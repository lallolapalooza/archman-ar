NAME

theme — إنشاء صفحة ويب من ملف قالب

SYNOPSIS

theme [-C flags-option] [-c options] [-d root] [-E] [-f] [-o file] [-p pagename] [-t template] [-V] [textfile]

DESCRIPTION

الأداة theme تأخذ ملف نصي بتنسيق markdown(7) (أو stdin إذا لم يتم تحديده)، تقوم بتجميعه، وتدمجه مع قالب (page.theme افتراضيًا) لإنتاج صفحة ويب. إذا لم يتم تحديد مسار للقالب، تبحث theme عن page.theme في الدليل الحالي، ثم في كل دليل أب حتى document root (المحدد بالخيار -d أو، إذا لم يكن محددًا، الدليل الجذري للنظام.) إذا تم العثور على page.theme، تقوم theme بنسخه إلى المخرجات، مع البحث عن علامات html <?theme action?> ومعالجة action المضمنة حسب الاقتضاء.

theme تعالج الإجراءات التالية:

author
تطبع اسم/أسماء المؤلف من الدالة mkd_doc_author(3).
body
تطبع ملف الإدخال بتنسيق markdown(7) المنسق.
date
تطبع التاريخ الذي تم إرجاعه بواسطة mkd_doc_date(3) أو، إذا لم يكن هناك، تاريخ آخر تعديل للملف المدخل.
dir
تطبع جزء الدليل من اسم الصفحة.
include(file)
تطبع محتويات file. Markdown(7) Translation لن تتم على هذا الملف.
source
جزء اسم الملف من اسم الصفحة.
style
تطبع أي أوراق أنماط (انظر mkd-extensions(7)) تم العثور عليها في ملف الإدخال.
title
تطبع العنوان الذي تم إرجاعه بواسطة mkd_doc_title(3)، أو، إذا لم يكن موجودًا، اسم ملف المصدر.
version
تطبع إصدار discount(7) الذي تم تجميع هذه النسخة من theme به.

إذا كان الإدخال يأتي من ملف ولم يتم تعيين المخرجات باستخدام الخيار -o، فإن تكتب المخرجات إلى file-sans-text.html (إذا كان file لديه لاحقة .text، فسيتم إزالتها واستبدالها بـ .html؛ بخلاف ذلك، سيتم إضافة .html إلى نهاية اسم الملف.)

الخيارات هي كما يلي:

-d root
تعيين document root إلى root
-E
عادةً، لن تقوم theme بتوسيع <?theme body?> أو <?theme toc?> في قسم <head>، أو <?theme style?> في قسم <body>، ولكن الخيار -E يتجاوز هذا ويسمح بالتوسعات في كل مكان.
-f
الكتابة فوق ملفات html الموجودة بالقوة.
-o filename
اكتب المخرجات إلى filename.
-p path
تعيين اسم الصفحة إلى path.
-t filename
استخدم filename كملف القالب.

RETURN VALUES

تخرج الأداة theme برمز 0 عند النجاح، و >0 إذا حدث خطأ.

SEE ALSO

markdown(1), markdown(3), markdown(7), mkd-extensions(7).
