toupper(3) دليل وظائف المكتبة toupper(3)

الاسم

toupper, tolower, toupper_l, tolower_l - تحويل الحالة إلى أحرف كبيرة أو صغيرة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <ctype.h>
int toupper(int c);
int tolower(int c);
int toupper_l(int c, locale_t locale);
int tolower_l(int c, locale_t locale);
متطلبات ميزة الاختبار (Feature Test Macro) لـ glibc (انظر feature_test_macros(7)):

toupper_l(), tolower_l():

    منذ glibc 2.10:
        _XOPEN_SOURCE >= 700
    قبل glibc 2.10:
        _GNU_SOURCE

الوصف

تقوم هذه الوظائف بتحويل الأحرف الصغيرة إلى أحرف كبيرة، والعكس صحيح.

إذا كانت c حرفًا صغيرًا، فإن toupper() تعيد تمثيله بالحرف الكبير، إذا كان له تمثيل بالحرف الكبير في المنطقة المحلية الحالية. وإلا، فإنها تعيد c. تؤدي الوظيفة toupper_l() نفس المهمة، ولكنها تستخدم المنطقة المحلية المشار إليها بواسطة مقبض المنطقة المحلية locale.

إذا كانت c حرفًا كبيرًا، فإن tolower() تعيد تمثيله بالحرف الصغير، إذا كان له تمثيل بالحرف الصغير في المنطقة المحلية الحالية. وإلا، فإنها تعيد c. تؤدي الوظيفة tolower_l() نفس المهمة، ولكنها تستخدم المنطقة المحلية المشار إليها بواسطة مقبض المنطقة المحلية locale.

إذا لم تكن c قيمة unsigned char أو EOF، فإن سلوك هذه الوظائف غير محدد.

سلوك toupper_l() و tolower_l() غير محدد إذا كانت locale هي كائن المنطقة المحلية الخاص LC_GLOBAL_LOCALE (انظر duplocale(3)) أو لم تكن مقبض كائن منطقة محلية صالحًا.

قيمة الإرجاع

القيمة المعادة هي قيمة الحرف المحول، أو c إذا لم يكن التحويل ممكنًا.

ملاحظات

تتطلب المعايير أن يكون الوسيط c لهذه الوظائف إما EOF أو قيمة يمكن تمثيلها في النوع unsigned char. إذا كان الوسيط c من النوع char، فيجب تحويله إلى unsigned char، كما في المثال التالي:


char c;
...
res = toupper((unsigned char) c);

هذا ضروري لأن char قد يكون مكافئًا لـ signed char، وفي هذه الحالة سيتم تمديد البت العلوي عند التحويل إلى int، مما ينتج عنه قيمة خارج نطاق unsigned char.

تعتمد تفاصيل ما يشكل حرفًا كبيرًا أو صغيرًا على المنطقة المحلية. على سبيل المثال، لا تعرف المنطقة المحلية الافتراضية "C" الأحرف المختلطة (umlauts)، لذلك لا يتم إجراء أي تحويل لها.

في بعض المناطق المحلية غير الإنجليزية، توجد أحرف صغيرة ليس لها مقابل حرف كبير؛ الحرف الألماني "sharp s" هو أحد الأمثلة.
