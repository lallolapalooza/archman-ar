toolbox-enter(1)

الحزمة: toolbox

التراخيص: Apache-2.0

toolbox-enter(1) دليل الأوامر العامة toolbox-enter(1)

الاسم

toolbox-enter - الدخول إلى حاوية Toolbx للاستخدام التفاعلي

الموجز

toolbox enter [--distro DISTRO | -d DISTRO]
[--release RELEASE | -r RELEASE]
[CONTAINER]

الوصف

يقوم بإنشاء قشرة تفاعلية داخل حاوية Toolbx تم إنشاؤها باستخدام الأمر toolbox create. يحاول إنشاء قشرة المستخدم الافتراضية، ولكن إذا لم تكن متاحة داخل الحاوية، فإنه يعود إلى /bin/bash.

عند استدعائه بدون أي خيارات، سيحاول toolbox enter الدخول إلى حاوية Toolbx الافتراضية للمضيف، أو إذا كانت هناك حاوية واحدة فقط متاحة فسيستخدمها. في Fedora، تُعرف الحاوية الافتراضية باسم fedora-toolbox-N، حيث N هو إصدار المضيف. إذا لم تكن هناك حاويات، فسيقدم toolbox enter إنشاء الحاوية الافتراضية لك.

يمكن تحديد حاوية معينة باستخدام الوسيط CONTAINER.

حاوية Toolbx هي حاوية OCI. لذلك، فإن toolbox enter يعادل podman start متبوعًا بـ podman exec.

خيارات

يتم فهم الخيارات التالية:

--distro DISTRO, -d DISTRO

الدخول إلى حاوية Toolbx لنظام تشغيل مختلف DISTRO عن المضيف. يجب أن يقترن بـ --release ما لم يطابق DISTRO المحدد المضيف.

--release RELEASE, -r RELEASE

الدخول إلى حاوية Toolbx لنظام تشغيل مختلف RELEASE عن المضيف.

أمثلة

الدخول إلى حاوية Toolbx الافتراضية المطابقة لنظام تشغيل المضيف

$ toolbox enter

الدخول إلى حاوية Toolbx الافتراضية لـ Fedora 36

$ toolbox enter --distro fedora --release f36

الدخول إلى حاوية Toolbx باسم مخصص

$ toolbox enter foo
