TAP::Parser::Result(3perl) دليل مبرمجي بيرل TAP::Parser::Result(3perl)

الاسم

TAP::Parser::Result - الفئة الأساسية لكائنات مخرجات TAP::Parser

الإصدار

الإصدار 3.50

الملخص

# فئة مجردة - لا يُقصد استخدامها مباشرة
# انظر TAP::Parser::ResultFactory للاستخدام المفضل
# مباشرة:
use TAP::Parser::Result;
my $token  = {...};
my $result = TAP::Parser::Result->new( $token );

الوصف

هذه فئة أساسية بسيطة تستخدمها TAP::Parser لتخزين الكائنات التي تمثل البيانات الحالية لمخرجات الاختبار من TAP (عادةً سطر واحد). إلا إذا كنت تقوم بإنشاء فئة فرعية، فمن غير المحتمل أن تحتاج إلى استخدام هذه الوحدة مباشرة.

الطرق

"new"

# انظر TAP::Parser::ResultFactory للاستخدام المفضل
# للاستخدام المباشر:
my $result = TAP::Parser::Result->new($token);

ترجع مثيلًا للفئة المناسبة لرمز الاختبار المقدم.

طرق منطقية

جميع الطرق التالية ترجع قيمة منطقية ويجب تجاوزها في الفئة الفرعية المناسبة.

  • "is_plan"

    يشير إلى ما إذا كان هذا هو سطر خطة الاختبار أم لا.

    1..3
  • "is_pragma"

    يشير إلى ما إذا كان هذا هو سطر pragma أم لا.

    pragma +strict
  • "is_test"

    يشير إلى ما إذا كان هذا هو سطر اختبار أم لا.

    ok 1 Is OK!
  • "is_comment"

    يشير إلى ما إذا كان هذا تعليقًا أم لا.

    # this is a comment
  • "is_bailout"

    يشير إلى ما إذا كان هذا هو سطر الهروب أم لا.

    Bail out! We're out of dilithium crystals.
  • "is_version"

    يشير إلى ما إذا كان هذا هو سطر إصدار TAP أم لا.

    TAP version 4
  • "is_unknown"

    يشير إلى ما إذا كان يمكن تحليل السطر الحالي أم لا.

    ... this line is junk ...
  • "is_yaml"

    يشير إلى ما إذا كان هذا مقطع YAML أم لا.

"raw"

print $result->raw;

يرجع السطر الأصلي للنص الذي تم تحليله.

"type"

my $type = $result->type;

يرجع "نوع" الرمز، مثل "comment" أو "test".

"as_string"

print $result->as_string;

يطبع تمثيلًا نصيًا للرمز. قد لا يكون هذا هو الإخراج الدقيق، ومع ذلك. ستتم إضافة أرقام الاختبارات إلى الاختبارات إذا لم تكن موجودة، وستتم كتابة توجيهات TODO و SKIP بأحرف كبيرة، وبشكل عام، سيتم تنظيف الأشياء. إذا كنت بحاجة إلى النص الأصلي للرمز، فراجع طريقة "raw".

"is_ok"

if ( $result->is_ok ) { ... }

يبلغ عما إذا كان نتيجة معينة قد نجحت أم لا. أي شيء ليس نتيجة اختبار يرجع قيمة صحيحة. يتم توفير هذا ببساطة كاختصار مريح.

"passed"

تم إهماله. يرجى استخدام "is_ok" بدلاً من ذلك.

"has_directive"

if ( $result->has_directive ) {
   ...
}

يشير إلى ما إذا كانت النتيجة المعطاة تحتوي على توجيه TODO أو SKIP أم لا.

"has_todo"

if ( $result->has_todo ) {
    ...
}

يشير إلى ما إذا كانت النتيجة المعطاة تحتوي على توجيه TODO أم لا.

"has_skip"

if ( $result->has_skip ) {
    ...
}

يشير إلى ما إذا كانت النتيجة المعطاة تحتوي على توجيه SKIP أم لا.

"set_directive"

يضبط التوجيه المرتبط بهذا الرمز. يستخدم داخليًا لمحاكاة اختبارات TODO.

إنشاء فئات فرعية

يرجى الاطلاع على "SUBCLASSING" في TAP::Parser للحصول على نظرة عامة على إنشاء الفئات الفرعية.

تذكر: إذا كنت تريد أن يتم استخدام فئتك الفرعية تلقائيًا بواسطة المحلل، فسيتعين عليك تسجيلها باستخدام "register_type" في TAP::Parser::ResultFactory.

إذا كنت تنشئ نوع نتيجة جديدًا تمامًا، فستحتاج على الأرجح إلى إنشاء فئة فرعية لـ TAP::Parser::Grammar أيضًا، وإلا فلن يتم استخدامه أبدًا.

مثال

package MyResult;
use strict;
use base 'TAP::Parser::Result';
# تسجيل مع المصنع:
TAP::Parser::ResultFactory->register_type( 'my_type' => __PACKAGE__ );
sub as_string { 'My results all look the same' }
