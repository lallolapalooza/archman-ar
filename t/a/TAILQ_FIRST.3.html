TAILQ_FIRST(3)

NAME

TAILQ_FIRST, TAILQ_NEXT, TAILQ_LAST, TAILQ_PREV, TAILQ_ENQUEUE, TAILQ_DEQUEUE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_REMOVE, TAILQ_SWAP — macros for manipulating doubly linked lists

LIBRARY

Standard C Library (libc, -lc)

SYNOPSIS

#include <sys/queue.h>

The structures of list entries are declared using TAILQ_ENTRY macro.

typedef struct { ... } TAILQ_HEAD(tailq_name, type);

The list head structure is declared using TAILQ_HEAD macro.

The macros for manipulating the list are:

TAILQ_FIRST(tailq_head_p)
TAILQ_NEXT(list_entry_p, field)
TAILQ_LAST(tailq_head_p, type)
TAILQ_PREV(list_entry_p, type, field)
TAILQ_ENQUEUE(tailq_head_p, list_entry_p, field)
TAILQ_DEQUEUE(tailq_head_p, list_entry_p, field)
TAILQ_INSERT_HEAD(tailq_head_p, list_entry_p, field)
TAILQ_INSERT_TAIL(tailq_head_p, list_entry_p, field)
TAILQ_INSERT_AFTER(list_entry_p, new_entry_p, field)
TAILQ_INSERT_BEFORE(list_entry_p, new_entry_p, field)
TAILQ_REMOVE(tailq_head_p, list_entry_p, field)
TAILQ_SWAP(tailq_head_p, list_entry_p, type)

DESCRIPTION

These macros provide an implementation of doubly linked lists. A doubly linked list is a data structure in which each element (node) stores a pointer to the previous element and to the next element. The list itself is managed through a head structure, which usually stores pointers to the first and last elements.

The macros manipulate TAILQ lists. The macros TAILQ_ENTRY and TAILQ_HEAD are used to declare the entry and head structures.

For example:

struct my_node {
    int data;
    TAILQ_ENTRY(my_node) entries;
};

TAILQ_HEAD(my_list_head, my_node);
struct my_list_head my_list;

struct my_node *new_node;
struct my_node *current_node;

TAILQ_INIT(&my_list);
...
new_node = malloc(sizeof(*new_node));
new_node->data = 42;
TAILQ_INSERT_TAIL(&my_list, new_node, entries);
...
TAILQ_FOREACH(current_node, &my_list, entries) {
    printf("%d\n", current_node->data);
}
...
TAILQ_REMOVE(&my_list, current_node, entries);
free(current_node);

The `field` argument in the manipulation macros refers to the name of the TAILQ_ENTRY member within the list node structure.

The `tailq_head_p` argument is a pointer to the TAILQ_HEAD structure.

The `list_entry_p` argument is a pointer to the list entry structure.

The `type` argument is the name of the structure being used in the list, as specified in the TAILQ_HEAD macro.

The `new_entry_p` argument is a pointer to the new entry to be inserted.

TAILQ_FIRST

Returns a pointer to the first entry in the list.

TAILQ_NEXT

Returns a pointer to the next entry in the list after the specified entry.

TAILQ_LAST

Returns a pointer to the last entry in the list.

TAILQ_PREV

Returns a pointer to the previous entry in the list before the specified entry.

TAILQ_ENQUEUE

Adds an entry to the end of the list. This is a synonym for TAILQ_INSERT_TAIL.

TAILQ_DEQUEUE

Removes an entry from the list and returns a pointer to it. This is a synonym for TAILQ_REMOVE.

TAILQ_INSERT_HEAD

Inserts a new entry at the head of the list.

TAILQ_INSERT_TAIL

Inserts a new entry at the tail of the list.

TAILQ_INSERT_AFTER

Inserts a new entry in the list after the specified entry.

TAILQ_INSERT_BEFORE

Inserts a new entry in the list before the specified entry.

TAILQ_REMOVE

Removes the specified entry from the list.

TAILQ_SWAP

Swaps the contents of two list entries.

RETURN VALUE

TAILQ_FIRST, TAILQ_NEXT, TAILQ_LAST, and TAILQ_PREV return pointers to list entries, or NULL if the list is empty or the operation is invalid.

TAILQ_ENQUEUE and TAILQ_DEQUEUE return a pointer to the dequeued entry, or NULL if the list is empty.

The insertion and removal macros do not return values.

STANDARDS

These macros are part of the BSD C library and are widely available on Unix-like systems. They are not part of the C standard.

HISTORY

The TAILQ macros first appeared in 4.4BSD.

CAVEATS

The TAILQ macros are not thread-safe. If used in a multithreaded environment, external synchronization mechanisms must be employed.

Care must be taken to ensure that the list entry structures are properly initialized before being used with these macros. Specifically, TAILQ_INIT should be called on the list head before any insertions.

EXAMPLES

The following example demonstrates how to create a doubly linked list, insert elements, iterate through it, and remove elements.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct item {
    int id;
    TAILQ_ENTRY(item) next;
};

TAILQ_HEAD(item_list_head, item);

int
main() {
    struct item_list_head head;
    struct item *n1, *n2;

    TAILQ_INIT(&head);

    // Insert items
    for (int i = 0; i < 5; ++i) {
        n1 = malloc(sizeof(*n1));
        n1->id = i;
        TAILQ_INSERT_TAIL(&head, n1, next);
    }

    // Iterate and print items
    printf("List contents:\n");
    TAILQ_FOREACH(n1, &head, next) {
        printf("Item ID: %d\n", n1->id);
    }

    // Remove and free items
    printf("\nRemoving items:\n");
    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, next);
        printf("Removing item ID: %d\n", n1->id);
        TAILQ_REMOVE(&head, n1, next);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head); // Re-initialize the head after emptying
    exit(EXIT_SUCCESS);
}
