TAILQ(3) دليل وظائف المكتبة TAILQ(3)

الاسم

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - تطبيق قائمة ذيلية مرتبطة بشكل مزدوج

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/queue.h>
TAILQ_ENTRY(TYPE);
TAILQ_HEAD(HEADNAME, TYPE);

                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_TAIL(TAILQ_HEAD *head,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_BEFORE(struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
void TAILQ_INSERT_AFTER(TAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, TAILQ_ENTRY NAME);
struct TYPE *TAILQ_FIRST(TAILQ_HEAD *head);
struct TYPE *TAILQ_LAST(TAILQ_HEAD *head, HEADNAME);
struct TYPE *TAILQ_PREV(struct TYPE *elm, HEADNAME, TAILQ_ENTRY NAME);

                         TAILQ_ENTRY NAME);

                         TAILQ_ENTRY NAME);

                         TAILQ_ENTRY NAME);

الوصف

تعرف هذه الماكرو وتشغل قوائم ذيلية مرتبطة بشكل مزدوج.

في تعريفات الماكرو، TYPE هو اسم هيكل معرف من قبل المستخدم، يجب أن يحتوي على حقل من نوع TAILQ_ENTRY، يسمى NAME. الوسيط HEADNAME هو اسم هيكل معرف من قبل المستخدم يجب تعريفه باستخدام الماكرو TAILQ_HEAD().

الإنشاء

تتكون قائمة الذيل من هيكل يتم تعريفه بواسطة الماكرو TAILQ_HEAD(). يحتوي هذا الهيكل على زوج من المؤشرات، واحد يشير إلى العنصر الأول في القائمة والآخر يشير إلى العنصر الأخير في القائمة. العناصر مرتبطة بشكل مزدوج بحيث يمكن إزالة عنصر تعسفي دون اجتياز القائمة. يمكن إضافة عناصر جديدة إلى القائمة بعد عنصر موجود، قبل عنصر موجود، في بداية القائمة، أو في نهاية القائمة. يتم تعريف هيكل TAILQ_HEAD كالتالي:


TAILQ_HEAD(HEADNAME, TYPE) head;

حيث struct HEADNAME هو الهيكل الذي سيتم تعريفه، و struct TYPE هو نوع العناصر التي سيتم ربطها في القائمة. يمكن لاحقًا تعريف مؤشر إلى رأس القائمة كالتالي:


struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

يعرف الماكرو TAILQ_ENTRY() هيكلًا يربط العناصر في القائمة.

يقيم الماكرو TAILQ_HEAD_INITIALIZER() قيمة تهيئة للقائمة head.

يقوم الماكرو TAILQ_INIT() بتهيئة القائمة المشار إليها بواسطة

يقيم الماكرو TAILQ_EMPTY() قيمة صحيحة إذا لم تكن هناك عناصر في القائمة. head.

الإدراج

يقوم الماكرو TAILQ_INSERT_HEAD() بإدراج العنصر الجديد elm في بداية القائمة.

يقوم الماكرو TAILQ_INSERT_TAIL() بإدراج العنصر الجديد elm في نهاية القائمة.

يقوم الماكرو TAILQ_INSERT_BEFORE() بإدراج العنصر الجديد elm قبل العنصر listelm.

يقوم الماكرو TAILQ_INSERT_AFTER() بإدراج العنصر الجديد elm بعد العنصر listelm.

الاجتياز

يقوم الماكرو TAILQ_FIRST() بإرجاع العنصر الأول في القائمة، أو NULL إذا كانت القائمة فارغة.

يقوم الماكرو TAILQ_LAST() بإرجاع العنصر الأخير في القائمة. إذا كانت القائمة فارغة، فإن قيمة الإرجاع هي NULL.

يقوم الماكرو TAILQ_PREV() بإرجاع العنصر السابق في القائمة، أو NULL إذا كان هذا العنصر هو الأول.

يقوم الماكرو TAILQ_NEXT() بإرجاع العنصر التالي في القائمة، أو NULL إذا كان هذا العنصر هو الأخير.

يقوم الماكرو TAILQ_FOREACH() باجتياز القائمة المشار إليها بواسطة head في الاتجاه الأمامي، وتعيين كل عنصر بدوره إلى var. يتم تعيين var إلى NULL إذا اكتملت الحلقة بشكل طبيعي، أو إذا لم تكن هناك عناصر.

يقوم الماكرو TAILQ_FOREACH_REVERSE() باجتياز القائمة المشار إليها بواسطة head في الاتجاه العكسي، وتعيين كل عنصر بدوره إلى var.

الإزالة

يقوم الماكرو TAILQ_REMOVE() بإزالة العنصر elm من القائمة.

ميزات أخرى

يقوم الماكرو TAILQ_CONCAT() بدمج القائمة التي يرأسها head2 بنهاية القائمة التي يرأسها head1، وإزالة جميع الإدخالات من الأولى.

قيمة الإرجاع

يرجع الماكرو TAILQ_EMPTY() قيمة غير صفرية إذا كانت القائمة فارغة، وصفر إذا كانت القائمة تحتوي على إدخال واحد على الأقل.

ترجع الماكرو TAILQ_FIRST(), TAILQ_LAST(), TAILQ_PREV(), و TAILQ_NEXT() مؤشرًا إلى هيكل TYPE الأول، الأخير، السابق، أو التالي، على التوالي.

يقيم الماكرو TAILQ_HEAD_INITIALIZER() قيمة تهيئة يمكن تعيينها لرأس القائمة head.

المعايير

BSD.

التاريخ

4.4BSD.

تحذيرات

لا تسمح الماكرو TAILQ_FOREACH() و TAILQ_FOREACH_REVERSE() بإزالة أو تحرير var داخل الحلقة، حيث سيؤثر ذلك على الاجتياز. الماكرو TAILQ_FOREACH_SAFE() و TAILQ_FOREACH_REVERSE_SAFE()، الموجودة في BSDs ولكنها غير موجودة في glibc، تعالج هذا القيد بالسماح بإزالة var بأمان من القائمة وتحريرها من داخل الحلقة دون التأثير على الاجتياز.

أمثلة

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Tail queue */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tail queue head */
    int i;
    TAILQ_INIT(&head);                      /* Initialize the queue */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insert at the tail */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insert before */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Deletion */
    free(n2);
                                            /* Forward traversal */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Reverse traversal */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
