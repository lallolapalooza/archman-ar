الاسم

TAP::Parser::Result::Plan - رمز نتيجة الخطة.

الإصدار

الإصدار 3.50

الوصف

هذه فئة فرعية من TAP::Parser::Result. سيتم إرجاع رمز من هذه الفئة إذا تم العثور على سطر خطة.

1..1
ok 1 - woo hooo!

1..1 هي الخطة. يجب أن تكون هناك خطة.

طرق متجاوزة

مدرجة هنا بشكل أساسي لإسكات صرخات اختبارات تغطية الـ pod. إنها تبقيني مستيقظًا في الليل.

  • "as_string"
  • "raw"

طرق المثيل

"plan"

if ( $result->is_plan ) {
   print $result->plan;
}

هذه مجرد مرادف لـ "as_string".

"tests_planned"

my $planned = $result->tests_planned;

تُرجع عدد الاختبارات المخطط لها. على سبيل المثال، خطة 1..17 ستتسبب في أن تُرجع هذه الطريقة '17'.

"directive"

my $directive = $plan->directive;

إذا تم تضمين توجيه SKIP مع الخطة، فسوف تُرجعه هذه الطريقة.

1..0 # SKIP: why bother?

"has_skip"

if ( $result->has_skip ) { ... }

تُرجع قيمة منطقية تشير إلى ما إذا كان هذا الاختبار يحتوي على توجيه SKIP أم لا.

"explanation"

my $explanation = $plan->explanation;

إذا تم تضمين توجيه SKIP مع الخطة، فسوف تُرجع هذه الطريقة الشرح، إن وجد.

"todo_list"

my $todo = $result->todo_list;
for ( @$todo ) {
    ...
}
