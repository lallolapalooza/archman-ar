الحزمة: libbobcat

التراخيص: GPL

FBB::Table(3bobcat) منسق الجدول FBB::Table(3bobcat)

الاسم

FBB::Table - إنشاء جداول مملوءة صفًا أو عمودًا

الملخص

#include <bobcat/table>
خيار الربط: -lbobcat

الوصف

يمكن استخدام كائنات FBB::Table لإنشاء جداول. تملأ الجداول إما عموديًا أو أفقيًا. يمكن ضبط العديد من خصائص الجدول بدقة باستخدام كائن FBB::TableSupport منفصل (راجع tablesupport(3bobcat)). عند عدم استخدام كائن FBB::TableSupport، يتم إنشاء جدول بسيط، مملوء أفقيًا أو عموديًا، والذي يمكن إدراجه في std::ostream.

تتكون الجداول المعرفة بواسطة Table من صفوف وعدد ثابت من الأعمدة. يتم تحديد عدد الأعمدة في وقت الإنشاء، ويعتمد عدد الصفوف أيضًا على عدد العناصر المدرجة. تتم معالجة الأعمدة والصفوف باستخدام المؤشرات (بدءًا من 0). قبل العمود الأيسر، وبين الأعمدة، وخارج العمود الأخير، يتم تعريف فواصل. افتراضيًا، تكون هذه الفواصل فارغة، ولكن يمكن إعطاء كل فاصل عرضًا أو محتوى (ثابتًا). تتم معالجة الفاصل قبل العمود col باسم فاصل col، ويتم معالجة الفاصل الأيمن باسم فاصل nColumns.

يمكن أيضًا فصل الصفوف عن بعضها البعض باستخدام فواصل. هذه الصفوف الفاصلة فارغة افتراضيًا. تتم معالجة الفاصل قبل الصف row باسم فاصل الصف row. تتم معالجة الفاصل بعد الصف النهائي باسم فاصل الصف nRows، حيث nRows هي القيمة التي تعيدها الدالة العضوية nRows.

تُعرّف الفواصل غير الافتراضية (أي غير الفارغة) باستخدام كائنات FBB::TableSupport (راجع tablesupport(3bobcat)).

تبدو كائنات Table مشابهة جدًا لكائنات ostream، باستخدام طريقة بسيطة لتعريف عناصر جديدة: كل إدخال جديد يحدد عنصر جدول آخر، ومن الصعب إنهاء صف قبل أن يحصل على عدد nColumn من العناصر. الفئة الشقيقة لـ Table، وهي TableBuf، هي فئة من نوع std::streambuf، توفر تحكمًا إضافيًا من خلال استخدام كائن فئة ostream محيط.

اسم النطاق

FBB
جميع المنشئات، الدوال الأعضاء، المعاملات، والمتحكمات المذكورة في صفحة الدليل هذه، معرفة في نطاق الأسماء FBB.

ترث من

std::ostringstream - ترث Table من std::ostringstream، مما يسمح بإدراج البيانات في كائن Table. كل إدخال منفصل يضيف عنصرًا آخر إلى كائن Table.

FBB::TableBase - تنفذ هذه الفئة عناصر مشتركة لتنفيذ الجدول. لا يُقصد استخدام فئة TableBase بمفردها، ولا توجد صفحة دليل منفصلة. يتم وصف المرافق التي توفرها Table والتي تم وراثتها من TableBase في صفحة الدليل هذه.

تعدادات

التعدادات التالية معرفة بواسطة الفئة FBB::Table: enum FillDirection
يحدد هذا التعداد قيمتين:

o
ROWWISE:
عند تحديد هذه القيمة في وقت الإنشاء، تتم إضافة العناصر صفًا. أي أن العنصر الثاني المدرج في Table سيوجد في العمود الثاني من الصف الأول؛
o
COLUMNWISE:
عند تحديد هذه القيمة في وقت الإنشاء، تتم إضافة العناصر عمودًا. أي أن العنصر الثاني يوجد في الصف الثاني من العمود الأول.

enum WidthType
يحدد هذا التعداد قيمتين:

o
COLUMNWIDTH:
حدد هذه القيمة عندما يمكن أن يكون للأعمدة عروض متغيرة. في هذه الحالة، سيكون كل عمود بعرض أوسع عنصر فيه. هذا هو WidthType الافتراضي المستخدم بواسطة كائنات Table.
o
EQUALWIDTH:
حدد هذه القيمة عندما يجب أن يكون لجميع أعمدة الجدول عروض متساوية (أي، مساوية لعرض أوسع عنصر في الجدول)،

المنشئات

o
Table(size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH):
يجب توفير عدد أعمدة الجدول، اتجاهات التعبئة، ونوع عرض العمود. يتم ضمنيًا تحديد عدد الصفوف من خلال مزيج هذا المعامل وعدد العناصر التي تم إدراجها فعليًا في كائن Table. يحدد معامل direction الطريقة التي تتم بها إضافة العناصر الجديدة إلى كائن Table: صفًا أو عمودًا. أخيرًا، يُستخدم المعامل widthType لتحديد الطريقة التي يتم بها تحديد عرض أعمدة الجدول. يحدد كل عمود عرضه الخاص أو جميع الأعمدة لها عروض متساوية.
o
Table(TableSupport &tableSupport, size_t nColumns, Table::FillDirection direction, Table::WidthType widthType = Table::COLUMNWIDTH):
يعمل هذا المنشئ بشكل مطابق للمنشئ السابق، ولكنه يتوقع مرجعًا إضافيًا لكائن TableSupport. يوفر كائن TableSupport ميزات تنسيق إضافية تستخدمها عناصر تعريف الجدول مثل الخطوط الأفقية بين الصفوف، والفواصل الإضافية، وما إلى ذلك. يتم تمرير كائن TableSupport كمرجع غير ثابت لأن كائن Table يجب أن يكون قادرًا على التلاعب ببياناته. انظر tablesuppport(3bobcat) لمزيد من المعلومات حول TableSupport.

منشئات النسخ والتحريك (وعوامل التعيين) غير متاحة.

MEMBER FUNCTIONS

o
void def():
The def member is called implicitly when the Table object is inserted into an output stream, i.e. by means of operator<<(ostream, Table). If the table is to be inserted into another stream, e.g. by means of the Table::operator<<(ostream, Table) function, then it may be called explicitly. This member is also called by the Table::operator<<(ostream, Table) function when it is inserted into a stream. Its purpose is to finalize the dimensions of the table, i.e. to resize the table to its final dimensions, given the current column-widths and alignments. If the table contents does not fill the table completely, then empty cells are appended. The table is then said to be complete.

It is automatically called by operator<<(ostream, Table). In other situations it may be called explicitly to force the insertion of another row in a table using ROWWISE insertions. With COLUMNWISE insertions its working is complex, since new elements added to a COLUMNWISE filled table will reshuffle its elements over the table’s columns;

o
void fill(InputIterator begin, InputIterator end):
This member is defined as a member template; InputIterator is a template type parameter representing any input iterator. It can also be, e.g., a pointer to an insertable type. The iterators must point to data elements which can be inserted into an std::ostream. The range of values implied by the member’s iterator pair are inserted into the table as new elements;
o
void push_back(std::string const &element):
New elements can be added to the table using push_back. It could e.g., be called from a back_inserter adaptor;
o
size_t nRows():
The table’s current number of rows is returned. It is initialized to 0, and after that updated when def has been called;
o
Table &setAlign(Align const &align):
The alignment type of either a column or an element of the Table object is defined using setAlign. The standard alignments std::left, std::right and std::internal may be specified, but in addition the alignment FBB::center may be used if elements should be centered into their column. A construction like 
tab << Align(2, FBB::center)
requests centering of all elements in the table’s column having index value 2 (i.e., the table’s 3rd column), whereas a construction like 
tab << Align(2, 3, FBB::center)
requests centering of element [2][3]. It is the responsibility of the programmer to ensure that such elements exist. By default, all elements are right-aligned. )

o
Table &def(Table &table):
This manipulator can be inserted into a table to call the table’s def member.

EXAMPLE

#include <iostream>
#include <bobcat/table>
#include <bobcat/tablelines>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    TableLines tablelines;
                                // width/separators of cols 0, 1 and 2
    tablelines << 0 << " | " << " | ";
                                // hline over cols 1 and 2 of row 1
    tablelines << TableLines::HLine(1, 1, 3);
    Table tab(tablelines, 3, Table::ROWWISE, Table::EQUALWIDTH);
    // or: Table tab(tablelines, 3, Table::ROWWISE);
    tab << Align(0, std::left);     // set column non-default alignment
    tab.fill(argv + 1, argv + argc);// fill range of values
    cout << tab << ’\n’;            // complete the table and insert
    tab << "hello" << "" << "wo";   // add additional elements.
    if (tab.nRows() > 2)
        tab << Align(2, 2, center); // set the layout of a specific element
    cout << tab << ’\n’;
}
