DESCRIPTION

These macros provide an implementation of a doubly linked list with a pointer to the tail. They are implemented using the standard C language and are suitable for use in kernel code as well as user code. The list head is represented by a TAILQ_HEAD macro, which must be initialized with TAILQ_INIT before use.

A list element is a structure that contains two pointers, next and prev, which are used to link the elements together. The element structure must be defined with the TAILQ_ENTRY macro. For example:

struct my_list_entry {
    ...
    TAILQ_ENTRY(my_list_entry) entries;
};

The TYPEQB argument in the macros refers to the head of the list, which is declared using the TAILQ_HEAD macro. For example:

TAILQ_HEAD(my_list_head, my_list_entry) my_list;

The TYPE argument refers to the type of the list element. The elm argument is a pointer to a list element. The prev argument is a pointer to the TAILQ_ENTRY field within the list element.

The TAILQ_FIRST macro returns a pointer to the first element in the list. If the list is empty, it returns NULL.

The TAILQ_NEXT macro returns a pointer to the next element in the list. If the given element is the last element in the list, it returns NULL.

The TAILQ_PREV macro returns a pointer to the previous element in the list. If the given element is the first element in the list, it returns NULL.

The TAILQ_LAST macro returns a pointer to the last element in the list. If the list is empty, it returns NULL.

The TAILQ_SUBSTR macro is similar to TAILQ_LAST, but it returns a pointer to the second to last element in the list. If the list has fewer than two elements, it returns NULL.

The TAILQ_END macro returns a pointer to a NULL value. This macro is typically used in conjunction with TAILQ_FIRST to iterate through the list.

The TAILQ_EMPTY macro returns true if the list is empty, and false otherwise.

The TAILQ_CIRCLE_FIRST, TAILQ_CIRCLE_NEXT, TAILQ_CIRCLE_PREV, TAILQ_CIRCLE_LAST, and TAILQ_CIRCLE_END macros are similar to their non-circular counterparts, but they operate on circular doubly linked lists. In a circular doubly linked list, the next pointer of the last element points to the first element, and the prev pointer of the first element points to the last element.

The TAILQ_CIRCLE_EMPTY macro returns true if the circular list is empty, and false otherwise.

The TAILQ_INIT macro initializes the list head so that it is empty.

The TAILQ_INSERT_HEAD macro inserts the element elm at the head of the list head.

The TAILQ_INSERT_TAIL macro inserts the element elm at the tail of the list head.

The TAILQ_INSERT_AFTER macro inserts the element elm after the element listelm in the list head.

The TAILQ_INSERT_BEFORE macro inserts the element elm before the element listelm in the list head.

The TAILQ_REMOVE macro removes the element elm from the list head.

The TAILQ_REPLACE macro replaces the element oldelm with the element newelm in the list head.

RETURN VALUE

The TAILQ_FIRST, TAILQ_NEXT, TAILQ_PREV, TAILQ_LAST, TAILQ_SUBSTR, TAILQ_END, TAILQ_CIRCLE_FIRST, TAILQ_CIRCLE_NEXT, TAILQ_CIRCLE_PREV, TAILQ_CIRCLE_LAST, and TAILQ_CIRCLE_END macros return pointers to list elements or NULL. The TAILQ_EMPTY and TAILQ_CIRCLE_EMPTY macros return a non-zero value if the list is empty, and zero otherwise.

STANDARDS

These macros are extensions to the C standard and are commonly found in BSD-derived systems. They are not part of the POSIX standard.

HISTORY

The tailq macros first appeared in 4.4BSD.

CAVEATS

The TAILQ_INSERT_AFTER and TAILQ_INSERT_BEFORE macros require that the listelm argument be non-NULL.

The TAILQ_REMOVE and TAILQ_REPLACE macros require that the elm argument be non-NULL.

EXAMPLES

The following example demonstrates how to use the tailq macros to create and manipulate a doubly linked list:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    TAILQ_ENTRY(node) entries;
};

TAILQ_HEAD(my_list_head, node) my_list;

int
main() {
    struct node *n1, *n2, *n_iter;

    TAILQ_INIT(&my_list);

    n1 = malloc(sizeof(*n1));
    n1->data = 10;
    TAILQ_INSERT_TAIL(&my_list, n1, entries);

    n2 = malloc(sizeof(*n2));
    n2->data = 20;
    TAILQ_INSERT_TAIL(&my_list, n2, entries);

    printf("List contents:\n");
    TAILQ_FOREACH(n_iter, &my_list, entries) {
        printf("%d\n", n_iter->data);
    }

    // Clean up the list
    while (!TAILQ_EMPTY(&my_list)) {
        n1 = TAILQ_FIRST(&my_list);
        TAILQ_REMOVE(&my_list, n1, entries);
        free(n1);
    }

    return 0;
}

The following example demonstrates how to free all elements from a tail queue:

    struct node *n1, *n2;

    ILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);

الوصف

توفر وحدات الماكرو هذه تطبيقًا لقائمة مزدوجة الارتباط مع مؤشر إلى الذيل. يتم تنفيذها باستخدام لغة C القياسية وهي مناسبة للاستخدام في كود النواة وكذلك كود المستخدم. يتم تمثيل رأس القائمة بواسطة ماكرو TAILQ_HEAD، والذي يجب تهيئته باستخدام TAILQ_INIT قبل الاستخدام.

عنصر القائمة هو هيكل يحتوي على مؤشرين، next و prev، واللذان يستخدمان لربط العناصر معًا. يجب تعريف هيكل العنصر باستخدام ماكرو TAILQ_ENTRY. على سبيل المثال:

struct my_list_entry {
    ...
    TAILQ_ENTRY(my_list_entry) entries;
};

يشير الوسيط TYPEQB في وحدات الماكرو إلى رأس القائمة، والذي يتم تعريفه باستخدام ماكرو TAILQ_HEAD. على سبيل المثال:

TAILQ_HEAD(my_list_head, my_list_entry) my_list;

يشير الوسيط TYPE إلى نوع عنصر القائمة. الوسيط elm هو مؤشر إلى عنصر القائمة. الوسيط prev هو مؤشر إلى حقل TAILQ_ENTRY داخل عنصر القائمة.

يرجع الماكرو TAILQ_FIRST مؤشرًا إلى العنصر الأول في القائمة. إذا كانت القائمة فارغة، فإنه يرجع NULL.

يرجع الماكرو TAILQ_NEXT مؤشرًا إلى العنصر التالي في القائمة. إذا كان العنصر المعطى هو العنصر الأخير في القائمة، فإنه يرجع NULL.

يرجع الماكرو TAILQ_PREV مؤشرًا إلى العنصر السابق في القائمة. إذا كان العنصر المعطى هو العنصر الأول في القائمة، فإنه يرجع NULL.

يرجع الماكرو TAILQ_LAST مؤشرًا إلى العنصر الأخير في القائمة. إذا كانت القائمة فارغة، فإنه يرجع NULL.

الماكرو TAILQ_SUBSTR مشابه لـ TAILQ_LAST، ولكنه يرجع مؤشرًا إلى العنصر قبل الأخير في القائمة. إذا كانت القائمة تحتوي على أقل من عنصرين، فإنه يرجع NULL.

يرجع الماكرو TAILQ_END مؤشرًا إلى قيمة NULL. يستخدم هذا الماكرو عادةً بالاقتران مع TAILQ_FIRST للتكرار عبر القائمة.

يرجع الماكرو TAILQ_EMPTY قيمة صحيحة إذا كانت القائمة فارغة، وقيمة خاطئة بخلاف ذلك.

تتشابه وحدات الماكرو TAILQ_CIRCLE_FIRST، TAILQ_CIRCLE_NEXT، TAILQ_CIRCLE_PREV، TAILQ_CIRCLE_LAST، و TAILQ_CIRCLE_END مع نظيراتها غير الدائرية، ولكنها تعمل على قوائم مزدوجة الارتباط دائرية. في قائمة مزدوجة الارتباط دائرية، يشير المؤشر next للعنصر الأخير إلى العنصر الأول، ويشير المؤشر prev للعنصر الأول إلى العنصر الأخير.

يرجع الماكرو TAILQ_CIRCLE_EMPTY قيمة صحيحة إذا كانت القائمة الدائرية فارغة، وقيمة خاطئة بخلاف ذلك.

يقوم الماكرو TAILQ_INIT بتهيئة رأس القائمة بحيث تكون فارغة.

يقوم الماكرو TAILQ_INSERT_HEAD بإدراج العنصر elm في رأس القائمة head.

يقوم الماكرو TAILQ_INSERT_TAIL بإدراج العنصر elm في ذيل القائمة head.

يقوم الماكرو TAILQ_INSERT_AFTER بإدراج العنصر elm بعد العنصر listelm في القائمة head.

يقوم الماكرو TAILQ_INSERT_BEFORE بإدراج العنصر elm قبل العنصر listelm في القائمة head.

يقوم الماكرو TAILQ_REMOVE بإزالة العنصر elm من القائمة head.

يقوم الماكرو TAILQ_REPLACE باستبدال العنصر oldelm بالعنصر newelm في القائمة head.

قيمة الإرجاع

ترجع وحدات الماكرو TAILQ_FIRST، TAILQ_NEXT، TAILQ_PREV، TAILQ_LAST، TAILQ_SUBSTR، TAILQ_END، TAILQ_CIRCLE_FIRST، TAILQ_CIRCLE_NEXT، TAILQ_CIRCLE_PREV، TAILQ_CIRCLE_LAST، و TAILQ_CIRCLE_END مؤشرات إلى عناصر القائمة أو NULL. ترجع وحدات الماكرو TAILQ_EMPTY و TAILQ_CIRCLE_EMPTY قيمة غير صفرية إذا كانت القائمة فارغة، وصفر بخلاف ذلك.

المعايير

تعد وحدات الماكرو هذه امتدادات لمعيار C وتوجد بشكل شائع في الأنظمة المشتقة من BSD. وهي ليست جزءًا من معيار POSIX.

التاريخ

ظهرت وحدات الماكرو tailq لأول مرة في 4.4BSD.

تحذيرات

تتطلب وحدات الماكرو TAILQ_INSERT_AFTER و TAILQ_INSERT_BEFORE أن يكون الوسيط listelm غير NULL.

تتطلب وحدات الماكرو TAILQ_REMOVE و TAILQ_REPLACE أن يكون الوسيط elm غير NULL.

#include <sys/queue.h>

    int data;
    TAILQ_ENTRY(node) entries;

TAILQ_HEAD(my_list_head, node) my_list;

int
main() {
    struct node *n1, *n2, *n_iter;

    TAILQ_INIT(&my_list);

    n1 = malloc(sizeof(*n1));
    n1->data = 10;
    TAILQ_INSERT_TAIL(&my_list, n1, entries);

    n2 = malloc(sizeof(*n2));
    n2->data = 20;
    TAILQ_INSERT_TAIL(&my_list, n2, entries);
