الحزمة: ocaml

التراخيص: LGPL2.1, custom: QPL-1.0

Targetint(3) مكتبة OCaml Targetint(3)

الاسم

Targetint - أعداد صحيحة أصلية خاصة بالمعالج المستهدف.

وحدة

الوحدة Targetint

التوثيق

الوحدة Targetint
: sig end

أعداد صحيحة أصلية خاصة بالمعالج المستهدف.

توفر هذه الوحدة عمليات على نوع الأعداد الصحيحة الموقعة ذات 32 بت (على الأنظمة الأساسية المستهدفة ذات 32 بت) أو الأعداد الصحيحة الموقعة ذات 64 بت (على الأنظمة الأساسية المستهدفة ذات 64 بت). هذا النوع من الأعداد الصحيحة له نفس عرض نوع المؤشر في مترجم C بالضبط. جميع العمليات الحسابية على هذه الأعداد تأخذ معامل 2^32 أو 2^64 اعتمادًا على حجم الكلمة في بنية النظام المستهدف.

تحذير: هذه الوحدة غير مستقرة وجزء من Compiler_libs.

val mul : t -> t -> t

الضرب.

val div : t -> t -> t

قسمة الأعداد الصحيحة. تثير Division_by_zero إذا كان الوسيط الثاني صفرًا. هذه القسمة تقرب خارج القسمة الحقيقي لوسائطه نحو الصفر، كما هو محدد لـ (/).

val unsigned_div : t -> t -> t

نفس Targetint.div، باستثناء أن الوسائط والنتائج تُفسر كأعداد صحيحة غير موقعة.

val rem : t -> t -> t

باقي قسمة الأعداد الصحيحة. إذا كان y لا يساوي صفرًا، فإن نتيجة Targetint.rem x y تحقق الخصائص التالية: Targetint.zero <= Nativeint.rem x y < Targetint.abs y و x = Targetint.add (Targetint.mul (Targetint.div x y) y)
(Targetint.rem x y). إذا كان y = 0، تثير Targetint.rem x y Division_by_zero.

val unsigned_rem : t -> t -> t

نفس Targetint.rem، باستثناء أن الوسائط والنتائج تُفسر كأعداد صحيحة غير موقعة.

val succ : t -> t

اللاحق. Targetint.succ x هو Targetint.add x Targetint.one.

val pred : t -> t

السابق. Targetint.pred x هو Targetint.sub x Targetint.one.

val abs : t -> t

abs x هي القيمة المطلقة لـ x. على min_int، تكون min_int نفسها وبالتالي تظل سالبة.

val size : int

حجم العدد الصحيح الأصلي المستهدف بالبت.

val max_int : t

أكبر عدد صحيح مستهدف يمكن تمثيله، إما 2^31 - 1 على منصة 32 بت، أو 2^63 - 1 على منصة 64 بت.

val min_int : t

أصغر عدد صحيح مستهدف يمكن تمثيله، إما -2^31 على منصة 32 بت، أو -2^63 على منصة 64 بت.

val logand : t -> t -> t

عملية AND المنطقية على مستوى البت.

val logor : t -> t -> t

عملية OR المنطقية على مستوى البت.

val logxor : t -> t -> t

عملية XOR المنطقية على مستوى البت.

val lognot : t -> t

النفي المنطقي على مستوى البت.

val shift_left : t -> int -> t

Targetint.shift_left x y تُزيح x إلى اليسار بمقدار y بت. تكون النتيجة غير محددة إذا كانت y < 0 أو y >= bitsize ، حيث bitsize هي 32 على منصة 32 بت و 64 على منصة 64 بت.

val shift_right : t -> int -> t

Targetint.shift_right x y تُزيح x إلى اليمين بمقدار y بت. هذه إزاحة حسابية: يتم تكرار بت الإشارة لـ x ويتم إدخاله في البتات الفارغة. تكون النتيجة غير محددة إذا كانت y < 0 أو y >= bitsize.

val shift_right_logical : t -> int -> t

Targetint.shift_right_logical x y تُزيح x إلى اليمين بمقدار y بت. هذه إزاحة منطقية: يتم إدخال أصفار في البتات الفارغة بغض النظر عن إشارة x. تكون النتيجة غير محددة إذا كانت y < 0 أو y >= bitsize.

val of_int : int -> t

تحويل العدد الصحيح المعطى (نوع int) إلى عدد صحيح مستهدف (نوع t)، معامل حجم الكلمة المستهدف.

val of_int_exn : int -> t

تحويل العدد الصحيح المعطى (نوع int) إلى عدد صحيح مستهدف (نوع t). تثير خطأ فادح إذا لم يكن التحويل دقيقًا.

val to_int : t -> int

تحويل العدد الصحيح المستهدف المعطى (نوع t) إلى عدد صحيح (نوع int). يتم فقد البت الأعلى أثناء التحويل.

val of_float : float -> t

تحويل الرقم ذو الفاصلة العائمة المعطى إلى عدد صحيح مستهدف، مع تجاهل الجزء الكسري (التقتير نحو الصفر). تكون نتيجة التحويل غير محددة إذا كان الرقم، بعد التقتير، خارج النطاق [ Targetint.min_int , Targetint.max_int ].

val to_float : t -> float

تحويل العدد الصحيح المستهدف المعطى إلى رقم ذي فاصلة عائمة.

val of_int32 : int32 -> t

تحويل العدد الصحيح ذي 32 بت المعطى (نوع int32) إلى عدد صحيح مستهدف.

val to_int32 : t -> int32

تحويل العدد الصحيح المستهدف المعطى إلى عدد صحيح ذي 32 بت (نوع int32). على منصات 64 بت، يتم أخذ العدد الصحيح الأصلي ذي 64 بت معامل 2^32، أي يتم فقد أعلى 32 بت. على منصات 32 بت، يكون التحويل دقيقًا.

val of_int64 : int64 -> t

تحويل العدد الصحيح ذي 64 بت المعطى (نوع int64) إلى عدد صحيح مستهدف.

val to_int64 : t -> int64

تحويل العدد الصحيح المستهدف المعطى إلى عدد صحيح ذي 64 بت (نوع int64).

val of_string : string -> t

تحويل السلسلة النصية المعطاة إلى عدد صحيح مستهدف. تتم قراءة السلسلة النصية بالنظام العشري (افتراضيًا) أو بالنظام الست عشري أو الثماني أو الثنائي إذا بدأت السلسلة النصية بـ 0x أو 0o أو 0b على التوالي. تثير Failure "int_of_string" إذا لم تكن السلسلة النصية المعطاة تمثيلًا صالحًا لعدد صحيح، أو إذا تجاوز العدد الصحيح الممثل نطاق الأعداد الصحيحة التي يمكن تمثيلها في النوع nativeint.

val to_string : t -> string

إرجاع التمثيل النصي للوسيط، بالنظام العشري.

val compare : t -> t -> int

وظيفة المقارنة للأعداد الصحيحة المستهدفة، مع نفس مواصفات compare. بالإضافة إلى النوع t، تسمح وظيفة compare هذه بتمرير الوحدة Targetint كوسيط لوظائف Set.Make و Map.Make.

val unsigned_compare : t -> t -> int

نفس Targetint.compare، باستثناء أن الوسائط تُفسر كأعداد صحيحة غير موقعة.

val equal : t -> t -> bool

وظيفة المساواة للأعداد الصحيحة المستهدفة.

type repr =

| Int64 of int64

val repr : t -> repr
