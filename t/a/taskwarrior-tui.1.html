الاسم

taskwarrior-tui — واجهة مستخدم طرفية لـ taskwarrior (https://github.com/kdheepak/taskwarrior-tui)

الملخص

taskwarrior-tui

taskwarrior-tui هي واجهة مستخدم طرفية لـ taskwarrior.

أمثلة

taskwarrior-tui
يبدأ واجهة مستخدم طرفية لـ taskwarrior.
اسم مستعار tt=taskwarrior-tui
أضف ما سبق إلى ملفات الإعداد الخاصة بك لاستخدام tt لبدء taskwarrior-tui.

اختصارات المفاتيح

اختصارات المفاتيح:

Esc
إنهاء الإجراء الحالي
]
العرض التالي - انتقل إلى العرض التالي
[
العرض السابق - انتقل إلى العرض السابق

اختصارات المفاتيح لتقرير المهام:

/
task {string} - تصفية تقرير المهام
a
task add {string} - إضافة مهمة جديدة
d
task {selected} done - تمييز المهمة كمكتملة
e
task {selected} edit - فتح المهمة المحددة في المحرر
j
{selected+=1} - الانتقال للأسفل في تقرير المهام
k
{selected-=1} - الانتقال للأعلى في تقرير المهام
J
{selected+=pageheight} - الانتقال لصفحة لأسفل في تقرير المهام
K
{selected-=pageheight} - الانتقال لصفحة للأعلى في تقرير المهام
g
{selected=first} - الانتقال إلى الأعلى
G
{selected=last} - الانتقال إلى الأسفل
l
task log {string} - تسجيل مهمة جديدة
m
task {selected} modify {string} - تعديل المهمة المحددة
q
exit - الخروج
s
task {selected} start/stop - تبديل البدء والإيقاف
t
task {selected} +{tag}/-{tag} - تبديل {uda.taskwarrior-tui.quick-tag.name} (الافتراضي: next)
u
task undo - تراجع
v
{toggle mark on selected} - تبديل علامة التحديد على العنصر المحدد
V
{toggle marks on all tasks} - تبديل علامات التحديد على جميع المهام في تقرير التصفية الحالي
x
task delete {selected} - حذف
z
toggle task info - تبديل عرض معلومات المهمة
A
task {selected} annotate {string} - إضافة تعليق توضيحي للمهمة الحالية
Ctrl-e
scroll down task details - تمرير تفاصيل المهمة لأسفل سطر واحد
Ctrl-y
scroll up task details - تمرير تفاصيل المهمة لأعلى سطر واحد
!
{string} - أمر صدفة مخصص
1-9
{string} - تشغيل اختصارات محددة من قبل المستخدم
:
{task id} - الانتقال إلى معرف المهمة
c
context switcher menu - فتح قائمة مبدل السياق
?
help - قائمة المساعدة

اختصارات المفاتيح لنافذة التصفية / موجه الأوامر:

Ctrl + f | Right
move forward - التحرك للأمام حرف واحد
Ctrl + b | Left
move backward - التحرك للخلف حرف واحد
Ctrl + h | Backspace
backspace - حذف حرف واحد للخلف
Ctrl + d | Delete
delete - حذف حرف واحد للأمام
Ctrl + a | Home
home - الانتقال إلى بداية السطر
Ctrl + e | End
end - الانتقال إلى نهاية السطر
Ctrl + k
delete to end - حذف إلى نهاية السطر
Ctrl + u
delete to beginning - حذف إلى بداية السطر
Ctrl + w
delete previous word - حذف الكلمة السابقة
Alt + d
delete next word - حذف الكلمة التالية
Alt + b
move to previous word - الانتقال إلى الكلمة السابقة
Alt + f
move to next word - الانتقال إلى الكلمة التالية
Alt + t
transpose words - تبديل الكلمات
Up
scroll history - الانتقال للخلف في السجل مطابقًا من بداية السطر إلى المؤشر
Down
scroll history - الانتقال للأمام في السجل مطابقًا من بداية السطر إلى المؤشر
TAB | Ctrl + n
tab complete - فتح إكمال علامة التبويب وتحديد العنصر الأول أو التدوير إلى العنصر التالي
BACKTAB | Ctrl + p
tab complete - التدوير إلى العنصر السابق

اختصارات المفاتيح لمبدل السياق:

k
