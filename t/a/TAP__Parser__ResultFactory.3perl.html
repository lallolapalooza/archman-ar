TAP::Parser::ResultFactory(3perl) دليل مبرمجي بيرل TAP::Parser::ResultFactory(3perl)

الاسم

TAP::Parser::ResultFactory - مصنع لإنشاء كائنات ناتج TAP::Parser

الملخص

use TAP::Parser::ResultFactory;
my $token   = {...};
my $factory = TAP::Parser::ResultFactory->new;
my $result  = $factory->make_result( $token );

الإصدار

الإصدار 3.50

الوصف

هذه فئة مصنع بسيطة تُرجع فئة فرعية من TAP::Parser::Result تمثل الجزء الحالي من بيانات الاختبار من TAP (عادةً سطر واحد). تُستخدم بشكل أساسي بواسطة TAP::Parser::Grammar. ما لم تكن تقوم بإنشاء فئة فرعية، فربما لن تحتاج إلى استخدام هذه الوحدة مباشرة.

الأساليب

أساليب الفئة

"new"

ينشئ فئة مصنع جديدة. ملاحظة: لا تحتاج حاليًا إلى إنشاء مثيل لمصنع لاستخدامه.

"make_result"

تُرجع مثيلاً للفئة المناسبة لرمز الاختبار المُمرر.

my $result = TAP::Parser::ResultFactory->make_result($token);

يمكن أيضًا استدعاؤها كطريقة مثيل.

"class_for"

تأخذ وسيطًا واحدًا: $type. تُرجع الفئة لهذا $type، أو تُصدر خطأ.

"register_type"

تأخذ وسيطين: $type، $class

يتيح لك هذا تجاوز نوع موجود بنوع مخصص خاص بك، أو تسجيل نوع جديد تمامًا، على سبيل المثال:

# إنشاء نوع نتيجة مخصص:
package MyResult;
use strict;
use base 'TAP::Parser::Result';
# تسجيله مع المصنع:
TAP::Parser::ResultFactory->register_type( 'my_type' => __PACKAGE__ );
# استخدامه:
my $r = TAP::Parser::ResultFactory->( { type => 'my_type' } );

يجب بعد ذلك التقاط نوعك المخصص تلقائيًا بواسطة TAP::Parser.

إنشاء فئات فرعية

يرجى الرجوع إلى "SUBCLASSING" في TAP::Parser للحصول على نظرة عامة على إنشاء الفئات الفرعية.

هناك بعض النقاط التي يجب مراعاتها عند إنشاء "ResultFactory" خاص بك:

1.
لا يتم إنشاء مثيل للمصنع نفسه (قد يتغير هذا في المستقبل). هذا يعني أن "_initialize" لا يتم استدعاؤها أبدًا.
2.
لا يتم استدعاء "TAP::Parser::Result->new"، بل يتم إعادة تهيئة $tokens. سيتغير هذا في إصدار مستقبلي!
3.
ستقوم الفئات الفرعية لـ TAP::Parser::Result بتسجيل نفسها مباشرة مع TAP::Parser::ResultFactory: 
package MyFooResult;
TAP::Parser::ResultFactory->register_type( foo => __PACKAGE__ );

بالطبع، يعود الأمر إليك فيما إذا كنت ستتجاهلها أم لا.

مثال

package MyResultFactory;
use strict;
use MyResult;
use base 'TAP::Parser::ResultFactory';
# فرض أن تكون جميع النتائج 'MyResult'
sub class_for {
  return 'MyResult';
}
1;
