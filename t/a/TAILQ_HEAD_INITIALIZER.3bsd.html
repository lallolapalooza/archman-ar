DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element

The macro SLIST_REMOVE removes the element elm from the list.

The macro SLIST_SWAP swaps the contents of the two lists referenced by head1 and head2.

الماكرو SLIST_NEXT يعيد العنصر التالي في القائمة.

الماكرو SLIST_REMOVE_AFTER يزيل العنصر الذي يلي elm من القائمة. على عكس SLIST_REMOVE، لا يجتاز هذا الماكرو القائمة بأكملها.

الماكرو SLIST_REMOVE_HEAD يزيل العنصر elm من رأس القائمة. للحصول على أقصى قدر من الكفاءة، يجب على العناصر التي يتم إزالتها من رأس القائمة استخدام هذا الماكرو صراحةً بدلاً من الماكرو العام SLIST_REMOVE.

الماكرو SLIST_REMOVE يزيل العنصر elm من القائمة. يجب تجنب استخدام هذا الماكرو لأنه يجتاز القائمة بأكملها. يجب استخدام قائمة مرتبطة مزدوجة إذا كان هذا الماكرو مطلوبًا في مسارات التعليمات البرمجية ذات الاستخدام العالي أو للعمل على قوائم طويلة.

الماكرو SLIST_SWAP يتبادل محتويات head1 و head2.

مثال على قائمة أحادية الارتباط

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* رأس قائمة أحادية الارتباط. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* قائمة أحادية الارتباط. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* تهيئة القائمة. */

n1 = malloc(sizeof(struct entry));	/* الإدراج في الرأس. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* الإدراج بعد. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* الحذف. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* الحذف من الرأس. */
free(n3);
					/* اجتياز أمامي. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* اجتياز أمامي آمن. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* حذف القائمة. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

طوابير الذيل أحادية الارتباط

يتم ترؤس طابور الذيل أحادي الارتباط بواسطة بنية يتم تعريفها بواسطة الماكرو STAILQ_HEAD. تحتوي هذه البنية على زوج من المؤشرات، أحدهما يشير إلى العنصر الأول في طابور الذيل والآخر إلى العنصر الأخير في طابور الذيل. ترتبط العناصر بشكل فردي لتقليل المساحة المطلوبة وتكاليف معالجة المؤشرات على حساب تكلفة إزالة O(n) للعناصر العشوائية. يمكن إضافة عناصر جديدة إلى طابور الذيل بعد عنصر موجود، أو في رأس طابور الذيل، أو في نهاية طابور الذيل. يتم الإعلان عن بنية STAILQ_HEAD على النحو التالي:

STAILQ_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم البنية التي سيتم تعريفها، و TYPE هو نوع العناصر التي سيتم ربطها في طابور الذيل. يمكن لاحقًا الإعلان عن مؤشر إلى رأس طابور الذيل على النحو التالي:

struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

الماكرو STAILQ_HEAD_INITIALIZER يقيم إلى مادة تهيئة لطابور الذيل head.

الماكرو STAILQ_CONCAT يربط طابور الذيل الذي ترأسه head2 بنهاية الطابور الذي ترأسه head1، ويزيل جميع الإدخالات من الطابور السابق.

الماكرو STAILQ_EMPTY يقيم إلى صحيح إذا لم تكن هناك عناصر في طابور الذيل.

الماكرو STAILQ_ENTRY يعلن عن بنية تربط العناصر في طابور الذيل.

الماكرو STAILQ_FIRST يعيد العنصر الأول في طابور الذيل أو NULL إذا كان طابور الذيل فارغًا.

الماكرو STAILQ_FOREACH يجتاز طابور الذيل المشار إليه بواسطة head في الاتجاه الأمامي، ويخصص كل عنصر بدوره للمتغير var.

الماكرو STAILQ_FOREACH_FROM يتصرف بشكل متطابق مع STAILQ_FOREACH عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر STAILQ تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في STAILQ المشار إليه بواسطة head.

الماكرو STAILQ_FOREACH_SAFE يجتاز طابور الذيل المشار إليه بواسطة head في الاتجاه الأمامي، ويخصص كل عنصر بدوره للمتغير var. ومع ذلك، على عكس STAILQ_FOREACH() هنا يُسمح بإزالة var وكذلك تحريره من داخل الحلقة بأمان دون التأثير على الاجتياز.

الماكرو STAILQ_FOREACH_FROM_SAFE يتصرف بشكل متطابق مع STAILQ_FOREACH_SAFE عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر STAILQ تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في STAILQ المشار إليه بواسطة head.

الماكرو STAILQ_INIT يهيئ طابور الذيل المشار إليه بواسطة head.

الماكرو STAILQ_INSERT_HEAD يُدرج العنصر الجديد elm في رأس طابور الذيل.

الماكرو STAILQ_INSERT_TAIL يُدرج العنصر الجديد elm في نهاية طابور الذيل.

الماكرو STAILQ_INSERT_AFTER يُدرج العنصر الجديد elm بعد العنصر listelm.

الماكرو STAILQ_LAST يعيد العنصر الأخير في طابور الذيل. إذا كان طابور الذيل فارغًا، فإن القيمة المعادة هي NULL.

الماكرو STAILQ_NEXT يعيد العنصر التالي في طابور الذيل، أو NULL إذا كان هذا العنصر هو الأخير.

الماكرو STAILQ_REMOVE_AFTER يزيل العنصر الذي يلي elm من طابور الذيل. على عكس STAILQ_REMOVE، لا يجتاز هذا الماكرو طابور الذيل بأكمله.

الماكرو STAILQ_REMOVE_HEAD يزيل العنصر الموجود في رأس طابور الذيل. للحصول على أقصى قدر من الكفاءة، يجب على العناصر التي يتم إزالتها من رأس طابور الذيل استخدام هذا الماكرو صراحةً بدلاً من الماكرو العام STAILQ_REMOVE.

الماكرو STAILQ_REMOVE يزيل العنصر elm من طابور الذيل. يجب تجنب استخدام هذا الماكرو لأنه يجتاز القائمة بأكملها. يجب استخدام طابور ذيل مزدوج الارتباط إذا كان هذا الماكرو مطلوبًا في مسارات التعليمات البرمجية ذات الاستخدام العالي أو للعمل على طوابير ذيل طويلة.

الماكرو STAILQ_SWAP يتبادل محتويات head1 و head2.

مثال على طابور ذيل أحادي الارتباط

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* رأس طابور ذيل أحادي الارتباط. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* طابور الذيل. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* تهيئة الطابور. */

n1 = malloc(sizeof(struct entry));	/* الإدراج في الرأس. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* الإدراج في الذيل. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* الإدراج بعد. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* الحذف. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* الحذف من الرأس. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* اجتياز أمامي. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* اجتياز أمامي آمن. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* حذف الطابور. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* حذف أسرع للطابور. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

القوائم

يتم ترؤس القائمة بواسطة بنية يتم تعريفها بواسطة الماكرو LIST_HEAD. تحتوي هذه البنية على مؤشر واحد إلى العنصر الأول في القائمة. ترتبط العناصر بشكل مزدوج بحيث يمكن إزالة عنصر عشوائي دون اجتياز القائمة. يمكن إضافة عناصر جديدة إلى القائمة بعد عنصر موجود، أو قبل عنصر موجود، أو في رأس القائمة. يتم الإعلان عن بنية LIST_HEAD على النحو التالي:

LIST_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم البنية التي سيتم تعريفها، و TYPE هو نوع العناصر التي سيتم ربطها في القائمة. يمكن لاحقًا الإعلان عن مؤشر إلى رأس القائمة على النحو التالي:

struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

الماكرو LIST_HEAD_INITIALIZER يقيم إلى مادة تهيئة للقائمة head.

الماكرو LIST_CONCAT يربط القائمة التي ترأسه head2 بنهاية القائمة التي ترأسه head1، ويزيل جميع الإدخالات من القائمة الأولى. يجب تجنب استخدام هذا الماكرو لأنه يجتاز القائمة head1 بأكملها. يجب استخدام طابور ذيل إذا كان هذا الماكرو مطلوبًا في مسارات التعليمات البرمجية ذات الاستخدام العالي أو للعمل على قوائم طويلة.

الماكرو LIST_EMPTY يقيم إلى صحيح إذا لم تكن هناك عناصر في القائمة.

الماكرو LIST_ENTRY يعلن عن بنية تربط العناصر في القائمة.

الماكرو LIST_FIRST يعيد العنصر الأول في القائمة أو NULL إذا كانت القائمة فارغة.

الماكرو LIST_FOREACH يجتاز القائمة المشار إليها بواسطة

	np->do_stuff();
	...
	LIST_REMOVE(np, entries);

طوابير الذيل

طابور الذيل يرأسه هيكل معرف بواسطة الماكرو TAILQ_HEAD. يحتوي هذا الهيكل على زوج من المؤشرات، أحدهما إلى العنصر الأول في طابور الذيل والآخر إلى العنصر الأخير في طابور الذيل. يتم ربط العناصر بشكل مزدوج بحيث يمكن إزالة عنصر عشوائي دون المرور عبر طابور الذيل. يمكن إضافة عناصر جديدة إلى طابور الذيل بعد عنصر موجود، قبل عنصر موجود، في رأس طابور الذيل، أو في نهاية طابور الذيل. يتم تعريف هيكل TAILQ_HEAD كما يلي:

TAILQ_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم الهيكل المراد تعريفه، و TYPE هو نوع العناصر التي سيتم ربطها في طابور الذيل. يمكن لاحقًا تعريف مؤشر إلى رأس طابور الذيل كالتالي:

struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

الماكرو TAILQ_HEAD_INITIALIZER يقيم إلى مهيئ لطابور الذيل head.

الماكرو TAILQ_CONCAT يربط طابور الذيل الذي يرأسه head2 بنهاية الطابور الذي يرأسه head1، مما يزيل جميع الإدخالات من الأول.

الماكرو TAILQ_EMPTY يقيم إلى صحيح إذا لم تكن هناك عناصر في طابور الذيل.

الماكرو TAILQ_ENTRY يعرف هيكلًا يربط العناصر في طابور الذيل.

الماكرو TAILQ_FIRST يعيد العنصر الأول في طابور الذيل أو NULL إذا كان طابور الذيل فارغًا.

الماكرو TAILQ_FOREACH يتجول في طابور الذيل المشار إليه بواسطة head في الاتجاه الأمامي، مع تعيين كل عنصر بدوره إلى var. يتم تعيين var إلى NULL إذا اكتملت الحلقة بشكل طبيعي، أو إذا لم تكن هناك عناصر.

الماكرو TAILQ_FOREACH_FROM يتصرف بشكل مطابق لـ TAILQ_FOREACH عندما يكون var يساوي NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في TAILQ المشار إليه بواسطة head.

الماكرو TAILQ_FOREACH_REVERSE يتجول في طابور الذيل المشار إليه بواسطة head في الاتجاه العكسي، مع تعيين كل عنصر بدوره إلى var.

الماكرو TAILQ_FOREACH_REVERSE_FROM يتصرف بشكل مطابق لـ TAILQ_FOREACH_REVERSE عندما يكون var يساوي NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة العكسية عند var بدلاً من العنصر الأخير في TAILQ المشار إليه بواسطة head.

الماكرو TAILQ_FOREACH_SAFE و TAILQ_FOREACH_REVERSE_SAFE يتجولان في القائمة المشار إليها بواسطة head في الاتجاه الأمامي أو العكسي على التوالي، مع تعيين كل عنصر بدوره إلى var. ومع ذلك، على عكس نظائرهما غير الآمنة، تجعل TAILQ_FOREACH و TAILQ_FOREACH_REVERSE من الممكن إزالة var وكذلك تحريره من داخل الحلقة بأمان دون التأثير على عملية التجول.

الماكرو TAILQ_FOREACH_FROM_SAFE يتصرف بشكل مطابق لـ TAILQ_FOREACH_SAFE عندما يكون var يساوي NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في TAILQ المشار إليه بواسطة head.

الماكرو TAILQ_FOREACH_REVERSE_FROM_SAFE يتصرف بشكل مطابق لـ TAILQ_FOREACH_REVERSE_SAFE عندما يكون var يساوي NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة العكسية عند var بدلاً من العنصر الأخير في TAILQ المشار إليه بواسطة head.

الماكرو TAILQ_INIT يهيئ طابور الذيل المشار إليه بواسطة head.

الماكرو TAILQ_INSERT_HEAD يدرج العنصر الجديد elm في رأس طابور الذيل.

الماكرو TAILQ_INSERT_TAIL يدرج العنصر الجديد elm في نهاية طابور الذيل.

الماكرو TAILQ_INSERT_AFTER يدرج العنصر الجديد elm بعد العنصر listelm.

الماكرو TAILQ_INSERT_BEFORE يدرج العنصر الجديد elm قبل العنصر listelm.

الماكرو TAILQ_LAST يعيد العنصر الأخير في طابور الذيل. إذا كان طابور الذيل فارغًا، تكون القيمة المعادة NULL.

الماكرو TAILQ_NEXT يعيد العنصر التالي في طابور الذيل، أو NULL إذا كان هذا العنصر هو الأخير.

الماكرو TAILQ_PREV يعيد العنصر السابق في طابور الذيل، أو NULL إذا كان هذا العنصر هو الأول.

الماكرو TAILQ_REMOVE يزيل العنصر elm من طابور الذيل.
