TAP::Parser::IteratorFactory(3perl) دليل برمجة Perl TAP::Parser::IteratorFactory(3perl)

الاسم

TAP::Parser::IteratorFactory - يحدد أي كائنات `SourceHandler` يجب استخدامها لمصدر معين

الإصدار

الإصدار 3.50

الملخص

use TAP::Parser::IteratorFactory;
my $factory = TAP::Parser::IteratorFactory->new({ %config });
my $iterator  = $factory->make_iterator( $filename );

الوصف

هذه فئة مصنع تقوم بأخذ `TAP::Parser::Source` وتشغيله عبر جميع `TAP::Parser::SourceHandlers` المسجلة لمعرفة أي منها يجب أن يتعامل مع المصدر.

إذا كنت مؤلف إضافة، فستكون مهتمًا بكيفية "تسجيل المعالج" (`register_handler`)، وكيف يعمل "اكتشاف المصدر" (`detect_source`).

الطرق

طرق الفئة

"new"

ينشئ فئة مصنع جديدة:

my $sf = TAP::Parser::IteratorFactory->new( $config );

$config اختياري. إذا تم تقديمه، فإنه يضبط "config" ويستدعي "load_handlers".

"register_handler"

يسجل `TAP::Parser::SourceHandler` جديدًا مع هذا المصنع.

__PACKAGE__->register_handler( $handler_class );

"handlers"

قائمة المعالجات التي تم تسجيلها.

طرق النسخة

"config"

my $cfg = $sf->config;
$sf->config({ Perl => { %config } });

جلب/تعيين سلسلة لمعلمات المصدر المتاحة للمعالجات. هذه عبارة عن هاش مفتاحها هو اسم الفئة وقيمتها تحتوي على التكوين الذي سيتم تمريره إلى المعالجات أثناء الاكتشاف والإنشاء. قد تكون أسماء الفئات مؤهلة بالكامل أو مختصرة، على سبيل المثال:

# هذه مكافئة
$sf->config({ 'TAP::Parser::SourceHandler::Perl' => { %config } });
$sf->config({ 'Perl' => { %config } });

"load_handlers"

$sf->load_handlers;

يقوم بتحميل فئات المعالج المعرفة في "config". على سبيل المثال، بالنظر إلى تكوين:

$sf->config({
  MySourceHandler => { some => 'config' },
});

"load_handlers" سيحاول تحميل فئة "MySourceHandler" عن طريق البحث في @INC عنها بهذا الترتيب:

TAP::Parser::SourceHandler::MySourceHandler
MySourceHandler

يستخدم "croak" عند حدوث خطأ.

"make_iterator"

my $iterator = $src_factory->make_iterator( $source );

بالنظر إلى `TAP::Parser::Source`، يجد `TAP::Parser::SourceHandler` الأنسب للاستخدام لإنشاء `TAP::Parser::Iterator` (انظر "detect_source"). يموت عند حدوث خطأ.

"detect_source"

بالنظر إلى `TAP::Parser::Source`، يكتشف نوع المصدر ويعيد واحدًا `TAP::Parser::SourceHandler` (الأكثر ثقة). يموت عند حدوث خطأ.

خوارزمية الكشف تعمل شيئًا كهذا:

for (@registered_handlers) {
  # نسألهم عن مدى ثقتهم في التعامل مع هذا المصدر
  $confidence{$handler} = $handler->can_handle( $source )
}
# نختار المعالج الأكثر ثقة

يتم التعامل مع حالات التعادل باختيار المعالج الأول.

الوراثة الفرعية

يرجى الاطلاع على "SUBCLASSING" في TAP::Parser للحصول على نظرة عامة على الوراثة الفرعية.

مثال

إذا قمنا بالأمور بشكل صحيح، فمن المحتمل أن ترغب في كتابة مصدر جديد، بدلاً من إنشاء فئة فرعية له (انظر TAP::Parser::SourceHandler لذلك).

ولكن في حال وجدت الحاجة إلى ذلك...

package MyIteratorFactory;
use strict;
use base 'TAP::Parser::IteratorFactory';
# تجاوز خوارزمية اكتشاف المصدر
sub detect_source {
  my ($self, $raw_source_ref, $meta) = @_;
  # قم بعمل تحري، باستخدام $meta وأي شيء آخر...
}
1;
