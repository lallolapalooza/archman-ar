الوصف

تحدد هذه الماكروات وتعمل مع قوائم الذيل ذات الارتباط المزدوج.

في تعريفات الماكرو، TYPE هو اسم هيكل معرف من قبل المستخدم، والذي يجب أن يحتوي على حقل من النوع TAILQ_ENTRY، يسمى NAME. الوسيط HEADNAME هو اسم هيكل معرف من قبل المستخدم يجب تعريفه باستخدام الماكرو TAILQ_HEAD().

الإنشاء

تترأس قائمة الذيل هيكل تم تعريفه بواسطة الماكرو TAILQ_HEAD(). يحتوي هذا الهيكل على زوج من المؤشرات، أحدهما يشير إلى العنصر الأول في القائمة والآخر يشير إلى العنصر الأخير في القائمة. العناصر مرتبطة بشكل مزدوج بحيث يمكن إزالة عنصر تعسفي دون الحاجة إلى اجتياز القائمة. يمكن إضافة عناصر جديدة إلى القائمة بعد عنصر موجود، أو قبل عنصر موجود، في بداية القائمة، أو في نهاية القائمة. يتم تعريف هيكل TAILQ_HEAD على النحو التالي:


TAILQ_HEAD(HEADNAME, TYPE) head;

حيث struct HEADNAME هو الهيكل المراد تعريفه، و struct TYPE هو نوع العناصر التي سيتم ربطها في القائمة. يمكن لاحقًا تعريف مؤشر إلى رأس القائمة على النحو التالي:


struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

يعرّف TAILQ_ENTRY() هيكلًا يربط العناصر في القائمة.

TAILQ_HEAD_INITIALIZER() يعطي قيمة تهيئة للقائمة head.

يقوم TAILQ_INIT() بتهيئة القائمة المشار إليها بواسطة

TAILQ_EMPTY() يعطي قيمة صحيحة إذا لم تكن هناك عناصر في القائمة. head.

الإدراج

يقوم TAILQ_INSERT_HEAD() بإدراج العنصر الجديد elm في بداية القائمة.

يقوم TAILQ_INSERT_TAIL() بإدراج العنصر الجديد elm في نهاية القائمة.

يقوم TAILQ_INSERT_BEFORE() بإدراج العنصر الجديد elm قبل العنصر listelm.

يقوم TAILQ_INSERT_AFTER() بإدراج العنصر الجديد elm بعد العنصر listelm.

الاجتياز

يعيد TAILQ_FIRST() العنصر الأول في القائمة، أو NULL إذا كانت القائمة فارغة.

يعيد TAILQ_LAST() العنصر الأخير في القائمة. إذا كانت القائمة فارغة، فإن القيمة المعادة هي NULL.

يعيد TAILQ_PREV() العنصر السابق في القائمة، أو NULL إذا كان هذا العنصر هو الأول.

يعيد TAILQ_NEXT() العنصر التالي في القائمة، أو NULL إذا كان هذا العنصر هو الأخير.

يقوم TAILQ_FOREACH() باجتياز القائمة المشار إليها بواسطة head في الاتجاه الأمامي، مع تعيين كل عنصر بدوره إلى var. يتم تعيين var إلى NULL إذا اكتملت الحلقة بشكل طبيعي، أو إذا لم تكن هناك عناصر.

يقوم TAILQ_FOREACH_REVERSE() باجتياز القائمة المشار إليها بواسطة head في الاتجاه العكسي، مع تعيين كل عنصر بدوره إلى var.

الإزالة

يقوم TAILQ_REMOVE() بإزالة العنصر elm من القائمة.

ميزات أخرى

يقوم TAILQ_CONCAT() بضم القائمة التي يترأسها head2 إلى نهاية القائمة التي يترأسها head1، مع إزالة جميع الإدخالات من القائمة الأولى.

قيمة الإرجاع

يعيد TAILQ_EMPTY() قيمة غير صفرية إذا كانت القائمة فارغة، وصفر إذا كانت القائمة تحتوي على إدخال واحد على الأقل.

يعيد TAILQ_FIRST() و TAILQ_LAST() و TAILQ_PREV() و TAILQ_NEXT() مؤشرًا إلى هيكل TYPE الأول أو الأخير أو السابق أو التالي، على التوالي.

TAILQ_HEAD_INITIALIZER() يعيد قيمة تهيئة يمكن تعيينها إلى رأس القائمة head.

المعايير

BSD.

التاريخ

4.4BSD.

تحذيرات

لا تسمح TAILQ_FOREACH() و TAILQ_FOREACH_REVERSE() بإزالة أو تحرير var داخل الحلقة، حيث قد يتعارض ذلك مع الاجتياز. TAILQ_FOREACH_SAFE() و TAILQ_FOREACH_REVERSE_SAFE()، الموجودة في BSDs ولكنها غير موجودة في glibc، تعالج هذا القيد عن طريق السماح بإزالة var بأمان من القائمة وتحريرها من داخل الحلقة دون التأثير على الاجتياز.

أمثلة

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Tail queue */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tail queue head */
    int i;
    TAILQ_INIT(&head);                      /* Initialize the queue */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insert at the tail */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insert before */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Deletion */
    free(n2);
                                            /* Forward traversal */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Reverse traversal */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */

EXAMPLE

The following code snippet demonstrates how to free all elements in a TAILQ:

    struct my_list_head head;
    struct my_list_entry *n1, *n2;

    TAILQ_INIT(&head);
    /* ... populate the queue ... */

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);

TAILQ

TAILQ

TAILQ is a data structure used for managing a queue of elements, typically in a linked list format.

The functions provided in this section allow for the insertion, deletion, and management of elements in a queue.

The functions are implemented in C and are part of the Linux man-pages documentation.
