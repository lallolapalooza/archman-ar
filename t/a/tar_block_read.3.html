tar_block_read(3)

الحزمة: libtar

التراخيص: BSD

tar_block_read(3) استدعاءات مكتبة C tar_block_read(3)

الاسم

tar_block_read, tar_block_write - وحدات ماكرو لاستدعاء وظائف القراءة والكتابة لنوع أرشيف tar الصحيح

الملخص

#include <libtar.h>

int tar_block_read(TAR *t, char *buf);

int tar_block_write(TAR *t, char *buf);

الإصدار

توثق صفحة الدليل هذه الإصدار 1.2 من libtar.

الوصف

تقوم وحدات الماكرو tar_block_read() و tar_block_write() باستدعاء وظائف القراءة والكتابة لنوع أرشيف tar المرتبط بمقبض TAR t. يتم تعيين هذا النوع عند إنشاء مقبض TAR باستخدام tar_open().

قيمة الإرجاع

تعيد وحدات الماكرو هذه نفس قيم وظائف القراءة والكتابة المقابلة.

انظر أيضًا

read(2), write(2), tar_open(3)
