الاسم

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - تنفيذ طابور ذيل مرتبط مزدوج

المكتبة

مكتبة C القياسية (libc, -lc)

الوصف

تعرف هذه الماكرو وتعمل على طوابير ذيل مرتبطة مزدوجة.

في تعريفات الماكرو، TYPE هو اسم هيكل محدد من قبل المستخدم، يجب أن يحتوي على حقل من النوع TAILQ_ENTRY، باسم NAME. الوسيط HEADNAME هو اسم هيكل محدد من قبل المستخدم يجب تعريفه باستخدام الماكرو TAILQ_HEAD().

الإنشاء

يتم استهلال طابور الذيل بهيكل تم تعريفه بواسطة الماكرو TAILQ_HEAD(). يحتوي هذا الهيكل على زوج من المؤشرات، أحدهما يشير إلى العنصر الأول في الطابور والآخر إلى العنصر الأخير في الطابور. العناصر مرتبطة مزدوجاً بحيث يمكن إزالة عنصر عشوائي دون اجتياز الطابور. يمكن إضافة عناصر جديدة إلى الطابور بعد عنصر موجود، قبل عنصر موجود، في رأس الطابور، أو في نهاية الطابور. يتم تعريف هيكل TAILQ_HEAD كما يلي:


TAILQ_HEAD(HEADNAME, TYPE) head;

حيث struct HEADNAME هو الهيكل المراد تعريفه، و struct TYPE هو نوع العناصر المراد ربطها في الطابور. يمكن لاحقًا الإعلان عن مؤشر لرأس الطابور كما يلي:


struct HEADNAME *headp;

(الاسمين head و headp اختياريان من قبل المستخدم.)

يعرف الماكرو TAILQ_ENTRY() هيكلاً يربط العناصر في الطابور.

يقيم الماكرو TAILQ_HEAD_INITIALIZER() بقيمة تهيئة للطابور head.

يقوم الماكرو TAILQ_INIT() بتهيئة الطابور المشار إليه بواسطة

يقيم الماكرو TAILQ_EMPTY() بقيمة صحيحة إذا لم تكن هناك عناصر في الطابور. head.

الإدراج

يقوم الماكرو TAILQ_INSERT_HEAD() بإدراج العنصر الجديد elm في رأس الطابور.

يقوم الماكرو TAILQ_INSERT_TAIL() بإدراج العنصر الجديد elm في نهاية الطابور.

يقوم الماكرو TAILQ_INSERT_BEFORE() بإدراج العنصر الجديد elm قبل العنصر listelm.

يقوم الماكرو TAILQ_INSERT_AFTER() بإدراج العنصر الجديد elm بعد العنصر listelm.

الاجتياز

يعيد الماكرو TAILQ_FIRST() العنصر الأول في الطابور، أو NULL إذا كان الطابور فارغًا.

يعيد الماكرو TAILQ_LAST() العنصر الأخير في الطابور. إذا كان الطابور فارغًا، تكون القيمة المعادة NULL.

يعيد الماكرو TAILQ_PREV() العنصر السابق في الطابور، أو NULL إذا كان هذا العنصر هو الأول.

يعيد الماكرو TAILQ_NEXT() العنصر التالي في الطابور، أو NULL إذا كان هذا العنصر هو الأخير.

يجتاز الماكرو TAILQ_FOREACH() الطابور المشار إليه بواسطة head في الاتجاه الأمامي، مع تعيين كل عنصر بدوره إلى var. يتم تعيين var إلى NULL إذا اكتملت الحلقة بشكل طبيعي، أو إذا لم تكن هناك عناصر.

يجتاز الماكرو TAILQ_FOREACH_REVERSE() الطابور المشار إليه بواسطة head في الاتجاه العكسي، مع تعيين كل عنصر بدوره إلى var.

الإزالة

يقوم الماكرو TAILQ_REMOVE() بإزالة العنصر elm من الطابور.

ميزات أخرى

يقوم الماكرو TAILQ_CONCAT() بدمج الطابور الذي يبدأ بـ head2 في نهاية الطابور الذي يبدأ بـ head1، مع إزالة جميع العناصر من الأول.

قيمة الإرجاع

يعيد الماكرو TAILQ_EMPTY() قيمة غير صفرية إذا كان الطابور فارغًا، وصفر إذا كان الطابور يحتوي على إدخال واحد على الأقل.

يعيد الماكرو TAILQ_FIRST() و TAILQ_LAST() و TAILQ_PREV() و TAILQ_NEXT() مؤشرًا إلى هيكل TYPE الأول أو الأخير أو السابق أو التالي، على التوالي.

يعيد الماكرو TAILQ_HEAD_INITIALIZER() قيمة تهيئة يمكن تعيينها إلى الطابور head.

المعايير

BSD.

التاريخ

4.4BSD.

تحذيرات

لا تسمح الماكرو TAILQ_FOREACH() و TAILQ_FOREACH_REVERSE() بإزالة أو تحرير var داخل الحلقة، لأن ذلك سيتداخل مع الاجتياز. الماكرو TAILQ_FOREACH_SAFE() و TAILQ_FOREACH_REVERSE_SAFE()، الموجودة في BSD ولكنها غير موجودة في glibc، تعالج هذا القيد عن طريق السماح بإزالة var بأمان من القائمة وتحريرها من داخل الحلقة دون التأثير على الاجتياز.

أمثلة

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Tail queue */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tail queue head */
    int i;
    TAILQ_INIT(&head);                      /* Initialize the queue */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insert at the tail */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insert before */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Deletion */
    free(n2);
                                            /* Forward traversal */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Reverse traversal */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n
