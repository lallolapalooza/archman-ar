DESCRIPTION

These macros define and operate on four types of data structures which can be used in both C and C++ source code:

  1. Lists
  2. Singly-linked lists
  3. Singly-linked tail queues
  4. Tail queues
All four structures support the following functionality:
  1. Insertion of a new entry at the head of the list.
  2. Insertion of a new entry after any element in the list.
  3. O(1) removal of an entry from the head of the list.
  4. Forward traversal through the list.
  5. Swapping the contents of two lists.

Singly-linked lists are the simplest of the four data structures and support only the above functionality. Singly-linked lists are ideal for applications with large datasets and few or no removals, or for implementing a LIFO queue. Singly-linked lists add the following functionality:

  1. O(n) removal of any entry in the list.
  2. O(n) concatenation of two lists.

Singly-linked tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. O(n) removal of any entry in the list.
  3. They may be concatenated.
However:
  1. All list insertions must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

Singly-linked tail queues are ideal for applications with large datasets and few or no removals, or for implementing a FIFO queue.

All doubly linked types of data structures (lists and tail queues) additionally allow:

  1. Insertion of a new entry before any element in the list.
  2. O(1) removal of any entry in the list.
However:
  1. Each element requires two pointers rather than one.
  2. Code size and execution time of operations (except for removal) is about twice that of the singly-linked data-structures.

Linked lists are the simplest of the doubly linked data structures. They add the following functionality over the above:

  1. O(n) concatenation of two lists.
  2. They may be traversed backwards.
However:
  1. To traverse backwards, an entry to begin the traversal and the list in which it is contained must be specified.

Tail queues add the following functionality:

  1. Entries can be added at the end of a list.
  2. They may be traversed backwards, from tail to head.
  3. They may be concatenated.
However:
  1. All list insertions and removals must specify the head of the list.
  2. Each head entry requires two pointers rather than one.
  3. Code size is about 15% greater and operations run about 20% slower than singly-linked lists.

In the macro definitions, TYPE is the name of a user defined structure. The structure must contain a field called NAME which is of type SLIST_ENTRY, STAILQ_ENTRY, LIST_ENTRY, or TAILQ_ENTRY. In the macro definitions, CLASSTYPE is the name of a user defined class. The class must contain a field called NAME which is of type SLIST_CLASS_ENTRY, STAILQ_CLASS_ENTRY, LIST_CLASS_ENTRY, or TAILQ_CLASS_ENTRY. The argument HEADNAME is the name of a user defined structure that must be declared using the macros SLIST_HEAD, SLIST_CLASS_HEAD, STAILQ_HEAD, STAILQ_CLASS_HEAD, LIST_HEAD, LIST_CLASS_HEAD, TAILQ_HEAD, or TAILQ_CLASS_HEAD. See the examples below for further explanation of how these macros are used.

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element or at the head of the list. An SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former. Use of this macro should be avoided as it traverses the entirety of the head1 list. A singly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_FROM behaves identically to SLIST_FOREACH when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_FOREACH_FROM_SAFE behaves identically to SLIST_FOREACH_SAFE when var is NULL, else it treats var as a previously found SLIST element and begins the loop at var instead of the first element in the SLIST referenced by head.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_INSERT_AFTER inserts the new element elm after the existing element listelm.

The macro SLIST_REMOVE removes the element elm from the list.

The macro SLIST_SWAP swaps the contents of the lists headed by head1 and head2.

LISTS

Una lista LIST se define mediante la macro LIST_HEAD. Esta estructura contiene un puntero al primer elemento de la lista. Los elementos están vinculados de forma que se puede acceder al siguiente elemento así como al elemento anterior. Se pueden insertar nuevos elementos al principio, al final o en cualquier punto intermedio de la lista. Una estructura LIST_HEAD se declara de la siguiente manera:

LIST_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definir y TYPE es el tipo de los elementos que se enlazan en la lista. Un puntero a la cabeza de la lista se puede declarar más tarde de esta manera:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables por el usuario.)

La macro LIST_HEAD_INITIALIZER evalúa a un inicializador para la lista head.

La macro LIST_CONCAT concatena la lista referida por head2 al final de la lista referida por head1, eliminando todas las entradas de la primera.

La macro LIST_EMPTY evalúa a true si no hay elementos en la lista.

La macro LIST_ENTRY declara una estructura que conecta los elementos de la lista.

La macro LIST_FIRST devuelve el primer elemento de la lista o NULL si la lista está vacía.

La macro LIST_FOREACH recorre la lista referida por head en la dirección forward, asignando cada elemento en orden a var.

El macro LIST_FOREACH_FROM comporta igualmente a LIST_FOREACH cuando var es NULL, sino que trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head.

El macro LIST_FOREACH_SAFE recorre la lista referida por head en la dirección forward, asignando cada elemento en orden a var. Sin embargo, a diferencia de LIST_FOREACH() aquí es permitido remover var así como liberar de forma segura var dentro del bucle sin interferir con la travesía.

El macro LIST_FOREACH_FROM_SAFE comporta igualmente a LIST_FOREACH_SAFE cuando var es NULL, sino que trata var como un elemento previamente encontrado en la lista referida por head y comienza el bucle desde var en lugar del primer elemento de la lista referida por head.

El macro LIST_INIT inicializa la lista referida por head.

El macro LIST_INSERT_HEAD inserta el elemento nuevo elm al frente de la lista.

El macro LIST_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

El macro LIST_INSERT_BEFORE inserta el elemento nuevo elm antes del elemento listelm.

El macro LIST_NEXT devuelve el siguiente elemento en la lista, o NULL si este es el último.

El macro LIST_PREV devuelve el elemento anterior en la lista, o NULL si este es el primero. La lista head debe contener el elemento elm.

El macro LIST_REMOVE elimina el elemento elm de la lista.

El macro LIST_SWAP intercambia el contenido de head1 y head2.

TAIL QUEUES

Una cola de cola tail está definida por la macro TAILQ_HEAD. Esta estructura contiene un par de punteros, uno al primer elemento en la cola de cola tail y el otro al último elemento en la cola de cola tail. Los elementos están vinculados doblemente de forma que se pueda eliminar cualquier elemento sin recorrer la cola de cola tail. Los elementos nuevos pueden agregarse a la cola de cola tail después de un elemento existente, antes de un elemento existente, al frente de la cola de cola tail, o al final de la cola de cola tail. Una estructura TAILQ_HEAD se declara así:

TAILQ_HEAD(HEADNAME, TYPE) head;

donde HEADNAME es el nombre de la estructura a definirse y TYPE es el tipo de los elementos vinculados a la cola de cola tail. Un puntero al cabeza de la cola de cola tail puede ser declarado más tarde así:

struct HEADNAME *headp;

(Los nombres head y headp son seleccionables del usuario.)

La macro TAILQ_HEAD_INITIALIZER evalúa a un inicializador para la cola de cola tail head.

La macro TAILQ_CONCAT concatená la cola de cola tail referida por head2 al final de la cola de cola tail referida por head1, eliminando todas las entradas de la former.

La macro TAILQ_EMPTY evalúa a true si no hay elementos en la cola de cola tail.

La macro TAILQ_ENTRY declara una estructura que conecta los elementos de la cola de cola tail.

La macro TAILQ_FIRST devuelve el primer elemento en la cola de cola tail o NULL si la cola de cola tail está vacía.

La macro TAILQ_FOREACH recorre la cola de cola tail referida por head en la dirección forward, asignando cada elemento en orden a var. var es establecido a NULL si el bucle termina normally, o si no hay elementos.

La macro TAILQ_FOREACH_FROM comporta igualmente a TAILQ_FOREACH cuando var es NULL, sino que trata var como un elemento previamente encontrado en la cola de cola tail y comienza el bucle desde var en lugar del primer elemento de la cola de cola tail referida por head.

La macro TAILQ_FOREACH_REVERSE recorre la cola de cola tail referida por head en la dirección reverse, asignando cada elemento en orden a var.

La macro TAILQ_FOREACH_REVERSE_FROM comporta igualmente a TAILQ_FOREACH_REVERSE cuando var es NULL, sino que trata var como un elemento previamente encontrado en la cola de cola tail y comienza el bucle en reversa desde var en lugar del último elemento de la cola de cola tail referida por head.

Las macros TAILQ_FOREACH_SAFE y TAILQ_FOREACH_REVERSE_SAFE recorren la lista referida por head en la dirección forward o reverse respectivamente, asignando cada elemento en orden a var. Sin embargo, a diferencia de sus contrapartes inseguras, TAILQ_FOREACH y TAILQ_FOREACH_REVERSE permiten remover var así como liberar de forma segura var dentro del bucle sin interferir con la travesía.

La macro TAILQ_FOREACH_FROM_SAFE comporta igualmente a TAILQ_FOREACH_SAFE cuando var es NULL, sino que trata var como un elemento previamente encontrado en la cola de cola tail y comienza el bucle desde var en lugar del primer elemento de la cola de cola tail referida por head.

La macro TAILQ_FOREACH_REVERSE_FROM_SAFE comporta igualmente a TAILQ_FOREACH_REVERSE_SAFE cuando var es NULL, sino que trata var como un elemento previamente encontrado en la cola de cola tail y comienza el bucle en reversa desde var en lugar del último elemento de la cola de cola tail referida por head.

La macro TAILQ_INIT inicializa la cola de cola tail referida por head.

La macro TAILQ_INSERT_HEAD inserta el elemento nuevo elm al frente de la cola de cola tail.

La macro TAILQ_INSERT_TAIL inserta el elemento nuevo elm al final de la cola de cola tail.

La macro TAILQ_INSERT_AFTER inserta el elemento nuevo elm después del elemento listelm.

La macro TAILQ_INSERT_BEFORE inserta el elemento nuevo elm antes del elemento listelm.

La macro TAILQ_LAST devuelve el último elemento en la cola de cola tail. Si la cola de cola tail está vacía, el valor devuelto es NULL.

La macro TAILQ_NEXT devuelve el siguiente elemento en la cola de cola tail, o NULL si este es el último.

La macro TAILQ_PREV devuelve el elemento anterior en la cola de cola tail, o NULL si este es el primero.

La macro TAILQ_REMOVE elimina el elemento elm de la cola de cola tail.

La macro TAILQ_SWAP intercambia el contenido de head1 y head2.

DESCRIPTION

These macros provide an implementation of doubly-linked lists. They are designed to be efficient and safe.

A doubly-linked list is a data structure that consists of a set of nodes, where each node contains a pointer to the previous node and a pointer to the next node. The list itself maintains pointers to the first and last nodes in the list.

The macros are defined in the header file <sys/queue.h>. In order to use these macros, you first need to define a structure for your list nodes and include a field of type TAILQ_ENTRY(type). You also need to define a structure for the list head, which will contain a pointer to the first and last elements in the list. This is done using the TAILQ_HEAD macro.

For example:

struct my_node {
    int data;
    TAILQ_ENTRY(my_node) next;
};

TAILQ_HEAD(my_list_head, my_node);

This defines a structure named my_node that can be used in a tail queue, and a tail queue head structure named my_list_head that contains pointers to my_node structures.

The following macros are available:

TAILQ_INIT
Initializes the list specified by head. This macro should be used before any other list operations are performed on the list.
TAILQ_INSERT_HEAD
Inserts the element specified by elm at the head of the list specified by head. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_INSERT_TAIL
Inserts the element specified by elm at the tail of the list specified by head. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_INSERT_AFTER
Inserts the element specified by elm after the element specified by listelm in the list specified by head. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_INSERT_BEFORE
Inserts the element specified by elm before the element specified by listelm in the list specified by head. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_REMOVE
Removes the element specified by elm from the list specified by head. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_REPLACE
Replaces the element specified by oldelm with the element specified by newelm in the list specified by head. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_FIRST
Returns the first element in the list specified by head, or NULL if the list is empty.
TAILQ_LAST
Returns the last element in the list specified by head, or NULL if the list is empty. The headname argument is the name of the tail queue head structure.
TAILQ_NEXT
Returns the next element in the list after the element specified by elm, or NULL if elm is the last element. The field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_PREV
Returns the previous element in the list before the element specified by elm, or NULL if elm is the first element. The headname argument is the name of the tail queue head structure, and the field argument is the name of the macro-defined TAILQ_ENTRY field in the element structure.
TAILQ_EMPTY
Returns true if the list specified by head is empty, and false otherwise.
TAILQ_FOREACH
Iterates over the list specified by head. In each iteration, var is set to the current element, and field is the name of the macro-defined TAILQ_ENTRY field in the element structure. This macro is not safe for removing elements from the list during iteration.
TAILQ_FOREACH_REVERSE
Iterates over the list specified by head in reverse order. In each iteration, var is set to the current element, headname is the name of the tail queue head structure, and field is the name of the macro-defined TAILQ_ENTRY field in the element structure. This macro is not safe for removing elements from the list during iteration.
TAILQ_FOREACH_SAFE
Same as TAILQ_FOREACH, but safe for removing elements from the list during iteration. The nextvar argument is a temporary variable that stores the next element before the current element is potentially removed.
TAILQ_FOREACH_REVERSE_SAFE
Same as TAILQ_FOREACH_REVERSE, but safe for removing elements from the list during iteration. The nextvar argument is a temporary variable that stores the next element before the current element is potentially removed.
TAILQ_FOREACH_FROM
Similar to TAILQ_FOREACH, but starts iteration from the element specified by var. This is useful when you only want to iterate over a portion of the list.
TAILQ_FOREACH_FROM_SAFE
Safe version of TAILQ_FOREACH_FROM, allowing removal of elements during iteration.
TAILQ_FOREACH_REVERSE_FROM
Similar to TAILQ_FOREACH_REVERSE, but starts iteration from the element specified by var.
TAILQ_FOREACH_REVERSE_FROM_SAFE
Safe version of TAILQ_FOREACH_REVERSE_FROM, allowing removal of elements during iteration.

SINGLY-LINKED LISTS

The macros SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_ENTRY, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_INSERT_TAIL, SLIST_REMOVE, SLIST_REMOVE_HEAD, SLIST_FIRST, SLIST_NEXT, SLIST_EMPTY, SLIST_FOREACH, SLIST_FOREACH_SAFE, SLIST_FOREACH_FROM, and SLIST_FOREACH_FROM_SAFE provide an implementation of singly-linked lists.

SINGLY-LINKED LIST EXAMPLE

The following example demonstrates the usage of singly-linked lists:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    SLIST_ENTRY(node) next;
};

SLIST_HEAD(list_head, node);

int
main(void) {
    struct list_head head;
    struct node *n1, *n2, *np;

    SLIST_INIT(&head);

    // Create and insert nodes
    n1 = malloc(sizeof(*n1));
    n1->data = 1;
    SLIST_INSERT_HEAD(&head, n1, next);

    n2 = malloc(sizeof(*n2));
    n2->data = 2;
    SLIST_INSERT_HEAD(&head, n2, next);

    // Iterate over the list
    SLIST_FOREACH(np, &head, next) {
        printf("Data: %d\n", np->data);
    }

    // Remove a node
    SLIST_REMOVE(&head, n1, node, next);
    free(n1);

    // Iterate again
    SLIST_FOREACH(np, &head, next) {
        printf("Data: %d\n", np->data);
    }

    // Free remaining node
    n2 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, next);
    free(n2);

    return 0;
}

DIAGNOSTICS

When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.
