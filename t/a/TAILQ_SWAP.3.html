الاسم

TAILQ_CONCAT, TAILQ_EMPTY, TAILQ_ENTRY, TAILQ_FIRST, TAILQ_FOREACH, TAILQ_FOREACH_REVERSE, TAILQ_HEAD, TAILQ_HEAD_INITIALIZER, TAILQ_INIT, TAILQ_INSERT_AFTER, TAILQ_INSERT_BEFORE, TAILQ_INSERT_HEAD, TAILQ_INSERT_TAIL, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE - تطبيق قائمة ذيل مربوطة بشكل مزدوج

المكتبة

مكتبة C القياسية (libc, -lc)

الوصف

تحدد هذه الماكروات وتعمل على قوائم الذيل المربوطة بشكل مزدوج.

في تعريفات الماكرو، TYPE هو اسم هيكل معرف من قبل المستخدم، يجب أن يحتوي على حقل من نوع TAILQ_ENTRY، اسمه NAME. الوسيط HEADNAME هو اسم هيكل معرف من قبل المستخدم يجب تعريفه باستخدام الماكرو TAILQ_HEAD().

الإنشاء

يتم ترؤس قائمة الذيل بهيكل معرف بواسطة الماكرو TAILQ_HEAD(). يحتوي هذا الهيكل على زوج من المؤشرات، أحدهما يشير إلى العنصر الأول في القائمة والآخر يشير إلى العنصر الأخير في القائمة. العناصر مربوطة بشكل مزدوج بحيث يمكن إزالة عنصر تعسفي دون الحاجة إلى اجتياز القائمة. يمكن إضافة عناصر جديدة إلى القائمة بعد عنصر موجود، أو قبل عنصر موجود، أو في بداية القائمة، أو في نهاية القائمة. يتم تعريف هيكل TAILQ_HEAD على النحو التالي:


TAILQ_HEAD(HEADNAME, TYPE) head;

حيث struct HEADNAME هو الهيكل المراد تعريفه، و struct TYPE هو نوع العناصر التي سيتم ربطها في القائمة. يمكن لاحقًا تعريف مؤشر إلى رأس القائمة كالتالي:


struct HEADNAME *headp;

(الأسماء head و headp يمكن للمستخدم اختيارها.)

يعرّف TAILQ_ENTRY() هيكلًا يربط العناصر في القائمة.

TAILQ_HEAD_INITIALIZER() يقيم إلى قيمة تهيئة للقائمة head.

يقوم TAILQ_INIT() بتهيئة القائمة المشار إليها بـ

يقيم TAILQ_EMPTY() إلى صحيح إذا لم تكن هناك عناصر في القائمة. head.

الإدخال

يقوم TAILQ_INSERT_HEAD() بإدراج العنصر الجديد elm في بداية القائمة.

يقوم TAILQ_INSERT_TAIL() بإدراج العنصر الجديد elm في نهاية القائمة.

يقوم TAILQ_INSERT_BEFORE() بإدراج العنصر الجديد elm قبل العنصر listelm.

يقوم TAILQ_INSERT_AFTER() بإدراج العنصر الجديد elm بعد العنصر listelm.

التجوال

يعيد TAILQ_FIRST() العنصر الأول في القائمة، أو NULL إذا كانت القائمة فارغة.

يعيد TAILQ_LAST() العنصر الأخير في القائمة. إذا كانت القائمة فارغة، تكون القيمة المعادة NULL.

يعيد TAILQ_PREV() العنصر السابق في القائمة، أو NULL إذا كان هذا العنصر هو الأول.

يعيد TAILQ_NEXT() العنصر التالي في القائمة، أو NULL إذا كان هذا العنصر هو الأخير.

يقوم TAILQ_FOREACH() بتجوال القائمة المشار إليها بواسطة head في الاتجاه الأمامي، وتعيين كل عنصر بدوره إلى var. يتم تعيين var إلى NULL إذا اكتملت الحلقة بشكل طبيعي، أو إذا لم تكن هناك عناصر.

يقوم TAILQ_FOREACH_REVERSE() بتجوال القائمة المشار إليها بواسطة head في الاتجاه العكسي، وتعيين كل عنصر بدوره إلى var.

الإزالة

يقوم TAILQ_REMOVE() بإزالة العنصر elm من القائمة.

ميزات أخرى

يقوم TAILQ_CONCAT() بضم القائمة التي ترأسها head2 إلى نهاية القائمة التي ترأسها head1، مع إزالة جميع الإدخالات من الأولى.

قيمة الإرجاع

يعيد TAILQ_EMPTY() قيمة غير صفرية إذا كانت القائمة فارغة، وصفر إذا كانت القائمة تحتوي على إدخال واحد على الأقل.

يعيد TAILQ_FIRST() و TAILQ_LAST() و TAILQ_PREV() و TAILQ_NEXT() مؤشرًا إلى هيكل TYPE الأول أو الأخير أو السابق أو التالي، على التوالي.

TAILQ_HEAD_INITIALIZER() يعيد قيمة تهيئة يمكن تعيينها إلى القائمة head.

المعايير

BSD.

التاريخ

4.4BSD.

تنبيهات

لا تسمح TAILQ_FOREACH() و TAILQ_FOREACH_REVERSE() بإزالة var أو تحريرها داخل الحلقة، لأن ذلك قد يتداخل مع عملية التجوال. TAILQ_FOREACH_SAFE() و TAILQ_FOREACH_REVERSE_SAFE()، الموجودة في BSD ولكنها غير موجودة في glibc، تعالج هذا القيد عن طريق السماح بإزالة var بأمان من القائمة وتحريرها من داخل الحلقة دون التدخل في عملية التجوال.

أمثلة

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    TAILQ_ENTRY(entry) entries;             /* Tail queue */
};
TAILQ_HEAD(tailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct tailhead head;                   /* Tail queue head */
    int i;
    TAILQ_INIT(&head);                      /* Initialize the queue */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    TAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insert at the tail */
    TAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    TAILQ_INSERT_AFTER(&head, n1, n2, entries);
    n3 = malloc(sizeof(struct entry));      /* Insert before */
    TAILQ_INSERT_BEFORE(n2, n3, entries);
    TAILQ_REMOVE(&head, n2, entries);       /* Deletion */
    free(n2);
                                            /* Forward traversal */
    i = 0;
    TAILQ_FOREACH(np, &head, entries)
        np->data = i++;
                                            /* Reverse traversal */
    TAILQ_FOREACH_REVERSE(np, &head, tailhead, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1
