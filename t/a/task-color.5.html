NAME

task-color, taskrc - Taskwarrior color configuration

AUTOMATIC MONOCHROME

When Taskwarrior detects that it is running in an environment that does not support color, it automatically switches to monochrome mode. This is done by checking the TERM environment variable. If TERM is set to dumb, or is unset, then monochrome mode is activated.

You can also force monochrome mode by adding the following to your .taskrc file:

    color.default: off

AVAILABLE COLORS

Taskwarrior supports 16-color and 256-color terminals. The available colors are:

    black, red, green, yellow, blue, magenta, cyan, white,
    bright-black, bright-red, bright-green, bright-yellow, bright-blue,
    bright-magenta, bright-cyan, bright-white.

In a 256-color terminal, the colors are referred to by number:

    color.red      = red
    color.red.256  = 196
    color.blue     = blue
    color.blue.256 = 21

It is possible to specify a color by name or by number.

16-COLOR SUPPORT

When running in 16-color mode, the following color names are recognized:

    black, red, green, yellow, blue, magenta, cyan, white,
    bright-black, bright-red, bright-green, bright-yellow, bright-blue,
    bright-magenta, bright-cyan, bright-white.

And also, for compatibility with older applications, the following names:

    gray,          (synonym for bright-black)
    bold-red,      (synonym for bright-red)
    bold-green,    (synonym for bright-green)
    bold-yellow,   (synonym for bright-yellow)
    bold-blue,     (synonym for bright-blue)
    bold-magenta,  (synonym for bright-magenta)
    bold-cyan,     (synonym for bright-cyan)
    bold-white     (synonym for bright-white)

There are also attributes for boldness and underline:

    bold,          underline.

256-COLOR SUPPORT

When running in 256-color mode, the following color names are recognized:

    black, red, green, yellow, blue, magenta, cyan, white,
    bright-black, bright-red, bright-green, bright-yellow, bright-blue,
    bright-magenta, bright-cyan, bright-white.

In addition, any of the 256 ANSI colors can be specified by number, preceded by a period. For example, to specify ANSI color 21:

    color.example = .21

The 256 colors are composed of:

    - The standard 16 colors (0-15)
    - A grayscale ramp (232-255)
    - A color cube (16-231)

For example, the following are all valid ways to specify red:

    color.red = red
    color.red = bright-red
    color.red = .196

There are also attributes for boldness and underline:

    bold,          underline.

MIXING 16- AND 256-COLORS

You can specify a color using the 256-color name, and then specify a foreground and background color.

    color.example = red on blue
    color.example = yellow on bright-cyan
    color.example = .196 on .21

The following modifiers can also be used:

    bold,          underline.

For example:

    color.example = bold red on underline blue

LEGEND

Taskwarrior can show you how the color rules are being applied with the command:

    $ task color legend

This command displays a table, showing the color rule name, the pattern it matches, and the color it assigns.

RULES

The color rules are processed in order of precedence, from highest to lowest. The first rule to match a task is the one that determines its color.

    deleted,completed,active,keyword.,tag.,project.,overdue,scheduled,due.today,due,blocked,blocking,recurring,tagged,uda.

These are just the color rules with the 'color.' prefix removed. The rule 'color.deleted' has the highest precedence, and 'color.uda.' the lowest.

The keyword rule shown here as 'keyword.' corresponds to a wildcard pattern, meaning 'color.keyword.*', or in other words all the keyword rules.

There is also 'color.project.none', 'color.tag.none' and 'color.uda.priority.none' to specifically represent missing data.

THEMES

Taskwarrior supports themes. What this really means is that with the ability to include other files into the .taskrc file, different sets of color rules can be included.

To get a good idea of what a color theme looks like, try adding this entry to your .taskrc file:

    include dark-256.theme

You can use any of the standard Taskwarrior themes:

    dark-16.theme
    dark-256.theme
    dark-blue-256.theme
    dark-gray-256.theme
    dark-green-256.theme
    dark-red-256.theme
    dark-violets-256.theme
    dark-yellow-green.theme
    light-16.theme
    light-256.theme
    solarized-dark-256.theme
    solarized-light-256.theme
    dark-default-16.theme
    dark-gray-blue-256.theme
    no-color.theme

Bear in mind that if you are using a terminal with a dark background, you will see better results using a dark theme.

You can also see how the theme will color the various tasks with the command:

    $ task color legend

Better yet, create your own, and share it. We will gladly host the theme file on https://taskwarrior.org.

الاسم

task-color, taskrc - تكوين ألوان Taskwarrior

الأحادية التلقائية

عندما يكتشف Taskwarrior أنه يعمل في بيئة لا تدعم الألوان، فإنه ينتقل تلقائيًا إلى وضع اللون الواحد. يتم ذلك عن طريق التحقق من متغير البيئة TERM. إذا تم تعيين TERM على "dumb"، أو تم إلغاء تعيينه، فسيتم تنشيط وضع اللون الواحد.

يمكنك أيضًا فرض وضع اللون الواحد عن طريق إضافة ما يلي إلى ملف .taskrc الخاص بك:

    color.default: off

الألوان المتاحة

يدعم Taskwarrior المحطات الطرفية ذات 16 لونًا و 256 لونًا. الألوان المتاحة هي:

    black, red, green, yellow, blue, magenta, cyan, white,
    bright-black, bright-red, bright-green, bright-yellow, bright-blue,
    bright-magenta, bright-cyan, bright-white.

في محطة طرفية ذات 256 لونًا، تتم الإشارة إلى الألوان بأرقام:

    color.red      = red
    color.red.256  = 196
    color.blue     = blue
    color.blue.256 = 21

من الممكن تحديد لون بالاسم أو بالرقم.

دعم 16 لونًا

عند التشغيل في وضع 16 لونًا، يتم التعرف على أسماء الألوان التالية:

    black, red, green, yellow, blue, magenta, cyan, white,
    bright-black, bright-red, bright-green, bright-yellow, bright-blue,
    bright-magenta, bright-cyan, bright-white.

وأيضًا، للتوافق مع التطبيقات القديمة، الأسماء التالية:

    gray,          (مرادف لـ bright-black)
    bold-red,      (مرادف لـ bright-red)
    bold-green,    (مرادف لـ bright-green)
    bold-yellow,   (مرادف لـ bright-yellow)
    bold-blue,     (مرادف لـ bright-blue)
    bold-magenta,  (مرادف لـ bright-magenta)
    bold-cyan,     (مرادف لـ bright-cyan)
    bold-white     (مرادف لـ bright-white)

هناك أيضًا سمات للخط العريض والتسطير:

    bold,          underline.

دعم 256 لونًا

عند التشغيل في وضع 256 لونًا، يتم التعرف على أسماء الألوان التالية:

    black, red, green, yellow, blue, magenta, cyan, white,
    bright-black, bright-red, bright-green, bright-yellow, bright-blue,
    bright-magenta, bright-cyan, bright-white.

بالإضافة إلى ذلك، يمكن تحديد أي من ألوان ANSI الـ 256 برقم، مسبوقًا بنقطة. على سبيل المثال، لتحديد لون ANSI 21:

    color.example = .21

تتكون الألوان الـ 256 من:

    - الألوان القياسية الـ 16 (0-15)
    - تدرج رمادي (232-255)
    - مكعب الألوان (16-231)

على سبيل المثال، الطرق التالية كلها صالحة لتحديد اللون الأحمر:

    color.red = red
    color.red = bright-red
    color.red = .196

هناك أيضًا سمات للخط العريض والتسطير:

    bold,          underline.

مزج 16 و 256 لونًا

يمكنك تحديد لون باستخدام اسم اللون ذي 256 لونًا، ثم تحديد لون أمامي ولون خلفي.

    color.example = red on blue
    color.example = yellow on bright-cyan
    color.example = .196 on .21

يمكن أيضًا استخدام المعدلات التالية:

    bold,          underline.

على سبيل المثال:

    color.example = bold red on underline blue

الأسطورة

يمكن لـ Taskwarrior أن يوضح لك كيف يتم تطبيق قواعد الألوان باستخدام الأمر:

    $ task color legend

يعرض هذا الأمر جدولًا، يوضح اسم قاعدة اللون، النمط الذي تطابقه، واللون الذي تخصصه.

القواعد

تتم معالجة قواعد الألوان بترتيب الأسبقية، من الأعلى إلى الأدنى. القاعدة الأولى التي تطابق مهمة هي التي تحدد لونها.

    deleted,completed,active,keyword.,tag.,project.,overdue,scheduled,due.today,due,blocked,blocking,recurring,tagged,uda.

هذه هي قواعد الألوان فقط مع إزالة البادئة 'color.'. القاعدة 'color.deleted' لها أعلى أسبقية، و 'color.uda.' الأدنى.

القاعدة "keyword." المعروضة هنا كـ "keyword." تتوافق مع نمط حرف بدل، مما يعني 'color.keyword.*'، أو بعبارة أخرى جميع قواعد الكلمات المفتاحية.

هناك أيضًا 'color.project.none'، 'color.tag.none'، و 'color.uda.priority.none' لتمثيل البيانات المفقودة بشكل خاص.

السمات

يدعم Taskwarrior السمات. ما يعنيه هذا في الواقع هو أنه مع القدرة على تضمين ملفات أخرى في ملف .taskrc، يمكن تضمين مجموعات مختلفة من قواعد الألوان.

للحصول على فكرة جيدة عن شكل سمة الألوان، جرب إضافة هذا الإدخال إلى ملف .taskrc الخاص بك:

    include dark-256.theme

يمكنك استخدام أي من سمات Taskwarrior القياسية:

    dark-16.theme
    dark-256.theme
    dark-blue-256.theme
    dark-gray-256.theme
    dark-green-256.theme
    dark-red-256.theme
    dark-violets-256.theme
    dark-yellow-green.theme
    light-16.theme
    light-256.theme
    solarized-dark-256.theme
    solarized-light-256.theme
    dark-default-16.theme
    dark-gray-blue-256.theme
    no-color.theme

ضع في اعتبارك أنه إذا كنت تستخدم طرفية بخلفية داكنة، فسترى نتائج أفضل باستخدام سمة داكنة.

يمكنك أيضًا رؤية كيف ستقوم السمة بتلوين المهام المختلفة باستخدام الأمر:

    $ task color legend

والأفضل من ذلك، قم بإنشاء سمة خاصة بك وشاركها. سنستضيف بكل سرور ملف السمة على https://taskwarrior.org.
