TAP::Parser::Iterator::Process(3perl) دليل مبرمجي Perl TAP::Parser::Iterator::Process(3perl)

الاسم

TAP::Parser::Iterator::Process - مكرر لمصادر TAP المستندة إلى العمليات

الإصدار

الإصدار 3.50

الملخص

use TAP::Parser::Iterator::Process;
my %args = (
 command  => ['python', 'setup.py', 'test'],
 merge    => 1,
 setup    => sub { ... },
 teardown => sub { ... },
);
my $it   = TAP::Parser::Iterator::Process->new(\%args);
my $line = $it->next;

الوصف

هذا غلاف مكرر بسيط لتنفيذ عمليات خارجية، يستخدمه TAP::Parser. إلا إذا كنت تكتب إضافة أو فئة فرعية، فمن المحتمل ألا تحتاج إلى استخدام هذه الوحدة مباشرة.

الأساليب

أساليب الفئة

"new"

إنشاء مكرر. يتوقع وسيطًا واحدًا يحتوي على hashref بالشكل التالي:

command  => \@command_to_execute
merge    => $attempt_merge_stderr_and_stdout?
setup    => $callback_to_setup_command
teardown => $callback_to_teardown_command

يحاول استخدام IPC::Open3 & IO::Select للتواصل مع العملية التي تم إنشاؤها إذا كانت متاحة. يعود إلى open().

أساليب المثيل

"next"

التكرار عبر مخرجات العملية، بالطبع.

"next_raw"

التكرار عبر الإدخال الخام دون تطبيق أي إصلاحات لقواعد الإدخال الغريبة.

"wait"

الحصول على حالة الانتظار لعملية هذا المكرر.

"exit"

الحصول على حالة الخروج لعملية هذا المكرر.

"handle_unicode"

ترقية تيار الإدخال للتعامل مع UTF8.

"get_select_handles"

إرجاع قائمة بمعالجات الملفات التي قد يتم استخدامها في الأعلى في استدعاء select() للإشارة إلى أن هذا المكرر جاهز. يجب على المكررات التي لا تعتمد على المعالجات إرجاع قائمة فارغة.

نسب

تم سرقتها في الأصل من Test::Harness.
