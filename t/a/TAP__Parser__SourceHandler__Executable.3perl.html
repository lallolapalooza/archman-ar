TAP::Parser::SourceHandler::Executable(3perl) دليل مبرمجي Perl TAP::Parser::SourceHandler::Executable(3perl)

الاسم

TAP::Parser::SourceHandler::Executable - تدفق المخرجات من مصدر TAP قابل للتنفيذ

الإصدار

الإصدار 3.50

الملخص

use TAP::Parser::Source;
use TAP::Parser::SourceHandler::Executable;
my $source = TAP::Parser::Source->new->raw(['/usr/bin/ruby', 'mytest.rb']);
$source->assemble_meta;
my $class = 'TAP::Parser::SourceHandler::Executable';
my $vote  = $class->can_handle( $source );
my $iter  = $class->make_iterator( $source );

الوصف

هذا هو معالج مصدر TAP قابل للتنفيذ - لديه مهمتان:

1. تحديد ما إذا كان مصدر TAP::Parser::Source الذي يتم تمريره عبارة عن أمر قابل للتنفيذ ("can_handle").

2. إنشاء مكرر للأوامر القابلة للتنفيذ ("make_iterator").

ما لم تكن تكتب إضافة أو ترث من TAP::Parser، فمن غير المرجح أن تحتاج إلى استخدام هذه الوحدة مباشرة.

الأساليب

أساليب الفئة

"can_handle"

my $vote = $class->can_handle( $source );

يصوت فقط إذا بدا $source كملف قابل للتنفيذ. يلقي الأصوات التالية:

0.9  إذا كان علامة تجزئة مع مفتاح 'exec'
0.8  إذا كان ملف .bat
0.75 إذا كان لديه بت التنفيذ معين

"make_iterator"

my $iterator = $class->make_iterator( $source );

يرجع مكرر TAP::Parser::Iterator::Process جديد للمصدر. يجب أن يكون "$source->raw" بأحد الأشكال التالية:

{ exec => [ @exec ] }
[ @exec ]
$file


يُصدر "croak" عند الخطأ.


"iterator_class"


فئة المكرر المراد استخدامها، تجاوزها إذا كنت ترث. الافتراضي هو
    TAP::Parser::Iterator::Process.

الوراثة

يرجى الاطلاع على "SUBCLASSING" في TAP::Parser للحصول على نظرة عامة على الوراثة.

مثال

package MyRubySourceHandler;
use strict;
use Carp qw( croak );
use TAP::Parser::SourceHandler::Executable;
use base 'TAP::Parser::SourceHandler::Executable';
# نتوقع $handler->(['mytest.rb', 'cmdline', 'args']);
sub make_iterator {
  my ($self, $source) = @_;
  my @test_args = @{ $source->test_args };
  my $rb_file   = $test_args[0];
  croak("error: Ruby file '$rb_file' not found!") unless (-f $rb_file);
  return $self->SUPER::raw_source(['/usr/bin/ruby', @test_args]);
}
