NAME

TAILQ_FIRST, TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, TAILQ_REMOVE, TAILQ_SWAP — queue(3) macros for examining tail queues

LIBRARY

libbsd, libcompiler_rt

SYNOPSIS

#include <sys/queue.h>
#define TAILQ_FIRST(head) \
    *(head)*- q_first;
#define TAILQ_LAST(head, name) \
    (name *)((char *)&(head)- q_last - offsetof(name, field))
#define TAILQ_NEXT(elm, name) \
    (name *)((char *)((elm)- field.tqe_next) - offsetof(name, field))
#define TAILQ_PREV(elm, name, field) \
    (name *)((char *)((elm)- field.tqe_prev) - offsetof(name, field))
#define TAILQ_REMOVE(head, elm, field) \
    do { \
        if (((elm)- field.tqe_next) != NULL) \
            ((TAILQ_NEXT((elm), field))- field.tqe_prev) = (elm)- field.tqe_prev; \
        else \
            (head)- q_last = (elm)- field.tqe_prev; \
        if ((elm)- field.tqe_prev) \
            (elm)- field.tqe_prev- tqe_next = (elm)- field.tqe_next; \
        else \
            (head)- q_first = (elm)- field.tqe_next; \
    } while (0)
#define TAILQ_SWAP(head1, head2, name) \
    do { \
        name *n1 = TAILQ_FIRST(head1); \
        name *n2 = TAILQ_FIRST(head2); \
        TAILQ_HEAD(name) tmp = *(head1); \
        *(head1) = *(head2); \
        *(head2) = tmp; \
        if (n1) \
            n1- field.tqe_prev = (head2); \
        else \
            (head2)- q_last = NULL; \
        if (n2) \
            n2- field.tqe_prev = (head1); \
        else \
            (head1)- q_last = NULL; \
    } while (0)

DESCRIPTION

These macros provide an API for manipulating tail queues. A tail queue is a doubly linked list with the addition of a pointer to the last element. The macros defined by this API are:

TAILQ_FIRST
Returns a pointer to the first element in the tail queue head. If the queue is empty, it returns NULL.
TAILQ_LAST
Returns a pointer to the last element in the tail queue head. If the queue is empty, it returns NULL. The name parameter is the structure name of the elements in the queue, and the field parameter is the name of the tail queue entry within the structure.
TAILQ_NEXT
Returns a pointer to the next element in the tail queue after elm. If elm is the last element in the queue, it returns NULL. The name parameter is the structure name of the elements in the queue, and the field parameter is the name of the tail queue entry within the structure.
TAILQ_PREV
Returns a pointer to the previous element in the tail queue before elm. If elm is the first element in the queue, it returns NULL. The name parameter is the structure name of the elements in the queue, and the field parameter is the name of the tail queue entry within the structure.
TAILQ_REMOVE
Removes the element elm from the tail queue head. The field parameter is the name of the tail queue entry within the structure.
TAILQ_SWAP
Swaps the contents of the tail queues head1 and head2. The name parameter is the structure name of the elements in the queue.

A tail queue element is defined using the TAILQ_ENTRY macro. For example:

struct my_list_entry {
    struct my_list_entry *next;
    struct my_list_entry *prev;
    char                 *data;
    TAILQ_ENTRY(my_list_entry) entries;
};

And the tail queue head is defined as:

TAILQ_HEAD(my_list_head, my_list_entry) my_list;

The macros iterate through the queue by dereferencing the q_first and q_last fields of the tail queue head, and the tqe_next and tqe_prev fields of the tail queue entry. The field parameter to TAILQ_LAST, TAILQ_NEXT, TAILQ_PREV, and TAILQ_REMOVE is used to specify the name of the tail queue entry field within the structure.

RETURN VALUE

TAILQ_FIRST, TAILQ_LAST, TAILQ_NEXT, and TAILQ_PREV return pointers to queue elements or NULL if the queue is empty or the specified element is at the end of the queue. TAILQ_REMOVE and TAILQ_SWAP do not return a value.

STANDARDS

These macros are extensions to the POSIX standard and are generally available on BSD-derived systems.

HISTORY

The tail queue macros first appeared in 4.4BSD.

CAVEATS

The TAILQ_REMOVE macro is unsafe if the element being removed is the first or last element in the queue, and the queue is empty. In such cases, the macro will attempt to dereference a NULL pointer, leading to a crash.

To safely remove elements from a tail queue, it is recommended to use the following pattern:

TAILQ_FOREACH_SAFE(n1, &head, entries, n2) {
    TAILQ_REMOVE(&head, n1, entries);
    free(n1);
}

The previous code snippet is a direct translation of the provided C code, which appears to have a potential issue. The code snippet provided in the prompt is:

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}

This code iterates through the tail queue, frees each element, and then reinitializes the queue. The `TAILQ_REMOVE` macro is not directly used in the provided snippet. However, the caveat mentioned about `TAILQ_REMOVE` is still relevant to the general usage of tail queues. The example shown in the caveat is a safer way to remove and free elements from a tail queue.

EXAMPLES

The following example demonstrates how to use the TAILQ_FIRST, TAILQ_NEXT, and TAILQ_REMOVE macros to iterate through a tail queue and remove all elements:

    struct my_list_head head;
    struct my_list_entry *n1, *n2;

    TAILQ_INIT(&head);

    /* ... add elements to the queue ... */

    n1 = TAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = TAILQ_NEXT(n1, entries);
        TAILQ_REMOVE(&head, n1, entries);
        free(n1);
        n1 = n2;
    }
    TAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
