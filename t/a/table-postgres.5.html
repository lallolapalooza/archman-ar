TABLE_POSTGRESQL(5) دليل صيغ الملفات TABLE_POSTGRESQL(5)

الاسم

table_postgresql — وصف الصيغة لجداول PostgreSQL الخاصة بـ smtpd

الوصف

صفحة الدليل هذه توثق صيغة ملفات PostgreSQL التي يستخدمها الدايمون البريدي smtpd(8).

الصيغة الموصوفة هنا تنطبق على الجداول كما هو معرف في smtpd.conf(5).

جدول PostgreSQL

يسمح جدول PostgreSQL بتخزين أسماء المستخدمين وكلمات المرور والأسماء المستعارة والنطاقات في صيغة يمكن مشاركتها عبر آلات مختلفة تدعم postgres(1).

يستخدم الجدول بواسطة smtpd(8) عند المصادقة على مستخدم، وعندما تكون معلومات المستخدم مثل معرّف المستخدم و/أو مجلد المنزل مطلوبة للتسليم، وعندما قد يلزم البحث عن النطاق، و/أو عند البحث عن اسم مستعار.

يتكون جدول PostgreSQL من قاعدة بيانات postgresql(1) واحدة أو أكثر تحتوي على جدول واحد أو أكثر.

إذا كان الجدول مستخدمًا للمصادقة، فيجب تشفير كلمة المرور باستخدام دالة crypt(3). يمكن إنشاء مثل هذه الكلمات المرور باستخدام الأداة المساعدة encrypt(1) أو أمر التشفير في smtpctl(8).

ملف تكوين جدول PostgreSQL

خيارات التكوين التالية متاحة:

conninfo host='المضيف' user='المستخدم' password='كلمة المرور' dbname='اسم قاعدة البيانات'
معلومات الاتصال اللازمة للاتصال بقاعدة بيانات PostgreSQL. على سبيل المثال: 
conninfo host='db.example.com' user='maildba' password='...' dbname='opensmtpdb'
query_alias عبارة SQL
تُستخدم لتقديم استعلام للبحث عن الأسماء المستعارة. يتم استبدال علامة الاستفهام بالبيانات المناسبة. بالنسبة للأسماء المستعارة، فهي الجانب الأيسر من عنوان SMTP. يتوقع أن يتم إرجاع VARCHAR واحد باسم المستخدم الذي يحل إليه الاسم المستعار.
query_credentials عبارة SQL
تُستخدم لتقديم استعلام للبحث عن بيانات اعتماد المستخدم. يتم استبدال علامة الاستفهام بالبيانات المناسبة. بالنسبة لبيانات الاعتماد، فهي الجانب الأيسر من عنوان SMTP. يتوقع الاستعلام أن يتم إرجاع VARCHARs، أحدهما باسم مستخدم والآخر بكلمة مرور بصيغة crypt(3).
query_domain عبارة SQL
تُستخدم لتقديم استعلام للبحث عن نطاق. يتم استبدال علامة الاستفهام بالبيانات المناسبة. بالنسبة للنطاق، سيكون الجانب الأيمن من عنوان SMTP. يتوقع أن يتم إرجاع VARCHAR واحد باسم نطاق مطابق.
query_mailaddrmap عبارة SQL
تُستخدم لتقديم استعلام للبحث عن المرسلين. يتم استبدال علامة الاستفهام بالبيانات المناسبة. يتوقع أن يتم إرجاع VARCHAR واحد بعنوان البريد الإلكتروني الذي يُسمح للمرسل بالإرسال منه.

ستكون عبارة SQL عامة شيئًا مثل:

query_ SELECT value FROM table WHERE key=$1;

أمثلة

مثال عام

مثال مبني على الأسئلة الشائعة لـ OpenSMTPD: بناء خادم بريد. تم استبعاد جزء التصفية في هذا المثال.

التكوين أدناه مخصص لخادم بريد متوسط الحجم يتعامل مع نطاقات متعددة مع مستخدمين افتراضيين متعددين ويعتمد على عدة افتراضات. أحدها هو استخدام مستخدم نظام واحد باسم vmail لجميع المستخدمين الافتراضيين. يجب إنشاء هذا المستخدم:

# useradd -g =uid -c "Virtual Mail" -d /var/vmail -s /sbin/nologin vmail
# mkdir /var/vmail
# chown vmail:vmail /var/vmail

مخطط PostgreSQL:

CREATE TABLE domains (
  id SERIAL,
  domain VARCHAR(255) NOT NULL DEFAULT ''
);
CREATE TABLE virtuals (
    id SERIAL,
    email VARCHAR(255) NOT NULL DEFAULT '',
    destination VARCHAR(255) NOT NULL DEFAULT ''
);
CREATE TABLE credentials (
    id SERIAL,
    email VARCHAR(255) NOT NULL DEFAULT '',
    password VARCHAR(255) NOT NULL DEFAULT ''
);

يمكن ملؤها على النحو التالي:

INSERT INTO domains VALUES (1, "example.com");
INSERT INTO domains VALUES (2, "example.net");
INSERT INTO domains VALUES (3, "example.org");

INSERT INTO virtuals VALUES (1, "abuse@example.com", "bob@example.com");
INSERT INTO virtuals VALUES (2, "postmaster@example.com", "bob@example.com");
INSERT INTO virtuals VALUES (3, "webmaster@example.com", "bob@example.com");
INSERT INTO virtuals VALUES (4, "bob@example.com", "vmail");
INSERT INTO virtuals VALUES (5, "abuse@example.net", "alice@example.net");
INSERT INTO virtuals VALUES (6, "postmaster@example.net", "alice@example.net");
INSERT INTO virtuals VALUES (7, "webmaster@example.net", "alice@example.net");
INSERT INTO virtuals VALUES (8, "alice@example.net", "vmail");

INSERT INTO credentials VALUES (1, "bob@example.com", "$2b$08$ANGFKBL.BnDLL0bUl7I6aumTCLRJSQluSQLuueWRG.xceworWrUIu");
INSERT INTO credentials VALUES (2, "alice@example.net", "$2b$08$AkHdB37kaj2NEoTcISHSYOCEBA5vyW1RcD8H1HG.XX0P/G1KIYwii");

/etc/mail/postgresql.conf

conninfo host='db.example.com' user='maildba' password='OpenSMTPDRules!' dbname='opensmtpdb'
query_alias SELECT destination FROM virtuals WHERE email=$1;
query_credentials SELECT email, password FROM credentials WHERE email=$1;
query_domain SELECT domain FROM domains WHERE domain=$1;

/etc/mail/smtpd.conf

table domains postgres:/etc/mail/postgres.conf
table virtuals postgres:/etc/mail/postgres.conf
table credentials postgres:/etc/mail/postgres.conf
listen on egress port 25 tls pki mail.example.com
listen on egress port 587 tls-require pki mail.example.com auth <credentials>
accept from any for domain <domains> virtual <virtuals> deliver to mbox

الانتقال من POSTFIX (و POSTFIXADMIN)

/etc/mail/postgres.conf

conninfo host='db.example.com' user='postfix' password='...' dbname='postfix'
query_alias SELECT destination FROM alias WHERE email=$1;
query_credentials SELECT username, password FROM mailbox WHERE username=$1;
query_domain SELECT domain FROM domain WHERE domain=$1;
