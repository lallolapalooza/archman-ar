TAP::Base(3perl) دليل مبرمجي بيرل TAP::Base(3perl)

الاسم

TAP::Base - الفئة الأساسية التي توفر وظائف مشتركة لـ TAP::Parser و TAP::Harness

الإصدار

الإصدار 3.50

الملخص

package TAP::Whatever;
use base 'TAP::Base';
# ... لاحقاً ...

my $thing = TAP::Whatever->new();

$thing->callback( event => sub {
    # افعل شيئًا مثيرًا للاهتمام
} );

الوصف

يوفر "TAP::Base" إدارة استدعاءات ردود الفعل (callback).

الطرق

طرق الفئة

"callback"

تثبيت استدعاء رد فعل لحدث مسمى.

"get_time"

إرجاع الوقت الحالي باستخدام Time::HiRes إن كان متاحًا.

"time_is_hires"

إرجاع صحيح إذا كان الوقت الذي تم إرجاعه بواسطة get_time عالي الدقة (أي إذا كان Time::HiRes متاحًا).

"get_times"

إرجاع مرجع مصفوفة لقائمة العناصر الأربعة من ثواني وحدة المعالجة المركزية، كما هو الحال مع "times" في perlfunc.
