Template__Namespace__Constants(3pm)

الحزمة: perl-template-toolkit

التراخيص: PerlArtistic

Template::Namespace::Constants(3) User Contributed Perl Documentation Template::Namespace::Constants(3)

الاسم

Template::Namespace::Constants - تبسيط الثوابت في وقت التصريف

الملخص

# طريقة سهلة لتعريف الثوابت
use Template;
my $tt = Template->new({
    CONSTANTS => {
        pi => 3.14,
        e  => 2.718,
    },
});
# طريقة دقيقة، يدوية
use Template::Namespace::Constants;
my $tt = Template->new({
    NAMESPACE => {
        constants => Template::Namespace::Constants->new({
            pi => 3.14,
            e  => 2.718,
        },
    },
});

الوصف

الوحدة "Template::Namespace::Constants" تنفذ معالج مساحة أسماء يتم توصيله بوحدة المترجم "Template::Directive". هذا يقوم بعد ذلك بإجراء تبسيط الثوابت في وقت التصريف للمتغيرات في مساحة أسماء معينة.

الطرق

new(\%constants)

تقوم طريقة البناء new() بإنشاء وإرجاع مرجع لكائن Template::Namespace::Constants جديد. هذا ينشئ مخزنًا داخليًا لتخزين تعريفات المتغيرات الثابتة المقدمة كوسائط.

my $handler = Template::Namespace::Constants->new({
    pi => 3.14,
    e  => 2.718,
});

ident(\@ident)

طريقة يتم استدعاؤها لحل معرف متغير إلى شكل مترجم. في هذه الحالة، تقوم الطريقة بجلب قيمة الثابت المقابلة من مخزنها الداخلي وتعيدها.
