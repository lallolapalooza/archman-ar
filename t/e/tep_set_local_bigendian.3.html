tep_set_local_bigendian(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_is_bigendian, tep_is_local_bigendian, tep_set_local_bigendian - الحصول / تعيين ترتيب البايتات للآلة المحلية.

الملخص

#include <event-parse.h>
enum tep_endian {
        TEP_LITTLE_ENDIAN = 0,
        TEP_BIG_ENDIAN
};
int tep_is_bigendian(void);
bool tep_is_local_bigendian(struct tep_handle *tep);
void tep_set_local_bigendian(struct tep_handle *tep, enum tep_endian endian);

الوصف

تقوم الدالة tep_is_bigendian() بالحصول على ترتيب البايتات للآلة التي تنفذ الدالة.

تقوم الدالة tep_is_local_bigendian() بالحصول على ترتيب البايتات للآلة المحلية، والتي تم حفظها في معالج tep. الوسيط tep هو سياق محلل أحداث التتبع. واجهة برمجة التطبيقات هذه أسرع قليلاً من tep_is_bigendian()، حيث إنها تُرجع ترتيب البايتات المخزن مؤقتًا للآلة المحلية بدلاً من التحقق منه في كل مرة.

تقوم الدالة tep_set_local_bigendian() بتعيين ترتيب البايتات للآلة المحلية في معالج tep. الوسيط tep هو سياق محلل أحداث التتبع. الوسيط endian هو ترتيب البايتات:

        TEP_LITTLE_ENDIAN - الآلة بترتيب البايتات الأصغر،
        TEP_BIG_ENDIAN - الآلة بترتيب البايتات الأكبر.

القيمة المرجعة

تُرجع الدالة tep_is_bigendian() قيمة غير صفرية إذا كان ترتيب البايتات للآلة التي تنفذ التعليمات البرمجية هو ترتيب البايتات الأكبر وصفر بخلاف ذلك.

تُرجع الدالة tep_is_local_bigendian() القيمة true، إذا كان ترتيب البايتات للآلة المحلية، المحفوظ في معالج tep، هو ترتيب البايتات الأكبر، أو false بخلاف ذلك.

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        if (tep_is_bigendian())
                tep_set_local_bigendian(tep, TEP_BIG_ENDIAN);
        else
                tep_set_local_bigendian(tep, TEP_LITTLE_ENDIAN);
...
        if (tep_is_local_bigendian(tep))
                printf("This machine you are running on is bigendian\n");
        else
                printf("This machine you are running on is little endian\n");
