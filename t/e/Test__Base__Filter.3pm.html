Test__Base__Filter(3pm)

الحزمة: perl-test-base

التراخيص: GPL, PerlArtistic

Test::Base::Filter(3) وثائق المستخدم من مساهمي بيرل Test::Base::Filter(3)

الاسم

Test::Base::Filter - فئة التصفية الافتراضية لـ Test::Base

الملخص

package MyTestSuite;
use Test::Base -Base;
... رموز اختبار قابلة لإعادة الاستخدام ...
package MyTestSuite::Filter;
use Test::Base::Filter -Base;
sub my_filter1 {
    ...
}

الوصف

التصفية هي المفتاح لكتابة اختبارات فعالة تعتمد على البيانات مع Test::Base. Test::Base::Filter هي فئة تحتوي على مجموعة افتراضية كبيرة من عوامل التصفية العامة. يمكنك بسهولة إنشاء فئة فرعية لها لإضافة/تجاوز الوظائف.

عوامل التصفية

هذه قائمة بعوامل التصفية القياسية الافتراضية (بالترتيب الأبجدي):

"append"
list => list

إلحاق سلسلة نصية بكل عنصر من عناصر القائمة.

--- numbers lines chomp append=-#\n join
one
two
three
"array"
list => scalar

تحويل قائمة قيم إلى مرجع مصفوفة مجهول.

"base64_decode"
scalar => scalar

فك ترميز بيانات base64. مفيد للاختبارات الثنائية.

"base64_encode"
scalar => scalar

ترميز بيانات base64. مفيد للاختبارات الثنائية.

"chomp"
list => list

إزالة السطر الجديد الأخير من كل قيمة سلسلة نصية في قائمة.

"chop"

list => list

إزالة الحرف الأخير من كل قيمة سلسلة نصية في قائمة.
"dumper"
scalar => list

أخذ بنية بيانات (يفترض أنها من عامل تصفية آخر مثل eval) واستخدام Data::Dumper لتركها بشكل موحد.

"escape"
scalar => scalar

فك ترميز جميع الأحرف المفسرة بشرطة مائلة عكسية.

"eval"
scalar => list

تشغيل أمر "eval" الخاص بـ Perl على البيانات واستخدام القيمة المرجعة كبيانات.

"eval_all"
scalar => list

تشغيل أمر "eval" الخاص بـ Perl على البيانات وإرجاع قائمة من 4 قيم:

1) قيمة الإرجاع
2) الخطأ في $@
3) STDOUT الملتقطة
4) STDERR الملتقطة
"eval_stderr"
scalar => scalar

تشغيل أمر "eval" الخاص بـ Perl على البيانات وإرجاع STDERR الملتقطة.

"eval_stdout"
scalar => scalar

تشغيل أمر "eval" الخاص بـ Perl على البيانات وإرجاع STDOUT الملتقطة.

"exec_perl_stdout"
list => scalar

يتم كتابة كود Perl المدخل إلى ملف مؤقت وتشغيله. يتم التقاط STDOUT وإرجاعها.

"flatten"
scalar => list

يأخذ مرجع hash أو array ويفلته إلى قائمة.

"get_url"
scalar => scalar

يتم إزالة السطر الجديد من النص ويعتبر عنوان URL. ثم يتم استخدام LWP::Simple::get لجلب محتويات عنوان URL.

"hash"
list => scalar

تحويل قائمة من أزواج المفتاح/القيمة إلى مرجع hash مجهول.

"head[=number]"
list => list

يأخذ قائمة ويرجع عدد العناصر من مقدمتها. العدد الافتراضي هو واحد.

"join"
list => scalar

ضم قائمة من السلاسل النصية إلى قيمة واحدة.

"Join"
ضم قائمة السلاسل النصية داخل قائمة من مراجع المصفوفات وإرجاع السلاسل النصية بدلاً من مراجع المصفوفات.
"lines"
scalar => list

تقسيم البيانات إلى مصفوفة مجهولة من الأسطر. كل سطر (باستثناء ربما الأخير إذا كان عامل التصفية "chomp" هو الأول) سيكون له سطر جديد في النهاية.

"norm"
scalar => scalar

تطبيع البيانات. تغيير نهايات الأسطر غير Unix إلى نهايات أسطر Unix.

"prepend=string"
list => list

إضافة سلسلة نصية في بداية كل سلسلة نصية في قائمة.

"read_file"
scalar => scalar

قراءة الملف المسمى بالمحتوى الحالي وإرجاع محتوى الملف.

"regexp[=xism]"
scalar => scalar

سيقوم عامل التصفية "regexp" بتحويل قسم البيانات الخاص بك إلى كائن تعبير نمطي. يمكنك تمرير علامات إضافية بعد علامة يساوي.

إذا كان النص يحتوي على أكثر من سطر واحد ولم يتم تحديد علامات، فيتم افتراض علامات 'xism'.

"reverse"
list => list

عكس عناصر القائمة.

"Reverse"
list => list

عكس قائمة السلاسل النصية داخل قائمة من مراجع المصفوفات.

"slice=x[,y]"
list => list

يرجع العنصر رقم x إلى العنصر رقم y من القائمة.

"sort"
list => list

فرز عناصر القائمة بترتيب الفرز الحرفي.

"Sort"
list => list

فرز قائمة السلاسل النصية داخل قائمة من مراجع المصفوفات.

"split[=string|pattern]"
scalar => list

تقسيم سلسلة نصية إلى قائمة. يأخذ سلسلة نصية اختيارية أو تعبير نمطي كمعامل. الافتراضي هو s+. نفس "split" الخاص بـ Perl.

"Split[=string|pattern]"
list => list

تقسيم كل سلسلة نصية في قائمة وتحويلها إلى مراجع مصفوفات.

"strict"
scalar => scalar

إضافة السلسلة النصية التالية في البداية:

use strict;
use warnings;

إلى نص الكتلة.

"tail[=number]"
list => list

إرجاع عدد من العناصر من نهاية القائمة. العدد الافتراضي هو واحد.

"trim"
list => list

إزالة الأسطر الفارغة الإضافية من بداية ونهاية البيانات. يسمح هذا لك بفصل بيانات الاختبار بصريًا باستخدام الأسطر الفارغة.

"unchomp"
list => list

إضافة سطر جديد إلى كل قيمة سلسلة نصية في قائمة.

"write_file[=filename]"
scalar => scalar

كتابة محتويات القسم إلى الملف المسمى. إرجاع اسم الملف.

"yaml"
scalar => list

تطبيق دالة YAML::Load على كتلة البيانات واستخدام البنية الناتجة. يتطلب YAML.pm.
