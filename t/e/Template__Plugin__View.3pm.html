Template__Plugin__View(3pm)

الحزمة: perl-template-toolkit

التراخيص: PerlArtistic

Template::Plugin::View(3) وثائق مساهمة المستخدم من Perl Template::Plugin::View(3)

الاسم

Template::Plugin::View - إضافة لإنشاء طرق عرض (Template::View)

الملخص

[% USE view(
        prefix = 'splash/'          # بادئة/لاحقة القالب
        suffix = '.tt2'
        bgcol  = '#ffffff'          # وأي متغيرات أخرى تهتم بتعريفها كبيانات وصفية لطريقة العرض،
        style  = 'Fancy HTML'       # بما في ذلك البيانات المعقدة والتعبيرات
        items  = [ foo, bar.baz ]
        foo    = bar ? baz : x.y.z
%]
[% view.title %]                    # الوصول إلى البيانات الوصفية لطريقة العرض
[% view.header(title = 'Foo!') %]   # "طرق" العرض تعالج الكتل أو القوالب مع إضافة البادئة/اللاحقة

الوصف

تنشئ وحدة الإضافة هذه كائنات Template::View. طرق العرض هي ميزة تجريبية وقد تتغير في المستقبل القريب. في الوقت الحالي، يرجى الرجوع إلى Template::View لمزيد من المعلومات.
