Template__Plugin__Date(3pm)

الحزمة: perl-template-toolkit

التراخيص: PerlArtistic

Template::Plugin::Date(3) وثائق مساهمة المستخدم من Perl Template::Plugin::Date(3)

الاسم

Template::Plugin::Date - مكون إضافي لإنشاء سلاسل تاريخ منسقة

الملخص

[% USE date %]
# استخدام الوقت الحالي والتنسيق الافتراضي
[% date.format %]
# تحديد الوقت كثوانٍ منذ الحقبة
# أو كسلسلة 'h:m:s d-m-y' أو 'y-m-d h:m:s'
[% date.format(960973980) %]
[% date.format('4:20:36 21/12/2000') %]
[% date.format('2000/12/21 4:20:36') %]
# تحديد التنسيق
[% date.format(mytime, '%H:%M:%S') %]
# تحديد اللغة المحلية
[% date.format(date.now, '%a %d %b %y', 'en_GB') %]
# معلمات مسماة
[% date.format(mytime, format = '%H:%M:%S') %]
[% date.format(locale = 'en_GB') %]
[% date.format(time       = date.now,
               format     = '%H:%M:%S',
               locale     = 'en_GB'
               use_offset = 1) %]
# تحديد التنسيق الافتراضي للمكون الإضافي
[% USE date(format = '%H:%M:%S', locale = 'de_DE') %]
[% date.format %]
...

الوصف

يوفر المكون الإضافي "Date" طريقة سهلة لإنشاء سلاسل زمنية وتاريخ منسقة عن طريق تفويضها إلى روتين strftime() الخاص بـ "POSIX".

يمكن تحميل المكون الإضافي عبر توجيه USE المألوف.

[% USE date %]

ينشئ هذا كائن مكون إضافي بالاسم الافتراضي '"date"'. يمكن تحديد اسم بديل على النحو التالي:

[% USE myname = date %]

يوفر المكون الإضافي طريقة format() التي تقبل قيمة وقت، وسلسلة تنسيق، واسم لغة محلية. جميع هذه المعلمات اختيارية مع استخدام وقت النظام الحالي، والتنسيق الافتراضي ('"%H:%M:%S %d-%b-%Y"') واللغة المحلية الحالية على التوالي، إذا لم يتم تعريفها. يمكن تحديد القيم الافتراضية للوقت و/أو التنسيق و/أو اللغة المحلية كمعلمات مسماة في توجيه "USE".

[% USE date(format = '%a %d-%b-%Y', locale = 'fr_FR') %]

عند استدعائها بدون أي معلمات، تعيد طريقة format() سلسلة تمثل وقت النظام الحالي، يتم تنسيقها بواسطة strftime() وفقًا للتنسيق الافتراضي وللغة المحلية الافتراضية (والتي قد لا تكون الحالية، إذا تم تعيين اللغة المحلية في توجيه "USE").

[% date.format %]

يسمح المكون الإضافي بتحديد وقت/تاريخ كثوانٍ منذ الحقبة، كما تعيده time().

آخر تعديل للملف: [% date.format(filemod_time) %]

يمكن أيضًا تحديد الوقت/التاريخ كسلسلة بالشكل "h:m:s d/m/y" أو "y/m/d h:m:s". يمكن استخدام أي من الأحرف : / - أو المسافة للفصل بين الحقول.

[% USE day = date(format => '%A', locale => 'en_GB') %]
[% day.format('4:20:00 9-13-2000') %]

المخرجات:

Tuesday

يمكن أيضًا تمرير سلسلة تنسيق إلى طريقة format()، ويمكن أن يتبعها تحديد اللغة المحلية.

[% date.format(filemod, '%d-%b-%Y') %]
[% date.format(filemod, '%d-%b-%Y', 'en_GB') %]

تسمح المعلمة الرابعة بإجبار الإخراج بتوقيت غرينتش (GMT)، في حالة إدخال ثوانٍ منذ الحقبة:

[% date.format(filemod, '%d-%b-%Y', 'en_GB', 1) %]

لاحظ أنه في هذه الحالة، إذا لم يكن التوقيت المحلي هو توقيت غرينتش، فإن تحديد '%Z' (المنطقة الزمنية) أيضًا في معلمة التنسيق سيؤدي إلى نتيجة مضللة للغاية.

للحفاظ على التوافق الرجعي، يتطلب استخدام العنصر النائب %z في سلسلة التنسيق (لإخراج إزاحة UTC) حاليًا تعيين المعلمة "use_offset" إلى قيمة صحيحة. يمكن أيضًا تمرير هذه المعلمة كمعلمة خامسة لـ format (لكن السابقة ستكون أوضح على الأرجح).

يمكن تسمية أي من هذه المعلمات أو جميعها. يجب أن تكون المعلمات الموضعية دائمًا بالترتيب "($time, $format, $locale)".

[% date.format(format => '%H:%M:%S') %]
[% date.format(time => filemod, format => '%H:%M:%S') %]
[% date.format(mytime, format => '%H:%M:%S') %]
[% date.format(mytime, format => '%H:%M:%S', locale => 'fr_FR') %]
[% date.format(mytime, format => '%H:%M:%S', gmt => 1) %]
...إلخ...

تعيد طريقة now() وقت النظام الحالي كثوانٍ منذ الحقبة.

[% date.format(date.now, '%A') %]

يمكن استخدام طريقة calc() لإنشاء واجهة لوحدة "Date::Calc" (إذا كانت مثبتة على نظامك).

[% calc = date.calc %]
[% calc.Monday_of_Week(22, 2001).join('/') %]

يمكن استخدام طريقة manip() لإنشاء واجهة لوحدة "Date::Manip" (إذا كانت مثبتة على نظامك).

[% manip = date.manip %]
[% manip.UnixDate("Noon Yesterday","%Y %b %d %H:%M") %]

المؤلفون

كتب تييري-ميشيل بارال المكون الإضافي الأصلي.

قدم آندي واردلي بعض الإصلاحات/التحسينات الطفيفة، وسكربت اختبار، وتوثيق.

نسخ مارك دي ميلز "Date::Manip" من المكون الإضافي الفرعي "Date::Calc".
