Template__Plugin__File(3pm)

الحزمة: perl-template-toolkit

التراخيص: PerlArtistic

Template::Plugin::File(3) وثائق مساهمة من Perl Template::Plugin::File(3)

الاسم

إضافة توفر معلومات حول الملفات

الملخص

[% USE File(filepath) %]
[% File.path %]         # المسار الكامل
[% File.name %]         # اسم الملف
[% File.dir %]          # الدليل

الوصف

توفر هذه الإضافة تجريدًا لملف. يمكن استخدامها للحصول على تفاصيل حول الملفات في نظام الملفات، أو لتمثيل ملفات مجردة (مثل عند إنشاء صفحة فهرس) قد تكون موجودة أو لا في نظام ملفات.

يجب تحديد اسم ملف أو مسار كوسيط للمنشئ. على سبيل المثال:

[% USE File('foo.html') %]
[% USE File('foo/bar/baz.html') %]
[% USE File('/foo/bar/baz.html') %]

يجب أن يوجد الملف في نظام الملفات الحالي (إلا إذا تم تمكين الخيار "nostat"، انظر أدناه) كملف مطلق عند تحديده ببادئة "/" مثل "/foo/bar/baz.html"، وإلا فسيكون ملفًا نسبيًا للدليل الحالي. يقوم المنشئ بتنفيذ stat() على الملف ويوفر 13 عنصرًا يتم إرجاعها كعناصر للإضافة:

dev ino mode nlink uid gid rdev size
atime mtime ctime blksize blocks

على سبيل المثال:

[% USE File('/foo/bar/baz.html') %]
[% File.mtime %]
[% File.mode %]
...

بالإضافة إلى ذلك، يتم تعيين العناصر "user" و "group" بأسماء المستخدمين والمجموعات المقابلة التي تم الحصول عليها عبر استدعاءات getpwuid() و getgrgid() للملف "uid" و "gid" على التوالي. في أنظمة Windows 32 حيث getpwuid() و getgrgid() غير متوفرين، تكون هذه القيم غير معرفة.

[% USE File('/tmp/foo.html') %]
[% File.uid %]      # مثال: 500
[% File.user %]     # مثال: abw

يمكن تعطيل البحث عن المستخدم/المجموعة هذا عن طريق تعيين الخيار "noid".

[% USE File('/tmp/foo.html', noid=1) %]
[% File.uid %]      # مثال: 500
[% File.user %]     # لا شيء

سيتم تعيين العلم "isdir" إذا كان الملف دليلًا.

[% USE File('/tmp') %]
[% File.isdir %]    # 1

إذا فشل stat() على الملف (على سبيل المثال، الملف غير موجود، أذونات غير صحيحة، إلخ)، فسيقوم المنشئ بإطلاق استثناء "File". يمكن التقاط هذا داخل كتلة "TRY...CATCH".

[% TRY %]
   [% USE File('/tmp/myfile') %]
   الملف موجود!
[% CATCH File %]
   خطأ: [% error.info %]
[% END %]

ملاحظة: يشير تنسيق حالة نوع الاستثناء، "File"، إلى أنه تم إطلاق استثناء بواسطة الإضافة "File"، للتمييز بينه وبين استثناء "file" عادي تم إطلاقه بواسطة Template Toolkit.

ملاحظة: يمكن أيضًا الإشارة إلى الإضافة "File" باسم "file" بالأحرف الصغيرة. ومع ذلك، فإن الاستثناءات دائمًا من النوع "File"، بغض النظر عن حالة أحرف اسم الإضافة المستخدم.

[% USE file('foo.html') %]
[% file.mtime %]

كما هو الحال مع أي إضافة أخرى في Template Toolkit، يمكن تحديد اسم بديل للكائن الذي تم إنشاؤه.

[% USE foo = file('foo.html') %]
[% foo.mtime %]

يمكن تحديد الخيار "nostat" لمنع المنشئ الإضافة من إجراء stat() على الملف المحدد. في هذه الحالة، لا يحتاج الملف إلى الوجود في نظام الملفات، ولن يحاول التحقق من وجوده، ولن يتم إطلاق استثناء إذا لم يكن موجودًا. سيتم تعيين قيم العناصر التي يتم إرجاعها عادةً بواسطة stat() لتكون فارغة.

[% USE file('/some/where/over/the/rainbow.html', nostat=1)
[% file.mtime %]     # لا شيء

الأساليب

جميع الإضافات "File"، بغض النظر عن خيار "nostat"، لديها عدد من العناصر المتعلقة بالمسار الأصلي المحدد.

path

المسار الكامل الأصلي المحدد للمنشئ.

[% USE file('/foo/bar.html') %]
[% file.path %]     # /foo/bar.html

name

اسم الملف بدون أدلة سابقة.

[% USE file('/foo/bar.html') %]
[% file.name %]     # bar.html

dir

عنصر الدليل في المسار، بدون اسم الملف.

[% USE file('/foo/bar.html') %]
[% file.name %]     # /foo

ext

امتداد الملف، إذا كان موجودًا، يظهر في نهاية المسار، ولا يشمل الامتداد.

[% USE file('/foo/bar.html') %]
[% file.ext %]      # html

home

يحتوي على سلسلة بالشكل "../.." والتي تمثل المسار إلى الدليل الجذر للملف.

[% USE file('bar.html') %]
[% file.home %]     # لا شيء
[% USE file('foo/bar.html') %]
[% file.home %]     # ..
[% USE file('foo/bar/baz.html') %]
[% file.home %]     # ../..

root

يمكن تحديد العنصر "root" كوسيط للمنشئ، مما يشير إلى دليل جذر يقع فيه الملف المسمى. يكون فارغًا بخلاف ذلك.

[% USE file('foo/bar.html', root='/tmp') %]
[% file.root %]     # /tmp

abs

يرجع المسار المطلق للملف عن طريق بناء مسار من الخيارات "root" و "path".

[% USE file('foo/bar.html', root='/tmp') %]
[% file.path %]     # foo/bar.html
[% file.root %]     # /tmp
[% file.abs %]      # /tmp/foo/bar.html

rel(path)

يرجع مسارًا نسبيًا من الملف الحالي إلى مسار آخر محدد كوسيط. يتم بناؤه عن طريق ربط المسار بعنصر "home".

[% USE file('foo/bar/baz.html') %]
[% file.rel('wiz/waz.html') %]      # ../../wiz/waz.html

أمثلة

[% USE file('/foo/bar/baz.html') %]
[% file.path  %]      # /foo/bar/baz.html
[% file.dir   %]      # /foo/bar
[% file.name  %]      # baz.html
[% file.home  %]      # ../..
[% file.root  %]      # ''
[% file.abs   %]      # /foo/bar/baz.html
[% file.ext   %]      # html
[% file.mtime %]      # 987654321
[% file.atime %]      # 987654321
[% file.uid   %]      # 500
[% file.user  %]      # abw
[% USE file('foo.html') %]
[% file.path %]           # foo.html
[% file.dir  %]       # ''
[% file.name %]           # foo.html
[% file.root %]       # ''
[% file.home %]       # ''
[% file.abs  %]       # foo.html
[% USE file('foo/bar/baz.html') %]
[% file.path %]           # foo/bar/baz.html
[% file.dir  %]       # foo/bar
[% file.name %]           # baz.html
[% file.root %]       # ''
[% file.home %]       # ../..
[% file.abs  %]       # foo/bar/baz.html
[% USE file('foo/bar/baz.html', root='/tmp') %]
[% file.path %]           # foo/bar/baz.html
[% file.dir  %]       # foo/bar
[% file.name %]           # baz.html
[% file.root %]       # /tmp
[% file.home %]       # ../..
[% file.abs  %]       # /tmp/foo/bar/baz.html
# حساب مسارات ملفات أخرى نسبية لهذا الملف وجذره
[% USE file('foo/bar/baz.html', root => '/tmp/tt2') %]
[% file.path('baz/qux.html') %]         # ../../baz/qux.html
[% file.dir('wiz/woz.html')  %]     # ../../wiz/woz.html
