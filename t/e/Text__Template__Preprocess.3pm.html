Text__Template__Preprocess(3pm)

الحزمة: perl-text-template

التراخيص: PerlArtistic, GPL

Text::Template::Preprocess(3) وثائق Perl من مساهمة المستخدم Text::Template::Preprocess(3)

الاسم

Text::Template::Preprocess - توسيع نص القالب باستخدام Perl مضمن

الإصدار

الإصدار 1.61

ملخص

use Text::Template::Preprocess;
my $t = Text::Template::Preprocess->new(...);  # مطابق تمامًا لـ Text::Template
# املأ القالب، ولكن قم بمعالجة كل جزء من الشيفرة باستخدام pp().
my $result = $t->fill_in(..., PREPROCESSOR => \&pp);
my $old_pp = $t->preprocessor(\&new_pp);

الوصف

"Text::Template::Preprocess" يوفر خيار "PREPROCESSOR" جديد لـ "fill_in". إذا تم توفير خيار "PREPROCESSOR"، فيجب أن يكون مرجعًا لوظيفة معالجة مسبقة. عند ملء قالب، ستستخدم "Text::Template::Preprocessor" هذه الوظيفة لمعالجة جزء البرنامج مسبقًا قبل تقييم الشيفرة.

سيتم استدعاء وظيفة المعالجة المسبقة بشكل متكرر، مرة واحدة لكل جزء برنامج. سيكون جزء البرنامج في $_. يجب على الوظيفة تعديل محتويات $_ والعودة. ستقوم "Text::Template::Preprocess" بعد ذلك بتنفيذ محتويات $_ وإدراج النتيجة في الجزء المناسب من القالب.

"Text::Template::Preprocess" تدعم كائنات الأداة أيضًا طريقة مساعدة، preprocessor()، والتي تقوم بتعيين معالج مسبق جديد للكائن. يستخدم هذا المعالج المسبق لجميع الاستدعاءات اللاحقة لـ "fill_in" ما لم يتم تجاوزه بواسطة خيار "PREPROCESSOR" صريح. preprocessor() تعيد وظيفة المعالج المسبق الافتراضية السابقة، أو غير محددة إذا لم تكن هناك وظيفة. عند استدعائها بدون وسائط، preprocessor() تعيد وظيفة المعالج المسبق الافتراضية الحالية للكائن دون تغييرها.

في جميع الجوانب الأخرى، "Text::Template::Preprocess" مطابق تمامًا لـ "Text::Template".

لماذا؟

غرض محتمل واحد: إذا كانت ملفاتك تحتوي على الكثير من JavaScript، مثل هذا:

نص عادي هنا...
{ شيفرة perl }
<script language=JavaScript>
      if (br== "n3") { 
          // الخ.
      }
</script>
{ شيفرة perl أخرى }
نص عادي آخر...

لا تريد أن تربك "Text::Template" الأقواس المعقوفة في برنامج JavaScript كشيفرة Perl قابلة للتنفيذ. استراتيجية واحدة:

sub quote_scripts {
  s(<script(.*?)</script>)(q{$1})gsi;
}

ثم استخدم "PREPROCESSOR => \&quote_scripts". هذا سيحول
