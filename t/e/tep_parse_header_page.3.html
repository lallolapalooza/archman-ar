tep_parse_header_page(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_parse_header_page - يقوم بتحليل البيانات المخزنة في صفحة الرأس.

ملخص

#include <event-parse.h>
int tep_parse_header_page(struct tep_handle *tep, char *buf, unsigned long size, int long_size);

الوصف

تقوم الدالة tep_parse_header_page() بتحليل بيانات صفحة الرأس من buf، وتقوم بتهيئة tep، سياق محلل أحداث التتبع، بها. يتم نسخ المخزن المؤقت buf بالحجم size، ويُفترض أن يتم نسخه من tracefs/events/header_page.

بعض النواة القديمة لا تحتوي على معلومات صفحة الرأس، في هذه الحالة يمكن استدعاء الدالة tep_parse_header_page() مع size يساوي 0. يتم تهيئة سياق tep بالقيم الافتراضية. يمكن استخدام long_size في حالة الاستخدام هذه، لتعيين حجم عدد صحيح طويل ليتم استخدامه.

قيمة الإرجاع

تعيد الدالة tep_parse_header_page() القيمة 0 في حالة النجاح، أو -1 في حالة حدوث خطأ.

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *buf;
int size;
buf = read_file("/sys/kernel/tracing/events/header_page", &size);
if (tep_parse_header_page(tep, buf, size, sizeof(unsigned long)) != 0) {
        /* فشل في تحليل صفحة الرأس */
}
...
