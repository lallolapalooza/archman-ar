TERMINATOR(1) دليل Terminator TERMINATOR(1)

اسم

terminator - محاكيات طرفية متعددة من GNOME في نافذة واحدة

ملخص

terminator [خيارات]

وصف

توثق صفحة الدليل هذه Terminator، وهو تطبيق محاكي طرفي.

Terminator هو برنامج يسمح للمستخدمين بإعداد ترتيبات مرنة لمحاكيات طرفية GNOME. يهدف إلى أولئك الذين يرتبون عادةً الكثير من المحاكيات الطرفية بالقرب من بعضها البعض، لكنهم لا يرغبون في استخدام مدير نوافذ قائم على الإطارات.

خيارات

يتبع هذا البرنامج صيغة سطر الأوامر المعتادة في GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتم تضمين ملخص للخيارات أدناه.

-h, --help

عرض ملخص للخيارات.

-v, --version

عرض إصدار تثبيت Terminator.

-m, -M, --maximise, --maximize

البدء بنافذة مكبرة.

-f, --fullscreen

البدء بنافذة بملء الشاشة.

-b, --borderless

إرشاد مدير النوافذ لعدم عرض الحدود/التزيينات على نافذة Terminator (يعمل هذا بشكل جيد مع --maximise).

-H, --hidden

إخفاء نافذة Terminator افتراضيًا. يمكن تبديل رؤيتها باستخدام اختصار لوحة المفاتيح hide_window (Ctrl+Shift+Alt+A افتراضيًا).

-T FORCEDTITLE, --title=FORCEDTITLE

فرض استخدام اسم محدد لنافذة Terminator بدلاً من تحديثه ديناميكيًا بناءً على رغبات الصدفة الفرعية.

--geometry=GEOMETRY

تحديد الحجم والموضع المفضلين لنافذة Terminator؛ راجع X(7).

-e COMMAND, --command=COMMAND

تشغيل الأمر المحدد بدلاً من الصدفة الافتراضية أو الأمر المحدد في الملف الشخصي.
ملاحظة: إذا تم تشغيل Terminator كـ x-terminal-emulator، فإن -e يتصرف مثل -x، ويصبح الشكل الطويل --execute2=COMMAND.

-x COMMAND [ARGS], --execute=COMMAND [ARGS]

تشغيل بقية سطر الأوامر بدلاً من الصدفة الافتراضية أو الأمر المحدد في الملف الشخصي.

--working-directory=DIR

تعيين دليل العمل للمحاكي الطرفي.

-g FILE, --config=FILE

استخدام الملف المحدد للتكوين.

-r ROLE, --role=ROLE

تعيين خاصية WM_WINDOW_ROLE مخصصة للنافذة.

-l LAYOUT, --layout=LAYOUT

بدء Terminator بتخطيط محدد. الوسيط هنا هو اسم تخطيط محفوظ.

-s LAYOUT, --select-layout=LAYOUT

فتح نافذة مشغل التخطيط بدلاً من المحاكي الطرفي العادي.

-p, --profile=PROFILE

استخدام ملف شخصي مختلف كافتراضي.

-i, --icon=FORCEDICON

تعيين أيقونة مخصصة للنافذة (حسب الملف أو الاسم)

-u, --no-dbus

تعطيل DBus.

-d, --debug

تمكين مخرجات التصحيح (يرجى استخدام هذا عند الإبلاغ عن الأخطاء). يمكن تحديد هذا مرتين لتمكين خادم تصحيح Python مدمج.

--debug-classes=DEBUG_CLASSES

إذا تم تحديد هذا كقائمة مفصولة بفواصل، فسيتم طباعة مخرجات التصحيح فقط من الفئات المحددة.

--debug-methods=DEBUG_METHODS

إذا تم تحديد هذا كقائمة مفصولة بفواصل، فسيتم طباعة مخرجات التصحيح فقط من الوظائف المحددة. إذا تم تحديد هذا بالإضافة إلى --debug-classes، فسيتم عرض تقاطع القائمتين فقط.

--new-tab

إذا تم تحديد هذا وكان Terminator قيد التشغيل بالفعل، فسيتم استخدام DBus لإنشاء علامة تبويب جديدة في نافذة Terminator الأولى.

--toggle-visibility

إذا تم تحديد هذا وكان Terminator قيد التشغيل بالفعل، فسيتم استخدام DBus لتبديل رؤية نافذة Terminator. يمكن استخدامه تحت Wayland لاستبدال اختصار لوحة المفاتيح للإخفاء.

اختصارات لوحة المفاتيح

يمكن استخدام اختصارات لوحة المفاتيح الافتراضية التالية للتحكم في Terminator. يمكن تغيير معظم اختصارات لوحة المفاتيح هذه في التفضيلات.

F1

تشغيل الدليل الكامل بتنسيق HTML.

الإنشاء والتدمير

تتعلق العناصر التالية بإنشاء وتدمير المحاكيات الطرفية.

Ctrl+Shift+O

تقسيم المحاكيات الطرفية أفقياً (Horizontally).

Ctrl+Shift+E

تقسيم المحاكيات الطرفية عمودياً (Vertically).

Ctrl+Shift+T

فتح علامة تبويب جديدة (tab).

Ctrl+Shift+I

فتح نافذة جديدة.
(ملاحظة: على عكس الإصدارات السابقة، هذه النافذة جزء من نفس عملية Terminator)

Super+I

تشغيل عملية Terminator جديدة.

Alt+L

فتح مشغل التخطيط (layout).

Ctrl+Shift+W

إغلاق المحاكي الطرفي الحالي.

Ctrl+Shift+Q

إغلاق النافذة الحالية.

التنقل

تتعلق العناصر التالية بالانتقال بين المحاكيات الطرفية وحولها.

Alt+Up

الانتقال إلى المحاكي الطرفي أعلى الحالي.

Alt+Down

الانتقال إلى المحاكي الطرفي أسفل الحالي.

Alt+Left

الانتقال إلى المحاكي الطرفي يسار الحالي.

Alt+Right

الانتقال إلى المحاكي الطرفي يمين الحالي.

Ctrl+PageDown

الانتقال إلى علامة التبويب التالية.

Ctrl+PageUp

الانتقال إلى علامة التبويب السابقة.

Ctrl+Shift+N أو Ctrl+Tab

الانتقال إلى المحاكي الطرفي التالي داخل نفس علامة التبويب.

Ctrl+Shift+P أو Ctrl+Shift+Tab

الانتقال إلى المحاكي الطرفي السابق داخل نفس علامة التبويب.

التنظيم

تتعلق العناصر التالية بترتيب وتغيير حجم المحاكيات الطرفية.

Ctrl+Shift+Right

تحريك شريط السحب الرئيسي يمينًا.

Ctrl+Shift+Left

تحريك شريط السحب الرئيسي يسارًا.

Ctrl+Shift+Up

تحريك شريط السحب الرئيسي للأعلى.

Ctrl+Shift+Down

تحريك شريط السحب الرئيسي للأسفل.

Super+R

تدوير المحاكيات الطرفية في اتجاه عقارب الساعة.

Super+Shift+R

تدوير المحاكيات الطرفية عكس اتجاه عقارب الساعة.

Ctrl+Shift+PageDown

تبديل موضع علامة التبويب مع علامة التبويب التالية.

Ctrl+Shift+PageUp

تبديل موضع علامة التبويب مع علامة التبويب السابقة.

السحب والإفلات

يمكن تعديل التخطيط عن طريق تحريك المحاكيات الطرفية بالسحب والإفلات. لبدء سحب محاكي طرفي، انقر مع الاستمرار على شريط العنوان الخاص به. بدلاً من ذلك، اضغط مع الاستمرار على Ctrl، وانقر مع الاستمرار على زر الماوس الأيمن. ثم، **حرر Ctrl**. يمكنك الآن سحب المحاكي الطرفي إلى النقطة في التخطيط التي تريد أن يكون فيها. سيتم تمييز المنطقة التي سيتم إدراج المحاكي الطرفي فيها.

التركيز

تتعلق العناصر التالية بالمساعدة في التركيز على محاكي طرفي معين.

F11

تبديل النافذة إلى وضع ملء الشاشة.

Ctrl+Shift+X

التبديل بين عرض جميع المحاكيات الطرفية وعرض المحاكي الطرفي الحالي فقط.

terminator(1) — Arch Linux manual pages

NAME

terminator

multiple command line terminals

SYNOPSIS

terminator [options]

DESCRIPTION

Terminator is a tool that duplicates windows to be arranged in a grid by using the power of Xinerama, the GNOME workspace, and the K Desktop Environment.

It is designed to be easily configurable and flexible.

Terminator can be configured from within the application via a preferences menu, or by editing the config file, ~/.config/terminator/config.

OPTIONS

Terminator supports the following command-line options:

--config config_file
Use the specified configuration file instead of the default one.
-n, --new-instance
Always start a new terminator instance.
-r, --maximise
Start maximised.
-m, --maximize
Start maximised.
-f, --fullscreen
Start in fullscreen mode.
-l, --layout layout_name
Start with the specified layout. See terminator_config(5) for more details on layouts.
-p, --profile profile_name
Start with the specified profile. See terminator_config(5) for more details on profiles.
-T, --title title
Set the window title.
-H, --hidden
Start hidden. See terminator_config(5) for more details.
-v, --version
Show program version.
-h, --help
Show help message.

KEYBINDINGS

The following are the default keybindings within Terminator. These can be changed in the preferences.

Window Management

Ctrl+Alt+T

New Terminal.

Ctrl+Alt+Shift+W

Close Window.

Ctrl+Shift+O

Split terminals horizontally.

Ctrl+Shift+E

Split terminals vertically.

Ctrl+Alt+Arrows

Navigate through terminals.

Ctrl+Shift+Arrows

Move through terminals.

Ctrl+Shift+R

Drag and drop terminals.

Ctrl+Alt+I

Switch input to the parent terminal.

Ctrl+Alt+N

Switch input to the next terminal.

Ctrl+Shift+W

Close terminal.

Ctrl+Shift+C

Close terminal.

Ctrl+Shift+Z

Toggle between showing all terminals and only showing a scaled version of the current one (zoom).

Ctrl+Shift+Alt+A

Hide the initial window. Note that this is a X11 global binding, and can only be bound once. On Wayland use window manager keyboard shortcuts to call terminator --toggle-visibility.

Grouping & Broadcasting

The following items relate to grouping and broadcasting.

Super+T

Group all terminals in the current tab so that any input sent to one of them goes to all of them.

Super+Shift+T

Remove grouping from all terminals in the current tab.

Super+G

Group all terminals so that any input sent to one of them goes to all of them.

Super+Shift+G

Remove grouping from all terminals.

Alt+A

Broadcast to all terminals.

Alt+G

Broadcast to grouped terminals.

Alt+O

Broadcast off.

Miscellaneous

The following items relate to miscellaneous terminal related functions.

Ctrl+Shift+C

Copy selected text to clipboard.

Ctrl+Shift+V

Paste clipboard text.

Ctrl+Shift+S

Toggle scrollbar.

Ctrl+Shift+F

Search within terminal scrollback.

Ctrl+Shift+R

Reset terminal state.

Ctrl+Shift+G

Reset terminal state and clear window.

Ctrl+Plus (+)

Increase font size.
Note: this may require you to press shift, depending on your keyboard.

Ctrl+Minus (-)

Decrease font size.
Note: this may require you to press shift, depending on your keyboard.

Ctrl+Zero (0)

Restore font size to original setting.

Ctrl+Alt+W

Rename window title.

Ctrl+Alt+A

Rename tab title.

Ctrl+Alt+X

Rename terminal title.

Super+1

Insert terminal number, i.e. 1 to 12.

Super+0

Insert padded terminal number, i.e. 01 to 12.
