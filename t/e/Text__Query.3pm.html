Text__Query(3pm)

الحزمة: perl-text-query

التراخيص: GPL, PerlArtistic

Text::Query(3) توثيق نصي مقدم من المستخدم Text::Query(3)

الاسم

Text::Query - إطار عمل لمعالجة الاستعلامات

التركيب

use Text::Query;

# المنشئ
$query = Text::Query->new([QSTRING] [OPTIONS]);
# التوابع
$query->prepare(QSTRING [OPTIONS]);
$query->match([TARGET]);
$query->matchscalar([TARGET]);

الوصف

توفر هذه الوحدة كائنًا يقارن مجموعة بيانات بتعبير استعلام.

تُترجم تعبيرات الاستعلام إلى شكل داخلي عند إنشاء كائن جديد أو عند استدعاء التابع "prepare"؛ لا يُعاد ترجمتها في كل مرة يتم فيها استدعاء التابع "match".

تستخدم الفئة التي توفرها هذه الوحدة أربع وحدات لمعالجة الاستعلام. محلل الاستعلام يحلل الاستعلام ويستدعي مُنشئ تعبير الاستعلام (الشكل الداخلي للاستعلام). يُستدعى المُحسِّن لتقليل تعقيد التعبير. المُحل يقوم بتطبيق التعبير على مجموعة بيانات.

توفر المحللات التالية:

Text::Query::ParseAdvanced
Text::Query::ParseSimple

توفر المُنشئات التالية:

Text::Query::BuildAdvancedString
Text::Query::BuildSimpleString

يوفر المُحل التالي:

Text::Query::SolveSimpleString
Text::Query::SolveAdvancedString

أمثلة

use Text::Query;
my $q=new Text::Query('hello and world',
                      -parse => 'Text::Query::ParseAdvanced',
                      -solve => 'Text::Query::SolveAdvancedString',
                      -build => 'Text::Query::BuildAdvancedString');
die "bad query expression" if not defined $q;
print if $q->match;
...
$q->prepare('goodbye or adios or ta ta',
            -litspace => 1,
            -case => 1);
#requires single space between the two ta's
if($q->match($line)) {
#doesn't match "Goodbye"
...
$q->prepare('"and" or "or"');
#quoting operators for literal match
...
$q->prepare('\\bintegrate\\b', -regexp => 1);
#won't match "disintegrated"

المُنشئ

new ([QSTRING] [OPTIONS])
هذا هو مُنشئ كائن Text::Query. إذا تم توفير "QSTRING"، فسيتم تجميعه إلى شكل داخلي.

يتم تمرير "OPTIONS" كأزواج مفتاح-قيمة. الخيارات المحتملة هي:

-parse - اسم وحدة المحلل. الافتراضي: Text::Query::ParseSimple.

-build - اسم وحدة المُنشئ. الافتراضي: Text::Query::Build.

-optimize - اسم وحدة المُحسِّن. الافتراضي: Text::Query::Optimize.

-solve - اسم وحدة المُحل. الافتراضي: Text::Query::Solve.

-mode - اسم مجموعة معدة مسبقًا من الوحدات لاستخدامها. الخيارات هي:
حاليا "simple_text" و "advanced_text".

تتم معالجة هذه الخيارات بواسطة التابع "configure".

يتم تمرير جميع الخيارات الأخرى إلى تابع المحلل "prepare". انظر صفحات الدليل ذات الصلة لوصف.

إذا لم يكن "QSTRING" محددًا، فلن يتم استدعاء التابع "prepare".

سيُلقي المنشئ خطأ إذا تم توفير "QSTRING" وكان به صيغة غير صالحة.

التوابع

configure ([OPTIONS])
يقوم بتعيين وحدات "parse"، "build"، "optimize" أو "solve". انظر وصف المنشئ.
prepare (QSTRING [OPTIONS])
يقوم بتجميع تعبير الاستعلام إلى شكل داخلي في "QSTRING" ويعين أي خيارات (نفس تلك الموجودة في المنشئ). يمكن استخدام "prepare" لتغيير تعبير الاستعلام والخيارات لكائن استعلام موجود. إذا لم يتم تحديد "OPTIONS"، فإن الخيارات التي تم تعيينها سابقًا بواسطة "prepare" ستظل قائمة.

يتم استدعاء المُحسِّن (-optimize) مع نتيجة المحلل (-parse). يستخدم المحلل المُنشئ (-build) لبناء الشكل الداخلي.

يعيد هذا التابع مرجعًا لكائن الاستعلام إذا كانت صيغة التعبير صالحة، أو سيُلقي خطأ إذا لم تكن كذلك.

match ([TARGET])
يستدعي تابع match لوحدة الحل (-solve).
matchscalar ([TARGET])
يستدعي تابع matchscalar لوحدة الحل (-solve).
