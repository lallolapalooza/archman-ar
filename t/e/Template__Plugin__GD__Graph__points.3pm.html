Template__Plugin__GD__Graph__points(3pm)

الحزمة: perl-template-gd

التراخيص: GPL, PerlArtistic

Template::Plugin::GD::Graph::points(3) توثيق مساهم من المستخدمين لبول Template::Plugin::GD::Graph::points(3)

الاسم

Template::Plugin::GD::Graph::points - إنشاء رسوم بيانية نقطية بمحاور وتسميات

الملخص

[% USE g = GD.Graph.points(x_size, y_size); %]

أمثلة

[% FILTER null; 
    data = [
        ["الأول","الثاني","الثالث","الرابع","الخامس","السادس","السابع", "الثامن", "التاسع"],
        [    5,   12,   24,   33,   19,    8,    6,    15,    21],
        [    1,    2,    5,    6,    3,  1.5,    2,     3,     4],
    ];
    USE my_graph = GD.Graph.points();
    my_graph.set(
            x_label => 'تسمية س',
            y_label => 'تسمية ص',
            title => 'رسم بياني نقطي',
            y_max_value => 40,
            y_tick_number => 8,
            y_label_skip => 2,
            legend_placement => 'RC',
            long_ticks => 1,
            marker_size => 6, 
            markers => [ 1, 7, 5 ],

            transparent => 0,
    );  
    my_graph.set_legend('واحد', 'اثنان');
    my_graph.plot(data).png | stdout(1);
   END; 
-%]

الوصف

توفر الإضافة GD.Graph.points واجهة لفئة GD::Graph::points المحددة بواسطة الوحدة GD::Graph. تسمح برسم مجموعة بيانات (س، ص) واحدة أو أكثر كنقاط، بالإضافة إلى المحاور والتسميات.

راجع GD::Graph لمزيد من التفاصيل.

المؤلف

كتب توماس بوتيل مكتبة GD للرسومات.

كتب لينكون دي. شتاين وحدات GD لبول التي تتصل بها.

كتب مارتين فيربورغن الوحدة GD::Graph.

كتب كريج بارات <craig@arraycomm.com> الإضافات الأصلية لـ GD لأداة القوالب (2001).

قام آندي واردلي <abw@cpan.org> باستخراجها من نواة TT إلى توزيع منفصل لـ TT الإصدار 2.15.
