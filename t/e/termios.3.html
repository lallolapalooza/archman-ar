man-pages(3)

NAME

man-pages - introduction to the Arch Linux man pages

LIBRARY

This is a meta-package, it doesn't provide any library.

SYNOPSIS

This package provides the manual pages for Arch Linux. These pages document the system calls, standard library functions, command-line utilities, and configuration files. You can access them using the man command.

DESCRIPTION

The man-pages package is a collection of manual pages for GNU/Linux systems. It includes detailed documentation for various aspects of the operating system. The manual pages are organized into sections, typically numbered 1 through 8, covering:

  • 1: Executable programs or shell commands
  • 2: System calls (functions provided by the kernel)
  • 3: Library calls (functions within program libraries)
  • 4: Special files (usually found in /dev)
  • 5: File formats and conventions
  • 6: Games
  • 7: Miscellaneous
  • 8: System administration commands (usually for root)
The Arch Linux manual pages are derived from the upstream Linux man-pages project and are integrated into the Arch Linux distribution. They are essential for understanding and using the system effectively.

RETURN VALUE

This is not applicable as it is a meta-package.

ATTRIBUTES

This is not applicable as it is a meta-package.

STANDARDS

The content of the man pages generally conforms to POSIX standards where applicable, but also documents Linux-specific features and extensions.

HISTORY

Manual pages have been a part of Unix-like systems since their early days. The Linux man-pages project aims to maintain and update these pages for the Linux kernel and its associated user-space components. This package integrates them into Arch Linux.

NOTES

To view a manual page, use the man command followed by the name of the command, function, or file. For example, to view the manual page for the ls command, you would type: man ls To view the manual page for the printf function (a library call), you would type: man 3 printf The section number is often important to distinguish between commands and library functions with the same name.

BUGS

Report bugs related to the content of the manual pages to the Arch Linux bug tracker or the upstream Linux man-pages project.

SEE ALSO

man(1), apropos(1), whatis(1), man-db(5)
