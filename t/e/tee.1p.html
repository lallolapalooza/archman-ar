TEE(1P) دليل مبرمج POSIX TEE(1P)

المقدمة

صفحة الدليل هذه جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

tee — نسخ الإدخال القياسي

ملخص

tee [-ai] [ملف...]

الوصف

يقوم الأداة المساعدة tee بنسخ الإدخال القياسي إلى الإخراج القياسي، مع إنشاء نسخة في ملف واحد أو أكثر. لا تقوم الأداة المساعدة tee بتخزين الإخراج مؤقتًا.

إذا لم يتم تحديد الخيار -a، فسيتم الكتابة فوق ملفات الإخراج (انظر القسم 1.1.1.4، قراءة الملف، الكتابة، والإنشاء.

الخيارات

ستلتزم الأداة المساعدة tee بالمجلد الأول من POSIX.1‐2017، القسم 12.2، إرشادات بناء جملة الأداة.

سيتم دعم الخيارات التالية:

-a
إلحاق الإخراج بالملفات.
-i
تجاهل إشارة SIGINT.

المعاملات

سيتم دعم المعاملات التالية:

ملف
مسار اسم ملف إخراج. إذا كان معامل ملف هو '-'، فسوف يشير إلى ملف يسمى -؛ لن تعامله التطبيقات على أنه يعني الإخراج القياسي. سيتم دعم معالجة 13 معامل ملف على الأقل.

الإدخال القياسي

يمكن أن يكون الإدخال القياسي من أي نوع.

ملفات الإدخال

لا يوجد.

متغيرات البيئة

ستؤثر متغيرات البيئة التالية على تنفيذ tee:

LANG
تقديم قيمة افتراضية لمتغيرات العولمة التي لم يتم تعيينها أو كانت فارغة. (راجع المجلد الأول من POSIX.1‐2017، القسم 8.2، متغيرات العولمة لتحديد أولويات متغيرات العولمة المستخدمة لتحديد قيم فئات اللغة.)
LC_ALL
إذا تم تعيينها إلى قيمة سلسلة غير فارغة، فقم بالكتابة فوق قيم جميع متغيرات العولمة الأخرى.
LC_CTYPE
تحديد اللغة لتفسير تسلسلات بايتات بيانات النص كأحرف (على سبيل المثال، أحرف ذات بايت واحد مقابل أحرف متعددة البايت في الوسائط).
LC_MESSAGES

تحديد اللغة التي يجب استخدامها للتأثير على تنسيق ومحتويات الرسائل التشخيصية المكتوبة إلى الخطأ القياسي.
NLSPATH
تحديد موقع كتالوجات الرسائل لمعالجة LC_MESSAGES.

الأحداث غير المتزامنة

افتراضي، باستثناء أنه إذا تم تحديد الخيار -i، فسيتم تجاهل SIGINT.

الإخراج القياسي

سيكون الإخراج القياسي نسخة من الإدخال القياسي.

الخطأ القياسي

سيتم استخدام الخطأ القياسي فقط للرسائل التشخيصية.

ملفات الإخراج

إذا تم تحديد أي معاملات ملف، فسيتم نسخ الإدخال القياسي إلى كل ملف مسماة.

الوصف الموسع

لا يوجد.

حالة الخروج

سيتم إرجاع قيم الخروج التالية:

 0
تم نسخ الإدخال القياسي بنجاح إلى جميع ملفات الإخراج.
>0
حدث خطأ.

عواقب الأخطاء

إذا فشلت عملية كتابة إلى أي معامل ملف تم فتحه بنجاح، فستستمر عمليات الكتابة إلى معاملات ملف أخرى تم فتحها بنجاح وإلى الإخراج القياسي، ولكن ستكون حالة الخروج غير صفرية. بخلاف ذلك، تنطبق الإجراءات الافتراضية المحددة في القسم 1.4، إجراءات الأداة الافتراضية.

الأقسام التالية إعلامية.

استخدام التطبيق

تُستخدم الأداة المساعدة tee عادةً في خط أنابيب، لإنشاء نسخة من إخراج أداة مساعدة معينة.

المعامل ملف اختياري من الناحية الفنية، ولكن tee ليست أكثر فائدة من cat عندما لا يتم تحديد أي شيء.

أمثلة

حفظ شكل وسيط غير مرتب للبيانات في خط أنابيب:

... | tee unsorted | sort > sorted

الأساس المنطقي

يعني متطلب التخزين المؤقت أن tee غير مسموح لها باستخدام كتابات ISO C القياسية ذات التخزين المؤقت الكامل أو التخزين المؤقت للأسطر. هذا لا يعني أن tee يجب أن تقوم بقراءات بايت واحد متبوعة بكتابات بايت واحد.

يجب ملاحظة أن الإصدارات المبكرة من BSD تتجاهل أي خيارات غير صالحة وتقبل '-' واحد كبديل لـ -i. كما أنها تطبع رسالة إذا فشلت في فتح ملف:

"tee: cannot access %s\n", <pathname>

تتجاهل التطبيقات التاريخية أخطاء الكتابة. هذا ليس مسموحًا به صراحةً بموجب هذا المجلد من POSIX.1‐2017.

تستخدم بعض التطبيقات التاريخية O_APPEND عند توفير وضع الإلحاق؛ يستخدم البعض الآخر دالة lseek() للانتقال إلى نهاية الملف بعد فتح الملف بدون O_APPEND. يتطلب هذا المجلد من POSIX.1‐2017 وظائف مكافئة لاستخدام O_APPEND؛ انظر القسم 1.1.1.4، قراءة الملف، الكتابة، والإنشاء.

اتجاهات مستقبلية

لا يوجد.

TEES(1P) User Commands TEES(1P)

NAME

tee - read from standard input and write to standard output and files

SYNOPSIS

tee [-a] [file...]

DESCRIPTION

The tee utility shall read standard input, then write standard output and each file in number of places similar to the action of a T-splitter in plumbing. The file arguments shall be opened for appending in the order they are specified on the command line.

The standard input is read until an end-of-file is reached. The data read may be from standard input, or from files specified in the command line, or from other commands via a pipe.

The -a option shall cause tee to append to the given files, rather than overwriting them.

If the -a option is not specified, then the contents of file are overwritten. If a specified file does not exist, then it is created.

When tee exits, all the files specified by the file arguments shall be closed.

If any write to a file argument fails, or if any read from standard input is terminated by a signal, tee shall exit with a non-zero exit status. Otherwise, when standard input reaches end-of-file and all data has been successfully written to standard output and all file arguments, tee shall exit with a zero exit status.

OPERANDS

The following operands are supported:

-a
Append to the given files, rather than overwriting them.
file...
A list of one or more pathnames. For each pathname, an attempt shall be made to open the file for appending. If the -a option is not specified, the file is opened for writing (and therefore truncated if it exists).

STDIN

Standard input is used to read data to be written to standard output and the specified files.

INPUT FILES

None.

ENVIRONMENT VARIABLES

The following environment variables shall affect the execution of tee:

LANG
Provide default values for the internationalization parameters that would otherwise be set by the active locale.
LC_ALL
Determine the locale that defines the Internationalization parameters.
LC_CTYPE
Determine the locale for the interpretation of sequences of bytes of data and for the classification of character codes that are used when writing output files.
LC_MESSAGES
Determine the locale that should be used to format messages displayed for internationalization.
NLSPATH
Determine the locations of message catalogues for the processing of LC_MESSAGES.

ASYNCHRONOUS EVENTS

Default.

STDOUT

Standard output is used to write the data read from standard input.

STDERR

Standard error is used for diagnostic messages.

OUTPUT FILES

The files specified by the file operands are written to, either by overwriting or appending, based on the presence or absence of the -a option.

EXTENDED DESCRIPTION

None.

EXIT STATUS

The exit status of tee is affected by the success or failure of its read and write operations.

0
Successful completion.
1-125
An error occurred during a read or write operation. The specific value indicates the nature of the error.
126
The command invoked by tee to write to a file could not be executed.
127
The command invoked by tee to write to a file could not be found.
128+N
A signal was received. N is the signal number.

CONSEQUENCES OF ERRORS

If any write to a file argument fails, or if any read from standard input is terminated by a signal, tee shall exit with a non-zero exit status. Otherwise, when standard input reaches end-of-file and all data has been successfully written to standard output and all file arguments, tee shall exit with a zero exit status.

APPLICATION USAGE

None.

EXAMPLES

  1. To write the output of the ls command to a file named log and also display it on the terminal: 
    $ ls | tee log
  2. To append the output of the date command to a file named history and also display it on the terminal: 
    $ date | tee -a history

RATIONALE

The tee utility is named after the T-splitter used in plumbing. It is useful for capturing the output of a command while it is still being processed by subsequent commands in a pipeline.

The default behavior is to overwrite the output files. The -a option is provided to allow appending to the output files.

The exit status reflects the success or failure of the read and write operations. If any write fails, or if a read is interrupted by a signal, the utility exits with a non-zero status.

FUTURE DIRECTIONS

None.
