Test2::Manual::Tooling::Plugin::TestExit(3perl) دليل مبرمجي Perl Test2::Manual::Tooling::Plugin::TestExit(3perl)

الاسم

Test2::Manual::Tooling::Plugin::TestExit - كيفية إضافة سلوكيات ما قبل الخروج بأمان.

الوصف

يصف هذا كيفية إضافة سلوكيات ما قبل الخروج إلى الاختبارات بشكل صحيح/آمن عبر مكون إضافي مخصص.

الطريقة البديهية لمحاولة القيام بذلك ستكون إضافة كتلة "END { ... }". قد يعمل ذلك، وقد لا يسبب مشاكل.... من ناحية أخرى، هناك العديد من الطرق التي يمكن أن تؤذيك. وصف جميع المشاكل المحتملة لكتلة END، وكيف يمكن أن تتعارض مع Test2 (الذي لديه كتلة END الخاصة به) يتجاوز نطاق هذا المستند.

رمز كامل مقدماً

package Test2::Plugin::MyPlugin;
use Test2::API qw{test2_add_callback_exit};
sub import {
    my $class = shift;
    test2_add_callback_exit(sub {
        my ($ctx, $orig_code, $new_exit_code_ref) = @_;
        return if $orig_code == 42;
        $$new_exit_code_ref = 42;
    });
}
1;

سطر بسطر

use Test2::API qw{test2_add_callback_exit};
يقوم هذا باستيراد رد الاتصال "(test2_add_callback_exit)".
test2_add_callback_exit(sub { ... });
يضيف هذا رد الاتصال الخاص بنا ليتم استدعاؤه قبل الخروج.
my ($ctx, $orig_code, $new_exit_code_ref) = @_
يحصل رد الاتصال على 3 وسائط. الأول هو كائن سياق يمكنك استخدامه. الثاني هو رمز الخروج الأصلي لكتلة "END" التي يستخدمها Test2. الوسيط الثالث هو مرجع عددي يمكنك استخدامه للحصول على رمز الخروج الحالي، أو تعيين رمز جديد.
return if $orig_code == 42
هذه اختصار لعدم القيام بأي شيء إذا كان رمز الخروج الأصلي هو 42 بالفعل.
$$new_exit_code_ref = 42
هذا يغير رمز الخروج إلى 42.
