Test__Specio(3pm)

الحزمة: perl-specio

التراخيص: GPL, PerlArtistic

Test::Specio(3) وثائق مساعدة مقدمة من Perl Test::Specio(3)

الاسم

Test::Specio - وظائف مساعدة لـ Specio

الإصدار

الإصدار 0.53

الخلاصة

use Test::Specio qw( test_constraint :vars );
test_constraint(
    t('Foo'), {
        accept => [ 'foo', 'bar' ],
        reject => [ 42,    {}, $EMPTY_STRING, $HASH_REF ],
    }
);

الوصف

توفر هذه الوحدة بعض الوظائف المساعدة والمتغيرات لاختبار أنواع Specio.

التصدير

تُصدر هذه الوحدة التصديرات التالية:

test_constraint( $type, $tests, [ $describer ] )

تقبل هذه الدالة الفرعية وسيطتين. يجب أن تكون الأولى كائن نوع Specio. الثانية هي hashref قد تحتوي على المفاتيح "accept" و "reject". يجب أن يحتوي كل مفتاح على arrayref من القيم التي يقبلها النوع أو يرفضها.

الوسيطة الثالثة اختيارية. هذه دالة فرعية سيتم استدعاؤها لإنشاء وصف لقيمة يتم اختبارها. تستدعي افتراضيًا الدالة الفرعية "describe" لهذه الوحدة، ولكن يمكنك توفير دالتك الخاصة.

describe($value)

نظرًا لقيمة، تُرجع هذه الدالة الفرعية سلسلة نصية تصف تلك القيمة بطريقة مفيدة لإخراج الاختبار. إنها تعرف الفئات المستخدمة للمتغيرات التي تم تصديرها بواسطة هذه الوحدة وستقوم بشيء ذكي عند العثور على متغير كهذا.

builtins_tests( $GLOB, $GLOB_OVERLOAD, $GLOB_OVERLOAD_FH )

تُرجع هذه الدالة الفرعية hashref يحتوي على متغيرات اختبار لجميع أنواع الأنواع المعرفة مسبقًا. يحتوي hashref على تنسيق مشابه لهذا:

{
    Bool => {
        accept => [
            $ZERO,
            $ONE,
            $BOOL_OVERLOAD_TRUE,
            $BOOL_OVERLOAD_FALSE,
            ...,
        ],
        reject => [
            $INT,
            $NEG_INT,
            $NUM,
            $NEG_NUM,
            ...,
            $OBJECT,
        ],
    },
    Maybe => {...},
}

يجب عليك تمرير كرة، وكائن يتجاوز التغيير الكروي، وكائن يتجاوز التغيير الكروي لإرجاع مقبض ملف. انظر مزيدًا من التفاصيل حول كيفية إنشاء هذه الكائنات في قسم تفاصيل الوثائق.

create_BAR_handle_code()

تُرجع سلسلة نصية يمكنك تقييمها لإنشاء مقبض ملف باسم "BAR". يجب استخدام هذا على النحو التالي:

local *BAR;
{
    local $@;
    eval create_BAR_handle_code();
    die $@ if $@;
}

المتغيرات

تقوم هذه الوحدة أيضًا بتصدير العديد من المتغيرات المفيدة لاختبار القيود. يجب أن تلاحظ أن المراجع دائمًا فارغة، ما لم يُذكر خلاف ذلك. يمكنك استيراد هذه المتغيرات بشكل فردي أو استيرادها جميعًا باستخدام العلامة ":vars".

  • $ZERO
  • $ONE
  • $INT

    عدد صحيح موجب عشوائي.

  • $NEG_INT

    عدد صحيح سالب عشوائي.

  • $NUM

    رقم موجب غير صحيح عشوائي.

  • $NEG_NUM

    رقم سالب غير صحيح عشوائي.

  • $EMPTY_STRING
  • $STRING

    سلسلة نصية غير فارغة عشوائية.

  • $NUM_IN_STRING

    سلسلة نصية تحتوي على رقم.

  • $INT_WITH_NL1

    سلسلة نصية تحتوي على رقم يتبعه سطر جديد.

  • $INT_WITH_NL2

    سلسلة نصية تحتوي على سطر جديد يتبعه رقم.

  • $SCALAR_REF
  • $SCALAR_REF_REF

    مرجع يحتوي على مرجع لمتغير سلمي.

  • $ARRAY_REF
  • $HASH_REF
  • $CODE_REF
  • $GLOB_REF
  • $FH

    مقبض ملف إخراج مفتوح.

  • $FH_OBJECT

    كائن IO::File مفتوح.

  • $REGEX

    تعبير عادي تم إنشاؤه باستخدام "qr//".

  • $REGEX_OBJ

    تعبير عادي تم إنشاؤه باستخدام "qr//" ثم تم رفعه إلى فئة.

  • $FAKE_REGEX

    تعبير عادي غير عادي تم رفعه إلى الفئة "Regexp" التي تستخدمها Perl داخليًا لكائنات "qr//".

  • $OBJECT

    كائن عشوائي.

  • $UNDEF
  • $CLASS_NAME

    سلسلة نصية تحتوي على اسم الفئة المحملة.

  • $BOOL_OVERLOAD_TRUE

    كائن يتجاوز التحويل المنطقي لإرجاع صحيح.

  • $BOOL_OVERLOAD_FALSE

    كائن يتجاوز التحويل المنطقي لإرجاع خطأ.

  • $STR_OVERLOAD_EMPTY

    كائن يتجاوز تحويل السلسلة النصية لإرجاع سلسلة نصية فارغة.

  • $STR_OVERLOAD_FULL

    كائن يتجاوز تحويل السلسلة النصية لإرجاع سلسلة نصية غير فارغة.

  • $STR_OVERLOAD_CLASS_NAME

    كائن يتجاوز تحويل السلسلة النصية لإرجاع اسم الفئة المحملة.

  • $NUM_OVERLOAD_ZERO
  • $NUM_OVERLOAD_ONE
  • $NUM_OVERLOAD_NEG
  • $NUM_OVERLOAD_DECIMAL
  • $NUM_OVERLOAD_NEG_DECIMAL
  • $CODE_OVERLOAD
  • $SCALAR_OVERLOAD

    كائن يتجاوز إلغاء مرجع المتغير السلمي لإرجاع سلسلة نصية غير فارغة.

  • $ARRAY_OVERLOAD

    كائن يتجاوز إلغاء مرجع المصفوفة لإرجاع مصفوفة غير فارغة.

  • $HASH_OVERLOAD

    كائن يتجاوز إلغاء مرجع الهاش لإرجاع هاش غير فارغ.

الكرات وحزمة _T::GlobOverload

لإنشاء كرة للاختبار، يمكنك استخدام هذا الرمز:

my $GLOB = do {
    no warnings 'once';
    *SOME_GLOB;
};

الحزمة "_T::GlobOverload" معرفة عند تحميل الحزمة "Test::Specio"، لذلك يمكنك إنشاء كائنات تجاوز كرة خاصة بك. لا يمكن تصدير هذه الكائنات لأن الكرة التي تُرجعها لا تنتقل بشكل صحيح بين الحزم.

يمكنك إنشاء متغير كهذا:

local *FOO;
my $GLOB_OVERLOAD = _T::GlobOverload->new( \*FOO );

إذا كنت ترغب في إنشاء كائن تجاوز كرة يُرجع مقبض ملف، فافعل هذا:

local *BAR;
open BAR, '<', $some_file or die $!;
my $GLOB_OVERLOAD_FH = _T::GlobOverload->new( \*BAR );

Test::Specio(3pm)

NAME

Test::Specio - A way to test Specio types

VERSION

0.53

SYNOPSIS

use Test::More tests => 1;
use Test::Specio;
use Specio::Constraint::Match;

my $foo = Specio::Constraint::Match->new(
    matches => qr/^foo$/
);

ok is_specio_type($foo), 'The constraint is a Specio type';

DESCRIPTION

This module provides some helper functions for testing things that are related to Specio.

EXPORTS

This module exports the following functions:

is_specio_type
Checks to see if the given object is a Specio type.

SUPPORT

See Specio(3pm).
