Template__Plugins(3pm)

الحزمة: perl-template-toolkit

التراخيص: PerlArtistic

Template::Plugins(3) توثيق مساهمة المستخدم في Perl Template::Plugins(3)

الاسم

Template::Plugins - وحدة مزود الإضافات

الملخص

use Template::Plugins;
$plugin_provider = Template::Plugins->new(\%options);
($plugin, $error) = $plugin_provider->fetch($name, @args);

الوصف

تعرّف الوحدة "Template::Plugins" فئة مزود يمكن استخدامها لتحميل وتكوين وحدات إضافات Template Toolkit.

الأساليب

new(\%params)

أسلوب المنشئ الذي يقوم بإنشاء وإرجاع مرجع إلى كائن "Template::Plugins". يمكن تمرير مرجع إلى مصفوفة تجزئة من عناصر التكوين كمعلمة. يتم وصف هذه العناصر أدناه.

لاحظ أن وحدة الواجهة الأمامية Template تنشئ مزودًا "Template::Plugins"، وتمرر جميع عناصر التكوين. وبالتالي، فإن الأمثلة المعروضة أدناه في شكل:

$plugprov = Template::Plugins->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});

يمكن استخدامها أيضًا عبر وحدة Template كـ:

$ttengine = Template->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});

بالإضافة إلى الشكل الأكثر وضوحًا:

$plugprov = Template::Plugins->new({
    PLUGIN_BASE => 'MyTemplate::Plugin',
    LOAD_PERL   => 1,
    ...
});
$ttengine = Template->new({
    LOAD_PLUGINS => [ $plugprov ],
});

fetch($name, @args)

يتم استدعاؤه لطلب توفير إضافة ذات اسم معين. يتم تحميل الوحدة ذات الصلة أولاً (إذا لزم الأمر) واستدعاء أسلوب الفئة load() لإرجاع اسم فئة المصنع (عادةً نفس اسم الحزمة) أو كائن مصنع (نموذج أولي). بعد ذلك، يتم استدعاء أسلوب new() كأسلوب فئة أو كائن مقابل المصنع، مع تمرير جميع المعلمات المتبقية.

يرجع مرجعًا إلى كائن إضافة جديد أو "($error, STATUS_ERROR)" عند حدوث خطأ. قد يرجع أيضًا "(undef, STATUS_DECLINED)" لرفض خدمة الطلب. إذا تم تعيين "TOLERANT"، فسيتم إرجاع جميع الأخطاء كرفض.

خيارات التكوين

تلخص القائمة التالية خيارات التكوين التي يمكن توفيرها لمنشئ "Template::Plugins" new(). يرجى الرجوع إلى Template::Manual::Config لمزيد من التفاصيل والأمثلة لكل خيار تكوين قيد الاستخدام.

PLUGINS

يمكن استخدام خيار PLUGINS لتوفير مرجع إلى مصفوفة تجزئة تربط أسماء الإضافات بأسماء وحدات Perl.

my $plugins = Template::Plugins->new({
    PLUGINS => {
        cgi => 'MyOrg::Template::Plugin::CGI',
        foo => 'MyOrg::Template::Plugin::Foo',
        bar => 'MyOrg::Template::Plugin::Bar',
    },
});

PLUGIN_BASE

إذا لم يتم تعريف إضافة في مصفوفة PLUGINS، فسيتم استخدام PLUGIN_BASE لمحاولة بناء اسم وحدة Perl صحيح يمكن تحميله بنجاح.

# PLUGIN_BASE بقيمة واحدة
my $plugins = Template::Plugins->new({
    PLUGIN_BASE => 'MyOrg::Template::Plugin',
});
# PLUGIN_BASE بقيم متعددة
my $plugins = Template::Plugins->new({
    PLUGIN_BASE => [   'MyOrg::Template::Plugin',
                       'YourOrg::Template::Plugin'  ],
});

LOAD_PERL

يمكن تعيين خيار LOAD_PERL للسماح لك بتحميل وحدات Perl عادية (أي تلك التي لا تقع في "Template::Plugin" أو مساحة اسم أخرى محددة من قبل المستخدم) كإضافات.

إذا تعذر تحميل إضافة باستخدام نهجي PLUGINS أو PLUGIN_BASE، فإذا تم تعيين LOAD_PERL، فسيقوم المزود ببذل محاولة أخيرة لتحميل الوحدة دون إضافة أي بادئة إلى مسار الوحدة.

على عكس الإضافات العادية، لا تتلقى الوحدات التي تم تحميلها باستخدام LOAD_PERL مرجع Template::Context كالحجة الأولى لأسلوب المنشئ new().

TOLERANT

يمكن تعيين علامة TOLERANT للإشارة إلى أن الوحدة "Template::Plugins" يجب أن تتجاهل أي أخطاء تحدث أثناء تحميل إضافة وأن ترجع بدلاً من ذلك "STATUS_DECLINED".

DEBUG

يمكن استخدام خيار DEBUG لتمكين رسائل التصحيح للوحدة "Template::Plugins" عن طريق تعيينها لتشمل القيمة "DEBUG_PLUGINS".

use Template::Constants qw( :debug );
my $template = Template->new({
    DEBUG => DEBUG_FILTERS | DEBUG_PLUGINS,
});

إضافات Template Toolkit

يرجى الاطلاع على Template::Manual::Plugins للحصول على قائمة كاملة بجميع وحدات الإضافات الموزعة مع Template Toolkit.
