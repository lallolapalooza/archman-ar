!>
!> قيم حقيقية للاختبار:
!> (1) x = 2**m، حيث m = MINEXPONENT-DIGITS، ..., MINEXPONENT-1. توقف عند أول نجاح.
!>     لاحظ أن جميع المنصات قد لا تدعم الأرقام الفرعية.
!> (2) x = 2**m، حيث m = MINEXPONENT، ..., 0. توقف عند أول نجاح.
!> (3) x = OV، حيث OV هو عتبة التدفق الزائد. OV^2 يفيض ولكن المعيار هو OV.
!> (4) x = 2**m، حيث m = MAXEXPONENT-1، ..., 1. توقف عند أول نجاح.
!>
!> الاختبارات:
!> (a) y = x + 0 * I، |y| = x
!> (b) y = 0 + x * I، |y| = x
!> (c) y = (3/4)*x + x * I، |y| = (5/4)*x كلما كان (3/4)*x و (5/4)*x يمكن تخزينهما بدقة
!> (d) y = (1/2)*x + (1/2)*x * I، |y| = (1/2)*x*sqrt(2) كلما كان (1/2)*x يمكن تخزينه بدقة
!>
!> حالات خاصة:
!>
!> (i) انتشار اللانهاية (Inf)
!>    (1) y = Inf + 0 * I، |y| هو Inf.
!>    (2) y =-Inf + 0 * I، |y| هو Inf.
!>    (3) y = 0 + Inf * I، |y| هو Inf.
!>    (4) y = 0 - Inf * I، |y| هو Inf.
!>    (5) y = Inf + Inf * I، |y| هو Inf.
!>
!> (n) انتشار NaN (ليس رقمًا)
!>    (1) y = NaN + 0 * I، |y| هو NaN.
!>    (2) y = 0 + NaN * I، |y| هو NaN.
!>    (3) y = NaN + NaN * I، |y| هو NaN.
!>
!>
