Test__LeakTrace__Script(3pm)

الحزمة: perl-test-leaktrace

التراخيص: PerlArtistic, GPL

Test::LeakTrace::Script(3) وثائق Perl المقدمة من المستخدم Test::LeakTrace::Script(3)

الاسم

Test::LeakTrace::Script - واجهة LeakTrace للبرامج النصية الكاملة

ملخص

#!perl -w
use Test::LeakTrace::Script sub{
        my($svref, $file, $line) = @_;
        warn "leaked $svref from $file line $line.\n";
};

الوصف

هذه واجهة لـ "Test::LeakTrace" للبرامج النصية الكاملة.

الواجهة

واجهة سطر الأوامر

$ perl -MTest::LeakTrace::Script script.pl
$ perl -MTest::LeakTrace::Script=-verbose script.pl
$ TEST_LEAKTRACE=-lines script.pl

متغيرات البيئة

TEST_LEAKTRACE=mode

-simple (الافتراضي)

-sv_dump

-lines

-verbose

انظر أيضًا

Test::LeakTrace.
