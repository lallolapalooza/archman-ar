tep_free(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_alloc, tep_free, tep_ref, tep_unref, tep_get_ref, tep_kbuffer - إنشاء، تدمير، إدارة الإشارات لسياق محلل أحداث التتبع.

الملخص

#include <event-parse.h>
struct tep_handle *tep_alloc(void);
void tep_free(struct tep_handle *tep);
void tep_ref(struct tep_handle *tep);
void tep_unref(struct tep_handle *tep);
int tep_get_ref(struct tep_handle *tep);
struct kbuffer *tep_kbuffer(struct tep_handle *tep);

الوصف

هذه هي الوظائف الرئيسية لإنشاء وتدمير tep_handle - الهيكل الرئيسي، الذي يمثل سياق محلل أحداث التتبع. يستخدم هذا السياق كمعامل إدخال لمعظم واجهات برمجة التطبيقات للمكتبة.

تقوم وظيفة tep_alloc() بتخصيص وتهيئة سياق tep.

ستقوم وظيفة tep_free() بتقليل الإشارة إلى معالج tep. عندما لا تكون هناك المزيد من الإشارات، فسيتم تحرير المعالج، بالإضافة إلى تنظيف جميع موارده التي استخدمها. المعامل tep هو مؤشر إلى سياق محلل أحداث التتبع.

تقوم وظيفة tep_ref() بإضافة إشارة إلى معالج tep.

تقوم وظيفة tep_unref() بإزالة إشارة من معالج tep. عند إزالة الإشارة الأخيرة، يتم تدمير tep، ويتم تنظيف جميع الموارد التي استخدمها.

تقوم وظيفة tep_ref_get() بالحصول على الإشارات الحالية لمعالج tep.

تقوم وظيفة tep_kbuffer() بتخصيص واصف kbuffer يمكن استخدامه لتحليل البيانات الخام التي يمثلها واصف tep. يجب تحريره باستخدام kbuf_free(3).

قيمة الإرجاع

tep_alloc() تُرجع مؤشرًا إلى بنية tep_handle تم إنشاؤها حديثًا. يتم إرجاع NULL في حالة عدم وجود ذاكرة حرة كافية لتخصيصها.

tep_ref_get() تُرجع الإشارات الحالية لـ tep. إذا كان tep فارغًا (NULL)، يتم إرجاع 0.

tep_kbuffer() تُرجع واصف kbuffer يمكنه تحليل البيانات الخام التي تمثل واصف tep. يجب تحريره باستخدام kbuf_free(3).

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int ref = tep_get_ref(tep);
tep_ref(tep);
if ( (ref+1) != tep_get_ref(tep)) {
        /* حدث شيء خاطئ، العداد لم تتم زيادته بمقدار 1 */
}
tep_unref(tep);
...
tep_free(tep);
...
