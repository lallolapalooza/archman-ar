texi2dvi(1)

الحزمة: texinfo

التراخيص: GPL3

TEXI2DVI(1) أوامر المستخدم TEXI2DVI(1)

الاسم

texi2dvi - تحويل مستندات Texinfo إلى DVI أو PDF

الملخص

texi2dvi [خيار]... ملف...
texi2pdf [خيار]... ملف...
pdftexi2dvi [خيار]... ملف...

الوصف

تشغيل كل ملف Texinfo أو (La)TeX FILE عبر TeX بالتتابع حتى يتم حل جميع المراجع المتقاطعة، وبناء جميع الفهارس. يبحث الدليل الذي يحتوي على كل FILE عن الملفات المتضمنة. يستخدم لاحقة FILE لتحديد لغته (La)TeX أو Texinfo. لمعالجة ملفات TeX البسيطة (e)plain، قم بتعيين متغير البيئة LATEX=tex.

عند الاستدعاء باسم `texi2pdf' أو بإعطاء الخيار --pdf، يتم إنشاء مخرجات PDF. بخلاف ذلك، يتم إنشاء DVI.

خيارات عامة:

-D, --debug
تشغيل تصحيح الأخطاء shell (تعيين -x)
-h, --help
عرض هذا المساعدة والخروج بنجاح
-o, --output=OFILE
ترك المخرجات في OFILE؛ يُسمح بملف إدخال واحد فقط
-q, --quiet
لا مخرجات إلا عند حدوث أخطاء
-v, --version
عرض معلومات الإصدار والخروج بنجاح
-V, --verbose
الإبلاغ عن ما تم إنجازه
--max-iterations=N
عدم معالجة الملفات أكثر من N مرة [7]
--mostly-clean
إزالة الملفات المساعدة أو الدلائل من التشغيلات السابقة (ولكن ليس المخرجات)

تنسيق المخرجات:

--dvi
إنشاء ملف DVI [الافتراضي]
--dvipdf
إنشاء ملف PDF عبر DVI (باستخدام برنامج تحويل dvi إلى pdf)
-p, --pdf
استخدام pdftex أو pdflatex للمعالجة
--ps
إنشاء ملف PostScript عبر DVI (باستخدام dvips)

ضبط TeX:

-E, --expand
توسيع الماكرو باستخدام makeinfo
-I DIR
البحث في DIR عن ملفات Texinfo
-l, --language=LANG
تحديد LANG للملف، إما latex أو texinfo
--no-line-error
عدم تمرير --file-line-error إلى TeX
--shell-escape
تمرير --shell-escape إلى TeX
--src-specials
تمرير --src-specials إلى TeX
--translate-file=FILE
استخدام ملف ترجمة الترميز المحدد لـ TeX
-t, --command=CMD
إدراج CMD في نسخة من ملف الإدخال

أوضاع البناء:

--build=MODE
تحديد طريقة التعامل مع الملفات المساعدة [local]
--tidy
نفس الأمر --build=tidy
-c, --clean
نفس الأمر --build=clean
--build-dir=DIR
تحديد مكان إجراء تجميع tidy؛ يتضمن --tidy

يحدد MODE مكان إجراء تجميع TeX، وبالتالي كيفية التعامل مع الملفات المساعدة.

القيم الصحيحة لـ MODE هي:

`local'
التجميع في الدليل الحالي، مع ترك جميع الملفات المساعدة. هذا هو الاستخدام التقليدي لـ TeX.
`tidy'
التجميع في دليل *.t2d محلي، حيث تُترك الملفات المساعدة. يتم نسخ ملفات المخرجات مرة أخرى إلى الملف الأصلي.
`clean'
نفس الأمر `tidy'، ولكن يتم إزالة الدليل المساعد بعد ذلك. كل تجميع يتطلب لذلك دورة كاملة.

يمكن أيضًا تعيين وضع البناء باستخدام متغير البيئة TEXI2DVI_BUILD_MODE. يمكن أيضًا تعيين دليل البناء tidy باستخدام متغير البيئة TEXI2DVI_BUILD_DIRECTORY.

تُستخدم قيم متغيرات البيئة هذه لتشغيل الأوامر المقابلة، إذا تم تعيينها:

BIBER BIBTEX DVIPDF DVIPS EGREP LATEX MAKEINDEX MAKEINFO PDFLATEX PDFTEX SED TEX TEXINDEX TEXINDY THUMBPDF_CMD

بالنسبة لـ --dvipdf، إذا لم يتم تعيين DVIPDF في البيئة، فسيتم البحث عن البرامج التالية (بهذا الترتيب): dvipmx dvipdfm dvipdf dvi2pdf dvitopdf.

إذا كان Texinfo مثبتًا في موقعك، فإن الأمر

info texi2dvi

يجب أن يمنحك الوصول إلى المزيد من الوثائق.
