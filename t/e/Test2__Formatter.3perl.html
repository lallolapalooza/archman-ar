Test2::Formatter(3perl) دليل مبرمجي بيرل Test2::Formatter(3perl)

الاسم

Test2::Formatter - مساحة اسم للمنسقين.

الوصف

هذه هي مساحة اسم للمنسقين. هذه حزمة فارغة.

إنشاء منسقين

المنسق هو أي حزمة أو كائن يحتوي على دالة "write($event, $num)".

package Test2::Formatter::Foo;
use strict;
use warnings;
sub write {
    my $self_or_class = shift;
    my ($event, $assert_num) = @_;
    ...
}
sub hide_buffered { 1 }
sub terminate { }
sub finalize { }
sub supports_tables { return $BOOL }
sub new_root {
    my $class = shift;
    ...
    $class->new(@_);
}
1;

الدالة "write" هي دالة، لذلك تحصل إما على فئة أو مثيل. الوسيطتان هما كائن "$event" الذي يجب تسجيله، و "$assert_num" وهو رقم التأكيد الحالي (ok)، أو آخر تأكيد إذا كان هذا الحدث ليس تأكيدًا بحد ذاته. قد يكون رقم التأكيد أي عدد صحيح 0 أو أكبر، وقد يكون غير محدد في بعض الحالات.

يجب أن تعيد الدالة "hide_buffered()" قيمة منطقية. يتم استخدام هذا لإخبار الاختبارات الفرعية المخزنة مؤقتًا ما إذا كان يجب إرسال الأحداث إليها أثناء تخزينها مؤقتًا. انظر "run_subtest(...)" في Test2::API لمزيد من المعلومات.

الدالتان "terminate" و "finalize" هما دالتان اختياريتان يمكن تنفيذهما إذا كان التنسيق الذي تقوم بإنشائه يحتاج إلى معالجة هذه الحالات، على سبيل المثال إذا كنت تقوم بإنشاء XML وتحتاج إلى إغلاق علامات مفتوحة.

يتم استدعاء الدالة "terminate" عندما تعيد دالة "terminate" الخاصة بالحدث قيمة صحيحة، على سبيل المثال عندما يكون لدى Test2::Event::Plan خطة 'skip_all'، أو عند إرسال حدث Test2::Event::Bail. يتم تمرير حدث Test2::Event الوحيد الذي أدى إلى الإنهاء إلى دالة "terminate".

الدالة "finalize" هي دائمًا آخر شيء يتم استدعاؤه على المنسق، *باستثناء عندما يتم استدعاء* *"terminate"* *لحدث Bail*. يتم تمرير الوسائط التالية لها:

يجب أن تكون الدالة "supports_tables" صحيحة إذا كان المنسق يدعم عرض بيانات الجدول مباشرة من جوانب "info". هذه ميزة أحدث وقد لا تدعمها العديد من المنسقات القديمة. عند عدم دعمها، يعود المنسق إلى عرض "detail" بدلاً من بيانات "table".

تُستخدم الدالة "new_root" عند إنشاء منسق جذر. الافتراضي هو مجرد تفويض إلى الدالة العادية new()، يمكن لمعظم المنسقات تجاهل هذا.

  • عدد الاختبارات التي تم التخطيط لها
  • عدد الاختبارات التي تمت رؤيتها فعليًا
  • عدد الاختبارات التي فشلت
  • قيمة منطقية تشير إلى ما إذا كانت مجموعة الاختبارات قد نجحت أم لا
  • قيمة منطقية تشير إلى ما إذا كان هذا الاستدعاء لاختبار فرعي أم لا

يتم استدعاء الدالة "new_root" عند تهيئة "Test2::API::Stack" للمحور الجذر لأول مرة. سيقوم معظم المنسقين ببساطة باستدعاء "$class->new"، وهو السلوك الافتراضي. قد يرغب بعض المنسقين الآخرين في اتخاذ إجراءات إضافية أثناء إنشاء المنسق الجذر، وهذا هو المكان الذي يمكنهم القيام بذلك فيه.
