Test2::Util::Sub(3perl) دليل مبرمجي Perl Test2::Util::Sub(3perl)

الاسم

Test2::Util::Sub - أدوات لفحص وتعديل الدوال.

الوصف

أدوات مساعدة تستخدمها Test2::Tools لفحص وتعديل الدوال.

التصدير

جميع الصادرات اختيارية، يجب عليك تحديد الدوال لاستيرادها.

$name = sub_name(\&sub)
احصل على اسم الدالة.
my $hr = sub_info(\&code)
هذا يعيد هاش ريف يحتوي على معلومات حول الدالة: 
{
    ref        => \&code,
    cobj       => $cobj,
    name       => "Some::Mod::code",
    file       => "Some/Mod.pm",
    package    => "Some::Mod",
    # ملاحظة: تم تعديل هذه بناءً على تخمين.
    start_line => 22,
    end_line   => 42,
    lines      => [22, 42],
    # ليس خطأ، هذه الأسطر مختلفة!
    all_lines  => [23, 25, ..., 39, 41],
};
$info->{ref} => \&code
هذه هي الدالة الأصلية التي تم تمريرها إلى sub_info().
$info->{cobj} => $cobj
هذا هو تمثيل كائن C لمرجع الكود.
$info->{name} => "Some::Mod::code"
هذا هو اسم مرجع الكود. بالنسبة لمراجع الكود المجهولة، قد تنتهي بـ '__ANON__'. لاحظ أيضًا أن الحزمة 'main' خاصة، وقد يتم حذف 'main::'.
$info->{file} => "Some/Mod.pm"
الملف الذي تم فيه تعريف الدالة.
$info->{package} => "Some::Mod"
الحزمة التي تم فيها تعريف الدالة.
$info->{start_line} => 22
$info->{end_line} => 42
$info->{lines} => [22, 42]
هذه الحقول الثلاثة هي سطر البداية، سطر النهاية، والمصفوفة التي تحتوي على كلاهما، بعد *التعديل*. من المهم ملاحظة أن هذه الأسطر تم تعديلها وقد لا تكون دقيقة.

يتم الحصول على الأسطر عن طريق اجتياز العمليات. على هذا النحو، يكون السطر الأول هو سطر البيان الأول، والسطر الأخير هو سطر البيان الأخير. هذا يعني أنه في الدوال متعددة الأسطر، تكون الأسطر عادةً غير دقيقة بمقدار 1. سيتم تعديل الأسطر في هذه المفاتيح لك إذا اكتشف دالة متعددة الأسطر.

$info->{all_lines} => [23, 25, ..., 39, 41]
هذه مصفوفة تحتوي على أسطر كل بيان في الدالة. على عكس حقول الأسطر الأخرى، لم يتم تعديل هذه لك.
