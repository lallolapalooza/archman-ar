BUGS

There is a known bug in Test::Exception whereby it doesn't correctly catch exceptions thrown by Perl's strictures. This is documented at http://rt.cpan.org/Ticket/Display.html?id=24678 for details, along with the t/edge-cases.t in the distribution test suite. These will be addressed in a future Test::Exception release.

If you find any more bugs please let me know by e-mail, or report the problem with http://rt.cpan.org/.
