Test__FailWarnings(3pm)

الحزمة: perl-test-failwarnings

التراخيص: PerlArtistic, GPL

Test::FailWarnings(3) وثائق Perl مساهمة من المستخدم Test::FailWarnings(3)

الاسم

Test::FailWarnings - إضافة فشل للاختبارات إذا تم التقاط التحذيرات

الإصدار

الإصدار 0.008

الملخص

ملف الاختبار:

use strict;
use warnings;
use Test::More;
use Test::FailWarnings;
ok( 1, "first test" );
ok( 1 + "lkadjaks", "add non-numeric" );
done_testing;

المخرجات:

ok 1 - first test
not ok 2 - Test::FailWarnings should catch no warnings
#   Failed test 'Test::FailWarnings should catch no warnings'
#   at t/bin/main-warn.pl line 7.
# Warning was 'Argument "lkadjaks" isn't numeric in addition (+) at t/bin/main-warn.pl line 7.'
ok 3 - add non-numeric
1..3
# Looks like you failed 1 test of 3.

الوصف

تقوم هذه الوحدة بربط $SIG{__WARN__} وتحويل التحذيرات إلى استدعاءات fail() الخاصة بـ Test::More. تم تصميمها للاستخدام مع "done_testing"، عندما لا تحتاج إلى معرفة عدد الاختبارات مسبقًا.

تمامًا كما هو الحال مع Test::NoWarnings، لا تلتقط هذه الوحدة التحذيرات إذا قامت أشياء أخرى بتحديد نطاق $SIG{__WARN__}، حيث تم تصميمها لالتقاط التحذيرات *غير المعالجة*.

الاستخدام

تجاوز $SIG{__WARN__}

عند "import"، يتم استبدال $SIG{__WARN__} بـ "Test::FailWarnings::handler".

use Test::FailWarnings;  # global

إذا كنت لا تريد استبدالًا شاملًا، فقم بتضمين الوحدة بدلاً من ذلك وقم بتحديد نطاقها في أي نطاق تريده.

require Test::FailWarnings;
{
    local $SIG{__WARN__} = \&Test::FailWarnings::handler;
    # ... سيتم إصدار تحذيرات fail() هنا
}

عندما تقوم المعالجة بالإبلاغ عن مصدر التحذير، فإنها ستنظر خلف أي حزم استدعاء تبدأ بـ "Carp" أو "warnings" لمحاولة اكتشاف الأصل الحقيقي للتحذير.

السماح بالتحذيرات من التبعيات

إذا كنت ترغب في تجاهل حالات الفشل من خارج الكود الخاص بك، يمكنك تعيين $Test::FailWarnings::ALLOW_DEPS إلى قيمة صحيحة. يمكنك القيام بذلك في سطر "use" باستخدام "-allow_deps".

use Test::FailWarnings -allow_deps => 1;

عندما تكون القيمة صحيحة، سيتم إصدار التحذيرات فقط إذا بدا أنها تنشأ من اسم ملف يطابق "qr/^(?:t|xt|lib|blib)/"

السماح بالتحذيرات من وحدات نمطية محددة

إذا كنت ترغب في قائمة بيضاء لوحدات نمطية محددة فقط، يمكنك إضافة أسماء حزمها إلى @Test::NoWarnings::ALLOW_FROM. يمكنك القيام بذلك في سطر "use" باستخدام "-allow_from".

use Test::FailWarnings -allow_from => [ qw/Annoying::Module/ ];

انظر أيضًا

  • Test::NoWarnings -- تلتقط التحذيرات وتقوم بالإبلاغ في كتلة "END". ليست (حتى الآن) متوافقة مع "done_testing".
  • Test::Warnings -- بديل لـ Test::NoWarnings يعمل مع done_testing
  • Test::Warn -- اختبر التحذيرات دون إثارة حالات فشل من هذه الوحدات
