tep_unref(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_alloc, tep_free, tep_ref, tep_unref, tep_get_ref, tep_kbuffer - إنشاء، تدمير، إدارة مراجع سياق محلل أحداث التتبع.

الملخص

#include <event-parse.h>
struct tep_handle *tep_alloc(void);
void tep_free(struct tep_handle *tep);
void tep_ref(struct tep_handle *tep);
void tep_unref(struct tep_handle *tep);
int tep_get_ref(struct tep_handle *tep);
struct kbuffer *tep_kbuffer(struct tep_handle *tep);

الوصف

هذه هي الوظائف الرئيسية لإنشاء وتدمير tep_handle - الهيكل الرئيسي، الذي يمثل سياق محلل أحداث التتبع. يستخدم هذا السياق كمعامل إدخال لمعظم واجهات برمجة التطبيقات للمكتبة.

تقوم الوظيفة tep_alloc() بتخصيص وتهيئة سياق tep.

ستقوم الوظيفة tep_free() بتقليل مرجع معالج tep. عندما لا تكون هناك مراجع أخرى، فستقوم بتحرير المعالج، بالإضافة إلى تنظيف جميع الموارد التي استخدمها.

تقوم الوظيفة tep_ref() بإضافة مرجع إلى معالج tep.

تقوم الوظيفة tep_unref() بإزالة مرجع من معالج tep. عندما تتم إزالة المرجع الأخير، يتم تدمير tep، ويتم تنظيف جميع الموارد التي استخدمها.

تقوم الوظيفة tep_ref_get() بالحصول على المراجع الحالية لمعالج tep.

تقوم الوظيفة tep_kbuffer() بتخصيص واصف kbuffer يمكن استخدامه لتحليل البيانات الأولية التي يمثلها واصف المقبض tep. يجب تحريرها باستخدام kbuf_free(3).

قيمة الإرجاع

tep_alloc() ترجع مؤشرًا إلى هيكل tep_handle تم إنشاؤه حديثًا. يتم إرجاع NULL في حالة عدم وجود ذاكرة حرة كافية لتخصيصها.

tep_ref_get() ترجع المراجع الحالية لـ tep. إذا كان tep هو NULL، يتم إرجاع 0.

tep_kbuffer() ترجع واصف kbuffer يمكنه تحليل البيانات الأولية التي تمثل مقبض tep. يجب تحريره باستخدام kbuf_free(3).

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int ref = tep_get_ref(tep);
tep_ref(tep);
if ( (ref+1) != tep_get_ref(tep)) {
        /* حدث خطأ ما، لم يتم زيادة العداد بمقدار 1 */
}
tep_unref(tep);
...
tep_free(tep);
...
