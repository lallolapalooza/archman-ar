tep_parse_event(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_parse_event, tep_parse_format - تحليل معلومات تنسيق الحدث

الخلاصة

#include <event-parse.h>
enum tep_errno tep_parse_event(struct tep_handle *tep, const char *buf, unsigned long size, const char *sys);
enum tep_errno tep_parse_format(struct tep_handle *tep, struct tep_event **eventp, const char *buf, unsigned long size, const char *sys);

الوصف

تقوم الدالة tep_parse_event() بتحليل تنسيق الحدث وإنشاء بنية حدث لتحليل سريع للبيانات الأولية لحدث معين. الوسيط tep هو سياق محلل أحداث التتبع. يتم تخزين بنية الحدث التي تم إنشاؤها في السياق tep. الوسيط buf هو مخزن مؤقت بحجم size، حيث توجد بيانات تنسيق الحدث. يمكن أخذ بيانات تنسيق الحدث من ملفات tracefs/events/.../.../format. الوسيط sys هو نظام الحدث.

تقوم الدالة tep_parse_format() بنفس عمل الدالة tep_parse_event(). الاختلاف الوحيد هو في الوسيط الإضافي eventp، حيث يتم إرجاع بنية الحدث التي تم إنشاؤها حديثًا.

قيمة الإرجاع

كلتا الدالتين tep_parse_event() و tep_parse_format() ترجعان 0 عند النجاح، أو TEP_ERRNO__... في حالة حدوث خطأ.

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
char *buf;
int size;
struct tep_event *event = NULL;
buf = read_file("/sys/kernel/tracing/events/ftrace/print/format", &size);
if (tep_parse_event(tep, buf, size, "ftrace") != 0) {
        /* فشل تحليل تنسيق الطباعة ftrace */
}
if (tep_parse_format(tep, &event, buf, size, "ftrace") != 0) {
        /* فشل تحليل تنسيق الطباعة ftrace */
}
...
