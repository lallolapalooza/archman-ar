Template__Plugin__HTML(3pm)

الحزمة: perl-template-toolkit

التراخيص: PerlArtistic

Template::Plugin::HTML(3) وثائق مساهمة من المستخدمين لـ Perl Template::Plugin::HTML(3)

الاسم

Template::Plugin::HTML - إضافة لإنشاء عناصر HTML

الملخص

[% USE HTML %]
[% HTML.escape("if (a < b && c > d) ..." %]
[% HTML.element(table => { border => 1, cellpadding => 2 }) %]
[% HTML.attributes(border => 1, cellpadding => 2) %]

الوصف

الإضافة "HTML" هي إضافة أساسية جداً، تنفذ بعض الدوال المفيدة لإنشاء HTML.

الدوال

escape(text)

ترجع النص المصدر مع أي رموز HTML محجوزة مثل "<"، ">"، إلخ، تم الهروب منها بشكل صحيح إلى مكافئاتها الكيانية.

attributes(hash)

ترجع عناصر المصفوفة الهاشية الممررة بالمرجع منسقة بشكل صحيح (على سبيل المثال، قيم مقتبسة ومهرب منها بشكل صحيح) كسمات لعنصر HTML.

add_attribute(attributes)

هذه توفر طريقة لإضافة السمات بشكل تدريجي إلى الكائن. يتم تخزين القيم الممررة في الكائن. استدعاء element مع مجرد علامة أو سمات بدون معلمات سيستخدم السمات المحفوظة.

USE tag = HTML;
tag.add_attributes( { class => 'navbar' } );
tag.add_attributes( { id => 'foo' } );
tag.add_attributes( { class => 'active' } );
tag.element( 'li' ); # <li class="navbar active" id="foo">

هذه الدالة لديها اسمان مستعاران: add_attribute() و add().

replace_attribute(attributes)

هذه ستحل محل قيمة سمة بدلاً من الإضافة إلى القائمة الموجودة.

USE tag = HTML;
tag.add_attributes( { class => 'navbar' } );
tag.add_attributes( { id => 'foo' } );
tag.replace_attributes( { class => 'active' } );
tag.element( 'li' ); # <li class="active" id="foo">

هذه الدالة لديها اسمان مستعاران: replace_attribute() و replace().

clear_attributes

مسح أي سمات محفوظة

element(type, attributes)

ينشئ عنصر HTML من النوع المحدد وبالسمات المقدمة كمرجع مصفوفة هاش اختياري كوسيط ثانٍ أو كوسائط مسماة.

[% HTML.element(table => { border => 1, cellpadding => 2 }) %]
[% HTML.element('table', border=1, cellpadding=2) %]
[% HTML.element(table => attribs) %]

التصحيح

تقبل إضافة HTML خيار "sorted" كوسيط مُنشئ والذي، عند تعيينه لأي قيمة حقيقية، يتسبب في إرجاع السمات التي تم إنشاؤها بواسطة الدالة attributes() (إما مباشرة أو عبر element()) بترتيب مرتب. ترتيب السمات ليس مهماً في HTML، ولكن هذا مقدم بشكل أساسي لأغراض التصحيح حيث يكون من المفيد أن يتم إنشاء السمات بترتيب حتمي بدلاً من أي ترتيب اختارت مصفوفة الهاش إرجاع المفاتيح به.

[% USE HTML(sorted=1) %]
[% HTML.element( foo => { charlie => 1, bravo => 2, alpha => 3 } ) %]

ينشئ:

<foo alpha="3" bravo="2" charlie="1">
