termkey_getkey(3)

الحزمة: libtermkey

التراخيص: MIT

TERMKEY_GETKEY(3) دليل وظائف المكتبة TERMKEY_GETKEY(3)

الاسم

termkey_getkey, termkey_getkey_force - استرداد حدث المفتاح التالي

الملخص

#include <termkey.h>

TermKeyResult termkey_getkey(TermKey *tk, TermKeyKey *key);
TermKeyResult termkey_getkey_force(TermKey *tk, TermKeyKey *key);

الربط مع -ltermkey.

الوصف

termkey_getkey() يحاول استرداد حدث ضغطة مفتاح واحدة من المخزن المؤقت لمثيل termkey(7)، ووضعه في البنية المشار إليها بواسطة key. تعود بإحدى القيم التالية:

TERMKEY_RES_KEY
تمت إزالة ضغطة مفتاح كاملة من المخزن المؤقت، وتم وضعها في بنية key.
TERMKEY_RES_AGAIN
تم العثور على حدث ضغطة مفتاح جزئي في المخزن المؤقت، ولكنه لا يحتوي بعد على جميع البايتات المطلوبة. تم وضع إشارة لما ستعيده termkey_getkey_force() في بنية key.
TERMKEY_RES_NONE
لا توجد بايتات في انتظار في المخزن المؤقت.
TERMKEY_RES_EOF

لا توجد بايتات جاهزة وتيار الإدخال مغلق الآن.
TERMKEY_RES_ERROR
تم الاستدعاء مع إيقاف إدخال/إخراج الطرفية، بسبب termkey_stop(3). في هذه الحالة، سيتم تعيين errno إلى EINVAL.

termkey_getkey_force() مشابهة لـ termkey_getkey() ولكنها لن تعود بـ TERMKEY_RES_AGAIN إذا تم العثور على تطابق جزئي. بدلاً من ذلك، ستجبر تفسير البايتات، حتى لو كان ذلك يعني تفسير بداية تسلسل متعدد البايتات مسبوق بحرف Escape كمفتاح Escape حرفي متبوع بأحرف عادية.

لن تقوم أي من هاتين الوظيفتين بحظر أو إجراء أي عمليات إدخال/إخراج على المقبض الملفي الأساسي. لاستخدام المثيل في برنامج غير متزامن، انظر termkey_advisereadable(3). للحصول على استدعاء حظر مناسب للاستخدام في برنامج متزامن، استخدم termkey_waitkey(3) بدلاً من termkey_getkey(). لتوفير إدخال بدون مقبض ملف قابل للقراءة، استخدم termkey_push_bytes(3).

قبل العودة، تقوم هذه الوظيفة بتوحيد بنية key وفقًا للقواعد المعطاة لـ termkey_canonicalise(3).

قيمة الإرجاع

termkey_getkey() تعود بتعداد من أحد TERMKEY_RES_KEY، TEMRKEY_RES_AGAIN، TERMKEY_RES_NONE، TERMKEY_RES_EOF أو TERMKEY_RES_ERROR. termkey_getkey_force() تعود بواحد من ما سبق، باستثناء TERMKEY_RES_AGAIN.

مثال

برنامج المثال التالي يطبع تفاصيل كل ضغطة مفتاح حتى يضغط المستخدم على Ctrl-C. يوضح كيفية استخدام مثيل termkey في برنامج نموذجي مدفوع بـ poll(2) غير متزامن، والذي قد يتضمن إدخال/إخراج مختلط مع مقابض ملفات أخرى.


// قد يحتاج <poll.h> هذا لـ sigset_t
#define _XOPEN_SOURCE 600
#include <poll.h>
#include <stdio.h>
#include "termkey.h"
static void on_key(TermKey *tk, TermKeyKey *key)
{
  char buffer[50];
  termkey_strfkey(tk, buffer, sizeof buffer, key, TERMKEY_FORMAT_VIM);
  printf("%s\n", buffer);
}
int main(int argc, char *argv[])
{
  TERMKEY_CHECK_VERSION;
  TermKey *tk = termkey_new(0, 0);
  if(!tk) {
    fprintf(stderr, "لا يمكن تخصيص مثيل termkey\n");
    exit(1);
  }
  struct pollfd fd;
  fd.fd = 0; /* المقبض الملفي الذي مررناه إلى termkey_new() */
  fd.events = POLLIN;
  TermKeyResult ret;
  TermKeyKey key;
  int running = 1;
  int nextwait = -1;
  while(running) {
    if(poll(&fd, 1, nextwait) == 0) {
      // انتهت المهلة
      if(termkey_getkey_force(tk, &key) == TERMKEY_RES_KEY)
        on_key(tk, &key);
    }
    if(fd.revents & (POLLIN|POLLHUP|POLLERR))
      termkey_advisereadable(tk);
    while((ret = termkey_getkey(tk, &key)) == TERMKEY_RES_KEY) {
      on_key(tk, &key);
      if(key.type == TERMKEY_TYPE_UNICODE &&
         key.modifiers & TERMKEY_KEYMOD_CTRL &&
         (key.code.codepoint == 'C' || key.code.codepoint == 'c'))
        running = 0;
    }
    if(ret == TERMKEY_RES_AGAIN)
      nextwait = termkey_get_waittime(tk);
    else
      nextwait = -1;
  }
  termkey_destroy(tk);
}
