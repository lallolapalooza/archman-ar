FBB::TempStream(3bobcat) ملف مؤقت FBB::TempStream(3bobcat)

الاسم

FBB::TempStream - ملف مؤقت

الملخص

#include <bobcat/tempstream>

الوصف

كائنات FBB::TempStream هي std::fstreams مؤقتة مفتوحة بالوضع 0600 (قراءة+كتابة للمستخدم فقط). الملف الذي تم إنشاؤه بواسطة كائن TempStream يتم حذفه من نظام الملفات بمجرد خروج كائن TempStream من نطاقه.

ينشئ كائن TempStream ملفًا فارغًا، ويمكن إدراج المعلومات فورًا في كائن TempStream. للتبديل بين الإدراج والاستخراج، قم ببساطة باستدعاء seekg (للاستخراج) أو seekp (للإدراج).

مساحة الاسم

FBB
جميع المنشئات والأعضاء والمعاملات والمعدلات المذكورة في صفحة الدليل هذه معرفة في مساحة الاسم FBB.

ترث من

std::fstream

المنشئات

o
TempStream(std::string const &base = "/tmp/FBB::TempStream"):
يقوم المنشئ بتهيئة الكائن وإنشاء ملف بالاسم الأساسي المحدد، والذي يتم إلحاق ستة أحرف عشوائية به. إذا تعذر إنشاء TempStream، يتم رمي FBB::Exception.

منشئات النسخ والنقل (وعوامل التعيين) غير متاحة.

دوال الأعضاء

جميع أعضاء std::fstream متاحة، حيث أن FBB::TempStream ترث من هذا الصف. بالإضافة إلى ذلك، يقدم TempStream نفسه:

o
std::string const &fileName() const:
اسم الملف المؤقت الذي تم إنشاؤه.

مثال

    #include <iostream>
    #include <bobcat/tempstream>
    using namespace std;
    using namespace FBB;
    int main()
    {
        TempStream ts("/tmp/demo");
        ts << "Hello world\n";
        ts.seekg(0);
        string line;
        getline(ts, line);
        cout << line << ", removed: " << ts.fileName() << ’\n’;
    }
