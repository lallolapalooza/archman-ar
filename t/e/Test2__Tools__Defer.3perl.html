Test2::Tools::Defer(3perl) دليل مبرمجي Perl Test2::Tools::Defer(3perl)

الاسم

Test2::Tools::Defer - اكتب اختبارات يتم تنفيذها في وقت لاحق

الوصف

في بعض الأحيان تحتاج إلى اختبار الأشياء قبل تحميل الوظائف اللازمة. تسمح لك هذه الوحدة بالقيام بذلك. يمكنك كتابة الاختبارات، ثم جعلها تعمل لاحقًا، بعد تحميل "Test2". تخبره بوظيفة الاختبار التي يجب تشغيلها، وما هي الوسائط التي يجب تمريرها إليها. سيتم تخزين اسم الوظيفة والوسائط لتنفيذها لاحقًا. عندما تكون جاهزًا، قم بتشغيل do_def() لبدء تشغيلها بمجرد تعريف الوظائف.

الخلاصة

use strict;
use warnings;
use Test2::Tools::Defer;
BEGIN {
    def ok => (1, 'pass');
    def is => ('foo', 'foo', 'runs is');
    ...
}
use Test2::Tools::Basic;
do_def(); # تشغيل الاختبارات
# تحديد المزيد من الاختبارات لتشغيلها لاحقًا:
def ok => (1, "another pass");
...
do_def(); # تشغيل الاختبارات الجديدة
done_testing;

تصدير

وظيفة def => @args;
سيؤدي هذا إلى تخزين اسم الوظيفة، والوسائط التي سيتم تشغيلها لاحقًا. لاحظ أن كل حزمة لديها مخزن منفصل للاختبارات التي سيتم تشغيلها.
do_def()
سيؤدي هذا إلى تشغيل جميع الاختبارات المخزنة. سيقوم أيضًا بإعادة تعيين القائمة لتكون فارغة حتى تتمكن من إضافة المزيد من الاختبارات للتشغيل لاحقًا.
