الحزمة: libtraceevent

NAME

tep_plugin_kvm_put_func - Libtraceevent KVM plugin

SYNOPSIS

#include <traceevent/libtraceevent.h>

int tep_plugin_kvm_put_func (struct tep_handle *tep);

DESCRIPTION

The KVM plugin provides functions to parse KVM specific tracepoints. It is automatically loaded by libtraceevent when it sees KVM tracepoints in the trace data.

This function can be used to load the KVM plugin manually.

RETURN VALUE

On success, it returns 0. On failure, it returns a negative value and sets the error code in tep->err.

EXAMPLE

This is a simple example of how to load the KVM plugin:

 struct tep_handle *tep;

 tep = tep_open_perf_file(NULL);
 if (!tep) {
  perror("tep_open_perf_file");
  return 1;
 }

 if (tep_plugin_kvm_put_func(tep) < 0) {
  fprintf(stderr, "Failed to load KVM plugin: %s\n", tep_strerror(tep));
  tep_close(tep);
  return 1;
 }

 // Now you can parse KVM tracepoints

Provides the function prototype and required structures.
