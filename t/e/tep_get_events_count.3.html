tep_get_events_count(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_get_event, tep_get_first_event, tep_get_events_count - الوصول إلى الأحداث.

الملخص

#include <event-parse.h>
struct tep_event *tep_get_event(struct tep_handle *tep, int index);
struct tep_event *tep_get_first_event(struct tep_handle *tep);
int tep_get_events_count(struct tep_handle *tep);

الوصف

تقوم الدالة tep_get_event() بإرجاع مؤشر إلى الحدث الموجود في index المحدد. الوسيط tep هو سياق محلل أحداث التتبع، و index هو فهرس الحدث المطلوب.

تقوم الدالة tep_get_first_event() بإرجاع مؤشر إلى الحدث الأول. نظرًا لتخزين الأحداث في مصفوفة، تقوم هذه الدالة بإرجاع مؤشر إلى بداية المصفوفة. الوسيط tep هو سياق محلل أحداث التتبع.

تقوم الدالة tep_get_events_count() بإرجاع عدد الأحداث في المصفوفة. الوسيط tep هو سياق محلل أحداث التتبع.

قيمة الإرجاع

تقوم الدالة tep_get_event() بإرجاع مؤشر إلى الحدث الموجود في index. يتم إرجاع NULL في حالة حدوث خطأ، أو في حالة عدم وجود أحداث، أو إذا كان index خارج النطاق.

تقوم الدالة tep_get_first_event() بإرجاع مؤشر إلى الحدث الأول. يتم إرجاع NULL في حالة حدوث خطأ، أو في حالة عدم وجود أحداث.

تقوم الدالة tep_get_events_count() بإرجاع عدد الأحداث. يتم إرجاع 0 في حالة حدوث خطأ، أو في حالة عدم وجود أحداث.

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
int i,count = tep_get_events_count(tep);
struct tep_event *event, *events = tep_get_first_event(tep);
if (events == NULL) {
        /* لا توجد أحداث */
} else {
        for (i = 0; i < count; i++) {
                event = (events+i);
                /* معالجة events[i] */
        }
        /* الحصول على الحدث الأخير */
        event = tep_get_event(tep, count-1);
}
