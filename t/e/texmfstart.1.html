mtxrun(1) أداة تشغيل ConTeXt TDS mtxrun(1)

الاسم


mtxrun - أداة تشغيل ConTeXt TDS

الملخص

mtxrun [ خيارات ... ] [ أسماء ملفات ]

الوصف

أداة تشغيل ConTeXt TDS

الخيارات

--script
تشغيل برنامج نصي mtx (طريقة lua المفضلة) (--noquotes)، لا يوجد برنامج نصي يعطي قائمة
--evaluate
تشغيل الكود المقدم في سطر الأوامر (بين علامتي اقتباس) (=loop) (exit|quit يوقف)
--execute
تشغيل برنامج نصي أو برنامج (طريقة texmfstart) (--noquotes)
--resolve
حل الوسائط ذات البادئة
--ctxlua
التشغيل داخليًا (باستخدام المكتبات المحملة مسبقًا)
--internal
تشغيل برنامج نصي باستخدام المكتبات المضمنة (نفس --ctxlua)
--locate
تحديد موقع اسم الملف المعطى في قاعدة البيانات (افتراضي) أو النظام (--first --all --detail)
--tree=pathtotree
استخدام شجرة texmf المعطاة (الملف الافتراضي: setuptex.tmf)
--path=runpath
الانتقال إلى المسار المعطى قبل التنفيذ
--ifchanged=filename
التنفيذ فقط عند تغيير الملف المعطى (ملخص md)
--iftouched=old,new
التنفيذ فقط عند تغيير الملف المعطى (الطابع الزمني)
--makestubs
إنشاء نوابط للبرامج النصية (المتعلقة بـ context)
--removestubs
إزالة النوابط (المتعلقة بـ context) للبرامج النصية
--stubpath=binpath
المسارات التي ستتم كتابة النوابط فيها
--windows
إنشاء نوابط ويندوز (mswin)
--unix
إنشاء نوابط يونكس (لينكس)
--addbinarypath
إضافة المسار الثنائي (الموجود) إلى بداية المشغلات
--verbose
تقديم المزيد من المعلومات
--trackers=list
تمكين المتعقبات المعطاة
--progname=str
التنسيق أو الواجهة الخلفية
--systeminfo=str
عرض نظام التشغيل الحالي، المعالج، إلخ.
--edit
تشغيل المحرر مع الملف الذي تم العثور عليه
--launch
تشغيل الملفات مثل الأدلة، يفترض دعم نظام التشغيل (--all,--list)
--timedrun
تشغيل برنامج نصي وتوقيت تنفيذه
--autogenerate
إعادة إنشاء قواعد البيانات عند الحاجة (مفيد عند استخدامه لتشغيل context في محرر)
--usekpse
استخدام kpse كبديل (عند عدم تثبيت mkiv و cache، غالبًا أبطأ)
--forcekpse
فرض استخدام kpse (مفيد عند عدم تثبيت mkiv و cache ولكن وظائف أقل)
--prefixes
عرض البادئات المدعومة
--generate
إنشاء قاعدة بيانات الملفات
--variables
عرض متغيرات التكوين
--configurations
عرض ترتيب التكوين
--directives
عرض التوجيهات (المعروفة)
--trackers
عرض المتعقبات (المعروفة)
--experiments
عرض التجارب (المعروفة)
--expand-braces
توسيع المتغير المعقد
--resolve-path
توسيع المتغير (حل المسارات بالكامل)
--expand-path
توسيع المتغير (حل المسارات)
--expand-var
توسيع المتغير (حل المراجع)
--show-path
عرض توسيع المسار لـ...
--var-value
تقرير قيمة المتغير
--find-file
تقرير موقع الملف
--find-path
تقرير مسار الملف
--pattern=string
تصفية المتغيرات
