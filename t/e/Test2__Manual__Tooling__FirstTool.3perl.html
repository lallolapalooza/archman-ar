Test2::Manual::Tooling::FirstTool(3perl) دليل مبرمجي بيرل Test2::Manual::Tooling::FirstTool(3perl)

الاسم

Test2::Manual::Tooling::FirstTool - اكتب أول أداة لك باستخدام Test2.

الوصف

سيساعدك هذا البرنامج التعليمي في كتابة أول أداة لك عن طريق استنساخ أداة ok().

الرمز الكامل مقدمًا

package Test2::Tools::MyOk;
use strict;
use warnings;
use Test2::API qw/context/;
use base 'Exporter';
our @EXPORT = qw/ok/;
sub ok($;$@) {
    my ($bool, $name, @diag) = @_;
    my $ctx = context();
    return $ctx->pass_and_release($name) if $bool;
    return $ctx->fail_and_release($name, @diag);
}
1;

سطر بسطر

sub ok($;$@) {
في هذه الحالة، نقوم بمحاكاة الدالة ok() التي تُصدرها Test2::Tools::Basic.

تستخدم ok() والأدوات المماثلة للتحقق النماذج الأولية لفرض تحليل الوسائط. لا يلزم بالضرورة أن تمتلك أدوات الاختبار الخاصة بك نماذج أولية، مثل أي دالة بيرل، عليك اتخاذ القرار بناءً على كيفية استخدامها.

النموذج الأولي يتطلب وسيطًا واحدًا على الأقل، والذي سيتم إجباره على سياق قياسي. الوسيط الثاني اختياري، ويتم إجباره أيضًا على أن يكون قياسيًا، وهو اسم الاختبار. يتم التعامل مع أي وسائط متبقية على أنها رسائل تشخيصية سيتم استخدامها فقط إذا فشل الاختبار.

my ($bool, $name, @diag) = @_;
هذا السطر لا يحتاج إلى الكثير من الشرح، نحن فقط نأخذ الوسائط.
my $ctx = context();
هذا سطر حيوي في **جميع** الأدوات. كائن السياق هو الواجهة الأساسية لأدوات الاختبار. **يجب** عليك الحصول على سياق إذا كنت ترغب في إصدار أي أحداث، مثل تقديم تأكيدات. علاوة على ذلك، فإن السياق مسؤول عن التأكد من أن الإخفاقات تُعزى إلى الملف ورقم السطر الصحيحين.

**ملاحظة:** يجب على دالة الاختبار دائمًا تحرير السياق عند الانتهاء منه، لا يمكنك ببساطة تركه خارج النطاق وجمع القمامة. يقوم Test2 بعمل جيد جدًا في الصراخ عليك إذا ارتكبت هذه الخطأ.

**ملاحظة:** **لا يجب** عليك أبدًا تخزين أو تمرير كائن سياق *حقيقي*. إذا كنت ترغب في الاحتفاظ بسياق لأي سبب، فيجب عليك استخدام `clone` لعمل نسخة "my $copy = $ctx->clone". يمكن تمرير النسخة أو تخزينها، ولكن **يجب** تحرير الأصل عند الانتهاء منه.

return $ctx->pass_and_release($name) if $bool;
عندما يكون $bool صحيحًا، يستخدم هذا السطر كائن السياق لإصدار حدث Test2::Event::Pass. إلى جانب إصدار الحدث، سيقوم أيضًا بتحرير كائن السياق وإرجاع القيمة `true`.

هذا اختصار لـ:

if($bool) {
    $ctx->pass($name);
    $ctx->release;
    return 1;
}
return $ctx->fail_and_release($name, @diag);
يصدر هذا السطر حدث Test2::Event::Fail، ويحرر كائن السياق، ويعيد القيمة `false`. سيتضمن حدث الفشل أي رسائل تشخيصية من مصفوفة @diag.

هذا اختصار لـ:

$ctx->fail($name, @diag);
$ctx->release;
return 0;

توثيق كائن السياق

Test2::API::Context هو المكان المناسب لقراءة ما هي الأساليب التي يوفرها السياق.
