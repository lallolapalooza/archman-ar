NAME

tep_register_event_handler - Register an event handler for a specific event.

SYNOPSIS

#include <tep.h>

int tep_register_event_handler(tep_handle_t handle, const char *event_name, tep_event_handler_t handler, void *data);

DESCRIPTION

Registers a callback function (handler) to be executed when an event with the specified name occurs.

handle: The tep handle obtained from tep_open().

event_name: The name of the event to listen for.

handler: The callback function to execute when the event occurs. The function should have the signature void handler(tep_handle_t handle, const char *event_name, void *data).

data: User-defined data to be passed to the handler function when the event occurs.

RETURN VALUE

Returns 0 on success, or a negative value on error.

EXAMPLE

```c #include <stdio.h> #include <tep.h> void my_event_handler(tep_handle_t handle, const char *event_name, void *data) { printf("Event '%s' occurred with data: %s\n", event_name, (char *)data); } int main() { tep_handle_t handle = tep_open("my_trace.dat"); if (!handle) { perror("tep_open"); return 1; } if (tep_register_event_handler(handle, "syscall", my_event_handler, "syscall_data") < 0) { perror("tep_register_event_handler"); tep_close(handle); return 1; } // Process events... tep_process_events(handle); tep_close(handle); return 0; } ```
