Test2::Bundle::Extended(3perl) دليل مبرمجي بيرل Test2::Bundle::Extended(3perl)

الاسم

Test2::Bundle::Extended - الاسم القديم لـ Test2::V0

*** تم إهماله ***

تم تغيير اسم هذه الحزمة إلى Test2::V0، حيث تم إزالة العلامة ':v1' لأنها غير ضرورية.

الوصف

هذه هي الحزمة الأم. تتضمن هذه الحزمة تقريبًا كل الأدوات، وبعض الإضافات، التي يستخدمها مؤلف Test2. تستخدم هذه الحزمة بشكل مكثف لاختبار Test2::Suite نفسها.

ملخص

use Test2::Bundle::Extended ':v1';
ok(1, "pass");
...
done_testing;

حل التعارضات مع MOOSE

use Test2::Bundle::Extended '!meta';

تقوم كل من Moose و Test2::Bundle::Extended بتصدير دوال meta() مختلفة جدًا. إضافة '!meta' إلى وسائط الاستيراد ستمنع استيراد الدالة. تقوم هذه الحزمة أيضًا بتصدير الدالة تحت الاسم meta_check() حتى تتمكن من استخدام هذه الصيغة كبديل.

العلامات

:v1
:DEFAULT
كل ما يلي متطابق: 
use Test2::Bundle::Extended;
use Test2::Bundle::Extended ':v1';
use Test2::Bundle::Extended ':DEFAULT';

إعادة التسمية عند الاستيراد

use Test2::Bundle::Extended ':v1', '!ok', ok => {-as => 'my_ok'};

تستخدم هذه الحزمة Importer للتصدير، وبذلك يمكنك استخدام أي وسائط يقبلها.

شرح:

:v1
استخدام العلامة الافتراضية، وجميع الصادرات الافتراضية.
'!ok'
لا تصدّر ok()
ok => {-as => 'my_ok'}
في الواقع، قم باستيراد ok() ولكن تحت اسم my_ok().

إذا لم تضف وسيط '!ok' فستحصل على كل من ok() و my_ok()

التعليمات

يمكن تعطيل كل هذه عبر وسائط استيراد فردية، أو عبر وسيط "-no_pragmas".

use Test2::Bundle::Extended -no_pragmas => 1;

صارم

تم تفعيل صارم لك. يمكنك تعطيل هذا باستخدام وسائط الاستيراد "-no_strict" أو "-no_pragmas":

use Test2::Bundle::Extended -no_strict => 1;

تحذيرات

تم تفعيل التحذيرات لك. يمكنك تعطيل هذا باستخدام وسائط الاستيراد "-no_warnings" أو "-no_pragmas":

use Test2::Bundle::Extended -no_warnings => 1;

UTF8

يتم هذا بالفعل عبر إضافة Test2::Plugin::UTF8، راجع قسم "PLUGINS" لمزيد من التفاصيل.

ملاحظة: "-no_pragmas => 1" سيقوم بتعطيل الإضافة بالكامل.

الإضافات

SRAND

راجع Test2::Plugin::SRand.

سيقوم هذا بتعيين بذرة العشوائية لتاريخ اليوم. يمكنك توفير بذرة بديلة باستخدام خيار الاستيراد "-srand":

use Test2::Bundle::Extended -srand => 1234;

UTF8

راجع Test2::Plugin::UTF8.

سيقوم هذا بتعيين الملف، وجميع مقابض الإخراج (بما في ذلك مقابض المُنسق)، إلى utf8. سيقوم هذا بتفعيل تعليمة utf8 للنطاق الحالي.

يمكن تعطيل هذا باستخدام وسائط الاستيراد "-no_utf8 => 1" أو "-no_pragmas => 1".

use Test2::Bundle::Extended -no_utf8 => 1;

ملخص الخروج

راجع Test2::Plugin::ExitSummary.

هذه الإضافة ليس لها تهيئة.

وظائف API

راجع Test2::API لهذه الوظائف

$ctx = context()
$events = intercept { ... }

أدوات

الهدف

راجع Test2::Tools::Target.

يمكنك تحديد فئة هدف باستخدام وسيط الاستيراد "-target". إذا لم تقدم هدفًا، فلن يتم استيراد $CLASS و CLASS().

use Test2::Bundle::Extended -target => 'My::Class';
print $CLASS;  # My::Class
print CLASS(); # My::Class

أو يمكنك تحديد أسماء:

use Test2::Bundle::Extended -target => { pkg => 'Some::Package' };
pkg()->xxx; # استدعاء 'xxx' على Some::Package
$pkg->xxx;  # نفس الشيء
$CLASS
متغير الحزمة الذي يحتوي على اسم فئة الهدف.
$class = CLASS()
دالة ثابتة تُرجع اسم فئة الهدف.

تأجيل

راجع Test2::Tools::Defer.

def $func => @args;
do_def()

أساسي

راجع Test2::Tools::Basic.

ok($bool, $name)
pass($name)
fail($name)
diag($message)
note($message)
$todo = todo($reason)
todo $reason => sub { ... }
skip($reason, $count)
plan($count)
skip_all($reason)
done_testing()
bail_out($reason)
