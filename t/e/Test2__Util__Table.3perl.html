Test2::Util::Table(3perl) دليل مبرمجي Perl Test2::Util::Table(3perl)

الاسم

Test2::Util::Table - تنسيق رأس وجداول إلى جدول

الوصف

يُستخدم هذا بواسطة بعض الاختبارات الفاشلة لتوفير تشخيصات حول ما حدث بشكل خاطئ. هذه الوحدة قادرة على تنسيق عام لصفوف البيانات في جداول.

الملخص

use Test2::Util::Table qw/table/;
my @table = table(
    max_width => 80,
    collapse => 1, # لا تعرض الأعمدة الفارغة
    header => [ 'الاسم', 'العمر', 'لون الشعر' ],
    rows => [
        [ 'فريد فلينتستون',  2000000, 'أسود' ],
        [ 'ويلما فلينتستون', 1999995, 'أحمر' ],
        ...,
    ],
);
# يحتوي المصفوفة @table على كل سطر من الجدول، ولا يتم إضافة أسطر جديدة.
say $_ for @table;

هذا يطبع جدولاً مثل هذا:

+-----------------+---------+------------+
| الاسم            | العمر     | لون الشعر |
+-----------------+---------+------------+
| فريد فلينتستون  | 2000000 | أسود      |
| ويلما فلينتستون | 1999995 | أحمر        |
| ...             | ...     | ...        |
+-----------------+---------+------------+

التصديرات

@rows = table(...)

تُرجع الدالة قائمة بالأسطر، والأسطر لا تحتوي على حرف "\n" مضاف.

الخيارات:

header => [ ... ]
إذا كنت تريد رأسًا، قم بتحديده هنا. يأخذ هذا مرجع مصفوفة مع عنوان كل عمود.
rows => [ [...], [...], ... ]
يجب أن يكون هذا مرجع مصفوفة يحتوي على مرجع مصفوفة لكل صف.
collapse => $bool
استخدم هذا إذا كنت تريد إخفاء الأعمدة الفارغة، أي أي عمود لا يحتوي على بيانات في أي صف. وجود رأس للعمود لن يؤثر على الطي.
max_width => $num
حدد الحد الأقصى لعرض الجدول، قد لا يكون الجدول بهذا الحجم، لكنه لن يكون أكبر منه. إذا لم يتم تحديد أي شيء، فسيحاول العثور على عرض طرفيتك واستخدامه، وإلا فسيعود إلى 80.
sanitize => $bool
سيقوم هذا بتنقية جميع البيانات في الجدول بحيث يتم استبدال الأسطر الجديدة والأحرف التحكم وجميع المسافات البيضاء باستثناء ASCII 20 ' ' بتسلسلات هروب. هذا يمنع الأسطر الجديدة وعلامات الجدول والمسافات البيضاء المماثلة من تعطيل الجدول.

ملاحظة: يتم تمييز الأسطر الجديدة كـ '\n'، ولكن يتم أيضًا إدراج سطر جديد في البيانات بحيث يتم عرضه عادةً بطريقة مفيدة للبشر.

مثال:

my $field = "foo\nbar\nbaz\n";
print join "\n" => table(
    sanitize => 1,
    rows => [
        [$field,      'col2'     ],
        ['row2 col1', 'row2 col2']
    ]
);

يطبع:

+-----------------+-----------+
| foo\n           | col2      |
| bar\n           |           |
| baz\n           |           |
|                 |           |
| row2 col1       | row2 col2 |
+-----------------+-----------+

لذلك يقوم بتمييز الأسطر الجديدة عن طريق إدراج تسلسل الهروب، لكنه يعرض أيضًا البيانات عبر أكبر عدد ممكن من الأسطر كما لو كانت ستظهر عادةً.

mark_tail => $bool
سيقوم هذا باستبدال آخر حرف مسافة بيضاء في أي مسافة بيضاء زائدة بتسلسل الهروب الخاص بها. هذا يجعل من السهل ملاحظة المسافات البيضاء الزائدة عند مقارنة القيم.

my $cols = term_size()

يحاول العثور على العرض بالأعمدة (الأحرف) للطرفية الحالية. يُرجع 80 كخيار آمن إذا لم يتمكن من العثور عليه بطريقة أخرى.

ملاحظة حول أحرف اليونيكود/الأحرف العريضة

بعض أحرف اليونيكود، مثل "婧" ("U+5A67") أعرض من غيرها. ستظهر هذه بشكل جيد إذا قمت بتنفيذ "use utf8;" حسب الضرورة، وتم تثبيت Unicode::GCString، ولكن إذا لم تكن الوحدة مثبتة، فستكون هناك شذوذات في الجدول:

+-----+-----+---+
| a   | b   | c |
+-----+-----+---+
| 婧 | x   | y |
| x   | y   | z |
| x   | 婧 | z |
+-----+-----+---+

المصدر

يمكن العثور على مستودع الكود المصدري لـ Test2-Suite على https://github.com/Test-More/test-more/.
