Test2::Util::Facets2Legacy(3perl) دليل مبرمجي بيرل Test2::Util::Facets2Legacy(3perl)

الاسم

Test2::Util::Facets2Legacy - تحويل بيانات الأوجه إلى واجهة برمجة التطبيقات القديمة للأحداث.

الوصف

تقوم هذه الوحدة بتصدير العديد من الروتينات الفرعية من واجهة برمجة التطبيقات القديمة للأحداث (انظر Test2::Event). يمكن استخدام هذه الروتينات الفرعية كطرق لأي كائن يوفر طريقة facet_data() مخصصة. يمكن أيضًا استخدام هذه الروتينات الفرعية كدوال تأخذ هاشرف بيانات الأوجه كمعاملات.

الملخص

كطرق

package My::Event;
use Test2::Util::Facets2Legacy ':ALL';
sub facet_data { return { ... } }

ثم للاستخدام:

my $e = My::Event->new(...);
my $causes_fail = $e->causes_fail;
my $summary     = $e->summary;
....

كدوال

use Test2::Util::Facets2Legacy ':ALL';
my $f = {
    assert => { ... },
    info => [{...}, ...],
    control => {...},
    ...
};
my $causes_fail = causes_fail($f);
my $summary     = summary($f);

ملاحظة حول الدورات

عند استخدامها كطرق، تستدعي جميع هذه الروتينات الفرعية "$e->facet_data()". تعتمد طريقة facet_data() الافتراضية في Test2::Event على الطرق القديمة التي تحاكيها هذه الوحدة لكي تعمل. نتيجة لذلك، من السهل جدًا إنشاء أخطاء التكرار اللانهائي.

تحتوي هذه الطرق على اكتشاف الدورات وستقوم بإلقاء استثناء مبكرًا إذا تم اكتشاف دورة. uuid() هي حاليًا الروتين الفرعي الوحيد في هذه المكتبة الذي يحتوي على سلوك احتياطي عند اكتشاف الدورات.

المصدر

لا يتم تصدير شيء بشكل افتراضي. يجب عليك تحديد الطرق المراد استيرادها، أو استخدام الوسم ':ALL'.

$bool = $e->causes_fail()
$bool = causes_fail($f)
تحقق مما إذا كان الحدث أو الأوجه تؤدي إلى حالة فشل.
$bool = $e->diagnostics()
$bool = diagnostics($f)
تحقق مما إذا كان الحدث أو الأوجه تحتوي على أي معلومات تشخيصية.
$bool = $e->global()
$bool = global($f)
تحقق مما إذا كان الحدث أو الأوجه تحتاج إلى معالجة عالمية.
$bool = $e->increments_count()
$bool = increments_count($f)
تحقق مما إذا كان الحدث أو الأوجه يقوم بتأكيد.
$bool = $e->no_display()
$bool = no_display($f)
تحقق مما إذا كان الحدث أو الأوجه يجب عرضه أو إخفاؤه.
($max, $directive, $reason) = $e->sets_plan()
($max, $directive, $reason) = sets_plan($f)
تحقق مما إذا كان الحدث أو الأوجه يضع خطة، وأرجع تفاصيل الخطة.
$id = $e->subtest_id()
$id = subtest_id($f)
احصل على معرف الاختبار الفرعي، إن وجد.
$string = $e->summary()
$string = summary($f)
احصل على ملخص الحدث أو هاش الأوجه، إن وجد.
$undef_or_int = $e->terminate()
$undef_or_int = terminate($f)
تحقق مما إذا كان الحدث أو الأوجه يجب أن يؤدي إلى إنهاء العملية، وإذا كان الأمر كذلك، يتم إرجاع رمز الخروج (والذي يمكن أن يكون 0). يتم إرجاع undef إذا لم يتم طلب الإنهاء.
$uuid = $e->uuid()
$uuid = uuid($f)
احصل على معرف UUID للأوجه أو الحدث.

ملاحظة: سيعود إلى "$e->SUPER::uuid()" إذا تم اكتشاف دورة وتم استخدام حدث كمعامل.
