الحزمة: texinfo

التراخيص: GPL3

TEXI2DVI(1) أوامر المستخدم TEXI2DVI(1)

الاسم

texi2dvi - تحويل مستندات Texinfo إلى DVI أو PDF

الملخص

texi2dvi [خيار]... ملف...
texi2pdf [خيار]... ملف...
pdftexi2dvi [خيار]... ملف...

الوصف

تشغيل كل ملف Texinfo أو (La)TeX FILE من خلال TeX بالتناوب حتى يتم حل جميع الإحالات المرجعية، وبناء جميع الفهارس. يتم البحث في الدليل الذي يحتوي على كل FILE عن الملفات المضمنة. يتم استخدام لاحقة FILE لتحديد لغته ((La)TeX أو Texinfo). لمعالجة ملفات TeX العادية (e)plain، قم بتعيين متغير البيئة LATEX=tex.

عند الاستدعاء كـ `texi2pdf' أو مع الخيار --pdf، يتم إنشاء مخرجات PDF. خلاف ذلك، يتم إنشاء DVI.

خيارات عامة:

-D, --debug
تشغيل تصحيح الشل (تعيين -x)
-h, --help
عرض هذا المساعدة والخروج بنجاح
-o, --output=OFILE
ترك الإخراج في OFILE؛ يُسمح بملف إدخال واحد فقط
-q, --quiet
لا يوجد إخراج إلا في حالة وجود أخطاء
-v, --version
عرض معلومات الإصدار والخروج بنجاح
-V, --verbose
الإبلاغ عما يتم القيام به
--max-iterations=N
لا تعالج الملفات أكثر من N مرة [7]
--mostly-clean
إزالة الملفات أو الدلائل المساعدة من عمليات التشغيل السابقة (ولكن ليس الإخراج)

شكل الإخراج:

--dvi
إنشاء ملف DVI [افتراضي]
--dvipdf
إنشاء ملف PDF عبر DVI (باستخدام برنامج تحويل DVI إلى PDF)
-p, --pdf
استخدام pdftex أو pdflatex للمعالجة
--ps
إنشاء ملف PostScript عبر DVI (باستخدام dvips)

ضبط TeX:

-E, --expand
توسيع الماكرو باستخدام makeinfo
-I DIR
ابحث في DIR عن ملفات Texinfo
-l, --language=LANG
حدد LANG للملف، إما latex أو texinfo
--no-line-error
لا تمرر --file-line-error إلى TeX
--shell-escape
مرر --shell-escape إلى TeX
--src-specials
مرر --src-specials إلى TeX
--translate-file=FILE
استخدم ملف ترجمة الترميز المحدد لـ TeX
-t, --command=CMD
أدرج CMD في نسخة من ملف الإدخال

أوضاع البناء:

--build=MODE
حدد طريقة التعامل مع الملفات المساعدة [local]
--tidy
نفس الشيء مثل --build=tidy
-c, --clean
نفس الشيء مثل --build=clean
--build-dir=DIR
حدد مكان إجراء تجميع tidy؛ يعني ضمنيًا --tidy

يحدد MODE مكان إجراء تجميع TeX، وبناءً على ذلك، كيفية التعامل مع الملفات المساعدة.

القيم الصالحة لـ MODE هي:

`local'
قم بالتجميع في الدليل الحالي، مع ترك جميع الملفات المساعدة. هذا هو استخدام TeX التقليدي.
`tidy'
قم بالتجميع في دليل *.t2d محلي، حيث تُترك الملفات المساعدة. يتم نسخ ملفات الإخراج مرة أخرى إلى الملف الأصلي.
`clean'
نفس الشيء مثل `tidy'، ولكن قم بإزالة الدليل المساعد بعد ذلك. كل تجميع يتطلب بالتالي الدورة الكاملة.

يمكن أيضًا تعيين وضع البناء باستخدام متغير البيئة TEXI2DVI_BUILD_MODE. يمكن أيضًا تعيين دليل البناء tidy باستخدام متغير البيئة TEXI2DVI_BUILD_DIRECTORY.

تُستخدم قيم متغيرات البيئة هذه لتشغيل الأوامر المقابلة، إذا تم تعيينها:

BIBER BIBTEX DVIPDF DVIPS EGREP LATEX MAKEINDEX MAKEINFO PDFLATEX PDFTEX SED TEX TEXINDEX TEXINDY THUMBPDF_CMD

فيما يتعلق بـ --dvipdf، إذا لم يتم تعيين DVIPDF في البيئة، يتم البحث عن البرامج التالية (بهذا الترتيب): dvipdfmx dvipdfm dvipdf dvi2pdf dvitopdf.

إذا تم تثبيت Texinfo على موقعك، فإن الأمر

info texi2dvi

يجب أن يمنحك الوصول إلى وثائق إضافية.
