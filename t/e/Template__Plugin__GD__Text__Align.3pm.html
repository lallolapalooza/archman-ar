Template__Plugin__GD__Text__Align(3pm)

الحزمة: perl-template-gd

التراخيص: GPL, PerlArtistic

Template::Plugin::GD::Text::Align(3) وثائق مساهمة المستخدم من Perl Template::Plugin::GD::Text::Align(3)

الاسم

Template::Plugin::GD::Text::Align - ارسم نصوصًا محاذاة في صور GD

الملخص

[% USE align = GD.Text.Align(gd_image); %]

أمثلة

[% FILTER null;
    USE im  = GD.Image(100,100);
    USE gdc = GD.Constants;
    # تخصيص بعض الألوان
    black = im.colorAllocate(0,   0, 0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,  255);
    # ارسم شكل بيضاوي أزرق
    im.arc(50,50,95,75,0,360,blue);
    USE a = GD.Text.Align(im);
    a.set_font(gdc.gdLargeFont);
    a.set_text("Hello");
    a.set(colour => red, halign => "center");
    a.draw(50,70,0);
    # إخراج الصورة بصيغة PNG
    im.png | stdout(1);
   END;
-%]

الوصف

توفر الإضافة GD.Text.Align واجهة لوحدة GD::Text::Align. تسمح برسم النصوص في صور GD بمحاذاة واتجاهات مختلفة.

راجع GD::Text::Align لمزيد من التفاصيل. راجع Template::Plugin::GD::Text::Wrap للحصول على إضافة تسمح لك بعرض نصوص متوازية في صور GD.

المؤلف

كتب توماس بوتل مكتبة GD الرسومية.

كتب لينكون د. شتاين وحدات Perl GD التي تتفاعل معها وكتب مارتين فيربورجن وحدة GD::Text.

كتب كريج بارات <craig@arraycomm.com> إضافات GD الأصلية لمجموعة أدوات القالب (2001).

قام آندي واردلي <abw@cpan.org> باستخراجها من نواة TT إلى توزيع منفصل لإصدار TT 2.15.

تبحث هذه الوحدات عن صائن جديد. يرجى الاتصال بآندي واردلي إذا كنت مستعدًا للمساعدة.
