NAME

Test::Fatal — Test for exceptions, fatal errors, and other non-local exits

VERSION

version 0.018

SYNOPSIS

use Test::More tests => 2;
use Test::Fatal;

# die
is( living( sub { die "This is an error" } ), undef, "dies dies" );
is( lives( sub { die "This is an error" } ), undef, "lives lives" );

# croak
is( living( sub { croak "This is an error" } ), undef, "croak dies" );
is( lives( sub { croak "This is an error" } ), undef, "croak lives" );

# eval
is( living( sub { eval { die "This is an error" } } ), undef, "eval dies" );
is( lives( sub { eval { die "This is an error" } } ), undef, "eval lives" );

# ok
ok( living( sub { 1 } ), "1 lives" );
ok( lives( sub { 1 } ), "1 lives" );

# specific exception
is( living( sub { die Exception->new("foo") } ), undef, "dies specific" );
is( lives( sub { die Exception->new("foo") } ), undef, "lives specific" );

# check the exception
my $expected_exception = Exception->new("foo");
my $actual_exception = lives( sub { die $expected_exception } );
is( $actual_exception, $expected_exception, "check exception" );
ok( $actual_exception->isa("Exception"), "exception is an Exception" );

# check the exception message
is( lives( sub { die "Bad foo!" } ), "Bad foo!", "check message" );

# check exception type
is( lives( sub { die Exception->new("foo") }, "Exception" ), undef, "lives correct exception type" );
isnt( lives( sub { die Exception->new("foo") }, "SomeOtherException" ), undef, "lives wrong exception type" );

# check exception message with type
is( lives( sub { die Exception->new("foo") }, "Exception", qr/foo/ ), undef, "lives exception type and message" );
isnt( lives( sub { die Exception->new("foo") }, "Exception", qr/bar/ ), undef, "lives exception type and wrong message" );

# dies_ok
dies_ok { die "This is an error" };
dies_ok { die Exception->new("foo") }, "Exception";
dies_ok { die Exception->new("foo") }, "Exception", "dies_ok with type and message";

# lives_ok
lives_ok { 1 };
lives_ok { die "This is an error" }, "This is an error";
lives_ok { die Exception->new("foo") }, "Exception";
lives_ok { die Exception->new("foo") }, "Exception", "Exception with message";

# sanity check
my $is_it_alive = lives( sub { 1 } );
ok( $is_it_alive, "lives returns true for successful code" );
is( $is_it_alive, 1, "lives returns exactly 1 for successful code" );

# $TODO
my $ok = lives( sub { die "This is an error" } );
skip( "dies are okay", 1, $ok );

# $TODO
my $ok = lives( sub { die "This is an error" } );
todo_skip( "dies are okay", 1, $ok );

# stack trace
use Test::Fatal qw(show_stacktrace);
sub foo { bar() }
sub bar { baz() }
sub baz { die "error" }
{
    local $@;
    eval { foo() };
    diag( show_stacktrace() );
}

# Test::Exception integration
use Test::Exception;
throws_ok { die "This is an error" } qr/This is an error/;

# Test::Fatal and Test::Exception are compatible
throws_ok { die "This is an error" } qr/This is an error/;
dies_ok { die "This is an error" };

# Test::Fatal and Test::Exception are compatible
my $caught = lives { die "This is an error" };
isa_ok( $caught, "Test::Fatal::Exception" );

# Test::Fatal::Exception and Test::Exception
throws_ok {
    my $caught = lives { die "This is an error" };
    Test::Exception::Exception->throw( message => $caught );
} qr/This is an error/;

DESCRIPTION

This module provides functions for testing code that is expected to die, or not die.

It is useful for testing code that might throw exceptions, or for testing code that should not throw exceptions.

It works by wrapping the code in an eval block, and then checking the value of $@.

It is intended to be a more convenient and flexible replacement for Test::Exception.

PERL_VERSION

This module requires Perl 5.008001 or later.

FUNCTIONS

lives( coderef [, exception_class [, exception_message ]] )

Tests if the code in coderef runs without dying. If it does not die, it returns the value that was returned by the code. If it does die, it returns undef.

If exception_class is provided, it checks if the died exception is an instance of that class. If it is not, it fails the test.

If exception_message is provided, it checks if the died exception's message matches the provided value (which can be a string or a regular expression). If it does not match, it fails the test.

If the code dies, and the checks for exception_class and exception_message fail, then lives returns undef.

This function returns the actual exception object if the code dies, otherwise it returns the value of the code.

living( coderef )

Tests if the code in coderef runs without dying. If it does not die, it returns true. If it does die, it returns undef.

This is similar to lives, but it does not return the value of the code, nor does it check for specific exception classes or messages.

dies_ok( coderef [, exception_class [, exception_message ]] )

Tests if the code in coderef dies. If it does not die, it fails the test. If it does die, it passes the test.

If exception_class and exception_message are provided, it checks if the died exception matches those criteria. If they do not match, it fails the test.

lives_ok( coderef [, exception_class [, exception_message ]] )

Tests if the code in coderef runs without dying. If it does not die, it passes the test. If it does die, it fails the test.

If exception_class and exception_message are provided, it checks if the died exception matches those criteria. If they do not match, it fails the test.

show_stacktrace()

Returns the current stack trace, as a string. This is useful for debugging, and can be used with Test::More::diag to print the stack trace to STDERR.
