Test2__V0.3perl

Test2::V0(3perl) دليل مبرمجي Perl Test2::V0(3perl)

الاسم

Test2::V0 - الإصدار 0 من حزمة Test2 الموصى بها.

الوصف

هذه هي الحزمة الرئيسية. تتضمن هذه الحزمة تقريبًا كل أداة، والعديد من المكونات الإضافية، التي يستخدمها مؤلف Test2. تُستخدم هذه الحزمة على نطاق واسع لاختبار Test2::Suite نفسها.

التسمية، الاستخدام، الاعتماد

لا ينبغي أن تتغير هذه الحزمة بطريقة غير متوافقة بشدة. قد يُسمح ببعض التغييرات الطفيفة التي تسبب كسر التوافق، وخاصة إصلاحات الأخطاء. إذا كانت هناك حاجة لتغييرات تسبب كسر التوافق، فيجب إصدار وحدة "Test2::V#" جديدة بدلاً من ذلك.

مع إصدار وحدات "V#" جديدة، قد يتم نقل الوحدات القديمة إلى توزيعات cpan مختلفة. يجب عليك دائمًا استخدام إصدار حزمة محدد وإدراج هذا الإصدار في متطلبات اختبار توزيعاتك. لا يجب عليك ببساطة إدراج Test2::Suite كاعتماد لتوزيعاتك، بل أدرج الحزمة المحددة، أو الأدوات والمكونات الإضافية التي تستخدمها مباشرة في البيانات الوصفية الخاصة بك.

ملخص

use Test2::V0;
ok(1, "pass");
...
done_testing;

حل التعارضات مع MOOSE

use Test2::V0 '!meta';

تقوم كل من Moose و Test2::V0 بتصدير دوال meta() مختلفة جدًا. سيمنع إضافة '!meta' إلى وسائط الاستيراد تصدير الدالة. تقوم هذه الحزمة أيضًا بتصدير الدالة تحت اسم meta_check() بحيث يمكنك استخدام هذا الهجاء كبديل.

علامات

:DEFAULT
ما يلي متطابقان: 
use Test2::V0;
use Test2::V0 ':DEFAULT';

إعادة التسمية عند الاستيراد

use Test2::V0 ':DEFAULT', '!ok', ok => {-as => 'my_ok'};

تستخدم هذه الحزمة Test2::Util::Importer للتصدير، وبالتالي يمكنك استخدام أي وسائط تقبلها.

الشرح:

'!ok'
لا تصدّر ok()
ok => {-as => 'my_ok'}
في الواقع، قم بتصدير ok() ولكن تحت اسم my_ok().

إذا لم تضف الوسيط '!ok'، فستحصل على كل من ok() و my_ok()

أوامر

يمكن تعطيل كل هذه عن طريق وسائط استيراد فردية، أو عن طريق الوسيط "-no_pragmas".

use Test2::V0 -no_pragmas => 1;

صارم

يتم تشغيل strict لك. يمكنك تعطيل هذا باستخدام وسائط الاستيراد "-no_strict" أو "-no_pragmas":

use Test2::V0 -no_strict => 1;

تحذيرات

يتم تشغيل warnings لك. يمكنك تعطيل هذا باستخدام وسائط الاستيراد "-no_warnings" أو "-no_pragmas":

use Test2::V0 -no_warnings => 1;

UTF8

يتم ذلك فعليًا عبر المكون الإضافي Test2::Plugin::UTF8، انظر قسم "المكونات الإضافية" لمزيد من التفاصيل.

ملاحظة: "-no_pragmas => 1" سيقوم بتعطيل المكون الإضافي بأكمله.

المكونات الإضافية

SRAND

انظر Test2::Plugin::SRand.

سيؤدي هذا إلى تعيين البذرة العشوائية إلى تاريخ اليوم. يمكنك توفير بذرة بديلة مع خيار الاستيراد "-srand":

use Test2::V0 -srand => 1234;

يمكنك أيضًا تعطيل هذا السلوك:

use Test2::V0 -no_srand => 1;

ملاحظة عندما يكون srand قيد التشغيل (افتراضي) يمكن أن يسبب مشاكل مع أشياء مثل File::Temp التي ستنتهي بمحاولة نفس أسماء الملفات "العشوائية" لكل عملية اختبار تبدأ في يوم معين (أو مشاركة نفس البذرة).

UTF8

انظر Test2::Plugin::UTF8.

سيؤدي هذا إلى تعيين الملف، وجميع مقبضات الإخراج (بما في ذلك مقبضات التنسيق)، إلى utf8. سيقوم بتشغيل الأمر utf8 للمدى الحالي.

يمكن تعطيل هذا باستخدام وسائط الاستيراد "-no_utf8 => 1" أو "-no_pragmas => 1".

use Test2::V0 -no_utf8 => 1;

ملخص الخروج

انظر Test2::Plugin::ExitSummary.

لا يحتوي هذا المكون الإضافي على تكوين.

متغيرات البيئة

انظر Test2::Env للحصول على قائمة بالمتغيرات البيئية الهامة.

وظائف API

انظر Test2::API لهذه

$ctx = context()
$events = intercept { ... }

أدوات

الهدف

انظر Test2::Tools::Target.

يمكنك تحديد فئة هدف باستخدام وسيط الاستيراد "-target". إذا لم تقدم هدفًا، فلن يتم استيراد $CLASS و CLASS().

use Test2::V0 -target => 'My::Class';
print $CLASS;  # My::Class
print CLASS(); # My::Class

أو يمكنك تحديد أسماء:

use Test2::V0 -target => { pkg => 'Some::Package' };
pkg()->xxx; # استدعاء 'xxx' على Some::Package
$pkg->xxx;  # نفس الشيء
$CLASS
متغير الحزمة الذي يحتوي على اسم فئة الهدف.
$class = CLASS()
وظيفة ثابتة تُرجع اسم فئة الهدف.

تأجيل

انظر Test2::Tools::Defer.

def $func => @args;
do_def()

أساسي

انظر Test2::Tools::Basic.

ok($bool, $name)
ok($bool, $name, @diag)
pass($name)
pass($name, @diag)
fail($name)
fail($name, @diag)
diag($message)
note($message)
$todo = todo($reason)
todo $reason => sub { ... }
skip($reason, $count)
plan($count)
skip_all($reason)
done_testing()
