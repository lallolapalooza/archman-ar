الحزمة: texlive-bin

التراخيص: GPL-2.0-or-later

LUATEX(1) دليل الأوامر العامة LUATEX(1)

الاسم

luatex, dviluatex, luahbtex, luajittex, texlua, texluac - إصدار موسع من TeX يستخدم Lua كلغة برمجة نصية مدمجة

ملخص

luatex [--lua=FILE] [OPTION]... [TEXNAME[.tex]] [COMMANDS]
luatex [--lua=FILE] [OPTION]... \FIRST-LINE
luatex [--lua=FILE] [OPTION]... &FMT [ARGS]

الوصف

قم بتشغيل أداة تنسيق luaTeX على TEXNAME، مما يؤدي عادةً إلى إنشاء TEXNAME.pdf. تتم معالجة أي COMMANDS متبقية كمدخلات luaTeX، بعد قراءة TEXNAME.

بدلاً من ذلك، إذا بدأ أول وسيط غير خيار بشرطة مائلة عكسية، فقم بتفسير جميع الوسائط غير الاختيارية كسطر من مدخلات luaTeX.

بدلاً من ذلك، إذا بدأ أول وسيط غير خيار بـ &، يؤخذ الكلمة التالية على أنها FMT للقراءة، مما يحل محل كل شيء آخر. تتم معالجة الوسائط المتبقية كما هو موضح أعلاه.

إذا لم يتم تحديد أي وسائط أو خيارات، اطلب الإدخال.

إذا تم استدعاؤه كـ texlua، فإنه يتصرف كمفسر Lua. إذا تم استدعاؤه كـ texluac، فإنه يتصرف كمترجم لغة Lua الثنائية.

بدأ LuaTeX كإصدار موسع من pdfTeX مع دعم Unicode والخطوط OpenType، ولغة برمجة Lua المدمجة، وامتدادات e-TeX و Omega، بالإضافة إلى محرك MetaPost متكامل، يمكنه إنشاء ملفات PDF بالإضافة إلى ملفات DVI. لمزيد من المعلومات حول luatex، انظر http://www.luatex.org؛ ويمكنك قراءة دليل LuaTeX باستخدام الأداة المساعدة texdoc (texdoc luatex).

تعتبر جميع مدخلات ومخرجات نص LuaTeX نصًا مطابقًا لـ Unicode، على الرغم من أن المرشحات المختلفة تجعل من الممكن دعم أي ترميز.

في وضع DVI، يمكن استخدام LuaTeX كبديل كامل لمحرك TeX.

في وضع PDF، يمكن لـ LuaTeX التعامل بشكل أصلي مع تنسيقات الرسوميات PDF، JPG، JBIG2، و PNG. لا يمكن لـ LuaTeX تضمين ملفات رسومات PostScript أو Encapsulated PostScript (EPS)؛ قم بتحويلها أولاً إلى PDF باستخدام epstopdf (1).

يتضمن المتغير luajittex مترجم Lua في الوقت المناسب (just-in-time).

يمكن للمتغير luahbtex استخدام محرك HarfBuzz لتشكيل الحروف (glyph shaping)، بدلاً من مشكل الحروف المدمج في LuaTeX.

خيارات

عند بدء تشغيل الملف التنفيذي LuaTeX، يبحث عن خيار سطر الأوامر --lua. إذا لم يكن هناك خيار --lua، فسيتم تفسير سطر الأوامر بطريقة مشابهة لبرامج web2c التقليدية و Aleph. ولكن إذا كان الخيار موجودًا، فسيدخل LuaTeX وضعًا بديلًا لتحليل سطر الأوامر مقارنة ببرامج web2c القياسية. وجود --lua يجعل معظم الخيارات الأخرى غير موثوقة، لأن ملف تهيئة lua يمكنه تعطيل kpathsea و / أو ربط الوظائف بالعديد من ردود الاتصال (callbacks).

--lua=FILE
ملف تهيئة lua.

يغير الخياران التاليان سلوك الملف التنفيذي:

--luaonly
ابدأ LuaTeX كمفسر Lua. في هذا الوضع، سيقوم بتعيين arg[0] الخاص بـ Lua إلى اسم البرنامج النصي الذي تم العثور عليه، ودفع الخيارات السابقة في قيم سالبة والباقي من سطر الأوامر في القيم الموجبة، تمامًا مثل مفسر Lua. سيخرج LuaTeX فورًا بعد تنفيذ البرنامج النصي Lua المحدد.
--luaconly
ابدأ LuaTeX كمترجم لغة Lua الثنائية. في هذا الوضع، LuaTeX مطابق تمامًا لـ luac من توزيعة Lua المستقلة، باستثناء أنه لا يحتوي على مفتاح -l، وأنه يقبل (ولكن يتجاهل) المفتاح --luaconly.

ثم خيارات web2c العادية:

--debug-format

تصحيح تحميل التنسيق.
--draftmode
يضبط \pdfdraftmode حتى لا يكتب luaTeX ملف PDF ولا يقرأ أي صور مضمنة، وبالتالي يسرع التنفيذ.
--enable-write18

مرادف لـ --shell-escape.
--disable-write18

مرادف لـ --no-shell-escape.
--shell-escape

قم بتمكين البناء \write18{command}، ووظائف Lua os.execute()، os.exec()، os.spawn()، و io.popen(). يمكن أن يكون command أي أمر صدفة (shell command). هذا البناء غير مسموح به عادة لأسباب أمنية.
--no-shell-escape

قم بتعطيل البناء \write18{command} ووظائف Lua الأخرى، حتى لو تم تمكينها في ملف texmf.cnf.
--shell-restricted
تمكين نسخة مقيدة من \write18، os.execute()، os.exec()، os.spawn()، و io.popen()، مسموح فقط بالأوامر المدرجة في ملف texmf.cnf.
--file-line-error
اطبع رسائل الخطأ في صيغة file:line:error والتي تشبه الطريقة التي تصيغ بها العديد من المترجمات هذه الرسائل.
--no-file-line-error
تعطيل طباعة رسائل الخطأ بأسلوب file:line:error.
--fmt=FORMAT
استخدم FORMAT كاسم للتنسيق المراد استخدامه، بدلاً من الاسم الذي تم استدعاء luaTeX به أو سطر %&.
--help
اطبع رسالة المساعدة واخرج.
--ini
ابدأ في وضع INI، والذي يستخدم لتفريغ التنسيقات. يمكن استخدام وضع INI للتنسيق، ولكن لا يتم تحميل أي تنسيق مسبقًا، وقد تكون التهيئة الأساسية مثل تعيين رموز الفئات (catcodes) مطلوبة.
--interaction=MODE
يضبط وضع التفاعل. يمكن أن يكون MODE إما batchmode، nonstopmode، scrollmode، و errorstopmode. معنى هذه الأوضاع هو نفس معنى الأوامر \ المقابلة.
--jobname=NAME
استخدم NAME لاسم المهمة (job name)، بدلاً من اشتقاقه من اسم ملف الإدخال.
--kpathsea-debug=BITMASK
يضبط علامات تصحيح البحث عن المسار وفقًا لـ BITMASK. انظر دليل Kpathsea للحصول على التفاصيل.
--mktex=FMT
تمكين توليد mktexFMT، حيث يجب أن يكون FMT إما tex أو tfm.
--nosocket
تعطيل مكتبة luasocket (الشبكة).
--output-comment=STRING
في وضع DVI، استخدم STRING لتعليق ملف DVI بدلاً من التاريخ. يتم تجاهل هذا الخيار في وضع PDF.
--output-directory=DIRECTORY
اكتب ملفات الإخراج في DIRECTORY بدلاً من الدليل الحالي. ابحث عن ملفات الإدخال في DIRECTORY أولاً، ثم على طول مسار البحث العادي.
--output-format=FORMAT
اضبط وضع تنسيق الإخراج، حيث يجب أن يكون FORMAT إما pdf أو dvi. يؤثر هذا أيضًا على مجموعة تنسيقات الرسوميات التي يفهمها luaTeX.
--progname=NAME
تظاهر بأنك البرنامج NAME (فقط لـ kpathsea).
--recorder
قم بتمكين مسجل أسماء الملفات. سيترك هذا أثرًا للملفات المفتوحة للإدخال والإخراج في ملف بامتداد .fls.
--safer
تعطيل بعض أوامر Lua التي يمكن إساءة استخدامها بسهولة بواسطة مستند ضار.
--syncte

NAME

texlua, texluac - Lua interpreter for TeX

SYNOPSIS

texlua [ OPTIONS ] [ LUA_FILE ] [ LUA_ARGS ]

texluac [ OPTIONS ] [ LUA_FILE ] [ LUA_ARGS ]

DESCRIPTION

LuaTeX is a TeX-variant that integrates the Lua scripting language. It provides an interface to Lua from within TeX macros, allowing for more sophisticated typesetting and document processing. The LuaTeX engine is used by default in many modern TeX distributions.

texlua is the command-line interpreter for LuaTeX. It can be used to execute Lua scripts directly.

texluac is similar to texlua but it behaves more like the standard tex command, meaning it expects to be given a Lua file to process and will run it.

Both commands use the Lua interpreter embedded within the LuaTeX engine. This means that Lua scripts executed via texlua or texluac have access to the full range of Lua capabilities as well as the LuaTeX-specific APIs for interacting with the TeX typesetting engine.

If a Lua file is not specified, the interpreter reads commands interactively from standard input.

OPTIONS

--interaction=MODE
Set interaction mode. MODE can be batchmode, nonstopmode, scrollmode, errorstopmode, or batchmode (the default when a script is run).
--jobname=NAME
Set the job name to NAME.
-output-directory=DIR
Set the output directory to DIR.
-fmt=FMT
Use format file FMT.
-ini
Run in INI mode.
-etex
Enable e-TeX extensions.
--parse-first-line
Parse the first line of the input file for TeX commands.
--no-parse-first-line
Do not parse the first line of the input file for TeX commands.
--synctex=NUMBER
Enable/disable SyncTeX extension.
--version
Print version information and exit.
--credits
Print credits and version details.
The following options are ignored:
--8bit, --etex, --parse-first-line, --no-parse-first-line
These are always on.
--default-translate-file=TCXNAME, --translate-file=TCXNAME
These are always off.

AUTHORS

The primary authors of LuaTeX are Taco Hoekwater, Hartmut Henkel, Hans Hagen, and Luigi Scarso, with help from Martin Schröder, Karel Skoupy, and Han The Thanh.

TeX was designed by Donald E. Knuth, who implemented it using his Web system for Pascal programs. It was ported to Unix at Stanford by Howard Trickey, and at Cornell by Pavel Curtis. The version now offered with the Unix TeX distribution is that generated by the Web to C system (web2c), originally written by Tomas Rokicki and Tim Morgan.
