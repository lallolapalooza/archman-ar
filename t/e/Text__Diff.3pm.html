Text__Diff(3pm)

الحزمة: perl-text-diff

التراخيص: GPL, PerlArtistic

Text::Diff(3) وثائق مساهمي Perl Text::Diff(3)

الاسم

Text::Diff - القيام بالاختلافات بين الملفات ومجموعات البيانات

الملخص

use Text::Diff;
## خلط أسماء الملفات، السلاسل النصية، مقابض الإدخال، استدعاءات المولد،
## أو مصفوفات السجلات؛ إرجاع الاختلاف كسلسلة نصية.
## ملاحظة: قد تُرجع اختلافات كبيرة للملفات الكبيرة.
my $diff = diff "file1.txt", "file2.txt", { STYLE => "Context" };
my $diff = diff \$string1,   \$string2,   \%options;
my $diff = diff \*FH1,       \*FH2;
my $diff = diff \&reader1,   \&reader2;
my $diff = diff \@records1,  \@records2;
## يمكن أيضًا خلط أنواع الإدخال:
my $diff = diff \@records1,  "file_B.txt";

الوصف

diff() يوفر مجموعة أساسية من الخدمات المشابهة لخدمات الأداة المساعدة "diff" من GNU. إنها ليست شاملة مثل "diff" من GNU، ولكنها مدمجة بشكل أفضل مع Perl ومتوفرة على جميع الأنظمة. إنها عمومًا أسرع من تشغيل أداة النظام "diff" للملفات الصغيرة، وأبطأ للملفات الكبيرة.

تعتمد على Algorithm::Diff من أجل، حسنًا، الخوارزمية. هذا لا ينتج نفس الاختلاف بالضبط مثل الأداة التنفيذية المحلية للنظام "diff"، ولكنه سيكون اختلافًا صالحًا ومفهومًا بواسطة "patch". لم نر اختلافات بين منطق Algorithm::Diff ومنطق "diff" من GNU، ولكننا لم نفحص للتأكد من أنها متطابقة.

ملاحظة: إذا كنت لا تريد استيراد الدالة "diff"، فقم بأحد الإجراءات التالية:

use Text::Diff ();
require Text::Diff;

نادرًا جدًا، يتم تصدير diff() افتراضيًا.

إذا مررت اسم ملف ولكن لا يمكن قراءة الملف، فسوف تقوم diff() بـ "croak" (إنهاء البرنامج برسالة خطأ).

خيارات

diff() تأخذ معلمتين يتم اشتقاق بيانات الإدخال منهما ومجموعة من الخيارات للتحكم في الإخراج. الخيارات هي:

FILENAME_A, MTIME_A, FILENAME_B, MTIME_B
اسم الملف ووقت التعديل للملفات. يتم ملء هذه تلقائيًا عندما تتلقى diff() اسم ملف، ما لم يتم تمرير قيمة محددة له.
OFFSET_A, OFFSET_B
فهرس السطر/العنصر الأول. القيمة الافتراضية هي 1 لجميع أنواع المعلمات باستثناء مصفوفات المراجع، حيث تكون القيمة الافتراضية 0. وذلك لأن مصفوفات المراجع يُفترض أن تكون هياكل بيانات، بينما النصوص الأخرى خطية.
STYLE
"Unified"، "Context"، "OldStyle"، أو فئة أو مرجع كائن يوفر طرقًا مثل file_header()، hunk_header()، hunk()، hunk_footer() و file_footer(). يتم توفير طريقتي footer() للكتابة فوقهما فقط؛ لا يوفر أي تنسيق لهما.
CONTEXT
عدد الأسطر قبل وبعد كل اختلاف لعرضه. يتم تجاهله في التنسيقات القديمة. القيمة الافتراضية هي 3.
OUTPUT
أمثلة وما يعادلها من استدعاءات: 
OUTPUT   => \*FOOHANDLE,   # مثل: sub { print FOOHANDLE shift() }
OUTPUT   => \$output,      # مثل: sub { $output .= shift }
OUTPUT   => \@output,      # مثل: sub { push @output, shift }
OUTPUT   => sub { $output .= shift },

إذا لم يتم تحديد "OUTPUT"، فسيتم إرجاع الاختلافات كسلسلة نصية. إذا كان "OUTPUT" مرجعًا لـ "CODE"، فسيتم استدعاؤه مرة واحدة مع (اختياري) رأس الملف، ومرة أخرى لكل كتلة hunk مع النص المراد إخراجه. إذا كان "OUTPUT" مقبض إدخال IO، فسيتم إخراج النتيجة إلى هذا المقبض.

FILENAME_PREFIX_A, FILENAME_PREFIX_B
السلسلة النصية التي ستتم طباعتها قبل اسم الملف في الرأس. لا يتم استخدامها في التنسيقات القديمة. القيم الافتراضية هي "---" و "+++" للتنسيق الموحد، و "***" و "+++" لتنسيق السياق.
KEYGEN, KEYGEN_ARGS
هذه يتم تمريرها إلى traverse_sequences في Algorithm::Diff.

ملاحظة: إذا لم يتم تحديد أي من خيارات "FILENAME_"، فلن تتم طباعة الرأس. إذا تم تقديم واحد على الأقل، فيجب تحديد الخيارات الأخرى وكلا خياري "MTIME_"، وإلا فستظهر تحذيرات "Use of undefined variable" (ما لم تكن في تنسيقات "OldStyle"، والتي تتجاهل هذه الخيارات).

فئات التنسيق

تقوم هذه الدوال بتنفيذ تنسيقات الإخراج. يتم تجميعها في فئات بحيث يمكن لـ diff() استخدام أسماء الفئات لاستدعاء روتينات الإخراج الصحيحة، ولكي تتمكن من الوراثة منها بسهولة. لا توجد مُنشئات أو طرق تهيئة لهذه الفئات، على الرغم من أن الفئات الفرعية يمكن أن توفرها إذا لزم الأمر.

كل فئة لديها طرق file_header()، hunk_header()، hunk()، و footer() مطابقة لتلك المذكورة في فصل "Text::Diff::Unified". يتم استدعاء header() قبل hunk() للاستدعاء الأول، و footer() بعد ذلك. طريقة footer() الافتراضية هي دالة فارغة مقدمة للكتابة فوقها:

sub footer { return "End of patch\n" }

يتم توفير بعض تنسيقات الإخراج بواسطة وحدات خارجية (يتم تحميلها تلقائيًا)، مثل Text::Diff::Table. يتم توثيق هذه هنا للحفاظ على بساطة التوثيق.
