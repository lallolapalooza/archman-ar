Test2::Compare::Custom(3perl) دليل مبرمجي بيرل Test2::Compare::Custom(3perl)

الاسم

Test2::Compare::Custom - فحص حقل مخصص للمقارنات.

الوصف

في بعض الأحيان تريد القيام بشيء معقد أو غير عادي عند التحقق من صحة حقل متداخل داخل بنية بيانات عميقة. يمكنك سحبه من البنية واختباره بشكل منفصل، أو يمكنك استخدام هذا لتضمين الفحص. يوفر هذا طريقة لك لكتابة فحوصات مخصصة للحقول في المقارنات العميقة.

الملخص

my $cus = Test2::Compare::Custom->new(
    name => 'IsRef',
    operator => 'ref(...)',
    stringify_got => 1,
    code => sub {
        my %args = @_;
        return $args{got} ? 1 : 0;
    },
);
# يمر
is(
    { a => 1, ref => {},   b => 2 },
    { a => 1, ref => $cus, b => 2 },
    "هذا سيمر"
);
# يفشل
is(
    {a => 1, ref => 'notref', b => 2},
    {a => 1, ref => $cus,     b => 2},
    "هذا سيفشل"
);

الوسائط

سيتم تمرير الدالة الفرعية المخصصة الخاصة بك مع 4 وسائط في علامة تصنيف:

code => sub {
    my %args = @_;
    # يوفر got, exists, operator, name
    return ref($args{got}) ? 1 : 0;
},

يتم تحديد $_ أيضًا محليًا لـ "got" لتسهيل الأمر على أولئك الذين يحتاجون إلى استخدام التعبيرات النمطية.

got
$_
القيمة التي سيتم فحصها.
exists
ستكون هذه قيمة منطقية. ستكون صحيحة إذا كان "got" موجودًا على الإطلاق. إذا كان "exists" خاطئًا، فهذا يعني أن "got" ليس مجرد قيمة غير محددة (undef)، ولكنه غير موجود على الإطلاق (فكر في التحقق من قيمة مفتاح علامة تصنيف غير موجود).
operator
المعامل المحدد عند الإنشاء.
name
الاسم المقدم عند الإنشاء.

الطرق

$code = $cus->code
يعيد الدالة الفرعية المقدمة عند الإنشاء.
$name = $cus->name
يعيد الاسم المقدم عند الإنشاء.
$op = $cus->operator
يعيد المعامل المقدم عند الإنشاء.
$stringify = $cus->stringify_got
يعيد علامة stringify_got المقدمة عند الإنشاء.
$bool = $cus->verify(got => $got, exists => $bool)

المصدر

يمكن العثور على مستودع الكود المصدري لـ Test2-Suite على https://github.com/Test-More/test-more/.
