TEXTESTVIS(1) TEXTESTVIS(1)

الاسم

textestvis - اختبارات الانحدار البصري لـ LaTeX

الملخص

textestvis [-cs] [-e ENGINE] [-d DENSITY] [PATTERN]

textestvis approve [-e ENGINE] [PATTERN]

textestvis compare [-d DENSITY] FILE FILE

textestvis perf [-cs] [-e ENGINE] FILE

الوصف

إجراء اختبارات الانحدار البصري لوثائق LaTeX.

textestvis
يقوم بإنشاء ملفات PDF لجميع ملفات tex التي تطابق النمط وإجراء اختبار انحدار بصري. إذا لم يتم تحديد نمط، يتم اختبار جميع الملفات في الدليل الحالي باستثناء الملفات التي تبدأ أسماؤها بشرطة سفلية.
textestvis approve
يستبدل الملفات المرجعية بالملفات الاختبارية.
textestvis compare
ينشئ فرقًا بصريًا لملفي PDF.
textestvis perf
يقيس الوقت اللازم لإنشاء ملف PDF من ملف tex المحدد.

الخيارات

-c
يمسح ذاكرة التخزين المؤقت.
-s
يمكّن هروب shell.
-d DENSITY
يحدد الكثافة بوحدة ppi (الافتراضي 72).
-e ENGINE
يحدد محرك latex (الافتراضي xelatex).
--help
يطبع رسالة مساعدة.
--version
يطبع معلومات الإصدار.

البيئة

textestvis يتطلب ImageMagick 7.0 أو أحدث.
