Template__Plugin__GD__Image(3pm)

الحزمة: perl-template-gd

التراخيص: GPL, PerlArtistic

Template::Plugin::GD::Image(3) وثائق Perl المساهمة من المستخدم Template::Plugin::GD::Image(3)

الاسم

Template::Plugin::GD::Image - واجهة لمكتبة GD الرسومية

الملخص

[% USE im = GD.Image(width, height) %]

أمثلة

[% FILTER null;
    USE gdc = GD.Constants;
    USE im  = GD.Image(200,100);
    black = im.colorAllocate(0  ,0,  0);
    red   = im.colorAllocate(255,0,  0);
    r = im.string(gdc.gdLargeFont, 10, 10, "نص أحمر كبير", red);
    im.png | stdout(1);
   END;
-%]
[% FILTER null;
    USE im = GD.Image(100,100);
    # تخصيص بعض الألوان
    black = im.colorAllocate(0,   0, 0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,  255);
    # رسم شكل بيضاوي أزرق
    im.arc(50,50,95,75,0,360,blue);
    # وملءه باللون الأحمر
    im.fill(50,50,red);
    # إخراج الصورة الثنائية بصيغة PNG
    im.png | stdout(1);
   END;
-%]
[% FILTER null;
    USE im   = GD.Image(100,100);
    USE c    = GD.Constants;
    USE poly = GD.Polygon;
    # تخصيص بعض الألوان
    white = im.colorAllocate(255,255,255);
    black = im.colorAllocate(0,  0,  0);
    red   = im.colorAllocate(255,0,  0);
    blue  = im.colorAllocate(0,  0,255);
    green = im.colorAllocate(0,  255,0);
    # جعل الخلفية شفافة ومتداخلة
    im.transparent(white);
    im.interlaced('true');
    # وضع إطار أسود حول الصورة
    im.rectangle(0,0,99,99,black);
    # رسم شكل بيضاوي أزرق
    im.arc(50,50,95,75,0,360,blue);
    # وملءه باللون الأحمر
    im.fill(50,50,red);
    # رسم مثلث أزرق
    poly.addPt(50,0);
    poly.addPt(99,99);
    poly.addPt(0,99);
    im.filledPolygon(poly, blue);
    # إخراج الصورة الثنائية بصيغة PNG
    im.png | stdout(1);
   END;
-%]

الوصف

يوفر المكون الإضافي GD.Image واجهة لفئة GD::Image الخاصة بـ GD.pm. فئة GD::Image هي الواجهة الرئيسية لـ GD.pm.

من المهم جدًا عدم وجود أي مخرجات قوالب إضافية قبل أو بعد الصورة. نظرًا لأن بعض الوظائف تُرجع قيمًا قد تظهر في المخرجات، يُوصى بلف كود GD.Image في مرشح فارغ. يمكن للوظائف التي تنتج المخرجات النهائية (على سبيل المثال، png، jpeg، gd، إلخ) بعد ذلك إخراجها صراحةً باستخدام مرشح stdout، مع وسيطة غير صفرية لفرض الوضع الثنائي (مطلوب لأنظمة التشغيل غير الحديثة).

راجع GD لوصف كامل لمكتبة GD وجميع الوظائف التي يمكن استدعاؤها عبر المكون الإضافي GD.Image. راجع Template::Plugin::GD::Constants للحصول على مكون إضافي يسمح لك بالوصول إلى ثوابت GD.pm.
