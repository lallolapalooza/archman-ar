Template__Plugin__GD__Graph__area(3pm)

الحزمة: perl-template-gd

التراخيص: GPL, PerlArtistic

Template::Plugin::GD::Graph::area(3) وثائق Perl المقدمة من المستخدم Template::Plugin::GD::Graph::area(3)

الاسم

Template::Plugin::GD::Graph::area - إنشاء رسوم بيانية للمساحة مع محاور وتسميات

الملخص

[% USE g = GD.Graph.area(x_size, y_size); %]

أمثلة

[% FILTER null;
    data = [
        ["الأول","الثاني","الثالث","الرابع","الخامس","السادس","السابع", "الثامن", "التاسع"],
        [    5,   12,   24,   33,   19,    8,    6,    15,    21],
        [   -1,   -2,   -5,   -6,   -3,  1.5,    1,   1.3,     2]
    ];  

    USE my_graph = GD.Graph.area();
    my_graph.set(
            two_axes => 1,  
            zero_axis => 1,
            transparent => 0,
    );  
    my_graph.set_legend('المحور الأيسر', 'المحور الأيمن' );
    my_graph.plot(data).png | stdout(1);
   END;
-%]

الوصف

توفر إضافة GD.Graph.area واجهة إلى الفئة GD::Graph::area التي تحددها الوحدة GD::Graph. تسمح برسم مجموعة بيانات واحدة أو أكثر (x,y) كخطوط مع تظليل المساحة بين الخط والمحور السيني، بالإضافة إلى المحاور والتسميات.

راجع GD::Graph لمزيد من التفاصيل.

المؤلف

قام توماس بوتل بكتابة مكتبة الرسومات GD.

قام لينكولن د. ستاين بكتابة وحدات Perl GD التي تتفاعل معها.

قام مارتين فيربورغن بكتابة الوحدة GD::Graph.

قام كريج بارات <craig@arraycomm.com> بكتابة إضافات GD الأصلية لـ Template Toolkit (2001).

قام آندي واردلي <abw@cpan.org> باستخراجها من نواة TT إلى توزيع منفصل لإصدار TT 2.15.
