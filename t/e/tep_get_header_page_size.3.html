tep_get_header_page_size(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_get_header_page_size, tep_get_header_timestamp_size, tep_is_old_format - الحصول على البيانات المخزنة في صفحة الرأس، في سياق النواة.

الملخص

#include <event-parse.h>
int tep_get_header_page_size(struct tep_handle *tep);
int tep_get_header_timestamp_size(struct tep_handle *tep);
bool tep_is_old_format(struct tep_handle *tep);

الوصف

تقوم هذه الدوال باسترداد معلومات من سياق النواة، المخزنة في أحداث tracefs/header_page. الأنوية القديمة لا تحتوي على معلومات صفحة الرأس، لذا يتم استخدام القيم الافتراضية من سياق مساحة المستخدم.

تقوم الدالة tep_get_header_page_size() بإرجاع حجم عدد صحيح طويل، في سياق النواة. الوسيط tep هو سياق محلل أحداث التتبع. يتم استرداد هذه المعلومات من حقل "commit" في tracefs events/header_page.

تقوم الدالة tep_get_header_timestamp_size() بإرجاع حجم الطوابع الزمنية، في سياق النواة. الوسيط tep هو سياق محلل أحداث التتبع. يتم استرداد هذه المعلومات من حقل "timestamp" في tracefs events/header_page.

تقوم الدالة tep_is_old_format() بإرجاع true إذا كانت النواة تسبق إضافة events/header_page، وإلا فإنها ترجع false.

قيمة الإرجاع

ترجع الدالة tep_get_header_page_size() حجم عدد صحيح طويل، بالبايت.

ترجع الدالة tep_get_header_timestamp_size() حجم الطوابع الزمنية، بالبايت.

ترجع الدالة tep_is_old_format() true، إذا تم استخدام نواة قديمة لتوليد بيانات التتبع، والتي لا تحتوي على event/header_page. إذا كانت النواة جديدة، أو كان tep هو NULL، يتم إرجاع false.

مثال

#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        int longsize;
        int timesize;
        bool old;
        longsize = tep_get_header_page_size(tep);
        timesize = tep_get_header_timestamp_size(tep);
        old = tep_is_old_format(tep);
        printf ("%s kernel is used to generate the tracing data.\n",
                old?"Old":"New");
        printf("The size of a long integer is %d bytes.\n", longsize);
        printf("The timestamps size is %d bytes.\n", timesize);
...
