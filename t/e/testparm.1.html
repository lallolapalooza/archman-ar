testparm(1)

الحزمة: samba

التراخيص: GPL-3.0-or-later

TESTPARM(1) أوامر المستخدم TESTPARM(1)

الاسم

testparm - التحقق من صحة ملف تكوين smb.conf داخليًا

الملخص

testparm [-s|--suppress-prompt] [-v|--verbose] [-?|--help] [--usage] [-d|--debuglevel=DEBUGLEVEL] [--debug-stdout] {ملف_التكوين} [اسم_المضيف عنوان_IP_للمضيف]

الوصف

هذه الأداة جزء من مجموعة samba(7).

testparm هو برنامج اختبار بسيط جدًا للتحقق من صحة ملف تكوين smbd(8) داخليًا. إذا أبلغ هذا البرنامج عن عدم وجود مشاكل، يمكنك استخدام ملف التكوين بثقة بأن smbd سيقوم بتحميل ملف التكوين بنجاح.

لاحظ أن هذا *ليس* ضمانًا بأن الخدمات المحددة في ملف التكوين ستكون متاحة أو ستعمل كما هو متوقع.

إذا تم تحديد اسم المضيف وعنوان IP للمضيف اختياريًا في سطر الأوامر، فسيقوم برنامج الاختبار هذا بالمرور عبر إدخالات الخدمة للإبلاغ عما إذا كان المضيف المحدد لديه وصول إلى كل خدمة.

إذا وجد testparm خطأ في ملف smb.conf، فإنه يعيد رمز خروج 1 إلى البرنامج المستدعي، وإلا فإنه يعيد رمز خروج 0. هذا يسمح لسكريبتات shell باختبار المخرجات من testparm.

الخيارات

-s|--suppress-prompt

بدون هذا الخيار، سيطلب testparm الضغط على Enter بعد طباعة أسماء الخدمات وقبل تفريغ تعريفات الخدمات.

-v|--verbose

إذا تم تحديد هذا الخيار، فسيعرض testparm أيضًا جميع الخيارات التي لم يتم استخدامها في smb.conf(5) وبالتالي تم تعيينها إلى قيمها الافتراضية.

--parameter-name parametername

يقوم بتفريغ المعلمة المسماة. إذا لم يتم تعيين اسم قسم، فإن العرض يقتصر افتراضيًا على القسم العام. من الممكن أيضًا تفريغ خيار معلمة. لهذا الغرض، يجب فصل الخيار عن اسم المعلمة بنقطتين رأسيتين.

--section-name sectionname

يقوم بتفريغ القسم المسمى.

--show-all-parameters

عرض المعلمات، النوع، القيم الممكنة.

-l|--skip-logic-checks

تخطي فحوصات المنطق العامة.

-?|--help

طباعة ملخص لخيارات سطر الأوامر.

--usage

عرض رسالة استخدام موجزة.

-d|--debuglevel=level

المستوى هو عدد صحيح من 0 إلى 10. القيمة الافتراضية إذا لم يتم تحديد هذه المعلمة هي 1 لتطبيقات العميل.

كلما زادت هذه القيمة، زادت التفاصيل التي سيتم تسجيلها في ملفات السجل حول أنشطة الخادم. عند المستوى 0، سيتم تسجيل الأخطاء الحرجة والتحذيرات الخطيرة فقط. المستوى 1 هو مستوى معقول للتشغيل اليومي - يولد كمية صغيرة من المعلومات حول العمليات التي تم تنفيذها.

المستويات الأعلى من 1 ستولد كميات كبيرة من بيانات السجل، ويجب استخدامها فقط عند التحقيق في مشكلة. المستويات الأعلى من 3 مصممة للاستخدام فقط من قبل المطورين وتولد كميات ضخمة من بيانات السجل، معظمها مشفر بشكل كبير.

لاحظ أن تحديد هذه المعلمة هنا سيتجاوز معلمة مستوى السجل في ملف /etc/samba/smb.conf.

--debug-stdout

سيؤدي ذلك إلى إعادة توجيه إخراج التصحيح إلى STDOUT. افتراضيًا، تسجل جميع العملاء في STDERR.

--configfile=<ملف التكوين>

يحتوي الملف المحدد على تفاصيل التكوين المطلوبة من قبل العميل. يمكن أن تكون المعلومات الموجودة في هذا الملف عامة للعميل والخادم أو توفر فقط خيارات محددة للعميل مثل client smb encrypt. انظر /etc/samba/smb.conf لمزيد من المعلومات. يتم تحديد اسم ملف التكوين الافتراضي في وقت الترجمة.

--option=<الاسم>=<القيمة>

قم بتعيين خيار smb.conf(5) "<الاسم>" إلى القيمة "<القيمة>" من سطر الأوامر. هذا يتجاوز القيم الافتراضية المدمجة والخيارات المقروءة من ملف التكوين. إذا كان الاسم أو القيمة يتضمنان مسافة، فقم بتضمين --option=name=value بأكملها داخل علامات اقتباس.

-V|--version

طباعة رقم إصدار البرنامج.

configfilename

هذا هو اسم ملف التكوين الذي سيتم فحصه. إذا لم تكن هذه المعلمة موجودة، فسيتم فحص ملف smb.conf(5) الافتراضي.

hostname

إذا تم تحديد هذه المعلمة وما يليها، فسيقوم testparm بفحص المعلمتين hosts allow و hosts deny في ملف smb.conf(5) لتحديد ما إذا كان اسم المضيف بهذا العنوان IP سيُسمح له بالوصول إلى خادم smbd. إذا تم توفير هذه المعلمة، فيجب أيضًا توفير المعلمة hostIP.

hostIP

هذا هو عنوان IP للمضيف المحدد في المعلمة السابقة. يجب توفير هذا العنوان إذا تم توفير المعلمة hostname.

الملفات

smb.conf(5)

هذا هو عادةً اسم ملف التكوين المستخدم بواسطة smbd(8).

التشخيصات

سيصدر البرنامج رسالة توضح ما إذا كان ملف التكوين قد تم تحميله بنجاح أم لا. قد تسبق هذه الرسالة أخطاء وتحذيرات إذا لم يتم تحميل الملف. إذا تم تحميل الملف بنجاح، فسيقوم البرنامج بعد ذلك بتفريغ جميع تفاصيل الخدمة المعروفة إلى المخرجات القياسية.

لبعض حالات الاستخدام، يتطلب بروتوكول SMB استخدام خوارزميات تشفير معروفة بأنها ضعيفة وتم كسرها بالفعل. تعتبر خوارزميات DES و ARCFOUR (RC4) للخوارزميات، وخوارزميات التجزئة SHA1 و MD5 ضعيفة ولكنها مطلوبة للتوافق مع الإصدارات السابقة. تعرض الأداة testparm ما إذا كانت أدوات Samba ستعود إلى خوارزميات التشفير الضعيفة هذه إذا لم يكن من الممكن استخدام التشفير القوي افتراضيًا. في وضع FIPS، لا يمكن تمكين التشفير الضعيف.

testparm(1)

NAME

testparm - check Samba configuration files

SYNOPSIS

testparm [-v] [-s] [-H] [-l] [-d] [-i] [-P] [-p] [-N] [-Y] [-Z] [-F] [-l loglevel] [-m smb version] [-e] [configuration file]

DESCRIPTION

testparm is a utility that checks the syntax of your Samba configuration file (usually smb.conf) and reports any errors. It can also be used to display the loaded configuration.

OPTIONS

-v
Verbose output.
-s
Show the loaded configuration in standard format.
-H
Show the loaded configuration in HIPAA format.
-l
Show the loaded configuration in long format.
-d
Debug mode.
-i
Ignore case in configuration file.
-P
Print the loaded parameters.
-p
Print the loaded parameters in a compact format.
-N
Don't ask any interactive questions.
-Y
Don't ask about the default share.
-Z
Don't ask about the printer share.
-F
Output configuration as a server would.
-l loglevel
Set the log level.
-m smb version
Set the Samba version.
-e
Display the loaded global parameters.

EXAMPLES

Check the syntax of smb.conf and report errors: 

    testparm

Check the syntax of a specific configuration file: 

    testparm /path/to/smb.conf

Show the loaded configuration in standard format: 

    testparm -s

Show the loaded configuration in long format: 

    testparm -l

Print the loaded parameters: 

    testparm -P
