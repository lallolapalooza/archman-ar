tep_set_page_size(3)

الحزمة: libtraceevent

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEEVENT(3) دليل libtraceevent LIBTRACEEVENT(3)

الاسم

tep_get_page_size, tep_set_page_size, tep_get_sub_buffer_data_size, tep_get_sub_buffer_size - الحصول / تعيين حجم صفحة الذاكرة في الجهاز الذي يتم إنشاء التتبع عليه

الملخص

#include <event-parse.h>
int tep_get_page_size(struct tep_handle *tep);
void tep_set_page_size(struct tep_handle *tep, int page_size);
int tep_get_sub_buffer_size(struct tep_handle *tep);
int tep_get_sub_buffer_data_size(struct tep_handle *tep);
int tep_get_sub_buffer_commit_offset(struct tep_handle *tep);

الوصف

تقوم الدالة tep_get_page_size() بإرجاع حجم صفحة الذاكرة في الجهاز الذي يتم إنشاء التتبع عليه. الوسيط tep هو سياق محلل أحداث التتبع.

تقوم الدالة tep_set_page_size() بتخزين حجم صفحة الذاكرة في الجهاز الذي يتم إنشاء التتبع عليه في سياق tep. الوسيط tep هو سياق محلل أحداث التتبع. الوسيط page_size هو حجم صفحة الذاكرة بالبايت.

تقوم الدالة tep_get_sub_buffer_size() بإرجاع حجم كل "مخزن مؤقت فرعي" للمخزن المؤقت الدائري. يتم تقسيم المخزن المؤقت الدائري لنواة Linux إلى أقسام تسمى المخازن المؤقتة الفرعية. هذه الدالة ترجع حجم تلك المخازن المؤقتة.

تقوم الدالة tep_get_sub_buffer_data_size() بإرجاع حجم جزء البيانات فقط من المخازن المؤقتة الفرعية.

تقوم الدالة tep_get_sub_buffer_commit_offset() بإرجاع الإزاحة في المخزن المؤقت الفرعي التي تحمل الجزء الملتزم به من البيانات. يحتوي هذا الرقم على الفهرس من جزء البيانات في المخزن المؤقت الفرعي والذي يمثل نهاية آخر عنصر في المخزن المؤقت الفرعي.

قيمة الإرجاع

تقوم الدالة tep_get_page_size() بإرجاع حجم صفحة الذاكرة بالبايت.

تقوم الدالة tep_get_sub_buffer_size() بإرجاع عدد البايتات التي تتكون منها كل مخزن مؤقت فرعي.

تقوم الدالة tep_get_sub_buffer_commit_offset() بإرجاع الموقع في المخزن المؤقت الفرعي الذي يحتوي على فهرس آخر عنصر.

مثال

#include <unistd.h>
#include <event-parse.h>
...
struct tep_handle *tep = tep_alloc();
...
        int page_size = getpagesize();
        tep_set_page_size(tep, page_size);
        printf("The page size for this machine is %d\n", tep_get_page_size(tep));
