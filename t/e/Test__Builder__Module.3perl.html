Test::Builder::Module(3perl) دليل مبرمجي Perl Test::Builder::Module(3perl)

الاسم

Test::Builder::Module - فئة أساسية لوحدات الاختبار

الملخص

# يحاكي Test::Simple
package Your::Module;
my $CLASS = __PACKAGE__;
use parent 'Test::Builder::Module';
@EXPORT = qw(ok);
sub ok ($;$) {
    my $tb = $CLASS->builder;
    return $tb->ok(@_);
}

1;

الوصف

هذه فئة فائقة لوحدات Test::Builder. توفر عددًا قليلًا من الوظائف المشتركة وطريقة للوصول إلى كائن Test::Builder الأساسي.

الاستيراد

Test::Builder::Module هي فئة فرعية من Exporter مما يعني أن وحدتك هي أيضًا فئة فرعية من Exporter. @EXPORT، @EXPORT_OK، إلخ... تعمل بشكل طبيعي.

تم توفير عدد قليل من الطرق للقيام بجزء "use Your::Module tests => 23" لك.

import

توفر Test::Builder::Module طريقة import() تعمل بنفس الطريقة الأساسية لـ Test::More، وتعيين الخطة والتحكم في تصدير الدوال والمتغيرات. هذا يسمح لوحدتك بتعيين الخطة بشكل مستقل عن Test::More.

سيتم تمرير جميع الوسائط المقدمة إلى import() إلى "Your::Module->builder->plan()" باستثناء "import =>[qw(things to import)]".

use Your::Module import => [qw(this that)], tests => 23;

يقول لاستيراد الدوال this() و that() وكذلك تعيين الخطة لتكون 23 اختبارًا.

import() يعين أيضًا السمة exported_to() لباني الخاص بك لتكون المتصل بدالة import().

يمكن إضافة سلوكيات إضافية إلى طريقة import() الخاصة بك عن طريق تجاوز import_extra().

import_extra

Your::Module->import_extra(\@import_args);

import_extra() يتم استدعاؤها بواسطة import(). توفر فرصة لإضافة سلوكيات إلى وحدتك بناءً على قائمة الاستيراد الخاصة بها.

يجب إزالة أي وسائط إضافية لا ينبغي تمريرها إلى plan() بواسطة هذه الطريقة.

راجع Test::More للحصول على مثال على استخدامه.

ملاحظة هذه الآلية هي ألفا جدًا ومن المحتمل أن تتغير لأنها تبدو وكأنها اختراق قبيح في شكلها الحالي.

الباني

توفر Test::Builder::Module بعض الطرق للوصول إلى كائن Test::Builder الأساسي.

builder

my $builder = Your::Class->builder;

تعيد هذه الطريقة كائن Test::Builder المرتبط بـ Your::Class. إنها ليست مُنشئًا لذلك يمكنك استدعاؤها كلما شئت.

هذه هي الطريقة المفضلة للحصول على كائن Test::Builder. يجب عليك عدم الحصول عليه عبر "Test::Builder->new" كما كان موصى به سابقًا.

قد يتغير الكائن الذي تعيده builder() في وقت التشغيل لذلك يجب عليك استدعاء builder() داخل كل دالة بدلاً من تخزينه في متغير عام.

sub ok {
    my $builder = Your::Class->builder;
    return $builder->ok(@_);
}
