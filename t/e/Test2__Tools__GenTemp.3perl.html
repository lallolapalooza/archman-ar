Test2::Tools::GenTemp(3perl) دليل مبرمجي بيرل Test2::Tools::GenTemp(3perl)

الاسم

Test2::Tools::GenTemp - أداة لإنشاء مجلد مؤقت مملوء.

الوصف

يقوم هذا بتصدير أداة تساعدك على إنشاء مجلد مؤقت، مجلدات متداخلة وملفات نصية بداخله.

ملخص

use Test2::Tools::GenTemp qw/gen_temp/;
my $dir = gen_temp(
    a_file => "محتويات a_file",
    a_dir  => {
        'a_file' => 'محتويات a_dir/afile',
        a_nested_dir => { ... },
    },
    ...
);
done_testing;

التصديرات

جميع الوظائف الفرعية يتم تصديرها افتراضياً.

gen_temp(file => 'content', subdir => [ sub_dir_file => 'content', ...], ...)
gen_temp(-tempdir => \@TEMPDIR_ARGS, file => 'content', subdir => [ sub_dir_file => 'content', ...], ...)
سيقوم هذا بإنشاء مجلد مؤقت جديد بكل الملفات والمجلدات الفرعية التي تحددها، بشكل متكرر. يتم إنشاء المجلد المؤقت الأولي باستخدام File::Temp::tempdir()، يمكنك تمرير وسيطات إلى tempdir باستخدام الوسيطة "-tempdir => [...]".

المصدر

يمكن العثور على مستودع الشيفرة المصدرية لمجموعة Test2 في https://github.com/Test-More/test-more/.
