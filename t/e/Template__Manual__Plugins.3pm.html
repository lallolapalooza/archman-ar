Template__Manual__Plugins(3pm)

Template::Manual::Plugins(3) وثائق Perl مقدمة من المستخدمين Template::Manual::Plugins(3)

الاسم

Template::Manual::Plugins - الإضافات القياسية

إضافات Template Toolkit

الوحدات الإضافية التالية موزعة مع Template Toolkit. تتصل بعض الإضافات بوحدات خارجية (مفصلة أدناه) يجب تنزيلها من أي مستودع CPAN وتثبيتها قبل استخدام الإضافة.

Assert

متوفرة مرة أخرى في 2.20! تضيف الإضافة Assert طريقة افتراضية "assert" يمكنك استخدامها لالتقاط القيم غير المعرفة.

على سبيل المثال، ضع في اعتبارك هذا النمط:

[% user.name %]

إذا كانت "user.name" قيمة غير معرفة، سيتجاهلها TT بصمت ولن يعرض شيئًا. إذا استخدمت الإضافة "assert"، يمكنك إدراج الطريقة "assert" بين عناصر "user" و "name"، هكذا:

[% user.assert.name %]

الآن، إذا كانت "user.name" قيمة غير معرفة، سيتم إطلاق استثناء:

خطأ تأكيد - قيمة غير معرفة لـ name

CGI

الإضافة CGI هي غلاف لمكتبة CGI.pm الخاصة بـ Lincoln Stein. يتم توزيع الإضافة مع Template Toolkit (انظر Template::Plugin::CGI) والوحدة CGI نفسها يتم توزيعها مع الإصدارات الحديثة من Perl أو متاحة على CPAN.

[% USE CGI %]
[% CGI.param('param_name') %]
[% CGI.start_form %]
[% CGI.popup_menu( Name   => 'color',
                   Values => [ 'Green', 'Brown' ] ) %]
[% CGI.end_form %]

Datafile

توفر واجهة لقراءة البيانات المخزنة في ملف نصي بصيغة بسيطة ومفصولة بفواصل. السطر الأول من الملف يحدد أسماء الحقول التي يجب فصلها بأي سلسلة من الأحرف غير الأبجدية الرقمية. الأسطر التالية تحدد البيانات باستخدام نفس الفاصل كما في السطر الأول. يتم تجاهل الأسطر الفارغة والتعليقات (الأسطر التي تبدأ بـ #). انظر Template::Plugin::Datafile لمزيد من التفاصيل.

/tmp/mydata:

# تحديد أسماء لكل حقل
id : email : name : tel
# هنا البيانات
fred : fred@here.com : Fred Smith : 555-1234
bill : bill@here.com : Bill White : 555-5678

مثال:

[% USE userlist = datafile('/tmp/mydata') %]
[% FOREACH user = userlist %]
   [% user.name %] ([% user.id %])
[% END %]

Date

توفر الإضافة Date طريقة سهلة لتوليد سلاسل تاريخ ووقت منسقة عن طريق التفويض إلى روتين POSIX strftime(). انظر Template::Plugin::Date و POSIX لمزيد من التفاصيل.

[% USE date %]
[% date.format %]           # الوقت/التاريخ الحالي
آخر تعديل: [% date.format(template.modtime) %]

Directory

توفر الإضافة Directory واجهة بسيطة للدليل وملفاته. انظر Template::Plugin::Directory لمزيد من التفاصيل.

[% USE dir = Directory('/tmp') %]
[% FOREACH file = dir.files %]
    # كل الملفات العادية في الدليل
[% END %]
[% FOREACH file = dir.dirs %]
    # كل الدلائل الفرعية
[% END %]

DBI

لم تعد الإضافة "DBI" موزعة كجزء من Template Toolkit (بدءًا من الإصدار 2.15). أصبحت متاحة الآن كتوزيع مستقل Template::DBI على CPAN.

Dumper

توفر الإضافة Dumper واجهة للوحدة Data::Dumper. انظر Template::Plugin::Dumper و Data::Dumper لمزيد من التفاصيل.

[% USE dumper(indent=0, pad="<br>") %]
[% dumper.dump(myvar, yourvar) %]

File

توفر الإضافة File تعميمًا للملفات ويمكن استخدامها للحصول على معلومات حول ملفات محددة في نظام الملفات. انظر Template::Plugin::File لمزيد من التفاصيل.

[% USE File('/tmp/foo.html') %]
[% File.name %]     # foo.html
[% File.dir %]      # /tmp
[% File.mtime %]    # وقت التعديل

Filter

تقوم هذه الوحدة بتنفيذ فئة أساسية للإضافة يمكن وراثتها لإنشاء وحدات خاصة بك تحدد وتثبت عوامل تصفية جديدة.

package MyOrg::Template::Plugin::MyFilter;
use Template::Plugin::Filter;
use base qw( Template::Plugin::Filter );
sub filter {
    my ($self, $text) = @_;
    # ... معالجة $text ...
    return $text;
}

مثال على الاستخدام:

# تحميلها الآن...
[% USE MyFilter %]
# ... واستخدام الكائن المُرجع كعامل تصفية
[% FILTER $MyFilter %]
  ...
[% END %]

انظر Template::Plugin::Filter لمزيد من التفاصيل.

Format

توفر الإضافة Format طريقة بسيطة لتنسيق النص بناءً على تنسيق مشابه لدالة printf(). انظر Template::Plugin::Format لمزيد من التفاصيل.

[% USE bold = format('<b>%s</b>') %]
[% bold('Hello') %]

GD

لم تعد الإضافات "GD" جزءًا من التوزيع الرئيسي لـ Template Toolkit. أصبحت متاحة الآن على CPAN كتوزيع مستقل Template::GD.

HTML

الإضافة HTML أساسية جدًا، وتنفذ بعض الطرق المفيدة لتوليد HTML. من المحتمل أن يتم توسيعها في المستقبل أو دمجها مع مشروع أكبر لتوليد عناصر HTML بطريقة عامة.

[% USE HTML %]
[% HTML.escape("if (a < b && c > d) ..." %]
[% HTML.attributes(border => 1, cellpadding => 2) %]
[% HTML.element(table => { border => 1, cellpadding => 2 }) %]

انظر Template::Plugin::HTML لمزيد من التفاصيل.

Iterator

توفر الإضافة Iterator طريقة لإنشاء كائن Template::Iterator للتكرار فوق مجموعة بيانات. يتم إنشاء مكرر تلقائيًا بواسطة التوجيه "FOREACH" ويتم استعراضه بالاسم "loop". تسمح هذه الإضافة بإنشاء مكرر بشكل صريح باسم معين، أو الاسم الافتراضي "iterator". انظر Template::Plugin::Iterator لمزيد من التفاصيل.

[% USE iterator(list, args) %]
[% FOREACH item = iterator %]
   [% '<ul>' IF iterator.first %]
   <li>[% item %]
   [% '</ul>' IF iterator.last %]
[% END %]

Pod

توفر هذه الإضافة واجهة للوحدة Pod::POM التي تقوم بتحليل مستندات POD إلى نموذج كائنات داخلي يمكن بعد ذلك اجتياحه وتقديمه باستخدام Template Toolkit.

[% USE Pod(podfile) %]
[% FOREACH head1 = Pod.head1;
     FOREACH head2 = head1/head2;
       ...
     END;
   END
%]

Scalar

يستدعي Template Toolkit الإجراءات الفرعية المعرفة من قبل المستخدم وطرق الكائنات باستخدام سياق المصفوفة الافتراضي. توفر وحدة الإضافة Scalar طريقة لاستدعاء الإجراءات الفرعية والطرق في سياق القياسي.

# TT2 يستدعي الطرق في سياق المصفوفة الافتراضي
[% object.method %]

توفر هذه الوحدة طريقة لاستدعاء الإجراءات الفرعية والطرق في سياق القياسي.

[% USE scalar %]
# فرض سياق القياسي
[% object.scalar.method %]
# يعمل أيضًا مع مراجع الإجراءات الفرعية
[% scalar.my_sub_ref %]

String

تنفذ الإضافة String واجهة موجهة للكائنات لمعالجة السلاسل النصية. انظر Template::Plugin::String لمزيد من التفاصيل.

[% USE String 'Hello' %]
[% String.append(' World') %]
[% msg = String.new('Another string') %]
[% msg.replace('string', 'text') %]
السلسلة "[% msg %]" تحتوي على "[% msg.length %] " حرف.

Table

تسمح الإضافة Table بتنسيق قائمة بيانات في جدول افتراضي عن طريق تحديد
