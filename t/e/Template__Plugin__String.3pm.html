Template__Plugin__String(3pm)

Template::Plugin::String(3) وثائق Perl المساهمة من المستخدمين Template::Plugin::String(3)

الاسم

Template::Plugin::String - واجهة كائنية التوجه لمعالجة النصوص

الملخص

# إنشاء كائنات String عبر توجيه USE
[% USE String %]
[% USE String 'النص الأولي' %]
[% USE String text => 'النص الأولي' %]
# أو من String موجودة عبر new()
[% newstring = String.new %]
[% newstring = String.new('نص السلسلة الجديدة') %]
[% newstring = String.new( text => 'نص السلسلة الجديدة' ) %]
# أو من String موجودة عبر copy()
[% newstring = String.copy %]
# إلحاق نص بالسلسلة
[% String.append('النص المراد إلحاقه') %]
# تنسيق بمحاذاة يسار أو يمين أو توسيط مع الحشو
[% String.left(20) %]
[% String.right(20) %]
[% String.center(20) %]   # التهجئة الأمريكية
[% String.centre(20) %]   # التهجئة الأوروبية
# وطرق أخرى متنوعة...

الوصف

تنفّذ هذه الوحدة صنف "String" للقيام بعمليات نصية على النص بطريقة كائنية التوجه.

يمكنك إنشاء كائن "String" عبر توجيه "USE"، مع إضافة أي قيمة نصية أولية كوسيط أو كمعامل مسمّى "text".

[% USE String %]
[% USE String 'النص الأولي' %]
[% USE String text='النص الأولي' %]

سيُشار إلى الكائن المُنشأ باسم "String" افتراضيًا، لكن يمكنك تقديم اسم متغير مختلف ليُسنَد إليه الكائن:

[% USE greeting = String 'Hello World' %]

بمجرد حصولك على كائن "String"، يمكنك استخدامه كنموذج أولي لإنشاء كائنات "String" أخرى باستخدام طريقة new().

[% USE String %]
[% greeting = String.new('Hello World') %]

تقبل طريقة new() أيضًا سلسلة نصية أولية كوسيط أو المعامل المسمّى "text".

[% greeting = String.new( text => 'Hello World' ) %]

يمكنك أيضًا استدعاء copy() لإنشاء "String" جديدة كنسخة من الأصل.

[% greet2 = greeting.copy %]

يمتلك كائن "String" طريقة text() لإرجاع محتوى السلسلة.

[% greeting.text %]

ومع ذلك، يكفي ببساطة طباعة السلسلة والسماح لعامل التحويل إلى سلسلة المحمّل بالزيادة باستدعاء طريقة text() تلقائيًا نيابةً عنك.

[% greeting %]

وبالتالي، يمكنك التعامل مع كائنات "String" إلى حد كبير مثل أي قطعة نص عادية، بإدراجها في سلاسل أخرى، على سبيل المثال:

[% msg = "It printed '$greeting' and then dumped core\n" %]

كما تستفيد من العديد من الطرق الأخرى لمعالجة السلسلة.

[% msg.append("PS  Don't eat the yellow snow") %]

لاحظ أن جميع الطرق تعمل على محتويات السلسلة نفسها وتعدّلها. إذا أردت العمل على نسخة من السلسلة فببساطة خذ نسخة أولًا:

[% msg.copy.append("PS  Don't eat the yellow snow") %]

تُرجع هذه الطرق مرجعًا إلى كائن "String" نفسه. يتيح لك ذلك ربط عدة طرق معًا.

[% msg.copy.append('foo').right(72) %]

يعني ذلك أيضًا أنه في الأمثلة أعلاه، تُرجَع "String" مما يؤدي إلى استدعاء طريقة text()، وهو ما ينتج عنه طباعة القيمة الجديدة للسلسلة. لكتم طباعة السلسلة، يمكنك استخدام توجيه "CALL".

[% foo = String.new('foo') %]
[% foo.append('bar') %]         # يطبع "foobar"
[% CALL foo.append('bar') %]    # لا شيء

طرق الإنشاء

تُستخدم هذه الطرق لإنشاء كائنات "String" جديدة.

new()

تنشئ سلسلة جديدة باستخدام قيمة أولية تُمرَّر كوسيط موضعي أو المعامل المسمّى "text".

[% USE String %]
[% msg = String.new('Hello World') %]
[% msg = String.new( text => 'Hello World' ) %]

copy()

تنشئ كائن "String" جديدًا يحتوي على نسخة من السلسلة الأصلية.

[% msg2 = msg.copy %]

طرق الفحص

تُستخدم هذه الطرق لفحص السلسلة.

text()

تُرجع القيمة النصية الداخلية للسلسلة. عامل التحويل إلى سلسلة محمّل بالزيادة لاستدعاء هذه الطريقة. وبالتالي فإن ما يلي متكافئ:

[% msg.text %]
[% msg %]

length()

تُرجع طول السلسلة.

[% USE String("foo") %]
[% String.length %]   # => 3

search($pattern)

تبحث في السلسلة عن التعبير النمطي المحدد في $pattern وتُرجع صحيحًا إذا وُجد أو خطأ خلاف ذلك.

[% item = String.new('foo bar baz wiz waz woz') %]
[% item.search('wiz') ? 'WIZZY! :-)' : 'not wizzy :-(' %]

split($pattern, $limit)

تقسم السلسلة بناءً على الفاصل $pattern و$limit الاختياري. تُفوّض إلى split() الداخلية في Perl لذا فإن المعاملات متطابقة تمامًا.

[% FOREACH item.split %]
     ...
[% END %]
[% FOREACH item.split('baz|waz') %]
     ...
[% END %]

طرق التعديل

تُعدّل هذه الطرق القيمة الداخلية للسلسلة. على سبيل المثال:

[% USE str=String('foobar') %]
[% str.append('.html') %]   # str => 'foobar.html'

قيمة "str" الآن '"foobar.html"'. إذا كنت لا تريد تعديل السلسلة فببساطة خذ نسخة أولًا.

[% str.copy.append('.html') %]

تُرجع هذه الطرق جميعها مرجعًا إلى كائن "String" نفسه. لهذا فائدتان مهمتان. الأولى أنه عند الاستخدام كما هو مذكور أعلاه، فإن كائن "String" '"str"' الذي تُرجعه طريقة append() سيُحوَّل إلى سلسلة باستدعاء طريقة text() الخاصة به. سيُرجع ذلك محتوى السلسلة المعدّل حديثًا. بعبارة أخرى، توجيه مثل:

[% str.append('.html') %]

سيحدّث السلسلة ويطبع القيمة الجديدة أيضًا. إذا أردت فقط تحديث السلسلة دون طباعة القيمة الجديدة فاستخدم "CALL".

[% CALL str.append('.html') %]

الفائدة الأخرى لإرجاع هذه الطرق مرجعًا إلى "String" هي أنه يمكنك ربط أي عدد من استدعاءات الطرق المختلفة معًا كما تشاء. على سبيل المثال:

[% String.append('.html').trim.format(href) %]

إليك الطرق:

push($suffix, ...) / append($suffix, ...)

تُلحق جميع الوسائط بنهاية السلسلة. تُقدَّم طريقة append() كاسم بديل لـ push().

[% msg.push('foo', 'bar') %]
[% msg.append('foo', 'bar') %]

pop($suffix)

تزيل اللاحقة المُمرَّرة كوسيط من نهاية السلسلة.

[% USE String 'foo bar' %]
[% String.pop(' bar')   %]   # => 'foo'

unshift($prefix, ...) / prepend($prefix, ...)

تُضيف جميع الوسائط إلى بداية السلسلة. تُقدَّم طريقة prepend() كاسم بديل لـ```html

NAME

Template::Plugin::String - String manipulation plugin

SYNOPSIS

 [% USE String %]
 [% str = String('hello world') %]
 [% str.upper %]        # => 'HELLO WORLD'
 [% str.capitalize %]   # => 'Hello world'
 [% str.replace('world', 'Perl') %] # => 'hello Perl'

 # Using with arguments to the constructor
 [% USE String('hello world', 'World') %]
 [% str.replace('world', 'Perl') %] # => 'hello Perl'

 # Using with a number and format
 [% USE String(10) %]
 [% str.format('%05d') %] # => '00010'

DESCRIPTION

This is a plugin for the Template Toolkit that provides a simple interface to common string manipulation functions. It can be used in a number of ways:

  • as a constructor: 
     [% USE String %]
 [% str = String('hello world') %]
  • as a constructor with arguments: 
     [% USE String('hello world', 'World') %]

    This creates a string object, initialised with the first argument and an optional default value for the second argument.

  • as a filter: 
     [% 'hello world' | string %]

The methods provided by the plugin are designed to be chained, allowing for complex operations to be expressed concisely.

CONSTRUCTOR METHODS

String

The String constructor takes a single argument, which is the string value to be wrapped.

[% USE str = String('some text') %]

If called without arguments, it returns an empty string object.

[% str = String() %]

You can also provide a default value:

[% str = String('foo', 'bar') %] # str is 'foo', default is 'bar'

This is mainly useful for the format() method.

INSPECTOR METHODS

These methods return a value but do not modify the original string.

length

Returns the length of the string.

[% USE String('foo') %]
[% String.length %]  # => 3

match($match)

Returns a list of matches found using the regular expression $match.

[% USE String('foo bar baz') %]
[% String.match(/foo/) %]  # => ['foo']
[% String.match(/oo/) %]   # => ['oo']

split($delimiter)

Splits the string into a list of strings using the specified $delimiter.

[% USE String('foo,bar,baz') %]
[% String.split(',') %]  # => ['foo', 'bar', 'baz']

contains($needle)

Returns true if the string contains the specified $needle, false otherwise.

[% USE String('foo bar baz') %]
[% String.contains('bar') %] # => 1 (true)
[% String.contains('foo') %] # => 1 (true)
[% String.contains('wiz') %] # => '' (false)

first($needle)

Returns the index of the first occurrence of $needle in the string, or undef if not found.

[% USE String('foo bar baz') %]
[% String.first('bar') %] # => 4
[% String.first('foo') %] # => 0
[% String.first('wiz') %] # => undef

last($needle)

Returns the index of the last occurrence of $needle in the string, or undef if not found.

[% USE String('foo bar baz bar') %]
[% String.last('bar') %] # => 12
[% String.last('foo') %] # => 0
[% String.last('wiz') %] # => undef

MUTATOR METHODS

These methods return a new string object with the modification applied. They do not modify the original string.

prepend($string1, $string2, ...)

Prepends the given string(s) to the start of the string.

[% msg = String('World') %]
[% msg.prepend('Hello ', 'Cruel ') %] # => 'Hello Cruel World'

unshift($string1, $string2, ...)

An alias for prepend().

[% msg = String('World') %]
[% msg.unshift('Hello ', 'Cruel ') %] # => 'Hello Cruel World'
[% msg.prepend('Hello ', 'Cruel ') %]

shift($prefix)

Removes the prefix passed as an argument from the start of the String.

[% USE String 'foo bar' %]
[% String.shift('foo ') %]   # => 'bar'

left($pad)

If the length of the string is less than $pad then the string is left formatted and padded with spaces to $pad length.

[% msg.left(20) %]

right($pad)

As per left() but right padding the "String" to a length of $pad.

[% msg.right(20) %]

center($pad) / centre($pad)

As per left() and right() but formatting the "String" to be centered within a space padded string of length $pad. The centre() method is provided as an alias for center().

[% msg.center(20) %]    # American spelling
[% msg.centre(20) %]    # European spelling

format($format)

Apply a format in the style of sprintf() to the string.

[% USE String("world") %]
[% String.format("Hello %s\n") %]  # => "Hello World\n"

upper()

Converts the string to upper case.

[% USE String("foo") %]
[% String.upper %]  # => 'FOO'

lower()

Converts the string to lower case

[% USE String("FOO") %]
[% String.lower %]  # => 'foo'

capital()

Converts the first character of the string to upper case.

[% USE String("foo") %]
[% String.capital %]  # => 'Foo'

The remainder of the string is left untouched. To force the string to be all lower case with only the first letter capitalised, you can do something like this:

[% USE String("FOO") %]
[% String.lower.capital %]  # => 'Foo'

chop()

Removes the last character from the string.

[% USE String("foop") %]
[% String.chop %]   # => 'foo'

chomp()

Removes the trailing newline from the string.

[% USE String("foo\n") %]
[% String.chomp %]  # => 'foo'

trim()

Removes all leading and trailing whitespace from the string

[% USE String("   foo   \n\n ") %]
[% String.trim %]   # => 'foo'

collapse()

Removes all leading and trailing whitespace and collapses any sequences of multiple whitespace to a single space.

[% USE String(" \n\r  \t  foo   \n \n bar  \n") %]
[% String.collapse %]   # => "foo bar"

truncate($length, $suffix)

Truncates the string to $length characters.

[% USE String('long string') %]
[% String.truncate(4) %]  # => 'long'

If $suffix is specified then it will be appended to the truncated string. In this case, the string will be further shortened by the length of the suffix to ensure that the newly constructed string complete with suffix is exactly $length characters long.

[% USE msg = String('Hello World') %]
[% msg.truncate(8, '...') %]   # => 'Hello...'

replace($search, $replace)

Replaces all occurrences of $search in the string with $replace.

[% USE String('foo bar foo baz') %]
[% String.replace('foo', 'wiz')  %]  # => 'wiz bar wiz baz'

remove($search)

Remove all occurrences of $search in the string.

[% USE String('foo bar foo baz') %]
[% String.remove('foo ')  %]  # => 'bar baz'

repeat($count)

Repeats the string $count times.

[% USE String('foo ') %]
[% String.repeat(3)  %]  # => 'foo foo foo '
