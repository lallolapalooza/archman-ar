tblgen(1)

الحزمة: llvm

التراخيص: Apache-2.0 WITH LLVM-exception

\n \n
\n \n
\n \n
\n \n \n \n \n \n \n
TBLGEN(1)LLVMTBLGEN(1)
\n
\n
\n

اسم

\n

tblgen - وصف إلى كود C++

\n
\n
\n

الملخص

\n

clang-tblgen [خيارات] [اسم الملف]

\n

lldb-tblgen [خيارات] [اسم الملف]

\n

llvm-tblgen [خيارات] [اسم الملف]

\n

mlir-tblgen [خيارات] [اسم الملف]

\n
\n
\n

الوصف

\n

\u202A*-tblgen هي عائلة من البرامج التي تترجم وصف الهدف (ملفات .td) إلى كود C++ وتنسيقات أخرى. معظم مستخدمي LLVM لن يحتاجوا لاستخدام هذا البرنامج. يُستخدم فقط لكتابة أجزاء من المترجم، المصحح، والمساند الخلفية لأهداف LLVM.

\n

تفاصيل المدخلات والمخرجات لبرامج \u202A*-tblgen تتجاوز نطاق هذه المقدمة القصيرة؛ يرجى مراجعة نظرة عامة على TableGen <> للحصول على مقدمة ومراجع لوثائق TableGen الإضافية.

\n

يحدد الوسيط اسم الملف اسم ملف وصف الهدف (.td) الذي تعالجه TableGen.

\n
\n
\n

خيارات

\n
\n

خيارات عامة

\n
\n
\n
-help
\n
طباعة وصف لخيارات سطر الأوامر.
\n
\n
\n
\n
\n
-help-list
\n
طباعة وصف لخيارات سطر الأوامر بتنسيق قائمة بسيط.
\n
\n
\n
\n
\n
-D=macroname
\n
تحديد اسم ماكرو ليتم تعريفه. يتم تعريف الاسم، لكن ليس له قيمة محددة.
\n
\n
\n
\n
\n
-d=filename
\n
تحديد اسم ملف الاعتماديات.
\n
\n
\n
\n
\n
-debug
\n
تمكين إخراج التصحيح.
\n
\n
\n
\n
\n
-dump-json
\n
طباعة تمثيل JSON لجميع السجلات، مناسب للمعالجة الآلية الإضافية.
\n
\n
\n
\n
\n
-I directory
\n
تحديد مكان البحث عن ملفات وصف الهدف الأخرى للإدراج. يجب أن تكون قيمة directory مسارًا كاملاً أو جزئيًا لدليل يحتوي على ملفات وصف الهدف.
\n
\n
\n
\n
\n
-null-backend
\n
تحليل الملفات المصدر وبناء السجلات، ولكن لا تقم بتشغيل أي backend. هذا مفيد لقياس وقت الواجهة الأمامية.
\n
\n
\n
\n
\n
-o filename
\n
تحديد اسم ملف الإخراج. إذا كان filename هو -، فإن \u202A*-tblgen يرسل مخرجاته إلى الإخراج القياسي.
\n
\n
\n
\n
\n
-print-records
\n
طباعة جميع الفئات والسجلات إلى الإخراج القياسي (خيار backend الافتراضي).
\n
\n
\n
\n
\n
-print-detailed-records
\n
طباعة تقرير مفصل لجميع المتغيرات العامة والفئات والسجلات إلى الإخراج القياسي.
\n
\n
\n
\n
\n
-stats
\n
طباعة تقرير بأي إحصائيات تم جمعها بواسطة backend.
\n
\n
\n
\n
\n
-time-phases
\n
قياس وقت مراحل المحلل والمراحل الخلفية وطباعة تقرير.
\n
\n
\n
\n
\n
-version
\n
عرض رقم إصدار البرنامج.
\n
\n
\n
\n
\n
-write-if-changed
\n
كتابة ملف الإخراج فقط إذا كان جديدًا أو قد تغير.

tblgen(1) — archlinux manual pages

NAME

tblgen — TableGen compiler

SYNOPSIS

tblgen [options] [filename]

DESCRIPTION

tblgen is a code generator that uses a table-driven approach. It takes a description of operations, types, and other related information as input and generates C++ source code or other text files.

OPTIONS

-gen-emitter
Generate code for emitting operations.
-gen-external-emitter
Generate code for emitting operations, using external definitions.
-gen-external-parser
Generate code for parsing operations, using external definitions.
-gen-intrinsic-emitter
Generate code for emitting intrinsic operations.
-gen-intrinsic-parser
Generate code for parsing intrinsic operations.
-gen-ld-initializer-emitter
Generate code for emitting layout-dependent initializers.
-gen-ld-initializer-parser
Generate code for parsing layout-dependent initializers.
-gen-operation-checkers
Generate checker functions for operations.
-gen-operation-info
Generate information structures for operations.
-gen-operation-list
Generate a list of all defined operations.
-gen-operation-parser
Generate code for parsing operations.
-gen-operation-update-list
Generate a list of operations that can be updated.
-gen-register-info
Generate information structures for registers.
-gen-op-decls
Generate operation declarations.
-gen-op-defs
Generate operation definitions.
-asmformat-error-is-fatal
Emit a fatal error if format parsing fails.
-op-exclude-regex
Regular expression of name of ops to exclude (no filter if empty).
-op-include-regex
Regular expression of name of ops to include (no filter if empty).
-gen-op-doc
Generate operation documentation.
-gen-pass-decls
Generate operation documentation.
-name namestring
The name of this group of passes.
-gen-pass-doc
Generate pass documentation.
-gen-rewriters
Generate pattern rewriters.
-gen-spirv-avail-impls
Generate SPIR-V operation utility definitions.
-gen-spirv-capability-implication
Generate utility function to return implied capabilities for a given capability.
-gen-spirv-enum-avail-decls
Generate SPIR-V enum availability declarations.
-gen-spirv-enum-avail-defs
Generate SPIR-V enum availability definitions.
-gen-spirv-op-utils
Generate SPIR-V operation utility definitions.
-gen-spirv-serialization
Generate SPIR-V (de)serialization utilities and functions.
-gen-struct-attr-decls
Generate struct utility declarations.
-gen-struct-attr-defs
Generate struct utility definitions.
-gen-typedef-decls
Generate TypeDef declarations.
-gen-typedef-defs
Generate TypeDef definitions.
-typedefs-dialect name
Generate types for this dialect.

EXIT STATUS

If *-tblgen succeeds, it will exit with 0. Otherwise, if an error occurs, it will exit with a non-zero value.
