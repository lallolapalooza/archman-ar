الغرض:

!>
!> CTBRFS يوفر حدود الخطأ وتقديرات الخطأ الخلفي لحل نظام المعادلات الخطية
!> مع مصفوفة معامل نطاق مثلثي.
!>
!> يجب حساب مصفوفة الحل X بواسطة CTBTRS أو بوسيلة أخرى
!> قبل استدعاء هذا الروتين. CTBRFS لا تقوم بالتنقيح التكراري
!> لأن القيام بذلك لا يحسن الخطأ الخلفي.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  A مثلثية عليا؛
!>          = 'L':  A مثلثية سفلى.
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد شكل نظام المعادلات:
!>          = 'N':  A * X = B     (بدون تبديل)
!>          = 'T':  A**T * X = B  (تبديل)
!>          = 'C':  A**H * X = B  (تبديل مترافق)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          = 'N':  A غير موحدة مثلثية؛
!>          = 'U':  A موحدة مثلثية.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

KD

!>          KD هو INTEGER
!>          عدد الأقطار الفائقة أو الأقطار الفرعية للمصفوفة
!>          النطاق المثلثي A.  KD >= 0.
!>

NRHS

!>          NRHS هو INTEGER
!>          عدد الأطراف اليمنى، أي عدد الأعمدة
!>          للمصفوفتين B و X.  NRHS >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX، البعد (LDAB,N)
!>          المصفوفة المثلثية العليا أو السفلى A، مخزنة في
!>          الصفوف الـ kd+1 الأولى من المصفوفة. العمود j من A مخزن
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)    = A(i,j) لـ j<=i<=min(n,j+kd).
!>          إذا كان DIAG = 'U'، فإن العناصر القطرية لـ A لا تتم الإشارة إليها
!>          ويفترض أنها 1.
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الأمامي للمصفوفة AB.  LDAB >= KD+1.
!>

B

!>          B هي مصفوفة COMPLEX، البعد (LDB,NRHS)
!>          مصفوفة الطرف الأيمن B.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الأمامي للمصفوفة B.  LDB >= max(1,N).
!>

X

!>          X هي مصفوفة COMPLEX، البعد (LDX,NRHS)
!>          مصفوفة الحل X.
!>

LDX

!>          LDX هو INTEGER
!>          البعد الأمامي للمصفوفة X.  LDX >= max(1,N).
!>

FERR

!>          FERR هي مصفوفة REAL، البعد (NRHS)
!>          حد الخطأ الأمامي المقدر لكل متجه حل
!>          X(j) (العمود j من مصفوفة الحل X).
!>          إذا كان XTRUE هو الحل الحقيقي المقابل لـ X(j)، فإن FERR(j)
!>          هو حد أعلى مقدر لقيمة الجزء الأكبر
!>          في (X(j) - XTRUE) مقسوماً على قيمة الجزء الأكبر
!>          في X(j). التقدير موثوق به بقدر
!>          موثوقية تقدير RCOND، وهو تقريباً دائماً زيادة طفيفة
!>          للخطأ الحقيقي.
!>

BERR

!>          BERR هي مصفوفة REAL، البعد (NRHS)
!>          الخطأ الخلفي النسبي المكوني لكل متجه حل
!>          X(j) (أي، أصغر تغيير نسبي في
!>          أي عنصر في A أو B يجعل X(j) حلاً دقيقاً).
!>

WORK

!>          WORK هي مصفوفة COMPLEX، البعد (2*N)
!>

RWORK

!>          RWORK هي مصفوفة REAL، البعد (N)
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت لها قيمة غير قانونية
!>

dtbrfs.f

NAME

dtbrfs -

SYNOPSIS

  SUBROUTINE DTBRFS( UPLO, TRANS, DIAG, N, KD, NRHS, AB, LDAB, B, LDB, X, &
                     LDX, FERR, BERR, WORK, IWORK, INFO )

DESCRIPTION

DTBRFS provides error bounds and backward error estimates for the solution to a system of linear equations with a triangular band coefficient matrix.

The solution matrix X must be computed by DTBTRS or some other means before entering this routine. DTBRFS does not do iterative refinement because doing so cannot improve the backward error.

PARAMETERS

UPLO

UPLO is CHARACTER*1

= 'U': A is upper triangular;

= 'L': A is lower triangular.

TRANS

TRANS is CHARACTER*1

Specifies the form of the system of equations:

= 'N': A * X = B (No transpose)

= 'T': A**T * X = B (Transpose)

= 'C': A**H * X = B (Conjugate transpose = Transpose)

DIAG

DIAG is CHARACTER*1

= 'N': A is non-unit triangular;

= 'U': A is unit triangular.

N

N is INTEGER

The order of the matrix A. N >= 0.

KD

KD is INTEGER

The number of superdiagonals or subdiagonals of the triangular band matrix A. KD >= 0.

NRHS

NRHS is INTEGER

The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.

AB

AB is DOUBLE PRECISION array, dimension (LDAB,N)

The upper or lower triangular band matrix A, stored in the first kd+1 rows of the array. The j-th column of A is stored in the j-th column of the array AB as follows:

if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) for max(1,j-kd)<=i<=j;

if UPLO = 'L', AB(1+i-j,j) = A(i,j) for j<=i<=min(n,j+kd).

If DIAG = 'U', the diagonal elements of A are not referenced and are assumed to be 1.

LDAB

LDAB is INTEGER

The leading dimension of the array AB. LDAB >= KD+1.

B

B is DOUBLE PRECISION array, dimension (LDB,NRHS)

The right hand side matrix B.

LDB

LDB is INTEGER

The leading dimension of the array B. LDB >= max(1,N).

X

X is DOUBLE PRECISION array, dimension (LDX,NRHS)

The solution matrix X.

LDX

LDX is INTEGER

The leading dimension of the array X. LDX >= max(1,N).

FERR

FERR is DOUBLE PRECISION array, dimension (NRHS)

The estimated forward error bound for each solution vector X(j) (the j-th column of the solution matrix X). If XTRUE is the true solution corresponding to X(j), FERR(j) is an estimated upper bound for the magnitude of the largest element in (X(j) - XTRUE) divided by the magnitude of the largest element in X(j). The estimate is as reliable as the estimate for RCOND, and is almost always a slight overestimate of the true error.

BERR

BERR is DOUBLE PRECISION array, dimension (NRHS)

The componentwise relative backward error of each solution vector X(j) (i.e., the smallest relative change in any element of A or B that makes X(j) an exact solution).

WORK

WORK is DOUBLE PRECISION array, dimension (3*N)

IWORK

IWORK is INTEGER array, dimension (N)

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

Detailed Description

TBRFS

    Purpose

TBRFS provides a forward-error estimate for the system of equations

    A * X = B,

where A is a triangular band matrix, and X and B are any rectangular matrices. The error estimate is computed for the scaled system

    ( S * A ) * X = ( S * B ),

where S is the scaling matrix consisting of the diagonal elements of A.

This routine is called by TBTRF to compute the forward error bound and the relative backward error. If the U and possibly UDIAG factors of A are available, then TBRFS can be used to compute forward and backward error bounds for the solution of A * X = B.

    Arguments
UPLO
CHARACTER*1.
          = 'U': A is an upper triangular band matrix.
          = 'L': A is a lower triangular band matrix.
TRANS
CHARACTER*1.
          Specifies the form of the system of equations:
          = 'N': A * X = B (No transpose)
          = 'T': A**T * X = B (Transpose)
          = 'C': A**H * X = B (Conjugate transpose)
DIAG
CHARACTER*1.
          = 'N': The unit diagonal implicitly stored in AFB.
          = 'U': The diagonal elements of the matrix are stored
                 in the first sub-diagonal of AFB.
          = 'S': The diagonal elements of the matrix are stored
                 in the first sub-diagonal of AFB.
N
INTEGER.
          The order of the matrix A.  N >= 0.
KD
INTEGER.
          The number of superdiagonals or subdiagonals of the
          triangular band matrix A.  KD >= 0.
NRHS
INTEGER.
          The number of right hand sides, i.e., the number of columns
          of the matrices B and X.  NRHS >= 0.
AB
COMPLEX*16 array, dimension (LDAB,N).
          The upper or lower triangular band matrix A, stored in the
          first kd+1 rows of the array. The j-th column of A is stored
