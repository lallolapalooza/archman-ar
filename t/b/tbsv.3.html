روتين فرعي ctbsv (character uplo, character trans, character diag, integer n, integer k, complex, dimension(lda,*) a, integer lda, complex, dimension(*) x, integer incx)

CTBSV

الغرض:

!>
!> CTBSV  يحل أحد أنظمة المعادلات
!>
!>    A*x = b,   أو   A**T*x = b,   أو   A**H*x = b,
!>
!> حيث b و x هما متجهان مكونان من n عنصر، و A هي مصفوفة قطرية علوية أو سفلية
!> وحدة، أو غير وحدة، عرضية، بحجم n × n، مع ( k + 1 ) قطري.
!>
!> لا يتضمن هذا الروتين اختبارًا للعزوم أو الاقتراب من العزم. يجب إجراء
!> مثل هذه الاختبارات قبل استدعاء هذا الروتين.
!>

المعلمات

UPLO 
!>          UPLO هي CHARACTER*1
!>           عند الدخول، تحدد UPLO ما إذا كانت المصفوفة مصفوفة قطرية علوية أو
!>           سفلية على النحو التالي:
!>
!>              UPLO = 'U' أو 'u'   A هي مصفوفة قطرية علوية.
!>
!>              UPLO = 'L' أو 'l'   A هي مصفوفة قطرية سفلية.
!>

TRANS

!>          TRANS هي CHARACTER*1
!>           عند الدخول، تحدد TRANS المعادلات التي سيتم حلها على النحو التالي:
!>
!>              TRANS = 'N' أو 'n'   A*x = b.
!>
!>              TRANS = 'T' أو 't'   A**T*x = b.
!>
!>              TRANS = 'C' أو 'c'   A**H*x = b.
!>

DIAG

!>          DIAG هي CHARACTER*1
!>           عند الدخول، تحدد DIAG ما إذا كانت A وحدة قطرية أم لا على النحو
!>           التالي:
!>
!>              DIAG = 'U' أو 'u'   يفترض أن A وحدة قطرية.
!>
!>              DIAG = 'N' أو 'n'   لا يفترض أن A وحدة
!>                                  قطرية.
!>

N

!>          N هو INTEGER
!>           عند الدخول، تحدد N رتبة المصفوفة A.
!>           يجب أن تكون N أكبر من أو تساوي صفر.
!>

K

!>          K هو INTEGER
!>           عند الدخول مع UPLO = 'U' أو 'u'، تحدد K عدد الأقطار الفائقة
!>           للمصفوفة A.
!>           عند الدخول مع UPLO = 'L' أو 'l'، تحدد K عدد الأقطار الفرعية
!>           للمصفوفة A.
!>           يجب أن تحقق K  0 .le. K.
!>

A

!>          A هي مصفوفة COMPLEX، ذات بُعد ( LDA, N )
!>           قبل الدخول مع UPLO = 'U' أو 'u'، يجب أن يحتوي الجزء الأمامي
!>           ( k + 1 ) × n من المصفوفة A على الجزء القطري العلوي للمصفوفة
!>           المعاملية، المقدمة عمودًا بعمود، مع وجود القطر الرئيسي للمصفوفة
!>           في الصف ( k + 1 ) من المصفوفة، ويبدأ القطر الفائق الأول في
!>           الموضع 2 في الصف k، وهكذا. المثلث العلوي الأيسر بحجم k × k
!>           من المصفوفة A غير مستخدم.
!>           سيقوم مقطع البرنامج التالي بنقل مصفوفة عرضية قطرية علوية من
!>           تخزين المصفوفة الكاملة التقليدي إلى تخزين العرض:
!>
!>                 DO 20, J = 1, N
!>                    M = K + 1 - J
!>                    DO 10, I = MAX( 1, J - K ), J
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           قبل الدخول مع UPLO = 'L' أو 'l'، يجب أن يحتوي الجزء الأمامي
!>           ( k + 1 ) × n من المصفوفة A على الجزء القطري السفلي للمصفوفة
!>           المعاملية، المقدمة عمودًا بعمود، مع وجود القطر الرئيسي للمصفوفة
!>           في الصف 1 من المصفوفة، ويبدأ القطر الفرعي الأول في الموضع 1 في
!>           الصف 2، وهكذا. المثلث السفلي الأيمن بحجم k × k من المصفوفة A
!>           غير مستخدم.
!>           سيقوم مقطع البرنامج التالي بنقل مصفوفة عرضية قطرية سفلية من
!>           تخزين المصفوفة الكاملة التقليدي إلى تخزين العرض:
!>
!>                 DO 20, J = 1, N
!>                    M = 1 - J
!>                    DO 10, I = J, MIN( N, J + K )
!>                       A( M + I, J ) = matrix( I, J )
!>              10    CONTINUE
!>              20 CONTINUE
!>
!>           لاحظ أنه عندما يكون DIAG = 'U' أو 'u'، فإن عناصر المصفوفة A
!>           المقابلة لعناصر القطر للمصفوفة غير مستخدمة، ولكن يفترض أنها
!>           الوحدة.
!>

LDA

!>          LDA هو INTEGER
!>           عند الدخول، تحدد LDA البعد الأول لـ A كما هو معلن في برنامج
!>           الاستدعاء (الفرعي). يجب أن يكون LDA على الأقل
!>           ( k + 1 ).
!>

X

!>          X هي مصفوفة COMPLEX، ذات بُعد على الأقل
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           قبل الدخول، يجب أن تحتوي المصفوفة X المتزايدة على متجه الطرف
!>           الأيمن b المكون من n عنصر. عند الخروج، يتم الكتابة فوق X
!>           بالمتجه الحل x.
!>

INCX

!>          INCX هو INTEGER
!>           عند الدخول، تحدد INCX الزيادة لعناصر X. يجب ألا تكون INCX صفرًا.
!>
