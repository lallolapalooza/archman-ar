الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

NAME

tracefs_cpu_unmap - free the tracefs cpu map

SYNOPSIS

tracefs_cpu_unmap(struct tracefs_cpu_map*map);

DESCRIPTION

The tracefs_cpu_unmap function frees the memory allocated for the tracefs cpu map passed in by map.

RETURN VALUE

This function does not return a value.

EXAMPLE

int ret;
struct tracefs_cpu_map *map;

map = tracefs_cpu_map_get(NULL);
if (!map) {
    /* handle error */
}

/* ... use the map ... */

tracefs_cpu_unmap(map);

FILES

No files are directly used by this function.
