الاسم

trace-cmd -- تتبع أوامر نظام التشغيل

الملخص

trace-cmd record -e --
trace-cmd start -e
trace-cmd stop
trace-cmd reset
trace-cmd list
trace-cmd listen
trace-cmd screenshot
trace-cmd shell
trace-cmd set -c
trace-cmd report
trace-cmd help

الوصف

trace-cmd هي أداة مساعدة لجمع بيانات التتبع من نواة Linux. يمكن استخدامها لتسجيل وتصوير وتحليل تتبع أحداث النواة. إنها واجهة مستخدم سهلة الاستخدام لـ ftrace، وهي أداة تتبع قوية مضمنة في نواة Linux.

تتيح لك trace-cmd:

  • تسجيل أحداث النواة لملف.
  • بدء وإيقاف التتبع ديناميكيًا.
  • عرض قائمة بالأحداث المتاحة.
  • الاستماع إلى أحداث التتبع في الوقت الفعلي.
  • أخذ لقطات من حالة التتبع الحالية.
  • تشغيل shell تفاعلي مع معلومات التتبع.
  • ضبط معلمات التتبع مثل حجم المخزن المؤقت.
  • الإبلاغ عن بيانات التتبع بتنسيقات مختلفة.

قيمة الإرجاع

تُرجع الأوامر قيمة 0 عند النجاح، وقيمة غير صفرية عند الفشل.

مثال

لتسجيل تتبع حدث sched_switch أثناء تشغيل أمر ls:

trace-cmd record -e sched_switch -- ls -l

لبدء التتبع لحدث syscalls:

trace-cmd start -e syscalls

لإيقاف التتبع:

trace-cmd stop

لعرض تقرير عن بيانات التتبع المسجلة:

trace-cmd report

الملفات

  • /sys/kernel/debug/tracing/: دليل جذر ftrace.

انظر أيضاً

ftrace(8), perf(1)

الإبلاغ عن الأخطاء

قم بالإبلاغ عن الأخطاء إلى linux-trace@vger.kernel.org.
