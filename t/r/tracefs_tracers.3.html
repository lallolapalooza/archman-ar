tracefs_tracers(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_tracers, tracefs_tracer_available, tracefs_get_clock, tracefs_list_free, tracefs_list_add, tracefs_list_size - وظائف مساعدة للعمل مع نظام ملفات التتبع.

الملخص

#include <tracefs.h>
char **tracefs_tracers(const char *tracing_dir);
bool tracefs_tracer_available(const char *tracing_dir, const char *tracer);
char *tracefs_get_clock(struct tracefs_instance *instance);
void tracefs_list_free(char **list);
char **tracefs_list_add(char *list, const char *string);
int *tracefs_list_size(char **list);

الوصف

وظائف مفيدة متنوعة للعمل مع نظام ملفات التتبع.

تقوم الدالة tracefs_tracers() بإرجاع مصفوفة من السلاسل النصية بأسماء ملحقات المتتبع المدعومة، الموجودة في دليل tracing_dir المحدد. يمكن أن يكون هذا NULL أو موقع نقطة تحميل tracefs لأنظمة تتبع الجهاز المحلي، أو قد يكون مسارًا لنسخة من دليل tracefs من جهاز آخر. العنصر الأخير في المصفوفة هو مؤشر NULL. يجب تحرير المصفوفة باستخدام واجهة برمجة التطبيقات tracefs_list_free().

ترجع الدالة tracefs_tracer_available() صحيحًا إذا كان tracer متاحًا في الدليل tracing_dir_director المحدد، وغير ذلك فترجع خطأ.

ترجع الدالة tracefs_get_clock() اسم ساعة التتبع الحالية، المستخدمة في instance المحدد. إذا كان instance هو NULL، فسيتم إرجاع ساعة المثيل الرئيسي للتتبع. يجب تحرير السلسلة النصية المرجعة باستخدام free().

تقوم الدالة tracefs_list_free() بتحرير مصفوفة من السلاسل النصية، التي تم إرجاعها بواسطة واجهات برمجة التطبيقات tracefs_event_systems() و tracefs_system_events() و tracefs_tracers().

تقوم الدالة tracefs_list_add() بإضافة string إلى قائمة السلاسل النصية list. إذا كان list هو NULL، فسيتم إنشاء قائمة جديدة مع كون العنصر الأول نسخة من string، وسيكون العنصر الثاني مؤشر NULL. إذا لم يكن list هو NULL، فسيتم إعادة تخصيصه لتضمين عنصر جديد ومُنهي NULL، وسيتم إرجاع المصفوفة الجديدة المخصصة. يجب تجاهل القائمة المقدمة، حيث سيتم تحريرها إذا تم تخصيص قائمة جديدة.

الدالة tracefs_list_size() هي طريقة سريعة لمعرفة عدد العناصر في مصفوفة سلاسل نصية سيتم تحريرها باستخدام tracefs_list_free(). لاحظ، يعتمد هذا على البيانات الوصفية التي تم إنشاؤها لهذه القوائم ولن تعمل على مصفوفات السلاسل النصية العادية مثل argv.

قيمة الإرجاع

ترجع الدالة tracefs_tracers() مصفوفة من السلاسل النصية. العنصر الأخير في تلك المصفوفة هو مؤشر NULL. يجب تحرير المصفوفة باستخدام واجهة برمجة التطبيقات tracefs_list_free(). في حالة حدوث خطأ، يتم إرجاع NULL.

ترجع الدالة tracefs_tracer_available() صحيحًا إذا كان tracer متاحًا، وغير ذلك فترجع خطأ.

ترجع الدالة tracefs_get_clock() سلسلة نصية، يجب تحريرها باستخدام free()، أو NULL في حالة حدوث خطأ.

ترجع الدالة tracefs_list_add() مصفوفة سلاسل نصية مخصصة يجب تحريرها باستخدام tracefs_list_free() عند النجاح أو NULL عند حدوث خطأ. إذا تم إرجاع NULL، فلن يتم المساس بالقائمة المقدمة. وبالتالي، يجب التعامل مع tracefs_list_add() بشكل مشابه لـ realloc(3).

ترجع الدالة tracefs_list_size() عدد السلاسل النصية في list. يجب أن تكون القائمة المقدمة هي تلك التي سيتم تحريرها باستخدام tracefs_list_free() حيث تحتوي القائمة على بيانات وصفية تُستخدم لتحديد الحجم وهذا لا يعمل على أي مصفوفة سلاسل نصية عادية مثل argv.

مثال

#include <tracefs.h>
char **tracers = tracefs_tracers(NULL);
        if (tracers) {
                /* حصل على ملحقات المتتبع من المثيل الأعلى للتتبع */
                ...
                tracefs_list_free(tracers);
        }
....
char *clock = tracefs_get_clock(NULL);
        if (clock) {
                /* حصل على ساعة التتبع الحالية للمثيل الأعلى للتتبع */
                ...
                free(clock);
        }
