tracefs_option_name(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_option_enable, tracefs_option_disable, tracefs_option_name - وظائف خيارات التتبع المختلفة.

الملخص

#include <tracefs.h>
int tracefs_option_enable(struct tracefs_instance *instance, enum tracefs_option_id id);
int tracefs_option_disable(struct tracefs_instance *instance, enum tracefs_option_id id);
const char *tracefs_option_name(enum tracefs_option_id id);

الوصف

يمكن استخدام مجموعة واجهات برمجة التطبيقات هذه لتمكين وتعطيل خيارات ftrace، وللحصول على اسم الخيار.

تقوم الدالة tracefs_option_enable() بتمكين الخيار ذي المعرف id في النسخة instance المعطاة. إذا كانت instance فارغة (NULL)، يتم تمكين الخيار في النسخة العلوية للتتبع.

تقوم الدالة tracefs_option_disable() بتعطيل الخيار ذي المعرف id في النسخة instance المعطاة. إذا كانت instance فارغة (NULL)، يتم تعطيل الخيار في النسخة العلوية للتتبع.

تعيد الدالة tracefs_option_name() سلسلة نصية تمثل الخيار ذي المعرف id. يجب عدم تحرير هذه السلسلة.

القيمة المعادة

تعيد الدالتان tracefs_option_enable() و tracefs_option_disable() القيمة 0 إذا تم تعيين حالة الخيار بنجاح، أو -1 في حالة حدوث خطأ.

تعيد الدالة tracefs_option_name() سلسلة نصية باسم الخيار، أو "unknown" في حالة حدوث خطأ. يجب عدم تحرير السلسلة المعادة.

مثال

#include <tracefs.h>
...
if (tracefs_option_enable(NULL, TRACEFS_OPTION_ANNOTATE)) {
        /* فشل في تمكين خيار الشرح في النسخة العلوية للتتبع */
}
...
if (tracefs_option_disable(NULL, TRACEFS_OPTION_CONTEXT_INFO)) {
        /* فشل في تعطيل خيار معلومات السياق في النسخة العلوية للتتبع */
}
...
char *name = tracefs_option_name(TRACEFS_OPTION_FUNC_STACKTRACE);
if (strcmp(name, "unknown")) {
        /* لا يمكن الحصول على اسم الخيار */
}
