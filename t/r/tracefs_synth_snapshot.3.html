الوصف

الأحداث الاصطناعية هي أحداث ديناميكية تُنشأ عن طريق مطابقة حدثين آخرين مما يؤدي إلى تشغيل حدث اصطناعي. أحد الحدثين هو حدث البداية الذي يُسجَّل فيه حقل ما، وعند تنفيذ الحدث الثاني، إذا كان يحتوي على حقل (أو حقول) يطابق حقل حدث البداية (أو حقوله) فإنه سيُشغِّل الحدث الاصطناعي. يمكن تمرير قيم الحقول غير الحقول المطابقة من حدث البداية إلى حدث النهاية لإجراء حسابات عليها، أو ببساطة تمريرها كمعامل إلى الحدث الاصطناعي.

أحد حالات الاستخدام الشائعة هو تعيين "sched_waking" كحدث البداية. يُشغَّل هذا الحدث عند إيقاظ عملية ما. ثم تعيين "sched_switch" كحدث النهاية. يُشغَّل هذا الحدث عند جدولة مهمة جديدة على وحدة المعالجة المركزية. بتعيين "common_pid" لكلا الحدثين كحقول مطابقة، يُعتبر الوقت بين الحدثين هو زمن استيقاظ تلك العملية. استخدم TRACEFS_TIMESTAMP كحقل لكلا الحدثين لحساب الفرق بالنانوثانية، أو استخدم TRACEFS_TIMESTAMP_USECS كحقول مقارنة لكلا الحدثين لحساب الفرق بالميكروثانية. يُستخدم هذا كمثال أدناه.

tracefs_synth_create() ينشئ الحدث الاصطناعي في النظام. افتراضيًا، تُنشأ محفزات المدرج التكراري في نسخة التتبع العليا، حيث يمكن استخدام أي حدث اصطناعي عالميًا عبر جميع النسخ. في حال أراد تطبيق ما إبقاء محفزات المدرج التكراري خارج نسخة المستوى الأعلى، يمكنه استخدام tracefs_synth_set_instance() لجعل المدرجات التكرارية المستخدمة لإنشاء الحدث الاصطناعي في نسخة غير المستوى الأعلى. يجب إنشاء واصف حدث اصطناعي باستخدام tracefs_synth_alloc(3) قبل أن يمكن استخدام هذا لإنشائه على النظام.

tracefs_synth_destroy() يدمّر الحدث الاصطناعي. سيحاول إيقاف تشغيله في نسخته (العليا افتراضيًا)، ولكن إذا كان يعمل في نسخة أخرى فقد يفشل ذلك بسبب الانشغال.

tracefs_synth_complete() يُرجع صحيحًا إذا كان الحدث الاصطناعي synth يحتوي على حدث بداية وحدث نهاية.

tracefs_synth_trace() بدلاً من مجرد إجراء تتبع عند مطابقة حدثي البداية والنهاية، نفّذ معالج type حيث يقوم TRACEFS_SYNTH_HANDLE_MAX بتتبع عندما يصل المتغير المعطى var إلى قيمة عظمى جديدة للمفاتيح المطابقة. أو TRACEFS_SYNTH_HANDLE_CHANGE عندما يتغير var. يجب أن يكون var أحد عناصر name المستخدمة في tracefs_synth_add_end_field(3).

tracefs_synth_snapshot() عندما يكون المتغير المعطى var إما قيمة عظمى جديدة إذا كان handler هو TRACEFS_SYNTH_HANDLE_MAX أو تغيّر ببساطة إذا كان TRACEFS_SYNTH_HANDLE_CHANGE فخذ "لقطة" من المخزن المؤقت. تنقل اللقطة مخزن "التتبع" العادي إلى مخزن "اللقطة"، والذي يمكن الوصول إليه عبر ملف "snapshot" في دليل tracefs للمستوى الأعلى، أو إحدى النسخ. يتغير var. يجب أن يكون var أحد عناصر name المستخدمة في tracefs_synth_add_end_field(3).

tracefs_synth_save() عندما يكون المتغير المعطى var إما قيمة عظمى جديدة إذا كان handler هو TRACEFS_SYNTH_HANDLE_MAX أو تغيّر ببساطة إذا كان TRACEFS_SYNTH_HANDLE_CHANGE فاحفظ قائمة save_fields المعطاة. ستُخزَّن الحقول في ملف "hist" للمدرج التكراري للحدث الذي يمكن استرجاعه باستخدام tracefs_event_file_read(3). يجب أن يكون var أحد عناصر name المستخدمة في tracefs_synth_add_end_field(3).

tracefs_synth_set_instance() تعيين نسخة التتبع، حيث ستُنشأ محفزات المدرج التكراري التي تنشئ الحدث الاصطناعي. افتراضيًا، تُستخدم النسخة العليا. يجب استدعاء واجهة البرمجة هذه قبل الاستدعاء إلى tracefs_synth_create()، لاستخدام النسخة الجديدة عند إنشاء الحدث. لاحظ أنه حتى إذا أُنشئ الحدث الاصطناعي في نسخة، فإنه لا يزال مرئيًا لجميع النسخ الأخرى بما في ذلك المستوى الأعلى. أي أنه يمكن للنسخ الأخرى تمكين الحدث الاصطناعي المُنشأ وجعله متتبعًا في المخازن المؤقتة التي تنتمي إلى النسخة التي مكّنته.

قيمة الإرجاع

جميع الدوال تُرجع صفرًا عند النجاح أو -1 عند الخطأ.

الأخطاء

الأخطاء التالية تخص جميع الاستدعاءات أعلاه:

EPERM لم يُشغَّل كمستخدم جذر عندما يكون ذلك مطلوبًا.

EINVAL إما أن معاملًا غير صالح (NULL عندما لا ينبغي أن يكون) أو حقل غير متوافق للحسابات.

ENODEV لم يُعثر على حدث أو أحد حقوله.

EBADE حقول حدثي البداية والنهاية غير متوافقة إما للمطابقة أو للمقارنة.

ENOMEM لا تتوفر ذاكرة كافية.

وقد تحدث المزيد من الأخطاء من استدعاءات النظام إلى النظام.

مثال

انظر tracefs_sql(3) لاستخدام أكثر تعمقًا لبعض هذا الكود.

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL); tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE, "prev_prio", TRACEFS_COMPARE_GE, "100"); /* * ملاحظة، ما سبق أضاف فقط: "next_prio < 50 || !(prev_prio >= 100" * وذلك لأنه، عند تنفيذ التركيب، ستُضاف القوس الختامي المتبقي. * أي أن السلسلة ستنتهي لتكون: * "next_prio < 50 || !(prev_prio >= 100)" عند تشغيل أحد * tracefs_sync_create() أو tracefs_sync_echo_cmd(). */ } /* عرض كيفية إنشاء الحدث التركيبي */ static void show_event(void) { struct trace_seq s; trace_seq_init(&s); tracefs_synth_echo_cmd(&s, synth); trace_seq_terminate(&s); trace_seq_do_printf(&s); trace_seq_destroy(&s); } int main (int argc, char **argv) { make_event(); if (argc > 1) { if (!strcmp(argv[1], "create")) { /* إنشاء الحدث التركيبي */ tracefs_synth_create(synth); } else if (!strcmp(argv[1], "delete")) { /* حذف الحدث التركيبي */ tracefs_synth_destroy(synth); } else { printf("usage: %s [create|delete]\n", argv[0]); exit(-1); } } else show_event(); tracefs_synth_free(synth); return 0; }
