tracefs_put_tracing_file(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_get_tracing_file, tracefs_put_tracing_file, tracefs_tracing_dir, tracefs_debug_dir, tracefs_set_tracing_dir, tracefs_tracing_dir_is_mounted - البحث عن مواقع دليل التتبع والملفات وتعيينها.

ملخص

#include <tracefs.h>
char *tracefs_get_tracing_file(const char *name);
void tracefs_put_tracing_file(char *name);
const char *tracefs_tracing_dir(void);
const char *tracefs_debug_dir(void);
int tracefs_set_tracing_dir(char *tracing_dir)
int tracefs_tracing_dir_is_mounted(bool mount, const char **path);

الوصف

يمكن استخدام مجموعة واجهات برمجة التطبيقات هذه للعثور على المسار الكامل لنقطة تحميل نظام الملفات للتتبع والملفات الموجودة فيه.

تقوم الدالة tracefs_set_tracing_dir() بتعيين موقع مخصص لنقطة تحميل دليل التتبع في النظام. عادةً، تقوم المكتبة بالكشف التلقائي عنه باستخدام المعلومات من ملف /proc/mounts. استخدم واجهة برمجة التطبيقات هذه فقط إذا كان نقطة التحميل غير قياسية ولا يمكن اكتشافها بواسطة المكتبة. يمكن أن تكون الوسيطة tracing_dir NULL، وفي هذه الحالة يتم حذف الموقع المخصص ويتم استخدام منطق الكشف التلقائي للمكتبة.

تقوم الدالة tracefs_get_tracing_file() بإرجاع المسار الكامل للملف بالاسم name المعطى في نظام ملفات التتبع. تعمل الدالة فقط مع الملفات في الدليل الرئيسي لـ tracefs، وهي ليست على دراية بتتبع المثيلات. يوصى باستخدام tracefs_instance_get_file() و tracefs_instance_get_dir() بدلاً من ذلك. يجب تحرير السلسلة المرجعة باستخدام tracefs_put_tracing_file().

تقوم الدالة tracefs_put_tracing_file() بتحرير اسم ملف التتبع، الذي تم إرجاعه بواسطة tracefs_get_tracing_file().

تقوم الدالة tracefs_tracing_dir() بإرجاع المسار الكامل لنظام ملفات التتبع. في أول استدعاء للدالة، يتم تحديد نقطة تحميل نظام ملفات التتبع وتخزينها مؤقتًا وإرجاعها. ستقوم بتحميلها، إذا لم تكن محملة. في أي استدعاء لاحق، يتم إرجاع المسار المخزن مؤقتًا. يجب عدم تحرير السلسلة المرجعة.

الدالة tracefs_debug_dir() مشابهة للدالة tracefs_tracing_dir() باستثناء أنها ستعيد مكان تحميل نظام ملفات debugfs. إذا لم يتم تحميله، فسوف يحاول تحميله. يجب عدم تحرير السلسلة المرجعة.

tracefs_tracing_dir_is_mounted() تُرجع 1 إذا كان دليل التتبع محملاً بالفعل و 0 إذا لم يكن كذلك. إذا كانت mount صحيحة، فستحاول تحميله إذا لم يكن كذلك، وتُرجع 0 إذا نجحت في تحميله و -1 إذا لم تفعل. إذا تم تعيين path، فسيتم تعيينه إلى المسار الذي تم تحميله فيه. path هو داخلي ولا ينبغي تحريره.

قيمة الإرجاع

تُرجع الدالة tracefs_set_tracing_dir() 0 عند النجاح، و -1 بخلاف ذلك.

تُرجع الدالة tracefs_get_tracing_file() سلسلة نصية أو NULL في حالة حدوث خطأ. يجب تحرير السلسلة النصية المرجعة بواسطة tracefs_put_tracing_file().

تُرجع الدالة tracefs_tracing_dir() سلسلة ثابتة أو NULL في حالة حدوث خطأ. يجب عدم تحرير السلسلة النصية المرجعة.

تُرجع الدالة tracefs_debug_dir() سلسلة ثابتة أو NULL في حالة حدوث خطأ. يجب عدم تحرير السلسلة النصية المرجعة.

تُرجع الدالة tracefs_tracing_dir_is_mounted() 1 إذا كان دليل التتبع محملاً بالفعل، و 0 إذا لم يكن كذلك، و -1 عند حدوث خطأ.

مثال

#include <tracefs.h>
...
char *trace_on = tracefs_get_tracing_file("tracing_on");
        if (trace_on) {
                ...
                tracefs_put_tracing_file(trace_on);
        }
...
const char *trace_dir = tracefs_tracing_dir();
