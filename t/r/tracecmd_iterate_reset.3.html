الوصف

يمكن استخدام مجموعة الواجهات هذه للتنقل عبر الأحداث بعد فتح ملف تتبع باستخدام إحدى وظائف الفتح مثل tracecmd_open(3) أو tracecmd_open_fd(3).

تقوم الدالة tracecmd_iterate_events() بالتنقل عبر جميع الأحداث في ملف التتبع المحدد بواسطة handle، حيث يتم إرجاع handle من إحدى وظائف tracecmd_open(3). ستقوم باستدعاء الدالة callback() على الأحداث الموجودة في وحدات المعالجة المركزية (CPUs) المحددة بواسطة cpus. يجب أن يكون cpu_size حجم cpus (راجع CPU_SET(3)). إذا كان cpus فارغًا (NULL)، فسيتم تجاهل cpu_size وسيتم استدعاء callback() لجميع الأحداث على جميع وحدات المعالجة المركزية في ملف التتبع. يتم تمرير callback_data إلى callback() كمعاملها الأخير. يمكن أن تكون callback فارغة (NULL)، وهو أمر مفيد إذا تم استخدام tracecmd_follow_event()، ولكن لاحظ أنه إذا كانت callback فارغة (NULL)، فسيتم تجاهل callback_data ولن يتم إرسالها إلى callback الخاصة بـ tracecmd_follow_event().

الدالة tracecmd_iterate_events_multi() مشابهة لـ tracecmd_iterate_events() باستثناء أنها تسمح بالتنقل عبر أكثر من ملف تتبع واحد. إذا تم استخدام tracecmd agent(1) للحصول على ملف تتبع لكل من المضيف والضيف، فتأكد من أن ملف تتبع المضيف هو الإدخال الأول في handles وستقوم tracecmd_iterate_events_multi() بمزامنة البيانات الوصفية لملفات الضيف التي تأتي لاحقًا في handles. handles هي مصفوفة من واصفات ملفات التتبع التي تم فتحها بواسطة tracecmd_open(3) وأخواتها. لاحظ، بخلاف tracecmd_iterate_events()، فإن tracecmd_iterate_events_multi() لا تقوم بالتصفية حسب وحدات المعالجة المركزية، لأن ذلك سيجعل الواجهة برمجة التطبيقات معقدة للغاية لمعرفة الواجهة التي يجب تصفية وحدات المعالجة المركزية عليها. إذا كان ترشيح وحدة المعالجة المركزية مطلوبًا، فيجب على callback التحقق من record→cpu وتُرجع 0 إذا لم تكن وحدة المعالجة المركزية المطلوبة للمعالجة. يشير nr_handles إلى عدد العناصر في handles. يتم تمرير callback_data إلى callback كمعاملها الأخير. يمكن أن تكون callback فارغة (NULL)، وهو أمر مفيد إذا تم استخدام tracecmd_follow_event()، ولكن لاحظ أنه إذا كانت callback فارغة (NULL)، فسيتم تجاهل callback_data ولن يتم إرسالها إلى callback الخاصة بـ tracecmd_follow_event().

تعمل الدالة tracecmd_iterate_events_reverse() بنفس طريقة عمل tracecmd_iterate_events() تقريبًا، ولكن بدلاً من استدعاء الدالة callback() لكل حدث بترتيب الطابع الزمني، ستقوم باستدعاء الدالة callback() لكل حدث بترتيب عكسي للطابع الزمني. إذا كان cont خاطئًا (false)، فستبدأ باستدعاء الحدث الذي يحتوي على أقدم طابع زمني في ملف trace.dat. إذا تم تعيين cont على صحيح (true)، فستبدأ حيثما كان الموضع الحالي لبيانات التتبع. على سبيل المثال، إذا أعادت callback() شيئًا بخلاف الصفر، فستخرج من التكرار. إذا تم استدعاء tracecmd_iterate_events_reverse() مرة أخرى مع cont صحيحًا (true)، فستستمر من حيث توقفت. إذا كان cont خاطئًا (false)، فستبدأ مرة أخرى عند الحدث ذي أقدم طابع زمني. تعمل handle، cpus، cpu_size، و callback_data بنفس طريقة عمل tracecmd_iterate_events().

نموذج الدالة callback() لكل من tracecmd_iterate_events() و tracecmd_iterate_events_reverse() و tracecmd_iterate_events_multi() هو:

int callback()(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data);

handle هو نفس handle الذي تم تمريره إلى tracecmd_iterate_events() أو الواجهة الحالية لـ handles التي تم تمريرها إلى tracecmd_iterate_events_multi() والتي ينتمي إليها record. record هو سجل الحدث الحالي. cpu هي وحدة المعالجة المركزية الحالية التي تتم معالجتها. لاحظ، بالنسبة لـ tracecmd_iterate_events_multi()، قد لا تكون وحدة المعالجة المركزية الفعلية للملف، ولكنها وحدة المعالجة المركزية رقم n لجميع handles مجمعة معًا. استخدم record→cpu للحصول على وحدة المعالجة المركزية الفعلية التي يوجد عليها الحدث.

تقوم الدالة tracecmd_follow_event() بالارتباط بوصفة ملف تتبع handle واستدعاء callback عند تطابق الحدث الموصوف بواسطة system و name مع حدث في تكرار tracecmd_iterate_events() أو tracecmd_iterate_events_multi(). لاحظ، cpu هي وحدة المعالجة المركزية رقم n لكل من tracecmd_iterate_events() و tracecmd_iterate_events_multi(). إذا كانت وحدة المعالجة المركزية الفعلية لـ record مطلوبة، استخدم record→cpu. بالنسبة لـ tracecmd_iterate_events_multi()، يتم استدعاء callback فقط إذا تطابق handle مع واصف ملف التتبع الحالي ضمن handles. يتم تمرير callback_data كمعامل أخير إلى الدالة callback(). لاحظ، سيتم استدعاء هذه الدالة callback() قبل الدالة callback() الخاصة بـ tracecmd_iterate_events() أو tracecmd_iterate_events_multi().

نموذج الدالة callback() لـ *tracecmd_follow_event()* هو:

int callback()(struct tracecmd_input *handle, struct tep_event *event, struct tep_record *_record, int cpu, void *data);

تقوم الدالة tracecmd_follow_missed_events() بالارتباط بوصفة ملف تتبع handle واستدعاء callback عند اكتشاف أحداث مفقودة. سيحتوي event على نوع الحدث الذي يمثله record. سيحتوي record على معلومات الأحداث المفقودة. cpu هي وحدة المعالجة المركزية رقم n لكل من tracecmd_iterate_events() و tracecmd_iterate_events_multi(). إذا كانت وحدة المعالجة المركزية التي تخص الأحداث المفقودة مطلوبة، فاستخدم record→cpu. إذا كان record→missed_events رقمًا موجبًا، فهو يمثل عدد الأحداث المفقودة منذ الحدث الأخير على وحدة المعالجة المركزية الخاصة به، وإلا فسيكون سالبًا، وسيعني ذلك أن عدد الأحداث المفقودة غير معروف ولكنه موجود منذ الحدث الأخير على وحدة المعالجة المركزية. callback و callback_data بنفس تنسيق tracecmd_follow_event() أعلاه. الأحداث المفقودة

NAME

tracecmd iterate events, tracecmd_iterate_events_reverse, tracecmd_iterate_events_multi, tracecmd_filter_add, tracecmd_iterate_reset - iterate through trace events

SYNOPSIS

#include <trace-cmd.h>
int tracecmd_iterate_events(struct tracecmd_input *handle,
                          cpu_set_t *cpuset, size_t cpusize,
                          int (*callback)(struct tracecmd_input *handle,
                                          struct tep_record *record, int cpu,
                                          void *data),
                          void *data);
int tracecmd_iterate_events_reverse(struct tracecmd_input *handle,
                                  cpu_set_t *cpuset, size_t cpusize,
                                  int (*callback)(struct tracecmd_input *handle,
                                                  struct tep_record *record, int cpu,
                                                  void *data),
                                  void *data);
int tracecmd_iterate_events_multi(struct tracecmd_input **handles,
                                size_t nr_handles,
                                int (*callback)(struct tracecmd_input *handle,
                                                struct tep_event *event,
                                                struct tep_record *record, int cpu,
                                                void *data),
                                void *data);
struct tracecmd_input *tracecmd_filter_add(struct tracecmd_input *handle,
                                       const char *filter_str, bool neg);
int tracecmd_iterate_reset(struct tracecmd_input *handle);

DESCRIPTION

The tracecmd_iterate_events function iterates through the events of the trace buffer specified by handle. It takes a cpuset and cpusize to specify which CPUs to iterate over. If cpuset is NULL, it iterates over all CPUs.

The callback function is called for each event. The callback function receives the handle, the record of the event, the cpu it occurred on, and the data pointer passed to tracecmd_iterate_events.

If the callback returns a non-zero value, the iteration stops.

The tracecmd_iterate_events_reverse function does the same as tracecmd_iterate_events but iterates in reverse order.

The tracecmd_iterate_events_multi function iterates through multiple trace buffers specified by the handles array. The callback function for this function receives an additional argument event which is a pointer to the tep_event structure.

The tracecmd_filter_add function adds a filter to the handle. The filter_str specifies the filter in a format defined by tep_filter_add_filter_str(3). If neg is true, the events matching the filter are skipped, otherwise, events matching the filter will cause the callback() function to be executed.

The tracecmd_iterate_reset function resets the handle to the beginning, so the next call to tracecmd_iterate_events will start from the first event.

The callback is called before any of the other callbacks and any filters that were added by tracecmd_filter_add() are ignored. If callback returns a non zero, it will stop the iterator before it calls any of the other iterator callbacks for the given record.

The tracecmd_filter_add() function, adds a filter to handle that affects both tracecmd_iterate_events() and tracecmd_iterate_events_multi(). The filter_str is a character string defining a filter in a format that is defined by tep_filter_add_filter_str(3). If neg is true, then the events that match the filter will be skipped, otherwise the events that match will execute the callback() function in the iterators.

The tracecmd_iterate_reset() sets the handle back to start at the beginning, so that the next call to tracecmd_iterate_events() starts back at the first event again, instead of continuing where it left off.

RETURN VALUE

Both tracecmd_iterate_events(), tracecmd_iterate_events_reverse() and tracecmd_iterate_events_multi() return zero if they successfully iterated all events (handling the follow and filters appropriately). Or an error value, which can include returning a non-zero result from the callback() function.

tracecmd_iterate_reset returns 0 on success and -1 if an error occurred. Note, if -1 is returned, a partial reset may have also happened.

EXAMPLE

#define _GNU_SOURCE
#include <sched.h>
#include <stdlib.h>
#include <getopt.h>
#include <trace-cmd.h>
struct private_data {
        int             cpu;
        const char      *file;
};
static int print_events(struct tracecmd_input *handle, struct tep_record *record, int cpu, void *data)
{
        static struct trace_seq seq;
        struct tep_handle *tep = tracecmd_get_tep(handle);
        struct private_data *pdata = tracecmd_get_private(handle);
        /* For multi handles we need this */
        if (pdata->cpu >= 0 && pdata->cpu != record->cpu)
                return 0;
        if (!seq.buffer)
                trace_seq_init(&seq);
        trace_seq_reset(&seq);
        trace_seq_printf(&seq, "%s: ", pdata->file);
        trace_seq_printf(&seq, "%6.1000d [%03d] %s-%d %s: %s\n",
                        TEP_PRINT_TIME, TEP_PRINT_CPU, TEP_PRINT_COMM, TEP_PRINT_PID,
                        TEP_PRINT_NAME, TEP_PRINT_INFO);
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
        return 0;
}
static int print_event(struct tracecmd_input *handle, struct tep_event *event,
                       struct tep_record *record, int cpu, void *data)
{
        return print_events(handle, record, cpu, data);
}
static int missed_events(struct tracecmd_input *handle, struct tep_event *event,
                         struct tep_record *record, int cpu, void *data)
{
        if (record->missed_events > 0)
                printf("CPU [%03d] has %d missed events\n",
                         record->cpu, record->missed_events);
        else
                printf("CPU [%03d] has missed events\n", record->cpu);
        return 0;
}
static void usage(const char *argv0)
{
        printf("usage: [-c cpu][-f filter][-e event] %s trace.dat [trace.dat ...]\n",
               argv0);
        exit(-1);
}
int main(int argc, char **argv)
{
        struct tracecmd_input **handles = NULL;
        const char *filter_str = NULL;
        const char *argv0 = argv[0];
        struct private_data *priv;
        cpu_set_t *cpuset = NULL;
        char *event = NULL;
        size_t cpusize = 0;
        int nr_handles = 0;
        int cpu = -1;
        int i;
        int c;
        while ((c = getopt(argc, argv, "c:f:e:")) >= 0) {
                switch (c) {
                case 'c':
                        /* filter all trace data to this one CPU. */
                        cpu = atoi(optarg);
                        break;
                case 'f':
                        filter_str = optarg;
                        break;
                case 'e':
                        event = optarg;
                        break;
                default:
                        usage(argv0);
                }
        }
        argc -= optind;
        argv += optind;
        if (argc == 0)
                usage(argv0);
        for (i = 0; i < argc; i++) {
                handles = realloc(handles, sizeof(*handles) * (nr_handles + 1));
                if (!handles)
                        exit(-1);
                handles[nr_handles] = tracecmd_open(argv[i], 0);
                if (!handles[nr_handles]) {
                        perror(argv[i]);
                        exit(-1);
                }
                if (filter_str) {
                        if (tracecmd_filter_add(handles[nr_handles], filter_str, false) == NULL) {
                                perror("adding filter");
                                exit(-1);
                        }
                }
                priv = calloc(1, sizeof(*priv));
                if (!priv)
                        exit(-1);
                priv->file = argv[i];
                priv->cpu = cpu;
                tracecmd_set_private(handles[nr_handles], priv);
                if (event) {
                        if (tracecmd_follow_event(handles[nr_handles], NULL, event, print_event, NULL) < 0) {
                                printf("Could not follow event %s for file %s\n", event, argv[i]);
                                exit(-1);
                        }
                }
                tracecmd_follow_missed_events(handles[nr_handles], missed_events, NULL);
                nr_handles++;
        }
        /* Shortcut */
        if (nr_handles == 1) {
                if (cpu >= 0) {
                        cpuset = CPU_ALLOC(cpu + 1);
                        if (!cpuset)
                                exit(-1);
                        cpusize = CPU_ALLOC_SIZE(cpu + 1);
                        CPU_SET_S(cpu, cpusize, cpuset);
                }
                if (event)
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, NULL, NULL);
                else
                        tracecmd_iterate_events(handles[0], cpuset, cpusize, print_events, NULL);
        } else {
                if (event)
                        tracecmd_iterate_events_multi(handles, nr_handles, NULL, NULL);
                else
                        tracecmd_iterate_events_multi(handles, nr_handles, print_events, NULL);
        }
        for (i = 0; i < nr_handles; i++) {
                priv = tracecmd_get_private(handles[i]);
                free(priv);
                tracecmd_close(handles[i]);
        }
        free(handles);
}
