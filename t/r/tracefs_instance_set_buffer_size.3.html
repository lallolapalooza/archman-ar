tracefs_instance_set_buffer_size(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_instance_get_name, tracefs_instance_get_trace_dir, tracefs_instances_walk, tracefs_instance_exists, tracefs_instance_get_buffer_size, tracefs_instance_set_buffer_size, tracefs_instance_get_buffer_percent, tracefs_instance_set_buffer_percent - وظائف مساعدة للتعامل مع مثيلات التتبع.

الملخص

#include <tracefs.h>
const char *tracefs_instance_get_name(struct tracefs_instance *instance);
const char *tracefs_instance_get_trace_dir(struct tracefs_instance *instance);
int tracefs_instances_walk(int (*callback)(const char *, void *), void *context);
bool tracefs_instance_exists(const char *name);
size_t tracefs_instance_get_buffer_size(struct tracefs_instance *instance, int cpu);
int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size, int cpu);
int tracefs_instance_get_buffer_percent(struct tracefs_instance *instance);
int tracefs_instance_set_buffer_percent(struct tracefs_instance *instance, int val);

الوصف

وظائف مساعدة للتعامل مع مثيلات التتبع.

تقوم الدالة tracefs_instance_get_name() بإرجاع اسم instance المعطى. لاحظ أن المثيل العلوي ليس له اسم، وتعيد الدالة NULL له.

تقوم الدالة tracefs_instance_get_trace_dir() بإرجاع دليل التتبع، حيث يتم تكوين instance المعطى.

تقوم الدالة tracefs_instances_walk() بالتنقل عبر جميع مثيلات التتبع المهيأة في النظام واستدعاء callback لكل واحد منها. يتم تمرير الوسيط context إلى callback، جنبًا إلى جنب مع اسم المثيل. إذا أعادت callback قيمة غير صفرية، تتوقف العملية. ملاحظة، لا يتم استدعاء callback للمثيل العلوي.

تتحقق الدالة tracefs_instance_exists() مما إذا كان مثيل بالاسم name المعطى موجودًا في النظام.

تعيد الدالة tracefs_instace_get_buffer_size() حجم المخزن المؤقت الدائري. إذا كان cpu سالبًا، فإنها تعيد الحجم الإجمالي لجميع المخازن المؤقتة الدائرية لكل وحدة معالجة مركزية، وإلا فإنها تعيد حجم المخزن المؤقت الدائري لكل وحدة معالجة مركزية لـ cpu.

تقوم الدالة tracefs_instance_set_buffer_size() بتعيين حجم المخزن المؤقت الدائري. إذا كان cpu سالبًا، فإنها تعين جميع المخازن المؤقتة الدائرية لكل وحدة معالجة مركزية إلى size (لاحظ أن الحجم الإجمالي هو عدد وحدات المعالجة المركزية * size). إذا تم تحديد cpu، فإنها تعين فقط حجم المخزن المؤقت الدائري لكل وحدة معالجة مركزية.

تقوم الدالة tracefs_instance_set_buffer_percent() بتعيين قيمة النسبة المئوية للمخزن المؤقت لمخزن التتبع الدائري لـ instance أو المخزن المؤقت للمستوى الأعلى إذا كان instance هو NULL. تحدد النسبة المئوية للمخزن المؤقت متى سيتم حظر القراء على tracefs_cpu_read(3)، tracefs_cpu_buffered_read(3)، tracefs_cpu_write(3) و tracefs_cpu_pipe(3) عند عدم تعيين O_NONBLOCK. يجب أن تكون قيمة val بين 0 و 100، حيث:

  0   - حظر حتى توجد أي بيانات في المخزن المؤقت الدائري
  1   - حظر حتى يتم ملء 1٪ من المخازن المؤقتة الفرعية للمخزن المؤقت الدائري
  50  - حظر حتى يتم ملء 50٪ من المخازن المؤقتة الفرعية للمخزن المؤقت الدائري
  100 - حظر حتى يتم ملء المخزن المؤقت الدائري بالكامل

ملاحظة، يمكن استخدام أي رقم من 0 إلى 100 حيث تكون النسبة المئوية للمخزن المؤقت التي يجب ملؤها قبل إخطار القارئ المحظور بوجود بيانات لاستردادها.

تقوم الدالة tracefs_instance_get_buffer_percent() باسترداد إعداد النسبة المئوية للمخزن المؤقت الحالي لمخزن التتبع الدائري لـ instance أو المخزن المؤقت للمستوى الأعلى إذا كان instance هو NULL.

قيمة الإرجاع

تعيد الدالة tracefs_instance_get_name() سلسلة نصية أو NULL في حالة المثيل العلوي. يجب عدم تحرير السلسلة النصية المعاد إرجاعها.

تعيد الدالة tracefs_instance_get_trace_dir() سلسلة نصية أو NULL في حالة حدوث خطأ. يجب عدم تحرير السلسلة النصية المعاد إرجاعها.

تعيد الدالة tracefs_instances_walk() القيمة 0، إذا تم تكرار جميع المثيلات، 1 إذا تم إيقاف التكرار بواسطة callback، أو -1 في حالة حدوث خطأ.

تعيد الدالة tracefs_instance_exists() القيمة true إذا كان مثيل بالاسم name المعطى موجودًا في النظام أو false بخلاف ذلك.

تعيد الدالة tracefs_instance_get_buffer_size() حجم المخزن المؤقت الدائري اعتمادًا على قيمة cpu التي تم تمريرها، أو -1 عند حدوث خطأ.

تعيد الدالة tracefs_instance_set_buffer_size() القيمة صفر عند النجاح و -1 عند حدوث خطأ.

NAME
tracefs_instance_set_buffer_size - Set the size of the buffer for a tracefs instance
SYNOPSIS

int tracefs_instance_set_buffer_size(struct tracefs_instance *instance, size_t size);
DESCRIPTION

The tracefs_instance_set_buffer_size function sets the size of the buffer for the given tracefs instance. The size is specified in bytes.

The buffer is used to store trace data. The size of the buffer can be increased or decreased as needed. If the buffer is increased, the new space will be filled with zeros. If the buffer is decreased, the data that is no longer in the buffer will be lost.

RETURN VALUE

On success, 0 is returned. On failure, a negative error code is returned.

EXAMPLE

struct tracefs_instance *instance;
int ret;

instance = tracefs_instance_open(NULL);
if (!instance) {
    // Handle error
}

ret = tracefs_instance_set_buffer_size(instance, 4096);
if (ret < 0) {
    // Handle error
}

// ... use the tracefs instance ...

tracefs_instance_close(instance);
FILES

None.
