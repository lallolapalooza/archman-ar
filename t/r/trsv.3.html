CTRSV

الغرض:

!>
!> CTRSV  يحـل أحـد الـمـعادلات الـتـالـيـة:
!>
!>    A*x = b,   أو   A**T*x = b,   أو   A**H*x = b,
!>
!> حيث b و x متجهات بعناصر n، و A مصفوفة مثلثية علوية أو سفلية، موحدة أو غير موحدة، بحجم n×n.
!>
!> لا يتضمن هذا الروتين اختبارًا للانفراد أو القرب من الانفراد. يجب إجراء مثل هذه الاختبارات قبل استدعاء هذا الروتين.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>           عند الإدخال، يحدد UPLO ما إذا كانت المصفوفة مصفوفة مثلثية علوية أو سفلية على النحو التالي:
!>
!>              UPLO = 'U' أو 'u'   A هي مصفوفة مثلثية علوية.
!>
!>              UPLO = 'L' أو 'l'   A هي مصفوفة مثلثية سفلية.
!>

TRANS

!>          TRANS هو CHARACTER*1
!>           عند الإدخال، يحدد TRANS المعادلات التي سيتم حلها على النحو التالي:
!>
!>              TRANS = 'N' أو 'n'   A*x = b.
!>
!>              TRANS = 'T' أو 't'   A**T*x = b.
!>
!>              TRANS = 'C' أو 'c'   A**H*x = b.
!>

DIAG

!>          DIAG هو CHARACTER*1
!>           عند الإدخال، يحدد DIAG ما إذا كانت A موحدة مثلثية أم لا على النحو التالي:
!>
!>              DIAG = 'U' أو 'u'   يفترض أن A موحدة مثلثية.
!>
!>              DIAG = 'N' أو 'n'   لا يفترض أن A موحدة مثلثية.
!>

N

!>          N هو INTEGER
!>           عند الإدخال، يحدد N رتبة المصفوفة A.
!>           يجب أن يكون N على الأقل صفر.
!>

A

!>          A هو مصفوفة COMPLEX، بحجم ( LDA, N )
!>           قبل الإدخال مع UPLO = 'U' أو 'u'، يجب أن يحتوي الجزء العلوي المثلثي بحجم n×n في المصفوفة A على المصفوفة المثلثية العلوية، ولا يتم الرجوع إلى الجزء السفلي المثلثي الصارم من A.
!>           قبل الإدخال مع UPLO = 'L' أو 'l'، يجب أن يحتوي الجزء السفلي المثلثي بحجم n×n في المصفوفة A على المصفوفة المثلثية السفلية، ولا يتم الرجوع إلى الجزء العلوي المثلثي الصارم من A.
!>           لاحظ أنه عندما يكون DIAG = 'U' أو 'u'، لا يتم الرجوع إلى عناصر القطر في A أيضًا، ولكن يفترض أنها تساوي الواحد.
!>

LDA

!>          LDA هو INTEGER
!>           عند الإدخال، يحدد LDA البعد الأول لـ A كما هو معلن في البرنامج (الفرعي) المستدعي. يجب أن يكون LDA على الأقل max( 1, n ).
!>

X

!>          X هي مصفوفة COMPLEX، بحجم لا يقل عن ( 1 + ( n - 1 )*abs( INCX ) ).
!>           قبل الإدخال، يجب أن تحتوي المصفوفة X المتزايدة على متجه الطرف الأيمن b المكون من n عنصر. عند الخروج، يتم الكتابة فوق X بالمتجه الحل x.
!>

INCX

!>          INCX هو INTEGER
!>           عند الإدخال، يحدد INCX الزيادة لعناصر X. يجب ألا يكون INCX صفرًا.
!>

NAME


trsv - solves a triangular system of linear equations






SYNOPSIS


subroutine ctrsv (character uplo, character trans, character diag, integer n,
complex a, dimension(lda,*) a, integer lda, complex x, dimension(*) x, integer incx)
subroutine dtrsv (character uplo, character trans, character diag, integer n,
double precision a, dimension(lda,*) a, integer lda, double precision x,
dimension(*) x, integer incx)
subroutine strsv (character uplo, character trans, character diag, integer n,
real a, dimension(lda,*) a, integer lda, real x, dimension(*) x, integer incx)
subroutine ztrsv (character uplo, character trans, character diag, integer n,
complex*16 a, dimension(lda,*) a, integer lda, complex*16 x,
dimension(*) x, integer incx)







Detailed Description


This subroutine solves a triangular system of linear equations. It is part of the BLAS (Basic Linear Algebra Subprograms) standard, which is used in many numerical libraries.


The general form of the system solved is:


A*x = b, or AT*x = b, or AH*x = b


where:


    
  
  • A is an n x n upper or lower triangular matrix.
    • 
  
  • x and b are n-element vectors.
    • 



The routines differ in the data type they operate on:


    
  
  • ctrsv: single-precision complex numbers
    • 
  
  • dtrsv: double-precision real numbers
    • 
  
  • strsv: single-precision real numbers
    • 
  
  • ztrsv: double-precision complex numbers
    • 



Key parameters for all routines include:


    
  
  • UPLO: Specifies whether A is upper ('U' or 'u') or lower ('L' or 'l') triangular.
    • 
  
  • TRANS: Specifies the equation to solve: 'N' or 'n' for A*x = b, 'T' or 't' for AT*x = b, 'C' or 'c' for AH*x = b (complex versions only).
    • 
  
  • DIAG: Specifies whether A is unit triangular ('U' or 'u') or not ('N' or 'n'). If unit triangular, the diagonal elements are assumed to be 1.
    • 
  
  • N: The order of the matrix A.
    • 
  
  • A: The coefficient matrix (input).
    • 
  
  • LDA: The leading dimension of the array A.
    • 
  
  • X: The right-hand side vector b (input), and the solution vector x (output).
    • 
  
  • INCX: The increment for the elements of X.
    • 



Note that these routines do not check for singularity or near-singularity of the matrix A. Such checks should be performed before calling these routines.

subroutine   ctrsv (character uplo, character trans, character diag, integer n, complex,   dimension(lda,*) a, integer lda, complex, dimension(*) x, integer incx)


CTRSV


Purpose:




!>
!> CTRSV  solves one of the systems of equations
!>
!>    A*x = b,   or   A**T*x = b,
!>
!> where b and x are n element vectors and A is an n by n unit, or
!> non-unit, upper or lower triangular matrix.
!>
!> No test for singularity or near-singularity is included in this
!> routine. Such tests must be performed before calling this routine.
!> 




Parameters


UPLO

!>          UPLO is CHARACTER*1
!>           On entry, UPLO specifies whether the matrix is an upper or
!>           lower triangular matrix as follows:
!>
!>              UPLO = 'U' or 'u'   A is an upper triangular matrix.
!>
!>              UPLO = 'L' or 'l'   A is a lower triangular matrix.
!> 


TRANS


!>          TRANS is CHARACTER*1
!>           On entry, TRANS specifies the equations to be solved as
!>           follows:
!>
!>              TRANS = 'N' or 'n'   A*x = b.
!>
!>              TRANS = 'T' or 't'   A**T*x = b.
!>
!>              TRANS = 'C' or 'c'   A**T*x = b.
!> 


DIAG


!>          DIAG is CHARACTER*1
!>           On entry, DIAG specifies whether or not A is unit
!>           triangular as follows:
!>
!>              DIAG = 'U' or 'u'   A is assumed to be unit triangular.
!>
!>              DIAG = 'N' or 'n'   A is not assumed to be unit
!>                                  triangular.
!> 


N


!>          N is INTEGER
!>           On entry, N specifies the order of the matrix A.
!>           N must be at least zero.
!> 


A


!>          A is COMPLEX array, dimension ( LDA, N )
!>           Before entry with  UPLO = 'U' or 'u', the leading n by n
!>           upper triangular part of the array A must contain the upper
!>           triangular matrix and the strictly lower triangular part of
!>           A is not referenced.
!>           Before entry with UPLO = 'L' or 'l', the leading n by n
!>           lower triangular part of the array A must contain the lower
!>           triangular matrix and the strictly upper triangular part of
!>           A is not referenced.
!>           Note that when  DIAG = 'U' or 'u', the diagonal elements of
!>           A are not referenced either, but are assumed to be unity.
!> 


LDA


!>          LDA is INTEGER
!>           On entry, LDA specifies the first dimension of A as declared
!>           in the calling (sub) program. LDA must be at least
!>           max( 1, n ).
!> 


X


!>          X is COMPLEX array, dimension at least
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           Before entry, the incremented array X must contain the n
!>           element right-hand side vector b. On exit, X is overwritten
!>           with the solution vector x.
!> 


INCX


!>          INCX is INTEGER
!>           On entry, INCX specifies the increment for the elements of
!>           X. INCX must not be zero.
!>
