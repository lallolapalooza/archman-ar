tracefs_tracer_available(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_tracers, tracefs_tracer_available, tracefs_get_clock, tracefs_list_free, tracefs_list_add, tracefs_list_size - وظائف مساعدة للعمل مع نظام ملفات trace.

الملخص

#include <tracefs.h>
char **tracefs_tracers(const char *tracing_dir);
bool tracefs_tracer_available(const char *tracing_dir, const char *tracer);
char *tracefs_get_clock(struct tracefs_instance *instance);
void tracefs_list_free(char **list);
char **tracefs_list_add(char *list, const char *string);
int *tracefs_list_size(char **list);

الوصف

وظائف مفيدة متنوعة للعمل مع نظام ملفات trace.

تقوم الدالة tracefs_tracers() بإرجاع مصفوفة من السلاسل النصية بأسماء المكونات الإضافية للمقتفيات المدعومة، الموجودة في الدليل tracing_dir المحدد. يمكن أن يكون هذا NULL أو موقع نقطة تثبيت tracefs لأنظمة trace للجهاز المحلي، أو قد يكون مسارًا لنسخة من دليل tracefs من جهاز آخر. العنصر الأخير في المصفوفة هو مؤشر NULL. يجب تحرير المصفوفة باستخدام واجهة برمجة التطبيقات tracefs_list_free().

تقوم الدالة tracefs_tracer_available() بإرجاع true إذا كان tracer متاحًا في الدليل tracing_dir_director المحدد، وfalse بخلاف ذلك.

تقوم الدالة tracefs_get_clock() بإرجاع اسم ساعة التتبع الحالية، المستخدمة في instance المحدد. إذا كان instance هو NULL، يتم إرجاع ساعة المثيل الرئيسي لـ trace. يجب تحرير السلسلة النصية المرجعة باستخدام free().

تقوم الدالة tracefs_list_free() بتحرير مصفوفة من السلاسل النصية، التي تم إرجاعها بواسطة واجهات برمجة التطبيقات tracefs_event_systems() وtracefs_system_events() وtracefs_tracers().

تقوم الدالة tracefs_list_add() بإضافة string إلى القائمة النصية list. إذا كان list هو NULL، فسيتم إنشاء قائمة جديدة مع كون العنصر الأول نسخة من string، وسيكون العنصر الثاني مؤشر NULL. إذا لم يكن list NULL، فسيتم إعادة تخصيصه ليشمل عنصرًا جديدًا ومُنهي NULL، وسيتم إرجاع المصفوفة المخصصة الجديدة. يجب تجاهل القائمة الممررة، حيث سيتم تحريرها إذا تم تخصيص واحدة جديدة.

تعتبر tracefs_list_size() طريقة سريعة لمعرفة عدد العناصر في مصفوفة سلاسل نصية سيتم تحريرها باستخدام tracefs_list_free(). لاحظ أن هذا يعتمد على البيانات الوصفية التي تم إنشاؤها لهذه القوائم ولن يعمل على مصفوفات سلاسل نصية عادية مثل argv.

قيمة الإرجاع

تقوم الدالة tracefs_tracers() بإرجاع مصفوفة من السلاسل النصية. العنصر الأخير في تلك المصفوفة هو مؤشر NULL. يجب تحرير المصفوفة باستخدام واجهة برمجة التطبيقات tracefs_list_free(). في حالة حدوث خطأ، يتم إرجاع NULL.

تقوم الدالة tracefs_tracer_available() بإرجاع true إذا كان tracer متاحًا، وfalse بخلاف ذلك.

تقوم الدالة tracefs_get_clock() بإرجاع سلسلة نصية، يجب تحريرها باستخدام free()، أو NULL في حالة حدوث خطأ.

تقوم الدالة tracefs_list_add() بإرجاع مصفوفة سلاسل نصية مخصصة يجب تحريرها باستخدام tracefs_list_free() عند النجاح أو NULL عند الفشل. إذا تم إرجاع NULL، فإن list الممرر لم يتم المساس به. وبالتالي، يجب التعامل مع tracefs_list_add() بشكل مشابه لـ realloc(3).

تقوم الدالة tracefs_list_size() بإرجاع عدد السلاسل النصية في list. يجب أن تكون القائمة الممررة هي القائمة التي سيتم تحريرها باستخدام tracefs_list_free() نظرًا لأن القائمة تحتوي على بيانات وصفية تُستخدم لتحديد الحجم وهذا لا يعمل على أي مصفوفة سلاسل نصية عادية مثل argv.

مثال

#include <tracefs.h>
char **tracers = tracefs_tracers(NULL);
        if (tracers) {
                /* تم الحصول على المكونات الإضافية للمقتفيات من مثيل trace الرئيسي */
                ...
                tracefs_list_free(tracers);
        }
....
char *clock = tracefs_get_clock(NULL);
        if (clock) {
                /* تم الحصول على ساعة trace الحالية لمثيل trace الرئيسي */
                ...
                free(clock);
        }
