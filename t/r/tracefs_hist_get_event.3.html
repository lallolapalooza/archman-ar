الوصف

يتم إنشاء هيستوجرامات الأحداث بواسطة ملف المشغل في دليل الحدث. يمكن أن يكون بناء الجملة معقدًا وصعبًا للحصول عليه بشكل صحيح. هذه الواجهة البرمجية تتعامل مع بناء الجملة، وتسهل إنشاء هيستوجرامات الأحداث والتفاعل معها. انظر https://www.kernel.org/doc/html/latest/trace/histogram.html لمزيد من المعلومات.

tracefs_hist_add_sort_key() سيضيف مفتاحًا للفرز عليه. hist هو واصف الهيستوجرام لإضافة مفتاح الفرز إليه. sort_key هو سلسلة نصية يجب أن تتطابق إما مع مفتاح معرف بالفعل للهيستوجرام، أو قيمة معرفة بالفعل. إذا كان hist يحتوي بالفعل على مفاتيح فرز (تمت إضافتها سابقًا) فإن sort_key الجديد سيكون له أولوية أقل (يكون ثانويًا وما إلى ذلك) عند الفرز.

tracefs_hist_set_sort_key() سيعيد تعيين قائمة المفاتيح للفرز عليها. hist هو واصف الهيستوجرام لإعادة تعيين مفتاح الفرز إليه. sort_key هو سلسلة نصية يجب أن تتطابق إما مع مفتاح معرف بالفعل للهيستوجرام، أو قيمة معرفة بالفعل. يمكن إضافة مفاتيح فرز متعددة للإشارة إلى ترتيب فرز ثانوي، وما إلى ذلك، ولكن يجب أن تتطابق جميع مفاتيح الفرز مع مفتاح أو قيمة موجودة، أو أن تكون TRACEFS_HIST_HITCOUNT. يجب أن يكون المعامل الأخير لـ tracefs_hist_add_sort_key() هو NULL.

tracefs_hist_sort_key_direction() يسمح بتغيير اتجاه مفتاح فرز موجود لـ hist. sort_key هو مفتاح الفرز المراد تغييره، ويمكن أن يكون dir إما TRACEFS_HIST_SORT_ASCENDING أو TRACEFS_HIST_SORT_DESCENDING، لجعل اتجاه الفرز إما تصاعديًا أو تنازليًا على التوالي.

tracefs_hist_add_name() يضيف اسمًا إلى هيستوجرام. يمكن تسمية الهيستوجرام، وإذا تطابق الاسم بين أكثر من حدث واحد، وكانت لديهما مفاتيح متوافقة، فسيتم دمج الهيستوجرامات المتعددة بنفس الاسم في هيستوجرام واحد (يتم عرضه بواسطة ملف الهيستوجرام لأي من الحدثين). hist هو الهيستوجرام المراد تسميته، و name هو الاسم المراد إعطاؤه له.

tracefs_hist_append_filter() ينشئ فلترًا أو يضيف إليه لحدث الهيستوجرام. اعتمادًا على type، سيقوم ببناء سلسلة من الرموز للقوسين أو عبارات المنطق، أو قد يضيف مقارنة لـ field مقابل val بناءً على compare.

إذا كان type هو: TRACEFS_FILTER_COMPARE - انظر أدناه TRACEFS_FILTER_AND - إضافة "&&" إلى الفلتر TRACEFS_FILTER_OR - إضافة "||" إلى الفلتر TRACEFS_FILTER_NOT - إضافة "!" إلى الفلتر TRACEFS_FILTER_OPEN_PAREN - إضافة "(" إلى الفلتر TRACEFS_FILTER_CLOSE_PAREN - إضافة ")" إلى الفلتر

يتم تجاهل field و compare و val ما لم يكن type يساوي TRACEFS_FILTER_COMPARE، ثم سيتم استخدام compare لما يلي:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : حيث field هي سلسلة نصية.

TRACEFS_COMPARE_AND - field & val : حيث field هو حقل علامات.

trace_hist_echo_cmd() يطبع الأوامر اللازمة لإنشاء الهيستوجرام المحدد في instance المحدد، أو NULL للمستوى الأعلى، إلى seq. الأمر الذي يتم طباعته موصوف بواسطة command ويظهر الوظيفة التي سيتم تنفيذها بواسطة tracefs_hist_command(3).

tracefs_hist_command() يتم استدعاؤه لمعالجة أمر على الهيستوجرام hist لحدثه في instance المحدد، أو NULL للمستوى الأعلى. يمكن أن يكون cmd أحد الخيارات التالية:

TRACEFS_HIST_CMD_START أو صفر لبدء تنفيذ الهيستوجرام.

TRACEFS_HIST_CMD_PAUSE لإيقاف الهيستوجرام المحدد مؤقتًا.

TRACEFS_HIST_CMD_CONT لمتابعة هيستوجرام متوقف مؤقتًا.

TRACEFS_HIST_CMD_CLEAR لإعادة تعيين قيم الهيستوجرام.

TRACEFS_HIST_CMD_DESTROY لتدمير الهيستوجرام (التراجع عن START).

الدوال أدناه هي أغلفة لـ tracefs_hist_command() لجعل اصطلاحات الاستدعاء أسهل لفهم ما يحدث.

أنواع المفاتيح

tracefs_hist_alloc_nd() و tracefs_hist_add_key() كلاهما يضيفان مفتاحًا ويتطلبان أن يكون لهذا المفتاح نوع. يمكن أن تكون الأنواع:

TRACEFS_HIST_KEY_NORMAL أو صفر (0) وهو عدم تعديل النوع.

TRACEFS_HIST_KEY_HEX لعرض المفتاح بصيغة سداسية عشرية.

TRACEFS_HIST_KEY_SYM لعرض المفتاح كرمز نواة (إذا تم العثور عليه). إذا كان المفتاح عنوانًا، فهذا مفيد لأنه سيعرض أسماء الوظائف بدلاً من مجرد رقم.

TRACEFS_HIST_KEY_SYM_OFFSET مشابه لـ TRACEFS_HIST_KEY_SYM ولكنه سيشمل أيضًا الإزاحة من الوظيفة لمطابقة العنوان الدقيق.

TRACEFS_HIST_KEY_SYSCALL إذا كان المفتاح هو "معرف" استدعاء النظام (الرقم الذي يتم تمريره من مساحة المستخدم إلى النواة لإبلاغها بنوع استدعاء النظام الذي يتم استدعاؤه)، فسيتم عرض اسم استدعاء النظام.

TRACEFS_HIST_KEY_EXECNAME إذا كان "common_pid" هو المفتاح (معرف العملية الخاصة بالمهمة المنفذة)، فبدلاً من إظهار الرقم، يتم عرض اسم المهمة قيد التشغيل.

TRACEFS_HIST_KEY_LOG سيعرض المفتاح بمقياس لوغاريتمي ثنائي.

TRACEFS_HIST_KEY_USECS للاستخدام مع "common_timestamp" أو TRACEFS_HIST_TIMESTAMP، وفي هذه الحالة، سيعرض الطابع الزمني بالميكروثانية بدلاً من النانوسانية.

قيمة الإرجاع

tracefs_hist_get_name() يُرجع اسم الهيستوجرام أو NULL في حالة حدوث خطأ. السلسلة النصية المرجعة تنتمي إلى كائن الهيستوجرام ويتم تحريرها مع الهيستوجرام بواسطة tracefs_hist_free().

tracefs_hist_get_event() يُرجع اسم حدث الهيستوجرام أو NULL في حالة حدوث خطأ. السلسلة النصية المرجعة تنتمي إلى كائن الهيستوجرام ويتم تحريرها مع الهيستوجرام بواسطة tracefs_hist_free().

tracefs_hist_get_system() يُرجع اسم نظام الهيستوجرام أو NULL في حالة حدوث خطأ. السلسلة النصية المرجعة تنتمي إلى كائن الهيستوجرام ويتم تحريرها مع الهيستوجرام بواسطة tracefs_hist_free().

tracefs_hist_alloc_nd() يُرجع واصف هيستوجرام مخصص يجب تحريره بواسطة tracefs_hist_free() أو NULL في حالة حدوث خطأ.

مثال

#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("فشل في تخصيص المحاور");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else {
                                fprintf(stderr, "سمة غير معرفة '%s'\n", att);
                                fprintf(stderr,"  سمات مقبولة:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "فشل إنشاء المثيل\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("لم يمكن قراءة الأحداث");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("قراءة ملف الهيستوجرام");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "الأمر يحتاج الخيار -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "لا مفاتيح؟؟\n");
                exit(-1);
        }
        /* عرض أمثلة لـ hist1d و hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* حقاً، 1 و 2 يمكنهما استخدام هذا أيضاً */
                hist = tracefs_hist_alloc_nd(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "فشل إنشاء الهيستوجرام");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "فشل في إضافة القيمة %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "فشل في إضافة مفتاح/قيمة فرز %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "فشل في إضافة مفتاح/قيمة تصاعدي %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "فشل في إضافة مفتاح/قيمة تنازلي %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* تم العرض بالفعل */
                break;
        }
        if (ret)
                fprintf(stderr, "فشل: الأمر\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "الاستخدام: %s command [-B instance][-e [system/]event][-k keys][-v vals][-s sort]\n", argv[0]);
                fprintf(stderr, "      [-a ascending][-d descending]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "أمر غير معروف %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}

NAME

tracefs_hist_get_event - الحصول على حدث تاريخي من الأداة

SYNOPSIS

#include <tracefs.h>

int
tracefs_hist_get_event(tracefs_hist_t *hist, const char *event_name);

DESCRIPTION

الدالة tracefs_hist_get_event تقوم بتعيين اسم الحدث المحدد إلى الأداة hist.

KEY TYPES

typedef struct tracefs_hist tracefs_hist_t;

RETURN VALUE

تعيد 0 عند النجاح، أو عددًا سالبًا عند الفشل.

EXAMPLE

#include <tracefs.h>
#include <stdio.h>

int main(void) {
    tracefs_hist_t *hist;
    int ret;

    hist = tracefs_hist_alloc();
    if (!hist) {
        perror("tracefs_hist_alloc");
        return 1;
    }

    ret = tracefs_hist_get_event(hist, "sched_switch");
    if (ret < 0) {
        fprintf(stderr, "Failed to set event: %s\n", strerror(-ret));
        tracefs_hist_free(hist);
        return 1;
    }

    printf("Successfully set event to sched_switch\n");

    tracefs_hist_free(hist);
    return 0;
}

FILES

No files are directly accessed by this function. It interacts with the tracefs filesystem indirectly through the libtracefs library.
