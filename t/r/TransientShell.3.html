NAME

TransientShell - a shell widget that is temporarily displayed

SYNOPSIS

#include <Xm/TransientS.h>

DESCRIPTION

The TransientShell widget is a subclass of the WMShell(3) widget. It is used to create a shell that is temporarily displayed. Transient shells are typically used for dialog boxes, menus, and other temporary pop-up windows.

The TransientShell widget has several resource values that are specific to its behavior:

Name Class Type Default Value Attributes
XmNancestorSensitive XmCSensitive Screen * dynamic CG
XmNsensitive XmCSensitive Boolean True CSG
XmNtranslations XmCTranslations XtTranslations dynamic CSG

XmNx XmCPosition Position 0 CSG
XmNy XmCPosition Position 0 CSG
