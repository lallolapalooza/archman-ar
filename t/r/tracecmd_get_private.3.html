tracecmd_get_private(3)

NAME

tracecmd_get_private - get private data of a trace event

SYNOPSIS

int tracecmd_get_private(struct tracecmd *instance, const char *event_name);

DESCRIPTION

The tracecmd_get_private function retrieves the private data associated with a specific trace event. This function is part of the trace-cmd library, which provides an interface to the kernel's tracepoints.

The instance parameter is a pointer to an initialized struct tracecmd, representing the trace-cmd instance.

The event_name parameter is a string specifying the name of the trace event for which the private data is requested.

The function returns a pointer to the private data if it exists, otherwise it returns NULL. The caller is responsible for managing the memory of the returned data.

RETURN VALUE

Returns a pointer to the private data associated with the trace event, or NULL if the event does not exist or has no private data.

EXAMPLE

This is a conceptual example and might require proper initialization of the tracecmd instance and error handling. 


#include <tracecmd/tracecmd.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    struct tracecmd *instance;
    void *private_data;

    // Initialize tracecmd instance (replace with actual initialization)
    instance = tracecmd_init();
    if (!instance) {
        fprintf(stderr, "Failed to initialize tracecmd\n");
        return 1;
    }

    // Get private data for a specific event (e.g., "sched_switch")
    private_data = tracecmd_get_private(instance, "sched_switch");

    if (private_data) {
        printf("Private data found for sched_switch event.\n");
        // Process private_data here...
        // Note: Memory management of private_data depends on the tracecmd library's implementation.
    } else {
        printf("No private data found for sched_switch event.\n");
    }

    // Clean up tracecmd instance (replace with actual cleanup)
    tracecmd_shutdown(instance);

    return 0;
}
