translate-shell - command-line translator utility

NAME

translate-shell - command-line translator utility

SYNOPSIS

trans [OPTION]... [TEXT]

trans [OPTION]... -i FILE

trans [OPTION]... -input STRING

DESCRIPTION

Translate Shell is an implementation of Gettext that allows you to translate text from any language to any other language using the command line. It supports Google Translate, Microsoft Translator, Yandex Translate, and DeepL translator.

It can be used as an interactive shell, or it can translate single strings or files.

Translate Shell can detect the source language automatically, or you can specify it. It can translate to one or more target languages.

OPTIONS

-t TARGET, --target=TARGET
Specify the target language. For example, -t en for English, -t fr for French, -t ja for Japanese. Multiple target languages can be specified, separated by commas.
-s SOURCE, --source=SOURCE
Specify the source language. For example, -s es for Spanish. If not specified, the source language is detected automatically.
-f FROM, --from=FROM
Alias for -s.
-u URL, --url=URL
Use a custom translation service URL. For example, a local translation server.
-e ENGINE, --engine=ENGINE
Use a specific translation engine. Available engines are: google, bing, yandex, deepl. The default is google.
-id INPUT_DEV, --input-dev=INPUT_DEV
Read input from the specified file descriptor. For example, -id 0 for standard input.
-i FILE, --input-file=FILE
Read input from the specified file.
-input STRING
Translate the given string.
-shell
Start an interactive shell.
-brief
Print only the translated text, without any additional information.
-no-warn
Suppress warning messages.
-verbose
Enable verbose output.
-version
Print version information and exit.
-help
Print help message and exit.

EXIT STATUS

Returns 0 on success, a non-zero value on failure.

ENVIRONMENT

No specific environment variables are used by translate-shell.

FILES

No configuration files are used by translate-shell.
