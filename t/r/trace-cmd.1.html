trace-cmd(1)

الحزمة: trace-cmd

التراخيص: GPL-2.0-only, LGPL-2.1-only

TRACE-CMD(1) دليل libtracefs TRACE-CMD(1)

الاسم

trace-cmd - يتفاعل مع متتبع النواة الداخلي Ftrace Linux

الملخص

trace-cmd الأمر [الخيارات]

الوصف

يتفاعل الأمر trace-cmd(1) مع متتبع Ftrace المضمن في نواة Linux. يتصل بالملفات الخاصة بـ Ftrace الموجودة في نظام ملفات debugfs تحت دليل التتبع (tracing). يجب تحديد الأمر لإخبار trace-cmd بما يجب فعله.

الأوامر

record  - تسجيل تتبع مباشر وكتابة ملف trace.dat إلى
          القرص المحلي أو عبر الشبكة.
set     - تعيين معلمة تكوين ftrace.
report  - يقرأ ملف trace.dat ويحول البيانات الثنائية إلى
          تنسيق نصي ASCII قابل للقراءة.
stream  - بدء التتبع وقراءة المخرجات مباشرة
profile - بدء التنميط وقراءة المخرجات مباشرة
hist    - عرض مخطط بياني للأحداث.
stat    - عرض حالة التتبع (ftrace) للنظام قيد التشغيل
options - سرد خيارات الإضافات المتاحة لـ *report*
start   - بدء التتبع دون التسجيل في ملف trace.dat.
stop    - إيقاف التتبع (فقط تعطيل التسجيل، عبء المتتبع
          لا يزال سارياً)
restart - إعادة تشغيل التتبع من إيقاف سابق (يؤثر فقط على التسجيل)
extract - استخراج البيانات من ذاكرة التخزين المؤقت للنواة وإنشاء ملف trace.dat
          .
show    - عرض محتويات أحد ملفات تتبع نواة Linux Ftrace
reset   - تعطيل كل التتبع وإعادة أداء النظام.
          (يمسح كل البيانات من ذاكرات التخزين المؤقت للنواة)
clear   - مسح محتويات ذاكرات الحلقة Ftrace.
split   - تقسيم ملف trace.dat إلى ملفات أصغر.
list    - سرد الإضافات أو الأحداث المتاحة التي يمكن تسجيلها.
listen  - فتح منفذ للاستماع لاتصالات التتبع عن بعد.
agent   - الاستماع على vsocket لعملاء التتبع
setup-guest - إنشاء FIFOs لتتبع أجهزة VM الضيفة
restore - استعادة ملفات البيانات لتشغيل فاشل لـ trace-cmd record
snapshot- أخذ لقطة من التتبع قيد التشغيل
stack   - تشغيل وعرض متتبع المكدس
check-events - تحليل سلاسل التنسيق لجميع أحداث التتبع وإرجاع
               ما إذا كانت جميع التنسيقات قابلة للتحليل
convert   - تحويل ملفات التتبع
attach   - ربط ملف trace.dat مضيف بملف trace.dat ضيف
dump    - قراءة البيانات الوصفية من ملف التتبع
