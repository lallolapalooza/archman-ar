CTRTRS

الغرض:

!>
!> CTRTRS يحل نظامًا مثلثيًا بالشكل:
!>
!>    A * X = B,  A**T * X = B,  أو  A**H * X = B,
!>
!> حيث A هي مصفوفة مثلثية من الدرجة N، و B هي مصفوفة N × NRHS.
!>
!> تتحقق هذه الروتينية من أن A غير منفردة، ولكن يجب ملاحظة أن عدم الانفرادية الدقيق فقط هو ما يتم اكتشافه. من الممكن أن تكون عناصر قطرية واحدة أو أكثر في A أرقامًا صغيرة جدًا دون أن تشير هذه الروتينية إلى خطأ.
!>
!> إذا كان فقدان الدقة العددية المحتمل بسبب المصفوفات شبه المنفردة مصدر قلق، فيجب على المتصل التحقق من أن A غير منفردة ضمن هامش معين قبل استدعاء هذه الروتينية.
!>

المعاملات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  A مثلثية علوية؛
!>          = 'L':  A مثلثية سفلية.
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد شكل نظام المعادلات:
!>          = 'N':  A * X = B     (بدون تبديل)
!>          = 'T':  A**T * X = B  (تبديل)
!>          = 'C':  A**H * X = B  (تبديل مرافق)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          = 'N':  A مثلثية غير وحدة؛
!>          = 'U':  A مثلثية وحدة.
!>

N

!>          N هو INTEGER
!>          درجة المصفوفة A.  N >= 0.
!>

NRHS

!>          NRHS هو INTEGER
!>          عدد الأطراف اليمنى، أي عدد أعمدة
!>          المصفوفة B.  NRHS >= 0.
!>

A

!>          A هو مصفوفة COMPLEX، الأبعاد (LDA,N)
!>          المصفوفة المثلثية A.  إذا كان UPLO = 'U'، فإن الجزء العلوي المثلثي العلوي الرئيسي N × N
!>          في المصفوفة A يحتوي على المصفوفة المثلثية العلوية، والجزء السفلي المثلثي الصارم
!>          لـ A لا يتم الرجوع إليه.  إذا كان UPLO = 'L'، فإن الجزء السفلي المثلثي الرئيسي N × N
!>          في المصفوفة A يحتوي على المصفوفة المثلثية السفلية، والجزء العلوي المثلثي الصارم
!>          لـ A لا يتم الرجوع إليه.  إذا كان DIAG = 'U'، فإن العناصر القطرية لـ A
!>          لا يتم الرجوع إليها أيضًا ويُفترض أنها 1.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

B

!>          B هو مصفوفة COMPLEX، الأبعاد (LDB,NRHS)
!>          عند الدخول، مصفوفة الطرف الأيمن B.
!>          عند الخروج، إذا كان INFO = 0، مصفوفة الحل X.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرئيسي للمصفوفة B.  LDB >= max(1,N).
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0: إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن العنصر القطري i لـ A هو صفر تمامًا،
!>               مما يشير إلى أن المصفوفة منفردة ولم يتم حساب الحلول
!>               X.
!>

trtrs(3) - LAPACK manual

NAME

trtrs - solves a triangular system of linear equations

SYNOPSIS

    SUBROUTINE STRTRS(UPLO, TRANS, DIAG, N, NRHS, A, LDA, B, LDB, INFO)

    SUBROUTINE DTRTRS(UPLO, TRANS, DIAG, N, NRHS, A, LDA, B, LDB, INFO)

    SUBROUTINE CTRTRS(UPLO, TRANS, DIAG, N, NRHS, A, LDA, B, LDB, INFO)

    SUBROUTINE ZTRTRS(UPLO, TRANS, DIAG, N, NRHS, A, LDA, B, LDB, INFO)

Detailed Description

The routines in the family STRTRS, DTRTRS, CTRTRS, ZTRTRS solve a triangular system of equations of the form:

    A * X = B,  A**T * X = B,  or  A**H * X = B

where A is an N-by-N triangular matrix, A**T is the transpose of A, and A**H is the conjugate transpose of A.

The routines verify that A is nonsingular. Callers should note that only exact singularity is detected. It is conceivable for one or more diagonal elements of A to be subnormally tiny numbers without this routine signalling an error. If a possible loss of numerical precision due to near-singular matrices is a concern, the caller should verify that A is nonsingular within some tolerance before calling this routine.

DTRTRS

Purpose:

!>
!> DTRTRS solves a triangular system of the form
!>
!>    A * X = B,  A**T * X = B,  or  A**H * X = B,
!>
!> where A is a triangular matrix of order N, and B is an N-by-NRHS matrix.
!>
!> This subroutine verifies that A is nonsingular, but callers should note that only exact
!> singularity is detected. It is conceivable for one or more diagonal elements of A to be
!> subnormally tiny numbers without this subroutine signalling an error.
!>
!> If a possible loss of numerical precision due to near-singular matrices is a concern, the
!> caller should verify that A is nonsingular within some tolerance before calling this subroutine.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N':  A * X = B     (No transpose)
!>          = 'T':  A**T * X = B  (Transpose)
!>          = 'C':  A**H * X = B  (Conjugate transpose)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          The triangular matrix A.  If UPLO = 'U', the leading N-by-N
!>          upper triangular part of the array A contains the upper
!>          triangular matrix, and the strictly lower triangular part of
!>          A is not referenced.  If UPLO = 'L', the leading N-by-N lower
!>          triangular part of the array A contains the lower triangular
!>          matrix, and the strictly upper triangular part of A is not
!>          referenced.  If DIAG = 'U', the diagonal elements of A are
!>          also not referenced and are assumed to be 1.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, if INFO = 0, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element of A is exactly zero,
!>               indicating that the matrix is singular and the solutions
!>               X have not been computed.
!>
