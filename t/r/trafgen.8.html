trafgen(8)

الحزمة: netsniff-ng

التراخيص: GPL2

>PAUSE (IEEE 802.3X) : pause(code=<number>, time=<number>)


code - رمز تشغيل MAC Control (الافتراضي: 0x0001)

time - وقت الإيقاف المؤقت (الافتراضي: 0)

بشكل افتراضي، تتم إضافة رأس Ethernet مع الحقول التالية:

نوع Ethernet - 0x8808

عنوان MAC الوجهة - 01:80:C2:00:00:01


PFC : pfc(pri|prio(<number>)=<number>, time(<number>)=<number>)


code - رمز تشغيل MAC Control (الافتراضي: 0x0101)

pri|prio - متجه تمكين الأولوية (الافتراضي: 0)

pri|prio(<number>) - تمكين/تعطيل (0 - تعطيل، 1 - تمكين) الإيقاف المؤقت للأولوية <number> (الافتراضي: 0)

time(<number>) - تعيين وقت الإيقاف المؤقت للأولوية <number> (الافتراضي: 0)

بشكل افتراضي، تتم إضافة رأس Ethernet مع الحقول التالية:

نوع Ethernet - 0x8808

عنوان MAC الوجهة - 01:80:C2:00:00:01


VLAN : vlan(tpid=<number>, id=<number>, dei=<number>, tci=<number>, pcp=<number>, 1q, 1ad)


tpid|prot|proto - معرّف بروتوكول العلامة (TPID) (الافتراضي: 0x8100)

tci - حقل معلومات التحكم بالعلامة (TCI) (معرف VLAN + PCP + DEI) (الافتراضي: 0)

dei|cfi - مؤشر مؤهل للإسقاط (DEI)، سابقًا مؤشر التنسيق القانوني (CFI) (الافتراضي: 0)

pcp - نقطة رمز الأولوية (PCP) (الافتراضي: 0)

id - معرف VLAN (الافتراضي: 0)

1q - تعيين رأس 802.1q (TPID: 0x8100)

1ad - تعيين رأس 802.1ad (TPID: 0x88a8)


بشكل افتراضي، إذا كان الرأس السفلي هو Ethernet، يتم تعيين نوع EtherType الخاص به إلى 0x8100 (802.1q).

MPLS : mpls(label=<number>, tc|exp=<number>, last=<number>, ttl=<number>)


label|lbl - قيمة ملصق MPLS (الافتراضي: 0)

tclass|tc|exp - فئة حركة المرور لحقل QoS (الافتراضي: 0)

last - علامة S لأسفل المكدس (الافتراضي: 1 لمعظم الملصقات الأخيرة)

ttl - الوقت المتبقي للحياة (TTL) (الافتراضي: 0)


بشكل افتراضي، إذا كان الرأس السفلي هو Ethernet، يتم تعيين نوع EtherType الخاص به إلى 0x8847 (MPLS Unicast). يتم تعيين علامة S تلقائيًا إلى 1 للملصق الأخير ويتم إعادة تعيينها إلى 0 إذا تمت إضافة ملصق MPLS السفلي بعد ذلك.

ARP : arp(htype=<number>, ptype=<number>, op=<request|reply|number>, request, reply, smac=<mac>, sip=<ip4_addr>, tmac=<mac>, tip=<ip4_addr>)


htype - نوع الأجهزة لـ ARP (الافتراضي: 1 [Ethernet])

ptype - نوع البروتوكول لـ ARP (الافتراضي: 0x0800 [IPv4])

op - نوع عملية ARP (طلب/رد) (الافتراضي: طلب)

req|request - نوع عملية طلب ARP

reply - نوع عملية رد ARP

smac|sha - عنوان الأجهزة (MAC) للمرسل (الافتراضي: عنوان MAC للجهاز)

sip|spa - عنوان البروتوكول (IPv4) للمرسل (الافتراضي: عنوان IPv4 للجهاز)

tmac|tha - عنوان الأجهزة (MAC) للوجهة (الافتراضي: 00:00:00:00:00:00)

tip|tpa - عنوان البروتوكول (IPv4) للوجهة (الافتراضي: عنوان IPv4 للجهاز)

بشكل افتراضي، يتم تعيين حقل عملية ARP إلى طلب ويتم تعيين عنوان MAC الوجهة لـ Ethernet إلى عنوان البث (ff:ff:ff:ff:ff:ff).

IPv4 : ip4|ipv4(ihl=<number>, ver=<number>, len=<number>, csum=<number>, ttl=<number>, tos=<number>, dscp=<number>, ecn=<number>,
id=<number>, flags=<number>, frag=<number>, df, mf, da=<ip4_addr>, sa=<ip4_addr>, prot[o]=<number>)


ver|version - حقل الإصدار (الافتراضي: 4)

ihl - طول الرأس بعدد كلمات 32 بت (الافتراضي: 5)

tos - حقل نوع الخدمة (ToS) (الافتراضي: 0)

dscp - حقل نقطة رمز الخدمات الممايزة (DSCP، DiffServ) (الافتراضي: 0)

ecn - حقل إشعار الازدحام الصريح (ECN) (الافتراضي: 0)

len|length - الطول الإجمالي للرأس والحمولة (يتم حسابه افتراضيًا)

id - معرف بيانات IPv4 (الافتراضي: 0)

flags - قيمة علامات IPv4 (DF، MF) (الافتراضي: 0)

df - علامة عدم التجزئة (DF) (الافتراضي: 0)

mf - علامة المزيد من الأجزاء (MF) (الافتراضي: 0)

frag - حقل إزاحة الجزء بعدد كتل 8 بايت (الافتراضي: 0)

ttl - حقل الوقت المتبقي للحياة (TTL) (الافتراضي: 0)

csum - مجموع التحقق للرأس (يتم حسابه افتراضيًا)

sa|saddr - عنوان IPv4 المصدر (الافتراضي: عنوان IPv4 للجهاز)

da|daddr - عنوان IPv4 الوجهة (الافتراضي: 0.0.0.0)

prot|proto - رقم بروتوكول IPv4 (الافتراضي: 0)

بشكل افتراضي، إذا كان الرأس السفلي هو Ethernet، يتم تعيين حقل EtherType الخاص به إلى 0x0800 (IPv4). إذا كان الرأس السفلي هو IPv4، يتم تعيين حقل البروتوكول الخاص به إلى 0x4 (IP-in-IP).

IPv6 : ip6|ipv6(ver=<number>, class=<number>, flow=<number> len=<number>, nexthdr=<number>, hoplimit=<number>,
da=<ip6_addr>, sa=<ip6_addr>)


ver|version - حقل الإصدار (الافتراضي: 6)

tc|tclass - فئة حركة المرور (الافتراضي: 0)

fl|flow - تسمية التدفق (الافتراضي: 0)

len|length - طول الحمولة (يتم حسابه افتراضيًا)

nh|nexthdr - نوع الرأس التالي، أي رقم بروتوكول طبقة النقل (الافتراضي: 0)

hl|hoplimit|ttl - حد القفزة، أي وقت الوصول (الافتراضي: 0)

sa|saddr - عنوان IPv6 المصدر (الافتراضي: عنوان IPv6 للجهاز)

da|daddr - عنوان IPv6 الوجهة (الافتراضي: 0:0:0:0:0:0:0:0)

بشكل افتراضي، إذا كان الرأس السفلي هو Ethernet، يتم تعيين حقل EtherType الخاص به إلى 0x86DD (IPv6).

ICMPv4 : icmp4|icmpv4(type=<number>, code=<number>, echorequest, echoreply, csum=<number>, mtu=<number>, seq=<number>, id=<number>, addr=<ip4_addr>)


type - نوع الرسالة (الافتراضي: 0 - رد صدى)

code - الرمز (الافتراضي: 0)

echorequest - طلب صدى (ping) ICMPv4 (النوع: 8، الرمز: 0)

echoreply - رد صدى (ping) ICMPv4 (النوع: 0، الرمز: 0)

csum - مجموع التحقق لرأس ICMPv4 والحمولة (يتم حسابه افتراضيًا)

mtu - حقل MTU للخطوة التالية المستخدم في رسالة "البيانات غير قابلة للتجزئة" (الافتراضي: 0)

seq - رقم التسلسل المستخدم في رسائل الصدى/الطوابع الزمنية/قناع العنوان (الافتراضي: 0)

id - المعرّف المستخدم في رسائل الصدى/الطوابع الزمنية/قناع العنوان (الافتراضي: 0)

addr - عنوان IPv4 المستخدم في رسائل إعادة التوجيه (الافتراضي: 0.0.0.0)


مثال لطلب صدى ICMP (ping):

{ icmpv4(echorequest, seq=1, id=1326) }

ICMPv6 : icmp6|icmpv6(type=<number>, echorequest, echoreply, code=<number>, csum=<number>)


type - نوع الرسالة (الافتراضي: 0)

code - الرمز (الافتراضي: 0)

echorequest - طلب صدى (ping) ICMPv6

echoreply - رد صدى (ping) ICMPv6

csum - مجموع التحقق للرسالة (يتم حسابه افتراضيًا)

بشكل افتراضي، إذا كان الرأس السفلي هو IPv6، يتم تعيين حقل Next Header الخاص به إلى 58 (ICMPv6).

UDP : udp(sp=<number>, dp=<number>, len=<number>, csum=<number>)


sp|sport - المنفذ المصدر (الافتراضي: 0)

dp|dport - المنفذ الوجهة (الافتراضي: 0)

len|length - طول رأس وبيانات UDP (يتم حسابه افتراضيًا)

csum - حقل مجموع التحقق فوق رأس UDP الزائف لـ IPv4 (يتم حسابه افتراضيًا)


بشكل افتراضي، إذا كان الرأس السفلي هو IPv4، يتم تعيين حقل البروتوكول الخاص به إلى 0x11 (UDP).

TCP : tcp(sp=<number>, dp=<number>, seq=<number>, aseq|ackseq=<number>, doff|hlen=<number>, cwr, ece|ecn, urg, ack, psh, rst, syn, fin, win|window=<number>, csum=<number>, urgptr=<number>)


sp|sport - المنفذ المصدر (الافتراضي: 0)

dp|dport - المنفذ الوجهة (الافتراضي: 0)

seq - رقم التسلسل (الافتراضي: 0)

aseq|ackseq - رقم الإقرار (الافتراضي: 0)

doff|hlen - حجم الرأس (إزاحة البيانات) بعدد كلمات 32 بت (الافتراضي: 5)

cwr - علامة تقليل نافذة الازدحام (CWR) (الافتراضي: 0)

ece|ecn - علامة ECN-Echo (ECE) (الافتراضي: 0)

urg - علامة Urgent (الافتراضي: 0)

ack - علامة الإقرار (الافتراضي: 0)

psh - علامة Push (الافتراضي: 0)

rst - علامة Reset (الافتراضي: 0)

syn - علامة Synchronize (الافتراضي: 0)

fin - علامة Finish (الافتراضي: 0)

win|window - حجم نافذة الاستقبال (الافتراضي: 0)

csum - حقل مجموع التحقق فوق رأس TCP الزائف لـ IPv4 (يتم حسابه افتراضيًا)

urgptr - مؤشر Urgent (الافتراضي: 0)


بشكل افتراضي، إذا كان الرأس السفلي هو IPv4، يتم تعيين حقل البروتوكول الخاص به إلى 0x6 (TCP).

مثال بسيط لحزمة UDP Echo:



{
eth(da=11:22:33:44:55:66),
ipv4(daddr=1.2.3.4)
udp(dp=7),
"Hello world"
}

بالإضافة إلى كل هذا، يمكن تمرير التكوين عبر المعالج المسبق لـ C قبل أن يتمكن مترجم trafgen من رؤيته باستخدام الخيار --cpp. لإعطائك لمحة عن مثال أكثر تقدمًا، قم بتشغيل ''trafgen -e''، الحقول معلقة:


/* ملاحظة: العناصر الديناميكية تجعل trafgen أبطأ! */
#include <stddef.h>


{
/* MAC Destination */
fill(0xff, ETH_ALEN),
/* MAC Source */
0x00, 0x02, 0xb3, drnd(3),
/* IPv4 Protocol */
c16(ETH_P_IP),
/* IPv4 Version, IHL, TOS */
0b01000101, 0,
/* IPv4 Total Len */
c1
