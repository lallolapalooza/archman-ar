trace-cmd-snapshot(1)

الحزمة: trace-cmd

التراخيص: GPL-2.0-only, LGPL-2.1-only

TRACE-CMD-SNAPSHOT(1) دليل libtracefs TRACE-CMD-SNAPSHOT(1)

الاسم

trace-cmd-snapshot - أخذ، إعادة تعيين، تحرير، أو عرض لقطة Ftrace لنواة النظام

الملخص

trace-cmd snapshot [خيارات]

الوصف

تتحكم الأداة trace-cmd(1) snapshot أو تعرض ميزة لقطة نواة نظام Ftrace (إذا كانت النواة تدعمها). هذا مفيد لـ "تجميد" نسخة من تتبع مباشر ولكن دون إيقاف التتبع.

 trace-cmd start -p function
 trace-cmd snapshot -s
 trace-cmd snapshot
[ يقوم بتفريغ محتوى المخزن المؤقت عند 'trace-cmd snapshot -s' ]
 trace-cmd snapshot -s
 trace-cmd snapshot
[ يقوم بتفريغ المحتوى الجديد للمخزن المؤقت عند آخر عملية -s ]

الخيارات

-s

أخذ لقطة للمخزن المؤقت الذي يعمل حاليًا.

-r

مسح المخزن المؤقت.

-f

تحرير المخزن المؤقت للقطة. يأخذ المخزن المؤقت مساحة في ذاكرة النواة. من الأفضل تحريره عند عدم استخدامه. العملية الأولى -s ستقوم بتخصيصه إذا لم يكن مخصصًا بالفعل.

-c cpu

العمل على لقطة لكل وحدة معالجة مركزية (قد لا تكون مدعومة بالكامل من قبل جميع النواة)

-B buf

إذا تم إنشاء نسخة من المخزن المؤقت، فإن الخيار -B سيعمل على اللقطة داخل المخزن المؤقت.
