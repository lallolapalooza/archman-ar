DESCRIPTION

A synthetic event is an event that is composed of two other events. It is made up of a start event and an end event. The start event is the event that starts the synthetic event, and the end event is the event that ends the synthetic event.

The synthetic event is created when the start event is seen. The fields from the start event are saved. When the end event is seen, the fields from the end event are saved. The synthetic event is then created and the saved fields are used to populate the synthetic event.

The synthetic event can be used to create new trace events that are not available in the kernel. This can be used to create custom trace events for debugging purposes.

The following functions are used to create and manage synthetic events:

tracefs_synth_alloc() allocates and initializes a synthetic event descriptor.

tracefs_synth_free() frees the memory allocated for a synthetic event descriptor.

tracefs_synth_add_start_field() adds a field from the start event to the synthetic event. The name argument is the name of the field in the start event, and the alias argument is the name of the field in the synthetic event. If alias is NULL, the name of the field in the synthetic event will be the same as the name of the field in the start event.

tracefs_synth_add_end_field() adds a field from the end event to the synthetic event. The name argument is the name of the field in the end event, and the alias argument is the name of the field in the synthetic event. If alias is NULL, the name of the field in the synthetic event will be the same as the name of the field in the end event.

tracefs_synth_add_compare_field() adds a field to the synthetic event that is the difference between two fields from the start and end events. The start_type and end_type arguments specify the type of the fields to be compared. The delta argument specifies how the difference should be calculated. The difference is stored in the synthetic event with the name specified by name in tracefs_synth_add_start_field() or tracefs_synth_add_end_field().

tracefs_synth_append_start_filter() appends a filter to the start event. The filter is used to determine whether the synthetic event should be created. The type argument specifies the type of filter. The field argument is the name of the field to filter on. The op argument is the comparison operator. The value argument is the value to compare against.

tracefs_synth_append_end_filter() appends a filter to the end event.

tracefs_synth_create() creates the synthetic event in the tracefs file system.

tracefs_synth_destroy() destroys the synthetic event.

tracefs_synth_trace() processes a trace record and generates output for the synthetic event.

tracefs_synth_snapshot() generates a snapshot of the synthetic event.

tracefs_synth_save() saves the synthetic event to a file.

tracefs_synth_echo_cmd() prints the command string used to create the synthetic event.

tracefs_synth_get_name() returns the name of the synthetic event.

tracefs_synth_get_event() returns the underlying tep_event structure for the synthetic event.

tracefs_synth_complete() completes the definition of the synthetic event by adding closing parentheses for filters.

tracefs_synth_get_start_hist() returns the histogram associated with the start event of the synthetic event.

tracefs_synth_show_event() prints the definition of the synthetic event to the trace sequence buffer.

tracefs_synth_show_start_hist() prints the definition of the start event histogram to the trace sequence buffer.

tracefs_synth_show_end_hist() prints the definition of the end event histogram to the trace sequence buffer.

tracefs_synth_raw_fmt() formats the output of the synthetic event using a custom format string.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
