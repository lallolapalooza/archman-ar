tracefs_cpu_open_mapped(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

NAME

tracefs_cpu_open_mapped - Open a mapped CPU's trace buffer

SYNOPSIS

#include <tracefs.h>
int tracefs_cpu_open_mapped(struct tracefs_instance *instance, int cpu);

DESCRIPTION

The tracefs_cpu_open_mapped() function opens the trace buffer for the given cpu on the given tracefs instance. This will return a file descriptor to the mapped buffer which can then be read from. If you want to read the trace data without mapping it, use tracefs_cpu_open().

RETURN VALUE

On success, tracefs_cpu_open_mapped() returns a valid file descriptor. On failure, it returns -1 and errno is set appropriately.

EXAMPLE

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
int main(void) {
    struct tracefs_instance *instance;
    int ret;
    int fd;
    int cpu = 0;
    instance = tracefs_open(NULL);
    if (!instance) {
        fprintf(stderr, "Failed to open tracefs\n");
        return 1;
    }
    fd = tracefs_cpu_open_mapped(instance, cpu);
    if (fd < 0) {
        fprintf(stderr, "Failed to open cpu %d trace buffer\n", cpu);
        tracefs_close(instance);
        return 1;
    }
    printf("Opened cpu %d mapped trace buffer with fd %d\n", cpu, fd);
    close(fd);
    tracefs_close(instance);
    return 0;
}

FILES

tracefs instances are typically mounted at /sys/kernel/tracing

الاسم

tracefs_cpu_open_mapped - فتح مخزن مؤقت للتتبع لوحدة المعالجة المركزية (CPU) المعينة

الملخص

#include <tracefs.h>
int tracefs_cpu_open_mapped(struct tracefs_instance *instance, int cpu);

الوصف

تقوم الدالة tracefs_cpu_open_mapped() بفتح المخزن المؤقت للتتبع لوحدة المعالجة المركزية cpu المحددة في مثيل tracefs instance المحدد. سيؤدي هذا إلى إرجاع واصف ملف للمخزن المؤقت المعين والذي يمكن بعد ذلك القراءة منه. إذا كنت ترغب في قراءة بيانات التتبع دون تعيينها، فاستخدم tracefs_cpu_open().

قيمة الإرجاع

عند النجاح، تُرجع tracefs_cpu_open_mapped() واصف ملف صالحًا. عند الفشل، تُرجع -1 ويتم تعيين errno بشكل مناسب.

مثال

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <tracefs.h>
int main(void) {
    struct tracefs_instance *instance;
    int ret;
    int fd;
    int cpu = 0;
    instance = tracefs_open(NULL);
    if (!instance) {
        fprintf(stderr, "Failed to open tracefs\n");
        return 1;
    }
    fd = tracefs_cpu_open_mapped(instance, cpu);
    if (fd < 0) {
        fprintf(stderr, "Failed to open cpu %d trace buffer\n", cpu);
        tracefs_close(instance);
        return 1;
    }
    printf("Opened cpu %d mapped trace buffer with fd %d\n", cpu, fd);
    close(fd);
    tracefs_close(instance);
    return 0;
}
