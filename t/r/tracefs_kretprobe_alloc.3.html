tracefs_kretprobe_alloc(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

الاسم

tracefs_kprobe_alloc, tracefs_kretprobe_alloc, tracefs_kprobe_raw, tracefs_kretprobe_raw, tracefs_kprobe_destroy - تخصيص، الحصول على، إنشاء، وإزالة kprobes

مُلَخَّص

#include <tracefs.h>
struct tracefs_dynevent *
tracefs_kprobe_alloc(const char *system, const char *event,
                       const char *addr, const char *format);
struct tracefs_dynevent *
tracefs_kretprobe_alloc(const char *system, const char *event,
                          const char *addr, const char *format, unsigned int max);
int tracefs_kprobe_raw(const char *system, const char *event,
                         const char *addr, const char *format);
int tracefs_kretprobe_raw(const char *system, const char *event,
                            const char *addr, const char *format);
int tracefs_kprobe_destroy(const char *system, const char *event,
                           const char *addr, const char *format, bool force);

الوصف

tracefs_kprobe_alloc() تقوم بتخصيص سياق kprobe جديد. لم يتم تكوين kprobe في النظام. يمكن إضافة kprobe إلى النظام عن طريق تمرير الواصف المُرجع إلى tracefs_dynevent_create(3). سيتم وضع kprobe الجديد في مجموعة system (أو kprobes إذا كان system NULL) وسيكون له اسم event (أو addr إذا كان event NULL). سيتم إدخال kprobe في addr (اسم الوظيفة، مع أو بدون إزاحة، أو عنوان)، وسيحدد format تنسيق kprobe. راجع ملف توثيق Linux تحت: Documentation/trace/kprobetrace.rst

tracefs_kretprobe_alloc() هي نفسها tracefs_kprobe_alloc، ولكنها تقوم بتخصيص سياق لـ kretprobe. لديها معامل إضافي واحد، وهو اختياري، max - الحد الأقصى للعدد النشط. راجع وصف kretprobes في ملف Documentation/trace/kprobetrace.rst.

tracefs_kprobe_raw() ستنشئ حدث kprobe. إذا كان system NULL، فسيتم استخدام القيمة الافتراضية "kprobes" للمجموعة (نظام الأحداث). خلاف ذلك، إذا تم تحديد system، فسيتم إنشاء kprobe تحت المجموعة بهذا الاسم. event هو اسم حدث kprobe المراد إنشاؤه. يمكن أن يكون addr وظيفة، أو وظيفة وإزاحة، أو عنوان نواة. هذا هو المكان الذي سيتم فيه إدراج موقع kprobe في النواة. format هو تنسيق kprobe كما هو محدد كـ FETCHARGS في مصدر نواة Linux في مستند Documentation/trace/kprobetrace.rst.

tracefs_kretprobe_raw() هي نفسها tracefs_kprobe_raw()، باستثناء أنها تنشئ kretprobe بدلاً من kprobe. يتم وصف الاختلاف أيضًا في مصدر نواة Linux في ملف Documentation/trace/kprobetrace.rst.

tracefs_kprobe_destroy() ستقوم بتدمير kprobe أو kretprobe محدد تم إنشاؤه بواسطة tracefs_kprobe_raw() أو tracefs_kretprobe_raw() بنفس المعلمات.

قيمة الإرجاع

tracefs_kprobe_raw() و tracefs_kretprobe_raw() ترجع 0 عند النجاح، أو -1 عند الخطأ. إذا حدث خطأ في التحليل لـ tracefs_kprobe_raw() أو tracefs_kretprobe_raw()، فيمكن استخدام tracefs_error_last(3) لاسترداد رسالة الخطأ التي تشرح مشكلة التحليل.

تُرجع الواجهات البرمجية tracefs_kprobe_alloc() و tracefs_kretprobe_alloc() مؤشرًا إلى بنية tracefs_dynevent مخصصة، تصف المسبار. يجب تحرير هذا المؤشر بواسطة tracefs_dynevent_free(3). ملاحظة، هذا يخصص واصفًا يمثل kprobe فقط. لا يقوم بتعديل النظام قيد التشغيل.

tracefs_kprobe_destroy() ترجع 0 عند النجاح أو -1 عند الخطأ إذا لم تتمكن من تدمير (أو العثور على) kprobe أو kretprobe بنجاح.

الأخطاء

الأخطاء التالية تنطبق على جميع الاستدعاءات المذكورة أعلاه:

EPERM لم يتم التشغيل كمستخدم جذر

ENODEV لم يتم تكوين أحداث kprobe للنواة قيد التشغيل.

ENOMEM خطأ في تخصيص الذاكرة.

tracefs_kprobe_raw() و tracefs_kretprobe_raw() و tracefs_kprobe_alloc() و tracefs_kretprobe_alloc() يمكن أن تفشل مع الأخطاء التالية:

EBADMSG إذا كان addr NULL.

EINVAL على الأرجح حدث خطأ في التحليل (استخدم tracefs_error_last(3) لرؤية الخطأ المحتمل).

قد تحدث أخطاء أخرى بسبب استدعاءات النظام الداخلية.

                trace_seq_puts(&seq, "open file='");
                tep_print_field(&seq, record->data, file_field);
                trace_seq_puts(&seq, "'\n");
        } else if (event->id == openret_event->id) {
                unsigned long long ret;
                tep_read_number_field(ret_field, record->data, &ret);
                trace_seq_printf(&seq, "open ret=%lld\n", ret);
        } else {
                goto out;
        }
        trace_seq_terminate(&seq);
        trace_seq_do_printf(&seq);
out:
        trace_seq_destroy(&seq);
        return 0;
}
