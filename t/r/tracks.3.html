int LIBMTP_Get_Track_To_File (LIBMTP_mtpdevice_t * device, uint32_t const id, char const *const path, LIBMTP_progressfunc_t const callback, void const *const data)

هذه الوظيفة تحصل على مسار من الجهاز إلى ملف محدد باسم ملف. هذه في الواقع مجرد غلاف للوظيفة LIBMTP_Get_File_To_File().

المعلمات

device مؤشر إلى الجهاز للحصول على المسار منه.
id معرف المسار للمسار المراد استرجاعه.
path اسم ملف لاستخدامه للمسار المسترجع.
callback وظيفة مؤشر تقدم أو NULL للتجاهل.
data مؤشر محدد من قبل المستخدم يتم تمريره إلى وظيفة التقدم من أجل تمرير بعض البيانات المحددة من قبل المستخدم إلى تحديثات التقدم. إذا لم يتم استخدامه، قم بتعيينه إلى NULL.

القيمة المعادة

0 إذا كان النقل ناجحاً، أي قيمة أخرى تعني الفشل.
