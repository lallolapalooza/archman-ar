الوصف

الأحداث الاصطناعية هي أحداث ديناميكية يتم إنشاؤها عن طريق مطابقة حدثين آخرين مما يؤدي إلى تشغيل حدث اصطناعي. أحد الأحداث هو الحدث البادئ الذي يتم فيه تسجيل حقل، وعندما يتم تنفيذ الحدث الثاني، إذا كان لديه حقل (أو حقول) يتطابق مع حقل (أو حقول) الحدث البادئ، فسيؤدي ذلك إلى تشغيل الحدث الاصطناعي. قد يتم تمرير قيم الحقول بخلاف الحقول المتطابقة من الحدث البادئ إلى الحدث النهائي لإجراء عمليات حسابية عليها، أو لمجرد تمريرها كمعلمة للحدث الاصطناعي.

يتمثل أحد حالات الاستخدام الشائعة في تعيين "sched_waking" كحدث بادئ. يتم تشغيل هذا الحدث عند إيقاظ عملية. ثم قم بتعيين "sched_switch" كحدث نهائي. يتم تشغيل هذا الحدث عند جدولة مهمة جديدة على وحدة المعالجة المركزية. عن طريق تعيين "common_pid" لكلا الحدثين كحقول مطابقة، يعتبر الوقت بين الحدثين هو زمن استجابة إيقاظ تلك العملية. استخدم TRACEFS_TIMESTAMP كحقل لكلا الحدثين لحساب الفرق بالنانوثانية، أو استخدم *"TRACEFS_TIMESTAMP_USECS" كحقول مقارنة لكلا الحدثين لحساب الفرق بالميكروثانية. يستخدم هذا كالمثال أدناه.

tracefs_synth_alloc() يقوم بتخصيص وتهيئة حدث اصطناعي. لا يقوم بإنشاء الحدث الاصطناعي، ولكنه يوفر المعلومات الدنيا للقيام بذلك. انظر tracefs_synth_create(3) لكيفية إنشاء الحدث الاصطناعي في النظام. يتطلب معالج tep يمكن إنشاؤه بواسطة tracefs_local_events(3) لمزيد من المعلومات. يحتوي name على اسم الحدث الاصطناعي الذي سيتم إنشاؤه. start_system هو اسم النظام للحدث البادئ. قد يكون NULL وسيتم اختيار أول حدث بالاسم start_event. end_system هو اسم النظام للحدث النهائي. قد يكون NULL وسيتم اختيار أول حدث بالاسم end_event كالحدث النهائي. إذا تم توفير match_name، فسيتم حفظه في الحقل الخاص بالحدث الاصطناعي الذي تم إنشاؤه والذي يحمل المفاتيح المتطابقة لـ start_match_field للحدث البادئ و end_match_field للحدث النهائي. إذا كان match_name NULL، فلن يتم تسجيله في الحدث الاصطناعي الذي تم إنشاؤه.

tracefs_synth_add_match_field() سيضيف مفتاحًا ثانيًا للمطابقة بين الحدث البادئ والحدث النهائي. إذا تم توفير name، فسيتم حفظ محتوى الحقل المطابق بهذا الاسم في الحدث الاصطناعي. start_match_field هو حقل الحدث البادئ للمطابقة مع end_match_field للحدث النهائي.

tracefs_synth_add_compare_field() يستخدم لمقارنة start_compare_field من الحدث البادئ مع end_compare_field من الحدث النهائي. يجب توفير name حتى يتم حفظ النتيجة بواسطة الحدث الاصطناعي. لا معنى لعدم تمرير هذا إلى الحدث الاصطناعي بعد القيام بعمل الحقول المقارنة، حيث أنه لا يخدم أي غرض آخر. يمكن أن يكون المعلم calc أحد:

TRACEFS_SYNTH_DELTA_END - حساب الفرق بين المحتوى في end_compare_field والمحتوى في start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - حساب الفرق بين المحتوى في start_compare_field والمحتوى في end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - إضافة محتوى start_compare_field إلى محتوى end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - يسجل start_field للحدث البادئ بالاسم name في الحدث الاصطناعي. إذا كان name NULL، فسيكون الاسم المستخدم هو نفس start_field.

tracefs_synth_add_end_field() - يسجل end_field للحدث النهائي بالاسم name في الحدث الاصطناعي. إذا كان name NULL، فسيكون الاسم المستخدم هو نفس end_field.

tracefs_synth_append_start_filter() ينشئ مرشحًا أو يلحق به للحدث البادئ. اعتمادًا على type، سيقوم ببناء سلسلة من الرموز للأقواس أو عبارات المنطق، أو قد يضيف مقارنة field مع val بناءً على compare.

إذا كان type: TRACEFS_FILTER_COMPARE - انظر أدناه TRACEFS_FILTER_AND - إضافة "&&" إلى المرشح TRACEFS_FILTER_OR - إضافة "||" إلى المرشح TRACEFS_FILTER_NOT - إضافة "!" إلى المرشح TRACEFS_FILTER_OPEN_PAREN - إضافة "(" إلى المرشح TRACEFS_FILTER_CLOSE_PAREN - إضافة ")" إلى المرشح

يتم تجاهل field و compare و val ما لم يكن type يساوي TRACEFS_FILTER_COMPARE، ثم سيتم استخدام _compare لما يلي:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ ""val"" : حيث field هو سلسلة نصية.

TRACEFS_COMPARE_AND - field & val : حيث field هو حقل علامات.

tracefs_synth_append_end_filter() هو نفس tracefs_synth_append_start_filter ولكنه يقوم بالترشيح على الحدث النهائي.

tracefs_synth_free() يحرر الواصف المخصص الذي تم إرجاعه بواسطة tracefs_synth_alloc().

DESCRIPTION

A synthetic event is a user-defined event that is created from other events. It is useful for measuring latencies or comparing values between two different events. For example, to measure the latency between a task being woken up and it starting to run, you could create a synthetic event that looks for the sched_waking event and then looks for the subsequent sched_switch event for that same task.

The basic structure of a synthetic event is defined by a start event and an end event. These are typically tracepoint events. The library allows you to specify a field to match between the start and end events to ensure they are related (e.g., matching on process ID).

Additional fields can be extracted from either the start or end event, or calculated as a difference between fields in the start and end events. Filters can be applied to the start and end events to only record synthetic events that meet specific criteria.

Once a synthetic event is defined using the various tracefs_synth_* functions, it can be created using tracefs_synth_create(). This will register the synthetic event with the kernel's trace buffer. The synthetic event can then be traced like any other event using tools like trace-cmd or by writing directly to the trace files in /sys/kernel/debug/tracing/events/synthetic/.

The synthetic event can be destroyed using tracefs_synth_destroy() and the allocated memory freed using tracefs_synth_free().

The tracefs_synth_alloc() function is used to allocate and initialize a new synthetic event descriptor. It takes the trace event handle, the name of the synthetic event, the event group (which can be NULL), the name of the starting event, the name of the ending event, the field to match in the starting event, the field to match in the ending event, and the field to use for matching the events.

Use tracefs_synth_add_start_field() and tracefs_synth_add_end_field() to add fields from the start and end events respectively to the synthetic event. The alias parameter allows you to rename the field in the synthetic event.

Use tracefs_synth_add_compare_field() to add a field that is calculated as a difference between a field in the start event and a field in the end event. type can be TRACEFS_TIMESTAMP_USECS, TRACEFS_TIMESTAMP_NS, etc.

Use tracefs_synth_append_start_filter(), tracefs_synth_append_end_filter(), and tracefs_synth_append_filter() to add filters to the synthetic event. Filters are applied to the start event, end event, or both respectively. type can be TRACEFS_FILTER_COMPARE, TRACEFS_FILTER_OR, TRACEFS_FILTER_AND, TRACEFS_FILTER_NOT, TRACEFS_FILTER_OPEN_PAREN, TRACEFS_FILTER_CLOSE_PAREN. The op parameter can be TRACEFS_COMPARE_EQ, TRACEFS_COMPARE_NE, TRACEFS_COMPARE_LT, TRACEFS_COMPARE_LE, TRACEFS_COMPARE_GT, TRACEFS_COMPARE_GE.

The tracefs_synth_echo_cmd() and tracefs_synth_show_event() functions can be used to print the command that would be used to create the synthetic event.

The tracefs_synth_save() function saves the synthetic event definition to a file. The tracefs_synth_snapshot() function takes a snapshot of the current trace buffer for the synthetic event. The tracefs_synth_trace() function traces the synthetic event to a file.

The tracefs_synth_complete() function completes the synthetic event definition, making it ready for creation.

The tracefs_synth_get_event() function retrieves the underlying synthetic event structure. The tracefs_synth_get_start_hist() and tracefs_synth_get_end_hist() functions retrieve the histogram structures associated with the start and end events, respectively.

The tracefs_synth_get_name() function returns the name of the synthetic event.

The tracefs_synth_show_start_hist(), tracefs_synth_show_end_hist(), and tracefs_synth_raw_fmt() functions can be used to print information about the start event histogram, end event histogram, and the raw format of the synthetic event, respectively.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
