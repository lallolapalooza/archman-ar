DESCRIPTION

These functions provide an interface to create and manage synthetic trace events. Synthetic trace events are a way to combine existing trace events into new ones, allowing for more complex analysis and filtering.

The core of this interface is the tracefs_synth structure, which describes a synthetic event. It is initialized using tracefs_synth_alloc.

tracefs_synth_alloc allocates and initializes a new tracefs_synth structure. It takes the following arguments:

  • tep: A pointer to a tep_handle structure, which should be initialized to load trace events from the system.
  • synth_name: The name of the new synthetic event.
  • start_event_name: The name of the event that marks the start of the synthetic event.
  • start_field_name: The name of the field in the start event that will be used for matching or comparison.
  • end_event_name: The name of the event that marks the end of the synthetic event.
  • end_field_name: The name of the field in the end event that will be used for matching or comparison.
  • match_name: The name of the field used to match the start and end events. If this is NULL, the start_field_name and end_field_name will be used for matching.

tracefs_synth_create creates the synthetic event on the system. This makes the synthetic event available for tracing.

tracefs_synth_destroy removes the synthetic event from the system.

tracefs_synth_free frees the memory allocated for the tracefs_synth structure.

The following functions are used to add fields and filters to the synthetic event:

  • tracefs_synth_add_start_field: Adds a field from the start event to the synthetic event. alias can be used to rename the field in the synthetic event.
  • tracefs_synth_add_end_field: Adds a field from the end event to the synthetic event.
  • tracefs_synth_add_compare_field: Adds a field that is the difference between a timestamp in the start event and a timestamp in the end event. alias is the name of the new field.
  • tracefs_synth_append_start_filter: Appends a filter condition to the start event.
  • tracefs_synth_append_end_filter: Appends a filter condition to the end event.

The filter functions take the following arguments:

  • synth: The synthetic event structure.
  • type: The type of filter element (e.g., TRACEFS_FILTER_COMPARE, TRACEFS_FILTER_OR, TRACEFS_FILTER_NOT, TRACEFS_FILTER_OPEN_PAREN, TRACEFS_FILTER_CLOSE_PAREN).
  • field: The name of the field to filter on (for TRACEFS_FILTER_COMPARE).
  • op: The comparison operator (e.g., TRACEFS_COMPARE_LT, TRACEFS_COMPARE_GT, TRACEFS_COMPARE_EQ).
  • value: The value to compare against (for TRACEFS_FILTER_COMPARE).

The following functions are used to display or use the synthetic event configuration:

  • tracefs_synth_echo_cmd: Writes the command string that would be used to create the synthetic event to a trace_seq structure.
  • tracefs_synth_complete: Finalizes the synthetic event definition, adding any necessary closing parentheses for filters.
  • tracefs_synth_trace: Starts tracing the synthetic event.
  • tracefs_synth_snapshot: Takes a snapshot of the synthetic event trace.
  • tracefs_synth_save: Saves the synthetic event trace to a file.
  • tracefs_synth_get_start_hist: Returns a pointer to the histogram structure for the start event.
  • tracefs_synth_get_end_hist: Returns a pointer to the histogram structure for the end event.
  • tracefs_synth_get_name: Returns the name of the synthetic event.
  • tracefs_synth_get_event: Returns the event structure for the start or end event.
  • tracefs_synth_raw_fmt: Writes the raw format string for the synthetic event to a trace_seq structure.
  • tracefs_synth_show_event: Writes a human-readable description of the synthetic event to a trace_seq structure.
  • tracefs_synth_show_start_hist: Writes a human-readable description of the start event's histogram to a trace_seq structure.
  • tracefs_synth_show_end_hist: Writes a human-readable description of the end event's histogram to a trace_seq structure.
  • tracefs_synth_get_filters: Returns the filter configuration of the synthetic event.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}
