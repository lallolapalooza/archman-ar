tracefs_sql(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_sql - إنشاء حدث اصطناعي عبر عبارة SQL

الملخص

#include <tracefs.h>
struct tracefs_synth *tracefs_sql(struct tep_handle *tep, const char *name,
                                        const char *sql_buffer, char **err);

الوصف

الأحداث الاصطناعية هي أحداث تُنشأ ديناميكيًا تربط حدثين موجودين معًا عبر حقل أو أكثر من الحقول المتطابقة بين الحدثين. يمكن استخدامها لإيجاد زمن التأخير بين الحدثين، أو ببساطة لتمرير حقول الحدث الأول إلى الحدث الثاني لعرضها كحدث واحد.

واجهة نواة لينكس لإنشاء الأحداث الاصطناعية معقدة، وهناك حاجة إلى طريقة أفضل لإنشاء الأحداث الاصطناعية تكون سهلة ويمكن فهمها عبر التقنيات الموجودة.

إذا فكرت في كل حدث كجدول، حيث تكون الحقول هي أعمدة الجدول وكل نسخة من الحدث كصف، يمكنك فهم كيف يمكن استخدام SQL لربط حدثين معًا وتكوين حدث آخر (جدول). باستخدام صيغة SQL SELECT FROM JOIN ON [ WHERE ]، يمكن إنشاء حدث اصطناعي بسهولة من حدثين مختلفين.

للاستعلامات البسيطة بـ SQL لإنشاء مدرج تكراري بدلاً من حدث اصطناعي، راجع المدرجات التكرارية أدناه.

تأخذ tracefs_sql() معالج tep (انظر tep_local_events(3)) يُستخدم للتحقق من الأحداث داخل تعبير sql_buffer. name هو اسم الحدث الاصطناعي المراد إنشاؤه. إذا أشار err إلى عنوان سلسلة نصية، فسيتم ملؤها برسالة مفصلة عن أي نوع من أخطاء التحليل، بما في ذلك الحقول التي لا تنتمي إلى حدث، أو إذا لم تتم مقارنة الأحداث أو الحقول بشكل صحيح.

البرنامج النموذجي أدناه هو محلل كامل الوظائف حيث سينشئ حدثًا اصطناعيًا من صيغة SQL تُمرر عبر سطر الأوامر أو ملف.

صيغة SQL هي كما يلي:

SELECT <fields> FROM <start-event> JOIN <end-event> ON <matching-fields> WHERE <filter>

ملاحظة، على الرغم من أن الأمثلة تُظهر أوامر SQL بأحرف كبيرة، إلا أنه ليس مطلوبًا أن تكون كذلك. أي يمكنك استخدام "SELECT" أو "select" أو "sElEct".

على سبيل المثال:

SELECT syscalls.sys_enter_read.fd, syscalls.sys_exit_read.ret FROM syscalls.sys_enter_read
   JOIN syscalls.sys_exit_read
   ON syscalls.sys_enter_read.common_pid = syscalls.sys_exit_write.common_pid

سينشئ حدثًا اصطناعيًا بالحقول:

u64 fd; s64 ret;

لأن الدالة تأخذ معالج tep، وعادةً ما تكون جميع أسماء الأحداث فريدة، يمكنك ترك اسم النظام (المجموعة) للحدث، وستكتشف tracefs_sql() النظام نيابة عنك.

أي أن العبارة أعلاه ستعمل مع:

SELECT sys_enter_read.fd, sys_exit_read.ret FROM sys_enter_read JOIN sys_exit_read
   ON sys_enter_read.common_pid = sys_exit_write.common_pid

يمكن استخدام الكلمة المفتاحية AS لتسمية الحقول وكذلك لإعطاء اسم مستعار للأحداث، بحيث يمكن تبسيط ما سبق أكثر كالتالي:

SELECT start.fd, end.ret FROM sys_enter_read AS start JOIN sys_exit_read AS end ON start.common_pid = end.common_pid

ما سبق يعطي الاسم المستعار sys_enter_read كـ start و sys_exit_read كـ end ويستخدم تلك الأسماء المستعارة للإشارة إلى الحدث في جميع أنحاء العبارة.

استخدام الكلمة المفتاحية AS في جزء التحديد من عبارة SQL سيحدد ما ستُسمى به تلك الحقول في الحدث الاصطناعي.

SELECT start.fd AS filed, end.ret AS return FROM sys_enter_read AS start JOIN sys_exit_read AS end
   ON start.common_pid = end.common_pid

ما سبق يسمي fd الخاص بـ start كـ filed و ret الخاص بـ end كـ return حيث سيكون الحدث الاصطناعي الذي تم إنشاؤه الآن بالحقول:

u64 filed; s64 return;

يمكن أيضًا حساب الحقول وتمرير النتائج إلى الحدث الاصطناعي:

select start.truesize, end.len, (start.truesize - end.len) as diff from napi_gro_receive_entry as start
   JOIN netif_receive_skb as end ON start.skbaddr = end.skbaddr

والذي سيُظهر truesize الخاص بحدث napi_gro_receive_entry، وlen الفعلي للمحتوى، كما يظهره netif_receive_skb، والفرق بين الاثنين معبرًا عنه بالحقل diff.

يدعم الكود أيضًا تسجيل الطوابع الزمنية عند أي من الحدثين، وإجراء حسابات عليها. لتأخير الاستيقاظ، لديك:

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid

ما سبق سينشئ حدثًا اصطناعيًا يسجل pid للمهمة التي يتم إيقاظها، والفرق الزمني بين حدث sched_waking وحدث sched_switch. ستقوم TIMESTAMP_USECS باقتطاع الوقت إلى ميكروثانية حيث أن الطابع الزمني المسجل عادةً في مخزن التتبع له دقة النانوثانية. إذا كنت لا تريد ذلك الاقتطاع، استخدم TIMESTAMP بدلاً من TIMESTAMP_USECS.

لأنه من الشائع جدًا وجود:

   (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS)

يمكن تمثيل ما سبق بـ TIMESTAMP_DELTA_USECS أو إذا كانت النانوثانية مقبولة، يمكنك استخدام TIMESTAMP_DELTA. أي أن التحديد السابق يمكن أيضًا تمثيله بـ:

select start.pid, TIMESTAMP_DELTA_USECS as lat from sched_waking as start JOIN sched_switch as end ON start.pid = end.next_pid

أخيرًا، يمكن إضافة جملة WHERE، والتي ستتيح لك إضافة مرشحات على أي من الحدثين أو كليهما.

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid
   WHERE start.prio < 100 && (!(end.prev_pid < 1 || end.prev_prio > 100) || end.prev_pid == 0)

ملاحظة

على الرغم من أنه يمكن استخدام كلا الحدثين معًا في جملة WHERE، إلا أنه لا يجب خلطهما خارج عبارات "&&" العليا. لا يمكنك استخدام OR (||) لربط الحدثين معًا، حيث يتم ربط مرشح لحدث واحد بـ OR مع مرشح للحدث الآخر. هذا لا معنى له، لأن الحدث الاصطناعي يتطلب حدوث كلا الحدثين ليتم تسجيله. إذا تمت تصفية أحدهما، فلن يُنفذ الحدث الاصطناعي.

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid
   WHERE start.prio < 100 && end.prev_prio < 100

ما سبق صالح.

بينما ما يلي غير صالح.

select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
   JOIN sched_switch as end ON start.pid = end.next_pid
   WHERE start.prio < 100 || end.prev_prio < 100

إذا كانت النواة تدعم ذلك، يمكنك تمرير تتبع مكدس بين الأحداث.

select start.prev_pid as pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as delta, start.STACKTRACE as stack
   FROM sched_switch as start JOIN sched_switch as end ON start.prev_pid = end.next_pid
   WHERE start.prev_state == 2

ما سبق سيسجل تتبع مكدس عندما تكون المهمة في حالة UNINTERRUPTIBLE (محظورة)، ويُفعّل الحدث الاصطناعي عندما يتم جدولتها مرة أخرى، مسجلاً فرق الوقت الذي كانت محظورة فيه. سيسجل تتبع المكدس لمكان وجودها عند جدولتها خارجًا مع الفرق.

الكلمات المفتاحية كحقول أحداث

في بعض الحالات، قد يحتوي الحدث على كلمة مفتاحية. على سبيل المثال، يحتوي regcache_drop_region على "from" كحقل ولن يعمل ما يلي

  select from from regcache_drop_region

في مثل هذه الحالات، أضف شرطة مائلة عكسية إلى الحقل المتعارض، وهذا سيخبر المحلل أن "from" هو حقل وليس كلمة مفتاحية:

  select \from from regcache_drop_region

المدرجات التكرارية

عبارات SQL البسيطة بدون JOIN ON قد يُستخدم أيضًا مما سيُنشئ مدرجًا تكراريًا بدلاً من ذلك. عند القيام بذلك، يمكن استرداد واصف tracefs_hist من واصف الحدث الاصطناعي المُعاد عبر tracefs_synth_get_start_hist(3).

من أجل الاستفادة من أنواع المدرج التكراري (انظر xxx) يمكن استخدام أمر CAST في SQL.

أي:

  select CAST(common_pid AS comm), CAST(id AS syscall) FROM sys_enter

ملاحظة، لا يجوز تحويل حقول النصوص.

الأنواع الممكن التحويل إليها هي:

HEX - تحويل القيمة لاستخدام النظام السادس عشري بدلاً من العشري

SYM - تحويل مؤشر إلى رمزي (قيم kallsyms)

SYM-OFFSET - تحويل مؤشر إلى رمزي مع تضمين الإزاحة.

SYSCALL - تحويل الرقم إلى اسم استدعاء النظام المُعيَّن

EXECNAME أو COMM - يمكن استخدامه فقط مع حقل common_pid. سيعرض اسم المهمة للعملية.

LOG أو LOG2 - تجميع قيم المفتاح في قيم لوغاريتم 2 (1, 2, 3-4, 5-8, 9-16, 17-32, ...)

الحقول أعلاه غير حساسة لحالة الأحرف، و"LOG2" يعمل بنفس جودة "log".

تحويل خاص إلى COUNTER أو COUNTER سيجعل الحقل قيمة وليس مفتاحًا. على سبيل المثال:

  SELECT common_pid, CAST(bytes_req AS _COUNTER_) FROM kmalloc

قيمة الإرجاع

تُرجع 0 عند النجاح و -1 عند الفشل. عند الفشل، إذا تم تعريف err، فسيتم تخصيصه لحمل وصف مفصل لما حدث من خطأ إذا كان الخطأ ناتجًا عن خطأ في التحليل، أو أن حدثًا أو حقلًا غير موجود أو غير متوافق مع ما تم دمجه معه.

إنشاء أداة

المثال أدناه هو برنامج وظيفي يمكن استخدامه لتحليل أوامر SQL إلى أحداث اصطناعية.

   man tracefs_sql | sed -ne '/^EXAMPLE/,/FILES/ { /EXAMPLE/d ; /FILES/d ; p}' > sqlhist.c
   gcc -o sqlhist sqlhist.c `pkg-config --cflags --libs libtracefs`

ثم يمكنك تشغيل الأمثلة أعلاه:

  sudo ./sqlhist 'select start.pid, (end.TIMESTAMP_USECS - start.TIMESTAMP_USECS) as lat from sched_waking as start
                  JOIN sched_switch as end ON start.pid = end.next_pid
                  WHERE start.prio < 100 || end.prev_prio < 100'

مثال

#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
#include <string.h>
#include <errno.h>
#include <unistd.h>
#include <tracefs.h>
static void usage(char **argv)
{
        fprintf(stderr, "usage: %s [-ed][-n name][-s][-S fields][-m var][-c var][-T][-t dir][-f file | sql-command-line]\n"
                "  -n name - name of synthetic event 'Anonymous' if left off\n"
                "  -t dir - use dir instead of /sys/kernel/tracing\n"
                "  -e - execute the commands to create the synthetic event\n"
                "  -m - trigger the action when var is a new max.\n"
                "  -c - trigger the action when var changes.\n"
                "  -s - used with -m or -c to do a snapshot of the tracing buffer\n"
                "  -S - used with -m or -c to save fields of the end event (comma deliminated)\n"
                "  -T - used with -m or -c to do both a snapshot and a trace\n"
                "  -f file - read sql lines from file otherwise from the command line\n"
                "            if file is '-' then read from standard input.\n",
                argv[0]);
        exit(-1);
}
enum action {
        ACTION_DEFAULT          = 0,
        ACTION_SNAPSHOT         = (1 << 0),
        ACTION_TRACE            = (1 << 1),
        ACTION_SAVE             = (1 << 2),
        ACTION_MAX              = (1 << 3),
        ACTION_CHANGE           = (1 << 4),
};
#define ACTIONS ((ACTION_MAX - 1))
static int do_sql(const char *instance_name,
                  const char *buffer, const char *name, const char *var,
                  const char *trace_dir, bool execute, int action,
                  char **save_fields)
{
        struct tracefs_synth *synth;
        struct tep_handle *tep;
        struct trace_seq seq;
        enum tracefs_synth_handler handler;
        char *err;
        int ret;
        if ((action & ACTIONS) && !var) {
                fprintf(stderr, "Error: -s, -S and -T not supported without -m or -c");
                exit(-1);
        }
        if (!name)
                name = "Anonymous";
        trace_seq_init(&seq);
        tep = tracefs_local_events(trace_dir);
        if (!tep) {
                if (!trace_dir)
                        trace_dir = "tracefs directory";
                perror(trace_dir);
                exit(-1);
        }
        synth = tracefs_sql(tep, name, buffer, &err);
        if (!synth) {
                perror("Failed creating synthetic event!");
                if (err)
                        fprintf(stderr, "%s", err);
                free(err);
                exit(-1);
        }
        if (tracefs_synth_complete(synth)) {
                if (var) {
                        if (action & ACTION_MAX)
                                handler = TRACEFS_SYNTH_HANDLE_MAX;
                        else
                                handler = TRACEFS_SYNTH_HANDLE_CHANGE;
                        if (action & ACTION_SAVE) {
                                ret = tracefs_synth_save(synth, handler, var, save_fields);
                                if (ret < 0) {
                                        err = "adding save";
                                        goto failed_action;
                                }
                        }
                        if (action & ACTION_TRACE) {
                                /*
                                 * By doing the trace before snapshot, it will be included
                                 * in the snapshot.
                                 */
                                ret = tracefs_synth_trace(synth, handler, var);
                                if (ret < 0) {
                                        err = "adding trace";
                                        goto failed_action;
                                }
                        }
                        if (action & ACTION_SNAPSHOT) {
                                ret = tracefs_synth_snapshot(synth, handler, var);
                                if (ret < 0) {
                                        err = "adding snapshot";
 failed_action:
                                        perror(err);
                                        if (errno == ENODEV)
                                                fprintf(stderr, "ERROR: '%s' is not a variable\n",
                                                        var);
                                        exit(-1);
                                }
                        }
                }
                tracefs_synth_echo_cmd(&seq, synth);
                if (execute) {
                        ret = tracefs_synth_create(synth);
                        if (ret < 0) {
                                fprintf(stderr, "%s\n", tracefs_error_last(NULL));
                                exit(-1);
                        }
                }
        } else {
                struct tracefs_instance *instance = NULL;
                struct tracefs_hist *hist;
                hist = tracefs_synth_get_start_hist(synth);
                if (!hist) {
                        perror("get_start_hist");
                        exit(-1);
                }
                if (instance_name) {
                        if (execute)
                                instance = tracefs_instance_create(instance_name);
                        else
                                instance = tracefs_instance_alloc(trace_dir,
                                                                  instance_name);
                        if (!instance) {
                                perror("Failed to create instance");
                                exit(-1);
                        }
                }
                tracefs_hist_echo_cmd(&seq, instance, hist, 0);
                if (execute) {
                        ret = tracefs_hist_start(instance, hist);
                        if (ret < 0) {
                                fprintf(stderr, "%s\n", tracefs_error_last(instance));
                                exit(-1);
                        }
                }
        }
        tracefs_synth_free(synth);
        trace_seq_do_printf(&seq);
        trace_seq_destroy(&seq);
        return 0;
}
int main (int argc, char **argv)
{
        char *trace_dir = NULL;
        char *buffer = NULL;
        char buf[BUFSIZ];
        int buffer_size = 0;
        const char *file = NULL;
        const char *instance = NULL;
        bool execute = false;
        char **save_fields = NULL;
        const char *name;
        const char *var;
        int action = 0;
        char *tok;
        FILE *fp;
        size_t r;
        int c;
        int i;
        for (;;) {
                c = getopt(argc, argv, "ht:f:en:m:c:sS:TB:");
                if (c == -1)
                        break;
                switch(c) {
                case 'h':
                        usage(argv);
                case 't':
                        trace_dir = optarg;
                        break;
                case 'f':
                        file = optarg;
                        break;
                case 'e':
                        execute = true;
                        break;
                case 'm':
                        action |= ACTION_MAX;
                        var = optarg;
                        break;
                case 'c':
                        action |= ACTION_CHANGE;
                        var = optarg;
                        break;
                case 's':
                        action |= ACTION_SNAPSHOT;
                        break;
                case 'S':
                        action |= ACTION_SAVE;
                        tok = strtok(optarg, ",");
                        while (tok) {
                                save_fields = tracefs_list_add(save_fields, tok);
                                tok = strtok(NULL, ",");
                        }
                        if (!save_fields) {
                                perror(optarg);
                                exit(-1);
                        }
                        break;
                case 'T':
                        action |= ACTION_TRACE | ACTION_SNAPSHOT;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 'n':
                        name = optarg;
                        break;
                }
        }
        if ((action & (ACTION_MAX|ACTION_CHANGE)) == (ACTION_MAX|ACTION_CHANGE)) {
                fprintf(stderr, "لا يمكن استخدام -m و -c معًا\n");
                exit(-1);
        }
        if (file) {
                if (!strcmp(file, "-"))
                        fp = stdin;
                else
                        fp = fopen(file, "r");
                if (!fp) {
                        perror(file);
                        exit(-1);
                }
                while ((r = fread(buf, 1, BUFSIZ, fp)) > 0) {
                        buffer = realloc(buffer, buffer_size + r + 1);
                        strncpy(buffer + buffer_size, buf, r);
                        buffer_size += r;
                }
                fclose(fp);
                if (buffer_size)
                        buffer[buffer_size] = '\0';
        } else if (argc == optind) {
                usage(argv);
        } else {
                for (i = optind; i < argc; i++) {
                        r = strlen(argv[i]);
                        buffer = realloc(buffer, buffer_size + r + 2);
                        if (i != optind)
                                buffer[buffer_size++] = ' ';
                        strcpy(buffer + buffer_size, argv[i]);
                        buffer_size += r;
                }
        }
        do_sql(instance, buffer, name, var, trace_dir, execute, action, save_fields);
        free(buffer);
        return 0;
}
