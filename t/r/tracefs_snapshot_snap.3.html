NAME

tracefs_snapshot_snap - snapshot a tracefs file

SYNOPSIS

#include <tracefs.h>

int tracefs_snapshot_snap(const char *path);

DESCRIPTION

The tracefs_snapshot_snap function takes a snapshot of the tracefs file specified by path. A snapshot is a copy of the file's current contents, stored in a temporary location. This is useful for capturing the state of tracefs at a specific point in time for later analysis.

RETURN VALUE

On success, tracefs_snapshot_snap returns 0. On failure, it returns -1 and sets errno to indicate the error.

ERRORS

  • EINVAL: The path is not a valid tracefs file.
  • ENOMEM: Not enough memory to create the snapshot.
  • ENOENT: The specified tracefs file does not exist.
  • EACCES: Permission denied to access the tracefs file.

EXAMPLES


#include <stdio.h>
#include <tracefs.h>
#include <errno.h>

int main() {
    const char *trace_file = "/sys/kernel/debug/tracing/trace";
    if (tracefs_snapshot_snap(trace_file) == 0) {
        printf("Snapshot of %s created successfully.\n", trace_file);
    } else {
        perror("Failed to create snapshot");
        return 1;
    }
    return 0;
}

VERSIONS

This function is available in libtracefs version 1.0 and later.

STANDARDS

This is a library function and not a POSIX standard.

AVAILABILITY

The tracefs.h header file and the libtracefs library are part of the Linux kernel source tree. They can also be installed separately using package managers on most Linux distributions.
