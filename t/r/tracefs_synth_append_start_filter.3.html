الوصف

الأحداث الاصطناعية هي أحداث ديناميكية يتم إنشاؤها عن طريق مطابقة حدثين آخرين مما يؤدي إلى تشغيل حدث اصطناعي. أحد الأحداث هو حدث البداية الذي يتم تسجيل حقل فيه، وعند تنفيذ الحدث الثاني، إذا كان يحتوي على حقل (أو حقول) يطابق حقل (أو حقول) حدث البداية، فسيؤدي ذلك إلى تشغيل الحدث الاصطناعي. قد يتم تمرير قيم الحقول بخلاف حقول المطابقة من حدث البداية إلى حدث النهاية لإجراء عمليات حسابية عليها، أو ببساطة لتمريرها كمعامل للحدث الاصطناعي.

أحد حالات الاستخدام الشائعة هو تعيين "sched_waking" كحدث البداية. يتم تشغيل هذا الحدث عند إيقاظ عملية. ثم قم بتعيين "sched_switch" كحدث النهاية. يتم تشغيل هذا الحدث عند جدولة مهمة جديدة على وحدة المعالجة المركزية. عن طريق تعيين "common_pid" لكلا الحدثين كمطابقة للحقول، يعتبر الوقت بين الحدثين هو زمن استجابة إيقاظ تلك العملية. استخدم TRACEFS_TIMESTAMP كحقل لكلا الحدثين لحساب الفرق بالنانوثانية، أو استخدم *TRACEFS_TIMESTAMP_USECS" كحقول مقارنة لكلا الحدثين لحساب الفرق بالميكروثانية. يتم استخدام هذا كمثال أدناه.

tracefs_synth_alloc() تقوم بتخصيص وتهيئة حدث اصطناعي. لا تقوم بإنشاء الحدث الاصطناعي، ولكنها توفر المعلومات الدنيا للقيام بذلك. انظر tracefs_synth_create(3) لكيفية إنشاء الحدث الاصطناعي في النظام. يتطلب معالج tep الذي يمكن إنشاؤه بواسطة tracefs_local_events(3) لمزيد من المعلومات. name يحمل اسم الحدث الاصطناعي الذي سيتم إنشاؤه. start_system هو اسم النظام لحدث البداية. قد يكون NULL وسيتم اختيار الحدث الأول بالاسم start_event. end_system هو اسم النظام لحدث النهاية. قد يكون NULL وسيتم اختيار الحدث الأول بالاسم end_event كحدث النهاية. إذا تم توفير match_name، فسيكون هذا هو الحقل للحدث الاصطناعي الذي تم إنشاؤه والذي يحمل مفاتيح المطابقة لـ start_match_field لحدث البداية و end_match_field لحدث النهاية. إذا كان match_name هو NULL، فلن يتم تسجيله في الحدث الاصطناعي الذي تم إنشاؤه.

tracefs_synth_add_match_field() ستضيف مفتاحًا ثانيًا للمطابقة بين حدث البداية وحدث النهاية. إذا تم توفير name، فسيتم حفظ محتوى حقل المطابقة بهذا name في الحدث الاصطناعي. start_match_field هو حقل حدث البداية للمطابقة مع end_match_field لحدث النهاية.

tracefs_synth_add_compare_field() يستخدم لمقارنة start_compare_field لحدث البداية مع end_compare_field لحدث النهاية. يجب توفير name حتى يتم حفظ النتيجة بواسطة الحدث الاصطناعي. لا معنى لعدم تمرير هذا إلى الحدث الاصطناعي بعد القيام بعمل الحقول المقارنة، لأنه لا يخدم أي غرض آخر. يمكن أن يكون المعامل calc واحدًا مما يلي:

TRACEFS_SYNTH_DELTA_END - احسب الفرق بين المحتوى في end_compare_field والمحتوى في start_compare_field.

name = end_compare_field - start_compare_field

TRACEFS_SYNTH_DELTA_START - احسب الفرق بين المحتوى في start_compare_field والمحتوى في end_compare_field.

name = start_compare_field - end_compare_field

TRACEFS_SYNTH_ADD - أضف محتوى start_compare_field إلى محتوى end_compare_field.

name = start_compare_field + end_compare_field

tracefs_synth_add_start_field() - يسجل start_field لحدث البداية باسم name في الحدث الاصطناعي. إذا كان name هو NULL، فسيكون الاسم المستخدم هو نفس start_field.

tracefs_synth_add_end_field() - يسجل end_field لحدث النهاية باسم name في الحدث الاصطناعي. إذا كان name هو NULL، فسيكون الاسم المستخدم هو نفس end_field.

tracefs_synth_append_start_filter() ينشئ مرشحًا أو يضيف إليه لحدث البداية. اعتمادًا على type، سيبني سلسلة من الرموز للأقواس أو عبارات المنطق، أو قد يضيف مقارنة لـ field مع val بناءً على compare.

إذا كان type هو: TRACEFS_FILTER_COMPARE - انظر أدناه TRACEFS_FILTER_AND - أضف "&&" إلى المرشح TRACEFS_FILTER_OR - أضف "||" إلى المرشح TRACEFS_FILTER_NOT - أضف "!" إلى المرشح TRACEFS_FILTER_OPEN_PAREN - أضف "(" إلى المرشح TRACEFS_FILTER_CLOSE_PAREN - أضف ")" إلى المرشح

يتم تجاهل field و compare و val ما لم يكن type يساوي TRACEFS_FILTER_COMPARE، ثم سيتم استخدام _compare لما يلي:

TRACEFS_COMPARE_EQ - field == val

TRACEFS_COMPARE_NE - field != val

TRACEFS_COMPARE_GT - field > val

TRACEFS_COMPARE_GE - field >= val

TRACEFS_COMPARE_LT - field < val

TRACEFS_COMPARE_LE - field <= val

TRACEFS_COMPARE_RE - field ~ "val" : حيث field هو سلسلة نصية.

TRACEFS_COMPARE_AND - field & val : حيث field هو حقل علامات.

tracefs_synth_append_end_filter() هو نفس tracefs_synth_append_start_filter ولكنه يقوم بالتصفية على حدث النهاية.

tracefs_synth_free() تحرر الواصف المخصص الذي تم إرجاعه بواسطة tracefs_synth_alloc().

DESCRIPTION

A synthetic event is an event that is composed by combining two other events. One event will be the start event and the other one will be the end event. When the start event is detected, it will save the current timestamp and specified fields. When the end event is detected, it will save the current timestamp and specified fields, and then it will create a new event, which contains the saved fields from the start event, the saved fields from the end event and the difference between the end timestamp and the start timestamp.

tracefs_synth_alloc() allocates and initializes a new synthetic event descriptor. The descriptor contains all the information needed to create a synthetic event.

The synthetic event requires a start event and an end event. These events are specified by start_event_name and end_event_name. The start and end events are matched by using the fields start_field_name and end_field_name. The match_name is used to match the start and end events. For example, if both events have a pid field, then match_name can be set to "pid". The start_event_filter and end_event_filter are used to filter events before they are used as start or end events.

tracefs_synth_create() creates the synthetic event in the kernel.

tracefs_synth_destroy() destroys the synthetic event in the kernel.

tracefs_synth_free() frees the synthetic event descriptor. Note that this does not destroy the synthetic event in the kernel.

tracefs_synth_add_start_field() saves a field from the start event. If alias is not NULL, the field will be renamed to alias. Otherwise, it will keep its original name.

tracefs_synth_add_end_field() saves a field from the end event. If alias is not NULL, the field will be renamed to alias. Otherwise, it will keep its original name.

tracefs_synth_add_compare_field() calculates the time difference between the start event and the end event. start_ts and end_ts specify the units of the timestamps to be used for the calculation. op specifies the operation to be performed, which can be TRACEFS_SYNTH_DELTA_END (end timestamp - start timestamp).

tracefs_synth_append_start_filter() appends a filter to the start event. The filter is applied to the fields of the start event.

tracefs_synth_append_end_filter() appends a filter to the end event. The filter is applied to the fields of the end event.

tracefs_synth_append_filter() appends a filter to the synthetic event. The filter can be applied to the fields of the start event, the end event, or the combined event.

tracefs_synth_echo_cmd() prints the command that would be used to create the synthetic event to the trace_seq buffer.

tracefs_synth_sync_create() creates the synthetic event in the kernel synchronously. It waits for the kernel to acknowledge the creation before returning.

tracefs_synth_sync_echo_cmd() prints the command that would be used to create the synthetic event to the trace_seq buffer synchronously.

RETURN VALUE

tracefs_synth_alloc() returns an allocated struct tracefs_synth descriptor on success or NULL on error.

All other functions that return an integer returns zero on success or -1 on error.

ERRORS

The following errors are for all the above calls:

EPERM Not run as root user when required.

EINVAL Either a parameter is not valid (NULL when it should not be) or a field that is not compatible for calculations.

ENODEV An event or one of its fields is not found.

EBADE The fields of the start and end events are not compatible for either matching or comparing.

ENOMEM not enough memory is available.

And more errors may have happened from the system calls to the system.

EXAMPLE

#include <stdlib.h>
#include <tracefs.h>
#define start_event "sched_waking"
#define start_field "pid"
#define end_event "sched_switch"
#define end_field "next_pid"
#define match_name "pid"
static struct tracefs_synth *synth;
static void make_event(void)
{
        struct tep_handle *tep;
        /* Load all events from the system */
        tep = tracefs_local_events(NULL);
        /* Initialize the synthetic event */
        synth = tracefs_synth_alloc(tep, "wakeup_lat",
                                    NULL, start_event,
                                    NULL, end_event,
                                    start_field, end_field,
                                    match_name);
        /* The tep is no longer needed */
        tep_free(tep);
        /* Save the "prio" field as "prio" from the start event */
        tracefs_synth_add_start_field(synth, "prio", NULL);
        /* Save the "next_comm" as "comm" from the end event */
        tracefs_synth_add_end_field(synth, "next_comm", "comm");
        /* Save the "prev_prio" as "prev_prio" from the end event */
        tracefs_synth_add_end_field(synth, "prev_prio", NULL);
        /*
         * Take a microsecond time difference between end and start
         * and record as "delta"
         */
        tracefs_synth_add_compare_field(synth, TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_TIMESTAMP_USECS,
                                        TRACEFS_SYNTH_DELTA_END, "delta");
        /* Only record if start event "prio" is less than 100 */
        tracefs_synth_append_start_filter(synth, TRACEFS_FILTER_COMPARE,
                                          "prio", TRACEFS_COMPARE_LT, "100");
        /*
         * Only record if end event "next_prio" is less than 50
         * or the previous task's prio was not greater than or equal to 100.
         *   next_prio < 50 || !(prev_prio >= 100)
         */
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "next_prio", TRACEFS_COMPARE_LT, "50");
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OR, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_NOT, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_OPEN_PAREN, NULL, 0, NULL);
        tracefs_synth_append_end_filter(synth, TRACEFS_FILTER_COMPARE,
                                        "prev_prio", TRACEFS_COMPARE_GE, "100");
        /*
         * Note, the above only added: "next_prio < 50 || !(prev_prio >= 100"
         * That's because, when the synth is executed, the remaining close parenthesis
         * will be added. That is, the string will end up being:
         * "next_prio < 50 || !(prev_prio >= 100)" when one of tracefs_sync_create()
         * or tracefs_sync_echo_cmd() is run.
         */
}
/* Display how to create the synthetic event */
static void show_event(void)
{
        struct trace_seq s;
        trace_seq_init(&s);
        tracefs_synth_echo_cmd(&s, synth);
        trace_seq_terminate(&s);
        trace_seq_do_printf(&s);
        trace_seq_destroy(&s);
}
int main (int argc, char **argv)
{
        make_event();
        if (argc > 1) {
                if (!strcmp(argv[1], "create")) {
                        /* Create the synthetic event */
                        tracefs_synth_create(synth);
                } else if (!strcmp(argv[1], "delete")) {
                        /* Delete the synthetic event */
                        tracefs_synth_destroy(synth);
                } else {
                        printf("usage: %s [create|delete]\n", argv[0]);
                        exit(-1);
                }
        } else
                show_event();
        tracefs_synth_free(synth);
        return 0;
}

DESCRIPTION

The tracefs file system provides an interface for interacting with the kernel's tracing infrastructure. The functions described here allow for the creation and manipulation of synthetic events and filters.

Synthetic events are events that are not generated by the kernel itself but are created and injected by userspace applications. This can be useful for custom tracing scenarios or for debugging purposes.

Filters are used to select which events should be recorded or processed. They can be based on various criteria such as event name, process ID, user ID, CPU, etc.

RETURN VALUE

On success, these functions return 0. On failure, they return a negative error code.

EXAMPLES

// Example of adding a filter and an event
                int ret;

                ret = tracefs_synth_add_filter("my_filter");
                if (ret < 0) {
                    fprintf(stderr, "Failed to add filter: %d\n", ret);
                    return 1;
                }

                ret = tracefs_synth_set_filter_string("my_filter", "comm=my_process");
                if (ret < 0) {
                    fprintf(stderr, "Failed to set filter string: %d\n", ret);
                    return 1;
                }

                ret = tracefs_synth_add_event("my_event");
                if (ret < 0) {
                    fprintf(stderr, "Failed to add event: %d\n", ret);
                    return 1;
                }

                ret = tracefs_synth_set_event_name("my_event", "MyCustomEvent");
                if (ret < 0) {
                    fprintf(stderr, "Failed to set event name: %d\n", ret);
                    return 1;
                }

                ret = tracefs_synth_set_event_string("my_event", "Some custom data");
                if (ret < 0) {
                    fprintf(stderr, "Failed to set event string: %d\n", ret);
                    return 1;
                }

                ret = tracefs_synth_flush_events();
                if (ret < 0) {
                    fprintf(stderr, "Failed to flush events: %d\n", ret);
                    return 1;
                }
