trace.h(0P) دليل مبرمج POSIX trace.h(0P)

مقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق هذا الواجهة في لينكس (استشر صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة في لينكس.

الاسم

trace.h — تتبع

الملخص

#include <trace.h>

الوصف

سيقوم الرأس <trace.h> بتعريف البنية posix_trace_event_info، والتي يجب أن تشمل على الأقل الأعضاء التالية:

trace_event_id_t  posix_event_id
pid_t             posix_pid
void             *posix_prog_address
pthread_t         posix_thread_id
struct timespec   posix_timestamp
int               posix_truncation_status

سيقوم الرأس <trace.h> بتعريف البنية posix_trace_status_info، والتي يجب أن تشمل على الأقل الأعضاء التالية:

int     posix_stream_full_status
int     posix_stream_overrun_status
int     posix_stream_status
int     posix_log_full_status
int     posix_log_overrun_status
int     posix_stream_flush_error
int     posix_stream_flush_status

سيقوم الرأس <trace.h> بتعريف الثوابت الرمزية التالية:

سيقوم الرأس <trace.h> بتعريف الأنواع size_t، trace_attr_t، trace_event_id_t، trace_event_set_t، و trace_id_t كما هو موضح في <sys/types.h>.
