الوصف

يتم إنشاء رسوم بيانية للأحداث بواسطة ملف المشغل في دليل الحدث. يمكن أن تكون الصيغة معقدة ويصعب الحصول عليها بشكل صحيح. تتعامل واجهة برمجة التطبيقات هذه مع الصيغة، وتسهل إنشاء الرسوم البيانية للأحداث والتفاعل معها. انظر https://www.kernel.org/doc/html/latest/trace/histogram.html لمزيد من المعلومات.

تقوم الدالة tracefs_hist_alloc() بتخصيص واصف "struct tracefs_hist" لرسم بياني أحادي البعد وتعيد عنوانه. يجب تحرير هذا الواصف بواسطة tracefs_hist_free(). tep هو مقبض حدث التتبع (انظر tracefs_local_events(3))، الذي يحتفظ بـ system و event التي سيتم إرفاق الرسم البياني بها. system هو النظام أو مجموعة الحدث. event هو الحدث الذي سيتم إرفاق الرسم البياني به. key هو حقل في الحدث سيتم استخدامه كمفتاح (بعد) للرسم البياني. type هو نوع key. انظر أنواع المفاتيح أدناه.

تقوم الدالة tracefs_hist_alloc_2d() بتخصيص واصف "struct tracefs_hist" لرسم بياني ثنائي الأبعاد وتعيد عنوانه. يجب تحرير هذا الواصف بواسطة tracefs_hist_free(). tep هو مقبض حدث التتبع (انظر tracefs_local_events(3))، الذي يحتفظ بـ system و event التي سيتم إرفاق الرسم البياني بها. system هو النظام أو مجموعة الحدث. event هو الحدث الذي سيتم إرفاق الرسم البياني به. key1 هو الحقل الأول في الحدث الذي سيتم استخدامه كمفتاح (بعد) للرسم البياني. type1 هو نوع key1. انظر أنواع المفاتيح أدناه. key2 هو الحقل الثاني في الحدث الذي سيتم استخدامه كمفتاح (بعد) للرسم البياني. type2 هو نوع key2. انظر أنواع المفاتيح أدناه.

تقوم الدالة tracefs_hist_alloc_nd() بتخصيص واصف "struct tracefs_hist" لرسم بياني N-الأبعاد وتعيد عنوانه. يجب تحرير هذا الواصف بواسطة tracefs_hist_free(). tep هو مقبض حدث التتبع (انظر tracefs_local_events(3))، الذي يحتفظ بـ system و event التي سيتم إرفاق الرسم البياني بها. system هو النظام أو مجموعة الحدث. event هو الحدث الذي سيتم إرفاق الرسم البياني به. axes هو مصفوفة من أزواج key / type، تحدد أبعاد الرسم البياني.

ستقوم الدالة tracefs_hist_alloc_nd_cnt() بتهيئة واصف رسم بياني سيتم إرفاقه بـ system/event. هذا يقوم فقط بتهيئة الواصف بالمفاتيح axes المعطاة كأوليات. هذا يقوم فقط بتهيئة الواصف، ولا يبدأ الرسم البياني في النواة. الفرق بين هذا و tracefs_hist_alloc_nd() هو أن المعلمة axes من نوع struct tracefs_hist_axis_cnt وليست struct tracefs_hist_axis.

تقوم الدالة tracefs_hist_free() بتحرير واصف tracefs_hist. ملاحظة، إنها لا توقف أو تعطل الرسم البياني قيد التشغيل إذا كان قد بدأ. يجب استدعاء tracefs_hist_destroy() للقيام بذلك.

تضيف الدالة tracefs_hist_add_key() مفتاحًا ثانويًا أو ثالثيًا إلى الرسم البياني. المفتاح الذي تم تمريره إلى tracefs_hist_alloc_nd() هو المفتاح الأساسي للرسم البياني. في المرة الأولى التي يتم فيها استدعاء هذه الدالة، ستضيف مفتاحًا ثانويًا (أو رسمًا بيانيًا ثنائي الأبعاد). إذا تم استدعاء هذه الدالة مرة أخرى على نفس الرسم البياني، فستضيف مفتاحًا ثالثيًا (أو رسمًا بيانيًا ثلاثي الأبعاد). المعلمة hist هي واصف الرسم البياني لإضافة key إليه. type هو نوع المفتاح المراد إضافته (انظر أنواع المفاتيح أدناه).

الدالة tracefs_hist_add_key_cnt() هي نفسها الدالة tracefs_hist_add_key() باستثناء أنها تسمح بإضافة عداد للنوع المعطى. حاليًا، هناك فقط نوع buckets الذي يتطلب عدادًا. عند إضافة مفتاح بنوع buckets، فإن tracefs_hist_add_key() غير كافية، حيث أن نوع buckets يتطلب عدادًا أو حجم صندوق. استخدم tracefs_hist_add_key_cnt() عند تحديد مفتاح مقسم إلى صناديق، ومرر حجم تلك الصناديق إلى cnt.

ستقوم الدالة tracefs_hist_add_value() بإضافة قيمة لتسجيلها. افتراضيًا، القيمة هي ببساطة "hitcount" لعدد المرات التي تم فيها ضرب مثيل مفتاح الرسم البياني. hist هو واصف الرسم البياني لإضافة القيمة إليه. value هو حقل في الرسم البياني للإضافة إليه عند ضرب مثيل للمفتاح.

أنواع المفاتيح

تقوم كل من tracefs_hist_alloc_nd() و tracefs_hist_add_key() بإضافة مفتاح وتتطلبان أن يكون لهذا المفتاح نوع. قد تكون الأنواع:

TRACEFS_HIST_KEY_NORMAL أو صفر (0) وهو لعدم تعديل النوع.

TRACEFS_HIST_KEY_HEX لعرض المفتاح بالنظام الست عشري.

TRACEFS_HIST_KEY_SYM لعرض المفتاح كرمز نواة (إذا تم العثور عليه). إذا كان المفتاح عنوانًا، فهذا مفيد لأنه سيعرض أسماء الوظائف بدلاً من مجرد رقم.

TRACEFS_HIST_KEY_SYM_OFFSET مشابه لـ TRACEFS_HIST_KEY_SYM ولكنه سيشمل أيضًا إزاحة الوظيفة لمطابقة العنوان الدقيق.

TRACEFS_HIST_KEY_SYSCALL إذا كان المفتاح "معرف" لنظام استدعاءات النظام (الرقم الذي تم تمريره من مساحة المستخدم إلى النواة لإعلامها بنظام استدعاءات النظام الذي يتم استدعاؤه)، فسيتم عرض اسم نظام استدعاءات النظام.

TRACEFS_HIST_KEY_EXECNAME إذا كان "common_pid" هو المفتاح (معرف العملية للمهمة قيد التنفيذ)، فبدلاً من عرض الرقم، سيتم عرض اسم المهمة قيد التشغيل.

TRACEFS_HIST_KEY_LOG ستعرض المفتاح على مقياس لوغاريتمي ثنائي.

TRACEFS_HIST_KEY_USECS للاستخدام مع "common_timestamp" أو TRACEFS_HIST_TIMESTAMP، وفي هذه الحالة، ستعرض الطابع الزمني بالميكروثانية بدلاً من النانوثانية.

قيمة الإرجاع

تعيد الدالة tracefs_hist_alloc_nd() واصف رسم بياني مخصص يجب تحريره بواسطة tracefs_hist_free() أو NULL في حالة حدوث خطأ.

تعيد جميع الدوال الأخرى صفرًا عند النجاح أو -1 عند حدوث خطأ.

إذا أعادت الدالة tracefs_hist_start() خطأ، فقد يتم عرض رسالة في النواة يمكن استردادها بواسطة tracefs_error_last().

tracefs_hist_free(3) — libtracefs

NAME

tracefs_hist_free — free a tracefs histogram object

SYNOPSIS

#include <tracefs.h>

void tracefs_hist_free(struct tracefs_hist *hist);

DESCRIPTION

The tracefs_hist_free function frees the memory allocated for the tracefs_hist structure pointed to by hist. It is important to call this function when you are done with a histogram object to prevent memory leaks.

KEY TYPES

struct tracefs_hist
This structure represents a histogram object within tracefs.

RETURN VALUE

This function does not return a value.

EXAMPLE

The following example demonstrates how to create, use, and free a tracefs histogram:

    #include <stdio.h>
    #include <tracefs.h>

    int main() {
        struct tracefs_hist *hist;

        // Create a histogram object
        hist = tracefs_hist_alloc("my_histogram");
        if (!hist) {
            perror("Failed to allocate histogram");
            return 1;
        }

        printf("Histogram object created successfully.\n");

        // ... use the histogram object here ...

        // Free the histogram object
        tracefs_hist_free(hist);
        printf("Histogram object freed successfully.\n");

        return 0;
    }

FILES

/usr/include/tracefs.h
        The header file to include in order to have access to the library APIs.
-ltracefs
        Linker switch to add when building a program that uses the library.

tracefs_hist_free — تحرير كائن رسم بياني لتتبع tracefs

الملخص

#include <tracefs.h>

void tracefs_hist_free(struct tracefs_hist *hist);

الوصف

تقوم الدالة tracefs_hist_free بتحرير الذاكرة المخصصة لهيكل tracefs_hist الذي يشير إليه hist. من المهم استدعاء هذه الدالة عند الانتهاء من كائن الرسم البياني لمنع تسرب الذاكرة.

أنواع رئيسية

struct tracefs_hist
يمثل هذا الهيكل كائن رسم بياني ضمن tracefs.

قيمة الإرجاع

لا تُرجع هذه الدالة قيمة.

مثال

يوضح المثال التالي كيفية إنشاء واستخدام وتحرير رسم بياني لـ tracefs:

    #include <stdio.h>
    #include <tracefs.h>

    int main() {
        struct tracefs_hist *hist;

        // إنشاء كائن رسم بياني
        hist = tracefs_hist_alloc("my_histogram");
        if (!hist) {
            perror("فشل تخصيص الرسم البياني");
            return 1;
        }

        printf("تم إنشاء كائن الرسم البياني بنجاح.\n");

        // ... استخدم كائن الرسم البياني هنا ...

        // تحرير كائن الرسم البياني
        tracefs_hist_free(hist);
        printf("تم تحرير كائن الرسم البياني بنجاح.\n");

        return 0;
    }
