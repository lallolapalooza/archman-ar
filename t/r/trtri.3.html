المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  A مصفوفة مثلثية عليا؛
!>          = 'L':  A مصفوفة مثلثية سفلى.
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          = 'N':  A مصفوفة مثلثية غير وحدوية؛
!>          = 'U':  A مصفوفة مثلثية وحدوية.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

A

!>          A هي مصفوفة COMPLEX، ذات البعد (LDA,N)
!>          عند الإدخال، تحتوي المصفوفة المثلثية A. إذا كان UPLO = 'U'، فإن
!>          الجزء العلوي المثلثي من المصفوفة A ذي الأبعاد N×N يحتوي على
!>          المصفوفة المثلثية العليا، والجزء السفلي المثلثي الصارم
!>          للمصفوفة A لا يتم الرجوع إليه. إذا كان UPLO = 'L'، فإن
!>          الجزء السفلي المثلثي من المصفوفة A ذي الأبعاد N×N يحتوي على
!>          المصفوفة المثلثية السفلى، والجزء العلوي المثلثي الصارم
!>          للمصفوفة A لا يتم الرجوع إليه. إذا كان DIAG = 'U'، فإن
!>          العناصر القطرية لـ A لا يتم الرجوع إليها ويُفترض أنها 1.
!>          عند الخروج، معكوس المصفوفة الأصلية (المثلثية)، بنفس تنسيق التخزين.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

INFO

!>          INFO هو INTEGER
!>          = 0: تم الخروج بنجاح
!>          < 0: إذا كان INFO = -i، فقد كانت الوسيطة i غير قانونية
!>          > 0: إذا كان INFO = i، فإن A(i,i) تساوي صفر بالضبط. المصفوفة
!>               المثلثية مفردة ولا يمكن حساب معكوسها.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the triangular matrix A.  If UPLO = 'U', the
!>          leading N-by-N upper triangular part of the array A contains
!>          the upper triangular matrix, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of the array A contains
!>          the lower triangular matrix, and the strictly upper
!>          triangular part of A is not referenced.  If DIAG = 'U', the
!>          diagonal elements of A are also not referenced and are
!>          assumed to be 1.
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same storage format.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = i, A(i,i) is exactly zero.  The triangular
!>               matrix is singular and its inverse can not be computed.
!>
