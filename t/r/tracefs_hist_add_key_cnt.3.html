الوصف

يتم إنشاء الرسوم البيانية للأحداث بواسطة ملف المشغل (trigger) في دليل الحدث (event). يمكن أن يكون بناء الجملة معقدًا ويصعب الحصول عليه بشكل صحيح. تعالج واجهة برمجة التطبيقات هذه بناء الجملة، وتسهل إنشاء الرسوم البيانية للأحداث والتفاعل معها. انظر https://www.kernel.org/doc/html/latest/trace/histogram.html لمزيد من المعلومات.

تقوم الدالة tracefs_hist_alloc() بتخصيص واصف "struct tracefs_hist" لرسم بياني أحادي البعد وتعيد عنوانه. يجب تحرير هذا الواصف بواسطة الدالة tracefs_hist_free(). tep هو مقبض حدث التتبع (انظر tracefs_local_events(3))، الذي يحمل system و event التي سيتم إرفاق الرسم البياني بها. system هو النظام أو مجموعة الحدث. event هو الحدث المراد إرفاق الرسم البياني به. key هو حقل في الحدث سيتم استخدامه كمفتاح (بعد) للرسم البياني. type هو نوع المفتاح. انظر أنواع المفاتيح أدناه.

تقوم الدالة tracefs_hist_alloc_2d() بتخصيص واصف "struct tracefs_hist" لرسم بياني ثنائي الأبعاد وتعيد عنوانه. يجب تحرير هذا الواصف بواسطة الدالة tracefs_hist_free(). tep هو مقبض حدث التتبع (انظر tracefs_local_events(3))، الذي يحمل system و event التي سيتم إرفاق الرسم البياني بها. system هو النظام أو مجموعة الحدث. event هو الحدث المراد إرفاق الرسم البياني به. key1 هو الحقل الأول في الحدث الذي سيتم استخدامه كمفتاح (بعد) للرسم البياني. type1 هو نوع key1. انظر أنواع المفاتيح أدناه. key2 هو الحقل الثاني في الحدث الذي سيتم استخدامه كمفتاح (بعد) للرسم البياني. type2 هو نوع key2. انظر أنواع المفاتيح أدناه.

تقوم الدالة tracefs_hist_alloc_nd() بتخصيص واصف "struct tracefs_hist" لرسم بياني ذي N أبعاد وتعيد عنوانه. يجب تحرير هذا الواصف بواسطة الدالة tracefs_hist_free(). tep هو مقبض حدث التتبع (انظر tracefs_local_events(3))، الذي يحمل system و event التي سيتم إرفاق الرسم البياني بها. system هو النظام أو مجموعة الحدث. event هو الحدث المراد إرفاق الرسم البياني به. axes هو مصفوفة من أزواج key / type، تحدد أبعاد الرسم البياني.

ستقوم الدالة tracefs_hist_alloc_nd_cnt() بتهيئة واصف رسم بياني سيتم إرفاقه بـ system/event. هذه تهيئ فقط الواصف بمفاتيح axes المعطاة كمفاتيح أساسية. هذه تهيئ الواصف فقط، ولا تبدأ الرسم البياني في النواة. الفرق بين هذه والدالة tracefs_hist_alloc_nd() هو أن المعامل axes من نوع struct tracefs_hist_axis_cnt وليس struct tracefs_hist_axis.

تقوم الدالة tracefs_hist_free() بتحرير واصف tracefs_hist. ملاحظة، لا توقف أو تعطّل الرسم البياني قيد التشغيل إذا كان قد بدأ. يجب استدعاء tracefs_hist_destroy() للقيام بذلك.

تقوم الدالة tracefs_hist_add_key() بإضافة مفتاح ثانوي أو ثالث للرسم البياني. المفتاح الذي تم تمريره إلى tracefs_hist_alloc_nd() هو المفتاح الأساسي للرسم البياني. عند استدعاء هذه الدالة لأول مرة، ستضيف مفتاحًا ثانويًا (أو رسمًا بيانيًا ثنائي الأبعاد). إذا تم استدعاء هذه الدالة مرة أخرى على نفس الرسم البياني، ستضيف مفتاحًا ثلاثيًا (أو رسمًا بيانيًا ثلاثي الأبعاد). المعامل hist هو واصف الرسم البياني لإضافة key إليه. type هو نوع المفتاح المراد إضافته (انظر أنواع المفاتيح أدناه).

الدالة tracefs_hist_add_key_cnt() هي نفس الدالة tracefs_hist_add_key() باستثناء أنها تسمح بإضافة عداد للنوع المعطى. حاليًا، يوجد نوع buckets فقط يتطلب عدادًا. عند إضافة مفتاح من نوع buckets، فإن الدالة tracefs_hist_add_key() غير كافية، حيث يتطلب نوع buckets حجم عداد أو جرافة. استخدم tracefs_hist_add_key_cnt() عند تحديد مفتاح مقسم إلى جرافات، ومرر حجم تلك الجرافات في cnt.

ستقوم الدالة tracefs_hist_add_value() بإضافة قيمة للتسجيل. افتراضيًا، القيمة هي ببساطة "عدد الزيارات" لعدد المرات التي تم فيها الوصول إلى مثيل مفتاح الرسم البياني. hist هو واصف الرسم البياني لإضافة القيمة إليه. value هو حقل في الرسم البياني للإضافة إليه عند الوصول إلى مثيل للمفتاح.

أنواع المفاتيح

كل من الدالتين tracefs_hist_alloc_nd() و tracefs_hist_add_key() تضيف مفتاحًا وتتطلبان أن يكون لهذا المفتاح نوع. قد تكون الأنواع:

TRACEFS_HIST_KEY_NORMAL أو صفر (0) وهو عدم تعديل النوع.

TRACEFS_HIST_KEY_HEX لعرض المفتاح بالنظام الست عشري.

TRACEFS_HIST_KEY_SYM لعرض المفتاح كرمز نواة (إذا تم العثور عليه). إذا كان المفتاح عنوانًا، فهذا مفيد لأنه سيعرض أسماء الدوال بدلًا من مجرد رقم.

TRACEFS_HIST_KEY_SYM_OFFSET مشابه لـ TRACEFS_HIST_KEY_SYM ولكنه سيشمل أيضًا إزاحة الدالة لمطابقة العنوان الدقيق.

TRACEFS_HIST_KEY_SYSCALL إذا كان المفتاح "معرف" استدعاء النظام (الرقم الذي يتم تمريره من مساحة المستخدم إلى النواة لإخبارها بالاستدعاء الذي يتم تنفيذه)، فسيتم عرض اسم استدعاء النظام.

TRACEFS_HIST_KEY_EXECNAME إذا كان "common_pid" هو المفتاح (معرف العملية للعملية المنفذة)، فبدلًا من إظهار الرقم، قم بإظهار اسم المهمة قيد التشغيل.

TRACEFS_HIST_KEY_LOG ستعرض المفتاح بمقياس لوغاريتمي ثنائي.

TRACEFS_HIST_KEY_USECS للاستخدام مع "common_timestamp" أو TRACEFS_HIST_TIMESTAMP، وفي هذه الحالة، ستعرض الطابع الزمني بالميكروثانية بدلًا من النانوثانية.

قيمة الإرجاع

تعيد الدالة tracefs_hist_alloc_nd() واصف رسم بياني مخصص يجب تحريره بواسطة tracefs_hist_free() أو NULL في حالة حدوث خطأ.

جميع الدوال الأخرى تعيد صفرًا عند النجاح أو -1 في حالة حدوث خطأ.

إذا أعادت الدالة tracefs_hist_start() خطأ، فقد يتم عرض رسالة في النواة يمكن استردادها بواسطة tracefs_error_last().

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

مثال

#include <stdlib.h>
#include <ctype.h>
#include <unistd.h>
#include <tracefs.h>
enum commands {
        START,
        PAUSE,
        CONT,
        RESET,
        DELETE,
        SHOW,
};
static void parse_system_event(char *group, char **system, char **event)
{
        *system = strtok(group, "/");
        *event = strtok(NULL, "/");
        if (!*event) {
                *event = *system;
                *system = NULL;
        }
}
static int parse_keys(char *keys, struct tracefs_hist_axis_cnt **axes)
{
        char *sav = NULL;
        char *key;
        int cnt = 0;
        for (key = strtok_r(keys, ",", &sav); key; key = strtok_r(NULL, ",", &sav)) {
                struct tracefs_hist_axis_cnt *ax;
                char *att;
                ax = realloc(*axes, sizeof(*ax) * (cnt + 2));
                if (!ax) {
                        perror("فشل تخصيص المحاور");
                        exit(-1);
                }
                ax[cnt].key = key;
                ax[cnt].type = 0;
                ax[cnt + 1].key = NULL;
                ax[cnt + 1].type = 0;
                *axes = ax;
                att = strchr(key, '.');
                if (att) {
                        *att++ = '\0';
                        if (strcmp(att, "hex") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_HEX;
                        else if (strcmp(att, "sym") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM;
                        else if (strcmp(att, "sym_offset") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYM_OFFSET;
                        else if (strcmp(att, "syscall") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_SYSCALL;
                        else if (strcmp(att, "exec") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_EXECNAME;
                        else if (strcmp(att, "log") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_LOG;
                        else if (strcmp(att, "usecs") == 0)
                                ax[cnt].type = TRACEFS_HIST_KEY_USECS;
                        else if (strncmp(att, "buckets", 7) == 0) {
                                if (att[7] != '=' && !isdigit(att[8])) {
                                        fprintf(stderr, "'buckets' يتطلب نوع المفتاح '=<size>'\n");
                                        exit(-1);
                                }
                                ax[cnt].type = TRACEFS_HIST_KEY_BUCKETS;
                                ax[cnt].cnt = atoi(&att[8]);
                        } else {
                                fprintf(stderr, "سمة غير معرفة '%s'\n", att);
                                fprintf(stderr,"  السمات المقبولة:\n");
                                fprintf(stderr,"    hex, sym, sym_offset, syscall, exe, log, usecs\n");
                                exit(-1);
                        }
                }
                cnt++;
        }
        return cnt;
}
static void process_hist(enum commands cmd, const char *instance_name,
                         char *group, char *keys, char *vals, char *sort,
                         char *ascend, char *desc)
{
        struct tracefs_instance *instance = NULL;
        struct tracefs_hist *hist;
        struct tep_handle *tep;
        struct tracefs_hist_axis_cnt *axes = NULL;
        char *system;
        char *event;
        char *sav;
        char *val;
        int ret;
        int cnt;
        if (instance_name) {
                instance = tracefs_instance_create(instance_name);
                if (!instance) {
                        fprintf(stderr, "فشل إنشاء المثيل\n");
                        exit(-1);
                }
        }
        tep = tracefs_local_events(NULL);
        if (!tep) {
                perror("تعذر قراءة الأحداث");
                exit(-1);
        }
        parse_system_event(group, &system, &event);
        if (cmd == SHOW) {
                char *content;
                content = tracefs_event_file_read(instance, system, event,
                                                  "hist", NULL);
                if (!content) {
                        perror("قراءة ملف hist");
                        exit(-1);
                }
                printf("%s\n", content);
                free(content);
                return;
        }
        if (!keys) {
                fprintf(stderr, "يحتاج الأمر إلى خيار -k\n");
                exit(-1);
        }
        cnt = parse_keys(keys, &axes);
        if (!cnt) {
                fprintf(stderr, "لا مفاتيح؟؟\n");
                exit(-1);
        }
        /* تتطلب الحاويات وظيفة nd_cnt */
        switch (cnt) {
        case 2:
                if (axes[1].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
                /* متابعة */
        case 1:
                if (axes[0].type == TRACEFS_HIST_KEY_BUCKETS)
                        cnt = -1;
        }
        /* عرض أمثلة لـ hist1d و hist2d */
        switch (cnt) {
        case 1:
                hist = tracefs_hist_alloc(tep, system, event,
                                          axes[0].key, axes[0].type);
                break;
        case 2:
                hist = tracefs_hist_alloc_2d(tep, system, event,
                                             axes[0].key, axes[0].type,
                                             axes[1].key, axes[1].type);
                break;
        default:
                /* حقًا، يمكن لـ 1 و 2 استخدام هذا أيضًا */
                hist = tracefs_hist_alloc_nd_cnt(tep, system, event, axes);
        }
        if (!hist) {
                fprintf(stderr, "فشل إنشاء hist\n");
                exit(-1);
        }
        if (vals) {
                sav = NULL;
                for (val = strtok_r(vals, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_value(hist, val);
                        if (ret) {
                                fprintf(stderr, "فشل إضافة القيمة %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (sort) {
                sav = NULL;
                for (val = strtok_r(sort, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_add_sort_key(hist, val);
                        if (ret) {
                                fprintf(stderr, "فشل إضافة مفتاح/قيمة الفرز %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (ascend) {
                sav = NULL;
                for (val = strtok_r(ascend, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_ASCENDING);
                        if (ret) {
                                fprintf(stderr, "فشل إضافة مفتاح/قيمة تصاعدي %s\n", val);
                                exit(-1);
                        }
                }
        }
        if (desc) {
                sav = NULL;
                for (val = strtok_r(desc, ",", &sav); val; val = strtok_r(NULL, ",", &sav)) {
                        ret = tracefs_hist_sort_key_direction(hist, val, TRACEFS_HIST_SORT_DESCENDING);
                        if (ret) {
                                fprintf(stderr, "فشل إضافة مفتاح/قيمة تنازلي %s\n", val);
                                exit(-1);
                        }
                }
        }
        tracefs_error_clear(instance);
        switch (cmd) {
        case START:
                ret = tracefs_hist_start(instance, hist);
                if (ret) {
                        char *err = tracefs_error_last(instance);
                        if (err)
                                fprintf(stderr, "\n%s\n", err);
                }
                break;
        case PAUSE:
                ret = tracefs_hist_pause(instance, hist);
                break;
        case CONT:
                ret = tracefs_hist_continue(instance, hist);
                break;
        case RESET:
                ret = tracefs_hist_reset(instance, hist);
                break;
        case DELETE:
                ret = tracefs_hist_destroy(instance, hist);
                break;
        case SHOW:
                /* تم عرض SHOW بالفعل */
                break;
        }
        if (ret)
                fprintf(stderr, "فشل: الأمر\n");
        exit(ret);
}
int main (int argc, char **argv, char **env)
{
        enum commands cmd;
        char *instance = NULL;
        char *cmd_str;
        char *event = NULL;
        char *keys = NULL;
        char *vals = NULL;
        char *sort = NULL;
        char *desc = NULL;
        char *ascend = NULL;
        if (argc < 2) {
                fprintf(stderr, "الاستخدام: %s command [-B instance][-e [system/]event][-k keys][-v vals][-s sort]\n", argv[0]);
                fprintf(stderr, "      [-a ascending][-d descending]\n");
                exit(-1);
        }
        cmd_str = argv[1];
        if (!strcmp(cmd_str, "start"))
                cmd = START;
        else if (!strcmp(cmd_str, "pause"))
                cmd = PAUSE;
        else if (!strcmp(cmd_str, "cont"))
                cmd = CONT;
        else if (!strcmp(cmd_str, "reset"))
                cmd = RESET;
        else if (!strcmp(cmd_str, "delete"))
                cmd = DELETE;
        else if (!strcmp(cmd_str, "show"))
                cmd = SHOW;
        else {
                fprintf(stderr, "أمر غير معروف %s\n", cmd_str);
                exit(-1);
        }
        for (;;) {
                int c;
                c = getopt(argc - 1, argv + 1, "e:k:v:B:s:d:a:");
                if (c == -1)
                        break;
                switch (c) {
                case 'e':
                        event = optarg;
                        break;
                case 'k':
                        keys = optarg;
                        break;
                case 'v':
                        vals = optarg;
                        break;
                case 'B':
                        instance = optarg;
                        break;
                case 's':
                        sort = optarg;
                        break;
                case 'd':
                        desc = optarg;
                        break;
                case 'a':
                        ascend = optarg;
                        break;
                }
        }
        if (!event) {
                event = "kmem/kmalloc";
                if (!keys)
                        keys = "call_site.sym,bytes_req";
                if (!vals)
                        vals = "bytes_alloc";
                if (!sort)
                        sort = "bytes_req,bytes_alloc";
                if (!desc)
                        desc = "bytes_alloc";
        }
        process_hist(cmd, instance, event, keys, vals, sort, ascend, desc);
}
