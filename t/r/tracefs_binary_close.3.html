tracefs_binary_close(3)

الحزمة: libtracefs

التراخيص: GPL-2.0-only, LGPL-2.1-only

LIBTRACEFS(3) دليل libtracefs LIBTRACEFS(3)

الاسم

tracefs_binary_init, tracefs_binary_close, tracefs_binary_write - فتح، إغلاق وكتابة بيانات ثنائية في مخزن التتبع المؤقت.

ملخص

#include <tracefs.h>
int tracefs_binary_init(struct tracefs_instance *instance);
int tracefs_binary_write(struct tracefs_instance *instance, void *data, int len);
void tracefs_binary_close(struct tracefs_instance *instance);

الوصف

مجموعة من الوظائف لكتابة بيانات ثنائية في مخزن التتبع المؤقت. انظر Documentation/trace/ftrace.rst من شجرة نواة لينكس لمزيد من المعلومات حول كتابة البيانات من مساحة المستخدم إلى مخزن التتبع المؤقت. كل هذه الواجهات لها instance كوسيط أول. إذا تم تمرير NULL كوسيط instance، يتم استخدام مثيل التتبع الأعلى.

تقوم الوظيفة tracefs_binary_init() بتهيئة المكتبة للكتابة في مخزن التتبع المؤقت للمثيل المحدد instance. ليس من الضروري استدعاء هذه الواجهة قبل كتابة البيانات، ستقوم tracefs_binary_write() باستدعائها تلقائيًا، إذا لم تكن المكتبة مهيأة بعد. ولكن استدعاء tracefs_binary_init() مسبقًا سيسرع عملية الكتابة.

تقوم الوظيفة tracefs_binary_write() بكتابة بيانات ثنائية في مخزن التتبع المؤقت للمثيل المحدد instance. يشير data إلى البيانات بطول len، والتي سيتم كتابتها في مخزن التتبع المؤقت.

تقوم الوظيفة tracefs_binary_close() بإغلاق الموارد المستخدمة بواسطة المكتبة للكتابة في مخزن التتبع المؤقت للمثيل المحدد.

قيمة الإرجاع

تعيد الوظيفتان tracefs_binary_init() و tracefs_binary_write() القيمة 0 إذا كانت العملية ناجحة، أو -1 في حالة حدوث خطأ.

مثال

#include <tracefs.h>
if (tracefs_binary_init(NULL) < 0) {
 /* فشل تهيئة المكتبة للكتابة في مخزن التتبع المؤقت لمثيل التتبع الأعلى */
}
unsigned int data = 0xdeadbeef;
        if (tracefs_binary_write(NULL, &data, sizeof(data)) < 0) {
                /* فشل الكتابة في مخزن التتبع المؤقت */
        }
tracefs_binary_close();
