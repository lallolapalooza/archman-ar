ttk_radiobutton(n)

الحزمة: tk

التراخيص: TCL

ttk::radiobutton(n) Tk Themed Widget ttk::radiobutton(n)

اسم

ttk::radiobutton - ودجة خيار متبادل حصري

موجز

ttk::radiobutton pathName ؟خيارات؟

الوصف

تُستخدم ودجات ttk::radiobutton في مجموعات لعرض أو تغيير مجموعة من الخيارات المتبادلة حصريًا. ترتبط أزرار الراديو بمتغير Tcl، ولها قيمة مرتبطة بها؛ عندما يتم النقر فوق زر راديو، فإنه يقوم بتعيين المتغير إلى قيمته المرتبطة.

خيارات قياسية

-class	-compound	-cursor
-image	-state	-style
-takefocus	-text	-textvariable
-underline	-width

راجع مدخل دليل ttk_widget للحصول على تفاصيل حول الخيارات القياسية.

خيارات خاصة بالودجة

اسم سطر الأوامر:	-command
اسم قاعدة البيانات:	command
فئة قاعدة البيانات:	Command
برنامج نصي Tcl لتقييمه كلما تم استدعاء الودجة.
اسم سطر الأوامر:	-value
اسم قاعدة البيانات:	Value
فئة قاعدة البيانات:	Value
القيمة المراد تخزينها في -variable المرتبط عند تحديد الودجة.
اسم سطر الأوامر:	-variable
اسم قاعدة البيانات:	variable
فئة قاعدة البيانات:	Variable
اسم متغير عام يرتبط قيمته بالودجة. القيمة الافتراضية هي ::selectedButton.

أمر الودجة

بالإضافة إلى أوامر cget، و configure، و identify، و instate، و state القياسية، تدعم أزرار الراديو الأوامر الإضافية التالية للودجة:

pathname invoke
يقوم بتعيين -variable إلى -value، ويحدد الودجة، ويقيم -command المرتبط. يعيد نتيجة -command، أو سلسلة فارغة إذا لم يتم تحديد -command.

حالات الودجة

لا تستجيب الودجة لمدخلات المستخدم إذا تم تعيين حالة disabled. تقوم الودجة بتعيين حالة selected كلما تم تعيين المتغير المرتبط -variable إلى -value الخاص بالودجة، وتلغيه بخلاف ذلك. تقوم الودجة بتعيين حالة alternate كلما تم إلغاء تعيين المتغير المرتبط -variable. (يمكن استخدام حالة alternate للإشارة إلى تحديد "ثلاثي الحالات" أو "غير محدد").

أنماط قياسية

تدعم ودجات Ttk::radiobutton نمط Toolbutton في جميع الثيمات القياسية، وهو مفيد لإنشاء ودجات لأشرطة الأدوات.

خيارات التنسيق

اسم الفئة لـ ttk::radiobutton هو TRadiobutton.

الحالات الديناميكية: active, alternate, disabled, pressed, readonly, selected.

خيارات تنسيق TRadiobutton القابلة للتكوين باستخدام ttk::style هي:

-background color
-compound compound
-foreground color
-indicatorbackground color
-indicatorcolor color
-indicatormargin padding
-indicatorrelief relief
-padding padding

بعض الخيارات متاحة فقط لثيمات معينة.

راجع صفحة دليل ttk::style لمعرفة معلومات حول كيفية تكوين أنماط ttk.
