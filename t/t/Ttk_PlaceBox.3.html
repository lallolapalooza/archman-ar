Ttk_PlaceBox(3)

الحزمة: tk

التراخيص: TCL

NAME

Ttk_PlaceBox - Tk box layout manager

SYNOPSIS

package require Ttk
ttk::place box window ?options?

ARGUMENTS

The ttk::place command is a general-purpose geometry manager that supports several different geometry specifications, including box layouts.

The box layout options are:

-padding
Specifies padding around the box. This can be a single value, which applies to all sides, or a list of one, two, or four values. A single value sets padding on all four sides. Two values set horizontal and vertical padding. Four values set padding on the left, top, right, and bottom sides, respectively.
-margins
Specifies margins around the box. This option is similar to -padding, but applies to the space outside the box, between the box and other widgets.
-anchor
Specifies how the box should be positioned within its allocated space. This can be one of the standard Tk anchor directions (e.g., n, s, e, w, center).
-relief
Specifies the relief style of the box. This can be one of the standard Tk relief styles (e.g., flat, raised, sunken, ridge, solid).
-width
Specifies the width of the box.
-height
Specifies the height of the box.

BOXES

A box is a rectangular region within its parent. The box layout manager allows you to arrange widgets within a box in a hierarchical manner. Widgets can be placed inside other widgets, creating nested boxes.

When a widget is placed using the box layout, it is given a reference point (an anchor) and dimensions. The box layout manager then calculates the positions of the children widgets based on their own options.

PADDDING

Padding is the space between the content of a widget and its border. Margins are the space between the border of a widget and the border of its parent or neighboring widgets.

The -padding and -margins options can be specified as a single value, or a list of values. For example:

-padding 10
Sets padding on all four sides to 10 pixels.
-padding {10 5}
Sets horizontal padding to 10 pixels and vertical padding to 5 pixels.
-padding {10 5 2 8}
Sets left padding to 10, top to 5, right to 2, and bottom to 8 pixels.

CONVERSION ROUTINES

The following functions are used to convert Tk option values to internal representations:

Tk_GetReliefFromObj(3), Tk_GetPixelsFromObj(3), Tk_GetAnchorFromObj(3)

Tk_GetReliefFromObj(3), Tk_GetPixelsFromObj(3), Tk_GetAnchorFromObj(3)
