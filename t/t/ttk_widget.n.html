ttk_widget(n)

الحزمة: tk

التراخيص: TCL

ttk::widget(n) Tk Themed Widget ttk::widget(n)

الاسم

ttk::widget - الخيارات والأوامر القياسية المدعومة بواسطة أدوات Tk ذات السمات

الوصف

يصف دليل المستخدم هذا الخيارات والأوامر الشائعة للأدوات.

الخيارات القياسية

الخيارات التالية مدعومة من قبل جميع أدوات Tk ذات السمات:

Command-Line Name:	-class
Database Name:	undefined
Database Class:	undefined
يحدد فئة النافذة. تُستخدم الفئة عند الاستعلام عن قاعدة بيانات الخيارات للخيارات الأخرى للنافذة، لتحديد علامات الربط الافتراضية للنافذة، ولاختيار التخطيط والنمط الافتراضيين للأداة. هذا خيار للقراءة فقط: لا يمكن تحديده إلا عند إنشاء النافذة، ولا يمكن تغييره باستخدام الأمر configure للأداة.
Command-Line Name:	-cursor
Database Name:	cursor
Database Class:	Cursor
يحدد مؤشر الفأرة الذي سيتم استخدامه للأداة. انظر Tk_GetCursor و cursors(n) في دليل Tk المرجعي للقيم القانونية. إذا تم تعيينه إلى سلسلة فارغة (الافتراضي)، يتم وراثة المؤشر من الأداة الأصل.
Command-Line Name:	-takefocus
Database Name:	takeFocus
Database Class:	TakeFocus
يحدد ما إذا كانت النافذة تقبل التركيز أثناء التنقل باستخدام لوحة المفاتيح. إما 0، 1، بادئة أمر (يتم إلحاق مسار الأداة بها، والتي يجب أن تُرجع 0 أو 1)، أو سلسلة فارغة. انظر options(n) في دليل Tk المرجعي للوصف الكامل.
Command-Line Name:	-style
Database Name:	style
Database Class:	Style
يمكن استخدامه لتحديد نمط أداة مخصص.

خيارات الأدوات القابلة للتمرير

الخيارات التالية مدعومة من قبل الأدوات التي يمكن التحكم فيها بواسطة شريط تمرير. انظر scrollbar(n) لمزيد من المعلومات.

Command-Line Name:	-xscrollcommand
Database Name:	xScrollCommand
Database Class:	ScrollCommand
بادئة أمر، تستخدم للتواصل مع أشرطة التمرير الأفقية.
عندما يتغير العرض في نافذة الأداة، ستنشئ الأداة أمر Tcl عن طريق دمج أمر التمرير ورقمين. كل من الرقمين هو جزء بين 0 و 1 يشير إلى موقع في المستند؛ 0 يشير إلى البداية، و 1 يشير إلى النهاية. يشير الكسر الأول إلى أول معلومة في الأداة مرئية في النافذة، ويشير الكسر الثاني إلى المعلومات التي تلي مباشرة الجزء الأخير المرئي.

عادةً ما يتكون خيار -xscrollcommand من اسم مسار أداة scrollbar متبوعًا بـ “set”، على سبيل المثال “.x.scrollbar set”. سيؤدي هذا إلى تحديث شريط التمرير عند تغيير العرض في النافذة.

إذا تم تعيين هذا الخيار إلى سلسلة فارغة (الافتراضي)، فلن يتم تنفيذ أي أمر.

Command-Line Name:	-yscrollcommand
Database Name:	yScrollCommand
Database Class:	ScrollCommand
بادئة أمر، تستخدم للتواصل مع أشرطة التمرير العمودية. انظر وصف -xscrollcommand أعلاه للحصول على التفاصيل.

خيارات التسمية

الخيارات التالية مدعومة من قبل التسميات والأزرار والأدوات الشبيهة بالأزرار:

Command-Line Name:	-compound
Database Name:	compound
Database Class:	Compound
يحدد كيفية عرض الصورة بالنسبة للنص، في حال وجود كل من -text و -image. إذا تم تعيينه إلى سلسلة فارغة (الافتراضي)، فإن القواعد الموضحة في قسم "العناصر" من ttk::intro(n) توضح القيمة التي يتم استخدامها فعليًا. القيم الصالحة الأخرى هي:
نص
عرض النص فقط.
صورة
عرض الصورة فقط.
وسط
عرض النص في المنتصف فوق الصورة.
أعلى
أسفل
يسار
يمين
عرض الصورة فوق، تحت، يسار، أو يمين النص، على التوالي.
لا شيء
عرض الصورة إذا كانت موجودة، وإلا النص.
Command-Line Name:	-font
Database Name:	font
Database Class:	Font
الخط المستخدم للنص المعروض بواسطة الأداة.
Command-Line Name:	-foreground
Database Name:	textColor
Database Class:	TextColor
لون المقدمة للأداة. إذا لم يتم تحديده، يتم استخدام افتراض السمة.
Command-Line Name:	-image
Database Name:	image
Database Class:	Image
يحدد صورة للعرض. هذه قائمة بعنصر واحد أو أكثر. العنصر الأول هو اسم الصورة الافتراضي. بقية القائمة هي تسلسل من أزواج statespec / value وفقًا لـ style map، يحدد صورًا مختلفة لاستخدامها عندما تكون الأداة في حالة معينة أو مجموعة من الحالات. يجب أن تكون جميع الصور في القائمة بنفس الحجم.
Command-Line Name:	-padding
Database Name:	padding
Database Class:	Padding
يحدد المساحة الداخلية للأداة. المساحة هي قائمة تصل إلى أربعة مواصفات طول left top right bottom. إذا تم تحديد أقل من أربعة عناصر، فإن bottom افتراضيًا إلى top، و right افتراضيًا إلى left، و top افتراضيًا إلى left. بمعنى آخر، تحدد قائمة بثلاثة أرقام المساحة اليسرى والعامودية واليمنى؛ تحدد قائمة برقمين المساحة الأفقية والعامودية؛ رقم واحد يحدد نفس المساحة حول الأداة.
Command-Line Name:	-text
Database Name:	text
Database Class:	Text
يحدد سلسلة نصية سيتم عرضها داخل الأداة (ما لم يتم تجاوزها بواسطة -textvariable للأدوات التي تدعم هذا الخيار).
Command-Line Name:	-textvariable
Database Name:	textVariable
Database Class:	Variable
يحدد اسم متغير عام سيتم استخدام قيمته بدلاً من مورد -text.
Command-Line Name:	-underline
Database Name:	underline
Database Class:	Underline
إذا تم تعيينه، يحدد فهرس العدد الصحيح (يبدأ من 0) لحرف ليتم تسطيره في سلسلة النص. يتم استخدام الحرف المسطر للتفعيل التذكيري.
Command-Line Name:	-width
Database Name:	width
Database Class:	Width
إذا كان أكبر من صفر، يحدد مقدار المساحة، بعروض الأحرف، لتخصيصها لتسمية النص. إذا كان أقل من صفر، يحدد الحد الأدنى للعرض. إذا كان صفرًا أو غير محدد، يتم استخدام العرض الطبيعي لتسمية النص.

خيارات التوافق

هذا الخيار متاح فقط للأدوات ذات السمات التي لها أدوات Tk تقليدية "مقابلة".

Command-Line Name:	-state
Database Name:	state
Database Class:	State
يمكن تعيينه إلى normal أو disabled للتحكم في بت حالة disabled. هذا خيار للكتابة فقط: يؤدي تعيينه إلى تغيير حالة الأداة، ولكن أمر الأداة state لا يؤثر على الخيار -state.

الأوامر

pathName cget option
يُرجع القيمة الحالية لخيار التكوين المعطى بواسطة option.
pathName configure ?option? ?value option value ...?
يُرجع أو يُعدّل خيارات التكوين للأداة. إذا تم حذف option، فإن الأمر يُرجع وصفًا لجميع خيارات الأداة المتاحة. إذا تم تحديد option ولكن تم حذف value، فإن الأمر يُرجع وصفًا لقيمة option المحددة. إذا تم تحديد كل من option و value، فإن الأمر يعدل الخيار المعطى بقيمة value الجديدة، ويُرجع سلسلة فارغة. يمكن تحديد خيارات تكوين متعددة في نفس الاستدعاء.
