ttk_spinbox(n)

الحزمة: tk

التراخيص: TCL

ttk::spinbox(n) Tk Themed Widget ttk::spinbox(n)

الاسم

ttk::spinbox - أداة اختيار حقل نصي

الملخص

ttk::spinbox pathName ?options?

الوصف

أداة ttk::spinbox هي أداة ttk::entry مع أزرار مدمجة للأعلى والأسفل تُستخدم إما لتعديل قيمة رقمية أو للاختيار من بين مجموعة من القيم. تطبق الأداة جميع ميزات أداة ttk::entry بما في ذلك دعم الخيار -textvariable لربط القيمة المعروضة بواسطة الأداة بمتغير Tcl.

الخيارات القياسية

-class	-cursor	-state
-style	-takefocus	-xscrollcommand

راجع دليل ttk_widget للحصول على تفاصيل حول الخيارات القياسية.

الخيارات القياسية

-validate	-validatecommand

راجع دليل ttk::entry للحصول على تفاصيل حول الخيارات القياسية.

خيارات خاصة بالأداة

اسم سطر الأوامر:	-command
اسم قاعدة البيانات:	command
فئة قاعدة البيانات:	Command
يحدد أمر Tcl ليتم استدعاؤه كلما تم استدعاء spinbutton.
اسم سطر الأوامر:	-format
اسم قاعدة البيانات:	format
فئة قاعدة البيانات:	Format
يحدد تنسيقًا بديلاً لاستخدامه عند تعيين قيمة السلسلة عند استخدام النطاق -from و -to. يجب أن يكون هذا محدد تنسيق بالشكل %<pad>.<pad>f، لأنه سيقوم بتنسيق رقم عشري.
اسم سطر الأوامر:	-from
اسم قاعدة البيانات:	from
فئة قاعدة البيانات:	From
قيمة عشرية تحدد أقل قيمة لـ spinbox. يتم استخدام هذا بالاشتراك مع -to و -increment لتعيين نطاق رقمي.
اسم سطر الأوامر:	-increment
اسم قاعدة البيانات:	increment
فئة قاعدة البيانات:	Increment
قيمة عشرية تحدد مقدار التغيير في القيمة الذي سيتم تطبيقه في كل مرة يتم فيها الضغط على أحد أزرار الدوران للأداة. يطبق زر الأعلى زيادة موجبة، ويطبق زر الأسفل زيادة سالبة.
اسم سطر الأوامر:	-to
اسم قاعدة البيانات:	to
فئة قاعدة البيانات:	To
قيمة عشرية تحدد أعلى قيمة مسموح بها للأداة. انظر أيضًا -from و -increment. نطاق.
اسم سطر الأوامر:	-values
اسم قاعدة البيانات:	values
فئة قاعدة البيانات:	Values
يجب أن تكون هذه قائمة Tcl بالقيم. إذا تم تعيين هذا الخيار، فسيتم تجاوز أي نطاق تم تعيينه باستخدام الخيارات -from و -to و -increment. ستستخدم الأداة بدلاً من ذلك القيم المحددة بدءًا من القيمة الأولى.
اسم سطر الأوامر:	-wrap
اسم قاعدة البيانات:	wrap
فئة قاعدة البيانات:	Wrap
يجب أن تكون قيمة منطقية صحيحة. إذا كانت مفعلة، فسوف تلتف spinbox حول قيم البيانات في الأداة.

الفهارس

راجع دليل ttk::entry للحصول على معلومات حول فهارس الأحرف.

التحقق

راجع دليل ttk::entry للحصول على معلومات حول استخدام الخيارات -validate و -validatecommand.

أمر الأداة

الأوامر الفرعية التالية ممكنة لأدوات spinbox بالإضافة إلى الأوامر الموصوفة لأداة ttk::entry:

pathName get
يُرجع القيمة الحالية لـ spinbox.
pathName set value
يعين سلسلة spinbox إلى value. إذا تم تكوين خيار -format، فسيتم تطبيق هذا التنسيق. إذا فشل التنسيق أو لم يتم تعيينه أو تم استخدام الخيار -values، فسيتم تعيين القيمة مباشرة.

الأحداث الافتراضية

تُنشئ أداة spinbox حدثًا افتراضيًا <<Increment>> عندما يضغط المستخدم على <Up>، وحدثًا افتراضيًا <<Decrement>> عندما يضغط المستخدم على <Down>.

خيارات التنميق

اسم الفئة لـ ttk::spinbox هو TSpinbox.

الحالات الديناميكية: active، disabled، focus، readonly.

خيارات تنميق TSpinbox التي يمكن تكوينها باستخدام ttk::style هي:

-arrowcolor color
-arrowsize amount
-background color

للأمان في التوافق، عند استخدام سمة aqua (لـ macOS)، يعمل هذا الخيار كاسم مستعار لـ -fieldbackground بشرط عدم تحديد قيمة لـ -fieldbackground. خلاف ذلك، يتم تجاهله.
-bordercolor color
-darkcolor color
-fieldbackground color
-foreground color
-insertcolor color
-insertwidth amount
-lightcolor color
-padding padding
-selectbackground color
-selectforeground color

بعض الخيارات متاحة فقط لسمات محددة.

راجع صفحة دليل ttk::style للحصول على معلومات حول كيفية تكوين سمات ttk.
