ttk_combobox(n)

الحزمة: tk

التراخيص: TCL

ttk::combobox(n) Tk Themed Widget ttk::combobox(n)

الاسم

ttk::combobox - حقل نصي مع قائمة اختيارات منسدلة

الملخص

ttk::combobox pathName ?options?

الوصف

ttk::combobox يجمع بين حقل نصي وقائمة منسدلة للقيم؛ يمكن للمستخدم اختيار قيمة الحقل النصي من بين القيم الموجودة في القائمة.

خيارات قياسية

-class	-cursor	-takefocus
-style

راجع صفحة دليل ttk_widget للحصول على تفاصيل حول الخيارات القياسية.

خيارات خاصة بالويجت

Command-Line Name:	-exportselection
Database Name:	exportSelection
Database Class:	ExportSelection
قيمة منطقية. إذا تم تعيينها، يتم ربط اختيار الويجت باختيار X.
Command-Line Name:	-justify
Database Name:	justify
Database Class:	Justify
تحدد كيفية محاذاة النص داخل الويجت. يجب أن تكون واحدة من left، center، أو right.
Command-Line Name:	-height
Database Name:	height
Database Class:	Height
تحدد ارتفاع مربع القائمة المنسدلة، بالصفوف.
Command-Line Name:	-postcommand
Database Name:	postCommand
Database Class:	PostCommand
برنامج Tcl النصي الذي يتم تقييمه فورًا قبل عرض مربع القائمة. قد يحدد برنامج -postcommand النصي -values المراد عرضها.
Command-Line Name:	-state
Database Name:	state
Database Class:	State
واحدة من normal، readonly، أو disabled. في حالة readonly، لا يمكن تحرير القيمة مباشرة، ويمكن للمستخدم فقط اختيار واحدة من -values من القائمة المنسدلة. في حالة normal، يمكن تحرير الحقل النصي مباشرة. في حالة disabled، لا يمكن التفاعل.
Command-Line Name:	-textvariable
Database Name:	textVariable
Database Class:	TextVariable
تحدد اسم متغير عام يرتبط قيمته بقيمة الويجت. كلما تغيرت قيمة المتغير، تم تحديث قيمة الويجت، والعكس صحيح.
Command-Line Name:	-values
Database Name:	values
Database Class:	Values
تحدد قائمة القيم المراد عرضها في مربع القائمة المنسدلة.
Command-Line Name:	-width
Database Name:	width
Database Class:	Width
تحدد قيمة عدد صحيح تشير إلى العرض المطلوب لنافذة الإدخال، بأحرف متوسطة الحجم لخط الويجت.

أمر الويجت

الأوامر الفرعية التالية ممكنة لمربعات الـ combobox:

pathName current ?newIndex?
إذا تم توفير newIndex، فإنه يضبط قيمة الـ combobox إلى العنصر الموجود في الموضع newIndex في قائمة -values (بالإضافة إلى الأعداد الصحيحة، يتم دعم الفهرس end ويشير إلى آخر عنصر في القائمة). بخلاف ذلك، يقوم بإرجاع فهرس القيمة الحالية في قائمة -values أو -1 إذا كانت القيمة الحالية غير موجودة في القائمة.
pathName get
يعيد القيمة الحالية للـ combobox.
pathName set value
يضبط قيمة الـ combobox إلى value.

يدعم الويجت combobox أيضًا الأوامر الفرعية التالية لويجت ttk::entry (انظر ttk::entry(n) للحصول على التفاصيل):

bbox	delete	icursor
index	insert	selection
xview

يدعم الويجت combobox أيضًا الأوامر الفرعية العامة التالية لويجت ttk::widget (انظر ttk::widget(n) للحصول على التفاصيل):

cget	configure	identify
instate	state

أحداث افتراضية

يولد الويجت combobox الحدث الافتراضي <<ComboboxSelected>> عندما يختار المستخدم عنصرًا من قائمة القيم. إذا قام إجراء التحديد بإلغاء نشر مربع القائمة، فسيتم تسليم هذا الحدث بعد إلغاء نشر مربع القائمة.

خيارات التنسيق

اسم الفئة لـ ttk::combobox هو TCombobox. يستخدم ttk::combobox الويجتات entry و listbox داخليًا. يحتوي إطار مربع القائمة على اسم فئة ComboboxPopdownFrame.

الحالات الديناميكية: disabled، focus، pressed، readonly.

خيارات تنسيق TCombobox التي يمكن تهيئتها باستخدام ttk::style هي:

-arrowcolor color
-arrowsize amount
-background color
-bordercolor color
-darkcolor color
-focusfill color
-foreground color
-fieldbackground color

لا يمكن تغييره إلا عند استخدام سمات غير أصلية وغير رسومية.
-insertcolor color
-insertwidth amount
-lightcolor color
-padding padding
-postoffset padding
-selectbackground color
خلفية تحديد الإدخال النصي.
-selectforeground color
مقدمة تحديد الإدخال النصي.

لا يمكن تهيئة مربع القائمة المنسدلة لـ ttk::combobox باستخدام ttk::style أو عبر أمر configure للويجت. يمكن تهيئة مربع القائمة باستخدام قاعدة بيانات الخيارات.

option add *TCombobox*Listbox.background color
option add *TCombobox*Listbox.font font
option add *TCombobox*Listbox.foreground color
option add *TCombobox*Listbox.selectBackground color
option add *TCombobox*Listbox.selectForeground color

لتهيئة مربع قائمة معين (يخضع للتغيير المستقبلي):

set popdown [ttk::combobox::PopdownWindow .mycombobox]
$popdown.f.l configure -font font

خيارات تنسيق ComboboxPopdownFrame التي يمكن تهيئتها باستخدام ttk::style هي:

-borderwidth amount
-relief relief

بعض الخيارات متاحة فقط لسمات محددة.

راجع صفحة دليل ttk::style للحصول على معلومات حول كيفية تهيئة سمات ttk.

انظر أيضًا

ttk::widget(n), ttk::entry(n)
