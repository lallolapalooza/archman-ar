ttk_notebook(n)

الحزمة: tk

التراخيص: TCL

خيارات علامة التبويب المحددة. إذا لم يتم تحديد -option، يُرجع قاموسًا بقيم خيارات علامة التبويب. إذا تم تحديد -option واحد، يُرجع قيمة تلك option. بخلاف ذلك، يقوم بتعيين -options إلى values المقابلة. راجع TAB OPTIONS للخيارات المتاحة.
pathname tabs
يُرجع قائمة النوافذ التي تديرها المفكرة، بترتيب الفهرس لعلامات التبويب المرتبطة بها.

اجتياز لوحة المفاتيح

لتمكين اجتياز لوحة المفاتيح لنافذة علوية تحتوي على عنصر واجهة مستخدم للمفكرة $nb، قم باستدعاء:

ttk::notebook::enableTraversal $nb

سيؤدي هذا إلى توسيع ربطيات النافذة العلوية التي تحتوي على المفكرة كما يلي:

  • Control-Tab يحدد علامة التبويب التالية لعلامة التبويب المحددة حاليًا.
  • Control-Shift-Tab يحدد علامة التبويب السابقة لعلامة التبويب المحددة حاليًا.
  • Alt-K، حيث K هو الحرف المختصر (تحته خط) لأي علامة تبويب، سيحدد تلك العلامة.

يمكن تمكين مفكرات متعددة في نافذة علوية واحدة للاجتياز، بما في ذلك المفكرات المتداخلة. ومع ذلك، يعمل اجتياز المفكرة بشكل صحيح فقط إذا كانت جميع الألواح أطفالًا مباشرين للمفكرة.

الأحداث الافتراضية

ينشئ عنصر واجهة مستخدم المفكرة حدثًا افتراضيًا <<NotebookTabChanged>> بعد تحديد علامة تبويب جديدة.

مثال

pack [ttk::notebook .nb]
.nb add [frame .nb.f1] -text "First tab"
.nb add [frame .nb.f2] -text "Second tab"
.nb select .nb.f2
ttk::notebook::enableTraversal .nb

خيارات التصميم

اسم الفئة لـ ttk::notebook هو TNotebook. علامة التبويب لها اسم فئة TNotebook.Tab

الحالات الديناميكية: active، disabled، selected.

خيارات تصميم TNotebook التي يمكن تهيئتها باستخدام ttk::style هي:

-background color
-bordercolor color
-darkcolor color
-foreground color
-lightcolor color
-padding padding
-tabmargins padding
-tabposition position

يحدد موضع صف أو عمود علامات التبويب كسلسلة طولها 1 أو 2. يشير الحرف الأول إلى الجانب كـ n، s، w، أو e، بينما الحرف الثاني (إذا كان موجودًا) هو بت الالتصاق (المحدد كـ w، e، n، أو s) داخل موضع علامة التبويب. الموضع الافتراضي هو n للموضوع aqua و nw لجميع الموضوعات الأخرى المضمنة.

خيارات تصميم TNotebook.Tab التي يمكن تهيئتها باستخدام ttk::style هي:

-background color
-bordercolor color
-compound compound
-expand padding

يحدد مدى نمو علامة التبويب في الحجم. يستخدم عادةً مع الحالة الديناميكية selected. يجب تعيين -tabmargins بشكل مناسب بحيث يكون هناك مساحة لنمو علامة التبويب. على سبيل المثال، يحتوي ملف مكتبة Ttk vistaTheme.tcl على الأسطر 
ttk::style configure TNotebook -tabmargins {2 2 2 0}
ttk::style map TNotebook.Tab -expand {selected {2 2 2 2}}
وهي صالحة للقيمة الافتراضية nw لخيار التصميم -tabposition. بالنسبة لموضوع ttk::notebook nbStyle المعرف بواسطة 
set nbStyle SW.TNotebook
ttk::style configure $nbStyle -tabposition sw
سيتعين عليك تكييف الإعدادات المذكورة أعلاه على النحو التالي: 
ttk::style configure $nbStyle -tabmargins {2 0 2 2}
ttk::style map $nbStyle.Tab -expand {2 2 2 2}
الطريقة الأسهل للقيام بذلك هي استدعاء إجراء المكتبة ttk::configureNotebookStyle مع $nbStyle كوسيط، بعد تعيين خيار -tabposition الخاص بالتصميم.
-font font
-foreground color
-padding padding
تستخدم بعض الموضوعات padding مختلفًا لعلامة التبويب المحددة. على سبيل المثال، يحتوي ملف مكتبة Ttk clamTheme.tcl على الأسطر 
ttk::style configure TNotebook.Tab -padding {6 2 6 2}
ttk::style map TNotebook.Tab -padding {selected {6 4 6 2}}
وهي صالحة للقيمة الافتراضية nw لخيار التصميم -tabposition. بالنسبة لموضوع ttk::notebook الذي له موضع علامة تبويب مختلف، سيتعين عليك تكييف الإعدادات المذكورة أعلاه وفقًا لذلك. مرة أخرى، الطريقة الأسهل للقيام بذلك هي استدعاء إجراء المكتبة ttk::configureNotebookStyle مع اسم التصميم كوسيط، بعد تعيين خيار -tabposition الخاص بالتصميم.

بعض الخيارات متاحة فقط لموضوعات محددة.

راجع صفحة دليل ttk::style للحصول على معلومات حول كيفية تهيئة تصميمات ttk.
