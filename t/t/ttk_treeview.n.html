ttk_treeview(n)

الحزمة: tk

التراخيص: TCL

pathname focus ?item?
إذا تم تحديد item، فإنه يضبط العنصر الذي تم التركيز عليه على item. بخلاف ذلك، يعيد العنصر الحالي الذي تم التركيز عليه، أو {} إذا لم يكن هناك عنصر.
pathname heading column ?-option ?value -option value...?
استعلام أو تعديل خيارات عنوان العمود للعمود column المحدد. الخيارات الصالحة هي:
-text text
النص المراد عرضه في عنوان العمود.
-image imageName
يحدد صورة لعرضها على يمين عنوان العمود.
-anchor anchor
يحدد كيفية محاذاة نص العنوان. أحد قيم Tk القياسية لمحاذاة العناصر.
-command script
برنامج نصي ليتم تقييمه عند الضغط على تسمية العنوان.

استخدم pathname heading #0 لتكوين عنوان عمود الشجرة.

pathname identify component x y
يعيد وصفًا للمكون component المحدد أسفل النقطة المعطاة بواسطة x و y، أو سلسلة فارغة إذا لم يكن هناك component موجود في هذا الموضع. قد تأخذ القيمتان x و y أي شكل مقبول بواسطة Tk_GetPixels. الأوامر الفرعية التالية مدعومة:
pathname identify region x y
يعيد أحد القيم التالية:
heading
منطقة عنوان الشجرة؛ استخدم [pathname identify column x y] لتحديد رقم العنوان.
separator
المساحة بين عنواني عمودين؛ [pathname identify column x y] سيعيد معرف العمود المعروض للعنوان الموجود على يسار الفاصل.
tree
منطقة الشجرة.
cell
خلية بيانات.
pathname identify item x y يعيد معرف العنصر في الموضع y.
pathname identify column x y
يعيد معرف العمود المعروض للخلية في الموضع x. عمود الشجرة له المعرف #0.
pathname identify element x y
العنصر في الموضع x,y.
pathname identify row x y
مرادف مهمل لـ pathname identify item.

انظر COLUMN IDENTIFIERS لمناقشة أعمدة العرض وأعمدة البيانات.

pathname index item
يعيد الفهرس العددي لـ item ضمن قائمة أطفاله الأصل.
pathname insert parent index ?-id id? options...
ينشئ عنصرًا جديدًا. parent هو معرف العنصر الأصل، أو سلسلة فارغة {} لإنشاء عنصر جديد على المستوى الأعلى. index هو عدد صحيح، أو القيمة end، مما يحدد مكان إدراج العنصر الجديد في قائمة أطفال parent. إذا كان index أقل من أو يساوي الصفر، يتم إدراج العقدة الجديدة في البداية؛ إذا كان index أكبر من أو يساوي العدد الحالي للأطفال، يتم إدراجها في النهاية. إذا تم تحديد -id، يتم استخدامه كمعرف للعنصر؛ يجب ألا يكون id موجودًا بالفعل في الشجرة. بخلاف ذلك، يتم إنشاء معرف فريد جديد.

pathname insert يعيد معرف العنصر للعنصر الذي تم إنشاؤه حديثًا. انظر ITEM OPTIONS لقائمة الخيارات المتاحة.

pathname instate statespec ?script?
اختبار حالة الأداة؛ انظر ttk::widget(n).
pathname item item ?-option ?value -option value...?
استعلام أو تعديل خيارات العنصر item المحدد. إذا لم يتم تحديد -option، فإنه يعيد قاموسًا من أزواج الخيار/القيمة. إذا تم تحديد -option واحد، فإنه يعيد قيمة هذا الخيار. بخلاف ذلك، يتم تحديث خيارات العنصر بالقيم المحددة. انظر ITEM OPTIONS لقائمة الخيارات المتاحة.
pathname move item parent index
ينقل item إلى الموضع index في قائمة أطفال parent. يُمنع نقل عنصر تحت أحد أحفاده.

إذا كان index أقل من أو يساوي الصفر، يتم نقل item إلى البداية؛ إذا كان أكبر من أو يساوي عدد الأطفال، يتم نقله إلى النهاية.

pathname next item
يعيد معرف الأخ التالي لـ item، أو {} إذا كان item هو الطفل الأخير لوالده.
pathname parent item
يعيد معرف الأصل لـ item، أو {} إذا كان item على المستوى الأعلى من التسلسل الهرمي.
pathname prev item
يعيد معرف الأخ السابق لـ item، أو {} إذا كان item هو الطفل الأول لوالده.
pathname see item
يضمن أن item مرئي: يضبط جميع الأسلاف لـ item على -open true، ويقوم بالتمرير إذا لزم الأمر بحيث يكون item ضمن الجزء المرئي من الشجرة.
pathname selection ?selop itemList?
إذا لم يتم تحديد selop، فإنه يعيد قائمة بالعناصر المحددة. بخلاف ذلك، selop هو أحد الخيارات التالية:
pathname selection set itemList
itemList تصبح التحديد الجديد.
pathname selection add itemList
إضافة itemList إلى التحديد.
pathname selection remove itemList
إزالة itemList من التحديد.
pathname selection toggle itemList
تبديل حالة تحديد كل عنصر في itemList.
pathname set item ?column? ?value?
مع وسيط واحد، يعيد قاموسًا لأزواج العمود/القيمة للعنصر item المحدد. مع وسيطين، يعيد القيمة الحالية للعمود column المحدد. مع ثلاثة وسائط، يقوم بتعيين قيمة العمود column في العنصر item إلى value المحدد. انظر أيضًا COLUMN IDENTIFIERS.
pathname state ?stateSpec?
تعديل أو استعلام حالة الأداة؛ انظر ttk::widget(n).
pathName tag args...
pathName tag bind tagName ?sequence? ?script?
إضافة برنامج نصي لربط Tk لتسلسل الأحداث sequence إلى العلامة tagName. عند تسليم حدث X إلى عنصر، يتم تقييم البرامج النصية للربط لكل -tags للعنصر بالترتيب وفقًا لـ bindtags(n).

<KeyPress>، <KeyRelease>، والأحداث الافتراضية يتم إرسالها إلى العنصر الذي تم التركيز عليه. الأحداث <ButtonPress>، <ButtonRelease>، و <Motion> يتم إرسالها إلى العنصر الموجود تحت مؤشر الماوس. لا يتم دعم أنواع الأحداث الأخرى.

يتم إجراء استبدالات % على ربط script قبل التقييم؛ انظر bind(n) للتفاصيل.

pathName tag configure tagName ?option? ?value option value...?
استعلام أو تعديل خيارات العلامة tagName المحددة. إذا تم تحديد زوج واحد أو أكثر من option/value، فإنه يعين قيمة هذه الخيارات للعلامة المحددة. إذا تم تحديد option واحد، فإنه يعيد قيمة هذا الخيار (أو سلسلة فارغة إذا لم يتم تحديد الخيار لـ tagName). بدون وسائط إضافية، يعيد قاموسًا لإعدادات الخيارات لـ tagName. انظر TAG OPTIONS لقائمة الخيارات المتاحة.
pathName tag has tagName ?item?
إذا تم تحديد item، فإنه يعيد 1 أو 0 اعتمادًا على ما إذا كان العنصر المحدد لديه العلامة المسماة. بخلاف ذلك، فإنه يعيد قائمة بجميع العناصر التي لديها العلامة المحددة.
pathName tag names
يعيد قائمة بجميع العلامات المستخدمة بواسطة الأداة.
pathName tag add tag items
يضيف العلامة tag المحددة إلى كل عنصر من items المحددة. إذا كانت tag موجودة بالفعل لعنصر معين، فإن -tags لهذا العنصر لا تتغير.
pathName tag remove tag ?items?
يزيل العلامة tag المحددة من كل عنصر من items المحددة. إذا تم حذف items، فإنه يزيل tag من كل عنصر في الشجرة. إذا لم تكن tag موجودة لعنصر معين، فإن -tags لهذا العنصر
