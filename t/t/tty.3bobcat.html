tty.3bobcat

الحزمة: libbobcat

التراخيص: GPL

FBB::Tty(3bobcat) التحكم في طباعة الأحرف FBB::Tty(3bobcat)

الاسم

FBB::Tty - التحكم في طباعة الأحرف المدخلة في الطرفية

الملخص

#include <bobcat/tty>
خيار الربط: -lbobcat

الوصف

يمكن استخدام كائنات Tty(3bobcat) للتحكم في طباعة الأحرف المدخلة في الطرفية (عادةً في /dev/tty). تتيح القراءة المباشرة من /dev/tty للبرامج قراءة المعلومات (على سبيل المثال، كلمات المرور أو عبارات المرور) حتى لو تم إعادة توجيه دفق الإدخال القياسي إلى ملف. ما لم يتم إعادة توجيهه، يتم توصيل std::cin بـ /dev/tty.

يمكن استخدام كائنات Tty(3bobcat) ككائنات مستقلة أو (عادةً كائنات غير مسماة) يمكن إدراج كائنات Tty(3bobcat) في دفق أو استخراجها منه. عند إدراج الكائنات أو استخراجها، لا تتأثر الدفقات المعنية؛ فقط تتم معالجة طباعة الأحرف المدخلة في /dev/tty.

لا يعيد مُدمِر Tty(3bobcat) حالة طباعة /dev/tty إلى قيمتها الأصلية. إذا كان ذلك مطلوبًا، فيجب إنشاء كائن Tty(3bobcat) أولاً، واستدعاء عضوه echo(Tty::RESET) في الوقت المناسب.

التعداد

يطلب enum EchoType نوع معالجة الطباعة:

o
RESET يُستخدم لإعادة حالة /dev/tty إلى الحالة الفعلية عند إنشاء كائن Tty(3bobcat)
o
ON يُستخدم لتنشيط طباعة الأحرف المدخلة في /dev/tty.
o
OFF يُستخدم لقمع طباعة الأحرف المدخلة في /dev/tty.

المنشئات

o
Tty():
يتم حفظ الحالة الحالية لـ /dev/tty.
o
Tty(EchoType type):
يتم حفظ الحالة الحالية لـ /dev/tty، ويتم استدعاء عضو الكائن echo(type).

منشئات النسخ والتحريك (وعوامل التعيين) متاحة.

عوامل التشغيل المُعاد تحميلها

o
std::istream &operator>>(std::istream &in, Tty const &tty):
لا يؤثر عامل الاستخراج على in، ولكن يتم تعيين حالة /dev/tty وفقًا لطريقة إنشاء كائن tty.
o
std::ostream &operator<<(std::ostream &out, Tty const &tty):
لا يؤثر عامل الإدراج على out، ولكن يتم تعيين حالة /dev/tty وفقًا لطريقة إنشاء كائن tty.

دالة العضو

o
echo(EchoType type):
يتم تعيين حالة /Dev/tty وفقًا لقيمة EchoType التي يتم تمريرها إلى هذا العضو.

مثال

#include <iostream>
#include <string>
#include <bobcat/tty>
using namespace std;
using namespace FBB;
int main()
{
    cout << "Enter some text (not echoed): " << Tty(Tty::OFF);
    string line;
    getline(cin, line);
    cout << "\n"
            "You entered: `" << line << "’\n";
    cout << "Enter some text (echoed): ";
    getline(cin >> Tty(Tty::ON), line);
    cout << "You entered: `" << line << "’\n";
}
