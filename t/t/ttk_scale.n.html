ttk_scale(n)

الحزمة: tk

التراخيص: TCL

ttk::scale(n) Tk Themed Widget ttk::scale(n)

الاسم

ttk::scale - إنشاء والتحكم في عنصر واجهة مستخدم منزلقة

ملخص

ttk::scale pathName ?options...?

الوصف

يُستخدم عنصر واجهة المستخدم ttk::scale عادةً للتحكم في القيمة الرقمية لمتغير مرتبط يتغير بشكل موحد عبر نطاق معين. تعرض المنزلقة *منزلقة* يمكن تحريكها على طول *مسار*، مع الإشارة إلى الموضع النسبي للمنزلقة فوق المسار إلى قيمة المتغير.

خيارات قياسية

-class	-cursor	-style
-takefocus

راجع صفحة دليل ttk_widget لمعرفة التفاصيل حول الخيارات القياسية.

خيارات خاصة بالعنصر

اسم سطر الأوامر:	-command
اسم قاعدة البيانات:	command
فئة قاعدة البيانات:	Command
يحدد البادئة لأمر Tcl الذي سيتم استدعاؤه كلما تم تغيير قيمة المنزلقة عبر أمر العنصر. يتكون الأمر الفعلي من هذا الخيار متبوعًا بمسافة ورقم حقيقي يشير إلى القيمة الجديدة للمنزلقة.
اسم سطر الأوامر:	-from
اسم قاعدة البيانات:	from
فئة قاعدة البيانات:	From
قيمة حقيقية مقابلة للطرف الأيسر أو العلوي للمنزلقة.
اسم سطر الأوامر:	-length
اسم قاعدة البيانات:	length
فئة قاعدة البيانات:	Length
يحدد البعد الطويل المطلوب للمنزلقة بوحدات الشاشة (أي أي شكل من الأشكال التي يمكن قبولها بواسطة Tk_GetPixels). بالنسبة للمنزلقات الرأسية، يكون هذا هو ارتفاع المنزلقة؛ بالنسبة للمنزلقات الأفقية، يكون هذا هو عرض المنزلقة.
اسم سطر الأوامر:	-orient
اسم قاعدة البيانات:	orient
فئة قاعدة البيانات:	Orient
يحدد اتجاه ترتيب العنصر، سواء كان أفقيًا أو رأسيًا. يجب أن يكون إما horizontal أو vertical أو اختصارًا لأحدهما.
اسم سطر الأوامر:	-to
اسم قاعدة البيانات:	to
فئة قاعدة البيانات:	To
يحدد قيمة حقيقية مقابلة للطرف الأيمن أو السفلي للمنزلقة. قد تكون هذه القيمة أقل من أو أكبر من الخيار -from.
اسم سطر الأوامر:	-value
اسم قاعدة البيانات:	value
فئة قاعدة البيانات:	Value
يحدد القيمة العشرية الحالية للمتغير. إذا تم تعيين -variable إلى متغير موجود، فإن تحديد -value ليس له تأثير (قيمة المتغير لها الأسبقية).
اسم سطر الأوامر:	-variable
اسم قاعدة البيانات:	variable
فئة قاعدة البيانات:	Variable
يحدد اسم متغير عام لربطه بالمنزلقة. كلما تغيرت قيمة المتغير، ستتحدث المنزلقة لتعكس هذه القيمة. كلما تم التلاعب بالمنزلقة تفاعليًا، سيتم تعديل المتغير ليعكس القيمة الجديدة للمنزلقة.

أمر العنصر

pathName cget option
يُرجع القيمة الحالية للخيار المحدد option؛ راجع ttk::widget(n).
pathName configure ?option? ?value option value ...?
تعديل أو الاستعلام عن خيارات العنصر؛ راجع ttk::widget(n).
pathName get ?x y?
احصل على القيمة الحالية للخيار -value، أو القيمة المقابلة للإحداثيات x,y إذا تم تحديدها. X و y هما إحداثيات البكسل بالنسبة إلى أصل عنصر المنزلقة.
pathName identify x y
يُرجع اسم العنصر في الموضع x، y. راجع ttk::widget(n).
pathName instate statespec ?script?
اختبار حالة العنصر؛ راجع ttk::widget(n).
pathName set value
تعيين قيمة العنصر (أي الخيار -value) إلى value. سيتم قص القيمة إلى النطاق المعطى بواسطة الخيارين -from و -to. لاحظ أن تعيين المتغير المرتبط (أي المتغير المسمى في الخيار -variable) لا يتسبب في قص مماثل.
pathName state ?stateSpec?
تعديل أو الاستعلام عن حالة العنصر؛ راجع ttk::widget(n).

أوامر داخلية

pathName coords ?value?
الحصول على الإحداثيات المقابلة لـ value، أو الإحداثيات المقابلة للقيمة الحالية للخيار -value إذا تم تجاهل value.

خيارات التنميق

اسم فئة ttk::scale هو TScale.

الحالات الديناميكية: active.

خيارات تنميق TScale القابلة للتكوين باستخدام ttk::style هي:

-background color
-borderwidth amount
-darkcolor color
-groovewidth amount
-lightcolor color
-sliderwidth amount
-troughcolor color
-troughrelief relief

بعض الخيارات متاحة فقط لسمات معينة.

راجع صفحة دليل ttk::style لمعرفة معلومات حول كيفية تكوين سمات ttk.
