ttk::intro(n) Tk Themed Widget ttk::intro(n)

الاسم

ttk::intro - مقدمة لمحرك سمات Tk

نظرة عامة

مجموعة سمات Tk المستندة إلى نسخة محسنة ومنقحة من TIP #48 (https://tip.tcl-lang.org/48) محرك الأنماط المحدد. المفاهيم الأساسية موضحة أدناه. الفكرة الأساسية هي فصل، إلى أقصى حد ممكن، الشفرة التي تنفذ سلوك أداة (widget) عن الشفرة التي تنفذ مظهرها. تتولى ربطات فئة الأداة بشكل أساسي مسؤولية الحفاظ على حالة الأداة واستدعاء الدوال الراجعة؛ جميع جوانب مظهر الأداة تتحكم بها سمة الأداة (أي، سمة عناصر الأداة).

السمات

السمة هي مجموعة من العناصر والأنماط التي تحدد شكل وأسلوب مجموعة الأدوات. يمكن استخدام السمات لـ:

  • عزل اختلافات النظام الأساسي (X11 مقابل Windows الكلاسيكي مقابل XP مقابل Aqua ...)
  • التكيف مع قيود العرض (ألوان منخفضة، تدرج رمادي، أحادية اللون، شاشات صغيرة)
  • إمكانية الوصول (تباين عالي، خط كبير)
  • علامة تجارية لمجموعة التطبيقات
  • الاندماج مع بقية سطح المكتب (Gnome، KDE، Java)
  • وبالطبع: الرسوميات الجذابة.

العناصر

العنصر يعرض جزءًا فرديًا من الأداة. على سبيل المثال، تحتوي أداة شريط التمرير العمودي على عناصر uparrow و downarrow و trough و slider.

تستخدم أسماء العناصر تدوينًا نقطيًا متكررًا. على سبيل المثال، uparrow تحدد عنصر سهم عام، بينما Scrollbar.uparrow و Combobox.uparrow تحدد عناصر خاصة بالأدوات. عند البحث عن عنصر، يبحث محرك الأنماط عن الاسم المحدد أولاً، وإذا لم يتم العثور على عنصر بهذا الاسم، فإنه يبحث عن عناصر عامة عن طريق إزالة مكونات بادئة متتالية من اسم العنصر.

مثل الأدوات، للعناصر خيارات تحدد ما يتم عرضه وكيفية عرضه. على سبيل المثال، يحتوي العنصر text (الذي يعرض سلسلة نصية) على خيارات -text و -font و -foreground و -background و -underline و -width. يتم أخذ قيمة خيار العنصر من (بترتيب الأسبقية):

  • خيار بنفس الاسم والنوع في الأداة التي تحتوي على العنصر؛
  • إعداد ديناميكي تم تحديده بواسطة style map والحالة الحالية؛
  • الإعداد الافتراضي المحدد بواسطة style configure؛ أو
  • القيمة الافتراضية للعنصر المضمنة لهذا الخيار.

التخطيطات

التخطيط يحدد العناصر التي تتكون منها الأداة وكيفية ترتيبها. يستخدم محرك التخطيط نسخة مبسطة من خوارزمية pack: بدءًا من تجويف أولي يساوي حجم الأداة، يتم تخصيص قطعة للعناصر داخل التجويف على الجانب المحدد بواسطة خيار -side، ويتم وضعها داخل القطعة وفقًا لخيار -sticky. على سبيل المثال، تخطيط شريط التمرير الأفقي هو:

ttk::style layout Horizontal.TScrollbar {
    Scrollbar.trough -children {
	Scrollbar.leftarrow -side left -sticky w
	Scrollbar.rightarrow -side right -sticky e
	Scrollbar.thumb -sticky ew
    }
}

افتراضيًا، يكون تخطيط الأداة هو نفس اسمها الفئوي. قد تتجاوز بعض الأدوات ذلك (على سبيل المثال، تختار أداة ttk::scrollbar تخطيطات مختلفة بناءً على خيار -orient).

الحالات

في Tk القياسي، تحتوي العديد من الأدوات على خيار -state والذي يكون (في معظم الحالات) إما normal أو disabled. تدعم بعض الأدوات حالات إضافية، مثل أداة entry التي تحتوي على حالة readonly والنكهات المختلفة للأزرار التي تحتوي على حالة active.

تُعمم مجموعة سمات Tk هذه الفكرة: كل أداة تحتوي على خريطة بتات من علامات الحالة المستقلة. تشمل علامات حالة الأداة active و disabled و pressed و focus، وما إلى ذلك (انظر ttk::widget(n) للحصول على القائمة الكاملة لعلامات الحالة).

بدلاً من خيار -state، تحتوي كل أداة الآن على أمر أداة state يُستخدم لتعيين أو الاستعلام عن الحالة. مواصفات الحالة هي قائمة بأسماء حالات رمزية تشير إلى البتات التي تم تعيينها، كل منها مسبوق اختياريًا بعلامة تعجب تشير إلى أنه تم مسح البت بدلاً من ذلك.

على سبيل المثال، ربطات الفئة لأداة ttk::button هي:

bind TButton <Enter>		{ %W state active }
bind TButton <Leave>		{ %W state !active }
bind TButton <ButtonPress-1>	{ %W state pressed }
bind TButton <Button1-Leave>	{ %W state !pressed }
bind TButton <Button1-Enter>	{ %W state pressed }
bind TButton <ButtonRelease-1>	\
    { %W instate {pressed} { %W state !pressed ; %W invoke } }

هذا يحدد أن الأداة تصبح active عند دخول المؤشر إلى الأداة، وغير نشطة عند مغادرتها. وبالمثل، تصبح pressed عند الضغط على زر الماوس، و !pressed عند حدث ButtonRelease. بالإضافة إلى ذلك، يتم إلغاء الضغط على الزر إذا تم سحب المؤشر خارج الأداة أثناء الضغط على Button-1، وإعادة الضغط عليه إذا تم سحبه مرة أخرى. أخيرًا، عند تحرير زر الماوس، يتم استدعاء -command الخاص بالأداة، ولكن فقط إذا كانت الأداة حاليًا في حالة pressed. (الربطات الفعلية أكثر تعقيدًا قليلاً من الربطات أعلاه، ولكن ليس بكثير).

الأنماط

ترتبط كل أداة بـ نمط، والذي يحدد القيم لخيارات العناصر. تستخدم أسماء الأنماط تدوينًا نقطيًا متكررًا مثل التخطيطات والعناصر؛ افتراضيًا، تستخدم الأدوات اسم الفئة للبحث عن نمط في السمة الحالية. على سبيل المثال:

ttk::style configure TButton \
	-background #d9d9d9 \
	-foreground black \
	-relief raised \
	;

تُعرض العديد من العناصر بشكل مختلف اعتمادًا على حالة الأداة. على سبيل المثال، الأزرار لها خلفية مختلفة عندما تكون نشطة، وواجهة أمامية مختلفة عند تعطيلها، وتخفيف مختلف عند الضغط عليها. يحدد أمر style map إعدادات خيارات ديناميكية لنمط معين:

ttk::style map TButton \
	-background [list disabled #d9d9d9  active #ececec] \
	-foreground [list disabled #a3a3a3] \
	-relief [list {pressed !disabled} sunken] \
	;
