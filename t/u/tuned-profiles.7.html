NAME

tuned-profiles - tuning profiles for the tuned daemon

DESCRIPTION

The tuned(8) daemon uses a set of tuning profiles to adjust system settings in order to optimize the system for specific workloads or scenarios.

These profiles are typically stored in the /usr/lib/tuned/ directory and may also be specified by the user in /etc/tuned/.

Each profile is a directory containing a tuned.conf file which specifies the tuning directives. These directives can cover a wide range of system aspects, including CPU affinity, memory management, disk I/O, network settings, and more.

The tuned(8) daemon reads these profiles and applies the specified settings to optimize the system.

PROFILES

The following tuning profiles are available by default:

balanced
A general-purpose profile that balances performance and power saving.
desktop
Optimized for desktop usage, prioritizing responsiveness.
latency-performance
A profile focused on minimizing latency, often for real-time applications.
network-latency
Optimized for network latency-sensitive workloads.
network-throughput
Optimized for network throughput-sensitive workloads.
optimize-serial-console
Tuning for systems heavily relying on serial console access.
powersave
A profile that prioritizes power saving over performance.
throughput-performance
A profile focused on maximizing throughput, often for batch processing.
virtual-guest
Optimized for running as a virtual machine guest.
virtual-host
Optimized for running as a virtual machine host.

Users can create custom profiles in /etc/tuned/ by copying and modifying existing profiles or creating new ones.

FILES

/usr/lib/tuned/
Default directory for system-wide tuning profiles.
/etc/tuned/
Directory for custom user-defined tuning profiles and overrides.
/usr/lib/tuned/tuned.conf
The main configuration file for a tuning profile.
