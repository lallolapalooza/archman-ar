turnadmin(1)

الحزمة: coturn

التراخيص: BSD

TURN(1) TURN(1)

معلومات عامة

turnadmin هي أداة لإدارة TURN. يمكن استخدام هذه الأداة لإدارة حسابات المستخدمين (إضافة/إزالة المستخدمين، توليد مفاتيح TURN للمستخدمين). لأسباب أمنية، لا نوصي بتخزين كلمات المرور بشكل مفتوح. الخيار الأفضل هو استخدام "مفاتيح" معالجة مسبقًا والتي تستخدم بعد ذلك للمصادقة. يتم إنشاء هذه المفاتيح بواسطة turnadmin. turnadmin هو رابط لبرنامج turnserver الثنائي، لكن turnadmin يؤدي وظائف مختلفة.

ملاحظة الخيارات: turnadmin لديه أسماء خيارات طويلة وقصيرة، لمعظم الخيارات. بعض الخيارات لها صيغة طويلة فقط، وبعض الخيارات لها صيغة قصيرة فقط. تركيبتها تختلف قليلاً، إذا كان الوسيط مطلوبًا:

يجب استخدام الصيغة القصيرة على هذا النحو (على سبيل المثال):

  $ turnadmin -u <اسم المستخدم> ...
يجب استخدام الصيغة الطويلة المكافئة مع الحرف "=": 
  $ turnadmin --user=<اسم المستخدم> ...
إذا كان هذا خيار علامة (لا يلزم وسيط) فإن استخداماتهما متماثلة، على سبيل المثال: 
 $ turnadmin -k ...
يعادل: 
 $ turnadmin --key ...
يجب عليك دائمًا استخدام الخيار -r <النطاق> مع أوامر بيانات الاعتماد طويلة الأجل - لأنه يمكن تخزين البيانات لنطاقات متعددة في نفس قاعدة البيانات.

=====================================

الاسم

turnadmin - أداة إدارة وكيل TURN.

الملخص

$ turnadmin [الأمر] [خيارات]
$ turnadmin [ -h | --help]

الوصف

الأوامر:

-P, --generate-encrypted-password
توليد وطباعة شكل مشفر لكلمة المرور إلى الإخراج القياسي (لمستخدم مسؤول الويب أو واجهة سطر الأوامر). يمكن استخدام القيمة بعد ذلك كمفتاح آمن لتخزين كلمة المرور على القرص أو في قاعدة البيانات. كل استدعاء لنفس كلمة المرور ينتج نتيجة مختلفة. تنسيق كلمة المرور المشفرة هو: $5$<...الملح...>$<...sha256(الملح+كلمة المرور)...>. الملح هو 16 حرفًا، وإخراج sha256 هو 64 حرفًا. الحرف 5 هو معرف الخوارزمية (sha256). يتم دعم sha256 فقط كوظيفة تجزئة.
-k, --key
توليد مفتاح لمستخدم آلية بيانات الاعتماد طويلة الأجل.
-a, --add
إضافة أو تحديث مستخدم طويل الأجل.
-A, --add-admin
إضافة أو تحديث مستخدم مسؤول.
-d, --delete
حذف مستخدم طويل الأجل.
-D, --delete-admin
حذف مسؤول.
-l, --list
سرد المستخدمين طويل الأجل في قاعدة البيانات.
-L, --list-admin
سرد المسؤولين في قاعدة البيانات.

-s, --set-secret=<قيمة> إضافة سر مشترك لواجهة برمجة تطبيقات TURN REST

-S, --show-secret
عرض الأسرار المشتركة المخزنة لواجهة برمجة تطبيقات TURN REST

-X, --delete-secret=<قيمة> حذف سر مشترك.

--delete-all_secrets
حذف جميع الأسرار المشتركة لواجهة برمجة تطبيقات REST.
-O, --add-origin
إضافة علاقة منشأ إلى نطاق.
-R, --del-origin
حذف علاقة منشأ إلى نطاق.
-I, --list-origins
سرد علاقات المنشأ إلى النطاق.
-g, --set-realm-option
تعيين معلمات النطاق: max-bps، total-quota، user-quota.
-G, --list-realm-options
سرد معلمات النطاق.
-E, --generate-encrypted-password-aes
توليد وطباعة شكل مشفر لكلمة المرور باستخدام AES-128 إلى الإخراج القياسي

الخيارات ذات القيم المطلوبة:

-b, --db, --userdb
اسم ملف قاعدة بيانات مستخدمي SQLite (الافتراضي - /var/db/turndb أو /usr/local/var/db/turndb أو /var/lib/turn/turndb). انظر نفس الخيار في قسم turnserver.
-e, --psql-userdb
سلسلة اتصال قاعدة بيانات مستخدمي PostgreSQL. انظر الخيار --psql-userdb في قسم turnserver.
-M, --mysql-userdb
سلسلة اتصال قاعدة بيانات مستخدمي MySQL. انظر الخيار --mysql-userdb في قسم turnserver.
-J, --mongo-userdb
سلسلة اتصال قاعدة بيانات مستخدمي MongoDB. انظر الخيار --mysql-mongo في قسم turnserver.
-N, --redis-userdb
سلسلة اتصال قاعدة بيانات مستخدمي Redis. انظر الخيار --redis-userdb في قسم turnserver.
-u, --user
اسم المستخدم.
-r, --realm
النطاق.
-p, --password
كلمة المرور.
-x, --key-path
ينشئ مفتاح 128 بت في المسار المحدد.
-f, --file-key-path
يحتوي على مفتاح 128 بت في المسار المحدد.
-v, --verify
التحقق من كلمة مرور مشفرة base64 معينة.
-o, --origin
المنشأ
--max-bps
تعيين قيمة معلمة max-bps للنطاق.
--total-quota
تعيين قيمة معلمة total-quota للنطاق.
--user-quota
تعيين قيمة معلمة user-quota للنطاق.
-h, --help
مساعدة.

أمثلة الأوامر:

توليد شكل مشفر لكلمة مرور:

$ turnadmin -P -p <كلمة المرور>

توليد مفتاح:

$ turnadmin -k -u <اسم المستخدم> -r <النطاق> -p <كلمة المرور>

إضافة/تحديث مستخدم في قاعدة البيانات:

$ turnadmin -a [-b <ملف قاعدة بيانات المستخدم> | -e <سلسلة اتصال قاعدة البيانات> | -M <سلسلة اتصال قاعدة البيانات> | -N <سلسلة اتصال قاعدة البيانات> ] -u <اسم المستخدم> -r <النطاق> -p <كلمة المرور>

حذف مستخدم من قاعدة البيانات:

$ turnadmin -d [-b <ملف قاعدة بيانات المستخدم> | -e <سلسلة اتصال قاعدة البيانات> | -M <سلسلة اتصال قاعدة البيانات> | -N <سلسلة اتصال قاعدة البيانات> ] -u <اسم المستخدم> -r <النطاق>

سرد جميع المستخدمين طويل الأجل في قاعدة بيانات MySQL:

$ turnadmin -l --mysql-userdb="<سلسلة اتصال قاعدة البيانات>" -r <النطاق>

سرد جميع المسؤولين في قاعدة بيانات Redis:

$ turnadmin -L --redis-userdb="<سلسلة اتصال قاعدة البيانات>"

تعيين سر في قاعدة بيانات MySQL:

$ turnadmin -s <السر> --mysql-userdb="<سلسلة اتصال قاعدة البيانات>" -r <النطاق>

عرض السر المخزن في قاعدة بيانات PostgreSQL:

$ turnadmin -S --psql-userdb="<سلسلة اتصال قاعدة البيانات>" -r <realm>

تعيين علاقة الأصل بالمجال في قاعدة بيانات MySQL:

$ turnadmin --mysql-userdb="<db-connection-string>" -r <realm> -o <origin>

حذف علاقة الأصل بالمجال من قاعدة بيانات Redis:

$ turnadmin --redis-userdb="<db-connection-string>" -o <origin>

سرد جميع علاقات الأصل بالمجال في قاعدة بيانات Redis:

$ turnadmin --redis-userdb="<db-connection-string>" -I

سرد علاقات الأصل بالمجال في قاعدة بيانات PostgreSQL لمجال واحد:

$ turnadmin --psql-userdb="<db-connection-string>" -I -r <realm>

إنشاء ملف مفتاح جديد لتشفير كلمة مرور mysql:

$ turnadmin -E --key-path <key-file>

إنشاء كلمة مرور mysql مشفرة:

$ turnadmin -E --file-key-path <key-file> -p <secret>

التحقق/فك تشفير كلمة مرور مشفرة:

$ turnadmin --file-key-path <key-file> -v <encrypted>

المساعدة:

$ turnadmin -h
