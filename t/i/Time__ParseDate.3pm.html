Time__ParseDate(3pm)

الحزمة: perl-time-modules

التراخيص: GPL, PerlArtistic

Time::ParseDate(3) وثائق Perl المساهمة من المستخدم Time::ParseDate(3)

الاسم

Time::ParseDate -- تحليل التواريخ المطلقة والنسبية

الملخص

use Time::ParseDate;
$seconds_since_jan1_1970 = parsedate("12/11/94 2pm", NO_RELATIVE => 1)
$seconds_since_jan1_1970 = parsedate("12/11/94 2pm", %options)

خيارات

يمكن لتحليل التواريخ استخدام الخيارات أيضًا. الخيارات هي كما يلي:

FUZZY   -> لا بأس بعدم تحليل سلسلة التاريخ بأكملها
NOW     -> وقت "الحالي" للأوقات النسبية (الافتراضي هو time())
ZONE    -> المنطقة الزمنية المحلية (الافتراضي هو $ENV{TZ})
WHOLE   -> يجب تحليل سلسلة الإدخال بالكامل
GMT     -> يفترض أن وقت الإدخال هو GMT، وليس localtime
UK      -> تفضيل تنسيق التواريخ البريطاني (dd/mm بدلاً من mm/dd)
DATE_REQUIRED -> لا تفترض التاريخ
TIME_REQUIRED -> لا تفترض الوقت
NO_RELATIVE -> الوقت المدخل ليس نسبيًا لـ NOW
TIMEFIRST -> حاول تحليل الوقت قبل التاريخ [ليس الافتراضي]
PREFER_PAST -> عند غموض السنة أو يوم الأسبوع، افترض الماضي
PREFER_FUTURE -> عند غموض السنة أو يوم الأسبوع، افترض المستقبل
SUBSECOND -> تحليل أجزاء الثانية
VALIDATE -> اقبل فقط القيم العادية لـ HHMMSS، YYMMDD. بخلاف ذلك
        قد تعطي أيام مثل -1 اليوم الأخير من الشهر السابق.

الوصف

تتعرف هذه الوحدة على تنسيقات التاريخ/الوقت المذكورة أعلاه. عادةً ما يتم تحديد التاريخ والوقت. هناك العديد من الخيارات للتحكم فيما يتم التعرف عليه وما لا يتم التعرف عليه.

رمز الإرجاع هو دائمًا الوقت بالثواني منذ 1 يناير 1970 أو undef إذا لم يتمكن من تحليل الوقت.

إذا تم تحديد منطقة زمنية، فيجب أن تكون بعد الوقت. يمكن إلحاق مواصفات السنة بنهاية الأوقات المطلقة.

إذا تم استدعاء parsedate() من سياق مصفوفة، فستقوم بإرجاع عنصرين. عند التحليل الناجح، ستعيد الثواني وما تبقى من سلسلة الإدخال الخاصة بها. عند التحليل غير الناجح، ستعيد "undef" وسلسلة خطأ.

أمثلة

$seconds = parsedate("Mon Jan  2 04:24:27 1995");
$seconds = parsedate("Tue Apr 4 00:22:12 PDT 1995");
$seconds = parsedate("04.04.95 00:22", ZONE => PDT);
$seconds = parsedate("Jan 1 1999 11:23:34.578", SUBSECOND => 1);
$seconds = parsedate("122212 950404", ZONE => PDT, TIMEFIRST => 1);
$seconds = parsedate("+3 secs", NOW => 796978800);
$seconds = parsedate("2 months", NOW => 796720932);
$seconds = parsedate("last Tuesday");
$seconds = parsedate("Sunday before last");
($seconds, $remaining) = parsedate("today is the day");
($seconds, $error) = parsedate("today is", WHOLE=>1);
