timespec_get(3) دليل وظائف المكتبة timespec_get(3)

الاسم

timespec_get, timespec_getres - واجهة ISO C لوظائف الساعة والوقت

المكتبة

مكتبة C القياسية (libc, -lc)،

الملخص

#include <time.h>
int timespec_get(struct timespec *res, int base);
int timespec_getres(struct timespec *tp, int base);

الوصف

تقوم الدالة timespec_get() بتخزين الوقت الحالي، بناءً على قاعدة الوقت المحددة، في الهيكل timespec(3type) الذي تشير إليه res.

تقوم الدالة timespec_getres() بتخزين دقة الأوقات التي يتم استردادها بواسطة timespec_get() مع قاعدة الوقت المحددة في الهيكل timespec(3type) الذي تشير إليه tp، إذا كانت tp غير NULL. بالنسبة لقاعدة وقت معينة، تكون الدقة ثابتة طوال فترة حياة العملية المستدعية.

TIME_UTC هي دائمًا قاعدة وقت مدعومة، وهي قاعدة الوقت الوحيدة المدعومة على Linux. الوقت والدقة في قاعدة الوقت هذه متماثلان مع تلك التي يتم استردادها بواسطة clock_gettime(CLOCK_REALTIME, res) و clock_getres(CLOCK_REALTIME, tp)، على التوالي. قد تدعم الأنظمة الأخرى قواعد وقت إضافية.

قيمة الإرجاع

تُرجع الدالة timespec_get() القيمة base غير الصفرية إذا كانت قاعدة وقت مدعومة وتم استرداد الوقت الحالي بنجاح، أو 0 بخلاف ذلك.

تُرجع الدالة timespec_getres() القيمة base غير الصفرية إذا كانت قاعدة وقت مدعومة، أو 0 بخلاف ذلك.
