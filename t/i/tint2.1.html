    إجراءات الماوس لأزرار شريط المهام

    الأحداث الممكنة للماوس هي: left, middle, right, scroll_up, scroll_down.

    الإجراءات الممكنة للماوس هي: none, close, toggle, iconify, shade, toggle_iconify, maximize_restore, desktop_left, desktop_right, next_task, prev_task.

    استخدم mouse_event = action لتخصيص إجراءات الماوس. مثال:
    mouse_middle = none
    mouse_right = close
    mouse_scroll_up = toggle
    mouse_scroll_down = iconify

    دلالات الإجراء:
    * none : إذا تم تعيين wm_menu = 1، يتم تمرير حدث الماوس إلى مدير النوافذ. بخلاف ذلك يتم تجاهله. * close : إغلاق المهمة * toggle : تبديل المهمة * iconify : تصغير (تقليل) المهمة * toggle_iconify : تبديل أو تصغير المهمة * maximize_restore : تكبير أو تقليل المهمة * shade : تظليل (طي) المهمة * desktop_left : إرسال المهمة إلى سطح المكتب على اليسار * desktop_right : إرسال المهمة إلى سطح المكتب على اليمين * next_task : إرسال التركيز إلى المهمة التالية * prev_task : إرسال التركيز إلى المهمة السابقة

    • execp_centered = boolean (0 or 1) : ما إذا كان سيتم توسيط النص. (منذ 0.12.4)
    • execp_padding = horizontal_padding vertical_padding spacing_between_icon_and_text (منذ 0.12.4)
    • execp_monitor = integer (1, 2, ...), primary or all : على أي شاشة سيتم رسم المنفذ. الشاشة الأولى هي 1. (منذ 17.0)
    • execp_lclick_command = text : الأمر الذي سيتم تنفيذه عند النقر بالزر الأيسر. إذا لم يتم تعريفه، يتم تنفيذ execp_command فورًا، ما لم يكن قيد التشغيل حاليًا. (منذ 0.12.4)
    • execp_mclick_command = text : الأمر الذي سيتم تنفيذه عند النقر بالزر الأوسط. إذا لم يتم تعريفه، يتم تنفيذ execp_command فورًا، ما لم يكن قيد التشغيل حاليًا. (منذ 0.12.4)
    • execp_rclick_command = text : الأمر الذي سيتم تنفيذه عند النقر بالزر الأيمن. إذا لم يتم تعريفه، يتم تنفيذ execp_command فورًا، ما لم يكن قيد التشغيل حاليًا. (منذ 0.12.4)
    • execp_uwheel_command = text : الأمر الذي سيتم تنفيذه عند تمرير عجلة الماوس للأعلى. إذا لم يتم تعريفه، يتم تنفيذ execp_command فورًا، ما لم يكن قيد التشغيل حاليًا. (منذ 0.12.4)
    • execp_dwheel_command = text : الأمر الذي سيتم تنفيذه عند تمرير عجلة الماوس للأسفل. إذا لم يتم تعريفه، يتم تنفيذ execp_command فورًا، ما لم يكن قيد التشغيل حاليًا. (منذ 0.12.4)

    tint2(1)

    الحزمة: tint2

    التراخيص: GPL-2.0-only

    NAME

    tint2 - a simple panel/taskbar for modern X11 desktops

    DESCRIPTION

    tint2 is a lightweight, highly configurable panel and taskbar for Linux.

    SYNOPSIS

    tint2 [-c file] [-p]

    OPTIONS

    -c file
    Use file instead of the default configuration file (~/.config/tint2/tint2rc or /etc/xdg/tint2/tint2rc).
    -p
    Print the default configuration file to stdout and exit.

    CONFIGURATION

    tint2 is configured via a configuration file, which is typically located at ~/.config/tint2/tint2rc. If this file does not exist, tint2 will look for /etc/xdg/tint2/tint2rc. The configuration file uses a simple key-value format, with comments starting with '#'.

    Below are some common configuration options:

    General Settings

    # The panel's position and size.
panel_position = bottom center horizontal
panel_size = 100% 30

# The panel's background.
panel_background_id = 1

# Whether to show the panel when the desktop is empty.
panel_show_iconbar = 1

# The margin around the panel.
panel_margin = 0 0

# The padding inside the panel.
panel_padding = 5 5 5

# The font used for panel items.
font_face = sans

# The font size.
font_size = 9

# The font color.
font_color = #ffffff 100

# Whether to enable transparency.
transparent = 1

# The transparency level.
alpha = 75

# Whether to show a border around the panel.
border_width = 1
border_color = #000000 100
border_radius = 5

    Taskbar Buttons

    # The taskbar configuration.
taskbar_mode = widgets
taskbar_name = taskbar

# The alignment of the taskbar buttons.
taskbar_align = left

# The spacing between taskbar buttons.
taskbar_padding = 2 5 2
taskbar_icon_padding = 4 4
taskbar_icon_size = 16

# The style of the taskbar buttons.
taskbar_style = flat

# The font color for active and inactive windows.
taskbar_active_color = #77aaff 100
taskbar_inactive_color = #aaaaaa 100

# The tooltip for taskbar buttons.
taskbar_tooltip = 1

    Clock Settings

    # Clock configuration.
clock_enabled = true
clock_font_color = #ffffff 100
clock_tooltip = Show Date
clock_lclick_command = zenity --calendar
clock_font = sans 8
clock_format = %H:%M:%S
clock_padding = 2 2 2

    System Tray Settings

    # System tray configuration.
systray_enabled = true
systray_padding = 2 2 2

    Launcher Settings

    # Launcher configuration.
launcher_enabled = true
launcher_item_text = 1
launcher_item_icon = 1
launcher_icon_size = 16
launcher_padding = 2 2 6
launcher_background_id = 0
launcher_lclick_command[1] = xdg-open $HOME
launcher_icon[1] = /usr/share/icons/Adwaita/16x16/actions/document-open.png
launcher_tooltip[1] = Open Home Directory

    Button with icon and rich text, executes command when clicked

    execp = new
execp_command = echo /usr/share/icons/elementary-xfce/emblems/24/emblem-colors-blue.png; echo '<span foreground="#7f7">Click</span> <span foreground="#77f">me</span> <span foreground="#f77">pls</span>'
execp_has_icon = 1
execp_interval = 0
execp_centered = 1
execp_font = sans 9
execp_markup = 1
execp_font_color = #aaffaa 100
execp_padding = 2 0
execp_tooltip = I will tell you a secret...
execp_lclick_command = zenity --info "--text=$(uname -sr)"
execp_background_id = 2

    Desktop pager with text

    execp = new
execp_command = xprop -root -spy | awk '/^_NET_CURRENT_DESKTOP/ { print "Workspace " ($3 + 1) ; fflush(); }'
execp_interval = 1
execp_continuous = 1

    Desktop pager with icon

    execp_command = xprop -root -spy | awk -v home="$HOME" '/^_NET_CURRENT_DESKTOP/ { print home "/.config/myPager/" ($3 + 1) ".png\n" ; fflush(); }'
execp_interval = 1
execp_has_icon = 1
execp_cache_icon = 1
execp_continuous = 2

    Round-trip time to the gateway, refreshed every second

    execp = new
execp_command = ping -i 1 -c 1 -W 1 -O -D -n $(ip route | grep default | grep via | grep -o '[0-9]*\.[0-9]*\.[0-9]*\.[0-9]*') | awk '/no/ { print "<span foreground=\"#faa\">timeout</span>"; fflush(); }; /time=/ { gsub(/time=/, "", $8); printf "<span foreground=\"#7af\">%3.0f %s</span>\n", $8, $9; fflush(); } '
execp_continuous = 0
execp_interval = 1
execp_markup = 1

    Memory usage

    # Note the use of "stdbuf -oL" to force the program to flush the output line by line.
execp = new
execp_command = free -b -s1 | stdbuf -oL awk '/^Mem:/ { printf "Mem: %s %.0f%%\n", $2, 100 * ($2 - $7) / $2 }' | stdbuf -oL numfmt --to=iec-i --field=2 -d' '
execp_interval = 1
execp_continuous = 1

    Network load

    execp = new
execp_command = stdbuf -oL bwm-ng -o csv -t 1000 | stdbuf -oL awk -F ';' '/total/ { printf "Net: %.0f Mb/s\n", ($5*8/1.0e6) }'
execp_continuous = 1
execp_interval = 1

    Button

    • button = new : Begins the configuration of a new button. Multiple such plugins are supported; just use multiple Ps in panel_items. (since 0.14)
    • button_icon = text : Name or path of icon (or empty). (since 0.14)
    • button_text = text : Text to display (or empty). (since 0.14)
    • button_tooltip = text : The tooltip (or empty). (since 0.14)
    • button_font = [FAMILY-LIST] [STYLE-OPTIONS] [SIZE] : The font used to draw the text. (since 0.14)
    • button_font_color = color opacity : The font color. (since 0.14)
    • button_background_id = integer : Which background to use. (since 0.14)
    • button_centered = boolean (0 or 1) : Whether to center the text. (since 0.14)
    • button_padding = horizontal_padding vertical_padding spacing_between_icon_and_text (since 0.14)
    • button_max_icon_size = integer : Sets a limit to the icon size. Otherwise, the icon will expand to the edges. (since 0.14)
    • button_lclick_command = text : Command to execute on left click. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
    • button_mclick_command = text : Command to execute on right click. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
    • button_rclick_command = text : Command to execute on middle click. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
    • button_uwheel_command = text : Command to execute on wheel scroll up. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)
    • button_dwheel_command = text : Command to execute on wheel scroll down. If not defined, execp_command is executed immediately, unless it is currently running. (since 0.14)

    Separator

    • separator = new : Begins the configuration of a new separator. Multiple such plugins are supported; just use multiple :s in panel_items. (since 0.13.0)
    • separator_background_id = integer : Which background to use. (since 0.13.0)
    • separator_color = color opacity : The foreground color. (since 0.13.0)
    • separator_style = [empty | line | dots] : The separator style. (since 0.13.0)
    • separator_size = integer : The thickness of the separator. Does not include the border and padding. For example, if the style is line, this is the line thickness; if the style is dots, this is the dot's diameter. (since 0.13.0)
    • separator_padding = side_padding cap_padding : The padding to add to the sides of the separator, in pixels. (since 0.13.0)
