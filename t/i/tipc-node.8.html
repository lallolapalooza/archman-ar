tipc-node(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

tipc-node(8) لينكس tipc-node(8)

الاسم

tipc-node - تعديل وعرض معلمات العقدة المحلية أو قائمة العقد النظيرة

الشكل العام


tipc node set { address عنوان | netid معرف_شبكة }

tipc node get { address | netid }

tipc node list

الخيارات

الخيارات (العلامات) التي يمكن تمريرها في أي مكان في سلسلة الأوامر.

-h, --help

عرض المساعدة حول آخر أمر صالح. على سبيل المثال، tipc node --help سيعرض مساعدة العقدة، و tipc --help سيعرض المساعدة العامة. موضع الخيار في السلسلة غير ذي صلة.

الوصف

معلمات العقدة

address

العنوان المنطقي لـ TIPC. بالشكل x.y.z حيث x و y و z هي أعداد صحيحة غير موقعة.
netid

معرف الشبكة. يمكن استخدامه لإنشاء مجموعات TIPC فردية على نفس الوسائط.

حالة الخروج

حالة الخروج هي 0 إذا كان الأمر ناجحًا أو عددًا صحيحًا موجبًا عند الفشل.

انظر أيضا

tipc(8)، tipc-bearer(8)، tipc-link(8)، tipc-media(8)، tipc-nametable(8)، tipc-peer(8)، tipc-socket(8)

الإبلاغ عن الأخطاء

أبلغ عن أي أخطاء إلى قائمة المطورين لشبكة kernel <netdev@vger.kernel.org> حيث يتم إجراء التطوير والصيانة بشكل أساسي. لست بحاجة إلى الاشتراك في القائمة لإرسال رسالة إليها.
