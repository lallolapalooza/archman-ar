TIFFSETFIELD(3tiff) LibTIFF TIFFSETFIELD(3tiff)

الاسم

TIFFSetField - تعيين قيمة (قيم) علامة في ملف TIFF مفتوح للكتابة

الملخص

#include <tiffio.h>
#include <stdarg.h>
int TIFFSetField(TIFF *tif, ttag_t tag, ...)
int TIFFVSetField(TIFF *tif, ttag_t tag, va_list ap)
int TIFFUnsetField(TIFF *tif, uint32_t tag)

الوصف

TIFFSetField() تعيّن قيمة حقل أو علامة زائفة في الدليل الحالي المرتبط بملف TIFF المفتوح tif. (العلامة الزائفة هي معلمة تُستخدم للتحكم في عملية مكتبة TIFF ولكن لا يتم قراءة قيمتها أو كتابتها إلى الملف الأساسي.) لتعيين قيمة حقل، يجب أن يكون الملف قد تم فتحه مسبقًا للكتابة باستخدام TIFFOpen(). يمكن تعيين العلامات الزائفة سواء تم فتح الملف للقراءة أو الكتابة. يتم تحديد الحقل بواسطة tag، وهي إحدى القيم المعرفة في ملف التضمين tiff.h (انظر أيضًا الجدول أدناه). يتم تحديد القيمة الفعلية باستخدام قائمة وسائط متغيرة، كما هو محدد في واجهة stdarg.h.

TIFFVSetField() مكافئة وظيفيًا لـ TIFFSetField() باستثناء أنها تأخذ مؤشرًا إلى قائمة وسائط متغيرة. TIFFVSetField() مفيدة لكتابة الروتينات التي تستند إلى الوظائف التي توفرها TIFFSetField().

TIFFUnsetField() تمسح محتويات الحقل في الهيكل الداخلي. إذا كان حقلًا مخصصًا، فسيتم إزالته من قائمة العلامات المعروفة.

العلامات التي تفهمها libtiff، وعدد قيم الوسائط، وأنواع الوسائط المتوقعة موضحة أدناه. أنواع البيانات هي:

أنواع بيانات العلامات

النوع الوصف
char* سلسلة نصية منتهية بـ null تتوافق مع نوع بيانات ASCII
uint16_t قيمة 16 بت غير موقعة
uint32_t قيمة 32 بت غير موقعة؛
uint16_t* مصفوفة من قيم 16 بت غير موقعة.
void* مصفوفة من قيم البيانات من نوع غير محدد.

استشر مواصفات TIFF للحصول على معلومات حول معنى كل علامة.

قيم الإرجاع

تعيد TIFFSetField() و TIFFVSetField() القيمة 1 إذا تم تعيين الحقل بنجاح، و 0 إذا لم يتم التعرف على العلامة أو كان نوع الوسيط غير صحيح. تعيد TIFFUnsetField() القيمة 1 إذا تم مسح الحقل بنجاح، و 0 إذا لم يتم التعرف على العلامة.

TIFFSetField

libtiff — TIFF image file library

NAME

TIFFSetField — set a value for a TIFF tag

SYNOPSIS

#include <tiff.h>

int TIFFSetField(TIFF* tif, uint32_t tag, ...);

int TIFFSetField(TIFF* tif, uint32_t tag, va_list ap);

DESCRIPTION

An application uses TIFFSetField to set a tag’s value within the current directory of an open TIFF file. The tif argument is an open TIFF file descriptor. The tag argument is the table identifier of the tag to be set. The data to be written is passed as subsequent arguments using the standard C ... notation for variable-length argument lists, or as a va_list. The data type and interpretation of the arguments are determined by the tag’s data type and the library’s internal tag handling functions.

The va_list version of the function is useful when you need to write a number of tags, or when you want to pass structures or other complex data types as tag values. The library will automatically allocate memory for tag values that require it. However, for tags that require arrays of values, you are responsible for ensuring that the pointer passed points to initialised memory.

For a list of known tags, their data types, and their default values, consult the TIFF specification. The specification defines the meaning of each tag and how it relates to other tags in the image file header.

The library can automatically convert common data types (e.g., int to float), but it is generally best to pass values in the type specified in the TIFF specification to avoid unexpected results.

The library automatically manages the memory associated with tag values. When you set a tag that requires memory allocation (e.g., a string or an array), the library allocates the necessary memory. If you later set the same tag again, the old memory is freed and new memory is allocated. You are responsible for managing the memory of data that you pass to the library, such as arrays that you initialise yourself.

†:
Tag may not have its values changed once data is written.

‡:

If SamplesPerPixel is one, then a single array is passed; otherwise three arrays should be passed.
*:
The contents of this field are quite complex. See “The ICC Profile Format Specification”, Annex B.3 “Embedding ICC Profiles in TIFF Files” (available at http://www.color.org) for an explanation.

RETURN VALUES

1 is returned if the operation was successful. Otherwise, 0 is returned if an error was detected.

DIAGNOSTICS

All error messages are directed to the TIFFErrorExtR() routine.

%s: Cannot modify tag "%s" while writing:

Data has already been written to the file, so the specified tag’s value can not be changed. This restriction is applied to all tags that affect the format of written data.

%d: Bad value for "%s":

An invalid value was supplied for the named tag.
