TIOCSPGRP(2const) TIOCSPGRP(2const)

الاسم

TIOCGPGRP, TIOCSPGRP, TIOCGSID - معرف مجموعة العمليات والجلسة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <asm/termbits.h>  /* تعريف الثوابت TIOC* */
#include <sys/ioctl.h>
int ioctl(int fd, TIOCGPGRP, pid_t *argp);
int ioctl(int fd, TIOCSPGRP, const pid_t *argp);
int ioctl(int fd, TIOCGSID, pid_t *argp);

الوصف

TIOCGPGRP
عند النجاح، يكافئ *argp = tcgetpgrp(fd).
الحصول على معرف مجموعة العمليات لمجموعة العمليات الأمامية في هذا الطرفية.
TIOCSPGRP
يكافئ tcsetpgrp(fd, *argp).
تعيين معرف مجموعة العمليات الأمامية لهذه الطرفية.
TIOCGSID
عند النجاح، يكافئ *argp = tcgetsid(fd).
الحصول على معرف الجلسة للطرفية المعطاة. يفشل هذا بخطأ ENOTTY إذا لم تكن الطرفية طرفية زائفة رئيسية وليست طرفية التحكم الخاصة بنا. غريب.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

ENOTTY
الطرفية ليست طرفية زائفة رئيسية وليست طرفية التحكم الخاصة بنا.
EPERM
إذن غير كافٍ.

راجع أيضًا

ioctl(2)، ioctl_tty(2)، tcgetpgrp(3)، tcsetpgrp(3)، tcgetsid(3)
