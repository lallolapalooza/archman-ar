tipc(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

tipc(8) Linux tipc(8)

الاسم

tipc - أداة تكوين وإدارة TIPC

الموجز


tipc [ خيارات ] أمر وسائط

أمر := { bearer | link | media | nametable | node | socket }

خيارات := { -h[help] }

الوصف

يقدم بروتوكول الاتصال الشفاف بين العمليات (TIPC) شفافية عنوان كاملة بين العمليات مما يسمح للتطبيقات في بيئة حاسوب مجمعة بالتواصل بسرعة وموثوقية مع بعضها البعض، بغض النظر عن موقعها داخل المجموعة.

نشأت TIPC في شركة الاتصالات Ericsson. تم إنشاء الإصدار المفتوح المصدر الأول من TIPC في عام 2000 عندما أصدرت Ericsson أول إصدار Linux لها من TIPC. تم تقديم TIPC في نواة Linux الرئيسية في عام 2006 ويستخدم الآن على نطاق واسع داخل Ericsson وخارجها.

الخيارات

-h, --help
عرض المساعدة حول الأمر الذي تم إعطاؤه مؤخرًا. على سبيل المثال، tipc bearer --help سيظهر مساعدة الحامل، و tipc --help سيظهر مساعدة عامة. موقع الخيار في السلسلة غير مهم.
-j, -json
إخراج النتائج بتنسيق JavaScript Object Notation (JSON).
-p, -pretty
تنسيق JSON الافتراضي مدمج وأكثر كفاءة في التحليل ولكنه صعب القراءة لمعظم المستخدمين. يضيف هذا العلم مسافة بادئة للقراءة.

الأوامر

BEARER
- عرض أو تعديل حوامل TIPC
LINK
- عرض أو تعديل روابط TIPC
MEDIA
- عرض أو تعديل وسائط TIPC
NAMETABLE
- عرض جدول أسماء TIPC
NODE
- عرض أو تعديل معلمات عقدة TIPC
SOCKET
- عرض مقابس TIPC

الوسائط

يتم وصف وسائط الأوامر في صفحة دليل خاصة بالأمر وعادة ما تتكون من أوامر متداخلة مع أزواج مفتاح-قيمة. إذا لم يتم تقديم أي وسائط، فعادةً ما يعرض الأمر نص المساعدة الخاص به. يمكن أن يظهر خيار المساعدة الصريح -h أو --help في أي مكان بين الوسائط وسيظهر المساعدة لآخر أمر صالح تم إعطاؤه.

حالة الخروج

حالة الخروج هي 0 إذا كان الأمر ناجحًا أو عددًا صحيحًا موجبًا عند الفشل.

انظر أيضًا

أبلغ عن أي أخطاء إلى قائمة المراسلات لمطوري الشبكات <netdev@vger.kernel.org> حيث يتم التطوير والصيانة بشكل أساسي. لا تحتاج إلى الاشتراك في القائمة لإرسال رسالة إليها.
