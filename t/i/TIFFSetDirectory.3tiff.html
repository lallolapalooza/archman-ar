TIFFSETDIRECTORY(3tiff) LibTIFF TIFFSETDIRECTORY(3tiff)

الاسم

TIFFSetDirectory - تحديد الدليل الحالي لملف TIFF مفتوح

المُلَخَّص

#include <tiffio.h>
int TIFFSetDirectory(TIFF *tif, tdir_t dirnum)
int TIFFSetSubDirectory(TIFF *tif, uint64_t diroff)

الوصف

TIFFSetDirectory() يغير الدليل الحالي ويقرأ محتوياته باستخدام TIFFReadDirectory(). المعامل dirnum يحدد الملف الفرعي/الدليل كرقم صحيح، مع ترقيم الدليل الأول بصفر. TIFFSetDirectory() يعمل فقط مع سلاسل IFD الرئيسية لأنها تبدأ دائمًا من IFD الرئيسي الأول وبالتالي تكون قادرة على إعادة تعيين سلسلة قراءة SubIFD إلى سلسلة IFD الرئيسية.

TIFFSetSubDirectory() تعمل مثل TIFFSetDirectory()، باستثناء أنه يتم تحديد الدليل كإزاحة ملف بدلاً من فهرس؛ هذا مطلوب للوصول إلى الأدلة الفرعية المرتبطة عبر علامة SubIFD. (انظر MultiPage SubIFD)

وظائف الاستعلام عن الدليل TIFFCurrentDirectory()، TIFFCurrentDirOffset()، TIFFLastDirectory() و TIFFNumberOfDirectories() تسترجع معلومات حول الأدلة في ملف TIFF مفتوح. كن على علم أنه حتى يتم كتابة دليل إلى الملف وقراءته مرة أخرى، فإن وظائف الاستعلام لن تسترجع المعلومات الصحيحة!

قيم الإرجاع

عند النجاح، يتم إرجاع 1. خلاف ذلك، يتم إرجاع 0 إذا كان dirnum أو diroff يحدد دليلًا غير موجود، أو إذا حدث خطأ أثناء قراءة محتويات الدليل.

التشخيصات

تُوجه جميع رسائل الخطأ إلى الروتين TIFFErrorExtR().

"%s: Error fetching directory count":

تم مواجهة خطأ أثناء قراءة حقل "عدد الأدلة".

"%s: Error fetching directory link":

تم مواجهة خطأ أثناء قراءة "قيمة الارتباط" التي تشير إلى الدليل التالي في ملف.
