tilt(1)

الحزمة: ruby-tilt

التراخيص: MIT

TILT(1) دليل الأوامر العامة TILT(1)

الاسم

tilt - معالجة القوالب

الملخص

tilt -l
tilt [-t نمط] [-y ملف] [-D اسم=قيمة] [-d ملف] [--vars=ruby] ملف

الوصف

يعالج ملف القالب file ويكتب الإخراج إلى stdout. عند عدم تحديد file أو عندما يكون file هو ´-´، اقرأ القالب من stdin واستخدم الخيار --type لتحديد نوع القالب.

الخيارات

-l, --list
قائمة بمحركات القوالب + أنماط الملفات والخروج
-t, --type=نمط
استخدم محرك القالب هذا؛ مطلوب إذا لم يتم تحديد file
-y, --layout=ملف
استخدم file كقالب تخطيط
-Dاسم=قيمة
عرف المتغير name بالقيمة value
-d, --define-file=ملف
قم بتحميل YAML أو JSON من file واستخدمه للمتغيرات
--vars=ruby
قم بتقييم ruby إلى Hash واستخدمها للمتغيرات
-h, --help
عرض رسالة المساعدة هذه

أمثلة

تحويل markdown إلى HTML:

$ tilt foo.markdown > foo.html

معالجة قالب ERB:

$ echo "Answer: <%= 2 + 2 %>" | tilt -t erb
Answer: 4

تعريف المتغيرات:

$ echo ´{"n":40}´ > data.json
$ echo "Answer: <%= 2 + n %>" | tilt -t erb -d data.json
Answer: 42
$ echo "Answer: <%= 2 + n %>" | tilt -t erb --vars="{:n=>40}"
Answer: 42
$ echo "Answer: <%= 2 + n.to_i %>" | tilt -t erb -Dn=40
Answer: 42
