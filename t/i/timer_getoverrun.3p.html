ERRORS

The timer_create() function shall fail if the following errors occur:

[EINVAL]
The value specified by timerid is not valid.
[EINVAL]
The value specified by evp is not valid.
[EINVAL]
The value specified by sevp is not valid.
[EINVAL]
The value specified by timerid is not valid and the timer\_id pointer is NULL.
[EAGAIN]
A timer could not be created because the system lacked the necessary resources (e.g., scheduling resources).
[ENAMETOOLONG]
The length of the name specified by name is longer than {NAME_MAX}.
[ENODEV]
The name specified by name does not exist.
[ENOSPC]
The system does not have enough space to create the timer.
[ENOSYS]
The timer_create() function is not implemented for the specified clock.
[ENOTSUP]
The timer implementation does not support the specified clock.
[EPERM]
The calling process does not have the required privileges to create the timer.
[EROFS]
The timer cannot be created on a read-only file system.
[STRUCTION]
The instruction is not valid.

The timer_create() function may fail if:

[EINTR]
A signal was delivered to the calling thread while the function was in the process of executing.
[ENOMEM]
Insufficient memory was available to create the timer.

And report an [EINVAL] error.
