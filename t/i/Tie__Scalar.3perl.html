Tie::Scalar(3perl) دليل مبرمجي بيرل Tie::Scalar(3perl)

الاسم

Tie::Scalar, Tie::StdScalar - تعريفات الفئة الأساسية للمتغيرات المرتبطة

الملخص

package NewScalar;
require Tie::Scalar;
@ISA = qw(Tie::Scalar);
sub FETCH { ... }           # توفير طريقة مطلوبة
sub TIESCALAR { ... }       # تجاوز طريقة موروثة
package NewStdScalar;
require Tie::Scalar;
@ISA = qw(Tie::StdScalar);
# جميع الطرق متوفرة افتراضيًا، لذا قم بتعريف
# فقط ما يحتاج إلى تجاوز
sub FETCH { ... }
package main;
tie $new_scalar, 'NewScalar';
tie $new_std_scalar, 'NewStdScalar';

الوصف

توفر هذه الوحدة بعض الطرق الهيكلية لربط المتغيرات في الفئات. راجع perltie للحصول على قائمة الوظائف المطلوبة لربط متغير بقزمة. توفر حزمة Tie::Scalar الأساسية طريقة "new"، بالإضافة إلى الطرق "TIESCALAR" و "FETCH" و "STORE". توفر حزمة Tie::StdScalar جميع الطرق المحددة في perltie. ترث من Tie::Scalar وتجعل المتغيرات المرتبطة بها تتصرف تمامًا مثل المتغيرات المدمجة، مما يسمح بتجاوز انتقائي للطرق. يتم توفير طريقة "new" كوسيلة لدعم التوافق مع الإصدارات السابقة للفئات التي تنسى توفير طريقة "TIESCALAR" الخاصة بها.

للمطورين الذين يرغبون في كتابة فئات المتغيرات المرتبطة الخاصة بهم، يتم تلخيص الطرق أدناه. لا يوثق قسم perltie هذه الطرق فحسب، بل يحتوي أيضًا على أمثلة للتعليمات البرمجية:

TIESCALAR classname, LIST
الطريقة التي يتم استدعاؤها بواسطة الأمر "tie $scalar, classname". تربط مثيل متغير جديد بالفئة المحددة. "LIST" ستمثل وسيطات إضافية (على غرار AnyDBM_File والأقران) المطلوبة لإكمال الارتباط.
FETCH this
استرداد قيمة المتغير المرتبط المشار إليه بواسطة this.
STORE this, value
تخزين البيانات value في المتغير المرتبط المشار إليه بواسطة this.
DESTROY this
تحرير المساحة المرتبطة بمثيل المتغير المرتبط المشار إليه بواسطة this. نادرًا ما يكون هذا مطلوبًا، حيث تدير Perl ذاكرتها بشكل جيد للغاية. ولكن الخيار متاح، في حال رغبت فئة في إجراء إجراءات محددة عند تدمير مثيل.

Tie::Scalar مقابل Tie::StdScalar

"Tie::Scalar" توفر جميع الطرق الضرورية، ولكن يجب أن يدرك المرء أنها لا تفعل شيئًا مفيدًا. يؤدي استدعاء "Tie::Scalar::FETCH" أو "Tie::Scalar::STORE" إلى ظهور خطأ (يمكن اعتراضه). وإذا كنت ترث من "Tie::Scalar"، فيجب عليك توفير طريقة "new" أو طريقة "TIESCALAR".

إذا كنت تبحث عن فئة تقوم بكل شيء لك ولا تعرفه بنفسك، فاستخدم فئة "Tie::StdScalar"، وليس فئة "Tie::Scalar".
