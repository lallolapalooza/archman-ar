tinysparql-sql(1)

الحزمة: tinysparql

التراخيص: GPL-2.0-or-later

TINYSPARQL-SQL(1) دليل TinySPARQL TINYSPARQL-SQL(1)

اسم

tinysparql sql - استخدم SQL للاستعلام عن قواعد بيانات TinySPARQL.

ملخص

tinysparql sql -q <sql> | -f <file>

وصف

يسمح هذا الأمر بفحص قاعدة البيانات الحالية. عند استخدام أوامر مثل tinysparql sparql، يتم ترجمة SPARQL المستخدم إلى SQL قبل تشغيله على قاعدة البيانات. هذا يسمح بالوصول المباشر إلى قاعدة البيانات باستخدام SQL مع تجنب محرك SPARQL بالكامل.

يمكن للمتصل تشغيل استعلام بطريقتين، إما عن طريق توفير ملف مع الاستعلام أو عن طريق توفير سلسلة نصية مع استعلام sql.

يمكن أن يكون الوسيط file مسارًا محليًا أو عنوان URI. كما أنه ليس بالضرورة أن يكون مسارًا مطلقًا.

خيارات

-f, --file=<ملف>

استخدم ملف يحتوي على محتوى SPARQL للاستعلام. لا تنسَ إنهاء جميع الاستعلامات بفاصلة منقوطة (;) واستخدام علامات اقتباس حول أسماء الجداول. علامات الاقتباس مهمة لأن معظم الجداول مسماة بأسماء فئات الأنطولوجيا مثل "nfo:Document" وستفشل الاستعلامات بدون علامات الاقتباس.

-q, --query=<sql>

استخدم سلسلة نصية sql للاستعلام عن قاعدة البيانات.

أمثلة

عرض أول 10 إدخالات "nfo:Document" حيث حقل TOC ليس NULL

$ tinysparql sql -q 'SELECT * FROM "nfo:Document" WHERE "nfo:tableOfContents" NOT NULL LIMIT 10;'
