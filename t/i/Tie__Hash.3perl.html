Tie::Hash(3perl) دليل مبرمجي Perl Tie::Hash(3perl)

الاسم

Tie::Hash, Tie::StdHash, Tie::ExtraHash - تعريفات الفئات الأساسية للتعليقات التوضيحية المجزأة

الملخص

package NewHash;
require Tie::Hash;
@ISA = qw(Tie::Hash);
sub DELETE { ... }          # توفر الدالة المطلوبة
sub CLEAR { ... }           # تتجاوز الدالة الموروثة
package NewStdHash;
require Tie::Hash;
@ISA = qw(Tie::StdHash);
# توفر جميع الدوال بشكل افتراضي، عرف فقط تلك التي تحتاج إلى تجاوز
# تصل المعدلات إلى التخزين في %{$_[0]};
# يجب أن ترجع TIEHASH مرجعًا إلى التخزين الفعلي
sub DELETE { ... }
package NewExtraHash;
require Tie::Hash;
@ISA = qw(Tie::ExtraHash);
# توفر جميع الدوال بشكل افتراضي، عرف فقط تلك التي تحتاج إلى تجاوز
# تصل المعدلات إلى التخزين في %{$_[0][0]};
# يجب أن ترجع TIEHASH مرجع مصفوفة مع العنصر الأول
# كونه مرجعًا إلى التخزين الفعلي
sub DELETE { 
  $_[0][1]->('del', $_[0][0], $_[1]); # استدعاء كاتب التقرير
  delete $_[0][0]->{$_[1]};           #  $_[0]->SUPER::DELETE($_[1])
}
package main;
tie %new_hash, 'NewHash';
tie %new_std_hash, 'NewStdHash';
tie %new_extra_hash, 'NewExtraHash',
    sub {warn "Doing \U$_[1]\E of $_[2].\n"};

الوصف

توفر هذه الوحدة بعض الدوال الهيكلية لفئات التعليقات التوضيحية المجزأة. راجع perltie للحصول على قائمة بالدوال المطلوبة لربط تجزئة بحزمة. توفر الحزمة الأساسية Tie::Hash دالة "new"، بالإضافة إلى الدوال "TIEHASH" و "EXISTS" و "CLEAR". توفر الحزمتان Tie::StdHash و Tie::ExtraHash معظم الدوال للتجزئات الموصوفة في perltie (الاستثناءات هي "UNTIE" و "DESTROY"). تسببان في أن تتصرف التجزئات المعلقة تمامًا مثل التجزئات القياسية، وتسمحان بالكتابة فوق الدوال بشكل انتقائي. تحتوي Tie::Hash على دعم إرثي لدالة "new": يتم استخدامها إذا لم يتم تعريف "TIEHASH" في حالة نسيت حزمة تضمين دالة "TIEHASH".

للمطورين الذين يرغبون في كتابة تجزئاتهم المعلقة الخاصة، يتم تعريف الدوال المطلوبة بإيجاز أدناه. راجع قسم perltie للحصول على وصف أكثر تفصيلاً، بالإضافة إلى أمثلة للكود:

TIEHASH classname, LIST
الدالة التي يتم استدعاؤها بواسطة الأمر "tie %hash, classname". تربط مثيل تجزئة جديد بالفئة المحددة. "LIST" ستمثل وسائط إضافية (على غرار AnyDBM_File ورفاقها) مطلوبة لإكمال الارتباط.
STORE this, key, value
قم بتخزين البيانات value في key للتجزئة المعلقة this.
FETCH this, key
استرداد البيانات في key للتجزئة المعلقة this.
FIRSTKEY this
إرجاع المفتاح الأول في التجزئة.
NEXTKEY this, lastkey
إرجاع المفتاح التالي في التجزئة.
EXISTS this, key
التحقق من أن key موجودة في التجزئة المعلقة this.

تنفيذ Tie::Hash هو مجرد رمز يقوم بالإبلاغ عن خطأ ببساطة.

DELETE this, key
حذف المفتاح key من التجزئة المعلقة this.
CLEAR this
مسح جميع القيم من التجزئة المعلقة this.
SCALAR this
يرجع ما ينتج عن تقييم التجزئة في سياق قياسي.

Tie::Hash لا ينفذ هذه الدالة (لكن Tie::StdHash و Tie::ExtraHash يفعلان).

الوراثة من Tie::StdHash

تفترض دوال المعدلات أن التخزين الفعلي للبيانات في التجزئة المعلقة موجود في التجزئة المشار إليها بواسطة tied(%tiedhash). لذلك يجب أن ترجع دالة "TIEHASH" التي تم تجاوزها مرجع تجزئة، ويجب أن تعمل الدوال المتبقية على التجزئة المشار إليها بواسطة الوسيط الأول:

package ReportHash;
our @ISA = 'Tie::StdHash';
sub TIEHASH  {
  my $storage = bless {}, shift;
  warn "New ReportHash created, stored in $storage.\n";
  $storage
}
sub STORE    {
  warn "Storing data with key $_[1] at $_[0].\n";
  $_[0]{$_[1]} = $_[2]
}

الوراثة من Tie::ExtraHash

تفترض دوال المعدلات أن التخزين الفعلي للبيانات في التجزئة المعلقة موجود في التجزئة المشار إليها بواسطة "(tied(%tiedhash))->[0]". لذلك يجب أن ترجع دالة "TIEHASH" التي تم تجاوزها مرجع مصفوفة مع العنصر الأول الذي يمثل مرجع تجزئة، ويجب أن تعمل الدوال المتبقية على التجزئة "%{ $_[0]->[0] }":

package ReportHash;
our @ISA = 'Tie::ExtraHash';
sub TIEHASH  {
  my $class = shift;
  my $storage = bless [{}, @_], $class;
  warn "New ReportHash created, stored in $storage.\n";
  $storage;
}
sub STORE    {
  warn "Storing data with key $_[1] at $_[0].\n";
  $_[0][0]{$_[1]} = $_[2]
}

تقوم دالة "TIEHASH" الافتراضية بتخزين الوسائط "الإضافية" إلى tie() بدءًا من الموضع 1 في المصفوفة المشار إليها بواسطة tied(%tiedhash)؛ وهذا هو نفس خوارزمية التخزين كما في دالة TIEHASH أعلاه. وبالتالي، فإن حزمة نموذجية ترث من Tie::ExtraHash لا تحتاج إلى تجاوز هذه الدالة.

"SCALAR", "UNTIE" و "DESTROY"

الدوال "UNTIE" و "DESTROY" غير معرفة في Tie::Hash أو Tie::StdHash أو Tie::ExtraHash. التجزئات المعلقة لا تتطلب وجود هذه الدوال، ولكن إذا تم تعريفها، فسيتم استدعاء الدوال في الوقت المناسب، راجع perltie.

"SCALAR" معرفة فقط في Tie::StdHash و Tie::ExtraHash.

إذا لزم الأمر، يجب تعريف هذه الدوال بواسطة الحزمة التي ترث من Tie::Hash أو Tie::StdHash أو Tie::ExtraHash. راجع "SCALAR" في perltie لمعرفة ما يحدث عندما لا تكون "SCALAR" موجودة.

مزيد من المعلومات

تظهر الحزم المتعلقة بتطبيقات DBM المختلفة (DB_File، NDBM_File، إلخ) أمثلة على التجزئات المعلقة العامة، وكذلك وحدة Config. بينما لا تستخدم هذه Tie::Hash، إلا أنها تعمل كأمثلة جيدة.
