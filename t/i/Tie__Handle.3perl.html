Tie::Handle(3perl) دليل مبرمجي بيرل Tie::Handle(3perl)

الاسم

Tie::Handle - تعريفات الفئة الأساسية للمقابض المرتبطة

الملخص

package NewHandle;
require Tie::Handle;
@ISA = qw(Tie::Handle);
sub READ { ... }            # توفير طريقة مطلوبة
sub TIEHANDLE { ... }       # تجاوز الطريقة الموروثة
package main;
tie *FH, 'NewHandle';

الوصف

توفر هذه الوحدة بعض الطرق الهيكلية لفئات المقابض المرتبطة. انظر perltie لقائمة الوظائف المطلوبة في ربط مقبض بفئة. توفر حزمة Tie::Handle الأساسية طريقة "new"، بالإضافة إلى الطرق "TIEHANDLE"، "PRINT"، "PRINTF" و "GETC".

للمطورين الذين يرغبون في كتابة فئات المقابض المرتبطة الخاصة بهم، تم تلخيص الطرق أدناه. لا يوثق قسم perltie هذه الطرق فحسب، بل يحتوي أيضًا على أمثلة تعليمات برمجية:

TIEHANDLE classname, LIST
الطريقة التي يتم استدعاؤها بواسطة الأمر "tie *glob, classname". تربط مثيل glob جديد بالفئة المحددة. ستمثل "LIST" وسائط إضافية (على غرار AnyDBM_File والرفقاء) مطلوبة لإكمال الارتباط.
WRITE this, scalar, length, offset
اكتب length بايت من البيانات من scalar بدءًا من offset.
PRINT this, LIST
اطبع القيم في LIST
PRINTF this, format, LIST
اطبع القيم في LIST باستخدام format
READ this, scalar, length, offset
اقرأ length بايت من البيانات في scalar بدءًا من offset.
READLINE this
اقرأ سطرًا واحدًا
GETC this
احصل على حرف واحد
CLOSE this
أغلق المقبض
OPEN this, filename
افتح المقبض (مرة أخرى)
BINMODE this
حدد أن المحتوى ثنائي
EOF this
اختبر نهاية الملف.
TELL this
أرجع الموضع في الملف.
SEEK this, offset, whence
ضع الملف.

اختبر نهاية الملف.

DESTROY this
حرر التخزين المرتبط بالمقبض المرتبط المشار إليه بواسطة this. هذا نادرًا ما يكون مطلوبًا، حيث تدير Perl ذاكرتها بشكل جيد للغاية. لكن الخيار متاح، إذا رغبت فئة في تنفيذ إجراءات محددة عند تدمير مثيل.

مزيد من المعلومات

يحتوي قسم perltie على مثال لربط المقابض.
