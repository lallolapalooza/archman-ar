Tie::Array(3perl) دليل مبرمجي Perl Tie::Array(3perl)

الاسم

Tie::Array - الفئة الأساسية للمصفوفات المرتبطة

الملخص

package Tie::NewArray;
use Tie::Array;
@ISA = ('Tie::Array');
# الطرق الإلزامية
sub TIEARRAY { ... }
sub FETCH { ... }
sub FETCHSIZE { ... }
sub STORE { ... }       # إلزامي إذا كانت العناصر قابلة للكتابة
sub STORESIZE { ... }   # إلزامي إذا كان يمكن إضافة/حذف العناصر
sub EXISTS { ... }      # إلزامي إذا كان متوقعًا أن تعمل exists()
sub DELETE { ... }      # إلزامي إذا كان متوقعًا أن تعمل delete()
# طرق اختيارية - للكفاءة
sub CLEAR { ... }
sub PUSH { ... }
sub POP { ... }
sub SHIFT { ... }
sub UNSHIFT { ... }
sub SPLICE { ... }
sub EXTEND { ... }
sub DESTROY { ... }
package Tie::NewStdArray;
use Tie::Array;
@ISA = ('Tie::StdArray');
# جميع الطرق مقدمة افتراضيًا
package main;
$object = tie @somearray,'Tie::NewArray';
$object = tie @somearray,'Tie::StdArray';
$object = tie @somearray,'Tie::NewStdArray';

الوصف

توفر هذه الوحدة الطرق لفئات ربط المصفوفات. انظر perltie للحصول على قائمة بالوظائف المطلوبة لربط مصفوفة بحزمة. توفر حزمة Tie::Array الأساسية طرق "DESTROY" و "EXTEND" وهمية لا تفعل شيئًا، وطرق "DELETE" و "EXISTS" وهمية تتسبب في تعطل (croak()) إذا تم استدعاء الوظائف المدمجة delete() أو exists() على المصفوفة المرتبطة، وتنفيذ لطرق "PUSH" و "POP" و "SHIFT" و "UNSHIFT" و "SPLICE" و "CLEAR" بناءً على طرق "FETCH" و "STORE" و "FETCHSIZE" و "STORESIZE" الأساسية.

توفر حزمة Tie::StdArray طرقًا فعالة مطلوبة للمصفوفات المرتبطة التي يتم تنفيذها كمرجع موجه إلى مصفوفة Perl "داخلية". ترث من Tie::Array، ويجب أن تجعل المصفوفات المرتبطة تتصرف تمامًا مثل المصفوفات القياسية، مما يسمح بالتحميل الزائد الانتقائي للطرق.

للمطورين الذين يرغبون في كتابة مصفوفاتهم المرتبطة الخاصة، يتم تعريف الطرق المطلوبة بإيجاز أدناه. انظر قسم perltie لمزيد من الوصف المفصل، بالإضافة إلى أمثلة التعليمات البرمجية:

TIEARRAY اسم_الفئة، القائمة
يتم استدعاء طريقة الفئة بواسطة الأمر "tie @array, اسم_الفئة". يربط مثيل مصفوفة بالفئة المحددة. ستمثل "القائمة" وسائط إضافية (على غرار AnyDBM_File ورفقائها) مطلوبة لإكمال الارتباط. يجب أن تعيد الطريقة كائنًا من فئة توفر الطرق أدناه.
STORE هذا، الفهرس، القيمة
قم بتخزين البيانات القيمة في الفهرس للمصفوفة المرتبطة بالكائن هذا. إذا جعل هذا المصفوفة أكبر، فيجب إرجاع تعيين الفئة لـ "undef" للمواقع الجديدة.
FETCH هذا، الفهرس
استرداد البيانات في الفهرس للمصفوفة المرتبطة بالكائن هذا.
FETCHSIZE هذا
يعيد العدد الإجمالي للعناصر في المصفوفة المرتبطة بالكائن هذا. (مكافئ لـ scalar(@array)).
STORESIZE هذا، العدد
يضبط العدد الإجمالي للعناصر في المصفوفة المرتبطة بالكائن هذا ليكون العدد. إذا جعل هذا المصفوفة أكبر، فيجب إرجاع تعيين الفئة لـ "undef" للمواقع الجديدة. إذا أصبحت المصفوفة أصغر، فيجب حذف الإدخالات التي تتجاوز العدد.
EXTEND هذا، العدد
مكالمة إعلامية بأن المصفوفة من المحتمل أن تنمو لتشمل العدد من الإدخالات. يمكن استخدامه لتحسين التخصيص. لا تحتاج هذه الطريقة إلى فعل شيء.
EXISTS هذا، المفتاح
تحقق من أن العنصر الموجود في الفهرس المفتاح موجود في المصفوفة المرتبطة هذا.

تنفيذ Tie::Array هو مجرد وهمي ويتسبب في تعطل.

DELETE هذا، المفتاح
حذف العنصر الموجود في الفهرس المفتاح من المصفوفة المرتبطة هذا.

تنفيذ Tie::Array هو مجرد وهمي ويتسبب في تعطل.

CLEAR هذا
مسح (إزالة، حذف، ...) جميع القيم من المصفوفة المرتبطة بالكائن هذا.
DESTROY هذا
طريقة مدمر الكائن القياسية.
PUSH هذا، القائمة
إلحاق عناصر القائمة بالمصفوفة.
POP هذا
إزالة العنصر الأخير من المصفوفة وإعادته.
SHIFT هذا
إزالة العنصر الأول من المصفوفة (تحريك العناصر الأخرى لأسفل) وإعادته.
UNSHIFT هذا، القائمة
إدراج عناصر القائمة في بداية المصفوفة، ونقل العناصر الموجودة لأعلى لإفساح المجال.
SPLICE هذا، الإزاحة، الطول، القائمة
تنفيذ ما يعادل "splice" على المصفوفة.

الإزاحة اختيارية وتكون افتراضيًا صفرًا، القيم السالبة تعد تنازليًا من نهاية المصفوفة.

الطول اختياري ويكون افتراضيًا باقي المصفوفة.

قد تكون القائمة فارغة.

يعيد قائمة بالعناصر الأصلية البالغ طولها الطول في الإزاحة.

محاذير

لا يوجد دعم في الوقت الحالي للمصفوفات المرتبطة @ISA. هناك تضارب محتمل بين الإدخالات السحرية اللازمة لملاحظة تعيين @ISA، وتلك اللازمة لتنفيذ 'tie'.
