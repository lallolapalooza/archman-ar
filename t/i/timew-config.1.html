الحزمة: timew

TIMEW-CONFIG(1) أدلة المستخدم TIMEW-CONFIG(1)

الاسم

timew-config - الحصول على إعدادات Timewarrior وتعيينها

الملخص

timew config [<name> {<value>|''}]

الوصف

يسمح بتعيين وإزالة قيم التكوين، كبديل للتعديل المباشر لملف timewarrior.cfg الخاص بك.

أمثلة

على سبيل المثال:

$ timew config verbose yes
$ timew config verbose ''
$ timew config verbose

يقوم الأمر الأول بتعيين 'verbose' إلى 'yes'. الثاني يقوم بتعيينه إلى قيمة فارغة تتجاوز القيمة الافتراضية. المثال الثالث يحذف إعداد 'verbose'.

عند تعديل التكوين بهذه الطريقة، سيتم طلب تأكيد تفاعلي. لتجاوز هذا التأكيد، استخدم تلميح ':yes'، مما يعني أنك تنوي الإجابة بـ 'yes' على أسئلة التأكيد:

$ timew config verbose '' :yes

إذا لم يتم توفير أي وسائط، فسيتم عرض جميع إعدادات التكوين:

$ timew config
verbose = yes
...
