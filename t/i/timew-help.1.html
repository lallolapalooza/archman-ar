timew-help(1)

الحزمة: timew

التراخيص: MIT

TIMEW-HELP(1) أدلة المستخدم TIMEW-HELP(1)

الاسم

timew-help - عرض المساعدة

الملخص

timew help {<الأمر>|interval|hints|date|duration}

الوصف

يعرض الأمر help وصفًا مفصلاً وأمثلة للأوامر، صيغة الفواصل الزمنية، التلميحات المدعومة، تنسيقات التاريخ والمدة، ومراجع DOM.

أمثلة

على سبيل المثال:

$ timew help
$ timew help start
$ timew help hints
$ timew help interval
$ timew help date
$ timew help duration
$ timew help dom
2025-08-22 timew 1.9.1
