الاسم

TIFFError - واجهة معالجة أخطاء المكتبة

المُلَخَّص

#include <tiffio.h>
#include <stdarg.h>
void TIFFError(const char *module, const char *fmt, ...)
void TIFFErrorExt(thandle_t fd, const char *module, const char *fmt, ...)
void TIFFErrorExtR(TIFF *tif, const char *module, const char *fmt, ...)
typedef void (*TIFFErrorHandler)(const char *module, const char *fmt, va_list ap)
typedef void (*TIFFErrorHandlerExt)(thandle_t fd, const char *module, const char *fmt, va_list ap)
typedef int (*TIFFErrorHandlerExtR)(TIFF *tif, void *user_data, const char *module, const char *fmt, va_list ap)
TIFFErrorHandler TIFFSetErrorHandler(TIFFErrorHandler handler)
TIFFErrorHandlerExt TIFFSetErrorHandlerExt(TIFFErrorHandlerExt handler)

الوصف

TIFFError() تستدعي الدالة المخصصة لمعالجة الأخطاء على مستوى المكتبة لـ (عادة) كتابة رسالة خطأ إلى stderr. المعامل fmt هو سلسلة تنسيق printf()، ويمكن توفير أي عدد من المعاملات. المعامل module يفسر كسلسلة، إذا لم تكن صفرية، يجب طباعتها قبل الرسالة؛ وهي تستخدم عادة لتحديد وحدة البرنامج البرمجي التي تم فيها اكتشاف خطأ.

التطبيقات التي ترغب في التقاط التحكم في حالة حدوث خطأ يجب أن تستخدم TIFFSetErrorHandler() لتجاوز معالج الأخطاء الافتراضي. يمكن تثبيت دالة معالج أخطاء NULL (0) لقمع رسائل الخطأ.

تتوفر دالتان أخريان لمعالجة الأخطاء الخاصتين بالتطبيق، لكل منهما معاملات استدعاء مختلفة وتمرير معاملات إلى المعالج. كل معالج مرتبط أيضًا بدالة رسالة خطأ، أي TIFFErrorExt() و TIFFErrorExtR() إذا كان التطبيق ينوي استدعاء المعالج بتلك المعاملات الموسعة.

TIFFErrorExt() توفر مقبض ملف كمعامل. داخل libtiff، يتم استدعاء TIFFErrorExt() مع تمرير tif->tif_clientdata كـ fd، والذي يمثل مقبض ملف TIFF (واصف الملف). يتم إعداد معالج الأخطاء الخاص بالتطبيق وعلى مستوى المكتبة لـ TIFFErrorExt() مع TIFFSetErrorHandlerExt().

TIFFErrorExtR() (تم تقديمه مع libtiff 4.5) يتم استدعاؤه مع مقبض TIFF الخاص به وبالتالي يوفر الوصول إلى معالج أخطاء لكل مقبض TIFF (قابل لإعادة الدخول). هذا يعني أنه بالنسبة لمقابض TIFF المختلفة، يمكن إعداد معالجات أخطاء مختلفة. يمكن إعداد هذا المعالج المحدد للتطبيق عند فتح ملف TIFF باستخدام إحدى الوظائف التالية: TIFFOpenExt()، TIFFOpenWExt()، TIFFFdOpenExt() أو TIFFClientOpenExt(). علاوة على ذلك، يمكن تقديم هيكل بيانات معرف خصيصًا user_data لمعالج الأخطاء.

ملاحظة

كلتا الدالتين TIFFError() و TIFFErrorExt() تحاولان استدعاء كلتا الدالتين المعالجتين إذا تم تعريفهما. أولاً يتم استدعاء TIFFErrorHandler() ثم TIFFErrorHandlerExt(). ومع ذلك، TIFFError() تمرر “0” كمقبض ملف إلى TIFFErrorHandlerExt().

TIFFErrorExtR() تحاول أولاً استدعاء معالج الخطأ المحدد لكل مقبض TIFF. إذا لم يتم تعريف TIFFErrorHandlerExtR() أو أرجعت 0، يتم استدعاء TIFFErrorHandler() ثم TIFFErrorHandlerExt(). بدءًا من libtiff 4.5، يتم استخدام TIFFErrorExtR() داخل مكتبة libtiff حيث يكون مقبض TIFF متاحًا. وإلا، يتم استخدام TIFFErrorExt()!

قيم الإرجاع

TIFFSetErrorHandler() و TIFFSetErrorHandlerExt() ترجع مرجعًا إلى دالة معالجة الأخطاء السابقة.

TIFFErrorHandlerExtR() ترجع عددًا صحيحًا كـ “إيقاف” للتحكم في استدعاء دوال رسائل الخطأ الأخرى داخل TIFFErrorExtR():

  • 0: يتم استدعاء كل من دالتي TIFFErrorHandler() و TIFFErrorHandlerExt().
  • غير صفري: لا يتم استدعاء أي دالة رسالة خطأ أخرى.
