الاسم

TIFFWarning - واجهة تحذير المكتبة

الملخص

#include <tiffio.h>
#include <stdarg.h>
void TIFFWarning(const char *module, const char *fmt, ...)
void TIFFWarningExt(thandle_t fd, const char *module, const char *fmt, ...)
void TIFFWarningExtR(TIFF *tif, const char *module, const char *fmt, ...)
typedef void (*TIFFWarningHandler)(const char *module, const char *fmt, va_list ap)
typedef void (*TIFFWarningHandlerExt)(thandle_t fd, const char *module, const char *fmt, va_list ap)
typedef int (*TIFFWarningHandlerExtR)(TIFF *tif, void *user_data, const char *module, const char *fmt, va_list ap)
TIFFWarningHandler TIFFSetWarningHandler(TIFFWarningHandler handler)
TIFFWarningHandlerExt TIFFSetWarningHandlerExt(TIFFWarningHandlerExt handler)

الوصف

TIFFWarning() تستدعي دالة معالج التحذير على مستوى المكتبة لكتابة رسالة تحذير (عادةً) إلى stderr. المعلمة fmt هي سلسلة تنسيق printf()، ويمكن توفير أي عدد من الوسائط. المعلمة module تُفسر كسلسلة نصية، إذا لم تكن صفرية، يجب طباعتها قبل الرسالة؛ عادةً ما تستخدم لتحديد الوحدة البرمجية التي تم اكتشاف التحذير فيها.

التطبيقات التي ترغب في التقاط التحكم في حالة حدوث تحذير يجب أن تستخدم TIFFSetWarningHandler() لتجاوز معالج التحذير الافتراضي. يمكن تثبيت معالج تحذير NULL (0) لقمع رسائل التحذير.

هناك معاودتا اتصال معالج تحذير إضافيتان خاصتان بالتطبيق، كل منهما بمعلمات استدعاء مختلفة وتمرير معلمات إلى المعالج. كل معالج مرتبط أيضًا بدالة رسالة تحذير، أي TIFFWarningExt() و TIFFWarningExtR() إذا كان التطبيق ينوي استدعاء المعالج بتلك المعلمات الموسعة.

TIFFWarningExt() توفر مقبض ملف كمعلمة. داخل libtiff يتم استدعاء TIFFWarningExt() مع تمرير tif->tif_clientdata كـ fd، والذي يمثل مقبض ملف TIFF (واصف الملف). يتم إعداد المعالج الخاص بالتطبيق والمعالج على مستوى المكتبة لـ TIFFWarningExt() باستخدام TIFFSetWarningHandlerExt().

TIFFWarningExtR() (تم تقديمه مع libtiff 4.5) يتم استدعاؤه مع مقبض TIFF الخاص به وبالتالي يوفر الوصول إلى معالج تحذير لكل مقبض TIFF (قابل لإعادة الدخول). هذا يعني أنه بالنسبة لمقابض TIFF المختلفة، يمكن إعداد معالجات تحذير مختلفة. يمكن إعداد هذا المعالج الخاص بالتطبيق عند فتح ملف TIFF باستخدام إحدى الوظائف التالية: TIFFOpenExt()، TIFFOpenWExt()، TIFFFdOpenExt() أو TIFFClientOpenExt(). علاوة على ذلك، يمكن توفير هيكل بيانات محدد مخصص user_data لمعالج التحذير.

ملاحظة

كلتا الدالتين TIFFWarning() و TIFFWarningExt() تحاولان استدعاء كلتا دالتي المعالج إذا كانتا معرفتين. أولاً يتم استدعاء TIFFWarningHandler() ثم TIFFWarningHandlerExt(). ومع ذلك، تمرر TIFFWarning() قيمة "0" كمقبض ملف إلى TIFFWarningHandlerExt().

TIFFWarningExtR() تحاول أولاً استدعاء المعالج المحدد لكل مقبض TIFF. إذا لم يكن TIFFWarningHandlerExtR() معرفًا أو أعاد 0، يتم استدعاء TIFFWarningHandler() ثم TIFFWarningHandlerExt(). من libtiff 4.5 فصاعدًا، يتم استخدام TIFFWarningExtR() داخل مكتبة libtiff.

قيم الإرجاع

TIFFSetWarningHandler() و TIFFSetWarningHandlerExt() ترجعان مرجعًا إلى دالة معالج التحذير السابقة.

TIFFWarningHandlerExtR() ترجع قيمة صحيحة كـ "توقف" للتحكم في استدعاء دوال معالج التحذير الإضافية داخل TIFFWarningExtR():

  • 0: يتم استدعاء كلتا الدالتين TIFFWarningHandler() و TIFFWarningHandlerExt().
  • غير صفري: لا يتم استدعاء أي دالة رسالة تحذير أخرى.
