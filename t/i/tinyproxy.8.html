TINYPROXY(8) دليل Tinyproxy TINYPROXY(8)

الاسم

tinyproxy - خادم وكيل HTTP خفيف الوزن

ملخص

tinyproxy [-vdch]

الوصف

tinyproxy هو خادم وكيل HTTP خفيف الوزن مصمم لاستهلاك الحد الأدنى من موارد النظام. يستمع على منفذ TCP معين ويتعامل مع طلبات وكيل HTTP. تم تصميمه من الألف إلى الياء ليكون سريعًا وصغيرًا في نفس الوقت، وهو حل مثالي لحالات الاستخدام مثل عمليات النشر المضمنة حيث يلزم وجود وكيل HTTP كامل الميزات، ولكن موارد النظام لوكيل أكبر غير متاحة.

خيارات

يقبل tinyproxy الخيارات التالية:

-c <ملف-التكوين>
استخدم ملف تكوين بديل.
-d
لا تقم بالتحويل إلى خدمة خلفية (daemonize) وابقى في الواجهة الأمامية. مفيد لأغراض التصحيح.
-h
اعرض شاشة مساعدة مختصرة لوسائط سطر الأوامر واخرج.
-v
عرض معلومات الإصدار والخروج.

الإشارات

بالإضافة إلى خيارات سطر الأوامر، هناك أيضًا العديد من الإشارات التي يمكن إرسالها إلى tinyproxy أثناء تشغيله لتوليد معلومات التصحيح ولفرض أحداث معينة.

SIGHUP
فرض على Tinyproxy إجراء جمع القمامة على قائمة الارتباطات الحالية للاتصالات. يتم هذا عادة تلقائيًا بعد التعامل مع عدد معين من الاتصالات. (وضع الخدمة الخلفية فقط)
SIGUSR1
فرض إعادة تحميل ملف التكوين وقائمة المرشحات. هذا مفيد لتحديث التكوين إذا كان Tinyproxy يعمل في الواجهة الأمامية دون إسقاط الاتصالات النشطة.

ملفات القوالب

هناك مناسبتان يقدم فيهما Tinyproxy صفحات HTML إلى العميل بنفسه:

  • عند حدوث خطأ، يتم إرجاع صفحة خطأ مقابلة.
  • عند طلب `stathost`، يتم إرجاع صفحة تلخص إحصائيات الاتصال. (انظر STATHOST أدناه).

يمكن التحكم في تخطيط كل من صفحات الخطأ وصفحة الإحصائيات عبر ملفات قوالب HTML قابلة للتكوين وهي ملفات HTML عادية تفهم أيضًا عددًا قليلاً من متغيرات القوالب.

متغيرات القوالب

هناك العديد من متغيرات HTML القياسية المتاحة في كل ملف قالب:

request
سطر طلب HTTP الكامل.
cause
سبب مختصر لحالة الخطأ.
clientip
عنوان IP للعميل الذي يقوم بالطلب.
clienthost
اسم المضيف للعميل الذي يقوم بالطلب.
version
إصدار Tinyproxy.
package
اسم الحزمة. حاليًا، يتم حلها إلى 'tinyproxy'.
date
التاريخ/الوقت الحالي بتنسيق HTTP.

بالإضافة إلى ذلك، تدعم جميع القوالب تقريبًا:

detail
شرح مفصل باللغة الإنجليزية العادية للخطأ والأسباب المحتملة.

عندما يجد Tinyproxy اسم متغير محاطًا بأقواس، على سبيل المثال ""{request}""، يتم استبداله بقيمة المتغير المقابل قبل تسليم الصفحة.

STATHOST

يقوم Tinyproxy بإرجاع صفحة HTML مع إحصائيات الاتصال عند استلام طلب HTTP لمضيف معين - `stathost`. اسم `stathost` افتراضيًا هو `tinyproxy.stats` ويمكن تغييره أثناء التشغيل إلى أي اسم أو عنوان IP باستخدام متغير التكوين `StatHost`.

يمكن تغيير قالب ملف الإحصائيات أثناء التشغيل من خلال متغير التكوين `StatFile`.

الملفات

`/etc/tinyproxy/tinyproxy.conf`, `/var/run/tinyproxy/tinyproxy.pid`, `/var/log/tinyproxy/tinyproxy.log`

الأخطاء

للإبلاغ عن أخطاء في Tinyproxy، يرجى زيارة https://tinyproxy.github.io/.
