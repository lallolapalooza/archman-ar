%(cmdlineargs) خيارات أخرى يتم تمريرها في سطر الأوامر. %(diffargs) خيارات من diff-options أو TIG_DIFF_OPTS التي يستخدمها عرض الاختلاف وعرض مرحلة التغييرات. %(blameargs) خيارات من blame-options التي يستخدمها عرض اللوم (blame). %(logargs) خيارات من log-options التي يستخدمها عرض السجل (log). %(mainargs) خيارات من main-options التي يستخدمها العرض الرئيسي. %(prompt) مطالبة بقيمة الوسيط. يمكنك اختياريًا تحديد مطالبة مخصصة باستخدام "%(prompt Enter branch name: )" %(text) عمود النص للسطر المحدد حاليًا. %(repo:head) اسم الفرع الذي تم سحبه، على سبيل المثال master %(repo:head-id) معرف الـ commit للفرع الذي تم سحبه. %(repo:remote) اسم المستودع البعيد المرتبط بالفرع الذي تم سحبه، على سبيل المثال origin. %(repo:upstream) الفرع العلوي المرتبط بالفرع الذي تم سحبه، على سبيل المثال origin/master. %(repo:cdup) المسار لتغيير الدليل إلى جذر المستودع، على سبيل المثال ../ %(repo:prefix) بادئة المسار لدليل العمل الحالي، على سبيل المثال subdir/. %(repo:git-dir) المسار لدليل Git، على سبيل المثال /src/repo/.git. %(repo:worktree) مسار شجرة العمل، إذا تم تعريفه. %(repo:is-inside-work-tree) ما إذا كان Tig يعمل داخل شجرة عمل، إما true أو false.

أوامر معرفة من قبل المستخدم كمثال:

• السماح بتعديل آخر commit: 
bind generic + !git commit --amend
• نسخ معرف الـ commit إلى الحافظة: 
bind generic 9 @sh -c "echo -n %(commit) | xclip -selection c"
• إضافة/تحرير ملاحظات للـ commit الحالي المستخدم أثناء مراجعة: 
bind generic T !git notes edit %(commit)
• الدخول إلى أمر Git التفاعلي للإضافة (add) لتحديد مراحل محتوى الملفات بدقة: 
bind generic I !git add -i %(file)
• إعادة تأسيس (rebase) الفرع الحالي فوق الفرع المحدد: 
bind refs 3 !git rebase -i %(branch)

نوافذ العنوان

كل عرض له نافذة عنوان تعرض اسم العرض، ومعرف الـ commit الحالي إذا كان متاحًا، ومكان تمركز العرض:

[main] c622eefaa485995320bc743431bae0d497b1d875 - commit 1 of 61             1%

بشكل افتراضي، يتم تمييز عنوان العرض الحالي باستخدام خط عريض. للعروض التي تستغرق وقتًا طويلاً للتحميل (أكثر من 3 ثوانٍ)، سيتم إلحاق الوقت منذ بدء التحميل:

[main] 77d9e40fbcea3238015aea403e06f61542df9a31 - commit 1 of 779 loading 5s 0%

متغيرات البيئة

يمكن تكوين العديد من الخيارات المتعلقة بالواجهة مع Git عبر متغيرات البيئة.

ملفات التكوين

عند بدء التشغيل، يقرأ Tig أولاً ملف التكوين العام للنظام ( {sysconfdir}/tigrc افتراضيًا) ثم ينتقل لقراءة ملف التكوين الخاص بالمستخدم (~/.tigrc أو $XDG_CONFIG_HOME/tig/config افتراضيًا). يمكن تجاوز المسارات إلى أي من هذين الملفين من خلال متغيرات البيئة التالية:

TIGRC_USER

مسار ملف تكوين المستخدم.

TIGRC_SYSTEM

مسار ملف تكوين النظام العام.

ملفات السجل

إذا تم تجميع Tig بدعم readline، فإنه يكتب سجل الأوامر والبحث الدائم إلى ~/.tig_history أو $XDG_DATA_HOME/tig/history.

مراجع المستودعات

سيتم تمييز الـ commits التي تشير إليها العلامات ورؤوس الفروع باسم المرجع محاطًا بـ [ و ]:

2006-03-26 19:42 Petr Baudis         | [cogito-0.17.1] Cogito 0.17.1

إذا كنت ترغب في تحديد الفروع التي يتم عرضها، على سبيل المثال عرض الفروع المسماة master فقط أو تلك التي تبدأ بالبادئة feature/، يمكنك القيام بذلك عن طريق تعيين المتغير التالي:

$ TIG_LS_REMOTE="git ls-remote . master feature/*" tig

أو قم بتعيين المتغير بشكل دائم في بيئتك.

TIG_LS_REMOTE

الأمر لاسترداد جميع مراجع المستودعات. يجب أن يخرج الأمر بيانات بنفس تنسيق git-ls-remote(1). الافتراضي هو:
git ls-remote .

خيارات الاختلاف

من الممكن تغيير كيفية عرض الاختلافات بواسطة عرض الاختلاف. إذا كنت، على سبيل المثال، تفضل عرض تواريخ الـ commit والمؤلف كتواريخ نسبية، استخدم:

$ TIG_DIFF_OPTS="--relative-date" tig

أو قم بتعيين المتغير بشكل دائم في بيئتك.

التحكم بالعرض

المفتاح الإجراء
q إغلاق العرض. إذا كان هناك عروض متعددة مفتوحة، فسيعود إلى العرض السابق في مكدس العروض. إذا كان هو آخر عرض مفتوح، فسيتم الخروج. استخدم Q للخروج من جميع العروض دفعة واحدة.
Enter هذا المفتاح "حساس للسياق" حسب العرض الذي تتواجد فيه حاليًا. عند التواجد في عرض السجل على سطر commit أو في العرض الرئيسي، قم بتقسيم العرض واعرض الاختلافات للـ commit. في عرض الاختلاف، سيؤدي الضغط على Enter ببساطة إلى تمرير العرض سطرًا واحدًا لأسفل.
Tab التبديل إلى العرض التالي.
R إعادة تحميل وتحديث العرض الحالي.
O تكبير العرض الحالي لملء الشاشة بأكملها.
Up هذا المفتاح "حساس للسياق" وسيقوم بتحريك المؤشر سطرًا واحدًا لأعلى. ومع ذلك، إذا قمت بفتح عرض مقسم، فسوف يغير المؤشر للإشارة إلى الـ commit السابق في العرض الأصل وتحديث العرض الفرعي لعرضه. إذا كنت تفضل أن يقوم هذا المفتاح بتحريك المؤشر أو التمرير داخل عرض الاختلاف بدلاً من ذلك، استخدم bind diff <Up> move-up أو bind diff <Up> scroll-line-up، على التوالي.
Down مشابه لـ Up ولكنه سيتحرك لأسفل.
, الانتقال إلى الأصل. في عرض الشجرة، هذا يعني التبديل إلى الدليل الأصل. في عرض اللوم، سيقوم بتحميل اللوم للـ commit الأصل. بالنسبة عمليات الدمج، يتم الاستعلام عن الأصل.

NAME

tigmanual — Tig manual

SYNOPSIS

tig [options]

DESCRIPTION

Tig is a Git revision browser. It provides an interface that allows you to view the Git history and the contents of the Git repository. Tig can be used in the same way as git-log(1) or git-ls-tree(1), which means that you can pass any revision specification or path name limiter to Tig.

The Tig manual is divided into several sections:

  • COPYRIGHT

CALLING CONVENTIONS

When Tig is invoked from the command line, it accepts the same options as git-log(1). If no options are given, Tig displays the log for the current branch. Revision specifications may be given as arguments. If a revision specification is given, Tig displays the log for the specified revision(s).

For example, to display the log for the last 10 commits:

$ tig -n10

To display the log for a specific branch:

$ tig my-branch

To display the log for a tag:

$ tig v1.0

To display the log for a specific commit:

$ tig a1b2c3d4

You can also limit the view to specific files or directories:

$ tig Makefile README

Or combine these options:

$ tig -n20 --since=1.week -- Documentation/

THE VIEWER

Tig presents the commit log in a two-pane view. The left pane displays the list of commits, and the right pane displays the diffs for the selected commit. You can navigate the list of commits using the arrow keys or Page Up/Page Down keys. Pressing Enter on a commit will display its diffs in the right pane.
