timeval(3type) timeval(3type)

الاسم

timeval - الوقت بالثواني والميكروثواني

المكتبة

مكتبة C القياسية (libc)

الملخص

#include <sys/time.h>
struct timeval {
    time_t       tv_sec;   /* ثواني */
    suseconds_t  tv_usec;  /* ميكروثواني */
};

الوصف

يصف الأوقات بالثواني والميكروثواني.

المعايير

POSIX.1-2024.

التاريخ

POSIX.1-2001.

ملاحظات
