الحزمة: perl

التراخيص: Artistic-1.0-Perl OR GPL-1.0-or-later

Tie::RefHash(3perl) دليل مبرمجي بيرل Tie::RefHash(3perl)

الاسم

Tie::RefHash - استخدام المراجع كمفاتيح للهاش (hash)

الإصدار

الإصدار 1.41

الملخص

require 5.004;
use Tie::RefHash;
tie HASHVARIABLE, 'Tie::RefHash', LIST;
tie HASHVARIABLE, 'Tie::RefHash::Nestable', LIST;
untie HASHVARIABLE;

الوصف

توفر هذه الوحدة النمطية القدرة على استخدام المراجع كمفاتيح للهاشات إذا قمت أولاً بربط (tie) متغير الهاش بهذه الوحدة النمطية. في العادة، يتم الاحتفاظ فقط بمفاتيح الهاش المرتبط نفسه كمراجع؛ لاستخدام المراجع كمفاتيح في الهاشات المتداخلة (hashes-of-hashes)، استخدم Tie::RefHash::Nestable، المضمنة كجزء من Tie::RefHash.

تم تنفيذه باستخدام واجهة TIEHASH القياسية في بيرل. يرجى مراجعة مدخل "tie" في perlfunc(1) و perltie(1) لمزيد من المعلومات.

تعمل النسخة المتداخلة (Nestable) عن طريق البحث عن مراجع الهاش التي يتم تخزينها وتحويلها إلى هاشات مرتبطة بحيث يمكنها أيضًا أن تحتوي على مراجع كمفاتيح. سيحدث هذا دون سابق إنذار كلما قمت بتخزين مرجع لهاش خاص بك في الهاش المرتبط.

مثال

use Tie::RefHash;
tie %h, 'Tie::RefHash';
$a = [];
$b = {};
$c = \*main;
$d = \"gunk";
$e = sub { 'foo' };
%h = ($a => 1, $b => 2, $c => 3, $d => 4, $e => 5);
$a->[0] = 'foo';
$b->{foo} = 'bar';
for (keys %h) {
   print ref($_), "\n";
}
tie %h, 'Tie::RefHash::Nestable';
$h{$a}->{$b} = 1;
for (keys %h, keys %{$h{$a}}) {
   print ref($_), "\n";
}

دعم الخيوط

تدعم Tie::RefHash دعم الخيوط بالكامل باستخدام الطريقة "CLONE".

دعم التخزين

تم توفير خطافات التخزين (Storable hooks) للتعامل مع التسلسل والاستنساخ الدلالي الصحيح للهاشات المرجعية المرتبطة.
