timerfd_create(2) دليل استدعاءات النظام timerfd_create(2)

الاسم

timerfd_create, timerfd_settime, timerfd_gettime - مؤقتات تعلم عبر واصفات الملفات

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/timerfd.h>
int timerfd_create(int clockid, int flags);
int timerfd_settime(int fd, int flags,
                    const struct itimerspec *new_value,
                    struct itimerspec *_Nullable old_value);
int timerfd_gettime(int fd, struct itimerspec *curr_value);

الوصف

تقوم استدعاءات النظام هذه بإنشاء وتشغيل مؤقت يرسل إشعارات انتهاء صلاحية المؤقت عبر واصف ملف. إنها توفر بديلاً لاستخدام setitimer(2) أو timer_create(2)، مع ميزة أن واصف الملف يمكن مراقبته بواسطة select(2)، poll(2)، و epoll(7).

استخدام استدعاءات النظام الثلاثة هذه مشابه لاستخدام timer_create(2)، timer_settime(2)، و timer_gettime(2). (لا يوجد مقابل لـ timer_getoverrun(2)، حيث يتم توفير هذه الوظيفة بواسطة read(2)، كما هو موضح أدناه.)

timerfd_create()

يقوم timerfd_create() بإنشاء كائن مؤقت جديد، ويعيد واصف ملف يشير إلى هذا المؤقت. يحدد الوسيط clockid الساعة التي تستخدم لتحديد تقدم المؤقت، ويجب أن يكون أحد ما يلي:

CLOCK_REALTIME
ساعة حقيقية قابلة للضبط على مستوى النظام.
CLOCK_MONOTONIC
ساعة متزايدة بشكل رتيب لا يمكن ضبطها وتقيس الوقت منذ نقطة غير محددة في الماضي لا تتغير بعد بدء تشغيل النظام.
CLOCK_BOOTTIME (منذ Linux 3.15)
مثل CLOCK_MONOTONIC، هذه ساعة متزايدة بشكل رتيب. ومع ذلك، في حين أن ساعة CLOCK_MONOTONIC لا تقيس الوقت أثناء تعليق النظام، فإن ساعة CLOCK_BOOTTIME تتضمن الوقت الذي كان فيه النظام معلقًا. هذا مفيد للتطبيقات التي تحتاج إلى الوعي بالتعليق. CLOCK_REALTIME ليست مناسبة لمثل هذه التطبيقات، حيث تتأثر هذه الساعة بالتغييرات غير المتصلة في ساعة النظام.
CLOCK_REALTIME_ALARM (منذ Linux 3.11)
هذه الساعة مثل CLOCK_REALTIME، ولكنها ستوقظ النظام إذا كان معلقًا. يجب أن يمتلك المتصل صلاحية CAP_WAKE_ALARM لضبط مؤقت مقابل هذه الساعة.
CLOCK_BOOTTIME_ALARM (منذ Linux 3.11)
هذه الساعة مثل CLOCK_BOOTTIME، ولكنها ستوقظ النظام إذا كان معلقًا. يجب أن يمتلك المتصل صلاحية CAP_WAKE_ALARM لضبط مؤقت مقابل هذه الساعة.

راجع clock_getres(2) لمزيد من التفاصيل حول الساعات المذكورة أعلاه.

يمكن استرداد القيمة الحالية لكل من هذه الساعات باستخدام clock_gettime(2).

بدءًا من Linux 2.6.27، يمكن إضافة القيم التالية معًا (OR bitwise) في flags لتغيير سلوك timerfd_create():

TFD_NONBLOCK
اضبط علامة حالة ملف O_NONBLOCK على الوصف المفتوح للملف (انظر open(2)) المشار إليه بواسطة واصف الملف الجديد. استخدام هذه العلامة يوفر استدعاءات إضافية لـ fcntl(2) لتحقيق نفس النتيجة.
TFD_CLOEXEC
اضبط علامة الإغلاق عند التنفيذ (FD_CLOEXEC) على واصف الملف الجديد. انظر وصف علامة O_CLOEXEC في open(2) للأسباب التي قد تجعل هذا مفيدًا.

في إصدارات Linux حتى 2.6.26 بما في ذلك، يجب تحديد flags على أنها صفر.

timerfd_settime()

يقوم timerfd_settime() بتنشيط (بدء) أو إلغاء تنشيط (إيقاف) المؤقت المشار إليه بواسطة واصف الملف fd.

يحدد الوسيط new_value انتهاء الصلاحية الأولي والفاصل الزمني للمؤقت. يوصف الهيكل itimerspec المستخدم لهذا الوسيط في itimerspec(3type).

يحدد new_value.it_value انتهاء الصلاحية الأولي للمؤقت، بالثواني والنانو ثانية. تحديد أي من الحقلين في new_value.it_value بقيمة غير صفرية ينشط المؤقت. تحديد كلا الحقلين في new_value.it_value بصفر يلغي تنشيط المؤقت.

تحديد حقل واحد أو كليهما في new_value.it_interval بقيم غير صفرية يحدد الفترة، بالثواني والنانو ثانية، لانتهاء صلاحية المؤقت بشكل متكرر بعد انتهاء الصلاحية الأولي. إذا كان كلا الحقلين في new_value.it_interval صفرًا، فإن المؤقت ينتهي مرة واحدة فقط، في الوقت المحدد بواسطة new_value.it_value.

بشكل افتراضي، يتم تفسير وقت انتهاء الصلاحية الأولي المحدد في new_value بالنسبة للوقت الحالي على ساعة المؤقت في وقت الاستدعاء (أي، يحدد new_value.it_value وقتًا نسبيًا للقيمة الحالية للساعة المحددة بواسطة clockid). يمكن تحديد انتهاء صلاحية مطلق عبر الوسيط flags.

الوسيط flags هو قناع بت يمكن أن يشمل القيم التالية:

TFD_TIMER_ABSTIME
فسر new_value.it_value كقيمة مطلقة على ساعة المؤقت. سينتهي المؤقت عندما تصل قيمة ساعة المؤقت إلى القيمة المحددة في new_value.it_value.
TFD_TIMER_CANCEL_ON_SET
إذا تم تحديد هذه العلامة مع TFD_TIMER_ABSTIME وكانت ساعة هذا المؤقت هي CLOCK_REALTIME أو CLOCK_REALTIME_ALARM، فقم بوضع علامة على هذا المؤقت على أنه قابل للإلغاء إذا حدث تغيير غير متصل في الساعة الحقيقية ( settimeofday(2)، clock_settime(2)، أو ما شابه). عند حدوث مثل هذه التغييرات، سيفشل قراءة حالية أو مستقبلية (read(2)) من واصف الملف مع الخطأ ECANCELED.

إذا كان الوسيط old_value ليس NULL، فسيتم استخدام هيكل itimerspec الذي يشير إليه لإرجاع إعداد المؤقت الذي كان ساريًا في وقت الاستدعاء؛ انظر وصف timerfd_gettime() التالي.

timerfd_gettime()

يعيد timerfd_gettime()، في curr_value، هيكل itimerspec يحتوي على الإعداد الحالي للمؤقت المشار إليه بواسطة واصف الملف fd.

يعيد الحقل it_value مقدار الوقت حتى ينتهي المؤقت من العمل في المرة القادمة. إذا كان كلا الحقلين في هذا الهيكل صفرين، فإن المؤقت غير نشط حاليًا. يحتوي هذا الحقل دائمًا على قيمة نسبية، بغض النظر عما إذا تم تحديد علامة TFD_TIMER_ABSTIME عند ضبط المؤقت.

يعيد الحقل it_interval فاصل المؤقت. إذا كان كلا الحقلين في هذا الهيكل صفرين، فإن المؤقت مضبوط لينتهي مرة واحدة فقط، في الوقت المحدد بواسطة curr_value.it_value.

التشغيل على واصف ملف مؤقت

يدعم واصف الملف الذي أعاده timerfd_create() العمليات الإضافية التالية:

read(2)
إذا كان المؤقت قد انتهى بالفعل مرة واحدة أو أكثر منذ آخر تعديل لإعداداته

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

timerfd_settime(2) — man pages

NAME

timerfd_settime - إعداد مؤقت في واجهة المؤقتات

LIBRARY

تستخدم مكتبة المؤقتات (librt)

SYNOPSIS

#include <sys/timerfd.h>

int timerfd_settime(int fd, unsigned int flags,
                    const struct itimerspec *new_value,
                    struct itimerspec *old_value);

DESCRIPTION

تسمح الدالة timerfd_settime بتغيير وقت انتهاء صلاحية المؤقت المحدد بواسطة fd. يمكن استخدام قيمة flags لتحديد كيفية تفسير new_value. إذا كانت flags تساوي 0، فإن new_value.it_value يتم تفسيرها كوقت نسبي (relative time). إذا كانت flags تحتوي على العلامة TFD_TIMER_ABSTIME، فسيتم تفسير new_value.it_value كوقت مطلق (absolute time).

new_value هي بنية itimerspec التي تحدد وقت انتهاء الصلاحية الأولي للمؤقت new_value.it_value والفاصل الزمني بين الانتهاءات new_value.it_interval.

إذا تم تعيين new_value.it_interval إلى الصفر، فسيتم تشغيل المؤقت مرة واحدة فقط. إذا تم تعيين new_value.it_value إلى الصفر، فسيتم تعطيل المؤقت.

إذا تم توفير old_value (ليس مؤشرًا فارغًا)، فسيتم تخزين وقت انتهاء الصلاحية الأصلي للمؤقت فيه.

RETURN VALUE

عند النجاح، تقوم الدالة timerfd_settime بإرجاع 0. في حالة الفشل، تقوم بإرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

ERRORS

EBADF
لم يكن fd معرف مؤقت صحيح.
EINVAL
تم تعيين علامة غير صالحة في flags، أو أن new_value يشير إلى وقت سالب، أو أن new_value.it_value أو new_value.it_interval يمثلان قيمًا غير صالحة.
EPERM
لم يكن لدى العملية الأذونات اللازمة لإنشاء مؤقت.

STANDARDS

تتوافق هذه الدالة مع معيار POSIX.1-2008.

HISTORY

تمت إضافة الدالة timerfd_settime في Linux kernel 2.6.27.

NOTES

تعمل الدالة timerfd_settime بشكل وثيق مع الدالة timerfd_create(2) لإنشاء مؤقتات تعتمد على الأحداث.

عند استخدام TFD_TIMER_ABSTIME، يجب التأكد من أن new_value.it_value تشير إلى وقت مطلق صحيح (مثل وقت النظام).

BUGS

لا توجد أخطاء معروفة.

EXAMPLES

   #include <sys/timerfd.h>
   #include <stdio.h>
   #include <stdlib.h>
   #include <unistd.h>
   #include <time.h>
   #include <stdint.h>
   #include <err.h>

   /* Helper function to print elapsed time */
   static void
   print_elapsed_time(const struct timespec *start)
   {
       struct timespec curr, diff;
       clock_gettime(CLOCK_REALTIME, &curr);
       diff.tv_sec = curr.tv_sec - start->tv_sec;
       diff.tv_nsec = curr.tv_nsec - start->tv_nsec;
       if (diff.tv_nsec < 0) {
           diff.tv_sec--;
           diff.tv_nsec += 1000000000;
       }
       printf("%lld.%03lld:\t", (long long)diff.tv_sec,
              (long long)(diff.tv_nsec + 500000) / 1000000);
   }

   int
   main(int argc, char *argv[])
   {
       int                fd;
       ssize_t            s;
       uint64_t           expir, tot_expir, max_expir;
       struct timespec    now;
       struct itimerspec  new_value;

       if (argc != 2 && argc != 4) {
           fprintf(stderr, "%s init-secs [interval-secs max-num-expir]\n",
                   argv[0]);
           exit(EXIT_FAILURE);
       }

       if (clock_gettime(CLOCK_REALTIME, &now) == -1)
           err(EXIT_FAILURE, "clock_gettime");

       /* Create a CLOCK_REALTIME absolute timer with initial
          expiration and interval as specified in command line.  */
       new_value.it_value.tv_sec = now.tv_sec + atoi(argv[1]);
       new_value.it_value.tv_nsec = now.tv_nsec;

       if (argc == 2) {
           new_value.it_interval.tv_sec = 0;
           max_expir = 1;
       } else {
           new_value.it_interval.tv_sec = atoi(argv[2]);
           max_expir = atoi(argv[3]);
       }
       new_value.it_interval.tv_nsec = 0;

       fd = timerfd_create(CLOCK_REALTIME, 0);
       if (fd == -1)
           err(EXIT_FAILURE, "timerfd_create");

       if (timerfd_settime(fd, TFD_TIMER_ABSTIME, &new_value, NULL) == -1)
           err(EXIT_FAILURE, "timerfd_settime");

       print_elapsed_time(&now);
       printf("timer started\n");

       for (tot_expir = 0; tot_expir < max_expir;) {
           s = read(fd, &expir, sizeof(uint64_t));
           if (s != sizeof(uint64_t))
               err(EXIT_FAILURE, "read");
           tot_expir += expir;
           print_elapsed_time(&now);
           printf("read: %" PRIu64 "; total=%" PRIu64 "\n",
                  expir, tot_expir);
       }

       exit(EXIT_SUCCESS);
   }
