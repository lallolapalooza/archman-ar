Time::HiRes(3perl) Perl 5.38.2

NAME

Time::HiRes - Access to high resolution timers and sleep

SYNOPSIS

 use Time::HiRes qw( sleep usleep nanosleep ":gettimeofday" );

 sleep(1.23);
 usleep(456000);  # 0.456 seconds
 nanosleep(123456789); # 0.123456789 seconds

 my ($tv_sec, $tv_usec) = gettimeofday();
 my ($tv_sec, $tv_usec, $tv_nsec) = gettimeofday(); # if available
 my ($now_sec, $now_usec) = gettimeofday();
 my ($now_sec, $now_usec, $now_nsec) = gettimeofday(); # if available

 use Time::HiRes;
 my $t0 = Time::HiRes::time();
 my $t1 = Time::HiRes::time();
 printf "Elapsed: %.4f seconds\n", $t1 - $t0;

DESCRIPTION

This module provides access to high-resolution timers and sleep functions. On systems that support it, it uses the C library functions gettimeofday() and nanosleep() (or equivalent) for more precise timing than the standard Perl time() and sleep() functions.

The standard Perl time() function returns the number of seconds since the epoch, with only second precision. The standard sleep() function can only sleep for whole seconds.

Time::HiRes::time() returns the time as a floating-point number of seconds since the epoch. This can be used for measuring short time intervals.

Time::HiRes::sleep(), Time::HiRes::usleep(), and Time::HiRes::nanosleep() allow sleeping for fractional seconds.

Time::HiRes::gettimeofday() is a wrapper around the C library's gettimeofday() function. It returns the current time as a list of seconds and microseconds since the epoch. If the underlying C library supports nanosecond resolution (e.g., via struct timeval extensions), it will return seconds, microseconds, and nanoseconds.

FUNCTIONS

time()

Returns the current time as a floating-point number of seconds since the epoch. This is analogous to the C library function gettimeofday(), but potentially with better precision than the standard Perl time() function.

sleep(seconds)

Suspends execution for the specified number of seconds. The argument can be a floating-point number to sleep for fractions of a second. Returns the number of seconds actually slept.

usleep(microseconds)

Suspends execution for the specified number of microseconds. This is equivalent to calling sleep() with a fractional argument (e.g., usleep(500000) is equivalent to sleep(0.5)).

Returns the number of microseconds actually slept.

nanosleep(nanoseconds)

Suspends execution for the specified number of nanoseconds. This is equivalent to calling sleep() with a fractional argument (e.g., nanosleep(500000000) is equivalent to sleep(0.5)).

Returns the number of nanoseconds actually slept.

gettimeofday()

Returns the current time as a list. The list typically contains two elements: seconds and microseconds since the epoch. If nanosecond resolution is available, it will return three elements: seconds, microseconds, and nanoseconds.

The return value is analogous to the C library's gettimeofday() function.

EXAMPLES

Measure the time taken for a block of code:

 use Time::HiRes();

 my $start_time = Time::HiRes::time();

 # ... code to measure ...

 my $end_time = Time::HiRes::time();
 my $elapsed = $end_time - $start_time;
 print "Code block took $elapsed seconds\n";

Sleep for a fraction of a second:

 use Time::HiRes qw( sleep );

 print "Sleeping for 0.1 seconds...\n";
 sleep(0.1);
 print "Done.\n";

Using gettimeofday:

 use Time::HiRes qw( gettimeofday );

 my ($sec, $usec) = gettimeofday();
 print "Current time: $sec.$usec seconds since epoch\n";

 # If nanosecond support is available
 my ($sec, $usec, $nsec) = gettimeofday();
 print "Current time: $sec.$usec$nsec seconds since epoch\n";

C API

This module is implemented in C. It exports the following functions to Perl:

  • PMf_time(): Equivalent to Time::HiRes::time().
  • PMf_sleep(): Equivalent to Time::HiRes::sleep().
  • PMf_usleep(): Equivalent to Time::HiRes::usleep().
  • PMf_nanosleep(): Equivalent to Time::HiRes::nanosleep().
  • PMf_gettimeofday(): Equivalent to Time::HiRes::gettimeofday().

DIAGNOSTICS

If the underlying system calls fail, the functions will raise an exception with a message indicating the nature of the failure.

CAVEATS

  • The precision of the timers and the accuracy of the sleep functions depend on the underlying operating system and hardware support.
  • On some older systems, gettimeofday() might not be available or might not offer significantly better precision than the standard time(). In such cases, the module might fall back to using the standard Perl functions.
  • The behavior of sleep(), usleep(), and nanosleep() can be affected by system signals. If a signal interrupts the sleep, the function might return prematurely.
  • Ensure that you are using a version of Perl that has been compiled with floating-point support for the fractional second values to work correctly.
