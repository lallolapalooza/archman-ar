TIMES(1P) دليل مبرمج POSIX TIMES(1P)

مقدمة

صفحة الدليل هذه جزء من دليل مبرمج POSIX. قد يختلف تنفيذ Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة منفذة على Linux.

الاسم

times — كتابة أوقات العملية

الملخص

times

الوصف

سيقوم الأمر times بكتابة أوقات المستخدم والنظام المتراكمة للصدفة وجميع عملياتها الفرعية، بالتنسيق التالي لموقع POSIX المحلي:

"%dm%fs %dm%fs\n%dm%fs %dm%fs\n", <دقائق مستخدم الصدفة>,
    <ثواني مستخدم الصدفة>, <دقائق نظام الصدفة>,
    <ثواني نظام الصدفة>, <دقائق مستخدم العمليات الفرعية>,
    <ثواني مستخدم العمليات الفرعية>, <دقائق نظام العمليات الفرعية>,
    <ثواني نظام العمليات الفرعية>

ستتوافق أزواج الأوقات الأربعة مع أعضاء بنية tms في <sys/times.h> (المعرفة في مجلد التعريفات الأساسية من POSIX.1-2017، الفصل 13، رؤوس) كما تم إرجاعه بواسطة times(): tms_utime، tms_stime، tms_cutime، و tms_cstime، على التوالي.

Arch is aimed at proficient Linux users who understand the implications of customization and are willing to compile some packages themselves.

The Arch Linux way is summarized by the Arch Way, which is a set of guidelines that govern the general philosophy and technical decisions behind Arch Linux.

Core principles

  • Simplicity
  • Modernity
  • Pragmatism
  • User centrality
  • Versatility

Current development

The Arch Linux project is currently developed by a dedicated team of volunteers. The core of the system is maintained in a Git repository.

The official package repositories are built automatically from the pacman build system. The packages are compiled for the x86-64 architecture.

The system is continuously updated, and a new ISO release is available every few months. This allows users to start with a recent system and keep it updated using the rolling-release model.

For the conversion of manual pages, we use mandoc.
