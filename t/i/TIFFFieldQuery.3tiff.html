TIFFFIELDQUERY(3tiff) LibTIFF TIFFFIELDQUERY(3tiff)

الاسم

TIFFFieldQuery - روتينات للاستعلام عن معلومات حقول TIFF

الملخص

#include <tiffio.h>
const TIFFField *TIFFFieldWithName(TIFF *tif, const char *field_name)
const TIFFField *TIFFFieldWithTag(TIFF *tif, uint32_t tag)
const TIFFField *TIFFFindField(TIFF *tif, uint32_t tag, TIFFDataType dt)
int TIFFFieldIsAnonymous(const TIFFField *fip)
int TIFFFieldSetGetSize(const TIFFField *fip)
int TIFFFieldSetGetCountSize(const TIFFField *fip)

الوصف

TIFFFieldWithName() و TIFFFieldWithTag() تعيد مؤشرًا إلى بنية معلومات حقل TIFF fip بواسطة field_name الخاص بالوسم أو رقمه tag.

TIFFFindField() تبحث عن بنية معلومات حقل TIFF fip لرقم tag معين ونوع بيانات TIFFDataType dt محدد. مع dt == TIFF_ANY يكون السلوك مطابقًا لـ TIFFFieldWithTag().

جميع الوظائف الثلاثة تعيد NULL عندما لا يتم تسجيل الوسم ضمن libtiff (انظر أيضًا Default Tag Auto-registration).

قد يكون البحث المعتمد على TIFFDataType مفيدًا عندما يتم تعريف نفس الوسم مرتين ولكن بأنواع بيانات مختلفة، وهو ما يحدث في حالات نادرة مثل TIFFTAG_XCLIPPATHUNITS. ومع ذلك، فإن libtiff لا تدعم حاليًا تعريفات متعددة لنفس الوسم.

الروتينات التالية تعيد معلومات الحالة حول حقول TIFF.

fip هو مؤشر معلومات الحقل الذي تم إرجاعه سابقًا بواسطة TIFFFindField() أو TIFFFieldWithTag() أو TIFFFieldWithName().

TIFFFieldIsAnonymous() تعيد صحيحًا (غير صفري) إذا كان الحقل، المقروء من الملف، غير معروف لـ libtiff وتم تسجيل حقل مجهول تلقائيًا. تعيد صفرًا "0" إذا كان الحقل معروفًا لـ libtiff. انظر Default Tag Auto-registration لمزيد من المعلومات.

TIFFFieldSetGetSize() تعيد حجم البيانات بالبايت لنوع بيانات الحقل المستخدم للتخزين الداخلي لـ libtiff. هذا هو أيضًا حجم البيانات للمعامل الذي سيتم تقديمه إلى TIFFSetField() و TIFFGetField(). يمكن تخزين قيم TIFF_RATIONAL المخصصة داخليًا إما كـ float أو double. TIFFFieldSetGetSize() ستعيد حينها "4" أو "8" على التوالي.

TIFFFieldSetGetCountSize() تعيد حجم معامل count الخاص بـ TIFFSetField() و TIFFGetField() وأيضًا إذا كان مطلوبًا: 0=لا شيء، 2= uint16_t، 4= uint32_t. انظر أيضًا وصف TIFFFieldReadCount().
