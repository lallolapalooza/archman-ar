Tcl_GetOpenFile(3)

الحزمة: tcl

التراخيص: TCL

Tcl_GetOpenFile(3) إجراءات مكتبة Tcl Tcl_GetOpenFile(3)

الاسم

Tcl_GetOpenFile - إرجاع FILE* لقناة مسجلة في المفسر المحدد (Unix فقط)

الملخص

#include <tcl.h>

int
Tcl_GetOpenFile(interp, chanID, write, checkUsage, filePtr)

المعاملات

Tcl_Interp *interp (داخل)
مفسر Tcl الذي سيتم الحصول على مقبض الملف منه.
const char *chanID (داخل)
معرف السلسلة للقناة، مثل stdin أو file4.
int write (داخل)
قيمة غير صفرية تعني أن الملف سيستخدم للكتابة، صفر يعني أنه سيستخدم للقراءة.
int checkUsage (داخل)
إذا كانت غير صفرية، فسيتم إنشاء خطأ إذا لم يتم فتح الملف للوصول المشار إليه بواسطة write.
ClientData *filePtr (خارج)
يشير إلى كلمة سيتم تخزين مؤشر إلى هيكل FILE للملف المحدد بواسطة chanID فيه.

الوصف

تأخذ Tcl_GetOpenFile كمُدخل معرف ملف بالشكل الذي تم إرجاعه بواسطة الأمر open وتعيد عند *filePtr مؤشرًا إلى هيكل FILE للملف. يحدد المعامل write ما إذا كان مؤشر FILE سيستخدم للقراءة أو الكتابة. في بعض الحالات، مثل قناة تتصل بخط أنابيب من العمليات الفرعية، سيتم إرجاع مؤشرات FILE مختلفة للقراءة والكتابة. تعيد Tcl_GetOpenFile عادةً TCL_OK. إذا حدث خطأ في Tcl_GetOpenFile (على سبيل المثال، chanID لم يكن له معنى أو تم تعيين checkUsage ولم يتم فتح الملف للوصول المحدد بواسطة write) فسيتم إرجاع TCL_ERROR وسيحتوي نتيجة المفسر على رسالة خطأ. في التنفيذ الحالي، يتم تجاهل checkUsage ويتم دائمًا إجراء فحوصات الاتساق.

لاحظ أن هذه الواجهة مدعومة فقط على منصة Unix.
