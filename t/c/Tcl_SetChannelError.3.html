NAME

Tcl_SetChannelError, Tcl_GetChannelError - set or retrieve channel error information

SYNOPSIS

#include <tcl.h>

int
Tcl_SetChannelError(
    Tcl_Channel channel,
    const char *errMsg
);

const char *
Tcl_GetChannelError(
    Tcl_Channel channel
);

DESCRIPTION

The procedure Tcl_SetChannelError is used to set the error message associated with a channel. The argument channel is the handle for the channel, and errMsg is a pointer to a null-terminated string containing the error message. The string is copied internally, so the caller is free to deallocate the original string after the call returns.

The procedure Tcl_GetChannelError is used to retrieve the error message associated with a channel. The argument channel is the handle for the channel. It returns a pointer to a null-terminated string containing the error message. If no error message is currently associated with the channel, it returns NULL.

KEYWORDS

channel, error, message, set, get
