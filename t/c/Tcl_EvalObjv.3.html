Tcl_Interp *interp (مدخل)
المفسر الذي سيتم تنفيذ النص البرمجي فيه. يتم تعديل نتيجة المفسر للاحتفاظ بالنتيجة أو رسالة الخطأ من النص البرمجي.
Tcl_Obj *objPtr (مدخل)
قيمة Tcl تحتوي على النص البرمجي المراد تنفيذه.
int flags (مدخل)
مزيج من بتات العلامات التي تحدد خيارات إضافية. حاليًا، يتم دعم TCL_EVAL_GLOBAL و TCL_EVAL_DIRECT.
const char *fileName (مدخل)
اسم ملف يحتوي على نص برمجي Tcl.
int objc (مدخل)
عدد القيم في المصفوفة المشار إليها بواسطة objv؛ وهذا هو أيضًا عدد الكلمات في الأمر.
Tcl_Obj **objv (مدخل)
يشير إلى مصفوفة من المؤشرات إلى القيم؛ كل قيمة تحمل قيمة كلمة واحدة في الأمر المراد تنفيذه.
int numBytes (مدخل)
عدد البايتات في script، ولا يشمل أي حرف إنهاء صفري. إذا كان -1، فسيتم استخدام جميع البايتات حتى أول بايت صفري.
const char *script (مدخل)
يشير إلى البايت الأول من النص البرمجي المراد تنفيذه (منهي بـ NULL و UTF-8).
const char *part (مدخل)
سلسلة تشكل جزءًا من نص برمجي Tcl.
va_list argList (مدخل)
قائمة معاملات يجب تهيئتها باستخدام va_start، ومسحها باستخدام va_end.

الوصف

يتم استدعاء الإجراءات الموضحة هنا لتنفيذ نصوص Tcl البرمجية بأشكال مختلفة. Tcl_EvalObjEx هو الإجراء الأساسي ويستخدمه الكثير من الآخرين. يقوم بتنفيذ الأوامر الموجودة في النص البرمجي المخزن في objPtr حتى يحدث خطأ أو يتم الوصول إلى نهاية النص البرمجي. إذا كانت هذه هي المرة الأولى التي يتم فيها تقييم objPtr، يتم تجميع أوامره في تعليمات بايت كود ثم تنفيذها. يتم حفظ البايت كود في objPtr بحيث يمكن تخطي خطوة التجميع إذا تم تقييم القيمة مرة أخرى في المستقبل.

قيمة الإرجاع من Tcl_EvalObjEx (وجميع الإجراءات الأخرى الموضحة هنا) هي رمز اكتمال Tcl مع إحدى القيم TCL_OK، TCL_ERROR، TCL_RETURN، TCL_BREAK، أو TCL_CONTINUE، أو ربما قيمة صحيحة أخرى تنشأ في امتداد. بالإضافة إلى ذلك، يتم ترك قيمة نتيجة أو رسالة خطأ في نتيجة interp؛ يمكن استردادها باستخدام Tcl_GetObjResult.

Tcl_EvalFile يقرأ الملف المحدد بواسطة fileName ويقوم بتقييم محتوياته كنص برمجي Tcl. يعيد نفس المعلومات مثل Tcl_EvalObjEx. إذا لم يكن من الممكن قراءة الملف، يتم إرجاع خطأ Tcl لوصف سبب عدم إمكانية قراءة الملف. حرف نهاية الملف للملفات هو “\32” (^Z) لجميع المنصات. إذا كنت بحاجة إلى “^Z” في الكود للمقارنة بين السلاسل، يمكنك استخدام “\032” أو “\u001a”، والتي سيتم استبدالها بأمان بواسطة مفسر Tcl بـ “^Z”.

Tcl_EvalObjv ينفذ أمرًا واحدًا تم تقسيمه مسبقًا بدلاً من نص برمجي. تحتوي وسيطات objc و objv على قيم الكلمات للأمر Tcl، كلمة واحدة في كل قيمة في objv. يقوم Tcl_EvalObjv بتقييم الأمر ويعيد رمز اكتمال ونتيجة تمامًا مثل Tcl_EvalObjEx. يجب على المستدعي لـ Tcl_EvalObjv إدارة عداد المراجع لعناصر objv، والتأكد من أن القيم صالحة حتى يعود Tcl_EvalObjv.

Tcl_Eval يشبه Tcl_EvalObjEx باستثناء أن النص البرمجي المراد تنفيذه يتم توفيره كسلسلة نصية بدلاً من قيمة ولا يحدث تجميع. يجب أن تكون السلسلة نصية UTF-8 صحيحة كما تم تحويلها بواسطة Tcl_ExternalToUtfDString أو Tcl_ExternalToUtf عندما يكون معروفًا أنها قد تحتوي على أحرف ASCII عليا قد تكون مجموعاتها عبارة عن رمز خاص من UTF-8. يتم تحليل السلسلة النصية وتنفيذها مباشرة (باستخدام Tcl_EvalObjv) بدلاً من تجميعها وتنفيذ البايت كود. في الحالات التي يكون فيها معروفًا أن النص البرمجي لن يتم تنفيذه مرة أخرى، قد يكون Tcl_Eval أسرع من Tcl_EvalObjEx.
يعيد Tcl_Eval رمز اكتمال ونتيجة تمامًا مثل Tcl_EvalObjEx. ملاحظة: للتوافق مع الإصدارات السابقة لإصدار Tcl 8.0، يقوم Tcl_Eval بنسخ نتيجة القيمة في interp إلى interp->result (استخدامها مهمل) حيث يمكن الوصول إليها مباشرة.
هذا يجعل Tcl_Eval أبطأ إلى حد ما من Tcl_EvalEx، الذي لا يقوم بالنسخ.

Tcl_EvalEx هو نسخة موسعة من Tcl_Eval تأخذ وسيطات إضافية numBytes و flags. لأسباب الكفاءة المذكورة أعلاه، يُفضل Tcl_EvalEx بشكل عام على Tcl_Eval.

Tcl_GlobalEval و Tcl_GlobalEvalObj هي إجراءات أقدم أصبحت مهملة الآن. وهي تشبه Tcl_EvalEx و Tcl_EvalObjEx باستثناء أن النص البرمجي يتم تقييمه في النطاق العام وسياق متغيراته يتكون من متغيرات عامة فقط (يتجاهل أي إجراءات Tcl نشطة). هذه الدوال تعادل استخدام العلامة TCL_EVAL_GLOBAL (انظر أدناه).

Tcl_VarEval يأخذ أي عدد من الوسيطات النصية بأي طول، ويدمجها في سلسلة نصية واحدة، ثم يستدعي Tcl_Eval لتنفيذ تلك السلسلة كنص برمجي Tcl. يعيد نتيجة الأمر ويعدل أيضًا interp->result بنفس الطريقة التي يعمل بها Tcl_Eval. يجب أن تكون الوسيطة الأخيرة لـ Tcl_VarEval هي (char *)NULL للإشارة إلى نهاية الوسيطات.

Tcl_VarEvalVA هو نفس Tcl_VarEval باستثناء أنه بدلاً من أخذ عدد متغير من الوسيطات، يأخذ قائمة معاملات. Tcl_VarEvalVA مهمل الآن.

بتات العلامات

يمكن استخدام أي مزيج من القيم التالية (OR) لوسيطة flags للإجراءات مثل Tcl_EvalObjEx:

TCL_EVAL_DIRECT
تستخدم هذه العلامة فقط بواسطة Tcl_EvalObjEx؛ يتم تجاهلها بواسطة الإجراءات الأخرى. إذا تم تعيين بت العلامة هذا، فلا يتم تجميع النص البرمجي إلى بايت كود؛ بدلاً من ذلك، يتم تنفيذه مباشرة كما هو الحال مع Tcl_EvalEx. علامة TCL_EVAL_DIRECT مفيدة في الحالات التي ستتغير فيها محتويات القيمة على الفور، لذلك لن يتم إعادة استخدام البايت كود في تنفيذ مستقبلي. في هذه الحالة، يكون تنفيذ النص البرمجي مباشرة أسرع.
TCL_EVAL_GLOBAL
إذا تم تعيين هذه العلامة، يتم تقييم النص البرمجي في النطاق العام بدلاً من النطاق الحالي ويتكون سياق المتغيرات الخاص به من متغيرات عامة فقط (يتجاهل أي إجراءات Tcl نشطة).

تفاصيل متنوعة

أثناء معالجة أمر Tcl، من القانوني إجراء مكالمات متداخلة لتقييم أوامر أخرى (هذه هي الطريقة التي يتم بها تنفيذ الإجراءات وبعض هياكل التحكم). إذا تم إرجاع رمز غير TCL_OK من استدعاء Tcl_EvalObjEx متداخل، فيجب على المستدعي عادةً العودة فورًا، وتمرير نفس رمز الإرجاع إلى المستدعي الخاص به، وهكذا حتى يتم الوصول إلى التطبيق الرئيسي. بعض الأوامر، مثل for، تتحقق من رموز الإرجاع معينة، مثل TCL_BREAK و TCL_CONTINUE، وتقوم بمعالجتها بشكل خاص دون العودة.

Tcl_EvalObjv(3) - Tcl

NAME

Tcl_EvalObjv, Tcl_EvalObjEx - evaluate a Tcl command from a list of objects

SYNOPSIS

#include <tcl.h>

int
Tcl_EvalObjv(interp, objc, objv, resultPtr)
Tcl_Interp *interp;
int objc;
Tcl_Obj *CONST objv[];
Tcl_Obj **resultPtr;

int
Tcl_EvalObjEx(interp, objPtr, resultPtr)
Tcl_Interp *interp;
Tcl_Obj *objPtr;
Tcl_Obj **resultPtr;

ARGUMENTS

Interpreter to use for evaluation.

Number of elements in the array objv.

Array of objects representing the words of the Tcl command. The first element of the array is the command name, and the remaining elements are its arguments.

A pointer to a Tcl_Obj **. If non-NULL, the result of the evaluation will be stored in the object pointed to by `*resultPtr`. If the result is a scalar, it will be stored as a simple string object. If it is a list, it will be stored as a list object. The caller is responsible for freeing the result object using Tcl_DecrRefCount if it is not NULL.

A pointer to an object representing the Tcl command to be evaluated. This object is not modified by the call.

DESCRIPTION

The Tcl_EvalObjv function provides a way to execute a Tcl command that is represented by an array of Tcl objects. The array objv contains objc objects, where the first object is the command name and the rest are the arguments to the command. The command is executed in the context of the Tcl interpreter specified by interp.

The Tcl_EvalObjEx function is similar to Tcl_EvalObjv, but it takes a single Tcl object objPtr that represents the command to be evaluated. This object is typically a list object where the first element is the command name and the remaining elements are the arguments.

Both functions return a value indicating the result of the evaluation. The return value is one of the following:

TCL_OK: The command completed successfully. The result of the command is stored in the object pointed to by resultPtr, if resultPtr is not NULL. If resultPtr is NULL, the result is discarded.

TCL_ERROR: An error occurred during the execution of the command. The error message is stored in the interpreter's result object. If resultPtr is not NULL, it will be set to NULL.

TCL_RETURN: The command executed a return command. The result of the return command is stored in the object pointed to by resultPtr, if resultPtr is not NULL.

TCL_BREAK: The command executed a break command. This should only happen within a loop. The result is stored in resultPtr, if not NULL.

TCL_CONTINUE: The command executed a continue command. This should only happen within a loop. The result is stored in resultPtr, if not NULL.

If a value other than TCL_OK or TCL_ERROR is returned, it indicates that a return, break, or continue command was invoked in an inappropriate place. This means that top-level applications should never see a return code from Tcl_EvalObjEx other than TCL_OK or TCL_ERROR.

KEYWORDS

execute, file, global, result, script, value
