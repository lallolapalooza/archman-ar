tc-skbmod(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

skbmod action in tc(8) Linux skbmod action in tc(8)

الاسم

skbmod - إجراء تعديل على الحزمة سهل الاستخدام

الملخص


tc ... action skbmod { set SETTABLE | swap SWAPPABLE | ecn } [ CONTROL ] [ index INDEX ]

SETTABLE := [ dmac DMAC ] [ smac SMAC ] [ etype ETYPE ]

SWAPPABLE := mac

CONTROL := { reclassify | pipe | drop | shot | continue | pass }

الوصف

يهدف إجراء skbmod إلى تحسين قابلية الاستخدام مقارنة بإجراء pedit الموجود. بدلاً من الاضطرار إلى تعديل أجزاء 8 أو 16 أو 32 بت من ترويسة الإيثرنت يدويًا، يتيح skbmod الاستبدال الكامل للعناصر المدعومة. يجب أن يكون الإجراء واحدًا من set أو swap أو ecn. يؤثر set و swap فقط على حزم الإيثرنت، بينما يؤثر ecn فقط على حزم IP.

الخيارات

dmac DMAC
تغيير عنوان MAC الوجهة إلى العنوان المحدد.
smac SMAC
تغيير عنوان MAC المصدر إلى العنوان المحدد.
etype ETYPE
تغيير نوع الإيثرنت إلى القيمة المحددة.
mac
يستخدم لتبديل عناوين MAC.
ecn
يستخدم لتمييز حزم IP الخاصة بـ ECN Capable Transport (ECT) كـ Congestion Encountered (CE). لا يؤثر على الحزم غير القادرة على ECN (Non-ECT).
CONTROL
تسمح الكلمات المفتاحية التالية بالتحكم في كيفية اجتياز شجرة qdisc، الفئات، المرشحات، والإجراءات بشكل أكبر بعد هذا الإجراء.
reclassify
إعادة البدء بالمرشح الأول في القائمة الحالية.
pipe
الاستمرار مع الإجراء التالي المرفق بنفس المرشح.
drop
shot
إسقاط الحزمة.
continue
متابعة التصنيف مع المرشح التالي في الطابور.
pass
إنهاء عملية التصنيف والعودة إلى qdisc المستدعي لمزيد من معالجة الحزمة. هذا هو الافتراضي.

أمثلة

للبدء، لاحظ المرشح التالي مع إجراء pedit:

tc filter add dev eth1 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action pedit munge offset -14 u8 set 0x02 \
	munge offset -13 u8 set 0x15 \
	munge offset -12 u8 set 0x15 \
	munge offset -11 u8 set 0x15 \
	munge offset -10 u16 set 0x1515 \
	pipe

باستخدام إجراء skbmod، يمكن تبسيط هذا الأمر إلى:

tc filter add dev eth1 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod set dmac 02:15:15:15:15:15 \
	pipe

ستزداد التعقيدات إذا تم أيضًا تحرير عنوان MAC المصدر ونوع الإيثرنت كجزء من الإجراء. إذا كان سيتم تغيير جميع الحقول الثلاثة باستخدام skbmod:

tc filter add dev eth5 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	set etype 0xBEEF \
	set dmac 02:12:13:14:15:16 \
	set smac 02:22:23:24:25:26

لتبديل عناوين MAC الوجهة والمصدر في ترويسة الإيثرنت:

tc filter add dev eth3 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	swap mac

أخيرًا، لتمييز نقطة الترميز CE في ترويسة IP لحزم ECN Capable Transport (ECT):

tc filter add dev eth0 parent 1: protocol ip prio 10 \
	u32 match ip protocol 1 0xff flowid 1:2 \
	action skbmod \
	ecn

يجب استخدام واحد فقط من set أو swap أو ecn في أمر واحد. يعتبر محاولة استخدام أكثر من واحد منها في أمر واحد سلوكًا غير معرف؛ استخدم أوامر متعددة مع pipe بدلًا من ذلك.
