Tcl_Interp *interp (في)
إذا حدث خطأ أثناء تحويل قيمة لتكون قيمة قائمة، يتم ترك رسالة خطأ في نتيجة المفسر ما لم يكن interp NULL.
Tcl_Obj *listPtr (في/خارج)
يشير إلى قيمة القائمة المراد معالجتها. إذا لم يكن listPtr يشير بالفعل إلى قيمة قائمة، فسيتم محاولة تحويلها إلى واحدة.
Tcl_Obj *elemListPtr (في/خارج)
بالنسبة لـ Tcl_ListObjAppendList، يشير هذا إلى قيمة قائمة تحتوي على عناصر سيتم إلحاقها بـ listPtr. سيصبح كل عنصر من *elemListPtr عنصرًا جديدًا في listPtr. إذا لم يكن *elemListPtr NULL ولم يكن يشير بالفعل إلى قيمة قائمة، فسيتم محاولة تحويله إلى واحدة.
Tcl_Obj *objPtr (في)
بالنسبة لـ Tcl_ListObjAppendElement، يشير إلى قيمة Tcl التي سيتم إلحاقها بـ listPtr. بالنسبة لـ Tcl_SetListObj، يشير إلى قيمة Tcl التي سيتم تحويلها إلى قيمة قائمة تحتوي على objc عنصر من المصفوفة المشار إليها بواسطة objv.
int *objcPtr (في)

Tcl_Obj ***objvPtr (خارج)

int objc (في)
عدد قيم Tcl التي ستقوم Tcl_NewListObj بإدراجها في قيمة قائمة جديدة، و Tcl_ListObjReplace بإدراجها في listPtr. بالنسبة لـ Tcl_SetListObj، عدد قيم Tcl للإدراج في objPtr.
Tcl_Obj *const objv[] (في)
مصفوفة من المؤشرات إلى القيم. ستقوم Tcl_NewListObj بإدراج هذه القيم في قيمة قائمة جديدة و Tcl_ListObjReplace بإدراجها في listPtr موجود. سيصبح كل قيمة عنصر قائمة منفصل.

عدد العناصر التي ستقوم Tcl_ListObjReplace باستبدالها.

الوصف

تحتوي قيم قوائم Tcl على تمثيل داخلي يدعم الفهرسة والإلحاق بكفاءة. تستخدم الإجراءات الموضحة في صفحة الدليل هذه لإنشاء وتعديل وفهرسة وإلحاق قيم قوائم Tcl من كود C.

تقوم كل من Tcl_ListObjAppendList و Tcl_ListObjAppendElement بإضافة قيمة واحدة أو أكثر إلى نهاية قيمة القائمة المشار إليها بواسطة listPtr. تقوم Tcl_ListObjAppendList بإلحاق كل عنصر من قيمة القائمة المشار إليها بواسطة elemListPtr بينما تقوم Tcl_ListObjAppendElement بإلحاق القيمة المفردة المشار إليها بواسطة objPtr. ستقوم كلتا الإجرائين بتحويل القيمة المشار إليها بواسطة listPtr إلى قيمة قائمة إذا لزم الأمر. إذا حدث خطأ أثناء التحويل، فسوف ترجع كلتا الإجرائين TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر إذا لم يكن interp NULL. بالمثل، إذا لم يكن elemListPtr يشير بالفعل إلى قيمة قائمة، فسوف تحاول Tcl_ListObjAppendList تحويله إلى واحدة وإذا حدث خطأ أثناء التحويل، فسوف ترجع TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر إذا لم يكن interp NULL. كلتا الإجرائين تبطل أي تمثيل نصي قديم لـ listPtr، وإذا تم تحويله إلى قيمة قائمة، فسيتم تحرير أي تمثيل داخلي قديم. وبالمثل، تقوم Tcl_ListObjAppendList بتحرير أي تمثيل داخلي قديم لـ elemListPtr إذا قامت بتحويله إلى قيمة قائمة. بعد إلحاق كل عنصر في elemListPtr، تقوم Tcl_ListObjAppendList بزيادة عدد مراجع العنصر حيث أن listPtr يشير إليه الآن أيضًا. لنفس السبب، تزيد Tcl_ListObjAppendElement عدد مراجع objPtr. إذا لم يحدث خطأ، فإن الإجرائين ترجعان TCL_OK بعد إلحاق القيم.

تقوم Tcl_NewListObj و Tcl_SetListObj بإنشاء قيمة جديدة أو تعديل قيمة موجودة للاحتفاظ بعناصر objc من المصفوفة المشار إليها بواسطة objv حيث كل عنصر هو مؤشر إلى قيمة Tcl. إذا كان objc أقل من أو يساوي صفر، فإنهما ترجعان قيمة فارغة. إذا كان objv NULL، فإن القائمة الناتجة تحتوي على 0 عنصر، مع مساحة محجوزة في تمثيل داخلي لـ objc عناصر إضافية (لتجنب إعادة تخصيصها لاحقًا). يتم ترك التمثيل النصي للقيمة الجديدة غير صالح. تزيد الإجرائين عدد مراجع العناصر في objc حيث أن قيمة القائمة تشير إليها الآن. قيمة القائمة الجديدة التي ترجعها Tcl_NewListObj لها عدد مراجع صفر.

تقوم Tcl_ListObjGetElements بإرجاع عدد ومؤشر إلى مصفوفة عناصر في قيمة قائمة. ترجع العدد بتخزينه في العنوان objcPtr. وبالمثل، ترجع مؤشر المصفوفة بتخزينه في العنوان objvPtr. الذاكرة المشار إليها تتم إدارتها بواسطة Tcl ويجب ألا يتم تحريرها أو الكتابة إليها بواسطة المتصل. إذا كانت القائمة فارغة، يتم تخزين 0 في objcPtr و NULL في objvPtr. إذا لم تكن listPtr بالفعل قيمة قائمة، فسوف تحاول Tcl_ListObjGetElements تحويلها إلى واحدة؛ إذا فشل التحويل، فإنها ترجع TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر إذا لم يكن interp NULL. بخلاف ذلك، ترجع TCL_OK بعد تخزين العدد ومؤشر المصفوفة.

تقوم Tcl_ListObjLength بإرجاع عدد العناصر في قيمة القائمة المشار إليها بواسطة listPtr. ترجع هذا العدد بتخزين عدد صحيح في العنوان lengthPtr. إذا لم تكن القيمة بالفعل قيمة قائمة، فسوف تحاول Tcl_ListObjLength تحويلها إلى واحدة؛ إذا فشل التحويل، فإنها ترجع TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر إذا لم يكن interp NULL. بخلاف ذلك، ترجع TCL_OK بعد تخزين طول القائمة.

يقوم الإجراء Tcl_ListObjIndex بإرجاع مؤشر إلى القيمة في العنصر index في القائمة المشار إليها بواسطة listPtr. يرجع هذه القيمة بتخزين مؤشر إليها في العنوان objPtrPtr. إذا لم تكن listPtr تشير بالفعل إلى قيمة قائمة، فسوف تحاول Tcl_ListObjIndex تحويلها إلى واحدة؛ إذا فشل التحويل، فإنها ترجع TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر إذا لم يكن interp NULL. إذا كان الفهرس خارج النطاق، أي أن index سالب أو أكبر من أو يساوي عدد العناصر في القائمة، فإن Tcl_ListObjIndex تخزن NULL في objPtrPtr وترجع TCL_OK. بخلاف ذلك، ترجع TCL_OK بعد تخزين مؤشر قيمة العنصر. لا يتم زيادة عدد مراجع عنصر القائمة؛ يجب على المتصل القيام بذلك إذا احتاج إلى الاحتفاظ بمؤشر للعنصر.

تقوم Tcl_ListObjReplace باستبدال صفر أو أكثر من العناصر في القائمة المشار إليها بواسطة listPtr بقيم objc في المصفوفة المشار إليها بواسطة objv. إذا لم تكن listPtr تشير إلى قيمة قائمة، فسوف تحاول Tcl_ListObjReplace تحويلها إلى واحدة؛ إذا فشل التحويل، فإنها ترجع TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر إذا لم يكن interp NULL. بخلاف ذلك، فإنها ترجع TCL_OK بعد استبدال القيم. إذا كان objv NULL، فلا يتم إضافة عناصر جديدة. إذا كان الوسيط first صفرًا أو سالبًا، فإنه يشير إلى العنصر الأول. إذا كان first أكبر من أو يساوي t

Tcl_ListObjReplace(3) — Tcl

NAME

Tcl_ListObjReplace — replace elements in a list object

SYNOPSIS

#include <tcl.h>

int
Tcl_ListObjReplace(
    Tcl_Interp *interp,
    Tcl_Obj *listPtr,
    int first,
    int count,
    int objc,
    const Tcl_Obj *const objv[]
);

ARGUMENTS

-interp (i) - Tcl interpreter to use for error reporting. If an error occurs, a message will be left in the interpreter’s result.
-listPtr (i) Pointer to the list object to modify.
-first (i) The index of the first element to replace. Negative values are invalid.
-count (i) The number of elements to delete. If count is zero or negative, no elements are deleted and the new elements are inserted.
-objc (i) The number of new elements to insert. If objc is zero then no elements are inserted.
-objv (i) Pointer to an array of objects to insert. If objv is NULL and objc is non-zero, then no elements are inserted.

DESCRIPTION

The Tcl_ListObjReplace procedure modifies the list object pointed to by listPtr. It replaces the elements starting at index first with the objc elements given by the array objv. The number of elements to be replaced is given by count. The list object listPtr must point to a Tcl list object; if it doesn’t, an error will be returned.

The replacement works as follows:

  • If count is positive, then up to count elements are deleted from the list starting at index first.
  • Then, the objc elements from the array objv are inserted into the list at index first.

If count is zero or negative, no elements are deleted. The objc new elements are simply inserted starting at index first. In this case, first can range from 0 to the current length of the list. If first is equal to the length of the list, the new elements are appended.

If objc is zero, then no elements are inserted. If count is positive, then count elements are deleted starting at index first. If count is zero or negative, nothing happens.

If count is greater than the number of elements available starting at index first, then all elements from first to the end of the list are deleted. The result is the same as if count were set to be the number of elements available.

If first is greater than or equal to the length of the list, then the new elements are appended to the list. If count is also greater than or equal to zero, then no elements are deleted.

The function returns TCL_OK if the operation was successful, and TCL_ERROR if an error occurred (e.g., if listPtr did not point to a list object, or if first was negative).

Tcl_ListObjReplace invalidates listPtr's old string representation. The reference counts of any elements inserted from objv are incremented since the resulting list now refers to them. Similarly, the reference counts for any replaced values are decremented.

Because Tcl_ListObjReplace combines both element insertion and deletion, it can be used to implement a number of list operations. For example, the following code inserts the objc values referenced by the array of value pointers objv just before the element index of the list referenced by listPtr:

result = Tcl_ListObjReplace(interp, listPtr, index, 0,
        objc, objv);

Similarly, the following code appends the objc values referenced by the array objv to the end of the list listPtr:

result = Tcl_ListObjLength(interp, listPtr, &length);
if (result == TCL_OK) {
    result = Tcl_ListObjReplace(interp, listPtr, length, 0,
            objc, objv);
}

The count list elements starting at first can be deleted by simply calling Tcl_ListObjReplace with a NULL objvPtr:

result = Tcl_ListObjReplace(interp, listPtr, first, count,
        0, NULL);
