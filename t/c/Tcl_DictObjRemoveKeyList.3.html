الحجج

Tcl_Interp *interp (in)
إذا حدث خطأ عند تحويل قيمة إلى قيمة قاموس، فسيتم ترك رسالة خطأ في قيمة نتيجة المفسر، وليس إذا كان interp فارغًا.
Tcl_Obj *dictPtr (in/out)
يشير إلى قيمة القاموس المراد معالجتها. إذا لم يكن dictPtr يشير بالفعل إلى قيمة قاموس، فسيتم محاولة تحويله.
Tcl_Obj *keyPtr (in)
يشير إلى المفتاح لزوج المفتاح/القيمة المراد معالجته داخل قيمة القاموس.
Tcl_Obj **keyPtrPtr (out)
يشير إلى متغير سيحتوي على المفتاح لزوج المفتاح/القيمة. يمكن أن يكون فارغًا للإشارة إلى أن المتصل غير مهتم بالمفتاح.
Tcl_Obj *valuePtr (in)
يشير إلى قيمة زوج المفتاح/القيمة المراد معالجته داخل قيمة القاموس (أو قيمة فرعية في حالة Tcl_DictObjPutKeyList).
Tcl_Obj **valuePtrPtr (out)
يشير إلى متغير سيحتوي على قيمة زوج المفتاح/القيمة. بالنسبة لـ Tcl_DictObjFirst و Tcl_DictObjNext، يمكن أن يكون فارغًا للإشارة إلى أن المتصل غير مهتم بالقيمة.
int *sizePtr (out)
يشير إلى متغير سيحتوي على عدد أزواج المفتاح/القيمة في القاموس.
Tcl_DictSearch *searchPtr (in/out)
يشير إلى السجل المستخدم لتتبع تكرار جميع أزواج المفتاح/القيمة في قاموس. يتم تهيئة محتويات السجل عن طريق استدعاء Tcl_DictObjFirst. إذا كان يجب إنهاء التكرار قبل إرجاع جميع قيم القاموس، فيجب تمرير سجل البحث إلى Tcl_DictObjDone لتحرير الضوابط الداخلية.
int *donePtr (out)
يشير إلى متغير سيحتوي على قيمة غير صفرية عندما ينتهي تكرار أزواج المفتاح/القيمة للقاموس، وصفر بخلاف ذلك.
int keyc (in)
يشير إلى عدد المفاتيح التي سيتم توفيرها في مصفوفة keyv.
Tcl_Obj *const *keyv (in)
مصفوفة من keyc مؤشرات إلى قيم ستستخدمها Tcl_DictObjPutKeyList و Tcl_DictObjRemoveKeyList لتحديد موقع زوج المفتاح/القيمة المراد معالجته داخل القواميس الفرعية لقيمة القاموس الرئيسية.

الوصف

تحتوي قيم قواميس Tcl على تمثيل داخلي يدعم الربط الفعال للمفاتيح بالقيم ويضمن بقاء ترتيب المفاتيح في القاموس هو نفسه، حتى لو تم حذفها أو إضافتها (مما يزيلها من الترتيب).

تُستخدم الإجراءات الموضحة في صفحة الدليل هذه لإنشاء قيم القاموس وتعديلها وفهرستها والتكرار عليها من كود C.

Tcl_NewDictObj ينشئ قيمة قاموس فارغة جديدة. سيكون التمثيل النصي للقيمة غير صالح وسيحتوي عداد المراجع للقيمة على صفر.

Tcl_DictObjGet يبحث عن المفتاح المحدد داخل القاموس ويكتب مؤشرًا إلى القيمة المرتبطة بهذا المفتاح في المتغير المشار إليه بواسطة valuePtrPtr، أو NULL إذا لم يكن هناك ربط لهذا المفتاح. ستكون نتيجة هذه العملية TCL_OK، أو TCL_ERROR إذا تعذر تحويل dictPtr إلى قاموس.

Tcl_DictObjPut يقوم بتحديث القاموس بحيث يرتبط المفتاح المحدد بالقيمة المحددة؛ يمكن أن يوجد أي مفتاح مرة واحدة فقط في القاموس. يجب ألا تتم مشاركة القاموس، ولكن يمكن مشاركة المفاتيح والقيم. قد تزيد هذه العملية من عداد المراجع لكل من المفتاح والقيمة إذا لزم الأمر لتخزينهما. لا ينبغي أن يكون المفتاح أو القيمة NULL. ستكون نتيجة هذه العملية TCL_OK، أو TCL_ERROR إذا تعذر تحويل dictPtr إلى قاموس.

Tcl_DictObjRemove يقوم بتحديث القاموس بحيث لا يرتبط المفتاح المحدد بأي قيمة. يجب ألا تتم مشاركة القاموس، ولكن يمكن مشاركة المفتاح. سيقلل المفتاح المخزن في القاموس من عداد المراجع الخاص به إذا كان موجودًا مسبقًا. لا يعتبر خطأ إذا لم يكن المفتاح موجودًا مسبقًا. ستكون نتيجة هذه العملية TCL_OK، أو TCL_ERROR إذا تعذر تحويل dictPtr إلى قاموس.

Tcl_DictObjSize يقوم بتحديث المتغير المشار إليه بعدد أزواج المفتاح/القيمة الموجودة حاليًا في القاموس. ستكون نتيجة هذه العملية TCL_OK، أو TCL_ERROR إذا تعذر تحويل dictPtr إلى قاموس.

Tcl_DictObjFirst يبدأ التكرار على جميع أزواج المفتاح/القيمة في القاموس، ويضع المفتاح والقيمة في المتغيرات المشار إليها بواسطة keyPtrPtr و valuePtrPtr (والتي يمكن أن تكون NULL للإشارة إلى أن المتصل غير مهتم بالمفتاح أو المتغير على التوالي). يمكن الحصول على زوج المفتاح/القيمة التالي في القاموس باستخدام Tcl_DictObjNext. لن تؤدي التحديثات المتزامنة للتمثيل الداخلي للقاموس إلى تغيير عملية التكرار، إلا إذا لم تتم مشاركة القاموس، وفي هذه الحالة سينتهي التكرار مبكرًا (مما لا يمكن أن يحدث بواسطة أمر dict في نصوص Tcl). يشير الوسيط searchPtr إلى سياق يستخدم لتحديد أي تكرار معين يتم تنفيذه، ويتم تهيئته عن طريق استدعاء Tcl_DictObjFirst. يشير الوسيط donePtr إلى متغير يتم تحديثه إلى صفر إذا كانت هناك أزواج مفتاح/قيمة أخرى للتكرار، أو إلى غير الصفر إذا اكتمل التكرار. ترتيب التكرار محدد بشكل ضمني. إذا تعذر تحويل dictPtr إلى قاموس، فإن Tcl_DictObjFirst يعيد TCL_ERROR ولن يبدأ التكرار، وإلا فإنه يعيد TCL_OK.

عند استدعاء Tcl_DictObjFirst على قاموس، يتم وضع قفل على القاموس للسماح بالتكرار على مفاتيح القاموس بأمان، بغض النظر عما إذا كان القاموس قد تم تعديله أثناء التكرار. لهذا السبب، بمجرد انتهاء التكرار على مفاتيح القاموس (إما بسبب اكتمال عدد القيم المتكررة المشار إليها بواسطة الوسيط donePtr تم تعيينها إلى 1، أو بسبب عدم الحاجة إلى المزيد من القيم)، يجب استدعاء Tcl_DictObjDone بنفس searchPtr الذي تم استخدامه في Tcl_DictObjFirst لتحرير الضوابط الداخلية. بمجرد تمرير searchPtr معين إلى Tcl_DictObjDone، فإن تمريره إلى Tcl_DictObjNext (دون تهيئته باستخدام Tcl_DictObjFirst) سيؤدي إلى إنتاج أي قيم وسيتم تعيين المتغير المشار إليه بواسطة donePtr إلى 1. من الآمن استدعاء Tcl_DictObjDone عدة مرات على نفس searchPtr لكل استدعاء لـ Tcl_DictObjFirst.

تعد الإجراءات Tcl_DictObjPutKeyList و Tcl_DictObjRemoveKeyList نظائر مغلقة لـ Tcl_DictObjPut و Tcl_DictObjRemove، باستثناء أنها تعمل مع أشجار من القواميس المتداخلة، مع تخزين القواميس الداخلية كقيم داخل القواميس الخارجية. تحدد الوسائط keyc و keyv قائمة مفاتيح (مع المفاتيح الخارجية أولاً) تعمل كمسار لزوج المفتاح/القيمة المراد تعديله. لاحظ أنه لا توجد عملية مقابلة لقراءة قيمة.

Tcl_DictObjRemoveKeyList(3)

NAME

Tcl_DictObjGet, Tcl_DictObjPutKeyList, Tcl_DictObjRemoveKeyList – dictionary access with index lists

SYNOPSIS

#include <tcl.h>

int
Tcl_DictObjGet(interp, dictPtr, keyList, valuePtr)
    Tcl_Interp *interp;
    Tcl_Obj *dictPtr;
    Tcl_Obj *keyList;
    Tcl_Obj **valuePtr;
int
Tcl_DictObjPutKeyList(interp, dictPtr, keyList, valuePtr)
    Tcl_Interp *interp;
    Tcl_Obj *dictPtr;
    Tcl_Obj *keyList;
    Tcl_Obj *valuePtr;
int
Tcl_DictObjRemoveKeyList(interp, dictPtr, keyList)
    Tcl_Interp *interp;
    Tcl_Obj *dictPtr;
    Tcl_Obj *keyList;

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj *dictPtr
Object pointer to a dictionary object.
Tcl_Obj *keyList
A list whose elements form a key or a path of keys into the dictionary.
Tcl_Obj **valuePtr
Location to store pointer to value object. If the key is not found, and the operation is not modifying, this will be NULL. The caller owns the reference count of this object.
Tcl_Obj *valuePtr
Value object to store in the dictionary.

DESCRIPTION

These functions provide a way to access nested dictionary values using a list of keys that specifies a path into the dictionary. This is useful for accessing dictionary values when the path is computed at runtime.

Tcl_DictObjGet retrieves the value associated with the path specified by keyList from the dictionary dictPtr. If the path is found, the value is placed in *valuePtr and the function returns TCL_OK. If the path is not found, or if any element along the path is not itself a dictionary (except for the final element), then TCL_OK is returned and *valuePtr is set to NULL.

Tcl_DictObjPutKeyList inserts or updates the value specified by valuePtr into the dictionary dictPtr at the location specified by keyList. If any non-terminal keys along the path do not exist, they are created as empty dictionaries. If dictPtr does not contain a dictionary value at any point along the path (except possibly the final element), an error is returned. Otherwise, the key/value pair is stored and TCL_OK is returned. Note that the value object passed in valuePtr is not copied; its reference count is incremented.

Tcl_DictObjRemoveKeyList removes the value associated with the path specified by keyList from the dictionary dictPtr. All non-terminal keys along the path must exist and have dictionary values; otherwise, an error is returned. If the removal is successful, TCL_OK is returned. Note that any intermediate dictionaries that become empty as a result of the removal are not removed.

The keyList must be a list object. The elements of the list are used sequentially to traverse the dictionary. For example, if keyList is {a b c}, Tcl_DictObjGet will look for the value associated with the key c in the dictionary which is the value of the key b in the dictionary which is the value of the key a in the original dictionary dictPtr.

Tcl_DictObjPutKeyList is more convenient than a sequence of Tcl_DictObjGet and Tcl_DictObjSet calls when dealing with nested dictionaries. It provides a way to specify a path as this is easy to construct from repeated use of Tcl_DictObjGet. With Tcl_DictObjPutKeyList, nested dictionaries are created for non-terminal keys where they do not already exist. With Tcl_DictObjRemoveKeyList, all non-terminal keys must exist and have dictionaries as their values.

EXAMPLE

Using the dictionary iteration interface to search determine if there is a key that maps to itself:

Tcl_DictSearch search;
Tcl_Obj *key, *value;
int done;
/*
 * Assume interp and objPtr are parameters.  This is the
 * idiomatic way to start an iteration over the dictionary; it
 * sets a lock on the internal representation that ensures that
 * there are no concurrent modification issues when normal
 * reference count management is also used.  The lock is
 * released automatically when the loop is finished, but must
 * be released manually when an exceptional exit from the loop
 * is performed. However it is safe to try to release the lock
 * even if we've finished iterating over the loop.
 */
if (Tcl_DictObjFirst(interp, objPtr, &search,
        &key, &value, &done) != TCL_OK) {
    return TCL_ERROR;
}
for (; !done ; Tcl_DictObjNext(&search, &key, &value, &done)) {
    /*
     * Note that strcmp() is not a good way of comparing
     * values and is just used here for demonstration
     * purposes.
     */
    if (!strcmp(Tcl_GetString(key), Tcl_GetString(value))) {
        break;
    }
}
Tcl_DictObjDone(&search);
Tcl_SetObjResult(interp, Tcl_NewBooleanObj(!done));
return TCL_OK;
