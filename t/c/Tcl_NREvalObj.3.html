Tcl_NREvalObj(3)

NAME

Tcl_NREvalObj - evaluate a Tcl script represented by a Tcl object

SYNOPSIS

#include <tcl.h>

int
Tcl_NREvalObj(interp, script, resultPtr)
    Tcl_Interp *interp;
    Tcl_Obj *script;
    Tcl_Obj **resultPtr;

ARGUMENTS

interp (in)
Interpreter to use for evaluation.
script (in)
The script to evaluate, as a Tcl object.
resultPtr (out)
Pointer to the result object. The object will be created by the function and must be disposed of by the caller.

DESCRIPTION

The Tcl_NREvalObj function provides a way to evaluate a Tcl script represented by a Tcl object, without needing to create a new Tcl object for the result.

The script is evaluated in the interpreter specified by interp. The result of the evaluation is stored in the Tcl object pointed to by resultPtr. The caller is responsible for disposing of the result object when it is no longer needed by calling Tcl_DecrRefCount.

The return value is a Tcl result code (TCL_OK, TCL_ERROR, or TCL_RETURN). If an error occurs during evaluation, information about the error is placed in the interpreter’s error message variable.

EXAMPLE

Tcl_Interp *interp;
Tcl_Obj *script;
Tcl_Obj *result;
int code;

interp = Tcl_CreateInterp();
script = Tcl_NewStringObj("puts hello", -1);

code = Tcl_NREvalObj(interp, script, &result);
if (code == TCL_OK) {
    printf("Result: %s\n", Tcl_GetString(result));
} else {
    fprintf(stderr, "Error: %s\n", Tcl_GetVar(interp, "errorInfo", 0));
}

Tcl_DecrRefCount(interp, script);
Tcl_DecrRefCount(interp, result);
Tcl_DeleteInterp(interp);
