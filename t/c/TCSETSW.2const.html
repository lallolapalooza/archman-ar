الوصف

TCGETS
مكافئ لـ tcgetattr(fd, argp).
الحصول على إعدادات المنفذ التسلسلي الحالية.
TCSETS
مكافئ لـ tcsetattr(fd, TCSANOW, argp).
تعيين إعدادات المنفذ التسلسلي الحالية.
TCSETSW
مكافئ لـ tcsetattr(fd, TCSADRAIN, argp).
السماح بتصريف مخزن الإخراج المؤقت، وتعيين إعدادات المنفذ التسلسلي الحالية.
TCSETSF
مكافئ لـ tcsetattr(fd, TCSAFLUSH, argp).
السماح بتصريف مخزن الإخراج المؤقت، وتجاهل الإدخال المعلق، وتعيين إعدادات المنفذ التسلسلي الحالية.

الأوامر الأربعة التالية لـ ioctl هي تمامًا مثل TCGETS، TCSETS، TCSETSW، TCSETSF، باستثناء أنها تأخذ struct termios2 * بدلاً من struct termios *. إذا كان عضو البنية c_cflag يحتوي على العلم BOTHER، فعندئذ يتم تخزين معدل الباود في أعضاء البنية c_ispeed و c_ospeed كقيم صحيحة. لا يتم دعم أوامر ioctl هذه على جميع البنيات.

أمثلة

الحصول على معدل باود عشوائي أو تعيينه على المنفذ التسلسلي.

/* SPDX-License-Identifier: GPL-2.0-or-later */
#include <asm/termbits.h>
#include <fcntl.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ioctl.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
#if !defined BOTHER
    fprintf(stderr, "BOTHER غير مدعوم\n");
    /* قد يتراجع البرنامج إلى TCGETS/TCSETS مع ثوابت Bnnn */
    exit(EXIT_FAILURE);
#else
    /* إعلان بنية tio، نوعها يعتمد على ioctl المدعوم */
# if defined TCGETS2
    struct termios2 tio;
# else
    struct termios tio;
# endif
    int fd, rc;
    if (argc != 2 && argc != 3 && argc != 4) {
        fprintf(stderr, "الاستخدام: %s device [output [input] ]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    fd = open(argv[1], O_RDWR | O_NONBLOCK | O_NOCTTY);
    if (fd < 0) {
        perror("open");
        exit(EXIT_FAILURE);
    }
    /* الحصول على إعدادات المنفذ التسلسلي الحالية عبر ioctl المدعوم */
# if defined TCGETS2
    rc = ioctl(fd, TCGETS2, &tio);
# else
    rc = ioctl(fd, TCGETS, &tio);
# endif
    if (rc) {
        perror("TCGETS");
        close(fd);
        exit(EXIT_FAILURE);
    }
    /* تغيير معدل الباود عند توفير وسيطات إضافية */
    if (argc == 3 || argc == 4) {
        /* مسح معدل الباود للإخراج الحالي وتعبئة قيمة جديدة */
        tio.c_cflag &= ~CBAUD;
        tio.c_cflag |= BOTHER;
        tio.c_ospeed = atoi(argv[2]);
        /* مسح معدل الباود للإدخال الحالي وتعبئة قيمة جديدة */
        tio.c_cflag &= ~(CBAUD << IBSHIFT);
        tio.c_cflag |= BOTHER << IBSHIFT;
        /* عندما لا يتم توفير الوسيطة الرابعة، أعد استخدام معدل الباود للإخراج */
        tio.c_ispeed = (argc == 4) ? atoi(argv[3]) : atoi(argv[2]);
        /* تعيين إعدادات المنفذ التسلسلي الجديدة عبر ioctl المدعوم */
# if defined TCSETS2
        rc = ioctl(fd, TCSETS2, &tio);
# else
        rc = ioctl(fd, TCSETS, &tio);
# endif
        if (rc) {
            perror("TCSETS");
            close(fd);
            exit(EXIT_FAILURE);
        }
        /* والحصول على القيم الجديدة التي تم تكوينها بالفعل */
# if defined TCGETS2
        rc = ioctl(fd, TCGETS2, &tio);
# else
        rc = ioctl(fd, TCGETS, &tio);
# endif
        if (rc) {
            perror("TCGETS");
            close(fd);
            exit(EXIT_FAILURE);
        }
    }
    close(fd);
    printf("معدل الباود للإخراج: %u\n", tio.c_ospeed);
    printf("معدل الباود للإدخال: %u\n", tio.c_ispeed);
    exit(EXIT_SUCCESS);
#endif
}

TCSETSW(2)

Linux Programmer's Manual

NAME

tcsetpgrp, tcgetsid, tcsetpgrp, tcgetpgrp, tcsetsid — set terminal foreground process group

LIBRARY

Terminal Control Library (libutil, so, -lutil)

SYNOPSIS

#include <termios.h>

pid_t tcgetpgrp(int fd);
int tcsetpgrp(int fd, pid_t pgrp);

DESCRIPTION

The tcgetpgrp() function returns the process group ID of the foreground process group on the terminal associated with the file descriptor fd.

The tcsetpgrp() function sets the foreground process group ID on the terminal associated with the file descriptor fd to pgrp. The calling process must have the same terminal associated with its file descriptor fd as the process group pgrp. The calling process must also be a member of the process group pgrp. In addition, the calling process must have the necessary permissions (see CAP_SYS_ADMIN capability or be the owner of the terminal device).

A controlling terminal is associated with a session. Within a session, there can be multiple process groups. One of these process groups can be the foreground process group. All other process groups are background process groups.

When a controlling terminal is opened, it is assigned to the foreground process group of the session. If no process group is currently the foreground process group, then the calling process becomes the foreground process group. If a process is to be allowed to move to the background, it must first create a new process group (typically by calling fork(2) and setsid(2)).

When a signal is sent to a process group (e.g., signal(7)), the default behavior is that the signal is sent to the foreground process group. For example, when the user presses the interrupt key (typically DEL), the SIGINT signal is sent to the foreground process group. When the user presses the quit key (typically Ctrl+\), the SIGQUIT signal is sent to the foreground process group. When the user presses the suspend key (typically Ctrl+Z), the SIGTSTP signal is sent to the foreground process group.

If a process moves itself into the background by calling setpgid(2), it should then call tcsetpgrp(2) to give up the foreground. If it does not, it will continue to receive signals intended for the foreground process group.

RETURN VALUE

On success, tcgetpgrp() returns the foreground process group ID. On failure, it returns -1 and sets errno to indicate the error.

On success, tcsetpgrp() returns 0. On failure, it returns -1 and sets errno to indicate the error.

ERRORS

EBADF
fd is not a valid file descriptor.
ENOTTY
The file descriptor fd refers to a terminal.
EPERM
The effective user ID of the calling process does not have the necessary permissions to set the foreground process group ID.
ESRCH
The process group ID pgrp does not exist.

HISTORY

These functions first appeared in POSIX.1-1990.

CAVEATS

The functions tcsetpgrp(2) and tcgetpgrp(2) are not present in POSIX.1-2001 but are available as extensions. They are part of the POSIX.1-2008 standard.

EXAMPLES

Get the foreground process group ID:

pid_t pgrp;
                pgrp = tcgetpgrp(STDOUT_FILENO);
                if (pgrp == -1) {
                    perror("tcgetpgrp");
                    exit(EXIT_FAILURE);
                }
                printf("Foreground process group ID: %d\n", pgrp);

Set the foreground process group ID:

pid_t pid = getpid();
                pid_t pgrp = getpgrp();
                if (tcsetpgrp(STDOUT_FILENO, pgrp) == -1) {
                    perror("tcsetpgrp");
                    exit(EXIT_FAILURE);
                }

TCSETSW(2)

دليل مبرمج Linux

الاسم

tcsetpgrp, tcgetsid, tcsetpgrp, tcgetpgrp, tcsetsid — تعيين مجموعة العمليات الأمامية للمحطة الطرفية

المكتبة

مكتبة تحكم المحطة الطرفية (libutil, so, -lutil)

الملخص

#include <termios.h>

pid_t tcgetpgrp(int fd);
int tcsetpgrp(int fd, pid_t pgrp);

الوصف

تقوم الدالة tcgetpgrp() بإرجاع معرف مجموعة العمليات لمجموعة العمليات الأمامية على المحطة الطرفية المرتبطة بوصف الملف fd.

تقوم الدالة tcsetpgrp() بتعيين معرف مجموعة العمليات الأمامية على المحطة الطرفية المرتبطة بوصف الملف fd إلى pgrp. يجب أن تكون العملية المتصلة تمتلك نفس المحطة الطرفية المرتبطة بوصف ملفها fd كمجموعة العمليات pgrp. يجب أن تكون العملية المتصلة أيضًا عضوًا في مجموعة العمليات pgrp. بالإضافة إلى ذلك، يجب أن تمتلك العملية المتصلة الأذونات اللازمة (راجع CAP_SYS_ADMIN أو أن تكون مالك جهاز المحطة الطرفية).

ترتبط المحطة الطرفية المتحكمة بجلسة. ضمن الجلسة، يمكن أن يكون هناك مجموعات عمليات متعددة. يمكن أن تكون إحدى هذه المجموعات هي مجموعة العمليات الأمامية. جميع مجموعات العمليات الأخرى هي مجموعات عمليات خلفية.

عند فتح محطة طرفية متحكمة، يتم تعيينها لمجموعة العمليات الأمامية للجلسة. إذا لم تكن هناك مجموعة عمليات تمثل مجموعة العمليات الأمامية حاليًا، فإن العملية المتصلة تصبح مجموعة العمليات الأمامية. إذا كان سيُسمح لعملية بالانتقال إلى الخلفية، فيجب عليها أولاً إنشاء مجموعة عمليات جديدة (عادةً عن طريق استدعاء fork(2) و setsid(2)).

عند إرسال إشارة إلى مجموعة عمليات (مثل signal(7))، يكون السلوك الافتراضي هو إرسال الإشارة إلى مجموعة العمليات الأمامية. على سبيل المثال، عندما يضغط المستخدم على مفتاح المقاطعة (عادةً DEL)، يتم إرسال إشارة SIGINT إلى مجموعة العمليات الأمامية. عندما يضغط المستخدم على مفتاح الإنهاء (عادةً Ctrl+\)، يتم إرسال إشارة SIGQUIT إلى مجموعة العمليات الأمامية. عندما يضغط المستخدم على مفتاح الإيقاف المؤقت (عادةً Ctrl+Z)، يتم إرسال إشارة SIGTSTP إلى مجموعة العمليات الأمامية.

إذا نقلت عملية نفسها إلى الخلفية عن طريق استدعاء setpgid(2)، فيجب عليها بعد ذلك استدعاء tcsetpgrp(2) للتخلي عن الواجهة الأمامية. إذا لم تفعل ذلك، فستستمر في تلقي الإشارات المخصصة لمجموعة العمليات الأمامية.

قيمة الإرجاع

عند النجاح، تُرجع tcgetpgrp() معرف مجموعة العمليات الأمامية. عند الفشل، تُرجع -1 وتعيّن errno للإشارة إلى الخطأ.

عند النجاح، تُرجع tcsetpgrp() 0. عند الفشل، تُرجع -1 وتعيّن errno للإشارة إلى الخطأ.

الأخطاء

EBADF
fd ليس وصف ملف صالح.
ENOTTY
يشير وصف الملف fd إلى محطة طرفية.
EPERM
معرف المستخدم الفعال للعملية المتصلة لا يمتلك الأذونات اللازمة لتعيين معرف مجموعة العمليات الأمامية.
ESRCH
معرف مجموعة العمليات pgrp غير موجود.

التاريخ

ظهرت هذه الدوال لأول مرة في POSIX.1-1990.

تحذيرات

الدوال tcsetpgrp(2) و tcgetpgrp(2) غير موجودة في POSIX.1-2001 ولكنها متاحة كملحقات. وهي جزء من معيار POSIX.1-2008.

أمثلة

الحصول على معرف مجموعة العمليات الأمامية:

pid_t pgrp;
                pgrp = tcgetpgrp(STDOUT_FILENO);
                if (pgrp == -1) {
                    perror("tcgetpgrp");
                    exit(EXIT_FAILURE);
                }
                printf("معرف مجموعة العمليات الأمامية: %d\n", pgrp);

تعيين معرف مجموعة العمليات الأمامية:

pid_t pid = getpid();
                pid_t pgrp = getpgrp();
                if (tcsetpgrp(STDOUT_FILENO, pgrp) == -1) {
                    perror("tcsetpgrp");
                    exit(EXIT_FAILURE);
                }
