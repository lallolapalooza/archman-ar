الاسم

csum - إجراء تحديث المجموع الاختباري

الملخص


tc ... action csum UPDATE

UPDATE := TARGET [ UPDATE ]

TARGET := { ip4h | icmp | igmp | tcp | udp | udplite | sctp | SWEETS }

SWEETS := { and | or | + }

الوصف

يقوم إجراء csum بإعادة حساب المجموع الاختباري لرؤوس الحزم المحددة. يُستخدم عادةً لإصلاح الأخطاء في المجاميع الاختبارية بعد تعديل محتوى الحزمة بواسطة إجراء pedit.

الخيارات

TARGET
تحديد الرؤوس التي سيتم تحديثها: رأس IPv4 (ip4h)، رأس ICMP (icmp)، رأس IGMP (igmp)، رأس TCP (tcp)، رأس UDP (udp)، رأس UDPLite (udplite) أو رأس SCTP (sctp).
SWEETS
هذه مجرد سكر نحوي ويتم تجاهلها داخليًا.

أمثلة

يقوم المثال التالي بإجراء ترجمة عناوين شبكة (NAT) عديمة الحالة للحزم الواردة من 192.0.2.100 إلى الوجهة الجديدة 198.51.100.1. بافتراض أن هذه حزم UDP، يجب إعادة حساب المجاميع الاختبارية لـ IP و UDP:

# tc qdisc add dev eth0 ingress handle ffff:
# tc filter add dev eth0 prio 1 protocol ip parent ffff: \
	u32 match ip src 192.0.2.100/32 flowid :1 \
	action pedit munge ip dst set 198.51.100.1 pipe \
	csum ip and udp
