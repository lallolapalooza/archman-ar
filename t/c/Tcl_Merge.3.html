NAME

Tcl_Merge - merge two lists into a new list

SYNOPSIS

#include <tcl.h>

int
Tcl_Merge(interp, list1, list2, resultPtr)
Tcl_Interp *interp;
Tcl_Obj *list1;
Tcl_Obj *list2;
Tcl_Obj **resultPtr;

ARGUMENTS

$interp
Interpreter to use for error reporting and object creation.
$list1
First list object.
$list2
Second list object.
$resultPtr
Pointer to the location where the resulting list object will be stored.

DESCRIPTION

The Tcl_Merge function is used to merge two Tcl lists into a new list. The first list's elements are appended to the second list's elements in the resulting list. Both input lists are preserved in their original form. If either of the input objects is not a list, an error will be reported and TCL_ERROR will be returned. Otherwise, a new list object representing the merged list is created and stored in the location pointed to by resultPtr, and TCL_OK is returned.

SEE ALSO

Tcl_ConcatObj, Tcl_ListObjAppendElement, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_NewListObj

KEYWORDS

list, merge, append

NAME

Tcl_Merge - دمج قائمتين في قائمة جديدة

SYNOPSIS

#include <tcl.h>

int
Tcl_Merge(interp, list1, list2, resultPtr)
Tcl_Interp *interp;
Tcl_Obj *list1;
Tcl_Obj *list2;
Tcl_Obj **resultPtr;

ARGUMENTS

$interp
المترجم المراد استخدامه للإبلاغ عن الأخطاء وإنشاء الكائنات.
$list1
كائن القائمة الأولى.
$list2
كائن القائمة الثانية.
$resultPtr
مؤشر إلى الموقع الذي سيتم فيه تخزين كائن القائمة الناتجة.

DESCRIPTION

تُستخدم الدالة Tcl_Merge لدمج قائمتين من Tcl في قائمة جديدة. يتم إلحاق عناصر القائمة الأولى بعناصر القائمة الثانية في القائمة الناتجة. يتم الحفاظ على كلتا القائمتين المدخلتين في شكلهما الأصلي. إذا كان أي من الكائنات المدخلة ليس قائمة، فسيتم الإبلاغ عن خطأ وسيتم إرجاع TCL_ERROR. وإلا، سيتم إنشاء كائن قائمة جديد يمثل القائمة المدمجة وتخزينه في الموقع المشار إليه بواسطة resultPtr، وسيتم إرجاع TCL_OK.

SEE ALSO

Tcl_ConcatObj, Tcl_ListObjAppendElement, Tcl_ListObjGetElements, Tcl_ListObjLength, Tcl_NewListObj

KEYWORDS

قائمة، دمج، إلحاق
