Tcl_StringMatch(3)

الحزمة: tcl

التراخيص: TCL

Tcl_StringMatch(3) إجراءات مكتبة Tcl Tcl_StringMatch(3)

الاسم

Tcl_StringMatch، Tcl_StringCaseMatch - اختبار ما إذا كانت السلسلة تتطابق مع نمط

ملخص

#include <tcl.h>

int
Tcl_StringMatch(str, pattern)

int
Tcl_StringCaseMatch(str, pattern, flags)

الوسائط

const char *str (مدخل)
السلسلة المراد اختبارها.
const char *pattern (مدخل)
النمط للمطابقة مع السلسلة. قد يحتوي على أحرف خاصة من المجموعة *?\[].
int flags (مدخل)
مزيج مع OR للأعلام المطابقة، حاليًا فقط TCL_MATCH_NOCASE. 0 يحدد بحثًا حساسًا لحالة الأحرف.

الوصف

يحدد هذا الإجراء المساعد ما إذا كانت السلسلة تتطابق مع نمط معين. إذا كانت كذلك، فإن Tcl_StringMatch تُرجع 1. وإلا فإن Tcl_StringMatch تُرجع 0. الخوارزمية المستخدمة للمطابقة هي نفس الخوارزمية المستخدمة في أمر Tcl string match وهي مشابهة للخوارزمية المستخدمة بواسطة C-shell لمطابقة أسماء الملفات؛ انظر إدخال دليل Tcl للتفاصيل.

في Tcl_StringCaseMatch، الخوارزمية هي نفسها، ولكن لديك خيار جعل المطابقة غير حساسة لحالة الأحرف. إذا اخترت ذلك (عن طريق تمرير TCL_MATCH_NOCASE)، فسيتم مطابقة السلسلة والنمط بشكل أساسي بالأحرف الصغيرة.
