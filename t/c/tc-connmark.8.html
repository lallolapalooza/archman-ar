الاسم

connmark - إجراء مستعيد connmark لشبكة netfilter

الملخص


tc ... action connmark [ zone u16_zone_index ] [ CONTROL ] [ index u32_index ]

CONTROL := { reclassify | pipe | drop | continue | ok }

الوصف

يُستخدم إجراء connmark لاستعادة قيمة علامة الاتصال (connection's mark value) إلى علامة الحزمة (packet's fwmark).

خيارات

zone u16_zone_index
تحديد منطقة تتبع الاتصال (conntrack zone) عند إجراء عمليات البحث في تتبع الاتصال للحزم. u16_zone_index هو قيمة عشرية غير موقعة بطول 16 بت.
CONTROL
كيفية المتابعة بعد تنفيذ هذا الإجراء.
reclassify
يعيد تصنيف الحزمة عن طريق القفز مرة أخرى إلى أول عامل تصفية (filter) ملحق بأصل هذا الإجراء.
pipe
المتابعة بالإجراء التالي، وهذا هو الوضع الافتراضي.
drop
shot
سيتم إسقاط الحزمة دون تشغيل إجراءات أخرى.
continue
متابعة التصنيف مع عامل التصفية التالي في الصف.
pass
العودة إلى قائمة انتظار (qdisc) الاستدعاء لمعالجة الحزمة. هذا ينهي عملية التصنيف.
index u32_index
تحديد فهرس (index) لهذا الإجراء لتتمكن من تحديده في الأوامر اللاحقة. u32_index هو قيمة عشرية غير موقعة بطول 32 بت.
