الوصف

هذه الإجراءات مخصصة للوصول إلى مرفق المترجمات المتعددة من داخل برامج C. تمكّن من إدارة مترجمات متعددة في علاقة هرمية، وإدارة الأسماء المستعارة، وهي أوامر عند استدعائها في مترجم واحد تقوم بتنفيذ أمر في مترجم آخر. القيمة المرتجعة لهذه الإجراءات التي تعيد int هي إما TCL_OK أو TCL_ERROR. إذا تم إرجاع TCL_ERROR، فإن نتيجة المترجم تحتوي على رسالة خطأ.

Tcl_CreateSlave ينشئ مترجمًا جديدًا كطفل لـ interp. كما ينشئ أمرًا فرعيًا يسمى childName في interp والذي يسمح لـ interp بمعالجة الطفل الجديد. إذا كان isSafe صفراً، فإن الأمر ينشئ طفلاً موثوقًا به يتمتع فيه رمز Tcl بالوصول إلى جميع أوامر Tcl. إذا كان 1، فإن الأمر ينشئ طفلاً "آمنًا" يتمتع فيه رمز Tcl بالوصول إلى مجموعة أوامر Tcl المحددة كـ "Safe Tcl"؛ راجع صفحة الدليل لأمر interp في Tcl للحصول على التفاصيل. إذا فشل إنشاء المترجم الفرعي الجديد، يتم إرجاع NULL.

Tcl_CreateChild مرادف لـ Tcl_CreateSlave.

Tcl_IsSafe يعيد 1 إذا كان interp "آمنًا" (تم إنشاؤه مع تحديد العلم TCL_SAFE_INTERPRETER)، 0 بخلاف ذلك.

Tcl_MakeSafe يميز interp على أنه "آمن"، بحيث تعيد الاستدعاءات المستقبلية لـ Tcl_IsSafe القيمة 1. كما يزيل جميع وظائف النواة الأساسية المحتملة الخطورة المعروفة (الأوامر والمتغيرات) من interp. ومع ذلك، لا يمكنه معرفة الأجزاء الآمنة من امتداد أو تطبيق ولا يقوم بأي محاولة لإزالة تلك الأجزاء، لذا لا يمكن ضمان السلامة بعد استدعاء Tcl_MakeSafe. سيرغب المستدعون في توخي الحذر مع استخدامهم لـ Tcl_MakeSafe لتجنب المطالبات الخاطئة بالسلامة. في العديد من الحالات، قد يكون Tcl_CreateSlave خيارًا أفضل، نظرًا لأنه ينشئ مترجمات في حالة آمنة معروفة.

Tcl_GetSlave يعيد مؤشرًا إلى مترجم فرعي لـ interp. يتم تحديد المترجم الفرعي بواسطة childName. إذا لم يكن هناك مثل هذا المترجم الفرعي، يتم إرجاع NULL.

Tcl_GetChild مرادف لـ Tcl_GetSlave.

Tcl_GetMaster يعيد مؤشرًا إلى المترجم الرئيسي لـ interp. إذا لم يكن لدى interp سيد (إنه مترجم من المستوى الأعلى) فإن NULL يتم إرجاعه.

Tcl_GetParent مرادف لـ Tcl_GetMaster.

Tcl_GetInterpPath يخزن في نتيجة interp المسار النسبي بين interp و childInterp؛ يجب أن يكون childInterp طفلاً لـ interp. إذا نجح حساب المسار النسبي، يتم إرجاع TCL_OK، وإلا يتم إرجاع TCL_ERROR ويتم تخزين رسالة خطأ كنتيجة لـ interp.

Tcl_CreateAlias ينشئ أمرًا يسمى childCmd في childInterp والذي عند استدعائه، سيؤدي إلى استدعاء الأمر targetCmd في targetInterp. يتم دائمًا إضافة الوسائط المحددة بواسطة السلاسل الموجودة في argv إلى بداية أي وسائط مقدمة في استدعاء childCmd ويتم تمريرها إلى targetCmd. هذه العملية تعيد TCL_OK إذا نجحت، أو TCL_ERROR إذا فشلت؛ في هذه الحالة، يتم ترك رسالة خطأ في النتيجة القيمة لـ childInterp. لاحظ أنه لا توجد قيود على علاقة النسب (كما تم إنشاؤها بواسطة Tcl_CreateSlave) بين childInterp و targetInterp. يمكن استخدام أي مترجمين، دون أي قيود على كيفية ارتباطهما.

Tcl_CreateAliasObj مشابه لـ Tcl_CreateAlias باستثناء أنه يأخذ متجهًا من القيم لتمريرها كوسائط إضافية بدلاً من متجه من السلاسل.

Tcl_GetAliasObj يعيد معلومات في شكل مؤشر إلى متجه من هياكل Tcl_Obj حول اسم مستعار aliasName في interp. يمكن أن تكون أي من حقول النتيجة NULL، وفي هذه الحالة، لا يتم إرجاع البيانات المقابلة. إذا كان حقل النتيجة غير NULL، يتم تعيين العنوان المشار إليه إلى البيانات المقابلة. على سبيل المثال، إذا كان targetCmdPtr غير NULL، يتم تعيينه إلى مؤشر إلى السلسلة التي تحتوي على اسم الأمر الهدف.

Tcl_GetAlias مشابه لـ Tcl_GetAliasObj باستثناء أنه يعيد مؤشرًا إلى متجه من السلاسل بدلاً من متجه من هياكل Tcl_Obj. تم إهمال Tcl_GetAlias

NAME

Tcl_ExposeCommand, Tcl_HideCommand - make commands visible or invisible

SYNOPSIS

#include <tcl.h>

int
Tcl_ExposeCommand(interp, hiddenCmdName, cmdName)
int
Tcl_HideCommand(interp, cmdName, hiddenCmdName)

ARGUMENTS

Tcl_Interp *interp
Interpreter in which to manipulate commands.
const char *hiddenCmdName
Name for the command when it is hidden.
const char *cmdName
Name for the command when it is exposed.

DESCRIPTION

Tcl_ExposeCommand moves the command named hiddenCmdName from the set of hidden commands to the set of exposed commands, putting it under the name cmdName. HiddenCmdName must be the name of an existing hidden command, or the operation will return TCL_ERROR and leave an error message as the result of interp. If an exposed command named cmdName already exists, the operation returns TCL_ERROR and leaves an error message as the result of interp. If the operation succeeds, it returns TCL_OK. After executing this command, attempts to use cmdName in any script evaluation mechanism will again succeed.

Tcl_HideCommand moves the command named cmdName from the set of exposed commands to the set of hidden commands, under the name hiddenCmdName. CmdName must be the name of an existing exposed command, or the operation will return TCL_ERROR and leave an error message as the result of interp. Currently both cmdName and hiddenCmdName must not contain namespace qualifiers, or the operation will return TCL_ERROR and leave an error message as the result of interp. The CmdName will be looked up in the global namespace, and not relative to the current namespace, even if the current namespace is not the global one. If a hidden command whose name is hiddenCmdName already exists, the operation also returns TCL_ERROR and an error message is left as the result of interp. If the operation succeeds, it returns TCL_OK. After executing this command, attempts to use cmdName in any script evaluation mechanism will fail.

For a description of the Tcl interface to multiple interpreters, see interp(n).
