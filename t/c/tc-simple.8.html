tc-simple(8) — إجراء بسيط Linux tc-simple(8) — إجراء بسيط

الاسم

simple - إجراء توضيحي أساسي

نبذة


tc ... action simple [ sdata سلسلة ] [ index فهرس ] [ تحكم ]

تحكم := { reclassify | pipe | drop | continue | ok }

الوصف

هذا مثال تعليمي أكثر من كونه إجراءً مفيدًا في الواقع. عند كل وصول، يقوم بطباعة السلسلة المعطاة التي قد تكون بطول اعتباطي.

خيارات

sdata سلسلة
السلسلة الفعلية للطباعة.
index فهرس
قيمة إجراء اختيارية.
تحكم
يحدد كيفية متابعة tc بعد تنفيذ الإجراء. لوصف التحكم الممكن، انظر tc-actions(8).

أمثلة

يجعل المثال التالي النواة تصرخ "ICMP وارد!" في كل مرة ترى فيها ICMP واردًا على eth0. الخطوات هي:

1)
إضافة نقطة qdisc واردة إلى eth0
2)
بدء سلسلة على وارد eth0 التي تطابق أولاً ICMP ثم تستدعي الإجراء البسيط للصراخ.
3)
عرض الإحصائيات وإظهار أنه لم تتم رؤية أي حزمة بواسطة الإجراء
4)
إرسال حزمة ping واحدة إلى google (توقع تلقي رد)
5)
البحث في السجلات لرؤية الرسالة المسجلة
6)
عرض الإحصائيات مرة أخرى وملاحظة الزيادة بمقدار 1 
  $ tc qdisc add dev eth0 ingress
  $ tc filter add dev eth0 parent ffff: protocol ip prio 5 \
