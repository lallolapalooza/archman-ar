Tcl_SetEnsembleMappingDict(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_SetEnsembleMappingDict, Tcl_GetEnsembleMappingDict — set and get the mapping dictionary for an ensemble

SYNOPSIS

#include <tcl.h>

int
Tcl_SetEnsembleMappingDict(interp, token, dict);
int
Tcl_GetEnsembleMappingDict(interp, token, dictPtr);

ARGUMENTS

interp
Interpreter to use for error reporting.
token
Token for the ensemble.
dict
A dictionary value (or an empty string) to set as the mapping dictionary.
dictPtr
Pointer to a Tcl_Obj to store the mapping dictionary value.

DESCRIPTION

The Tcl_SetEnsembleMappingDict function sets the mapping dictionary for the ensemble specified by token to be dict. The mapping dictionary is a dictionary value where keys are subcommand names and values are interpreted as commands to be invoked for those subcommands. If dict is an empty string, it indicates that no mapping dictionary is set, and the ensemble will fall back to its other properties to determine how to handle subcommands.

The Tcl_GetEnsembleMappingDict function retrieves the mapping dictionary for the ensemble specified by token and stores it in the Tcl_Obj pointed to by dictPtr. If no mapping dictionary is set for the ensemble, the object will be set to an empty string. The object obtained from Tcl_GetEnsembleMappingDict should be treated as immutable, even if it is unshared.

Both functions return a Tcl result code. If the operation is successful, they return TCL_OK. If the token does not refer to a valid ensemble, they return TCL_ERROR, and an error message is left in the interpreter's result.

Ensembles also have a subcommand list and an unknown command handler. The mapping dictionary is consulted first when a subcommand is invoked. If the subcommand is found as a key in the mapping dictionary, the corresponding value is invoked as a command. If the subcommand is not found in the mapping dictionary, the subcommand list is consulted. If the subcommand is found in the subcommand list, the corresponding command is invoked. If the subcommand is not found in either the mapping dictionary or the subcommand list, the unknown command handler is invoked. If the unknown command handler is NULL, a suitable error message is generated.

See the namespace ensemble command for more details. The unknown command handler may be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.

bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
