Tcl_GlobalEvalObj(3)

Tcl_GlobalEvalObj - Evaluate a Tcl command or script in the context of the global interpreter

NAME

Tcl_GlobalEvalObj, Tcl_GlobalEval - evaluate a Tcl command or script in the context of the global interpreter

SYNOPSIS

#include <tcl.h>

int
Tcl_GlobalEvalObj(interp, objPtr)
Tcl_Obj *objPtr;
int
Tcl_GlobalEval(interp, script)
char *script;

ARGUMENTS

Tcl_Interp *interp (in)
Interpreter in which to execute the script.
Tcl_Obj *objPtr (in)
An object containing the script to execute.
char *script (in)
A string containing the script to execute.

DESCRIPTION

The Tcl_GlobalEvalObj and Tcl_GlobalEval commands evaluate a Tcl command or script. The difference between these two commands is similar to the difference between Tcl_EvalObj and Tcl_Eval: Tcl_GlobalEvalObj takes an object for its script argument, while Tcl_GlobalEval takes a string. The commands differ from Tcl_EvalObj and Tcl_Eval in that they execute the script in the global context of the interpreter, rather than in the context of the caller’s current scope.

The script is executed in the context of the global scope of the interpreter specified by interp. Any variable references in the script are resolved within the global scope. If the script is executed successfully, then Tcl_GlobalEvalObj and Tcl_GlobalEval return TCL_OK. In this case the result of the script is stored in the interpreter’s result (`interp->result`). If an error occurs during the script’s execution, then the command returns TCL_ERROR and the error message is stored in the interpreter’s result.

Tcl_GlobalEvalObj should be used when the script is already in Tcl object form. It is more efficient than Tcl_GlobalEval because it avoids the overhead of converting the script to an object.

Tcl_GlobalEval should be used when the script is in string form. It converts the script to an object before evaluating it. This involves a call to Tcl_NewObj, followed by Tcl_AppendToObj, and finally Tcl_GlobalEvalObj.

Note that if the script contains any commands that change the execution context, such as uplevel or source, these commands will operate within the global scope.

The return value from these functions can be TCL_OK, TCL_ERROR, or TCL_RETURN. However, in the context of top-level applications, only TCL_OK and TCL_ERROR are expected. If a TCL_RETURN value is encountered, it indicates that a return command was invoked in an inappropriate place. This means that top-level applications should never see a return code from Tcl_EvalObjEx other than TCL_OK or TCL_ERROR.

KEYWORDS

execute, file, global, result, script, value

Tcl_GlobalEvalObj(3)

Tcl_GlobalEvalObj - تقييم أمر Tcl أو نص برمجي في سياق المفسر العام

الاسم

Tcl_GlobalEvalObj, Tcl_GlobalEval - تقييم أمر Tcl أو نص برمجي في سياق المفسر العام

ملخص

#include <tcl.h>

int
Tcl_GlobalEvalObj(interp, objPtr)
Tcl_Obj *objPtr;
int
Tcl_GlobalEval(interp, script)
char *script;

المعاملات

Tcl_Interp *interp (في)
المفسر الذي سيتم تنفيذ النص البرمجي فيه.
Tcl_Obj *objPtr (في)
كائن يحتوي على النص البرمجي المراد تنفيذه.
char *script (في)
سلسلة نصية تحتوي على النص البرمجي المراد تنفيذه.

الوصف

يقوم الأمران Tcl_GlobalEvalObj و Tcl_GlobalEval بتقييم أمر Tcl أو نص برمجي. الفرق بين هذين الأمرين مشابه للفرق بين Tcl_EvalObj و Tcl_Eval: يأخذ Tcl_GlobalEvalObj كائنًا لمعامل النص البرمجي الخاص به، بينما يأخذ Tcl_GlobalEval سلسلة نصية. تختلف الأوامر عن Tcl_EvalObj و Tcl_Eval في أنها تنفذ النص البرمجي في السياق العام للمفسر، بدلاً من سياق النطاق الحالي للمتصل.

يتم تنفيذ النص البرمجي في سياق النطاق العام للمفسر المحدد بواسطة interp. يتم حل أي مرجع متغيرات في النص البرمجي ضمن النطاق العام. إذا تم تنفيذ النص البرمجي بنجاح، فإن Tcl_GlobalEvalObj و Tcl_GlobalEval يعيدان TCL_OK. في هذه الحالة، يتم تخزين نتيجة النص البرمجي في نتيجة المفسر (`interp->result`). إذا حدث خطأ أثناء تنفيذ النص البرمجي، فإن الأمر يعيد TCL_ERROR ويتم تخزين رسالة الخطأ في نتيجة المفسر.

يجب استخدام Tcl_GlobalEvalObj عندما يكون النص البرمجي بالفعل في شكل كائن Tcl. إنه أكثر كفاءة من Tcl_GlobalEval لأنه يتجنب الحمل الزائد لتحويل النص البرمجي إلى كائن.

يجب استخدام Tcl_GlobalEval عندما يكون النص البرمجي في شكل سلسلة نصية. يقوم بتحويل النص البرمجي إلى كائن قبل تقييمه. يتضمن ذلك استدعاء Tcl_NewObj، متبوعًا بـ Tcl_AppendToObj، وأخيرًا Tcl_GlobalEvalObj.

لاحظ أنه إذا كان النص البرمجي يحتوي على أي أوامر تغير سياق التنفيذ، مثل uplevel أو source، فإن هذه الأوامر ستعمل ضمن النطاق العام.

يمكن أن تكون القيمة المرجعة لهذه الدوال TCL_OK أو TCL_ERROR أو TCL_RETURN. ومع ذلك، في سياق التطبيقات العليا، يُتوقع فقط TCL_OK و TCL_ERROR. إذا تمت مواجهة قيمة TCL_RETURN، فهذا يشير إلى أن الأمر return قد تم استدعاؤه في مكان غير مناسب. هذا يعني أن التطبيقات العليا يجب ألا ترى أبدًا رمز إرجاع من Tcl_EvalObjEx بخلاف TCL_OK أو TCL_ERROR.
