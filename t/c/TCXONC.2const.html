TCXONC(2const) TCXONC(2const)

اسم

TCXONC - تحكم تدفق البرمجيات

المكتبة

مكتبة C القياسية (libc, -lc)

ملخص

#include <asm/termbits.h>  /* تعريف TCXONC */
#include <sys/ioctl.h>
int ioctl(int fd, TCXONC, int arg);

الوصف

يعادل tcflow(fd, arg).

انظر tcflow(3) لقيم الوسيطات TCOOFF, TCOON, TCIOFF, TCION.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno لتوضيح الخطأ.

انظر أيضًا

ioctl(2), ioctl_tty(2), tcflow(3), termios(3)
