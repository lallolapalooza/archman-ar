Tcl_GlobalEval(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_GlobalEval - execute a Tcl script in an application-global context

SYNOPSIS

#include <tcl.h>
int
Tcl_GlobalEval(interp, script);

ARGUMENTS

Tcl_Interp *interp
Interpreter in which to execute the script.
const char *script
The script to execute.

DESCRIPTION

The Tcl_GlobalEval procedure is used to execute a Tcl script in the interpreter specified by interp. The script is executed in the global scope, meaning that it has access to global variables and procedures. The return value of the script is accessible via Tcl_EvalObjEx and Tcl_GetObjResult.

The return value of Tcl_GlobalEval is the same as the return value of Tcl_EvalObjEx, which is one of the following:

TCL_OK
The script executed successfully.
TCL_ERROR
An error occurred during script execution.
TCL_RETURN
The script executed a return command.
TCL_BREAK
The script executed a break command.
TCL_CONTINUE
The script executed a continue command.

Applications should typically only expect TCL_OK or TCL_ERROR as return codes from Tcl_GlobalEval. The other return codes are typically handled internally by Tcl's command loop. If the TCL_RETURN, TCL_BREAK, or TCL_CONTINUE return codes are seen at the top level, it indicates that the return, break, or continue command was invoked in an inappropriate place. This means that top-level applications should never see a return code from Tcl_EvalObjEx other than TCL_OK or TCL_ERROR.

KEYWORDS

execute, file, global, result, script, value
