FIONREAD(2const) FIONREAD(2const)

الاسم

FIONREAD, TIOCINQ, TIOCOUTQ, TCFLSH, TIOCSERGETLSR - عدد المخزن المؤقت والتفريغ

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <asm/termbits.h>  /* تعريف الثوابت */
#include <sys/ioctl.h>
int ioctl(int fd, FIONREAD, int *argp);
int ioctl(int fd, TIOCINQ, int *argp);
int ioctl(int fd, TIOCOUTQ, int *argp);
int ioctl(int fd, TCFLSH, int arg);
int ioctl(int fd, TIOCSERGETLSR, int *argp);

الوصف

FIONREAD
الحصول على عدد البايتات في المخزن المؤقت للإدخال.
TIOCINQ
نفس FIONREAD.
TIOCOUTQ
الحصول على عدد البايتات في المخزن المؤقت للإخراج.
TCFLSH
يعادل tcflush(fd, arg).
انظر tcflush(3) لقيم الوسائط TCIFLUSH، TCOFLUSH، TCIOFLUSH.
TIOCSERGETLSR
الحصول على سجل حالة الخط. يحتوي سجل الحالة على بت TIOCSER_TEMT معين عندما يكون المخزن المؤقت للإخراج فارغًا ويكون المرسل الفعلي فارغًا أيضًا.
لا يجب أن تدعمه جميع برامج تشغيل tty التسلسلية.
tcdrain(3) لا ينتظر ويعود فورًا عند تعيين بت TIOCSER_TEMT.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

انظر أيضًا

ioctl(2)، ioctl_tty(2)، tcflush(3)، termios(3)
