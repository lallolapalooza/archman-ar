الوصف

تقوم هذه الإجراءات بالتحويل بين سلاسل UTF-8 و Tcl_UniChars. Tcl_UniChar هو حرف Unicode ممثل بكيان غير موقّع وثابت الحجم. حرف UTF-8 هو حرف Unicode ممثل بتسلسل متغير الطول يصل إلى TCL_UTF_MAX بايت. يتكون تسلسل UTF-8 متعدد البايتات من بايت رائد متبوعًا بعدد من البايتات التابعة.

TCL_UTF_MAX هو الحد الأقصى لعدد البايتات اللازمة لتمثيل حرف Unicode واحد في تمثيل UTF-8.

Tcl_UniCharToUtf تخزن Tcl_UniChar ch كسلسلة UTF-8 بدءًا من buf. القيمة المرجعة هي عدد البايتات المخزنة في buf.

Tcl_UtfToUniChar تقرأ حرف UTF-8 واحدًا بدءًا من src وتخزنه كـ Tcl_UniChar في *chPtr. القيمة المرجعة هي عدد البايتات التي تم قراءتها من src. يجب على المتصل التأكد من أن المخزن المؤقت المصدر طويل بما يكفي بحيث لا يتجاوز هذا الإجراء النهاية ويفك مرجع الذاكرة غير الموجودة أو العشوائية؛ إذا كان المخزن المؤقت المصدر معلومًا أنه مختوم بصفر، فلن يحدث هذا. إذا لم يكن الإدخال بتنسيق UTF-8 صحيح، فسيقوم Tcl_UtfToUniChar بتخزين البايت الأول من src في *chPtr كـ Tcl_UniChar بين 0x80 و 0xFF ويعيد 1.

Tcl_UniCharToUtfDString تحول سلسلة Unicode المعطاة إلى UTF-8، وتخزن النتيجة في Tcl_DString تم تهيئتها مسبقًا. يجب عليك تحديد uniLength، طول سلسلة Unicode المعطاة. القيمة المرجعة هي مؤشر إلى تمثيل UTF-8 لسلسلة Unicode. يتم إلحاق مساحة التخزين للقيمة المرجعة بنهاية Tcl_DString.

Tcl_UtfToUniCharDString تحول سلسلة UTF-8 المعطاة إلى Unicode، وتخزن النتيجة في Tcl_DString تم تهيئتها مسبقًا. في المعامل length، يمكنك إما تحديد طول سلسلة UTF-8 المعطاة بالبايتات أو " -1"، في هذه الحالة تستخدم Tcl_UtfToUniCharDString strlen لحساب الطول. القيمة المرجعة هي مؤشر إلى تمثيل Unicode لسلسلة UTF-8. يتم إلحاق مساحة التخزين للقيمة المرجعة بنهاية Tcl_DString. يتم إنهاء سلسلة Unicode بحرف Unicode صفري.

Tcl_UniCharLen يتوافق مع strlen لأحرف Unicode. يقبل سلسلة Unicode مختومة بصفر ويعيد عدد أحرف Unicode (وليس البايتات) في تلك السلسلة.

Tcl_UniCharNcmp و Tcl_UniCharNcasecmp يتوافقان مع strncmp و strncasecmp، على التوالي، لأحرف Unicode. يقبلان سلسلتين Unicode مختومتين بصفر وعدد الأحرف المطلوب مقارنتها. يُفترض أن تكون كلتا السلسلتين طويلتين بما لا يقل عن numChars حرفًا. تقارن Tcl_UniCharNcmp السلسلتين حرفًا بحرف وفقًا لترتيب أحرف Unicode. يعيد قيمة عددية أكبر من أو تساوي أو أقل من 0 إذا كانت السلسلة الأولى أكبر من أو تساوي أو أقل من السلسلة الثانية على التوالي. Tcl_UniCharNcasecmp هي النسخة غير الحساسة لحالة أحرف Unicode.

Tcl_UniCharCaseMatch هي مكافئ Unicode لـ Tcl_StringCaseMatch. تقبل سلسلة Unicode مختومة بصفر، ونمط Unicode، وقيمة منطقية تحدد ما إذا كان يجب أن يكون التطابق حساسًا لحالة الأحرف أم لا، وتعيد ما إذا كانت السلسلة تتطابق مع النمط.

Tcl_UtfNcmp يتوافق مع strncmp لسلاسل UTF-8. يقبل سلسلتي UTF-8 مختومتين بصفر وعدد الأحرف المطلوب مقارنتها. (يُفترض أن تكون كلتا السلسلتين طويلتين بما لا يقل عن numChars حرفًا.) تقارن Tcl_UtfNcmp السلسلتين حرفًا بحرف وفقًا لترتيب أحرف Unicode. يعيد قيمة عددية أكبر من أو تساوي أو أقل من 0 إذا كانت السلسلة الأولى أكبر من أو تساوي أو أقل من السلسلة الثانية على التوالي.

Tcl_UtfNcasecmp يتوافق مع strncasecmp لسلاسل UTF-8. إنه مشابه لـ Tcl_UtfNcmp باستثناء أن المقارنات تتجاهل الاختلافات في حالة الأحرف عند مقارنة الأحرف الكبيرة أو الصغيرة أو العنوان.

Tcl_UtfCharComplete يعيد 1 إذا كانت سلسلة UTF-8 المصدر src بطول length بايت طويلة بما يكفي لفك تشفيرها بواسطة Tcl_UtfToUniChar/Tcl_UtfNext، أو 0 بخلاف ذلك. لا يضمن هذا الإجراء أن سلسلة UTF-8 مشكلة بشكل صحيح. يستخدم هذا الإجراء من قبل الإجراءات التي تعمل بايتًا تلو الآخر وتحتاج إلى معرفة ما إذا كان قد تم رؤية حرف Tcl_UniChar كامل.

Tcl_NumUtfChars يتوافق مع strlen لسلاسل UTF-8. يعيد عدد Tcl_UniChars التي تمثلها سلسلة UTF-8 src. طول السلسلة المصدر هو length بايت. إذا كان الطول سالبًا، يتم استخدام جميع البايتات حتى البايت الصفري الأول.

Tcl_UtfFindFirst يتوافق مع strchr لسلاسل UTF-8. يعيد مؤشرًا إلى أول ظهور لـ Tcl_UniChar ch في سلسلة UTF-8 src المختومة بصفر. يعتبر الختم الصفري جزءًا من سلسلة UTF-8.

Tcl_UtfFindLast يتوافق مع strrchr لسلاسل UTF-8. يعيد مؤشرًا إلى آخر ظهور لـ Tcl_UniChar

Tcl_UtfNext(3) - Tcl C API

NAME

Tcl_UtfNext, Tcl_UniCharAtIndex, Tcl_UtfAtIndex, Tcl_UtfPrev, Tcl_UtfBackslash - Tcl UTF-8 character manipulation

SYNOPSIS

#include <tcl.h>

const char *
Tcl_UtfNext(src);

Tcl_UniChar
Tcl_UniCharAtIndex(src, index);

const char *
Tcl_UtfAtIndex(src, index);

const char *
Tcl_UtfPrev(start, src);

int
Tcl_UtfBackslash(src, readPtr, dst);

ARGUMENTS

const char *src
Pointer to a UTF-8 string or a character within a UTF-8 string.
const char *start
Pointer to the beginning of the UTF-8 string.
int index
Index of the character to access (0 for the first character).
int *readPtr
Pointer to an integer that will be updated with the number of bytes read.
char *dst
Pointer to the destination buffer for the processed character.

DESCRIPTION

These functions provide facilities for accessing and manipulating UTF-8 encoded strings in Tcl. UTF-8 is a variable-length character encoding capable of representing every character in the Unicode standard.

Tcl_UtfNext returns a pointer to the next UTF-8 character in the string starting at src. The null terminator is considered part of the UTF-8 string.

Given src, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
