المعاملات

Tcl_Interp *interp (in)
يُستخدم للإبلاغ عن الأخطاء وللبحث عن قناة مسجلة فيه.
const char *fileName (in)
اسم ملف محلي أو شبكة.
const char *mode (in)
يحدد كيفية الوصول إلى الملف. قد يأخذ أيًا من القيم المسموح بها لمعامل mode لأمر Tcl open.
int permissions (in)
علامات الأذونات بنمط POSIX مثل 0644. إذا تم إنشاء ملف جديد، فسيتم تعيين هذه الأذونات على الملف الذي تم إنشاؤه.
int argc (in)
عدد العناصر في argv.
const char **argv (in)
معاملات لبناء خط أنابيب الأوامر. هذه القيم لها نفس معنى المعاملات غير التبديلية لأمر Tcl exec.
int flags (in)
يحدد تصرف مقابض stdio في خط الأنابيب: مزيج OR للمعاملات TCL_STDIN، TCL_STDOUT، TCL_STDERR، و TCL_ENFORCE_MODE. إذا تم تعيين TCL_STDIN، فإن stdin للطفل الأول في خط الأنابيب هو قناة خط الأنابيب، وإلا فهو نفسه بالنسبة للمدخلات القياسية للعملية المستدعية؛ وكذلك بالنسبة لـ TCL_STDOUT و TCL_STDERR. إذا لم يتم تعيين TCL_ENFORCE_MODE، فيمكن لخط الأنابيب إعادة توجيه مقابض stdio لتجاوز مقابض stdio التي تم تعيين TCL_STDIN و TCL_STDOUT و TCL_STDERR لها. إذا تم تعيينه، فإن مثل هذه عمليات إعادة التوجيه تسبب خطأ.
ClientData handle (in)
مقبض خاص بنظام التشغيل للإدخال/الإخراج إلى ملف. بالنسبة لنظام Unix، هذا هو واصف ملف (file descriptor)، وبالنسبة لنظام Windows، فهو HANDLE.
int readOrWrite (in)
مزيج OR للمعاملات TCL_READABLE و TCL_WRITABLE للإشارة إلى العمليات الصالحة على handle.
const char *channelName (in)
اسم القناة.
int *modePtr (out)
يشير إلى متغير صحيح سيستقبل مزيج OR للمعاملات TCL_READABLE و TCL_WRITABLE الذي يشير إلى ما إذا كانت القناة مفتوحة للقراءة والكتابة.
const char *pattern (in)
النمط المراد مطابقته، يتم تمريره إلى Tcl_StringMatch، أو NULL.
Tcl_Channel channel (in)
قناة Tcl للإدخال أو الإخراج. يجب أن تكون قد كانت نتيجة إجراء مثل Tcl_OpenFileChannel.
Tcl_Obj *readObjPtr (in/out)
مؤشر إلى قيمة Tcl سيتم تخزين الأحرف المقروءة من القناة فيها.
int charsToRead (in)
عدد الأحرف المراد قراءتها من القناة. إذا كان ترميز القناة هو binary، فهذا يعادل عدد البايتات المراد قراءتها من القناة.
int appendFlag (in)
إذا كان غير صفري، فسيتم إلحاق البيانات المقروءة من القناة بالقيمة. بخلاف ذلك، ستحل البيانات محل المحتويات الحالية للقيمة.
char *readBuf (out)
مخزن مؤقت سيتم تخزين البايتات المقروءة من القناة فيه.
int bytesToRead (in)
عدد البايتات المراد قراءتها من القناة. يجب أن يكون المخزن المؤقت readBuf كبيرًا بما يكفي لاستيعاب هذا العدد من البايتات.
Tcl_Obj *lineObjPtr (in/out)
مؤشر إلى قيمة Tcl سيتم تخزين السطر المقروء من القناة فيها. سيتم إلحاق السطر المقروء بالقيمة الحالية للقيمة.
Tcl_DString *lineRead (in/out)
مؤشر إلى سلسلة Tcl ديناميكية سيتم تخزين السطر المقروء من القناة فيها. يجب أن يكون قد تم تهيئته بواسطة المتصل. سيتم إلحاق السطر المقروء بأي بيانات موجودة بالفعل في السلسلة الديناميكية.
const char *input (in)
المدخلات المراد إضافتها إلى مخزن مؤقت للقناة.
int inputLen (in)
طول المدخلات.
int addAtEnd (in)
علم يشير إلى ما إذا كان سيتم إضافة المدخلات إلى نهاية أو بداية المخزن المؤقت للقناة.
Tcl_Obj *writeObjPtr (in)
مؤشر إلى قيمة Tcl سيتم إخراج محتوياتها إلى القناة.
const char *charBuf (in)
مخزن مؤقت يحتوي على الأحرف المراد إخراجها إلى القناة.
const char *byteBuf (in)
مخزن مؤقت يحتوي على البايتات المراد إخراجها إلى القناة.
int bytesToWrite (in)
عدد البايتات المراد استهلاكها من charBuf أو byteBuf وإخراجها إلى القناة.
Tcl_WideInt offset (in)
المسافة المراد نقل نقطة الوصول في القناة إليها، حيث سيتم تطبيق عملية الإدخال أو الإخراج التالية، مقاسة بالبايتات من الموضع المعطى بواسطة seekMode. قد تكون موجبة أو سالبة.
int seekMode (in)
النقطة التي سيتم البحث بالنسبة لها؛ تُستخدم مع offset لحساب نقطة الوصول الجديدة للقناة. القيم القانونية هي SEEK_SET، SEEK_CUR، و SEEK_END.
Tcl_WideInt length (in)
الطول (غير السالب) الذي سيتم اقتطاع القناة إليه.
const char *optionName (in)
اسم خيار ينطبق على هذه القناة، مثل -blocking. قد يأخذ أيًا من القيم التي يقبلها أمر fconfigure.
Tcl_DString *optionValue (in)
المكان الذي سيتم فيه تخزين قيمة خيار أو قائمة بجميع الخيارات وقيمها. يجب أن يكون قد تم تهيئته بواسطة المتصل.
const char *newValue (in)
قيمة جديدة للخيار المعطى بواسطة optionName.

الوصف

توفر آلية قنوات Tcl آلية مستقلة عن الأجهزة ومستقلة عن النظام الأساسي لأداء عمليات الإدخال والإخراج المؤقت على مجموعة متنوعة من أنواع الملفات والمقابس والأجهزة. آلية القنوات قابلة للتوسيع لأنواع قنوات جديدة، عن طريق توفير مشغل قنوات منخفض المستوى للنوع الجديد؛ يوصف واجهة مشغل القنوات في صفحة الدليل لـ Tcl_CreateChannel. توفر آلية القنوات مخطط تخزين مؤقت مشابه لـ I/O القياسي في Unix، كما أنها تسمح بالإدخال/الإخراج غير المحجوب على القنوات.

تتضمن الإجراءات الموصوفة في صفحة الدليل هذه واجهات برمجة التطبيقات C للطبقة العامة لبنية القنوات. لوصف بنية مشغل القنوات وكيفية تنفيذ مشغلات القنوات لأنواع القنوات الجديدة، راجع صفحة الدليل لـ Tcl_CreateChannel.

TCL_GETCHANNELOPTION

Tcl_GetChannelOption returns the current value of an option optionName on channel. If optionName is not recognized by the channel driver for channel, then Tcl_GetChannelOption leaves an error message in interp and returns TCL_ERROR. Otherwise it returns TCL_OK. The value is stored in the valuePtr argument, which must point to a Tcl_Obj. The caller is responsible for managing the reference count of the Tcl_Obj returned. The channel driver for a channel type is responsible for implementing the channel type specific options. These are typically implemented by a procedure that is called recursively by Tcl_GetChannelOption in a series of calls to Tcl_DStringAppendElement. The various preexisting options and their possible values are described in the manual entry for the Tcl fconfigure command. Other options can be added by each channel type. These channel type specific options are described in the manual entry for the Tcl command that creates a channel of that type; for example, the additional options for TCP-based channels are described in the manual entry for the Tcl socket command. The procedure normally returns TCL_OK. If an error occurs, it returns TCL_ERROR and calls Tcl_SetErrno to store an appropriate POSIX error code.

TCL_SETCHANNELOPTION

Tcl_SetChannelOption sets a new value newValue for an option optionName on channel. The procedure normally returns TCL_OK. If an error occurs, it returns TCL_ERROR; in addition, if interp is non-NULL, Tcl_SetChannelOption leaves an error message in the interpreter's result.

TCL_EOF

Tcl_Eof returns a nonzero value if channel encountered an end of file during the last input operation.

TCL_INPUTBLOCKED

Tcl_InputBlocked returns a nonzero value if channel is in nonblocking mode and the last input operation returned less data than requested because there was insufficient data available. The call always returns zero if the channel is in blocking mode.

TCL_INPUTBUFFERED

Tcl_InputBuffered returns the number of bytes of input currently buffered in the internal buffers for a channel. If the channel is not open for reading, this function always returns zero.

TCL_OUTPUTBUFFERED

Tcl_OutputBuffered returns the number of bytes of output currently buffered in the internal buffers for a channel. If the channel is not open for writing, this function always returns zero.

PLATFORM ISSUES

The handles returned from Tcl_GetChannelHandle depend on the platform and the channel type. On Unix platforms, the handle is always a Unix file descriptor as returned from the open system call. On Windows platforms, the handle is a file HANDLE when the channel was created with Tcl_OpenFileChannel, Tcl_OpenCommandChannel, or Tcl_MakeFileChannel. Other channel types may return a different type of handle on Windows platforms.
