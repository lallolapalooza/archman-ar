الوصف

الأسلوب هو عملية يتم تنفيذها على كائن وهو مرتبط بالكائن. يجب ربط كل أسلوب إما بكائن أو بفئة؛ الأساليب المرتبطة بفئة مرتبطة بجميع مثيلات تلك الفئة (المباشرة وغير المباشرة).

بالنظر إلى أسلوب، يمكن العثور على الكيان الذي أعلنه باستخدام Tcl_MethodDeclarerClass والذي يعيد الفئة التي يرتبط بها الأسلوب (أو NULL إذا لم يكن الأسلوب مرتبطًا بأي فئة) و Tcl_MethodDeclarerObject الذي يعيد الكائن الذي يرتبط به الأسلوب (أو NULL إذا لم يكن الأسلوب مرتبطًا بكائن). يمكن استرداد اسم الأسلوب باستخدام Tcl_MethodName وما إذا كان الأسلوب مصدّرًا يتم استرداده باستخدام Tcl_MethodIsPublic. يمكن أيضًا فحص نوع الأسلوب إلى درجة محدودة؛ تعيد الدالة Tcl_MethodIsType ما إذا كان الأسلوب من نوع معين، وتعين clientData لكل أسلوب للمتغير المشار إليه بواسطة clientDataPtr إذا (كان غير NULL) إذا تمت مطابقة النوع.

إنشاء الأسلوب

يتم إنشاء الأساليب بواسطة Tcl_NewMethod و Tcl_NewInstanceMethod، والتي تنشئ أسلوبًا مرتبطًا بفئة أو كائن على التوالي. في كلتا الحالتين، يعطي معامل nameObj اسم الأسلوب المراد إنشاؤه، وتشير علامة isPublic إلى ما إذا كان الأسلوب سيتم تصديره مبدئيًا، ويصف معامل methodTypePtr تنفيذ الأسلوب (انظر قسم أنواع الأساليب أدناه) ويوفر معامل clientData بعض البيانات الخاصة بالتنفيذ التي يتم تمريرها إلى تنفيذ الأسلوب عند استدعائه.

عندما يكون معامل nameObj لـ Tcl_NewMethod هو NULL، يتم إنشاء أسلوب غير مسمى، والذي يستخدم للمنشئات والمدمرات. يجب تثبيت المنشئات في فئتها باستخدام الدالة Tcl_ClassSetConstructor، ويجب تثبيت المدمرات (التي يجب ألا تتطلب أي وسائط) في فئتها باستخدام الدالة Tcl_ClassSetDestructor. لا ينبغي استخدام الأساليب غير المسماة لأي غرض آخر، ولا ينبغي استخدام الأساليب المسماة كمنشئات أو مدمرات. لاحظ أيضًا أن methodTypePtr NULL يستخدم لتوفير إشارة داخلية، ولا ينبغي استخدامه في كود العميل.

سياقات استدعاء الأسلوب

عند استدعاء أسلوب، يتم تمرير مرجع سياق استدعاء الأسلوب كواحد من الوسائط إلى دالة التنفيذ. يمكن فحص هذا السياق لتوفير معلومات حول المتصل، ولكن لا ينبغي الاحتفاظ به بعد لحظة انتهاء استدعاء الأسلوب.

يمكن استرداد الأسلوب الذي يتم استدعاؤه من السياق باستخدام Tcl_ObjectContextMethod، ويمكن استرداد الكائن الذي تسبب في استدعاء الأسلوب باستخدام Tcl_ObjectContextObject. يتم قراءة عدد الوسائط التي يجب تخطيها (مثل اسم الكائن واسم الأسلوب في استدعاء أسلوب عادي) باستخدام Tcl_ObjectContextSkippedArgs، ويمكن للسياق أيضًا الإبلاغ عما إذا كان يعمل كمرشح لأسلوب آخر من خلال Tcl_ObjectContextIsFiltering.

خلال تنفيذ الأسلوب، قد يختار تنفيذ الأسلوب استدعاء مراحل سلسلة استدعاء الأسلوب التي تأتي بعد تنفيذ الأسلوب الحالي. يتم ذلك (جوهر الأمر next) باستخدام Tcl_ObjectContextInvokeNext. لاحظ أن هذه الدالة لا تعالج مكدس إطار الاستدعاء، على عكس الأمر next؛ إذا قام تنفيذ الأسلوب بدفع إطار أو أكثر على المكدس كجزء من تنفيذه، فهو مسؤول أيضًا عن إزالة تلك الإطارات مؤقتًا من المكدس أثناء تنفيذ الدالة Tcl_ObjectContextInvokeNext. لاحظ أيضًا أن سياق استدعاء الأسلوب لا يتم حذفه أبدًا أثناء تنفيذ هذه الدالة.

أنواع الأساليب

يتم وصف أنواع الأساليب بواسطة مؤشر إلى بنية Tcl_MethodType، والتي تم تعريفها كالتالي:

typedef struct {
    int version;
    const char *name;
    Tcl_MethodCallProc *callProc;
    Tcl_MethodDeleteProc *deleteProc;
    Tcl_CloneProc *cloneProc;
} Tcl_MethodType;

يسمح حقل version بالتوسع المستقبلي للبنية، ويجب دائمًا تعريفه على أنه يساوي TCL_OO_METHOD_VERSION_CURRENT. يوفر حقل name اسمًا يمكن قراءته بواسطة الإنسان للنوع، وهو القيمة التي يتم كشفها عبر أوامر Tcl info class methodtype و info object methodtype.

يعطي حقل callProc دالة يتم استدعاؤها عند استدعاء الأسلوب؛ يجب ألا يكون NULL أبدًا.

يعطي حقل deleteProc دالة تستخدم لحذف أسلوب معين، ويتم استدعاؤها عند استبدال الأسلوب أو إزالته؛ إذا كان الحقل NULL، فمن المفترض أن clientData الخاص بالأسلوب لا يحتاج إلى إجراء خاص للحذف.

حقل cloneProc هو إما دالة تستخدم لنسخ clientData الخاص بالأسلوب (كجزء من Tcl_CopyObjectInstance) أو NULL للإشارة إلى أن clientData يمكن نسخه مباشرة.

توقيع دالة Tcl_MethodCallProc

تتبع توقيعات دالة تنفيذ الأسلوب الموقعة Tcl_MethodCallProc:

typedef int
Tcl_MethodCallProc(Tcl_Interp *interp, Tcl_Object object,
        Tcl_ObjectContext context, int objc, Tcl_Obj *const objv[]);

يتم تمرير معامل clientData (المخزن في الـ methodTypePtr عند إنشاء الأسلوب) كمتغير إضافي إلى تنفيذ الأسلوب:

typedef int
Tcl_MethodCallProc(Tcl_Interp *interp, ClientData clientData,
        Tcl_Object object, Tcl_ObjectContext context, int objc,
        Tcl_Obj *const objv[]);

يتم تمرير الوسائط interp و object و context و objc و objv على النحو الموضح في القسم المعاملات أعلاه. يجب أن تعيد دالة التنفيذ 0 عند النجاح، أو TCL_ERROR عند حدوث خطأ.
