termios(3) دليل وظائف المكتبة termios(3)

الاسم

termios, tcgetattr, tcsetattr, tcsendbreak, tcdrain, tcflush, tcflow, cfmakeraw, cfgetospeed, cfgetispeed, cfsetispeed, cfsetospeed, cfsetspeed - الحصول على سمات الطرفية وتعيينها، التحكم في الخط، الحصول على معدل الباود وتعيينه

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <termios.h>
#include <unistd.h>
int tcgetattr(int fd, struct termios *termios_p);
int tcsetattr(int fd, int optional_actions,
              const struct termios *termios_p);
int tcsendbreak(int fd, int duration);
int tcdrain(int fd);
int tcflush(int fd, int queue_selector);
int tcflow(int fd, int action);
void cfmakeraw(struct termios *termios_p);
speed_t cfgetispeed(const struct termios *termios_p);
speed_t cfgetospeed(const struct termios *termios_p);
int cfsetispeed(struct termios *termios_p, speed_t speed);
int cfsetospeed(struct termios *termios_p, speed_t speed);
int cfsetspeed(struct termios *termios_p, speed_t speed);
متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

cfsetspeed()، cfmakeraw():

    منذ glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 وما قبله:
        _BSD_SOURCE

الوصف

تصف وظائف termios واجهة طرفية عامة يتم توفيرها للتحكم في منافذ الاتصال غير المتزامنة.

بنية termios

العديد من الوظائف الموضحة هنا تحتوي على وسيط termios_p وهو مؤشر إلى بنية termios. تحتوي هذه البنية على الأعضاء التالية على الأقل:


tcflag_t c_iflag;      /* أنماط الإدخال */
tcflag_t c_oflag;      /* أنماط الإخراج */
tcflag_t c_cflag;      /* أنماط التحكم */
tcflag_t c_lflag;      /* أنماط محلية */
cc_t     c_cc[NCCS];   /* أحرف خاصة */

القيم التي يمكن تعيينها لهذه الحقول موضحة أدناه. في حالة حقلي قناع البت الأربعة الأولين، لا يتم الكشف عن تعريف بعض الأعلام المرتبطة التي يمكن تعيينها إلا إذا تم تعريف ماكرو اختبار ميزة محدد (انظر feature_test_macros(7))، كما هو ملاحظ في الأقواس ("[]").

في الأوصاف أدناه، تعني "ليست في POSIX" أن القيمة غير محددة في POSIX.1-2001، و "XSI" تعني أن القيمة محددة في POSIX.1-2001 كجزء من امتداد XSI.

ثوابت علم c_iflag:

IGNBRK
تجاهل حالة BREAK عند الإدخال.
BRKINT
إذا تم تعيين IGNBRK، يتم تجاهل BREAK. إذا لم يتم تعيينه ولكن تم تعيين BRKINT، فإن BREAK يتسبب في مسح طوابير الإدخال والإخراج، وإذا كانت الطرفية هي الطرفية المتحكمة في مجموعة عمليات أمامية، فستتسبب في إرسال SIGINT إلى مجموعة العمليات الأمامية هذه. عندما لا يتم تعيين IGNBRK ولا BRKINT، تقرأ BREAK كبايت فارغ ('\0')، باستثناء عندما يتم تعيين PARMRK، وفي هذه الحالة تقرأ كسلسلة \377 \0 \0.
IGNPAR
تجاهل أخطاء التأطير وأخطاء التكافؤ.
PARMRK
إذا تم تعيين هذه البت، يتم تمييز بايتات الإدخال ذات أخطاء التكافؤ أو التأطير عند تمريرها إلى البرنامج. هذه البت ذات معنى فقط عندما يتم تعيين INPCK وعندما لا يتم تعيين IGNPAR. الطريقة التي يتم بها تمييز البايتات الخاطئة هي بباينتات سابقة، \377 و \0. وبالتالي، يقرأ البرنامج ثلاثة بايت لبايت واحد خاطئ تم استلامه من الطرفية. إذا كان للبايت الصحيح قيمة \377، ولم يتم تعيين ISTRIP (انظر أدناه)، فقد يخلطه البرنامج مع البادئة التي تميز خطأ التكافؤ. لذلك، يتم تمرير بايت صحيح \377 إلى البرنامج كبايتين، \377 \377، في هذه الحالة.
إذا لم يتم تعيين IGNPAR ولا PARMRK، فاقرأ حرفًا بخطأ تكافؤ أو خطأ تأطير كـ \0.
INPCK
تمكين التحقق من تكافؤ الإدخال.
ISTRIP
إزالة البت الثامن.
INLCR
ترجمة NL إلى CR عند الإدخال.
IGNCR
تجاهل إرجاع العربة عند الإدخال.
ICRNL
ترجمة إرجاع العربة إلى سطر جديد عند الإدخال (ما لم يتم تعيين IGNCR).
IUCLC
(ليست في POSIX) تعيين الأحرف الكبيرة إلى أحرف صغيرة عند الإدخال.
IXON
تمكين التحكم في تدفق XON/XOFF عند الإخراج.
IXANY
(XSI) كتابة أي حرف سيعيد تشغيل الإخراج المتوقف. (الافتراضي هو السماح لحرف START فقط بإعادة تشغيل الإخراج.)
IXOFF
تمكين التحكم في تدفق XON/XOFF عند الإدخال.
IMAXBEL
(ليست في POSIX) إصدار رنين عند امتلاء طابور الإدخال. لا يقوم Linux بتنفيذ هذه البت، ويتصرف كما لو كانت دائمًا مضبوطة.
IUTF8 (منذ Linux 2.6.4)
(ليست في POSIX) الإدخال هو UTF8؛ وهذا يسمح بإجراء مسح الأحرف بشكل صحيح في الوضع العادي.

ثوابت علم c_oflag:

OPOST
تمكين معالجة الإخراج التي يحددها التنفيذ.
OLCUC
(ليست في POSIX) تعيين الأحرف الصغيرة إلى أحرف كبيرة عند الإخراج.
ONLCR
(XSI) ترجمة NL إلى CR-NL عند الإخراج.
OCRNL
ترجمة CR إلى NL عند الإخراج.
ONOCR
لا تخرج CR في العمود 0.
ONLRET
يُفترض أن الحرف NL يقوم بوظيفة إرجاع العربة؛ يتم تعيين عمود السجل الحالي للنواة إلى 0 بعد كل من NL و CR.
OFILL
إرسال أحرف ملء للتأخير، بدلاً من استخدام تأخير زمني.
OFDEL
حرف الملء هو ASCII DEL (0177). إذا لم يتم تعيينه، فإن حرف الملء هو ASCII NUL ('\0'). (غير منفذ في Linux.)
NLDLY
قناع تأخير السطر الجديد. القيم هي NL0 و NL1. [يتطلب _BSD_SOURCE أو _SVID_SOURCE أو _XOPEN_SOURCE]
CRDLY
قناع تأخير إرجاع العربة. القيم هي CR0، CR1، CR2، أو CR3. [يتطلب _BSD_SOURCE أو _SVID_SOURCE أو _XOPEN_SOURCE]
TABDLY
قناع تأخير علامة الجدولة الأفقية. القيم هي TAB0، TAB1، TAB2، TAB3 (أو XTABS، ولكن انظر قسم BUGS). القيمة TAB3، أي XTABS، توسع علامات الجدولة إلى مسافات (مع نقاط توقف كل ثماني أعمدة). [يتطلب _BSD_SOURCE أو _SVID_SOURCE أو _XOPEN_SOURCE]
BSDLY
قناع تأخير المسافة للخلف. القيم هي BS0 أو BS1. (لم يتم تنفيذه مطلقًا.) [يتطلب _BSD_SOURCE أو _SVID_SOURCE أو _XOPEN_SOURCE]
VTDLY
قناع تأخير علامة الجدولة الرأسية. القيم هي VT0 أو VT1.
FFDLY
قناع تأخير التغذية الورقية. القيم هي FF0 أو FF1. [يتطلب _BSD_SOURCE أو _SVID_SOURCE أو _XO
