الوصف

تُستخدم هذه الإجراءات لإنشاء، تعديل، قراءة، وحذف متغيرات Tcl من كود C.

تقوم Tcl_SetVar2Ex، Tcl_SetVar، Tcl_SetVar2، و Tcl_ObjSetVar2 بإنشاء متغير جديد أو تعديل متغير موجود. هذه الإجراءات ستعين القيمة المعطاة بواسطة newValuePtr أو newValue للمتغير المحدد وسترجع مؤشرًا إلى قيمة المتغير الجديدة، والتي يتم تخزينها في بنية متغير Tcl. تستقبل Tcl_SetVar2Ex و Tcl_ObjSetVar2 القيمة الجديدة كـ Tcl_Obj وترجع مؤشرًا إلى Tcl_Obj. تستقبل Tcl_SetVar و Tcl_SetVar2 القيمة الجديدة كسلسلة نصية وترجع سلسلة نصية؛ وهي عمومًا أقل كفاءة من Tcl_ObjSetVar2. لاحظ أن القيمة المرجعة قد تكون مختلفة عن الوسيط newValuePtr أو newValue، بسبب التعديلات التي أجرتها تتبعات الكتابة. إذا حدث خطأ عند تعيين المتغير (على سبيل المثال، يشير إلى مصفوفة دون تحديد مؤشر) يتم إرجاع NULL ورسالة خطأ تُترك في نتيجة interp إذا كان بت TCL_LEAVE_ERR_MSG نشطًا.

تقوم Tcl_GetVar2Ex، Tcl_GetVar، Tcl_GetVar2، و Tcl_ObjGetVar2 بإرجاع القيمة الحالية للمتغير. تُعامل الوسائط لهذه الإجراءات بنفس طريقة الوسائط للإجراءات المذكورة أعلاه. عادةً، تكون القيمة المرجعة مؤشرًا إلى قيمة المتغير. بالنسبة لـ Tcl_GetVar2Ex و Tcl_ObjGetVar2، يتم إرجاع القيمة كمؤشر إلى Tcl_Obj. بالنسبة لـ Tcl_GetVar و Tcl_GetVar2، يتم إرجاع القيمة كسلسلة نصية؛ وهذا عمومًا أقل كفاءة، لذلك يُفضل Tcl_GetVar2Ex أو Tcl_ObjGetVar2. إذا حدث خطأ عند قراءة المتغير (على سبيل المثال، المتغير غير موجود أو تم تحديد عنصر مصفوفة لمتغير قياسي)، يتم إرجاع NULL ورسالة خطأ تُترك في نتيجة interp إذا كان بت TCL_LEAVE_ERR_MSG نشطًا.

يمكن استخدام Tcl_UnsetVar و Tcl_UnsetVar2 لحذف متغير، لذا فإن محاولات القراءة المستقبلية ستؤدي إلى خطأ. تُعامل الوسائط لهذه الإجراءات بنفس طريقة الوسائط للإجراءات السابقة. إذا تم حذف المتغير بنجاح، يتم إرجاع TCL_OK. إذا لم يكن المتغير موجودًا ولا يمكن حذفه، يتم إرجاع TCL_ERROR ورسالة خطأ تُترك في نتيجة interp إذا كان بت TCL_LEAVE_ERR_MSG نشطًا. إذا تم تحديد عنصر مصفوفة، يتم حذف العنصر المحدد ولكن تبقى المصفوفة. إذا تم تحديد اسم مصفوفة بدون مؤشر، يتم حذف المصفوفة بأكملها.

يمكن تحديد اسم المتغير لهذه الإجراءات بأربع طرق مختلفة:

[1]
إذا تم استدعاء Tcl_SetVar أو Tcl_GetVar أو Tcl_UnsetVar، يتم توفير اسم المتغير كسلسلة نصية فريدة، varName. إذا كان varName يحتوي على قوس مفتوح وينتهي بقوس مغلق، تُعامل القيمة بين الأقواس كمؤشر (أي قيمة سلسلة نصية) وتُعامل الأحرف قبل القوس الأول كاسم متغير مصفوفة. إذا لم يكن varName يحتوي على أقواس كما هو موضح، تُعامل القيمة الكاملة كاسم متغير قياسي.
[2]
إذا تم توفير الوسيطين name1 و name2 و name2 غير فارغ، يتم تحديد عنصر مصفوفة وقد تم فصل اسم المصفوفة والمؤشر بواسطة المستدعي: يحتوي name1 على الاسم و name2 يحتوي على المؤشر. يتم إنشاء خطأ إذا كان name1 يحتوي على قوس مفتوح وينتهي بقوس مغلق (عنصر مصفوفة) و name2 غير فارغ.
[3]
إذا كان name2 فارغًا، تُعامل name1 كاسم المتغير في الحالة [1] أعلاه (يمكن أن يكون متغيرًا قياسيًا أو مصفوفة).

يمكن استخدام الوسيط flags لتحديد أي من الخيارات المتعددة للإجراءات. يتكون من مجموعة OR للبتات التالية:

TCL_GLOBAL_ONLY
عادةً، تبحث الإجراءات عن المتغيرات بالطريقة التالية. إذا كان هناك استدعاء نشط في interp، يتم البحث عن المتغير في مستوى استدعاء الإجراء الحالي. بخلاف ذلك، يتم البحث أولاً في مساحة الاسم الحالية، ثم في مساحة الاسم العامة. ومع ذلك، إذا تم تعيين البت في flags، يتم البحث عن المتغير فقط في مساحة الاسم العامة، حتى لو كان هناك استدعاء نشط في interp. إذا تم توفير كل من TCL_GLOBAL_ONLY و TCL_NAMESPACE_ONLY، يتم تجاهل TCL_GLOBAL_ONLY.
TCL_NAMESPACE_ONLY
إذا تم تعيين هذا البت في flags، يتم البحث عن المتغير فقط في مساحة الاسم الحالية؛ إذا كان هناك استدعاء نشط، يتم تجاهل متغيراته، ويتم تجاهل مساحة الاسم العامة أيضًا، إلا إذا كانت هي مساحة الاسم الحالية.
TCL_LEAVE_ERR_MSG
إذا تم إرجاع خطأ وتم تعيين هذا البت في flags، فسيتم ترك رسالة خطأ في نتيجة المفسر، حيث يمكن استعادتها باستخدام Tcl_GetObjResult أو Tcl_GetStringResult. إذا لم يتم تفعيل هذا البت، فلن يتم ترك رسالة خطأ ولن يتم تعديل نتيجة المفسر.
TCL_APPEND_VALUE
إذا تم تعيين هذا البت، تتم إضافة قيمة newValuePtr أو newValue إلى القيمة الحالية بدلاً من استبدالها. إذا كان المتغير غير محدد حاليًا، يتم تجاهل البت. يستخدم هذا البت فقط بواسطة إجراءات Tcl_Set*.
TCL_LIST_ELEMENT
إذا تم تعيين هذا البت، تتم معالجة قيمة newValue كقائمة Tcl صالحة قبل تعيين (أو إضافة) المتغير. تتم إضافة مساحة فاصلة قبل الـ

NAME

Tcl_SetVar, Tcl_SetVar2, Tcl_GetVar, Tcl_GetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 - read and write Tcl variables

SYNOPSIS

    const char *rootName,
    const char *elementName,
    const char *newValue,
    int flags)

const char *
Tcl_GetVar(
    Tcl_Interp *interp,
    const char *varName,
    int flags)

const char *
Tcl_GetVar2(
    Tcl_Interp *interp,
    const char *rootName,
    const char *elementName,
    int flags)

int
Tcl_UnsetVar(
    Tcl_Interp *interp,
    const char *varName,
    int flags)

int
Tcl_UnsetVar2(
    Tcl_Interp *interp,
    const char *rootName,
    const char *elementName,
    int flags)

ARGUMENTS

Tcl_Interp *interp
Interpreter in which to manipulate the variable.
const char *varName
Name of the variable (for Tcl_SetVar, Tcl_GetVar, Tcl_UnsetVar).
const char *rootName
Name of the root variable (for Tcl_SetVar2, Tcl_GetVar2, Tcl_UnsetVar2).
const char *elementName
Index of the array element (for Tcl_SetVar2, Tcl_GetVar2, Tcl_UnsetVar2). If NULL, it means the variable is not an array element. For scalar variables, this argument must be NULL.
const char *newValue
The new value to set for the variable. Must be a valid Tcl value.
int flags
A bitmask of zero or more of the following values:
TCL_GLOBAL_ONLY
If set, the variable is looked up in the global scope even if the command is executed in a procedure. If not set, the variable is looked up in the current scope, or the global scope if there is no such variable in the current scope.
TCL_LEAVE_ERR_MSG
If set, error messages are left in the interpreter's result if an error occurs. If not set, the error messages are cleared.
TCL_APPEND_VALUE
If set, the newValue is appended to the existing value of the variable. The variable must already exist and contain a valid list. The resulting value will also be a valid list.
TCL_LIST_ELEMENT
If set, the variable is treated as a list and newValue is added as an element to the list. This is similar to TCL_APPEND_VALUE, but it does not require the variable to be a list already. The new element is added to the end unless it is the first element of a list or sublist. When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

DESCRIPTION

These procedures provide C-level access to Tcl variables. They allow you to read, write, and delete variables within a Tcl interpreter.

Tcl_SetVar and Tcl_SetVar2 are used to set the value of a Tcl variable. The variable is specified either by its name (for Tcl_SetVar) or by its root name and element name (for Tcl_SetVar2). Tcl_SetVar2 is used for array elements, where rootName is the name of the array and elementName is the index of the element. For scalar variables, elementName must be NULL. The newValue argument specifies the value to store in the variable. The flags argument controls how the variable is accessed and modified.

TCL_APPEND_VALUE: Appends newValue to the existing value of the variable. The variable must already exist and contain a valid Tcl list. The resulting value will also be a valid Tcl list.

TCL_LIST_ELEMENT: Treats the variable as a list and appends newValue as an element to the list. This flag is similar to TCL_APPEND_VALUE, but it does not require the variable to already contain a valid list. The new element is added to the end unless it is the first element of a list or sublist (i.e. the variable's current value is empty, or contains the single character “{”, or ends in “ }”). When appending, the original value of the variable must also be a valid list, so that the operation is the appending of a new list element onto a list.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
