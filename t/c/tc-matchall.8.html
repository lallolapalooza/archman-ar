tc-matchall(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

Match-all classifier in tc(8) Linux Match-all classifier in tc(8)

الاسم

matchall - مرشح التحكم في حركة المرور الذي يطابق كل حزمة

الملخص


tc filter ... matchall [ skip_sw | skip_hw ] [ action ACTION_SPEC ] [ classid CLASSID ]

الوصف

يتيح مرشح matchall تصنيف كل حزمة تتدفق على المنفذ وتنفيذ إجراء عليها.

الخيارات

action ACTION_SPEC
تطبيق إجراء من إطار عمل الإجراءات العام على الحزم المطابقة.
classid CLASSID
دفع الحزم المطابقة إلى الفئة المحددة بواسطة CLASSID.
skip_sw
لا تقم بمعالجة المرشح بواسطة البرنامج. إذا لم يكن لدى الجهاز دعم تفريغ لهذا المرشح، أو إذا لم يتم تمكين تفريغ TC للواجهة، فسيفشل التشغيل.
skip_hw
لا تقم بمعالجة المرشح بواسطة الجهاز.

أمثلة

لإنشاء نسخة طبق الأصل عند الدخول من المنفذ eth1 إلى المنفذ eth2:

tc qdisc  add dev eth1 handle ffff: clsact
tc filter add dev eth1 ingress                \
        matchall skip_sw                      \
        action mirred egress mirror           \
        dev eth2

يقوم الأمر الأول بإنشاء qdisc clsact بمعرف ffff: على الجهاز eth1 حيث يرفق الأمر الثاني مرشح matchall به الذي ينسخ الحزم إلى الجهاز eth2 عند الدخول.

لإنشاء نسخة طبق الأصل عند الخروج من المنفذ eth1 إلى المنفذ eth2:

tc qdisc add dev eth1 handle ffff: clsact
tc filter add dev eth1 egress                  \
        matchall skip_sw                       \
        action mirred egress mirror            \
        dev eth2

يقوم الأمر الأول بإنشاء qdisc clsact بمعرف ffff: على الجهاز eth1 حيث يرفق الأمر الثاني مرشح matchall به الذي ينسخ الحزم إلى الجهاز eth2 عند الخروج.

لأخذ عينة من كل 100 حزمة تتدفق إلى الواجهة eth0 إلى مجموعة psample 12:

tc qdisc add dev eth0 handle ffff: ingress
tc filter add dev eth0 parent ffff: matchall \
     action sample rate 100 group 12
