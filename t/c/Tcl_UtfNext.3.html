الوصف

تقوم هذه الإجراءات بالتحويل بين سلاسل UTF-8 و Tcl_UniChars. Tcl_UniChar هو حرف Unicode ممثل بكمية ثابتة الحجم، غير موقعة. حرف UTF-8 هو حرف Unicode ممثل بتسلسل متغير الطول يصل إلى TCL_UTF_MAX بايت. يتكون تسلسل UTF-8 متعدد البايتات من بايت رائد متبوعًا ببعض البايتات التالية.

TCL_UTF_MAX هو الحد الأقصى لعدد البايتات المطلوبة لتمثيل حرف Unicode واحد في تمثيل UTF-8.

Tcl_UniCharToUtf يخزن Tcl_UniChar ch كسلسلة UTF-8 تبدأ من buf. القيمة المرجعة هي عدد البايتات المخزنة في buf.

Tcl_UtfToUniChar يقرأ حرف UTF-8 واحد بدءًا من src ويخزنه كـ Tcl_UniChar في *chPtr. القيمة المرجعة هي عدد البايتات المقروءة من src. يجب على المستدعي التأكد من أن المخزن المؤقت المصدر طويل بما يكفي بحيث لا يتجاوز هذا الإجراء النهاية ويفك مرجع ذاكرة غير موجودة أو عشوائية؛ إذا كان المخزن المؤقت المصدر معروفًا بأنه منتهي بـ null، فلن يحدث هذا. إذا لم يكن الإدخال بتنسيق UTF-8 صحيح، فسيقوم Tcl_UtfToUniChar بتخزين البايت الأول من src في *chPtr كـ Tcl_UniChar بين 0x80 و 0xFF ويعيد 1.

Tcl_UniCharToUtfDString يحول سلسلة Unicode المعطاة إلى UTF-8، ويخزن النتيجة في Tcl_DString تم تهيئته مسبقًا. يجب عليك تحديد uniLength، طول سلسلة Unicode المعطاة. القيمة المرجعة هي مؤشر إلى تمثيل UTF-8 لسلسلة Unicode. يتم إلحاق مساحة الذاكرة للقيمة المرجعة بنهاية Tcl_DString.

Tcl_UtfToUniCharDString يحول سلسلة UTF-8 المعطاة إلى Unicode، ويخزن النتيجة في Tcl_DString الذي تم تهيئته مسبقًا. في الوسيط length، يمكنك إما تحديد طول سلسلة UTF-8 المعطاة بالبايتات أو "“-1”", في هذه الحالة يستخدم Tcl_UtfToUniCharDString strlen لحساب الطول. القيمة المرجعة هي مؤشر إلى تمثيل Unicode لسلسلة UTF-8. يتم إلحاق مساحة الذاكرة للقيمة المرجعة بنهاية Tcl_DString. يتم إنهاء سلسلة Unicode بحرف null Unicode.

Tcl_UniCharLen يقابل strlen لأحرف Unicode. يقبل سلسلة Unicode منتهية بـ null ويعيد عدد أحرف Unicode (ليس بايتات) في تلك السلسلة.

Tcl_UniCharNcmp و Tcl_UniCharNcasecmp يقابلان strncmp و strncasecmp، على التوالي، لأحرف Unicode. يقبلان سلسلتي Unicode منتهيتين بـ null وعدد الأحرف للمقارنة. يُفترض أن كلتا السلسلتين بطول numChars على الأقل. يقارن Tcl_UniCharNcmp السلسلتين حرفًا بحرف وفقًا لترتيب أحرف Unicode. يعيد عددًا صحيحًا أكبر من، أو يساوي، أو أقل من 0 إذا كانت السلسلة الأولى أكبر من، أو تساوي، أو أقل من السلسلة الثانية على التوالي. Tcl_UniCharNcasecmp هو الإصدار غير الحساس لحالة أحرف Unicode.

Tcl_UniCharCaseMatch هو مكافئ Unicode لـ Tcl_StringCaseMatch. يقبل سلسلة Unicode منتهية بـ null، ونمط Unicode، وقيمة منطقية تحدد ما إذا كان يجب أن تكون المطابقة حساسة لحالة الأحرف أم لا، ويعيد ما إذا كانت السلسلة تطابق النمط.

Tcl_UtfNcmp يقابل strncmp لسلاسل UTF-8. يقبل سلسلتي UTF-8 منتهيتين بـ null وعدد الأحرف للمقارنة. (يُفترض أن كلتا السلسلتين بطول numChars على الأقل.) يقارن Tcl_UtfNcmp السلسلتين حرفًا بحرف وفقًا لترتيب أحرف Unicode. يعيد عددًا صحيحًا أكبر من، أو يساوي، أو أقل من 0 إذا كانت السلسلة الأولى أكبر من، أو تساوي، أو أقل من السلسلة الثانية على التوالي.

Tcl_UtfNcasecmp يقابل strncasecmp لسلاسل UTF-8. إنه مشابه لـ Tcl_UtfNcmp باستثناء أن المقارنات تتجاهل اختلافات الحالة عند مقارنة الأحرف العلوية، السفلية، أو العناوين.

Tcl_UtfCharComplete يعيد 1 إذا كانت سلسلة UTF-8 المصدر src بطول length بايت طويلة بما يكفي ليتم فك ترميزها بواسطة Tcl_UtfToUniChar/Tcl_UtfNext، أو 0 بخلاف ذلك. لا يضمن هذا الإجراء أن سلسلة UTF-8 مشكلة بشكل صحيح. يستخدم هذا الإجراء من قبل الإجراءات التي تعمل بايتًا تلو الآخر وتحتاج إلى معرفة ما إذا كان قد تم رؤية Tcl_UniChar كامل.

Tcl_NumUtfChars يقابل strlen لسلاسل UTF-8. يعيد عدد Tcl_UniChars التي يتم تمثيلها بواسطة سلسلة UTF-8 src. طول السلسلة المصدر هو length بايت. إذا كان الطول سالبًا، فسيتم استخدام جميع البايتات حتى أول بايت null.

Tcl_UtfFindFirst يقابل strchr لسلاسل UTF-8. يعيد مؤشرًا إلى أول ظهور لـ Tcl_UniChar ch في سلسلة UTF-8 المنتهية بـ null src. يعتبر الفاصل null جزءًا من سلسلة UTF-8.

Tcl_UtfFindLast يقابل strrchr لسلاسل UTF-8. يعيد مؤشرًا إلى آخر ظهور لـ Tcl_UniChar ch في سلسلة UTF-8 المنتهية بـ null src. يعتبر الفاصل null جزءًا من سلسلة UTF-8.

Tcl_UtfNext يعيد مؤشرًا إلى البايت التالي لحرف UTF-8 الحالي في src. يجب أن يكون src بالفعل في بداية حرف UTF-8 (على سبيل المثال، تم الحصول عليه من Tcl_UtfFindFirst أو Tcl_UtfNext). إذا كان src يشير إلى الفاصل null، فسيتم إرجاع src.

Tcl_UtfPrev يعيد مؤشرًا إلى بداية حرف UTF-8 السابق في src. يبدأ البحث من start، وهو مؤشر إلى بداية سلسلة UTF-8. إذا كان src يشير إلى بداية سلسلة UTF-8، فلن يتم إرجاع أي شيء.

Tcl_UniCharAtIndex يعيد Tcl_UniChar في الفهرس index (عدد الأحرف) في سلسلة UTF-8 src. إذا لم يكن الفهرس صالحًا، فسيتم إرجاع حرف null Unicode.

Tcl_UtfAtIndex يعيد مؤشرًا إلى بداية حرف UTF-8 في الفهرس index (عدد الأحرف) في سلسلة UTF-8 src. إذا لم يكن الفهرس صالحًا، فسيتم إرجاع سلسلة فارغة.

Tcl_UtfBackslash يفسر تسلسل الشرطة المائلة العكسية في src. إذا نجح، فإنه يكتب تمثيل UTF-8 للأحرف المعنية في dst، ويقوم بتعيين *readPtr لعدد البايتات التي تم قراءتها من src (بما في ذلك الشرطة المائلة العكسية)، ويعيد 1. إذا لم يكن src يبدأ بتسلسل شرطة مائلة عكسية صالح، فإنه يعيد 0.

NAME

Tcl_UtfNext, Tcl_UniCharAtIndex, Tcl_UtfAtIndex, Tcl_UtfPrev, Tcl_UtfBackslash - process UTF-8 strings

DESCRIPTION

Tcl_UtfNext returns the first UTF-8 character starting at the location given by src. The character is returned as a Tcl_UniChar. The argument src is modified to point to the byte following the character returned.

Tcl_UniCharAtIndex returns the Tcl_UniChar for the character at the given index in the UTF-8 string src. The string is assumed to be null terminated. The character at the given index must be completely contained within the string.

Tcl_UtfAtIndex returns a pointer to the character at the given index in the UTF-8 string src. The string is assumed to be null terminated. The character at the given index must be completely contained within the string.

Tcl_UtfPrev is used to step backward through the UTF-8 string that begins at start. Given src, a pointer to some location in a UTF-8 string, Tcl_UtfPrev returns a pointer to the UTF-8 character in the string that contains the byte src[-1]. The null terminator is considered part of the UTF-8 string.

Given src, a pointer to some location in a UTF-8 string, Tcl_UtfNext returns a pointer to the next UTF-8 character in the string. The caller must not ask for the next character after the last character in the string if the string is not terminated by a null character. Tcl_UtfCharComplete can be used in that case to make sure enough bytes are available before calling Tcl_UtfNext.

Tcl_UtfPrev is used to step backward through but not beyond the UTF-8 string that begins at start. If the UTF-8 string is made up entirely of complete and well-formed characters, and src points to the lead byte of one of those characters (or to the location one byte past the end of the string), then repeated calls of Tcl_UtfPrev will return pointers to the lead bytes of each character in the string, one character at a time, terminating when it returns start.

When the conditions of completeness and well-formedness may not be satisfied, a more precise description of the function of Tcl_UtfPrev is necessary. It always returns a pointer greater than or equal to start; that is, always a pointer to a location in the string. It always returns a pointer to a byte that begins a character when scanning for characters beginning from start. When src is greater than start, it always returns a pointer less than src and greater than or equal to (src - TCL_UTF_MAX). The character that begins at the returned pointer is the first one that either includes the byte src[-1], or might include it if the right trail bytes are present at src and greater. Tcl_UtfPrev never reads the byte src[0] nor the byte start[-1] nor the byte src[-TCL_UTF_MAX-1].

Tcl_UniCharAtIndex corresponds to a C string array dereference or the Pascal Ord() function. It returns the Tcl_UniChar represented at the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. Behavior is undefined if a negative index is given.

Tcl_UtfAtIndex returns a pointer to the specified character (not byte) index in the UTF-8 string src. The source string must contain at least index characters. This is equivalent to calling Tcl_UtfToUniChar index times. If a negative index is given, the return pointer points to the first character in the source string.

Tcl_UtfBackslash is a utility procedure used by several of the Tcl commands. It parses a backslash sequence and stores the properly formed UTF-8 character represented by the backslash sequence in the output buffer dst. At most TCL_UTF_MAX bytes are stored in the buffer. Tcl_UtfBackslash modifies *readPtr to contain the number of bytes in the backslash sequence, including the backslash character. The return value is the number of bytes stored in the output buffer.

See the Tcl manual entry for information on the valid backslash sequences. All of the sequences described in the Tcl manual entry are supported by Tcl_UtfBackslash.
