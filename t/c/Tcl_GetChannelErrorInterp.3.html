Tcl_GetChannelErrorInterp(3)

الحزمة: tcl

التراخيص: TCL

Tcl_SetChannelError(3) إجراءات مكتبة Tcl Tcl_SetChannelError(3)

الاسم

Tcl_SetChannelError, Tcl_SetChannelErrorInterp, Tcl_GetChannelError, Tcl_GetChannelErrorInterp - وظائف لإنشاء / اعتراض أخطاء Tcl بواسطة برامج تشغيل القناة.

الملخص

#include <tcl.h>

void
Tcl_SetChannelError(chan, msg)

void
Tcl_SetChannelErrorInterp(interp, msg)

void
Tcl_GetChannelError(chan, msgPtr)

void
Tcl_GetChannelErrorInterp(interp, msgPtr)

المعاملات

Tcl_Channel chan (في)
يشير إلى قناة Tcl التي يتم الوصول إلى منطقة تجاوزها.
Tcl_Interp* interp (في)
يشير إلى مترجم Tcl الذي يتم الوصول إلى منطقة تجاوزه.
Tcl_Obj* msg (في)
رسالة الخطأ توضع في منطقة تجاوز. قائمة بخيارات وقيم الإرجاع، تليها رسالة نصية. كلاهما، الرسالة ومعلومات الخيار / القيمة، اختيارية.
Tcl_Obj** msgPtr (خارج)
مرجع لمكان يمكن تخزين الرسالة المخزنة في منطقة التجاوز التي تم الوصول إليها فيه.

الوصف

التعريف الحالي لبرنامج تشغيل قناة Tcl لا يسمح بالإرجاع المباشر لرسائل خطأ عشوائية، باستثناء تعيين واسترداد خيارات القناة. جميع الوظائف الأخرى مقيدة برموز خطأ POSIX.

الوظائف الموصوفة هنا تتغلب على هذا القيد. يُسمح لبرامج تشغيل القناة باستخدام Tcl_SetChannelError و Tcl_SetChannelErrorInterp لوضع رسائل خطأ عشوائية في مناطق التجاوز المعرفة للقنوات والمترجمات. ويستخدم طبقة الإدخال / الإخراج العامة Tcl_GetChannelError و Tcl_GetChannelErrorInterp للبحث عن رسائل في مناطق التجاوز وترتيب إرجاعها كأخطاء. يتم استخدام رموز خطأ POSIX التي تم تعيينها بواسطة برنامج التشغيل الآن فقط إذا لم تكن هناك رسائل موجودة.

Tcl_SetChannelError يخزن معلومات الخطأ في منطقة التجاوز للقناة المحددة. يزداد عدد المراجع لقيمة msg بواحد. سيتم تجاهل المعلومات المخزنة سابقًا، عن طريق تحرير المرجع الذي تحتفظ به القناة. يجب ألا يكون مرجع القناة NULL.

Tcl_SetChannelErrorInterp يخزن معلومات الخطأ في منطقة التجاوز للمترجم المحدد. يزداد عدد المراجع لقيمة msg بواحد. سيتم تجاهل المعلومات المخزنة سابقًا، عن طريق تحرير المرجع الذي يحتفظ به المترجم. يجب ألا يكون مرجع المترجم NULL.

Tcl_GetChannelError يضع إما رسالة الخطأ المخزنة في منطقة التجاوز للقناة المحددة في msgPtr، أو NULL؛ ويعيد تعيين التجاوز، أي بعد استدعاء ستعيد جميع الاستدعاءات اللاحقة NULL، حتى استدعاء وسيط لـ Tcl_SetChannelError مع رسالة غير NULL. يجب ألا يكون msgPtr NULL. لا يتم لمس عدد المراجع للرسالة. المرجع الذي كانت تحتفظ به القناة سابقًا يتم الاحتفاظ به الآن بواسطة مستدعي الوظيفة وهو مسؤوليتها لتحرير هذا المرجع عندما تنتهي من القيمة.

Tcl_GetChannelErrorInterp يضع إما رسالة الخطأ المخزنة في منطقة التجاوز للمترجم المحدد في msgPtr، أو NULL؛ ويعيد تعيين التجاوز، أي بعد استدعاء ستعيد جميع الاستدعاءات اللاحقة NULL، حتى استدعاء وسيط لـ Tcl_SetChannelErrorInterp مع رسالة غير NULL. يجب ألا يكون msgPtr NULL. لا يتم لمس عدد المراجع للرسالة. المرجع الذي كان يحتفظ به المترجم سابقًا يتم الاحتفاظ به الآن بواسطة مستدعي الوظيفة وهو مسؤوليتها لتحرير هذا المرجع عندما تنتهي من القيمة.

تُدرج أدناه الوظائف التي يُسمح لبرنامج تشغيل القناة باستخدامها، وكذلك الوظائف التي قد تترك رسائل في مناطق التجاوز من واجهة برمجة تطبيقات القناة العامة.

Tcl_GetChannelErrorInterp

Tcl_GetChannelErrorInterp — retrieve the last channel error for an interpreter

SYNOPSIS

#include <tcl.h>

int
Tcl_GetChannelErrorInterp(interp)
    Tcl_Interp *interp;

ARGUMENTS

interp (in)
Tcl interpreter.

DESCRIPTION

The Tcl_GetChannelErrorInterp function returns the channel-specific error message for the interpreter given by interp. This function is intended for use by channel drivers to retrieve the channel-specific error message after an error has occurred. The error message is stored in the interpreter’s result.

If no channel error has occurred, the result is an empty string. The caller is responsible for freeing the memory used by the result if it is not empty, using Tcl_Free.

SEE ALSO

Tcl_GetChannelError(3), Tcl_SetChannelError(3), Tcl_GetErrorLine(3)

KEYWORDS

channel, error, message, interpreter
