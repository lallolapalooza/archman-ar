mpls في tc(8) - وحدة معالجة MPLS Linux mpls في tc(8) - وحدة معالجة MPLS

الاسم

mpls - وحدة معالجة MPLS

موجز


tc ... action mpls { POP | PUSH | MODIFY | dec_ttl } [ CONTROL ]

POP := pop protocol MPLS_PROTO

PUSH := { push | mac_push } [ protocol MPLS_PROTO ] [ tc MPLS_TC ] [ ttl MPLS_TTL ] [ bos MPLS_BOS ] label MPLS_LABEL

MODIFY := modify [ label MPLS_LABEL ] [ tc MPLS_TC ] [ ttl MPLS_TTL ]

CONTROL := { reclassify | pipe | drop | continue | pass | goto chain CHAIN_INDEX }

الوصف

يقوم الإجراء mpls بتغليف أو فك تغليف MPLS للحزمة، وينعكس ذلك في أوضاع التشغيل POP و PUSH و MODIFY و DEC_TTL. يتطلب وضع POP نوع البروتوكول (ethertype) للرأس الذي يتبع رأس MPLS (على سبيل المثال IPv4 أو MPLS آخر). سيقوم بإزالة رأس MPLS الخارجي واستبدال نوع البروتوكول في رأس MAC بالنوع الذي تم تمريره. تقوم أوضاع PUSH و MODIFY بتحديث معلومات رأس MPLS الحالية أو إضافة رأس جديد. يتطلب PUSH على الأقل MPLS_LABEL. يتطلب DEC_TTL عدم وجود وسيطات ويقوم ببساطة بطرح 1 من حقل TTL لرأس MPLS.

الخيارات

pop
وضع فك التغليف. يتطلب بروتوكول الرأس التالي.
push
وضع التغليف. يضيف رأس MPLS بين رأس MAC ورؤوس الشبكة. يتطلب على الأقل الخيار label.
mac_push
وضع التغليف. يضيف رأس MPLS قبل رأس MAC. يتطلب على الأقل الخيار label.
modify
وضع الاستبدال. يتم استبدال علامة MPLS الموجودة. label و tc و ttl كلها اختيارية.
dec_ttl
تقليل قيمة حقل TTL في رأس MPLS الخارجي.
label MPLS_LABEL
تحديد MPLS_LABEL لرأس MPLS الخارجي. MPLS_LABEL هو عدد صحيح غير سالب بحجم 20 بت، ويتم اكتشاف التنسيق تلقائيًا (على سبيل المثال، بادئة بـ '0x' للتفسير السداسي عشري، وما إلى ذلك).
protocol MPLS_PROTO
اختر البروتوكول المراد استخدامه. بالنسبة لإجراءات الدفع، يجب أن يكون mpls_uc أو mpls_mc (mpls_uc هو الافتراضي). بالنسبة لإجراءات السحب، يجب أن يكون بروتوكول الرأس التالي. لا يمكن استخدام هذا الخيار مع modify.
tc MPLS_TC
اختر قيمة TC لرأس MPLS الخارجي. رقم عشري في النطاق من 0-7. القيمة الافتراضية هي 0.
ttl MPLS_TTL
اختر قيمة TTL لرأس MPLS الخارجي. رقم في النطاق من 0-255. سيتم تحديد قيمة افتراضية غير صفرية إذا لم يتم تعيين هذا بشكل صريح.
bos MPLS_BOS
تكوين يدوي لبت قاع المكدس لرأس MPLS. الافتراضي هو أن يقوم TC تلقائيًا بتعيين (أو إلغاء تعيين) البت بناءً على الرأس التالي للحزمة.
CONTROL
كيفية المتابعة بعد تنفيذ هذا الإجراء.
reclassify
إعادة تشغيل التصنيف بالقفز مرة أخرى إلى أول مرشح مرتبط بالسلف لهذا الإجراء.
pipe
متابعة الإجراء التالي، هذا هو الافتراضي.
drop
سيتم إسقاط الحزمة دون تشغيل إجراءات أخرى.
continue
متابعة التصنيف مع المرشح التالي في الصف.
pass
العودة إلى qdisc المتصل لمعالجة الحزمة. هذا ينهي عملية التصنيف.

أمثلة

المثال التالي يغلف حزم IP الواردة على eth0 في MPLS بعلامة (label) 123 ويرسلها خارج eth1:

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 protocol ip parent ffff: flower \
	action mpls push protocol mpls_uc label 123  \
	action mirred egress redirect dev eth1

في هذا المثال، يتم فك تغليف حزم MPLS unicast الواردة على eth0 وإعادة توجيهها إلى eth1:

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 protocol mpls_uc parent ffff: flower \
	action mpls pop protocol ipv4  \
	action mirred egress redirect dev eth1

هنا مثال آخر، حيث يتم تغليف إطارات Ethernet الواردة في MPLS بعلامة 123 و TTL 64. ثم، يتم إضافة رأس Ethernet خارجي ويتم إرسال الإطار الناتج أخيرًا على eth1:

#tc qdisc add dev eth0 ingress
#tc filter add dev eth0 ingress matchall \
	action mpls mac_push label 123 ttl 64 \
	action vlan push_eth \
		dst_mac 02:00:00:00:00:02 \
		src_mac 02:00:00:00:00:01 \
	action mirred egress redirect dev eth1

يفترض المثال التالي أن حزم MPLS الواردة بعلامة 123 تنقل إطارات Ethernet. يتم تجريد رؤوس Ethernet و MPLS الخارجية، ثم يتم إرسال إطار Ethernet الداخلي على eth1:

#tc qdisc add dev eth0 ingress
#tc filter add dev eth0 ingress protocol mpls_uc \
	flower mpls_label 123 mpls_bos 1 \
	action vlan pop_eth \
	action mpls pop protocol teb \
	action mirred egress redirect dev eth1
