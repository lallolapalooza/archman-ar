Tcl_NewMethod(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_NewMethod, Tcl_NewObjectMethod, Tcl_NewInstanceMethod, Tcl_GetMethod, Tcl_GetMethodByName, Tcl_MethodCallProc, Tcl_MethodDeleteProc, Tcl_CloneProc - manage methods for TclOO objects

SYNOPSIS

#include <tclOO.h>

Tcl_Method
Tcl_NewMethod(
        Tcl_Interp *interp,
        Tcl_Class class,
        const char *methodName,
        Tcl_MethodCallProc *callProc,
        Tcl_MethodDeleteProc *deleteProc,
        ClientData clientData);

Tcl_Method
Tcl_NewObjectMethod(
        Tcl_Interp *interp,
        Tcl_Class class,
        const char *methodName,
        Tcl_MethodCallProc *callProc,
        Tcl_MethodDeleteProc *deleteProc,
        ClientData clientData);

Tcl_Method
Tcl_NewInstanceMethod(
        Tcl_Interp *interp,
        Tcl_Class class,
        const char *methodName,
        Tcl_MethodCallProc *callProc,
        Tcl_MethodDeleteProc *deleteProc,
        ClientData clientData);

Tcl_Method
Tcl_GetMethod(
        Tcl_Interp *interp,
        Tcl_ObjectContext context,
        const char *methodName);

Tcl_Method
Tcl_GetMethodByName(
        Tcl_Interp *interp,
        Tcl_ObjectContext context,
        Tcl_Obj *methodNamePtr);

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting and command execution.
Tcl_Class class
The class to add the method to.
const char *methodName
The name of the method to create.
Tcl_MethodCallProc *callProc
The procedure to invoke when the method is called.
Tcl_MethodDeleteProc *deleteProc
The procedure to invoke when the method is deleted.
ClientData clientData
Arbitrary client data to associate with the method.
Tcl_ObjectContext context
The context in which to look up the method.
Tcl_Method *methodPtr
Pointer to a Tcl_Method to retrieve.
Tcl_Obj *methodNamePtr
The name of the method to retrieve.

DESCRIPTION

These functions are used to create, retrieve and manage methods for classes and objects in the TclOO object system.

Tcl_NewMethod creates and installs a new method in the specified class. The method is specified by methodName, callProc, deleteProc, and clientData. When the method is called, callProc is invoked with clientData as its first argument. When the method is deleted, deleteProc is invoked with clientData as its argument.

Tcl_NewObjectMethod and Tcl_NewInstanceMethod are specializations of Tcl_NewMethod. Tcl_NewObjectMethod creates an object method, which is invoked when the method is called on a class. Tcl_NewInstanceMethod creates an instance method, which is invoked when the method is called on an object.

Tcl_GetMethod searches for a method named methodName in the specified context. The context specifies the object or class in which to search for the method. The search proceeds up the method resolution order of the object's class.

Tcl_GetMethodByName is similar to Tcl_GetMethod, but takes a Tcl object pointer for the method name.

TCL_METHODCALLPROC FUNCTION SIGNATURE

Functions matching this signature are called when the method is invoked.

typedef int Tcl_MethodCallProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_ObjectContext objectContext,
        int objc,
        Tcl_Obj *const *objv);

The clientData argument to a Tcl_MethodCallProc is the value that was given when the method was created, the interp is a place in which to execute scripts and access variables as well as being where to put the result of the method, and the objc and objv fields give the parameter objects to the method. The calling context of the method can be discovered through the objectContext argument, and the return value from a Tcl_MethodCallProc is any Tcl return code (e.g. TCL_OK, TCL_ERROR).

TCL_METHODDELETEPROC FUNCTION SIGNATURE

Functions matching this signature are used when a method is deleted, whether through a new method being created or because the object or class is deleted.

typedef void Tcl_MethodDeleteProc(
        ClientData clientData);

The clientData argument to a Tcl_MethodDeleteProc will be the same as the value passed to the clientData argument to Tcl_NewMethod or Tcl_NewInstanceMethod when the method was created.

TCL_CLONEPROC FUNCTION SIGNATURE

Functions matching this signature are used to copy a method when the object or class is copied using Tcl_CopyObjectInstance (or oo::copy).

typedef int Tcl_CloneProc(
        Tcl_Interp *interp,
        ClientData oldClientData,
        ClientData *newClientDataPtr);

The interp argument gives a place to write an error message when the attempt to clone the object is to fail, in which case the clone procedure must also return TCL_ERROR; it should return TCL_OK otherwise. The oldClientData field to a Tcl_CloneProc gives the value from the method being copied from, and the newClientDataPtr field will point to a variable in which to write the value for the method being copied to.
