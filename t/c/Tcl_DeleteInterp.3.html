Tcl_DeleteInterp(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_DeleteInterp - destroy an interpreter

SYNOPSIS

#include <tcl.h>

void
Tcl_DeleteInterp(interp)
    Tcl_Interp *interp;

ARGUMENTS

<code>interp</code> (in)

Interpreter to destroy.

DESCRIPTION

The procedure Tcl_DeleteInterp destroys the interpreter specified by interp. This will free all memory that was allocated by Tcl for the interpreter, including any memory allocated for the interpreter's variable storage, command table, and script resources. It will also call the Tcl_CallExitProcs procedure to invoke any exit procedures that were registered with the interpreter. It is unsafe to use the interpreter after it has been deleted.

KEYWORDS

interpreter, destroy, delete, free

الاسم

Tcl_DeleteInterp - تدمير مترجم

الملخص

#include <tcl.h>

void
Tcl_DeleteInterp(interp)
    Tcl_Interp *interp;

الوسائط

<code>interp</code> (في)

المترجم المراد تدميره.

الوصف

يقوم الإجراء Tcl_DeleteInterp بتدمير المترجم المحدد بواسطة interp. سيؤدي هذا إلى تحرير جميع الذاكرة التي خصصتها Tcl للمترجم، بما في ذلك أي ذاكرة مخصصة لتخزين متغيرات المترجم، جدول الأوامر، وموارد النص البرمجي. سيقوم أيضًا باستدعاء الإجراء Tcl_CallExitProcs لاستدعاء أي إجراءات خروج تم تسجيلها مع المترجم. استخدام المترجم بعد تدميره غير آمن.
