tcl_prefix(n)

الحزمة: tcl

التراخيص: TCL

prefix(n) أوامر Tcl المضمنة prefix(n)

الاسم

tcl::prefix - تسهيلات لمطابقة البادئة

الملخص

::tcl::prefix all جدول سلسلة
::tcl::prefix longest جدول سلسلة
::tcl::prefix match ?خيار ...? جدول سلسلة

الوصف

توثق هذه الوثيقة الأوامر التي تبحث عن بادئة في قائمة من السلاسل. الأوامر التالية مدعومة:

::tcl::prefix all جدول سلسلة
يعيد قائمة بجميع العناصر في جدول التي تبدأ بالبادئة سلسلة.
::tcl::prefix longest جدول سلسلة
يعيد أطول بادئة مشتركة لجميع العناصر في جدول التي تبدأ بالبادئة سلسلة.
::tcl::prefix match ?خيار ...? جدول سلسلة
إذا كانت سلسلة تساوي عنصرًا واحدًا في جدول أو كانت بادئة لعنصر واحد بالضبط، فسيتم إرجاع العنصر المتطابق. إذا لم يكن الأمر كذلك، فإن النتيجة تعتمد على الخيار -error. (يوصى بفرز جدول قبل استخدامه مع هذا الأمر الفرعي، بحيث تكون قائمة التطابقات المعروضة في رسالة الخطأ مرتبة أيضًا، على الرغم من أن هذا ليس ضروريًا بشكل صارم لعمل هذا الأمر الفرعي نفسه.) الخيارات التالية مدعومة:
-exact 
قبول التطابقات الدقيقة فقط.
-message سلسلة
استخدم سلسلة في رسالة الخطأ عند عدم التطابق. الافتراضي هو “option”.
-error خيارات
تستخدم خيارات عندما لا يتم العثور على تطابق. إذا كانت خيارات فارغة، فلن يتم إنشاء خطأ وسيتم إرجاع سلسلة فارغة. خلاف ذلك، تستخدم خيارات كخيارات return عند إنشاء رسالة الخطأ. الافتراضي يتوافق مع تعيين “-level 0”. مثال: إذا تم استخدام “-error {-errorcode MyError -level 1}”، فسيتم إنشاء خطأ على النحو التالي:
return -errorcode MyError -level 1 -code error \
       "ambiguous option ..."

أمثلة

الاستخدام الأساسي:

namespace import ::tcl::prefix
prefix match {apa bepa cepa} apa
     → apa
prefix match {apa bepa cepa} a
     → apa
prefix match -exact {apa bepa cepa} a
     → bad option "a": must be apa, bepa, or cepa
prefix match -message "switch" {apa ada bepa cepa} a
     → ambiguous switch "a": must be apa, ada, bepa, or cepa
prefix longest {fblocked fconfigure fcopy file fileevent flush} fc
     → fco
prefix all {fblocked fconfigure fcopy file fileevent flush} fc
     → fconfigure fcopy

تبسيط مطابقة الخيارات:

array set opts {-apa 1 -bepa "" -cepa 0}
foreach {arg val} $args {
    set opts([prefix match {-apa -bepa -cepa} $arg]) $val
}

إنشاء switch يدعم البادئات:

switch [prefix match {apa bepa cepa} $arg] {
    apa  { }
    bepa { }
    cepa { }
}
