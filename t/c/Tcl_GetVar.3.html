Tcl_GetVar(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_GetVar, Tcl_GetVar2, Tcl_SetVar, Tcl_SetVar2, Tcl_UnsetVar, Tcl_UnsetVar2 - access Tcl variables

SYNOPSIS

#include <tcl.h>

int
Tcl_SetVar(interp, name, value, flags)
Tcl_Obj *interp;
const char *name;
const char *value;
int flags;

int
Tcl_SetVar2(interp, name1, name2, value, flags)
Tcl_Obj *interp;
const char *name1;
const char *name2;
const char *value;
int flags;

Tcl_Obj *
Tcl_GetVar(interp, name, flags)
Tcl_Obj *interp;
const char *name;
int flags;

Tcl_Obj *
Tcl_GetVar2(interp, name1, name2, flags)
Tcl_Obj *interp;
const char *name1;
const char *name2;
int flags;

int
Tcl_UnsetVar(interp, name, flags)
Tcl_Obj *interp;
const char *name;
int flags;

int
Tcl_UnsetVar2(interp, name1, name2, flags)
Tcl_Obj *interp;
const char *name1;
const char *name2;
int flags;

ARGUMENTS

Tcl_Obj *interp
Interpreter to use for the operation.
const char *name
Name of the variable.
const char *name1
First part of the variable name (used for arrays).
const char *name2
Second part of the variable name (used for arrays).
const char *value
The value to set the variable to.
int flags
A bit-mask of options. The following bits are valid:
TCL_GLOBAL_ONLY
Operate on the global variable with the given name, not the one in the current scope. If this flag is set, then the variable is looked up in the global scope. If it is not set, then the variable is looked up in the current scope unless it is qualified with a scope qualifier like ::.
TCL_LEAVE_ERR_MSG
If an error occurs and this flag is set, then Tcl will not update the error message in the interpreter. This can be used when calling Tcl_SetVar or Tcl_GetVar from within another Tcl command, where the command itself will set the error message.
TCL_APPEND_VALUE
Append value to the existing value of the variable instead of replacing it. The variable must already exist and have a scalar value. The result will be the concatenation of the old value and value.
TCL_APPEND_STRING
Append value to the existing value of the variable instead of replacing it. The variable must already exist and have a scalar value. The result will be the concatenation of the old value and value. This flag is deprecated and should not be used. Use TCL_APPEND_VALUE instead.
TCL_LIST_ELEMENT
Append value as a new element to the list stored in the variable. The variable must exist and its value must be a list (or an empty string, which is treated as an empty list). The new element is added to the end of the list. The variable's new value will be the old list with the new element added. The variable must not be an array element.
TCL_LIST_ONLY
This flag is the same as TCL_LIST_ELEMENT, except that it prevents list elements from being automatically created if the variable doesn't exist or is not a list. This flag can only be used with Tcl_SetVar and Tcl_SetVar2.

DESCRIPTION

The procedures Tcl_SetVar and Tcl_SetVar2 may be used to set the value of a Tcl variable. The procedures Tcl_GetVar and Tcl_GetVar2 may be used to read the value of a Tcl variable. The procedures Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a Tcl variable.

In most cases, a variable is referred to by a simple name, like "varName". If the variable is an array element, then the name is specified in two parts: the array name (e.g., "myArray") and the element name (e.g., "elem1"). In this case, Tcl_SetVar and Tcl_GetVar are not sufficient, and Tcl_SetVar2 and Tcl_GetVar2 must be used instead, with name1 being the array name and name2 being the element name.

The flags argument controls the behavior of these procedures. The flags TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG have the same meaning for all procedures.

If TCL_GLOBAL_ONLY is specified, the variable is looked up in the global scope. Otherwise, it is looked up in the current scope unless it is qualified with a scope qualifier like ::. If an error occurs, then TCL_ERROR is returned by the set and unset procedures, and NULL is returned by the get procedures. If the operation is successful, then TCL_OK is returned by the set and unset procedures.

If the flag TCL_APPEND_VALUE is given to Tcl_SetVar or Tcl_SetVar2, the value is appended to the existing value of the variable, rather than replacing it. The variable must already exist and have a scalar value. The result is the concatenation of the old value and the new value. Note that this is a string concatenation; if the variable contains a list, this operation is not meaningful.

If the flag TCL_LIST_ELEMENT is given to Tcl_SetVar or Tcl_SetVar2, the value is appended as a new element to the list stored in the variable. The variable must already exist and its value must be a list (or an empty string, which is treated as an empty list). The new element is added to the end of the list. The variable's new value will be the old list with the new element added. This flag can only be used for scalar variables, not array elements. If the variable doesn't exist, it will be created as a list containing just the new element.

If the flag TCL_LIST_ONLY is given to Tcl_SetVar or Tcl_SetVar2, the value is appended as a new element to the list stored in the variable. The variable must already exist and its value must be a list (or an empty string, which is treated as an empty list). The new element is added to the end of the list. The variable's new value will be the old list with the new element added. This flag can only be used for scalar variables, not array elements. If the variable doesn't exist, it will be created as a list containing just the new element. This flag is similar to TCL_LIST_ELEMENT, but it prevents list elements from being automatically created if the variable doesn't exist or is not a list. This flag can only be used with Tcl_SetVar and Tcl_SetVar2.

Note that when appending to a list, the value being appended is treated as a single element. If the value itself is a list, it will be nested within the existing list. For example, if a variable contains the list {a b} and you append {c d} to it using TCL_LIST_ELEMENT, the variable will then contain {a b {c d}}.

Tcl_GetVar and Tcl_GetVar2 return the current value of a variable. The arguments to these procedures are treated in the same way as the arguments to Tcl_SetVar and Tcl_SetVar2. Under normal circumstances, the return value is a pointer to the variable's value (which is stored in Tcl's variable structure and will not change before the next call to Tcl_SetVar or Tcl_SetVar2). Tcl_GetVar and Tcl_GetVar2 use the flag bits TCL_GLOBAL_ONLY and TCL_LEAVE_ERR_MSG, both of which have the same meaning as for Tcl_SetVar. If an error occurs in reading the variable (e.g. the variable does not exist or an array element is specified for a scalar variable), then NULL is returned.

Tcl_UnsetVar and Tcl_UnsetVar2 may be used to remove a variable, so that future calls to Tcl_GetVar or Tcl_GetVar2 for the variable will return an error. The arguments to these procedures are treated in the same way as the arguments to Tcl_GetVar and Tcl_GetVar2. If the variable is successfully removed then TCL_OK is returned. If the variable cannot be removed because it does not exist then TCL_ERROR is returned. If an array element is specified, the given element is removed but the array remains. If an array name is specified without an index, then the entire array is removed.
