Tcl_GetMathFuncInfo(3)

الحزمة: tcl

التراخيص: TCL

Tcl_CreateMathFunc(3) إجراءات مكتبة Tcl Tcl_CreateMathFunc(3)

الاسم

Tcl_CreateMathFunc، Tcl_GetMathFuncInfo، Tcl_ListMathFuncs - تعريف، استعلام، وتعداد وظائف الرياضيات للتعبيرات

إشعار بالاستهلاك المستقبلي

أصبحت وظائف Tcl_CreateMathFunc و Tcl_GetMathFuncInfo قديمة إلى حد ما بسبب القدرة على إنشاء وظائف للتعبيرات عن طريق وضع أوامر في مساحة الاسم tcl::mathfunc، كما هو موضح في صفحة دليل mathfunc؛ لا يُتوقع صيانة واجهة برمجة التطبيقات الموصوفة في هذه الصفحة إلى أجل غير مسمى.

الملخص

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

الوصف

يسمح Tcl باستخدام عدد من الدوال الرياضية في التعبيرات، مثل sin و cos و hypot. يتم تمثيل هذه الدوال بواسطة أوامر في مساحة الاسم tcl::mathfunc. الدالة Tcl_CreateMathFunc هي طريقة مهملة للتطبيقات لإضافة دوال إضافية إلى تلك التي يوفرها Tcl بالفعل أو لاستبدال الدوال الموجودة. لا ينبغي استخدامها بواسطة التطبيقات الجديدة، والتي يجب عليها إنشاء دوال رياضية باستخدام Tcl_CreateObjCommand لإنشاء أمر في مساحة الاسم tcl::mathfunc.

في واجهة Tcl_CreateMathFunc، Name هو اسم الدالة كما ستظهر في التعبيرات. إذا كان name غير موجود بالفعل في مساحة الاسم ::tcl::mathfunc، يتم إنشاء أمر جديد في تلك المساحة. إذا كان name موجودًا، يتم استبدال الدالة الموجودة. NumArgs و argTypes يصفان معاملات الدالة. يجب أن يكون كل إدخال في مصفوفة argTypes واحدًا من TCL_INT، TCL_DOUBLE، TCL_WIDE_INT، أو TCL_EITHER للإشارة إلى ما إذا كان المعامل المقابل يجب أن يكون عددًا صحيحًا، قيمة فاصلة عائمة دقيقة، عدد صحيح عريض (64 بت)، أو أي نوع.

في كل مرة يتم فيها استدعاء الدالة في تعبير، سيقوم Tcl باستدعاء proc. يجب أن يكون لدى Proc معاملات ونتيجة تتطابق مع النوع Tcl_MathProc:

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

عند استدعاء proc، ستكون معاملات clientData و interp هي نفسها التي تم تمريرها إلى Tcl_CreateMathFunc. سيشير Args إلى مصفوفة من هياكل Tcl_Value بحجم numArgs، والتي تصف المعاملات الفعلية للدالة:

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

يشير الحقل type إلى نوع المعامل وهو واحد من TCL_INT، TCL_DOUBLE أو TCL_WIDE_INT. سيطابق قيمة argTypes المحددة للدالة ما لم تكن قيمة argTypes هي TCL_EITHER. يقوم Tcl بتحويل المعامل المقدم في التعبير إلى النوع المطلوب في argTypes، إذا كان ذلك ضروريًا. اعتمادًا على قيمة الحقل type، سيحتوي الحقل intValue أو doubleValue أو wideValue على القيمة الفعلية للمعامل.

يجب على Proc حساب نتيجته وتخزينها إما كعدد صحيح في resultPtr->intValue أو كقيمة فاصلة عائمة في resultPtr->doubleValue. يجب عليه أيضًا تعيين resultPtr->type إلى واحد من TCL_INT، TCL_DOUBLE أو TCL_WIDE_INT للإشارة إلى القيمة التي تم تعيينها. في الظروف العادية، يجب أن تعيد proc القيمة TCL_OK. إذا حدث خطأ أثناء تنفيذ الدالة، يجب أن تعيد proc القيمة TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر.

تقوم Tcl_GetMathFuncInfo باسترداد القيم المرتبطة بالدالة name التي تم تمريرها إلى استدعاء سابق لـ Tcl_CreateMathFunc. عادةً ما يكون رمز الإرجاع هو TCL_OK ولكن إذا كانت الدالة المسماة غير موجودة، فسيتم إرجاع TCL_ERROR وسيتم وضع رسالة خطأ في نتيجة المفسر.

إذا لم يحدث خطأ، فإن مرجع المصفوفة الذي تم وضعه في المتغير المشار إليه بواسطة argTypesPtr تم تخصيصه حديثًا، ويجب تحريره عن طريق تمريره إلى Tcl_Free. بعض الدوال (المجموعة القياسية المنفذة في النواة، وتلك المعرفة بوضع أوامر في مساحة الاسم tcl::mathfunc) ليس لديها معلومات عن أنواع المعاملات؛ يؤدي محاولة استرداد القيم لها إلى تخزين NULL في المتغير المشار إليه بواسطة procPtr ولن يتم تعديل المتغير المشار إليه بواسطة clientDataPtr. سيحتوي المتغير المشار إليه بواسطة numArgsPointer على -1، ولن يتم تخزين أي أنواع معاملات في المتغير المشار إليه بواسطة argTypesPointer.

تعيد Tcl_ListMathFuncs قيمة Tcl تحتوي على قائمة بجميع الدوال الرياضية المعرفة في المفسر التي يتطابق اسمها مع pattern. قيمة الإرجاع لها عدد مراجع يساوي صفر.

Tcl_GetMathFuncInfo(3)

NAME

Tcl_GetMathFuncInfo - retrieve information about Tcl math functions

SYNOPSIS

#include <tcl.h>

int
Tcl_GetMathFuncInfo(interp, name, funcPtrPtr, typePtr)
Tcl_Interp *interp;
const char *name;
Tcl_MathFunc **funcPtrPtr;
int *typePtr;

DESCRIPTION

The function Tcl_GetMathFuncInfo retrieves information about a Tcl math function. The function is identified by its name. The information is returned in the variables pointed to by funcPtrPtr and typePtr.

If the math function with the given name is found, Tcl_GetMathFuncInfo sets *funcPtrPtr to a pointer to the Tcl_MathFunc structure representing the function and sets *typePtr to the type of the function. The function type is one of the following values:

  • TCL_MATH_FUNC_BUILTIN: The function is a built-in Tcl math function.
  • TCL_MATH_FUNC_USER: The function is a user-defined math function.

If the function is not found, Tcl_GetMathFuncInfo returns TCL_ERROR and sets the interp's result to an error message. Otherwise, it returns TCL_OK.
