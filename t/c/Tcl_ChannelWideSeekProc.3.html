التراخيص: TCL

NAME

Tcl_ChannelWideSeekProc -procédure pour rechercher les canaux

SYNOPSIS

#include <tcl.h>

int
Tcl_ChannelWideSeekProc(
    Tcl_Channel channel,
    Tcl_WideInt offset,
    int seekMode)

ARGUMENTS

in
channel — Le canal à rechercher.
in
offset — Le nombre d'octets à rechercher.
in
seekMode — Le mode de recherche. Peut être SEEK_SET, SEEK_CUR, ou SEEK_END.

DESCRIPTION

La procédure Tcl_ChannelWideSeekProc déplace la position de lecture/écriture du canal channel.

Les modes de recherche sont définis comme suit :

SEEK_SET
La nouvelle position est offset octets depuis le début du fichier.
SEEK_CUR
La nouvelle position est offset octets depuis la position actuelle.
SEEK_END
La nouvelle position est offset octets depuis la fin du fichier.

La procédure renvoie la nouvelle position du canal ou -1 en cas d'erreur.

TCL_CHANNELTYPE

Cette procédure est utilisée par les types de canaux personnalisés pour implémenter la fonctionnalité de recherche. Le champ seekProc de la structure Tcl_ChannelType doit pointer vers une procédure qui implémente cette fonctionnalité.

TCL_BADCHANNELOPTION

Si le canal ne supporte pas la recherche, cette procédure générera une erreur TCL_BADCHANNELOPTION.

OLD CHANNEL TYPES

Dans les anciennes versions de Tcl, il existait une procédure Tcl_ChannelSeekProc qui ne prenait pas en charge les décalages de 64 bits. Il est recommandé d'utiliser Tcl_ChannelWideSeekProc pour une compatibilité avec les fichiers volumineux.

SEE ALSO

Tcl_CreateChannel, Tcl_GetChannelType, Tcl_RegisterChannel

KEYWORDS

bloqueante, driver de canal, registro de canal, tipo de canal, no bloqueante
