tcl_version(n)

الحزمة: tcl

التراخيص: TCL

NAME

tcl_traceExec, tcl_wordchars, tcl_nonwordchars, tcl_version, argc, argv, argv0, tcl_interactive — Tcl global variables

DESCRIPTION

tcl_traceExec
يمكن تعيين قيمة هذا المتغير للتحكم في مقدار معلومات التتبع التي يتم عرضها أثناء تنفيذ الكود الثنائي. افتراضيًا، قيمة tcl_traceExec هي صفر ولا يتم عرض أي معلومات. يؤدي تعيين tcl_traceExec إلى 1 إلى إنشاء تتبع من سطر واحد في stdout عند كل استدعاء لإجراء Tcl. يؤدي تعيينه إلى 2 إلى إنشاء سطر إخراج في كل مرة يتم فيها استدعاء أي أمر Tcl يحتوي على اسم الأمر وحججه. يؤدي تعيينه إلى 3 إلى إنشاء تتبع مفصل يوضح نتيجة تنفيذ كل تعليمة من تعليمات الكود الثنائي. لاحظ أنه عندما تكون قيمة tcl_traceExec هي 2 أو 3، فإن الأوامر مثل set و incr التي تم استبدالها بالكامل بسلسلة من تعليمات الكود الثنائي لا يتم عرضها. يعد تعيين هذا المتغير مفيدًا في تعقب المشاكل المشتبه بها في مترجم الكود الثنائي والمفسر.
هذا المتغير والوظيفة موجودان فقط إذا تم تعريف TCL_COMPILE_DEBUG أثناء تجميع Tcl.
tcl_wordchars
قيمة هذا المتغير هي تعبير عادي يمكن تعيينه للتحكم في الأحرف التي تعتبر "كلمة"، لأمثلة مثل تحديد كلمة بالنقر المزدوج في نص في Tk. يعتمد ذلك على النظام الأساسي. في Windows، القيمة الافتراضية هي \S، مما يعني أي شيء باستثناء حرف مسافة Unicode. بخلاف ذلك، القيمة الافتراضية هي \w، وهي أي حرف كلمة Unicode (رقم، حرف، أو شرطة سفلية).
tcl_nonwordchars
قيمة هذا المتغير هي تعبير عادي يمكن تعيينه للتحكم في الأحرف التي تعتبر "غير كلمة"، لأمثلة مثل تحديد كلمة بالنقر المزدوج في نص في Tk. يعتمد ذلك على النظام الأساسي. في Windows، القيمة الافتراضية هي \s، مما يعني أي حرف مسافة Unicode. بخلاف ذلك، القيمة الافتراضية هي \W، وهي أي شيء باستثناء حرف كلمة Unicode (رقم، حرف، أو شرطة سفلية).
tcl_version
عند إنشاء مفسر، يقوم Tcl بتهيئة هذا المتغير ليحتوي على رقم الإصدار لهذا الإصدار من Tcl بالشكل x.y. تمثل التغييرات في x تغييرات كبيرة مع تعارضات محتملة، وتمثل التغييرات في y تحسينات طفيفة وإصلاحات للأخطاء التي تحافظ على التوافق الخلفي. يتم إرجاع قيمة هذا المتغير بواسطة الأمر info tclversion.

OTHER GLOBAL VARIABLES

لا يُضمن وجود المتغيرات التالية إلا في الملفات التنفيذية tclsh و wish؛ لا يقوم مكتب Tcl بتعريفها بنفسه ولكن العديد من بيئات Tcl تقوم بذلك.

argc
عدد الحجج لـ tclsh أو wish.
argv
قائمة Tcl بالحجج لـ tclsh أو wish.
argv0
البرنامج النصي الذي بدأ tclsh أو wish تنفيذه (إذا تم تحديده) أو بخلاف ذلك الاسم الذي تم به استدعاء tclsh أو wish.
tcl_interactive
يحتوي على 1 إذا كان tclsh أو wish يعمل بشكل تفاعلي (لم يتم تحديد برنامج نصي وكان الإدخال القياسي جهازًا شبيهًا بالطرفية)، 0 بخلاف ذلك.

EXAMPLES

لإضافة دليل إلى مجموعة المواقع التي يتم البحث فيها بواسطة package require، على سبيل المثال، بسبب بعض الحزم الخاصة بالتطبيق المستخدمة، يجب تحديث المتغير auto_path:

lappend ::auto_path [file join [pwd] "theLibDir"]

طريقة بسيطة، وإن لم تكن قوية جدًا، للتعامل مع حجج سطر الأوامر بالشكل " -foo 1 -bar 2 " هي تحميلها في مصفوفة بعد تحميل الإعدادات الافتراضية أولاً:

array set arguments {-foo 0 -bar 0 -grill 0}
array set arguments $::argv
puts "foo is $arguments(-foo)"
puts "bar is $arguments(-bar)"
puts "grill is $arguments(-grill)"

يمكن استخدام المتغير العام argv0 (بالاقتران مع الأمر info script) لتحديد ما إذا كان البرنامج النصي الحالي يتم تنفيذه كبرنامج نصي رئيسي أو تم تحميله كمكتبة. هذا مفيد لأنه يسمح باستخدام برنامج نصي واحد كمكتبة وعرض توضيحي لهذه المكتبة:

if {$::argv0 eq [info script]} {
    # running as: tclsh example.tcl
} else {
    package provide Example 1.0
}
