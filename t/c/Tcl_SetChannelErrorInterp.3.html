الاسم

Tcl_SetChannelError, Tcl_SetChannelErrorInterp, Tcl_GetChannelError, Tcl_GetChannelErrorInterp - وظائف لإنشاء/اعتراض أخطاء Tcl بواسطة برامج تشغيل القنوات.

الملخص

#include <tcl.h>

void
Tcl_SetChannelError(chan, msg)

void
Tcl_SetChannelErrorInterp(interp, msg)

void
Tcl_GetChannelError(chan, msgPtr)

void
Tcl_GetChannelErrorInterp(interp, msgPtr)

الوسائط

Tcl_Channel chan (in)
يشير إلى قناة Tcl التي يتم الوصول إلى منطقة التجاوز الخاصة بها.
Tcl_Interp* interp (in)
يشير إلى مترجم Tcl الذي يتم الوصول إلى منطقة التجاوز الخاصة به.
Tcl_Obj* msg (in)
رسالة خطأ موضوعة في منطقة تجاوز. قائمة من الخيارات والقيم، تليها رسالة نصية. كل من رسالة ومعلومات الخيار/القيمة اختياريان.
Tcl_Obj** msgPtr (out)
مرجع إلى مكان يمكن تخزين رسالة الخطأ المخزنة في منطقة التجاوز فيه.

الوصف

التعريف الحالي لبرنامج تشغيل قناة Tcl لا يسمح بإرجاع رسائل خطأ عشوائية، باستثناء تعيين واسترداد خيارات القناة. جميع الوظائف الأخرى مقيدة برموز خطأ POSIX.

تتجاوز الوظائف الموصوفة هنا هذا القيد. يمكن لبرامج تشغيل القنوات استخدام Tcl_SetChannelError و Tcl_SetChannelErrorInterp لوضع رسائل خطأ عشوائية في مناطق تجاوز محددة للقنوات والمترجمات. ويتم استخدام القدرة العامة للإدخال/الإخراج بواسطة Tcl_GetChannelError و Tcl_GetChannelErrorInterp للبحث عن رسائل في مناطق التجاوز وتنظيم إرجاعها كأخطاء. سيتم استخدام رموز خطأ POSIX التي تم تعيينها بواسطة برنامج التشغيل الآن فقط إذا لم تكن هناك رسائل.

Tcl_SetChannelError تخزن معلومات الخطأ في منطقة التجاوز للقناة المحددة. يزداد عدد المراجع للقيمة msg بواحد. سيتم مسح المعلومات المخزنة مسبقًا، وتحرير مرجع القناة. لا يمكن أن يكون مرجع القناة NULL.

Tcl_SetChannelErrorInterp تخزن معلومات الخطأ في منطقة التجاوز للمترجم المحدد. يزداد عدد المراجع للقيمة msg بواحد. سيتم مسح المعلومات المخزنة مسبقًا، وتحرير مرجع المترجم. لا يمكن أن يكون مرجع المترجم NULL.

Tcl_GetChannelError تضع رسالة الخطأ المخزنة في منطقة التجاوز للقناة المحددة في msgPtr، أو NULL؛ وتعيد تعيين التجاوز، أي بعد استدعاء، ستعيد جميع الاستدعاءات اللاحقة NULL، حتى يحدث استدعاء لـ Tcl_SetChannelError مع رسالة غير NULL. لا يمكن أن يكون msgPtr NULL. لا يتم المساس بعداد المراجع للرسالة. مرجع القناة السابق الآن هو مرجع استدعاء الوظيفة ومسؤوليته تحرير هذا المرجع عند الانتهاء من القيمة.

Tcl_GetChannelErrorInterp تضع رسالة الخطأ المخزنة في منطقة التجاوز للمترجم المحدد في msgPtr، أو NULL؛ وتعيد تعيين التجاوز، أي بعد استدعاء، ستعيد جميع الاستدعاءات اللاحقة NULL، حتى يحدث استدعاء لـ Tcl_SetChannelErrorInterp مع رسالة غير NULL. لا يمكن أن يكون msgPtr NULL. لا يتم المساس بعداد المراجع للرسالة. مرجع المترجم السابق الآن هو مرجع استدعاء الوظيفة ومسؤوليته تحرير هذا المرجع عند الانتهاء من القيمة.

الوظائف من برنامج تشغيل القناة التي يمكنها استخدام أي من وظائف واجهة برمجة التطبيقات العامة للقناة مدرجة أدناه، بالإضافة إلى الوظائف من واجهة برمجة التطبيقات العامة للقناة التي يمكنها ترك رسائل في مناطق التجاوز.

Tcl_SetChannelErrorInterp

Tcl_SetChannelErrorInterp – sets the error code and message for a channel.

SYNTAX

#include <tcl.h>
void
Tcl_SetChannelErrorInterp(
    Tcl_Interp *interp,
    const char *code,
    const char *msg
);

ARGUMENTS

interp (in)
Interpreter to associate the error with.
code (in)
The error code. If NULL, the error code from the previous channel operation is used.
msg (in)
The error message. If NULL, the error message from the previous channel operation is used.

DESCRIPTION

The Tcl_SetChannelErrorInterp function is used to set the error code and message for the interpreter interp. This is typically used within channel drivers to report errors that occurred during channel operations.

The code and msg arguments specify the error code and message, respectively. If either argument is NULL, the corresponding value from the previous channel operation is used. This allows channel drivers to propagate errors from underlying system calls or other Tcl channel operations.

The error code is typically a short string representing a standardized error condition (e.g., "EACCES", "EINVAL"). The error message provides a more detailed description of the error.

After calling Tcl_SetChannelErrorInterp, subsequent Tcl commands that operate on this interpreter will see the set error code and message. This is usually done in conjunction with returning TCL_ERROR from a Tcl command procedure to signal that an error has occurred.

EXAMPLE

Consider a custom channel driver that attempts to open a file that does not exist. If the underlying system call returns an error, the driver could use Tcl_SetChannelErrorInterp to set the Tcl error information:

    /* Assume 'errorCodePtr' and 'errorMsgPtr' are populated from system call */
    if (errorCodePtr != NULL && errorMsgPtr != NULL) {
        Tcl_SetChannelErrorInterp(interp, *errorCodePtr, *errorMsgPtr);
        return TCL_ERROR;
    }

Tcl_SetChannelErrorInterp – يحدد رمز الخطأ ورسالته لقناة.

الصيغة

#include <tcl.h>
void
Tcl_SetChannelErrorInterp(
    Tcl_Interp *interp,
    const char *code,
    const char *msg
);

المعاملات

interp (في)
المفسر لربط الخطأ به.
code (في)
رمز الخطأ. إذا كان NULL، يتم استخدام رمز الخطأ من عملية القناة السابقة.
msg (في)
رسالة الخطأ. إذا كانت NULL، يتم استخدام رسالة الخطأ من عملية القناة السابقة.

الوصف

تُستخدم الدالة Tcl_SetChannelErrorInterp لتحديد رمز الخطأ ورسالته للمفسر interp. يُستخدم هذا عادةً داخل برامج تشغيل القنوات للإبلاغ عن الأخطاء التي حدثت أثناء عمليات القناة.

يحدد المعاملان code و msg رمز الخطأ والرسالة على التوالي. إذا كان أي من المعاملين NULL، يتم استخدام القيمة المقابلة من عملية القناة السابقة. هذا يسمح لبرامج تشغيل القنوات بنقل الأخطاء من استدعاءات النظام الأساسية أو عمليات قنوات Tcl الأخرى.

عادةً ما يكون رمز الخطأ عبارة عن سلسلة نصية قصيرة تمثل حالة خطأ موحدة (مثل "EACCES"، "EINVAL"). توفر رسالة الخطأ وصفًا أكثر تفصيلاً للخطأ.

بعد استدعاء Tcl_SetChannelErrorInterp، سترى أوامر Tcl اللاحقة التي تعمل على هذا المفسر رمز الخطأ والرسالة المحددين. يتم ذلك عادةً بالاقتران مع إرجاع TCL_ERROR من إجراء أمر Tcl للإشارة إلى حدوث خطأ.

مثال

ضع في اعتبارك برنامج تشغيل قناة مخصص يحاول فتح ملف غير موجود. إذا أعادت استدعاء النظام خطأ، فيمكن لبرنامج التشغيل استخدام Tcl_SetChannelErrorInterp لتحديد معلومات خطأ Tcl:

    /* افترض أن 'errorCodePtr' و 'errorMsgPtr' مملوءان من استدعاء النظام */
    if (errorCodePtr != NULL && errorMsgPtr != NULL) {
        Tcl_SetChannelErrorInterp(interp, *errorCodePtr, *errorMsgPtr);
        return TCL_ERROR;
    }
