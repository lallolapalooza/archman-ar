Tcl_IsEnsemble(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_IsEnsemble, Tcl_GetEnsembleUnknownHandler, Tcl_SetEnsembleUnknownHandler, Tcl_GetEnsembleNamespace - manipulate ensembles

SYNOPSIS

#include <tcl.h>

int
Tcl_IsEnsemble(token)
    Tcl_Command token;
int
Tcl_GetEnsembleUnknownHandler(token, handlerPtr)
    Tcl_Command token;
    Tcl_EnsembleUnknownHandler *handlerPtr;
int
Tcl_SetEnsembleUnknownHandler(token, handler)
    Tcl_Command token;
    Tcl_EnsembleUnknownHandler handler;
int
Tcl_GetEnsembleNamespace(token, nsPtr)
    Tcl_Command token;
    Tcl_Namespace **nsPtr;

ARGUMENTS

Tcl_Command token
Token for a command.
Tcl_EnsembleUnknownHandler *handlerPtr
Address to store the unknown handler for the ensemble.
Tcl_EnsembleUnknownHandler handler
The new unknown handler for the ensemble.
Tcl_Namespace **nsPtr
Address to store the namespace for the ensemble.

DESCRIPTION

Ensembles are a mechanism for grouping related commands. For example, the standard Tcl namespace command is implemented as an ensemble. The ensemble command itself is a dispatcher that, based on the first word of the command line, dispatches to one of the subcommands defined by the ensemble. The subcommands may themselves be ensembles, allowing for nested ensembles.

The ensemble command is created using Tcl_CreateEnsemble. This function takes a list of subcommands, each of which is defined by a name and a Tcl script to execute. The Tcl_Command token returned by Tcl_CreateEnsemble can be used to query and modify the ensemble's properties.

Tcl_IsEnsemble tests whether the command referred to by token is an ensemble. It returns 1 if it is an ensemble, and 0 otherwise.

Tcl_GetEnsembleUnknownHandler retrieves the unknown handler for the ensemble referred to by token. If the ensemble has no unknown handler, the handler is set to NULL. The handler is stored in the location pointed to by handlerPtr. The function returns TCL_OK if the token refers to an ensemble, and TCL_ERROR otherwise.

Tcl_SetEnsembleUnknownHandler sets the unknown handler for the ensemble referred to by token to handler. If handler is NULL, the ensemble will use the default behavior of generating an error message when an unknown subcommand is encountered. The function returns TCL_OK if the token refers to an ensemble, and TCL_ERROR otherwise.

Tcl_GetEnsembleNamespace retrieves the namespace to which the ensemble referred to by token is bound. The namespace is stored in the location pointed to by nsPtr. The function returns TCL_OK if the token refers to an ensemble, and TCL_ERROR otherwise.

PROPERTIES

unknownhandler namespace
This property specifies the handler to be called when an unknown subcommand is encountered. The handler is a Tcl script that takes as arguments the ensemble name and the unknown subcommand. If this property is NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.
bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
