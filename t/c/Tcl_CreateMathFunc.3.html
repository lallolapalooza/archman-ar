Tcl_CreateMathFunc(3)

الحزمة: tcl

Tcl_CreateMathFunc(3) إجراءات مكتبة Tcl Tcl_CreateMathFunc(3)

الاسم

Tcl_CreateMathFunc, Tcl_GetMathFuncInfo, Tcl_ListMathFuncs — تحديد، الاستعلام عن، وسرد الدوال الرياضية للتعبيرات

إشعار إيقاف الاستخدام المحتمل

تم إيقاف استخدام إجراءات Tcl_CreateMathFunc و Tcl_GetMathFuncInfo قليلاً لصالح القدرة على إنشاء دوال للتعبيرات عن طريق وضع أوامر في مساحة الاسم tcl::mathfunc، كما هو موضح في صفحة الدليل mathfunc؛ واجهة برمجة التطبيقات الموضحة في هذه الصفحة لن يتم صيانتها إلى أجل غير مسمى.

الملخص

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,

                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

المعاملات

Tcl_Interp *interp (in)
المفسر الذي سيتم فيه تعريف الدالة الجديدة.
const char *name (in)
اسم الدالة الجديدة.
int numArgs (in)
عدد معاملات الدالة الجديدة؛ وهو أيضًا حجم مصفوفة argTypes.
Tcl_ValueType *argTypes (in)
مؤشر إلى مصفوفة تحدد أنواع المعاملات المسموح بها لكل معامل للدالة.
Tcl_MathProc *proc (in)
الإجراء الذي ينفذ الدالة.
ClientData clientData (in)
قيمة عشوائية من كلمة واحدة سيتم تمريرها إلى proc عند استدعائها.
int *numArgsPtr (out)
مؤشر إلى متغير سيحتوي على عدد معاملات الدالة.
Tcl_ValueType **argTypesPtr (out)
مؤشر إلى متغير سيحتوي على مؤشر إلى مصفوفة تحدد أنواع المعاملات المسموح بها لكل معامل للدالة، والتي ستحتاج إلى تحريرها باستخدام Tcl_Free.
Tcl_MathProc **procPtr (out)
مؤشر إلى متغير سيحتوي على مؤشر إلى رمز تنفيذ الدالة (أو NULL إذا كانت الدالة منفذة مباشرة في bytecode).
ClientData *clientDataPtr (out)
مؤشر إلى متغير سيحتوي على معامل clientData الذي تم تمريره إلى Tcl_CreateMathFunc عند إنشاء الدالة إذا لم تكن الدالة منفذة مباشرة في bytecode.
const char *pattern (in)
نمط للبحث عن أسماء الدوال، يتم تمريره إلى Tcl_StringMatch، أو NULL لعدم تطبيق أي فلتر.

الوصف

يسمح Tcl بسلسلة من الدوال الرياضية للاستخدام في التعبيرات، مثل sin و cos و hypot. يتم تمثيل هذه الدوال كأوامر في مساحة الاسم tcl::mathfunc. الدالة Tcl_CreateMathFunc هي طريقة قديمة لإضافة دوال جديدة إلى تلك التي يوفرها Tcl بالفعل أو لاستبدال الدوال الموجودة. يجب تجنبها في التطبيقات الجديدة، والتي يجب أن تنشئ دوال رياضية باستخدام Tcl_CreateObjCommand لإنشاء أمر في مساحة الاسم tcl::mathfunc.

في واجهة Tcl_CreateMathFunc، الاسم هو اسم الدالة كما ستظهر في التعبيرات. إذا كان الاسم غير موجود بالفعل في مساحة الاسم ::tcl::mathfunc، فسيتم إنشاء دالة جديدة في تلك المساحة. إذا كان الاسم موجودًا، فسيتم استبدال الدالة الموجودة. تصف numArgs و argTypes معاملات الدالة. يجب أن يكون كل إدخال في مصفوفة argTypes إما TCL_INT أو TCL_DOUBLE أو TCL_WIDE_INT أو TCL_EITHER للإشارة إلى ما إذا كان المعامل المقابل يجب أن يكون عددًا صحيحًا، أو قيمة عشرية مزدوجة، أو عددًا صحيحًا بحجم 64 بت، أو أي شيء، على التوالي.

عند استدعاء الدالة في تعبير، يستدعي Tcl الإجراء proc. يجب أن يتطابق proc مع المعاملات والنتيجة مع نوع Tcl_MathProc:

typedef int Tcl_MathProc(
                                        ClientData clientData,
                                        Tcl_Interp *interp,
                                        Tcl_Value *args,
                                        Tcl_Value *resultPtr);

عند استدعاء proc، سيكون clientData و interp هما نفس القيم التي تم تمريرها إلى Tcl_CreateMathFunc. ستشير args إلى مصفوفة من numArgs هياكل Tcl_Value، والتي تصف معاملات الدالة الفعلية:

typedef struct Tcl_Value {
                                        Tcl_ValueType type;
                                        long intValue;
                                        double doubleValue;
                                        Tcl_WideInt wideValue;
                                    } Tcl_Value;

يشير الحقل type إلى نوع المعامل وهو إما TCL_INT أو TCL_DOUBLE أو TCL_WIDE_INT. يتوافق الحقل type مع قيمة argTypes المحددة للدالة، ما لم تكن قيمة argTypes هي TCL_EITHER. يقوم Tcl بتحويل الوسيط المقدم في التعبير إلى النوع المطلوب في argTypes، إذا لزم الأمر. اعتمادًا على قيمة الحقل type، سيحتوي الحقل intValue أو doubleValue أو wideValue على القيمة الفعلية للمعامل.

يجب على proc حساب نتيجته وتخزينها في resultPtr كعدد صحيح في intValue أو كقيمة عشرية في doubleValue. يجب عليه أيضًا تعيين الحقل resultPtr->type إلى TCL_INT أو TCL_DOUBLE أو TCL_WIDE_INT للإشارة إلى القيمة التي تم تعيينها. في الظروف العادية، يجب أن ترجع proc TCL_OK. إذا حدث خطأ أثناء تنفيذ الدالة، يجب أن ترجع proc TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر.

تسترد Tcl_GetMathFuncInfo القيم المرتبطة بالدالة name التي تم تمريرها إلى استدعاء سابق لـ Tcl_CreateMathFunc. عادةً، يكون رمز الإرجاع هو TCL_OK، ولكن إذا كانت الدالة name غير موجودة، يتم إرجاع TCL_ERROR ويتم وضع رسالة خطأ في نتيجة المفسر.

إذا لم يحدث خطأ، فإن القيمة المشار إليها في المتغير الذي يشير إليه argTypesPtr جديدة ويجب تحريرها بتمريرها إلى Tcl_Free. بعض الدوال (المجموعة القياسية المنفذة في النواة وتلك المعرفة بوضع أوامر في مساحة الاسم tcl::mathfunc) ليس لديها معلومات حول أنواع المعاملات؛ محاولة الحصول على قيم منها تؤدي إلى NULL في القيمة التي يشير إليها procPtr ولن يتم تعديل القيمة المشار إليها بواسطة clientDataPtr. ستحتوي القيمة المشار إليها بواسطة numArgsPointer على -1، ولن يتم تخزين أي أنواع معاملات في القيمة المشار إليها بواسطة argTypesPointer.

ترجع Tcl_ListMathFuncs قيمة Tcl تحتوي على قائمة بجميع الدوال الرياضية المعرفة في المفسر والتي يتطابق اسمها مع النمط. القيمة المرجعة لها عداد مرجعي صفر.

Tcl_CreateMathFunc(3)

Tcl_CreateMathFunc -- create a new procedure that can be called from Tcl math expressions.

SYNOPSIS

#include <tcl.h>

int
Tcl_CreateMathFunc(
    Tcl_Interp *interp,
    const char *name,
    Tcl_MathProc *proc,
    ClientData clientData
)

DESCRIPTION

The function Tcl_CreateMathFunc is used to add a new mathematical function to the Tcl interpreter interp that can be called from Tcl math expressions. The function will be available in Tcl scripts under the name name . The proc argument points to a C procedure that implements the mathematical function. The proc should have the following signature: 

typedef int (*Tcl_MathProc)(ClientData clientData, Tcl_Interp *interp, int objc, Tcl_Obj *const objv[]);

The clientData argument is arbitrary user-defined data that is passed to the C procedure. The interp argument is the interpreter in which the function is being created. The objc argument is the number of arguments passed to the math function. The objv argument is an array of Tcl objects representing the arguments.

The C procedure should attempt to convert its arguments to numeric types (doubles, integers, etc.) as appropriate for the function being implemented. If the arguments are not valid numbers, or if the function encounters an error, it should set an error message in the interpreter using Tcl_SetObjResult and return NULL . If the function succeeds, it should return a Tcl object representing the result.

The function Tcl_CreateMathFunc returns TCL_OK if the function was created successfully, and TCL_ERROR if an error occurred (e.g., if name already exists).
