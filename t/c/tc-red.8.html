NAME

tc-red - Random Early Detection (RED) queueing discipline

SYNOPSIS

tc qdisc { add | change | replace } ... red [ limit BYTES ] [ min BYTES ] [ max BYTES ] [ ptcp PROB ] [ athresh BYTES ] [ wred ] [ adaptive ] [ dp-model MODEL ] [ hard-drop ] [ backlog BYTES ] [ ecn | no-ecn ] [ bytemode | packetmode ] [ forced-pinky ] [ quantum BYTES ] [ dequeue-ratio RATIO ] [ priority-offset OFFSET ] [ child-queue-size SIZE ] [ parent-queue-size SIZE ] [ queue-size SIZE ] [ buffer-growth GROWTH ] [ target TIME ] [ interval TIME ] [ avpkt BYTES ] [ ewma-log BYTES ] [ weights WEIGHTS ] dev DEVICE

DESCRIPTION

The RED (Random Early Detection) queueing discipline is a congestion control algorithm designed to avoid the global synchronization problem that can occur with tail-drop routers. RED works by probabilistically dropping packets when the average queue length exceeds certain thresholds. This allows end hosts to detect congestion early and reduce their sending rates, preventing the queue from becoming full and leading to synchronized packet drops.

The RED algorithm maintains an estimate of the average queue length. When a packet arrives, the algorithm checks the current average queue length against two thresholds: min and max.

If the average queue length is below min, the packet is accepted.

If the average queue length is above max, the packet is dropped.

If the average queue length is between min and max, the packet is dropped with a probability that increases linearly with the average queue length.

The RED algorithm has several parameters that can be tuned to optimize its performance:

limit BYTES
The maximum queue size in bytes.
min BYTES
The minimum average queue size threshold in bytes.
max BYTES
The maximum average queue size threshold in bytes.
ptcp PROB
The probability exponent for calculating the packet drop probability.
athresh BYTES
The average queue size threshold for calculating the packet drop probability.
wred
Enables Weighted RED (WRED), which allows different drop probabilities for different traffic classes.
adaptive
Enables adaptive RED, which dynamically adjusts the RED parameters based on network conditions.
dp-model MODEL
Specifies the drop probability model to use. Possible values are basic, linear, and exp.
hard-drop
Enables hard drop, which means packets are dropped immediately when the queue limit is reached.
backlog BYTES
The current backlog of bytes in the queue.
ecn | no-ecn
Enables or disables Explicit Congestion Notification (ECN).
bytemode | packetmode
Specifies whether the RED algorithm operates in byte mode or packet mode.
forced-pinky
Enables a specific RED variant known as "forced pinky".
quantum BYTES
The quantum value used in fair queuing algorithms.
dequeue-ratio RATIO
The ratio of dequeued packets to enqueued packets.
priority-offset OFFSET
An offset used in priority queuing.
child-queue-size SIZE
The size of child queues.
parent-queue-size SIZE
The size of parent queues.
queue-size SIZE
The overall queue size.
buffer-growth GROWTH
Specifies how the buffer size grows.
target TIME
The target average queue length time.
interval TIME
The interval for measuring the average queue length.
avpkt BYTES
The average packet size in bytes.
ewma-log BYTES
The exponential weighted moving average logarithm for queue length calculation.
weights WEIGHTS
Weights used in WRED for different traffic classes.
dev DEVICE
The network device on which to apply the RED qdisc.

EXAMPLES

Add a RED qdisc to the eth0 interface with a limit of 64KB, min threshold of 10KB, and max threshold of 20KB: 

tc qdisc add dev eth0 parent 1:1 red limit 65536 min 10240 max 20480

Add a RED qdisc with ECN enabled and using packet mode: 

tc qdisc add dev eth0 parent 1:1 red limit 65536 min 10240 max 20480 ecn packetmode

الوصف

آلية قائمة الانتظار RED (الكشف المبكر العشوائي) هي خوارزمية للتحكم في الازدحام مصممة لتجنب مشكلة التزامن العام التي يمكن أن تحدث مع أجهزة التوجيه التي تسقط الحزم عند الذيل. تعمل RED عن طريق إسقاط الحزم بشكل احتمالي عندما يتجاوز متوسط طول قائمة الانتظار عتبات معينة. هذا يسمح للمضيفين النهائيين باكتشاف الازدحام مبكرًا وتقليل معدلات إرسالهم، مما يمنع قائمة الانتظار من الامتلاء ويؤدي إلى إسقاطات متزامنة للحزم.

تحافظ خوارزمية RED على تقدير لمتوسط طول قائمة الانتظار. عند وصول حزمة، تتحقق الخوارزمية من متوسط طول قائمة الانتظار الحالي مقابل عتبتين: min و max.

إذا كان متوسط طول قائمة الانتظار أقل من min، يتم قبول الحزمة.

إذا كان متوسط طول قائمة الانتظار أعلى من max، يتم إسقاط الحزمة.

إذا كان متوسط طول قائمة الانتظار بين min و max، يتم إسقاط الحزمة باحتمالية تزداد خطيًا مع متوسط طول قائمة الانتظار.

تحتوي خوارزمية RED على العديد من المعلمات التي يمكن ضبطها لتحسين أدائها:

limit BYTES
أقصى حجم لقائمة الانتظار بالبايت.
min BYTES
الحد الأدنى لعتبة متوسط طول قائمة الانتظار بالبايت.
max BYTES
الحد الأقصى لعتبة متوسط طول قائمة الانتظار بالبايت.
ptcp PROB
أس الاحتمالية لحساب احتمالية إسقاط الحزمة.
athresh BYTES
عتبة متوسط طول قائمة الانتظار لحساب احتمالية إسقاط الحزمة.
wred
يُمكّن Weighted RED (WRED)، الذي يسمح باحتمالات إسقاط مختلفة لفئات حركة المرور المختلفة.
adaptive
يُمكّن RED التكيفي، الذي يضبط معلمات RED ديناميكيًا بناءً على ظروف الشبكة.
dp-model MODEL
يحدد نموذج احتمالية الإسقاط المراد استخدامه. القيم الممكنة هي basic، linear، و exp.
hard-drop
يُمكّن الإسقاط الصعب، مما يعني إسقاط الحزم فورًا عند الوصول إلى حد قائمة الانتظار.
backlog BYTES
العبء الحالي بالبايت في قائمة الانتظار.
ecn | no-ecn
يُمكّن أو يعطل إشعار الازدحام الصريح (ECN).
bytemode | packetmode
يحدد ما إذا كانت خوارزمية RED تعمل في وضع البايت أو وضع الحزمة.
forced-pinky
يُمكّن متغير RED معين يُعرف باسم "forced pinky".
quantum BYTES
قيمة الكم (quantum) المستخدمة في خوارزميات قوائم الانتظار العادلة.
dequeue-ratio RATIO
نسبة الحزم التي تم إخراجها إلى الحزم التي تم إدخالها.
priority-offset OFFSET
إزاحة تستخدم في قوائم الانتظار ذات الأولوية.
child-queue-size SIZE
حجم قوائم الانتظار الفرعية.
parent-queue-size SIZE
حجم قوائم الانتظار الرئيسية.
queue-size SIZE
حجم قائمة الانتظار الإجمالي.
buffer-growth GROWTH
يحدد كيف ينمو حجم المخزن المؤقت.
target TIME
وقت متوسط طول قائمة الانتظار المستهدف.
interval TIME
الفترة الزمنية لقياس متوسط طول قائمة الانتظار.
avpkt BYTES
متوسط حجم الحزمة بالبايت.
ewma-log BYTES
لوغاريتم المتوسط المتحرك المرجح أسيًا لحساب طول قائمة الانتظار.
weights WEIGHTS
الأوزان المستخدمة في WRED لفئات حركة المرور المختلفة.
dev DEVICE
جهاز الشبكة الذي سيتم تطبيق آلية قائمة الانتظار RED عليه.

أمثلة

أضف آلية قائمة انتظار RED إلى الواجهة eth0 بحد أقصى 64 كيلوبايت، وحد أدنى 10 كيلوبايت، وحد أقصى 20 كيلوبايت: 

tc qdisc add dev eth0 parent 1:1 red limit 65536 min 10240 max 20480

أضف آلية قائمة انتظار RED مع تمكين ECN واستخدام وضع الحزمة: 

tc qdisc add dev eth0 parent 1:1 red limit 65536 min 10240 max 20480 ecn packetmode
