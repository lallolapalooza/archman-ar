tcpspray(1)

الحزمة: ndisc6

التراخيص: GPL

TCPSPRAY(1) دليل المستخدم TCPSPRAY(1)

الاسم

tcpspray - أداة قياس عرض النطاق الترددي TCP/IP (عميل Discard و Echo)

الملخص

tcpspray [-46ev] [-b حجم_الكتلة] [-d انتظار_ميكروثانية] [ -f اسم_الملف] [-n عدد] <اسم_المضيف> [المنفذ]

الوصف

يستخدم tcpspray بروتوكول Discard أو Echo (RFC 863 أو RFC 862) لإجراء قياسات عرض النطاق الترددي لجلسات TCP بين النظام المحلي وخادم Discard أو Echo.

يمكن للمضيفين المستندين إلى Unix توفير خوادم Discard و/أو Echo باستخدام super-server للإنترنت inetd. على Windows NT، تقوم مكونات simple network protocols الاختيارية بنفس الشيء.

يجب تحديد اسم أو عنوان عقدة الخادم. سيحاول tcpspray تلقائيًا استخدام IPv6 عند توفره. إذا لم يكن كذلك، أو إذا فشل، فسيعود إلى IPv4. ومع ذلك، فإن tcpspray4 أو tcpspray6 يحاولان فقط استخدام IPv4 أو IPv6.

الخيارات

-4 أو --ipv4
فرض استخدام TCP عبر IPv4.
-6 أو --ipv6
فرض استخدام TCP عبر IPv6.
-b حجم_الكتلة أو --bsize حجم_الكتلة
إرسال كتلة بالحجم المحدد بالبايت (الافتراضي: 1024).
-d انتظار_ميكروثانية أو --delay انتظار_ميكروثانية
ينتظر للمدة المحددة بالميكروثانية بعد إرسال أي شيء قبل محاولة إرسال الذي يليه. لا يوجد تأخير افتراضيًا.
-e أو --echo
استخدام بروتوكول Echo بدلاً من Discard. سيقيس tcpspray الوقت اللازم لإرسال البيانات واستلامها مرة أخرى، بدلاً من مجرد إرسالها.
-f اسم_الملف أو --fill اسم_الملف
قراءة البيانات من الملف المحدد لملء الكتل المرسلة به. إذا كان الملف أصغر من حجم الكتل، أو إذا لم يتم تحديد ملف، فسيتم تعيين البايتات اللاحقة المتبقية جميعها إلى صفر.
-h أو --help
عرض بعض المساعدة والخروج.
-n عدد_الكتل أو --count عدد_الكتل
إرسال العدد المحدد من كتل البيانات للقياسات (الافتراضي: 100).
-V أو --version
عرض إصدار البرنامج والترخيص والخروج.
-v أو --verbose
عرض معلومات أكثر تفصيلاً. على وجه الخصوص، سيقوم tcpspray بطباعة نقطة في كل مرة يتم فيها إرسال كتلة. إذا تم استخدام بروتوكول Echo (الخيار -e)، فسيتم مسح النقاط عند استلام البيانات.

التشخيص

إذا لم تحصل على استجابة بينما تعرف أن المضيف البعيد قيد التشغيل، فمن المحتمل جدًا أنه لا توجد خدمة Discard/Echo قيد التشغيل، أو أن هذه الخدمات محظورة بواسطة جدار حماية. قد يساعد تشغيل tcptraceroute6(8) أو tcptraceroute(8) باتجاه المضيف البعيد IPv6 أو IPv4 في اكتشاف مثل هذا الموقف.

الأمان

لا يتطلب tcpspray أي امتيازات للتشغيل.

انظر أيضًا

tcp(7)، inetd(8)، tcptraceroute6(8)، tcptraceroute(8)
