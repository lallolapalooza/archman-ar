Tcl_SetEnsembleFlags(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_Ensemble

SYNOPSIS

Tcl_Ensemble(namespace, command, subcommand, flags, options)

ARGUMENTS

namespace: string - اسم المساحة

command: string - اسم الأمر

subcommand: string - اسم الأمر الفرعي

flags: string - علامات إضافية

options: string - خيارات إضافية

DESCRIPTION

يُستخدم الأمر ensemble لإدارة مساحات الأسماء في Tcl. يمكن تعديل مساحة الأسماء باستخدام علامات إضافية. إذا لم يتم تحديد مساحة أسماء، يتم استخدام السلوك الافتراضي: يتم إنشاء رسالة مناسبة إذا تم العثور على أمر فرعي غير معروف. يمكن قراءة هذا الأمر وكتابته باستخدام Tcl_GetEnsembleUnknownHandler و Tcl_SetEnsembleUnknownHandler على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يكن الرمز يشير إلى فرقة) ويجب اعتبار القائمة التي تم الحصول عليها من Tcl_GetEnsembleUnknownHandler غير قابلة للتغيير حتى لو لم تكن مشتركة.

SEE ALSO

namespace(n), Tcl_DeleteCommandFromToken(3)

KEYWORDS

command, ensemble
