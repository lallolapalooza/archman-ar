الاسم

pedit - إجراء محرر حزم عام

ملخص


tc ... action pedit [ex] munge { RAW_OP | LAYERED_OP | EXTENDED_LAYERED_OP } [ CONTROL ]

RAW_OP := offset OFFSET { u8 | u16 | u32 } [ AT_SPEC ] CMD_SPEC

AT_SPEC := at AT offmask MASK shift SHIFT

LAYERED_OP := { ip IPHDR_FIELD | ip BEYOND_IPHDR_FIELD } CMD_SPEC

EXTENDED_LAYERED_OP := { eth ETHHDR_FIELD | ip IPHDR_FIELD | ip EX_IPHDR_FIELD | ip6 IP6HDR_FIELD | tcp TCPHDR_FIELD | udp UDPHDR_FIELD } CMD_SPEC

ETHHDR_FIELD := { src | dst | type }

IPHDR_FIELD := { src | dst | tos | dsfield | ihl | protocol | precedence | nofrag | firstfrag | ce | df }

BEYOND_IPHDR_FIELD := { dport | sport | icmp_type | icmp_code }

EX_IPHDR_FIELD := { ttl }

IP6HDR_FIELD := { src | dst | traffic_class | flow_lbl | payload_len | nexthdr | hoplimit }

TCPHDR_FIELD := { sport | dport | flags }

UDPHDR_FIELD := { sport | dport }

CMD_SPEC := { clear | invert | set VAL | add VAL | decrement | preserve } [ retain RVAL ]

CONTROL := { reclassify | pipe | drop | shot | continue | pass | goto chain CHAIN_INDEX }

الوصف

يمكن استخدام الإجراء pedit لتغيير بيانات الحزم العشوائية. يمكن تحديد موقع البيانات المراد تغييرها إما بتحديد إزاحة وحجم كما في RAW_OP، أو بالنسبة لقيم الرأس عن طريق تسمية الرأس والحقل المراد تحريره، ويتم اختيار الحجم تلقائيًا بناءً على حجم حقل الرأس.

خيارات

ex
استخدم pedit الموسع. يُسمح بـ EXTENDED_LAYERED_OP وأوامر CMD_SPEC للإضافة/الطرح فقط في هذا الوضع.
offset OFFSET { u32 | u16 | u8 }
حدد الإزاحة التي سيتم تغيير البيانات عندها. OFFSET هو عدد صحيح مشير، يتم اختيار أساسه تلقائيًا (على سبيل المثال، سداسي عشري إذا كان مسبوقًا بـ 0x أو ثماني إذا كان مسبوقًا بـ 0). تحدد الوسيطة الثانية طول البيانات المراد تغييرها، أي أربعة بايت (u32) أو بايتان (u16) أو بايت واحد (u8).
at AT offmask MASK shift SHIFT
هذا جزء اختياري من RAW_OP يسمح بإزاحة متغيرة OFFSET تعتمد على بيانات الحزمة في الإزاحة AT، والتي يتم تطبيق عملية AND الثنائية عليها مع MASK وإزاحتها إلى اليمين بمقدار SHIFT قبل إضافتها إلى OFFSET.
eth ETHHDR_FIELD
تغيير حقل رأس ETH. الكلمات الرئيسية المدعومة لـ ETHHDR_FIELD هي:
src
dst
عنوان MAC المصدر أو الوجهة بالتنسيق القياسي: XX:XX:XX:XX:XX:XX
type
نوع الإيثر (Ether-type) بالقيمة الرقمية
ip IPHDR_FIELD
تغيير حقل رأس IPv4. الكلمات الرئيسية المدعومة لـ IPHDR_FIELD هي:
src
dst
عنوان IP المصدر أو الوجهة، قيمة بحجم أربعة بايت.
tos
dsfield
precedence
حقل نوع الخدمة (Type Of Service)، قيمة بحجم ثمانية بت.
ihl
تغيير حقل طول رأس IP (IP Header Length)، قيمة بحجم أربعة بت.
protocol
حقل البروتوكول للطبقة التالية (Next-layer Protocol)، قيمة بحجم ثمانية بت.
nofrag
firstfrag
ce
df
mf
تغيير بتات علم رأس IP. لاحظ أن القيمة التي يتم تمريرها إلى الأمر set ليست مجرد قيمة بت، بل البايت الكامل بما في ذلك حقل الأعلام (flags). على الرغم من أن الأجزاء ذات الصلة فقط من تلك القيمة هي التي يتم احترامها، ويتم تجاهل الباقي.
ip BEYOND_IPHDR_FIELD
مدعوم فقط لعملية الطبقات غير الموسعة. يتم تمريره إلى النواة كإزاحات بالنسبة لبداية رأس IP ويفترض أن رأس IP ذو حجم أدنى (20 بايت). الكلمات الرئيسية المدعومة لـ BEYOND_IPHDR_FIELD هي:
dport
sport
أرقام منافذ الوجهة أو المصدر، قيمة بحجم 16 بت. في الواقع، لا تحتوي رؤوس IPv4 على هذه المعلومات. بدلاً من ذلك، سيقوم هذا بتعيين إزاحة تناسب TCP و UDP على الأقل إذا كان رأس IP ذو حجم أدنى (20 بايت). إذا لم يكن كذلك، فسيؤدي ذلك إلى نتائج غير متوقعة.
icmp_type
icmp_code
مرة أخرى، هذا يسمح بتغيير البيانات بعد رأس IP الفعلي نفسه. يفترض وجود رأس ICMP مباشرة بعد رأس IP (بالحجم الأدنى). إذا لم يكن موجودًا أو كان الأخير أكبر من الحد الأدنى البالغ 20 بايت، فسيؤدي ذلك إلى نتائج غير متوقعة. هذه الحقول هي قيم بحجم ثمانية بت.
ip EX_IPHDR_FIELD
مدعوم فقط عند استخدام ex. الكلمات الرئيسية المدعومة لـ EX_IPHDR_FIELD هي:
ttl
ip6 IP6HDR_FIELD
الكلمات الرئيسية المدعومة لـ IP6HDR_FIELD هي:
src
dst
traffic_class
flow_lbl
payload_len
nexthdr
hoplimit
tcp TCPHDR_FIELD
الكلمات الرئيسية المدعومة لـ TCPHDR_FIELD هي:
sport
dport
رقم منفذ TCP المصدر أو الوجهة، قيمة بحجم 16 بت.
flags
udp UDPHDR_FIELD
