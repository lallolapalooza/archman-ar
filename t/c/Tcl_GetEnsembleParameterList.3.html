مؤشر إلى متغير يتم فيه كتابة مقبض المساحة التي تم تسجيل المجموعة بها.

DESCRIPCIÓN

المجموعة هي أمر، مسجل في مساحة ما، يتكون من مجموعة من الأوامر الفرعية المنفذة بواسطة أوامر Tcl أخرى. يتم تفسير الوسيط الأول لأمر المجموعة دائمًا كمحدد يشير إلى الأمر الفرعي الذي يجب تنفيذه.

يتم إنشاء المجموعات باستخدام Tcl_CreaEnsemble، والتي تأخذ أربعة وسائط: المفسر الذي يجب العمل فيه، اسم المجموعة المراد إنشاؤها، المساحة داخل المفسر التي سيتم فيها تسجيل المجموعة، ومجموعة علامات المجموعة الافتراضية. نتيجة الدالة هي رمز الأمر للمجموعة، والذي يمكن استخدامه لتكوين المجموعة باستخدام واجهة برمجة التطبيقات الموضحة في PROPIEDAD DE ENJAMBRE.

بالنظر إلى اسم أمر المجموعة، يمكن استرداد الرمز لهذا الأمر باستخدام Tcl_BuscaEnsemble. إذا كان الاسم المحدد (في nombreObj) لا يشير إلى أمر مجموعة، فإن نتيجة الدالة هي NULL، وإذا تم تعيين البت TCL_LEAVE_ERR_MSG في flags، يتم ترك رسالة خطأ في نتيجة المفسر.

يمكن التحقق من رمز الأمر لمعرفة ما إذا كان مجموعة باستخدام Tcl_IsEnsemble. تُرجع هذه الدالة 1 إذا كان الرمز يشير إلى مجموعة، أو 0 بخلاف ذلك.

PROPIEDADES DE ENJAMBRE

لكل مجموعة أربع خصائص للقراءة/الكتابة وخاصية قراءة/كتابة واحدة. الخصائص هي:

flags (lectura/escritura)
مجموعة العلامات للمجموعة، معبر عنها كحقل بت. حاليًا، العلامة العامة الوحيدة هي TCL_ENJAMBRE_PREFIX، والتي يتم تعيينها عندما يمكن مطابقة البادئات الواضحة للأوامر الفرعية مع التطبيقات جنبًا إلى جنب مع المطابقات الدقيقة. يمكن قراءة العلامات وكتابتها باستخدام Tcl_ObtieneFlagsEnsemble و Tcl_SetsFlagsEnsemble على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يكن الرمز يشير إلى مجموعة).
diccionario de mapa de subcomandos (lectura/escritura)
قاموس يحتوي على تعيين لأسماء الأوامر الفرعية إلى قوائم كلمات تستخدم كبادئة أمر (تستبدل أول كلمتين من الأمر، وهما أمر المجموعة واسم الأمر الفرعي)، أو NULL إذا كان يجب تعيين جميع الأوامر الفرعية إلى أوامر بنفس الاسم غير المؤهل في مساحة اسم المجموعة. القيمة الافتراضية هي NULL. يمكن قراءتها وكتابتها باستخدام Tcl_ObtieneMappingDictEnsemble و Tcl_SetsMappingDictEnsemble على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يكن الرمز يشير إلى مجموعة) ويجب دائمًا التعامل مع القاموس الذي تم الحصول عليه من Tcl_ObtieneMappingDictEnsemble على أنه غير قابل للتغيير حتى لو لم يكن مشتركًا. يجب تأهيل جميع أسماء الأوامر في البادئات المعينة باستخدام Tcl_SetsMappingDictEnsemble.
lista de parámetros formales antes del subcomando (lectura/escritura)
قائمة بأسماء المعلمات الرسمية (الأسماء المستخدمة فقط عند إنشاء رسائل الخطأ) التي تسبق اسم الأمر الفرعي. NULL (افتراضي) يعادل القائمة الفارغة. يمكن قراءتها وكتابتها باستخدام Tcl_ObtieneListaParametrosEnsemble و Tcl_SetsListaParametrosEnsemble على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يكن الرمز يشير إلى مجموعة) ويجب دائمًا التعامل مع القائمة التي تم الحصول عليها من Tcl_ObtieneListaParametrosEnsemble على أنها غير قابلة للتغيير حتى لو لم تكن مشتركة.
lista de subcomandos (lectura/escritura)
قائمة بجميع أسماء الأوامر الفرعية للمجموعة، أو NULL إذا كان سيتم اشتقاقها من أسماء الأوامر الفرعية لمفتاح القاموس (انظر أعلاه) أو (إذا كان هذا أيضًا NULL) من الأوامر المصدرة من مساحة اسم المسجل. يمكن قراءتها وكتابتها باستخدام Tcl_ObtieneSubcomandosEnsemble و Tcl_SetsSubcomandosEnsemble على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يكن الرمز يشير إلى مجموعة) ويجب دائمًا التعامل مع القائمة التي تم الحصول عليها من Tcl_ObtieneSubcomandosEnsemble على أنها غير قابلة للتغيير حتى لو لم تكن مشتركة.
prefijo de comando de handler de subcomandos no definido (lectura/escritura)
قائمة كلمات سيتم إضافتها إلى مقدمة أي أمر فرعي عندما يكون الأمر الفرعي غير معروف للمجموعة (وفقًا للمعالجة الحالية للبادئات). يمكن قراءتها وكتابتها باستخدام Tcl_ObtieneHandlerNoDefinidoEnsemble و Tcl_SetsHandlerNoDefinidoEnsemble على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يكن الرمز يشير إلى مجموعة) ويجب دائمًا التعامل مع القائمة التي تم الحصول عليها من Tcl_ObtieneHandlerNoDefinidoEnsemble على أنها غير قابلة للتغيير حتى لو لم تكن مشتركة. يجب تأهيل جميع أسماء الأوامر في البادئات المعينة باستخدام Tcl_SetsHandlerNoDefinidoEnsemble.

Tcl_GetEnsembleParameterList(3) — Tcl

NAME

Tcl_GetEnsembleParameterList, Tcl_GetEnsembleUnknownHandler, Tcl_GetEnsembleNamespace, Tcl_GetEnsembleMapping

SYNOPSIS

#include <tcl.h>

CONST char *
Tcl_GetEnsembleParameterList(
    Tcl_Interp *interp,
    Tcl_CommandToken token
);

CONST char *
Tcl_GetEnsembleUnknownHandler(
    Tcl_Interp *interp,
    Tcl_CommandToken token
);

Tcl_Namespace *
Tcl_GetEnsembleNamespace(
    Tcl_Interp *interp,
    Tcl_CommandToken token
);

Tcl_HashTable *
Tcl_GetEnsembleMapping(
    Tcl_Interp *interp,
    Tcl_CommandToken token
);

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_CommandToken token
Token for the ensemble command.

DESCRIPTION

These functions retrieve information about an ensemble command. The token argument should be a token returned from a prior call to Tcl_CreateEnsemble.

parameter list (read-only)
The list of parameters that the ensemble command expects. See the namespace ensemble command for more details. May be read using Tcl_GetEnsembleParameterList which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleParameterList should always be treated as immutable even if it is unshared.
unknown handler (read-only)
The script to be executed when an unknown subcommand is encountered. If NULL, the default behavior - generate a suitable error message - will be used when an unknown subcommand is encountered. May be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The result of both functions is a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble) and the list obtained from Tcl_GetEnsembleUnknownHandler should always be treated as immutable even if it is unshared.
bound namespace (read-only)
The namespace to which the ensemble is bound; when the namespace is deleted, so too will the ensemble, and this namespace is also the namespace whose list of exported commands is used if both the mapping dictionary and the subcommand list properties are NULL. May be read using Tcl_GetEnsembleNamespace which returns a Tcl result code (TCL_OK, or TCL_ERROR if the token does not refer to an ensemble).
