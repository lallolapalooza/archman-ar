Tcl_ListMathFuncs(3)

الحزمة: tcl

التراخيص: TCL

Tcl_CreateMathFunc(3) إجراءات مكتبة Tcl Tcl_CreateMathFunc(3)

الاسم

Tcl_CreateMathFunc، Tcl_GetMathFuncInfo، Tcl_ListMathFuncs - تعريف، استعلام، وتعداد الدوال الرياضية للتعبيرات

إشعار الإلغاء المستقبلي

أصبحت دالتا Tcl_CreateMathFunc و Tcl_GetMathFuncInfo قديمة إلى حد ما بسبب القدرة على إنشاء دوال للتعبيرات عن طريق وضع الأوامر في فضاء الأسماء tcl::mathfunc، كما هو موضح في صفحة الدليل mathfunc؛ لا يُتوقع أن تستمر واجهة برمجة التطبيقات الموضحة في هذه الصفحة في الصيانة إلى أجل غير مسمى.

الملخص

#include <tcl.h>

void
Tcl_CreateMathFunc(interp, name, numArgs, argTypes, proc, clientData)

int
Tcl_GetMathFuncInfo(interp, name, numArgsPtr, argTypesPtr, procPtr,
                    clientDataPtr)

Tcl_Obj *
Tcl_ListMathFuncs(interp, pattern)

المعاملات

Tcl_Interp *interp (مدخل)
المفسر الذي ستُعرَّف فيه الدالة الجديدة.
const char *name (مدخل)
اسم الدالة.
int numArgs (مدخل)
عدد معاملات الدالة؛ يحدد أيضًا حجم مصفوفة argTypes.
Tcl_ValueType *argTypes (مدخل)
يشير إلى مصفوفة تحدد أنواع المعاملات المسموح بها لكل معامل للدالة.
Tcl_MathProc *proc (مدخل)
الإجراء الذي ينفذ الدالة.
ClientData clientData (مدخل)
قيمة كلمة واحدة عشوائية ليتم تمريرها إلى proc عند استدعائها.
int *numArgsPtr (مخرج)
يشير إلى متغير سيتم تعيينه ليحتوي على عدد معاملات الدالة.
Tcl_ValueType **argTypesPtr (مخرج)
يشير إلى متغير سيتم تعيينه ليحتوي على مؤشر إلى مصفوفة تحدد أنواع المعاملات المسموح بها لكل معامل للدالة، والتي ستحتاج إلى تحريرها باستخدام Tcl_Free.
Tcl_MathProc **procPtr (مخرج)
يشير إلى متغير سيتم تعيينه ليحتوي على مؤشر إلى كود التنفيذ للدالة (أو NULL إذا كانت الدالة منفذة مباشرة في الكود الثنائي).
ClientData *clientDataPtr (مخرج)
يشير إلى متغير سيتم تعيينه ليحتوي على معامل clientData الذي تم تمريره إلى Tcl_CreateMathFunc عند إنشاء الدالة إذا لم تكن الدالة منفذة مباشرة في الكود الثنائي.
const char *pattern (مدخل)
نمط للمطابقة مع أسماء الدوال لتصفيتها (عن طريق تمريره إلى Tcl_StringMatch)، أو NULL لعدم تطبيق أي تصفية.

الوصف

تسمح Tcl باستخدام عدد من الدوال الرياضية في التعبيرات، مثل sin، cos، و hypot. تمثل هذه الدوال بأوامر في فضاء الأسماء tcl::mathfunc. الدالة Tcl_CreateMathFunc هي طريقة قديمة للتطبيقات لإضافة دوال إضافية إلى تلك التي توفرها Tcl بالفعل أو لاستبدال الدوال الموجودة. لا ينبغي استخدامها من قبل التطبيقات الجديدة، التي ينبغي عليها إنشاء دوال رياضية باستخدام Tcl_CreateObjCommand لإنشاء أمر في فضاء الأسماء tcl::mathfunc.

في واجهة Tcl_CreateMathFunc، Name هو اسم الدالة كما ستظهر في التعبيرات. إذا كان name غير موجود بالفعل في فضاء الأسماء ::tcl::mathfunc، فسيتم إنشاء أمر جديد في هذا الفضاء. إذا كان name موجودًا، فسيتم استبدال الدالة الموجودة. NumArgs و argTypes تصفان معاملات الدالة. يجب أن يكون كل إدخال في مصفوفة argTypes واحدًا من TCL_INT، TCL_DOUBLE، TCL_WIDE_INT، أو TCL_EITHER للإشارة إلى ما إذا كان المعامل المقابل يجب أن يكون عددًا صحيحًا، أو قيمة فاصلة عائمة مزدوجة الدقة، أو عددًا صحيحًا واسعًا (64 بت)، أو أي شيء، على التوالي.

عند استدعاء الدالة في تعبير، ستقوم Tcl باستدعاء proc. يجب أن تتطابق المعاملات والنتيجة لـ Proc مع النوع Tcl_MathProc:

typedef int Tcl_MathProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_Value *args,
        Tcl_Value *resultPtr);

عند استدعاء proc، ستكون معاملات clientData و interp هي نفسها التي تم تمريرها إلى Tcl_CreateMathFunc. سيشير Args إلى مصفوفة من هياكل Tcl_Value، والتي تصف المعاملات الفعلية للدالة:

typedef struct Tcl_Value {
    Tcl_ValueType type;
    long intValue;
    double doubleValue;
    Tcl_WideInt wideValue;
} Tcl_Value;

يشير حقل type إلى نوع المعامل وهو أحد TCL_INT، TCL_DOUBLE أو TCL_WIDE_INT. سيتطابق مع قيمة argTypes المحددة للدالة ما لم تكن قيمة argTypes هي TCL_EITHER. تقوم Tcl بتحويل المعامل المقدم في التعبير إلى النوع المطلوب في argTypes، إذا كان ذلك ضروريًا. اعتمادًا على قيمة حقل type، سيحتوي حقل intValue، doubleValue أو wideValue على القيمة الفعلية للمعامل.

يجب على Proc حساب نتيجته وتخزينها إما كعدد صحيح في resultPtr->intValue أو كقيمة فاصلة عائمة في resultPtr->doubleValue. يجب عليه أيضًا تعيين resultPtr->type إلى واحد من TCL_INT، TCL_DOUBLE أو TCL_WIDE_INT للإشارة إلى القيمة التي تم تعيينها. في الظروف العادية، يجب أن تُرجع proc القيمة TCL_OK. إذا حدث خطأ أثناء تنفيذ الدالة، يجب أن تُرجع proc القيمة TCL_ERROR وتترك رسالة خطأ في نتيجة المفسر.

تقوم Tcl_GetMathFuncInfo باسترداد القيم المرتبطة بالدالة name التي تم تمريرها إلى استدعاء Tcl_CreateMathFunc سابق. عادةً، يكون رمز الإرجاع TCL_OK، ولكن إذا كانت الدالة المسماة غير موجودة، فسيتم إرجاع TCL_ERROR ويتم وضع رسالة خطأ في نتيجة المفسر.

إذا لم يحدث خطأ، فإن مرجع المصفوفة الموضوع في المتغير المشار إليه بواسطة argTypesPtr تم تخصيصه حديثًا، ويجب تحريره عن طريق تمريره إلى Tcl_Free. بعض الدوال (المجموعة القياسية المنفذة في النواة، وتلك المعرفة عن طريق وضع الأوامر في فضاء الأسماء tcl::mathfunc) لا تحتوي على معلومات نوع المعامل؛ محاولة استرداد القيم لها تؤدي إلى تخزين NULL في المتغير المشار إليه بواسطة procPtr ولن يتم تعديل المتغير المشار إليه بواسطة clientDataPtr. سيحتوي المتغير المشار إليه بواسطة numArgsPointer على -1، ولن يتم تخزين أي أنواع معاملات في المتغير المشار إليه بواسطة argTypesPointer.

تُرجع Tcl_ListMathFuncs قيمة Tcl تحتوي على قائمة بجميع الدوال الرياضية المعرفة في المفسر التي يتطابق اسمها مع pattern. القيمة المرجعة لها عدد مراجع صفر.

Tcl_ListMathFuncs(3)

Tcl_ListMathFuncs - Tcl_ListMathFuncs – returns a list of all defined mathematical functions

SYNOPSIS

#include <tcl.h>

int
Tcl_ListMathFuncs(interp, numFuncsPtr)
    Tcl_Interp *interp;
    int *numFuncsPtr;

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for storing the result.
int *numFuncsPtr
Pointer to an integer location that will be filled with the number of functions.

DESCRIPTION

The Tcl_ListMathFuncs function returns a list of the names of all mathematical functions that are currently available in the interpreter interp. The list is stored in the interpreter's result using Tcl_SetResult. In addition, the number of functions found is stored in the location pointed to by numFuncsPtr. If an error occurs, the function returns TCL_ERROR, otherwise it returns TCL_OK.
