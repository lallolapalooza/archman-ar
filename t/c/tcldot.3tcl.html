NAME

tcldot - A Tcl/Tk interface to the dot(1) layout engine.

SYNOPSIS

package require tcldot

tcldot::drawGraph graphDescription options...

tcldot::dot options...

tcldot::neato options...

USAGE

This package requires Tcl/Tk and the Graphviz package. See the example scripts in the distribution for detailed usage.

INTRODUCTION

The tcldot package provides a Tcl/Tk interface to the dot(1) layout engine. It allows you to generate graphs dynamically within a Tcl/Tk application, or to load and display existing graph descriptions.

The primary command is tcldot::drawGraph, which takes a graph description string (in DOT language) and renders it into a Tk canvas widget. The tcldot::dot and tcldot::neato commands are convenience wrappers that execute the respective layout engines and return the output.

COMMANDS

tcldot::drawGraph graphDescription options...

Draws a graph into a specified Tk canvas. The graphDescription should be a string in DOT language. The following options are supported:

-canvas canvasPath
Specifies the Tk canvas widget where the graph should be drawn. If not specified, a new canvas is created.
-layout engine
Specifies the layout engine to use (e.g., "dot", "neato", "fdp", "circo", "twopi"). Defaults to "dot".
-options args
A list of options to be passed to the layout engine (e.g., "-Gratio=1.5").
-showlabels boolean
Whether to display node and edge labels. Defaults to true.
-animate boolean
Enables animation during layout (useful for interactive exploration). Defaults to false.
tcldot::dot options...

Executes the dot(1) layout engine with the given options. The input DOT description can be provided via standard input or a file. The output is typically SVG or PNG, depending on the options.

tcldot::neato options...

Executes the neato(1) layout engine with the given options. Similar to tcldot::dot but uses the spring model layout algorithm.

Interactive elements like node dragging can be enabled using the mouse. See the script in examples/disp of the tcldot distribution for a demonstration of this facility.

BUGS
