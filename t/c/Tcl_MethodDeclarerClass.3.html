Tcl_MethodDeclarerClass(3)

الحزمة: tcl

التراخيص: TCL

NAME

Tcl_MethodDeclarerClass, Tcl_MethodCallProc, Tcl_MethodDeleteProc, Tcl_CloneProc - management of TclOO methods

SYNOPSIS

#include <tclOO.h>

typedef Tcl_Object Tcl_MethodDeclarerClass(
        Tcl_Interp *interp,
        Tcl_Object context,
        Tcl_Object type,
        const char *methodName,
        Tcl_MethodCallProc *callProc,
        ClientData callData,
        Tcl_MethodDeleteProc *deleteProc);
typedef int Tcl_MethodCallProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_ObjectContext objectContext,
        int objc,
        Tcl_Obj *const *objv);
typedef void Tcl_MethodDeleteProc(
        ClientData clientData);
typedef int Tcl_CloneProc(
        Tcl_Interp *interp,
        ClientData oldClientData,
        ClientData *newClientDataPtr);

ARGUMENTS

-interp (Tcl_Interp *interp)
The interpreter in which to operate.
-context (Tcl_Object context)
The object defining the class or instance in which the method is to be declared.
-type (Tcl_Object type)
The type of method to declare (e.g., oo::object method or oo::class method).
-methodname (const char *methodName)
The name of the method to declare.
-callproc (Tcl_MethodCallProc *callProc)
The C procedure to be invoked when the method is called.
-calldata (ClientData callData)
Arbitrary data to be passed to the C procedure.
-deleteproc (Tcl_MethodDeleteProc *deleteProc)
The C procedure to be invoked when the method is deleted.
-clientdata (ClientData clientData)
Arbitrary data associated with the method.
-objectcontext (Tcl_ObjectContext objectContext)
The context in which the method is being invoked.
-objc (int objc)
The number of arguments passed to the method.
-objv (Tcl_Obj *const *objv)
The arguments passed to the method.
-oldclientdata (ClientData oldClientData)
The client data from the method being copied.
-newclientdatapointer (ClientData *newClientDataPtr)
A pointer to where the client data for the new method should be stored.

DESCRIPTION

These functions provide the C API for declaring and managing methods in TclOO. TclOO is an object-oriented extension to Tcl that allows for the creation of objects, classes, and methods.

TCL_METHODDECLARERCLASS FUNCTION SIGNATURE

Functions matching this signature are used to declare a new method for a class or object. The function returns the object representing the declared method, or NULL if an error occurred.

typedef Tcl_Object Tcl_MethodDeclarerClass(
        Tcl_Interp *interp,
        Tcl_Object context,
        Tcl_Object type,
        const char *methodName,
        Tcl_MethodCallProc *callProc,
        ClientData callData,
        Tcl_MethodDeleteProc *deleteProc);

The interp argument is the interpreter in which the method is being declared. The context argument is the object representing the class or instance for which the method is being declared. The type argument specifies the type of method (e.g., instance method or class method). The methodName is the name of the method. The callProc is the C function that will be called when the method is invoked, and callData is arbitrary data passed to the callProc. The deleteProc is a C function called when the method is destroyed.

TCL_METHODCALLPROC FUNCTION SIGNATURE

Functions matching this signature are called when the method is invoked.

typedef int Tcl_MethodCallProc(
        ClientData clientData,
        Tcl_Interp *interp,
        Tcl_ObjectContext objectContext,
        int objc,
        Tcl_Obj *const *objv);

The clientData argument to a Tcl_MethodCallProc is the value that was given when the method was created, the interp is a place in which to execute scripts and access variables as well as being where to put the result of the method, and the objc and objv fields give the parameter objects to the method. The calling context of the method can be discovered through the objectContext argument, and the return value from a Tcl_MethodCallProc is any Tcl return code (e.g. TCL_OK, TCL_ERROR).

TCL_METHODDELETEPROC FUNCTION SIGNATURE

Functions matching this signature are used when a method is deleted, whether through a new method being created or because the object or class is deleted.

typedef void Tcl_MethodDeleteProc(
        ClientData clientData);

The clientData argument to a Tcl_MethodDeleteProc will be the same as the value passed to the clientData argument to Tcl_NewMethod or Tcl_NewInstanceMethod when the method was created.

TCL_CLONEPROC FUNCTION SIGNATURE

Functions matching this signature are used to copy a method when the object or class is copied using Tcl_CopyObjectInstance (or oo::copy).

typedef int Tcl_CloneProc(
        Tcl_Interp *interp,
        ClientData oldClientData,
        ClientData *newClientDataPtr);

The interp argument gives a place to write an error message when the attempt to clone the object is to fail, in which case the clone procedure must also return TCL_ERROR; it should return TCL_OK otherwise. The oldClientData field to a Tcl_CloneProc gives the value from the method being copied from, and the newClientDataPtr field will point to a variable in which to write the value for the method being copied to.
