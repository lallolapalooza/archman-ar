tc-sample(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

الاسم

sample - إجراء أخذ عينات للحزم في tc

الملخص


tc ... action sample rate RATE group GROUP [ trunc SIZE ] [ index INDEX ]

tc ... action sample index INDEX

الوصف

يسمح إجراء sample بأخذ عينات من الحزم التي تطابق المصنف.

يتم اختيار الحزم عشوائياً وفقاً لمعامل rate، ويتم أخذ عينات منها باستخدام قناة psample العامة (generic netlink channel). يمكن للمستخدم أيضاً تحديد اقتطاع الحزم لتوفير حركة مرور المستخدم-النواة. تتضمن كل عينة بيانات وصفية إعلامية حول الحزمة الأصلية، والتي يتم إرسالها باستخدام سمات netlink، إلى جانب بيانات الحزمة الأصلية.

يمكن للمستخدم إما تحديد معلمات إجراء العينة كما هو موضح في النموذج الأول أعلاه، أو استخدام إجراء عينة موجود باستخدام مؤشره، كما هو موضح في النموذج الثاني.

حقول البيانات الوصفية للحزم المعينة

يتم تسليم البيانات الوصفية إلى تطبيقات مساحة المستخدم باستخدام قناة psample العامة (generic netlink channel)، حيث تتضمن كل عينة سمات netlink التالية:

PSAMPLE_ATTR_IIFINDEX
فهرس الواجهة المدخلة للحزمة، إذا كانت موجودة.
PSAMPLE_ATTR_OIFINDEX
فهرس الواجهة المخرجة للحزمة. هذا الحقل غير ذي صلة بأخذ العينات عند الدخول (ingress).
PSAMPLE_ATTR_ORIGSIZE
حجم الحزمة الأصلية (قبل الاقتطاع).
PSAMPLE_ATTR_SAMPLE_GROUP
مجموعة psample التي تم إرسال الحزمة إليها.
PSAMPLE_ATTR_GROUP_SEQ
رقم تسلسلي للحزمة المعينة. يتم زيادة هذا الرقم مع كل حزمة معينة من مجموعة psample الحالية.
PSAMPLE_ATTR_SAMPLE_RATE
المعدل الذي تم أخذ عينة الحزمة به.

خيارات

rate RATE
معدل أخذ عينات الحزمة. RATE هو النسبة المتوقعة بين الحزم المرصودة والحزم المعينة. على سبيل المثال، سيؤدي RATE بقيمة 100 إلى متوسط حزمة واحدة معينة من كل 100 حزمة مرصودة.
trunc SIZE
عند التعيين، يحدد الحد الأقصى لحجم الحزم المعينة، ويتسبب في اقتطاعها إذا لزم الأمر.
group GROUP
مجموعة psample التي سيتم إرسال الحزمة إليها. تعرف وحدة psample مفهوم المجموعات، مما يسمح للمستخدم بمطابقة حزم معينة تم أخذ عينات منها في حالة وجود قواعد أخذ عينات متعددة، وبالتالي تحديد الحزم التي جاءت من قاعدة معينة فقط.
index INDEX
معرف فريد لإجراء. عند إنشاء مثيل إجراء جديد، يسمح هذا المعامل بتعيين فهرس الإجراء الجديد. عند استخدام إجراء موجود، يسمح هذا المعامل بتحديد فهرس الإجراء الموجود. يجب أن يكون الفهرس عدداً صحيحاً غير سالب 32 بت أكبر من الصفر.

أمثلة

خذ عينة من حزمة واحدة من كل 100 حزمة تتدفق إلى الواجهة eth0 إلى مجموعة psample 12:

tc qdisc add dev eth0 handle ffff: ingress
tc filter add dev eth0 parent ffff: matchall \
     action sample rate 100 group 12 index 19

استخدم نفس مثيل الإجراء لأخذ عينات من eth1 أيضاً:

tc qdisc add dev eth1 handle ffff: ingress
tc filter add dev eth1 parent ffff: matchall \
     action sample index 19
