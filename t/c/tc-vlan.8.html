tc-vlan(8) — وحدة معالجة VLAN Linux tc-vlan(8) — وحدة معالجة VLAN

الاسم

vlan - وحدة معالجة VLAN

الملخص


tc ... action vlan { pop | pop_eth | PUSH | MODIFY | PUSH_ETH } [ CONTROL ]

PUSH := push [ protocol VLANPROTO ] [ priority VLANPRIO ] id VLANID

MODIFY := modify [ protocol VLANPROTO ] [ priority VLANPRIO ] id VLANID

PUSH_ETH := push_eth dst_mac LLADDR src_mac LLADDR

CONTROL := { reclassify | pipe | drop | continue | pass | goto chain CHAIN_INDEX }

الوصف

يسمح إجراء vlan بإجراء تغليف أو فك تغليف 802.1Q للحزمة، كما ينعكس في أوضاع التشغيل POP و PUSH و MODIFY. وضع POP بسيط، حيث لا توجد حاجة لمعلومات إضافية لإزالة غلاف VLAN الخارجي فقط. تتطلب أوضاع PUSH و MODIFY على الأقل VLANID وتسمح باختيار VLANPROTO المراد استخدامه اختياريًا.

يمكن أيضًا استخدام إجراء vlan لإضافة أو إزالة رأس Ethernet الأساسي. يتم استخدام وضع pop_eth، الذي لا يأخذ أي وسيط، لإزالة رأس Ethernet الأساسي. يجب أن تكون جميع شبكات VLAN الموجودة قد تمت إزالتها مسبقًا. يتم إجراء العملية المعاكسة، وهي إضافة رأس Ethernet أساسي، باستخدام وضع push_eth. في هذه الحالة، يجب ألا تحتوي الحزمة على رأس MAC (تجميع رؤوس MAC غير مسموح به). هذا الوضع مفيد في الغالب عندما يكون الإجراء السابق قد قام بتغليف الإطار الأصلي بالكامل خلف رأس شبكة ويحتاج المرء إلى إضافة رأس Ethernet قبل إعادة توجيه الحزمة الناتجة.

الخيارات

pop
وضع فك التغليف، لا يُسمح بأي وسيط إضافي.
push
وضع التغليف. يتطلب على الأقل خيار id.
modify
وضع الاستبدال. يتم استبدال علامة 802.1Q الموجودة. يتطلب على الأقل خيار id.
pop_eth
وضع فك تغليف رأس Ethernet. يعمل فقط على رأس Ethernet عادي: يجب إزالة شبكات VLAN، إن وجدت، أولاً.
push_eth
وضع تغليف رأس Ethernet. يتم تعيين نوع الإيثرت تلقائيًا باستخدام نوع رأس الشبكة. لا يُسمح بتجميع رؤوس Ethernet: يجب ألا تحتوي الحزمة على رأس MAC عند استخدام هذا الوضع. يتطلب خيارات dst_mac و src_mac.
id VLANID
تحديد معرف VLAN (VLAN ID) المراد تغليفه فيه. VLANID هو عدد صحيح 16 بت غير موقع، يتم اكتشاف التنسيق تلقائيًا (على سبيل المثال، البادئة بـ '0x' للتفسير السداسي عشري، إلخ).
protocol VLANPROTO
اختر بروتوكول VLAN المراد استخدامه. وقت كتابة هذه السطور، تقبل النواة فقط 802.1Q أو 802.1ad.
priority VLANPRIO
اختر أولوية VLAN المراد استخدامها. رقم عشري في النطاق 0-7.
dst_mac LLADDR
اختر عنوان MAC الوجهة المراد استخدامه.
src_mac LLADDR
اختر عنوان MAC المصدر المراد استخدامه.
CONTROL
كيفية المتابعة بعد تنفيذ هذا الإجراء.
reclassify
إعادة بدء التصنيف بالقفز إلى المرشح الأول المرفق بوالد هذا الإجراء.
pipe
المتابعة مع الإجراء التالي، وهذا هو الافتراضي.
drop
سيتم إسقاط الحزمة دون تشغيل إجراءات أخرى.
continue
متابعة التصنيف مع المرشح التالي في الخط.
pass
العودة إلى qdisc المستدعي لمعالجة الحزمة. هذا ينهي عملية التصنيف.

أمثلة

المثال التالي يقوم بتغليف حزم ICMP الواردة على eth0 من 10.0.0.2 في معرف VLAN 123:

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev eth0 parent ffff: pref 11 protocol ip \
	u32 match ip protocol 1 0xff flowid 1:1 \
	    match ip src 10.0.0.2 flowid 1:1 \
	action vlan push id 123

هنا مثال على وظيفة pop: يتم فك تغليف حزم VLAN الواردة على eth0، ثم يتم إعادة بدء عملية التصنيف للحزمة العادية:

#tc qdisc add dev eth0 handle ffff: ingress
#tc filter add dev $ETH parent ffff: pref 1 protocol 802.1Q \
	u32 match u32 0 0 flowid 1:1 \
	action vlan pop reclassify

للحصول على مثال لأوضاع pop_eth و push_eth، راجع tc-mpls(8).
