الوصف

التجميع هو أمر، مرتبط بفضاء اسمي ما، يتكون من مجموعة من الأوامر الفرعية التي تنفذها أوامر Tcl أخرى. يتم دائمًا تفسير الوسيط الأول لأمر التجميع على أنه محدد يحدد الأمر الفرعي المراد تنفيذه.

يتم إنشاء التجميعات باستخدام Tcl_CreateEnsemble، والتي تأخذ أربعة وسائط: المفسر للعمل ضمنه، اسم التجميع المراد إنشاؤه، الفضاء الاسمي داخل المفسر للربط به، ومجموعة الأعلام الافتراضية للتجميع. نتيجة الدالة هي رمز الأمر للتجميع، والذي يمكن استخدامه لتهيئة التجميع بشكل أكبر باستخدام واجهة برمجة التطبيقات الموضحة أدناه في خصائص التجميع.

بالنظر إلى اسم أمر التجميع، يمكن استرداد رمز هذا الأمر باستخدام Tcl_FindEnsemble. إذا كان اسم الأمر المحدد (في cmdNameObj) لا يشير إلى أمر تجميع، فإن نتيجة الدالة هي NULL (وإذا تم تعيين بت TCL_LEAVE_ERR_MSG في flags) يتم ترك رسالة خطأ في نتيجة المفسر.

يمكن التحقق من رمز الأمر لمعرفة ما إذا كان يشير إلى تجميع باستخدام Tcl_IsEnsemble. هذه الدالة تعيد 1 إذا كان الرمز يشير إلى تجميع، أو 0 بخلاف ذلك.

خصائص التجميع

كل تجميع له أربع خصائص للقراءة والكتابة وخاصية للقراءة فقط. الخصائص هي:

الأعلام (قراءة/كتابة)
مجموعة أعلام التجميع، معبر عنها كحقل بت. حاليًا، العلم العام الوحيد هو TCL_ENSEMBLE_PREFIX الذي يتم تعيينه عندما يُسمح لحل البادئات غير الغامضة للأوامر الفرعية بالحل للتطبيقات بالإضافة إلى التطابقات الدقيقة. يمكن قراءة الأعلام وكتابتها باستخدام Tcl_GetEnsembleFlags و Tcl_SetEnsembleFlags على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يشر الرمز إلى تجميع).
قاموس التعيين (قراءة/كتابة)
قاموس يحتوي على تعيين من أسماء الأوامر الفرعية إلى قوائم من الكلمات لاستخدامها كأمر بادئ (يستبدل الكلمتين الأوليين للأمر وهما أمر التجميع نفسه واسم الأمر الفرعي)، أو NULL إذا كان يجب تعيين كل أمر فرعي إلى الأمر الذي يحمل نفس الاسم غير المؤهل في الفضاء الاسمي المرتبط بالتجميع. الافتراضي هو NULL. يمكن قراءته وكتابته باستخدام Tcl_GetEnsembleMappingDict و Tcl_SetEnsembleMappingDict على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يشر الرمز إلى تجميع) ويجب دائمًا التعامل مع القاموس الذي تم الحصول عليه من Tcl_GetEnsembleMappingDict على أنه غير قابل للتغيير حتى لو كان مشتركًا. يجب أن تكون جميع أسماء الأوامر في البادئات المعينة عبر Tcl_SetEnsembleMappingDict مؤهلة بالكامل.
قائمة المعلمات الرسمية قبل الأمر الفرعي (قراءة/كتابة)
قائمة بأسماء المعلمات الرسمية (تستخدم الأسماء فقط عند إنشاء رسائل الخطأ) التي تأتي عند استدعاء التجميع بين اسم التجميع ووسيط الأمر الفرعي. NULL (الافتراضي) يعادل القائمة الفارغة. يمكن قراءتها وكتابتها باستخدام Tcl_GetEnsembleParameterList و Tcl_SetEnsembleParameterList على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يشر الرمز إلى تجميع) ويجب دائمًا التعامل مع القاموس الذي تم الحصول عليه من Tcl_GetEnsembleParameterList على أنه غير قابل للتغيير حتى لو كان مشتركًا.
قائمة الأوامر الفرعية (قراءة/كتابة)
قائمة بجميع أسماء الأوامر الفرعية للتجميع، أو NULL إذا كان يجب اشتقاق هذا من مفاتيح قاموس التعيين (انظر أعلاه) أو (إذا كان هذا أيضًا NULL) من مجموعة الأوامر المصدرة من الفضاء الاسمي المرتبط. يمكن قراءتها وكتابتها باستخدام Tcl_GetEnsembleSubcommandList و Tcl_SetEnsembleSubcommandList على التوالي. نتيجة كلتا الدالتين هي رمز نتيجة Tcl (TCL_OK، أو TCL_ERROR إذا لم يشر الرمز إلى تجميع) ويجب دائمًا التعامل مع القائمة التي تم الحصول عليها من Tcl_GetEnsembleSubcommandList على أنها غير قابلة للتغيير حتى لو كانت مشتركة.
الأمر البادئ لمعالج الأمر الفرعي غير المعروف (قراءة/كتابة)
قائمة من الكلمات لإلحاقها في بداية أي أمر فرعي عندما يكون الأمر الفرعي غير معروف للتجميع (وفقًا لمعالجة البادئة الحالية

ARGUMENTS

Tcl_Interp *interp (in)
Interpreter to use for creating and managing the ensemble.
Tcl_Token ensembleToken (in)
The token representing the ensemble whose property is being queried or modified. The token is obtained from Tcl_CreateEnsemble.
Tcl_Obj *handlerList (in)
A Tcl value that is a list of command names or Tcl script strings. This list defines the handler that will be invoked when an unknown subcommand is encountered.
Tcl_Obj *nsObj (in)
A Tcl object representing the namespace to which the ensemble should be bound.
const char *nsName (in)
The name of the namespace to which the ensemble should be bound.
Tcl_Obj *subcommands (in)
A Tcl value representing the list of subcommands that the ensemble should export.
Tcl_Obj *handler (in)
A Tcl value representing the handler to be invoked when an unknown subcommand is encountered.

DESCRIPTION

These functions provide programmatic access to the properties of Tcl ensembles, which are mechanisms for grouping related commands under a common name. Ensembles allow for more structured and organized command interfaces, especially when dealing with complex applications or packages.

unknownhandler (read-write)
This property specifies the handler to be invoked when an unknown subcommand is encountered within the ensemble. It is represented as a Tcl list of command names or Tcl script strings. The first element of the list is executed. If it returns TCL_ERROR or if it is empty, the next element is tried, and so on. If all elements fail or the list is empty, the default behavior (generating an error message) is used. This property can be read and written using Tcl_GetEnsembleUnknownHandler and Tcl_SetEnsembleUnknownHandler respectively. The returned list should be treated as immutable.
bound namespace (read-only)
The namespace to which the ensemble is bound. When this namespace is deleted, the ensemble will also be deleted. This namespace is also used to determine the list of exported commands if both the mapping dictionary and the subcommand list properties are NULL. This property can be read using Tcl_GetEnsembleNamespace.
mapping dict (read-only)
A dictionary that maps subcommand names to the actual commands that implement them. If this is NULL, the subcommand list is used. This property can be read using Tcl_GetEnsembleMappingDict.
subcommand list (read-only)
A list of subcommand names that the ensemble exports. If this is NULL and the mapping dictionary is also NULL, the exported commands are determined by the export list of the bound namespace. This property can be read using Tcl_GetEnsembleSubcommandList.

The Tcl_CreateEnsemble function creates a new ensemble within the interpreter interp. The ensemble is associated with the namespace named nsName. The subcommands argument is a Tcl list of subcommand names, and handler specifies the unknown handler for the ensemble.

The Tcl_FreeEnsemble function frees the resources associated with the ensemble identified by ensembleToken.

Tcl_SetEnsembleUnknownHandler sets the unknown command handler for the ensemble. The handlerList argument is a Tcl object that represents a list of Tcl commands or scripts. The first element in the list that successfully executes will handle the unknown command. If no handler is found, an error message is generated. A return value of TCL_OK indicates success, while TCL_ERROR indicates that the ensembleToken does not refer to a valid ensemble.

Tcl_GetEnsembleUnknownHandler retrieves the current unknown command handler for the ensemble. The returned value is a Tcl object that should be treated as immutable.

Tcl_SetEnsembleNamespace associates the ensemble with a given namespace. nsObj is a Tcl object representing the namespace. This function returns TCL_OK on success and TCL_ERROR if the token is invalid.

Tcl_GetEnsembleNamespace retrieves the namespace associated with the ensemble. The returned value is a Tcl object representing the namespace.

Tcl_GetEnsembleMappingDict retrieves the mapping dictionary for the ensemble. This dictionary maps subcommand names to their corresponding command implementations.

Tcl_GetEnsembleSubcommandList retrieves the list of subcommands exported by the ensemble.
