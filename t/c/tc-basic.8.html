tc-basic(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

مُصنِّف أساسي في tc(8) Linux مُصنِّف أساسي في tc(8)

الاسم

basic - مرشح تحكم حركة المرور الأساسي

الملخص


tc filter ... basic [ match EMATCH_TREE ] [ action ACTION_SPEC ] [ classid CLASSID ]

الوصف

يتيح المرشح basic تصنيف الحزم باستخدام البنية الأساسية للمطابقة الموسعة.

خيارات

action ACTION_SPEC
تطبيق إجراء من إطار عمل الإجراءات العام على الحزم المتطابقة.
classid CLASSID
دفع الحزم المتطابقة إلى الفئة المحددة بواسطة CLASSID.
match EMATCH_TREE
مطابقة الحزم باستخدام البنية الأساسية للمطابقة الموسعة. انظر tc-ematch(8) لوصف تفصيلي للصيغة المسموح بها في EMATCH_TREE.

انظر أيضاً

tc(8), tc-ematch(8)
