CTGSJA

الغرض:

!>
!> CTGSJA تحسب التحلل القيم المفردة المعمم (GSVD) لمصفوفتين مثلثيتين علويتين (أو شبه منحرفتين) معقدتين A و B.
!>
!> عند الدخول، يُفترض أن للمصفوفتين A و B الأشكال التالية، والتي قد يتم الحصول عليها بواسطة روتين المعالجة المسبقة CGGSVP
!> من مصفوفة عامة M-by-N A ومصفوفة P-by-N B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) إذا كان M-K-L >= 0؛
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) إذا كان M-K-L < 0؛
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> حيث تكون المصفوفة A12 ذات الحجم K-by-K والمصفوفة B13 ذات الحجم L-by-L غير مفردة
!> مثلثية علوية؛ A23 هي L-by-L مثلثية علوية إذا كان M-K-L >= 0،
!> بخلاف ذلك، A23 هي (M-K)-by-L شبه منحرفة علوية.
!>
!> عند الخروج،
!>
!>        U**H *A*Q = D1*( 0 R )،    V**H *B*Q = D2*( 0 R )،
!>
!> حيث U، V، و Q هي مصفوفات وحدوية.
!> R هي مصفوفة مثلثية علوية غير مفردة، و D1
!> و D2 هي مصفوفات "قطرية"، وهي ذات هياكل تالية:
!>
!> إذا كان M-K-L >= 0،
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                    K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> حيث
!>
!>   C = diag( ALPHA(K+1)، ... ، ALPHA(K+L) )،
!>   S = diag( BETA(K+1)،  ... ، BETA(K+L) )،
!>   C**2 + S**2 = I.
!>
!>   يتم تخزين R في A(1:K+L,N-K-L+1:N) عند الخروج.
!>
!> إذا كان M-K-L < 0،
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> حيث
!> C = diag( ALPHA(K+1)، ... ، ALPHA(M) )،
!> S = diag( BETA(K+1)،  ... ، BETA(M) )،
!> C**2 + S**2 = I.
!>
!> R = ( R11 R12 R13 ) مخزن في A(1:M, N-K-L+1:N) و R33 مخزن
!>     (  0  R22 R23 )
!> في B(M-K+1:L,N+M-K-L+1:N) عند الخروج.
!>
!> حساب المصفوفات التحويلية الوحدوية U، V أو Q اختياري. قد يتم تشكيل هذه المصفوفات بشكل صريح، أو قد يتم ضربها لاحقًا في المصفوفات المدخلة U1، V1، أو Q1.
!>

B

!>          عند الدخول، المصفوفة B ذات الحجم P-by-N.
!>          عند الخروج، إذا لزم الأمر، B(M-K+1:L,N+M-K-L+1:N) تحتوي على
!>          جزء من R. انظر الغرض للتفاصيل.
!>

TOLA

!>          TOLA is REAL
!>

TOLB

!>          TOLB is REAL
!>
!>          TOLA و TOLB هما معايير التقارب لإجراء التكرار Jacobi-
!>          Kogbetliantz. بشكل عام، هما نفس القيم المستخدمة في خطوة المعالجة المسبقة، على سبيل المثال
!>              TOLA = MAX(M,N)*norm(A)*MACHEPS،
!>              TOLB = MAX(P,N)*norm(B)*MACHEPS.

ALPHA

!>          ALPHA is REAL array, dimension (N)
!>

BETA

!>          BETA is REAL array, dimension (N)

!>          لـ A و B؛
!>            ALPHA(1:K) = 1،
!>            BETA(1:K)  = 0،
!>          وإذا كان M-K-L >= 0،
!>            ALPHA(K+1:K+L) = diag(C)،
!>            BETA(K+1:K+L)  = diag(S)،
!>          أو إذا كان M-K-L < 0،
!>            ALPHA(K+1:M)= C, ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S, BETA(M+1:
K+L) = 1. !> علاوة على ذلك، إذا كان K+L < N، !> ALPHA(K+L+1:N) = 0 !> BETA(K+L+1:N) = 0. !>

U

!>          U هو مصفوفة مركبة (COMPLEX array)، البعد (LDU,M)

!>          إذا كان JOBU = 'I'، تحتوي U على المصفوفة الوحدوية U؛
