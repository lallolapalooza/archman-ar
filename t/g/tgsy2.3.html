!>
!> CTGSY2 تحل معادلة سيلفستر المعممة
!>
!>             A * R - L * B = scale *  C               (1)
!>             D * R - L * E = scale * F
!>
!> باستخدام BLAS المستوى 1 و 2 ، حيث R و L هما مصفوفتان غير معروفتين بحجم M-by-N،
!> (A, D), (B, E) و (C, F) هي أزواج مصفوفات معطاة بحجم M-by-M،
!> N-by-N و M-by-N، على التوالي. A, B, D و E هي مصفوفات مثلثية عليا
!> (أي ، (A,D) و (B,E) في شكل شتور المعمم).
!>
!> الحل (R, L) يكتب فوق (C, F). 0 <= SCALE <= 1 هو عامل قياس
!> للإخراج تم اختياره لتجنب الفائض.
!>
!> في تمثيل المصفوفة ، يطابق حل المعادلة (1) حل
!> Zx = scale * b ، حيث Z معرفة كـ
!>
!>        Z = [ kron(In, A)  -kron(B**H, Im) ]             (2)
!>            [ kron(In, D)  -kron(E**H, Im) ],
!>
!> Ik هي المصفوفة الوحدة بحجم k و X**H هي منقول X.
!> kron(X, Y) هو حاصل كرونيكر بين المصفوفتين X و Y.
!>
!> إذا كان TRANS = 'C'، يتم حل y في النظام المترافق (transposed) Z**H*y = scale*b
!> ، والذي يعادل حل R و L في
!>
!>             A**H * R  + D**H * L   = scale * C           (3)
!>             R  * B**H + L  * E**H  = scale * -F
!>
!> هذه الحالة تستخدم لحساب تقدير لـ Dif[(A, D), (B, E)] =
!> = sigma_min(Z) باستخدام الاتصال العكسي مع CLACON.
!>
!> CTGSY2 أيضا (IJOB >= 1) يساهم في حساب CTGSYL
!> لحد علوي على الفصل بين أزواج المصفوفات. ثم
!> (A, D) و (B, E) هي مصفوفات فرعية لأزواج مصفوفات في
!> CTGSYL.
!>

Detailed Description

This routine is called by the driver routine ZTGSYL to compute the solutions of the generalized Sylvester equation:

op(A) * R * op(E) + op(D) * R * op(B) = op(C) * op(F) * op(C)

where R and L are the solutions for matrices C and F, respectively. op(X) is either X or conjg(X).

The matrices A, D are upper triangular and the matrices B, E are upper triangular.

IJOB = 0: Solve the generalized Sylvester equation for R and L.

IJOB = 1: Compute the RIF-estimate, i.e. the relative residual norm estimate for the solution R. Note that the input matrices C and F are overwritten by the solution R.

If the matrix is nonsingular, the solution is computed in approximately (M*N*(M+N)) operations.

The generalized Sylvester equation is solved by reducing the problem to a triangular structure and then using back substitution.

The routine computes a scaling factor SCALE in order to control the effect of rounding errors on the solution. If the matrix is close to singular, the input matrices A, B, D, E are modified.

!>          The leading dimension of the matrix C. LDC >= max(1, M).

D 

!>          D is COMPLEX*16 array, dimension (LDD, M)
!>          On entry, D contains an upper triangular matrix.

LDD 

!>          LDD is INTEGER
!>          The leading dimension of the matrix D. LDD >= max(1, M).

E 

!>          E is COMPLEX*16 array, dimension (LDE, N)
!>          On entry, E contains an upper triangular matrix.

LDE 

!>          LDE is INTEGER
!>          The leading dimension of the matrix E. LDE >= max(1, N).

F 

!>          F is COMPLEX*16 array, dimension (LDF, N)
!>          On entry, F contains the right-hand-side of the second matrix
!>          equation in (1).
!>          On exit, if IJOB = 0, F has been overwritten by the solution
!>          L.

LDF 

!>          LDF is INTEGER
!>          The leading dimension of the matrix F. LDF >= max(1, M).

SCALE 

!>          SCALE is DOUBLE PRECISION
!>          On exit, 0 <= SCALE <= 1. If 0 < SCALE < 1, the solutions
!>          R and L (C and F on entry) will hold the solutions to a
!>          slightly perturbed system but the input matrices A, B, D and
!>          E have not been changed. If SCALE = 0, R and L will hold the
!>          solutions to the homogeneous system with C = F = 0.
!>          Normally, SCALE = 1.

RDSUM 

!>          RDSUM is DOUBLE PRECISION
!>          On entry, the sum of squares of computed contributions to
!>          the Dif-estimate under computation by ZTGSYL, where the
!>          scaling factor RDSCAL (see below) has been factored out.
!>          On exit, the corresponding sum of squares updated with the
!>          contributions from the current sub-system.
!>          If TRANS = 'T' RDSUM is not touched.
!>          NOTE: RDSUM only makes sense when ZTGSY2 is called by
!>          ZTGSYL.

RDSCAL 

!>          RDSCAL is DOUBLE PRECISION
!>          On entry, scaling factor used to prevent overflow in RDSUM.
!>          On exit, RDSCAL is updated w.r.t. the current contributions
!>          in RDSUM.
!>          If TRANS = 'T', RDSCAL is not touched.
!>          NOTE: RDSCAL only makes sense when ZTGSY2 is called by
!>          ZTGSYL.

INFO 

!>          INFO is INTEGER
!>          On exit, if INFO is set to
!>            =0: Successful exit
!>            <0: If INFO = -i, input argument number i is illegal.
!>            >0: The matrix pairs (A, D) and (B, E) have common or very
!>                close eigenvalues.
