CTGSEN

الغرض:

!>
!> CTGSEN تعيد ترتيب تحلل Schur المعمم لزوج المصفوفات المعقدة (A, B) (من حيث
!> التحويل الوحدوي المكافئ Q**H * (A, B) * Z)، بحيث تظهر مجموعة مختارة من
!> القيم الذاتية في القطاعات القطرية الأمامية للزوج (A,B). الأعمدة الأمامية
!> لـ Q و Z تشكل قواعد وحدوية لملتقيات المتجهات الذاتية اليسرى واليمنى المقابلة
!> (ملتقيات منحلة). يجب أن تكون (A, B) في صيغة Schur المعممة القياسية، أي أن A و B
!> كلتيهما مثلثيتان علويتان.
!>
!> CTGSEN تحسب أيضًا القيم الذاتية المعممة
!>
!>          w(j)= ALPHA(j) / BETA(j)
!>
!> لزوج المصفوفات المعاد ترتيبها (A, B).
!>
!> اختياريًا، تقوم الروتين بحساب تقديرات لأرقام الشروط المتبادلة للقيم الذاتية
!> والملتقيات الذاتية. هذه هي Difu[(A11,B11), (A22,B22)] و Difl[(A11,B11), (A22,B22)]،
!> أي الفصل (الفصول) بين أزواج المصفوفات (A11, B11) و (A22,B22) التي تتوافق
!> مع المجموعة المختارة والقيم الذاتية خارج المجموعة، على التوالي، ومعايير
!>  على الملتقيات اليسرى واليمنى بالنسبة للمجموعة المختارة في القطاع (1,1).
!>
!>

subroutine   ctgsen (integer ijob, logical wantq, logical wantz, logical, dimension( * )   select, integer n, complex, dimension( lda, * ) a, integer lda,   complex, dimension( ldb, * ) b, integer ldb, complex, dimension( * )   alpha, complex, dimension( ldq, * ) q, integer ldq, complex, dimension(   ldz, * ) z, integer ldz, integer m, complex pl, complex pr, complex,   dimension( * ) dif, complex, dimension( * ) work, integer lwork, integer,   dimension( * ) iwork, integer liwork, integer info)


CTGSEN


Purpose:




!>
!> CTGSEN reorders the generalized Schur decomposition of a complex matrix
!> pair (A, B) so that a selected block of eigenvalues appears in the
!> leading diagonal blocks of A and B. The matrices Q and Z are updated
!> so that the matrices (A, B) are factorized as
!>
!>              A = Q * A * Z**H
!>              B = Q * B * Z**H
!>
!> CTGSEN also computes the generalized eigenvalues w(j) = alpha(j)/beta(j)
!> and optionally the Schur vectors Z and Q.
!>
!> Additionally, CTGSEN can compute the reciprocal condition numbers for
!> the selected eigenvalues and their corresponding left and right
!> eigenvectors.
!> 




Parameters


IJOB

!>          IJOB is INTEGER
!>          Specifies the course of action:
!>          = 0  Do nothing. Return immediately.
!>          = 1  Compute the norms of the deflating subspaces.
!>          = 2  Compute the selected approximate error bounds for the
!>               generalized eigenvalues.
!>          = 3  Compute the condition numbers for the selected
!>               generalized eigenvalues and the deflating subspaces.
!>          = 4  Compute all information listed above.
!>          = 5  Compute information listed in IJOB=3 together with
!>               the condition number for the pairs of
!>               (A11,B11) and (A22,B22).
!> 


WANTQ


!>          WANTQ is LOGICAL
!>          Specifies whether to compute the Schur vectors Q.
!> 


WANTZ


!>          WANTZ is LOGICAL
!>          Specifies whether to compute the Schur vectors Z.
!> 


SELECT


!>          SELECT is LOGICAL array, dimension (N)
!>          Specifies the eigenvalues to be selected. For each j = 1:N,
!>          if SELECT(j) is true, then the j-th eigenvalue is selected.
!> 


N


!>          N is INTEGER
!>          The order of the matrix pair (A, B).  N >= 0.
!> 


A


!>          A is COMPLEX array, dimension (LDA, N)
!>          On entry, A contains the upper quasi-triangular matrix from
!>          the generalized Schur decomposition of a matrix pair.
!>          On exit, A is permuted so that the selected eigenvalues are
!>          in the leading diagonal blocks.
!> 


LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1, N).
!> 


B


!>          B is COMPLEX array, dimension (LDB, N)
!>          On entry, B contains the upper triangular matrix from the
!>          generalized Schur decomposition of a matrix pair.
!>          On exit, B is permuted so that the selected eigenvalues are
!>          in the leading diagonal blocks.
!> 


LDB


!>          LDB is INTEGER
!>          The leading dimension of the array B. LDB >= max(1, N).
!> 


ALPHA


!>          ALPHA is COMPLEX array, dimension (N)
!>          On exit, ALPHA and BETA contain the diagonals of the pair
!>          of matrices A and B, computed from the generalized Schur
!>          decomposition. The generalized eigenvalues are computed as
!>          alpha(j)/beta(j).
!> 


Q


!>          Q is COMPLEX array, dimension (LDQ, N)
!>          On exit, if WANTQ is .TRUE., Q is an orthonormal basis for the
!>          left eigenvectors of the matrix pair (A, B) corresponding
!>          to the selected eigenvalues.
!> 


LDQ


!>          LDQ is INTEGER
!>          The leading dimension of the array Q. LDQ >= 1. If
!>          wantq is .TRUE., LDQ >= max(1, N).
!> 


Z


!>          Z is COMPLEX array, dimension (LDZ, N)
!>          On exit, if WANTZ is .TRUE., Z is an orthonormal basis for the
!>          right eigenvectors of the matrix pair (A, B) corresponding
!>          to the selected eigenvalues.
!> 


LDZ


!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1. If
!>          wantz is .TRUE., LDZ >= max(1, N).
!> 


M


!>          M is INTEGER
!>          The number of selected eigenvalues. M is the number of TRUE
!>          values in the array SELECT.
!> 


PL


!>          PL is COMPLEX
!>          If IJOB = 2 or 4, PL is an upper bound on the angle between
!>          the left eigenvectors of the selected block (A11, B11) and
!>          the left eigenvectors of the left block (A22, B22).
!>          If IJOB = 3 or 5, PL is the reciprocal condition number of
!>          the deflating subspace formed by the eigenvectors of the
!>          selected block of eigenvalues.
!> 


PR


!>          PR is COMPLEX
!>          If IJOB = 2 or 4, PR is an upper bound on the angle between
!>          the right eigenvectors of the selected block (A11, B11) and
!>          the right eigenvectors of the right block (A22, B22).
!>          If IJOB = 3 or 5, PR is the reciprocal condition number of
!>          the deflating subspace formed by the eigenvectors of the
!>          selected block of eigenvalues.
!> 


DIF


!>          DIF is COMPLEX array, dimension (2)
!>          If IJOB = 1, 3, 4 or 5, DIF is the reciprocal condition
!>          number of the selected generalized eigenspace corresponding
!>          to the pair of matrix blocks (A11, B11).
!>          DIF(1) = Difu[(A11, B11), (A22, B22)]
!>          DIF(2) = Difl[(A11, B11), (A22, B22)]
!>
!>          If M = 0 or N, DIF(1:2) = F-norm([A, B]).
!>          If IJOB = 0 or 1, DIF is not referenced.
!> 


WORK


!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> 


LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= 1
!>          If IJOB = 1, 2 or 4, LWORK >=  2*M*(N-M)
!>          If IJOB = 3 or 5, LWORK >=  4*M*(N-M)
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!> 


IWORK


!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!> 


LIWORK


!>          LIWORK is INTEGER
!>          The dimension of the array IWORK. LIWORK >= 1.
!>          If IJOB = 1, 2 or 4, LIWORK >=  N+2;
!>          If IJOB = 3 or 5, LIWORK >= MAX(N+2, 2*M*(N-M));
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!> 


INFO


!>          INFO is INTEGER
!>            =0: Successful exit.
!>            <0: If INFO = -i, the i-th argument had an illegal value.
!>            =1: Reordering of (A, B) failed because the transformed
!>                matrix pair (A, B) would be too far from generalized
!>                Schur form; the problem is very ill-conditioned.
!>                (A, B) may have been partially reordered.
!>                If requested, 0 is returned in DIF(*), PL and PR.
!>

Further Details:




!>
!>  CTGSEN first collects the selected eigenvalues by computing unitary
!>  U and W that move them to the top left corner of (A, B). In other
!>  words, the selected eigenvalues are the eigenvalues of (A11, B11) in
!>
!>              U**H*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!>  where N = n1+n2 and U**H means the conjugate transpose of U. The first
!>  n1 columns of U and W span the specified pair of left and right
!>  eigenspaces (deflating subspaces) of (A, B).
!>
!>  If (A, B) has been obtained from the generalized real Schur
!>  decomposition of a matrix pair (C, D) = Q*(A, B)*Z', then the
!>  reordered generalized Schur form of (C, D) is given by
!>
!>           (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,
!>
!>  and the first n1 columns of Q*U and Z*W span the corresponding
!>  deflating subspaces of (C, D) (Q and Z store Q*U and Z*W, resp.).
!>
!>  Note that if the selected eigenvalue is sufficiently ill-conditioned,
!>  then its value may differ significantly from its value before
!>  reordering.
!>
!>  The reciprocal condition numbers of the left and right eigenspaces
!>  spanned by the first n1 columns of U and W (or Q*U and Z*W) may
!>  be returned in DIF(1:2), corresponding to Difu and Difl, resp.
!>
!>  The Difu and Difl are defined as:
!>
!>       Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!>  and
!>       Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!>  where sigma-min(Zu) is the smallest singular value of the
!>  (2*n1*n2)-by-(2*n1*n2) matrix
!>
!>       Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
!>            [ kron(In2, B11)  -kron(B22**H, In1) ].
!>
!>  Here, Inx is the identity matrix of size nx and A22**H is the
!>  conjugate transpose of A22. kron(X, Y) is the Kronecker product between
!>  the matrices X and Y.
!>
!>  When DIF(2) is small, small changes in (A, B) can cause large changes
!>  in the deflating subspace. An approximate (asymptotic) bound on the
!>  maximum angular error in the computed deflating subspaces is
!>
!>       EPS * norm((A, B)) / DIF(2),
!>
!>  where EPS is the machine precision.
!>
!>  The reciprocal norm of the projectors on the left and right
!>  eigenspaces associated with (A11, B11) may be returned in PL and PR.
!>  They are computed as follows. First we compute L and R so that
!>  P*(A, B)*Q is block diagonal, where
!>
!>       P = ( I -L ) n1           Q = ( I R ) n1
!>           ( 0  I ) n2    and        ( 0 I ) n2
!>             n1 n2                    n1 n2
!>
!>  and (L, R) is the solution to the generalized Sylvester equation
!>
!>       A11*R - L*A22 = -A12
!>       B11*R - L*B22 = -B12
!>
!>  Then PL = (F-norm(L)**2+1)**(-1/2) and PR = (F-norm(R)**2+1)**(-1/2).
!>  An approximate (asymptotic) bound on the average absolute error of
!>  the selected eigenvalues is
!>
!>       EPS * norm((A, B)) / PL.
!>
!>  There are also global error bounds which valid for perturbations up
!>  to a certain restriction:  A lower bound (x) on the smallest
!>  F-norm(E,F) for which an eigenvalue of (A11, B11) may move and
!>  coalesce with an eigenvalue of (A22, B22) under perturbation (E,F),
!>  (i.e. (A + E, B + F), is
!>
!>   x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!>  An approximate bound on x can be computed from DIF(1:2), PL and PR.
!>
!>  If y = ( F-norm(E,F) / x) <= 1, the angles between the perturbed
!>  (L', R') and unperturbed (L, R) left and right deflating subspaces
!>  associated with the selected cluster in the (1,1)-blocks can be
!>  bounded as
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!>  See LAPACK User's Guide section 4.11 or the following references
!>  for more information.
!>
!>  Note that if the default method for computing the Frobenius-norm-
!>  based estimate DIF is not wanted (see CLATDF), then the parameter
!>  IDIFJB (see below) should be changed from 3 to 4 (routine CLATDF
!>  (IJOB = 2 will be used)). See CTGSYL for more details.
!>

DESCRIPTION


STGSEN reorders the generalized real Schur decomposition of a real matrix pair (A, B) (in terms of an orthonormal equivalence transformation QT*(A,B)*Z), so that a selected cluster of eigenvalues appears in the leading diagonal blocks of the upper quasi-triangular matrix A and the upper triangular B. The leading columns of Q and Z form orthonormal bases of the corresponding left and right eigenspaces (deflating subspaces). (A, B) must be in generalized real Schur canonical form (as returned by SGGES), i.e. A is block upper triangular with 1-by-1 and 2-by-2 diagonal blocks. B is upper triangular.


STGSEN also computes the generalized eigenvalues


             w(j) = (ALPHAR(j) + i*ALPHAI(j))/BETA(j)



of the reordered matrix pair (A, B).


Optionally, STGSEN computes the estimates of reciprocal condition numbers for eigenvalues and eigenspaces. These are Difu[(A11,B11),(A22,B22)] and Difl[(A11,B11),(A22,B22)], i.e. the separation(s) between the matrix pairs (A11, B11) and (A22,B22) that correspond to the selected cluster and the eigenvalues outside the cluster, resp., and norms of 


 x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).



An approximate bound on x can be computed from DIF(1:2), PL and PR.


If y = ( F-norm(E,F) / x) <= 1, the angles between the perturbed (L', R') and unperturbed (L, R) left and right deflating subspaces associated with the selected cluster in the (1,1)-blocks can be bounded as


  max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
  max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))



See LAPACK User's Guide section 4.11 or the following references for more information.


Note that if the default method for computing the Frobenius-norm- based estimate DIF is not wanted (see DLATDF), then the parameter IDIFJB (see below) should be changed from 3 to 4 (routine DLATDF (IJOB = 2 will be used)). See DTGSYL for more details.

!>           Difu and Difl. If IJOB = 3 or 5, DIF(1:2) are 1-norm-based
!>           estimates of Difu and Difl, computed using reversed
!>           communication with ZLACN2.
!>           If M = 0 or N, DIF(1:2) = F-norm([A, B]).
!>           If IJOB = 0 or 1, DIF is not referenced.
!>
!> WORK
!>           WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
!>           On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>
!> LWORK
!>           LWORK is INTEGER
!>           The dimension of the array WORK. LWORK >= 1
!>           If IJOB = 1, 2 or 4, LWORK >= 2*M*(N-M)
!>           If IJOB = 3 or 5, LWORK >= 4*M*(N-M)
!>
!>           If LWORK = -1, then a workspace query is assumed; the routine
!>           only calculates the optimal size of the WORK array, returns
!>           this value as the first entry of the WORK array, and no error
!>           message related to LWORK is issued by XERBLA.
!>
!> IWORK
!>           IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>           On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>
!> LIWORK
!>           LIWORK is INTEGER
!>           The dimension of the array IWORK. LIWORK >= 1.
!>           If IJOB = 1, 2 or 4, LIWORK >= N+2;
!>           If IJOB = 3 or 5, LIWORK >= MAX(N+2, 2*M*(N-M));
!>
!>           If LIWORK = -1, then a workspace query is assumed; the
!>           routine only calculates the optimal size of the IWORK array,
!>           returns this value as the first entry of the IWORK array, and
!>           no error message related to LIWORK is issued by XERBLA.
!>
!> INFO
!>           INFO is INTEGER
!>             =0: Successful exit.
!>             <0: If INFO = -i, the i-th argument had an illegal value.
!>             =1: Reordering of (A, B) failed because the transformed
!>                 matrix pair (A, B) would be too far from generalized
!>                 Schur form; the problem is very ill-conditioned.
!>                 (A, B) may have been partially reordered.
!>                 If requested, 0 is returned in DIF(*), PL and PR.

;==============================================================================
;
; Author
; ======
;
; Univ. of Tennessee
; Univ. of California Berkeley
; Univ. of Colorado Denver
; NAG Ltd.
;
;==============================================================================
;
; Further Details
; ===============
;
!>
!> ZTGSEN first collects the selected eigenvalues by computing unitary
!> U and W that move them to the top left corner of (A, B). In other
!> words, the selected eigenvalues are the eigenvalues of (A11, B11) in
!>
!>              U**H*(A, B)*W = (A11 A12) (B11 B12) n1
!>                              ( 0  A22),( 0  B22) n2
!>                                n1  n2    n1  n2
!>
!> where N = n1+n2 and U**H means the conjugate transpose of U. The first
!> n1 columns of U and W span the specified pair of left and right
!> eigenspaces (deflating subspaces) of (A, B).
!>
!> If (A, B) has been obtained from the generalized real Schur
!> decomposition of a matrix pair (C, D) = Q*(A, B)*Z**H, then the
!> reordered generalized Schur form of (C, D) is given by
!>
!>          (C, D) = (Q*U)*(U**H *(A, B)*W)*(Z*W)**H,
!>
!> and the first n1 columns of Q*U and Z*W span the corresponding
!> deflating subspaces of (C, D) (Q and Z store Q*U and Z*W, resp.).
!>
!> Note that if the selected eigenvalue is sufficiently ill-conditioned,
!> then its value may differ significantly from its value before
!> reordering.
!>
!> The reciprocal condition numbers of the left and right eigenspaces
!> spanned by the first n1 columns of U and W (or Q*U and Z*W) may
!> be returned in DIF(1:2), corresponding to Difu and Difl, resp.
!>
!> The Difu and Difl are defined as:
!>
!>      Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
!> and
!>      Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],
!>
!> where sigma-min(Zu) is the smallest singular value of the
!> (2*n1*n2)-by-(2*n1*n2) matrix
!>
!>      Zu = [ kron(In2, A11)  -kron(A22**H, In1) ]
!>           [ kron(In2, B11)  -kron(B22**H, In1) ].
!>
!> Here, Inx is the identity matrix of size nx and A22**H is the
!> conjugate transpose of A22. kron(X, Y) is the Kronecker product between
!> the matrices X and Y.
!>
!> When DIF(2) is small, small changes in (A, B) can cause large changes
!> in the deflating subspace. An approximate (asymptotic) bound on the
!> maximum angular error in the computed deflating subspaces is
!>
!>      EPS * norm((A, B)) / DIF(2),
!>
!> where EPS is the machine precision.
!>
!> The reciprocal norm of the projectors on the left and right
!> eigenspaces associated with (A11, B11) may be returned in PL and PR.
!> They are computed as follows. First we compute L and R so that
!> P*(A, B)*Q is block diagonal, where
!>
!>      P = ( I -L ) n1           Q = ( I R ) n1
!>          ( 0  I ) n2    and        ( 0 I ) n2
!>            n1 n2                    n1 n2
!>
!> and (L, R) is the solution to the generalized Sylvester equation
!>
!>      A11*R - L*A22 = -A12
!>      B11*R - L*B22 = -B12
!>
!> Then PL = (F-norm(L)**2+1)**(-1/2) and PR = (F-norm(R)**2+1)**(-1/2).
!> An approximate (asymptotic) bound on the average absolute error of
!> the selected eigenvalues is
!>
!>      EPS * norm((A, B)) / PL.
!>
!> There are also global error bounds which valid for perturbations up
!> to a certain restriction:  A lower bound (x) on the smallest
!> F-norm(E,F) for which an eigenvalue of (A11, B11) may move and
!!> coalesce with an eigenvalue of (A22, B22) under perturbation (E,F),
!> (i.e. (A + E, B + F), is
!>
!>  x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).
!>
!> An approximate bound on x can be computed from DIF(1:2), PL and PR.
!>
!> If y = ( F-norm(E,F) / x) <= 1, the angles between the perturbed
!> (L', R') and unperturbed (L, R) left and right deflating subspaces
!> associated with the selected cluster in the (1,1)-blocks can be
!> bounded as
!>
!>   max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
!>   max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))
!>
!> See LAPACK User's Guide section 4.11 or the following references
!> for more information.
!>
!> Note that if the default method for computing the Frobenius-norm-
!> based estimate DIF is not wanted (see ZLATDF), then the parameter
!> IDIFJB (see below) should be changed from 3 to 4 (routine ZLATDF
!> (IJOB = 2 will be used)). See ZTGSYL for more details.
!>
;==============================================================================

Detailed Description


This subroutine is part of the LAPACK routine.


The purpose of the subroutine TGSE is to compute the generalized Schur
    decomposition of a regular pair (A, B).


Input arguments:


  NI: INTEGER
      NI = NL + NR. The number of eigenvalues of the pair (A, B)
      which are to be selected. NI is the number of elements in the
      array SELECT which are set to .TRUE.

  NJ: INTEGER
      NJ = NL + NR. The number of eigenvalues of the pair (A, B)
      which are to be selected. NJ is the number of elements in the
      array SELECT which are set to .TRUE.

  NK: INTEGER
      NK = NL + NR. The number of eigenvalues of the pair (A, B)
      which are to be selected. NK is the number of elements in the
      array SELECT which are set to .TRUE.

  A: (type is DOUBLE PRECISION or COMPLEX*)
     The first matrix of the pair (A, B).

  LDA: INTEGER
       The leading dimension of the array A.

  B: (type is DOUBLE PRECISION or COMPLEX*)
     The second matrix of the pair (A, B).

  LDB: INTEGER
       The leading dimension of the array B.

  SELECT: LOGICAL array, dimension (N)
          On input, the elements of SELECT corresponding to the eigenvalues
          which are to be selected are set to .TRUE.

  Q: (type is DOUBLE PRECISION or COMPLEX*)
     On input, Q is an orthogonal (or unitary) matrix

  LDQ: INTEGER
       The leading dimension of the array Q.

  Z: (type is DOUBLE PRECISION or COMPLEX*)
     On input, Z is an orthogonal (or unitary) matrix

  LDZ: INTEGER
       The leading dimension of the array Z.

  WORK: (type is DOUBLE PRECISION or COMPLEX*)
        A workspace array used by the subroutine.

  LWORK: INTEGER
         The dimension of the array WORK.

  IWORK: INTEGER array, dimension (N)
         A workspace array used by the subroutine.

  INFO: INTEGER
        On exit, INFO is an integer with the value 0 if the subroutine
        runs successfully.
