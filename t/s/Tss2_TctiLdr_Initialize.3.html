Tss2_TctiLdr_Initialize(3)

الحزمة: tpm2-tss

التراخيص: BSD-2-Clause

Tss2_TctiLdr_Initialize(3) دليل وظائف المكتبة Tss2_TctiLdr_Initialize(3)

الاسم

Tss2_TctiLdr_Initialize, Tss2_TctiLdr_Initialize_Ex - تهيئة وإنشاء سياق TCTI.

الملخص

#include <tss2/tss2_tctildr.h>

TSS2_RC Tss2_TctiLdr_Initialize (const char *nameConf, TSS2_TCTI_CONTEXT **context);

TSS2_RC Tss2_TctiLdr_Initialize_Ex (const char *name, const char *conf, TSS2_TCTI_CONTEXT **context);

الوصف

تقوم وظائف Tss2_TctiLdr_Initialize() و Tss2_TctiLdr_Initialize_Ex() بتهيئة سياق TCTI المستخدم للتواصل مع TPM2 أو بعض المكونات الوسيطة في مكدس برامج TCG TPM2.

تأخذ Tss2_TctiLdr_Initialize() سلسلة نصية واحدة تشفر كل من اسم مكتبة TCTI التي يرغب المتصل في إنشائها وتكوينها المطلوب في المعلمة nameConf. nameConf هي سلسلة نصية تتكون من سلسلتين فرعيتين: name و conf على التوالي. يتم دمج هاتين السلسلتين الفرعيتين مع name أولاً، مفصولة بحرف ':' / نقطتين رأسيتين واحد: 'name:conf'. استشر القسم بعنوان TCTI CONFIG للحصول على معلومات حول ترميز هذه السلاسل النصية. تستخدم المعلمة context لإرجاع مرجع لسياق TCTI الذي تم إنشاؤه بواسطة الوظيفة.

تتصرف Tss2_TctiLdr_Initialize_Ex() بشكل متطابق مع وظيفة Tss2_TctiLdr_Initialize() باستثناء أن اسم وتكوين TCTI يتم تمريرهما كسلاسل نصية منفصلة. يتم وصف ترميز هذه السلاسل النصية في قسم TCTI_CONFIG.

تكوين TCTI

إذا كانت السلسلة النصية name هي NULL أو سلسلة فارغة، فستختار وظائف التهيئة TCTI افتراضي مناسب للمنصة. في Linux، هذا يعني أولاً محاولة تحميل مكتبة باسم libtss2-tcti-default.so. هذا هو عنصر نائب لتوفير التوزيعات TCTI افتراضي خاص بالتوزيع. يوصى بأن يكون هذا رابطًا رمزيًا لمكتبة TCTI أخرى مثبتة. إذا فشلت محاولات تحميل كائن الكائن المشترك هذا، فستحاول التطبيق TCTIs المعروفة بالترتيب التالي:

•
libtss2-tcti-tabrmd.so.0
•
libtss2-tcti-device.so.0
•
libtss2-tcti-mssim.so.0

عندما لا تكون السلسلة النصية name فارغة أو NULL، ستحاول التطبيق استخدام dlopen لتحميل مكتبة بالاسم المحدد. إذا فشل ذلك، تفترض التطبيق أنها تلقت اسمًا مختصرًا وستحاول تحميل المكتبات بالاسم مع التغييرات التالية:

•
<name>
•
libtss2-tcti-<name>.so.0
•
libtss2-tcti-<name>.so

لا يتم تفسير السلسلة النصية config بواسطة وظائف تهيئة TctiLdr ويتم تمريرها دون تغيير إلى وظيفة التهيئة لـ TCTI المحدد. تنسيق هذه السلسلة النصية خاص بـ TCTI.

Tss2_TctiLdr_Initialize يتم تمريرها إلى وظيفة السلاسل النصية name و conf كمعلمة واحدة. في هذه الحالة، يتم ربط السلاسل النصية name و conf مع حرف ':' / نقطتين رأسيتين واحد يفصل بينهما.

لمناقشة أكثر تفصيلاً لواجهة برمجة تطبيقات TCTILDR، راجع "مواصفات واجهة نقل أوامر TPM2 (TCTI) الخاصة بـ TCG 2.0".

قيمة الإرجاع

سترجع المكالمة الناجحة لهذه الوظيفة TSS2_RC_SUCCESS. ستنتج المكالمة غير الناجحة رمز استجابة موصوف في القسم الأخطاء.

الأخطاء

TSS2_TCTI_RC_MEMORY يتم إرجاعه إذا فشل تخصيص الذاكرة

TSS2_TCTI_RC_NOT_SUPPORTED يتم إرجاعه عندما يفشل المحمل في تحديد موقع مكتبة TCTI بالاسم name المقدم

TSS2_TCTI_RC_IO_ERROR يتم إرجاعه إذا حدث فشل في آلية تحميل المكتبة الأساسية

TSS2_TCTI_RC_BAD_REFERENCE يتم إرجاعه إذا كانت المعلمة tctiContext هي NULL

مثال

مثال على الكود.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_CONTEXT *ctx = NULL;
TSS2_RC rc = Tss2_TctiLdr_Initialize (NULL, &ctx);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "Initialization of default TCTI context failed with "
             "response code: 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
