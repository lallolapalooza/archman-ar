Tss2_Tcti_Cmd_Init(3)

الحزمة: tpm2-tss

التراخيص: BSD-2-Clause

Tss2_Tcti_Cmd_Init(3) دليل وظائف المكتبة Tss2_Tcti_Cmd_Init(3)

الاسم

Tss2_Tcti_Cmd_Init - وظيفة التهيئة لمكتبة Cmd TCTI.

الملخص

#include <tss2/tss2_tcti_cmd.h>

TSS2_RC Tss2_Tcti_Cmd_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *contextSize, const char *conf);

تقوم وظيفة Tss2_Tcti_Cmd_Init() بتهيئة سياق TCTI المستخدم للتواصل مع عملية فرعية محددة في سلسلة التهيئة. تستخدم إرسال واستقبال TCTI مدخلات/مخرجات العملية الفرعية القياسية على التوالي.

الوصف

تحاول Tss2_Tcti_Cmd_Init() تهيئة tcti_context مخصص من قبل المستدعي بالحجم size باستخدام سلسلة التهيئة conf المقدمة من المستدعي. نظرًا لأن tcti_context يجب أن يكون مخزنًا مؤقتًا مخصصًا من قبل المستدعي، يحتاج المستدعي إلى معرفة حجم المخزن المؤقت الذي تتطلبه مكتبة TCTI. يمكن اكتشاف الحد الأدنى لحجم هذا السياق عن طريق توفير NULL لـ tcti_context ومعامل size غير NULL. ستقوم وظيفة التهيئة بعد ذلك بملء المعامل size بالحد الأدنى لحجم مخزن tcti_context المؤقت. يجب على المستدعي بعد ذلك تخصيص مخزن مؤقت بهذا الحجم (أو أكبر) واستدعاء Tss2_Tcti_Cmd_Init () مرة أخرى مع توفير tcti_context المخصص حديثًا وحجم هذا السياق في المعامل size. هذا النمط شائع لجميع وظائف تهيئة TCTI. نقدم مثالًا لهذا النمط باستخدام وظيفة Tss2_Tcti_Cmd_Init() في القسم المسمى مثال.

المعامل conf هو سلسلة C تستخدم لتهيئة سياق TCTI. سلسلة التهيئة هذه هي الأمر المستخدم لـ popen(3). لا يمكن أن تكون سلسلة conf فارغة لـ TCTI هذا.

بمجرد التهيئة، يكشف سياق TCTI الذي تم إرجاعه عن واجهة برمجة التطبيقات المحددة لمجموعة الحوسبة الموثوقة (TCG) لأدنى مستوى اتصال مع TPM. باستخدام واجهة برمجة التطبيقات هذه، يمكن للمستدعي تبادل (إرسال / استقبال) أوامر TPM2 وردود المخازن المؤقتة مع خدمة يمكنها تبادل أوامر TPM2 وردود المخازن المؤقتة. في معظم الحالات، سيقوم المستدعي بتهيئة سياق باستخدام هذه الوظيفة قبل تمرير السياق إلى واجهة برمجة تطبيقات مستوى أعلى مثل واجهة برمجة تطبيقات النظام (SAPI) أو واجهة برمجة تطبيقات النظام المحسنة (ESAPI) أو واجهة برمجة تطبيقات الميزات (FAPI) وبعد ذلك لا يلمسها مرة أخرى.

لمناقشة أكثر تفصيلاً لواجهة برمجة تطبيقات TCTI، راجع "مواصفات واجهة نقل أوامر TPM2 لواجهة برمجة تطبيقات مستوى النظام الخاصة بـ TSS" كما نشرتها TCG: https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

قيمة الإرجاع

سيؤدي الاستدعاء الناجح لـ Tss2_Tcti_Cmd_Init() إلى إرجاع TSS2_RC_SUCCESS. سيؤدي الاستدعاء غير الناجح إلى إنتاج رمز استجابة موصوف في القسم الأخطاء.

الأخطاء

يتم إرجاع TSS2_TCTI_RC_BAD_VALUE إذا كان كل من المعاملين tcti_context و size فارغين (NULL)، أو إذا كان المعامل config فارغًا (NULL).

مثال

جزء تهيئة TCTI:

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_mssim.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
const char *conf = "XXX TODO SAMPLE"
rc = Tss2_Tcti_Cmd_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل الحصول على حجم التخصيص لسياق mssim TCTI "
             " : 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "فشل تخصيص سياق TCTI: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Cmd_Init (&tcti_context, &size, conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل تهيئة سياق mssim TCTI: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
