Tss2_Tcti_Tabrmd_Init(3)

الحزمة: tpm2-abrmd

التراخيص: BSD-2-Clause

TSS2_TCTI_TABRMD_INIT(3) مجموعة برامج TPM2 TSS2_TCTI_TABRMD_INIT(3)

الاسم

Tss2_Tcti_Tabrmd_Init - دالة التهيئة لمكتبة tpm2-abrmd TCTI.

الملخص

تُستخدم الدالة Tss2_Tcti_Tabrmd_Init() لتهيئة سياق TCTI للتواصل مع tpm2-abrmd(8).

#include <tcti/tcti-tabrmd.h>

TSS2_RC Tss2_Tcti_Tabrmd_Init (TSS2_TCTI_CONTEXT *tcti_context, size_t *size, const char *conf);

الوصف

تحاول Tss2_Tcti_Tabrmd_Init() تهيئة tcti_context مخصص من قبل المستدعي بحجم size مع الإعدادات المحددة في سلسلة الإعدادات conf. . نظرًا لأن tcti_context يجب أن يكون مخزنًا مؤقتًا مخصصًا من قبل المستدعي، يحتاج المستدعي إلى معرفة الحجم المطلوب بواسطة مكتبة TCTI. يمكن اكتشاف الحد الأدنى لحجم هذا السياق عن طريق توفير NULL للمعامل tcti_context ومعامل size غير NULL. ستقوم دالة التهيئة بعد ذلك بملء المعامل size بالحد الأدنى لحجم المخزن المؤقت tcti_context. يمكن للمستدعي بعد ذلك تخصيص مخزن مؤقت بهذا الحجم (أو أكبر) واستدعاء tss2_Tcti_Tabrmd_Init () مرة أخرى، مع توفير tcti_context المخصص حديثًا وحجم هذا السياق في المعامل size. هذا النمط شائع لجميع دوال تهيئة TCTI. نقدم مثالًا لهذا النمط باستخدام الدالة Tss2_Tcti_Tabrmd_Init() في القسم المسمى مثال.

المعامل conf هو سلسلة من أزواج المفتاح / القيمة التي تصف خصائص الاتصال المطلوبة لـ TCTI. إذا قدم المستدعي سلسلة conf فارغة، فسيتم استخدام الإعدادات الافتراضية التي تتوافق مع الإعدادات الافتراضية لـ tpm2-abrmd (8). هذا هو نفس تقديم سلسلة conf: "bus_name=com.intel.tss2.Tabrmd,bus_type=system". يتم فصل المفاتيح والقيم بحرف '=' بينما يتم فصل كل زوج مفتاح / قيمة بالحرف ','. المفاتيح والقيم المدعومة هي:

•
bus_name - اسم dbus الذي يمتلكه الخادم. انظر الخيار --dbus-name في tpm2-abrmd (8).
•
bus_type - نوع الناقل المستخدم للاتصال بالخادم. قد تكون القيمة المرتبطة بهذا المفتاح "system" أو "session".

بمجرد تهيئة سياق TCTI، فإنه يعرض واجهة برمجة تطبيقات TCG (Trusted Computing Group) المحددة لعملية الاتصال ذات المستوى الأدنى مع TPM. باستخدام واجهة برمجة التطبيقات هذه، يمكن للمستدعي تبادل (إرسال / استقبال) أوامر TPM2 ومخازن الاستجابة مع tpm2-abrmd (8). في معظم الحالات، سيقوم المستدعي بتهيئة سياق باستخدام هذه الدالة قبل تمرير السياق إلى واجهة برمجة تطبيقات ذات مستوى أعلى مثل واجهة برمجة تطبيقات النظام (SAPI)، ولن يلمسه مرة أخرى.

لمناقشة أكثر تفصيلاً لواجهة برمجة تطبيقات TCTI، راجع مواصفات "TSS System Level API and TPM Command Transmission Interface Specification" كما نشرتها TCG: https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

قيمة الإرجاع

سيؤدي الاستدعاء الناجح لـ Tss2_Tcti_Tabrmd_Init() إلى إرجاع TSS2_RC_SUCCESS. سيؤدي الاستدعاء غير الناجح إلى رمز استجابة موصوف في قسم الأخطاء.

الأخطاء

يتم إرجاع TSS2_TCTI_RC_BAD_VALUE إذا كان المعامل size يساوي NULL.

يتم إرجاع TSS2_TCTI_RC_NO_CONNECTION عند فشل الاتصال بـ tpm2-abrmd (8).

يتم إرجاع TSS2_TCTI_RC_GENERAL_FAILURE لجميع الأخطاء الأخرى.

مثال

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti-tabrmd.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
rc = tss2_tcti_tabrmd_init (NULL, &size, NULL,
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل الحصول على حجم التخصيص لسياق tabrmd TCTI "
             ": 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "فشل تخصيص سياق TCTI: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = tss2_tcti_tabrmd_init (tcti_context, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل تهيئة سياق tabrmd TCTI: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
