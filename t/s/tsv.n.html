tsv(n)

الحزمة: tcl

التراخيص: TCL

tsv(n) tsv(n)

الاسم

tsv - جزء من امتداد الخيوط Tcl الذي يسمح بالتلاعب على مستوى النص البرمجي بالبيانات المشتركة بين الخيوط.

package require Tcl 8.4

package require Thread ?2.8?

tsv::object varname element

tsv::set varname element ?value?

tsv::get varname element ?namedvar?

tsv::unset varname ?element?

tsv::exists varname element

tsv::pop varname element

tsv::move varname oldname newname

tsv::incr varname element ?count?

tsv::append varname element value ?value ...?

tsv::lock varname arg ?arg ...?

tsv::lrange varname element from to

tsv::lset varname element index ?index ...? value

tsv::lpop varname element ?index?

tsv::lpush varname element ?index?

الوصف

يصف هذا القسم الأوامر التي تنفذ المتغيرات المشتركة بين الخيوط. المتغير المشترك بين الخيوط مشابه جدًا لمصفوفة Tcl ولكن على عكس مصفوفة Tcl يتم إنشاؤه في الذاكرة المشتركة ويمكن الوصول إليه من العديد من الخيوط في نفس الوقت. من الميزات المهمة للمتغير المشترك بين الخيوط أن كل وصول إلى المتغير محمي داخليًا بقفل (mutex) بحيث لا يضطر مبرمج النص البرمجي إلى الاهتمام بقفل المتغير بنفسه.

المتغيرات المشتركة بين الخيوط غير مرتبطة بأي خيط بشكل صريح. وهذا يعني أنه عندما ينتهي خيط أنشأ أيًا من المتغيرات المشتركة بين الخيوط، فإن المتغير والذاكرة المرتبطة به لا يتم إلغاؤها/استعادتها. يجب على المستخدم إلغاء تعيين المتغير صراحةً لاستعادة الذاكرة التي يستهلكها المتغير.

أوامر العناصر

tsv::names ?pattern?
يعيد أسماء المتغيرات المشتركة المطابقة للنمط الاختياري ?pattern? أو جميع المتغيرات المعروفة إذا تم حذف النمط.
tsv::object varname element
ينشئ أمر وصول كائن للعنصر element في المتغير المشترك varname. باستخدام هذا الأمر، يمكن للمرء تطبيق معظم أوامر المتغيرات المشتركة الأخرى كدوال طريقة لأمر كائن العنصر. يتم حذف أمر الكائن تلقائيًا عندما يتم إلغاء تعيين العنصر الذي يشير إليه هذا الأمر.
    % tsv::set foo bar "A shared string"
    % set string [tsv::object foo bar]
    % $string append " appended"
    => A shared string appended
tsv::set varname element ?value?
يعيّن قيمة العنصر element في المتغير المشترك varname إلى value ويعيد القيمة إلى المستدعي. يمكن حذف value، وفي هذه الحالة سيعيد الأمر القيمة الحالية للعنصر. إذا تعذر العثور على العنصر، يتم إطلاق خطأ.
tsv::get varname element ?namedvar?
يسترد قيمة العنصر element من المتغير المشترك varname. إذا تم إعطاء الوسيطة الاختيارية namedvar، يتم تخزين القيمة في المتغير المسمى. تعتمد قيمة إرجاع الأمر على وجود الوسيطة الاختيارية namedvar. إذا تم حذف الوسيطة ولم يتم العثور على العنصر المطلوب في المصفوفة المشتركة، فإن الأمر يطلق خطأ. ومع ذلك، إذا تم إعطاء الوسيطة الاختيارية على سطر الأوامر، فإن الأمر يعيد صحيحًا (1) إذا تم العثور على العنصر أو خطأ (0) إذا لم يتم العثور على العنصر.
tsv::unset varname ?element?
يلغي تعيين العنصر element من المتغير المشترك varname. إذا لم يتم إعطاء العنصر الاختياري، فإنه يحذف المتغير.
tsv::exists varname element
يتحقق مما إذا كان العنصر element موجودًا في المتغير المشترك varname ويعيد صحيحًا (1) إذا كان موجودًا أو خطأ (0) إذا لم يكن كذلك.
tsv::pop varname element
يعيد قيمة العنصر element في المتغير المشترك varname ويلغي تعيين العنصر، كل ذلك في عملية ذرية واحدة.
tsv::move varname oldname newname
يعيد تسمية العنصر oldname إلى newname في المتغير المشترك varname. يؤدي هذا فعليًا إلى تنفيذ تسلسل عمليات get/unset/set ولكن في خطوة ذرية واحدة.
tsv::incr varname element ?count?
مشابه لأمر Tcl القياسي incr ولكنه يزيد قيمة العنصر element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::append varname element value ?value ...?
مشابه لأمر Tcl القياسي append ولكنه يلحق قيمة واحدة أو أكثر بالعنصر element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lock varname arg ?arg ...?
يقوم هذا الأمر بربط الوسائط التي تم تمريرها وتقييم النص البرمجي الناتج تحت حماية القفل الداخلي. أثناء تقييم النص البرمجي، يتم قفل المتغير المشترك بالكامل. بالنسبة لأوامر المتغيرات المشتركة داخل النص البرمجي، يتم تعطيل القفل الداخلي بحيث لا يمكن حدوث حالة توقف تام. يُسمح أيضًا بإلغاء تعيين المتغير المشترك من داخل النص البرمجي. يتم إنشاء المتغير المشترك تلقائيًا إذا لم يكن موجودًا في وقت عملية القفل الأولى.
    % tsv::lock foo {
        tsv::lappend foo bar 1
        tsv::lappend foo bar 2
        puts stderr [tsv::set foo bar]
        tsv::unset foo
    }
tsv::handlers
يعيد أسماء جميع معالجات التخزين الدائم الممكّنة في وقت الترجمة. راجع أوامر المصفوفة للحصول على التفاصيل.

أوامر القوائم

هذه الأوامر مشابهة لأمر Tcl المسمى بالمكافئ. الفرق هو أنها تعمل على عناصر المصفوفات المشتركة.

tsv::lappend varname element value ?value ...?
مشابه لأمر Tcl القياسي lappend ولكنه يلحق قيمة واحدة أو أكثر بالعنصر element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::linsert varname element index value ?value ...?
مشابه لأمر Tcl القياسي linsert لكنه يُدرج قيمة واحدة أو أكثر في موضع القائمة index داخل element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lreplace varname element first last ?value ...?
مشابه لأمر Tcl القياسي lreplace لكنه يستبدل قيمة واحدة أو أكثر بين الموضعين first و last في element من المتغير المشترك varname بدلاً من متغير Tcl.
tsv::llength varname element
مشابه لأمر Tcl القياسي llength لكنه يُرجع طول element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lindex varname element ?index?
مشابه لأمر Tcl القياسي lindex لكنه يُرجع القيمة عند موضع القائمة index من element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lrange varname element from to
مشابه لأمر Tcl القياسي lrange لكنه يُرجع القيم بين موضعي القائمة from و to من element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lsearch varname element ?options? pattern
مشابه لأمر Tcl القياسي lsearch لكنه يبحث في element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lset varname element index ?index ...? value
مشابه لأمر Tcl القياسي lset لكنه يضبط element في المتغير المشترك varname بدلاً من متغير Tcl.
tsv::lpop varname element ?index?
مشابه لأمر Tcl القياسي lindex لكنه بالإضافة إلى الإرجاع، يقوم أيضاً باقتطاع القيمة من element في المتغير المشترك varname في عملية ذرية واحدة. على عكس أمر Tcl lindex، لا يُرجع هذا الأمر أي قيمة إلى المستدعي.
tsv::lpush varname element ?index?
ينفذ هذا الأمر عكس أمر tsv::lpop. وكما نظيره، فإنه لا يُرجع أي قيمة إلى المستدعي.

أوامر المصفوفات

يدعم هذا الأمر معظم خيارات أمر Tcl القياسي array. بالإضافة إلى ذلك، فإنه يسمح بربط متغير مشترك ببعض قواعد بيانات التخزين الدائم. حالياً خيارات التخزين الدائم المدعومة هي GNU Gdbm الشهير و LMDB. يجب اختيار هذه الخيارات أثناء وقت تجميع الحزمة. يوفر التنفيذ خطافات لتعريف طبقات تخزين دائم أخرى، إذا لزم الأمر.

tsv::array set varname list
يفعل نفس الشيء الذي يفعله أمر Tcl القياسي array set.
tsv::array get varname ?pattern?
يفعل نفس الشيء الذي يفعله أمر Tcl القياسي array get.
tsv::array names varname ?pattern?
يفعل نفس الشيء الذي يفعله أمر Tcl القياسي array names.
tsv::array size varname
يفعل نفس الشيء الذي يفعله أمر Tcl القياسي array size.
tsv::array reset varname list
يفعل نفس الشيء الذي يفعله أمر Tcl القياسي array set لكنه يمسح varname ويضبط قيماً جديدة من القائمة بشكل ذري.
tsv::array bind varname handle
يربط varname بمقبض التخزين الدائم handle. تنسيق handle هو <handler>:<address>، حيث <handler> هو "gdbm" لـ GNU Gdbm و "lmdb" لـ LMDB و <address> هو المسار إلى ملف قاعدة البيانات.
tsv::array unbind varname
يفصل array المشترك عن التخزين الدائم المرتبط به.
tsv::array isbound varname
يُرجع صحيحاً (1) إذا كان varname المشترك مرتبطاً ببعض التخزين الدائم أو صفراً (0) إذا لم يكن كذلك.

أوامر القوائم المفتاحية

أوامر القوائم المفتاحية مستعارة من حزمة TclX. توفر القوائم المفتاحية نوع بيانات منظم مبني على قوائم Tcl القياسية. هذه وظيفة مشابهة للبنى (structs) في لغة البرمجة C.

القائمة المفتاحية هي قائمة يحتوي كل عنصر فيها على زوج مفتاح وقيمة. تُخزَّن أزواج العناصر هذه كقوائم بحد ذاتها، حيث يكون المفتاح هو العنصر الأول من القائمة، والقيمة هي الثاني. يُشار إلى أزواج المفتاح-القيمة باسم الحقول. هذا مثال على قائمة مفتاحية:

    {{NAME  {Frank  Zappa}} {JOB {musician and composer}}}
قد تحتوي الحقول على حقول فرعية؛ الحرف `.' هو حرف الفصل. الحقول الفرعية هي في الواقع حقول حيث تكون القيمة قائمة مفتاحية أخرى. وبالتالي فإن القائمة التالية تحتوي على الحقلين العلويين ID و NAME، والحقلين الفرعيين NAME.FIRST و NAME.LAST: 
    {ID 106} {NAME {{FIRST Frank} {LAST Zappa}}}
لا يوجد حد للعمق التكراري للحقول الفرعية، مما يسمح ببناء بنى بيانات معقدة. تُبنى القوائم المفتاحية ويُوصَل إليها عبر عدد من الأوامر. جميع أوامر إدارة القوائم المفتاحية تأخذ اسم المتغير الذي يحتوي على القائمة المفتاحية كوسيط (أي تمرير بالمرجع)، بدلاً من تمرير القائمة مباشرة.
tsv::keyldel varname keylist key
يحذف الحقل المحدد بواسطة key من القائمة المفتاحية keylist في المتغير المشترك varname. هذا يزيل كلاً من المفتاح والقيمة من القائمة المفتاحية.
tsv::keylget varname keylist key ?retvar?
يُرجع القيمة المرتبطة بـ key من القائمة المفتاحية keylist في المتغير المشترك varname. إذا لم يُحدَّد retvar الاختياري، فستُرجَع القيمة كنتيجة للأمر. في هذه الحالة، إذا لم يُعثر على المفتاح في القائمة، فسينتج خطأ.

إذا حُدِّد retvar وكان key في القائمة، فستُرجَع القيمة في المتغير retvar ويُرجع الأمر 1 إذا كان المفتاح موجوداً ضمن القائمة. إذا لم يكن key في القائمة، فسيُرجع الأمر 0، وسيُترك retvar دون تغيير. إذا حُدِّد {} لـ retvar، فلن تُرجَع القيمة، مما يسمح لمبرمج Tcl بتحديد ما إذا كان key موجوداً في قائمة مفتاحية دون ضبط متغير كأثر جانبي.

tsv::keylkeys varname keylist ?key?
يُرجع قائمة بالمفاتيح في القائمة المفتاحية keylist في المتغير المشترك varname. إذا حُدِّد key، فهو اسم حقل مفتاح يُراد استرداد مفاتيحه الفرعية.
tsv::keylset varname keylist key value ?key value..?
يضبط القيمة المرتبطة بـ key، في القائمة المفتاحية keylist إلى value. إذا لم تكن keylist موجودة، فسيتم إنشاؤها. إذا لم يكن key موجوداً حالياً في القائمة، فسيُضاف. إذا كان موجوداً بالفعل، فستستبدل value القيمة الحالية. يمكن تحديد كلمات مفتاحية وقيم متعددة، إذا رُغب في ذلك.

مناقشة

يسمح التنفيذ الحالي للمتغيرات المشتركة بين الخيوط بالوصول السهل والمريح إلى البيانات المشتركة بين خيوط مختلفة. داخلياً، تُخزَّن البيانات في كائنات Tcl وتعمل جميع أوامر الحزمة على التمثيل الداخلي للبيانات، مما يقلل من التلألؤ (shimmering) ويحسّن الأداء. وقد أُولي اهتمام خاص لضمان قفل جميع بيانات الكائنات بشكل صحيح ونسخها نسخاً عميقاً عند نقل الكائنات بين الخيوط.

نظراً للتصميم الداخلي لنواة Tcl، لا يوجد للأسف توفير تكامل كامل للمتغيرات المشتركة ضمن صيغة Tcl. يجب تنفيذ جميع عمليات الوصول إلى البيانات المشتركة باستخدام أوامر الحزمة المرفقة. أيضاً، لا تُدعم تتبعات المتغيرات. ولكن مع ذلك، فإن فوائد التلاعب السهل والبسيط والآمن بالبيانات المشتركة تفوق القيود المفروضة.

شكر وتقدير

المتغيرات المشتركة بين الخيوط مستوحاة من واجهة nsv الموجودة في AOLserver، وهو خادم ويب عالي القابلية للتوسع من America Online.
