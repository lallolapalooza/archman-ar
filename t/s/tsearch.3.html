الاسم

tsearch, tfind, tdelete, twalk, twalk_r, tdestroy — إدارة شجرة بحث ثنائية

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <search.h>
typedef enum { preorder, postorder, endorder, leaf } VISIT;
void *tfind(const void *key, void *const *rootp,
            typeof(int (const void *, const void *)) *compar);
void *tsearch(const void *key, void **rootp,
            typeof(int (const void *, const void *)) *compar);
void *tdelete(const void *restrict key, void **restrict rootp,
            typeof(int (const void *, const void *)) *compar);
void twalk(const void *root,
            typeof(void (const void *nodep, VISIT which, int depth))
                *action);
#define _GNU_SOURCE         /* انظر feature_test_macros(7) */
#include <search.h>
void twalk_r(const void *root,
            typeof(void (const void *nodep, VISIT which, void *closure))
                *action,
            void *closure);
void tdestroy(void *root,
            typeof(void (void *nodep)) *free_node);

الوصف

tsearch(), tfind(), twalk(), و tdelete() تدير شجرة بحث ثنائية. تم تعميمها من خوارزمية T في Knuth (6.2.2). الحقل الأول في كل عقدة من الشجرة هو مؤشر إلى عنصر البيانات المقابل. (يجب على البرنامج المستدعي تخزين البيانات الفعلية.) يشير compar إلى روتين مقارنة، يأخذ مؤشرات إلى عنصرين. يجب أن يعيد عددًا صحيحًا يكون سالبًا، أو صفرًا، أو موجبًا، اعتمادًا على ما إذا كان العنصر الأول أصغر من، مساويًا، أو أكبر من العنصر الثاني.

tsearch() تبحث في الشجرة عن عنصر. يشير key إلى العنصر المراد البحث عنه. يشير rootp إلى متغير يشير إلى جذر الشجرة. إذا كانت الشجرة فارغة، فيجب تعيين المتغير الذي يشير إليه rootp إلى NULL. إذا تم العثور على العنصر في الشجرة، فإن tsearch() تعيد مؤشرًا إلى عقدة الشجرة المقابلة. (بعبارة أخرى، tsearch() تعيد مؤشرًا إلى مؤشر إلى عنصر البيانات.) إذا لم يتم العثور على العنصر، فإن tsearch() تضيفه، وتعيد مؤشرًا إلى عقدة الشجرة المقابلة.

tfind() تشبه tsearch()، ولكن إذا لم يتم العثور على العنصر، فإن tfind() تعيد NULL.

tdelete() تحذف عنصرًا من الشجرة. حججها هي نفس حجج tsearch().

twalk() تنفذ عبورًا من العمق أولاً، من اليسار إلى اليمين لشجرة ثنائية. يشير root إلى عقدة البداية للعبور. إذا لم تكن تلك العقدة هي الجذر، فسيتم زيارة جزء فقط من الشجرة. تستدعي twalk() الدالة المستخدمة action في كل مرة يتم فيها زيارة عقدة (أي ثلاث مرات لعقدة داخلية، ومرة واحدة لعقدة طرفية). تأخذ action بدورها ثلاثة وسائط. الوسيط الأول هو مؤشر إلى العقدة التي تتم زيارتها. بنية العقدة غير محددة، ولكن من الممكن تحويل المؤشر إلى مؤشر إلى مؤشر عنصر للوصول إلى العنصر المخزن داخل العقدة. لا يجوز للتطبيق تعديل البنية المشار إليها بهذا الوسيط. الوسيط الثاني هو عدد صحيح يأخذ إحدى القيم preorder، postorder، أو endorder اعتمادًا على ما إذا كانت هذه هي الزيارة الأولى، الثانية، أو الثالثة لعقدة داخلية، أو القيمة leaf إذا كانت هذه هي الزيارة الوحيدة لعقدة طرفية. (هذه الرموز معرفة في <search.h>.) الوسيط الثالث هو عمق العقدة؛ العقدة الجذرية لها عمق صفر.

(بشكل أكثر شيوعًا، تُعرف preorder، postorder، و endorder باسم preorder، inorder، و postorder: قبل زيارة الأبناء، بعد الأول وقبل الثاني، وبعد زيارة الأبناء. وبالتالي، فإن اختيار الاسم postorder مربك إلى حد ما.)

twalk_r() مشابهة لـ twalk()، ولكن بدلاً من وسيط depth، يتم تمرير المؤشر closure إلى كل استدعاء لدالة الإجراء، دون تغيير. يمكن استخدام هذا المؤشر لتمرير معلومات إلى ومن دالة الإجراء بطريقة آمنة للخيوط، دون اللجوء إلى متغيرات عامة.

tdestroy() تزيل الشجرة بأكملها المشار إليها بواسطة root، وتحرر جميع الموارد التي تم تخصيصها بواسطة الدالة tsearch(). بالنسبة للبيانات في كل عقدة من الشجرة، يتم استدعاء الدالة free_node. يتم تمرير مؤشر إلى البيانات كوسيط للدالة. إذا لم تكن هناك حاجة إلى مثل هذا العمل، فيجب أن يشير free_node إلى دالة لا تفعل شيئًا.

قيمة الإرجاع

tsearch() تعيد مؤشرًا إلى عقدة مطابقة في الشجرة، أو إلى العقدة المضافة حديثًا، أو NULL إذا كانت الذاكرة غير كافية لإضافة العنصر. tfind() تعيد مؤشرًا إلى العقدة، أو NULL إذا لم يتم العثور على تطابق. إذا كانت هناك عناصر متعددة تطابق المفتاح، فإن العنصر الذي يتم إرجاع عقدته غير محدد.

tdelete() تعيد مؤشرًا إلى والد العقدة المحذوفة، أو NULL إذا لم يتم العثور على العنصر. إذا كانت العقدة المحذوفة هي العقدة الجذرية، فإن tdelete() تعيد مؤشرًا معلقًا يجب عدم الوصول إليه.

tsearch() و tfind() و tdelete() تعيد أيضًا NULL إذا كان rootp هو NULL عند الدخول.

ملاحظات

twalk() تأخذ مؤشرًا إلى الجذر، بينما تأخذ الدوال الأخرى مؤشرًا إلى متغير يشير إلى الجذر.

tdelete() تحرر الذاكرة المطلوبة للعقدة في الشجرة. المستخدم مسؤول عن تحرير الذاكرة للبيانات المقابلة.

يعتمد البرنامج المثال على حقيقة أن twalk() لا تقوم بأي إشارة إضافية إلى عقدة بعد استدعاء الدالة المستخدمة بالوسيط "endorder" أو "leaf". هذا يعمل مع تنفيذ مكتبة GNU، ولكنه غير موجود في وثائق System V.
