Tss2_Tcti_Mssim_Init(3)

الحزمة: tpm2-tss

التراخيص: BSD-2-Clause

Tss2_Tcti_Mssim_Init(3) دليل دوال المكتبة Tss2_Tcti_Mssim_Init(3)

الاسم

Tss2_Tcti_Mssim_Init - دالة تهيئة مكتبة TCTI لمحاكاة TPM من Microsoft.

الملخص

#include <tcti/tcti_mssim.h>

TSS2_RC Tss2_Tcti_Mssim_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *contextSize, const char *conf);

تقوم الدالة Tss2_Tcti_Mssim_Init() بتهيئة سياق TCTI المستخدم للتواصل مع محاكي TPM2 من Microsoft.

الوصف

تحاول Tss2_Tcti_Mssim_Init() تهيئة tcti_context مخصص من قبل المتصل بحجم size باستخدام سلسلة التكوين conf المقدمة من المتصل. نظرًا لأن tcti_context يجب أن يكون مخزنًا مؤقتًا مخصصًا من قبل المتصل، يحتاج المتصل إلى معرفة حجم المخزن المؤقت المطلوب من قبل مكتبة TCTI. يمكن اكتشاف الحد الأدنى لحجم هذا السياق عن طريق توفير NULL لـ tcti_context ومعامل size غير NULL. ستقوم دالة التهيئة بعد ذلك بملء المعامل size بالحد الأدنى لحجم المخزن المؤقت tcti_context. يجب بعد ذلك على المتصل تخصيص مخزن مؤقت بهذا الحجم (أو أكبر) واستدعاء Tss2_Tcti_Mssim_Init () مرة أخرى مع توفير tcti_context المخصص حديثًا وحجم هذا السياق في المعامل size. هذا النمط شائع لجميع دوال تهيئة TCTI. نقدم مثالًا لهذا النمط باستخدام الدالة Tss2_Tcti_Mssim_Init() في القسم المسمى مثال.

المعامل conf هو سلسلة C تستخدم لتكوين سياق TCTI. سلسلة التكوين هذه عبارة عن سلسلة من أزواج المفتاح / القيمة التي تحدد المضيف والمنفذ المستخدمين للاتصال بنسخة من محاكي TPM2 من Microsoft. يتم فصل المفاتيح والقيم بحرف '='، بينما يتم فصل كل زوج مفتاح / قيمة بحرف ','.

المفاتيح الوحيدة المدعومة في سلسلة conf هي host و port. يمكن أن يكون المضيف عنوان IPv4، أو عنوان IPv6، أو اسم مضيف. يجب أن يكون المنفذ uint16_t صالحًا في شكل سلسلة. إذا تم توفير سلسلة conf فارغة (NULL) من قبل المتصل، فسيتم استخدام القيمة الافتراضية "host=localhost,port=2321". إذا تم حذف host أو port، فسيتم استخدام قيمته الافتراضية.

بمجرد تهيئته، يعرض سياق TCTI المرجع واجهة برمجة التطبيقات (API) المحددة من TCG (Trusted Computing Group) لأدنى مستوى اتصال مع TPM. باستخدام واجهة برمجة التطبيقات هذه، يمكن للمتصل تبادل (إرسال / استقبال) مخازن أوامر واستجابات TPM2 مع محاكي TPM من Microsoft. في الغالبية العظمى من الحالات، سيقوم المتصل بتهيئة سياق باستخدام هذه الدالة قبل تمرير السياق إلى واجهة برمجة تطبيقات أعلى مستوى مثل واجهة برمجة تطبيقات النظام (SAPI)، ولن يلمسها مرة أخرى.

للحصول على مناقشة أكثر تفصيلاً لواجهة برمجة تطبيقات TCTI، راجع "مواصفات واجهة نظام TSS لواجهة برمجة التطبيقات (API) لنقل أوامر TPM" كما نشرتها TCG: https://trustedcomputinggroup.org/tss-system-level-api-tpm-command-transmission-interface-specification/

قيمة الإرجاع

سيؤدي الاستدعاء الناجح لـ Tss2_Tcti_Mssim_Init() إلى إرجاع TSS2_RC_SUCCESS. سيؤدي الاستدعاء غير الناجح إلى رمز استجابة موصوف في قسم الأخطاء.

الأخطاء

يتم إرجاع TSS2_TCTI_RC_BAD_VALUE إذا كان كلا المعاملين tcti_context و size فارغين (NULL)، أو إذا كان المعامل config فارغًا (NULL).

مثال

جزء تهيئة TCTI:

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_mssim.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
const char *conf = "host=localhost,port=2321"
rc = Tss2_Tcti_Mssim_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل الحصول على حجم التخصيص لسياق mssim TCTI "
             ": 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "فشل تخصيص سياق TCTI: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Mssim_Init (&tcti_context, &size, conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل تهيئة سياق mssim TCTI: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
