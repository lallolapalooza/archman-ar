Tss2_TctiLdr_FreeInfo(3)

الحزمة: tpm2-tss

التراخيص: BSD-2-Clause

Tss2_TctiLdr_FreeInfo(3) دليل وظائف المكتبة Tss2_TctiLdr_FreeInfo(3)

الاسم

Tss2_TctiLdr_FreeInfo - وظيفة لتحرير بنية TSS2_TCTI_INFO تم تخصيصها بواسطة Tss2_TctiLdr_Initialize().

الموجز

#include <tss2/tss2_tctildr.h>

void Tss2_TctiLdr_FreeInfo (TSS2_TCTI_INFO*info);

الوصف

تقوم الدالة Tss2_TctiLdr_FreeInfo() بتدمير مثيل لبنية TSS2_TCTI_INFO التي تم إنشاؤها بواسطة الدالة Tss2_TctiLdr_GetInfo().

المعامل info هو مرجع إلى بنية TSS2_TCTI_INFO المراد تحريرها.

قيمة الإرجاع

لا تُرجع هذه الدالة أي قيمة.

مثال

مثال على الكود.

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tss2/tss2_tctildr.h>
TSS2_TCTI_INFO *info = NULL;
TSS2_RC rc = Tss2_TctiLdr_GetInfo (NULL, &info);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل في الحصول على بنية TSS2_TCTI_INFO لـ TCTI الافتراضي "
             "مع رمز الاستجابة: 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
if (info != NULL) {
    Tss2_TctiLdr_FreeInfo (info);
    info = NULL;
}
exit (EXIT_SUCCESS);
