Tss2_Tcti_Device_Init(3)

الحزمة: tpm2-tss

التراخيص: BSD-2-Clause

Tss2_Tcti_Device_Init(3) دليل وظائف المكتبة Tss2_Tcti_Device_Init(3)

الاسم

Tss2_Tcti_Device_init - دالة التهيئة لمكتبة TCTI الخاصة بالجهاز.

الملخص

#include <tcti/tcti_device.h>

TSS2_RC Tss2_Tcti_Device_Init (TSS2_TCTI_CONTEXT *tctiContext, size_t *size, const char *conf);

تقوم الدالة Tss2_Tcti_Device_Init() بتهيئة سياق TCTI المستخدم للتواصل مع مشغل جهاز TPM.

الوصف

تحاول Tss2_Tcti_Device_Init() تهيئة tctiContext تم تخصيصه من قبل المستدعي بحجم size. نظرًا لأن tctiContext يجب أن يكون مخزنًا مؤقتًا مخصصًا من قبل المستدعي، يحتاج المستدعي إلى معرفة الحجم المطلوب من قبل مكتبة TCTI. يمكن اكتشاف الحد الأدنى لحجم هذا السياق عن طريق توفير NULL لـ tctiContext ومعامل size غير NULL. ستقوم دالة التهيئة بعد ذلك بملء المعامل size بالحد الأدنى لحجم المخزن المؤقت tctiContext. يجب بعد ذلك على المستدعي تخصيص مخزن مؤقت بهذا الحجم (أو أكبر) واستدعاء Tss2_Tcti_Device_Init () مرة أخرى لتوفير tctiContext المخصص حديثًا وحجم هذا السياق في المعامل size. هذا النمط شائع لجميع دوال تهيئة TCTI. نقدم مثالاً لهذا النمط باستخدام الدالة Tss2_Tcti_Device_Init() في القسم المسمى مثال.

المعامل conf هو سلسلة C. إذا كانت هذه السلسلة NULL، فستستخدم المكتبة سلسلة تكوين افتراضية للمستدعي. بدلاً من ذلك، يمكن للمستدعي توفير سلسلة تكوين يجب أن تحتوي على المسار إلى عقدة الجهاز التي يكشفها مشغل جهاز TPM.

بمجرد تهيئته، يكشف سياق TCTI المُرجع عن واجهة برمجة التطبيقات المحددة من قبل مجموعة الحوسبة الموثوقة (TCG) لأدنى مستوى اتصال مع TPM. باستخدام واجهة برمجة التطبيقات هذه، يمكن للمستدعي تبادل (إرسال / استقبال) أوامر واستجابات TPM2 مع مشغل جهاز TPM. في معظم الحالات، سيقوم المستدعي بتهيئة سياق باستخدام هذه الدالة قبل تمرير السياق إلى واجهة برمجة تطبيقات أعلى مستوى مثل واجهة برمجة تطبيقات النظام (SAPI)، وبعد ذلك لن يلمسها مرة أخرى.

مواصفات واجهة برمجة التطبيقات لنقل أوامر TPM 2.0 لمجموعة الحوسبة الموثوقة (TCG) (TCTI)

للحصول على مناقشة أكثر شمولاً لواجهة برمجة التطبيقات TCTI، راجع "مواصفات واجهة برمجة التطبيقات لنقل أوامر TPM 2.0 لمجموعة الحوسبة الموثوقة (TCG) (TCTI)" كما نشرتها TCG: https://trustedcomputinggroup.org/wp-content/uploads/TSS_TCTI_Version-1.0_Revision-05_Review_END030918.pdf

قيمة الإرجاع

سيؤدي استدعاء ناجح لـ Tss2_Tcti_Device_Init() إلى إرجاع TSS2_RC_SUCCESS. سيؤدي استدعاء غير ناجح إلى إنتاج رمز استجابة موصوف في قسم الأخطاء.

الأخطاء

يتم إرجاع TSS2_TCTI_RC_BAD_VALUE إذا كانت أي معلمات تحتوي على قيم غير متوقعة. يتم إرجاع TSS2_TCTI_RC_BAD_REFERENCE إذا كانت أي معلمات NULL عندما لا ينبغي أن تكون كذلك. يتم إرجاع TSS2_TCTI_RC_BAD_CONTEXT إذا كان حجم tctiContext المقدم غير كافٍ.

مثال

جزء تهيئة TCTI:

#include <inttypes.h>
#include <stdlib.h>
#include <stdio.h>
#include <tcti/tcti_device.h>
TSS2_RC rc;
TSS2_TCTI_CONTEXT *tcti_context;
size_t size;
char *conf = "/dev/tpm0",
rc = Tss2_Tcti_Device_Init (NULL, &size, NULL);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل الحصول على حجم التخصيص لسياق TCTI للجهاز "
             ": 0x%" PRIx32 "0, rc);
    exit (EXIT_FAILURE);
}
tcti_context = calloc (1, size);
if (tcti_context == NULL) {
    fprintf (stderr, "فشل تخصيص سياق TCTI: %s0,
             strerror (errno));
    exit (EXIT_FAILURE);
}
rc = Tss2_Tcti_Device_Init (&tcti_context, &size, &conf);
if (rc != TSS2_RC_SUCCESS) {
    fprintf (stderr, "فشل تهيئة سياق TCTI للجهاز: "
             "0x%" PRIx32 "0, rc);
    free (tcti_context);
    exit (EXIT_FAILURE);
}
exit (EXIT_SUCCESS);
