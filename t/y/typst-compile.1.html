typst-compile(1)

الحزمة: typst

التراخيص: Apache-2.0

typst-compile(1) دليل الأوامر العامة typst-compile(1)

الاسم

typst-compile - يقوم بتجميع ملف إدخال إلى تنسيق إخراج مدعوم

الملخص

typst-compile [-f|--format] [--root] [--input] [--font-path] [--ignore-system-fonts] [--ignore-embedded-fonts] [--package-path] [--package-cache-path] [--creation-timestamp] [--pages] [--pdf-standard] [--no-pdf-tags] [--ppi] [--deps] [--deps-format] [-j|--jobs] [--features] [--diagnostic-format] [--open] [--timings] [-h|--help] <INPUT> [OUTPUT]

الوصف

يقوم بتجميع ملف إدخال إلى تنسيق إخراج مدعوم

الخيارات

-f, --format=FORMAT
تنسيق ملف الإخراج، يتم استنتاجه من الامتداد افتراضيًا

[القيم الممكنة: pdf, png, svg, html]

--root=DIR
يقوم بتكوين جذر المشروع (للمسارات المطلقة)
يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_ROOT.
--input=key=value
أضف زوج مفتاح-قيمة نصي مرئي عبر `sys.inputs`
--font-path=DIR
يضيف مجلدات إضافية يتم البحث فيها بشكل متكرر عن الخطوط.

إذا تم تحديد مسارات متعددة، فإنها تفصلها فاصل المسار الخاص بالنظام (`:` على أنظمة Unix-like و `;` على Windows).

يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_FONT_PATHS.
--ignore-system-fonts
يضمن عدم البحث عن خطوط النظام، إلا إذا تم تضمينها صراحةً عبر `--font-path`
يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_IGNORE_SYSTEM_FONTS.
--ignore-embedded-fonts
يضمن عدم أخذ الخطوط المضمنة في Typst في الاعتبار
يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_IGNORE_EMBEDDED_FONTS.
--package-path=DIR
مسار مخصص للحزم المحلية، افتراضيًا في موقع يعتمد على النظام
يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_PACKAGE_PATH.
--package-cache-path=DIR
مسار مخصص لذاكرة التخزين المؤقت للحزم، افتراضيًا في موقع يعتمد على النظام
يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_PACKAGE_CACHE_PATH.
--creation-timestamp=UNIX_TIMESTAMP
تاريخ إنشاء المستند منسقًا كختم زمني UNIX.

لمزيد من المعلومات، انظر https://reproducible-builds.org/specs/source-date-epoch/.

يمكن أيضًا تحديده باستخدام متغير البيئة SOURCE_DATE_EPOCH.
--pages=PAGES
الصفحات المراد تصديرها. عند عدم التحديد، يتم تصدير جميع الصفحات.

يتم فصل الصفحات المراد تصديرها بفواصل، ويمكن أن تكون أرقام صفحات بسيطة (مثل '2,5' لتصدير الصفحتين 2 و 5 فقط) أو نطاقات صفحات (مثل '2,3-6,8-' لتصدير الصفحة 2، والصفحات من 3 إلى 6 (شاملة)، والصفحة 8 وأي صفحات بعدها).

أرقام الصفحات تبدأ من واحد وتتوافق مع أرقام الصفحات الفعلية في المستند (وبالتالي لا تتأثر بعداد صفحات المستند).

--pdf-standard=PDF_STANDARD
معيار PDF واحد (أو متعدد مفصول بفواصل) سيفرض Typst الامتثال معه

القيم الممكنة:

  • 1.4: PDF 1.4
  • 1.5: PDF 1.5
  • 1.6: PDF 1.6
  • 1.7: PDF 1.7
  • 2.0: PDF 2.0
  • a-1b: PDF/A-1b
  • a-1a: PDF/A-1a
  • a-2b: PDF/A-2b
  • a-2u: PDF/A-2u
  • a-2a: PDF/A-2a
  • a-3b: PDF/A-3b
  • a-3u: PDF/A-3u
  • a-3a: PDF/A-3a
  • a-4: PDF/A-4
  • a-4f: PDF/A-4f
  • a-4e: PDF/A-4e
  • ua-1: PDF/UA-1
--no-pdf-tags
افتراضيًا، حتى عند عدم إنتاج مستند `PDF/UA-1`، يتم كتابة مستند PDF مُعنون لتوفير أساس لإمكانية الوصول. في بعض الظروف (على سبيل المثال، عند محاولة تقليل حجم المستند)، قد يكون من المرغوب فيه تعطيل PDF المُعنون
--ppi=PPI [الافتراضي: 144]
PPI (بكسل لكل بوصة) المستخدم لتصدير PNG
--deps=PATH
مسار الملف الذي سيتم كتابة قائمة التبعيات للتجميع الحالي إليه. استخدم `-` للكتابة إلى الإخراج القياسي
--deps-format=DEPS_FORMAT [الافتراضي: json]
تنسيق الملف المستخدم للتبعيات

القيم الممكنة:

  • json: ترميز كـ JSON، فشل للمسارات غير Unicode
  • zero: يفصل المسارات ببايتات NULL ويمكنه التعبير عن جميع المسارات
  • make: يصدر بتنسيق Make، متجاهلاً المسارات التي لا يمكن التعبير عنها
-j, --jobs=JOBS
عدد المهام المتوازية التي يتم إنشاؤها أثناء التجميع. الافتراضي هو عدد وحدات المعالجة المركزية. ضبطه على 1 يعطل التوازي
--features=FEATURES
يمكّن الميزات قيد التطوير التي قد يتم تغييرها أو إزالتها في أي وقت

[القيم الممكنة: html, a11y-extras]

يمكن أيضًا تحديده باستخدام متغير البيئة TYPST_FEATURES.
--diagnostic-format=DIAGNOSTIC_FORMAT [الافتراضي: human]
التنسيق الذي يتم به إصدار التشخيصات

[القيم الممكنة: human, short]

--open=VIEWER
يفتح ملف الإخراج باستخدام العارض الافتراضي أو برنامج معين بعد التجميع. يتم تجاهله إذا كان الإخراج هو الإخراج القياسي
--timings=OUTPUT_JSON
ينتج قياسات أداء لعملية التجميع. (تجريبي)

يمكن تحميل ملف JSON الناتج في أداة تتبع مثل https://ui.perfetto.dev. لا يحتوي على أي معلومات حساسة باستثناء أسماء الملفات وأرقام الأسطر.

-h, --help
طباعة المساعدة (راجع ملخصًا باستخدام '-h')
<INPUT>
مسار ملف Typst الإدخال. استخدم `-` لقراءة الإدخال من stdin
[OUTPUT]
مسار ملف الإخراج (PDF، PNG، SVG، أو HTML). استخدم `-` للكتابة إلى الإخراج القياسي.

لتنسيقات الإخراج التي تصدر ملفًا واحدًا لكل صفحة (PNG & SVG)، يجب وجود قالب رقم صفحة إذا كان المستند المصدر ينتج صفحات متعددة. استخدم `{p}` لأرقام الصفحات، `{0p}` لأرقام الصفحات المملوءة بالأصفار، و `{t}` لعدد الصفحات. على سبيل المثال، `page-{0p}-of-{t}.png` ينشئ `page-01-of-10.png`، `page-02-of-10.png`، وهكذا.

NAME

typst-compile - Compile Typst document to output format

SYNOPSIS

typst compile [OPTIONS] [SOURCE] [DESTINATION]

DESCRIPTION

Compiles a Typst source file into a destination file. If no source is specified, typst compile reads from standard input. If no destination is specified, it will be derived from the source file name or it will be printed to standard output if reading from standard input.

OPTIONS

--help, -h
Prints help information
--version, -v
Prints version information
--diagnostic-format <format>

Specifies the format for diagnostics (e.g., human, short, json, raw)

Defaults to human

--diagnostic-verbosity <level>

Specifies the verbosity level for diagnostics (e.g., error, warning, info, debug)

Defaults to warning

--root <path>

Sets the virtual file system's root directory.

Defaults to the current directory

--font-path <path>

Adds a directory to the system font search path.

This option can be used multiple times.

--input-encoding <encoding>

Specifies the encoding of the input file.

Defaults to utf8

--output-format <format>

Specifies the output format. Can be one of: pdf, html, png, jpg, svg.

If not specified, it is inferred from the destination file extension.

--ppi <value>

The resolution in pixels per inch for rasterized formats (png, jpg).

Defaults to 300

--watch, -w

Watches the source file and any included files for changes and recompiles automatically.
