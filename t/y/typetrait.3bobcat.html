FBB::TypeTrait(3bobcat) سمات النوع FBB::TypeTrait(3bobcat)

الاسم

FBB::TypeTrait - فئة سمات النوع

الملخص

#include <bobcat/typetrait>

الوصف

FBB::TypeTrait هي فئة سمات. لا تحدد أي دوال أعضاء أو أعضاء بيانات، بل مجرد أنواع. يمكن استخدامها لتحديد النوع الأساسي والخصائص الأخرى لأنواع (const) العادية، (const) المؤشرات، أو (const) المراجع. تم تصميمها على غرار فئة القالب TypeTraits الخاصة بـ Alexandrescu (2001).

تُستخدم القالب FBB::LpromotesR لتحديد، وقت الترجمة، ما إذا كان النوع الثاني (الجانب الأيمن) من القالب يمكن ترقيته إلى النوع الأول (الجانب الأيسر) من القالب.

تتوقع القالب FBB::Use اسمين للنوع LHS و RHS وتعرف typename Use<LHS, RHS>::type كـ LHS إذا كان يمكن ترقية RHS إلى LHS، أو تعرف typename Use<LHS, RHS>::type كـ RHS.

ترث من

-

TypeTrait<TYPE>

TYPE هو معامل النوع في القالب الذي يجب تحديد خصائصه.

TypeTrait<TYPE> تحدد النوع Plain: النوع العادي (النوع بدون مؤشر const، مؤشر، إشارة مرجع) لأي نوع عادي، مؤشر، مرجع lvalue أو rvalue، سواء كان const أو غير const.

TypeTrait<TYPE> تحدد القيم bool التالية:

o
isClass: true إذا كان معامل النوع في القالب يمثل نوع فئة (struct)، false خلاف ذلك.
o
isConst: true إذا كان معامل النوع في القالب يمثل نوع const، false خلاف ذلك.
o
isPointer: true إذا كان معامل النوع في القالب يمثل نوع مؤشر، false خلاف ذلك.
o
isR_Ref: true إذا كان معامل النوع في القالب يمثل نوع مرجع rvalue، false خلاف ذلك.
o
isRef: true إذا كان معامل النوع في القالب يمثل نوع مرجع lvalue، false خلاف ذلك.

LpromotesR<LeftType, RightType>

LpromotesR<LeftType, RightType> تعرف الثابت العددي yes كـ 1 إذا كان يمكن ترقية معامل RightType إلى قيمة أو كائن LeftType. تعرف القيمة العددية yes كـ 0 إذا لم يكن هناك مثل هذا الباني متاح أو إذا تم تعريف مثل هذا الباني باستخدام الكلمة المفتاحية explicit.

أمثلة

هنا مثال باستخدام LpromotesR:

    int main()
    {
        cout << "string promotes char const *: " <<
                LpromotesR<string, char const *>::yes << ’\n’;  // 1
        cout << "string promotes string " <<
                LpromotesR<string, string>::yes << ’\n’;        // 1
        cout << "char const * promotes string " <<
                LpromotesR<char const *, string>::yes << ’\n’;  // 0
    }
