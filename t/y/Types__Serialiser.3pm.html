Types__Serialiser(3pm)

الحزمة: perl-types-serialiser

التراخيص: PerlArtistic, GPL

فك التشفير

عندما يواجه وحدة فك التشفير بعد ذلك كائن perl مشفرًا كهذا، يجب عليه البحث عن الدالة "THAW" في اسم الفئة المخزن، واستدعائها باسم الفئة، والسلسلة الثابتة لتحديد نموذج البيانات / تنسيق البيانات، وجميع القيم المرتجعة التي تم إرجاعها بواسطة "FREEZE".

أمثلة

راجع قسم "SERIALISATION OBJECT" في صفحة دليل CBOR::XS لمزيد من التفاصيل، وتنفيذ مثال، وأمثلة على التعليمات البرمجية.

إليك زوج مثال من الدوال "FREEZE" / "THAW":

sub My::Object::FREEZE {
   my ($self, $model) = @_;
   ($self->{type}, $self->{id}, $self->{variant})
}
sub My::Object::THAW {
   my ($class, $model, $type, $id, $variant) = @_;
   $class->new (type => $type, id => $id, variant => $variant)
}

أخطاء

استخدام overload يجعل هذه الوحدة أثقل بكثير مما ينبغي (على نظامي، هذه الوحدة: 4kB RSS، overload: 260kB RSS).

انظر أيضًا

حاليًا، تستخدم JSON::XS و CBOR::XS هذه الأنواع.
