Type__Tiny__Class(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Type::Tiny::Class(3) وثائق بيرل مقدمة من المستخدم Type::Tiny::Class(3)

الاسم

Type::Tiny::Class - قيود النوع المستندة إلى طريقة "isa"

الملخص

الاستخدام عبر Types::Standard:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str InstanceOf );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => InstanceOf[ 'Local::Person' ],
    default  => sub { Local::Person->new },
  );
}

استخدام ميزة التصدير الخاصة بـ Type::Tiny::Class:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Class 'Local::Person';

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => LocalPerson,
    default  => sub { LocalPerson->new },
  );
}

استخدام الواجهة الموجهة للكائنات في Type::Tiny::Class:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Tiny::Class;

  my $Person = Type::Tiny::Class->new( class => 'Local::Person' );

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Person,
    default  => sub { $Person->new },
  );
}

استخدام الواجهة الوظيفية لـ Type::Utils:

package Local::Horse {
  use Moo;
  use Types::Standard qw( Str );
  use Type::Utils;

  my $Person = class_type 'Local::Person';

  has name => (
    is       => 'ro',
    isa      => Str,
  );

  has owner => (
    is       => 'ro',
    isa      => $Person,
    default  => sub { $Person->new },
  );
}

الحالة

هذه الوحدة مغطاة بسياسة استقرار Type-Tiny.

الوصف

قيود النوع من الشكل العام "{ $_->isa("Some::Class") }".

ترث هذه الحزمة من Type::Tiny؛ راجعها لمعظم الوثائق. الاختلافات الرئيسية مدرجة أدناه:

المنشئ

"new"
عند استدعاء المنشئ على مثيل من Type::Tiny::Class، فإنه يمرر الاستدعاء إلى منشئ الفئة للتقييد. لذا على سبيل المثال: 
my $type = Type::Tiny::Class->new(class => "Foo::Bar");
my $obj  = $type->new(hello => "World");
say ref($obj);   # prints "Foo::Bar"

هذه القطعة الصغيرة من DWIM تم استعارتها من MooseX::Types::TypeDecorator، ولكن Type::Tiny لا تأخذ الفكرة إلى هذا الحد.

الخصائص

"class"
الفئة الخاصة بالتقييد.
"constraint"
على عكس Type::Tiny، لا يمكنك تمرير دالة استدعاء تقييد إلى المنشئ. بدلاً من ذلك، اعتمد على الافتراضي.
"inlined"
على عكس Type::Tiny، لا يمكنك تمرير دالة استدعاء تضمين إلى المنشئ. بدلاً من ذلك، اعتمد على الافتراضي.
"parent"
يتم حساب الوالد تلقائيًا، ولا يمكن تمريره إلى المنشئ.

الطرق

"plus_constructors($source, $method_name)"
تشبه إلى حد كبير "plus_coercions" ولكنها تضيف عمليات تحويل تتم عبر منشئ. (في الواقع، يتم تنفيذ هذا كغلاف لـ "plus_coercions".)

مثال:

package MyApp::Minion;

use Moose; extends "MyApp::Person";

use Types::Standard qw( HashRef Str );
use Type::Utils qw( class_type );

my $Person = class_type({ class => "MyApp::Person" });

has boss => (
   is     => "ro",
   isa    => $Person->plus_constructors(
      HashRef,     "new",
      Str,         "_new_from_name",
   ),
   coerce => 1,
);

package main;

MyApp::Minion->new(
   ...,
   boss => "Bob",  ## via MyApp::Person->_new_from_name
);

MyApp::Minion->new(
   ...,
   boss => { name => "Bob" },  ## via MyApp::Person->new
);

نظرًا لأن تحويل "HashRef" عبر منشئ هو رغبة شائعة، إذا قمت باستدعاء "plus_constructors" بدون وسائط على الإطلاق، فهذا هو الافتراضي.

$classtype->plus_constructors(HashRef, "new")
$classtype->plus_constructors()  ## identical to above

هذا مفيد للفئات المستندة إلى Moose/Mouse/Moo.

stringifies_to($constraint)
انظر Type::Tiny::ConstrainedObject.
numifies_to($constraint)
انظر Type::Tiny::ConstrainedObject.
"with_attribute_values($attr1 => $constraint1, ...)"
انظر Type::Tiny::ConstrainedObject.

التصديرات

يمكن استخدام Type::Tiny::Class كمصدر للتصدير.

use Type::Tiny::Class 'HTTP::Tiny';

سيقوم هذا بتصدير الدوال التالية إلى مساحة الأسماء الخاصة بك:

"HTTPTiny"
is_HTTPTiny( $value )
assert_HTTPTiny( $value )
to_HTTPTiny( $value )

ستكون قادرًا أيضًا على استخدام "HTTPTiny->new(...)" كاختصار لـ "HTTP::Tiny->new(...)".

يمكن تصدير أنواع متعددة في وقت واحد:

use Type::Tiny::Class qw( HTTP::Tiny LWP::UserAgent );
