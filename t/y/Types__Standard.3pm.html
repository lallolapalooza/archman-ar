Types__Standard(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Types::Standard(3) توثيق Perl مساهمة من المستخدم Types::Standard(3)

الاسم

Types::Standard - مجموعة مدمجة من الأنواع المضمنة لـ Type::Tiny

الملخص

use v5.36;

package Horse {
  use Moo;
  use Types::Standard qw( Str Int Enum ArrayRef Object );
  use Type::Params qw( signature_for );
  use namespace::autoclean;

  has name => (
    is       => 'ro',
    isa      => Str,
    required => 1,
  );

  has gender => (
    is       => 'ro',
    isa      => Enum[qw( f m )],
  );

  has age => (
    is       => 'rw',
    isa      => Int->where( '$_ >= 0' ),
  );

  has children => (
    is       => 'ro',
    isa      => ArrayRef[Object],
    default  => sub { return [] },
  );

  # توقيع الدالة
  signature_for add_child => (
    method     => Object,
    positional => [ Object ],
  );

  sub add_child ( $self, $child ) {
    push $self->children->@*, $child;
    return $self;
  }
}

package main;

my $boldruler = Horse->new(
  name    => "Bold Ruler",
  gender  => 'm',
  age     => 16,
);

my $secretariat = Horse->new(
  name    => "Secretariat",
  gender  => 'm',
  age     => 0,
);

$boldruler->add_child( $secretariat );

use Types::Standard qw( is_Object assert_Object );

# is_Object($thing) ترجع قيمة منطقية
my $is_it_an_object = is_Object $boldruler;

# assert_Object($thing) ترجع $thing أو تموت
say assert_Object($boldruler)->name;  # تقول "Bold Ruler"

الحالة

تتم تغطية هذه الوحدة بواسطة سياسة استقرار Type-Tiny.

الوصف

يوثق هذا التفاصيل الخاصة بمكتبة النوع Types::Standard. Type::Tiny::Manual هو مكان أفضل للبدء إذا كنت جديدًا.

تجمع Type::Tiny بضعة أنواع تبدو مفيدة.

شبيهة بـ Moose

الأنواع التالية مشابهة لتلك الموصوفة في Moose::Util::TypeConstraints.

  • Any

    أي قيمة على الإطلاق تمر بهذا القيد النوعي (حتى undef).

  • Item

    نفس الشيء بشكل أساسي مثل Any. جميع قيود الأنواع الأخرى في هذه المكتبة ترث بشكل مباشر أو غير مباشر من Item.

  • Bool

    القيم التي تعتبر قيمًا منطقية معقولة. تقبل 1، 0، السلسلة النصية الفارغة و undef.

    اشترى العملاء الآخرون أيضًا: BoolLike من Types::TypeTiny.

  • Maybe[`a]

    باعتبار قيد نوع آخر، تقبل أيضًا undef. على سبيل المثال، Maybe[Int] تقبل جميع الأعداد الصحيحة بالإضافة إلى undef.

  • Undef

    فقط undef تمر بهذا القيد النوعي.

  • Defined

    فقط undef تفشل في هذا القيد النوعي.

  • Value

    أي قيمة معرفة، غير مرجعية.

  • Str

    أي سلسلة نصية.

    (الاختلاف الوحيد بين Value و Str هو أن الأول يقبل typeglobs و vstrings.)

    اشترى العملاء الآخرون أيضًا: StringLike من Types::TypeTiny.

  • Num

    انظر LaxNum و StrictNum أدناه.

  • Int

    عدد صحيح؛ أي سلسلة نصية من الأرقام من 0 إلى 9، قد تكون مسبوقة بشرطة ناقص.

    توقع نتائج غير متناسقة لـ dualvars، والأرقام العالية جدًا (أو الأرقام السالبة المنخفضة جدًا) التي لا يمكن لـ Perl تمثيلها بأمان كعدد صحيح.

  • ClassName

    اسم حزمة محملة. يجب أن تحتوي الحزمة على @ISA أو $VERSION معرفة، أو يجب أن تعرف على الأقل وظيفة واحدة ليتم اعتبارها حزمة محملة.

  • RoleName

    مثل ClassName، ولكن يجب أن *لا* تعرف الحزمة دالة تسمى "new". هذا يختلف قليلاً عن قيد Moose الذي يحمل نفس الاسم؛ أخبرني إذا تسبب هذا لك في أي مشاكل. (لا يمكنني الوعد بتغيير أي شيء رغم ذلك.)

  • Ref[`a]

    أي قيمة مرجعية معرفة، بما في ذلك الكائنات المسماة.

    بخلاف Moose، Ref هو نوع معلم، يسمح بفحوصات Scalar::Util::reftype، مثل

    Ref["HASH"]  # hashrefs، بما في ذلك hashrefs المسماة
  • ScalarRef[`a]

    قيمة حيث "ref($value) eq "SCALAR" or ref($value) eq "REF"".

    إذا تم تمييزها، فيجب أن تمر القيمة المشار إليها بالقيود الإضافية. على سبيل المثال، ScalarRef[Int] يجب أن يكون مرجعًا إلى قيمة قياسية تحتوي على قيمة عدد صحيح.

  • ArrayRef[`a]

    قيمة حيث "ref($value) eq "ARRAY"".

    إذا تم تمييزها، فيجب أن تمر عناصر المصفوفة بالقيود الإضافية. على سبيل المثال، ArrayRef[Num] يجب أن يكون مرجعًا إلى مصفوفة من الأرقام.

    كتوسيع لنوع ArrayRef في Moose، يمكن تحديد الحد الأدنى والأقصى لطول المصفوفة:

    ArrayRef[CodeRef, 1]        # ArrayRef من CodeRef واحد على الأقل
ArrayRef[FileHandle, 0, 2]  # ArrayRef يصل إلى اثنين من FileHandles
ArrayRef[Any, 0, 100]       # ArrayRef يصل إلى 100 عنصر

    اشترى العملاء الآخرون أيضًا: ArrayLike من Types::TypeTiny.

  • HashRef[`a]

    قيمة حيث "ref($value) eq "HASH"".

    إذا تم تمييزها، فيجب أن تمر قيم الـ hash بالقيود الإضافية. على سبيل المثال، HashRef[Num] يجب أن يكون مرجعًا إلى hash حيث القيم هي أرقام. لا يتم تقييد مفاتيح الـ hash، ولكن Perl يحدها إلى سلاسل نصية؛ انظر Map أدناه إذا كنت بحاجة إلى تقييد قيم الـ hash بشكل أكبر.

    اشترى العملاء الآخرون أيضًا: HashLike من Types::TypeTiny.

  • CodeRef

    قيمة حيث "ref($value) eq "CODE"".

    اشترى العملاء الآخرون أيضًا: CodeLike من Types::TypeTiny.

  • RegexpRef

    مرجع حيث re::is_regexp($value) صحيح، أو مرجع مسمى حيث "$value->isa("Regexp")" صحيح.

  • GlobRef

    قيمة حيث "ref($value) eq "GLOB"".

  • FileHandle

    مقبض ملف.

  • Object

    كائن مسمى.

    (هذا يقبل أيضًا مراجع الـ regex.)

مهيكلة

حسنًا، لقد سرقت بعض الأفكار من MooseX::Types::Structured.

  • Map[`k, `v]

    مشابه لـ HashRef ولكن تم تمييزه بقيود نوعية لكل من المفتاح والقيمة. عادة ما يكون قيد المفاتيح نوعًا فرعيًا من Str.

  • Tuple[...]

    نوع فرعي من ArrayRef، يقبل قائمة من قيود النوع لكل موقع في المصفوفة.

    Tuple[Int, HashRef] سيطابق "[1, {}]" ولكن ليس "[{}, 1]".

  • Dict[...]

    نوع فرعي من HashRef، يقبل قائمة من قيود النوع لكل موقع في الـ hash.

    على سبيل المثال Dict[name => Str, id => Int] يسمح بـ "{ name => "Bob", id => 42 }".

  • Optional[`a]

    يستخدم بالتزامن مع Dict و Tuple لتحديد المواقع التي تعتبر اختيارية ويمكن حذفها (ولكن ليس بالضرورة تعيينها إلى undef صريح).

    Dict[name => Str, id => Optional[Int]] يسمح بـ "{ name => "Bob" }" ولكن ليس "{ name => "Bob", id => "BOB" }".

    لاحظ أن أي استخدام لـ Optional[`a] خارج سياق قيود النوع المميزة Dict و Tuple ليس له معنى كبير، وسلوكه غير محدد. (استثناء: يتم استخدامه بواسطة Type::Params لغرض مشابه لكيفية استخدامه في Tuple.)

تُصدر هذه الوحدة أيضًا نوعًا معلمًا Slurpy، والذي يمكن استخدامه على النحو التالي.
