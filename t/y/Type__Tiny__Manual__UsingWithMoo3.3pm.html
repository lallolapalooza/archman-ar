دليل

مسجلات الأنواع

في جميع الأمثلة السابقة، قمنا باستيراد مجموعة من قيود الأنواع إلى كل فئة:

package Horse {
  use Moo;
  use Types::Standard qw( Str ArrayRef HashRef Int Any InstanceOf );
  use Types::Common::Numeric qw( PositiveInt );
  use Types::Common::String qw( NonEmptyStr );

  has name    => ( is => 'ro', isa => Str );
  has father  => ( is => 'ro', isa => InstanceOf["Horse"] );
  ...;
}

يقوم هذا بإنشاء مجموعة من الدوال الفرعية في مساحة أسماء Horse، واحدة لكل نوع. لقد استخدمنا namespace::autoclean لتنظيفها لاحقًا.

ولكن من الممكن أيضًا تجنب سحب كل هذه إلى مساحة أسماء Horse. بدلاً من ذلك، سنستخدم مسجل أنواع:

package Horse {
  use Moo;
  use Type::Registry qw( t );

  t->add_types('-Standard');
  t->add_types('-Common::String');
  t->add_types('-Common::Numeric');

  t->alias_type('InstanceOf["Horse"]' => 'Horsey');

  has name     => ( is => 'ro', isa => t('Str') );
  has father   => ( is => 'ro', isa => t('Horsey') );
  has mother   => ( is => 'ro', isa => t('Horsey') );
  has children => ( is => 'ro', isa => t('ArrayRef[Horsey]') );
  ...;
}

لا تحتاج حتى إلى استيراد الدالة t(). يمكن استخدام Type::Registry بطريقة موجهة للكائنات بالكامل.

package Horse {
  use Moo;
  use Type::Registry;

  my $reg = Type::Registry->for_me;

  $reg->add_types('-Standard');
  $reg->add_types('-Common::String');
  $reg->add_types('-Common::Numeric');

  $reg->alias_type('InstanceOf["Horse"]' => 'Horsey');

  has name => ( is => 'ro', isa => $reg->lookup('Str') );
  ...;
}

يمكنك إنشاء مسجلين بتعريفات مختلفة تمامًا لنفس النوع المسمى.

my $dracula = Aristocrat->new(name => 'Dracula');

package AristocracyTracker {
  use Type::Registry;

  my $reg1 = Type::Registry->new;
  $reg1->add_types('-Common::Numeric');
  $reg1->alias_type('PositiveInt' => 'Count');

  my $reg2 = Type::Registry->new;
  $reg2->add_types('-Standard');
  $reg2->alias_type('InstanceOf["Aristocrat"]' => 'Count');

  $reg1->lookup("Count")->assert_valid("1");
  $reg2->lookup("Count")->assert_valid($dracula);
}

يستخدم Type::Registry "AUTOLOAD"، لذا تعمل أشياء مثل هذه:

$reg->ArrayRef->of( $reg->Int );

على الرغم من أنه يمكنك إنشاء أكبر عدد تريده من المسجلات، إلا أن Type::Registry سينشئ مسجلًا افتراضيًا لكل حزمة.

# إنشاء مسجل فارغ جديد.
# 
my $reg = Type::Registry->new;

# الحصول على المسجل الافتراضي لحزمتي.
# سيتم ملؤه مسبقًا بأي أنواع قمنا باستيرادها باستخدام `use`.
#
my $reg = Type::Registry->for_me;

# الحصول على المسجل الافتراضي لحزمة أخرى.
#
my $reg = Type::Registry->for_class("Horse");

مسجلات الأنواع هي مكان مناسب لتخزين مجموعة من الأنواع دون تلويث مساحة الأسماء الخاصة بك. إنها ليست مثل مكتبات الأنواع. Types::Standard و Types::Common::String و Types::Common::Numeric هي مكتبات أنواع؛ حزم تصدر أنواعًا ليستخدمها الآخرون. سننظر في كيفية إنشاء واحدة من هذه لاحقًا.

في الوقت الحالي، إليك أفضل طريقة للتفكير في الفرق:

  • مسجل الأنواع

    قم بتنسيق مجموعة من الأنواع لاستخدامها هنا في هذه الفئة. هذه المجموعة هي تفصيل تنفيذي.

  • مكتبة الأنواع

    قم بتصدير مجموعة من الأنواع لاستخدامها عبر فئات متعددة. هذه المجموعة هي جزء من واجهة برمجة التطبيقات الخاصة بك.

استيراد الدوال

لقد رأينا كيف أن Types::Standard، على سبيل المثال، تصدر دالة فرعية تسمى "Int" تعيد كائن النوع Int.

use Types::Standard qw( Int );

my $type = Int;
$type->check($value) or die $type->get_message($value);

مكتبات الأنواع قادرة أيضًا على تصدير دوال مساعدة أخرى.

"is_*"

هذا اختصار للتحقق مما إذا كانت القيمة تفي بشرط النوع:

use Types::Standard qw( is_Int );

if ( is_Int $value ) {
  ...;
}

قد يكون استدعاء is_Int($value) أسرع بشكل هامشي من استدعاء "Int->check($value)" لأنه يتجنب استدعاء الطريقة. (استدعاءات الطريقة في Perl تنتهي بكونها أبطأ من استدعاءات الدوال العادية.)

قد يكون استخدام أشياء مثل "is_ArrayRef" في الكود الخاص بك مفضلًا على "ref($value) eq "ARRAY"" لأنه أكثر أناقة، ويؤدي إلى فحص أنواع أكثر اتساقًا، وقد يكون أسرع أيضًا. (يمكن أن يكون Type::Tiny سريعًا جدًا؛ فهو قادر أحيانًا على تصدير هذه الدوال كدوال XS.)

إذا كنت تتحقق من قيود الأنواع مثل "is_ArrayRef" أو "is_InstanceOf"، فلا توجد طريقة لإعطاء معلمة. "is_ArrayRef[Int]($value)" لا يعمل، ولا "is_ArrayRef(Int, $value)" ولا "is_ArrayRef($value, Int)". بالنسبة لبعض الأنواع مثل "is_InstanceOf"، هذا يجعلها عديمة الفائدة تمامًا؛ بدون القدرة على إعطاء اسم فئة، فإنها تعمل بنفس طريقة "is_Object". انظر "تصدير الأنواع المعلمة" للحصول على حل. أيضًا، تحقق من isa.

يوجد أيضًا دالة "is" عامة.

use Types::Standard qw( ArrayRef Int );
use Type::Utils qw( is );

if ( is ArrayRef[Int], \@numbers ) {
  ...;
}

"assert_*"

بينما تعيد is_Int($value) قيمة منطقية، فإن assert_Int($value) سيثير خطأ إذا لم تتوافق القيمة مع القيد، ويعيد القيمة بخلاف ذلك. لذا يمكنك القيام بما يلي:

my $sum = assert_Int($x) + assert_Int($y);

وستحصل على مجموع الأعداد الصحيحة $x و $y، وانفجار إذا كان أي منهما ليس عددًا صحيحًا!

Assert مفيد للتحقق السريع من المعلمات إذا كنت تتجنب Type::Params لسبب غريب:

sub add_numbers {
  my $x = assert_Num(shift);
  my $y = assert_Num(shift);
  return $x + $y;
}

يمكنك أيضًا استخدام دالة "assert" عامة.

use Type::Utils qw( assert );

sub add_numbers {
  my $x = assert Num, shift;
  my $y = assert Num, shift;
  return $x + $y;
}

"to_*"

هذا اختصار للتحويل:

my $truthy = to_Bool($value);

إنه يثق في أن التحويل قد تم بشكل جيد. يمكنك دمجه مع تأكيد إذا كنت تريد التأكد.

my $truthy = assert_Bool(to_Bool($value));

اختصارات لتصدير الدوال

هذا مطول بعض الشيء:

use Types::Standard qw( Bool is_Bool assert_Bool to_Bool );

أليس هذا أفضل قليلاً؟

use Types::Standard qw( +Bool );

العلامة الموجبة تخبر مكتبة الأنواع بتصدير ليس فقط النوع نفسه، ولكن جميع دوال المساعدة أيضًا.

يمكنك أيضًا استخدام:

use Types::Standard -types;   # تصدير Int, Bool, etc
use Types::Standard -is;      # تصدير is_Int, is_Bool, etc
use Types::Standard -assert;  # تصدير assert_Int, assert_Bool, etc
use Types::Standard -to;      # تصدير to_Bool, etc
use Types::Standard -all;     # تصدير كل شيء!!!

لذا، إذا تخيلت أن الدوال التي تصدرها Types::Standard هي كالتالي:

qw(
  Str             is_Str          assert_Str
  Num             is_Num          assert_Num
  Int             is_Int          assert_Int
  Bool            is_Bool         assert_Bool     to_Bool
  ArrayRef        is_ArrayRef     assert_ArrayRef
);
# ... والمزيد

إذًا "+" تصدر مجموعة أفقية منها، و "-" تصدر مجموعة عمودية.

تصدير الأنواع المعلمة

من الممكن تصدير أنواع معلمة مثل ArrayRef، ولكن من الممكن أيضًا تصدير أنواع *معلمة*.

use Types::Standard qw( ArrayRef Int );
use Types::Stan

أنواع معيارية تُصدر أسماء مخصصة

إذا كان لديك نوع معيار مُعرّف مسبقًا، يمكنك استخدامه كأسماء لأنواع جديدة:

use Types::Standard -types;
use Types::Standard::ArrayRef (
  IntList => { of => Int, -as => 'IntList' },
);

has numbers => (is => 'ro', isa => IntList);

يجب أن يكون استخدام is_IntList($value) أسرع بكثير من "ArrayRef->of(Int)->check($value)".

هذه الحيلة تعمل فقط مع الأنواع المُعلمة التي لها معامل واحد، مثل ArrayRef، HashRef، InstanceOf، إلخ. (عذرًا، "Dict" و "Tuple"!)

منذ Type::Tiny 2.8.0، كان هناك دعم تجريبي لطريقة مختلفة لتصدير إصدارات مُعلمة من بعض القيود النوعية القابلة للتعليم.

use Types::Standard -types;
use Types::Standard::ArrayRef (
  IntList         => { of => Int },
  StrList         => { of => Str },
  NonEmptyStrList => { of => Str->where( sub { length($_) > 0 } ) },
  StrNonEmptyList => { of => Str, where => sub { @$_ > 0 } },
  NEStrNEList     => {
    of    => Str->where( sub { length($_) > 0 } ),
    where => sub { @$_ > 0 },
  },
);

assert_IntList [ 1.. 5 ];                      # لا يموت

is_NonEmptyStrList [ "foo", "bar" ];           # ==> صحيح
is_NonEmptyStrList [ "foo", "" ];              # ==> خطأ
is_NonEmptyStrList [];                         # ==> صحيح

is_StrNonEmptyList [ "foo", "bar" ];           # ==> صحيح
is_StrNonEmptyList [ "foo", "" ];              # ==> صحيح
is_StrNonEmptyList [];                         # ==> خطأ

is_NEStrNEList [ "foo", "bar" ];               # ==> صحيح
is_NEStrNEList [ "foo", "" ];                  # ==> خطأ
is_NEStrNEList [];                             # ==> خطأ

وبالطبع، يقبل "where" أيضًا سلسلة من شيفرة Perl.

استيرادات معجمية

Type::Tiny 2.0 مع Perl 5.37.2+ تسمح بالاستيرادات ذات النطاق المعجمي. لذا:

my $is_ok = do {
  use Types::Standard -lexical, qw( Str ArrayRef );
  ArrayRef->of( Str )->check( \@things );
};

# أنواع Str و ArrayRef غير مُعرفة هنا.

افعل ما أقصده!

use Type::Utils qw( dwim_type );

my $type = dwim_type("ArrayRef[Int]");

"dwim_type" سيبحث عن قيد نوع من سلسلة ويحاول تخمين ما قصدته.

إذا كان قيد نوع قمت باستيراده باستخدام "use"، فسيجده. وإلا، إذا كنت تستخدم Moose أو Mouse، فسيبذل قصارى جهده للسؤال. أو إذا كان في Types::Standard، فسيبحث هناك. وإذا لم يكن لديه فكرة بعد، فسيفترض أن dwim_type("Foo") تعني dwim_type("InstanceOf['Foo']").

إنه يقوم فقط بالكثير من التخمين.

ستستخدم الدالة "is" "dwim_type" إذا مررت لها سلسلة كنوع.

use Type::Utils qw( is );

if ( is "ArrayRef[Int]", \@numbers ) {
  ...;
}

Types::Common

لاحظ أننا في العديد من الأمثلة نستورد دالة أو اثنتين من وحدات قليلة مختلفة:

use Types::Common::Numeric qw( PositiveInt );
use Types::Common::String qw( NonEmptyStr );
use Types::Standard qw( ArrayRef Slurpy );
use Type::Params qw( signature_for );

توجد وحدة تسمى Types::Common تعمل كمكان واحد يمكنك استخدامه لاستيراد معظم أنواع ووظائف Type::Tiny شائعة الاستخدام.

use Types::Common qw(
  PositiveInt NonEmptyStr ArrayRef Slurpy
  signature_for
);

يوفر Types::Common:

  • جميع الأنواع من Types::Standard.
  • جميع الأنواع من Types::Common::Numeric و Types::Common::String.
  • جميع الأنواع من Types::TypeTiny.
  • العلامة "-sigs" من Type::Params.
  • الدالة t() من Type::Registry.
