TYPE(1P) دليل مبرمج POSIX TYPE(1P)

المقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تنفيذ Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

type — كتابة وصف لنوع الأمر

الملخص

type name...

الوصف

يحدد الأداة المساعدة type كيف سيتم تفسير كل وسيط إذا تم استخدامه كاسم أمر.

الخيارات

لا شيء.

المعاملات

سيتم دعم المعامل التالي:

name
اسم ليتم تفسيره.

المدخل القياسي

غير مستخدم.

ملفات الإدخال

لا شيء.

متغيرات البيئة

سيؤثر متغيرات البيئة التالية على تنفيذ type:

LANG
توفير قيمة افتراضية لمتغيرات التدويل التي لم يتم تعيينها أو كانت فارغة. (راجع الجزء الخاص بالتعريفات الأساسية من POSIX.1-2017، القسم 8.2، متغيرات التدويل لمعرفة أولوية متغيرات التدويل المستخدمة لتحديد قيم فئات اللغة.)
LC_ALL
إذا تم تعيينه إلى قيمة سلسلة غير فارغة، فسيتم تجاوز قيم جميع متغيرات التدويل الأخرى.
LC_CTYPE
تحديد اللغة لتفسير تسلسلات البايت لبيانات النص كأحرف (على سبيل المثال، أحرف أحادية البايت مقابل أحرف متعددة البايت في المعاملات).
LC_MESSAGES

تحديد اللغة التي يجب استخدامها للتأثير على تنسيق ومحتويات رسائل التشخيص المكتوبة إلى الخطأ القياسي.
NLSPATH
تحديد موقع كتالوجات الرسائل لمعالجة LC_MESSAGES.
PATH
تحديد موقع name، كما هو موضح في الجزء الخاص بالتعريفات الأساسية من POSIX.1-2017، الفصل 8، متغيرات البيئة.

الأحداث غير المتزامنة

افتراضي.

الخرج القياسي

يحتوي الخرج القياسي لـ type على معلومات حول كل معامل بتنسيق غير محدد. تحدد المعلومات المقدمة عادةً المعامل كأمر مدمج في الصدفة، أو دالة، أو اسم مستعار، أو كلمة مفتاحية، وعند الاقتضاء، قد تعرض المسار الكامل للمعامل.

الخطأ القياسي

يجب استخدام الخطأ القياسي فقط لرسائل التشخيص.

استخدام التطبيق

نظرًا لأن type يجب أن يكون على دراية بمحتويات بيئة تنفيذ الصدفة الحالية (مثل قوائم الأوامر والدوال والأوامر المدمجة التي يعالجها hash)، فإنه يتم توفيره دائمًا كأمر مدمج عادي في الصدفة. إذا تم استدعاؤه في بيئة تنفيذ أداة منفصلة، مثل إحدى الحالات التالية:

nohup type writer
find . -type f | xargs type

قد لا ينتج عنه نتائج دقيقة.
