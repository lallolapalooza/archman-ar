Type__Registry(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Type::Registry(3) وثائق Perl مقدمة من المستخدم Type::Registry(3)

الاسم

Type::Registry - دالة تجزئة مذهبة للبحث عن قيود النوع

الملخص

package Foo::Bar;

use Type::Registry;

my $reg = "Type::Registry"->for_me;  # سجل لـ Foo::Bar

# تسجيل جميع الأنواع من Types::Standard
$reg->add_types(-Standard);

# تسجيل نوع واحد فقط من Types::XSD
$reg->add_types(-XSD => ["NonNegativeInteger"]);

# تسجيل جميع الأنواع من MyApp::Types
$reg->add_types("MyApp::Types");

# إنشاء اسم مستعار للنوع
$reg->alias_type("NonNegativeInteger" => "Count");

# البحث عن قيد نوع
my $type = $reg->lookup("ArrayRef[Count]");

$type->check([1, 2, 3.14159]);  # يسبب خطأ

بدلا من ذلك:

package Foo::Bar;

use Type::Registry qw( t );

# تسجيل جميع الأنواع من Types::Standard
t->add_types(-Standard);

# تسجيل نوع واحد فقط من Types::XSD
t->add_types(-XSD => ["NonNegativeInteger"]);

# تسجيل جميع الأنواع من MyApp::Types
t->add_types("MyApp::Types");

# إنشاء اسم مستعار للنوع
t->alias_type("NonNegativeInteger" => "Count");

# البحث عن قيد نوع
my $type = t("ArrayRef[Count]");

$type->check([1, 2, 3.14159]);  # يسبب خطأ

الحالة

هذه الوحدة مغطاة بسياسة استقرار Type-Tiny.

الوصف

سجل النوع هو في الأساس مجرد دالة تجزئة تقوم بربط أسماء الأنواع بأشياء قيد النوع.

المنشئات

"new"
إنشاء دالة تجزئة مذهبة جديدة.
for_class($class)
إنشاء أو إرجاع دالة التجزئة المذهبة الموجودة والمرتبطة بالفئة المحددة.

لاحظ أن أي قيد نوع قمت باستيراده من مكتبات أنواع تستند إلى Type::Library سيكون متاحًا تلقائيًا في سجل فئتك.

"for_me"
إنشاء أو إرجاع دالة التجزئة المذهبة الموجودة والمرتبطة بالمتصل.

الأساليب

add_types(@libraries)
تتم معاملة قائمة المكتبات على أنها "قائمة خيارات" (مثل Data::OptList).

السلاسل النصية هي أسماء مكتبات الأنواع؛ إذا كان الحرف الأول شرطة، فإنه يتوسع إلى البادئة "Types::". إذا تلاها مصفوفة، فهذه هي قائمة الأنواع المراد استيرادها من تلك المكتبة. بخلاف ذلك، يستورد جميع الأنواع من المكتبة.

use Type::Registry qw(t);

t->add_types(-Standard);  # أو: t->add_types("Types::Standard");

t->add_types(
   -TypeTiny => ['HashLike'],
   -Standard => ['HashRef' => { -as => 'RealHash' }],
);

يمكن أيضًا إضافة مكتبات MooseX::Types (وتجريبيًا، MouseX::Types) بهذه الطريقة، ولكن *لا يمكن أن يليها مصفوفة* *أنواع للاستيراد*.

"add_type($type, $name)"
الشكل المفرد الذي طال انتظاره لـ "add_types". بالنظر إلى كائن قيد نوع، يضيفه إلى السجل باسم معين. يمكن حذف الاسم، وفي هذه الحالة يتم استدعاء "$type->name"، وسيقوم Type::Registry برمي خطأ إذا كان $type مجهولا. إذا تم إعطاء اسم صراحة، فلا يهتم Type::Registry على الإطلاق ما إذا كان قيد النوع مجهولا.

يمكن لهذا الأسلوب إضافة قيود النوع MooseX::Types و MouseX::Types؛ في الواقع، أي شيء يمكن معالجته بواسطة دالة "to_TypeTiny" الخاصة بـ Types::TypeTiny. (ضع في اعتبارك أن to_TypeTiny يؤدي *دائمًا* إلى قيد نوع مجهول، لذلك سيكون $name مطلوبًا.)

"alias_type($oldname, $newname)"
إنشاء اسم مستعار لنوع موجود.
simple_lookup($name)
البحث عن نوع في السجل بالاسم.

يرجع undef إذا لم يتم العثور عليه.

foreign_lookup($name)
مثل "simple_lookup"، ولكن إذا كان اسم النوع يحتوي على "::"، فسوف يحاول تحميله من مكتبة أنواع. (وسيحاول تحميل هذه الوحدة.)
lookup($name)
البحث بالاسم، مع لغة خاصة بالنطاق. 
t->lookup("Int|ArrayRef[Int]")

يمكن تلخيص لغة DSL على النحو التالي:

X               نوع من هذا السجل
My::Lib::X      نوع من مكتبة أنواع
~X              نوع مكمل
X | Y           اتحاد
X & Y           تقاطع
X[...]          نوع معلم
slurpy X        نوع slurpy
Foo::Bar::      نوع فئة

يسبب خطأ إذا لم يتم العثور عليه.

make_union(@constraints), make_intersection(@constraints), make_class_type($class), make_role_type($role)
أساليب ملائمة لإنشاء قيود أنواع شائعة معينة.
"AUTOLOAD"
تم تحميله بشكل زائد لاستدعاء "lookup". 
$registry->Str;  # مثل $registry->lookup("Str")
"get_parent", set_parent($reg), "clear_parent", "has_parent"
أمور متقدمة. تسمح للسجل بأن يكون له سجل "أب" يرث منه قيود الأنواع.

الدوال

"t"
يمكن لهذه الفئة تصدير دالة "t" تعمل مثل ""Type::Registry"->for_class($importing_class)".

Type::Registry(3pm)

الاسم

Type::Registry - Perl module for extensible type checking and conversion

الملخص

الوصف

This module provides a flexible and extensible way to define, check, and convert types. It's particularly useful when dealing with complex data structures or when you need to enforce specific data formats.

The core idea is to register type checkers and converters, allowing you to associate them with specific type names. You can then use the registry to validate data against a type or to convert data from one type to another.

الأساليب

نظرة عامة على الأساليب

  • register_type(name => $type_name, check => $coderef, [convert => $coderef]): Registers a new type with its checker and optional converter.
  • check_type(data => $data, type => $type_name): Checks if the given data conforms to the specified type. Returns true if it does, false otherwise.
  • convert_type(data => $data, from_type => $from_type_name, to_type => $to_type_name): Converts the given data from one type to another. Returns the converted data or undef if conversion is not possible.
  • get_checker(type => $type_name): Retrieves the checker coderef for a given type.
  • get_converter(from_type => $from_type_name, to_type => $to_type_name): Retrieves the converter coderef between two types.
