Type__Tiny__Manual__NonOO(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Type::Tiny::Manual::NonOO(3) وثائق Perl المساهمة من قبل المستخدم Type::Tiny::Manual::NonOO(3)

الاسم

Type::Tiny::Manual::NonOO - Type::Tiny في كود غير موجه للكائنات

دليل

على الرغم من أن Type::Tiny تم تصميمه مع البرمجة الموجهة للكائنات في الاعتبار، وخاصة فئات وأدوار أسلوب Moose، إلا أنه يمكن استخدامه في البرمجة الإجرائية والوظيفية.

إذا كنت قد قرأت Type::Tiny::Manual::UsingWithMoo، فيجب أن تفهم كيف يمكن استخدام Type::Params للتحقق من صحة معلمات الأساليب. يمكن تطبيق هذه التقنية نفسها على الدوال العادية أيضًا. يمكن العثور على مزيد من المعلومات حول التحقق من المعلمات في Type::Tiny::Manual::Params.

قد تكون الدوال "is_*" و "assert_*" المصدرة بواسطة مكتبات الأنواع مفيدة أيضًا في الكود غير الموجه للكائنات. انظر Type::Tiny::Manual::UsingWithMoo3.

Type::Tiny والمطابقة الذكية

قدم Perl 5.10 عامل المطابقة الذكية "~~"، والذي تم إهماله منذ ذلك الحين لأنه على الرغم من أن الفكرة العامة سليمة إلى حد ما، إلا أن التفاصيل كانت فوضوية بعض الشيء.

مع ذلك، لدى Type::Tiny دعم للمطابقة الذكية وأنا أوثقها هنا لأنه لا يوجد مكان أفضل لوضعها.

يمكن استخدام ما يلي للتحقق مما إذا كانت القيمة تمر باختبار نوع:

$value ~~ SomeType

حيث يصبح الأمر غريبًا إذا كانت $value كائنًا وتتجاوز "~~". أي تجاوز لـ "~~" سيفوز؟ لا أعرف.

من الأفضل استخدام:

SomeType->check( $value )   # أكثر موثوقية، أسرع على الأرجح
is_SomeType($value)         # أكثر موثوقية، أسرع بالتأكيد

من الممكن أيضًا القيام بما يلي:

$value ~~ SomeType->coercion

هذا يتحقق مما إذا كانت $value تتطابق مع أي نوع يمكن تحويله إلى SomeType.

لكن من الأفضل استخدام:

SomeType->coercion->has_coercion_for_value( $value )

"given" و "when"

مرتبط بعامل المطابقة الذكية هو بناء الجملة "given"/"when".

هذا لن يفعل ما تريد:

use Types::Standard qw( Str Int );

given ( $value ) {
  when ( Int ) { ... }
  when ( Str ) { ... }
}

هذا سيفعل ما أردته:

use Types::Standard qw( is_Str is_Int );

given ( $value ) {
  when ( \&is_Int ) { ... }
  when ( \&is_Str ) { ... }
}

آسف، هذه هي طريقة عمل Perl.

لكن من الأفضل:

use Types::Standard qw( Str Int );
use Type::Utils qw( match_on_type );

match_on_type $value => (
  Str, sub { ... },
  Int, sub { ... },
);

إذا كان هذا جزءًا من حلقة أو جزءًا آخر يتم استدعاؤه بشكل متكرر من الكود، يمكنك تجميع الفحوصات مرة واحدة واستخدامها عدة مرات:

use Types::Standard qw( Str Int );
use Type::Utils qw( compile_match_on_type );

my $dispatch_table = compile_match_on_type(
  Str, sub { ... },
  Int, sub { ... },
);

$dispatch_table->($_) for @lots_of_values;

كما هو الحال مع معظم الأشياء في Type::Tiny، يمكن استبدال تلك الدوال (coderefs) بسلاسل نصية من كود Perl.
