Type__Tiny__Union(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Type::Tiny::Union(3) وثائق بيرل المساهمة من المستخدم Type::Tiny::Union(3)

الاسم

Type::Tiny::Union - قيود النوع الاتحادي

الملخص

الاستخدام عبر الحمل الزائد للمشغل "|":

package Local::Stash {
  use Moo;
  use Types::Common qw( ArrayRef HashRef );

  has data => (
    is   => 'ro',
    isa  => HashRef | ArrayRef,
  );
}

my $x = Local::Stash->new( data => {} );  # مقبول
my $y = Local::Stash->new( data => [] );  # مقبول

الاستخدام عبر واجهة Type::Tiny::Union للكائنات:

package Local::Stash {
  use Moo;
  use Types::Common qw( ArrayRef HashRef );
  use Type::Tiny::Union;

  my $AnyData = Type::Tiny::Union->new(
    name             => 'AnyData',
    type_constraints => [ HashRef, ArrayRef ],
  );

  has data => (
    is   => 'ro',
    isa  => $AnyData,
  );
}

الاستخدام عبر الواجهة الوظيفية لـ Type::Utils:

package Local::Stash {
  use Moo;
  use Types::Common qw( ArrayRef HashRef );
  use Type::Utils;

  my $AnyData = union AnyData => [ HashRef, ArrayRef ];

  has data => (
    is   => 'ro',
    isa  => $AnyData,
  );
}

الحالة

هذه الوحدة مغطاة بسياسة استقرار Type-Tiny.

الوصف

قيود النوع الاتحادي.

هذه الحزمة ترث من Type::Tiny؛ راجعها لمعظم الوثائق. الاختلافات الرئيسية مدرجة أدناه:

المنشئ

لا يزال منشئ "new" من Type::Tiny يعمل، بالطبع. ولكن هناك أيضًا:

new_by_overload(%attributes)
مثل منشئ "new"، ولكنه سيعيد أحيانًا قيد نوع آخر ليس بالضرورة نسخة من Type::Tiny::Union، ولكنه يجسد نفس المعنى. يستخدم هذا المنشئ الحمل الزائد للمشغل "|" بواسطة Type::Tiny.

السمات

"type_constraints"
مصفوفة من قيود النوع.

عند تمريرها إلى المنشئ، إذا كان أي من قيود النوع في الاتحاد هو نفسه قيد نوع اتحادي، فسيتم "تفجيره" في الاتحاد الجديد.

"constraint"
على عكس Type::Tiny، لا يمكنك تمرير دالة تشفير قيد إلى المنشئ. بدلاً من ذلك، اعتمد على الافتراضي.
"inlined"
على عكس Type::Tiny، لا يمكنك تمرير دالة تشفير تضمين إلى المنشئ. بدلاً من ذلك، اعتمد على الافتراضي.
"parent"
على عكس Type::Tiny، لا يمكنك تمرير دالة تشفير تضمين إلى المنشئ. سيتم حساب الأصل تلقائيًا بدلاً من ذلك.
"coercion"
من المحتمل ألا تمرر هذا إلى المنشئ. (لم يتم حظره حاليًا، حيث قد يكون له فائدة لم أفكر فيها بعد.)

سيكون الافتراضي الذي تم إنشاؤه تلقائيًا كائن Type::Coercion::Union.

الطرق

find_type_for($value)
يعيد أول قيد نوع فردي في الاتحاد الذي يجتاز القيمة $value.
stringifies_to($constraint)
راجع Type::Tiny::ConstrainedObject.
numifies_to($constraint)
راجع Type::Tiny::ConstrainedObject.
"with_attribute_values($attr1 => $constraint1, ...)"
راجع Type::Tiny::ConstrainedObject.

الحمل الزائد

•
يستدعي تحويل المصفوفة "type_constraints".
