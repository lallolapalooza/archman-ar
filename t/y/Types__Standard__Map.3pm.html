Types__Standard__Map(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Types::Standard::Map(3) توثيق مساهمة المستخدم في بيرل Types::Standard::Map(3)

الاسم

Types::Standard::Map - أداة تصدير لقيود نوع Map

الملخص

use Types::Standard -types;

# الطريقة العادية للتحقق من الخريطة.
#
Map->of( Int, Str )->assert_valid( { 1 => "one" } );

use Types::Standard::Map IntsToStrs => { keys => Int, values => Str },

# اختصار مُصدَّر
#
assert_IntsToStrs { 1 => "one" };

الحالة

هذه الوحدة ليست مغطاة بسياسة استقرار Type-Tiny.

الوصف

هذه في الغالب تعليمات برمجية داخلية، ولكنها يمكن أن تعمل أيضًا كأداة تصدير.

التصديرات

يمكن استخدام Types::Standard::Map تجريبيًا كمُصدِّر.

use Types::Standard 'Int';
use Types::Standard::Map IntsToStrs => { keys => Int, values => Str },

سيؤدي هذا إلى تصدير الدوال التالية إلى مساحة الاسم الخاصة بك:

"IntsToStrs"
is_IntsToStrs( $value )
assert_IntsToStrs( $value )
to_IntsToStrs( $value )

يمكن تصدير أنواع متعددة دفعة واحدة:

use Types::Standard -types;
use Types::Standard::Map (
  IntsToStrs  => { keys => Int, values => Str },
  StrsToInts  => { keys => Str, values => Int },
);

assert_StrsToInts { two => 2 };   # يجب ألا يموت

من الممكن تقييد الـ hashref بشكل أكبر باستخدام "where":

use Types::Standard::Dict MyThing => {
  keys   => Str->where( sub { ... } ),
  values => Int->where( sub { ... } ),
  where  => sub { ... },
};
