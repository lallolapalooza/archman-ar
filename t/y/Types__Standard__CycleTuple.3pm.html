Types__Standard__CycleTuple(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Types::Standard::CycleTuple(3) وثائق Perl مساهمة من المستخدم Types::Standard::CycleTuple(3)

الاسم

Types::Standard::CycleTuple - أداة تصدير لتقييد نوع CycleTuple

الملخص

use Types::Standard -types;

# الطريقة العادية للتحقق من قائمة أزواج من الأعداد الصحيحة.
#
CycleTuple->of( Int, Int )->assert_valid( [ 7, 49, 8, 64 ] );

use Types::Standard::CycleTuple IntPairs => { of => [ Int, Int ] },

# اختصار مُصدَّر
#
assert_IntPairs [ 7, 49, 8, 64 ];

الحالة

هذه الوحدة ليست مغطاة بسياسة استقرار Type-Tiny.

الوصف

هذا في الغالب رمز داخلي، ولكنه يمكن أن يعمل أيضًا كأداة تصدير.

التصديرات

يمكن استخدام Types::Standard::CycleTuple تجريبيًا كـ مُصدِّر.

use Types::Standard 'Int';
use Types::Standard::CycleTuple IntPairs => { of => [ Int, Int ] };

سيقوم هذا بتصدير الوظائف التالية إلى مساحة الاسم الخاصة بك:

"IntPairs"
is_IntPairs( $value )
assert_IntPairs( $value )
to_IntPairs( $value )

يمكن تصدير أنواع متعددة دفعة واحدة:

use Types::Standard -types;
use Types::Standard::CycleTuple (
  IntIntPairs   => { of => [ Int, Int ] },
  StrIntPairs   => { of => [ Str, Int ] },
);

assert_StrIntPairs [ one => 1, two => 2 ];   # يجب ألا يموت

من الممكن تقييد cycle tuple بشكل أكبر باستخدام "where":

use Types::Standard::CycleTuple MyThing => { of => [ ... ], where => sub { ... } };
