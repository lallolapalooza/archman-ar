Types__Standard__ScalarRef(3pm)

الحزمة: perl-type-tiny

التراخيص: PerlArtistic, GPL

Types::Standard::ScalarRef(3) توثيق بيرل مقدم من المستخدم Types::Standard::ScalarRef(3)

الاسم

Types::Standard::ScalarRef - أداة تصدير لقيود نوع ScalarRef

ملخص

use Types::Standard -types;

# الطريقة العادية للتحقق من مرجع لسلسلة نصية.
#
ScalarRef->of( Str )->assert_valid( \ "foo" );

use Types::Standard::ScalarRef StrRef => { of => Str },

# اختصار مصدّر
#
assert_StrRef \ "foo";

الحالة

لا يندرج هذا الموديول تحت سياسة استقرار Type-Tiny.

الوصف

هذه في الغالب أكواد داخلية، ولكن يمكنها أيضًا العمل كأداة تصدير.

التصديرات

يمكن استخدام Types::Standard::ScalarRef تجريبياً كـ مُصدِّر.

use Types::Standard 'Str';
use Types::Standard::ScalarRef StrRef => { of => Str };

سيقوم هذا بتصدير الوظائف التالية إلى مساحة الأسماء الخاصة بك:

"StrRef"
is_StrRef( $value )
assert_StrRef( $value )
to_StrRef( $value )

يمكن تصدير أنواع متعددة في وقت واحد:

use Types::Standard -types;
use Types::Standard::ScalarRef (
  IntRef  => { of => Int },
  StrRef  => { of => Str },
);

assert_IntRef \42;   # لا ينبغي أن يموت

من الممكن تقييد المرجع بشكل أكبر باستخدام "where":

use Types::Standard::ScalarRef MyThing => { of => Str, where => sub { ... } };

الأخطاء
