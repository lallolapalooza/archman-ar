tlsrpt_set_nonblocking(3)

الحزمة: libtlsrpt

التراخيص: LGPL-3.0-or-later

TLSRPT_SET_NONBLOCKING(3) tlsrpt_set_nonblocking TLSRPT_SET_NONBLOCKING(3)

الاسم

tlsrpt_set_nonblocking - يستعيد استدعاء `sendto` داخل `tlsrpt_finish_delivery_request` إلى سلوكه الافتراضي غير المانع

الملخص

#include <tlsrpt.h>

void tlsrpt_set_nonblocking()

الوصف

تقوم الدالة tlsrpt_set_nonblocking باستعادة استدعاء sendto داخل tlsrpt_finish_delivery_request إلى سلوكه الافتراضي غير المانع.

قيمة الإرجاع

الدالة tlsrpt_set_nonblocking ليس لها قيمة إرجاع.

راجع أيضًا

tlsrpt_set_blocking(3)
