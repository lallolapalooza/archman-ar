tlsrpt_init_delivery_request(3)

الحزمة: libtlsrpt

التراخيص: LGPL-3.0-or-later

TLSRPT_INIT_DELIVERY_REQUEST(3) tlsrpt_init_delivery_request TLSRPT_INIT_DELIVERY_REQUEST(3)

الاسم

tlsrpt_init_delivery_request - تخصيص وتهيئة كائن `struct tlsrpt_dr_t`

الملخص

#include <tlsrpt.h>

int tlsrpt_init_delivery_request(struct tlsrpt_dr_t** pdr, struct tlsrpt_connection_t* con, const char* domainname, const char* policyrecord)

الوصف

تقوم الدالة tlsrpt_init_delivery_request بتخصيص وتهيئة الكائن struct tlsrpt_dr_t. يجب تحرير الموارد التي تقوم بتخصيصها عن طريق استدعاء tlsrpt_finish_delivery_request أو tlsrpt_cancel_delivery_request.

قيمة الإرجاع

تُرجع الدالة tlsrpt_init_delivery_request القيمة 0 عند النجاح، ورمز خطأ مجمع عند الفشل. يمكن تحليل رمز الخطأ المجمع باستخدام الدالة tlsrpt_strerror.

راجع أيضًا

tlsrpt_cancel_delivery_request(3), tlsrpt_finish_delivery_request(3), tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
