DESCRIPTION

\n

The tls_config_set_protocols() function sets the allowed TLS protocols for config to protocols.

\n

The tls_config_get_protocols() function returns the protocols set for config.

\n

The tls_config_parse_protocols() function parses a string representation of protocols.

\n

The tls_config_set_dheparams() function sets the Diffie-Hellman parameters for config to params.

\n

The tls_config_set_ecdhecurve() function sets the Elliptic Curve Diffie-Hellman curve for config to curve.

\n

The tls_config_prefer_ciphers_client() function sets the preferred cipher list for config for client connections to ciphers. If is_fallback is non-zero, the cipher list is treated as a fallback list.

\n

The tls_config_prefer_ciphers_server() function sets the preferred cipher list for config for server connections to ciphers.

\n

The tls_config_set_alpn() function sets the Application-Layer Protocol Negotiation (ALPN) string for config to alpn.

\n
\n
\n

RETURN VALUES

\n

All functions return 0 on success, or -1 on error.
