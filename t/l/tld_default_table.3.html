tld_default_table(3)

الحزمة: libidn

التراخيص: GPL3, LGPL

tld_default_table(3) libidn tld_default_table(3)

الاسم

tld_default_table - وظيفة API

الملخص

#include <tld.h>

const Tld_table * tld_default_table(const char * tld, const Tld_table ** overrides);

المعاملات

const char * tld
اسم TLD (على سبيل المثال، "com") كسلسلة بايت ASCII تنتهي بصفر.
const Tld_table ** overrides
مصفوفة إضافية تنتهي بصفر من هياكل معلومات Tld_table لـ TLDs، أو NULL لاستخدام جداول المكتبة الافتراضية فقط.

الوصف

الحصول على جدول TLD لـ TLD مسمى، باستخدام الافتراضيات الداخلية، والتي قد تتجاوزها الجداول (الاختيارية) المقدمة.

قيمة الإرجاع: إرجاع الهيكل المقابل لـ TLD tld_str، مع البحث أولاً عبر overrides ثم عبر القائمة المضمنة، أو NULL إذا لم يتم العثور على هيكل من هذا القبيل.
