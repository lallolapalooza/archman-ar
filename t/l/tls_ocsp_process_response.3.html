tls_ocsp_process_response(3)

NAME SYNOPSIS DESCRIPTION RETURN VALUES SEE ALSO HISTORY AUTHORS

NAME

tls_ocsp_process_response, tls_ocsp_response_new, tls_ocsp_response_free, tls_ocsp_response_parse, tls_ocsp_response_status, tls_ocsp_response_time, tls_ocsp_response_responder, tls_ocsp_response_certs, tls_ocsp_response_add_cert, tls_ocsp_response_verify - process OCSP responses

SYNOPSIS

#include <tls.h>

int
tls_ocsp_process_response(tls_ctx *ctx, const char *url, const unsigned char *resp, size_t len);

struct tls_ocsp_response *
tls_ocsp_response_new(void);

void
tls_ocsp_response_free(struct tls_ocsp_response *resp);

int
tls_ocsp_response_parse(const unsigned char *buf, size_t len, struct tls_ocsp_response **resp);

int
tls_ocsp_response_status(const struct tls_ocsp_response *resp);

time_t
tls_ocsp_response_time(const struct tls_ocsp_response *resp);

const char *
tls_ocsp_response_responder(const struct tls_ocsp_response *resp);

struct tls_cert **
tls_ocsp_response_certs(const struct tls_ocsp_response *resp);

int
tls_ocsp_response_add_cert(struct tls_ocsp_response *resp, const unsigned char *buf, size_t len);

int
tls_ocsp_response_verify(const struct tls_ocsp_response *resp, const struct tls_cert *issuer, const struct tls_cert *server);

DESCRIPTION

The tls_ocsp_process_response() function processes an OCSP response received from the given url. The response is expected in the buffer resp of length len.

The tls_ocsp_response_new() function allocates a new OCSP response structure.

The tls_ocsp_response_free() function frees the OCSP response structure resp.

The tls_ocsp_response_parse() function parses the OCSP response from the buffer buf of length len and stores it in the structure pointed to by resp.

The tls_ocsp_response_status() function returns the status of the certificate in the OCSP response resp.

The tls_ocsp_response_time() function returns the time the OCSP response was generated.

The tls_ocsp_response_responder() function returns the name of the OCSP responder.

The tls_ocsp_response_certs() function returns a list of certificates contained in the OCSP response.

The tls_ocsp_response_add_cert() function adds a certificate to the OCSP response structure resp.

The tls_ocsp_response_verify() function verifies the OCSP response resp using the issuer certificate issuer and the server certificate server.

RETURN VALUES

None of these functions return a value.

SEE ALSO

tls_connect(3), tls_server(3)

HISTORY

The tls_ocsp_process_response and related functions first appeared in OpenBSD 5.6.
