tlsrpt_cancel_delivery_request(3)

الحزمة: libtlsrpt

التراخيص: LGPL-3.0-or-later

TLSRPT_CANCEL_DELIVERY_REQUEST(3) tlsrpt_cancel_delivery_request TLSRPT_CANCEL_DELIVERY_REQUEST(3)

الاسم

tlsrpt_cancel_delivery_request - يضع علامة على طلب التسليم كملغى

الملخص

#include <tlsrpt.h>

int tlsrpt_cancel_delivery_request(struct tlsrpt_dr_t** pdr)

الوصف

tlsrpt_cancel_delivery_request تقوم الدالة بوضع علامة على طلب التسليم كملغى. يتم ذلك بواسطة "خطأ وهمي" داخلي للمكتبة TLSRPT_ERR_TLSRPT_CANCELLED والذي، مثل جميع الأخطاء، سيمنع إرسال طلب التسليم. ثم تقوم الدالة باستدعاء tlsrpt_finish_delivery_request، والتي ستقوم بجميع عمليات تنظيف الموارد المستخدمة.

قيمة الإرجاع

تُرجع الدالة tlsrpt_cancel_delivery_request القيمة 0 عند النجاح ورمز خطأ مدمج عند الفشل. يمكن تحليل رمز الخطأ المدمج باستخدام الدالة tlsrpt_strerror.

انظر أيضًا

tlsrpt_init_delivery_request(3), tlsrpt_finish_delivery_request(3), tlsrpt_strerror(3), tlsrpt_error_code_is_internal(3)
