tld_get_table(3)

الحزمة: libidn

التراخيص: GPL3, LGPL

tld_get_table(3) libidn tld_get_table(3)

الاسم

tld_get_table - دالة API

الملخص

#include <tld.h>

const Tld_table * tld_get_table(const char * tld, const Tld_table ** tables);

المعاملات

const char * tld
اسم TLD (على سبيل المثال "com") كسلسلة بايت ASCII منتهية بصفر.
const Tld_table ** tables
مصفوفة منتهية بصفر لهياكل معلومات Tld_table لـ TLDs.

الوصف

الحصول على جدول TLD لـ TLD مسمى بالبحث عبر مصفوفة جدول TLD المعطاة.

قيمة الإرجاع: إرجاع الهيكل المقابل لـ TLD tld بالمرور عبر tables، أو إرجاع NULL إذا لم يتم العثور على مثل هذا الهيكل.
