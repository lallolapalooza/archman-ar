NAME

tlsrpt-reportd - reporting daemon for tlsrpt

SYNOPSIS

tlsrpt-reportd [-c config] [-d] [-f fetcher] [-L log] [-p pidfile] [-v]

DESCRIPTION

The tlsrpt-reportd daemon retrieves reports from configured fetchers and merges them into a database. It is intended to be used in conjunction with a TLS reporting server.

OPTIONS

-c config
Specify the configuration file. The default is /etc/tlsrpt/reportd.conf.
-d
Run in the foreground.
-f fetcher
Add a fetcher. This option can be specified multiple times. See Fetcher Configuration below.
-L log
Specify the log file. The default is to log to syslog.
-p pidfile
Specify the PID file. The default is /run/tlsrpt-reportd.pid.
-v
Be verbose.

ENVIRONMENT

The following environment variables can be set:

TLSrpt_CONFIG
Overrides the default configuration file location.
TLSrpt_LOG
Overrides the default log file location.
TLSrpt_PIDFILE
Overrides the default PID file location.

See also `man:tlsrpt-fetcher(1)` for fetcher-related environment variables.

EXAMPLES

Retrieve data from two local fetchers with standard configuration:

tlsrpt-reportd --fetchers "tlsrpt-fetcher, tlsrpt-fetcher"

Retrieve data from a local fetcher with standard configuration and from another local fetcher with a different storage:

tlsrpt-reportd --fetchers "tlsrpt-fetcher, tlsrpt-fetcher --storage sqlite:///tmp/test.sqlite"

Retrieve data from a local fetcher and a remote fetcher:

tlsrpt-reportd --fetchers "tlsrpt-fetcher, ssh user@remote tlsrpt-fetcher"

EXIT STATUS

0

Success.

1

Failure.
