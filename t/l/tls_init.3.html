الاسم

tls_init - تهيئة مكتبة GnuTLS

الملخص

#include <gnutls/gnutls.h>

int tls_init(void);

الوصف

تهيئة مكتبة GnuTLS. يجب استدعاء هذه الدالة مرة واحدة قبل استخدام أي من وظائف GnuTLS الأخرى.

المعاملات

لا تأخذ هذه الدالة أي معاملات.

قيمة الإرجاع

عند النجاح، تعيد 0. عند الفشل، تعيد رقمًا سالبًا يشير إلى رمز الخطأ.

الأخطاء

يمكن أن تعيد هذه الدالة رموز الخطأ القياسية لمكتبة GnuTLS، مثل:

  • GNUTLS_E_AGAIN: فشل مؤقت.
  • GNUTLS_E_MEMORY_ERROR: خطأ في الذاكرة.
  • GNUTLS_E_UNEXPECTED_PACKET: حزمة غير متوقعة.

مثال

#include <gnutls/gnutls.h>
#include <stdio.h>

int main() {
    int ret;

    ret = tls_init();
    if (ret < 0) {
        fprintf(stderr, "tls_init failed: %s\n", gnutls_strerror(ret));
        return 1;
    }

    // استخدم وظائف GnuTLS الأخرى هنا...

    return 0;
}

محاذير

يجب استدعاء tls_init() مرة واحدة فقط في بداية تشغيل البرنامج. إذا تم استدعاؤها عدة مرات، فقد يؤدي ذلك إلى سلوك غير متوقع.
