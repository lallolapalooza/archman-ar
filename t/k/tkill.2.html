tkill(2) دليل استدعاءات النظام tkill(2)

الاسم

tkill, tgkill - إرسال إشارة إلى خيط

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <signal.h>           /* تعريف ثوابت SIG* */
#include <sys/syscall.h>      /* تعريف ثوابت SYS_* */
#include <unistd.h>
[[deprecated]] int syscall(SYS_tkill, pid_t tid, int sig);
#include <signal.h>
int tgkill(pid_t tgid, pid_t tid, int sig);

ملاحظة: لا توفر glibc غلافًا لـ tkill()، مما يستلزم استخدام syscall(2).

الوصف

ترسل tgkill() الإشارة sig إلى الخيط الذي يحمل معرّف الخيط tid في مجموعة الخيوط tgid. (على النقيض من ذلك، يمكن استخدام kill(2) لإرسال إشارة إلى العملية (أي مجموعة الخيوط) ككل، وسيتم تسليم الإشارة إلى خيط عشوائي داخل تلك العملية.)

tkill() هي سابقة مهملة لـ tgkill(). تسمح فقط بتحديد معرّف الخيط المستهدف، مما قد يؤدي إلى إرسال الإشارة إلى الخيط الخطأ إذا انتهى خيط ما وتم إعادة تدوير معرّف الخيط الخاص به. تجنب استخدام استدعاء النظام هذا.

هذه هي واجهات استدعاء النظام الخام، والمقصود بها للاستخدام الداخلي لمكتبة الخيوط.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EAGAIN
تم الوصول إلى الحد الأقصى لمورد RLIMIT_SIGPENDING و sig هي إشارة في الوقت الفعلي.
EAGAIN
كانت ذاكرة النواة غير كافية و sig هي إشارة في الوقت الفعلي.
EINVAL
تم تحديد معرّف خيط، أو معرّف مجموعة خيوط، أو إشارة غير صالحة.
EPERM
تم رفض الإذن. للحصول على الأذونات المطلوبة، انظر kill(2).
ESRCH
لا توجد عملية بالمعرّف المحدد للخيط (ومجموعة الخيوط) موجودة.

المعايير

Linux.

التاريخ

tkill()
Linux 2.4.19 / 2.5.4.
tgkill()
Linux 2.5.75, glibc 2.30.

ملاحظات

انظر وصف CLONE_THREAD في clone(2) لشرح مجموعات الخيوط.
