$text->insert(index, text, ?tagOrOptions?, ...)
Insert text at the specified index. If text contains newline characters, they will be converted to the appropriate newline characters for the platform. The tagOrOptions arguments are optional and may be repeated. They specify tags that are to be applied to the inserted text or configuration options for the inserted text. See the tag command for information on how to specify tags. See the text command for information on how to specify configuration options. When tags are applied, they are applied in the order they appear in the argument list. If the argument is an option instead of a tag, it must be one of the following:

-background color

-borderwidth width

-disableselect boolean

-fg color

-height height

-image image

-justify justify

-relief relief

-underline index

-width width

-wrap wrapMode

-window window

The values for these options are as described in the text configuration options. When inserting text with embedded windows or images, the widget that is inserted must be created before this method is called. If text is empty, this method has no effect. A newline character is inserted at the specified index. The index is updated to point to the character immediately after the inserted newline.
$text->mark(name, index)
Set the mark named name to the specified index. If a mark with the given name already exists, its position is updated. If the index is not specified, then the mark is set to the current insertion point. Marks are not deleted when text is deleted. However, marks are deleted if the text containing them is deleted.
$text->markAbsorbing(name, ?boolean?)
Query or set whether mark name is absorbing. An absorbing mark is one that moves with the text around it. For example, if a mark is positioned just before a newline character, and that newline character is deleted, then the mark is moved to the position just before the character that followed the newline. If boolean is specified, then the mark is set to be absorbing or non-absorbing accordingly. If boolean is omitted, the command returns 1 if the mark is absorbing, 0 otherwise.
$text->markGravity(name, ?gravity?)
Query or set the gravity of mark name. The gravity determines how the mark moves when text is inserted or deleted near it. If gravity is left, the mark will move with the character to its left when text is inserted. If gravity is right, the mark will move with the character to its right when text is inserted. If gravity is omitted, the command returns the current gravity of the mark. The default gravity is right.
$text->markNext(index)
Return the index of the mark that comes immediately after index. If there are no marks after index, then an empty string is returned.
$text->markPrevious(index)
Return the index of the mark that comes immediately before index. If there are no marks before index, then an empty string is returned.
$text->markset(name)
Return the index of the mark named name. If no such mark exists, an empty string is returned.
$text->next(index)
Return the index of the character immediately following the character at index. If index is the last character in the buffer, an empty string is returned.
$text->previous(index)
Return the index of the character immediately preceding the character at index. If index is the first character in the buffer, an empty string is returned.
$text->search(pattern, index, ?options?)
Search for the pattern starting at index. The search continues up to the end of the buffer if the -forall option is not given, otherwise it wraps around the entire buffer. The return value is the index of the first match, or an empty string if no match is found. The following options may be given, in any order:

-backwards: Search backwards from index instead of forwards.

-count variable: If specified, the variable will be set to the number of matches found.

-exact: Match pattern exactly. This is the default.

-fuzz amount: If specified, then the search will match characters that are within amount of the characters in the pattern. For example, if amount is 1, then the search will match characters that are the same as, or one character away from, the characters in the pattern.

-forwards: Search forwards from index. This is the default.

-kill: If specified, then any currently selected text will be deleted before the search begins. The text that is deleted will be stored in the variable specified by the -count option.

-nocase: Ignore case during the match. This option has no effect with the -regexp option.

-regexp: Interpret pattern as a regular expression. The regular expression syntax is the same as that used by Tcl's regexp command.

- << : When searching backwards, this option causes the search to wrap around to the end of the buffer if the beginning of the buffer is reached without finding a match. When searching forwards, this option causes the search to wrap around to the beginning of the buffer if the end of the buffer is reached without finding a match. This option is equivalent to the -forall option.

- >> : Same as - <<.

-forall: Search the entire buffer, wrapping around if necessary. This option is equivalent to the - << option.

$text->searchAndReplace(mode, case, find, replace, index, ?endindex?)
Searches for the pattern specified by find starting at index and replaces all occurrences with replace up to endindex. mode and case are as for the search command.
$text->searchPopUp(direction, pattern)
Creates a find popup window if one does not already exist. If the popup window already exists, it will be raised and its contents will be updated with the provided arguments. The direction can be -forwards or -backwards. The pattern is the text to search for.
$text->searchRange(index1, index2, pattern)
Searches for the given pattern within the specified range [index1, index2). Returns a list of all matching indices. The pattern matching is exact and case-sensitive by default. Use the options from the search command to modify this behavior.
$text->see(index)
Scroll the widget so that the character at index is visible. If the character is already visible, then this command does nothing.
$text->selectionClear
Clear the current selection, if any.
$text->selectionIncludes(index)
Returns 1 if the character at index is currently selected, 0 otherwise.
$text->selectionOwns(?boolean?)
Query or set whether the widget owns the selection. If the widget owns the selection, then it will handle selection events. If boolean is specified, then the widget's selection ownership is set accordingly. If boolean is omitted, the command returns 1 if the widget owns the selection, 0 otherwise.
$text->selectionRange(?index1, index2?)
Returns a two-element list containing the start and end indices of the current selection. If there is no selection, an empty string is returned. If index1 and index2 are specified, then the selection is set to the range [index1, index2).
$text->selectionToMark(name)
Set the selection to range from the current insertion point to the mark named name.
$text->tag(option, name, ?index1, index2?)
This command is used to query and modify the tags associated with ranges of text. The behavior of the command depends on the option argument. The following forms of the command are currently supported:

tag add name index1 index2 ?index1 index2 ...?: Adds the tag name to the specified ranges. Multiple ranges may be specified.

tag bind name ?sequence? ?script?: Binds events to occurrences of the tag name. When an event in sequence occurs on text with this tag, script is executed. If script is omitted, the bindings for name are returned.

tag ranges name: Returns a list of all ranges in the buffer that have the tag name associated with them.

tag remove name index1 index2 ?index1 index2 ...?: Removes the tag name from the specified ranges. Multiple ranges may be specified.

tag names ?pattern?: Returns a list of all defined tag names. If pattern is specified, only returns names matching the pattern.

tag next name index: Returns the index of the first occurrence of tag name at or after index.

tag previous name index: Returns the index of the first occurrence of tag name at or before index.

tag lower name ?name2 ...?: Lowers the specified tags in the stacking order. Tags with lower numerical values are drawn on top of tags with higher numerical values.

tag raise name ?name2 ...?: Raises the specified tags in the stacking order. Tags with lower numerical values are drawn on top of tags with higher numerical values.

tag configure name ?option value ...?*:

Configures the appearance of text tagged with name. The available options are:

-background color
The background color for text with this tag.
-bgstipple tile
A stipple pattern to use for the background color.
-borderwidth width
The border width for text with this tag.
-fg color
The foreground color for text with this tag.
-fgstipple tile
A stipple pattern to use for the foreground color.
-font font
The font for text with this tag.
-justify justify
The justification for text with this tag (left, center, or right).
-lmargin1 pixels
The left margin for the first line of a paragraph tagged with this tag.
-lmargin2 pixels
The left margin for subsequent lines of a paragraph tagged with this tag.
-offset pixels
The vertical offset for text with this tag. Positive values move the text up, negative values move it down.
-overstrike boolean
If true, draws a line through the center of the text.
-relief relief
The relief style for text with this tag (flat, sunken, raised, or ridge).
-rmargin pixels
The right margin for text with this tag.
-rstrip boolean
If true, trailing whitespace is removed from lines tagged with this tag.
-tabs tabspec
Tab stops for text with this tag. See the tabs command for details.
-underline boolean
If true, underlines the text.
-wrap wrapMode
How to handle lines that are too long to fit in the widget (none, char, or word).
$text->tagged(index1, ?index2?)
Return a list of all tags that apply to the character at index1. If index2 is specified, return a list of all tags that apply to any character in the range [index1, index2).
$text->text(option, ?arg, arg ...?)
This command is used to configure the text widget itself. The behavior of the command depends on the option argument. The following forms of the command are currently supported:
$text->textAnchor(?anchor?)
Returns the current anchor position. If anchor is specified, sets the anchor position to anchor. The anchor is used in conjunction with indices like wordstart and wordend.
$text->textBackground(?color?)
Returns the background color of the text widget. If color is specified, sets the background color.
$text->textBorderwidth(?width?)
Returns the border width of the text widget. If width is specified, sets the border width.
$text->textChars(?index?)
Returns a list of characters at the specified index. If no index is specified, returns a list of all characters in the widget. The characters are returned as a list of single-character strings.
$text->textConfig(?option, value, ...?)
Query or modify the configuration options for the text widget. If no options are specified, returns a list describing all of the available options (see Tk::options for information on the format of this list). If an option is specified with no value, then the command returns a list describing the one named option. If one or more option-value pairs are specified, then the command modifies the widget's configuration.
$text->textDisableselect(?boolean?)
Returns the value of the disableselect option. If boolean is specified, sets the disableselect option to that value. If true, then users are not allowed to select text in the widget.
$text->textExport(index1, index2)
Returns the contents of the text widget between index1 and index2 in a form that can be pasted into another text widget. This includes text, marks, tags, and embedded windows.
$text->textFont(?font?)
Returns the font used for the text widget. If font is specified, sets the font.
$text->textForeground(?color?)
Returns the foreground color of the text widget. If color is specified, sets the foreground color.
$text->textHeight(?height?)
Returns the height of the text widget in lines. If height is specified, sets the height.
$text->textHighlightbackground(?color?)
Returns the background color used for highlighted text. If color is specified, sets the highlight background color.
$text->textHighlightcolor(?color?)
Returns the color used for highlighting. If color is specified, sets the highlight color.
$text->textInsertOffTime(?milliseconds?)
Returns the insert cursor blink off-time in milliseconds. If milliseconds is specified, sets the blink off-time.
$text->textInsertOnTime(?milliseconds?)
Returns the insert cursor blink on-time in milliseconds. If milliseconds is specified, sets the blink on-time.
$text->textInsertwidth(?width?)
Returns the width of the insert cursor in pixels. If width is specified, sets the width.
$text->textJustify(?justify?)
Returns the justification of the text widget. If justify is specified, sets the justification to justify (left, center, or right).
$text->textRelief(?relief?)
Returns the relief style of the text widget. If relief is specified, sets the relief style (e.g., raised, sunken, flat).
$text->textSelectBackground(?color?)
Returns the background color of selected text. If color is specified, sets the background color of selected text.
$text->textSelectForeground(?color?)
Returns the foreground color of selected text. If color is specified, sets the foreground color of selected text.
$text->textTabs(?tabspec?)
Returns the tab specifications for the text widget. If tabspec is specified, sets the tab specifications.
$text->textUndo(?boolean?)
Returns the state of the undo mechanism. If boolean is specified, sets the undo mechanism to that state. If true, then the text widget will keep track of changes made to the buffer so that they can be undone.

This command is used to manage embedded windows. The behavior of the command depends on the option argument. The following forms of the command are currently supported:

window configure index ?option value ...?: Configures the specified embedded window. The options are the same as for the -window option of the text insert command.

الأحداث الوحيدة التي يمكن تحديد ارتباطات لها هي تلك المتعلقة بالفأرة ولوحة المفاتيح (مثل Enter، Leave، ButtonPress، Motion، و KeyPress) أو الأحداث الافتراضية. تستخدم ارتباطات الأحداث لأداة النص العلامة current الموصوفة في "MARKS" سابقًا. يتم تشغيل حدث Enter عندما تصبح العلامة مرئية في الحرف الحالي، ويتم تشغيل حدث Leave عندما تتوقف العلامة عن كونها مرئية في الحرف الحالي. يمكن أن تحدث أحداث Enter و Leave بسبب حركة العلامة current أو بسبب تغيير الحرف في هذا الموضع. لاحظ أن هذه الأحداث تختلف عن أحداث النافذة Enter و Leave. توجه أحداث الفأرة ولوحة المفاتيح إلى الحرف الحالي. إذا تم استخدام حدث افتراضي في ارتباط، فسيتم تشغيل هذا الارتباط فقط إذا كان الحدث الافتراضي محددًا بواسطة حدث متعلق بالفأرة أو لوحة المفاتيح.

من الممكن أن يحتوي الحرف الحالي على علامات متعددة، ولكل منها ارتباط لتسلسل حدث محدد. عندما يحدث هذا، يتم استدعاء ارتباط لكل علامة، بترتيب الأولوية من الأدنى إلى الأعلى. إذا كان هناك ارتباطات متعددة تتطابق مع نفس العلامة، يتم اختيار الأكثر تحديدًا (انظر وثائق أمر bind للحصول على التفاصيل). تتم معالجة التعليمات continue و break داخل نصوص الارتباط بنفس الطريقة التي تتم بها مع الارتباطات التي تم إنشاؤها باستخدام أمر bind.

إذا تم إنشاء ارتباطات للأداة بشكل عام باستخدام أمر bind، فستكمل هذه الارتباطات ارتباطات العلامات. يتم استدعاء ارتباطات العلامات أولاً، تليها الارتباطات العامة للأداة.

$text->xview(option, args)
This command is used to query and change the horizontal position of the text in the widget's window. It can take any of the following forms:
$text->xview
Returns a list containing two elements. Each element is a real fraction between 0 and 1; together they describe the portion of the document's horizontal span that is visible in the window. For example, if the first element is .2 and the second element is .6, 20% of the text is off-screen to the left, the middle 40% is visible in the window, and 40% of the text is off-screen to the right. The fractions refer only to the lines that are actually visible in the window: if the lines in the window are all very short, so that they are entirely visible, the returned fractions will be 0 and 1, even if there are other lines in the text that are much wider than the window. These are the same values passed to scrollbars via the -xscrollcommand option.

This command shifts the view in the window left or right according to number and what. Number must be an integer. What must be either units or pages or an abbreviation of one of these. If what is units, the view adjusts left or right by number average-width characters on the display; if it is pages then the view adjusts by number screenfuls. If number is negative then characters farther to the left become visible; if it is positive then characters farther to the right become visible.

The second element gives the position of the character just after the last one in the bottom line of the window, relative to the text as a whole. These are the same values passed to scrollbars via the -yscrollcommand option.

Adjusts the view in the window so that the character given by fraction appears on the top line of the window. Fraction is a fraction between 0 and 1; 0 indicates the first character in the text, 0.33 indicates the character one-third the way through the text, and so on.
$text->yviewScroll(number, what)
This command adjust the view in the window up or down according to number and what. Number must be an integer. What must be either units or pages. If what is units, the view adjusts up or down by number lines on the display; if it is pages then the view adjusts by number screenfuls. If number is negative then earlier positions in the text become visible; if it is positive then later positions in the text become visible.
$text->yview(?-pickplace,? index)
Changes the view in the $text's window to make index visible. If the -pickplace option isn't specified then index will appear at the top of the window. If -pickplace is specified then the widget chooses where index appears in the window:
[1]
If index is already visible somewhere in the window then the command does nothing.
[2]
If index is only a few lines off-screen above the window then it will be positioned at the top of the window.
[3]
If index is only a few lines off-screen below the window then it will be positioned at the bottom of the window.
[4]
Otherwise, index will be centered in the window.

The -pickplace option has been obsoleted by the see widget command (see handles both x- and y-motion to make a location visible, whereas -pickplace only handles motion in y).

$text->yview(number)
This command makes the first character on the line after the one given by number visible at the top of the window. Number must be an integer. This command used to be used for scrolling, but now it is obsolete.

BINDINGS

Tk automatically creates class bindings for texts that give them the following default behavior. In the descriptions below, ``word'' refers to a contiguous group of letters, digits, or ``_'' characters, or any single character other than these.

[1]
Clicking mouse button 1 positions the insertion cursor just before the character underneath the mouse cursor, sets the input focus to this widget, and clears any selection in the widget. Dragging with mouse button 1 strokes out a selection between the insertion cursor and the character under the mouse.
[2]
Double-clicking with mouse button 1 selects the word under the mouse and positions the insertion cursor at the beginning of the word. Dragging after a double click will stroke out a selection consisting of whole words.
[3]
Triple-clicking with mouse button 1 selects the line under the mouse and positions the insertion cursor at the beginning of the line. Dragging after a triple click will stroke out a selection consisting of whole lines.
[4]
The ends of the selection can be adjusted by dragging with mouse button 1 while the Shift key is down; this will adjust the end of the selection that was nearest the mouse cursor when button 1 was pressed. If the button is double-clicked before dragging then the selection will be adjusted in units of whole words; if it is triple-clicked then the selection will be adjusted in units of whole lines.
[5]
Clicking mouse button 1 with the Control key down will reposition the insertion cursor without affecting the selection.
[6]
If any normal printing characters are typed, they are inserted at the point of the insertion cursor.
[7]
The view in the widget can be adjusted by dragging with mouse button 2. If mouse button 2 is clicked without moving the mouse, the selection is copied into the text at the position of the mouse cursor. The Insert key also inserts the selection, but at the position of the insertion cursor.
[8]
If the mouse is dragged out of the widget while button 1 is pressed, the entry will automatically scroll to make more text visible (if there is more text off-screen on the side where the mouse left the window).
[9]
The Left and Right keys move the insertion cursor one character to the left or right; they also clear any selection in the text. If Left or Right is typed with the Shift key down, then the insertion cursor moves and the selection is extended to include the new character. Control-Left and Control-Right move the insertion cursor by words, and Control-Shift-Left and Control-Shift-Right move the insertion cursor by words and also extend the selection. Control-b and Control-f behave the same as Left and Right, respectively. Meta-b and Meta-f behave the same as Control-Left and Control-Right, respectively.
