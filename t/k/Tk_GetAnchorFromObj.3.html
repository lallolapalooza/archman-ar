Tk_GetAnchorFromObj(3)

الحزمة: tk

التراخيص: TCL

Tk_GetAnchorFromObj(3) إجراءات مكتبة Tk Tk_GetAnchorFromObj(3)

الاسم

Tk_GetAnchorFromObj, Tk_GetAnchor, Tk_NameOfAnchor - الترجمة بين السلاسل النصية ومواقع الربط

ملخص

#include <tk.h>

int
Tk_GetAnchorFromObj(
    Tcl_Interp *interp,
    Tcl_Obj *objPtr,
    int *anchorPtr
);

int
Tk_GetAnchor(
    Tcl_Interp *interp,
    const char *string,
    int *anchorPtr
);

const char *
Tk_NameOfAnchor(
    int anchor
);

المعاملات

Tcl_Interp *interp (in)
المفسر لاستخدامه في الإبلاغ عن الأخطاء، أو NULL.
Tcl_Obj *objPtr (in/out)
القيمة النصية تحتوي على اسم نقطة الربط: “n”، “ne”، “e”، “se”، “s”، “sw”، “w”، “nw”، أو “center”؛ سيتم تعديل التمثيل الداخلي لتخزين موقع الربط المقابل. في حالة “center” عند الإدخال، يمكن أيضًا استخدام اختصار غير فارغ له عند الإدخال.
const char *string (in)
نفس objPtr باستثناء أن وصف نقطة الربط يتم تمريره كسلسلة نصية.
int *anchorPtr (out)
مؤشر إلى الموقع الذي سيتم فيه تخزين موقع الربط المقابل لـ objPtr أو string.
int anchor (in)
موقع الربط، على سبيل المثال TCL_ANCHOR_CENTER.

الوصف

تضع Tk_GetAnchorFromObj في *anchorPtr موقع ربط (نوع تعدادي Tk_Anchor) مطابق لقيمة objPtr. ستكون النتيجة واحدة من TK_ANCHOR_N، TK_ANCHOR_NE، TK_ANCHOR_E، TK_ANCHOR_SE، TK_ANCHOR_S، TK_ANCHOR_SW، TK_ANCHOR_W، TK_ANCHOR_NW، أو TK_ANCHOR_CENTER. تُستخدم مواقع الربط عادةً للإشارة إلى نقطة على كائن سيتم استخدامها لوضع الكائن، على سبيل المثال TK_ANCHOR_N يعني وضع النقطة المركزية العليا للكائن في مكان معين.

في الظروف العادية، تكون القيمة المرجعة TCL_OK ولا يتم استخدام interp. إذا كانت string لا تحتوي على موقع ربط صالح أو اختصار لأحد هذه الأسماء، يتم إرجاع TCL_ERROR، وتبقى *anchorPtr دون تغيير، ويتم تخزين رسالة خطأ في نتيجة interp إذا كان interp ليس NULL. تقوم Tk_GetAnchorFromObj بتخزين المعلومات حول القيمة المرجعة في objPtr، مما يسرع الاستدعاءات المستقبلية لـ Tk_GetAnchorFromObj باستخدام نفس objPtr.

Tk_GetAnchor مطابق لـ Tk_GetAnchorFromObj باستثناء أن وصف الربط محدد بسلسلة نصية بدلاً من كائن. هذا يمنع Tk_GetAnchor من تخزين القيمة المرجعة، لذا فإن Tk_GetAnchor أقل كفاءة من Tk_GetAnchorFromObj.

Tk_NameOfAnchor هو العكس المنطقي لـ Tk_GetAnchor. نظرًا لموقع ربط مثل TK_ANCHOR_N، فإنه يعيد سلسلة نصية مخصصة بشكل ثابت تتوافق مع anchor. إذا كان anchor ليس قيمة ربط قانونية، فسيتم إرجاع "unknown anchor position".
