Tk_RedrawImage(3)

التراخيص: TCL

Tk_GetImage(3) إجراءات مكتبة Tk Tk_GetImage(3)

الاسم

Tk_GetImage, Tk_RedrawImage, Tk_SizeOfImage, Tk_FreeImage - استخدام صورة في أداة واجهة المستخدم

المُلَخَّص

#include <tk.h>

Tk_Image
Tk_GetImage(interp, tkwin, name, changeProc, clientData)

Tk_RedrawImage(image, imageX, imageY, width, height, drawable, drawableX, drawableY)

Tk_SizeOfImage(image, widthPtr, heightPtr)

Tk_FreeImage(image)

المُعاملات

Tcl_Interp *interp (مدخل)
مكان ترك رسالة الخطأ.
Tk_Window tkwin (مدخل)
النافذة التي ستُستخدم فيها الصورة.
const char *name (مدخل)
اسم الصورة.
Tk_ImageChangedProc *changeProc (مدخل)
الإجراء الذي ستستدعيه Tk عند تغيير محتوى الصورة أو حجمها.
ClientData clientData (مدخل)
قيمة ذات كلمة واحدة لتمريرها بواسطة Tk إلى changeProc.
Tk_Image image (مدخل)
رمز تعريف مثيل الصورة؛ يجب أن يكون قد تم إرجاعه بواسطة استدعاء سابق لـ Tk_GetImage.
int imageX (مدخل)
إحداثي X للزاوية العلوية اليسرى للمنطقة من الصورة التي سيتم إعادة عرضها (مقاسة بالبكسل من الزاوية العلوية اليسرى للصورة).
int imageY (مدخل)
إحداثي Y للزاوية العلوية اليسرى للمنطقة من الصورة التي سيتم إعادة عرضها (مقاسة بالبكسل من الزاوية العلوية اليسرى للصورة).
int width ((مدخل))
عرض المنطقة من الصورة التي سيتم إعادة عرضها.
int height ((مدخل))
ارتفاع المنطقة من الصورة التي سيتم إعادة عرضها.
Drawable drawable (مدخل)
المكان الذي سيتم عرض الصورة فيه. يجب أن تكون إما النافذة المحددة لـ Tk_GetImage أو صورة نقطية (pixmap) متوافقة مع تلك النافذة.
int drawableX (مدخل)
المكان الذي سيتم عرض الصورة فيه في drawable: هذا هو إحداثي X في drawable حيث يجب عرض إحداثي X imageX للصورة.
int drawableY (مدخل)
المكان الذي سيتم عرض الصورة فيه في drawable: هذا هو إحداثي Y في drawable حيث يجب عرض إحداثي Y imageY للصورة.
int widthPtr (مخرج)
قم بتخزين عرض image (بالبكسل) هنا.
int heightPtr (مخرج)
قم بتخزين ارتفاع image (بالبكسل) هنا.

الوصف

يتم استدعاء هذه الإجراءات بواسطة الأدوات التي ترغب في عرض الصور. يتم استدعاء Tk_GetImage بواسطة أداة واجهة المستخدم عندما تقرر لأول مرة عرض صورة. يعطي name اسم الصورة المطلوبة و tkwin يحدد النافذة التي سيتم عرض الصورة فيها. تبحث Tk_GetImage عن الصورة في جدول الصور الموجودة وتعيد رمز تعريف لمثيل جديد للصورة. إذا لم تكن الصورة موجودة، فإن Tk_GetImage تعيد NULL وتترك رسالة خطأ في نتيجة المفسر interp.

عندما ترغب أداة واجهة المستخدم في عرض صورة فعليًا، يجب عليها استدعاء Tk_RedrawImage، وتحديد الصورة (image)، ومنطقة داخل الصورة لإعادة عرضها (imageX، imageY، width، و height)، ومكان لعرض الصورة (drawable، drawableX، و drawableY). بعد ذلك، ستستدعي Tk مدير الصورة المناسب، والذي سيعرض الجزء المطلوب من الصورة قبل العودة.

يمكن لأداة واجهة المستخدم معرفة أبعاد الصورة عن طريق استدعاء Tk_SizeOfImage: سيتم تخزين العرض والارتفاع في المواقع التي تحددها widthPtr و heightPtr، على التوالي.

عندما تنتهي أداة واجهة المستخدم من استخدام صورة (على سبيل المثال، يتم حذف الأداة أو أنها ستستخدم صورة مختلفة بدلاً من الصورة الحالية)، يجب عليها استدعاء Tk_FreeImage لتحرير مثيل الصورة. يجب ألا تستخدم الأداة رمز تعريف الصورة مطلقًا بعد تمريره إلى Tk_FreeImage. يجب أن يكون هناك استدعاء واحد بالضبط لـ Tk_FreeImage لكل استدعاء لـ Tk_GetImage.

إذا تغير محتوى الصورة أو حجمها، فستحتاج جميع أدوات واجهة المستخدم التي تستخدم الصورة إلى معرفة التغييرات حتى تتمكن من إعادة عرض نفسها. تُستخدم وسائط changeProc و clientData لـ Tk_GetImage لهذا الغرض. سيتم استدعاء changeProc بواسطة Tk عند حدوث أي تغيير في الصورة؛ يجب أن يتطابق مع النموذج الأولي التالي:

typedef void Tk_ImageChangedProc(
        ClientData clientData,
        int x,
        int y,
        int width,
        int height,
        int imageWidth,
        int imageHeight);
وسيط clientData لـ changeProc هو نفس وسيط clientData لـ Tk_GetImage. عادة ما يكون مؤشرًا إلى سجل أداة واجهة المستخدم أو إلى بنية بيانات أخرى تديرها أداة واجهة المستخدم. تحدد الوسائط x، y، width، و height منطقة داخل الصورة يجب إعادة عرضها؛ يتم تحديدها بالبكسل مقاسًا من الزاوية العلوية اليسرى للصورة. تحدد الوسائط imageWidth و imageHeight حجم الصورة (الجديد).
