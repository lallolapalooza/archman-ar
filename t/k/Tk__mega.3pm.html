Tk__mega(3pm)

الحزمة: perl-tk

التراخيص: PerlArtistic, GPL, custom

mega(3) توثيق Perl الذي ساهم به المستخدم mega(3)

الاسم

Tk::mega - دعم Perl/Tk لكتابة الأدوات (widgets) بلغة Perl النقية

الملخص

حدد اسم الفئة الجديدة للأداة:

    package Tk::MyNewWidget;

لفئات الأدوات المركبة:

    use base qw/ Tk::container /; # حيث container هي Frame أو Toplevel

لفئات الأدوات المشتقة:

    use base qw/ Tk::Derived Tk::DerivedWidget /;

قم بتثبيت الأداة الجديدة في مساحة اسم Tk وإنشاء مُنشِئات الفئة والتخوم (instances).

    Construct Tk::Widget 'MyNewWidget';

    sub ClassInit { my ($self, $args) = @_; ... }

    sub Populate { my ($self, $args) = @_; ... }

الوصف

الهدف من دعم الأدوات الكبيرة (mega-widgets) في Perl/Tk هو تسهيل كتابة هذه الأدوات بحيث تتبع نفس البروتوكول والواجهة التي تدعمها أدوات Tk الأساسية. لأمثلة كود الأدوات الكبيرة، يرجى تشغيل برنامج العرض التوضيحي widget والانتقال إلى قسم نماذج أدوات Perl الكبيرة.

هناك نوعان من الأدوات الكبيرة:

  • الأدوات المركبة

    الأداة المركبة تتكون من أداة أو أكثر من الأدوات الموجودة. تبدو الأداة المركبة للمستخدم كأداة واحدة بسيطة. مثال معروف هو مربع اختيار الملفات.

  • الأدوات المشتقة

    الأداة المشتقة تضيف/تعدل/تزيل خصائص ووظائف من أداة واحدة (قد تكون هذه الأداة نفسها أداة كبيرة).

دعم الأدوات الكبيرة (MEGA-WIDGET)

الإعلان (Advertise)

امنح أداة فرعية اسمًا رمزيًا.

الاستخدام:

    $self->Advertise(name=>$widget);

يمنح الأداة الفرعية $widget للأداة الكبيرة $self الاسم name. يمكن استرداد مرجع الأداة الفرعية المعلن عنها باستخدام الدالة Subwidget.

تعليق: كتاب الأدوات الكبيرة: يرجى التأكد من توثيق الأدوات الفرعية المعلن عنها والمخصصة للاستخدام العام. إذا لم تكن هناك أدوات، وثق هذه الحقيقة، على سبيل المثال:

=head1 ADVERTISED WIDGETS
None.

استدعاء الاستجابة (Callback)

قم بتنفيذ استدعاء استجابة محدد بخيار.

الاستخدام:

    $self->Callback(-option ?,args ...?);

Callback ينفذ استدعاء الاستجابة المحدد بـ $self->ConfigSpecs(-option, [CALLBACK, ...]); إذا تم توفير args، فسيتم تمريرها إلى استدعاء الاستجابة. إذا لم يكن -option محددًا، فلن يفعل شيئًا.

تهيئة الفئة (ClassInit)

تهيئة فئة الأداة الكبيرة.

الاستخدام:

    sub ClassInit { my ($class, $mw) = @_; ... }

يتم استدعاء ClassInit مرة واحدة لكل MainWindow قبل إنشاء أول تخم (instance) للأداة من فئة ما في شجرة الأدوات الخاصة بـ MainWindow.

غالبًا ما تُستخدم ClassInit لتعريف الارتباطات و/أو الموارد الأخرى التي تشترك فيها جميع التخوم، على سبيل المثال، الصور.

أمثلة:

$mw->bind($class,"<Tab>", sub { my $w = shift; $w->Insert("\t"); $w->focus; $w->break});
$mw->bind($class,"<Return>", ['Insert',"\n"]);
$mw->bind($class,"<Delete>",'Delete');

لاحظ أن $class هو اسم الفئة (على سبيل المثال، Tk::MyText) و $mw هو النافذة الرئيسية.

لا تنس استدعاء $class->SUPER::ClassInit($mw) في ClassInit.

المكون (Component)

دالة مساعدة لإنشاء أدوات فرعية.

الاستخدام:

$cw->Component('Whatever', 'AdvertisedName',
    -delegate => ['method1', 'method2', ...],
    ... مزيد من خيارات الأدوات ...,
);

تقوم Component بالعديد من الأشياء من أجلك في استدعاء واحد:

o إنشاء الأداة

o الإعلان عنها باسم معين (يتم تجاوزه بواسطة خيار 'Name')

o تفويض مجموعة من الوظائف إلى هذه الأداة (اختياري)

مثال:

$cw->Component('Button', 'quitButton', -command => sub{$mw->'destroy'});

مواصفات التكوين (ConfigSpecs)

تحدد الخيارات وكيفية التعامل معها

الاستخدام:

$cw->ConfigSpecs(
    -option => [ where, dbname, dbclass, default],
    ...,
    DEFAULT => [where],
);

يحدد خيارات الأداة الكبيرة والإجراءات التي يتم تشغيلها بواسطة configure/cget للخيارات (انظر Tk::ConfigSpecs و Tk::Derived للتفاصيل).

الإنشاء (Construct)

اجعل الأداة الكبيرة الجديدة معروفة لـ Tk.

الاستخدام:

    Construct baseclass 'Name';

Construct يعلن عن فئة الأداة الجديدة بحيث تعمل الأداة الكبيرة الخاصة بك مثل أدوات Perl/Tk العادية.

أمثلة:

    Construct Tk::Widget 'Whatever';     Construct Tk::Menu 'MyItem';

المثال الأول يسمح باستخدام $widget->Whatever لإنشاء أداة Whatever جديدة.

المثال الثاني يقيد استخدام الدالة المنشئة MyItem للأدوات المشتقة من Menu: $isamenu->MyItem.

وسائط الإنشاء (CreateArgs)

معالجة الخيارات قبل إنشاء أي أداة:

    sub CreateArgs { my ($package, $parent, $args) = @_; ...; return @newargs; }

$package هو حزمة الأداة الكبيرة (على سبيل المثال، Tk::MyText)، $parent هو الأب للأداة التي سيتم إنشاؤها، و $args هو مرجع إلى الهاش (hash reference) للخيارات المحددة في استدعاء مُنشئ الأداة.

لا تنس استدعاء $package->SUPER::CreateArgs($parent, $args) في CreateArgs.

التفويض (Delegates)

إعادة توجيه وظيفة من الأداة الكبيرة إلى أداة فرعية للأداة المركبة.

الاستخدام:

$cw->Delegates(
    'method1' => $subwidget1,
    'method2' => 'advertived_name',
    ...,
    'Construct' => $subwidget2,
    'DEFAULT'   => $subwidget3,
);

لـ 'Construct' التفويض معنى خاص. بعد تفويض 'Construct'، يتم إعادة توجيه جميع مُنشِئات الأدوات. على سبيل المثال، بعد

    $self->Delegates('Construct'=>$subframe);
