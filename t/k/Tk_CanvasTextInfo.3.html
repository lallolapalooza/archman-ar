Tk_CanvasTextInfo(3)

الحزمة: tk

التراخيص: TCL

Tk_CanvasTextInfo(3) إجراءات مكتبة Tk Tk_CanvasTextInfo(3)

الاسم

Tk_CanvasTextInfo - معلومات إضافية لإدارة عناصر النص في اللوحات

الملخص

#include <tk.h>

Tk_CanvasTextInfo *
Tk_CanvasGetTextInfo(canvas)

المعاملات

Tk_Canvas canvas (إدخال)
رمز يحدد لوحة معينة.

الوصف

عناصر النص في اللوحة أكثر تعقيدًا في الإدارة من العناصر الأخرى، وذلك بسبب أشياء مثل التحديد وتركيز الإدخال. يمكن استدعاء Tk_CanvasGetTextInfo بواسطة مدير النوع للحصول على معلومات إضافية مطلوبة للعناصر التي تعرض النص. القيمة المرجعة من Tk_CanvasGetTextInfo هي مؤشر إلى هيكل مشترك بين Tk وجميع العناصر التي تعرض النص. الهيكل له الشكل التالي:

typedef struct Tk_CanvasTextInfo {
    Tk_3DBorder selBorder;
    int selBorderWidth;
    XColor *selFgColorPtr;
    Tk_Item *selItemPtr;
    int selectFirst;
    int selectLast;
    Tk_Item *anchorItemPtr;
    int selectAnchor;
    Tk_3DBorder insertBorder;
    int insertWidth;
    int insertBorderWidth;
    Tk_Item *focusItemPtr;
    int gotFocus;
    int cursorOn;
} Tk_CanvasTextInfo;
يشير الحقل selBorder إلى Tk_3DBorder الذي يجب استخدامه لرسم الخلفية تحت النص المحدد. selBorderWidth يعطي عرض الحدود المرفوعة حول النص المحدد، بالبكسل. selFgColorPtr يشير إلى XColor يصف لون المقدمة المراد استخدامه عند رسم النص المحدد. selItemPtr يشير إلى العنصر المحدد حاليًا، أو NULL إذا لم يكن هناك عنصر محدد أو إذا كانت اللوحة لا تملك التحديد. selectFirst و selectLast يعطيان مؤشرات أول وآخر حرف محدد في selItemPtr، كما تم إرجاعه بواسطة indexProc لهذا العنصر. anchorItemPtr يشير إلى العنصر الذي يمتلك حاليًا نقطة تثبيت التحديد؛ هذا ليس بالضرورة نفس selItemPtr. selectAnchor هو مؤشر يحدد موضع نقطة التثبيت داخل anchorItemPtr. insertBorder يحتوي على Tk_3DBorder لاستخدامه عند رسم مؤشر الإدخال؛ insertWidth يعطي العرض الكلي لمؤشر الإدخال بالبكسل، و insertBorderWidth يعطي عرض الحدود المرفوعة حول مؤشر الإدخال. focusItemPtr يحدد العنصر الذي يمتلك حاليًا تركيز الإدخال، أو NULL إذا لم يكن هناك مثل هذا العنصر. gotFocus هو 1 إذا كانت لوحة الودجت تمتلك تركيز الإدخال و 0 بخلاف ذلك. cursorOn هو 1 إذا كان يجب رسم مؤشر الإدخال في focusItemPtr و 0 إذا كان لا ينبغي رسمه؛ يتم تبديل هذا الحقل وتشغيله بواسطة Tk لجعل المؤشر يومض.

الهيكل الذي يتم إرجاعه بواسطة Tk_CanvasGetTextInfo مشترك بين Tk ومديري الأنواع؛ عادةً ما يستدعي مدير النوع Tk_CanvasGetTextInfo مرة واحدة عند إنشاء عنصر ويحفظ المؤشر في سجل العنصر. سيقوم Tk بتحديث المعلومات في Tk_CanvasTextInfo؛ على سبيل المثال، قد يغير أمر الودجت configure الحقل selBorder، أو قد يغير أمر الودجت select الحقل selectFirst، أو قد يغير Tk cursorOn لجعل مؤشر الإدخال يومض بشكل متقطع أثناء عمليات إعادة العرض المتتالية.

يجب على مديري الأنواع التعامل مع جميع حقول هيكل Tk_CanvasTextInfo على أنها للقراءة فقط، باستثناء selItemPtr و selectFirst و selectLast و selectAnchor. قد يقوم مديرو الأنواع بتغيير selectFirst و selectLast و selectAnchor للتكيف مع الإدخالات والحذف في العنصر (ولكن فقط إذا كان العنصر هو المالك الحالي للتحديد أو نقطة التثبيت، كما هو محدد بواسطة selItemPtr أو anchorItemPtr). إذا تم حذف كل النص المحدد في العنصر، يجب على العنصر تعيين selItemPtr إلى NULL للإشارة إلى عدم وجود تحديد.
