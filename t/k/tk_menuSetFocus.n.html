مقدمة

ينشئ الأمر menu نافذة جديدة علوية (يتم تحديدها بالوسيط pathName) ويجعلها عنصر واجهة قائمة. يمكن استخدام عنصر واجهة القائمة هذا كنافذة منبثقة أو تطبيقه على toplevel (باستخدام الخيار -menu الخاص بها) لجعله شريط القائمة لذلك الـ toplevel. يمكن تحديد خيارات إضافية، موصوفة أعلاه، في سطر الأوامر أو في قاعدة بيانات الخيارات لتكوين جوانب القائمة مثل ألوانها وخطها. يعيد الأمر menu وسيطه pathName. في وقت استدعاء هذا الأمر، يجب ألا توجد نافذة بالاسم pathName، ولكن يجب أن يكون أصل pathName موجودًا.

القائمة هي عنصر واجهة يعرض مجموعة من الإدخالات المكونة من سطر واحد مرتبة في عمود واحد أو أكثر. توجد عدة أنواع مختلفة من الإدخالات، لكل منها خصائص مختلفة. يمكن دمج إدخالات من أنواع مختلفة في قائمة واحدة. إدخالات القائمة ليست هي نفسها عناصر الإدخال (entry widgets). في الواقع، إدخالات القائمة ليست حتى عناصر واجهة مميزة؛ القائمة بأكملها هي عنصر واجهة واحد.

يتم عرض إدخالات القائمة بما يصل إلى ثلاثة حقول منفصلة. الحقل الرئيسي هو تسمية (label) في شكل سلسلة نصية، أو خريطة بت (bitmap)، أو صورة، يتم التحكم فيها بواسطة خيارات -label، -bitmap، و -image للإدخال. إذا تم تحديد الخيار -accelerator لإدخال ما، فسيتم عرض حقل نصي ثانٍ إلى يمين التسمية. يصف المسارع (accelerator) عادةً تسلسل مفاتيح يمكن استخدامه في التطبيق لتحقيق نفس نتيجة استدعاء إدخال القائمة. هذا خيار عرض، ولا يقوم فعليًا بتعيين الربط المقابل (والذي يمكن تحقيقه باستخدام الأمر bind). الحقل الثالث هو مؤشر (indicator). المؤشر موجود فقط لإدخالات أزرار التحديد (checkbutton) أو أزرار الاختيار (radiobutton). إنه يشير إلى ما إذا كان الإدخال محددًا أم لا، ويتم عرضه إلى يسار سلسلة الإدخال.

في الاستخدام العادي، يصبح الإدخال نشطًا (يعرض نفسه بشكل مختلف) كلما كان مؤشر الماوس فوق الإدخال. إذا تم تحرير زر الماوس فوق الإدخال، فسيتم استدعاء الإدخال. يكون تأثير الاستدعاء مختلفًا لكل نوع من أنواع الإدخالات؛ يتم وصف هذه التأثيرات أدناه في الأقسام الخاصة بكل إدخال.

يمكن تعطيل الإدخالات، مما يؤدي إلى عرض تسمياتها ومسرعاتها بألوان باهتة. إعدادات الربط الافتراضية للقائمة لن تسمح بتنشيط أو استدعاء إدخال معطل. يمكن إعادة تمكين الإدخالات المعطلة، وعندئذ يصبح من الممكن تنشيطها واستدعائها مرة أخرى.

في كل مرة يتم فيها تغيير الإدخال النشط في القائمة، يتم إرسال حدث افتراضي <<MenuSelect>> إلى القائمة. يمكن بعد ذلك الاستعلام عن العنصر النشط من القائمة، ويمكن اتخاذ إجراء، مثل تعيين نص المساعدة الحساس للسياق للإدخال.

أنواع الإدخالات

إدخالات الأوامر

النوع الأكثر شيوعًا لإدخال القائمة هو إدخال الأمر، والذي يتصرف بشكل كبير مثل عنصر الواجهة الزر (button widget). عند استدعاء إدخال أمر، يتم تنفيذ أمر Tcl. يتم تحديد أمر Tcl باستخدام الخيار -command.

إدخالات الفواصل

الفاصل هو إدخال يتم عرضه كخط فاصل أفقي. لا يمكن تنشيط الفاصل أو استدعاؤه، وليس له سلوك بخلاف مظهره.

إدخالات أزرار التحديد

يتصرف إدخال زر تحديد القائمة بشكل كبير مثل عنصر الواجهة زر التحديد (checkbutton widget). عندما يتم استدعاؤه، فإنه يتنقل بين حالة التحديد وغير التحديد. عندما يتم تحديد الإدخال، يتم تخزين قيمة معينة في متغير عام معين (كما هو محدد بواسطة خيارات -onvalue و -variable للإدخال)؛ عندما يتم إلغاء تحديد الإدخال، يتم تخزين قيمة أخرى (محددة بواسطة الخيار -offvalue) في المتغير العام. يتم عرض مربع مؤشر بجوار تسمية إدخال زر التحديد. إذا تم تحديد الإدخال، فسيتم عرض مركز المؤشر باللون المحدد بواسطة الخيار -selectcolor للإدخال؛ بخلاف ذلك، سيتم عرض مركز المؤشر بلون خلفية القائمة. إذا تم تحديد خيار -command لإدخال زر تحديد، فسيتم تقييم قيمته كأمر Tcl في كل مرة يتم فيها استدعاء الإدخال؛ يحدث هذا بعد تبديل حالة تحديد الإدخال.

إدخالات أزرار الاختيار

tk_menuSetFocus

NAME

tk_menuSetFocus – Manage the input focus for a toplevel menu

SYNOPSIS

tk_menuSetFocus ?menu?

DESCRIPTION

This procedure is used to manage the input focus for a toplevel menu widget. It is normally called automatically by Tk when a menu is posted or unposted, or when the mouse pointer moves into or out of a menu.

If the menu argument is specified, it must be the name of a menu widget. If the menu is currently visible (i.e., it has been posted), then tk_menuSetFocus will attempt to set the input focus to that menu widget. This is typically used when a menu is initially posted, or when the mouse enters the menu.

If the menu argument is omitted, then tk_menuSetFocus will determine which menu, if any, should currently have the input focus. This is typically used when a menu is unposted, or when the mouse leaves a menu. It will then set the focus to that menu, or remove the focus from any menu if no menu should have it.

In general, the input focus should be on the toplevel menu that is currently active. This allows keyboard traversal of the menu. If the mouse pointer is inside a menu, the focus is given to that menu. If the mouse pointer leaves a menu and moves into another toplevel window, the focus is removed from the menu. If the mouse pointer leaves a menu and moves into a child menu (a submenu), the focus is given to the child menu.

tk_menuSetFocus – إدارة تركيز الإدخال لقائمة النافذة العلوية

الوصف

يُستخدم هذا الإجراء لإدارة تركيز الإدخال لعنصر واجهة قائمة النافذة العلوية. يتم استدعاؤه عادةً تلقائيًا بواسطة Tk عند نشر قائمة أو إلغاء نشرها، أو عند تحريك مؤشر الماوس داخل قائمة أو خارجها.

إذا تم تحديد الوسيط menu، فيجب أن يكون اسم عنصر واجهة قائمة. إذا كانت القائمة مرئية حاليًا (أي تم نشرها)، فستحاول tk_menuSetFocus تعيين تركيز الإدخال لعنصر واجهة القائمة هذا. يُستخدم هذا عادةً عند نشر قائمة في البداية، أو عند دخول الماوس إلى القائمة.

إذا تم حذف الوسيط menu، فستحدد tk_menuSetFocus أي قائمة، إن وجدت، يجب أن يكون لها تركيز الإدخال حاليًا. يُستخدم هذا عادةً عند إلغاء نشر قائمة، أو عند خروج الماوس من قائمة. ثم تقوم بتعيين التركيز إلى تلك القائمة، أو إزالة التركيز من أي قائمة إذا لم يكن ينبغي لأي قائمة الحصول عليه.

بشكل عام، يجب أن يكون تركيز الإدخال على قائمة النافذة العلوية النشطة حاليًا. هذا يسمح بالتنقل في القائمة باستخدام لوحة المفاتيح. إذا كان مؤشر الماوس داخل قائمة، يتم إعطاء التركيز لتلك القائمة. إذا غادر مؤشر الماوس القائمة وانتقل إلى نافذة علوية أخرى، يتم إزالة التركيز من القائمة. إذا غادر مؤشر الماوس القائمة وانتقل إلى قائمة فرعية (قائمة فرعية)، يتم إعطاء التركيز للقائمة الفرعية.
