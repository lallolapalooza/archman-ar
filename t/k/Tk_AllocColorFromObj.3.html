NAME

Tk_AllocColorFromObj - allocate a color value from a Tk object

SYNOPSIS

#include <tk.h>

typedef struct TkColor TkColor;

TkColor *
Tk_AllocColorFromObj(interp, objPtr)
    Tcl_Interp *interp;
    Tcl_Obj *objPtr;

ARGUMENTS

Tcl_Interp *interp
Interpreter to use for error reporting.
Tcl_Obj *objPtr
Object containing the color specification. The object is expected to be a string representation of a color.

DESCRIPTION

The Tk_AllocColorFromObj function is a high-level Tk routine that allocates a color value corresponding to the color specification in objPtr. objPtr should be a Tk object that contains a string representation of a color. Tk_AllocColorFromObj will parse the string, convert it to an RGB value, and return a pointer to a TkColor structure. This structure contains the RGB value and a pixel value suitable for use with the window system. The returned TkColor structure is managed by Tk and should not be freed by the caller. It is guaranteed to remain valid for the lifetime of the application. If the color string cannot be parsed or if an error occurs during allocation, Tk_AllocColorFromObj will return NULL and leave an error message in the interpreter.

KEYWORDS

color, allocation, object, Tk_AllocColor
