NAME

Tk_ConfigureValue, Tk_ConfigureWidget, Tk_ConfigureOptions, Tk_ConfigureInfo, Tk_ConfigureValue — configure Tk widgets

SYNOPSIS

#include <tk.h>

int
Tk_ConfigureWidget(
    Tk_Window tkwin,
    Tk_ConfigSpec *specPtr,
    int argc,
    const char **argv,
    ClientData instanceData,
    int flags
);

int
Tk_ConfigureOptions(
    ClientData instanceData,
    Tk_ConfigSpec *specPtr,
    const char *argv
);

int
Tk_ConfigureInfo(
    Tk_Window tkwin,
    Tk_ConfigSpec *specPtr,
    ClientData instanceData,
    int flags
);

int
Tk_ConfigureValue(
    Tk_Window tkwin,
    Tk_ConfigSpec *specPtr,
    ClientData instanceData,
    const char *value,
    int flags
);

ARGUMENTS

ClientData instanceData
Points to the instance-specific data for the widget, typically the widget’s main structure.

If the option type is TK_CONFIG_CUSTOM, this argument is passed to the parseProc and freeProcPtr functions.

Tk_ConfigSpec *specPtr
Points to an array of Tk_ConfigSpec structures that describe the configuration options supported by the widget.
int argc
Number of elements in the argv array.
const char **argv
Array of strings describing the configuration options to set. For Tk_ConfigureWidget, each element of argv is a string like "option value".
Tk_Window tkwin
The widget’s window. This is needed for options that depend on the window’s display or other window-specific information.
int flags
Zero or more of the following flags, OR-ed together. The flags control how configuration is performed.
TK_CONFIG_ARGV0
The first element of argv is the name of the option, and the rest of the elements are the value. This is used when parsing individual option assignments.

If this flag is not set, then each element of argv is assumed to be a string like "option value".

TK_CONFIG_COLOR_ONLY
Only allow color options to be set. This is used for options like "background" and "foreground".
TK_CONFIG_DEF_ONLY
Only allow default values to be set. This is used for options that have default values.
TK_CONFIG_MONO_ONLY
Only allow monochrome options to be set. This is used for options that depend on the color depth of the display.
TK_CONFIG_OBJV
The argv argument is actually an array of Tcl objects.

This flag is used internally by Tk.

TK_CONFIG_SET_DEFAULT
Set the default value for the option, rather than the actual value. This is used for options that have default values.
TK_CONFIG_SKIP_UNMATCHED
If an option is not found in the configuration table, skip it rather than generating an error. This is useful when configuring multiple widgets with the same configuration table.
TK_CONFIG_VALIDATE
Validate the option value but do not set it. This is used for options that are being validated before being set.
const char *value
The value to set for the option. This is used by Tk_ConfigureValue.

DESCRIPTION

These functions are used to configure Tk widgets. They allow you to set and get the configuration options of a widget.

Tk_ConfigureWidget is the main configuration function. It takes a widget’s window, a configuration table, and a list of option-value pairs, and it configures the widget accordingly. It returns a standard Tk error code: TCL_OK on success, or TCL_ERROR on failure.

Tk_ConfigureOptions is a lower-level function that configures a widget based on a single string containing option-value pairs.

Tk_ConfigureInfo retrieves the current values of the configuration options for a widget. It returns a list of strings, where each string is an option-value pair.

Tk_ConfigureValue sets the value of a single configuration option for a widget.

CUSTOM OPTION TYPES

Tk_ConfigSpec supports custom option types through the TK_CONFIG_CUSTOM type. When this type is used, the customPtr field of the Tk_ConfigSpec structure points to a Tk_CustomOption structure:

typedef struct {
    void (*parseProc)(ClientData clientData, Tcl_Interp *interp,
            Tk_Window tkwin, const char *value, char *recordPtr,
            int offset, char *saveInternalPtr);
    void (*printProc)(ClientData clientData, Tk_Window tkwin,
            char *recordPtr, int offset, Tcl_Obj **objPtrPtr);
    void (*freeProcPtr)(ClientData clientData, Tk_Window tkwin,
            char *recordPtr, int offset);
    char *name; /* Internal name of the option type */
} Tk_CustomOption;

The parseProc function is called to parse the string value of the option and store it in the widget’s record. The recordPtr argument points to the widget’s main data structure, and offset is the byte offset within that structure where the option’s value should be stored. The saveInternalPtr argument points to a location where the original value of the option should be saved, so that it can be restored later if the configuration fails.

The printProc function is called to convert the stored value of the option back into a string representation. The objPtrPtr argument points to a Tcl_Obj pointer that should be filled with the string representation of the option’s value. If the result string is stored in static memory then printProc need not do anything with the freeProcPtr argument.

Once parseProc and printProc have been defined and a Tk_CustomOption structure has been created for them, options of this new type may be manipulated with Tk_ConfigSpec entries whose type fields are TK_CONFIG_CUSTOM and whose customPtr fields point to the Tk_CustomOption structure.

EXAMPLES

Although the explanation of Tk_ConfigureWidget is fairly complicated, its actual use is pretty straightforward. The easiest way to get started is to copy the code from an existing widget. The library implementation of frames (tkFrame.c) has a simple configuration table, and the library implementation of buttons (tkButton.c) has a much more complex table that uses many of the fancy specFlags mechanisms.
