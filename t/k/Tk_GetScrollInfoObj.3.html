Tk_GetScrollInfoObj(3)

الحزمة: tk

التراخيص: TCL

Tk_GetScrollInfo(3) إجراءات مكتبة Tk Tk_GetScrollInfo(3)

الاسم

Tk_GetScrollInfoObj، Tk_GetScrollInfo - تحليل الوسائط لأوامر التمرير

الملخص

#include <tk.h>

int
Tk_GetScrollInfoObj(
    Tcl_Interp *interp,
    int objc,
    Tcl_Obj *const *objv,
    double *fractionPtr,
    int *stepsPtr
);

int
Tk_GetScrollInfo(
    Tcl_Interp *interp,
    int argc,
    const char ** argv,
    double *fractionPtr,
    int *stepsPtr
);

الوسائط

Tcl_Interp *interp (مدخل)
المفسر المستخدم لتقديم تقارير الأخطاء.
int objc (مدخل)
عدد كائنات Tcl_Obj في مصفوفة objv.
Tcl_Obj *const * objv (مدخل)
كائنات الوسائط. تمثل هذه الكائنات أمر الأداة بأكمله، حيث تكون الكلمة الأولى عادةً هي اسم الأداة والكلمة الثانية عادةً هي xview أو yview.
int argc (مدخل)
عدد السلاسل النصية في مصفوفة argv.
const char ** argv (مدخل)
سلاسل الوسائط. تمثل هذه السلاسل أمر الأداة بأكمله، حيث تكون الكلمة الأولى عادةً هي اسم الأداة والكلمة الثانية عادةً هي xview أو yview.
double *fractionPtr (مخرج)
يتم ملؤها بكسر من الخيار moveto، إن وجد.
int *stepsPtr (مخرج)
يتم ملؤها بعدد الأسطر أو الصفحات من الخيار scroll، إن وجد. قد تكون القيمة سالبة.

الوصف

Tk_GetScrollInfoObj تقوم بتحليل الوسائط المتوقعة من أوامر التمرير في الأداة مثل xview و yview. تستقبل قائمة الكلمات الكاملة التي تشكل أمر الأداة وتقوم بتحليل الكلمات بدءًا من objv[2]. يجب أن تكون الكلمات بدءًا من objv[2] بأحد الأشكال التالية:

moveto fraction
scroll number units
scroll number pages

أي من الكلمات الرئيسية moveto، scroll، units، و pages يمكن اختصارها. إذا كانت objv بالشكل moveto، يتم إرجاع TK_SCROLL_MOVETO كنتيجة ويتم ملء *fractionPtr بوسيط fraction الأمر، والذي يجب أن يكون قيمة حقيقية صحيحة. إذا كانت objv بالشكل scroll، يتم إرجاع TK_SCROLL_UNITS أو TK_SCROLL_PAGES ويتم ملء *stepsPtr بقيمة number، والتي يجب أن تكون قيمة صحيحة. إذا حدث خطأ في تحليل الوسائط، يتم إرجاع TK_SCROLL_ERROR ويتم ترك رسالة خطأ في نتيجة المفسر interp.

Tk_GetScrollInfo متطابقة في الوظيفة مع Tk_GetScrollInfoObj. ومع ذلك، تقبل Tk_GetScrollInfo وسائط نصية، مما يجعلها أكثر ملاءمة للاستخدام مع الأدوات القديمة.
