Tk__TableMatrix__SpreadsheetHideRows(3pm)

الحزمة: perl-tk-tablematrix

التراخيص: GPL, PerlArtistic

TableMatrix::SpreadsheetHideRows(3) توثيق Perl Tk TableMatrix::SpreadsheetHideRows(3)

الاسم

Tk::TableMatrix::SpreadsheetHideRows - عرض جدول مع إمكانية إخفاء/إظهار الصفوف قابلة للتحديد

الملخص

use Tk;
use Tk::TableMatrix::SpreadsheetHideRows
my $t = $top->Scrolled('SpreadsheetHideRows', 
  -selectorCol => 3,
  -expandData => $hashRef,
  -rows => 21, -cols => 11, 
  -width => 6, -height => 6,
  -titlerows => 1, -titlecols => 1,
  -variable => $arrayVar,
  -selectmode => 'extended',
  -resizeborders => 'both',
  -bg => 'white',
);

الوصف

Tk::TableMatrix::SpreadsheetHideRows هو عنصر واجهة مستخدم مشتق من Tk::TableMatrix::Spreadsheet، يقوم بتنفيذ عرض يشبه جداول البيانات للمعلومات الجدولية، حيث يمكن توسيع/إخفاء بعض صفوف الجدول عن طريق النقر على محدد +/- في الصف. يمكن استخدام هذا لعرض معلومات المستوى الأعلى في جدول، مع السماح للمستخدم بتوسيع صفوف جدول معينة لعرض معلومات مستوى التفاصيل.

راجع demos/SpreadsheetHideRows في توزيع المصدر للحصول على مثال بسيط لهذا العنصر الواجهة.

خيارات خاصة بالعنصر

بالإضافة إلى خيارات Tk::TableMatrix القياسية للعنصر. يتم تطبيق الخيارات التالية:

-selectorCol
رقم العمود الذي سيظهر فيه محدد +/-. النقر على محدد +/- سيقوم بتوسيع/إخفاء بيانات التفاصيل في الجدول لصف معين.
-selectorColWidth
عرض العمود المستخدم لعرض محدد +/-. الافتراضي هو 2
-expandData
مرجع هاش يحدد بيانات التفاصيل التي يتم عرضها عند توسيع صف (بالنقر على محدد +/-). يجب أن يحتوي مرجع الهاش هذا على الهيكل التالي: 
$expandData = {  
      row1 => {  tag  => 'detailDataTag',
                 data => $detailData,
                 spans=> $spanData,
                 expandData => $subLevelData
              },
      row2 => { 
         .
         .
}

حيث: 
  row1, row2, ...         أرقام الصفوف التي يمكن توسيعها.
  tag => 'detailDataTag'  اسم العلامة الذي سيتم تطبيقه على بيانات التفاصيل.
                          (اختياري)
  $detailData              مصفوفة ثنائية الأبعاد من بيانات التفاصيل التي سيتم عرضها 
                           عند توسيع الصف.
                           مثال: [ [ r1c1, r1c2, r1c3 ],
                                  [ r2c1, r2c2, r2,c3] ]
  $spans                   مصفوفة أحادية البعد من معلومات الامتداد (اختياري) 
                           لاستخدامها في عرض معلومات التفاصيل.
                           مثال:  [ col2 =>  "rows,cols", col4 =>  "rows,cols", ... ]
  $subLevelData            اختياري expandData متكرر يستخدم للاحتفاظ ببيانات تفاصيل بيانات التفاصيل.

بيانات الأعضاء

العناصر التالية مخزنة كبيانات أعضاء:

defaultCursor
اسم مؤشر الفأرة الذي يستخدم للخلايا العادية (أي غير العنوان، غير المؤشر) في العنصر. يتم تعيين هذا إلى قيمة خيار $widget->cget(-cursor) عند إنشاء العنصر.
indRowCols
مرجع هاش لفهارس الصفوف/الأعمدة حيث توجد المؤشرات. هذا مرجع بحث سريع مبني من _expandData.
_expandData
النسخة الداخلية من مرجع الهاش expandData. أي بيانات تفاصيل فرعية (أي بيانات توسيع موجودة في مستويات أقل من expandData) تكون مرئية يتم وضعها في المستوى الأعلى من هذا المرجع، لتتبع expandData المرئية.

طرق العنصر

بالإضافة إلى الطريقة القياسية لعنصر Tk::TableMatrix. يتم تطبيق الطرق التالية:

showDetail

يعرض (أي يوسع الجدول) بيانات التفاصيل لصف معين. يتم استدعاء هذه الطريقة عندما ينقر المستخدم على مؤشر غير متوسع بالفعل.

الاستخدام:

$widget->showDetail($row);  

# يعرض بيانات التفاصيل للصف رقم $row

hideDetail

يخفي بيانات التفاصيل لصف معين. يتم استدعاء هذه الطريقة عندما ينقر المستخدم على مؤشر متوسع بالفعل.

الاستخدام:

$widget->hideDetail($row);  

# يخفي بيانات التفاصيل للصف رقم $row
