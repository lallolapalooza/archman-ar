Tk_GetCapStyle(3)

الحزمة: tk

التراخيص: TCL

Tk_GetCapStyle(3) إجراءات مكتبة Tk Tk_GetCapStyle(3)

الاسم

Tk_GetCapStyle, Tk_NameOfCapStyle - ترجمة بين السلاسل النصية وأنماط الأطراف

الملخص

#include <tk.h>

int
Tk_GetCapStyle(interp, string, capPtr)

const char *
Tk_NameOfCapStyle(cap)

الوسائط

Tcl_Interp *interp (مدخل)
المفسر لاستخدامه في الإبلاغ عن الأخطاء.
const char *string (مدخل)
سلسلة نصية تحتوي على اسم نمط الطرف - أحد الخيارات التالية: “butt”، “projecting”، أو “round” - أو اختصار فريد لأحدها.
int *capPtr (مخرج)
مؤشر إلى الموقع الذي سيتم فيه تخزين نمط طرف X المقابل لـ string.
int cap (مدخل)
نمط الطرف: أحد الخيارات التالية: CapButt، CapProjecting، أو CapRound.

الوصف

تقوم Tk_GetCapStyle بتخزين نمط طرف X المقابل لـ string في *capPtr. سيكون هذا أحد القيم CapButt، CapProjecting، أو CapRound. تُستخدم أنماط الأطراف عادةً في سياقات رسومات X للإشارة إلى كيفية إنهاء نقاط نهاية الخطوط. راجع وثائق X للحصول على معلومات حول ما تعنيه كل نمط.

في الظروف العادية، يكون القيمة المرجعة هي TCL_OK ولا يتم استخدام interp. إذا لم تحتوي string على نمط طرف صالح أو اختصار لأحد هذه الأسماء، يتم تخزين رسالة خطأ في نتيجة المفسر interp، ويتم إرجاع TCL_ERROR، ولا يتم تعديل *capPtr.

Tk_NameOfCapStyle هي العملية العكسية المنطقية لـ Tk_GetCapStyle. بالنظر إلى نمط طرف مثل CapButt، فإنها تُرجع سلسلة نصية ثابتة مخصصة مقابلة لـ cap. إذا لم يكن cap نمط طرف قانونيًا، فسيتم إرجاع "unknown cap style".

كلمات مفتاحية

butt، cap style، projecting، round
