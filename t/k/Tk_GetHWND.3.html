Tk_GetHWND(3)

الحزمة: tk

التراخيص: TCL

HWND(3) إجراءات مكتبة Tk HWND(3)

الاسم

Tk_GetHWND, Tk_AttachHWND - إدارة التفاعلات بين مقبض Windows ونافذة X

الملخص

#include <tkPlatDecls.h>

HWND
Tk_GetHWND(window)

Window
Tk_AttachHWND(tkwin, hwnd)

الوسائط

Window window (مدخل)
رمز X للنافذة.
Tk_Window tkwin (مدخل)
نافذة Tk للنافذة.
HWND hwnd (مدخل)
مقبض Windows للنافذة.

الوصف

Tk_GetHWND تُرجع معرّف مقبض Windows (HWND) لنافذة X التي تم تقديمها بواسطة window.

Tk_AttachHWND تربط معرّف مقبض Windows (HWND) بـ Tk_Window المحددة التي تم تقديمها بواسطة tkwin. تُرجع نافذة X التي تغلف مقبض HWND.
