Tk__demos__widget_lib__trace2(3pm)

الحزمة: perl-tk

التراخيص: PerlArtistic, GPL, custom

demos::widget_lib::trace2(3) وثائق Perl/Tk demos::widget_lib::trace2(3)

الاسم

Tk::TraceText - محتويات النص معرفة بمتغير متتبع.

ملخص

$tt = $parent->TraceText(-option => value, ... );

الوصف

إنشاء عنصر واجهة مستخدم TraceText جديد مشتق من عنصر الواجهة Text القياسي. نظرًا لأنه يرث جميع الخيارات والأساليب الأساسية، فإنه يتصرف تمامًا مثل عنصر الواجهة Text. بالإضافة إلى ذلك، يضيف TraceText خيار -textvariable، وهو مرجع إلى متغير عادي (scalar) يحدد محتويات العنصر.

مبني على عنصر الواجهة TracedText الخاص بـ Tcl/Tk "عنصر واجهة مستخدم متجاوز" بواسطة Kevin Kenny.

-textvariable
مرجع لمتغير عادي (scalar). تحدد قيمة المتغير محتويات عنصر الواجهة TraceText. يؤدي استخدام لوحة المفاتيح لإدراج أو حذف النص إلى تغيير قيمة المتغير، ويؤدي تغيير المتغير إلى تغيير محتويات عنصر الواجهة TraceText.

الأساليب

أساليب عنصر الواجهة Text القياسية.

العناصر الفرعية المعلنة

لا شيء.

مثال

my $tt = $mw->TraceText( -textvariable => \$scalar );
