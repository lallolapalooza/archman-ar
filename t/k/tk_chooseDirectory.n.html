tk_chooseDirectory(n)

الحزمة: tk

التراخيص: TCL

tk_chooseDirectory(n) أوامر Tk المضمنة tk_chooseDirectory(n)

الاسم

tk_chooseDirectory - تظهر مربع حوار للمستخدم لاختيار دليل.

الملخص

tk_chooseDirectory ?option value ...?

الوصف

الإجراء tk_chooseDirectory يظهر مربع حوار للمستخدم لاختيار دليل. الأزواج التالية من option-value ممكنة كوسائط لسطر الأوامر:

-command string
يحدد بادئة لأمر Tcl لاستدعائه عند إغلاق المستخدم لمربع الحوار بعد تحديد عنصر. لا يتم استدعاء هذا الرد إذا ألغى المستخدم مربع الحوار. يتكون الأمر الفعلي من string متبوعًا بمسافة والقيمة التي اختارها المستخدم في مربع الحوار. هذا متاح فقط على macOS.
-initialdir dirname
يحدد أنه يجب عرض الأدلة في directory عند ظهور مربع الحوار. إذا لم يتم تحديد هذا المعلمة، فإن الدليل الأولي يكون افتراضيًا إلى دليل العمل الحالي في الأنظمة غير Windows وفي أنظمة Windows قبل Vista. في Vista والأنظمة الأحدث، يكون الدليل الأولي افتراضيًا إلى آخر دليل اختاره المستخدم للتطبيق. إذا حددت المعلمة مسارًا نسبيًا، فستقوم القيمة المرجعة بتحويل المسار النسبي إلى مسار مطلق.
-message string
يحدد رسالة لتضمينها في مساحة العميل لمربع الحوار. هذا متاح فقط على macOS.
-mustexist boolean
يحدد ما إذا كان يمكن للمستخدم تحديد أدلة غير موجودة. إذا كانت هذه المعلمة صحيحة، فلا يمكن للمستخدم تحديد سوى الأدلة الموجودة بالفعل. القيمة الافتراضية هي false.
-parent window
يجعل window الشبيه المنطقي لمربع الحوار. يتم عرض مربع الحوار فوق نافذة الأصل. على macOS، يحول هذا مربع حوار الملف إلى ورقة مرفقة بنافذة الأصل.
-title titleString
يحدد سلسلة نصية لعرضها كعنوان لمربع الحوار. إذا لم يتم تحديد هذه المعلمة، فسيتم عرض عنوان افتراضي.

مثال

set dir [tk_chooseDirectory \
        -initialdir ~ -title "اختر دليلاً"]
if {$dir eq ""} {
   label .l -text "لم يتم اختيار أي دليل"
} else {
   label .l -text "تم الاختيار $dir"
}
