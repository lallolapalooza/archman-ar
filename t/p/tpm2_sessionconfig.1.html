NAME

tpm2_sessionconfig — Configure TPM2 session attributes.

SYNOPSIS

tpm2_sessionconfig [OPTION...] [session.ctx]

DESCRIPTION

The tpm2_sessionconfig command is used to configure session attributes for TPM2. Sessions are used to manage state between TPM2 commands, and can be configured to provide various security and operational benefits.

The command allows for the modification of session parameters such as disabling continuation sessions, enabling debugging, and specifying other session-related attributes.

OPTIONS

The following options are available:

COMMON OPTIONS

In addition to the options below, the following options are common to all commands:

-h, --help
Display help message.
-v, --version
Display version information.
-d, --debug
Enable debug logging.
-V, --verbose
Enable verbose logging.
-t, --tcti NAME[:CONFIG]
Tabernacle Connection and Test Interface (TCTI) module name and optional configuration string. Default is mssim.

TCTI Configuration

The TCTI configuration string is a series of simple key-value pairs separated by a comma (,). Each key and value are separated by an equals sign (=).

•
The TCTI abrmd supports two keys:
1.
bus_name : The name of the tabrmd service on the bus (a string).
2.
bus_type : The type of the dbus instance (a string) limited to session and system.

Specify the tabrmd tcti name and a config string of bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

Specify the default (abrmd) tcti and a config string of bus_type=session:

\--tcti:bus_type=session

NOTE: abrmd and tabrmd are synonymous for the various known TCTI modules.

TCTI OPTIONS

--disable-continuesession
Disable the ability for the session to continue after the current TCTI connection is closed.
--enable-continuesession
Enable the ability for the session to continue after the current TCTI connection is closed.
--disable-tpmreset
Disable the automatic TPM reset when the session is closed.
--enable-tpmreset
Enable the automatic TPM reset when the session is closed.
--disable-savedstate
Disable the ability to save the session state.
--enable-savedstate
Enable the ability to save the session state.
--session-attributes ATTRIBUTES
Set the session attributes. ATTRIBUTES is a comma-separated list of attributes, which can be any combination of:
  • continueSession
  • decryptWithPolicy
  • encryptedTakeOwnership
  • auditBothExtra
  • auditCreator
  • auditPolicy
  • commandAudit
  • tpmSeal
  • restricted
  • decrypt
  • verified
  • userWithAuth
  • ownerAuth

EXAMPLES

Start a bounded & salted session, disable continuesession and display session

tpm2 createprimary -c prim.ctx
tpm2 startauthsession -S session.ctx --policy-session -c prim.ctx
### Session info before changing attributes
tpm2 sessionconfig session.ctx
### Session info after changing attributes
tpm2 sessionconfig --disable-continuesession
tpm2 sessionconfig session.ctx

Returns

Tools can return any of the following codes:

•
0 - Success.
•
1 - General non-specific error.
•
2 - Options handling error.
•
3 - Authentication error.
•
4 - TCTI related error.
•
5 - Non supported scheme. Applicable to tpm2_testparams.
