tpsv(3)

الحزمة: lapack-doc

التراخيص: custom

الاسم

tpsv - يحل أحد أنظمة المعادلات لمصفوفة مثلثة، معلبة.

الشرح

subroutine ctpsv (character uplo, character trans, character diag, integer n, complex, dimension(*) ap, complex, dimension(*) x, integer incx)

CTPSV

الغرض:

!>
!> CTPSV  يحل أحد أنظمة المعادلات
!>
!>    A*x = b,   أو   A**T*x = b,   أو   A**H*x = b,
!>
!> حيث b و x متجهان بعنصر n و A مصفوفة مثلثة n × n، وحدة، أو غير وحدة، علوية أو سفلية،
!> مقدمة في شكل معلب.
!>
!> لا يتضمن هذا الروتين اختبارًا للتعارض أو شبه التعارض. يجب إجراء مثل هذه الاختبارات
!> قبل استدعاء هذا الروتين.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>           عند الدخول، يحدد UPLO ما إذا كانت المصفوفة علوية أو
!>           مصفوفة مثلثة سفلية كما يلي:
!>
!>              UPLO = 'U' أو 'u'   A هي مصفوفة مثلثة علوية.
!>
!>              UPLO = 'L' أو 'l'   A هي مصفوفة مثلثة سفلية.
!>

TRANS

!>          TRANS هو CHARACTER*1
!>           عند الدخول، يحدد TRANS المعادلات التي سيتم حلها كما يلي:
!>
!>              TRANS = 'N' أو 'n'   A*x = b.
!>
!>              TRANS = 'T' أو 't'   A**T*x = b.
!>
!>              TRANS = 'C' أو 'c'   A**H*x = b.
!>

DIAG

!>          DIAG هو CHARACTER*1
!>           عند الدخول، يحدد DIAG ما إذا كانت A وحدة أم لا
!>           مثلثة كما يلي:
!>
!>              DIAG = 'U' أو 'u'   يُفترض أن A وحدة مثلثة.
!>
!>              DIAG = 'N' أو 'n'   لا يُفترض أن A وحدة
!>                                  مثلثة.
!>

N

!>          N هو INTEGER
!>           عند الدخول، يحدد N ترتيب المصفوفة A.
!>           يجب أن يكون N على الأقل صفر.
!>

AP

!>          AP هو مصفوفة COMPLEX، أبعادها على الأقل
!>           ( ( n*( n + 1 ) )/2 ).
!>           قبل الدخول مع UPLO = 'U' أو 'u'، يجب أن يحتوي AP
!>           على المصفوفة المثلثة العلوية معلبة بالتتابع،
!>           عمودًا بعمود، بحيث يحتوي AP( 1 ) على a( 1, 1 )،
!>           يحتوي AP( 2 ) و AP( 3 ) على a( 1, 2 ) و a( 2, 2 )
!>           على التوالي، وهكذا.
!>           قبل الدخول مع UPLO = 'L' أو 'l'، يجب أن يحتوي AP
!>           على المصفوفة المثلثة السفلية معلبة بالتتابع،
!>           عمودًا بعمود، بحيث يحتوي AP( 1 ) على a( 1, 1 )،
!>           يحتوي AP( 2 ) و AP( 3 ) على a( 2, 1 ) و a( 3, 1 )
!>           على التوالي، وهكذا.
!>           لاحظ أنه عندما يكون DIAG = 'U' أو 'u'، فإن العناصر القطرية
!>           لـ A لا تتم الإشارة إليها، ولكن يُفترض أنها الوحدة.
!>

X

!>          X هي مصفوفة COMPLEX، أبعادها على الأقل
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           قبل الدخول، يجب أن تحتوي المصفوفة X المزودة بزيادة على المتجه
!>           b ذي n عنصرًا للطرف الأيمن. عند الخروج، يتم الكتابة فوق X
!>           بالمتجه x الحل.
!>

INCX

!>          INCX هو INTEGER
!>           عند الدخول، يحدد INCX الزيادة لعناصر
!>           X. يجب ألا يكون INCX صفرًا.
!>
