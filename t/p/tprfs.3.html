CTPRFS

الغرض:

!>
!> توفر CTPRFS حدود خطأ وتقديرات للخطأ العكسي لحل نظام المعادلات الخطية
!> ذات مصفوفة معاملات مثلثة معبأة.
!>
!> يجب أن يتم حساب مصفوفة الحل X بواسطة CTPTRS أو وسيلة أخرى
!> قبل الدخول إلى هذا الروتين. لا تقوم CTPRFS بالتنقيح التكراري
!> لأن القيام بذلك لا يمكن أن يحسن الخطأ العكسي.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular; (مثلثة عليا)
!>          = 'L':  A is lower triangular. (مثلثة سفلى)
!>

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations: (يحدد شكل نظام المعادلات:)
!>          = 'N':  A * X = B     (No transpose) (بدون تبديل)
!>          = 'T':  A**T * X = B  (Transpose) (تبديل)
!>          = 'C':  A**H * X = B  (Conjugate transpose) (تبديل مترافق)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular; (مثلثة غير وحدة)
!>          = 'U':  A is unit triangular. (مثلثة وحدة)
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0. (رتبة المصفوفة A. N >= 0.)
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0. (عدد الأطراف اليمنى، أي عدد أعمدة
!>          المصفوفتين B و X. NRHS >= 0.)
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          The upper or lower triangular matrix A, packed columnwise in
!>          a linear array.  The j-th column of A is stored in the array
!>          AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          If DIAG = 'U', the diagonal elements of A are not referenced
!>          and are assumed to be 1.
!>          (المصفوفة المثلثية العليا أو السفلى A، معبأة عمودياً في
!>          مصفوفة خطية. يتم تخزين العمود j من A في المصفوفة
!>          AP كالتالي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>          إذا كان DIAG = 'U'، لا تتم الإشارة إلى العناصر القطرية لـ A
!>          ويفترض أنها 1.)
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          The right hand side matrix B. (المصفوفة الطرفية اليمنى B.)
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>          (البعد الرئيسي للمصفوفة B. LDB >= max(1,N).)
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          The solution matrix X. (مصفوفة الحل X.)
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(1,N).
!>          (البعد الرئيسي للمصفوفة X. LDX >= max(1,N).)
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          The estimated forward error bound for each solution vector
!>          X(j) (the j-th column of the solution matrix X).
!>          If XTRUE is the true solution corresponding to X(j), FERR(j)
!>          is an estimated upper bound for the magnitude of the largest
!>          element in (X(j) - XTRUE) divided by the magnitude of the
!>          largest element in X(j).  The estimate is as reliable as
!>          the estimate for RCOND, and is almost always a slight
!>          overestimate of the true error.
!>          (حد الخطأ الأمامي المقدر لكل متجه حل
!>          X(j) (العمود j من مصفوفة الحل X).
!>          إذا كان XTRUE هو الحل الحقيقي المقابل لـ X(j)، فإن FERR(j)
!>          هو حد أعلى مقدر لحجم أكبر
!>          عنصر في (X(j) - XTRUE) مقسومًا على حجم أكبر
!>          عنصر في X(j). التقدير موثوق به قدر
!>          تقدير RCOND، وهو دائمًا تقريبًا تقدير زائد طفيف للخطأ الحقيقي.)
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          The componentwise relative backward error of each solution
!>          vector X(j) (i.e., the smallest relative change in
!>          any element of A or B that makes X(j) an exact solution).
!>          (الخطأ العكسي النسبي لكل مكون لكل متجه حل
!>          X(j) (أي، أصغر تغيير نسبي في
!>          أي عنصر في A أو B يجعل X(j) حلاً دقيقًا).)
!>

WORK

!>          WORK is COMPLEX array, dimension (2*N)
!>          (مصفوفة العمل WORK هي مصفوفة مركبة، حجمها (2*N).)
!>

RWORK

!>          RWORK is REAL array, dimension (N)
!>          (مصفوفة العمل RWORK هي مصفوفة حقيقية، حجمها (N).)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit (نجاح الخروج)
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          (< 0: إذا كان INFO = -i، فإن المعلمة i كانت ذات قيمة غير قانونية)
!>

NAME


ZTTPRFS


estimate the error and compute backward error bounds for a solution to a triangular plus low-rank factorisation problem






SYNOPSIS


       SUBROUTINE ZTTPRFS( UPLO, TRANS, DIAG, N, NRHS, AP, B, LDB, X, LDX,
                           FERR, BERR, WORK, RWORK, INFO )



       CHARACTER * 1 UPLO, TRANS, DIAG



       INTEGER N, NRHS, LDB, LDX, INFO


       COMPLEX*16 AP( * ), B( LDB, * ), X( LDX, * )


       DOUBLE PRECISION FERR( * ), BERR( * )


       COMPLEX*16 WORK( * )


       DOUBLE PRECISION RWORK( * )






Detailed Description


ZTTPRFS approximates the backward error and computes
    weighted error bounds for the computed solution to a system of equations
    with a triangular plus a low-rank matrix $A$.


Let $A = T - S S^H$ be a triangular plus a low-rank matrix.
    This subroutine is called for each of the right hand side vectors $B$ and
    corresponding solution vectors $X$.


A system of equations $AX = B$ is solved for $X$.
    ZTTPRFS is an auxiliary routine for ZTPRTRI.


The triangular matrix $T$ is n by n, the matrix $S$ is n by k,
    and $B$ and $X$ are n by nrhs.


If UPLO = 'U', then $T$ is upper triangular.


If UPLO = 'L', then $T$ is lower triangular.


If TRANS = 'N', then $A = T - S S^H$ is not transposed.


If TRANS = 'T' or 'C', then $A = T^T - S S^H$ or $A = T^H - S S^H$
    respectively.


If DIAG = 'N', then the diagonal elements of $T$ are assumed
    to be non-unity.


If DIAG = 'U', then the diagonal elements of $T$ are assumed
    to be unity.

الاسم


ZTTPRFS


تقدير الخطأ وحساب حدود الخطأ الخلفي لحل مشكلة تحويل مصفوفة مثلثة بالإضافة إلى مصفوفة منخفضة الرتبة






الملخص


       SUBROUTINE ZTTPRFS( UPLO, TRANS, DIAG, N, NRHS, AP, B, LDB, X, LDX,
                           FERR, BERR, WORK, RWORK, INFO )



       CHARACTER * 1 UPLO, TRANS, DIAG



       INTEGER N, NRHS, LDB, LDX, INFO


       COMPLEX*16 AP( * ), B( LDB, * ), X( LDX, * )


       DOUBLE PRECISION FERR( * ), BERR( * )


       COMPLEX*16 WORK( * )


       DOUBLE PRECISION RWORK( * )






الوصف التفصيلي


يقوم ZTTPRFS بتقريب الخطأ الخلفي وحساب حدود الخطأ الموزونة للحل المحسوب لنظام معادلات بمصفوفة مثلثة بالإضافة إلى مصفوفة ذات رتبة منخفضة $A$.


لنفترض أن $A = T - S S^H$ هي مصفوفة مثلثة بالإضافة إلى مصفوفة ذات رتبة منخفضة. يتم استدعاء هذه الروتين الفرعي لكل متجه من المتجهات الطرفية $B$ ومتجهات الحل المقابلة $X$.


يتم حل نظام المعادلات $AX = B$ لإيجاد $X$. ZTTPRFS هو روتين فرعي مساعد لـ ZTPRTRI.


المصفوفة المثلثة $T$ هي $n \times n$، والمصفوفة $S$ هي $n \times k$، والمصفوفتان $B$ و $X$ هما $n \times nrhs$.


إذا كان UPLO = 'U'، فإن $T$ تكون مثلثة علوية.


إذا كان UPLO = 'L'، فإن $T$ تكون مثلثة سفلية.


إذا كان TRANS = 'N'، فإن $A = T - S S^H$ ليست منقولة.


إذا كان TRANS = 'T' أو 'C'، فإن $A = T^T - S S^H$ أو $A = T^H - S S^H$ على التوالي.


إذا كان DIAG = 'N'، فإن عناصر القطر في $T$ يُفترض أنها غير موحدة.


إذا كان DIAG = 'U'، فإن عناصر القطر في $T$ يُفترض أنها موحدة.
