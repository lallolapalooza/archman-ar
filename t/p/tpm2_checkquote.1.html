الاسم

tpm2_checkquote(1) - يتحقق من صحة اقتباس مقدم من TPM.

الملخص

tpm2_checkquote [خيارات]

الوصف

tpm2_checkquote(1) - يستخدم الجزء العام من المفتاح المقدم للتحقق من صحة اقتباس تم إنشاؤه بواسطة TPM. سيتحقق هذا من صحة التوقيع مقابل رسالة الاقتباس، وإذا تم توفيرها، تحقق من أن البيانات المؤهلة وقيم PCR تتطابق مع تلك الموجودة في الاقتباس. يمكن توفير قيم PCR مع أو بدون معلومات TPML_PCR_SELECTION. مثال على قيم PCR بدون معلومات اختيار PCR هو ناتج tpm2_pcrread. إذا تم تحديد قيمة PCR بدون معلومات اختيار PCR، فيجب تحديد سلسلة اختيار PCR باستخدام الخيار -l لتفسير بيانات PCR.

الخيارات

•
-u, --public=ملف:

مدخل الملف للجزء العام من مفتاح التحقق من التوقيع. إما ملف pem أو ملف التنسيق العام tss.

•
-g, --hash-algorithm=خوارزمية:

خوارزمية التجزئة المستخدمة لهضم الرسالة.

•
-m, --message=ملف:

ملف رسالة الاقتباس الذي يشكل البيانات التي تم توقيعها بواسطة TPM.

•
-s, --signature=ملف:

ملف التوقيع المدخل للتوقيع الذي سيتم التحقق من صحته.

•
-f, --pcr=ملف:

ملف PCR اختياري لحفظ قائمة قيم PCR التي تم تضمينها في الاقتباس.

•
-l, --pcr-list=PCR:

قائمة بنوك PCR ومعرفات PCR المحددة لكل بنك.

•
-q, --qualification=سلسلة سداسية عشرية أو مسار:

بيانات التأهيل للاقتباس. يمكن أن تكون سلسلة سداسية عشرية أو مسار. يستخدم هذا عادةً لإضافة رقم عشوائي ضد هجمات إعادة التشغيل.

•
-F, --format=تنسيق:

مهمل وتم تجاهله لأنه زائد عن الحاجة.

محددات الخوارزميات

تدعم الخيارات التي تأخذ خوارزميات "أسماء لطيفة".

هناك فئتان رئيسيتان من سلاسل تحديد الخوارزميات، بسيطة ومعقدة. لن تقبل TPM سوى خوارزميات معينة، بناءً على الاستخدام والظروف.

محددات معقدة

الكائنات، عند تحديدها لإنشائها بواسطة TPM، لديها خوارزميات عديدة لملء البيانات العامة. أشياء مثل النوع والمخطط وتفاصيل غير متماثلة وحجم المفتاح وما إلى ذلك. فيما يلي التنسيق العام لتحديد هذه البيانات: <النوع>:<المخطط>:<تفاصيل متماثلة>

محددات النوع

هذا الجزء من محدد الخوارزمية المعقد مطلوب. سيتم افتراض مخطط المخطط والتفاصيل المتماثلة المتبقية بناءً على النوع المحدد ونوع الكائن الذي يتم إنشاؤه.

•
aes - افتراضي AES: aes128
•
aes128<الوضع> - AES 128 بت مع وضع اختياري (ctr|ofb|cbc|cfb|ecb). إذا لم يتم تحديد الوضع، فسيتم افتراض null.
•
aes192<الوضع> - نفس aes128<الوضع>، باستثناء حجم مفتاح 192 بت.
•
aes256<الوضع> - نفس aes128<الوضع>، باستثناء حجم مفتاح 256 بت.
•
sm4 - افتراضي SM4: sm4128
•
sm4128 أو sm4_128 <الوضع> - SM4 128 بت مع وضع اختياري (ctr|ofb|cbc|cfb|ecb). إذا لم يتم تحديد الوضع، فسيتم افتراض null.
•
ecc - منحنى بيضاوي، افتراضي ecc256.
•
ecc192 أو ecc_nist_p192 - منحنى NIST ECC 192 بت
•
ecc224 أو ecc_nist_p224 - منحنى NIST ECC 224 بت
•
ecc256 أو ecc_nist_p256 - منحنى NIST ECC 256 بت
•
ecc384 أو ecc_nist_p384 - منحنى NIST ECC 384 بت
•
ecc521 أو ecc_nist_p521 - منحنى NIST ECC 521 بت
•
ecc_sm2 أو ecc_sm2_p256 - منحنى SM2 256 بت
•
rsa - افتراضي RSA: rsa2048
•
rsa1024 - RSA بحجم مفتاح 1024 بت.
•
rsa2048 - RSA بحجم مفتاح 2048 بت.
•
rsa3072 - RSA بحجم مفتاح 3072 بت.
•

محددات المخطط

بعد ذلك، يوجد حقل اختياري، يمكن تخطيه.

المخططات عادة ما تكون مخططات التوقيع أو مخططات التشفير غير المتماثل. تأخذ معظم مخططات التوقيع خوارزمية تجزئة مباشرة بعد مخطط التوقيع. إذا كانت خوارزمية التجزئة مفقودة، فإنها تفترض sha256. بعضها لا يأخذ معلمات، والبعض الآخر يأخذ معلمات متعددة.

NAME

tpm2_checkquote — verify a TPM quote

SYNOPSIS

tpm2_checkquote [-n | --nontrusted] [-S s | --session s] [-c c | --context c] [-p p | --parent p] [-r r | --policy-parent r] [-l l | --locality l] [-t t | --tcti t] [-e e | --endpoint e] [-P P | --pcr-bank P] [-u u | --auth-session u] [-U U | --auth-value U] [-T T | --ticket T] [-f f | --signature-format f] [-Q | --quiet] [-V | --version] [-h | --help]

DESCRIPTION

tpm2_checkquote is used to verify a quote generated by the TPM. A quote is a signed digest of a set of PCRs. This command verifies the signature and PCR values.

OPTIONS

-n, --nontrusted
The quote is not signed by a primary seed, but by a quote key under the non-trusted primary.
-S s, --session s
The session file to load. This is used to load the session state.
-c c, --context c
The context file to load. This is used to load the TPM context.
-p p, --parent p
The parent of the quote key. This defaults to the owner primary if the --nontrusted flag is not set.
-r r, --policy-parent r
The parent of the quote key if it was created under a policy. This is only used if the --nontrusted flag is not set.
-l l, --locality l
The locality of the PCRs. This defaults to 0x3 if not specified.
-t t, --tcti t
The Trusted Computing Technology Interface (TCTI) module to use. This defaults to the value of the TPM2_TCTI environment variable.
-e e, --endpoint e
The endpoint for the TCTI module. This can be a device path, IP address, or hostname.
-P P, --pcr-bank P
The PCR bank to use. This can be a comma-separated list of PCR banks. Supported values are sha1, sha256, sha384, sha512.
-u u, --auth-session u
The authorization session to use. This can be a session handle or a session file.
-U U, --auth-value U
The authorization value for the owner. This is used to load the owner primary if the --nontrusted flag is not set.
-T T, --ticket T
The ticket to verify. This can be a ticket file or a ticket value.
-f f, --signature-format f
The signature format to use. Supported values are DER, RAW, and PEM.
-Q, --quiet
Suppress output.
-V, --version
Print version information and exit.
-h, --help
Print help information and exit.

Algorithm Specifiers

The following options can be used to specify the algorithm to use:

-P P, --pcr-bank P
The PCR bank to use. This can be a comma-separated list of PCR banks. Supported values are sha1, sha256, sha384, sha512.

Signature Format Specifiers

The following options can be used to specify the signature format:

-f f, --signature-format f
The signature format to use. Supported values are DER, RAW, and PEM.

COMMON OPTIONS

These options are common to all tpm2-tools commands:

-t t, --tcti t
The Trusted Computing Technology Interface (TCTI) module to use. This defaults to the value of the TPM2_TCTI environment variable.
-e e, --endpoint e
The endpoint for the TCTI module. This can be a device path, IP address, or hostname.

TCTI Configuration

The TCTI configuration is used to specify how to connect to the TPM. The following TCTI modules are supported:

-t t, --tcti t
The Trusted Computing Technology Interface (TCTI) module to use. This defaults to the value of the TPM2_TCTI environment variable.
-e e, --endpoint e
The endpoint for the TCTI module. This can be a device path, IP address, or hostname.

TCTI OPTIONS

The following TCTI options are supported:

-t t, --tcti t
The Trusted Computing Technology Interface (TCTI) module to use. This defaults to the value of the TPM2_TCTI environment variable.
-e e, --endpoint e
The endpoint for the TCTI module. This can be a device path, IP address, or hostname.

EXAMPLES

Verify a quote signed by the non-trusted primary:

$ tpm2_checkquote -n -P sha256 -T ticket.bin

Verify a quote signed by the owner primary:

$ tpm2_checkquote -P sha256 -T ticket.bin -U owner_password

Returns

The command returns 0 if the quote is valid, and non-zero otherwise. The following exit codes are used:

•
0 - Success.
•
1 - General error.
•
2 - Invalid arguments.
•
3 - TPM error.
•
4 - TCTI related error.
•
5 - Non supported scheme. Applicable to tpm2_testparams.
