TPMLIB_GetTPMProperty(3)

الحزمة: libtpms

التراخيص: BSD-3-Clause

TPMLIB_GetTPMProperty(3) TPMLIB_GetTPMProperty(3)

الاسم

TPMLIB_GetTPMProperty - الحصول على خاصية وقت تشغيل لوحدة TPM

المكتبة

مكتبة TPM (libtpms, -ltpms)

الملخص

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_GetTPMProperty(enum TPMLIB_TPMProperty, int *result);

الوصف

يُستخدم استدعاء TPMLIB_GetTPMProperty() لاسترداد معلمات وقت التشغيل لوحدة TPM مثل عدد جلسات المصادقة التي يمكنها الاحتفاظ بها أو الحد الأقصى لأحجام بيانات الحالة الدائمة، أو حالة الحفظ، أو بيانات الحالة المتطايرة.

يمكن استدعاء هذه الوظيفة قبل أو بعد إنشاء وحدة TPM. التطبيق الحالي لـ libtpms سيعيد نفس القيمة قبل وبعد بدء تشغيل وحدة TPM.

مع تقديم الوظيفة TPMLIB_ChooseTPMVersion()، يجب تنفيذ استدعاء هذه الوظيفة بعد اختيار إصدار TPM. السبب هو أن إصدارات TPM المختلفة قد تعيد قيمًا مختلفة.

تم تعريف الخصائص التالية:

TPMPROP_TPM_RSA_KEY_LENGTH_MAX
الحد الأقصى لحجم مفتاح RSA.
TPMPROP_TPM_BUFFER_MAX
الحد الأقصى لأحجام مخازن أوامر ونتائج TPM.
TPMPROP_TPM_KEY_HANDLES
عدد خانات المفاتيح.
TPMPROP_TPM_OWNER_EVICT_KEY_HANDLES
عدد مفاتيح المالك التي يمكن إخلاؤها.
TPMPROP_TPM_MIN_AUTH_SESSIONS
عدد جلسات المصادقة.
TPMPROP_TPM_MIN_TRANS_SESSIONS
عدد جلسات النقل.
TPMPROP_TPM_MIN_DAA_SESSIONS
عدد جلسات DAA.
TPMPROP_TPM_MIN_SESSION_LIST
حجم قائمة الجلسات.
TPMPROP_TPM_MIN_COUNTERS
عدد العدادات الأحادية.
TPMPROP_TPM_NUM_FAMILY_TABLE_ENTRY_MIN
عدد إدخالات العائلة.
TPMPROP_TPM_NUM_DELEGATE_TABLE_ENTRY_MIN
عدد إدخالات المندوب.
TPMPROP_TPM_SPACE_SAFETY_MARGIN
هامش أمان المساحة المستخدم لأحجام الحالة القصوى لحالة الحفظ وبيانات الحالة المتطايرة. لا يُستخدم هامش الأمان هذا لحجم بيانات الحالة الدائمة.
TPMPROP_TPM_MAX_NV_SPACE
الحد الأقصى لحجم بيانات الحالة الدائمة.
TPMPROP_TPM_MAX_SAVESTATE_SPACE
الحد الأقصى لحجم بيانات حالة الحفظ (يشمل هامش أمان المساحة).
TPMPROP_TPM_MAX_VOLATILESTATE_SPACE
الحد الأقصى لحجم بيانات الحالة المتطايرة (يشمل هامش أمان المساحة).

الأخطاء

TPM_SUCCESS
اكتملت الوظيفة بنجاح.
TPM_FAIL
تم الاستعلام عن خاصية غير معرفة.

للحصول على قائمة كاملة برموز خطأ TPM، يرجى الرجوع إلى ملف التضمين libtpms/tpm_error.h

مثال

#include <stdio.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
int main(void) {
    TPM_RESULT res;
    int result;
    int rc = 0;
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
        fprintf(stderr, "Could not start the TPM.\n");
        return 1;
    }
    if (TPMLIB_GetTPMProperty(TPMPROP_TPM_RSA_KEY_LENGTH_MAX, &result)
        != TPM_SUCCESS) {
        fprintf(stderr, "Could not read the max. size of RSA keys.\n");
        goto err_exit;
    }
    fprintf(stdout, "Max. size of RSA keys: %d\n", result);
err_exit:
    TPMLIB_Terminate();
    return 0;
}
