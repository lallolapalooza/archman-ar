الحزمة: tpm2-tools

tpm2_pcrreset(1) دليل الأوامر العامة tpm2_pcrreset(1)

الاسم

tpm2_pcrreset(1) - إعادة تعيين بنوك PCR واحدة أو أكثر

الملخص

tpm2_pcrreset [خيارات] مؤشر_PCR ...

الوصف

tpm2_pcrreset(1) - إعادة تعيين قيمة PCR في جميع البنوك للمؤشر المحدد. يمكن تحديد أكثر من مؤشر PCR واحد.

قيمة إعادة التعيين تعتمد على الشركة المصنعة وهي إما سلسلة من 00 أو FF بطول خوارزمية التجزئة لكل بنك مدعوم.

مؤشر_PCR هي قائمة مفصولة بمسافات لمؤشرات PCR التي سيتم إعادة تعيينها عند إصدار الأمر.

الخيارات

لا يقبل هذا الأداة أي خيارات خاصة بالأداة.

•
--cphash=ملف

مسار الملف لتسجيل تجزئة معلمات الأمر. وهذا ما يطلق عليه عادةً cpHash. ملاحظة: عند تحديد هذا الخيار، لن يقوم الأداة بتنفيذ الأمر فعليًا، بل سيعيد فقط cpHash.

خيارات شائعة

هذه المجموعة من الخيارات مشتركة بين العديد من البرامج وتوفر معلومات قد يتوقعها العديد من المستخدمين.

•
-h, --help=[man|no-man]: عرض دليل الأداة. افتراضيًا، يحاول استدعاء مدير الأدلة للأداة، ولكن عند الفشل، سيقوم بإخراج ملخص قصير للأداة. هذا هو نفس السلوك إذا تم تحديد الوسيطة "man" للخيار، ومع ذلك، إذا تم طلب "man" صراحةً، فستقدم الأداة أخطاء من man على stderr. إذا تم تحديد الخيار "no-man"، أو فشل مدير الأدلة، فسيتم إخراج الخيارات القصيرة إلى stdout.

للاستخدام الناجح لميزة الأدلة، يلزم تثبيت الأدلة أو وجودها في MANPATH، انظر man(1) لمزيد من التفاصيل.

•
-v, --version: عرض معلومات الإصدار لهذه الأداة، tctis المدعومة والخروج.
•
-V, --verbose: زيادة المعلومات التي تطبعها الأداة إلى وحدة التحكم أثناء تنفيذها. عند استخدام هذا الخيار، يتم طباعة رقم الملف والسطر.
•
-Q, --quiet: كتم الإخراج العادي للأداة إلى stdout.
•
-Z, --enable-errata: تمكين تطبيق إصلاحات الأخطاء. مفيد إذا كانت هناك حاجة لتطبيق إصلاح أخطاء على الأوامر المرسلة إلى TPM. تعريف متغير البيئة TPM2TOOLS_ENABLE_ERRATA يعادل هذا.
•
-R, --autoflush: تمكين التفريغ التلقائي للكائنات المؤقتة التي أنشأتها الأداة. إذا تم تحميل كائن أب من ملف سياق، فسيتم أيضًا تفريغ الكائن الأب المؤقت. يمكن أيضًا تنشيط التفريغ التلقائي إذا تم تعيين متغير البيئة TPM2TOOLS_AUTOFLUSH على yes أو true.

تكوين TCTI

TCTI أو "واجهة الإرسال" هي آلية الاتصال بـ TPM. يمكن تغيير TCTIs للاتصال بـ TPMs عبر وسائط مختلفة.

للتحكم في TCTI، تحترم الأدوات:

1.
خيار سطر الأوامر -T أو --tcti
2.
متغير البيئة: TPM2TOOLS_TCTI.

ملاحظة: يتجاوز خيار سطر الأوامر دائمًا متغير البيئة.

TCTIs المعروفة حاليًا هي:

•
tabrmd - مدير الموارد، يسمى tabrmd. لاحظ أن tabrmd و abrmd كاسم tcti مترادفان.
•
mssim - يستخدم عادةً للاتصال بمحاكي برنامج TPM.
•
device - يستخدم عند التحدث مباشرة إلى ملف جهاز TPM.
•
none - لا تقم بتهيئة اتصال مع TPM. تسمح بعض الأدوات بخيارات خارج TPM وبالتالي تدعم عدم استخدام TCTI. الأدوات التي لا تدعمها ستظهر خطأ عند محاولة استخدامها بدون اتصال TCTI. لا تدعم أي خيارات ويجب تقديمها كنص "none" بالضبط.

تكون الوسائط إما لخيار سطر الأوامر أو لمتغير البيئة بالشكل:

<اسم_tcti>:<تكوين_خيارات_tcti>

تحديد سلسلة فارغة إما لـ <اسم_tcti> أو <تكوين_خيارات_tcti> ينتج عنه استخدام الافتراضي لتلك الجزء على التوالي.

افتراضيات TCTI

عند عدم تحديد TCTI، يتم البحث عن TCTI الافتراضي باستخدام دلالات dlopen(3). ستبحث الأدوات عن TCTIs tabrmd و device و mssim بهذا الترتيب وتستخدم أول واحدة يتم العثور عليها. يمكنك الاستعلام عن TCTI الذي سيتم اختياره كافتراضي باستخدام الخيار -v لطباعة معلومات الإصدار. سيشير زوج المفتاح والقيمة "default-tcti" إلى أي من TCTIs المذكورة أعلاه هو الافتراضي.

TCTIs مخصصة

يمكن تحميل أي TCTI ينفذ واجهة TCTI الديناميكية. تستخدم الأدوات داخليًا dlopen(3)، ويتم استخدام قيمة اسم_tcti الخام للبحث. وبالتالي، يمكن أن يكون هذا مسارًا إلى المكتبة المشتركة، أو اسم مكتبة كما هو مفهوم بواسطة دلالات dlopen(3).

خيارات TCTI

تستخدم هذه المجموعة من الخيارات لتكوين وحدات TCTI المعروفة المختلفة المتاحة:

•
device: بالنسبة لـ TCTI الجهاز، يمكن تحديد ملف جهاز TPM لاستخدامه بواسطة TCTI الجهاز. الافتراضي هو /dev/tpm0.

مثال: -T device:/dev/tpm0 أو export TPM2TOOLS_TCTI=“device:/dev/tpm0”

•
mssim: بالنسبة لـ TCTI mssim، يمكن تحديد اسم النطاق أو عنوان IP ورقم المنفذ المستخدمين بواسطة المحاكي. الافتراضي هو 127.0.0.1 و 2321.

مثال: -T mssim:host=localhost,port=2321 أو export TPM2TOOLS_TCTI=“mssim:host=localhost,port=2321”

•
abrmd: بالنسبة لـ TCTI abrmd، يكون تنسيق سلسلة التكوين عبارة عن سلسلة من أزواج المفتاح والقيمة البسيطة مفصولة بحرف ",". يتم فصل كل مفتاح وسلسلة قيمة بحرف "=".
•
يدعم TCTI abrmd مفتاحين:
1.
`bus_name' : اسم خدمة tabrmd على ناقل الاتصال (سلسلة نصية).
2.
`bus_type' : نوع مثيل dbus (سلسلة نصية) مقيد بـ `session' و `system'.

تحديد اسم tcti tabrmd وسلسلة تكوين من bus_name=com.example.FooBar:

\--tcti=tabrmd:bus_name=com.example.FooBar

تحديد tcti الافتراضي (abrmd) وسلسلة تكوين من bus_type=session:

\--tcti:bus_type=session

ملاحظة: abrmd و tabrmd مترادفان.

tpm2_pcrreset 23

إعادة تعيين PCRs متعددة

NAME

tpm2_pcrreset - Reset one or more PCRs

SYNOPSIS

tpm2_pcrreset [OPTIONS] [TPM_SERVER_OPTIONS] [TCTI_OPTIONS] <pcrs>...

DESCRIPTION

The tpm2_pcrreset command resets the specified PCRs to zero. This functionality is only available if the TPM is in the FIPS compliant mode.

The tool will iterate through the list of PCRs specified, and attempt to reset each one.

PCRs that are not resettable will be skipped.

OPTIONS

The tpm2_pcrreset command accepts the following options:

-p, --pcr-list
This option takes a comma-separated list of PCR indexes to reset. The indexes can be represented in decimal or hexadecimal (prefixed with 0x).
-a, --all
Resets all PCRs.
-f, --force
Force the reset of the PCRs. Without this option, the command will check if the PCRs are resettable and prompt for confirmation. This option bypasses the confirmation prompt.

COMMON OPTIONS

These options are common to most of the tpm2 tools.

-h, --help
Help information.
-v, --version
Return tool version and exit.
-c, --cancel
Cancel an ongoing operation.
-t, --tcti
TCTI configuration string.
--tcti-list
List available TCTIs.

TCTI Configuration

The TPM Communication Transport Interface (TCTI) is responsible for the communication with the TPM device. The default TCTI is the `device` TCTI which communicates with the TPM device node (e.g., `/dev/tpm0`). Other TCTIs are available, such as `mssim` for communication with the simulator, `socket` for communication over a network socket, etc.

The TCTI can be configured using the -t or --tcti option followed by a configuration string. The format of the configuration string depends on the TCTI being used.

For the `device` TCTI, the configuration string can be used to specify the device node:

--tcti device:/dev/tpmrm0

For the `socket` TCTI, the configuration string specifies the host and port:

--tcti socket:host=127.0.0.1,port=2321

The --tcti-list option can be used to display a list of available TCTIs and their respective configurations.

TCTI OPTIONS

These options are specific to certain TCTIs and may not be available for all TCTIs.

-z, --zlog
Enable zlog logging for the TCTI.

EXAMPLES

Reset PCR 0:

tpm2_pcrreset -p 0

Reset PCRs 10 and 11:

tpm2_pcrreset -p 10,11

Reset all PCRs:

tpm2_pcrreset -a

Force reset of PCR 5 without confirmation:

tpm2_pcrreset -f -p 5

NOTES

PCRs 0 to 15 are part of the SRTM (Static Read-Only Memory Technology) and are generally not resettable. PCRs 16 to 22 are typically reserved for DRTM (Dynamic Root of Trust Measurement) or specific localities and their resettability might depend on the current TPM locality. The behavior can vary depending on TPM manufacturers which could define this PCR as resettable.

PCR 0 to 15 are not resettable (being part of SRTM). PCR 16 to 22 are mostly reserved for DRTM or dedicated to specific localities and might not be resettable depending on current TPM locality.

Returns

Tools can return any of the following codes:

•
0 - Success.
•
1 - General non-specific error.
•
2 - Options handling error.
•
3 - Authentication error.
•
4 - TCTI related error.
•
5 - Non supported scheme. Applicable to tpm2_testparams.
