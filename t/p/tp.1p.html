tp(1p)

الحزمة: perl-io-pager

التراخيص: GPL, PerlArtistic

TP(1p) مساهمات Perl المستخدم الموثقة TP(1p)

الاسم

tp - عارض بسيط بلغة Perl

ملخص

tp -[JSenrs] [-cols] [-f STR] [-j|+ #] [-p|+/ STR] [FILE]...

خيارات

-e
الخروج عند نهاية الملف.
-f STR
إذا تم تحديده، سيتوقف العارض عند مواجهة تسلسل الأحرف المحدد بواسطة STR في نص الإدخال.

القيمة الافتراضية عند التفعيل هي حرف التغذية (formfeed) أي؛ ^L؛ لمحاكاة السلوك التقليدي لـ "1" في more، ولكن نظرًا لخصوصيات Getopt::Long>، تحتاج إلى استخدام فاصل الوسيط -- لتشغيل هذا، على سبيل المثال:

tp -f -- foo # يتوقف عند الأسطر في foo التي تحتوي على "^L"

قد تقوم أيضًا بتوفير تعبير عادي كـ STR، على سبيل المثال:

tp -f '[ie]t' bar # يتوقف عند الأسطر في bar التي تحتوي على "it" أو "et"
-J
أضف عمودًا بعلامات تشير إلى الأسطر التي تطابق تعبير البحث.
-n
عرض ترقيم الأسطر. يمكن تبديله أثناء التشغيل باستخدام #.
-r
إرسال أحرف التحكم الخام من الإدخال دون تغيير إلى الطرفية. افتراضيًا، سيتم تحويل الأحرف بخلاف علامة الجدولة والسطر الجديد إلى ترميز caret، على سبيل المثال: ^@ للصفر أو ^L لحرف التغذية.
-s
ضغط الأسطر الفارغة المتعددة إلى سطر واحد.
-S
لا تقم بطي الأسطر الطويلة.
-[ أو --scrollbar
عرض شريط تمرير تفاعلي في أقصى العمود الأيمن.
-$ أو --tail
استمر في التحقق من الملف المعروض بحثًا عن محتوى جديد. متاح فقط عند عرض ملف واحد.
--cols
تعيين عدد الأعمدة للعرض.

إذا كان غائبًا، يتم الاستعلام عن الطرفية مباشرة باستخدام Term::ReadKey إذا تم تحميله أو "stty" أو "tput"، وإذا فشلت هذه، فإنها تعود إلى 80.

واجهة المستخدم

"C-" هي Control، "M-" هي Meta/Alt، "S-" هي Shift، و "\d+" هي سلسلة من الأرقام

عام

مساعدة - "h" أو "H"
إغلاق - "q" أو "Q" أو ":q" أو ":Q"
تحديث - "r" أو "C-l" أو "C-R"
مسح المخزن المؤقت - "R"
حفظ المخزن المؤقت - ":w"
فتح ملف - ":e"

تنقل

لأسفل سطر واحد - "ENTER" أو "e" أو "j" أو "J" أو "C-e" أو "C-n" أو "سهم لأسفل"
لأسفل نصف صفحة - "d" أو "C-d"
لأسفل صفحة واحدة - "SPACE" "f" أو "z" أو "C-f" أو "C-v" أو "M-space" أو "PgDn"
لأعلى صفحة واحدة - "b" أو "w" أو "C-b" أو "M-v" أو "PgUp"
لأعلى نصف صفحة - "u" أو "C-u"
لأعلى سطر واحد - "k" أو "y" أو "K" أو "Y" أو "C-K" أو "C-P" أو "C-Y" أو "سهم لأعلى"
إلى الأسفل - "G" أو "$" أو ">" أو "M->>" أو "End"
إلى الأعلى - "g" أو "<" أو "M-<"
يسار علامة جدولة واحدة - "سهم أيسر"
يسار نصف شاشة - "S-سهم أيسر"
يمين علامة جدولة واحدة - "سهم أيمن"
يمين نصف شاشة - "S-سهم أيمن"
الانتقال إلى رقم السطر - "\d+"
الملف التالي - ":n" أو "S-M-سهم أيمن"
الملف السابق - ":p" أو "S-M-سهم أيسر"

علامات مرجعية

حفظ علامة - "m" أو "Ins"
الانتقال إلى علامة - "'"
علامة خاصة: بداية الملف - "^"
علامة خاصة: نهاية الملف - "$"
علامة خاصة: الموقع السابق - "'"
علامة خاصة: عرض قائمة العلامات التي أنشأها المستخدم - """"
علامة خاصة: "\d" - أعلى الملف \d عند عرض ملفات متعددة

بحث

إلى الأمام - /
إلى الخلف - ?
المطابقة التالية - n أو P
المطابقة السابقة - p أو N
grep (عرض الأسطر المطابقة فقط) - &

خيارات

تبديل ترقيم الأسطر - #
تبديل الطي - S
تبديل الإخراج الخام/المعالج - C

بيئة

يفحص tp متغيرات LESS و MORE و TPOPT و TERM و TERMCAP.

يتم استخدام المتغير TPOPT لتعيين خيارات صراحة لـ tp، عن طريق دمج الخيارات غير المزخرفة معًا، على سبيل المثال: Sr للإخراج المضغوط الخام.

يتم فحص LESS و MORE بحثًا عن خيارات يدعمها tp، وإذا تم اكتشافها، يتم تمكينها.
