Name

DTQPQRT2, STPQR2, STPQR2, ZTPQRT2 — Computes a QR factorization of a general matrix, which is composed of a triangular block and a pentagonal block, using the compact WY representation for Q.

Description

The subroutines DTQPQRT2, STPQRT2, STPQRT2, and ZTPQRT2 compute a QR factorization for a matrix C that is composed of a triangular block A and a pentagonal block B. The factorization is computed using block reflectors such that the WY representation of the orthogonal matrix Q is maintained. This is particularly useful for updating QR factorizations.

The matrix C is conceptually structured as:

      C = [ A ]
          [ B ]

where A is an N-by-N upper triangular matrix, and B is an M-by-N pentagonal matrix. The pentagonal matrix B is further decomposed into:

      B = [ B1 ]  (M-L)-by-N rectangular
          [ B2 ]  L-by-N upper trapezoidal

Here, B2 consists of the first L rows of an N-by-N upper triangular matrix. The parameter L satisfies 0 <= L <= MIN(M, N).

The subroutines compute the QR factorization of C, such that C = Q * R, where Q is an orthogonal matrix and R is an upper triangular-band matrix. The orthogonal matrix Q is represented in the compact WY format:

      Q = I - W * T * W^T

where W is a matrix constructed from the elementary reflectors, and T is an upper triangular matrix.

Specifically, the subroutine computes the factorization:

      [ A ] = [ R ]
      [ B ] = [ 0 ]

and the matrix W is implicitly stored in the input matrix B. On exit, the array B will contain the pentagonal matrix V, which forms part of W:

      W = [ I ]
          [ V ]

The upper triangular matrix R is stored in the upper triangular part of array A, and the upper triangular factor T is stored in the array T.

The following mapping between the subroutine names and their data types is used:

      DTQPQRT2: DOUBLE PRECISION (real*8)
      STPQRT2:  REAL (real*4)
      ZTPQRT2:  COMPLEX*16 (complex*16)

Note: The Fortran standard uses REAL for single-precision floating-point numbers and DOUBLE PRECISION for double-precision. COMPLEX*16 is typically used for double-precision complex numbers. The documentation uses generic terms like "real" and "complex" where appropriate.

!>
!>              H = I - W * T * W**T  (for real)

!>
!> where W^H is the conjugate transpose of W and T is the upper triangular
!> factor of the block reflector.
!>
