TPMLIB_ChooseTPMVersion(3)

الحزمة: libtpms

التراخيص: BSD-3-Clause

TPMLIB_ChooseTPMVersion(3) TPMLIB_ChooseTPMVersion(3)

الاسم

TPMLIB_ChooseTPMVersion - اختيار إصدار TPM

الملخص

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_library.h>

TPM_RESULT TPMLIB_ChooseTPMVersion(TPMLIB_TPMVersion ver);

typedef enum TPMLIB_TPMVersion {
   TPMLIB_TPM_VERSION_1_2,
   TPMLIB_TPM_VERSION_2,
} TPMLIB_TPMVersion;

الوصف

تُستخدم الدالة TPMLIB_ChooseTPMVersion() لاختيار إصدار TPM، سواء كان TPM 1.2 أو TPM 2.

يجب استدعاء هذه الدالة قبل استدعاء TPMLIB_MainInit() وإلا فإنها ستُرجع خطأ. يمكن استدعاء هذه الدالة مرة أخرى بمجرد استدعاء TPMLIB_Terminate().

إذا لم يتم استدعاء هذه الدالة، فسيتم بدء تشغيل إصدار TPM الأخير الذي تم اختياره باستخدام TPMLIB_MainInit(). إذا لم يتم استدعاء هذه الدالة، فسيتم استخدام TPM 1.2.

الأخطاء

TPM_SUCCESS
تم اختيار إصدار TPM بنجاح.
TPM_FAIL
كان اختيار TPM خاطئًا، أو تم استدعاء TPMLIB_MainInit() بالفعل.

للحصول على قائمة كاملة برموز خطأ TPM، يرجى الرجوع إلى ملف التضمين libtpms/tpm_error.h
