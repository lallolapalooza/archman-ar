tpm2_create(1)

الحزمة: tpm2-tools

التراخيص: BSD-3-Clause

NAME

tpm2_create

create a primary key or an object

SYNOPSIS

tpm2_create [OPTIONS] [-u file] [-r file] [-c file]

DESCRIPTION

The tpm2_create command is used to create primary keys or objects. The objects are created from a primary key specified by the -C option. The created object can be a primary key or a standard TPM object, like a signing key, a key for encryption, etc. The created object is represented by its public and private portions, which are saved to files specified by the -u and -r options.

If the TPM does not support the creation of an object and its associated context from a single command, one can use tpm2_load(1) after the object has been created.

OPTIONS

See tpm2_options(1) for common options.

-C context
specifies the context object of the parent key for the object to be created. This is a file path to a .ctx file.
-G [alg][:][prot:]keylen
specifies the algorithm for the key to be created. The following algorithms are supported:
  • rsa: 1024, 2048, 3072, 4096
  • ecc: 256, 384, 521
  • hmac: 128, 192, 256, 384, 512
  • sym: 128, 192, 256 (symmetric keys)

The argument can also include the signing or sealing scheme. For example:

rsa2048:rsapss:null
RSA key with 2048 bits, using the RSAPSS scheme and no symmetric encryption.
ecc256:ecdsa:aes
ECC key with 256 bits, using the ECDSA scheme and AES symmetric encryption.

The algorithm specifiers are described in more detail in the Algorithm Specifiers section.

-a attributes
specifies the attributes for the object to be created. The attributes are a comma separated list of keywords. Available attributes include:
  • fixedparent
  • fixedtpm
  • sensitivedataorigin
  • userwithauth
  • adminwithpolicy
  • userwithpolicy
  • admin lockout
  • restricted
  • decrypt
  • signing
  • shelved
  • permanent
  • protected
