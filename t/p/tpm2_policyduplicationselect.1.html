tpm2_policyduplicationselect(1)

الحزمة: tpm2-tools

التراخيص: BSD-3-Clause

NAME

tpm2_policyduplicationselect — selects the duplication role policy

SYNOPSIS

tpm2_policyduplicationselect [OPTIONS...]

DESCRIPTION

The tpm2_policyduplicationselect command is used to specify the duplication role policy for a session. This policy allows an object to be duplicated under specific conditions related to the destination parent. The command sets up a policy that must be met before an object can be duplicated.

OPTIONS

The tpm2_policyduplicationselect command supports the following options:

•
-S session, --session=session
The authorization session to use. This is typically created using tpm2_startauthsession(1).
•
-N name, --name=name
The name of the destination parent. This is the public name of the TPM object that will be the parent of the duplicated object.
•
-L policy_file, --policy-file=policy_file
The file to write the policy digest to. This file can then be used when creating or duplicating objects that require this policy.
•
-n object_name, --object-name=object_name
The name of the object to be duplicated. This is used when satisfying the policy during the duplication process.
•
-Q, --quiet
Suppress output to stdout.
•
-h, --help
Print a help message and exit.
•
-v, --version
Print version information and exit.

COMMON OPTIONS

These options are common to most tpm2_tools commands and are used to configure the connection to the TPM.

•
-T TCTI, --tcti=TCTI
TPM Transmission Interface (TCTI). This option specifies how to connect to the TPM. For more details, see tpm2_tools(7).

TCTI Configuration

The TCTI can be configured using environment variables. For more details, see tpm2_tools(7).

TCTI OPTIONS

Options specific to the selected TCTI can be provided using the -T option. For example, to use the `mssim` TCTI, you might use -T mssim.

EXAMPLES

The following example demonstrates the typical workflow for setting up and using a duplication role policy:

Setup a duplication role policy to restricted new parent

Create source parent and destination(or new) parent

tpm2_createprimary -C n -g sha256 -G rsa -c dst_n.ctx -Q
tpm2_createprimary -C o -g sha256 -G rsa -c src_o.ctx -Q

Create the restricted parent policy

tpm2_readpublic -c dst_n.ctx -n dst_n.name -Q
tpm2_startauthsession -S session.ctx
tpm2_policyduplicationselect -S session.ctx  -N dst_n.name \
-L policydupselect.dat -Q
tpm2_flushcontext session.ctx
rm session.ctx

Create the object to be duplicated using the policy

tpm2_create -C src_o.ctx -g sha256 -G rsa -r dupkey.priv -u dupkey.pub \
-L policydupselect.dat  -a "sensitivedataorigin|sign|decrypt" -c dupkey.ctx -Q
tpm2_readpublic -c dupkey.ctx -n dupkey.name -Q

Satisfy the policy and duplicate the object

tpm2_startauthsession -S session.ctx --policy-session
tpm2_policyduplicationselect -S session.ctx  -N dst_n.name -n dupkey.name -Q
tpm2_duplicate -C dst_n.ctx -c dupkey.ctx -G null -p session:session.ctx \
-r new_dupkey.priv -s dupseed.dat
tpm2_flushcontext  session.ctx
rm session.ctx

NOTES

•
This command usually cooperates with tpm2_duplicate(1), so referring to the man page of tpm2_duplicate(1) is recommended.
•
This command will set the policy session’s command code to TPM_CC_Duplicate which enables duplication role of the policy.

Returns

Tools can return any of the following codes:

•
0 - Success.
•
1 - General non-specific error.
•
2 - Options handling error.
•
3 - Authentication error.
•
4 - TCTI related error.
•
5 - Non supported scheme. Applicable to tpm2_testparams.

Limitations

It expects a session to be already established via tpm2_startauthsession(1) and requires one of the following:

•
direct device access
•
extended session support with tpm2-abrmd.

Without it, most resource managers will not save session state between command invocations.
