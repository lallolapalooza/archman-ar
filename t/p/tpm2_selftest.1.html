NAME

tpm2_selftest — run TPM self-tests

SYNOPSIS

tpm2_selftest [OPTIONS] [TPM_TEST_SELECTOR]

DESCRIPTION

Runs the self-test routines on the TPM. The TPM self-test is a set of checks that the TPM can perform on itself. The results of the self-test are returned by the TPM. The tpm2_selftest utility allows you to run these self-tests and view the results.

The self-test can be run on the entire TPM, or on specific components. The TPM_TEST_SELECTOR argument can be used to specify which components to test. If no TPM_TEST_SELECTOR is specified, the entire TPM is tested.

OPTIONS

The following options are available:

-f, --force
Force the execution of the self-test, even if the TPM is already in a state where self-tests are not normally run.
-h, --help
Display the help message and exit.
-V, --version
Display version information and exit.

COMMON OPTIONS

These options are common to all tpm2-tools and do not need to be specified per-command.

-c, --cancel[=SESSION]
Cancel a previously started command. The SESSION is the handle of the session to cancel.
-e, --enable-tcti=TCTI
Enable a specific TCTI. For example: mssim, device, socket.
-l, --list-tcti
List the available TCTIs.
-p, --port=PORT
Specify the port for the socket TCTI.
-S, --socket=HOST:PORT
Connect to a TPM simulator via socket.
-t, --tcti-context=CONTEXT
Set the TCTI context.
-T, --tpm-device=DEVICE
Specify the TPM device to use. Defaults to /dev/tpm0.
-X, --hex
Print output in hexadecimal format.

TCTI Configuration

The TPM communication can be configured using a TCTI (TPM Command Transmission Interface). The default TCTI is usually the device TCTI, which communicates with the TPM device node (e.g. /dev/tpm0).

Other TCTIs can be enabled using the -e or --enable-tcti option. For example, to use the mssim simulator, you would use -e mssim.

The -S or --socket option can be used to connect to a TPM simulator listening on a specific host and port.

The -t or --tcti-context option can be used to specify a TCTI context string, which can be used to configure complex TCTI setups.

TCTI OPTIONS

The following options are used to configure the TCTI:

-d, --device=DEVICE
Specify the TPM device to use. Defaults to /dev/tpm0.
-n, --no-tcti-option
Disable TCTI options.
-p, --port=PORT
Specify the port for the socket TCTI.
-S, --socket=HOST:PORT
Connect to a TPM simulator via socket.
-t, --tcti-context=CONTEXT
Set the TCTI context.

EXAMPLES

Run the TPM self-test:
$ tpm2_selftest

Run the TPM self-test on the CPU component:
$ tpm2_selftest CPU

Run the TPM self-test on the Network component:
$ tpm2_selftest NETWORK

Run the TPM self-test, forcing the execution:
$ m2_selftest -f

Returns

Tools can return any of the following codes:

•
0 - Success.
•
1 - General non-specific error.
•
2 - Options handling error.
•
3 - Authentication error.
•
4 - TCTI related error.
•
5 - Non supported scheme. Applicable to tpm2_testparams.
