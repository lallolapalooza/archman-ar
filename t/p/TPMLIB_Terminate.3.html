TPMLIB_Terminate(3)

الحزمة: libtpms

التراخيص: BSD-3-Clause

TPMLIB_MainInit(3) TPMLIB_MainInit(3)

الاسم

TPMLIB_MainInit - تهيئة TPM

TPMLIB_Terminate - إنهاء TPM

المكتبة

مكتبة TPM (libtpms, -ltpms)

الملخص

#include <libtpms/tpm_types.h>

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_MainInit(void);

TPM_RESULT TPMLIB_Terminate(void);

الوصف

تُستخدم الدالتان TPMLIB_MainInit() و TPMLIB_Terminate() لتهيئة وإنهاء TPM على التوالي. يجب استدعاء الدالة TPMLIB_MainInit() قبل أن تعالج TPM أي أمر TPM. يتم استدعاء الدالة TPMLIB_Terminate() لتحرير جميع الموارد الداخلية (تخصيصات الذاكرة) التي استخدمتها TPM ويجب استدعاؤها بعد معالجة آخر أمر TPM بواسطة TPM. بعد ذلك، يمكن استدعاء الدالة TPMLIB_MainInit() مرة أخرى.

استخدم TPMLIB_RegisterCallbacks() لتعيين دوال رد الاتصال لتهيئة وكتابة واستعادة الحالة الداخلية بتنسيق محمول.

الأخطاء

TPM_SUCCESS
اكتملت الدالة بنجاح.
TPM_FAIL
فشل عام.

للحصول على قائمة كاملة برموز أخطاء TPM، يرجى الرجوع إلى ملف التضمين libtpms/tpm_error.h

مثال

#include <stdio.h>
#include <libtpms/tpm_types.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
int main(void) {
    TPM_RESULT res;
    unsigned char *respbuffer = NULL;
    uint32_t resp_size = 0;
    uint32_t respbufsize = 0;
    unsigned char *command;
    uint32_t command_size;
    [...]
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
        fprintf(stderr, "Could not start the TPM.\n");
        return 1;
    }
    [...]
    /* build TPM command */
    [...]
    res = TPMLIB_Process(&respbuffer, &resp_size,
                         &respbufsize,
                         command, command_size);
    [...]
    TPMLIB_Terminate();
    return 0;
}
