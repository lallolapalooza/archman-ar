TPMLIB_GetInfo(3)

الحزمة: libtpms

التراخيص: BSD-3-Clause

TPMLIB_GetInfo(3) TPMLIB_GetInfo(3)

الاسم

TPMLIB_GetInfo - الحصول على معلومات حول تطبيق TPM

المكتبة

مكتبة TPM (libtpms، -ltpms)

الملخص

#include <libtpms/tpm_library.h>

char *TPMLIB_GetInfo(TPMLIB_InfoFlags flags);

الوصف

تسمح الدالة TPMLIB_GetInfo() بالاستعلام عن خصوصيات تطبيق TPM والحصول على سلسلة JSON كإرجاع. يمكن تحديد البيانات التي سيتم إرجاعها في المعامل flags الذي قد يكون عبارة عن 'or' منطقي للعلامات. إذا لم يتم دعم العلامات المارة، فلا يتم إرجاع شيء. إذا تم تمرير 0، يتم إرجاع كائن JSON فارغ '{}'.

تم تعريف العلامات التالية وترجع كائنات JSON كما يلي:

TPMLIB_INFO_TPMSPECIFICATION
{"TPMSpecification":{"family":"1.2","level":2,"revision":116}}
TPMLIB_INFO_TPMATTRIBUTES
{"TPMAttributes":{"manufacturer":"id:00001014","version":"id:00740001","model":"swtpm"}}
TPMLIB_INFO_TPMFEATURES (منذ v0.8.0)
{"TPMFeatures":{"RSAKeySizes":[1024,2048,3072]}}

قد يتم توسيع كائن JSON هذا في المستقبل.

TPMLIB_INFO_RUNTIME_ALGORITHMS (منذ v0.10.0)

  "RuntimeAlgorithms": {
    "Implemented": "rsa,rsa-min-size=1024,tdes,tdes-min-size=128,sha1,hmac," \

يقوم كائن JSON هذا بسرد جميع الخوارزميات *المطبقة* بالإضافة إلى منحنيات التشفير الإهليلجية (ECC) المدعومة. تشير هذه الأفعال المدرجة ضمن CanBeDisabled إلى الخوارزميات ومنحنيات ECC التي قد يتجاهلها المستخدم من ملف تعريف، مما يجعلها غير متاحة للتطبيقات. تشير الأفعال المدرجة ضمن Enabled و Disabled إلى الخوارزميات التي تم تمكينها وتعطيلها في ملف التعريف النشط حاليًا.

تعد الأفعال ecc-nist و ecc-bn اختصارات لتمكين جميع منحنيات NIST ECC المطبقة حاليًا (ecc-nist-p192، ecc-nist-p256، ...) ومنحنيات BN (Baretto-Naehrig) (ecc-bn-p256، ecc-bn-p638). إذا تم تجاهلها، فلا يزال من الممكن سرد المنحنيات الفردية لتمكينها. نظرًا لأنه لا يمكن تعطيل ecc-nist-p256 و ecc-nist-p384، فيجب سردها إذا لم يتم استخدام الاختصار ecc-nist.

يتم أيضًا وصف أحجام المفاتيح الدنيا لـ rsa، ecc، tdes، aes، و camellia.

عند إضافة خوارزميات ومنحنيات ECC جديدة إلى TPM في المستقبل، فسيرجع كائن JSON هذا خوارزميات أكثر.

يسرد كائن JSON هذا جميع الأوامر *المطبقة* بأرقامها السداسية عشرية ويعرض أي منها يمكن تعطيله، وأيها ممكّن حاليًا، وأيها معطل.

TPMLIB_INFO_ACTIVE_PROFILE (منذ v0.10.0)
يعرض كائن JSON هذا ملف التعريف النشط حاليًا. 
{
  "ActiveProfile": {
    "Name": "null",
    "StateFormatLevel": 1,
    "Commands": "0x11f-0x122,0x124-0x12e,0x130-0x140,0x142-0x159," \

                "0x17a-0x193,0x197",
    "Algorithms": "rsa,rsa-min-size=1024,tdes,tdes-min-size=128,sha1,hmac," \
                  "aes,aes-min-size=128,mgf1,keyedhash,xor,sha256,sha384," \
                  "sha512,null,rsassa,rsaes,rsapss,oaep,ecdsa,ecdh,ecdaa," \
                  "sm2,ecschnorr,ecmqv,kdf1-sp800-56a,kdf2,kdf1-sp800-108," \
                  "ecc,ecc-min-size=192,ecc-nist,ecc-bn,symcipher,camellia," \
                  "camellia-min-size=128,cmac,ctr,ofb,cbc,cfb,ecb",
    "Description": "The profile enables the commands and algorithms that " \
                   "were enabled in libtpms v0.9. This profile is " \
                   "automatically used when the state does not have a " \
                   "profile, for example when it was created by " \
                   "libtpms v0.9 or before."
  }
}

ملف التعريف أعلاه هو ملف التعريف 'null'. إذا تم استخدام ملف التعريف null، فستكون الحالة قابلة للقراءة مرة أخرى بواسطة libtpms v0.9.

قيمة الإرجاع

تُرجع هذه الدالة سلسلة JSON عند النجاح ومؤشر NULL في حالة حدوث فشل في تخصيص الذاكرة.
