التفاصيل الإضافية:

!>
!> المصفوفة المدخلة C هي مصفوفة (N+M)-by-N
!>
!>               C = [ A ]
!>                   [ B ]
!>
!> حيث A هي مصفوفة مثلثة علوية N-by-N، و B هي مصفوفة خماسية M-by-N
!> تتكون من مصفوفة مستطيلة B1 ذات الأبعاد (M-L)-by-N في الأعلى ومصفوفة
!> شبه منحرفة علوية L-by-N تسمى B2:
!>
!>               B = [ B1 ]  <- مستطيلة (M-L)-by-N
!>                   [ B2 ]  <- شبه منحرفة علوية L-by-N.
!>
!> تتكون المصفوفة شبه المنحرفة العلوية B2 من الصفوف L الأولى لمصفوفة
!> مثلثة علوية N-by-N، حيث 0 <= L <= MIN(M,N). إذا كان L=0،
!> تكون B مستطيلة M-by-N؛ إذا كان M=L=N، تكون B مثلثة علوية.
!>
!> تخزن المصفوفة W المستشعرات الأولية H(i) في العمود i
!> تحت القطر (لـ A) في المصفوفة المدخلة C ذات الأبعاد (N+M)-by-N
!>
!>               C = [ A ]  <- مثلثة علوية N-by-N
!>                   [ B ]  <- خماسية M-by-N
!>
!> بحيث يمكن تمثيل W كـ
!>
!>               W = [ I ]  <- الهوية، N-by-N
!>                   [ V ]  <- M-by-N، بنفس شكل B.
!>
!> وبالتالي، تقع جميع المعلومات اللازمة لـ W عند الخروج في B،
!> والتي نسميها V أعلاه. لاحظ أن V لها نفس شكل B؛ أي،
!>
!>               V = [ V1 ] <- مستطيلة (M-L)-by-N
!>                   [ V2 ] <- شبه منحرفة علوية L-by-N.
!>
!> تمثل أعمدة V المتجهات التي تحدد H(i).
!>
!> عدد الكتل هو B = سقف(N/NB)، حيث كل
!> كتلة من الرتبة NB باستثناء الكتلة الأخيرة، التي تكون من الرتبة
!> IB = N - (B-1)*NB. لكل كتلة من الكتل B، يتم حساب عامل
!> مستشعر كتلة مثلثية علوية: T1، T2، ...، TB. يتم تخزين T
!> ذات الأبعاد NB-by-NB (و IB-by-IB للكتلة الأخيرة) في المصفوفة
!> المثلثية العلوية T ذات الأبعاد NB-by-N كـ
!>
!>               T = [T1 T2 ... TB].
!>
