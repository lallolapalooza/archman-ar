TPMLIB_Process(3)

الحزمة: libtpms

التراخيص: BSD-3-Clause

TPMLIB_Process(3) TPMLIB_Process(3)

الاسم

TPMLIB_Process - معالجة أمر TPM

المكتبة

مكتبة TPM (libtpms, -ltpms)

الملخص

#include <libtpms/tpm_library.h>

#include <libtpms/tpm_error.h>

TPM_RESULT TPMLIB_Process(unsigned char **respbuffer,
uint32_t *resp_size,
uint32_t *respbufsize,
unsigned char *command,
uint32_t command_size);

الوصف

تُستخدم الدالة TPMLIB_Process() لإرسال أوامر TPM إلى TPM واستقبال النتائج.

يوفر المعامل command المخزن المؤقت لأمر TPM والمعامل command_size عدد البايتات الصالحة لأمر TPM داخل هذا المخزن المؤقت.

respbuffer هو مؤشر إلى مخزن مؤقت سيُرجع فيه TPM نتيجته. إذا لم يتم توفير مخزن مؤقت (respbuffer هو NULL)، فسيقوم TPM بتخصيص مخزن مؤقت. يُرجع المعامل resp_size عدد البايتات الصالحة للاستجابة من TPM في المخزن المؤقت. يُضمن أن عدد البايتات الصالحة في الاستجابة لن يتجاوز الحد الأقصى لحجم مخزن الإدخال/الإخراج. استخدم واجهة برمجة التطبيقات TPMLIB_GetTPMProperty() والمعامل TPMPROP_TPM_BUFFER_MAX للحصول على الحد الأقصى للحجم. يجب على المستخدم الإشارة إلى حجم المخزن المؤقت المقدم باستخدام المعامل respbufsize. إذا لم يكن المخزن المؤقت كبيرًا بما يكفي للاستجابة، فسيقوم TPM بتحرير المخزن المؤقت المقدم وتخصيص واحد بحجم كافٍ وتكييف respbufsize. يخضع المخزن المؤقت المُرجع لقيود الحجم فقط كما هو موضح لـ TPM_Malloc().

الأخطاء

TPM_SUCCESS
اكتملت الدالة بنجاح.
TPM_FAIL
فشل عام.

للحصول على قائمة كاملة برموز أخطاء TPM، يرجى الرجوع إلى ملف التضمين libtpms/tpm_error.h

مثال

#include <stdio.h>
#include <libtpms/tpm_types.h>
#include <libtpms/tpm_library.h>
#include <libtpms/tpm_error.h>
static unsigned char TPM_Startup_ST_CLEAR[] = {
    0x00, 0xC1, 0x00, 0x00, 0x00, 0x0C, 0x00, 0x00, 0x00, 0x99,
    0x00, TPM_ST_CLEAR
};
int main(void) {
    TPM_RESULT res;
    unsigned char *respbuffer = NULL;
    uint32_t resp_size = 0;
    uint32_t respbufsize = 0;
    unsigned char *command;
    uint32_t command_size;
    [...]
    if (TPMLIB_MainInit() != TPM_SUCCESS) {
         fprintf(stderr, "Could not start the TPM.\n");
         return 1;
    }
    [...]
    /* build TPM command */
    command = TPM_Startup_ST_CLEAR;
    command_size = sizeof(TPM_Startup_ST_CLEAR);
    [...]
    res = TPMLIB_Process(&respbuffer, &resp_size,
                         &respbufsize,
                         command, command_size);
    [...]
    TPMLIB_Terminate();
    return 0;
}
