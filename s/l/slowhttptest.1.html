slowhttptest(1)

الحزمة: slowhttptest

التراخيص: Apache

SLOWHTTPTEST(1) دليل الأوامر العامة SLOWHTTPTEST(1)

الاسم

slowhttptest — محاكي هجمات حجب الخدمة (Denial Of Service)

ملخص

slowhttptest [-H|B|R|X] [-g] [-a نطاق البداية] [-b حد النطاق] [-c عدد الاتصالات] [-d توجيه كل حركة المرور عبر وكيل HTTP في المضيف:المنفذ] [-e توجيه حركة الاستكشاف عبر وكيل HTTP في المضيف:المنفذ] [-f قيمة رأس نوع المحتوى] [-i الفاصل الزمني بالثواني] [-k عامل ضرب الطلب] [-l مدة الاختبار بالثواني] [-m قيمة رأس القبول] [-n الفاصل الزمني للقراءة البطيئة بالثواني] [-o مسار واسم ملف الإخراج] [-p مهلة اتصال الاستكشاف بالثواني] [-r اتصال في الثانية] [-s قيمة رأس طول المحتوى] [-t فعل HTTP] [-u عنوان URL مطلق] [-v مستوى تفاصيل الإخراج] [-w نطاق حجم نافذة TCP المعلنة بداية] [-x أقصى طول للبيانات اللاحقة] [-y نطاق حجم نافذة TCP المعلنة نهاية] [-z قراءة بطيئة من مخزن الاستقبال بالبايت]

الوصف

slowhttptest يقوم بتنفيذ معظم هجمات طبقة التطبيق الشائعة منخفضة النطاق الترددي (DoS) وينتج ملفات CSV و HTML بإحصائيات الاختبار.

الهجمات المدعومة حاليًا هي:

  • Slowloris
  • Slow HTTP POST
  • Apache Range Header
  • Slow Read

الخيارات هي كما يلي:

-g
يجبر slowhttptest على إنشاء ملفات CSV و HTML عند انتهاء الاختبار مع طابع زمني في اسم الملف.
-H
يبدأ slowhttptest في وضع SlowLoris، وإرسال طلبات HTTP غير مكتملة.
-B
يبدأ slowhttptest في وضع Slow POST، وإرسال أجسام رسائل HTTP غير مكتملة.
-R
يبدأ slowhttptest في وضع Range Header، وإرسال بيانات رأس طلب النطاق الضارة.
-X
يبدأ slowhttptest في وضع Slow Read، وقراءة استجابات HTTP ببطء.
-a البداية
يضبط قيمة البداية لمحدد النطاق لهجوم Range Header.
-b بايت
يضبط قيمة الحد لمحدد النطاق لهجوم Range Header.
-c عدد الاتصالات
يحدد العدد المستهدف للاتصالات التي سيتم إنشاؤها أثناء الاختبار.
-d وكيل HTTP المضيف:المنفذ
يحدد خادم وكيل HTTP للاتصال به لجميع الاتصالات.
-e وكيل HTTP المضيف:المنفذ
يحدد خادم وكيل HTTP للاتصال به لاتصالات الاستكشاف.
-f نوع المحتوى
يحدد قيمة رأس نوع المحتوى.
-i ثواني
يحدد الفاصل الزمني بين بيانات المتابعة لاختبارات slowrois و Slow POST.
-k عامل الأنابيب
يحدد عدد المرات التي سيتم فيها طلب المورد لكل مقبس في اختبار Slow Read.
-l ثواني
يحدد مدة الاختبار بالثواني.
-m القبول
يحدد قيمة رأس القبول.
-n ثواني
يحدد الفاصل الزمني بين عمليات القراءة لاختبار Slow Read.
-o اسم الملف
يحدد اسم ملف مخصص، وهو فعال مع -g.
-p ثواني
يحدد الفاصل الزمني للانتظار لاستجابة HTTP على اتصال الاستكشاف، قبل تمييز الخادم على أنه تم حجب الخدمة.
-r اتصالات في الثانية
يحدد معدل الاتصال.
-s بايت
يحدد قيمة رأس طول المحتوى لاختبار Slow POST.
-t فعل HTTP
يحدد الفعل المستخدم في طلب HTTP.
-u عنوان URL
يحدد عنوان URL.
-v المستوى
يحدد مستوى تفاصيل التسجيل.
-w بايت
يحدد بداية النطاق الذي سيتم منه اختيار حجم نافذة TCP المعلنة في اختبار Slow Read.
-x بايت
يحدد الحد الأقصى لطول بيانات المتابعة لاختبارات slowloris و Slow POST.
-y بايت
يحدد نهاية النطاق الذي سيتم منه اختيار حجم نافذة TCP المعلنة في اختبار Slow Read.
-z بايت
يحدد عدد البايتات التي سيتم قراءتها من مخزن الاستقبال مع كل عملية read().

أمثلة

ابدأ اختبار slowloris على host.example.com بـ 1000 اتصال، تذهب الإحصائيات إلى my_header_stats، والفاصل الزمني بين الرؤوس اللاحقة هو 10 ثوانٍ، ومعدل الاتصال هو 200 اتصال في الثانية:

$ slowhttptest -c 1000 -H -g -o my_header_stats -i 10 -r 200 -t GET -u https://host.example.com/index.html -x 24 -p 3

ابدأ اختبار slow POST على host.example.com بـ 3000 اتصال، تذهب الإحصائيات إلى my_body_stats، والفاصل الزمني بين الرؤوس اللاحقة هو 110 ثوانٍ، ومعدل الاتصال هو 200 اتصال في الثانية، وقيمة رأس Content-Length هي 8192، والحد الأقصى لطول بيانات المتابعة هو قيمة عشوائية محدودة بـ 10 بايت، وتنتظر اتصالات الاستكشاف 3 ثوانٍ لاستجابة HTTP قبل تمييز الخادم على أنه تم حجب الخدمة:
