NAME

sloccount - counts source lines of code

SYNOPSIS

sloccount [-w] [-l] [-x] [-h] [-s] [-c] [-e EXCLUDE] [-- FILES...]

DESCRIPTION

sloccount is a tool that counts lines of code (LOC) in various programming languages. It is designed to be accurate and robust, handling different file types and comments correctly.

The tool can analyze files or directories specified on the command line. It recognizes a wide range of programming languages and attempts to exclude comments and blank lines from the count.

OPTIONS

-w
Wide output format, showing more details per language.
-l
List all supported languages.
-x
Output in XML format.
-h
Print a help message and exit.
-s
Summarize counts per directory.
-c
Count comments as code.
-e EXCLUDE
Exclude files matching the given pattern (e.g., '*.c'). Can be specified multiple times.
--
End of options. All subsequent arguments are treated as file or directory names.

NOTES
