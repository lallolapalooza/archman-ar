SLALSA تقوم بحساب SVD للمصفوفة المعاملة في شكل مضغوط. تستخدم بواسطة sgelsd.

الغرض:

!>
!> SLALSA هي خطوة وسيطة في حل مشكلة أقل المربعات عن طريق حساب SVD
!> للمصفوفة المعاملة في شكل مضغوط (تُحسب المتجهات المنفردة كمنتجات
!> لمصفوفات متعامدة بسيطة).
!>
!> إذا كانت ICOMPQ = 0، فإن SLALSA تطبق معكوس مصفوفة المتجهات المنفردة
!> اليسرى لمصفوفة ثنائية علوية على الطرف الأيمن؛ وإذا كانت ICOMPQ = 1،
!> فإن SLALSA تطبق مصفوفة المتجهات المنفردة اليمنى على الطرف الأيمن.
!> تم إنشاء مصفوفات المتجهات المنفردة في شكل مضغوط بواسطة SLALSA.
!>

المعلمات

ICOMPQ 
!>          ICOMPQ هو عدد صحيح (INTEGER)
!>         يحدد ما إذا كانت مصفوفة المتجهات المنفردة اليسرى أو اليمنى
!>         متضمنة.
!>         = 0: مصفوفة المتجهات المنفردة اليسرى
!>         = 1: مصفوفة المتجهات المنفردة اليمنى
!>

N

!>         أبعاد الصف والعمود للمصفوفة ثنائية الأبعاد العلوية.
!>

NRHS

!>          NRHS هو عدد صحيح (INTEGER)
!>         عدد أعمدة B و BX. يجب أن يكون NRHS على الأقل 1.
!>

B

!>          B هي مصفوفة حقيقية (REAL array)، ذات أبعاد ( LDB, NRHS )
!>         عند الإدخال، تحتوي B على الأطراف اليمنى لمشكلة أقل المربعات
!>         في الصفوف من 1 إلى M.
!>         عند الخروج، تحتوي B على الحل X في الصفوف من 1 إلى N.
!>

!>         البعد الرئيسي لـ B في البرنامج الفرعي المستدعي.

!>

BX

!>          BX هي مصفوفة حقيقية (REAL array)، ذات أبعاد ( LDBX, NRHS )

LDBX

!>          LDBX هو عدد صحيح (INTEGER)

!>         POLES, GIVNUM, و Z.
!>

VT

!>          VT هي مصفوفة حقيقية (REAL array)، ذات أبعاد ( LDU, SMLSIZ+1 ).
!>         عند الإدخال، يحتوي VT**T على مصفوفات المتجهات المنفردة اليمنى
!>         لجميع المشاكل الفرعية في المستوى السفلي.
!>

K

!>          K هي مصفوفة أعداد صحيحة (INTEGER array)، ذات أبعاد ( N ).
!>

DIFL

!>          DIFL هي مصفوفة حقيقية (REAL array)، ذات أبعاد ( LDU, NLVL ).

!>         المسافات بين القيم المنفردة في المستوى I و

!>         للمشاكل الفرعية في المستوى I.

Z

NAME

slalsa — A subroutine to compute the LÂ°>s approximation of a sparse symmetric-definite, or general, system of linear equations.

SYNOPSIS

SUBROUTINE SLALSA(ICTXT, TRANS, M, N, A, LDA, B, X, WORK, INFO)
  INTEGER ICTXT(*)
  CHARACTER TRANS
  INTEGER M, N, LDA, INFO
  REAL A(LDA,*)
  REAL B(M), X(N)
  REAL WORK(*)

Function/Subroutine Documentation

SLALSA computes the L°s approximation of a sparse symmetric-definite, or general, system of linear equations.

ICTXT

INTEGER array, length 4. SLALSA context.

The elements of ICTXT are:

ICTXT(1) = 1 if A is symmetric positive definite, 0 otherwise.
ICTXT(2) = 1 if A is symmetric, 0 otherwise.
ICTXT(3) = 1 if A is general sparse, 0 otherwise.
ICTXT(4) = 0, reserved for future use.
TRANS

CHARACTER*1.

Specifies the form of the system of equations:

'N' or 'n' The system to be solved is A*X = B.
'T' or 't' The system to be solved is A**T*X = B.
'C' or 'c' The system to be solved is A**H*X = B (where A**H denotes the conjugate transpose of A).
M

INTEGER.

The number of rows of the matrix A.

N

INTEGER.

The number of columns of the matrix A.

A

REAL array, dimension (LDA, K) where K is N if TRANS = 'N' or 'n', and K is M if TRANS = 'T' or 't' or 'C' or 'c'.

On entry, A contains the matrix A.

LDA

INTEGER.

The leading dimension of the array A.

B

REAL array, dimension (M).

On entry, B contains the right hand side vector B.

X

REAL array, dimension (N).

On exit, X contains the solution vector X.

WORK

REAL array, dimension (LWORK).

Local workspace array.

INFO

INTEGER.

INFO = 0: successful exit.

INFO < 0: if INFO = -i, the i-th argument had an illegal value.

INFO > 0: if INFO = i, SLALSA failed to converge. i is the number of iterations performed.
