NAME

slatme - forms the real general matrix A.

SYNOPSIS

  SUBROUTINE SLATME(
     N, DIST, DISTS, MODE, COND, ANORM, MAXMIN, KVAL, NKVAL, VL, VU, IL, IU,
     CLVL, CVL, CIJL, CIJR, IROFF, ICLOFF, I, M, NB, SIGMA, D, DS, MODES,
     CONDS, KL, KU, ANORM, A, LDA, WORK, INFO
  )

Function/Subroutine Documentation

This routine is used to construct a matrix A of a desired order N, such that A has a specified spectral condition number “cond” (when MODE = 0 or 2), or a specified norm and maximum or minimum eigenvalue respectively (when MODE = 1 or 3).

When MODE = 0, the matrix A is chosen so that its eigenvalues have a specified condition number, and the minimum singular value is also specified.

When MODE = 1, the matrix A is chosen so that its maximum eigenvalue has a specified condition number.

When MODE = 2, the matrix A is chosen so that its minimum singular value has a specified condition number.

When MODE = 3, the matrix A is chosen so that its maximum singular value has a specified condition number.

When MODE = 4, the matrix A is chosen so that its minimum eigenvalue has a specified norm.

When MODE = 5, the matrix A is chosen so that its maximum eigenvalue has a specified norm.

When MODE = 6, the matrix A is chosen so that its minimum singular value has a specified norm.

When MODE = 7, the matrix A is chosen so that its maximum singular value has a specified norm.

When MODE = 8, the matrix A is chosen so that its eigenvalues have a specified condition number, and the maximum singular value is also specified.

When MODE = 9, the matrix A is chosen so that its singular values have a specified condition number.

When MODE = 10, the matrix A is chosen so that its eigenvalues have a specified norm.

When MODE = 11, the matrix A is chosen so that its singular values have a specified norm.

Special values of MODE, denoted by MODES, can be used to construct matrices with random eigenvalues or singular values.

See the documentation for SLATME.

This routine is part of the LAPACK testing suite.

Arguments:

N

!>          N is INTEGER
!>           The order of the matrix A.  N >= 0.
!>           Not modified.

DIST

!>          DIST is CHARACTER*1
!>           Specifies the storage format of the matrix.
!>           'R' => REAL,      'U' => UPPER TRIANGULAR
!>           'L' => LOWER TRIANGULAR, 'S' => SYMMETRIC
!>           'H' => UPPER HESSENBERG,   'B' => LOWER HESSENBERG
!>           'Q' => QUASI-UPPER TRIANGULAR, 'Z' => QUASI-LOWER TRIANGULAR
!>           'P' => PERSYMMETRIC,      'G' => GENERAL
!>           Not modified.

DISTS

!>          DISTS is CHARACTER*1
!>           Specifies the storage format of the matrix when singular
!>           values are used.
!>           'R' => REAL,      'U' => UPPER TRIANGULAR
!>           'L' => LOWER TRIANGULAR, 'S' => SYMMETRIC
!>           'H' => UPPER HESSENBERG,   'B' => LOWER HESSENBERG
!>           'Q' => QUASI-UPPER TRIANGULAR, 'Z' => QUASI-LOWER TRIANGULAR
!>           'P' => PERSYMMETRIC,      'G' => GENERAL
!>           Not modified.

MODE

!>          MODE is INTEGER
!>           Specifies the type of condition to be imposed on the matrix.
!>           MODE = 0: A is chosen so that its eigenvalues have condition number COND.
!>           MODE = 1: A is chosen so that its maximum eigenvalue is COND.
!>           MODE = 2: A is chosen so that its minimum singular value is COND.
!>           MODE = 3: A is chosen so that its maximum singular value is COND.
!>           MODE = 4: A is chosen so that its minimum eigenvalue is COND.
!>           MODE = 5: A is chosen so that its maximum eigenvalue is COND.
!>           MODE = 6: A is chosen so that its minimum singular value is COND.
!>           MODE = 7: A is chosen so that its maximum singular value is COND.
!>           MODE = 8: A is chosen so that its eigenvalues have condition number COND.
!>           MODE = 9: A is chosen so that its singular values have condition number COND.
!>           MODE = 10: A is chosen so that its eigenvalues have norm ANORM.
!>           MODE = 11: A is chosen so that its singular values have norm ANORM.
!>           Modified if MODE is nonzero.

COND

!>          COND is REAL
!>           The condition number.  COND is only used if MODE is nonzero.
!>           Modified if MODE is nonzero.

ANORM

!>          ANORM is REAL
!>           The norm of the matrix.  ANORM is only used if MODE = 10 or 11.
!>           Modified if MODE is nonzero.

MAXMIN

!>          MAXMIN is CHARACTER*1
!>           Specifies whether to use the maximum or minimum eigenvalue or
!>           singular value.
!>           'M' => maximum, 'm' => minimum
!>           Not modified.

KVAL

!>          KVAL is INTEGER
!>           Specifies the value of k, the number of eigenvalues or
!>           singular values to be computed.  KVAL must be at least 1.
!>           Not modified.

NKVAL

!>          NKVAL is INTEGER
!>           The number of eigenvalues or singular values to be computed.
!>           Not modified.

VL

!>          VL is REAL
!>           The lower bound for the eigenvalues or singular values.
!>           Not modified.

VU

!>          VU is REAL
!>           The upper bound for the eigenvalues or singular values.
!>           Not modified.

IL

!>          IL is INTEGER
!>           The index of the first eigenvalue or singular value to be
!>           returned.
!>           Not modified.

IU

!>          IU is INTEGER
!>           The index of the last eigenvalue or singular value to be
!>           returned.
!>           Not modified.

CLVL

!>          CLVL is REAL
!>           The lower bound for the condition number.
!>           Not modified.

CVL

!>          CVL is REAL
!>           The lower bound for the condition number.
!>           Not modified.

CIJL

!>          CIJL is INTEGER
!>           The index of the first eigenvalue or singular value to be
!>           returned.
!>           Not modified.

CIJR

!>          CIJR is INTEGER
!>           The index of the last eigenvalue or singular value to be
!>           returned.
!>           Not modified.

IROFF

!>          IROFF is INTEGER
!>           The row offset for the matrix.
!>           Not modified.

ICLOFF

!>          ICLOFF is INTEGER
!>           The column offset for the matrix.
!>           Not modified.

I

!>          I is INTEGER array, dimension ( N )
!>           This array is used to specify the diagonal elements of the
!>           matrix.
!>           Modified if MODE is nonzero.

M

!>          M is INTEGER
!>           The number of eigenvalues or singular values to be returned.
!>           Not modified.

NB

!>          NB is INTEGER
!>           The size of the blocks to be used in the computation.
!>           Not modified.

SIGMA

!>          SIGMA is REAL
!>           Shift value.
!>           Not modified.

D

!>          D is REAL array, dimension ( N )
!>           This array is used to specify the eigenvalues of A.
!>           If MODE=0, D contains the eigenvalues, which may not be zero.
!>           Modified if MODE is nonzero.

DS

!>          DS is REAL array, dimension ( N )
!>           This array is used to specify the singular values of X,
!>           in the same way that D specifies the eigenvalues of A.
!>           If MODE=0, the DS contains the singular values, which
!>           may not be zero.
!>           Modified if MODE is nonzero.

MODES

!>          MODES is INTEGER

CONDS

!>          CONDS is REAL
!>           Same as MODE and COND, but for specifying the diagonal
!>           of S.  MODES=-6 and +6 are not allowed (since they would
!>           result in randomly ill-conditioned eigenvalues.)

KL

!>          KL is INTEGER
!>           This specifies the lower bandwidth of the  matrix.  KL=1
!>           specifies upper Hessenberg form.  If KL is at least N-1,
!>           then A will have full lower bandwidth.  KL must be at
!>           least 1.
!>           Not modified.

KU

!>          KU is INTEGER
!>           This specifies the upper bandwidth of the  matrix.  KU=1
!>           specifies lower Hessenberg form.  If KU is at least N-1,
!>           then A will have full upper bandwidth; if KU and KL
!>           are both at least N-1, then A will be dense.  Only one of
!>           KU and KL may be less than N-1.  KU must be at least 1.
!>           Not modified.

ANORM

!>          ANORM is REAL
!>           If ANORM is not negative, then A will be scaled by a non-
!>           negative real number to make the maximum-element-norm of A
!>           to be ANORM.
!>           Not modified.

A

!>          A is REAL array, dimension ( LDA, N )
!>           On exit A is the desired test matrix.
!>           Modified.

LDA

!>          LDA is INTEGER
!>           LDA specifies the first dimension of A as declared in the
!>           calling program.  LDA must be at least N.
!>           Not modified.

WORK

!>          WORK is REAL array, dimension ( 3*N )
!>           Workspace.
!>           Modified.

INFO

!>          INFO is INTEGER
!>           Error code.  On exit, INFO will be set to one of the
!>           following values:
!>             0 => normal return
!>            -1 => N negative
!>            -2 => DIST illegal string
!>            -5 => MODE not in range -6 to 6
!>            -6 => COND less than 1.0, and MODE neither -6, 0 nor 6
!>            -8 => EI(1) is not ' ' or 'R', EI(j) is not 'R' or 'I', or
!>                  two adjacent elements of EI are 'I'.
!>            -9 => RSIGN is not 'T' or 'F'
!>           -10 => UPPER is not 'T' or 'F'
!>           -11 => SIM   is not 'T' or 'F'
!>           -12 => MODES=0 and DS has a zero singular value.
!>           -13 => MODES is not in the range -5 to 5.
!>           -14 => MODES is nonzero and CONDS is less than 1.
!>           -15 => KL is less than 1.
!>           -16 => KU is less than 1, or KL and KU are both less than
!>                  N-1.
!>           -19 => LDA is less than N.
!>            1  => Error return from SLATM1 (computing D)
!>            2  => Cannot scale to DMAX (max. eigenvalue is 0)
!>            3  => Error return from SLATM1 (computing DS)
!>            4  => Error return from SLARGE
!>            5  => Zero singular value from SLATM1.
