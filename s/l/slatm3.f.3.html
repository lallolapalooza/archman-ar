SLATM3

الغرض:

!>
!>    SLATM3 تعيد الإدخال (ISUB,JSUB) لمصفوفة عشوائية ذات
!>    بعد (M, N) موصوفة بالمعلمات الأخرى. (ISUB,JSUB)
!>    هو الموضع النهائي للإدخال (I,J) بعد المحورية
!>    وفقًا لـ IPVTNG و IWORK. يتم استدعاء SLATM3 بواسطة
!>    روتين SLATMR لبناء مصفوفات اختبار عشوائية. لا يوجد خطأ
!>    فحص للمعلمات، لأن هذا الإجراء الفرعي يتم استدعاؤه في
!>    حلقة ضيقة بواسطة SLATMR الذي قام بالفعل بفحص المعلمات.
!>
!>    يختلف استخدام SLATM3 عن SLATM2 في الترتيب الذي يتم به الرقم العشوائي
!>    يتم استدعاء المولد لملء إدخالات المصفوفة العشوائية.
!>    مع SLATM2، يتم استدعاء المولد لملء المصفوفة المحورية
!>    عموديًا. مع SLATM3، يتم استدعاء المولد لملء
!>    المصفوفة عموديًا، وبعد ذلك يتم محورها. وبالتالي، يمكن لـ SLATM3
!>    استخدامها لإنشاء مصفوفات عشوائية تختلف فقط في ترتيب
!>    صفوفها و/أو أعمدتها. يستخدم SLATM2 لإنشاء مصفوفات النطاق
!>    مع تجنب استدعاء مولد الأرقام العشوائية للإدخالات خارج
!>    النطاق (وبالتالي توليد أرقام عشوائية بترتيبات مختلفة لأوامر
!>    محورية مختلفة).
!>
!>    المصفوفة التي يتم إرجاع إدخالها (ISUB,JSUB) يتم بناؤها على النحو
!>    التالي (يقوم هذا الإجراء الفرعي بحساب إدخال واحد فقط):
!>
!>      إذا كان ISUB خارج (1..M) أو JSUB خارج (1..N)، أعد صفرًا
!>         (هذا مناسب لإنشاء مصفوفات بتنسيق نطاق).
!>
!>      قم بإنشاء مصفوفة A بإدخالات عشوائية من التوزيع IDIST.
!>
!>      عيّن القطر إلى D.
!>
!>      قم بتصنيف المصفوفة، إذا رغبت في ذلك، من اليسار (بواسطة DL) و/أو
!>         من اليمين (بواسطة DR أو DL) كما هو محدد بواسطة IGRADE.
!>
!>      قم بالتبديل، إذا رغبت في ذلك، للصفوف و/أو الأعمدة كما هو محدد بواسطة
!>         IPVTNG و IWORK.
!>
!>      قم بتنطيط المصفوفة لتكون لها نطاق سفلي KL ونطاق علوي
!>         KU.
!>
!>      قم بتعيين الإدخالات العشوائية إلى صفر كما هو محدد بواسطة SPARSE.
!>

KL

!>          KL is INTEGER
!>           عرض النطاق السفلي. لم يتم تعديله.

!>           لتوليد مصفوفة عشوائية.
!>           1 => UNIFORM( 0, 1 )
!>           2 => UNIFORM( -1, 1 )
!>           3 => NORMAL( 0, 1 )
!>           لم يتم تعديله.
!>

ISEED

!>          ISEED is INTEGER array of dimension ( 4 )
!>           بذرة لمولد الأرقام العشوائية.
!>           تم تغييره عند الخروج.
!>

D

!>          D is REAL array of dimension ( MIN( I , J ) )
!>           إدخالات القطر للمصفوفة. لم يتم تعديلها.
!>

IGRADE

!>          IGRADE is INTEGER
!>           يحدد تصنيف المصفوفة على النحو التالي:
!>           0  => لا يوجد تصنيف
!>           1  => تم ضرب المصفوفة مسبقًا بـ diag( DL )
!>           2  => تم ضرب المصفوفة لاحقًا بـ diag( DR )
!>           3  => تم ضرب المصفوفة مسبقًا بـ diag( DL ) و
!>                         تم ضربها لاحقًا بـ diag( DR )
!>           4  => تم ضرب المصفوفة مسبقًا بـ diag( DL ) و
!>                         تم ضربها لاحقًا بـ inv( diag( DL ) )
!>           5  => تم ضرب المصفوفة مسبقًا بـ diag( DL ) و
!>                         تم ضربها لاحقًا بـ diag( DL )
!>           لم يتم تعديله.
!>

DL

!>          DL is REAL array ( I or J, as appropriate )
!>           عوامل القياس اليسرى لتصنيف المصفوفة. لم يتم تعديلها.
!>

DR

!>          DR is REAL array ( I or J, as appropriate )
!>           عوامل القياس اليمنى لتصنيف المصفوفة. لم يتم تعديلها.
!>

IPVTNG

!>          IPVTNG is INTEGER
!>           عند الإدخال يحدد تباديل المحورية على النحو التالي:
!>           0 => لا شيء.
!>           1 => محورية الصف.
!>           2 => محورية العمود.
!>           3 => محورية كاملة، أي من الجانبين.
!>           لم يتم تعديله.
!>

IWORK

!>          IWORK is INTEGER array ( I or J, as appropriate )
!>           يحدد هذا المصفوفة التبديل المستخدم.
!>           الصف (أو العمود) الموجود في الأصل في الموضع K موجود في
!>           الموضع IWORK( K ) بعد المحورية.
!>           يختلف هذا عن IWORK لـ SLATM2. لم يتم تعديله.
!>

SPARSE

!>          SPARSE is REAL between 0. and 1.
!>           عند الإدخال يحدد تخلخل المصفوفة
!>           إذا كان سيتم إنشاء مصفوفة متخلخلة.
!>           يجب أن يكون SPARSE بين 0 و 1.
!>           يتم إنشاء رقم عشوائي موحد (0, 1) x ويتم
!>           مقارنته بـ SPARSE؛ إذا كان x أكبر، فإن إدخال المصفوفة
!>           لا يتغير وإذا كان x أصغر، يتم تعيين الإدخال
!>           إلى صفر. وبالتالي، في المتوسط، سيتم تعيين جزء من
!>           الإدخالات إلى صفر.
!>           لم يتم تعديله.
!>

NAME

slatm3 - The routine computes the overlap matrix for a given atom.

SYNOPSIS

Subroutine slatm3(N, M, L, R, F)

INTEGER N, M, L
REAL(8) R(N,M), F(L)

Function/Subroutine Documentation

slatm3

The routine computes the overlap matrix for a given atom.

Arguments:
N: The dimension of the matrix.
M: The number of atoms.
L: The maximum angular momentum.
R: The overlap matrix.
F: The array of atomic orbitals.
