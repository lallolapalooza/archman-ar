توثيق الوظيفة/الروتين الفرعي

subroutine slags2 (logical upper, real a1, real a2, real a3, real b1, real b2, real b3, real csu, real snu, real csv, real snv, real csq, real snq)

SLAGS2 تحسب مصفوفتين متعامدتين 2x2 وهما U و V و Q، وتطبقهما على المصفوفتين A و B بحيث تكون صفوف A و B المحولة متوازية.

الغرض:

!>
!> SLAGS2 تحسب مصفوفتين متعامدتين 2x2 وهما U و V و Q، بحيث إذا كان ( UPPER )، عندها:
!>
!>           U**T *A*Q = U**T *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> و
!>           V**T*B*Q = V**T *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> أو إذا كان ( .NOT.UPPER )، عندها:
!>
!>           U**T *A*Q = U**T *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> و
!>           V**T*B*Q = V**T*( B1 0  )*Q = ( x  x  )
!>                           ( B2 B3 )     ( 0  x  )
!>
!> صفوف A و B المحولة تكون متوازية، حيث
!>
!>   U = (  CSU  SNU ), V = (  CSV SNV ), Q = (  CSQ   SNQ )
!>       ( -SNU  CSU )      ( -SNV CSV )      ( -SNQ   CSQ )
!>
!> Z**T يمثل منقول Z.
!>
!>
