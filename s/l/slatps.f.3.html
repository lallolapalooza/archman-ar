SLATPS يحل نظام معادلات مثلثي مع المصفوفة المخزنة في تخزين مكدس.

توثيق الوظيفة/الروتين الفرعي

subroutine slatps (character uplo, character trans, character diag, character normin, integer n, real, dimension( * ) ap, real, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

SLATPS يحل نظام مثلثي للمعادلات مع المصفوفة المخزنة في تخزين مكدس.

الغرض:

!>
!> SLATPS يحل أحد الأنظمة المثلثية
!>
!>    A *x = s*b  أو  A**T*x = s*b
!>
!> مع القياس لمنع الفائض، حيث A مصفوفة مثلثية علوية أو سفلية مخزنة بشكل مكدس. هنا A**T تمثل منقول A، x و b هما متجهان ذو n عنصر، و s هو عامل قياس، عادة ما يكون أقل من أو يساوي 1، يتم اختياره بحيث تكون مكونات x أقل من عتبة الفائض. إذا لم يتسبب النظام غير المقاس في فيضان، يتم استدعاء روتين المستوى 2 BLAS STPSV. إذا كانت المصفوفة A مفردة (A(j,j) = 0 لبعض j)، فسيتم تعيين s إلى 0 وإرجاع حل غير بديهي لـ A*x = 0.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية علوية أو سفلية.
!>          = 'U':  مثلثية علوية
!>          = 'L':  مثلثية سفلية
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد العملية المطبقة على A.
!>          = 'N':  حل A * x = s*b  (بدون منقول)
!>          = 'T':  حل A**T* x = s*b  (منقول)
!>          = 'C':  حل A**T* x = s*b  (منقول مترافق = منقول)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية وحدية أم لا.
!>          = 'N':  مثلثية غير وحدية
!>          = 'U':  مثلثية وحدية
!>

NORMIN

!>          NORMIN هو CHARACTER*1
!>          يحدد ما إذا تم تعيين CNORM أم لا.
!>          = 'Y':  يحتوي CNORM على معايير الأعمدة عند الدخول
!>          = 'N':  لم يتم تعيين CNORM عند الدخول. عند الخروج، سيتم
!>                  حساب المعايير وتخزينها في CNORM.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

AP

!>          AP هو مصفوفة REAL، حجمها (N*(N+1)/2)
!>          المصفوفة المثلثية العلوية أو السفلية A، مكدسة عموديًا في
!>          مصفوفة خطية. يتم تخزين العمود j من A في المصفوفة
!>          AP على النحو التالي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

X

!>          X هو مصفوفة REAL، حجمها (N)
!>          عند الدخول، الطرف الأيمن b للنظام المثلثي.
!>          عند الخروج، يتم الكتابة فوق X بواسطة متجه الحل x.
!>

SCALE

!>          SCALE هو REAL
!>          عامل القياس s للنظام المثلثي
!>             A * x = s*b  أو  A**T* x = s*b.
!>          إذا كان SCALE = 0، فإن المصفوفة A مفردة أو مقاسة بشكل سيء،
!>          ومتجه x هو حل دقيق أو تقريبي لـ A*x = 0.
!>

CNORM

!>          CNORM هو مصفوفة REAL، حجمها (N)
!>
!>          إذا كان NORMIN = 'Y'، فإن CNORM هو وسيط إدخال و CNORM(j)
!>          يحتوي على معيار الجزء غير القطري من العمود j
!>          من A. إذا كان TRANS = 'N'، يجب أن يكون CNORM(j) أكبر من أو يساوي
!>          معيار اللانهاية، وإذا كان TRANS = 'T' أو 'C'، يجب أن يكون CNORM(j)
!>          أكبر من أو يساوي معيار 1.
!>
!>          إذا كان NORMIN = 'N'، فإن CNORM هو وسيط إخراج و CNORM(j)
!>          يُرجع معيار 1 للجزء غير القطري من العمود j
!>          من A.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -k، فإن الوسيط k كان له قيمة غير قانونية
!>

تفاصيل إضافية:

!>
!>  يتم حساب حد تقريبي للمتجه x؛ إذا كان هذا أقل من الفائض، يتم استدعاء STPSV،
!>  وإلا، يتم استخدام رمز محدد يتحقق من الفائض المحتمل أو القسمة على صفر في كل عملية.
!>
!>  يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!>  إذا كانت A مثلثية سفلية هي
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!>  نحدد حدودًا لمكونات x بعد j تكرار للحلقة:
!>     M(j) = حد لـ x[1:j]
!>     G(j) = حد لـ x[j+1:n]
!>  مبدئيًا، دع M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!>  ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!>  حيث CNORM(j+1) أكبر من أو يساوي معيار اللانهاية لـ
!>  العمود j+1 من A، باستثناء القطر. وبالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!>  و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!>  نظرًا لأن |x(j)| <= M(j)، نستخدم روتين المستوى 2 BLAS STPSV إذا كان
!>  المقلوب لأكبر M(j)، j=1,..,n، أكبر من
!>  max(underflow, 1/overflow).
!>
!>  يتم أيضًا استخدام الحد لـ x(j) لتحديد متى يمكن إجراء خطوة في
!>  المخطط العمودي دون خوف من الفائض. إذا
!>  الحد المحسوب أكبر من ثابت كبير، يتم قياس x لمنع الفائض، ولكن إذا
!>  فشل الحد، يتم تعيين x إلى 0، و x(j) إلى 1، و scale إلى 0، ويتم العثور على حل غير بديهي لـ A*x = 0.
!>
!>  بالمثل، يتم استخدام مخطط صفي لحل A**T*x = b. الخوارزمية الأساسية
!>  لـ A المثلثية العلوية هي
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       end
!>
!>  نقوم بحساب حدين في وقت واحد
!>       G(j) = حد لـ ( b(i) - A[1:i-1,i]**T * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد لـ x(i)، 1<=i<=j
!>
!>  القيم الأولية هي G(0) = 0، M(0) = max{b(i)، i=1,..,n}، ونحن
!>  نضيف الشرط G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!>  ثم حد x(j) هو
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!>  ويمكننا استدعاء STPSV بأمان إذا كان 1/M(n) و 1/G(n) كلاهما أكبر
!>  من max(underflow, 1/overflow).
!>
