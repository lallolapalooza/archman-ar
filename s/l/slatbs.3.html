SLATBS تحل نظام معادلات باند مثلثي.

توثيق الوظيفة/الإجراء الفرعي

subroutine slatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, real, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) x, real scale, real, dimension( * ) cnorm, integer info)

SLATBS تحل نظام معادلات مثلثي باند.

الغرض:

!>
!> SLATBS تحل أحد الأنظمة المثلثية
!>
!>    A *x = s*b  أو  A**T*x = s*b
!>
!> مع القياس لمنع الفائض، حيث A هي مصفوفة باند مثلثية علوية أو سفلية.
!> هنا A**T تعني منقول A، و x و b هما متجهان من n عنصر، و s هو عامل قياس،
!!> يكون عادة أقل من أو يساوي 1، يتم اختياره بحيث تكون عناصر x أقل من
!> عتبة الفائض. إذا لم يسبب النظام غير المقاس فيضاناً، يتم استدعاء
!> روتين BLAS من المستوى 2 STBSV. إذا كانت المصفوفة A منفردة (A(j,j) = 0
!> لبعض j)، فإن s يتم تعيينه إلى 0 ويتم إرجاع حل غير تافه لـ A*x = 0.
!>

المعاملات

UPLO 
!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية علوية أم سفلية.
!>          = 'U':  مثلثية علوية
!>          = 'L':  مثلثية سفلية
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد العملية المطبقة على A.
!>          = 'N':  حل A * x = s*b  (بدون منقول)
!>          = 'T':  حل A**T* x = s*b  (منقول)
!>          = 'C':  حل A**T* x = s*b  (منقول مترافق = منقول)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية وحدة أم لا.
!>          = 'N':  مثلثية غير وحدة
!>          = 'U':  مثلثية وحدة
!>

NORMIN

!>          NORMIN هو CHARACTER*1
!>          يحدد ما إذا تم تعيين CNORM أم لا.
!>          = 'Y':  تحتوي CNORM على معايير الأعمدة عند الإدخال
!>          = 'N':  لم يتم تعيين CNORM عند الإدخال. عند الخروج، سيتم
!>                  حساب المعايير وتخزينها في CNORM.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

KD

!>          KD هو INTEGER
!>          عدد الأقطار الفرعية أو الأقطار العلوية في
!>          المصفوفة المثلثية A.  KD >= 0.
!>

AB

!>          AB هو مصفوفة REAL، البعد (LDAB,N)
!>          المصفوفة المثلثية العلوية أو السفلية A، مخزنة في
!>          الصفوف KD+1 الأولى من المصفوفة. يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB على النحو التالي:
!>          إذا كان UPLO = 'U'، فإن AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd) <= i <= j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)    = A(i,j) لـ j <= i <= min(n,j+kd).
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= KD+1.
!>

X

!>          X هو مصفوفة REAL، البعد (N)
!>          عند الإدخال، الجانب الأيمن b من النظام المثلثي.
!>          عند الخروج، يتم الكتابة فوق X بواسطة متجه الحل x.
!>

SCALE

!>          SCALE هو REAL
!>          عامل القياس s للنظام المثلثي
!>             A * x = s*b  أو  A**T* x = s*b.
!>          إذا كان SCALE = 0، فإن المصفوفة A منفردة أو مقاسة بشكل سيء،
!>          والمتجه x هو حل دقيق أو تقريبي لـ A*x = 0.
!>

CNORM

!>          CNORM هو مصفوفة REAL، البعد (N)
!>
!>          إذا كان NORMIN = 'Y'، فإن CNORM هو معامل إدخال ويحتوي CNORM(j)
!>          على معيار الجزء غير القطري للعمود j
!>          من A. إذا كان TRANS = 'N'، يجب أن يكون CNORM(j) أكبر من أو يساوي
!>          معيار اللانهاية، وإذا كان TRANS = 'T' أو 'C'، يجب أن يكون CNORM(j)
!>          أكبر من أو يساوي معيار 1.
!>
!>          إذا كان NORMIN = 'N'، فإن CNORM هو معامل إخراج ويقوم CNORM(j)
!>          بتخزين معيار الجزء غير القطري للعمود j
!>          من A.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -k، فإن المعامل k كان له قيمة غير قانونية
!>

تفاصيل إضافية:

!>
!> يتم حساب حد تقريبي لـ x؛ إذا كان أقل من الفائض، يتم استدعاء STBSV،
!> وإلا، يتم استخدام رمز محدد يتحقق من الفائض المحتمل أو القسمة على
!> صفر عند كل عملية.
!>
!> يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!> إذا كانت A مثلثية سفلية هي
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> نحدد حدود عناصر x بعد j تكرار للحلقة:
!>     M(j) = حد لـ x[1:j]
!>     G(j) = حد لـ x[j+1:n]
!> في البداية، لنكن M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!> ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> حيث CNORM(j+1) أكبر من أو يساوي معيار اللانهاية
!> للعمود j+1 من A، باستثناء القطر. بالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> بما أن |x(j)| <= M(j)، فإننا نستخدم روتين BLAS من المستوى 2 STBSV إذا كان
!> مقلوب أكبر M(j)، j=1,..,n، أكبر من
!> max(underflow, 1/overflow).
!>
!> يتم أيضًا استخدام الحد على x(j) لتحديد متى يمكن
!> تنفيذ خطوة في المخطط العمودي دون خوف من الفائض. إذا
!> كان الحد المحسوب أكبر من ثابت كبير، يتم قياس x لمنع
!> الفائض، ولكن إذا فاض الحد، يتم تعيين x إلى 0، و x(j) إلى
!> 1، و scale إلى 0، ويتم العثور على حل غير تافه لـ A*x = 0.
!>
!> وبالمثل، يتم استخدام مخطط صفي لحل A**T*x = b. الخوارزمية الأساسية
!> لـ A المثلثية العلوية هي
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]**T * x[1:j-1] ) / A(j,j)
!>       end
!>
!> نقوم بحساب حدين في نفس الوقت
!>       G(j) = حد لـ ( b(i) - A[1:i-1,i]**T * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد لـ x(i)، 1<=i<=j
!>
!> القيم الأولية هي G(0) = 0، M(0) = max{b(i), i=1,..,n}، و نضيف
!> الشرط G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!> ثم الحد على x(j) هو
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> ويمكننا استدعاء STBSV بأمان إذا كان 1/M(n) و 1/G(n) كلاهما أكبر
!> من max(underflow, 1/overflow).
!>
