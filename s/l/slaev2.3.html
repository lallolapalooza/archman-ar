توثيق الوظيفة/الإجراء الفرعي

subroutine slaev2 (real a, real b, real c, real rt1, real rt2, real cs1, real sn1)

SLAEV2 يحسب القيم الذاتية والمتجهات الذاتية لمصفوفة متماثلة/هرميتية 2x2.

الغرض:

!>
!> SLAEV2 تحسب التحلل الذاتي لمصفوفة متماثلة 2x2
!>    [  A   B  ]
!>    [  B   C  ].
!> عند الإرجاع، RT1 هي القيمة الذاتية ذات القيمة المطلقة الأكبر، RT2 هي القيمة
!> الذاتية ذات القيمة المطلقة الأصغر، و (CS1,SN1) هو المتجه الذاتي الأيمن
!> الأيمن لـ RT1، مما يعطي التحلل
!>
!>    [ CS1  SN1 ] [  A   B  ] [ CS1 -SN1 ]  =  [ RT1  0  ]
!>    [-SN1  CS1 ] [  B   C  ] [ SN1  CS1 ]     [  0  RT2 ].
!>

المعلمات

A 
!>          A هو REAL
!>          العنصر (1,1) للمصفوفة 2x2.
!>

B

!>          B هو REAL
!>          العنصر (1,2) والمرافق للعنصر (2,1) للمصفوفة
!>          2x2.
!>

C

!>          C هو REAL
!>          العنصر (2,2) للمصفوفة 2x2.
!>

RT1

!>          RT1 هو REAL
!>          القيمة الذاتية ذات القيمة المطلقة الأكبر.
!>

RT2

!>          RT2 هو REAL
!>          القيمة الذاتية ذات القيمة المطلقة الأصغر.
!>

CS1

!>          CS1 هو REAL
!>

SN1

!>          SN1 هو REAL
!>          المتجه (CS1, SN1) هو متجه ذاتي أيمن واحد لـ RT1.
!>

تفاصيل إضافية:

!>
!>  RT1 دقيق لبضعة وحدات دقة نسبية (ulps) باستثناء تجاوز أو نقص التدفق.
!>
!>  قد يكون RT2 غير دقيق إذا كان هناك إلغاء هائل في المحدد A*C-B*B؛
!>  فالرياضيات ذات الدقة الأعلى أو التقريب الصحيح أو الاقتطاع الصحيح ستكون
!>  مطلوبة لحساب RT2 بدقة في جميع الحالات.
!>
!>  CS1 و SN1 دقيقان لبضعة وحدات دقة نسبية (ulps) باستثناء تجاوز أو نقص التدفق.
!>
!>  التجاوز ممكن فقط إذا كانت RT1 ضمن عامل 5 من تجاوز الحد.
!>  نقص التدفق لا يسبب ضررًا إذا كانت بيانات الإدخال 0 أو تتجاوز
!>     عتبة نقص التدفق / macheps.
!>
