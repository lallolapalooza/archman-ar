NAME

SLASD6 - SLASD6 is a subroutine to find the desired singular values, and their corresponding singular vectors, of a diagonal matrix ABT + UVT, where A and B are diagonal matrices, and U and V are small matrices.

SYNOPSIS

    SUBROUTINE SLASD6( ICMPNN, LN, K, L, M,
                         D, Z, WORK, IWORK, INFO )
    REAL               D( * ), Z( * ), WORK( * )
    INTEGER            IWORK( * )
    INTEGER            ICMPNN, LN, K, L, M, INFO

Function/Subroutine Documentation

This subroutine is part of the Symmetric/Hermitian eigenvalue problem, specifically, the divide and conquer method for the computation of the singular value decomposition.

Purpose:

!> SLASD6 applies a sequence of Givens rotations to update the singular
!> values and singular vectors.

Arguments:

ICMPNN
ICMPNN is INTEGER

ICMPNN = 0 if the updating matrix has positive diagonal entries, and ICMPNN = 1 if the updating matrix has negative diagonal entries.

Note: In the current version of the code, ICMPNN is always 0.

LN
LN is INTEGER

The dimension of the deflation-adjusted matrix. 1 <= LN <= N.

K
K is INTEGER

Contains the dimension of the non-deflated matrix, This is the order of the related secular equation. 1 <= K <=N.

L
L is INTEGER

The size of the deflation window (currently, L=2).

M
M is INTEGER

The size of the deflation-adjusted vector Z.

D
D is REAL array, dimension ( N )

On entry, D contains the old singular values sorted in ascending order.

On exit, D contains the new singular values sorted in ascending order. The first K elements of D are the singular values of the deflated matrix.

Z
Z is REAL array, dimension ( M )

The first elements of this array contain the components of the deflation-adjusted updating row vector.

WORK
WORK is REAL array, dimension ( 4 * M )
IWORK
IWORK is INTEGER array, dimension ( 3 * N )
INFO
INFO is INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.

> 0: if INFO = 1, a singular value did not converge

Description:

SLASD6 is used in the divide and conquer algorithm for the singular value decomposition. It is called after the secular equation has been solved to update the singular values and vectors.

Specifically, SLASD6 updates the singular values (stored in array D) and the deflation-adjusted updating vector (stored in array Z). The deflation-adjusted updating vector Z is used to update the singular vectors of the original matrix. The routine uses Givens rotations to perform these updates efficiently.

The input array D contains the old singular values sorted in ascending order. On exit, D contains the new singular values, also sorted in ascending order. The first K elements of D correspond to the singular values of the deflated matrix, which means that K singular values have been "deflated" or removed from further consideration.

The array Z contains the components of the deflation-adjusted updating row vector. This vector is crucial for updating the singular vectors of the original matrix. The size of Z is M, where M is related to the deflation process.

The routine returns an INFO flag to indicate success or failure. An INFO value of 0 signifies successful completion. A negative value indicates an illegal argument, and a positive value (specifically 1) indicates that a singular value did not converge, which might require a different approach or more iterations.

The arrays WORK and IWORK are used as temporary storage by SLASD6.

Note that the parameters ICMPNN and L are described as having specific values in the current implementation (ICMPNN=0, L=2), suggesting that the routine is tailored for a particular stage of the divide and conquer algorithm.

!> SVD algorithm. It's called after the secular equation is solved.

!>         < 0: if INFO = -i, the i-th argument had an illegal value.

!> Detailed Description:
!> SLASD6 is a subroutine used in the divide and conquer algorithm for the
!> Singular Value Decomposition (SVD). It plays a role in updating the singular
!> values and vectors after the secular equation has been solved.
!>
!> The routine takes the current singular values (in D) and a deflation-adjusted
!> updating vector (in Z) as input. It then computes the new, updated singular
!> values and updates the deflation-adjusted vector Z. This process involves
!> applying Givens rotations.
!>
!> Specifically:
!> - The input array D contains the old singular values, sorted in ascending order.
!>   After the subroutine runs, D will contain the new singular values, also
!>   sorted in ascending order.
!> - The first K elements of the updated D array represent the singular values
!>   of the deflated matrix. Deflation is a technique used in the divide and
!>   conquer SVD algorithm to reduce the problem size by removing components
!>   that are relatively small or have converged.
!> - The array Z holds the components of the deflation-adjusted updating row
!>   vector. This vector is essential for updating the singular vectors of the
!>   original matrix, which is typically done in a subsequent step.
!> - The parameters ICMPNN and L are described as having specific roles and
!>   values (ICMPNN=0, L=2) in the context of the algorithm, suggesting that
!>   this subroutine is invoked at a particular stage of the divide and conquer
!>   process.
!> - The INFO integer output parameter indicates the success of the operation.
!>   0 means success. A negative value indicates an error in the input
!>   arguments. A positive value (specifically 1) signals that convergence
!>   was not achieved for one or more singular values.
!> - WORK and IWORK are auxiliary arrays used for temporary storage during
!>   computations.
!>
!> Overall, SLASD6 is a crucial component for refining the singular values and
!> preparing for the update of singular vectors within the SVD divide and conquer
!> framework.
