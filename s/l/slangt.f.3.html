real function slangt (norm, n, dl, d, du)
SLANGT تُعيد قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة ثلاثية عامة.

توثيق الوظيفة/الإجراء الفرعي

real function slangt (character norm, integer n, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du)

SLANGT تُعيد قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة ثلاثية عامة.

الغرض:

!>
!> SLANGT  تُعيد قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة ثلاثية حقيقية A.
!>

تُعيد

SLANGT 
!>
!>    SLANGT = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تشير إلى  المعيار الواحد لمصفوفة (أقصى مجموع أعمدة)،
!> normI  تشير إلى  المعيار اللانهائي  لمصفوفة (أقصى مجموع صفوف) و
!> normF  تشير إلى  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          تحدد القيمة التي سيتم إرجاعها في SLANGT كما هو موضح
!>          أعلاه.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين SLANGT
!>          إلى صفر.
!>

DL

!>          DL is REAL array, dimension (N-1)
!>          عناصر المصفوفة الفرعية (n-1) لـ A.
!>

D

!>          D is REAL array, dimension (N)
!>          العناصر القطرية لـ A.
!>

DU

!>          DU is REAL array, dimension (N-1)
!>          عناصر المصفوفة الفوقية (n-1) لـ A.
!>
