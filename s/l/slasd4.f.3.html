توثيق الوظيفة/الروتين الفرعي

subroutine slasd4 (integer n, integer i, real, dimension( * ) d, real, dimension( * ) z, real, dimension( * ) delta, real rho, real sigma, real, dimension( * ) work, integer info)

SLASD4 تحسب الجذر التربيعي للقيمة الذاتية المحدثة i لمصفوفة قطرية موجبة متناظرة مع تعديل رتبة واحد. تستخدم بواسطة sbdsdc.

الغرض:

!>
!> هذا الروتين الفرعي يحسب الجذر التربيعي للقيمة الذاتية المحدثة I
!> لمصفوفة قطرية موجبة متناظرة مع تعديل رتبة واحد إلى
!> مصفوفة قطرية موجبة تكون مدخلاتها معطاة كمربعات
!> المدخلات المقابلة في المصفوفة d، و
!>
!>        0 <= D(i) < D(j)  for  i < j
!>
!> و RHO > 0. يتم ترتيب هذا بواسطة الروتين المستدعي، ولا يوجد
!> خسارة في التعميم. نظام الرتبة الواحدة المعدل هو بالتالي
!>
!>        diag( D ) * diag( D ) +  RHO * Z * Z_transpose.
!>
!> حيث نفترض أن المعيار الإقليدي لـ Z هو 1.
!>
!> تتكون الطريقة من تقريب الدوال الكسرية في المعادلة العلمانية
!> بواسطة دوال كسرية استيفاء أبسط.
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>         طول جميع المصفوفات.
!>

I

!>          I هو عدد صحيح (INTEGER)
!>         فهرس القيمة الذاتية المطلوب حسابها.  1 <= I <= N.
!>

D

!>          D هي مصفوفة حقيقية (REAL array)، البعد ( N )
!>         القيم الذاتية الأصلية.  يفترض أنها مرتبة،
!>         0 <= D(I) < D(J)  for I < J.
!>

Z

!>          Z هي مصفوفة حقيقية (REAL array)، البعد ( N )
!>         مكونات المتجه المحدث.
!>

DELTA

!>          DELTA هي مصفوفة حقيقية (REAL array)، البعد ( N )
!>         إذا كان N .ne. 1، تحتوي DELTA على (D(j) - sigma_I) في المكون j.
!>         إذا كان N = 1، فإن DELTA(1) = 1. تحتوي المصفوفة DELTA
!>         على المعلومات اللازمة لبناء المتجهات الذاتية (المنفردة).
!>

RHO

!>          RHO هو عدد حقيقي (REAL)
!>         المقياس في صيغة التحديث المتناظرة.
!>

SIGMA

!>          SIGMA هو عدد حقيقي (REAL)
!>         سيجما_I المحسوبة، القيمة الذاتية المحدثة I.
!>

WORK

!>          WORK هي مصفوفة حقيقية (REAL array)، البعد ( N )
!>         إذا كان N .ne. 1، تحتوي WORK على (D(j) + sigma_I) في المكون j.
!>         إذا كان N = 1، فإن WORK( 1 ) = 1.
!>

INFO

!>          INFO هو عدد صحيح (INTEGER)
!>         = 0:  خروج ناجح
!>         > 0:  إذا كان INFO = 1، فشلت عملية التحديث.
!>

المعاملات الداخلية:

!>  المتغير المنطقي ORGATI (origin-at-i؟) يستخدم للتمييز
!>  ما إذا كان D(i) أو D(i+1) يعامل كنقطة الأصل.
!>
!>            ORGATI = .true.    نقطة الأصل عند i
!>            ORGATI = .false.   نقطة الأصل عند i+1
!>
!>  المتغير المنطقي SWTCH3 (switch-for-3-poles؟) يستخدم لملاحظة
!>  ما إذا كنا نعمل مع ثلاثة أقطاب!
!>
!>  MAXIT هو الحد الأقصى لعدد التكرارات المسموح بها لكل
!>  قيمة ذاتية.
!>
