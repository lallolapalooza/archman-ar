الوظائف/الروتينات الفرعية


real function slange (norm, m, n, a, lda, work)
SLANGE تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة مستطيلة عامة.

توثيق الوظيفة/الروتين الفرعي

real function slange (character norm, integer m, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

SLANGE تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة مستطيلة عامة.

الغرض:

!>
!> SLANGE  تُرجع قيمة المعيار واحد،  أو معيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو  العنصر ذي القيمة المطلقة الأكبر  لمصفوفة
!> حقيقية A.
!>

تُرجع

SLANGE 
!>
!>    SLANGE = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى  معيار المصفوفة واحد (أقصى مجموع أعمدة)،
!> normI  يشير إلى  معيار المصفوفة اللانهائي  (أقصى مجموع صفوف) و
!> normF  يشير إلى  معيار فروبينيوس للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة المراد إرجاعها في SLANGE كما هو موضح
!>          أعلاه.
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A.  M >= 0.  عندما M = 0،
!>          يتم تعيين SLANGE إلى صفر.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة A.  N >= 0.  عندما N = 0،
!>          يتم تعيين SLANGE إلى صفر.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          المصفوفة A بحجم m × n.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(M,1).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= M عندما NORM = 'I'.  بخلاف ذلك، لا يتم
!>          الرجوع إلى WORK.
!>
