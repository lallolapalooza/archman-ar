الغرض:

!>
!>    SLATMT تولد مصفوفات عشوائية بقيم فردية محددة
!>    (أو متماثلة/هيرميتية بقيم ذاتية محددة)
!>    لاختبار برامج LAPACK.
!>
!>    تعمل SLATMT عن طريق تطبيق التسلسل التالي من
!>    العمليات:
!>
!>      تعيين القطر إلى D، حيث يمكن أن تكون D مدخلة أو
!>         محسوبة وفقًا لـ MODE، COND، DMAX، و SYM
!>         كما هو موضح أدناه.
!>
!>      توليد مصفوفة ذات هيكل نطاق مناسب، بواسطة واحدة
!>         من طريقتين:
!>
!>      الطريقة أ:
!>          توليد مصفوفة كثيفة M x N بضرب D من اليسار
!>              ومن اليمين بمصفوفات وحدوية عشوائية، ثم:
!>
!>          تقليل عرض النطاق وفقًا لـ KL و KU، باستخدام
!>          تحويلات هاوسهولدر.
!>
!>      الطريقة ب:
!>          تحويل مصفوفة عرض النطاق صفري (أي قطرية) إلى
!>              مصفوفة عرض نطاق واحد باستخدام دورانات جيفينز،
!>              العناصر خارج النطاق مرة أخرى، تمامًا مثل QR؛ ثم
!>              تحويل عرض النطاق واحد إلى عرض نطاق اثنان، إلخ.
!>              لاحظ أنه لعروض النطاق الصغيرة بشكل معقول (مقارنة بـ
!>              M و N) يتطلب هذا تخزينًا أقل، حيث لا يتم إنشاء مصفوفة كثيفة.
!>              أيضًا، للمصفوفات المتماثلة، يتم إنشاء مثلث واحد فقط.
!>
!>      يتم اختيار الطريقة أ إذا كان عرض النطاق جزءًا كبيرًا من
!>          رتبة المصفوفة، و LDA على الأقل M (لذلك يمكن تخزين مصفوفة كثيفة.)
!>          يتم اختيار الطريقة ب إذا كان عرض النطاق
!>          صغيرًا (< 1/2 N للمتماثلة، < .3 N+M لغير
!>          المتماثلة)، أو LDA أقل من M وليس أقل من
!>          عرض النطاق.
!>
!>      تعبئة المصفوفة إذا رغبت في ذلك. الخيارات المحددة بواسطة PACK هي:
!>         لا يوجد تعبئة
!>         تصفير النصف العلوي (إذا كانت متماثلة)
!>         تصفير النصف السفلي (إذا كانت متماثلة)
!>         تخزين النصف العلوي عموديًا (إذا كانت متماثلة أو
!>               مثلثية علوية)
!>         تخزين النصف السفلي عموديًا (إذا كانت متماثلة أو
!>               مثلثية سفلية)
!>         تخزين المثلث السفلي بتنسيق نطاق (إذا كانت متماثلة
!>               أو مثلثية سفلية)
!>         تخزين المثلث العلوي بتنسيق نطاق (إذا كانت متماثلة
!>               أو مثلثية علوية)
!>         تخزين المصفوفة بأكملها بتنسيق نطاق
!>      إذا تم اختيار الطريقة ب، وتم تحديد تنسيق النطاق، فسيتم
!>         إنشاء المصفوفة بتنسيق النطاق، لذلك لن تكون هناك حاجة لإعادة التعبئة.
!>

!>

DIST

!>          DIST هو حرف (CHARACTER*1)
!>           عند الإدخال، تحدد DIST نوع التوزيع المستخدم
!>           لتوليد القيم الذاتية/الفردية العشوائية.
!>           'U' => منتظم (UNIFORM) (0, 1) ( 'U' لـ uniform )
!>           'S' => منتظم (UNIFORM) (-1, 1) ( 'S' للمتماثل )
!>           'N' => طبيعي (NORMAL) (0, 1) ( 'N' للطبيعي )
!>           لم يتم تعديله.

!>          ISEED هو مصفوفة أعداد صحيحة (INTEGER array)، حجمها (4)
!>           عند الإدخال، يحدد ISEED بذرة مولد الأرقام
!>           العشوائية. يجب أن تكون بين 0 و 4095 شاملة،
!>           ويجب أن يكون ISEED(4) فرديًا. يستخدم مولد الأرقام
!>           العشوائية تسلسل خطي تآلفي محدود بأعداد صحيحة صغيرة،
!>           لذلك يجب أن ينتج أرقامًا عشوائية مستقلة عن الجهاز.
!>           تتغير قيم ISEED عند الخروج، ويمكن استخدامها في
!>           الاستدعاء التالي لـ SLATMT
!>           للمتابعة بنفس تسلسل الأرقام العشوائية.
!>           تم تعديله عند الخروج.
!>

SYM

!>          SYM هو حرف (CHARACTER*1)
!>           إذا كانت SYM='S' أو 'H'، تكون المصفوفة المولدة متماثلة، مع
!>             قيم ذاتية محددة بواسطة D، COND، MODE، و DMAX؛ يمكن أن تكون
!>             موجبة، سالبة، أو صفرية.
!>           إذا كانت SYM='P'، تكون المصفوفة المولدة متماثلة، مع
!>             قيم ذاتية (= قيم فردية) محددة بواسطة D، COND،
!>             MODE، و DMAX؛ لن تكون سالبة.
!>           إذا كانت SYM='N'، تكون المصفوفة المولدة غير متماثلة، مع
!>             قيم فردية محددة بواسطة D، COND، MODE، و DMAX؛
!>             لن تكون سالبة.
!>           لم يتم تعديله.
!>

D

!>          D هي مصفوفة حقيقية (REAL array)، حجمها ( MIN( M , N ) )
!>           تستخدم هذه المصفوفة لتحديد القيم الفردية أو
!>           الذاتية لـ A (انظر SYM، أعلاه.) إذا كان MODE=0، فمن المفترض أن
!>           تحتوي D على القيم الذاتية/الفردية، وإلا فسيتم
!>           حسابها وفقًا لـ MODE، COND، و DMAX،
!>           ووضعها في D.
!>           تم تعديله إذا كان MODE غير صفري.
!>

MODE

!>          MODE هو عدد صحيح (INTEGER)
!>           عند الإدخال، يصف هذا كيفية تحديد القيم الفردية/الذاتية:
!>           MODE = 0 يعني استخدام D كمدخل
!>
!>           MODE = 1 يضع D(1)=1 و D(2:RANK)=1.0/COND
!>           MODE = 2 يضع D(1:RANK-1)=1 و D(RANK)=1.0/COND
!>           MODE = 3 يضع D(I)=COND**(-(I-1)/(RANK-1))
!>
!>           MODE = 4 يضع D(i)=1 - (i-1)/(N-1)*(1 - 1/COND)
!>           MODE = 5 يضع D لأرقام عشوائية في النطاق
!>                    ( 1/COND , 1 ) بحيث تكون لوغاريتماتها
!>                    موزعة بشكل منتظم.
!>           MODE = 6 يضع D لأرقام عشوائية من نفس التوزيع
!>                    مثل بقية المصفوفة.
!>           MODE < 0 له نفس المعنى مثل ABS(MODE)، باستثناء أن
!>              ترتيب عناصر D يتم عكسه.
!>           لذلك، إذا كان MODE موجبًا، فإن D تحتوي على عناصر تتراوح من
!>              1 إلى 1/COND، وإذا كان سالبًا، من 1/COND إلى 1،
!>           إذا كانت SYM='S' أو 'H'، وكان MODE ليس 0 أو 6 أو -6، فسيتم
!>              ضرب عناصر D أيضًا بإشارة عشوائية (أي +1 أو -1.)
!>           لم يتم تعديله.
!>

COND

!>          COND هو رقم حقيقي (REAL)
!>           عند الإدخال، يستخدم كما هو موضح تحت MODE أعلاه.
!>           إذا تم استخدامه، يجب أن يكون >= 1. لم يتم تعديله.
!>

DMAX

!>          DMAX هو رقم حقيقي (REAL)
!>           إذا كان MODE ليس -6 أو 0 أو 6، فسيتم قياس محتويات D، كما
!>           تم حسابها وفقًا لـ MODE و COND، بواسطة
!>           DMAX / max(abs(D(i)))؛ وبالتالي، ستكون أكبر قيمة ذاتية أو
!>           فردية مطلقة (وهي المعيار) هي abs(DMAX).
!>           لاحظ أن DMAX ليس بالضرورة موجبًا: إذا كان DMAX سالبًا
!>           (أو صفرًا)، فسيتم قياس D بعدد سالب (أو صفر).
!>           لم يتم تعديله.
!>

RANK

!>          RANK هو عدد صحيح (INTEGER)
!>           رتبة المصفوفة المراد توليدها للأوضاع 1، 2، 3 فقط.
!>           D( RANK+1:N ) = 0.
!>           لم يتم تعديله.
!>

!>           يجب أن يساوي KL قيمة KU إذا كانت المصفوفة متماثلة.
!>           لم يتم تعديله.
!>

NAME

slatmt - Latent test matrix generator

SYNOPSIS

SUBROUTINE SLATMT(
&     M, N, DIST,       D,      TYPE,       SYM,        PACK,
&     DL, DR,             A,      LDA,        WORK,       INFO )

Parameters:

  CHARACTER*1           DIST
  CHARACTER*1           TYPE
  CHARACTER*1           SYM
  CHARACTER*1           PACK
  REAL                  D( * )
  REAL                  DL( * )
  REAL                  DR( * )
  REAL                  A( LDA, * )
  INTEGER               M
  INTEGER               N
  INTEGER               LDA
  REAL                  WORK( * )
  INTEGER               INFO

Function/Subroutine Documentation

SLATMT generates test matrices for the LAPACK routines. The matrix is generated in full, unpacked form, and then packed if PACK is specified.

Arguments:

M

M is INTEGER

The number of rows of the matrix A.

Not modified.

N

N is INTEGER

The number of columns of the matrix A.

Not modified.

DIST

DIST is CHARACTER*1

Specifies the form of the distribution of random numbers:

  • 'U' => uniform distribution
  • 'N' => normally distributed

Not modified.

D

D is REAL array, dimension ( N )

Not modified.

TYPE

TYPE is CHARACTER*1

Specifies the type of matrix A:

  • 'S' => sparse
  • 'H' => upper hessenberg
  • 'T' => upper triangular
  • 'B' => lower bandwidth
  • 'P' => lower triangular
  • 'O' => orthogonal
  • 'A' => general

Not modified.

SYM

SYM is CHARACTER*1

Specifies the properties of the matrix A:

  • 'N' => Not symmetric
  • 'S' => Symmetric
  • 'H' => Upper hessenberg
  • 'P' => Permutation matrix

Not modified.

PACK

PACK is CHARACTER*1

This specifies packing of matrix as follows:

  • 'N' => no packing
  • 'U' => zero out all subdiagonal entries (if symmetric)
  • 'L' => zero out all superdiagonal entries (if symmetric)
  • 'C' => store the upper triangle columnwise
    (only if the matrix is symmetric or upper triangular)
  • 'R' => store the lower triangle columnwise
    (only if the matrix is symmetric or lower triangular)
  • 'B' => store the lower triangle in band storage scheme
    (only if matrix symmetric or lower triangular)
  • 'Q' => store the upper triangle in band storage scheme
    (only if matrix symmetric or upper triangular)
  • 'Z' => store the entire matrix in band storage scheme
    (pivoting can be provided for by using this
    option to store A in the trailing rows of
    the allocated storage)

Using these options, the various LAPACK packed and banded
storage schemes can be obtained:

GB               - use 'Z'
PB, SB or TB     - use 'B' or 'Q'
PP, SP or TP     - use 'C' or 'R'

If two calls to SLATMT differ only in the PACK parameter,
they will generate mathematically equivalent matrices.

Not modified.

A

A is REAL array, dimension ( LDA, N )

On exit A is the desired test matrix. A is first generated
in full (unpacked) form, and then packed, if so specified
by PACK. Thus, the first M elements of the first N
columns will always be modified. If PACK specifies a
packed or banded storage scheme, all LDA elements of the
first N columns will be modified; the elements of the
array which do not correspond to elements of the generated
matrix are set to zero.

Modified.

LDA

LDA is INTEGER

LDA specifies the first dimension of A as declared in the
calling program. If PACK='N', 'U', 'L', 'C', or 'R', then
LDA must be at least M. If PACK='B' or 'Q', then LDA must
be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
If PACK='Z', LDA must be large enough to hold the packed
array: MIN( KU, N-1) + MIN( KL, M-1) + 1.

Not modified.

WORK

WORK is REAL array, dimension ( 3*MAX( N , M ) )

Workspace.

Modified.

INFO

INFO is INTEGER

Error code. On exit, INFO will be set to one of the
following values:

  0 => normal return
 -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
 -2 => N negative
 -3 => DIST illegal string
 -5 => SYM illegal string
 -7 => MODE not in range -6 to 6
 -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
-10 => KL negative
-11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
-12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
          or PACK='C' or 'Q' and SYM='N' and KL is not zero;
          or PACK='R' or 'B' and SYM='N' and KU is not zero;
          or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
          N.
-14 => LDA is less than M, or PACK='Z' and LDA is less than
          MIN(KU,N-1) + MIN(KL,M-1) + 1.
  1 => Error return from SLATM7
  2 => Cannot scale to DMAX (max. sing. value is 0)
  3 => Error return from SLAGGE or SLAGSY
