SLAPD OVERLAYS

NAME

slapd.overlays - slapd configuration file syntax

DESCRIPTION

The slapd daemon implements an overlay mechanism, which allows for dynamic modification of the backend behavior. Overlays are configured per-database, and are chained together in a stack. Configuration is done via the OpenLDAP configuration file, typically located at /etc/openldap/slapd.conf or in the directory structure defined by the olcDatabase directive.

OpenLDAP Software is derived from the University of Michigan LDAP 3.3 Release.
