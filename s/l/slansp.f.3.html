SLANSP تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة مقدمة في شكل مكدس.

توثيق الوظيفة/الإجراء الفرعي

real function slansp (character norm, character uplo, integer n, real, dimension( * ) ap, real, dimension( * ) work)

SLANSP تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية مقدمة في شكل مكدس.

الغرض:

!>
!> SLANSP  تُرجع قيمة المعيار الواحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة
!> حقيقية A، مقدمة في شكل مكدس.
!>

تُرجع

SLANSP 
!>
!>    SLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يمثل المعيار الواحد لمصفوفة (أقصى مجموع أعمدة)،
!> normI  يمثل المعيار اللانهائي لمصفوفة (أقصى مجموع صفوف) و
!> normF  يمثل معيار فروبينيوس لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابت.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في SLANSP كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي المثلثي للمصفوفة
!>          المتماثلة A مقدمًا.
!>          = 'U':  يتم تقديم الجزء العلوي المثلثي لـ A
!>          = 'L':  يتم تقديم الجزء السفلي المثلثي لـ A
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين SLANSP
!>          إلى صفر.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          الجزء العلوي أو السفلي المثلثي للمصفوفة المتماثلة A، مكدس
!>          في عمود في مصفوفة خطية.  يتم تخزين العمود j للمصفوفة A
!>          في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'؛ بخلاف ذلك،
!>          لا يتم الإشارة إلى WORK.
!>
