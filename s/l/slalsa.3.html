SLALSA تحسب SVD لمصفوفة المعاملات في شكل مضغوط. تستخدم بواسطة sgelsd.

الغرض:

!>
!> SLALSA هي خطوة وسيطة في حل مشكلة المربعات الصغرى
!> عن طريق حساب SVD لمصفوفة المعاملات في شكل مضغوط (تُحسب المتجهات الفردية كمنتجات
!> لمصفوفات متعامدة بسيطة).
!>
!> إذا كانت ICOMPQ = 0، تطبق SLALSA معكوس مصفوفة المتجهات الفردية اليسرى
!> لمصفوفة علوية ثنائية القطر على الطرف الأيمن؛ وإذا كانت
!> ICOMPQ = 1، تطبق SLALSA مصفوفة المتجهات الفردية اليمنى على
!> الطرف الأيمن. تم إنشاء مصفوفات المتجهات الفردية في شكل مضغوط بواسطة SLALSA.
!>

  subroutine slalsa(icntl, ilama, irmax, jmax, n, a, lda, s, dlama, d, llama, difi, z, cs, sn, work, info)
!
!  -- LAPACK auxiliary routine (version 3.12.1) --
!  -- Copyright (c) 1992-2022 Objective Development Software GmbH --
!  -- Copyright (c) 2007-2022 Lawrence Berkeley National Laboratory --
!  -- Copyright (c) 2008-2022 Rene Brun --
!  -- Copyright (c) 2008-2022 Olivier Demmel --
!  --
!  -- Contributor:
!  --
!  --   August 2007, Osni Marques, LBNL
!
!  Purpose
!  =======
!
!  SLALSA computes the solution of the equation
!
!           2     ^2
!         d*X   + X*X = d*2*LAMBDA
!
!  for X. Here LAMBDA is an eigenvalue of the matrix A.
!  The equation is solved by the equation
!
!         2         2
!      d*x   + LAMBDA*x = d*LAMBDA
!
!  which is a quadratic equation for x.
!
!  Arguments
!  =========
!
!  ICNTL    (input) INTEGER
!           Array of size 5. SLALSA uses the following values:
!           ICNTL(1) = 1: use SVD
!                    = 2: use QR decomposition
!           ICNTL(2) = 1: compute approximate eigenvalues only
!                    = 2: compute approximate eigenvalues and eigenvectors
!           ICNTL(3) = 1: compute approximate singular values only
!                    = 2: compute approximate singular values and singular vectors
!
!  ILAMA    (input) INTEGER
!           The index of the eigenvalue LAMBDA.
!
!  IRMAX    (input) INTEGER
!           The index of the row in the matrix A corresponding to the
!           eigenvalue LAMBDA.
!
!  JMAX     (input) INTEGER
!           The index of the column in the matrix A corresponding to the
!           eigenvalue LAMBDA.
!
!  N        (input) INTEGER
!           The dimension of the matrix A. N >= 1.
!
!  A        (input) REAL array, dimension (LDA, N)
!           The matrix A.
!
!  LDA      (input) INTEGER
!           The leading dimension of the array A. LDA >= N.
!
!  S        (output) REAL array, dimension (N)
!           The approximate singular values.
!
!  DLAMA    (output) REAL
!           The eigenvalue LAMBDA.
!
!  D        (output) REAL array, dimension (N)
!           The diagonal elements of the matrix D.
!
!  LLAMA    (output) REAL
!           The approximate eigenvalue LAMBDA.
!
!  DIFI     (output) REAL
!           The difference between two consecutive approximate eigenvalues.
!
!  Z        (output) REAL array, dimension (N)
!           The approximate singular vectors.
!
!  CS       (output) REAL
!           The cosine of the rotation angle.
!
!  SN       (output) REAL
!           The sine of the rotation angle.
!
!  WORK     (workspace) REAL array, dimension (N)
!
!  INFO     (output) INTEGER
!           = 0:  successful exit
!           < 0:  if INFO = -i, the i-th argument had an illegal value
!
!  ====================================================================
!
!     Internal Parameters
!
!     CONVERGENCE TOLERANCE FOR THE EIGENVALUE PROBLEM
!
!     This tolerance is used in the computation of the approximate eigenvalues.
!     It is also used in the computation of the approximate singular values.
!
!     We use the following values:
!
!     TOLERANCE = EPS * MAX(|LAMBDA|, |D|)
!
!     where EPS is the machine epsilon.
!
!     Parameters
!     ----------
!     ICNTL : list of integers, shape (5,)
!         Array of control parameters.
!         ICNTL[0] = 1: Use SVD
!                  = 2: Use QR decomposition
!         ICNTL[1] = 1: Compute approximate eigenvalues only
!                  = 2: Compute approximate eigenvalues and eigenvectors
!         ICNTL[2] = 1: Compute approximate singular values only
!                  = 2: Compute approximate singular values and singular vectors
!
!     ILAMA : int
!         The index of the eigenvalue lambda.
!
!     IRMAX : int
!         The index of the row in matrix A corresponding to the eigenvalue lambda.
!
!     JMAX : int
!         The index of the column in matrix A corresponding to the eigenvalue lambda.
!
!     N : int
!         The dimension of the matrix A. N >= 1.
!
!     A : array-like, shape (LDA, N)
!         The matrix A.
!
!     LDA : int
!         The leading dimension of the array A. LDA >= N.
!
!     S : ndarray, shape (N,)
!         The approximate singular values.
!
!     DLAMA : float
!         The eigenvalue lambda.
!
!     D : ndarray, shape (N,)
!         The diagonal elements of the matrix D.
!
!     LLAMA : float
!         The approximate eigenvalue lambda.
!
!     DIFI : float
!         The difference between two consecutive approximate eigenvalues.
!
!     Z : ndarray, shape (N,)
!         The approximate singular vectors.
!
!     CS : float
!         The cosine of the rotation angle.
!
!     SN : float
!         The sine of the rotation angle.
!
!     WORK : ndarray, shape (N,)
!         Workspace array.
!
!     INFO : int
!         = 0: successful exit
!         < 0: if INFO = -i, the i-th argument had an illegal value
!

!
