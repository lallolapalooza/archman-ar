real function slansp (norm, uplo, n, ap, work)
SLANSP تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة مقدمة في شكل مضغوط.

توثيق الوظيفة/الروتين الفرعي

real function slansp (character norm, character uplo, integer n, real, dimension( * ) ap, real, dimension( * ) work)

SLANSP تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية مقدمة في شكل مضغوط.

الغرض:

!>
!> SLANSP  تُرجع قيمة المعيار واحد،  أو معيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو  العنصر ذي القيمة المطلقة الأكبر  لمصفوفة
!> متماثلة حقيقية A،  مقدمة في شكل مضغوط.
!>

تُرجع

SLANSP 
!>
!>    SLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يمثل  المعيار واحد لمصفوفة (مجموع الأعمدة الأقصى)،
!> normI  يمثل  المعيار اللانهائي  لمصفوفة (مجموع الصفوف الأقصى) و
!> normF  يمثل  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة المراد إرجاعها في SLANSP كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي المثلثي للمصفوفة
!>          المتماثلة A مقدمًا.
!>          = 'U':  الجزء العلوي المثلثي لـ A مقدم
!>          = 'L':  الجزء السفلي المثلثي لـ A مقدم
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين SLANSP
!>          إلى الصفر.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          الجزء العلوي أو السفلي المثلثي للمصفوفة المتماثلة A، مضغوط
!>          عمودياً في مصفوفة خطية.  يتم تخزين العمود j للمصفوفة A
!>          في المصفوفة AP كالتالي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I' أو '1' أو 'O'؛ بخلاف ذلك،
!>          لا تتم الإشارة إلى WORK.
!>
