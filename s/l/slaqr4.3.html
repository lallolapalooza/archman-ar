 COMPLEX*16 SD( * )

The subroutine SLAQR4 is a Fortran subroutine.

Function/Subroutine Documentation

This subroutine is part of the LAPACK library, specifically designed for solving the nonsymmetric tridiagonal eigenvalue problem. It calculates eigenvalues and optionally eigenvectors of a complex upper Hessenberg matrix that has been reduced to quasi-upper triangular form.

The main purpose of SLAQR4 is to apply one or more steps of the implicitly shifted QR algorithm to a selected submatrix of the original Hessenberg matrix. This is a key component in the overall process of finding all eigenvalues and eigenvectors of the original matrix.

Arguments:

WANTT (input) CHARACTER*1

Specifies whether the Schur factorization is desired.

If WANTT = ‘T’, the Schur form T is updated.

If WANTT = ‘N’, the Schur form is not computed.

WANTZ (input) CHARACTER*1

Specifies whether the eigenvectors are desired.

If WANTZ = ‘V’, the eigenvectors are computed.

If WANTZ = ‘N’, the eigenvectors are not computed.

N (input) INTEGER

The order of the upper Hessenberg matrix.

ILO (input) INTEGER

The starting row and column of the submatrix for which eigenvalues and eigenvectors are to be computed.

IHI (input) INTEGER

The ending row and column of the submatrix for which eigenvalues and eigenvectors to be computed.

SCALE (input/output) REAL array of dimension N

The scaling factors applied to each row of the original matrix. This argument is used to prevent overflow or underflow during the computation. It is modified by the subroutine.

SD (input/output) COMPLEX*16 array of dimension (N*N)

This array contains the quasi-upper triangular Schur factorization of the matrix and its corresponding eigenvectors. It is modified by the subroutine during the computation.

Details:

SLAQR4 is called by the subroutines SLAQR0 and SLAQR1 to compute the eigenvalues and optionally eigenvectors of a complex upper Hessenberg matrix. It applies one or more steps of the QR algorithm to a submatrix of the original matrix. The subroutine uses aggressive early deflation to reduce the size of the subproblem whenever possible.

The implementation of SLAQR4 is based on the work of Braman, Byers, and Mathias, which introduced the multi-shift QR algorithm with aggressive early deflation.

The subroutine returns the eigenvalues of the submatrix in the diagonal elements of the array SD. If WANTZ is ‘V’, it also returns the corresponding eigenvectors in the columns of the array SD.

The scaling factors in the array SCALE are used to ensure that intermediate computations do not overflow or underflow. These scaling factors are applied to the rows of the original matrix.

The subroutine uses blocking and loop unrolling to achieve good performance on modern computer architectures.

Example Usage:

Consider an upper Hessenberg matrix H. SLAQR4 would typically be called by a higher-level routine that manages the deflation process and determines the subproblems to be solved. The initial call might look like:

 CALL SLAQR4( 'T', 'V', N, ILO, IHI, SCALE, SD )

This call requests both the Schur form and the eigenvectors for the submatrix defined by ILO and IHI. The array SD would be initialized with the submatrix H, and SCALE would be initialized with appropriate scaling factors. After the call, SD would contain the computed eigenvalues and eigenvectors.

Notes:

The routine assumes that the input matrix is in upper Hessenberg form. If the matrix is not in this form, the results will be incorrect.

The use of COMPLEX*16 indicates that the subroutine operates on double-precision complex numbers.

The array SD is expected to be dimensioned appropriately, typically N*N, to hold the matrix and its eigenvectors.

The algorithm may not converge for certain pathological cases, although this is rare in practice.

The subroutine should not be called directly unless the user is familiar with the internals of the QR algorithm and the LAPACK implementation.
