SLA_GBRCOND يقدر رقم الشرط لـ Skeel لمصفوفة عامة ذات نطاق.

توثيق الوظيفة/الإجراء الفرعي

real function sla_gbrcond (character trans, integer n, integer kl, integer ku, real, dimension( ldab, * ) ab, integer ldab, real, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, integer cmode, real, dimension( * ) c, integer info, real, dimension( * ) work, integer, dimension( * ) iwork)

SLA_GBRCOND يقدر رقم الشرط لـ Skeel لمصفوفة عامة ذات نطاق.

الغرض:

!>
!>    SLA_GBRCOND يقدر رقم الشرط لـ Skeel لـ op(A) * op2(C)
!>    حيث يتم تحديد op2 بواسطة CMODE على النحو التالي
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    يتم حساب رقم الشرط لـ Skeel  cond(A) = norminf( |inv(A)||A| )
!>    عن طريق حساب عوامل القياس R بحيث يكون
!>    diag(R)*A*op2(C) موزون الصف ويتم حساب رقم الشرط القياسي
!>    للمعيار اللانهائي.
!>

المعلمات

TRANS 
!>          TRANS is CHARACTER*1
!>     يحدد شكل نظام المعادلات:
!>       = 'N':  A * X = B     (بدون تبديل)
!>       = 'T':  A**T * X = B  (تبديل)
!>       = 'C':  A**H * X = B  (تبديل مترافق = تبديل)
!>

N

!>          N is INTEGER
!>     عدد المعادلات الخطية، أي رتبة
!>     المصفوفة A.  N >= 0.
!>

KL

!>          KL is INTEGER
!>     عدد الأقطار الفرعية داخل نطاق A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>     عدد الأقطار الفائقة داخل نطاق A.  KU >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>     عند الدخول، المصفوفة A بتخزين نطاق، في الصفوف 1 إلى KL+KU+1.
!>     يتم تخزين العمود j من A في العمود j من
!>     المصفوفة AB كما يلي:
!>     AB(KU+1+i-j,j) = A(i,j) for max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB is INTEGER
!>     البعد الرئيسي للمصفوفة AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB is REAL array, dimension (LDAFB,N)
!>     تفاصيل التحلل LU لمصفوفة النطاق A، كما
!>     تم حسابها بواسطة SGBTRF.  يتم تخزين U كمصفوفة نطاق مثلثة عليا
!>     مع KL+KU أقطار فائقة في الصفوف 1 إلى KL+KU+1،
!>     ويتم تخزين المضاعفات المستخدمة أثناء التحلل
!>     في الصفوف KL+KU+2 إلى 2*KL+KU+1.
!>

LDAFB

!>          LDAFB is INTEGER
!>     البعد الرئيسي للمصفوفة AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>     مؤشرات المحور من التحلل A = P*L*U
!>     كما تم حسابها بواسطة SGBTRF؛ تم تبديل الصف i من المصفوفة
!>     مع الصف IPIV(i).
!>

CMODE

!>          CMODE is INTEGER
!>     يحدد op2(C) في الصيغة op(A) * op2(C) على النحو التالي:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C is REAL array, dimension (N)
!>     المتجه C في الصيغة op(A) * op2(C).
!>

INFO

!>          INFO is INTEGER
!>       = 0:  انتهاء ناجح.
!>     i > 0:  المعلمة i غير صالحة.
!>

WORK

!>          WORK is REAL array, dimension (5*N).
!>     مساحة العمل.
!>

IWORK

!>          IWORK is INTEGER array, dimension (N).
!>     مساحة العمل.
!>
