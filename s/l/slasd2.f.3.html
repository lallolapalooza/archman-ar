NAME

slasd2 - SLASD2 computes the initial left and right singular vectors for the first block in the divide and conquer SVD computation.

Function/Subroutine Documentation

Function/Subroutine Signature

SUBROUTINE SLASD2(NL, NR, SQRE, LWORK, LWORKMIN, LWORKOPT, LWORKGIVEN, A, LDA,
                  S, U, LDU, V, LDV, VT, LDVT, RHS, NGUESS, HOWMNY,
                  FINISH, MXITER, RADIX, ALPHA, BETA, INFO)

Purpose

This subroutine computes the initial left and right singular vectors for the first block in the divide and conquer SVD computation. It is a helper routine for SLASDQ.

Arguments

NL
INTEGER. Number of non-zero singular values in the left block.
NR
INTEGER. Number of non-zero singular values in the right block.
SQRE
REAL (KIND=RKIND). If SQRE = 1.0, the last row of A is a zero row. If SQRE = 0.0, the last row of A is a row of zeros.
LWORK
INTEGER. Workspace dimension.
LWORKMIN
INTEGER. Minimum required dimension for LWORK.
LWORKOPT
INTEGER. Optimal dimension for LWORK.
LWORKGIVEN
INTEGER. The dimension of the array LWORK supplied by the caller.
A
REAL (KIND=RKIND). Array A of size (LDA, NL+NR). Contains the initial singular values and vectors.
LDA
INTEGER. Leading dimension of the array A.
S
REAL (KIND=RKIND). Array S of size (NL+NR). Contains the singular values of the matrix.
U
REAL (KIND=RKIND). Array U of size (LDU, NL+NR). Contains the left singular vectors.
LDU
INTEGER. Leading dimension of the array U.
V
REAL (KIND=RKIND). Array V of size (LDV, NL+NR). Contains the right singular vectors.
LDV
INTEGER. Leading dimension of the array V.
VT
REAL (KIND=RKIND). Array VT of size (LDVT, NL+NR). Contains the transpose of the right singular vectors.
LDVT
INTEGER. Leading dimension of the array VT.
RHS
REAL (KIND=RKIND). Array RHS of size (NL+NR). Contains the right-hand side vectors.
NGUESS
INTEGER. Number of right-hand side vectors to be computed.
HOWMNY
CHARACTER*1. Computes all or only a subset of the right-hand side vectors.
= 'A': Computes all right-hand side vectors.
= 'S': Computes a subset of the right-hand side vectors.
FINISH
CHARACTER*1. Determines whether the current block of singular vectors is the final block.
= 'F': The current block is the final block.
= 'W': The current block is not the final block.
MXITER
INTEGER. Maximum number of iterations allowed.
RADIX
INTEGER. The radix of the machine integer.
ALPHA
REAL (KIND=RKIND). Not used.
BETA
REAL (KIND=RKIND). Not used.
INFO
INTEGER. = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: A(i,j) is NaN, where i is the row and j is the column.
