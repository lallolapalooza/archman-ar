SLAQP3RK يحسب خطوة من التفكيك المقطوع QR مع تدوير الأعمدة لمصفوفة حقيقية m-by-n A باستخدام BLAS من المستوى 3 ويستبدل مصفوفة حقيقية m-by-nrhs B بـ Q**T * B.

الغرض:

!>
!> SLAQP3RK يحسب خطوة من التفكيك المقطوع QR مع تدوير الأعمدة
!> لمصفوفة حقيقية M-by-N A block A(IOFFSET+1:M,1:N)
!> باستخدام BLAS من المستوى 3 كما يلي:
!>
!>   A * P(KB) = Q(KB) * R(KB).
!>
!> الروتين الفرعي يحاول تفكيك NB عمودًا من A بدءًا من
!> الصف IOFFSET+1 وتحديث مصفوفة الباقي باستخدام BLAS 3
!> xGEMM. يتم إرجاع عدد الأعمدة المفككة فعليًا
!> وهو أقل من NB.
!>
!> يتم تدوير الكتلة A(1:IOFFSET,1:N) وفقًا لذلك، ولكن لا يتم تفكيكها.
!>
!> الروتين الفرعي يستبدل أيضًا مصفوفة الطرف الأيمن B المخزنة
!> في A(IOFFSET+1:M,1:N+1:N+NRHS) بـ Q(KB)**T * B.
!>
!> الحالات التي يكون فيها عدد الأعمدة المفككة KB < NB:
!>
!> (1) في بعض الحالات، بسبب الإلغاءات الكارثية، لا يمكنه
!> تفكيك جميع الأعمدة NB ويحتاج إلى تحديث مصفوفة الباقي.
!> وبالتالي، فإن العدد الفعلي للأعمدة المفككة في الكتلة المرجعة
!> في KB أقل من NB. يتم إرجاع القيمة المنطقية DONE على أنها FALSE.
!> يجب أن يستمر تفكيك مصفوفة A_orig الأصلية بأكملها
!> مع الكتلة التالية.
!>
!> (2) كلما تم استيفاء معيار التوقف ABSTOL أو RELTOL،
!> يتوقف تفكيك مصفوفة A_orig الأصلية بأكملها،
!> يتم إرجاع القيمة المنطقية DONE على أنها TRUE. يتم إرجاع عدد الأعمدة المفككة
!> الذي هو أقل من NB في KB.
!>
!> (3) في حال لم يتم استخدام كلا معياري التوقف ABSTOL أو RELTOL،
!> وعندما تكون مصفوفة الباقي مصفوفة صفرية في خطوة تفكيك ما KB،
!> يتوقف تفكيك مصفوفة A_orig الأصلية بأكملها،
!> يتم إرجاع القيمة المنطقية DONE على أنها TRUE. يتم إرجاع عدد الأعمدة المفككة
!> الذي هو أقل من NB في KB.
!>
!> (4) كلما تم اكتشاف NaN في المصفوفة A أو في المصفوفة TAU،
!> يتوقف تفكيك مصفوفة A_orig الأصلية بأكملها،
!> يتم إرجاع القيمة المنطقية DONE على أنها TRUE. يتم إرجاع عدد الأعمدة المفككة
!> الذي هو أقل من NB في KB. يتم تعيين المعلمة INFO
!> إلى فهرس العمود لأول ظهور لـ NaN.
!>
!>

!>

!>              المصفوفة A بحجم M-by-N والمصفوفة B بحجم M-by-NRHS، كما في
!>
!>                                  N     NRHS
!>              array_A   =   M  [ mat_A, mat_B ]
!>
!>          عند الخروج:
!>          1. العناصر في الكتلة A(IOFFSET+1:M,1:KB) أسفل
!>             القطر، جنبًا إلى جنب مع المصفوفة TAU، تمثل
!>             المصفوفة المتعامدة Q(KB) كناتج للمنعكسات الأولية.
!>          2. الكتلة المثلثية العلوية للمصفوفة A المخزنة
!>             في A(IOFFSET+1:M,1:KB) هي العامل المثلثي الذي تم الحصول عليه.

NAME


slaqp3rk.f - Perform a rank revealing QR factorization of a
  real matrix.






SYNOPSIS


SUBROUTINE SLAQP3RK(
     M, N, NB, A, LDA, DU, DU2, SR,
     INFF, ISGN, WORK, LWORK, JPVT, INFO,
     A_orig, LWORK_orig, VN1, VN2, AUXV, F, LDF, IWORK )
  INTEGER M, N, NB, LDA, LWORK, LDF
  REAL    A( LDA, * ), DU( * ), DU2( * ), SR( * ),
          WORK( * ), A_orig( * ), VN1( * ), VN2( * ),
          AUXV( * ), F( LDF, * )
  INTEGER JPVT( * )
  INTEGER INFO
  LOGICAL INFF
  INTEGER ISGN( * )
  INTEGER LWORK_orig








Function/Subroutine Documentation


SLAQP3RK is a subroutine in LAPACK library. It performs a rank
  revealing QR factorization of a real matrix.


This subroutine is intended for the computation of the rank of a
  matrix and of the condition number estimate.


The purpose of LAPACK routine SLAQP3RK is to compute the QR
  factorization of a matrix A, possibly matrix A has been computed previously
  by another subroutine, and to compute the rank and condition number estimate
  of the matrix A.


The routine computes the factorization
  A = Q * R, where Q is an orthogonal matrix and R is an
  upper trapezoidal matrix.


Parameters:


M


!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>



N


!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>



NB


!>          NB is INTEGER
!>          The block size to be used in the algorithm.
!>



A


!>          A is REAL array, dimension (LDA, N)
!>          On entry, the M-by-N matrix A.
!>          On exit, the first K rows of A contain the upper
!>          trapezoidal factor R, and the remaining rows contain
!>          information about the Householder vectors.
!>



LDA


!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>



DU


!>          DU is REAL array, dimension (N)
!>          On exit, DU(i) is the i-th diagonal element of the
!>          upper trapezoidal factor R.
!>



DU2


!>          DU2 is REAL array, dimension (N)
!>          On exit, DU2(i) is the i-th diagonal element of the
!>          upper triangular factor R from the first i columns.
!>



SR


!>          SR is REAL array, dimension (N)
!>          On exit, SR(i) is the i-th diagonal element of the
!>          upper triangular factor R from the first i columns.
!>



INFF


!>          INFF is LOGICAL
!>          ISFF is TRUE: if the factorization completed before
!>          processing min(M,N) columns.
!>          ISFF is FALSE: otherwise.
!>



ISGN


!>          ISGN is INTEGER array, dimension (N)
!>          On exit, ISGN(i) contains the sign of the diagonal
!>          element DU(i).
!>



WORK


!>          WORK is REAL array, dimension (LWORK)
!>          On exit, WORK(1) contains the minimum value of LWORK.
!>



LWORK


!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>



JPVT


!>          JPVT is INTEGER array, dimension (N)
!>          On exit, JPVT(i) is the column that was interchanged
!>          with column i. JPVT(i) = k means that column k was
!>          interchanged with column i.
!>



INFO


!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an
!>                illegal value.
!>          > 0:  = k,  thektrank reveals that the matrix is of
!>                rank k.
!>



A_orig


!>          A_orig is REAL array, dimension (LWORK_orig)
!>          On entry, A_orig contains the original matrix A.
!>



LWORK_orig


!>          LWORK_orig is INTEGER
!>          The dimension of the array A_orig.
!>



VN1


!>          VN1 is REAL array, dimension (N)
!>          The vector with the partial column norms.
!>



VN2


!>          VN2 is REAL array, dimension (N)
!>          The vector with the exact column norms.
!>



AUXV


!>          AUXV is REAL array, dimension (NB)
!>          Auxiliary vector.
!>



F


!>          F is REAL array, dimension (LDF,NB)
!>          Matrix F**T = L*(Y**T)*A.
!>



LDF


!>          LDF is INTEGER
!>          The leading dimension of the array F. LDF >= max(1,N+NRHS).
!>



IWORK


!>          IWORK is INTEGER array, dimension (N-1).
!>          Is a work array. ( IWORK is used to store indices
!>          of  columns for norm downdating in the residual
!>          matrix ).
!>



ISGN


!>          ISGN is LOGICAL
!>          ISGN is TRUE: if the factorization completed before processing
!>          all min(M-IOFFSET,NB,N) columns due to ABSTOL
!>          or RELTOL criterion,
!>          ISGN is FALSE: if the factorization completed before processing
!>          all min(M-IOFFSET,NB,N) columns due to the
!>          residual matrix being a ZERO matrix.
!>          ISGN is TRUE: when NaN was detected in the matrix A
!>          or in the array TAU.
!>          ISGN is FALSE: otherwise.
!>



KB


!>          KB is INTEGER
!>          Factorization rank of the matrix A, i.e. the rank of
!>          the factor R, which is the same as the number of non-zero
!>          rows of the factor R.  0 <= KB <= min(M-IOFFSET,NB,N).
!>
!>          KB also represents the number of non-zero Householder
!>          vectors.
!>



MAXC2NRMK


!>          MAXC2NRMK is REAL
!>          The maximum column 2-norm of the residual matrix,
!>          when the factorization stopped at rank KB. MAXC2NRMK >= 0.
!>



RELMAXC2NRMK


!>          RELMAXC2NRMK is REAL
!>          The ratio MAXC2NRMK / MAXC2NRM of the maximum column
!>          2-norm of the residual matrix (when the factorization
!>          stopped at rank KB) to the maximum column 2-norm of the
!>          original matrix A_orig. RELMAXC2NRMK >= 0.
!>



JPIV


!>          JPIV is INTEGER array, dimension (N)
!>          Column pivot indices, for 1 <= j <= N, column j
!>          of the matrix A was interchanged with column JPIV(j).
!>



TAU


!>          TAU is REAL array, dimension (min(M-IOFFSET,N))
!>          The scalar factors of the elementary reflectors.
!>



VN1


!>          VN1 is REAL array, dimension (N)
!>          The vector with the partial column norms.
!>



VN2


!>          VN2 is REAL array, dimension (N)
!>          The vector with the exact column norms.
!>



AUXV


!>          AUXV is REAL array, dimension (NB)
!>          Auxiliary vector.
!>



F


!>          F is REAL array, dimension (LDF,NB)
!>          Matrix F**T = L*(Y**T)*A.
!>



LDF


!>          LDF is INTEGER
!>          The leading dimension of the array F. LDF >= max(1,N+NRHS).
!>



IWORK


!>          IWORK is INTEGER array, dimension (N-1).
!>          Is a work array. ( IWORK is used to store indices
!>          of  columns for norm downdating in the residual
!>          matrix ).
!>



INFO


!>          INFO is INTEGER
!>          1) INFO = 0: successful exit.
!>          2) If INFO = j_1, where 1 <= j_1 <= N, then NaN was
!>             detected and the routine stops the computation.
!>             The j_1-th column of the matrix A or the j_1-th
!>             element of array TAU contains the first occurrence
!>             of NaN in the factorization step KB+1 ( when KB columns
!>             have been factorized ).
!>
!>             On exit:
!>             KB                  is set to the number of
!>                                    factorized columns without
!>                                    exception.
!>             MAXC2NRMK           is set to NaN.
!>             RELMAXC2NRMK        is set to NaN.
!>             TAU(KB+1:min(M,N))     is not set and contains undefined
!>                                    elements. If j_1=KB+1, TAU(KB+1)
!>                                    may contain NaN.
!>          3) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN
!>             was detected, but +Inf (or -Inf) was detected and
!>             the routine continues the computation until completion.
!>             The (j_2-N)-th column of the matrix A contains the first
!>             occurrence of +Inf (or -Inf) in the actorization
!>             step KB+1 ( when KB columns have been factorized ).
!>
