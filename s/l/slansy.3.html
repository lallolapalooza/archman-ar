الوظائف/الروتينات الفرعية


real function slansy (norm, uplo, n, a, lda, work)
SLANSY تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية.

توثيق الوظيفة/الروتين الفرعي

real function slansy (character norm, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

SLANSY تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية.

الغرض:

!>
!> SLANSY  تُرجع قيمة المعيار واحد،  أو معيار فروبنيوس،  أو المعيار
!> اللانهائي،  أو  العنصر ذو القيمة المطلقة الأكبر  لمصفوفة متماثلة
!> حقيقية A.
!>

تُرجع

SLANSY 
!>
!>    SLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على  المعيار واحد لمصفوفة (مجموع العمود الأقصى)،
!> normI  يدل على  المعيار اللانهائي  لمصفوفة (مجموع الصف الأقصى)  و
!> normF  يدل على  معيار فروبنيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في SLANSY كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان سيتم الرجوع إلى الجزء العلوي أو السفلي
!>          المثلثي للمصفوفة المتماثلة A.
!>          = 'U':  يتم الرجوع إلى الجزء العلوي المثلثي من A
!>          = 'L':  يتم الرجوع إلى الجزء السفلي المثلثي من A
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم ضبط SLANSY
!>          على الصفر.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          المصفوفة المتماثلة A.  إذا كان UPLO = 'U'، فإن الجزء
!>          العلوي المثلثي من A بحجم n × n يحتوي على الجزء العلوي
!>          المثلثي للمصفوفة A، ولا يتم الرجوع إلى الجزء السفلي
!>          المثلثي الصارم من A.  إذا كان UPLO = 'L'، فإن الجزء
!>          السفلي المثلثي من A بحجم n × n يحتوي على الجزء السفلي
!>          المثلثي للمصفوفة A، ولا يتم الرجوع إلى الجزء العلوي
!>          المثلثي الصارم من A.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I' أو '1' أو 'O'. خلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
