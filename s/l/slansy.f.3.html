real function slansy (norm, uplo, n, a, lda, work)

SLANSY تعيد قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر الأكبر قيمة مطلقة لمصفوفة متماثلة حقيقية.

توثيق الوظيفة/الإجراء الفرعي

real function slansy (character norm, character uplo, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

SLANSY تعيد قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر الأكبر قيمة مطلقة لمصفوفة متماثلة حقيقية.

الغرض:

!>
!> SLANSY  تعيد قيمة المعيار واحد،  أو معيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو  العنصر ذو القيمة المطلقة الأكبر  لمصفوفة
!> متماثلة حقيقية A.
!>

النتائج

SLANSY 
!>
!>    SLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى  المعيار واحد  لمصفوفة (أقصى مجموع للأعمدة)،
!> normI  يشير إلى  المعيار اللانهائي  لمصفوفة  (أقصى مجموع للصفوف) و
!> normF  يشير إلى  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في SLANSY كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان سيتم الرجوع إلى الجزء العلوي أو السفلي المثلثي
!>          للمصفوفة المتماثلة A.
!>          = 'U':  يتم الرجوع إلى الجزء المثلثي العلوي من A
!>          = 'L':  يتم الرجوع إلى الجزء المثلثي السفلي من A
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين SLANSY
!>          إلى صفر.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          المصفوفة المتماثلة A.  إذا كان UPLO = 'U'، فإن الجزء المثلثي العلوي
!>          الموجود في أعلى المصفوفة N x N A يحتوي على الجزء المثلثي العلوي
!>          للمصفوفة A، ولا يتم الرجوع إلى الجزء السفلي المثلثي الصارم من A.
!>          إذا كان UPLO = 'L'، فإن الجزء المثلثي السفلي الموجود في أعلى المصفوفة
!>          N x N A يحتوي على الجزء المثلثي السفلي للمصفوفة A، ولا يتم الرجوع
!>          إلى الجزء العلوي المثلثي الصارم من A.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'. خلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
