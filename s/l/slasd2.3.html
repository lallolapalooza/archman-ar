LAPACK routine

NAME

slasd2 -

SYNOPSIS

SUBROUTINE SLASD2( ITYPE, NL, NR, SQRE, KBLS, MBR, NNB, NOR, KAC,
&                   KSPLIT, DLAMDA, D, Q, QL, QR, XS, XSC, INFO )

CHARACTER*1 ITYPE

INTEGER NL, NR, SQRE, KBLS, MBR, NNB, NOR, KAC, KSPLIT(*), INFO

REAL DLAMDA( * ), D( * ), Q( * ), QL( * ), QR( * ), XS( * ), XSC( * )

Function/Subroutine Documentation

  ITYPE:character*1
        specifies the task to be performed.
        = 'S': solve theniejsa subproblem.
        = 'D': solve theniejsa subproblem.

  NL:integer
        The number of elements of the first part of the vector D.

  NR:integer
        The number of elements of the second part of the vector D.

  SQRE:integer
        specifies the sign of the square root of the eigenvalues.
        =  0: the square root is positive.
        = -1: the square root is negative.

  KBLS:integer
        The number of rows of the matrix XS.

  MBR:integer
        The number of rows of the matrix XSC.

  NNB:integer
        The number of columns of the matrix XSC.

  NOR:integer
        The number of rows of the matrix QR.

  KAC:integer
        The number of columns of the matrix QR.

  KSPLIT:integer array, dimension ( N )
        Array describing the structure of the diagonal blocks of the matrix
        A. This array is used only when ITYPE is equal to 'S'.
        Of A. This array is used only when ITYPE is equal to 'S'.
        KSPLIT(i) = 1 indicates that the i-th block is a K x K matrix
        which is not a diagonal block.
        KSPLIT(i) = 2 indicates that the i-th block is a K x K matrix
        which is a diagonal block.
        KSPLIT(i) = 3 indicates that the i-th block is a K x K matrix
        which is a K x K identity matrix.
        KSPLIT(i) = 4 indicates that the i-th block is a K x K matrix
        which is a K x K diagonal matrix.

  DLAMDA:real array, dimension ( N )
        The discrete approximation of the eigenvalues of the original problem.

  D:real array, dimension ( N )
        The initial guess of the eigenvalues of theniejsa subproblem.

  Q:real array, dimension ( N )
        The left singular vectors of theniejsa subproblem.

  QL:real array, dimension ( LDA*N )
        The left singular vectors of theniejsa subproblem.

  QR:real array, dimension ( LDR*N )
        The right singular vectors of theniejsa subproblem.

  XS:real array, dimension ( KBLS*N )
        The left singular vectors of theniejsa subproblem.

  XSC:real array, dimension ( MBR*NNB )
        The right singular vectors of theniejsa subproblem.

  INFO:integer
        = 0:  successful exit.
        < 0:  if INFO = -i, the i-th argument had an illegal value.
