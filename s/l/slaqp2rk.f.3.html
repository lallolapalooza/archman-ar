SLAQP2RK يحسب تحليل QR المقتطع مع محورية الأعمدة لكتلة مصفوفة حقيقية باستخدام BLAS من المستوى 2 ويستبدل مصفوفة حقيقية B بحجم m في nrhs بـ Q**T * B.

الغرض:

!>
!> SLAQP2RK يحسب تحليل QR المقتطع (رتبة K) أو كامل الرتبة بطريقة Householder
!> مع محورية الأعمدة لكتلة مصفوفة حقيقية
!> A(IOFFSET+1:M,1:N) على النحو
!>
!>   A * P(K) = Q(K) * R(K).
!>
!> يستخدم الروتين BLAS من المستوى 2. الكتلة A(1:IOFFSET,1:N)
!> تُحوَّر وفقًا لذلك، لكن لا تُحلَّل.
!>
!> يستبدل الروتين أيضًا كتلة مصفوفة الأطراف اليمنى B
!> المخزنة في A(IOFFSET+1:M,N+1:N+NRHS) بـ Q(K)**T * B.
!>

NAME

SLAQP2RK - SLAQP2RK

SYNOPSIS

SUBROUTINE SLAQP2RK(
  M, N, K, A, LDA, B, LDB, C, LDC, D, LDD, T, LDT, TAU, W, VN1, VN2, WORK,
  INFO
)
INTEGER M, N, K, LDA, LDB, LDC, LDD, LDT, INFO
REAL A( LDA, * ), B( LDB, * ), C( LDC, * ), D( LDD, * ),
 T( LDT, * ), TAU( * ), W( * ), VN1( * ), VN2( * ), WORK( * )

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines for performing rank-revealing QR factorization with column pivoting.

The routine computes the QR factorization with column pivoting of a real matrix B in

    B = Q * [ R ]
            [ 0 ]

where R is upper trapezoidal.

The routine differs from SLAQP2RK in that it performs the operation

    B := OP(A) * OP(B)

where OP(A) is an M-by-K matrix and OP(B) is a K-by-N matrix.

It is intended to be used as a subroutine in a rank-revealing QR factorization algorithm.

Arguments

M
INTEGER. The number of rows of the matrix OP(A) and OP(B).
N
INTEGER. The number of columns of the matrix OP(B).
K
INTEGER. The number of columns of the matrix OP(A) and the number of rows of the matrix OP(B).
A
REAL array, dimension (LDA, K).

The M-by-K matrix OP(A).

LDA
INTEGER. The leading dimension of the array A.
B
REAL array, dimension (LDB, N).

The K-by-N matrix OP(B).

LDB
INTEGER. The leading dimension of the array B.
C
REAL array, dimension (LDC, K).

The M-by-K matrix used to store the result of the QR factorization of OP(A) in SLAQP2RK.

LDC
INTEGER. The leading dimension of the array C.
D
REAL array, dimension (LDD, N).

The K-by-N matrix used to store the result of the QR factorization of OP(B) in SLAQP2RK.

LDD
INTEGER. The leading dimension of the array D.
T
REAL array, dimension (LDT, K).

The K-by-K upper triangular matrix T.

LDT
INTEGER. The leading dimension of the array T.
TAU
REAL array, dimension (K).

The coefficients of the elementary reflectors.

W
REAL array, dimension (K).
VN1
REAL array, dimension (N)

The vector with the partial column norms.

VN2
REAL array, dimension (N)

The vector with the exact column norms.

WORK
REAL array, dimension (N-1)

Used in SLARF1F subroutine to apply an elementary reflector from the left.

INFO
INTEGER
  1. INFO = 0: successful exit.
  2. If INFO = j_1, where 1 <= j_1 <= N, then NaN was detected and the routine stops the computation. The j_1-th column of the matrix A or the j_1-th element of array TAU contains the first occurrence of NaN in the factorization step K+1 ( when K columns have been factorized ). On exit: K is set to the number of factorized columns without exception. MAXC2NRMK is set to NaN. RELMAXC2NRMK is set to NaN. TAU(K+1:min(M,N)) is not set and contains undefined elements. If j_1=K+1, TAU(K+1) may contain NaN.
  3. If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN was detected, but +Inf (or -Inf) was detected and the routine continues the computation until completion. The (j_2-N)-th column of the matrix A contains the first occurrence of +Inf (or -Inf) in the factorization step K+1 ( when K columns have been factorized ).
