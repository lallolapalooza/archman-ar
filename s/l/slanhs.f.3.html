real function slanhs (norm, n, a, lda, work)

SLANHS تُرجع قيمة المعيار 1، أو المعيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة هسنبرغ علوية.

توثيق الوظائف/الإجراءات الفرعية

real function slanhs (character norm, integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

SLANHS تُرجع قيمة المعيار 1، أو المعيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة هسنبرغ علوية.

الغرض:

!>
!> SLANHS  تُرجع قيمة المعيار واحد،  أو المعيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> هسنبرغ A.
!>

تُرجع

SLANHS 
!>
!>    SLANHS = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على  المعيار واحد لمصفوفة (أقصى مجموع أعمدة)،
!> normI  يدل على  المعيار اللانهائي  لمصفوفة (أقصى مجموع صفوف) و
!> normF  يدل على  المعيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في SLANHS كما هو موضح
!>          أعلاه.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين SLANHS
!>          إلى صفر.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          مصفوفة هسنبرغ العلوية A بحجم N × N؛ الجزء الموجود أسفل
!>          القطر الفرعي الأول لا يتم الرجوع إليه.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I'؛ بخلاف ذلك، لا يتم الرجوع
!>          إلى WORK.
!>
