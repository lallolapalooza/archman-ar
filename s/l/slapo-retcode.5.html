slapo-retcode(5)

الحزمة: openldap

التراخيص: custom

SLAPO-RETCODE(5) دليل تنسيقات الملفات SLAPO-RETCODE(5)

الاسم

slapo-retcode - طبقة استرجاع رمز الاستجابة لـ slapd

الملخص

/etc/openldap/slapd.conf

الوصف

تعتبر طبقة retcode الإضافية لـ slapd(8) مفيدة لاختبار سلوك العملاء عندما تحدث استجابات خاطئة و/أو غير عادية تم إنشاؤها بواسطة الخادم، على سبيل المثال: رموز الخطأ، الإحالات، أوقات الاستجابة المفرطة وما إلى ذلك.

يتم إنشاء استجابات الخطأ وفقًا لاستراتيجيات مختلفة.

في الحالة الأولى، تتسبب جميع العمليات المستهدفة لشجرة فرعية قابلة للتكوين محددة في البحث عن الكائن المتعلق باسم الطلب والتحقق من بيانات رمز الاستجابة: رمز استجابة، بالإضافة إلى رسالة نصية اختيارية، وتأخير اختياري قابل للتكوين، وحقل اسم مطابق اختياري، وعندما يكون رمز الاستجابة "إحالة"، فإن (قائمة) إحالة (إحالات).

يتم توفير رموز الاستجابة المعروفة جيدًا من مستندات المسار القياسية في retcode.conf، والتي يمكن تضمينها بعد استنساخ الطبقة الإضافية.

في الحالة الثانية، يتم تغيير الكائنات من فئات موروثة من errAbsObject، مثل errObject أو errAuxObject، عند إرجاعها كاستجابات وسيطة لطلب بحث، إلى الاستجابة التي يمليها محتواها.

يتسبب الوضع الثالث في البحث عن الكائنات من قاعدة البيانات الأساسية لاكتشاف ما إذا كانت فئتها ترث من errABsObject؛ في هذه الحالة، يتم استخدام محتواها لحساب الاستجابة المقابلة.

يتم تعطيل السلوك باستخدام التحكم manageDSAit (RFC 3296)؛ في هذه الحالة، يتم التعامل مع الكائن الناتج، سواء كان موجودًا في الدليل أو تم إنشاؤه ديناميكيًا بواسطة الطبقة الإضافية، أو موجودًا في الطلب، كما هو معتاد.

يجب أن تكون توجيهات التكوين الخاصة بالطبقة الإضافية retcode مسبوقة بـ retcode-، لتجنب التعارض مع التوجيهات الخاصة بقاعدة البيانات الأساسية أو بالطبقات الإضافية المكدسة الأخرى. يمكن استخدام التوجيهات المحددة التالية لتكوين طبقة retcode الإضافية:

retcode-parent <DN>
يحدد هذا التوجيه اسم DN الأصل حيث توجد الإدخالات التي تم إنشاؤها ديناميكيًا. إذا لم يتم تعريفه، يتم استخدام لاحقة قاعدة البيانات.

retcode-item <RDN> <errCode> [op=<oplist>] [text=<message>] [ref=<referral>] [sleeptime=<sec>] [matched=<DN>] [unsolicited=<OID>[:<data>]] [flags=[pre|post-]disconnect[,...]]

إدخال تم إنشاؤه ديناميكيًا، يقع أسفل retcode-parent. errCode هو رقم رمز الاستجابة؛ يمكن أن يكون بأي تنسيق تدعمه strtol(3). oplist الاختياري هو قائمة بالعمليات التي تسبب إنشاء رمز الاستجابة؛ إذا كانت غائبة، تتأثر جميع العمليات. حقل matched هو الاسم المطابق الذي يتم إرجاعه مع الخطأ، بينما حقل text هو رسالة تشخيص اختيارية. الحقل ref مسموح به فقط لرمز الاستجابة referral. يتسبب حقل sleeptime في أن تقوم slapd(8) بالنوم لعدد الثواني المحدد قبل المتابعة مع العملية. يمكن استخدام حقل unsolicited لتسبب إرجاع رسالة استجابة غير مرغوب فيها RFC 4511؛ إذا لم يكن OID "0"، يتم إنشاء استجابة موسعة، مع إلحاق data الاختياري. إذا احتوت flags على disconnect، أو pre-disconnect، تقوم slapd(8) بالانفصال بشكل مفاجئ، دون إشعار؛ يتسبب post-disconnect في الانفصال مباشرة بعد إرسال الاستجابة كما هو مناسب.
retcode-indir
يُمكّن استغلال errAbsObject المخزن في الدليل. قد يؤدي إلى الكثير من الحمل غير الضروري.
retcode-sleep [-]<n>
يحدد وقت نوم بالثواني يتم إنفاقه قبل معالجة أي عملية فعليًا. إذا كان سالبًا، يتم استخدام وقت عشوائي بين 0 والقيمة المطلقة للحجة.

المخطط

تستخدم طبقة retcode الإضافية مخطط "رمز الاستجابة" الموصوف هنا. تم تصميم هذا المخطط خصيصًا للاستخدام مع هذه الطبقة الإضافية وليس مخصصًا للاستخدام بخلاف ذلك. يُلاحظ أيضًا أن المخطط الموصوف هنا هو عمل قيد التقدم، وبالتالي قد يتغير دون إشعار. يتم تحميل المخطط تلقائيًا بواسطة الطبقة الإضافية.

يتضمن المخطط عددًا من فئات الكائنات وأنواع السمات المرتبطة بها كما هو موضح أدناه.

رمز الخطأ:

( 1.3.6.1.4.1.4203.666.11.4.1.1
NAME ( 'errCode' )
DESC 'LDAP error code'
EQUALITY integerMatch
ORDERING integerOrderingMatch
SYNTAX 1.3.6.1.4.1.1466.115.121.1.27
SINGLE-VALUE )

العمليات التي تؤدي إلى تشغيل رمز الاستجابة:

( 1.3.6.1.4.1.4203.666.11.4.1.2
NAME ( 'errOp' )
DESC 'Operations the errObject applies to'
EQUALITY caseIgnoreMatch
SUBSTR caseIgnoreSubstringsMatch
SYNTAX 1.3.6.1.4.1.1466.115.121.1.15 )

الرسالة النصية:

( 1.3.6.1.4.1.4203.666.11.4.1.3
NAME ( 'errText' )
DESC 'LDAP error textual description'
EQUALITY caseIgnoreMatch
SUBSTR caseIgnoreSubstringsMatch
SYNTAX 1.3.6.1.4.1.1466.115.121.1.15
SINGLE-VALUE )

وقت الانتظار قبل إرجاع الاستجابة فعليًا إلى العميل:

( 1.3.6.1.4.1.4203.666.11.4.1.4
NAME ( 'errSleepTime' )
DESC 'Time to wait before returning the error'
EQUALITY integerMatch
SYNTAX 1.3.6.1.4.1.1466.115.121.1.27
SINGLE-VALUE )

الاسم المطابق الذي تم إرجاعه إلى العميل:

( 1.3.6.1.4.1.4203.666.11.4.1.5
NAME ( 'errMatchedDN' )
DESC 'Value to be returned as matched DN'
EQUALITY distinguishedNameMatch
SYNTAX 1.3.6.1.4.1.1466.115.121.1.12
SINGLE-VALUE )

معرف الكائن (OID) الذي سيتم إرجاعه كمعرف كائن استجابة موسعة في استجابات RFC 4511 غير المرغوب فيها ("0" ينشئ استجابة عادية مع تعيين msgid إلى 0):

( 1.3.6.1.4.1.4203.666.11.4.1.6
NAME ( 'errUnsolicitedOID' )
DESC 'OID to be returned within unsolicited response'
EQUALITY objectIdentifierMatch
SYNTAX 1.3.6.1.4.1.1466.115.121.1.38
SINGLE-VALUE )

السلسلة الثمانية التي سيتم إرجاعها كبيانات استجابة موسعة في استجابة RFC 4511 غير المرغوب فيها:

( 1.3.6.1.4.1.4203.666.11.4.1.7
NAME ( 'errUnsolicitedData' )
DESC 'Data to be returned within unsolicited response'
SYNTAX 1.3.6.1.4.1.1466.115.121.1.40
SINGLE-VALUE )

إذا كانت TRUE، تقوم slapd(8) بالانفصال بشكل مفاجئ دون إشعار؛ إذا كانت FALSE، فإنها تنفصل بعد إرسال الاستجابة كما هو مناسب:

( 1.3.6.1.4.1.4203.666.11.4.1.8
NAME ( 'errDisconnect' )
DESC 'Disconnect without notice'
SYNTAX 1.3.6.1.4.1.1466.115.121.1.7
SINGLE-VALUE )

الفئة المجردة التي تؤدي إلى تشغيل الطبقة الإضافية:

( 1.3.6.1.4.1.4203.666.11.4.3.0
NAME ( 'errAbsObject' )
SUP top ABSTRACT
MUST ( errCode )
MAY ( cn $ description $ errOp $ errText $ errSleepTime
$ errMatchedDN ) )

فئة الكائن الهيكلية المستقلة للبيانات المنشأة خصيصًا:

( 1.3.6.1.4.1.4203.666.11.4.3.1
NAME ( 'errObject' )
SUP errAbsObject STRUCTURAL )

فئة الكائن الإضافية لتغيير سلوك الكائنات الحالية:

( 1.3.6.1.4.1.4203.666.11.4.3.2
NAME ( 'errAuxObject' )
SUP errAbsObject AUXILIARY )

مثال

overlay         retcode
retcode-parent  "ou=RetCodes,dc=example,dc=com"
# retcode.conf is found in tests/data/ of the source tree
include         ./retcode.conf
# Wait 10 seconds, then return success (0x00)
retcode-item    "cn=Success after 10 seconds" 0x00 sleeptime=10
# Wait 10 seconds, then return timelimitExceeded (0x03)
retcode-item    "cn=Timelimit after 10 seconds" 0x03 sleeptime=10
