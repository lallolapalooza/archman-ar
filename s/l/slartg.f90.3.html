subroutine slartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

SLARTG تولد دوران مستوى بجيب تمام حقيقي وجيب حقيقي.

الغرض:

!>
!> SLARTG تولد دوران مستوى بحيث:
!>
!>    [  C  S  ]  .  [ F ]  =  [ R ]
!>    [ -S  C  ]     [ G ]     [ 0 ]
!>
!> حيث C**2 + S**2 = 1.
!>
!> الصيغ الرياضية المستخدمة لـ C و S هي:
!>    R = sign(F) * sqrt(F**2 + G**2)
!>    C = F / R
!>    S = G / R
!> وبالتالي C >= 0. الخوارزمية المستخدمة لحساب هذه الكميات
!> تتضمن القياس لتجنب التدفق الزائد أو الناقص في حساب
!> الجذر التربيعي لمجموع المربعات.
!>
!> هذا الإصدار متقطع في R عند F = 0 ولكنه يعيد نفس
!> C و S مثل CLARTG للمدخلات المعقدة (F,0) و (G,0).
!>
!> هذا إصدار أكثر دقة للإجراء الفرعي SROTG في BLAS1،
!> مع الاختلافات الأخرى التالية:
!>    F و G لم تتغير عند العودة.
!>    إذا كان G=0، فإن C=1 و S=0.
!>    إذا كان F=0 و (G .ne. 0)، فإن C=0 و S=sign(1,G) دون أي
!>       عمليات نقطة عائمة (يوفر العمل في SBDSQR عندما
!>       تكون هناك أصفار على القطر).
!>
!> أدناه، wp=>sp تعني الدقة الأحادية من وحدة LA_CONSTANTS.
!>
