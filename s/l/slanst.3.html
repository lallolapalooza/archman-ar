real function slanst (norm, n, d, e)
SLANST تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية ثلاثية الأقطار.

توثيق الوظيفة/الروتين الفرعي

real function slanst (character norm, integer n, real, dimension( * ) d, real, dimension( * ) e)

SLANST تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية ثلاثية الأقطار.

الغرض:

!>
!> SLANST  تُرجع قيمة المعيار واحد،  أو معيار فروبنيوس،  أو المعيار
!> اللانهائي،  أو  العنصر ذو القيمة المطلقة الأكبر  لمصفوفة متماثلة حقيقية ثلاثية
!> الأقطار A.
!>

تُرجع

SLANST 
!>
!>    SLANST = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على  المعيار واحد للمصفوفة (مجموع العمود الأقصى)،
!> normI  يدل على  المعيار اللانهائي  للمصفوفة (مجموع الصف الأقصى) و
!> normF  يدل على  معيار فروبنيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابت.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          تحدد القيمة التي سيتم إرجاعها في SLANST كما هو موضح
!>          أعلاه.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين SLANST
!>          إلى صفر.
!>

D

!>          D is REAL array, dimension (N)
!>          العناصر القطرية للمصفوفة A.
!>

E

!>          E is REAL array, dimension (N-1)
!>          العناصر تحت القطرية أو فوق القطرية (n-1) للمصفوفة A.
!>
