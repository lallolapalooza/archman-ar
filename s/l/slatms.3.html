NAME

slatms - generate a distributed matrix

SYNOPSIS 

SUBROUTINE SLATMS(
   M, N, DIST, SYM, MODE, COND, DMAX, PACK, A, LDA, WORK, INFO )

      IMPLICIT NONE

      INTEGER :: INFO
      INTEGER :: M, N
      INTEGER :: LDA
      INTEGER :: MODE, KL, KU
      REAL :: COND, DMAX
      CHARACTER(1) :: DIST, SYM, PACK

      REAL, DIMENSION( LDA, N ) :: A
      REAL, DIMENSION( 3*MAX( N , M ) ) :: WORK

Function/Subroutine Documentation

SLATMS is a subroutine in LAPACK used to generate test matrices for various linear algebra routines. It can create matrices with specified properties like dimension, distribution, symmetry, condition number, and norm.

M 

          M is INTEGER
          The number of rows of the matrix A.
          Not modified.

N 

          N is INTEGER
          The number of columns of the matrix A.
          Not modified.

DIST 

          DIST is CHARACTER*1
          Specifies the distribution of the elements of A, as follows:
          'U' => uniform distribution
          'N' => normally distributed (with 0 mean and unit variance)
          'D' => diagonally dominant
          'S' => symmetric or skew-symmetric structure
          Not modified.

SYM 

          SYM is CHARACTER*1
          Specifies the symmetry of the matrix A:
          'N' => no symmetry, A is not symmetric.
          'U' => upper triangular matrix.
          'L' => lower triangular matrix.
          'S' => symmetric matrix.
          'H' => symmetric or skew-symmetric matrix.
          'P' => positive definite symmetric matrix.
          'Z' => zero matrix.
          Not modified.

MODE 

          MODE is INTEGER
          Specifies the condition of the matrix A. The following values
          are possible:
          -1 => A is selected from a uniform distribution on interval [0,1]
          -2 => A is selected from a normal distribution with mean 0 and
                 unit variance
          -3 => A is selected from a factored matrix (A = U * D * U**T)
                 where U is uniformly distributed and D is diagonal
          -4 => A is selected from a factored matrix (A = U * D * U**T)
                 where U is normally distributed and D is diagonal
          -5 => A is selected from a factored matrix (A = U * D * U**T)
                 where U is triangular and D is diagonal
          -6 => A is selected from a factored matrix (A = U * D * U**T)
                 where U is random orthogonal and D is diagonal
           0 => A is the identity matrix (and D is the identity matrix).
           1 => A is selected from a uniform distribution on interval [0,1]
                and scaled to have condition number COND.
           2 => A is selected from a normal distribution with mean 0 and
                unit variance and scaled to have condition number COND.
           3 => A is selected from a factored matrix (A = U * D * U**T)
                where U is uniformly distributed and D is diagonal, and
                scaled to have condition number COND.
           4 => A is selected from a factored matrix (A = U * D * U**T)
                where U is normally distributed and D is diagonal, and
                scaled to have condition number COND.
           5 => A is selected from a factored matrix (A = U * D * U**T)
                where U is triangular and D is diagonal, and scaled to
                have condition number COND.
           6 => A is selected from a factored matrix (A = U * D * U**T)
                where U is random orthogonal and D is diagonal, and scaled
                to have condition number COND.
          Not modified.

COND 

          COND is REAL
          If MODE is in the range [1, 6], COND is the desired condition
          number of A.
          Not modified.

DMAX 

          DMAX is REAL
          If MODE is in the range [1, 6], DMAX is the desired maximum
          absolute value of the diagonal entries of A.
          Not modified.

PACK 

          PACK is CHARACTER*1
          This specifies packing of matrix as follows:
          'N' => no packing
          'U' => zero out all subdiagonal entries (if symmetric)
          'L' => zero out all superdiagonal entries (if symmetric)
          'C' => store the upper triangle columnwise
                 (only if the matrix is symmetric or upper triangular)
          'R' => store the lower triangle columnwise
                 (only if the matrix is symmetric or lower triangular)
          'B' => store the lower triangle in band storage scheme
                 (only if matrix symmetric or lower triangular)
          'Q' => store the upper triangle in band storage scheme
                 (only if matrix symmetric or upper triangular)
          'Z' => store the entire matrix in band storage scheme
                     (pivoting can be provided for by using this
                     option to store A in the trailing rows of
                     the allocated storage)

          Using these options, the various LAPACK packed and banded
          storage schemes can be obtained:
          GB               - use 'Z'
          PB, SB or TB     - use 'B' or 'Q'
          PP, SP or TP     - use 'C' or 'R'

          If two calls to SLATMS differ only in the PACK parameter,
          they will generate mathematically equivalent matrices.
          Not modified.

A 

          A is REAL array, dimension ( LDA, N )
          On exit A is the desired test matrix. A is first generated
          in full (unpacked) form, and then packed, if so specified
          by PACK. Thus, the first M elements of the first N
          columns will always be modified. If PACK specifies a
          packed or banded storage scheme, all LDA elements of the
          first N columns will be modified; the elements of the
          array which do not correspond to elements of the generated
          matrix are set to zero.
          Modified.

LDA 

          LDA is INTEGER
          LDA specifies the first dimension of A as declared in the
          calling program. If PACK='N', 'U', 'L', 'C', or 'R', then
          LDA must be at least M. If PACK='B' or 'Q', then LDA must
          be at least MIN( KL, M-1) (which is equal to MIN(KU,N-1)).
          If PACK='Z', LDA must be large enough to hold the packed
          array: MIN( KU, N-1) + MIN( KL, M-1) + 1.
          Not modified.

WORK 

          WORK is REAL array, dimension ( 3*MAX( N , M ) )
          Workspace.
          Modified.

INFO 

          INFO is INTEGER
          Error code. On exit, INFO will be set to one of the
          following values:
            0 => normal return
           -1 => M negative or unequal to N and SYM='S', 'H', or 'P'
           -2 => N negative
           -3 => DIST illegal string
           -5 => SYM illegal string
           -7 => MODE not in range -6 to 6
           -8 => COND less than 1.0, and MODE neither -6, 0 nor 6
          -10 => KL negative
          -11 => KU negative, or SYM='S' or 'H' and KU not equal to KL
          -12 => PACK illegal string, or PACK='U' or 'L', and SYM='N';
                 or PACK='C' or 'Q' and SYM='N' and KL is not zero;
                 or PACK='R' or 'B' and SYM='N' and KU is not zero;
                 or PACK='U', 'L', 'C', 'R', 'B', or 'Q', and M is not
                 N.
          -14 => LDA is less than M, or PACK='Z' and LDA is less than
                 MIN(KU,N-1) + MIN(KL,M-1) + 1.
            1  => Error return from SLATM1
            2  => Cannot scale to DMAX (max. sing. value is 0)
            3  => Error return from SLAGGE or SLAGSY
