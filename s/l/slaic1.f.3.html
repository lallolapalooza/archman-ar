subroutine slaic1 (integer job, integer j, real, dimension( j ) x, real sest, real, dimension( j ) w, real gamma, real sestpr, real s, real c)

SLAIC1 تطبق خطوة واحدة من تقدير الشرط التزايدي.

الغرض:

!>
!> SLAIC1 تطبق خطوة واحدة من تقدير الشرط التزايدي في
!> أبسط إصداراتها:
!>
!> لتكن x، twonorm(x) = 1، متجهًا منفردًا تقريبيًا لمصفوفة L
!> ثلاثية سفلية بحجم j*j، بحيث
!>          twonorm(L*x) = sest
!> ثم تقوم SLAIC1 بحساب sestpr، s، c بحيث
!> المتجه
!>                 [ s*x ]
!>          xhat = [  c  ]
!> هو متجه منفرد تقريبي للمصفوفة
!>                 [ L      0  ]
!>          Lhat = [ w**T gamma ]
!> بمعنى أن
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> اعتمادًا على JOB، يتم حساب تقدير لأكبر قيمة منفردة أو أصغر قيمة منفردة.
!>
!> لاحظ أن [s c]**T و sestpr**2 هي زوج قيمة / متجه ذاتي للنظام
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ alpha ]
!>                                           [ gamma ]
!>
!> حيث alpha =  x**T*w.
!>

!>          = 1: يتم حساب تقدير لأكبر قيمة منفردة.

!>
