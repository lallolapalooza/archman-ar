SLIST(3) دليل وظائف المكتبة SLIST(3)

الاسم

SLIST_EMPTY, SLIST_ENTRY, SLIST_FIRST, SLIST_FOREACH, SLIST_HEAD, SLIST_HEAD_INITIALIZER, SLIST_INIT, SLIST_INSERT_AFTER, SLIST_INSERT_HEAD, SLIST_NEXT, SLIST_REMOVE, SLIST_REMOVE_HEAD - تنفيذ قائمة مرتبطة أحادية

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/queue.h>
SLIST_ENTRY(TYPE);
SLIST_HEAD(HEADNAME, TYPE);
SLIST_HEAD SLIST_HEAD_INITIALIZER(SLIST_HEAD head);
void SLIST_INIT(SLIST_HEAD *head);
int SLIST_EMPTY(SLIST_HEAD *head);
void SLIST_INSERT_HEAD(SLIST_HEAD *head,
                        struct TYPE *elm, SLIST_ENTRY NAME);
void SLIST_INSERT_AFTER(struct TYPE *listelm,
                        struct TYPE *elm, SLIST_ENTRY NAME);
struct TYPE *SLIST_FIRST(SLIST_HEAD *head);
struct TYPE *SLIST_NEXT(struct TYPE *elm, SLIST_ENTRY NAME);
SLIST_FOREACH(struct TYPE *var, SLIST_HEAD *head, SLIST_ENTRY NAME);
void SLIST_REMOVE(SLIST_HEAD *head, struct TYPE *elm, TYPE,
                        SLIST_ENTRY NAME);
void SLIST_REMOVE_HEAD(SLIST_HEAD *head,
                        SLIST_ENTRY NAME);

الوصف

تحدد هذه الماكروهات وتعمل على قوائم مرتبطة أحادية.

في تعريفات الماكروهات، TYPE هو اسم بنية معرفة من قبل المستخدم، والتي يجب أن تحتوي على حقل من النوع SLIST_ENTRY، يسمى NAME. الحجة HEADNAME هي اسم بنية معرفة من قبل المستخدم يجب الإعلان عنها باستخدام الماكرو SLIST_HEAD().

الإنشاء

يتم ترؤس القائمة المرتبطة الأحادية ببنية معرفة بواسطة الماكرو SLIST_HEAD(). تحتوي هذه البنية على مؤشر واحد إلى العنصر الأول في القائمة. العناصر مرتبطة أحادياً لتقليل استهلاك المساحة وتعقيد معالجة المؤشرات، مقابل تكلفة O(n) للإزالة للعناصر العشوائية. يمكن إضافة عناصر جديدة إلى القائمة بعد عنصر موجود أو في رأس القائمة. يتم الإعلان عن بنية SLIST_HEAD على النحو التالي:


SLIST_HEAD(HEADNAME, TYPE) head;

حيث struct HEADNAME هي البنية التي سيتم تعريفها، و struct TYPE هو نوع العناصر التي سيتم ربطها في القائمة. يمكن لاحقًا الإعلان عن مؤشر إلى رأس القائمة على النحو التالي:


struct HEADNAME *headp;

(أسماء head و headp قابلة للاختيار من قبل المستخدم.)

يعلن SLIST_ENTRY() عن بنية تربط العناصر في القائمة.

يقيم SLIST_HEAD_INITIALIZER() قيمة أولية للرأس head للقائمة.

يقوم SLIST_INIT() بتهيئة القائمة المشار إليها بواسطة head.

يقيّم SLIST_EMPTY() إلى صحيح إذا لم تكن هناك عناصر في القائمة.

الإدراج

يقوم SLIST_INSERT_HEAD() بإدراج العنصر الجديد elm في رأس القائمة.

يقوم SLIST_INSERT_AFTER() بإدراج العنصر الجديد elm بعد العنصر listelm.

التجوال

يعيد SLIST_FIRST() العنصر الأول في القائمة، أو NULL إذا كانت القائمة فارغة.

يعيد SLIST_NEXT() العنصر التالي في القائمة.

يقوم SLIST_FOREACH() بتجوال القائمة المشار إليها بواسطة head في الاتجاه الأمامي، مع تعيين كل عنصر بدوره إلى var.

الإزالة

يقوم SLIST_REMOVE() بإزالة العنصر elm من القائمة.

يقوم SLIST_REMOVE_HEAD() بإزالة العنصر elm من رأس القائمة. للحصول على أقصى كفاءة، يجب على العناصر التي تتم إزالتها من رأس القائمة استخدام هذا الماكرو صراحةً بدلاً من SLIST_REMOVE() العام.

قيمة الإرجاع

يعيد SLIST_EMPTY() قيمة غير صفرية إذا كانت القائمة فارغة، وصفر إذا كانت القائمة تحتوي على إدخال واحد على الأقل.

يعيد SLIST_FIRST() و SLIST_NEXT() مؤشراً إلى بنية TYPE الأولى أو التالية، على التوالي.

يعيد SLIST_HEAD_INITIALIZER() قيمة أولية يمكن تعيينها إلى رأس القائمة head.

المعايير

BSD.

التاريخ

4.4BSD.

الأخطاء

لا يسمح SLIST_FOREACH() بإزالة أو تحرير var داخل الحلقة، حيث سيؤثر ذلك على التجوال. يصلح SLIST_FOREACH_SAFE()، الموجود في BSD ولكنه غير موجود في glibc، هذا القيد عن طريق السماح بإزالة var بأمان من القائمة وتحريرها من داخل الحلقة دون التأثير على التجوال.

أمثلة

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    SLIST_ENTRY(entry) entries;             /* قائمة أحادية مرتبطة */
};
SLIST_HEAD(slisthead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct slisthead head;                  /* رأس القائمة الأحادية المرتبطة */
    SLIST_INIT(&head);                      /* تهيئة الطابور */
    n1 = malloc(sizeof(struct entry));      /* الإدراج في الرأس */
    SLIST_INSERT_HEAD(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* الإدراج بعد */
    SLIST_INSERT_AFTER(n1, n2, entries);
    SLIST_REMOVE(&head, n2, entry, entries);/* الحذف */
    free(n2);
    n3 = SLIST_FIRST(&head);
    SLIST_REMOVE_HEAD(&head, entries);      /* الحذف من الرأس */
    free(n3);
    for (unsigned int i = 0; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        SLIST_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
                                            /* التجوال الأمامي */
    SLIST_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
    while (!SLIST_EMPTY(&head)) {           /* حذف القائمة */
        n1 = SLIST_FIRST(&head);
        SLIST_REMOVE_HEAD(&head, entries);
        free(n1);
    }
    SLIST_INIT(&head);
    exit(EXIT_SUCCESS);
}

SLIST_HEAD_INITIALIZER(3bsd) — Arch Linux
SLIST_HEAD_INITIALIZER (3bsd) - July 26, 2023

الاسم

SLIST_HEAD_INITIALIZER - مُهيئ لرأس قائمة ارتباط أحادي

المكتبة

Standard C Library (libc, -lc)

الملخص

<sys/queue.h>

SLIST_HEAD_INITIALIZER(head)

الوصف

The SLIST_HEAD_INITIALIZER macro returns a value suitable for initializing a variable of type SLIST_HEAD_T(type). This macro is intended for use when you need to create a static or global variable of the head type, and you cannot rely on macros like SLIST_INIT to initialize it.

قيمة الإرجاع

The macro expands to an initializer that sets the slh_first member of the SLIST head to NULL.

المعايير

None.

التاريخ

The SLIST macros first appeared in FreeBSD 3.0.

الأخطاء

The SLIST macros are not a drop-in replacement for other list implementations. For example, the SLIST_FOREACH macro does not allow removal of list elements during iteration. If you need to remove elements during iteration, you should use the SLIST_FOREACH_SAFE macro instead.

أمثلة

The following example demonstrates how to use SLIST_HEAD_INITIALIZER to declare and initialize a static SLIST head:

#include <sys/queue.h>

typedef struct my_node {
    int data;
    SLIST_ENTRY(my_node) next;
} my_node_t;

SLIST_HEAD(my_list_head, my_node);

static struct my_list_head my_global_list = SLIST_HEAD_INITIALIZER(my_global_list);

int
main(void)
{
    struct my_node *node;
    struct my_list_head my_local_list = SLIST_HEAD_INITIALIZER(my_local_list);

    // ... use my_global_list and my_local_list ...

    return 0;
}
