FBB::ServerSocket(3bobcat) مقبس الخادم FBB::ServerSocket(3bobcat)

الاسم

FBB::ServerSocket - مقبس خادم يقبل طلبات الاتصال بالإنترنت

الموجز

#include <bobcat/serversocket>
خيار الربط: -lbobcat

الوصف

يمكن إنشاء FBB::ServerSocket للاستماع إلى طلبات الاتصال من الإنترنت أو من المضيف المحلي. يمكن قبول طلبات الاتصال في الوضع المُعطِّل أو غير المُعطِّل. عند قبول اتصال، يتم إرجاع مقبس يمكن استخدامه لقراءة المعلومات من أو كتابة المعلومات إلى العميل الذي طلب الاتصال. المقبس الذي يتم توفيره هو واصف ملف يمكن استخدامه لتهيئة std::istream و/أو std::ostream. يستخدم std::istream لقراءة المعلومات من عملية العميل؛ ويستخدم std::ostream لإرسال المعلومات إلى عملية العميل. نظرًا لأنه يمكن اعتبار المقبس واصف ملف، يمكن استخدام فئات FBB::IFdStream و FBB::IFdStreamBuf و FBB::OFdStream و FBB::OFdStreamBuf المتاحة بشكل مفيد هنا. لاحظ أن توفر المقبس لا يعني أن هذا يحدد بروتوكول الاتصال. تقع على عاتق المبرمج (لا يزال) مسؤولية الامتثال لبروتوكول موجود أو تنفيذ بروتوكول مصمم خصيصًا. الوضع الأخير يعني أن تسلسل عمليات الإدخال والإخراج يتم تحديده بواسطة المبرمج.

يمكن تعريف مقبس خادم Unix Domain باستخدام FBB::LocalServerSocket.

المنشئ

o
ServerSocket(size_t port):
يقوم هذا المنشئ بتهيئة كائن FBB::ServerSocket، والذي سيستمع للاتصالات على المنفذ المحدد. بناء المقبس لا يعني أن كائن FBB::ServerSocket يستمع بالفعل للاتصالات. لبدء الاستماع، يجب استخدام العضو listen().

منشئات النسخ والانتقال (وكذلك عوامل التعيين) غير متاحة.

دوال الأعضاء

جميع أعضاء FBB::SocketBase (وبالتالي FBB::InetAddress) متاحة، لأن FBB::ServerSocket ترث من FBB::SocketBase.

o
void listen(size_t backlog = 5, bool blocking = true):
يحدد العضو listen() طريقة استماع FBB::ServerSocket للعملاء الذين يطلبون اتصالاً. لا يمكن استخدامه إلا مرة واحدة مع FBB::ServerSocket. يتم رمي كائن FBB::Exception إذا فشل الاستماع، أو إذا لم يتمكن المنشئ من إنشاء مقبس، أو إذا لم يتمكن فئة الأساس SocketBase من البناء بشكل صحيح.
يحدد معامل backlog للعضو listen() حجم قائمة الانتظار الداخلية لـ FBB::ServerSocket حيث يمكن تخزين طلبات الاتصال في انتظار دورها ليتم خدمتها. عندما تنتظر طلبات backlog ويصل طلب آخر، يتم فقدان هذا الطلب.
يستخدم المعامل الثاني للعضو، blocking، للتحكم في وضع التعطيل. افتراضيًا، يتم استخدام التعطيل، وسينتظر listen() حتى يتم إنشاء الاتصال. هذا جيد في المواقف التي يتصل فيها العملاء بشكل غير متكرر ولفترات زمنية قصيرة نسبيًا. بخلاف ذلك، في البرامج الأكثر تعقيدًا، يمكن استخدام كائن FBB::Selector لاستشعار الإدخال على مقبس الخادم و/أو على مقابس عملاء مختلفة.
o
SocketBase accept():
يرجع العضو accept() كائن FBB::SocketBase يحتوي على معلومات حول العميل الذي تم قبول طلب اتصاله. يمكن استخدام قيمة مقبس كائن FBB::SocketBase لتهيئة التدفقات التي يمكن استخدامها للتواصل مع العميل. في البرامج الأكثر تعقيدًا، يمكن تمرير FBB::SocketBase إلى فئة مشتقة من FBB::Fork، والتي تتعامل مع الاتصال مع الطفل كعملية منفصلة (طفل).

مثال

انظر أيضًا مثال clientsocket(3bobcat).

    #include <iostream>
    #include <string>
    #include <bobcat/serversocket>
    #include <bobcat/ifdstream>
    #include <bobcat/ofdstream>
    using namespace std;
    using namespace FBB;
    int main(int argc, char **argv)
    try
    {
        if (argc == 1)
        {
            cerr << "Provide server port number\n";
            return 1;
        }
        size_t portnr = stoul(argv[1]);
        ServerSocket server(portnr);
        cerr << "server listens on port " << argv[1] << endl;
        cerr << "serversocket returns:\n" <<
            "address = " << server.dottedDecimalAddress() << "\n"
            "port    = " << server.port() << endl;
        int fd = server.socket();       // open the socket’s descriptor
        cout << "File descriptor of the socket is " << fd << "\n"
            "The server terminates when it receives a "
                                        "single `q’ on a line\n"
            "A connection is terminated when no input "
                                        "is received anymore.\n"
            "Then another connection is possible" << endl;
        server.listen();                // listen in blocking mode
        while (true)
        {
            SocketBase fdb = server.accept();
            int fd = fdb.socket();
            cerr << "Client FD = " << fd << ", " << endl <<
                    "address = " << fdb.dottedDecimalAddress() << ", " <<
                    endl <<
                    "communication through port " << fdb.port() << endl;
            IFdStream in(fd);           // stream to read from client
            OFdStream out(fd);          // stream to write to client
            string cmd;
            while (getline(in, cmd))
            {
                cout << "Got: " << cmd << endl;
                out << "Got: " << cmd << "\r" << endl;
                if (cmd[0] == ’q’)
                    return 0;
            }
            cout << "Ready for another connection\n";
        }
    }
    catch (Exception const &err)
    {
        cerr <<
            err.what() << endl <<
            "Server socket on port " << argv[1] <<
            " can’t be opened" << endl;
        return -1;
    }

DESCRIPTION

The ServerSocket class is used to implement server-side TCP/IP sockets. A server socket listens to a specific port on the local machine for incoming connection requests from clients. A client-side socket connects to a server socket, and when a client attempts to connect, the server socket can accept the connection and return a new socket object representing the connection to the client. The server can then communicate with the client using the new socket object. If the server socket is not busy, it can accept multiple incoming connection requests. The ServerSocket class implements this functionality.

NAMESPACE

Bobcat

INHERITS FROM

The ServerSocket class inherits from the base class Socket.

CONSTRUCTOR

The ServerSocket class has two constructors:

o
ServerSocket(const char* name, unsigned short port, int backlog = 10): This constructor creates a ServerSocket object that listens on the specified port for incoming connections. The name parameter is a human-readable name for the socket, used for debugging purposes. The backlog parameter specifies the maximum number of pending connections that the socket can queue.
This constructor is useful for creating a server socket that listens on a specific port and accepts incoming connections.
o
ServerSocket(const char* name, const Socket& socket): This constructor creates a ServerSocket object from an existing Socket object. This is useful when you have a socket that has already been created and configured, and you want to use it as a server socket. The name parameter is a human-readable name for the socket.
This constructor is useful for situations where a socket is passed to the constructor, and it is assumed that the socket is already configured and bound to a port.

MEMBER FUNCTIONS

o
virtual ~ServerSocket(): The virtual destructor for the ServerSocket class. It ensures that resources are properly cleaned up when a ServerSocket object is destroyed.
o
Socket* accept(int data = 0, bool nonBlocking = false): This function accepts an incoming connection request on the server socket. If successful, it returns a new Socket object representing the connection to the client. The data parameter can be used to pass arbitrary data to the accepted socket, and the nonBlocking parameter specifies whether the operation should be performed in non-blocking mode.
This function is essential for accepting client connections in a server application.
o
bool listen(int backlog = 10): This function starts listening for incoming connections on the server socket. The backlog parameter specifies the maximum number of pending connections that can be queued.
This function should be called after creating the ServerSocket object and before calling accept() to begin accepting connections.

EXAMPLE

Here is a simple example of how to use the ServerSocket class to create a basic echo server:

#include <iostream>
#include <serversocket.h>
#include <socket.h>

int main() {
    try {
        Bobcat::ServerSocket server("Echo Server", 12345);
        server.listen();

        std::cout << "Server listening on port 12345..." << std::endl;

        while (true) {
            Bobcat::Socket* client = server.accept();
            if (client) {
                std::cout << "Client connected." << std::endl;

                char buffer[1024];
                int bytesRead;
                while ((bytesRead = client->receive(buffer, sizeof(buffer))) > 0) {
                    client->send(buffer, bytesRead);
                }

                std::cout << "Client disconnected." << std::endl;
                delete client;
            }
        }
    } catch (const std::exception& e) {
        std::cerr << "Error: " << e.what() << std::endl;
        return 1;
    }
    return 0;
}

This example creates a server socket that listens on port 12345. It then enters a loop, accepting incoming client connections. For each connection, it reads data from the client, echoes it back, and then closes the connection.
