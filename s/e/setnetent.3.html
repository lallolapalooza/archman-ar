getnetent(3) دليل وظائف المكتبة getnetent(3)

الاسم

getnetent, getnetbyname, getnetbyaddr, setnetent, endnetent - الحصول على مدخل شبكة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <netdb.h>
struct netent *getnetent(void);
struct netent *getnetbyname(const char *name);
struct netent *getnetbyaddr(uint32_t net, int type);
void setnetent(int stayopen);
void endnetent(void);

الوصف

تقوم الدالة getnetent() بقراءة المدخل التالي من قاعدة بيانات الشبكات وإرجاع بنية netent تحتوي على الحقول المفككة من المدخل. يتم فتح اتصال بقاعدة البيانات عند الضرورة.

تقوم الدالة getnetbyname() بإرجاع بنية netent للمدخل من قاعدة البيانات الذي يتطابق مع اسم الشبكة name.

تقوم الدالة getnetbyaddr() بإرجاع بنية netent للمدخل من قاعدة البيانات الذي يتطابق مع رقم الشبكة net من النوع type. يجب أن يكون الوسيط net بترتيب بايت المضيف.

تقوم الدالة setnetent() بفتح اتصال بقاعدة البيانات، وتعيين المدخل التالي ليكون المدخل الأول. إذا كانت stayopen غير صفرية، فلن يتم إغلاق الاتصال بقاعدة البيانات بين استدعاءات إحدى دوال getnet*().

تقوم الدالة endnetent() بإغلاق الاتصال بقاعدة البيانات.

يتم تعريف بنية netent في <netdb.h> على النحو التالي:


struct netent {
    char      *n_name;     /* الاسم الرسمي للشبكة */
    char     **n_aliases;  /* قائمة بالأسماء البديلة */
    int        n_addrtype; /* نوع عنوان الشبكة */
    uint32_t   n_net;      /* رقم الشبكة */
}

أعضاء بنية netent هم:

n_name
الاسم الرسمي للشبكة.
n_aliases
قائمة منتهية بـ NULL بأسماء بديلة للشبكة.
n_addrtype
نوع رقم الشبكة؛ دائمًا AF_INET.
n_net
رقم الشبكة بترتيب بايت المضيف.

قيمة الإرجاع

تقوم الدوال getnetent() و getnetbyname() و getnetbyaddr() بإرجاع مؤشر إلى بنية netent مخصصة ثابتة، أو مؤشر فارغ إذا حدث خطأ أو تم الوصول إلى نهاية الملف.

الملفات

/etc/networks
ملف قاعدة بيانات الشبكات

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
getnetent () سلامة الخيوط MT-Unsafe race:netent race:netentbuf env locale
getnetbyname () سلامة الخيوط MT-Unsafe race:netbyname env locale
getnetbyaddr () سلامة الخيوط MT-Unsafe race:netbyaddr locale
setnetent (), endnetent () سلامة الخيوط MT-Unsafe race:netent env locale

في الجدول أعلاه، تشير netent في race:netent إلى أنه إذا تم استخدام أي من الدوال setnetent() أو getnetent() أو endnetent() بشكل متوازٍ في خيوط مختلفة من البرنامج، فقد تحدث سباقات على البيانات.

المعايير

POSIX.1-2008.

التاريخ

POSIX.1-2001, 4.3BSD.

قبل glibc 2.2، كان الوسيط net للدالة getnetbyaddr() من نوع long.
