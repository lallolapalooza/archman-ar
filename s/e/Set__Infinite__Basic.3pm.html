Set__Infinite__Basic(3pm)

الحزمة: perl-set-infinite

التراخيص: GPL, PerlArtistic

Set::Infinite::Basic(3) وثائق Perl مساهمة من المستخدم Set::Infinite::Basic(3)

الاسم

Set::Infinite::Basic - مجموعات من الفترات 6 =head1 الملخص

use Set::Infinite::Basic;
$set = Set::Infinite::Basic->new(1,2);    # [1..2]
print $set->union(5,6);            # [1..2],[5..6]

الوصف

Set::Infinite::Basic هي وحدة نظرية المجموعات للمجموعات اللانهائية.

تعمل على الأعداد الحقيقية والأعداد الصحيحة والكائنات.

هذه الوحدة لا تدعم التكرارات. يتم تنفيذ التكرارات في Set::Infinite.

الوظائف

empty_set

تنشئ مجموعة فارغة.

إذا تم استدعاؤها من مجموعة موجودة، فإن المجموعة الفارغة ترث خصائص "النوع" و "الكثافة".

universal_set

تنشئ مجموعة تحتوي على "جميع" العناصر الممكنة.

إذا تم استدعاؤها من مجموعة موجودة، فإن المجموعة الشاملة ترث خصائص "النوع" و "الكثافة".

until

تمدد مجموعة حتى مجموعة أخرى:

0,5,7 -> until 2,6,10

تعطي

[0..2), [5..6), [7..10)

ملاحظة: هذه الوظيفة لا تزال تجريبية.

copy

clone

تنشئ كائنًا جديدًا من بيانات الكائن.

وظائف الوضع:

$set = $set->real;
$set = $set->integer;

وظائف المنطق:

$logic = $set->intersects($b);
$logic = $set->contains($b);
$logic = $set->is_null;  # يطلق عليها أيضًا "is_empty"

وظائف المجموعة:

$set = $set->union($b);    
$set = $set->intersection($b);
$set = $set->complement;
$set = $set->complement($b);   # يمكن استدعاؤها أيضًا "minus" أو "difference"
$set = $set->symmetric_difference( $b );
$set = $set->span;   
    النتيجة هي (min .. max)

وظائف القياس:

$i = $set->min;
$i = $set->max;
$i = $set->size;  
$i = $set->count;  # عدد الفترات

وظائف Perl المحملة بشكل زائد:

print    
sort, <=>

تحذيرات

$set = Set::Infinite->new(10,1);
    سيتم تفسيرها على أنها [1..10]
$set = Set::Infinite->new(1,2,3,4);
    سيتم تفسيرها على أنها [1..2],[3..4] بدلاً من [1,2,3,4].
    قد ترغب في ->new([1],[2],[3],[4]) بدلاً من ذلك،
    أو ربما ->new(1,4) 
$set = Set::Infinite->new(1..3);
    سيتم تفسيرها على أنها [1..2],3 بدلاً من [1,2,3].
    قد ترغب في ->new(1,3) بدلاً من ذلك.

الداخليات

التمثيل الداخلي لـ span هو هاش:

{ a =>   بداية الـ span،
  b =>   نهاية الـ span،
  open_begin =>   '0' يبدأ الـ span في 'a'
                  '1' يبدأ الـ span بعد 'a'
  open_end =>     '0' ينتهي الـ span في 'b'
                  '1' ينتهي الـ span قبل 'b'
}

على سبيل المثال، هذه المجموعة:

[100..200),300,(400..infinity)

يتم تمثيلها بواسطة مصفوفة من الهاش:

list => [
    { a => 100, b => 200, open_begin => 0, open_end => 1 },
    { a => 300, b => 300, open_begin => 0, open_end => 0 },
    { a => 400, b => infinity, open_begin => 0, open_end => 1 },
]

يتم تخزين كثافة المجموعة في متغير "tolerance":

tolerance => 0;  # المجموعة مصنوعة من أرقام حقيقية.
tolerance => 1;  # المجموعة مصنوعة من أعداد صحيحة.

يخزن المتغير "type" فئة الكائنات التي سيتم تخزينها في المجموعة.

type => 'DateTime';   # هذه مجموعة من كائنات DateTime

يتم إنشاء قيمة infinity بواسطة Perl، عند اكتشاف تجاوز رقمي:

$inf = 100**100**100;
