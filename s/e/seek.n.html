seek(n)

الحزمة: tcl

seek(n) Tcl Built-In Commands seek(n)

الاسم

seek - تغيير موضع الوصول لقناة مفتوحة

الملخص

seek channelId offset ?origin?

الوصف

يغيّر موضع الوصول الحالي للقناة channelId.

يجب أن يكون ChannelId معرّفًا لقناة مفتوحة مثل قناة Tcl القياسية (stdin أو stdout أو stderr)، أو القيمة المُرجعة من استدعاء open أو socket، أو نتيجة أمر إنشاء قناة يوفّره امتداد Tcl.

تحدّد الوسيطتان offset وorigin الموضع الذي ستحدث عنده عملية القراءة أو الكتابة التالية للقناة channelId. يجب أن يكون Offset عددًا صحيحًا (قد يكون سالبًا) ويجب أن يكون origin واحدًا مما يلي:

start
سيكون موضع الوصول الجديد على بُعد offset بايت من بداية الملف أو الجهاز الأساسي.
current
سيكون موضع الوصول الجديد على بُعد offset بايت من موضع الوصول الحالي؛ حيث ينقل offset السالب موضع الوصول إلى الخلف داخل الملف أو الجهاز الأساسي.
end
سيكون موضع الوصول الجديد على بُعد offset بايت من نهاية الملف أو الجهاز. يضع offset السالب موضع الوصول قبل نهاية الملف، ويضع offset الموجب موضع الوصول بعد نهاية الملف.

القيمة الافتراضية للوسيطة origin هي start.

يقوم الأمر بتفريغ جميع المخرجات المخزّنة مؤقتًا للقناة قبل أن يعود، حتى لو كانت القناة في الوضع غير الحاجز. كما يتجاهل أي إدخال مخزّن مؤقتًا وغير مقروء. يُرجع هذا الأمر سلسلة فارغة. يحدث خطأ إذا طُبّق هذا الأمر على قنوات لا يدعم ملفها أو جهازها الأساسي عملية البحث عن الموضع.

لاحظ أن قيم offset هي إزاحات بالبايت، وليست إزاحات بالأحرف. يعمل كلٌّ من seek وtell بوحدات البايت، لا الأحرف، على خلاف read.

أمثلة

قراءة ملف مرتين:

set f [open file.txt]
set data1 [read $f]
seek $f 0
set data2 [read $f]
close $f
# $data1 eq $data2 إذا لم يتم تحديث الملف

قراءة آخر 10 بايتات من ملف:

set f [open file.data]
# هذا مضمون للعمل مع البيانات الثنائية لكن
# قد يفشل مع ترميزات أخرى...
fconfigure $f -translation binary
seek $f -10 end
set data [read $f 10]
close $f
