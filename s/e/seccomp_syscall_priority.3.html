seccomp_syscall_priority(3)

الحزمة: libseccomp

التراخيص: LGPL-2.1-only

seccomp_syscall_priority(3) توثيق libseccomp seccomp_syscall_priority(3)

الاسم

seccomp_syscall_priority - تحديد أولوية استدعاءات النظام في مرشح seccomp

الملخص

#include <seccomp.h>

typedef void * scmp_filter_ctx;

int SCMP_SYS(syscall_name);

int seccomp_syscall_priority(scmp_filter_ctx ctx,
                             int syscall, uint8_t priority);

ربط مع -lseccomp.

الوصف

توفر الدالة seccomp_syscall_priority() تلميحًا للأولوية لمولد مرشح seccomp في libseccomp بحيث يتم وضع استدعاءات النظام ذات الأولوية الأعلى في وقت مبكر في كود مرشح seccomp، مما يقلل من العبء على حساب استدعاءات النظام ذات الأولوية الأقل. يمكن تعيين أولوية استدعاء النظام بغض النظر عما إذا كانت هناك قواعد موجودة حاليًا لهذا الاستدعاء؛ ستحتفظ المكتبة بالأولوية وسيتم تعيينها لاستدعاء النظام إذا وعندما يتم إنشاء قاعدة لذلك الاستدعاء.

في حين أنه من الممكن تحديد قيمة syscall مباشرة باستخدام قيم __NR_syscall القياسية، لضمان التشغيل السليم عبر معماريات متعددة، يوصى بشدة باستخدام الماكرو SCMP_SYS() بدلاً من ذلك. انظر قسم الأمثلة أدناه.

يأخذ المعامل priority قيمة 8 بت تتراوح من 0 إلى 255؛ تمثل القيمة الأعلى أولوية أعلى.

سياق المرشح ctx هو القيمة التي تم إرجاعها من استدعاء seccomp_init().

قيمة الإرجاع

يعيد الماكرو SCMP_SYS() قيمة مناسبة للاستخدام كقيمة syscall في seccomp_syscall_priority().

تعيد الدالة seccomp_syscall_priority() صفرًا عند النجاح أو أحد رموز الخطأ التالية عند الفشل:

-EDOM
فشل خاص بالمعمارية.
-EFAULT
فشل داخلي في libseccomp.
-EINVAL
مدخلات غير صالحة، إما السياق أو رمز المعمارية غير صالح.
-ENOMEM
لم تتمكن المكتبة من تخصيص ذاكرة كافية.

أمثلة

#include <seccomp.h>
int main(int argc, char *argv[])
{
	int rc = -1;
	scmp_filter_ctx ctx;
	ctx = seccomp_init(SCMP_ACT_KILL);
	if (ctx == NULL)
		goto out;
	/* ... */
	rc = seccomp_syscall_priority(ctx, SCMP_SYS(read), 200);
	if (rc < 0)
		goto out;
	/* ... */
out:
	seccomp_release(ctx);
	return -rc;
}

ملاحظات

في حين يمكن إنشاء مرشح seccomp بشكل مستقل عن النواة، فإن دعم النواة مطلوب لتحميل وإنفاذ مرشح seccomp الذي تم إنشاؤه بواسطة libseccomp.

يمكن العثور على موقع مشروع libseccomp، مع مزيد من المعلومات ومستودع الشفرة المصدرية، على https://github.com/seccomp/libseccomp. هذه الأداة، وكذلك مكتبة libseccomp، قيد التطوير حاليًا، يرجى الإبلاغ عن أي أخطاء في موقع المشروع أو مباشرة إلى المؤلف.
