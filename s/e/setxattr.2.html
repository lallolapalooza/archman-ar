setxattr(2) دليل استدعاءات النظام setxattr(2)

الاسم

setxattr, lsetxattr, fsetxattr - تعيين قيمة سمة موسعة

المكتبة

مكتبة C القياسية (libc, -lc)

المتطلبات

#include <sys/xattr.h>
int setxattr(size_t size;
              const char *path, const char *name,
              const void value[size], size_t size, int flags);
int lsetxattr(size_t size;
              const char *path, const char *name,
              const void value[size], size_t size, int flags);
int fsetxattr(size_t size;
              int fd, const char *name,
              const void value[size], size_t size, int flags);

الوصف

السمات الموسعة هي أزواج اسم:قيمة مرتبطة بعقد (ملفات، أدلة، روابط رمزية، إلخ). وهي امتدادات للسمات العادية المرتبطة بجميع العقد في النظام (أي بيانات stat(2)). يمكن العثور على نظرة عامة كاملة لمفاهيم السمات الموسعة في xattr(7).

تقوم setxattr() بتعيين القيمة للسمة الموسعة المعرفة بالاسم name والمرتبطة بالمسار path المحدد في نظام الملفات. يحدد الوسيط size حجم (بالبايت) value؛ يُسمح بقيمة طولها صفر.

lsetxattr() هي مطابقة لـ setxattr()، باستثناء حالة الرابط الرمزي، حيث يتم تعيين السمة الموسعة على الرابط نفسه، وليس على الملف الذي يشير إليه.

fsetxattr() هي مطابقة لـ setxattr()، فقط يتم تعيين السمة الموسعة على الملف المفتوح الذي يشير إليه fd (كما تم إرجاعه بواسطة open(2)) بدلاً من path.

اسم السمة الموسعة هو سلسلة نصية منتهية بـ NULL. يشمل name بادئة مساحة اسم؛ قد تكون هناك عدة مساحات اسم منفصلة مرتبطة بعقدة فردية. value للسمة الموسعة هي كتلة من البيانات النصية أو الثنائية العشوائية بالطول المحدد.

بشكل افتراضي (أي، flags هو صفر)، سيتم إنشاء السمة الموسعة إذا لم تكن موجودة، أو سيتم استبدال القيمة إذا كانت السمة موجودة بالفعل. لتعديل هذه الدلالات، يمكن تحديد إحدى القيم التالية في flags:

XATTR_CREATE
تنفيذ إنشاء خالص، يفشل إذا كانت السمة المسماة موجودة بالفعل.
XATTR_REPLACE
تنفيذ عملية استبدال خالصة، تفشل إذا كانت السمة المسماة غير موجودة بالفعل.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. عند الفشل، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EDQUOT
حدود حصة القرص تعني أنه لا توجد مساحة كافية متبقية لتخزين السمة الموسعة.
EEXIST
تم تحديد XATTR_CREATE، والسمة موجودة بالفعل.
ENODATA
تم تحديد XATTR_REPLACE، والسمة غير موجودة.
ENOSPC
لا توجد مساحة كافية متبقية لتخزين السمة الموسعة.
ENOTSUP
بادئة مساحة الاسم لـ name غير صالحة.
ENOTSUP
السمات الموسعة غير مدعومة من قبل نظام الملفات، أو تم تعطيلها،
EPERM
الملف معلم بأنه غير قابل للتغيير أو للقراءة فقط. (انظر FS_IOC_SETFLAGS(2const).)

بالإضافة إلى ذلك، يمكن أن تحدث الأخطاء الموثقة في stat(2).

ERANGE
يتجاوز حجم name أو value حدًا خاصًا بنظام الملفات.
