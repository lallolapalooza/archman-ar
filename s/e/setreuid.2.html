setreuid(2)

SETREUID(2) Linux Programmer's Manual SETREUID(2)

NAME

setreuid - set real and effective user IDs

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <unistd.h>

int setreuid(int real, int effective);

DESCRIPTION

The setreuid() system call sets the real and effective user IDs of the calling process. The caller must have appropriate privileges to set arbitrary IDs.

The arguments real and effective specify the desired new real and effective user IDs, respectively. A value of -1 for either argument means that the corresponding ID should not be changed.

A non-privileged process can change its effective user ID to its real user ID, or its real user ID to its effective user ID. It can also change both its real and effective user IDs to the same value.

A process with the CAP_SETUID capability (usually the superuser) can set the real and effective user IDs to any value.

RETURN VALUE

On success, setreuid() returns 0. On error, -1 is returned, and errno is set to indicate the error.

ERRORS

The following error codes are defined in <errno.h>:

EAGAIN
real or effective is not -1, and the requested UID is not the caller's real UID, effective UID, or saved set-UID, and the caller is not privileged.
EINVAL
An invalid argument was provided.
EPERM
real or effective is not -1, and the requested UID is not the caller's real UID, effective UID, or saved set-UID, and the caller is not privileged.

STANDARDS

This system call is specific to Linux and some other Unix-like systems. It is not part of the POSIX standard.

HISTORY

Linux 2.1.43.

setuid(2), setuid(3p)
