semaphore.h(0P) دليل مبرمجي POSIX semaphore.h(0P)

مقدمة

هذه الصفحة اليدوية هي جزء من دليل مبرمجي POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة Linux اليدوية المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة في Linux.

الاسم

semaphore.h — الإشارات (semaphores)

الملخص

#include <semaphore.h>

الوصف

يقوم الرأس <semaphore.h> بتعريف النوع sem_t، المستخدم في إجراء عمليات الإشارة. قد يتم تطبيق الإشارة باستخدام واصف ملف، وفي هذه الحالة يمكن للتطبيقات فتح ما لا يقل عن {OPEN_MAX} ملفات وإشارات إجمالاً.

يقوم الرأس <semaphore.h> بتعريف الثابت الرمزي SEM_FAILED الذي يجب أن يكون من النوع sem_t *.

سيتم تعريف الدوال التالية كدوال وقد يتم تعريفها أيضًا كـ macros. سيتم توفير نماذج أولية للدوال.

int    sem_close(sem_t *);
int    sem_destroy(sem_t *);
int    sem_getvalue(sem_t *restrict, int *restrict);
int    sem_init(sem_t *, int, unsigned);
sem_t *sem_open(const char *, int, ...);
int    sem_post(sem_t *);
int    sem_timedwait(sem_t *restrict, const struct timespec *restrict);
int    sem_trywait(sem_t *);
int    sem_unlink(const char *);
int    sem_wait(sem_t *);

قد يؤدي تضمين الرأس <semaphore.h> إلى إظهار الرموز المعرفة في رأسي <fcntl.h> و <time.h>.

الأقسام التالية إعلامية.
