SelectSaver(3perl) دليل مبرمجي Perl SelectSaver(3perl)

الاسم

SelectSaver - حفظ واستعادة مقبض الملف المحدد

ملخص

use SelectSaver;
{
   my $saver = SelectSaver->new(FILEHANDLE);
   # FILEHANDLE محدد
}
# المقبض السابق محدد
{
   my $saver = SelectSaver->new;
   # قد يتم تحديد مقبض جديد، أو لا
}
# المقبض السابق محدد

الوصف

يحتوي كائن "SelectSaver" على مرجع لمقبض الملف الذي تم تحديده عند إنشائه. إذا حصلت طريقة "new" الخاصة به على معلمة إضافية، فسيتم تحديد تلك المعلمة؛ وإلا، يبقى مقبض الملف المحدد دون تغيير.

عند تدمير "SelectSaver"، يتم إعادة تحديد مقبض الملف الذي تم تحديده عند إنشائه.
