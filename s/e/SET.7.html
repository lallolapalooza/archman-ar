SET(7)

الحزمة: postgresql

التراخيص: PostgreSQL

SET(7) توثيق PostgreSQL 18.1 SET(7)

الاسم

SET - تغيير معلمة تشغيل

الملخص

SET [ SESSION | LOCAL ] parameter_name { = | TO } { value | 'value' | DEFAULT }
SET [ SESSION | LOCAL ] TIME ZONE { value | 'value' | LOCAL | DEFAULT }

الوصف

الأمر SET يغير معلمات التكوين أثناء التشغيل. العديد من معلمات التكوين المذكورة في الفصل 19 يمكن تغييرها أثناء التشغيل باستخدام SET. (بعض المعلمات لا يمكن تغييرها إلا بواسطة المستخدمين الخارقين والمستخدمين الذين مُنحوا الامتياز SET على تلك المعلمة. هناك أيضًا معلمات لا يمكن تغييرها بعد بدء تشغيل الخادم أو الجلسة.) SET يؤثر فقط على القيمة المستخدمة في الجلسة الحالية.

إذا تم إصدار SET (أو SET SESSION المكافئ) داخل معاملة يتم التراجع عنها لاحقًا، فإن آثار أمر SET ستختفي عند التراجع عن المعاملة. بمجرد تأكيد المعاملة المحيطة، ستظل الآثار سارية حتى نهاية الجلسة، إلا إذا تم استبدالها بواسطة SET آخر.

آثار SET LOCAL تستمر فقط حتى نهاية المعاملة، سواء تم تأكيدها أم لا. حالة خاصة هي SET متبوعًا بـ SET LOCAL داخل معاملة واحدة: ستكون قيمة SET LOCAL مرئية حتى نهاية المعاملة، ولكن بعد ذلك (إذا تم تأكيد المعاملة) سيتم تطبيق قيمة SET.

آثار SET أو SET LOCAL يتم إلغاؤها أيضًا عند التراجع إلى نقطة حفظ (savepoint) تكون أقدم من الأمر.

إذا تم استخدام SET LOCAL داخل دالة لديها خيار SET لنفس المتغير (انظر CREATE FUNCTION (CREATE_FUNCTION(7)))، فإن آثار أمر SET LOCAL ستختفي عند الخروج من الدالة؛ أي، سيتم استعادة القيمة الفعالة عند استدعاء الدالة. يسمح هذا باستخدام SET LOCAL للتغييرات الديناميكية أو المتكررة لمعلمة داخل دالة، مع الاحتفاظ براحة استخدام خيار SET لحفظ واستعادة قيمة المتصل. ومع ذلك، فإن أمر SET عادي يتجاوز أي خيارات SET للدالة تم تحديدها؛ ستستمر آثارها حتى يتم إعادة حسابها.


ملاحظة

في إصدارات PostgreSQL من 8.0 إلى 8.2، كانت آثار SET LOCAL تلغى عند تحرير نقطة حفظ سابقة أو عند الخروج بنجاح من كتلة استثناء PL/pgSQL. تم تغيير هذا السلوك لأنه اعتبر غير بديهي.

المعلمات

SESSION

يشير إلى أن الأمر ينطبق على الجلسة الحالية. (هذه هي القيمة الافتراضية إذا لم يتم تحديد SESSION أو LOCAL).

LOCAL

يشير إلى أن الأمر ينطبق فقط على المعاملة الحالية. بعد COMMIT أو ROLLBACK، تصبح إعدادات الجلسة سارية المفعول مرة أخرى. إصدار هذا الأمر خارج كتلة معاملة يصدر تحذيرًا ولا يكون له أي تأثير بخلاف ذلك.

parameter_name

اسم معلمة تكوين يمكن تغييرها. يتم توثيق المعلمات المتاحة في الفصل 19 وما بعده.

value

القيمة الجديدة للمعلمة. يمكن تحديد القيم كثوابت نصية، أو معرفات، أو أرقام، أو قوائم مفصولة بفواصل، حسب ما هو مناسب للمعلمة. يمكن استخدام DEFAULT لإعادة تعيين المعلمة إلى قيمتها الافتراضية (أي، القيمة التي كانت ستكون عليها إذا لم يتم تنفيذ أي SET في هذه الجلسة).

بالإضافة إلى معلمات التكوين الموثقة في الفصل 19، هناك عدد قليل يمكن تعديله باستخدام الأمر SET فقط أو لهما رمز خاص:

SCHEMA

SET SCHEMA 'value' هو اسم مستعار لـ SET search_path TO value. يمكن تحديد مخطط واحد فقط باستخدام هذا الرمز.

NAMES

SET NAMES 'value' هو اسم مستعار لـ SET client_encoding TO value.

SEED

يحدد البذرة الداخلية لمولد الأرقام العشوائية (الدالة random). القيم المسموح بها هي أرقام عائمة بين -1 و 1، بما في ذلك.

يمكن أيضًا تعيين البذرة عن طريق استدعاء الدالة setseed:

SELECT setseed(value);

TIME ZONE

SET TIME ZONE 'value' هو اسم مستعار لـ SET timezone TO 'value'. تسمح صيغة SET TIME ZONE بصيغة خاصة لتحديد المناطق الزمنية. إليك أمثلة للقيم الصالحة:

'America/Los_Angeles'

المنطقة الزمنية لبيركلي، كاليفورنيا.

'Europe/Rome'

المنطقة الزمنية لإيطاليا.

-7

المنطقة الزمنية 7 ساعات غرب UTC (مكافئ لـ PDT). القيم الموجبة موجهة نحو UTC.

'INTERVAL '-08:00' HOUR TO MINUTE'

المنطقة الزمنية 8 ساعات غرب UTC (مكافئ لـ PST).

LOCAL

يضبط المنطقة الزمنية إلى منطقتك الزمنية المحلية (أي، القيمة الافتراضية لسمة timezone للخادم).

يتم تحويل قيم المناطق الزمنية المعطاة كأرقام أو فترات داخليًا إلى صيغة POSIX للمنطقة الزمنية. على سبيل المثال، بعد SET TIME ZONE -7، سيبلغ SHOW TIME ZONE عن <-07>+07.

الاختصارات للمناطق الزمنية غير مدعومة بواسطة SET؛ انظر القسم 8.5.3 لمزيد من المعلومات حول المناطق الزمنية.

ملاحظات

توفر الدالة set_config نفس الوظيفة؛ انظر القسم RESET(7). من الممكن أيضًا تحديث العرض pg_settings لأداء ما يعادل SET.

أمثلة

ضبط مسار البحث:

SET search_path TO my_schema, public;

ضبط نمط التاريخ إلى تقليدي POSTGRES مع اصطلاح الإدخال 'اليوم قبل الشهر'

SET datestyle TO postgres, dmy;

ضبط المنطقة الزمنية إلى بيركلي، كاليفورنيا:

SET TIME ZONE 'America/Los_Angeles';

ضبط المنطقة الزمنية إلى إيطاليا:

SET TIME ZONE 'Europe/Rome';

التوافق

SET TIME ZONE يوسع الصيغة المعرفة في معيار SQL. يسمح المعيار فقط بقيم إزاحة المنطقة الزمنية الرقمية، بينما يسمح PostgreSQL بتحديد أكثر مرونة. جميع الجوانب الأخرى لميزات SET هي امتدادات لـ PostgreSQL.
