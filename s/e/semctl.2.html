semctl(2) دليل استدعاءات النظام semctl(2)

الاسم

semctl - عمليات التحكم في سيمافورات System V

المكتبة

مكتبة C القياسية (libc،  -lc)

الملخص

#include <sys/sem.h>
int semctl(int semid, int semnum, int op, ...);

الوصف

يقوم semctl() بتنفيذ العملية التحكمية المحددة بواسطة op على مجموعة سيمافورات System V التي تم تحديدها بواسطة semid، أو على السيمافور رقم semnum في تلك المجموعة. (السيمافورات في المجموعة مرقمة بدءًا من 0).

تحتوي هذه الدالة على ثلاثة أو أربعة معاملات، اعتمادًا على op. عندما تكون أربعة، يكون الرابع من نوع union semun. يجب على البرنامج المستدعي تعريف هذا الاتحاد على النحو التالي:


union semun {
    int              val;    /* قيمة لـ SETVAL */
    struct semid_ds *buf;    /* مخزن مؤقت لـ IPC_STAT، IPC_SET */
    unsigned short  *array;  /* مصفوفة لـ GETALL، SETALL */
    struct seminfo  *__buf;  /* مخزن مؤقت لـ IPC_INFO
                                (خاص بلينكس) */
};

يتم تعريف بنية البيانات semid_ds في <sys/sem.h> على النحو التالي:


struct semid_ds {
    struct ipc_perm sem_perm;  /* ملكية وصلاحيات */
    time_t          sem_otime; /* وقت آخر عملية semop */
    time_t          sem_ctime; /* وقت الإنشاء / وقت آخر
                                  تعديل عبر semctl() */
    unsigned long   sem_nsems; /* عدد السيمافورات في المجموعة */
};

حقول بنية semid_ds هي كالتالي:

sem_perm
هذه بنية ipc_perm (انظر أدناه) تحدد صلاحيات الوصول إلى مجموعة السيمافورات.
sem_otime
وقت آخر استدعاء نظام semop(2).
sem_ctime
وقت إنشاء مجموعة السيمافورات أو وقت آخر عملية semctl() IPCSET، SETVAL، أو SETALL.
sem_nsems
عدد السيمافورات في المجموعة. كل سيمافور في المجموعة مشار إليه برقم صحيح غير سالب يتراوح من 0 إلى sem_nsems-1.

يتم تعريف بنية ipc_perm على النحو التالي (الحقول المميزة قابلة للتعيين باستخدام IPC_SET):


struct ipc_perm {
    key_t          __key; /* المفتاح المقدم إلى semget(2) */
    uid_t          uid;   /* معرف المستخدم الفعال للمالك */
    gid_t          gid;   /* معرف المجموعة الفعال للمالك */
    uid_t          cuid;  /* معرف المستخدم الفعال للمنشئ */
    gid_t          cgid;  /* معرف المجموعة الفعال للمنشئ */
    unsigned short mode;  /* الصلاحيات */
    unsigned short __seq; /* رقم التسلسل */
};

تحدد أقل 9 بتات من حقل mode في بنية ipc_perm صلاحيات الوصول لقطعة الذاكرة المشتركة. بتات الصلاحيات هي:

0400 قراءة بواسطة المستخدم
0200 كتابة بواسطة المستخدم
0040 قراءة بواسطة المجموعة
0020 كتابة بواسطة المجموعة
0004 قراءة بواسطة الآخرين
0002 كتابة بواسطة الآخرين

في الواقع، تعني "الكتابة" "التعديل" لمجموعة سيمافورات. البتات 0100، 0010، و 0001 (بتات التنفيذ) غير مستخدمة بواسطة النظام.

القيم الصالحة لـ op هي:

IPC_STAT
نسخ المعلومات من بنية بيانات النواة المرتبطة بـ semid إلى بنية semid_ds المشار إليها بواسطة arg.buf. يتم تجاهل المعامل semnum. يجب أن يمتلك العملية المستدعية صلاحية القراءة على مجموعة السيمافورات.
IPC_SET
كتابة قيم بعض أعضاء بنية semid_ds المشار إليها بواسطة arg.buf إلى بنية بيانات النواة المرتبطة بمجموعة السيمافورات هذه، وتحديث عضو sem_ctime الخاص بها أيضًا.
يتم تحديث الأعضاء التالية للبنية: sem_perm.uid، sem_perm.gid، و (أقل 9 بتات من) sem_perm.mode.
يجب أن يتطابق معرف المستخدم الفعال للعملية المستدعية مع المالك (sem_perm.uid) أو المنشئ (sem_perm.cuid) لمجموعة السيمافورات، أو يجب أن تكون العملية المستدعية مميزة. يتم تجاهل المعامل semnum.
IPC_RMID
إزالة مجموعة السيمافورات فورًا، وإيقاظ جميع العمليات المحظورة في استدعاءات semop(2) على المجموعة (مع إرجاع خطأ وتعيين errno إلى EIDRM). يجب أن يتطابق معرف المستخدم الفعال للعملية المستدعية مع منشئ أو مالك مجموعة السيمافورات، أو يجب أن تكون العملية المستدعية مميزة. يتم تجاهل المعامل semnum.
IPC_INFO (خاص بلينكس)
إرجاع معلومات حول حدود ومعلمات السيمافورات على مستوى النظام في البنية المشار إليها بواسطة arg.__buf. هذه البنية من نوع seminfo، معرفة في <sys/sem.h> إذا كان ماكرو اختبار الميزة _GNU_SOURCE معرفًا:

struct seminfo {
    int semmap;  /* عدد الإدخالات في خريطة
                    السيمافورات؛ غير مستخدم داخل النواة */
    int semmni;  /* الحد الأقصى لعدد مجموعات السيمافورات */
    int semmns;  /* الحد الأقصى لعدد السيمافورات في جميع
                    مجموعات السيمافورات */
    int semmnu;  /* الحد الأقصى لهياكل التراجع على مستوى
                    النظام؛ غير مستخدم داخل النواة */
    int semmsl;  /* الحد الأقصى لعدد السيمافورات في
                    مجموعة */
    int semopm;  /* الحد الأقصى للعمليات لـ
                    semop(2) */
    int semume;  /* الحد الأقصى لإدخالات التراجع لكل
                    عملية؛ غير مستخدم داخل النواة */
    int semusz;  /* حجم struct sem_undo */
    int semvmx;  /* قيمة السيمافور القصوى */
    int semaem;  /* الحد الأقصى للقيمة التي يمكن تسجيلها
                    لتعديل السيمافور (SEM_UNDO) */
};

يمكن تغيير إعدادات semmsl، semmns، semopm، و semmni عبر /proc/sys/kernel/sem؛ انظر proc(5) للتفاصيل.
SEM_INFO (خاص بلينكس)
إرجاع بنية seminfo تحتوي على نفس المعلومات كما في IPC_INFO، باستثناء أن الحقول التالية يتم إرجاعها بمعلومات حول موارد النظام التي تستهلكها السيمافورات: يرجع الحقل semusz عدد مجموعات السيمافورات الموجودة حاليًا على النظام؛ ويرجع الحقل semaem العدد الإجمالي للسيمافورات في جميع مجموعات السيمافورات على النظام.
SEM_STAT (خاص بلينكس)
إرجاع بنية semid_ds كما في IPC_STAT. ومع ذلك، فإن المعامل semid ليس معرف سيمافور، بل هو فهرس في المصفوفة الداخلية للنواة التي تحتفظ بمعلومات حول جميع مجموعات السيمافورات على النظام.
SEM_STAT_ANY (خاص بلينكس، منذ لينكس 4.17)
إرجاع بنية semid_ds كما في SEM_STAT. ومع ذلك، لا يتم التحقق من sem_perm.mode لصلاحية القراءة لـ semid، مما يعني أن أي مستخدم يمكنه استخدام هذه العملية (تمامًا كما يمكن لأي مستخدم قراءة /proc/sysvipc/sem للحصول على نفس المعلومات).
GETALL
إرجاع semval (أي، القيمة الحالية) لجميع السيمافورات في المجموعة إلى arg.array. يتم تجاهل المعامل semnum. يجب أن تمتلك العملية المستدعية صلاحية القراءة على مجموعة السيمافورات.
GETNCNT
إرجاع قيمة semncnt للسيمافور رقم semnum في المجموعة (أي، عدد العمليات التي تنتظر زيادة قيمة السيمافور). يجب أن تمتلك العملية المستدعية صلاحية القراءة على مجموعة السيمافورات.
GETPID

SYNOPSIS

#include <sys/types.h> #include <sys/ipc.h> #include <sys/sem.h>

int semctl(int semid, int semnum, int cmd, ...);

DESCRIPTION

The semctl() system call performs the control operation specified by cmd on the semaphore set identified by semid.

semid is the identifier of the semaphore set.

semnum specifies the semaphore number within the set. Semaphores are numbered starting from 0.

cmd is the control operation to be performed. The value of cmd must be one of the following:

SETVAL
Set the value of the semaphore number semnum to the value in the semun union argument arg.val. Only the current user can set the value of a semaphore.
GETVAL
Return the value of the semaphore number semnum.
SETALL
Set the values of all semaphores in the set to the corresponding values in the semun union argument arg.array.
GETALL
Return the values of all semaphores in the set to the corresponding values in the semun union argument arg.array.
GETPID
Return the process ID (PID) of the last process to perform an operation on the semaphore number semnum.
GETNCNT
Return the number of processes whose semaphore semnum is currently waiting for a SEM_UNDO operation to complete.
GETZCNT
Return the number of processes whose semaphore semnum is currently waiting for its value to become zero.

The semun union argument is defined as:

    int              val;    // Value for SETVAL
    struct semid_ds *buf;    // Buffer for IPC_STAT, IPC_SET
