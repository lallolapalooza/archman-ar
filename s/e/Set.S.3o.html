منذ 4.05

val find_first : (elt -> bool) -> t -> elt

find_first f s، حيث f هي دالة متزايدة بشكل رتيب، تُرجع أدنى عنصر e من s بحيث يكون f e، أو إطلاق Not_found إذا لم يكن هناك مثل هذا العنصر.

على سبيل المثال، find_first (fun e -> Ord.compare e x >= 0) s سترجع أول عنصر e من s حيث Ord.compare e x >= 0 (بشكل بديهي: e >= x)، أو إطلاق Not_found إذا كان x أكبر من أي عنصر في s.

التجول

val iter : (elt -> unit) -> t -> unit

iter f s تُطبق f بالتناوب على جميع عناصر s. يتم تقديم عناصر s إلى f بترتيب تصاعدي وفقًا للترتيب على نوع العناصر.

val fold : (elt -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f s init تحسب (f xN ... (f x2 (f x1 init))...)، حيث x1 ... xN هي عناصر s، بترتيب تصاعدي.

التحويل

val map : (elt -> elt) -> t -> t

map f s هي المجموعة التي عناصرها هي f a0، f a1 ... f aN، حيث a0، a1 ... aN هي عناصر s.

يتم تمرير العناصر إلى f بترتيب تصاعدي وفقًا للترتيب على نوع العناصر.

إذا لم يتم تغيير أي عنصر في s بواسطة f، يتم إرجاع s دون تغيير. (إذا كان كل ناتج من f متساويًا فيزيائيًا مع مدخله، فإن المجموعة المرجعة تكون متساوية فيزيائيًا مع s.)

منذ 4.04

val filter : (elt -> bool) -> t -> t

filter f s تُرجع مجموعة جميع العناصر في s التي تحقق الشرط f. إذا حقق f كل عنصر في s، يتم إرجاع s دون تغيير (نتيجة الدالة تكون متساوية فيزيائيًا مع s).

قبل 4.03 لم يكن التساوي الفيزيائي مضمونًا.

val filter_map : (elt -> elt option) -> t -> t

filter_map f s تُرجع مجموعة جميع v بحيث يكون f x = Some v لبعض العناصر x من s.

على سبيل المثال،

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
هي مجموعة أنصاف العناصر الزوجية من s.

إذا لم يتم تغيير أو إسقاط أي عنصر من s بواسطة f (إذا كان f x = Some x لكل عنصر x)، فسيتم إرجاع s دون تغيير: نتيجة الدالة تكون متساوية فيزيائيًا مع s.
