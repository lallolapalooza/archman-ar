SECURITY_LABEL(7)

الحزمة: postgresql

التراخيص: PostgreSQL

SECURITY LABEL(7) توثيق PostgreSQL 18.1 SECURITY LABEL(7)

الاسم

SECURITY LABEL - تعريف أو تغيير تسمية أمنية مطبقة على كائن

الملخص

SECURITY LABEL [ FOR provider ] ON
{
  TABLE object_name |
  COLUMN table_name.column_name |
  AGGREGATE aggregate_name ( aggregate_signature ) |
  DATABASE object_name |
  DOMAIN object_name |
  EVENT TRIGGER object_name |
  FOREIGN TABLE object_name |
  FUNCTION function_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  LARGE OBJECT large_object_oid |
  MATERIALIZED VIEW object_name |
  [ PROCEDURAL ] LANGUAGE object_name |
  PROCEDURE procedure_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  PUBLICATION object_name |
  ROLE object_name |
  ROUTINE routine_name [ ( [ [ argmode ] [ argname ] argtype [, ...] ] ) ] |
  SCHEMA object_name |
  SEQUENCE object_name |
  SUBSCRIPTION object_name |
  TABLESPACE object_name |
  TYPE object_name |
  VIEW object_name
} IS { string_literal | NULL }
where aggregate_signature is:
* |
[ argmode ] [ argname ] argtype [ , ... ] |
[ [ argmode ] [ argname ] argtype [ , ... ] ] ORDER BY [ argmode ] [ argname ] argtype [ , ... ]

الوصف

SECURITY LABEL يطبق تسمية أمنية على كائن قاعدة بيانات. يمكن ربط عدد تعسفي من التسميات الأمنية، واحدة لكل موفر تسمية، بكائن قاعدة بيانات معين. موفرو التسميات هم وحدات قابلة للتحميل تسجل نفسها باستخدام الدالة register_label_provider.


ملاحظة

register_label_provider ليست دالة SQL؛ يمكن استدعاؤها فقط من رمز C يتم تحميله في الواجهة الخلفية.

يحدد موفر التسمية ما إذا كانت تسمية معينة صالحة وما إذا كان مسموحًا بتعيين تلك التسمية لكائن معين. معنى تسمية معينة هو أيضًا وفقًا لتقدير موفر التسمية. لا تفرض PostgreSQL أي قيود على كيفية تفسير موفر التسمية للتسميات الأمنية أو ما إذا كان يجب عليه ذلك؛ إنها ببساطة توفر آلية لتخزينها. في الممارسة العملية، تهدف هذه المنشأة إلى السماح بالتكامل مع أنظمة التحكم في الوصول الإلزامي (MAC) المستندة إلى التسميات مثل SELinux. تتخذ هذه الأنظمة جميع قرارات التحكم في الوصول بناءً على تسميات الكائنات، بدلاً من مفاهيم التحكم في الوصول التقديري (DAC) التقليدية مثل المستخدمين والمجموعات.

يجب أن تمتلك كائن قاعدة البيانات لاستخدام SECURITY LABEL.

المعلمات

object_name
table_name.column_name
aggregate_name
function_name
procedure_name
routine_name

اسم الكائن الذي سيتم تسميته. يمكن أن تكون أسماء الكائنات الموجودة في مخططات (جداول، وظائف، إلخ) مؤهلة بالمخطط.

provider

اسم الموفر الذي سيتم ربط هذه التسمية به. يجب تحميل الموفر المسمى ويجب أن يوافق على عملية التسمية المقترحة. إذا تم تحميل موفر واحد فقط، يمكن حذف اسم الموفر للاختصار.

argmode

وضع وسيطة دالة أو إجراء أو تجميع: IN، OUT، INOUT، أو VARIADIC. إذا تم حذفه، يكون الافتراضي هو IN. لاحظ أن SECURITY LABEL لا تهتم فعليًا بالوسطاء OUT، لأن الوسطاء المدخلين فقط مطلوبين لتحديد هوية الدالة. لذا يكفي سرد الوسطاء IN و INOUT و VARIADIC.

argname

اسم وسيطة دالة أو إجراء أو تجميع. لاحظ أن SECURITY LABEL لا تهتم فعليًا بأسماء الوسطاء، لأن أنواع بيانات الوسطاء فقط مطلوبة لتحديد هوية الدالة.

argtype

نوع بيانات وسيطة دالة أو إجراء أو تجميع.

large_object_oid

معرف الكائن الكبير (OID).

PROCEDURAL

هذه كلمة زائفة.

string_literal

الإعداد الجديد للتسمية الأمنية، مكتوب كحرف نصي.

NULL

اكتب NULL لإزالة التسمية الأمنية.

أمثلة

يوضح المثال التالي كيف يمكن تعيين تسمية أمنية لجدول أو تغييرها:

SECURITY LABEL FOR selinux ON TABLE mytable IS 'system_u:object_r:sepgsql_table_t:s0';

لإزالة التسمية:

SECURITY LABEL FOR selinux ON TABLE mytable IS NULL;

التوافق

لا يوجد أمر SECURITY LABEL في معيار SQL.

راجع أيضًا
