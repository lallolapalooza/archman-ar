محتوى دليل (مثال)

الصفحات التالية هي مجرد أمثلة توضيحية للمحتوى الذي قد تجده في أدلة `man-pages`:

اسم:
setgroups32 - ضبط مجموعة معرفات العمل
مكتبة:
مكتبة C القياسية (libc)، مثل libc
الشكل (Synopsis):
#include <sys/types.h>
#include <unistd.h>

int setgroups32(size_t gidsetsize, const gid_t *gidset);
الوصف:
تُضيف الدالة `setgroups32` كل معرف مجموعة (GID) من المصفوفة `gidset` إلى قائمة معرفات مجموعات العمل للمستدعي. يجب أن يكون حجم المصفوفة `gidsetsize` هو عدد معرفات المجموعات في `gidset`.
قيمة الإرجاع:
عند النجاح، تُرجع `setgroups32` صفرًا. عند الفشل، تُرجع -1، ويتم تعيين `errno` للإشارة إلى الخطأ.
الأخطاء:
  • EPERM: لا يمتلك المستدعي الامتياز المطلوب (CAP_SETGID) لضبط معرفات المجموعات.
  • EINVAL: `gidsetsize` أكبر من عدد المجموعات التي يسمح بها النظام، أو أن `gidset` يحتوي على معرفات مجموعات غير صالحة.
الإصدارات:
تمت إضافة الدالة `setgroups32` في Linux kernel 2.6.11.
المعايير:
تتوافق هذه الدالة مع POSIX.1-2001.
التاريخ:
تم تقديم الدالة `setgroups32` في Linux kernel 2.6.11.
ملاحظات:
عادةً ما يتم استدعاء الدالة `setgroups()` بدلاً من `setgroups32()`. يتم استخدام `setgroups32()` في بعض الأنظمة التي تحتاج إلى التوافق مع معرفات مجموعات 32 بت.
أمثلة:
#include <sys/types.h>
#include <unistd.h>
#include <stdio.h>
#include <stdlib.h>

int main() {
    gid_t groups[] = {1001, 1002}; // معرفات مجموعات كمثال
    size_t num_groups = sizeof(groups) / sizeof(groups[0]);

    if (setgroups32(num_groups, groups) == -1) {
        perror("setgroups32");
        exit(EXIT_FAILURE);
    }

    printf("تم ضبط مجموعات العمل بنجاح.\n");
    return 0;
}
