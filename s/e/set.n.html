set(n)

الحزمة: tcl

التراخيص: TCL

set(n) أوامر Tcl المضمنة set(n)

الاسم

set - قراءة وكتابة المتغيرات

ملخص

set اسم_المتغير ?القيمة?

الوصف

يُرجع قيمة المتغير اسم_المتغير. إذا تم تحديد القيمة، فقم بتعيين قيمة اسم_المتغير إلى القيمة، مع إنشاء متغير جديد إذا لم يكن موجودًا بالفعل، وأرجع قيمته. إذا كان اسم_المتغير يحتوي على قوس مفتوح وينتهي بقوس مغلق، فإنه يشير إلى عنصر مصفوفة: الأحرف قبل القوس المفتوح الأول هي اسم المصفوفة، والأحرف بين الأقواس هي الفهرس داخل المصفوفة. بخلاف ذلك، يشير اسم_المتغير إلى متغير عددي.

إذا تضمن اسم_المتغير مؤهلات مساحة اسم (في اسم المصفوفة إذا كان يشير إلى عنصر مصفوفة)، أو إذا كان اسم_المتغير غير مؤهل (لا يتضمن أسماء أي مساحات أسماء محتواة)، ولكن لا توجد إجراءات نشطة، فإن اسم_المتغير يشير إلى متغير مساحة اسم يتم حله وفقًا للقواعد الموضحة تحت تفسير الاسم في صفحة دليل namespace.

إذا كان هناك إجراء نشط وكان اسم_المتغير غير مؤهل، فإن اسم_المتغير يشير إلى معلمة أو متغير محلي للإجراء، ما لم يتم الإعلان عن اسم_المتغير ليتم حله بشكل مختلف من خلال أحد أوامر global أو variable أو upvar.

أمثلة

تخزين رقم عشوائي في المتغير r:

set r [expr {rand()}]

تخزين رسالة قصيرة في عنصر مصفوفة:

set anAry(msg) "Hello, World!"

تخزين رسالة قصيرة في عنصر مصفوفة محدد بمتغير:

set elemName "msg"
set anAry($elemName) "Hello, World!"

نسخ قيمة إلى المتغير out من متغير اسمه مخزن في vbl (لاحظ أنه غالبًا ما يكون من الأسهل استخدام المصفوفات عمليًا بدلاً من إجراء إلغاء مرجعية مزدوج):

set in0 "small random"
set in1 "large random"
set vbl in[expr {rand() >= 0.5}]
set out [set $vbl]
