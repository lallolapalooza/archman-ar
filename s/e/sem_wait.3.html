sem_wait(3) دليل وظائف المكتبة sem_wait(3)

الاسم

sem_wait, sem_timedwait, sem_trywait - قفل سيمافور

المكتبة

مكتبة خيوط POSIX (libpthread, -lpthread)

الملخص

#include <semaphore.h>
int sem_wait(sem_t *sem);
int sem_trywait(sem_t *sem);
int sem_timedwait(sem_t *restrict sem,
                  const struct timespec *restrict abs_timeout);
متطلبات ماكرو اختبار الميزة لـ glibc (انظر feature_test_macros(7)):

sem_timedwait():

    _POSIX_C_SOURCE >= 200112L

الوصف

يقوم sem_wait() بتقليل (قفل) السيمافور الذي يشير إليه sem. إذا كانت قيمة السيمافور أكبر من الصفر، فسيتم التقليل، وستعود الدالة فورًا. إذا كانت قيمة السيمافور حاليًا صفرًا، فستتوقف الاستدعاء حتى يصبح من الممكن إجراء التقليل (أي، ترتفع قيمة السيمافور فوق الصفر)، أو يقوم معالج إشارة مقاطعة الاستدعاء.

sem_trywait() هي نفس sem_wait()، باستثناء أنه إذا لم يكن من الممكن إجراء التقليل على الفور، فسترجع الاستدعاء خطأ (errno معين إلى EAGAIN) بدلاً من التوقف.

sem_timedwait() هي نفس sem_wait()، باستثناء أن abs_timeout تحدد حدًا للمدة التي يجب أن تتوقف فيها الاستدعاء إذا لم يكن من الممكن إجراء التقليل على الفور. يشير الوسيط abs_timeout إلى بنية timespec(3) تحدد مهلة مطلقة بالثواني وأجزاء من الثانية منذ Epoch، 1970-01-01 00:00:00 +0000 (UTC).

إذا انتهت المهلة بالفعل بحلول وقت الاستدعاء، ولم يكن من الممكن قفل السيمافور على الفور، فستفشل sem_timedwait() بخطأ مهلة (errno معين إلى ETIMEDOUT).

إذا كان من الممكن إجراء العملية على الفور، فلن تفشل sem_timedwait() أبدًا بخطأ مهلة، بغض النظر عن قيمة abs_timeout. علاوة على ذلك، لم يتم التحقق من صحة abs_timeout في هذه الحالة.

قيمة الإرجاع

جميع هذه الدوال ترجع 0 عند النجاح؛ عند حدوث خطأ، تبقى قيمة السيمافور دون تغيير، ويتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EAGAIN
(sem_trywait()) لم يكن من الممكن إجراء العملية دون توقف (أي، السيمافور لديه حاليًا القيمة صفر).
EINTR
تم مقاطعة الاستدعاء بواسطة معالج إشارة؛ انظر signal(7).
EINVAL
sem ليس سيمافورًا صالحًا.
EINVAL
(sem_timedwait()) قيمة abs_timeout.tv_nsecs أقل من 0، أو أكبر من أو تساوي 1000 مليون.
ETIMEDOUT
(sem_timedwait()) انتهت مهلة الاستدعاء قبل أن يمكن قفل السيمافور.

أمثلة

يعمل البرنامج (الذي يمكن اعتباره تافهًا إلى حد ما) المعروض أدناه على سيمافور غير مسمى. يتوقع البرنامج وسيطين في سطر الأوامر. يحدد الوسيط الأول قيمة بالثواني تستخدم لتعيين مؤقت إنذار لتوليد إشارة SIGALRM. يقوم معالج هذا بإنشاء sem_post(3) لزيادة السيمافور الذي يتم الانتظار عليه في main() باستخدام sem_timedwait(). يحدد الوسيط الثاني في سطر الأوامر طول المهلة، بالثواني، لـ sem_timedwait(). تظهر الأشياء التالية عند تشغيل البرنامج مرتين:


$ ./a.out 2 3
About to call sem_timedwait()
sem_post() from handler
sem_timedwait() succeeded
$ ./a.out 2 1
About to call sem_timedwait()
sem_timedwait() timed out

مصدر البرنامج

#include <err.h>
#include <errno.h>
#include <semaphore.h>
#include <signal.h>
#include <stdio.h>
#include <stdlib.h>
#include <time.h>
#include <unistd.h>
#include <assert.h>
sem_t sem;
static void
handler(int sig)
{
    write(STDOUT_FILENO, "sem_post() from handler\n", 24);
    if (sem_post(&sem) == -1) {
        write(STDERR_FILENO, "sem_post() failed\n", 18);
        _exit(EXIT_FAILURE);
    }
}
int
main(int argc, char *argv[])
{
    struct sigaction sa;
    struct timespec ts;
    int s;
    if (argc != 3) {
        fprintf(stderr, "Usage: %s <alarm-secs> <wait-secs>\n",
                argv[0]);
        exit(EXIT_FAILURE);
    }
    if (sem_init(&sem, 0, 0) == -1)
        err(EXIT_FAILURE, "sem_init");
    /* Establish SIGALRM handler; set alarm timer using argv[1].  */
    sa.sa_handler = handler;
    sigemptyset(&sa.sa_mask);
    sa.sa_flags = 0;
    if (sigaction(SIGALRM, &sa, NULL) == -1)
        err(EXIT_FAILURE, "sigaction");
    alarm(atoi(argv[1]));
    /* Calculate relative interval as current time plus
       number of seconds given argv[2].  */
    if (clock_gettime(CLOCK_REALTIME, &ts) == -1)
        err(EXIT_FAILURE, "clock_gettime");
    ts.tv_sec += atoi(argv[2]);
    printf("%s() about to call sem_timedwait()\n", __func__);
    while ((s = sem_timedwait(&sem, &ts)) == -1 && errno == EINTR)
        continue;       /* Restart if interrupted by handler.  */
    /* Check what happened.  */
    if (s == -1) {
        if (errno == ETIMEDOUT)
            printf("sem_timedwait() timed out\n");
        else
            perror("sem_timedwait");
    } else
        printf("sem_timedwait() succeeded\n");
    exit((s == 0) ? EXIT_SUCCESS : EXIT_FAILURE);
}

NAME

sem_wait - lock (and unlock) a semaphore

LIBRARY

Real-time threads library (librt, –thread)

SYNOPSIS


#include <semaphore.h>

int sem_wait(sem_t *sem);
int sem_trywait(sem_t *sem);
int sem_timedwait(sem_t *sem, const struct timespec *abs_timeout);

DESCRIPTION

These functions perform the operations on a semaphore referred to by sem.

A semaphore is a synchronization object that consists of a nonnegative integer value with two atomic operations: increment and decrement.

The semaphore value is incremented by P(sem) (also known as wait, lock, decrement, or semop) and decremented by V(sem) (also known as signal, unlock, or increment).

The decrement operation is implemented by sem_wait(). If the semaphore value is positive, it is decremented, and the function returns immediately. If the semaphore value is zero, the calling thread blocks until the semaphore value becomes positive, then decrements it.

The sem_trywait() function is similar to sem_wait() except that if the semaphore value is zero, the call returns immediately with an error, and errno is set to EAGAIN.

The sem_timedwait() function is similar to sem_wait() except that if the semaphore value is zero, the calling thread blocks until the semaphore value becomes positive, or until the time interval specified by abs_timeout expires.

abs_timeout points to a structure specifying a time limit expressed as seconds and nanoseconds since the Epoch. The structure is defined in <time.h> as follows:


struct timespec {
    time_t tv_sec;        /* seconds */
    long   tv_nsec;       /* nanoseconds */
};

If the semaphore value becomes positive before the timeout expires, sem_timedwait() decrements the semaphore value and returns successfully.

If the timeout expires before the semaphore value becomes positive, sem_timedwait() returns with an error, and errno is set to ETIMEDOUT.

When a thread is woken up from blocking in sem_wait() or sem_timedwait() due to the semaphore value becoming positive, the semaphore value is decremented.

RETURN VALUE

On success, sem_wait(), sem_trywait(), and sem_timedwait() return 0.

On failure, these functions return -1 and set errno to indicate the error.

ERRORS

EINVAL
sem does not refer to a valid semaphore.
EINTR
The signal was caught during the wait.
EAGAIN
sem_trywait() was called, and the semaphore value was zero.
ETIMEDOUT
The timeout expired before the semaphore value became positive.

الاسم

sem_wait - قفل (وفتح) إشارة

المكتبة

مكتبة خيوط الوقت الحقيقي (librt, –thread)

الملخص


#include <semaphore.h>

int sem_wait(sem_t *sem);
int sem_trywait(sem_t *sem);
int sem_timedwait(sem_t *sem, const struct timespec *abs_timeout);

الوصف

تقوم هذه الدوال بتنفيذ العمليات على إشارة تشير إليها sem.

الإشارة هي كائن مزامنة يتكون من قيمة عدد صحيح غير سالب مع عمليتين ذريتين: زيادة وإنقاص.

يتم زيادة قيمة الإشارة بواسطة P(sem) (المعروفة أيضًا بالانتظار، القفل، الإنقاص، أو semop) ويتم إنقاصها بواسطة V(sem) (المعروفة أيضًا بالإشارة، الفتح، أو الزيادة).

يتم تنفيذ عملية الإنقاص بواسطة sem_wait(). إذا كانت قيمة الإشارة موجبة، يتم إنقاصها، وتعود الدالة فورًا. إذا كانت قيمة الإشارة صفرًا، يتم حظر الخيط المستدعي حتى تصبح قيمة الإشارة موجبة، ثم يتم إنقاصها.

الدالة sem_trywait() مشابهة للدالة sem_wait() باستثناء أنه إذا كانت قيمة الإشارة صفرًا، تعود المكالمة فورًا بخطأ، ويتم تعيين errno إلى EAGAIN.

الدالة sem_timedwait() مشابهة للدالة sem_wait() باستثناء أنه إذا كانت قيمة الإشارة صفرًا، يتم حظر الخيط المستدعي حتى تصبح قيمة الإشارة موجبة، أو حتى تنتهي الفترة الزمنية المحددة بواسطة abs_timeout.

abs_timeout يشير إلى بنية تحدد حدًا زمنيًا معبرًا عنه بالثواني والنانوثواني منذ بداية العصر. يتم تعريف البنية في <time.h> على النحو التالي:


struct timespec {
    time_t tv_sec;        /* seconds */
    long   tv_nsec;       /* nanoseconds */
};

إذا أصبحت قيمة الإشارة موجبة قبل انتهاء المهلة، تقوم sem_timedwait() بإنقاص قيمة الإشارة والعودة بنجاح.

إذا انتهت المهلة قبل أن تصبح قيمة الإشارة موجبة، تعود sem_timedwait() بخطأ، ويتم تعيين errno إلى ETIMEDOUT.

عندما يتم إيقاظ خيط من الحظر في sem_wait() أو sem_timedwait() بسبب أن قيمة الإشارة أصبحت موجبة، يتم إنقاص قيمة الإشارة.

قيمة الإرجاع

عند النجاح، تعود sem_wait() و sem_trywait() و sem_timedwait() بالقيمة 0.

عند الفشل، تعود هذه الدوال بالقيمة -1 وتعين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
sem لا تشير إلى إشارة صالحة.
EINTR
تم التقاط الإشارة أثناء الانتظار.
EAGAIN
تم استدعاء sem_trywait()، وكانت قيمة الإشارة صفرًا.
ETIMEDOUT
انتهت المهلة قبل أن تصبح قيمة الإشارة موجبة.
