getmntent(3) دليل وظائف المكتبة getmntent(3)

الاسم

getmntent, setmntent, addmntent, endmntent, hasmntopt, getmntent_r - الحصول على إدخال ملف وصف نظام الملفات

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdio.h>
#include <mntent.h>
FILE *setmntent(const char *path, const char *type);
struct mntent *getmntent(FILE *stream);
int addmntent(FILE *restrict stream,
              const struct mntent *restrict mnt);
int endmntent(FILE *streamp);
char *hasmntopt(const struct mntent *mnt, const char *opt);
/* امتداد GNU */
#include <mntent.h>
struct mntent *getmntent_r(int size;
              FILE *restrict streamp,
              struct mntent *restrict mntbuf,
              char buf[restrict size], int size);

الوصف

تُستخدم هذه الروتينات للوصول إلى ملف وصف نظام الملفات /etc/fstab وملف وصف أنظمة الملفات المثبتة /etc/mtab.

تقوم الدالة setmntent() بفتح ملف وصف نظام الملفات path وتعيد مؤشر ملف يمكن استخدامه بواسطة getmntent(). الوسيط type هو نوع الوصول المطلوب ويمكن أن يأخذ نفس القيم التي يأخذها الوسيط mode الخاص بـ fopen(3). يجب إغلاق التيار المعاد باستخدام endmntent() بدلاً من fclose(3).

تقوم الدالة getmntent() بقراءة السطر التالي من ملف وصف نظام الملفات من stream وتعيد مؤشرًا إلى بنية تحتوي على الحقول المفككة من سطر في الملف. يشير المؤشر إلى منطقة ذاكرة ثابتة يتم الكتابة فوقها بواسطة استدعاءات لاحقة لـ getmntent().

تقوم الدالة addmntent() بإضافة بنية mntent mnt إلى نهاية stream المفتوحة.

تقوم الدالة endmntent() بإغلاق stream المرتبطة بملف وصف نظام الملفات.

تقوم الدالة hasmntopt() بمسح الحقل mnt_opts (انظر أدناه) الخاص ببنية mntent mnt للبحث عن سلسلة فرعية تتطابق مع opt. انظر <mntent.h> و mount(8) للخيارات الصحيحة للتركيب.

الدالة القابلة لإعادة الدخول getmntent_r() مشابهة لـ getmntent()، ولكنها تخزن بنية mntent في *mntbuf المقدمة، وتخزن السلاسل التي تشير إليها الإدخالات في تلك البنية في المصفوفة buf المقدمة بحجم size.

البنية mntent معرفة في <mntent.h> على النحو التالي:


struct mntent {
    char *mnt_fsname;   /* اسم نظام الملفات المثبت */
    char *mnt_dir;      /* بادئة مسار نظام الملفات */
    char *mnt_type;     /* نوع التركيب (انظر mntent.h) */
    char *mnt_opts;     /* خيارات التركيب (انظر mntent.h) */
    int   mnt_freq;     /* تردد التفريغ بالأيام */
    int   mnt_passno;   /* رقم المرور لفحص نظام الملفات المتوازي */
};

بما أن الحقول في ملفات mtab و fstab مفصولة بمسافات بيضاء، يتم استخدام التسلسلات الثمانية لتمثيل الأحرف مسافة (\040)، علامة جدولة (\011)، سطر جديد (\012)، وشرطة مائلة عكسية (\\) في تلك الملفات عندما تحدث في إحدى السلاسل الأربع في بنية mntent. ستقوم الروتينات addmntent() و getmntent() بالتحويل من التمثيل النصي إلى التمثيل المشفّر والعكس. عند التحويل من التمثيل المشفّر، يتم أيضًا تحويل التسلسل \134 إلى شرطة مائلة عكسية.

قيمة الإرجاع

تعيد الدالتان getmntent() و getmntent_r() مؤشرًا إلى بنية mntent أو NULL عند الفشل.

تعيد الدالة addmntent() القيمة 0 عند النجاح و 1 عند الفشل.

تعيد الدالة endmntent() القيمة 1 دائمًا.

تعيد الدالة hasmntopt() عنوان السلسلة الفرعية إذا تم العثور على تطابق و NULL بخلاف ذلك.

التاريخ

الوظائف غير القابلة لإعادة الدخول من SunOS 4.1.3. تم تقديم روتين getmntent_r() في HP-UX 10، ولكنه يعيد int. النموذج الأولي المعروض هو خاص بـ glibc فقط.

يحتوي System V أيضًا على دالة getmntent() ولكن تسلسل الاستدعاء يختلف، والبنية المعاد تكون مختلفة. تحت System V، يتم استخدام /etc/mnttab. تحتوي 4.4BSD و Digital UNIX على روتين getmntinfo()، وهو غلاف حول استدعاء النظام getfsstat().
