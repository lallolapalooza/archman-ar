الوصف

توفر وظائف sg_get_process_stats إحصائيات حول العمليات الجاري تشغيلها حاليًا. تأخذ كلتا الوظيفتين، sg_get_process_stats() و sg_get_process_stats_r()، معامل entries اختياري، والذي يشير (عند توفيره) إلى size_t للحصول على عدد إدخالات المتجه التي تم إرجاعها.

توفر الوظيفتان sg_get_process_count_of() و sg_get_process_count_r() عرضًا مجمعًا لجدول العمليات - فإنهما تقدمان كمية العمليات لكل حالة عملية. sg_get_process_count() هي في الواقع وحدة معالجة مسبقة للتوافق مع الإصدارات السابقة وتستدعي sg_get_process_count_of() بالمعامل pcs الخاص بـ sg_entire_process_count لمحاكاة السلوك حتى الإصدار 0.17.

تقارن هذه الوظائف إدخالي sg_process_stats، وترجع int لتمثيل أيهما أكبر. الاستخدام الرئيسي لهذه الوظائف هو تمريرها إلى qsort لفرز sg_process_stats حسب النوع المحدد.

مثال

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* ترتيب الإدخالات بمقارنة معرف العملية */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

DESCRIPTION

The functions listed in this page are used to retrieve information about the processes running on the system.

The structure returned by the sg_*_res functions is of type sg_process_stats.

typedef struct{
        pid_t                   pid;
        char                    *name;
        char                    *exe;
        char                    *cmdline;
        uid_t                   uid;
        gid_t                   gid;
        char                    *username;
        char                    *groupname;
        size_t                  memory;
        size_t                  resident;
        unsigned long long      pagefaults;
        unsigned long long      old_pages;
        unsigned long long      new_pages;
        time_t                  vtime;
        time_t                  stime;
        time_t                  time;
        int                     priority;
        int                     nice;
        double                  cpu_percent;
        int                     state;
        sg_process_count        *count;
        sg_process_tree         *tree;
        time_t                  systime;
}sg_process_stats;

The sg_process_compare_res function compares two sg_process_stats structures and returns a value indicating whether the first argument is considered to be less than, equal to, or greater than the second. The comparison is based on the PID of the processes.

The other functions in this page retrieve specific fields from an sg_process_stats structure. The retrieved value is stored in the memory pointed to by the second argument. If the function succeeds, a zero is returned. Otherwise, a negative value is returned.

The strings returned by sg_process_name_res, sg_process_exe_res, sg_process_cmdline_res, sg_process_username_res, and sg_process_groupname_res are allocated by libstatgrab and should be freed by the caller using free().

The sg_process_count_res function retrieves the number of processes matching the specified sg_process_count_source. The count is stored in the sg_process_count structure pointed to by count.

The sg_process_tree_res function retrieves the process tree information. The tree is stored in the sg_process_tree structure pointed to by tree.

The sg_process_stats structure contains pointers to other structures like sg_process_count and sg_process_tree. These should also be freed by the caller when no longer needed.

The sg_process_stats structure also contains pointers to strings. These strings are allocated by libstatgrab and should be freed by the caller using free() after the structure itself has been freed.

If you want to retrieve information about all processes on the system, you should use sg_get_process_list() instead.

The sg_process_tree_res function retrieves the process tree information. The process tree is a hierarchical representation of the processes running on the system, where each process is a node in the tree and the parent-child relationships are represented by edges.

typedef struct sg_process_tree sg_process_tree;

The actual structure of `sg_process_tree` is not exposed in this documentation, but it is understood to represent the process hierarchy.

RETURN VALUES

The sg_*_res functions return 0 on success, or a negative value on error. The sg_process_compare_res function returns a negative value if p1 < p2, zero if p1 == p2, and a positive value if p1 > p2.

On success, the retrieved values are stored in the memory pointed to by the second argument.

The strings returned by sg_process_name_res, sg_process_exe_res, sg_process_cmdline_res, sg_process_username_res, and sg_process_groupname_res are allocated by libstatgrab and should be freed by the caller using free().

The sg_process_count and sg_process_tree structures pointed to by the `count` and `tree` fields of sg_process_stats are also allocated by libstatgrab and should be freed by the caller using free() after the sg_process_stats structure itself has been freed.

In the sg_process_stats structure, the fields `name`, `exe`, `cmdline`, `username`, and `groupname` are pointers to strings. These strings are allocated by libstatgrab. The caller is responsible for freeing these strings using free() after the sg_process_stats structure has been freed.

The example below demonstrates how to use these functions:

#include <stdio.h>
#include <stdlib.h>
#include <statgrab.h>

int main(void) {
    sg_process_stats *process_list;
    size_t process_count;
    int ret;

    process_list = sg_get_process_list(&process_count);
    if (!process_list) {
        fprintf(stderr, "Failed to get process list\n");
        return 1;
    }

    for (size_t i = 0; i < process_count; ++i) {
        pid_t pid;
        char *name;
        double cpu_percent;
        sg_process_count count;
        sg_process_tree *tree = NULL;

        ret = sg_process_pid_res(&process_list[i], &pid);
        if (ret == 0) {
            printf("PID: %d\n", pid);
        }

        ret = sg_process_name_res(&process_list[i], &name);
        if (ret == 0) {
            printf("  Name: %s\n", name);
            free(name); /* Free the allocated string */
        }

        ret = sg_process_cpu_percent_res(&process_list[i], &cpu_percent);
        if (ret == 0) {
            printf("  CPU Usage: %.2f%%\n", cpu_percent);
        }

        ret = sg_process_count_res(&process_list[i], sg_entire_process_count, &count);
        if (ret == 0) {
            printf("  Total Processes: %llu\n", count.total);
        }

        // Example of retrieving process tree (if available)
        // Note: sg_process_tree_res might require specific conditions or setup
        ret = sg_process_tree_res(&process_list[i], &tree);
        if (ret == 0 && tree != NULL) {
            printf("  Process has tree info (details depend on sg_process_tree structure)\n");
            // You would need to implement logic to traverse and display the tree
            // free(tree); // Free the allocated tree structure if it was allocated
        }

        /* Free other allocated fields if they were successfully retrieved and allocated */
        /* For example: */
        /*
        char *exe_path;
        ret = sg_process_exe_res(&process_list[i], &exe_path);
        if (ret == 0) {
            printf("  Executable: %s\n", exe_path);
            free(exe_path);
        }
        */
    }

    sg_free_process_list(process_list); /* Free the list of process stats */

    return 0;
}

BUGS

The very first call of sg_get_process_count_of(sg_last_process_count) will return the same as sg_get_process_count_of(sg_entire_process_count).

The compare functions exist rather for backward compatibility than for functionality enhancements. Limited flexibility (e.g. reverse order) and lack of optimising opportunities for the compiler leads to the recommendation to implement the required compare routines locally.
