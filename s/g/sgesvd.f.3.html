الحزمة: lapack-doc

NAME

sgesvd - performs a singular value decomposition of a real matrix.

SYNOPSIS

Subroutine sgesvd(jobu, jobv, m, n, a, lda, s, u, ldu, vt, ldvt, work, lwork, info)

CHARACTER * 1 jobu, jobv

INTEGER m, n, lda, ldu, ldvt, lwork, info

REAL a( lda, * ), s( * ), u( ldu, * ), vt( ldvt, * ), work( * )

Function/Subroutine Documentation

This subroutine computes the singular value decomposition (SVD) of a real matrix A of dimensions M by N. The SVD is a factorization A = U*S*V^T, where U and V are orthogonal matrices, and S is a diagonal matrix. The diagonal entries of S, denoted as s(i), are the singular values of A.

Arguments

jobu

CHARACTER*1. Specifies the options for computing the vectors U.

  • 'A': All M columns of U are returned.
  • 'S': The first K columns of U are returned, where K = min(M,N).
  • 'O': The first M columns of U are returned, if M <= N.
  • 'N': No vectors are computed.
jobv

CHARACTER*1. Specifies the options for computing the vectors V.

  • 'A': All N columns of V are returned.
  • 'S': The first K columns of V are returned, where K = min(M,N).
  • 'O': The first N columns of V are returned, if M >= N.
  • 'N': No vectors are computed.
m

INTEGER. The number of rows of the matrix A.

n

INTEGER. The number of columns of the matrix A.

a

REAL array of dimension (LDA, N). On entry, the M-by-N matrix A.

On exit, the lower trapezoidal part of A, or the full matrix A if jobu = 'O' or jobv = 'O', contains the details of the factorization.

lda

INTEGER. The leading dimension of the array A.

s

REAL array of dimension (min(M,N)). On exit, the singular values of A, sorted in descending order.

u

REAL array of dimension (LDU, K). On exit, the matrix U, or the relevant columns of U, depending on jobu.

ldu

INTEGER. The leading dimension of the array U.

vt

REAL array of dimension (LDVT, N). On exit, the matrix V^T, or the relevant rows of V^T, depending on jobv.

ldvt

INTEGER. The leading dimension of the array VT.

work

REAL array of dimension (LWORK). On exit, work(1) contains the optimal value of LWORK.

lwork

INTEGER. The dimension of the array WORK. If LWORK = -1, then the optimal dimension for LWORK is returned in WORK(1).

info

INTEGER. < 0: If info = -i, the i-th argument had an illegal value.

= 0: Successful exit.

> 0: If info = i, the algorithm did not converge. The i-th singular value did not converge.
