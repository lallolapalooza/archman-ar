Function/Subroutine Documentation

The subroutine sgges3 computes the generalized Schur factorization of a real matrix pair (A, B) and optionally, the left and right Schur vectors.

The generalized Schur factorization is an upper triangular matrix T and orthogonal matrices Z and Q such that

        A = Z * T * Q**T
        B = Z * U * Q**T

where U is a real upper triangular matrix.

The generalized eigenvalues are computed from the diagonal elements of T and U. If

        alpha_i = T(i,i) * U(i,i)
        beta_i  = T(i,i) * U(i,i)

then the generalized eigenvalues are lambda_i = alpha_i / beta_i.

The subroutine can also sort the eigenvalues so that the selected eigenvalues (as specified by the SORT and SELCTG arguments) come first. The corresponding left and right Schur vectors are computed to satisfy

        A * VL = VL * T
        B * VL = VL * U
        A**T * VR = VR * T
        B**T * VR = VR * U

where VL and VR are the matrices of left and right Schur vectors, respectively.

Arguments

JOBVSL

CHARACTER*1. Optional argument.
= 'N': Do not compute the left Schur vectors VL.
'V': Compute the left Schur vectors VL.
Constraint: JOBVSL is supported only when the input matrices A and B are not scaled, i.e. SRFAC is not used.

JOBVSR

CHARACTER*1. Optional argument.
= 'N': Do not compute the right Schur vectors VR.
'V': Compute the right Schur vectors VR.

SORT

CHARACTER*1. Optional argument.
'N': Accept the ordering of the eigenvalues as computed.
'S': Reorder the eigenvalues in the following order: SELCTG(i) = TRUE. for i=1,...,N.

SELCTG

LOGICAL array, dimension (N).
Required if SORT = 'S'.
For i = 1 to N, SELCTG(i) specifies whether the i-th eigenvalue is to be selected.
Not referenced if SORT = 'N'.

N

INTEGER.
The order of the matrices A and B. N >= 0.

A

REAL array, dimension (LDA, *).
On entry, the leading N x N part of this array must contain the matrix A.
On exit, if JOBVSL = 'V' or JOBVSR = 'V', the array contains the matrix A in Schur form T.

LDA

INTEGER.
The leading dimension of the array A. LDA >= max(1, N).

B

REAL array, dimension (LDB, *).
On entry, the leading N x N part of this array must contain the matrix B.
On exit, if JOBVSL = 'V' or JOBVSR = 'V', the array contains the matrix U in Schur form U.

LDB

INTEGER.
The leading dimension of the array B. LDB >= max(1, N).

ALPHA

REAL array, dimension (N).
On exit, ALPHA(i) and BETA(i) contain the real and imaginary parts of the i-th generalized eigenvalue, for i = 1 to N.
ALPHA(i) = T(i,i)
BETA(i) = U(i,i)

BETA

REAL array, dimension (N).
See description of ALPHA.

VL

REAL array, dimension (LDVL, N).
On exit, if JOBVSL = 'V', the matrix VL of left Schur vectors is returned in this array.
Not referenced if JOBVSL = 'N'.

LDVL

INTEGER.
The leading dimension of the array VL.
If JOBVSL = 'V', LDVL >= max(1, N).

VR

REAL array, dimension (LDVR, N).
On exit, if JOBVSR = 'V', the matrix VR of right Schur vectors is returned in this array.
Not referenced if JOBVSR = 'N'.

LDVR

INTEGER.
The leading dimension of the array VR.
If JOBVSR = 'V', LDVR >= max(1, N).

WORK

REAL array, dimension (LWORK).
On exit, WORK(1) contains the optimal value of LWORK.

LWORK

INTEGER.
The dimension of the array WORK.
LWORK >= max(1, 2*N).
For good performance, LWORK must generally be larger.
If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

BWORK

LOGICAL array, dimension (N).
Not referenced if SORT = 'N'.

INFO

INTEGER.
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
= 1,...,N:
The QZ iteration failed. (A,B) are not in Schur form, but ALPHAR(j), ALPHAI(j), and BETA(j) should be correct for j=INFO+1,...,N.
> N: =N+1: other than QZ iteration failed in SLAQZ0.
=N+2: after reordering, roundoff changed values of some complex eigenvalues so that leading eigenvalues in the Generalized Schur form no longer satisfy SELCTG=.TRUE. This could also be caused due to scaling.
=N+3: reordering failed in STGSEN.
