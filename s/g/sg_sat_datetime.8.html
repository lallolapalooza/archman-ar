الملخص

sg_sat_datetime [OPTIONS] DEVICE

الوصف

This utility reads the SATI (SCSI ATA Translation Interface) datetime (date and time) information from the given SCSI generic DEVICE. The datetime information is stored in a 512-byte CDB.

الخيارات

-h, --help
print the help message and exit.
-H, --hex
print the datetime information in hexadecimal.
-o, --offset=arg
set the offset to which the datetime information is written. Defaults to 0.
-r, --raw
print the raw datetime information.
-s, --side=arg
set the side to which the datetime information is written. Defaults to 0.
-v, --verbose
increase the verbosity of the output.
-V, --version
print the version string and exit.

حالة الخروج

Returns non-zero on error.

ملاحظات

This utility is part of the sg3_utils package.

أمثلة

Read the datetime information from the given SCSI generic device: 

                    sg_sat_datetime /dev/sg0
