NAME

sgbsvxx - solve a banded general system of linear equations with iterative refinement.

SYNOPSIS

SUBROUTINE SGBSVXX(
   UPLO, N, KL, KU, NRHS, AB, LDAB, B, LDB, X, LDX, SRCOND, A, LDA, AFAC, LDAFAC,
   IPIV, EQNRHS, WORK, LWORK, IWORK, LIWORK, INFO )

 CHARACTER(LEN=1)      :: UPLO
 INTEGER               :: N, KL, KU, NRHS, LDAB, LDB, LDX, LDA, LDAFAC, LWORK, LIWORK
 REAL, DIMENSION( * )  :: AB, B, X, SRCOND, A, AFAC, WORK
 INTEGER, DIMENSION( * ) :: IPIV, EQNRHS, IWORK
 INTEGER               :: INFO

Function/Subroutine Documentation

UPLO

CHARACTER*1. Must be ‘U’ or ‘L’.

On entry, UPLO specifies whether the upper or lower banded part of matrix A is stored in the array AB. See below for more information.

N

INTEGER. The order of the matrix A. N >= 0.

KL

INTEGER. The number of subdiagonals of the banded matrix A. KL >= 0.

KU

INTEGER. The number of superdiagonals of the banded matrix A. KU >= 0.

NRHS

INTEGER. The number of right hand sides, i.e., the number of columns of the matrices B, X, A, and AFAC. NRHS >= 0.

AB

REAL array, dimension (LDAB,N).

On entry, the upper or lower band part of the original M-by-N matrix A.

It is assumed that the matrix A is N-by-N. The format of AB depends on UPLO.

If UPLO = ‘U’ or ‘U’, AB is an upper triangular band matrix. The diagonal element A(I,I) is in AB(KU+1,I), the first superdiagonal element A(I,I+1) is in AB(KU,I+1), ..., the last superdiagonal element A(I,I+KU) is in AB(1,I+KU).

If UPLO = ‘L’ or ‘l’, AB is a lower triangular band matrix. The diagonal element A(I,I) is in AB(KL+1,I), the first subdiagonal element A(I+1,I) is in AB(KL,I), ..., the last subdiagonal element A(I+KL,I) is in AB(1,I).

Note that the dimensions of AB are larger than necessary if the matrix A is not square. Only the first N columns are used.

LDAB

INTEGER. The leading dimension of the array AB.

If UPLO = ‘U’ or ‘u’, LDAB >= KU + 1.

If UPLO = ‘L’ or ‘l’, LDAB >= KL + 1.

B

REAL array, dimension (LDB,NRHS).

On entry, the right hand side matrix B.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1,N).

X

REAL array, dimension (LDX,NRHS).

On exit, the solution matrix X.

LDX

INTEGER. The leading dimension of the array X. LDX >= max(1,N).

SRCOND

REAL.

On exit, an estimate of the reciprocal condition number of the matrix A. SRCOND is `too small’ if A is near singular.

A

REAL array, dimension (LDA, N).

On exit, the factor of the original matrix A that is used in the solution process. For more information see the description of AFAC.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,N).

AFAC

REAL array, dimension (LDAFAC, N).

On exit, the factor U from the factorization A = U*P (or L*U*P). This is a triangular band matrix.

LDAFAC

INTEGER. The leading dimension of the array AFAC. LDAFAC >= max(1,N).

IPIV

INTEGER array, dimension (MIN(N,KL+KU+1)).

On exit, the pivot indices array. The pivot information derived from the factorization of A. The pivot indices specify the permutation that was applied.

EQNRHS

INTEGER array, dimension (NRHS).

For each right hand side vector b, the corresponding row of EQRHS defines the set of equations for which a solution is computed. Specifically, if EQRHS(J)=K, then the code attempts to solve the system for the first K equations. This is useful if only the first K equations are of interest or if the matrix is block lower triangular.

It is assumed that EQRHS(J) <= N for each J and that EQRHS(J) is non-decreasing with J.

WORK

REAL array, dimension (LWORK).

Workspace array.

LWORK

INTEGER.

The dimension of the array WORK. LWORK >= 0.

If LWORK = -1, then a workspace query is assumed, the routine only calculates the optimal size of the WORK array, and returns this size in the first entry of WORK, and no further processing is done.

IWORK

INTEGER array, dimension (LIWORK).

Workspace array.

LIWORK

INTEGER.

The dimension of the array IWORK. LIWORK >= 0.

If LIWORK = -1, then a workspace query is assumed, the routine only calculates the optimal size of the IWORK array, and returns this size in the first entry of IWORK, and no further processing is done.

INFO

INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value. Negative values of INFO in this range refer to the arguments as follows:

1: UPLO

2: N

3: KL

4: KU

5: NRHS

6: AB

7: LDAB

8: B

9: LDB

10: X

11: LDX

12: SRCOND

13: A

14: LDA

15: AFAC

16: LDAFAC

17: IPIV

18: EQNRHS

19: WORK

20: LWORK

21: IWORK

22: LIWORK

> 0 and <= N: U(INFO,INFO) is exactly zero. The factorization has been completed, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.

= N+J: The solution corresponding to the Jth right- hand side is not guaranteed. The solutions corresponding to other right- hand sides K with K > J may not be guaranteed as well, but only the first such right-hand side is reported. If a small componentwise error is not requested (PARAMS(3) = 0.0) then the Jth right-hand side is the first with a normwise error bound that is not guaranteed (the smallest J such that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0) the Jth right-hand side is the first with either a normwise or componentwise error bound that is not guaranteed (the smallest J such that either ERR_BNDS_NORM(J,1) = 0.0 or ERR_BNDS_COMP(J,1) = 0.0). See the definition of ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information about all of the right-hand sides check ERR_BNDS_NORM or ERR_BNDS_COMP.

Description

The routine `SGBSVXX' is used to solve the equation Ax = B for an N-by-N band matrix A with KL subdiagonals and KU superdiagonals. It is assumed that the matrix A is rectangular and has dimensions M-by-N. The routine then computes the solution for each of the NRHS right hand sides, B(j), j=1:NRHS. Error bounds on the solution are computed, and iterative refinement is performed.

Before calling `SGBSVXX', the user must supply the parameters described in the DESCRIPTION section.

The routine computes an estimate for the reciprocal condition number of A. If the estimate is zero, A is singular. If the estimate is positive, A is non-singular, and the routine computes and returns the solution X, the error bounds on the solution for each right hand side, and estimates of the relative errors in X.

The parameter `PARAMS' is an array of real values that controls the behavior of the routine. Only positions up to NPARAMS are accessed; defaults are used for higher-numbered parameters.

PARAMS(LA_LINRX_ITREF_I = 1)

Whether to perform iterative refinement or not.

Default: 1.0

= 0.0: No refinement is performed, and no error bounds are computed.

= 1.0: Use the double-precision refinement algorithm, possibly with doubled-single computations if the compilation environment does not support DOUBLE PRECISION.

(other values are reserved for future use)

PARAMS(LA_LINRX_ITHRESH_I = 2)

Maximum number of residual computations allowed for refinement.

Default: 10

Aggressive: Set to 100 to permit convergence using approximate factorizations or factorizations other than LU. If the factorization uses a technique other than Gaussian elimination, the guarantees in err_bnds_norm and err_bnds_comp may no longer be trustworthy.

PARAMS(LA_LINRX_CWISE_I = 3)

Flag determining if the code will attempt to find a solution with small componentwise relative error in the double-precision algorithm. Positive is true, 0.0 is false.

Default: 1.0 (attempt componentwise convergence)
