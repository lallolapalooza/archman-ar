الوصف

تقوم sg_init() إما بتهيئة مكتبة statgrab وتعيين عداد التهيئة إلى 1، إذا لم يتم ذلك بالفعل، أو بزيادة عداد التهيئة. إذا تم استدعاؤها للمرة الأولى (في الواقع: عند استدعائها عندما يكون عداد التهيئة 0)، يتم استدعاء منشئ (روتين التهيئة) لكل مكون مسجل، ويتم تهيئة بعض المتغيرات العامة، ويتم تهيئة أقفال الاستبعاد المتبادل المطلوبة وما إلى ذلك. يتم تأمين sg_init() بواسطة القفل المسمى "statgrab".

تسمح sg_log_init() ببعض تهيئة تسجيل الأحداث الخاصة بالتطبيق. وهي مخصصة للمشاريع التي تحتوي على العديد من التطبيقات أو الأوامر التي قد يكون لها ملحقات مختلفة. ضع في اعتبارك أنه يجب استدعاء sg_log_init قبل sg_init، ولكن بعد أن يقوم تطبيقك بتهيئة إطار عمل التسجيل.

sg_snapshot() خاص بنظام Win32 ومن المحتمل أن يتم إزالته.

يقوم sg_shutdown() بتقليل عداد التهيئة. إذا وصل العداد إلى الصفر، يتم استدعاء مدمرات المكونات، ويتم تدمير أقفال الاستبعاد المتبادل (باستثناء "statgrab") وما إلى ذلك. يتم تأمين sg_shutdown() بواسطة القفل المسمى "statgrab".

تقوم sg_drop_privileges() بإسقاط الامتيازات المرتفعة.

قيم الإرجاع

جميع الدوال ترجع رمز خطأ statgrab. إما SG_ERROR_NONE عندما يكون كل شيء على ما يرام أو رمز الخطأ المناسب من منشئ/مدمر.

مثال

تسلسل تهيئة/إنهاء نموذجي عند الاستخدام مع log4cplus:

static void *l4cplus_initializer;
static void
cleanup_logging(void)
{
       log4cplus_deinitialize(l4cplus_initializer);
}
int
main(int argc, char const *argv[])
{
    l4cplus_initializer = log4cplus_initialize();
    atexit((void (*)(void))cleanup_logging);
    sg_log_init("saidar", "SAIDAR_LOG_PROPERTIES", argv[0]);
    sg_init(1);
    if(sg_drop_privileges() != 0) {
	die("Failed to drop setuid/setgid privileges");
    }
    do_something();
    sg_shutdown();
    return 0;
}
