الاسم

sg_get_fs_stats، sg_get_fs_stats_r، sg_get_fs_stats_diff، sg_get_fs_stats_diff_between، sg_free_fs_stats، sg_get_valid_filesystems، sg_set_valid_filesystems، sg_fs_compare_device_name، sg_fs_compare_mnt_point - الحصول على إحصائيات نظام الملفات

الملخص

(size_t *entries);

sg_fs_stats *sg_get_fs_stats_diff_between

sg_error sg_free_fs_stats
(sg_fs_stats *data);

الوصف

توفر وظائف sg_get_fs_stats إحصائيات لأنظمة الملفات المثبتة. تأخذ كلتا الوظيفتين معلمة اختيارية للسجلات (entries)، والتي تشير (عند تقديمها) إلى متغير من نوع size_t لأخذ عدد إدخالات المتجه المرتجعة.

وظائف sg_get_fs_stats() و sg_get_fs_stats_r() تقدم إحصائيات نظام الملفات في اللحظة التي يتم فيها استدعاء الوظيفة. وظائف sg_get_fs_stats_diff() و sg_get_fs_stats_diff_between() تقدم الفرق بين استدعاءين لوظيفتي sg_get_fs_stats() أو sg_get_fs_stats_r()، على التوالي.

اختصار واجهة برمجة التطبيقات (API Shortcut)

الوظيفة تعيد مالك البيانات
sg_get_fs_stats sg_fs_stats * libstatgrab (محلي للخيط)
sg_get_fs_stats_r sg_fs_stats * المتصل
sg_get_fs_stats_diff sg_fs_stats * libstatgrab (محلي للخيط)
sg_get_fs_stats_diff_between sg_fs_stats * المتصل
sg_get_valid_filesystems char ** libstatgrab (عام)

يجب تحرير متجهات sg_fs_stats التي تم الحصول عليها من sg_get_fs_stats_r() أو sg_get_fs_stats_diff_between() باستخدام sg_free_fs_stats() عندما لا تكون هناك حاجة إليها. المتصل هو المسؤول عن ذلك.

تأتي مكتبة statgrab مع قائمة مدمجة بأنواع أنظمة الملفات الصالحة اعتمادًا على نظام التشغيل الذي تم تجميعها له. توفر بعض أنظمة التشغيل واجهة برمجة تطبيقات إضافية لمعرفة أنواع أنظمة الملفات المعروفة أو الصالحة لمثيل نظام التشغيل قيد التشغيل، والتي يتم استخدامها عند اكتشافها. ومع ذلك، هناك مشاكل معروفة عند جمع إحصائيات نظام الملفات: أنظمة الملفات الشبكية يتم تحميلها من خوادم معطلة، ومطورو أنظمة الملفات يشغلون برنامج تشغيل تجريبي إلخ.

لمنع تعطل العمليات عند الحصول على إحصائيات نظام الملفات أو للسماح للمطورين باختبار برامج التشغيل الخاصة بهم، يمكن للعمليات تعديل قائمة أنظمة الملفات الصالحة باستخدام sg_get_valid_filesystems() و sg_set_valid_filesystems(). القائمة التي تعمل معها كلتا الوظيفتين هي مصفوفة من المؤشرات إلى أحرف (char *) تنتهي دائمًا بعنصر يشير إلى NULL.

يجب عدم تعديل القائمة التي تعيدها sg_get_valid_filesystems(). قم دائمًا بنسخ القائمة إلى هيكل خاص بك، إذا كنت تخطط لتوسيع القائمة أو تقليصها:

مثال على إزالة أنظمة الملفات الشبكية

int compare_fs_type(const void *va, const void *vb) {
    const char **a = (const char **)va;
    const char **b = (const char **)vb;
    return strcmp( *a, *b );
}
void filter_network_fs_types(void) {
    /* أسماء أنظمة الملفات الشبكية المعروفة على منصات مختلفة */
    const char *nfs_types[] = { "nfs", "nfs3", "nfs4", "cifs", "smbfs", "samba" };
    const size_t nfs_types_count = sizeof(nfs_types) / sizeof(nfs_types[0])
    size_t fs_entries = 0;
    const char **orig_valid_fs = sg_get_valid_filesystems(&fs_entries);
    /* نسخ إلى ذاكرة خاصة لتعديل القائمة */
    char **valid_fs = calloc( entries + 1, sizeof(valid_fs[0]) );
    memcpy( valid_fs, orig_valid_fs, (entries + 1) * sizeof(valid_fs[0]) );
    size_t i;
    for( i = 0; i < nfs_types_count; ++i ) {
        char **inv_fs = bsearch( &nfs_types[i], &valid_fs[0],
                                 fs_entries, sizeof(valid_fs[0]),
                                 compare_fs_type );
        if( NULL != inv_fs ) {
            /* نسخ بما في ذلك مؤشر NULL النهائي */
            memmove( inv_fs, inv_fs + 1, fs_entries - (inv_fs - valid_fs) );
            --fs_entries;
        }
    }
    sg_set_valid_filesystems( valid_fs );
    free( valid_fs );
}

لاحظ أنه لا حاجة لنسخ السلاسل الموجودة في قائمة أنظمة الملفات الصالحة في المثال أعلاه - فهي لا يتم تعديلها.

قد تصبح القائمة التي تعيدها sg_get_valid_filesystems() غير صالحة عند استخدامها بينما تقوم العملية بإجراء استدعاءات لـ sg_set_valid_filesystems(). لا تحمي أي من وظائف sg_fs_stats الوصول إلى التخزين المستخدم عالميًا حيث يتم الاحتفاظ بنسخة خاصة من قائمة أنظمة الملفات الصالحة. تقع على عاتق المتصل مسؤولية عدم خلط مكالمات التكوين مع مكالمات جلب الإحصائيات.

بالإضافة إلى ذلك، تتوفر وظيفتان داعمتان لـ qsort(3): sg_fs_compare_device_name() و sg_fs_compare_mnt_point().

مثال على الترتيب

size_t entries;
sg_fs_stats *fs_stats = NULL;
while( NULL != ( fs_stats = sg_get_fs_stats_diff(&entries) ) ) {
    /* ترتيب الإدخالات أبجديًا باستخدام نقطة التركيب */
    qsort( fs_stats, entries, sizeof(fs_stats[0]), &sg_fs_compare_mnt_point );
    show_fs_stats( fs_stats );
}

        sg_fs_unknown  = 0,

sg_set_valid_filesystems(3) — libstatgrab — Arch manual pages

NAME

sg_set_valid_filesystems, sg_get_valid_filesystems, sg_free_valid_filesystems - set, get and free the list of valid file systems

SYNOPSIS

#include <statgrab.h>
int
sg_set_valid_filesystems (const char *const *filesystems);
int
sg_get_valid_filesystems (char ***filesystems);
void
sg_free_valid_filesystems (char **filesystems);

DESCRIPTION

The sg_set_valid_filesystems function is used to set the list of file systems that are to be considered valid by libstatgrab. If the list is set to NULL, or if the list is empty, then all file systems will be considered valid.

The list of file systems is represented by an array of strings, each string being a file system type. The array must be terminated by a NULL pointer.

The sg_get_valid_filesystems function is used to retrieve the current list of valid file systems. The list is returned as an array of strings, terminated by a NULL pointer. The caller is responsible for freeing the memory allocated for this list using sg_free_valid_filesystems.

The sg_free_valid_filesystems function is used to free the memory allocated by sg_get_valid_filesystems.

For a full list of available statistics, please refer to statgrab(3).

Statistics

avail
The amount of space available to non-privileged users/processes (free space less reserved space).

avail = free - reserved

free
The amount of space, in bytes, free on the file system.
total_inodes
The total number of inodes in the file system.
used_inodes
The number of used inodes in the file system.
free_inodes
The number of free inodes in the file system.
avail_inodes
The number of free inodes available to non-privileged processes.
io_size
A suggested optimal block size for I/O operations -- if you're reading or writing lots of data, do it in chunks of this size.
block_size
The size in bytes of the minimum unit of allocation on this file system.
total_blocks
The total number of blocks in the file system.
free_blocks
The number of free blocks in the file system.
used_blocks
The number of used blocks in the file system.
avail_blocks
The number of free blocks available to non-privileged processes.
systime
The time in seconds since epoch when the statistic was retrieved from kernel.

BUGS

Only mounted file systems are recognised.

Some file systems might be reported twice when mounted on different mount points.

The compare functions exist rather for backward compatibility than for functionality enhancements. Limited flexibility (e.g. reverse order) and lack of optimising opportunities for the compiler leads to the recommendation to implement the required compare routines locally.

Calling sg_set_valid_filesystems with an empty list with clear the internal list of valid file systems. There's currently no way to reset to the initial list.
