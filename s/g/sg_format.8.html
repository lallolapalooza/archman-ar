الاسم

sg_format - تنسيق، تنسيق مع إعداد مسبق، تغيير حجم قرص SCSI؛ تنسيق شريط

الملخص

sg_format [--cappid] [--cmplst={0|1}] [--count=COUNT] [--dcrt] [--dry-run] [--early] [--ffmt=FFMT] [--fmtmaxlba [--format] [--help] [--ip-def] [--long] [--mode=MP] [--pfu=PFU] [--pie=PIE] [--pinfo] [--poll=PT] [--preset=ID] [--quick] [--resize] [--rto_req] [--security] [--six] [--size=LB_SZ] [--tape=FM] [--timeout=SECS] [--verbose] [--verify] [--version] [--wait] DEVICE

الوصف

لا تحتاج جميع أجهزة الوصول المباشر SCSI إلى التنسيق، والبعض منها له إجراءات تنسيق خاصة بالبائع. أقراص SCSI ذات الوسائط الدوارة ربما تكون أكبر مجموعة تدعم عملية تنسيق "قياسية". يتم تنسيقها عادةً في المصنع بحجم كتلة يبلغ 512 بايت مع أكبر عدد من الكتل التي يوصي بها المصنع. توصية الشركة المصنعة تترك عادةً عددًا معينًا من المسارات، منتشرة عبر الوسائط، لإعادة تعيين الكتل إلى عناوين الكتل المنطقية خلال عمر القرص.

تقوم هذه الأداة بإصدار أحد أوامر تنسيق SCSI الثلاثة: FORMAT UNIT، FORMAT MEDIUM أو FORMAT WITH PRESET. في الوصف التالي، عادةً ما تشير الأقسام غير المؤهلة إلى أمر SCSI FORMAT UNIT. ينطبق كل من FORMAT UNIT و FORMAT WITH PRESET على الأقراص (أو الأجهزة الشبيهة بالأقراص). أمر FORMAT MEDIUM مخصص للأشرطة. يصنف استجابة SCSI INQUIRY "نوع الجهاز الطرفي" (PDT) لكل جهاز SCSI. تستخدم هذه الأداة PDT للتحقق مما إذا كان هناك تعارض بين DEVICE والخيارات المحددة (على سبيل المثال، إعطاء خيار --tape=FM عندما يكون DEVICE قرصًا عاديًا). إذا كان هناك تعارض، فلن تستمر هذه الأداة.

يمكن لهذه الأداة تنسيق أقراص SCSI الحديثة وربما تغيير حجم الكتلة الخاص بها (إذا سمح بذلك) وعدد الكتل (أي عدد الكتل التي يمكن الوصول إليها على الوسائط والمعروفة أيضًا باسم "تغيير الحجم"). قد لا يتطلب تغيير حجم القرص إلى أقل من عدد الكتل الموصى به من قبل الشركة المصنعة عملية تنسيق. لقد أبطل معيار SBC-2 (انظر www.t10.org) صفحة الوضع "format device". تُركت العديد من التفاصيل منخفضة المستوى الموجودة في صفحة الوضع هذه إلى تقدير الشركة المصنعة. توجد صفحة سجل حالة التنسيق (Format Status log page) التي تعرض معلومات حول عمليات التنسيق الناجحة السابقة.

عند استخدام هذه الأداة بدون خيارات (أي، يتم إعطاؤها فقط وسيط DEVICE) فإنها تطبع حجم الكتلة الحالي وعدد الكتل المستمد من مصدرين. هذان المصدران هما واصف الكتلة في الاستجابة لأمر MODE SENSE والاستجابة لأمر READ CAPACITY. سبب هذا الفحص المزدوج هو اكتشاف حالة "تنسيق فاسد" (انظر قسم الملاحظات أدناه). هذا الاستخدام لن يعدل القرص.

عند استخدام هذه الأداة مع --format أو --preset=ID أو --tape=FM، ستحاول تنسيق DEVICE المحدد. في غياب الخيار --quick، يوجد تأخير لمدة 15 ثانية يدعى خلاله المستخدم ثلاث مرات (بفارق 5 ثوانٍ) لإلغاء sg_format. يحدث هذا قبل إصدار أمر SCSI FORMAT UNIT أو FORMAT WITH PRESET أو FORMAT MEDIUM. انظر قسم الملاحظات لمزيد من المعلومات.

معلومات الحماية (PI) اختيارية وتتكون من فاصل حماية واحد أو أكثر، كل منها يتكون من 8 بايتات مرتبطة بكتلة منطقية. عندما تكون PI نشطة، سيكون لكل كتلة منطقية 1، 2، 4، 8، إلخ فاصل حماية (أي قوة من اثنين)، متداخلة مع (وتتبع) بيانات المستخدم التي تشير إليها. تم تعريف أربعة أنواع من الحماية، حيث النوع 0 لا يتضمن فواصل حماية. انظر قسم معلومات الحماية أدناه لمزيد من المعلومات.

عند إعطاء الخيار --tape=FM، يتم إرسال أمر SCSI FORMAT MEDIUM إلى DEVICE. تم تعريف FORMAT MEDIUM في مستندات SSC في T10 ويجهز وحدة لتكون جاهزة للاستخدام. قد يشمل ذلك تقسيم الوسائط. انظر القسم أدناه حول TAPE لمزيد من المعلومات.

تمت إضافة FORMAT WITH PRESET في المسودة SBC-4 مراجعة 18. يتم كتابة نمط معد مسبقًا، محدد بواسطة حقل معرف الإعداد المسبق (--id=FWPID)، على القرص. انظر صفحة VPD الخاصة بإعدادات التنسيق المسبقة (0xb8) للحصول على قائمة بمعرفات الإعداد المسبق للتنسيق المتاحة والبيانات المرتبطة بها.

خيارات

الوسائط للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا. يتم ترتيب الخيارات بترتيب أبجدي بناءً على اسم الخيار الطويل.

-a, --cappid
يضبط هذا الخيار بت CAPPID في رأس MODE SELECT الذي يعد جزءًا من قائمة معلمات هذا الأمر. يلزم وجود أمر MODE SELECT عند تغيير COUNT (أي عدد الكتل المنطقية). يجب أن يكتمل أمر MODE SELECT بنجاح قبل تنفيذ أمر FORMAT UNIT. يرتبط بت CAPPID (المقدم في SBC-5 مراجعة 4) ارتباطًا وثيقًا بصفحة VPD Mapping Product Identification/Capacity (0xba). إذا لم تكن صفحة VPD هذه موجودة، فلن يتم تعيين بت CAPPID ما لم يتم إعطاء الخيار مرتين. إذا لم يكن بت CAPPID مدعومًا، فيجب الإبلاغ عن مفتاح إحساس بالطلب غير الصالح (illegal request) مع إحساس إضافي بـ "حقل غير صالح في قائمة المعلمات" (invalid field in parameter list).
إذا نجح، فقد يؤدي هذا الخيار إلى تغيير حقل معرف المنتج (Product identification field) في استجابة INQUIRY القياسية. إذا كان الأمر كذلك، فسيتم تعيين شرط انتباه الوحدة (Unit attention condition) مع إحساس إضافي بـ "تغيرت بيانات الاستعلام" (Inquiry data has changed).
-C, --cmplst={0|1}
يضبط بت CMPLST ("قائمة كاملة" - complete list) في FORMAT UNIT cdb إلى 0 أو 1. إذا كانت القيمة 0، فسيتم أخذ قائمة GLIST (قائمة النمو - grown list) الحالية في الاعتبار. إذا كانت القيمة 1، فسيتم تجاهل قائمة GLIST الحالية. قيمة CMPLST الافتراضية هي 1 بخلاف ذلك عندما تكون قيمة خيار --ffmt=FFMT غير صفرية، وفي هذه الحالة تكون قيمة CMPLST الافتراضية 0. انظر قسم القوائم أدناه. في معظم الحالات، يجب ترك هذا البت عند قيمته الافتراضية.
-c, --count=COUNT
حيث COUNT هو عدد الكتل المراد تنسيقها أو الوسائط المراد تغيير حجمها. يمكن استخدامه مع --format أو --resize. مع --format، لا يلزم إعطاء هذا الخيار، وفي هذه الحالة يعتبر صفرًا.
مع --format، تفسير COUNT هو:
(COUNT > 0) : تنسيق أول COUNT كتلة فقط وسيبلغ READ CAPACITY عن COUNT كتلة بعد التنسيق
(COUNT = 0) وتغيير حجم الكتلة لم يحدث : استخدم عدد الكتل الحالي
(COUNT = 0) وتغيير حجم الكتلة حدث : أقصى عدد كتل موصى به لحجم الكتلة الجديد
(COUNT = -1) : استخدم أقصى عدد كتل موصى به
(COUNT < -1) : غير صالح. مع --resize، يجب إعطاء هذا الخيار و COUNT له التفسير التالي:
(COUNT > 0) : بعد تغيير الحجم، سيبلغ READ CAPACITY عن COUNT كتلة
(COUNT = 0) : بعد تغيير الحجم، سيبلغ READ CAPACITY عن 0 كتلة
(COUNT = -1) : بعد تغيير الحجم، سيبلغ READ CAPACITY عن أقصى عدد كتل له
(COUNT < -1) : غير صالح
في كلتا الحالتين، إذا تجاوز COUNT المحدد الحد الأقصى لعدد الكتل (لحجم الكتلة)، فسيبلغ القرص عن خطأ. انظر قسم الملاحظات أدناه.
-D, --dcrt
يضبط هذا الخيار بت DCRT في قائمة معلمات FORMAT UNIT. سيؤدي ذلك إلى "تعطيل التصديق" (disable certification). التصديق يتحقق من أن الكتل قابلة للاستخدام أثناء عملية التنسيق. قد يؤدي استخدام هذا الخيار إلى تسريع التنسيق، ولكن --ffmt=FFMT، إذا كان متاحًا، سيكون أفضل على الأرجح. الإجراء الافتراضي لهذه الأداة (أي عند عدم إعطاء هذا الخيار) هو مسح بت DCRT، وبالتالي طلب "تصديق الوسائط" (media certification) (وأيضًا ما لم يطلب خيار آخر ذلك، سيتم مسح بت FOV). عندما يتم تعيين بت DCRT، يجب أيضًا تعيين بت FOV، وبالتالي تقوم sg_format بذلك.
إذا تم إعطاء هذا الخيار مرتين، فسيتم تمكين التصديق عن طريق مسح بت DCRT وتعيين بت FOV. كلا هذين البتين موجودان في قائمة المعلمات المرتبطة بـ FORMAT UNIT cdb.
-d, --dry-run
سيقوم هذا الخيار بتحليل سطر الأوامر، والقيام بكل التحضيرات ولكن تجاوز أمر FORMAT UNIT الفعلي،

NAME

sg_format - formats a SCSI tape or disk.

SYNOPSIS

sg_format [--format-type=FT] [--fmt-vary] [--force] [--help] [--index] [--long] [--mode=MODE] [--new=NEW] [--next] [--pback] [--psize=PSZ] [--quick] [--raw] [--reset] [--resize] [--rseq] [--size=SZ] [--tape] [--truncate] [--verbose] [--version] DEVICE

DESCRIPTION

This utility formats a SCSI tape or disk. Before using this utility, it is strongly recommended to consult the vendor's SCSI documentation for the relevant device. Formatting can destroy existing data.

The DEVICE argument is usually a SCSI generic device like /dev/sg0.

OPTIONS

--format-type=FT
format type. The default is 0 (a full format). Other possible values depend on the device's support. For tape devices, values 1 and 2 are sometimes used.
--fmt-vary
(tape) vary the block size.
--force
force formatting. Some devices may require this option to format a cartridge that is already formatted.
--help
print out the usage message.
--index
(tape) index the tape. Some tape drives support indexing the tape after formatting.
--long
perform a long format. This is the default for disks and usually the default for tapes unless --quick is given.
--mode=MODE
(disk) mode page to use. Default is 0.
--new=NEW
(tape) format new cartridge.
--next
(tape) format next cartridge.
--pback
(tape) write patterns to back of tape.
--psize=PSZ
(disk) block size (in bytes) to use for formatting.
--quick
(tape) perform a quick format. This is typically faster but less thorough than a long format.
--raw
(disk) raw format. This is usually faster than a long format.
--reset
(tape) reset the tape cartridge.
--resize
(disk) resize the partition. This is used to change the partition size.
--rseq
(tape) write random sequence numbers to tape.
--size=SZ
(disk) size of the disk (in blocks) to format. If omitted, the entire disk is formatted.
--tape
treat the device as a tape. This is the default.
--truncate
(disk) truncate the partition. This is used to shrink the partition size.
--verbose
increase the level of verbosity.
--version
print the version string and exit.

LISTS

Some SCSI devices, particularly tape drives, allow formatting with different block sizes and other characteristics. The exact options available depend on the device. Refer to the device's documentation for details.

PROTECTION INFORMATION

Some SCSI disks support protection information. If supported, protection information can be written during formatting. The type of protection information to be written is specified by the --mode option.

NOTES

Formatting a device can be a time-consuming process, especially for large disks or tapes. Be patient and ensure that the process is not interrupted.

Using the wrong options or formatting the wrong device can lead to data loss. Always double-check the DEVICE name and the options before proceeding.

TAPE

For tape devices, the sg_format command can be used to format new cartridges, index tapes, and reset tape cartridges. The default behavior is to format the tape with a variable block size.

EXAMPLES

Format a tape drive with a quick format: sg_format --quick /dev/sg0

Format a disk partition with a block size of 512 bytes: sg_format --psize=512 /dev/sg1

EXIT STATUS

Returns 0 on success, 1 on failure.
