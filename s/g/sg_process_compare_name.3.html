الوصف

توفر الدوال sg_get_process_stats إحصائيات حول العمليات الجاري تشغيلها حاليًا. تأخذ كلتا الدالتين، sg_get_process_stats() و sg_get_process_stats_r()، معلمة اختيارية للإدخالات، والتي تشير (عند تقديمها) إلى قيمة size_t لأخذ عدد الإدخالات المرجعة.

توفر الدالتان sg_get_process_count_of() و sg_get_process_count_r() عرضًا مجمعًا لجدول العمليات - حيث تقدمان كمية العمليات لكل حالة عملية. sg_get_process_count() هو في الواقع وحدة معالجة مسبقة للتوافق الرجعي ويتصل بـ sg_get_process_count_of() بالمعلمة pcs لـ sg_entire_process_count لمحاكاة السلوك حتى 0.17.

اختصار واجهة برمجة التطبيقات (API Shortcut)

الدالة تعيد مالك البيانات
sg_get_process_stats sg_process_stats * libstatgrab (خيط محلي)

sg_get_process_count_of sg_process_count * libstatgrab (خيط محلي)

يجب تحرير متجهات sg_process_stats المستلمة من sg_get_process_stats_r() أو ملخصات sg_process_count المستلمة من sg_get_process_count_r باستخدام sg_free_process_stats() أو sg_free_process_count()، على التوالي. المتصل مسؤول عن القيام بذلك عندما لا تكون البيانات مطلوبة بعد الآن.

تقارن هذه الدوال إدخالات sg_process_stats اثنتين، وتعيد قيمة int لتمثيل أيهما أكبر. الاستخدام الرئيسي لهذه الدوال هو تمريرها إلى qsort لفرز sg_process_stats حسب النوع المحدد.

مثال

size_t entries;
sg_process_stats *proc_stats = NULL;
while( NULL != ( proc_stats = sg_get_process_stats_r(&entries) ) ) {
    /* order entries by comparing the process identifier */
    qsort( proc_stats, entries, sizeof(proc_stats[0]), &sg_process_compare_pid );
    show_proc_stats( proc_stats );
    sg_free_process_stats( proc_stats );
}

قيم الإرجاع

الهيكل الذي تعيده sg_get_process_stats هو من النوع sg_process_stats.

typedef struct {
        char *process_name;
        char *proctitle;
        pid_t pid;    /* process identifier */
        pid_t parent; /* Parent pid */
        pid_t pgid;   /* process id of process group leader */
        pid_t sessid; /* session id of the session the process belongs to */
        uid_t uid;
        uid_t euid;
        gid_t gid;
        gid_t egid;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long proc_size; /* in bytes */
        unsigned long long proc_resident; /* in bytes */
        time_t start_time; /* When was the process started */
        time_t time_spent; /* time running in seconds */
        double cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
} sg_process_stats;

typedef enum {
        SG_PROCESS_STATE_RUNNING,
        SG_PROCESS_STATE_SLEEPING,
        SG_PROCESS_STATE_STOPPED,
        SG_PROCESS_STATE_ZOMBIE,
        SG_PROCESS_STATE_UNKNOWN
} sg_process_state;
process_name
اسم الأمر الذي تم تشغيله. يعتمد محتوى هذا الحقل بشكل كبير على نظام التشغيل الأساسي، حيث يقوم البعض بتخزين اسم المسار الأساسي الذي تمرره العملية القابلة للتنفيذ إلى استدعاء نظام exec(2)، والبعض الآخر يخزن المسار الكامل. معظم أنظمة التشغيل تقيد حجم هذا الحقل - بعضها مثل عائلة *BSD إلى قيمة منخفضة جدًا تبلغ 15 بايت.

عادة ما يكون هذا الحقل غير قابل للتغيير للعمليات في مساحة المستخدم.

proctitle
سطر الأوامر ( "عنوان" ) للعملية. لاحظ - يمكن تعديل هذا بواسطة العملية، لذلك لا يمكن ضمان أنه سطر الأوامر الأصلي.
pid
معرف العملية.
parent
معرف العملية الأب.
pgid
معرف العملية لقائد مجموعة العمليات.
sessid
معرف الجلسة التي تنتمي إليها العملية.
uid
معرف المستخدم الذي تعمل العملية باسمه.
euid
معرف المستخدم الفعلي الذي تعمل العملية باسمه.
gid
معرف المجموعة التي تعمل العملية باسمها.
egid
معرف المجموعة الفعلية التي تعمل العملية باسمها.
context_switches
عدد تبديلات السياق لهذه العملية (طوعية وغير طوعية).
voluntary_context_switches
عدد تبديلات السياق الطوعية لهذه العملية (على سبيل المثال، عن طريق استدعاء sched_yield() أو sleep()).
involuntary_context_switches
عدد تبديلات السياق غير الطوعية لهذه العملية (على سبيل المثال، استنفاد شريحة الوقت أو إرسال إشارة).
proc_size
حجم الذاكرة الافتراضي للعملية بالبايت.
start_time
الوقت الذي بدأت فيه العملية. تمثيل الوقت بوحدة ثواني منذ حقبة النظام (epoch).
time_spent
الوقت المستغرق في تشغيل العملية بالثواني. هذا هو إجمالي وقت وحدة المعالجة المركزية (CPU) التي استهلكتها العملية، حتى لو تم استهلاكه على مدى فترات زمنية مختلفة.
cpu_percent
النسبة المئوية لاستخدام وحدة المعالجة المركزية (CPU) بواسطة العملية. يتم حساب هذه القيمة على مدار آخر قياس.
nice
قيمة "nice" للعملية. تشير القيم الأقل إلى أولوية أعلى.
state
حالة العملية الحالية. يمكن أن تكون إحدى القيم التالية:
SG_PROCESS_STATE_RUNNING
العملية قيد التشغيل حاليًا.
SG_PROCESS_STATE_SLEEPING
العملية نائمة (في انتظار حدث).
SG_PROCESS_STATE_STOPPED
تم إيقاف العملية (على سبيل المثال، عن طريق إشارة SIGSTOP).
SG_PROCESS_STATE_ZOMBIE
العملية ميتة (zombie) (تم الانتهاء منها ولكن لم تتم معالجتها بواسطة العملية الأب).
SG_PROCESS_STATE_UNKNOWN
حالة غير معروفة.
systime
الوقت المستغرق في وضع النظام (kernel mode) بالثواني.

يعيد sg_free_process_stats() 0 عند النجاح، أو -1 عند الخطأ.

sg_process_count
sg_process_count_of
sg_get_process_count
sg_get_process_count_r

يتم تعريف الهيكل التالي:

typedef struct {
        unsigned long long count;
        sg_process_state state;
} sg_process_count;
count
عدد العمليات في حالة معينة.
state
حالة العملية (كما هو موضح أعلاه).

sg_get_process_count_of() لديه المعلمات التالية:

pcs
يحدد مصدر العد. يمكن أن يكون إحدى القيم التالية:
SG_PROCESS_COUNT_SOURCE_RUNNING
العمليات التي هي في حالة تشغيل.
SG_PROCESS_COUNT_SOURCE_SLEEPING
العمليات التي هي في حالة نوم.
SG_PROCESS_COUNT_SOURCE_STOPPED
العمليات التي هي في حالة توقف.
SG_PROCESS_COUNT_SOURCE_ZOMBIE
العمليات التي هي في حالة زومبي.
SG_PROCESS_COUNT_SOURCE_UNKNOWN
العمليات في حالة غير معروفة.
SG_PROCESS_COUNT_SOURCE_ALL
جميع العمليات.
sg_get_process_count_r() يأخذ مؤشرًا إلى sg_process_stats vector (عادةً ما يكون نتيجة استدعاء سابق لـ sg_get_process_stats_r) ويقدم ملخصًا للحالات بناءً على العمليات الموجودة في هذا المتجه.

sg_free_process_count() يعيد 0 عند النجاح، أو -1 عند الخطأ.

sg_process_compare_*

تعيد هذه الدوال:

negative
إذا كان الإدخال الأول أصغر من الثاني.
zero
إذا كانت الإدخالات متساوية.
positive
إذا كان الإدخال الأول أكبر من الثاني.

تستخدم هذه الدوال بشكل أساسي لتمريرها إلى qsort لفرز sg_process_stats حسب النوع المحدد.

DESCRIPTION

The sg_process_compare_* functions are comparison functions that can be used with qsort(3) or other sorting functions.

The sg_get_process_count_of function returns a list of processes that match the criteria given by the source argument.

The argument source can be one of the following values:

sg_entire_process_count
Return information about all processes on the system.
sg_last_process_count
Return information about processes that were running at the time of the last call to sg_get_process_count_of, if the system has not been rebooted since.

The structure returned by sg_get_process_count_of is of type sg_process_count.

typedef struct{
        unsigned long long pid;
        char name[SG_MAX_NAME_LEN];
        unsigned long long proc_resident;
        time_t start_time;
        unsigned long long time_spent;
        unsigned long long cpu_percent;
        int nice;
        sg_process_state state;
        time_t systime;
}sg_process_count_entry;
pid
The process ID.
name
The name of the process.
proc_resident
The size of the process that's resident in memory.
start_time
The time when the process has been started in seconds since epoch.
time_spent
The number of seconds the process has been running (user+system time, without time spent by child processes).
cpu_percent
The current percentage of CPU the process is using.
nice
The nice value of the process.
state
The current state of the process. See sg_process_state for permitted values.
systime
The time in seconds since epoch of the moment where the present statistic has been created. This might be (but doesn't have to be) the same moment for all returned entries, regardless whether they're fetched with one snapshot or puzzled from some kind of procfs.

The structure returned by sg_get_process_count_of and sg_get_process_count_r is of type sg_process_count.

typedef enum sg_process_count_source {
        sg_entire_process_count,
        sg_last_process_count
} sg_process_count_source;

typedef struct{
        unsigned long long total;
        unsigned long long running;
        unsigned long long sleeping;
        unsigned long long stopped;
        unsigned long long zombie;
        unsigned long long unknown;
        time_t systime;
}sg_process_count;
total
The total number of processes.
running
The number of running processes.
sleeping
The number of sleeping processes.
stopped
The number of stopped processes.
zombie
The number of zombie processes.
unknown
The number of processes not matching any of above named categories.
systime
The time in seconds since epoch of the moment where the present statistic has been created.

BUGS

The very first call of sg_get_process_count_of(sg_last_process_count) will return the same as sg_get_process_count_of(sg_entire_process_count).

The compare functions exist rather for backward compatibility than for functionality enhancements. Limited flexibility (e.g. reverse order) and lack of optimising opportunities for the compiler leads to the recommendation to implement the required compare routines locally.
