الوصف

هناك أربع وظائف للحصول على معلومات حول الخطأ الأخير الذي حدث: sg_get_error، sg_get_error_arg، sg_get_error_errno، و sg_get_error_details. الوظائف المتبقية مخصصة لتحسين الواجهة بين الآلة والإنسان (مثل سجل الأخطاء أو مربع الرسالة): sg_str_error توفر اسم خطأ يمكن قراءته بشريًا، و sg_strperror تجهز رسالة خطأ كاملة للطباعة.

يتم تخزين وسيط الخطأ (sg_get_error_arg) محليًا للخيط ويتم إعادة استخدامه في كل مرة يحدث فيها خطأ. إذا كانت هناك حاجة للاستخدام لاحقًا، فإن نسخها يعد استراتيجية مناسبة. وينطبق الشيء نفسه على error_arg الخاص بـ sg_error_details الذي توفره sg_get_error_details.

عندما يستدعي شخص ما الدالة sg_get_error_details مع مؤشر NULL، يتم استبدال الخطأ الأخير بخطأ جديد يصف أن sg_get_error_details تم استدعاؤها بوسائط غير صالحة. يرجى توخي الحذر.

يُسمح باستدعاء الدالة sg_strperror مع أو بدون تفاصيل خطأ مجمعة (err_details هو NULL). في الحالة الأخيرة، يتم استخدام الخطأ الأخير الذي حدث في هذا الخيط لتجهيز رسالة الخطأ. كن على علم بأن مؤشر المخزن المؤقت يجب ألا يكون NULL (يشير إلى قيمة lvalue char * موجودة)، ولكن قيمة lvalue char * التي يشير إليها يجب أن تكون NULL. عند استدعائها بشكل صحيح، هناك شرطي خطأ ممكنان فقط يجعلان sg_strperror تفشل: ENOMEM (نفاد الذاكرة) و EINVAL (رمز خطأ غير صالح).

مثال

if( NULL == sg_get_cpu_stats() ) {
    char *buf = NULL;
    if( NULL != sg_strperror( &buf, NULL ) ) {
        fprintf( stderr, "error getting CPU stats: %s\n", buf );
        free(buf);
        exit(255);
    }
    else {
        fprintf( stderr, "error getting CPU stats and error information\n" );
        exit(255);
    }
}

قيم الإرجاع

تحتوي تفاصيل الخطأ على المعلومات التالية:

typedef struct sg_error_details {
        sg_error error;
        int errno_value;
        const char *error_arg;
} sg_error_details;
error
رمز خطأ مكتبة statgrab.
errno_value
رمز خطأ نظام التشغيل.
error_arg
معلومات إضافية تم تعيينها عند الإبلاغ عن الخطأ.
