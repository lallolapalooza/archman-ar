sg_set_error_with_errno_code(3)

الحزمة: libstatgrab

التراخيص: LGPL, GPL

sg_set_error(3) sg_set_error(3)

الاسم

sg_set_error, sg_set_error_with_errno, sg_set_error_with_errno_code, sg_clear_error - يحدد حالة الخطأ

الملخص

#include <statgrab.h>


sg_error sg_set_error
(sg_error code, const char *arg);


sg_error sg_set_error_with_errno
(sg_error code, const char *arg);


sg_error sg_set_error_with_errno_code
(sg_error code, const char *arg, int errno_value);


void sg_clear_error
(void);

الوصف

sg_set_error() يحدد حالة الخطأ الذي حدث مع وسيط. الوسيط عادة ما يكون وصفيًا، على سبيل المثال، اسم الملف الذي فشل فتحه.

sg_set_error_with_errno() يحدد حالة الخطأ الذي حدث مع وسيط وقيمة مكتبة النظام errno. الوسيط عادة ما يكون وصفيًا، على سبيل المثال، اسم استدعاء sysctl() الفاشل.

sg_set_error_with_errno_code() يحدد حالة الخطأ الذي حدث مع وسيط وقيمة خطأ لاستدعاء مكتبة نظام لا تحدد قيمة errno (على سبيل المثال، استدعاءات pthread_*). الوسيط عادة ما يكون وصفيًا، على سبيل المثال، اسم القفل الذي فشل في الحصول عليه.

sg_clear_error() يمسح حالة الخطأ الحالية.
