NAME

sgtsvx - sGTSVX

SYNOPSIS

    SUBROUTINE SGTSVX( FACT, TRANS, EQUED, N, NRHS, DL, D, DR, DLIN, DIN, DRIN,
&                   DU, DUIN, AB, LDAB, B, LDB, X, LDX, RCOND, BERR,
&                   Z, LDZ, WORK, IWORK, INFO )

Parameters

FACT
CHARACTER*1. 
          = 'N': no reordering is done.
          = 'E': reordering is done.
TRANS
CHARACTER*1. 
          = 'N':  No transpose, solve A*X = B.
          = 'T':  Transpose, solve A**T*X = B.
          = 'C':  Conjugate transpose, solve A**H*X = B.
EQUED
CHARACTER*1. 
          = 'N': no scaling is performed.
          = 'R': row scaling is performed.
          = 'C': column scaling is performed.
          = 'B': both row and column scaling is performed.
N
INTEGER. 
          The order of the matrix A. N >= 0.
NRHS
INTEGER. 
          The number of right hand side vectors, i.e., the number of
          columns of the matrices B, X, and Z. NRHS >= 0.
DL
REAL array, dimension (N-1) 
          The (n-1) sub-diagonal entries of the lower triangular matrix L.
D
REAL array, dimension (N) 
          The diagonal entries of the original bidiagonal matrix A.
DR
REAL array, dimension (N-1) 
          The (n-1) super-diagonal entries of the upper triangular matrix U.
DLIN
REAL array, dimension (N-1) 
          The (n-1) entries of the lower triangular matrix L from input
          when FACT = 'N'.
DIN
REAL array, dimension (N) 
          The N diagonal entries of the original bidiagonal matrix A from
          input when FACT = 'N'.
DRIN
REAL array, dimension (N-1) 
          The (n-1) entries of the upper triangular matrix U from input
          when FACT = 'N'.
DU
REAL array, dimension (N-1) 
          The (n-1) super-diagonal entries of the upper triangular matrix U.
DUIN
REAL array, dimension (N-1) 
          The (n-1) entries of the upper triangular matrix U from input
          when FACT = 'N'.
AB
REAL array, dimension (LDAB, K) where K = max(1, N) 
          On entry with FACT = 'N', AB contains the matrix A.
          On exit with FACT = 'E', AB contains the factored matrix A.
LDAB
INTEGER. 
          The leading dimension of the array AB.  LDAB >= max(1,N).
B
REAL array, dimension (LDB,NRHS). 
          On entry with EQUED = 'N', B contains the right hand side matrix
          B.
          On entry with EQUED = 'R', 'C', or 'B', B contains the scaled
          right hand side matrix B.
LDB
INTEGER. 
          The leading dimension of the array B. LDB >= max(1,N).
X
REAL array, dimension (LDX,NRHS). 
          On exit, the solution matrix X to the system of linear equations.
LDX
INTEGER. 
          The leading dimension of the array X. LDX >= max(1,N).
RCOND
REAL. 
          The reciprocal of the condition number of A.
BERR
REAL array, dimension (NRHS) 
          The componentwise relative backward error of each solution
          vector X(j) (i.e., the smallest relative change in
          any element of A or B that makes X(j) an exact solution).
Z
REAL array, dimension (LDZ,NRHS). 
          The solution of the system J*x = b, where J is the solution
          of the ill-conditioned system.
LDZ
INTEGER. 
          The leading dimension of the array Z. LDZ >= max(1,N).
WORK
REAL array, dimension (3*N) 
          Workspace array.
IWORK
INTEGER array, dimension (N) 
          Workspace array.
INFO
INTEGER. 
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, and i is
                <= N:  U(i,i) is exactly zero.  The factorization
                       has not been completed unless i = N, but the
                       factor U is exactly singular, so the solution
                       and error bounds could not be computed.
                       RCOND = 0 is returned.
                = N+1: U is nonsingular, but RCOND is less than machine
                       precision, meaning that the matrix is singular
                       to working precision.  Nevertheless, the
                       solution and error bounds are computed because
                       there are a number of situations where the
                       computed solution can be more accurate than the
                       value of RCOND would suggest.
