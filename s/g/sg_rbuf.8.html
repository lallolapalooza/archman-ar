sg_rbuf(8)

الحزمة: sg3_utils

التراخيص: GPL, custom:BSD

SG_RBUF(8) SG3_UTILS SG_RBUF(8)

الاسم

sg_rbuf - يقرأ البيانات باستخدام أمر SCSI READ BUFFER

ملخص

sg_rbuf [--buffer=EACH] [--dio] [--help] [--mmap] [--quick] [--size=OVERALL] [--verbose] [--version] DEVICE

sg_rbuf [-b=EACH_KIB] [-d] [-m] [-q] [-s=OVERALL_MIB] [-t] [-v] [-V] DEVICE

الوصف

يقوم هذا الأمر بقراءة البيانات باستخدام أمر SCSI READ BUFFER ثم يتجاهلها. عادةً ما تكون البيانات التي يتم قراءتها من ذاكرة التخزين المؤقت للقرص. يُفترض أن البيانات يتم توفيرها بسرعة (على الرغم من أن هذا غير مضمون بواسطة معايير SCSI) بحيث تكون أسرع من قراءة البيانات من الوسائط. تم تصميم هذا الأمر لقياس سرعات النقل عبر ناقل SCSI.

لجلب البيانات باستخدام أمر SCSI READ BUFFER وفك ترميزها اختياريًا، انظر أداة sg_read_buffer. توجد أيضًا أداة sg_write_buffer مفيدة لتنزيل البرامج الثابتة من بين أشياء أخرى.

هذه أداة خاصة بنظام Linux وتعمل فقط عندما يكون DEVICE عقدة جهاز sg (مثل "/dev/sg1"). تتمتع أداة sg_read_buffer بوظائف مماثلة وتم نقلها إلى أنظمة تشغيل أخرى، وداخل Linux يمكنها استخدام أسماء أجهزة bsg وأجهزة الحظر العادية (مثل "/dev/sdc").

خيارات

الوسائط للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا.

-b, --buffer=EACH
حيث EACH هو عدد البايتات التي سيتم نقلها بواسطة كل أمر READ BUFFER. القيمة الافتراضية هي حجم المخزن المؤقت المتاح فعليًا الذي تم إرجاعه بواسطة أمر READ BUFFER (الموصوف). الحد الأقصى هو نفسه القيمة الافتراضية، وبالتالي لا يمكن استخدام هذه الوسيلة إلا لتقليل حجم كل نقل إلى أقل من حجم المخزن المؤقت الفعلي للجهاز.
-d, --dio
استخدم الإدخال/الإخراج المباشر إذا كان متاحًا. هذا الخيار متاح فقط إذا كان DEVICE عقدة جهاز برنامج sg (مثل /dev/sg1). في هذه الحالة، سيحاول برنامج sg تكوين DMA من محول SCSI لنقل البيانات مباشرة إلى ذاكرة المستخدم. سيؤدي هذا إلى إلغاء النسخ عبر مخازن النواة المؤقتة. إذا لم يكن متاحًا، فسيتم الإبلاغ عن ذلك وسيتم إجراء إدخال/إخراج غير مباشر بدلاً من ذلك.
-h, --help
طباعة رسالة الاستخدام ثم الخروج.
-m, --mmap
استخدم الإدخال/الإخراج المعين بالذاكرة إذا كان متاحًا. هذا الخيار متاح فقط إذا كان DEVICE عقدة جهاز برنامج sg (مثل /dev/sg1). في هذه الحالة، سيحاول برنامج sg تكوين DMA من محول SCSI لنقل البيانات مباشرة إلى ذاكرة المستخدم. سيؤدي هذا إلى إلغاء النسخ عبر مخازن النواة المؤقتة.
-O, --old
التبديل إلى خيارات الأسلوب القديم. يرجى استخدامه كأول خيار.
-q, --quick
نقل البيانات فقط إلى مخازن النواة المؤقتة (عادةً بواسطة DMA من بطاقة محول SCSI) وعدم نقلها إلى مساحة المستخدم. هذا الخيار متاح فقط إذا كان DEVICE عقدة جهاز برنامج sg (مثل /dev/sg1).
-s, --size=OVERALL
حيث OVERALL هو حجم النقل الإجمالي بالبايت. القيمة الافتراضية هي 200 ميبي (200*1024*1024 بايت). قد يكون العدد الفعلي للبايتات المنقولة أقل قليلاً من المطلوب نظرًا لأن جميع عمليات النقل لها نفس الحجم (ويتم إجراء قسمة صحيحة تقريبًا نحو الصفر).
-t, --time
يقوم بتوقيت مكون نقل البيانات بالجملة لهذا الأمر. يتم طباعة الوقت المنقضي بالإضافة إلى حساب ميجا بايت/ثانية. في هذه الحالة، "MB" هي 1,000,000 بايت. يتم استخدام استدعاء نظام gettimeofday() داخليًا لحساب الوقت.
-v, --verbose
زيادة مستوى التفصيل. يمكن استخدامه عدة مرات.
-V, --version
طباعة سلسلة الإصدار ثم الخروج.

ملاحظات

عادةً ما يستخدم هذا الأمر على الأقراص SCSI الحديثة التي تحتوي على ذاكرة تخزين مؤقت RAM في إلكترونياتها. إذا لم يكن هناك إدخال/إخراج إلى الوسائط المغناطيسية، أو أجهزة أبطأ مثل ذاكرة الفلاش، فقد يكون القرص قادرًا على توفير البيانات بسرعة كافية لإشباع عرض نطاق ناقل SCSI. قد يكون الاختناق بعد ذلك هو DMA في HBA، أو برامج تشغيل Linux، أو أجهزة الكمبيوتر المضيف (على سبيل المثال، سرعة ذاكرة الوصول العشوائي).

قد تتضمن الوسائط الرقمية المختلفة (على سبيل المثال، OVERALL) لواحق مضاعفة أو يتم تقديمها بالنظام الست عشري. انظر قسم "الوسائط الرقمية" في صفحة دليل sg3_utils(8).

أمثلة

على نظام الاختبار، يتوافق /dev/sg0 مع قرص سريع على ناقل U2W SCSI (بحد أقصى 80 ميجا بايت/ثانية). تنص مواصفات القرص على أن ذاكرته المؤقتة هي 4 ميجابايت.
$ time ./sg_rbuf /dev/sg0
تقارير READ BUFFER: سعة المخزن المؤقت = 3434944،
حد فاصل المخزن المؤقت = 6
قراءة 200 ميبي (199 ميبي فعلي، 209531584 بايت)،
حجم المخزن المؤقت = 3354 كيلوبايت
الوقت الحقيقي 0م5.072ث، وقت المستخدم 0م0.000ث، وقت النظام 0م2.280ث

لذلك، هذا حوالي 40 ميجابايت/ثانية باستهلاك 40٪. الآن مع إضافة الخيار "-q"، يتحسن هذا الإنتاجية وينخفض الاستهلاك إلى 0٪.
$ time ./sg_rbuf -q /dev/sg0
تقارير READ BUFFER: سعة المخزن المؤقت = 3434944،
حد فاصل المخزن المؤقت = 6
قراءة 200 ميبي (199 ميبي فعلي، 209531584 بايت)،
حجم المخزن المؤقت = 3354 كيلوبايت
الوقت الحقيقي 0م2.784ث، وقت المستخدم 0م0.000ث، وقت النظام 0م0.000ث

حالة الخروج لـ sg_rbuf هي 0 عند نجاحها. بخلاف ذلك، انظر صفحة دليل sg3_utils(8).

خيارات سطر الأوامر الأقدم

كانت الخيارات في هذا القسم هي الوحيدة المتاحة قبل الإصدار 1.23 من sg3_utils. منذ ذلك الحين، تفضل هذه الأداة افتراضيًا خيارات سطر الأوامر الأحدث التي يمكن تجاوزها باستخدام --old (أو -O) كأول خيار. انظر قسم متغيرات البيئة لمعرفة طريقة أخرى لإجبار استخدام خيارات سطر الأوامر القديمة هذه.

-b=EACH_KIB
حيث EACH_KIB هو عدد الكيلوبايت (أي وحدات 1024 بايت) التي سيتم نقلها بواسطة كل أمر READ BUFFER. مشابه لـ --buffer=EACH في الوصف الرئيسي ولكن الوحدات مختلفة.
-d
استخدم الإدخال/الإخراج المباشر إذا كان متاحًا. يعادل الخيار --dio في الوصف الرئيسي.
-m
استخدم الإدخال/الإخراج المعين بالذاكرة إذا كان متاحًا. يعادل الخيار --mmap في الوصف الرئيسي.
-N, --new
التبديل إلى خيارات الأسلوب الجديد.
-q
نقل البيانات فقط إلى مخازن النواة المؤقتة (عادةً بواسطة DMA من بطاقة محول SCSI) وعدم نقلها إلى مساحة المستخدم. يعادل الخيار --quick في الوصف الرئيسي.
-s=OVERALL_MIB
حيث OVERALL_MIB هو حجم النقل الإجمالي بالميجابايت (1048576 بايت). مشابه لـ --size=OVERALL في الوصف الرئيسي ولكن الوحدات مختلفة.
-t
يقوم بتوقيت مكون نقل البيانات بالجملة لهذا الأمر. يعادل الخيار --time في الوصف الرئيسي.
-v
زيادة مستوى التفصيل. يمكن استخدامه عدة مرات.
-V
طباعة سلسلة الإصدار ثم الخروج.

ENVIRONMENT VARIABLES

The SG_LIB_FILE environment variable can be used to specify a file containing command line options. This file is read and its contents are processed as if they were command line options. This can be useful for setting many default options, or options that are always used. The contents of the file are processed in the order they appear. Blank lines and lines starting with '#' are ignored. Each non-blank line is treated as a separate command line option. Command line options given on the command line override options from this file.

The _OLD_OPTS can be given. When it is present this utility will expect the older command line options. So the presence of this environment variable is equivalent to using --old (or -O) as the first command line option.

متغيرات البيئة

يمكن استخدام متغير البيئة SG_LIB_FILE لتحديد ملف يحتوي على خيارات سطر الأوامر. يتم قراءة هذا الملف ومعالجة محتوياته كما لو كانت خيارات سطر الأوامر. يمكن أن يكون هذا مفيدًا لتعيين العديد من الخيارات الافتراضية، أو الخيارات التي يتم استخدامها دائمًا. يتم معالجة محتويات الملف بالترتيب الذي تظهر به. يتم تجاهل الأسطر الفارغة والأسطر التي تبدأ بـ '#'. يتم التعامل مع كل سطر غير فارغ كخيار سطر أوامر منفصل. تتجاوز خيارات سطر الأوامر المقدمة على سطر الأوامر الخيارات من هذا الملف.

يمكن إعطاء _OLD_OPTS. عندما يكون موجودًا، سيتوقع هذا الأداة خيارات سطر الأوامر القديمة. لذا فإن وجود متغير البيئة هذا يعادل استخدام --old (أو -O) كأول خيار في سطر الأوامر.
