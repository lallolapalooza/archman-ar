الاسم

sg_logs - الوصول إلى صفحات السجل باستخدام أمر SCSI LOG SENSE

ملخص

sg_logs [--ALL] [--all] [--brief] [--exclude] [--filter=FL] [--full] [--hex] [--json[=JO]] [--js-file=JFN] [--list] [--maxlen=LEN] [--name] [--no_inq] [--page=PG] [--paramp=PP] [--pcb] [--ppc] [--pdt=DT] [--raw] [--readonly] [--sp] [--temperature] [--transport] [--undefined] [--vendor=VP] [--verbose] DEVICE

sg_logs --inhex=FN [--ALL] [--all] [--brief] [--exclude] [--filter=FL] [--full] [--hex] [--json[=JO]] [--js-file=JFN] [--list] [--name] [--page=PG] [--pdt=DT] [--raw] [--undefined] [--vendor=VP]

sg_logs --select [--control=PC] [--page=PG] [--raw] [--reset] [--sp] [--verbose] DEVICE

sg_logs --enumerate [--filter=FL] [--help] [--vendor=VP] [--version]

sg_logs [-a] [-A] [-b] [-c=PC] [-D=DT] [-e] [-E] [-f=FL] [-F] [-h] [-H] [-i=FN] [-l] [-L] [-m=LEN] [-M=VP] [-n] [-p=PG] [-paramp=PP] [-pcb] [-ppc] [-r] [-R] [-select] [-sp] [-t] [-T] [-u] [-v] [-V] [-?] [-x] DEVICE

الوصف

تقوم هذه الأداة بإرسال أمر SCSI LOG SENSE إلى DEVICE ثم تعرض الاستجابة. يستخدم أمر LOG SENSE لجلب صفحات السجل والتي، إذا كانت معروفة، يتم فك تشفيرها افتراضيًا. عند إعطاء خيار --reset و/أو --select يتم إصدار أمر SCSI LOG SELECT إلى DEVICE. بدلاً من ذلك، يمكن أن تكون استجابة صفحة سجل واحدة أو أكثر في ملف مقروء باستخدام الخيار --inhex=FN؛ في هذه الحالة، يتم فك تشفير تلك الاستجابات ويتم تجاهل وسيط DEVICE، إذا تم تقديمه.

في الإصدار 5 من SPC-4، تم تقديم رمز الصفحة الفرعية لكل من أمر LOG SENSE و LOG SELECT. في نفس الوقت، تم تقديم حقل رمز الصفحة إلى أمر LOG SELECT. يمكن أن يتراوح رمز الصفحة الفرعية للسجل من 0 إلى 255 (0xff) شاملة. يمكن اعتبار قيمة الرمز الفرعي 255 كرمز شامل.

ينقسم قسم SYNOPSIS أعلاه إلى خمسة أشكال. يوضح الشكل الأول الخيارات التي يمكن استخدامها لإرسال أمر LOG SENSE إلى DEVICE وفك تشفير استجابته. يجلب الشكل الثاني بيانات من ملف (يسمى FN) ويقوم بفك تشفيرها كما لو كانت استجابة من أمر LOG SENSE. يوضح الشكل الثالث الخيارات التي يمكن استخدامها لإصدار أمر LOG SELECT. يوضح الشكل الرابع مجموعات خيارات إدارة متنوعة. يعرض الشكل الأخير واجهة سطر الأوامر القديمة، التي تم إهمالها، والتي يتم صيانتها للتوافق الرجعي.

عند عدم تقديم أي خيارات، فقط DEVICE، فإن هذا يعادل استدعاء هذه الأداة بالخيار --list. في هذه الحالة، يتم عرض أسماء صفحات السجل المدعومة (ولكن ليس الصفحات الفرعية).

خيارات

الوسائط للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا. الخيارات مرتبة أبجديًا بناءً على اسم الخيار الطويل.

-A, --ALL
يجلب ويفك تشفير جميع صفحات السجل والصفحات الفرعية التي يدعمها DEVICE. يتطلب هذا عملية من مرحلتين: أولاً، يتم جلب صفحة السجل "صفحات السجل والصفحات الفرعية المدعومة"، ثم لكل إدخال في استجابتها، يتم جلب صفحة السجل (أو الصفحة الفرعية) المقابلة وعرضها. لاحظ أن هناك العديد من أجهزة SCSI التي لا تدعم الصفحات الفرعية لـ LOG SENSE وتستجيب لهذا الخيار بمفتاح طلب غير قانوني. في هذه الحالة، تستمر هذه الأداة عن طريق جلب صفحة السجل "صفحات السجل المدعومة" بدلاً من ذلك. بمعنى آخر، إذا فشل الخيار --ALL، يتم استخدام --all بدلاً من ذلك. السبب هو أنه من المؤكد تقريبًا أن DEVICE لا تحتوي على أي صفحات سجل فرعية للإبلاغ عنها.
لفرض خطأ إذا فشل جلب صفحة السجل "صفحات السجل والصفحات الفرعية المدعومة" استخدم كلا الخيارين --ALL و --full.
نظرًا لأن بعض البائعين لا يدرجون جميع صفحات السجل في صفحة "صفحات السجل والصفحات الفرعية المدعومة"، يمكن إعطاء الخيار '-lll' بالإضافة إلى ذلك. سيؤدي هذا إلى دمج كلتا الصفحتين "المدعومة..."، ثم من هذه القائمة المدمجة الناتجة، جلب محتويات الصفحة.
يتجاوز هذا الخيار --page=PG إذا تم تقديم الأخير أيضًا.
-a, --all
يعرض جميع صفحات السجل التي يدعمها DEVICE. يتطلب هذا عملية من مرحلتين: أولاً، يتم جلب صفحة السجل "صفحات السجل المدعومة"، ثم لكل إدخال في استجابتها، يتم جلب صفحة السجل المقابلة وعرضها. عند استخدامه مرتين (على سبيل المثال، '-aa') يتم جلب جميع صفحات السجل والصفحات الفرعية.
يتجاوز هذا الخيار --page=PG إذا تم تقديم الأخير أيضًا.
-b, --brief
تقصير كمية الإخراج لبعض صفحات السجل. على سبيل المثال، صفحة سجل Tape Alert تعرض فقط المعلمات التي تم تعيين علاماتها عند تقديم --brief.
-c, --control=PC
يقبل 0، 1، 2، أو 3 للوسيط PC:
0 : قيم العتبة الحالية
1 : القيم التراكمية الحالية
2 : قيم العتبة الافتراضية
3 : القيم التراكمية الافتراضية
القيمة الافتراضية هي 1 (أي القيم التراكمية الحالية).
-e, --enumerate
يستخدم هذا الخيار لعرض المعلومات الموجودة في الجداول الداخلية لهذه الأداة حول صفحات السجل المعروفة بما في ذلك اسمها والاختصار والحقول. إذا تم تقديمه، يتم تجاهل وسيط DEVICE. عند تقديمه مرة واحدة (على سبيل المثال، '-e') يتم سرد جميع الصفحات المعروفة، مرتبة أبجديًا تصاعديًا حسب الاختصار.
عند تقديمه مرتين، يتم استبعاد صفحات البائع. عند تقديمه ثلاث مرات، يتم سرد جميع الصفحات المعروفة، مرتبة رقميًا تصاعديًا؛ عند تقديمه أربع مرات، يتم استبعاد صفحات البائع من الترتيب الرقمي.
الخياران --filter=FL و --verbose يقللان من إخراج التعداد.
-E, --exclude
يستبعد هذا الخيار الصفحات والمعلمات الخاصة بالبائع من الإخراج. محاولة فك تشفير الصفحات والمعلمات الخاصة بالبائع لا تعمل بشكل جيد بالضرورة لأسباب عديدة. يقصر هذا الخيار الإخراج على الصفحات والمعلمات التي حددها T10.
يتم استبعاد حقول المعلمات التي تم تحديدها في المسودات على أنها 'خاصة بالبائع' فقط. لذا يتم عرض رموز المعلمات التي تم تحديدها على أنها 'محجوزة'.
-f, --filter=FL
FL هو إما رمز معلمة عند تقديم DEVICE، أو نوع جهاز طرفي (pdt) (أو غير ذلك) إذا تم تقديم --enumerate.
في حالة رمز المعلمة، FL هي قيمة بين 0 و 65535 (0xffff) ويتم عرض قسم المعلمة المطابق لهذا الرمز فقط. إذا تم تقديم الخيار --hex، يتم عرض معلمة السجل بالنظام السداسي عشر بدلاً من فك تشفيرها. إذا تم استخدام الخيار --hex مرتين، تتم إزالة العنوان البادئ على كل سطر سداسي عشري. إذا تم تقديم الخيار --raw، يتم عرض معلمة السجل بتنسيق ثنائي. تحتوي معظم صفحات السجل على معلمة سجل واحدة أو أكثر. الأمثلة على تلك التي لا تتبع هذا الاصطلاح هي الصفحات التي تسرد صفحات السجل (والصفحات الفرعية) المدعومة.
في حالة --enumerate، عندما يكون FL >= صفر، يتم اعتباره قيمة pdt ويتم تعداد صفحات السجل المرتبطة بهذا pdt بالإضافة إلى الصفحات العامة المدرجة في SPC. إذا كان FL هو -1، فإن التصفية لا تفعل شيئًا، وهو ما يعادل عدم تقديم هذا الخيار؛ عندما يكون FL هو -2، يتم تعداد الصفحات العامة فقط المدرجة في SPC. إذا كان FL هو -10، يتم تعداد الصفحات العامة ذات الوصول المباشر فقط (مثل القرص). إذا كان FL هو -11، يتم تعداد الصفحات العامة الشريطية فقط (مثل يشمل ADC).
-F, --full
يستخدم هذا الخيار فقط في حالتين: مع صفحة سجل عميل التطبيق (AC) ومع الخيار --ALL. عادةً ما تحتوي صفحة سجل AC على أكثر من 16000 بايت من البيانات التي قدمها المستخدم. بدلاً من طباعة كل شيء، يتمثل الافتراضي في طباعة أول 64 بايت من البيانات. عند تقديم هذا

NAME

sg_logs — fetches and displays log pages from a SCSI device

SYNOPSIS

sg_logs [OPTIONS] [DEVICE]

DESCRIPTION

This utility fetches and displays log pages from a SCSI device. Log pages are used to convey information about the device's state, configuration and performance. They are accessed via the SCSI LOG SENSE command. This command has a CDB (Command Data Block) of 6 bytes and up to 16 bytes. The structure is defined in SCSI standards and varies somewhat between standards and device types.

This utility is primarily designed to query specific log pages rather than the whole log structure.

The default action is to read and display the log page defined by the -p option (or --page). If no page is specified, the command attempts to read the standard information log page (page code 0x00).

A number of options exist to control which log pages are read, how they are interpreted, and what actions are performed.

OPTIONS

-a, --all
list all available log pages. This is done by sending LOG SENSE commands with increasing page numbers until an exception is returned. Available acronyms can be listed with the --enumerate option.
-A, --application_client
outputs the application client log page. Equivalent to --page=0x10.
-b
outputs the buffer integrity log page. Equivalent to --page=0x11.
-c
outputs the cache log page. Equivalent to --page=0x01.
-c=CS
Sets the Current/Saved (CS) bit in the LOG SELECT CDB. Default is 0 (saved). This option only has an effect when the LOG SELECT command is used. When CS is 1, the current values are selected, otherwise (0) the saved values are selected.
-d
outputs the disk persistent data log page. Equivalent to --page=0x02.
-D
outputs the disk (non-persistent) log page. Equivalent to --page=0x03.
-e, --enumerate
lists the available log page acronyms and their corresponding page codes. These acronyms can be used with the -p option.
-f
outputs the fault detect log page. Equivalent to --page=0x04.
-F
outputs the fault history log page. Equivalent to --page=0x05.
-g
outputs the general fault log page. Equivalent to --page=0x12.
-h
outputs the history log page. Equivalent to --page=0x06.
-i
outputs the information log page. Equivalent to --page=0x00.
-I
outputs the error counter log page. Equivalent to --page=0x07.
-j
outputs the SMART error log page. Equivalent to --page=0x13.
-l
outputs the long LBA list log page. Equivalent to --page=0x08.
-m
outputs the medium statistics log page. Equivalent to --page=0x09.
-n
outputs the non-medium error log page. Equivalent to --page=0x0a.
-N, --new
Switch to the newer style options.
-p=PG
log page code to access. PG is either an acronym, a page number, or a page, subpage pair. Available acronyms can be listed with the --enumerate option. Page (0 to 3f) and subpage (0 to ff) numbers are comma separated. The numbers are assumed to be hexadecimal.
-paramp=PP
PP is the parameter pointer value (in hex) to place in command. Should be a number between 0 and ffff inclusive.
-pcb
show Parameter Control Byte settings (only relevant when log parameters being output in ASCII).
-ppc
sets the Parameter Pointer Control (PPC) bit. Default is 0 (i.e. cleared).
-r
use SCSI LOG SELECT command (PCR bit set) to reset the all log pages (or the given page). Equivalent to --reset in the main description.
-R
Equivalent to --readonly in the main description.
-select
use a LOG SELECT command. Equivalent to --select in the main description.
-sp
sets the Saving Parameters (SP) bit. Default is 0 (i.e. cleared). Equivalent to --sp in the main description.
-t
outputs the temperature. Equivalent to --temperature in the main description.
-T
outputs the transport ('Protocol specific port') log page. Equivalent to --transport in the main description.
-v
increase level of verbosity.
-V
print out version string then exit.
-x
suppress the INQUIRY command. Equivalent to --no_inq in the main description.
-?
output usage message then exit.

LOG SELECT

The following options select the LOG SELECT command to be used instead of the default LOG SENSE command:

-C
outputs the configuration log page. Equivalent to --page=0x0b.
-c
sets the Current/Saved (CS) bit. Default is 0 (saved).
-p=PG
log page code to access. PG is either an acronym, a page number, or a page, subpage pair. Available acronyms can be listed with the --enumerate option. Page (0 to 3f) and subpage (0 to ff) numbers are comma separated. The numbers are assumed to be hexadecimal.
-P
sets the Parameter Pointer Control (PPC) bit. Default is 0 (cleared).
-S
sets the Saving Parameters (SP) bit. Default is 0 (cleared).

APPLICATION CLIENT

The following options select application client specific log pages:

-A
outputs the application client log page (page 0x10).
-P=PN
PN is the parameter name value (in hex) to place in command. Should be a number between 0 and ffff inclusive.
-p=PG
log page code to access. PG is either an acronym, a page number, or a page, subpage pair. Available acronyms can be listed with the --enumerate option. Page (0 to 3f) and subpage (0 to ff) numbers are comma separated. The numbers are assumed to be hexadecimal.
-S
sets the Saving Parameters (SP) bit. Default is 0 (cleared).

INHEX INSTEAD OF DEVICE

Instead of a device name, a hex number can be given. This is interpreted as an INHEX number (SCSI command set). The command will then only accept hex options.

NOTES

The Log Sense and Log Select commands are defined in the SCSI commands specifications. The interpretation of the returned data depends on the specific log page and the device type.

The output format is designed to be human readable. For machine readable output, use the --hex option.

Some log pages may require the LOG SELECT command to be issued first, e.g. to set the parameter pointer. Refer to the device's manual for details.

Not all devices support all log pages. Attempting to access a non-existent log page may result in an error.

EXIT STATUS

The exit status is 0 when the command completes successfully. It is non-zero when an error occurs.

ENVIRONMENT VARIABLES

Since sg3_utils version 1.23 the environment variable SG3_UTILS_OLD_OPTS can be given. When it is present this utility will expect the older command line options. So the presence of this environment variable is equivalent to using --old (or -O) as the first command line option.
