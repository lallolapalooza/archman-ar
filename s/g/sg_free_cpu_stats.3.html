الوصف

هذه هي فئات البيانات التي يقدمها وحدة إحصائيات وحدة المعالجة المركزية: sg_get_cpu_stats() و sg_get_cpu_stats_r() تقدم عدادات وحدة معالجة مركزية أصلية منذ بدء تشغيل الجهاز، sg_get_cpu_stats_diff() و sg_get_cpu_stats_diff_between() تقدم عدادات وحدة معالجة مركزية أصلية بين استدعاءين لـ sg_get_cpu_stats() و sg_get_cpu_percents_of() و sg_get_cpu_percents_r() تقدم عدادات وحدة معالجة مركزية نسبية متزامنة (حيث المجموع هو 100٪).

اختصار واجهة برمجة التطبيقات (API)

الدالة الناتج مالك البيانات
sg_get_cpu_stats sg_cpu_stats * libstatgrab (محلي للخيط)
sg_get_cpu_stats_r sg_cpu_stats * المستدعي
sg_get_cpu_stats_diff sg_cpu_stats * libstatgrab (محلي للخيط)
sg_get_cpu_stats_diff_between sg_cpu_stats * المستدعي
sg_get_cpu_percents_of sg_cpu_percents * libstatgrab (محلي للخيط)
sg_get_cpu_percents_r sg_cpu_percents * المستدعي

يجب تحرير مخزن sg_cpu_stats المستلم من sg_get_cpu_stats_r() و sg_get_cpu_stats_diff_between() وكذلك مخزن sg_cpu_percents المستلم من sg_get_cpu_percents_r() باستخدام sg_free_cpu_stats() أو sg_free_cpu_percents()، على التوالي، عندما لا تكون هناك حاجة إليها بعد الآن. المستدعي مسؤول عن القيام بذلك.

القيمة المخزنة (الـ "نقرات") ستختلف بين أنظمة التشغيل. على سبيل المثال، تمتلك Solaris ما مجموعه 100 في الثانية، بينما تمتلك Linux أكثر بكثير. أيضًا، تخزن أنظمة التشغيل المختلفة معلومات مختلفة - لن تجد وحدة معالجة مركزية لطيفة على Solaris على سبيل المثال.

يجب أن توفر الأنظمة الحديثة معلومات حول دقة ساعة النقرة عن طريق استدعاء sysconf(_SC_CLK_TCK).

قيم الإرجاع

هناك بنيتان يتم إرجاعهما بواسطة دوال إحصائيات وحدة المعالجة المركزية.

typedef struct {
        unsigned long long user;
        unsigned long long kernel;
        unsigned long long idle;
        unsigned long long iowait;
        unsigned long long swap;
        unsigned long long nice;
        unsigned long long total;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long syscalls;
        unsigned long long interrupts;
        unsigned long long soft_interrupts;
        time_t systime;
} sg_cpu_stats;

typedef struct {
        double user;
        double kernel;
        double idle;
        double iowait;
        double swap;
        double nice;
        time_t time_taken;
} sg_cpu_percents;
user kernel idle iowait swap nice total
حالات وحدة المعالجة المركزية المختلفة.
context_switches voluntary_context_switches involuntary_context_switches syscalls interrupts soft_interrupts
إجراءات البرنامج المختلفة على وحدة المعالجة المركزية.
systime time_taken
الوقت المستغرق بالثواني منذ آخر استدعاء للدالة، أو وقت النظام.
