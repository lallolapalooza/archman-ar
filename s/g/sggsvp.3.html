الغرض:

!>
!> هذا الإجراء الفرعي مهمل واستبدل بالإجراء الفرعي SGGSVP3.
!>
!> SGGSVP يحسب المصفوفات المتعامدة U، V و Q بحيث
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  إذا كان M-K-L >= 0؛
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  إذا كان M-K-L < 0؛
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> حيث A12 المصفوفة K-by-K و B13 المصفوفة L-by-L غير المفردة
!> هي مصفوفات عليا مثلثية؛ A23 مصفوفة مثلثية عليا L-by-L إذا كان M-K-L >= 0،
!> وإلا فإن A23 هي مصفوفة شبه منحرفة عليا (M-K)-by-L. K+L = الرتبة العددية الفعلية
!> للمصفوفة (A**T,B**T)**T التي حجمها (M+P)-by-N.
!>
!> هذا التحلل هو خطوة المعالجة المسبقة لحساب التحليل المتعامد القياسي المعمم (GSVD)، انظر الإجراء الفرعي
!> SGGSVD.
!>

sggsvp(3)

NAME

sggsvp - sggsvp routine

SYNOPSIS

SUBROUTINE sggsvp( JOBU, JOBV, M, N, A, LDA, B, LDB, TAU, T0, LDT0, U, LDU, V, LDV, WORK, LWORK, INFO )
    CHARACTER * 1 JOBU, JOBV
    INTEGER M, N, LDA, LDB, LDT0, LDU, LDV, LWORK, INFO
    REAL A( LDA, * ), B( LDB, * ), TAU( * ), T0( LDT0, * ), U( LDU, * ), V( LDV, * ), WORK( * )

Function/Subroutine Documentation

sggsvp is a subroutine in LAPACK, a library of Fortran routines for numerical linear algebra.

This subroutine computes the generalized Schur decomposition of a real matrix pair (A, B).

It is defined as:

A = U*T0*VT

B = U*T1*VT

where T0 is a real upper quasi-triangular matrix with 1-by-1 and 2-by-2 diagonal blocks, and T1 is a real upper triangular matrix. U and V are orthogonal matrices.

Arguments:

  • JOBU: (Input) Specifies whether to compute the matrix U.
  • JOBV: (Input) Specifies whether to compute the matrix V.
  • M: (Input) The number of rows of A and B.
  • N: (Input) The number of columns of A and B.
  • A: (Input/Output) On entry, the M-by-N matrix A. On exit, overwritten by the transformed matrix.
  • LDA: (Input) The leading dimension of A.
  • B: (Input/Output) On entry, the M-by-N matrix B. On exit, overwritten by the transformed matrix.
  • LDB: (Input) The leading dimension of B.
  • TAU: (Output) The coefficients of the orthogonal transformations.
  • T0: (Output) On exit, the M-by-N upper quasi-triangular matrix T0.
  • LDT0: (Input) The leading dimension of T0.
  • U: (Output) On exit, the M-by-M orthogonal matrix U.
  • LDU: (Input) The leading dimension of U.
  • V: (Output) On exit, the N-by-N orthogonal matrix V.
  • LDV: (Input) The leading dimension of V.
  • WORK: (Workspace) The work array.
  • LWORK: (Input) The dimension of the work array.
  • INFO: (Output) On exit, an integer value indicating success or error.

توثيق الدالة/الروتين الفرعي

sggsvp هو روتين فرعي في LAPACK، وهي مكتبة من روتينات Fortran للجبر الخطي العددي.

يقوم هذا الروتين الفرعي بحساب تحليل Schur المعمم لزوج من المصفوفات الحقيقية (A، B).

يتم تعريفه على النحو التالي:

A = U*T0*VT

B = U*T1*VT

حيث T0 مصفوفة شبه ثلاثية عليا حقيقية مع كتل قطرية 1x1 و 2x2، و T1 مصفوفة ثلاثية عليا حقيقية. U و V مصفوفات متعامدة.

المعاملات:

  • JOBU: (مدخل) يحدد ما إذا كان سيتم حساب المصفوفة U.
  • JOBV: (مدخل) يحدد ما إذا كان سيتم حساب المصفوفة V.
  • M: (مدخل) عدد صفوف A و B.
  • N: (مدخل) عدد أعمدة A و B.
  • A: (مدخل/مخرج) عند الإدخال، المصفوفة A ذات الأبعاد M×N. عند الخروج، يتم استبدالها بالمصفوفة المحولة.
  • LDA: (مدخل) البعد الرائد للمصفوفة A.
  • B: (مدخل/مخرج) عند الإدخال، المصفوفة B ذات الأبعاد M×N. عند الخروج، يتم استبدالها بالمصفوفة المحولة.
  • LDB: (مدخل) البعد الرائد للمصفوفة B.
  • TAU: (مخرج) معاملات التحويلات المتعامدة.
  • T0: (مخرج) عند الخروج، المصفوفة شبه الثلاثية العليا T0 ذات الأبعاد M×N.
  • LDT0: (مدخل) البعد الرائد للمصفوفة T0.
  • U: (مخرج) عند الخروج، المصفوفة المتعامدة U ذات الأبعاد M×M.
  • LDU: (مدخل) البعد الرائد للمصفوفة U.
  • V: (مخرج) عند الخروج، المصفوفة المتعامدة V ذات الأبعاد N×N.
  • LDV: (مدخل) البعد الرائد للمصفوفة V.
  • WORK: (مساحة عمل) مصفوفة العمل.
  • LWORK: (مدخل) بعد مصفوفة العمل.
  • INFO: (مخرج) عند الخروج، قيمة صحيحة تشير إلى النجاح أو الخطأ.
