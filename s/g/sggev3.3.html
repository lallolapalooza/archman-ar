SGGEV3 يحسب القيم الذاتية، اختياريًا، المتجهات الذاتية اليسرى و/أو اليمنى لمصفوفات GE (خوارزمية مجمعة)

الغرض:

!>
!> SGGEV3 يحسب لمصفوفات حقيقية غير متماثلة (A,B) ذات الرتبة N
!> القيم الذاتية المعممة، واختياريًا، المتجهات الذاتية المعممة اليسرى و/أو اليمنى.
!>
!> قيمة ذاتية معممة لزوج من المصفوفات (A,B) هي قيمة عددية
!> lambda أو نسبة alpha/beta = lambda، بحيث A - lambda*B
!> مفردة. وعادة ما تمثل بالزوج (alpha,beta)، حيث
!> يوجد تفسير معقول لـ beta=0، وحتى عندما يكون كلاهما
!> صفرًا.
!>
!> المتجه الذاتي الأيمن v(j) المقابل للقيمة الذاتية lambda(j)
!> للمصفوفة (A,B) يحقق:
!>
!>                  A * v(j) = lambda(j) * B * v(j).
!>
!> المتجه الذاتي الأيسر u(j) المقابل للقيمة الذاتية lambda(j)
!> للمصفوفة (A,B) يحقق:
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B .
!>
!> حيث u(j)**H هو المرافق المتراجع لـ u(j).
!>
!>

NAME

sggev3 - Solves the general complex pair eigenvalue problem (A*x = lambda*B*x).

SYNOPSIS

SUBROUTINE SGGEV3( JOBVL, JOBVR, N, A, LDA, B, LDB, ALPHAR, ALPHAI, BETA, VL, LDVL, VR, LDVR, WORK, LWORK, INFO )

Function/Subroutine Documentation

This subroutine is part of the LAPACK library, which provides routines for linear algebra computations.

SGGEV3 computes for a general complex pair of matrices (A, B), the generalized eigenvalues (lambda) and, optionally, the left and right eigenvectors.

The generalized eigenvalue problem is typically stated as:

A * x = lambda * B * x

where A and B are matrices, x is a vector of unknowns, and lambda is a scalar (the generalized eigenvalue).

Arguments:

  • JOBVL: CHARACTER*1. If JOBVL = 'N', then the left eigenvectors are not computed. If JOBVL = 'V', then the left eigenvectors are computed.
  • JOBVR: CHARACTER*1. If JOBVR = 'N', then the right eigenvectors are not computed. If JOBVR = 'V', then the right eigenvectors are computed.
  • N: INTEGER. The order of the matrices A and B. N >= 0.
  • A: DOUBLE PRECISION array, dimension (LDA, N). On entry, the matrix A. On exit, A has been overwritten.
  • LDA: INTEGER. The leading dimension of A. LDA >= max(1, N).
  • B: DOUBLE PRECISION array, dimension (LDB, N). On entry, the matrix B. On exit, B has been overwritten.
  • LDB: INTEGER. The leading dimension of B. LDB >= max(1, N).
  • ALPHAR: DOUBLE PRECISION array, dimension (N). On exit, ALPHAR contains the real parts of the complex eigenvalues alpha.
  • ALPHAI: DOUBLE PRECISION array, dimension (N). On exit, ALPHAI contains the imaginary parts of the complex eigenvalues alpha.
  • BETA: DOUBLE PRECISION array, dimension (N). On exit, BETA contains the real generalized eigenvalues beta.
  • VL: DOUBLE PRECISION array, dimension (LDVL, N). If JOBVL = 'V', VL contains the left eigenvectors. Each column VL(i1:i1+n-1, j) is the left eigenvector for the j-th generalized eigenvalue.
  • LDVL: INTEGER. The leading dimension of the array VL. LDVL >= N.
  • VR: DOUBLE PRECISION array, dimension (LDVR, N). If JOBVR = 'V', VR contains the right eigenvectors. Each column VR(i1:i1+n-1, j) is the right eigenvector for the j-th generalized eigenvalue.
  • LDVR: INTEGER. The leading dimension of the array VR. LDVR >= N.
  • WORK: DOUBLE PRECISION array, dimension (LWORK).
  • LWORK: INTEGER. The dimension of the array WORK. LWORK >= 1. For optimal performance, LWORK is N*N + 2*N.
  • INFO: INTEGER.
    • INFO = 0: successful exit.
    • INFO < 0: if INFO = -i, the i-th argument had an illegal value.
    • INFO > 0: if INFO = i, then the QZ iteration did not converge. i eigenvectors could not be computed.
