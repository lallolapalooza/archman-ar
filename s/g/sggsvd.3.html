NAME

sggsvd - the generalized singular value decomposition of an M-by-N matrix A, and an N-by-P matrix B

Function/Subroutine Documentation

Purpose:

The subroutine SGGVD computes the generalized singular value decomposition (GSVD) of an M-by-N matrix A, and an N-by-P matrix B, ,

A = U*S1*(RT)T

B = V*S2*(RT)T

where U, V are orthogonal matrices, and R is a quasi-upper triangular matrix with diagonal blocks of order at most 2.

The diagonal entries of S1 and S2 are related by the singular values.

Specifically, let

S1 = diag(α1, ..., αK, 1, ..., 1, 0, ..., 0)

S2 = diag(β1, ..., βK, 0, ..., 0, 1, ..., 1)

where αi > 0 and βi > 0 for i=1,...,K.

Then

diag(α1, ..., αK) = diag(cos(θ1), ..., cos(θK))

diag(β1, ..., βK) = diag(sin(θ1), ..., sin(θK))

where 0 <= θi <= PI/2.

The singular values are not computed directly. Instead, cos(θi) and sin(θi) are computed.

The triangular matrices T1 and T2 are computed from the decomposition:

A = Q*T1*ZT

B = P*T2*ZT

where Q, P, and Z are orthogonal matrices.

The GSVD is computed in two stages:

1. Compute the GSVD of A and B.

2. Transform the matrices to the form described above.

Parameters:

  CHARACTER JOB
  Input
  On entry: JOB specifies which of the following is to be computed:
  = 'N':  Compute the generalized singular value decomposition.
  = 'S':  Compute the generalized singular value decomposition and
          reduce it to triangular form.

  REAL A( LDA, * )
  Input/Output
  On entry, the M-by-N matrix A.
  On exit, if JOB = 'N', A is overwritten by the details of its
  decomposition.
  if JOB = 'S', A is overwritten by the elements of the upper
  triangular matrix T1 from the decomposition
  A = Q*T1*Z**T.

  INTEGER LDA
  Input
  The leading dimension of the array A. LDA >= max(1, M).

  REAL B( LDB, * )
  Input/Output
  On entry, the N-by-P matrix B.
  On exit, if JOB = 'N', B is overwritten by the details of its
  decomposition.
  if JOB = 'S', B is overwritten by the elements of the upper
  triangular matrix T2 from the decomposition
  B = P*T2*Z**T.

  INTEGER LDB
  Input
  The leading dimension of the array B. LDB >= max(1, N).

  REAL ALPHA( * )
  Output
  On exit, ALPHA contains the diagonal entries of S1.

  REAL VT( LDT, * )
  Output
  On exit, VT contains the orthogonal matrix Z.

  INTEGER M
  Input
  The number of rows of A. 0 <= M.

  INTEGER N
  Input
  The number of columns of A and the number of rows of B. 0 <= N.

  INTEGER P
  Input
  The number of columns of B. 0 <= P.

  INTEGER K
  Output
  The number of singular values greater than TOLA.

  INTEGER L
  Output
  The number of singular values greater than TOLB.

  REAL WORK( * )
  Workspace
  On exit, WORK(1) contains the optimal value of LWORK.

  INTEGER LWORK
  Input
  The dimension of the array WORK. LWORK >= max(1, M, N, P).
  For optimal performance, LWORK should be greater than or equal to
  MAX(M,N,P) + MAX(M,N,P)*MAX(M,N,P) + MAX(M,N,P).

  INTEGER IWORK( * )
  Workspace
  On exit, IWORK stores the sorting information. More
  precisely, the following loop will sort ALPHA
             for I = K+1, min(M,K+L)
                 swap ALPHA(I) and ALPHA(IWORK(I))
             endfor
  such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

  INTEGER INFO
  Output
  = 0:  successful exit
  < 0:  if INFO = -i, the i-th argument had an illegal value.
  > 0:  if INFO = 1, the Jacobi-type procedure failed to
        converge.  For further details, see subroutine STGSJA.

Internal Parameters:

  TOLA    REAL
  TOLB    REAL
          TOLA and TOLB are the thresholds to determine the effective
          rank of (A**T,B**T)**T. Generally, they are set to
                   TOLA = MAX(M,N)*norm(A)*MACHEPS,
                   TOLB = MAX(P,N)*norm(B)*MACHEPS.
          The size of TOLA and TOLB may affect the size of backward
          errors of the decomposition.
