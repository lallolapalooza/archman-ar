الوصف

هذه هي فئات البيانات التي يوفرها وحدة إحصائيات وحدة المعالجة المركزية: sg_get_cpu_stats() و sg_get_cpu_stats_r() تسلم عدادات وحدة المعالجة المركزية الأصلية منذ بدء تشغيل الجهاز، sg_get_cpu_stats_diff() و sg_get_cpu_stats_diff_between() تسلم عدادات وحدة المعالجة المركزية الأصلية بين استدعاءين لـ sg_get_cpu_stats() و sg_get_cpu_percents_of() و sg_get_cpu_percents_r() تسلم عدادات وحدة المعالجة المركزية النسبية المترابطة (حيث يكون الإجمالي 100٪).

اختصار واجهة برمجة التطبيقات

الدالة تُرجع مالك البيانات
sg_get_cpu_stats sg_cpu_stats * libstatgrab (محلي للخيط)
sg_get_cpu_stats_r sg_cpu_stats * المتصل
sg_get_cpu_stats_diff sg_cpu_stats * libstatgrab (محلي للخيط)
sg_get_cpu_stats_diff_between sg_cpu_stats * المتصل
sg_get_cpu_percents_of sg_cpu_percents * libstatgrab (محلي للخيط)
sg_get_cpu_percents_r sg_cpu_percents * المتصل

يجب تحرير مخزن sg_cpu_stats المؤقت الذي تم استلامه من sg_get_cpu_stats_r() و sg_get_cpu_stats_diff_between()، وكذلك مخزن sg_cpu_percents المؤقت الذي تم استلامه من sg_get_cpu_percents_r()، باستخدام sg_free_cpu_stats() أو sg_free_cpu_percents()، على التوالي، عندما لا تكون هناك حاجة إليه بعد الآن. المتصل مسؤول عن القيام بذلك.

ستختلف القيمة المخزنة ("النقرات") بين أنظمة التشغيل. على سبيل المثال، لدى Solaris إجمالي 100 في الثانية، بينما لدى Linux أكثر بكثير. أيضًا، تخزن أنظمة التشغيل المختلفة معلومات مختلفة - لن تجد وحدة معالجة مركزية لطيفة في Solaris على سبيل المثال.

يجب أن توفر الأنظمة الحديثة معلومات حول دقة ساعة النقرات عن طريق استدعاء sysconf(_SC_CLK_TCK).

قيم الإرجاع

هناك بنيتان يتم إرجاعهما بواسطة دوال إحصائيات وحدة المعالجة المركزية.

typedef struct {
        unsigned long long user;
        unsigned long long kernel;
        unsigned long long idle;
        unsigned long long iowait;
        unsigned long long swap;
        unsigned long long nice;
        unsigned long long total;
        unsigned long long context_switches;
        unsigned long long voluntary_context_switches;
        unsigned long long involuntary_context_switches;
        unsigned long long syscalls;
        unsigned long long interrupts;
        unsigned long long soft_interrupts;
        time_t systime;
} sg_cpu_stats;

typedef struct {
        double user;
        double kernel;
        double idle;
        double iowait;
        double swap;
        double nice;
        time_t time_taken;
} sg_cpu_percents;
user kernel idle iowait swap nice total
حالات وحدة المعالجة المركزية المختلفة.
context_switches voluntary_context_switches involuntary_context_switches syscalls interrupts soft_interrupts
إجراءات البرنامج المختلفة على وحدة المعالجة المركزية.
systime time_taken
الوقت المستغرق بالثواني منذ آخر استدعاء للدالة، أو وقت النظام.
