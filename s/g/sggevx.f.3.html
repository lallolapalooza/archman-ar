SGGEVX تحسب القيم الذاتية، اختياريًا، للمتجهات الذاتية اليسرى و/أو اليمنى لمصفوفات GE

الغرض:

!>
!> SGGEVX تحسب لأزواج من المصفوفات الحقيقية غير المتماثلة N-by-N (A,B)
!> القيم الذاتية المعممة، واختياريًا، المتجهات الذاتية المعممة اليسرى و/أو اليمنى.
!>
!> اختياريًا، تقوم أيضًا بحساب تحويل موازنة لتحسين
!> تكييف القيم الذاتية والمتجهات الذاتية (ILO, IHI,
!> LSCALE, RSCALE, ABNRM, و BBNRM)، ومعكوسات أرقام التكييف
!> للقيم الذاتية (RCONDE)، ومعكوسات أرقام التكييف
!> للمتجهات الذاتية اليمنى (RCONDV).
!>
!> القيمة الذاتية المعممة لزوج من المصفوفات (A,B) هي قيمة عددية
!> lambda أو نسبة alpha/beta = lambda، بحيث تكون A - lambda*B
!> شاذة. يتم تمثيلها عادةً بالزوج (alpha,beta)، حيث
!> يوجد تفسير معقول لـ beta=0، وحتى عندما يكون كلاهما صفرًا.
!>
!> المتجه الذاتي الأيمن v(j) المقابل للقيمة الذاتية lambda(j)
!> للمصفوفة (A,B) يحقق
!>
!>                  A * v(j) = lambda(j) * B * v(j) .
!>
!> المتجه الذاتي الأيسر u(j) المقابل للقيمة الذاتية lambda(j)
!> للمصفوفة (A,B) يحقق
!>
!>                  u(j)**H * A  = lambda(j) * u(j)**H * B.
!>
!> حيث u(j)**H هي المرافق النقال لـ u(j).
!>
!>

sggevx - sGGEVX

Function/Subroutine Documentation

!> \brief \
!> Calls the routines which balance the matrix pair (A,B) and then computes the Schur factorization of the balanced matrix pair.
!>
!> \details
!> ALGORITHM
!> The algorithm consists of two stages:
!> 1. Balancing the matrix pair (A,B).
!> 2. Computing the Schur factorization of the balanced matrix pair.
!>
!> The purpose of balancing a matrix pair is to simplify the input matrix
!> pair in place by permuting rows and columns to isolate eigenvalues, and
!> then to apply diagonal similarity transformations to the rows and columns
!> to make the rows and columns of the matrix pair as close in norm as
!> possible. Thus, balancing may reduce the norm of the matrix pair and
!> improve the accuracy of the computed eigenvectors.
!>
!> After balancing, the Schur factorization of the balanced matrix pair is
!> computed. The algorithm used is based on the QR algorithm for finding
!> the Schur factorization of a single matrix, adapted for matrix pairs.
!>
!> Finally, if requested, the eigenvectors are computed and, if specified,
!> the reciprocal condition numbers of the eigenvalues and eigenvectors are
!> estimated.
!>
!> \param JOBVL CHARACTER*1.
!> \param JOBVL specifies whether to compute the left eigenvectors of A.
!> \param JOBVR CHARACTER*1.
!> \param JOBVR specifies whether to compute the right eigenvectors of A.
!> \param SENSE CHARACTER*1.
!> \param SENSE specifies which reciprocal condition numbers are to be computed.
!> \param N INTEGER.
!> \param A REAL array, dimension (LDA, N).
!> \param LDA INTEGER.
!> \param B REAL array, dimension (LDB, N).
!> \param LDB INTEGER.
!> \param ALPHAR REAL array, dimension (N).
!> \param ALPHAI REAL array, dimension (N).
!> \param BETA REAL array, dimension (N).
!> \param VL REAL array, dimension (LDVL, N).
!> \param LDVL INTEGER.
!> \param VR REAL array, dimension (LDVR, N).
!> \param LDVR INTEGER.
!> \param RCONDE REAL array, dimension (N).
!> \param RCONDV REAL array, dimension (N).
!> \param WORK REAL array, dimension (MAX(1,LWORK)).
!> \param LWORK INTEGER.
!> \param IWORK INTEGER array, dimension (N+6).
!> \param INFO INTEGER.
!>
!> \return INFO INTEGER.
!> = 0: successful exit
!> < 0: if INFO = -i, the i-th argument had an illegal value.
!> = 1,...,N: The QZ iteration failed. No eigenvectors have been calculated, but ALPHAR(j), ALPHAI(j), and BETA(j) should be correct for j=INFO+1,...,N.
!> > N: =N+1: other than QZ iteration failed in SHGEQZ.
!>      =N+2: error return from STGEVC.
!>
!> \details
!> \param A (output) REAL array, dimension (LDA, N)
!>          On exit, A contains the upper quasi-triangular matrix V from
!>          the Schur factorization.
!> \param LDA (input) INTEGER
!>          The leading dimension of the array A. LDA >= max(1,N).
!> \param B (output) REAL array, dimension (LDB, N)
!>          On exit, B contains the upper triangular matrix U from
!>          the Schur factorization.
!> \param LDB (input) INTEGER
!>          The leading dimension of the array B. LDB >= max(1,N).
!> \param ALPHAR (output) REAL array, dimension (N)
!>          The real parts of the eigenvalues of the matrix pair (A,B).
!> \param ALPHAI (output) REAL array, dimension (N)
!>          The imaginary parts of the eigenvalues of the matrix pair (A,B).
!> \param BETA (output) REAL array, dimension (N)
!>          The imaginary parts of the eigenvalues of the matrix pair (A,B).
!>          The eigenvalues are (ALPHAR(i) + i*ALPHAI(i)) / BETA(i).
!> \param VL (output) REAL array, dimension (LDVL, N)
!>          If JOBVL = 'V', VL contains the left eigenvectors of the
!>          generalized eigenvalue problem A*x = lambda*B*x.
!>          The eigenvectors are normalized so that the sum of squares
!>          of each vector is 1.
!> \param LDVL (input) INTEGER
!>          The leading dimension of the array VL. LDVL >= N.
!> \param VR (output) REAL array, dimension (LDVR, N)
!>          If JOBVR = 'V', VR contains the right eigenvectors of the
!>          generalized eigenvalue problem A*x = lambda*B*x.
!>          The eigenvectors are normalized so that the sum of squares
!>          of each vector is 1.
!> \param LDVR (input) INTEGER
!>          The leading dimension of the array VR. LDVR >= N.
!>
!> \param ILO and IHI
!>          ILO and IHI are integer values such that on exit
!>          A(i,j) = 0 and B(i,j) = 0 if i > j and
!>          j = 1,...,ILO-1 or i = IHI+1,...,N.
!>          If BALANC = 'N' or 'S', ILO = 1 and IHI = N.
!>
!> \param LSCALE
!>          LSCALE is REAL array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the left side of A and B.  If PL(j) is the index of the
!>          row interchanged with row j, and DL(j) is the scaling
!>          factor applied to row j, then
!>            LSCALE(j) = PL(j)  for j = 1,...,ILO-1
!>                      = DL(j)  for j = ILO,...,IHI
!>                      = PL(j)  for j = IHI+1,...,N.
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>
!> \param RSCALE
!>          RSCALE is REAL array, dimension (N)
!>          Details of the permutations and scaling factors applied
!>          to the right side of A and B.  If PR(j) is the index of the
!>          column interchanged with column j, and DR(j) is the scaling
!>          factor applied to column j, then
!>            RSCALE(j) = PR(j)  for j = 1,...,ILO-1
!>                      = DR(j)  for j = ILO,...,IHI
!>                      = PR(j)  for j = IHI+1,...,N
!>          The order in which the interchanges are made is N to IHI+1,
!>          then 1 to ILO-1.
!>
!> \param ABNRM
!>          ABNRM is REAL
!>          The one-norm of the balanced matrix A.
!>
!> \param BBNRM
!>          BBNRM is REAL
!>          The one-norm of the balanced matrix B.
!>
!> \param RCONDE
!>          RCONDE is REAL array, dimension (N)
!>          If SENSE = 'E' or 'B', the reciprocal condition numbers of
!>          the eigenvalues, stored in consecutive elements of the array.
!>          For a complex conjugate pair of eigenvalues two consecutive
!>          elements of RCONDE are set to the same value. Thus RCONDE(j),
!>          RCONDV(j), and the j-th columns of VL and VR all correspond
!>          to the j-th eigenpair.
!>          If SENSE = 'N' or 'V', RCONDE is not referenced.
!>
!> \param RCONDV
!>          RCONDV is REAL array, dimension (N)
!>          If SENSE = 'V' or 'B', the estimated reciprocal condition
!>          numbers of the eigenvectors, stored in consecutive elements
!>          of the array. For a complex eigenvector two consecutive
!>          elements of RCONDV are set to the same value. If the
!>          eigenvalues cannot be reordered to compute RCONDV(j),
!>          RCONDV(j) is set to 0; this can only occur when the true
!>          value would be very small anyway.
!>          If SENSE = 'N' or 'E', RCONDV is not referenced.
!>
!> \param WORK
!>          WORK is REAL array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>
!> \param LWORK
!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,2*N).
!>          If BALANC = 'S' or 'B', or JOBVL = 'V', or JOBVR = 'V',
!>          LWORK >= max(1,6*N).
!>          If SENSE = 'E', LWORK >= max(1,10*N).
!>          If SENSE = 'V' or 'B', LWORK >= 2*N*N+8*N+16.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>
!> \param IWORK
!>          IWORK is INTEGER array, dimension (N+6)
!>          If SENSE = 'E', IWORK is not referenced.
!>
!> \param BWORK
!>          BWORK is LOGICAL array, dimension (N)
!>          If SENSE = 'N', BWORK is not referenced.
!>
!> \param INFO
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          = 1,...,N:
!>                The QZ iteration failed.  No eigenvectors have been
!>                calculated, but ALPHAR(j), ALPHAI(j), and BETA(j)
!>                should be correct for j=INFO+1,...,N.
!>          > N:  =N+1: other than QZ iteration failed in SHGEQZ.
!>                =N+2: error return from STGEVC.
!>

Further Details:

!>
!>  Balancing a matrix pair (A,B) includes, first, permuting rows and
!>  columns to isolate eigenvalues, second, applying diagonal similarity
!>  transformation to the rows and columns to make the rows and columns
!>  as close in norm as possible. The computed reciprocal condition
!>  numbers correspond to the balanced matrix. Permuting rows and columns
!>  will not change the condition numbers (in exact arithmetic) but
!>  diagonal scaling will.  For further explanation of balancing, see
!>  section 4.11.1.2 of LAPACK Users' Guide.
!>
!>  An approximate error bound on the chordal distance between the i-th
!>  computed generalized eigenvalue w and the corresponding exact
!>  eigenvalue lambda is
!>
!>       chord(w, lambda) <= EPS * norm(ABNRM, BBNRM) / RCONDE(I)
!>
!>  An approximate error bound for the angle between the i-th computed
!>  eigenvector VL(i) or VR(i) is given by
!>
!>       EPS * norm(ABNRM, BBNRM) / DIF(i).
!>
!>  For further explanation of the reciprocal condition numbers RCONDE
!>  and RCONDV, see section 4.11 of LAPACK User's Guide.
!>
