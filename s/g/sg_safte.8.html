sg_safte(8)

الحزمة: sg3_utils

التراخيص: GPL, custom:BSD

SG_SAFTE(8) SG3_UTILS SG_SAFTE(8)

الاسم

sg_safte - الوصول إلى جهاز الغلاف الداخلي لتحمل الأخطاء الذي يمكن الوصول إليه عبر SCSI (SAF-TE)

الملخص

sg_safte [--config] [--devstatus] [--encstatus] [--flags] [--help] [--hex] [--insertions] [--raw] [--usage] [--verbose] [--version] DEVICE

الوصف

جلب حالة الغلاف الداخلي (عبر أمر SCSI READ BUFFER). يجب أن يكون DEVICE جهاز SAF-TE والذي قد يكون متحكم مصفوفة تخزين (نوع جهاز الطرفي للاستعلام 0xc) أو جهاز معالج عام (نوع جهاز الطرفي للاستعلام 0x3).

إذا لم يتم تقديم أي خيارات (فقط الوسيط DEVICE) فسيتم الإبلاغ عن الحالة العامة للغلاف الداخلي كما تم الإبلاغ عنها بواسطة الخيار --config.

الخيارات

الوسائط للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا. يتم ترتيب الخيارات أبجديًا بناءً على اسم الخيار الطويل.

-c, --config
سيصدر أمر قراءة تكوين الغلاف الداخلي (READ BUFFER ID 0) إلى الجهاز، والذي يعيد قائمة بموارد أجهزة الغلاف الداخلي.
-d, --devstatus
سيصدر أمر قراءة حالة فتحات الجهاز (READ BUFFER ID 4) إلى الجهاز، والذي يعيد معلومات حول الحالة الحالية لكل محرك أو فتحة.
-s, --encstatus
سيصدر أمر قراءة حالة الغلاف الداخلي (READ BUFFER ID 1) إلى الجهاز، والذي يعيد الحالة التشغيلية للمكونات.
-f, --flags
سيصدر أمر قراءة الأعلام العامة (READ BUFFER ID 5) إلى الجهاز، والذي يقرأ أحدث حالة للأعلام العامة لجهاز معالج RAID.
-h, --help
إخراج رسالة الاستخدام ثم الخروج.
-H, --hex
إخراج الاستجابة لأمر READ BUFFER بتنسيق hex ASCII إلى المخرج القياسي. إذا تم استخدامه مرة واحدة، فسيتم إخراج الاستجابة لأمر READ BUFFER الأول (أي مع buffer_id=0). يجب أن يكون هذا هو تكوين الغلاف الداخلي. إذا تم استخدامه مرتين (أو أكثر)، فسيتم إخراج الاستجابة لأوامر READ BUFFER اللاحقة.
-i, --insertions
سيصدر أمر قراءة إدخالات الجهاز (READ BUFFER ID 3) إلى الجهاز، والذي يعيد معلومات حول عدد المرات التي تم فيها إدخال الأجهزة أثناء تشغيل نظام RAID.
-r, --raw
إخراج الاستجابة لأمر READ BUFFER بتنسيق ثنائي إلى المخرج القياسي. إذا تم استخدامه مرة واحدة، فسيتم إخراج الاستجابة لأمر READ BUFFER الأول (أي مع buffer_id=0). يجب أن يكون هذا هو تكوين الغلاف الداخلي. إذا تم استخدامه مرتين (أو أكثر)، فسيتم إخراج الاستجابة لأوامر READ BUFFER اللاحقة.
-u, --usage
سيصدر أمر قراءة إحصائيات الاستخدام (READ BUFFER ID 2) إلى الجهاز، والذي يعيد معلومات حول إجمالي وقت الاستخدام وعدد دورات التشغيل للجهاز.
-v, --verbose
زيادة مستوى الإسهاب، (أي إخراج التصحيح).
-V, --version
طباعة سلسلة الإصدار ثم الخروج.

ملاحظات

يعتمد هذا التنفيذ على وثيقة المراجعة المتوسطة المؤرخة 19970414 والمسمى "SR041497.pdf". لذا فهي قديمة جدًا. Intel و nStor هما المؤلفان. لدى Intel أرشيف مضغوط يحتوي على هذه الوثائق والوثائق ذات الصلة في قسم "SAF-TE: SCSI Accessed Fault Tolerant Enclosures Interface Specification" في هذه الصفحة:

https://www.intel.com/content/www/us/en/servers/ipmi/ipmi-technical-resources.html

يتم توفير وظائف مماثلة بواسطة أجهزة خدمات الغلاف الداخلي (SES) الخاصة بـ SPC-4 (نوع جهاز طرفي 0xd)، والتي يمكن الاستعلام عنها باستخدام الأداة المساعدة sg_ses.

أمثلة

لعرض التكوين:


sg_safte /dev/sg1

لعرض حالة فتحات الجهاز:


sg_safte --devstatus /dev/sg1

حالة الخروج

حالة خروج sg_safte هي 0 عند النجاح. بخلاف ذلك، راجع صفحة الدليل sg3_utils(8).
