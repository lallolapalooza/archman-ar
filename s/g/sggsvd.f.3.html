NAME

sggsvd - Singular value decomposition of a general matrix-matrix pair.

SYNOPSIS 

  SUBROUTINE SGGVD(
        JOBZ,  MATRIX_A,  MATRIX_B,  M,  N,  A,  LDA,  B,  LDB,
        ALPHA, BETA,  WORK,  LWORK,  IWORK,  INFO)

      CHARACTER          JOBZ
      INTEGER            M,  N,  LDA,  LDB,  LWORK,  INFO
      REAL               A( LDA, * ),  B( LDB, * ),  ALPHA( * ),
                         BETA( * ),  WORK( * )
      INTEGER            IWORK( * )

Function/Subroutine Documentation

Purpose:

SGGVD computes the singular value decomposition of a general matrix-matrix pair (A, B), where A is an M-by-N matrix and B is an M-by-P matrix, with A and B in general rectangular (not necessarily square) matrices. The decomposition is performed by the following steps: 

            A = U * diag(s, 0) * Q**T
            B = V * diag(t, 0) * Q**T

where U, V, and Q are orthogonal matrices, s and t are non-negative, decreasing vectors, and diag(s, 0) denotes the M-by-N matrix diag(s(1), ..., s(k), 0, ..., 0), and diag(t, 0) denotes the M-by-P matrix diag(t(1), ..., t(k), 0, ..., 0), where k = min(M, N, P).

This routine is the first step in a procedure to compute the generalized singular values of the matrix pair (A, B).

Arguments:

JOBZ: CHARACTER*1.
= 'O': Orthogonal factors U and V are not computed.
= 'U': Orthogonal factor U is computed.
= 'V': Orthogonal factor V is computed.
= 'B': Orthogonal factors U and V are computed.

MATRIX_A: CHARACTER*1.
= 'G': MATRIX_A is a general matrix.
= 'T': MATRIX_A is a transpose matrix.

MATRIX_B: CHARACTER*1.
= 'G': MATRIX_B is a general matrix.
= 'T': MATRIX_B is a transpose matrix.

M: INTEGER.
The number of rows of A and B. M >= 0.

N: INTEGER.
The number of columns of A. N >= 0.

A: REAL array, dimension (LDA,*)
On entry, the M-by-N matrix A.
On exit, A is overwritten by the U matrix or parts of A used in the computation.

LDA: INTEGER.
The leading dimension of the array A. LDA >= max(1,M).

B: REAL array, dimension (LDB,*)
On entry, the M-by-P matrix B.
On exit, B is overwritten by the V matrix or parts of B used in the computation.

LDB: INTEGER.
The leading dimension of the array B. LDB >= max(1,M).

ALPHA: REAL array, dimension (min(M,N))
On exit, ALPHA contains the values s.

BETA: REAL array, dimension (min(M,P))
On exit, BETA contains the values t.

WORK: REAL array, dimension (LWORK)
On exit, WORK(1) contains the optimal LWORK.

LWORK: INTEGER.
The dimension of the array WORK. LWORK >= max(1,2*min(M+N,N+P)).
For optimum performance, LWORK should be at least MAX(1,2*MIN(M+N,N+P)) + 2*MAX(M,N,P) + MAX(MAX(M,N),2*MAX(M,N)) + MAX(MAX(M,P),2*MAX(M,P)).

IWORK: INTEGER array, dimension (N)
On exit, IWORK stores the sorting information. More precisely, the following loop will sort ALPHA
for I = K+1, min(M,K+L)
swap ALPHA(I) and ALPHA(IWORK(I))
endfor
such that ALPHA(1) >= ALPHA(2) >= ... >= ALPHA(N).

INFO: INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
> 0: if INFO = 1, the Jacobi-type procedure failed to converge. For further details, see subroutine STGSJA.

Internal Parameters: 

TOLA    REAL
TOLB    REAL
       TOLA and TOLB are the thresholds to determine the effective
       rank of (A**T,B**T)**T. Generally, they are set to
                TOLA = MAX(M,N)*norm(A)*MACHEPS,
                TOLB = MAX(P,N)*norm(B)*MACHEPS.
       The size of TOLA and TOLB may affect the size of backward
       errors of the decomposition.
