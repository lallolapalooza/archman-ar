sgml2html(1)

الحزمة: linuxdoc-tools

التراخيص: GPL

SGML2HTML(1) دليل الأوامر العامة SGML2HTML(1)

الاسم

sgml2html - إنشاء مخرجات HTML من ملف مصدر SGML بنوعية LinuxDoc DTD

الملخص

sgml2html [generic-option...] [--split 0|1|2 ] [--toc 0|1|2 ] [--dosnames] [--imagebuttons] file[.sgml]

الوصف

sgml2html هو شكل قديم وملغى لأمر html converter الخاص بـ LinuxDoc-Tools (قد يكون اسمه مضللاً، حيث أنه ليس أداة لأي SGML DTD، بل يدعم فقط SGML LinuxDoc DTD). يوصى بالتحول إلى الشكل الجديد linuxdoc -B html الآن. هذا يحول ملف مصدر SGML بنوعية LinuxDoc DTD إلى مخرجات HTML. ستظهر المخرجات في الملف الأعلى مستوى file.html و file-n.html لكل قسم، حيث file هو اسم ملف مصدر SGML و n هو اسم القسم.

يتم تعيين زوج السمة/القيمة "output=html" للشرطيات.

الخيارات

sgml2html يقبل جميع الخيارات العامة الموصوفة في linuxdoc(1)، والخيارات المحددة التالية:

--split, -s
مستوى تقسيم المستندات المصدر. 0 = لا تقسم، 1 = قسم حسب الأقسام الرئيسية، 2 = قسم حسب الأقسام الفرعية.
--toc, -T
مستوى إنشاء جدول المحتويات.
0 = لا تنشئ جدول محتويات على الإطلاق،
1 = يشمل الأقسام الرئيسية (/فصول/أجزاء)،
2 = يشمل الأقسام الفرعية.
--dosnames, -h
استخدم ".htm" بدلاً من ".html" كامتداد للملفات.
--imagebuttons, -I
استخدم أيقونات الصور السهمية "التالي" و "السابق" و "المحتويات" المضمنة في /usr/share/linuxdoc-tools كأزرار تنقل.
--footer, -F
استخدم الملف المحدد كذيل لكل ملف HTML ناتج. الذيل الافتراضي هو ببساطة 
 </BODY>\n </HTML>\n
--header, -H
استخدم الملف المحدد كجزء علوي من الرأس في كل ملف HTML ناتج. لاحظ أن هذا ليس الجزء الكامل من الرأس، أي أن العنوان والروابط (التالي، السابق، المحتويات) في الرأس الافتراضي يتم الاحتفاظ بها. الافتراضي هو 
 <!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 3.2 Final//EN">\n
 <HTML>\n <HEAD>\n
file
ملف مصدر SGML، المسمى إما file أو file.sgml.

الملفات

يتم استخدام العديد من الملفات والملفات التنفيذية في /usr/share/linuxdoc-tools و /usr/bin.

الأخطاء

لا توجد أخطاء معروفة.
