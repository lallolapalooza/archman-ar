توثيق الوظيفة/الروتين الفرعي

subroutine sgtt05 (character trans, integer n, integer nrhs, real, dimension( * ) dl, real, dimension( * ) d, real, dimension( * ) du, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) reslts)

SGTT05

الغرض:

!>
!> SGTT05 تختبر حدود الخطأ من التنقيح التكراري للحل المحسوب لنظام
!> المعادلات A*X = B، حيث A مصفوفة ثلاثية قطرية عامة من الرتبة n
!> و op(A) = A أو A**T، اعتمادًا على TRANS.
!>
!> RESLTS(1) = اختبار حد الخطأ
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> تُرجع قيمة كبيرة إذا لم تكن هذه النسبة أقل من واحد.
!>
!> RESLTS(2) = الباقي من روتين التنقيح التكراري
!>           = الحد الأقصى لـ BERR / ( NZ*EPS + (*) )، حيث
!>             (*) = NZ*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>             و NZ = الحد الأقصى لعدد العناصر غير الصفرية في أي صف من A، بالإضافة إلى 1
!>

المعلمات

TRANS 
!>          TRANS is CHARACTER*1
!>          يحدد شكل نظام المعادلات.
!>          = 'N':  A * X = B     (بدون تبديل)
!>          = 'T':  A**T * X = B  (تبديل)
!>          = 'C':  A**H * X = B  (تبديل مترافق = تبديل)
!>

N

!>          N is INTEGER
!>          عدد صفوف مصفوفتي X و XACT.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          عدد أعمدة مصفوفتي X و XACT.  NRHS >= 0.
!>

DL

!>          DL is REAL array, dimension (N-1)
!>          عناصر القطر السفلي (n-1) للمصفوفة A.
!>

D

!>          D is REAL array, dimension (N)
!>          عناصر القطر الرئيسي للمصفوفة A.
!>

DU

!>          DU is REAL array, dimension (N-1)
!>          عناصر القطر العلوي (n-1) للمصفوفة A.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          متجهات الطرف الأيمن لنظام المعادلات الخطية.
!>

LDB

!>          LDB is INTEGER
!>          البعد الرائد للمصفوفة B.  LDB >= max(1,N).
!>

X

!>          X is REAL array, dimension (LDX,NRHS)
!>          متجهات الحل المحسوبة.  يتم تخزين كل متجه كعمود في المصفوفة X.
!>

LDX

!>          LDX is INTEGER
!>          البعد الرائد للمصفوفة X.  LDX >= max(1,N).
!>

XACT

!>          XACT is REAL array, dimension (LDX,NRHS)
!>          متجهات الحل الدقيقة.  يتم تخزين كل متجه كعمود في المصفوفة XACT.
!>

LDXACT

!>          LDXACT is INTEGER
!>          البعد الرائد للمصفوفة XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          تقديرات حدود الخطأ الأمامي لكل متجه حل X.
!>          إذا كان XTRUE هو الحل الحقيقي، فإن FERR يحد من حجم أكبر
!>          مدخل في (X - XTRUE) مقسومًا على حجم أكبر مدخل في X.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          خطأ الخلفية النسبي المكون لكل متجه حل
!>          (أي، أصغر تغيير نسبي في أي مدخل في A أو B يجعل X حلاً دقيقًا).
!>

RESLTS

!>          RESLTS is REAL array, dimension (2)
!>          الحد الأقصى عبر متجهات الحل NRHS للنسب التالية:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
