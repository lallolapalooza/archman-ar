SGGSVP

الغرض:

!>
!> هذا الإجراء الفرعي مهمل وتم استبداله بالإجراء الفرعي SGGSVP3.
!>
!> SGGSVP يحسب المصفوفات المتعامدة U، V و Q بحيث
!>
!>                    N-K-L  K    L
!>  U**T*A*Q =     K ( 0    A12  A13 )  if M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  if M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**T*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> حيث تكون المصفوفة A12 بحجم KxK والمصفوفة B13 بحجم LxL غير مفردة
!> ومثلثية عليا؛ A23 تكون مثلثية عليا بحجم LxL إذا كان M-K-L >= 0،
!> وإلا فإن A23 تكون شبه منحرفة عليا بحجم (M-K)xL.  K+L = الرتبة العددية الفعالة
!> للمصفوفة (A**T,B**T)**T بحجم (M+P)xN.
!>
!> هذا التحلل هو خطوة المعالجة المسبقة لحساب التحلل القيم المنفردة المعممة (GSVD)، انظر الإجراء الفرعي
!> SGGSVD.
!>

توثيق الدالة/الروتين الفرعي

SGGVSP هو روتين فرعي ضمن مكتبة LAPACK (Linear Algebra PACKage) يستخدم لحل مشكلة القيم الذاتية المعممة (Generalized Eigenvalue Problem) للمصفوفات ذات الحجم المحدود.

**المعلمات:**

  • N: (إدخال) عدد الصفوف والأعمدة للمصفوفات A و B.
  • A: (إدخال/إخراج) مصفوفة حقيقية من الدرجة N x N. عند الإدخال، تحتوي على المصفوفة الأصلية. عند الإخراج، قد يتم تعديلها.
  • LDA: (إدخال) طول الصف الأول للمصفوفة A.
  • B: (إدخال/إخراج) مصفوفة حقيقية من الدرجة N x N. عند الإدخال، تحتوي على المصفوفة الأصلية. عند الإخراج، قد يتم تعديلها.
  • LDB: (إدخال) طول الصف الأول للمصفوفة B.
  • Q: (إخراج) مصفوفة متعامدة من الدرجة N x N.
  • LDQ: (إدخال) طول الصف الأول للمصفوفة Q.
  • Z: (إخراج) مصفوفة متعامدة من الدرجة N x N.
  • LDZ: (إدخال) طول الصف الأول للمصفوفة Z.
  • X: (إخراج) متجه يحتوي على القيم الذاتية المعممة.
  • LWORK: (إدخال) حجم مساحة العمل X. يجب أن يكون LWORK على الأقل N*N.
  • IWORK: (إخراج) متجه للأعداد الصحيحة يستخدمه الروتين. حجمه يجب أن يكون على الأقل 5*N.
  • INFO: (إخراج) عدد صحيح يشير إلى حالة الإنجاز:
    • INFO = 0: تم التنفيذ بنجاح.
    • INFO < 0: خطأ في معلمة الإدخال.
    • INFO > 0: فشل في خوارزمية التقارب.

**الوصف:**

تقوم SGGVSP بحساب القيم الذاتية المعممة λ والمؤشرات الذاتية μ (ممثلة هنا في المتجه X) التي تحقق المعادلة:

A*v = λ*B*v

حيث v هو المتجه الذاتي.

يتم حل هذه المشكلة من خلال تخفيضها إلى مشكلة قيم ذاتية قياسية باستخدام تحويلات متوازية لـ Q و Z:

Q'*A*Z = D_A*R_A

Q'*B*Z = D_B*R_B

حيث Q و Z مصفوفتان متعامدتان، D_A و D_B مصفوفتان قطريتان، و R_A و R_B مصفوفتان مثلثيتان علويتان.

ثم يتم حل مشكلة القيم الذاتية المعممة للمصفوفات المثلثية المبسطة.
