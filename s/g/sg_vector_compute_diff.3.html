sg_vector_compute_diff(3)

الحزمة: libstatgrab

التراخيص: LGPL, GPL

NAME

sg_vector_compute_diff, VECTOR_CREATE, VECTOR_CLEAR, VECTOR_CREATE_OR_RESIZE, VECTOR_UPDATE, VECTOR_ITEM_COUNT - computes difference between two vectors

SYNOPSIS

#include <statgrab.h>

struct sg_vector *sg_vector_compute_diff(const struct sg_vector *v1, const struct sg_vector *v2);

struct sg_vector *sg_vector_create(size_t alloc_count, size_t initial_used, size_t block_size, size_t item_size, const void *init_info);

void sg_vector_clear(struct sg_vector *vector);

struct sg_vector *VECTOR_CREATE(size_t alloc_count, size_t block_size, identifier type);

struct sg_vector *VECTOR_CREATE_OR_RESIZE(struct sg_vector *vector, size_t new_count, identifier type);

void VECTOR_UPDATE(struct sg_vector **vectorptr, size_t new_count, datatype *data, identifier datatype);

size_t VECTOR_ITEM_COUNT(struct sg_vector *vector);

DESCRIPTION

The sg_vector_compute_diff() function computes and returns a difference between two vectors.

The sg_vector_create() function creates a new vector. alloc_count parameter is the maximum number of elements that the vector can hold. initial_used parameter is the number of elements the vector already holds. block_size parameter is the number of elements to allocate each time the vector runs out of space. item_size parameter is the size of each element. init_info parameter is a pointer to initialization information structure. The structure type is defined by the vector's specialisation. A vector's specialisation is specified by the type argument of the VECTOR_CREATE macro.

The sg_vector_clear() function clears the vector.

The VECTOR_CREATE() macro is a wrapper around sg_vector_create(). It calls sg_vector_create() with alloc_count = block_size and initial_used = 0 using the vector specialisation type##_vector_init_info.

The VECTOR_CLEAR() macro simply calls sg_vector_clear(). This macro exists only for conformity.

The VECTOR_CREATE_OR_RESIZE() macro calls sg_vector_create() when the given vector pointer points to NULL or sg_vector_resize() otherwise. The result of the appropriate function is returned.

The VECTOR_UPDATE() macro calls VECTOR_CREATE_OR_RESIZE() and sets data to the first element of the resulting vector when a non-NULL pointer got, to NULL otherwise. When VECTOR_CREATE_OR_RESIZE() returns a NULL pointer and new_count is not equal to 0 (zero), the instructions from the macro VECTOR_UPDATE_ERROR_CLEANUP are executed to cleanup before returning from current subroutine with the error which has been occurred.

The VECTOR_ITEM_COUNT() macro returns 0 for a non-existing vector (vector == 0) and the number of containing elements otherwise.

NOTES

VECTOR_CREATE_OR_RESIZE() calls sg_vector_create() when the given vector pointer points to NULL or sg_vector_resize() otherwise. The result of the appropriate function is returned.

VECTOR_UPDATE() calls VECTOR_CREATE_OR_RESIZE() and sets data to the first element of the resulting vector when a non-NULL pointer got, to NULL otherwise. When VECTOR_CREATE_OR_RESIZE() returns a NULL pointer and new_count is not equal to 0 (zero), the instructions from the macro VECTOR_UPDATE_ERROR_CLEANUP are executed to cleanup before returning from current subroutine with the error which has been occurred.

VECTOR_ITEM_COUNT() returns 0 for a non-existing vector (vector == 0) and the number of containing elements otherwise.

RETURN VALUES

Beside error codes, the return values, if any, are always a pointer to vector structures (struct sg_vector *).
