n A = P*L*U !> كما تم حسابه بواسطة SGETRF؛ تم تبديل الصف i من المصفوفة !> مع الصف IPIV(i). !> !> إذا كانت FACT = 'N'، فإن IPIV هو وسيط إخراج ويحتوي عند الخروج !> على مؤشرات المحورية من تحليل A = P*L*U !> للمصفوفة الأصلية A. !> !> إذا كانت FACT = 'E'، فإن IPIV هو وسيط إخراج ويحتوي عند الخروج !> على مؤشرات المحورية من تحليل A = P*L*U !> للمصفوفة المتوازنة A. !>

EQUED

!>          EQUED هو CHARACTER*1
!>     يحدد شكل التوازن الذي تم إجراؤه.
!>       = 'N':  لا يوجد توازن (صحيح دائمًا إذا كانت FACT = 'N').
!>       = 'R':  توازن الصفوف، أي تم ضرب A مسبقًا بواسطة
!>               diag(R).
!>       = 'C':  توازن الأعمدة، أي تم ضرب A لاحقًا بواسطة
!>               diag(C).
!>       = 'B':  توازن الصفوف والأعمدة معًا، أي تم استبدال A بـ
!>               diag(R) * A * diag(C).
!>     EQUED هو وسيط إدخال إذا كانت FACT = 'F؛ بخلاف ذلك، فهو وسيط
!>     إخراج.
!>

R


!>          R هو مصفوفة REAL، بأبعاد (N)
!>     عوامل قياس الصفوف لـ A. إذا كانت EQUED = 'R' أو 'B'، يتم ضرب A
!>     من اليسار بـ diag(R)؛ إذا كانت EQUED = 'N' أو 'C'، فلن يتم الوصول إلى R.
!>     R هو وسيط إدخال إذا كانت FACT = 'F؛ بخلاف ذلك، R هو وسيط إخراج.
!>     إذا كانت FACT = 'F' وكانت EQUED = 'R' أو 'B'، يجب أن يكون كل عنصر من R موجبًا.
!>     إذا كان R هو إخراج، فإن كل عنصر من R هو قوة للجذر.
!>     إذا كان R هو إدخال، يجب أن يكون كل عنصر من R قوة للجذر
!>     لضمان حل موثوق به وتقديرات للأخطاء. القياس بقوى الجذر لا يسبب
!>     أخطاء تقريب إلا إذا كانت النتيجة تحت التدفق أو تجاوزت التدفق.
!>     تؤدي أخطاء التقريب أثناء القياس إلى تنقيح بمصفوفة ليست مكافئة
!>     للمصفوفة المدخلة، مما ينتج تقديرات أخطاء قد لا تكون موثوقة.
!>

C


!>          C هو مصفوفة REAL، بأبعاد (N)
!>     عوامل قياس الأعمدة لـ A. إذا كانت EQUED = 'C' أو 'B'، يتم ضرب A
!>     من اليمين بـ diag(C)؛ إذا كانت EQUED = 'N' أو 'R'، فلن يتم الوصول إلى C.
!>     C هو وسيط إدخال إذا كانت FACT = 'F؛ بخلاف ذلك، C هو وسيط إخراج.
!>     إذا كانت FACT = 'F' وكانت EQUED = 'C' أو 'B'، يجب أن يكون كل عنصر من C موجبًا.
!>     إذا كان C هو إخراج، فإن كل عنصر من C هو قوة للجذر.
!>     إذا كان C هو إدخال، يجب أن يكون كل عنصر من C قوة للجذر
!>     لضمان حل موثوق به وتقديرات للأخطاء. القياس بقوى الجذر لا يسبب
!>     أخطاء تقريب إلا إذا كانت النتيجة تحت التدفق أو تجاوزت التدفق.
!>     تؤدي أخطاء التقريب أثناء القياس إلى تنقيح بمصفوفة ليست مكافئة
!>     للمصفوفة المدخلة، مما ينتج تقديرات أخطاء قد لا تكون موثوقة.
!>

B


!>          B هو مصفوفة REAL، بأبعاد (LDB,NRHS)
!>     عند الإدخال، مصفوفة الطرف الأيمن B بأبعاد N-by-NRHS.
!>     عند الخروج،
!>     إذا كانت EQUED = 'N'، لا يتم تعديل B؛
!>     إذا كانت TRANS = 'N' وكانت EQUED = 'R' أو 'B'، يتم استبدال B بـ
!>        diag(R)*B؛
!>     إذا كانت TRANS = 'T' أو 'C' وكانت EQUED = 'C' أو 'B'، يتم استبدال B بـ
!>        diag(C)*B.
!>

LDB


!>          LDB هو INTEGER
!>     البعد الرائد للمصفوفة B. LDB >= max(1,N).
!>

X


!>          X هو مصفوفة REAL، بأبعاد (LDX,NRHS)
!>     إذا كان INFO = 0، فإن مصفوفة الحل X بأبعاد N-by-NRHS لنظام
!>     المعادلات الأصلي. لاحظ أن A و B يتم تعديلهما عند الخروج
!>     إذا كانت EQUED .ne. 'N'، وأن حل النظام المتوازن هو
!>     inv(diag(C))*X إذا كانت TRANS = 'N' و EQUED = 'C' أو 'B'، أو
!>     inv(diag(R))*X إذا كانت TRANS = 'T' أو 'C' و EQUED = 'R' أو 'B'.
!>

LDX


!>          LDX هو INTEGER
!>     البعد الرائد للمصفوفة X. LDX >= max(1,N).
!>

RCOND


!>          RCOND هو REAL
!>     المقلوب النسبي لرقم الشرط. هذا تقدير لـ
!>     مقلوب رقم شرط Skeel للمصفوفة A بعد
!>     التوازن (إذا تم إجراؤه). إذا كان هذا أقل من الدقة الآلية
!>     (على وجه الخصوص، إذا كان صفرًا)، فإن المصفوفة منفردة
!>     بدقة العمل. لاحظ أن الخطأ قد يكون لا يزال صغيرًا حتى
!>     إذا كان هذا الرقم صغيرًا جدًا وكانت المصفوفة تبدو سيئة
!>     الشرط.
!>

RPVGRW


!>          RPVGRW هو REAL
!>     مقلوب نمو المحور. عند الخروج، يحتوي هذا على المقلوب
!>     لعامل نمو المحور norm(A)/norm(U). يتم استخدام الـ
!>     norm. إذا كان هذا أقل بكثير من 1، فإن استقرار
!>     تحليل LU للمصفوفة A (المتوازنة) قد يكون ضعيفًا.
!>     هذا يعني أيضًا أن الحل X، والأرقام الشرطية المقدرة،
!>     وحدود الأخطاء قد لا تكون موثوقة. إذا فشل التحليل مع
!>     0<INFO<=N، فإن هذا يحتوي على عامل نمو المحور المقلوب
!>     للأعمدة INFO الرائدة لـ A. في SGESVX، هذه الكمية
!>     تُعاد في WORK(1).
!>

BERR


!>          BERR هو مصفوفة REAL، بأبعاد (NRHS)
!>     الخطأ الخلفي النسبي على مستوى المكون. هذا هو
!>     الخطأ الخلفي النسبي على مستوى المكون لكل متجه حل X(j)
!>     (أي، أصغر تغيير نسبي في أي عنصر من A أو B يجعل X(j)
!>     حلاً دقيقًا).
!>

N_ERR_BNDS


!>          N_ERR_BNDS هو INTEGER
!>     عدد حدود الخطأ المراد إرجاعها لكل جانب أيمن
!>     ولكل نوع (على مستوى المعيار أو على مستوى المكون). انظر ERR_BNDS_NORM و
!>     ERR_BNDS_COMP أدناه.
!>

ERR_BNDS_NORM


!>          ERR_BNDS_NORM هو مصفوفة REAL، بأبعاد (NRHS, N_ERR_BNDS)
!>     لكل جانب أيمن، تحتوي هذه المصفوفة على معلومات حول
!>     حدود الخطأ المختلفة وأرقام الشرط المقابلة لـ
!>     الخطأ النسبي على مستوى المعيار، والذي يتم تعريفه على النحو التالي:
!>
!>     الخطأ النسبي على مستوى المعيار في متجه الحل i:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     يتم فهرسة المصفوفة حسب نوع معلومات الخطأ كما هو موضح
!>     أدناه. هناك حاليًا ما يصل إلى ثلاث قطع من المعلومات
!>     يتم إرجاعها.
!>
!>     الفهرس الأول في ERR_BNDS_NORM(i,:) يتوافق مع الجانب الأيمن i.
!>
!>     الفهرس الثاني في ERR_BNDS_NORM(:,err) يحتوي على المجالات الثلاثة التالية:
!>     err = 1  قيمة منطقية. ثق بالإجابة إذا كان
!>              رقم الشرط المقلوب أقل من الحد
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  حد الخطأ: الخطأ الأمامي المقدر،
!>              بالتأكيد ضمن عامل 10 من الخطأ الحقيقي
!>              طالما أن الإدخال التالي أكبر من الحد
!>              sqrt(n) * slamch('Epsilon'). يجب فقط أن يتم الوثوق بهذا الحد
!>              الخطأ إذا كانت القيمة المنطقية السابقة صحيحة.
!>
!>     err = 3  رقم الشرط المقلوب: رقم الشرط النسبي المقدر على مستوى المعيار.
!>              مقارنة بالحد
!>              sqrt(n) * slamch('Epsilon') لتحديد ما إذا كان الخطأ
!>              التقدير . هذه الأرقام الشرطية المقلوبة
!>              هي 1 / (norm(Z^{-1},inf) * norm(Z,inf)) لبعض
!>              المصفوفة Z المتوازنة بشكل مناسب.
!>              لتكن Z = S*A، حيث تقوم S بقياس كل صف بقوة للجذر
!>              بحيث تكون جميع مجاميع الصفوف المطلقة لـ Z تقريبًا 1.
!>
!>     انظر Lapack Working Note 165 لمزيد من التفاصيل وتحذيرات إضافية.
!>

ERR_BNDS_COMP


!>          ERR_BNDS_COMP هو مصفوفة REAL، بأبعاد (NRHS, N_ERR_BNDS)
!>     لكل جانب أيمن، تحتوي هذه المصفوفة على معلومات حول
!>     حدود الخطأ المختلفة وأرقام الشرط المقابلة لـ
!>     الخطأ النسبي على مستوى المكون، والذي يتم تعريفه على النحو التالي:
!>
!>     الخطأ النسبي على مستوى المكون في متجه الحل i:
!>                    abs(XTRUE(j,i) - X(j,i))
!>             max_j ----------------------
!>                         abs(X(j,i))
!>
!>     يتم فهرسة المصفوفة حسب الجانب الأيمن i (الذي يعتمد عليه
!>     الخطأ النسبي على مستوى المكون)، ونوع معلومات الخطأ كما هو موضح
!>     أدناه. هناك حاليًا ما يصل إلى ثلاث قطع من المعلومات
!>     يتم إرجاعها لكل جانب أيمن. إذا
!>     لم يتم طلب الدقة على مستوى المكون (PARAMS(3) = 0.0)، فإن
!>     ERR_BNDS_COMP لا يتم الوصول إليها. إذا كان N_ERR_BNDS < 3، فسيتم إرجاع
!>     أول (:,N_ERR_BNDS) إدخالات فقط.
!>
!>     الفهرس الأول في ERR_BNDS_COMP(i,:) يتوافق مع الجانب الأيمن i.
!>
!>     الفهرس الثاني في ERR_BNDS_COMP(:,err) يحتوي على المجالات الثلاثة التالية:
!>     err = 1  قيمة منطقية. ثق بالإجابة إذا كان
!>              رقم الشرط المقلوب أقل من الحد
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  حد الخطأ: الخطأ الأمامي المقدر،
!>              بالتأكيد ضمن عامل 10 من الخطأ الحقيقي
!>              طالما أن الإدخال التالي أكبر من الحد
!>              sqrt(n) * slamch('Epsilon'). يجب فقط أن يتم الوثوق بهذا الحد
!>              الخطأ إذا كانت القيمة المنطقية السابقة صحيحة.
!>
!>     err = 3  رقم الشرط المقلوب: رقم الشرط النسبي المقدر على مستوى المكون.
!>              مقارنة بالحد
!>              sqrt(n) * slamch('Epsilon') لتحديد ما إذا كان الخطأ
!>              التقدير . هذه الأرقام الشرطية المقلوبة
!>              هي 1 / (norm(Z^{-1},inf) * norm(Z,inf)) لبعض
!>              المصفوفة Z المتوازنة بشكل مناسب.
!>              لتكن Z = S*(A*diag(x))، حيث x هو الحل
!>              للجانب الأيمن الحالي وتقوم S بقياس كل صف من
!>              A*diag(x) بقوة للجذر بحيث تكون جميع مجاميع الصفوف المطلقة
!>              لـ Z تقريبًا 1.
!>
!>     انظر Lapack Working Note 165 لمزيد من التفاصيل وتحذيرات إضافية.
!>

NPARAMS


!>          NPARAMS هو INTEGER
!>     يحدد عدد المعلمات التي تم تعيينها في PARAMS. إذا كان <= 0، فإن
!>     مصفوفة PARAMS لا يتم الوصول إليها أبدًا ويتم استخدام القيم الافتراضية.
!>

PARAMS


!>          PARAMS هي مصفوفة REAL، بأبعاد NPARAMS
!>     تحدد معلمات الخوارزمية. إذا كانت قيمة إدخال < 0.0، فسيتم
!>     ملء هذا الإدخال بالقيمة الافتراضية المستخدمة لهذا
!>     المعلم. يتم الوصول إلى المواضع حتى NPARAMS فقط؛ يتم استخدام الافتراضيات
!>     للمعلمات ذات الأرقام الأعلى.
!>
!>       PARAMS(LA_LINRX_ITREF_I = 1) : ما إذا كان سيتم إجراء التنقيح التكراري
!>            أم لا.
!>         الافتراضي: 1.0
!>            = 0.0:  لا يتم إجراء التنقيح، ولا يتم حساب حدود الخطأ.
!>            = 1.0:  استخدم خوارزمية التنقيح بالدقة المزدوجة،
!>                    ربما مع عمليات حسابية أحادية مضاعفة إذا كانت
!>                    بيئة الترجمة لا تدعم الدقة المزدوجة.
!>              (القيم الأخرى محجوزة للاستخدام المستقبلي)
!>
!>       PARAMS(LA_LINRX_ITHRESH_I = 2) : الحد الأقصى لعدد حسابات المتبقي
!>            المسموح بها للتنقيح.
!>         الافتراضي: 10
!>

NAME


sgesvxx - High-level interface for solving a general linear system of equations Ax = B with iterative refinement.







SYNOPSIS


SUBROUTINE SGESVXX(
     CHARACTER(1)            ORDER,
     CHARACTER(1)            JOB,
     INTEGER                 N,
     INTEGER                 NRHS,
     REAL, DIMENSION( *)    A,
     INTEGER                 LDA,
     REAL, DIMENSION( *)    B,
     INTEGER                 LDB,
     INTEGER                 *                                     APIVOT,
     REAL, DIMENSION( *)    EQUED,
     REAL, DIMENSION( *)    RCOND,
     REAL, DIMENSION( *)    ERR_BNDS_NORM,
     REAL, DIMENSION( *)    ERR_BNDS_COMP,
     REAL, DIMENSION( *)    WORK,
     INTEGER, DIMENSION( *) IWORK,
     INTEGER                 INFO )



Parameters




ORDER


ORDER is CHARACTER(1)


Input parameter.


Specifies the storage format of the matrix A.


ORDER = 'C' or 'c': Col-major (column-major).


ORDER = 'R' or 'r': Row-major.




JOB


JOB is CHARACTER(1)


Input parameter.


Specifies the type of solution to be computed.


JOB = 'N': No error bounds are computed.


JOB = 'E': Error bounds are computed.




N


N is INTEGER


Input parameter.


The order of the matrix A. N >= 0.




NRHS


NRHS is INTEGER


Input parameter.


The number of right hand sides, i.e., the number of columns of the matrix B. 0 <= NRHS <= max(1,N).




A


A is REAL array, dimension (LDA,N)


Input parameter.


On entry, the array A contains the coefficient matrix of the linear system.


On exit, A may be overwritten by details of the factorization.




LDA


LDA is INTEGER


Input parameter.


The leading dimension of the array A.




B


B is REAL array, dimension (LDB,NRHS)


Input parameter.


On entry, the array B contains the right-hand side matrix.


On exit, the array B contains the solution matrix X.




LDB


LDB is INTEGER


Input parameter.


The leading dimension of the array B.




APIVOT


APIVOT is INTEGER array, dimension (N)


Output parameter.


The pivot indices array. APIVOT[I] contains the row and column
    indices of the pivot element in the I-th factorization step.




EQUED


EQUED is CHARACTER(1) array, dimension (1)


Output parameter.


EQUED[0] is set to 'N' if no row and scaling was
    performed.


EQUED[0] is set to 'R' if row scaling was performed.


EQUED[0] is set to 'C' if column scaling was performed.


EQUED[0] is set to 'B' if both row and column scaling
    were performed.




RCOND


RCOND is REAL array, dimension (1)


Output parameter.


Estimate of the reciprocal condition number of A. RCOND is computed
    only if JOB = 'E' or 'N'.




ERR_BNDS_NORM


ERR_BNDS_NORM is REAL array, dimension (NRHS)


Output parameter.


If JOB = 'E', ERR_BNDS_NORM(J) estimates the normwise
    relative error bound for the solution corresponding to the J-th
    right-hand side, and is computed only if.




ERR_BNDS_COMP


ERR_BNDS_COMP is REAL array, dimension (NRHS)


Output parameter.


If JOB = 'E', ERR_BNDS_COMP(J) estimates the componentwise
    relative error bound for the solution corresponding to the J-th
    right-hand side, and is computed only if.




WORK


WORK is REAL array, dimension (4*N)


Workspace array. The dimension of WORK is at least max(1, 4*N).




IWORK


IWORK is INTEGER array, dimension (N)


Integer workspace array. The dimension of IWORK is at least max(1, N).




INFO


INFO is INTEGER


Output parameter.


= 0: Successful exit. The solution to every right-hand side is
    guaranteed.


< 0: If INFO = -i, the i-th argument had an illegal value.


> 0 and <= N: U(INFO,INFO) is exactly zero. The factorization
    has been completed, but the factor U is exactly singular, so
    the solution and error bounds could not be computed. RCOND = 0
    is returned.


= N+J: The solution corresponding to the Jth right-hand side is
    not guaranteed. The solutions corresponding to other right-
    hand sides K with K > J may not be guaranteed as well, but
    only the first such right-hand side is reported. If a small
    componentwise error is not requested (PARAMS(3) = 0.0) then
    the Jth right-hand side is the first with a normwise error
    bound that is not guaranteed (the smallest J such
    that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
    the Jth right-hand side is the first with either a normwise or
    componentwise error bound that is not guaranteed (the smallest
    J such that either ERR_BNDS_NORM(J,1) = 0.0 or
    ERR_BNDS_COMP(J,1) = 0.0). See the definition of
    ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
    about all of the right-hand sides check ERR_BNDS_NORM or
    ERR_BNDS_COMP.











Function/Subroutine Documentation


!> @brief High-level interface for solving a general linear system
!>        of equations Ax = B with iterative refinement.
!>
!> This subroutine solves the system of linear equations Ax = B,
!> optionally computing error bounds for the solution.
!>
!> The routine uses a robust Gaussian elimination with partial
!> pivoting to factorize the matrix A. It then computes the solution
!> vector(s) x and, if requested, estimates the forward error bound
!> for the solution.
!>
!> @param ORDER Specifies the storage format of matrix A.
!>        'C' or 'c': Col-major (column-major).
!>        'R' or 'r': Row-major.
!> @param JOB Specifies the type of solution to be computed.
!>        'N': No error bounds are computed.
!>        'E': Error bounds are computed.
!> @param N The order of the matrix A. N >= 0.
!> @param NRHS The number of right-hand sides, i.e., the number of columns
!>        of the matrix B. 0 <= NRHS <= max(1,N).
!> @param A Array A contains the coefficient matrix of the linear system.
!>        On exit, A may be overwritten by details of the factorization.
!> @param LDA The leading dimension of the array A.
!> @param B Array B contains the right-hand side matrix. On exit, the
!>        array B contains the solution matrix X.
!> @param LDB The leading dimension of the array B.
!> @param APIVOT Pivot indices array. APIVOT(I) contains the row and column
!>        indices of the pivot element in the I-th factorization step.
!> @param EQUED Output parameter. EQUED(0) is set to 'N' if no row
!>        and column scaling was performed, 'R' if row scaling was
!>        performed, 'C' if column scaling was performed, and 'B' if both
!>        row and column scaling were performed.
!> @param RCOND Estimate of the reciprocal condition number of A. RCOND is
!>        computed only if JOB = 'E' or 'N'.
