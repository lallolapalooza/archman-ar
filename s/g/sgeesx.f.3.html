SGEESX(1)

LAPACK 3.12.0

الاسم

SGEESX - حساب القيم الذاتية والمتجهات الذاتية لمصفوفة عامة.

الصيغة

 SUBROUTINE SGEESX(MATRIXNAME, N, A, LDA, SELECT, VL,
                LDVL, VR, LDVR, LWORK, INFO)
```

الوصف

يقوم SGEESX بحساب القيم الذاتية والمتجهات الذاتية (الخاصة والمستقلة) لمصفوفة تشارلز A (N × N) مع تطبيق فرز اختياري.

سيتم حساب القيم الذاتية بالترتيب المحدد بواسطة مصفوفة SELECT.

يتم فرز القيم الذاتية بحيث إذا كانت SELECT(j) = TRUE، فسيتم وضع القيمة الذاتية j في بداية القائمة (المعرفة بواسطة ILO و IHI). يتم ترتيب القيم الذاتية في قسمها الجزئي (ILO إلى IHI) بطريقة لا يمكن تحديدها.

إذا كانت VL = TRUE، يتم حساب المتجهات الذاتية اليسرى.

إذا كانت VR = TRUE، يتم حساب المتجهات الذاتية اليمنى.

يتم حساب المتجهات الذاتية اليمنى بحيث تكون A * VR = VL * VR.

إذا كانت VL = TRUE، يتم حساب المتجهات الذاتية اليسرى بحيث تكون VL**H * A = VR * VL.

يتم حساب القيم الذاتية والمتجهات الذاتية اليمنى بحيث تكون A * VR = VL * VR.

يتم حساب المتجهات الذاتية اليسرى بحيث تكون VL**H * A = VR * VL.

إذا تم اختيار فرز معين (أي، إذا كانت SELECT = TRUE لبعض j)، فسيتم حساب المتجهات الذاتية اليمنى بحيث تكون A * VR = VL * VR.

إذا كان VL = TRUE، يتم حساب المتجهات الذاتية اليسرى بحيث تكون VL**H * A = VR * VL.

معلمات

MATRIXNAME

MATRIXNAME is CHARACTER*1 Input

يحدد نوع المصفوفة:

  • MATRIXNAME = 'N' (بدون فرز)

  • MATRIXNAME = 'S' (فرز)

N

N is INTEGER Input

رتبة المصفوفة A.

A

A is REAL array, dimension (LDA, N)

يتم تخزين المصفوفة A في A.

LDA

LDA is INTEGER Input

مضاعف الصف للمصفوفة A. يتم تحديد LDA ≥ max(1, N).

SELECT

SELECT is LOGICAL array, dimension (N)

تحدد القيمة الذاتية التي سيتم فرزها. إذا كانت SELECT(j) = TRUE، فسيتم وضع القيمة الذاتية j في بداية القائمة.

VL

VL is LOGICAL Input

إذا كان VL = TRUE، يتم حساب المتجهات الذاتية اليسرى.

LDVL

LDVL is INTEGER Input

مضاعف الصف للمصفوفة VL. يتم تحديد LDVL ≥ max(1, N).

VR

VR is LOGICAL Input

إذا كان VR = TRUE، يتم حساب المتجهات الذاتية اليمنى.

LDVR

LDVR is INTEGER Input

مضاعف الصف للمصفوفة VR. يتم تحديد LDVR ≥ max(1, N).

LWORK

LWORK is INTEGER Input

عدد المساحة المتاحة في WORK. عادة، تكون LWORK ≥ max(1, N).

إذا كان LWORK = -1، فسيقوم الروتين فقط بحساب حدود عليا لحجم مصفوفة WORK، وإرجاع هذه القيم كأول إدخالات في مصفوفة WORK، ولن يتم إصدار رسائل خطأ متعلقة بـ LWORK بواسطة XERBLA.

INFO

INFO is INTEGER Output

  • INFO = 0: خروج ناجح
  • < 0: إذا كانت INFO = -i، كانت الوسيطة i غير قانونية.
  • > 0: إذا كانت INFO = i، و i هو
    • ≤ N: فشل خوارزمية QR في حساب جميع القيم الذاتية؛ تحتوي العناصر 1:ILO-1 و i+1:N من WR و WI على تلك القيم الذاتية التي تقاربت؛ إذا كان JOBVS = 'V'، فإن VS تحتوي على التحويل الذي يقلل A إلى شكله الجزئي المتشكل؛
    • = N+1: لم يكن بالإمكان إعادة ترتيب القيم الذاتية لأن بعض القيم الذاتية كانت قريبة جدًا من بعضها البعض (المشكلة غير مستقرة للغاية)؛
    • = N+2: بعد إعادة الترتيب، غيرت دقة التقريب قيم بعض القيم الذاتية المعقدة بحيث لم تعد القيم الذاتية الرائدة في الشكل المتشكل تفي بـ SELECT=.TRUE. يمكن أن يحدث هذا أيضًا بسبب التدفق السفلي الناتج عن القياس.
