schemagen-openjdk8(1)

الحزمة: jdk8-openjdk

التراخيص: LicenseRef-Java

schemagen(1) أدوات خدمات الويب Java schemagen(1)

الاسم

schemagen - يقوم بإنشاء مخطط لكل مساحة اسم يتم الإشارة إليها في فئات Java الخاصة بك.

الملخص

schemagen [ خيارات ] ملفات Java
خيارات
خيارات سطر الأوامر. انظر الخيارات.
ملفات Java
ملفات فئة Java المراد معالجتها.

الوصف

يقوم مولد المخطط بإنشاء ملف مخطط لكل مساحة اسم يتم الإشارة إليها في فئات Java الخاصة بك. حاليًا، لا يمكنك التحكم في اسم ملفات المخطط التي تم إنشاؤها. للتحكم في أسماء ملفات المخطط، انظر استخدام SchemaGen مع Ant على http://jaxb.java.net/nonav/2.2.3u1/docs/schemagenTask.html

ابدأ مولد المخطط باستخدام برنامج shell schemagen المناسب في دليل bin لمنصتك. يمكن لمولد المخطط الحالي معالجة ملفات مصدر Java أو ملفات الفئة.

schemagen.sh Foo.java Bar.java ...
ملاحظة: كتابة schema1.xsd

إذا أشارت ملفات Java الخاصة بك إلى فئات أخرى، فيجب أن تكون هذه الفئات متاحة في متغير البيئة CLASSPATH الخاص بنظامك، أو يجب تحديدها في سطر أوامر schemagen باستخدام خيارات مسار الفئة. انظر الخيارات. إذا لم تكن الملفات المشار إليها متاحة أو محددة، فستحصل على أخطاء عند إنشاء المخطط.

الخيارات

-d مسار

الموقع الذي يضع فيه أمر schemagen الملفات التي تم إنشاؤها بواسطة المعالج والملفات التي تم إنشاؤها بواسطة javac.
-cp مسار

الموقع الذي يضع فيه أمر schemagen الملفات التي حددها المستخدم.
-classpath مسار

الموقع الذي يضع فيه أمر schemagen الملفات التي حددها المستخدم.
-encoding ترميز

يحدد الترميز المراد استخدامه لاستدعاءات أمر apt أو javac.
-episode ملف

ينشئ ملف حلقة (episode file) للتجميع المنفصل.
-version

يعرض معلومات الإصدار.
-help

يعرض رسالة مساعدة.
