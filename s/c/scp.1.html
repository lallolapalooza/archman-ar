SCP(1) دليل الأوامر العامة SCP(1)

الاسم

scp — نسخ آمن للملفات عبر OpenSSH

الملخص

scp [-346ABCOpqRrsTv] [-c التشفير] [-D مسار_خادم_sftp] [-F ssh_config] [-i ملف_الهوية] [-J الوجهة] [-l الحد] [-o خيار_ssh] [-P المنفذ] [-S البرنامج] [-X خيار_sftp] المصدر ... الهدف

الوصف

scp يقوم بنسخ الملفات بين المضيفين على شبكة.

scp يستخدم بروتوكول SFTP عبر اتصال ssh(1) لنقل البيانات، ويستخدم نفس آليات المصادقة ويوفر نفس مستوى الأمان لجلسة تسجيل الدخول.

scp سيطلب كلمات المرور أو عبارات المرور إذا كانت مطلوبة للمصادقة.

يمكن تحديد المصدر و الهدف كعنوان مسار محلي، أو مضيف بعيد مع مسار اختياري بالشكل [user@]host:[path]، أو عنوان URI بالشكل scp://[user@]host[:port][/path]. يمكن جعل أسماء الملفات المحلية واضحة باستخدام عناوين المسار المطلقة أو النسبية لتجنب قيام scp بمعاملة أسماء الملفات التي تحتوي على ‘:’ كمحدِّدات مضيف.

عند النسخ بين مضيفين بعيدين، إذا تم استخدام صيغة URI، فلا يمكن تحديد المنفذ في الهدف إذا تم استخدام الخيار -R.

الخيارات هي كالتالي:

-3
يتم نقل النسخ بين مضيفين بعيدين عبر المضيف المحلي. هذه هي الوضعية الافتراضية، ولكن انظر أيضًا الخيار -R لنسخ البيانات مباشرة بين مضيفين بعيدين. لاحظ أنه عند استخدام بروتوكول SCP القديم (عبر العلم -O)، يختار هذا الخيار وضع الدفعة للمضيف الثاني حيث لا يمكن لـ scp طلب كلمات مرور أو عبارات مرور لكلا المضيفين.
-4
يجبر scp على استخدام عناوين IPv4 فقط.
-6
يجبر scp على استخدام عناوين IPv6 فقط.
-A
يسمح بتمرير ssh-agent(1) إلى النظام البعيد. الافتراضي هو عدم تمرير وكيل المصادقة.
-B
يختار وضع الدفعة (يمنع طلب كلمات المرور أو عبارات المرور).
-C
تمكين الضغط. يمرر العلم -C إلى ssh(1) لتمكين الضغط.
-c التشفير
يختار التشفير المستخدم لتشفير نقل البيانات. يتم تمرير هذا الخيار مباشرة إلى ssh(1).
-D مسار_خادم_sftp
الاتصال مباشرة ببرنامج خادم SFTP محلي بدلاً من خادم بعيد عبر ssh(1). قد يكون هذا الخيار مفيدًا في تصحيح أخطاء العميل والخادم.
-F ssh_config
يحدد ملف تكوين بديل لكل مستخدم لـ ssh. يتم تمرير هذا الخيار مباشرة إلى ssh(1).
-i ملف_الهوية
يختار الملف الذي تُقرأ منه هوية (مفتاح خاص) المصادقة بالمفتاح العام. يتم تمرير هذا الخيار مباشرة إلى ssh(1).
-J الوجهة
الاتصال بالمضيف الهدف عن طريق إجراء اتصال scp أولاً بالمضيف الانتقالي الموصوف بواسطة الوجهة ثم إنشاء إعادة توجيه TCP إلى الوجهة النهائية من هناك. يمكن تحديد قفزات متعددة مفصولة بفواصل. هذا اختصار لتحديد توجيه ProxyJump في التكوين. يتم تمرير هذا الخيار مباشرة إلى ssh(1).
-l الحد
يحد من عرض النطاق الترددي المستخدم، المحدد بالكيلوبت في الثانية.
-O
استخدام بروتوكول SCP القديم لنقل الملفات بدلاً من بروتوكول SFTP. قد يكون فرض استخدام بروتوكول SCP ضروريًا للخوادم التي لا تنفذ SFTP، للتوافق مع الإصدارات السابقة لأنماط أحرف البدل الخاصة بالملفات، ولتوسيع المسارات التي تبدأ بـ ‘~’ للخوادم القديمة التي تدعم SFTP.
-o خيار_ssh
يمكن استخدامه لتمرير خيارات إلى ssh بالصيغة المستخدمة في ssh_config(5). هذا مفيد لتحديد الخيارات التي لا يوجد لها علامة منفصلة في سطر أوامر scp. للحصول على التفاصيل الكاملة للخيارات المدرجة أدناه، والقيم الممكنة لها، راجع ssh_config(5).

OPTIONS

scp supports the following options:

-4
Forces scp to use IPv4 addresses only.
-6
Forces scp to use IPv6 addresses only.
-A
Allows forwarding of the authentication agent (such as ssh-agent) to the remote machine. The default is to not forward authentication agent connections.
-a
Sets the Access Control Lists (ACLs) to the source file. This option is not supported on all file systems.
-B
Batch mode. Causes scp to not prompt for passwords or passphrases. It will exit if it needs to prompt.
-b homedir
Specifies the starting directory on the remote host for file transfers. This is only supported by the legacy SCP protocol.
-C
Enable compression. This may reduce the amount of data whether it is transferred over the network. Note that it may increase CPU utilization. Compression is turned off by default.
-c cipher
Selects the cipher specification to use for encrypting the data transferred over the secure channel. See ssh_config(5) for more information on the format of the cipher specification.
-D
Disables the use of the SSH protocol version 1. The default is to try protocol version 2.
-d
Requests that scp copy recursively. This is a deprecated synonym for the -r option.
-E
Exits immediately if any SSH protocol error is encountered. This is useful for debugging and automated testing.
-e
Disables the use of TCP keepalive messages. These messages are used to detect dead connections.
-F config_file
Specifies the name of the configuration file to use for ssh. This option is only used when the legacy SCP protocol is selected by the -O flag.
-f
Requests that scp read from standard input and write to standard output. This option is only supported by the legacy SCP protocol.
-g
Allows scp to transfer files from multiple owners. The default is to transfer files from only the owner.
-h
Forces scp to run in host-based authentication mode. This is only supported by the legacy SCP protocol.
-i identity_file
Selects a file from which the identity (private key) for public key authentication is read. The default is to try to load identity information from the files named ~/.ssh/id_rsa, ~/.ssh/id_dsa, ~/.ssh/id_ecdsa, and ~/.ssh/id_ed25519.
-J jump_host
Connect to the target host by first connecting to the jump host and then forwarding the TCP connection. This is a shortcut for specifying a ProxyCommand. Multiple -J options may be provided, in which case the jump hosts are connected to in sequence. See also -W.
-j
Disables the use of the cipher specification. This is only supported by the legacy SCP protocol.
-K
Disable GSSAPI authentication. GSSAPI is an authentication mechanism that can be used with SSH. This option is useful if you are having problems with GSSAPI authentication.
-k realm
Specifies the Kerberos realm to use for authentication. This option is only supported by the legacy SCP protocol.
-l limit
Limits the used bandwidth, specified in Kbit/s. scp will try to not exceed this limit.
-m mac_spec
Specifies a list of Message Authentication Code (MAC) algorithms, separated by commas and ordered by preference. See ssh_config(5) for more information.
-N
Do not execute a remote command. This is useful for just forwarding ports.
-n
Do not execute a remote command. This is useful for just forwarding ports.
-O
Use the legacy SCP protocol. This is the default when connecting to older SSH servers, or when the server is not capable of handling the SFTP protocol. Since OpenSSH 9.0, the SFTP protocol is used by default.
-o ssh_option
Can be used to give options in the format used by ssh_config(5). This allows you to specify options for ssh which are not available as command-line flags. For example, -o "StrictHostKeyChecking=no".
-p
Preserves modification times, access times, and file mode bits from the source file.
-P port
Specifies the port to connect to on the remote host. Note that this option is written with a capital ‘P’, because -p is already reserved for preserving the times and mode bits of the file.
-q
Quiet mode: disables the progress meter as well as warning and diagnostic messages from ssh(1).
-R
Copies between two remote hosts are transferred through the local host by default. This option instead copies between two remote hosts by connecting to the origin host and executing scp there. This requires that scp running on the origin host can authenticate to the destination host without requiring a password.
-r
Recursively copy entire directories. Note that scp follows symbolic links encountered in the tree traversal.
-S program
Name of program to use for the encrypted connection. The program must understand ssh(1) options.
-T
Disable strict filename checking. By default when copying files from a remote host to a local directory scp checks that the received filenames match those requested on the command-line to prevent the remote end from sending unexpected or unwanted files. Because of differences in how various operating systems and shells interpret filename wildcards, these checks may cause wanted files to be rejected. This option disables these checks at the expense of fully trusting that the server will not send unexpected filenames.
-v
Verbose mode. Causes scp and ssh(1) to print debugging messages about their progress. This is helpful in debugging connection, authentication, and configuration problems.
-W hopcount
Specifies the maximum number of hops that scp will follow when resolving a remote host name. This option is useful for preventing infinite loops in DNS.
-X sftp_option
Specify an option that controls aspects of SFTP protocol behaviour. The valid options are:
nrequests=value
Controls how many concurrent SFTP read or write requests may be in progress at any point in time during a download or upload. By default 64 requests may be active concurrently.
buffer=value
Controls the maximum buffer size for a single SFTP read/write operation used during download or upload. By default a 32KB buffer is used.

EXIT STATUS

The scp utility exits 0 on success, and >0 if an error occurs.

HISTORY

scp is based on the rcp program in BSD source code from the Regents of the University of California.

Since OpenSSH 9.0, scp has used the SFTP protocol for transfers by default.

CAVEATS

The legacy SCP protocol (selected by the -O flag) requires execution of the remote user's shell to perform glob(3) pattern matching. This requires careful quoting of any characters that have special meaning to the remote shell, such as quote characters.
