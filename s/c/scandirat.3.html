الاسم

scandir, scandirat, alphasort, versionsort - فحص دليل للإدخالات المطابقة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <dirent.h>
int scandir(const char *restrict dirp,
            struct dirent ***restrict namelist,
            typeof(int (const struct dirent *)) *filter,
            typeof(int (const struct dirent **, const struct dirent **))
                *compar);
int alphasort(const struct dirent **a, const struct dirent **b);
int versionsort(const struct dirent **a, const struct dirent **b);
#include <fcntl.h>          /* تعريف الثوابت AT_* */
#include <dirent.h>
int scandirat(int dirfd, const char *restrict dirp,
            struct dirent ***restrict namelist,
            typeof(int (const struct dirent *)) *filter,
            typeof(int (const struct dirent **, const struct dirent **))
                *compar);

الوصف

تقوم الدالة scandir() بفحص الدليل dirp، وتستدعي filter() على كل إدخال في الدليل. الإدخالات التي تعيد الدالة filter() قيمة غير صفرية لها يتم تخزينها في سلاسل نصية مخصصة باستخدام malloc(3)، ويتم فرزها باستخدام qsort(3) مع دالة المقارنة compar()، وجمعها في المصفوفة namelist التي تم تخصيصها باستخدام malloc(3). إذا كانت filter NULL، يتم تحديد جميع الإدخالات.

يمكن استخدام الدالتين alphasort() و versionsort() كدالة مقارنة compar(). الأولى تقوم بفرز إدخالات الدليل باستخدام strcoll(3)، والثانية باستخدام strverscmp(3) على السلاسل النصية (*a)->d_name و (*b)->d_name.

scandirat()

تعمل الدالة scandirat() بنفس الطريقة تمامًا مثل scandir()، باستثناء الاختلافات الموضحة هنا.

إذا كان dirp نسبيًا، فسيتم تفسيره بالنسبة للدليل الذي يشير إليه واصف الملف dirfd (بدلاً من كونه نسبيًا إلى دليل العمل الحالي للعملية المستدعية، كما تفعل scandir() لمسار نسبي).

إذا كان dirp نسبيًا وكانت dirfd هي القيمة الخاصة AT_FDCWD، فسيتم تفسير dirp بالنسبة لدليل العمل الحالي للعملية المستدعية (مثل scandir()).

إذا كان dirp مطلقًا، فسيتم تجاهل dirfd.

انظر openat(2) لشرح الحاجة إلى scandirat().

قيمة الإرجاع

تعيد الدالة scandir() عدد إدخالات الدليل المختارة. عند حدوث خطأ، يتم إرجاع -1، مع تعيين errno للإشارة إلى الخطأ.

تعيد الدالتان alphasort() و versionsort() قيمة صحيحة أقل من أو تساوي أو أكبر من الصفر إذا تم اعتبار الوسيط الأول أقل من أو يساوي أو أكبر من الثاني على التوالي.

الأخطاء

EBADF
(scandirat()) dirp نسبي ولكن dirfd ليست AT_FDCWD ولا واصف ملف صالح.
ENOENT
المسار في dirp غير موجود.
ENOMEM
ذاكرة غير كافية لإكمال العملية.
ENOTDIR
المسار في dirp ليس دليلًا.
ENOTDIR
(scandirat()) dirp نسبي و dirfd هو واصف ملف يشير إلى ملف غير دليل.

ملاحظات

منذ glibc 2.1، تستدعي alphasort() strcoll(3)؛ قبل ذلك كانت تستخدم strcmp(3).

قبل glibc 2.10، كانت وسائط alphasort() و versionsort() من النوع const void *. عندما تم توحيد alphasort() في POSIX.1-2008، تم تحديد نوع الوسيط على أنه const struct dirent ** الآمن من حيث النوع، وغيرت glibc 2.10 تعريف alphasort() (و versionsort() غير القياسية) لتتوافق مع المعيار.

أمثلة

البرنامج أدناه يطبع قائمة بالملفات في الدليل الحالي بترتيب عكسي.

مصدر البرنامج

#define _DEFAULT_SOURCE
#include <dirent.h>
#include <stdio.h>
#include <stdlib.h>
int
main(void)
{
    struct dirent **namelist;
    int n;
    n = scandir(".", &namelist, NULL, alphasort);
    if (n == -1) {
        perror("scandir");
        exit(EXIT_FAILURE);
    }
    while (n--) {
        printf("%s\n", namelist[n]->d_name);
        free(namelist[n]);
    }
    free(namelist);
    exit(EXIT_SUCCESS);
}
