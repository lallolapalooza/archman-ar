الغرض:

!>
!> SCHKGG  يتحقق من إجراءات المسألة الذاتية المعممة غير المتناظرة.
!>                                T          T        T
!> SGGHRD تقوم بتحليل A و B إلى U H V  و U T V ، حيث  تعني
!> التبديل (transpose)، H هسبرج، T مثلثية، و U و V متعامدتان.
!>                                 T          T
!> SHGEQZ تقوم بتحليل H و T إلى  Q S Z  و Q P Z ، حيث P مثلثية عليا،
!> S في شكل Schur المعمم (متجه علوي كتلي، مع كتل 1x1 و 2x2 على القطر،
!> الكتل 2x2 المقابلة لأزواج مترافقة معقدة من القيم الذاتية المعممة)،
!> و Q و Z متعامدتان. كما تحسب القيم الذاتية المعممة (alpha(1),beta(1))،...،(alpha(n),beta(n))،
!> حيث alpha(j)=S(j,j) و beta(j)=P(j,j) -- وبالتالي،
!> w(j) = alpha(j)/beta(j) هو جذر المسألة الذاتية المعممة
!>
!>     det( A - w(j) B ) = 0
!>
!> و m(j) = beta(j)/alpha(j) هو جذر المسألة المكافئة جوهريًا
!>
!>     det( m(j) A - B ) = 0
!>
!> STGEVC تحسب مصفوفة L من المتجهات الذاتية اليسرى ومصفوفة R من المتجهات الذاتية اليمنى
!> لزوج المصفوفات ( S, P ). في الوصف أدناه،  l و r هي متجهات ذاتية يسرى
!> ويمينية مقابلة للقيم الذاتية المعممة (alpha,beta).
!>
!> عند استدعاء SCHKGG، يتم تحديد عدد من المصفوفات () و
!> عدد من المصفوفات (). لكل حجم () ولكل نوع مصفوفة، سيتم إنشاء مصفوفة واحدة
!> واستخدامها لاختبار الإجراءات الذاتية غير المتناظرة. لكل مصفوفة، سيتم إجراء 15
!> اختبارًا. الاثني عشر الأولى  يجب أن تكون صغيرة - O(1).
!> سيتم مقارنتها مع الحد الأدنى THRESH:
!>
!>                  T
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  T
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               T
!> (3)   | I - UU  | / ( n ulp )
!>
!>               T
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  T
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  T
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               T
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               T
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)   أقصى قيمة لجميع أزواج القيم الذاتية/المتجهات الذاتية اليسرى (beta/alpha,l) لـ
!>
!>    | l**H * (beta S - alpha P) | / ( ulp max( |beta S|, |alpha P| ) )
!>
!> (10)  أقصى قيمة لجميع أزواج القيم الذاتية/المتجهات الذاتية اليسرى (beta/alpha,l') لـ
!>                           T
!>   | l'**H * (beta H - alpha T) | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       حيث المتجهات الذاتية l' هي نتيجة تمرير Q إلى
!>       STGEVC والتحويل العكسي (HOWMNY='B').
!>
!> (11)  أقصى قيمة لجميع أزواج القيم الذاتية/المتجهات الذاتية اليمنى (beta/alpha,r) لـ
!>
!>       | (beta S - alpha T) r | / ( ulp max( |beta S|, |alpha T| ) )
!>
!> (12)  أقصى قيمة لجميع أزواج القيم الذاتية/المتجهات الذاتية اليمنى (beta/alpha,r') لـ
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       حيث المتجهات الذاتية r' هي نتيجة تمرير Z إلى
!>       STGEVC والتحويل العكسي (HOWMNY='B').
!>
!> آخر ثلاثة نسب اختبار ستكون عادة صغيرة، ولكن لا يوجد شرط رياضي لذلك.
!> لذلك، تتم مقارنتها مع THRESH فقط إذا كان TSTDIF هو .TRUE.
!>
!> (13)  | S(Q,Z المحسوبة) - S(Q,Z غير المحسوبة) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z المحسوبة) - P(Q,Z غير المحسوبة) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z المحسوبة) - alpha(Q,Z غير المحسوبة)|/|S| ,
!>            |beta(Q,Z المحسوبة) - beta(Q,Z غير المحسوبة)|/|P| ) / ulp
!>
!> بالإضافة إلى ذلك، يتم التحقق من تطبيع L و R، ومقارنتها
!> بالحد الأدنى THRSHN.
!>
!> مصفوفات الاختبار
!> ---- --------
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد  بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كان DOTYPE(j) هو .TRUE.، فسيتم إنشاء مصفوفة النوع .
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة هوية ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة صفرية ومصفوفة هوية)
!>
!> (4)  ( I, I )         (زوج من مصفوفات الهوية)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان المبدلة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I هي مصفوفة هوية بحجم k x k و J كتلة جوردان
!>                       بحجم (k+1)x(k+1)؛ k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هي قطرية diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!>                       بإدخالات قطرية).
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث  قريب من الفيضان و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*D, big*I )
!>
!> (12) ( small*D, small*I )
!>
!> (13) ( D1, D2 )        حيث D1 هي قطرية diag( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2 هي قطرية diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) U ( J , J ) V     حيث U و V مصفوفتان متعامدتان عشوائيتان.
!>
!> (17) U ( T1, T2 ) V    حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!>                        بإدخالات عشوائية بحجم O(1) فوق القطر
!>                        وإدخالات قطرية diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) U ( T1, T2 ) V    diag(T1) = ( 0, 0, 1,
