الوصف التفصيلي

الفئة الأساسية لجميع عناصر SCXML.

هذه فئة أساسية مشتركة لجميع فئات عناصر مستند SCXML. تدير سمات XML على المستوى العام، ولديها أدوات مساعدة للتحقق من احتواء المستند، وتوفر بعض خطافات البنية التحتية.

منذ

Coin 3.1

SbBool ScXMLElt::handleXMLAttributes (void ) [virtual]

يتم استدعاء هذه الدالة عندما يقوم قارئ الملف بتعيين جميع سمات XML على الكائن، ويريد من الكائن معالجتها والإبلاغ عما إذا كانت القيم مقبولة أو ما إذا كان يجب إنشاء خطأ في القراءة.

النتائج

TRUE إذا كانت السمات مقبولة، و FALSE عند حدوث خطأ.

لا تقوم هذه التنفيذ الأساسي بعمل أي شيء وتعيد TRUE ببساطة.

تم إعادة التنفيذ في ScXMLAbstractStateElt، ScXMLAnchorElt، ScXMLAssignElt، ScXMLDataElt، ScXMLDataModelElt، ScXMLElseIfElt، ScXMLEventElt، ScXMLHistoryElt، ScXMLIfElt، ScXMLInvokeElt، ScXMLLogElt، ScXMLParallelElt، ScXMLParamElt، ScXMLScxmlElt، ScXMLSendElt، ScXMLStateElt، ScXMLTransitionElt، و ScXMLValidateElt.

SbBool ScXMLElt::isContainedIn (const ScXMLElt * object) const

تُرجع TRUE إذا كان العنصر المحدد هو أب لهذا العنصر، أو أب لأبيه، وهكذا.

تُرجع FALSE إذا لم يتم العثور على العنصر المحدد في التسلسل الهرمي للعناصر.
