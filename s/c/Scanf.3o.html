مواصفات التحويل في سلاسل التنسيق

تتكون مواصفات التحويل من حرف %، متبوعًا بعلامة اختيارية، وعرض حقل اختياري، ثم حرف تحويل واحد أو اثنين.

أحرف التحويل ومعانيها هي:

- d : يقرأ عددًا صحيحًا عشريًا اختياري الإشارة (0-9 +).

- i : يقرأ عددًا صحيحًا اختياري الإشارة (تُفهم اصطلاحات الإدخال المعتادة للأعداد العشرية (0-9 +)، والأعداد الست عشرية (0x[0-9a-f]+ و 0X[0-9A-F]+)، والأعداد الثمانية (0o[0-7]+)، والأعداد الثنائية (0b[0-1]+)).

- u : يقرأ عددًا صحيحًا عشريًا غير مُشار إليه.

- x أو X : يقرأ عددًا صحيحًا ست عشريًا غير مُشار إليه ([0-9a-fA-F]+).

- o : يقرأ عددًا صحيحًا ثمانيًا غير مُشار إليه ([0-7]+).

- s : يقرأ وسيط سلسلة نصية يمتد قدر الإمكان، حتى يتحقق الشرط المحدد التالي:

-تم العثور على مسافة بيضاء (انظر Scanf.space)،

-تم مواجهة مؤشر مسح (انظر مسح Scanf.indication)،

-تم الوصول إلى نهاية الإدخال.

وبالتالي، ينجح هذا التحويل دائمًا: فهو يُرجع سلسلة فارغة إذا كان الشرط المحدد صحيحًا عند بدء المسح.

- S : يقرأ وسيط سلسلة نصية محددة (تتبع المحددات والأحرف الخاصة المُهملة الاصطلاحات المعجمية لـ OCaml).

- c : يقرأ حرفًا واحدًا. لاختبار الحرف الحالي في الإدخال دون قراءته، حدد عرض حقل صفري، أي استخدم المواصفات %0c. ارفع Invalid_argument، إذا كان عرض الحقل المحدد أكبر من 1.

- C : يقرأ حرفًا واحدًا محددًا (تتبع المحددات والأحرف الخاصة المُهملة الاصطلاحات المعجمية لـ OCaml).

- f، e، E، g، G : يقرأ عددًا عشريًا اختياري الإشارة بتنسيق عشري، على غرار dddd.ddd أو e/E+-dd.

- h، H : يقرأ عددًا عشريًا اختياري الإشارة بتنسيق ست عشري.

- F : يقرأ عددًا عشريًا وفقًا للاصطلاحات المعجمية لـ OCaml (وبالتالي يجب أن تكون النقطة العشرية إلزامية إذا لم يتم ذكر جزء الأُس).

- B : يقرأ وسيط منطقي (true أو false).

- b : يقرأ وسيط منطقي (للتوافق مع الإصدارات السابقة؛ لا تستخدم في البرامج الجديدة).

- ld، li، lu، lx، lX، lo : يقرأ وسيط int32 بالتنسيق المحدد بالحرف الثاني للأعداد الصحيحة العادية.

- nd، ni، nu، nx، nX، no : يقرأ وسيط nativeint بالتنسيق المحدد بالحرف الثاني للأعداد الصحيحة العادية.

- Ld، Li، Lu، Lx، LX، Lo : يقرأ وسيط int64 بالتنسيق المحدد بالحرف الثاني للأعداد الصحيحة العادية.

- [ range ] : يقرأ الأحرف التي تتطابق مع أحد الأحرف المذكورة في نطاق الأحرف range (أو التي لم تُذكر فيه، إذا بدأ النطاق بـ ^). يقرأ سلسلة نصية يمكن أن تكون فارغة، إذا لم يتطابق حرف الإدخال التالي مع النطاق. تتم الإشارة إلى مجموعة الأحرف من c1 إلى c2 (بما في ذلك) بـ c1-c2. وبالتالي، فإن %[0-9] يُرجع سلسلة نصية تمثل عددًا عشريًا أو سلسلة فارغة إذا لم يتم العثور على أي رقم عشري؛ وبالمثل، فإن %[0-9a-f] يُرجع سلسلة من الأرقام الست عشرية. إذا ظهر قوس إغلاق في نطاق، فيجب أن يظهر كأول حرف في النطاق (أو مباشرة بعد ^ في حالة نفي النطاق)؛ وبالتالي فإن []] يتطابق مع حرف ] و [^]] يتطابق مع أي حرف ليس ]. استخدم %% و %@ لتضمين حرف % أو @ في نطاق.

- r : قارئ مُعرّف من قبل المستخدم. يأخذ دالة الإدخال التالية المنسقة ri ويطبقها على مخزن المسح المؤقت ib لقراءة الوسيط التالي. يجب أن يكون دالة الإدخال ri بالتالي من النوع Scanning.in_channel -> 'a ويكون الوسيط المقروء من النوع 'a.

- { fmt %} : يقرأ وسيط سلسلة تنسيق. يجب أن يكون سلسلة التنسيق المقروءة من نفس نوع مواصفات سلسلة التنسيق fmt. على سبيل المثال، "%{ %i %}" يقرأ أي سلسلة تنسيق يمكنها قراءة قيمة من النوع int؛ وبالتالي، إذا كانت s هي السلسلة النصية "fmt:\"number is %u\""، فإن Scanf.sscanf s "fmt: %{%i%}" ينجح ويُرجع سلسلة التنسيق "number is %u".

- ( fmt %) : استبدال تنسيق فرعي للمسح. يقرأ سلسلة تنسيق rf في الإدخال، ثم يواصل المسح باستخدام rf بدلاً من المسح باستخدام fmt. يجب أن تكون سلسلة التنسيق rf من نفس نوع مواصفات سلسلة التنسيق fmt التي تستبدلها. على سبيل المثال، "%( %i %)" يقرأ أي سلسلة تنسيق يمكنها قراءة قيمة من النوع int. يُرجع التحويل سلسلة التنسيق المقروءة rf، ثم قيمة مقروءة باستخدام rf. وبالتالي، إذا كانت s هي السلسلة النصية "\"%4d\"1234.00"، فإن Scanf.sscanf s "%(%i%)" (fun fmt i -> fmt, i) يُقيم إلى ("%4d", 1234). هذا السلوك ليس مجرد استبدال تنسيق، حيث أن التحويل يُرجع سلسلة التنسيق المقروءة كوسيط إضافي. إذا كنت بحاجة إلى استبدال تنسيق خالص، استخدم العلامة الخاصة _ لتجاهل الوسيط الإضافي: التحويل %_( fmt %) يقرأ سلسلة تنسيق rf ثم يتصرف بنفس طريقة سلسلة التنسيق rf. وبالتالي، إذا كانت s هي السلسلة النصية "\"%4d\"1234.00"، فإن Scanf.sscanf s "%_(%i%)" يكافئ ببساطة Scanf.sscanf "1234.00" "%4d".

- l : يُرجع عدد الأسطر المقروءة حتى الآن.

- n : يُرجع عدد الأحرف المقروءة حتى الآن.

- N أو L : يُرجع عدد الرموز المقروءة حتى الآن.

- ! : يتطابق مع شرط نهاية الإدخال.

- % : يتطابق مع حرف % واحد في الإدخال.

- @ : يتطابق مع حرف @ واحد في الإدخال.

- , : لا يفعل شيئًا.

مباشرة بعد حرف % الذي يقدم تحويلًا، قد تكون هناك علامة خاصة _: يحدث التحويل التالي بشكل طبيعي، ولكن يتم تجاهل القيمة الناتجة. على سبيل المثال، إذا كانت f هي الدالة fun i -> i + 1، وكانت s هي السلسلة النصية "x = 1"، فإن Scanf.sscanf s "%_s = %i" f يُرجع 2.

يتكون عرض الحقل من حرف رقمي اختياري يشير إلى الحد الأقصى لعرض الرمز المراد قراءته. على سبيل المثال، يقرأ %6d عددًا صحيحًا، بحد أقصى 6 أرقام عشرية؛ يقرأ %4f عددًا عشريًا بما يصل إلى 4 أحرف؛ ويرجع %8[\000-\255] الأحرف الثمانية التالية (أو جميع الأحرف المتاحة، إذا كان هناك أقل من 8 أحرف متاحة في الإدخال).

ملاحظات:

-كما ذكرنا أعلاه، ينجح تحويل %s دائمًا، حتى لو لم يكن هناك شيء للقراءة في الإدخال: في هذه الحالة، يُرجع ببساطة "".

-بالإضافة إلى الأرقام ذات الصلة، قد تظهر أحرف '_' داخل الأرقام (هذا يذكرنا بالاصطلاحات المعجمية العادية لـ OCaml). إذا كنت ترغب في مسح أكثر صرامة، فاستخدم إمكانية تحويل النطاق بدلاً من تحويلات الأرقام.

-ميزة scanf ليست مخصصة للتحليل المعجمي والتحليل النحوي المكثف. إذا بدا أنها غير معبرة بما يكفي لاحتياجاتك، توجد عدة بدائل: التعبيرات العادية (وحدة Str)، محللات التدفق، المحللات التي تم إنشاؤها بواسطة ocamllex، المحللات التي تم إنشاؤها بواسطة ocamlyacc.

مؤشرات المسح في سلاسل التنسيق

تظهر مؤشرات المسح مباشرة بعد تحويلات السلاسل النصية %s و %[ range ] لتحديد نهاية الرمز. يتم تقديم مؤشر المسح بواسطة حرف @، متبوعًا بحرف عادي c. هذا يعني أن رمز السلسلة النصية يجب أن ينتهي مباشرة قبل المطابقة التالية لـ c (والتي يتم تخطيها). إذا لم يتم العثور على حرف c، فإن رمز السلسلة النصية يمتد قدر الإمكان. على سبيل المثال، "%s@\t" يقرأ سلسلة نصية حتى الحرف التالي (tab) أو حتى نهاية الإدخال. إذا ظهر حرف @ في أي مكان آخر في سلسلة التنسيق، فإنه يُعامل كحرف عادي.

ملاحظة:

-كما هو الحال في سلاسل التنسيق، يجب تهريب أحرف % و @ باستخدام %% و %@؛ تظل هذه القاعدة سارية داخل مواصفات النطاق ومؤشرات المسح. على سبيل المثال، سلسلة التنسيق "%s@%%" تقرأ سلسلة نصية حتى الحرف % التالي، وسلسلة التنسيق "%s@%@" تقرأ سلسلة نصية حتى الحرف @ التالي.

-تُدخل مؤشرات المسح اختلافات طفيفة في بناء جملة سلاسل تنسيق Scanf، مقارنة بتلك المستخدمة لوحدة Printf. ومع ذلك، فإن مؤشرات المسح مشابهة لتلك المستخدمة في وحدة Format؛ وبالتالي، عند إنتاج نص منسق ليتم مسحه بواسطة Scanf.bscanf، من الحكمة استخدام دوال الطباعة من وحدة Format (أو، إذا كنت بحاجة إلى استخدام دوال من Printf، قم بنفي أو التحقق بعناية من سلاسل التنسيق التي تحتوي على أحرف '@').

استثناءات أثناء المسح

قد تثير الماسحات الاستثناءات التالية عندما لا يمكن قراءة الإدخال وفقًا لسلسلة التنسيق:

-ارفع Scanf.Scan_failure إذا لم يتطابق الإدخال مع التنسيق.

-ارفع Failure إذا لم يكن التحويل إلى رقم ممكنًا.

-ارفع End_of_file إذا تم الوصول إلى نهاية الإدخال بينما هناك حاجة لمزيد من الأحرف لقراءة مواصفات التحويل الحالية.

-ارفع Invalid_argument إذا كانت سلسلة التنسيق غير صالحة.

ملاحظة:

-نتيجة لذلك، فإن مسح تحويل %s لا يثير استثناء End_of_file أبدًا: إذا تم الوصول إلى نهاية الإدخال، ينجح التحويل ويُرجع ببساطة الأحرف المقروءة حتى الآن، Scanf(3o) — صفحة دليل لينكس

Basic input functions

val bscanf : Scanning.in_channel -> ('a, 'b, 'c, 'd) scanner

Reads from the formatted input channel ic . The function bscanf is a member of the family of scanning functions, which are analogous to the printing functions of Printf . They use a format string to specify how to interpret the input.

A scanning function takes a format string as its first argument, followed by the arguments to be filled in. The format string is a sequence of characters that specifies how to interpret the input. Ordinary characters in the format string are matched literally against the input. Format specifiers (starting with % ) indicate arguments to be read from the input.

The scanning functions return a result value. This value is a function of the arguments that were not consumed by the format string. For example, Scanf.sscanf reads from a string, and returns a function that takes the arguments to be filled in. The format string itself can contain arguments, in which case they are read from the input and returned as the result of the scanning function.

The argument ic is a formatted input channel. It is a reference to a scanning function, initialized to read from the given channel.

The scanning function associated with ic must be of type ('a, 'b, 'c, 'd) scanner. The type variables represent:

  • 'a: The type of the result of the scanning function.
  • 'b: The type of the arguments to be filled in.
  • 'c: The type of the arguments to be supplied to the format string.
  • 'd: The type of the arguments to be supplied to the scanning function.

The type scanner is defined as:

type ('a, 'b, 'c, 'd) scanner = { format : 'a; }

The function bscanf raises Scan_failure if the input does not match the format string.

val bscanf_opt : Scanning.in_channel -> ('a, 'b, 'c, 'd) scanner_opt

Same as Scanf.bscanf , but returns None in case of scanning failure.

Since 5.0

val fscanf : in_channel -> ('a, 'b, 'c, 'd) scanner

Same as Scanf.bscanf , but reads from the standard input channel stdin .

val fscanf_opt : in_channel -> ('a, 'b, 'c, 'd) scanner_opt

Same as Scanf.fscanf , but returns None in case of scanning failure.

Since 5.0

val scanf : ('a, 'b, 'c, 'd) scanner

Same as Scanf.bscanf , but reads from the predefined formatted input channel Scanf.Scanning.stdin that is connected to stdin .

val scanf_opt : ('a, 'b, 'c, 'd) scanner_opt

Same as Scanf.scanf , but returns None in case of scanning failure.

Since 5.0

val kscanf : Scanning.in_channel -> (Scanning.in_channel -> exn -> 'd) -> ('a, 'b, 'c, 'd) scanner

Same as Scanf.bscanf , but takes an additional function argument ef that is called in case of error: if the scanning process or some conversion fails, the scanning function aborts and calls the error handling function ef with the formatted input channel and the exception that aborted the scanning process as arguments.

val ksscanf : string -> (Scanning.in_channel -> exn -> 'd) -> ('a, 'b, 'c, 'd) scanner

Same as Scanf.kscanf but reads from the given string.

val unescaped : string -> string

unescaped s return a copy of s with escape sequences (according to the lexical conventions of OCaml) replaced by their corresponding special characters. More precisely, Scanf.unescaped has the following property: for all string s , Scanf.unescaped (String.escaped s) = s .

Always return a copy of the argument, even if there is no escape sequence in the argument.

Since 4.00

Raises Scan_failure if s is not properly escaped (i.e. s has invalid escape sequences or special characters that are not properly escaped). For instance, Scanf.unescaped "\"" will fail.
