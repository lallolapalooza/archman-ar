SCCS(1P) دليل مبرمجي POSIX SCCS(1P)

PROLOG

صفحة الدليل هذه جزء من دليل مبرمجي POSIX. قد يختلف تطبيق Linux لهذه الواجهة (استشر صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

sccs — واجهة أمامية لنظام SCCS الفرعي (التطوير)

الملخص

sccs [-r] [-d path] [-p path] command [options...] [operands...]

الوصف

الأداة المساعدة sccs هي واجهة أمامية لبرامج SCCS. كما أنها تتضمن القدرة على التشغيل بمعرف مستخدم معين لمستخدم آخر لتوفير حماية إضافية.

ستقوم الأداة المساعدة sccs باستدعاء command المحدد مع options و operands المحددين. افتراضيًا، سيتم تعديل كل من operands عن طريق إضافة السلسلة "SCCS/s." إليها.

يمكن أن يكون command اسمًا لأحد أدوات SCCS المساعدة في هذا المجلد من POSIX.1‐2017 (admin، delta، get، prs، rmdel، sact، unget، val، أو what) أو أحد الأدوات المساعدة الزائفة المدرجة في قسم الوصف الموسع.

خيارات

ستلتزم الأداة المساعدة sccs بتعريفات المجلد الأساسي لـ POSIX.1‐2017، القسم 12.2، إرشادات بناء جملة الأداة المساعدة، باستثناء أن options operands هي في الواقع خيارات سيتم تمريرها إلى الأداة المساعدة المسماة بواسطة command. عند النظر إلى جزء الأمر:

command [options ... ] [operands ... ]

ستدعم جميع الأدوات المساعدة الزائفة المستخدمة كـ command إرشادات بناء جملة الأداة المساعدة. أي من أدوات SCCS الأخرى التي يمكن استدعاؤها بهذه الطريقة تدعم الإرشادات بالقدر المشار إليه في أقسام الخيارات الفردية الخاصة بها.

سيتم دعم الخيارات التالية قبل command operand:

-d path
مسار دليل سيتم استخدامه كدليل جذر لملفات SCCS. الافتراضي هو الدليل الحالي. ستكون الأولوية لـ -d على متغير PROJECTDIR. انظر -p.
-p path
مسار دليل توجد فيه ملفات SCCS. الافتراضي هو دليل SCCS.

يختلف الخيار -p عن الخيار -d في أن وسيطة خيار -d سيتم إلحاقها بمسار المسار بأكمله وسيتم إدراج وسيطة خيار -p قبل المكون النهائي للمسار. على سبيل المثال:

sccs -d /x -p y get a/b

يتم تحويله إلى:

get /x/a/y/s.b

يسمح هذا بإنشاء أسماء مستعارة مثل:

alias syssccs="sccs -d /usr/src"

والذي يستخدم على النحو التالي:

syssccs get cmd/who.c
-r
استدعاء command بمعرف المستخدم الحقيقي للعملية، وليس أي معرف مستخدم فعال تم تعيينه لـ sccs. لا يمكن تشغيل بعض الأوامر (admin، check، clean، diffs، info، rmdel، و tell) بمعرف مستخدم معين من قبل جميع المستخدمين، لأن ذلك سيسمح لأي شخص بتغيير الأذونات. يتم تشغيل هذه الأوامر دائمًا بصفتهم المستخدم الحقيقي.

عوامل التشغيل

سيتم دعم عوامل التشغيل التالية:

command
اسم أداة مساعدة SCCS أو اسم أحد الأدوات المساعدة الزائفة المدرجة في قسم الوصف الموسع.
options
خيار أو وسيطة خيار سيتم تمريرها إلى command.
operands
عامل تشغيل سيتم تمريره إلى command.

متغيرات البيئة

ستؤثر متغيرات البيئة التالية على تنفيذ sccs:

LANG
توفر قيمة افتراضية لمتغيرات العولمة غير المعينة أو الفارغة. (انظر مجلد التعريفات الأساسي لـ POSIX.1‐2017، القسم 8.2، متغيرات العولمة لمعرفة أولوية متغيرات العولمة المستخدمة لتحديد قيم فئات اللغة.)
LC_ALL
إذا تم تعيينها على قيمة سلسلة غير فارغة، فتجاوز قيم جميع متغيرات العولمة الأخرى.
LC_CTYPE
تحديد اللغة لتفسير تسلسلات البايتات لنصوص البيانات كأحرف (على سبيل المثال، أحرف أحادية البايت مقابل متعددة البايتات في عوامل التشغيل وملفات الإدخال).
LC_MESSAGES

تحديد اللغة التي يجب استخدامها للتأثير على تنسيق ومحتويات رسائل التشخيص المكتوبة إلى الخطأ القياسي.
NLSPATH
تحديد موقع كتالوجات الرسائل لمعالجة LC_MESSAGES.
PROJECTDIR

توفير قيمة افتراضية لـ -d path option. إذا بدأت قيمة PROJECTDIR بـ <slash>، فسيتم اعتبارها مسارًا مطلقًا؛ بخلاف ذلك، يتم التعامل مع قيمة PROJECTDIR كاسم مستخدم وسيتم فحص الدليل الأولي لهذا المستخدم بحثًا عن دليل فرعي src أو source. إذا تم العثور على مثل هذا الدليل، فسيتم استخدامه. بخلاف ذلك، سيتم استخدام القيمة كمسار نسبي.

قد توجد تأثيرات إضافية لمتغيرات البيئة في وصف الأداة المساعدة لـ command المحدد.

الوصف الموسع

سيتم دعم الأدوات المساعدة الزائفة التالية كـ command operands. جميع الخيارات المشار إليها في القائمة التالية هي قيم معطاة في options operands بعد command.

check
يعادل info، باستثناء أنه لن يتم طباعة أي شيء إذا لم يكن هناك شيء قيد التحرير، وسيتم إرجاع حالة خروج غير صفرية إذا كان أي شيء قيد التحرير. الهدف هو تضمين هذا في إدخال ``install'' في ملف make لضمان تضمين كل شيء في ملف SCCS قبل تثبيت إصدار.
clean
قم بإزالة كل شيء من الدليل الحالي الذي يمكن إعادة إنشائه من ملفات SCCS، ولكن لا تقم بإزالة أي ملفات قيد التحرير. إذا تم إعطاء الخيار -b، فسيتم تجاهل الفروع في تحديد ما إذا كان سيتم
