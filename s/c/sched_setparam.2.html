sched_setparam(2) دليل استدعاءات النظام sched_setparam(2)

الاسم

sched_setparam, sched_getparam - تعيين واسترجاع معلمات الجدولة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sched.h>
int sched_setparam(pid_t pid, const struct sched_param *param);
int sched_getparam(pid_t pid, struct sched_param *param);
struct sched_param {
    ...
    int sched_priority;
    ...
};

الوصف

تقوم الدالة sched_setparam() بتعيين معلمات الجدولة المرتبطة بسياسة الجدولة للخيط الذي تم تحديده بواسطة معرف الخيط pid. إذا كان pid يساوي صفرًا، يتم تعيين معلمات الخيط المتصل.

تفسير الوسيط param يعتمد على سياسة الجدولة للخيط المحدد بواسطة pid. انظر sched(7) لوصف سياسات الجدولة المدعومة في Linux.

تقوم الدالة sched_getparam() باسترجاع معلمات الجدولة للخيط المحدد بواسطة pid. إذا كان pid يساوي صفرًا، يتم استرجاع معلمات الخيط المتصل.

تتحقق الدالة sched_setparam() من صلاحية param لسياسة الجدولة للخيط. يجب أن تقع القيمة param->sched_priority ضمن النطاق المعطى بواسطة sched_get_priority_min(2) و sched_get_priority_max(2).

لمناقشة الامتيازات وحدود الموارد المتعلقة بأولوية وسياسة الجدولة، انظر sched(7).

أنظمة POSIX التي تتوفر فيها sched_setparam() و sched_getparam() تعرف _POSIX_PRIORITY_SCHEDULING في <unistd.h>.

قيمة الإرجاع

عند النجاح، تعيد الدالتان sched_setparam() و sched_getparam() القيمة 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
وسائط غير صالحة: param فارغة (NULL) أو pid سالبة.
EINVAL
(sched_setparam()) الوسيط param غير منطقي لسياسة الجدولة الحالية.
EPERM
(sched_setparam()) المتصل ليس لديه الامتيازات المناسبة (في Linux: لا يمتلك القدرة CAP_SYS_NICE).
ESRCH
لم يتم العثور على الخيط الذي معرفه pid.

المعايير

POSIX.1-2024.

التاريخ

POSIX.1-2001.
