وصف تفصيلي

الفئة الأساسية لأهداف الحدث للاتصال الحدثي بين الأنظمة

تدير هذه الفئة الاتصال بين أنظمة SCXML والأنظمة المخصصة للتواصل مع مثل هذه الأنظمة. كما تدير طابور الأحداث الخارجي لمثل هذه الأنظمة (قد يكون لدى الأنظمة أيضًا طوابير أحداث داخلية).

منذ

Coin 3.1

توثيق وظائف الأعضاء

virtual SoType ScXMLEventTarget::getTypeId (void ) const [pure virtual]

ترجع تعريف نوع الكائن المشتق من فئة ترث SoBase. يستخدم هذا للتحقق من النوع وقت التشغيل و "التحويل لأسفل".

انظر أيضًا

SoBase::getTypeId() const

يطبق ScXMLObject.

تم التنفيذ في ScXMLStateMachine، SoScXMLDollyTarget، SoScXMLFlightControlTarget، SoScXMLMiscTarget، SoScXMLMotionTarget، SoScXMLNavigationTarget، SoScXMLPanTarget، SoScXMLRotateTarget، SoScXMLSeekTarget، SoScXMLSpinTarget، SoScXMLStateMachine، و SoScXMLZoomTarget.

virtual const ScXMLEvent * ScXMLEventTarget::getCurrentEvent (void ) const [inline], [virtual]

ترجع هذه الطريقة الحدث الحالي أثناء معالجة الحدث، و NULL عند عدم معالجة الأحداث.

تتم معالجة الأحداث في حالات خاصة مع NULL كحدث حالي، كما هو الحال مثلاً أثناء تهيئة آلة الحالة.

void ScXMLEventTarget::queueEvent (const ScXMLEvent * event) [virtual]

يضيف حدث ScXMLEvent إلى الطابور. يتم نسخ الحدث، ويمكن حذفه بمجرد عودة الوظيفة.

void ScXMLEventTarget::queueEvent (const SbName & eventid) [virtual]

يضيف حدث ScXMLEvent إلى الطابور له eventid المحدد كاسم للحدث.

void ScXMLEventTarget::setCurrentEvent (const ScXMLEvent * event) [protected], [virtual]

يضبط مؤشرًا للحدث "الحالي" أثناء معالجة الحدث. هذه طريقة داخلية، ويجب التعامل مع تحديث الحدث الحالي تلقائيًا.

SbBool ScXMLEventTarget::processOneEvent (const ScXMLEvent * event) [protected], [virtual]

تقوم هذه الوظيفة بمعالجة حدث واحد. تنفيذ الفئة الأساسية لا يفعل شيئًا.

تم إعادة التنفيذ في ScXMLStateMachine، SoScXMLDollyTarget، SoScXMLFlightControlTarget، SoScXMLMiscTarget، SoScXMLMotionTarget، SoScXMLPanTarget، SoScXMLRotateTarget، SoScXMLSeekTarget، SoScXMLSpinTarget، و SoScXMLZoomTarget.
