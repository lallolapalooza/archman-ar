sctp_recvmsg(3)

الحزمة: lksctp-tools

التراخيص: GPL-2.0-or-later, LGPL-2.1-only

SCTP_RECVMSG(3) دليل مبرمج Linux SCTP_RECVMSG(3)

الاسم

sctp_recvmsg - استقبال رسالة من مقبس SCTP.

الملخص

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_recvmsg(int sd, void * msg, size_t len,
                 struct sockaddr * from, socklen_t * fromlen,
                 struct sctp_sndrcvinfo * sinfo, int * msg_flags);

الوصف

sctp_recvmsg هي دالة مكتبة غلاف يمكن استخدامها لاستقبال رسالة من مقبس مع استخدام الميزات المتقدمة لـ SCTP. sd هو واصف المقبس الذي يتم استقبال الرسالة المشار إليها بواسطة msg بطول len عليه.

إذا لم يكن from NULL، يتم ملء عنوان المصدر للرسالة. الوسيط fromlen هو معلمة قيمة-نتيجة، يتم تهيئتها إلى حجم المخزن المؤقت المرتبط بـ from، ويتم تعديلها عند الإرجاع للإشارة إلى الحجم الفعلي للعنوان المخزن.

sinfo هو مؤشر إلى بنية sctp_sndrcvinfo ليتم ملؤها عند استقبال الرسالة. msg_flags هو مؤشر إلى عدد صحيح يتم ملؤه بأي علامات للرسالة مثل MSG_NOTIFICATION أو MSG_EOR. يجب تهيئة قيمة المؤشر msg_flags إلى 0 لتجنب سلوك غير متوقع؛ يتم استخدام msg_flags أيضًا كوسيط flags مدخل لدالة recvmsg.

قيمة الإرجاع

عند النجاح، تعيد sctp_recvmsg عدد البايتات المستلمة أو -1 إذا حدث خطأ.
