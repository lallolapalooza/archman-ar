sctp_recvv(3)

الحزمة: lksctp-tools

التراخيص: GPL-2.0-or-later, LGPL-2.1-only

SCTP_RECVV(3) Linux SCTP_RECVV(3)

الاسم

sctp_recvv - استقبال رسالة من مقبس SCTP بطريقة قابلة للتوسيع.

الملخص

#include <sys/types.h>
#include <sys/socket.h>
#include <netinet/sctp.h>

int sctp_recvv(int sd, const struct iovec * iov, int iovlen,
               struct sockaddr * from, socklen_t * fromlen, void * info,
               socklen_t * infolen, unsigned int * infotype, int * flags);

الوصف

توفر sctp_recvv طريقة قابلة للتوسيع لطبقة SCTP لتمرير سمات SCTP المختلفة المرتبطة برسالة مستلمة إلى التطبيق. هناك نوعان من السمات التي يمكن إرجاعها بواسطة هذا الاستدعاء: سمة الرسالة المستلمة وسمة الرسالة التالية في مخزن الاستقبال المؤقت. يقوم المتصل بتمكين خيارات المقبس SCTP_RECVRCVINFO و SCTP_RECVNXTINFO، على التوالي، لاستلام هذه السمات. يتم إرجاع سمات الرسالة المستلمة في struct sctp_rcvinfo، ويتم إرجاع سمات الرسالة التالية في struct sctp_nxtinfo. إذا تم تمكين كلا الخيارين، فسيتم إرجاع كلا السمتين باستخدام الهيكل التالي.


struct sctp_recvv_rn {
struct sctp_rcvinfo recvv_rcvinfo;
struct sctp_nxtinfo recvv_nxtinfo;
};

sd هو واصف المقبس. iov هو مخزن التجميع، ويتم إرجاع رسالة مستخدم واحدة فقط في هذا المخزن. iovlen هو عدد العناصر في iov. from هو مؤشر إلى مخزن سيتم ملؤه بعنوان مرسل الرسالة المستلمة. fromlen هو معلمة إدخال/إخراج تصف طول المصدر. info هو مؤشر إلى المخزن لاحتواء سمات الرسالة المستلمة، ويتم تحديد نوع هيكل info بواسطة المعلمة info_type. infolen هو معلمة إدخال/إخراج تصف حجم مخزن info. عند الإرجاع، يتم تعيين infotype إلى نوع مخزن info، والقيم المعرفة حاليًا هي كما يلي:

SCTP_RECVV_NOINFO
إذا لم يتم تمكين خيارات SCTP_RECVRCVINFO أو SCTP_RECVNXTINFO، فلن يتم إرجاع أي سمة. إذا تم تمكين خيار SCTP_RECVNXTINFO فقط ولم تكن هناك رسالة تالية في المخزن، فلن يتم إرجاع أي سمة. في هذه الحالات، سيتم تعيين *info_type إلى SCTP_RECVV_NOINFO.
SCTP_RECVV_RCVINFO
نوع info هو struct sctp_rcvinfo، والسمة تتعلق بالرسالة المستلمة.
SCTP_RECVV_NXTINFO
نوع info هو struct sctp_nxtinfo، والسمة تتعلق بالرسالة التالية في مخزن الاستقبال المؤقت. هذه هي الحالة عند تمكين خيار SCTP_RECVNXTINFO فقط وهناك رسالة تالية في المخزن.
SCTP_RECVV_RN
نوع info هو struct sctp_recvv_rn. حقل recvv_rcvinfo هو سمة الرسالة المستلمة، وحقل recvv_nxtinfo هو سمة الرسالة التالية في المخزن. هذه هي الحالة عند تمكين خيارات SCTP_RECVRCVINFO و SCTP_RECVNXTINFO وهناك رسالة تالية في مخزن الاستقبال المؤقت.

flags هو مؤشر إلى عدد صحيح ليتم ملؤه بأي علامات رسالة (مثل MSG_NOTIFICATION).

قيمة الإرجاع

عند النجاح، تُرجع sctp_recvv عدد البايتات المستلمة أو -1 في حالة حدوث خطأ.
