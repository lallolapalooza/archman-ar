توثيق الوظيفة/الإجراء الفرعي

real(wp) function scnrm2 (integer n, complex(wp), dimension(*) x, integer incx)

SCNRM2

الغرض:

!>
!> SCNRM2 تُرجع المعيار الإقليدي للمتجه عبر اسم الوظيفة، بحيث
!>
!>    SCNRM2 := sqrt( x**H*x )
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>         عدد العناصر في المتجه (المتجهات) المدخلة
!>

X

!>          X هو مصفوفة مركبة (COMPLEX)، ذات بُعد (N)
!>         متجه مركب يحتوي على N عنصر
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)، المسافة بين عناصر X في الذاكرة
!>          إذا كان INCX > 0، فإن X(1+(i-1)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX < 0، فإن X(1-(n-i)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX = 0، فإن x ليس متجهًا، لذا لا داعي لاستدعاء
!>          هذا الإجراء الفرعي. إذا استدعيته على أي حال، فسيتم احتساب x(1)
!>          في معيار المتجه N مرة.
!>
