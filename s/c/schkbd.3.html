الغرض:

!>
!> SCHKBD يتحقق من إجراءات تحليل القيم المفردة (SVD).
!>
!> SGEBRD يقلل مصفوفة A الحقيقية العامة m × n إلى شكل صفري علوي أو سفلي B بتحويل متعامد: Q' * A * P = B
!> (أو A = Q * B * P'). المصفوفة B تكون صفرية علوية إذا كان m ≥ n
!> وصفرية سفلية إذا كان m < n.
!>
!> SORGBR يولد المصفوفات المتعامدة Q و P' من SGEBRD.
!> لاحظ أن Q و P ليستا بالضرورة مربعتين.
!>
!> SBDSQR يحسب تحليل القيم المفردة للمصفوفة الصفرية B على هيئة B = U S V'.
!> يتم استدعاؤه ثلاث مرات لحساب:
!>    1) B = U S1 V', حيث S1 هي مصفوفة قطرية بالقيم المفردة والأعمدة للمصفوفتين U و V هي المتجهات المفردة اليسرى
!>        واليمنى، على التوالي، لـ B.
!>    2) نفس الشيء كما في 1)، ولكن القيم المفردة مخزنة في S2 والمتجهات المفردة غير محسوبة.
!>    3) A = (UQ) S (P'V')، وهو تحليل SVD للمصفوفة الأصلية A.
!> بالإضافة إلى ذلك، SBDSQR لديه خيار لتطبيق المصفوفة المتعامدة اليسرى
!> U على مصفوفة X، وهو مفيد في تطبيقات المربعات الصغرى.
!>
!> SBDSDC يحسب تحليل القيم المفردة للمصفوفة الصفرية B على هيئة B = U S V' باستخدام التقسيم والقهر. يتم استدعاؤه مرتين
!> لحساب:
!>    1) B = U S1 V', حيث S1 هي مصفوفة قطرية بالقيم المفردة والأعمدة للمصفوفتين U و V هي المتجهات المفردة اليسرى
!>        واليمنى، على التوالي، لـ B.
!>    2) نفس الشيء كما في 1)، ولكن القيم المفردة مخزنة في S2 والمتجهات المفردة غير محسوبة.
!>
!> SBDSVDX يحسب تحليل القيم المفردة للمصفوفة الصفرية B على هيئة B = U S V' باستخدام التنصيف والتكرار العكسي. يتم استدعاؤه ست مرات
!> لحساب:
!>     1) B = U S1 V', RANGE='A'، حيث S1 هي مصفوفة قطرية بالقيم المفردة والأعمدة للمصفوفتين U و V هي المتجهات المفردة اليسرى
!>         واليمنى، على التوالي، لـ B.
!>     2) نفس الشيء كما في 1)، ولكن القيم المفردة مخزنة في S2 والمتجهات المفردة غير محسوبة.
!>     3) B = U S1 V', RANGE='I'، حيث S1 هي مصفوفة قطرية بالقيم المفردة والأعمدة للمصفوفتين U و V هي المتجهات المفردة اليسرى
!>         واليمنى، على التوالي، لـ B.
!>     4) نفس الشيء كما في 3)، ولكن القيم المفردة مخزنة في S2 والمتجهات المفردة غير محسوبة.
!>     5) B = U S1 V', RANGE='V'، حيث S1 هي مصفوفة قطرية بالقيم المفردة والأعمدة للمصفوفتين U و V هي المتجهات المفردة اليسرى
!>         واليمنى، على التوالي، لـ B.
!>     6) نفس الشيء كما في 5)، ولكن القيم المفردة مخزنة في S2 والمتجهات المفردة غير محسوبة.
!>
!> لكل زوج من أبعاد المصفوفة (M,N) ولكل نوع مصفوفة محدد، يتم توليد مصفوفة A بحجم M × N ومصفوفة X بحجم M × NRHS.
!> أبعاد المشكلة هي كما يلي:
!>    A:          M × N
!>    Q:          M × min(M,N) (ولكن M × M إذا كان NRHS > 0)
!>    P:          min(M,N) × N
!>    B:          min(M,N) × min(M,N)
!>    U, V:       min(M,N) × min(M,N)
!>    S1, S2      قطرية، ترتيب min(M,N)
!>    X:          M × NRHS
!>
!> لكل مصفوفة تم إنشاؤها، يتم إجراء 14 اختبارًا:
!>
!> اختبار SGEBRD و SORGBR
!>
!> (1)   | A - Q B PT | / ( |A| max(M,N) ulp )، PT = P'
!>
!> (2)   | I - Q' Q | / ( M ulp )
!>
!> (3)   | I - PT PT' | / ( N ulp )
!>
!> اختبار SBDSQR على المصفوفة الصفرية B
!>
!> (4)   | B - U S1 VT | / ( |B| min(M,N) ulp )، VT = V'
!>
!> (5)   | Y - U Z | / ( |Y| max(min(M,N),k) ulp )، حيث Y = Q' X
!>                                                  و Z = U' Y.
!> (6)   | I - U' U | / ( min(M,N) ulp )
!>
!> (7)   | I - VT VT' | / ( min(M,N) ulp )
!>
!> (8)   تحتوي S1 على min(M,N) قيم غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!> (9)   | S1 - S2 | / ( |S1| ulp )، حيث تم حساب S2 بدون
!>                                   حساب U و V.
!>
!> (10)  0 إذا كانت القيم المفردة الحقيقية لـ B ضمن THRESH
!>       لتلك الموجودة في S1. 2*THRESH إذا لم تكن كذلك. (يتم اختباره باستخدام
!>       SSVDCH)
!>
!> اختبار SBDSQR على المصفوفة A
!>
!> (11)  | A - (QU) S (VT PT) | / ( |A| max(M,N) ulp )
!>
!> (12)  | X - (QU) Z | / ( |X| max(M,k) ulp )
!>
!> (13)  | I - (QU)'(QU) | / ( M ulp )
!>
!> (14)  | I - (VT PT) (PT'VT') | / ( N ulp )
!>
!> اختبار SBDSDC على المصفوفة الصفرية B
!>
!> (15)  | B - U S1 VT | / ( |B| min(M,N) ulp )، VT = V'
!>
!> (16)  | I - U' U | / ( min(M,N) ulp )
!>
!> (17)  | I - VT VT' | / ( min(M,N) ulp )
!>
!> (18)  تحتوي S1 على min(M,N) قيم غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!> (19)  | S1 - S2 | / ( |S1| ulp )، حيث تم حساب S2 بدون
!>                                   حساب U و V.
!>  اختبار SBDSVDX على المصفوفة الصفرية B
!>
!>  (20)  | B - U S1 VT | / ( |B| min(M,N) ulp )، VT = V'
!>
!>  (21)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (22)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (23)  تحتوي S1 على min(M,N) قيم غير سالبة بترتيب تنازلي.
!>        (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!>  (24)  | S1 - S2 | / ( |S1| ulp )، حيث تم حساب S2 بدون
!>                                    حساب U و V.
!>
!>  (25)  | S1 - U' B VT' | / ( |S| n ulp )    SBDSVDX('V', 'I')
!>
!>  (26)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (27)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (28)  تحتوي S1 على min(M,N) قيم غير سالبة بترتيب تنازلي.
!>        (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!>  (29)  | S1 - S2 | / ( |S1| ulp )، حيث تم حساب S2 بدون
!>                                    حساب U و V.
!>
!>  (30)  | S1 - U' B VT' | / ( |S1| n ulp )   SBDSVDX('V', 'V')
!>
!>  (31)  | I - U' U | / ( min(M,N) ulp )
!>
!>  (32)  | I - VT VT' | / ( min(M,N) ulp )
!>
!>  (33)  تحتوي S1 على min(M,N) قيم غير سالبة بترتيب تنازلي.
!>        (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!>  (34)  | S1 - S2 | / ( |S1| ulp )، حيث تم حساب S2 بدون
!>                                    حساب U و V.
!>
!> أنواع المصفوفات الممكنة هي:
!>
!> (1)  مصفوفة الصفر.
!> (2)  مصفوفة الهوية.
!>
!> (3)  مصفوفة قطرية بإدخالات متباعدة بالتساوي
!>      1, ..., ULP  وإشارات عشوائية.
!>      (ULP = (أول رقم أكبر من 1) - 1)
!> (4)  مصفوفة قطرية

SYNOPSIS

This man page is for the SCHKBD subroutine in the LAPACK library.

SUBROUTINE SCHKBD( NSIZES, MVAL, NVAL, NTYPES, DOTYPE, NRHS, ISEED,
&                  THRESH, A, LDA, BD, BE, S1, S2, X, LDX, Y, Z, Q, LDQ,
&                  PT, LDPT, U, VT, WORK, LWORK, IWORK, NOUT, INFO )

Function/Subroutine Documentation

This subroutine checks the nonsymmetric tridiagonal reduction routines:

  • SGEBRD: reduction of a general matrix to bidiagonal form.
  • SORGBR: generation of a matrix having bidiagonal Singular Value Decomposition (SVD).
  • SBDSQR: bidiagonal SVD.

The arguments are as follows:

Matrix Types

The following are the legal values of the logarithm of the condition number:

Type 1:
Matrix with uniformly distributed random entries in (-1, 1).
Type 2:
Matrix with normally distributed random entries.
Type 3:
A diagonal matrix with entries 1, ..., ULP and random signs.
Type 4:
A diagonal matrix with geometrically spaced entries 1, ..., ULP and random signs.
Type 5:
A diagonal matrix with entries 1, ULP, ..., ULP and random signs.
Type 6:
Same as (3), but multiplied by SQRT( overflow threshold )
Type 7:
Same as (3), but multiplied by SQRT( underflow threshold )
Type 8:
A matrix of the form U D V, where U and V are orthogonal and D has evenly spaced entries 1, ..., ULP with random signs on the diagonal.
Type 9:
A matrix of the form U D V, where U and V are orthogonal and D has geometrically spaced entries 1, ..., ULP with random signs on the diagonal.
Type 10:
A matrix of the form U D V, where U and V are orthogonal and D has entries 1, ULP,..., ULP with random signs on the diagonal.
Type 11:
Same as (8), but multiplied by SQRT( overflow threshold )
Type 12:
Same as (8), but multiplied by SQRT( underflow threshold )
Type 13:
Rectangular matrix with random entries chosen from (-1,1).
Type 14:
Same as (13), but multiplied by SQRT( overflow threshold )
Type 15:
Same as (13), but multiplied by SQRT( underflow threshold )

Special case:

Type 16:
A bidiagonal matrix with random entries chosen from a logarithmic distribution on [ulp^2,ulp^(-2)] (I.e., each entry is e^x, where x is chosen uniformly on [ 2 log(ulp), -2 log(ulp) ] .) For *this* type:
  • (a) SGEBRD is not called to reduce it to bidiagonal form.
  • (b) the bidiagonal is min(M,N) x min(M,N); if M<N, the matrix will be lower bidiagonal, otherwise upper.
  • (c) only tests 5--8 and 14 are performed.

A subset of the full set of matrix types may be selected through the logical array DOTYPE.

Parameters

NSIZES

          NSIZES is INTEGER
          The number of values of M and N contained in the vectors
          MVAL and NVAL. The matrix sizes are used in pairs (M,N).

MVAL

          MVAL is INTEGER array, dimension (NM)
          The values of the matrix row dimension M.

NVAL

          NVAL is INTEGER array, dimension (NM)
          The values of the matrix column dimension N.

NTYPES

          NTYPES is INTEGER
          The number of elements in DOTYPE. If it is zero, SCHKBD
          does nothing. It must be at least zero. If it is MAXTYP+1
          and NSIZES is 1, then an additional type, MAXTYP+1 is
          defined, which is to use whatever matrices are in A and B.
          This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
          DOTYPE(MAXTYP+1) is .TRUE. .

DOTYPE

          DOTYPE is LOGICAL array, dimension (NTYPES)
          If DOTYPE(j) is .TRUE., then for each size (m,n), a matrix
          of type j will be generated. If NTYPES is smaller than the
          maximum number of types defined (PARAMETER MAXTYP), then
          types NTYPES+1 through MAXTYP will not be generated. If
          NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1) through
          DOTYPE(NTYPES) will be ignored.

NRHS

          NRHS is INTEGER
          The number of columns in the matrices X, Y,
          and Z, used in testing SBDSQR. If NRHS = 0, then the
          operations on the right-hand side will not be tested.
          NRHS must be at least 0.

ISEED

          ISEED is INTEGER array, dimension (4)
          On entry ISEED specifies the seed of the random number
          generator. The array elements should be between 0 and 4095;
          if not they will be reduced mod 4096. Also, ISEED(4) must
          be odd. The values of ISEED are changed on exit, and can be
          used in the next call to SCHKBD to continue the same random
          number sequence.

THRESH

          THRESH is REAL
          The threshold value for the test ratios. A result is
          included in the output file if RESULT >= THRESH. To have
          every test ratio printed, use THRESH = 0. Note that the
          expected value of the test ratios is O(1), so THRESH should
          be a reasonably small multiple of 1, e.g., 10 or 100.

A

          A is REAL array, dimension (LDA,NMAX)
          where NMAX is the maximum value of N in NVAL.

LDA

          LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1,MMAX),
          where MMAX is the maximum value of M in MVAL.

BD

          BD is REAL array, dimension
                      (max(min(MVAL(j),NVAL(j))))

BE

          BE is REAL array, dimension
                      (max(min(MVAL(j),NVAL(j))))

S1

          S1 is REAL array, dimension
                      (max(min(MVAL(j),NVAL(j))))

S2

          S2 is REAL array, dimension
                      (max(min(MVAL(j),NVAL(j))))

X

          X is REAL array, dimension (LDX,NRHS)

LDX

          LDX is INTEGER
          The leading dimension of the arrays X, Y, and Z.
          LDX >= max(1,MMAX)

Y

          Y is REAL array, dimension (LDX,NRHS)

Z

          Z is REAL array, dimension (LDX,NRHS)

Q

          Q is REAL array, dimension (LDQ,MMAX)

LDQ

          LDQ is INTEGER
          The leading dimension of the array Q. LDQ >= max(1,MMAX).

PT

          PT is REAL array, dimension (LDPT,NMAX)

LDPT

          LDPT is INTEGER
          The leading dimension of the arrays PT, U, and V.
          LDPT >= max(1, max(min(MVAL(j),NVAL(j)))).

U

          U is REAL array, dimension
                      (LDPT,max(min(MVAL(j),NVAL(j))))

VT

          VT is REAL array, dimension
                      (LDPT,max(min(MVAL(j),NVAL(j))))

WORK

          WORK is REAL array, dimension (LWORK)

LWORK

          LWORK is INTEGER
          The number of entries in WORK. This must be at least
          3(M+N) and M(M + max(M,N,k) + 1) + N*min(M,N) for all
          pairs (M,N)=(MM(j),NN(j))

IWORK

          IWORK is INTEGER array, dimension at least 8*min(M,N)

NOUT

          NOUT is INTEGER
          The FORTRAN unit number for printing out error messages
          (e.g., if a routine returns IINFO not equal to 0.)

INFO

          INFO is INTEGER
          If 0, then everything ran OK.
           -1: NSIZES < 0
           -2: Some MM(j) < 0
           -3: Some NN(j) < 0
           -4: NTYPES < 0
           -6: NRHS  < 0
           -8: THRESH < 0
          -11: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
          -17: LDB < 1 or LDB < MMAX.
          -21: LDQ < 1 or LDQ < MMAX.
          -23: LDPT< 1 or LDPT< MNMAX.
          -27: LWORK too small.
          If SLATMR, SLATMS, SGEBRD, SORGBR, or SBDSQR,
              returns an error code, the
              absolute value of it is returned.

Some Local Variables and Parameters:

---- ----- --------- --- ----------

ZERO, ONE Real 0 and 1.

MAXTYP The number of types defined.

NTEST The number of tests performed, or which can be performed so far, for the current matrix.

MMAX Largest value in NN.

NMAX Largest value in NN.

MNMIN min(MM(j), NN(j)) (the dimension of the bidiagonal matrix.)

MNMAX The maximum value of MNMIN for j=1,...,NSIZES.

NFAIL The number of tests which have exceeded THRESH

COND, IMODE Values to be passed to the matrix generators.

ANORM Norm of A; passed to matrix generators.

OVFL, UNFL Overflow and underflow thresholds.

RTOVFL, RTUNFL Square roots of the previous 2 values.

ULP, ULPINV Finest relative precision and its inverse.

The following four arrays decode JTYPE:

KTYPE(j) The general type (1-10) for type .

KMODE(j) The MODE value to be passed to the matrix generator for type .

KMAGN(j) The order of magnitude ( O(1), O(overflow^(1/2) ), O(underflow^(1/2) )
