الغرض:

!>
!>    SCASUM يأخذ مجموع القيمة المطلقة لـ (|Re(.)| + |Im(.)|) لمتجه مركب ويعيد
!>    نتيجة بدقة أحادية.
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>         عدد العناصر في المتجه (المتجهات) المدخلة
!>

CX

!>          CX هو مصفوفة مركبة (COMPLEX)، البعد ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)
!>         تباعد التخزين بين عناصر SX
!>
