NAME

sblat2 — Level 2 Basic Linear Algebra Subprograms (BLAS) for real single-precision general matrices.

SYNOPSIS

Contains subroutines for Level 2 BLAS operations on real single-precision general matrices.

Key subroutines include:

  • smake: Constructs a matrix.

  • smvch: Performs matrix-vector multiplication and related operations.

  • sregr1: Computes a rank-1 update of a matrix.

  • xerbla: Error handler for BLAS routines.
