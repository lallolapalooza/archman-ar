الوصف المفصل

يمثل عنصر انتقال SCXML.

يجب أن يتم استدعاء الانتقال إما عن طريق حدث (event) أو عن طريق استيفاء تعبير شرطي (conditional expression). يمكن أن يكون هناك اختياريًا علامة ScXMLContentElt التي تحتوي على كود ليتم تنفيذه عند المرور عبر هذا الانتقال. يمكن أن يكون هناك اختياريًا علامة ScXMLTargetElt التي تعرّف الحالة المستهدفة للانتقال.

SbBool ScXMLTransitionElt::handleXMLAttributes (void ) [virtual]

يتم استدعاء هذه الطريقة عندما يقوم قارئ الملف بتعيين جميع سمات XML على الكائن، ويريد من الكائن التعامل معها والإبلاغ عما إذا كانت القيم صحيحة أم يجب إنتاج خطأ في القراءة.

القيم المعادة

TRUE إذا كانت السمات صحيحة، و FALSE عند حدوث خطأ.

تنفيذ الفئة الأساسية هذا لا يفعل شيئًا ويعيد TRUE فقط.

const ScXMLElt * ScXMLTransitionElt::search (const char * attrname, const char * attrvalue) const [virtual]

تبحث هذه الطريقة في هيكل SCXML عن عنصر بقيمة السمة المعطاة للسمة المعطاة.

تعيد NULL إذا لم يتم العثور على شيء.

SbBool ScXMLTransitionElt::isConditionLess (void ) const

تعيد ما إذا كان هذا انتقال SCXML بدون شرط أم لا.

يجب دائمًا اتخاذ الانتقال بدون شرط.

SbBool ScXMLTransitionElt::isTargetLess (void ) const

تعيد ما إذا كان هذا انتقالًا بدون تعيين هدف أم لا.

عند اتخاذ انتقال بدون هدف، لا تتغير حالة آلة الحالة. يختلف هذا عن تعيين الهدف إلى حالته الخاصة، مما سيؤدي إلى مغادرة آلة الحالة للحالة وإعادة الدخول إليها مرة أخرى.

SbBool ScXMLTransitionElt::isSelfReferencing (void ) const

تعيد ما إذا كان هذا الانتقال يشير إلى حاويته أم لا.

إذا كانت TRUE، فهذا يعني أنه يجب أن ينتهي بك الأمر في نفس الحالة التي بدأت بها عند القيام بهذا الانتقال. لاحظ مع ذلك أنه على عكس الانتقال بدون هدف، يجب أن يخرج هذا الانتقال بالفعل من الحالة ثم يعيد الدخول إليها مرة أخرى. سيتم استدعاء المحتوى القابل للتنفيذ بعد الخروج من الحالة، قبل إعادة الدخول.

SbBool ScXMLTransitionElt::isEventMatch (const ScXMLEvent * eventobj) const [virtual]

تعيد هذه الدالة TRUE إذا كان الانتقال يطابق كائن eventobj المعطى و FALSE بخلاف ذلك.

SbBool ScXMLTransitionElt::evaluateCondition (ScXMLStateMachine * statemachine) [virtual]

تستخدم هذه الدالة مقيّم آلة الحالة لتقييم تعبير الشرط الخاص بها، وتعيد TRUE أو FALSE بناءً على التقييم.

عند حدوث خطأ في التعبير، يتم إصدار أحداث خطأ إلى آلة حالة SCXML.

إذا كان الانتقال بدون شرط، فستعيد هذه الدالة TRUE.

void ScXMLTransitionElt::execute (ScXMLStateMachine * statemachine) const [virtual]

يستدعي الاستدعاء على جميع العناصر الفرعية ScXMLInvoke.
