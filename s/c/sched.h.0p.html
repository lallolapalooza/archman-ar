sched.h(0P) دليل مبرمج POSIX sched.h(0P)

الملحق

هذه الصفحة اليدوية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة في Linux.

الاسم

sched.h — جدولة التنفيذ

الملخص

#include <sched.h>

الوصف

سيقوم رأس <sched.h> بتعريف النوع pid_t كما هو موضح في <sys/types.h>.

سيقوم رأس <sched.h> بتعريف النوع time_t كما هو موضح في <sys/types.h>.

سيقوم رأس <sched.h> بتعريف هيكل timespec كما هو موضح في <time.h>.

سيقوم رأس <sched.h> بتعريف هيكل sched_param، والذي سيشمل معلمات الجدولة المطلوبة لتنفيذ كل سياسة جدولة مدعومة. يجب أن يشمل هذا الهيكل على الأقل العضو التالي:

int       sched_priority        أولوية جدولة تنفيذ العملية أو الخيط.

سيشمل هيكل sched_param المحدد في <sched.h> الأعضاء التالية بالإضافة إلى تلك المحددة أعلاه:

int             sched_ss_low_priority أولوية جدولة منخفضة للخادم المتقطع.
struct timespec sched_ss_repl_period  فترة تجديد الخادم المتقطع.
struct timespec sched_ss_init_budget  ميزانية أولية للخادم المتقطع.
int             sched_ss_max_repl     أقصى عدد من عمليات التجديد المعلقة للخادم المتقطع.

يتم التحكم في كل عملية أو خيط بواسطة سياسة جدولة وأولوية مرتبطة بها. مرتبطة بكل سياسة نطاق أولوية. يحدد تعريف كل سياسة نطاق الأولوية الأدنى لتلك السياسة. قد تتداخل نطاقات الأولوية لكل سياسة مع نطاقات أولوية السياسات الأخرى.

تم تعريف أربع سياسات جدولة؛ قد يتم تعريف سياسات أخرى بواسطة التطبيق. يتم الإشارة إلى السياسات القياسية الأربع بقيم الثوابت الرمزية التالية:

SCHED_FIFO
سياسة جدولة "الوارد أولاً، يخرج أولاً" (FIFO).
SCHED_RR
سياسة جدولة "الدور المنظم" (Round Robin).
SCHED_SPORADIC
سياسة جدولة الخادم المتقطع.
SCHED_OTHER
سياسة جدولة أخرى.

قيم هذه الثوابت مميزة.

سيتم تعريف ما يلي كدوال وقد يتم تعريفه أيضًا كمكروهات. سيتم توفير نماذج الدوال.

int    sched_get_priority_max(int);
int    sched_get_priority_min(int);
int    sched_getparam(pid_t, struct sched_param *);
int    sched_getscheduler(pid_t);
int    sched_rr_get_interval(pid_t, struct timespec *);
int    sched_setparam(pid_t, const struct sched_param *);
int    sched_setscheduler(pid_t, int, const struct sched_param *);
int    sched_yield(void);

قد يؤدي تضمين رأس <sched.h> إلى إظهار جميع الرموز من رأس <time.h>.

الأقسام التالية إعلامية.
