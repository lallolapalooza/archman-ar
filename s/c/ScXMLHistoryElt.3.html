وصف تفصيلي

ينفذ عنصر <history> الخاص بـ SCXML.

العنصر <history> غير مدعوم، باستثناء كحالة وهمية.

Coin 3.0

SbBool ScXMLHistoryElt::handleXMLAttributes (void ) [virtual]

يتم استدعاء هذه الوظيفة عندما يقوم قارئ الملف بتعيين جميع سمات XML للكائن، ويريد من الكائن التعامل معها والإبلاغ عما إذا كانت القيم صحيحة أم أنه يجب إصدار خطأ في القراءة.

يعيد

TRUE إذا كانت السمات صحيحة، و FALSE عند حدوث خطأ.

هذا التنفيذ الأساسي يعيد TRUE.
