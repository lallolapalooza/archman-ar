Symbol(3perl) دليل مبرمجي Perl Symbol(3perl)

الاسم

Symbol - معالجة رموز Perl وأسمائها

الملخص

use Symbol;
$sym = gensym;
open($sym, '<', "filename");
$_ = <$sym>;
# إلخ.
ungensym $sym;      # لا تأثير
# استبدال مقبض *FOO{IO} ولكن ليس $FOO، %FOO، إلخ.
*FOO = geniosym;
print qualify("x"), "\n";              # "main::x"
print qualify("x", "FOO"), "\n";       # "FOO::x"
print qualify("BAR::x"), "\n";         # "BAR::x"
print qualify("BAR::x", "FOO"), "\n";  # "BAR::x"
print qualify("STDOUT", "FOO"), "\n";  # "main::STDOUT" (عام)
print qualify(\*x), "\n";              # يعيد \*x
print qualify(\*x, "FOO"), "\n";       # يعيد \*x
use strict refs;
print { qualify_to_ref $fh } "foo!\n";
$ref = qualify_to_ref $name, $pkg;
use Symbol qw(delete_package);
delete_package('Foo::Bar');
print "deleted\n" unless exists $Foo::{'Bar::'};

الوصف

"Symbol::gensym" ينشئ رمزًا مجهولًا (glob) ويعيد مرجعًا له. يمكن استخدام مرجع الرمز هذا كمقبض ملف أو دليل.

للتوافق مع الإصدارات السابقة مع التطبيقات القديمة التي لم تدعم الرموز المجهولة، يتم توفير "Symbol::ungensym" أيضًا. لكنها لا تفعل شيئًا.

"Symbol::geniosym" ينشئ مقبض IO مجهول. يمكن تعيين هذا في رمز موجود دون التأثير على الأجزاء غير المتعلقة بـ IO للرمز.

"Symbol::qualify" تحول أسماء الرموز غير المؤهلة إلى أسماء متغيرات مؤهلة (على سبيل المثال، "myvar" -> "MyPackage::myvar"). إذا تم إعطاؤها معاملًا ثانيًا، فإن "qualify" تستخدمه كحزمة افتراضية؛ وإلا، فإنها تستخدم حزمة المتصل. بغض النظر، فإن أسماء المتغيرات العامة (على سبيل المثال، "STDOUT"، "ENV"، "SIG") يتم تأهيلها دائمًا بـ "main::".

ينطبق التأهيل فقط على أسماء الرموز (السلاسل النصية). تترك المراجع دون تغيير على افتراض أنها مراجع رموز، وهي مؤهلة بطبيعتها.

"Symbol::qualify_to_ref" يشبه تمامًا "Symbol::qualify" باستثناء أنها تعيد مرجع رمز (glob ref) بدلاً من اسم رمز، لذلك يمكنك استخدام النتيجة حتى لو كان "use strict 'refs'" مفعلًا.

"Symbol::delete_package" تمسح مساحة اسم الحزمة بأكملها. لاحظ أن هذه الروتين ليست مصدرة افتراضيًا - قد ترغب في استيرادها بشكل صريح.

الأخطاء

"Symbol::delete_package" قوية جدًا. فهي تلغي تعريف كل رمز موجود في الحزمة المحددة. نظرًا لأن perl، لأسباب تتعلق بالأداء، لا يقوم بعمل بحث في جدول الرموز في كل مرة يتم فيها استدعاء دالة أو الوصول إلى متغير عام، فإن بعض التعليمات البرمجية التي تم تحميلها بالفعل وتستخدم رموزًا في الحزمة "Foo" قد تتوقف عن العمل بعد حذف "Foo"، حتى إذا قمت بإعادة تحميل الوحدة "Foo" بعد ذلك.
