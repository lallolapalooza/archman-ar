syncthing-event-api(7)

الحزمة: syncthing

التراخيص: MPL-2.0

SYNCTHING-EVENT-API(7) Syncthing SYNCTHING-EVENT-API(7)

الاسم

syncthing-event-api - واجهة برمجة تطبيقات الأحداث

الوصف

يوفر Syncthing واجهة بسيطة للاستقصاء طويل المدى لعرض الأحداث من الأداة الأساسية نحو واجهة المستخدم الرسومية. لاستقبال الأحداث، راجع GET /rest/events.

هيكل الحدث

يتم تمثيل كل حدث بكائن مشابه لما يلي:

{
    "id": 2,
    "globalID": 3,
    "type": "DeviceConnected",
    "time": "2014-07-13T21:04:33.687836696+02:00",
    "data": {
        "addr": "172.16.32.25:22000",
        "id": "NFGKEKE-7Z6RTH7-I3PRZXS-DEJF3UJ-FRWJBFO-VBBTDND-4SGNGVZ-QUQHJAG"
    }
}

المفاتيح الرئيسية id و globalID و time و type و data موجودة دائمًا، على الرغم من أن data قد تكون null.

id
معرف فريد لهذا الحدث في واجهة برمجة تطبيقات الأحداث. يزداد دائمًا بمقدار 1: الحدث الأول الذي تم إنشاؤه له المعرف 1، والحدث التالي له المعرف 2، وهكذا. إذا زاد هذا بأكثر من 1، فهذا يعني أنه تم تخطي حدث واحد أو أكثر بواسطة واجهة برمجة تطبيقات الأحداث.
globalID
معرف عالمي لهذا الحدث، عبر واجهة برمجة تطبيقات الأحداث وسجل التدقيق وأي مصادر أخرى. قد يزداد بأكثر من 1، ولكنه سيكون دائمًا أكبر من أو يساوي المعرف.
time
الوقت الذي تم فيه إنشاء الحدث.
type
يشير إلى نوع الحدث (أي سبب الحدث) وهو أحد أنواع الأحداث أدناه.
data
كائن يحتوي على معلومات إضافية اختيارية؛ يتم تحديد البنية الدقيقة حسب نوع الحدث.

أنواع الأحداث

ClusterConfigReceived

تمت الإضافة في الإصدار 1.20.0.

يتم إصدار الحدث ClusterConfigReceived بعد معالجة رسالة بروتوكول كهذه تم استلامها من جهاز بعيد. يستخدم بشكل أساسي للأغراض الداخلية.

{
    "id": 84,
    "globalID": 84,
    "type": "ClusterConfigReceived",
    "time": "2022-04-27T14:14:27.043576583+09:00",
    "data": {
        "device": "I6KAH76-66SLLLB-5PFXSOA-UFJCDZC-YAOMLEK-CP2GB32-BV5RQST-3PSROAU"
    }
}

ConfigSaved

يتم إصداره بعد حفظ التكوين بواسطة المستخدم أو بواسطة Syncthing نفسه.

{
    "id": 50,
    "globalID": 50,
    "type": "ConfigSaved",
    "time": "2014-12-13T00:09:13.5166486Z",
    "data": {
        "version": 7,
        "folders": [{"..."}],
        "devices": [{"..."}],
        "gui": {"..."},
        "ldap": {"..."},
        "options": {"..."},
        "remoteIgnoredDevices": [{"..."}],
        "defaults": {"..."}
    }
}

DeviceConnected

يتم إنشاؤه في كل مرة يتم فيها إنشاء اتصال بجهاز.

{
    "id": 2,
    "globalID": 2,
    "type": "DeviceConnected",
    "time": "2014-07-13T21:04:33.687836696+02:00",
    "data": {
        "addr": "172.16.32.25:22000",
        "id": "NFGKEKE-7Z6RTH7-I3PRZXS-DEJF3UJ-FRWJBFO-VBBTDND-4SGNGVZ-QUQHJAG",
        "deviceName": "Laptop",
        "clientName": "syncthing",
        "clientVersion": "v0.13.4",
        "type": "TCP (Client)"
    }
}

DeviceDisconnected

يتم إنشاؤه في كل مرة يتم فيها إنهاء الاتصال بجهاز.

{
    "id": 48,
    "globalID": 48,
    "type": "DeviceDisconnected",
    "time": "2014-07-13T21:18:52.859929215+02:00",
    "data": {
        "error": "unexpected EOF",
        "id": "NFGKEKE-7Z6RTH7-I3PRZXS-DEJF3UJ-FRWJBFO-VBBTDND-4SGNGVZ-QUQHJAG"
    }
}

ملاحظة:

يحتوي مفتاح الخطأ على سبب الانقطاع، والذي قد لا يكون بالضرورة خطأ بحد ذاته. على وجه التحديد، يشير كل من "EOF" و "unexpected EOF" إلى إنهاء اتصال TCP، إما بسبب إعادة تشغيل الجهاز الآخر أو عدم اتصاله بالإنترنت أو بسبب تغيير في الشبكة.

DeviceDiscovered

يتم إصداره عند اكتشاف جهاز جديد باستخدام الاكتشاف المحلي.

{
    "id": 13,
    "globalID": 13,
    "type": "DeviceDiscovered",
    "time": "2014-07-17T13:28:05.043465207+02:00",
    "data": {
        "addrs": [
            "172.16.32.25:22000"
        ],
        "device": "NFGKEKE-7Z6RTH7-I3PRZXS-DEJF3UJ-FRWJBFO-VBBTDND-4SGNGVZ-QUQHJAG"
    }
}

يتم إصداره عند إيقاف جهاز مؤقتًا.

{

    "type": "DevicePaused",

تم إهماله منذ الإصدار v1.13.0: لا يزال هذا الحدث يصدر للتوافق، ولكنه مهمل. استخدم الحدث PendingDevicesChanged البديل بدلاً منه.

يتم إصداره عند وجود اتصال من جهاز لا نتلقى تكوينًا للتحدث معه.

{
    "id": 24,
    "globalID": 24,
    "type": "DeviceRejected",
    "time": "2014-08-19T10:43:00.562821045+02:00",
    "data": {

        "device": "EJHMPAQ-OGCVORE-ISB4IS3-SYYVJXF-TKJGLTU-66DIQPF-GJ5D2GX-GQ3OWQK"
