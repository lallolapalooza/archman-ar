Sys::Virt::Error(3pm) وثائق Perl المساهمة من المستخدم Sys::Virt::Error(3pm)

الاسم

Sys::Virt::Error - كائن خطأ لواجهات برمجة التطبيقات libvirt

الوصف

يقوم الصنف "Sys::Virt::Error" بتوفير ترميز لأخطاء libvirt. يمكن رمي مثيلات هذا الكائن بواسطة أي من واجهات برمجة التطبيقات Sys::Virt تقريبًا.

الطرق

$err->stringify
تحويل الكائن إلى تنسيق سلسلة مناسب للطباعة على وحدة التحكم لإعلام المستخدم بالخطأ.
my $level = $err->level
إرجاع مستوى الخطأ الخام الذي يمثله هذا الخطأ. أحد ثوابت مستوى الخطأ
my $code = $err->code
إرجاع رمز الخطأ الخام الذي يمثله هذا الخطأ. أحد ثوابت رمز الخطأ
my $from = $err->domain
إرجاع نطاق الخطأ الذي يثير هذا الخطأ. أحد ثوابت نطاق الخطأ
my $msg = $err->message
إرجاع رسالة مفيدة تصف حالة الخطأ.

NAME

Sys::Virt::Error – error codes for Sys::Virt

DESCRIPTION

This module defines constants used to represent errors that can occur when interacting with the libvirt API.

METHODS

The module exports no public methods. All functionality is accessed via constants.

CONSTANTS
