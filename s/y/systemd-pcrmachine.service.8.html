NAME

systemd-pcrmachine.service, systemd-pcrmachine - TPM2 PCR machine service

SYNOPSIS


systemd-pcrmachine.service

DESCRIPTION

This service is responsible for managing the TPM2 Platform Configuration Register (PCR) measurements for the host itself. It hooks into the system startup process and records various boot events into PCRs 0-7 (or a subset thereof) via the TPM2_PCR_Extend operation.

The primary goal is to provide a secure and verifiable way to measure the integrity of the system's boot process. By measuring the initialization code, firmware, kernel, and other critical system components, it allows for later verification that the system booted in a known and trusted state.

The service creates and manages a log file (typically located at /var/lib/systemd/tpm2/pcrvalues.log) which contains the measurements and associated event data in JSON-SEQ format. This log is used to store the state of the PCRs at different stages of the boot process, as well as the data that was extended into them.

The measurements are typically performed by systemd-pcrphase.service units for different boot phases (e.g., firmware, kernel, initrd) and then aggregated by systemd-pcrmachine.service.

It is crucial that access to the TPM2 device and the PCR log file is properly protected. The service acquires an exclusive lock (e.g., LOCK_EX) on the log file (see LOCK_EX in systemd.prctl(2)) on the log file is acquired while the measurement is made and the file is updated. Thus, applications that intend to acquire a consistent quote from the TPM with the associated snapshot of the event log should acquire a LOCK_SH lock while doing so.

Added in version 252.
