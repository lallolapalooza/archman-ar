systemd-cryptenroll(1)

الحزمة: systemd

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later, MIT-0

CREDENTIALS

The following command-line options may be used to pass secrets to the tool via environment variables (see also systemd.exec(5) LoadCredential=, SetCredential= (see systemd.exec(5) for details). The following credentials are used when passed in:

cryptenroll.passphrase, cryptenroll.new-passphrase

May contain the passphrase to unlock the volume with/to newly enroll.

Added in version 256.

cryptenroll.tpm2-pin, cryptenroll.new-tpm2-pin

May contain the TPM2 PIN to unlock the volume with/to newly enroll.

Added in version 256.

cryptenroll.fido2-pin

If a FIDO2 token is enrolled this may contain the PIN of the token.

Added in version 256.

cryptenroll.pkcs11-pin

If a PKCS#11 token is enrolled this may contain the PIN of the token.

Added in version 256.

EXIT STATUS

On success, 0 is returned, a non-zero failure code otherwise.

EXAMPLES

crypttab(5) and systemd-measure(1) contain various examples employing systemd-cryptenroll.

SEE ALSO

systemd(1), systemd-cryptsetup@.service(8), crypttab(5), cryptsetup(8), systemd-measure(1)

بيانات الاعتماد

قد تُستخدم خيارات سطر الأوامر التالية لتمرير الأسرار إلى الأداة عبر متغيرات البيئة (انظر أيضًا systemd.exec(5) LoadCredential=، SetCredential= (انظر systemd.exec(5) للحصول على التفاصيل). تُستخدم بيانات الاعتماد التالية عند تمريرها:

cryptenroll.passphrase، cryptenroll.new-passphrase

قد تحتوي على عبارة المرور لفتح القفل الخاص بالجهاز/لتسجيل عبارة مرور جديدة.

تمت الإضافة في الإصدار 256.

cryptenroll.tpm2-pin، cryptenroll.new-tpm2-pin

قد تحتوي على رقم التعريف الشخصي لـ TPM2 لفتح القفل الخاص بالجهاز/لتسجيل رقم تعريف شخصي جديد.

تمت الإضافة في الإصدار 256.

cryptenroll.fido2-pin

إذا تم تسجيل جهاز FIDO2، فقد يحتوي هذا على رقم التعريف الشخصي للجهاز.

تمت الإضافة في الإصدار 256.

cryptenroll.pkcs11-pin

إذا تم تسجيل جهاز PKCS#11، فقد يحتوي هذا على رقم التعريف الشخصي للجهاز.

تمت الإضافة في الإصدار 256.
