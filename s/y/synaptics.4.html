SYNAPTICS(4) دليل برامج تشغيل الأجهزة SYNAPTICS(4)

الاسم

synaptics - برنامج تشغيل إدخال لوحة اللمس

الملخص

Section "InputDevice"
  Identifier "اسم الجهاز"
  Driver "synaptics"
  Option "Device"   "مسار الجهاز"
  Option "Path"     "مسار"
  ...
EndSection

الوصف

synaptics هو برنامج تشغيل إدخال Xorg للوحات اللمس. على الرغم من أنه يمكن التعامل مع لوحات اللمس بواسطة برامج تشغيل evdev أو الماوس العادية، إلا أن هذا البرنامج التشغيل يتيح الوصول إلى ميزات أكثر تقدمًا للوحة اللمس. بعض الفوائد ستكون:

  • الحركة مع تسارع وسرعة قابلة للتعديل وغير خطية.
  • أحداث الأزرار من خلال اللمس القصير للوحة اللمس.
  • أحداث النقر المزدوج من خلال النقر المزدوج القصير للوحة اللمس.
  • السحب من خلال اللمس القصير وإبقاء الإصبع مضغوطًا على لوحة اللمس (إيماءة النقر والسحب).
  • أحداث الزر الأوسط والأيمن في الزاوية العلوية والسفلية للوحة اللمس.
  • التمرير العمودي (أحداث الأزرار الأربعة والخمسة) من خلال تحريك الإصبع على الجانب الأيمن من لوحة اللمس.
  • الزر العلوي/السفلي يرسل أحداث الزر 4/5.
  • التمرير الأفقي (أحداث الأزرار ستة وسبعة) من خلال تحريك الإصبع على الجانب السفلي من لوحة اللمس.
  • الأزرار المتعددة ترسل أحداث الزر 4/5 للتمرير العمودي وأحداث الزر 6/7 للتمرير الأفقي.
  • اكتشاف الإصبع قابل للتعديل.
  • نقرات متعددة الأصابع: إصبعين لزر الماوس الأيمن وثلاثة أصابع لأحداث زر الماوس الأوسط. (يتطلب دعم الأجهزة. لا تنفذ جميع الطرز هذه الميزة.)
  • سرعة حركة تعتمد على الضغط.

لاحظ أنه اعتمادًا على البرنامج الثابت للوحة اللمس، قد تكون بعض هذه الميزات متاحة حتى بدون استخدام برنامج تشغيل synaptics. لاحظ أيضًا أن بعض الوظائف غير متاحة على جميع طرازات لوحات اللمس، لأنها تتطلب دعمًا من أجهزة/برامج لوحة اللمس. (نقرات متعددة الأصابع على سبيل المثال.)

اسم "synaptics" تاريخي ولا يزال برنامج التشغيل يوفر شفرة تحليل بروتوكول synaptics. ومع ذلك، في Linux، يتم التعامل مع تفاصيل الأجهزة بواسطة النواة وسيعمل برنامج التشغيل هذا لأي لوحة لمس لديها برنامج تشغيل نواة يعمل. إذا تم التعرف على جهازك كـ "PS/2 Mouse" أو ما شابه، فإن برنامج تشغيل النواة لا يدعم جهازك وسيقتصر برنامج التشغيل هذا على توفير وظائف محدودة.

خيارات التكوين

يرجى الرجوع إلى xorg.conf(5) للحصول على تفاصيل التكوين العامة وللخيارات التي يمكن استخدامها مع جميع برامج تشغيل الإدخال. يغطي هذا القسم فقط تفاصيل التكوين الخاصة ببرنامج التشغيل هذا.

خيارات برنامج التشغيل التالية مدعومة:

Option "Device" "سلسلة"
يحدد هذا الخيار ملف الجهاز في دليل "/dev" الخاص بك والذي سيتم استخدامه للوصول إلى الجهاز الفعلي. عادةً يجب عليك استخدام شيء مثل "/dev/input/eventX"، حيث X هو عدد صحيح.
Option "Protocol" "سلسلة"
يحدد برنامج تشغيل النواة الذي سيتم استخدامه بواسطة برنامج التشغيل هذا. هذه هي قائمة برامج التشغيل المدعومة وسيناريوهات الاستخدام الافتراضية لها.
auto-dev تلقائي، افتراضي (موصى به)
event أحداث نواة Linux 2.6
psaux وصول مباشر للجهاز (Linux 2.4)
psm برنامج تشغيل FreeBSD psm
Option "LeftEdge" "عدد صحيح"
إحداثيات X للحافة اليسرى. الخاصية: "Synaptics Edges"
Option "RightEdge" "عدد صحيح"
إحداثيات X للحافة اليمنى. الخاصية: "Synaptics Edges"
Option "TopEdge" "عدد صحيح"
إحداثيات Y للحافة العلوية. الخاصية: "Synaptics Edges"
Option "BottomEdge" "عدد صحيح"
إحداثيات Y للحافة السفلية. الخاصية: "Synaptics Edges"
Option "FingerLow" "عدد صحيح"
عندما ينخفض ضغط الإصبع عن هذه القيمة، يعتبره برنامج التشغيل بمثابة تحرير. الخاصية: "Synaptics Finger"
Option "FingerHigh" "عدد صحيح"
عندما يزيد ضغط الإصبع عن هذه القيمة، يعتبره برنامج التشغيل بمثابة لمس. الخاصية: "Synaptics Finger"
Option "MaxTapTime" "عدد صحيح"
الحد الأقصى للوقت (بالمللي ثانية) لاكتشاف النقر. الخاصية: "Synaptics Tap Durations"
Option "MaxTapMove" "عدد صحيح"
الحد الأقصى لحركة الإصبع لاكتشاف النقر. الخاصية: "Synaptics Tap Move"
Option "MaxDoubleTapTime" "عدد صحيح"
الحد الأقصى للوقت (بالمللي ثانية) لاكتشاف النقر المزدوج. الخاصية: "Synaptics Tap Durations"
Option "ClickTime" "عدد صحيح"
مدة نقرة الماوس التي تم إنشاؤها عن طريق النقر. الخاصية: "Synaptics Tap Durations"
Option "ClickPad" "قيمة منطقية"
ما إذا كان الجهاز عبارة عن لوحة نقر. انظر دعم ClickPad لمزيد من التفاصيل. الخاصية: "Synaptics ClickPad"
Option "VertEdgeScroll" "قيمة منطقية"
تمكين التمرير العمودي عند السحب على طول الحافة اليمنى. الخاصية: "Synaptics Edge Scrolling"
Option "HorizEdgeScroll" "قيمة منطقية"
تمكين التمرير الأفقي عند السحب على طول الحافة السفلية. الخاصية: "Synaptics Edge Scrolling"
Option "CornerCoasting" "قيمة منطقية"
تمكين التمرير على الحافة للاستمرار أثناء بقاء الإصبع في زاوية الحافة. الخاصية: "Synaptics Edge Scrolling"
Option "VertTwoFingerScroll" "قيمة منطقية"
تمكين التمرير العمودي عند السحب بإصبعين في أي مكان على لوحة اللمس. الخاصية: "Synaptics Two-Finger Scrolling"
Option "HorizTwoFingerScroll" "قيمة منطقية"
تمكين التمرير الأفقي عند السحب بإصبعين في أي مكان على لوحة اللمس. الخاصية: "Synaptics Two-Finger Scrolling"
Option "VertScrollDelta" "عدد صحيح"
مسافة حركة الإصبع لحدث تمرير. الخاصية: "Synaptics Scrolling Distance"
Option "HorizScrollDelta" "عدد صحيح"
مسافة حركة الإصبع لحدث تمرير. الخاصية: "Synaptics Scrolling Distance"
Option "MinSpeed" "عائم"
عامل السرعة الأدنى. الخاصية: "Synaptics Move Speed"
Option "MaxSpeed" "عائم"
عامل السرعة الأقصى. الخاصية: "Synaptics Move Speed"
Option "AccelFactor" "عائم"
عامل التسارع لحركات المؤشر العادية. الخاصية: "Synaptics Move Speed"

OPTIONS

Options are specified in the device section of your Xorg configuration file.

Option "Device" string
Specifies the input device filename. Defaults to /dev/input/inputX, where X is the lowest possible number.
Option "Protocol" string
Specifies the protocol to use. Possible values are "auto", "ps/2", "synaptics", "lm", "glide", "etch". Defaults to "auto".
Option "LeftEdge" integer
Defines the left edge of the touchpad.
Option "RightEdge" integer
Defines the right edge of the touchpad.
Option "TopEdge" integer
Defines the top edge of the touchpad.
Option "BottomEdge" integer
Defines the bottom edge of the touchpad.
Option "Touch" integer
Defines the threshold value for touch detection.
Option "Coasting" string
Enable/disable coasting. Defaults to on. Possible values are "on", "off".
Option "CoastingSpeed" integer
Defines the speed threshold for coasting. Defaults to 20.
Option "CornerCoasting" string
Enable/disable corner coasting. Defaults to on. Possible values are "on", "off".
Option "PressureCoasting" string
Enable/disable pressure coasting. Defaults to off. Possible values are "on", "off".
Option "MaxTapTime" integer
Maximum time allowed between initial contact and releasing the finger to register a tap. Defaults to 200ms.
Option "MaxDoubleTapTime" integer
Maximum time allowed between two consecutive taps to register a double tap. Defaults to 180ms.
Option "MaxTapMove" integer
Maximum distance the finger can move between initial contact and releasing the finger to register a tap. Defaults to 1/2 of the touchpad width.
Option "TapButton1" integer
Defines the button mapping for a tap with one finger. Defaults to button 1 (left).
Option "TapButton2" integer
Defines the button mapping for a tap with two fingers. Defaults to button 3 (middle).
Option "TapButton3" integer
Defines the button mapping for a tap with three fingers. Defaults to button 2 (right).
Option "TapAction" string
Enable/disable tap actions. Defaults to on. Possible values are "on", "off".
Option "ClickTime" integer
Delay between button press and release events generated by a tap. Defaults to 10ms.
Option "MinSpeed" float
Minimum speed for pointer acceleration. Defaults to 0.0.
Option "MaxSpeed" float
Maximum speed for pointer acceleration. Defaults to 0.0.
Option "AccelFactor" float
Acceleration factor for pointer motion. Defaults to 0.0.
Option "PressureMotion" string
Enable/disable pressure motion. Defaults to off. Possible values are "on", "off".
Option "PressureMotionMinZ" integer
Minimum pressure value to trigger pressure motion. Defaults to 20.
Option "PressureMotionMaxZ" integer
Maximum pressure value to trigger pressure motion. Defaults to 120.
Option "PressureMotionMinFactor" float
Minimum sensitivity factor for pressure motion. Defaults to 1.0.

ملاحظات

يوصى بالتكوين من خلال أقسام InputClass في خوادم X 1.8 وما بعدها. انظر xorg.conf.d(5) لمزيد من التفاصيل. يتم توفير مثال لمقتطف xorg.conf.d في ${sourcecode}/conf/70-synaptics.conf

يوصى بالتكوين من خلال ملفات hal fdi في خوادم X 1.5 و 1.6 و 1.7. يتم توفير مثال لملف سياسة hal في ${sourcecode}/conf/11-x11-synaptics.fdi

إذا تم استخدام Protocol "auto-dev" (افتراضي) أو Protocol "event"، يقوم برنامج التشغيل بتهيئة القيم الافتراضية بناءً على الإمكانيات التي يبلغ عنها برنامج تشغيل النواة. يعتمد التسارع والحواف والدقة على الأبعاد التي تبلغ عنها النواة. إذا أبلغت النواة عن اكتشاف متعدد الأصابع، يتم تمكين التمرير العمودي بإصبعين، وتعطيل التمرير الأفقي بإصبعين، وتعطيل التمرير بالحافة. إذا لم يتم الإبلاغ عن أي قدرات متعددة الأصابع، يتم تمكين التمرير بالحافة لكل من التمرير الأفقي والعمودي. يتم تعطيل النقر افتراضيًا لأجهزة اللمس التي تحتوي على زر واحد أو أكثر. لتمكينه، تحتاج إلى تعيين إجراءات النقر إلى أزرار. انظر الخيارات "TapButton1" و "TapButton2" و "TapButton3".

يتم التعامل مع تعيين الأزرار للأزرار المادية في الخادم. إذا تم تبديل الجهاز إلى وضع اليد اليسرى (تعيين داخلي للخادم للأزرار المادية 1، 2، 3 إلى الأزرار المنطقية 3، 2، 1، على التوالي)، يتأثر كل من الأزرار المادية و TapButtons. لمواجهة ذلك، يجب إعداد TapButtons بترتيب عكسي (TapButton1=3، TapButton2=1).
