NAME

Sys::Hostname::Long - Get the fully qualified domain name

SYNOPSIS

 use Sys::Hostname::Long qw(longname);
 my $long_hostname = longname();

DESCRIPTION

This module provides one function, longname(), which attempts to return the fully qualified domain name (FQDN) of the local machine.

This is a wrapper around the standard Sys::Hostname module that attempts to return the fully qualified domain name of the local machine.

Some systems rely on a fully qualified domain name being set up in the system correctly. This module provides a generic way of accessing it.

It is often desired to have the fully qualified domain name and not just the short name that Sys::Hostname may return.

DISCUSSION

It is possible that this module may not work on all systems, or that it may not return the desired name.

KNOWN LIMITATIONS

Unix

Most unix systems have trouble working out the fully qualified domain name as it to be configured somewhere in the system correctly. For example in most linux systems (debian, ?) the fully qualified name should be the first entry next to the ip number in /etc/hosts

192.168.0.1     fred.somwhere.special   fred

If it is the other way around, it will fail.
