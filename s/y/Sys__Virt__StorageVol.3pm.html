Sys::Virt::StorageVol(3pm) وثائق Perl مقدمة من المستخدم Sys::Virt::StorageVol(3pm)

الاسم

Sys::Virt::StorageVol - تمثيل وإدارة وحدة تخزين libvirt

الوصف

الوحدة "Sys::Virt::StorageVol" تمثل وحدة تخزين يتم إدارتها بواسطة libvirt. ترتبط وحدة التخزين دائمًا بحوض تخزين يحتوي عليها ("Sys::Virt::StoragePool").

الوظائف

my $name = $vol->get_name()
يعيد سلسلة نصية تحتوي على اسم فريد محليًا لوحدة التخزين
my $name = $vol->get_key()
يعيد سلسلة نصية تحتوي على مفتاح فريد عالميًا لوحدة التخزين
my $name = $vol->get_path()
يعيد سلسلة نصية تحتوي على مسار ملف فريد محليًا لوحدة التخزين
my $xml = $vol->get_xml_description()
يعيد وثيقة XML تحتوي على وصف كامل لتكوين وحدة التخزين
$vol->delete($flags)
حذف وحدة التخزين فورًا وتحرير موارد التخزين الخاصة بها. يشير المعامل "flags" إلى أي إجراء خاص يجب اتخاذه عند حذف وحدة التخزين.
$vol->resize($newcapacity, $flags=0)
تعديل حجم وحدة التخزين. تعتمد دلالات القيمة $newcapacity على المعامل $flags. إذا كان $flags يحدد "RESIZE_DELTA"، فإن $newcapacity يكون نسبيًا للحجم الحالي. إذا كان $flags يحدد "RESIZE_SHRINK"، فإن قيمة $newcapacity هي مقدار المساحة التي سيتم إزالتها
$vol->wipe($flags = 0)
مسح البيانات في وحدة التخزين لتجنب تسرب المعلومات المستقبلية. المعامل "flags" غير مستخدم حاليًا ويؤدي افتراضيًا إلى الصفر.
$vol->wipe_pattern($algorithm, $flags = 0)
مسح البيانات في وحدة التخزين لتجنب تسرب المعلومات المستقبلية. يحدد المعامل $algorithm نمط البيانات المستخدم لمسح البيانات، ويجب أن يكون أحد ثوابت خوارزمية المسح المذكورة لاحقًا. المعامل "flags" غير مستخدم حاليًا ويؤدي افتراضيًا إلى الصفر.
my $info = $vol->get_info($flags = 0)
استرداد معلومات حية حول وحدة التخزين. يحتوي مرجع الهاش $info المُعاد على ثلاثة مفاتيح. يشير "type" إلى ما إذا كانت الوحدة ملفًا أو جهاز كتلة. يوفر "capacity" الحد الأقصى للحجم المنطقي للوحدة. يوفر "allocation" الاستخدام الفعلي الحالي للوحدة. قد يكون التخصيص أقل من السعة للوحدات المتفرقة أو التي تنمو عند الطلب. قد يكون التخصيص أيضًا أكبر من السعة، إذا كان هناك عبء إضافي للبيانات الوصفية لتنسيق الوحدة. يمكن أن يأخذ $flags إحدى القيم
Sys::Virt::StorageVol::USE_ALLOCATION
إعادة التخصيص الحالي في التخصيص
Sys::Virt::StorageVol::GET_PHYSICAL
إعادة الحجم الفعلي في التخصيص
$vol->download($st, $offset, $length, $flags=0);
تنزيل البيانات من $vol باستخدام التدفق $st. إذا كانت $offset و $length غير صفرية، فقم بتقييد البيانات بنطاق البايت المحدد للوحدة. يقبل $flags القيم التالية:
Sys::Virt::StorageVol::VOL_DOWNLOAD_SPARSE_STREAM
إذا تم تعيين هذا العلم في @flags، فسيتم تمكين الإرسال الفعال للفراغات. يفترض هذا استخدام التدفق $st بالاشتراك مع "sparse_recv_all" أو "recv($flags = VIR_STREAM_RECV_STOP_AT_HOLE)" لتكريم الفراغات المرسلة من الخادم.
$vol->upload($st, $offset, $length, $flags=0);
تحميل البيانات إلى $vol باستخدام التدفق $st. إذا كانت $offset و $length غير صفرية، فقم بتقييد البيانات بنطاق البايت المحدد للوحدة. يقبل $flags القيم التالية:
Sys::Virt::StorageVol::VOL_UPLOAD_SPARSE_STREAM
إذا تم تعيين هذا في $flags، فسيتم تمكين الإرسال الفعال للفراغات. يفترض هذا استخدام التدفق $st بالاشتراك مع "sparse_send_all" أو "send_hole" للحفاظ على فراغ الملف المصدر.

Sys::Virt::StorageVol(3pm) — Perl manual

NAME

Sys::Virt::StorageVol - Virtual machine storage volume operations

DESCRIPTION

This module provides an object oriented interface to the libvirt storage volume API. It is not intended to be used directly, but rather provides the methods and constants that are used by the higher level Sys::Virt module.

See Sys::Virt::StoragePool for details on how to access storage volumes.

METHODS

Sys::Virt::StorageVol->new(conn, vol_xml)
Creates a new storage volume object.
name()
Get the name of the storage volume.
key()
Get the unique key of the storage volume.
path()
Get the path to the storage volume.
size()
Get the size of the storage volume in bytes.
info()
Get information about the storage volume.
create(capacity, flags=0)
Creates a storage volume with the specified capacity and flags.
delete(flags=0)
Deletes the storage volume with the specified flags.
wipe(algorithm, flags=0)
Wipes the storage volume using the specified algorithm and flags.
resize(capacity, flags=0)
Resizes the storage volume to the specified capacity and flags.
clone(dest_pool, dest_name, flags=0)
Clones the storage volume to the specified destination pool and name.
upload(href, offset, length, flags=0)
Uploads data to the storage volume.
download(href, offset, length, flags=0)
Downloads data from the storage volume.

CONSTANTS

DELETE FLAGS

Sys::Virt::StorageVol::DELETE_ZEROED
Zero out current allocated blocks when deleting the volume
Sys::Virt::StorageVol::DELETE_WITH_SNAPSHOTS
Delete snapshots associated with the volume

WIPE ALGORITHM CONSTANTS

The following constants specify the algorithm for erasing data

Sys::Virt::StorageVol::WIPE_ALG_BSI
9-pass method recommended by the German Center of Security in Information Technologies
Sys::Virt::StorageVol::WIPE_ALG_DOD
4-pass Dod 5220.22-M section, 8-306 procedure
Sys::Virt::StorageVol::WIPE_ALG_GUTMANN
The canonical 35-pass sequence
Sys::Virt::StorageVol::WIPE_ALG_NNSA
4-pass NNSA Policy Letter NAP-14.1-C (XVI-8)
Sys::Virt::StorageVol::WIPE_ALG_PFITZNER7
7-pass random
Sys::Virt::StorageVol::WIPE_ALG_PFITZNER33
33-pass random
Sys::Virt::StorageVol::WIPE_ALG_RANDOM
1-pass random
Sys::Virt::StorageVol::WIPE_ALG_SCHNEIER
7-pass method described by Bruce Schneier in "Applied Cryptography" (1996)
Sys::Virt::StorageVol::WIPE_ALG_ZERO
1-pass, all zeroes
Sys::Virt::StorageVol::WIPE_ALG_TRIM
1-pass, trim all data on the volume by using TRIM or DISCARD

VOLUME RESIZE CONSTANTS

The following constants control how storage volumes can be resized

Sys::Virt::StorageVol::RESIZE_ALLOCATE
Fully allocate the extra space required during resize
Sys::Virt::StorageVol::RESIZE_DELTA
Treat the new capacity as a delta to the current capacity
Sys::Virt::StorageVol::RESIZE_SHRINK
Treat the new capacity as an amount to remove from the capacity
