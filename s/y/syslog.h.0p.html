syslog.h(0p) دليل مبرمجي POSIX syslog.h(0p)

مقدمة

هذه الصفحة الدليلية جزء من دليل مبرمجي POSIX. قد يختلف تنفيذ هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة في لينكس.

الاسم

syslog.h — تعريفات لتسجيل أخطاء النظام

ملخص

#include <syslog.h>

الوصف

يحدد رأس <syslog.h> الثوابت الرمزية التالية، والتي يمكن دمج صفر أو أكثر منها لتشكيل خيار logopt الخاص بـ openlog():

LOG_PID
تسجيل معرف العملية مع كل رسالة.
LOG_CONS
تسجيل على وحدة التحكم في النظام عند حدوث خطأ.
LOG_NDELAY
الاتصال بخادم syslog فورًا.
LOG_ODELAY
تأخير الفتح حتى يتم استدعاء syslog().
LOG_NOWAIT
عدم الانتظار لتنفيذ العمليات الفرعية.

يحدد رأس <syslog.h> الثوابت الرمزية التالية لاستخدامها كوسيط facility لـ openlog():

LOG_KERN
محجوز للرسائل التي تم إنشاؤها بواسطة النظام.
LOG_USER
الرسائل التي تم إنشاؤها بواسطة عملية.
LOG_MAIL
محجوز للرسائل التي تم إنشاؤها بواسطة نظام البريد.
LOG_NEWS
محجوز للرسائل التي تم إنشاؤها بواسطة نظام الأخبار.
LOG_UUCP
محجوز للرسائل التي تم إنشاؤها بواسطة نظام UUCP.
LOG_DAEMON
محجوز للرسائل التي تم إنشاؤها بواسطة خادم النظام.
LOG_AUTH
محجوز للرسائل التي تم إنشاؤها بواسطة خادم المصادقة.
LOG_CRON
محجوز للرسائل التي تم إنشاؤها بواسطة خادم الوقت.
LOG_LPR
محجوز للرسائل التي تم إنشاؤها بواسطة نظام الطباعة.
LOG_LOCAL0
محجوز للاستخدام المحلي.

محجوز للاستخدام المحلي.

يحدد رأس <syslog.h> الثوابت التالية لاستخدامها في وسيط maskpri الخاص بـ setlogmask(). تتوسع الثوابت التالية إلى تعبير من نوع int عندما يكون الوسيط pri تعبيرًا من نوع int:

LOG_MASK(pri)
قناع للأولوية pri.

يحدد رأس <syslog.h> الثوابت الرمزية التالية لاستخدامها كوسيط priority الخاص بـ syslog():

LOG_EMERG
تم الإبلاغ عن حالة ذعر لجميع العمليات.
LOG_ALERT
حالة يجب تصحيحها فورًا.
LOG_CRIT
حالة حرجة.
LOG_ERR
رسالة خطأ.
LOG_WARNING
رسالة تحذير.
LOG_NOTICE
حالة تتطلب معالجة خاصة.
LOG_INFO
رسالة معلومات عامة.
LOG_DEBUG
رسالة مفيدة لتصحيح أخطاء البرامج.

سيتم الإعلان عن ما يلي كدوال وقد يتم تعريفه أيضًا كـ macros. يجب توفير نماذج الدالة.

void  closelog(void);
void  openlog(const char *, int, int);
int   setlogmask(int);
void  syslog(int, const char *, ...);

NAME

syslog.h - interface to the syslog(3) system log facility

SYNOPSIS

#include <syslog.h>

DESCRIPTION

The syslog() function is used to send messages to the system logger. The system logger can be configured to direct messages to various destinations, such as log files, the console, or remote systems.

The syslog() function takes two arguments:

priority
A value specifying the severity level and the facility of the message. The severity levels are defined by constants starting with LOG_ and followed by a level name (e.g., LOG_EMERG, LOG_ALERT, LOG_CRIT, LOG_ERR, LOG_WARNING, LOG_NOTICE, LOG_INFO, LOG_DEBUG). The facilities define the type of program generating the message (e.g., LOG_KERN, LOG_USER, LOG_MAIL, LOG_DAEMON, LOG_AUTH, LOG_SYSLOG, LOG_LPR, LOG_NEWS, LOG_UUCP, LOG_CRON, LOG_AUTHPRIV, LOG_FTP, LOG_LOCAL0 through LOG_LOCAL7). The facility and priority are combined using the bitwise OR operator: priority = LOG_FACILITY | LOG_LEVEL.
message
The message string to be logged. It is recommended to end the message with a newline character. The syslog() function will append a newline if one is not present.

The openlog() function initializes the logging process. It should be called before the first call to syslog(). It takes three arguments:

ident
A string that will be prepended to every message. Typically, this is the name of the program.
logopt
Options that control the behavior of the logger. These include:
  • LOG_PID: Log the process ID with each message.
  • LOG_CONS: Log on the console if there is an error while sending to system logger.
  • LOG_ODELAY: Delay opening the connection until the first message is logged.
  • LOG_NDELAY: Open the connection immediately.
  • LOG_NOWAIT: Do not wait for child processes when logging.
  • LOG_PERROR: Log to stderr in addition to the system log.
facility
The default facility to use if none is specified in the priority argument to syslog(). If 0, the default is LOG_USER.

The closelog() function closes the connection to the logger. It is recommended to call this function when the program is exiting.

The setlogmask() function sets the log mask for the current process. The log mask determines which messages will be logged. The argument is a pointer to a 32-bit integer that represents the mask. The LOG_MASK() macro can be used to create a mask for a specific priority, and LOG_UPTO() can be used to create a mask for all priorities up to a certain level.

DIAGNOSTICS

The syslog() function may encounter errors if the system logger is not running or if there are issues with the log files or network connections. These errors are typically handled internally by the system logger and may result in messages being logged to alternative destinations or simply being discarded.

RETURN_VALUE

The syslog() function does not return a value.

The openlog(), closelog(), and setlogmask() functions do not return values.

ERRORS

The syslog() function does not set errno.

EXAMPLES

#include <syslog.h>

int main() {
    openlog("myprog", LOG_PID | LOG_CONS, LOG_USER);

    syslog(LOG_INFO, "This is an informational message.");
    syslog(LOG_WARNING, "This is a warning message.");
    syslog(LOG_ERR, "This is an error message.");

    closelog();
    return 0;
}

FUTURE DIRECTIONS

The syslog() interface is part of the POSIX standard and is expected to remain in use. Future developments may focus on enhancing the system logger's capabilities, such as improved filtering, remote logging protocols, and security features.
