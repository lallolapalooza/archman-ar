syd-path(1)

الحزمة: syd

التراخيص: GPL-3.0-only

SYD-PATH(1) دليل الأوامر العامة SYD-PATH(1)

الاسم

syd-path - كتابة قواعد Force sandboxing للملفات التنفيذية تحت PATH

ملخص

syd-path [-h1235cCeklmpsw]

الوصف

كتابة قواعد Force sandboxing للملفات التنفيذية تحت PATH.

إذا تم تحديد خيار واحد على الأقل من خيارات -e المتنوعة، قم بسرد الملفات التنفيذية بمعلومات محددة تحت PATH.

خيارات

-h عرض المساعدة.
-c حساب المجموع الاختباري CRC64 (غير آمن).
-C حساب المجموع الاختباري CRC32 (غير آمن).
-m حساب المجموع الاختباري MD5 (غير آمن، متوافق مع vdb لـ portage/paludis).
-1 حساب المجموع الاختباري SHA1 (غير آمن).
-2 حساب المجموع الاختباري SHA3-256.
-3 حساب المجموع الاختباري SHA3-384.
-5 حساب المجموع الاختباري SHA3-512 (الافتراضي).
-k استخدام الإجراء kill (الافتراضي).
-w استخدام الإجراء warn.
-l num تحديد العدد حسب عدد الإدخالات.
-p path تحديد PATH بديل.
-s بادئة القواعد بـ "/dev/syd/".
-e32 سرد الملفات التنفيذية ELF 32-بت تحت PATH (يتعارض مع -e64).
-e64 سرد الملفات التنفيذية ELF 64-بت تحت PATH (يتعارض مع -e32).
-ed سرد الملفات التنفيذية ELF المرتبطة ديناميكيًا تحت PATH (يتعارض مع -es).
-es سرد الملفات التنفيذية ELF المرتبطة ثابتًا تحت PATH (يتعارض مع -ed).
-ep سرد الملفات التنفيذية PIE تحت PATH (يتعارض مع -eP).
-eP سرد الملفات التنفيذية غير PIE تحت PATH (يتعارض مع -ep).
-ex سرد النصوص البرمجية تحت PATH.
-eX سرد الملفات التنفيذية ذات المكدس القابل للتنفيذ تحت PATH.
