systemd-udevd(8)

الحزمة: systemd

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later, MIT-0

SYNOPSIS

/usr/lib/systemd/systemd-udevd

DESCRIPTION

systemd-udevd is the event driven device event managing daemon. It listens to kernel uevent messages, processes them, and dispatches them to interested applications and the udev rule processing system.

The daemon should be started by systemd itself during boot. It is responsible for creating device nodes, symbolic links and other device related files in the /dev directory.

systemd-udevd maintains a dynamic device tree and may be used to query device information and to configure devices.

OPTIONS

The following options are understood:

--daemon

Run as a daemon. This is the default.

--replace-bin=BIN

Replace the specified binary with systemd-udevd. This option is mainly used internally for bootstrapping.

--child-pidfd

Returns a file descriptor referring to the child process after fork() in the parent. This is primarily for use with systemd's internal fork() and exec() mechanisms. Not generally useful otherwise.

--disable-kmsg

Do not read device events from /dev/kmsg. This is useful if the kernel does not provide kmsg events.

--error-on-miss

Report an error if a requested device node is missing. This is useful for debugging rule sets.

--log-priority=LEVEL

Set the logging priority to LEVEL. Valid values are debug, info, notice, warning, err, crit, alert, and emerg.

--log-target=TARGET

Set the logging target. Valid values are console, journal, syslog, and kmsg.

--resolve-alias=NAME

Resolve the device alias NAME to its canonical device path.

--resolve-path=PATH

Resolve the device path PATH to its canonical device path.

--matches=MATCH

Print all devices that match the specified MATCH string.

--exit-if-no-tty

Exit if no controlling terminal is available. This is useful for debugging.

KERNEL COMMAND LINE

systemd-udevd can be influenced by kernel command line parameters. These are typically used to influence the early boot process, before systemd is fully up and running.

udev.debug

Enable debug logging for udev.

udev.extra-log-level=LEVEL

Set the logging level for udev rules to LEVEL. Valid values are debug, info, notice, warning, err, crit, alert, and emerg.

udev.log-priority=LEVEL

Set the logging priority for udev events to LEVEL. Valid values are debug, info, notice, warning, err, crit, alert, and emerg.

udev.log-all-rules

Log all udev rules, even if they don't match any devices. This is useful for debugging rule sets.

udev.root=/dev/sdXY

Set the root device to /dev/sdXY. This is typically used to specify the root filesystem device at boot time.
