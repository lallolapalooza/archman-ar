NAME

systemd.netdev(5)

ملفات تعريف أجهزة الشبكة

SYNOPSIS

systemd.netdev(5)

DESCRIPTION

يقوم systemd-networkd بإنشاء أجهزة شبكة خاصة (مثل الجسور، و VLANs، والوصلات، والأنفاق) كما هو محدد في ملفات .netdev. سيتم تحليل هذه الملفات في /etc/systemd/network/، /run/systemd/network/، و /usr/lib/systemd/network/. يتم إعطاء الأولوية للملفات في الدلائل الأولى.

تتكون ملفات .netdev من الأقسام التالية:

  • قسم [NetDev] مطلوب.
  • قسم [Bond] خاص بأجهزة الربط.
  • قسم [VLAN] خاص بأجهزة VLAN.
  • قسم [Tunnel] خاص بأجهزة الأنفاق.
  • قسم [FooOverUDP] خاص بـ Foo-over-UDP.
  • قسم [Tap] خاص بأجهزة TAP.
  • قسم [Veth] خاص بأجهزة VETH.
  • قسم [Bridge] خاص بأجهزة الجسور.
  • قسم [Dummy] خاص بأجهزة الوهمية.
  • قسم [VirtualEth] خاص بأجهزة Ethernet الافتراضية.
  • قسم [Veth] خاص بأجهزة Veth.
  • قسم [Rtmp] خاص بأجهزة Rtmp.
  • قسم [WireGuard] خاص بأجهزة WireGuard.
  • قسم [Xfrm] خاص بأجهزة Xfrm.
  • قسم [IPVLAN] خاص بأجهزة IPVLAN.
  • قسم [MACVLAN] خاص بأجهزة MacVLAN.
  • قسم [VirtualPort] خاص بأجهزة Port الافتراضية.
  • قسم [SIT] خاص بأجهزة SIT.
  • قسم [6rd] خاص بأجهزة 6rd.
  • قسم [GRE] خاص بأجهزة GRE.
  • قسم [GRE6] خاص بأجهزة GRE6.
  • قسم [IFB] خاص بأجهزة IFB.
  • قسم [VRF] خاص بأجهزة VRF.
  • قسم [WLAN] خاص بأجهزة WLAN.
  • قسم [Simulated] خاص بأجهزة المحاكاة.

[NetDev] SECTION

يحتوي قسم [NetDev] على معلومات أساسية حول الجهاز.

Name=
يحدد اسم الجهاز. يجب أن يكون هذا الاسم فريدًا.
Kind=
يحدد نوع الجهاز. القيم الممكنة هي: bridge، bond، vlan، tunnel، tap، veth، dummy، ipip، ip6ip6، ip6gre، gre، sit، wireguard، bridge-slave، vlan-slave، macvlan، macvtap، ipvlan، xfrm، vrf، wlan، fou، fou-tunnel.
MTUBytes=
يحدد حجم الوحدة القصوى للنقل (MTU) بالجول. إذا لم يتم تحديده، فإن القيمة الافتراضية تعتمد على نوع الجهاز. بالنسبة لأنواع الأنفاق، قد يتم إزالة رأس IP الأولي من MTU المحدد.

تمت الإضافة في الإصدار 250.

[Bond] SECTION

يحتوي قسم [Bond] على خيارات خاصة بأجهزة الربط.

Mode=
يحدد وضع الربط. القيم الممكنة هي: balance-rr، active-backup، balance-xor، broadcast، 802.3ad، balance-tlb، balance-alb. يتم تحديد وضع 802.3ad افتراضيًا.
TransmitHashPolicy=
يحدد سياسة التجزئة للإرسال عند استخدام أوضاع الربط balance-xor، 802.3ad، balance-tlb، balance-alb. القيم الممكنة هي: layer2، layer3، layer4، layer2+3، layer2+4، layer3+4، full. تحدد القيمة الافتراضية layer2.
MIIMonitorSec=
يحدد فترة المراقبة لـ MII بالثواني. إذا تم تعيينها على 0، فلن يتم تمكين مراقبة MII.
LACPTransmitRate=
يحدد معدل إرسال LACP. القيم الممكنة هي: fast أو slow.
LACPDUv1=
يحدد ما إذا كان سيتم استخدام LACPDU v1. يأخذ قيمة منطقية.

تمت الإضافة في الإصدار 250.

[VLAN] SECTION

يحتوي قسم [VLAN] على خيارات خاصة بأجهزة VLAN.

Id=
يحدد معرف VLAN. يجب أن يكون هذا معرفًا رقميًا بين 1 و 4094.
GVRP=
يحدد ما إذا كان سيتم تمكين GVRP. يأخذ قيمة منطقية.
802.1Q=
يحدد ما إذا كان سيتم تمكين 802.1Q. يأخذ قيمة منطقية.

تمت الإضافة في الإصدار 250.

[Tunnel] SECTION

يحتوي قسم [Tunnel] على خيارات خاصة بأجهزة الأنفاق.

Mode=
يحدد وضع النفق. القيم الممكنة هي: ipip، gre، sit، tunnel6، wireguard.
Local=
يحدد عنوان IP المحلي للواجهة.
Remote=
يحدد عنوان IP البعيد للواجهة.
TTL=
يحدد قيمة TTL (Time To Live) لحزم النفق. إذا تم تعيينها على 0، فسيتم استخدام قيمة TTL الافتراضية.
Independent=
يحدد ما إذا كان سيتم إنشاء النفق بشكل مستقل عن الواجهة الأساسية. يأخذ قيمة منطقية.
Key=
يحدد مفتاح النفق.
FlowLabel=
يحدد تسمية التدفق لـ IPv6.
Proto=
يحدد بروتوكول النفق (على سبيل المثال، 47 لـ GRE).
Scope=
يحدد نطاق النفق.
NUDPipe=
يحدد حجم NUD Pipe.
Metric=

systemd.netdev(5)

NAME

systemd.netdev - describes network devices for systemd

SYNOPSIS

/etc/systemd/network/<name>.netdev, /run/systemd/network/<name>.netdev, /usr/lib/systemd/network/<name>.netdev

DESCRIPTION

A unit file to describe network devices. This file is used by systemd-networkd(8) to configure network interfaces.

The file describes a network device. One or more sections are allowed. The first section must be of type [Match]. The second section must be of type [NetDev]. Any subsequent sections are optional and are used to configure specific device types like bridges, bonds, or tunnels.

OPTIONS

The file consists of sections, separated by a blank line. Sections are identified by a string in brackets, e.g. [NetDev].

An optional comment character #, the same like in shell scripts, can be used at the beginning of lines.

Recognized section types are:

  • [Match]
  • [NetDev]
  • [Bridge]
  • [VLAN]
  • [Macvlan]
  • [Macvtap]
  • [IPVLAN]
  • [IPVTAP]
  • [VXLAN]
  • [GENEVE]
  • [HSR]
  • [BAREUDP]
  • [L2TP]
  • [L2TPSession]
  • [MACSEC]
  • [MACSECReceiveChannel]
  • [MACSECTransmitAssociation]
  • [MACSECReceiveAssociation]
  • [Tunnel]
  • [FOOOVERUDP]
  • [Peer]
  • [VXCAN]
  • [TUN]
  • [TAP]
  • [WireGuard]
  • [WireGuardPeer]
  • [Bond]
  • [XFRM]
  • [VRF]
  • [BatmanAdv]
  • [IPOIB]
  • [WLAN]

The [Match] section is described in systemd.network(5).

The [NetDev] section is mandatory and describes the network device itself.

All other sections are optional and describe specific device types or configurations.

[NETDEV] SECTION OPTIONS

The following options are available in the [NetDev] section:

Name=
The name of the network device. This is a mandatory option.
Kind=
The kind of the network device. This is a mandatory option. Possible values are:
  • bridge
  • bond
  • vlan
  • macvlan
  • macvtap
  • ipvlan
  • ipvtap
  • vxlan
  • geneve
  • hsr
  • bareudp
  • l2tp
  • l2tpv3ipsec
  • l2tpv3（L2TPv3）
  • macsec
  • tunnel
  • tun
  • tap
  • wireguard
  • vrf
  • batman-adv
  • ipoib
  • wlan
MACAddress=
The MAC address of the network device. If not specified, the MAC address is assigned automatically.
MTUBytes=
The Maximum Transmission Unit (MTU) of the network device in bytes. If not specified, the MTU is determined automatically.
Description=
A description of the network device. This is an optional option.

[BRIDGE] SECTION OPTIONS

The following options are available in the [Bridge] section:

Port=
The name of the network device to be added to the bridge.
PathCost=
The path cost of the port.
Priority=
The priority of the port.

[VLAN] SECTION OPTIONS

The following options are available in the [VLAN] section:

Id=
The VLAN ID.
Protocol=
The VLAN protocol. Possible values are 802.1q and 802.1ad.

[MACVLAN] SECTION OPTIONS

The following options are available in the [Macvlan] section:

Mode=
The mode of the macvlan interface. Possible values are default, private, promisc, passthru, bridge, vepa.
MacAddress=
The MAC address of the macvlan interface. If not specified, the MAC address is assigned automatically.
