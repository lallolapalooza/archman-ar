syd-dns(1)

الحزمة: syd

التراخيص: GPL-3.0-only

SYD-DNS(1) دليل الأوامر العامة SYD-DNS(1)

الاسم

syd-dns - حل اسم المضيف إلى عناوين IP باستخدام محلل DNS للنظام

الموجز

syd-dns [-hr46] اسم_المضيف

syd-dns [-R] عنوان_IPv4/6

الوصف

حل اسم المضيف إلى عناوين IP باستخدام محلل DNS للنظام.

بالنظر إلى -R، قم بإجراء بحث DNS عكسي لعنوان IPv4/6 المحدد باستخدام محلل DNS للنظام.

خيارات

-h عرض المساعدة والخروج.
-4 طباعة عناوين IPv4 فقط
-6 طباعة عناوين IPv6 فقط
-r طباعة عنوان IP عشوائي تم اختياره باستخدام getrandom(2)
-R إجراء بحث DNS عكسي باستخدام getnameinfo(3)

انظر أيضًا

syd(1), syd(2), syd(5), syd-net(1), getrandom(2), getnameinfo(3)
