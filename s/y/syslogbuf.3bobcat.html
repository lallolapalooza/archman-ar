NAME

syslogbuf — wrapper for the syslog daemon interface

SYNOPSIS

#include <bobcat/syslogbuf>
namespace FBB {
    class SyslogBuf:
        public std::streambuf
    {
        public:
            enum Priority
            {
                emerg,        // emergency
                alert,        // alert
                crit,         // critical
                err,          // error
                warning,      // warning
                notice,       // notice
                info,         // informational
                debug,        // debug
                syslog // <= syslogged priority
            };
            enum Option
            {
                cons,       // log to console if error
                ndelay,     // don't delay open
                nowait,     // don't wait for child processes
                odelay      // delay open
            };
            // construction
            explicit SyslogBuf(
                char const *ident,
                int option = consts.NDELAY,
                Priority priority = consts.LOG_DEFAULT
            );
            explicit SyslogBuf(
                char const *ident,
                int option,
                int priority
            );
            explicit SyslogBuf(
                std::string const &ident,
                int option = consts.NDELAY,
                Priority priority = consts.LOG_DEFAULT
            );
            explicit SyslogBuf(
                std::string const &ident,
                int option,
                int priority
            );
            // destruction
            ~SyslogBuf() override;
            // (un)blocking I/O
            void open();
            void close();
            // data members
            Priority setDefaultPriority(Priority priority);
            Priority setPriority(Priority priority);
            // manipulator
            static void eoi(std::ostream &out);
        private:
            // ...
    };
    // manipulator
    FBB::eoi;
};

DESCRIPTION

The SyslogBuf class provides a buffer that writes its data to the system logger, see syslog(3). A SyslogBuf object can be inserted into an std::ostream object to funnel output to the syslog daemon.

The SyslogBuf class inherits from std::streambuf.

NAMESPACE

FBB

INHERITS FROM

std::streambuf

ENUMERATIONS

The SyslogBuf class has two nested enumerations:

o
Priority: Defines the priority of syslog messages. These priorities are identical to the symbolic constants defined in syslog(3).
o
Option: Defines the options for the syslog facility. These options are identical to the symbolic constants defined in openlog(3).

CONSTRUCTOR

o
SyslogBuf(char const *ident, int option, Priority priority):
o
SyslogBuf(char const *ident, int option, int priority):
o
SyslogBuf(std::string const &ident, int option, Priority priority):
o
SyslogBuf(std::string const &ident, int option, int priority):
o
SyslogBuf(char const *ident, int option = consts.NDELAY, Priority priority = consts.LOG_DEFAULT):
o
SyslogBuf(std::string const &ident, int option = consts.NDELAY, Priority priority = consts.LOG_DEFAULT):
o
Constructs a SyslogBuf object. The ident string is prepended to every message sent to the syslog daemon. The option and priority parameters are passed to openlog(3). If no options are specified, NDELAY is assumed. If no priority is specified, LOG_DEFAULT is assumed.

MEMBER FUNCTIONS

o
void open(): Opens a connection to the syslog daemon using the ident, option and priority that were specified when the SyslogBuf object was constructed. If a connection is already open, this function does nothing. If the connection fails, an exception of type std::runtime_error is thrown.
o
void close(): Closes the connection to the syslog daemon. If no connection is open, this function does nothing.
o
Priority setDefaultPriority(Priority priority):
Sets the default priority for the next message sent to the syslog daemon. The previously active default priority is returned.
o
Priority setPriority(Priority priority):
Sets the priority for the next message sent to the syslog daemon. Subsequent messages will again use the default priority. The previously active priority is returned.
o
static void eoi(std::ostream &out):
This manipulator can be inserted into an std::ostream to close the connection to the syslog daemon. It performs the same actions as the close() member function. If inserted into a plain std::ostream, nothing happens.

MANIPULATOR

o
FBB::eoi:
The eoi manipulator can be inserted into the ostream instead of calling the SyslogBuf::close member. It performs the same actions as the close member. If inserted into a plain std::ostream nothing happens.

EXAMPLE

See also syslogstream(3bobcat)

#include <iostream>
#include <bobcat/syslogbuf>
using namespace std;
using namespace FBB;
int main(int argc, char **argv)
{
    ostream sls(new SyslogBuf(argv[0]));
    sls << SyslogStream::debug << "Hello world" << flush <<
           SyslogStream::strerrno << endl;
}

BUGS

The constructor’s option parameter is an int. Because of this, int values rather than enumeration values are passed to the constructor. It is the responsibility of the programmer to pass defined option values only.
