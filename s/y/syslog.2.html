NAME

syslog, klogctl - read or clear kernel message ring buffer; set kernel message ring buffer size

LIBRARY

Standard C library (libc, although often linked as -lc)

SYNOPSIS

int syslog(int type, char *buf, int len);

int klogctl(int type, char *buf, int len);

DESCRIPTION

The syslog() and klogctl() system calls are used to control and read the kernel message buffer.

The type argument determines the action to be performed. The following values are defined for type. Some values are common to both syslog() and klogctl().

SYSLOG_ACTION_CLOSE
KLOGCTL_CLEAR
(0) Close the log device. This prevents further messages from being written.
SYSLOG_ACTION_OPEN
KLOGCTL_READ_ALL
(1) Open the log device. This allows messages to be written.
SYSLOG_ACTION_READ
KLOGCTL_READ_ALL
(2) Read from the log device. This reads at most len bytes from the kernel message buffer into buf.
SYSLOG_ACTION_READ_ALL
KLOGCTL_READ_ALL
(3) Read all available messages from the log device. This reads at most len bytes from the kernel message buffer into buf.
SYSLOG_ACTION_READ_CLEAR
KLOGCTL_READ_CLEAR
(4) Read and clear the log device. This reads at most len bytes from the kernel message buffer into buf and then clears the buffer.
SYSLOG_ACTION_SETtoEqual
(5) Set the console log level. The minimum level to be printed to the console is set to the value in len.
SYSLOG_ACTION_SET_SYSLOGLEVEL
(6) Set the default message log level. The default level for messages without an explicit level is set to the value in len.
SYSLOG_ACTION_DEFAULT_MESSAGE_LOGLEVEL
(7) Get the default message log level. The value is returned in len.
SYSLOG_ACTION_DEFAULT_CONSOLE_LOGLEVEL
(8) Get the default console log level. The value is returned in len.
SYSLOG_ACTION_CLEAR
KLOGCTL_CLEAR
(9) Clear the kernel message ring buffer.
SYSLOG_ACTION_CONSOLE_LEVEL
(10) Get the current console log level.
SYSLOG_ACTION_LEVEL_MASK
(11) Set the current console log level mask.

The syslog() system call is the older interface, and klogctl() is the newer interface. On Linux, they are generally implemented as the same system call.

Console log level

The kernel message buffer is accessible via the /proc/kmsg file. Reading from this file yields messages from the kernel ring buffer. The behavior is controlled by several parameters, which can be set using syslog() or klogctl().

console_loglevel
This variable controls which messages are printed to the console. A message is printed if its log level is less than or equal to the value of console_loglevel. The value can range from 0 (KERN_EMERG) to 8 (disabled). If console_loglevel is 1, only emergency messages are printed. If it is 7, all messages except debug messages are printed. If it is 8, no messages are printed.
default_message_loglevel
This variable determines the default log level for kernel messages that do not explicitly specify a log level. Its value is defined by the kernel configuration option CONFIG_DEFAULT_MESSAGE_LOGLEVEL, which defaults to 4.
minimum_console_loglevel
The value in this field is the minimum value to which console_loglevel can be set.
default_console_loglevel
This is the default value for console_loglevel.

The log level

Every printk() message has its own log level. If the log level is not explicitly specified as part of the message, it defaults to default_message_loglevel. The conventional meaning of the log level is as follows:

Kernel constant Level value Meaning
KERN_EMERG 0 System is unusable
KERN_ALERT 1 Action must be taken immediately
KERN_CRIT 2 Critical conditions
KERN_ERR 3 Error conditions
KERN_WARNING 4 Warning conditions
KERN_NOTICE 5 Normal but significant condition
KERN_INFO 6 Informational
KERN_DEBUG 7 Debug-level messages

The kernel printk() routine will print a message on the console only if it has a log level less than the value of console_loglevel.

RETURN VALUE

For type equal to 2, 3, or 4, a successful call to syslog() returns the number of bytes read. For type 9, syslog() returns the number of bytes currently available to be read on the kernel log buffer. For type 10, syslog() returns the total size of the kernel log buffer. For other values of type, 0 is returned on success.

In case of error, -1 is returned, and errno is set to indicate the error.

ERRORS

EINVAL
Bad arguments (e.g., bad type; or for type 2, 3, or 4, buf is NULL, or size is less than zero; or for type 8, the level is outside the range 1 to 8).
ENOSYS
This syslog() system call is not available, because the kernel was compiled with the CONFIG_PRINTK kernel-configuration option disabled.
EPERM
An attempt was made to change console_loglevel or clear the kernel message ring buffer by a process without sufficient privilege (more precisely: without the CAP_SYS_ADMIN or CAP_SYSLOG capability).
ERESTARTSYS
System call was interrupted by a signal; nothing was read. (This can be seen only during a trace.)

STANDARDS

Linux.

HISTORY

From the very start, people noted that it is unfortunate that a system call and a library routine of the same name are entirely different animals.
