الحزمة: perl-sys-virt

التراخيص: PerlArtistic

Sys::Virt(3pm) توثيق Perl المساهم من قبل المستخدم Sys::Virt(3pm)

الاسم

Sys::Virt - تمثيل وإدارة اتصال بمنصة افتراضية libvirt

الملخص

my $conn = Sys::Virt->new(uri => $uri);
my @domains = $conn->list_domains();
foreach my $dom (@domains) {
  print "Domain ", $dom->get_id, " ", $dom->get_name, "\n";
}

الوصف

توفر الوحدة Sys::Virt ربط XS لـ Perl بواجهات برمجة تطبيقات إدارة الأجهزة الافتراضية libvirt. يتيح ذلك إدارة الأجهزة التي تعمل ضمن حاويات افتراضية عشوائية باستخدام واجهة برمجة تطبيقات متسقة.

معالجة ردود الاتصال

كل روتين تسجيل رد اتصال يعيد $callbackID (باستثناء "domain_event_register" و "register_close_callback"). يجب الاحتفاظ بقيمة الإرجاع هذه واستخدامها لإلغاء تسجيل رد الاتصال.

مهم: يجب إلغاء تسجيل جميع ردود الاتصال (بما في ذلك تلك المسجلة باستخدام "domain_event_register" و "register_close_callback")؛ سيؤدي عدم القيام بذلك إلى منع كائن "Sys::Virt" من التخلص منه بواسطة جامع القمامة ومنع إغلاق الاتصال بـ "libvirtd".

معالجة الأخطاء

أي عمليات في واجهة برمجة تطبيقات Sys::Virt والتي لديها سيناريوهات فشل ستؤدي إلى رمي مثيل من الوحدة Sys::Virt::Error. لالتقاط هذه الأخطاء، قم ببساطة بتغليف الطريقة في كتلة تقييم:

eval { my $conn = Sys::Virt->new(uri => $uri); };
if ($@) {
  print STDERR "Unable to open connection to $addr" . $@->message . "\n";
}

لمزيد من التفاصيل حول المعلومات الواردة في كائنات الخطأ، راجع صفحة دليل Sys::Virt::Error.

الطرق

my $conn = Sys::Virt->new(uri => $uri, readonly => $ro, flags => $flags);
الاتصال بمضيف المحاكاة الافتراضية المحدد بواسطة "uri". يمكن حذف المعلمة "uri"، وفي هذه الحالة سيكون الاتصال الافتراضي إلى مضيف Xen المحلي. تتضمن بعض عناوين URI أمثلة:
xen:///
Xen على الجهاز المحلي
test:///default
برنامج تشغيل وهمي "في الذاكرة" لمجموعات الاختبار
qemu:///system
برنامج تشغيل على مستوى النظام للمحاكاة الافتراضية QEMU / KVM
qemu:///session
برنامج تشغيل لكل مستخدم للمحاكاة الافتراضية QEMU
qemu+tls://somehost/system
برنامج تشغيل QEMU على مستوى النظام على "somehost" باستخدام أمان TLS
xen+tcp://somehost/
برنامج تشغيل Xen على "somehost" باستخدام TCP / أمان SASL

لمزيد من التفاصيل، راجع "http://libvirt.org/uri.html"

إذا تم توفير المعلمة الاختيارية "readonly"، فسيتم محاولة الاتصال غير المتميز بمنصة المحاكاة الافتراضية. إذا لم يتم توفيرها، فسيكون الافتراضي هو إجراء اتصال مميز بالكامل بمنصة المحاكاة الافتراضية. إذا لم يكن التطبيق المستدعي يعمل كـ root، فقد يكون من الضروري توفير ردود اتصال للمصادقة.

إذا تم تعيين المعلمة الاختيارية "auth" إلى قيمة غير صفرية، فسيتم تمكين المصادقة أثناء الاتصال، باستخدام المجموعة الافتراضية لردود الاتصال لجمع بيانات الاعتماد. تطلب ردود الاتصال الافتراضية بيانات الاعتماد من وحدة التحكم، لذلك فهي غير مناسبة للتطبيقات الرسومية. لمثل هذه التطبيقات، يجب توفير تنفيذ مخصص. يجب أن تكون المعلمة "credlist" مرجعًا للمصفوفة يسرد مجموعة أنواع بيانات الاعتماد التي سيتم دعمها. يمكن استخدام ثوابت بيانات الاعتماد في هذه الوحدة كوحدات في هذه القائمة. يجب أن تكون المعلمة "callback" مرجعًا لروتين يحتوي على التعليمات البرمجية اللازمة لجمع بيانات الاعتماد. عند استدعائها، سيتم تزويدها بمعلمة واحدة، وهي مرجع مصفوفة لبيانات الاعتماد المطلوبة. عناصر المصفوفة هي مراجع هاش، مع مفاتيح "type" تعطي نوع بيانات الاعتماد، "prompt" تعطي وصفًا للمستخدم لطلب بيانات الاعتماد، "challenge" تعطي اسم بيانات الاعتماد المطلوبة. يجب جمع الإجابة من المستخدم، وإرجاعها عن طريق تعيين مفتاح "result". قد يتم تعيين هذا المفتاح بالفعل بنتيجة افتراضية إذا كان ذلك منطبقًا.

كمثال بسيط يعيد بيانات اعتماد مرمزة ثابتًا

my $uri  = "qemu+tcp://192.168.122.1/system";
my $username = "test";
my $password = "123456";
my $con = Sys::Virt->new(uri => $uri,
                         auth => 1,
                         credlist => [
                           Sys::Virt::CRED_AUTHNAME,
                           Sys::Virt::CRED_PASSPHRASE,
                         ],
                         callback =>
     sub {
           my $creds = shift;
           foreach my $cred (@{$creds}) {
              if ($cred->{type} == Sys::Virt::CRED_AUTHNAME) {
                  $cred->{result} = $username;
              }
              if ($cred->{type} == Sys::Virt::CRED_PASSPHRASE) {
                  $cred->{result} = $password;
              }
           }
           return 0;
     });

إرجاع معلومات حول عدد الصفحات الحرة في كل خلية NUMA بين $start و $end شاملة. يجب أن تكون المعلمة @pagesizes عبارة عن مرجع مصفوفة يحدد أحجام الصفحات التي يجب إرجاع معلومات عنها. تتوفر معلومات حول أحجام الصفحات المدعومة في XML الخاص بالإمكانيات. تحتوي المصفوفة المرجعة على عنصر لكل خلية NUMA مطلوبة. العناصر هي مراجع تجزئة ذات مفتاحين، 'cell' يحدد رقم خلية NUMA و 'pages' يحدد معلومات الصفحة الحرة لهذه الخلية. قيمة 'pages' هي مرجع تجزئة آخر حيث المفاتيح هي أحجام الصفحات والقيم هي عدد الصفحات الحرة لهذا الحجم.
$con->node_alloc_pages(\@pages, $start, $end, $flags=0)
تخصيص المزيد من الصفحات الكبيرة للجهاز المحجوز. المعلمة "\@pages" هي مرجع مصفوفة مع إدخال واحد لكل حجم صفحة لتخصيصه. كل إدخال هو مرجع مصفوفة آخر حيث العنصر الأول هو حجم الصفحة والعنصر الثاني هو عدد الصفحات. سيتم تخصيص نفس العدد من الصفحات على كل عقدة NUMA في النطاق من $start إلى $end شاملة. تقبل المعلمة $flags ثابتين
Sys::Virt::NODE_ALLOC_PAGES_ADD
سيتم إضافة العدد المطلوب من الصفحات إلى حجز الصفحات الكبير الحالي.
Sys::Virt::NODE_ALLOC_PAGES_SET
سيتم تعيين حجز الصفحات الكبير ليكون مطابقًا تمامًا للعدد المطلوب

مجموعات الثوابت التالية مفيدة عند التعامل مع واجهات برمجة التطبيقات في هذه الحزمة

الاتصال

عند فتح اتصال، يمكن استخدام الثوابت التالية:

Sys::Virt::CONNECT_RO
طلب اتصال للقراءة فقط
Sys::Virt::CONNECT_NO_ALIASES
منع حل الأسماء المستعارة لـ URI

أنواع بيانات الاعتماد

عند تقديم ردود اتصال للمصادقة، تشير الثوابت التالية إلى نوع بيانات الاعتماد المطلوب

Sys::Virt::CRED_AUTHNAME
الهوية للتصرف بها
Sys::Virt::CRED_USERNAME
الهوية للمصادقة عليها
Sys::Virt::CRED_CNONCE
يقوم العميل بتزويد nonce
Sys::Virt::CRED_REALM
مجال المصادقة
Sys::Virt::CRED_ECHOPROMPT
استجابة التحدي غير السرية
Sys::Virt::CRED_NOECHOPROMPT
استجابة التحدي السرية
Sys::Virt::CRED_PASSPHRASE
عبارة مرور سرية
Sys::Virt::CRED_LANGUAGE
رمز لغة RFC 1766
Sys::Virt::CRED_EXTERNAL
بيانات اعتماد مقدمة خارجيًا

ثوابت الهوية

الثوابت التالية مفيدة لتغيير هوية الاتصال

Sys::Virt::IDENTITY_USER_NAME
اسم مستخدم العملية
Sys::Virt::IDENTITY_UNIX_USER_ID
معرف مستخدم UNIX للعملية
Sys::Virt::IDENTITY_GROUP_NAME
اسم مجموعة العملية
Sys::Virt::IDENTITY_UNIX_GROUP_ID
معرف مجموعة UNIX للعملية
Sys::Virt::IDENTITY_PROCESS_ID
معرف العملية.
Sys::Virt::IDENTITY_PROCESS_TIME
وقت بدء العملية.
Sys::Virt::IDENTITY_SASL_USER_NAME
اسم مستخدم SASL المصادق عليه
Sys::Virt::IDENTITY_X509_DISTINGUISHED_NAME
اسم X509 الشهادة المميز لاتصال TLS
Sys::Virt::IDENTITY_SELINUX_CONTEXT
سياق عملية SELinux

ثوابت مقارنة وحدة المعالجة المركزية

Sys::Virt::CPU_COMPARE_INCOMPATIBLE
يفتقد هذا المضيف ميزة واحدة أو أكثر من ميزات وحدة المعالجة المركزية في وصف وحدة المعالجة المركزية
Sys::Virt::CPU_COMPARE_IDENTICAL
يقدم المضيف وصفًا مطابقًا لوحدة المعالجة المركزية
Sys::Virt::CPU_COMPARE_SUPERSET
يقدم المضيف مجموعة شاملة لوصف وحدة المعالجة المركزية

ثوابت تعليق العقدة

Sys::Virt::NODE_SUSPEND_TARGET_MEM
يعلق إلى الذاكرة (مكافئ لـ S3 على معماريات x86)
Sys::Virt::NODE_SUSPEND_TARGET_DISK
يعلق إلى القرص (مكافئ لـ S5 على معماريات x86)
Sys::Virt::NODE_SUSPEND_TARGET_HYBRID
يعلق إلى الذاكرة والقرص (مكافئ لـ S3 + S5 على معماريات x86)
