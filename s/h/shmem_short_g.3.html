shmem_short_g(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_SHORT_G(3) Open MPI SHMEM_SHORT_G(3)

shmem_char_g(3)، shmem_float_g(3)، shmem_int_g(3)، shmem_long_g(3)، shmem_short_g(3)، shmem_longlong_g(3)، shmem_longdouble_g(3) - توفر هذه الروتينات آلية زمن وصول منخفض لقراءة الأنواع الأساسية (char، short، int، float، double، long، long long، long double) من كائنات البيانات المتماثلة على وحدات معالجة طرفية عن بعد.

SYNOPSIS

C أو C++:

#include <mpp/shmem.h>
char shmem_char_g(const char *addr, int pe)
short shmem_short_g(const short *addr, int pe)
int shmem_int_g(const int *addr, int pe)
long shmem_long_g(const long *addr, int pe)
long shmem_longlong_g(const long long *addr, int pe)
float shmem_float_g(const float *addr, int pe)
double shmem_double_g(const double *addr, int pe)
long shmem_longdouble_g(const long double *addr, int pe)

DESCRIPTION

توفر هذه الروتينات إمكانية الحصول بزمن وصول منخفض جدًا للعناصر الفردية من معظم الأنواع الأساسية.

الوسائط هي كما يلي:

addr
عنصر المصفوفة القابل للوصول عن بعد أو كائن البيانات القياسي الذي سيستقبل البيانات على وحدة المعالجة الطرفية البعيدة.
pe
رقم وحدة المعالجة الطرفية البعيدة.
