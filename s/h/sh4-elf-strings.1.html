sh4-elf-strings(1)

الحزمة: sh4-elf-binutils

التراخيص: GPL

STRINGS(1) أدوات تطوير GNU STRINGS(1)

اسم

strings - طباعة تسلسلات الأحرف القابلة للطباعة في الملفات

ملخص

strings [-afovV] [-min-len]
[-n min-len] [--bytes=min-len]
[-t radix] [--radix=radix]
[-e encoding] [--encoding=encoding]
[-U method] [--unicode=method]
[-] [--all] [--print-file-name]
[-T bfdname] [--target=bfdname]
[-w] [--include-all-whitespace]
[-s] [--output-separator sep_string]
[--help] [--version] file...

الوصف

لكل file معطى، تقوم GNU strings بطباعة تسلسلات الأحرف القابلة للطباعة التي طولها 4 أحرف على الأقل (أو العدد المحدد بالخيارات أدناه) وتتبعها بحرف غير قابل للطباعة.

اعتمادًا على كيفية تهيئة برنامج strings، فإنه سيقوم افتراضيًا إما بعرض جميع التسلسلات القابلة للطباعة التي يمكنه العثور عليها في كل ملف، أو فقط تلك التسلسلات الموجودة في أقسام البيانات التي يمكن تحميلها والمُهيأة. إذا كان نوع الملف غير معروف، أو إذا كان strings يقرأ من الإدخال القياسي، فسيقوم دائمًا بعرض جميع التسلسلات القابلة للطباعة التي يمكنه العثور عليها.

للتوافق مع الإصدارات السابقة، سيتم مسح أي ملف يأتي بعد خيار سطر الأوامر المتمثل في - فقط بشكل كامل، بغض النظر عن وجود أي خيار -d.

strings مفيد بشكل أساسي لتحديد محتويات الملفات غير النصية.

الخيارات

-a
--all
-
مسح الملف بالكامل، بغض النظر عن الأقسام التي يحتوي عليها أو ما إذا كانت تلك الأقسام محملة أو مُهيأة. عادةً ما يكون هذا هو السلوك الافتراضي، ولكن يمكن تهيئة strings بحيث يكون -d هو الافتراضي بدلاً من ذلك.

الخيار - يعتمد على الموضع ويجبر strings على إجراء عمليات مسح كاملة لأي ملف مذكور بعد - في سطر الأوامر، حتى لو تم تحديد الخيار -d.

-d
--data
طباعة السلاسل النصية فقط من أقسام البيانات المُهيأة والمُحمّلة في الملف. قد يقلل هذا من كمية البيانات غير المرغوبة في المخرجات، ولكنه يعرض برنامج strings أيضًا لأي ثغرات أمنية قد تكون موجودة في مكتبة BFD المستخدمة لمسح الأقسام وتحميلها. يمكن تهيئة strings بحيث يكون هذا الخيار هو السلوك الافتراضي. في مثل هذه الحالات، يمكن استخدام الخيار -a لتجنب استخدام مكتبة BFD وطباعة جميع السلاسل النصية الموجودة في الملف بدلاً من ذلك.
-f
--print-file-name
طباعة اسم الملف قبل كل سلسلة نصية.
--help
طباعة ملخص لاستخدام البرنامج على المخرجات القياسية والخروج.
-min-len
-n min-len
--bytes=min-len
طباعة تسلسلات الأحرف القابلة للعرض التي يبلغ طولها min-len على الأقل. إذا لم يتم تحديدها، يتم استخدام الحد الأدنى للطول الافتراضي وهو 4. يعتمد التمييز بين الأحرف القابلة للعرض وغير القابلة للعرض على إعدادات الخيارين -e و -U. يتم دائمًا إنهاء التسلسلات عند الأحرف التحكمية مثل السطر الجديد وعودة العربة، ولكن ليس عند حرف الجدولة.
-o
مثل -t o. تمتلك بعض الإصدارات الأخرى من strings أن -o يعمل مثل -t d بدلاً من ذلك. نظرًا لأنه لا يمكننا أن نكون متوافقين مع كلا الطريقين، فقد اخترنا ببساطة أحدهما.
-t radix
--radix=radix
طباعة الإزاحة داخل الملف قبل كل سلسلة نصية. يحدد الحرف المفرد الوسيط أساس الإزاحة - o للأرقام الثمانية، x للأرقام الستة عشرية، أو d للأرقام العشرية.
-e encoding
--encoding=encoding
تحديد ترميز الأحرف للسلاسل النصية التي سيتم العثور عليها. القيم الممكنة لـ encoding هي: s = أحرف بايت واحد 7 بت (افتراضي)، S = أحرف بايت واحد 8 بت، b = 16 بت bigendian، l = 16 بت littleendian، B = 32 بت bigendian، L = 32 بت littleendian. مفيد للعثور على سلاسل الأحرف الواسعة. (l و b تنطبق على، على سبيل المثال، ترميزات Unicode UTF-16/UCS-2).
-U [d|i|l|e|x|h]
--unicode=[default|invalid|locale|escape|hex|highlight]
يتحكم في عرض الأحرف متعددة البايتات المشفرة بـ UTF-8 في السلاسل النصية. القيمة الافتراضية (--unicode=default) هي عدم التعامل معها بشكل خاص، والاعتماد بدلاً من ذلك على إعداد الخيار --encoding. القيم الأخرى لهذا الخيار تقوم بتمكين --encoding=S تلقائيًا.

الخيار --unicode=invalid يعاملها كأحرف غير رسومية وبالتالي ليست جزءًا من سلسلة نصية صالحة. جميع الخيارات المتبقية تعاملها كأحرف سلاسل نصية صالحة.

الخيار --unicode=locale يعرضها في الإعداد المحلي الحالي، والذي قد يدعم ترميز UTF-8 أو لا يدعمه. الخيار --unicode=hex يعرضها كتسلسلات بايت ستة عشرية محاطة بأحرف <>. الخيار --unicode=escape يعرضها كتسلسلات هروب (\uxxxx) والخيار --unicode=highlight يعرضها كتسلسلات هروب مميزة باللون الأحمر (إذا كان مدعومًا بواسطة جهاز الإخراج). التلوين مخصص لجذب الانتباه إلى وجود تسلسلات يونيكود حيث قد لا تكون متوقعة.

-T bfdname
--target=bfdname
تحديد تنسيق رمز كائني آخر غير التنسيق الافتراضي لنظامك.
-v
-V
--version
طباعة رقم إصدار البرنامج على المخرجات القياسية والخروج.
-w
--include-all-whitespace
افتراضيًا، يتم تضمين أحرف الجدولة والمسافة في السلاسل النصية المعروضة، ولكن الأحرف الأخرى التي تتضمن المسافات البيضاء، مثل أحرف السطر الجديد وعودة العربة، لا يتم تضمينها. الخيار -w يغير هذا بحيث يتم اعتبار جميع أحرف المسافات البيضاء جزءًا من سلسلة نصية.
-s
--output-separator
افتراضيًا، يتم تحديد السلاسل النصية للمخرجات بفاصل سطر جديد. يسمح هذا الخيار بتوفير أي سلسلة نصية لاستخدامها كفاصل سجل الإخراج. مفيد مع --include-all-whitespace حيث قد تحتوي السلاسل النصية على أسطر جديدة داخليًا.
@file
قراءة خيارات سطر الأوامر من file. يتم إدراج الخيارات المقروءة في مكان خيار @file الأصلي. إذا كان file غير موجود، أو لا يمكن قراءته، فسيتم التعامل مع الخيار حرفيًا، ولن تتم إزالته.

يتم فصل الخيارات في file عن طريق المسافات البيضاء. يمكن تضمين حرف مسافة بيضاء في خيار عن طريق إحاطة الخيار بالكامل إما بعلامات اقتباس مفردة أو مزدوجة. يمكن تضمين أي حرف (بما في ذلك الشرطة المائلة العكسية) عن طريق وضع الشرطة المائلة العكسية قبل الحرف المراد تضمينه. قد يحتوي file نفسه على خيارات @file إضافية؛ سيتم معالجة أي خيارات من هذا القبيل بشكل متكرر.

strings

print the strings of printable characters in files

SYNOPSIS

strings [-a | -d] [-n min-len] [-t radix] [--all] [--debug] [--bytes=min-len] [--radix=radix] [--help] [--version] [file...

DESCRIPTION

The strings utility is a small utility that searches the given input files, or the archive files if any are specified, for sequences of printable characters.

A sequence of printable characters is defined to be at least four characters long. The sequences can be terminated by a newline character or an end-of-file character.

Strings can be printed from an object file that do not have any association with a symbol table. This means that strings inside binary blobs can be extracted.

OPTIONS

The order in which the options are presented to strings does not matter.

-a, -d, --all, --debug
Scan the entire file, including the symbol table. Normally, strings only scans the data sections of an object file.
-n min-len, --bytes=min-len
Set the minimum string length to min-len. The default is 4.
-t radix, --radix=radix
Print the string offset with each string. The radix can be one of the following:
d
Decimal.
o
Octal.
x
Hexadecimal.
i
Indirect notation (e.g. 0x10).
--help
Print a usage message on standard output and exit successfully.
--version
Print version information on standard output, and exit with a non-zero exit code if any specified files cannot be processed.
