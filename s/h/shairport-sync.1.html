NAME
shairport-sync - A metadata-driven AirPlay audio receiver.
SYNOPSIS

shairport-sync [-h|--help] [-V|--version]

DESCRIPTION

shairport-sync is a metadata-driven AirPlay audio receiver that outputs audio to the ALSA sound device.

CONFIGURATION FILE SETTINGS

The shairport-sync configuration is controlled by the configuration file /etc/shairport-sync.conf. The configuration file uses a simple key-value format.

metadata_interval
Sets the interval in seconds for updating metadata. Default is 1.
volume_control
Specifies the volume control method. Options: none, alsa, software. Default is alsa.
output_device
Sets the ALSA output device. Default is default.
buffer_time
Sets the buffer time in microseconds. Default is 100000.
latency
Sets the latency in microseconds. Default is 20000.
codec
Sets the audio codec. Options: aac, alac. Default is aac.
session_timeout
Sets the session timeout in seconds. Default is 60.
metadata_url
Sets the URL for metadata. Default is empty.
rsa_keys
Specifies the directory containing RSA keys. Default is /etc/shairport-sync/keys.
password
Sets the AirPlay password. Default is empty.
log_level
Sets the log level. Options: error, warning, info, debug. Default is info.
pipe_name
Sets the name of the pipe for metadata output. Default is empty.
use_ssrc
Enable or disable Silent Sync Recording. Options: yes, no. Default is no.
disable_rtp_trim
Disable RTP trim. Options: yes, no. Default is no.
auto_stop_timeout
Sets the auto-stop timeout in seconds. Default is 300.
check_interval
Sets the check interval in seconds. Default is 30.
timeout
Sets the timeout in seconds. Default is 5.
discoveryd_interval
Sets the discoveryd interval in seconds. Default is 60.
allow_docker
Allow Docker. Options: yes, no. Default is no.
OPTIONS
-h, --help
Show help message and exit.
-V, --version
Show program version and exit.
PROGRAM OPTIONS

These options can be used to override settings in the configuration file.

--config <file>
Use the specified configuration file.
--device <device>
Use the specified ALSA output device.
--volume-control <method>
Use the specified volume control method (none, alsa, software).
--codec <codec>
Use the specified audio codec (aac, alac).
--password <password>
Set the AirPlay password.
--log-level <level>
Set the log level (error, warning, info, debug).
--pipe-name <name>
Set the name of the pipe for metadata output.
--use-ssrc <yes|no>
Enable or disable Silent Sync Recording.
--disable-rtp-trim <yes|no>
Disable RTP trim.
--auto-stop-timeout <seconds>
Set the auto-stop timeout.
--check-interval <seconds>
Set the check interval.
--timeout <seconds>
Set the timeout.
--discoveryd-interval <seconds>
Set the discoveryd interval.
--allow-docker <yes|no>
Allow Docker.
AUDIO BACKEND OPTIONS

These options are specific to the audio backend.

--buffer-time <microseconds>
Set the buffer time.
--latency <microseconds>
Set the latency.
--metadata-url <url>
Set the URL for metadata.
--rsa-keys <directory>
Set the directory containing RSA keys.
EXAMPLES

Start shairport-sync with default settings:

shairport-sync

Start shairport-sync with a specific ALSA device and AAC codec:

shairport-sync --device hw:0 --codec aac

Start shairport-sync with software volume control and a password:

shairport-sync --volume-control software --password mysecretpassword
CREDITS

This program is based on the original ShairPort by James Conger.

Many thanks to the contributors to the Shairport Sync project.

COMMENTS

For more detailed information and advanced configuration options, please refer to the official Shairport Sync documentation.
