FBB::SharedSegment(3bobcat) بيانات الذاكرة المشتركة FBB::SharedSegment(3bobcat)

الاسم

FBB::SharedSegment - بنية بيانات الذاكرة المشتركة

الملخص

#include <bobcat/sharedsegment>
خيار الربط: -lbobcat

الوصف

الفئة FBB::SharedSegment تنفذ بنية بيانات الذاكرة المشتركة المستخدمة بواسطة فئات الذاكرة المشتركة في Bobcat. فئة SharedMemory في Bobcat تصل إلى مقطع ذاكرة مشترك أو تعرفه، متحكمة في جميع عمليات القراءة والكتابة الخاصة به.

المقدار المطلوب من الذاكرة المشتركة هو دائمًا حد أدنى للمقدار الأقصى من الذاكرة المشتركة الذي قد يصبح متاحًا في النهاية. عند تعريف كائن SharedSegment، لا يتم تخصيص كل الذاكرة المشتركة المتاحة له على الفور. سيتم تخصيص الذاكرة المشتركة بواسطة كائن SharedSegment عند الحاجة (حتى حد أقصى محسوب).

كمثال تخيلي: لنفترض أنه تم طلب 100 كيلوبايت من الذاكرة، فإن كائن SharedSegment يحتفظ بجدول، على سبيل المثال، 10 إدخالات، كل منها يتحكم في الوصول إلى كتلة ذاكرة مشتركة بحجم 10 كيلوبايت. هذه الكتل بحجم 10 كيلوبايت لا يتم تخصيصها على الفور، ولكنها تصبح متاحة بمجرد أن يقرأ البرنامج من عناوين تقع في قطاعات البيانات هذه أو يكتب إليها.

لذلك، تحدد الفئة SharedSegment بوابة، تتحكم في الوصول إلى وتخصيص قطاعات بيانات الذاكرة المشتركة المطلوبة. يتكون الجدول المذكور من قيم nBlocks SharedBlock (sharedblock(3bobcat))، توفر أقفالًا (mutexes) ومعرفات لقطاعات بيانات الذاكرة المشتركة. تتحكم الأقفال في العملية التي لديها وصول إلى جزء معين من ذاكرة البيانات المشتركة، والمعرفات إما -1، مما يعني أنه لم يتم تخصيص قطاعات بيانات الذاكرة المشتركة الخاصة بها بعد، أو أنها تحتوي على معرفات لقطاعات بيانات الذاكرة المشتركة المعرفة.

المسؤولية الوحيدة للفئة SharedSegment هي توفير الإطار كما هو موصوف. عند استخدامها بواسطة كائن FBB::SharedMemory، قد تحصل العمليات المختلفة على وصول إلى أجزاء مختلفة من بيانات الذاكرة المشتركة دون التأثير على عمليات القراءة والكتابة الخاصة ببعضها البعض.

لم يتم تعريف منشئات عامة متاحة للفئة SharedSegment. دالة عضو ثابتة create (انظر أدناه) متاحة، وتعيد مؤشرًا إلى مقطع ذاكرة مشترك، تم فيه تعريف SharedSegment.

o

o
bool truncate(std::streamsize offset):
بعد استدعاء nReadableLock، إذا لم يتجاوز offset القيمة التي تعيدها nReadable، يتم تغيير nReadable إلى offset ويتم إرجاع true. بخلاف ذلك، يتم إرجاع false، ولم يتم تغيير القيمة التي تعيدها nReadable. قبل الإرجاع، يتم استدعاء nReadableUnlock.

تحرر القفل على مقطع بيانات الذاكرة المشتركة idx. إذا كانت العملية الحالية لا تمتلك قفل كتلة بيانات الذاكرة المشتركة idx، فلا يحدث شيء وتعود الدالة على الفور.
o

يتم تحديث عدد البايتات التي يمكن استرجاعها من الذاكرة المشتركة إلى max(nReadable(), offset).

FUNCTIONS MEMBER

o
void attach(int id, Type *&sharedPtr, size_t size, mode_t mode = S_IRUSR | S_IWUSR | S_IRGRP | S_IWGRP | S_IROTH | S_IWOTH):
This member is defined as a member template. It is used to attach a shared memory segment having ID id to the calling process’s memory space. A pointer to the attached memory is returned in sharedPtr. If the segment does not exist, it is created with the specified size. The access rights for the segment are defined by mode. The default mode gives read and write permissions to the owner, group and others. It is recommended to use octal numbers (e.g. 0666) for mode. Consult the man page chmod(1)) for the definition of access rights for the owner, the group and others).
To return the shared segment to the operating system deleteSegment should be used.
An FBB::Exception is thrown if the shared memory data segment could not be created.
o
void deleteSegment(int id):
The shared memory segment having ID id is deleted. After calling deleteSegment shared memory segment id doesn’t exist anymore. The id can be the shared memory ID of any segment for which the current user has write permissions.
An FBB::Exception is thrown if shared memory data segment id could not be deleted.
o
Type *detach(Type *sharedPtr, bool requireOK = true):
This member is defined as a member template. It expects a pointer to a shared memory segment, previously mapped on the calling process’s memory space by attach, and detaches it from the process’s memory space, returning 0.
By default, detaching the memory must succeed or an FBB::Exception is thrown. Throwing an exception on failure can be prevented by passing false as the member’s second argument.
Note that detaching a memory segment does not destroy it. To return a shared segment to the operating system deleteSegment should be used.
o
size_t size(int id):
The size (in bytes) of shared memory data block having ID id is returned.
An FBB::Exception is thrown if the size of segment id could not be determined.
