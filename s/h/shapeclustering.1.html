shapeclustering(1)

الحزمة: tesseract

التراخيص: APACHE

SHAPECLUSTERING(1)   SHAPECLUSTERING(1)

الاسم

shapeclustering - تجميع الأشكال لتدريب Tesseract

الموجز

shapeclustering -D directory_output -U unicharset -O mfunicharset -F font_props -X xheights FILE...

الوصف

يأخذ shapeclustering(1) ملفات الميزات المستخرجة .tr (الناتجة عن تشغيل tesseract(1) في وضع خاص من ملفات الصناديق) وينتج ملف shapetable ومجموعة أحرف محسنة. هذا البرنامج لا يزال تجريبيًا، ولا يلزم (حتى الآن) لتدريب Tesseract.

الخيارات

-U FILE

مجموعة الأحرف الناتجة عن unicharset_extractor(1).

-D dir

الدليل لكتابة ملفات الإخراج إليه.

-F font_properties_file

(الإدخال) ملف خصائص الخط، حيث كل سطر بالشكل التالي، حيث كل حقل بخلاف اسم الخط هو 0 أو 1: 
'اسم_الخط' 'مائل' 'غامق' 'مسافة_ثابتة' 'مسنن' 'كسري'

-X xheights_file

(الإدخال) ملف ارتفاعات x، كل سطر بالشكل التالي، حيث يتم حساب ارتفاع x على أنه ارتفاع x بالبكسل لحرف مرسوم بحجم 32 نقطة بدقة 300 نقطة في البوصة. [ أي، إذا كان ارتفاع x الأساسي + الصاعدات + الهابطات = 133، فما مقدار ارتفاع x؟ ] 
'اسم_الخط' 'ارتفاع_x'

-O FILE

مجموعة الأحرف الإخراج التي سيتم تقديمها إلى combine_tessdata(1).
