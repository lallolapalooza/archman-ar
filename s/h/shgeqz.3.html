NAME

shgeqz - Schur factorization for upper triangular matrices

SYNOPSIS

 SUBROUTINE SHGEQZ( JOBQZ, COMPZ, N, ILO, IHI, A, LDA, B, LDB, ALPHA,
&                   BETA, Q, LDQ, Z, LDZ, WORK, LWORK, INFO )

C/Fortran Interface

 SUBROUTINE shgeqz( jobqz, compz, n, ilo, ihi, a, lda, b, ldb, alpha,
&                   beta, q, ldq, z, ldz, work, lwork, info )

The subroutine shgeqz computes the generalized Schur factorization of two upper triangular matrices.

Function/Subroutine Documentation

JOBQZ
 JOBQZ is CHARACTER*1
 Options indicate the transformations to be applied.
 JOBQZ = 'E': compute the generalized Schur factorization
          A = Q*S*Z**T, B = Q*T*Z**T
 JOBQZ = 'S': compute the generalized Schur factorization and
          also the generalized eigenvalues
 else: no result is returned
COMPZ
 COMPZ is CHARACTER*1
 Options indicate the orthogonal transformations to be applied.
 COMPZ = 'V': compute the matrices Q and Z of Schur vectors.
          The matrices Q and Z have unitary columns containing the
          left and right Schur vectors respectively.
 COMPZ = 'I': compute the matrix Z of right Schur vectors.
          The matrix Z has unitary columns containing the right
          Schur vectors.
 COMPZ = 'N': no Schur vectors are computed.
N
 N is INTEGER
 The order of the matrices A and B. N >= 0.
ILO
 ILO is INTEGER
 IHI is INTEGER
 The integers ILO and IHI specify the range of indices in the
 diagonal of A and B for which the generalized Schur factorization
 is desired. The Schur factorization is computed for the submatrix
 A(ILO:IHI, ILO:IHI) and B(ILO:IHI, ILO:IHI).
 Usually, ILO = 1 and IHI = N.
 Range of ILO/IHI: 1 <= ILO <= IHI <= N, if N > 0, and ILO=1, IHI=0 if N=0.
A
 A is REAL array, dimension (LDA, N)
 On entry, A contains the first upper triangular matrix.
 On exit, A contains the first matrix in the generalized Schur
 factorization. If COMPZ = 'N', A is upper triangular. If COMPZ = 'V'
 or 'I', A is upper triangular. If JOBQZ = 'S', the diagonal elements
 of A contain the real parts of the generalized eigenvalues, and the
 elements of ALPHA contain the generalized eigenvalues.
 If JOBQZ = 'E', the eigenvalues are returned in ALPHA and BETA.
LDA
 LDA is INTEGER
 The leading dimension of the array A. LDA >= max(1, N).
B
 B is REAL array, dimension (LDB, N)
 On entry, B contains the second upper triangular matrix.
 On exit, B contains the second matrix in the generalized Schur
 factorization. If COMPZ = 'N', B is upper triangular. If COMPZ = 'V'
 or 'I', B is upper triangular. If JOBQZ = 'S', the diagonal elements
 of B contain the real parts of the generalized eigenvalues, and the
 elements of BETA contain the generalized eigenvalues.
 If JOBQZ = 'E', the eigenvalues are returned in ALPHA and BETA.
LDB
 LDB is INTEGER
 The leading dimension of the array B. LDB >= max(1, N).
ALPHA
 ALPHA is REAL array, dimension (N)
 BETA is REAL array, dimension (N)
 On exit, ALPHA and BETA contain the generalized eigenvalues of A and B.
 alpha(i) / beta(i) = lambda(i) for i = 1, ..., N.
 alpha and beta may be complex if the eigenvalues are complex.
Q
 Q is REAL array, dimension (LDQ, N)
 If COMPZ = 'V', Q contains the orthogonal matrix of left Schur vectors.
 If COMPZ = 'N', the array Q is not referenced.
LDQ
 LDQ is INTEGER
 The leading dimension of the array Q. LDQ >= 1.
 If COMPZ = 'V', then LDQ >= N.
Z
 Z is REAL array, dimension (LDZ, N)
 If COMPZ = 'V', Z contains the orthogonal matrix of right Schur vectors.
 If COMPZ = 'I', Z contains the orthogonal matrix of right Schur vectors.
 If COMPZ = 'N', the array Z is not referenced.
LDZ
 LDZ is INTEGER
 The leading dimension of the array Z. LDZ >= 1.
 If COMPZ = 'V' or 'I', then LDZ >= N.
WORK
 WORK is REAL array, dimension (MAX(1,LWORK))
 On exit, if INFO >= 0, WORK(1) returns the optimal LWORK.
LWORK
 LWORK is INTEGER
 The dimension of the array WORK. LWORK >= max(1,N).
 If LWORK = -1, then a workspace query is assumed; the routine
 only calculates the optimal size of the WORK array, returns
 this value as the first entry of the WORK array, and no error
 message related to LWORK is issued by XERBLA.
INFO
 INFO is INTEGER
 = 0: successful exit
 < 0: if INFO = -i, the i-th argument had an illegal value
 = 1,...,N: the QZ iteration did not converge.  (H,T) is not
            in Schur form, but ALPHAR(i), ALPHAI(i), and
            BETA(i), i=INFO+1,...,N should be correct.
 = N+1,...,2*N: the shift calculation failed.  (H,T) is not
            in Schur form, but ALPHAR(i), ALPHAI(i), and
            BETA(i), i=INFO-N+1,...,N should be correct.
