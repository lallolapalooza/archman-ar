shmem_alltoall32(3)، shmem_alltoall64(3)، shmem_alltoalls32(3)، shmem_alltoalls64(3) - روتين جماعي حيث يقوم كل PE بتبادل كمية ثابتة من البيانات مع جميع PEs الأخرى في المجموعة النشطة

ملخص

الوصف

روتينات shmem_alltoalls هي روتينات جماعية. يقوم كل PE في المجموعة النشطة بتبادل nelems عناصر بيانات متتابعة بحجم 32 بت (لـ shmem_alltoalls32) أو 64 بت (لـ shmem_alltoalls64) مع جميع PEs الأخرى في المجموعة. يجب أن يكون كل من الخطوات dst و sst أكبر من أو يساوي 1. يتم وضع الكتلة j-th التي ترسلها PE i إلى PE j في الكتلة i-th التي ترسلها في كائن بيانات الوجهة على PE j. كما هو الحال مع جميع روتينات OpenSHMEM الجماعية، تفترض هذه الروتينات أن PEs الموجودة في المجموعة النشطة فقط هي التي تستدعي الروتين. إذا استدعت PE غير موجودة في المجموعة النشطة روتين OpenSHMEM جماعي، فإن السلوك غير محدد. يجب أن تكون قيم الوسائط dst و sst و nelems و PE_start و logPE_stride و PE_size متساوية على جميع PEs في المجموعة النشطة. يجب تمرير نفس كائنات بيانات الوجهة والمصدر، ونفس مصفوفة العمل pSync إلى جميع PEs في المجموعة النشطة. قبل أي استدعاء PE لروتين shmem_alltoalls، يجب استيفاء الشروط التالية (غالباً ما يكون التزامن عبر حاجز أو طريقة أخرى ضروريًا لضمان ذلك): مصفوفة pSync على جميع PEs في المجموعة النشطة ليست قيد الاستخدام من استدعاء سابق لروتين shmem_alltoalls. كائن بيانات الوجهة على جميع PEs في المجموعة النشطة جاهز لاستقبال بيانات shmem_alltoalls. عند العودة من روتين shmem_alltoalls، يكون ما يلي صحيحًا لـ PE المحلي: تم تحديث كائن بيانات الوجهة المتماثل الخاص به بالكامل وتم نسخ البيانات خارج كائن بيانات المصدر. تم استعادة القيم الموجودة في مصفوفة pSync إلى القيم الأصلية.

الوسائط كما يلي:

كائن بيانات متماثل بأحد أنواع البيانات التالية:

shmem_alltoall32: أي نوع غير حرفي له
حجم عنصر 32 بت. لا يُسمح بأنواع مشتقة من Fortran أو هياكل C/C++.
shmem_alltoall64: أي نوع غير حرفي له حجم
عنصر 64 بت. لا يُسمح بأنواع مشتقة من Fortran أو هياكل C/C++.

target: كائن بيانات متماثل كبير بما يكفي لاستقبال إجمالي مجموع nelems عناصر من كل PE في المجموعة النشطة.

source
كائن بيانات متماثل يحتوي على nelems عناصر بيانات لكل PE في المجموعة النشطة، مرتبة حسب PE الوجهة.
dst
الخطوة بين العناصر المتتالية لكائن بيانات الوجهة. يتم قياس الخطوة بواسطة حجم العنصر. القيمة 1 تشير إلى بيانات متجاورة. يجب أن يكون dst من نوع ptrdiff_t. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضي.
sst
الخطوة بين العناصر المتتالية لكائن بيانات المصدر. يتم قياس الخطوة بواسطة حجم العنصر. القيمة 1 تشير إلى بيانات متجاورة. يجب أن يكون sst من نوع ptrdiff_t. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضي.
nelems
عدد العناصر المراد تبادلها لكل PE. يجب أن يكون nelems من نوع size_t لـ C/C++. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضي.
PE_start
أدنى رقم PE افتراضي للمجموعة النشطة من PEs. يجب أن يكون PE_start من نوع عدد صحيح. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضي.
logPE_stride
اللوغاريتم (الأساس 2) للخطوة بين أرقام PE الافتراضية المتتالية في المجموعة النشطة. يجب أن يكون log_PE_stride من نوع عدد صحيح. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضي.
PE_size
عدد PEs في المجموعة النشطة. يجب أن يكون PE_size من نوع عدد صحيح. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضي.
pSync
مصفوفة عمل متماثلة. في C/C++، يجب أن يكون pSync من نوع long وحجم _SHMEM_ALLTOALL_SYNC_SIZE. في Fortran، يجب أن يكون pSync من نوع عدد صحيح وحجم SHMEM_ALLTOALL_SYNC_SIZE. يجب تهيئة كل عنصر من هذه المصفوفة بالقيمة _SHMEM_SYNC_VALUE (في C/C++) أو SHMEM_SYNC_VALUE (في Fortran) قبل أن تدخل أي من PEs في المجموعة النشطة shmem_barrier().

عند العودة من روتين shmem_alltoalls، يكون ما يلي صحيحًا لـ PE المحلي: تم تحديث كائن بيانات الوجهة المتماثل الخاص به بالكامل وتم نسخ البيانات خارج كائن بيانات المصدر. تم استعادة القيم الموجودة في مصفوفة pSync إلى القيم الأصلية.

يجب أن تكون قيم الوسائط PE_root و PE_start و logPE_stride و PE_size متساوية على جميع PEs في المجموعة النشطة. يجب تمرير نفس كائنات بيانات الوجهة والمصدر، ونفس مصفوفة العمل pSync إلى جميع PEs في المجموعة النشطة.

قبل أن تستدعي أي PE روتين alltoall، يجب عليك التأكد من استيفاء الشروط التالية (غالباً ما يكون التزامن عبر حاجز أو طريقة أخرى ضروريًا لضمان ذلك): مصفوفة pSync على جميع PEs في المجموعة النشطة ليست قيد الاستخدام من استدعاء سابق لروتين alltoall. مصفوفة الوجهة على جميع PEs في المجموعة النشطة جاهزة لاستقبال بيانات alltoall.

ملاحظات

تم تعريف مصطلحي "جمعي" و "متماثل" في intro_shmem(3).

تقوم جميع روتينات SHMEM alltoall باستعادة pSync إلى محتوياتها الأصلية. لا تتطلب الاستدعاءات المتعددة لروتينات SHMEM التي تستخدم نفس مصفوفة pSync إعادة تهيئة pSync بعد الاستدعاء الأول.

يجب عليك التأكد من أن مصفوفة pSync لا يتم تحديثها بواسطة أي PE في المجموعة النشطة أثناء مشاركة أي من PEs في معالجة استدعاء لروتين SHMEM بث. كن حذرًا لتجنب هذه المواقف: إذا تمت تهيئة مصفوفة pSync في وقت التشغيل، فإن بعض أنواع التزامن مطلوبة لضمان أن جميع PEs في مجموعة العمل قد قامت بتهيئة pSync قبل أن يدخل أي منها روتين SHMEM تم استدعاؤه باستخدام مصفوفة مزامنة pSync. يمكن إعادة استخدام مصفوفة pSync في روتين SHMEM بث لاحق فقط إذا لم يكن أي من PEs في المجموعة النشطة لا يزال يعالج استدعاء روتين SHMEM alltoall سابق استخدم نفس مصفوفة pSync. بشكل عام، لا يمكن ضمان ذلك إلا عن طريق القيام ببعض أنواع التزامن. ومع ذلك، في الحالة الخاصة لروتينات SHMEM التي يتم استدعاؤها بنفس المجموعة النشطة، يمكنك تخصيص مصفوفتي pSync والتبديل بينهما في الاستدعاءات المتتالية.

shmem_alltoalls32, shmem_alltoalls64, shmem_long_alltoalls32, shmem_longlong_alltoalls64 

#include <memory.h>

void shmem_alltoalls32(void *target, const void *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);
void shmem_alltoalls64(void *target, const void *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);
void shmem_long_alltoalls32(long *target, const long *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);
void shmem_longlong_alltoalls64(long long *target, const long long *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);

DESCRIPTION

The symmetric distributed memory parallel programming model, often called Bulk Synchronous Parallel (BSP) model, has been implemented by the SHMEM library. The SHMEM library has been designed for parallel applications that employ a large number of processors.

The collectives are assumed to be invoked symmetrically by all processing elements (PEs) participating in the communication. For the collective operations, the library assumes that the PEs invoke the calls with the same arguments. The synchronization is also part of the operation. All PEs will return from the collective call only after all PEs have completed and returned from the collective call.

The SHMEM collective communication routines are:

shmem_allreduce(3), shmem_broadcast(3), shmem_collect(3), shmem_fcollect(3), shmem_gather(3), shmem_gcollect(3), shmem_reduce(3), shmem_reduce_scatter(3), shmem_scan(3), shmem_scatter(3).

The shmem_alltoalls32 routine provides a means to exchange data among all the PEs in a Cartesian topology.

The function signature is:

void shmem_alltoalls32(void *target, const void *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);
void shmem_alltoalls64(void *target, const void *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);
void shmem_long_alltoalls32(long *target, const long *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);
void shmem_longlong_alltoalls64(long long *target, const long long *source, size_t nelems, int PE_size, int PE_stride, int PE_count, long pSync[]);

Where:

target
A pointer to the symmetric memory address where the data is to be received.
source
A pointer to the symmetric memory address from which the data is to be sent.
nelems
The number of elements to be exchanged.
PE_size
Specifies the number of PEs in the target dimension of the Cartesian topology. For SHMEM versions prior to 1.1, this argument was used to specify the number of PEs for the communication. For SHMEM versions 1.1 and later, it is used to specify the number of PEs in the target dimension of the Cartesian topology.
PE_stride
Specifies the stride between PEs in the target dimension of the Cartesian topology. For SHMEM versions prior to 1.1, this argument was unused. For SHMEM versions 1.1 and later, it is used to specify the stride between PEs in the target dimension.
PE_count
Specifies the number of PEs to participate in the communication. This argument is used in conjunction with PE_size and PE_stride to define the set of PEs that will participate in the communication. For SHMEM versions prior to 1.1, this argument was used to specify the number of PEs for the communication. For SHMEM versions 1.1 and later, it is used to specify the number of dimensions participating in the communication.
pSync
A pointer to a synchronization array. This array must be a symmetric array and must contain at least the number of elements specified by SHMEM_ALLTOALLS_SYNC_SIZE. Each element of the synchronization array must be initialized to SHMEM_SYNC_VALUE.

NOTES

All SHMEM communication routines are assumed to be invoked symmetrically by all PEs. That is, each PE must invoke the same routine with the same arguments. The collectives are blocking calls and the function will not return until the operation is complete. This means that all PEs will complete the call at approximately the same time.

The shmem_alltoalls32 routine is equivalent to calling:

shmem_alltoalls64(target, source, nelems, PE_size, PE_stride, PE_count, pSync);

when the data type is 32-bit.

The shmem_long_alltoalls32 and shmem_longlong_alltoalls64 routines are provided for convenience when working with 32-bit or 64-bit integer types, respectively.

The value of PE_size, PE_stride, and PE_count arguments define the set of PEs that will participate in the communication. If PE_count is greater than 1, then the PEs involved in the communication form a Cartesian topology. The PEs are indexed by PE_stride, PE_size, and PE_count. The specific PEs involved are determined by the combination of these arguments.

The synchronization array pSync is used to ensure that all PEs have reached a common point in the execution of the program. This is essential for the correct operation of the collective communication routines.

The size of the synchronization array is determined by SHMEM_ALLTOALLS_SYNC_SIZE. This macro is defined in the <memory.h> header file.

EXAMPLES

/*
 * Example for shmem_alltoalls64
 */
#include <stdio.h>
#include <stdlib.h>
#include <mpp/shmem.h>

#define COUNT 100

int main(void) {
    long *dest;
    long *source;
    long *pSync;
    int pe, i;

    /* Allocate symmetric memory */
    dest = (long *)shmem_malloc(COUNT * shmem_n_pes() * sizeof(long));
    source = (long *)shmem_malloc(COUNT * shmem_n_pes() * sizeof(long));
    pSync = (long *)shmem_malloc(SHMEM_ALLTOALLS_SYNC_SIZE * sizeof(long));

    /* Initialize source data */
    for (pe=0; pe <shmem_n_pes(); pe++){
        for (i=0; i<count; i++){
            source[(pe*count)+i] = shmem_my_pe() + pe;
            dest[(pe*count)+i] = 9999;
        }
    }

    /* Initialize synchronization array */
    for (i=0; i< SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* Wait for all PEs to initialize pSync */
    shmem_barrier_all();

    /* Perform the alltoall communication */
    shmem_alltoalls64(dest, source, 1, 1, count, 0, 0, shmem_n_pes(), pSync);

    /* Verify results */
    for (pe=0; pe<shmem_n_pes(); pe++) {
        for (i=0; i<count; i++){
            if (dest[(pe*count)+i] != shmem_my_pe() + pe) {
                printf("[%d] ERROR: dest[%d]=%ld, should be %d\n",
                       shmem_my_pe(), (pe*count)+i, dest[(pe*count)+i],
                       shmem_n_pes() + pe);
                shmem_global_exit(1);
            }
        }
    }

    shmem_barrier_all();

    /* Free symmetric memory */
    shmem_free(dest);
    shmem_free(source);
    shmem_free(pSync);

    shmem_finalize();
    return 0;
}
