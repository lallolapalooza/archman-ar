shmem_long_cswap(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_LONG_CSWAP(3) Open MPI SHMEM_LONG_CSWAP(3)

shmem_int_cswap(3)، shmem_int4_cswap(3)، shmem_int8_cswap(3)، shmem_long_cswap(3)، shmem_longlong_cswap(3) - تقوم بتبديل شرطي ذري لكائن بيانات عن بعد

الشكل العام

C أو C++:

#include <mpp/shmem.h>
int shmem_int_cswap(int *target, int cond, int value, int pe)
long shmem_long_cswap(long *target, long cond, long value,
  int pe)
long long shmem_longlong_cswap(longlong *target,
  longlong cond, longlong value, int pe)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER pe
INTEGER(KIND=4) SHMEM_INT4_CSWAP
ires = SHMEM_INT4_CSWAP(target, cond, value, pe)
INTEGER(KIND=8) SHMEM_INT8_CSWAP
ires = SHMEM_INT8_CSWAP(target, cond, value, pe)

الوصف

تقوم روتينات التبديل الشرطي بتحديث كائن بيانات مستهدف بشكل شرطي على عنصر معالجة (PE) عشوائي وإرجاع المحتويات السابقة لكائن البيانات في عملية ذرية واحدة.

الوسائط هي كما يلي:

target
كائن البيانات الصحيح القابل للوصول عن بعد ليتم تحديثه على PE البعيد. إذا كنت تستخدم C/C++، فيجب أن يتطابق نوع target مع النوع المشار إليه في قسم الشكل العام. إذا كنت تستخدم مترجم Fortran، فيجب أن يكون من نوع عدد صحيح بحجم عنصر 4 بايت لـ SHMEM_INT4_ADD و 8 بايت لـ SHMEM_INT8_ADD.
value
القيمة التي سيتم إضافتها بشكل ذري إلى target. إذا كنت تستخدم C/C++، فيجب أن يتطابق نوع value مع النوع المشار إليه في قسم الشكل العام. إذا كنت تستخدم Fortran، فيجب أن يكون من نوع عدد صحيح بحجم عنصر يتطابق مع target.
pe
عدد صحيح يشير إلى رقم PE الذي سيتم تحديث target عليه. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضية.
target
كائن البيانات الصحيح القابل للوصول عن بعد ليتم تحديثه على PE البعيد. إذا كنت تستخدم C/C++، فيجب أن يتطابق نوع بيانات target مع النوع المشار إليه في قسم الشكل العام. إذا كنت تستخدم Fortran، فيجب أن يكون من النوع التالي:

SHMEM_INT4_CSWAP: عدد صحيح 4 بايت

SHMEM_INT8_CSWAP: عدد صحيح 8 بايت

cond
تتم مقارنة cond مع قيمة target البعيدة. إذا كانت cond و target البعيد متساويين، فسيتم تبديل value في target البعيد. بخلاف ذلك، يبقى target البعيد دون تغيير. في كلتا الحالتين، يتم إرجاع القيمة القديمة لـ target البعيد كقيمة إرجاع للدالة. يجب أن يكون cond من نفس نوع بيانات target.
value
القيمة التي سيتم كتابتها بشكل ذري إلى PE البعيد. يجب أن تكون value بنفس نوع بيانات target.
pe
عدد صحيح يشير إلى رقم PE الذي سيتم تحديث target عليه. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضية.

ملاحظات

يتم تعريف المصطلح "قابل للوصول عن بعد" في intro_shmem(3).

قيم الإرجاع

المحتويات التي كانت في كائن البيانات target في PE البعيد قبل التبديل الشرطي.

أمثلة

يضمن الاستدعاء التالي أن أول PE ينفذ التبديل الشرطي سينجح في كتابة رقم PE الخاص به إلى race_winner على PE 0.

main()
{
  static int race_winner = -1;
  int oldval;
  shmem_init();
  oldval = shmem_int_cswap(&race_winner, -1, shmem_my_pe(), 0);
  if (oldval == -1)
    printf("pe %d was first\n",shmem_my_pe());
}
