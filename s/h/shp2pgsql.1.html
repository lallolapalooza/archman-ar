shp2pgsql(1)

NAME

shp2pgsql - PostGIS shapefile import command line utility

SYNOPSIS

shp2pgsql [OPTIONS] shapefile [schema.table]

DESCRIPTION

shp2pgsql is a command line utility that reads a shapefile and converts it into SQL statements that can be used to load the data into a PostGIS-enabled PostgreSQL database.

OPTIONS

-a, --append
Append the shapefile data to an existing table. If the table does not exist, it will be created.
-c, --create
Create a new table and load the shapefile data into it. This is the default behavior if the table does not exist.
-d, --delete
Delete all rows from the table before loading the shapefile data. This option implies --create if the table does not exist.
-D, --proj
Add a SRID to the table definition. The SRID is determined from the projection file (.prj) associated with the shapefile.
-g geom_column, --geometry-column=geom_column
The name of the geometry column in the table. Defaults to 'geom'.
-I, --index
Create a spatial index on the geometry column after loading the data.
-k, --keep-ెం
Keep the original column names from the shapefile. By default, shp2pgsql uses shortened names to avoid exceeding PostgreSQL's identifier length limits.
-l srid, --srid=srid
Force the SRID of the geometry column to be srid. This overrides any SRID found in the .prj file.
-m srid, --mex-srid=srid
Set the SRID for geometries that do not have one defined. If this option is not specified, geometries without an SRID will be created with an SRID of 0.
-n layer_name, --layer-name=layer_name
Create a table with the specified layer name. If not specified, the table name is derived from the shapefile name.
-s srid, --spatial-reference=srid
Set the SRID for all geometries in the shapefile. This option overrides any SRID found in the .prj file and forces all geometries to use the specified SRID.
-S, --use-new-spatial-index
Use the new GiST spatial index type (PostGIS 1.0 and later). This is the default behavior.
-t precision, --precision=precision
Set the precision of the Z coordinate. Defaults to 8.
-u srid, --update-srid=srid
Update the SRID of all geometries in the table to srid. This option should be used with caution as it modifies existing data.
-W encoding, --work-encoding=encoding
Specify the character encoding of the shapefile. Defaults to UTF-8.
--
Signals the end of options. Any subsequent arguments are treated as positional arguments.

ARGUMENTS

shapefile
The path to the input shapefile (e.g., world_borders.shp).
schema.table
The name of the PostgreSQL table to create or load data into. If omitted, the table name is derived from the shapefile name.

EXAMPLES

Create a new table named 'states' from 'states.shp' with spatial index:
shp2pgsql -c -I states.shp states | psql -d gisdb

Append data from 'cities.shp' to an existing table 'locations':
shp2pgsql -a cities.shp locations | psql -d gisdb

Create a table with a specific SRID:
shp2pgsql -c -s 4326 -D roads.shp | psql -d gisdb

Load data from a shapefile with a different encoding:
shp2pgsql -W LATIN1 -c countries.shp | psql -d gisdb

shp2pgsql(1)

الاسم

shp2pgsql - أداة سطر أوامر لاستيراد ملفات الشكل (shapefile) إلى PostGIS

الصيغة

shp2pgsql [خيارات] ملف_الشكل [مخطط.جدول]

الوصف

shp2pgsql هي أداة سطر أوامر تقرأ ملف شكل (shapefile) وتحوله إلى عبارات SQL يمكن استخدامها لتحميل البيانات إلى قاعدة بيانات PostgreSQL ممكّنة لـ PostGIS.

الخيارات

-a, --append
إلحاق بيانات ملف الشكل بجدول موجود. إذا لم يكن الجدول موجودًا، فسيتم إنشاؤه.
-c, --create
إنشاء جدول جديد وتحميل بيانات ملف الشكل فيه. هذا هو السلوك الافتراضي إذا لم يكن الجدول موجودًا.
-d, --delete
حذف كافة الصفوف من الجدول قبل تحميل بيانات ملف الشكل. يتضمن هذا الخيار --create إذا لم يكن الجدول موجودًا.
-D, --proj
إضافة SRID إلى تعريف الجدول. يتم تحديد SRID من ملف الإسقاط (.prj) المرتبط بملف الشكل.
-g عمود_هندسي, --geometry-column=عمود_هندسي
اسم عمود الهندسة في الجدول. الافتراضي هو 'geom'.
-I, --index
إنشاء فهرس مكاني على عمود الهندسة بعد تحميل البيانات.
-k, --keep-ెం
الاحتفاظ بأسماء الأعمدة الأصلية من ملف الشكل. افتراضيًا، يستخدم shp2pgsql أسماء مختصرة لتجنب تجاوز حدود طول المعرفات في PostgreSQL.
-l srid, --srid=srid
فرض SRID لعمود الهندسة ليكون srid. هذا يتجاوز أي SRID موجود في ملف .prj.
-m srid, --mex-srid=srid
تعيين SRID للهندسات التي لا تحتوي على SRID معرف. إذا لم يتم تحديد هذا الخيار، فسيتم إنشاء هندسات بدون SRID باستخدام SRID بقيمة 0.
-n اسم_الطبقة, --layer-name=اسم_الطبقة
إنشاء جدول بالاسم المحدد للطبقة. إذا لم يتم تحديده، فسيتم اشتقاق اسم الجدول من اسم ملف الشكل.
-s srid, --spatial-reference=srid
تعيين SRID لجميع الهندسات في ملف الشكل. يتجاوز هذا الخيار أي SRID موجود في ملف .prj ويجبر جميع الهندسات على استخدام SRID المحدد.
-S, --use-new-spatial-index
استخدام نوع الفهرس المكاني الجديد GiST (PostGIS 1.0 وما بعده). هذا هو السلوك الافتراضي.
-t دقة, --precision=دقة
تعيين دقة الإحداثي Z. الافتراضي هو 8.
-u srid, --update-srid=srid
تحديث SRID لجميع الهندسات في الجدول إلى srid. يجب استخدام هذا الخيار بحذر لأنه يعدل البيانات الموجودة.
-W ترميز, --work-encoding=ترميز
تحديد ترميز أحرف ملف الشكل. الافتراضي هو UTF-8.
--
يشير إلى نهاية الخيارات. سيتم التعامل مع أي وسيطات لاحقة على أنها وسيطات موضعية.

الوسيطات

ملف_الشكل
المسار إلى ملف الشكل المدخل (على سبيل المثال، world_borders.shp).
مخطط.جدول
اسم جدول PostgreSQL المراد إنشاؤه أو تحميل البيانات فيه. إذا تم حذفه، فسيتم اشتقاق اسم الجدول من اسم ملف الشكل.

أمثلة

إنشاء جدول جديد باسم 'states' من 'states.shp' مع فهرس مكاني:
shp2pgsql -c -I states.shp states | psql -d gisdb

إلحاق البيانات من 'cities.shp' بجدول موجود 'locations':
shp2pgsql -a cities.shp locations | psql -d gisdb

إنشاء جدول باستخدام SRID محدد:
shp2pgsql -c -s 4326 -D roads.shp | psql -d gisdb

تحميل البيانات من ملف شكل بترميز مختلف:
shp2pgsql -W LATIN1 -c countries.shp | psql -d gisdb
