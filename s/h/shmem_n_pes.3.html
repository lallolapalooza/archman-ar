SHMEM_N_PES(3) Open MPI SHMEM_N_PES(3)

_num_pes, _num_pes shmem_n_pes - يُعيد عدد عناصر المعالجة (PEs) المستخدمة لتشغيل التطبيق.

الملخص

C أو C++:

#include <mpp/shmem.h>
int _num_pes (void)
int shmem_n_pes (void)

Fortran:

include 'mpp/shmem.fh'
I = NUM_PES ()
I = SHMEM_N_PES ()

الوصف

num_pes() أو shmem_n_pes() تُعيد العدد الإجمالي لعناصر المعالجة (PEs) التي تعمل في التطبيق.

انظر أيضاً:

intro_shmem(3) shmem_my_pe(3) shmem_init(3)
