shmem_int_min_to_all(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SYNOPSIS

Fortran: call shmem_real8_min_to_all(target, source, nelems, PE_arg1, PE_arg2, logPeMap, pWrk, pSync)

C/C++: void shmem_int_min_to_all(int target[], const int source[], int nelems, int PE_arg1, int PE_arg2, int logPeMap, shmem_int_t pWrk[], long pSync[])

C/C++: void shmem_long_min_to_all(long target[], const long source[], int nelems, int PE_arg1, int PE_arg2, int logPeMap, shmem_long_t pWrk[], long pSync[])

C/C++: void shmem_real32_min_to_all(float target[], const float source[], int nelems, int PE_arg1, int PE_arg2, int logPeMap, shmem_real32_t pWrk[], long pSync[])

C/C++: void shmem_real64_min_to_all(double target[], const double source[], int nelems, int PE_arg1, int PE_arg2, int logPeMap, shmem_real64_t pWrk[], long pSync[])

C/C++: void shmem_complex32_min_to_all(float complex target[], const float complex source[], int nelems, int PE_arg1, int PE_arg2, int logPeMap, shmem_complex32_t pWrk[], long pSync[])

C/C++: void shmem_complex64_min_to_all(double complex target[], const double complex source[], int nelems, int PE_arg1, int PE_arg2, int logPeMap, shmem_complex64_t pWrk[], long pSync[])

DESCRIPTION

These collectives perform a global minimum reduction across a set of processing elements (PEs). The reduction is performed on the elements specified by nelems. The destination of the reduction is the target array on each PE. The source of the reduction is the source array on each PE.

The PE_arg1 and PE_arg2 arguments specify the range of PEs that participate in the reduction. The PEs are specified as PE_arg1, PE_arg1 + 1, ..., PE_arg2. The total number of PEs participating in the reduction is (PE_arg2 - PE_arg1 + 1).

The logPeMap argument specifies how the PEs are mapped to the reduction tree. A value of 0 indicates that the PEs are mapped contiguously. A value of k where k > 0 indicates that the PEs are mapped such that PE i is mapped to PE (i & -k). For a contiguous mapping, k would be equal to the number of PEs participating in the reduction.

The pWrk argument is a working array that is used by the collective operation. The size of this array depends on the type of the operation and the number of elements being reduced. The minimum required size for the working array is specified by the SHMEM constants SHMEM_REDUCE_MIN_WRKDATA_SIZE, SHMEM_INT_REDUCE_MIN_WRKDATA_SIZE, SHMEM_LONG_REDUCE_MIN_WRKDATA_SIZE, SHMEM_REAL32_REDUCE_MIN_WRKDATA_SIZE, SHMEM_REAL64_REDUCE_MIN_WRKDATA_SIZE, SHMEM_COMPLEX32_REDUCE_MIN_WRKDATA_SIZE, and SHMEM_COMPLEX64_REDUCE_MIN_WRKDATA_SIZE.

The pSync argument is a synchronization array that is used to ensure that the collective operation completes before proceeding. The size of this array is specified by the SHMEM constant SHMEM_REDUCE_SYNC_SIZE. All elements of the synchronization array must be initialized to SHMEM_SYNC_VALUE before the call.

The target array on each participating PE will contain the minimum value computed across all participating PEs for each element. The source array on each participating PE should contain the value to be reduced.

The following SHMEM constants are available for use with these collectives:

• SHMEM_REDUCE_SYNC_SIZE

• SHMEM_REDUCE_SYNC_VALUE

• SHMEM_INT_REDUCE_MIN_WRKDATA_SIZE

• SHMEM_LONG_REDUCE_MIN_WRKDATA_SIZE

• SHMEM_REAL32_REDUCE_MIN_WRKDATA_SIZE

• SHMEM_REAL64_REDUCE_MIN_WRKDATA_SIZE

• SHMEM_COMPLEX32_REDUCE_MIN_WRKDATA_SIZE

• SHMEM_COMPLEX64_REDUCE_MIN_WRKDATA_SIZE

NOTES

The pWrk and pSync arrays must be allocated in a way that they are accessible by all PEs participating in the collective operation. In Fortran, this is typically done using a COMMON block or module variables. In C/C++, this is typically done using global arrays.

The logPeMap argument allows for efficient reductions when the participating PEs are not contiguous in the PE numbering scheme. For example, if only even PEs are participating, then PE_arg1=0, PE_arg2=N (where N is the total number of PEs), and logPeMap=1 (since 2^1=2, and even PEs can be identified by pe & 1 == 0). Note that the Fortran example below demonstrates this specific case, and the NR/2+1 size calculation assumes that only half of the PEs are used.

The source and target arrays must not overlap.

The behavior is undefined if PE_arg1 or PE_arg2 are out of range, or if PE_arg1 > PE_arg2.

EXAMPLES

Example 1: Fortran code to find the minimum value of real variable FOO across all the even PEs.

INCLUDE "mpp/shmem.fh"
INTEGER PSYNC(SHMEM_REDUCE_SYNC_SIZE)
DATA PSYNC /SHMEM_REDUCE_SYNC_SIZE*SHMEM_SYNC_VALUE/
PARAMETER (NR=1)
REAL FOO, FOOMIN, PWRK(MAX(NR/2+1,SHMEM_REDUCE_MIN_WRKDATA_SIZE))
COMMON /COM/ FOO, FOOMIN, PWRK
INTRINSIC MY_PE
IF ( MOD(MY_PE(),2) .EQ. 0) THEN
  CALL SHMEM_REAL8_MIN_TO_ALL(FOOMIN, FOO, NR, 0, 1, N$PES/2,
  & PWRK, PSYNC)
  PRINT *, 'Result on PE ', MY_PE(), ' is ', FOOMIN
ENDIF

Example 2: Consider the following C/C++ call:

shmem_int_min_to_all( target, source, 3, 0, 0, 8, pwrk, psync );

The preceding call is more efficient, but semantically equivalent to, the combination of the following calls:

shmem_int_min_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk1, psync1);
shmem_int_min_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk2, psync2);
shmem_int_min_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk1, psync1);

Note that two sets of pWrk and pSync arrays are used alternately because no synchronization is done between calls.
