shmem_udcflush(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_UDCFLUSH(3) Open MPI SHMEM_UDCFLUSH(3)

shmem_clear_cache_inv(3)، shmem_set_cache_inv(3)، shmem_set_cache_line_inv(3)، shmem_udcflush(3)، shmem_udcflush_line(3) - تتحكم في أدوات ذاكرة التخزين المؤقت للبيانات

ملخص

C أو C++:

#include <mpp/shmem.h>
void shmem_clear_cache_inv(void)
void shmem_clear_cache_line_inv(void *target)
void shmem_set_cache_inv(void)
void shmem_set_cache_line_inv(void *target)
void shmem_udcflush(void)
void shmem_udcflush_line(void *target)

Fortran:

INCLUDE "mpp/shmem.fh"
CALL SHMEM_CLEAR_CACHE_INV
CALL SHMEM_CLEAR_CACHE_LINE_INV(target)
CALL SHMEM_SET_CACHE_INV
CALL SHMEM_SET_CACHE_LINE_INV(target)
CALL SHMEM_UDCFLUSH
CALL SHMEM_UDCFLUSH_LINE(target)

الوصف

يتم تمرير الوسيط التالي إلى روتينات التحكم في خط ذاكرة التخزين المؤقت:

target
كائن بيانات محلي للعنصر المعالج (PE). يمكن أن يكون target من أي نوع غير حرفي. إذا كنت تستخدم Fortran، فيمكن أن يكون من أي نوع.

shmem_clear_cache_inv تعطّل وضع اتساق ذاكرة التخزين المؤقت التلقائي الذي تم تمكينه سابقًا بواسطة shmem_set_cache_inv أو shmem_set_cache_line_inv.

shmem_clear_cache_line_inv تعطّل وضع اتساق ذاكرة التخزين المؤقت لخط ذاكرة التخزين المؤقت المرتبط بعنوان target فقط.

shmem_set_cache_inv تمكن واجهة OpenSHMEM من تحديد أفضل استراتيجية لاتساق ذاكرة التخزين المؤقت تلقائيًا.

shmem_set_cache_line_inv تمكن وضع اتساق ذاكرة التخزين المؤقت لخط ذاكرة التخزين المؤقت المرتبط بعنوان target فقط.

shmem_clear_cache_inv تعطّل وضع اتساق ذاكرة التخزين المؤقت التلقائي الذي تم تمكينه سابقًا بواسطة shmem_set_cache_inv أو shmem_set_cache_line_inv.

shmem_udcflush تجعل ذاكرة التخزين المؤقت لبيانات المستخدم بأكملها متسقة.

shmem_udcflush_line تجعل خط ذاكرة التخزين المؤقت الذي يتوافق مع العنوان المحدد بواسطة target متسقًا.

ملاحظات

تم الاحتفاظ بهذه الروتينات لتحسين التوافق مع الإصدارات السابقة مع البنى القديمة.
