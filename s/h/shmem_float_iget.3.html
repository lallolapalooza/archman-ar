الوصف

تقوم روتينات الاستلام المتدرجة بجلب بيانات المصفوفة المتاحة في العنوان source على PE البعيد (pe). يتم فصل عناصر مصفوفة source بفارق sst. بمجرد استلام البيانات، يتم تخزينها في عنوان الذاكرة المحلي target، مفصولة بفارق tst. تعود الروتينات عندما يتم نسخ البيانات إلى مصفوفة target المحلية.

الوسائط هي كما يلي:

target
المصفوفة التي سيتم تحديثها على PE المحلي.
source
المصفوفة التي تحتوي على البيانات المراد نسخها على PE البعيد.
tst
الفارق بين العناصر المتتالية لمصفوفة الهدف. يتم قياس الفارق حسب حجم العنصر لمصفوفة الهدف. تشير القيمة 1 إلى بيانات متجاورة. يجب أن يكون tst من نوع integer. إذا كنت تستدعي من Fortran، فيجب أن تكون قيمة integer افتراضية.
sst
الفارق بين العناصر المتتالية لمصفوفة المصدر. يتم قياس الفارق حسب حجم العنصر لمصفوفة المصدر. تشير القيمة 1 إلى بيانات متجاورة. يجب أن يكون sst من نوع integer. إذا كنت تستدعي من Fortran، فيجب أن تكون قيمة integer افتراضية.
len
عدد العناصر في مصفوفتي الهدف والمصدر. يجب أن يكون len من نوع integer. إذا كنت تستخدم Fortran، فيجب أن يكون ثابتًا أو متغيرًا أو عنصر مصفوفة من نوع integer افتراضي.
pe
رقم PE للـ PE البعيد. يجب أن يكون pe من نوع integer. إذا كنت تستخدم Fortran، فيجب أن يكون ثابتًا أو متغيرًا أو عنصر مصفوفة من نوع integer افتراضي.

أمثلة

يستخدم المثال البسيط التالي shmem_logical_iget في برنامج Fortran. قم بتجميع هذا المثال باستخدام الخيار -lsma للمترجم.

PROGRAM STRIDELOGICAL
  LOGICAL SOURCE(10), TARGET(5)
  SAVE SOURCE ! SAVE MAKES IT REMOTELY ACCESSIBLE
  DATA SOURCE /.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F.,.T.,.F./
  DATA TARGET / 5*.F. /
  CALL START_PES(2)
  IF (MY_PE() .EQ. 0) THEN
    CALL SHMEM_LOGICAL_IGET(TARGET, SOURCE, 1, 2, 5, 1)
    PRINT*,'TARGET AFTER SHMEM_LOGICAL_IGET:',TARGET
  ENDIF
  CALL SHMEM_BARRIER_ALL
END

SYNOPSIS

C Synopsis

#include <mpp/shmem.h>

long shmem_float_iget(void *target, const void *source, size_t nelems, int pe);

DESCRIPTION

The function shmem_float_iget is an asynchronous, remote memory copy operation. It initiates a non-blocking copy of floating-point numbers from the remote symmetric memory of the process specified by pe to the local symmetric memory of the calling process. The data is copied from the memory location pointed to by source to the memory location pointed to by target. The number of elements to be copied is specified by nelems.

The arguments are:

  • target: Pointer to the local memory location where the data will be copied.
  • source: Pointer to the remote memory location from which the data will be copied.
  • nelems: The number of floating-point elements to copy.
  • pe: The process element (PE) to copy from.

This function returns a non-negative integer on success, and a negative integer on failure. The return value is an identifier for the initiated transfer, which can be used for subsequent operations like shmem_quiet.

NOTES

The shmem_float_iget function is part of the OpenSHMEM API for parallel computing. It allows for asynchronous data transfer between processing elements, which can improve performance by overlapping communication with computation.

The memory specified by target and source must be symmetric memory.

EXAMPLES

#include <mpp/shmem.h>
#include <stdio.h>

int main(void) {
    static float data_local[10];
    static float data_remote[10];
    long status;
    int me;

    shmem_init();
    me = shmem_my_pe();

    // Initialize remote data (e.g., on PE 1)
    if (me == 1) {
        for (int i = 0; i < 10; i++) {
            data_remote[i] = (float) (me + i);
        }
    }
    shmem_barrier_all();

    // Initiate an asynchronous get from PE 1 to the local PE
    if (me == 0) {
        status = shmem_float_iget(data_local, data_remote, 10, 1);
        if (status < 0) {
            printf("PE %d: shmem_float_iget failed\n", me);
        }
    }

    // Wait for the operation to complete
    shmem_quiet();

    // Print the received data on PE 0
    if (me == 0) {
        printf("PE %d received: ", me);
        for (int i = 0; i < 10; i++) {
            printf("%.1f ", data_local[i]);
        }
        printf("\n");
    }

    shmem_finalize();
    return 0;
}
