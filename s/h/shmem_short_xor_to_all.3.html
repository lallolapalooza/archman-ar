shmem_short_xor_to_all(3)

الحزمة: openmpi

NAME

shmem_short_xor_to_all, shmem_long_xor_to_all, shmem_int_xor_to_all, shmem_longlong_xor_to_all — one-sided symmetric XOR reduction operation

SYNOPSIS 

#include <mpp/shmem.h>

void shmem_short_xor_to_all(short *target, const short *source, size_t n, int logPe);
void shmem_long_xor_to_all(long *target, const long *source, size_t n, int logPe);
void shmem_int_xor_to_all(int *target, const int *source, size_t n, int logPe);
void shmem_longlong_xor_to_all(long long *target, const long long *source, size_t n, int logPe);

DESCRIPTION

The symmetric reduction functions perform an XOR reduction on the elements of the data objects in the array source on each processing element (PE), and place the result in the data object in the array target on each PE.

The reduction operation is applied across all PEs participating in the operation. The reduction is performed across the PEs specified by the symmetric transpose operator. The symmetric transpose operator is implicitly defined for the collective operations.

The target and source arrays are implicitly defined across all PEs participating in the operation.

The parameter n specifies the number of elements in the arrays.

The parameter logPe is used to specify the stride between elements in the source and target arrays. Specifically, the stride is 2logPe. The maximum value for logPe is determined by the type of the data object. For shmem_short_xor_to_all, the maximum value is defined by SHMEM_SHORT_LOG_MAX. For shmem_long_xor_to_all, the maximum value is defined by SHMEM_LONG_LOG_MAX. For shmem_int_xor_to_all, the maximum value is defined by SHMEM_INT_LOG_MAX. For shmem_longlong_xor_to_all, the maximum value is defined by SHMEM_LONGLONG_LOG_MAX.

The symmetric reduction functions are one-sided operations. Thus, shmem_barrier_all or other synchronization functions may be required to ensure that the reduction operation is completed.

NOTES

The elements of the target and source arrays must be of the same type. The source array is not modified by this operation. The target array is overwritten by the result of the reduction.

The behavior is undefined if the target and source arrays overlap.

The operation is only performed on the PEs within the symmetric transpose group. The symmetric transpose operator is implicitly defined for the collective operations.

EXAMPLES

The following example demonstrates the use of shmem_short_xor_to_all:

#include <mpp/shmem.h>

int
main(int argc, char **argv)
{
    short target[_NR_PES];
    short source[_NR_PES];
    int i;

    for (i = 0; i < _NR_PES; i++) {
        source[i] = i;
    }

    shmem_short_xor_to_all(target, source, 1, 0);

    shmem_barrier_all();

    if (_my_pe() == 0) {
        for (i = 0; i < _NR_PES; i++) {
            printf("target[%d] = %d\n", i, target[i]);
        }
    }

    return 0;
}

The preceding call is more efficient, but semantically equivalent to, the combination of the following calls:

shmem_short_xor_to_all(&(target[0]), &(source[0]), 1, 0, 0, 8,
  pwrk1, psync1);
shmem_short_xor_to_all(&(target[1]), &(source[1]), 1, 0, 0, 8,
  pwrk2, psync2);
shmem_short_xor_to_all(&(target[2]), &(source[2]), 1, 0, 0, 8,
  pwrk1, psync1);

Note that two sets of pWrk and pSync arrays are used alternately because no synchronization is done between calls.
