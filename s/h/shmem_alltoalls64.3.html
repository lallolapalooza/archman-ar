الحزمة: openmpi

SHMEM_ALLTOALLS64(3) Open MPI SHMEM_ALLTOALLS64(3)

تُستخدم الروتينات shmem_alltoall32(3)، shmem_alltoall64(3)، shmem_alltoalls32(3)، shmem_alltoalls64(3) لتبادل كمية ثابتة من البيانات بين جميع وحدات المعالجة (PEs) في المجموعة النشطة.

ملخص

C أو C++:

#include <mpp/shmem.h>
void shmem_alltoall32(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoall64(void *target, const void *source,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls32(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)
void shmem_alltoalls64(void *target, const void *source,
  ptrdiff_t dst, ptrdiff_t sst,
  size_t nelems, int PE_start, int logPE_stride,
  int PE_size, long *pSync)

Fortran:

INCLUDE "mpp/shmem.fh"
INTEGER dst, sst, nelems, PE_root, PE_start, logPE_stride, PE_size
INTEGER pSync(SHMEM_ALLTOALL_SYNC_SIZE)
CALL SHMEM_ALLTOALL32(target, source, nelems,
& PE_start, logPE_stride, PE_size, fIpSync)
CALL SHMEM_ALLTOALL64(target, source, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS32(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)
CALL SHMEM_ALLTOALLS64(target, source, dst, sst, nelems,
& PE_start, logPE_stride, PE_size, pSync)

الوصف

تُعد روتينات shmem_alltoalls روتينات جماعية. تقوم كل وحدة معالجة (PE) في المجموعة النشطة بتبادل nelems من عناصر البيانات ذات حجم 32 بت (لـ shmem_alltoalls32) أو 64 بت (لـ shmem_alltoalls64) مع جميع وحدات المعالجة الأخرى في المجموعة. يجب أن يكون كل من المباعدين dst و sst أكبر من أو يساوي 1. يتم وضع الكتلة sst*j المرسلة من PE i إلى PE j في الكتلة dst*i من كائن بيانات الوجهة على PE j. كما هو الحال مع جميع روتينات OpenSHMEM الجماعية، تفترض هذه الروتينات أن وحدات المعالجة الموجودة في المجموعة النشطة فقط هي التي تستدعي الروتين. إذا استدعت وحدة معالجة غير موجودة في المجموعة النشطة روتينًا جماعيًا لـ OpenSHMEM، فستكون النتيجة سلوكًا غير محدد. يجب أن تكون قيم الوسائط dst، sst، nelems، PE_start، logPE_stride، و PE_size متساوية على جميع وحدات المعالجة في المجموعة النشطة. يجب تمرير نفس كائنات بيانات الوجهة والمصدر، ونفس مصفوفة العمل pSync إلى جميع وحدات المعالجة في المجموعة النشطة. قبل أي استدعاءات لوحدات المعالجة لروتين shmem_alltoalls، يجب أن تكون الظروف التالية موجودة (غالبًا ما يكون المزامنة عبر حاجز أو طريقة أخرى ضرورية لضمان ذلك): مصفوفة pSync على جميع وحدات المعالجة في المجموعة النشطة ليست قيد الاستخدام من استدعاء سابق لروتين shmem_alltoalls. كائن بيانات الوجهة على جميع وحدات المعالجة في المجموعة النشطة جاهز لاستقبال بيانات shmem_alltoalls. عند العودة من روتين shmem_alltoalls، يكون ما يلي صحيحًا بالنسبة لوحدة المعالجة المحلية: تم تحديث كائن بيانات الوجهة المتماثل بالكامل وتم نسخ البيانات من كائن مصدر البيانات. تمت استعادة القيم الموجودة في مصفوفة pSync إلى قيمها الأصلية.

الوسائط هي كما يلي:

كائن بيانات متماثل بأحد أنواع البيانات التالية:

shmem_alltoall32: أي نوع غير حرفي
له حجم عنصر 32 بت. لا يُسمح بأنواع بيانات Fortran المشتقة أو هياكل C/C++.
shmem_alltoall64: أي نوع غير حرفي له حجم عنصر
64 بت. لا يُسمح بأنواع بيانات Fortran المشتقة أو هياكل C/C++.

target: كائن بيانات متماثل كبير بما يكفي لاستقبال الإجمالي المجمع لـ nelems عنصر من كل وحدة معالجة في المجموعة النشطة.

source
كائن بيانات متماثل يحتوي على nelems عنصر من البيانات لكل وحدة معالجة في المجموعة النشطة، مرتبة وفقًا لوحدة المعالجة الوجهة.
dst
المسافة بين العناصر المتتالية لكائن بيانات الوجهة. يتم قياس المسافة حسب حجم العنصر. القيمة 1 تشير إلى بيانات متجاورة. يجب أن يكون dst من نوع ptrdiff_t. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضية.
sst
المسافة بين العناصر المتتالية لكائن مصدر البيانات. يتم قياس المسافة حسب حجم العنصر. القيمة 1 تشير إلى بيانات متجاورة. يجب أن يكون sst من نوع ptrdiff_t. إذا كنت تستخدم Fortran، فيجب أن تكون قيمة عدد صحيح افتراضية.
nelems
عدد العناصر المراد تبادلها لكل وحدة معالجة. يجب أن يكون nelems من نوع size_t لـ C/C++. إذا كنت تستخدم Fortran، فيجب أن يكون قيمة عدد صحيح افتراضية.
PE_start
أدنى رقم وحدة معالجة افتراضية للمجموعة النشطة لوحدات المعالجة. يجب أن يكون PE_start من نوع عدد صحيح. إذا كنت تستخدم Fortran، فيجب أن يكون قيمة عدد صحيح افتراضية.
logPE_stride
اللوغاريتم (الأساس 2) للمسافة بين أرقام وحدات المعالجة الافتراضية المتتالية في المجموعة النشطة. يجب أن يكون log_PE_stride من نوع عدد صحيح. إذا كنت تستخدم Fortran، فيجب أن يكون قيمة عدد صحيح افتراضية.
PE_size
عدد وحدات المعالجة في المجموعة النشطة. يجب أن يكون PE_size من نوع عدد صحيح. إذا كنت تستخدم Fortran، فيجب أن يكون قيمة عدد صحيح افتراضية.
pSync
مصفوفة عمل متماثلة. في C/C++، يجب أن تكون pSync من نوع long وحجم _SHMEM_ALLTOALL_SYNC_SIZE. في Fortran، يجب أن تكون pSync من نوع عدد صحيح وحجم SHMEM_ALLTOALL_SYNC_SIZE. يجب تهيئة كل عنصر في هذه المصفوفة بالقيمة _SHMEM_SYNC_VALUE (في C/C++) أو SHMEM_SYNC_VALUE (في Fortran) قبل أن تدخل أي من وحدات المعالجة في المجموعة النشطة إلى shmem_barrier().

عند العودة من روتين shmem_alltoalls، يكون ما يلي صحيحًا بالنسبة لوحدة المعالجة المحلية: تم تحديث كائن بيانات الوجهة المتماثل بالكامل وتم نسخ البيانات من كائن مصدر البيانات. تمت استعادة القيم الموجودة في مصفوفة pSync إلى قيمها الأصلية.

يجب أن تكون قيم الوسائط PE_root، PE_start، logPE_stride، و PE_size متساوية على جميع وحدات المعالجة في المجموعة النشطة. يجب تمرير نفس كائنات بيانات الوجهة والمصدر، ونفس مصفوفة العمل pSync إلى جميع وحدات المعالجة في المجموعة النشطة.

قبل أن تستدعي أي وحدة معالجة روتين alltoall، يجب عليك التأكد من وجود الشروط التالية (غالبًا ما تكون المزامنة عبر حاجز أو طريقة أخرى ضرورية لضمان ذلك): مصفوفة pSync على جميع وحدات المعالجة في المجموعة النشطة ليست قيد الاستخدام من استدعاء سابق لروتين alltoall. مصفوفة target على جميع وحدات المعالجة في المجموعة النشطة جاهزة لاستقبال بيانات alltoall.

ملاحظات

يتم تعريف مصطلحات "جماعي" و "متماثل" في intro_shmem(3).

جميع روتينات SHMEM alltoall تعيد pSync إلى محتوياتها الأصلية. الاستدعاءات المتعددة لروتينات SHMEM التي تستخدم نفس مصفوفة pSync لا تتطلب إعادة تهيئة pSync بعد الاستدعاء الأول.

يجب عليك التأكد من أن مصفوفة pSync لا يتم تحديثها بواسطة أي وحدة معالجة في المجموعة النشطة أثناء مشاركة أي من وحدات المعالجة في معالجة استدعاء روتين بث SHMEM. كن حذرًا لتجنب هذه المواقف: إذا تم تهيئة مصفوفة pSync في وقت التشغيل، فإن بعض أنواع المزامنة ضرورية لضمان أن جميع وحدات المعالجة في مجموعة العمل قد قامت بتهيئة pSync قبل أن تدخل أي منها إلى روتين SHMEM تم استدعاؤه مع مصفوفة مزامنة pSync. يمكن إعادة استخدام مصفوفة pSync في روتين بث SHMEM لاحق فقط إذا لم تكن أي من وحدات المعالجة في المجموعة النشطة لا تزال تعالج استدعاء روتين SHMEM alltoall سابق استخدم نفس مصفوفة pSync. بشكل عام، لا يمكن ضمان ذلك إلا عن طريق إجراء بعض أنواع المزامنة. ومع ذلك، في الحالة الخاصة لروتينات SHMEM التي يتم استدعاؤها بنفس المجموعة النشطة، يمكنك تخصيص مصفوفتي pSync والتبديل بينهما في الاستدعاءات المتتالية.

NAME

shmem_alltoalls64 - Alltoalls Collective Communication

SYNOPSIS

#include <mpp/shmem.h>

void shmem_alltoalls64(void *dest, const void *source,
                       uint64_t nelems, int PE_size,
                       int logPE_stride, int PE_map,
                       long Psync[]);

DESCRIPTION

The shmem_alltoalls64() function is a collective communication routine that exchanges data among all PEs in a symmetric heap, symmetric data, or symmetric object. Every PE in the job is involved in the communication. Each PE sends the same number of elements of data to every other PE. Each PE receives the same number of elements of data from every other PE.

The elements are of size 8 bytes each.

dest: The starting address of the symmetric memory data structure to be received.

source: The starting address of the symmetric memory data structure to be sent.

nelems: The number of elements to be sent and received. The total number of bytes transferred is 8 * nelems.

PE_size: The number of PEs to participate in this collective communication. This parameter is used to define the group of PEs for which the alltoalls is performed.

logPE_stride: This parameter encodes the stride between PEs. logPE_stride = 0 means a stride of 1. logPE_stride = 1 means a stride of 2, and so on. The stride S is given by S = 2^logPE_stride.

PE_map: This parameter encodes the mapping of PEs to the collective communication. PE_map = 0 means contiguous mapping. PE_map = 1 means contiguous mapping with stride. PE_map = 2 means symmetric mapping.

Psync: The address of the synchronization buffer. This is an array of type long, and it must contain at least SHMEM_ALLTOALLS_SYNC_SIZE elements. All elements in this array must be initialized to SHMEM_SYNC_VALUE.

NOTES

All arguments are the same for all PEs in the job. The data referenced by dest and source must be in symmetric memory.

The shmem_alltoalls64() function is a blocking routine. That is, it does not return until the alltoalls operation is complete.

The synchronization buffer Psync is used to synchronize the completion of the shmem_alltoalls64() call. It is assumed that the caller has initialized the synchronization buffer to the value of SHMEM_SYNC_VALUE on all participating PEs before calling shmem_alltoalls64().

EXAMPLES

#include <stdio.h>
#include <stdlib.h>
#include <mpp/shmem.h>

#define SHMEM_SYNC_VALUE -1
#define SHMEM_ALLTOALLS_SYNC_SIZE 2

int main(int argc, char* argv[]) {
    long *source, *dest;
    long pSync[SHMEM_ALLTOALLS_SYNC_SIZE];
    int count, pe, i;

    /* Initialize shared memory environment */
    start_pes(0);

    /* Number of elements to transfer */
    count = 10;

    /* Allocate symmetric memory for source and destination */
    source = (long*)shmem_malloc(shmem_n_pes() * count * sizeof(long));
    dest = (long*)shmem_malloc(shmem_n_pes() * count * sizeof(long));

    /* Initialize source and destination arrays */
    for (pe=0; pe <shmem_n_pes(); pe++){
        for (i=0; i<count; i++){
            source[(pe*count)+i] = shmem_my_pe() + pe;
            dest[(pe*count)+i] = 9999;
        }
    }

    /* Initialize synchronization buffer */
    for (i=0; i< SHMEM_ALLTOALLS_SYNC_SIZE; i++) {
        pSync[i] = SHMEM_SYNC_VALUE;
    }

    /* wait for all PEs to initialize pSync */
    shmem_barrier_all();

    /* Perform the alltoalls operation */
    shmem_alltoalls64(dest, source, count, shmem_n_pes(), 0, 0, pSync);

    /* Verify results */
    for (pe=0; pe<shmem_n_pes(); pe++) {
        for (i=0; i<count; i++){
            if (dest[(pe*count)+i] != shmem_my_pe() + pe) {
                printf("[%d] ERROR: dest[%d]=%ld, should be %ld\n",
                       shmem_my_pe(), (pe*count)+i, dest[(pe*count)+i],
                       shmem_my_pe() + pe);
            }
        }
    }

    /* Wait for all PEs to finish verification */
    shmem_barrier_all();

    /* Free allocated memory */
    shmem_free(dest);
    shmem_free(source);

    /* Finalize shared memory environment */
    shmem_finalize();

    return 0;
}
