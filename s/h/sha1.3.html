SHA1(3) دليل وظائف المكتبة SHA1(3)

الاسم

SHA1Init, SHA1Update, SHA1Pad, SHA1Final, SHA1Transform, SHA1End, SHA1File, SHA1FileChunk, SHA1Data — حساب خوارزمية التجزئة الآمنة من NIST

المكتبة

مكتبة دعم تشفير تجزئة الرسالة (MD4، MD5، إلخ) (libmd، -lmd)

الملخص

#include <sys/types.h>
#include <sha1.h>

void
SHA1Init(SHA1_CTX *context);

void
SHA1Update(SHA1_CTX *context, const uint8_t *data, size_t len);

void
SHA1Pad(SHA1_CTX *context);

void
SHA1Final(uint8_t digest[SHA1_DIGEST_LENGTH], SHA1_CTX *context);

void
SHA1Transform(uint32_t state[5], const uint8_t buffer[SHA1_BLOCK_LENGTH]);

char *
SHA1End(SHA1_CTX *context, char *buf);

char *
SHA1File(const char *filename, char *buf);

char *
SHA1FileChunk(const char *filename, char *buf, off_t offset, off_t length);

char *
SHA1Data(const uint8_t *data, size_t len, char *buf);

الوصف

تنفذ وظائف SHA1 خوارزمية التجزئة الآمنة من NIST (SHA-1)، FIPS PUB 180-1. تستخدم SHA-1 لتوليد تمثيل مكثف للرسالة يسمى هضم الرسالة. تأخذ الخوارزمية رسالة أقل من 2^64 بت كمدخل وتنتج هضمًا بحجم 160 بت مناسب للاستخدام كـ توقيع رقمي.

على الرغم من أن وظائف SHA1 تعتبر أكثر أمانًا من وظائف md4(3) و md5(3) التي تشاركها واجهة متشابهة، إلا أنها تعتبر غير آمنة اعتبارًا من عام 2005، واعتبارًا من عام 2020 أصبحت هجمات الاختيار المسبق عملية، وبالتالي يجب عدم استخدامها في سياقات التشفير.

تقوم الدالة SHA1Init() بتهيئة SHA1_CTX context للاستخدام مع SHA1Update()، و SHA1Final(). تضيف الدالة SHA1Update() data بطول len إلى SHA1_CTX المحدد بواسطة context. يتم استدعاء SHA1Final() عندما تتم إضافة جميع البيانات عبر SHA1Update() وتقوم بتخزين هضم الرسالة في المعلمة digest.

يمكن استخدام الدالة SHA1Pad() لتطبيق حشو على هضم الرسالة كما في SHA1Final()، ولكن يمكن الاستمرار في استخدام السياق الحالي مع SHA1Update().

تستخدم الدالة SHA1Transform() بواسطة SHA1Update() لتجزئة كتل بحجم 512 بت وتشكل جوهر الخوارزمية. يجب على معظم البرامج استخدام الواجهة التي توفرها SHA1Init() و SHA1Update() و SHA1Final() بدلاً من استدعاء SHA1Transform() مباشرة.

الدالة SHA1End() هي واجهة أمامية لـ SHA1Final() التي تحول الهضم إلى تمثيل ASCII للهضم المكون من 160 بت بالنظام الست عشري.

تقوم الدالة SHA1File() بحساب الهضم لملف وإرجاع النتيجة عبر SHA1End(). إذا فشلت SHA1File() في فتح الملف، يتم إرجاع مؤشر NULL.

SHA1FileChunk() تعمل مثل SHA1File() ولكنها تحسب الهضم فقط للجزء من الملف الذي يبدأ عند offset ويستمر لمدة length بايت أو حتى نهاية الملف، أيهما يأتي أولاً. يمكن تحديد length يساوي صفر للقراءة حتى نهاية الملف. سيتم تجاهل length أو offset السالب.

تقوم الدالة SHA1Data() بحساب الهضم لسلسلة عشوائية وإرجاع النتيجة عبر SHA1End().

لكل من الدوال SHA1End() و SHA1File() و SHA1Data()، يجب أن يكون المعلمة buf إما سلسلة نصية بحجم 41 حرفًا على الأقل أو مؤشر NULL. في الحالة الأخيرة، سيتم تخصيص مساحة ديناميكيًا عبر malloc(3) ويجب تحريرها باستخدام free(3) عندما لا تكون هناك حاجة إليها.

أمثلة

سيعمل المقطع التالي من الكود على حساب الهضم للسلسلة النصية "abc" وهو "0xa9993e364706816aba3e25717850c26c9cd0d89d".

SHA1_CTX sha;
uint8_t results[SHA1_DIGEST_LENGTH];
char *buf;
int n;

buf = "abc";
n = strlen(buf);
SHA1Init(&sha);
SHA1Update(&sha, (uint8_t *)buf, n);
SHA1Final(results, &sha);

/* Print the digest as one long hex value */
printf("0x");
for (n = 0; n < SHA1_DIGEST_LENGTH; n++)
	printf("%02x", results[n]);
putchar('\n');

بدلاً من ذلك، يمكن استخدام الدوال المساعدة بالطريقة التالية:

uint8_t output[SHA1_DIGEST_STRING_LENGTH];
char *buf = "abc";

printf("0x%s\n", SHA1Data(buf, strlen(buf), output));

sha1.3 - SHA-1 cryptographic hash function

NAME

sha1 - SHA-1 cryptographic hash function

LIBRARY

libmd, -lmd

SYNOPSIS

#include <sys/types.h>
#include <sys/sha1.h>

void
SHA1Init(SHA1_CTX *ctx);

void
SHA1Update(SHA1_CTX *ctx,
    const void *data, u_int32_t len);

void
SHA1Final(u_int8_t digest[SHA1_DIGEST_LENGTH],
    SHA1_CTX *ctx);

char *
SHA1End(SHA1_CTX *ctx, char *buf);

char *
SHA1File(const char *path, char *buf);

char *
SHA1FileChunk(const char *path,
    char *buf, off_t offset, off_t length);

char *
SHA1Data(const void *data,
    u_int32_t len, char *buf);

DESCRIPTION

The SHA-1 algorithm is a cryptographic hash function that produces a 160-bit (20-byte) message digest from a given input message. This implementation of SHA-1 is designed to be used with the OpenBSD operating system.

The SHA-1 algorithm is described in FIPS PUB 180-1.

The main functions are:

SHA1Init()
Initializes the SHA-1 context structure pointed to by ctx.
SHA1Update()
Updates the SHA-1 context with the data pointed to by data, which has length len. This function can be called multiple times to process messages of arbitrary length.
SHA1Final()
Calculates the SHA-1 message digest from the current context and stores it in the buffer pointed to by digest. The buffer must be at least SHA1_DIGEST_LENGTH bytes long. After calling SHA1Final(), the context is no longer valid.

The helper functions are:

SHA1End()
This is a convenience function that calls SHA1Final() and then formats the digest into a null-terminated hexadecimal string. The buffer buf must be at least SHA1_DIGEST_LENGTH bytes long. If buf is NULL, a buffer will be allocated by this function.
SHA1File()
Calculates the SHA-1 digest for the file specified by path. The digest is formatted into a null-terminated hexadecimal string. The buffer buf must be at least SHA1_DIGEST_LENGTH bytes long. If buf is NULL, a buffer will be allocated by this function.
SHA1FileChunk()
Calculates the SHA-1 digest for a portion of the file specified by path. The portion of the file to be hashed starts at offset and has a length of length. The digest is formatted into a null-terminated hexadecimal string. The buffer buf must be at least SHA1_DIGEST_LENGTH bytes long. If buf is NULL, a buffer will be allocated by this function.
SHA1Data()
Calculates the SHA-1 digest for the data specified by data and len. The digest is formatted into a null-terminated hexadecimal string. The buffer buf must be at least SHA1_DIGEST_LENGTH bytes long. If buf is NULL, a buffer will be allocated by this function.

EXAMPLES

To calculate the SHA-1 digest of a string:

    SHA1_CTX ctx;
    char digest[SHA1_DIGEST_LENGTH];
    char *hex_digest;

    SHA1Init(&ctx);
    SHA1Update(&ctx, "hello world", 11);
    SHA1Final(digest, &ctx);
    hex_digest = SHA1End(&ctx, NULL); /* SHA1End uses the last context */
    printf("Hex digest: %s\n", hex_digest);

To calculate the SHA-1 digest of a file:

    char *hex_digest;

    hex_digest = SHA1File("myfile.txt", NULL);
    printf("File digest: %s\n", hex_digest);

SEE ALSO

md5sum(1), md5(3), sha224(3), sha256(3), sha384(3), sha512(3)

HISTORY

The SHA-1 functions first appeared in OpenBSD 2.0.

AUTHORS

This implementation of SHA-1 was written by Steve Reid.

The SHA1End(), SHA1File(), SHA1FileChunk(), and SHA1Data() helper functions are derived from code written by Poul-Henning Kamp.

CAVEATS

This implementation of SHA-1 has not been validated by NIST and as such is not in official compliance with the standard.

If a message digest is to be copied to a multi-byte type (ie: an array of five 32-bit integers) it will be necessary to perform byte swapping on little endian machines such as the i386, alpha, and vax.
