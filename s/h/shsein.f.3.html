الغرض:

!>
!> SHSEIN يستخدم التكرار العكسي لإيجاد المتجهات الذاتية اليمنى و/أو اليسرى المحددة
!> لمصفوفة هسنبرغ الحقيقية H.
!>
!> المتجه الذاتي اليميني x والمتجه الذاتي اليساري y للمصفوفة H
!> المقابلة لقيمة ذاتية w معرفة بواسطة:
!>
!>              H * x = w * x,     y**h * H = w * y**h
!>
!> حيث تشير y**h إلى منقول المرافق للمتجه y.
!>

Function/Subroutine Documentation

SUBROUTINE SHSEIN(
     JOB, COMPQ, N, NL, NR, D, E, LDW, W, LDU, W1, LDU1, V, LDV, W2, LDU2,
     WORK, LWORK, INFO)

Purpose:

SHSEIN computes the eigenvectors of a real symmetric tridiagonal matrix.

Parameters:

JOB
(Input) CHARACTER*1.

Specifies whether to compute eigenvectors of a general tridiagonal matrix, or of a symmetric tridiagonal matrix. JOB = 'N': vectors are not computed.

JOB = 'V': vectors are computed.

COMPQ
(Input) CHARACTER*1.

Specifies whether to compute all eigenvectors or just a subset. COMPQ = 'A': all eigenvectors are computed.

COMPQ = 'S': a subset of the eigenvectors is computed.

N
(Input) INTEGER.

The order of the matrix T.

NL
(Input) INTEGER.

The number of eigenvalues to be selected from the left end of the spectrum.

NR
(Input) INTEGER.

The number of eigenvalues to be selected from the right end of the spectrum.

D
(Input) DOUBLE PRECISION array, dimension (N).
E
(Input) DOUBLE PRECISION array, dimension (N-1).
LDW
(Input) INTEGER.

The number of rows in the array W.

W
(Output) DOUBLE PRECISION array, dimension (LDW, N).
LDU
(Input) INTEGER.

The number of rows in the array U.

W1
(Output) DOUBLE PRECISION array, dimension (LDU1, N).
LDU1
(Input) INTEGER.

The number of rows in the array U1.

V
(Output) DOUBLE PRECISION array, dimension (LDV, N).
LDV
(Input) INTEGER.

The number of rows in the array V.

W2
(Output) DOUBLE PRECISION array, dimension (LDU2, N).
LDU2
(Input) INTEGER.

The number of rows in the array U2.

WORK
(Workspace) DOUBLE PRECISION array, dimension (LWORK).
LWORK
(Input) INTEGER.

The dimension of the array WORK.

INFO
(Output) INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, i eigenvectors had failed to converge. Please see IFAILL and IFAILR for further details.

Description:

This subroutine is intended to be called by the subroutine LAED3.

This subroutine computes the eigenvectors of a real symmetric tridiagonal matrix T.

The eigenvalues of T are assumed to be in the array D, and the super- and sub-diagonals are in the array E.

The eigenvectors are computed by applying a sequence of Givens rotations to the tridiagonal matrix T.

The eigenvectors are normalized so that the element of largest magnitude is equal to 1.

The subroutine returns the eigenvectors in the array V. The eigenvectors are stored column by column, so that the i-th column of V contains the eigenvector corresponding to the i-th eigenvalue in D.

Algorithm:

The eigenvectors are computed using the inverse iteration method. The subroutine uses a divide and conquer approach to compute the eigenvectors. The matrix T is first divided into two smaller matrices. The eigenvectors of these smaller matrices are then computed recursively. Finally, the eigenvectors of T are computed by combining the eigenvectors of the smaller matrices.

Further Details:

Each eigenvector is normalized so that the element of largest
magnitude has magnitude 1. The magnitude of a complex number
(x,y) is taken to be |x|+|y|.
