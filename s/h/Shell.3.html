NAME

Shell - a managed widget that is the parent of other widgets

SYNOPSIS

#include <Xm/Shell.h>

DESCRIPTION

The Shell widget is a managed widget that serves as the parent of other widgets. It is used to create top-level windows, dialog boxes, and other container widgets. The Shell widget provides a basic framework for managing child widgets, including geometry management, event handling, and resource management.

The Shell widget is a subclass of the Core widget and inherits all of its resources. It also provides additional resources for controlling the appearance and behavior of the shell window.
