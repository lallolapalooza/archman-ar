shmem_double_p(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_DOUBLE_P(3) Open MPI SHMEM_DOUBLE_P(3)

shmem_char_p(3)، shmem_float_p(3)، shmem_int_p(3)، shmem_long_p(3)، shmem_short_p(3)، shmem_longlong_p(3)، shmem_longdouble_p(3) - توفر هذه الروتينات آلية زمن وصول منخفض لكتابة أنواع أساسية (char, short, int, float, double, long, long long, long double) إلى كائنات بيانات متناظرة على وحدات المعالجة البعيدة (PEs).

الملخص

C أو C++:

#include <mpp/shmem.h>
void shmem_char_p(char *addr, char value, int pe)
void shmem_short_p(short *addr, short value, int pe)
void shmem_int_p(int *addr, int value, int pe)
void shmem_long_p(long *addr, long value, int pe)
void shmem_longlong_p(long long *addr, long long value, int pe)
void shmem_float_p(float *addr, float value, int pe)
void shmem_double_p(double *addr, double value, int pe)
void shmem_longdouble_p(long double *addr, long double value, int pe)

الوصف

توفر هذه الروتينات قدرة إرسال (put) بزمن وصول منخفض جدًا لعناصر فردية من معظم الأنواع الأساسية.

الوسائط هي كما يلي:

addr
عنصر المصفوفة الذي يمكن الوصول إليه عن بعد أو كائن البيانات القياسي الذي سيتلقى البيانات على وحدة المعالجة البعيدة.
value
القيمة التي سيتم نقلها إلى addr على وحدة المعالجة البعيدة.
pe
رقم وحدة المعالجة البعيدة.

كما هو الحال مع shmem_put(3)، تبدأ هذه الدوال النقل عن بعد وقد تعود قبل تسليم البيانات إلى وحدة المعالجة البعيدة. استخدم shmem_quiet(3) لإجبار اكتمال جميع عمليات PUT عن بعد.

انظر أيضًا:

intro_shmem(3) shmem_put(3)
