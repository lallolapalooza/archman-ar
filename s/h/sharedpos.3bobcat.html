FBB::Sharedpos(3bobcat) إزاحة الذاكرة المشتركة FBB::Sharedpos(3bobcat)

الاسم

FBB::Sharedpos - متحكم إزاحة الذاكرة المشتركة

الملخص

#include <bobcat/sharedpos>
خيار الربط: -lbobcat

الوصف

الفئة SharedPos هي فئة دعم لفئات معالجة الذاكرة المشتركة الخاصة بـ Bobcat. تتحكم في إزاحة القراءة/الكتابة في الذاكرة المشتركة وتضمن أن عمليات الذاكرة المشتركة لا تتجاوز أبدًا الحد الأقصى لإزاحة الذاكرة المشتركة.

تحتوي الفئة SharedPos على العديد من الأعضاء العامة، ولكنها مفيدة بشكل أساسي لفئات Shared* الأخرى التي تقدمها Bobcat. من المحتمل أن يكون هناك استخدام قليل لكائن SharedPos مستقل.

في أوصاف الدوال الأعضاء للفئة، تشير offset إلى إزاحة القراءة/الكتابة داخل كائن FBB::SharedSegment(3bobcat) الذي تقوم SharedPos بإدارة الإزاحة له.

FBB

التعريفات والفئات التعدادية

البنائين

تتوفر البنائين الافتراضي، النسخ، والنقل، بالإضافة إلى عوامل تعيين النسخ والنقل. الباني الافتراضي لا يراقب إزاحة كائن FBB::SharedSegment بعد. يتم استخدام العضو reset لبدء مراقبة الإزاحات.

عوامل التشغيل المحملة بشكل زائد

o
void operator++():
تتم زيادة الإزاحة. إذا تم استدعاء هذا العضو عندما تكون الإزاحة مساوية للحد الأقصى لإزاحة الذاكرة المشتركة، يتم طرح FBB::Exception.
o
void operator+=(size_t len):
تتم زيادة الإزاحة بمقدار len. إذا تجاوزت offset + len الحد الأقصى لإزاحة الذاكرة المشتركة، يتم تعيين الإزاحة إلى الحد الأقصى وطرح FBB::Exception.
o
std::ostream &operator<<(std::ostream &out, SharedPos const &pos):
يقوم بإدراج معلومات حول كائن SharedPos في out.

الدوال الأعضاء

ملاحظة: سلوك الدوال الأعضاء التي تُرجع قيمًا تشير إلى معلومات كائن FBB::SharedSegment غير معرف حتى يتم استدعاء العضو reset.

o
bool atMaxOffset() const:
تُرجع true إذا كانت الإزاحة تساوي الحد الأقصى للإزاحة التي يمكن استخدامها لكائن FBB::SharedSegment المُعد بشكل صحيح.
o
size_t blockIdx() const:
يتم إرجاع فهرس كتلة بيانات الشريحة المشتركة لكائن FBB::SharedSegment المُعد التي تشير إليها الإزاحة.
o
size_t blockOffset() const:
يتم إرجاع الإزاحة داخل كتلة بيانات الشريحة المشتركة التي تطابق قيمة الإرجاع للعضو offset.
o
bool eof() const:
تُرجع true إذا تجاوزت الإزاحة الحد الأقصى للإزاحة لأي حرف تم كتابته على الإطلاق في الذاكرة المشتركة التي تتفاعل معها كائن SharedPos. إذا أعادت eof القيمة true، قد لا يزال من الممكن كتابة معلومات إلى الذاكرة المشتركة: الكتابة ممكنة حتى الوصول إلى الحد الأقصى لإزاحة شريحة الذاكرة المشتركة.
o
std::streamsize eos() const:
يتم إرجاع الإزاحة مباشرة بعد الحد الأقصى للإزاحة لكتلة بيانات الشريحة المشتركة الحالية. على سبيل المثال، إذا أعادت blockIdx القيمة 5، وكان حجم كتل بيانات الشريحة المشتركة يساوي 2000، فإن eos تُرجع 12000 (الإزاحة الأولى للشريحة 6).
o
std::streamsize maxOffset() const:
يتم إرجاع الحد الأقصى للإزاحة الممكنة للشريحة المشتركة التي تتم مراقبتها حاليًا FBB::SharedSegment.
o
std::streamsize offset() const:
يتم إرجاع الإزاحة داخل شريحة الذاكرة المشتركة التي تتم مراقبتها حاليًا.
o
void reset(SharedSegment *sharedData):
يتم إعادة تعيين كائن SharedPos لمراقبة إزاحة كائن FBB::SharedSegment الذي يتم تمرير عنوانه كوسيط إلى reset. يجب أن يشير العنوان إلى كائن sharedsegment(3bobcat) موجود حتى نهاية عمر كائن SharedPos أو حتى استدعاء reset التالي. مباشرة بعد استدعاء reset، يتم إعادة تعيين الإزاحة إلى 0.
o
std::streamsize showmanyc() const:
يتم إرجاع عدد الأحرف التي يمكن قراءتها من كتلة بيانات الشريحة المشتركة الحالية. يستعلم هذا العضو عن عدد الأحرف القابلة للقراءة في شريحة الذاكرة المشتركة. قد يتغير هذا العدد أثناء تنفيذ هذا العضو. للحصول على قيمة إرجاع مستقرة، يجب على الدوال التي تستدعي الحصول على قفل على بيانات FBB::SharedSegment قبل استدعاء هذا العضو. انظر أيضًا صفحة الدليل sharedsegment(3bobcat).
o
std::ios::pos_type seek(std::ios::off_type offset, std::ios::seekdir origin = std::ios::beg):
يتم تغيير الإزاحة المراقبة إلى وسيط offset لهذا العضو، نسبة إلى origin. البحث بعد eof مقبول. ومع ذلك، يتم إرجاع -1 عند البحث بعد maxOffset أو البحث قبل الإزاحة 0 للشريحة المشتركة.

NAME

sharedpos - a base class for objects that are identified by a position in a file or stream.

SYNOPSIS

#include <bobcat/sharedpos>

namespace Bobcat {

class SharedPos {

public:
    SharedPos();
    SharedPos(const char *filename, long offset, long size);
    SharedPos(const SharedPos &other);
    virtual ~SharedPos();

    operator=(const SharedPos &other);

    bool empty() const;
    long offset() const;
    long size() const;
    const char *filename() const;

    void swap(SharedPos &other);

private:
    // uncopyable
    SharedPos(const SharedPos &other);

};

} // namespace Bobcat

DESCRIPTION

The SharedPos class is a base class for objects that are identified by a position in a file or stream. The position is defined by the filename, an offset and a size.

The filename is the name of the file in which the object is located. The offset is the position of the object within the file, and the size is the size of the object.

The SharedPos class is not intended to be used directly. It is intended to be inherited by other classes that represent objects with a position in a file or stream.

NAMESPACE

All methods and classes defined in this library are in the namespace Bobcat.

INHERITS FROM

None.

TYPEDEFS AND ENUMS

None.

CONSTRUCTORS

SharedPos()
Constructs a SharedPos object. The filename, offset, and size are all initialized to empty values.
SharedPos(const char *filename, long offset, long size)
Constructs a SharedPos object with the given filename, offset, and size.
SharedPos(const SharedPos &other)
Copy constructor.
~SharedPos()
Destructor.

OVERLOADED OPERATORS

operator=(const SharedPos &other)
Assignment operator.

MEMBER FUNCTIONS

empty() const
Returns true if the SharedPos object is empty (i.e., filename is null, offset and size are 0). Otherwise, returns false.
filename() const
Returns the filename associated with the SharedPos object. Returns null if the filename is not set.
offset() const
Returns the offset associated with the SharedPos object. Returns 0 if the offset is not set.
size() const
Returns the size associated with the SharedPos object. Returns 0 if the size is not set.
swap(SharedPos &other)
Swaps the contents of this SharedPos object with another one.
