Shell__Config__Generate(3pm)

الحزمة: perl-shell-config-generate

التراخيص: PerlArtistic

الاسم

Shell::Config::Generate

الإصدار

0.34-9

الملخص

use Shell::Config::Generate;

قم بإنشاء مثيل جديد لـ Shell::Config::Generate واستخدمه لتوليد شفرة تكوين الـ shell.

الوصف

يقوم هذا الوحدة بتوليد شفرة تكوين الـ shell لمختلف الـ shells. يقوم بإنشاء اختصارات (aliases) لتلك الـ shells التي تدعمها، ويستخدم فاصل المسار الافتراضي للـ shell. على نظام التشغيل Windows، يستخدم وظيفة بسيطة بدلاً من اختصار لـ PowerShell للسماح بتحديد الوسائط.

المُنشئ

يقوم المُنشئ بإنشاء مثيل جديد لـ Shell::Config::Generate وتهيئته بالتكوين المُعطى.

الطرق

تقوم الطرق بتوليد شفرة تكوين الـ shell للـ shell المُعطى. $shell هو مثيل لـ Shell::Guess. إذا لم يتم توفير $shell، فإن هذه الطريقة تستخدم Shell::Guess لتخمين الـ shell الذي استدعى سكربت perl الخاص بك.

الوظائف

تقوم الوظائف بتوليد شفرة تكوين الـ shell للـ shell المُعطى وكتابتها إلى الملف المُعطى. $shell هو مثيل لـ Shell::Guess. إذا كان هناك خطأ في الإدخال/الإخراج، فسيتم إطلاق استثناء.

تحذيرات

يقوم نظام الاختبار باختبار ناتج هذه الوحدة مقابل الـ shells الفعلية التي يجب أن تفهمها، إذا كان يمكن العثور عليها في المسار. يمكنك إنشاء تكوينات لـ shells غير متاحة (على سبيل المثال، تكوينات "cmd.exe" من UNIX أو تكوينات bourne تحت نظام Windows)، ولكن نظام الاختبار يختبرها فقط إذا تم العثور عليها أثناء بناء هذه الوحدة.

يعتمد التنفيذ لـ "csh" على الأمر الخارجي "test". على حد علمي، يجب أن يكون الأمر "test" متاحًا في جميع إصدارات UNIX الحديثة التي تستخدم "csh". إذا تمكن أي شخص من معرفة كيفية إضافة بادئة أو لاحقة لمتغير البيئة من نوع المسار بدون أمر خارجي في "csh"، فسيكون التصحيح موضع تقدير.

العبارة المستخدمة لإضافة بادئة ولاحقة للعناصر إلى مسار في "csh" تستحق تعليقًا هنا على الأرجح. تبدو كالتالي:

test "$?PATH" = 0 && setenv PATH '/foo/bar/bin:/bar/foo/bin' || setenv PATH "$PATH":'/foo/bar/bin:/bar/foo/bin';
•
سطر واحد

الأمر كله في سطر واحد، ولا يستخدم if، وهو ربما أكثر وضوحًا وأصالة. هذا، على سبيل المثال، قد يكون له معنى أكبر:

if ( $?PATH == 0 ) then
  setenv PATH '/foo/bar/bin:/bar/foo/bin'
else
  setenv PATH "$PATH":'/foo/bar/bin:/bar/foo/bin'
endif

ومع ذلك، هذا يعمل فقط إذا تم تفسير الشفرة باستخدام أمر "source" الخاص بـ csh أو تم تضمينها في سكربت csh بشكل مباشر. إذا حاولت استدعاء هذه الشفرة باستخدام "eval" الخاص بـ csh، فسيقوم بتحويلها تلقائيًا إلى سطر واحد ولن تعمل مع csh في سطر واحد.

ربما توجد طرق أذكى أو أجمل لإضافة/إلحاق متغيرات البيئة للمسار حيث أنني لست مبرمج shell. التصحيحات مرحب بها.

يتم دعم UNIX (bourne، bash، csh، ksh، fish ومشتقاتها) و Windows (command.com، cmd.exe و PowerShell) فقط حتى الآن.

يجب اعتبار دعم Fish shell معاينة تقنية. Fish shell نفسه في حالة تقلب، وبالتالي يتم تخطي بعض الاختبارات لـ Fish shell لأن السلوك يختلف باختلاف الإصدارات. على وجه الخصوص، قد لا تعمل الأسطر الجديدة في متغيرات البيئة في الإصدارات الأحدث.

التصحيحات مرحب بها لـ shell / نظام التشغيل المفضل لديك.
