shmem_barrier_all(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SHMEM_BARRIER_ALL(3) Open MPI SHMEM_BARRIER_ALL(3)

shmem_barrier_all - يعلّق تنفيذ PE المتصل حتى تقوم جميع PEs الأخرى باستدعاء هذا البيان المحدد shmem_barrier_all().

ملخص

C أو C++:

#include <mpp/shmem.h>
void shmem_barrier_all(void)

Fortran:

include 'mpp/shmem.h'
CALL SHMEM_BARRIER_ALL

الوصف

لا تعود الدالة shmem_barrier_all حتى تقوم جميع PEs الأخرى بالدخول إلى هذه الدالة في نفس نقطة مسار التنفيذ.

قبل مزامنة PEs الأخرى، تضمن shmem_barrier_all اكتمال جميع مخازن الذاكرة المحلية المسبقة وتحديثات الذاكرة البعيدة الصادرة عبر دوال SHMEM مثل shmem_put32(3).

أمثلة

setup_data()
{
  if (shmem_my_pe() == 0) {
    setup();
  }
  /* جميع PEs تنتظر PE 0 لإكمال setup().  */
  shmem_barrier_all();
}
