Specio__Exception(3pm)

الحزمة: perl-specio

التراخيص: GPL, PerlArtistic

Specio::Exception(3) وثائق مساهمات المستخدم Perl Specio::Exception(3)

الاسم

Specio::Exception - فئة استثناء لفشل قيود النوع

الإصدار

الإصدار 0.53

الملخص

use Try::Tiny;
try {
    $type->validate_or_die($value);
}
catch {
    if ( $_->isa('Specio::Exception') ) {
        print $_->message, "\n";
        print $_->type->name, "\n";
        print $_->value, "\n";
    }
};

الوصف

يتم طرح فئة الاستثناء هذه بواسطة Specio عند فشل فحص النوع. إنها تحاكي واجهة برمجة تطبيقات Throwable::Error، ولكنها لا تستخدم تلك الوحدة لتجنب إضافة تبعية على Moo.

واجهة برمجة التطبيقات

توفر هذه الفئة الطرق التالية:

$exception->message

رسالة الخطأ المرتبطة بالاستثناء.

$exception->stack_trace

كائن Devel::StackTrace للاستثناء.

$exception->type

كائن قيد النوع الذي فشلت القيمة مقابله.

$exception->value

القيمة التي فشلت في فحص النوع.

$exception->as_string

الاستثناء كسلسلة نصية. يشمل ذلك الطريقة وتتبع المكدس.

التحميل الزائد

تقوم هذه الفئة بتحميل السلسلة النصية بشكل زائد لاستدعاء طريقة "as_string".
