الحزمة: spamassassin

التراخيص: APACHE

NAME

spamassassin — SpamAssassin(tm) is a Perl module that implements a full, highly-configurable spam filtering system.

DESCRIPTION

SpamAssassin(tm) is an e-mail filtering program that identifies spam (unsolicited e-mail) and ham (legitimate e-mail).

It works by running a suite of tests against incoming messages. Each message is assigned a score based on the results of these tests. If the score exceeds a predefined threshold, the message is classified as spam.

SpamAssassin can be configured to run in several ways, including as a standalone daemon, as a front-end to a mail server, or as a simple filter for individual users.

SYNOPSIS

    use Mail::SpamAssassin;

    # Create a SpamAssassin object
    my $spamtest = Mail::SpamAssassin->new();

    # Process a message
    my $result = $spamtest->check($message);

    # Set the message as spam or ham
    $spamtest->set_report($result); # or $spamtest->set_result("spam")
    $spamtest->learn($result);     # or $spamtest->learn(0) for ham

CONFIGURATION FILES

SpamAssassin can be configured via the following files:

${prefix}/etc/mail/spamassassin/
System-wide configuration files.
~/.spamassassin/
User-specific configuration files.

The main configuration file is v310.pre, which is typically located in /etc/mail/spamassassin/.

For more information on configuration, please refer to the Mail::SpamAssassin::Conf documentation.

TAGGING

SpamAssassin can add various headers to messages to indicate the likelihood of them being spam (unsolicited e-mail) or ham (non-spam).

X-Spam-Checker-Version: header
The version and subversion of SpamAssassin and the host where SpamAssassin was run.
X-Spam-Level: header
A series of "*" characters where each one represents a full score point.
X-Spam-Status: header
A string, "(Yes|No), score=nn required=nn tests=xxx,xxx autolearn=(ham|spam|no|unavailable|failed)" is set in this header to reflect the filter status. For the first word, "Yes" means spam and "No" means ham (non-spam).

The headers that added are fully configurable via the "add_header" option (see "Mail::SpamAssassin::Conf" for more information).

INSTALLATION

The spamassassin command is part of the Mail::SpamAssassin Perl module. Install this as a normal Perl module, using "perl -MCPAN -e shell", or by hand.

Note that it is not possible to use the "PERL5LIB" environment variable to affect where SpamAssassin finds its perl modules, due to limitations imposed by perl's "taint" security checks.

For further details on how to install, please read the "INSTALL" file from the SpamAssassin distribution.
