SPI_gettypeid(3)

الحزمة: postgresql

التراخيص: PostgreSQL

SPI_GETTYPEID(3) PostgreSQL 18.1 Documentation SPI_GETTYPEID(3)

الاسم

SPI_gettypeid - إرجاع معرف OID لنوع البيانات للعمود المحدد

الملخص

Oid SPI_gettypeid(TupleDesc rowdesc, int colnumber)

الوصف

SPI_gettypeid ترجع معرف OID لنوع بيانات العمود المحدد.

المعاملات

TupleDesc rowdesc

وصف الصف المدخل

int colnumber

رقم العمود (العد يبدأ من 1)

قيمة الإرجاع

معرف OID لنوع بيانات العمود المحدد أو InvalidOid عند حدوث خطأ. عند حدوث خطأ، يتم تعيين SPI_result إلى SPI_ERROR_NOATTRIBUTE.
