SPI_register_relation(3)

الحزمة: postgresql

التراخيص: PostgreSQL

SPI_REGISTER_RELATION(3) وثائق PostgreSQL 18.1 SPI_REGISTER_RELATION(3)

الاسم

SPI_register_relation - جعل علاقة مسماة مؤقتة متاحة بالاسم في استعلامات SPI

الملخص

int SPI_register_relation(EphemeralNamedRelation enr)

الوصف

SPI_register_relation تجعل علاقة مسماة مؤقتة، مع المعلومات المرتبطة بها، متاحة للاستعلامات التي يتم تخطيطها وتنفيذها عبر اتصال SPI الحالي.

الوسائط

EphemeralNamedRelation enr

مدخل سجل العلاقة المسماة المؤقتة

قيمة الإرجاع

إذا نجح تنفيذ الأمر، فسيتم إرجاع القيمة التالية (غير السالبة):

SPI_OK_REL_REGISTER

إذا تم تسجيل العلاقة بنجاح بالاسم

عند حدوث خطأ، سيتم إرجاع إحدى القيم السالبة التالية:

SPI_ERROR_ARGUMENT

إذا كانت enr فارغة أو كان حقل name الخاص بها فارغًا

SPI_ERROR_UNCONNECTED

إذا تم الاستدعاء من دالة C غير متصلة

SPI_ERROR_REL_DUPLICATE

إذا كان الاسم المحدد في حقل name الخاص بـ enr مسجلاً بالفعل لهذا الاتصال
