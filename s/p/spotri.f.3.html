توثيق الوظيفة/الإجراء الفرعي

subroutine spotri (character uplo, integer n, real, dimension( lda, * ) a, integer lda, integer info)

SPOTRI

الغرض:

!>
!> تقوم SPOTRI بحساب معكوس مصفوفة حقيقية متماثلة موجبة محددة
!> A باستخدام تحليل Cholesky A = U**T*U أو A = L*L**T
!> الذي تم حسابه بواسطة SPOTRF.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  المثلث العلوي لـ A مخزن؛
!>          = 'L':  المثلث السفلي لـ A مخزن.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

A

!>          A هو مصفوفة REAL، أبعادها (LDA,N)
!>          عند الإدخال، العامل المثلثي U أو L من تحليل Cholesky
!>          A = U**T*U أو A = L*L**T، كما تم حسابه بواسطة
!>          SPOTRF.
!>          عند الخروج، المثلث العلوي أو السفلي للمصفوفة المعكوسة (المتماثلة)
!>          لـ A، مساوياً للعامل المدخل U أو L.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت لها قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن العنصر (i,i) للعامل U أو L هو
!>                صفر، ولم يكن بالإمكان حساب المعكوس.
!>
