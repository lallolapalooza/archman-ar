Function/Subroutine Documentation

SPPSVX( UPLO, N, NRHS, AP, AFP, LDA, IPIV, B, LDB, X, LDX, RCOND, FERR, BERR, WORK, IWORK, INFO )

PURPOSE: The subroutine SPPSVX uses the packed storage scheme to compute the solution to a complex system of linear equations AX = B, where A is a symmetric positive definite matrix, and its factorizations are computed by SPPSFA.

ARGUMENTS:

UPLO

CHARACTER*1
          On entry, UPLO specifies whether the upper or lower
          triangular part of the symmetric matrix A is stored.
          UPLO = 'U' or 'u'   Upper triangular
          UPLO = 'L' or 'l'   Lower triangular

N

INTEGER
          On entry, N is the order of the matrix A, and the number of
          linear systems to be solved.

NRHS

INTEGER
          On entry, NRHS is the number of right hand sides, i.e., the
          number of columns of the matrices B and X.

AP

REAL array, dimension (N*(N+1)/2)
          Before entry, the array AP contains the packed symmetric matrix
          A. See below for more information on packed storage.

AFP

REAL array, dimension (N*(N+1)/2)
          Before entry, if UPLO = 'U' or 'L', then AFP contains the
          packed Cholesky factorization of A computed by SPPSFA.
          If UPLO = 'U' or 'u', the upper triangle of A is packed column
          by column by the same format used by SPPSFA.
          If UPLO = 'L' or 'l', the lower triangle of A is packed column
          by column by the same format used by SPPSFA.

LDA

INTEGER
          On entry, LDA is the leading dimension of the array AFP.

IPIV

INTEGER array, dimension (N)
          On entry, the pivot information for the factorization of A.
          See below for more information.

B

REAL array, dimension (LDB, NRHS)
          On entry, B is the right hand side matrix of size LDA by NRHS.
          On exit, the array B has been overwritten by the solution matrix X.

LDB

INTEGER
          On entry, LDB is the leading dimension of the array B.

X

REAL array, dimension (LDX, NRHS)
          On exit, X contains the solution to the system of linear
          equations.

LDX

INTEGER
          On entry, LDX is the leading dimension of the array X.

RCOND

REAL
          On exit, RCOND is an estimate of the reciprocal of the condition
          number of the matrix A. RCOND is always less than or equal to 1.

FERR

REAL array, dimension (NRHS)
          The estimated forward error bound for each solution vector
          X(j) (the j-th column of the solution matrix X).
          If XTRUE is the true solution corresponding to X(j), FERR(j)
          is an estimated upper bound for the magnitude of the largest
          element in (X(j) - XTRUE) divided by the magnitude of the
          largest element in X(j).  The estimate is as reliable as
          the estimate for RCOND, and is almost always a slight
          overestimate of the true error.

BERR

REAL array, dimension (NRHS)
          The componentwise relative backward error of each solution
          vector X(j) (i.e., the smallest relative change in
          any element of A or B that makes X(j) an exact solution).

WORK

REAL array, dimension (3*N)

IWORK

INTEGER array, dimension (N)

INFO

INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  if INFO = i, and i is
                <= N:  the leading principal minor of order i of A
                       is not positive, so the factorization could not
                       be completed, and the solution has not been
                       computed. RCOND = 0 is returned.
                = N+1: U is nonsingular, but RCOND is less than machine
                       precision, meaning that the matrix is singular
                       to working precision.  Nevertheless, the
                       solution and error bounds are computed because
                       there are a number of situations where the
                       computed solution can be more accurate than the
                       value of RCOND would suggest.
