sprof(1) دليل الأوامر العامة sprof(1)

الاسم

sprof - قراءة وعرض بيانات تحليل الأداء للكائنات المشتركة

الاستخدام

sprof [خيار ...] مسار-الكائن-المشترك [مسار-بيانات-التحليل]

الوصف

يقوم الأمر sprof بعرض ملخص تحليل الأداء للكائن المشترك (مكتبة مشتركة) المحدد كوسيط أول في سطر الأوامر. يتم إنشاء ملخص تحليل الأداء باستخدام بيانات تحليل الأداء التي تم إنشاؤها مسبقًا في الوسيط الثاني في سطر الأوامر (اختياري). إذا تم حذف مسار بيانات تحليل الأداء، فسيحاول sprof استنتاجه باستخدام اسم مصدر الكائن المشترك، والبحث عن ملف بالاسم <soname>.profile في الدليل الحالي.

الخيارات

تحدد خيارات سطر الأوامر التالية مخرجات تحليل الأداء المراد إنتاجها:

--call-pairs
-c
طباعة قائمة بأزواج مسارات الاستدعاء للواجهات التي يصدّرها الكائن المشترك، جنبًا إلى جنب مع عدد المرات التي يتم فيها استخدام كل مسار.
--flat-profile
-p
إنشاء تحليل مسطح لجميع الدوال في الكائن المراقب، مع عدد الاستدعاءات والنقرات.
--graph
-q
إنشاء رسم بياني للاستدعاءات.

إذا لم يتم تحديد أي من الخيارات المذكورة أعلاه، فإن السلوك الافتراضي هو عرض تحليل مسطح ورسم بياني للاستدعاءات.

تتوفر خيارات سطر الأوامر الإضافية التالية:

--help
-?
عرض ملخص لخيارات وسائط سطر الأوامر والخروج.
--usage
عرض رسالة استخدام قصيرة والخروج.
--version
-V
عرض إصدار البرنامج والخروج.

المعايير

GNU.

أمثلة

يوضح المثال التالي استخدام sprof. يتكون المثال من برنامج رئيسي يستدعي دالتين في كائن مشترك. أولاً، رمز البرنامج الرئيسي:


$ cat prog.c;
#include <stdlib.h>
void x1(void);
void x2(void);
int
main(int argc, char *argv[])
{
    x1();
    x2();
    exit(EXIT_SUCCESS);
}

تم تعريف الدالتين x1() و x2() في ملف المصدر التالي المستخدم لبناء الكائن المشترك:


$ cat libdemo.c;
#include <unistd.h>
void
consumeCpu1(int lim)
{
    for (unsigned int j = 0; j < lim; j++)
	getppid();
}
void
x1(void) {
    for (unsigned int j = 0; j < 100; j++)
	consumeCpu1(200000);
}
void
consumeCpu2(int lim)
{
    for (unsigned int j = 0; j < lim; j++)
	getppid();
}
void
x2(void)
{
    for (unsigned int j = 0; j < 1000; j++)
	consumeCpu2(10000);
}

الآن نقوم ببناء الكائن المشترك بالاسم الحقيقي libdemo.so.1.0.1، واسم المصدر libdemo.so.1:


$ cc -g -fPIC -shared -Wl,-soname,libdemo.so.1 \
        -o libdemo.so.1.0.1 libdemo.c;

ثم نقوم بإنشاء روابط رمزية لاسم مصدر المكتبة واسم رابط المكتبة:


$ ln -sf libdemo.so.1.0.1 libdemo.so.1;
$ ln -sf libdemo.so.1 libdemo.so;

بعد ذلك، نقوم بتجميع البرنامج الرئيسي، وربطه بالكائن المشترك، ثم نسرد تبعيات البرنامج الديناميكية:


$ cc -g -o prog prog.c -L. -ldemo;
$ ldd prog;
	linux-vdso.so.1 =>  (0x00007fff86d66000)
	libdemo.so.1 => not found
	libc.so.6 => /lib64/libc.so.6 (0x00007fd4dc138000)
	/lib64/ld-linux-x86-64.so.2 (0x00007fd4dc51f000)

للحصول على معلومات تحليل الأداء للكائن المشترك، نقوم بتعريف متغير البيئة LD_PROFILE باسم مصدر المكتبة:


$ export LD_PROFILE=libdemo.so.1;

ثم نقوم بتعريف متغير البيئة LD_PROFILE_OUTPUT بمسار الدليل الذي يجب كتابة مخرجات تحليل الأداء فيه، وننشئ هذا الدليل إذا لم يكن موجودًا بالفعل:


$ export LD_PROFILE_OUTPUT=$(pwd)/prof_data;
$ mkdir -p $LD_PROFILE_OUTPUT;

يتسبب LD_PROFILE في *إلحاق* مخرجات تحليل الأداء بالملف الناتج إذا كان موجودًا بالفعل، لذلك نتأكد من عدم وجود بيانات تحليل أداء سابقة:


$ rm -f $LD_PROFILE_OUTPUT/$LD_PROFILE.profile;

ثم نقوم بتشغيل البرنامج لإنتاج مخرجات تحليل الأداء، والتي تتم كتابتها إلى ملف في الدليل المحدد في LD_PROFILE_OUTPUT:


$ LD_LIBRARY_PATH=. ./prog;
$ ls prof_data;
libdemo.so.1.profile

ثم نستخدم الخيار sprof -p لإنشاء تحليل مسطح مع عدد الاستدعاءات والنقرات:


$ sprof -p libdemo.so.1 $LD_PROFILE_OUTPUT/libdemo.so.1.profile;
Flat profile:
Each sample counts as 0.01 seconds.
  %   cumulative   self              self     total
 time   seconds   seconds    calls  us/call  us/call  name
 60.00      0.06     0.06      100   600.00           consumeCpu1
 40.00      0.10     0.04     1000    40.00           consumeCpu2
  0.00      0.10     0.00        1     0.00           x1
  0.00      0.10     0.00        1     0.00           x2

يقوم الخيار sprof -q بإنشاء رسم بياني للاستدعاءات:


$ sprof -q libdemo.so.1 $LD_PROFILE_OUTPUT/libdemo.so.1.profile;
index % time    self  children    called     name
                0.00    0.00      100/100         x1 [1]
[0]    100.0    0.00    0.00      100         consumeCpu1 [0]
-----------------------------------------------
                0.00    0.00        1/1           <UNKNOWN>
[1]      0.0    0.00    0.00        1         x1 [1]
                0.00    0.00      100/100         consumeCpu1 [0]
-----------------------------------------------
                0.00    0.00     1000/1000        x2 [3]
[2]      0.0    0.00    0.00     1000         consumeCpu2 [2]
-----------------------------------------------
                0.00    0.00        1/1           <UNKNOWN>
[3]      0.0    0.00    0.00        1         x2 [3]
                0.00    0.00     1000/1000        consumeCpu2 [2]
-----------------------------------------------

تمثل السلاسل "<UNKNOWN>" أعلاه وأدناه المعرفات التي تقع خارج الكائن الذي تم تحليله (في هذا المثال، هذه هي حالات main()).

يقوم الخيار sprof -c بإنشاء قائمة بأزواج الاستدعاء وعدد تكراراتها:


$ sprof -c libdemo.so.1 $LD_PROFILE_OUTPUT/libdemo.so.1.profile;
<UNKNOWN>                  x1                                 1
x1                         consumeCpu1                      100
<UNKNOWN>                  x2                                 1
x2                         consumeCpu2                     1000
