NAME

sphinx-quickstart - Quickly set up a Sphinx documentation directory

SYNOPSIS

sphinx-quickstart [options] sourcedir

DESCRIPTION

sphinx-quickstart is a script that sets up a new Sphinx documentation directory. Sphinx is a documentation generator that takes reStructuredText markup files as input and produces HTML, LaTeX, and other formats. It is widely used for Python documentation.

When you run sphinx-quickstart, it will ask you a series of questions to configure your documentation project. These questions include:

  • Project name
  • Author name(s)
  • Project release
  • Project language

It will then create a directory structure and necessary configuration files (like conf.py and Makefile) for your Sphinx project.

OPTIONS

-h, --help
Show help message and exit.
-q, --quiet
Do not show any messages, except for errors.
-v, --verbose
Show more detailed output.
-p <project_name>, --project <project_name>
Set the project name.
-a <author_name>, --author <author_name>
Set the author name(s).
-r <release>, --release <release>
Set the project release.
-l <language>, --language <language>
Set the project language (e.g., 'en' for English, 'es' for Spanish).
--use-make=yes|no
Whether to create a Makefile for building the documentation (default: yes).
--dot
Enable the dot graph extension.
--nosplit
Disable the ability to automatically split source files.

FILES

conf.py
The main Sphinx configuration file.
Makefile
A Makefile to build the documentation using make html, make latexpdf, etc.
make.bat
A Windows batch file equivalent to the Makefile.
index.rst
The main reStructuredText file for your documentation.

EXAMPLE

To set up a new Sphinx project in a directory called docs:

sphinx-quickstart docs

This will prompt you for project details. You can also pre-configure some options:

sphinx-quickstart --project="My Project" --author="John Doe" docs
