spu_run(2) دليل استدعاءات النظام spu_run(2)

الاسم

spu_run - تنفيذ سياق SPU

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/spu.h>          /* تعريف الثوابت SPU_* */
#include <sys/syscall.h>      /* تعريف الثوابت SYS_* */
#include <unistd.h>
int syscall(SYS_spu_run, int fd, uint32_t *npc, uint32_t *event);

ملاحظة: لا توفر glibc غلافًا لـ spu_run()، مما يستلزم استخدام syscall(2).

الوصف

يُستخدم استدعاء النظام spu_run() على أجهزة PowerPC التي تطبق بنية محرك التوصيل الخلوي (Cell Broadband Engine Architecture) للوصول إلى وحدات المعالجة التآزرية (SPUs). الوسيط fd هو واصف ملف تم إرجاعه بواسطة spu_create(2) والذي يشير إلى سياق SPU محدد. عندما يتم جدولة السياق لوحدة SPU فعلية، تبدأ التنفيذ عند مؤشر التعليمات المُمرر في npc.

يحدث تنفيذ كود SPU بشكل متزامن، مما يعني أن spu_run() يحظر أثناء تشغيل SPU. إذا كانت هناك حاجة لتنفيذ كود SPU بالتوازي مع كود آخر على وحدة المعالجة الرئيسية أو وحدات SPU الأخرى، فيجب إنشاء خيط تنفيذ جديد أولاً (على سبيل المثال، باستخدام pthread_create(3)).

عندما يعود spu_run()، تتم كتابة القيمة الحالية لعداد برنامج SPU إلى npc، لذا يمكن للاستدعاءات المتتالية لـ spu_run() استخدام نفس مؤشر npc.

يوفر الوسيط event مخزنًا مؤقتًا لرمز حالة موسع. إذا تم إنشاء سياق SPU بالعلامة SPU_CREATE_EVENTS_ENABLED، فسيتم ملء هذا المخزن المؤقت بواسطة نواة Linux قبل عودة spu_run().

قد يكون رمز الحالة واحدًا (أو أكثر) من الثوابت التالية:

SPE_EVENT_DMA_ALIGNMENT
حدث خطأ في محاذاة DMA.
SPE_EVENT_INVALID_DMA
تمت محاولة أمر DMA غير صالح من MFC.
SPE_EVENT_SPE_DATA_STORAGE
حدث خطأ في تخزين DMA.
SPE_EVENT_SPE_ERROR
تم تنفيذ تعليمات غير قانونية.

القيمة NULL هي قيمة صالحة للوسيط event. في هذه الحالة، لن يتم الإبلاغ عن الأحداث إلى العملية المتصلة.

قيمة الإرجاع

عند النجاح، يُرجع spu_run() قيمة السجل spu_status. عند الفشل، يُرجع -1 ويتم تعيين errno للإشارة إلى الخطأ.

قيمة السجل spu_status هي قناع بت لرموز الحالة وربما رمز ذي 14 بت تم إرجاعه من تعليمة stop-and-signal في SPU. أقنعة البتات لرموز الحالة هي:

0x02
تم إيقاف SPU بواسطة تعليمة stop-and-signal.
0x04
تم إيقاف SPU بواسطة تعليمة halt.
0x08
SPU ينتظر قناة.
0x10
SPU في وضع الخطوة الواحدة.
0x20
حاول SPU تنفيذ تعليمات غير صالحة.
0x40
حاول SPU الوصول إلى قناة غير صالحة.
0x3fff0000
البتات التي تم حجبها بهذا القيمة تحتوي على الرمز الذي تم إرجاعه من تعليمة stop-and-signal. هذه البتات صالحة فقط إذا تم تعيين البت 0x02.

إذا لم يُرجع spu_run() خطأ، فسيتم دائمًا تعيين واحد أو أكثر من البتات ضمن الثمانية بتات الدنيا.

الأخطاء

EBADF
fd ليس واصف ملف صالح.
EFAULT
npc ليس مؤشرًا صالحًا، أو event غير NULL ومؤشر غير صالح.
EINTR
حدثت إشارة أثناء تقدم spu_run()؛ انظر signal(7). تم تحديث قيمة npc إلى قيمة عداد البرنامج الجديدة إذا لزم الأمر.
EINVAL
fd ليس واصف ملف صالح تم إرجاعه من spu_create(2).
ENOMEM
لم تكن هناك ذاكرة كافية متاحة للتعامل مع خطأ الصفحة الناتج عن وصول DMA لـ MFC (Memory Flow Controller).
ENOSYS
الوظيفة غير مقدمة من النظام الحالي، إما لأن الأجهزة لا توفر SPUs أو أن وحدة spufs ليست محملة.

المعايير

Linux على PowerPC.

التاريخ

Linux 2.6.16.

ملاحظات

spu_run() مخصص للاستخدام من المكتبات التي تطبق واجهة أكثر تجريدًا لوحدات SPU، وليس للاستخدام من التطبيقات العادية. انظر http://www.bsc.es/projects/deepcomputing/linuxoncell/ للمكتبات الموصى بها.

أمثلة

فيما يلي مثال على تشغيل برنامج SPU بسيط، بتعليمة واحدة، باستخدام استدعاء النظام spu_run().

#include <err.h>
#include <fcntl.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
int main(void)
{
    int       context, fd, spu_status;
    uint32_t  instruction, npc;
    context = syscall(SYS_spu_create, "/spu/example-context", 0, 0755);
    if (context == -1)
        err(EXIT_FAILURE, "spu_create");
    /*
     * كتابة تعليمة 'stop 0x1234' إلى ذاكرة المتجر المحلية
     * لوحدة SPU.
     */
    instruction = 0x00001234;
    fd = open("/spu/example-context/mem", O_RDWR);
    if (fd == -1)
        err(EXIT_FAILURE, "open");
    write(fd, &instruction, sizeof(instruction));
    /*
     * تعيين npc إلى عنوان التعليمات البادئ لبرنامج
     * SPU.  نظرًا لأننا كتبنا التعليمات في بداية ملف mem،
     * فإن نقطة الدخول ستكون 0x0.
     */
    npc = 0;
    spu_status = syscall(SYS_spu_run, context, &npc, NULL);
    if (spu_status == -1)
        err(EXIT_FAILURE, "open");
    /*
     * يجب أن نرى رمز حالة 0x12340002:
     *   0x00000002 (تم إيقاف SPU بسبب stop-and-signal)
     * | 0x12340000 (رمز stop-and-signal)
     */
    printf("SPU Status: %#08x\n", spu_status);
    exit(EXIT_SUCCESS);
}
