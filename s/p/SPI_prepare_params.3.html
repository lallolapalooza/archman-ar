SPI_prepare_params(3)

الحزمة: postgresql

التراخيص: PostgreSQL

SPI_PREPARE_PARAMS(3) توثيق PostgreSQL 18.1 SPI_PREPARE_PARAMS(3)

الاسم

SPI_prepare_params - تحضير عبارة، دون تنفيذها حتى الآن

ملخص

SPIPlanPtr SPI_prepare_params(const char * command,
                              ParserSetupHook parserSetup,
                              void * parserSetupArg,
                              int cursorOptions)

الوصف

SPI_prepare_params تنشئ وتعيد عبارة مُعدة للأمر المحدد، ولكنها لا تنفذ الأمر. هذه الوظيفة تعادل SPI_prepare_cursor، مع إضافة أن المستدعي يمكنه تحديد دوال الربط الخاصة بالمحلل للتحكم في تحليل مراجع المعلمات الخارجية.

تم إيقاف هذه الوظيفة الآن لصالح SPI_prepare_extended.

الوسائط

const char * command

سلسلة الأمر

ParserSetupHook parserSetup

دالة إعداد الربط الخاصة بالمحلل

void * parserSetupArg

وسيط تمرير لـ parserSetup

int cursorOptions

قناع بت عدد صحيح لخيارات المؤشر؛ صفر ينتج السلوك الافتراضي

قيمة الإرجاع

SPI_prepare_params لديها نفس اتفاقيات الإرجاع مثل SPI_prepare.
