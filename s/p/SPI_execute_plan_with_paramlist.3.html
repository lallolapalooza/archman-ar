SPI_execute_plan_with_paramlist(3)

الحزمة: postgresql

التراخيص: PostgreSQL

SPI_EXECUTE_PLAN_WITH_PARAMLIST(3) توثيق PostgreSQL 18.1 SPI_EXECUTE_PLAN_WITH_PARAMLIST(3)

الاسم

SPI_execute_plan_with_paramlist - تنفيذ عبارة تم إعدادها بواسطة SPI_prepare

الملخص

int SPI_execute_plan_with_paramlist(SPIPlanPtr plan,
                                    ParamListInfo params,
                                    bool read_only,
                                    long count)

الوصف

SPI_execute_plan_with_paramlist ينفذ عبارة تم إعدادها بواسطة SPI_prepare. هذه الدالة مكافئة لـ SPI_execute_plan باستثناء أن معلومات حول قيم المعلمات التي سيتم تمريرها إلى الاستعلام يتم تقديمها بشكل مختلف. يمكن أن يكون تمثيل ParamListInfo مفيدًا لتمرير القيم التي تم توفيرها بالفعل بهذا التنسيق. كما أنه يدعم استخدام مجموعات المعلمات الديناميكية عبر وظائف الخطاف المحددة في ParamListInfo.

تم إهمال هذه الدالة الآن لصالح SPI_execute_plan_extended.

المعاملات

SPIPlanPtr plan

عبارة معدة (تم إرجاعها بواسطة SPI_prepare)

ParamListInfo params

هيكل بيانات يحتوي على أنواع وقيم المعلمات؛ NULL إذا لم تكن موجودة

bool read_only

true للتنفيذ للقراءة فقط

long count

الحد الأقصى لعدد الصفوف المراد إرجاعها، أو 0 بدون حد

قيمة الإرجاع

قيمة الإرجاع هي نفسها كما في SPI_execute_plan.

يتم تعيين SPI_processed و SPI_tuptable كما في SPI_execute_plan عند النجاح.
