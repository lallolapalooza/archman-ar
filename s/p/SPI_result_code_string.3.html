الاسم

SPI_result_code_string - إرجاع رمز الخطأ كسلسلة نصية

الملخص

const char * SPI_result_code_string(int code);

الوصف

SPI_result_code_string تُرجع تمثيلًا نصيًا لرمز النتيجة الذي تُرجعه دوال SPI المختلفة أو المخزن في SPI_result.
