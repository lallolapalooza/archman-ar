NAME

spank - Slurm Plug-in Loading API

DESCRIPTION

SPANK (Slurm Plug-in Loading API) is a framework for extending the functionality of Slurm. SPANK allows external programs to be loaded and invoked at various points in the Slurm daemon and job execution lifecycle. This document describes the SPANK API and how to use it.

The SPANK framework provides a way to load and unload plug-ins written in C. These plug-ins can hook into various Slurm events and modify Slurm's behavior. SPANK plug-ins are typically loaded via the plugstack.conf file.

SPANK PLUGINS

SPANK plug-ins are shared libraries that implement specific SPANK functions. These functions are called by Slurm at predefined points in its execution. The following table lists some of the common SPANK plug-ins and the events they hook into:

Tool SPANK Function Context Priority Local Remote
srun slurm_spank_init remote 1 no yes
srun slurm_spank_fini remote 0 no yes
srun slurm_spank_task_init remote 1 no yes
srun slurm_spank_task_post_fork remote 1 no yes
srun slurm_spank_task_exit remote 0 no yes
srun slurm_spank_exit allocator 0 no no
sbatch slurm_spank_init remote 1 no yes
sbatch slurm_spank_fini remote 0 no yes
sbatch slurm_spank_task_init remote 1 no yes
sbatch slurm_spank_task_exit remote 0 no no
sbatch slurm_spank_exit allocator 0 no no
scrontab slurm_spank_init allocator 1 no no
scrontab slurm_spank_exit allocator 0 no no

NOTE: The behavior for ProctrackType=proctrack/pgid may result in timeouts for slurm_spank_task_post_fork with remote context on failure.

SPANK OPTIONS

SPANK plug-ins can be configured with options passed from the plugstack.conf file or from the command line. These options are passed to the SPANK plug-in's initialization function.

Common options include:

--conf=<file>
Specifies a configuration file for the plug-in.
--name=<name>
Sets the name of the plug-in instance.
--param=<key>=<value>
Passes a key-value pair to the plug-in.

CONFIGURATION

SPANK plug-ins are configured in the /etc/slurm/plugstack.conf file. The format of this file is as follows:

plugstack.conf {
    plugin {
        name = "example_plugin"
        path = "/usr/lib/slurm/example_spank.so"
        conf = "/etc/slurm/example_plugin.conf"
        options = "key1=value1 key2=value2"
    }
}

This configuration will load the example_spank.so plug-in with the specified options when Slurm starts.

Plug-ins can also be loaded on a per-job basis using the --spank option with srun, sbatch, or other Slurm commands.

Errors

Errors during SPANK plug-in loading or execution are reported to the Slurm log files and may also be printed to standard error. The specific error messages will depend on the plug-in and the nature of the error.
