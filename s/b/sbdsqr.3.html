الاسم

sbdsqr - يحل مشكلة القيمة الذاتية لمصفوفة متناظرة شبه مستمرة.

توثيق الدالة/الإجراء الفرعي

SBDSQR solves the singular value decomposition (SVD) of a real symmetric tridiagonal matrix A. The SVD is computed for A. It is assumed that A is symmetric, so only the upper or lower triangular part of A needs to be provided.

Arguments:

  • UPLO: Character. Specifies whether the upper or lower triangular part of A is supplied.
    • If UPLO = 'U' or 'u', the upper triangle of A is supplied.
    • If UPLO = 'L' or 'l', the lower triangle of A is supplied.
  • N: Integer. The order of the matrix A.
  • KD: Integer. The bandwidth of A. For a tridiagonal matrix, KD = 1.
  • AB: Real array of dimension (LDAB, N). Contains the upper or lower triangular part of the symmetric tridiagonal matrix A.
  • LDAB: Integer. The leading dimension of the array AB.
  • D: Real array of dimension (N). The computed singular values of A.
  • E: Real array of dimension (N-1). The computed sub-diagonal elements of the bidiagonal matrix B, if any.
  • Z: Real array of dimension (LDZ, N). Contains the normalized eigenvectors, one from each column. Column j contains the eigenvector corresponding to the singular value D(j).
  • LDZ: Integer. The leading dimension of the array Z.
  • WORK: Real array of dimension (LWORK).
  • LWORK: Integer. The dimension of the array WORK.
  • INFO: Integer.
    • 0: successful exit.
    • <0: if INFO = -i, then the i-th argument had an illegal value.
    • >0: if INFO = i, then the algorithm failed to converge; i off-diagonal elements of an intermediate bidiagonal matrix did not converge to zero.
