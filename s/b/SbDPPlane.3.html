الوصف التفصيلي

الفئة SbDPPlane تمثل مستويًا في الفضاء ثلاثي الأبعاد.

يتم استخدام SbDPPlane بواسطة العديد من الفئات الأخرى في Coin. إنها توفر طريقة لتمثيل مستوي، محدد بواسطة متجه عمودي للمستوي ومسافة من نقطة الأصل للنظام الإحداثي.

كن على علم بأن هذه الفئة هي امتداد لـ Coin، وهي غير متاحة في واجهة برمجة التطبيقات الأصلية Open Inventor v2.1 من SGI.

توثيق المنشئ والمدمّر

SbDPPlane::SbDPPlane (void )

سيتم تهيئة SbDPPlane التي يتم إنشاؤها باستخدام المنشئ الافتراضي غير مهيأة.

SbDPPlane::SbDPPlane (const SbVec3d & normalref, const double D)

قم بإنشاء مثيل SbDPPlane بمتجه عمودي يشير في الاتجاه المعطى والمسافة القصيرة المعطاة من نقطة الأصل للنظام الإحداثي إلى نقطة في المستوي.

normal يجب ألا يكون متجهًا صفريًا.

SbDPPlane::SbDPPlane (const SbVec3d & p0, const SbVec3d & p1, const SbVec3d & p2)

قم بإنشاء SbDPPlane بثلاث نقاط تقع في المستوي. تأكد من أن p0 و p1 و p2 هي بالفعل ثلاث نقاط مميزة عند استخدام هذا المنشئ.

SbDPPlane::SbDPPlane (const SbVec3d & normalref, const SbVec3d & point)

قم بإنشاء SbDPPlane من متجه عمودي ونقطة تقع في المستوي.

normal يجب ألا يكون متجهًا صفريًا.

توثيق الوظائف الأعضاء

void SbDPPlane::offset (const double d)

أضف الإزاحة المعطاة d إلى مسافة المستوي من نقطة الأصل.

SbBool SbDPPlane::intersect (const SbDPLine & l, SbVec3d & intersection) const

ابحث عن النقطة على الخط المعطى l التي تتقاطع مع المستوي وأعدها في intersection. إذا كان الخط موازيًا للمستوي، فإننا نعيد FALSE، وإلا فنعيد TRUE.

لا تمرر خطًا غير صالح للمعامل l (أي بمتجه اتجاه صفري).

void SbDPPlane::transform (const SbDPMatrix & matrix)

حوّل المستوي باستخدام matrix.

انظر أيضًا

offset()

SbBool SbDPPlane::isInHalfSpace (const SbVec3d & point) const

تحقق مما إذا كانت النقطة المعطاة تقع في نصف الفضاء للمستوي الذي يشير إليه متجه المستوي العمودي.

double SbDPPlane::getDistance (const SbVec3d & point) const

أعد المسافة من point إلى المستوي. المسافة الموجبة تعني أن النقطة في نصف الفضاء للمستوي.

هذه الوظيفة هي امتداد خاص بـ Coin مقارنة بواجهة برمجة التطبيقات الأصلية SGI Inventor.

const SbVec3d & SbDPPlane::getNormal (void ) const

أعد المتجه العمودي للمستوي، والذي يشير إلى اتجاه توجيه المستوي.

انظر أيضًا

getDistanceFromOrigin().

double SbDPPlane::getDistanceFromOrigin (void ) const

أعد المسافة من نقطة الأصل للنظام الإحداثي إلى النقطة في المستوي التي هي الأقرب إلى نقطة الأصل.

انظر أيضًا

getNormal().

void SbDPPlane::print (FILE * fp) const

قم بتفريغ حالة هذا الكائن إلى تدفق الملف fp. تعمل فقط في النسخة التصحيحية من المكتبة، والوظيفة لا تفعل شيئًا في بناء محسّن.

SbBool SbDPPlane::intersect (const SbDPPlane & pl, SbDPLine & line) const

تقاطع هذا المستوي مع pl، وأعد الخط الناتج في line. يعيد TRUE إذا كان يمكن العثور على خط تقاطع، و FALSE إذا كانت المستويات متوازية.

هذه الوظيفة هي امتداد لـ Coin، وهي غير متاحة في واجهة برمجة التطبيقات الأصلية Open Inventor v2.1 من SGI.

    SbDPPlane(3)

    NAME

    SbDPPlane — The SbDPPlane class represents a plane in 3D space.

    SYNOPSIS

    #include <Inventor/SbDPPlane.h>

    Class SbDPPlane

    Inherits SbPlane.

    DESCRIPTION

    The SbDPPlane class represents a plane in 3D space using double precision floating-point numbers. It is derived from the SbPlane class, which uses single precision floating-point numbers.

    A plane is defined by a normal vector and a distance from the origin.

    CONSTRUCTION

    SbDPPlane()

    Constructs an identity plane (normal (0,0,1), distance 0).

    SbDPPlane(const SbVec3f &normal, double distance)

    Constructs a plane with the given normal and distance.

    SbDPPlane(const SbVec3d &normal, double distance)

    Constructs a plane with the given double precision normal and distance.

    SbDPPlane(const SbDPPlane &plane)

    Copy constructor.

    SbDPPlane(const SbPlane &plane)

    Constructs a double precision plane from a single precision plane.

    METHODS

    SbBool isParallel(const SbDPPlane &plane) const

    Returns true if this plane is parallel to the given plane.

    SbBool isCoplanar(const SbDPPlane &plane) const

    Returns true if this plane is coplanar with the given plane.

    void getNormal(SbVec3d &normal) const

    Returns the normal vector of the plane.

    void getNormal(SbVec3f &normal) const

    Returns the normal vector of the plane as a single precision vector.

    double getDistance() const

    Returns the distance of the plane from the origin.

    void setNormal(const SbVec3d &normal)

    Sets the normal vector of the plane.

    void setDistance(double distance)

    Sets the distance of the plane from the origin.

    void normalize()

    Normalizes the plane so that the length of the normal vector is 1.

    SbDPPlane & operator=(const SbDPPlane &plane)

    Assignment operator.

    SbDPPlane & operator=(const SbPlane &plane)

    Assignment operator from a single precision plane.
