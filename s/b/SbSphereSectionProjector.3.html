Detailed Description

This class is derived from SbSpherePlaneProjector and implements projection onto a sphere using a section.

The section is defined by a cutting plane.

This class is primarily used internally by Coin, and is therefore not very well documented.

The radialFactor parameter controls how rotations are calculated outside the sphere.

A radialFactor equal to 0.0 will make the rotations be done like if they were done by dragging the sphere, while a value of 1.0 will make the rotation be around the axis from the viewpoint towards the sphere.

The tolerance parameter decides how much of the half-sphere to do projections against.
