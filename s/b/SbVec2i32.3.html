الوصف التفصيلي

الفئة SbVec2i32 هي متجه ثنائي الأبعاد بإحداثيات أعداد صحيحة موقعة 32 بت.

يتم استخدام فئة المتجهات هذه بواسطة العديد من الفئات الأخرى في Coin. إنها توفر تخزينًا لمتجه في بعدين بالإضافة إلى عمليات حسابية بسيطة للأعداد الصحيحة.

Detailed Description

This class represents a 2D vector with integer components.

It is used in several Coin classes to represent coordinates, directions, and other 2D vector quantities.
