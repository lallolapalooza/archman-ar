void SbViewVolume::print (FILE * fp) const

تفريغ حالة هذا الكائن إلى مجرى الملف fp. يعمل فقط في الإصدار الذي يتم تصحيحه من المكتبة، ولا تقوم الدالة بأي شيء في إصدار محسّن.

void SbViewVolume::getViewVolumePlanes (SbPlane planes[6]) const

إرجاع المستويات الستة التي تحدد حجم العرض بالترتيب التالي: يسار، أسفل، يمين، أعلى، قريب، بعيد. يتم توجيه متجهات المستويات إلى داخل حجم العرض.

هذه الدالة هي امتداد لـ Coin، وهي غير متوفرة في Open Inventor الأصلي.

void SbViewVolume::transform (const SbMatrix & matrix)

تحويل حجم العرض بواسطة matrix.

SbVec3f SbViewVolume::getViewUp (void ) const

إرجاع متجه الأعلى للعرض لهذا الحجم البصري. إنه متجه عمودي على اتجاه الإسقاط، ومتوازي وموجه في نفس اتجاه المتجه من الزاوية السفلية اليسرى إلى الزاوية العلوية اليسرى للمستوى القريب.

SbBool SbViewVolume::intersect (const SbVec3f & p) const

إرجاع TRUE إذا كانت p داخل حجم العرض.

منذ

Coin 2.3

SbBool SbViewVolume::intersect (const SbVec3f & p0, const SbVec3f & p1, SbVec3f & closestpoint) const

إرجاع TRUE إذا كان المقطع الخطي p0، p1 قد يتقاطع مع الحجم. كن على علم بأنه ليس من المؤكد بنسبة 100٪ أن المقطع الخطي يتقاطع مع الحجم حتى لو عادت هذه الدالة بـ TRUE.

يتم تعيين closestpoint إلى أقرب نقطة على الخط إلى الشعاع المركزي لحجم العرض.

منذ

Coin 2.3

SbBool SbViewVolume::intersect (const SbBox3f & box) const

إرجاع TRUE إذا كان box قد يكون داخل حجم العرض.

منذ

Coin 2.3

SbBox3f SbViewVolume::intersectionBox (const SbBox3f & box) const

حساب صندوق الإحاطة للتقاطع بين bbox وحجم العرض.

منذ

Coin 4.0

SbBool SbViewVolume::outsideTest (const SbPlane & p, const SbVec3f & bmin, const SbVec3f & bmax) const

إرجاع TRUE إذا كانت جميع النقاط الثمانية في الزوايا في bmin، bmax خارج p.

const SbDPViewVolume & SbViewVolume::getDPViewVolume (void ) const
