SbBool SbBox3d::outside (const SbDPMatrix & mvp, int & cullbits) const

يتحقق مما إذا كان الصندوق خارج حجم العرض المحدد بواسطة المصفوفة mvp. يقوم بتعيين cullbits وفقًا للطائرات التي نحن بداخلها أو خارجها. يتم مسح البت 0 (0x1) عندما يكون الصندوق بالكامل داخل مستويات القطع اليسرى واليمنى. يتم مسح البت 1 (0x2) عندما يكون الصندوق داخل مستويات القطع العلوية والسفلية. يتم مسح البت 2 (0x4) عندما يكون الصندوق داخل مستويات القطع القريبة والبعيدة.

يعيد TRUE إذا كان الصندوق بالكامل خارج أحد مستويات القطع. FALSE بخلاف ذلك.
