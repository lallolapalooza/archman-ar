Detailed Description

This element class stores profile coordinates. Profile coordinates are used to define the shape of 2D primitives like profiles or holes. The coordinates can be specified as 2D or 3D vectors.

The element is used internally by Coin to pass profile coordinate information down the scene graph traversal. Applications typically don't need to use this class directly.

يخزن فئة العنصر هذه إحداثيات الشكل. تستخدم إحداثيات الشكل لتحديد شكل الأشكال ثنائية الأبعاد مثل الأشكال أو الثقوب. يمكن تحديد الإحداثيات كمتجهات ثنائية أو ثلاثية الأبعاد.

يتم استخدام العنصر داخليًا بواسطة Coin لتمرير معلومات إحداثيات الشكل لأسفل عبر اجتياز الرسم البياني للمشهد. عادةً لا تحتاج التطبيقات إلى استخدام هذه الفئة مباشرة.
