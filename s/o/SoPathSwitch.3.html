Detailed Description

The SoPathSwitch class traverses only when current path matches a configurable path.

FILE FORMAT/DEFAULTS:

PathSwitch {
    path NULL
}

SoPathSwitch::SoPathSwitch (void )

Default constructor.

SoPathSwitch::SoPathSwitch (int numchildren)

Constructor.

The argument should be the approximate number of children which is expected to be inserted below this node. The number need not be exact, as it is only used as a hint for better memory resource allocation.
