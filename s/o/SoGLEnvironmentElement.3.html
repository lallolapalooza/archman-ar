NAME

SoGLEnvironmentElement — an element that stores OpenGL environment settings.

SYNOPSIS

#include <Inventor/GLES/elements/SoGLEnvironmentElement.h>

Inherits SoEnvironmentElement.

class SoGLEnvironmentElement : public SoEnvironmentElement {
  public:
    // Public members
    static SoGLEnvironmentElement *	createInstance (void);
    static void			initClass (void);
    virtual void		init (SoState *state);
    virtual void		pop (SoState *state, const SoElement *prevTopElement);

  protected:
    // Protected members
    virtual void		setElt (SoState *const state, const float ambientIntensity, const SbColor & ambientColor, const SbVec3f & attenuation, const int32_t fogType, const SbColor & fogColor, const float fogVisibility, const float fogNear);

  private:
    // Private members
    // ...
};

Detailed Description

This class is used to store OpenGL environment settings, such as ambient light intensity, fog settings, etc. It inherits from SoEnvironmentElement and overrides the necessary methods to interact with the OpenGL rendering state.

Constructor & Destructor Documentation

This class does not have explicit constructors or destructors documented here, but it inherits them from its base class SoEnvironmentElement.
