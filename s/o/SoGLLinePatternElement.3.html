NAME

SoGLLinePatternElement - GL line pattern element

SYNOPSIS

#include <Inventor/elements/SoGLLinePatternElement.h>

Inheritance

SoSMLinePatternElement > SoLinePatternElement > SoInt32Element > SoElement > SoBase

SoGLLinePatternElement is a GL backend specific element.

Detailed Description

This element is used to control the line pattern which is set using OpenGL's glLineStipple function.

The element is only active when the GL rendering backend is used.
