الاسم

SoLOD - مستوى التفاصيل

الملخص

class SoLOD : public SoNode

الوصف التفصيلي

SoLOD هي عقدة تدير مستوى التفاصيل (LOD) للمشهد. تسمح للمستخدم بالتحكم في كيفية عرض التفاصيل بناءً على مسافة المشاهد من الكائن.

توثيق المُنشئ والمُدمّر

يقوم المُنشئ بتهيئة العقدة بقيم افتراضية. المُدمّر افتراضي ويستخدم لإدارة الذاكرة بشكل صحيح.

توثيق دوال الأعضاء

فيما يلي دوال الأعضاء لفئة SoLOD:

  • void getBoundingBox(SoGetBoundingBoxAction * action)

  • void getPrimitiveCount(SoGetPrimitiveCountAction * action)

  • void doAction(SoAction * action)

  • void callback(SoCallbackAction * action)

  • void GLRender(SoGLRenderAction * action)

  • void GLRenderBelowPath(SoGLRenderAction * action)

  • void GLRenderInPath(SoGLRenderAction * action)

  • void GLRenderOffPath(SoGLRenderAction * action)

  • void rayPick(SoRayPickAction * action)

  • void doAction(SoAction * action)

  • int whichToTraverse(SoAction * action)

توثيق بيانات الأعضاء

فيما يلي بيانات الأعضاء لفئة SoLOD:

  • SoMFFloat range

  • SoSFVec3f center
