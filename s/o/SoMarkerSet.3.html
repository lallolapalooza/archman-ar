الاسم

SoMarkerSet - الفئة SoMarkerSet تعرض مجموعة من علامات الصور النقطية ثنائية الأبعاد في الفضاء ثلاثي الأبعاد.

الوصف التفصيلي

تعرض الفئة SoMarkerSet مجموعة من العلامات ثنائية الأبعاد في مساحة ثلاثية الأبعاد.

يستخدم هذا العقدة الإحداثيات الحالية في الحالة (أو في حقل vertexProperty) لإنشاء النقاط. يحدد الحقل numPoints عدد النقاط في المجموعة.

بالإضافة إلى توفير المستخدم بمجموعة علامات قياسية للاختيار من بينها، من الممكن أيضًا تحديد صور نقطية خاصة بالستخدم.

تعتبر فئة العقدة هذه امتدادًا لواجهة برمجة تطبيقات SGI Inventor v2.1 الأصلية. بالإضافة إلى كونها امتدادًا لـ Coin، فهي موجودة أيضًا في تطبيق Inventor الخاص بـ TGS. (ملاحظة: لا يدعم تطبيق TGS القيمة NONE لـ markerIndex.)

ملف التنسيق/الافتراضيات:

MarkerSet {
    vertexProperty NULL
    startIndex 0
    numPoints -1
    markerIndex 0
}

void SoMarkerSet::addMarker (int idx, const SbVec2s & size, const unsigned char * bytes, SbBool isLSBFirst = TRUE, SbBool isUpToDown = TRUE) [static]

يستبدل تمثيل العلامة في الفهرس idx بالتمثيل المحدد بواسطة أبعاد size وبيانات الصورة في bytes. يشير isLSBFirst و isUpToDown إلى كيفية ترتيب بيانات الصورة. إذا كان markerIndex هو NONE، فلن تفعل شيئًا.

هذا مثال كامل الاستخدام يوضح كيفية تعيين علامة محددة بواسطة المستخدم من خريطة أحرف. لاحظ أن بيانات خريطة البكسل متعددة الألوان يتم تحويلها إلى صورة أحادية اللون قبل تمريرها إلى addMarker() لأن addMarker() تدعم الصور فقط.

const int WIDTH = 18;
const int HEIGHT = 19;
const int BYTEWIDTH = (WIDTH + 7) / 2;
const char coin_marker[WIDTH * HEIGHT + 1] = {
  ".+                "
  "+@.+              "
  " .@#.+            "
  " +$@##.+          "
  "  .%@&##.+        "
  "  +$@&&*##.+      "
  "   .%@&&*=##.+    "
  "   +$@&&&&=-##.+  "
  "    .%@&&&&&-;#&+ "
  "    +$@&&&&&&=#.  "
  "     .%@&&&*#.   "
  "     +$@&&&#.    "
  "      .%@&@%@#.   "
  "      +$%@%.$@#.  "
  "       .%%. .$@#. "
  "       +$.   .$>#."
  "        +     .$. "
  "               .  "
  "                  " };
int byteidx = 0;
unsigned char bitmapbytes[BYTEWIDTH * HEIGHT];
for (int h = 0; h < HEIGHT; h++) {
  unsigned char bits = 0;
  for (int w = 0; w < WIDTH; w++) {
    if (coin_marker[(h * WIDTH) + w] != ' ') { bits |= (0x80 >> (w % 8)); }
    if ((((w + 1) % 8) == 0) || (w == WIDTH - 1)) {
      bitmapbytes[byteidx++] = bits;
      bits = 0;
    }
  }
}

Detailed Description

This node is used to register a bitmap marker, that can be used in order to display markers. The addMarker() method takes a marker bitmap and returns an index, which can be used later on to display the marker. A default marker is defined (CROSS_5_5).

The index returned by addMarker() is of type SoMFInt32. For example, if you define an arrow marker, you can store it in SoMarkerSet::markerIndex as follows:

// In your application class:
addMarker(MYAPP_ARROW_IDX, SbVec2s(WIDTH, HEIGHT),
                       bitmapbytes, FALSE, TRUE);

// In your scene graph:
SoNode* root = new SoNode;
SoSeparator* sep = new SoSeparator;
sep->addChild(new SoMarkerSet);
sep->addChild(new SoMarkerSet(MYAPP_ARROW_IDX)); // Display arrow marker
root->addChild(sep);

This will provide you with an index given by MYAPP_ARROW_IDX which can be used in SoMarkerSet::markerIndex to display the new marker.

Member Function Documentation

void addMarker (int & idx, const SbVec2s & size, const unsigned char *bytes, SbBool isLSBFirst, SbBool isRGB)

Adds the given bitmap marker to the marker set. The idx parameter will be set to the index of the new marker. The size parameter specifies the width and height of the marker bitmap. The bytes parameter points to the bitmap data. If isLSBFirst is TRUE, the bits in each byte are ordered from least significant to most significant. If isRGB is TRUE, the bitmap is interpreted as RGB data; otherwise, it is interpreted as grayscale data.

void addMarker (int & idx, const SbVec2s & size, const unsigned char *bytes, SbBool isLSBFirst)

Adds the given bitmap marker to the marker set. The idx parameter will be set to the index of the new marker. The size parameter specifies the width and height of the marker bitmap. The bytes parameter points to the bitmap data. If isLSBFirst is TRUE, the bits in each byte are ordered from least significant to most significant. This version defaults to interpreting the bitmap as grayscale data.

SbBool getMarker (int idx, SbVec2s & size, const unsigned char *& bytes, SbBool & isLSBFirst) [static]

Returns data for marker at idx in the size, bytes and isLSBFirst parameters.

If no marker is defined for given idx, or SoMarkerSet::markerIndex is NONE (not removable), FALSE is returned. If everything is OK, TRUE is returned.

SbBool removeMarker (int idx) [static]

Removes marker at idx.

If no marker is defined for given idx, or SoMarkerSet::markerIndex is NONE (not removable), FALSE is returned. If everything is OK, TRUE is returned.
