Detailed Description

La clase SoFrustumCamera define un cámara con un frustum general.

La clase SoFrustumCamera permite especificar un frustum de manera similar a la función glFrustum() de OpenGL. Tiene cuatro nuevos campos (left, right, top, bottom) y utilizará SoCamera::nearDistance y SoCamera::farDistance para los dos últimos parámetros de glFrustum().

Este cámara puede ser útil en aplicaciones que requieran control completo sobre el frustum de vista, como en CAVE o aplicaciones multipipe.

Sin

Coin 2.5
