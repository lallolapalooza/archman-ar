SoTexture3Transform

3D texture transformation

#include <Inventor/nodes/SoTexture3Transform.h>

Detailed Description

This node specifies a 3D texture transformation. The transformation consists of a translation, a rotation, and a scaling. The translation is applied first, then the rotation, and finally the scaling. The fields for translation, rotation and scaling all take SoSFVec3f, SoSFRotation and SoSFVec3f as types respectively. The center field is used for scaling and rotation. It is applied before scaling and rotation.

The order of transformations applied is: translation, rotation, scaling.

The default values for translation, rotation and scaling are all the identity element, meaning no transformation is applied.
