Detailed Description

The SoVRMLShape class contains geometry and appearance nodes.

The detailed class documentation is taken verbatim from the VRML97 (ISO/IEC 14772-1:1997) standard. It is copyrighted by the Web3D Consortium and used with the Council's permission:

Shape {
  exposedField SFNode appearance NULL
  exposedField SFNode geometry   NULL
}

The Shape node has two fields, appearance and geometry, which are used to create rendered objects in the world. The appearance field contains an SoVRMLAppearance node that specifies the visual properties (e.g., material and texture) applied to the geometry. The geometry field contains a geometry node. The specified geometry node is rendered with the specified appearance nodes. See 4.6.3, Shapes and geometry (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.3), and SoVRMLAppearance, for more information.

4.14, Lighting model (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14), contains details about VRML's lighting model and the interaction between appearance and geometry nodes. If the geometry field is NULL, the object is not drawn.

SbBool SoVRMLShape::affectsState (void ) const [virtual]

Returns TRUE if the node might have any effect on state during traversal.

If it returns FALSE, then no data in the traversal state will change from the state before traversal to the state after traversal. The SoSeparator node will return FALSE, because it pushes and pops state before and after traversing its children. All SoShape nodes also return FALSE, because only geometry data is displayed before rendering, which does not affect the actual rendering state.

The default method returns TRUE, based on the "better safe than sorry" principle.
