NAME

SoPointLightManip — point light manipulator

DESCRIPTION

This is a manipulator for a point light source.

It allows interactive manipulation of the point light source's position and intensity.

INHERITANCE

This class inherits from SoLightManip, which inherits from SoNodeManip, which inherits from SoSeparator, which inherits from SoNode.
