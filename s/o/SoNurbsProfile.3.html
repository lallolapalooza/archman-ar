Detalles de descripción

Este perfil se basa en una curva NURBS (superficie NURBS de una dimensión). Se puede utilizar para definir el perfil de una extrusión o revolución.

El perfil NURBS se puede utilizar como un perfil genérico en las siguientes clases:

  • SoExtrusion
  • SoRevolution

Puede elegir si la curva NURBS debe ser aproximada como una serie de polilíneas utilizando el campo setApprox.
