Detailed Description

The SoAccumulatedElement class is an abstract class for storing accumulated state.

This is the superclass of elements where new element data accumulates with older data.

The element stores node id values for all nodes accumulated during traversal for the current state. These id values are used to determine when to invalidate caches.

See also

SoReplacedElement, SoFloatElement, SoInt32Element

Detailed Description

This class is a base class for all elements that need to accumulate a list of node identifiers. Elements derived from this class will typically override the SoElement::initClass() method and the SoElement::push() and SoElement::pop() methods.

The node ids are stored internally in a SbList of SbUniqueId. The actual list is managed by the derived classes.

The SoAccumulatedElement class itself provides methods to add, clear, and copy the list of node ids. These methods are intended for use by derived classes.

virtual SoElement * SoAccumulatedElement::copyMatchInfo (void ) const

Creates a copy of the element with enough information to allow the matches() function to work.

This method is used internally by the scene graph traversal mechanism to cache element states. The returned element is a copy of the current element, but it only contains the data needed for comparison by the matches() method.
