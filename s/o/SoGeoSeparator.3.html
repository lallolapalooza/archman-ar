Detailed Description

La clase SoGeoSeparator se utiliza para georreferenciar un árbol de escena.

FORMATO DE ARCHIVO/VALORES POR DEFECTO:

GeoSeparator {
  geoSystem ["GD", "WE"]
  geoCoords 0 0 0
}

Este nodo especifica un sistema de coordenadas geográficas absoluta para los hijos. Cuando se renderiza (o se aplica otros acciones), Coin añadirá una transformación que transforma la geometría en el sistema de coordenadas SoGeoOrigin. Todos los objetos se rotarán para que el eje Z local apunte hacia arriba desde el suelo (a la ubicación especificada en geo-location), el eje Y apuntará hacia el polo norte y el eje X se encuentra utilizando el regla de la mano derecha.
