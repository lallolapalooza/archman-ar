SORCSD

الغرض:

!>
!> SORCSD يحسب تفكيك CS لمصفوفة X المتعامدة المقسمة من حجم M-by-M:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 هي P-by-Q. المصفوفات المتعامدة U1، U2، V1، و V2 هي P-by-P،
!> (M-P)-by-(M-P)، Q-by-Q، و (M-Q)-by-(M-Q)، على التوالي. C و S هي
!> مصفوفات قطرية غير سالبة بحجم R-by-R تحقق C^2 + S^2 = I، حيث
!> R = MIN(P,M-P,Q,M-Q).
!>
