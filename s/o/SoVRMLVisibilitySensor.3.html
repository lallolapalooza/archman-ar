Detailed Description

This sensor detects when objects enter or exit a defined bounding box. The visibility sensor is intended to be used to detect when objects enter or exit a specified region in the 3D scene.

The sensor is defined by a center point and a size, which together define an axis-aligned bounding box. The visibility sensor checks if the viewer's viewpoint is within this bounding box. If the viewpoint enters the box, the enterTime and isActive events are generated. If the viewpoint exits the box, the exitTime and isActive events are generated.

The visibility sensor is enabled or disabled by the enabled field.
