Detailed Description

This node is used to define a polygonal mesh. The vertices that make up the mesh are defined by the point node, which is a SoNode. This node must be of type SoCoordinate3. The mesh is defined by the coordIndex field, which is a list of integers. Each integer is an index into the point node's list of coordinates. A value of -1 indicates the end of a polygon. For example, the following coordIndex defines two triangles: 0, 1, 2, -1, 0, 2, 3, -1.

The normalIndex, texCoordIndex, and materialIndex fields are used to specify the indices for normals, texture coordinates, and materials, respectively. If these fields are empty, the normals, texture coordinates, and materials are taken from the current inherited values. If they are not empty, then each value is an index into the corresponding SoNormal, SoTextureCoordinate2, or SoMaterial node's list of values.

The startIndex and endIndex fields can be used to define multiple disconnected meshes within a single SoIndexedFaceSet. The startIndex field is a list of integers that specify the starting index of each mesh. The endIndex field is a list of integers that specify the ending index of each mesh.
