NAME

SoMFVec2s — multiple field of SbVec2s vectors

SYNOPSIS

#include <Inventor/fields/SoMFVec2s.h>
                    
class SoMFVec2s : public SoMField {
public:
    SoMFVec2s();
    ~SoMFVec2s();

    static SoType    classTypeId();
    virtual SoType   getTypeId() const;
    void             copyFrom(const SoField & f);
    SbBool           isSame(const SoField & f) const;

    void             setValues(int start, int numarg, const short xy[][2]);
    void             set1Value(int idx, short x, short y);
    void             set1Value(int idx, const short xy[2]);
    void             setValue(short x, short y);
    void             setValue(const short xy[2]);

    const SbVec2s *  getValues(const int start) const;

    static void      initClass();
    static SoType    getClassTypeId();

protected:
    virtual void     deleteAllValues();
    virtual void     copyValue(int to, int from);

private:
    // Internal methods
    static void *    createInstance();
};

Description

This field supports application data sharing through a setValuesPointer() method. See SoMField documentation for information on how to use this function.

See also

SbVec2s, SoSFVec2s Be aware that this class is an extension for Coin, and it is not available in the original SGI Open Inventor v2.1 API.

Since

Coin 2.5
