وصف تفصيلي

تنشئ فئة SoTextureCoordinateNormalMap إحداثيات النسيج عن طريق الإسقاط على نسيج محيط.

سيتم تعيين النسيج الذي يحدد البيئة حول الرسم البياني للمشهد أسفل هذه العقدة باستخدام كرة. سيتم تعيين النسيج على الرسم البياني للمشهد مع مراعاة موضع الكاميرا. سيؤدي ذلك إلى انعكاس الكائن لبيئته.

هنا مثال لرسم بياني للمشهد يوضح كيفية تطبيق تعيين النسيج على كائن:

#Inventor V2.1 ascii
Separator {
  Texture2 {
    filename "ocean.jpg" # the environment, in this case ocean
  }
  TextureCoordinateNormalMap {}
  Cube {} # the environmentally mapped object
}
