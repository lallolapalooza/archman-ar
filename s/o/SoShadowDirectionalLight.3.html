SoShadowDirectionalLight - directional light source with shadow map

Detailed Description

This node is inherited from SoDirectionalLight and is used to render shadow maps for directional lights.

A shadow map is a texture that represents the depth values of the scene as seen from the light source. This texture can then be used in the rendering process to determine whether a point in the scene is in shadow or not.

To enable shadow mapping for a SoShadowDirectionalLight node, you need to set its shadowMapScene field to point to the scene graph that should be rendered into the shadow map. If shadowMapScene is NULL (the default), the node will behave like a normal SoDirectionalLight.

The maxShadowDistance field controls the maximum distance from the camera at which shadows will be rendered. This can be used to optimize rendering by not rendering shadows for objects that are too far away.

The bboxCenter and bboxSize fields can be used to specify a bounding box that will be used for calculating the shadow volume. This can be useful for optimizing the shadow rendering process by limiting the area in which shadows are calculated.
