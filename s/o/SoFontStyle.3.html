Descripción Detallada

La clase SoFontStyle cambia la apariencia de las fuentes para los nodos de renderizado de texto.

Los nodos de renderizado de texto sucesivos utilizarán las fuentes con los ajustes de estilo de este nodo, siempre que se encuentre y cargue una fuente con los ajustes especificados en el sistema.

Si el estilo especificado de fuente no se encuentra en el sistema del cliente, se usará un fallback por defecto. Por lo tanto, el programador debe considerar SoFontStyle como nodos que ofrecen indicaciones sobre ajustes de fuentes, ya que no está garantizado que obtenga exactamente lo que desea.

Actualmente, la familia SERIF se mapea a “Times New Roman”, SANS a “Arial” y TYPEWRITER a “Courier New”.

Nota: Este nodo hereda SoFont. Las configuraciones de fuente en una rama se borran con el valor por defecto de SoFont si se inserta un nodo SoFontStyle vacío en la rama.

NB! Este nodo está proporcionado por razones de compatibilidad con Open Inventor 2.1, pero en la mayoría de los casos resultará en la visualización del fuente por defecto. Se recomienda usar el nodo SoFont en lugar.

FORMATO DE ARCHIVO/DEFALTOS:

FontStyle {
    name "defaultFont"
    size 10
    family SERIF
    style ()
}

NAME

SoFontStyle - font style node

SYNOPSIS

#include <Inventor/nodes/SoFontStyle.h>

Inherits from SoFont.

Detailed Description

This node controls the font style and family that will be used for subsequent SoText and SoAnnotation nodes.

It has two fields:

family
This field controls the font family. Valid values are:
  • SoFontStyle::SERIF
  • SoFontStyle::SANS
  • SoFontStyle::TYPE_WRITER
  • SoFontStyle::DECORATIVE
style
This field controls the font style. Valid values are:
  • SoFontStyle::NONE
  • SoFontStyle::INHERIT
  • SoFontStyle::BOLD
  • SoFontStyle::ITALIC
  • SoFontStyle::BOLDITALIC

A value of SoFontStyle::INHERIT means that the style will be inherited from the nearest ancestor node that specifies a style.

If both fields are set to SoFontStyle::INHERIT, then the font style will be inherited from the nearest ancestor node that specifies a font style.
