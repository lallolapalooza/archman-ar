Detailed Description

This class is used internally by Coin to store coordinate information for geometry primitives like SoIndexedFaceSet, SoTriangleStrip, etc.

The main purpose of the element is to allow Inventor readers and writers to easily read and write coordinate data, and to allow nodes like SoShape to retrieve coordinate data.

The coordinate data can be either 3D (i.e. stored as SbVec3f) or 4D (i.e. stored as SbVec4f). This is determined by the primitive.

This element is typically pushed onto the state stack by an SoNode that has coordinate data, and then retrieved by other nodes that need access to the coordinate data.
