Detailed Description

The SoDepthBuffer class is a scene graph node that may be used to control depth buffer settings. It is only intended for use by the application itself, or by an application-specific extensions to the Coin API.

The node's settings will affect all subsequent geometry that is rendered to the screen.

SoSFBool SoDepthBuffer::write

Enable depth buffer writing. Defaults to TRUE.

SoSFEnum SoDepthBuffer::function

Which depth function to use. Defaults to LESS.

SoSFVec2f SoDepthBuffer::range

The value range for the depth buffer data. Defaults to [0.0, 1.0]. The range will be clamped to [0.0, 1.0].
