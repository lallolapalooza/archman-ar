Detailed Description

This field class holds a time value. The time is stored as a floating point number representing seconds since the Epoch (January 1st, 1970, 00:00:00 UTC).

You can retrieve the time value with get and set it with setValue().

الوصف المفصل

يحمل فئة الحقل هذه قيمة وقت. يتم تخزين الوقت كرقم عشري يمثل الثواني منذ العصر (1 يناير 1970، 00:00:00 بالتوقيت العالمي المنسق).

يمكنك استرداد قيمة الوقت باستخدام get وتعيينها باستخدام setValue().
