Detailed Description

\n

This class is used internally by Coin to store the diffuse color, i.e. the color which is used to compute the diffuse reflection component of the material.

\n

The diffuse color is set by the SoMaterial node.

\n

The diffuse color is used by most of the shapes in Coin, e.g. SoSphere, SoCube, etc.

\n

The diffuse color is stored as an SoColorElement.
