NAME

SoPolygonOffsetElement — El elemento que define si los polígonos se compensan

SYNOPSIS

Clase padre: SoNode

Herencia directa:

  SoPolygonOffsetElement

Clases derivadas:

  SoGLPolygonOffsetElement

Detalles de la Descripción

Este elemento define si los polígonos se compensan en el navegador.

El desplazamiento se usa para evitar problemas de acoplamiento de z-buffer al renderizar objetos 3D. Permite que el polígono se desplace ligeramente hacia adelante o hacia atrás a lo largo de su normal. Los dos parámetros que controlan el desplazamiento son los siguientes:

factor
Este es un factor de escala para la pendiente del polígono. Los valores más altos producen un mayor desplazamiento.
units
Este es un valor discreto que se suma al desplazamiento. Los valores más altos producen un mayor desplazamiento.

El desplazamiento de polígonos solo se implementa en la implementación de OpenGL (SoGLPolygonOffsetElement) y no está disponible en otras implementaciones.

Se puede habilitar o deshabilitar el desplazamiento de polígonos estableciendo el miembro active en verdadero o falso. El desplazamiento de polígonos se aplica a todos los polígonos que se dibujan después de que se establece el elemento.

La siguiente tabla resume los valores predeterminados para los miembros de este elemento:

Miembro Valor predeterminado
style SoPolygonOffsetElement::FILLED
active verdadero
offsetfactor 1.0
offsetunits 0.0
