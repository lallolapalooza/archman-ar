وصف تفصيلي

يُستخدم العقدة SoSurroundScale لأتمتة تغيير حجم الهندسة لتطويق هندسة أخرى.

تقوم هذه العقدة بحساب تحويل (إزاحة وحجم) ، عند اجتياز العقدة ، يتم إلحاقه بمصفوفة النموذج الحالية ، مما يؤدي إلى إنشاء صندوق افتراضي يقع مباشرة على يمين هذه العقدة في الرسم البياني الهندسي حول عقدة الحاوية الخاصة بها. يتم تحديد الحاوية بواسطة حقل SoSurroundScale::numNodesUpToContainer.

عند حساب صندوق الحدود المطلوب تطويقه ، سيتم تطبيق إجراء الصندوق على عقدة الحاوية ، وسيتم إعادة تعيين حسابات الصندوق بعد اجتياز العقدة المحددة بواسطة حقل SoSurroundScale::numNodesUpToReset.

إحدى طرق التفكير في عقدة الحاوية هي أن هناك مسارًا من العقدة الجذرية إلى عقدة SoSurroundScale. يحتوي هذا المسار على عدد من العقد. numNodesUpToContainer هو عدد العقد في المسار من عقدة SoSurroundScale باتجاه العقدة الجذرية. من خلال عد numNodesUpToContainer من عقدة SoSurroundScale ، ستصل إلى عقدة الحاوية. عقدة الحاوية هي عقدة البذرة التي يتم حساب صندوق الحدود الخاص بها. تعتبر جميع العقد الموجودة أسفل هذه العقدة جزءًا من صندوق الحدود ، إلا إذا كانت أقرب إلى عقدة SoSurroundScale من numNodesUpToReset.

لضمان عدم تضمين العقد التي سيتم تغيير حجمها بواسطة عقدة SoSurroundScale في صندوق الحدود ، يتم استخدام numNodesUpToReset. وهو أيضًا عدد العقد الموجودة على يسار عقدة SoSurroundScale باتجاه العقدة الجذرية. معنى numNodesUpToReset هو أن العقد التي تكون أقرب إلى عقدة SoSurroundScale من العقدة في الموضع numNodesUpToReset لا يتم استخدامها لحسابات صندوق الحدود.

إليك مثال كامل ومستقل يضبط SoTrackballDragger (متصل بمكعب)، ويستخدم عقدة SoSurroundScale لجعلها تتغير حجمها تلقائيًا لتناسب حجم المكعب العالي ونقله إلى جانب المكعب:

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>;
#include <Inventor/draggers/SoTrackballDragger.h>;
#include <Inventor/nodes/SoAntiSquish.h>;
#include <Inventor/nodes/SoSeparator.h>;
#include <Inventor/nodes/SoCube.h>;
#include <Inventor/nodes/SoSurroundScale.h>;
#include <Inventor/nodes/SoRotation.h>;
#include <Inventor/nodes/SoTranslation.h>;
int
main(int argc, char **argv)
{
  QWidget * window = SoQt::init(argv[0]);
  if (window == NULL) exit(1);
  SoSeparator * root = new SoSeparator;
  root->ref();
  SoSeparator * surroundsep = new SoSeparator;
  root->addChild(surroundsep);
  SoTranslation * translation = new SoTranslation;
  translation->translation = SbVec3f(12, 0, 0);
  surroundsep->addChild(translation);
  SoSurroundScale * ss = new SoSurroundScale;
  ss->numNodesUpToReset = 1;
  ss->numNodesUpToContainer = 2;
  surroundsep->addChild(ss);
  SoAntiSquish * antisquish = new SoAntiSquish;
  antisquish->sizing = SoAntiSquish::BIGGEST_DIMENSION;
  surroundsep->addChild(antisquish);
  SoTrackballDragger * dragger = new SoTrackballDragger;
  surroundsep->addChild(dragger);
  SoRotation * rotation = new SoRotation;
  rotation->rotation.connectFrom(& dragger->rotation);
  root->addChild(rotation);
  SoCube * cube = new SoCube;
  cube->height = 10.0f;
  root->addChild(cube);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  viewer->setSceneGraph(root);
  viewer->setViewing(FALSE);
  viewer->setDecoration(FALSE);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

قد يكون من الأسهل رؤية كيفية عمل عقدة SoSurroundScale في المثال السابق من خلال النظر إلى الرسم البياني الفعلي للمشهد:

#Inventor V2.1 ascii
Separator {
   Separator {
      Translation {
         translation 12 0 0
      }
      SurroundScale {
         numNodesUpToContainer 2
         numNodesUpToReset 1
      }
      AntiSquish {
         sizing BIGGEST_DIMENSION
      }
      DEF mydragger TrackballDragger {
      }
   }
   Rotation {
      rotation 0 0 1  0 =
      USE mydragger . rotation
   }
   Cube {
      height 10
   }
}

تُستخدم هذه العقدة داخليًا بواسطة المتحكمات لجعل المتحكمات قادرة على تغيير حجم هندسة المتحكم الخاص بها لمطابقة هندسة صندوق المشهد التي تعدلها ، كما هو موضح أعلاه (ولكن خارج سياق المتحكم).

وهي مفيدة بشكل عام أيضًا لمبرمجي التطبيقات الذين يرغبون في أي جزء محدد من الهندسة لتطويق هندسة أخرى غير معروفة أو متغيرة الحجم.

غالبًا ما تكون عقد SoSurroundScale في الرسم البياني للمشهد مقترنة بعقد SoAntiSquish للحصول على تغيير حجم موحد في الاتجاهات الرئيسية الثلاثة ، كما تم في المثال أعلاه.

صيغة الملف/الافتراضيات:

SurroundScale {
    numNodesUpToContainer 0
    numNodesUpToReset 0
}
