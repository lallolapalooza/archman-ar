Descripción detallada🔗

La clase SoIndexedLineSet se utiliza para renderizar y representar de otra manera las líneas indexadas.

El counterpart indexado de SoLineSet. Las líneas pueden especificarse usando índices para coordenadas, normales, materiales y coordenadas de texto.

Si no se especifican normales en el stack (o en el campo vertexProperty), las líneas se renderizarán con iluminación desactivada.

Para más información sobre sets de líneas, vea la documentación en SoLineSet. Para más información sobre formas indexadas, vea la documentación en SoIndexedShape y SoIndexedFaceSet).

FORMATO DE ARCHIVO/DEFAULTE:

IndexedLineSet {
    vertexProperty NULL
    coordIndex 0
    materialIndex -1
    normalIndex -1
    textureCoordIndex -1
}
