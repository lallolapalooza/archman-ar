وصف تفصيلي

الفئة SoVertexAttributeBinding هي عقدة لإعداد كيفية ربط سمات الرأس (vertex attributes) بالأشكال.

راجع أيضاً

SoVertexAttribute

ربط المواد المحدد في العقد من هذا النوع يحدد كيفية ربط قيم سمات الرأس لعقد SoVertexAttribute على عقد الأشكال الهندسية المدمجة.

إليك مثال استخدام بسيط:

#Inventor V2.1 ascii
ShaderProgram {
  shaderObject [
    VertexShader {
      sourceProgram "vertex.glsl"
    }
  ]
}
Coordinate3 {
  point [ 0 0 0, 1 0 0, 1 1 0 ]
}
VertexAttributeBinding { value OVERALL }
VertexAttribute {
  typeName "SoMFVec3f"
  name "color"
  values [ 1.0 0.0 0.0 ]
}
IndexedFaceSet {
  coordIndex [ 0, 1, 2, -1 ]
}

المظلل الرأسي (vertex shader) (vertex.glsl):

attribute vec3 color;
void main(void)
{
  gl_Position = ftransform();
  fragcolor = color;
}

مع ضبط SoVertexAttributeBinding::value إلى PER_VERTEX_INDEXED أعلاه، سيتم أخذ مؤشرات السمات من حقل SoIndexedFaceSet::coordIndex عند التصيير.

إذا تم ضبط SoVertexAttributeBinding::value إلى PER_VERTEX، سيتم جلب السمات بطريقة متزايدة بشكل رتيب من حقل SoVertexAttribute::value، بدءاً من المؤشر 0.

إذا تم ضبط SoVertexAttributeBinding::value إلى OVERALL، سيتم إرسال قيمة السمة الأولى من SoVertexAttribute::value إلى OpenGL قبل التصيير.

تنسيق الملف / القيم الافتراضية:

VertexAttributeBinding {
    value PER_VERTEX_INDEXED
}

راجع أيضاً

SoVertexAttribute انتبه إلى أن هذه الفئة هي امتداد لـ Coin، وهي غير متوفرة في واجهة برمجة التطبيقات الأصلية لـ Open Inventor v2.1.

توثيق تعداد الأعضاء

تعداد SoVertexAttributeBinding::Binding

تعداد لأنواع ربط المواد المتاحة.

المُعدِّدات

OVERALL
تطبيق نفس المادة على الشكل الكامل.
PER_VERTEX
الحصول على مادة جديدة من مجموعة قيم المواد لكل مضلع، خط، أو نقطة *رأس* للشكل.

يتم جلب السمات من المؤشر 0 وما بعده، مع زيادة المؤشر إلى مجموعة السمات بمقدار 1 لكل رأس جديد للشكل العقدة.

PER_VERTEX_INDEXED
الحصول على سمة جديدة من مجموعة قيم السمات لكل مضلع، خط، أو نقطة *رأس* للشكل.

يتم جلب السمات بواسطة قيم المؤشرات الخاصة بالشكل.
