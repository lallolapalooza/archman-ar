وصف مفصل

فئة SoCoordinate4 هي عقدة لتوفير الإحداثيات لعقد الأشكال.

عند مواجهة عقد من هذا النوع أثناء المسح، سيتم وضع الإحداثيات التي تحتوي عليها في مكدس الحالة للاستخدام لاحقًا بواسطة عقد الأشكال التي تحتاج إلى مجموعات إحداثيات (مثل عقد SoFaceSet أو عقد SoPointSet).

يتم استخدام العنصر الرابع من متجهات الإحداثيات للتطبيع. العقدة من هذا النوع حيث تكون جميع قيم التطبيع تساوي 1.0 تعادل إعداد عقدة SoCoordinate3.

لاحظ أن عقدة SoCoordinate4 ستقوم باستبدال الإحداثيات الموجودة بالفعل في الحالة (إن وجدت).

تنسيق الملف/الافتراضيات:

Coordinate4 {
    point 0 0 0 1
}

SoCoordinate4 — 4D coordinate class

Detailed Description

This node defines a set of 4D coordinates. Each coordinate consists of a 3D point and a normalization value. The normalization value is used to determine how the coordinate should be scaled when it is rendered. Normalization is typically used for perspective projection, where points further away are scaled down.

This class is derived from SoNode and inherits all of its functionality.
