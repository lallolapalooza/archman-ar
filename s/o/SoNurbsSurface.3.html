Detailed Description

NURBS surface node. This node is able to define parametric surfaces. It is defined by a set of control points, knot vectors and the degree of the surface in the two parametric directions.

The following members define the surface:

  • numUControlPoints, numVControlPoints: Number of control points in the U and V directions respectively.

  • numSControlPoints, numTControlPoints: These members are not used by the SoNurbsSurface node itself, but are there for compatibility with SGI's Open Inventor 2.1 API.

  • uKnotVector, vKnotVector: The knot vectors for the U and V directions. The knot vector specifies the parameter values at which the basis functions change. The knot vector must be non-decreasing.

  • sKnotVector, tKnotVector: These members are not used by the SoNurbsSurface node itself, but are there for compatibility with SGI's Open Inventor 2.1 API.

  • controlPoints: A list of 3D vectors defining the control points of the NURBS surface. The control points are specified row by row, corresponding to the V direction first (for a fixed U), and then the U direction.

  • uDegree, vDegree: The degree of the NURBS surface in the U and V directions, respectively. The degree must be less than or equal to the number of control points minus 1.

Note that the node is inherited from SoShape, so you can use the standard shape node features (like SoMaterial, SoTexture2, etc.) to further define the appearance of the surface.

The surface is tessellated into polygons when rendered.

Will create triangle detail for a SoPickedPoint. This method will only be called internally, when generatePrimitives() is used for picking (SoShape::rayPick() is not overridden).

This method returns NULL in Open Inventor, and subclasses will need to override this method to create details for a SoPickedPoint.

This is not necessary with Coin. Of course, if you choose to override it, it will work in the same way as Open Inventor.

For this to work, you must supply a face or line detail when generating primitives. If you supply NULL for the detail argument in SoShape::beginShape(), you'll have to override this method.

Reimplemented from SoShape.
