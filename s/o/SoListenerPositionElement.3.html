Detailed Description

El SoListenerPositionElement contiene la posición del actual listener.

Esta posición se establece por nodos SoListener y SoCamera durante la renderización auditiva. Cuando un SoListener es visitado por el SoAudioRenderAction, se agregará un nuevo SoListenerPositionElement al estado, que mantiene su posición y marca el flag setbylistener como verdadero. Cuando un SoCamera es visitado por el SoAudioRenderAction, se agregará un nuevo SoListenerPositionElement si no hay elementos previos con el flag setbylistener marcado como verdadero.

El SoListenerPositionElement se utiliza cuando se renderizan los nodos SoVRMLSound.

Debe tener en cuenta que esta clase es una extensión de Coin y no está disponible en la API original de SGI Open Inventor v2.1.

Detailed Description

This element stores the current listener's position in world space. It is used by the 3D audio system to determine where the listener is located in the scene.

The position can be set by either a SoListener node or a SoCamera node. The setbylistener flag in the set() method indicates which type of node set the position.

This class does not have user-callable constructors or destructors. It is managed internally by the Coin scene graph traversal mechanism.
