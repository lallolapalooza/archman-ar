Detailed Description

This class provides a manipulator for applying transformations to scene graph objects. It allows the user to translate, rotate, and scale objects interactively.

The SoTransformerManip is built upon the SoTransformManip class and adds specific dragger implementations for translation, rotation, and scaling operations.
