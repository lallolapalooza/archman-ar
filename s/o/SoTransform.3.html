توثيق فئة SoTransform.

فئة SoTransform هي نوع العقدة "متعددة الاستخدامات" للتحويل.

مثل SoMatrixTransform، تمنح العقد من هذا النوع لمطور التطبيق أقصى قدر من المرونة عند تحديد التحويلات الهندسية في شجرة المشهد. إذا كنت ترغب في تعيين مكونات مصفوفة التحويل والاحتفاظ بها في كيانات منفصلة، فإن نوع العقدة هذا هو المفضل، على الرغم من ذلك.

ترتيب العمليات هو: أولاً القياس، ثم الدوران، ثم الإزاحة.

تنسيق الملف/الافتراضات:

Transform {
    translation 0 0 0
    rotation 0 0 1  0
    scaleFactor 1 1 1
    scaleOrientation 0 0 1  0
    center 0 0 0
}
