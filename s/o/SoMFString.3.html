الوصف التفصيلي

void * SoMFString::createInstance (void ) [static]

يعتبر عضو الواجهة البرمجية هذا داخليًا للمكتبة، حيث من غير المحتمل أن يكون محل اهتمام لمبرمج التطبيق.


ينشئ مثيلاً جديدًا لنوع الفئة المقابل لكائن SoType.

SoType SoMFString::getClassTypeId (void ) [static]

تقوم هذه الدالة الثابتة بإرجاع كائن SoType المرتبط بالكائنات من هذه الفئة.

SoType SoMFString::getTypeId (void ) const [virtual]

تعيد تعريف نوع الكائن المشتق من فئة ترث SoField. يستخدم هذا للتحقق من النوع في وقت التشغيل وللتحويل "لأسفل".

تنفيذ لـ SoField.

void SoMFString::copyFrom (const SoField & f) [virtual]

نسخ القيمة (القيم) من f إلى هذا الحقل. يجب أن يكون f من نفس نوع هذا الحقل.

تنفيذ لـ SoField.

SbBool SoMFString::isSame (const SoField & f) const [virtual]

التحقق من تساوي النوع والقيمة (القيم).

تنفيذ لـ SoField.

void SoMFString::deleteAllValues (void ) [protected], [virtual]

يعتبر عضو الواجهة البرمجية هذا داخليًا للمكتبة، حيث من غير المحتمل أن يكون محل اهتمام لمبرمج التطبيق.

تنفيذ لـ SoMField.

void SoMFString::copyValue (int to, int from) [protected], [virtual]

تستخدم هذه الدالة لنقل القيم داخليًا ضمن حقل متعدد القيم. يجب تجاوزها في كل حقل لضمان أنها تأخذ في الاعتبار تلقائيًا تشغيل مُنشئات النسخ عند الضرورة.

تنفيذ لـ SoMField.

const SbString * SoMFString::getValues (const int start) const [inline]

تعيد مؤشرًا إلى مصفوفة القيم.

void SoMFString::initClass (void ) [static]

دالة داخلية يتم استدعاؤها عند تهيئة المكتبة (من SoDB::init()) لإعداد نظام الأنواع.

void SoMFString::setValues (const int start, const int numarg, const char * strings[])

ضبط الحقل ليحتوي على num strings من الفهرس start، مع استبدال أي سلاسل موجودة بالفعل في الفهارس المحددة.

void SoMFString::setValue (const char * str)

ضبط الحقل ليحتوي على سلسلة نصية واحدة، من str.

void SoMFString::deleteText (const int fromline, const int fromchar, const int toline, const int tochar)

إزالة جميع النصوص من fromchar في fromline وإلى tochar في toline، بما في ذلك جميع الأسطر بين fromline و toline. دمج fromline و toline بعد الحذف.
