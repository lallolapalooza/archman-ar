الاسم

SoSceneTexture2 - الفئة SoSceneTexture2 تُستخدم لإنشاء نسيج ثنائي الأبعاد من رسم بياني لمشهد Coin.

الملخص

وصف تفصيلي

يستخدم صنف SoSceneTexture2 لإنشاء نسيج ثنائي الأبعاد من رسم بياني لمشهد Coin.

يسمح بعرض رسم بياني لمشهد كمصفوفة نسيج لاستخدامها في رسم بياني لمشهد آخر. قم بإعداد الرسم البياني للمشهد المستخدم للنسيج في حقل SoSceneTexture2::scene.

يتصرف هذا العقد تمامًا مثل SoTexture2 عند تعيين النسيج الفعلي على الهندسة اللاحقة. يرجى قراءة وثائق SoTexture2 لمزيد من المعلومات حول كيفية تعيين الأنسجة على الأشكال.

تتمثل إحدى الميزات البارزة لهذا العقد في أنه سيستخدم مخازن مؤقتة خارج الشاشة لتسريع العرض بواسطة الأجهزة، إذا كانت متوفرة من برنامج تشغيل OpenGL. تدعم WGL و GLX و AGL، لبرامج تشغيل OpenGL على Microsoft Windows و X11 و Mac OS X على التوالي، كلها امتداد pbuffer لهيئة مراجعة بنية OpenGL (ARB) في التكرارات اللاحقة من معظم بائعي OpenGL.

لاحظ أيضًا أن المخزن المؤقت خارج الشاشة سيتم استخدامه مباشرة على البطاقة كنسيج، دون أي رحلة ذهاب وعودة مكلفة من وإلى ذاكرة وحدة المعالجة المركزية، إذا كان برنامج تشغيل OpenGL يدعم امتداد ARB_render_texture الحديث.

القيود الهامة هي أن الأنسجة يجب أن تكون أبعادها تساوي قوة كاملة للاثنين، راجع وثائق SoSceneTexture::size.

تنسيق الملف / القيم الافتراضية:

SceneTexture2 {
    size 256 256
    scene NULL
    sceneTransparencyType NULL
    type RGBA_UNSIGNED_BYTE
    backgroundColor 0 0 0 0
    transparencyFunction NONE
    wrapS REPEAT
    wrapT REPEAT
    model MODULATE
    blendColor 0 0 0
}

توثيق تعداد الأعضاء

enum SoSceneTexture2::Model

نموذج تعيين النسيج، لتحديد كيفية "دمج" خريطة النسيج مع الكائن الذي يتم تعيينها عليه.

المُعدِّد

MODULATE
يتم ضرب لون النسيج بلون المضلع. ستكون النتيجة تظليل Phong (إذا كان نموذج الإضاءة هو PHONG).
DECAL
تتجاوز صورة النسيج تظليل المضلع. لن يتم تظليل بكسلات النسيج بـ Phong. له سلوك غير محدد للنسيج باللون الرمادي وللنسيج باللون الرمادي مع ألفا.
BLEND
يستخدم هذا النموذج عادةً مع الأنسجة أحادية اللون (أي الأنسجة بمكون واحد أو مكونين). سيتم استخدام المكون الأول، الشدة، لمزج لون التظليل للمضلع مع SoSceneTexture2::blendColor.
REPLACE
تتجاوز صورة النسيج تظليل المضلع. لن يتم تظليل بكسلات النسيج بـ Phong. يدعم الأنسجة باللون الرمادي ومع ألفا. تتطلب هذه الميزة OpenGL 1.1. سيتم استخدام MODULATE إذا تم اكتشاف إصدار OpenGL < 1.1.

enum SoSceneTexture2::Wrap

تعداد استراتيجيات الالتفاف التي يمكن استخدامها عندما لا تغطي خريطة النسيج النطاق الكامل للهندسة.

المُعدِّد

REPEAT
تكرار النسيج عندما لا يكون الإحداثي بين 0 و 1.
CLAMP
تثبيت الإحداثي بين 0 و 1.
CLAMP_TO_BORDER
تثبيت الإحداثي في النطاق [1/2N، 1 - 1/2N]، حيث N هو حجم النسيج في اتجاه التثبيت.

enum SoSceneTexture2::TransparencyFunction

لتحديد كيفية التعامل مع قناة ألفا للنسيج. لا يمكن اكتشاف ذلك تلقائيًا، لأن النسيج مخزن فقط في ذاكرة بطاقة الرسومات، وسيكون بطيئًا للغاية لجلب الصورة لاختبار قناة ألفا كما يفعل Coin للأنسجة العادية.

المُعدِّد

NONE
يتم تجاهل قناة ألفا.
ALPHA_BLEND
يتم استخدام مزج ألفا.
ALPHA_TEST
يتم استخدام دالة اختبار ألفا.

DEPTH

RGBA8
يحدد نسيج RGBA مع 8 بت لكل مكون.
