Detailed Description

The SoScale class is a node type for scaling scene graph geometry.

Use nodes of this type to apply scaling operations during scene graph traversals for e.g. rendering. Scale values are specified in a triple-value vector, with one scale factor for each of the 3 principal axes.

FILE FORMAT/DEFAULTS:

Scale {
    scaleFactor 1 1 1
}

توثيق بيانات الأعضاء

SoSFVec3f SoScale::scaleFactor

يحدد القياس على طول المحاور الثلاثة.

للحصول على قياس موحد مطبق على الأشكال المتأثرة، قم بتعيين حقل scaleFactor إلى متجه بقيمة متساوية لجميع المكونات.

خطأ شائع عند إجراء قياس غير موحد في اتجاه واحد هو تعيين القيمة للمكونين الآخرين لمتجه scaleFactor إلى 0. هذا خطأ واضح، يجب تعيينها إلى 1 لـ عدم قياس الشكل (الأشكال) في الاتجاهين الآخرين.

كن حذرًا عند تعيين قيم مكونات scaleFactor إلى 0 أو إلى قيم سالبة. يجب أن تتعامل معظم الأشكال مع هذه الحالات بطريقة ما، ولكن النتائج غير محددة ما لم يتم تحديد خلاف ذلك.

القيمة الافتراضية لهذا الحقل المتجهي هي [1.0, 1.0, 1.0].
