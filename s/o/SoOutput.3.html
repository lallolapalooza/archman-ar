الفئة SoOutput هي تجريد لتيار إخراج.

تقدم SoOutput القدرة على كتابة أنواع أساسية إلى ملف أو مخزن مؤقت للذاكرة بتنسيق ASCII أو ثنائي.

SbBool SoOutput::setCompression (const SbName & compmethod, const float level = 0.5f)

يحدد طريقة الضغط والمستوى المستخدمين عند كتابة الملف. compmethod هي مكتبة الضغط/الطريقة المستخدمة عند الضغط. level هو مستوى الضغط، حيث 0.0 يعني عدم الضغط و 1.0 يعني أقصى ضغط.

حاليًا، طرق الضغط المدعومة هي BZIP2 و GZIP، ويجب عليك تجميع Coin مع دعم zlib و bzip2 لتمكينها.

إذا كنت ترغب في تعطيل الضغط، فقم بتوفير compmethod = NONE أو level = 0.0. يتم تعطيل الضغط افتراضيًا.

ملاحظة: لا يمكن الضغط عند الكتابة إلى مخزن مؤقت للذاكرة.

ستعيد هذه الطريقة TRUE إذا كانت طريقة الضغط المحددة متاحة. إذا لم تكن كذلك، فستعيد FALSE وسيتم تعطيل الضغط.

void SoOutput::setBuffer (void * bufPointer, size_t initSize, SoOutputReallocCB * reallocFunc, int32_t offset = 0) [virtual]

يحدد مخزنًا مؤقتًا للذاكرة بحجم initSize للكتابة. ستبدأ الكتابة عند bufPointer + offset.

إذا امتلأ المخزن المؤقت، يتم استدعاء reallocFunc للحصول على المزيد من الذاكرة. إذا أعادت reallocFunc NULL، فسيتم تعطيل الكتابة.

ملاحظة هامة: تذكر أن المخزن المؤقت للذاكرة الناتج بعد عمليات الكتابة قد يقع في ذاكرة مختلفة عن bufPointer إذا تم تعيين reallocFunc. من الجيد جعلها عادة استخدام getBuffer() لاسترداد المؤشر إلى المخزن المؤقت بعد عمليات الكتابة.

إليك مثال كامل ومستقل يوضح كيفية كتابة سيناريو رسومي إلى مخزن مؤقت للذاكرة:

#include <Inventor/SoDB.h>
#include <Inventor/actions/SoWriteAction.h>
#include <Inventor/nodes/SoCone.h>
#include <Inventor/nodes/SoSeparator.h>
static char * buffer;
static size_t buffer_size = 0;
static void *
buffer_realloc(void * bufptr, size_t size)
{
  buffer = (char *)realloc(bufptr, size);
  buffer_size = size;
  return buffer;
}
static SbString
buffer_writeaction(SoNode * root)
{
  SoOutput out;
  buffer = (char *)malloc(1024);
  buffer_size = 1024;
  out.setBuffer(buffer, buffer_size, buffer_realloc);
  SoWriteAction wa(&out);
  wa.apply(root);
  SbString s(buffer);
  free(buffer);
  return s;
}
int
main(int argc, char ** argv)
{
  SoDB::init();
  SoSeparator * root = new SoSeparator;
  root->ref();
  root->addChild(new SoCone);
  SbString s = buffer_writeaction(root);
  (void)fprintf(stdout, "%s\n", s.getString());
  root->unref();
  return 0;
}

Detailed Description

This class is derived from SoState, which is used to hold the current traversal state. SoOutput adds functionality for writing scene graphs to files or memory buffers.

The writer will automatically write the file header if it hasn't already been written. This happens for the first invocation of any write method in the class.

The class also keeps track of Open Inventor proto nodes, which allows for writing files that can be read back by Coin.

It is also used to keep track of routes that have been added to the scene graph.

typedef void (* SoOutput::reallocationcallback) (void * clientdata, size_t newsize, size_t * oldsize)

Callback function pointer type for buffer reallocation.

The clientdata is the pointer that was passed to setBuffer(). The newsize is the requested new size of the buffer. The oldsize pointer points to the current size of the buffer. The callback should return a pointer to the newly allocated buffer, or NULL if reallocation fails.
