وصف تفصيلي

فئة SoSFEnum هي حاوية لقيمة تعداد.

يستخدم هذا الحقل عندما تحتاج العقد أو المحركات أو حاويات الحقول الأخرى إلى تخزين قيمة واحدة معينة من مجموعة تعداد.

يقوم حقل من هذا النوع بتخزين قيمته في الملف بالاسم الرمزي، بدلاً من القيمة العددية الفعلية.

يتم تهيئة مثيلات SoSFEnum على أساس المثيل، عادةً في مُنشئ حاوية الحقل باستخدام وحدات الماكرو SO_NODE_DEFINE_ENUM_VALUE(enumtype, symbolvalue) و SO_NODE_SET_SF_ENUM_TYPE(enumfield, enumtype) للعقد، أو للمحركات؛ SO_ENGINE_DEFINE_ENUM_VALUE() و SO_ENGINE_SET_SF_ENUM_TYPE().

مثال على التهيئة من مُنشئ فئة SoCone:

SO_NODE_DEFINE_ENUM_VALUE(Part, SIDES);
SO_NODE_DEFINE_ENUM_VALUE(Part, BOTTOM);
SO_NODE_DEFINE_ENUM_VALUE(Part, ALL);
SO_NODE_SET_SF_ENUM_TYPE(parts, Part);

Detailed Description


An SoSFEnum is a field that holds an enumeration value.
    Enumeration values are represented as integer values, but the application
    can provide a set of names for these values. An enumeration value can be set
    by string name or by integer value.


When setting the value by name, the library searches for the
    given name in the set of registered enum names. If found, the corresponding
    integer value is set. If not found, the value is not changed.


If no enum name-to-value mapping is registered for an SoSFEnum
    field, it behaves like an SoSFInt32 field.


The enum name-to-value mappings can be registered by calling
    SoSFEnum::setEnums(). This is typically done by the node class
    that uses the field.
