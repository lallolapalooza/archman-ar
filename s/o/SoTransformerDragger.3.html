SoRotation(3)

Name

SoRotation - node for specifying object rotation, translation and scale

Description

This node is intended to be used by draggers to specify the rotation, translation and scale of an object.

It stores three fields: rotation, translation and scaleFactor.

It also stores two configuration fields: minDiscRotDot and maxDiscRotDot.

rotation is the rotation value.

translation is the translation value.

scaleFactor is the scale value.

minDiscRotDot is the minimum dot product between rotation vectors that allows a discrete rotation.

maxDiscRotDot is the maximum dot product between rotation vectors that allows a discrete rotation.

When the rotation field is modified, the dragger will receive a notification and use the new value to rotate the object.

The translation and scaleFactor fields are not used by the rotation dragger.

The minDiscRotDot and maxDiscRotDot fields are used to control the discrete rotation behavior.

The default values are:

rotation = 0 0 1 0
translation = 0 0 0
scaleFactor = 1 1 1
minDiscRotDot = 0.9
maxDiscRotDot = 0.95

هذه دالة افتراضية، ويجب أن يستدعي الكود فيها SoField::setDefault() مع الوسيط TRUE على الحقول الجزئية التي لا ينبغي كتابتها عند تصدير الرسوم البيانية للمشهد.

يتم ذلك عادةً عندما:

1.
قيمة الحقل هي NULL والحزء هو NULL بشكل افتراضي
2.
إنها عقدة طرفية SoGroup أو SoSeparator بدون أبناء
3.
إنها جزء طرفي وقائمة بدون أبناء وSoGroup أو SoSeparator حاوية
4.
إنها جزء غير طرفي وهي من نوع SoGroup وجميع الحقول عند قيمها الافتراضية

عادةً ما يجب على الفئات الفرعية تجاوز هذا لإجراء إعدادات إضافية للحقول الجديدة. من الفئة الفرعية، تذكر أن تستدعي "للأعلى" إلى دالة setDefaultOnNonWritingFields() الخاصة بفئتك الأم.
