SOFTHSM2-DUMP-FILE(1) دليل الأوامر العامة (General Commands Manual) SOFTHSM2-DUMP-FILE(1)

الاسم (NAME)

softhsm2-dump-file - تفريغ ملف كائن SoftHSM

نبذة (SYNOPSIS)

softhsm2-dump-file path

الوصف (DESCRIPTION)

softhsm2-dump-file هي أداة يمكنها تفريغ ملف كائن SoftHSM v2 لأغراض التصحيح.

خيارات (OPTIONS)

path
ملف كائن SoftHSM v2 الذي سيتم تفريغه.
--help, -h
عرض معلومات المساعدة.
