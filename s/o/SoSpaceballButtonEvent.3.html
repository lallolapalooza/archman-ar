الوصف التفصيلي

فئة SoSpaceballButtonEvent تحتوي على معلومات حول تفاعل زر الكره الفضائيه.

عندما يضغط المستخدم على أي أزرار في جهاز الكره الفضائيه، سيتم ترجمتها من حدث خاص بالنظام إلى حدث Coin وإرسالها إلى الرسم البياني للمشهد باستخدام مثيلات من هذه الفئة.

NAME

SoSpaceballButtonEvent - Button press/release event from a 3D input device.

#include <Inventor/events/SoSpaceballButtonEvent.h>

Detailed Description

This event class is used for button press and release events from a 3D input device (like a 3D mouse or Spaceball).

The class is derived from SoButtonEvent, and adds the capability to represent the different buttons on a Spaceball.

The possible values for buttons are enumerated in the `Button` enumeration.
