SOAP__Packager(3pm)

الحزمة: perl-soap-lite

التراخيص: GPL-1.0-or-later, Artistic-1.0-Perl

SOAP::Packager(3) وثائق مقدمة من Perl SOAP::Packager(3)

الاسم

SOAP::Packager - هذه الفئة فئة مجردة تسمح بإدارة أنواع متعددة من وكلاء التعبئة، مثل MIME و DIME.

الوصف

فئة SOAP::Packager مسؤولة عن إدارة مجموعة من "الأجزاء". الأجزاء هي قطع إضافية من المعلومات، مستندات إضافية، أو أي شيء تقريبًا يحتاج إلى الارتباط بجسم رسالة SOAP. ثم يأخذ المعبئ هذه الأجزاء ويقوم بتشفير/فك تشفير أو "تعبئة"/"تفريغ" لها أثناء انتقالها عبر الشبكة.

الطرق

جديد
يقوم بإنشاء مثيل جديد لفئة SOAP::Packager.
أجزاء
تحتوي على مصفوفة من الأجزاء. يعتمد محتوى هذه المصفوفة وأنواعها بالكامل على ما يستخدمه المعبئ. على سبيل المثال، عند استخدام MIME، فإن محتوى هذه المصفوفة هو MIME::Entity's.
push_part
يضيف جزءًا إلى قائمة الأجزاء التي تديرها المثيل الحالي لـ SOAP::Packager.
محلل
يعيد المحلل المستخدم لتحليل الملفات المرفقة من تدفق بيانات.
headers_http
هذا خطاف في طبقة HTTP. يوفر طريقة لوكيل لتصنيع و/أو تعديل رؤوس HTTP في طلب/استجابة. على سبيل المثال، أكثر من 90٪ من وكلاء المجتمع سيحتاجون إلى استبدال نوع المحتوى (مثل multipart/related أو application/dime).

الطرق المجردة

إذا كنت تريد تطبيق SOAP::Packager الخاص بك، فيجب عليك تطبيق الطرق أدناه وفقًا لمتطلبات الإدخال والإخراج المحددة.

packejar()
تأخذ الوظيفة الفرعية "packejar" كمدخل رسالة SOAP كسلسلة نصية/SCALAR. ستكون هذه هي محتويات الجزء الأول. يقوم المعبئ بتغليف الرسالة في الأجزاء الموجودة في "parts" ويعيد الرسالة المغلفة بشكل صحيح كسلسلة نصية/SCALAR.
despackejar()
تأخذ الوظيفة الفرعية "despackejar" كمدخل بيانات خام يجب تحليلها إلى مجموعة من الأجزاء. وهي مسؤولة عن استخراج الرسالة من المدخل وملء "parts" بمصفوفة من الأجزاء المستخرجة من المدخل. ثم تعيد رسالة SOAP كسلسلة نصية/SCALAR حتى تتمكن SOAP::Lite من تحليلها.

تنسيقات التعبئة المدعومة بالبرامج

SOAP::Packager::MIME

"SOAP::Packager::MIME" تستخدم MIME::Tools لتوفير القدرة على إرسال واستقبال الطلبات والاستجابات بتنسيق Multipart/Related و Multipart/Form-Data.

طرق MIME

تستخدم الطرق التالية عند إنشاء رسالة بتنسيق MIME.

transfer_encoding
قيمة رأس Content-Transfer-Encoding للجزء الرئيسي. القيمة الافتراضية: 8bit.
env_id
قيمة رأس Content-Id للجزء الرئيسي. القيمة الافتراضية: <main_envelope>.
env_location
قيمة رأس Content-Location للجزء الرئيسي. القيمة الافتراضية: /main_envelope.
env_type
قيمة رأس Content-Type للجزء الرئيسي. القيمة الافتراضية: text/xml.

تحسين محلل MIME

يمكن أن يؤدي استخدام المرفقات إلى استهلاك كبير لموارد النظام اعتمادًا على كيفية تكوين محلل MIME. على سبيل المثال، يمكنك إخبار المحلل بتخزين المرفقات في الذاكرة أو استخدام ملفات مؤقتة. قد يؤثر استخدام أحدهما على الأداء، استخدام القرص، و/أو الموثوقية. لذلك، يجب عليك الرجوع إلى عنوان URL التالي للحصول على تقنيات التحسين والمقايضات:

http://search.cpan.org/dist/MIME-tools/lib/MIME/Parser.pm#OPTIMIZING_YOUR_PARSER

لتعديل خيارات تكوين المحلل، راجع مثال الكود التالي، والذي يوضح أيضًا كيفية تقليل استخدام الذاكرة:

my $packager = SOAP::Packager::MIME->new;
# $packager->parser->decode_headers(1); # لا يهم
# $packager->parser->extract_nested_messages(1); # لا يهم
$packager->parser->output_to_core(0); # ذاكرة أقل
$packager->parser->tmp_to_core(0); # ذاكرة أقل
$packager->parser->tmp_recycling(0); # يعزز جمع القمامة الأسرع
$packager->parser->use_inner_files(1); # لا يهم
my $client = SOAP::Lite->uri($NS)->proxy($URL)->packager($packager);
$client->someMethod();

مثال عميل

يوضح مثال الكود التالي كيفية استخدام المرفقات في سياق عميل SOAP::Lite.

#!/usr/bin/perl
use SOAP::Lite;
use MIME::Entity;
my $ent = build MIME::Entity
  Type        => "text/plain",
  Path        => "attachment.txt",
  Filename    => "attachment.txt",
  Disposition => "attachment";
my $NS = "urn:Majordojo:TemperatureService";
my $HOST = "http://localhost/cgi-bin/soaplite.cgi";
my $client = SOAP::Lite
  ->packager(SOAP::Packager::MIME->new)
  ->parts([ $ent ])
  ->uri($NS)
  ->proxy($HOST);
my $response = $client->c2f(SOAP::Data->name("temperature" => '100'));
print $response->valueof('//c2fResponse/foo');

مثال خادم

يوضح المثال التالي كيفية استخدام المرفقات في سياق نص CGI. يعرض كيفية قراءة المرفقات الواردة وإعادتها إلى العميل.

#!/usr/bin/perl -w
use SOAP::Transport::HTTP;
use MIME::Entity;
SOAP::Transport::HTTP::CGI
  ->packager(SOAP::Packager::MIME->new)
  ->dispatch_with({'urn:Majordojo:TemperatureService' => 'TemperatureService'})
  ->handle;
BEGIN {
  package TemperatureService;
  use vars qw(@ISA);
  @ISA = qw(Exporter SOAP::Server::Parameters);
  use SOAP::Lite;
  sub c2f {
    my $self = shift;
    my $envelope = pop;
    my $temp = $envelope->dataof("//c2f/temperature");
    use MIME::Entity;
    my $ent = build MIME::Entity
      Type        => "text/plain",
      Path        => "printenv",
      Filename    => "printenv",
      Disposition => "attachment";
    # قراءة المرفقات
    foreach my $part (@{$envelope->parts}) {
      print STDERR "soaplite.cgi: مرفق تم العثور عليه! (".ref($part).")\n";
      print STDERR "soaplite.cgi: المحتوى => ".$part->stringify."\n";
    }
    # إرجاع المرفقات
    return SOAP::Data->name('convertedTemp' => (((9/5)*($temp->value)) + 32)),
      $ent;
  }
}
