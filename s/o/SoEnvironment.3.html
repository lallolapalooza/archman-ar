تعداد SoEnvironment::FogType

تعداد لأنواع الضباب المتاحة.

المعدادات:

NONE
لا يوجد ضباب. ستكون الرؤية متساوية لجميع الكائنات بغض النظر عن المسافة إلى الكاميرا.
HAZE

FOG
ستقل الرؤية أسيًا مع المسافة إلى الكاميرا.
SMOKE
ستقل الرؤية أسيًا مع مربع المسافة إلى الكاميرا (محاكاة ضباب كثيف جدًا).

SoSFFloat SoEnvironment::ambientIntensity

قيمة شدة الإضاءة المحيطة للمشهد بأكمله. يوفر هذا بعض الضوء حتى لو لم تكن هناك مصادر ضوء محددة في المشهد.

NAME

SoEnvironment

manages rendering state (light, fog, visibility, etc.)

SYNOPSIS

#include <Inventor/nodes/SoEnvironment.h>

Inherits from SoNode.

Inherited Field Data:

  SoSFNode           children
  SoSFNode           renderCull

Detailed Description

This node defines the global rendering environment. It contains several fields which control the rendering of the scene, such as fog, visibility, background color, etc.

The state defined by this node is inherited downwards through the scene graph, meaning that any node after this node in the scene graph will have the environment defined by this node. This node should normally appear near the root of the scene graph.

Member Data Documentation

SoSFColor SoEnvironment::backgroundColor

Background color. Defaults to black.

SoSFBool SoEnvironment::visible

Specifies whether the scene is visible. Defaults to TRUE.

SoSFFloat SoEnvironment::nearDistance

The distance from the camera to the near clipping plane. Defaults to 0.1.

SoSFFloat SoEnvironment::farDistance

The distance from the camera to the far clipping plane. Defaults to 1000.0.

SoSFFloat SoEnvironment::intensity

The intensity of the ambient light. Defaults to 1.0.

This field is only used when the fog model is set to SoEnvironment::FOG_NONE.

SoSFFloat SoEnvironment::fogIntensity

The intensity of the fog. This is a value between 0.0 and 1.0, inclusive. Defaults to 1.0.

The actual attenuation is calculated using the following formula: attenuation = exp(-fogIntensity * distance / fogVisibility). See the description of fogVisibility of how attenuation is usually specified.

SoSFEnum SoEnvironment::fogType

The fog model. See SoEnvironment::FoType.

SoSFColor SoEnvironment::fogColor

Color of fog. Defaults to full intensity white.

SoSFFloat SoEnvironment::fogVisibility

The "cut-off" distance from the camera where objects will be totally obscured by fog. If set to 0.0, the far plane distance will be used instead.

Default value is 0.0.
