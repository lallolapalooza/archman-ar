Sort::Key::Types(3) وثائق Perl مساهمة من المستخدم Sort::Key::Types(3)

Sort::Key::Types - التعامل مع أنواع بيانات Sort::Key

ملخص

use Sort::Key::Types qw(register_type);
register_type(Color => sub { $_->R, $_->G, $_->B }, qw(int, int, int));
# من الأفضل لك
# use Sort::Key::Register ...

الوصف

يمكن توسيع عائلة وحدات Sort::Key لدعم أنواع مفاتيح جديدة باستخدام هذه الوحدة (أو Sort::Key::Register الأكثر سهولة).

الوظائف

يتم توفير الوظائف التالية:

Sort::Key::register_type($name, \&gensubkeys, @subkeystypes)
تسجل نوع بيانات جديد يسمى $name يحدد كيفية تحويله إلى مفتاح متعدد.

&gensubkeys يجب أن يحول كائن النوع $name الممرر في $_ إلى قائمة قيم تشكل المفتاح المتعدد.

@subkeystypes هي قائمة الأنواع للمفاتيح الفرعية المنشأة.

على سبيل المثال:

Sort::Key::Types::register_type
               'Person',
               sub { $_->surname,
                     $_->name,
                     $_->middlename },
               qw(str str str);
Sort::Key::Types::register_type
               'Color',
               sub { $_->R, $_->G, $_->B },
               qw(int int int);

بمجرد تسجيل نوع بيانات، يمكن استخدامه بنفس الطريقة التي تستخدم بها الأنواع المدعومة أصليًا، حتى لتعريف أنواع جديدة، أي:

Sort::Key::Types::register_type
               'Family',
               sub { $_->father, $_->mother },
               qw(Person Person);

انظر أيضًا

Sort::Key, Sort::Key::Merger, Sort::Key::Register.
