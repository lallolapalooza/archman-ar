NAME

SoMFEnum — manifold enumeration field

SYNOPSIS

#include <Inventor/fields/SoMFEnum.h>

Inheritance diagram:

SoField
  |
  +--SoMField
       |
       +--SoMFEnum

Detailed Description

This is a field type that stores multiple enumeration values.

A field of this type stores its values to file as the symbolic names, rather than the actual integer values.

See also

SoSFEnum, SoMFBitMask
