Detailed Description

This node transforms texture coordinates. The transformation is applied to the texture coordinates before they are used to look up texels in the texture. By default, only the first texture unit is affected.

The SoTexture2Transform node affects the texture coordinates by applying a scale, rotation and translation. It can also be used to specify a texture coordinate generation type.

The transformation is specified relative to the node's center. The default center is [0,0].

The SoTexture2Transform node supports the following transformations:

scale
Scales the texture coordinates. The default value is [1,1].
rotation
Rotates the texture coordinates. The default value is 0.
translation
Translates the texture coordinates. The default value is [0,0].
center
The center for rotation and scaling. The default value is [0,0].

The SoTexture2Transform node also supports two different modes for texture coordinate generation: TRANSFORM_PIXEL_AREA and TRANSFORM_UV_AREA. The former implies that the transformations specified in the node are meant to be applied to the pixels of the texture, while the latter implies that the transformations are meant to be applied to the texture's UV coordinate space. The default mode is TRANSFORM_UV_AREA.

In addition to the above, the node also supports setting an arbitrary 3x3 matrix. This is useful for applying more complex transformations that cannot be represented by simple scaling, rotation and translation.

The texture unit which is affected by the transformation can be specified using the texUnit field. By default, the transformation is applied to texture unit 0.

See also: SoTextureTransform, SoTexture3Transform
