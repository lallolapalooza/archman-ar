SONIVOXRENDER(1) Sonivox MIDI File Renderer SONIVOXRENDER(1)

الاسم

sonivoxrender — معالجة ملفات MIDI القياسية إلى صوت PCM خام

الملخص

sonivoxrender [-h|--help] [-v|--version] [-d|--dls file.dls] [-r|--reverb 0..4] [-w|--wet 0..32767] [-n|--dry 0..32767] [-c|--chorus 0..4] [-l|--level 0..32767] [-g|--gain 0..100] [-V|--Verbosity 0..5] midi_file

الوصف

هذا البرنامج هو معالج ملفات MIDI يعتمد على مكتبة sonivox synthesizer. يقرأ تنسيق ملف .MID (ملفات MIDI القياسية)، ويكتب دفق صوتي إلى المخرج القياسي كعينات PCM ستيريو خام 16 بت.

خيارات

-h, --help
طباعة معلومات الاستخدام المختصرة.
-v, --version
طباعة أرقام الإصدار.
-d, --dls file.dls
اسم ملف DLS soundfont اختياري. إذا لم يتم توفيره، فإنه يستخدم soundfont مضمن داخليًا.
-r, --reverb reverb_preset
إعداد مسبق للصدى بين 0 و 4: 0=لا، 1=قاعة كبيرة، 2=قاعة، 3=غرفة، 4=غرفة.
-w, --wet reverb_wet
مستوى الرطوبة للصدى بين 0 و 32767.
-n, --dry reverb_dry
مستوى الجفاف للصدى بين 0 و 32767.
-c, --chorus chorus_preset
إعداد مسبق للكورس بين 0 و 4: 0=لا، 1..4=إعدادات مسبقة.
-l, --level chorus_level
مستوى الكورس بين 0 و 32767.
-g, --gain master_gain
كسب رئيسي بين 0 و 100، الافتراضي هو 90 (10 ديسيبل تحت الحد الأقصى).
-V, --Verbosity verbosity
مستوى الإسهاب بين 0 و 5، حيث 0=لا، 1..5=مستويات الشدة.

الوسائط

midi_file
اسم ملف MID المدخل.

أمثلة

تفترض الأمثلة التالية أن معدل العينة الافتراضي USE_44KHZ=ON، مما يعني أن معدل عينة الإخراج = 44100 هرتز.

مثال 1: معالجة ملف MIDI وحفظ الصوت المعالج كملف صوت خام:

$ sonivoxrender ants.mid > ants.pcm

مثال 2: تمرير الصوت المعالج عبر أداة aplay الخاصة بـ Linux ALSA:

$ sonivoxrender ants.mid | aplay -c 2 -f S16_LE -r 44100

يعادل:

$ sonivoxrender ants.mid | aplay -f cd

مثال 3: تمرير الصوت المعالج عبر أداة lame لإنشاء ملف MP3:

$ sonivoxrender ants.mid | lame -r -s 44100 - ants.mp3

مثال 4: تمرير الصوت المعالج عبر أداة sox لإنشاء ملف WAV:

$ sonivoxrender ants.mid | sox -t s16 -c 2 -r 44100 - ants.wav

مثال 5: تمرير الصوت المعالج عبر أداة pacat الخاصة بـ PulseAudio:

$ sonivoxrender ants.mid | pacat
