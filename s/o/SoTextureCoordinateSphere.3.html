SoTextureCoordinateSphere - A sphere texture coordinate generator

NAME

SoTextureCoordinateSphere - A sphere texture coordinate generator

SYNOPSIS

Inherits from SoTextureCoordinate3D.

DESCRIPTION

This node generates texture coordinates based on spherical mapping. It maps the texture onto the object as if the object were enclosed in a sphere, and the texture were projected from the center of the sphere outwards.
