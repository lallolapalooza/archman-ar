NAME

SoHandleBoxManip, SoHandleBoxManip — Manipulator with a box shape for handles

Detailed Description

This manipulator provides a manipulator with a box shape. The box has handles on each of its faces, which can be used to translate, rotate or scale the object. The manipulator is intended to be used as a component in other manipulators, such as SoDragPointManip.

The manipulator provides three fields: translation, rotation and scale. These fields can be used to control the manipulator's transformation.
