توثيق الوظيفة/الإجراء الفرعي

subroutine sorbdb3 (integer m, integer p, integer q, real, dimension(ldx11,*) x11, integer ldx11, real, dimension(ldx21,*) x21, integer ldx21, real, dimension(*) theta, real, dimension(*) phi, real, dimension(*) taup1, real, dimension(*) taup2, real, dimension(*) tauq1, real, dimension(*) work, integer lwork, integer info)

SORBDB3

الغرض:

!>
!> تقوم SORBDB3 بتحويل كتل المصفوفة X ذات الأعمدة المتعامدة، والتي تكون طويلة ورفيعة،
!> إلى شكل ثنائي الأقطار بشكل متزامن:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 هي مصفوفة من حجم P × Q، و X21 هي مصفوفة من حجم (M-P) × Q. يجب أن يكون M-P
!> أصغر من أو يساوي P، Q، أو M-Q. الإجراءات SORBDB1, SORBDB2, و SORBDB4 تتعامل مع
!> الحالات التي لا يكون فيها M-P هو الحد الأدنى للحجم.
!>
!> P1, P2, و Q1 هي مصفوفات متعامدة بأبعاد P × P، (M-P) × (M-P)، و (M-Q) × (M-Q)
!> على التوالي. يتم تمثيلها ضمنيًا بواسطة متجهات هاوسهولدر.
!>
!> B11 و B21 هي مصفوفات ثنائية الأقطار بأبعاد (M-P) × (M-P) ممثلة ضمنيًا
!> بزوايا THETA و PHI.
!>
!>

المعلمات:

M 
!>          M is INTEGER
!>           عدد صفوف X11 زائد عدد صفوف X21.
!>

P

!>          P is INTEGER
!>           عدد صفوف X11. 0 <= P <= M. M-P <= min(P,Q,M-Q).
!>

Q

!>          Q is INTEGER
!>           عدد أعمدة X11 و X21. 0 <= Q <= M.
!>

X11

!>          X11 is REAL array, dimension (LDX11,Q)
!>           عند الإدخال، الجزء العلوي من المصفوفة X المراد تخفيضها. عند
!>           الخروج، تحدد أعمدة tril(X11) متجهات الانعكاس لـ P1
!>           وتحدد صفوف triu(X11,1) متجهات الانعكاس لـ Q1.
!>

LDX11

!>          LDX11 is INTEGER
!>           البعد الرائد لـ X11. LDX11 >= P.
!>

X21

!>          X21 is REAL array, dimension (LDX21,Q)
!>           عند الإدخال، الجزء السفلي من المصفوفة X المراد تخفيضها. عند
!>           الخروج، تحدد أعمدة tril(X21) متجهات الانعكاس لـ P2.
!>

LDX21

!>          LDX21 is INTEGER
!>           البعد الرائد لـ X21. LDX21 >= M-P.
!>

THETA

!>          THETA is REAL array, dimension (Q)
!>           تُعرّف إدخالات الكتل ثنائية الأقطار B11, B21 بواسطة
!>           THETA و PHI. انظر التفاصيل الإضافية.
!>

PHI

!>          PHI is REAL array, dimension (Q-1)
!>           تُعرّف إدخالات الكتل ثنائية الأقطار B11, B21 بواسطة
!>           THETA و PHI. انظر التفاصيل الإضافية.
!>

TAUP1

!>          TAUP1 is REAL array, dimension (P)
!>           العوامل العددية لمُحدِثات العناصر الأولية التي تُعرّف
!>           P1.
!>

TAUP2

!>          TAUP2 is REAL array, dimension (M-P)
!>           العوامل العددية لمُحدِثات العناصر الأولية التي تُعرّف
!>           P2.
!>

TAUQ1

!>          TAUQ1 is REAL array, dimension (Q)
!>           العوامل العددية لمُحدِثات العناصر الأولية التي تُعرّف
!>           Q1.
!>

WORK

!>          WORK is REAL array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>           بعد مصفوفة WORK. LWORK >= M-Q.
!>
!>           إذا كانت LWORK = -1، فيُفترض استعلام مساحة العمل؛ يقوم الإجراء
!>           بحساب حجم مساحة العمل المثلى فقط، ويعيد هذا الحجم كالإدخال الأول
!>           لمصفوفة WORK، ولا يتم إصدار أي رسالة خطأ متعلقة بـ LWORK بواسطة
!>           XERBLA.
!>

INFO

!>          INFO is INTEGER
!>           = 0:  انتهاء ناجح.
!>           < 0:  إذا كان INFO = -i، فقد كان الوسيط i غير قانوني.
!>

التفاصيل الإضافية:

!>
!>  تُمثّل الكتل ثنائية الأقطار العلوية B11, B21 ضمنيًا بواسطة
!>  الزوايا THETA(1), ..., THETA(Q) و PHI(1), ..., PHI(Q-1). كل إدخال
!>  في كل نطاق ثنائي الأقطار هو ناتج ضرب جيب أو جيب تمام لـ THETA
!>  مع جيب أو جيب تمام لـ PHI. انظر [1] أو SORCSD للتفاصيل.
!>
!>  تُمثّل P1, P2, و Q1 كنوات لضرب مُحدِثات العناصر الأولية.
!>  انظر SORCSD2BY1 لمعرفة تفاصيل توليد P1, P2, و Q1 باستخدام SORGQR
!>  و SORGLQ.
!>

المراجع:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
