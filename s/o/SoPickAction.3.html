Detailed Description

The SoPickAction class is the base class for all actions that perform some kind of picking. Picking involves traversing the scene graph and determining which objects are intersected by rays or are within certain regions.

The primary purpose of SoPickAction is to define the interface for classes that inherit from it, such as SoRayPickAction, and to provide common functionality needed by all picking actions.

Key features and concepts related to SoPickAction include:

Viewport Region
A picking action operates within a specific viewport region. This region defines the area of the screen or window that the picking operation is concerned with. The viewport region can be set using setViewportRegion().
Culling
Picking actions can optionally perform culling to optimize the traversal. Culling involves determining if objects are outside the visible area and can therefore be skipped. The enableCulling() and isCullingEnabled() methods control this behavior.
Enabled Elements and Action Methods
The class provides mechanisms (though considered internal) to manage lists of enabled elements and action methods, which are crucial for the action's traversal and processing logic.

void SoPickAction::beginTraversal (SoNode * node) [protected], [virtual]

This virtual method is called from SoAction::apply(), and is the entry point for the actual scene graph traversal.

It can be overridden to initialize the action at traversal start, for specific initializations in the action subclasses inheriting SoAction.

Default method just calls traverse(), which any overridden implementation of the method must do too (or call SoAction::beginTraversal()) to trigger the scene graph traversal.
