SoLightModelElement(3)

NAME SoLightModelElement - element for controlling light model

SYNOPSIS #include <Inventor/elements/SoLightModelElement.h>

Inherits SoElement.

Inherited by SoGLLightModelElement.

Detailed Description This element controls the light model which is used for lighting calculations. The light model specifies how the lighting equations are computed, and in particular how ambient, diffuse and specular light components are to be calculated. The available light models are:

  • SoLightModelElement::BASE: this is the default light model. It uses ambient, diffuse, and specular components in the lighting equation. This light model is a simpler model and is less computationally expensive than the other models.
  • SoLightModelElement::PHONG: this light model uses the Phong shading model. It is more computationally expensive than the BASE model, but produces more realistic results.
