SoTimerQueueSensor(3)

الحزمة: coin

التراخيص: BSD-3-Clause

NAME

SoTimerQueueSensor, SbBool SoTimerQueueSensor::scheduled

SYNOPSIS

#include <Inventor/sensors/SoTimerQueueSensor.h>

<Inherits from SoSensor>

// Static methods
static SoType SoType_SoTimerQueueSensor(void);
static void SoTimerQueueSensor_setTimerResolution(SbTime duration);

// Methods
protected :
  virtual SbBool scheduled(void) const;

DESCRIPTION

This class is an extension of SoSensor that triggers a timer event. It is used to perform actions after a specific time interval has passed. The timer resolution can be set globally for all timer queue sensors.

CONSTRUCTOR & DESTRUCTOR DOCUMENTATION

There are no specific constructors or destructors documented for this class. It inherits them from its parent class SoSensor.

MEMBER FUNCTION DOCUMENTATION

SoType SoTimerQueueSensor::SoType_SoTimerQueueSensor(void)

Returns the SoType object associated with this class.

void SoTimerQueueSensor::setTimerResolution(SbTime duration)

Sets the timer resolution for all timer queue sensors. The `duration` parameter specifies the minimum time interval between timer events.

SbBool SoTimerQueueSensor::scheduled(void) const

Returns TRUE if the sensor is currently scheduled.

MEMBER DATA DOCUMENTATION

SbBool SoTimerQueueSensor::scheduled [protected]

TRUE if the sensor is currently scheduled.
