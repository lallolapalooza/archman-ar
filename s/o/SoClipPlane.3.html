الوصف المفصل

SoClipPlane هي فئة نوع عقدة لتحديد مستويات القطع.

يستخدم الرسم البياني للمشهد بدون أي عقد SoClipPlane ستة مستويات قطع لتحديد المخروط المرئي: علوي، سفلي، أيسر، أيمن، قريب وبعيد. إذا كنت تريد مستويات قطع إضافية لـ "تقطيع" الهندسة المرئية، يمكنك القيام بذلك باستخدام عقد من هذا النوع. يتم قص الهندسة على الجانب الخلفي لمستوى القطع.

لاحظ أن تطبيقات OpenGL لديها حد أقصى ثابت لعدد مستويات القطع المتاحة. لمعرفة هذا الرقم، يمكنك استخدام الكود التالي:

#include <Inventor/elements/SoGLClipPlaneElement.h>
// ...[تم اقتطاعها]...
int maxplanes = SoGLClipPlaneElement::getMaxGLPlanes();

أدناه مثال بسيط أساسي لاستخدام الرسم البياني للمشهد لـ SoClipPlane. يقوم بتوصيل SoClipPlane بـ SoCenterballDragger، للتحكم من قبل المستخدم في اتجاه وموضع مستوى القطع:

#Inventor V2.1 ascii
Separator {
   Separator {
      Translation { translation -6 0 0 }
      DEF cbdragger CenterballDragger { }
   }
   TransformSeparator {
      Transform {
         rotation 0 0 1 0 = USE cbdragger . rotation
         translation 0 0 0 = USE cbdragger . center
      }
      ClipPlane { }
   }
   Sphere { }
}

لاحظ أن SoClipPlane هي عقدة مظهرية تغير الحالة، وعلى هذا النحو، فإنها ستؤكد فقط تأثيراتها ضمن SoSeparator الحالي (حيث يقوم SoSeparator بدفع مكدس الحالة للخارج عند عودة المرور فوقه)، كما يمكن رؤيته بتحميل ملف المثال البسيط هذا في عارض Coin:

#Inventor V2.1 ascii
Separator {
   ClipPlane { }
   Cube { }
}
Separator {
   Translation { translation -3 0 0 }
   Cube { }
}

تنسيق الملف/الافتراضيات:

ClipPlane {
    plane 1 0 0  0
    on TRUE
}

NAME

SoClipPlane - clipping plane node

SYNOPSIS

Inherits from SoNode.

SoClipPlane {
    SoSFPlane plane
    SoSFBool on
}

DETAILED DESCRIPTION

This node defines a clipping plane. Clipping planes are used to cut away parts of the scene graph. They can be used for various effects, such as sectioning objects or creating transparent objects. Geometry on the back side of the clipping plane is clipped away.

The clipping plane is defined by its normal vector and its distance from the origin. The normal vector determines the orientation of the plane, and the distance determines its position. The default clipping plane has its normal pointing in the <1,0,0> direction, and intersects the origin. This means that everything along the negative X-axis is clipped away by default.

The on field determines whether the clipping plane is active or not. If on is TRUE, the clipping plane is active and geometry is clipped. If on is FALSE, the clipping plane is inactive and no clipping occurs.

CONSTRUCTOR & DESTRUCTOR DOCUMENTATION

SoClipPlane()
Creates a new SoClipPlane node with default values. The default clipping plane has its normal pointing in the <1,0,0> direction, and intersects the origin. The on field defaults to TRUE.
~SoClipPlane()
Destroys the SoClipPlane node.

MEMBER FUNCTION DOCUMENTATION

This class does not define any new member functions. It inherits all its member functions from SoNode.

MEMBER DATA DOCUMENTATION

SoSFPlane SoClipPlane::plane

Definition of clipping plane. Geometry on the back side of the clipping plane is clipped away.

The default clipping plane has its normal pointing in the <1,0,0> direction, and intersects origo. (I.e., everything along the negative X-axis is clipped.)

SoSFBool SoClipPlane::on

Whether clipping plane should be on or off. Defaults to TRUE.

الوصف التفصيلي

تحدد هذه العقدة مستوى قطع. تُستخدم مستويات القطع لقص أجزاء من شجرة المشهد. يمكن استخدامها لتأثيرات مختلفة، مثل تقسيم الكائنات أو إنشاء كائنات شفافة. يتم قص الهندسة الموجودة على الجانب الخلفي لمستوى القطع.

يتم تحديد مستوى القطع بواسطة متجهه الطبيعي والمسافة من الأصل. يحدد المتجه الطبيعي اتجاه المستوى، وتحدد المسافة موضعه. مستوى القطع الافتراضي له متجهه الطبيعي يشير في اتجاه <1,0,0>، ويمر بالأصل. هذا يعني أن كل شيء على طول المحور السيني السالب يتم قصه افتراضيًا.

يحدد الحقل on ما إذا كان مستوى القطع نشطًا أم لا. إذا كان on هو TRUE، فإن مستوى القطع نشط ويتم قص الهندسة. إذا كان on هو FALSE، فإن مستوى القطع غير نشط ولا يحدث أي قطع.
