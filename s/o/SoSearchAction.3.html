Detailed Description

This class is used to search for nodes in a scene graph.

You can set the search interest to SoSearchAction::FIRST, SoSearchAction::LAST, SoSearchAction::ALL, SoSearchAction::ALL_NOT_FIRST, SoSearchAction::ALL_NOT_LAST, or SoSearchAction::FROM_TAIL.

When the search is done, you can retrieve the found path(s) using getPath() or getPaths().

The search action is typically used in conjunction with SoAction::apply().

Example:

SoSearchAction searchAction;
searchAction.setInterest(SoSearchAction::FIRST);
searchAction.setType(SoNode::VRML97); // Search for VRML97 nodes
searchAction.apply(rootNode);

SoPath *path = searchAction.getPath();
if (path) {
  // Process the found path
}

void SoSearchAction::beginTraversal (SoNode * node) [protected], [virtual]

This virtual method is called from SoAction::apply(), and is the entry point for the actual scene graph traversal.

It can be overridden to initialize the action at traversal start, for specific initializations in the action subclasses inheriting SoAction.

Default method just calls traverse(), which any overridden implementation of the method must do too (or call SoAction::beginTraversal()) to trigger the scene graph traversal.

Reimplemented from SoAction.

SoSearchAction::Interest SoSearchAction::getInterest (void ) const

Returns the current search interest.

SoPath * SoSearchAction::getPath (void ) const

Returns the path that matched the search criterion. If the search interest is SoSearchAction::FIRST or SoSearchAction::LAST, this method returns the single matching path, or NULL if no node matched.

If the search interest is SoSearchAction::ALL, SoSearchAction::ALL_NOT_FIRST, or SoSearchAction::ALL_NOT_LAST, this method returns the first path found. Use getPaths() to get all the paths.

Note that if the actual tail of the path is needed, you might need to cast the path to a SoFullPath. See SoFullPath::getTail() for more information.

Example:

// Get the actual tail node
SoFullPath * path = (SoFullPath *) searchAction.getPath();
SoVRMLCoordinate * vrmlcord = (SoVRMLCoordinate *) path->getTail();

SbBool SoSearchAction::duringSearchAll = FALSE [static]

Obsoleted global flag, only present for compatibility reasons with old SGI / TGS Inventor application code.

It's set to TRUE when an SoSearchAction traversal with SoSearchAction::isSearchingAll() equal to TRUE is started, and is reset to FALSE again after traversal has finished.

(The flag is used by SGI / TGS Inventor in SoSwitch::affectsState() to know when SoSwitch::whichChild should behave as SoSwitch::SO_SWITCH_ALL. We have a better solution for this problem in Coin.)
