NAME

SoCreaseAngleElement — crease angle element

SYNOPSIS

#include <Inventor/elements/SoCreaseAngleElement.h>

Inheritance diagram:

    SoElement
        SoFloatElement
            SoCreaseAngleElement

Detailed Description

This element is used to store and retrieve the crease angle value for an Inventor scene graph. The crease angle determines how automatically generated normal vectors are calculated for curved surfaces.

A crease angle of 0 means that normal vectors will be generated for all faces, effectively making the surface appear faceted. A large crease angle, such as 180 degrees, will cause Inventor to attempt to generate smooth normal vectors across the entire surface.

الوصف التفصيلي

يُستخدم هذا العنصر لتخزين واسترجاع قيمة زاوية الطي لـ Inventor scene graph. تحدد زاوية الطي كيفية حساب متجهات المتعامد المولدة تلقائيًا للأسطح المنحنية.

تعني زاوية الطي 0 أن متجهات المتعامد سيتم إنشاؤها لجميع الوجوه، مما يجعل السطح يبدو مسطحًا. ستتسبب زاوية الطي الكبيرة، مثل 180 درجة، في محاولة Inventor إنشاء متجهات متعامدة سلسة عبر السطح بأكمله.
