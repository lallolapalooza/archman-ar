Name

SoNodeKitDetail — A node kit to manage the detail parts of a scene graph.

Synopsis

#include <Inventor/nodekits/SoNodeKitDetail.h>

Class SoNodeKitDetail

Inherits SoDetail.

---

Public Members

virtual const SoNode * getDetail () const

virtual void setDetail (const SoNode *detail)

Description

The SoNodeKitDetail node kit is used to manage the detail parts of a scene graph. It allows you to associate a specific node with a detail, which can be useful for storing additional information or metadata about a particular part of the scene.

The class provides two main methods:

  • getDetail(): Returns a pointer to the detail node associated with this SoNodeKitDetail.
  • setDetail(const SoNode *detail): Sets the detail node associated with this SoNodeKitDetail.

SoNodeKitDetail inherits from SoDetail, which is the base class for all detail objects in the Open Inventor scene graph.
