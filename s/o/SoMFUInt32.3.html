وصف تفصيلي

الفئة SoMFUInt32 هي حاوية لقيم الأعداد الصحيحة غير الموقعة ذات 32 بت.

يُستخدم هذا الحقل حيث تحتاج العقد أو المحركات أو حاويات الحقول الأخرى إلى تخزين مجموعة من قيم الأعداد الصحيحة غير الموقعة ذات 32 بت.

يدعم هذا الحقل مشاركة بيانات التطبيق من خلال دالة setValuesPointer(). راجع توثيق SoMField للحصول على معلومات حول كيفية استخدام هذه الدالة.

Detailed Description

Field module for storing an array of unsigned 32-bit integers. This field module is used to store multiple unsigned 32-bit integer values, typically to represent things like vertex indices, color values, etc.

This field module supports the following operations:

  • Setting and getting values.
  • Copying values from other fields.
  • Comparing values for equality.
  • Adding and removing values.

The actual values are stored as an array of unsigned 32-bit integers. The number of values in the array can be queried using the getNumValues() method (inherited from SoMField).

Example usage:

  // Create a new SoMFUInt32 field
  SoMFUInt32* myUInt32Array = new SoMFUInt32;

  // Add some values to the field
  myUInt32Array->addValue(10);
  myUInt32Array->addValue(20);
  myUInt32Array->addValue(30);

  // Get the values from the field
  const uint32_t* values = myUInt32Array->getValues(0);
  int numValues = myUInt32Array->getNumValues();

  // Print the values
  for (int i = 0; i < numValues; ++i) {
    std::cout << "Value " << i << ": " << values[i] << std::endl;
  }

  // Remove a value from the field
  myUInt32Array->removeValue(1); // Removes the value 20

  // Delete the field
  delete myUInt32Array;
