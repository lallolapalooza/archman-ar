الوصف التفصيلي

الفئة SoSFVec4d هي حاوية لمتجه SbVec4d.

يستخدم هذا الحقل عندما تحتاج العقد أو المحركات أو حاويات الحقول الأخرى إلى تخزين متجه واحد بأربعة عناصر.

انظر أيضًا

SbVec4d، SoMFVec4d كن على علم بأن هذه الفئة هي امتداد لـ Coin، وهي غير متوفرة في واجهة برمجة التطبيقات الأصلية لـ SGI Open Inventor v2.1.

منذ

Coin 2.5

NAME

SoSFVec4d - field containing a 4-component double-precision vector

SYNOPSIS

Detailed Description

This field class stores a 4-component double-precision vector. The components are typically used for homogeneous coordinates (x, y, z, w).

Implements SoField.
