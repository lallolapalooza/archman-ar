Mantener toda la estructura del archivo.
  • Una parte del kit de nodos no tiene una configuración específica. Una parte de tipo SoShape puede reemplazarse con cualquier otra forma, ya que son del mismo tipo. Si el kit de nodos de un humano tiene una parte llamada "head" de tipo SoShape, podría predefinirse como una esfera. Pero si el programador piensa que un cubo podría ajustarse mejor, puede establecer la parte "head" como un cubo o tal vez una parte de cara representando un modelo complejo de la cabeza.
  • Los kits de nodos pueden tener como simple o complejo catalogos según se necesite. Los nodos incluidos en el kit pueden representar, si es necesario, el rango completo de características de Inventor. Una parte puede ser de un tipo de kit de nodos, lo que permite crear jerarquías de kits de nodos. Con un kit de nodo de un humano, podría ser posible tener subkits de nodo que describan diferentes partes del cuerpo.
  • Los kits de nodo son una forma eficiente de crear árboles de escena. Si alguna parte del kit no se necesita al momento de la creación del kit de nodo, no se crea. Por lo tanto, las partes se crean solo cuando sean necesarias, por ejemplo, por la aplicación o por otra parte.
  • El código de la aplicación se vuelve más pequeño y fácil de leer, ya que el kit de nodos proporciona rutinas simples para crear y establecer partes.
  • Se pueden crear nuevos kits de nodo a través de herencia para obtener configuraciones simples de árboles de escena adecuadas para el aplicativo.

    • El uso de un kit de nodo es sencillo. A continuación, se muestra un ejemplo de uso de SoShapeKit.

    #include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/nodekits/SoShapeKit.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoCube.h>
int
main(int argc, char ** argv)
{
  QWidget * window = SoQt::init(argv[0]);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  // Instantiando un kit de forma por defecto, creando una esfera.
  SoShapeKit * shapekit = new SoShapeKit;
  // Cambiando la esfera por un cubo.
  shapekit->setPart("shape", new SoCube);
  // Estableciendo el cubo para ser renderizado en color rojo. El kit de nodo
  // tiene un SoAppearanceKit como una de sus partes. La parte "material"
  // utilizada para establecer el color de la forma realmente pertenece al
  // kit de apariencia. Si se usa SoShapeKit::set(), se verificará si alguna
  // de sus kits subordinados tiene una parte con el nombre dado y delegará la
  // configuración en el kit correcto.
  shapekit->set("material", "diffuseColor 1 0 0");
  SoSeparator * newroot = new SoSeparator;
  newroot->ref();
  newroot->addChild(shapekit);
  viewer->setSceneGraph(newroot);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  newroot->unref();
  return 0;
}

    A continuación, se muestra un ejemplo completo de extensión de un kit de nodo. El kit de nodo es un kit que automáticamente escala una forma para que tenga el mismo tamaño en píxeles de pantalla, sin importar la distancia desde el ojo. Esto es útil para gráficos de marcador. La forma predeterminada es un cubo, pero puede ser establecida por el programador a cualquier forma o subgrafo de escena.

    // Copyright (C) Kongsberg Oil & Gas Technologies. All rights reserved.
// El clase ShapeScale se usa para escalar una forma basada en el tamaño
// proyectado.
// Este nodokit puede insertarse en tu árbol de escena para añadir por
// ejemplo 3D markers que serán de tamaño constante en píxeles de pantalla.
// La forma de los marcadores se almacena en la parte "shape". Cualquier
// tipo de nodo puede usarse, incluso nodos de grupo con varias formas, pero
// la forma del marcador debería ser aproximadamente de tamaño unitario, y
// con un centro en (0, 0, 0).
// SoSFFloat ShapeScale::active
// Activa o desactiva la escala. Valor por defecto es TRUE.
// SoSFFloat ShapeScale::projectedSize
// El tamaño proyectado de la forma. Valor por defecto es 5.0.
#include "ShapeScale.h"
#include <Inventor/actions/SoGLRenderAction.h>
#include <Inventor/nodes/SoShape.h>
#include <Inventor/nodes/SoScale.h>
#include <Inventor/nodes/SoCube.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/elements/SoViewVolumeElement.h>
#include <Inventor/elements/SoViewportRegionElement.h>
#include <Inventor/elements/SoModelMatrixElement.h>
SO_KIT_SOURCE(ShapeScale);
// Constructor.
ShapeScale::ShapeScale(void)
{
  SO_KIT_CONSTRUCTOR(ShapeScale);
  SO_KIT_ADD_FIELD(active, (TRUE));
  SO_KIT_ADD_FIELD(projectedSize, (5.0f));
  SO_KIT_ADD_CATALOG_ENTRY(topSeparator, SoSeparator, FALSE, this, \x0, FALSE);
  SO_KIT_ADD_CATALOG_ABSTRACT_ENTRY(shape, SoNode, SoCube, TRUE, topSeparator, \x0, TRUE);
  SO_KIT_ADD_CATALOG_ENTRY(scale, SoScale, FALSE, topSeparator, shape, FALSE);
  SO_KIT_INIT_INSTANCE();
}
// Destructor.
ShapeScale::~ShapeScale()
{
}
// Inicializa esta clase. Llama antes de usarla.
void
ShapeScale::initClass(void)
{
  SO_KIT_INIT_CLASS(ShapeScale, SoBaseKit, "BaseKit");
}
static void
update_scale(SoScale * scale, const SbVec3f & v)
{
  // solo escribir en el campo cuando la escala haya cambiado.
  if (scale->scaleFactor.getValue() != v) {
    scale->scaleFactor = v;
  }
}
// Sobrescrito para (re)inicializar la escala antes de renderizar el marcador.
void
ShapeScale::GLRender(SoGLRenderAction * action)
{
  SoState * state = action->getState();
  SoScale * scale = (SoScale*) this->getAnyPart(SbName("scale"), TRUE);
  if (!this->active.getValue()) {
    update_scale(scale, SbVec3f(1.0f, 1.0f, 1.0f));
  }
  else {
    const SbViewportRegion & vp = SoViewportRegionElement::get(state);
    const SbViewVolume & vv = SoViewVolumeElement::get(state);
    SbVec3f center(0.0f, 0.0f, 0.0f);
    float nsize = this->projectedSize.getValue() / float(vp.getViewportSizePixels()[1]);
    SoModelMatrixElement::get(state).multVecMatrix(center, center); // transform to WCS
    float scalefactor = vv.getWorldToScreenScale(center, nsize);
    update_scale(scale, SbVec3f(scalefactor, scalefactor, scalefactor));
  }
  inherited::GLRender(action);
}

// Devuelve un valor aleatorio entre 0.0f y 1.0f.
static float
normalized_rand(void)
{
  return float(rand())/float(RAND_MAX);
}
static SoSeparator *
construct_new_marker(const SbVec3f & v)
{
  SoSeparator * markerroot = new SoSeparator;
  SoTranslation * t = new SoTranslation;
  t->translation = v;
  markerroot->addChild(t);
  ShapeScale * kit = new ShapeScale;
  kit->active = TRUE;
  kit->projectedSize = 5.0f;
  // crear el marcador
  SoSeparator * markersep = new SoSeparator;
  SoBaseColor * mat = new SoBaseColor;
  mat->rgb.setValue(normalized_rand(), normalized_rand(), normalized_rand());
  markersep->addChild(mat);
  // forma del marcador debería ser de tamaño unitario, con centro en (0.0f, 0.0f, 0.0f)
  SoCube * cube = new SoCube;
  cube->width = 1.0f;
  cube->height = 1.0f;
  cube->depth = 1.0f;
  markersep->addChild(cube);
  kit->setPart("shape", markersep);
  markerroot->addChild(kit);
  return markerroot;
}
static void
event_cb(void * ud, SoEventCallback * n)
{
  const SoMouseButtonEvent * mbe = (SoMouseButtonEvent *)n->getEvent();
  if (mbe->getButton() == SoMouseButtonEvent::BUTTON1 &&
    mbe->getState() == SoButtonEvent::DOWN) {
    SoQtExaminerViewer * viewer = (SoQtExaminerViewer *)ud;
    SoRayPickAction rp(viewer->getViewportRegion());
    rp.setPoint(mbe->getPosition());
    rp.apply(viewer->getSceneManager()->getSceneGraph());
    SoPickedPoint * point = rp.getPickedPoint();
    if (point == NULL) {
      (void)fprintf(stderr, "\n** miss! **\n\n");
      return;
    }
    n->setHandled();
    const SoPath * p = rp.getCurPath();
    for (int i = 0; i < p->getLength(); i++) {
      SoNode * n = p->getNodeFromTail(i);
      if (n->isOfType(SoGroup::getClassTypeId())) {
        SoGroup * g = (SoGroup *)n;
        g->addChild(construct_new_marker(point->getPoint()));
        break;
      }
    }
  }
}

    وثائق الباني والمُدمّر

    SoBaseKit::SoBaseKit (void )

    الباني.

    هذه هي الفئة الأصلية العليا لجميع فئات مجموعات العقد (node kit) وعناصر السحب (dragger). هيكل الكتالوج لـ SoBaseKit هو كما يلي:

    CLASS SoBaseKit
-->"this"
-->   "callbackList"

    (راجع SoBaseKit::printDiagram() للحصول على معلومات حول تنسيق الإخراج.)

    معلومات مفصلة عن أجزاء الكتالوج:

    CLASS SoBaseKit
PVT   "this",  SoBaseKit  ---
      "callbackList",  SoNodeKitListPart [ SoCallback, SoEventCallback ]

    (راجع SoBaseKit::printTable() للحصول على معلومات حول تنسيق الإخراج.)

    كما يتضح من الكتالوج، يمكن لجميع مجموعات العقد أن تحتوي على عقدة استدعاء (callback node) أمام جميع العقد الأخرى في المجموعة. وهذا مفيد لالتقاط الأحداث التي يجب أن تذهب إلى معالجة التطبيق.

    SbBool SoBaseKit::setPart (const int partnum, SoNode * node) [protected], [virtual]

    تعيين الأجزاء، وتحديث الرسم البياني لعقد المجموعة، والتأكد من أن الرسم البياني صالح فيما يتعلق بالأشقاء اليمنى والأب. هذه الدالة افتراضية للسماح للمشتقات باكتشاف متى تتغير قيمة في جزء.

    هذه الدالة ليست جزءًا من واجهة برمجة التطبيقات الأصلية لـ SGI Open Inventor، ولكنها امتداد خاص بـ Coin.

    تمت إعادة تطبيقها في SoInteractionKit.

    توثيق دوال الأعضاء

    SoBaseKit::setDefaultOnNonWritingFields

    هذه دالة افتراضية، ويجب أن يستدعي الكود فيها SoField::setDefault() مع الوسيط TRUE للحقول التي لا ينبغي كتابتها أثناء تصدير الرسم البياني للمشهد.

    يتم ذلك عادةً عندما:

    1.
    قيمة الحقل هي NULL والحقل هو NULL افتراضيًا
    2.
    إنه عقد من النوع SoGroup أو SoSeparator بدون أطفال
    3.
    إنه جزء قائمة من النوع SoGroup أو SoSeparator بدون أطفال ومع حاوية من SoGroup أو SoSeparator
    4.
    إنه جزء غير طرفي وهو من النوع SoGroup، وجميع الحقول في قيمها الافتراضية

    يجب على الفئات الفرعية عمومًا تجاوز هذه الدالة لإجراء تعديلات إضافية لحقول الأعضاء الجديدة. يجب أن تتذكر من الفئة الفرعية استدعاء setDefaultOnNonWritingFields() الخاصة بالوالد.

    تمت إعادة تطبيقها في SoCenterballDragger، SoDirectionalLightDragger، SoDragger، SoDragPointDragger، SoHandleBoxDragger، SoInteractionKit، SoJackDragger، SoPointLightDragger، SoSeparatorKit، SoShapeKit، SoSpotLightDragger، SoTabBoxDragger، SoTabPlaneDragger، SoTrackballDragger، SoTransformBoxDragger، و SoTransformerDragger.
