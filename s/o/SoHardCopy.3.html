الاسم

SoHardCopy - الفئة SoHardCopy هي فئة ثابتة لتهيئة دعم النسخ الصلب.

الملخص

#include <Inventor/annex/HardCopy/SoHardCopy.h>

static void init (void)

وصف تفصيلي

الفئة SoHardCopy هي فئة ثابتة لتهيئة دعم النسخ الصلب.

توثيق دوال الأعضاء

void SoHardCopy::init (void ) [static]

تتم تهيئة دعم النسخ الصلب تلقائيًا من SoDB::init()، لذلك لا ينبغي لمبرمج التطبيق عادةً القلق بشأنها.

const char * SoHardCopy::getProductName (void ) [static]

ترجع اسم امتداد النسخ الصلب.

const char * SoHardCopy::getVersion (void ) [static]

سيتطابق رقم الإصدار دائمًا مع رقم إصدار Coin.
