الوصف التفصيلي

الفئة SoBase هي الفئة العليا لمجموعة من التسلسلات الهرمية للفئات.

توفر SoBase الواجهات والأساليب الأساسية للعد المرجعي، وتحديد النوع، والاستيراد/التصدير. جميع الفئات في Coin التي تستخدم هذه الآليات هي منحدرات من هذه الفئة.

من الأمور الهامة المتعلقة بالفئات المشتقة من SoBase هي أنه لا ينبغي تخصيصها ديناميكيًا، سواء في الذاكرة الثابتة أو في إطارات المكدس للدوال. يجب دائمًا تخصيص الفئات المشتقة من SoBase ديناميكيًا في ذاكرة الكومة باستخدام المعامل new.

هذا ضروري لأن مثيلات SoBase يتم الرجوع إليها وسيتم حذفها في الوقت المناسب. لكي يعمل هذا، يجب تخصيصها صراحة في ذاكرة الكومة. راجع وثائق فئة SoNode لمزيد من المعلومات.

void SoBase::ref (void ) const

يزيد عداد المرجع للكائن. قد يكون هذا ضروريًا صراحةً من كود المستخدم في مواقف معينة (بشكل أساسي لمنع الحذف المبكر)، ولكنه يُستدعى عادةً من مثيلات أخرى داخل مكتبة Coin عندما تعتمد الكائنات على بعضها البعض.

راجع توثيق الفئة SoNode لمزيد من المعلومات حول عد المراجع.

void SoBase::unref (void ) const

يقلل عداد المرجع لكائن. إذا انخفض العداد إلى الصفر، فسيتم حذف الكائن بواسطة نفسه. كن حذرًا عند استدعاء هذه الدالة صراحةً، حيث تحتاج عادةً إلى مطابقة استدعاءات ref() الخاصة بالمستخدم مع استدعاءات unref() أو unrefNoDelete() لتجنب تسرب الذاكرة.

virtual SoType SoBase::getTypeId (void ) const [pure virtual]

تُرجع تعريف النوع لكائن مشتق من فئة ترث SoBase. يُستخدم هذا للتحقق من النوع وقت التشغيل و "الإسقاط" لأسفل. مثال للاستخدام:

void foo(SoNode * node)
{
  if (node->getTypeId() == SoFile::getClassTypeId()) {
    SoFile * filenode = (SoFile *)node;  // إسقاط آمن لأسفل، يعرف النوع
  }
}

SbBool SoBase::isOfType (SoType type) const

تُرجع TRUE إذا كان نوع هذا الكائن هو نفس النوع أو مشتق من type. يُستخدم هذا للتحقق من النوع وقت التشغيل و "الإسقاط" لأسفل.

مثال للاستخدام:

void foo(SoNode * node)
{
  if (node->isOfType(SoGroup::getClassTypeId())) {
    SoGroup * group = (SoGroup *)node;  // إسقاط آمن لأسفل، يعرف النوع
  }
}

SbBool SoBase::writeHeader (SoOutput * out, SbBool isgroup, SbBool isengine) const [protected]

يكتب رأس أي كائن SoBase مشتق. يتكون الرأس من الكلمة المفتاحية DEF واسم الكائن (إذا كان للكائن اسم، وإلا يتم تجاهل هذه)، واسم الفئة وقوس أيسر.

بدلاً من ذلك، قد يتكون تمثيل الكائن فقط من الكلمة المفتاحية USE بالإضافة إلى اسم الكائن، إذا كانت هذه هي الكتابة الثانية أو المرجع اللاحق الذي يتم كتابته في الملف.

إذا تم إكمال الكائن عن طريق كتابة الرأس فقط (وهو ما سيحدث إذا قمنا بكتابة مراجع متعددة لكائن)، فإننا نعيد TRUE، وإلا FALSE.

إذا أعدنا FALSE (أي، هناك المزيد للكتابة)، فإننا نزيد مستوى المسافة البادئة.

virtual SbBool SoBase::readInstance (SoInput * in, unsigned short flags) [protected], [pure virtual]

تم تخصيص هذه الطريقة بشكل أساسي للاستخدام الداخلي أثناء عمليات استيراد الملفات.

يقرأ تعريفًا لمثيل من تدفق الإدخال in. يشير مؤشر تدفق الإدخال إلى بداية تمثيل متسلسل / دائم لمثيل من هذا النوع من الفئة.

يعيد TRUE أو FALSE اعتمادًا على ما إذا كانت عملية إنشاء وتكوين الكائن الجديد من هذه الفئة ناجحة أم لا. يجب أن تكون عملية الاستيراد قوية ويجب أن تتعامل بشكل صحيح مع تدفقات الإدخال التالفة عن طريق إعادة FALSE.

تُستخدم القيمة flags داخليًا أثناء الاستيراد الثنائي عند قراءة عقد امتداد المستخدم، أو عقد المجموعة، أو المحركات.
