الوصف التفصيلي

SoText2 هو نوع عقدة لعرض نص ثنائي الأبعاد محاذي لمستوى الكاميرا.

لا يتم تحجيم نص SoText2 بناءً على المسافة من الكاميرا ولا يتأثر بالدوران أو القياس مثل مبادئ ثلاثية الأبعاد. إذا كانت هذه خصائص ترغب في أن يمتلكها النص، فيجب عليك استخدام عقدة SoText3 أو SoAsciiText بدلاً من ذلك.

ملاحظة: على الرغم من أن حجم النص ثنائي الأبعاد لا يتأثر بالمسافة من الكاميرا، إلا أن النص لا يزال يخضع للقواعد المعتادة فيما يتعلق بصندوق العمق، لذلك سيتم إخفاؤه بواسطة الرسوم التي أمامه.

سيتم وضع النص افتراضيًا وفقًا للتحويل الحالي. موقع x للنص هو البكسل الأول للحرف الأيسر من النص. موقع y للنص هو الخط الأساسي للفقرة الأولى من النص (الخط الأساسي هو الخط الوهمي الذي تقع عليه جميع الأحرف الكبيرة).

يتم تحديد حجم الخطوط على الشاشة وفقًا لحقل SoFont::size لعقدة SoFont المستخدمة سابقًا في المشهد، والتي تحدد الحجم بوحدات البكسل. هذه القيمة تحدد تقريبًا البعد العمودي للأحرف. القيمة الافتراضية إذا لم يتم استخدام عقد SoFont هي 10.

مشكلة أداء عرض مهمة: نظرًا لأن تحديد موضع وعرض عقدة SoText2 يعتمد على منفذ العرض والكاميرا الحالية، فإن وجود عقد SoText2 في المشهد يمكن أن يسبب اعتمادية في التخزين المؤقت على عقد SoCamera التي تم العثور عليها سابقًا. يمكن أن يكون لهذا تأثير كبير على أداء العرض، لأنه إذا كانت الكاميرا فوق أقرب عقدة SoSeparator لعقدة SoText2، فلن يتمكن SoSeparator من تخزين الهندسة تحتها مؤقتًا.

(سيتم فرض أداء عرض أسوأ إذا تم ضبط علامة SoSeparator::renderCaching بشكل صريح على ON، حيث سيقوم عقد SoSeparator باستمرار بإنشاء نفس ذاكرة التخزين المؤقت وتدميرها أثناء تحرك الكاميرا.)

لذلك، يتم تحسين عقد SoText2 بوضعها تحت عقدة SoSeparator الخاصة بها، خارج منطقة

  ]

Derived classes:

  SoAsciiText

Detailed Description

This node generates 2D text geometry. It takes a list of strings and renders them in a 2D plane, originating at the current transformation matrix's translation component. The text is rendered using a bitmap font specified by an associated SoFont node (or the default font).

The text is rendered in the XY plane (positive Z-axis points out of the screen). The origin of the text is at the baseline of the first line of text. The justification field controls how the text is aligned horizontally relative to this origin.

The spacing field controls the vertical distance between lines of text. A value of 1.0 means the spacing is equal to the vertical size of the highest character in the bitmap font. Larger values increase the spacing, and smaller values decrease it.

The string field holds the text to be rendered. Each string in the list is rendered on a separate line.

Note that SoText2 nodes are not intended to be used with nodes that modify geometry like SoBump or SoNormal, as they generate primitive geometry directly. Other geometry nodes such as SoLine or SoSphere can be used in the same scene graph.

Also note that SoText2 nodes cache the ids and positions of each glyph bitmap used to render string. This means that USE of a DEF'ed SoText2 node, with a different font, will be noticeably slower than using two separate SoText2 nodes, one for each font, since it will have to recalculate glyph bitmap ids and positions for each call to GLrender().

SoScale nodes cannot be used to influence the dimensions of the rendering output of SoText2 nodes.

FILE FORMAT/DEFAULTS:

Text2 {
    string ""
    spacing 1
    justification LEFT
}

See also

SoFont, SoFontStyle, SoText3, SoAsciiText

Member Data Documentation

SoMFString SoText2::string

The set of strings to render. Each string in the multiple value field will be rendered on a separate line.

The default value of the field is a single empty string.

SoSFFloat SoText2::spacing

Vertical spacing between the baselines of two consecutive horizontal lines. Default value is 1.0, which means that it is equal to the vertical size of the highest character in the bitmap alphabet.

SoSFEnum SoText2::justification

Determines horizontal alignment of text strings.

If justification is set to SoText2::LEFT, the left edge of the first string is at the origin and all strings are aligned with their left edges. If set to SoText2::RIGHT, the right edge of the first string is at the origin and all strings are aligned with their right edges. Otherwise, if set to SoText2::CENTER, the center of the first string is at the origin and all strings are aligned with their centers. The origin is always located at the baseline of the first line of text.

Default value is SoText2::LEFT.
