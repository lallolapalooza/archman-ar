Detailed Description

This interpolator node interpolates between a list of orientations. The interpolated result is outputted to the value_changed eventOut. The interpolation is done by converting the input orientations to quaternions and then interpolating the orientation using spherical linear interpolation (SLERP).

This node is part of the Coin VRML97 compatibility module.
