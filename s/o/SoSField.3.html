الاسم

SoSField - الفئة SoSField هي الفئة الأساسية للحقول التي تحتوي على قيمة واحدة فقط.

الملخص

#include <Inventor/fields/SoSField.h>

وصف تفصيلي

الفئة SoSField هي الفئة الأساسية للحقول التي تحتوي على قيمة واحدة فقط.

جميع أنواع الحقول التي يجب أن تحتوي دائمًا على قيمة عضو واحد فقط ترث هذه الفئة. SoSField هي فئة مجردة.

يمكنك استخدام الدوال setValue() و getValue() لتخزين أو جلب قيمة الحقول ذات القيمة الواحدة. مثال:

SoSpotLight * lightnode = new SoSpotLight;
lightnode->on.setValue(TRUE); // حقل "on" الخاص بـ SoSpotLight هو
                              // حقل قيمة واحدة من النوع SoSFBool.
...
...
// تغيير مفتاح الإضاءة.
if (lightnode->on.getValue() == FALSE)
  lightnode->on = TRUE; // يمكننا استخدام المعامل = بدلاً من setValue().
else
  lightnode->on = FALSE;
...

عند كتابة العقد أو المحركات أو أنواع أخرى من حاويات الحقول إلى ملف، تتم كتابة حقول القيمة الواحدة الخاصة بها إلى الملف بهذا التنسيق:

containerclass {
  fieldname value
  fieldname value
  ...
}

..مثل هذا، على سبيل المثال، عقدة SpotLight من رسم المشهد سيتم تعيينها افتراضيًا على إيقاف عند قراءتها مرة أخرى من الملف:

SpotLight {
  on FALSE
}
