الفئة SoSFBox3i32 هي حاوية لمتجه SbBox3i32.

يتم استخدام هذا الحقل حيث تحتاج العقد أو المحركات أو حاويات الحقول الأخرى إلى تخزين صندوق.

كن على علم بأن هذه الفئة هي امتداد لـ Coin، وهي غير متوفرة في واجهة برمجة تطبيقات SGI Open Inventor v2.1 الأصلية.

NAME

SoSFBox3i32 - 3D bounding box field with 32-bit integer coordinates

SYNOPSIS

#include <Inventor/fields/SoSFBox3i32.h>

Detailed Description

This class is a single-value field containing a 3D bounding box defined by two 3D integer vectors. The first vector is the minimum corner (bottom-left-back), and the second vector is the maximum corner (top-right-front).
