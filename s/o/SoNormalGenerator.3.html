void SoNormalGenerator::reset (const SbBool ccwarg)

يعيد تعيين مولد المتجهات العادية، مما يسمح بإعادة استخدامه دون الحاجة إلى تخصيص مولد جديد.

هذه الدالة هي امتداد لـ Coin، وليست متاحة في واجهة برمجة تطبيقات SGI Open Inventor v2.1 الأصلية.

void SoNormalGenerator::generate (const float creaseAngle, const int32_t * striplens = NULL, const int numstrips = 0)

يُطلق توليد المتجهات العادية. يتم توليد المتجهات العادية باستخدام creaseAngle للعثور على الحواف التي يجب أن تكون متدرجة والتي يجب أن تكون ناعمة التدرج.

إذا تم توليد متجهات عادية لمثلثات الشريط، فيجب تحديد striplens و numstrips. انظر src/nodes/SoTriangleStripSet.cpp (generateDefaultNormals()) كمثال لكيفية إرسال معلومات الشريط إلى هذا المولد. هذا ليس بسيطًا، حيث يجب أن تعرف كيف يقوم OpenGL/Coin بإنشاء المثلثات من الأشرطة.

void SoNormalGenerator::generatePerStrip (const int32_t * striplens, const int numstrips)

يولد متجهًا عاديًا لكل شريط عن طريق حساب متوسط المتجهات العادية للوجه.

void SoNormalGenerator::generatePerFace (void )

يولد المتجهات العادية لكل وجه. استخدم هذا عندما تحتاج إلى ربط المتجهات العادية بالوجه. هذه الدالة ليست جزءًا من واجهة برمجة تطبيقات OIV.

void SoNormalGenerator::generateOverall (void )

يولد متجهًا عاديًا عامًا عن طريق حساب متوسط جميع المتجهات العادية للوجه. استخدم هذا عندما يكون ربط المتجهات العادية عامًا. هذه الدالة ليست جزءًا من واجهة برمجة تطبيقات OIV.
