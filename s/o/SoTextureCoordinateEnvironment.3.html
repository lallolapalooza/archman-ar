وصف مفصل

تولد فئة SoTextureCoordinateEnvironment إحداثيات النسيج عن طريق الإسقاط على نسيج محيط.

سيتم تعيين النسيج الذي يحدد البيئة حول الرسم البياني للمشهد أسفل هذه العقدة باستخدام كرة. سيتم تعيين النسيج على الرسم البياني للمشهد مع مراعاة موضع الكاميرا. سيؤدي هذا إلى انعكاس الكائن لبيئته.

إليك مثال على الرسم البياني للمشهد يوضح كيفية تطبيق رسم الخرائط البيئية على كائن:

#Inventor V2.1 ascii
Separator {
  Texture2 {
    filename "ocean.jpg" # the environment, in this case ocean
  }
  TextureCoordinateEnvironment {}
  Cube {} # the environmentally mapped object
}

صيغة الملف / القيم الافتراضية:

TextureCoordinateEnvironment {
}
