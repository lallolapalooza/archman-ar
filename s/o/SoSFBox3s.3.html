يستخدم هذا الحقل عندما تحتاج العقد أو المحركات أو حاويات الحقول الأخرى لتخزين صندوق.

NAME

SoSFBox3s — Field container for a 3D box with short coordinates.

SYNOPSIS

  SoSFBox3s ()
  SoSFBox3s (short xmin, short ymin, short zmin, short xmax, short ymax, short zmax)
  SoSFBox3s (const SbBox3s & box)
  void initClass (void ) [static]
  void setValue (short xmin, short ymin, short zmin, short xmax, short   ymax, short zmax)
  void setValue (const SbVec3s & minvec, const SbVec3s   & maxvec)
  void getValue (SbBox3s & box) const
  int operator== (const SoSFBox3s & ab) const
  int operator!= (const SoSFBox3s & ab) const

Description

This field contains a 3D box, defined by two 3D vectors with short coordinates, representing the minimum and maximum corner points. The coordinates are stored as shorts (16-bit signed integers).

A box is considered empty if its minimum corner is greater than its maximum corner in any dimension. Use the getValue() method to retrieve the box's contents.

The coordinates are clamped to the range of short integers.

Inherits from SoSFBox3f.
