وصف تفصيلي

La clase SoVRMLColorInterpolator se utiliza para interpolar valores de color.

La documentación detallada de la clase se toma verbatim de la estándar VRML97 (ISO/IEC 14772-1:1997). Es propiedad del Consortium Web3D y se usa con permiso del mismo:

ColorInterpolator {
  eventIn      SFFloat set_fraction        # (-inf, inf)
  exposedField MFFloat key           []    # (-inf, inf)
  exposedField MFColor keyValue      []    # [0,1]
  eventOut     SFColor value_changed
}

Este nodo interpola entre un conjunto de valores de MFColor clave para producir un evento SFColor (RGB) value_changed. El número de colores en el campo keyValue debe ser igual al número de keyframes en el campo key. Los campos keyValue y value_changed están definidos en el espacio de color RGB. Se realiza una interpolación lineal utilizando el valor de set_fraction como entrada en el espacio de color HSV (ver http://www.web3d.org/documents/specifications/14772/V2.0/part1/bibliography.html#[FOLE para descripción del espacio de color RGB y HSV). Los resultados son indefinidos cuando se interpola entre dos clave consecutivas con colores complementarios.

4.6.8, Nodos de interpolación (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.8), contiene una discusión detallada sobre los interpoladores.
