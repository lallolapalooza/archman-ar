الوصف التفصيلي

الفئة SoState تدير بيانات حالة اجتياز الرسم البياني للمشهد في Coin.

تستخدم الفئة SoState من قبل الإجراءات المشتقة من الفئة SoAction. إنها تدير حالة الرسم البياني للمشهد كأكوام من العناصر (أي، مثيلات للفئات المشتقة من SoElement).

لمزيد من المعلومات حول العمليات الداخلية لحالات الاجتياز في Coin، نوصي بكتاب The Inventor Toolmaker (ISBN 0-201-62493-1)، المتوفر أيضًا في مكتبة SGI عبر الإنترنت. ابحث عن "Toolmaker".

توثيق المُنشئ والمدمر

SoState::SoState (SoAction * theAction, const SoTypeList & enabledelements)

المُنشئ. الوسيط theAction هو كائن الإجراء الذي تنتمي إليه الحالة، والوسيط enabledElements هو SoTypeList للعناصر التي تم تمكينها لهذا الإجراء.

يقوم المُنشئ بدفع عنصر افتراضي إلى مؤشرات جميع أكوام العناصر الممكّنة. لا يتم استدعاء SoElement::push() على العناصر الأولية في أكوام SoState، ولكن يتم استدعاء SoElement::init().

SoState::~SoState (void )

المدمر.

لاحظ أنه عند حدوث التدمير، لن يتم تنفيذ الأحداث المتأخرة الناتجة عن التقييم الكسول.

توثيق الدوال الأعضاء

SoAction * SoState::getAction (void ) const

تعيد هذه الدالة مؤشرًا إلى مثيل الإجراء الذي تم تمريره إلى المُنشئ.

SoElement * SoState::getElement (const int stackindex)

تعيد هذه الدالة مثيلًا قابلًا للتعديل للعنصر الموجود في قمة الكومة ذات stackindex المحدد. نظرًا للبرمجة الكسولة، قد تحتاج هذه الدالة إلى القيام ببعض العمل، لذلك يجب استخدام SoState::getConstElement() بدلاً من ذلك كلما أمكن.

const SoElement * SoState::getConstElement (const int stackIndex) const [inline]

تعيد هذه الدالة مؤشرًا إلى العنصر العلوي في كومة العناصر المحددة. العنصر للقراءة فقط ويجب عدم تغييره تحت أي ظرف من الظروف وإلا ستحدث آثار جانبية غريبة.

لاحظ أن هذه الدالة ستؤكد إذا لم يكن العنصر ذو قيمة هوية الكومة المحددة موجودًا حاليًا في كومة الحالة. للتحقق مما إذا كان العنصر موجودًا في الكومة أم لا، استخدم SoState::isElementEnabled().

void SoState::push (void )

تدفع هذه الدالة الحالة مستوى واحدًا إلى الأسفل. هذا يحفظ الحالة بحيث يمكن تغييرها واستعادتها لاحقًا إلى هذه الحالة عن طريق استدعاء SoState::pop().

يتم تنفيذ آلية الدفع والسحب بشكل كسول لأسباب تتعلق بالكفاءة (تجنب الكثير من تخصيص الذاكرة والنسخ). فقط عندما يكون عنصر الحالة على وشك التغيير فعليًا، سيتم دفع هذا العنصر فعليًا.

void SoState::pop (void )

تقوم هذه الدالة بسحب الحالة لاستعادتها إلى حالة سابقة. يتم تنفيذ عمليات السحب بشكل استباقي ولكن الكود ضيق جدًا لذلك لا داعي للقلق بشأن الكفاءة.

void SoState::print (FILE *const file = stdout) const

هذه الدالة لأغراض التصحيح فقط.

SbBool SoState::isElementEnabled (const int stackindex) const [inline]

تعيد هذه الدالة TRUE إذا كان العنصر ذو فهرس كومة العنصر المحدد ممكّنًا، و FALSE بخلاف ذلك.

int SoState::getDepth (void ) const

تعيد هذه الدالة العمق الحالي لكومة الحالة.

العمق "افتراضي"، وليس بالضرورة فيزيائي.

void SoState::setCacheOpen (const SbBool open)

تتحكم فيما إذا كانت ذاكرة التخزين المؤقت مفتوحة.

SbBool SoState::isCacheOpen (void ) const [inline]

تُعيد ما إذا كانت ذاكرة التخزين المؤقت مفتوحة.
