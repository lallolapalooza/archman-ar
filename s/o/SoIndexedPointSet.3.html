NAME

SoIndexedPointSet - Indexed point set geometry node

SYNOPSIS

Inherits from SoPointSet.

Instantiating a derived class of SoBaseObject (including SoIndexedPointSet) is not allowed.

#include <Inventor/nodes/SoIndexedPointSet.h>

SoIndexedPointSet {
};

Inherited classes:
SoPointSet
SoShape
SoNode
SoBase

Detailed Description

This node defines a point set shape. The coordinates of the points are given by the inherited point field. The indices of the points to be drawn are given by the inherited startIndex field (if present).
