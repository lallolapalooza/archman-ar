NAME

SoSFVec3s — Single-value field containing a 3-component vector of short integers

SYNOPSIS

  public:

  protected:
    // ... inheritance ...
  private:
    // ... data ...
    static void initClass(void);
};

Detailed Description

This field type is used for storing three-component vectors where each component is a short integer. That is, its value is (x, y, z).

SoSFVec3s is a Single-value field, meaning it can only contain one value.
