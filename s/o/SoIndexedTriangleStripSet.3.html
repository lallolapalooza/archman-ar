وصف تفصيلي

تحتفظ الفئة SoIndexedTriangleStripSet ببيانات لرسم وتمثيل شرائط المثلثات بطريقة فعالة.

استخدم العقد من هذا النوع كطريقة فعالة لرسم المثلثات المتصلة معًا.

لمزيد من المعلومات، انظر توثيق عقدة SoTriangleStripSet.

لرسم عدة شرائط داخل نفس العقدة، افصل فهارس الإحداثيات بـ -1. لمزيد من المعلومات حول الأشكال المفهرسة، انظر التوثيق في SoIndexedShape و SoIndexedFaceSet.

مثال على الرسم البياني للمشهد:

#Inventor V2.1 ascii
Separator {
   Coordinate3 {
      point [
       -2 1 0, -1 -1 0, 0 1 0, 1 -1 0, 2 1 0, # first strip, z==0
       -2 1 5, -1 -1 5, 0 1 5, 1 -1 5, 2 1 5  # second strip, z==5
      ]
   }
   IndexedTriangleStripSet {
      coordIndex [
       0, 1, 2, 3, 4, -1,
       5, 6, 7, 8, 9, -1
      ]
   }
}

تنسيق الملف/الافتراضيات:

IndexedTriangleStripSet {
    vertexProperty NULL
    coordIndex 0
    materialIndex -1
    normalIndex -1
    textureCoordIndex -1
}
