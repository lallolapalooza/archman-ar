وصف تفصيلي

يحافظ SoOverrideElement على قائمة بالعناصر القابلة للتجاوز وقائمة بالعناصر التي يجب تجاوزها.

يمكن تجاوز عناصر معينة فقط.

توثيق الفئة المتبقي يصف حالة واحدة خاصة:

طلب شائع للوظائف هو تجاوز شفافية الرسم البياني الكامل للمشهد، أو أجزاء من الرسم البياني للمشهد.

في SGI Inventor الأصلي، هذا يكاد يكون مستحيلاً، حيث تم تصميم واجهة برمجة التطبيقات (API) لجعل تجاوز جميع الحقول أو لا شيء منها في عقدة ممكنًا فقط. لذا فإن استدعاء SoNode::setOverride() على عقدة SoMaterial سيؤدي إلى تجاوز جميع إعدادات المواد لتلك العقدة لجميع إعدادات المواد التي تأتي بعد ذلك في الرسم البياني للمشهد، ولا توجد طريقة لتجاوز إعدادات الشفافية فقط.

في Coin، أضفنا خدعة صغيرة للتغلب على هذه المشكلة، نظرًا لأنها طلب شائع جدًا للوظائف: للحصول على إعدادات تجاوز شفافية منفصلة، قم بتعيين متغير البيئة COIN_SEPARATE_DIFFUSE_TRANSPARENCY_OVERRIDE إلى "1" لتمكين هذه الخدعة.

(لاحظ مع ذلك أن هذا لن يعمل عندما يتم استخدام عقدة SoPackedColor أو SoVertexProperty لتحديد اللون المنتشر والشفافية - فقط مع عقدة SoMaterial.)

إليك مثال كامل ومستقل يوضح كيفية تحقيق ذلك:

#include <Inventor/Qt/SoQt.h>
#include <Inventor/Qt/viewers/SoQtExaminerViewer.h>
#include <Inventor/nodes/SoSeparator.h>
#include <Inventor/nodes/SoMaterial.h>
// *************************************************************************
const char * scene = "#Inventor V2.1 asci\n"
"Separator { Cone { } Translation { translation 1 0 5 } DEF OVERRIDEMATERIAL Material { transparency 0.5 } DEF OBJMATERIAL Material { diffuseColor 0.5 0 0 transparency 0 } Sphere { } }"
;
int
main(int argc, char ** argv)
{
  QWidget * window = SoQt::init(argv[0]);
  (void)coin_setenv("COIN_SEPARATE_DIFFUSE_TRANSPARENCY_OVERRIDE", "1", TRUE);
  SoInput * in = new SoInput;
  in->setBuffer(scene, strlen(scene));
  SoSeparator * root = SoDB::readAll(in);
  assert(root);
  delete in;
  root->ref();
  SoMaterial * overridemat = (SoMaterial *)
    SoBase::getNamedBase("OVERRIDEMATERIAL", SoMaterial::getClassTypeId());
  assert(overridemat);
  overridemat->diffuseColor.setIgnored(TRUE);
  overridemat->setOverride(TRUE);
  SoQtExaminerViewer * viewer = new SoQtExaminerViewer(window);
  viewer->setSceneGraph(root);
  viewer->show();
  SoQt::show(window);
  SoQt::mainLoop();
  delete viewer;
  root->unref();
  return 0;
}

الوصف التفصيلي

فئة عناصر التجاوز.

تُستخدم عناصر التجاوز للسماح للعقد بتجاوز بعض سمات العرض التي يتم تعيينها في أجزاء سابقة من الشجرة. على سبيل المثال، إذا تم تعيين لون للمشهد، ولكن بعد ذلك يتم العثور على عقدة SoMaterial، فسيتم استخدام اللون المحدد في عقدة SoMaterial. ومع ذلك، إذا تم تعيين خاصية setMaterialOverride() مع قيمة true، فسيكون هذا التجاوز هو الأولوية.

فيما يلي قائمة بالطرق التي توفرها هذه الفئة:

setAmbientColorOverride()
يمكن استخدامها لتعيين تجاوز اللون المحيط.
setDiffuseColorOverride()
يمكن استخدامها لتعيين تجاوز اللون المنتشر.
setEmissiveColorOverride()
يمكن استخدامها لتعيين تجاوز اللون الباعث.
setFontNameOverride()
يمكن استخدامها لتعيين تجاوز اسم الخط.
setFontSizeOverride()
يمكن استخدامها لتعيين تجاوز حجم الخط.
setLightModelOverride()
يمكن استخدامها لتعيين تجاوز نموذج الإضاءة.
setLinePatternOverride()
يمكن استخدامها لتعيين تجاوز نمط الخط.
setLineWidthOverride()
يمكن استخدامها لتعيين تجاوز عرض الخط.
setPickStyleOverride()
يمكن استخدامها لتعيين تجاوز نمط الالتقاط.
setPointSizeOverride()
يمكن استخدامها لتعيين تجاوز حجم النقطة.
setPolygonOffsetOverride()
يمكن استخدامها لتعيين تجاوز إزاحة المضلع.
setShapeHintsOverride()
يمكن استخدامها لتعيين تجاوز تلميحات الشكل.
setShininessOverride()
يمكن استخدامها لتعيين تجاوز اللمعان.
setSpecularColorOverride()
يمكن استخدامها لتعيين تجاوز اللون الانعكاسي.
setTransparencyOverride()
يمكن استخدامها لتعيين تجاوز الشفافية.
setTransparencyTypeOverride()
يمكن استخدامها لتعيين تجاوز نوع الشفافية.
setNormalVectorOverride()
يمكن استخدامها لتعيين تجاوز متجه العادي.
setNormalBindingOverride()
يمكن استخدامها لتعيين تجاوز ربط العادي.
