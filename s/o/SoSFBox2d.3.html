SoSFBox2d

Description

This class is derived from SoField and implements a single field containing a 2D box.

The box is defined by two 2D vectors: the minimum corner and the maximum corner. These vectors must be ordered such that `minvec[0] <= maxvec[0]` and `minvec[1] <= maxvec[1]`.

The SoSFBox2d class provides methods to set and get the box value, either by passing an SbBox2d object or by passing the four coordinate values directly.

It also implements the necessary virtual methods from the base class SoField, such as copyField, defaultValue, and getType.
