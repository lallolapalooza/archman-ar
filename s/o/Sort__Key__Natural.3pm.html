Sort__Key__Natural(3pm)

الحزمة: perl-sort-key

التراخيص: GPL, PerlArtistic

Sort::Key::Natural(3) وثائق مساهمة من Perl Sort::Key::Natural(3)

الاسم

Sort::Key::Natural - ترتيب طبيعي سريع

ملخص

use Sort::Key::Natural qw(natsort);
my @data = qw(foo1 foo23 foo6 bar12 bar1
              foo bar2 bar-45 foomatic b-a-r-45);
my @sorted = natsort @data;
print "@sorted\n";
# يطبع:
#   b-a-r-45 bar1 bar2 bar12 bar-45 foo foo1 foo6 foo23 foomatic
use Sort::Key::Natural qw(natkeysort);
my @objects = (...);
my @sorted = natkeysort { $_->get_id } @objects;

الوصف

توسع هذه الوحدة عائلة وحدات Sort::Key لدعم الترتيب الطبيعي.

في الترتيب الطبيعي، يتم تقسيم السلاسل النصية إلى أجزاء عند حدود الكلمات والأرقام، وتتم مقارنة الأجزاء الناتجة على النحو التالي:

  • تتم مقارنة السلاسل الرقمية رقميًا
  • تتم مقارنة السلاسل الأبجدية أبجديًا
  • تأتي السلاسل الرقمية دائمًا قبل السلاسل الأبجدية

تُعتبر المسافات والرموز والأحرف غير القابلة للطباعة فقط لتقسيم السلسلة النصية إلى أجزائها، ولكن ليس للترتيب. على سبيل المثال، "foo-bar-42" تنقسم إلى ثلاثة أجزاء "foo" و "bar" و 42، ثم يتم تجاهل الشرطات.

ملاحظة: الترتيب حساس لحالة الأحرف. لإجراء ترتيب غير حساس لحالة الأحرف، يجب عليك تحويل المفاتيح صراحةً:

my @sorted = natkeysort { lc $_ } @data

بالإضافة إلى ذلك، بمجرد تحميل هذه الوحدة، سيكون نوع "natural" (أو "nat") الجديد متاحًا في Sort::Key::Maker. على سبيل المثال:

use Sort::Key::Natural;
use Sort::Key::Maker i_rnat_keysort => qw(integer -natural);

ينشئ مرتبًا متعدد المفاتيح "i_rnat_keysort" يقبل مفتاحين، الأول تتم مقارنته كرقم صحيح والثاني بترتيب تنازلي.

هناك أيضًا دوال ترتيب طبيعي بديلة تتعرف على الأرقام ذات الفاصلة العائمة. تستخدم نوع المفتاح "natwf" (اختصار لـ "natural_with_floats").

الدوال

الدوال التي يمكن استيرادها من هذه الوحدة هي:

natsort @data
يعيد عناصر @data مرتبة بترتيب طبيعي.
rnatsort @data
يعيد عناصر @data مرتبة بترتيب طبيعي تنازلي.
natkeysort { CALC_KEY($_) } @data
يعيد عناصر @array مرتبة طبيعيًا وفقًا للمفاتيح التي تم الحصول عليها عن طريق تطبيق "CALC_KEY".
rnatkeysort { CALC_KEY($_) } @data
مشابه لـ "natkeysort" ولكنه يرتب العناصر بترتيب تنازلي.
natsort_inplace @data
rnatsort_inplace @data
natkeysort_inplace { CALC_KEY($_) } @data
rnatkeysort_inplace { CALC_KEY($_) } @data
هذه الدوال مشابهة لـ "natsort" و "rnatsort" و "natsortkey" و "rnatsortkey" على التوالي، ولكنها تقوم بترتيب القائمة @data في مكانها بدلاً من إعادة قائمة جديدة.
$key = mkkey_natural $string
بالنظر إلى $string، فإنه يعيد مفتاحًا يمكن مقارنته أبجديًا مع مفتاح آخر تم الحصول عليه بنفس الطريقة، مما يعطي نفس ترتيب مقارنة السلاسل الأصلية بالترتيب الطبيعي.
natwfsort @data
rnatwfsort @data
natwfkeysort { CALC_KEY($_) } @data
rnatwfkeysort { CALC_KEY($_) } @data
natwfsort_inplace @data
rnatwfsort_inplace @data
natwfkeysort_inplace { CALC_KEY($_) } @data
rnatwfkeysort_inplace { CALC_KEY($_) } @data
mkkey_natural_with_floats $key
هذه السلسلة من الدوال مشابهة لنظيرتها s/natwf/nat/ ولكنها تحترم الأرقام ذات الفاصلة العائمة داخل السلاسل.

في هذا السياق، الرقم العائم هو سلسلة نصية تطابق النمط المنتظم "/[+\-]?\d+(\.\d*)?/". ملاحظة: الأرقام بدون جزء صحيح (مثل ".2" أو "-.12") لا يتم التعرف عليها.

لاحظ أيضًا أنه لا يتم دعم الأرقام بدون جزء صحيح (مثل ".2" أو "-.12").

انظر أيضًا

Sort::Key, Sort::Key::Maker.

الوحدات الأخرى التي تقدم وظائف مماثلة تشمل Sort::Naturally.
