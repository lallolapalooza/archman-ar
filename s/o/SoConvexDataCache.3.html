الوصف التفصيلي

فئة SoConvexDataCache تُستخدم لتخزين المضلعات المحدبة مؤقتًا.

تُستخدم SoConvexDataCache لتسريع عرض المضلعات المقعرة عن طريق تقسيم جميع المضلعات إلى مثلثات وتخزين الأشكال الهندسية الجديدة التي تم إنشاؤها في ذاكرة تخزين مؤقت داخلية.

هذه الفئة ليست جزءًا من واجهة برمجة تطبيقات SGI Open Inventor v2.1 الأصلية، ولكنها امتداد لـ Coin.

Detailed Description

Returns the indices of the texture coordinates. The texture coordinates are stored in a different list than the vertices. These indices are used to map the texture coordinates to the vertices. The indices are in the same order as the vertices. If there are no texture coordinates, the list will be empty.
