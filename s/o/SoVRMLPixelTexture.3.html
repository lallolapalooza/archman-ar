وصف تفصيلي

يتم استخدام الفئة SoVRMLPixelTexture لتعيين صورة نصية على الهندسة.

يتم أخذ الوصف التفصيلي للفئة حرفيًا من معيار VRML97 (ISO / IEC 14772-1: 1997). إنها مملوكة لـ Web3D Consortium ويتم استخدامها بإذن من المجلس:

PixelTexture {
  exposedField SFImage  image      0 0 0    # انظر SoSFImage
  field        SFBool   repeatS    TRUE
  field        SFBool   repeatT    TRUE
}

يعرّف العقدة PixelTexture خريطة نسيج تعتمد على صورة ثنائية الأبعاد (مصفوفة قيم بكسل) (حقل الصورة) ومعلمات تتحكم في تكرار النسيج على الهندسة. يتم تحديد خرائط النسيج في نظام إحداثيات ثنائي الأبعاد (s، t) يتراوح من 0.0 إلى 1.0 في كلا الاتجاهين. الحافة السفلية لصورة البكسل تتوافق مع المحور s لخريطة النسيج، والحافة اليسرى لصورة البكسل تتوافق مع المحور t لخريطة النسيج. يتوافق بكسل أسفل اليسار في الصورة مع s=0.0، t=0.0، ويتوافق البكسل العلوي الأيمن في الصورة مع s=1.0، t=1.0. ارجع إلى 4.6.11، خرائط النسيج (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.6.11)، للحصول على نظرة عامة على خرائط النسيج. يوضح الشكل 6.13 مثالًا لعقدة PixelTexture.


الشكل 6.13 - عقدة PixelTexture

ارجع إلى 4.14، نموذج الإضاءة (http://www.web3d.org/documents/specifications/14772/V2.0/part1/concepts.html#4.14)، لوصف كيفية تفاعل قيم النسيج مع مظهر الهندسة. يصف SoSFImage مواصفات الصورة. تحدد الحقول repeatS و repeatT كيفية تكرار النسيج في اتجاهي s و t. إذا كان repeatS صحيحًا (افتراضيًا)، يتم تكرار النسيج خارج نطاق إحداثيات النسيج من 0.0 إلى 1.0 في اتجاه s، لملء الشكل. إذا كان repeatS خاطئًا، يتم قص إحداثيات النسيج في اتجاه s لتكون ضمن النطاق من 0.0 إلى 1.0. الحقل repeatT مشابه للحقل repeatS.

Detailed Description

Pixel texture node.

This node defines a texture by providing raw pixel data. The pixel data can be given in either RGB, RGBA, Intensity, Luminance, or Luminance Alpha formats. The dimensions of the texture are also specified.

The node is an implementation of the VRML 97 <PixelTexture> node.
