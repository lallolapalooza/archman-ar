NAME

SoMFBitMask - multi-field bitmask field

SYNOPSIS

API 

#include <Inventor/fields/SoMFBitMask.h>

Detailed Description

The SoMFBitMask class is a container for a set of bitmasks.

This field is used where nodes, engines or other field containers need to store multiple bitmasks with values from an enumerated set.
