NAME

SoScXMLSeekTarget — A seek target for ScXML.

SYNOPSIS

#include <Inventor/scxml/SoScXMLSeekTarget.h>

Inherits from SoScXMLTarget.

Detailed Description

A seek target for ScXML. This is an abstract base class. You will need to subclass it and implement the processEvent() method.

The ScXML engine will call processEvent() when it is asked to seek to this target. The default implementation in the base class does nothing.

Member Function Documentation

SoScXMLSeekTarget::processEvent ()

Processes one event. The base class implementation does nothing.

Reimplemented from ScXMLEventTarget.
