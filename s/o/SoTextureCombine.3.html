الوصف المفصل

La clase SoTextureCombine es un nodo para establecer funciones de combinación de texturas.

Este nodo es más o menos una exacta representación de la extensión OpenGL ARB_texture_env_combine (incluida en OpenGL en OpenGL v1.3). Ver http://oss.sgi.com/projects/ogl-sample/registry/ARB/texture_env_combine.txt para más información sobre esta extensión.

Basicamente, este nodo permite especificar hasta tres fuentes y una función para combinar esas fuentes. Además, es posible aplicar operadores simples a las fuentes. En la documentación a continuación, las fuentes se llamarán Arg0, Arg1 y Arg2, como en la especificación ARB_texture_env_mode.

Es posible especificar tanto una operación de color como de alpha.

Este nodo tiene muchos campos, pero suelen ser suficientes establecer solo uno o muy pocos. El seleccionado operador decide qué valores necesitas establecer. Un ejemplo común es añadir una luz de mapa a la geometría texturada. Una luz de mapa puede verse así:

  TextureUnit {
    unit 1
  }
  TextureCombine {
    rgbOperation ADD_SIGNED
    rgbSource [PREVIOUS, TEXTURE]

    alphaOperation REPLACE
    alphaSource [TEXTURE]
    alphaOperand [SRC_ALPHA]
  }
  Texture2 { filename "lightmap.jpg" }
  TextureUnit { unit 0 }

Detailed Description

This node allows the application programmer to control the texture combiner functionality of OpenGL.

The texture combiner extension provides a way to combine textures in complex ways. It's a successor to the old texture environment.

The new texture combiner functionality is defined by three stages, each defined by a rgbSource, rgbOperand, rgbOperation, and a rgbScale field.

The alpha channel is combined using a second set of fields, alphaSource, alphaOperand, alphaOperation, and alphaScale.

The three stages use the same textures, constant color, and previous stage's result as input. The result of stage i is the input to stage i+1.

The specific settings for the texture combiner extension are set by the SoTextureCombine node. It can be inserted into the scene graph anywhere.

The node supports up to three texture units. If less than three are set, the node will use the default values.

The following table lists the arguments that can be assigned to the rgbSource and alphaSource fields:

NONE
Disables the stage.
COLOR
Use the current fragment's color as source.
TEXTURE
Choose texture as source.
CONSTANT
Choose the constantColor field as source.
PREVIOUS
Choose the previous unit's texture as source.

The following table lists the arguments that can be assigned to the rgbOperand and alphaOperand fields:

SRC_COLOR
Use the source color as operand.
ONE_MINUS_SRC_COLOR
Use one minus source color as operand.
SRC_ALPHA
Use the source alpha as operand.
ONE_MINUS_SRC_ALPHA
Use one minus source alpha as operand.

The following table lists the arguments that can be assigned to the rgbOperation and alphaOperation fields:

REPLACE
dst = Arg0
MODULATE
dst = Arg0 * Arg1
ADD
dst = Arg0 + Arg1
ADD_SIGNED
dst = Arg0 + Arg1 - 0.5
SUBTRACT
dst = Arg0 - Arg1
INTERPOLATE
dst = Arg0 * (Arg2) + Arg1 * (1-Arg2)
DOT3_RGB
Dot product of Arg0 and Arg1
DOT3_RGBA
Dot product (including alpha) of Arg0 and Arg1

SoTextureCombine::rgbOperand

The color operands. This field is empty by default, but you can insert up to three values. When the field contains less than three values, the default [SRC_COLOR, SRC_COLOR, SRC_COLOR] will be used for missing values.

SoTextureCombine::alphaOperand

The alpha operands. This field is empty by default, but you can insert up to three values. When the field contains less than three values, the default [SRC_ALPHA, SRC_ALPHA, SRC_ALPHA] will be used for missing values. Please not that only SRC_ALPHA and ONE_MINUS_SRC_ALPHA are valid operands for alpha operations.

SoTextureCombine::rgbOperation

The color operation. Default value is MODULATE.

SoTextureCombine::alphaOperation

The alpha operation. Default value is MODULATE.

SoTextureCombine::rgbScale

Scale color result by this value. Supported values are 1, 2, and 4.

SoTextureCombine::alphaScale

Scale alpha result by this value. Supported values are 1, 2, and 4.

SoTextureCombine::constantColor

The constant color (when CONSTANT is used as source). Default value is (1,1,1,1).
