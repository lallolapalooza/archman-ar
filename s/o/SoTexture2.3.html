تُستخدم الفئة SoTexture2 لتعيين نسيج ثنائي الأبعاد (2D) إلى الهندسة اللاحقة في شجرة المشهد.

ستُطبق الأنسجة على عقد الأشكال ضمن نطاق عقد SoTexture2 (أي، أسفل SoSeparator نفسه وعلى يمين SoTexture2) وفقًا للميزات الفردية لكل نوع شكل. راجع وثائق أنواع الأشكال المختلفة (SoFaceSet، SoCube، SoSphere، إلخ) للحصول على معلومات حول كيفية تطبيق النسيج.

يمكن العثور على مثال بسيط للاستخدام في وثائق فئة SoSFImage.

خطأ شائع في العديد من البرامج التي تدعم تصدير ملفات VRML أو Inventor هو تصدير نفس ملف النسيج عدة مرات، حتى لو تم تعيين عقد مختلفة له. يمكن أن يؤدي هذا إلى استخدام مفرط لذاكرة النسيج وأداء بطيء. فيما يلي مثال على رمز يقوم بتصحيح هذه المشكلة عن طريق استبدال جميع مثيلات النسيج نفسه بمؤشر إلى العقدة الأولى:

#include <Inventor/actions/SoSearchAction.h>
#include <Inventor/actions/SoWriteAction.h>;
#include <Inventor/nodes/SoSeparator.h>;
#include <Inventor/nodes/SoTexture2.h>;
#include <Inventor/SoDB.h>;
#include <Inventor/SoInput.h>;
#include <Inventor/SoOutput.h>;
int main(int argc, char ** argv)
{
  if (argc < 2) return -1;
  SoDB::init();
  SoInput in;
  if (!in.openFile(argv[1])) return -1;
  SoSeparator * root = SoDB::readAll(&in);
  if (!root) return -1;
  root->ref();
  SoSearchAction sa;
  sa.setType(SoTexture2::getClassTypeId());
  sa.setInterest(SoSearchAction::ALL);
  sa.setSearchingAll(TRUE);
  sa.apply(root);
  SoPathList & pl = sa.getPaths();
  SbDict namedict;
  for (int i = 0; i < pl.getLength(); i++) {
    SoFullPath * p = (SoFullPath*) pl[i];
    if (p->getTail()->isOfType(SoTexture2::getClassTypeId())) {
      SoTexture2 * tex = (SoTexture2*) p->getTail();
      if (tex->filename.getValue().getLength()) {
        SbName name = tex->filename.getValue().getString();
        unsigned long key = (unsigned long) ((void*) name.getString());
        void * tmp;
        if (!namedict.find(key, tmp)) {
          // نسيج جديد. قم بإدراجه في القائمة فقط
          (void) namedict.enter(key, tex);
        }
        else if (tmp != (void*) tex) { // استبدال بالعقدة الموجودة في القائمة
          SoGroup * parent = (SoGroup*) p->getNodeFromTail(1);
          int idx = p->getIndexFromTail(0);
          parent->replaceChild(idx, (SoNode*) tmp);
        }
      }
    }
  }
  sa.reset();
  // إخراج المشهد مع ضبط الأنسجة إلى stdout
  SoOutput out;
  SoWriteAction wa(&out);
  wa.apply(root);
  root->unref();
}

عند العمل مع ملفات Inventor، غالبًا ما يرغب المرء في تضمين ملفات النسيج الخارجية في ملفات Inventor نفسها. فيما يلي مثال بسيط ومستقل يوضح كيف يمكن تحقيق ذلك عن طريق استدعاء SoField::touch() على حقول SoTexture2::image قبل تصدير شجرة المشهد:

#include <Inventor/SoDB.h>;
#include <Inventor/nodes/SoSeparator.h>;
#include <Inventor/nodes/SoTexture2.h>;
#include <Inventor/actions/SoSearchAction.h>;
#include <Inventor/actions/SoWriteAction.h>;
int
main(void)
{
  if (argc == 1) {
    fprintf(stderr,"الاستخدام: %s <infile> > outfile.iv\n", argv[0]);
    return -1;
  }
  SoDB::init();
  // افتح الملف (لا تستخدم stdin) حتى يتمكن Coin من البحث عن الأنسجة المتعلقة بالملف المدخل.
  SoInput in;
  if (!in.openFile(argv[1])) {
    return -1;
  }
  SoSeparator * root = SoDB::readAll(&in);
  if (!root) { exit(1); }
  root->ref();
  SoSearchAction searchaction;
  searchaction.setType(SoTexture2::getClassTypeId());
  searchaction.setSearchingAll(TRUE);
  searchaction.setInterest(SoSearchAction::ALL);
  searchaction.apply(root);
  const SoPathList & pl = searchaction.getPaths();
  for (int i=0; i < pl.getLength(); i++) {
    SoFullPath * fp = (SoFullPath *)pl[i];
    SoTexture2 * tex = (SoTexture2 *)fp->getTail();
    assert(tex->getTypeId() == SoTexture2::getClassTypeId());
    tex->image.touch();
  }
  SoWriteAction wa;
  wa.apply(root);
  root->unref();
  return 0;
}

$ ./test < input.iv

بنية الملف/الافتراضيات:

Texture2 {
    filename ""
    image 0 0 0
    wrapS REPEAT
    wrapT REPEAT
    model MODULATE
    blendColor 0 0 0
    enableCompressedTexture FALSE
}
DECAL
صورة النسيج تستبدل تظليل المضلعات. لا يتم تغطية وحدات البكسل ذات النسيج بتظليل Phong. لها سلوك غير محدد للنسيج الرمادي والرمادي-ألفا.
BLEND
يُستخدم هذا النموذج عادةً مع الأنسجة أحادية اللون (أي، الأنسجة ذات مكون واحد أو اثنين). يُستخدم المكون الأول، الكثافة، للمزج بين لون تظليل المضلع وSoTexture2::blendColor.
REPLACE
صورة النسيج تستبدل تظليل المضلعات. لا يتم تغطية وحدات البكسل ذات النسيج بتظليل Phong. يدعم النسيج الرمادي والرمادي-ألفا. تتطلب هذه الميزة OpenGL 1.1. سيتم استخدام MODULATE إذا تم اكتشاف إصدار OpenGL أقل من 1.1.

ملاحظة: سيؤدي استخدام نموذج النسيج هذا إلى جعل ملفات Inventor الخاصة بك غير متوافقة مع الإصدارات القديمة من Coin وInventor. تحتاج إلى Coin >= 2.2 أو TGS Inventor 4.0 لتحميل ملفات Inventor التي تستخدم نموذج النسيج REPLACE.

NAME

SoTexture2 - 2D texture node

SYNOPSIS

#include <Inventor/nodes/SoTexture2.h>
                    
SoTexture2 {
    SoSFEnum  wrapT     <REPEAT |CLAMP |MIRROR>
    SoSFEnum  model     <REPLACE | MODULATE | DECAL |BLEND | ADD>
    SoSFColor blendColor  <0 0 0>
    SoSFBool  enableCompressedTexture <FALSE>
}

DESCRIPTION

This node defines a 2D texture map. A 2D texture map is an image that can be applied to the surfaces of 3D objects. The image is accessed using texture coordinates, which are associated with the vertices of the primitive objects. The texture map is automatically generated from the specified image file.

The texture coordinates are generated by the SoTextureCoordinate2 node. If no SoTextureCoordinate2 node is present in the scene graph, the texture coordinates will be generated automatically by default.

The SoTexture2 node specifies the texture image, the way the texture wraps around the object, and the texture mapping model.

MEMBER ENUMERATION DOCUMENTATION

SoSFEnum SoTexture2::wrapT

Wrapping strategy for the T coordinate when the texture map is shorter than the object to map onto.

Default value is SoTexture2::REPEAT.

SoSFEnum SoTexture2::model

Texture mapping model for how the texture map is "merged" with the polygon primitives it is applied to. Default value is SoTexture2::MODULATE.

CONSTRUCTOR & DESTRUCTOR DOCUMENTATION

No specific constructor/destructor documentation available.

MEMBER FUNCTION DOCUMENTATION

No specific member function documentation available.

MEMBER DATA DOCUMENTATION

SoSFColor SoTexture2::blendColor

Blend color. Used when SoTexture2::model is SoTexture2::BLEND.

Default color value is [0, 0, 0], black, which means no contribution to the blending is made.

SoSFBool SoTexture2::enableCompressedTexture

Hint to Coin that compressed textures should be used if this is supported by the graphics hardware and OpenGL drivers. Using compressed textures usually reduces texture memory usage for a texture by 4-6 times.
