NAME

SoTextureCombineElement - texture combine parameter element

SYNOPSIS

      #include <Coin/SoTextureCombineElement.h>

SoTextureCombineElement is a subclass of SoElement.

It contains information about the texture combine parameters for OpenGL texture units.

The texture combine extension allows more complex texture blending operations.

It is possible to specify how the RGB and Alpha components of the texture color are combined with the fragment color.

The SoTextureCombineElement can be used to set the combine mode, the source operands, and the operator for both RGB and Alpha channels.

The following combine modes are available:

  • GL_REPLACE
  • GL_MODULATE
  • GL_ADD
  • GL_ALPHA
  • GL_COMBINE

The available source operands are:

  • GL_TEXTURE
  • GL_CURRENT_ALPHA
  • GL_PREVIOUS_ALPHA
  • GL_PRIMARY_COLOR
  • GL_CONSTANT
  • GL_TEXTURE_ALPHA

The available operators are:

  • GL_MODULATE
  • GL_ADD
  • GL_SUBTRACT
  • GL_DOT3_RGB
  • GL_DOT3_RGBA

For the GL_COMBINE mode, you can specify up to three operands and an operator. The operands can be textures, constants, or primary colors. The operator determines how the operands are combined.

Usage:

    SoTextureCombine textureCombine;
    textureCombine.enable(TRUE);
    textureCombine.setModeRGB(GL_COMBINE);
    textureCombine.setSourceRGB(0, GL_TEXTURE);
    textureCombine.setSourceRGB(1, GL_PRIMARY_COLOR);
    textureCombine.setOperatorRGB(GL_ADD);
    textureCombine.setConstantColor(SbColor4f(1.0f, 0.0f, 0.0f, 1.0f));
    root->addChild(&textureCombine);

virtual void SoTextureCombineElement::push (SoState * state) [virtual]

This method is called every time a new element is required in one of the stacks. This happens when a writable element is requested, using SoState::getElement() or indirectly SoElement::getElement(), and the depth of the current element is less than the state depth.

Override this method if your element needs to copy data from the previous top of stack. The push() method is called on the new element, and the previous element can be found using SoElement::getNextInStack().

Reimplemented from SoElement.
