SbBool SoNormalBundle::shouldGenerate (int numneeded)

تُرجع FALSE إذا كانت هناك متجهات عمودية في الحالة. بخلاف ذلك، يتم استدعاء initGenerator() مع numneeded كوسيط، ويتم إرجاع TRUE.

void SoNormalBundle::initGenerator (int initnum = 100)

تبدأ مولد المتجهات العمودية. initnum هو مؤشر يجب أن يحتوي على عدد تقريبي للمتجهات العمودية التي سيتم إنشاؤها.

void SoNormalBundle::generate (int startindex = 0, SbBool addtostate = TRUE)

ينشئ متجهات عمودية للشكل. startindex يجب أن يكون دائمًا 0 (حقل SoNonIndexedShape::startIndex تم إهماله). يجب أن يكون addtostate صحيحًا إذا كان يجب إرسال المتجهات العمودية التي تم إنشاؤها إلى الحالة الحالية.

NAME

SoNormalBundle - A bundle for defining normal behavior.

SYNOPSIS

#include <Inventor/nodes/SoNormalBundle.h>

Detailed Description

The SoNormalBundle class is a node that bundles together normal-related information. It is used to define the normal behavior for subsequent geometry. This can include specifying normals explicitly, or defining how normals should be generated (e.g., flat or smooth shading).

SoNormalBundle is typically used in conjunction with SoShape nodes or other geometry-defining nodes to control the appearance of lighting and shading.

Constructor & Destructor Documentation

There are no specific constructor or destructor documentation for SoNormalBundle as it inherits these from its base classes. The default constructor and destructor are usually sufficient.

Member Function Documentation

SoNormalBundle provides member functions for setting and getting normal-related information. Some key functions include:

  • void set(SoState *state): Sets the normal bundle information in the state. This is typically called internally by the Inventor rendering system.
  • static SoNormalBundle *get(SoState *state): Retrieves the current normal bundle from the state.

For a comprehensive list of member functions and their usage, please refer to the Coin API documentation.

SoNormalBundle

الاسم

SoNormalBundle - حزمة لتحديد السلوك الطبيعي.

الملخص

#include <Inventor/nodes/SoNormalBundle.h>

الوصف التفصيلي

الفئة SoNormalBundle هي عقدة تجمع معلومات متعلقة بالمتجهات الطبيعية (normals). تُستخدم لتحديد السلوك الطبيعي للهندسة اللاحقة. يمكن أن يشمل ذلك تحديد المتجهات الطبيعية صراحةً، أو تحديد كيفية توليد المتجهات الطبيعية (مثل التظليل المسطح أو السلس).

تُستخدم SoNormalBundle عادةً بالاقتران مع عقد SoShape أو عقد أخرى تحدد الهندسة للتحكم في مظهر الإضاءة والتظليل.

توثيق المُنشئ والمُدمّر

لا يوجد توثيق محدد للمُنشئ أو المُدمّر لفئة SoNormalBundle حيث أنها ترث هذه الوظائف من فئاتها الأساسية. عادةً ما يكون المُنشئ والمُدمّر الافتراضيان كافيين.

توثيق دوال الأعضاء

توفر SoNormalBundle دوال أعضاء لتعيين واسترجاع المعلومات المتعلقة بالمتجهات الطبيعية. تتضمن بعض الدوال الرئيسية:

  • void set(SoState *state): تقوم بتعيين معلومات حزمة المتجهات الطبيعية في الحالة (state). يتم استدعاء هذه الدالة عادةً داخليًا بواسطة نظام التصيير الخاص بـ Inventor.
  • static SoNormalBundle *get(SoState *state): تقوم باسترجاع حزمة المتجهات الطبيعية الحالية من الحالة (state).

للحصول على قائمة شاملة بدوال الأعضاء واستخداماتها، يرجى الرجوع إلى توثيق واجهة برمجة تطبيقات Coin.
