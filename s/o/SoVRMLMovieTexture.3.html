Detailed Description

This node provides movie playback functionality.

Supported only on Coin-3.1.0+.

This node supports the following fields:

  • SoSFBool loop
  • SoSFFloat speed
  • SoSFTime startTime
  • SoSFTime stopTime
  • SoMFString url
  • SoSFTime duration_changed
  • SoSFBool isActive
