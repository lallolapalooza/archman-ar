الاسم

SoGeoElement - وصف قصير للعنصر الجغرافي.

الملخص

#include <Inventor/geo.h>

class SoGeoElement { ... };

الوصف التفصيلي

هذه الفئة هي عنصر أساسي في مكتبة Inventor لتخزين وإدارة المعلومات الجغرافية. توفر واجهة موحدة للتعامل مع البيانات الجغرافية مثل النقاط، الخطوط، والمضلعات.

توثيق المُنشئ والمُدمّر

SoGeoElement(): المُنشئ الافتراضي.

~SoGeoElement(): المُدمّر.

int getNumPoints() const: يعيد عدد النقاط المخزنة.
