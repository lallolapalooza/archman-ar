وصف تفصيلي

SoMaterialBinding هي عقدة لضبط كيفية تعيين المواد للأشكال.

يحدد ربط المواد المحدد في العقد من هذا النوع كيفية تعيين قيم المواد لعقد SoMaterial على عقد الأشكال الهندسية المضمنة.

يعتمد المعنى الدقيق للربط على نوع الشكل المحدد الذي يتم تطبيق مادة أو مجموعة من المواد عليه.

هذا مثال بسيط جدًا للاستخدام:

#Inventor V2.1 ascii
Separator {
   Coordinate3 {
      point [ 0 0 0, 1 0 0, 1 1 0 ]
   }
   Material {
      diffuseColor [ 1 0 0, 1 1 0, 0 0 1 ]
   }
   MaterialBinding {
      value PER_VERTEX_INDEXED
   }
   IndexedFaceSet {
      coordIndex [ 0, 1, 2, -1 ]
      materialIndex [ 0, 1, 0 ]
   }
}

مع تعيين SoMaterialBinding::value إلى PER_VERTEX_INDEXED أعلاه، سيتم أخذ مؤشرات المواد من حقل SoIndexedFaceSet::materialIndex عند التصيير.

إذا تم تعيين SoMaterialBinding::value إلى PER_VERTEX_INDEXED كما هو مذكور أعلاه، وكان SoIndexedFaceSet::materialIndex غير محدد أو فارغ، فسيتم أخذ المؤشرات ضمنيًا من حقل SoIndexedFaceSet::coordIndex.

إذا تم تعيين SoMaterialBinding::value إلى PER_VERTEX، فسيتم جلب الألوان بطريقة متزايدة بشكل رتيب من حقل SoMaterial::diffuseColor، بدءًا من الفهرس 0.

تنسيق الملف / القيم الافتراضية:

MaterialBinding {
    value OVERALL
}

توثيق تعداد الأعضاء

تعداد SoMaterialBinding::Binding

تعداد لأنواع ربط المواد المتاحة.

المُعَدِّد

OVERALL
تطبيق نفس المادة على الشكل الكامل.
PER_PART
الحصول على مادة جديدة من مجموعة قيم المواد لكل *جزء* من الشكل، حيث يعتمد تعريف *الجزء* على نوع الشكل.

يتم جلب المواد من الفهرس 0 وما بعده، مع زيادة الفهرس إلى مجموعة المواد بمقدار 1 لكل جزء جديد بالترتيب الذي يحدده نوع الشكل المحدد.

ملاحظة مهمة حول قابلية النقل: كان مسموحًا سابقًا مع مكتبة SGI Inventor بتوفير عدد قليل جدًا من الألوان مقارنة بعدد أجزاء الأشكال اللاحقة في الرسم البياني للمشهد. كانت الألوان ستدور بعد ذلك عبر الألوان المتاحة.

منذ SGI Open Inventor v2.1، تم حظر ذلك، على الرغم من أنه يجب توفير ما يكفي من الألوان لجميع الأجزاء، أو سيكون السلوك غير محدد (من المحتمل أن يتسبب في تعطل، في الواقع). لاحظ أن كتاب Inventor Mentor يحتوي على وصف للسلوك *القديم*، *غير الصالح* في الفصل 5، قسم "عقد الربط" (منتصف الصفحة 128 في الطبعة العاشرة).

PER_PART_INDEXED
الحصول على مادة جديدة من مجموعة قيم المواد لكل *جزء* من الشكل، حيث يعتمد تعريف *الجزء* على نوع الشكل.

يتم جلب المواد عن طريق قيم الفهرس لإعدادات الشكل.

PER_FACE
الحصول على مادة جديدة من مجموعة قيم المواد لكل *وجه* متعدد الأضلاع للشكل.

يتم جلب المواد من الفهرس 0 وما بعده، مع زيادة الفهرس إلى مجموعة المواد بمقدار 1 لكل وجه جديد لعقدة الشكل.

لاحظ أن الأوجه الفردية بعد تجزئة الأشكال المعقدة (مثل عقد SoCylinder) لا تعتبر كيانات منفصلة، وبالتالي سيتم التعامل مع هذا الربط بنفس طريقة SoMaterialBinding::PER_PART لتلك الأشكال.

PER_FACE_INDEXED
الحصول على مادة جديدة من مجموعة قيم المواد لكل *وجه* متعدد الأضلاع للشكل.

يتم جلب المواد عن طريق قيم الفهرس لإعدادات الشكل.

لاحظ أن الأوجه الفردية بعد تجزئة الأشكال المعقدة (مثل عقد SoCylinder) لا تعتبر كيانات منفصلة، وبالتالي سيتم التعامل مع هذا الربط بنفس طريقة SoMaterialBinding::PER_PART_INDEXED لتلك الأشكال.

PER_VERTEX
الحصول على مادة جديدة من مجموعة قيم المواد لكل *رأس* متعدد الأضلاع أو خط أو نقطة للشكل.

يتم جلب المواد من الفهرس 0 وما بعده، مع زيادة الفهرس إلى مجموعة المواد بمقدار 1 لكل رأس جديد لعقدة الشكل.

PER_VERTEX_INDEXED
الحصول على مادة جديدة من مجموعة قيم المواد لكل *رأس* متعدد الأضلاع أو خط أو نقطة للشكل.

يتم جلب المواد عن طريق قيم الفهرس لإعدادات الشكل.

DEFAULT
مهمل. لا تستخدم هذه القيمة.
NONE
مهمل. لا تستخدم هذه القيمة.

الوصف التفصيلي

هذه العقدة تحدد كيف يجب تطبيق سمات المواد (الألوان، الإضاءة، إلخ) على الأشكال اللاحقة في الرسم البياني للمشهد. إنها تحدد إما ربطًا واحدًا (OVERALL) يتم تطبيقه على الشكل بأكمله، أو ربطًا خاصًا بالقمة (PER_PART, PER_FACE, PER_EDGE, PER_VERTEX) حيث يتم تطبيق السمة على كل جزء أو وجه أو حافة أو قمة من الشكل.

توثيق تعداد الأعضاء

لا توجد تعدادات للأعضاء في هذه الفئة.
