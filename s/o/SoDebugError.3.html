وصف تفصيلي

الفئة SoDebugError هي آلية تمرير رسائل التصحيح الداخلية.

تخدم هذه الفئة غرضين أساسيين:

1) هي واجهة الرسائل التي يتم من خلالها تمرير حالات الخطأ والتحذير إلى المبرمج الذي يستخدم واجهة برمجة تطبيقات مكتبة Coin لبناء التطبيقات. يتم إنشاء هذه الرسائل عند استخدام طرق واجهة برمجة التطبيقات بطريقة غير صحيحة، أو إذا تسببت الإجراءات على المكتبة في دخولها في حالة غير متسقة. لذلك يجب أن يكون مبرمجو Coin قادرين بسرعة على تتبع الأخطاء في كود التطبيق الخاص بهم.

لكي تكون هذه الخدمة متاحة، يجب تجميع مكتبة Coin مع معلومات التصحيح. بالنسبة لإصدارات الإصدار، يتم إزالة معظم هذه "شبكة الأمان للمبرمج" لتحقيق أقصى سرعة وللاستخدام بأقل مساحة (لإنشاء أصغر مكتبة ممكنة).

2) يمكن لمبرمجي تطبيقات Coin استدعاء طرق SoDebugError داخل الكود الخاص بهم كطريقة مريحة لتصحيح كود التطبيق، بدلاً من سلاسل استدعاءات fprintf() المعتادة.

يدعم Coin متغير بيئة لتعيين نقاط توقف شرطية. يمكن تعيين متغير البيئة COIN_DEBUG_BREAK لأي عدد من الدوال على شكل قائمة مفصولة بفواصل أو مسافات. يجب إعطاء أسماء الدوال على شكل "classname::functionname" (أي بدون نوع الإرجاع، أقواس، أو أنواع أو أسماء الوسائط). إذا تم نشر رسالة تصحيح من إحدى هذه الدوال، فسيتوقف برنامجك (باستخدام assert(0)).

يمكن أن يكون هذا مفيدًا إذا كنت تريد الحصول على تفريغ النواة أو الدخول في مصحح الأخطاء عندما يتم نشر تحذير أو خطأ (على سبيل المثال، "SbVec3f::normalize") من دالة معينة. هذه الميزة مفعلة فقط في النسخة المعدة للتصحيح من Coin.

Detailed Description

This class is an extension of the SoError class for reporting of debug messages.

The Coin library uses this class to report debug messages, and it is recommended that applications also use this class for their own debug reporting.

The default behavior of this class is to print all debug messages to stderr. This behavior can be changed by registering a callback function for debug messages.

The callback function must be of type SoErrorCB and it will be invoked whenever a debug message is posted using one of the post*() methods. The callback function is given a pointer to the string containing the message, and a pointer to the user-defined data that was registered with the callback.

The callback function should return TRUE if it has handled the message, and FALSE otherwise. If the callback returns FALSE, the message will be printed to stderr as usual.

You can register a callback function and user-defined data using the SoError::setHandler() method, which is inherited from the SoError class.

The post*() methods take a source argument, which should be the name of the calling function. This is used to help identify the source of the debug message.

The post*() methods also take a format argument, which is a standard printf()-style format string, followed by any arguments required by the format string.
