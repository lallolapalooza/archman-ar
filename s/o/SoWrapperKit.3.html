Detailed Description

This class is a subclass of SoSeparatorKit which provides the SoNodekitCatalog mechanism to all subclasses. The constructor and destructor are protected, and the class is not intended to be instantiated directly.

The main purpose of SoWrapperKit is to provide a generic base class for nodekits that are meant to be extended and not to be used directly.

If you need to create a custom nodekit, you should subclass SoWrapperKit and implement the SoNodekitCatalog mechanism.
