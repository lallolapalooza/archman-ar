وصف مفصل

الفئة SoSFDouble هي حاوية لقيمة فاصلة عائمة مزدوجة الدقة.

يتم استخدام هذه الخاصية حيث تحتاج العقد أو المحركات أو حاويات الحقول الأخرى إلى تخزين قيمة فاصلة عائمة واحدة.

Detailed Description

An SoSFDouble is a single-precision floating-point value field.

Use this field to store and retrieve double precision floating point numbers.

Example:

  SoSFDouble myDoubleField;
  myDoubleField.setValue(3.14);
  double value = myDoubleField.getValue();
