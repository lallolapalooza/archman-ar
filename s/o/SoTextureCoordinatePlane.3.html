وصف تفصيلي

تُنشئ الفئة SoTextureCoordinatePlane إحداثيات نسيج مسقطة على مستوى.

يُستخدم SoTextureCoordinatePlane لإنشاء إحداثيات نسيج مسقطة على مستوى نسيج. تُحسب إحداثيات النسيج s و t و r كمسافة من الأصل إلى النقطة المسقطة، في الاتجاهات الخاصة بها. يتم تحديد مستوى النسيج بواسطة متجهي اتجاه، مُعطاة كـ SoTextureCoordinatePlane::directionS و SoTextureCoordinatePlane::directionT في إحداثيات الكائن. يُستخدم SoTextureCoordinatePlane::directionR لإنشاء الإحداثي الثالث، ويمكن استخدامه لإنشاء إحداثيات نسيج للنسيج ثلاثي الأبعاد. بالنسبة للنسيج ثنائي الأبعاد، يمكنك ترك هذا الحقل كما هو.

يحدد طول المتجه فترة تكرار النسيج لكل وحدة طول.

مثال استخدام بسيط:

SoSeparator *root = new SoSeparator;
root->ref();
// صورة النسيج
SoTexture2 *tex = new SoTexture2;
tex->filename.setValue("foo.png");
root->addChild(tex);
// مستوى النسيج
SoTextureCoordinatePlane *texPlane = new SoTextureCoordinatePlane;
texPlane->directionS.setValue(SbVec3f(1,0,0));
texPlane->directionT.setValue(SbVec3f(0,1,0));
root->addChild(texPlane);
// إضافة مكعب بسيط
SoCube * c = new SoCube;
c->width.setValue(1.0);
c->height.setValue(1.0)
c->depth.setValue(1.0);
root->addChild(new SoCube);

هنا، نسقط نسيجًا على مكعب. يتم تحديد إحداثي النسيج للمستوى بواسطة directionS = (1,0,0) و directionT = (0,1,0)، مما يعني أنه متوازي لوجه المكعب الأمامي. سيؤدي تعيين، على سبيل المثال، directionS = (0,1,0) و directionT = (-1,0,0) إلى تدوير النسيج عكس اتجاه عقارب الساعة بمقدار 90 درجة. سيؤدي تعيينها إلى ((2,0,0), (0,2,0)) إلى تكرار النسيج مرتين لكل وحدة، وبالتالي يتم عرضه أربع مرات على الوجه 1x1.

ملاحظة: عند تحويل المكعب، سيؤثر التحويل أيضًا على النسيج - سيتم تحويله مع بقية العالم، ولكنه سيبدو "ثابتًا" على الكائن. إذا كنت تريد تغيير موضع النسيج على الكائن، فيجب عليك إدراج عقدة SoTexture2Transform قبل مستوى إحداثيات النسيج. على سبيل المثال، في المثال أعلاه، نظرًا لأن المكعب متمركز في نظام إحداثياته، يبدو الركن السفلي الأيسر للنسيج في منتصف الوجه. لنقل أصل النسيج ليتطابق مع الركن السفلي الأيسر للوجه، قم بإدراج:

SoTexture2Transform * tf = new SoTexture2Transform;
tf->translation.setValue(-0.5,-0.5);
root->addChild(tf);

قبل إضافة مستوى إحداثيات النسيج.

تنسيق الملف / القيم الافتراضية:

TextureCoordinatePlane {
    directionS 1 0 0
    directionT 0 1 0
}
