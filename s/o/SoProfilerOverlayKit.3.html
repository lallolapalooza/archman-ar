Description

This class provides a simple overlay for the profiler.

The overlay displays the profiling scene graph on top of the regular viewport.

You can enable or disable the profiler overlay by calling enableProfile().

You can add or remove geometry to the overlay by calling addOverlayGeometry() or removeOverlayGeometry().

The profiler overlay is enabled by default.
