وصف تفصيلي

تستخدم الفئة SoTextureCubeMap لتعيين خريطة مكعبة على عقد الأشكال اللاحقة.

عقد الأشكال الموجودة ضمن نطاق عقد SoTextureCubeMap في مخطط المشهد (أي أسفل نفس SoSeparator وعلى الجانب الأيمن من SoTextureCubeMap) سيتم تطبيق النسيج عليها وفقًا لخصائص كل نوع شكل فردي. انظر توثيق أنواع الأشكال المختلفة (SoFaceSet، SoCube، SoSphere، إلخ) للحصول على معلومات حول تفاصيل كيفية تطبيق الأنسجة.

تنسيق الملف / القيم الافتراضية:

TextureCubeMap {
    filenames [  ]
    imagePosX 0 0 0
    imageNegX 0 0 0
    imagePosY 0 0 0
    imageNegY 0 0 0
    imagePosZ 0 0 0
    imageNegZ 0 0 0
    wrapS REPEAT
    wrapT REPEAT
    model MODULATE
    blendColor 0 0 0
}

منذ

Coin 3.0

توثيق تعداد الأعضاء

enum SoTextureCubeMap::Model

نموذج تعيين النسيج، لتحديد كيفية "دمج" خريطة النسيج مع الكائن الذي تم تعيينها عليه.

المُعدِّد

MODULATE
يتم ضرب لون النسيج بلون المضلع. ستكون النتيجة تظليل Phong (إذا كان نموذج الإضاءة هو PHONG).
DECAL
تستبدل صورة النسيج تظليل المضلع. لن تكون وحدات البكسل ذات النسيج مظللة بـ Phong. لها سلوك غير محدد للصور الرمادية وصور الرمادية والألفا.
BLEND
يستخدم هذا النموذج عادةً مع الأنسجة أحادية اللون (أي الأنسجة ذات مكون واحد أو مكونين). سيتم استخدام المكون الأول، الشدة، لمزج اللون المظلل للمضلع مع SoTextureCubeMap::blendColor.
REPLACE
تستبدل صورة النسيج تظليل المضلع. لن تكون وحدات البكسل ذات النسيج مظللة بـ Phong. تدعم الأنسجة الرمادية وأنسجة الرمادية والألفا. تتطلب هذه الميزة OpenGL 1.1. سيتم استخدام MODULATE إذا تم اكتشاف إصدار OpenGL < 1.1.

يرجى ملاحظة أن استخدام نموذج النسيج هذا سيجعل ملفات Inventor الخاصة بك غير متوافقة مع الإصدارات الأقدم من Coin و Inventor. تحتاج إلى Coin >= 2.2 أو TGS Inventor 4.0 لتحميل ملفات Inventor التي تستخدم نموذج النسيج REPLACE.

enum SoTextureCubeMap::Wrap

تعداد استراتيجيات الالتفاف التي يمكن استخدامها عندما لا تغطي خريطة النسيج النطاق الكامل للهندسة.

المُعدِّد

REPEAT
كرر النسيج عندما يكون الإحداثي ليس بين 0 و 1.
CLAMP
ثبت الإحداثي بين 0 و 1.
