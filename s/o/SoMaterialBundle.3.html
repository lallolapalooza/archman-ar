وصف تفصيلي

تسهل الفئة SoMaterialBundle التعامل مع المواد.

يجب على كل عقدة شكل إنشاء (على المكدس) مثيل لهذه الفئة واستدعاء sendFirst() قبل إرسال أي شيء إلى GL. أثناء التصيير، يجب استخدام send() لإرسال قيم المواد إلى GL.

SoMaterialBundle::SoMaterialBundle (SoAction * action)

المنشئ مع كون action هو الإجراء المطبق على عقدة الهندسة.

SoMaterialBundle::~SoMaterialBundle ()

المدمر

وثائق الدوال الأعضاء

void SoMaterialBundle::setUpMultiple (void )

غير مستخدم حاليًا. تم توفيره فقط للامتثال لـ OIV.

void SoMaterialBundle::sendFirst (void )

يرسل قيم المواد الأولية إلى GL. يجب القيام بذلك مرة واحدة في جميع عقد الهندسة قبل بدء التصيير.

void SoMaterialBundle::forceSend (const int index)

سيرسل المادة إلى GL حتى لو كان index يساوي الفهرس الحالي.

متوفر للتوافق مع واجهة برمجة تطبيقات SGI Open Inventor v2.1.

SbBool SoMaterialBundle::isColorOnly (void ) const

يعيد TRUE إذا كان نموذج الإضاءة الحالي هو BASE_COLOR.

void SoMaterialBundle::send (const int index, const SbBool betweenbeginend)

يرسل قيم المواد بالفهرس index إلى GL. سيختبر ما إذا كان الفهرس الحالي يساوي index قبل الإرسال.

يجب أن يكون betweenbeginend TRUE إذا كان برنامجك بين glBegin() و glEnd() (من غير القانوني تغيير نمط المضلع بين glBegin() و glEnd()).
