Detailed Description

This node defines a spotlight in VRML. A spotlight is a directional light that emits light in a cone. The cone is defined by the direction and cutOffAngle fields. The beamWidth field controls the falloff of the light intensity within the cone.

The location field defines the position of the light source in the scene graph's coordinate system. The direction field defines the direction in which the light is emitted. The attenuation field controls how the light intensity decreases with distance.

The radius field defines the maximum distance at which the light has any effect. Light beyond this radius is not emitted.
