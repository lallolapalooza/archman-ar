Sort__Key(3pm)

الحزمة: perl-sort-key

التراخيص: GPL, PerlArtistic

Sort::Key(3) وثائق بيرل المساهمة من المستخدمين Sort::Key(3)

الاسم

Sort::Key - أسرع طريقة لفرز أي شيء في بيرل

الملخص

use Sort::Key qw(keysort nkeysort ikeysort);
@by_name = keysort { "$_->{surname} $_->{name}" } @people;
# الفرز حسب مفتاح رقمي:
@by_age = nkeysort { $_->{age} } @people;
# الفرز حسب مفتاح رقمي صحيح:
@by_sons = ikeysort { $_->{sons} } @people;

الوصف

يوفر Sort::Key مجموعة من الدوال لفرز قوائم القيم حسب قيمة مفتاح محسوبة.

إنه أسرع (عادةً أسرع بكثير) ويستخدم ذاكرة أقل من البدائل الأخرى المبنية حول دالة الفرز في بيرل (ST، GRT، إلخ).

كما تتوفر وظيفة الفرز متعدد المفاتيح عبر الوحدات المرافقة Sort::Key::Multi وSort::Key::Maker وSort::Key::Register.

الدوال

توفر هذه الوحدة عددًا كبيرًا من الإجراءات الفرعية للفرز، لكنها جميعًا تنويعات على "keysort":

@sorted = keysort { CALC_KEY($_) } @data

وهي مكافئة مفاهيميًا لـ

@sorted = sort { CALC_KEY($a) cmp CALC_KEY($b) } @data

حيث يمكن أن يكون CALC_KEY($_) أي تعبير لاستخراج قيمة المفتاح من $_ (وليس فقط استدعاء إجراء فرعي).

على سبيل المثال، بعض التنويعات هي "nkeysort" التي تُجري مقارنة رقمية، و"rkeysort" التي ترتب البيانات بترتيب تنازلي، و"ikeysort" و"ukeysort" وهما نسختان محسّنتان من "nkeysort" يمكن استخدامهما عندما تكون المفاتيح أعدادًا صحيحة أو أعدادًا صحيحة غير موقعة على التوالي، إلخ.

كما تتوفر نسخ في المكان (inplace) من أدوات الفرز. على سبيل المثال

keysort_inplace { CALC_KEY($_) } @data

وهي مكافئة لـ

@data = keysort { CALC_KEY($_) } @data

لكنها (أسرع قليلًا) وتستخدم ذاكرة أقل.

القائمة الكاملة للإجراءات الفرعية التي يمكن استيرادها من هذه الوحدة كما يلي:

keysort { CALC_KEY } @array
تُرجع العناصر في @array مرتبة حسب المفتاح المحسوب بتطبيق "{ CALC_KEY }" عليها.

داخل "{ CALC_KEY }"، يكون العنصر متاحًا باسم $_.

على سبيل المثال:

@a=({name=>john, surname=>smith}, {name=>paul, surname=>belvedere});
@by_name=keysort {$_->{name}} @a;

تحترم هذه الدالة التوجيه "use locale".

nkeysort { CALC_KEY } @array
مشابهة لـ "keysort" لكنها تقارن المفاتيح رقميًا بدلًا من مقارنتها كسلاسل نصية.

تحترم هذه الدالة التوجيه "use integer"، أي:

use integer;
my @s=(2.4, 2.0, 1.6, 1.2, 0.8);
my @ns = nkeysort { $_ } @s;
print "@ns\n"

تطبع

0.8 1.6 1.2 2.4 2

تعمل مثل "nkeysort"، مع مقارنة المفاتيح بترتيب رقمي معكوس (أو تنازلي).
ikeysort { CALC_KEY } @array
تعمل مثل "keysort" لكنها تقارن المفاتيح كأعداد صحيحة (32 بت أو أكثر، ولا يتم التحقق من الفائض).
rikeysort { CALC_KEY } @array
تعمل مثل "ikeysort"، لكن بترتيب معكوس (أو تنازلي).
ukeysort { CALC_KEY } @array
تعمل مثل "keysort" لكنها تقارن المفاتيح كأعداد صحيحة غير موقعة (32 بت أو أكثر).

             } @data;

على سبيل المثال، هذه التركيبات متكافئة:

@sorted = nsort @foo;
@sorted = nkeysort { $_ } @foo;
@sorted = sort { $a <=> $b } @foo;
multikeysorter(@types)
multikeysorter_inplace(@types)
multikeysorter(\&genkeys, @types)
multikeysorter_inplace(\&genkeys, @types)
هي الواجهة منخفضة المستوى لوظيفة الفرز متعدد المفاتيح (عادةً، يجب استخدام Sort::Key::Maker وSort::Key::Register أو Sort::Key::Multi بدلًا من ذلك).

تتلقى قائمة بأوصاف المفاتيح وتُرجع مرجعًا إلى إجراء فرعي للفرز متعدد المفاتيح.

الأنواع المقبولة افتراضيًا هي:

string, str, locale, loc, integer, int,
unsigned_integer, uint, number, num

ويمكن إضافة دعم لأنواع إضافية عبر الإجراء الفرعي register_type المتاح من Sort::Key::Types أو الواجهة الأكثر سهولة المتاحة من Sort::Key::Register.

يمكن أن تسبق الأنواع إشارة سالب للإشارة إلى الترتيب التنازلي.

الاسم

Sort::Key::Multi - وظيفة استخراج مفتاح متعدد الأبعاد

ملخص

my $sorter1 = multikeysorter(sub {length $_, $_}, qw(int str)); my @sorted1 = &$sorter1(qw(foo fo o of oof)); my $sorter2 = multikeysorter(qw(int str)); my @sorted2 = &$sorter2(sub {length $_, $_}, qw(foo fo o of oof));

الوصف

وظيفة استخراج المفتاح متعدد الأبعاد. إذا لم يكن الأمر كذلك، فإن المفرزات المولدة تتوقع وسيطة كحجتها الأولى.

انظر أيضًا

وظيفة الفرز في Perl، integer، locale.

الوحدات المكملة Sort::Key::Multi، Sort::Key::Register، Sort::Key::Maker و Sort::Key::Natural.

الوحدات Sort::Key::IPv4، Sort::Key::DateTime و Sort::Key::OID تضيف دعمًا لأنواع بيانات إضافية إلى Sort::Key.

الوحدة Sort::Key::External تسمح بفرز القوائم الكبيرة التي لا تتناسب مع مساحة الذاكرة المتاحة.

الوحدات الشيقة للفرز في Perl تشمل Sort::Maker، Sort::Naturally و Sort::External.
