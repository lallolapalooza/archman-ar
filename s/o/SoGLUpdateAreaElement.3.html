Detailed Description

This element defines the area of the window that needs to be updated. It is used to optimize rendering when only parts of the window need to be redrawn (e.g. during a window expose event).

The origin and size are specified in normalized window coordinates, meaning that (0,0) is the lower-left corner and (1,1) is the upper-right corner of the window.
