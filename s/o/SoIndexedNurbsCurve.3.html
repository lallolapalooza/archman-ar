La clase SoIndexedNurbsCurve es un nodo para representar curvas suaves.

Explicar NURBS va más allá del alcance de este documento. Si no estás familiarizado con los principios de representación de curvas y superficies al realizar visualizaciones 3D, recomendamos buscar un buen libro sobre el tema.

Detailed Description

This node defines a NURBS curve by specifying the control points and their indices in a separate node (usually a `SoCoordinate3` node).

The control points are referenced by the `coordIndex` field.

The curve is defined by the control points, the knot vector, the degree and the rational flag.

The curve is generated by subdividing the parameter interval into `numControlPoints` sub-intervals and evaluating the curve at the midpoints.

Reimplemented from SoShape.

SoDetail * SoIndexedNurbsCurve::createLineSegmentDetail (SoRayPickAction * action, const SoPrimitiveVertex * v1, const SoPrimitiveVertex * v2, SoPickedPoint * pp) [protected], [virtual]

Will create line detail for a SoPickedPoint. This method will only be called internally, when generatePrimitives() is used for picking (SoShape::rayPick() is not overridden).

This method returns NULL in Open Inventor, and subclasses will need to override this method to create details for a SoPickedPoint.

This is not necessary with Coin. Of course, if you choose to override it, it will work in the same way as Open Inventor.

For this to work, you must supply a face or line detail when generating primitives. If you supply NULL for the detail argument in SoShape::beginShape(), you'll have to override this method.
