وصف مفصل

تستخدم الفئة SoVertexShader لإعداد برامج ظل الرأس.

انظر الظلال في Coin لمزيد من المعلومات حول كيفية إعداد شجرة مشهد مع الظلال.

تنسيق الملف / الافتراضيات:

VertexShader {
  isActive TRUE
  sourceType FILENAME
  sourceProgram ""
  parameter []
}

توثيق دوال الأعضاء

SoType SoVertexShader::getClassTypeId (void ) [static]

تعيد هذه الدالة الثابتة الكائن SoType المرتبط بالكائنات من هذه الفئة.

SoType SoVertexShader::getTypeId (void ) const [virtual]

تعيد تحديد نوع الكائن المشتق من فئة ترث SoBase. يستخدم هذا للتحقق من النوع وقت التشغيل وللتحويل "لأسفل".

تمت إعادة تعريفها من SoShaderObject.

const SoFieldData ** SoVertexShader::getFieldDataPtr (void ) [static], [protected]

يعتبر عضو API هذا داخليًا للمكتبة، حيث من غير المرجح أن يكون ذا أهمية لمبرمج التطبيق.


تعيد فئة SoFieldData التي تحتوي على معلومات حول الحقول في هذه العقدة.

const SoFieldData * SoVertexShader::getFieldData (void ) const [protected], [virtual]

تعيد مؤشرًا إلى مخزن بيانات الحقول على مستوى الفئة لهذا المثيل. إذا لم تكن هناك حقول، فتعيد NULL.

تمت إعادة تعريفها من SoShaderObject.

SbBool SoVertexShader::isSupported (SourceType sourceType) [static]

تعيد قيمة منطقية تشير إلى ما إذا كان نوع المصدر المطلوب مدعومًا بواسطة مشغل OpenGL أم لا.

تحذير: للحصول على إجابة صحيحة، يجب أن يكون سياق OpenGL صالحًا متاحًا.
