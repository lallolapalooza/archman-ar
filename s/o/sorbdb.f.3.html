الغرض:

!>
!> يقوم SORBDB بتجزئة كتل المصفوفة المتعامدة M-by-M X إلى مصفوفتين ثنائيتي الأقطار بشكل متزامن:
!>
!>                                 [ B11 | B12 0  0 ]
!>     [ X11 | X12 ]   [ P1 |    ] [  0  |  0 -I  0 ] [ Q1 |    ]**T
!> X = [-----------] = [---------] [----------------] [---------]   .
!>     [ X21 | X22 ]   [    | P2 ] [ B21 | B22 0  0 ] [    | Q2 ]
!>                                 [  0  |  0  0  I ]
!>
!> X11 هي P-by-Q. يجب أن تكون Q لا تزيد عن P، M-P، أو M-Q. (إذا لم يكن
!> هذا هو الحال، فيجب تبديل و/أو إعادة ترتيب X. يمكن القيام بذلك في وقت ثابت
!> باستخدام خيارات TRANS و SIGNS. انظر SORCSD
!> للتفاصيل.)
!>
!> المصفوفات المتعامدة P1، P2، Q1، و Q2 هي P-by-P، (M-P)-by-
!> (M-P)، Q-by-Q، و (M-Q)-by-(M-Q) على التوالي. يتم
!> تمثيلها ضمنيًا بواسطة متجهات هاوسهولدر.
!>
!> B11، B12، B21، و B22 هي مصفوفات ثنائية الأقطار Q-by-Q ممثلة
!> ضمنيًا بواسطة الزوايا THETA و PHI.
!>

NAME

sorbdb — does the bidiagonal reduction of a general matrix.

SYNOPSIS

SUBROUTINE SORBD B( UPLO, M, N,      RMAX, MINAA,     A, LDA,      TAU,          D, E,          T, LDT,     WORK, LWORK,      INFO )
  CHARACTER          UPLO
  INTEGER            M, N, LDA, LDT, LWORK, INFO
  REAL               RMAX, MINAA
  REAL               A( LDA, * ), TAU( * ), D( * ), E( * ), T( LDT, * ), WORK( * )

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the complete CS decomposition of a general matrix A2. A2 is an M x N matrix and is assumed to be;

  if UPLO = 'U' or 'u' then
     A2 = [ R11  R12 ]
          [ 0    R22 ]
  else
     A2 = [ R11  0   ]
          [ R21  R22 ]
  end if

where R11 is min(M,N) x min(M,N), R12 is min(M,N) x max(0,N-M), R21 is max(0,M-N) x min(M,N), and R22 is max(0,M-N) x max(0,N-M).

The bidiagonal blocks B11, B12, B21, and B22 are represented implicitly by angles THETA(1), ..., THETA(Q) and PHI(1), ..., PHI(Q-1). B11 and B21 are upper bidiagonal, while B21 and B22 are lower bidiagonal. Every entry in each bidiagonal band is a product of a sine or cosine of a THETA with a sine or cosine of a PHI. See [1] or SORCSD for details.

P1, P2, Q1, and Q2 are represented as products of elementary reflectors. See SORCSD for details on generating P1, P2, Q1, and Q2 using SORGQR and SORGLQ.

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
