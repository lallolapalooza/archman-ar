الوصف التفصيلي

يستخدم الكلاس SoGLRenderCache لتخزين استدعاءات OpenGL مؤقتًا.

توثيق المنشئ والمدمّر

SoGLRenderCache::SoGLRenderCache (SoState * state)

المنشئ مع كون state هو الحالة الحالية.

SoGLRenderCache::~SoGLRenderCache () [virtual]

المدمّر.

توثيق الدوال العضو

void SoGLRenderCache::open (SoState * state)

يفتح التخزين المؤقت. سيتم تخزين جميع استدعاءات GL مؤقتًا حتى يتم استدعاء close().

انظر أيضًا

close()

call()

void SoGLRenderCache::close (void )

يغلق التخزين المؤقت. يجب استدعاؤه بعد جميع استدعاءات GL.

انظر أيضًا

open()

void SoGLRenderCache::call (SoState * state)

ينفذ قائمة العرض المخزنة مؤقتًا.

انظر أيضًا

open()

int SoGLRenderCache::getCacheContext (void ) const

يعيد سياق التخزين المؤقت لهذا التخزين المؤقت. يستخدم هذا لتحديد ما إذا كان يمكن استخدام التخزين المؤقت لحالة معينة بسرعة.

هذه الدالة هي امتداد لواجهة برمجة تطبيقات Open Inventor.

SbBool SoGLRenderCache::isValid (const SoState * state) const [virtual]

يعيد TRUE إذا كان هذا التخزين المؤقت صالحًا، و FALSE بخلاف ذلك.

مُعاد تطبيقه من SoCache.

void SoGLRenderCache::addNestedCache (SoGLDisplayList * child) [virtual]

يضيف قائمة عرض يتم استدعاؤها من هذا التخزين المؤقت. هذا للتأكد من عدم تدمير قائمة العرض الفرعية مبكرًا جدًا.

void SoGLRenderCache::destroy (SoState * state) [protected], [virtual]

يمكن إعادة تطبيقه بواسطة الفئات الفرعية لتنظيف قبل حذفها. الدالة الافتراضية لا تفعل شيئًا.

مُعاد تطبيقه من SoCache.
