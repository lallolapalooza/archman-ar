sfizz_render(1) صفحة دليل sfizz_render sfizz_render(1)

اسم

sfizz_render - تصيير ملف MIDI كملف WAV باستخدام وصف آلة SFZ.

ملخص

sfizz_render --sfz FILE --wav FILE --midi FILE [خيارات...]

وصف

sfizz_render يغلف مكتبة sfizz SFZ ويمكن استخدامه لتصيير ملف MIDI كملفات صوتية باستخدام ملف وصف SFZ وعينات العينات المرتبطة به.

خيارات

-b, --blocksize NUMBER
حجم الكتلة لاستدعاءات sfizz
-s, --samplerate NUMBER
معدل عينات الإخراج
-q, --quality NUMBER
جودة إعادة أخذ العينات، مثل شفرة sample_quality في SFZ. قيمة 1 ستستخدم استيفاء خطي لعينات المصدر، بينما ستستخدم القيم الأعلى خوارزميات أفضل بشكل متزايد.
-p, --polyphony NUMBER
أقصى تعدد أصوات
-v, --verbose
مخرجات مفصلة
--log PREFIX
إنتاج سجلات
--use-eot
إنهاء التصيير عند آخر رسالة End of Track MIDI
-h, --help
إظهار المساعدة
