INTERACTIVE COMMANDS

The following commands can be entered at the sftp prompt.

ascii
Use ASCII file transfer mode (the default is usually binary).
binary
Use binary file transfer mode (the default).
cd path
Change the remote working directory to path.
chgrp group path
Change the group of file path to group.
chmod mode path
Change the permissions of file path to mode.
chown user path
Change the owner of file path to user.
close
Terminate the sftp session.
δήποτε command
Execute command in the remote shell.
exit
Terminate the sftp session.
get [-afpR] remotepath [localpath]
Download file specified by remotepath from the remote site. If localpath is present, it is used as the local file name. Otherwise, the file is saved in the local directory with the same name as the remote file.
glob cmd
Execute cmd by passing cmd to the local shell, after enabling globbing of cmd. This is equivalent to ! cmd.
help [command]
Display help for command, or all commands if command is not specified.
lcd [path]
Change the local working directory to path. If path is not specified, print the current local working directory.
lls [ls-options]
Display a list of local files, equivalent to running ls locally.
lmstat
Display connection status information for the remote host.
ln oldpath newpath
Create a symbolic link on the remote system named newpath which points to oldpath.
lpwd
Print the current local working directory.
ls [-lR] [path]
Display a listing of files on the remote site. -l uses familiar ls-style output. -R lists subdirectories recursively.
mkdir path
Create a directory specified by path on the remote host.
mv oldpath newpath
Rename remote file from oldpath to newpath.
open host
Connect to a remote host.
progress
Toggle display of progress meter for file transfers.
put [-afpR] localpath [remotepath]
Upload file specified by localpath to the remote site. If remotepath is present, it is used as the remote file name. Otherwise, the file is saved on the remote host with the same name as the local file.
pwd
Print the current remote working directory.
quit
Terminate the sftp session.
rekey
Start rekeying of the SSH session.
reput [-fpR] local-path [remote-path]
Resume upload of local-path. Equivalent to put with the -a flag set.
rename oldpath newpath
Rename remote file from oldpath to newpath.
rm path
Delete remote file specified by path.
rmdir path
Remove remote directory specified by path.
symlink oldpath newpath
Create a symbolic link from oldpath to newpath.
version
Display the sftp protocol version.
!command
Execute command in local shell.
!
Escape to local shell.
?
Synonym for help.
