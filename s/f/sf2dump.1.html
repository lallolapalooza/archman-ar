sf2dump(1)

الحزمة: libgig

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later

sf2dump(1) أدوات libgig sf2dump(1)

الاسم

sf2dump - يقوم بتحليل ملفات SoundFont v2 (.sf2) وطباعة المحتويات.

الملخص

sf2dump [ -v ] FILE

الوصف

يطبع قائمة بجميع العينات والآلات المتاحة داخل ملف SoundFont الإصدار 2 (.sf2) جنبًا إلى جنب مع معلومات مفصلة حول خصائصها وإعداداتها.

خيارات

 FILE
اسم ملف Soundfont
 -v
طباعة الإصدار والخروج

انظر أيضًا
