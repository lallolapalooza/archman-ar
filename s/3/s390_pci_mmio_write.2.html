s390_pci_mmio_write(2) دليل استدعاءات النظام s390_pci_mmio_write(2)

الاسم

s390_pci_mmio_write, s390_pci_mmio_read - نقل البيانات إلى/من صفحة ذاكرة PCI MMIO

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/syscall.h>      /* تعريف ثوابت SYS_* */
#include <unistd.h>
int syscall(size_t length;
            SYS_s390_pci_mmio_write, unsigned long mmio_addr,
            const void user_buffer[length], size_t length);
int syscall(size_t length;
            SYS_s390_pci_mmio_read, unsigned long mmio_addr,
            void user_buffer[length], size_t length);

ملاحظة: لا توفر glibc أي استدعاءات تغليف لهذه الاستدعاءات، مما يجعل استخدام syscall(2) ضروريًا.

الوصف

يقوم استدعاء النظام s390_pci_mmio_write() بكتابة length بايت من البيانات من مساحة المستخدم user_buffer إلى موقع ذاكرة PCI MMIO المحدد بواسطة mmio_addr. يقوم استدعاء النظام s390_pci_mmio_read() بقراءة length بايت من البيانات من موقع ذاكرة PCI MMIO المحدد بواسطة mmio_addr إلى مساحة المستخدم user_buffer.

يجب استخدام استدعاءات النظام هذه بدلاً من عمليات الإسناد البسيطة أو عمليات نقل البيانات المستخدمة للوصول إلى مناطق ذاكرة PCI MMIO المعينة إلى مساحة المستخدم على منصة Linux System z. يجب أن ينتمي العنوان المحدد بواسطة mmio_addr إلى تعيين صفحة ذاكرة PCI MMIO في مساحة عنوان المتصل، ويجب ألا تعبر البيانات التي تتم كتابتها أو قراءتها حدود الصفحة. لا يمكن أن تكون قيمة length أكبر من حجم صفحة النظام.

قيمة الإرجاع

عند النجاح، تعيد s390_pci_mmio_write() و s390_pci_mmio_read() القيمة 0. عند الفشل، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EFAULT
العنوان في mmio_addr غير صالح.
EFAULT
user_buffer لا يشير إلى موقع صالح في مساحة عنوان المتصل.
EINVAL
وسيط length غير صالح.
ENODEV
دعم PCI غير ممكّن.
ENOMEM
ذاكرة غير كافية.

المعايير

Linux على s390.

التاريخ

Linux 3.19. System z EC12.
