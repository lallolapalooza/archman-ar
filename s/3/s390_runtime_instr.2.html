s390_runtime_instr(2) دليل استدعاءات النظام s390_runtime_instr(2)

الاسم

s390_runtime_instr - تمكين/تعطيل القياس الزمني لتشغيل وحدة المعالجة المركزية s390

المكتبة

مكتبة C القياسية (libc، -lc)

الخلاصة

#include <asm/runtime_instr.h> /* تعريف ثوابت S390_* */
#include <sys/syscall.h>       /* تعريف ثوابت SYS_* */
#include <unistd.h>
int syscall(SYS_s390_runtime_instr, int command, int signum);

ملاحظة: لا توفر glibc واجهة استدعاء لـ s390_runtime_instr()، مما يستلزم استخدام syscall(2).

الوصف

يبدأ استدعاء النظام s390_runtime_instr() أو يوقف القياس الزمني لتشغيل وحدة المعالجة المركزية للخيط المستدعي.

يتحكم الوسيط command في ما إذا كان سيتم بدء القياس الزمني للتشغيل (S390_RUNTIME_INSTR_START, 1) أو إيقافه (S390_RUNTIME_INSTR_STOP, 2) للخيط المستدعي.

يحدد الوسيط signum رقم إشارة زمنية حقيقية. تم استخدام هذا الوسيط لتحديد رقم إشارة يجب تسليمه إلى الخيط إذا كان مخزن القياس الزمني لتشغيل ممتلئًا أو إذا حدث مقاطعة توقف القياس الزمني لتشغيل. لم يتم استخدام هذه الميزة مطلقًا، وفي لينكس 4.4 تم إزالة الدعم لهذه الميزة؛ وبالتالي، في النواة الحالية، يتم تجاهل هذا الوسيط.

قيمة الإرجاع

عند النجاح، تعيد s390_runtime_instr() القيمة 0 وتمكّن الخيط للقياس الزمني لتشغيل عن طريق تعيين كتلة تحكم افتراضية للقياس الزمني لتشغيل للخيط. يمكن للمستدعي بعد ذلك قراءة وتعديل كتلة التحكم وبدء القياس الزمني لتشغيل. عند حدوث خطأ، يتم إرجاع -1 وتعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
القيمة المحددة في command ليست أمرًا صالحًا.
EINVAL
القيمة المحددة في signum ليست رقم إشارة زمني حقيقي. من لينكس 4.4 فصاعدًا، لا يكون للوسيط signum أي تأثير، بحيث لا ينتج عن رقم إشارة غير صالح خطأ.
ENOMEM
فشل تخصيص الذاكرة لكتلة التحكم القياس الزمني لتشغيل.
EOPNOTSUPP
مرفق القياس الزمني لتشغيل غير متاح.

المعايير

Linux على s390.

التاريخ

Linux 3.7. System z EC12.

ملاحظات

ملف الترويسة asm/runtime_instr.h متاح منذ لينكس 4.16.

بدءًا من لينكس 4.4، تم إزالة دعم الإشارات، وكذلك التحقق مما إذا كان signum إشارة زمنية حقيقية صالحة. للتوافق مع الإصدارات السابقة مع النواة الأقدم، يوصى بتمرير رقم إشارة زمني حقيقي صالح في signum وتركيب معالج لتلك الإشارة.
