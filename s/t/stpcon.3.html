وثائق الوظيفة/الروتين الفرعي

subroutine stpcon (character norm, character uplo, character diag, integer n, real, dimension( * ) ap, real rcond, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

STPCON

الغرض:

!>
!> STPCON يقدر مقلوب رقم الشرط لمصفوفة مثلثة معبأة A، إما في المعيار 1-norm أو المعيار اللانهائي infinity-norm.
!>
!> يتم حساب معيار A ويتم الحصول على تقدير لـ
!> norm(inv(A))، ثم يتم حساب مقلوب رقم الشرط على النحو التالي
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          تحدد ما إذا كان رقم الشرط 1-norm أو رقم الشرط اللانهائي infinity-norm مطلوبًا:
!>          = '1' or 'O':  1-norm;
!>          = 'I':         Infinity-norm.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  A مصفوفة مثلثة عليا؛
!>          = 'L':  A مصفوفة مثلثة سفلى.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A مصفوفة مثلثة غير أحادية؛
!>          = 'U':  A مصفوفة مثلثة أحادية.
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          المصفوفة المثلثة العلوية أو السفلية A، مجمعة عمودياً في مصفوفة خطية.
!>          يتم تخزين العمود j من A في المصفوفة AP كما يلي:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>          If DIAG = 'U', لا يتم الرجوع إلى العناصر القطرية لـ A
!>          ويفترض أنها 1.
!>

RCOND

!>          RCOND is REAL
!>          مقلوب رقم شرط المصفوفة A،
!>          محسوب كـ RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK is REAL array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت ذات قيمة غير قانونية
!>
