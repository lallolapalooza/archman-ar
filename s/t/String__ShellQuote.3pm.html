String__ShellQuote(3pm)

الحزمة: perl-string-shellquote

التراخيص: GPL

ShellQuote(3) وثائق Perl التي ساهم بها المستخدم ShellQuote(3)

الاسم

String::ShellQuote - اقتباس السلاسل النصية للتمرير عبر الـ shell

الملخص

$string = shell_quote @list;
$string = shell_quote_best_effort @list;
$string = shell_comment_quote $string;

الوصف

تحتوي هذه الوحدة على بعض الدوال المفيدة لاقتباس السلاسل النصية التي سيتم تمريرها عبر الـ shell أو كائن مشابه للـ shell.

shell_quote [string]...
تقوم shell_quote باقتباس السلاسل النصية بحيث يمكن تمريرها عبر الـ shell. يتم اقتباس كل string بحيث يقوم الـ shell بتمريره كحجة واحدة ودون تفسير إضافي. إذا لم يتم إعطاء أي string، يتم إرجاع سلسلة نصية فارغة.

إذا تعذر اقتباس أي string بأمان، فإن shell_quote ستقوم بـ الانهيار (croak).

shell_quote_best_effort [string]...
هذه الدالة تشبه shell_quote، باستثناء أنه إذا تعذر اقتباس السلسلة النصية بأمان، فإنها تبذل قصارى جهدها وتعيد النتيجة بدلاً من الانهيار.
shell_comment_quote [string]
تقوم shell_comment_quote باقتباس string بحيث يمكن تضمينها بأمان في تعليق بأسلوب الـ shell (الخوارزمية الحالية هي وضع علامة # بعد أي سطر جديد في السلسلة النصية).

قد يتم تغيير هذه الدالة لقبول وسائط string متعددة في المستقبل. لم أفعل ذلك بعد لأنني لست متأكدًا مما إذا كان يجب ربط strings بمسافات ($") أو لا شيء ($,). صوّت اليوم! تأكد من تبرير إجابتك.

أمثلة

$cmd = 'fuser 2>/dev/null ' . shell_quote @files;
@pids = split ' ', `$cmd`;
print CFG "# Configured by: ",
            shell_comment_quote($ENV{LOGNAME}), "\n";

أخطاء

يتم دعم اقتباسات Bourne shell فقط. أود إضافة قذائف أخرى (خاصة cmd.exe)، لكنني لست ملمًا بها. سيكون من المفيد جدًا لو قدم شخص ما التفاصيل.
