القيمة length : 'a list -> int

إرجاع طول (عدد العناصر) القائمة المعطاة.

القيمة compare_lengths : 'a list -> 'b list -> int

مقارنة أطوال قائمتين. compare_lengths l1 l2 تعادل compare (length l1) (length l2) ، باستثناء أن الحساب يتوقف بعد الوصول إلى نهاية أقصر قائمة.

منذ 4.05

القيمة compare_length_with : 'a list -> len:int -> int

مقارنة طول قائمة بعدد صحيح. compare_length_with l len تعادل compare (length l) len ، باستثناء أن الحساب يتوقف بعد len تكرار على الأكثر للقائمة.

منذ 4.05

القيمة is_empty : 'a list -> bool

is_empty l تكون صحيحة إذا وفقط إذا كانت l لا تحتوي على عناصر. إنها تعادل compare_length_with l 0 = 0.

القيمة singleton : 'a -> 'a list

singleton x ترجع القائمة ذات العنصر الواحد [x].

القيمة hd : 'a list -> 'a

إرجاع العنصر الأول من القائمة المعطاة.

تثير Failure إذا كانت القائمة فارغة.

القيمة tl : 'a list -> 'a list

إرجاع القائمة المعطاة بدون عنصرها الأول.

تثير Failure إذا كانت القائمة فارغة.

القيمة nth : 'a list -> int -> 'a

إرجاع العنصر n -th من القائمة المعطاة. العنصر الأول (رأس القائمة) هو في الموضع 0.

تثير Failure إذا كانت القائمة قصيرة جدًا.

تثير Invalid_argument إذا كان n سالبًا.

القيمة nth_opt : 'a list -> int -> 'a option

إرجاع العنصر n -th من القائمة المعطاة. العنصر الأول (رأس القائمة) هو في الموضع 0. ترجع None إذا كانت القائمة قصيرة جدًا.

القيمة rev : 'a list -> 'a list

عكس القائمة.

القيمة init : len:int -> f:(int -> 'a) -> 'a list

init ~len ~f هي [f 0; f 1; ...; f (len-1)] ، يتم تقييمها من اليسار إلى اليمين.

منذ 4.06

تثير Invalid_argument إذا كان len < 0.

القيمة append : 'a list -> 'a list -> 'a list

append l0 l1 تلحق l1 بـ l0. نفس وظيفة المعامل البيني @.

منذ 5.1 هذه الوظيفة تكرارية ذيلية (tail-recursive).

القيمة rev_append : 'a list -> 'a list -> 'a list

rev_append l1 l2 تعكس l1 وتلحقها بـ l2. هذا يعادل ( ListLabels.rev l1) @ l2.

القيمة concat : 'a list list -> 'a list

دمج قائمة من القوائم. يتم دمج جميع عناصر الوسيط معًا (بنفس الترتيب) لإنتاج النتيجة. ليست تكرارية ذيلية (طول الوسيط + طول أطول قائمة فرعية).

القيمة flatten : 'a list list -> 'a list

نفس وظيفة ListLabels.concat. ليست تكرارية ذيلية (طول الوسيط + طول أطول قائمة فرعية).

المقارنة

القيمة equal : eq:('a -> 'a -> bool) -> 'a list -> 'a list -> bool

equal eq [a1; ...; an] [b1; ..; bm] صحيح عندما يكون للقائمتين المدخلتين نفس الطول، ولكل زوج من العناصر ai ، bi في نفس الموضع، يكون eq ai bi.

ملاحظة: قد يتم استدعاء وظيفة eq حتى لو كانت للقائمتين أطوال مختلفة. إذا كنت تعلم أن وظيفة المساواة الخاصة بك مكلفة، فقد ترغب في التحقق من ListLabels.compare_lengths أولاً.

منذ 4.12

القيمة compare : cmp:('a -> 'a -> int) -> 'a list -> 'a list -> int

compare cmp [a1; ...; an] [b1; ...; bm] تقوم بمقارنة معجمية للقائمتين المدخلتين، باستخدام نفس الواجهة 'a -> 'a -> int مثل compare :

- a1 :: l1 أصغر من a2 :: l2 (نتيجة سالبة) إذا كانت a1 أصغر من a2 ، أو إذا كانتا متساويتين (نتيجة 0) و l1 أصغر من l2

- القائمة الفارغة [] أصغر من القوائم غير الفارغة بشكل صارم

ملاحظة: سيتم استدعاء وظيفة cmp حتى لو كانت للقائمتين أطوال مختلفة.

المكررات

القيمة iter : f:('a -> unit) -> 'a list -> unit

iter ~f [a1; ...; an] تطبق الوظيفة f بالتناوب على [a1; ...; an]. إنها تعادل f a1; f a2; ...; f an.

القيمة iteri : f:(int -> 'a -> unit) -> 'a list -> unit

نفس وظيفة ListLabels.iter ، ولكن يتم تطبيق الوظيفة على فهرس العنصر كوسيط أول (عد من 0)، والعنصر نفسه كوسيط ثانٍ.

منذ 4.00

القيمة map : f:('a -> 'b) -> 'a list -> 'b list

map ~f [a1; ...; an] تطبق الوظيفة f على a1, ..., an ، وتبني القائمة [f a1; ...; f an] بالنتائج التي ترجعها f.

القيمة mapi : f:(int -> 'a -> 'b) -> 'a list -> 'b list

نفس وظيفة ListLabels.map ، ولكن يتم تطبيق الوظيفة على فهرس العنصر كوسيط أول (عد من 0)، والعنصر نفسه كوسيط ثانٍ.

منذ 4.00

القيمة rev_map : f:('a -> 'b) -> 'a list -> 'b list

rev_map ~f l تعطي نفس نتيجة ListLabels.rev ( ListLabels.map f l) ، ولكنها أكثر كفاءة.

القيمة filter_map : f:('a -> 'b option) -> 'a list -> 'b list

filter_map ~f l تطبق f على كل عنصر من عناصر l ، وتستبعد العناصر None وترجع قائمة بالوسائط للعناصر Some.

منذ 4.08

القيمة concat_map : f:('a -> 'b list) -> 'a list -> 'b list

concat_map ~f l تعطي نفس نتيجة ListLabels.concat ( ListLabels.map f l). تكرارية ذيلية.

منذ 4.10

القيمة fold_left_map : f:('acc -> 'a -> 'acc * 'b) -> init:'acc -> 'a list -> 'acc * 'b list

fold_left_map هو مزيج من fold_left و map الذي يمرر مجمعًا عبر استدعاءات f.

منذ 4.11

القيمة fold_left : f:('acc -> 'a -> 'acc) -> init:'acc -> 'a list -> 'acc

fold_left ~f ~init [b1; ...; bn] هي f (... (f (f init b1) b2) ...) bn.

القيمة fold_right : f:('a -> 'acc -> 'acc) -> 'a list -> init:'acc -> 'acc

fold_right ~f [a1; ...; an] ~init هي f a1 (f a2 (... (f an init) ...)). ليست تكرارية ذيلية.

القيمة iter2 : f:('a -> 'b -> unit) -> 'a list -> 'b list -> unit

iter2 ~f [a1; ...; an] [b1; ...; bn] تستدعي بالتناوب f a1 b1; ...; f an bn.

map2 ~f [a1; ...; an] [b1; ...; bn] هي [f a1 b1; ...; f an bn].
