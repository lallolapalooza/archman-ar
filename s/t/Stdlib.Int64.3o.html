قسمة الأعداد الصحيحة.

val rem : int64 -> int64 -> int64

باقي قسمة الأعداد الصحيحة. إذا كان y ليس صفرًا، فإن نتيجة Int64.rem x y تحقق الخاصية التالية: x = Int64.add (Int64.mul (Int64.div x y) y) (Int64.rem x y). إذا كان y = 0 ، فإن Int64.rem x y يطرح Division_by_zero.

val unsigned_rem : int64 -> int64 -> int64

نفس Int64.rem ، باستثناء أن الوسائط والنتيجة يتم تفسيرهما كأعداد صحيحة غير موقعة ذات 64 بت.

val shift_left : int64 -> int -> int64

Int64.shift_left x y تقوم بإزاحة x إلى اليسار بمقدار y بت. النتيجة غير محددة إذا كان y < 0 أو y >= 64.

val shift_right : int64 -> int -> int64

Int64.shift_right x y تقوم بإزاحة x إلى اليمين بمقدار y بت. هذه إزاحة حسابية: يتم تكرار بت الإشارة لـ x وإدراجه في البتات الفارغة. النتيجة غير محددة إذا كان y < 0 أو y >= 64.

val shift_right_logical : int64 -> int -> int64

Int64.shift_right_logical x y تقوم بإزاحة x إلى اليمين بمقدار y بت. هذه إزاحة منطقية: يتم إدخال أصفار في البتات الفارغة بغض النظر عن إشارة x. النتيجة غير محددة إذا كان y < 0 أو y >= 64.

val of_int : int -> int64

تحويل العدد الصحيح المحدد (النوع int) إلى عدد صحيح ذي 64 بت (النوع int64).

val to_int : int64 -> int

تحويل العدد الصحيح ذي 64 بت المحدد (النوع int64) إلى عدد صحيح (النوع int). على المنصات ذات 64 بت، يتم أخذ العدد الصحيح ذي 64 بت بترديد 2^63، أي يتم فقدان البت الأعلى أثناء التحويل. على المنصات ذات 32 بت، يتم أخذ العدد الصحيح ذي 64 بت بترديد 2^31، أي يتم فقدان الـ 33 بت العليا أثناء التحويل.

val unsigned_to_int : int64 -> int option

نفس Int64.to_int ، ولكنها تفسر الوسيط كعدد صحيح غير موقع. ترجع None إذا كانت القيمة غير الموقعة للوسيط لا يمكن أن تتناسب مع int.

منذ 4.08

val of_float : float -> int64

تحويل العدد ذي الفاصلة العائمة المحدد إلى عدد صحيح ذي 64 بت، مع تجاهل الجزء الكسري (الاقتطاع نحو الصفر). إذا كان العدد ذو الفاصلة العائمة المقتطع خارج النطاق [ Int64.min_int ، Int64.max_int ]، فلا يتم طرح أي استثناء، ويتم إرجاع عدد صحيح غير محدد ويعتمد على النظام الأساسي.

val to_float : int64 -> float

تحويل العدد الصحيح ذي 64 بت المحدد إلى عدد ذي فاصلة عائمة.

val of_int32 : int32 -> int64

تحويل العدد الصحيح المحدد ذي 32 بت (النوع int32) إلى عدد صحيح ذي 64 بت (النوع int64).

val to_int32 : int64 -> int32

تحويل العدد الصحيح المحدد ذي 64 بت (النوع int64) إلى عدد صحيح ذي 32 بت (النوع int32). يتم أخذ العدد الصحيح ذي 64 بت بترديد 2^32، أي يتم فقدان الـ 32 بت العليا أثناء التحويل.

val of_nativeint : nativeint -> int64

تحويل العدد الصحيح الأصلي المحدد (النوع nativeint) إلى عدد صحيح ذي 64 بت (النوع int64).

val to_nativeint : int64 -> nativeint

تحويل العدد الصحيح المحدد ذي 64 بت (النوع int64) إلى عدد صحيح أصلي. على المنصات ذات 32 بت، يتم أخذ العدد الصحيح ذي 64 بت بترديد 2^32. على المنصات ذات 64 بت، يكون التحويل دقيقًا.

val of_string : string -> int64

تحويل السلسلة النصية المحددة إلى عدد صحيح ذي 64 بت. تتم قراءة السلسلة النصية بنظام العد العشري (افتراضيًا، أو إذا بدأت السلسلة بـ 0u) أو بنظام العد الست عشري أو الثماني أو الثنائي إذا بدأت السلسلة بـ 0x أو 0o أو 0b على التوالي.

البادئة 0u تقرأ المدخلات كعدد صحيح غير موقع في النطاق [0، 2*Int64.max_int+1]. إذا تجاوزت المدخلات Int64.max_int، فسيتم تحويلها إلى العدد الصحيح الموقع Int64.min_int + input - Int64.max_int - 1.

يمكن أن يظهر الحرف _ (شرطة سفلية) في أي مكان في السلسلة ويتم تجاهله.

يطرح Failure إذا لم تكن السلسلة النصية المحددة تمثيلًا صالحًا لعدد صحيح، أو إذا تجاوز العدد الصحيح الممثل نطاق الأعداد الصحيحة القابلة للتمثيل في النوع int64.

val of_string_opt : string -> int64 option

نفس of_string ، ولكن ترجع None بدلاً من طرح استثناء.

val bits_of_float : float -> int64

ترجع التمثيل الداخلي للعدد العائم المحدد وفقًا لتخطيط بت تنسيق 'double format' القياسي IEEE 754. البت 63 للنتيجة يمثل إشارة العدد العائم؛ البتات من 62 إلى 52 تمثل الأس (المتحيز)؛ البتات من 51 إلى 0 تمثل الجزء العشري (mantissa).

val float_of_bits : int64 -> float

ترجع العدد العائم الذي تمثيله الداخلي، وفقًا لتخطيط بت تنسيق 'double format' القياسي IEEE 754، هو int64 المحدد.

type t = int64

اسم مستعار لنوع الأعداد الصحيحة ذات 64 بت.

val compare : t -> t -> int

وظيفة المقارنة للأعداد الصحيحة ذات 64 بت، بنفس المواصفات مثل compare. إلى جانب النوع t، تسمح هذه الوظيفة compare بتمرير الوحدة Int64 كوسيط للمُنشئات Set.Make و Map.Make.

val unsigned_compare : t -> t -> int

نفس Int64.compare ، باستثناء أن الوسائط يتم تفسيرها كأعداد صحيحة غير موقعة ذات 64 بت.
