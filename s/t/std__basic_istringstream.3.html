long & std::ios_base::iword (int __ix) [inline], [inherited]

الوصول إلى مصفوفة الأعداد الصحيحة.

المعاملات

__ix فهرس في المصفوفة.

المرتجعات

مرجع إلى عدد صحيح مرتبط بالفهرس.

توفر الدالة iword الوصول إلى مصفوفة من الأعداد الصحيحة يمكن استخدامها لأي غرض. تنمو المصفوفة حسب الحاجة لاستيعاب الفهرس المقدم. تتم تهيئة جميع الأعداد الصحيحة في المصفوفة إلى 0.

تحتفظ التنفيذ بعدة فهارس. يجب عليك استخدام xalloc للحصول على فهرس آمن للاستخدام. لاحظ أيضًا أنه نظرًا لأن المصفوفة يمكن أن تنمو ديناميكيًا، فليس من الآمن الاحتفاظ بالمرجع.

مراجع iword().

تمت الإشارة إليها بواسطة iword().

استخراج إلى مخزن مؤقت آخر.

المعاملات

__sb مؤشر إلى مخزن مؤقت

تعمل هذه الدالة مثل واحدة من مستخرجات الحساب الأساسية، حيث تقوم أيضًا ببناء كائن إرسال ولها نفس سلوك معالجة الأخطاء.

إذا كان __sb فارغًا (NULL)، فسوف يضبط الدفق بت failbit في حالة خطأه.

يتم استخراج الأحرف من هذا الدفق وإدخالها في المخزن المؤقت __sb حتى يحدث أحد ما يلي:

  • يصل دفق الإدخال إلى نهاية الملف،
  • فشل الإدراج في المخزن المؤقت للإخراج (في هذه الحالة، لا يتم استخراج الحرف الذي كان سيتم إدراجه)، أو
  • يحدث استثناء (ويتم التقاطه في هذه الحالة)

إذا لم تقم الدالة بإدراج أي أحرف، يتم ضبط failbit.

المعاملات

__sb المخزن المؤقت الجديد للمجرى.

الإرجاع

المخزن المؤقت السابق للمجرى.

يقترن مخزن مؤقت جديد بالمجرى الحالي، ويمسح حالة الخطأ.

بسبب الحوادث التاريخية التي يرفض LWG تصحيحها، تعاني مكتبة الإدخال/الإخراج من خطأ تصميم: هذه الوظيفة مخفية في الفئات المشتقة عن طريق تجاوزات rdbuf() ذات الوسيط الصفري، وهي ليست افتراضية لأسباب هيستيرية. نتيجة لذلك، يجب عليك استخدام التأهيلات الصريحة للوصول إلى هذه الوظيفة عبر أي فئة مشتقة. على سبيل المثال:

std::streambuf*  p = .....;
foo.ios::rdbuf(p);            // ios == basic_ios<char>

template<typename _CharT, typename _Traits> basic_istream< _CharT, _Traits > & std::basic_stream< _CharT, _Traits >::read (char_type * __s, streamsize __n) [inherited]

استخلاص بدون فواصل.

المعاملات

__s مصفوفة أحرف.
__n الحد الأقصى لعدد الأحرف المراد تخزينها.

الإرجاع

*this

إذا كانت حالة المجرى جيدة، فإنه يستخلص الأحرف ويخزنها في *__s* حتى يحدث أحد الأمور التالية:

  • يتم تخزين *__n* من الأحرف
  • يصل تسلسل الإدخال إلى نهاية الملف، وفي هذه الحالة يتم تعيين حالة الخطأ إلى failbit|eofbit.

ملاحظة

لم يتم تحميل هذه الوظيفة على char موقع أو unsigned char.

يستخلص الأحرف ويخزنها في *__s* اعتمادًا على عدد الأحرف المتبقية في المخزن المؤقت للمجرى، rdbuf()->in_avail()، ويسمى A هنا:

  • إذا كان A == -1، يتم تعيين eofbit ولا يتم استخلاص أي أحرف
  • إذا كان A == 0، لا يتم استخلاص أي أحرف
  • إذا كان A > 0، e
  • std::istream::gcount: Returns the number of characters extracted by the last unformatted input operation.
  • std::istream::tellg: Returns the current position in the input sequence.
  • std::istream::seekg: Changes the current read position.
  • std::istream::sync: Synchronizes the stream buffer.
  • std::istream::read: Extracts characters from the input sequence.
  • std::istream::readsome: Extracts characters from the input sequence.
  • std::istream::putback: Inserts a character back into the input sequence.
  • std::istream::unget: Inserts a character back into the input sequence.
  • std::basic_ios::clear: Clears the error state.
  • std::basic_ios::setstate: Sets additional flags in the error state.
  • std::ios_base::setf: Setting new format flags.
  • std::ios_base::unsetf: Unsetting format flags.
  • std::ios_base::register_callback: Registers a function as an event callback.
  • std::ios_base::sync_with_stdio: Interaction with the standard C I/O objects.
  • std::basic_istringstream::str: Copying out the string buffer.
  • std::basic_istringstream::str: Setting a new buffer.

The goal is to empty the current buffer, and to not request any more from the external input sequence controlled by the streambuf.

template<typename _CharT, typename _Traits> basic_istream< _CharT, _Traits > & std::basic_istream< _CharT, _Traits >::seekg (off_type __off, ios_base::seekdir __dir) [inherited]

Changing the current read position.

Parameters

__off A file offset object.
__dir The direction in which to seek.

Returns

*this

If fail() is not true, calls rdbuf()->pubseekoff(__off,__dir). If that function fails, sets failbit.
