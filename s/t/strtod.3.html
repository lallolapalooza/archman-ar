NAME

strtod - convert string to double-precision floating-point number

SYNTAX

HEADER FILES

<stdlib.h>

FUNCTION PROTOTYPES

double strtod(const char *nptr, char **endptr);

DESCRIPTION

The strtod() function

The strtod() function converts the initial portion of the string pointed to by nptr to double-precision floating-point representation.

The string is interpreted based on the current locale settings, specifically the decimal point character.

If the value of the converted number is outside the range of representable values for a double, strtod() returns the appropriate range error.

If the string is not a valid floating-point number, strtod() returns 0 and endptr is left unchanged.

The endptr argument is a pointer to a pointer to a character. If not NULL, strtod() stores the address of the first character in nptr that is not part of the converted number in the location pointed to by endptr. If no conversion could be performed, nptr is stored in the location pointed to by endptr.

Recognized floating-point values are:

  • Optional sign ('+' or '-').
  • A sequence of decimal digits, optionally containing a decimal point.
  • Optional exponent part, starting with 'e' or 'E', followed by an optional sign and a sequence of decimal digits.
  • The strings "NaN", "nan", "Infinity", or "infinity" (case-insensitive) are recognized as Not-a-Number and infinity, respectively.

RETURN VALUE

strtod() returns the converted value

strtod() returns the converted value.

If the value is too large to be represented, HUGE_VAL, HUGE_VALF, or HUGE_VALL is returned.

If the value is too small to be represented, 0 is returned.

If no conversion could be performed, 0 is returned.

ERRORS

If the value is too large to be represented

ERANGE is set if the value is too large to be represented.

If the value is too small to be represented

ERANGE is set if the value is too small to be represented.

EXAMPLES

Basic Usage

#include <stdio.h>
#include <stdlib.h>

int main() {
    char *str1 = "123.456";
    char *str2 = "  -789.0abc";
    char *str3 = "1.23e-4";
    char *str4 = "Infinity";
    char *str5 = "NaN";
    char *endptr;
    double val1, val2, val3, val4, val5;

    val1 = strtod(str1, &endptr);
    printf("strtod(\"%s\", ...) = %f, endptr = \"%s\"\n", str1, val1, endptr);

    val2 = strtod(str2, &endptr);
    printf("strtod(\"%s\", ...) = %f, endptr = \"%s\"\n", str2, val2, endptr);

    val3 = strtod(str3, &endptr);
    printf("strtod(\"%s\", ...) = %f, endptr = \"%s\"\n", str3, val3, endptr);

    val4 = strtod(str4, &endptr);
    printf("strtod(\"%s\", ...) = %f, endptr = \"%s\"\n", str4, val4, endptr);

    val5 = strtod(str5, &endptr);
    printf("strtod(\"%s\", ...) = %f, endptr = \"%s\"\n", str5, val5, endptr);

    return 0;
}

Output:

strtod("123.456", ...) = 123.456000, endptr = ""
strtod("  -789.0abc", ...) = -789.000000, endptr = "abc"
strtod("1.23e-4", ...) = 0.000123, endptr = ""
strtod("Infinity", ...) = inf, endptr = ""
strtod("NaN", ...) = nan, endptr = ""

NOTES

Locale and Decimal Point

The interpretation of the decimal point in strtod() is locale-dependent. In the "C" locale, the decimal point is a period (.). In other locales, it may be a comma (,) or another character.

NaN and Infinity

The strings "NaN", "nan", "Infinity", and "infinity" (case-insensitive) are recognized as Not-a-Number and infinity. These values are represented by special floating-point values.

CONFORMING TO

C99, POSIX.1-2001 and later

The strtod() function conforms to C99 and POSIX.1-2001 and later.
