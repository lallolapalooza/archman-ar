الوصف التفصيلي

مساحة اسم ISO C++ 2014 للحواشي اللاحقة لـ duration literals.

يمكن استخدام هذه الحواشي اللاحقة لإنشاء قيم chrono::duration بنبضات قياس للساعات أو الدقائق أو الثواني أو الأجزاء من الألف من الثانية أو الميكرو ثانية أو النانو ثانية. على سبيل المثال، يمكن كتابة std::chrono::seconds(5) كـ 5s بعد جعل اللازجة مرئية في النطاق الحالي. يمكن جعل الحواشي اللاحقة مرئية باستخدام توجيه استخدام أو إعلان استخدام مثل:

  • using namespace std::chrono_literals;
  • using namespace std::literals;
  • using namespace std::chrono;
  • using namespace std;
  • using std::chrono_literals::operator""s;

نتيجة هذه الحواشي اللاحقة على حرف رقمي هي واحدة من الأنواع المعرفة مسبقًا مثل std::chrono::hours. نتيجة على حرف عشري هي نوع مدة بنبضة قياس محددة وتمثيل عشري غير محدد، على سبيل المثال 1.5e2ms قد يكون مكافئًا لـ chrono::duration<long double, chrono::milli>(1.5e2).
