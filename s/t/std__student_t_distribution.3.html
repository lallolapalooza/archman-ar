NAME

std::student_t_distribution — student t distribution

SYNOPSIS

Class template

template<typename _RealType = double> class student_t_distribution

DESCRIPTION

The Student t distribution is a continuous probability distribution. It is commonly used in hypothesis testing and confidence intervals when the population standard deviation is unknown and the sample size is small.

The distribution is parameterized by the degrees of freedom, denoted by ν (nu). The probability density function (PDF) of the Student t distribution is given by:
