الوصف

This namespace contains utilities that are not part of the C++ Standard Library but are intended to be.

This namespace contains features defined in ISO Technical Specifications.

الاسم

std::experimental - دوال وقوالب مخصصة للوظائف.

الوصف المختصر

#include <experimental/algorithm>
#include <experimental/memory>

الوصف المفصل

تمثل هذه الـ "template" دوال ووظائف قيد التطوير أو التجريب. يمكن أن تتغير أو تُحذف في الإصدارات المستقبلية.
