الاسم

STAILQ_REMOVE_HEAD, STAILQ_REMOVE_HEAD_EQ - حذف عنصر من رأس قائمة مرتبطة من ذيل مزدوج

المكتبة

هذه الدوال متوفرة في مكتبة libbsd.

الملخص

 
#include <sys/queue.h>
/*
   For STAILQ_REMOVE_HEAD:
   type = the type of the element
   head = the head of the queue
   field = the name of the next field in the element
*/
void
STAILQ_REMOVE_HEAD(type *head, field);
/*
   For STAILQ_REMOVE_HEAD_EQ:
   type = the type of the element
   head = the head of the queue
   field = the name of the next field in the element
   val = the value of the element to remove
*/
void
STAILQ_REMOVE_HEAD_EQ(type *head, field, val);

الوصف

الدوال STAILQ_REMOVE_HEAD و STAILQ_REMOVE_HEAD_EQ تزيل العنصر الأول من قائمة مرتبطة أحادية الاتجاه مع قائمة مزدوجة من الذيل (tail queue). القائمة المزدوجة من الذيل هي قائمة مرتبطة أحادية الاتجاه يتم إدارتها بواسطة مؤشر إلى العنصر الأول ومؤشر إلى العنصر الأخير.

يتم تحديد بنية القائمة بواسطة الماكرو STAILQ_HEAD. تأخذ هذه الدوال مؤشرًا إلى رأس القائمة، واسم حقل الربط (الذي يجب أن يكون من نوع STAILQ_ENTRY)، وفي حالة STAILQ_REMOVE_HEAD_EQ، قيمة العنصر المراد إزالته.

ملاحظة: هذه الدوال لا تقوم بتحرير الذاكرة الخاصة بالعنصر الذي تم إزالته. يجب على المستخدم القيام بذلك بشكل صريح.

قيمة الإرجاع

لا تُرجع هذه الدوال أي قيمة.

الإصدارات

هذه الدوال متاحة في نظام التشغيل FreeBSD 3.0 وما بعده.

الأخطاء

لا يوجد أخطاء معروفة.

المعايير

لم يتم توثيق هذه الدوال في أي معيار.

التاريخ

تم تقديم هذه الدوال في نظام التشغيل FreeBSD 3.0.

أمثلة

/* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
