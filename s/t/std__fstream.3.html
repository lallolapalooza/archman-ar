DESCRIPTION

The ios_base class is the base class for stream classes like basic_istream, basic_ostream, and basic_iostream. It defines the public interface for accessing stream state, formatting flags, locale, and other common stream properties.

ios_base defines several types that are used throughout the iostreams library:

  • char_type: The character type used by the stream.
  • int_type: An integral type that can represent character values, plus one additional value (eof).
  • pos_type: An object type that can represent a position in a stream.
  • off_type: An object type that can represent an offset relative to a position in a stream.
  • streamsize: An integral type that can represent the size of character sequences.
  • fmtflags: An enumeration type that represents formatting flags.
  • iostate: An enumeration type that represents the state of the stream (good, eof, fail, bad).
  • openmode: An enumeration type that represents the mode in which a stream is opened (input, output, append, etc.).
  • seekdir: An enumeration type that represents the direction in which to seek within a stream (beg, cur, end).
  • event_callback: A type for registering callbacks for stream events.
  • failure: An exception class for reporting stream errors.

Extractors

The operator>> functions are used to extract data from input streams. They have some common behavior:

  • Each starts by constructing a temporary object of type std::basic_istream::sentry. This object performs several setup operations, including checking the stream's state and potentially skipping whitespace.
  • If the sentry status is good, the function attempts to extract data appropriate for the target type.
  • If an exception occurs during extraction, ios_base::badbit is set in the stream's error state, and the exception is rethrown if the stream's exceptions mask includes badbit.

Specific extractor functions are provided for various arithmetic types (integers and floating-point numbers), as well as for characters and strings (though string extraction is typically handled by derived classes like std::string).

int std::ios_base::xalloc () [static], [inherited]

Access to unique indices.

Returns

An integer different from all previous calls.

This function returns a unique integer every time it is called. It can be used for any purpose, but is primarily intended to be a unique index for the iword and pword functions. The expectation is that an application calls xalloc in order to obtain an index in the iword and pword arrays that can be used without fear of conflict.

The implementation maintains a static variable that is incremented and returned on each invocation. xalloc is guaranteed to return an index that is safe to use in the iword and pword arrays.
