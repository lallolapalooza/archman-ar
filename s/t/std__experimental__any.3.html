NAME

std::experimental::any - a type-safe container for single values of any type.

SYNOPSIS

#include <experimental/any>

namespace std::experimental {

class any;

}

Detailed Description

A type-safe container for single values of any type. The type std::experimental::any (in namespace std::experimental) holds a value of a type T that is copy-constructible and move-constructible. The type of the contained value can be queried at runtime.

A default-constructed any object contains no value. An any object may be assigned a value of any copy-constructible type.

The type std::experimental::any supports dynamic type checking and safe type casting. A value can be retrieved from a std::experimental::any object only if its contained type is known.

The value-held type T must satisfy the requirements of CopyConstructible and MoveConstructible.
