الفرز والخلط

val sort : cmp:('a -> 'a -> int) -> 'a array -> unit

فرز مصفوفة بترتيب تصاعدي وفقًا لدالة مقارنة. يجب أن ترجع دالة المقارنة 0 إذا كانت وسائطها متساوية، وعددًا صحيحًا موجبًا إذا كان الأول أكبر، وعددًا صحيحًا سالبًا إذا كان الأول أصغر (انظر أدناه لمواصفات كاملة). على سبيل المثال، compare هي دالة مقارنة مناسبة. بعد استدعاء sort، يتم فرز المصفوفة في مكانها بترتيب تصاعدي. يضمن sort أن تعمل في مساحة كومة ثابتة ومساحة مكدس لوغاريتمية (بحد أقصى).

التنفيذ الحالي يستخدم فرز الكومة. يعمل في مساحة مكدس ثابتة.

مواصفات دالة المقارنة: لتكن a المصفوفة و cmp دالة المقارنة. يجب أن يكون ما يلي صحيحًا لجميع x و y و z في a:

- cmp x y > 0 إذا وفقط إذا كان cmp y x < 0

- إذا كان cmp x y >= 0 و cmp y z >= 0، فإن cmp x z >= 0

عندما ترجع sort، تحتوي a على نفس العناصر كما كانت من قبل، مع إعادة ترتيبها بحيث لجميع الفهارس الصحيحة لـ a.

- cmp a.(i) a.(j) >= 0 إذا كان i >= j

val stable_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

نفس دالة ArrayLabels.sort، ولكن خوارزمية الفرز مستقرة (أي يتم الاحتفاظ بالعناصر المتساوية في ترتيبها الأصلي) ولا تضمن العمل في مساحة كومة ثابتة.

التنفيذ الحالي يستخدم فرز الدمج. يستخدم مصفوفة مؤقتة بطول n/2، حيث n هو طول المصفوفة. عادة ما يكون أسرع من التنفيذ الحالي لـ ArrayLabels.sort.

val fast_sort : cmp:('a -> 'a -> int) -> 'a array -> unit

نفس دالة ArrayLabels.sort أو ArrayLabels.stable_sort، أيهما أسرع على المدخلات النموذجية.

val shuffle : rand:(int -> int) -> 'a array -> unit

shuffle ~rand a يخلط عشوائيًا عناصر a باستخدام rand للعشوائية. توزيع التباديل موحد.

يجب أن تكون rand بحيث أن استدعاء rand n يرجع عددًا عشوائيًا موزعًا بشكل موحد في النطاق [0; n-1]. يمكن استخدام Random.int لهذا الغرض (لا تنس Random.self_init للمولد).

منذ 4.07

المصفوفات والسلامة المتزامنة

يجب توخي الحذر عند الوصول المتزامن إلى المصفوفات من نطاقات متعددة: لن يؤدي الوصول إلى مصفوفة إلى تعطل البرنامج أبدًا، ولكن الوصول غير المتزامن قد يؤدي إلى نتائج غير متوقعة (غير متسقة تسلسليًا).

الذرية

كل عملية مصفوفة تصل إلى أكثر من عنصر واحد في المصفوفة ليست ذرية. يشمل ذلك التكرار، والفحص، والفرز، وتقسيم ودمج المصفوفات.

على سبيل المثال، ضع في اعتبارك البرنامج التالي:

let size = 100_000_000
let a = ArrayLabels.make size 1
let d1 = Domain.spawn (fun () ->
   ArrayLabels.iteri ~f:(fun i x -> a.(i) <- x + 1) a
)
let d2 = Domain.spawn (fun () ->
  ArrayLabels.iteri ~f:(fun i x -> a.(i) <- 2 * x + 1) a
)
let () = Domain.join d1; Domain.join d2

بعد تنفيذ هذا الكود، كل حقل في المصفوفة a إما 2 أو 3 أو 4 أو 5. إذا كانت الذرية مطلوبة، فيجب على المستخدم تنفيذ المزامنة الخاصة به (على سبيل المثال، باستخدام Mutex.t).

سباقات البيانات

إذا كانت نطاقات أخرى تصل فقط إلى أجزاء منفصلة من المصفوفة، فإن السلوك المرصود يعادل بعض التداخل التسلسلي للعمليات من النطاقين.

يُقال أن سباق البيانات يحدث عندما يصل نطاقان إلى نفس عنصر المصفوفة دون مزامنة، وعلى الأقل واحد من a

تُعرّف عمليات الوصول المتزامنة على نفس العنصر في مصفوفة ما بأنها "سباقات البيانات" (data races). في غياب سباقات البيانات، يكون السلوك المرصود مكافئًا لبعض التداخلات المتسلسلة للعمليات من نطاقات مختلفة.

كلما أمكن، يجب تجنب سباقات البيانات باستخدام المزامنة لتنظيم عمليات الوصول إلى عناصر المصفوفة.

في الواقع، في وجود سباقات البيانات، لن تتعطل البرامج ولكن السلوك المرصود قد لا يكون مكافئًا لأي تداخل متسلسل للعمليات من نطاقات مختلفة. ومع ذلك، حتى في وجود سباقات البيانات، ستقوم عملية القراءة بإرجاع قيمة لعملية كتابة سابقة إلى هذا الموقع (مع استثناءات قليلة لمصفوفات الأعداد العشرية).

مصفوفات الأعداد العشرية

تتمتع مصفوفات الأعداد العشرية باثنين من التحذيرات الإضافية في وجود سباقات البيانات.

أولاً، قد تقوم عملية النسخ (blit) بنسخ مصفوفة بايت ببايت. قد تؤدي سباقات البيانات بين عملية نسخ كهذه وعملية أخرى إلى إنتاج قيم مفاجئة بسبب التمزق (tearing): قد تؤدي الكتابات الجزئية المتداخلة مع عمليات أخرى إلى إنشاء قيم عشرية لن تكون موجودة مع تنفيذ متسلسل.

على سبيل المثال، في نهاية:

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
قد تحتوي المصفوفة res على قيم ليست 0. ولا max_float.

ثانياً، على المعماريات ذات 32 بت، يتضمن الحصول على حقل أو تعيينه وصولين منفصلين للذاكرة. في وجود سباقات البيانات، قد يلاحظ المستخدم التمزق (tearing) على أي عملية.
