Function/Subroutine Documentation

STGSJA computes the Schur decomposition of a matrix pair (A, B) in general triangular form.

This routine is part of the "Generalized Schur Decomposition" routines.

Arguments:

JOBU

CHARACTER*1. On entry, JOBU specifies whether to compute the matrix U. JOBU = 'U': The orthogonal matrix U is computed. JOBU = 'N': U is not computed.

On exit: U contains the orthogonal matrix U.

If JOBU = 'N', U is not referenced.

JOBV

CHARACTER*1. On entry, JOBV specifies whether to compute the matrix V. JOBV = 'V': The orthogonal matrix V is computed. JOBV = 'N': V is not computed.

On exit: V contains the orthogonal matrix V.

If JOBV = 'N', V is not referenced.

JOBQ

CHARACTER*1. On entry, JOBQ specifies whether to compute the matrix Q. JOBQ = 'Q': The orthogonal matrix Q is computed. JOBQ = 'N': Q is not computed.

On exit: Q contains the orthogonal matrix Q.

If JOBQ = 'N', Q is not referenced.

M

INTEGER. The number of rows of the matrix A. M >= 0.

N

INTEGER. The number of columns of the matrix A. N >= 0.

K

INTEGER. The number of rows of the matrix B. K >= 0.

L

INTEGER. The number of columns of the matrix B. L >= 0.

A

REAL array, dimension (LDA,N). On entry, the leading M-by-N part of the array A must contain the matrix A.

On exit, if JOBU = 'U', the leading M-by-N part of A contains the upper triangular matrix.

If JOBU = 'N', A is not referenced.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,M) if JOBU = 'U'; LDA >= 1 otherwise.

B

REAL array, dimension (LDB,L). On entry, the leading K-by-L part of the array B must contain the matrix B.

On exit, if JOBV = 'V', the leading K-by-L part of B contains the upper triangular matrix.

If JOBV = 'N', B is not referenced.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1,K) if JOBV = 'V'; LDB >= 1 otherwise.

U

REAL array, dimension (LDU,N). On entry, if JOBU = 'U', U must contain a matrix U1 (usually the orthogonal matrix returned by SGGSVP). On exit, if JOBU = 'I', U contains the orthogonal matrix U; if JOBU = 'U', U contains the product U1*U. If JOBU = 'N', U is not referenced.

LDU

INTEGER. The leading dimension of the array U. LDU >= max(1,M) if JOBU = 'U'; LDU >= 1 otherwise.

V

REAL array, dimension (LDV,P). On entry, if JOBV = 'V', V must contain a matrix V1 (usually the orthogonal matrix returned by SGGSVP). On exit, if JOBV = 'I', V contains the orthogonal matrix V; if JOBV = 'V', V contains the product V1*V. If JOBV = 'N', V is not referenced.

LDV

INTEGER. The leading dimension of the array V. LDV >= max(1,P) if JOBV = 'V'; LDV >= 1 otherwise.

Q

REAL array, dimension (LDQ,N). On entry, if JOBQ = 'Q', Q must contain a matrix Q1 (usually the orthogonal matrix returned by SGGSVP). On exit, if JOBQ = 'I', Q contains the orthogonal matrix Q; if JOBQ = 'Q', Q contains the product Q1*Q. If JOBQ = 'N', Q is not referenced.

LDQ

INTEGER. The leading dimension of the array Q. LDQ >= max(1,N) if JOBQ = 'Q'; LDQ >= 1 otherwise.

Z

REAL array, dimension (LDZ,P). On entry, if JOBZ = 'Z', Z must contain a matrix Z1 (usually the orthogonal matrix returned by SGGSVP). On exit, if JOBZ = 'I', Z contains the orthogonal matrix Z; if JOBZ = 'Z', Z contains the product Z1*Z. If JOBZ = 'N', Z is not referenced.

LDZ

INTEGER. The leading dimension of the array Z. LDZ >= max(1,P) if JOBZ = 'Z'; LDZ >= 1 otherwise.

ALPHA

REAL array, dimension (min(M,N,K,L)).

See ALPHA in STGEQR.

BETA

REAL array, dimension (min(M,N,K,L)).

See BETA in STGEQR.

WORK

REAL array, dimension (2*N).

LWORK

INTEGER. The dimension of the array WORK. LWORK >= 2*N.

INFO

INTEGER. = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value. = 1: the procedure does not converge after MAXIT cycles.

Internal Parameters

MAXIT

INTEGER. MAXIT specifies the total loops that the iterative procedure may take. If after MAXIT cycles, the routine fails to converge, we return INFO = 1.

Further Details:




!>
!>  STGSJA essentially uses a variant of Kogbetliantz algorithm to reduce
!>  min(L,M-K)-by-L triangular (or trapezoidal) matrix A23 and L-by-L
!>  matrix B13 to the form:
!>
!>           U1**T *A13*Q1 = C1*R1; V1**T *B13*Q1 = S1*R1,
!>
!>  where U1, V1 and Q1 are orthogonal matrix, and Z**T is the transpose
!>  of Z.  C1 and S1 are diagonal matrices satisfying
!>
!>                C1**2 + S1**2 = I,
!>
!>  and R1 is an L-by-L nonsingular upper triangular matrix.
!>
