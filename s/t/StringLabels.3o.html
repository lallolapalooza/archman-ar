سلاسل نصية.

السلسلة النصية s بطول n هي تسلسل قابل للفهرسة وغير قابل للتغيير من n بايت. لأسباب تاريخية، يشار إلى هذه البايتات باسم الأحرف.

يتم تعريف دلالات وظائف السلاسل النصية من حيث الفهارس والمواقع. يتم تصويرها ووصفها على النحو التالي.

المواقع 0 1 2 3 4 n-1 n +---+---+---+---+ +-----+ الفهارس | 0 | 1 | 2 | 3 | ... | n-1 | +---+---+---+---+ +-----+

-الفهرس i للسلسلة s هو عدد صحيح في النطاق [ 0 ; n-1 ]. يمثل البايت (الحرف) i من s والذي يمكن الوصول إليه باستخدام عامل الفهرسة للسلسلة ذي الوقت الثابت s.[i].

-الموقع i للسلسلة s هو عدد صحيح في النطاق [ 0 ; n ]. يمثل إما نقطة بداية السلسلة، أو النقطة بين فهرسين، أو نقطة نهاية السلسلة. فهرس البايت i يقع بين الموقع i و i+1.

يُقال إن عددين صحيحين start و len يحددان سلسلة فرعية صالحة لـ s إذا كان len >= 0 و start و start+len هما موقعان للسلسلة s.

نص Unicode. بما أن السلاسل النصية هي تسلسلات عشوائية من البايتات، فيمكنها احتواء أي نوع من الترميزات النصية. ومع ذلك، فإن الترميز الموصى به لتخزين نص Unicode في سلاسل OCaml هو UTF-8. هذا هو الترميز المستخدم بواسطة تسلسلات Unicode النصية في تعريفات السلاسل. على سبيل المثال، السلسلة النصية "\u{1F42B}" هي ترميز UTF-8 لحرف Unicode U+1F42B.

تجاوز قابلية التعديل. قبل OCaml 4.02، كانت السلاسل النصية قابلة للتعديل في مكانها مثل التسلسلات القابلة للتعديل من البايتات Bytes.t. احتوى OCaml 4 على خيارات تجميع مختلفة وخيارات تكوين لدعم الفترة الانتقالية من السلاسل النصية القابلة للتعديل إلى غير القابلة للتعديل. لم تعد هذه الخيارات متاحة، والسلاسل النصية الآن غير قابلة للتعديل دائمًا.

يمكن استخدام النسخة المسماة (labeled) لهذه الوحدة كما هو موضح في الوحدة StdLabels.

السلاسل النصية

type t = string

النوع للسلاسل النصية.

val make : int -> char -> string

make n c هي سلسلة نصية بطول n تحتوي كل فهرس فيها على الحرف c.

يثير Invalid_argument إذا كان n < 0 أو n > Sys.max_string_length.

val init : int -> f:(int -> char) -> string

init n ~f هي سلسلة نصية بطول n حيث يحتوي الفهرس i على الحرف f i (يتم استدعاؤه بترتيب الفهرس المتزايد).

منذ 4.02

يثير Invalid_argument إذا كان n < 0 أو n > Sys.max_string_length.

val empty : string

منذ 4.13

val length : string -> int

length s هو طول (عدد البايتات/الأحرف) للسلسلة s.

val get : string -> int -> char

get s i هو الحرف في الفهرس i في السلسلة s. هذا يماثل كتابة s.[i].

يثير Invalid_argument إذا كان i ليس فهرسًا صالحًا في s.

val of_bytes : bytes -> string

الدمج

ملاحظة. عامل التشغيل الثنائي (^) يدمج سلسلتين نصيتين.

val concat : sep:string -> string list -> string

concat ~sep ss يدمج قائمة السلاسل النصية ss، مع إدراج سلسلة الفاصل sep بين كل منها.

يثير Invalid_argument إذا كانت النتيجة أطول من Sys.max_string_length بايت.

val cat : string -> string -> string

cat s1 s2 يدمج s1 و s2 ( s1 ^ s2 ).

منذ 4.13

يثير Invalid_argument إذا كانت النتيجة أطول من Sys.max_string_length بايت.

المحددات والمقارنات

val equal : t -> t -> bool

equal s0 s1 تكون true إذا وفقط إذا كانت s0 و s1 متساويتين حرفًا بحرف.

منذ 4.05

val compare : t -> t -> int

compare s0 s1 يرتب s0 و s1 أبجديًا. compare تعمل مثل compare على السلاسل النصية ولكنها قد تكون أكثر كفاءة.

val starts_with : prefix:string -> string -> bool

starts_with ~prefix s تكون true إذا وفقط إذا كانت s تبدأ بـ prefix.

منذ 4.13

val ends_with : suffix:string -> string -> bool

ends_with ~suffix s تكون true إذا وفقط إذا كانت s تنتهي بـ suffix.

منذ 4.13

val contains_from : string -> int -> char -> bool

contains_from s start c تكون true إذا وفقط إذا كان الحرف c يظهر في s بعد الموقع start.

يثير Invalid_argument إذا كان start ليس موقعًا صالحًا في s.

val rcontains_from : string -> int -> char -> bool

rcontains_from s stop c تكون true إذا وفقط إذا كان الحرف c يظهر في s قبل الموقع stop+1.

يثير Invalid_argument إذا كان stop < 0 أو stop+1 ليس موقعًا صالحًا في s.

val contains : string -> char -> bool

contains s c يساوي String.contains_from s 0 c.

استخراج السلاسل الفرعية

val sub : string -> pos:int -> len:int -> string

sub s ~pos ~len هي سلسلة نصية بطول len، تحتوي على السلسلة الفرعية من s التي تبدأ بالموقع pos ولها طول len.

يثير Invalid_argument إذا لم يحدد pos و len سلسلة فرعية صالحة من s.

val split_on_char : sep:char -> string -> string list

split_on_char ~sep s هي قائمة بجميع السلاسل النصية الفرعية (المحتمل أن تكون فارغة) من s التي تفصلها الحرف sep. إذا كانت s فارغة، فالنتيجة هي القائمة أحادية العنصر [""].

يتم تحديد نتيجة الدالة من خلال الثوابت التالية:

-القائمة ليست فارغة.

-دمج عناصرها باستخدام sep كمفصل يعيد سلسلة نصية مساوية للمدخل ( concat (make 1 sep)
(split_on_char sep s) = s ).

-لا تحتوي أي سلسلة نصية في النتيجة على الحرف sep.

التحويل

val map : f:(char -> char) -> string -> string

map f s هي السلسلة النصية الناتجة عن تطبيق f على جميع أحرف s بترتيب متزايد.

منذ 4.00

val mapi : f:(int -> char -> char) -> string -> string

mapi ~f s تشبه StringLabels.map ولكن يتم تمرير فهرس الحرف أيضًا إلى f.
