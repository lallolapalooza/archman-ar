Detailed Description

The C++ standard library provides internationalization through locales. The time_get facet is used to format and parse time and date information. This class, time_get_byname, is a specific implementation of time_get for a particular locale.

The time_get_byname class defines the interface for retrieving the date, time, monthname, and weekday strings from input, based on the locale's conventions.

4 consecutive digits are interpreted as a full year. If there are exactly 2 consecutive digits, the library interprets this as the number of years since 1900.

If an error occurs before the end, err |= ios_base::failbit. If parsing reads all the characters, err |= ios_base::eofbit.
