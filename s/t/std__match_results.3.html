template<typename _Bi_iter, typename _Alloc = std::allocator<sub_match<_Bi_iter> >> class std::match_results

Derived from std::regex_iterator.

Description

The class template std::match_results is a container that holds the results of a regular expression match.

The template parameters are:

_Bi_iter
The type of the iterators used to designate the sequence to be searched.
_Alloc
The allocator type used to manage the storage of the match results.

It stores the sub-matches that result from a regex search. Each element in the container is a sub_match object, which represents a portion of the sequence that matched a sub-expression.
