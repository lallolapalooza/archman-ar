Stream State and Formatting

The primary function of this class is to manage the state and formatting of an output stream. This includes the stream's error state, its locale, and various formatting flags.

Error State

The stream maintains an error state indicated by `iostate` flags: `goodbit`, `eofbit`, `failbit`, and `badbit`. `goodbit` indicates no error has occurred. The other bits indicate specific error conditions. An exception can be configured to be thrown when `badbit` or `failbit` are set using the `exceptions()` member function.

Locale

The stream uses a `locale` object to adapt to local conventions for character classification, number formatting, etc. The locale can be changed using the `imbue()` member function.

Formatting Flags

Various flags control the format of output operations. These include flags for base (decimal, octal, hex), floating-point notation (fixed, scientific), alignment (left, right, internal), and others like `boolalpha`, `showbase`, `showpos`, `uppercase`, `unitbuf`, and `skipws`.

Formatting flags are manipulated using `setf()`, `unsetf()`, and `flags()`.

Stream Buffer

The `basic_ios` class holds a pointer to a `basic_streambuf` object, which is responsible for the actual input/output operations. This pointer can be changed using `rdbuf()`.

Formatted Output Functions

These functions format their arguments according to the stream's current formatting flags and locale, and then insert the formatted data into the stream.

Each formatted output function starts by constructing a temporary object of type `std::basic_ostream::sentry`. This object performs several actions before the actual output occurs. First, it checks if the stream is in a good state (`!fail()`). If not, it does nothing further. If the stream is good, it may tie the stream to another stream (if `tie()` is set) and flushes the tied stream. After these preparations, the actual data insertion takes place.

If an exception is thrown during insertion, `ios_base::badbit` will be turned on in the stream's error state without causing an `ios_base::failure` to be thrown. The original exception will then be rethrown.

Unformatted Output Functions
All the unformatted output functions have some common behavior. Each starts by constructing a temporary object of type std::basic_ostream::sentry. This has several effects, concluding with the setting of a status flag; see the sentry documentation for more.

If the sentry status is good, the function tries to generate whatever data is appropriate for the type of the argument.

If an exception is thrown during insertion, ios_base::badbit will be turned on in the stream's error state. If badbit is on in the stream's exceptions mask, the exception will be rethrown without completing its actions.
