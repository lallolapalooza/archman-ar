NAME

std::ctype - character classification and conversion facet

SYNOPSIS

template<typename _CharT>
class std::ctype : public std::__ctype_abstract_base< _CharT > {
public:
  // types
  typedef typename traits_type::char_type char_type;
  typedef std___ctype_abstract_base< _CharT >::mask mask;

  // access functions
  static locale::id id;
  explicit ctype(size_t = 0);
  explicit ctype(const mask* __tab, bool = false, size_t = 0);

  // virtual functions
  virtual bool do_is(mask __m, char_type __c) const;
  virtual const char_type* do_is(const char_type* __lo, const char_type* __hi, mask* __vec) const;
  virtual const char_type* do_scan_is(mask __m, const char_type* __lo, const char_type* __hi) const;
  virtual const char_type* do_scan_not(mask __m, const char_type* __lo, const char_type* __hi) const;
  virtual char_type do_tolower(char_type __c) const;
  virtual const char_type* do_tolower(char_type* __lo, const char_type* __hi) const;
  virtual char_type do_toupper(char_type __c) const;
  virtual const char_type* do_toupper(char_type* __lo, const char_type* __hi) const;
  virtual char do_narrow(char_type __c, char __dfault) const;
  virtual const char_type* do_narrow(const char_type* __lo, const char_type* __hi, char __dfault, char* __to) const;
  virtual char_type do_widen(char __c) const;
  virtual const char* do_widen(const char* __lo, const char* __hi, char_type* __to) const;

protected:
  // virtual functions
  virtual int do_encoding() const;
  virtual bool do_in_range(char_type __c) const;
  virtual size_t do_length(const char* __low, const char* __high) const;
  virtual const char* do_mbtowc(char_type* __out, const char* __in, size_t __n) const;
  virtual const char* do_wctomb(char* __out, char_type __wide) const;
};

DESCRIPTION

The template class std::ctype<_CharT> is a template that defines the interface for the character classification and conversion facet. It inherits from std::__ctype_abstract_base<_CharT>.

The ctype facet is used to classify characters (e.g., is it a digit, is it an alphabet character, is it whitespace) and to convert characters to and from uppercase and lowercase. It also handles narrowing (converting from _CharT to char) and widening (converting from char to _CharT).

The default ctype facet is created using the C locale.

The virtual functions declared in this class are hooks for derived classes to override the default behavior. The standard library provides specializations for char and wchar_t.

Referenced by std::ctype< _CharT >::do_narrow(), and std::ctype< _CharT >::do_narrow().

Narrow char_type array to char. This virtual function converts each char_type in the range [__lo,__hi) to char using the simplest reasonable transformation and writes the results to the destination array. For any element in the input that cannot be converted, __dfault is used instead.

do_narrow() is a hook for a derived facet to change the behavior of narrowing. do_narrow() must always return the same result for the same input.

Note: this is not what you want for codepage conversions. See codecvt for that.
