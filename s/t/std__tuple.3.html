std::tuple - Generic tuple

NAME

std::tuple - Generic tuple

SYNOPSIS

#include <tuple>

template< class... Types > class tuple;

Detailed Description

A tuple is a heterogeneous fixed-size collection of elements. The sizes and types of the elements are known at compile time.

Constructors

The std::tuple class has several constructors, including:

  • Default constructor: Creates an empty tuple.
  • Copy constructor: Creates a tuple by copying another tuple.
  • Move constructor: Creates a tuple by moving from another tuple.
  • Initializer list constructor: Creates a tuple from an initializer list.
  • Constructors that forward arguments: Creates a tuple by forwarding arguments to the element types' constructors.

Member functions

The std::tuple class provides the following member functions:

  • get<I>(tuple& t): Returns a reference to the element at index I.
  • get<I>(const tuple& t): Returns a const reference to the element at index I.
  • swap(tuple& other): Swaps the contents of the tuple with another tuple.

Non-member functions

The std::tuple class is supported by the following non-member functions:

  • std::get<I>(tuple& t): Returns a reference to the element at index I.
  • std::get<I>(const tuple& t): Returns a const reference to the element at index I.
  • std::swap(tuple& t1, tuple& t2): Swaps the contents of two tuples.
  • std::tuple_cat(tuples...): Concatenates multiple tuples.
  • std::make_tuple(args...): Creates a tuple from the given arguments.
  • std::tie(vars...): Creates a tuple of references to variables.

الدوال العضوية

توفر الفئة std::tuple الدوال العضوية التالية:
