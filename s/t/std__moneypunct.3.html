NAME

std::moneypunct - Formats for monetary punctuation.

SYNOPSIS

#include <locale>

template<typename _CharT, bool _Intl>
class std::moneypunct {
public:
  // types
  typedef _CharT char_type;
  typedef std::basic_string<_CharT> string_type;

  // virtual members
  virtual ~moneypunct();
  virtual string_type do_curr_symbol() const;
  virtual string_type do_format_decimal_point() const;
  virtual string_type do_format_grouping() const;
  virtual string_type do_format_negative_pattern() const;
  virtual string_type do_format_positive_pattern() const;
  virtual char_type do_grouping_separator() const;
  virtual char_type do_decimal_point() const;
  virtual string_type do_negative_sign() const;
  virtual string_type do_positive_sign() const;
  virtual char_type do_thousands_sep() const;

  // string formatting, may be overridden
  string_type curr_symbol() const;
  string_type format_decimal_point() const;
  string_type format_grouping() const;
  string_type format_negative_pattern() const;
  string_type format_positive_pattern() const;
  char_type grouping_separator() const;
  char_type decimal_point() const;
  string_type negative_sign() const;
  string_type positive_sign() const;
  char_type thousands_sep() const;

  // static data members
  static const bool intl;
  static const std::locale::id id;
};

Detailed Description

The C++ standard library provides locale-specific information concerning the formatting of monetary values. This information is encapsulated in the std::moneypunct class template.

The template takes two parameters:

  • _CharT: The character type used by the locale (e.g., char or wchar_t).
  • _Intl: A boolean value indicating whether to use international formatting conventions (true) or national conventions (false).

The std::moneypunct class is a locale::facet, meaning it is part of a locale object and can be accessed using the locale::use_facet function.

It provides methods to retrieve information such as:

  • Currency symbol (curr_symbol())
  • Decimal point character (decimal_point())
  • Thousands separator character (thousands_sep())
  • Formatting patterns for positive and negative amounts (pos_format(), neg_format())
  • Positive and negative sign strings (positive_sign(), negative_sign())

The actual locale-specific values are obtained by calling the virtual functions prefixed with do_ (e.g., do_curr_symbol()). The non-virtual functions (e.g., curr_symbol()) are provided as a convenience and call their corresponding do_ functions.

The intl static member indicates whether the facet uses international formatting conventions.

The id static member is used to identify the facet within a locale object.

template<typename _CharT, bool _Intl> string_type std::moneypunct< _CharT, _Intl >::pos_format () const [inline]

Return pattern for positive money values. This function returns a string_type describing the formatting of positive money values. It does so by returning returning moneypunct<char_type>::do_format_positive_pattern().

The pattern has 4 fields describing the ordering of symbol, sign, value, and none or space. There must be one of each in the pattern. The none and space enums may not appear in the first field and space may not appear in the final field.

The parts of a money string must appear in the order indicated by the fields of the pattern. The symbol field indicates that the value of curr_symbol() may be present. The sign field indicates that the value of positive_sign() or negative_sign() must be present. The value field indicates that the absolute value of the money amount is present. none indicates 0 or more whitespace characters, except at the end, where it permits no whitespace. space indicates that 1 or more whitespace characters must be present.

For example, for the US locale and pos_format() pattern {symbol,sign,value,none}, curr_symbol() == '$' positive_sign() == '+', and value 10.01, and options set to force the symbol, the corresponding string is $+10.01.

Returns

Pattern for positive money values.

References do_format_positive_pattern().
