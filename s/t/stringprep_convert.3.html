stringprep_convert(3)

الحزمة: libidn

التراخيص: GPL3, LGPL

stringprep_convert(3) libidn stringprep_convert(3)

اسم

stringprep_convert - دالة API

ملخص

#include <stringprep.h>

char * stringprep_convert(const char * str, const char * to_codeset, const char * from_codeset);

المعلمات

const char * str
سلسلة الإدخال ذات الإنهاء الصفري.
const char * to_codeset
اسم مجموعة الأحرف الوجهة.
const char * from_codeset
اسم مجموعة الأحرف الأصلية، كما تستخدمها str.

الوصف

تحويل السلسلة من مجموعة أحرف إلى أخرى باستخدام دالة النظام iconv().

القيمة المعادة: تعيد سلسلة جديدة ذات إنهاء صفري وهي str محولة إلى to_codeset.
