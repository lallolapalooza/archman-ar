Detailed Description

The C++ standard library provides two template classes for manipulating sequences of characters: std::basic_string and std::string. The latter is an instantiation of the former with character type char, character traits type std::char_traits<char>, and an allocator type std::allocator<char>.

std::basic_string is a template class that encapsulates many of the string manipulation operations. It is a sequence container that supports random access iterators. It is similar to std::vector<T, Allocator> but with additional string-specific operations.

This class is defined in the <string> header.
