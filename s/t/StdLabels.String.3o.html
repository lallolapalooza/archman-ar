النوع للسلاسل النصية.

val make : int -> char -> string

make n c هي سلسلة نصية بطول n تحتوي على الحرف c في كل موقع.

تثير Invalid_argument إذا كان n < 0 أو n > Sys.max_string_length.

val init : int -> f:(int -> char) -> string

init n ~f هي سلسلة نصية بطول n حيث يحمل الموقع i الحرف f i (يتم استدعاؤها بترتيب المواقع المتزايدة).

val concat : sep:string -> string list -> string

concat ~sep ss يدمج قائمة السلاسل النصية ss، مع إدراج السلسلة الفاصلة sep بين كل منها.

تثير Invalid_argument إذا كانت النتيجة أطول من Sys.max_string_length بايت.

val cat : string -> string -> string

cat s1 s2 يدمج s1 و s2 ( s1 ^ s2 ).

val contains_from : string -> int -> char -> bool

contains_from s start c هي true إذا وفقط إذا كان الحرف c يظهر في s بعد الموقع start.

تثير Invalid_argument إذا كان start ليس موقعًا صالحًا في s.

val rcontains_from : string -> int -> char -> bool

rcontains_from s stop c هي true إذا وفقط إذا كان الحرف c يظهر في s قبل الموضع stop+1.

تثير Invalid_argument إذا كان stop < 0 أو stop+1 ليس موقعًا صالحًا في s.

val contains : string -> char -> bool

contains s c هو String.contains_from s 0 c.

استخراج الأجزاء الفرعية

val sub : string -> pos:int -> len:int -> string

sub s ~pos ~len هي سلسلة نصية بطول len، تحتوي على الجزء الفرعي من s الذي يبدأ في الموقع pos وله طول len.

تثير Invalid_argument إذا كان pos و len لا يحددان جزءًا فرعيًا صالحًا من s.

val split_on_char : sep:char -> string -> string list

split_on_char ~sep s هي قائمة بكل الأجزاء الفرعية (قد تكون فارغة) للسلسلة s التي يتم فصلها بالحرف sep. إذا كانت s فارغة، فإن النتيجة هي قائمة أحادية [""].

يتم تحديد نتيجة الدالة بالثوابت التالية:

-القائمة ليست فارغة.

-دمج عناصرها باستخدام sep كمحدد يعيد سلسلة نصية تساوي المدخل ( concat (make 1 sep)
(split_on_char sep s) = s ).

-لا تحتوي أي سلسلة نصية في النتيجة على الحرف sep.

val fold_left : f:('acc -> char -> 'acc) -> init:'acc -> string -> 'acc

fold_left f x s يحسب f (... (f (f x s.[0]) s.[1]) ...) s.[n-1] ، حيث n هو طول السلسلة النصية s.

val fold_right : f:(char -> 'acc -> 'acc) -> string -> init:'acc -> 'acc

fold_right f s x يحسب f s.[0] (f s.[1] ( ... (f s.[n-1] x) ...)) ، حيث n هو طول السلسلة النصية s.

val trim : string -> string

trim s هو s بدون مسافات بيضاء بادئة وخلفية. أحرف المسافات البيضاء هي: ' ' ، '\x0C' (تغذية نموذج)، '\n' ، '\r' ، و '\t'.

منذ 4.00

val escaped : string -> string

escaped s هي s مع تمثيل الأحرف الخاصة بتسلسلات الهروب، باتباع الاتفاقيات المعجمية لـ OCaml.

يتم تمثيل جميع الأحرف خارج النطاق القابل للطباعة لـ US-ASCII [0x20;0x7E]، بالإضافة إلى الشرطة المائلة العكسية (0x2F) وعلامة الاقتباس المزدوجة (0x22).

الدالة Scanf.unescaped هي عكس أيسر لـ escaped، أي Scanf.unescaped (escaped s) = s لأي سلسلة نصية s (ما لم تفشل escaped s).

تثير Invalid_argument إذا كانت النتيجة أطول من Sys.max_string_length بايت.

val uppercase_ascii : string -> string

uppercase_ascii s هي s مع تحويل جميع الأحرف الصغيرة إلى أحرف كبيرة، باستخدام مجموعة أحرف US-ASCII.
