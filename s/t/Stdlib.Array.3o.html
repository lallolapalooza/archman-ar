اسم مستعار لنوع المصفوفات.

قيمة length : 'a array -> int

تُرجع طول (عدد العناصر) للمصفوفة المعطاة.

قيمة get : 'a array -> int -> 'a

get a n تُرجع العنصر رقم n من المصفوفة a. العنصر الأول رقمه 0. العنصر الأخير رقمه length a - 1. يمكنك أيضًا كتابة a.(n) بدلًا من get a n.

يثير Invalid_argument إذا كان n خارج النطاق من 0 إلى length a - 1.

قيمة set : 'a array -> int -> 'a -> unit

set a n x تعدل المصفوفة a باستبدال العنصر رقم n بالقيمة x. يمكنك أيضًا كتابة a.(n) <- x بدلًا من set a n x.

يثير Invalid_argument إذا كان n خارج النطاق من 0 إلى length a - 1.

قيمة make : int -> 'a -> 'a array

make n x تُرجع مصفوفة جديدة بطول n، مهيأة بالقيمة x. جميع عناصر هذه المصفوفة الجديدة متساوية فيزيائيًا مع x في البداية (بمعنى العامل ==). لذلك، إذا كان x قابلًا للتغيير، فسوف تتم مشاركته بين جميع عناصر المصفوفة. تعديل x عبر أحد عناصر المصفوفة سيعدل جميع العناصر الأخرى في نفس الوقت.

يثير Invalid_argument إذا كان n < 0 أو n > Sys.max_array_length. إذا كانت قيمة x عددًا عشريًا، فإن الحد الأقصى للحجم هو فقط Sys.max_array_length / 2.

قيمة create_float : int -> float array

create_float n تُرجع مصفوفة جديدة من الأعداد العشرية بطول n، مع بيانات غير مهيأة.

قيمة init : int -> (int -> 'a) -> 'a array

init n f تُرجع مصفوفة جديدة بطول n، حيث يتم تهيئة العنصر رقم i بنتيجة f i. بعبارة أخرى، init n f يجدول نتائج f المطبقة بترتيب على الأعداد الصحيحة من 0 إلى n-1.

يثير Invalid_argument إذا كان n < 0 أو n > Sys.max_array_length. إذا كان نوع الإرجاع لـ f هو float، فإن الحد الأقصى للحجم هو فقط Sys.max_array_length / 2.

قيمة make_matrix : int -> int -> 'a -> 'a array array

make_matrix dimx dimy e تُرجع مصفوفة ثنائية الأبعاد (مصفوفة من المصفوفات) بأبعاد dimx و dimy. جميع عناصر هذه المصفوفة الجديدة متساوية فيزيائيًا مع e في البداية. يمكن الوصول إلى العنصر ( x,y ) للمصفوفة m باستخدام الترميز m.(x).(y).

يثير Invalid_argument إذا كان dimx أو dimy سالبًا أو أكبر من Sys.max_array_length. إذا كانت قيمة e عددًا عشريًا، فإن الحد الأقصى للحجم هو فقط Sys.max_array_length / 2.

قيمة init_matrix : int -> int -> (int -> int -> 'a) -> 'a array array

init_matrix dimx dimy f تُرجع مصفوفة ثنائية الأبعاد (مصفوفة من المصفوفات) بأبعاد dimx و dimy، حيث يتم تهيئة العنصر في الموضع ( x,y ) بالقيمة f x y. يمكن الوصول إلى العنصر ( x,y ) للمصفوفة m باستخدام الترميز m.(x).(y).

قيمة append : 'a array -> 'a array -> 'a array

append v1 v2 تُرجع مصفوفة جديدة تحتوي على ربط المصفوفتين v1 و v2.

يثير Invalid_argument إذا كان length v1 + length v2 > Sys.max_array_length.

قيمة concat : 'a array list -> 'a array

هي نفس Array.append، ولكنها تربط قائمة من المصفوفات.

قيمة sub : 'a array -> int -> int -> 'a array

sub a pos len تُرجع مصفوفة جديدة بطول len، تحتوي على العناصر من الرقم pos إلى pos + len - 1 من المصفوفة a.

يثير Invalid_argument إذا لم يكن pos و len يشيران إلى مصفوفة فرعية صالحة من a؛ أي إذا كان pos < 0 أو len < 0 أو pos + len > length a.

قيمة copy : 'a array -> 'a array

copy a تُرجع نسخة من a، أي مصفوفة جديدة تحتوي على نفس عناصر a.

قيمة fill : 'a array -> int -> int -> 'a -> unit

fill a pos len x تعدل المصفوفة a باستبدال العناصر من الرقم pos إلى pos + len - 1 بالقيمة x.

يثير Invalid_argument إذا لم يكن pos و len يشيران إلى مصفوفة فرعية صالحة من a.

قيمة blit : 'a array -> int -> 'a array -> int -> int -> unit

blit src src_pos dst dst_pos len تنسخ len عنصرًا من src، بدءًا من العنصر رقم src_pos، إلى dst، بدءًا من العنصر رقم dst_pos. تعمل بشكل صحيح حتى لو كانت src و dst نفس المصفوفة، وتتداخل الكتل المصدر والوجهة.

يثير Invalid_argument إذا لم يكن src_pos و len يشيران إلى مصفوفة فرعية صالحة من src، أو إذا لم يكن dst_pos و len يشيران إلى مصفوفة فرعية صالحة من dst.

قيمة to_list : 'a array -> 'a list

to_list a تُرجع قائمة بجميع عناصر a.

قيمة of_list : 'a list -> 'a array

of_list l تُرجع مصفوفة جديدة تحتوي على عناصر l.

يثير Invalid_argument إذا كان طول l أكبر من Sys.max_array_length.

equal eq a b تكون true إذا وفقط إذا كان a و b لهما نفس الطول n ولكل i في [ 0 ; n-1 ]، فإن eq a.(i) b.(i) تكون true.

compare cmp a b تقارن a و b وفقًا لترتيب قصير بالمعنى المعجمي، أي المصفوفات الأقصر أصغر، والمصفوفات ذات الطول المتساوي تتم مقارنتها بالترتيب المعجمي باستخدام cmp لمقارنة العناصر.

المكررات

قيمة iter : ('a -> unit) -> 'a array -> unit

iter f a تطبق الدالة f على جميع عناصر a. وهي تعادل f a.(0); f a.(1); ...; f a.(length a - 1); ().

قيمة iteri : (int -> 'a -> unit) -> 'a array -> unit

هي نفس Array.iter، ولكن يتم تطبيق الدالة على فهرس العنصر كوسيط أول والعنصر كوسيط ثانٍ.

قيمة map : ('a -> 'b) -> 'a array -> 'b array

map f a تطبق الدالة f على جميع عناصر a وتبني مصفوفة بالنتائج من f المطبقة على كل عنصر من عناصر a: [| f a.(0); f a.(1); ...; f a.(length a - 1) |].

مصفوفات الفاصلة العائمة (Float arrays)

تحتوي مصفوفات الفاصلة العائمة على ملاحظتين إضافيتين فيما يتعلق بتضارب البيانات (data races).

أولاً، يمكن لعملية النسخ أن تنسخ مصفوفة بايت بايت. قد تؤدي تضاربات البيانات بين مثل هذه العملية والكتابة من نطاق آخر إلى ظهور قيم مفاجئة بسبب التمزق (tearing): الكتابات الجزئية المتداخلة مع عمليات من نطاقات أخرى يمكن أن تنشئ قيم فاصلة عائمة غير موجودة في التنفيذ المتسلسل.

على سبيل المثال، في نهاية الـ

let zeros = Array.make size 0.
let max_floats = Array.make size Float.max_float
let res = Array.copy zeros
let d1 = Domain.spawn (fun () -> Array.blit zeros 0 res 0 size)
let d2 = Domain.spawn (fun () -> Array.blit max_floats 0 res 0 size)
let () = Domain.join d1; Domain.join d2
قد تحتوي المصفوفة res على قيم ليست 0. وليست max_float.

ثانياً، في معماريات 32 بت، يتضمن الحصول على حقل أو تعيينه وصولين منفصلين للذاكرة. في وجود تضاربات البيانات، قد يلاحظ المستخدم التمزق في أي عملية.
