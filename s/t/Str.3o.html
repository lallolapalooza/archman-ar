التعابير النمطية

توفر مكتبة Str تعابير نمطية على سلاسل البايت. بشكل عام، هي غير مناسبة لمطابقة أحرف Unicode.

type regexp

نوع التعابير النمطية المترجمة.

val regexp : string -> regexp

ترجمة تعبير نمطي. يتم التعرف على التراكيب التالية:

- . تطابق أي حرف باستثناء حرف السطر الجديد.

- * (لاحقة) تطابق التعبير السابق صفرًا أو مرة واحدة أو أكثر.

- + (لاحقة) تطابق التعبير السابق مرة واحدة أو أكثر.

- ? (لاحقة) تطابق التعبير السابق مرة واحدة أو لا شيء.

- [..] مجموعة أحرف. يتم تمثيل النطاقات بـ -، كما في [a-z]. يشير ^ في البداية، كما في [^0-9]، إلى عكس المجموعة. لتضمين ] في مجموعة، اجعلها الحرف الأول في المجموعة. لتضمين - في مجموعة، اجعلها الحرف الأول أو الأخير في المجموعة.

- ^ تطابق بداية السطر: إما في بداية السلسلة النصية المطابقة، أو بعد حرف سطر جديد.

- $ تطابق نهاية السطر: إما في نهاية السلسلة النصية المطابقة، أو قبل حرف سطر جديد مباشرة.

- \| (بادئة) بديل بين تعبيرين.

- \(..\) تجميع وتسمية التعبير المغلق.

- \1 النص المطابق للتعبير الأول \(...\) ( \2 للثاني، وهكذا حتى \9).

- \b تطابق حدود الكلمة.

- \ تهرب الأحرف الخاصة. الأحرف الخاصة هي $^\.*+?[].

في التعابير النمطية، يتم استخدام حرف الشرطة المائلة العكسية بشكل متكرر؛ من الأسهل استخدام سلسلة نصية حرفية بأقواس {|...|} لتجنب الحاجة إلى تهريب الشرطات المائلة العكسية.

على سبيل المثال، التعبير التالي:

let r = Str.regexp {|hello \([A-Za-z]+\)|} in
      Str.replace_first r {|\1|} "hello world"
يعيد السلسلة النصية "world".

إذا كنت تريد تعبيرًا نمطيًا يطابق حرف شرطة مائلة عكسية حرفي، فأنت بحاجة إلى مضاعفته: Str.regexp {|\\|}.

يمكنك استخدام سلاسل نصية حرفية "..." أيضًا، على الرغم من أنك ستحتاج إلى تهريب الشرطات المائلة العكسية. يمكن إعادة كتابة المثال السابق بسلسلة نصية عادية كما يلي:

let r = Str.regexp "hello \\([A-Za-z]+\\)" in
      Str.replace_first r "\\1" "hello world"

ويصبح التعبير النمطي لمطابقة الشرطة المائلة العكسية شرطة مائلة عكسية رباعية: Str.regexp "\\\\".

val regexp_case_fold : string -> regexp

مثل regexp، ولكن التعبير المترجم يطابق النص في وضع غير حساس لحالة الأحرف.

val quote : string -> string

Str.quote s يعيد سلسلة نصية نمطية تطابق s بالضبط ولا شيء آخر.

val regexp_string : string -> regexp

Str.regexp_string s يعيد تعبيرًا نمطيًا يطابق s بالضبط ولا شيء آخر.

val regexp_string_case_fold : string -> regexp

Str.regexp_string_case_fold مشابه لـ Str.regexp_string، ولكن التعبير النمطي يطابق في وضع غير حساس لحالة الأحرف.

مطابقة وبحث السلاسل النصية

val string_match : regexp -> string -> int -> bool

string_match r s start تختبر ما إذا كانت سلسلة نصية فرعية من s تبدأ من الموضع start تتطابق مع التعبير النمطي r. الحرف الأول من السلسلة النصية له الموضع 0، كما هو معتاد.

val search_forward : regexp -> string -> int -> int

search_forward r s start تبحث في السلسلة النصية s عن سلسلة نصية فرعية تطابق التعبير النمطي r. يبدأ البحث من الموضع start ويتجه نحو نهاية السلسلة النصية. يعيد موضع السمة الأولى للسلسلة النصية الفرعية المطابقة.

Raises Not_found إذا لم يتم العثور على أي سلسلة نصية فرعية مطابقة.

val search_backward : regexp -> string -> int -> int

search_backward r s last تبحث في السلسلة النصية s عن سلسلة نصية فرعية تطابق التعبير النمطي r. يبدأ البحث أولاً بالسلاسل النصية الفرعية التي تبدأ من الموضع last ويتجه نحو بداية السلسلة النصية. يعيد موضع السمة الأولى للسلسلة النصية الفرعية المطابقة.

Raises Not_found إذا لم يتم العثور على أي سلسلة نصية فرعية مطابقة.

val string_partial_match : regexp -> string -> int -> bool

مشابه لـ Str.string_match، ولكنه يعيد أيضًا true إذا كانت السلسلة النصية الوسيطة هي بادئة لسلسلة نصية مطابقة. يشمل ذلك حالة المطابقة الكاملة.

val matched_string : string -> string

matched_string s تعيد السلسلة النصية الفرعية من s التي تطابقت مع آخر استدعاء لإحدى وظائف المطابقة أو البحث التالية:

- Str.string_match

- Str.search_forward

- Str.search_backward

- Str.string_partial_match

- Str.global_substitute

- Str.substitute_first

بشرط عدم استدعاء أي من الوظائف التالية بينهما:

- Str.global_replace

- Str.replace_first

- Str.split

- Str.bounded_split

- Str.split_delim

- Str.bounded_split_delim

- Str.full_split

- Str.bounded_full_split

ملاحظة: في حالة global_substitute و substitute_first، يكون استدعاء matched_string صالحًا فقط ضمن الوسيطة subst، وليس بعد عودة global_substitute أو substitute_first.

يجب على المستخدم التأكد من أن الوسيطة s هي نفس السلسلة النصية التي تم تمريرها إلى وظيفة المطابقة أو البحث.

val match_beginning : unit -> int

match_beginning() يعيد موضع السمة الأولى للسلسلة النصية الفرعية التي تطابقت مع آخر استدعاء لوظيفة مطابقة أو بحث (انظر Str.matched_string للتفاصيل).

val match_end : unit -> int

match_end() يعيد موضع السمة التالية لآخر حرف في السلسلة النصية الفرعية التي تطابقت مع آخر استدعاء لوظيفة مطابقة أو بحث (انظر Str.matched_string للتفاصيل).

val matched_group : int -> string -> string

matched_group n s يعيد السلسلة النصية الفرعية من s التي تطابقت مع المجموعة n من التعبير النمطي الذي تطابق مع آخر استدعاء لوظيفة مطابقة أو بحث (انظر Str.matched_string للتفاصيل). عندما تكون n تساوي 0، فإنها تعيد السلسلة النصية الفرعية المطابقة للتعبير النمطي الكامل. يجب على المستخدم التأكد من أن الوسيطة s هي نفس السلسلة النصية التي تم تمريرها إلى وظيفة المطابقة أو البحث.

Raises Not_found إذا لم تتطابق المجموعة n من التعبير النمطي. يمكن أن يحدث هذا مع المجموعات داخل البدائل \|، الخيارات ?، أو التكرارات *. على سبيل المثال، السلسلة النصية الفارغة ستتطابق مع \(a\)*، ولكن matched_group 1 "" سيطلق Not_found لأن المجموعة الأولى لم تتطابق.

val group_beginning : int -> int

group_beginning n يعيد موضع السمة الأولى للسلسلة النصية الفرعية التي تطابقت مع المجموعة n من التعبير النمطي الذي تطابق مع آخر استدعاء لوظيفة مطابقة أو بحث (انظر Str.matched_string للتفاصيل).

Raises Not_found إذا لم تتطابق المجموعة n من التعبير النمطي.

Raises Invalid_argument إذا كان هناك أقل من n مجموعة في التعبير النمطي.

Str - string manipulation with regular expressions

Matching and searching

val match_string : regexp -> string -> bool

match_string regexp s tests if the regular expression regexp matches the string s starting from the beginning of s.

val search_string : regexp -> string -> bool

search_string regexp s tests if the regular expression regexp matches anywhere in the string s.

val match_beginning : regexp -> string -> int

match_beginning regexp s returns the index of the first character of the substring of s that matches regexp. The match must start at the beginning of the string s.

val search_beginning : regexp -> string -> int

search_beginning regexp s returns the index of the first character of the first substring of s that matches regexp. If no match is found, Not_found is raised.

val matched_string : unit -> string

matched_string () returns the substring that was matched by the last call to a matching or searching function (see below). This function can only be called after a successful call to match_string, search_string, match_beginning, or search_beginning.

val matched_group : int -> unit -> string

matched_group n () returns the substring that was matched by the n-th group of the regular expression in the last call to a matching or searching function. Group 0 corresponds to the whole match.

val match_end : regexp -> string -> int

match_end regexp s returns the index of the character following the matched substring. The match must start at the beginning of the string s.

val search_end : regexp -> string -> int

search_end regexp s returns the index of the character following the first matched substring. If no match is found, Not_found is raised.

val match_offset : regexp -> string -> (int * int)

match_offset regexp s returns a pair of integers (first, last) such that first is the index of the first character of the matched substring, and last is the index of the character following the matched substring. The match must start at the beginning of the string s.

val search_offset : regexp -> string -> (int * int)

search_offset regexp s returns a pair of integers (first, last) such that first is the index of the first character of the first matched substring, and last is the index of the character following the matched substring. If no match is found, Not_found is raised.

val group_count : regexp -> string -> int

group_count regexp s returns the number of groups in the regular expression regexp. The last group is group n, where n is the result of group_count.

val match_groups : regexp -> string -> string list

match_groups regexp s returns the list of substrings matched by the groups of the regular expression regexp. The match must start at the beginning of the string s.

val search_groups : regexp -> string -> string list

search_groups regexp s returns the list of substrings matched by the groups of the first occurrence of regexp in s.

val group : int -> string -> string

group n s returns the substring corresponding to the n-th group of the regular expression that was matched by the last call to a matching or searching function (see Str.matched_string for details).

val pos_of_group : int -> int

pos_of_group n returns the position of the first character of the substring matched by the n th group of the regular expression that was matched by the last call to a matching or searching function (see Str.matched_string for details).

val group_len : int -> int

group_len n returns the length of the substring matched by the n th group of the regular expression that was matched by the last call to a matching or searching function (see Str.matched_string for details).

val group_bounded_pos : int -> int

group_bounded_pos n returns the position of the character following the last character of substring that was matched by the n th group of the regular expression that was matched by the last call to a matching or searching function (see Str.matched_string for details).

Raises Not_found if the n th group of the regular expression was not matched.

Raises Invalid_argument if there are fewer than n groups in the regular expression.

Replacement

val global_replace : regexp -> string -> string -> string

global_replace regexp templ s returns a string identical to s , except that all substrings of s that match regexp have been replaced by templ . The replacement template templ can contain \1 , \2 , etc; these sequences will be replaced by the text matched by the corresponding group in the regular expression. \0 stands for the text matched by the whole regular expression.

val replace_first : regexp -> string -> string -> string

Same as Str.global_replace , except that only the first substring matching the regular expression is replaced.

val global_substitute : regexp -> (string -> string) -> string -> string

global_substitute regexp subst s returns a string identical to s , except that all substrings of s that match regexp have been replaced by the result of function subst . The function subst is called once for each matching substring, and receives s (the whole text) as argument.

val substitute_first : regexp -> (string -> string) -> string -> string

Same as Str.global_substitute , except that only the first substring matching the regular expression is replaced.

val replace_matched : string -> string -> string

replace_matched repl s returns the replacement text repl in which \1 , \2 , etc. have been replaced by the text matched by the corresponding groups in the regular expression that was matched by the last call to a matching or searching function (see Str.matched_string for details). s must be the same string that was passed to the matching or searching function.

Splitting

val split : regexp -> string -> string list

split r s splits s into substrings, taking as delimiters the substrings that match r , and returns the list of substrings. For instance, split (regexp "[ \t]+") s splits s into blank-separated words. An occurrence of the delimiter at the beginning or at the end of the string is ignored.

val bounded_split : regexp -> string -> int -> string list

Same as Str.split , but splits into at most n substrings, where n is the extra integer parameter.

val split_delim : regexp -> string -> string list

Same as Str.split but occurrences of the delimiter at the beginning and at the end of the string are recognized and returned as empty strings in the result. For instance, split_delim (regexp " ") " abc " returns [""; "abc"; ""] , while split with the same arguments returns ["abc"] .

val bounded_split_delim : regexp -> string -> int -> string list

Same as Str.bounded_split , but occurrences of the delimiter at the beginning and at the end of the string are recognized and returned as empty strings in the result.

val full_split : regexp -> string -> split_result list

Same as Str.split_delim , but returns the delimiters as well as the substrings contained between delimiters. The former are tagged Delim in the result list; the latter are tagged Text . For instance, full_split (regexp "[{}]") "{ab}" returns [Delim "{"; Text "ab"; Delim "}"] .

val bounded_full_split : regexp -> string -> int -> split_result list

Same as Str.bounded_split_delim , but returns the delimiters as well as the substrings contained between delimiters. The former are tagged Delim in the result list; the latter are tagged Text .

Extracting substrings

val string_before : string -> int -> string

string_before s n returns the substring of all characters of s that precede position n (excluding the character at position n ).

val string_after : string -> int -> string

string_after s n returns the substring of all characters of s that follow position n (including the character at position n ).

val first_chars : string -> int -> string

first_chars s n returns the first n characters of s . This is the same function as Str.string_before .

val last_chars : string -> int -> string

last_chars s n returns the last n characters of s .
