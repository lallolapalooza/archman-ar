states(1)

الحزمة: enscript

التراخيص: GPL3

STATES(1) STATES STATES(1)

الاسم

states - أداة معالجة نصوص شبيهة بـ awk

الملخص

states [-hvV] [-D var=val] [-f file] [-o outputfile] [-p path] [-s startstate] [-W level] [filename ...]

الوصف

States هي أداة معالجة نصوص شبيهة بـ awk مع بعض الإضافات الخاصة بآلات الحالة. تم تصميمها لتلوين أكواد المصدر البرمجية وللمهام المشابهة التي تستفيد من معلومات الحالة في معالجة المدخلات.

في نقطة زمنية واحدة، تكون States في حالة واحدة، وكل منها مشابه جدًا لبيئة عمل awk، لديهم تعابير نمطية يتم مطابقتها من المدخلات وإجراءات يتم تنفيذها عند العثور على تطابق. من كتل الإجراءات، يمكن لـ states تنفيذ انتقالات للحالة؛ يمكنها الانتقال إلى حالة أخرى يتم من خلالها متابعة المعالجة. يتم تسجيل انتقالات الحالة بحيث يمكن لـ states العودة إلى الحالة التي استدعتها بمجرد انتهاء الحالة الحالية.

الاختلاف الأكبر بين states و awk، بخلاف إضافات آلة الحالة، هو أن states ليست موجهة بالأسطر. إنها تطابق رموز التعابير النمطية من المدخلات وبمجرد معالجة التطابق، تستمر في المعالجة من الموضع الحالي، وليس من بداية سطر الإدخال التالي.

الخيارات

-D var=val, --define=var=val
تعريف المتغير var ليأخذ القيمة النصية val. تعريفات سطر الأوامر تلغي تعريفات المتغيرات الموجودة في ملف الإعداد.
-f file, --file=file
قراءة تعريفات الحالة من الملف file. بشكل افتراضي، تحاول states قراءة تعريفات الحالة من الملف states.st في دليل العمل الحالي.
-h, --help
طباعة رسالة مساعدة مختصرة والخروج.
-o file, --output=file
حفظ الإخراج في الملف file بدلاً من طباعته على stdout.
-p path, --path=path
تعيين مسار التحميل إلى path. مسار التحميل الافتراضي هو الدليل الذي يتم تحميل ملف تعريفات الحالة منه.
-s state, --state=state
بدء التنفيذ من الحالة state. هذا التعريف يلغي حالة البداية التي تم حلها من كتلة start.
-v, --verbose
زيادة تفصيل البرنامج.
-V, --version
طباعة إصدار states والخروج.
-W level, --warning=level
تعيين مستوى التحذير إلى level. القيم الممكنة لـ level هي:
light
تحذيرات خفيفة (افتراضي)
all
جميع التحذيرات

ملفات برامج STATES

يمكن أن تحتوي ملفات برامج States على كتلة start، وكتل startrules و namerules لتحديد الحالة الابتدائية، وتعريفات state، و expressions.

كتلة start هي الـ main() في برنامج states، ويتم تنفيذها عند بدء تشغيل البرنامج النصي لكل ملف إدخال ويمكنها إجراء أي تهيئة يحتاجها البرنامج النصي. عادةً ما تستدعي أيضًا الدوال الأولية check_startrules() و check_namerules() التي تحدد الحالة الابتدائية من اسم ملف الإدخال أو البيانات الموجودة في بداية ملف الإدخال. إليك مثال لكتلة start تهيئ متغيرين وتجري عملية تحديد حالة البداية القياسية:

start
{
  a = 1;
  msg = "Hello, world!";
  check_startrules ();
  check_namerules ();
}

بعد معالجة كتلة البداية، تستمر معالجة المدخلات من الحالة الابتدائية.

يتم تحديد الحالة الابتدائية بواسطة المعلومات الموجودة في كتل startrules و namerules. تحتوي كلتا الكتلتين على أزواج من التعابير النمطية - رموز، عندما تتم مطابقة التعبير النمطي مع اسم ملف الإدخال أو بدايته، يتم تسمية الحالة الابتدائية بالرمز المقابل. على سبيل المثال، يمكن لقواعد البداية والاسم التالية التمييز بين ملفات C و Fortran:

namerules
{
  /\.(c|h)$/    c;
  /\.[fF]$/     fortran;
}
startrules
{
  /-\*- [cC] -\*-/      c;
  /-\*- fortran -\*-/   fortran;
}

إذا تم استخدام هذه القواعد مع كتلة البداية المعروضة سابقًا، فإن states تتحقق أولاً من بداية ملف الإدخال. إذا كان يحتوي على السلسلة النصية -*- c -*-، يُفترض أن الملف يحتوي على كود C ويتم بدء المعالجة من الحالة المسماة c. إذا كانت بداية ملف الإدخال تحتوي على السلسلة النصية -*- fortran -*-، فإن الحالة الابتدائية هي fortran. إذا لم تتطابق أي من قواعد البداية، يتم مطابقة اسم ملف الإدخال مع قواعد الاسم. إذا انتهى الاسم باللاحقة c أو C، ننتقل إلى الحالة c. إذا كانت اللاحقة f أو F، فإن الحالة الابتدائية هي fortran.

إذا فشلت كلتا قاعدتي البداية والاسم في تحديد حالة البداية، فإن states تقوم ببساطة بنسخ مدخلاتها إلى الإخراج دون تعديل.

يمكن أيضًا تحديد حالة البداية من سطر الأوامر باستخدام الخيار -s، --state.

تعريفات الحالة لها الصيغة التالية:

state { expr {statements} ... }

حيث expr هو: تعبير نمطي، تعبير خاص، أو رمز، و statements هي قائمة بالعبارات. عندما تتم مطابقة التعبير expr مع المدخلات، يتم تنفيذ كتلة العبارات. يمكن لكتلة العبارات استدعاء الدوال الأولية لـ states، أو الإجراءات الفرعية المعرفة من قبل المستخدم، أو استدعاء حالات أخرى، إلخ. بمجرد تنفيذ الكتلة، تستمر معالجة المدخلات من موضع الإدخال الحالي (والذي قد يكون قد تغير إذا قامت كتلة العبارات باستدعاء حالات أخرى).

يمكن استخدام التعبيرات الخاصة BEGIN و END بدلاً من expr. التعبير BEGIN يطابق بداية الحالة، ويتم استدعاء كتلته عند الدخول إلى الحالة. التعبير END يطابق نهاية الحالة، ويتم تنفيذ كتلته عندما تغادر states الحالة.

إذا كان expr رمزًا، يتم البحث عن قيمته في البيئة العامة، وإذا كان تعبيرًا نمطيًا، فسيتم مطابقته مع المدخلات، وإلا فسيتم تجاهل هذه القاعدة.

يمكن لملف برنامج states أيضًا أن يحتوي على تعابير على أعلى المستوى، ويتم تقييمها بعد تحليل ملف البرنامج وقبل معالجة أي ملفات إدخال أو تقييم كتلة start.

الدوال الأولية

call (symbol)
الانتقال إلى الحالة symbol ومتابعة معالجة ملف الإدخال من تلك الحالة. تعود الدالة بأي شيء تعيده عبارة return النهائية للحالة symbol.
calln (name)
مثل call ولكن يتم تقييم الوسيط name ويجب أن تكون قيمته سلسلة نصية. على سبيل المثال، يمكن استخدام هذه الدالة لاستدعاء حالة اسمها مخزن في متغير.
check_namerules ()
محاولة تحديد حالة البداية من قواعد namerules. تعود الدالة بـ 1 إذا تم تحديد حالة البداية أو 0 بخلاف ذلك.
check_startrules ()
محاولة تحديد حالة البداية من قواعد startrules. تعود الدالة بـ 1 إذا تم تحديد حالة البداية أو 0 بخلاف ذلك.
concat (str, ...)
ربط السلاسل النصية للوسائط وإرجاع النتيجة كسلسلة جديدة.
float (any)
تحويل الوسيط إلى رقم عائم.
getenv (str)
الحصول على قيمة

STATES PROGRAM FILES

The states program is described in the following files:

get (str)
Get the value of environment variable str. Returns an empty string if variable var is undefined.
int (any)
Convert argument to an integer number.
length (item, ...)
Count the length of argument strings or lists.
list (any, ...)
Create a new list which contains items any, ...
panic (any, ...)
Report a non-recoverable error and exit with status 1. Function never returns.
print (any, ...)
Convert arguments to strings and print them to the output.
range (source, start, end)
Return a sub-range of source starting from position start (inclusively) to end (exclusively). Argument source can be string or list.
regexp (string)
Convert string string to a new regular expression.
regexp_syntax (char, syntax)
Modify regular expression character syntaxes by assigning new syntax syntax for character char. Possible values for syntax are:
'w'
character is a word constituent
' '
character isn't a word constituent
regmatch (string, regexp)
Check if string string matches regular expression regexp. Functions returns a boolean success status and sets sub-expression registers $n.
regsub (string, regexp, subst)
Search regular expression regexp from string string and replace the matching substring with string subst. Returns the resulting string. The substitution string subst can contain $n references to the n:th parenthesized sup-expression.
regsuball (string, regexp, subst)
Like regsub but replace all matches of regular expression regexp from string string with string subst.
require_state (symbol)
Check that the state symbol is defined. If the required state is undefined, the function tries to autoload it. If the loading fails, the program will terminate with an error message.
split (regexp, string)
Split string string to list considering matches of regular rexpression regexp as item separator.
sprintf (fmt, ...)
Format arguments according to fmt and return result as a string.
strcmp (str1, str2)
Perform a case-sensitive comparision for strings str1 and str2. Function returns a value that is:
-1
string str1 is less than str2
0
strings are equal
1
string str1 is greater than str2
string (any)
Convert argument to string.
strncmp (str1, str2, num)
Perform a case-sensitive comparision for strings str1 and str2 comparing at maximum num characters.
substring (str, start, end)
Return a substring of string str starting from position start (inclusively) to end (exclusively).

BUILTIN VARIABLES

$.
current input line number
$n
the n:th parenthesized regular expression sub-expression from the latest state regular expression or from the regmatch primitive
$`
everything before the matched regular rexpression. This is usable when used with the regmatch primitive; the contents of this variable is undefined when used in action blocks to refer the data before the block's regular expression.
$B
an alias for $`
argv
list of input file names
filename
name of the current input file
program
name of the program (usually states)
version
program version string
