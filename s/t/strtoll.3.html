strtol(3) Library Functions Manual strtol(3)

الاسم

strtol, strtoll, strtoq - تحويل سلسلة نصية إلى عدد صحيح طويل

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdlib.h>
long strtol(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);
long long strtoll(const char *restrict nptr,
            char **_Nullable restrict endptr, int base);

الوصف

تقوم الدالة strtol() بتحويل الجزء الأولي من السلسلة النصية في nptr إلى قيمة عدد صحيح طويل وفقًا للـ base المعطاة، والتي يجب أن تكون بين 2 و 36 شاملة، أو أن تكون القيمة الخاصة 0.

قد تبدأ السلسلة النصية بكمية اعتباطية من المسافات البيضاء (كما تحددها isspace(3)) متبوعة بعلامة اختيارية واحدة '+' أو '-'. إذا كانت base صفرًا أو 16، فقد تتضمن السلسلة النصية بعد ذلك البادئة "0x" أو "0X"، وسيتم قراءة الرقم بالأساس 16؛ إذا كانت base صفرًا أو 2، فقد تتضمن السلسلة النصية بعد ذلك البادئة "0b" أو "0B"، وسيتم قراءة الرقم بالأساس 2؛ بخلاف ذلك، يعتبر الأساس الصفر 10 (عشري) ما لم يكن الحرف التالي هو '0'، وفي هذه الحالة يعتبر 8 (ثامني).

يتم تحويل بقية السلسلة النصية إلى قيمة long بالطريقة الواضحة، مع التوقف عند أول حرف ليس رقمًا صالحًا في الأساس المحدد. (في الأساسات التي تزيد عن 10، يمثل الحرف 'A' بأحرف كبيرة أو صغيرة 10، ويمثل 'B' 11، وهكذا، مع تمثيل 'Z' لـ 35.)

إذا لم تكن endptr NULL، وكانت base مدعومة، تقوم strtol() بتخزين عنوان أول حرف غير صالح في *endptr. إذا لم تكن هناك أي أرقام على الإطلاق، تقوم strtol() بتخزين القيمة الأصلية لـ nptr في *endptr (وتعيد 0). وبشكل خاص، إذا لم يكن *nptr '\0' ولكن **endptr هو '\0' عند العودة، فإن السلسلة النصية بأكملها صالحة.

تعمل الدالة strtoll() تمامًا مثل الدالة strtol() ولكنها تعيد قيمة عدد صحيح long long.

قيمة الإرجاع

تعيد الدالة strtol() نتيجة التحويل، ما لم يكن من الممكن أن يؤدي ذلك إلى نقص أو زيادة. في حالة حدوث نقص، تعيد strtol() القيمة LONG_MIN. في حالة حدوث زيادة، تعيد strtol() القيمة LONG_MAX. في كلتا الحالتين، يتم تعيين errno إلى ERANGE. تنطبق نفس القاعدة تمامًا على strtoll() (مع LLONG_MIN و LLONG_MAX بدلاً من LONG_MIN و LONG_MAX).

الأخطاء

لا تعدل هذه الدالة errno عند النجاح.

EINVAL
(غير موجود في C99) تحتوي base المعطاة على قيمة غير مدعومة.
ERANGE
كانت النتيجة خارج النطاق.

قد تقوم التنفيذ أيضًا بتعيين errno إلى EINVAL في حالة عدم إجراء أي تحويل (لم يتم رؤية أرقام، وتم إرجاع 0).

تحذيرات

فحوصات النطاق

نظرًا لأن strtol() يمكن أن تعيد بشكل شرعي 0، LONG_MAX، أو LONG_MIN (LLONG_MAX أو LLONG_MIN لـ strtoll()) عند النجاح والفشل، يجب على البرنامج المستدعي تعيين errno إلى 0 قبل الاستدعاء، ثم تحديد ما إذا كان قد حدث خطأ عن طريق التحقق مما إذا كان errno == ERANGE بعد الاستدعاء.


errno = 0;
n = strtol(s, &end, base);
if (end == s)
	goto no_number;
if ((errno == ERANGE && n == LONG_MIN) || n < min)
	goto too_low;
if ((errno == ERANGE && n == LONG_MAX) || n > max)
	goto too_high;

base

إذا كانت base بحاجة إلى اختبار، فيجب اختبارها في استدعاء حيث من المعروف أن السلسلة النصية تنجح. خلاف ذلك، من المستحيل التفريق بين الأخطاء بشكل قابل للنقل.


errno = 0;
strtol("0", NULL, base);
if (errno == EINVAL)
    goto unsupported_base;

أخطاء

المسافات البيضاء

تقبل هذه الدوال بصمت المسافات البيضاء الرائدة. لرفض المسافات البيضاء، قم باستدعاء isspace(3) قبل strtol().

strtoll(3) - Linux man-pages

NAME

strtoll, strtoll_l - convert string to long long integer

LIBRARY

Library C library (libc, -lc)

SYNOPSIS

       #include <stdlib.h>

       long long int
       strtoll(const char *restrict nptr, char **restrict endptr, int base);

       long long int
       strtoll_l(const char *restrict nptr, char **restrict endptr, int base,
                 locale_t restrict loc);

DESCRIPTION

The strtoll() function converts the initial portion of the string pointed to by nptr to long long int representation. If the base is indicated by the value of base, that base is used. If base is zero, the base is determined from the characters immediately preceding the universal character NUL. Thus, white space characters are ignored. If base is specified as 16, the characters "0x" may be omitted. If base is specified as 8, the characters "0" may be omitted.

The string is broken down into three parts:

  • Initial white-space characters (as determined by isspace(3)).
  • Optional sign characters.
  • Sequence of characters that are digits in the specified base.

If the value of base is not between 0 and 36, inclusive, or if base is 0 and the input string does not contain a valid number, the behavior is undefined.

The strtoll_l() function is equivalent to strtoll() except that it uses the locale specified by loc.

strtoll() sets the external variable errno to the value of ERANGE if the converted value falls out of range of representable values by a long long int.

If the input string is not a number, or if no conversion could be performed, zero is returned and endptr is set to point to nptr.

The strtoll() function sets the external variable errno to the value of ERANGE if the converted value falls out of range of representable values by a long long int.

If the input string is not a number, or if no conversion could be performed, zero is returned and endptr is set to point to nptr.

RETURN VALUE

The strtoll() function returns the converted value. If no conversion could be performed, zero is returned.

ERRORS

The strtoll() function sets errno to ERANGE if the converted value cannot be represented by a long long int.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Attribute
strtoll(), strtoll_l() thread safe

VERSIONS

strtoll() was added to Glibc in version 2.0.

strtoll_l() was added to Glibc in version 2.2.

STANDARDS

C99, POSIX.1-2001, POSIX.1-2008.

HISTORY

The strtoll() function first appeared in BSD.

CAVEATS

The interpretation of digits in bases greater than 10 is case-insensitive; that is, "0x1a" and "0x1A" are equivalent.

If the string nptr points to contains only white space characters, or does not contain a valid number for the specified base, no conversion is performed, and strtoll() returns 0. Additionally, if no conversion is performed, endptr is set to point to the beginning of the string.

If the string nptr points to contains only white space characters, or does not contain a valid number for the specified base, no conversion is performed, and strtoll() returns 0. Additionally, if no conversion is performed, endptr is set to point to the beginning of the string.

BUGS

The behavior of strtoll() with regard to the errno variable is somewhat inconsistent across different implementations. For example, some implementations may not set errno to ERANGE when the value overflows, but rather return the maximum or minimum representable value. Some implementations may also set errno to EINVAL if no valid digits are found.

EXAMPLES

The following code snippet demonstrates the use of strtoll() and its error handling:

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int
main(void)
{
    char *str;
    long long int val;
    char *endptr;

    str = "9223372036854775807"; // LLONG_MAX
    errno = 0; // To distinguish success from failure
    val = strtoll(str, &endptr, 10);

    if (errno == ERANGE && val == LLONG_MAX) {
        fprintf(stderr, "Overflow occurred\n");
    } else if (errno == ERANGE && val == LLONG_MIN) {
        fprintf(stderr, "Underflow occurred\n");
    } else if (endptr == str) {
        fprintf(stderr, "No digits were found\n");
    } else if (*endptr != '\0') {
        printf("Further characters after number: \"%s\"\n", endptr);
    }

    if (val == 0 && errno == 0 && endptr == str) {
        // Handle cases where the string is not a valid number
        printf("strtol() did not find any digits\n");
        exit(EXIT_FAILURE);
    }

    printf("strtoll() returned %lld\n", val);

    // Example with a different base
    str = "0xFF"; // Hexadecimal
    val = strtoll(str, &endptr, 0); // Base 0 automatically detects base
    if (errno != 0) {
        perror("strtoll");
        exit(EXIT_FAILURE);
    }
    if (endptr == str) {
        printf("No digits were found\n");
        exit(EXIT_FAILURE);
    }
    printf("strtoll(\"%s\", ..., 0) returned %lld\n", str, val);
    if (*endptr != '\0') {
        printf("Further characters after number: \"%s\"\n", endptr);
    }

    return 0;
}

Another example showing potential error conditions:

#include <stdio.h>
#include <stdlib.h>
#include <errno.h>

int
main(void)
{
    char *endptr;
    long long int val;

    // Test case 1: Valid number
    val = strtoll("12345", &endptr, 10);
    printf("Input: \"12345\", Base: 10\n");
    printf("strtoll() returned %lld\n", val);
    if (*endptr != '\0')
        printf("Further characters: \"%s\"\n", endptr);
    printf("\n");

    // Test case 2: Number with leading whitespace
    val = strtoll("  -6789", &endptr, 10);
    printf("Input: \"  -6789\", Base: 10\n");
    printf("strtoll() returned %lld\n", val);
    if (*endptr != '\0')
        printf("Further characters: \"%s\"\n", endptr);
    printf("\n");

    // Test case 3: Hexadecimal number (base 0 auto-detection)
    val = strtoll("0xABCDEF", &endptr, 0);
    printf("Input: \"0xABCDEF\", Base: 0\n");
    printf("strtoll() returned %lld\n", val);
    if (*endptr != '\0')
        printf("Further characters: \"%s\"\n", endptr);
    printf("\n");

    // Test case 4: Octal number (base 0 auto-detection)
    val = strtoll("012345", &endptr, 0);
    printf("Input: \"012345\", Base: 0\n");
    printf("strtoll() returned %lld\n", val);
    if (*endptr != '\0')
        printf("Further characters: \"%s\"\n", endptr);
    printf("\n");

    // Test case 5: Number followed by non-numeric characters
    val = strtoll("42abc", &endptr, 10);
    printf("Input: \"42abc\", Base: 10\n");
    printf("strtoll() returned %lld\n", val);
    if (*endptr != '\0')
        printf("Further characters: \"%s\"\n", endptr);
    printf("\n");

    // Test case 6: Invalid input (no digits)
    errno = 0;
    val = strtoll("abc", &endptr, 10);
    printf("Input: \"abc\", Base: 10\n");
    if (errno != 0) {
        perror("strtoll");
    }
    if (endptr == &strtoll) { // Check if endptr points to the start of the string
        printf("No digits were found\n");
    } else {
        printf("strtoll() returned %lld\n", val);
        if (*endptr != '\0')
            printf("Further characters: \"%s\"\n", endptr);
    }
    printf("\n");

    // Test case 7: Overflow
    errno = 0;
    // LLONG_MAX is 2^63 - 1. A value larger than this will cause overflow.
    val = strtoll("9223372036854775808", &endptr, 10);
    printf("Input: \"9223372036854775808\" (LLONG_MAX + 1), Base: 10\n");
    if (errno == ERANGE) {
        printf("Overflow occurred as expected.\n");
        printf("strtoll() returned %lld (LLONG_MAX)\n", val);
    } else {
        printf("strtoll() returned %lld\n", val);
        if (*endptr != '\0')
            printf("Further characters: \"%s\"\n", endptr);
    }
    printf("\n");

    // Test case 8: Underflow
    errno = 0;
    // LLONG_MIN is -2^63. A value smaller than this will cause underflow.
    val = strtoll("-9223372036854775809", &endptr, 10);
    printf("Input: \"-9223372036854775809\" (LLONG_MIN - 1), Base: 10\n");
    if (errno == ERANGE) {
        printf("Underflow occurred as expected.\n");
        printf("strtoll() returned %lld (LLONG_MIN)\n", val);
    } else {
        printf("strtoll() returned %lld\n", val);
        if (*endptr != '\0')
            printf("Further characters: \"%s\"\n", endptr);
    }
    printf("\n");

    // Example from the problem description
    printf("Example from problem description:\n");
    char *p = " -12345abc";
    char *q;
    long long int v = strtoll(p, &q, 10);
    if ((v == 0 && errno == EINVAL) || (errno == ERANGE && (v == LLONG_MAX || v == LLONG_MIN))) {
        fprintf(stderr, "Invalid argument or out of range\n");
        exit(EXIT_FAILURE);
    }
    if (q == p) {
        printf("No digits were found\n");
        exit(EXIT_FAILURE);
    }
    printf("strtol() returned %lld\n", v);
    if (*q != '\0')
        printf("Further characters after number: \"%s\"\n", q);
    exit(EXIT_SUCCESS);
}
