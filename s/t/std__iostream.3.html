دوال الإدخال غير المنسقة
جميع دوال الإدخال غير المنسقة لها سلوك مشترك. يبدأ كل منها بإنشاء كائن مؤقت من النوع std::basic_istream::sentry مع تعيين الوسيط الثاني (noskipws) إلى true. هذا له عدة تأثيرات، تنتهي بتعيين علامة حالة؛ راجع توثيق sentry لمزيد من التفاصيل.

إذا كانت حالة sentry جيدة، تحاول الدالة استخراج أي بيانات مناسبة لنوع الوسيط.

يتم تخزين عدد الأحرف المستخرجة للاسترداد لاحقًا بواسطة gcount().

إذا تم طرح استثناء أثناء الاستخراج، فسيتم تشغيل ios_base::badbit في حالة خطأ التدفق (دون التسبب في طرح ios_base::failure) وسيتم إعادة طرح الاستثناء الأصلي إذا تم تعيين badbit في قناع الاستثناءات.

القيمة المرجعة

*this

يتم استخلاص الأحرف وتخزينها في __s حتى يحدث أحد الأمور التالية:

  • تم تخزين __n-1 حرفًا
  • وصل تسلسل الإدخال إلى نهاية الملف (EOF)
  • الحرف التالي يساوي __delim، وفي هذه الحالة لا يتم استخلاص الحرف

إذا لم يتم تخزين أي أحرف، يتم تعيين بت الفشل (failbit) في حالة خطأ التدفق.

في أي حال، يتم تخزين حرف صفري (null character) في الموقع التالي في المصفوفة.

هذه الدالة ليست متجاوزة (overloaded) على `signed char` و `unsigned char`.

القيمة المرجعة

*this

يستخلص ويخزن الأحرف في __s حتى يحدث أحد الأمور التالية. لاحظ أنه يجب اختبار هذه المعايير بالترتيب المذكور هنا، للسماح لسطر إدخال بملء مصفوفة __s بالضبط دون تعيين بت الفشل (failbit).

1.
يصل تسلسل الإدخال إلى نهاية الملف (end-of-file)، وفي هذه الحالة يتم تعيين بت نهاية الملف (eofbit) في حالة خطأ التدفق
2.
الحرف التالي يساوي __delim، وفي هذه الحالة يتم استخلاص الحرف (وبالتالي يتم عده في gcount()) ولكنه لا يتم تخزينه
3.
تم تخزين __n-1 حرفًا، وفي هذه الحالة يتم تعيين بت الفشل (failbit) في حالة خطأ التدفق

إذا لم يتم استخلاص أي أحرف، يتم تعيين بت الفشل (failbit). (لذلك، لا ينبغي أن يتسبب سطر إدخال فارغ في تعيين بت الفشل).

في أي حال، يتم تخزين حرف صفري (null character) في الموقع التالي في المصفوفة.

template<typename _CharT, typename _Traits> basic_istream< _CharT, _Traits > & std::basic_istream< _CharT, _Traits >::operator>> (__streambuf_type * __sb) [inherited]

Extracting into another streambuf.

Parameters

__sb A pointer to a streambuf

This function behaves like one of the basic arithmetic extractors, in that it also constructs a sentry object and has the same error handling behavior.

If __sb is NULL, the stream will set failbit in its error state.

Characters are extracted from this stream and inserted into the __sb streambuf until one of the following occurs:

  • the input stream reaches end-of-file,
  • insertion into the output buffer fails (in this case, the character that would have been inserted is not extracted), or
  • an exception occurs (and in this case is caught)

If the function inserts no characters, failbit is set.
