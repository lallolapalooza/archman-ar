وصول غير متزامن

قد تؤدي عمليات الوصول غير المتزامنة إلى مخزن مؤقت إلى حالة مخزن مؤقت غير صالحة. لذلك، يجب مزامنة العمليات المتزامنة على المخزن المؤقت (على سبيل المثال، باستخدام Mutex.t).

type t

النوع المجرد للمخازن المؤقتة.

val create : int -> t

create n تُرجع مخزنًا مؤقتًا جديدًا، فارغًا في البداية. المعامل n هو الحجم الأولي لسلسلة البايتات التي تحتوي على محتويات المخزن المؤقت. تتم إعادة تخصيص سلسلة البايتات هذه تلقائيًا عند تخزين أكثر من n حرف في المخزن المؤقت، ولكن يتم إعادة تخصيصها إلى n حرف عند استدعاء reset. للحصول على أفضل أداء، يجب أن يكون n في نفس ترتيب حجم عدد الأحرف المتوقع تخزينها في المخزن المؤقت (على سبيل المثال، 80 لمخزن مؤقت يخزن سطر إخراج). لن يحدث شيء سيء إذا نما المخزن المؤقت إلى ما بعد هذا الحد، على الرغم من أنه عند الشك، اختر n = 16 على سبيل المثال. إذا لم يكن n بين 1 و Sys.max_string_length، فسيتم قصه إلى هذا النطاق.

val contents : t -> string

تُرجع نسخة من المحتويات الحالية للمخزن المؤقت. المخزن المؤقت نفسه لا يتغير.

val to_bytes : t -> bytes

تُرجع نسخة من المحتويات الحالية للمخزن المؤقت. المخزن المؤقت نفسه لا يتغير.

Since 4.02

val sub : t -> int -> int -> string

Buffer.sub b off len تُرجع نسخة بطول len من المحتويات الحالية للمخزن المؤقت b، بدءًا من الموضع off.

Raises Invalid_argument إذا كان off و len لا يحددان نطاقًا صالحًا لـ b.

val blit : t -> int -> bytes -> int -> int -> unit

Buffer.blit src srcoff dst dstoff len ينسخ len حرفًا من المحتويات الحالية للمخزن المؤقت src، بدءًا من srcoff، إلى dst، بدءًا من dstoff.

Since 3.11.2

Raises Invalid_argument إذا كان srcoff و len لا يحددان نطاقًا صالحًا لـ src، أو إذا كان dstoff و len لا يحددان نطاقًا صالحًا لـ dst.

val nth : t -> int -> char

يحصل على الحرف n من المخزن المؤقت.

Raises Invalid_argument إذا كان الفهرس خارج النطاق.

val length : t -> int

تُرجع عدد الأحرف الموجودة حاليًا في المخزن المؤقت.

val clear : t -> unit

يمسح المخزن المؤقت.

val reset : t -> unit

يمسح المخزن المؤقت ويحرر سلسلة البايتات الداخلية التي تحتوي على محتويات المخزن المؤقت، ويستبدلها بسلسلة البايتات الأولية بطول n التي تم تخصيصها بواسطة Buffer.create n. بالنسبة للمخازن المؤقتة الكبيرة التي ربما تكون قد نمت بشكل كبير، يسمح reset باستئناف أسرع للمساحة التي يستخدمها المخزن المؤقت.

val output_buffer : out_channel -> t -> unit

output_buffer oc b يكتب المحتويات الحالية للمخزن المؤقت b إلى قناة الإخراج oc.

val truncate : t -> int -> unit

truncate b len يقلل طول b إلى len. ملاحظة: سلسلة البايتات الداخلية لا يتم قصها.

Since 4.05

Raises Invalid_argument إذا كان len < 0 أو len > length b.

val add_substring : t -> string -> int -> int -> unit

add_substring b s ofs len يأخذ len حرفًا من الموضع ofs في السلسلة s ويضيفها إلى نهاية المخزن المؤقت b.

Raises Invalid_argument إذا كان ofs و len لا يحددان نطاقًا صالحًا لـ s.

val add_subbytes : t -> bytes -> int -> int -> unit

add_subbytes b s ofs len يأخذ len حرفًا من الموضع ofs في سلسلة البايتات s ويضيفها إلى نهاية المخزن المؤقت b.

Since 4.02

Raises Invalid_argument إذا كان ofs و len لا يحددان نطاقًا صالحًا لـ s.

val add_substitute : t -> (string -> string) -> string -> unit

add_substitute b f s يضيف السلسلة النمطية s إلى نهاية المخزن المؤقت b مع الاستبدال. تبحث عملية الاستبدال عن مراجع المتغيرات في النمط وتستبدل كل مرجع متغير بقيمته، يتم الحصول عليها عن طريق تطبيق المخطط f على اسم المتغير. داخل النمط السلسلة، مرجع المتغير هو حرف غير مفلت $ متبوعًا مباشرة باسم متغير، وهو أحد ما يلي:

- تسلسل غير فارغ من الأحرف الأبجدية الرقمية أو _

- تسلسل عشوائي من الأحرف المحاط بزوج من الأقواس أو الأقواس المعقوفة. يتم تهريب الحرف $ كـ $ يتبع مباشرة حرف هروب؛ تشكل الحرفان معًا $ مسطحًا.

val add_buffer : t -> t -> unit

add_buffer b1 b2 يضيف المحتويات الحالية للمخزن المؤقت b2 إلى نهاية المخزن المؤقت b1. لا يتم تعديل b2.

val add_channel : t -> in_channel -> int -> unit

add_channel b ic n يقرأ حتى n حرفًا من قناة الإدخال ic ويخزنها في نهاية المخزن المؤقت b.

Raises End_of_file إذا احتوت القناة على أقل من n حرفًا. في هذه الحالة، لا تزال الأحرف تضاف إلى المخزن المؤقت، مما يمنع فقدان البيانات.

Raises Invalid_argument إذا كان len < 0 أو len > Sys.max_string_length.

The functions in this section append binary encodings of integers to buffers.

Little-endian (resp. big-endian) encoding means that least (resp. most) significant bytes are stored first. Big-endian is also known as network byte order. Native-endian encoding is either little-endian or big-endian depending on Sys.big_endian .

32-bit and 64-bit integers are represented by the int32 and int64 types, which can be interpreted either as signed or unsigned numbers.

8-bit and 16-bit integers are represented by the int type, which has more bits than the binary encoding. Functions that encode these values truncate their inputs to their least significant bytes.
