subroutine stgsja (jobu حرفي، jobv حرفي، jobq حرفي، m صحيح، p صحيح، n صحيح، k صحيح، l صحيح، real، dimension( lda, * ) a، lda صحيح، real، dimension( ldb, * ) b، ldb صحيح، tola حقيقي، tolb حقيقي، real، dimension( * ) alpha، real، dimension( * ) beta، real، dimension( ldu, * ) u، ldu صحيح، real، dimension( ldv, * ) v، ldv صحيح، real، dimension( ldq, * ) q، ldq صحيح، real، dimension( * ) work، ncycle صحيح، info صحيح)

STGSJA

الغرض:

!>
!> STGSJA تحسب تحليل القيم المفردة المعممة (GSVD)
!> لمصفوفتين مثلثيتين علويتين حقيقيتين (أو شبه منحرف) A و B.
!>
!> عند الدخول، يُفترض أن المصفوفتين A و B لهما الأشكال التالية،
!> والتي قد يتم الحصول عليها بواسطة الإجراء الفرعي الأولي SGGSVP
!> من مصفوفة عامة M-by-N المصفوفة A ومصفوفة P-by-N المصفوفة B:
!>
!>              N-K-L  K    L
!>    A =    K ( 0    A12  A13 ) إذا كان M-K-L >= 0؛
!>           L ( 0     0   A23 )
!>       M-K-L ( 0     0    0  )
!>
!>            N-K-L  K    L
!>    A =  K ( 0    A12  A13 ) إذا كان M-K-L < 0؛
!>       M-K ( 0     0   A23 )
!>
!>            N-K-L  K    L
!>    B =  L ( 0     0   B13 )
!>       P-L ( 0     0    0  )
!>
!> حيث تكون المصفوفة A12 بحجم K-by-K والمصفوفة B13 بحجم L-by-L غير منفردتين
!> مثلثيتين علويتين؛ A23 تكون مثلثية علوية L-by-L إذا كان M-K-L >= 0،
!> وإلا فإن A23 تكون شبه منحرف علوية M-K-by-L.
!>
!> عند الخروج،
!>
!>        U**T *A*Q = D1*( 0 R )،    V**T *B*Q = D2*( 0 R )،
!>
!> حيث U، V، و Q هي مصفوفات متعامدة.
!> R هي مصفوفة مثلثية علوية غير منفردة، و D1 و D2 هما
!> مصفوفتان "قطريتان"، وهما ذات الهياكل التالية:
!>
!> إذا كان M-K-L >= 0،
!>
!>                     K  L
!>        D1 =     K ( I  0 )
!>                 L ( 0  C )
!>             M-K-L ( 0  0 )
!>
!>                   K  L
!>        D2 = L   ( 0  S )
!>             P-L ( 0  0 )
!>
!>                N-K-L  K    L
!>   ( 0 R ) = K (  0   R11  R12 ) K
!>             L (  0    0   R22 ) L
!>
!> حيث
!>
!>   C = diag( ALPHA(K+1), ... , ALPHA(K+L) )،
!>   S = diag( BETA(K+1)،  ... ، BETA(K+L) )،
!>   C**2 + S**2 = I.
!>
!>   يتم تخزين R في A(1:K+L,N-K-L+1:N) عند الخروج.
!>
!> إذا كان M-K-L < 0،
!>
!>                K M-K K+L-M
!>     D1 =   K ( I  0    0   )
!>          M-K ( 0  C    0   )
!>
!>                  K M-K K+L-M
!>     D2 =   M-K ( 0  S    0   )
!>          K+L-M ( 0  0    I   )
!>            P-L ( 0  0    0   )
!>
!>                N-K-L  K   M-K  K+L-M
!> ( 0 R ) =    K ( 0    R11  R12  R13  )
!>           M-K ( 0     0   R22  R23  )
!>         K+L-M ( 0     0    0   R33  )
!>
!> حيث
!> C = diag( ALPHA(K+1), ... , ALPHA(M) )،
!> S = diag( BETA(K+1)،  ... ، BETA(M) )،
!> C**2 + S**2 = I.
!>
!> يتم تخزين R = ( R11 R12 R13 ) في A(1:M, N-K-L+1:N) و R33
!>     (  0  R22 R23 )
!> في B(M-K+1:L,N+M-K-L+1:N) عند الخروج.
!>
!> حساب المصفوفات التحويل المتعامدة U، V أو Q اختياري.
!> قد يتم تشكيل هذه المصفوفات بشكل صريح، أو
!> قد يتم ضربها لاحقًا في المصفوفات المدخلة U1، V1، أو Q1.
!>

المعلمات

JOBU 
!>          JOBU is CHARACTER*1
!>          = 'U':  يجب أن تحتوي U على مصفوفة متعامدة U1 عند الدخول، و
!>                  يتم إرجاع المنتج U1*U؛
!>          = 'I':  يتم تهيئة U إلى مصفوفة الوحدة، و
!>                  يتم إرجاع المصفوفة المتعامدة U؛
!>          = 'N':  لا يتم حساب U.
!>

JOBV

!>          JOBV is CHARACTER*1
!>          = 'V':  يجب أن تحتوي V على مصفوفة متعامدة V1 عند الدخول، و
!>                  يتم إرجاع المنتج V1*V؛
!>          = 'I':  يتم تهيئة V إلى مصفوفة الوحدة، و
!>                  يتم إرجاع المصفوفة المتعامدة V؛
!>          = 'N':  لا يتم حساب V.
!>

JOBQ

!>          JOBQ is CHARACTER*1
!>          = 'Q':  يجب أن تحتوي Q على مصفوفة متعامدة Q1 عند الدخول، و
!>                  يتم إرجاع المنتج Q1*Q؛
!>          = 'I':  يتم تهيئة Q إلى مصفوفة الوحدة، و
!>                  يتم إرجاع المصفوفة المتعامدة Q؛
!>          = 'N':  لا يتم حساب Q.
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A.  M >= 0.
!>

P

!>          P is INTEGER
!>          عدد صفوف المصفوفة B.  P >= 0.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفتين A و B.  N >= 0.
!>

K

!>          K is INTEGER
!>

L

!>          L is INTEGER
!>
!>          يحدد K و L الكتل الفرعية في المصفوفتين المدخلتين A و B:
!>          A23 = A(K+1:MIN(K+L,M),N-L+1:N) و B13 = B(1:L,N-L+1:N)
!>          من A و B، والتي سيتم حساب GSVD لها بواسطة STGSJA.
!>          انظر التفاصيل الإضافية.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          عند الدخول، المصفوفة A بحجم M-by-N.
!>          عند الخروج، تحتوي A(N-K+1:N,1:MIN(K+L,M) ) على المصفوفة
!>          المثلثية R أو جزء من R. انظر الغرض للتفاصيل.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A. LDA >= max(1,M).
!>

B

!>          B is REAL array, dimension (LDB,N)
!>          عند الدخول، المصفوفة B بحجم P-by-N.
!>          عند الخروج، إذا لزم الأمر، تحتوي B(M-K+1:L,N+M-K-L+1:N) على
!>          جزء من R. انظر الغرض للتفاصيل.
!>

LDB

!>          LDB is INTEGER
!>          البعد الرئيسي للمصفوفة B. LDB >= max(1,P).
!>

TOLA

!>          TOLA is REAL
!>

TOLB

!>          TOLB is REAL
!>
!>          TOLA و TOLB هما معيارا التقارب لإجراء تكرار Jacobi-
!>          Kogbetliantz. بشكل عام، هما نفس المعيارين المستخدمين في خطوة المعالجة الأولية، مثل
!>              TOLA = max(M,N)*norm(A)*MACHEPS،
!>              TOLB = max(P,N)*norm(B)*MACHEPS.
!>

ALPHA

!>          ALPHA is REAL array, dimension (N)
!>

BETA

!>          BETA is REAL array, dimension (N)
!>
!>          عند الخروج، تحتوي ALPHA و BETA على أزواج القيم المفردة المعممة
!>          لـ A و B؛
!>            ALPHA(1:K) = 1،
!>            BETA(1:K)  = 0،
!>          وإذا كان M-K-L >= 0،
!>            ALPHA(K+1:K+L) = diag(C)،
!>            BETA(K+1:K+L)  = diag(S)،
!>          أو إذا كان M-K-L < 0،
!>            ALPHA(K+1:M)= C، ALPHA(M+1:K+L)= 0
!>            BETA(K+1:M) = S، BETA(M+1:K+L) = 1.
!>          بالإضافة إلى ذلك، إذا كان K+L < N،
!>            ALPHA(K+L+1:N) = 0 و
!>            BETA(K+L+1:N)  = 0.
!>

U

!>          U is REAL array, dimension (LDU,M)
!>          عند الدخول، إذا كان JOBU = 'U'، يجب أن تحتوي U على مصفوفة U1 (عادةً
!>          المصفوفة المتعامدة التي ترجعها SGGSVP).
!>          عند الخروج،
!>          إذا كان JOBU = 'I'، تحتوي U على المصفوفة المتعامدة U؛
!>          إذا كان JOBU = 'U'، تحتوي U على المنتج U1*U.
!>          إذا كان JOBU = 'N'، لا يتم استخدام U.
!>

LDU

!>          LDU is INTEGER
!>          البعد الرئيسي للمصفوفة U. LDU >= max(1,M
