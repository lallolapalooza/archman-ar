STRCMP(3P) دليل مبرمج POSIX STRCMP(3P)

PROLOG

هذه الصفحة من الدليل هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا يتم تنفيذ الواجهة في لينكس.

NAME

strcmp — مقارنة سلسلتين نصيتين

SYNOPSIS

#include <string.h>
int strcmp(const char *s1, const char *s2);

DESCRIPTION

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C هو غير مقصود. هذا المجلد من POSIX.1‐2017 يعتمد على معيار ISO C.

تقوم الدالة strcmp() بمقارنة السلسلة النصية التي يشير إليها s1 بالسلسلة النصية التي يشير إليها s2.

سيتم تحديد إشارة قيمة الإرجاع غير الصفرية بناءً على إشارة الفرق بين قيم أول زوج من البايتات (يتم تفسيرهما كنوع unsigned char) التي تختلف في السلاسل النصية التي تتم مقارنتها.

RETURN VALUE

عند الانتهاء، ستعيد الدالة strcmp() قيمة صحيحة أكبر من أو تساوي أو أقل من 0، إذا كانت السلسلة النصية التي يشير إليها s1 أكبر من أو تساوي أو أقل من السلسلة النصية التي يشير إليها s2، على التوالي.

ERRORS

لا توجد أخطاء محددة.

الأقسام التالية إعلامية.

EXAMPLES

التحقق من إدخال كلمة المرور

يقارن المثال التالي المعلومات التي تم قراءتها من الإدخال القياسي بقيمة اسم إدخال المستخدم. إذا أعادت الدالة strcmp() القيمة 0 (مما يدل على تطابق)، سيتم إجراء فحص إضافي لمعرفة ما إذا كان المستخدم قد أدخل كلمة المرور القديمة الصحيحة. تقوم الدالة crypt() بتشفير كلمة المرور القديمة التي أدخلها المستخدم، باستخدام قيمة كلمة المرور المشفرة في بنية passwd كملح. إذا تطابقت هذه القيمة مع قيمة passwd المشفرة في البنية، فإن كلمة المرور oldpasswd المدخلة هي كلمة مرور المستخدم الصحيحة. أخيرًا، تقوم الدالة بتشفير كلمة المرور الجديدة لتتمكن من تخزين المعلومات في بنية passwd.

#include <string.h>
#include <unistd.h>
#include <stdio.h>
...
int valid_change;
struct passwd *p;
char user[100];
char oldpasswd[100];
char newpasswd[100];
char savepasswd[100];
...
if (strcmp(p->pw_name, user) == 0) {
    if (strcmp(p->pw_passwd, crypt(oldpasswd, p->pw_passwd)) == 0) {
        strcpy(savepasswd, crypt(newpasswd, user));
        p->pw_passwd = savepasswd;
        valid_change = 1;
    }
    else {
        fprintf(stderr, "Old password is not valid\n");
    }
}
...
