الوصف

يحدد رأس <stropts.h> البنية bandinfo، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

int            bi_flag  نوع التصفية.
unsigned char  bi_pri   نطاق الأولوية.

يحدد رأس <stropts.h> البنية strpeek، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

struct strbuf  ctlbuf   الجزء التحكمي للرسالة.
struct strbuf  databuf  الجزء البياناتي للرسالة.
t_uscalar_t    flags    RS_HIPRI أو 0.

يحدد رأس <stropts.h> البنية strbuf، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

char  *buf     مؤشر إلى المخزن المؤقت.
int    len     طول البيانات.
int    maxlen  أقصى طول للمخزن المؤقت.

يحدد رأس <stropts.h> البنية strfdinsert، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

struct strbuf  databuf  الجزء البياناتي للرسالة.
int            fildes   واصف الملف لـ STREAM آخر.
t_uscalar_t    flags    RS_HIPRI أو 0.
int            offset   الموقع النسبي للقيمة المخزنة.

يحدد رأس <stropts.h> البنية strioctl، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

int    ic_cmd     أمر ioctl().
char  *ic_dp      مؤشر إلى المخزن المؤقت.
int    ic_len     طول البيانات.
int    ic_timout  مهلة الاستجابة.

يحدد رأس <stropts.h> البنية strrecvfd، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

int    fd   واصف الملف المستلم.
gid_t  gid  معرف المجموعة للمرسل.
uid_t  uid  معرف المستخدم للمرسل.

يحدد رأس <stropts.h> النوعين uid_t و gid_t من خلال typedef، كما هو موضح في <sys/types.h>.

يحدد رأس <stropts.h> النوعين t_scalar_t و t_uscalar_t، على التوالي، كأنواع غير شفافة موقعة وغير موقعة بطول متساوٍ لا يقل عن 32 بت.

stropts.h - POSIX standard manual pages

PROLOG

This manual page describes the header file <stropts.h> as required for POSIX operating systems.

NAME

stropts.h - stream data and control options

SYNOPSIS

#include <stropts.h>

DESCRIPTION

The <stropts.h> header file defines constants, structures, and function declarations used for controlling STREAMS-based drivers and modules. It defines the following constants for use with ioctl() calls:

I_ADDMODULE
Add a module to a stream.
I_CONFLATE
Specify that the stream should be conflated.
I_DETACH
Detach the top module from a stream.
I_FORK
Fork the stream.
I_GETBAND
Get the priority band of the message at the head of the read queue.
I_GETCLIENTID
Get the client ID of the stream.
I_GETEVAR
Get the event information associated with the stream.
I_GETFLOATING
Check if the stream is floating.
I_GETLINK
Get information about a link ID.
I_LINK
Link two streams together.
I_LISTMODULES
List the modules currently on the stream.
I_LOOKUPADDR
Look up a service access point by address.
I_LOOKUPUNIT
Look up a module or driver by unit number.
I_NURSE
Register the stream with the STREAMS nurse service.
I_PEEK
Look at the message at the head of the read queue without removing it.
I_POP
Pop a module from the stream.
I_PUSH
Push a module onto the stream.
I_READIF
Read from the stream if data is available.
I_RECVFD
Receive a file descriptor from a message.
I_SENDFD
Send a file descriptor in a message.
I_SETCLIENTID
Set the client ID of the stream.
I_SETEVAR
Set event information associated with the stream.
I_SETFLOATING
Set the stream to floating.
I_SETLINK
Set link information for a stream.
I_SETSIG
Set signal notification for events on the stream.
I_SRDOPT
Set read options for the stream.
I_STRINFO
Get information about the stream.
I_SWOPT
Set write options for the stream.
I_UNLINK
Unlink two streams.
I_WRITEIF
Write to the stream if space is available.

The <stropts.h> header shall define at least the following symbolic constants for use with ioctl(2) with the I_PEEK or I_LOOKUPADDR requests:

S_HIPRI
A high-priority message has arrived at the head of a STREAM head read queue.
S_RDNORM
A normal (priority band set to 0) message has arrived at the head of a STREAM head read queue.
S_WRBAND
The write queue for a non-zero priority band just below the STREAM head is no longer full.
S_WRNORM
Equivalent to S_OUTPUT.

The <stropts.h> header shall define at least the following symbolic constant for use with I_PEEK:

RS_HIPRI
Only look for high-priority messages.

The <stropts.h> header shall define at least the following symbolic constants for use with I_SRDOPT:

RMSGD
Message-discard mode.
RMSGN
Message-non-discard mode.
RNORM
Byte-STREAM mode, the default.
RPROTDAT
Deliver the control part of a message as data when a process issues a read().
RPROTDIS
Discard the control part of a message, delivering any data part, when a process issues a read().
RPROTNORM
Fail read() with [EBADMSG] if a message containing a control part is at the front of the STREAM head read queue.

The <stropts.h> header shall define at least the following symbolic constant for use with I_SWOPT:

SNDZERO
Send a zero-length message downstream when a write() of 0 bytes occurs.

The <stropts.h> header shall define at least the following symbolic constants for use with I_ATMARK:

ANYMARK
Check if the message is marked.
LASTMARK
Check if the message is the last one marked on the queue.

The <stropts.h> header shall define at least the following symbolic constant for use with I_UNLINK:

MUXID_ALL
Unlink all STREAMs linked to the STREAM associated with fildes.

The <stropts.h> header shall define the following symbolic constants for getmsg(), getpmsg(), putmsg(), and putpmsg():

MORECTL
More control information is left in message.
MOREDATA
More data is left in message.
MSG_ANY
Receive any message.
MSG_BAND
Receive message from specified band.
MSG_HIPRI
Send/receive high-priority message.

The <stropts.h> header may make visible all of the symbols from <unistd.h>.

The <stropts.h> header may also define macros for message types using names that start with M_.

The following shall be declared as functions and may also be defined as macros. Function prototypes shall be provided.

int    fattach(int, const char *);
int    fdetach(const char *);
int    getmsg(int, struct strbuf *restrict, struct strbuf *restrict,
           int *restrict);
int    getpmsg(int, struct strbuf *restrict, struct strbuf *restrict,
           int *restrict, int *restrict);
int    ioctl(int, int, ...);
int    isastream(int);
int    putmsg(int, const struct strbuf *, const struct strbuf *, int);
int    putpmsg(int, const struct strbuf *, const struct strbuf *, int,
           int);
