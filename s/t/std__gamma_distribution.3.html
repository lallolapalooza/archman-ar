Detailed Description

This struct represents a Gamma random number distribution.

The Gamma distribution is a continuous probability distribution. It is commonly used in statistics to model waiting times for events that occur at a certain average rate. For example, it can be used to model the time until the k-th event in a Poisson process.

The probability density function (PDF) for the Gamma distribution is given by:

f(x; k, θ) = (x^{k-1} * e^{-x/θ}) / (Γ(k) * &theta>^k)

where:

  • x > 0 is the random variable
  • k > 0 is the shape parameter (also known as the number of events)
  • θ > 0 is the scale parameter (the inverse of the rate parameter)
  • Γ(k) is the Gamma function

In the C++ standard library, the Gamma distribution is parameterized by the shape parameter alpha (corresponding to k) and the scale parameter beta (corresponding to θ).
