class std::basic_istream< _CharT, _Traits >"Template class basic_istream.

Template Parameters

_CharT Type of character stream.
_Traits Traits for character type, defaults to char_traits<_CharT>.

This is the base class for all input streams. It provides text formatting of all builtin types, and communicates with any class derived from basic_streambuf to do the actual input.

الإرجاع

*this

يستخرج ويخزن الأحرف في __s حتى يحدث أحد الأمور التالية. لاحظ أن هذه المعايير يجب اختبارها بالترتيب المذكور هنا، للسماح لسطر الإدخال بملء مصفوفة __s تمامًا دون تعيين failbit.

1.
تصل متتالية الإدخال إلى نهاية الملف، وفي هذه الحالة يتم تعيين eofbit في حالة خطأ التدفق
2.
الحرف التالي يساوي __delim، وفي هذه الحالة يتم استخراج الحرف (وبالتالي يتم حسابه في gcount()) ولكن لا يتم تخزينه
3.
يتم تخزين __n-1 حرف، وفي هذه الحالة يتم تعيين failbit في حالة خطأ التدفق

إذا لم يتم استخراج أي أحرف، يتم تعيين failbit. (لذلك، لا ينبغي لسطر إدخال فارغ التسبب في تعيين failbit.)

في أي حال، يتم تخزين حرف فارغ في الموقع التالي في المصفوفة.

Detailed Description

The class std::basic_ios is the base class for all stream classes. It provides basic I/O functionality and manipulates stream state.
The class std::basic_istream handles input operations.
The class std::basic_ostream handles output operations.

The class std::istream is the class for handling input from character sequences.
The class std::ostream is the class for handling output to character sequences.

std::basic_istream is a template class.
std::istream is a template class.

The iostream library defines the following type aliases for std::basic_istream:
std::istream: the standard input stream.
std::wistream: the standard wide character input stream.
