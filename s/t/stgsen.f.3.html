الغرض:

!>
!> يقوم STGSEN بإعادة ترتيب التحلل شبه المستقرة الحقيقي المعمم لمصفوفة
!> زوجية (A, B) (من حيث تحويلات التكافؤ المتعامدة Q**T * (A, B) * Z)، بحيث
!> تظهر مجموعة مختارة من القيم الذاتية في الكتل القطرية الرائدة للمصفوفة
!> شبه المستقرة العليا A والمصفوفة المستقرة العليا B. الأعمدة الرائدة لـ Q و
!> Z تشكل قواعد متعامدة لمساحات القيم الذاتية اليسرى واليمنى المقابلة
!> (مساحات التفريغ). يجب أن تكون (A, B) في شكل طبيعي شبه مستقر حقيقي معمّم
!> (كما هو معروض بواسطة SGGES)، أي أن A تكون كتلة شبه مستقرة عليا مع كتل
!> قطرية 1x1 و 2x2. B تكون مستقرة عليا.
!>
!> يقوم STGSEN أيضًا بحساب القيم الذاتية المعممة
!>
!>             w(j) = (ALPHAR(j) + i*ALPHAI(j))/BETA(j)
!>
!> للمصفوفة الزوجية المعاد ترتيبها (A, B).
!>
!> اختياريًا، يحسب STGSEN تقديرات للأعداد الشرطية المعكوسة
!> للقيم الذاتية ومساحات القيم الذاتية. هذه هي Difu[(A11,B11),
!> (A22,B22)] و Difl[(A11,B11), (A22,B22)]، أي الفصل (الفصول)
!> بين أزواج المصفوفات (A11, B11) و (A22,B22) التي تتوافق مع
!> المجموعة المختارة والقيم الذاتية خارج المجموعة، على التوالي،
!> ومعايير مساحات القيم الذاتية اليسرى واليمنى فيما يتعلق
!> بالمجموعة المختارة في كتلة (1,1).
!>

Function/Subroutine Documentation

STGSEN 

!> \brief \encoding{UTF-8}
!>
!> \details STGSEN computes the selected eigenvalues and the corresponding
!>          left and right eigenvectors (i.e., the Schur vectors) for a
!>          regular pair of matrices (A, B).
!>
!> \par
!> STGSEN uses the following values of IJOB to determine the computation:
!> \li \c IJOB = 1: Compute all eigenvalues and the corresponding left and
!>          right eigenvectors.
!> \li \c IJOB = 2: Compute all eigenvalues and the corresponding left and
!>          right eigenvectors, and the Schur vectors are computed so that
!>          the selected deflating subspaces are well-conditioned.
!> \li \c IJOB = 3: Compute the selected eigenvalues and the corresponding
!>          left and right eigenvectors, and the Schur vectors are computed so
!>          that the selected deflating subspaces are well-conditioned.
!> \li \c IJOB = 4: Compute all eigenvalues and the Schur vectors such that
!>          the selected deflating subspaces are well-conditioned.
!> \li \c IJOB = 5: Compute the selected eigenvalues and the Schur vectors
!>          such that the selected deflating subspaces are well-conditioned.
!> \li \c IJOB = 0: Compute the selected eigenvalues.
!>
!> \par
!> The pair (A, B) is assumed to be in generalized Schur canonical form, i.e.,
!> A is upper triangular and B is upper triangular.
!>
!> \par
!> This subroutine returns the matrices Q and Z, whose first M columns
!> correspond to the selected eigenvalues, such that
!>
!> \verbatim
!>       A = Q*A*Z**T
!>       B = Q*B*Z**T
!> \endverbatim
!>
!> \par
!> where **T** denotes the transpose.
!>
!> \par
!> The selected eigenvalues are the ones for which SELECT is TRUE.
!>
!> \par
!> The condition numbers of the deflating subspaces are computed as the
!> reciprocal of the smallest singular values of certain matrices.
!>
!> \warning
!> The Schur vectors are computed if and only if the selected eigenvalues
!> are well-conditioned.
!>
!> \param ITYPE ITYPE is INTEGER
!> \param GJWORK GJWORK is CHARACTER*1
!> The character string specifying the computation.
!> \param SELECT SELECT is LOGICAL array, dimension (N)
!> On entry, SELECT specifies the eigenvalues to be selected.
!> On exit, the SELECT array is always TRUE.
!> \param N N is INTEGER
!> The order of the matrices A and B.
!> \param A A is REAL array, dimension (LDA, N)
!> On entry, A is the upper triangular matrix in the generalized Schur
!> decomposition.
!> On exit, if IJOB >= 2, A is permuted so that the selected eigenvalues are
!> in the leading positions.
!> \param LDA LDA is INTEGER
!> The leading dimension of A.
!> \param B B is REAL array, dimension (LDB, N)
!> On entry, B is the upper triangular matrix in the generalized Schur
!> decomposition.
!> On exit, if IJOB >= 2, B is permuted so that the selected eigenvalues are
!> in the leading positions.
!> \param LDB LDB is INTEGER
!> The leading dimension of B.
!> \param Q Q is REAL array, dimension (LDQ, N)
!> On exit, Q is a orthogonal matrix whose first M columns form an
!> orthonormal basis for the selected deflating subspaces.
!> If IJOB = 1, Q is the matrix U.
!> If IJOB = 2, 3, 4, or 5, Q is the matrix Q*U.
!> \param LDQ LDQ is INTEGER
!> The leading dimension of Q.
!> \param Z Z is REAL array, dimension (LDZ, N)
!> On exit, Z is a orthogonal matrix whose first M columns form an
!> orthonormal basis for the selected deflating subspaces.
!> If IJOB = 1, Z is the matrix W.
!> If IJOB = 2, 3, 4, or 5, Z is the matrix Z*W.
!> \param LDZ LDZ is INTEGER
!> The leading dimension of Z.
!> \param ALPHAR ALPHAR is REAL array, dimension (N)
!> On exit, ALPHAR and ALPHAI contain the real parts and imaginary parts of
!> the eigenvalues of the matrix pair (A, B).
!> \param ALPHAI ALPHAI is REAL array, dimension (N)
!> See ALPHAR.
!> \param BETA BETA is REAL array, dimension (N)
!> On exit, BETA contains the denominators of the eigenvalues of the matrix
!> pair (A, B).
!> \param M M is INTEGER
!> On exit, M is the number of selected eigenvalues.
!> \param DIF DIF is REAL array, dimension (2)
!> On exit, DIF(1) stores Difu, the reciprocal condition number of the
!> selected right deflating subspace, and DIF(2) stores Difl, the
!> reciprocal condition number of the selected left deflating subspace.
!> If IJOB = 0 or 1, DIF is not referenced.
!>
!> \par
!> If IJOB = 2 or 4, DIF(1:2) are F-norm-based upper bounds on Difu and Difl.
!> If IJOB = 3 or 5, DIF(1:2) are 1-norm-based estimates of Difu and Difl.
!>
!> \par
!> If M = 0 or N, DIF(1:2) = F-norm([A, B]).
!> \par
!> If IJOB = 0 or 1, DIF is not referenced.
!>
!> \param WORK WORK is REAL array, dimension (MAX(1,LWORK))
!> On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!> \param LWORK LWORK is INTEGER
!> The dimension of the array WORK. LWORK >= 4*N+16.
!> If IJOB = 1, 2 or 4, LWORK >= MAX(4*N+16, 2*M*(N-M)).
!> If IJOB = 3 or 5, LWORK >= MAX(4*N+16, 4*M*(N-M)).
!>
!> \par
!> If LWORK = -1, then a workspace query is assumed; the routine
!> only calculates the optimal size of the WORK array, returns
!> this value as the first entry of the WORK array, and no error
!> message related to LWORK is issued by XERBLA.
!> \param IWORK IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!> On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!> \param LIWORK LIWORK is INTEGER
!> The dimension of the array IWORK. LIWORK >= 1.
!> If IJOB = 1, 2 or 4, LIWORK >= N+6.
!> If IJOB = 3 or 5, LIWORK >= MAX(2*M*(N-M), N+6).
!>
!> \par
!> If LIWORK = -1, then a workspace query is assumed; the
!> routine only calculates the optimal size of the IWORK array,
!> returns this value as the first entry of the IWORK array, and
!> no error message related to LIWORK is issued by XERBLA.
!> \param INFO INFO is INTEGER
!> =0: Successful exit.
!> <0: If INFO = -i, the i-th argument had an illegal value.
!> =1: Reordering of (A, B) failed because the transformed
!> matrix pair (A, B) would be too far from generalized
!> Schur form; the problem is very ill-conditioned.
!> (A, B) may have been partially reordered.
!> If requested, 0 is returned in DIF(*), PL and PR.
!>

Further Details:

STGSEN first collects the selected eigenvalues by computing
orthogonal U and W that move them to the top left corner of (A, B).
In other words, the selected eigenvalues are the eigenvalues of
(A11, B11) in:

              U**T*(A, B)*W = (A11 A12) (B11 B12) n1
                              ( 0  A22),( 0  B22) n2
                                n1  n2    n1  n2

where N = n1+n2 and U**T means the transpose of U. The first n1 columns
of U and W span the specified pair of left and right eigenspaces
(deflating subspaces) of (A, B).

If (A, B) has been obtained from the generalized real Schur
decomposition of a matrix pair (C, D) = Q*(A, B)*Z**T, then the
reordered generalized real Schur form of (C, D) is given by

         (C, D) = (Q*U)*(U**T*(A, B)*W)*(Z*W)**T,

and the first n1 columns of Q*U and Z*W span the corresponding
deflating subspaces of (C, D) (Q and Z store Q*U and Z*W, resp.).

Note that if the selected eigenvalue is sufficiently ill-conditioned,
then its value may differ significantly from its value before
reordering.

The reciprocal condition numbers of the left and right eigenspaces
spanned by the first n1 columns of U and W (or Q*U and Z*W) may
be returned in DIF(1:2), corresponding to Difu and Difl, resp.

The Difu and Difl are defined as:

     Difu[(A11, B11), (A22, B22)] = sigma-min( Zu )
and
     Difl[(A11, B11), (A22, B22)] = Difu[(A22, B22), (A11, B11)],

where sigma-min(Zu) is the smallest singular value of the
(2*n1*n2)-by-(2*n1*n2) matrix

     Zu = [ kron(In2, A11)  -kron(A22**T, In1) ]
          [ kron(In2, B11)  -kron(B22**T, In1) ].

Here, Inx is the identity matrix of size nx and A22**T is the
transpose of A22. kron(X, Y) is the Kronecker product between
the matrices X and Y.

When DIF(2) is small, small changes in (A, B) can cause large changes
in the deflating subspace. An approximate (asymptotic) bound on the
maximum angular error in the computed deflating subspaces is

     EPS * norm((A, B)) / DIF(2),

where EPS is the machine precision.

The reciprocal norm of the projectors on the left and right
eigenspaces associated with (A11, B11) may be returned in PL and PR.
They are computed as follows. First we compute L and R so that
P*(A, B)*Q is block diagonal, where

     P = ( I -L ) n1           Q = ( I R ) n1
         ( 0  I ) n2    and        ( 0 I ) n2
           n1 n2                    n1 n2

and (L, R) is the solution to the generalized Sylvester equation

     A11*R - L*A22 = -A12
     B11*R - L*B22 = -B12

Then PL = (F-norm(L)**2+1)**(-1/2) and PR = (F-norm(R)**2+1)**(-1/2).
An approximate (asymptotic) bound on the average absolute error of
the selected eigenvalues is

     EPS * norm((A, B)) / PL.

There are also global error bounds which valid for perturbations up
to a certain restriction:  A lower bound (x) on the smallest
F-norm(E,F) for which an eigenvalue of (A11, B11) may move and
coalesce with an eigenvalue of (A22, B22) under perturbation (E,F),
(i.e. (A + E, B + F), is

  x = min(Difu,Difl)/((1/(PL*PL)+1/(PR*PR))**(1/2)+2*max(1/PL,1/PR)).

An approximate bound on x can be computed from DIF(1:2), PL and PR.

If y = ( F-norm(E,F) / x) <= 1, the angles between the perturbed
(L', R') and unperturbed (L, R) left and right deflating subspaces
associated with the selected cluster in the (1,1)-blocks can be
bounded as

  max-angle(L, L') <= arctan( y * PL / (1 - y * (1 - PL * PL)**(1/2))
  max-angle(R, R') <= arctan( y * PR / (1 - y * (1 - PR * PR)**(1/2))

See LAPACK User's Guide section 4.11 or the following references
for more information.

Note that if the default method for computing the Frobenius-norm-
based estimate DIF is not wanted (see SLATDF), then the parameter
IDIFJB (see below) should be changed from 3 to 4 (routine SLATDF
(IJOB = 2 will be used)). See STGSYL for more details.
