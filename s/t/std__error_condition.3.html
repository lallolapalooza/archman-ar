std::error_condition

std::error_condition - represents an abstract, semantic value of an error condition.

SYNOPSIS

#include <system_error>

class error_condition;

DESCRIPTION

The class std::error_condition is a lightweight object that represents an abstract, semantic value of an error condition. It is intended to provide a generic way to represent error conditions that may have different underlying representations on different operating systems or platforms.

An error_condition object consists of two components: an integer value and a pointer to an std::error_category object. The std::error_category object provides the semantic meaning of the error condition and allows for comparisons between different error condition objects.

IN BRIEF

Represents an abstract, semantic value of an error condition.

TEMPLATE PARAMETERS

None.

MEMBER FUNCTIONS

  • error_condition() noexcept;
  • error_condition(int val, const std::error_category& cat) noexcept;
  • void assign(int val, const std::error_category& cat) noexcept;
  • int value() const noexcept;
  • const std::error_category& category() const noexcept;
  • std::string message() const;
  • explicit operator bool() const noexcept;

NON-MEMBER FUNCTIONS

  • bool operator==(const error_condition& lhs, const error_condition& rhs) noexcept;
  • bool operator!=(const error_condition& lhs, const error_condition& rhs) noexcept;
  • bool operator<(const error_condition& lhs, const error_condition& rhs) noexcept;

EXAMPLE

A simple example demonstrating the use of std::error_condition:

#include <iostream>
#include <system_error>

int main() {
    // Create an error_condition object for a generic permission error
    std::error_condition perm_error = std::errc::permission_denied;

    // Get the value and category of the error condition
    int value = perm_error.value();
    const std::error_category& category = perm_error.category();

    // Print the error message
    std::cout << "Error: " << perm_error.message() << std::endl;
    std::cout << "Value: " << value << std::endl;
    std::cout << "Category: " << category.name() << std::endl;

    return 0;
}
