النوع لقيم الأعداد الصحيحة.

val zero : int

zero هو العدد الصحيح 0.

val one : int

one هو العدد الصحيح 1.

val minus_one : int

minus_one هو العدد الصحيح -1.

val neg : int -> int

neg x هو ~-x.

val add : int -> int -> int

add x y هو عملية الجمع x + y.

val sub : int -> int -> int

sub x y هو عملية الطرح x - y.

val mul : int -> int -> int

mul x y هو عملية الضرب x * y.

val div : int -> int -> int

div x y هي عملية القسمة x / y. انظر (/) للتفاصيل.

val rem : int -> int -> int

rem x y هو باقي القسمة x mod y. انظر (mod) للتفاصيل.

val succ : int -> int

succ x هو add x 1.

val pred : int -> int

pred x هو sub x 1.

val abs : int -> int

abs x هي القيمة المطلقة لـ x. أي x إذا كان x موجبًا و neg x إذا كان x سالبًا. تحذير. قد تكون هذه القيمة سالبة إذا كان المدخل هو Int.min_int.

val max_int : int

max_int هو أكبر عدد صحيح قابل للتمثيل، 2 ^ Sys.int_size - 1 -1.

val min_int : int

min_int هو أصغر عدد صحيح قابل للتمثيل، -2 ^ Sys.int_size - 1.

val logand : int -> int -> int

logand x y هو عملية AND المنطقية على مستوى البت لـ x و y.

val logor : int -> int -> int

logor x y هو عملية OR المنطقية على مستوى البت لـ x و y.

val logxor : int -> int -> int

logxor x y هو عملية XOR المنطقية على مستوى البت لـ x و y.

val lognot : int -> int

lognot x هو النفي المنطقي على مستوى البت لـ x.

val shift_left : int -> int -> int

shift_left x n تقوم بإزاحة x إلى اليسار بمقدار n بت. النتيجة غير محددة إذا كان n < 0 أو n > Sys.int_size.

val shift_right : int -> int -> int

shift_right x n تقوم بإزاحة x إلى اليمين بمقدار n بت. هذه إزاحة حسابية: يتم تكرار بت الإشارة لـ x وإدراجه في البتات التي تم إخلاؤها. النتيجة غير محددة إذا كان n < 0 أو n > Sys.int_size.

val shift_right_logical : int -> int -> int

shift_right x n تقوم بإزاحة x إلى اليمين بمقدار n بت. هذه إزاحة منطقية: يتم إدراج أصفار في البتات التي تم إخلاؤها بغض النظر عن إشارة x. النتيجة غير محددة إذا كان n < 0 أو n > Sys.int_size.

التحويل

val to_float : int -> float

to_float x هو x كرقم عشري.

val of_float : float -> int

of_float x تقوم باقتطاع x إلى عدد صحيح. النتيجة غير محددة إذا كان الوسيط nan أو يقع خارج نطاق الأعداد الصحيحة القابلة للتمثيل.

val to_string : int -> string

to_string x هو التمثيل المكتوب لـ x بالنظام العشري.

val seeded_hash : int -> int -> int

دالة تجزئة (hash) مبذرة للأعداد الصحيحة، بنفس قيمة الإخراج مثل Hashtbl.seeded_hash. تسمح هذه الدالة بتمرير هذه الوحدة كوسيط للمُنشئ Hashtbl.MakeSeeded.

Since 5.1

val hash : int -> int

دالة تجزئة (hash) غير مبذرة للأعداد الصحيحة، بنفس قيمة الإخراج مثل Hashtbl.hash. تسمح هذه الدالة بتمرير هذه الوحدة كوسيط للمُنشئ Hashtbl.Make.

Since 5.1
