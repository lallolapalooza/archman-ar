توثيق الوظيفة/الروتين الفرعي

subroutine stpt01 (character uplo, character diag, integer n, real, dimension( * ) ap, real, dimension( * ) ainvp, real rcond, real, dimension( * ) work, real resid)

STPT01

الغرض:

!>
!> STPT01 يحسب الباقي لمصفوفة مثلثية A مضروبة في معكوسها عندما تكون A مخزنة
!> بتنسيق مضغوط:
!>    RESID = norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS ),
!> حيث EPS هو خطأ الآلة.
!>

المعاملات

UPLO 
!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A علوية أو سفلية مثلثية.
!>          = 'U':  علوية مثلثية
!>          = 'L':  سفلية مثلثية
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A وحدة مثلثية أم لا.
!>          = 'N':  غير وحدة مثلثية
!>          = 'U':  وحدة مثلثية
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          المصفوفة المثلثية الأصلية A، مضغوطة
!>          عمودياً في مصفوفة خطية.  يتم تخزين العمود j للمصفوفة A
!>          في AP كالتالي:
!>          إذا كان UPLO = 'U'، فإن AP((j-1)*j/2 + i) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'،
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) لـ j<=i<=n.
!>

AINVP

!>          AINVP is REAL array, dimension (N*(N+1)/2)
!>          عند الدخول، معكوس (المثلثي) للمصفوفة A، مضغوط
!>          عمودياً في مصفوفة خطية كما في AP.
!>          عند الخروج، يتم تدمير محتويات AINVP.
!>

RCOND

!>          RCOND is REAL
!>          المقلوب الرقم الشرطي للمصفوفة A، محسوب كـ
!>          1/(norm(A) * norm(AINV)).
!>

WORK

!>          WORK is REAL array, dimension (N)
!>

RESID

!>          RESID is REAL
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
