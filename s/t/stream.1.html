stream(1)

الحزمة: imagemagick

التراخيص: custom

stream(1) دليل الأوامر العامة stream(1)

الاسم

stream - أداة خفيفة الوزن لبث مكون بكسل واحد أو أكثر من الصورة أو جزء من الصورة إلى تنسيقات التخزين التي تختارها.

الاستخدام

magick stream [خيارات] ملف-الإدخال ملف-الإخراج

نظرة عامة

Stream هي أداة خفيفة الوزن لبث مكون بكسل واحد أو أكثر من الصورة أو جزء من الصورة إلى تنسيقات التخزين التي تختارها. تكتب مكونات البكسل كما تتم قراءتها من الصورة المدخلة سطراً بسطر، مما يجعل stream مرغوبة عند العمل مع الصور الكبيرة أو عندما تحتاج إلى مكونات بكسل خام.

لمزيد من المعلومات حول أمر stream، افتح متصفحك على file:///usr/share/doc/ImageMagick-7/www/stream.html أو https://imagemagick.org/script/stream.php.

الوصف

إعدادات الصورة:
-authenticate value فك تشفير الصورة بهذه الكلمة المرور
-colorspace type مساحة ألوان الصورة البديلة
-compress type نوع ضغط البكسل عند كتابة الصورة
-define format:option
تحديد خيار أو أكثر لصيغة الصورة
-density geometry الكثافة الأفقية والرأسية للصورة
-depth value عمق الصورة
-extract geometry استخراج منطقة من الصورة
-identify تحديد صيغة وخصائص الصورة
-interlace type نوع مخطط التشبيك للصورة
-interpolate method طريقة استيفاء لون البكسل
-limit type value حد مورد ذاكرة البكسل
-map components مكون بكسل واحد أو أكثر
-monitor مراقبة التقدم
-quantize colorspace تقليل الألوان في مساحة الألوان هذه
-quiet قمع جميع رسائل التحذير
-regard-warnings الانتباه إلى رسائل التحذير
-respect-parentheses تظل الإعدادات سارية المفعول حتى حد القوس
-sampling-factor geometry
عامل أخذ العينات الأفقي والرأسي
-seed value بذرة تسلسل جديد من الأرقام شبه العشوائية
-set attribute value تعيين سمة صورة
-size geometry عرض وارتفاع الصورة
-storage-type type نوع تخزين البكسل
-synchronize مزامنة الصورة مع جهاز التخزين
-taint الإعلان عن تعديل الصورة
-transparent-color color
اللون الشفاف
-verbose طباعة معلومات مفصلة عن الصورة
-virtual-pixel method
طريقة الوصول إلى البكسل الافتراضي

خيارات متنوعة:
-channel mask تعيين قناع قناة الصورة
-debug events عرض معلومات تصحيح مفصلة
-help طباعة خيارات البرنامج
-log format تنسيق معلومات التصحيح
-list type طباعة قائمة بالحجج المدعومة للخيارات
-version طباعة معلومات الإصدار

افتراضيًا، يتم تحديد صيغة الصورة لـ `file' بواسطة رقم السحر الخاص بها. لتحديد صيغة صورة معينة، ضع اسم صيغة الصورة متبوعًا بنقطتين رأسيتين (مثل ps:image) قبل اسم الملف أو حدد نوع الصورة كلاحقة لاسم الملف (مثل image.ps). حدد `file' كـ '-' للإدخال أو الإخراج القياسي.
