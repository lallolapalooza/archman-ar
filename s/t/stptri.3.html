توثيق الوظيفة/الروتين الفرعي

subroutine stptri (character uplo, character diag, integer n, real, dimension( * ) ap, integer info)

STPTRI

الغرض:

!>
!> STPTRI يحسب معكوس مصفوفة مثلثية حقيقية علوية أو سفلية مخزنة بصيغة مضغوطة.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular; (A مصفوفة مثلثة علوية)
!>          = 'L':  A is lower triangular. (A مصفوفة مثلثة سفلية)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular; (A مثلثة غير وحدة)
!>          = 'U':  A is unit triangular. (A مثلثة وحدة)
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0. (رتبة المصفوفة A. N أكبر من أو يساوي 0)
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          On entry, the upper or lower triangular matrix A, stored
!>          columnwise in a linear array.  The j-th column of A is stored
!>          in the array AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*((2*n-j)/2) = A(i,j) for j<=i<=n.
!>          See below for further details. (انظر أدناه لمزيد من التفاصيل)
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same packed storage format. (عند الخروج، معكوس المصفوفة الأصلية (المثلثة)، بنفس صيغة التخزين المضغوطة)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit (خروج ناجح)
!>          < 0:  if INFO = -i, the i-th argument had an illegal value (إذا كان INFO = -i، كان الوسيط i له قيمة غير قانونية)
!>          > 0:  if INFO = i, A(i,i) is exactly zero.  The triangular
!>                matrix is singular and its inverse can not be computed. (إذا كان INFO = i، فإن A(i,i) يساوي صفرًا بالضبط. المصفوفة المثلثية منفردة ولا يمكن حساب معكوسها.)
!>

تفاصيل إضافية:

!>
!>  يمكن نقل مصفوفة مثلثة A إلى تخزين مضغوط باستخدام أحد مقاطع البرنامج التالية:
!>
!>  UPLO = 'U':                      UPLO = 'L':
!>
!>        JC = 1                           JC = 1
!>        DO 2 J = 1, N                    DO 2 J = 1, N
!>           DO 1 I = 1, J                    DO 1 I = J, N
!>              AP(JC+I-1) = A(I,J)              AP(JC+I-J) = A(I,J)
!>      1    CONTINUE                    1    CONTINUE
!>           JC = JC + J                      JC = JC + N - J + 1
!>      2 CONTINUE                       2 CONTINUE
!>
