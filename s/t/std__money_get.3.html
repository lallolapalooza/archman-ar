Detailed Description

Faceted to imbue input streams with the ability to parse monetary values. This is a base class. For the template parameters, see std::money_get.

In order to use this facet, you must imbue a locale with it. For example:

  locale mylocale(locale::classic(), new money_get<char>);
  cin.imbue(mylocale);
  cin >> money;

This class implements the C++ standard library's support for monetary value formatting. It is designed to work with other locale facets like ctype and numpunct to interpret and format monetary values according to the rules of a specific locale.

The primary interface for this facet is provided by the get() member functions. These functions take an input iterator range, an internationalization flag, an IO stream object, an error state flag, and a variable to store the parsed monetary value.

The get() functions delegate their work to virtual functions do_get(). This allows derived classes to customize the parsing behavior.

The facet also provides a static member id which is used by the locale system to identify and retrieve facet instances.

Implement this function to parse a monetary value from the input stream defined by the iterators __s and __end. The monetary value should be interpreted according to the moneypunct and ctype facets retrieved from __io. The __intl parameter indicates whether to use international or national formatting conventions.

If successful, the function stores the parsed value in __units as an integer multiplied by the number of fractional digits (e.g., $10.01 would be stored as 1001). The function should return an iterator pointing to the character immediately following the parsed monetary value.

If parsing fails, the function should set the error state __err to __io.failbit. If the entire input stream is consumed before parsing is complete, __io.eofbit should also be set.

This function is intended to be overridden by derived classes to provide custom monetary parsing behavior.

Implement this function to parse a monetary value from the input stream defined by the iterators __s and __end. The monetary value should be interpreted according to the moneypunct and ctype facets retrieved from __io. The __intl parameter indicates whether to use international or national formatting conventions.

If successful, the function stores the parsed value as a string of digits in __digits. For example, the string "$10.01" would result in "1001" being stored in __digits. The function should return an iterator pointing to the character immediately following the parsed monetary value.

If parsing fails, the function should set the error state __err to __io.failbit. If the entire input stream is consumed before parsing is complete, __io.eofbit should also be set.

This function is intended to be overridden by derived classes to provide custom monetary parsing behavior.

This function is called by std::money_get::get(). It is related to std::ctype::widen().

template<typename _CharT, typename _InIter> iter_type std::money_get< _CharT, _InIter >::get (iter_type __s, iter_type __end, bool __intl, ios_base & __io, ios_base::iostate & __err, long double& __units) const [inline]

Read and parse a monetary value. This function reads characters from __s, interprets them as a monetary value according to moneypunct and ctype facets retrieved from io.getloc(), and returns the result in units as an integral value moneypunct::frac_digits() * the actual amount. For example, the string $10.01 in a US locale would store 1001 in units.

Any characters not part of a valid money amount are not consumed.

If a money value cannot be parsed from the input stream, sets err=(err|io.failbit). If the stream is consumed before finishing parsing, sets err=(err|io.failbit|io.eofbit). units is unchanged if parsing fails.

This function works by returning the result of do_get().
