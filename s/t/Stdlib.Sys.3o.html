val argv : string array

وسائط سطر الأوامر المعطاة للعملية. العنصر الأول هو اسم الأمر المستخدم لاستدعاء البرنامج. العناصر التالية هي وسائط سطر الأوامر المعطاة للبرنامج.

val executable_name : string

اسم الملف الذي يحتوي على الملف التنفيذي قيد التشغيل حاليًا. قد يكون هذا الاسم مطلقًا أو نسبيًا للدليل الحالي، اعتمادًا على النظام الأساسي وما إذا كان البرنامج قد تم تجميعه إلى بايت كود أو ملف تنفيذي أصلي.

val file_exists : string -> bool

اختبار ما إذا كان ملف بالاسم المحدد موجودًا.

val is_directory : string -> bool

يعيد true إذا كان الاسم المحدد يشير إلى دليل، و false إذا كان يشير إلى نوع ملف آخر.

منذ 4.05

val command : string -> int

تنفيذ أمر shell المحدد وإعادة رمز الخروج الخاص به.

عادةً ما يكون الوسيط الخاص بـ Sys.command هو اسم أمر متبوعًا بصفر أو واحد أو عدة وسائط، مفصولة بمسافات بيضاء. يتم تفسير الوسيط المعطى بواسطة shell: إما shell Windows cmd.exe لمنافذ OCaml Win32، أو shell POSIX sh لمنافذ أخرى. يمكن أن يحتوي على أوامر shell المضمنة مثل echo ، وأيضًا أحرف خاصة مثل إعادة توجيه الملفات > و < ، والتي سيتم احترامها من قبل shell.

على العكس من ذلك، يجب اقتباس أو تهريب المسافات البيضاء أو الأحرف الخاصة الخاصة بالـ shell التي تحدث في أسماء الأوامر أو في وسائطها حتى لا يفسرها الـ shell. تختلف قواعد الاقتباس بين shell POSIX و shell Windows. يؤدي Filename.quote_command إلى الاقتباس المناسب بالنظر إلى اسم الأمر وقائمة الوسائط وإعادة التوجيهات الاختيارية للملفات.

إعادة دليل العمل الحالي للعملية.

val readdir : string -> string array

إعادة أسماء جميع الملفات الموجودة في الدليل المحدد. الأسماء التي تدل على الدليل الحالي والدليل الأصل ( "." و ".." في Unix) لا يتم إرجاعها. كل سلسلة نصية في النتيجة هي اسم ملف بدلاً من مسار كامل. لا يوجد ضمان بأن سلاسل الأسماء في المصفوفة الناتجة ستظهر بأي ترتيب معين؛ فهي ليست، على وجه الخصوص، مضمونة للظهور بترتيب أبجدي.

val io_buffer_size : int

حجم مخازن C المؤقتة المستخدمة بواسطة نظام التشغيل وأولويات الإدخال/الإخراج لمكتبة unix.

تستخدم الأوامر الأولية التي تقرأ أو تكتب إلى قيم من نوع string أو bytes عمومًا مخزنًا مؤقتًا وسيطًا بهذا الحجم لتجنب الاحتفاظ بقفل المجال.

val interactive : bool ref

يتم تعيين هذا المرجع مبدئيًا إلى false في البرامج المستقلة وإلى true إذا كان الكود قيد التنفيذ تحت نظام الوحدة التفاعلي ocaml.

تنبيه unsynchronized_access. حالة التفاعل هي حالة عالمية قابلة للتغيير.

val os_type : string

نظام التشغيل الذي ينفذ حاليًا برنامج OCaml. أحد

- "Unix" (لجميع إصدارات Unix، بما في ذلك Linux و Mac OS X)،

- "Win32" (لـ MS-Windows، OCaml تم تجميعه باستخدام MSVC++ أو MinGW-w64)،

- "Cygwin" (لـ MS-Windows، OCaml تم تجميعه باستخدام Cygwin).

type backend_type =
| Native
| Bytecode
| Other of string

حاليا، يدعم التوزيع الرسمي فقط Native و Bytecode، ولكن يمكن أن تكون هناك واجهات خلفية أخرى مع مترجمات بديلة، على سبيل المثال، javascript.
