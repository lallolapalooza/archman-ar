stl2dcm(1)

الحزمة: dcmtk

التراخيص: BSD-3-Clause

stl2dcm(1) OFFIS DCMTK stl2dcm(1)

الاسم

stl2dcm - تغليف ملف STL في صيغة ملف DICOM

ملخص

stl2dcm [خيارات] stlfile-in dcmfile-out

الوصف

تقوم الأداة المساعدة stl2dcm بقراءة ملف STL (stlfile-in)، وتحويله إلى مثيل تخزين STL المغلف DICOM وتخزين البيانات المحولة في ملف إخراج (dcmfile-out).

المعلمات

stlfile-in   اسم ملف STL الإدخال المراد تغليفه
dcmfile-out  اسم ملف DICOM الإخراج ("-" للمعيار القياسي)

الخيارات

خيارات عامة

  -h   --help
         طباعة نص المساعدة هذا والخروج
       --version
         طباعة معلومات الإصدار والخروج
       --arguments
         طباعة وسيطات سطر الأوامر الموسعة
  -q   --quiet
         وضع الهدوء، لا تطبع تحذيرات أو أخطاء
  -v   --verbose
         وضع المطول، طباعة تفاصيل المعالجة
  -d   --debug
         وضع التصحيح، طباعة معلومات التصحيح
  -ll  --log-level  [l]evel: string constant
         (fatal, error, warn, info, debug, trace)
         استخدم المستوى l للمسجل
  -lc  --log-config  [f]ilename: string
         استخدم ملف الإعداد f للمسجل

خيارات مستند DICOM

عنوان المستند:
  +t   --title  [t]itle: string (الافتراضي: فارغ)
         عنوان المستند
  +cn  --concept-name  [CSD] [CV] [CM]: string (الافتراضي: فارغ)
         تمثيل مشفر لعنوان المستند محدد بواسطة
         معرّف مخطط الترميز CSD، وقيمة الرمز CV، ومعنى الرمز CM
بيانات المريض:
  +pn  --patient-name  [n]ame: string
         اسم المريض بصيغة PN في DICOM
  +pi  --patient-id  [i]d: string
         معرّف المريض
  +pb  --patient-birthdate  [d]ate: string (YYYYMMDD)
         تاريخ ميلاد المريض
  +ps  --patient-sex  [s]ex: string (M, F أو O)
         جنس المريض
الدراسة والسلسلة:
  +sg  --generate
         إنشاء معرفات دراسة وسلسلة جديدة (الافتراضي)
  +st  --study-from  [f]ilename: string
         قراءة بيانات المريض/الدراسة من ملف DICOM
  +se  --series-from  [f]ilename: string
         قراءة بيانات المريض/الدراسة/السلسلة من ملف DICOM
رقم المثيل:
  +i1  --instance-one
         استخدام رقم المثيل 1 (الافتراضي، ليس مع +se)
  +ii  --instance-inc
         زيادة رقم المثيل (مع +se فقط)
  +is  --instance-set [i]nstance number: integer
         استخدام رقم المثيل i
التعليق المحروق:
  +an  --annotation-yes
         يحتوي المستند على بيانات تعريف المريض (الافتراضي)
  -an  --annotation-no
         لا يحتوي المستند على بيانات تعريف المريض
معدات عامة محسنة:
  +mn  --manufacturer  [n]ame: string
         اسم الشركة المصنعة
  +mm  --manufacturer-model  [n]ame: string
         نموذج الشركة المصنعة
  +ds  --device-serial  [n]umber: string
         الرقم التسلسلي للجهاز
  +sv  --software-versions  [v]ersions: string
         إصدارات البرامج
وحدات القياس النموذج ثلاثي الأبعاد:
  +mu  --measurement-units  [CSD] [CV] [CM]: string
         وحدات القياس مع معرّف مخطط الترميز CSD،
         قيمة الرمز CV، ومعنى الرمز CM (الافتراضي: UCUM, um, um)

خيارات المعالجة

خيارات المعالجة الأخرى:
  -k   --key  [k]ey: gggg,eeee="str", path or dictionary name="str"
         إضافة سمة إضافية

خيارات الإخراج

صيغة ملف الإخراج:
  +F   --write-file
         صيغة ملف الكتابة (الافتراضي)
  -F   --write-dataset
         كتابة مجموعة البيانات بدون معلومات تعريفية للملف
ترميز طول المجموعة:
  +g=  --group-length-recalc
         إعادة حساب أطوال المجموعات إذا كانت موجودة (الافتراضي)
  +g   --group-length-create
         الكتابة دائمًا بعناصر طول المجموعة
  -g   --group-length-remove
         الكتابة دائمًا بدون عناصر طول المجموعة
ترميز الطول في التسلسلات والعناصر:
  +e   --length-explicit
         الكتابة بأطوال صريحة (الافتراضي)
  -e   --length-undefined
         الكتابة بأطوال غير محددة
حشو نهاية مجموعة البيانات (ليس مع --write-dataset):
  -p   --padding-off
         لا حشو (ضمنية إذا --write-dataset)
  +p   --padding-create  [f]ile-pad [i]tem-pad: integer
         محاذاة الملف على مضاعف f بايت
         والعناصر على مضاعف i بايت

ملاحظات

مصادر السمات

قد يتم تزويد التطبيق ببعض المدخلات الإضافية لملء السمات الإلزامية (والاختيارية) في ملف DICOM الجديد مثل معلومات المريض والدراسة والسلسلة:

  • يمكن استخدام خيار --key لإضافة سمات إضافية إلى ملف إخراج DICOM.
  • من الممكن أيضًا تحديد التسلسلات والعناصر والسمات المتداخلة باستخدام خيار --key. في هذه الحالات، يجب استخدام ترميز "مسار" خاص. يمكن العثور على تفاصيل حول ترميز المسار هذا في وثائق dcmodify.
  • يمكن استخدام خيار --key أكثر من مرة.
  • قد يكون جزء القيمة (بعد '=') غائبًا مما يتسبب في تعيين السمة بطول صفر.
  • يرجى العلم أن خيار --key يتم تطبيقه في النهاية، مباشرة قبل حفظ ملف DICOM، لذلك لا يوجد أي تحقق من القيمة على الإطلاق.

التسجيل

يمكن للمستخدم تحديد مستوى إخراج التسجيل للأدوات المختلفة لسطر الأوامر والمكتبات الأساسية. افتراضيًا، يتم فقط كتابة الأخطاء والتحذيرات إلى تيار الخطأ القياسي. باستخدام الخيار --verbose، يتم أيضًا الإبلاغ عن الرسائل المعلوماتية مثل تفاصيل المعالجة. يمكن استخدام الخيار --debug للحصول على مزيد من التفاصيل حول النشاط الداخلي، على سبيل المثال، لأغراض التصحيح. يمكن تحديد مستويات تسجيل أخرى باستخدام الخيار --log-level. في وضع --quiet، يتم الإبلاغ فقط عن الأخطاء القاتلة. في مثل هذه الأحداث الخطيرة، سينتهي التطبيق عادةً. لمزيد من التفاصيل حول مستويات التسجيل المختلفة، راجع وثائق وحدة "oflog".

في حالة رغبة كتابة إخراج التسجيل إلى ملف (اختياريًا مع تدوير ملف السجل)، أو إلى syslog (يونكس) أو سجل الأحداث (ويندوز)، يمكن استخدام الخيار --log-config. يسمح ملف الإعداد هذا أيضًا بتوجيه رسائل معينة فقط إلى تيار إخراج معين وتصفية رسائل معينة بناءً على الوحدة أو التطبيق الذي تم إنشاؤها فيه. يتم توفير ملف إعداد مثال في <etcdir>/logger.cfg.

سطر الأوامر

تستخدم جميع أدوات سطر الأوامر الترميز التالي للمعلمات: الأقواس المربعة تحيط بالقيم الاختيارية (0-1)، تشير النقاط الثلاث المتتالية إلى أن قيمًا متعددة مسموح بها (1-n)، مزيج من كليهما يعني 0 إلى n قيم.

يتم تمييز خيارات سطر الأوامر عن المعلمات بواسطة علامة '+' أو '-' في البداية، على التوالي. عادةً، يكون ترتيب وموضع خيارات سطر الأوامر اعتباطيًا (أي يمكن أن تظهر في أي مكان). ومع ذلك، إذا كانت الخيارات متعارضة، يتم استخدام المظهر الأخير. يتوافق هذا السلوك مع قواعد التقييم القياسية لأصداف Unix الشائعة.

بالإضافة إلى ذلك، يمكن تحديد ملف أمر واحد أو أكثر باستخدام علامة '@' كبادئة لاسم الملف (على سبيل المثال، @command.txt). يتم استبدال وسيطة الأمر هذه بمحتوى الملف النصي المقابل (تُعامل المسافات البيضاء المتعددة كفاصل واحد ما لم تكن موجودة بين علامتي اقتباس) قبل أي تقييم آخر. يرجى ملاحظة أنه لا يمكن لملف الأمر أن يحتوي على ملف أمر آخر. هذا النهج البسيط والفعال يسمح بتلخيص التركيبات الشائعة للخيارات/المعلمات ويتجنب سطور الأوامر الطويلة والمربكة (يتم توفير مثال في الملف <datadir>/dumppat.txt).

رموز الخروج

تستخدم الأداة المساعدة stl2dcm رموز الخروج التالية عند الانتهاء. هذا يمكّن المستخدم من التحقق من سبب انتهاء التطبيق.

عام

EXITCODE_NO_ERROR                 0
EXITCODE_COMMANDLINE_SYNTAX_ERROR 1
EXITCODE_MEMORY_EXHAUSTED         4

أخطاء ملف الإدخال

EXITCODE_CANNOT_READ_INPUT_FILE   20
EXITCODE_NO_INPUT_FILES

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
