سلاسل نصية.

السلسلة النصية s ذات الطول n هي تسلسل قابل للفهرسة وغير قابل للتعديل مكون من n بايت. لأسباب تاريخية، تسمى هذه البايتات أحرفًا.

يتم تعريف معنى وظائف السلسلة النصية من حيث الفهارس والمواقع. يتم تمثيلها ووصفها على النحو التالي.

المواقع 0 1 2 3 4 n-1 n +---+---+---+---+ +-----+ الفهارس | 0 | 1 | 2 | 3 | ... | n-1 | +---+---+---+---+ +-----+

-فهرس i للسلسلة s هو عدد صحيح في النطاق [ 0 ; n-1 ]. يمثل البايت (الحرف) i للسلسلة s ، والذي يمكن الوصول إليه عبر عامل الفهرسة الثابت s.[i].

-موقع i للسلسلة s هو عدد صحيح في النطاق [ 0 ; n ]. يمثل الموضع في بداية السلسلة، أو بين فهرسين، أو في نهاية السلسلة. البايت ذو الفهرس i يقع بين الموضع i والموضع i+1.

يعتبر عددان صحيحان start و len بمثابة سلسلة فرعية صالحة للسلسلة s إذا كان len >= 0 وكان start و start+len موقعين للسلسلة s.

نصوص Unicode. السلاسل النصية هي تسلسلات عشوائية من البايتات، ويمكن أن تحتوي على أي نوع من الترميزات النصية. ومع ذلك، فإن التوصية لتخزين نصوص Unicode في سلاسل OCaml هي UTF-8. هذا هو الترميز المستخدم للهروب من Unicode في ثوابت السلسلة. على سبيل المثال، السلسلة "\u{1F42B}" هي ترميز UTF-8 للحرف Unicode U+1F42B.

قابلية التعديل السابقة. قبل OCaml 4.02، كانت السلاسل النصية قابلة للتعديل بدلاً من كونها غير قابلة للتعديل، مثل تسلسلات البايتات Bytes.t. في OCaml 4، كانت هناك علامات تجميع وخيارات تكوين مختلفة لدعم فترة الانتقال من القابلة للتعديل إلى غير القابلة للتعديل. هذه الخيارات لم تعد متاحة، والسلاسل النصية الآن غير قابلة للتعديل دائمًا.

يمكن استخدام النسخة المسماة لهذه الوحدة كما هو موضح في وحدة StdLabels.

val make : int -> char -> string

make n c هي سلسلة نصية بطول n حيث يخزن كل فهرس الحرف c.

تطلق Invalid_argument إذا كان n < 0 أو n > Sys.max_string_length.

val init : int -> (int -> char) -> string

init n f هي سلسلة نصية بطول n حيث يخزن الفهرس i الحرف f i (يتم استدعاؤه بترتيب الفهرس المتزايد).

تطلق Invalid_argument إذا كان n < 0 أو n > Sys.max_string_length.

الدمج

ملاحظة. العامل الثنائي (^) يدمج سلسلتين نصيتين.

val concat : string -> string list -> string

concat sep ss يدمج قائمة السلاسل النصية ss، مع إدراج الفاصل sep بين كل منها.

إذا كان الناتج أطول من Sys.max_string_length بايت، يتم إطلاق Invalid_argument.

val cat : string -> string -> string

cat s1 s2 يدمج s1 و s2 ( s1 ^ s2 ).

منذ 4.13

إذا كان الناتج أطول من Sys.max_string_length بايت، يتم إطلاق Invalid_argument.

استخراج السلاسل الفرعية

val sub : string -> int -> int -> string

sub s pos len هي سلسلة نصية بطول len تحتوي على السلسلة الفرعية للسلسلة s التي تبدأ من الموضع pos ولها الطول len.

يتم إطلاق Invalid_argument إذا كان pos و len لا يحددان سلسلة فرعية صالحة للسلسلة s.

val split_on_char : char -> string -> string list

split_on_char sep s هي قائمة بجميع السلاسل الفرعية (المحتملة والفارغة) للسلسلة s التي تفصلها الحرف sep. إذا كانت s فارغة، فالناتج هو القائمة [""].

يتم تحديد نتيجة الدالة بواسطة الثوابت التالية:

-القائمة ليست فارغة.

-دمج عناصرها مع sep كفاصل يعيد سلسلة نصية تساوي المدخل ( concat (make 1 sep) ).

-لا تحتوي أي من السلاسل النصية في النتيجة على الحرف sep.

val fold_left : ('acc -> char -> 'acc) -> 'acc -> string -> 'acc

fold_left f x s تحسب f (... (f (f x s.[0]) s.[1]) ...) s.[n-1]، حيث n هو طول السلسلة s.

Since 4.00

val escaped : string -> string

escaped s هي s مع الأحرف الخاصة ممثلة بتسلسلات الهروب، باتباع الاتفاقيات المعجمية لـ OCaml.

يتم الهروب من جميع الأحرف خارج نطاق US-ASCII القابل للطباعة [0x20;0x7E]، بالإضافة إلى الشرطة المائلة العكسية (0x2F) وعلامة الاقتباس المزدوجة (0x22).

الدالة Scanf.unescaped هي معكوس يسار للدالة escaped ، أي Scanf.unescaped (escaped s) = s لأي سلسلة s (ما لم تفشل escaped s).

Raises Invalid_argument إذا كان الناتج أطول من Sys.max_string_length بايت.

val iter : (char -> unit) -> string -> unit

iter f s تطبق الدالة f بالدور على جميع أحرف s . وهي تعادل f s.[0]; f s.[1]; ...; f s.[length s - 1]; () .

iteri تشبه String.iter ، ولكن الدالة تُعطى أيضًا فهرس الحرف المقابل.

التدقيق الإملائي

val edit_distance : ?limit:int -> t -> t -> int

edit_distance s0 s1 هو عدد التعديلات الفردية للأحرف (المفهومة على أنها إدراج، حذف، استبدال، تبديل) المطلوبة لتغيير s0 إلى s1 .

إذا تم توفير limit ، فإن الدالة تعود مع limit بمجرد التأكد من أن s0 و s1 لديهما مسافة لا تقل عن limit . هذا أسرع إذا كان لديك حد ثابت، على سبيل المثال للتدقيق الإملائي.

تفترض الدالة أن السلاسل مرمزة بـ UTF-8 وتستخدم Uchar.t لمفهوم الحرف. يتم استبدال أخطاء فك الترميز بـ Uchar.rep . تطبيع السلاسل إلى NFC يعطي نتائج أفضل.

ملاحظة. هذا يطبق مسافة محاذاة السلسلة المثلى (OSA) الأبسط، وليس مسافة Damerau-Levenshtein. مع هذه الدالة "ca" و "abc" لهما مسافة 3 وليست 2.

Since 5.4

val spellcheck : ?max_dist:(string -> int) -> ((string -> unit) -> unit) -> string -> string list

spellcheck iter_dict s هي السلاسل التي تم تعدادها بواسطة المكرر iter_dict والتي تكون String.edit_distance إلى s هي الأصغر ولا تتجاوز max_dist s . إذا تم إرجاع تصحيحات متعددة، فإن ترتيبها هو كما هو موجود في iter_dict . الحد الافتراضي max_dist s هو:

- 0 إذا كان s يحتوي على 0 إلى 2 حرف Unicode.

- 1 إذا كان s يحتوي على 3 إلى 4 أحرف Unicode.

- 2 بخلاف ذلك.

إذا كانت القاموس الخاص بك قائمة l ، فإن iter_dict مناسبة يتم توفيرها بواسطة (fun yield -> List.iter yield l) .

يفترض أن جميع السلاسل مرمزة بـ UTF-8، ويتم استبدال أخطاء فك الترميز بأحرف Uchar.rep .

Since 5.4

فك ترميز الأعداد الصحيحة الثنائية

تقوم الدوال في هذا القسم بفك ترميز الأعداد الصحيحة ثنائيًا من السلاسل.

تثير جميع الدوال التالية Invalid_argument إذا كانت الأحرف المطلوبة في الفهرس i لفك ترميز العدد الصحيح غير متوفرة.

الترميز منخفض الترتيب (على التوالي، كبير الترتيب) يعني أن البايتات الأقل (على التوالي، الأكثر) أهمية يتم تخزينها أولاً. يُعرف ترميز كبير الترتيب أيضًا بترتيب بايت الشبكة. الترميز الأصلي هو إما ترتيب منخفض أو ترتيب كبير اعتمادًا على Sys.big_endian.

يتم تمثيل الأعداد الصحيحة 32 بت و 64 بت بأنواع int32 و int64 ، والتي يمكن تفسيرها كأرقام موقعة أو غير موقعة.

يتم تمثيل الأعداد الصحيحة 8 بت و 16 بت بنوع int ، الذي يحتوي على بتات أكثر من الترميز الثنائي. يتم تمديد هذه البتات الإضافية (أو تمديدها بالصفر) للدوال التي تفك ترميز أعداد صحيحة 8 بت أو 16 بت وتمثيلها بقيم int.
