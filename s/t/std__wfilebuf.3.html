DESCRIPTION

A basic_filebuf associates a stream buffer with a C language FILE object.

This is the base class for basic_fstream. It is templated on the character type and character traits.

When it is constructed with a C FILE pointer, it becomes the stream buffer for that file.

Otherwise, it allocates a buffer and opens a new file using fopen() with the given name and mode.
