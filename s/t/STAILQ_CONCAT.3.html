NAME

DESCRIPTION

These macros provide a way to implement a singly linked list that is suitable for use as a queue. The main difference between this and a normal singly linked list is that the tail is kept track of. This allows for efficient insertion at both the head and the tail of the list.

A list is normally declared as:

STAILQ_HEAD(list_name, type_name) headvar = STAILQ_HEAD_INITIALIZER(headvar);

Where type_name is the name of the structure that contains the list entry, and list_name is the name of the structure that will be used to refer to the head of the list.

STAILQ_HEAD_INITIALIZER( x) is a macro that expands to an initializer for an empty queue of type STAILQ_HEAD. This can be used to initialize a STAILQ_HEAD variable statically.

Each element in the list must be of type type_name and must contain a field of type struct staqlq_entry. This field is used by the macros to link the elements together.

STAILQ_CONCAT( headp1, headp2) concats the list headp2 onto the end of the list headp1. The list headp2 becomes empty after this operation.

The following macros are provided for operating on the queues:

STAILQ_FIRST
Returns the first element in the queue, or NULL if the queue is empty.
STAILQ_LAST
Returns the last element in the queue, or NULL if the queue is empty.
STAILQ_NEXT( elm, field)
Returns the next element in the queue after elm, or NULL if elm is the last element.
STAILQ_PREV( elm, field)
Returns the previous element in the queue before elm, or NULL if elm is the first element.
STAILQ_EMPTY( headp)
Returns true if the queue is empty, false otherwise.
STAILQ_INIT( headp)
Initializes the queue headp to be empty.
STAILQ_INSERT_HEAD( headp, elm, field)
Inserts the element elm at the head of the queue headp. The field argument is the name of the list entry field within the structure that elm points to.
STAILQ_INSERT_TAIL( headp, elm, field)
Inserts the element elm at the tail of the queue headp. The field argument is the name of the list entry field within the structure that elm points to.
STAILQ_INSERT_AFTER( headp, listelm, elm, field)
Inserts the element elm after the element listelm in the queue headp. The field argument is the name of the list entry field within the structure that elm points to.
STAILQ_INSERT_BEFORE( headp, listelm, elm, field)
Inserts the element elm before the element listelm in the queue headp. The field argument is the name of the list entry field within the structure that elm points to.
STAILQ_REMOVE_HEAD( headp, field)
Removes the first element from the queue headp and returns it. Returns NULL if the queue is empty. The field argument is the name of the list entry field within the structure that the removed element pointed to.
STAILQ_REMOVE( headp, elm, field)
Removes the element elm from the queue headp. The field argument is the name of the list entry field within the structure that elm points to.
STAILQ_SWAP( headp1, headp2, type)
Swaps the contents of the queues headp1 and headp2. The type argument is the name of the structure that will be used to refer to the head of the list.

RETURN VALUE

Functions that retrieve elements from the queue return a pointer to the element, or NULL if the queue is empty. Functions that modify the queue do not return a value.

VERSIONS

The STAILQ* macros are available in libutil.

BUGS

These macros are implemented using macros, and therefore do not appear in the symbol table. This can make debugging more difficult.

STANDARDS

These macros are similar to those found in BSD systems.

HISTORY

The STAILQ* macros first appeared in 4.3BSD.

EXAMPLES

The following example shows how to use the STAILQ* macros to implement a simple queue of integers.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct	item {
	int	data;
	STAILQ_ENTRY(item) entries;
};

STAILQ_HEAD(itemhead, item);

int
main(void)
{
	struct itemhead head;
	struct item *np, *n1, *n2;

	STAILQ_INIT(&head);

	/* Allocate and insert items */
	np = malloc(sizeof(struct item));
	np->data = 1;
	STAILQ_INSERT_TAIL(&head, np, entries);

	np = malloc(sizeof(struct item));
	np->data = 2;
	STAILQ_INSERT_TAIL(&head, np, entries);

	np = malloc(sizeof(struct item));
	np->data = 3;
	STAILQ_INSERT_TAIL(&head, np, entries);

                                     /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}

الوصف

توفر هذه الماكرو طريقة لتنفيذ قائمة مرتبطة بشكل فردي مناسبة للاستخدام كطابور. الفرق الرئيسي بين هذه القائمة وقائمة فردية عادية هو أنه يتم تتبع الذيل. هذا يسمح بالإدخال بكفاءة في كل من رأس وذيل القائمة.

عادة ما يتم تعريف القائمة على النحو التالي:

STAILQ_HEAD(list_name, type_name) headvar = STAILQ_HEAD_INITIALIZER(headvar);

حيث type_name هو اسم الهيكل الذي يحتوي على إدخال القائمة، و list_name هو الاسم الذي سيتم استخدامه للإشارة إلى رأس القائمة.

STAILQ_HEAD_INITIALIZER( x) هو ماكرو يتوسع إلى مُهيئ لطابور فارغ من النوع STAILQ_HEAD. يمكن استخدام هذا لتهيئة متغير STAILQ_HEAD بشكل ثابت.

يجب أن يكون كل عنصر في القائمة من النوع type_name ويجب أن يحتوي على حقل من النوع struct staqlq_entry. يستخدم هذا الحقل بواسطة الماكرو لربط العناصر معًا.

STAILQ_CONCAT( headp1, headp2) يربط القائمة headp2 بنهاية القائمة headp1. تصبح القائمة headp2 فارغة بعد هذه العملية.

الماكرو التالية متوفرة لتشغيل الطوابير:

STAILQ_FIRST
يعيد العنصر الأول في الطابور، أو NULL إذا كان الطابور فارغًا.
STAILQ_LAST
يعيد العنصر الأخير في الطابور، أو NULL إذا كان الطابور فارغًا.
STAILQ_NEXT( elm, field)
يعيد العنصر التالي في الطابور بعد elm، أو NULL إذا كان elm هو العنصر الأخير.
STAILQ_PREV( elm, field)
يعيد العنصر السابق في الطابور قبل elm، أو NULL إذا كان elm هو العنصر الأول.
STAILQ_EMPTY( headp)
يعيد true إذا كان الطابور فارغًا، false بخلاف ذلك.
STAILQ_INIT( headp)
يقوم بتهيئة الطابور headp ليكون فارغًا.
STAILQ_INSERT_HEAD( headp, elm, field)
يدرج العنصر elm في رأس الطابور headp. الوسيط field هو اسم حقل إدخال القائمة داخل الهيكل الذي يشير إليه elm.
STAILQ_INSERT_TAIL( headp, elm, field)
يدرج العنصر elm في ذيل الطابور headp. الوسيط field هو اسم حقل إدخال القائمة داخل الهيكل الذي يشير إليه elm.
STAILQ_INSERT_AFTER( headp, listelm, elm, field)
يدرج العنصر elm بعد العنصر listelm في الطابور headp. الوسيط field هو اسم حقل إدخال القائمة داخل الهيكل الذي يشير إليه elm.
STAILQ_INSERT_BEFORE( headp, listelm, elm, field)
يدرج العنصر elm قبل العنصر listelm في الطابور headp. الوسيط field هو اسم حقل إدخال القائمة داخل الهيكل الذي يشير إليه elm.
STAILQ_REMOVE_HEAD( headp, field)
يزيل العنصر الأول من الطابور headp ويعيده. يعيد NULL إذا كان الطابور فارغًا. الوسيط field هو اسم حقل إدخال القائمة داخل الهيكل الذي يشير إليه العنصر المُزال.
STAILQ_REMOVE( headp, elm, field)
يزيل العنصر elm من الطابور headp. الوسيط field هو اسم حقل إدخال القائمة داخل الهيكل الذي يشير إليه elm.
STAILQ_SWAP( headp1, headp2, type)
يتبادل محتويات الطابورين headp1 و headp2. الوسيط type هو الاسم الذي سيتم استخدامه للإشارة إلى رأس القائمة.

قيمة الإرجاع

الوظائف التي تسترجع العناصر من الطابور تعيد مؤشرًا إلى العنصر، أو NULL إذا كان الطابور فارغًا. الوظائف التي تعدل الطابور لا تعيد قيمة.

الإصدارات

الماكرو STAILQ* متوفرة في libutil.

الأخطاء

يتم تنفيذ هذه الماكرو باستخدام الماكرو، وبالتالي لا تظهر في جدول الرموز. هذا يمكن أن يجعل التصحيح أكثر صعوبة.

المعايير

هذه الماكرو مشابهة لتلك الموجودة في أنظمة BSD.

التاريخ

أمثلة

يوضح المثال التالي كيفية استخدام ماكرو STAILQ* لتنفيذ طابور بسيط من الأعداد الصحيحة.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct	item {
	int	data;
	STAILQ_ENTRY(item) entries;
};

STAILQ_HEAD(itemhead, item);

int
main(void)
{
	struct itemhead head;
	struct item *np, *n1, *n2;

	STAILQ_INIT(&head);

	/* Allocate and insert items */
	np = malloc(sizeof(struct item));
	np->data = 1;
	STAILQ_INSERT_TAIL(&head, np, entries);

	np = malloc(sizeof(struct item));
	np->data = 2;
	STAILQ_INSERT_TAIL(&head, np, entries);

	np = malloc(sizeof(struct item));
	np->data = 3;
	STAILQ_INSERT_TAIL(&head, np, entries);

                                     /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                            /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
