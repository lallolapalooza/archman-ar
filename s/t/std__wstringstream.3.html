basic_ios - واجهة للفئات الأساسية لتشغيل الإدخال / الإخراج

الملخص

template< class _CharT, class _Traits >
class basic_ios

الوصف

تُعد الفئة basic_ios فئة أساسية مجردة (abstract base class) للفئات basic_istream و basic_ostream. توفر الأعضاء المشتركين لهذه الفئات، بما في ذلك الحالة، الإعدادات، والعمليات.

لا يمكن إنشاء كائنات من basic_ios مباشرة. يجب استخدامها كفئة أساسية للفئات المشتقة.

Detailed Description

template<typename _CharT, typename _Traits, typename _Alloc>

class std::basic_stringstream< _CharT, _Traits, _Alloc >

Controlling input and output for std::string.

Template Parameters

_CharT Type of character stream.
_Traits Traits for character type, defaults to char_traits<_CharT>.
_Alloc Allocator type, defaults to allocator<_CharT>.

This class supports reading from and writing to objects of type std::basic_string, using the inherited functions from std::basic_iostream. To control the associated sequence, an instance of std::basic_stringbuf is used, which this page refers to as sb.

يُرجع

حرف، أو eof().

يحاول استخراج حرف. إذا لم تكن هناك أحرف متاحة، يضبط failbit ويعيد traits::eof().

مراجع إلى _M_gcount، و std::ios_base::goodbit، و std::basic_ios< _CharT, _Traits >::rdbuf()، و std::basic_streambuf< _CharT, _Traits >::sgetc().

المعلمات

__n عدد الأحرف المراد تجاهلها.

يُرجع

*this

يستخرج الأحرف ويتخلص منها حتى يحدث أحد الأمور التالية:

  • إذا كان __n != std::numeric_limits<int>::max()، يتم استخراج __n حرف.
