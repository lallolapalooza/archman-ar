Detailed Description

template<typename _Key, typename _Compare = std::less<_Key>, typename _Alloc = std::allocator<_Key>>

class std::set< _Key, _Compare, _Alloc >"A standard container made up of unique keys, which can be retrieved in logarithmic time.

Since

C++98

Template Parameters

_Key Type of key objects.
_Compare Comparison function object type, defaults to less<_Key>.
_Alloc Allocator type, defaults to allocator<_Key>.

Meets the requirements of a container, a reversible container, and an associative container (using unique keys).

Sets support bidirectional iterators.

The private tree data is declared exactly the same way for set and multiset; the distinction is made entirely in how the tree functions are called (*_unique versus *_equal, same as the standard).

NAME

std::set - A container that stores elements in a sorted order.

SYNOPSIS

#include <set>

template<
    typename _Key,
    typename _Compare = std::less<_Key>,
    typename _Alloc = std::allocator<_Key>
>
class set {
public:
    // types
    typedef _Key key_type;
    typedef key_type value_type;
    typedef _Compare key_compare;
    typedef key_compare value_compare;
    typedef typename _Alloc::template rebind<value_type>::other allocator_type;

Detailed Description

A std::set is an associative container that contains a set of unique objects of type Key. The objects are always ordered by means of the comparison function Compare.

A set cannot contain duplicate elements. Duplicate elements are ignored. If the ordering determines two elements to be equivalent, they are not both stored.

The ordering means that it is possible to easily retrieve a particular element or a range of elements. Elements are stored in order, and this order is preserved even after insertions and deletions.

This makes it possible to efficiently retrieve elements by key.

This container is implemented as a balanced binary search tree.
