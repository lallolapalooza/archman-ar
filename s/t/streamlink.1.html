streamlink(1)

الحزمة: streamlink

التراخيص: BSD

STREAMLINK(1) Streamlink STREAMLINK(1)

الاسم

streamlink - يستخرج البث من خدمات مختلفة ويوجهها إلى مشغل فيديو من اختيارك

نبذة

streamlink [خيارات] <URL> [بث]

أمثلة

streamlink --loglevel debug youtu.be/VIDEO-ID best
streamlink --player mpv --player-args '--no-border --no-keepaspect-window' twitch.tv/CHANNEL 1080p60
streamlink --player-external-http --player-external-http-port 8888 URL STREAM
streamlink --output /path/to/file --http-timeout 60 URL STREAM
streamlink --stdout URL STREAM | ffmpeg -i pipe:0 ...
streamlink --http-header 'Authorization=OAuth TOKEN' --http-header 'Referer=URL' URL STREAM
streamlink --hls-live-edge 5 --stream-segment-threads 5 'hls://https://host/playlist.m3u8' best
streamlink --twitch-low-latency -p mpv -a '--cache=yes --demuxer-max-back-bytes=2G' twitch.tv/CHANNEL best

خيارات

وسائط موضعية

URL
عنوان URL لمحاولة استخراج البث منه.

عادةً، يمكن حذف بروتوكول عناوين URL http(s) (https://)، اعتمادًا على تنفيذ المكون الإضافي المستخدم.

بدلاً من ذلك، يمكن أيضًا تحديد عنوان URL باستخدام الخيار --url.

بث (STREAM)
البث المراد تشغيله.

استخدم best أو worst لاختيار أعلى أو أدنى جودة متاحة.

يمكن تحديد بث بديل باستخدام قائمة مفصولة بفواصل:

"720p,480p,best"

إذا لم يتم تحديد بث ولم يتم استخدام --default-stream، فسيتم طباعة قائمة بالبث المتاح.

خيارات عامة

-h
--help
عرض رسالة المساعدة هذه والخروج.
-V
--version
عرض سلسلة الإصدار والخروج.
--version-check
تشغيل فحص الإصدار والخروج.
--auto-version-check {yes,true,1,on,no,false,0,off}
تمكين أو تعطيل الفحص التلقائي لإصدار جديد من Streamlink.

الافتراضي هو: "no".

--config FILENAME
تحميل الخيارات من ملف الإعدادات هذا.

يمكن تكراره لتحميل ملفات متعددة، وفي هذه الحالة يتم دمج الخيارات فوق بعضها البعض حيث يحظى الإعداد الأخير بالأولوية القصوى.

--no-config
تعطيل تحميل أي ملفات إعدادات افتراضية أو مخصصة.
--locale LOCALE
تجاوز إعداد اللغة المحلي للنظام، لتحديد اللغة المفضلة للترجمة الصوتية والترجمة النصية.

يتم تنسيق الإعداد المحلي كـ [رمز اللغة]_[رمز البلد]، على سبيل المثال en_US أو es_ES.

الافتراضي هو: الإعداد المحلي للنظام.

وسائط التسجيل

-l LEVEL
--loglevel LEVEL
تعيين حد رسائل السجل.

المستويات الصالحة هي، بترتيب زيادة التفاصيل:

none، critical، error، warning، info، debug، trace، all

الافتراضي هو: "info".

--logformat FORMAT
تعيين تنسيق تسجيل مخصص.

انظر وثائق مكتبة Python القياسية logging.Formatter لمزيد من المعلومات حول تنسيق التسجيل وسمات LogRecord المتاحة. يستخدم منسق Streamlink أسلوب الأقواس المتعرجة.

التنسيق الافتراضي يعتمد على مستوى السجل المختار.

للمستويات التفصيلية (trace و all):

الافتراضي هو: "[{asctime}][{threadName}][{name}][{levelname}] {message}".

بخلاف ذلك:

الافتراضي هو: "[{name}][{levelname}] {message}".

--logdateformat DATEFORMAT
تعيين تنسيق تاريخ تسجيل مخصص.

يقوم هذا بتنسيق السمة asctime الخاصة بـ LogRecord عبر strftime().

يعتمد تنسيق التاريخ الافتراضي على مستوى السجل المختار.

للمستويات التفصيلية (trace و all):

الافتراضي هو: "%H:%M:%S.%f".

بخلاف ذلك:

الافتراضي هو: "%H:%M:%S".

--logfile FILE
إلحاق إخراج السجل بـ FILE بدلاً من الكتابة إلى stdout/stderr.

لن تتم كتابة مطالبات المستخدم وتقدم التنزيل إلى FILE.

قيمة - (شرطة) ستعيّن اسم الملف إلى سلسلة تشبه ISO8601 وستختار أدلة السجل الافتراضية التالية.

Windows:

%TEMP%\streamlink\logs

macOS:

${HOME}/Library/Logs/streamlink

Linux/BSD:

${XDG_STATE_HOME:-${HOME}/.local/state}/streamlink/logs
-Q
--quiet
كبت كل مخرجات الوحدة الطرفية والسجلات، وتعطيل مطالبات المستخدم أيضًا.
-j
--json
إخراج تمثيلات JSON بدلاً من المخرجات النصية العادية.

مفيد للبرمجة النصية الخارجية.

خيارات المكونات الإضافية

--plugins
طباعة قائمة بجميع المكونات الإضافية المثبتة حاليًا.
--show-matchers PLUGIN
عرض قائمة بالمطابقات لمكون إضافي معين (نمط تعبير عادي لعنوان URL مع أولوية اختيارية واسم اختياري).

الإخراج هو تنسيق YAML شبه قابل للقراءة. يرجى استخدام --json عند قراءة بيانات المطابقة برمجياً.

--can-handle-url URL
التحقق مما إذا كان Streamlink لديه مكون إضافي يمكنه التعامل مع عنوان URL المحدد.

رمز الحالة هو 0 عند النجاح، 1 عند الفشل.

مفيد للبرمجة النصية الخارجية.

--can-handle-url-no-redirect URL
نفس --can-handle-url، ولكن بدون متابعة عمليات إعادة التوجيه عند "16M".

--stream-segment-attempts ATTEMPTS
عدد محاولات تنزيل كل جزء من أجزاء البث قبل الاستسلام.

ينطبق هذا على جميع أنواع الأجزاء المختلفة للبث، مثل DASH و HLS، وما إلى ذلك.

القيمة الافتراضية هي: 3.

--stream-segment-threads THREADS
حجم مجموعة الخيوط المستخدمة لتنزيل الأجزاء. الحد الأدنى للقيمة هو 1 والحد الأقصى هو 10.

ينطبق هذا على جميع أنواع الأجزاء المختلفة للبث، مثل DASH و HLS، وما إلى ذلك.

القيمة الافتراضية هي: 1.

--stream-segment-timeout TIMEOUT
الحد الأقصى للوقت للانتظار لبدء تنزيل كل جزء.

ينطبق هذا على جميع أنواع الأجزاء المختلفة للبث، مثل DASH و HLS، وما إلى ذلك.

القيمة الافتراضية هي: 10.0.

--stream-segmented-duration [[XX:]XX:]XX[.XX] | [XXh][XXm][XX[.XX]s]
تحديد مدة إخراج البث المجزأ، مثل HLS و DASH. قد تكون المدة الفعلية أطول قليلاً، حيث يتم تقريبها إلى أقرب جزء.

اضبط على 0 لتعطيل.

القيمة الافتراضية هي: 0.

--stream-timeout TIMEOUT
الحد الأقصى للوقت للانتظار حتى يستمر بث غير مصفى في إخراج البيانات.

ينطبق هذا على جميع أنواع البث المختلفة، مثل DASH و HLS و HTTP، وما إلى ذلك.

القيمة الافتراضية هي: 60.0.

--mux-subtitles
دمج الترجمات المتاحة تلقائيًا في تيار الإخراج.

يحتاج إلى أن يدعمه المكون الإضافي المستخدم.

خيارات HLS

--hls-live-edge SEGMENTS
عدد الأجزاء من الموضع الحالي للبث المباشر لبدء البث. يتم تحديد حجم أو طول كل جزء بواسطة مزود البث.

القيم المنخفضة ستقلل من الكمون، ولكنها ستزيد أيضًا من فرصة التخزين المؤقت، حيث يكون هناك وقت أقل لـ Streamlink لتنزيل الأجزاء وكتابة بياناتها إلى المخزن المؤقت للإخراج. يمكن تعيين عدد تنزيلات الأجزاء المتوازية باستخدام --stream-segment-threads ويمكن تجاوز وقت إعادة تحميل قائمة HLS لجلب وتخزين الأجزاء الجديدة مؤقتًا باستخدام --hls-playlist-reload-time.

القيمة الافتراضية هي: 3.

ملاحظة:

أثناء التشغيل المباشر، ستضيف إعدادات التخزين المؤقت/التخزين المؤقت للمشغل المستخدم زمن انتقال إضافي. لضبط هذا، يرجى الرجوع إلى وثائق المشغل الخاصة به للحصول على التكوين المطلوب. يمكن تعيين معلمات المشغل عبر --player-args.
--hls-segment-stream-data
كتابة بيانات الجزء فورًا إلى مخزن الإخراج المؤقت أثناء التنزيل.
--hls-playlist-reload-attempts ATTEMPTS
الحد الأقصى لعدد المحاولات عند إعادة تحميل قائمة HLS قبل الاستسلام.

القيمة الافتراضية هي: 3.

--hls-playlist-reload-time TIME
تعيين قيمة مخصصة لوقت إعادة تحميل قائمة HLS، إما بالثواني أو باستخدام إحدى الكلمات الرئيسية التالية:
  • segment: مدة الجزء الأخير في القائمة الحالية
  • live-edge: مجموع مدة أجزاء قيمة الحافة الحية مطروحًا منها واحد
  • default: بيانات مدة الهدف للقائمة

القيمة الافتراضية هي: default.

--hls-segment-queue-threshold FACTOR
عامل الضرب لمدة الهدف لقائمة HLS التي بعدها سيتوقف البث مبكرًا إذا لم يتم وضع أجزاء جديدة في قائمة الانتظار بعد تحديث القائمة (عدة مرات). تحدد مدة الهدف الحد الأقصى للمدة التي يمكن أن يستغرقها جزء واحد، مما يعني أنه يجب أن تكون هناك أجزاء جديدة متاحة خلال هذا الإطار الزمني، وإلا يمكن أن تحدث مشاكل في التشغيل.

الهدف من عتبة قائمة الانتظار هذه هو أن تكون قادرًا على التوقف مبكرًا عندما لا يتم الإعلان عن نهاية البث بواسطة الخادم، لذلك لا يحتاج Streamlink إلى الانتظار حتى يحدث مهلة للقراءة. انظر --stream-timeout.

اضبط على 0 لتعطيل.

القيمة الافتراضية هي: 3.

--hls-segment-ignore-names NAMES
قائمة مفصولة بفواصل لأسماء الأجزاء التي سيتم تصفيتها.

مثال: --hls-segment-ignore-names 000,001,002

سيؤدي هذا إلى تجاهل كل جزء ينتهي بـ 000.ts أو 001.ts و 002.ts

القيمة الافتراضية هي: None.

--hls-segment-key-uri URI
تجاوز عناوين URL لمفتاح تشفير الجزء للأجزاء المشفرة.

يمكن معالجة القيمة باستخدام المتغيرات التالية، والتي سيتم استبدالها بالجزء المقابل لها من عنوان URL للجزء المصدر:

{url} {scheme} {netloc} {path} {query}

أمثلة:

--hls-segment-key-uri "https://example.com/hls/encryption_key"
--hls-segment-key-uri "{scheme}://1.2.3.4{path}{query}"
--hls-segment-key-uri "{scheme}://{netloc}/custom/path/to/key"

القيمة الافتراضية هي: None.

--hls-audio-select CODE
حدد مصادر صوت محددة واحدة أو أكثر حسب رمز اللغة أو الاسم. يمكن تعيينها إلى * (نجمة) لتضمين جميع مصادر الصوت.

أمثلة:

--hls-audio-select "English,German"
--hls-audio-select "en,de"
--hls-audio-select "*"

ملاحظة:

هذا مفيد فقط في ظروف خاصة حيث يفشل خيار اللغة العادي، مثل عندما توجد مصادر متعددة من نفس اللغة.
--hls-start-offset [[XX:]XX:]XX[.XX] | [XXh][XXm][XX[.XX]s]
مقدار الوقت الذي يجب تخطيه من بداية البث. بالنسبة للبث المباشر، يكون هذا إزاحة سلبية من نهاية البث (تراجع).

القيمة الافتراضية هي: 0.

--hls-duration [[XX:]XX:]XX[.XX] | [XXh][XXm][XX[.XX]s]
تم إيقافه لصالح --stream-segmented-duration.
--hls-live-restart
الانتقال إلى بداية بث مباشر، أو إلى أبعد نقطة ممكنة.

خيارات FFmpeg

--ffmpeg-ffmpeg FILENAME
تعيين موقع ملف FFmpeg التنفيذي إذا لم يكن من الممكن حله من مسارات متغير بيئة PATH للنظام.

FFmpeg مطلوب للوصول إلى أو دمج تدفقات الفيديو والصوت المنفصلة، على سبيل المثال في تدفقات DASH أو تدفقات HLS بمصادر متعددة.

مثال: --ffmpeg-ffmpeg "/usr/local/bin/ffmpeg"

--ffmpeg-no-validation
تعطيل التحقق من صحة FFmpeg وتسجيل الإصدار.
--ffmpeg-verbose
كتابة إخراج stderr الخاص بـ FFmpeg إلى إخراج stderr الخاص بـ Streamlink.
--ffmpeg-verbose-path PATH
كتابة إخراج stderr الخاص بـ FFmpeg إلى PATH.
--ffmpeg-loglevel LOGLEVEL
تغيير قيمة -loglevel الخاصة بـ FFmpeg إلى LOGLEVEL.

ما لم يتم تعيين --ffmpeg-verbose أو --ffmpeg-verbose-path، فإن تغيير مستوى السجل لن يكون له أي تأثير.

القيمة الافتراضية هي: "info".

--ffmpeg-fout OUTFORMAT
تعيين تنسيق الإخراج إلى OUTFORMAT. ينطبق هذا فقط على التدفقات التي تتطلب الدمج.

القيمة الافتراضية هي: "matroska".

مثال: --ffmpeg-fout "mpegts"

--ffmpeg-video-transcode CODEC
إعادة ترميز الفيديو إلى CODEC. ينطبق هذا فقط على التدفقات التي تتطلب الدمج.

القيمة الافتراضية هي: "copy".

Twitch

--twitch-low-latency
يمكّن البث بزمن انتقال منخفض عن طريق التحميل المسبق لشرائح HLS. يضبط --hls-segment-stream-data على true و --hls-live-edge على 2، إذا كان أعلى. سيؤدي تقليل --hls-live-edge إلى 1 إلى أدنى زمن انتقال ممكن، ولكنه سيؤدي على الأرجح إلى تخزين مؤقت.

لتحقيق بث بزمن انتقال منخفض حقيقي أثناء التشغيل، ستحتاج إلى تعديل إعدادات التخزين المؤقت/التخزين المؤقت للمشغل وتقليلها إلى أدنى قيمة ممكنة، ولكن لا تزال مرتفعة بما يكفي لعدم التسبب في أي تخزين مؤقت. يعتمد هذا على معدل بت البث وجودة الاتصال بخوادم Twitch. يرجى الرجوع إلى وثائق المشغل الخاصة لإعداد التكوين المطلوب. يمكن تعيين معلمات المشغل عبر --player-args.

ملاحظة:

يجب تمكين بثوث زمن الانتقال المنخفض من قبل المذيعين على Twitch بأنفسهم. قد تتسبب البثوث العادية في حدوث مشاكل في التخزين المؤقت مع هذا الخيار ممكّن بسبب انخفاض قيمة --hls-live-edge.
--twitch-supported-codecs CODECS
قائمة مفصولة بفواصل بأسماء الترميزات التي تشير إلى تفضيل ترميز بث العميل لـ Twitch. تعتمد البثوث والترميزات المتاحة على القناة والبث المحددين.

الافتراضي هو: "h264".

الترميزات المدعومة هي h264 و h265 و av1. اضبطها على "h264,h265,av1" لتمكين جميع الترميزات.

قد تكون البثوث ذات الجودة الأعلى متاحة فقط عن طريق تمكين h265 أو av1. قد لا تزال البثوث ذات الجودة الأقل التي يعاد ترميزها من جانب Twitch تكون h264، حتى لو لم يتم طلبها.

--twitch-api-header KEY=VALUE
رأس لإضافته إلى كل طلب HTTP لواجهة برمجة تطبيقات Twitch.

يمكن تكراره لإضافة رؤوس متعددة.

مفيد لإضافة بيانات مصادقة يمكن أن تمنع الإعلانات. راجع الوثائق الخاصة بالمكون الإضافي لمزيد من المعلومات.

--twitch-access-token-param KEY=VALUE
معلمة لإضافتها إلى طلب واجهة برمجة التطبيقات للحصول على رمز الوصول إلى البث.

يمكن تكراره لإضافة معلمات متعددة.

لا تحاول طلب رمز الوصول إلى البث بدون رمز تكامل العميل.
--twitch-purge-client-integrity
مسح رمز تكامل العميل المخزن مؤقتًا لـ Twitch والحصول على رمز جديد.

Ustreamtv

--ustream-password PASSWORD
كلمة مرور للوصول إلى قنوات UStream.tv المحمية بكلمة مرور.

Ustvnow

--ustvnow-username USERNAME
اسم مستخدم حساب USTV Now الخاص بك.
--ustvnow-password PASSWORD
كلمة مرور حساب USTV Now الخاص بك.

Wwenetwork

--wwenetwork-email EMAIL
البريد الإلكتروني المرتبط بحساب WWE Network الخاص بك، مطلوب للوصول إلى أي بث WWE Network.
--wwenetwork-password PASSWORD
كلمة مرور حساب WWE Network لاستخدامها مع --wwenetwork-email.

Yupptv

--yupptv-boxid BOXID
معرف صندوق yupptv.com المستخدم في ملف تعريف الارتباط BoxId.
--yupptv-yuppflixtoken YUPPFLIXTOKEN
رمز yuppflixtoken الخاص بـ yupptv.com المستخدم في ملف تعريف الارتباط YuppflixToken.
--yupptv-purge-credentials
مسح بيانات اعتماد YuppTV المخزنة مؤقتًا لبدء جلسة جديدة وإعادة المصادقة.

Zattoo

--zattoo-email EMAIL
البريد الإلكتروني المرتبط بحساب zattoo الخاص بك، مطلوب للوصول إلى أي بث zattoo.
--zattoo-password PASSWORD
كلمة مرور حساب Zattoo لاستخدامها مع --zattoo-email.
--zattoo-purge-credentials
مسح بيانات اعتماد Zattoo المخزنة مؤقتًا لبدء جلسة جديدة وإعادة المصادقة.
--zattoo-stream-types TYPES
قائمة مفصولة بفواصل لأنواع التدفق التي يجب استخدامها.
