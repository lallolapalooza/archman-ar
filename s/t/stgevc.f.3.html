NAME

stgevc - compute the eigenvectors of a generalized eigenvalue problem A*v = lambda*B*v, where A and B are upper triangular matrices.

SYNOPSIS

 Call STGEVC(
  SIDE, JOBZ, N, A, LDA, B, LDB, VL, LDVL, VR, LDVR, LCM, WORK, INFO)

Function/Subroutine Documentation

This subroutine computes the eigenvectors of a generalized eigenvalue problem of the form

  A*v = lambda*B*v

where A and B are upper triangular matrices. The eigenvectors are computed for the generalized eigenvalue problem

  A*x = lambda*B*x

Left eigenvectors are also computed by taking the transpose of the matrix.

  y**H*A = lambda*y**H*B

where y**H is the conjugate transpose of y.

!>
!>  Compute the eigenvalues and eigenvectors of the generalized eigenvalue
!>  problem A*v = lambda*B*v where A and B are upper triangular matrices.
!>
!>  If the problem is solved by balancing, the matrices A and B are
!>  multiplied by diagonal matrices D1 and D2 such that A*D1 = A and
!>  B*D2 = B, and the generalized eigenvalues and eigenvectors are computed
!>  for A*D1*inv(D2)*B.
!>
!>  The generalized eigenvalues are computed in descending order of the
!>  absolute values of the eigenvalues.
!>
!>  Right eigenvectors are computed by the equation:
!>
!>  (A - w*B)*v = 0
!>
!>  Left eigenvectors are computed by the equation:
!>
!>  v**H * (A - w*B) = 0
!>
!>  where w is an eigenvalue.
!>
!>  The eigenvectors are normalized so that the largest component is 1.
!>  If an eigenvector is zero, then the largest component is taken to be 0.
!>
!>  The method used is a block version of the inverse iteration method.
!>  The algorithm is based on the observation that the equation
!>  (A - w*B)*v = 0 can be written as
!>
!>  A*v = w*B*v
!>
!>  which can be solved for w as:
!>
!>  w = (A*v) / (B*v)
!>
!>  The algorithm proceeds by computing the eigenvalues and eigenvectors
!>  one by one, starting from the eigenvalue with the largest absolute value.
!>  The eigenvectors are computed using inverse iteration with shifts.
!>
!>  The algorithm for computing a right eigenvector v for eigenvalue w is
!>  as follows:
!>
!>  Start with an initial guess v(1:n).
!>  Iterate:
!>    Solve (A - w*B)*y = v for y.
!>    v = y / ||y||
!>  until convergence.
!>
!>  The solution of (A - w*B)*y = v is obtained by back substitution.
!>  Let C = (A - w*B). Then the equation is C*y = v.
!>
!>  The components of the eigenvector v are computed from the last component
!>  upwards.  Let the eigenvector be v = [v(1), v(2), ..., v(n)]**T.
!>  We have the equations:
!>
!>  C(1,1)*v(1) + C(1,2)*v(2) + ... + C(1,n)*v(n) = 0
!>  C(2,2)*v(2) + ... + C(2,n)*v(n) = 0
!>  ...
!>  C(n-1,n-1)*v(n-1) + C(n-1,n)*v(n) = 0
!>  C(n,n)*v(n) = 0
!>
!>  From the last equation, if C(n,n) is non-zero, then v(n) = 0.
!>  If C(n,n) is zero, then v(n) can be any value. We can set v(n) = 1.
!>
!>  Consider finding the i-th right eigenvector (assume all eigenvalues
!>  are real). The equation to be solved is:
!>       n                   i
!>  0 = sum  C(j,k) v(k)  = sum  C(j,k) v(k)     for j = i,. . .,1
!>      k=j                 k=j
!>
!>  where  C = (A - w B)  (The components v(i+1:n) are 0.)
!>
!>  The  method is:
!>
!>  (1)  v(i) := 1
!>  for j = i-1,. . .,1:
!>                          i
!>      (2) compute  s = - sum C(j,k) v(k)   and
!>                        k=j+1
!>
!>      (3) v(j) := s / C(j,j)
!>
!>  Step 2 is sometimes called the  step, since it is an
!>  inner product between the j-th row and the portion of the eigenvector
!>  that has been computed so far.
!>
!>  The  method consists basically in doing the sums
!>  for all the rows in parallel.  As each v(j) is computed, the
!>  contribution of v(j) times the j-th column of C is added to the
!>  partial sums.  Since FORTRAN arrays are stored columnwise, this has
!>  the advantage that at each step, the elements of C that are accessed
!>  are adjacent to one another, whereas with the rowwise method, the
!>  elements accessed at a step are spaced LDS (and LDP) words apart.
!>
!>  When finding left eigenvectors, the matrix in question is the
!>  transpose of the one in storage, so the rowwise method then
!>  actually accesses columns of A and B at each step, and so is the
!>  preferred method.
!>
