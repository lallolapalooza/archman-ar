DESCRIPTION

The class template `std::basic_ios` is the base class for all input/output stream classes. It stores various information about the state of the stream, such as error state flags, formatting flags, and a pointer to an associated stream buffer (`rdbuf()`).

It also stores a pointer to another stream (`tie()`) which is flushed before certain I/O operations. This is commonly used to tie `std::cin` to `std::cout` so that prompts are displayed before input is read.

This class template is not intended to be used directly by applications. Instead, applications typically use derived classes such as `std::basic_istream`, `std::basic_ostream`, `std::basic_iostream`, `std::fstream`, `std::ifstream`, `std::ofstream`, `std::stringstream`, `std::istringstream`, and `std::ostringstream`.

See https://gcc.gnu.org/onlinedocs/libstdc++/manual/streams.html#streams.stream.classes for more information.
