Detailed Description

template<typename _CharT, typename _InIter> class std::_V2_::num_get< _CharT, _InIter >

Class to support reading numbers from input streams.

This class is a standard facet, and is required by default by `std::basic_ios::get()` and `std::basic_ios::getline()` methods. It is used for parsing numbers from input streams according to the conventions of the specified locale.

The `do_get()` methods are the actual parsing hooks. They are called by the `get()` methods. Derived classes may override `do_get()` to change the numeric parsing behavior.

The template parameters are:

`_CharT`
The character type used by the stream.
`_InIter`
The type of the input iterator used to read characters from the stream.

إذا لم يتم تعيين ios_base::boolalpha، فإنه يستمر كما هو الحال مع قراءة long، باستثناء أنه إذا كانت القيمة 1، فإنه يضبط v إلى true، وإذا كانت القيمة 0، فإنه يضبط v إلى false، وإلا فإنه يضبط err إلى ios_base::failbit.
