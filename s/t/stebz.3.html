NAME

stebz - computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

SUBROUTINE STEBZ(
     CHARACTER*1      JOB,
     CHARACTER*1      RANGE,
     INTEGER          N,
     REAL             VL,
     REAL             VU,
     INTEGER          IL,
     INTEGER          IU,
     REAL             ABSTOL,
     REAL             D,
     REAL             E,
     REAL             Z,
     INTEGER          LDZ,
     REAL             RTOL,
     INTEGER          SSIZE,
     INTEGER          CSHIFT,
     INTEGER          LWORK,
     REAL             WORK,
     INTEGER          IWORK,
     INTEGER          INFO )

Detailed Description

This subroutine computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

Parameters

JOB
'E': compute all eigenvalues and eigenvectors. 'V': compute all eigenvalues and eigenvectors by value. 'I': compute all eigenvalues and eigenvectors by index. 'N': compute all eigenvalues and eigenvectors by name.
RANGE
'A': all eigenvalues will be found. 'V': all eigenvalues in the interval (VL, VU) will be found. 'I': all eigenvalues in the range [IL, IU] will be found.
N
The order of the matrix. N >= 0.
VL, VU
If RANGE = 'V', the lower and upper bounds of the interval to be searched for eigenvalues.
IL, IU
If RANGE = 'I', the indices of the eigenvalues to be returned.
ABSTOL
The absolute tolerance to be used when the interval (VL, VU) is specified by RANGE = 'V'. This is only used for eigenvalues close to zero.
D
On entry, the diagonal elements of the tridiagonal matrix. On exit, the eigenvalues, sorted in ascending order.
E
On entry, the subdiagonal elements of the tridiagonal matrix. On exit, E is overwritten.
Z
On exit, the eigenvectors. Z(:, I) is the eigenvector corresponding to the I-th eigenvalue.
LDZ
The leading dimension of the array Z. LDZ >= max(1, N).
RTOL
Relative tolerance to be used when the interval (VL, VU) is specified by RANGE = 'V'.
SSIZE
The number of eigenvalues found.
CSHIFT
The number of shifts used in the algorithm.
LWORK
The dimension of the array WORK.
WORK
Workspace array. WORK(LWORK) must be at least max(1, 4*N).
IWORK
Integer workspace array. IWORK(N) must be at least max(1, 3*N).
INFO
INFO = 0: successful exit. INFO < 0: if INFO = -i, then the i-th argument had an illegal value. INFO > 0: some or all of the calls to SLARRV or SLARRC failed.

Function Documentation

This subroutine computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.
