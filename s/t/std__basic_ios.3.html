الاسم

std::basic_ios< _CharT, _Traits > - الفئة الأساسية للقالب basic_ios، فئة أساسية افتراضية لجميع فئات التدفق.

الملخص

#include <ios>

ترث من std::ios_base.

ورثت بواسطة std::basic_istream< char > [افتراضي]، std::basic_istream< wchar_t > [افتراضي]، std::basic_ostream< char > [افتراضي]، std::basic_ostream< wchar_t > [افتراضي]، std::basic_istream< _CharT, _Traits > [افتراضي]، و std::basic_ostream< _CharT, _Traits > [افتراضي].

template<typename _CharT, typename _Traits>

class std::basic_ios< _CharT, _Traits >"Template class basic_ios, virtual base class for all stream classes.

Template Parameters

_CharT Type of character stream.
_Traits Traits for character type, defaults to char_traits<_CharT>.

Most of the member functions called dispatched on stream objects (e.g., std::cout.foo(bar);) are consolidated in this class.

الوصول إلى مصفوفة الأعداد الصحيحة.

المعلمات

__ix الفهرس في المصفوفة.

الإرجاع

مرجع إلى عدد صحيح مرتبط بالفهرس.

توفر وظيفة iword الوصول إلى مصفوفة من الأعداد الصحيحة يمكن استخدامها لأي غرض. تنمو المصفوفة حسب الحاجة لاستيعاب الفهرس المقدم. يتم تهيئة جميع الأعداد الصحيحة في المصفوفة إلى 0.
