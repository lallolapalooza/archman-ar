stty(1)

الحزمة: coreutils

التراخيص: GPL-3.0-or-later, GFDL-1.3-or-later

STTY(1) أوامر المستخدم STTY(1)

الاسم

stty - تغيير وعرض إعدادات سطر الطرفية

الملخص

stty [DEVICE -F | --file=DEVICE] [SETTING]...
stty [DEVICE -F | --file=DEVICE] [-a|--all]
stty [DEVICE -F | --file=DEVICE] [-g|--save]

الوصف

عرض أو تغيير خصائص الطرفية.

الوسائط الإلزامية للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا.

-a, --all
عرض جميع الإعدادات الحالية بشكل قابل للقراءة
-g, --save
عرض جميع الإعدادات الحالية بشكل قابل للقراءة بواسطة stty
-F, --file=DEVICE
فتح واستخدام DEVICE بدلاً من الإدخال القياسي
--help
عرض هذا المساعدة والخروج
--version
إخراج معلومات الإصدار والخروج

الشرطة (-) الاختيارية قبل SETTING تشير إلى النفي. علامة * تشير إلى إعدادات غير قياسية (non-POSIX). يحدد النظام الأساسي الإعدادات المتاحة.

الأحرف الخاصة:

* discard CHAR
س يقوم CHAR بتبديل إلغاء الإخراج
eof CHAR
س يرسل CHAR نهاية ملف (إنهاء الإدخال)
eol CHAR
س ينهي CHAR السطر
* eol2 CHAR
CHAR بديل لإنهاء السطر
erase CHAR
س يمحو CHAR آخر حرف تم كتابته
intr CHAR
س يرسل CHAR إشارة مقاطعة
kill CHAR
س يمحو CHAR السطر الحالي
* lnext CHAR
س يدخل CHAR الحرف التالي المقتبس
quit CHAR
س يرسل CHAR إشارة خروج
* rprnt CHAR
س يعيد CHAR رسم السطر الحالي
start CHAR
س يعيد CHAR تشغيل الإخراج بعد إيقافه
stop CHAR
س يوقف CHAR الإخراج
susp CHAR
س يرسل CHAR إشارة إيقاف الطرفية
* swtch CHAR
س يبدل CHAR إلى طبقة shell مختلفة
* werase CHAR
س يمحو CHAR الكلمة الأخيرة المكتوبة

الإعدادات الخاصة:

N
ضبط سرعة الإدخال والإخراج على N بود
cols N
إخبار النواة بأن الطرفية بها N عمود
* columns N
نفس cols N
* [-]drain
الانتظار حتى اكتمال الإرسال قبل تطبيق الإعدادات (ممكّن افتراضيًا)
ispeed N
ضبط سرعة الإدخال على N
* line N
استخدام خط الانضباط N
min N
مع -icanon، ضبط N حرف كحد أدنى للقراءة المكتملة
ospeed N
ضبط سرعة الإخراج على N
rows N
إخبار النواة بأن الطرفية بها N صف
size
عرض عدد الصفوف والأعمدة حسب النواة
speed
عرض سرعة الطرفية
time N
مع -icanon، ضبط مهلة القراءة بـ N أعشار من الثانية

إعدادات التحكم:

[-]clocal
تعطيل إشارات التحكم في المودم
[-]cread
السماح باستقبال الإدخال
* [-]crtscts
تمكين المصافحة RTS/CTS
csN
ضبط حجم الحرف على N بت، N في [5..8]
[-]cstopb
استخدام بتي توقف لكل حرف (واحد مع '-')
[-]hup
إرسال إشارة انقطاع الاتصال عند إغلاق آخر عملية للطرفية
[-]hupcl
نفس [-]hup
[-]parenb
إنشاء بت تماثل في الإخراج وتوقع بت تماثل في الإدخال
[-]parodd
ضبط تماثل فردي (أو تماثل زوجي مع '-')
* [-]cmspar
استخدام تماثل "ملصق" (علامة/فراغ)

إعدادات الإدخال:

[-]brkint
فواصل تسبب إشارة مقاطعة
[-]icrnl
ترجمة حرف العودة إلى سطر جديد
[-]ignbrk
تجاهل أحرف الفاصل
[-]igncr
تجاهل حرف العودة
[-]ignpar
تجاهل الأحرف ذات أخطاء التماثل
* [-]imaxbel
إصدار صوت وعدم مسح المخزن المؤقت للإدخال الممتلئ عند حرف
[-]inlcr
ترجمة سطر جديد إلى حرف العودة
[-]inpck
تمكين التحقق من تماثل الإدخال
[-]istrip
مسح البت العالي (الثامن) لأحرف الإدخال
* [-]iutf8
افتراض أن أحرف الإدخال مشفرة بـ UTF-8
* [-]iuclc
ترجمة الأحرف الكبيرة إلى أحرف صغيرة
* [-]ixany
السماح لأي حرف بإعادة تشغيل الإخراج، وليس فقط حرف البدء
[-]ixoff
تمكين إرسال أحرف البدء/الإيقاف
[-]ixon
تمكين التحكم في تدفق XON/XOFF
[-]parmrk
تمييز أخطاء التماثل (بتسلسل 255-0-حرف)
[-]tandem
نفس [-]ixoff

إعدادات الإخراج:

* bsN
أسلوب تأخير المسافة للخلف، N في [0..1]
* crN
أسلوب تأخير حرف العودة، N في [0..3]
* ffN
أسلوب تأخير تغذية النموذج، N في [0..1]
* nlN
أسلوب تأخير سطر جديد، N في [0..1]
* [-]ocrnl
ترجمة حرف العودة إلى سطر جديد
* [-]ofdel
استخدام أحرف الحذف للحشو بدلاً من أحرف NUL
* [-]ofill
استخدام أحرف الحشو (المبطنة) بدلاً من التوقيت للتأخيرات
* [-]olcuc
ترجمة الأحرف الصغيرة إلى أحرف كبيرة
* [-]onlcr
ترجمة سطر جديد إلى حرف عودة-سطر جديد
* [-]onlret
يقوم سطر جديد بوظيفة حرف العودة
* [-]onocr
لا تطبع أحرف العودة في العمود الأول
[-]opost
معالجة الإخراج لاحقًا
* tabN
أسلوب تأخير علامة الجدولة الأفقية، N في [0..3]
* tabs
نفس tab0
* -tabs
نفس tab3
* vtN
أسلوب تأخير علامة الجدولة العمودية، N في [0..1]
