STRPTIME(3P) دليل مبرمج POSIX STRPTIME(3P)

مقدمة

هذه الصفحة الدليل هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux) ، أو قد لا يتم تنفيذ الواجهة على Linux.

الاسم

strptime — تحويل التاريخ والوقت

الملخص

#include <time.h>
char *strptime(const char *restrict buf, const char *restrict format,
    struct tm *restrict tm);

الوصف

تقوم الدالة strptime() بتحويل سلسلة الأحرف التي يشير إليها buf إلى قيم يتم تخزينها في بنية tm التي يشير إليها tm ، باستخدام التنسيق المحدد بواسطة format.

يتكون التنسيق من صفر أو أكثر من التوجيهات. يتكون كل توجيه من أحد مما يلي: حرف مسافة بيضاء واحد أو أكثر (حسب ما هو محدد بواسطة isspace()) ؛ حرف عادي (ليس '%' ولا حرف مسافة بيضاء) ؛ أو مواصفات تحويل.

يتم تقديم كل مواصفات تحويل بواسطة الحرف '%' يليه ما يلي بالتتابع:

*
علامة اختيارية، الحرف الصفري ('0') أو حرف علامة الجمع ('+')، والتي يتم تجاهلها.
*
عرض حقل اختياري. إذا تم تحديد عرض حقل، فسيتم تفسيره كسلسلة من الأرقام العشرية التي ستحدد الحد الأقصى لعدد البايتات المحولة للتحويل بدلاً من عدد البايتات المحدد أدناه في وصف محددات التحويل.
*
معدل E أو O اختياري.
*
حرف محدد تحويل نهائي يشير إلى نوع التحويل المراد تطبيقه.

يتم تحديد التحويلات باستخدام فئة LC_TIME للموقع الحالي. يجب على التطبيق التأكد من وجود مسافة بيضاء أو أحرف أخرى غير أبجدية رقمية بين أي مواصفات تحويل ما لم تكن جميع مواصفات التحويل المتجاورة تقوم بتحويل عدد معروف وثابت من الأحرف. في القائمة التالية، الحد الأقصى لعدد الأحرف التي تم فحصها (باستثناء الحرف الذي يتطابق مع التوجيه التالي) هو كما يلي:

*
إذا تم تحديد عرض حقل أقصى، فإن هذا العدد
*
بخلاف ذلك، يشير النمط "{x}" إلى أن الحد الأقصى هو x
*
بخلاف ذلك، يشير النمط "[x,y]" إلى أن القيمة يجب أن تقع ضمن النطاق المحدد (كلا الحدين شاملين)، وأن الحد الأقصى لعدد الأحرف التي تم فحصها يجب أن يكون الحد الأقصى المطلوب لتمثيل أي قيمة في النطاق بدون أصفار بادئة وبدون علامة زائد بادئة.

محددات التحويل التالية مدعومة.

النتائج غير محددة إذا تم تحديد معدل مع علامة أو مع عرض حقل أدنى، أو إذا تم تحديد عرض حقل لأي محدد تحويل بخلاف C أو Y.

a
يوم الأسبوع، باستخدام أسماء أيام الأسبوع للموقع ؛ يمكن تحديد الاسم المختصر أو الكامل.
A
مكافئ لـ %a.
b
الشهر، باستخدام أسماء الأشهر للموقع ؛ يمكن تحديد الاسم المختصر أو الكامل.
B
مكافئ لـ %b.
c
يتم استبداله بالتمثيل المناسب للتاريخ والوقت للموقع.
C
جميع الأرقام باستثناء آخر رقمين من السنة {2} ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب. يُسمح بحرف '+' أو '-' قبل أي أصفار بادئة ولكن لا يُطلب.
d
يوم الشهر [01,31] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
D
التاريخ كـ %m/%d/%y.
e
مكافئ لـ %d.
h
مكافئ لـ %b.
H
الساعة (ساعة 24) [00,23] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
I
الساعة (ساعة 12) [01,12] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
j
رقم يوم السنة [001,366] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
m
رقم الشهر [01,12] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
M
الدقيقة [00,59] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
n
أي مسافة بيضاء.
p
المعادل في الموقع لـ a.m. أو p.m.
r
توقيت ساعة 12 باستخدام تدوين AM/PM إذا كانت t_fmt_ampm ليست سلسلة فارغة في جزء LC_TIME من الموقع الحالي؛ في الموقع POSIX، سيكون هذا مكافئًا لـ %I:%M:%S %p.
R
الوقت كـ %H:%M.
S
الثواني [00,60] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
t
أي مسافة بيضاء.
T
الوقت كـ %H:%M:%S.
U
رقم الأسبوع من السنة (الأحد هو أول يوم في الأسبوع) كرقم عشري [00,53] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
w
يوم الأسبوع كرقم عشري [0,6] ، حيث يمثل 0 الأحد.
W
رقم الأسبوع من السنة (الاثنين هو أول يوم في الأسبوع) كرقم عشري [00,53] ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب.
x
التاريخ، باستخدام تنسيق التاريخ للموقع.
X
الوقت، باستخدام تنسيق الوقت للموقع.
y
آخر رقمين من السنة. عندما يحتوي format على محدد التحويل C أو محدد التحويل Y، فإن القيم في النطاق [69,99] تشير إلى السنوات 1969 إلى 1999 شاملة والقيم في النطاق [00,68] تشير إلى السنوات 2000 إلى 2068 شاملة؛ يُسمح بالأصفار البادئة ولكن لا يُطلب. يُسمح بحرف '+' أو '-' قبل أي أصفار بادئة ولكن لا يُطلب.
ملاحظة:
من المتوقع أنه في إصدار مستقبلي من هذا المعيار، سيتغير القرن الافتراضي المستنتج من سنة من رقمين. (سيطبق هذا على جميع الأوامر التي تقبل سنة من رقمين كمدخل.)
Y
السنة الكاملة {4} ؛ يُسمح بالأصفار البادئة ولكن لا يُطلب. يُسمح بحرف '+' أو '-' قبل أي أصفار بادئة ولكن لا يُطلب.
%
يتم استبداله بـ %.

محددات التحويل المعدلة

يمكن تعديل بعض محددات التحويل بواسطة حرفي التعديل E و O للإشارة إلى أنه يجب استخدام تنسيق أو مواصفات بديلة بدلاً من تلك التي يستخدمها محدد التحويل غير المعدل عادةً. إذا كان التنسيق أو المواصفات البديلة غير موجود في الموقع الحالي، فسيكون السلوك كما لو تم استخدام محدد التحويل غير المعدل.

تمثيل التاريخ والوقت المناسب البديل للموقع.
%EC
اسم سنة الأساس (فترة) في التمثيل البديل للموقع.
%Ex
تمثيل التاريخ البديل للموقع.

strptime(3p) — Arch manual pages

PROLOG

This page describes the strptime() function as implemented in the POSIX standard.

NAME

strptime — convert a time expressed in std::string to broken-down time

SYNOPSIS

#include <time.h>
char *strptime(const char *restrict buf, const char *restrict format,
       struct tm *restrict tm);

DESCRIPTION

The strptime() function shall parse the time std::string referenced by buf according to the std::string specified by format, and store the parsed representation into the struct tm structure referenced by tm.

The format std::string is a std::string of zero or more directives, which are converted to matching sequences in the std::string to be scanned. The other characters are, except in the cases noted below, unmatched.

A directive is a whitespace character or a conversion specification.

A conversion specification is introduced by a '%' character; it is followed by a character that specifies the meaning of the conversion specification. The following conversion specifications are supported:

%a
The locale's abbreviated weekday name. For example, Sun, Mon, etc.
%A
The locale's full weekday name. For example, Sunday, Monday, etc.
%b
The locale's abbreviated month name. For example, Jan, Feb, etc.
%B
The locale's full weekday name. For example, January, February, etc.
%c
The locale's appropriate date and time representation.
%C
The century. For example, for 1999, the century is 19.
%d
The day of the month when using the C locale, as a decimal number [01,31]. However, if the locale's alternative numeric symbols are used, the range is implementation-defined.
%D
Equivalent to %m/%d/%y.
%e
The day of the month when using the C locale, as a decimal number [1,31]. A single digit is preceded by a space. However, if the locale's alternative numeric symbols are used, the range is implementation-defined.
%F
Equivalent to %Y-%m-%d.
%g
The last two digits of the year of the ISO 8601 week number.
%G
The year of the ISO 8601 week number.
%h
Equivalent to %b.
%H
The hour (24-hour clock) as a decimal number [00,23].
%I
The hour (12-hour clock) as a decimal number [01,12].
%j
The day of the year as a decimal number [001,366].
%m
The month as a decimal number [01,12].
%M
The minute as a decimal number [00,59].
%n
A newline character. The behavior is equivalent to processing a whitespace character.
%O
The locale's alternative representation of the appropriate date and time representation.
%p
The locale's equivalent of either AM or PM.
%P
The locale's equivalent of either am or pm.
%r
The locale's 12-hour clock time. For example, 06:35:09 PM.
%R
The locale's 24-hour clock time. For example, 18:35:09.
%s
The number of seconds since the Epoch.
%S
The second as a decimal number [00,60].
%t
A tab character. The behavior is equivalent to processing a whitespace character.
%T
The locale's 24-hour clock time. For example, 18:35:09.
%u
The ISO 8601 weekday as a decimal number [1,7], where 1 is Monday.
%U
The week number of the year (Sunday as the first day of the week) as a decimal number [00,53].
%V
The ISO 8601 week number as a decimal number [01,53].
%w
The weekday as a decimal number [0,6], where 0 is Sunday.
%W
The week number of the year (Monday as the first day of the week) as a decimal number [00,53].
%x
The locale's appropriate date representation.
%X
The locale's appropriate time representation.
%y
The last two digits of the year as a decimal number [00,99].
%Y
The full year as a decimal number. For example, 1999.
%z
The time zone offset from UTC. The format is +hhmm or -hhmm. If the offset is unknown, this is unspecified.
%Z
The time zone name. If the time zone name is not known, this is unspecified.
%%
A '%' character.

Some conversion specifications have associated modifiers that indicate alternative representations. These modifiers are applicable only when the locale's alternative numeric symbols are used.

%Ec
The locale's alternative representation of the appropriate date and time representation.
%EC
The locale's alternative representation of the center of the era.
%Eg
The offset from %EC (year only) in the locale's alternative representation.
%EG
The full alternative year representation.
%Ex
The locale's alternative representation of the appropriate date representation.
%Ey
The offset from %EC (year only) in the locale's alternative representation.
%EY
The full alternative year representation.
%Od
The day of the month using the locale's alternative numeric symbols; leading zeros shall be permitted but shall not be required.
%Oe
Equivalent to %Od.
%OH
The hour (24-hour clock) using the locale's alternative numeric symbols.
%OI
The hour (12-hour clock) using the locale's alternative numeric symbols.
%Om
The month using the locale's alternative numeric symbols.
%OM
The minutes using the locale's alternative numeric symbols.
%OS
The seconds using the locale's alternative numeric symbols.
%OU
The week number of the year (Sunday as the first day of the week) using the locale's alternative numeric symbols.
%Ow
The number of the weekday (Sunday=0) using the locale's alternative numeric symbols.
%OW
The week number of the year (Monday as the first day of the week) using the locale's alternative numeric symbols.
%Oy
The year (offset from %C) using the locale's alternative numeric symbols.

A conversion specification composed of white-space characters is executed by scanning input up to the first character that is not white-space (which remains unscanned), or until no more characters can be scanned.

A conversion specification that is an ordinary character is executed by scanning the next character from the buffer. If the character scanned from the buffer differs from the one comprising the directive, the directive fails, and the differing and subsequent characters remain unscanned.

A series of conversion specifications composed of %n, %t, white-space characters, or any combination is executed by scanning up to the first character that is not white space (which remains unscanned), or until no more characters can be scanned.

Any other conversion specification is executed by scanning characters until a character matching the next directive is scanned, or until no more characters can be scanned. These characters, except the one matching the next directive, are then compared to the locale values associated with the conversion specifier. If a match is found, values for the appropriate tm structure members are set to values corresponding to the locale information. Case is ignored when matching items in buf such as month or weekday names. If no match is found, strptime() fails and no more characters are scanned.

RETURN VALUE

Upon successful completion, strptime() shall return a pointer to the character following the last character parsed. Otherwise, a null pointer shall be returned.

ERRORS

No errors are defined.

The following sections are informative.

EXAMPLES

Convert a Date-Plus-Time String to Broken-Down Time and Then into Seconds

The following example demonstrates the use of strptime() to convert a string into broken-down time. The broken-down time is then converted into seconds since the Epoch using mktime().

#include <time.h>
...
struct tm tm;
time_t t;
if (strptime("6 Dec 2001 12:33:45", "%d %b %Y %H:%M:%S", &tm) == NULL)
    /* Handle error */;
printf("year: %d; month: %d; day: %d;\n",
        tm.tm_year, tm.tm_mon, tm.tm_mday);
printf("hour: %d; minute: %d; second: %d\n",
        tm.tm_hour, tm.tm_min, tm.tm_sec);
printf("week day: %d; year day: %d\n", tm.tm_wday, tm.tm_yday);
tm.tm_isdst = -1;      /* Not set by strptime(); tells mktime()
                          to determine whether daylight saving time
                          is in effect */
t = mktime(&tm);
if (t == -1)
    /* Handle error */;
printf("seconds since the Epoch: %ld\n", (long) t);"

APPLICATION USAGE

Several ``equivalent to'' formats and the special processing of white-space characters are provided in order to ease the use of identical format strings for strftime() and strptime().

It should be noted that dates constructed by the strftime() function with the %Y or %C%y conversion specifiers may have values larger than 9999. If the strptime() function is used to read such values using %C%y or %Y, the year values will be truncated to four digits. Applications should use %+w%y or %+xY with w and x set large enough to contain the full value of any years that will be printed or scanned.

See also the APPLICATION USAGE section in strftime().

It is unspecified whether multiple calls to strptime() using the same tm structure will update the current contents of the structure or overwrite all contents of the structure. Conforming applications should make a single call to strptime() with a format and all data needed to completely specify the date and time being converted.
