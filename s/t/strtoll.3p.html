STRTOLL(3P) دليل مبرمجي POSIX STRTOLL(3P)

PROLOG

هذه الصفحة اليدوية هي جزء من دليل مبرمجي POSIX. قد يختلف تطبيق Linux لهذا الواجهة (استشر صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا يتم تطبيق الواجهة على Linux.

NAME

strtoll — تحويل سلسلة نصية إلى عدد صحيح طويل

SYNOPSIS

#include <stdlib.h>
long long strtoll(const char *restrict str, char **restrict endptr,
    int base);

DESCRIPTION

راجع strtol().
