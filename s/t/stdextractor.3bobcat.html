stdextractor.3bobcat

الحزمة: libbobcat

التراخيص: GPL

FBB::StdExtractor(3bobcat) تنفيذ العمليات الفرعية FBB::StdExtractor(3bobcat)

الاسم

FBB::StdExtractor - تشغيل البرامج الخارجية التي تكتب مخرجات الخطأ القياسية

الملخص

#include <bobcat/cerrextractor>
خيار الربط: -lbobcat

الوصف

توفر الفئة FBB::StdExtractor واجهة أساسية لاستدعاء البرامج الخارجية (ما يسمى بالعمليات الفرعية) التي تكتب تدفقات المخرجات القياسية والخطأ القياسية. لا يتم التعامل مع تدفق الإدخال القياسي للعمليات الفرعية بشكل افتراضي بواسطة كائنات StdExtractor. يتم قراءة تدفقات المخرجات القياسية والخطأ القياسية للعملية الفرعية من خلال كائن StdExtractor: يتم استخراج المعلومات التي تكتبها العملية الفرعية إلى هذه التدفقات أو قراءتها من كائن StdExtractor. لا يتم استخدام متغير البيئة PATH عند استدعاء العمليات الفرعية: يجب تحديد برامج العمليات الفرعية باستخدام المسارات.

يمكن استخدام كائنات StdExtractor بشكل متكرر لتنفيذ نفس العمليات الفرعية أو عمليات فرعية مختلفة.

يمكن إحاطة الوسائط التي تم تمريرها إلى العمليات الفرعية بعلامات اقتباس مزدوجة أو مفردة. يتم إزالة علامات الاقتباس المزدوجة من الوسائط المحاطة بعلامات اقتباس مزدوجة، مع تفسير أي تسلسلات هروب قد تم استخدامها بداخلها. يتم إزالة علامات الاقتباس المفردة من الوسائط المحاطة بعلامات اقتباس مفردة، مع قبول محتواها كما هو. بالإضافة إلى ذلك، يمكن تحديد تسلسلات هروب غير مقتبسة: يتم تقييم تسلسلات الهروب هذه واستبدالها بأحرفها المقصودة (على سبيل المثال، يتم تحويل \100 إلى @).

الباني

o
StdExtractor(size_t bufSize = 100):
يمكن تحديد وسيط bufSize: يحدد حجم المخزن المؤقت الداخلي المستخدم بواسطة مخزن تدفق StdExtractor. افتراضيًا، لا يتم التعامل مع تدفق الإدخال القياسي.
o
CoutExtractor(Mode mode, size_t bufSize = 100):
يجب أن يكون وسيط mode هو StdExtractor::CLOSE_STD. يشير هذا إلى أن تدفق الإدخال القياسي تم إعادة توجيهه إلى /dev/null: لا يمكن للعمليات الفرعية قراءة تدفقات الإدخال القياسية الخاصة بها. يمكن تحديد وسيط bufSize: يحدد حجم المخزن المؤقت الداخلي المستخدم بواسطة مخزن تدفق CinInserter.

لا تتوفر البانيات النسخ والتحريك (وكذلك عوامل التشغيل المخصصة).

الأعضاء

o
void execute(std::string const &cmd):
يحدد الوسيط الأمر المراد تنفيذه: يجب تحديد الأمر نفسه كمسار (لا يتم استخدام متغير البيئة PATH). تعود هذه العضو على الفور، وبعد ذلك يمكن استخراج المعلومات التي كتبتها العملية الفرعية إلى تدفقاتها القياسية والخطأ القياسية من كائن StdExtractor.
بمجرد عودة execute، يمكن استدعاؤها مرة أخرى، إما باستخدام نفس الأمر أو أمر آخر.
يمكن اختياريًا تحديد الوسائط التي تم تمريرها إلى البرنامج المراد تنفيذه كعملية فرعية باستخدام علامات اقتباس مفردة أو مزدوجة، كما هو موضح في قسم الوصف بهذه الصفحة.
o
int ret() const:
بمجرد عودة execute، يوفر هذا العضو رمز الخروج الفعلي للعملية الفرعية. قيمته تساوي -1 قبل أول استدعاء لـ exectue.

العضو المحمي

o
Pipe &childOutPipe():
إذا احتاجت الفئات المشتقة إلى تجاوز الأعضاء المعاد توجيهها، فمن المحتمل أنها تحتاج إلى الوصول إلى الأنبوب الذي كتبته العملية الفرعية. يوفر هذا العضو مرجعًا لهذا الأنبوب. افتراضيًا، تقرأ العملية الأصلية المعلومات من الأنبوب، بينما تدرج العملية الفرعية مخرجات الخطأ القياسية الخاصة بها في الأنبوب.

مثال

#include <iostream>
#include <bobcat/cerrextractor>
using namespace std;
using namespace FBB;
int main()
{
    CerrExtractor extractor;
    extractor.execute("/bin/cat driver.cc");
    cout << extractor.rdbuf();
    cerr << "Returning: " << extractor.ret() << "\n"
            "again:\n";
    extractor.execute("/bin/cat driver.cc");
    cout << extractor.rdbuf();
    cerr << "Returning: " << extractor.ret() << ’\n’;
}
