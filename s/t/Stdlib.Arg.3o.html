Arg(3o)

Argument parsing library

Module Arg

This module provides functions for parsing command-line arguments.

The core of the module is the function Arg.parse, which iterates through the command-line arguments and applies actions associated with recognized options.

The module also provides functions for writing arguments to a file, which can be useful for debugging or for passing arguments between processes.

Signature 

val write_arg : string -> string array -> unit

Arg.write_arg file args writes the arguments args newline-terminated into the file file . If any of the arguments in args contains a newline, use Arg.write_arg0 instead.

Since 4.05

Signature 

val write_arg0 : string -> string array -> unit

Identical to Arg.write_arg but uses the null character for terminator instead of newline.

Since 4.05
