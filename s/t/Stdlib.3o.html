Module Stdlib
: sig end

مكتبة OCaml القياسية.

يتم فتح هذه الوحدة تلقائيًا في بداية كل تجميع. يمكن الإشارة إلى جميع مكونات هذه الوحدة باسمها المختصر، دون الحاجة إلى سابقتها بـ Stdlib.

وبشكل خاص، توفر العمليات الأساسية على الأنواع المدمجة (الأرقام، القيم المنطقية، سلاسل البايت، السلاسل النصية، الاستثناءات، المراجع، القوائم، المصفوفات، قنوات الإدخال/الإخراج، ...) و الوحدات.

exception Assert_failure of (string * int * int)

exception Invalid_argument of string

الاستثناء الذي تثيره دوال المكتبة للإشارة إلى أن الوسائط المقدمة غير صالحة. السلسلة النصية تقدم معلومات للمبرمج. كقاعدة عامة، يجب عدم التقاط هذا الاستثناء، لأنه يشير إلى خطأ في البرمجة ويجب تعديل الكود لتجنب إثارته.

exception Failure of string

الاستثناء الذي تثيره دوال المكتبة للإشارة إلى أنها غير معرفة للوسائط المقدمة. السلسلة النصية مخصصة لتقديم معلومات للمبرمج؛ لا يجب مطابقتها مع سلسلة نصية حرفية، لأنها قد تتغير في إصدارات مستقبلية (استخدم Failure بدلاً من ذلك).

exception Not_found

الاستثناء الذي تثيره دوال البحث عندما لا يمكن العثور على الكائن المطلوب.

exception Out_of_memory

الاستثناء الذي يثيره جامع القمامة عندما لا توجد ذاكرة كافية لإكمال العملية. (غير موثوق به لتخصيصات في الذاكرة الفرعية).

exception Stack_overflow

الاستثناء الذي يثيره مترجم الكود الثنائي عندما تصل مكدس التقييم إلى حجمها الأقصى. يشير هذا عادةً إلى تكرار لا نهائي أو عميق جدًا في برنامج المستخدم.

قبل 4.10، لم يتم تنفيذه بالكامل بواسطة مترجم الكود الأصلي.

exception Sys_error of string

الاستثناء الذي تثيره دوال الإدخال/الإخراج للإبلاغ عن خطأ في نظام التشغيل. السلسلة النصية مخصصة لتقديم معلومات للمبرمج؛ لا يجب مطابقتها مع سلسلة نصية حرفية، لأنها قد تتغير في إصدارات مستقبلية (استخدم Sys_error بدلاً من ذلك).

exception End_of_file

الاستثناء الذي تثيره دوال الإدخال للإشارة إلى الوصول إلى نهاية الملف.

exception Division_by_zero

الاستثناء الذي تثيره عمليات القسمة الصحيحة والباقي عندما يكون الوسيط الثاني صفرًا.

exception Sys_blocked_io

حالة خاصة من Sys_error التي تثار عندما لا يكون هناك إدخال/إخراج ممكن على قناة إدخال/إخراج غير محظورة.

exception Undefined_recursive_module of (string * int * int)

الاستثناء الذي يثار عند تقييم تعريف وحدة تكرارية غير مؤسس بشكل جيد. الوسائط هي موقع التعريف في الكود المصدري (اسم الملف، رقم السطر، رقم العمود).

val (mod) : int -> int -> int

باقي الأعداد الصحيحة. إذا كان y ليس صفرًا، فإن نتيجة x mod y تحقق الخصائص التالية: x = (x / y) * y + x mod y و abs(x mod y) <= abs(y) - 1 . إذا كان y = 0 ، فإن x mod y تثير Division_by_zero . لاحظ أن x mod y يكون سالبًا فقط إذا كان x < 0 . عامل تجميع يساري، انظر Ocaml_operators لمزيد من المعلومات.

حسابات الأعداد العشرية

تتبع أرقام OCaml العشرية معيار IEEE 754، باستخدام أرقام الدقة المزدوجة (64 بت). لا تثير العمليات العشرية استثناءات أبدًا عند تجاوز السعة، أو النقص، أو القسمة على صفر، وما إلى ذلك. بدلاً من ذلك، يتم إرجاع أرقام IEEE خاصة حسب الاقتضاء، مثل infinity لـ 1.0 /. 0.0 ، و neg_infinity لـ -1.0 /. 0.0 ، و nan ('not a number') لـ 0.0 /. 0.0 . تنتشر هذه الأرقام الخاصة بعد ذلك في الحسابات العشرية كما هو متوقع: على سبيل المثال، 1.0 /. infinity هو 0.0 ، العمليات الحسابية الأساسية ( +. ، -. ، *. ، /. ) مع nan كوسيط تُرجع nan ، إلخ.

عمليات على سلاسل التنسيق

سلاسل التنسيق هي سلاسل أحرف ذات اصطلاحات معجمية محددة تحدد وظائف عمليات الإدخال/الإخراج المنسقة. تستخدم سلاسل التنسيق لقراءة البيانات باستخدام وظائف الإدخال المنسقة من وحدة Scanf وطباعة البيانات باستخدام وظائف الإخراج المنسقة من وحدات Printf و Format.

تتكون سلاسل التنسيق من ثلاثة أنواع من الكيانات:

- مواصفات التحويل، مقدمة بالحرف الخاص '%' متبوعًا بحرف واحد أو أكثر يحدد نوع الوسيط الذي سيتم قراءته أو طباعته،

- مؤشرات التنسيق، مقدمة بالحرف الخاص '@' متبوعًا بحرف واحد أو أكثر يحدد كيفية قراءة أو طباعة الوسيط،

- أحرف عادية تحدد أحرفًا حرفية ذات اصطلاحات معجمية نموذجية. تحدد الأحرف العادية سلاسل حرفية ليتم قراءتها أو طباعتها في الإدخال أو الإخراج.

هناك قاعدة إضافية للهروب من الأحرف الخاصة '%' و '@' في سلاسل التنسيق: إذا اتبع حرف خاص حرف '%'، فإنه يعامل كحرف عادي. بعبارة أخرى، يعتبر "%%" حرفًا عاديًا '%' و "%@" حرفًا عاديًا '@'.

NAME

Stdlib - The standard library

Module

This module contains the OCaml standard library. It is automatically opened at the beginning of each program.

Documentation

Para más información sobre las especificaciones de conversión y indicaciones de formato disponibles, consulte la documentación de los módulos Scanf, Printf y Format .

Los strings de formato tienen un tipo general y altamente polimórfico ('a, 'b, 'c, 'd, 'e, 'f) format6 . Las dos tipos simplificadas, format y format4 a continuación, son incluidas para compatibilidad con versiones anteriores de OCaml.

El significado de los parámetros de tipo de los strings de formato es el siguiente:

- 'a es el tipo de los parámetros de los funciones de salida formatada ( printf - estilo); 'a es el tipo de los valores leídos por las funciones de entrada formatada ( scanf - estilo).

- 'b es el tipo de fuente de entrada para las funciones de entrada formatada y el tipo de destino de salida para las funciones de salida formatada. Para las funciones printf - estilo de módulo Printf, 'b es típicamente out_channel ; para las funciones printf - estilo de módulo Format, 'b es típicamente Format.formatter ; para las funciones scanf - estilo de módulo Scanf, 'b es típicamente Scanf.Scanning.in_channel .

El tipo 'b también es el tipo del primer argumento dado a las funciones de impresión definidas por el usuario para %a y %t, y del argumento transmitido a las funciones kprintf - estilo o a las funciones kscanf - estilo.

- 'c es el tipo de resultado de las funciones %a y %t de impresión, y también el tipo del argumento transmitido al primer argumento de las funciones kprintf - estilo o a las funciones kscanf - estilo.

- 'd es el tipo de parámetros de las funciones scanf - estilo.

- 'e es el tipo de la función receptor de las funciones scanf - estilo.

- 'f es el tipo de resultado final de una invocación de función de entrada/ salida formatada: para las funciones printf - estilo, es típicamente unit ; para las funciones scanf - estilo, es típicamente el tipo de resultado de la función receptor.

val format_of_string : ('a, 'b, 'c, 'd, 'e, 'f) format6 -> ('a, 'b, 'c, 'd, 'e, 'f) format6

format_of_string s devuelve un string de formato leído a partir del literal s . Nota: format_of_string no puede convertir un argumento de cadena que no sea un literal. Si necesitas esta funcionalidad, usa la función más general Scanf.format_from_string .

val (^^) : ('a, 'b, 'c, 'd, 'e, 'f) format6 -> ('f, 'b, 'c, 'e, 'g, 'h) format6 -> ('a, 'b, 'c, 'd, 'g, 'h) format6

f1 ^^ f2 concatenan los strings de formato f1 y f2 . El resultado es un string de formato que comporta como la concatenación de los strings de formato f1 y f2 : en caso de salida formatada, acepta los argumentos de f1 , luego los de f2 ; en caso de entrada formatada, devuelve los resultados de f1 , luego de f2 . Operador asociativo a la derecha, ver Ocaml_operators para más información.

Program termination

val exit : int -> 'a

Termina el proceso, devolviendo el código de estado dado al sistema operativo: generalmente 0 para no tener errores, y un pequeño número positivo para indicar un error. Todos los canales de salida abiertos se flujean con flush_all . Las callbacks registradas con Domain.at_exit se llaman después de los registrados con at_exit .

Se realiza un exit 0 implícito cada vez que un programa termina normalmente. Se realiza un exit 2 implícito si el programa termina anticipadamente debido a una excepción no capturada.

val at_exit : (unit -> unit) -> unit

Registra la función dada para que se ejecute al finalizar el programa. Las funciones registradas con at_exit se llaman cuando el programa realice alguna de las siguientes acciones:

- ejecuta exit

- termina, ya sea normally o debido a una excepción no capturada

- ejecuta la función C caml_shutdown . Las funciones se llaman en el orden 'último en, primero en' : la función más recientemente registrada con at_exit se llama primero.
