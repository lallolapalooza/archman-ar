وصف مفصل

template<typename _BiIter>

class std::sub_match< _BiIter >"تسلسل من الأحرف تم مطابقته بواسطة تعبير فرعي محدد في نمط التعبير العادي.

الكائن من هذا الصنف هو بشكل أساسي زوج من المكررات (iterators) تشير إلى تعبير فرعي مطابق ضمن مطابقة نمط تعبير عادي. يمكن تحويل مثل هذه الكائنات إلى كائنات std::basic_string من نفس نوع الأحرف للتعبير العادي المطابق ومقارنتها بها.

sub_match<Iter> لها فئة أساسية عامة من النوع pair<Iter, Iter>، لذا ترث أعضاء بيانات pair المسماة first و second. المكررات التي تشكل الزوج هي الفترة نصف المفتوحة المعتادة التي تشير إلى النمط الأصلي الفعلي الذي تمت مطابقته.

NAME

std::sub_match - represents a matched sub-sequence of a sequence

SYNOPSIS

#include <regex>

template<typename   _BiIter>
class std::sub_match {
public:
  // types
  typedef _BiIter iterator;
  typedef std::iterator_traits<_BiIter> traits;
  typedef typename traits::difference_type difference_type;
  typedef std::basic_string<typename traits::value_type> string_type;

  // accessors
  iterator first;
  iterator second;

  // capture operators
  operator string_type() const;
  template<typename   T> operator std::basic_string<T>() const;
  template<typename   T> operator std::basic_string_view<T>() const;
  template<typename   T> operator std::basic_regex<T>() const;

  // members
  difference_type length() const;
  string_type str() const;
  void swap(sub_match& __s);
};

Detailed Description

The C++ standard library provides the std::sub_match class template, which represents a matched sub-sequence of a sequence.

It is defined in the <regex> header.

The std::sub_match class template is a pair of iterators, first and second, that denote the beginning and end of the matched sub-sequence within the original sequence.

The contents of a std::sub_match object are typically obtained from the results of regular expression operations, such as those performed by std::regex_match, std::regex_search, or std::regex_iterator.

It is important to note that a std::sub_match object itself does not store the matched characters. Instead, it provides iterators pointing into the original sequence where the match occurred. This means that if the original sequence is modified or goes out of scope, the std::sub_match object may become invalid.

The std::sub_match class template has a member type string_type, which is an alias for std::basic_string<charT>, where charT is the character type of the iterators.

There are several conversion operators that allow you to easily obtain the matched sequence as different string types or even as a std::basic_regex object.

Be aware that regular expression matching can sometimes lead to unexpected results or behaviors, especially with complex patterns or edge cases. This can cause the std::sub_match object to pop up in unexpected places and cause a great deal of confusion and cursing from the unwary.
