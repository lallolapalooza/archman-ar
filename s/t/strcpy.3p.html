STRCPY(3P) دليل مبرمج POSIX STRCPY(3P)

PROLOG

هذه الصفحة الدليلية جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذه الواجهة (استشر صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

NAME

stpcpy, strcpy — نسخ سلسلة وإرجاع مؤشر إلى نهاية النتيجة

SYNOPSIS

#include <string.h>
char *stpcpy(char *restrict s1, const char *restrict s2);
char *strcpy(char *restrict s1, const char *restrict s2);

DESCRIPTION

بالنسبة لـ strcpy(): الوظيفة الموضحة في صفحة المرجع هذه متوافقة مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

تقوم دالتا stpcpy() و strcpy() بنسخ السلسلة التي يشير إليها s2 (بما في ذلك حرف NUL الختامي) إلى المصفوفة التي يشير إليها s1.

إذا حدث النسخ بين كائنات متداخلة، فإن السلوك غير محدد.

RETURN VALUE

تُرجع دالة stpcpy() مؤشرًا إلى حرف NUL الختامي الذي تم نسخه إلى المخزن المؤقت s1.

تُرجع دالة strcpy() القيمة s1.

لا توجد قيم إرجاع محجوزة للإشارة إلى خطأ.

ERRORS

لا توجد أخطاء محددة.

الأقسام التالية إعلامية.

EXAMPLES

إنشاء رسالة متعددة الأجزاء في مخزن مؤقت واحد

#include <string.h>
#include <stdio.h>
int
main (void)
{
    char buffer [10];
    char *name = buffer;
    name = stpcpy (stpcpy (stpcpy (name, "ice"),"-"), "cream");
    puts (buffer);
    return 0;
}

تهيئة سلسلة

يقوم المثال التالي بنسخ السلسلة "----------" إلى المتغير permstring.

#include <string.h>
...
static char permstring[11];
...
strcpy(permstring, "----------");
...

تخزين مفتاح وبيانات

يقوم المثال التالي بتخصيص مساحة لمفتاح باستخدام malloc() ثم يستخدم strcpy() لوضع المفتاح هناك. ثم يقوم بتخصيص مساحة للبيانات باستخدام malloc()، ويستخدم strcpy() لوضع البيانات هناك. (تقوم الدالة المعرفة من قبل المستخدم dbfree() بتحرير الذاكرة المخصصة مسبقًا لمصفوفة من نوع struct element *.)

#include <string.h>
#include <stdlib.h>
#include <stdio.h>
...
/* Structure used to read data and store it. */
struct element {
    char *key;
    char *data;
};
struct element *tbl, *curtbl;
char *key, *data;
int count;
...
void dbfree(struct element *, int);
...
if ((curtbl->key = malloc(strlen(key) + 1)) == NULL) {
    perror("malloc"); dbfree(tbl, count); return NULL;
}
strcpy(curtbl->key, key);
if ((curtbl->data = malloc(strlen(data) + 1)) == NULL) {
    perror("malloc"); free(curtbl->key); dbfree(tbl, count); return NULL;
}
strcpy(curtbl->data, data);
...

APPLICATION USAGE

يتم تنفيذ حركة الأحرف بشكل مختلف في تطبيقات مختلفة. وبالتالي، قد تؤدي الحركات المتداخلة إلى مفاجآت.

هذه النسخة متوافقة مع معيار ISO C؛ هذا لا يؤثر على التوافق مع تطبيقات XPG3. لم يتم أبدًا ضمان اكتشاف الأخطاء الموثوق به بواسطة هذه الدالة.
