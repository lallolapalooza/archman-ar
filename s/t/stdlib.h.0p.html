stdlib.h(0P) دليل مبرمج POSIX stdlib.h(0P)

PROLOG

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تنفيذ هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة منفذة على لينكس.

الاسم

stdlib.h — تعريفات المكتبة القياسية

الملخص

#include <stdlib.h>

الوصف

تمتد بعض الوظائف الموصوفة في صفحة المرجع هذه معيار ISO C. يجب على التطبيقات تحديد ماكرو اختبار الميزة المناسب (راجع مجلد واجهات النظام في POSIX.1-2017، القسم 2.2، بيئة الترجمة) لتمكين رؤية هذه الرموز في هذا الرأس.

يجب على رأس <stdlib.h> تحديد الثوابت التالية التي يجب أن تتوسع إلى تعبيرات ثابتة صحيحة:

EXIT_FAILURE
إنهاء غير ناجح لـ exit(); يساوي قيمة غير صفرية.
EXIT_SUCCESS
إنهاء ناجح لـ exit(); يساوي 0.
{RAND_MAX}
أقصى قيمة تعود بها rand(); على الأقل 32767.

يجب على رأس <stdlib.h> تحديد الماكرو التالي الذي يجب أن يتوسع إلى تعبير صحيح موجب بنوع size_t:

{MB_CUR_MAX}
الحد الأقصى لعدد البايتات في حرف محدد بواسطة الإعداد المحلي الحالي (الفئة LC_CTYPE).

في الإعداد المحلي POSIX، تكون قيمة {MB_CUR_MAX} هي 1.

يجب على رأس <stdlib.h> تحديد NULL كما هو موصوف في <stddef.h>.

يجب على رأس <stdlib.h> تحديد أنواع البيانات التالية من خلال typedef:

div_t
نوع الهيكل الذي تعيده الدالة div().
ldiv_t
نوع الهيكل الذي تعيده الدالة ldiv().
lldiv_t
نوع الهيكل الذي تعيده الدالة lldiv().
size_t
كما هو موصوف في <stddef.h>.
wchar_t
كما هو موصوف في <stddef.h>.

بالإضافة إلى ذلك، يجب على رأس <stdlib.h> تحديد الثوابت والماكرو الرمزية التالية كما هو موصوف في <sys/wait.h>:

WEXITSTATUS
WIFEXITED
WIFSIGNALED
WIFSTOPPED
WNOHANG
WSTOPSIG
WTERMSIG
WUNTRACED

NAME

stdlib.h — standard library definitions

SYNOPSIS

Include the following header:

#include <stdlib.h>

DESCRIPTION

The <stdlib.h> header shall define the behavior of the functions and types for general utilities.

The following macros shall be defined:

EXIT_FAILURE
An integer expression that is the opposite of EXIT_SUCCESS.
EXIT_SUCCESS
An integer expression that is the value passed to exit() to indicate successful termination.
MB_CUR_MAX
A one-byte macro that is the maximum number of bytes in a character in the current locale.
NULL
A macro that expands to an implementation-defined null pointer constant.

The following macros shall be defined:

RAND_MAX
A constant expression with the value of the maximum value returned by rand().

The following types shall be defined:

size_t
An unsigned integer type that is large enough to contain the size of most objects.
wchar_t
An integer type whose range of values can represent a character from the execution character set.

The following functions shall be declared:

void *calloc(size_t number, size_t size);
void exit(int status);
void free(void *ptr);
char *getenv(const char *name);
void *malloc(size_t size);
int rand(void);
void *realloc(void *ptr, size_t size);
void srand(unsigned int seed);

The following functions shall be declared:

int abs(int j);
long int labs(long int j);
div_t div(int numer, int denom);
ldiv_t ldiv(long int numer, long int denom);

The following functions shall be declared:

int mblen(const char *s, size_t n);
size_t mbstowcs(wchar_t *ws, const char *s, size_t n);
int mbtowc(wchar_t *pwc, const char *s, size_t n);

The following functions shall be declared:

void abort(void);
int atexit(void (*func)(void));
double atof(const char *nptr);
int atoi(const char *nptr);
long int atol(const char *nptr);
void *bsearch(const void *key, const void *base, size_t nel, size_t width,
     int (*compar)(const void *, const void *));
char *ecvt(double arg, int ndigit, int *decpt, int *sign);
char *fcvt(double arg, int ndigit, int *decpt, int *sign);
char *gcvt(double arg, int ndigit, char *buf);
int getopt(int argc, char *const argv[], const char *optstring);
int max(int x, int y);
int min(int x, int y);
long int strtol(const char *nptr, char **endptr, int base);
long long int strtoll(const char *nptr, char **endptr, int base);
unsigned long int strtoul(const char *nptr, char **endptr, int base);
unsigned long long int strtoull(const char *nptr, char **endptr, int base);
int system(const char *command);
size_t wcstombs(char *s, const wchar_t *ws, size_t n);
int wctomb(char *s, wchar_t wchar);

APPLICATION USAGE

The atof(), atoi(), and atol() functions do not support the parsing of whitespace. The strtod() and strtol() functions support the parsing of whitespace, but do not support the parsing of non-numeric characters immediately following a valid number.

It is recommended that applications use strtol() instead of atoi() or atol(), and strtod() instead of atof(), because the latter functions do not support error reporting.

The behavior of strtol() and strtod() is undefined if the value of the base argument is other than 0, 2 to 36.

The getenv() function may return a pointer to a static array that may be overwritten by subsequent calls to getenv() or other functions that modify the environment.
