الوصف

The std::basic_stringstream class provides capabilities to manipulate a sequence of characters (a string) as a stream. It inherits from std::basic_iostream, which itself inherits from std::basic_istream and std::basic_ostream. This means it supports both input and output operations on strings.

The string buffer used by std::basic_stringstream is of type std::basic_stringbuf. This buffer stores the character sequence in memory.

std::basic_stringstream is templated on the character type (_CharT), the character traits (_Traits), and the allocator (_Alloc).

The primary use cases for std::basic_stringstream are:

  • Formatting data into a string: You can use insertion operators (<<) to write various data types into the stringstream, and they will be converted to their string representations.
  • Parsing data from a string: You can use extraction operators (>>) to read data from the stringstream and convert it into various data types.
  • Building strings incrementally: You can append strings or other data to the stringstream and later retrieve the entire constructed string.

Key members of std::basic_stringstream include:

str()
Returns the string currently held by the stream buffer. There are two overloads: one that returns a copy of the string and another that returns an rvalue reference for move semantics.
str(__string_type)
Sets the string buffer to a new string. This replaces the current content of the stream.
operator<<
Insertion operators for writing data into the stream.
operator>>
Extraction operators for reading data from the stream.

Since it inherits from std::basic_iostream, it also has access to all the stream manipulation functions like getline, ignore, seekp, tellp, etc.

The template parameters allow for customization:

_CharT
Specifies the character type (e.g., char for narrow strings, wchar_t for wide strings).
_Traits
Specifies the character traits class, which provides information and functions for manipulating characters (e.g., std::char_traits).
_Alloc
Specifies the allocator type used for managing the string buffer's memory.

Commonly used typedefs simplify declarations:

std::stringstream
Equivalent to std::basic_stringstream<char>.
std::wstringstream
Equivalent to std::basic_stringstream<wchar_t>.

Note: The constructor taking a basic_stringstream&& and the copy constructor being deleted (marked as "=delete") indicate that move semantics are supported, but copy semantics are explicitly disabled.

مثال

The following example demonstrates basic usage of std::stringstream for formatting and parsing:

#include <iostream>
#include <sstream>
#include <string>

int main() {
    // Formatting data into a stringstream
    std::stringstream ss;
    int age = 30;
    double height = 5.9;
    std::string name = "Alice";

    ss << "Name: " << name << ", Age: " << age << ", Height: " << height;

    // Get the formatted string
    std::string formatted_string = ss.str();
    std::cout << "Formatted string: " << formatted_string << std::endl;

    // Reset the stringstream for parsing
    ss.str(""); // Clear the content
    ss.clear(); // Clear any error flags

    // Parsing data from a stringstream
    std::string input_string = "Bob 25 6.1";
    ss << input_string;

    std::string parsed_name;
    int parsed_age;
    double parsed_height;

    ss >> parsed_name >> parsed_age >> parsed_height;

    std::cout << "Parsed data:" << std::endl;
    std::cout << "Name: " << parsed_name << std::endl;
    std::cout << "Age: " << parsed_age << std::endl;
    std::cout << "Height: " << parsed_height << std::endl;

    return 0;
}

Output:

Formatted string: Name: Alice, Age: 30, Height: 5.9
Parsed data:
Name: Bob
Age: 25
Height: 6.1

الإرجاع

عدد صحيح مختلف عن جميع الاستدعاءات السابقة.
