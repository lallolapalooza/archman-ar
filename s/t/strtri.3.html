الغرض:

!>
!> STRTRI يحسب معكوس مصفوفة مثلثية حقيقية عليا أو سفلى A.
!>
!> هذا هو الإصدار من المستوى 3 من BLAS للخوارزمية.
!>

المعاملات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular; (A مصفوفة مثلثية عليا)
!>          = 'L':  A is lower triangular. (A مصفوفة مثلثية سفلى)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular; (A مثلثية غير وحدوية)
!>          = 'U':  A is unit triangular. (A مثلثية وحدوية)
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0. (ترتيب المصفوفة A. N >= 0)
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the triangular matrix A.  If UPLO = 'U', the
!>          leading N-by-N upper triangular part of the array A contains
!>          the upper triangular matrix, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of the array A contains
!>          the lower triangular matrix, and the strictly upper
!>          triangular part of A is not referenced.  If DIAG = 'U', the
!>          diagonal elements of A are also not referenced and are
!>          assumed to be 1.
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same storage format.
!> (عند الدخول، المصفوفة المثلثية A. إذا كانت UPLO = 'U'، الجزء المثلثي العلوي
!>  من حجم N×N في الصفيف A يحتوي على المصفوفة المثلثية العليا، والجزء السفلي
!>  المثلثي بدقة من A غير مُشار إليه. إذا كانت UPLO = 'L'، الجزء المثلثي السفلي
!>  من حجم N×N في الصفيف A يحتوي على المصفوفة المثلثية السفلى، والجزء العلوي
!>  المثلثي بدقة من A غير مُشار إليه. إذا كانت DIAG = 'U'، فإن العناصر القطرية
!>  في A غير مُشار إليها وتُفترض أنها 1.
!>  عند الخروج، المعكوس (المثلثي) للمصفوفة الأصلية، بنفس تنسيق التخزين.)
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!> (البعد الرائد للصفيف A. LDA >= max(1,N).)
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit (نجاح)
!>          < 0: if INFO = -i, the i-th argument had an illegal value (إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية)
!>          > 0: if INFO = i, A(i,i) is exactly zero.  The triangular
!>               matrix is singular and its inverse can not be computed.
!> (إذا كان INFO = i، فإن A(i,i) يساوي صفرًا تمامًا. المصفوفة المثلثية
!>  منفردة ولا يمكن حساب معكوسها.)
!>
