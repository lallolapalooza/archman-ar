توثيق الوظيفة/الروتين الفرعي

subroutine stptrs (character uplo, character trans, character diag, integer n, integer nrhs, real, dimension( * ) ap, real, dimension( ldb, * ) b, integer ldb, integer info)

STPTRS

الغرض:

!>
!> STPTRS يحل نظامًا مثلثيًا بالشكل
!>
!>    A * X = B  أو  A**T * X = B,
!>
!> حيث A هي مصفوفة مثلثية من الدرجة N مخزنة بتنسيق مضغوط، و B هي مصفوفة N-by-NRHS.
!>
!> يتحقق هذا الروتين الفرعي من أن A غير قابلة للانعكاس، ولكن يجب على المتصلين ملاحظة أنه لا يتم اكتشاف
!> إلا الانعكاسات الدقيقة. من الممكن أن تكون عناصر القطر واحد أو أكثر لـ A عبارة عن أرقام صغيرة
!> بشكل غير طبيعي دون أن يشير هذا الروتين الفرعي إلى خطأ.
!>
!> إذا كان فقدان الدقة الرقمية المحتمل بسبب المصفوفات القريبة من الانعكاس مصدر قلق،
!> يجب على المتصل التحقق من أن A غير قابلة للانعكاس ضمن بعض التسامح قبل استدعاء هذا الروتين الفرعي.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular;
!>          = 'L':  A is lower triangular.
!>

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations:
!>          = 'N':  A * X = B  (No transpose)
!>          = 'T':  A**T * X = B  (Transpose)
!>          = 'C':  A**H * X = B  (Conjugate transpose = Transpose)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular;
!>          = 'U':  A is unit triangular.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0.
!>

AP

!>          AP is REAL array, dimension (N*(N+1)/2)
!>          The upper or lower triangular matrix A, packed columnwise in
!>          a linear array.  The j-th column of A is stored in the array
!>          AP as follows:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) for j<=i<=n.
!>

B

!>          B is REAL array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B.
!>          On exit, if INFO = 0, the solution matrix X.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element of A is exactly zero,
!>                indicating that the matrix is singular and the
!>                solutions X have not been computed.
!>
