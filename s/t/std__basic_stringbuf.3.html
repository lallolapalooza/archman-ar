معلمات القالب

_CharT نوع تدفق الأحرف.
_Traits خصائص نوع الحرف، الافتراضي هو char_traits<_CharT>.
_Alloc نوع المخصص، الافتراضي هو allocator<_CharT>.

تقوم هذه الفئة بربط تسلسل إدخال أو إخراج أو كليهما بتسلسل من الأحرف، والذي يمكن تهيئته من، أو جعله متاحًا كـ std::basic_string. (تمت إعادة صياغته من [27.7.1]/1).

بالنسبة لهذه الفئة، تكون أوضاع الفتح (من نوع ios_base::openmode) في الحالة 'مُعيّنة' إذا كان يمكن قراءة تسلسل الإدخال، وفي الحالة 'مُعيّنة' إذا كان يمكن كتابة تسلسل الإخراج.

الإرجاع

template<class _CharT, class _Traits, class _Alloc> basic_stringbuf< _CharT, _Traits, _Alloc >::int_type std::basic_stringbuf< _CharT, _Traits, _Alloc >::overflow (int_type __c = traits_type::eof()) [protected], [virtual]

تستهلك البيانات من المخزن المؤقت؛ وتكتب إلى التسلسل المتحكم به.

المعلمات

__c حرف إضافي للاستهلاك.

الإرجاع

eof() للإشارة إلى الفشل، شيء آخر (عادةً __c، أو not_eof())

بشكل غير رسمي، يتم استدعاء هذه الدالة عندما يكون مخزن الإخراج المؤقت ممتلئًا (أو غير موجود، حيث لا يلزم إجراء التخزين المؤقت فعليًا). إذا كان هناك مخزن مؤقت موجود، فإنه يتم استهلاكه، مع تأثير ما على التسلسل المتحكم به. (عادةً، يتم كتابة المخزن المؤقت إلى التسلسل حرفيًا.) في كلتا الحالتين، يتم كتابة الحرف c أيضًا، إذا لم يكن __c هو eof().

لتعريف رسمي لهذه الدالة، راجع نصًا جيدًا مثل Langer & Kreft، أو [27.5.2.4.5]/3-7.

يمكن إنشاء مخزن مؤقت إخراج يعمل عن طريق تجاوز هذه الدالة فقط (لن يتم استخدام منطقة تخزين مؤقت).

ملاحظة

لا تقوم النسخة الأساسية من الفئة بأي شيء، وتعيد eof().

تمت إعادة التنفيذ من std::basic_streambuf< _CharT, _Traits >.

std::basic_streambuf - Abstract base class for stream buffer classes.

SYNOPSIS

All classes with this member function are derived from std::basic_streambuf.

  • std::basic_filebuf< _CharT, _Traits >

Detailed Description

The basic_streambuf class is an abstract base class, and it is the foundation for all stream buffer classes in libstdc++. Stream buffers are used to handle the transfer of data between streams and external sources or destinations. Essentially, a stream buffer is an object that manages a sequence of characters. The basic_streambuf class defines the interface for these operations, but it does not provide the actual implementation. Instead, derived classes such as basic_stringbuf and basic_filebuf provide concrete implementations for specific types of character sequences (e.g., strings in memory or files on disk).

The basic_streambuf class is templated on the character type (_CharT) and the character traits type (_Traits), allowing it to work with various character encodings and character handling functionalities.

Key responsibilities of a stream buffer include:

  • Managing input and output character sequences.
  • Providing mechanisms for reading characters from an input sequence.
  • Providing mechanisms for writing characters to an output sequence.
  • Handling buffer management (e.g., filling the input buffer, emptying the output buffer).
  • Supporting synchronization between the stream and the external device.

The basic_streambuf class defines several protected member functions that derived classes typically override to implement their specific buffering behavior. These include functions for getting characters (underflow, uflow), putting characters (overflow, pprune), and managing the buffer pointers (_M_in_beg, _M_in_cur, _M_in_end, _M_out_beg, _M_out_cur, _M_out_end).
