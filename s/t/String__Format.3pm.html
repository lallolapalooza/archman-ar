String__Format(3pm)

الحزمة: perl-string-format

التراخيص: PerlArtistic

Format(3) توثيق مساهمي المستخدم في Perl Format(3)

الاسم

String::Format - إمكانيات تنسيق سلسلة شبيهة بـ sprintf مع تعريفات تنسيق عشوائية

ملخص

تسمح String::Format بإمكانيات تنسيق تشبه sprintf مع تعريفات تنسيق عشوائية

ملخص التركيب

use String::Format;
my %fruit = (
      'a' => "تفاح",
      'b' => "موز",
      'g' => "جريب فروت",
      'm' => "بطيخ",
      'w' => "بطيخ",
);
my $format = "أحب %a، %b، و %g، ولكن ليس %m أو %w.";
print stringf($format, %fruit);

# يطبع:
# أحب التفاح، الموز، والجريب فروت، ولكن ليس البطيخ أو البطيخ.

الوصف

تسمح لك String::Format بتعريف تسلسلات تنسيق تشبه printf ليتم توسيعها. ستكون هذه الوحدة مفيدة للغاية في ملفات التكوين وأدوات إعداد التقارير، حيث تحتاج نتائج الاستعلام إلى التنسيق بطريقة معينة. استوحيت من تنسيق الفهرس (index_format) والتوجيهات ذات الصلة في mutt (انظر <URL:http://www.mutt.org/doc/manual/manual-6.html#index_format>).

الوظائف

stringf

تُصدّر String::Format وظيفة واحدة تسمى stringf. تأخذ stringf وسيطين: سلسلة تنسيق (انظر سلاسل التنسيق، أدناه) وإشارة إلى تجزئة من أزواج اسم => قيمة. هذه الأزواج اسم => قيمة هي ما سيتم توسيعه في سلسلة التنسيق.

سلاسل التنسيق

يجب أن تتطابق سلاسل التنسيق مع التعبير العادي التالي:

qr/
   (%             # '%' البادئة
    (-)?          # محاذاة لليسار، بدلاً من اليمين
    (\d*)?        # (اختياري) الحد الأدنى لعرض الحقل
    (?:\.(\d*))?  # (اختياري) الحد الأقصى لعرض الحقل
    ({.*?})?      # (اختياري) المحتوى بين الأقواس
    (\S)          # حرف التنسيق الفعلي
   )/x;

إذا كان حرف الهروب المحدد غير موجود في %args، فسيتم استخدام السلسلة الأصلية. تعمل خيارات المحاذاة والعرض الأدنى والأقصى بنفس الطريقة التي تم تعريفها بها في sprintf(3) (أي اختلاف هو خطأ، ويجب الإبلاغ عنه).

لاحظ أن تعريف sprintf في Perl أكثر ليبرالية قليلاً من التعبير العادي أعلاه؛ الانحرافات كانت متعمدة، وكلها تتعلق بالتنسيق الرقمي (تم استبعاد الزعماء #، 0، و + على وجه التحديد).

القيمة المرفقة بالمفتاح يمكن أن تكون قيمة عددية أو مرجعًا لروتين فرعي؛ إذا كانت مرجعًا لروتين فرعي، فسيتم تمرير أي شيء بين '{' و '}' (الخامس في التعبير العادي أعلاه) باسم $_[0] إلى مرجع الروتين الفرعي. هذا يسمح بإدخالات مثل هذه:

%args = (
    d => sub { POSIX::strftime($_[0], localtime) },

والتي يمكن استدعاؤها بسلسلة التنسيق هذه:

"الوقت هو %{%M:%S}d الآن، في %{%A، %B %e}d."

وينتج عنه (على سبيل المثال):

الوقت هو 17:45 الآن، في الاثنين، 4 فبراير.

نظرًا لأن السلسلة يتم تمريرها دون تعديل إلى مرجع الروتين الفرعي، وسيقوم strftime بالعمل الصحيح مع هذه البيانات، يمكن كتابة سلسلة التنسيق أعلاه على النحو التالي:

"الوقت هو %{%M:%S الآن، في %A، %B %e}d."

افتراضيًا، يتم تعريف التنسيقات 'n' و 't' و '%' لتكون سطرًا جديدًا، وعلامة جدولة، و '%' على التوالي، إذا لم يتم تعريفها بالفعل في تجزئة الوسائط التي تم تمريرها إليها. لذلك يمكننا إضافة أحرف الإرجاع ببساطة:

"الوقت هو %{%M:%S الآن، في %A، %B %e}d.%n"

بسبب كيفية تحليل السلسلة، يتم تحويل "\n" و "\t" العادية إلى حرفين لكل منهما، ولا يتم التعامل معها كسطر جديد وعلامة جدولة. هذا خطأ.

طريقة المصنع

تدعم String::Format أيضًا طريقة فئة، تسمى stringfactory، والتي ستعيد مرجعًا لروتين فرعي "مُجهز". يجب تمرير stringfactory مرجعًا إلى تجزئة القيمة؛ سيستخدم الروتين الفرعي المُعاد هذه القيم كتجزئة %args.

my $self = Some::Groovy::Package->new($$, $<, $^T);
my %formats = (
      'i' => sub { $self->id      },
      'd' => sub { $self->date    },
      's' => sub { $self->subject },
      'b' => sub { $self->body    },
);
my $index_format = String::Format->stringfactory(\%formats);
print $index_format->($format1);
print $index_format->($format2);

يمكن تعيين مرجع الروتين الفرعي هذا إلى إدخال جدول رموز محلي، واستدعاؤه بشكل طبيعي، بالطبع:

*reformat = String::Format->stringfactory(\%formats);
my $reformed = reformat($format_string);
