std::istream_iterator

NAME

istream_iterator — An iterator adapter to read elements from an input stream.

SYNOPSIS

std::istream_iterator is a template class provided by the C++ Standard Library. It allows you to treat elements read from an input stream (like std::cin or an std::ifstream) as if they were elements in a container, making them usable with standard algorithms.

It's a *single-pass* iterator, meaning you can only iterate through it once. After reading an element, you cannot go back to it.

Detailed Description

The std::istream_iterator is designed to simplify reading sequences of elements from input streams. It internally manages the stream and reads elements as needed when the iterator is dereferenced or incremented.

It is particularly useful when you need to populate a container from a stream or use stream elements with algorithms like std::copy or std::accumulate.

Member Typedef Documentation

Typedef Type Description

Constructor & Destructor Documentation

std::istream_iterator() Default constructor. Creates an "end-of-stream" iterator. This is typically used to mark the end of a range.
std::istream_iterator(std::istream& s, const char* delim = " \t\n\r\f\v") Constructs an istream_iterator that reads elements of type T from the input stream s. Elements are extracted using the extraction operator (>>). The optional delim parameter specifies whitespace characters that delimit the elements. If not provided, it defaults to standard whitespace.
~istream_iterator() Destructor.

Friends And Related Symbol Documentation

operator== Compares two istream_iterator objects for equality. Two iterators are equal if they both represent the end-of-stream or if they are currently pointing to the same stream state (this comparison can be complex and depends on the stream's internal state).
operator!= Compares two istream_iterator objects for inequality.
operator* Dereferences the iterator, returning the value of the element read from the stream. Note that this operation might advance the stream's internal state.
operator++ Advances the iterator to the next element in the stream. This operation reads the next element from the stream.
