stringprep_4zi(3)

الحزمة: libidn

التراخيص: GPL3, LGPL

stringprep_4zi(3) libidn stringprep_4zi(3)

الاسم

stringprep_4zi - دالة API

الملخص

#include <stringprep.h>

int stringprep_4zi(uint32_t * ucs4, size_t maxucs4len, Stringprep_profile_flags flags, const Stringprep_profile * profile);

المعاملات

uint32_t * ucs4
مصفوفة إدخال/إخراج مع سلسلة منتهية بصفر ليتم تحضيرها.
size_t maxucs4len
الحد الأقصى لطول مصفوفة الإدخال/الإخراج.
Stringprep_profile_flags flags
قيمة Stringprep_profile_flags، أو 0.
const Stringprep_profile * profile
مؤشر إلى Stringprep_profile للاستخدام.

الوصف

قم بتحضير سلسلة UCS-4 المدخلة المنتهية بصفر وفقًا لملف تعريف stringprep، واكتب النتيجة مرة أخرى إلى السلسلة المدخلة.

نظرًا لأن عملية stringprep يمكن أن توسع السلسلة، فإن maxucs4len تشير إلى حجم المخزن المؤقت الذي يحتوي على السلسلة. لن تقوم هذه الدالة بالقراءة أو الكتابة إلى نقاط الترميز خارج هذا الحجم.

العلامات flags هي إحدى قيم Stringprep_profile_flags، أو 0.

يحتوي profile على تعليمات Stringprep_profile التي سيتم تنفيذها. يمكن لتطبيقك تحديد ملفات تعريف جديدة، ربما بإعادة استخدام جداول stringprep العامة التي ستكون دائمًا جزءًا من المكتبة، أو استخدام أحد ملفات التعريف المدعومة حاليًا.

قيمة الإرجاع: تُرجع STRINGPREP_OK في حالة النجاح، أو رمز خطأ Stringprep_rc.
