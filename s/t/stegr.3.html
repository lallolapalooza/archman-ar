Detailed Description

ZSTEGR computes the eigenvectors and/or eigenvalues of a generalized tri-diagonal matrix defined by the real symmetric tri-diagonal matrix T (in one-dimensional arrays D and E) and optionally the eigenvalues and eigenvectors of a specific range of eigenvalues, to the specified precision.

The tri-diagonal matrix $T$ is defined as:

            T =   diag(D(1), D(2), ..., D(N))
                  +   diag(E(1), 2, ..., N-1) [upper triangular part]
                  +   diag(E(1), 2, ..., N-1) [lower triangular part]

The eigenvalues are computed using the divide and conquer method. If the eigenvectors are requested, then the eigenvectors are computed using the same method.
