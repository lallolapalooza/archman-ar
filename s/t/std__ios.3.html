الاسم

std::basic_ios< _CharT, _Traits > - فئة القالب basic_ios، فئة أساسية افتراضية لجميع فئات التدفق.

الملخص

#include <ios>

ترث من std::ios_base.

ترث منها std::basic_istream< char > [افتراضي]، std::basic_istream< wchar_t > [افتراضي]، std::basic_ostream< char > [افتراضي]، std::basic_ostream< wchar_t > [افتراضي]، std::basic_istream< _CharT, _Traits > [افتراضي]، و std::basic_ostream< _CharT, _Traits > [افتراضي].

template<typename _CharT, typename _Traits> typedef _Ios_Fmtflags std::basic_ios< _CharT, _Traits >::fmtflags

This is a bitmask type. _Ios_Fmtflags is implementation-defined, but it is valid to perform bitwise operations on these values and expect the Right Thing to happen. Defined objects of type fmtflags are:

  • dec: Converts integer input or generates integer output in decimal base.
  • fixed: Generates floating-point output in fixed-point notation.
  • hex: Converts integer input or generates integer output in hexadecimal base.
  • internal: Adds fill characters after the sign or base prefix but before the digits for numeric output.
  • left: Adds fill characters on the right (end positions) of certain generated output. (I.e., the thing you print is flush left.)
  • oct: Converts integer input or generates integer output in octal base.
  • right: Adds fill characters on the left (initial positions) of certain generated output. (I.e., the thing you print is flush right.)
  • scientific: Generates floating-point output in scientific notation.
  • showbase: Generates a prefix indicating the numeric base of generated integer output.
  • showpoint: Generates a decimal-point character unconditionally in generated floating-point output.
  • showpos: Generates a + sign in non-negative generated numeric output.
  • skipws: Skips leading white space before certain input operations.
  • unitbuf: Flushes output after each output operation.
  • uppercase: Replaces certain lowercase letters with their uppercase equivalents in generated output.

template<typename _CharT, typename _Traits> typedef _Ios_Openmode std::basic_ios< _CharT, _Traits >::openmode

This is a bitmask type. _Ios_Openmode is implementation-defined, but it is valid to perform bitwise operations on these values and expect the Right Thing to happen. Defined objects of type openmode are:

  • app: Output to the end of the stream.
  • ate: Seek to the end of the stream on opening.
  • binary: Stream is opened in binary mode.
  • in: Open for input. Default for ifstream and fstream.
  • out: Open for output. Default for ofstream and fstream.
  • trunc: Truncate an existing stream when opening. Default for ofstream.

Template class basic_ios, virtual base class for all stream classes.

Template Parameters

_CharT Type of character stream.

_Traits Traits for character type, defaults to char_traits<_CharT>.

Most of the member functions called dispatched on stream objects (e.g., std::cout.foo(bar);) are consolidated in this class.

يعيد

المخزن المؤقت السابق للتيار.

يربط مخزناً مؤقتاً جديداً بالتيار الحالي، ويمسح حالة الخطأ.

بسبب حوادث تاريخية رفض LWG تصحيحها، تعاني مكتبة الإدخال/الإخراج من خطأ تصميمي: هذه الوظيفة مخفية في الفئات المشتقة عن طريق تجاوزات rdbuf() التي لا تأخذ معلمات، وهي ليست افتراضية لأسباب تاريخية. نتيجة لذلك، يجب عليك استخدام مؤهلات صريحة للوصول إلى هذه الوظيفة عبر أي فئة مشتقة. على سبيل المثال:

std::fstream     foo;         // أو أي نوع مشتق آخر
std::streambuf*  p = .....;
foo.ios::rdbuf(p);            // ios == basic_ios<char>
