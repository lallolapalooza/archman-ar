أمثلة

بالنظر إلى إعدادات محلية للولايات المتحدة والقيم 123.45، و -123.45، و 3456.781، فقد ينتج عنها المخرجات التالية. يتم استخدام الأقواس المربعة ("[]") في هذا المثال لتحديد حدود المخرجات.

%n         [$123.45]         تنسيق افتراضي
           [-$123.45]
           [$3,456.78]
%11n       [    $123.45]     محاذاة لليمين ضمن حقل من 11 حرفًا
           [   -$123.45]
           [  $3,456.78]
%#5n       [ $   123.45]     أعمدة محاذاة للقيم حتى 99999
           [-$   123.45]
           [ $ 3,456.78]
%=*#5n     [ $***123.45]     تحديد حرف ملء
           [-$***123.45]
           [ $*3,456.78]
%=0#5n     [ $000123.45]     لا تستخدم أحرف الملء الفواصل للتجميع
           [-$000123.45]     حتى لو كان حرف الملء رقمًا
           [ $03,456.78]
%^#5n      [ $  123.45]      تعطيل فاصل التجميع
           [-$  123.45]
           [ $ 3456.78]
%^#5.0n    [ $  123]         تقريب إلى وحدات كاملة
           [-$  123]
           [ $ 3457]
%^#5.4n    [ $  123.4500]    زيادة الدقة
           [-$  123.4500]
           [ $ 3456.7810]
%(#5n      [ $   123.45 ]    استخدام نمط بديل للإيجاب والمطلق
           [($   123.45)]
           [ $ 3,456.78 ]
%!(#5n     [    123.45 ]     تعطيل رمز العملة
           [(   123.45)]
           [  3,456.78 ]
%-14#5.4n  [ $   123.4500 ]  محاذاة المخرجات إلى اليسار
           [-$   123.4500 ]
           [ $ 3,456.7810 ]
%14#5.4n   [  $   123.4500]  مخرجات محاذاة إلى اليمين المقابلة
           [ -$   123.4500]
           [  $ 3,456.7810]

انظر أيضًا قسم الأمثلة في fprintf().
