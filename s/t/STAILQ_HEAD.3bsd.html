  1. إزالة أي عنصر في القائمة بتعقيد زمني O(n).
  2. دمج قائمتين بتعقيد زمني O(n).

  3. يمكن دمجها.

  3. حجم الكود أكبر بنسبة 15% تقريبًا وتعمل العمليات أبطأ بنسبة 20% تقريبًا من القوائم المرتبطة أحادياً.

القوائم المرتبطة أحادياً

القائمة المرتبطة أحادياً يترأسها هيكل معرف بواسطة الماكرو SLIST_HEAD. يحتوي هذا الهيكل على مؤشر واحد للعنصر الأول في القائمة. ترتبط العناصر أحادياً لتقليل مساحة الذاكرة وأعباء معالجة المؤشرات إلى الحد الأدنى على حساب O(n) للإزالة للعناصر العشوائية. يمكن إضافة عناصر جديدة إلى القائمة بعد عنصر موجود أو في بداية القائمة. يتم تعريف هيكل SLIST_HEAD على النحو التالي:

SLIST_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم الهيكل الذي سيتم تعريفه، و TYPE هو نوع العناصر التي سيتم ربطها في القائمة. يمكن لاحقًا تعريف مؤشر إلى رأس القائمة على النحو التالي:

struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

الماكرو SLIST_HEAD_INITIALIZER تُقيم إلى مُهيئ للقائمة head.

الماكرو SLIST_CONCAT يدمج القائمة التي يترأسها head2 في نهاية القائمة التي يترأسها head1 ويزيل جميع العناصر من الأولى. يجب تجنب استخدام هذا الماكرو لأنه يجتاز القائمة head1

الماكرو SLIST_EMPTY يُقيم إلى صحيح إذا لم تكن هناك عناصر في القائمة.

الماكرو SLIST_ENTRY يُعرّف هيكلاً يربط العناصر في القائمة.

الماكرو SLIST_FIRST يُرجع العنصر الأول في القائمة أو NULL إذا كانت القائمة فارغة.

الماكرو SLIST_FOREACH يجتاز القائمة المشار إليها بـ head في الاتجاه الأمامي، ويُعيّن كل عنصر بدوره إلى var.

الماكرو SLIST_FOREACH_FROM يعمل بشكل مطابق لـ SLIST_FOREACH عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر SLIST تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في SLIST المشار إليه بـ head.

الماكرو SLIST_FOREACH_SAFE يجتاز القائمة المشار إليها بـ head في الاتجاه الأمامي، ويُعيّن كل عنصر بدوره إلى var. ومع ذلك، على عكس SLIST_FOREACH() هنا يُسمح بإزالة var وكذلك تحريره من داخل الحلقة بأمان دون التأثير على الاجتياز.

الماكرو SLIST_FOREACH_FROM_SAFE يعمل بشكل مطابق لـ SLIST_FOREACH_SAFE عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر SLIST تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في SLIST المشار إليه بـ head.

الماكرو SLIST_INIT يقوم بتهيئة القائمة المشار إليها بـ head.

الماكرو SLIST_INSERT_HEAD يُدرج العنصر الجديد elm في بداية القائمة.

الماكرو SLIST_INSERT_AFTER يُدرج العنصر الجديد elm بعد العنصر

SINGLY-LINKED LISTS

A singly-linked list is headed by a structure defined by the SLIST_HEAD macro. This structure contains a single pointer to the first element on the list. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the list after an existing element, or at the head of the list. A SLIST_HEAD structure is declared as follows:

SLIST_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the list. A pointer to the head of the list can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro SLIST_HEAD_INITIALIZER evaluates to an initializer for the list head.

The macro SLIST_CONCAT concatenates the list headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro SLIST_EMPTY evaluates to true if there are no elements in the list.

The macro SLIST_ENTRY declares a structure that connects the elements in the list.

The macro SLIST_FIRST returns the first element in the list or NULL if the list is empty.

The macro SLIST_FOREACH traverses the list referenced by head in the forward direction, assigning each element in turn to var.

The macro SLIST_FOREACH_SAFE traverses the list referenced by head in the forward direction, assigning each element in turn to var. However, unlike SLIST_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro SLIST_INIT initializes the list referenced by head.

The macro SLIST_INSERT_AFTER inserts the new element elm after the element listelm.

The macro SLIST_INSERT_HEAD inserts the new element elm at the head of the list.

The macro SLIST_NEXT returns the next element in the list.

The macro SLIST_REMOVE_AFTER removes the element after elm from the list. Unlike SLIST_REMOVE, this macro does not traverse the entire list.

The macro SLIST_REMOVE_HEAD removes the element elm from the head of the list. For optimum efficiency, elements being removed from the head of the list should explicitly use this macro instead of the generic SLIST_REMOVE macro.

The macro SLIST_REMOVE removes the element elm from the list. Use of this macro should be avoided as it traverses the entire list. A doubly-linked list should be used if this macro is needed in high-usage code paths or to operate on long lists.

The macro SLIST_SWAP swaps the contents of head1 and head2.

SINGLY-LINKED LIST EXAMPLE

SLIST_HEAD(slisthead, entry) head =
    SLIST_HEAD_INITIALIZER(head);
struct slisthead *headp;		/* Singly-linked List head. */
struct entry {
	...
	SLIST_ENTRY(entry) entries;	/* Singly-linked List. */
	...
} *n1, *n2, *n3, *np;

SLIST_INIT(&head);			/* Initialize the list. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
SLIST_INSERT_HEAD(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
SLIST_INSERT_AFTER(n1, n2, entries);

SLIST_REMOVE(&head, n2, entry, entries);/* Deletion. */
free(n2);

n3 = SLIST_FIRST(&head);
SLIST_REMOVE_HEAD(&head, entries);	/* Deletion from the head. */
free(n3);
					/* Forward traversal. */
SLIST_FOREACH(np, &head, entries)
	np-> ...
					/* Safe forward traversal. */
SLIST_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	SLIST_REMOVE(&head, np, entry, entries);
	free(np);
}

while (!SLIST_EMPTY(&head)) {		/* List Deletion. */
	n1 = SLIST_FIRST(&head);
	SLIST_REMOVE_HEAD(&head, entries);
	free(n1);
}

SINGLY-LINKED TAIL QUEUES

A singly-linked tail queue is headed by a structure defined by the STAILQ_HEAD macro. This structure contains a pair of pointers, one to the first element in the tail queue and the other to the last element in the tail queue. The elements are singly linked for minimum space and pointer manipulation overhead at the expense of O(n) removal for arbitrary elements. New elements can be added to the tail queue after an existing element, at the head of the tail queue, or at the end of the tail queue. A STAILQ_HEAD structure is declared as follows:

STAILQ_HEAD(HEADNAME, TYPE) head;

where HEADNAME is the name of the structure to be defined, and TYPE is the type of the elements to be linked into the tail queue. A pointer to the head of the tail queue can later be declared as:

struct HEADNAME *headp;

(The names head and headp are user selectable.)

The macro STAILQ_HEAD_INITIALIZER evaluates to an initializer for the tail queue head.

The macro STAILQ_CONCAT concatenates the tail queue headed by head2 onto the end of the one headed by head1 removing all entries from the former.

The macro STAILQ_EMPTY evaluates to true if there are no items on the tail queue.

The macro STAILQ_ENTRY declares a structure that connects the elements in the tail queue.

The macro STAILQ_FIRST returns the first item on the tail queue or NULL if the tail queue is empty.

The macro STAILQ_FOREACH traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var.

The macro STAILQ_FOREACH_FROM behaves identically to STAILQ_FOREACH when var is NULL, else it treats var as a previously found STAILQ element and begins the loop at var instead of the first element in the STAILQ referenced by head.

The macro STAILQ_FOREACH_SAFE traverses the tail queue referenced by head in the forward direction, assigning each element in turn to var. However, unlike STAILQ_FOREACH() here it is permitted to both remove var as well as free it from within the loop safely without interfering with the traversal.

The macro STAILQ_FOREACH_FROM_SAFE behaves identically to STAILQ_FOREACH_SAFE when var is NULL, else it treats var as a previously found STAILQ element and begins the loop at var instead of the first element in the STAILQ referenced by head.

The macro STAILQ_INIT initializes the tail queue referenced by head.

The macro STAILQ_INSERT_HEAD inserts the new element elm at the head of the tail queue.

The macro STAILQ_INSERT_TAIL inserts the new element elm at the end of the tail queue.

The macro STAILQ_INSERT_AFTER inserts the new element elm after the element listelm.

The macro STAILQ_LAST returns the last item on the tail queue. If the tail queue is empty the return value is NULL.

The macro STAILQ_NEXT returns the next item on the tail queue, or NULL this item is the last.

The macro STAILQ_REMOVE_AFTER removes the element after elm from the tail queue. Unlike STAILQ_REMOVE, this macro does not traverse the entire tail queue.

The macro STAILQ_REMOVE_HEAD removes the element at the head of the tail queue. For optimum efficiency, elements being removed from the head of the tail queue should use this macro explicitly rather than the generic STAILQ_REMOVE macro.

The macro STAILQ_REMOVE removes the element elm from the tail queue. Use of this macro should be avoided as it traverses the entire list. A doubly-linked tail queue should be used if this macro is needed in high-usage code paths or to operate on long tail queues.

The macro STAILQ_SWAP swaps the contents of head1 and head2.

SINGLY-LINKED TAIL QUEUE EXAMPLE

STAILQ_HEAD(stailhead, entry) head =
    STAILQ_HEAD_INITIALIZER(head);
struct stailhead *headp;		/* Singly-linked tail queue head. */
struct entry {
	...
	STAILQ_ENTRY(entry) entries;	/* Tail queue. */
	...
} *n1, *n2, *n3, *np;

STAILQ_INIT(&head);			/* Initialize the queue. */

n1 = malloc(sizeof(struct entry));	/* Insert at the head. */
STAILQ_INSERT_HEAD(&head, n1, entries);

n1 = malloc(sizeof(struct entry));	/* Insert at the tail. */
STAILQ_INSERT_TAIL(&head, n1, entries);

n2 = malloc(sizeof(struct entry));	/* Insert after. */
STAILQ_INSERT_AFTER(&head, n1, n2, entries);
					/* Deletion. */
STAILQ_REMOVE(&head, n2, entry, entries);
free(n2);
					/* Deletion from the head. */
n3 = STAILQ_FIRST(&head);
STAILQ_REMOVE_HEAD(&head, entries);
free(n3);
					/* Forward traversal. */
STAILQ_FOREACH(np, &head, entries)
	np-> ...
					/* Safe forward traversal. */
STAILQ_FOREACH_SAFE(np, &head, entries, np_temp) {
	np->do_stuff();
	...
	STAILQ_REMOVE(&head, np, entry, entries);
	free(np);
}
					/* TailQ Deletion. */
while (!STAILQ_EMPTY(&head)) {
	n1 = STAILQ_FIRST(&head);
	STAILQ_REMOVE_HEAD(&head, entries);
	free(n1);
}
					/* Faster TailQ Deletion. */
n1 = STAILQ_FIRST(&head);
while (n1 != NULL) {
	n2 = STAILQ_NEXT(n1, entries);
	free(n1);
	n1 = n2;
}
STAILQ_INIT(&head);

STAILQ_HEAD, STAILQ_INIT, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_INSERT_BEFORE, STAILQ_INSERT_AFTER, STAILQ_REMOVE_HEAD, STAILQ_REMOVE_TAIL, STAILQ_REMOVE, STAILQ_MOVE_HEAD, STAILQ_MOVE_TAIL, STAILQ_MOVE_UP, STAILQ_MOVE_DOWN, STAILQ_NEXT, STAILQ_PREV, STAILQ_FIRST, STAILQ_LAST, STAILQ_EMPTY, STAILQ_CONCAT, STAILQ_SWAP — singly linked tail queues

LIBRARY

libbsd(3)

SYNOPSIS

#include <sys/queue.h>

Singly linked tail queue definitions:

struct type {
    ...
    struct type *field_next;
    ...
};
typedef struct type typename;

struct stailq_head {
    struct type *stqh_first;
    struct type **stqh_last;
};

#define STAILQ_HEAD(name, type)           \
    struct name {                     \
        struct type *stqh_first; \
        struct type **stqh_last;  \
    }

#define STAILQ_INIT(head)                 \
    do {                                    \
        *(head)-stqh_first = NULL;        \
        *(head)-stqh_last = &(head)-stqh_first; \
    } while (0)

#define STAILQ_INSERT_HEAD(head, elm, field) \
    do {                                    \
        *(elm)-field_next = *(head)-stqh_first; \
        if (*(head)-stqh_last == &(head)-stqh_first) \
            *(head)-stqh_last = &(elm)-field_next; \
        *(head)-stqh_first = (elm);          \
    } while (0)

#define STAILQ_INSERT_TAIL(head, elm, field) \
    do {                                    \
        *(elm)-field_next = NULL;          \
        *(*(head)-stqh_last) = (elm);        \
        *(head)-stqh_last = &(elm)-field_next; \
    } while (0)

#define STAILQ_INSERT_BEFORE(listelm, head, elm, field) \
    do {                                    \
        if ((elm)-field_next = (listelm)-field_next, \
            (listelm)-field_next = (elm), \
            (head)-stqh_first == (listelm)) \
            *(head)-stqh_first = (elm); \
    } while (0)

#define STAILQ_INSERT_AFTER(listelm, head, elm, field) \
    do {                                    \
        *(elm)-field_next = (listelm)-field_next; \
        if (*(head)-stqh_last == &(listelm)-field_next) \
            *(head)-stqh_last = &(elm)-field_next; \
        (listelm)-field_next = (elm);       \
    } while (0)

#define STAILQ_REMOVE_HEAD(head, field) \
    do {                                    \
        struct type *n = *(head)-stqh_first; \
        *(head)-stqh_first = n-field_next; \
        if (*(head)-stqh_first == NULL) \
            *(head)-stqh_last = &(head)-stqh_first; \
        /* XXX: THIS IS DANGEROUS IF n IS NOT REMOVED ELSEWHERE */ \
        /* THIS IS DANGEROUS IF n IS NOT REMOVED ELSEWHERE */ \
    } while (0)

#define STAILQ_REMOVE_TAIL(head, field) \
    do {                                    \
        struct type *n; \
        if (*(head)-stqh_first) { \
            n = *(head)-stqh_first; \
            if (n->field_next == NULL) \
                *(head)-stqh_first = NULL; \
            else { \
                while (n->field_next->field_next) \
                    n = n->field_next; \
                *(head)-stqh_last = &(n)-field_next; \
                n->field_next = NULL; \
            } \
        } \
    } while (0)

#define STAILQ_REMOVE(head, elm, type, field) \
    do {                                    \
        struct type *n = (elm); \
        if (*(head)-stqh_first == n) \
            STAILQ_REMOVE_HEAD((head), field); \
        else {                              \
            struct type *p = *(head)-stqh_first; \
            while (p->field_next != n) \
                p = p->field_next; \
            *(head)-stqh_last = &(p)-field_next; \
            p->field_next = n->field_next; \
        }                                   \
        /* XXX: THIS IS DANGEROUS IF n IS NOT REMOVED ELSEWHERE */ \
        /* THIS IS DANGEROUS IF n IS NOT REMOVED ELSEWHERE */ \
    } while (0)

#define STAILQ_MOVE_HEAD(head, nhead) \
    do {                                \
        *(head)-stqh_first = *(nhead)-stqh_first; \
        *(head)-stqh_last = *(nhead)-stqh_last; \
        STAILQ_INIT((nhead));           \
    } while (0)

#define STAILQ_MOVE_TAIL(head, nhead) \
    do {                                \
        *(head)-stqh_first = *(nhead)-stqh_first; \
        *(head)-stqh_last = *(nhead)-stqh_last; \
        STAILQ_INIT((nhead));           \
    } while (0)

#define STAILQ_MOVE_UP(head, elm, field) \
    do {                                \
        struct type *p = *(head)-stqh_first; \
        struct type *e = (elm); \
        if (p == e) { \
            if (e->field_next) { \
                *(head)-stqh_first = e->field_next; \
                e->field_next = (*(head)-stqh_first)->field_next; \
                (*(head)-stqh_first)->field_next = e; \
            } \
        } else { \
            while (p && p->field_next != e) \
                p = p->field_next; \
            if (p && p->field_next) { \
                *(head)-stqh_first = e->field_next; \
                e->field_next = (*(head)-stqh_first)->field_next; \
                (*(head)-stqh_first)->field_next = e; \
                p->field_next = *(head)-stqh_first; \
            } \
        } \
    } while (0)

#define STAILQ_MOVE_DOWN(head, elm, field) \
    do {                                \
        struct type *p = *(head)-stqh_first; \
        struct type *e = (elm); \
        if (e && e->field_next) { \
            if (p == e) { \
                *(head)-stqh_first = e->field_next; \
                e->field_next = (*(head)-stqh_first)->field_next; \
                (*(head)-stqh_first)->field_next = e; \
            } else { \
                while (p && p->field_next != e) \
                    p = p->field_next; \
                if (p && p->field_next) { \
                    p->field_next = e->field_next; \
                    e->field_next = p; \
                } \
            } \
        } \
    } while (0)

#define STAILQ_NEXT(elm, field) ((elm)-field_next)

#define STAILQ_PREV(elm, type, field) \
    (( struct type * ) \
    ((char *) (elm) - __offsetof( struct type, field##_next ) )

#define STAILQ_FIRST(head) ((head)-stqh_first)

#define STAILQ_LAST(head, type, field) \
    (( struct type * ) \
    (( char * ) (head)-stqh_last - __offsetof( struct type, field##_next ) )

#define STAILQ_EMPTY(head) ((head)-stqh_first == NULL)

#define STAILQ_CONCAT(head1, head2, field) \
    do {                                    \
        if (!STAILQ_EMPTY(head2)) {            \
            *(head1)-stqh_last = *(head2)-stqh_last; \
            *(head2)-stqh_first->field_next = *(head1)-stqh_first;\
            *(head1)-stqh_first = (head2)-stqh_first; \
            STAILQ_INIT((head2));           \
        }                                   \
    } while (0)

#define STAILQ_SWAP(head1, head2, type) \
    do {                                \
        struct stailq_head tmp = *(head1); \
        *(head1) = *(head2);            \
        *(head2) = tmp;               \
        if (*(head1)-stqh_first) { \
            if (*(head1)-stqh_first == *(head2)-stqh_last) \
                *(head1)-stqh_last = &(head1)-stqh_first; \
        } \
        if (*(head2)-stqh_first) { \
            if (*(head2)-stqh_first == *(head1)-stqh_last) \
                *(head2)-stqh_last = &(head2)-stqh_first; \
        } \
    } while (0)

DESCRIPTION

Singly linked tail queues are doubly linked lists with a difference. The difference is that the queue is only singly linked in the forward direction. This means that it is possible to iterate through the list in the forward direction, but not in the backward direction. The STAILQ_HEAD macro declares a tail queue head. The STAILQ_INIT macro initializes an empty queue. The STAILQ_INSERT_HEAD and STAILQ_INSERT_TAIL macros insert an element at the head and tail of the queue, respectively. The STAILQ_INSERT_BEFORE and STAILQ_INSERT_AFTER macros insert an element before and after the specified element, respectively. The STAILQ_REMOVE_HEAD and STAILQ_REMOVE_TAIL macros remove the head and tail elements from the queue, respectively. The STAILQ_REMOVE macro removes the specified element from the queue. The STAILQ_MOVE_HEAD and STAILQ_MOVE_TAIL macros move the entire contents of one queue to the head or tail of another. The STAILQ_MOVE_UP and STAILQ_MOVE_DOWN macros move an element within a queue. The STAILQ_NEXT macro returns the next element in the queue. The STAILQ_PREV macro returns the previous element in the queue. The STAILQ_FIRST macro returns the first element in the queue. The STAILQ_LAST macro returns the last element in the queue. The STAILQ_EMPTY macro returns true if the queue is empty. The STAILQ_CONCAT macro concatenates two queues. The STAILQ_SWAP macro swaps the contents of two queues.

SINGLY-LINKED LISTS

The macros described in this manual page are implemented using singly linked lists. A singly linked list is a data structure that consists of a sequence of nodes, where each node contains a pointer to the next node in the sequence. The last node in the list points to NULL. Singly linked lists can be used to implement queues, stacks, and other data structures.

The STAILQ_HEAD macro declares a singly linked tail queue head. The STAILQ_INIT macro initializes an empty queue. The STAILQ_INSERT_HEAD and STAILQ_INSERT_TAIL macros insert an element at the head and tail of the queue, respectively. The STAILQ_REMOVE_HEAD and STAILQ_REMOVE_TAIL macros remove the head and tail elements from the queue, respectively. The STAILQ_REMOVE macro removes the specified element from the queue. The STAILQ_NEXT macro returns the next element in the queue. The STAILQ_FIRST macro returns the first element in the queue. The STAILQ_LAST macro returns the last element in the queue. The STAILQ_EMPTY macro returns true if the queue is empty.

SINGLY-LINKED LIST EXAMPLE

struct node {
    int data;
    struct node *next;
};

struct node *head = NULL;
struct node *n1, *n2;

n1 = malloc(sizeof(struct node));
n1->data = 10;
n1->next = NULL;
STAILQ_INSERT_HEAD(&head, n1, next);

n2 = malloc(sizeof(struct node));
n2->data = 20;
n2->next = NULL;
STAILQ_INSERT_TAIL(&head, n2, next);

n1 = STAILQ_FIRST(&head);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 10 20 */

STAILQ_REMOVE_HEAD(&head, next);
free(n1);
n1 = STAILQ_FIRST(&head);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 20 */

STAILQ_INIT(&head);

SINGLY-LINKED TAIL QUEUES

Singly linked tail queues are a variation of singly linked lists. They are implemented using a head structure that contains a pointer to the first element and a pointer to the last element. This allows for efficient insertion and deletion at both the head and tail of the queue. The macros described in this manual page can be used to manipulate singly linked tail queues.

SINGLY-LINKED TAIL QUEUE EXAMPLE

struct node {
    int data;
    struct node *next;
};

struct stailq_head myqueue;
struct node *n1, *n2;

STAILQ_INIT(&myqueue);

n1 = malloc(sizeof(struct node));
n1->data = 10;
n1->next = NULL;
STAILQ_INSERT_HEAD(&myqueue, n1, next);

n2 = malloc(sizeof(struct node));
n2->data = 20;
n2->next = NULL;
STAILQ_INSERT_TAIL(&myqueue, n2, next);

n1 = STAILQ_FIRST(&myqueue);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 10 20 */

n1 = STAILQ_LAST(&myqueue, node, next);
printf("last: %d\n", n1->data);
/* Output: last: 20 */

STAILQ_REMOVE_HEAD(&myqueue, next);
free(n1);
n1 = STAILQ_FIRST(&myqueue);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 20 */

STAILQ_REMOVE_TAIL(&myqueue, next);
free(n1);
STAILQ_INIT(&myqueue);

DIAGNOSTICS

When debugging queue(3), it can be useful to trace queue changes. To enable tracing, define the macro QUEUE_MACRO_DEBUG_TRACE at compile time.

It can also be useful to trash pointers that have been unlinked from a queue, to detect use after removal. To enable pointer trashing, define the macro QUEUE_MACRO_DEBUG_TRASH at compile time. The macro QMD_IS_TRASHED(void *ptr) returns true if ptr has been trashed by the QUEUE_MACRO_DEBUG_TRASH option.

قوائم الذيل المرتبطة أحادياً هي اختلاف عن القوائم المرتبطة أحادياً. يتم تنفيذها باستخدام بنية رأس تحتوي على مؤشر إلى العنصر الأول ومؤشر إلى العنصر الأخير. هذا يسمح بالإدراج والحذف بكفاءة في كل من رأس وذيل القائمة. يمكن استخدام وحدات الماكرو الموصوفة في صفحة الدليل هذه لمعالجة قوائم الذيل المرتبطة أحادياً.

القوائم المرتبطة أحادياً

وحدات الماكرو الموصوفة في صفحة الدليل هذه منفذة باستخدام قوائم مرتبطة أحادياً. القائمة المرتبطة أحادياً هي بنية بيانات تتكون من تسلسل من العقد، حيث تحتوي كل عقدة على مؤشر إلى العقدة التالية في التسلسل. تشير العقدة الأخيرة في القائمة إلى NULL. يمكن استخدام القوائم المرتبطة أحادياً لتنفيذ قوائم الانتظار، والمكدسات، وهياكل البيانات الأخرى.

يعرّف الماكرو STAILQ_HEAD رأس قائمة ذيل مرتبطة أحادياً. يقوم الماكرو STAILQ_INIT بتهيئة قائمة فارغة. تقوم وحدات الماكرو STAILQ_INSERT_HEAD و STAILQ_INSERT_TAIL بإدراج عنصر في رأس وذيل القائمة، على التوالي. تقوم وحدات الماكرو STAILQ_REMOVE_HEAD و STAILQ_REMOVE_TAIL بإزالة عناصر الرأس والذيل من القائمة، على التوالي. يقوم الماكرو STAILQ_REMOVE بإزالة العنصر المحدد من القائمة. يقوم الماكرو STAILQ_NEXT بإرجاع العنصر التالي في القائمة. يقوم الماكرو STAILQ_FIRST بإرجاع العنصر الأول في القائمة. يقوم الماكرو STAILQ_LAST بإرجاع العنصر الأخير في القائمة. يقوم الماكرو STAILQ_EMPTY بإرجاع صحيح إذا كانت القائمة فارغة.

مثال على قائمة مرتبطة أحادياً

struct node {
    int data;
    struct node *next;
};

struct node *head = NULL;
struct node *n1, *n2;

n1 = malloc(sizeof(struct node));
n1->data = 10;
n1->next = NULL;
STAILQ_INSERT_HEAD(&head, n1, next);

n2 = malloc(sizeof(struct node));
n2->data = 20;
n2->next = NULL;
STAILQ_INSERT_TAIL(&head, n2, next);

n1 = STAILQ_FIRST(&head);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 10 20 */

STAILQ_REMOVE_HEAD(&head, next);
free(n1);
n1 = STAILQ_FIRST(&head);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 20 */

STAILQ_INIT(&head);

قوائم الذيل المرتبطة أحادياً

قوائم الذيل المرتبطة أحادياً هي تنويع للقوائم المرتبطة أحادياً. يتم تنفيذها باستخدام بنية رأس تحتوي على مؤشر إلى العنصر الأول ومؤشر إلى العنصر الأخير. هذا يسمح بالإدراج والحذف بكفاءة في كل من رأس وذيل القائمة. يمكن استخدام وحدات الماكرو الموصوفة في صفحة الدليل هذه لمعالجة قوائم الذيل المرتبطة أحادياً.

مثال على قائمة ذيل مرتبطة أحادياً

struct node {
    int data;
    struct node *next;
};

struct stailq_head myqueue;
struct node *n1, *n2;

STAILQ_INIT(&myqueue);

n1 = malloc(sizeof(struct node));
n1->data = 10;
n1->next = NULL;
STAILQ_INSERT_HEAD(&myqueue, n1, next);

n2 = malloc(sizeof(struct node));
n2->data = 20;
n2->next = NULL;
STAILQ_INSERT_TAIL(&myqueue, n2, next);

n1 = STAILQ_FIRST(&myqueue);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 10 20 */

n1 = STAILQ_LAST(&myqueue, node, next);
printf("last: %d\n", n1->data);
/* Output: last: 20 */

STAILQ_REMOVE_HEAD(&myqueue, next);
free(n1);
n1 = STAILQ_FIRST(&myqueue);
while (n1) {
    printf("%d ", n1->data);
    n1 = STAILQ_NEXT(n1, next);
}
/* Output: 20 */

STAILQ_REMOVE_TAIL(&myqueue, next);
free(n1);
STAILQ_INIT(&myqueue);

التشخيص

عند تصحيح أخطاء queue(3)، قد يكون من المفيد تتبع تغييرات القائمة. لتمكين التتبع، قم بتعريف الماكرو QUEUE_MACRO_DEBUG_TRACE في وقت الترجمة.

قد يكون من المفيد أيضاً إتلاف المؤشرات التي تم فصلها عن قائمة، لاكتشاف الاستخدام بعد الإزالة. لتمكين إتلاف المؤشرات، قم بتعريف الماكرو QUEUE_MACRO_DEBUG_TRASH في وقت الترجمة. الماكرو QMD_IS_TRASHED(void *ptr) يعيد صحيحاً إذا تم إتلاف ptr بواسطة خيار QUEUE_MACRO_DEBUG_TRASH.
