val div : int32 -> int32 -> int32

قسمة الأعداد الصحيحة. هذه القسمة تقرب حاصل القسمة الحقيقي لمعاملاتها نحو الصفر، كما هو محدد لـ (/).

val unsigned_div : int32 -> int32 -> int32

val rem : int32 -> int32 -> int32

باقي القسمة للأعداد الصحيحة. إذا لم يكن y صفرًا، فإن نتيجة Int32.rem x y تحقق الخاصية التالية: x = Int32.add (Int32.mul (Int32.div x y) y) (Int32.rem x y). إذا كان y = 0، فإن Int32.rem x y يطلق استثناء Division_by_zero.

val unsigned_rem : int32 -> int32 -> int32

نفس Int32.rem ، باستثناء أن المعاملات والنتائج تُفسر كأعداد صحيحة غير موقعة ذات 32 بت.

val shift_left : int32 -> int -> int32

Int32.shift_left x y يُزيح x إلى اليسار بمقدار y بت. النتيجة غير محددة إذا كان y < 0 أو y >= 32.

val shift_right : int32 -> int -> int32

Int32.shift_right x y يُزيح x إلى اليمين بمقدار y بت. هذه إزاحة حسابية: يتم تكرار بت الإشارة لـ x وإدراجه في البتات الشاغرة. النتيجة غير محددة إذا كان y < 0 أو y >= 32.

val shift_right_logical : int32 -> int -> int32

Int32.shift_right_logical x y يُزيح x إلى اليمين بمقدار y بت. هذه إزاحة منطقية: يتم إدراج أصفار في البتات الشاغرة بغض النظر عن إشارة x. النتيجة غير محددة إذا كان y < 0 أو y >= 32.

val of_int : int -> int32

تحويل العدد الصحيح المعطى (النوع int) إلى عدد صحيح ذو 32 بت (النوع int32). على المنصات ذات 64 بت، يتم أخذ المعامل بتردد 2^32.

val to_int : int32 -> int

تحويل العدد الصحيح ذي 32 بت المعطى (النوع int32) إلى عدد صحيح (النوع int). على المنصات ذات 32 بت، يتم أخذ العدد الصحيح ذي 32 بت بتردد 2^31، أي يتم فقدان البت الأعلى أثناء التحويل. على المنصات ذات 64 بت، يكون التحويل دقيقًا.

val unsigned_to_int : int32 -> int option

نفس Int32.to_int ، ولكن يفسر المعامل كعدد صحيح غير موقع. يُرجع None إذا لم يكن للقيمة غير الموقعة للمعامل مكان في int.

منذ 4.08

val of_float : float -> int32

تحويل الرقم العائم المعطى إلى عدد صحيح ذي 32 بت، مع تجاهل الجزء الكسري (الاقتطاع نحو الصفر). إذا كان الرقم العائم المقتطع خارج النطاق [ Int32.min_int ، Int32.max_int ]، فلا يتم إطلاق استثناء، ويتم إرجاع عدد صحيح غير محدد ويعتمد على النظام.

val to_float : int32 -> float

تحويل العدد الصحيح ذي 32 بت المعطى إلى رقم عائم.

val of_string : string -> int32

تحويل السلسلة النصية المعطاة إلى عدد صحيح ذي 32 بت. تُقرأ السلسلة النصية بالنظام العشري (افتراضيًا، أو إذا بدأت السلسلة بـ 0u) أو بالنظام الست عشري، الثماني، أو الثنائي إذا بدأت السلسلة بـ 0x ، 0o أو 0b على التوالي.

البادئة 0u تقرأ المدخلات كعدد صحيح غير موقع في النطاق [0, 2*Int32.max_int+1]. إذا تجاوز المدخل Int32.max_int، يتم تحويله إلى العدد الصحيح الموقع Int32.min_int + input - Int32.max_int - 1.

يمكن أن تظهر الأحرف _ (شرطة سفلية) في أي مكان في السلسلة النصية ويتم تجاهلها.

يُطلق استثناء Failure إذا كانت السلسلة النصية المعطاة تمثيلًا غير صالح لعدد صحيح، أو إذا تجاوز العدد الصحيح الممثل نطاق الأعداد الصحيحة القابلة للتمثيل في النوع int32.

val of_string_opt : string -> int32 option
