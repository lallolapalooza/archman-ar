المستخرجات
جميع دوال operator>> (المعروفة أيضًا باسم دوال الإدخال المهيأة) لها بعض السلوك المشترك. يبدأ كل منها بإنشاء كائن مؤقت من نوع std::basic_istream::sentry مع تعيين الوسيط الثاني (noskipws) إلى false. هذا له عدة تأثيرات، تنتهي بتعيين علامة حالة؛ انظر وثائق sentry لمزيد من التفاصيل.

    Detailed Description

    iostream class to handle character streams.

    This class inherits from std::basic_istream and std::basic_ostream. Therefore, it has all the capabilities of both.

    The stream buffer associated with a basic_iostream object is the same as the stream buffer associated with the underlying stream buffer of the inherited input and output stream classes.
