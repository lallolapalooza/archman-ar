يعيد

هذا المكرر، لعمليات متسلسلة.

هذا النوع من المكررات يحافظ على موضعه الخاص في الحاوية. تعيين قيمة للمكرر سيقوم بإدراج القيمة في الحاوية في المكان الذي يسبق المكرر.

يتم الحفاظ على الموضع بحيث تدرج القيم المتتالية واحدة تلو الأخرى مباشرة. على سبيل المثال،

// المتجه v يحتوي على A و Z
insert_iterator i (v, ++v.begin());
i = 1;
i = 2;
i = 3;
// المتجه v يحتوي على A، 1، 2، 3، و Z

الوصف

std::insert_iterator هو مُكرِّر مُلائم (adaptor iterator) يسمح بالإدراج في حاوية. إنه مُخصص للاستخدام مع الحاويات التي تدعم الإدراج (مثل std::vector, std::list, std::set, std::map, إلخ). عند تعيين قيمة إلى insert_iterator، يتم إدراج القيمة في الحاوية الأساسية.

الصيغة

template<class Container>
class insert_iterator {
public:
    using iterator_category = output_iterator_tag;
    using value_type = void;
    using difference_type = void;
    using pointer = void;
    using reference = void;

    insert_iterator(Container& c, typename Container::iterator iter);
    insert_iterator& operator=(const typename Container::value_type& value);
    insert_iterator& operator*();
    insert_iterator& operator++();
    insert_iterator operator++(int);
};

الترويسة

ضمن الملف <iterator>

النطاق

std

المعاملات

  • c: الحاوية التي سيتم الإدراج فيها.
  • iter: مُكرِّر يشير إلى الموضع الذي سيتم فيه الإدراج.

القيمة المُعادة

  • operator=: تُعيد مرجعًا إلى *this.
  • operator*: تُعيد مرجعًا إلى *this.
  • operator++: تُعيد مرجعًا إلى *this.

الاستثناءات

لا تُصدر استثناءات افتراضيًا، ولكن قد تُصدر دوال الإدراج في الحاوية استثناءات.

التعقيد

يعتمد التعقيد على عملية الإدراج في الحاوية الأساسية.

مثال

#include <iostream>
#include <vector>
#include <iterator>
#include <algorithm>

int main() {
    std::vector<int> vec = {1, 2, 3, 4, 5};
    std::vector<int> source = {10, 20, 30};

    // إنشاء مُكرِّر إدراج للإدراج بعد العنصر الثاني (الفهرس 2)
    auto it = std::insert_iterator(vec, vec.begin() + 2);

    // نسخ العناصر من source إلى vec باستخدام مُكرِّر الإدراج
    std::copy(source.begin(), source.end(), it);

    std::cout << "Vector after insertion: ";
    for (int x : vec) {
        std::cout << x << " ";
    }
    std::cout << std::endl;

    return 0;
}

النتيجة:

Vector after insertion: 1 2 10 20 30 3 4 5

ملاحظات

  • insert_iterator هو مُكرِّر من الفئة output_iterator_tag، مما يعني أنه لا يدعم عمليات الوصول العشوائي أو القراءة.
  • الموضع المحدد عند إنشاء insert_iterator هو المكان الذي سيتم فيه الإدراج.

توثيق المُنشئ والمُدمِّر

insert_iterator(Container& c, typename Container::iterator iter); المُنشئ: يقوم بإنشاء مُكرِّر إدراج جديد للحاوية c، مع تحديد موضع الإدراج بواسطة iter.

توثيق دوال الأعضاء

  • insert_iterator& operator=(const typename Container::value_type& value); يقوم بإدراج value في الحاوية الأساسية عند الموضع المحدد.
  • insert_iterator& operator*(); لا تفعل شيئًا فعليًا، تُعيد مرجعًا إلى *this.
  • insert_iterator& operator++(); لا تفعل شيئًا فعليًا، تُعيد مرجعًا إلى *this.
  • insert_iterator operator++(int); لا تفعل شيئًا فعليًا، تُعيد نسخة من *this قبل الزيادة.
