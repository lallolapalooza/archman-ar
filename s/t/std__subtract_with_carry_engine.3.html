NAME

std::subtract_with_carry_engine, std::subtract_with_carry_engine - A subtract with carry random number generator engine

SYNOPSIS

#include <random>

template<typename _UIntType, size_t __w, size_t __s, size_t __r>
class std::subtract_with_carry_engine

Detailed Description

The % subtract_with_carry_engine random number generator engine is an implementation of the subtract with carry algorithm described in.

The state of the engine consists of:

  • A sequence $x_{-r}, \ldots, x_{-1}$ of $r$ unsigned integers of type _UIntType.

  • A single unsigned integer _UIntType representing the carry.

When the engine is called as a function using operator(), the next value in the sequence is computed as follows: 

       v = x_0 - x_q - c;
       q = (q + 1) % s;
       c = (v >> (w - 1));
       x_q = v;
       return x_q;

Here $q$ is the index of the most recently generated value, and $c$ is the carry. The parameters _w, __s, and __r are template parameters for the engine, and _UIntType is the underlying unsigned integer type.

The valid ranges for the template parameters are:

  • _w is the number of bits in the result.

  • __s is the number of states, $r+1 \le s \le 175$.

  • __r is the lag, $1 \le r < s$.

N1871[4.19] defines the default parameters for subtract_with_carry_engine as: _UIntType = uint_fast32_t, __w = 24, __s = 10, __r = 24.

Seeds the initial state $x_0$ of the random number generator. N1688[4.19] modifies this as follows. If __value == 0, sets value to 19780503. In any case, with a linear congruential generator lcg(i) having parameters $ m_{lcg} = 2147483563, a_{lcg} = 40014, c_{lcg} = 0, and lcg(0) = value $, sets $ x_{-r} ots x_{-1} $ to $ lcg(1) ots lcg(r) $ respectively. If $ x_{-1} = 0 $ set carry to 1, otherwise sets carry to 0.
