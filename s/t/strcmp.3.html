strcmp(3) دليل وظائف المكتبة strcmp(3)

الاسم

strcmp, strncmp - مقارنة سلسلتين نصيتين

المكتبة

مكتبة C القياسية (libc, -lc)

الاختصار

#include <string.h>
int strcmp(const char *s1, const char *s2);
int strncmp(size_t n;
            const char s1[n], const char s2[n], size_t n);

الوصف

تقوم الدالة strcmp() بمقارنة السلسلتين النصيتين s1 و s2. لا يتم أخذ اللغة في الاعتبار (للمقارنة التي تأخذ اللغة في الاعتبار، انظر strcoll(3)). تتم المقارنة باستخدام أحرف غير موقعة.

تعيد strcmp() عددًا صحيحًا يشير إلى نتيجة المقارنة، على النحو التالي:

•
0، إذا كانت s1 و s2 متساويتين؛
•
قيمة سالبة إذا كانت s1 أقل من s2؛
•
قيمة موجبة إذا كانت s1 أكبر من s2.

الدالة strncmp() مشابهة، باستثناء أنها تقارن فقط أول n بايت (على الأكثر) من s1 و s2.

قيمة الإرجاع

تعيد الدالتان strcmp() و strncmp() عددًا صحيحًا أقل من، مساويًا لـ، أو أكبر من صفر إذا تم العثور على s1 (أو أول n بايت منها)، على التوالي، أقل من، مطابقًا لـ، أو أكبر من s2.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
strcmp (), strncmp () أمان الخيط MT-Safe

الإصدارات

تحدد POSIX.1 فقط ما يلي:

يجب تحديد إشارة قيمة الإرجاع غير الصفرية بواسطة إشارة الفرق بين قيم أول زوج من البايتات (كلاهما مفسر كنوع unsigned char) التي تختلف في السلاسل النصية التي تتم مقارنتها.

في glibc، كما هو الحال في معظم التطبيقات الأخرى، تكون قيمة الإرجاع هي النتيجة الحسابية لطرح آخر بايت تم مقارنته في s2 من آخر بايت تم مقارنته في s1. (إذا كان الحرفان متساويين، يكون هذا الفرق 0.)

المعايير

C11, POSIX.1-2008.

التاريخ

POSIX.1-2001, C89, SVr4, 4.3BSD.

أمثلة

يمكن استخدام البرنامج التالي لتوضيح عملية strcmp() (عند إعطائها وسيطين) و strncmp() (عند إعطائها ثلاثة وسائط). أولاً، بعض الأمثلة باستخدام strcmp():


$ ./string_comp ABC ABC;
<str1> و <str2> متساويتان
$ ./string_comp ABC AB;      # 'C' هو ASCII 67؛ 'C' - '\0' = 67
<str1> أكبر من <str2> (67)
$ ./string_comp ABA ABZ;     # 'A' هو ASCII 65؛ 'Z' هو ASCII 90
<str1> أقل من <str2> (-25)
$ ./string_comp ABJ ABC;
<str1> أكبر من <str2> (7)
$ ./string_comp $'\201' A;   # 0201 - 0101 = 0100 (أو 64 عشري)
<str1> أكبر من <str2> (64)

يستخدم المثال الأخير صيغة bash-specific (bash(1)) لإنشاء سلسلة نصية تحتوي على رمز ASCII بـ 8 بت؛ توضح النتيجة أن مقارنة السلسلة النصية تستخدم أحرفًا غير موقعة.

ثم بعض الأمثلة باستخدام strncmp():


$ ./string_comp ABC AB 3;
<str1> أكبر من <str2> (67)
$ ./string_comp ABC AB 2;
<str1> و <str2> متساويتان في أول 2 بايت

مصدر البرنامج

/* string_comp.c
   مرخص بموجب رخصة جنو العمومية العامة الإصدار 2 أو أحدث.
*/
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
int
main(int argc, char *argv[])
{
    int res;
    if (argc < 3) {
        fprintf(stderr, "Usage: %s <str1> <str2> [<n>]\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (argc == 3)
        res = strcmp(argv[1], argv[2]);
    else
        res = strncmp(argv[1], argv[2], atoi(argv[3]));
    if (res == 0) {
        printf("<str1> و <str2> متساويتان");
        if (argc > 3)
            printf(" في أول %d بايت\n", atoi(argv[3]));
        printf("\n");
    } else if (res < 0) {
        printf("<str1> أقل من <str2> (%d)\n", res);
    } else {
        printf("<str1> أكبر من <str2> (%d)\n", res);
    }
    exit(EXIT_SUCCESS);
}
