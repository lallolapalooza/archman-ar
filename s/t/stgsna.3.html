t; !> A summary for the i-th generalized eigenvalue is computed and returned. !> The error bounds are computed using the reciprocal condition numbers. !> !> Arguments: !> ======== !> !> JOB (input) CHARACTER*1 !> Specifies the computation to be performed. !> = 'E': Error estimates for the eigenvalues (and optionally eigenvectors). !> = 'V': Error estimates for the eigenvectors (and optionally eigenvalues). !> = 'B': Error estimates for both the eigenvalues and eigenvectors. !> !> HOWMNY (input) CHARACTER*1 !> Indicates how to compute the error estimates for the eigenvalues. !> = 'A': Compute error estimates for all generalized eigenvalues. !> = 'S': Compute error estimates for the selected generalized eigenvalues. !> !> SELECT (input) LOGICAL array, dimension (N) !> If HOWMNY = 'S', then only the entries of SELECT corresponding to !> the desired generalized eigenvalues are set to .TRUE. !> If HOWMNY = 'A', then SELECT is not referenced. !> !> N (input) INTEGER !> The dimension of the matrices A and B. 0 <= N. !> !> T (input) REAL or DOUBLE PRECISION array, dimension (LD T, N) !> The upper triangular matrix T from the generalized Schur decomposition. !> !> DT (input) INTEGER !> The number of blocks of eigenvalues. !> !> E (input) REAL or DOUBLE PRECISION array, dimension (N) !> The real eigenvalues of the generalized eigenvalue problem. !> !> F (input) REAL or DOUBLE PRECISION array, dimension (N) !> The real eigenvalues of the generalized eigenvalue problem. !> !> A (input) REAL or DOUBLE PRECISION array, dimension (LDA, N) !> The matrix A from the generalized Schur decomposition. !> !> B (input) REAL or DOUBLE PRECISION array, dimension (LDB, N) !> The matrix B from the generalized Schur decomposition. !> !> VL (input) REAL or DOUBLE PRECISION array, dimension (LDVL, N) !> If JOB = 'V' or 'B', VL contains the left eigenvectors of the !> generalized eigenvalue problem A*x = lambda*B*x. Each column !> VL(i) represents a left eigenvector. !> !> LDVL (input) INTEGER !> The leading dimension of the array VL. !> !> VR (input) REAL or DOUBLE PRECISION array, dimension (LDRR, N) !> If JOB = 'V' or 'B', VR contains the right eigenvectors of the !> generalized eigenvalue problem A*x = lambda*B*x. Each column !> VR(i) represents a right eigenvector. !> !> LDRR (input) INTEGER !> The leading dimension of the array VR. !> !> MAXMN (input) INTEGER !> The maximum number of eigenvalue/eigenvector pairs for which !> error estimates will be computed. !> !> DIFL (output) REAL or DOUBLE PRECISION array, dimension (MAXMN) !> If JOB = 'E' or 'B', DIFL contains the reciprocal condition !> numbers for the selected eigenvalues. !> !> DIFR (output) REAL or DOUBLE PRECISION array, dimension (MAXMN) !> If JOB = 'V' or 'B', DIFR contains the reciprocal condition !> numbers for the selected eigenvectors. !> !> SEW (output) REAL or DOUBLE PRECISION array, dimension (MAXMN) !> If JOB = 'E' or 'B', SEW contains the estimated error bounds !> for the selected eigenvalues. !> !> SWE (output) REAL or DOUBLE PRECISION array, dimension (MAXMN) !> If JOB = 'V' or 'B', SWE contains the estimated error bounds !> for the selected eigenvectors. !> !> WORK (workspace) REAL or DOUBLE PRECISION array, dimension (LWORK) !> Workspace array. !> !> LWORK (input) INTEGER !> The dimension of the array WORK. !> !> IINFO (output) INTEGER !> = 0: successful exit. !> > 0: a warning that some information could not be computed. !> See above for details on how to interpret the returned value. !> !> INFO (output) INTEGER !> = 0: successful exit. !> < 0: if INFO = -i, the i-th argument had an illegal value. !> > 0: if INFO = i, then the i-th singular value is zero. !> !> Details: !> ======= !> !> The accuracy of the generalized eigenvalue problem A*x = lambda*B*x is !> measured by the condition number. For a generalized eigenvalue lambda !> and corresponding right eigenvector u and left eigenvector v, the !> reciprocal condition number is defined as !> !> cond(lambda, u, v)**(-1) = lambda * (u**H * v) / (v**H * u) !> = (u**H * v) / (u**H * u) !> = (v**H * v) / (v**H * u) !> !> where u**H is the conjugate transpose of u. !> !> An approximate error bound on the chordal distance between the i-th !> computed generalized eigenvalue w and the corresponding exact !> eigenvalue lambda is !> !> chord(w, lambda) <= EPS * norm(A, B) / S(I) !> !> where EPS is the machine precision. !> !> The reciprocal of the condition number DIF(i) of right eigenvector u !> and left eigenvector v corresponding to the generalized eigenvalue w !> is defined as follows: !> !> a) If the i-th eigenvalue w = (a,b) is real !> !> Suppose U and V are orthogonal transformations such that !> !> U**T*(A, B)*V = (S, T) = ( a * ) ( b * ) 1 !> ( 0 S22 ),( 0 T22 ) n-1 !> 1 n-1 1 n-1 !> !> Then the reciprocal condition number DIF(i) is !> !> Difl((a, b), (S22, T22)) = sigma-min( Zl ), !> !> where sigma-min(Zl) denotes the smallest singular value of the !> 2(n-1)-by-2(n-1) matrix !> !> Zl = [ kron(a, In-1) -kron(1, S22) ] !> [ kron(b, In-1) -kron(1, T22) ] . !> !> Here In-1 is the identity matrix of size n-1. kron(X, Y) is the !> Kronecker product between the matrices X and Y. !> !> Note that if the default method for computing DIF(i) is wanted !> (see SLATDF), then the parameter DIFDRI (see below) should be !> changed from 3 to 4 (routine SLATDF(IJOB = 2 will be used)). !> See STGSYL for more details. !> !> b) If the i-th and (i+1)-th eigenvalues are complex conjugate pair, !> !> Suppose U and V are orthogonal transformations such that !> !> U**T*(A, B)*V = (S, T) = ( S11 * ) ( T11 * ) 2 !> ( 0 S22 ),( 0 T22) n-2 !> 2 n-2 2 n-2 !> !> and (S11, T11) corresponds to the complex conjugate eigenvalue !> pair (w, conjg(w)). There exist unitary matrices U1 and V1 such !> that !> !> U1**T*S11*V1 = ( s11 s12 ) and U1**T*T11*V1 = ( t11 t12 ) !> ( 0 s22 ) ( 0 t22 ) !> !> where the generalized eigenvalues w = s11/t11 and !> conjg(w) = s22/t22. !> !> Then the reciprocal condition number DIF(i) is bounded by !> !> min( d1, max( 1, |real(s11)/real(s22)| )*d2 ) !> !> where, d1 = Difl((s11, t11), (s22, t22)) = sigma-min(Z1), where !> Z1 is the complex 2-by-2 matrix !> !> Z1 = [ s11 -s22 ] !> [ t11 -t22 ], !> !> This is done by computing (using real arithmetic) the !> roots of the characteristical polynomial det(Z1**T * Z1 - lambda I), !> where Z1**T denotes the transpose of Z1 and det(X) denotes !> the determinant of X. !> !> and d2 is an upper bound on Difl((S11, T11), (S22, T22)), i.e. an !> upper bound on sigma-min(Z2), where Z2 is (2n-2)-by-(2n-2) !> !> Z2 = [ kron(S11**T, In-2) -kron(I2, S22) ] !> [ kron(T11**T, In-2) -kron(I2, T22) ] !> !> Note that if the default method for computing DIF is wanted (see !> SLATDF), then the parameter DIFDRI (see below) should be changed !> from 3 to 4 (routine SLATDF(IJOB = 2 will be used)). See STGSYL !> for more details. !> !> For each eigenvalue/vector specified by SELECT, DIF stores a !> Frobenius norm-based estimate of Difl. !> !> An approximate error bound for the i-th computed eigenvector VL(i) or !> VR(i) is given by !> !> EPS * norm(A, B) / DIF(i). !> !> See ref. [2-3] for more details and further references. !>
