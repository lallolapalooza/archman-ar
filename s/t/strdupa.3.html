strdup(3) دليل الوظائف المكتبية strdup(3)

الاسم

strdup, strndup, strdupa, strndupa - تكرار سلسلة نصية

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <string.h>
char *strdup(const char *s);
char *strndup(size_t n;
              const char s[n], size_t n);
char *strdupa(const char *s);
char *strndupa(size_t n;
              const char s[n], size_t n);
متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

strdup():

    _XOPEN_SOURCE >= 500
        || /* منذ glibc 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

strndup():

    منذ glibc 2.10:
        _POSIX_C_SOURCE >= 200809L
    قبل glibc 2.10:
        _GNU_SOURCE

strdupa(), strndupa():

    _GNU_SOURCE

الوصف

تعيد الوظيفة strdup() مؤشرًا إلى سلسلة نصية جديدة تكون نسخة مكررة من السلسلة s. يتم الحصول على الذاكرة للسلسلة الجديدة باستخدام malloc(3)، ويمكن تحريرها باستخدام free(3).

الوظيفة strndup() مشابهة، ولكنها تنسخ بحد أقصى n بايت. إذا كانت s أطول من n، يتم نسخ n بايت فقط، ويتم إضافة بايت صفري إنهاء ('\0').

strdupa() و strndupa() متشابهتان، ولكنهما تستخدمان alloca(3) لتخصيص المخزن المؤقت.

قيمة الإرجاع

عند النجاح، تعيد الوظيفة strdup() مؤشرًا إلى السلسلة المكررة. تعيد NULL إذا كانت الذاكرة غير كافية، مع ضبط errno للإشارة إلى الخطأ.

الأخطاء

ENOMEM
ذاكرة غير كافية متاحة لتخصيص سلسلة مكررة.
