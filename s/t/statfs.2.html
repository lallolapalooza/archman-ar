statfs(2)

statfs(2) دليل استدعاءات النظام statfs(2)

الاسم

statfs, fstatfs - الحصول على إحصائيات نظام الملفات

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/vfs.h>    /* أو <sys/statfs.h> */
int statfs(const char *path, struct statfs *buf);
int fstatfs(int fd, struct statfs *buf);

ما لم تكن بحاجة إلى حقل f_type، يجب عليك استخدام واجهة statvfs(3) القياسية بدلاً من ذلك.

الوصف

يقوم استدعاء النظام statfs() بإرجاع معلومات حول نظام ملفات مثبت. path هو اسم المسار لأي ملف داخل نظام الملفات المثبت. buf هو مؤشر إلى هيكل statfs معرف تقريبًا على النحو التالي:


struct statfs {
    __fsword_t f_type;    /* نوع نظام الملفات (انظر أدناه) */
    __fsword_t f_bsize;   /* حجم كتلة النقل المثلى */
    fsblkcnt_t f_blocks;  /* إجمالي كتل البيانات في نظام الملفات */
    fsblkcnt_t f_bfree;   /* كتل خالية في نظام الملفات */
    fsblkcnt_t f_bavail;  /* كتل خالية متاحة للمستخدم غير المميز */
    fsfilcnt_t f_files;   /* إجمالي الـ inodes في نظام الملفات */
    fsfilcnt_t f_ffree;   /* inodes خالية في نظام الملفات */
    fsid_t     f_fsid;    /* معرف نظام الملفات */
    __fsword_t f_namelen; /* أقصى طول لأسماء الملفات */
    __fsword_t f_frsize;  /* حجم الكسر (منذ Linux 2.6) */
    __fsword_t f_flags;   /* خيارات تثبيت نظام الملفات (منذ Linux 2.6.36) */
    __fsword_t f_spare[xxx];
                    /* بايتات حشو محفوظة للاستخدام المستقبلي */
};

الحقل f_flags هو قناع بت يشير إلى خيارات التثبيت لنظام الملفات. يحتوي على صفر أو أكثر من البتات التالية:

ST_MANDLOCK
يُسمح بالقفل الإلزامي على نظام الملفات (انظر fcntl(2)).
ST_NOATIME
لا تقم بتحديث أوقات الوصول؛ انظر mount(2).
ST_NODEV
تمنع الوصول إلى ملفات الأجهزة الخاصة على نظام الملفات هذا.
ST_NODIRATIME
لا تقم بتحديث أوقات وصول الدلائل؛ انظر mount(2).
ST_NOEXEC
يُمنع تنفيذ البرامج على نظام الملفات هذا.
ST_NOSUID
يتم تجاهل بتات set-user-ID و set-group-ID بواسطة exec(3) للملفات القابلة للتنفيذ على نظام الملفات هذا.
ST_RDONLY
تم تثبيت نظام الملفات هذا للقراءة فقط.
ST_RELATIME
قم بتحديث atime بالنسبة إلى mtime/ctime؛ انظر mount(2).
ST_SYNCHRONOUS
تتم مزامنة الكتابات إلى نظام الملفات فورًا (انظر وصف O_SYNC في open(2)).
ST_NOSYMFOLLOW (منذ Linux 5.10)
لا يتم اتباع الروابط الرمزية عند حل المسارات؛ انظر mount(2).

لا أحد يعرف ما الذي يفترض أن يحتويه f_fsid (ولكن انظر أدناه).

يتم تعيين الحقول غير المعرفة لنظام ملفات معين إلى 0.

fstatfs() يرجع نفس المعلومات حول ملف مفتوح مشار إليه بواسطة واصف fd.

قيمة الإرجاع

عند النجاح، يتم إرجاع الصفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EACCES
(statfs()) يتم إنكار إذن البحث عن مكون في بادئة المسار path. (انظر أيضًا path_resolution(7).)
EBADF
(fstatfs()) fd ليس واصف ملف مفتوح صالح.
EFAULT
buf أو path يشير إلى عنوان غير صالح.
EINTR
تم مقاطعة الاستدعاء بواسطة إشارة؛ انظر signal(7).
EIO
حدث خطأ إدخال/إخراج أثناء القراءة من نظام الملفات.
ELOOP
(statfs()) تم العثور على عدد كبير جدًا من الروابط الرمزية أثناء ترجمة path.
ENAMETOOLONG
