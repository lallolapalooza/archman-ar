streqvcmp(3)

الحزمة: autogen

التراخيص: GPL3

streqvcmp(3) دليل المبرمج streqvcmp(3)

الاسم

streqvcmp - مقارنة سلسلتين مع تعيين مكافئ

الملخص

#include <your-opts.h>
cc [...] -o outfile infile.c -lopts [...]

int streqvcmp(char const * str1, char const * str2);

الوصف

باستخدام تعيين أحرف، تتم مقارنة سلسلتين لـ "المكافأة". يتم تعيين كل حرف إدخال إلى حرف مقارنة ويتم مقارنة الأحرف المعينة للسلسلتين المدخلتين المنتهيتين بـ NUL. يتم تعيين اسم هذه الدالة إلى option_streqvcmp حتى لا يتعارض مع مساحة أسماء POSIX.

str1
السلسلة الأولى
str2
السلسلة الثانية

الفرق بين حرفين مختلفين

الأخطاء

لم يتم التحقق من شيء. المتصل مسؤول عن أخطاء التجزئة.
