قالب وسيطات

std::forward_list

A doubly-linked list.

Header: <forward_list>

Namespace: std

Template parameters

_Tp
Type of element.
_Alloc
Allocator type, defaults to allocator<_Tp>.

Meets the requirements of a container, a sequence, including the optional sequence requirements with the exception of at and operator[].

This is a singly linked list. Traversal up the list requires linear time, but adding and removing elements (or nodes) is done in constant time, regardless of where the change takes place. Unlike std::vector and std::deque, random-access iterators are not provided, so subscripting ([]) access is not allowed. For algorithms which only need sequential access, this lack makes no difference.

Also unlike the other standard containers, std::forward_list provides specialized algorithms unique to linked lists, such as splicing, sorting, and in-place reversal.

The following operations are list-specific:

before_begin()
Returns an iterator that points before the first element.
push_front()
Inserts an element at the beginning of the list.
emplace_front()
Constructs an element in-place at the beginning of the list.
pop_front()
Removes the first element of the list.
insert_after()
Inserts elements after a given position.
emplace_after()
Constructs elements in-place after a given position.
erase_after()
Removes elements after a given position.
remove()
Removes all elements equal to a given value.
remove_if()
Removes all elements satisfying a given predicate.
splice_after()
Moves elements from another list into this list.
merge()
Merges two sorted lists.
merge() with comparison object
Merges two sorted lists using a custom comparison object.
sort()
Sorts the list.

Sorts the list using a custom comparison object.
unique()
Removes consecutive duplicate elements.
unique() with comparison object
Removes consecutive duplicate elements using a custom comparison object.
reverse()
Reverses the order of elements in the list.
assign()
Assigns new contents to the list, replacing its current contents.
fill()
Fills the list with a given value.

عمليات القائمة

العمليات التالية خاصة بالقائمة:

before_begin()
تُرجع مُكرِّرًا يشير إلى ما قبل العنصر الأول.
push_front()
تُدرج عنصرًا في بداية القائمة.
emplace_front()
تُنشئ عنصرًا في مكانه في بداية القائمة.
pop_front()
تُزيل العنصر الأول من القائمة.
insert_after()
تُدرج عناصر بعد موضع معين.
emplace_after()
تُنشئ عناصر في مكانها بعد موضع معين.

تُزيل عناصر بعد موضع معين.
remove()
تُزيل جميع العناصر المساوية لقيمة معينة.
remove_if()
تُزيل جميع العناصر التي تحقق شرطًا معينًا.

تنقل عناصر من قائمة أخرى إلى هذه القائمة.

تدمج قائمتين مرتبتين.

تدمج قائمتين مرتبتين باستخدام كائن مقارنة مخصص.

ترتب القائمة باستخدام كائن مقارنة مخصص.
