NAME

Description

The basic_fstream class template provides an interface for file stream buffering.

It is derived from basic_iostream, which is derived from basic_istream and basic_ostream. The underlying stream buffer is a basic_filebuf.

The class template is parameterized by:

  • _CharT: The character type.
  • _Traits: The character traits type, defaulting to std::char_traits<_CharT>.
