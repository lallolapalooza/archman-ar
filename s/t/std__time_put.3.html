Detailed Description

template<typename _CharT, typename _OutIter>
class std::time_put< _CharT, _OutIter >

time_put facet.

The class `time_put` encapsulates formatting of date and time information into a sequence of characters. It is derived from `locale::facet` and behaves as described in the C++ Standard.

The primary function is `do_put`, which handles formatting based on a format specifier.

This is a template class specialized for character type `_CharT` and an output iterator type `_OutIter`.

The primary template is not defined.

The default constructor constructs a `time_put` facet with a default size.

The virtual destructor does nothing.

The `operator()` functions provide a convenient interface to the `do_put` methods.

The first `operator()` overload formats a single time specifier.

The second `operator()` overload formats a sequence of characters according to the format string specified by the range `[__beg, __end)`.

The third `operator()` overload is a convenience function that takes a `std::string` as the format string.

The `do_put` methods are pure virtual functions that must be implemented by derived classes. The first `do_put` method formats a single time specifier. The second `do_put` method formats a sequence of characters according to the format string specified by the range `[__beg, __end)`.

The `_S_days_abbrev`, `_S_days_full`, `_S_months_abbrev`, `_S_months_full`, `_S_era`, and `_S_ampm` arrays contain strings used for formatting date and time information, specific to the locale.

The related `operator<<` overload allows direct output of `std::tm` structures to `std::basic_ostream`.
