الوظائف الأساسية

تستخدم الدوال في هذا القسم دالة تجزئة MD5 لإنتاج تجزئات 128 بت (16 بايت). MD5 ليست آمنة للتشفير. لذلك، لا ينبغي استخدام هذه الدوال في التطبيقات الحساسة للأمان. دوال BLAKE2 أدناه آمنة للتشفير.

type t = string

نوع التجزئات: سلاسل نصية 16 بايت.

val compare : t -> t -> int

دالة المقارنة للتجزئات 16 بايت، بنفس مواصفات compare والمشاركة في التنفيذ مع String.compare . جنباً إلى جنب مع النوع t ، تسمح هذه الدالة compare بتمرير الوحدة Digest كوسيطة للدوال الوصفية Set.Make و Map.Make .

منذ 4.02

val substring : string -> int -> int -> t

Digest.substring s ofs len ترجع تجزئة السلسلة النصية الفرعية لـ s بدءًا من الفهرس ofs وتحتوي على len حرفًا.

val subbytes : bytes -> int -> int -> t

Digest.subbytes s ofs len ترجع تجزئة التسلسل الفرعي لـ s بدءًا من الفهرس ofs وتحتوي على len بايت.

منذ 4.02

val channel : in_channel -> t

إذا كان len غير سالب، تقرأ Digest.channel ic len len حرفًا من القناة ic وترجع تجزئتها، أو تثير End_of_file إذا تم الوصول إلى نهاية الملف قبل قراءة len حرفًا. إذا كان len سالبًا، تقرأ Digest.channel ic len جميع الأحرف من ic حتى الوصول إلى نهاية الملف وترجع تجزئتها.

module type S = sig end

التوقيع لدالة تجزئة تنتج تجزئات بطول hash_length من سلاسل نصية، ومصفوفات بايت، وملفات.

منذ 5.2

دوال تجزئة محددة

module BLAKE128 : S

BLAKE128 هي دالة تجزئة BLAKE2b تنتج تجزئات 128 بت (16 بايت). إنها آمنة للتشفير. ومع ذلك، فإن الحجم الصغير للتجزئات يتيح هجمات القوة الغاشمة في 2{^64} محاولة.

منذ 5.2

module BLAKE256 : S

BLAKE256 هي دالة تجزئة BLAKE2b تنتج تجزئات 256 بت (32 بايت). إنها آمنة للتشفير، والتجزئات كبيرة بما يكفي لإحباط هجمات القوة الغاشمة.

منذ 5.2

module BLAKE512 : S

BLAKE512 هي دالة تجزئة BLAKE2b تنتج تجزئات 512 بت (64 بايت). إنها آمنة للتشفير، والتجزئات كبيرة بما يكفي لإحباط هجمات القوة الغاشمة.

منذ 5.2

module MD5 : S

MD5 هي دالة تجزئة MD5. تنتج تجزئات 128 بت (16 بايت) وليست آمنة للتشفير على الإطلاق. يجب استخدامها فقط للتوافق مع التصميمات السابقة التي تتطلب استخدام MD5.
