SILE(1) دليل الأوامر العامة SILE(1)

الاسم

SILE - مدقق SILE يقرأ ملف (ملفات) الإدخال وينسق المحتوى إلى تنسيق مستند معروض، عادة PDF

ملخص

sile [-b|--backend] [-c|--class] [-d|--debug] [-e|--evaluate] [-E|--evaluate-after] [-f|--fontmanager] [--luarocks-tree] [-m|--makedeps] [-o|--output] [-O|--option] [-p|--preamble] [-P|--postamble] [-u|--use] [-q|--quiet] [-t|--traceback] [-h|--help] [INPUT]

الوصف

مدقق SILE يقرأ ملف (ملفات) الإدخال وينسق المحتوى إلى تنسيق مستند معروض، عادة PDF.

افتراضياً، قد تكون ملفات الإدخال بتنسيق SIL التصريحي، XML منظم، أو Lua برمجي. يتم اكتشاف تنسيق الإدخال تلقائياً بواسطة الوحدات النشطة. افتراضياً، سيكون ملف الإخراج هو ملف بنفس اسم أول ملف إدخال مع تغيير الامتداد إلى .pdf. يمكن تجاوز اسم ملف الإخراج باستخدام الوسيطة `--output`. باستخدام `--backend` يمكن التبديل إلى تنسيق إخراج مختلف (أو مشغل مختلف لنفس التنسيق). يمكن التعامل مع تنسيقات إدخال أو إخراج إضافية عن طريق تحميل وحدة طرف ثالث تدعمها عن طريق إضافة الوسيطة `--use` على سطر الأوامر (والتي سيتم تحميلها قبل محاولة قراءة مستندات الإدخال).

خيارات

-b, --backend=BACKEND
تحديد مشغل الإخراج.

الافتراضي هو `libtexpdf` وهو مناسب لمعظم إخراج PDF. البدائل المدعومة بشكل افتراضي تشمل `text` و `debug` و `dummy` و `cairo` و `podofo`. قد يتم تمكين مخرجات أخرى عبر `--use`.

-c, --class=CLASS
تجاوز فئة المستند الافتراضية أو المحددة.

الفئة الافتراضية للمستندات التي لا تحدد واحدة في العلامة الجذر هي `plain`. يمكن استخدام هذا إما لتغيير الفئة الافتراضية أو لتجاوز الفئة المحددة فعلياً في المستند. تشمل الفئات المجمعة الأخرى `base`, `bible`, `book`, `diglot`, `docbook`, `docbook`, `jbook`, `jplain`, `letter`, `pecha`, `tbook`, `tplain`, و `triglot`. سيتم تحميل الأخرى ديناميكياً من مسار الوحدة.

-d, --debug=DEBUGFLAG[,DEBUGFLAG]
عرض معلومات التصحيح للجوانب المحددة من عملية SILE.

يمكن إعطاء عدة علامات تصحيح كقائمة مفصولة بفواصل. بينما قد تحدد الحزم علامات تصحيح خاصة بها، فإن الأكثر استخداماً هي `typesetter`, `pagebuilder`, `vboxes`, `break`, `frames`, `profile`, و `versions`. يمكن تحديدها أكثر من مرة.

-e, --evaluate=EXRPESION
تقييم تعبير Lua قبل معالجة الإدخال.

يمكن تحديده أكثر من مرة.

-E, --evaluate-after=EXRPESION
تقييم تعبير Lua بعد معالجة الإدخال.

يمكن تحديده أكثر من مرة.

-f, --fontmanager=FONTMANAGER
تحديد مدير الخطوط الذي سيتم استخدامه.

مدير الخطوط مسؤول عن اكتشاف مواقع ملفات الخطوط على النظام بالنظر إلى اسم الخط. مدير الخطوط الافتراضي هو `fontconfig` على الأنظمة غير macOS و `macfonts` على macOS.

--luarocks-tree=LUAROCKS_TREE
إضافة مسار إلى قائمة أشجار LuaRocks التي يتم البحث فيها عن الوحدات.

عند تثبيت وحدات SILE طرف ثالث عبر LuaRocks هناك عدة مواقع تثبيت محتملة. قد يتم تثبيتها في النظام المضيف، أو دليل المستخدم الرئيسي، أو مسار محلي للمشروع، أو أي موقع عشوائي. في حالة النظام أو المسار المحلي للمشروع المسمى `lua_modules` بالضبط، سيتم العثور عليها تلقائياً. في حالة أي مسار آخر، يحتاج SILE إلى معرفة مكان العثور عليها. يمكن القيام بذلك عن طريق تصدير متغير البيئة LUA_PATH قبل تشغيل SILE، أو باستخدام هذا الخيار.

-m, --makedeps=FILE
إنشاء قائمة بالتبعيات بتنسيق Makefile وكتابتها إلى ملف.

يتتبع هذا جميع الملفات (ملفات الإدخال، مكتبات Lua، الخطوط، الصور، إلخ) المستخدمة أثناء عملية التدقيق. بعد الانتهاء، يتم كتابة القائمة إلى FILE بتنسيق قائمة تبعيات لهدف في Makefile. يمكن استخدام هذا لاحقاً لتحديد ما إذا كان PDF يحتاج إلى إعادة عرض بناءً على ما إذا كانت أي مدخلات قد تغيرت.

-o, --output=FILE
تحديد اسم ملف الإخراج صراحةً.

افتراضياً، سيتم استخدام الاسم الأساسي لأول ملف إدخال كاسم ملف الإخراج. سيتم اختيار امتداد بناءً على مشغل الإخراج، عادة .pdf. مع هذا الخيار يمكن إعطاء أي اسم ومسار اعتباطي. بالإضافة إلى ذلك يمكن استخدام `-` لكتابة الإخراج إلى STDOUT.

-O, --option=OPTION
تعيين أو تجاوز خيارات فئة المستند.

يمكن استخدامه لتغيير الخيارات الافتراضية أو تجاوز تلك المحددة في مستند. على سبيل المثال، تعيين `--option papersize=letter` سيتجاوز كل من الحجم الافتراضي A4 وأي حجم محدد في خيارات المستند. يمكن تحديده أكثر من مرة.

-p, --preamble=FILE
تضمين محتويات ملف SIL أو XML أو أي ملف مورد آخر قبل محتوى مستند الإدخال.

يجب أن تكون القيمة اسم ملف كامل مع مسار نسبي إلى PWD أو مسار مطلق. يمكن تحديده أكثر من مرة.

-P, --postamble=FILE
تضمين محتويات ملف SIL أو XML أو أي ملف مورد آخر بعد محتوى مستند الإدخال.

يجب أن تكون القيمة اسم ملف كامل مع مسار نسبي إلى PWD أو مسار مطلق. يمكن تحديده أكثر من مرة.

-u, --use=MODULE[[PARAMETER=VALUE[,PARAMETER=VALUE]]]
تحميل وتهيئة فئة أو مدخل أو مشكل أو وحدة أخرى قبل معالجة الإدخال الرئيسي.

يجب أن تكون القيمة اسم وحدة قابلة للتحميل (بدون امتداد، باستخدام `.` كفاصل مسار) وسيتم تحميلها باستخدام مسار بحث وحدة SILE. يمكن تمرير خيارات إلى الوحدة عن طريق تغليف أزواج `key=value` في أقواس مربعة بعد اسم الوحدة. هذا مفيد بشكل خاص عندما لا يكون مستند الإدخال SIL أو مخطط XML معترف به أصلاً ويحتاج SILE إلى تعليم حيل جديدة حتى قبل محاولة قراءة ملف الإدخال. إذا كانت الوحدة فئة مستند، فستحل محل `plain` كفئة افتراضية لمعالجة المستندات التي لا تحدد واحدة لاستخدامها. نظراً لأن هذا يتم تنفيذه قبل تحميل المستند، فقد يضيف حتى محلل إدخال أو يعدل محللاً موجوداً لدعم تنسيقات الملفات الجديدة. سيتم إضافة وحدات الحزمة إلى المقدمة ليتم تحميلها بعد تهيئة الفئة. يمكن تحديده أكثر من مرة.

-q, --quiet
كتم التحذيرات والرسائل الإخبارية أثناء المعالجة
-t, --traceback
عرض تتبع الموقع المفصل للأخطاء والتحذيرات
-h, --help
طباعة المساعدة (انظر ملخصاً بـ '-h')
[INPUT]
اسم (أسماء) ملف (ملفات) المستند الإدخالي، افتراضياً بتنسيقات SIL أو XML أو Lua.

ملف إدخال واحد أو أكثر لمعالجة المحتوى منه. يعتبر الملف الأول المدرج هو المستند الرئيسي، ويتم معالجة الملفات الأخرى بالتتابع. يمكن تمكين تنسيقات مدخلات أخرى عبر `--use`. استخدم `-` لقراءة تيار المحتوى من STDIN.

NAME

sile - typesetting system

SYNOPSIS 

sile [file]

DESCRIPTION

DESCRIPTION

SiLE (pronounced “silly”) is a typesetting system that uses Lua for its scripting language. It is intended to be a free, high-quality, and powerful alternative to TeX. It is also intended to be easier to use and extend than TeX, by virtue of using a modern, general-purpose programming language for its scripting capabilities.

It is written in C and Lua.

If no file is specified, SiLE will read standard input.

The output file will be a PDF document.

OPTIONS

OPTIONS

No command-line options are supported.
