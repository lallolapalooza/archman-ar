SIGINTERRUPT(3P) دليل مبرمج POSIX SIGINTERRUPT(3P)

الملحق

هذه الصفحة من الدليل هي جزء من دليل مبرمج POSIX. قد يختلف تنفيذ Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

siginterrupt — السماح للإشارات مقاطعة الوظائف

الملخص

#include <signal.h>
int siginterrupt(int sig, int flag);

الوصف

تقوم الدالة siginterrupt() بتغيير سلوك إعادة التشغيل عند مقاطعة دالة بإشارة محددة. للدالة siginterrupt(sig, flag) تأثير كما لو كانت مطبقة كالتالي:

int siginterrupt(int sig, int flag) {
    int ret;
    struct sigaction act;
    (void) sigaction(sig, NULL, &act);
    if (flag)
        act.sa_flags &= ~SA_RESTART;
    else
        act.sa_flags |= SA_RESTART;
    ret = sigaction(sig, &act, NULL);
    return ret;
}

قيمة الإرجاع

عند الانتهاء بنجاح، تعيد الدالة siginterrupt() القيمة 0؛ بخلاف ذلك، سيتم إرجاع -1 وسيتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

ستفشل الدالة siginterrupt() إذا:

EINVAL
الوسيط sig ليس رقم إشارة صالحًا.

الأقسام التالية إعلامية.

أمثلة

لا شيء.

استخدام التطبيقات

تدعم الدالة siginterrupt() البرامج المكتوبة لواجهات النظام التاريخية. يجب على التطبيقات استخدام sigaction() مع علامة SA_RESTART بدلاً من الدالة siginterrupt() المهملة.
