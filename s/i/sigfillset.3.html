SIGSETOPS(3) دليل وظائف المكتبة SIGSETOPS(3)

الاسم

sigemptyset, sigfillset, sigaddset, sigdelset, sigismember - عمليات مجموعات الإشارات POSIX

المكتبة

مكتبة C القياسية (libc، -lc)

المُلَخَّص

#include <signal.h>
int sigemptyset(sigset_t *set);
int sigfillset(sigset_t *set);
int sigaddset(sigset_t *set, int signum);
int sigdelset(sigset_t *set, int signum);
int sigismember(const sigset_t *set, int signum);
متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

sigemptyset()، sigfillset()، sigaddset()، sigdelset()، sigismember():

    _POSIX_C_SOURCE

الوصف

تسمح هذه الوظائف بمعالجة مجموعات الإشارات POSIX.

تقوم sigemptyset() بتهيئة مجموعة الإشارات المعطاة بواسطة set لتكون فارغة، مع استبعاد جميع الإشارات من المجموعة.

تقوم sigfillset() بتهيئة set لتكون ممتلئة، شاملة جميع الإشارات.

تقوم sigaddset() و sigdelset() بإضافة وحذف الإشارة signum من set على التوالي.

تختبر sigismember() ما إذا كانت signum عضوًا في set.

يجب تهيئة الكائنات من النوع sigset_t باستدعاء sigemptyset() أو sigfillset() قبل تمريرها إلى الوظائف sigaddset() و sigdelset() و sigismember() أو وظائف glibc الإضافية الموضحة أدناه (sigisemptyset() و sigandset() و sigorset()). تكون النتائج غير محددة إذا لم يتم ذلك.

قيمة الإرجاع

تعيد sigemptyset() و sigfillset() و sigaddset() و sigdelset() القيمة 0 عند النجاح و -1 عند حدوث خطأ.

تعيد sigismember() القيمة 1 إذا كانت signum عضوًا في set، و 0 إذا لم تكن signum عضوًا، و -1 عند حدوث خطأ.

عند حدوث خطأ، تقوم هذه الوظائف بتعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
signum ليست إشارة صالحة.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
sigemptyset (), sigfillset (), sigaddset (), sigdelset (), sigismember (), sigisemptyset (), sigorset (), sigandset () Thread safety MT-Safe

الإصدارات

GNU

إذا تم تعريف ماكرو اختبار الميزة _GNU_SOURCE، فإن <signal.h> يعرض ثلاث وظائف أخرى لمعالجة مجموعات الإشارات:

int sigisemptyset(const sigset_t *set);
int sigorset(sigset_t *dest, const sigset_t *left,
              const sigset_t *right);
int sigandset(sigset_t *dest, const sigset_t *left,
              const sigset_t *right);

تعيد sigisemptyset() القيمة 1 إذا كانت set لا تحتوي على أي إشارات، و 0 خلاف ذلك.

تضع sigorset() اتحاد المجموعتين left و right في dest. تضع sigandset() تقاطع المجموعتين left و right في dest. تعيد كلتا الوظيفتين 0 عند النجاح، و -1 عند الفشل.

هذه الوظائف غير قياسية (توفر بعض الأنظمة الأخرى وظائف مماثلة) ويجب تجنب استخدامها في التطبيقات المحمولة.

المعايير

POSIX.1-2008.

التاريخ

POSIX.1-2001.

ملاحظات

عند إنشاء مجموعة إشارات ممتلئة، لا تتضمن وظيفة sigfillset() في glibc إشارتين في الوقت الفعلي تستخدمان داخليًا لتطبيق خيوط NPTL. انظر nptl(7) للتفاصيل.
