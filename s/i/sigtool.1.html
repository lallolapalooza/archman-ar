sigtool(1) Clam AntiVirus sigtool(1)

الاسم

sigtool - أداة إدارة التواقيع وقواعد البيانات

موجز

sigtool [خيارات]

الوصف

يمكن استخدام sigtool لتوليد مدققات MD5، وتحويل البيانات إلى تنسيق سداسي عشري، وقائمة تواقيع الفيروسات، وبناء/فك ضغط/اختبار/التحقق من قواعد بيانات CVD ونصوص التحديث.

الخيارات الشائعة

-h, --help
إخراج معلومات المساعدة والخروج.
-V, --version
طباعة رقم الإصدار والخروج.
--quiet
كن هادئًا، أخرج رسائل الخطأ فقط.
--debug
تمكين رسائل التصحيح
--stdout
اكتب جميع الرسائل إلى الإخراج القياسي.
--tempdir=DIRECTORY
إنشاء ملفات مؤقتة في DIRECTORY. يجب أن يكون الدليل قابلاً للكتابة للمستخدم الذي يقوم بتشغيل sigtool.
--leave-temps
لا تقم بإزالة الملفات المؤقتة.
--datadir=DIR
استخدم DIR كدليل قاعدة البيانات الافتراضي لجميع العمليات.

أوامر العمل مع التواقيع

-l[FILE], --list-sigs[=FILE]
قائمة بجميع أسماء التواقيع من دليل قاعدة البيانات المحلي (افتراضي) أو من FILE.
-fREGEX, --find-sigs=REGEX
ابحث واعرض التواقيع من دليل قاعدة البيانات المحلي التي تطابق REGEX المعطى. يتم فحص نص التوقيع بأكمله (الاسم، السلسلة السداسية العشرية، إلخ).
--decode-sigs=REGEX
فك ترميز التواقيع المقروءة من الإدخال القياسي (على سبيل المثال، تم توجيهها من --find-sigs)
--test-sigs=DATABASE TARGET_FILE
اختبار جميع التواقيع من DATABASE مقابل TARGET_FILE. لن تعطي هذه الخيار نتائج صالحة إلا إذا كان الملف المستهدف هو الملف النهائي (بعد فك الضغط، والتوحيد، وما إلى ذلك) الذي تم إنشاء التواقيع من أجله.

أوامر لتوليد التواقيع

--md5 [FILES]
توليد مدقق MD5 من الإدخال القياسي أو تواقيع MD5 للملفات.
--sha1 [FILES]
توليد مدقق SHA1 من الإدخال القياسي أو تواقيع SHA1 للملفات.
--sha2-256 [FILES]
توليد مدقق SHA2-256 من الإدخال القياسي أو تواقيع SHA2-256 للملفات. الخيار السابق --sha256 مهمل وقد تتم إزالته في إصدار مستقبلي.
--mdb [FILES]
توليد تواقيع .mdb (تجزئة قسم PE) للملفات.
--imp [FILES]
توليد تواقيع .imp (تجزئة جدول عنوان استيراد PE) للملفات.
--fuzzy-img [FILES]
توليد تجزئة ضبابية للصورة لكل ملف.

أوامر لتوحيد الملفات

--html-normalise=FILE
إنشاء ملفات HTML موحدة comment.html، nocomment.html، و script.html في دليل العمل الحالي.
--ascii-normalise=FILE
إنشاء ملف نصي موحد من مصدر ASCII.
--utf16-decode=FILE
فك ترميز بيانات UTF16.

أوامر لتحليل الملفات

--vba=FILE
استخراج وحدات VBA/Word6 الماكرو من مستند MS Office المعطى.
--vba-hex=FILE
استخراج وحدات Word6 الماكرو من مستند MS Office المعطى وعرض القيم السداسية العشرية المقابلة.
--print-certs=FILE
طباعة تفاصيل Authenticode من ملف PE.
--hex-dump
قراءة البيانات من الإدخال القياسي وكتابة سلسلة سداسية عشرية إلى الإخراج القياسي.

أوامر العمل مع CVDS

-i, --info
طباعة معلومات CVD والتحقق من MD5 وتوقيع رقمي.
--build=FILE, -b FILE
بناء ملف CVD. يتطلب -s، --server لقواعد بيانات الفيروسات الموقعة (.cvd)، أو --unsigned لـ (.cud) غير الموقع.
--max-bad-sigs=NUMBER
العدد الأقصى للتواقيع غير المتطابقة عند بناء CVD. الافتراضي: 3000
--flevel
تحديد مستوى flevel مخصص. الافتراضي: 77
--cvd-version
تحديد رقم الإصدار لاستخدامه في البناء. الافتراضي هو استخدام القيمة + 1 من CVD الحالي في --datadir. إذا لم يتم العثور على ملف بيانات، يكون السلوك الافتراضي هو المطالبة برقم الإصدار، وهذا المفتاح سيمنع المطالبة. ملاحظة: إذا تم العثور على CVD في --datadir، يتم استخدام الإصدار + 1 الخاص به ويتم تجاهل هذه القيمة.
--no-cdiff
لا تقم بإنشاء ملف .cdiff عند بناء ملف قاعدة بيانات جديد.
--hybrid
إنشاء ملف قاعدة بيانات هجين (قياسي وكود بايت).
--unsigned
إنشاء ملف قاعدة بيانات بدون توقيعات رقمية (.cud).
--server=ADDR
عنوان خدمة توقيع ClamAV (لمسؤولي قواعد بيانات الفيروسات فقط).
--unpack=FILE, -u FILE
فك ضغط FILE (CVD) إلى الدليل الحالي.
--unpack-current
فك ضغط ملف CVD محلي (رئيسي أو يومي) إلى الدليل الحالي.
--fips-limits
فرض حدود شبيهة بـ FIPS على استخدام خوارزميات التجزئة للأغراض التشفيرية. سيؤدي ذلك إلى تعطيل تواقيع FP لـ MD5 و SHA1 وسيطلب ملفات .sign للتحقق من صحة CVD.

أوامر العمل مع ملفات ترقيع CDIFF

--diff=OLD NEW, -d OLD NEW
إنشاء ملف ترقيع لـ CVDs/INCDIRs القديمة والجديدة.
--compare=OLD NEW, -c OLD NEW
سيقوم هذا الأمر بمقارنة ملفين نصيين وطباعة الاختلافات بتنسيق cdiff.
--run-cdiff=FILE, -r FILE
تنفيذ نص التحديث FILE في الدليل الحالي.
--verify-cdiff=FILE, -r FILE
التحقق من DIFF مقابل CVD/INCDIR.

أوامر لإنشاء والتحقق من التوقيعات الرقمية المنفصلة

--sign
توقيع ملف. سيكون اسم ملف .sign الناتج بالشكل: dbname-version.cvd.sign أو FILE.sign للأهداف غير CVD.

NAME

sigtool

utility for signature management

SYNOPSIS

sigtool [options] [inputfile]

DESCRIPTION

The sigtool utility is a helper tool for ClamAV. It can be used for signing and verifying signatures, generating hex dumps, managing CVD files, and more.

COMMON OPTIONS

--hex-dump
Generate a hex dump of the input file. The output is suitable for use in ClamAV signature databases.
--help
Show help message.
--version
Show version information.

COMMANDS FOR WORKING WITH SIGNATURES

--sign
Sign the input file. The signature will be saved in a file named inputfile.sign in the same directory as the input file. If a .sign file already exists, then the new signature will be appended to file.
--key=FILE
Specify a signing key.
--cert=FILE
Specify a signing cert. May be used more than once to add intermediate and root certificates.
--append
Use to add a signature line to an existing .sign file. Otherwise an existing .sign file will be overwritten.
--verify
Find and verify a detached digital signature for the given file. The digital signature file name must be in the form: dbname-version.cvd.sign or FILE.sign for non-CVD targets. It must be found next to the target file.
--cvdcertsdir=DIR
Specify a directory containing the root CA cert needed to verify the signature. If not provided, then sigtool will look in the default certs directory.

COMMANDS TO GENERATE SIGNATURES

See COMMANDS FOR WORKING WITH SIGNATURES above.

COMMANDS TO NORMALIZE FILES

Not applicable to sigtool.

COMMANDS FOR FILE ANALYSIS

Not applicable to sigtool.

COMMANDS FOR WORKING WITH CVDS

Not applicable to sigtool.

COMMANDS FOR WORKING WITH CDIFF PATCH FILES

Not applicable to sigtool.

COMMANDS FOR CREATING AND VERIFYING DETACHED DIGITAL SIGNATURES

--sign
Create a detached digital signature for the given file. The signature will be saved in a file named inputfile.sign next to the target file. If a .sign file already exists, then the new signature will be appended to file.
--key=FILE
Specify a signing key.
--cert=FILE
Specify a signing cert. May be used more than once to add intermediate and root certificates.
--append
Use to add a signature line to an existing .sign file. Otherwise an existing .sign file will be overwritten.
--verify
Find and verify a detached digital signature for the given file. The digital signature file name must be in the form: dbname-version.cvd.sign or FILE.sign for non-CVD targets. It must be found next to the target file.
--cvdcertsdir=DIR
Specify a directory containing the root CA cert needed to verify the signature. If not provided, then sigtool will look in the default certs directory.

ENVIRONMENT VARIABLES

Sigtool uses the following environment variables:

SIGNDUSER
The username to authenticate with the signing server when building a signed CVD database.
SIGNDPASS
The password to authenticate with the signing server when building a signed CVD database.
CVD_CERTS_DIR
Specify a directory containing the root CA cert needed to verify detached CVD digital signatures. If not provided, then sigtool will look in the default directory.

EXAMPLES

Generate hex string from testfile and save it to testfile.hex:

cat testfile | sigtool --hex-dump > testfile.hex
