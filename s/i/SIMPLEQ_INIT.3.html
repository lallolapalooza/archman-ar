SIMPLEQ_INIT(3)

NAME

SIMPLEQ_INIT, SIMPLEQ_FOREACH, SIMPLEQ_FIRST, SIMPLEQ_NEXT, SIMPLEQ_CONCAT, SIMPLEQ_ADD_HEAD, SIMPLEQ_ADD_TAIL, SIMPLEQ_REM_HEAD, SIMPLEQ_REM_TAIL, SIMPLEQ_REMOVE, SIMPLEQ_SWAP — simple-valued singly linked list macros

LIBRARY

Userland library (libucrts), libbsd

SYNOPSIS

    #include <sys/queue.h>

    SIMPLEQ_HEAD(simplehead, node);
    struct node {
        int data;
        SIMPLEQ_ENTRY(node) entries;
    };

    void
    function(struct simplehead *head)
    {
        struct node *np;
        struct node *n1, *n2;

        /* Forward traversal */
        SIMPLEQ_FOREACH(np, head, entries)
            printf("%i\n", np->data);

        /* TailQ deletion */
        n1 = SIMPLEQ_FIRST(head);
        while (n1 != NULL) {
            n2 = SIMPLEQ_NEXT(n1, entries);
            free(n1);
            n1 = n2;
        }
        SIMPLEQ_INIT(head);
        exit(EXIT_SUCCESS);
    }

DESCRIPTION

These macros provide an implementation of a simple-valued singly linked list.

A singly linked list is a list where each element contains a pointer to the next element in the list. The SIMPLEQ_ macros are useful for implementing stacks, queues, or lists where you only need to traverse the list in one direction.

The macros are defined in the <sys/queue.h> header file.

Head declaration

SIMPLEQ_HEAD(simplehead, node); declares a type struct simplehead which represents the head of a simple-valued singly linked list. The second argument, node, is the name of the structure that will be used for the list nodes. Each node structure must contain a field of type SIMPLEQ_ENTRY(node) entries;. The name entries can be any valid identifier.

Initialization

SIMPLEQ_INIT(head); initializes the list pointed to by head to be empty.

Accessing elements

SIMPLEQ_FIRST(head)
Returns a pointer to the first element in the list, or NULL if the list is empty.
SIMPLEQ_NEXT(node, entries)
Returns a pointer to the next element in the list after node. The entries argument is the name of the field within the node structure that holds the SIMPLEQ pointer.

Traversing the list

SIMPLEQ_FOREACH(np, head, entries) provides a forward iteration over the list. In each iteration, np is assigned a pointer to the current node. The iteration stops when np becomes NULL. The entries argument is the name of the field within the node structure that holds the SIMPLEQ pointer.

Adding elements

SIMPLEQ_ADD_HEAD(head, node)
Adds the element node to the head of the list head.
SIMPLEQ_ADD_TAIL(head, node)
Adds the element node to the tail of the list head.

Removing elements

SIMPLEQ_REM_HEAD(head)
Removes and returns the head element from the list head. Returns NULL if the list is empty.
SIMPLEQ_REM_TAIL(head)
Removes and returns the tail element from the list head. Returns NULL if the list is empty.
SIMPLEQ_REMOVE(head, node, entries)
Removes the element node from the list head. The entries argument is the name of the field within the node structure that holds the SIMPLEQ pointer.

Concatenating lists

SIMPLEQ_CONCAT(head1, head2, entries) concatenates the list head2 to the end of the list head1. The list head2 becomes empty after the operation. The entries argument is the name of the field within the node structure that holds the SIMPLEQ pointer.

Swapping lists

SIMPLEQ_SWAP(head1, head2, entries) swaps the contents of the lists head1 and head2. The entries argument is the name of the field within the node structure that holds the SIMPLEQ pointer.

RETURN VALUE

Various macros return pointers to list nodes, or NULL if the list is empty or the operation fails.

VERSIONS

The SIMPLEQ_ macros first appeared in FreeBSD 2.0.

BUGS

The SIMPLEQ_REMOVE macro has a linear time complexity, which might be inefficient for large lists.

STANDARDS

The SIMPLEQ_ macros are compliant with the BSD style guide and are widely used in various Unix-like operating systems.

HISTORY

The SIMPLEQ_ macros were implemented in FreeBSD and later adopted by other systems.

EXAMPLES

The synopsis section provides a basic example of how to use these macros.

A more complete example:

    #include <stdio.h>
    #include <stdlib.h>
    #include <sys/queue.h>

    /* Define the node structure and the list head */
    struct mynode {
        int data;
        SIMPLEQ_ENTRY(mynode) next;
    };
    SIMPLEQ_HEAD(mylist, mynode);

    int
    main() {
        struct mylist head;
        struct mynode *np, *n1, *n2;

        /* Initialize the list */
        SIMPLEQ_INIT(&head);

        /* Allocate and add nodes */
        np = malloc(sizeof(struct mynode));
        np->data = 10;
        SIMPLEQ_ADD_TAIL(&head, np);

        np = malloc(sizeof(struct mynode));
        np->data = 20;
        SIMPLEQ_ADD_TAIL(&head, np);

        np = malloc(sizeof(struct mynode));
        np->data = 30;
        SIMPLEQ_ADD_HEAD(&head, np);

        /* Forward traversal */
        printf("List contents (forward):\n");
        SIMPLEQ_FOREACH(np, &head, next)
            printf("%i\n", np->data);

        /* Remove the first element */
        n1 = SIMPLEQ_REM_HEAD(&head);
        if (n1 != NULL) {
            printf("Removed head: %i\n", n1->data);
            free(n1);
        }

        /* Remove the last element */
        n2 = SIMPLEQ_REM_TAIL(&head);
        if (n2 != NULL) {
            printf("Removed tail: %i\n", n2->data);
            free(n2);
        }

        /* Traverse again */
        printf("List contents after removal:\n");
        SIMPLEQ_FOREACH(np, &head, next)
            printf("%i\n", np->data);

        /* Free remaining nodes */
        n1 = SIMPLEQ_FIRST(&head);
        while (n1 != NULL) {
            n2 = SIMPLEQ_NEXT(n1, next);
            free(n1);
            n1 = n2;
        }
        SIMPLEQ_INIT(&head); /* Re-initialize to be safe */

        return 0;
    }
