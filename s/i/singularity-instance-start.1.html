NAME

apptainer-instance-start(1) – start an Apptainer instance

SYNOPSIS

apptainer instance start [options] container instance_name

DESCRIPTION

The apptainer instance start command starts a new Apptainer container instance. An instance is a running container that can be interacted with via the apptainer instance command group.

The instance is started from the specified container image (which can be a SIF file, a sandbox directory, or a Docker/library remote). The instance_name is a user-defined name for the instance.

When a container is started as an instance, it runs in the background. You can interact with the instance using commands like apptainer instance start, apptainer instance stop, apptainer instance list, apptainer instance use, and apptainer instance exec.

OPTIONS

The apptainer instance start command supports the following options:

--bind <source path>:<dest path>[:<options>]
Bind mount a host path into the instance. The <source path> is a path on the host system, and <dest path> is the path inside the instance. The optional <options> can include ro for read-only.
--cleanenv
Clean, with the exception of variables explicitly set using the --env or --env-file options, the user environment.
--env <NAME>=<value>
Set an environment variable within the instance. This option can be used multiple times.
--env-file <path>
Read environment variables from a file. Each line in the file should be in the format NAME=value.
--network <type>
Specify the network type for the instance. Supported types include bridge, host, none.
--overlay <path>[:<options>]
Attach an overlay filesystem. The <path> is the path to the overlay image (e.g., a SquashFS file). The optional <options> can include ro for read-only.
--tmpfs [=<path>[:<options>]]
Mount a tmpfs at the specified <path> inside the instance. If no path is specified, it defaults to the instance's root directory. The optional <options> can include rw for read-write and size for size limit.
--writable-tmpfs[=false]
makes the file system accessible as read-write with non persistent data (with overlay support only)

EXAMPLE

  $ apptainer instance start /tmp/my-sql.sif mysql
  $ apptainer shell instance://mysql
  Apptainer my-sql.sif> pwd
  /home/mibauer/mysql
  Apptainer my-sql.sif> ps
  PID TTY          TIME CMD
    1 pts/0    00:00:00 appinit
    2 pts/0    00:00:00 bash
    3 pts/0    00:00:00 ps
  Apptainer my-sql.sif>
  $ apptainer instance stop /tmp/my-sql.sif mysql
  Stopping /tmp/my-sql.sif mysql
