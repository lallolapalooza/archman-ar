sigwaitinfo(2) دليل استدعاءات النظام sigwaitinfo(2)

الاسم

sigwaitinfo, sigtimedwait, rt_sigtimedwait - الانتظار بشكل متزامن للإشارات المعلقة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <signal.h>
int sigwaitinfo(const sigset_t *restrict set,
                siginfo_t *_Nullable restrict info);
int sigtimedwait(const sigset_t *restrict set,
                siginfo_t *_Nullable restrict info,
                const struct timespec *restrict timeout);
متطلبات ميزة الاختبار (Feature Test Macro Requirements) لـ glibc (انظر feature_test_macros(7)):

sigwaitinfo(), sigtimedwait():

    _POSIX_C_SOURCE >= 199309L

الوصف

sigwaitinfo() يوقف تنفيذ الخيط الحالي (thread) حتى تصبح إحدى الإشارات في set معلقة (إذا كانت إحدى الإشارات في set معلقة بالفعل للخيط الحالي، فستعود sigwaitinfo() فورًا).

sigwaitinfo() تزيل الإشارة من مجموعة الإشارات المعلقة وتعيد رقم الإشارة كنتيجة للدالة. إذا كان الوسيط info ليس NULL، فسيتم استخدام الذاكرة المؤقتة التي يشير إليها لإعادة بنية من النوع siginfo_t (انظر sigaction(2)) تحتوي على معلومات حول الإشارة.

إذا كانت هناك عدة إشارات في set معلقة للخيط، فإن الإشارة التي يتم استلامها بواسطة sigwaitinfo() يتم تحديدها وفقًا لقواعد الترتيب المعتادة؛ انظر signal(7) لمزيد من التفاصيل.

sigtimedwait() تعمل بنفس الطريقة تمامًا مثل sigwaitinfo() باستثناء أنها تحتوي على وسيط إضافي، timeout، الذي يحدد الفترة الزمنية التي يعلق فيها الخيط انتظارًا لإشارة. (سيتم تقريب هذه الفترة إلى أعلى مقياس لساعة النظام، وقد تتجاوز التأخيرات في جدولة النواة هذه الفترة بمقدار صغير). هذا الوسيط هو بنية timespec(3).

إذا تم تحديد كلا الحقلين في هذه البنية على أنهما 0، يتم إجراء استطلاع (poll): تعود sigtimedwait() فورًا، إما بمعلومات حول إشارة كانت معلقة للخيط، أو بخطأ إذا لم تكن أي من الإشارات في set معلقة.

قيمة الإرجاع

عند النجاح، تعيد كل من sigwaitinfo() و sigtimedwait() رقم إشارة (أي قيمة أكبر من صفر). عند الفشل، تعيد كلتا الاستدعائين -1، مع تعيين errno للإشارة إلى الخطأ.

الأخطاء

EAGAIN
لم تصبح أي إشارة في set معلقة خلال فترة timeout المحددة لـ sigtimedwait().
EINTR
تم مقاطعة الانتظار بواسطة معالج إشارة؛ انظر signal(7). (كان هذا المعالج لإشارة غير تلك الموجودة في set.)
EINVAL
timeout غير صالح.

الإصدارات

اختلافات مكتبة C/النواة

في Linux، sigwaitinfo() هي وظيفة مكتبة منفذة فوق sigtimedwait().

تتجاهل دوال التغليف glibc الخاصة بـ sigwaitinfo() و sigtimedwait() بصمت محاولات الانتظار للإشارتين الخاصتين بالوقت الحقيقي المستخدمتين داخليًا بواسطة تطبيق الترابط NPTL. انظر nptl(7) للتفاصيل.

كان استدعاء النظام الأصلي في Linux يسمى sigtimedwait(). ومع ذلك، مع إضافة إشارات الوقت الحقيقي في Linux 2.2، لم يعد نوع sigset_t ذي الحجم الثابت والمكون من 32 بت الذي يدعمه استدعاء النظام هذا مناسبًا. نتيجة لذلك، تمت إضافة استدعاء نظام جديد، rt_sigtimedwait()، لدعم نوع sigset_t الموسع. يأخذ استدعاء النظام الجديد وسيطًا رابعًا، size_t sigsetsize، الذي يحدد حجم مجموعة الإشارات بالبايت في set. هذا الوسيط مطلوب حاليًا أن تكون قيمته sizeof(sigset_t) (أو ينتج عنه خطأ EINVAL). تخفي دالة التغليف glibc sigtimedwait() هذه التفاصيل عنا، وتستدعي rt_sigtimedwait() بشفافية عندما توفرها النواة.

المعايير

POSIX.1-2024.

التاريخ

POSIX.1-2001.

ملاحظات

في الاستخدام العادي، يقوم البرنامج المتصل بحظر الإشارات في set عبر استدعاء سابق لـ sigprocmask(2) (بحيث لا يحدث التصرف الافتراضي لهذه الإشارات إذا أصبحت معلقة بين استدعاءات متتالية لـ sigwaitinfo() أو sigtimedwait()) ولا يقوم بإنشاء معالجات لهذه الإشارات. في برنامج متعدد الخيوط، يجب حظر الإشارة في جميع الخيوط، لمنع معالجة الإشارة وفقًا لتصرفها الافتراضي في خيط آخر غير الخيط الذي يستدعي sigwaitinfo() أو sigtimedwait().

مجموعة الإشارات التي تكون معلقة لخيط معين هي اتحاد مجموعة الإشارات المعلقة بشكل خاص لهذا الخيط ومجموعة الإشارات المعلقة للعملية ككل (انظر signal(7)).

يتم تجاهل محاولات الانتظار لـ SIGKILL و SIGSTOP بصمت.

إذا كانت هناك خيوط متعددة للعملية محظورة في انتظار نفس الإشارة (الإشارات) في sigwaitinfo() أو sigtimedwait()، فسيتلقى أحد الخيوط فقط الإشارة إذا أصبحت معلقة للعملية ككل؛ أي من الخيوط التي تتلقى الإشارة غير محدد.

لا يمكن استخدام sigwaitinfo() أو sigtimedwait() لاستقبال الإشارات التي يتم إنشاؤها بشكل متزامن، مثل إشارة SIGSEGV التي تنشأ عن الوصول إلى عنوان ذاكرة غير صالح أو إشارة SIGFPE التي تنشأ عن خطأ حسابي. يمكن فقط التقاط مثل هذه الإشارات عبر معالج الإشارة.

يترك POSIX معنى قيمة NULL لوسيط timeout الخاص بـ sigtimedwait() غير محدد، مما يسمح بإمكانية أن يكون له نفس معنى استدعاء لـ sigwaitinfo()، وهذا بالفعل ما يتم على Linux.

sigwaitinfo(2)

NAME

sigwaitinfo - synchronous and polled notification of signal delivery

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS


#include <signal.h>

int sigwaitinfo(const sigset_t *set, siginfo_t *info);

DESCRIPTION

The sigwaitinfo() function suspends the execution of the calling thread until one of the signals specified in the set pointed to by set is pending for the process. If more than one signal is pending, the signal to be returned is chosen according to the system's signal selection criteria.

If info is not NULL, the system returns detailed information about the delivered signal in the structure pointed to by info. The structure siginfo_t is defined as follows:


typedef struct siginfo {
    int      si_signo;    /* Signal number */
    int      si_errno;    /* Error number */
    int      si_code;     /* Signal code */
    pid_t    si_pid;      /* PID of sending process */
    uid_t    si_uid;      /* Real UID of sending process */
    void     *si_addr;    /* Address at which fault occurred */
    int      si_status;   /* Exit value or signal */
    sigval_t si_value;    /* Signal value */
    int      si_int;      /* Integer signal value */
    sigval_t si_value;    /* Signal value */
    // ... other fields ...
} siginfo_t;

If info is NULL, the detailed information is not returned.

The sigwaitinfo() function is an atomic and interruptible function. If the signal selected is not generated by a system call, sigwaitinfo() will return, and the signal will be returned as the result of the call.

If a signal is generated by a system call, the system call will be restarted.

The set of signals specified by set should not include SIGKILL or SIGSTOP, as these signals cannot be caught or blocked.

RETURN VALUE

On success, sigwaitinfo() returns the number of the signal that was delivered. On failure, it returns -1 and sets errno to indicate the error.

ERRORS

EFAULT

info points to invalid address.

EINTR

The call was interrupted by a signal. This is not possible when using sigwaitinfo(), as sigwaitinfo() waits for signals specified in the set argument.

EINVAL

An invalid set was specified.

VERSIONS

The sigwaitinfo() function first appeared in Linux. It is available since glibc 2.1.

STANDARDS

POSIX.1-2001, POSIX.1-2008.

HISTORY

Linux.

NOTES

The sigwaitinfo() function is a real-time extension. Signal flags such as SA_SIGINFO are ignored when using sigwaitinfo().

When sigwaitinfo() returns, the signal specified by the return value is removed from the process's pending signals. If the signal was selected from the set argument, the signal is also removed from the set of blocked signals.

The sigwaitinfo() function is thread-safe. If multiple threads are blocked in sigwaitinfo() waiting for the same signal, only one thread will return when the signal is delivered.

If sigwaitinfo() is interrupted by a signal that is not specified in set, the call will return -1 with errno set to EINTR.

For a simpler interface to synchronous signal handling, see sigwait(3).
