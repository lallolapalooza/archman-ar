NOTES

الوظائف التي يتم استدعاؤها من معالج إشارة يعمل على مكدس إشارة بديل ستستخدم أيضًا مكدس الإشارة البديل. (هذا ينطبق أيضًا على أي معالجات يتم استدعاؤها لإشارات أخرى بينما يكون الخيط قيد التنفيذ على مكدس الإشارة البديل.) على عكس المكدس القياسي، لا يقوم النظام بتوسيع مكدس الإشارة البديل تلقائيًا. تجاوز الحجم المخصص لمكدس الإشارة البديل سيؤدي إلى نتائج غير متوقعة.

نجاح استدعاء execve(2) يزيل أي مكدس إشارة بديل موجود. يرث الطفل الذي تم إنشاؤه عبر fork(2) نسخة من إعدادات مكدس الإشارة البديل لوالده. وينطبق الشيء نفسه على الطفل الذي تم إنشاؤه باستخدام clone(2)، إلا إذا كانت علامات الاستنساخ تتضمن CLONE_VM ولا تتضمن CLONE_VFORK، وفي هذه الحالة يتم تعطيل أي مكدس إشارة بديل تم إنشاؤه في الوالد في الطفل.

sigaltstack() تحل محل استدعاء sigstack(2) الأقدم. للتوافق مع الإصدارات السابقة، توفر glibc أيضًا sigstack(2). يجب كتابة جميع التطبيقات الجديدة باستخدام sigaltstack().

History

كانت 4.2BSD تحتوي على استدعاء نظام sigstack(). استخدمت بنية مختلفة قليلاً، وكان لها عيب رئيسي وهو أن المتصل كان عليه معرفة اتجاه نمو المكدس.

BUGS

في Linux 2.2 والإصدارات الأقدم، كانت العلامة الوحيدة التي يمكن تحديدها في ss.sa_flags هي SS_DISABLE. في الفترة التي سبقت إصدار نواة Linux 2.4، تم إجراء تغيير للسماح لـ sigaltstack() بالسماح بـ ss.ss_flags==SS_ONSTACK بنفس المعنى مثل ss.ss_flags==0 (أي أن تضمين SS_ONSTACK في ss.ss_flags لا يفعل شيئًا). في التطبيقات الأخرى، ووفقًا لـ POSIX.1، يظهر SS_ONSTACK فقط كعلامة مُبلغ عنها في old_ss.ss_flags. في Linux، لا حاجة أبدًا لتحديد SS_ONSTACK في ss.ss_flags، بل يجب تجنب القيام بذلك لأسباب تتعلق بالقدرة على النقل: تعطي أنظمة أخرى مختلفة خطأ إذا تم تحديد SS_ONSTACK في ss.ss_flags.

EXAMPLES

يوضح مقطع الكود التالي استخدام sigaltstack() (و sigaction(2)) لتثبيت مكدس إشارة بديل تستخدمه معالج لـ SIGSEGV إشارة:


stack_t ss;
ss.ss_sp = malloc(SIGSTKSZ);
if (ss.ss_sp == NULL) {
    perror("malloc");
    exit(EXIT_FAILURE);
}
ss.ss_size = SIGSTKSZ;
ss.ss_flags = 0;
if (sigaltstack(&ss, NULL) == -1) {
    perror("sigaltstack");
    exit(EXIT_FAILURE);
}
sa.sa_flags = SA_ONSTACK;
sa.sa_handler = handler();      /* Address of a signal handler */
sigemptyset(&sa.sa_mask);
if (sigaction(SIGSEGV, &sa, NULL) == -1) {
    perror("sigaction");
    exit(EXIT_FAILURE);
}
