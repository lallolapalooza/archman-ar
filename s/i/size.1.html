size(1)

الحزمة: binutils

التراخيص: GPL-2.0-or-later, GPL-3.0-or-later, LGPL-2.0-or-later, LGPL-3.0-or-later, GFDL-1.3, FSFAP

SIZE(1) أدوات تطوير GNU SIZE(1)

الاسم

size - سرد أحجام الأقسام والحجم الإجمالي للملفات الثنائية

نبذة

size [-A|-B|-G|--format=compatibility]
[--help]
[-d|-o|-x|--radix=number]
[--common]
[-t|--totals]
[--target=bfdname] [-V|--version]
[-f]
[objfile...]

الوصف

يقوم أداة size من GNU بسرد أحجام الأقسام والحجم الإجمالي لكل من الملفات الثنائية objfile الموجودة في قائمة الوسائط الخاصة بها. افتراضيًا، يتم إنشاء سطر إخراج لكل ملف أو لكل وحدة إذا كان الملف عبارة عن أرشيف.

objfile... هي الملفات التي سيتم فحصها. إذا لم يتم تحديد أي ملفات، فسيتم استخدام الملف "a.out" بدلاً من ذلك.

خيارات

خيارات سطر الأوامر لها المعاني التالية:

-A
-B
-G
--format=compatibility
باستخدام أحد هذه الخيارات، يمكنك اختيار ما إذا كان إخراج size من GNU يشبه إخراج size من System V (باستخدام -A، أو --format=sysv)، أو size من Berkeley (باستخدام -B، أو --format=berkeley). الافتراضي هو تنسيق سطر واحد مشابه لـ Berkeley. بدلاً من ذلك، يمكنك اختيار إخراج تنسيق GNU (باستخدام -G، أو --format=gnu)، وهو يشبه تنسيق إخراج Berkeley، ولكن يتم حساب الأحجام بشكل مختلف.

إليك مثال على تنسيق Berkeley (الافتراضي) لإخراج size:

$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

يحسب إخراج نمط Berkeley البيانات للقراءة فقط في عمود "text"، وليس في عمود "data"، ويعرض كل من العمودين "dec" و "hex" مجموع الأعمدة "text" و "data" و "bss" بالأرقام العشرية والسداسية عشرية على التوالي.

يحسب تنسيق GNU البيانات للقراءة فقط في عمود "data"، وليس في عمود "text"، ويعرض فقط مجموع الأعمدة "text" و "data" و "bss" مرة واحدة، في عمود "total". يمكن استخدام الخيار --radix لتغيير قاعدة الأرقام لجميع الأعمدة. إليك نفس البيانات المعروضة باتفاقيات GNU:

$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

هذه هي نفس البيانات، ولكنها معروضة بشكل أقرب إلى اتفاقيات System V:

$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--help
-h
-H
-?
عرض ملخص للحجج والخيارات المقبولة.
-d
-o
-x
--radix=number
باستخدام أحد هذه الخيارات، يمكنك التحكم فيما إذا كان حجم كل قسم معطى بالأرقام العشرية (-d، أو --radix=10)؛ أو الثمانية (-o، أو --radix=8)؛ أو السداسية عشرية (-x، أو --radix=16). في --radix=number، يتم دعم القيم الثلاث (8، 10، 16) فقط. يتم دائمًا إعطاء الحجم الإجمالي بنظامين؛ عشري وسداسي عشري لإخراج -d أو -x، أو ثماني وسداسي عشري إذا كنت تستخدم -o.
--common
طباعة الحجم الإجمالي للرموز المشتركة في كل ملف. عند استخدام تنسيق Berkeley أو GNU، يتم تضمين هذه الرموز في حجم bss.
-t
--totals
عرض الإجماليات لجميع الكائنات المدرجة (وضع تنسيق Berkeley أو GNU فقط).
--target=bfdname
تحديد أن تنسيق رمز الكائن الخاص بـ objfile هو bfdname. قد لا يكون هذا الخيار ضروريًا؛ يمكن لـ size التعرف على العديد من التنسيقات تلقائيًا.
-v
-V
--version
عرض رقم إصدار size.
-f
تم تجاهله. يستخدم هذا الخيار بواسطة إصدارات أخرى من برنامج size، ولكنه غير مدعوم من قبل إصدار GNU Binutils.
@file
قراءة خيارات سطر الأوامر من file. يتم إدراج الخيارات المقروءة بدلاً من خيار @file الأصلي. إذا كان file غير موجود، أو لا يمكن قراءته، فسيتم التعامل مع الخيار حرفيًا، ولن يتم إزالته.

يتم فصل الخيارات في file بالمسافات البيضاء. يمكن تضمين حرف مسافة بيضاء في خيار عن طريق إحاطة الخيار بالكامل بعلامات اقتباس مفردة أو مزدوجة. يمكن تضمين أي حرف (بما في ذلك الشرطة المائلة العكسية) عن طريق وضع البادئة للحرف المراد تضمينه بشرطة مائلة عكسية. قد يحتوي file نفسه على خيارات @file إضافية؛ سيتم معالجة أي خيارات من هذا القبيل بشكل تكراري.

size(1)

الاسم

size - يعرض أحجام أقسام الملفات الكائنية

الملخص

size [-B|-k|-m] [-f format] [-t] [--format=format] [--help] [--target=TARGET] [--traditional] [--version] [--width=width] [-A|--totals] [-o[num]] [-x[num]] [--radix=number] [--wide] [--help] [--version] file...

الوصف

يعرض size حجم الأقسام في كل ملف كائن أو مكتبة. إذا تم تحديد ملف كائني، فإن size يعرض حجم كل قسم في الملف. إذا تم تحديد مكتبة، فإن size يعرض حجم كل ملف كائني في المكتبة.

الناتج الافتراضي هو: 

    text data bss dec hex filename
حيث:
  • text هو حجم قسم النص (الكود).
  • data هو حجم قسم البيانات.
  • bss هو حجم قسم bss (بيانات تم تهيئتها).
  • dec هو مجموع الأقسام الثلاثة بالبايت.
  • hex هو مجموع الأقسام الثلاثة بالتمثيل الست عشري.

تتعرف size على صيغ ملفات الأوبجكت الرئيسية، مثل a.out، وcoff، وelf.

الخيارات

-B, --bytes

يطبع الأحجام بالبايت.

-k, --kilobytes

يطبع الأحجام بالكيلوبايت.

-m, --options

يطبع أسماء الأقسام بالإضافة إلى الأحجام.

-f format, --format=format

يحدد تنسيق الإخراج. يمكن أن يكون التنسيق سلسلة من الأحرف التي تمثل المعلومات المراد عرضها. الأحرف المتاحة هي:

  • n: اسم الملف.
  • s: حجم قسم النص.
  • d: حجم قسم البيانات.
  • b: حجم قسم bss.
  • t: حجم القسم النصي + البيانات + bss (بالعشري).
  • h: حجم القسم النصي + البيانات + bss (بالست عشري).
  • a: حجم جميع الأقسام (بالعشري).
  • A: حجم جميع الأقسام (بالست عشري).

على سبيل المثال، -f "n s d b" سيطبع اسم الملف، وحجم قسم النص، وحجم قسم البيانات، وحجم قسم bss.

-t, --totals

يطبع إجماليات جميع الأقسام.

--target=TARGET

يحدد نوع نظام الملفات الهدف. يستخدم هذا الخيار عندما لا يمكن تحديد نوع نظام الملفات تلقائيًا.

--traditional

يستخدم تنسيق الإخراج التقليدي.

--version

يعرض معلومات الإصدار ويخرج.

--width=width

يحدد عرض الإخراج. يستخدم هذا الخيار مع --wide.

-A, --totals

مثل -t، ولكن يطبع الأحجام بالست عشري.

-o[num], --radix=10[num]

يطبع الأحجام بالأرقام العشرية. الخيار num اختياري.

-x[num], --radix=16[num]

يطبع الأحجام بالأرقام الست عشرية. الخيار num اختياري.

--wide

يطبع الأحجام بالشكل العريض.
