sigtrap(3perl) دليل مبرمجي بيرل sigtrap(3perl)

الاسم

sigtrap - موديول Perl لتمكين معالجة الإشارات البسيطة

الملخص

use sigtrap;
use sigtrap qw(stack-trace old-interface-signals);  # يعادل
use sigtrap qw(BUS SEGV PIPE ABRT);
use sigtrap qw(die INT QUIT);
use sigtrap qw(die normal-signals);
use sigtrap qw(die untrapped normal-signals);
use sigtrap qw(die untrapped normal-signals
                stack-trace any error-signals);
use sigtrap 'handler' => \&my_handler, 'normal-signals';
use sigtrap qw(handler my_handler normal-signals
                stack-trace error-signals);

الوصف

الموديول sigtrap هو واجهة بسيطة لتثبيت معالجات الإشارات. يمكنك جعله يثبت أحد المعالجين اللذين يوفرهما sigtrap نفسه (أحدهما يوفر تتبع مكدس Perl والآخر ببساطة ينفذ die())، أو بالتناوب يمكنك توفير معالج خاص بك لتثبيته. يمكن إخباره بتثبيت معالج فقط للإشارات التي لم يتم التقاطها أو تجاهلها. لديه ثلاث قوائم من الإشارات لالتقاطها، بالإضافة إلى أنه يمكنك توفير قائمة إشارات خاصة بك.

تتم معالجة الوسائط التي تم تمريرها إلى بيان "use" الذي يستدعي sigtrap بالترتيب. عند مواجهة اسم إشارة أو اسم إحدى قوائم إشارات sigtrap، يتم تثبيت معالج على الفور، وعند مواجهة خيار، فإنه يؤثر على المعالجات المثبتة لاحقًا.

خيارات

معالجات الإشارات

تؤثر هذه الخيارات على المعالج الذي سيتم استخدامه للإشارات المثبتة لاحقًا.

stack-trace
المعالج المستخدم للإشارات المثبتة لاحقًا يخرج تتبع مكدس Perl إلى STDERR ثم يحاول تفريغ النواة. هذا هو معالج الإشارة الافتراضي.
die
المعالج المستخدم للإشارات المثبتة لاحقًا يستدعي "die" (في الواقع "croak") برسالة تشير إلى الإشارة التي تم التقاطها.
handler your-handler
سيتم استخدام your-handler كمعالج للإشارات المثبتة لاحقًا. يمكن أن يكون your-handler أي قيمة صالحة عند تعيينها لعنصر في %SIG. انظر perlvar للحصول على أمثلة لوظائف المعالجة.

قوائم الإشارات

لدى sigtrap بعض القوائم المدمجة للإشارات لالتقاطها. وهي:

normal-signals
هذه هي الإشارات التي قد يتوقع البرنامج بشكل طبيعي مواجهتها والتي تتسبب افتراضيًا في إنهائه. وهي HUP، INT، PIPE، و TERM.
error-signals
عادة ما تشير هذه الإشارات إلى مشكلة خطيرة في مترجم Perl أو في النص البرمجي الخاص بك. وهي ABRT، BUS، EMT، FPE، ILL، QUIT، SEGV، SYS، و TRAP.
old-interface-signals
هذه هي الإشارات التي تم التقاطها افتراضيًا بواسطة الواجهة القديمة لـ sigtrap، وهي ABRT، BUS، EMT، FPE، ILL، PIPE، QUIT، SEGV، SYS، TERM، و TRAP. إذا لم يتم تمرير أي إشارات أو قوائم إشارات إلى sigtrap، فسيتم استخدام هذه القائمة.

لكل من هذه القوائم الثلاث، يتم التحقق من مجموعة الإشارات التي تم ضبطها لالتقاطها قبل التقاطها؛ إذا لم تقم بنيتك بتنفيذ إشارة معينة، فلن يتم التقاطها ولكن سيتم تجاهلها بصمت.

أخرى

untrapped
يخبر هذا الرمز sigtrap بتثبيت معالجات فقط للإشارات اللاحقة التي لم يتم التقاطها أو تجاهلها بالفعل.
any
يخبر هذا الرمز sigtrap بتثبيت معالجات لجميع الإشارات اللاحقة. هذا هو السلوك الافتراضي.
signal
يشير أي وسيط يبدو كاسم إشارة (أي، "/^[A-Z][A-Z0-9]*$/") إلى أنه يجب على sigtrap تثبيت معالج لهذا الاسم.
number
يتطلب استخدام الإصدار number على الأقل من sigtrap.

أمثلة

توفير تتبع مكدس للإشارات القديمة:

use sigtrap;

نفس الشيء:

use sigtrap qw(stack-trace old-interface-signals);

توفير تتبع مكدس على الإشارات الأربع المذكورة فقط:

use sigtrap qw(BUS SEGV PIPE ABRT);

الموت عند INT أو QUIT:

use sigtrap qw(die INT QUIT);

الموت عند HUP، INT، PIPE أو TERM:

use sigtrap qw(die normal-signals);

الموت عند HUP، INT، PIPE أو TERM، مع عدم تغيير السلوك للإشارات التي تم التقاطها أو تجاهلها بالفعل:

use sigtrap qw(die untrapped normal-signals);

الموت عند استلام أي من normal-signals التي تم untrapped حاليًا، توفير تتبع مكدس عند استلام any من error-signals:

use sigtrap qw(die untrapped normal-signals
                stack-trace any error-signals);

تثبيت my_handler() كمعالج لـ normal-signals:

use sigtrap 'handler', \&my_handler, 'normal-signals';

تثبيت my_handler() كمعالج لـ normal-signals، توفير تتبع مكدس Perl عند استلام أحد error-signals:

use sigtrap qw(handler my_handler normal-signals
                stack-trace error-signals);
