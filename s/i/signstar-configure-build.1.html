signstar-configure-build(1)

الحزمة: signstar-configure-build

التراخيص: Apache-2.0 OR MIT

signstar-configure-build(1) دليل الأوامر العامة signstar-configure-build(1)

الاسم

signstar-configure-build - واجهة سطر الأوامر لتكوين بناء صور Signstar

الملخص

signstar-configure-build [-c|--config] [-v|--version] [-h|--help]

الوصف

واجهة سطر الأوامر لتكوين بناء صور Signstar

ملاحظة: يجب تشغيل هذا الأمر بصلاحيات المستخدم الجذر (root)!

هذا الملف التنفيذي مخصص للاستخدام لتكوين مستخدمي النظام ذوي الصلة لنظام Signstar أثناء عملية البناء.

يقوم بإنشاء مستخدمي النظام ودمجهم بناءً على ملف تكوين مركزي.

بشكل افتراضي، يتم استخدام أحد ملفات التكوين التالية إذا كان موجودًا، بالترتيب التالي:

- "/usr/local/share/signstar/config.toml"

- "/run/signstar/config.toml"

- "/etc/signstar/config.toml"

إذا لم يتم العثور على أي من الملفات أعلاه، يتم استخدام الموقع الافتراضي "/usr/share/signstar/config.toml". بدلاً من ذلك، يمكن تحديد موقع ملف تكوين مخصص باستخدام الخيار "--config"/"-c".

يتم إنشاء مستخدمي النظام، إذا لم يكونوا موجودين بالفعل، بمساعدة `useradd`. يتم إنشاء المستخدمين بدون كلمة مرور وإعدادهم مع مجلد منزل تحت "/var/lib/signstar/home/". ومع ذلك، لا يتم إنشاء مجلد المنزل الخاص بهم تلقائيًا. يتم بعد ذلك فتح حسابات مستخدمي النظام بمساعدة `usermod`. يتم توفير تكامل tmpfiles.d لكل مستخدم نظام تحت "/usr/lib/tmpfiles.d"، للسماح بالإنشاء التلقائي لمجلد المنزل الخاص بهم.

إذا ربط ملف التكوين المستخدم مستخدم النظام بمفاتيح SSH العامة، يتم إنشاء ملف مخصص "authorized_keys" يحتوي على مفاتيح SSH العامة للمستخدم تحت "/etc/ssh/". بالإضافة إلى ذلك، يتم إنشاء تكوين إسقاط "sshd_config" تحت "/etc/ssh/sshd_config.d/". يفرض هذا التكوين الإسقاط "sshd_config" استخدام "authorized_keys" الخاص بالمستخدم واستخدام أمر معين (أي أحد ["signstar-download-backup", "signstar-download-key-certificate", "signstar-download-metrics", "signstar-download-secret-share", "signstar-download-wireguard", "signstar-sign", "signstar-upload-backup", "signstar-upload-secret-share", "signstar-upload-update"]) اعتمادًا على دور المستخدم.

الخيارات

-c, --config <CONFIG>
المسار إلى ملف تكوين مخصص

إذا تم تحديده، يتم استخدام ملف التكوين المخصص بدلاً من موقع ملف التكوين الافتراضي.

إذا لم يتم تحديده، يتم استخدام أحد ملفات التكوين التالية إذا كان موجودًا، بالترتيب التالي:

- "/usr/local/share/signstar/config.toml"

- "/run/signstar/config.toml"

- "/etc/signstar/config.toml"

إذا لم يتم العثور على أي من الملفات أعلاه، يتم استخدام الموقع الافتراضي "/usr/share/signstar/config.toml".

يمكن أيضًا تحديده باستخدام متغير البيئة SIGNSTAR_CONFIG.
-v, --version
إرجاع اسم وإصدار التطبيق
-h, --help
طباعة المساعدة (عرض ملخص باستخدام '-h')
