الاسم

apptainer-capability-add - إضافة قدرات لمستخدم أو مجموعة (يتطلب الجذر)

ملخص

apptainer capability add [خيارات الإضافة...]

الوصف

إضافة قدرات لينكس لمستخدم أو مجموعة. ملاحظة: يتطلب هذا الأمر الجذر
لتشغيله.

يجب فصل وسيطات القدرات بفواصل وهي غير حساسة لحالة الأحرف
.

لمعرفة القدرات المتاحة، اكتب "apptainer capability avail" أو ارجع إلى
دليل القدرات "man 7 capabilities".

الخيارات

-g, --group="" إدارة القدرات لمجموعة

-h, --help[=false] مساعدة للإضافة

-u, --user="" إدارة القدرات لمستخدم

مثال

  $ sudo apptainer capability add --user nobody AUDIT_READ,chown
  $ sudo apptainer capability add --group nobody cap_audit_write
  لإضافة جميع القدرات لمستخدم:
  $ sudo apptainer capability add --user nobody all
