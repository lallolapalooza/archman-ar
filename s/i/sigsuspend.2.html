NAME

\n

sigsuspend, rt_sigsuspend - wait for a signal

\n
\n
\n

LIBRARY

\n

Standard C library (libc, -lc)

\n
\n
\n

SYNOPSIS

\n
#include <signal.h>
\n
int sigsuspend(const sigset_t *mask);
\n
Feature Test Macro Requirements for glibc (see\n feature_test_macros(7)):\n
\n

sigsuspend():

\n
    _POSIX_C_SOURCE
\n
\n
\n

DESCRIPTION

\n

sigsuspend() temporarily replaces the signal mask of the\n calling thread with the mask given by mask and then suspends the\n thread until delivery of a signal whose action is to invoke a signal handler\n or to terminate a process.

\n

If the signal terminates the process, then sigsuspend() \n does not return. If the signal is caught, then sigsuspend() returns\n after the signal handler returns, and the signal mask is restored to the\n state before the call to sigsuspend().

\n

It is not possible to block SIGKILL or SIGSTOP; \n specifying these signals in mask, has no effect on the thread's\n signal mask.

\n
\n
\n

RETURN VALUE

\n

sigsuspend() always returns -1, with errno set to\n indicate the error (normally, EINTR).

\n
\n
\n

ERRORS

\n
\n
EFAULT
\n
mask points to memory which is not a valid part of the process\n address space.
\n
EINTR
\n
The call was interrupted by a signal; signal(7).
\n
\n
\n
\n

STANDARDS

\n

POSIX.1-2024.

\n
\n
\n

HISTORY

\n

POSIX.1-2001.

\n
\n

C library/kernel differences

\n

The original Linux system call was named sigsuspend().\n However, with the addition of real-time signals in Linux 2.2, the\n fixed-size, 32-bit sigset_t type supported by that system call was no\n longer fit for purpose. Consequently, a new system call,\n rt_sigsuspend(), was added to support an enlarged sigset_t\n type. The new system call takes a second argument, size_t sigsetsize,\n which specifies the size in bytes of the signal set in mask. This\n argument is currently required to have the value sizeof(sigset_t) (or\n the error EINVAL results). The glibc sigsuspend() wrapper\n function hides these details from us, transparently calling\n rt_sigsuspend() when the kernel provides it.

\n
\n
\n
\n

NOTES

\n

Normally, sigsuspend() is used in conjunction with\n sigprocmask(2) in order to prevent delivery of a signal during the\n execution of a critical code section. The caller first blocks the signals\n with sigprocmask(2). When the critical code has completed, the caller\n then waits for the signals by calling sigsuspend() with the signal\n mask that was returned by sigprocmask(2) (in the oldset\n argument).

\n

See sigsetops(3) for details on manipulating signal\n sets.

\n
\n
\n

SEE ALSO

\n

kill(2), pause(2), sigaction(2),\n signal(2), sigprocmask(2), sigwaitinfo(2),\n sigsetops(3), sigwait(3), signal(7)

الاسم

\n

sigsuspend, rt_sigsuspend - انتظار إشارة

\n
\n
\n

المكتبة

\n

مكتبة C القياسية (libc, -lc)

\n
\n
\n

ملخص

\n
#include <signal.h>
\n
int sigsuspend(const sigset_t *mask);
\n
متطلبات ماكرو اختبار الميزة لـ glibc (انظر\n feature_test_macros(7)):\n
\n

sigsuspend():

\n
    _POSIX_C_SOURCE
\n
\n
\n

الوصف

\n

sigsuspend() يستبدل مؤقتًا قناع الإشارة للـ thread المتصل بالقناع المعطى بواسطة mask ثم يعلق الـ thread حتى وصول إشارة يكون إجراءها هو استدعاء معالج إشارة أو إنهاء عملية.

\n

إذا أنهت الإشارة العملية، فإن sigsuspend() لا تعود. إذا تم التقاط الإشارة، فإن sigsuspend() تعود بعد عودة معالج الإشارة، ويتم استعادة قناع الإشارة إلى الحالة التي كانت عليها قبل استدعاء sigsuspend().

\n

لا يمكن حظر SIGKILL أو SIGSTOP؛ تحديد هذه الإشارات في mask، ليس له تأثير على قناع إشارة الـ thread.

\n
\n
\n

قيمة الإرجاع

\n

sigsuspend() تعود دائمًا بـ -1، مع تعيين errno للإشارة إلى الخطأ (عادةً، EINTR).

\n
\n
\n

الأخطاء

\n
\n
EFAULT
\n
mask يشير إلى ذاكرة ليست جزءًا صالحًا من مساحة عنوان العملية.
\n
EINTR
\n
تم مقاطعة الاستدعاء بواسطة إشارة؛ signal(7).
\n
\n

اختلافات مكتبة C / النواة

\n

كان استدعاء النظام الأصلي في Linux يسمى sigsuspend(). ومع ذلك، مع إضافة الإشارات في الوقت الفعلي في Linux 2.2، لم يعد نوع sigset_t ذو الحجم الثابت، 32 بت، المدعوم بواسطة استدعاء النظام هذا مناسبًا للغرض. نتيجة لذلك، تمت إضافة استدعاء نظام جديد، rt_sigsuspend()، لدعم نوع sigset_t موسع. يأخذ استدعاء النظام الجديد وسيطًا ثانيًا، size_t sigsetsize، يحدد حجم مجموعة الإشارات بالبايت في mask. هذا الوسيط مطلوب حاليًا أن يكون له القيمة sizeof(sigset_t) (أو ينتج عنه خطأ EINVAL). الدالة المساعدة sigsuspend() في glibc تخفي هذه التفاصيل عنا، وتستدعي rt_sigsuspend() بشفافية عندما توفرها النواة.

\n
\n
\n
\n

ملاحظات

\n

عادةً، يتم استخدام sigsuspend() بالاقتران مع\n sigprocmask(2) لمنع وصول إشارة أثناء تنفيذ قسم كود حرج. يقوم المتصل أولاً بحظر الإشارات باستخدام sigprocmask(2). عند اكتمال الكود الحرج، ينتظر المتصل بعد ذلك الإشارات عن طريق استدعاء sigsuspend() بالقناع الذي تم إرجاعه بواسطة sigprocmask(2) (في الوسيط oldset).

\n

انظر sigsetops(3) للحصول على تفاصيل حول معالجة مجموعات الإشارات.

\n
\n
