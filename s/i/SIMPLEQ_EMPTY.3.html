NAME

SIMPLEQ_EMPTY, SIMPLEQ_INIT, SIMPLEQ_FINI, SIMPLEQ_ENQUEUE, SIMPLEQ_DEQUEUE, SIMPLEQ_CONCAT, SIMPLEQ_FOREACH, STAILQ_EMPTY, STAILQ_INIT, STAILQ_FINI, STAILQ_ENQUEUE, STAILQ_DEQUEUE, STAILQ_CONCAT, STAILQ_FOREACH, TAILQ_EMPTY, TAILQ_INIT, TAILQ_FINI, TAILQ_ENQUEUE, TAILQ_DEQUEUE, TAILQ_CONCAT, TAILQ_FOREACH, SLIST_EMPTY, SLIST_INIT, SLIST_FINI, SLIST_INSERT_HEAD, SLIST_INSERT_AFTER, SLIST_INSERT_BEFORE, SLIST_REMOVE_HEAD, SLIST_REMOVE, SLIST_REMOVE_AFTER, SLIST_SWAP, LIST_EMPTY, LIST_INIT, LIST_FINI, LIST_INSERT_HEAD, LIST_INSERT_AFTER, LIST_INSERT_BEFORE, LIST_REMOVE_HEAD, LIST_REMOVE, LIST_REMOVE_AFTER, LIST_SWAP, Q_EMPTY, Q_INIT, Q_FINI, Q_ENQUEUE, Q_DEQUEUE, Q_CONCAT, Q_FOREACH, Q_NEXT, Q_PREV, Q_FIRST, Q_LAST, Q_NEXTLEN, Q_PREVLEN —
macros for implementing queues, linked lists, and stacks

LIBRARY

libbsd (for SLIST_* and LIST_* macros),
libcompat (for Q_* macros)

SYNOPSIS

Include <sys/queue.h>.

For the SLIST_* and LIST_* macros, also include <bsd/stdlib.h>.

DESCRIPTION

These macros provide implementations for several types of list and queue data structures. They are very efficient and widely used within the BSD operating systems.

The macros operate on structures that contain list or queue heads and entries. The list/queue head is typically a field within a structure, and the entries are fields within the elements being stored in the list/queue.

For example, a node in a singly linked list might look like this: 

struct mynode {
    struct slist_entry mylist;     /* List entry */
    int data;
};

And the list head: 

struct slist_head mylist_head = SLIST_HEAD_INITIALIZER(mylist_head);

The macros come in several families, each optimized for a different type of list or queue.

Singly-Linked Lists (SLIST_)

These implement singly linked lists. They are efficient for insertions and deletions at the head of the list.

  • SLIST_HEAD(name, type): Defines a list head structure named name for elements of type type.
  • SLIST_HEAD_INITIALIZER(head): Initializes a list head.
  • SLIST_INIT(head): Initializes a list head.
  • SLIST_ENTRY(type): Defines a list entry structure.
  • SLIST_EMPTY(head): Returns true if the list is empty.
  • SLIST_FIRST(head): Returns the first element in the list.
  • SLIST_NEXT(elm, field): Returns the next element after elm.
  • SLIST_FOREACH(var, head, field): Iterates through the list.
  • SLIST_INSERT_HEAD(head, elm, field): Inserts elm at the head.
  • SLIST_INSERT_AFTER(listelm, elm, field): Inserts elm after listelm.
  • SLIST_INSERT_BEFORE(listelm, elm, field): Inserts elm before listelm.
  • SLIST_REMOVE_HEAD(head, field): Removes the first element.
  • SLIST_REMOVE(head, elm, type, field): Removes element elm.
  • SLIST_REMOVE_AFTER(elm, field): Removes the element after elm.
  • SLIST_SWAP(head1, head2, type): Swaps the contents of two lists.
  • SLIST_CONCAT(head1, head2, field): Concatenates head2 to the end of head1.
  • SLIST_FINI(head): Destroys the list head.

Doubly-Linked Lists (LIST_)

These implement doubly linked lists, offering efficient insertion and deletion anywhere in the list.

  • LIST_HEAD(name, type): Defines a list head structure.
  • LIST_HEAD_INITIALIZER(head): Initializes a list head.
  • LIST_INIT(head): Initializes a list head.
  • LIST_ENTRY(type): Defines a list entry structure.
  • LIST_EMPTY(head): Returns true if the list is empty.
  • LIST_FIRST(head): Returns the first element.
  • LIST_LAST(head): Returns the last element.
  • LIST_NEXT(elm, field): Returns the next element.
  • LIST_PREV(elm, field): Returns the previous element.
  • LIST_FOREACH(var, head, field): Iterates through the list.
  • LIST_FOREACH_REVERSE(var, head, field): Iterates through the list in reverse.
  • LIST_INSERT_HEAD(head, elm, field): Inserts at the head.
  • LIST_INSERT_AFTER(listelm, elm, field): Inserts after listelm.
  • LIST_INSERT_BEFORE(listelm, elm, field): Inserts before listelm.
  • LIST_REMOVE_HEAD(head, field): Removes the first element.
  • LIST_REMOVE(elm, field): Removes element elm.
  • LIST_REMOVE_AFTER(elm, field): Removes the element after elm.
  • LIST_SWAP(head1, head2, type): Swaps the contents of two lists.
  • LIST_CONCAT(head1, head2, field): Concatenates head2 to the end of head1.
  • LIST_FINI(head): Destroys the list head.

Simple Queues (SIMPLEQ_)

These implement simple queues, optimized for insertion and deletion at both ends. They are similar to singly linked lists but with specific queue operations.

  • SIMPLEQ_HEAD(name, type): Defines a queue head structure.
  • SIMPLEQ_HEAD_INITIALIZER(head): Initializes a queue head.
  • SIMPLEQ_INIT(head): Initializes a queue head.
  • SIMPLEQ_ENTRY(type): Defines a queue entry structure.
  • SIMPLEQ_EMPTY(head): Returns true if the queue is empty.
  • SIMPLEQ_FIRST(head): Returns the first element.
  • SIMPLEQ_NEXT(elm, field): Returns the next element.
  • SIMPLEQ_FOREACH(var, head, field): Iterates through the queue.
  • SIMPLEQ_ENQUEUE(head, elm, field): Adds an element to the tail.
  • SIMPLEQ_DEQUEUE(head, field): Removes and returns the first element.
  • SIMPLEQ_CONCAT(head1, head2, field): Concatenates head2 to the end of head1.
  • SIMPLEQ_FINI(head): Destroys the queue head.

Tail Queues (STAILQ_)

These implement tail queues, which are similar to simple queues but maintain a pointer to the last element for more efficient additions to the tail.

  • STAILQ_HEAD(name, type): Defines a queue head structure.
  • STAILQ_HEAD_INITIALIZER(head): Initializes a queue head.
  • STAILQ_INIT(head): Initializes a queue head.
  • STAILQ_ENTRY(type): Defines a queue entry structure.
  • STAILQ_EMPTY(head): Returns true if the queue is empty.
  • STAILQ_FIRST(head): Returns the first element.
  • STAILQ_LAST(head, field): Returns the last element.
  • STAILQ_NEXT(elm, field): Returns the next element.
  • STAILQ_FOREACH(var, head, field): Iterates through the queue.
  • STAILQ_FOREACH_REVERSE(var, head, field): Iterates in reverse.
  • STAILQ_ENQUEUE(head, elm, field): Adds an element to the tail.
  • STAILQ_DEQUEUE(head, field): Removes and returns the first element.
  • STAILQ_CONCAT(head1, head2, field): Concatenates head2 to the end of head1.
  • STAILQ_FINI(head): Destroys the queue head.

Tail Queues with Length (TAILQ_)

These are similar to STAILQ_* but also maintain the length of the queue.

  • TAILQ_HEAD(name, type): Defines a queue head structure.
  • TAILQ_HEAD_INITIALIZER(head): Initializes a queue head.
  • TAILQ_INIT(head): Initializes a queue head.
  • TAILQ_ENTRY(type): Defines a queue entry structure.
  • TAILQ_EMPTY(head): Returns true if the queue is empty.
  • TAILQ_FIRST(head): Returns the first element.
  • TAILQ_LAST(head, field): Returns the last element.
  • TAILQ_NEXT(elm, field): Returns the next element.
  • TAILQ_PREV(elm, field): Returns the previous element.
  • TAILQ_FOREACH(var, head, field): Iterates through the queue.
  • TAILQ_FOREACH_REVERSE(var, head, field): Iterates in reverse.
  • TAILQ_ENQUEUE(head, elm, field): Adds an element to the tail.
  • TAILQ_DEQUEUE(head, field): Removes and returns the first element.
  • TAILQ_CONCAT(head1, head2, field): Concatenates head2 to the end of head1.
  • TAILQ_FINI(head): Destroys the queue head.
  • TAILQ_LENGTH(head): Returns the number of elements in the queue.

Generic Queues (Q_)

These are older macros providing similar functionality to the other queue types. Their use is generally discouraged in favor of the more specific and efficient macros.

  • Q_HEAD(name, type): Defines a queue head structure.
  • Q_INIT(head): Initializes a queue head.
  • Q_ENTRY(type): Defines a queue entry structure.
  • Q_EMPTY(head): Returns true if the queue is empty.
  • Q_FIRST(head): Returns the first element.
  • Q_LAST(head): Returns the last element.
  • Q_NEXT(elm, field): Returns the next element.
  • Q_PREV(elm, field): Returns the previous element.
  • Q_FOREACH(var, head, field): Iterates through the queue.
  • Q_ENQUEUE(head, elm, field): Adds an element to the tail.
  • Q_DEQUEUE(head, field): Removes and returns the first element.
  • Q_CONCAT(head1, head2, field): Concatenates head2 to the end of head1.
  • Q_FINI(head): Destroys the queue head.
  • Q_NEXTLEN(head): Returns the number of elements.
  • Q_PREVLEN(head): Returns the number of elements.

RETURN VALUE

Most macros return void. Macros that check for emptiness return a non-zero value if the list/queue is empty, and zero otherwise. Macros that return elements return a pointer to the element.

VERSIONS

The SLIST_*, SIMPLEQ_*, STAILQ_*, and TAILQ_* macros are part of the BSD standard and are available on most Unix-like systems. The LIST_* and SLIST_* macros are available via the libbsd library. The Q_* macros are older and may be deprecated.

BUGS

The macros are powerful but can be confusing to use correctly. Ensure that the field argument to each macro correctly refers to the list/queue entry member within your data structure.

For LIST_* and SLIST_*, the list head and entry types must be compatible.

STANDARDS

These macros are inspired by the BSD operating systems' queue implementation. They are not part of any official POSIX standard but are widely adopted.

HISTORY

The queue macros first appeared in the 4.4BSD-Lite release.

EXAMPLES

The following example demonstrates the use of STAILQ_* macros for a simple tail queue. 

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

/* Define the structure for queue entries */
struct mynode {
    int data;
    STAILQ_ENTRY(mynode) entries; /* Macro defines structure, field name */
};

/* Define the head of the queue */
STAILQ_HEAD(myqueue_head, mynode);

int main() {
    struct myqueue_head head; /* The actual queue head */
    struct mynode *np;      /* Pointer for iterating */
    struct mynode *n1, *n2; /* Pointers for deletion */

    /* Initialize the queue */
    STAILQ_INIT(&head);

    /* Add some elements */
    for (int i = 0; i < 5; ++i) {
        np = malloc(sizeof(struct mynode));
        if (np == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
        np->data = i;
        STAILQ_ENQUEUE(&head, np, entries); /* Add to the tail */
    }

    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head); /* Re-initialize after clearing */

    return 0;
}

Here is an example of using LIST_* macros for a doubly linked list. 

#include <stdio.h>
#include <stdlib.h>
#include <bsd/stdlib.h> /* For LIST_* macros */

/* Define the structure for list entries */
struct list_node {
    int data;
    LIST_ENTRY(list_node) link; /* Macro defines structure, field name */
};

/* Define the head of the list */
LIST_HEAD(my_list_head, list_node);

int main() {
    struct my_list_head head; /* The actual list head */
    struct list_node *np;     /* Pointer for iterating */
    struct list_node *temp;   /* Temporary pointer for removal */

    /* Initialize the list */
    LIST_INIT(&head);

    /* Add some elements */
    for (int i = 0; i < 5; ++i) {
        np = malloc(sizeof(struct list_node));
        if (np == NULL) {
            perror("malloc");
            exit(EXIT_FAILURE);
        }
        np->data = i;
        LIST_INSERT_HEAD(&head, np, link); /* Add to the head */
    }

    /* Forward traversal */
    printf("Forward traversal:\n");
    LIST_FOREACH(np, &head, link)
        printf("%d ", np->data);
    printf("\n");

    /* Backward traversal */
    printf("Backward traversal:\n");
    LIST_FOREACH_REVERSE(np, &head, link)
        printf("%d ", np->data);
    printf("\n");

    /* Deletion */
    printf("Deleting elements:\n");
    while (!LIST_EMPTY(&head)) {
        np = LIST_FIRST(&head);
        printf("Removing %d\n", np->data);
        LIST_REMOVE(np, link); /* Remove the element */
        free(np);
    }

    /* List is now empty */
    if (LIST_EMPTY(&head)) {
        printf("List is empty.\n");
    }

    return 0;
}
