NAME

SIMPLEQ_REMOVE_HEAD, STAILQ_REMOVE_HEAD, SIMPLEQ_REMOVE_TAIL, STAILQ_REMOVE_TAIL, SIMPLEQ_REMOVE, STAILQ_REMOVE, SIMPLEQ_CONCAT, STAILQ_CONCAT - macros for manipulating singly linked lists and tail queues

LIBRARY

Data structures Library (libbsd, libevent, etc.)

SYNOPSIS

#include <sys/queue.h>

void
SIMPLEQ_REMOVE_HEAD(struct simpleq *head, struct simpleq_entry *elm);
void
STAILQ_REMOVE_HEAD(struct stailq *head, struct stailq_entry *elm);
void
SIMPLEQ_REMOVE_TAIL(struct simpleq *head, struct simpleq_entry *elm);
void
STAILQ_REMOVE_TAIL(struct stailq *head, struct stailq_entry *elm);
void
SIMPLEQ_REMOVE(struct simpleq *head, struct simpleq_entry *elm);
void
STAILQ_REMOVE(struct stailq *head, struct stailq_entry *elm);
void
SIMPLEQ_CONCAT(struct simpleq *head1, struct simpleq *head2);
void
STAILQ_CONCAT(struct stailq *head1, struct stailq *head2);

DESCRIPTION

These macros are used to manipulate singly linked lists and tail queues. These data structures are useful for implementing queues, stacks, and other data structures. The macros provided by the <sys/queue.h> header allow for efficient manipulation of these lists.

A singly linked list is a list where each element points to the next element in the list. A tail queue is a doubly linked list where each element points to the next and previous element. The macros provided here are for singly linked lists and tail queues.

The macros provided are:

  • SIMPLEQ_REMOVE_HEAD and STAILQ_REMOVE_HEAD: These macros remove the first element from a singly linked list or tail queue, respectively. The element to be removed is specified by the elm argument.
  • SIMPLEQ_REMOVE_TAIL and STAILQ_REMOVE_TAIL: These macros remove the last element from a singly linked list or tail queue, respectively. The element to be removed is specified by the elm argument.
  • SIMPLEQ_REMOVE and STAILQ_REMOVE: These macros remove a specified element (elm) from a singly linked list or tail queue, respectively.
  • SIMPLEQ_CONCAT and STAILQ_CONCAT: These macros concatenate two singly linked lists or tail queues, respectively. The second list (head2) is appended to the end of the first list (head1).

RETURN VALUE

These macros do not return any values.

VERSIONS

The <sys/queue.h> header and its macros are available in most Unix-like systems, including Linux, BSD, and macOS.

BUGS

There are no known bugs associated with these macros.

STANDARDS

These macros are part of the Berkeley Software Distribution (BSD) queue macros, which are widely adopted but not part of any official POSIX standard.

HISTORY

The queue macros were originally developed for the Berkeley Software Distribution (BSD) operating system.

EXAMPLES

The following example demonstrates how to use STAILQ_REMOVE to remove an element from a tail queue:

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct entry {
    int data;
    struct stailq_entry entries;
};

int main() {
    struct stailq head;
    STAILQ_INIT(&head);

    /* Create and add some elements */
    struct entry *np1 = malloc(sizeof(struct entry));
    np1->data = 10;
    STAILQ_INSERT_TAIL(&head, np1, entries);

    struct entry *np2 = malloc(sizeof(struct entry));
    np2->data = 20;
    STAILQ_INSERT_TAIL(&head, np2, entries);

    struct entry *np3 = malloc(sizeof(struct entry));
    np3->data = 30;
    STAILQ_INSERT_TAIL(&head, np3, entries);

    /* Forward traversal */
    struct entry *np;
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);
                                             /* TailQ deletion */
    struct entry *n1, *n2;
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
