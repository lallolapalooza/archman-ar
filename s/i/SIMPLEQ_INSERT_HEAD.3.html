SIMPLEQ_INSERT_HEAD(3)

NAME

SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_BEFORE, SIMPLEQ_REMOVE, SIMPLEQ_CONCAT, SIMPLEQ_FOREACH, SIMPLEQ_FIRST, SIMPLEQ_LAST, SIMPLEQ_NEXT, SIMPLEQ_PREV, SIMPLEQ_PEEK_HEAD, SIMPLEQ_PEEK_TAIL, SIMPLEQ_INIT, SIMPLEQ_EMPTY — macros for manipulating simple queues

LIBRARY

libutil, -lutil

SYNOPSIS

#include <sys/queue.h>

Simple queue structure definition:

    struct my_queue {
        ...
        SIMPLEQ_ENTRY(my_queue) mq_next; /* Must be named SIMPLEQ_ENTRY(type) */
    };

Queue head definition:

    SIMPLEQ_HEAD(my_queue_head, my_queue);

Operations:

    struct my_queue_head head;
    struct my_queue *np, *n_prev, *n_next;

    SIMPLEQ_INIT(&head);
    np = malloc(sizeof(struct my_queue));
    SIMPLEQ_INSERT_HEAD(&head, np, mq_next);
    SIMPLEQ_INSERT_TAIL(&head, np, mq_next);
    SIMPLEQ_INSERT_AFTER(np, n_next, mq_next);
    SIMPLEQ_INSERT_BEFORE(np, n_prev, mq_next);
    SIMPLEQ_REMOVE(&head, np, my_queue, mq_next);
    SIMPLEQ_CONCAT(&head, &head2);
    SIMPLEQ_FOREACH(np, &head) { ... }
    np = SIMPLEQ_FIRST(&head);
    np = SIMPLEQ_LAST(&head);
    np = SIMPLEQ_NEXT(np, mq_next);
    np = SIMPLEQ_PREV(np, my_queue, mq_next);
    np = SIMPLEQ_PEEK_HEAD(&head);
    np = SIMPLEQ_PEEK_TAIL(&head);
    SIMPLEQ_EMPTY(&head);

DESCRIPTION

These macros provide an implementation of simple singly-linked lists (queues). A simple queue is a list where each element points only to the next element. Simple queues are efficient for adding and removing elements from the head and tail of the list.

The macros are:

  • SIMPLEQ_HEAD(headname, typename);

    Declares a queue head structure named headname for elements of type typename. The structure typename must contain an entry of the form SIMPLEQ_ENTRY(typename);. The entry must be named typenameentry, where typenameentry is the name of the struct member that holds the next pointer. This must be the name used in the SIMPLEQ_ENTRY macro.

    For example:

        struct node {
        int data;
        SIMPLEQ_ENTRY(node) next;
    };
    SIMPLEQ_HEAD(node_list, node);

    This declares a structure `struct node_list` which is a pointer to the first node in the list, and a pointer to the last node in the list.

  • SIMPLEQ_INIT(head);

    Initializes the queue head head to an empty queue.

  • SIMPLEQ_INSERT_HEAD(head, elm, field);

    Inserts the element elm at the head of the queue head. The field argument is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_INSERT_TAIL(head, elm, field);

    Inserts the element elm at the tail of the queue head. The field argument is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_INSERT_AFTER(head, elm, field);

    Inserts the element elm after the element head. The field argument is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_INSERT_BEFORE(head, elm, field);

    Inserts the element elm before the element head. The field argument is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_REMOVE(head, elm, type, field);

    Removes the element elm from the queue head. The type argument is the name of the element structure type, and field is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_CONCAT(head1, head2);

    Appends the queue head2 to the end of the queue head1. Both queues must be of the same type. After the operation, head2 will be empty.

  • SIMPLEQ_FOREACH(var, head);

    A loop that iterates over all elements in the queue head. In each iteration, var is assigned the current element. The loop continues as long as var is not NULL.

  • SIMPLEQ_FIRST(head);

    Returns a pointer to the first element in the queue head, or NULL if the queue is empty.

  • SIMPLEQ_LAST(head);

    Returns a pointer to the last element in the queue head, or NULL if the queue is empty.

  • SIMPLEQ_NEXT(elm, field);

    Returns a pointer to the next element after elm, or NULL if elm is the last element. The field argument is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_PREV(elm, type, field);

    Returns a pointer to the previous element before elm, or NULL if elm is the first element. The type argument is the name of the element structure type, and field is the name of the SIMPLEQ_ENTRY field within the element structure.

  • SIMPLEQ_PEEK_HEAD(head);

    Returns a pointer to the first element in the queue head without removing it, or NULL if the queue is empty.

  • SIMPLEQ_PEEK_TAIL(head);

    Returns a pointer to the last element in the queue head without removing it, or NULL if the queue is empty.

  • SIMPLEQ_EMPTY(head);

    Returns true if the queue head is empty, false otherwise.

RETURN VALUE

The SIMPLEQ_REMOVE macro returns the removed element pointer. The SIMPLEQ_EMPTY macro returns a boolean value.

VERSIONS

These macros first appeared in FreeBSD 3.0.

BUGS

The SIMPLEQ_PREV macro is inefficient as it requires traversing the list from the head to find the previous element.

STANDARDS

The SIMPLEQ_* macros are not part of any standard. They are derived from the list implementation found in FreeBSD.

HISTORY

The simple queue macros were implemented in FreeBSD 3.0.

EXAMPLES

The following example demonstrates how to use the SIMPLEQ_FOREACH macro to traverse a queue and print its elements, and then how to free the memory allocated for the queue elements.

#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>

struct node {
    int data;
    SIMPLEQ_ENTRY(node) entries;
};

int
main(void)
{
    struct node_list {
        struct node *sqh_first; /* first element */
        struct node *sqh_last;  /* last element */
    } head;
    struct node *np, *n2;

    SIMPLEQ_INIT(&head);

    /* Insert some elements */
    for (int i = 0; i < 5; i++) {
        np = malloc(sizeof(struct node));
        np->data = i;
        SIMPLEQ_INSERT_TAIL(&head, np, entries);
    }

    /* Forward traversal */
    STAILQ_FOREACH(np, &head, entries)
        printf("%i\n", np->data);

    /* TailQ deletion */
    n1 = STAILQ_FIRST(&head);
    while (n1 != NULL) {
        n2 = STAILQ_NEXT(n1, entries);
        free(n1);
        n1 = n2;
    }
    STAILQ_INIT(&head);
    exit(EXIT_SUCCESS);
}
