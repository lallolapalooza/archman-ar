sigevent(3type) sigevent(3type)

الاسم

sigevent, sigval - هيكل للإخطار من الروتينات غير المتزامنة

الملخص

#include <signal.h>
struct sigevent {
    int             sigev_notify;  /* نوع الإخطار */
    int             sigev_signo;   /* رقم الإشارة */
    union sigval    sigev_value;   /* البيانات المرسلة مع الإخطار */
    typeof(void (union sigval))  *sigev_notify_function;
                                   /* دالة الإخطار
                                      (SIGEV_THREAD) */
    pthread_attr_t *sigev_notify_attributes;
                                   /* سمات الإخطار */
    /* Linux فقط: */
    pid_t           sigev_notify_thread_id;
                                   /* معرف الخيط الذي سيتم إرسال الإشارة إليه
                                      (SIGEV_THREAD_ID) */
};
union sigval {                     /* البيانات المرسلة مع الإخطار */
    int             sival_int;     /* قيمة صحيحة */
    void           *sival_ptr;     /* قيمة مؤشر */
};

الوصف

sigevent

يتم استخدام هيكل sigevent بواسطة واجهات برمجة التطبيقات المختلفة لوصف الطريقة التي يجب بها إخطار العملية بحدث ما (على سبيل المثال، اكتمال طلب غير متزامن، انتهاء صلاحية مؤقت، أو وصول رسالة).

التعريف المعروض في الملخص هو تقريبي: قد يتم تعريف بعض الحقول في هيكل sigevent كجزء من اتحاد. يجب على البرامج استخدام الحقول ذات الصلة فقط بالقيمة المحددة في sigev_notify.

يحدد الحقل sigev_notify كيفية إجراء الإخطار. يمكن أن يأخذ هذا الحقل أحد القيم التالية:

SIGEV_NONE
إخطار "فارغ": لا تفعل شيئًا عند وقوع الحدث.
SIGEV_SIGNAL
قم بإخطار العملية عن طريق إرسال الإشارة المحددة في sigev_signo.
إذا تم التقاط الإشارة باستخدام معالج إشارات تم تسجيله باستخدام علامة sigaction(2) SA_SIGINFO، فسيتم تعيين الحقول التالية في هيكل siginfo_t الذي يتم تمريره كوسيط ثانٍ للمُعالج:
si_code
يتم تعيين هذا الحقل إلى قيمة تعتمد على واجهة برمجة التطبيقات التي توصل الإخطار.
si_signo
يتم تعيين هذا الحقل إلى رقم الإشارة (أي نفس قيمة sigev_signo).
si_value
يتم تعيين هذا الحقل إلى القيمة المحددة في sigev_value.
اعتمادًا على واجهة برمجة التطبيقات، قد يتم أيضًا تعيين حقول أخرى في هيكل siginfo_t.
تتوفر نفس المعلومات أيضًا إذا تم قبول الإشارة باستخدام sigwaitinfo(2).
SIGEV_THREAD
قم بإخطار العملية عن طريق استدعاء sigev_notify_function "كما لو" كانت دالة بدء خيط جديد. (من بين إمكانيات التنفيذ هنا أن كل إخطار مؤقت يمكن أن يؤدي إلى إنشاء خيط جديد، أو أنه يتم إنشاء خيط واحد لتلقي جميع الإخطارات.) يتم استدعاء الدالة مع sigev_value كوسيط وحيد لها. إذا لم يكن sigev_notify_attributes NULL، فيجب أن يشير إلى هيكل pthread_attr_t يحدد سمات الخيط الجديد (انظر pthread_attr_init(3)).
SIGEV_THREAD_ID (خاص بنظام Linux)
يستخدم حاليًا فقط بواسطة مؤقتات POSIX؛ انظر timer_create(2).

sigval

البيانات المرسلة مع إشارة.

المعايير

POSIX.1-2024.

التاريخ

POSIX.1-2001.

<aio.h> و <time.h> يحددان sigevent منذ POSIX.1-2008.

ملاحظات

توفر الرؤوس التالية أيضًا sigevent: <aio.h>، <mqueue.h>، و <time.h>.
