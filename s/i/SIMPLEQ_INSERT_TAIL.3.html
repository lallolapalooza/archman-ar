STAILQ(3) دليل وظائف المكتبة STAILQ(3)

الاسم

SIMPLEQ_EMPTY, SIMPLEQ_ENTRY, SIMPLEQ_FIRST, SIMPLEQ_FOREACH, SIMPLEQ_HEAD, SIMPLEQ_HEAD_INITIALIZER, SIMPLEQ_INIT, SIMPLEQ_INSERT_AFTER, SIMPLEQ_INSERT_HEAD, SIMPLEQ_INSERT_TAIL, SIMPLEQ_NEXT, SIMPLEQ_REMOVE, SIMPLEQ_REMOVE_HEAD, STAILQ_CONCAT, STAILQ_EMPTY, STAILQ_ENTRY, STAILQ_FIRST, STAILQ_FOREACH, STAILQ_HEAD, STAILQ_HEAD_INITIALIZER, STAILQ_INIT, STAILQ_INSERT_AFTER, STAILQ_INSERT_HEAD, STAILQ_INSERT_TAIL, STAILQ_NEXT, STAILQ_REMOVE, STAILQ_REMOVE_HEAD, - تنفيذ قائمة انتظار ذيلية أحادية الارتباط

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/queue.h>
STAILQ_ENTRY(TYPE);
STAILQ_HEAD(HEADNAME, TYPE);
STAILQ_HEAD STAILQ_HEAD_INITIALIZER(STAILQ_HEAD head);
void STAILQ_INIT(STAILQ_HEAD *head);
int STAILQ_EMPTY(STAILQ_HEAD *head);
void STAILQ_INSERT_HEAD(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_TAIL(STAILQ_HEAD *head,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
void STAILQ_INSERT_AFTER(STAILQ_HEAD *head, struct TYPE *listelm,
                         struct TYPE *elm, STAILQ_ENTRY NAME);
struct TYPE *STAILQ_FIRST(STAILQ_HEAD *head);
struct TYPE *STAILQ_NEXT(struct TYPE *elm, STAILQ_ENTRY NAME);
STAILQ_FOREACH(struct TYPE *var, STAILQ_HEAD *head, STAILQ_ENTRY NAME);
void STAILQ_REMOVE(STAILQ_HEAD *head, struct TYPE *elm, TYPE,
                         STAILQ_ENTRY NAME);
void STAILQ_REMOVE_HEAD(STAILQ_HEAD *head,
                         STAILQ_ENTRY NAME);
void STAILQ_CONCAT(STAILQ_HEAD *head1, STAILQ_HEAD *head2);

ملاحظة: توجد وحدات ماكرو متطابقة مع البادئة SIMPLEQ بدلاً من STAILQ؛ انظر الإصدارات.

الوصف

تعرف وحدات الماكرو هذه وتعمل على قوائم انتظار ذيلية أحادية الارتباط.

في تعريفات وحدات الماكرو، TYPE هو اسم هيكل معرف من قبل المستخدم، يجب أن يحتوي على حقل من النوع STAILQ_ENTRY، اسمه NAME. الوسيط HEADNAME هو اسم هيكل معرف من قبل المستخدم يجب تعريفه باستخدام وحدة الماكرو STAILQ_HEAD().

الإنشاء

تتكون قائمة انتظار ذيلية أحادية الارتباط من هيكل يتم تعريفه بواسطة وحدة الماكرو STAILQ_HEAD(). يحتوي هذا الهيكل على زوج من المؤشرات، واحد يشير إلى العنصر الأول في قائمة الانتظار الذيلية والآخر يشير إلى العنصر الأخير في قائمة الانتظار الذيلية. العناصر مرتبطة بشكل فردي لتقليل مساحة الاستهلاك وتكاليف معالجة المؤشرات للعناصر العشوائية، مقابل تكلفة O(n) للإزالة للعناصر العشوائية. يمكن إضافة عناصر جديدة إلى قائمة الانتظار الذيلية بعد عنصر موجود، في رأس قائمة الانتظار الذيلية، أو في نهاية قائمة الانتظار الذيلية. يتم تعريف هيكل STAILQ_HEAD على النحو التالي:


STAILQ_HEAD(HEADNAME, TYPE) head;

حيث struct HEADNAME هو الهيكل الذي سيتم تعريفه، و struct TYPE هو نوع العناصر التي سيتم ربطها في قائمة الانتظار الذيلية. يمكن بعد ذلك تعريف مؤشر إلى رأس قائمة الانتظار الذيلية على النحو التالي:


struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

تعرف STAILQ_ENTRY() هيكلًا يربط العناصر في قائمة الانتظار الذيلية.

تقوم STAILQ_HEAD_INITIALIZER() بتقييمها إلى مُهيئ لقائمة الانتظار الذيلية head.

تقوم STAILQ_INIT() بتهيئة قائمة الانتظار الذيلية التي يشير إليها head.

تقوم STAILQ_EMPTY() بتقييمها إلى صحيح إذا لم تكن هناك عناصر في قائمة الانتظار الذيلية.

الإدراج

تقوم STAILQ_INSERT_HEAD() بإدراج العنصر الجديد elm في رأس قائمة الانتظار الذيلية.

تقوم STAILQ_INSERT_TAIL() بإدراج العنصر الجديد elm في نهاية قائمة الانتظار الذيلية.

تقوم STAILQ_INSERT_AFTER() بإدراج العنصر الجديد elm بعد العنصر listelm.

التكرار

تعيد STAILQ_FIRST() العنصر الأول في قائمة الانتظار الذيلية أو NULL إذا كانت قائمة الانتظار الذيلية فارغة.

تعيد STAILQ_NEXT() العنصر التالي في قائمة الانتظار الذيلية، أو NULL إذا كان هذا العنصر هو الأخير.

تقوم STAILQ_FOREACH() بالتكرار عبر قائمة الانتظار الذيلية التي يشير إليها head في الاتجاه الأمامي، وتعين كل عنصر بدوره إلى var.

الإزالة

تقوم STAILQ_REMOVE() بإزالة العنصر elm من قائمة الانتظار الذيلية.

تقوم STAILQ_REMOVE_HEAD() بإزالة العنصر في رأس قائمة الانتظار الذيلية. لتحقيق أقصى قدر من الكفاءة، يجب على العناصر التي تتم إزالتها من رأس قائمة الانتظار الذيلية استخدام وحدة الماكرو هذه بشكل صريح بدلاً من وحدة الماكرو العامة STAILQ_REMOVE().

ميزات أخرى

تقوم STAILQ_CONCAT() بدمج قائمة الانتظار الذيلية التي يرأسها head2 في نهاية قائمة الانتظار التي يرأسها head1، مع إزالة جميع الإدخالات من الأولى.

قيمة الإرجاع

تعيد STAILQ_EMPTY() قيمة غير صفرية إذا كانت القائمة فارغة، وصفر إذا كانت القائمة تحتوي على إدخال واحد على الأقل.

تعيد STAILQ_FIRST() و STAILQ_NEXT() مؤشرًا إلى هيكل TYPE الأول أو التالي، على التوالي.

تقوم STAILQ_HEAD_INITIALIZER() بإرجاع مُهيئ يمكن تعيينه إلى head القائمة.

الإصدارات

توفر بعض أنظمة BSD خدمة SIMPLEQ بدلاً من STAILQ. وهما متطابقان، ولكن لأسباب تاريخية كانت تسميتهما مختلفة في أنظمة BSD المختلفة. نشأت STAILQ في FreeBSD، ونشأت SIMPLEQ في NetBSD. لأسباب التوافق، توفر بعض الأنظمة مجموعتي وحدات الماكرو. يوفر glibc كلاً من STAILQ و SIMPLEQ، وهما متطابقان باستثناء عدم وجود مكافئ لـ SIMPLEQ لوحدة STAILQ_CONCAT().

الأخطاء

لا تسمح STAILQ_FOREACH() بإزالة var أو تحريره داخل الحلقة، حيث إن ذلك قد يتعارض مع عملية التكرار. وحدة STAILQ_FOREACH_SAFE()، الموجودة في أنظمة BSD ولكن غير موجودة في glibc، تعالج هذا القيد عن طريق السماح بإزالة var بأمان من القائمة وتحريره من داخل الحلقة دون التأثير على عملية التكرار.

المعايير

BSD.

التاريخ

4.4BSD.

أمثلة

#include <stddef.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/queue.h>
struct entry {
    int data;
    STAILQ_ENTRY(entry) entries;        /* Singly linked tail queue */
};
STAILQ_HEAD(stailhead, entry);
int
main(void)
{
    struct entry *n1, *n2, *n3, *np;
    struct stailhead head;                  /* Singly linked tail queue
                                               head */
    STAILQ_INIT(&head);                     /* Initialize the queue */
    n1 = malloc(sizeof(struct entry));      /* Insert at the head */
    STAILQ_INSERT_HEAD(&head, n1, entries);
    n1 = malloc(sizeof(struct entry));      /* Insert at the tail */
    STAILQ_INSERT_TAIL(&head, n1, entries);
    n2 = malloc(sizeof(struct entry));      /* Insert after */
    STAILQ_INSERT_AFTER(&head, n1, n2, entries);
    STAILQ_REMOVE(&head, n2, entry, entries); /* Deletion */
    free(n2);
    n3 = STAILQ_FIRST(&head);
    STAILQ_REMOVE_HEAD(&head, entries);     /* Deletion from the head */
    free(n3);
    n1 = STAILQ_FIRST(&head);
    n1->data = 0;
    for (unsigned int i = 1; i < 5; i++) {
        n1 = malloc(sizeof(struct entry));
        STAILQ_INSERT_HEAD(&head, n1, entries);
        n1->data = i;
    }
 

    /* Traverse the list */
    printf("The list contains:\n");
    STAILQ_FOREACH(np, &head, entries) {
        printf("Data: %d\n", np->data);
    }
    /* Free allocated memory */
    while (!STAILQ_EMPTY(&head)) {
        np = STAILQ_FIRST(&head);
        STAILQ_REMOVE_HEAD(&head, entries);
        free(np);
    }
    return 0;
}
