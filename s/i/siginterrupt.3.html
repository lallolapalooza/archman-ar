siginterrupt(3) دليل الدوال المكتبية siginterrupt(3)

الاسم

siginterrupt - السماح للإشارات بمقاطعة استدعاءات النظام

المكتبة

مكتبة C القياسية (libc، -lc)

الشكل

#include <signal.h>
[[deprecated]] int siginterrupt(int sig, int flag);
متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

siginterrupt():

    _XOPEN_SOURCE >= 500
        || /* منذ glibc 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _BSD_SOURCE

الوصف

تقوم الدالة siginterrupt() بتغيير سلوك إعادة التشغيل عند مقاطعة استدعاء نظام بواسطة الإشارة sig. إذا كان الوسيط flag خاطئًا (0)، فسيتم إعادة تشغيل استدعاءات النظام إذا تمت مقاطعتها بواسطة الإشارة المحددة sig. هذا هو السلوك الافتراضي في لينكس.

إذا كان الوسيط flag صحيحًا (1) ولم يتم نقل أي بيانات، فسيتم مقاطعة استدعاء النظام وسيُرجع -1 وسيتم تعيين errno إلى EINTR.

إذا كان الوسيط flag صحيحًا (1) وقد بدأت عملية نقل البيانات، فسيتم مقاطعة استدعاء النظام وسيرجع الكمية الفعلية للبيانات التي تم نقلها.

القيمة المرجعة

ترجع الدالة siginterrupt() القيمة 0 عند النجاح. ترجع -1 إذا كان رقم الإشارة sig غير صالح، مع تعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
رقم الإشارة المحدد غير صالح.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
siginterrupt () أمان الخيط MT-Unsafe const:sigintr

المعايير

POSIX.1-2008.

التاريخ

4.3BSD، POSIX.1-2001. مهمل في POSIX.1-2008، يوصى باستخدام sigaction(2) مع العلم SA_RESTART بدلاً منه.
