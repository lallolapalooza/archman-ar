sq-key-userid-add(1)

الحزمة: sequoia-sq

التراخيص: LGPL-2.0-or-later

SQ(1) أوامر المستخدم SQ(1)

الاسم

sq-key-userid-add - إضافة معرف مستخدم

الملخص

sq key userid add [خيارات]

الوصف

إضافة معرف مستخدم.

يمكن لمعرف المستخدم أن يحتوي على اسم، مثل `Juliet`، أو عنوان بريد إلكتروني، مثل `<juliet@example.org>`. تاريخياً، كان الاسم وعنوان البريد الإلكتروني يدمجان عادةً كمعرف مستخدم واحد، مثل `Juliet <juliet@example.org>`. ومع ذلك، فإن معرفات المستخدم التي تتضمن معلومات مختلفة مثل الاسم وعنوان البريد الإلكتروني يصعب التعامل معها، لذا يُفضل استخدام معرفات مستخدم منفصلة للاسم وعنوان البريد الإلكتروني في الوقت الحاضر.

يحترم الأمر `sq key userid add` الوقت المرجعي المحدد بواسطة الوسيطة العليا `--time`. يقوم بتعيين وقت إنشاء توقيع ربط معرف المستخدم إلى الوقت المحدد.

الخيارات

خيارات الأمر الفرعي

--allow-non-canonical-userids
لا ترفض معرفات المستخدم التي ليست بالشكل القانوني
معرفات المستخدم القانونية تكون بالشكل `Name (Comment) <localpart@example.org>`.
--cert=FINGERPRINT|KEYID
إضافة معرف المستخدم إلى المفتاح بالبصمة أو معرف المفتاح المحدد
--cert-email=EMAIL
إضافة معرف المستخدم إلى المفتاح حيث يتضمن معرف المستخدم عنوان البريد الإلكتروني المحدد
--cert-file=PATH
إضافة معرف المستخدم إلى المفتاح المقروء من PATH
--cert-userid=USERID
إضافة معرف المستخدم إلى المفتاح بمعرف المستخدم المحدد
--email=ADDRESS
إضافة عنوان بريد إلكتروني كمعرف مستخدم إلى المفتاح
--name=NAME
إضافة اسم كمعرف مستخدم إلى المفتاح
--output=FILE
الكتابة إلى الملف المحدد FILE
إذا لم يتم تحديده، وتم قراءة الشهادة من مخزن الشهادات، يتم استيراد الشهادة المعدلة إلى مخزن الشهادات. إذا لم يتم تحديده، وتم قراءة الشهادة من ملف، يتم كتابة الشهادة المعدلة إلى الإخراج القياسي.
--userid=USERID
إضافة معرف مستخدم إلى المفتاح
يمكن لمعرف المستخدم هذا دمج الاسم وعنوان البريد الإلكتروني، ويمكن أن يحتوي اختياريًا على تعليق، أو حتى أن يكون نصًا حرًا إذا تم تقديم `--allow-non-canonical-userids`. ومع ذلك، فإن معرفات المستخدم التي تتضمن معلومات مختلفة مثل الاسم وعنوان البريد الإلكتروني يصعب التعامل معها، لذا يُفضل استخدام معرفات مستخدم منفصلة للاسم وعنوان البريد الإلكتروني في الوقت الحاضر.
في حالة الشك، فضل `--name` و `--email`.

الخيارات العامة

راجع sq(1) لوصف الخيارات العامة.

أمثلة

# إضافة معرف مستخدم جديد إلى مفتاح Alice.

sq key userid add --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0 --name Alice \
--email alice@work.example.com
