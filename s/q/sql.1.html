sql(1)

الحزمة: parallel

التراخيص: GPL-3.0-or-later

SQL(1) parallel SQL(1)

الاسم

sql - تنفيذ أمر على قاعدة بيانات محددة بواسطة dburl

الملخص

sql [خيارات] dburl [أوامر]

sql [خيارات] dburl < ملف_الأوامر

#!/usr/bin/sql --shebang [خيارات] dburl

الوصف

يهدف GNU sql إلى توفير واجهة بسيطة وموحدة للوصول إلى قواعد البيانات عبر جميع عملاء سطر الأوامر المختلفين لقواعد البيانات. حتى الآن كان التركيز على توفير طريقة مشتركة لتحديد معلومات تسجيل الدخول (البروتوكول، اسم المستخدم، كلمة المرور، اسم المضيف، ورقم المنفذ)، والحجم (حجم قاعدة البيانات والجدول)، وتشغيل الاستعلامات.

يتم عنونة قاعدة البيانات باستخدام DBURL. إذا تم حذف الأوامر فستحصل على الصدفة التفاعلية لتلك قاعدة البيانات.

غالبًا ما يُستخدم GNU sql بالاقتران مع GNU parallel.

dburl
يكون لـ DBURL الصيغة التالية: [sql:]vendor:// [[user][:password]@][host][:port]/[database][?sqlquery]

انظر قسم DBURL أدناه.

أوامر
أوامر SQL المراد تشغيلها. ستُضاف سطر جديد إلى كل وسيطة.

مثال: "SELECT * FROM foo;" "SELECT * FROM bar;"

إذا كانت الوسيطات تحتوي على '\n' أو '\x0a' فسيتم استبدالها بسطر جديد:

مثال: "SELECT * FROM foo;\n SELECT * FROM bar;"

إذا لم تُعطَ أي أوامر فسيتم قراءة SQL من لوحة المفاتيح أو STDIN.

مثال: echo 'SELECT * FROM foo;' | sql mysql:///

-p تمرير
سيتم إعطاء السلسلة التي تلي -p لبرنامج اتصال قاعدة البيانات كوسيطات. سيتم دمج عدة -p مع مسافة. مثال: تمرير '-U' واسم المستخدم إلى البرنامج:

-p "-U scott" يمكن أيضًا كتابتها -p -U -p scott.

لكي يعمل هذا يجب تعيين --shebang أو -Y كخيار أول.

DBURL

يكون لـ DBURL الصيغة التالية: [sql:]vendor:// [[user][:password]@][host][:port]/[database][?sqlquery]

لاقتباس الأحرف الخاصة استخدم ترميز % المحدد في http://tools.ietf.org/html/rfc3986#section-2.1 (مثلًا كلمة مرور تحتوي على '/' ستحتوي على '%2F').

csv:///%2Ftmp%2Fparallel-bug-56096/mytable csv:////tmp/parallel-bug-56096/mytable mysql://me@/me/ mysql:////

sqlite3:///%2Frun%2Fshm%2Fparallel.db sqlite3:///%2Frun%2Fshm%2Fparallel.db/table sqlite:///%2Ftmp%2Ffile.sqlite?SELECT csv:///%2Ftmp%2Fparallel-CSV/OK csv:///%2Fmust%2Ffail/fail sqlite3:///%2Frun%2Fshm%2Fparallel.db

أمثلة:

mysql://scott:tiger@my.example.com/mydb
influxdb://scott:tiger@influxdb.example.com/foo
sql:oracle://scott:tiger@ora.example.com/xe
postgresql://scott:tiger@pg.example.com/pgdb
pg:///
postgresqlssl://scott@pg.example.com:3333/pgdb
sql:sqlite2:////tmp/db.sqlite?SELECT * FROM foo;
sqlite3:///../db.sqlite3?SELECT%20*%20FROM%20foo;

البائعون المدعومون حاليًا:

  • MySQL (mysql) مع SSL (mysqls, mysqlssl)
  • Oracle (oracle, ora)
  • PostgreSQL (postgresql, pg, pgsql, postgres) مع SSL (postgresqlssl, pgs, pgsqlssl, postgresssl, pgssl, postgresqls, pgsqls, postgress)
  • SQLite2 (sqlite, sqlite2)
  • SQLite3 (sqlite3)
  • InfluxDB 1.x (influx, influxdb) مع SSL (influxdbssl, influxdbs, influxs, influxssl)

يجب أن تبدأ الأسماء المستعارة بـ ':' وتُقرأ من /etc/sql/aliases و ~/.sql/aliases. يجب أن يكون ملف ~/.sql/aliases الخاص بالمستخدم قابلاً للقراءة من قبل المستخدم فقط.

مثال على الأسماء المستعارة:

:myalias1 pg://scott:tiger@pg.example.com/pgdb
:myalias2 ora://scott:tiger@ora.example.com/xe
# Short form of mysql://`whoami`:nopassword@localhost:3306/`whoami`
:myalias3 mysql:///
# Short form of mysql://`whoami`:nopassword@localhost:33333/mydb
:myalias4 mysql://:33333/mydb
# Alias for an alias
:m      :myalias4
# the sortest alias possible
:       sqlite2:////tmp/db.sqlite
# Including an SQL query
:query  sqlite:////tmp/db.sqlite?SELECT * FROM foo;

أمثلة

الحصول على موجه تفاعلي

أبسط استخدام لـ GNU sql هو gاحصل على موجه تفاعلي:

sql sql:oracle://scott:tiger@ora.example.com/xe

إذا قمت بإعداد اسم مستعار يمكنك القيام بما يلي:

sql :myora

تشغيل استعلام

لتشغيل استعلام مباشرة من سطر الأوامر:

sql :myalias "SELECT * FROM foo;"

يتطلب Oracle أسطرًا جديدة بعد كل عبارة. يمكن القيام بذلك على النحو التالي:

sql :myora "SELECT * FROM foo;" "SELECT * FROM bar;"

أو هكذا:

sql :myora "SELECT * FROM foo;\nSELECT * FROM bar;"

نسخ قاعدة بيانات PostgreSQL

لنسخ قاعدة بيانات PostgreSQL استخدم pg_dump لإنشاء النسخة الاحتياطية و GNU sql لاستيرادها:

pg_dump pg_database | sql pg://scott:tiger@pg.example.com/pgdb

إفراغ جميع الجداول في قاعدة بيانات MySQL

باستخدام GNU parallel من السهل إفراغ جميع الجداول دون إسقاطها:

sql -n mysql:/// 'show tables' | parallel sql mysql:/// DELETE FROM {};

إسقاط جميع الجداول في قاعدة بيانات PostgreSQL

لإسقاط جميع الجداول في قاعدة بيانات PostgreSQL قم بما يلي:

sql -n pg:/// '\dt' | parallel --colsep '\|' -r sql pg:/// DROP TABLE {2};

التشغيل كنص برمجي

بدلاً من القيام بما يلي:

sql mysql:/// < sqlfile

يمكنك دمج ملف sql مع DBURL لإنشاء نص برمجي UNIX. أنشئ نصًا برمجيًا يسمى demosql:

#!/usr/bin/sql -Y mysql:///

SELECT * FROM foo;

ثم قم بما يلي:

chmod +x demosql; ./demosql

استخدام --colsep لمعالجة أعمدة متعددة

استخدم --colsep الخاص بـ GNU parallel لفصل الأعمدة:

sql -s '\t' :myalias 'SELECT * FROM foo;' | parallel --colsep '\t' do_stuff {4} {1}

إعادة المحاولة إذا فشل الاتصال

إذا فشل الوصول إلى قاعدة البيانات أحيانًا، يمكن أن يساعد --retries في ضمان نجاح الاستعلام:

sql --retries 5 :myalias 'SELECT * FROM really_big_foo;'

الحصول على معلومات حول نظام قاعدة البيانات قيد التشغيل

إظهار حجم قاعدة البيانات:

sql --db-size :myalias

سرد الجداول:

sql --list-tables :myalias

سرد حجم الجداول:

sql --table-size :myalias

سرد العمليات قيد التشغيل:

sql --show-processlist :myalias

الاعتماديات

يستخدم GNU sql لغة Perl. إذا كان mysql مثبتًا، فستعمل روابط dburls الخاصة بـ MySQL. إذا كان psql مثبتًا، فستعمل روابط dburls الخاصة بـ PostgreSQL. إذا كان sqlite مثبتًا، فستعمل روابط dburls الخاصة بـ SQLite2. إذا كان sqlite3 مثبتًا، فستعمل روابط dburls الخاصة بـ SQLite3. إذا كان sqlplus مثبتًا، فستعمل روابط dburls الخاصة بـ Oracle. إذا كان rlwrap مثبتًا، فسيكون لدى GNU sql سجل أوامر لـ Oracle.
