sql2csv(1)

الحزمة: csvkit

التراخيص: MIT

SQL2CSV(1) csvkit SQL2CSV(1)

الاسم

sql2csv - وثائق sql2csv

الوصف

ينفذ أوامر عشوائية ضد قاعدة بيانات SQL ويخرج النتائج كملف CSV:

usage: sql2csv [-h] [-v] [-l] [-V] [--db CONNECTION_STRING] [--query QUERY]
               [-e ENCODING] [-H]
               [FILE]
تنفيذ استعلام SQL على قاعدة بيانات وإخراج النتيجة إلى ملف CSV.
الوسائط الموضعية:
  FILE                  الملف المستخدم كاستعلام SQL. إذا تم حذف FILE و --query،
                        يتم تمرير البيانات عبر STDIN.
الوسائط الاختيارية:
  -h, --help            إظهار رسالة المساعدة هذه والخروج
  --db CONNECTION_STRING
                        سلسلة اتصال SQLAlchemy للاتصال بقاعدة بيانات.
  --engine-option ENGINE_OPTION ENGINE_OPTION
                        وسيط مفتاح لكلمة مفتاح لـ SQLAlchemy's create_engine()،
                        كزوج مفصول بمسافات. يمكن تحديد هذا الخيار عدة مرات.
                        مثال: thick_mode True
  --execution-option EXECUTION_OPTION EXECUTION_OPTION
                        وسيط مفتاح لكلمة مفتاح لـ SQLAlchemy's
                        execution_options()، كزوج مفصول بمسافات. يمكن
                        تحديد هذا الخيار عدة مرات. مثال: stream_results
                        True
  --query QUERY         استعلام SQL المراد تنفيذه. يتجاوز FILE و STDIN.
  -e ENCODING, --encoding ENCODING
                        تحديد ترميز ملف الاستعلام المدخل.
  -H, --no-header-row   عدم إخراج أسماء الأعمدة.

أمثلة

تحميل بيانات نموذجية في جدول باستخدام csvsql ثم الاستعلام عنها باستخدام sql2csv:

csvsql --db "sqlite:///dummy.db" --tables "test" --insert examples/dummy.csv
sql2csv --db "sqlite:///dummy.db" --query "select * from test"

تحميل بيانات عن المستفيدين من المساعدات المالية إلى PostgreSQL. ثم البحث عن الولايات الثلاث التي حصلت على أكبر قدر، مع تصفية الصفوف الفارغة أيضًا:

createdb recipients
csvsql --db "postgresql:///recipients" --tables "fy09" --insert examples/realdata/FY09_EDU_Recipients_by_State.csv
sql2csv --db "postgresql:///recipients" --query "select * from fy09 where \"State Name\" != '' order by fy09.\"TOTAL\" limit 3"

يمكنك استخدامه حتى كآلة حاسبة SQL بسيطة (في هذا المثال، يتم استخدام قاعدة بيانات SQLite في الذاكرة كافتراضي):

sql2csv --query "select 300 * 47 % 14 * 27 + 7000"

سلسلة الاتصال تقبل المعلمات. على سبيل المثال، لتعيين ترميز قاعدة بيانات MySQL:

sql2csv --db 'mysql://user:pass@host/database?charset=utf8' --query "SELECT myfield FROM mytable"
