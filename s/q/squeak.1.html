الوصف

squeak هي الآلة الافتراضية لنظام Squeak Smalltalk. تتطلب ثلاثة ملفات للعمل بشكل صحيح: ملف صورة يحتوي على 'لقطة شاشة' لجلسة Squeak حية، وملف تغييرات يحتوي على الكود المصدري للطرق المعدلة في الصورة، ونسخة من (أو رابط إلى) ملف مصادر نظام مشترك يحتوي على الكود المصدري للطرق التي لم يتم تعديلها منذ آخر زيادة في الإصدار الرئيسي.

تحتوي ملفات الصورة والتغييرات على حالة جلسة المستخدم في Squeak، والتي تكون دائمة بين الجلسات المتتالية. لذلك، عادة ما تكون النسخ الخاصة من هذه الملفات مطلوبة. يتحقق النص البرمجي inisqueak من أن تثبيت Squeak المحلي يبدو سليمًا، ثم ينسخ الملفات المطلوبة إلى دليل العمل الحالي. إذا لم يواجه inisqueak أي مشاكل، فسينتهي عن طريق تشغيل squeak لبدء جلسة Squeak باستخدام ملفات الصورة والتغييرات المنسوخة حديثًا.

يجب تشغيل inisqueak مرة واحدة، عند استخدام Squeak لأول مرة، لإنشاء جلسة Squeak 'شخصية' جديدة. بعد ذلك، يجب تشغيل squeak في كل مرة سيتم فيها استئناف تلك الجلسة.

الاستدعاء

لا يحتوي inisqueak على خيارات أو معاملات. ببساطة 'cd' إلى الدليل الذي سيحتوي على نسخ العمل لملفات الصورة والتغييرات، ثم قم بتشغيله.

يقبل squeak خيارات مختلفة (موضحة أدناه)، ثم اسم صورة اختياري (يجب ألا يبدأ بعلامة الطرح '-'). إذا تم تقديم اسم صورة في سطر الأوامر، فسيحاول squeak تشغيل تلك الصورة. بخلاف ذلك، يتحقق squeak من متغير البيئة SQUEAK_IMAGE، وإذا تم تعيينه، فإنه يستخدم قيمته كاسم للصورة المراد تشغيلها. بخلاف ذلك، يبحث squeak عن صورة تسمى 'squeak.image' في الدليل الحالي. إذا لم يكن ملف الصورة موجودًا، فسيقوم squeak بطباعة رسالة تشير إلى الملف الذي فشل في العثور عليه ثم يخرج. إذا كان امتداد '.image' مفقودًا في وسيطة الصورة أو في قيمة متغير SQUEAK_IMAGE، فسيتم إلحاقه تلقائيًا.

يمكن أن يتبع وسيطة الصورة اسم نص برمجي. هذا هو اسم 'مستند' يجب أن يحتوي على كود Smalltalk ليتم تنفيذه عند بدء التشغيل. يمكن أن يكون المستند إما اسم ملف أو عنوان URL يبدأ بـ 'http:'. يتم تجاهل أي معاملات تظهر بعد اسم النص البرمجي، ولكن يتم جعلها متاحة للنص البرمجي من داخل Squeak عبر الطريقة getSystemAttribute:. (انظر القسم SCRIPTS أدناه.)

إذا تم تقديم الصورة كـ '--'، فسيقوم squeak بإيقاف معالجة المعاملات فورًا (ويتصرف كما لو لم يتم تحديد الصورة). هذا مفيد لتحديد نص برمجي (ربما مع معاملات نص برمجي) دون تحديد صورة صريحة.

الخيارات

تقع خيارات سطر الأوامر في فئتين: خيارات 'مشتركة' تتعرف عليها الآلة الافتراضية الأساسية وخيارات 'محددة' مرتبطة ببرنامج تشغيل عرض أو صوت معين. سيتم التعرف دائمًا على الخيارات المشتركة بواسطة squeak، بينما سيتم التعرف على خيار محدد معين فقط بعد أن يقوم squeak بتحميل برنامج التشغيل الذي يرتبط به. ارجع إلى خيار '-vm' أدناه لمزيد من التفاصيل.

الخيارات المشتركة التي يتعرف عليها squeak هي كما يلي:

-encoding enc
يحدد الترميز الداخلي للأحرف الذي سيستخدمه Squeak. يؤثر هذا على الترجمة التي تقوم بها الآلة الافتراضية عند استيراد النص (من لوحة المفاتيح أو عبر 'لصق' من تحديد خارجي) أو تصدير النص (لصق النص من Squeak إلى تطبيق آخر، أو عند إنشاء أسماء ملفات تحتوي على أحرف خاصة). بمعنى آخر، يؤثر على العلاقة بين ما يعرضه Squeak على الشاشة وما ترسله إلى (أو تتلقاه من) التطبيقات الخارجية. تعتمد القيمة الصحيحة على طريقة ترميز خطوط Squeak الداخلية. يتم تسليم الصور الحالية بخطوط Macintosh 'New York' التقليدية التي تستخدم ترميز Mac Roman، لذا فهذا هو الترميز الداخلي الافتراضي. إذا تم استيراد خطوط أخرى (من X11 أو غيرها) إلى الصورة واستخدامها كخطوط نظام، فستعطي هذه الترجمة الافتراضية نتائج غير صحيحة للعلامات الصوتية والأحرف الخاصة. في مثل هذه الحالات، يمكن استخدام خيار -encoding لتغيير الترميز الداخلي، على سبيل المثال 
    -encoding ISO-8859-15

(المعروف أيضًا باسم Latin9) والذي سيكون مناسبًا للعديد من الخطوط المصممة للغات الأوروبية.

-help
يطبع ملخصًا موجزًا لبنية سطر الأوامر والخيارات وبرامج التشغيل المتاحة، ثم يخرج.
-memory size[mk]
يطلب تخصيص كومة ثابتة بحجم size بايت للصورة Squeak. إذا تم إعطاء اللاحقة `k'، فإن الوسيطة تعبر عنها بالكيلوبايت. إذا تم إعطاء اللاحقة `m'، فإن الوسيطة تعبر عنها بالميجابايت. يجب *عدم* استخدام هذا الخيار، إلا إذا كان هناك سبب وجيه لذلك، لأنه يضع حدًا تعسفيًا على حجم ذاكرة الكائنات في Squeak.
-mmap size[mk]
يطلب تخصيص كومة متغيرة بحد أقصى size بايت. (اللاحقات كما هو موضح للخيار '-memory'.) سيقوم squeak بتخصيص كومة كبيرة بما يكفي لاحتواء الصورة في البداية، مع مساحة قليلة للزيادة. إذا احتاج Squeak في أي وقت إلى مزيد من الذاكرة لصوره، فسيتم تخصيص مساحة إضافية ديناميكيًا. وبالمثل، عندما لم تعد الذاكرة مطلوبة، سيتم إلغاء تخصيصها وإعادتها إلى النظام. يضع الوسيط size حدًا أعلى لمقدار نمو الكومة بهذه الطريقة. يستخدم squeak كومة ديناميكية افتراضيًا مع الحد الأقصى للحجم المحدد بنسبة 75% من الذاكرة الافتراضية المتاحة أو 1 جيجابايت، أيهما أصغر.
-noevents
يعطل آلية الإدخال الجديدة المعتمدة على الأحداث (الصورة 2.8 وما بعده). هذا الخيار مفيد فقط لاختبار التوافق مع الإصدارات الأقدم من الصور ويجب عدم استخدامه.
-notimer
يعطل استخدام مؤقت الفاصل الزمني لتتبع الوقت المنخفض الدقة. (إذا كنت تواجه مشاكل مع ملفات أو صوت أو اتصالات شبكة تبلغ عن 'مكالمة نظام متوقفة'، فقد يساعد تعيين هذا العلم.)
-pathenc enc
يحدد ترميز الأحرف الخارجي الذي سيستخدمه Squeak عند الوصول إلى نظام الملفات (مسارات الملفات والأدلة). تعتمد القيمة الصحيحة على خصائص المنصة المحلية. إذا كان يجب عدم إجراء أي تحويل ترميز، فيجب تعيين هذا الترميز إلى نفس الترميز الذي يستخدمه Squeak داخليًا (انظر خيار -encoding). بخلاف ذلك، قد يكون ISO-8859-15 (المعروف أيضًا باسم Latin9) منطقيًا على نظام ملفات يدعم أحرف 8 بت، و UTF-8 لأنظمة الملفات التي تستخدم مسارات تعتمد على Unicode. الافتراضي هو UTF-8 وهو صحيح لنظام Mac OS X وتوزيعات GNU/Linux الحديثة جدًا، والذي (في عالم مثالي) سيتم اعتماده في النهاية من قبل جميع متغيرات Unix.
-plugins path
يحدد موقعًا بديلاً للإضافات الخارجية (مجموعات من الأساليب المسماة) وبرامج التشغيل (للعرض والصوت). يحتوي وسيط path على نمط حيث سيتم استبدال أي تكرارات لـ '%n' باسم الإضافة أو برنامج التشغيل الذي يتم تحميله. يمكن أن يحدد path إما دليلًا أو الإضافة نفسها ويمكن أن يكون مطلقًا أو نسبيًا (بالنسبة للدليل الذي تم تشغيل squeak منه). إذا تعذر العثور على إضافة أو برنامج تشغيل في الموقع المحدد بواسطة path، يستمر البحث في المواقع الافتراضية.
-textenc enc
يحدد ترميز الأحرف الخارجي الذي سيستخدمه Squeak عند تبادل نص الحافظة مع تطبيقات أخرى. الافتراضي هو UTF-8 على Mac OS X و ISO-8859-15 (المعروف أيضًا باسم Latin9) على أنظمة Unix الأخرى. لاحظ أن تطبيقات X11 التي تطلب التحديد
tion محوّلة إلى بيانات UTF8_STRING ستتلقى (بشكل صحيح) نص الحافظة مشفرًا بـ UTF-8، بغض النظر عن هذا الإعداد.

يتعرف Squeak على مجموعة فرعية من أسماء الترميز التي حددتها IANA. (إذا كنت تفضل استخدام رمز العملة الدولي بدلاً من رمز اليورو في النص الخارجي، فقد ترغب في ضبط هذا على ISO-8859-1، المعروف أيضًا بـ Latin1.)

-version
يطبع ثلاثة أسطر أو أكثر من معلومات الإصدار، على النحو التالي:
   •
البنية التي تم تكوين الجهاز الظاهري لها وقت التجميع، و"رقم تسلسل التجميع"، ووقت وتاريخ التجميع، واسم (وإصدار، إذا كان معروفًا) المترجم الذي تم استخدامه لتجميع squeak؛
   •
معلومات uname(1) الكاملة للجهاز المضيف الذي تم تجميع الجهاز الظاهري عليه؛
   •
الموقع الافتراضي المثبت للمكونات الإضافية وبرامج التشغيل؛

بعد طباعة ما سبق، سيتم إنهاء الجهاز الظاهري.

-vm driver
يطلب من squeak تحميل برنامج تشغيل للصوت/العرض. لكل جهاز مدعوم، يوجد برنامج تشغيل مقابل يقوم squeak بتحميله أثناء التهيئة. ما لم يُطلب خلاف ذلك، سيحدد squeak برامج تشغيل افتراضية معقولة لتحميلها. يمكن تجاوز هذا الاختيار باستخدام هذا الخيار. الوسيط driver هو قائمة من "تعيينات" واحدة أو أكثر بالشكل

     class=device

مفصولة بمسافات أو فواصل. التركيبات المدعومة حاليًا هي:

   display=X11
لعرض نافذة Squeak على خادم نظام نوافذ X محلي أو بعيد.
   display=Quartz
للعرض على سطح مكتب Mac OS X المحلي.
   display=none
لتعطيل العرض (ولوحة المفاتيح/الفأرة) تمامًا. (هذا البرنامج التشغيل مفيد بشكل أساسي لتشغيل تطبيقات "الخادم" في Squeak.)
   sound=OSS
يوفر إدخال وإخراج الصوت عبر نظام الصوت المفتوح (Open Sound System). (إذا كان لديك جهاز يسمى '/dev/dsp'، فهذا هو الجهاز الذي تريده على الأرجح.)
   sound=MacOSX
يوفر إدخال/إخراج الصوت عبر Core Audio على Mac OS X.
   sound=NAS
يوفر إدخال/إخراج الصوت عبر نظام الصوت الشبكي (Network Audio System).
   sound=Sun
يوفر الصوت على أجهزة Sun Microsystems.
   sound=none
يعطل الصوت تمامًا. لن يحاول squeak تشغيل أو تسجيل الأصوات عند تحميل هذا البرنامج التشغيل.
لاحظ أنه لن تكون متاحة إلا برامج التشغيل ذات الصلة بالجهاز المحلي. سيؤدي محاولة تحميل برنامج تشغيل غير مدعوم إلى إنهاء squeak برسالة خطأ. يتم طباعة قائمة ببرامج التشغيل المتاحة بواسطة الخيار '-help'. إذا فشل برنامج تشغيل معين في تحميل مكتبات النظام التي يعتمد عليها، فلن يتم إدراجه ولن يكون متاحًا للتحميل وقت التشغيل.
لاحظ أيضًا أنه على Mac OS X، يتم دعم كل من برامج تشغيل العرض X11 و Quartz، على الرغم من أن الأول سيرفض التحميل إذا لم تكن مكتبات عميل X11 مثبتة على الجهاز المحلي. سيتم تحميل برنامج تشغيل Quartz بسهولة (وسيعمل Squeak كتطبيق كامل الميزات) حتى عند استدعاء squeak من سطر الأوامر. توخ الحذر عند تسجيل الدخول إلى Mac OS X من جهاز آخر: قد يؤدي نسيان تعيين DISPLAY قبل محاولة تشغيل squeak على العرض البعيد إلى إحراج.

الخيارات الخاصة ببرنامج تشغيل العرض X11 هي كما يلي:

-browserWindow id
يحدد معرف النافذة التي يجب أن يستخدمها squeak للعرض. هذا الخيار مخصص للاستخدام عندما يعمل Squeak كإضافة متصفح ويب.
-display server
يحدد أن Squeak يجب أن يتصل بخادم العرض server المحدد بدلاً من البحث في متغير البيئة DISPLAY (السلوك الافتراضي) للعثور على اسم الخادم المراد استخدامه.
-cmdmod N
يخبر الجهاز الظاهري بتعيين مفتاح التعديل N على لوحة المفاتيح إلى رمز التعديل الذي تتوقعه الصورة لمفتاح Command.
-optmod N
يخبر الجهاز الظاهري بتعيين مفتاح التعديل N على لوحة المفاتيح إلى رمز التعديل الذي تتوقعه الصورة لمفتاح Option.
-compositioninput
يُمكّن دعم نافذة تراكب يتم فيها تكوين أحرف فردية (مثل اليابانية hiragana) قبل تفسيرها كحرف واحد (مثل اليابانية kanji) بواسطة الصورة.
-xicfont font
يخبر الجهاز الظاهري باستخدام الخط المسمى داخل نافذة تراكب التكوين.
-fullscreen
يجعل نافذة Squeak تشغل أكبر قدر ممكن من مساحة الشاشة. يتضمن '-notitle'.
-headless
يعطل العرض الرسومي وإدخال الفأرة/لوحة المفاتيح. وضع التشغيل هذا مفيد بشكل أساسي للخوادم.
-iconic
يطلب من مدير النوافذ تصغير نافذة Squeak عند بدء التشغيل.
-lazy
يجعل Squeak "يغفو" كلما تم إلغاء ربط النافذة الرئيسية. يمكن استخدام هذا إذا بدا أن Squeak يستهلك وقت المعالج أثناء عدم النشاط (وهو ما لا ينبغي أن يحدث عادة). لاحظ أنه إذا كان هذا الخيار ساري المفعول، فعند إلغاء ربط نافذة Squeak، لن يستجيب squeak لأي محفزات خارجية (بخلاف توفير تحديد X للأطراف الطالبة، عندما يكون Squeak هو المالك).
-mapdelbs
يعين مفتاح الحذف (Delete) إلى مفتاح المسافة الخلفية (Backspace). يحذف المسافة الخلفية الحرف الموجود على يسار المؤشر، ويحذف الحذف عادةً الحرف الموجود على يمين المؤشر. مع هذا الخيار، سيعمل الحذف مثل المسافة الخلفية. لا يتغير سلوك المسافة الخلفية.
-noxdnd
يعطل دعم بروتوكول السحب والإفلات لـ X.
-nointl
يعطل التعامل مع المفاتيح الميتة على لوحات المفاتيح الدولية. بدون هذا الخيار، يتم تمكين التعامل مع المفاتيح الميتة إذا تم تعيين LC_ALL أو LC_CTYPE في البيئة.
-notitle
يعطل شريط العنوان على نافذة Squeak (إذا كان مدير النوافذ يدعمه). يتم تضمين هذا الخيار بواسطة '-fullscreen'.
-swapbtn
يبدل بين الزرين الأصفر والأزرق. (تقليديًا، الزر الأحمر على اليسار، والأصفر في المنتصف، والأزرق على اليمين. تأتي الأسماء الملونة من Xerox Alto حيث تم تطبيق Smalltalk لأول مرة.) عادةً ما يقوم Squeak بتعيين أزرار X 1 و 2 و 3 إلى الأزرار الحمراء و الصفراء و الزرقاء، بهذا الترتيب. مع هذا الخيار، يقوم بتعيين أزرار X 1 و 2 و 3 إلى الأزرار الحمراء و الزرقاء و الصفراء.)
-xasync
يجعل Squeak يستخدم تحديثات العرض غير المتزامنة. عادةً ما يقوم الجهاز الظاهري بمسح وتزامن اتصال العرض على فترات منتظمة. يؤدي استخدام هذا الخيار إلى تعطيل المزامنة، والتي سيتم إجراؤها فقط عندما يطلبها المشهد صراحة.
-xshm
يُمكّن استخدام امتداد ذاكرة X المشتركة على الخوادم التي تدعمه. يمكن أن يحسن هذا بشكل كبير أداء العرض، ولكنه يعمل فقط عندما يعمل Squeak على الخادم.

الخيارات الخاصة ببرنامج تشغيل العرض FBDev هي كما يلي:

-fbdev device
استخدم جهاز إطار التخزين المحدد device بدلاً من الافتراضي '/dev/fb0'.
-kbmap mapfile
قم بتحميل خريطة لوحة المفاتيح من ملف الخريطة المحدد mapfile بدلاً من قراءتها من النواة قيد التشغيل. لاحظ أن squeak لا يمكنه (حاليًا) قراءة الملفات المضغوطة أو "المختصرة" (كما هو موجود في /usr/share/keymaps أو /lib/kbd/keymaps). لإنشاء ملف خريطة مفاتيح قابل للاستخدام بواسطة squeak، قم بتنفيذ البرنامج التالي من الوحدة الطرفية:

    dumpkeys -f -n --keys-only > key.map

إذا واجه squeak مشكلة أثناء محاولة تحميل mapfile، فسيطبع رسالة خطأ ويخرج. انظر keymaps(5) لمزيد من المعلومات حول تنسيق ملف خريطة المفاتيح. يمكن استخدام البرامج dumpkeys(1) و loadkeys(1) و showkey(1) لتعديل خريطة لوحة المفاتيح قبل إنشاء ملف خريطة مفاتيح لـ squeak.

-msdev device
استخدم جهاز الفأرة المحدد device بدلاً من الافتراضي. الافتراضي هو محاولة '/dev/psaux' و '/dev/input/mice' و '/dev/adbmouse'، بهذا الترتيب، واستخدام أول جهاز تم العثور عليه متصل بجهاز فعلي.
-msproto protocol
استخدم بروتوكول الفأرة المحدد protocol بدلاً من الافتراضي. البروتوكولات المدعومة هي 'ps2' و 'adb'. الافتراضي هو 'ps2' للفئران المتصلة بـ '/dev/psaux' أو '/dev/input/mice'، و 'adb' للفئران المتصلة بـ '/dev/adbmouse'.
-vtlock
يمنع تبديل VT، بغض النظر عما إذا كان الطلب يأتي من لوحة المفاتيح أو من برنامج آخر مثل chvt(1).
-vtswitch
يمكّن تبديل VT بلوحة المفاتيح. لاحظ أن هذا الخيار معطل فعليًا إذا كان خيار '-vtlock' ممكّنًا أيضًا.

OPTIONS

The squeak command takes the following options:

-vm vm-name
Specifies the virtual machine executable to use. If not given, then squeak will search the default locations for a suitable VM.
-vmargs ...
Passes the arguments ... to the virtual machine executable. This option should be used with care, as the virtual machine may not understand the arguments that you pass to it.
-heapsize size[k|m]
Sets the initial size of the Squeak heap (object memory). The default size is 64 megabytes. The optional suffix 'k' or 'm' indicates that the size is in kilobytes or megabytes, respectively.
-path path
Adds path to the Squeak search path. This path will be searched for image files, sources files and plugins. Multiple '-path' options can be given.
-userpath path
Adds path to the Squeak search path for user-specific files. This path is searched for image files, sources files and plugins, after any paths specified using the '-path' option. Multiple '-userpath' options can be given.
-plugins path
Adds path to the Squeak search path for plugins. Multiple '-plugins' options can be given.
-display dpy
Use display dpy. This is equivalent to setting the DISPLAY environment variable.
-fullscreen
Run Squeak in fullscreen mode.
-iconic
Start Squeak in iconic (minimized) mode.
-geometry WxH
Set the initial window size to width W and height H.
-vmarguments ...
Arguments passed to the VM. Obsolete, use -vmargs.
-imagestats
Print image statistics on exit.
-noimagestats
Do not print image statistics on exit.
-grab
Grab the keyboard and mouse.
-nograb
Do not grab the keyboard and mouse.
-noisy
Enable debugging messages from the VM.
-quiet
Disable debugging messages from the VM.
-encoding name
Use name as the internal character encoding. The default is usually "unicode".
-textenc name
Use name as the character encoding for copying/pasting text to/from external applications.
-pathenc name
Use name as the character encoding for constructing file and directory names.
-locale locale-name
Use locale-name to set the locale, which affects things like date and time formatting.
-kbmap keymap-name
Use keymap-name as the keyboard map for console input.
-msdev device-name
Use device-name as the mouse device for console input.
-msproto protocol-name
Use protocol-name as the mouse protocol for console input.
-fbdev device-name
Use device-name as the framebuffer device for console display.
-nosound
Disable sound support.
-nomixer
Disable the mixer.
-nosyslog
Do not send messages to syslog.
-vtlock
Lock the virtual terminal.
-vtswitch
Allow switching away from the virtual terminal.
-mapdelbs
Map the Delete key to Backspace.
-swapbtn
Swap the mouse buttons.
-xshm
Use the X shared memory extension.
-xasync
Use asynchronous X events.
-xicfont fontname
Use fontname for the X Input Context (composition overlay) font.
-compositioninput
Enable X Input Context (composition overlay).
-headless
Run without a display server. Useful for servers or batch processing.
-nodisplay
Run without any display.
-noevents
Do not process X events.
-nointl
Disable international keyboard support.
-notimer
Disable timer events.
-notitle
Do not display the window title bar.
-x11
Use the X11 display driver.
-quartz
Use the Quartz display driver (macOS only).
-help
Print a help message and exit.
-version
Print version information and exit.

The following options are specific to the ALSA sound driver:

-capture device
Use the named input device for sound capture.
-playback device
Use the named output device for sound playback.

Several common options are deprecated and are provided only for backward compatibility. These options should not be used and will be removed in a future release:

-display dpy
is equivalent to '-vm display=X11 -display dpy'.
-headless
is equivalent to '-vm display=X11 -headless'.
-nodisplay
is equivalent to '-vm display=none'.
-nosound
is equivalent to '-vm sound=none'.
-quartz
is equivalent to '-vm display=Quartz'.

Many of the options that can be set on the command line can also be set from environment variables.

SQUEAK_ASYNC
if set in the environment then equivalent to the '-xasync' flag. (The value is ignored.)
SQUEAK_CAPTURE
see '-capture'.
SQUEAK_COMPOSITIONINPUT
if set in the environment then equivalent to the '-compositioninput' flag. (The value is ignored.)
SQUEAK_ENCODING
the name of the internal character encoding used by Squeak. Equivalent to giving the '-encoding' command-line option if set.
SQUEAK_FBDEV
the name of the framebuffer device to use when running on the console. See the '-fbdev' option.
SQUEAK_FULLSCREEN
equivalent to '-fullscreen' if set.
SQUEAK_ICONIC
equivalent to the '-iconic' flag.
SQUEAK_IMAGE
the name of the image file to execute if no image argument is given on the command line.
SQUEAK_KBMAP
the name of the keymap file to use when running on the console. See the '-kbmap' option.
SQUEAK_LAZY
equivalent to the '-lazy' flag.
SQUEAK_MAPDELBS
equivalent to the '-mapdelbs' flag.
SQUEAK_MEMORY
the initial size of the heap, with optional 'k' or 'm' suffix. Equivalent to the '-memory size[km]' flag.
SQUEAK_MSDEV
the name of the mouse device to use when running on the console. See the '-msdev' option.
SQUEAK_MSPROTO
the name of the mouse protocl to use when running on the console. See the '-msproto' option.
SQUEAK_VTLOCK
if set then equivalent to specifying the '-vtlock' option on the command line.
SQUEAK_VTSWITCH
if set then equivalent to specifying the '-vtswitch' option on the command line.
SQUEAK_NOEVENTS
if set, equivalent to '-noevents'.
SQUEAK_NOINTL
equivalent to '-nointl' if set.
SQUEAK_NOMIXER
equivalent to '-nomixer' if set.
SQUEAK_NOTIMER
equivalent to '-notimer' if set.
SQUEAK_NOTITLE
if set, equivalent to '-notitle'.
SQUEAK_PATHENC
the name of the character encoding used to construct file and directory names. Equivalent to giving the '-pathenc' command-line option if set.
SQUEAK_PLAYBACK
see '-playback'.
SQUEAK_PLUGINS
see '-plugins'.
SQUEAK_SWAPBTN
equivalent to '-swapbtn' if set.
SQUEAK_TEXTENC
the name of the character encoding used to copy/paste text from/to external applications. Equivalent to giving the '-textenc' command-line option if set.
SQUEAK_VM
contains the names of one or more drivers to be loaded during initialisation. See the '-vm' option for details.
SQUEAK_XICFONT
if set in the environment then it provides a default name for the composition overlay font; see the '-xicfont' flag.
SQUEAK_XSHM
equivalent to '-xshm'.

If an environment variable and a command-line option conflict over a particular value then normally the value in the command line takes precedence. The exception to this rule is the '-vm' option. Environment variables are processed before command-line arguments and '-vm' cannnot be used to unload a driver that was loaded while processing the contents of 'SQUEAK_VM'.

squeak also checks the environment for LC_ALL and LC_CTYPE. If either of these variables is set then support for international keyboards (including dead keys for diacritical marks) is enabled. To prevent this support being enabled even when one or both of these variables is set, use the '-nointl' option (or set SQUEAK_NOINTL in the environment). For example, to start squeak with support for dead keys on Spanish keyboards, with Latin-1 encoding of external characters and the default MacRoman internal font encoding, run squeak like this:

export LC_CTYPE=es_ES
export SQUEAK_TEXTENC=latin1
squeak

SCRIPTS

Squeak can load and execute a 'script' file containing Smalltalk code at startup. The name of the file should be given as the script argument to squeak. For example, assuming that the image 'foo.image' contains an open Transcript window, then the following represents the 'hello world' program for Squeak:

Transcript cr; show: 'Hello, world'.

If this script is in a file called 'hello.sq', then it could be run like this:

squeak foo.image hello.sq

It is also possible to make 'self interpreting' scripts by adding an 'interpreter line' to the start of the script. The 'hello.sq' file could be changed to

#!/usr/bin/squeak --
Transcript cr; show: 'Hello, world'.

and then made executable with

chmod +x hello.sq

and then invoked by running the script file directly:

SQUEAK_IMAGE="foo.image"
export SQUEAK_IMAGE
./hello.sq

If any arguments are present after the script name then they can be retrieved from within the script using the method

Smalltalk getSystemAttribute: 
n

where n is the index of the argument, starting at 3 for the first argument. (See the method comment for

SystemDictionary>>getSystemAttribute:

in the image for an explanation of the meanings of the indices.)

As an example of this, here is the 'echo' program written as a Squeak script:

#!/usr/bin/squeak --
"Echo arguments to the Transcript."
| i a |
i := 2.
[(a := Smalltalk getSystemAttribute: (i := i + 1))
    notNil]
  whileTrue: [Transcript space; show: a].

When run as

./echo.sq one two three

this would print 'one two three' in the Transcript window.

DIAGNOSTICS

inisqueak
prints several informational messages while doing its stuff. If it encounters a problem it prints an appropriate message before bailing out. The messages should be self-explanatory.
squeak
normally does not print anything at all. If it prints something then there is a problem. The messages should be self-explanatory.
