sq-key - إدارة المفاتيح

الموجز

sq key list [خيارات] بصمة/معرف المفتاح/نمط
sq key generate [خيارات]

الوصف

إدارة المفاتيح.

نستخدم مصطلح "مفتاح" للإشارة إلى مفاتيح OpenPGP التي تحتوي على أسرار. يوفر هذا الأمر الفرعي أساسيات لتوليد المفاتيح والتلاعب بها.

على العكس من ذلك، نستخدم مصطلح "شهادة" أو "شهادة" اختصارًا، للإشارة إلى مفاتيح OpenPGP التي لا تحتوي على أسرار. انظر `sq cert` لعمليات على الشهادات.

الأوامر الفرعية

sq key list

قائمة المفاتيح التي تديرها مخزن المفاتيح.

sq key generate

توليد مفتاح جديد.

يعد توليد المفتاح شرطًا مسبقًا لاستقبال الرسائل المشفرة وإنشاء التواقيع. هناك عدد قليل من المعلمات لهذه العملية، لكننا نقدم افتراضيات معقولة لمعظم المستخدمين.

عند توليد مفتاح، نقوم أيضًا بتوليد شهادة إلغاء طارئة. يمكن استخدامها في حالة فقدان المفتاح أو اختراقه. يتم حفظها بجانب المفتاح. يمكن تغيير ذلك باستخدام الوسيطة `--rev-cert`.

بشكل افتراضي، تنتهي صلاحية المفتاح بعد 3 سنوات. يمكن تغيير ذلك باستخدام الوسيطة `--expiration`.

يحترم `sq key generate` وقت المرجع المحدد بواسطة الوسيطة العليا `--time`. تحدد هذه الوسيطة وقت إنشاء المفتاح الأساسي، وجميع المفاتيح الفرعية، وتواقيع الربط إلى وقت المرجع.

sq key rotate

تدوير شهادة.

ينشئ شهادة جديدة لاستبدال شهادة موجودة.

ستمتلك الشهادة الجديدة نفس إمكانيات الشهادة القديمة. يمكن تجاوز ذلك باستخدام الوسائط `--can-sign`، `--cannot-sign`، إلخ. ملاحظة: قد يكون للشهادة الجديدة شكل مختلف عن الشهادة القديمة. على سبيل المثال، إذا تم تمييز المفتاح الأساسي للشهادة القديمة على أنه قادر على التصديق والتوقيع، فإن المفتاح الأساسي للشهادة الجديدة سيكون قادرًا على التصديق، وسيكون لديه مفتاح فرعي للتوقيع.

بشكل افتراضي، تنتهي صلاحية الشهادة بعد 3 سنوات. يمكن تغيير ذلك باستخدام الوسيطة `--expiration`.

ستمتلك الشهادة الجديدة نفس معرفات المستخدم الموقعة ذاتيًا مثل الشهادة القديمة. يتم تجاهل معرفات المستخدم الملغاة.

ستقوم الشهادة الجديدة والشهادة القديمة بالتصديق المتبادل على بعضهما البعض كمعرفين موثوقين غير مقيدين.

سيتم ربط الشهادة الجديدة بنفس طريقة ربط الشهادة القديمة. يمكن تجاوز ذلك باستخدام الوسيطة `--own-key`، أو الوسيطة `--shared-key`.

ستقوم الشهادة الجديدة بالتصديق على نفس الشهادات التي صدقت عليها الشهادة القديمة. أي، سيتم إعادة تشغيل تصديقات الشهادة القديمة. انظر `sq pki vouch replay` لمزيد من المعلومات.

سيتم إصدار شهادة إلغاء تشير إلى أن الشهادة القديمة تم سحبها، ويجب استخدام الشهادة الجديدة بدلاً منها. افتراضيًا، ستدخل حيز التنفيذ في غضون 182 يومًا. يمكن تغيير ذلك أو كبحه باستخدام الوسيطة `--retire-in`.

عند استخدام `--output`، يتم كتابة الشهادة الجديدة وجميع الشهادات المحدثة الأخرى إلى الملف المحدد.

مستقر منذ 1.2.0.

sq key import

استيراد المفاتيح إلى مخزن المفاتيح.

sq key export

تصدير المفاتيح من مخزن المفاتيح.

يصدر مواد المفتاح السري المرتبطة بشهادة. لاحظ أنه حتى لو كانت مواد المفتاح السري متاحة، فقد لا يمكن تصديرها. على سبيل المثال، عادةً ما لا يمكن تصدير مواد المفتاح السري المخزنة على وحدة أمان الأجهزة من الجهاز.

التكرار عبر جميع الشهادات المحددة وتصدير أي مفاتيح (المفتاح الأساسي والمفاتيح الفرعية) التي تحتوي على مواد مفتاح سري. يتم إرجاع خطأ إذا كانت أي شهادة محددة لا تحتوي على أي مواد مفتاح سري.

إذا كنت ترغب فقط في تصدير مفتاح معين وليس جميع المفاتيح المرتبطة بشهادة، استخدم `sq key subkey export`.

sq key delete

حذف مواد المفتاح السري لشهادة.

sq key password

تغيير كلمة المرور التي تحمي مواد المفتاح السري.

يمكن حماية مواد المفتاح السري بكلمة مرور. يغير هذا الأمر الفرعي كلمة المرور أو يمسحها.

لإزالة كلمة المرور، استخدم `--clear` أو قم بتوفير كلمة مرور بطول صفر عند المطالبة بكلمة المرور الجديدة.

إذا كان المفتاح محميًا بكلمة مرور، ولم يتم توفير كلمة المرور الصحيحة باستخدام الوسيطة `--password-file`، فسيتم مطالعة المستخدم بكلمة المرور. وبالمثل، إذا لم يتم توفير كلمة المرور الجديدة، فسيتم مطالعة المستخدم.

sq key expire

تغيير وقت انتهاء صلاحية الشهادة.

يغير هذا الأمر الفرعي وقت انتهاء صلاحية الشهادة. لتغيير وقت انتهاء صلاحية مفتاح فرعي فردي، استخدم الأمر الفرعي `sq key subkey expire`.

sq key revoke

إلغاء شهادة.

ينشئ شهادة إلغاء لشهادة.

إذا تم توفير `--revoker` أو `--revoker-file`، فسيتم استخدام هذا المفتاح لإنشاء شهادة الإلغاء. إذا كان هذا المفتاح مختلفًا عن الشهادة التي يتم إلغاؤها، فسينتج عن ذلك إلغاء من طرف ثالث. يكون هذا عادةً مفيدًا فقط إذا كان مالك الشهادة قد عين المفتاح كمفتاح إلغاء معين.

يحترم `sq key revoke` وقت المرجع المحدد بواسطة الوسيطة العليا `--time`. عند تحديده، فإنه يستخدم الوقت المحدد بدلاً من الوقت الحالي عند تحديد المفاتيح الصالحة، ويحدد وقت إنشاء شهادة الإلغاء بدلاً من الوقت الحالي.

sq key userid

إدارة معرفات المستخدم.

إضافة معرفات المستخدم إلى مفتاح، أو إلغاؤها.

sq key subkey

إدارة المفاتيح الفرعية.

إضافة مفاتيح فرعية جديدة إلى شهادة موجودة، وتغيير وقت انتهاء صلاحيتها، وإلغاؤها.

sq key approvals

يدير موافقات التصديق.

يجوز لحاملي المفاتيح الموافقة على التصديقات من طرف ثالث المرتبطة بشهادتهم. يدير هذا الأمر الفرعي الموافقات.

لمنع هجمات إغراق الشهادات، تمنع خوادم المفاتيح الحديثة التوزيع غير المنضبط للتصديقات من طرف ثالث على الشهادات. للسماح لحامل المفتاح بالتحكم في المعلومات التي يتم توزيعها مع شهادته، تقوم خوادم المفاتيح هذه فقط بتوزيع التصديقات من طرف ثالث التي وافق عليها حامل المفتاح صراحة.

أمثلة

sq key list

قائمة المفاتيح التي يديرها خادم مخزن المفاتيح.

sq key list

قائمة المفاتيح التي يديرها خادم مخزن المفاتيح بمعرف مستخدم في example.org.

sq key list --cert-domain=example.org

sq key generate

توليد مفتاح، وحفظه على مخزن المفاتيح.

sq key generate --own-key --name Alice --email \
alice@example.org

توليد مفتاح، وحفظه في ملف بدلاً من مخزن المفاتيح.

sq key generate --own-key --name Alice --email \
alice@example.org --output alice-priv.pgp --rev-cert \
alice-priv.rev

sq key rotate

تدوير شهادة.

sq key rotate --cert-id 0xDEADBEEF

sq key import

استيراد مفتاح من ملف.

sq key import --own-key bob-priv.pgp

استيراد مفتاح من ملف، وتصدير شهادة إلغاء معها.

sq key import --own-key bob-priv.pgp --output bob.rev

sq key export

تصدير المفتاح الخاص بـ Bob.

sq key export --cert-id 0xDEADBEEF --output bob-priv.pgp

sq key delete

حذف المفتاح الخاص بـ Bob.

sq key delete --cert-id 0xDEADBEEF

sq key password

تغيير كلمة مرور المفتاح الخاص بـ Bob.

sq key password --cert-id 0xDEADBEEF

تغيير كلمة مرور المفتاح الخاص بـ Bob.

sq key password --cert-id 0xDEADBEEF --password-file pw.txt

إزالة كلمة مرور المفتاح الخاص بـ Bob.

sq key password --cert-id 0xDEADBEEF --clear

sq key expire

تغيير وقت انتهاء صلاحية المفتاح الخاص بـ Bob إلى 1 يناير 2025.

sq key expire --cert-id 0xDEADBEEF --expiration 2025-01-01

sq key revoke

إلغاء المفتاح الخاص بـ Bob.

sq key revoke --cert-id 0xDEADBEEF

إلغاء المفتاح الخاص بـ Bob، باستخدام مفتاح Alice كمفتاح إلغاء.

sq key revoke --cert-id 0xDEADBEEF --revoker 0xCAFEBABE

إلغاء المفتاح الخاص بـ Bob، مع سحب الشهادة بعد 90 يومًا.

sq key revoke --cert-id 0xDEADBEEF --retire-in 90

sq key userid

إضافة معرف مستخدم جديد إلى المفتاح الخاص بـ Bob.

sq key userid --cert-id 0xDEADBEEF --add bob-new@example.org

إلغاء معرف مستخدم من المفتاح الخاص بـ Bob.

sq key userid --cert-id 0xDEADBEEF --revoke bob-old@example.org

تحديث معرف مستخدم موجود للمفتاح الخاص بـ Bob.

sq key userid --cert-id 0xDEADBEEF --update bob@example.org bob.new@example.org

sq key subkey

توليد مفتاح فرعي جديد للمفتاح الخاص بـ Bob.

sq key subkey --cert-id 0xDEADBEEF --generate

تغيير وقت انتهاء صلاحية المفتاح الفرعي للمفتاح الخاص بـ Bob.

sq key subkey --cert-id 0xDEADBEEF --subkey-id 0x12345678 --expiration 2024-01-01

إلغاء المفتاح الفرعي للمفتاح الخاص بـ Bob.

sq key subkey --cert-id 0xDEADBEEF --subkey-id 0x12345678 --revoke

sq key approvals

السماح لـ Bob بالموافقة على التصديقات من طرف ثالث.

sq key approvals --cert-id 0xDEADBEEF --allow

منع Bob من الموافقة على التصديقات من طرف ثالث.

sq key approvals --cert-id 0xDEADBEEF --forbid

قائمة الموافقات الحالية لـ Bob.

sq key approvals --cert-id 0xDEADBEEF --list

NAME

sq-key - Manage keys

SYNOPSIS

sq key SUBCOMMAND

DESCRIPTION

This is a section describing the management of keys.

SUBCOMMANDS

This command supports the following subcommands:

  • sq key rotate
  • sq key import
  • sq key export
  • sq key delete
  • sq key password
  • sq key expire
  • sq key revoke

EXAMPLES

sq key rotate

Rotates Alice's certificate.

sq key rotate --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key import

Import the keys into the key store.

sq key import alice-secret.pgp

sq key export

Export Alice's certificate with all available secret key material.

sq key export --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Export Alice's certificate with all available secret key material identified by email address.

sq key export --cert-email alice@example.org

sq key delete

Delete any secret key associated with Alice's certificate.

sq key delete --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Delete any secret key associated with Alice's certificate selected by user ID.

sq key delete --cert-email=alice@example.org

sq key password

Change the password for all of Alice's keys to the password in the specified file.

sq key password --new-password-file password-file.txt --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Clear the password protection for all of Alice's keys.

sq key password --password-file password-file.txt \
--clear-password --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key expire

Change Alice's certificate to expire in a year.

sq key expire --expiration 1y --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

Change Alice's certificate to never expire.

sq key expire --expiration never --cert \
EB28F26E2739A4870ECC47726F0073F60FD0CBF0

sq key revoke

Revoke Alice's key, indicating that there is a new certificate.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason superseded --message \
"My new cert is C5999E8191BF7B503653BE958B1F7910D01F86E5"

Revoke the key, indicating that the secret key material was compromised.

sq key revoke --cert EB28F26E2739A4870ECC47726F0073F60FD0CBF0 \
--reason compromised --message \
"Computer attacked, secret key material compromised"
