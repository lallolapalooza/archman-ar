sq-network(1)

SQ(1) أوامر المستخدم SQ(1)

الاسم

sq-network - استرجاع ونشر الشهادات عبر الشبكة

الملخص

sq network search [خيارات] استعلام
sq network keyserver [خيارات] أمر فرعي
sq network wkd [خيارات] أمر فرعي
sq network dane [خيارات] أمر فرعي

الوصف

استرجاع ونشر الشهادات عبر الشبكة.

يمكن اكتشاف شهادات OpenPGP وتحديثها من، ونشرها على خدمات يمكن الوصول إليها عبر الشبكة. هذه مجموعة من الأوامر للتفاعل مع هذه الخدمات.

الأوامر الفرعية

sq network search

استرجاع الشهادات باستخدام جميع خدمات الشبكة المدعومة.

سيحاول هذا الأمر تحديد الشهادات ذات الصلة بالنظر إلى استعلام، والذي قد يكون بصمة، أو معرف مفتاح، أو عنوان بريد إلكتروني، أو عنوان URLhttps. قد يقوم أيضًا باكتشاف واستيراد شهادات مرتبطة بالشهادة المطلوبة، مثل الشهادات البديلة، والشهادات المنتهية الصلاحية، أو الشهادات الملغاة.

يعد اكتشاف الشهادات ذات الصلة أمرًا مفيدًا: تدعم الشهادات البديلة تناوب المفاتيح، وتسمح الشهادات المنتهية الصلاحية بالتحقق من التوقيعات التي تم إجراؤها في الماضي، ويعد اكتشاف الشهادات الملغاة مهمًا للحصول على معلومات الإلغاء. ستساعد آلية PKI في اختيار الشهادة الصحيحة، انظر `sq pki`.

بشكل افتراضي، يتم تخزين أي شهادات مسترجعة في مخزن الشهادات المحلي. يمكن تجاوز ذلك باستخدام خيار `--output`.

عند استرجاع شهادة من خادم مفاتيح تحقق (حالياً، يقتصر هذا على قائمة بالخوادم المعروفة: `hkps://keys.openpgp.org`, `hkps://keys.mailvelope.com`, و `hkps://mail-api.proton.me`), WKD, DANE، أو عبر https، واستيرادها إلى مخزن الشهادات المحلي، يتم أيضًا اعتماد معرفات المستخدمين بمفتاح محلي خاص بالخادم. يتم اعتماد مفتاح الوكيل هذا بدوره كمرجع مصدق CA موثوق به بشكل طفيف (مقدار الثقة: 1 من 120) من جذر الثقة المحلي. يمكن تعديل مقدار الثقة في CA مفتاح الوكيل باستخدام `sq pki link add` أو `sq pki link retract` بالطريقة المعتادة.

sq network keyserver

استرجاع ونشر الشهادات عبر خوادم المفاتيح.

بروتوكول خادم مفاتيح HTTP الخاص بـ OpenPGP (HKP) هو طريقة لنشر واسترجاع الشهادات من خوادم المفاتيح.

sq network wkd

استرجاع ونشر الشهادات عبر أدلة مفاتيح الويب (Web Key Directories).

دليل مفاتيح الويب (WKD) هو طريقة لنشر واسترجاع الشهادات من خوادم الويب.

sq network dane

استرجاع ونشر الشهادات عبر DANE.

المصادقة المستندة إلى DNS للكيانات المسماة (DANE) هي طريقة لنشر واسترجاع الشهادات في DNS كما هو محدد في RFC 7929.

أمثلة

ابحث عن شهادة توقيع Qubes الرئيسية.

sq network search 427F11FD0FAA4B080123F01CDDFA1A3E36879494

ابحث عن الشهادات المرتبطة بعنوان بريد إلكتروني.

sq network search alice@example.org
