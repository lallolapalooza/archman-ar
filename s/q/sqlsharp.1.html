sqlsharp(1)

خيارات دعم الموفر

UseParameter
TRUE,FALSE لتمكين أو تعطيل الاستعلام عن قيم المتغيرات التي لم يتم تعيينها عند تنفيذ عبارات SQL التي تستخدم المتغيرات التي تم تعيينها.

إذا كان هذا الخيار صحيحًا، تحتوي عبارة SQL على معلمات، ولكل معلمة لم يتم تعيين متغير SQL# لها، سيتم مطالبة المستخدم بإدخال قيمة لتلك المعلمة.

مثال:
	SQL# \useparameter true

الافتراضي: false

UseSimpleReader
TRUE,FALSE لاستخدام قارئ بسيط عند عرض النتائج. 
مثال:
	SQL# \usesimplereader true

الافتراضي: false. في الغالب، يعتمد هذا على الموفر. إذا لم يكن لدى الموفر ما يكفي من IDataReader لتشغيل القارئ العادي، فيمكن استخدام القارئ البسيط. موفرات مثل SqlClient و MySQL و PostgreSQL لديها هذا الخيار افتراضيًا إلى true.

نماذج سلسلة الاتصال

أمثلة على سلاسل الاتصال لموفرين مختلفين لاستخدامها عبر الأمر \ConnectionString

مثال للاستخدام:
	\connectionstring Database=testdb
أمثلة على سلاسل الاتصال:
Microsoft SQL Server عبر System.Data.SqlClient
	Server=DANPC;Database=pubs;User ID=saPassword=;
	بالنسبة للأمان المتكامل، ضع في اعتبارك أن Mono غير
	متكامل مع Windows أو عميل SQL Server أو الخادم أو
	خادم Windows. لذلك، يجب عليك توفير اسم مجال Windows
	واسم مستخدم المجال وكلمة المرور لهذا المستخدم.
	Server=DANPC;Database=pubs;User ID=DOMAINser;Password=pass;Integrated Security=SSPI
	بالنسبة لخادم محلي، يمكنك استخدام localhost.

ODBC عبر موفر System.Data.Odbc باستخدام
DSN باسم "MSSQLDSN" الذي قمت بتعيينه
في لوحة تحكم Windows الخاصة بمصادر بيانات ODBC
والذي يتصل بـ Microsoft SQL Server 2000:
	DSN=MSSQLDSN;UID=danmorg;PWD=freetds
لاستخدام ODBC على Unix، فكر في unixODBC من http://www.unixodbc.org/
أو استخدم iODBC من http://www.iodbc.org/
SQL Lite عبر موفر Mono.Data.SqliteClient
والذي يتصل بملف قاعدة البيانات SqliteTest.db؛ إذا لم يتم العثور عليه،
يتم إنشاء الملف:
	URI=file:SqliteTest.db
Oracle عبر System.Data.OracleClient
	Data Source=testdb;User ID=scott;Password=tiger
        إذا كنت تفضل عدم استخدام ملف tnsnames.ora، يمكنك
	استخدام سلسلة اتصال تسمح بوصف شبكة
	TNS محدد بين قوسين
مثل التالي الذي يحتوي على المضيف والمنفذ واسم الخدمة. بالنسبة للمضيف، يمكنك تحديد عنوان IP
        بدلاً من اسم المضيف.
User ID=SCOTT;
Password=TIGER;
Data Source=(DESCRIPTION=(ADDRESS=(PROTOCOL=TCP)(HOST=192.168.1.101)(PORT=1521))(CONNECT_DATA=(SERVER=DEDICATED)(SERVICE_NAME=TESTDB)))

Npgsql (.NET PostgreSQL) من
http://gborg.postgresql.org/project/npgsql/projdisplay.php
	Server=localhost;Database=test;User ID=postgres;Password=fun2db

ByteFX (ByteFX MySQL) من
	يرجى استخدام MySql.Data بدلاً من ذلك.
	Server=localhost;Database=test;User ID=mysql;Password=
FirebirdSql عبر FirebirdSql.Data.Firebird (تنزيل أحدث إصدار من FirebirdSql.org)
	Database=C:\FIREBIRD\EXAMPLES\EMPLOYEE.FDB;User=SYSDBA;Password=masterkey;Dialect=3;Server=localhost
MySQL عبر (MySql.Data) MySQL Connector/Net من http://www.mysql.com/
	Server=localhost;Database=test;User ID=mysql;Password=mypass;Pooling=false
