توثيق الدالة/الإجراء الفرعي

subroutine srqt02 (integer m, integer n, integer k, real, dimension( lda, * ) a, real, dimension( lda, * ) af, real, dimension( lda, * ) q, real, dimension( lda, * ) r, integer lda, real, dimension( * ) tau, real, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

SRQT02

الغرض:

!>
!> SRQT02 يختبر SORGRQ، الذي ينشئ مصفوفة Q بحجم m*n ذات صفوف متعامدة
!> مُعرّفة كناتج لـ k عاكسات أولية.
!>
!> بالنظر إلى تحليل RQ للمصفوفة A بحجم m*n، يولد SRQT02
!> المصفوفة المتعامدة Q المعرفة بتحليل آخر k صفوف
!> من A؛ ويقارن R(m-k+1:m,n-m+1:n) مع
!> A(m-k+1:m,1:n)*Q(n-m+1:n,1:n)'، ويتحقق من أن صفوف Q متعامدة.
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>          عدد صفوف المصفوفة Q المراد إنشاؤها. M >= 0.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>          عدد أعمدة المصفوفة Q المراد إنشاؤها.
!>          N >= M >= 0.
!>

K

!>          K هو عدد صحيح (INTEGER)
!>          عدد العواكس الأولية التي يُعرّف ناتجها المصفوفة Q.
!>          M >= K >= 0.
!>

A

!>          A مصفوفة حقيقية (REAL array)، بُعدها (LDA,N)
!>          المصفوفة A بحجم m*n والتي تم تحليلها بواسطة SRQT01.
!>

AF

!>          AF مصفوفة حقيقية (REAL array)، بُعدها (LDA,N)
!>          تفاصيل تحليل RQ للمصفوفة A، كما تم إرجاعها بواسطة SGERQF.
!>          راجع SGERQF لمزيد من التفاصيل.
!>

Q

!>          Q مصفوفة حقيقية (REAL array)، بُعدها (LDA,N)
!>

R

!>          R مصفوفة حقيقية (REAL array)، بُعدها (LDA,M)
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البعد الرائد للمصفوفات A, AF, Q, و L. LDA >= N.
!>

TAU

!>          TAU مصفوفة حقيقية (REAL array)، بُعدها (M)
!>          العوامل العددية للعواكس الأولية المقابلة لتحليل RQ في AF.
!>

WORK

!>          WORK مصفوفة حقيقية (REAL array)، بُعدها (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح (INTEGER)
!>          بعد المصفوفة WORK.
!>

RWORK

!>          RWORK مصفوفة حقيقية (REAL array)، بُعدها (M)
!>

RESULT

!>          RESULT مصفوفة حقيقية (REAL array)، بُعدها (2)
!>          نسب الاختبار:
!>          RESULT(1) = norm( R - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
