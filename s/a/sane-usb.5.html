الحزمة: sane

sane-usb is a SANE backend that supports scanners connected via USB. It relies on libusb for low-level USB access.

NAME

sane-usb - SANE (Scanner Access Now Easy) - USB Backend

DESCRIPTION

The sane-usb backend is a backend for the SANE (Scanner Access Now Easy) library. It allows SANE applications to communicate with scanners connected via USB. This backend uses libusb for direct USB access, bypassing the standard USB mass storage class or specific vendor drivers. This means that the backend should work with a wide range of USB scanners, provided that they are not using a protocol that is already handled by the kernel's USB drivers (like bulk-only for removable media).

QUICK START

To use the sane-usb backend, you need to ensure that libusb is installed on your system. Then, you typically don't need to do anything else, as the backend should be automatically detected and configured by SANE.

If you encounter problems, you can consult the SANE documentation and the upstream SANE project for potential issues or required configuration steps for your specific scanner model.

USB ACCESS METHODS

The sane-usb backend supports several methods for accessing USB devices:

  • libusb: This is the primary and recommended method. It provides direct access to USB devices without requiring kernel drivers.
  • Other methods might be available depending on the system and libusb configuration, but libusb is the most common and versatile.

LIBUSB

libusb is a cross-platform library that provides access to USB devices. The sane-usb backend uses libusb to enumerate USB devices, claim interfaces, and communicate with scanners. For libusb to function correctly, you might need to install it and potentially configure udev rules to grant access to USB devices for your user account.

On most Linux systems, you can install libusb using your package manager (e.g., sudo apt install libusb-1.0-0 on Debian/Ubuntu, or sudo pacman -S libusb on Arch Linux).

SANE ISSUES

If you experience problems with the sane-usb backend, such as the scanner not being detected or communication errors, consider the following:

  • Check if your scanner is supported by SANE and specifically by the sane-usb backend. Refer to the SANE TODO list or the backend's documentation.
  • Ensure libusb is correctly installed and accessible.
  • Verify that you have the necessary permissions to access USB devices. This often involves adding your user to a specific group (e.g., scanner or plugdev) or configuring udev rules.
  • Try running sane-find-scanner to see if the backend can detect your device.
  • Consult the SANE documentation and upstream resources for known issues and troubleshooting tips.

ENVIRONMENT

The sane-usb backend might be affected by the following environment variables:

  • SANE_DEBUG_SANE_USB: Controls the debug output level for the sane-usb backend. Higher values provide more detailed information, which can be useful for troubleshooting.
  • SANE_CONFIG_DIR: Specifies directories where SANE configuration files are located.
