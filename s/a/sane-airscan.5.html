sane-airscan(5)

SANE-AIRSCAN(5) ملحق SANE الخاص بـ AirScan (eSCL) و WSD SANE-AIRSCAN(5)

الاسم

sane-airscan - ملحق SANE الخاص بماسحات ضوئية AirScan (eSCL) و WSD والأجهزة متعددة الوظائف.

الوصف

sane-airscan هو الملحق الشامل للمسح الضوئي للمستندات "بدون برامج تشغيل" (driverless). حاليًا يدعم بروتوكولين:

1. eSCL، المعروف أيضًا باسم AirScan أو AirPrint scan
2. WSD، المعروف أيضًا باسم WS-Scan

الإعداد

يقوم sane-airscan بتحميل ملفات الإعداد الخاصة به من الأماكن التالية:

1. /etc/sane.d/airscan.conf
2. /etc/sane.d/airscan.d/*

صيغة ملف الإعداد تشبه إلى حد كبير صيغة ملفات .INI. تتكون من أقسام، كل قسم يحتوي على بعض المتغيرات. تبدأ التعليقات من الأحرف # أو ; وتستمر حتى نهاية السطر.

# هذا تعليق
[section 1]
variable 1 = value 1  ; وتعليق آخر
variable 2 = value 2

المسافات البادئة واللاحقة لاسم المتغير وقيمته يتم تجريدها. إذا أردت الحفاظ عليها، قم بوضع الاسم أو القيمة بين علامتي اقتباس ("مثل هذا").

إعداد الأجهزة

إذا كان الماسح الضوئي والكمبيوتر متصلين بنفس قسم الشبكة المحلية (LAN segment)، فمن المتوقع أن تعمل كل الأمور "بشكل مباشر" دون الحاجة إلى أي إعداد يدوي.

ومع ذلك، في بعض الحالات، يمكن أن يكون الإعداد اليدوي مفيدًا. على سبيل المثال:

1. إذا كان الكمبيوتر والماسح الضوئي متصلين عبر جهاز توجيه IP
2. يوجد الكثير من الأجهزة على شبكة مؤسسية، ولكن
   القليل منها فقط هو المهم
3. الاكتشاف التلقائي يعمل بشكل غير موثوق

لإعداد جهاز يدويًا، أضف القسم التالي إلى ملف الإعداد:

[devices]
"Kyocera eSCL" = http://192.168.1.102:9095/eSCL, eSCL
"Kyocera WSD" = http://192.168.1.102:5358/WSDScanner, WSD
"Device I do not want to see" = disable

يحتوي قسم [devices] على جميع الأجهزة المعدة يدويًا، سطر واحد لكل جهاز، ويحتوي كل سطر على اسم الجهاز على الجانب الأيسر للمعادلة وعنوان URL للجهاز على الجانب الأيمن، متبوعًا بالبروتوكول (eSCL أو WSD). إذا تم حذف البروتوكول، يفترض أنه eSCL. يمكنك أيضًا تعطيل جهاز معين باستخدام الكلمة المفتاحية disable بدلاً من عنوان URL.

بالإضافة إلى ذلك، يمكنك إعداد جهاز يدويًا عن طريق تمرير عنوان URL الخاص به مباشرةً في اسم الجهاز دون إضافته إلى ملف الإعداد. يأخذ هذا الصيغة protocol:Device Name:URL. يمكن كتابة الأمثلة المذكورة أعلاه كـ escl:Kyocera eSCL:http://192.168.1.102:9095/eSCL و wsd:Kyocera WSD:http://192.168.1.102:5358/WSDScanner.

لتحديد عناوين URL للأجهزة المتاحة، فإن أبسط طريقة هي تشغيل أداة airscan-discover(1) المقدمة على جهاز كمبيوتر متصل بالماسح الضوئي بنفس قسم الشبكة المحلية. عند النجاح، سيقوم هذا البرنامج بطباعة قائمة بالأجهزة المكتشفة على مخرجاته القياسية بتنسيق مناسب لتضمينه في ملف الإعداد.

إذا لم يكن من الممكن تشغيل airscan-discover(1) على نفس قسم الشبكة المحلية مثل الماسح الضوئي، فسيتعين عليك اتباع الطريق الصعب. يجب أن يعرف مسؤول النظام الخاص بك عنوان IP للجهاز، استشر دليل جهازك لمنفذ eSCL، وطريق URL للمكونات غالبًا ما يكون ""/eSCL""، على الرغم من أنه قد يختلف على بعض الأجهزة. اكتشاف عناوين URL لـ WSD بهذه الطريقة أصعب بكثير، لأنه من الصعب جدًا تخمين منفذ TCP ومسار URL، كما هو الحال في حالة eSCL.

بالنسبة لأجهزة eSCL، يمكن لعنوان URL أيضًا استخدام مخطط unix://، مثل unix://scanner.sock/eSCL. سيتم البحث عن "المضيف" من عنوان URL في الدليل المحدد بواسطة socket_dir (انظر أدناه). عند الاتصال بالماسح الضوئي، سيتم إرسال جميع حركة المرور إلى مقبس UNIX المحدد بدلاً من اتصال TCP.

بشكل افتراضي، يعامل sane-airscan جميع الماسحات الضوئية كأجهزة بعيدة. قد يكون هذا غير مرغوب فيه، عند تكوين وكيل يترجم من eSCL/WSD إلى بروتوكول SANE، حيث يتجاهل saned(8) أي جهاز غير متصل محليًا. من خلال تعيين pretend-local = true، يمكن لـ sane-airscan جعل أجهزته متاحة لخادم شبكة SANE.

خيارات الإعداد

تذهب الخيارات المتنوعة جميعها إلى قسم [options]. حاليًا، الخيارات التالية مدعومة:

[options]
; إذا كان هناك الكثير من الماسحات الضوئية في الجوار وكنت مهتمًا
; فقط بالقليل منها، قم بتعطيل الاكتشاف التلقائي
; وإعداد الماسحات الضوئية يدويًا.
discovery = enable | disable
; اختر ما ستعرضه تطبيقات SANE في قائمة الأجهزة:
; اسم شبكة الماسح الضوئي (الافتراضي) أو اسم طراز الأجهزة.
model = network | hardware
; إذا كان الجهاز يدعم بروتوكول eSCL و WSD، فقد يختار sane-airscan
; البروتوكول "الأفضل" تلقائيًا، أو
; يعرض جميع المتغيرات للمستخدم، مما يسمح بالاختيار اليدوي للبروتوكول.
; الافتراضي هو "auto".
protocol = auto | manual
; قد يكون اكتشاف أجهزة WSD "سريعًا" أو "كاملاً". يعمل وضع "سريع"
; بأسرع ما يمكن اكتشاف DNS-SD، ولكنه قد يكون غير موثوق به في بعض الحالات.
; وضع "كامل" بطيء وموثوق.
; من الممكن أيضًا تعطيل الاكتشاف التلقائي
; لأجهزة WSD. الافتراضي هو "fast".
ws-discovery = fast | full | off
; يمكن للماسحات الضوئية التي تستخدم مخطط unix:// في عنوان URL الخاص بها
; تحديد اسم المقبس فقط (وليس المسار الكامل). سيتم البحث عن الاسم
; في الدليل المحدد هنا.
; الافتراضي هو /var/run.
socket_dir = /path/to/directory
; قم بتكوين ما إذا كان سيتم التعامل مع أجهزة eSCL و WSD كما لو
; كانت متصلة محليًا. السلوك الافتراضي يعتبرها
; أجهزة بعيدة يتم الوصول إليها عبر الشبكة.
; يجب تغيير هذا الخيار عند تصدير ماسح ضوئي عبر
; saned. الافتراضي هو "false".
pretend-local = false | true

قائمة الحظر للأجهزة

يمكن أن تكون هذه الميزة مفيدة، إذا كنت على شبكة كبيرة جدًا ولديك الكثير من الأجهزة حولك، بينما تهتم فقط بالقليل منها.

[blacklist]
model = "Xerox*"       ; قائمة الحظر حسب اسم الطراز
name  = "HP*"          ; قائمة الحظر حسب اسم الشبكة
ip    = 192.168.0.1    ; قائمة الحظر حسب العنوان
ip    = 192.168.0.0/24 ; قائمة الحظر للشبكة الفرعية بأكملها

تأتي أسماء الشبكات من DNS-SD، ولا يوفر WS-Discovery هذه المعلومات. للتصفية حسب اسم الشبكة للعمل، يجب تمكين Avahi ويجب أن يكون الجهاز قابلاً للاكتشاف عبر DNS-SD (ليس بالضرورة كماسح ضوئي، يكفي إذا كان الماسح الضوئي WSD قابلاً للاكتشاف كطابعة عبر DNS-SD).

قائمة الحظر تؤثر فقط على الاكتشاف التلقائي، ولا تؤثر على الأجهزة المعدة يدويًا.

التصحيح

يوفر sane-airscan أدوات مفيدة جدًا لاستكشاف الأخطاء وإصلاحها دون الحصول على وصول مادي للجهاز الإشكالي.

يمكن التحكم في مرافق التصحيح باستخدام قسم [debug] في ملف الإعداد:

[debug]
; تمكين أو تعطيل تسجيل وحدة التحكم
enable = false | true
; تمكين تتبع البروتوكول وتكوين دليل الإخراج
; لملفات التتبع. كما هو الحال في shell، لتحديد مسار نسبي إلى
; الدليل الرئيسي، ابدأه بحرف tilda، متبوعًا
; بشرطة مائلة، على سبيل المثال "، ~ / airscan/trace ". سيتم
; إنشاء الدليل تلقائيًا.
trace = path
; عرض سداسي عشري لجميع حركة المرور إلى ملف التتبع (مطول جدًا!)
hexdump = false | true
