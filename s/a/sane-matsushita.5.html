sane-matsushita(5) SANE Scanner Access Now Easy sane-matsushita(5)

الاسم

sane-matsushita - الواجهة الخلفية لـ SANE للمسحات الضوئية عالية السرعة من باناسونيك KV-SS

الوصف

تقوم مكتبة sane-matsushita بتنفيذ الواجهة الخلفية لـ SANE (Scanner Access Now Easy) التي توفر الوصول إلى بعض المسحات الضوئية عالية السرعة من باناسونيك KV-SS. هذه الواجهة الخلفية مستقرة.

في الوقت الحالي، يُعرف أن المسحات الضوئية التالية تعمل مع هذه الواجهة الخلفية:

  معرف المنتج
--------------
   KV-SS25
   KV-SS25D
   KV-SS55EX (*)
   KV-S2025C (*)
   KV-S2045C (*)
   KV-S2065L (*)

(*) تحذير: لا تتوفر أي من الخيارات المتقدمة لهذه المسحات الضوئية (أي لا يوجد ألوان، لا توجد دقة عالية، لا يوجد اقتصاص تلقائي). بشكل أساسي، لا يقوم برنامج التشغيل بأكثر مما يفعله لـ KV-SS25. ليس لدي وصول إلى مثل هذه المسحات الضوئية، وبالتالي لا يمكنني إضافة هذه الخيارات.

قد تعمل المسحات الضوئية الأخرى عالية السرعة من باناسونيك أو لا تعمل مع هذه الواجهة الخلفية.

يمكن سرد خيارات سطر الأوامر الصالحة وصيغتها عن طريق استخدام:

scanimage --help -d matsushita

وضع المسح
--mode
يحدد وضع التشغيل الأساسي للمسح الضوئي.
--resolution
يحدد الدقة للمسح الضوئي. يدعم كل طراز جميع الدقات أو مجموعة فرعية منها: 100، 150، 200، 240، 300، 360، 400.
--duplex
يشير إلى ما إذا كان سيتم مسح كلا جانبي الورقة.
--feeder-mode
يحدد عدد الصفحات المراد مسحها (واحدة أو حتى تفرغ الدرج).
الهندسة
--paper-size A4|...|Legal|Letter [A4]
يحدد المنطقة المراد مسحها. يقوم بضبط الخيارات -l -t -x -y وفقًا لذلك. لا يلزم أن يكون حجم الورقة الحقيقي.
-l -t -x -y
يتحكم في منطقة المسح: -l يحدد إحداثي x للزاوية العلوية اليسرى، -t يحدد إحداثي y للزاوية العلوية اليسرى، -x يحدد العرض و -y يحدد الارتفاع لمنطقة المسح. يتم تحديد جميع المعلمات بالمليمتر. من الممكن استخدام الخيار --paper-size بدلاً من ذلك.
التحسين
--brightness
يتحكم في سطوع الصورة المكتسبة. تتراوح القيمة من 1 إلى 255، أو أقل، اعتمادًا على طراز الماسح الضوئي.
--contrast
يتحكم في تباين الصورة المكتسبة. لا تدعم بعض الطرازات هذا الخيار.
--automatic-threshold
يضبط تلقائيًا السطوع والتباين ومستوى البياض والجامما وتقليل الضوضاء وتركيز الصورة. هذه الخيارات غير متاحة عند استخدام العتبة التلقائية.
--halftone-pattern
يحدد التدرج اللوني لوضع نصف الدرجة. لم يتم تنفيذ تنزيل النمط بواسطة الواجهة الخلفية.
--autoseparation
يوفر الفصل التلقائي للنص والصور.
--white-level
يشير إلى مصدر القاعدة البيضاء.
--noise-reduction
يقلل من ضوضاء النقاط المنفصلة. هذا الخيار غير مدعوم من جميع الماسحات الضوئية.
--image-emphasis
يضبط تركيز الصورة. بعض الاختيارات غير متاحة في جميع الماسحات الضوئية.
--gamma
يضبط منحنى جاما. يكون صالحًا فقط لأوضاع الرمادي، وغير متاح في جميع الماسحات الضوئية. لم يتم تنفيذ تنزيل جاما بواسطة الواجهة الخلفية.

ملف التكوين

يدعم ملف التكوين /etc/sane.d/matsushita.conf اسم الجهاز المراد استخدامه (على سبيل المثال، /dev/scanner) وخيار SCSI لاكتشاف الماسحات الضوئية المدعومة تلقائيًا.

الملفات

/usr/lib/sane/libsane-matsushita.a
المكتبة الثابتة التي تنفذ هذه الواجهة الخلفية.
/usr/lib/sane/libsane-matsushita.so
المكتبة المشتركة التي تنفذ هذه الواجهة الخلفية (موجودة على الأنظمة التي تدعم التحميل الديناميكي).

البيئة

SANE_DEBUG_MATSUSHITA
إذا تم تجميع المكتبة مع تمكين دعم التصحيح، فإن متغير البيئة هذا يتحكم في مستوى التصحيح لهذه الواجهة الخلفية. على سبيل المثال، يطلب مستوى 128 طباعة جميع مخرجات التصحيح. المستويات الأقل تقلل من الإسهاب.

القيود

الذاكرة في KV-SS 25
لا تحتوي KV-SS 25 على ذاكرة داخلية كافية لمسح صفحة A4 كاملة في وضع مزدوج بدقة عالية. ستعيد الواجهة الأمامية خطأ في الذاكرة في هذه الحالة. على ما يبدو، KV-SS 25D لا تعاني من هذه المشكلة.
تنزيل النمط وجاما
يمكن للمسح الضوئي، مع البرامج الثابتة المناسبة، تنزيل نمط نصف الدرجة وجدول جاما. لم يتم تنفيذ ذلك.
المناطق الفرعية
يمكن للمسح الضوئي دعم ما يصل إلى 3 مناطق فرعية على كل جانب لتحديد خيارات تحسين أكثر دقة. لم يتم تنفيذ ذلك.
وضع مزدوج
لا تدعم الواجهة الخلفية تعيين خيارات مختلفة لكل جانب. سيحدث المسح بنفس الخيارات (نمط نصف الدرجة، السطوع، تركيز الصورة) لكلا الجانبين.

مثال على المسح

حتى الآن، الواجهة الأمامية الوحيدة القادرة على استخدام هذا الماسح الضوئي بسرعة كاملة هي scanadf(1).

سيكون سطر أوامر scanadf(1):

scanadf -d matsushita --output-file scan%04d.pbm --start-count 0 --duplex --resolution 300 --feeder-mode="All pages" --paper-size="A4"

لا توجد أخطاء معروفة.

NAME

sane-matsushita - SANE backend for Matsushita scanners

SYNOPSIS

sane-matsushita

DESCRIPTION

The sane-matsushita library is a backend for the Scanner Access Now Easy (SANE) API that provides access to various Matsushita (Panasonic) scanners. This backend supports a range of models, but compatibility might vary.

CONFIGURATION FILE

The backend is configured by the file /etc/sane.d/matsushita.conf. This file contains configuration options specific to the Matsushita backend. Typically, it's used to specify the device name or port for the scanner if it's not automatically detected.

FILES

/etc/sane.d/matsushita.conf
The configuration file for the Matsushita backend.
/usr/lib/sane/libsane-matsushita.so*
The actual implementation of the Matsushita backend.

ENVIRONMENT

No specific environment variables are typically used by this backend.

LIMITATIONS

Not all Matsushita scanner models are supported. Compatibility depends on the specific hardware and firmware. Refer to the SANE documentation or the backend's release notes for a list of known supported devices.

Functionality like automatic document feeders, duplex scanning, or specific color calibration features might not be fully supported or available for all models.

SCANNING EXAMPLE

A typical scanning process using a SANE frontend application (like xsane or simple-scan) would involve selecting the Matsushita scanner as the source, configuring scan parameters (resolution, color mode), and initiating the scan.

Command-line example using scanimage: 

scanimage --device-name 'matsushita:libusb:/dev/usb/scanner0' --resolution 300 --format=tiff > output.tiff

Note: The device name might vary depending on your system configuration.

BUGS

Refer to the SANE bug tracking system for any reported bugs related to the sane-matsushita backend. Users are encouraged to report any issues encountered with specific scanner models.

SEE ALSO

sane-find-scanner(8), scanimage(1), sane-frontends(7)

AUTHOR

The sane-matsushita backend was developed by various contributors to the SANE project.

sane-matsushita(5)

الاسم

sane-matsushita - الواجهة الخلفية لـ SANE للماسحات الضوئية Matsushita

الملخص

sane-matsushita

الوصف

مكتبة sane-matsushita هي واجهة خلفية لواجهة برمجة تطبيقات Scanner Access Now Easy (SANE) توفر الوصول إلى مختلف الماسحات الضوئية من Matsushita (Panasonic). تدعم هذه الواجهة الخلفية مجموعة من الموديلات، ولكن التوافق قد يختلف.

ملف التكوين

يتم تكوين الواجهة الخلفية بواسطة الملف /etc/sane.d/matsushita.conf. يحتوي هذا الملف على خيارات التكوين الخاصة بالواجهة الخلفية Matsushita. عادةً، يتم استخدامه لتحديد اسم الجهاز أو المنفذ للماسح الضوئي إذا لم يتم اكتشافه تلقائيًا.

الملفات

/etc/sane.d/matsushita.conf
ملف التكوين للواجهة الخلفية Matsushita.
/usr/lib/sane/libsane-matsushita.so*
التنفيذ الفعلي للواجهة الخلفية Matsushita.

البيئة

لا يتم عادةً استخدام متغيرات بيئة محددة بواسطة هذه الواجهة الخلفية.

القيود

لا يتم دعم جميع موديلات الماسحات الضوئية Matsushita. يعتمد التوافق على الأجهزة والبرامج الثابتة المحددة. ارجع إلى وثائق SANE أو ملاحظات إصدار الواجهة الخلفية للحصول على قائمة بالأجهزة المدعومة المعروفة.

قد لا تكون وظائف مثل وحدات تغذية المستندات التلقائية، أو المسح الضوئي المزدوج، أو ميزات معايرة الألوان المحددة مدعومة بالكامل أو متاحة لجميع الموديلات.

مثال على المسح الضوئي

تتضمن عملية المسح الضوئي النموذجية باستخدام تطبيق واجهة أمامية لـ SANE (مثل xsane أو simple-scan) تحديد الماسح الضوئي Matsushita كمصدر، وتكوين معلمات المسح (الدقة، وضع الألوان)، وبدء المسح.

مثال سطر الأوامر باستخدام scanimage:

scanimage --device-name 'matsushita:libusb:/dev/usb/scanner0' --resolution 300 --format=tiff > output.tiff

ملاحظة: قد يختلف اسم الجهاز اعتمادًا على تكوين نظامك.

الأخطاء

ارجع إلى نظام تتبع أخطاء SANE لأي أخطاء تم الإبلاغ عنها تتعلق بالواجهة الخلفية sane-matsushita. يتم تشجيع المستخدمين على الإبلاغ عن أي مشاكل يتم مواجهتها مع موديلات الماسحات الضوئية المحددة.

انظر أيضًا

sane-find-scanner(8)، scanimage(1)، sane-frontends(7)

المؤلف

تم تطوير الواجهة الخلفية sane-matsushita بواسطة مساهمين مختلفين في مشروع SANE.
