NAME

sane-fujitsu - SANE backend for Fujitsu scanners

DESCRIPTION

The sane-fujitsu library is a backend for SANE (Scanner Access Now Easy) that supports a number of Fujitsu scanner models. The backend uses the appropriate protocols to communicate with the scanner. For USB scanners, this involves the libusb library. For SCSI scanners, it uses the generic SCSI transport provided by the SANE architecture.

SUPPORTED HARDWARE

The sane-fujitsu backend aims to support as many Fujitsu scanner models as possible. Specific models that are known to work include, but are not limited to:

  Fujitsu ScanAce series (e.g., ScanAce III, ScanAce II)
  Fujitsu ScanPartner series (e.g., ScanPartner 10, ScanPartner Jr.)
  Fujitsu Fi series (e.g., Fi-4120C, Fi-5110C, Fi-6130, Fi-6000)
  Fujitsu SnapScan series (e.g., SnapScan S1500)
  Fujitsu ix500, ix100

For a detailed and up-to-date list of supported hardware, please refer to the backend's documentation or the SANE project website.

UNSUPPORTED HARDWARE

Older parallel port scanners and some very old SCSI models might not be supported due to the complexity of their interfaces or lack of documentation.

OPTIONS

The options available depend on the specific scanner model and the capabilities of the backend. Common options include:

  • Mode: Selects the scan mode (e.g., Color, Grayscale, Lineart).
  • Resolution: Sets the scanning resolution in DPI (dots per inch).
  • Paper Size: Specifies the size of the document being scanned.
  • ADF (Automatic Document Feeder): Controls the use of the ADF for multi-page scanning.
  • Duplex Scanning: Enables or disables double-sided scanning if supported by the hardware.
  • Brightness / Contrast: Adjusts the brightness and contrast of the scanned image.
  • Threshold: For Lineart mode, sets the threshold for converting pixels to black or white.

Use the scanimage command with the -L option to list available devices and the scanimage command with the --help option to see the options supported by your specific scanner.

CONFIGURATION FILE

Configuration for the sane-fujitsu backend is typically done through the ~/.sane/sane-fujitsu.conf file. This file can be used to specify device paths, alternative driver settings, or other backend-specific parameters. Refer to the backend's documentation for details on available configuration options.

ENVIRONMENT

No specific environment variables are documented for this backend.

KNOWN ISSUES

Some advanced features or specific model quirks might not be fully supported or may exhibit unexpected behavior. Consult the backend's issue tracker or mailing lists for known problems and their workarounds.
