sane-epson(5) SANE Scanner Access Now Easy sane-epson(5)

الاسم

sane-epson - الواجهة الخلفية لـ SANE للمسح الضوئي لأجهزة EPSON

الوصف

تطبق مكتبة sane-epson واجهة خلفية لـ SANE (Scanner Access Now Easy) توفر الوصول إلى الماسحات الضوئية المسطحة من EPSON. يجب اعتبار بعض وظائف هذه الواجهة الخلفية برمجيات بجودة تجريبية! معظم الوظائف مستقرة منذ فترة طويلة، ولكن بالطبع التطوير الجديد لا يمكن وغالباً لن يعمل بشكل صحيح منذ اليوم الأول. يرجى الإبلاغ عن أي سلوك غريب إلى القائم على صيانة الواجهة الخلفية.

في الوقت الحالي، يُعرف أن الماسحات الضوئية التالية تعمل مع هذه الواجهة الخلفية:

الطراز:                       نوع الاتصال
---------------------------  -------------------
GT-5000                      SCSI، متوازي
GT-6000                      متوازي
GT-6500                      SCSI (استخدم فقط السطر "scsi" في epson.conf)
ActionScanner II             SCSI، متوازي
GT-7000                      SCSI
Perfection 636               SCSI
Perfection 636U              USB
Perfection 610               USB
Perfection 640               USB
Perfection 1200S             SCSI
Perfection 1200U             USB
Perfection 1240              USB، SCSI
Perfection 1640              USB، SCSI
Perfection 1650              USB
Perfection 1660              USB
Perfection 2400              USB
Perfection 2450              USB، IEEE-1394
Expression 636 / GT-9500     SCSI
Expression 1600              USB، SCSI، IEEE-1394
Expression 1680              USB، SCSI، IEEE-1394
CX-3200                      USB
CX-5200                      USB
والعديد غيرها. القائمة الرسمية موجودة على موقع Sane على الويب.

بالنسبة للمسح الضوئي الأخرى، قد يعمل البرنامج أو لا يعمل. يرجى إرسال بريد إلكتروني إلى مؤلف الواجهة الخلفية (khk@khk.net) للإبلاغ عن النجاح مع الماسحات الضوئية غير المدرجة أو المشاكل مع الماسحات الضوئية المدرجة.

خيارات

يمكن تحديد الخيارات التي تدعمها الواجهة الخلفية إما من خلال خيارات سطر الأوامر للبرامج مثل scanimage(1) أو من خلال عناصر واجهة المستخدم الرسومية في برامج مثل xscanimage(1) أو xsane(1).

يمكن سرد خيارات سطر الأوامر الصالحة وصيغتها باستخدام:

scanimage --help -d epson

لا تدعم جميع الأجهزة جميع الخيارات.

وضع المسح
يحدد المفتاح --mode وضع التشغيل الأساسي للماسح الضوئي. الخيارات الصالحة هي Binary (ثنائي)، Gray (تدرج رمادي)، و Color (ملون). وضع Binary هو أبيض وأسود فقط، Gray سينتج 256 مستوى من الرمادي أو أكثر حسب الماسح الضوئي، و Color يعني وضع الألوان 24 بت أو أكثر حسب الماسح الضوئي. قد تستخدم بعض الماسحات الضوئية داخليًا 36 بت ألوان، لكن واجهة الاتصال الخارجية قد تدعم 24 بت فقط.

يحدد الخيار --depth عمق البت الذي يستخدمه الماسح الضوئي. هذا الخيار متاح فقط للماسحات الضوئية التي تدعم أكثر من عمق بت واحد. الماسحات الضوئية القديمة ستنقل الصورة دائمًا بوضع 8 بت. الماسحات الضوئية الأحدث تسمح باختيار 8 بت، 12 بت، أو 14 بت لكل قناة لون. للمسح الضوئي الملون، هذا يعني عمق لون فعال 36 أو 42 بت عبر القنوات الثلاث. الخيارات الصالحة تعتمد على طراز الماسح الضوئي.

يحدد المفتاح --halftoning الوضع المستخدم في وضع Binary. الخيارات الصالحة هي "None" (لا شيء)، "Halftone A (Hard Tone)" (تدرج خشن أ - نغمة قاسية)، "Halftone B (Soft Tone)" (تدرج خشن ب - نغمة ناعمة)، "Halftone C (Net Screen)" (تدرج خشن ج - شبكة)، "Dither A (4x4 Bayer)" (تجزئة أ - 4x4 باير)، "Dither B (4x4 Spiral)" (تجزئة ب - 4x4 حلزوني)، "Dither C (4x4 Net Screen)" (تجزئة ج - 4x4 شبكة)، "Dither D (8x4 Net Screen)" (تجزئة د - 8x4 شبكة)، "Text Enhanced Technology" (تقنية محسنة للنص)، "Download pattern A" (تنزيل نمط أ)، و "Download pattern B" (تنزيل نمط ب).

يحدد المفتاح --dropout ما يسمى بلون التسرب. الخيارات الصالحة هي None (لا شيء)، Red (أحمر)، Green (أخضر)، و Blue (أزرق). الافتراضي هو None. لون التسرب يستخدم للمسح الضوئي أحادي اللون ويحدد اللون الذي لا يتم مسحه ضوئيًا. يمكن استخدام هذا للمسح الضوئي مثلاً لأصل بخلفية ملونة.

يتحكم المفتاح --brightness في سطوع المسح الضوئي. الخيارات الصالحة هي قيم صحيحة من -3 إلى 3. الافتراضي هو 0. كلما زادت قيمة السطوع، أصبحت الصورة أكثر سطوعًا. إذا تم تحديد جدول مخصص للمستخدم لتصحيح جاما، فإن معلمة السطوع غير متاحة.

يحدد المفتاح --sharpness حدة بيانات الصورة. الخيارات الصالحة هي قيم صحيحة من -2 إلى 2، حيث -2 تعني "Defocus" (ضبابية)، -1 "Defocus slightly" (ضبابية قليلاً)، 0 "Normal" (عادي)، 1 "Sharpen slightly" (حدة قليلاً)، و 2 "Sharpen" (حدة).

يتحكم المفتاح --gamma-correction في تصحيح جاما الداخلي للماسح الضوئي. الخيارات الصالحة هي "Default" (افتراضي)، "User defined" (محدد من قبل المستخدم)، "High density printing" (طباعة بكثافة عالية)، "Low density printing" (طباعة بكثافة منخفضة)، و "High contrast printing" (طباعة تباين عالٍ).

يتحكم المفتاح --color-correction في وظيفة تصحيح الألوان الداخلية للماسح الضوئي. الخيارات الصالحة هي "No Correction" (لا تصحيح)، "Impact-dot printers" (طابعات النفث النقطي)، "Thermal printers" (طابعات حرارية)، "Ink-jet printers" (طابعات نفث الحبر)، و "CRT monitors" (شاشات CRT). الافتراضي هو "CRT monitors".

يحدد الخيار --resolution دقة المسح الضوئي. بعض ماسحات EPSON الضوئية ستمسح ضوئيًا بأي دقة بين أدنى وأعلى قيمة ممكنة. يمكن عرض القائمة التي يبلغ عنها الماسح الضوئي باستخدام معلمات "--help -d epson" لـ scanimage(1).

يتحكم الخيار --mirror في طريقة مسح الصورة ضوئيًا. عن طريق قراءة بيانات الصورة من اليمين إلى اليسار، يتم عكس الصورة. الخيارات الصالحة هي "yes" (نعم) و "no" (لا). الافتراضي هو "no".

يمكن للخيار --speed تحسين سرعة المسح الضوئي في الوضع أحادي اللون. الخيارات الصالحة هي "yes" (نعم) أو "no" (لا)، الخيار "yes" سيسرع المسح الضوئي إذا كان هذا الخيار مدعومًا.

يقوم المفتاح --auto-area-segmentation بتنشيط تقسيم المنطقة التلقائي للمسح الضوئي أحادي اللون. سيحاول الماسح الضوئي تحديد المناطق التي تحتوي على نص والمناطق التي تحتوي على صور. سيتم معالجة المناطق المصورة، وسيتم تحسين النص. الخيارات الصالحة هي "yes" (نعم) و "no" (لا). الافتراضي هو "yes".

يمكن استخدام المعلمة --gamma-table لتنزيل جدول جاما معرف من قبل المستخدم. يأخذ الخيار 256 قيمة من النطاق 0-255. في وضع اللون، يؤثر هذا الخيار بالتساوي على قنوات الأحمر والأخضر والأزرق.

يمكن استخدام المعلمة --red-gamma-table لتنزيل جدول جاما معرف من قبل المستخدم لقناة الأحمر. الخيارات الصالحة هي نفس خيارات --gamma-table.

يمكن استخدام المعلمة --green-gamma-table لتنزيل جدول جاما معرف من قبل المستخدم لقناة الأخضر. الخيارات الصالحة هي نفس خيارات --gamma-table.

يمكن استخدام المعلمة --blue-gamma-table لتنزيل جدول جاما معرف من قبل المستخدم لقناة الأزرق. الخيارات الصالحة هي نفس خيارات --gamma-table.

معاملات تصحيح الألوان --cct-1 --cct-2 --cct-3 ... --cct-9 ستقوم بتثبيت معاملات تصحيح الألوان للتصحيح اللوني المحدد من قبل المستخدم. يتم تحديد القيم كأعداد صحيحة في النطاق -127..127.

يطلب الخيار --preview مسحًا ضوئيًا للمعاينة. يختار برنامج الواجهة تلقائيًا دقة منخفضة. الخيارات الصالحة هي "yes" (نعم) و "no" (لا). الافتراضي هو "no".

سيؤدي الخيار --preview-speed إلى زيادة سرعة المسح الضوئي إذا كان مدعومًا من قبل الماسح الضوئي. الخيارات الصالحة هي "yes" (نعم) و "no" (لا)، الافتراضي هو "no".

تتحكم خيارات الهندسة -l -t -x -y في منطقة المسح: -l تحدد إحداثي x للزاوية اليسرى العلوية، -t تحدد إحداثي y للزاوية اليسرى العلوية، -x تحدد العرض، و -y تحدد الارتفاع لمنطقة المسح. جميع المعلمات محددة بالمليمتر.

يسمح الخيار --quick-format للمستخدم بتحديد منطقة مسح بأحجام محددة مسبقًا. الخيارات الصالحة هي "CD" (قرص مدمج)، "A5 portrait" (A5 عمودي)، "A5 landscape" (A5 أفقي)، "Letter" (ورق رسالة)، "A4"، و "max" (الأقصى). الافتراضي هو "max"، الذي يحدد أكبر منطقة ممكنة.

يحدد الخيار --source مصدر المسح الضوئي. الخيارات الصالحة تعتمد على الخيارات المثبتة. الافتراضي هو "Flatbed" (سطح مستو).

NAME

sane-epson - SANE backend for Epson scanners

DESCRIPTION

The sane-epson library implements the SANE interface [the*SANE*Interface] for Epson scanners. See sane(7) for details.

The backend supports scanners connected via SCSI, parallel port and USB. The actual support depends on the specific scanner model and the connection type.

OPTIONS

This backend supports the standard SANE options plus the following options:

--auto-eject
The --auto-eject option will eject a page after scanning from the document feeder.
--film-type
The --film-type option will select the film type for scans with the transparency unit. This option is only activated if the TPU is selected as scan source. Valid options are "Negative Film" and "Positive Film".
--focus-position
The --focus-position option selects the focus position for all scans. Valid options are "Focus 2.5mm above glass" and "Focus on glass". The focus on the 2.5mm point above the glass is necessary for scans with the transparency unit, so that the scanner can focus on the film if one of the film holders is used. This option is only functional for selected scanners, all other scanners will ignore this option.

CONFIGURATION FILE

The configuration file /etc/sane.d/epson.conf specifies the device(s) that the backend will use. Possible connection types are:

SCSI
This is the default, and if nothing else is specified the backend software will open a given path as SCSI device. More information about valid syntax for SCSI devices can be found in sane-scsi(5).
Usually SCSI scanners are configured with a line "scsi EPSON" in this file. In some cases it may be necessary to only use the string "scsi" (e.g. for the GT-6500).
PIO - Parallel Interface
The parallel interface can be configured in two ways: An integer value starting at the beginning of a line will be interpreted as the IO address of the parallel port. To make it clearer that a configured IO address is a parallel port the port address can be preceded by the string "PIO". The PIO connection does not use a special device file in the /dev directory. The IO address can be specified in hex mode (prefixed with "0x").
USB
A device file that is preceded by the string "USB" is treated as a scanner connected via the Universal Serial Bus. The correct special device file has to be created prior to using it with Sane. See the USB documentation for more information about how to set up the USB subsystem and the required device files.

FILES

/usr/lib/sane/libsane-epson.a
The static library implementing this backend.
/usr/lib/sane/libsane-epson.so
The shared library implementing this backend (present on systems that support dynamic loading).

ENVIRONMENT

SANE_DEBUG_EPSON
If the library was compiled with debug support enabled, this environment variable controls the debug level for this backend. E.g., a value of 128 requests all debug output to be printed. Smaller levels reduce verbosity.
SANE_DEBUG_EPSON_SCSI
If the library was compiled with debug support enabled, this environment variable controls the SCSI related debug level for this backend. Only a value of 2 is supported.
SANE_EPSON_CMD_LVL
This allows one to override the function or command level that the backend uses to communicate with the scanner. The function level a scanner supports is determined during the initialization of the device. If the backend does not recognize the function level reported by the scanner it will default to function level B3. Valid function levels are A1, A2, B1, B2, B3, B4, B5, B6, B7, B8, D1 and F5. Use this feature only if you know what you are doing!

SEE ALSO

sane-scsi(5), scanimage(1), xscanimage(1), xsane(1)

BUGS

None :-) At least none are currently known.

UNSUPPORTED DEVICES

The backend may be used with Epson scanners that are not yet listed under the list of supported devices. A scanner that is not recognized may default to the function level B3, which means that not all functions that the scanner may be capable of are accessible.

If the scanner is not even recognized as an Epson scanner this is probably because the device name reported by the scanner is not in the correct format. Please send this information to the backend maintainer (email address is in the AUTHOR section of this man page or in the AUTHORS file of the SANE distribution).

The Perfection 600, Perfection 650, Perfection 660, Perfection 1250 and Perfection 1260 are not supported by this backend.
