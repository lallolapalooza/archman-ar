--user-allowed-to-authenticate-to=SDDL

تطبق هذه السياسة على حساب مستخدم (على سبيل المثال، حساب مستخدم عادي)، وتقيد أي الحسابات التي يمكنها الوصول إليه.

يجب أن تكون سلسلة SDDL صالحة. يمكن لـ SDDL الإشارة إلى شروط المستخدم (bare) وشروط الجهاز (Device).

مثال SDDL: O:SYG:SYD:(XA;OICI;CR;;;WD;(Member_of {SID(AU)}))

--service-allowed-to-authenticate-from=SDDL

تطبق هذه السياسة على حساب خدمة (على سبيل المثال، حساب خدمة مُدار، حساب خدمة مُدار للمجموعة)، وتقيد من أي الأجهزة التي يمكن لحساب الخدمة المصادقة منها.

يجب أن تكون سلسلة SDDL صالحة دون أي مرجع لكلمات مفتاحية خاصة بالجهاز (Device keywords).

مثال SDDL: O:SYG:SYD:(XA;OICI;CR;;;WD;(Member_of {SID(AU)}))

--service-allowed-to-authenticate-to=SDDL

تطبق هذه السياسة على حساب خدمة (على سبيل المثال، حساب خدمة مُدار، حساب خدمة مُدار للمجموعة)، وتقيد أي الحسابات التي يمكنها الوصول إليها.

يجب أن تكون سلسلة SDDL صالحة. يمكن لـ SDDL الإشارة إلى كل من الشروط الخاصة بالمستخدم (bare) وشروط الجهاز (Device).

مثال SDDL: O:SYG:SYD:(XA;OICI;CR;;;WD;(Member_of {SID(AO)}))

--computer-tgt-lifetime-mins

عمر التذكرة لمنح التذكرة لحسابات أجهزة الكمبيوتر.

--computer-allowed-to-authenticate-to=SDDL

تطبق هذه السياسة على حساب جهاز كمبيوتر (على سبيل المثال، خادم أو محطة عمل)، وتقيد أي الحسابات التي يمكنها الوصول إليه.

يجب أن تكون سلسلة SDDL صالحة. يمكن لـ SDDL الإشارة إلى كل من الشروط الخاصة بالمستخدم (bare) وشروط الجهاز (Device).

مثال SDDL: O:SYG:SYD:(XA;OICI;CR;;;WD;(Member_of {SID(AO)}))

يضيف هذا الأمر سمات Unix إلى حساب مستخدم في نطاق Active Directory.

اسم المستخدم المحدد في الأمر هو sAMAccountName.

يجب عليك توفير معرف فريد (uid).

سيتم إضافة سمات Unix (RFC2307) إلى حساب المستخدم.

إذا قمت بتوفير معرف مجموعة باستخدام '--gid-number'، فسيتم استخدام هذا لمعرف مجموعة المستخدم Unix 'gidNumber'.

إذا لم يتم توفير '--gid-number'، فسيتم تعيين gidNumber الخاص بالمستخدم إلى الذي تم العثور عليه في 'Domain Users'، وهذا يعني أن Domain Users يجب أن يكون لديها سمة gidNumber.

إذا لم يتم توفير '--unix-home'، فسيتم تعيين الدليل الرئيسي لمستخدم Unix إلى /home/DOMAIN/username.

إذا لم يتم توفير '--login-shell'، فسيتم تعيين shell تسجيل دخول Unix للمستخدم إلى '/bin/sh'

إذا لم يتم توفير '---gecos'، فسيتم تعيين حقل gecos الخاص بمستخدم Unix إلى سمة 'CN' الخاصة بالمستخدم.

أضف 'idmap_ldb:use rfc2307 = Yes' إلى smb.conf على وحدات التحكم بالنطاق (DCs) لاستخدام هذه السمات لتعيين UID/GID.

يمكن تشغيل الأمر من معرف المستخدم root أو معرف مستخدم آخر مصرح له. يمكن استخدام الخيار -H أو --URL= لتنفيذ الأمر مقابل خادم بعيد.

المثال 1:

samba-tool user addunixattrs User1 10001

يوضح المثال 1 كيفية إضافة سمات RFC2307 إلى حساب مستخدم ممكّن النطاق، وسيتم تعيين Domain Users كـ gidNumber للمستخدم.

سيتم تعيين معرف Unix الخاص بالمستخدم إلى '10001'، شريطة أن هذا المعرف غير مستخدم بالفعل.

المثال 2:

samba-tool user addunixattrs User2 10002 --gid-number=10001 --unix-home=/home/User2

يوضح المثال 2 كيفية إضافة سمات RFC2307 إلى حساب مستخدم ممكّن النطاق.

سيتم تعيين معرف Unix الخاص بالمستخدم إلى '10002'، شريطة أن هذا المعرف غير مستخدم بالفعل.

سيتم تعيين سمة gidNumber الخاصة بالمستخدم إلى '10001'

سيتم تعيين الدليل الرئيسي الخاص بمستخدم Unix إلى '/home/user2'

المثال 3:

يوضح المثال 3 كيفية إضافة سمات RFC2307 إلى حساب مستخدم ممكّن النطاق.

سيتم تعيين معرف Unix الخاص بالمستخدم إلى '10003'، شريطة أن هذا المعرف غير مستخدم بالفعل. سيتم تعيين سمة gidNumber الخاصة بالمستخدم إلى '10001'. سيتم تعيين shell تسجيل دخول Unix الخاص بالمستخدم إلى '/bin/false'. سيتم تعيين حقل gecos الخاص بالمستخدم إلى 'User3 test'.

NAME

samba-tool - Samba collection of administration commands

SYNOPSIS

samba-tool [options] subcommand [subcommand arguments]

DESCRIPTION

The samba-tool command is a collection of administration commands for Samba. These commands are intended to replace many of the older smbtool commands and add new functionality.

Note that samba-tool is a work in progress and new commands and options are added frequently.

OPTIONS

samba-tool supports the following options:

--verbose, -V
Enable verbose output.
--debug, -d
Enable debug output.
--option=VALUE
Set a Samba configuration option.
--option-file=FILENAME
Read Samba configuration options from a file.
--configfile=FILENAME
Use the specified configuration file.
--no-config
Do not read any configuration file.

Looks at NTDS connections.

Looks at repsTo and repsFrom objects.

Looks at replication lag as shown by the uptodateness vectors.

GRAPHICAL MODES

--distance

Distances between DCs are shown in a matrix in the terminal.

--dot

Generate Graphviz dot output (for ntdsconn and reps modes). When viewed using dot or xdot, this shows the network as a graph with DCs as vertices and connections edges. Certain types of degenerate edges are shown in different colours or line-styles.

--xdot

Generate Graphviz dot output as with [--dot] and attempt to view it immediately using /usr/bin/xdot.

-r

Normally, samba-tool talks to one database; with the [-r] option attempts are made to contact all the DCs known to the first database. This is necessary for samba-tool visualize uptodateness and for samba-tool visualize reps because the repsFrom/To objects are not replicated, and it can reveal replication issues in other modes.
