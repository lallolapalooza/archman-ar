SDRVRFP

الغرض:

!>
!> SDRVRFP يختبر إجراءات LAPACK RFP:
!>     SPFTRF, SPFTRS, و SPFTRI.
!>
!> هذا الإجراء الاختباري يتبع نفس اختبارات DDRVPO (اختبار لمحلل المصفوفات المتناظرة المحددة موجبة بالصيغة الكاملة).
!>
!> يتم إجراء الاختبارات بالصيغة الكاملة، ويتم التحويل ذهابًا وإيابًا من الصيغة الكاملة إلى صيغة RFP باستخدام الإجراءات STRTTF و STFTTR.
!>
!> أولاً، يتم إنشاء مصفوفة A محددة بحجم N. هناك تسعة أنواع مختلفة من المصفوفات الممكنة.
!>  1. قطرية                        6. عشوائية، CNDNUM = sqrt(0.1/EPS)
!>  2. عشوائية، CNDNUM = 2              7. عشوائية، CNDNUM = 0.1/EPS
!> *3. الصف والعمود الأول أصفار       8. مقياس قريب من الحد الأدنى للفيضان
!> *4. الصف والعمود الأخير أصفار       9. مقياس قريب من الحد الأقصى للفيضان
!> *5. الصف والعمود الأوسط أصفار
!> (* - يختبر مخارج الخطأ من SPFTRF، لا يتم حساب نسب الاختبار)
!> يتم إنشاء حل XACT بحجم N-by-NRHS والطرف الأيمن B المرتبط به. ثم يتم استدعاء SPFTRF لحساب L (أو U)، العامل Cholesky للمصفوفة A. ثم يتم استخدام L (أو U) لحل نظام المعادلات الخطي AX = B. هذا يعطي X. ثم يتم استخدام L (أو U) لحساب معكوس A، وهو AINV. ثم يتم إجراء الاختبارات الأربعة التالية:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) أو
!>     norm( U'*U - A ) / ( N * norm(A) * EPS )،
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS )،
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS )،
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS )،
!> حيث EPS هو دقة الآلة، RCOND هو رقم حالة A، و norm( . ) هو المعيار 1 (للـ 1، 2، 3) والمعيار اللانهائي (للـ 4).
!> تحدث الأخطاء عندما لا يكون المعامل INFO كما هو متوقع. تحدث الإخفاقات عندما تكون نسبة الاختبار أكبر من THRES.
!>

sdrvrfp(3)

NAME

sdrvrfp - sdrvrfp

SYNOPSIS

subroutine sdrvrfp(n, r, ldr, c, ldc, p, work)

Arguments

integer, intent(in) :: n real, dimension(ldr, *) integer, intent(in) :: ldr real, dimension(ldc, *) integer, intent(in) :: ldc real, dimension(*) :: p real, dimension(*) :: work

Function/Subroutine Documentation

sdrvrfp performs the reverse orthogonal transformation to the solution of a balanced pair of general matrices, (A, B), to (S, S-1B*S) in the case of the generalized eigenvalue problem A*x = lambda*B*x.

This subroutine is used in the calculation of the generalized eigenvalues of the pair of matrices (A, B).

توثيق الدالة/الإجراء الفرعي

sdrvrfp يقوم بالتحويل المتعامد العكسي لحل زوج من المصفوفات العامة، (A, B)، إلى (S, S-1B*S) في حالة مشكلة القيمة الذاتية المعممة A*x = lambda*B*x.

يستخدم هذا الإجراء الفرعي في حساب القيم الذاتية المعممة للمصفوفة الزوجية (A, B).
