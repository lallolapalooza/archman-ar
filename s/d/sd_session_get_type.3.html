NAME

sd_session_get_display, sd_session_get_tty, sd_session_is_active, sd_session_get_seats, sd_session_get_scope, sd_session_get_service, sd_session_get_desktop, sd_session_get_remote_host, sd_session_get_remote_user, sd_session_get_state, sd_session_get_type, sd_session_get_id, sd_session_get_pid, sd_session_get_username, sd_session_get_start_time, sd_session_get_leader - Get information about sessions

#include <systemd/sd-login.h>

int sd_session_get_display(const char **display);
int sd_session_get_tty(const char **tty);
int sd_session_is_active(const char *session_id);
int sd_session_get_seats(const char *session_id, const char ***seats);
int sd_session_get_scope(const char *session_id, const char **scope);
int sd_session_get_service(const char *session_id, const char **service);
int sd_session_get_desktop(const char *session_id, const char **desktop);
int sd_session_get_remote_host(const char *session_id, const char **remote_host);
int sd_session_get_remote_user(const char *session_id, const char **remote_user);
int sd_session_get_state(const char *session_id, const char **state);
int sd_session_get_type(const char *session_id, const char **type);
int sd_session_get_id(const char *session_id, const char **id);
int sd_session_get_pid(const char *session_id, pid_t *pid);
int sd_session_get_username(const char *session_id, const char **username);
int sd_session_get_start_time(const char *session_id, struct timespec *ts);
int sd_session_get_leader(const char *session_id, pid_t *leader);

DESCRIPTION

The functions described here retrieve information about logged-in sessions. The parameters session_id, if not NULL, specify the session to query. If session_id is NULL, the functions will attempt to determine the session from the current environment, as described in sd-login(3).

sd_session_get_display(), sd_session_get_tty(), sd_session_get_seats(), sd_session_get_scope(), sd_session_get_service(), sd_session_get_desktop(), sd_session_get_remote_host(), sd_session_get_remote_user(), sd_session_get_state(), sd_session_get_type(), sd_session_get_id(), sd_session_get_pid(), sd_session_get_username(), sd_session_get_start_time() and sd_session_get_leader() all return 0 or a positive integer on success. On failure, these calls return a negative errno-style error code.

The return value of sd_session_is_active() is 1 if the session is active, 0 if it is not, and a negative error code on failure.

The strings returned by these functions are valid until the next call to any sd-login function, or until the memory is freed by the caller. The caller must free the memory allocated for the returned strings and arrays using free(3).

Note that not all fields might be set for every session. For example, a session might not have a TTY associated with it, or it might not be a remote session. In such cases, the output parameters will be set to NULL, or an empty string for scalar return values.

sd_session_get_display(), sd_session_get_tty(), sd_session_get_remote_user() and sd_session_get_remote_host() return 0 or a positive integer. On failure, these calls return a negative errno-style error code.

Errors

Returned errors may indicate the following problems:

-ENXIO

The specified session does not exist.

-ENODATA

The given field is not specified for the described session.

-EINVAL

An input parameter was invalid (out of range, or NULL, where that is not accepted).

-ENOMEM

Memory allocation failed.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
