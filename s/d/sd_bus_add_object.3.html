sd_bus_add_object(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

NAME

sd_bus_add_object, sd_bus_add_object_vtable, sd_bus_add_fallback, sd_bus_add_fallback_vtable, sd_bus_add_filter, sd_bus_object_find_t, sd_bus_property_get_t, sd_bus_property_set_t — Add a new object to the bus

SYNOPSIS

#include <systemd/sd-bus.h>

sd_bus_add_object(3);
sd_bus_add_object_vtable(3);
sd_bus_add_fallback(3);
sd_bus_add_fallback_vtable(3);
sd_bus_add_filter(3);
sd_bus_object_find_t(3);
sd_bus_property_get_t(3);
sd_bus_property_set_t(3);

DESCRIPTION

The functions described here are part of the sd-bus(3) low-level API to manage objects and implement bus logic.

They are implemented as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
