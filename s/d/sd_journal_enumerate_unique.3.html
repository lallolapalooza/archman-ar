sd_journal_enumerate_unique(3)

sd_journal_enumerate_unique - Get the next unique field value from the journal

NAME

sd_journal_enumerate_unique - Get the next unique field value from the journal

SYNOPSIS

#include <systemd/sd-journal.h>

int sd_journal_enumerate_unique(sd_journal *j, const char **field,
                                const char **value);

DESCRIPTION

The sd_journal_enumerate_unique() function may be used to iterate over all unique field names and their associated values stored in the journal. It is used in conjunction with sd_journal_next_unique(). Initially, sd_journal_seek_head() or sd_journal_next() might be called. Then, sd_journal_enumerate_unique() is called in a loop. In each iteration, it returns the next available field name in field and its corresponding value in value.

If field or value are passed as NULL, the corresponding return value is not stored. This is useful to skip fields.

The journal object j must have been initialized with sd_journal_open().

The function is intended to be called repeatedly. In each call, the journal cursor is advanced. The iteration stops when sd_journal_enumerate_unique() returns 0.

The returned strings pointed to by field and value are owned by the journal object j and must not be freed. They are only valid until the next journal-related call on the same j object.

RETURN VALUE

On success, sd_journal_enumerate_unique() returns a positive integer if a field was found, and 0 if the end of the unique fields has been reached. On failure, it returns a negative errno-style error code.

NOTES

This function is a convenience function. For more control over field iteration, use sd_journal_get_unique() in combination with sd_journal_field_get().

EXAMPLES

This example iterates over all unique field names and values in the journal and prints them.

#include <stdio.h>
#include <systemd/sd-journal.h>

int main(void) {
    sd_journal *j = NULL;
    int r;

    r = sd_journal_open(&j, SD_JOURNAL_LOCAL_ONLY);
    if (r < 0) {
        fprintf(stderr, "Failed to open journal: %s\n", strerror(-r));
        return 1;
    }

    // Optional: Seek to the beginning of the journal
    // sd_journal_seek_head(j);

    while ((r = sd_journal_enumerate_unique(j, NULL, NULL)) > 0) {
        const char *field, *value;
        r = sd_journal_enumerate_unique(j, &field, &value);
        if (r < 0) {
            fprintf(stderr, "Failed to enumerate unique field: %s\n", strerror(-r));
            break;
        }
        if (r == 0) {
            break; // End of unique fields
        }
        printf("%s=%s\n", field, value);
    }

    sd_journal_close(j);
    return 0;
}
