sd_journal_perror_with_location(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

NAME

sd_journal_perror_with_location, sd_journal_print_with_location, sd_journal_printv_with_location, sd_journal_send_with_location, sd_journal_sendv_with_location - إرسال رسائل إلى سجل النظام.

SYNOPSIS

#include <systemd/sd-journal.h>

int sd_journal_perror_with_location(const char *file, int line, const char *msg);
int sd_journal_print_with_location(const char *file, int line, const char *format, ...);
int sd_journal_printv_with_location(const char *file, int line, const char *format, va_list ap);
int sd_journal_send_with_location(const char *file, int line, const char *format, ...);
int sd_journal_sendv_with_location(const char *file, int line, const char *format, va_list ap);

DESCRIPTION

تسمح هذه الدوال بتسجيل رسائل إلى سجل نظام systemd (journal). تتيح لك الدوال الملحقة بـ "_with_location" تحديد اسم الملف ورقم السطر حيث تم استدعاء الدالة، مما يسهل تتبع مصدر الرسائل.

  • sd_journal_perror_with_location(): يكتب رسالة خطأ بالصيغة `msg` مع إضافة وصف للخطأ الحالي (من `errno(3)`) إلى السجل.

  • sd_journal_print_with_location(): تنسق الرسالة باستخدام `format` (بنفس صيغة printf(3)) وتضيفها إلى السجل. لا يتم إرسال هذه الرسائل كـ "حقائق" (fields) إلى سجل النظام، بل يتم دمجها في حقل `MESSAGE`.

  • sd_journal_printv_with_location(): نفس سلوك sd_journal_print_with_location() ولكنها تأخذ قائمة متغيرات من الوسائط (`va_list`).

  • sd_journal_send_with_location(): تنسق الرسالة باستخدام `format` (بنفس صيغة printf(3)) وتقوم بإرسالها كـ "حقائق" (fields) منفصلة إلى سجل النظام. يجب أن تكون الوسائط عبارة عن أزواج من المفتاح/القيمة، حيث يمثل كل زوج "KEY=VALUE". يتم دمج جميع الحقائق في عملية تسجيل واحدة.

  • sd_journal_sendv_with_location(): نفس سلوك sd_journal_send_with_location() ولكنها تأخذ قائمة متغيرات من الوسائط (`va_list`).

إذا كان سجل نظام systemd غير قيد التشغيل (المقبس غير موجود)، فلن تقوم هذه الدوال بأي شيء وستعيد 0.

RETURN VALUE

عند النجاح، تعيد هذه الدوال قيمة موجبة. عند الفشل، تعيد قيمة سالبة تشير إلى رمز خطأ.

إذا لم يكن سجل نظام systemd قيد التشغيل (المقبس غير موجود)، فستعيد هذه الدوال 0.

THREAD SAFETY

جميع الدوال المدرجة هنا آمنة للاستخدام في بيئات متعددة الخيوط (thread-safe) ويمكن استدعاؤها بشكل متوازٍ من خيوط متعددة.

sd_journal_sendv() و sd_journal_sendv_with_location() تعتبران "آمنتين للإشارة غير المتزامنة" (async signal safe) بالمعنى المحدد في signal-safety(7).

sd_journal_print()، sd_journal_printv()، sd_journal_send()، sd_journal_perror()، ونظائرها الملحقة بـ "_with_location" ليست آمنة للإشارة غير المتزامنة.

NOTES

الدوال الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها وربطها مع ملف pkg-config(1) الخاص بـ libsystemd.

الكود الموصوف هنا يستخدم getenv(3)، والتي تم التصريح بأنها ليست آمنة للاستخدام في بيئات متعددة الخيوط. هذا يعني أن الكود الذي يستدعي الدوال الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط متوازٍ. يوصى بإجراء استدعاءات لـ setenv() فقط في مرحلة مبكرة من البرنامج عندما لم يتم بدء أي خيوط أخرى.
