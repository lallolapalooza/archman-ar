sd_bus_reply_method_errno(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_REPLY_METHOD_ERROR(3) sd_bus_reply_method_error SD_BUS_REPLY_METHOD_ERROR(3)

الاسم

sd_bus_reply_method_error, sd_bus_reply_method_errorf, sd_bus_reply_method_errorfv, sd_bus_reply_method_errno, sd_bus_reply_method_errnof, sd_bus_reply_method_errnofv - الرد بخطأ على استدعاء طريقة D-Bus

ملخص

#include <systemd/sd-bus.h>

int sd_bus_reply_method_error(sd_bus_message *call, const sd_bus_error *e);

int sd_bus_reply_method_errorf(sd_bus_message *call, const char *name, const char *format, ...);

int sd_bus_reply_method_errorfv(sd_bus_message *call, const char *name, const char *format, va_list ap);

int sd_bus_reply_method_errno(sd_bus_message *call, int error, const sd_bus_error *p);

int sd_bus_reply_method_errnof(sd_bus_message *call, int error, const char *format, ...);

int sd_bus_reply_method_errnofv(sd_bus_message *call, int error, const char *format, va_list ap);

الوصف

تقوم الدالة sd_bus_reply_method_error() بإرسال رد خطأ إلى الرسالة call. تحدد بنية الخطأ e الخطأ المراد إرساله، ويتم استخدامها كما هو موضح في sd_bus_message_new_method_error(3). إذا لم يكن هناك رد متوقع على call، فإن هذه الدالة تنجح دون إرسال رد.

sd_bus_reply_method_errorf() هي لـ sd_bus_reply_method_error() كما أن sd_bus_message_new_method_errorf() هي لـ sd_bus_message_new_method_error().

sd_bus_reply_method_errno() هي لـ sd_bus_reply_method_error() كما أن sd_bus_message_new_method_errno() هي لـ sd_bus_message_new_method_error().

sd_bus_reply_method_errnof() هي لـ sd_bus_reply_method_error() كما أن sd_bus_message_new_method_errnof() هي لـ sd_bus_message_new_method_error().

قيمة الإرجاع

تعيد هذه الدالة عددًا صحيحًا غير سالب إذا تم إرسال رد الخطأ بنجاح أو إذا كان call لا يتوقع ردًا. عند الفشل، فإنها تعيد رمز خطأ سالبًا بأسلوب errno.

الأخطاء

قد تشير الأخطاء المعادة إلى المشاكل التالية:

-EINVAL

المعلمة الإدخال call هي NULL.

الرسالة call ليست رسالة استدعاء طريقة.

الرسالة call غير مرتبطة بناقل.

معلمة الخطأ e لـ sd_bus_reply_method_error() غير مضبوطة، انظر sd_bus_error_is_set(3).

-EPERM

تم ختم الرسالة call.

-ENOTCONN

الناقل الذي ترتبط به الرسالة call غير متصل.

-ENOMEM

فشل تخصيص الذاكرة.

بالإضافة إلى ذلك، يمكن إرجاع أي خطأ تعيده sd_bus_send(3).

ملاحظات

الوظائف الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها وربطها مع ملف pkg-config(1) الخاص بـ libsystemd.

الكود الموصوف هنا يستخدم getenv(3)، والذي تم الإعلان عنه بأنه ليس آمنًا للاستخدام في خيوط متعددة. هذا يعني أن الكود الذي يستدعي الوظائف الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط متوازي. يوصى بالقيام باستدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم تبدأ أي خيوط أخرى.
