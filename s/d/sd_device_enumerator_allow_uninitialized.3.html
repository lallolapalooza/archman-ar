الوصف

تقوم الدالة sd_device_enumerator_add_match_parent() بإضافة مرشح إلى enumerator بحيث يتم تعداد الأجهزة الموجودة تحت شجرة الجهاز parent المحدد فقط. إذا تم استدعاء هذه الدالة عدة مرات، فسيتم مسح الجهاز parent المحدد سابقًا ولن يكون للوظيفة سوى التأثير الأخير.

تقوم الدالة sd_device_enumerator_add_match_property() بإضافة مرشح إلى enumerator بحيث يتم تعداد الأجهزة التي تحتوي على خاصية property المحددة مساوية لـ value فقط. يمكن أن يكون كل من property و value نمطًا عامًا (glob pattern). عندما يتم استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على خاصية واحدة على الأقل من الخصائص المحددة بقيم متطابقة. هذا يعني أن المرشحات يتم ربطها بمنطق OR.

تقوم الدالة sd_device_enumerator_add_match_property_required() بإضافة مرشح إلى enumerator بحيث يتم تعداد الأجهزة التي تحتوي على خاصية property المحددة مساوية لـ value فقط. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عند استدعائها عدة مرات، يتم تعداد الأجهزة التي تحتوي على جميع الخصائص المحددة بقيم متطابقة. هذا يعني أن المرشحات يتم ربطها بمنطق AND.

تقوم الدالة sd_device_enumerator_add_match_subsystem() بإضافة مرشح إلى enumerator بحيث يتم تعداد جميع الأجهزة في subsystem المحدد، عندما يكون match هو true. عندما يكون match هو false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند استدعائها عدة مرات، يتم ربط المرشحات الإيجابية بمنطق OR، والمرشحات السلبية بمنطق AND.

تقوم الدالة sd_device_enumerator_add_match_sysattr() بإضافة مرشح على السمة `sysfs` sysattr المطابقة للقيمة value. يمكن أن يكون value نمطًا عامًا (glob pattern). إذا كان value هو NULL، يتم تضمين الأجهزة التي لديها (إذا كان match هو true) أو ليس لديها (إذا كان match هو false) السمة sysattr المحددة، بغض النظر عن قيمتها. هذا يعني أن NULL يكافئ بشكل عام "*". عندما يتم استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع مرشحات sysattr المحددة فقط. هذا يعني أن هذه المرشحات يتم ربطها بمنطق AND.

تقوم الدالة sd_device_enumerator_add_match_sysname() بإضافة مرشح بحيث يتم تعداد الأجهزة التي اسمها `sysname` الخاص بها يساوي sysname فقط. يمكن أن يكون sysname نمطًا عامًا (glob pattern). عند استدعائها عدة مرات، يتم ربط المرشحات بمنطق OR.

تقوم الدالة sd_device_enumerator_add_nomatch_sysname() بإضافة مرشح بحيث يتم استبعاد الأجهزة التي اسمها `sysname` الخاص بها يساوي sysname من عملية التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند استدعائها عدة مرات، يتم ربط الميزات بمنطق AND.

تقوم الدالة sd_device_enumerator_add_match_tag() بإضافة مرشح بحيث يتم تعداد الأجهزة التي تم تمييزها بالعلامة tag فقط. عند استدعائها عدة مرات، يتم ربط المرشحات بمنطق OR.

تسمح الدالة sd_device_enumerator_allow_uninitialized() بتضمين الأجهزة التي لم يتم تهيئتها بواسطة udev بعد في عملية التعداد.

تقوم الدالة sd_device_enumerator_add_all_parents() بتعداد جميع الأجهزة الأصلية للأجهزة المطابقة. هذا مفيد في الحالات التي تريد فيها تضمين جميع الأجهزة الأصلية في عملية التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة بأكملها التي تؤدي إلى جهاز معين.

قيمة الإرجاع

تعيد جميع الدوال القيمة 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا بأسلوب errno عند الفشل.

الأخطاء

قد تشير الأخطاء المُرجعة إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد المعاملات غير صالح.

أمثلة

مثال 1. اكتشاف أجهزة USB القابلة للإزالة (باستخدام المطابقة والاستثناء)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء مُعدِّد أجهزة جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل إنشاء مُعدِّد الأجهزة: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من النظام الفرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل إضافة مطابقة النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي تحتوي على السمة "removable" بقيمة "0"
     * هذه عادةً ما تكون أجهزة غير قابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل إضافة مطابقة سمة النظام: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على المسار `syspath` للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}
