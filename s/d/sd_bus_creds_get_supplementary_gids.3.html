sd_bus_creds_get_supplementary_gids(3)

NAME

sd_bus_creds_get_supplementary_gids - retrieve supplementary group IDs of the credentials

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_creds_get_supplementary_gids(sd_bus_creds *creds, const gid_t **gids);

DESCRIPTION

The sd_bus_creds_get_supplementary_gids() function retrieves the list of supplementary group IDs associated with the credentials object creds.

The group IDs are returned in the gids parameter. The list is NULL-terminated, meaning the last element of the array is 0. The returned array and its contents are owned by the creds object and must not be freed or modified by the caller. The pointer is valid until creds is destroyed.

RETURN VALUE

On success, sd_bus_creds_get_supplementary_gids() returns a non-negative integer. The number of supplementary group IDs in the list is returned. The actual list of group IDs is placed in the memory location pointed to by gids.

On failure, a negative errno-style error code is returned.

NOTES

This function is part of systemd. The supplementary group IDs are typically obtained from the credentials of the peer process on a D-Bus connection.

HISTORY

The sd_bus_creds_get_supplementary_gids() function was introduced in version 240.

SEE ALSO

sd_bus_creds_new(3), sd_bus_creds_get_pid(3), sd_bus_creds_get_uid(3)

NOTES

The array pointed to by gids is guaranteed to be valid until the creds object is deallocated. The array itself is owned by the creds object and must not be freed or modified.

sd_bus_creds_get_supplementary_gids(3)

الاسم

sd_bus_creds_get_supplementary_gids - استرداد معرفات المجموعات الإضافية للاعتمادات

الملخص

#include <systemd/sd-bus.h>

int sd_bus_creds_get_supplementary_gids(sd_bus_creds *creds, const gid_t **gids);

الوصف

تقوم الدالة sd_bus_creds_get_supplementary_gids() باسترداد قائمة معرفات المجموعات الإضافية المرتبطة بكائن الاعتمادات creds.

يتم إرجاع معرفات المجموعات في المعلمة gids. القائمة منتهية بصفر (NULL-terminated)، مما يعني أن العنصر الأخير في المصفوفة هو 0. المصفوفة التي تم إرجاعها ومحتوياتها مملوكة لكائن creds ويجب على المتصل عدم تحريرها أو تعديلها. يشير المؤشر صالح حتى يتم تدمير creds.

قيمة الإرجاع

عند النجاح، تعيد الدالة sd_bus_creds_get_supplementary_gids() عددًا صحيحًا غير سالب. يتم إرجاع عدد معرفات المجموعات الإضافية في القائمة. يتم وضع القائمة الفعلية لمعرفات المجموعات في الموقع الذاكري الذي يشير إليه gids.

عند الفشل، يتم إرجاع رمز خطأ سالب بصيغة errno.

ملاحظات

هذه الدالة جزء من systemd. عادةً ما يتم الحصول على معرفات المجموعات الإضافية من اعتمادات العملية النظيرة على اتصال D-Bus.
