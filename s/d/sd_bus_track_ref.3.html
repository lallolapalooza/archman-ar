الوصف

sd_bus_track_new() ينشئ كائنًا جديدًا لتتبع أقران الناقل. يتم تخصيص الكائن للناقل المحدد، ويتم إرجاعه في المعلمة *ret. بعد الاستخدام، يجب تحرير الكائن مرة أخرى عن طريق إسقاط المرجع المستحوذ عليه باستخدام sd_bus_track_unref() (انظر أدناه). يمكن استخدام كائن تتبع أقران الناقل لتتبع الأقران على ناقل IPC محدد، للحالات التي يستخدم فيها الأقران واحدًا أو أكثر من الكائنات المحلية، من أجل التحكم في دورة حياة الكائنات المحلية وضمان بقائها طالما أن الأقران الذين يحتاجونها موجودون، ويتم إسقاطها (وربما تدميرها) بمجرد اختفاء جميع الأقران ذوي الصلة. يمكن استخدام كل كائن تتبع أقران ناقل لتتبع صفر أو واحد أو أكثر من الأقران في وقت واحد. يتم إضافة مراجع إلى أقران ناقل محددين عبر sd_bus_track_add_name(3) أو sd_bus_track_add_sender(). يمكن إسقاطها مرة أخرى عبر sd_bus_track_remove_name() و sd_bus_track_remove_sender(). بدلاً من ذلك، يتم إزالة المراجع على الأقران تلقائيًا عند فصلهم عن الناقل. إذا لم يكن NULL، فقد تحدد handler دالة يتم استدعاؤها كلما تم إسقاط المرجع الأخير، بغض النظر عما إذا كان المرجع قد تم إسقاطه صراحةً عبر sd_bus_track_remove_name() أو ضمنيًا لأن القرين فصل عن الناقل. يمكن استخدام المعلمة الأخيرة userdata لإرفاق مؤشر بيانات مستخدم عام بالكائن. يتم تمرير هذا المؤشر إلى دالة رد النداء عند استدعائها.

sd_bus_track_ref() ينشئ مرجعًا جديدًا لكائن تتبع أقران الناقل. لن يتم تدمير هذا الكائن حتى يتم استدعاء sd_bus_track_unref() عدد المرات نفسه زائد مرة أخرى. بمجرد انخفاض عدد المراجع إلى الصفر، لا يمكن استخدام الكائن المحدد بعد الآن، والمكالمات الإضافية إلى sd_bus_track_ref() أو sd_bus_track_unref() على نفس الكائن غير قانونية.

sd_bus_track_unref() يدمر مرجعًا لكائن تتبع أقران الناقل.

sd_bus_track_unrefp() مشابه لـ sd_bus_track_unref() ولكنه يأخذ مؤشرًا إلى مؤشر لكائن sd_bus_track. هذه المكالمة مفيدة بالاقتران مع Clean-up Variable Attribute[1] الخاصة بـ GCC و LLVM. لاحظ أن هذه الوظيفة معرفة كدالة مضمنة.

sd_bus_track_ref() و sd_bus_track_unref() و sd_bus_track_unrefp() لا تنفذ أي عملية إذا كان كائن تتبع أقران الناقل الممرر هو NULL.

قد توجد كائنات تتبع أقران الناقل في وضعين: بشكل افتراضي تعمل في وضع غير تكراري، ولكن يمكن تبديلها اختياريًا إلى وضع تكراري. إذا كانت تعمل في الوضع الافتراضي غير التكراري، يتم تتبع القرين أو لا يتم تتبعه. في هذا الوضع، استدعاء sd_bus_track_add_name() عدة مرات متتالية لنفس القرين يعادل تمامًا استدعائه مرة واحدة فقط، حيث يضيف الاستدعاء القرين إلى مجموعة الأقران الذين يتم تتبعهم إذا لزم الأمر، ولا ينفذ أي عملية إذا كان القرين يتم تتبعه بالفعل. يقوم استدعاء واحد لـ sd_bus_track_remove_name() بإزالة المرجع على القرين مرة أخرى، بغض النظر عن عدد المرات التي تم فيها استدعاء sd_bus_track_add_name() من قبل. إذا كانت تعمل في وضع تكراري، يتم عد عدد المرات التي تم فيها استدعاء sd_bus_track_add_name() لنفس اسم القرين ويجب استدعاء sd_bus_track_remove_name() نفس العدد من المرات قبل ألا يتم تتبع القرين بعد الآن، باستثناء الحالة التي يختفي فيها القرين المتتبع من الناقل، وفي هذه الحالة يكون العدد غير ذي صلة ويتم إزالة تتبع القرين المحدد على الفور. يمكن استخدام sd_bus_track_get_recursive() لتحديد ما إذا كان كائن تتبع أقران الناقل يعمل في وضع تكراري. يمكن استخدام sd_bus_track_set_recursive() لتمكين أو تعطيل الوضع التكراري. بشكل افتراضي، يعمل كائن تتبع أقران الناقل في وضع غير تكراري، وبالتالي فإن sd_bus_track_get_recursive() لكائن تم تخصيصه حديثًا يعيد قيمة تساوي صفرًا. استخدم sd_bus_track_set_recursive() لتمكين الوضع التكراري، مباشرة بعد التخصيص. يأخذ معلمة منطقية لتمكين أو تعطيل الوضع التكراري. لاحظ أن كائنات التتبع التي تم فيها استدعاء sd_bus_track_add_name() مرة واحدة على الأقل (والتي تتتبع بالفعل قرينًا واحدًا أو أكثر) قد لا يتم تبديلها من الوضع التكراري إلى الوضع غير التكراري.

sd_bus_track_get_bus() يعيد كائن الناقل الذي ينتمي إليه كائن تتبع أقران الناقل. يعيد كائن الناقل الذي تم تمريره في البداية إلى sd_bus_track_new() عند تخصيص الكائن.

sd_bus_track_get_userdata() يعيد مؤشر بيانات المستخدم العام الذي تم تعيينه على كائن تتبع أقران الناقل وقت الإنشاء باستخدام sd_bus_track_new() أو في وقت لاحق، باستخدام sd_bus_track_set_userdata().

قيمة الإرجاع

عند النجاح، تعيد sd_bus_track_new() و sd_bus_track_set_recursive() القيمة 0 أو عددًا صحيحًا موجبًا. عند الفشل، تعيد رمز خطأ سالبًا على غرار errno.

sd_bus_track_ref() تعيد دائمًا المعلمة.

sd_bus_track_unref() تعيد دائمًا NULL.

sd_bus_track_get_recursive() تعيد 0 إذا تم تحديد الوضع غير التكراري (افتراضي)، وأكثر من 0 إذا تم تحديد الوضع التكراري. عند الفشل، يتم إرجاع رمز خطأ سالبًا على غرار errno.

sd_bus_track_get_bus() يعيد كائن الناقل المرتبط بكائن تتبع أقران الناقل.

sd_bus_track_get_userdata() يعيد مؤشر بيانات المستخدم العام المرتبط بكائن تتبع أقران الناقل. sd_bus_track_set_userdata() يعيد مؤشر بيانات المستخدم السابق الذي تم تعيينه.

ملكية المرجع

تقوم الدالة sd_bus_track_new() بإنشاء كائن جديد ويمتلك المتصل المرجع الوحيد. عندما لا تكون هناك حاجة إليه بعد الآن، يجب تدمير هذا المرجع باستخدام sd_bus_track_unref().

الأخطاء

قد تشير الأخطاء المرجعة إلى المشاكل التالية:

-EBUSY

تمت بالفعل إضافة أقران الناقل إلى كائن تتبع أقران الناقل وتم استدعاء sd_bus_track_set_recursive() لتغيير وضع التتبع.

-EINVAL

المعلمة المحددة غير صالحة (NULL في حالة معلمات الإخراج).

-ENOMEM

فشل تخصيص الذاكرة.

#include <systemd/sd-bus.h>
int sd_bus_track_ref(sd_bus_track *track);

int sd_bus_track_set_recursive(sd_bus_track *track, int recursive);
sd_bus *sd_bus_track_get_bus(sd_bus_track *track);
void *sd_bus_track_get_userdata(sd_bus_track *track);
void sd_bus_track_set_userdata(sd_bus_track *track, void *userdata);

DESCRIPTION

sd_bus_track_ref() increments the reference count of the bus track object `track`.

sd_bus_track_unref() decrements the reference count of the bus track object `track`. If the reference count drops to zero, the object is deallocated.

sd_bus_track_unrefp() is similar to sd_bus_track_unref(), but takes and sets the pointer to the pointer to NULL on deallocation. This is useful to prevent use-after-free bugs.

sd_bus_track_get_recursive() returns whether the bus track object `track` is configured to track recursively. If it is, any new bus connections created by the bus object `track` is associated with will also be tracked. This defaults to false.

sd_bus_track_set_recursive() configures whether the bus track object `track` should track recursively. If `recursive` is true, new bus connections created by the bus object `track` is associated with will also be tracked.

sd_bus_track_get_bus() returns the bus object that `track` is associated with.

sd_bus_track_get_userdata() returns the arbitrary user data pointer that was previously set on `track` with sd_bus_track_set_userdata().

sd_bus_track_set_userdata() sets the arbitrary user data pointer `userdata` on the bus track object `track`. This may be useful for tracking additional state related to the track.

RETURN VALUE

sd_bus_track_ref() returns 0 on success, and a negative errno value on failure.

sd_bus_track_unref() returns the same pointer as passed in `track` if the reference count is still greater than zero, or NULL otherwise. It is safe to pass NULL to this function.

sd_bus_track_unrefp() returns NULL. It is safe to pass NULL to this function.

sd_bus_track_get_recursive() returns a non-zero integer if recursive tracking is enabled, and zero otherwise.

sd_bus_track_get_bus() returns a pointer to the associated bus object.

sd_bus_track_get_userdata() returns the user data pointer.

sd_bus_track_set_recursive() returns 0 on success, and a negative errno value on failure.

sd_bus_track_set_userdata() returns 0 on success, and a negative errno value on failure.

REFERENCE OWNERSHIP

The caller gains full ownership of the reference returned by any of the functions that return a `sd_bus_track *` pointer. This ownership is transferred to the caller by the caller passing a pointer to the return value to sd_bus_track_unref(), or by passing to sd_bus_track_unrefp().

NOTES

All functions listed here are thread-safe. They may be safely called from any context.

New bus tracks may be created using sd_bus_track_new(), see sd-bus(3).

Bus tracks may be added to a bus using sd_bus_track_add_name(), see sd_bus_track_add_name(3).

الوصف

sd_bus_track_ref() يزيد عدد المراجع لكائن مسار الناقل `track`.

sd_bus_track_unref() يقلل عدد المراجع لكائن مسار الناقل `track`. إذا انخفض عدد المراجع إلى الصفر، يتم تحرير الكائن.

sd_bus_track_unrefp() مشابه لـ sd_bus_track_unref()، ولكنه يأخذ ويضبط المؤشر إلى المؤشر إلى NULL عند التحرير. هذا مفيد لمنع أخطاء الاستخدام بعد التحرير.

sd_bus_track_get_recursive() تعيد ما إذا كان كائن مسار الناقل `track` تم تكوينه للتتبع بشكل تكراري. إذا كان كذلك، فسيتم أيضًا تتبع أي اتصالات ناقل جديدة يتم إنشاؤها بواسطة كائن الناقل الذي يرتبط به `track`.

sd_bus_track_set_recursive() تقوم بتكوين ما إذا كان يجب على كائن مسار الناقل `track` التتبع بشكل تكراري. إذا كان `recursive` صحيحًا، فسيتم أيضًا تتبع اتصالات الناقل الجديدة التي يتم إنشاؤها بواسطة كائن الناقل الذي يرتبط به `track`.

sd_bus_track_get_bus() تعيد كائن الناقل الذي يرتبط به `track`.

sd_bus_track_get_userdata() تعيد مؤشر بيانات المستخدم العشوائي الذي تم تعيينه سابقًا على `track` باستخدام sd_bus_track_set_userdata().

sd_bus_track_set_userdata() تعين مؤشر بيانات المستخدم العشوائي `userdata` على كائن مسار الناقل `track`. قد يكون هذا مفيدًا لتتبع الحالة الإضافية المتعلقة بالمسار.

قيمة الإرجاع

sd_bus_track_ref() تعيد 0 عند النجاح، وقيمة خطأ سالبة (errno) عند الفشل.

sd_bus_track_unref() تعيد نفس المؤشر الذي تم تمريره في `track` إذا كان عدد المراجع لا يزال أكبر من الصفر، أو NULL بخلاف ذلك. من الآمن تمرير NULL لهذه الدالة.

sd_bus_track_unrefp() تعيد NULL. من الآمن تمرير NULL لهذه الدالة.

sd_bus_track_get_recursive() تعيد عددًا صحيحًا غير صفري إذا كان التتبع التكراري ممكّنًا، وصفرًا بخلاف ذلك.

sd_bus_track_get_bus() تعيد مؤشرًا إلى كائن الناقل المرتبط.

sd_bus_track_get_userdata() تعيد مؤشر بيانات المستخدم.

sd_bus_track_set_recursive() تعيد 0 عند النجاح، وقيمة خطأ سالبة (errno) عند الفشل.

sd_bus_track_set_userdata() تعيد 0 عند النجاح، وقيمة خطأ سالبة (errno) عند الفشل.

ملكية المراجع
