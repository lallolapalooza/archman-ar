sd_bus_set_trusted(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

NAME

sd_bus_set_trusted - تعيين صلاحيات الاتصال لـ D-Bus

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_set_trusted(sd_bus *bus, int trusted);

DESCRIPTION

تحدد الدالة sd_bus_set_trusted() ما إذا كان اتصال D-Bus المعطى bus سيتم التعامل معه على أنه "موثوق به" أم لا.

إذا تم تعيين trusted إلى قيمة غير صفرية، فسيتم اعتبار الاتصال موثوقًا به. إذا تم تعيين trusted إلى صفر، فسيتم اعتبار الاتصال غير موثوق به.

بشكل افتراضي، يتم اعتبار جميع اتصالات D-Bus غير موثوق بها.

يجب استخدام هذا الخيار فقط لاتصالات D-Bus التي يتم إنشاؤها من خلال اتصال D-Bus محلي تم التحقق منه، مثل الاتصال مع bus الخاص بالمستخدم (user bus) أو الخاص بالنظام (system bus). في مثل هذه الحالات، قد يتم تمرير اتصال D-Bus الذي تم إنشاؤه من خلال آلية مصادقة D-Bus.

عندما يكون الاتصال موثوقًا به، سيتم تخطي بعض آليات الأمان، مثل التحقق من صلاحيات الوصول، وسيتم اعتبار معرف المستخدم (UID) لعملية العميل الموثوق بها على أنه خاص بالعملية.

قد يؤدي استخدام هذا الخيار بشكل غير صحيح إلى ثغرات أمنية خطيرة. استخدمه بحذر شديد.

تتأثر الإعدادات التالية بشكل خاص بهذا الخيار:

allow_interactive_authorization

عندما يكون الاتصال موثوقًا به، يتم تعيين هذه الخاصية تلقائيًا إلى false.

peer_cred_type

إذا كان نوع بيانات الاعتماد هو SD_BUS_CREDS_UNIX، فسيتم تخطي التحقق من صلاحيات الوصول.

RETURN VALUE

على النجاح، تُرجع الدالة sd_bus_set_trusted() قيمة غير صفرية. على الفشل، تُرجع قيمة سالبة.
