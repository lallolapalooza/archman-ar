sd_bus_reply_method_errorf(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_REPLY_METHOD_ERROR(3) sd_bus_reply_method_error SD_BUS_REPLY_METHOD_ERROR(3)

الاسم

sd_bus_reply_method_error, sd_bus_reply_method_errorf, sd_bus_reply_method_errorfv, sd_bus_reply_method_errno, sd_bus_reply_method_errnof, sd_bus_reply_method_errnofv - الرد بخطأ على استدعاء طريقة D-Bus

ملخص

#include <systemd/sd-bus.h>

int sd_bus_reply_method_error(sd_bus_message *call, const sd_bus_error *e);

int sd_bus_reply_method_errorf(sd_bus_message *call, const char *name, const char *format, ...);

int sd_bus_reply_method_errorfv(sd_bus_message *call, const char *name, const char *format, va_list ap);

int sd_bus_reply_method_errno(sd_bus_message *call, int error, const sd_bus_error *p);

int sd_bus_reply_method_errnof(sd_bus_message *call, int error, const char *format, ...);

int sd_bus_reply_method_errnofv(sd_bus_message *call, int error, const char *format, va_list ap);

الوصف

تقوم الدالة sd_bus_reply_method_error() بإرسال رد خطأ إلى الرسالة call. تحدد بنية الخطأ e الخطأ المراد إرساله، وتُستخدم كما هو موضح في sd_bus_message_new_method_error(3). إذا لم يكن هناك رد متوقع للرسالة call، تنجح هذه الدالة دون إرسال رد.

الدالة sd_bus_reply_method_errorf() هي بمثابة sd_bus_message_new_method_errorf() مقارنة بالدالة sd_bus_reply_method_error()، كما أن sd_bus_message_new_method_error() بمثابة sd_bus_message_new_method_error().

الدالة sd_bus_reply_method_errno() هي بمثابة sd_bus_message_new_method_errno() مقارنة بالدالة sd_bus_reply_method_error()، كما أن sd_bus_message_new_method_error() بمثابة sd_bus_message_new_method_error().

الدالة sd_bus_reply_method_errnof() هي بمثابة sd_bus_message_new_method_errnof() مقارنة بالدالة sd_bus_reply_method_error()، كما أن sd_bus_message_new_method_error() بمثابة sd_bus_message_new_method_error().

قيمة الإرجاع

تُرجع هذه الدالة عددًا صحيحًا غير سالب إذا تم إرسال رد الخطأ بنجاح أو إذا لم تكن الرسالة call تتوقع ردًا. عند الفشل، تُرجع رمز خطأ سالب من نوع errno.

الأخطاء

قد تشير الأخطاء المُرجعة إلى المشاكل التالية:

-EINVAL

المعلمة المدخلة call هي NULL.

الرسالة call ليست رسالة استدعاء طريقة.

الرسالة call غير مرتبطة بحافلة.

المعلمة e للخطأ في sd_bus_reply_method_error() غير مُعينة، انظر sd_bus_error_is_set(3).

-EPERM

تم ختم الرسالة call.

-ENOTCONN

الحافلة التي تم ربط الرسالة call بها غير متصلة.

-ENOMEM

فشل تخصيص الذاكرة.

بالإضافة إلى ذلك، قد يتم إرجاع أي خطأ ناتج عن sd_bus_send(3).

ملاحظات

الوظائف الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها والربط معها باستخدام ملف libsystemd pkg-config(1).

الكود الموصوف هنا يستخدم getenv(3)، والذي تم تعريفه بأنه غير آمن للاستخدام في خيوط متعددة. هذا يعني أن الكود الذي يستدعي الوظائف الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط موازٍ. يوصى بإجراء استدعاءات لـ setenv() فقط في مرحلة مبكرة من البرنامج عندما لم يتم بدء أي خيوط أخرى.
