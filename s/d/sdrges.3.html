!>
!> SDRGES يتحقق من مشغل مشكلة القيم الذاتية المعممة غير المتناظرة (الشكل شوري)
!> SGGES.
!>
!> يقوم SGGES بتفكيك A و B كـ Q S Z' و Q T Z' ، حيث يعني ' المقلوب (transpose)،
!> T هو مثلثي علوي، S في شكل شوري معمم (مقسم إلى أجزاء عليا مثلثة، مع أجزاء 1x1 و 2x2
!> على القطر، الأجزاء 2x2 المقابلة لأزواج القيم الذاتية المعممة المترافقة المعقدة)،
!> و Q و Z متعامدان (orthogonal). كما أنه يحسب القيم الذاتية المعممة (alpha(j),beta(j))،
!> j=1,...,n. وبالتالي، w(j) = alpha(j)/beta(j) هو جذر المعادلة المميزة
!>                 det( A - w(j) B ) = 0
!> اختياريًا، يقوم أيضًا بإعادة ترتيب القيم الذاتية بحيث تظهر مجموعة محددة
!> من القيم الذاتية في الجزء القطري الأمامي من الأشكال الشورية.
!>
!> عند استدعاء SDRGES، يتم تحديد عدد من المصفوفات () وعدد من المصفوفات
!> . لكل حجم () ولكل نوع من المصفوفات، سيتم إنشاء زوج من المصفوفات (A, B)
!> واستخدامه للاختبار. لكل زوج مصفوفات، سيتم إجراء الاختبارات الـ 13 التالية
!> ومقارنتها بالعتبة THRESH باستثناء الاختبارات (5)، (11) و (13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (بدون فرز القيم الذاتية)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (بدون فرز القيم الذاتية)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (بدون فرز القيم الذاتية)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (بدون فرز القيم الذاتية)
!>
!> (5)   إذا كانت A في شكل شوري (أي، شكل شبه مثلثي)
!>       (بدون فرز القيم الذاتية)
!>
!> (6)   إذا كانت القيم الذاتية = الأجزاء القطرية للشكل شوري (S, T)،
!>       أي، اختبار الحد الأقصى لـ j حيث D(j) :
!>
!>       إذا كانت alpha(j) حقيقية:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       إذا كانت alpha(j) معقدة:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       و S و T هنا هما الأجزاء القطرية 2x2 من S و T
!>       المقابلة للقيم الذاتية j و j+1.
!>       (بدون فرز القيم الذاتية)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!>            (مع فرز القيم الذاتية).
!>
!> (8)   | I - QQ' | / ( n ulp ) (مع فرز القيم الذاتية).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (مع فرز القيم الذاتية).
!>
!> (10)  إذا كانت A في شكل شوري (أي، شكل شبه مثلثي)
!>       (مع فرز القيم الذاتية).
!>
!> (11)  إذا كانت القيم الذاتية = الأجزاء القطرية للشكل شوري (S, T)،
!>       أي، اختبار الحد الأقصى لـ j حيث D(j) :
!>
!>       إذا كانت alpha(j) حقيقية:
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       إذا كانت alpha(j) معقدة:
!>                                 | det( s S - w T ) |
!>           D(j) = ---------------------------------------------------
!>                  ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!>       و S و T هنا هما الأجزاء القطرية 2x2 من S و T
!>       المقابلة للقيم الذاتية j و j+1.
!>       (مع فرز القيم الذاتية).
!>
!> (12)  إذا نجح الفرز وكان SDIM هو عدد القيم الذاتية
!>       التي تم تحديدها.
!>
!> مصفوفات الاختبار
!> =============
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ القيمة لكل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد الأنواع بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كانت DOTYPE(j) هي .TRUE. ، فسيتم إنشاء نوع المصفوفة.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة هوية ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة صفرية ومصفوفة هوية)
!>
!> (4)  ( I, I )         (زوج من مصفوفات الهوية)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان المنقولة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I هي مصفوفة هوية k x k و J كتلة جوردان (k+1)x(k+1)
!>                       ؛ k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هي diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!>                       بمدخلات قطرية).
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث  قريب من تجاوز الحد و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     حيث Q و Z مصفوفتان متعامدتان عشوائيتان.
!>
!> (17) Q ( T1, T2 ) Z    حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!>                        بمدخلات O(1) عشوائية فوق القطر
!>                        والمدخلات القطرية diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!>                        ( 0, 1, ..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>

NAME

sdrges

Driver routine for generalized eigenvalue problem (A, B)

SYNOPSIS

SUBROUTINE SDRGES( NSIZES, NN, NTYPES, DOTYPE, ISEED, THRESH, NOUNIT,
  A, LDA, B, S, T, Q, LDQ, Z, ALPHAR, ALPHAI, BETA, WORK, LWORK,
  RESULT, BWORK, INFO )

Function/Subroutine Documentation

SDRGES tests the subroutine SGGES, which computes the generalized eigenvalue decomposition of a pair of matrices (A, B).

DOTYPE determines the types of matrices to be used.

Type 1
A and B are upper triangular matrices.
Type 2
A and B are upper triangular matrices, and A is randomly scaled.
Type 3
A is randomly scaled upper triangular, B is upper triangular.
Type 4
A and B are general matrices.
Type 5
A and B are general matrices, and A is randomly scaled.
Type 6
A is randomly scaled general, B is general.
Type 7
A is upper Hessenberg, B is upper triangular.
Type 8
A is upper Hessenberg, B is upper triangular, and A is randomly scaled.
Type 9
A is upper Hessenberg and randomly scaled, B is upper triangular.
Type 10
A and B are upper triangular matrices.
Type 11
A and B are upper triangular matrices.
Type 12
A and B are upper triangular matrices.
Type 13
A and B are random matrices.
Type 14
A is upper triangular, B is diagonal.
Type 15
A is diagonal, B is upper triangular.
Type 16
A is diagonal, B is diagonal.
Type 17
A is upper triangular, B is diagonal, and A is randomly scaled.
Type 18
A is diagonal, B is upper triangular, and A is randomly scaled.
Type 19
A is diagonal, B is diagonal, and A is randomly scaled.
Type 20
A is upper triangular, B is upper triangular.
Type 21
A is upper triangular, B is upper triangular.
Type 22
A is upper triangular, B is upper triangular.
Type 23
A is upper triangular, B is upper triangular.
Type 24
A is upper triangular, B is upper triangular.
Type 25
A is upper triangular, B is upper triangular.
Type 26

Q * diag(T2) * Z where T1 and T2 are random upper-triangular matrices.

Parameters

NSIZES 
!>          NSIZES is INTEGER
!>          The number of sizes of matrices to use.  If it is zero,
!>          SDRGES does nothing.  NSIZES >= 0.

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          An array containing the sizes to be used for the matrices.
!>          Zero values will be skipped.  NN >= 0.

NTYPES

!>          NTYPES is INTEGER
!>          The number of elements in DOTYPE.   If it is zero, SDRGES
!>          does nothing.  It must be at least zero.  If it is MAXTYP+1
!>          and NSIZES is 1, then an additional type, MAXTYP+1 is
!>          defined, which is to use whatever matrix is in A on input.
!>          This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!>          DOTYPE(MAXTYP+1) is .TRUE. .

DOTYPE

!>          DOTYPE is LOGICAL array, dimension (NTYPES)
!>          If DOTYPE(j) is .TRUE., then for each size in NN a
!>          matrix of that size and of type j will be generated.
!>          If NTYPES is smaller than the maximum number of types
!>          defined (PARAMETER MAXTYP), then types NTYPES+1 through
!>          MAXTYP will not be generated. If NTYPES is larger
!>          than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!>          will be ignored.

ISEED

!>          ISEED is INTEGER array, dimension (4)
!>          On entry ISEED specifies the seed of the random number
!>          generator. The array elements should be between 0 and 4095;
!>          if not they will be reduced mod 4096. Also, ISEED(4) must
!>          be odd.  The random number generator uses a linear
!>          congruential sequence limited to small integers, and so
!>          should produce machine independent random numbers. The
!>          values of ISEED are changed on exit, and can be used in the
!>          next call to SDRGES to continue the same random number
!>          sequence.

THRESH

!>          THRESH is REAL
!>          A test will count as  if the , computed as
!>          described above, exceeds THRESH.  Note that the error is
!>          scaled to be O(1), so THRESH should be a reasonably small
!>          multiple of 1, e.g., 10 or 100.  In particular, it should
!>          not depend on the precision (single vs. double) or the size
!>          of the matrix.  THRESH >= 0.

NOUNIT

!>          NOUNIT is INTEGER
!>          The FORTRAN unit number for printing out error messages
!>          (e.g., if a routine returns IINFO not equal to 0.)

A

!>          A is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original A matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.

LDA

!>          LDA is INTEGER
!>          The leading dimension of A, B, S, and T.
!>          It must be at least 1 and at least max( NN ).

B

!>          B is REAL array,
!>                                       dimension(LDA, max(NN))
!>          Used to hold the original B matrix.  Used as input only
!>          if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!>          DOTYPE(MAXTYP+1)=.TRUE.

S

!>          S is REAL array, dimension (LDA, max(NN))
!>          The Schur form matrix computed from A by SGGES.  On exit, S
!>          contains the Schur form matrix corresponding to the matrix
!>          in A.

T

!>          T is REAL array, dimension (LDA, max(NN))
!>          The upper triangular matrix computed from B by SGGES.

Q

!>          Q is REAL array, dimension (LDQ, max(NN))
!>          The (left) orthogonal matrix computed by SGGES.

LDQ

!>          LDQ is INTEGER
!>          The leading dimension of Q and Z. It must
!>          be at least 1 and at least max( NN ).

Z

!>          Z is REAL array, dimension( LDQ, max(NN) )
!>          The (right) orthogonal matrix computed by SGGES.

ALPHAR

!>          ALPHAR is REAL array, dimension (max(NN))

ALPHAI

!>          ALPHAI is REAL array, dimension (max(NN))

BETA

!>          BETA is REAL array, dimension (max(NN))
!>
!>          The generalized eigenvalues of (A,B) computed by SGGES.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) is the k-th
!>          generalized eigenvalue of A and B.

WORK

!>          WORK is REAL array, dimension (LWORK)

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          LWORK >= MAX( 10*(N+1), 3*N*N ), where N is the largest
!>          matrix dimension.

RESULT

!>          RESULT is REAL array, dimension (15)
!>          The values computed by the tests described above.
!>          The values are currently limited to 1/ulp, to avoid overflow.

BWORK

!>          BWORK is LOGICAL array, dimension (N)

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  A routine returned an error code.  INFO is the
!>                absolute value of the INFO value returned.
