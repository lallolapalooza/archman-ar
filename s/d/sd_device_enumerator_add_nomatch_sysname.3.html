الوصف

الدالة sd_device_enumerator_add_match_parent() تضيف مرشحًا إلى enumerator بحيث يتم تعداد الأجهزة فقط ضمن شجرة الجهاز parent المحدد. إذا تم استدعاء هذه الدالة عدة مرات، فسيتم مسح الجهاز parent المحدد سابقًا ولن يكون سوى آخر استدعاء له تأثير.

الدالة sd_device_enumerator_add_match_property() تضيف مرشحًا إلى enumerator بحيث يتم تعداد الأجهزة فقط التي لها property المحدد مطابق للقيمة value. يمكن لكل من property و value أن يكونا نمط glob. عندما يتم استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي لديها واحدة على الأقل من الخصائص المحددة بقيم مطابقة. أي، يتم دمج المرشحات بواسطة OR.

الدالة sd_device_enumerator_add_match_property_required() تضيف مرشحًا إلى enumerator بحيث يتم تعداد الأجهزة فقط التي لها property المحدد مطابق للقيمة value. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عندما يتم استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي لديها جميع الخصائص المحددة بقيم مطابقة. أي، يتم دمج المرشحات بواسطة AND.

الدالة sd_device_enumerator_add_match_subsystem() تضيف مرشحًا إلى enumerator بحيث يتم تعداد جميع الأجهزة في subsystem المحدد، عندما يكون match هو true. عندما يكون match هو false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند استدعائها عدة مرات، يتم دمج المرشحات الإيجابية بواسطة OR، ويتم دمج السلبية بواسطة AND.

الدالة sd_device_enumerator_add_match_sysattr() تضيف مرشحًا على سمة sysfs sysattr مطابقة للقيمة value. يمكن أن تكون value نمط glob. إذا كانت value هي NULL، يتم تضمين الأجهزة التي لديها (إذا كان match هو true) أو ليس لديها (إذا كان match هو false) سمة sysattr المحددة، بغض النظر عن قيمتها. أي، NULL يكافئ تقريبًا "*". عندما يتم استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع مرشحات sysattr المحددة فقط. أي، يتم دمج هذه المرشحات بواسطة AND.

الدالة sd_device_enumerator_add_match_sysname() تضيف مرشحًا بحيث يتم تعداد الأجهزة التي يكون اسم sysname الخاص بها مطابقًا لـ sysname فقط. يمكن أن يكون sysname نمط glob. عند استدعائها عدة مرات، يتم دمج المرشحات بواسطة OR.

الدالة sd_device_enumerator_add_nomatch_sysname() تضيف مرشحًا بحيث يتم استبعاد الأجهزة التي يكون اسم sysname الخاص بها مطابقًا لـ sysname من عملية التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند استدعائها عدة مرات، يتم دمج الميزات بواسطة AND.

الدالة sd_device_enumerator_add_match_tag() تضيف مرشحًا بحيث يتم تعداد الأجهزة الموسومة بـ tag فقط. عند استدعائها عدة مرات، يتم دمج المرشحات بواسطة OR.

الدالة sd_device_enumerator_allow_uninitialized() تسمح بتضمين الأجهزة التي لم يتم تهيئتها بواسطة udev بعد في عملية التعداد.

الدالة sd_device_enumerator_add_all_parents() تقوم بتعداد جميع الأجهزة الأصلية للأجهزة المطابقة. هذا مفيد في الحالات التي ترغب فيها في تضمين جميع الأجهزة الأصلية في عملية التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة بأكملها التي تؤدي إلى جهاز معين.

قيمة الإرجاع

جميع الدوال ترجع 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا على نمط errno عند الفشل.

الأخطاء

قد تشير الأخطاء التي تم إرجاعها إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد الوسائط غير صالح.

أمثلة

مثال 1. اكتشاف أجهزة USB القابلة للإزالة (باستخدام التطابق والاستبعاد)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء enumerator جهاز جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل في إنشاء enumerator الجهاز: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من النظام الفرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة تطابق النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي تكون سمة "removable" فيها هي "0"
     * هذه عادةً أجهزة غير قابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة تطابق سمة النظام: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على syspath للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}
