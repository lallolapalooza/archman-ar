sd_session_get_remote_user(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

NAME

sd_session_get_class, sd_session_get_display, sd_session_get_leader, sd_session_get_remote_user, sd_session_get_remote_host, sd_session_get_tty - الحصول على معلومات حول جلسة تسجيل دخول

SYNOPSIS

#include <systemd/sd-login.h>

int
sd_session_get_class(const char *session, const char **value);
int
sd_session_get_display(const char *session, const char **value);
int
sd_session_get_leader(const char *session, pid_t *pid);
int
sd_session_get_remote_user(const char *session, const char **value);
int
sd_session_get_remote_host(const char *session, const char **value);
int
sd_session_get_tty(const char *session, const char **value);

DESCRIPTION

The functions sd_session_get_class(), sd_session_get_display(), sd_session_get_leader(), sd_session_get_remote_user(), sd_session_get_remote_host() and sd_session_get_tty() retrieve information about a specific session. The session is identified by its session ID string, passed in the session parameter.

If the session is found, the value of the requested field is stored in the memory location pointed to by the value parameter (for string values) or pid (for the leader PID). The caller must not modify or free the pointer stored in value. The pointer is valid until the next call to any sd_session_* function or until the program terminates.

sd_session_get_class() retrieves the session class (e.g., "tty", "x11", "wayland").

sd_session_get_display() retrieves the display name (e.g., ":0") for graphical sessions.

sd_session_get_leader() retrieves the process ID of the session leader process.

sd_session_get_remote_user() retrieves the user name of the remote user for remote sessions.

sd_session_get_remote_host() retrieves the host name or IP address of the remote host for remote sessions.

sd_session_get_tty() retrieves the terminal name (e.g., "tty1") for TTY sessions.

If the session ID string is NULL, the session associated with the current process is used.

RETURN VALUE

On success, these calls return 0 or a positive integer. On failure, these calls return a negative errno-style error code.

Errors

Returned errors may indicate the following problems:

-ENXIO

The specified session does not exist.

-ENODATA

The given field is not specified for the described session.

-EINVAL

An input parameter was invalid (out of range, or NULL, where that is not accepted).

-ENOMEM

Memory allocation failed.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
