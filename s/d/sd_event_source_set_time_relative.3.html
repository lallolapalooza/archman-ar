sd_event_source_set_time_relative(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

NAME

sd_event_source_set_time_relative, sd_event_source_get_time_accuracy, sd_event_source_set_time_accuracy, sd_event_source_get_time_clock - ضبط وتعديل مصدر حدث مؤقت

SYNOPSIS

#include <systemd/sd-event.h>

int sd_event_source_set_time_relative(sd_event_source *source, uint64_t usec);

int sd_event_source_get_time_accuracy(sd_event_source *source, uint64_t *accuracy_usec);

int sd_event_source_set_time_accuracy(sd_event_source *source, uint64_t accuracy_usec);

int sd_event_source_get_time_clock(sd_event_source *source, clockid_t *clock_ret);

DESCRIPTION

sd_event_source_set_time_relative() يسمح بتعيين مصدر حدث مؤقت تم إنشاؤه مسبقًا باستخدام sd_event_add_time(). يتم استدعاء هذا التابع مع مصدر الحدث والكائن المحدد بوحدة الميكروثانية.

sd_event_source_get_time_accuracy() تسترجع الدقة الحالية لمصدر حدث مؤقت تم إنشاؤه مسبقًا باستخدام sd_event_add_time(). تأخذ هذه الوظيفة كائن مصدر الحدث ومؤشر إلى متغير لتخزين قيمة الدقة بوحدة الميكروثانية.

sd_event_source_set_time_accuracy() تسمح بتعيين دقة مصدر حدث مؤقت تم إنشاؤه مسبقًا باستخدام sd_event_add_time(). تأخذ هذه الوظيفة كائن مصدر الحدث وقيمة الدقة بوحدة الميكروثانية.

sd_event_source_get_time_clock() تسترجع الساعة المكونة لمصدر حدث تم إنشاؤه مسبقًا باستخدام sd_event_add_time(). تأخذ هذه الوظيفة كائن مصدر الحدث ومؤشر إلى متغير لتخزين معرف الساعة.

RETURN VALUE

عند النجاح، تعيد هذه الوظائف 0 أو قيمة صحيحة موجبة. عند الفشل، تعيد رمز خطأ سالبًا بنمط errno.

Errors

قد تشير القيم التي تم إرجاعها إلى المشاكل التالية:

-ENOMEM

لا توجد ذاكرة كافية لتخصيص كائن.

-EINVAL

تم تمرير وسيطة غير صالحة.

-ESTALE

حلقة الأحداث قد انتهت بالفعل.

-ECHILD

تم إنشاء حلقة الأحداث في عملية مختلفة، أو مكتبة، أو مثيل وحدة.

-EOPNOTSUPP

الساعة المحددة غير مدعومة من قبل تنفيذ حلقة الأحداث.

-EDOM

مصدر الحدث الذي تم تمريره ليس مصدر حدث مؤقت.

-EOVERFLOW

الوقت النسبي الذي تم تمريره خارج النطاق المسموح به لقيم الوقت (أي أن القيمة المحددة مضافة إلى الوقت الحالي تقع خارج نطاق الأعداد الصحيحة غير الموقعة ذات 64 بت).

تمت الإضافة في الإصدار 247.

NOTES

الوظائف الموصوفة هنا متاحة كمكتبة مشتركة، يمكن الترجمة ضدها والربط بها باستخدام ملف libsystemd pkg-config(1).

يستخدم الكود الموصوف هنا getenv(3)، والذي تم تعريفه بأنه ليس آمنًا للاستخدام المتوازي مع الخيوط. هذا يعني أن الكود الذي يستدعي الوظائف الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط متوازي. يوصى بإجراء استدعاءات لـ setenv() فقط في مرحلة مبكرة من البرنامج عندما لم تبدأ خيوط أخرى بعد.
