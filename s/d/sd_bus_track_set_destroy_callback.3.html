sd_bus_track_set_destroy_callback(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SLOT_SET_DESTROY_CALLBACK(3) sd_bus_slot_set_destroy_callback SD_BUS_SLOT_SET_DESTROY_CALLBACK(3)

الاسم

sd_bus_slot_set_destroy_callback, sd_bus_slot_get_destroy_callback, sd_bus_track_set_destroy_callback, sd_bus_track_get_destroy_callback, sd_bus_destroy_t - تحديد دالة رد النداء لتنظيف الموارد

الملخص

#include <systemd/sd-bus.h>

typedef int (*sd_bus_destroy_t)(void *userdata);

int sd_bus_slot_set_destroy_callback(sd_bus_slot *slot, sd_bus_destroy_t callback);

int sd_bus_slot_get_destroy_callback(sd_bus_slot *slot, sd_bus_destroy_t *callback);

int sd_bus_track_set_destroy_callback(sd_bus_track *track, sd_bus_destroy_t callback);

int sd_bus_track_get_destroy_callback(sd_bus_track *track, sd_bus_destroy_t *callback);

الوصف

sd_bus_slot_set_destroy_callback() تحدد callback كدالة رد نداء سيتم استدعاؤها مباشرة قبل إلغاء تخصيص كائن فتحة الحافلة slot. سيتم تمرير مؤشر userdata من كائن الفتحة كمعلمة userdata. يمكن تعيين هذا المؤشر بواسطة وسيطة لدوال البناء، راجع sd_bus_add_match(3)، أو مباشرة، راجع sd_bus_slot_set_userdata(3). يتم استدعاء دالة رد النداء هذه حتى لو كان userdata هو NULL. لاحظ أن رد النداء هذا يتم استدعاؤه في وقت يكون فيه كائن فتحة الحافلة نفسه قد تم إبطاله بالفعل، ولا يجوز تنفيذ عمليات أو أخذ مراجع جديدة لكائن فتحة الحافلة.

sd_bus_slot_get_destroy_callback() ترجع رد النداء الحالي لـ slot في المعلمة callback.

sd_bus_track_set_destroy_callback() و sd_bus_track_get_destroy_callback() توفران وظائف مماثلة لمؤشر userdata المرتبط بكائنات تتبع نظير الحافلة. للتفاصيل حول كائنات تتبع نظير الحافلة، راجع sd_bus_track_new(3).

قيمة الإرجاع

عند النجاح، ترجع sd_bus_slot_set_destroy_callback() و sd_bus_track_set_destroy_callback() قيمة 0 أو عددًا صحيحًا موجبًا. عند الفشل، ترجع رمز خطأ سلبي بنمط errno.

sd_bus_slot_get_destroy_callback() و sd_bus_track_get_destroy_callback() ترجعان قيمة موجبة إذا تم تعيين دالة رد النداء للتدمير، و 0 إذا لم يتم تعيينها. عند الفشل، ترجعان رمز خطأ سلبي بنمط errno.

الأخطاء

قد تشير الأخطاء المرجعة إلى المشاكل التالية:

-EINVAL

المعلمة slot أو track هي NULL.

ملاحظات

الدوال الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها وربطها باستخدام ملف pkg-config(1) لـ libsystemd.

الكود الموصوف هنا يستخدم getenv(3)، والذي تم الإعلان عنه بأنه غير آمن للاستخدام المتزامن في خيوط متعددة. هذا يعني أن الكود الذي يستدعي الدوال الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط متوازي. يوصى فقط بإجراء استدعاءات لـ setenv() من مرحلة مبكرة من البرنامج عندما لم يتم بدء أي خيوط أخرى.
