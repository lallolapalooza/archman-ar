الوصف

تقوم الدالة sd_device_enumerator_add_match_parent() بإضافة مرشح إلى enumerator بحيث يتم تعداد الأجهزة الموجودة تحت شجرة الجهاز parent المحدد فقط. إذا تم استدعاء هذه الدالة عدة مرات، فسيتم مسح الجهاز parent الذي تم تعيينه سابقًا ولن يكون لآخر استدعاء سوى التأثير.

تقوم الدالة sd_device_enumerator_add_match_property() بإضافة مرشح إلى enumerator بحيث يتم تعداد الأجهزة التي يكون فيها property المحدد مساويًا لـ value فقط. يمكن أن يكون كل من property و value نمط كرة (glob pattern). عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي لديها خاصية واحدة على الأقل من الخصائص المحددة مع القيم المتطابقة. أي، يتم جمع المرشحات باستخدام OR.

تقوم الدالة sd_device_enumerator_add_match_property_required() بإضافة مرشح إلى enumerator بحيث يتم تعداد الأجهزة التي يكون فيها property المحدد مساويًا لـ value فقط. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي لديها جميع الخصائص المحددة مع القيم المتطابقة. أي، يتم جمع المرشحات باستخدام AND.

تقوم الدالة sd_device_enumerator_add_match_subsystem() بإضافة مرشح إلى enumerator بحيث يتم تعداد جميع الأجهزة في subsystem المحدد، عندما يكون match هو true. عندما يكون match هو false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند الاستدعاء عدة مرات، يتم جمع المرشحات الإيجابية باستخدام OR، والمرشحات السلبية باستخدام AND.

تقوم الدالة sd_device_enumerator_add_match_sysattr() بإضافة مرشح على سمة نظام الملفات (sysfs attribute) sysattr المطابقة لـ value. يمكن أن يكون value نمط كرة. إذا كان value هو NULL، فسيتم تضمين الأجهزة التي لديها (إذا كان match هو true) أو لا تحتوي على (إذا كان match هو false) سمة sysattr المحددة، بغض النظر عن قيمتها. أي، NULL يعادل "*" في الغالب. عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع مرشحات sysattr المحددة فقط. أي، يتم جمع هذه المرشحات باستخدام AND.

تقوم الدالة sd_device_enumerator_add_match_sysname() بإضافة مرشح بحيث يتم تعداد الأجهزة التي يكون اسمها في نظام الملفات (sysname) مساويًا لـ sysname فقط. يمكن أن يكون sysname نمط كرة. عند الاستدعاء عدة مرات، يتم جمع المرشحات باستخدام OR.

تقوم الدالة sd_device_enumerator_add_nomatch_sysname() بإضافة مرشح بحيث يتم استبعاد الأجهزة التي يكون اسمها في نظام الملفات (sysname) مساويًا لـ sysname من التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند الاستدعاء عدة مرات، يتم جمع الميزات باستخدام AND.

تقوم الدالة sd_device_enumerator_add_match_tag() بإضافة مرشح بحيث يتم تعداد الأجهزة التي تحمل العلامة tag فقط. عند الاستدعاء عدة مرات، يتم جمع المرشحات باستخدام OR.

تسمح الدالة sd_device_enumerator_allow_uninitialized() بتضمين الأجهزة التي لم يتم تهيئتها بواسطة udev بعد في التعداد.

تقوم الدالة sd_device_enumerator_add_all_parents() بتعداد جميع الأجهزة الأم (parent devices) للأجهزة المطابقة. هذا مفيد في الحالات التي تريد فيها تضمين جميع الأجهزة الأم في التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة الكاملة التي تؤدي إلى جهاز معين.

قيمة الإرجاع

تعيد جميع الدوال القيمة 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا بأسلوب errno عند الفشل.

الأخطاء

قد تشير الأخطاء التي يتم إرجاعها إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد الوسائط غير صالح.

أمثلة

مثال 1. اكتشاف أجهزة USB القابلة للإزالة (باستخدام التطابق والاستبعاد)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء عداد جهاز جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل في إنشاء عداد الجهاز: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من نظام فرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة تطابق نظام فرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي تكون فيها سمة النظام "removable" هي "0"
     * هذه عادةً هي الأجهزة غير القابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة تطابق سمة النظام: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على مسار النظام للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}
