الوصف

الدالة sd_device_enumerator_add_match_parent() تضيف عامل تصفية إلى enumerator بحيث يتم فقط تعداد الأجهزة تحت شجرة الجهاز المحدد parent. إذا تم استدعاء هذه الدالة عدة مرات، فسيتم مسح الجهاز parent الذي تم تعيينه مسبقًا، ولن يكون للتعديل الأخير سوى التأثير.

الدالة sd_device_enumerator_add_match_property() تضيف عامل تصفية إلى enumerator بحيث يتم فقط تعداد الأجهزة التي خاصيتها المحددة property تساوي القيمة value. يمكن أن يكون كل من property و value نمط glob. عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي لديها خاصية واحدة على الأقل من الخصائص المحددة بقيم مطابقة. أي، يتم ربط عوامل التصفية بـ OR.

الدالة sd_device_enumerator_add_match_property_required() تضيف عامل تصفية إلى enumerator بحيث يتم فقط تعداد الأجهزة التي خاصيتها المحددة property تساوي القيمة value. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عند استدعائها عدة مرات، يتم تعداد الأجهزة التي لديها *جميع* الخصائص المحددة بقيم مطابقة. أي، يتم ربط عوامل التصفية بـ AND.

الدالة sd_device_enumerator_add_match_subsystem() تضيف عامل تصفية إلى enumerator بحيث يتم تعداد جميع الأجهزة في النظام الفرعي المحدد subsystem، عندما يكون match هو true. عندما يكون match هو false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في النظام الفرعي المحدد subsystem. عند الاستدعاء عدة مرات، يتم ربط عوامل التصفية الإيجابية بـ OR، والعوامل السلبية بـ AND.

الدالة sd_device_enumerator_add_match_sysattr() تضيف عامل تصفية على سمة sysfs sysattr التي تطابق value. يمكن أن يكون value نمط glob. إذا كان value هو NULL، يتم تضمين الأجهزة التي لديها (إذا كان match هو true) أو لا لديها (إذا كان match هو false) السمة المحددة sysattr، بغض النظر عن قيمتها. أي، NULL يعادل تقريبًا "*" . عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع عوامل التصفية sysattr المحددة. أي، يتم ربط عوامل التصفية هذه بـ AND.

الدالة sd_device_enumerator_add_match_sysname() تضيف عامل تصفية بحيث يتم فقط تعداد الأجهزة التي يتطابق اسمها في sysfs مع sysname. يمكن أن يكون sysname نمط glob. عند الاستدعاء عدة مرات، يتم ربط عوامل التصفية بـ OR.

الدالة sd_device_enumerator_add_nomatch_sysname() تضيف عامل تصفية بحيث يتم استبعاد الأجهزة التي يتطابق اسمها في sysfs مع sysname من عملية التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند الاستدعاء عدة مرات، يتم ربط الميزات بـ AND.

الدالة sd_device_enumerator_add_match_tag() تضيف عامل تصفية بحيث يتم فقط تعداد الأجهزة المميزة بالوسم tag. عند الاستدعاء عدة مرات، يتم ربط عوامل التصفية بـ OR.

الدالة sd_device_enumerator_allow_uninitialized() تسمح بتضمين الأجهزة التي لم يتم تهيئتها بعد بواسطة udev في عملية التعداد.

الدالة sd_device_enumerator_add_all_parents() تقوم بتعداد جميع الأجهزة الأصلية للأجهزة المطابقة. هذا مفيد للحالات التي تريد فيها تضمين جميع الأجهزة الأصلية في عملية التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة بأكملها التي تؤدي إلى جهاز معين.

قيمة الإرجاع

جميع الدوال ترجع 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا من نوع errno عند الفشل.

الأخطاء

قد تشير الأخطاء التي تم إرجاعها إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد الوسائط غير صالح.

أمثلة

مثال 1. اكتشاف أجهزة USB القابلة للإزالة (باستخدام المطابقة والاستبعاد)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء مُعدّ أجهزة جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل في إنشاء مُعدّ الأجهزة: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من النظام الفرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة مطابقة النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة حيث السمة "removable" هي "0"
     * هذه عادةً الأجهزة غير القابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة مطابقة السمة: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على مسار النظام للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}

sd_device_enumerator_add_all_parents() - Add all parent devices of a device to an enumerator

DESCRIPTION

\n

The sd_device_enumerator_add_all_parents() function is used to add the specified device, as well as all of its parent devices up to the root device, to the given enumerator object. This is useful when you want to ensure that the enumerator contains not only the device itself, but also all the devices on which it depends.

\n

The enumerator parameter is a pointer to an sd_device_enumerator object. The device parameter is a pointer to the sd_device object whose parents should be added.

\n

This function will recursively add parent devices until it reaches a device that has no parent (typically the root device).

\n
\n
\n

RETURN VALUE

\n

On success, sd_device_enumerator_add_all_parents() returns a non-negative integer. On failure, it returns a negative errno value.
