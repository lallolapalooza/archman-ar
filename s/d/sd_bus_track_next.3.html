DESCRIPTION

The sd_bus_track_* functions manage a collection of bus names and sender addresses that are being tracked. A bus track object is created with sd_bus_track_new(3). These functions allow adding and removing names and sender addresses, checking if a name or address is in the track, and iterating through the tracked items.

The functions sd_bus_track_add_name, sd_bus_track_add_sender, sd_bus_track_remove_name, and sd_bus_track_remove_sender add or remove a specific bus name or sender address to/from the track.

The functions sd_bus_track_count_name and sd_bus_track_count_sender return the number of names or sender addresses currently in the track.

The function sd_bus_track_contains checks if a specific name or sender address is currently in the track.

The functions sd_bus_track_first and sd_bus_track_next are used for iterating through the tracked items. sd_bus_track_first returns the first tracked item (either a name or a sender address), and sd_bus_track_next returns the next item.

RETURN VALUE

These functions return a non-negative integer on success, or a negative error number on failure. For detailed return value documentation, refer to the specific function's man page.

NOTES

When iterating using sd_bus_track_first and sd_bus_track_next, the returned items are transient and might become invalid if the track is modified. It is recommended to copy the relevant information from the returned item immediately.

The iteration order is not guaranteed. It is important to note that the set of tracked items might change during iteration if other threads modify the track. This function is intended for use in an early phase of the program when no other threads have been started.
