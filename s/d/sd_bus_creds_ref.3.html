sd_bus_creds_ref(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

RETURN VALUE

On success, these functions return a reference to the credentials object, or a pointer to NULL. On failure, they return an error code. See ERROR CODES for more details.

ERROR CODES

Errors may be diagnosed by inspecting the return value of the functions. The codes returned are:

-EINVAL

المعلمة المحددة غير صالحة (NULL في حالة معلمات الإخراج).

-ENOMEM

فشل تخصيص الذاكرة.

-EOPNOTSUPP

أحد الحقول المطلوبة غير معروف للنظام المحلي.

ملاحظات

الوظائف الموضحة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها ضدها وربطها مع ملف libsystemd pkg-config(1).

الكود الموصوف هنا يستخدم getenv(3)، والذي تم تعريفه على أنه ليس آمنًا للاستخدام في خيوط متعددة. هذا يعني أن الكود الذي يستدعي الوظائف الموضحة هنا يجب ألا يستدعي setenv(3) من خيط متوازي. يوصى بإجراء استدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم يتم بدء أي خيوط أخرى.

التاريخ

تمت إضافة sd_bus_creds_new_from_pid()، sd_bus_creds_get_mask()، sd_bus_creds_ref()، sd_bus_creds_unref()، و sd_bus_creds_get_augmented_mask() في الإصدار 221.

تمت إضافة sd_bus_creds_unrefp() في الإصدار 229.

تمت إضافة sd_bus_creds_new_from_pidfd() في الإصدار 256.
