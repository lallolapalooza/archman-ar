sd_bus_get_property_string(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SET_PROPERTY(3) sd_bus_set_property SD_BUS_SET_PROPERTY(3)

الاسم

sd_bus_set_property, sd_bus_set_propertyv, sd_bus_get_property, sd_bus_get_property_trivial, sd_bus_get_property_string, sd_bus_get_property_strv - تعيين أو استعلام خصائص خدمة D-Bus

الملخص

#include <systemd/sd-bus.h>

int sd_bus_set_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, ...);

int sd_bus_set_propertyv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, va_list ap);

int sd_bus_get_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, sd_bus_message **reply, const char *type);

int sd_bus_get_property_trivial(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char type, void *ret_ptr);

int sd_bus_get_property_string(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char **ret);

int sd_bus_get_property_strv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char ***ret);

الوصف

تقوم هذه الدوال بتعيين أو استعلام خصائص D-Bus. خصائص D-Bus هي حقول خدمة يتم عرضها عبر الواجهة org.freedesktop.DBus.Properties. في الخلفية، تستدعي هذه الدوال طرق الواجهة org.freedesktop.DBus.Properties ونتيجة لذلك، فإن معانيها مشابهة لدوال sd_bus_call_method(3).

sd_bus_set_property() تقوم بتعيين خاصية D-Bus. إذا فشل تعيين الخاصية أو حدث خطأ داخلي، يتم إرجاع خطأ ويتم اختياريًا تخزين وصف موسع للخطأ في ret_error إذا لم يكن NULL. type والوسائط التي تليه تصف القيمة الجديدة للخاصية ويجب أن تتبع التنسيق الموصوف في sd_bus_message_append(3).

sd_bus_set_propertyv() تعادل sd_bus_set_property()، باستثناء أنها تُستدعى مع "va_list" بدلاً من عدد متغير من الوسائط.

sd_bus_get_property() تستعلم عن خاصية D-Bus. إذا فشل استرداد الخاصية أو حدث خطأ داخلي، يتم إرجاع خطأ ويتم اختياريًا تخزين وصف موسع للخطأ في ret_error إذا لم يكن NULL. عند النجاح، يتم تخزين الخاصية في reply. type يصف نوع الخاصية ويجب أن يتبع التنسيق الموصوف في sd_bus_message_append(3).

sd_bus_get_property_trivial() و sd_bus_get_property_string() و sd_bus_get_property_strv() هي اختصارات لدوال sd_bus_get_property() تُستخدم لاستعلام الخصائص الأساسية، والمتسلسلة، ومتجهات المتسلسلات على التوالي. يتحمل المستدعي مسؤولية تحرير نتائج المتسلسلة ومتجه المتسلسلات المخزنة في ret بواسطة sd_bus_get_property_string() و sd_bus_get_property_strv().

قيمة الإرجاع

عند النجاح، تعيد هذه الدوال عددًا صحيحًا غير سالب. عند الفشل، تعيد رمز خطأ سالب بأسلوب errno.

الأخطاء

راجع صفحة الدليل sd_bus_call_method(3) للحصول على قائمة بالأخطاء المحتملة.

ملاحظات

الدوال الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها والربط معها باستخدام ملف pkg-config(1) الخاص بـ libsystemd.

الكود الموصوف هنا يستخدم getenv(3)، والذي تم الإعلان عنه بأنه ليس آمنًا للاستخدام متعدد الخيوط. هذا يعني أن الكود الذي يستدعي الدوال الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط متوازي. يوصى بالقيام باستدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم يتم بدء خيوط أخرى.
