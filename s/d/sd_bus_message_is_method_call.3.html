sd_bus_message_is_method_call(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_GET_TYPE(3) sd_bus_message_get_type SD_BUS_MESSAGE_GET_TYPE(3)

الاسم

sd_bus_message_get_type, sd_bus_message_get_error, sd_bus_message_get_errno, sd_bus_message_get_creds, sd_bus_message_is_signal, sd_bus_message_is_method_call, sd_bus_message_is_method_error - الاستعلام عن بيانات التعريف الخاصة بعنوان الرسالة / بيانات اعتمادها

الملخص

#include <systemd/sd-bus.h>

int sd_bus_message_get_type(sd_bus_message *m, uint8_t *type);

sd_bus_error* sd_bus_message_get_error(sd_bus_message *m);

int sd_bus_message_get_errno(sd_bus_message *m);

sd_bus_creds* sd_bus_message_get_creds(sd_bus_message *m);

int sd_bus_message_is_signal(sd_bus_message *m, const char *interface, const char *member);

int sd_bus_message_is_method_call(sd_bus_message *m, const char *interface, const char *member);

int sd_bus_message_is_method_error(sd_bus_message *m, const char *name);

الوصف

sd_bus_message_get_type() تعيد نوع الرسالة في المعلمة type، والتي تكون أحد الخيارات التالية: SD_BUS_MESSAGE_METHOD_CALL, SD_BUS_MESSAGE_METHOD_RETURN, SD_BUS_MESSAGE_METHOD_ERROR, SD_BUS_MESSAGE_SIGNAL. يتم تحديد هذا النوع إما كمعلمة عند إنشاء الرسالة باستخدام sd_bus_message_new(3)، أو يتم تعيينه تلقائيًا عند إنشاء الرسالة باستخدام sd_bus_message_new_signal(3)، sd_bus_message_new_method_call(3)، sd_bus_message_new_method_error(3) والدوال المشابهة.

sd_bus_message_get_error() تعيد الخطأ المخزن في الرسالة m، إذا كان هناك أي خطأ. بخلاف ذلك، تعيد NULL. sd_bus_message_get_errno() تعيد الخطأ المخزن في الرسالة m كقيمة موجبة على نمط errno، إذا كان هناك أي خطأ. بخلاف ذلك، تعيد صفر. يتم تعيين الأخطاء إلى قيم errno وفقًا لخرائط الأخطاء الافتراضية وأي خرائط إضافية مسجلة. انظر sd-bus-errors(3) و sd_bus_error_add_map(3).

sd_bus_message_get_creds() تعيد بيانات اعتماد الرسالة المرفقة بالرسالة m. إذا لم تكن هناك بيانات اعتماد مرفقة بالرسالة، تعيد NULL. لا يتم نقل ملكية مثيل بيانات الاعتماد إلى المتصل، وبالتالي لا ينبغي تحريرها.

sd_bus_message_is_signal() تتحقق مما إذا كانت الرسالة m هي رسالة إشارة. إذا كانت interface غير فارغة، فإنها تتحقق أيضًا مما إذا كانت الرسالة تحتوي على نفس الواجهة المعينة. إذا كانت member غير فارغة، فإنها تتحقق أيضًا مما إذا كانت الرسالة تحتوي على نفس العضو المعين. انظر أيضًا sd_bus_message_new_signal(3). تعيد true عندما تمر جميع الفحوصات.

sd_bus_message_is_method_call() تتحقق مما إذا كانت الرسالة m هي رسالة استدعاء طريقة. إذا كانت interface غير فارغة، فإنها تتحقق أيضًا مما إذا كانت الرسالة تحتوي على نفس الواجهة المعينة. إذا كانت member غير فارغة، فإنها تتحقق أيضًا مما إذا كانت الرسالة تحتوي على نفس العضو المعين. انظر أيضًا sd_bus_message_new_method_call(3). تعيد true عندما تمر جميع الفحوصات.

sd_bus_message_is_method_error() تتحقق مما إذا كانت الرسالة m هي رسالة رد خطأ. إذا كانت name غير فارغة، فإنها تتحقق أيضًا مما إذا كانت الرسالة تحتوي على نفس معرف الخطأ المعين. انظر أيضًا sd_bus_message_new_method_error(3). تعيد true عندما تمر جميع الفحوصات.

قيمة الإرجاع

عند النجاح، تعيد هذه الدوال (باستثناء sd_bus_message_get_error() و sd_bus_message_get_creds()) عددًا صحيحًا غير سالب. عند الفشل، تعيد رمز خطأ سالب على نمط errno. sd_bus_message_get_errno() تعيد دائمًا عددًا صحيحًا غير سالب، حتى عند الفشل.

الأخطاء

قد تشير الأخطاء المعادة إلى المشاكل التالية:

-EINVAL

المعلمة m للرسالة أو معلمة الإخراج هي NULL.

ملاحظات

الدوال الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها وربطها مع ملف pkg-config(1) الخاص بـ libsystemd.

الكود الموصوف هنا يستخدم getenv(3)، والذي تم تعريفه على أنه غير آمن للعمل مع خيوط متعددة. هذا يعني أنه يجب على الكود الذي يستدعي الدوال الموصوفة هنا عدم استدعاء setenv(3) من خيط متوازٍ. يوصى بالقيام باستدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم يتم بدء خيوط أخرى بعد.
