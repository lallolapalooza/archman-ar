NAME

sdrvrfp - Driver routine for the singular value decomposition of a general matrix.

SYNOPSIS

SUBROUTINE SDRVRFP(A, LDA, M, N, S, U, LDU, V, LDV, WORK, LWORK, INFO)

Function/Subroutine Documentation

SDRVRFP is a driver routine for computing the singular value decomposition (SVD) of a real matrix A.

The SVD is a factorization of the form A = U * S * V^T, where U and V are orthogonal matrices and S is a diagonal matrix containing the singular values of A.

The routine uses a call to the LAPACK routine SGESVD to perform the SVD computation.

Arguments

A
REAL array, dimension (LDA,N). On entry, the M-by-N matrix A. On exit, the contents of A are overwritten.
LDA
INTEGER. The leading dimension of the array A. LDA must be at least max(1,M).
M
INTEGER. The number of rows of the matrix A. M must be at least 0.
N
INTEGER. The number of columns of the matrix A. N must be at least 0.
S
REAL array, dimension (min(M,N)). The singular values of A, sorted in descending order.
U
REAL array, dimension (LDU,M). If U is requested, it contains the left singular vectors of A.
LDU
INTEGER. The leading dimension of the array U. LDU must be at least M if U is requested.
V
REAL array, dimension (LDV,N). If V is requested, it contains the right singular vectors of A.
LDV
INTEGER. The leading dimension of the array V. LDV must be at least N if V is requested.
WORK
REAL array, dimension (LWORK). Workspace array.
LWORK
INTEGER. The dimension of the array WORK. LWORK must be at least max(1,3*min(M,N)+max(max(M,N),5)). For optimal performance, LWORK should be larger.
INFO
INTEGER.
  • INFO = 0: Successful exit.
  • INFO < 0: If INFO = -i, the i-th argument had an illegal value.
  • INFO > 0: The algorithm failed to compute all K singular values. INFO is the number of singular values that could not be computed.
