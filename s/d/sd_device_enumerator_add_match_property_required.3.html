الوصف

تقوم الدالة sd_device_enumerator_add_match_parent() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة الموجودة ضمن شجرة الجهاز parent المحدد. إذا تم استدعاء هذه الدالة عدة مرات، يتم مسح الجهاز parent الذي تم تعيينه مسبقًا، وتكون الاستدعاءات اللاحقة فقط هي التي يكون لها تأثير.

تقوم الدالة sd_device_enumerator_add_match_property() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة التي يكون فيها property المحدد مساويًا للقيمة value. يمكن أن يكون كل من property و value نمطًا عامًا (glob pattern). عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على خاصية واحدة على الأقل من الخصائص المحددة مع قيم مطابقة. بمعنى آخر، يتم دمج المرشحات بعلاقة OR (أو).

تقوم الدالة sd_device_enumerator_add_match_property_required() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة التي يكون فيها property المحدد مساويًا للقيمة value. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عند استدعائها عدة مرات، يتم تعداد الأجهزة التي تحتوي على جميع الخصائص المحددة مع قيم مطابقة. بمعنى آخر، يتم دمج المرشحات بعلاقة AND (و).

تقوم الدالة sd_device_enumerator_add_match_subsystem() بإضافة مرشح إلى enumerator بحيث يتم تعداد جميع الأجهزة في subsystem المحدد، عندما تكون match تساوي true. عندما تكون match تساوي false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند الاستدعاء عدة مرات، يتم دمج المرشحات الإيجابية بعلاقة OR، والمرشحات السلبية بعلاقة AND.

تقوم الدالة sd_device_enumerator_add_match_sysattr() بإضافة مرشح على سمة النظام sysattr المطابقة للقيمة value. يمكن أن تكون value نمطًا عامًا (glob pattern). إذا كانت value تساوي NULL، يتم تضمين الأجهزة التي إما لديها (إذا كانت match تساوي true) أو لا تحتوي على (إذا كانت match تساوي false) السمة sysattr المحددة، بغض النظر عن قيمتها. بمعنى آخر، NULL يعادل تقريبًا "*". عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع مرشحات sysattr المحددة فقط. بمعنى آخر، يتم دمج هذه المرشحات بعلاقة AND (و).

تقوم الدالة sd_device_enumerator_add_match_sysname() بإضافة مرشح بحيث يتم فقط تعداد الأجهزة التي يكون اسم النظام الخاص بها sysname مساويًا لـ sysname المحدد. يمكن أن يكون sysname نمطًا عامًا (glob pattern). عند الاستدعاء عدة مرات، يتم دمج المرشحات بعلاقة OR (أو).

تقوم الدالة sd_device_enumerator_add_nomatch_sysname() بإضافة مرشح بحيث يتم استبعاد الأجهزة التي يكون اسم النظام الخاص بها sysname مساويًا لـ sysname المحدد من التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند الاستدعاء عدة مرات، يتم دمج السمات بعلاقة AND (و).

تقوم الدالة sd_device_enumerator_add_match_tag() بإضافة مرشح بحيث يتم فقط تعداد الأجهزة التي تم تمييزها بالعلامة tag. عند الاستدعاء عدة مرات، يتم دمج المرشحات بعلاقة OR (أو).

تسمح الدالة sd_device_enumerator_allow_uninitialized() بتضمين الأجهزة التي لم يتم تهيئتها بعد بواسطة udev في التعداد.

تقوم الدالة sd_device_enumerator_add_all_parents() بتعداد جميع الأجهزة الأصلية للأجهزة المطابقة. هذا مفيد للحالات التي ترغب فيها في تضمين جميع الأجهزة الأصلية في التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة بأكملها التي تؤدي إلى جهاز معين.

قيمة الإرجاع

جميع الدوال تعيد 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا بنمط errno عند الفشل.

الأخطاء

قد تشير الأخطاء التي تم إرجاعها إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد المعلمات غير صالح.

أمثلة

مثال 1. الكشف عن أجهزة USB القابلة للإزالة (باستخدام المطابقة والاستثناء)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء مُعدِّد أجهزة جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل إنشاء مُعدِّد الأجهزة: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من نظام فرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل إضافة مطابقة النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي تكون فيها السمة "removable" هي "0"
     * هذه عادةً هي الأجهزة غير القابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل إضافة مطابقة سمة النظام: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على مسار النظام للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}
