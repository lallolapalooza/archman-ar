الوصف

تقوم الدالة sd_device_enumerator_add_match_parent() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة الموجودة تحت شجرة الجهاز parent المحدد. إذا تم استدعاء هذه الدالة عدة مرات، فسيتم مسح الجهاز parent الذي تم تعيينه سابقًا ولن يكون للاستدعاء الأخير سوى التأثير.

تقوم الدالة sd_device_enumerator_add_match_property() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة التي يكون فيها property المحدد يساوي value. يمكن أن يكون كل من property و value نمط glob. عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على خاصية واحدة على الأقل من الخصائص المحددة مع قيم متطابقة. أي، يتم دمج المرشحات بواسطة OR.

تقوم الدالة sd_device_enumerator_add_match_property_required() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة التي يكون فيها property المحدد يساوي value. هذه الدالة مشابهة للدالة sd_device_enumerator_add_match_property()، ولكن عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على جميع الخصائص المحددة مع قيم متطابقة. أي، يتم دمج المرشحات بواسطة AND.

تقوم الدالة sd_device_enumerator_add_match_subsystem() بإضافة مرشح إلى enumerator بحيث يتم تعداد جميع الأجهزة في subsystem المحدد، عندما يكون match يساوي **true**. عندما يكون match يساوي **false**، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند استدعاء هذه الدالة عدة مرات، يتم دمج المرشحات الإيجابية بواسطة OR، والمرشحات السلبية بواسطة AND.

تقوم الدالة sd_device_enumerator_add_match_sysattr() بإضافة مرشح على سمة sysfs sysattr تتطابق مع value. يمكن أن يكون value نمط glob. إذا كان value يساوي **NULL**، يتم تضمين الأجهزة التي لديها (إذا كان match يساوي **true**) أو لا تمتلك (إذا كان match يساوي **false**) سمة sysattr المحددة، بغض النظر عن قيمتها. أي، **NULL** يكافئ تقريبًا "*". عند استدعاء هذه الدالة عدة مرات، يتم فقط تعداد الأجهزة التي تتطابق مع جميع مرشحات sysattr المحددة. أي، يتم دمج هذه المرشحات بواسطة AND.

تقوم الدالة sd_device_enumerator_add_match_sysname() بإضافة مرشح بحيث يتم فقط تعداد الأجهزة التي يكون اسم نظامها (sysname) يساوي sysname. يمكن أن يكون sysname نمط glob. عند استدعاء هذه الدالة عدة مرات، يتم دمج المرشحات بواسطة OR.

تقوم الدالة sd_device_enumerator_add_nomatch_sysname() بإضافة مرشح بحيث يتم استبعاد الأجهزة التي يكون اسم نظامها (sysname) يساوي sysname من عملية التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند استدعاء هذه الدالة عدة مرات، يتم دمج الميزات بواسطة AND.

تقوم الدالة sd_device_enumerator_add_match_tag() بإضافة مرشح بحيث يتم فقط تعداد الأجهزة التي تحمل العلامة (tag) tag. عند استدعاء هذه الدالة عدة مرات، يتم دمج المرشحات بواسطة OR.

تسمح الدالة sd_device_enumerator_allow_uninitialized() بتضمين الأجهزة التي لم يتم تهيئتها بعد بواسطة udev في عملية التعداد.

تقوم الدالة sd_device_enumerator_add_all_parents() بتعداد جميع الأجهزة الأم للأجهزة المتطابقة. هذا مفيد للحالات التي ترغب فيها بتضمين جميع الأجهزة الأم في عملية التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة بأكملها التي تؤدي إلى جهاز معين.

قيمة الإرجاع

ترجع جميع الدوال **0** أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا من نوع errno عند الفشل.

الأخطاء

قد تشير الأخطاء المرجعة إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد الوسائط غير صالح.

أمثلة

مثال 1. اكتشاف أجهزة USB القابلة للإزالة (باستخدام المطابقة والاستبعاد)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء مُعدِّد أجهزة جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل في إنشاء مُعدِّد الأجهزة: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من نظام فرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة مطابقة النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي تكون فيها سمة sysattr "removable" هي "0"
     * هذه عادةً ما تكون أجهزة غير قابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة مطابقة سمة sysattr: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المتطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على مسار النظام (syspath) للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}
