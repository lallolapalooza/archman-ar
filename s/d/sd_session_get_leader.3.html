الوصف

sd_session_is_active() يمكن استخدامها لتحديد ما إذا كانت الجلسة التي تم التعرف عليها بواسطة معرف الجلسة المحدد نشطة حاليًا (أي في المقدمة حاليًا ومتاحة لمدخلات المستخدم) أم لا.

sd_session_is_remote() يمكن استخدامها لتحديد ما إذا كانت الجلسة التي تم التعرف عليها بواسطة معرف الجلسة المحدد هي جلسة بعيدة (أي معروف مضيفها البعيد) أم لا.

sd_session_get_state() يمكن استخدامها لتحديد حالة الجلسة التي تم التعرف عليها بواسطة معرف الجلسة المحدد. الحالات التالية معروفة حاليًا: "online" (الجلسة مسجلة الدخول، لكن الجلسة ليست نشطة، أي ليست في المقدمة)، "active" (الجلسة مسجلة الدخول ونشطة، أي في المقدمة)، "closing" (الجلسة مسجلة الخروج اسميًا، لكن بعض العمليات التابعة لها لا تزال موجودة). في المستقبل قد يتم تعريف حالات إضافية، يجب أن يتم كتابة كود العميل ليكون قويًا فيما يتعلق بالسلاسل النصية للحالة الإضافية التي يتم إرجاعها. هذه الوظيفة هي نسخة عامة من sd_session_is_active(). تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_uid() يمكن استخدامها لتحديد معرف المستخدم لمستخدم Unix الذي تنتمي إليه الجلسة المحددة بمعرف الجلسة المحدد.

sd_session_get_username() يمكن استخدامها لتحديد اسم مستخدم Unix الذي تنتمي إليه الجلسة المحددة بمعرف الجلسة المحدد. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_seat() يمكن استخدامها لتحديد معرف المقعد الذي تنتمي إليه الجلسة المحددة بمعرف الجلسة المحدد. لاحظ أن ليست كل الجلسات مرتبطة بمقعد، هذه المكالمة ستفشل (إرجاع -ENODATA) لها. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_start_time() يمكن استخدامها لتحديد وقت بدء الجلسة المحددة بمعرف الجلسة المحدد. usec بالميكروثانية منذ بداية الحقبة (CLOCK_REALTIME).

sd_session_get_service() يمكن استخدامها لتحديد اسم الخدمة (كما تم تمريره أثناء إعداد جلسة PAM) التي سجلت الجلسة المحددة بمعرف الجلسة المحدد. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_type() يمكن استخدامها لتحديد نوع الجلسة المحددة بمعرف الجلسة المحدد. السلسلة النصية المرجعة هي واحدة من "x11"، "wayland"، "tty"، "mir"، أو "unspecified" وتحتاج إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_class() يمكن استخدامها لتحديد فئة الجلسة المحددة بمعرف الجلسة المحدد. السلسلة النصية المرجعة هي واحدة من "user"، "user-early"، "user-light"، "user-early-light"، "user-incomplete"، "greeter"، "lock-screen"، "background"، "background-light"، "manager"، أو "manager-early" وتحتاج إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_desktop() يمكن استخدامها لتحديد علامة سطح المكتب الذي يعمل في الجلسة المحددة بمعرف الجلسة المحدد. يمكن تعيين هذا الحقل بحرية بواسطة بيئات سطح المكتب ولا يتبع أي تنسيق خاص. ومع ذلك، يوصى بشدة بأن تستخدم أسطح المكتب نفس المعرفات والأحرف الكبيرة كما هو الحال بالنسبة لـ $XDG_CURRENT_DESKTOP، كما هو محدد بواسطة مواصفات إدخال سطح المكتب[1]. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_display() يمكن استخدامها لتحديد شاشة X11 للجلسة المحددة بمعرف الجلسة المحدد. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_leader() يمكن استخدامها لتحديد PID لقائد الجلسة المحددة بمعرف الجلسة المحدد.

sd_session_get_remote_host() يمكن استخدامها لتحديد اسم المضيف البعيد للجلسة المحددة بمعرف الجلسة المحدد. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_remote_user() يمكن استخدامها لتحديد اسم المستخدم البعيد للجلسة المحددة بمعرف الجلسة المحدد. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام. لاحظ أن هذا القيمة نادرًا ما تكون معروفة للنظام، وحتى حينها لا ينبغي الاعتماد عليها.

sd_session_get_tty() يمكن استخدامها لتحديد جهاز TTY للجلسة المحددة بمعرف الجلسة المحدد. تحتاج السلسلة النصية المرجعة إلى تحريرها باستخدام استدعاء libc free(3) بعد الاستخدام.

sd_session_get_vt() يمكن استخدامها لتحديد رقم VT للجلسة المحددة بمعرف الجلسة المحدد. سترجع هذه الوظيفة خطأ إذا كان المقعد لا يدعم VTs.

إذا تم تمرير المعلمة session لأي من هذه الوظائف كـ NULL، يتم تنفيذ العملية للجلسة التي يعد العمليتها الحالية جزءًا منها، إذا كان هناك أي.

NAME

sd_session_get_state, sd_session_get_display, sd_session_get_leader, sd_session_get_remote_user, sd_session_get_remote_host, sd_session_get_tty, sd_session_is_remote, sd_session_get_username, sd_session_get_desktop, sd_session_get_start_time, sd_session_get_vt, sd_session_get_seat - Retrieve information about a session

SYNOPSIS

#include <systemd/sd-login.h>

int sd_session_get_state(const char *session, const char **state);
int sd_session_get_display(const char *session, const char **display);
int sd_session_get_leader(const char *session, pid_t *leader);
int sd_session_get_remote_user(const char *session, const char **user);
int sd_session_get_remote_host(const char *session, const char **host);
int sd_session_get_tty(const char *session, const char **tty);
int sd_session_is_remote(const char *session);
int sd_session_get_username(const char *session, const char **user);
int sd_session_get_desktop(const char *session, const char **desktop);
int sd_session_get_start_time(const char *session, time_t *start_time);
int sd_session_get_vt(const char *session, int *vt);
int sd_session_get_seat(const char *session, const char **seat);

DESCRIPTION

The sd_session_get_state(), sd_session_get_display(), sd_session_get_leader(), sd_session_get_remote_user(), sd_session_get_remote_host() and sd_session_get_tty() functions retrieve the session state, X11 display name, session leader process ID, remote user name, remote host name, and TTY device name, respectively, for the session specified by session. If session is NULL, the session of the calling process is queried.

sd_session_is_remote() checks if the session specified by session is remote. If session is NULL, the session of the calling process is queried.

sd_session_get_username() retrieves the login name of the user that owns the session specified by session. If session is NULL, the session of the calling process is queried.

sd_session_get_desktop() retrieves the desktop environment name (e.g. "GNOME", "KDE", "XFCE") for the session specified by session. If session is NULL, the session of the calling process is queried. See NOTES.

sd_session_get_start_time() retrieves the time the session specified by session was started, as a Unix timestamp. If session is NULL, the session of the calling process is queried.

sd_session_get_vt() retrieves the virtual terminal number associated with the session specified by session. If session is NULL, the session of the calling process is queried.

sd_session_get_seat() retrieves the seat name associated with the session specified by session. If session is NULL, the session of the calling process is queried.

The session name is an opaque string that identifies a login session. It is often the same as the name of the user's login directory in /var/run/utmp, or the name of the X11 display (e.g. ":0").

For functions that return strings, the returned string pointer points to memory that is managed internally by the library. It is valid until the next call to any of these functions. The memory should not be freed by the caller. If the field is not set for the session, the returned string pointer will be NULL.

If session is NULL, the functions will query information about the session associated with the calling process. If the calling process is not associated with any session, these functions will fail with -ENODATA.

RETURN VALUE

On success, these calls return 0 or a positive integer. sd_session_get_state(), sd_session_get_display(), sd_session_get_leader(), sd_session_get_remote_user(), sd_session_get_remote_host() and sd_session_get_tty() return 0 or a positive integer. On failure, these calls return a negative errno-style error code.

Errors

Returned errors may indicate the following problems:

-ENXIO

The specified session does not exist.

-ENODATA

The given field is not specified for the described session.

-EINVAL

An input parameter was invalid (out of range, or NULL, where that is not accepted).

-ENOMEM

Memory allocation failed.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
