الوصف

تسترد هذه الدوال معلومات بيانات الاعتماد من كائن sd_bus_creds. يمكن إنشاء كائنات بيانات الاعتماد باستخدام sd_bus_creds_new_from_pid(3)، وفي هذه الحالة تصف بيانات اعتماد العملية التي يتم تحديدها بواسطة PID المحدد، أو باستخدام sd_bus_get_name_creds(3)، وفي هذه الحالة تصف بيانات اعتماد نظير الناقل المحدد باسم الناقل المحدد، أو باستخدام sd_bus_get_owner_creds(3)، وفي هذه الحالة تصف بيانات اعتماد منشئ الناقل، أو باستخدام sd_bus_message_get_creds(3)، وفي هذه الحالة تصف بيانات اعتماد مرسل الرسالة.

ليست كل حقول بيانات الاعتماد جزءًا من كل كائن "sd_bus_creds". استخدم sd_bus_creds_get_mask(3) لتحديد قناع الحقول المتاحة.

sd_bus_creds_get_pid() ستسترد معرف العملية (PID). وبالمثل، sd_bus_creds_get_ppid() ستسترد معرف العملية الأصلية (PPID). لاحظ أن العملية رقم 1 ليس لها عملية أصلية، وفي هذه الحالة يتم إرجاع -ENXIO.

sd_bus_creds_get_pidfd_dup() ستسترد واصف ملف PID (pidfd)، انظر pidfd_open(2) للتفاصيل. يتم تكرار واصف الملف وبالتالي يجب على المتصل إغلاقه.

sd_bus_creds_get_tid() ستسترد معرف الخيط (TID).

sd_bus_creds_get_uid() ستسترد معرف المستخدم الرقمي (UID). وبالمثل، sd_bus_creds_get_euid() تُرجع معرف المستخدم الفعال (effective UID)، sd_bus_creds_get_suid() معرف المستخدم المحفوظ (saved UID)، و sd_bus_creds_get_fsuid() معرف نظام الملفات للمستخدم (filesystem UID).

sd_bus_creds_get_gid() ستسترد معرف المجموعة الرقمي (GID). وبالمثل، sd_bus_creds_get_egid() تُرجع معرف المجموعة الفعال (effective GID)، sd_bus_creds_get_sgid() معرف المجموعة المحفوظ (saved GID)، و sd_bus_creds_get_fsgid() معرف نظام الملفات للمجموعة (filesystem GID).

sd_bus_creds_get_supplementary_gids() ستسترد قائمة معرفات المجموعات الإضافية.

sd_bus_creds_get_comm() ستسترد حقل comm (الاسم المقتطع للملف التنفيذي، كما هو مخزن في /proc/pid/comm).

sd_bus_creds_get_tid_comm() ستسترد حقل comm للخيط (كما هو مخزن في /proc/pid/task/tid/comm).

sd_bus_creds_get_exe() ستسترد المسار إلى الملف التنفيذي للبرنامج (كما هو مخزن في الارتباط /proc/pid/exe، ولكن مع إزالة اللاحقة " (deleted)"). لاحظ أن خيوط النواة ليس لديها مسار تنفيذي، وفي هذه الحالة يتم إرجاع -ENXIO. لاحظ أنه لا ينبغي استخدام هذه الخاصية لأكثر من معلومات توضيحية، وبالتحديد لا ينبغي استخدامها لاتخاذ قرارات ذات صلة بالأمان. وذلك لأن الملف التنفيذي قد تم استبداله أو إزالته بحلول الوقت الذي يمكن فيه معالجة القيمة. علاوة على ذلك، تصدر النواة هذه المعلومات بطريقة غامضة (أي لا يمكن تمييز الملف التنفيذي المحذوف بأمان عن ملف لم يتم

sd_bus_creds_get_pidfd_dup(3)

NAME

sd_bus_creds_get_pidfd_dup - الحصول على نسخة مضاعفة من واصف ملف pidfd للعملية.

SYNOPSIS

#include <bus/bus.h>
int sd_bus_creds_get_pidfd_dup(sd_bus_creds *creds, int *fd);

DESCRIPTION

يأخذ الدالة sd_bus_creds_get_pidfd_dup() نسخة من بيانات الاعتماد creds. إذا كانت بيانات الاعتماد تحتوي على واصف ملف pidfd نشط، يتم إنشاء نسخة مضاعفة من هذا الواصف وإعادتها في المتغير fd. يتم زيادة مرجع الواصف pidfd. إذا لم يكن هناك pidfd نشط، يتم إرجاع 0 ويتم تعيين *fd إلى -1.

يجب استدعاء هذه الدالة فقط بعد استدعاء sd_bus_creds_get_pid() بنجاح.

RETURN VALUE

في حالة النجاح، يتم إرجاع 0. في حالة الفشل، يتم إرجاع قيمة سالبة.

ERRORS

-ENOENT: لم يتم العثور على pidfd.

-EINVAL: بيانات الاعتماد غير صالحة أو لم يتم تهيئتها بشكل صحيح.

-ENOMEM: فشل تخصيص الذاكرة.

EXAMPLE

sd_bus_creds *creds = NULL;
int fd = -1;
int ret;

ret = sd_bus_creds_get_pidfd_dup(creds, &fd);
if (ret < 0) {
    fprintf(stderr, "Failed to get pidfd: %s\n", strerror(-ret));
    // Handle error
} else {
    // Use the pidfd
    close(fd); // Remember to close the fd when done
}

sd_bus_creds_unref(creds);

SEE ALSO

sd_bus_creds_new(3), sd_bus_creds_get_pid(3), sd_bus_creds_unref(3)

NOTES

بعد الحصول على نسخة مضاعفة من pidfd، يجب على المستخدم إغلاق الواصف عند الانتهاء منه باستخدام close().
