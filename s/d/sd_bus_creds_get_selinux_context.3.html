NAME

sd_bus_creds_get_selinux_context - Get the SELinux context of the bus credentials

SYNOPSIS

#include <systemd/sd-bus.h>

int sd_bus_creds_get_selinux_context(sd_bus_creds *creds, const char **context);

DESCRIPTION

Retrieves the SELinux security context string associated with the given bus credentials structure. The returned string pointer is owned by the caller and must be freed using free(3) by the caller. It is valid until creds is destroyed or sd_bus_creds_get_selinux_context() is called again on the same creds object.

RETURN VALUE

On success, returns 0. On failure, returns a negative errno value.

NOTES

This function is only available when the system is built with SELinux support.

HISTORY

sd_bus_creds_get_selinux_context() was introduced in version 242.

SEE ALSO

sd_bus_creds_new_user(3), sd_bus_creds_new_pid(3), free(3)
