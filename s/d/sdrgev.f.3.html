SDRGEV

الغرض:

!>
!> SDRGEV تختبر الروتين الفرعي الرئيسي للمصفوفات غير المتناظرة SGGEV.
!>
!> SGGEV تحسب، لزوج من المصفوفات غير المتناظرة n-by-n (A,B)، القيم الذاتية المعممة،
!> وبالاختيار، المتجهات الذاتية اليسرى واليمنى.
!>
!> القيمة الذاتية المعممة لزوج من المصفوفات (A,B) هي عدد ثابت w
!> أو نسبة alpha/beta = w، بحيث تكون A - w*B مفردة. عادة ما يتم تمثيلها
!> كزوج (alpha,beta)، حيث يوجد تفسير معقول لـ beta=0، وحتى لكليهما صفر.
!>
!> المتجه الذاتي المعممي الأيمن المقابل لقيمة ذاتية معممة w لزوج من المصفوفات
!> (A,B) هو متجه r بحيث (A - wB) * r = 0. المتجه الذاتي المعممي الأيسر هو متجه l
!> بحيث l**H * (A - wB) = 0، حيث l**H هو المرافق التام لـ l.
!>
!> عند استدعاء SDRGEV، يتم تحديد عدد من أحجام المصفوفات (NN) و
!> عدد من أنواع المصفوفات (DOTYPE). لكل حجم ونوع مصفوفة، سيتم إنشاء زوج
!> من المصفوفات (A, B) واستخدامه للاختبار. لكل زوج مصفوفات، سيتم إجراء الاختبارات التالية
!> ومقارنتها مع الحد الأدنى THRESH.
!>
!> النتائج من SGGEV:
!>
!> (1)  الحد الأقصى لجميع أزواج القيم الذاتية/المتجهات الذاتية اليسرى (alpha/beta,l) لـ
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      حيث VL**H هو المرافق التام لـ VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp وهل أكبر مكون حقيقي
!>
!>      VL(i) يمثل العمود i من VL.
!>
!> (3)  الحد الأقصى لجميع أزواج القيم الذاتية/المتجهات الذاتية اليسرى (alpha/beta,r) لـ
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp وهل أكبر مكون حقيقي
!>
!>      VR(i) يمثل العمود i من VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) تمثل القيم الذاتية المحسوبة عندما يتم حساب كل من l و r
!>      W(partial) تمثل النتائج عندما يتم حساب W فقط، أو W و r فقط، أو W و l فقط.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) تمثل المتجهات الذاتية اليسرى المحسوبة عندما يتم حساب كل من l و r،
!>      VL(partial) تمثل النتائج عندما يتم حساب l فقط.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) تمثل المتجهات الذاتية اليمنى المحسوبة عندما يتم حساب كل من l و r،
!>      VR(partial) تمثل النتائج عندما يتم حساب l فقط.
!>
!>
!> مصفوفات الاختبار
!> ---- --------
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ يحدد كل عنصر NN(j) حجمًا واحدًا.
!> يتم تحديد أنواع المصفوفات بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كان DOTYPE(j) هو .TRUE.، فسيتم إنشاء نوع المصفوفة j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة هوية ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة صفرية ومصفوفة هوية)
!>
!> (4)  ( I, I )         (زوج من المصفوفات الهوية)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان المنقولة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I مصفوفة هوية k x k و J كتلة جوردان (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هو قطري( 0, 1,..., N-1 ) (مصفوفة قطرية
!>                       بهذه المدخلات القطرية.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث  big تقترب من فيضان و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        حيث D1 هو قطري( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2 هو قطري( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     حيث Q و Z مصفوفات متعامدة عشوائية.
!>
!> (17) Q ( T1, T2 ) Z    حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!>                        بمدخلات عشوائية O(1) فوق القطر
!>                        ومدخلات قطرية diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     حيث T1 و T2 مصفوفتان مثلثيتان علويتان عشوائيتان.
!>
!>

NAME

sdrgev - checks the nonsymmetric generalized eigenvalue problem A x = lambda B x.

SYNOPSIS

 SUBROUTINE SDRGEV(
     NPT, NJ, NSIZES, NN, DOTYPE, NTSTYPES, NTYP, NQUERY,
     QL, QLR, QLI, ALPHA, BETA,
     ISEED, THRESH, NOUNIT, A, LDA, B, S, T,
     Q, LDQ, Z, ZERCOND, QE, LDQE, ALPHAR, ALPHAI, BETA,
     ALPHR1, ALPHI1, BETA1, WORK, LWORK, RESULT, INFO )
 
 INPUT/OUTPUT PARAMETERS
 
 PARAMETER NPT      (INTEGER)
 !> Number of problems to generate.


 PARAMETER NJ       (INTEGER)
 !> Which problems to run. NJ=1 means run all.


 PARAMETER NSIZES   (INTEGER)
 !> Number of matrix sizes.


 PARAMETER NN       (INTEGER array, dimension (NSIZES))
 !> Matrix sizes.


 PARAMETER DOTYPE   (LOGICAL array, dimension (NTYPES))
 !> Which matrix types to run.


 PARAMETER NTSTYPES (INTEGER)
 !> Number of types to run.


 PARAMETER NTYP     (INTEGER)
 !> Number of types defined.


 PARAMETER NQUERY   (INTEGER)
 !> Number of queries to the random number generator.


 PARAMETER QL       (LOGICAL)
 !> If .TRUE., query the optimal workspace lengths.


 PARAMETER QLR      (INTEGER)
 !> Workspace length for the QR algorithm.


 PARAMETER QLI      (INTEGER)
 !> Workspace length for the Inverse Iteration algorithm.


 PARAMETER ALPHA    (INTEGER)
 !> The alpha eigenvalues.


 PARAMETER BETA     (INTEGER)
 !> The beta eigenvalues.


 PARAMETER ISEED    (INTEGER array, dimension (4))
 !> Random number seed.


 PARAMETER THRESH   (REAL)
 !> Threshold for error norms.


 PARAMETER NOUNIT   (INTEGER)
 !> Unit number for error messages.


 PARAMETER A        (REAL array, dimension (LDA, max(NN)))
 !> Matrix A.


 PARAMETER LDA      (INTEGER)
 !> Leading dimension of A, B, S, T.


 PARAMETER B        (REAL array, dimension (LDA, max(NN)))
 !> Matrix B.


 PARAMETER S        (REAL array, dimension (LDA, max(NN)))
 !> Upper quasi-triangular matrix S.


 PARAMETER T        (REAL array, dimension (LDA, max(NN)))
 !> Upper triangular matrix T.


 PARAMETER Q        (REAL array, dimension (LDQ, max(NN)))
 !> Orthogonal matrix Q.


 PARAMETER LDQ      (INTEGER)
 !> Leading dimension of Q and Z.


 PARAMETER Z        (REAL array, dimension (LDQ, max(NN)))
 !> Orthogonal matrix Z.


 PARAMETER ZERCOND  (REAL)
 !> Condition number for zero eigenvalues.


 PARAMETER QE       (REAL array, dimension (LDQE, max(NN)))
 !> Matrix QE.


 PARAMETER LDQE     (INTEGER)
 !> Leading dimension of QE.


 PARAMETER ALPHAR   (REAL array, dimension (max(NN)))
 !> Real part of eigenvalues.


 PARAMETER ALPHAI   (REAL array, dimension (max(NN)))
 !> Imaginary part of eigenvalues.


 PARAMETER BETA     (REAL array, dimension (max(NN)))
 !> Beta eigenvalues.


 PARAMETER ALPHR1   (REAL array, dimension (max(NN)))
 !> Real part of eigenvalues.


 PARAMETER ALPHI1   (REAL array, dimension (max(NN)))
 !> Imaginary part of eigenvalues.


 PARAMETER BETA1    (REAL array, dimension (max(NN)))
 !> Beta eigenvalues.


 PARAMETER WORK     (REAL array, dimension (LWORK))
 !> Workspace array.


 PARAMETER LWORK    (INTEGER)
 !> Length of WORK.


 PARAMETER RESULT   (REAL array, dimension (2))
 !> Test results.


 PARAMETER INFO     (INTEGER)
 !> Error code.

Function/Subroutine Documentation

NPT

!> NPT is INTEGER
!> The number of problems to generate. Only the first NPT problems will
!> be generated and tested.

NJ

!> NJ is INTEGER
!> Which problems to run.
!> If NJ = 1, then all problems are run.
!> If NJ > 1, then only problems of type NJ are run.

NSIZES

!> NSIZES is INTEGER
!> The number of matrix sizes to test.

NN

!> NN is INTEGER array, dimension (NSIZES)
!> The matrix sizes to test. NN(i) is the size of the matrix to be
!> tested.

NTYPES

!> NTYPES is INTEGER
!> The number of types of matrices to generate.
!> If NTYPES < 0, then the test routines will not generate any matrices.
!> If NTYPES = 0, then the test routines will not generate any matrices.
!> If NTYPES > 0, then the test routines will generate NTYPES matrix types.

DOTYPE

!> DOTYPE is LOGICAL array, dimension (NTYPES)
!> If DOTYPE(j) is .TRUE., then for each size in NN a matrix of that size
!> and of type j will be generated.
!> If NTYPES is smaller than the maximum number of types defined
!> (PARAMETER MAXTYP), then types NTYPES+1 through MAXTYP will not be
!> generated. If NTYPES is larger than MAXTYP, DOTYPE(MAXTYP+1)
!> through DOTYPE(NTYPES) will be ignored.
!> A value of NTYPES=MAXTYP+1 is allowed, in which case DOTYPE(MAXTYP+1)
!> is used to specify that the input matrix A should be used.
!> In this case, the dimension of DOTYPE should be MAXTYP+1.
!> The value DOTYPE(MAXTYP+1) is only relevant if NSIZES=1.
!> If DOTYPE(MAXTYP+1) is .TRUE. and NSIZES=1, then the matrix A is
!> used as input. This requires that the routine has access to the
!> matrix A. This is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!> DOTYPE(MAXTYP+1) is .TRUE. .
!>

NTSTYPES

!> NTSTYPES is INTEGER
!> The number of types of matrices to test.

NTYP

!> NTYP is INTEGER
!> The number of types of matrices defined. It must be at least zero. If it
!> is MAXTYP+1 and NSIZES is 1, then an additional type, MAXTYP+1 is
!> defined, which is to use whatever matrix is in A. This
!> is only useful if DOTYPE(1:MAXTYP) is .FALSE. and
!> DOTYPE(MAXTYP+1) is .TRUE. .
!>

DOTYPE

!> DOTYPE is LOGICAL array, dimension (NTYPES)
!> If DOTYPE(j) is .TRUE., then for each size in NN a
!> matrix of that size and of type j will be generated.
!> If NTYPES is smaller than the maximum number of types
!> defined (PARAMETER MAXTYP), then types NTYPES+1 through
!> MAXTYP will not be generated. If NTYPES is larger
!> than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES)
!> will be ignored.
!>

ISEED

!> ISEED is INTEGER array, dimension (4)
!> On entry ISEED specifies the seed of the random number
!> generator. The array elements should be between 0 and 4095;
!> if not they will be reduced mod 4096. Also, ISEED(4) must
!> be odd. The random number generator uses a linear
!> congruential sequence limited to small integers, and so
!> should produce machine independent random numbers. The
!> values of ISEED are changed on exit, and can be used in the
!> next call to SDRGES to continue the same random number
!> sequence.
!>

THRESH

!> THRESH is REAL
!> A test will count as if the , computed as
!> described above, exceeds THRESH. Note that the error is
!> scaled to be O(1), so THRESH should be a reasonably small
!> multiple of 1, e.g., 10 or 100. In particular, it should
!> not depend on the precision (single vs. double) or the size
!> of the matrix. It must be at least zero.
!>

NOUNIT

!> NOUNIT is INTEGER
!> The FORTRAN unit number for printing out error messages
!> (e.g., if a routine returns IERR not equal to 0.)
!>

A

!> A is REAL array,
!> dimension(LDA, max(NN))
!> Used to hold the original A matrix. Used as input only
!> if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!> LDA is INTEGER
!> The leading dimension of A, B, S, and T.
!> It must be at least 1 and at least max( NN ).
!>

B

!> B is REAL array,
!> dimension(LDA, max(NN))
!> Used to hold the original B matrix. Used as input only
!> if NTYPES=MAXTYP+1, DOTYPE(1:MAXTYP)=.FALSE., and
!> DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!> S is REAL array,
!> dimension (LDA, max(NN))
!> The Schur form matrix computed from A by SGGES. On exit, S
!> contains the Schur form matrix corresponding to the matrix
!> in A.
!>

T

!> T is REAL array,
!> dimension (LDA, max(NN))
!> The upper triangular matrix computed from B by SGGES.
!>

Q

!> Q is REAL array,
!> dimension (LDQ, max(NN))
!> The (left) eigenvectors matrix computed by SGGEV.
!>

LDQ

!> LDQ is INTEGER
!> The leading dimension of Q and Z. It must
!> be at least 1 and at least max( NN ).
