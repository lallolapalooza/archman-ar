SDRGEV3

الغرض:

!>
!> يتحقق SDRGEV3 من روتين مشغل مسألة القيمة الذاتية المعممة غير المتماثلة
!> SGGEV3.
!>
!> يحسب SGGEV3 لزوج من المصفوفات غير المتماثلة (A,B) بحجم n×n
!> القيم الذاتية المعممة، واختياريًا، المتجهات الذاتية
!> اليسرى واليمنى.
!>
!> القيمة الذاتية المعممة لزوج من المصفوفات (A,B) هي عدد قياسي w
!> أو نسبة alpha/beta = w، بحيث تكون A - w*B مفردة.  وعادةً ما
!> تُrepresented كالزوج (alpha,beta)، حيث يوجد تفسير معقول
!> لـ beta=0، وحتى لكليهما معًا.
!>
!> المتجه الذاتي المعمم الأيمن المقابل لقيمة ذاتية معممة
!> w لزوج من المصفوفات (A,B) هو متجه r بحيث
!> (A - wB) * r = 0.  والمتجه الذاتي المعمم الأيسر هو متجه l بحيث
!> l**H * (A - wB) = 0، حيث l**H هو المرافق-المنقول لـ l.
!>
!> عند استدعاء SDRGEV3، يتم تحديد عدد من أحجام المصفوفات ()
!> وعدد من أنواع المصفوفات.  لكل حجم ()
!> ولكل نوع من المصفوفات، سيتم توليد زوج من المصفوفات (A, B)
!> واستخدامه للاختبار.  لكل زوج من المصفوفات، سيتم إجراء الاختبارات
!> التالية ومقارنتها مع العتبة THRESH.
!>
!> النتائج من SGGEV3:
!>
!> (1)  الحد الأقصى على جميع أزواج القيمة الذاتية/المتجه الذاتي اليسرى (alpha/beta,l) من
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      حيث VL**H هو المرافق-المنقول لـ VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp وما إذا كان أكبر مكوّن حقيقيًا
!>
!>      VL(i) يشير إلى العمود i من VL.
!>
!> (3)  الحد الأقصى على جميع أزواج القيمة الذاتية/المتجه الذاتي اليسرى (alpha/beta,r) من
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp وما إذا كان أكبر مكوّن حقيقيًا
!>
!>      VR(i) يشير إلى العمود i من VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) يشير إلى القيم الذاتية المحسوبة عندما يتم أيضًا
!>      حساب كل من l و r، و W(partial) يشير إلى القيم الذاتية
!>      المحسوبة عندما يتم حساب W فقط، أو W و r فقط، أو W و l فقط.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) يشير إلى المتجهات الذاتية اليسرى المحسوبة عندما يتم حساب
!>      كل من l و r، و VL(partial) يشير إلى النتيجة
!>      عندما يتم حساب l فقط.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) يشير إلى المتجهات الذاتية اليمنى المحسوبة عندما يتم أيضًا
!>      حساب كل من l و r، و VR(partial) يشير إلى النتيجة
!>      عندما يتم حساب l فقط.
!>
!>
!> مصفوفات الاختبار
!> ---- --------
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد الأنواع بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا كانت
!> DOTYPE(j) تساوي .TRUE.، فسيتم توليد نوع المصفوفة j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة وحدة ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة وحدة ومصفوفة صفرية)
!>
!> (4)  ( I, I )         (زوج من مصفوفات الوحدة)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان المنقولة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I هي مصفوفة وحدة k×k و J كتلة جوردان
!>                       (k+1)×(k+1)؛ k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هي diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!>                       بتلك العناصر القطرية.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث big قريب من الفائض و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     حيث Q و Z مصفوفات متعامدة عشوائية.
!>
!> (17) Q ( T1, T2 ) Z    حيث T1 و T2 مصفوفات مثلثية عليا
!>                        بعناصر عشوائية O(1) فوق القطر
!>                        وعناصر قطرية diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     حيث T1 و T2 مصفوفات مثلثية عليا
!>                         عشوائية.
!>
!>

المعاملات

NSIZES 
!>          NSIZES هو INTEGER
!>          عدد أحجام المصفوفات المراد استخدامها.  إذا كانت صفرًا،
!>          فإن SDRGEV3 لا يفعل شيئًا.  NSIZES >= 0.
!>

NN

!>          NN هي مصفوفة INTEGER، البعد (NSIZES)
!>          مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
!>          سيتم تخطي القيم الصفرية.  NN >= 0.
!>

NTYPES

!>          NTYPES هو INTEGER
!>          عدد العناصر في DOTYPE.  إذا كان صفرًا، فإن SDRGEV3
!>لا يفعل شيئًا. يجب أن يكون على الأقل صفرًا. إذا كان MAXTYP+1
!>          وكان NSIZES يساوي 1، فسيتم تعريف نوع إضافي، MAXTYP+1،
!>          وهو استخدام أي مصفوفة موجودة في A. هذا
!>          مفيد فقط إذا كانت DOTYPE(1:MAXTYP) تساوي .FALSE. و
!>          DOTYPE(MAXTYP+1) تساوي .TRUE. .
!>

DOTYPE

!>          DOTYPE هي مصفوفة LOGICAL، البُعد (NTYPES)
!>          إذا كانت DOTYPE(j) تساوي .TRUE.، فسيتم لكل حجم في NN
!>          توليد مصفوفة بذلك الحجم ومن النوع j.
!>          إذا كان NTYPES أصغر من الحد الأقصى لعدد الأنواع
!>          المعرفة (PARAMETER MAXTYP)، فلن يتم توليد الأنواع NTYPES+1 حتى
!>          MAXTYP. إذا كان NTYPES أكبر
!>          من MAXTYP، فسيتم تجاهل DOTYPE(MAXTYP+1) حتى DOTYPE(NTYPES).
!>

ISEED

!>          ISEED هي مصفوفة INTEGER، البُعد (4)
!>          عند الإدخال تحدد ISEED بذرة مولّد الأرقام
!>          العشوائية. يجب أن تكون عناصر المصفوفة بين 0 و 4095؛
!>          وإلا فسيتم اختزالها بمعامل 4096. أيضًا، يجب أن تكون ISEED(4)
!>          فردية. يستخدم مولّد الأرقام العشوائية متتالية
!>          خطية متطابقة محدودة بأعداد صحيحة صغيرة، ولذلك
!>          يجب أن ينتج أرقامًا عشوائية مستقلة عن الآلة. يتم
!>          تغيير قيم ISEED عند الخروج، ويمكن استخدامها في
!>          الاستدعاء التالي لـ SDRGEV3 لمتابعة نفس متتالية
!>          الأرقام العشوائية.
!>

THRESH

!>          THRESH هي REAL
!>          سيُحتسب الاختبار على أنه  إذا تجاوزت ، المحسوبة كما
!>          هو موصوف أعلاه، قيمة THRESH. لاحظ أن الخطأ
!>          مُقاس ليكون O(1)، لذا يجب أن تكون THRESH مضاعفًا
!>          صغيرًا معقولًا للعدد 1، مثل 10 أو 100. على وجه الخصوص، يجب
!>          ألا تعتمد على الدقة (المفردة مقابل المزدوجة) أو حجم
!>          المصفوفة. يجب أن تكون على الأقل صفرًا.
!>

NOUNIT

!>          NOUNIT هي INTEGER
!>          رقم وحدة FORTRAN لطباعة رسائل الخطأ
!>          (مثلًا، إذا أعادت روتين قيمة IERR لا تساوي 0.)
!>

A

!>          A هي مصفوفة REAL،
!>                                       البُعد(LDA, max(NN))
!>          تُستخدم لحفظ المصفوفة A الأصلية. تُستخدم كمدخل فقط
!>          إذا كان NTYPES=MAXTYP+1، وDOTYPE(1:MAXTYP)=.FALSE.، و
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA هي INTEGER
!>          البُعد الرئيسي لـ A و B و S و T.
!>          يجب أن يكون على الأقل 1 وعلى الأقل max( NN ).
!>

B

!>          B هي مصفوفة REAL،
!>                                       البُعد(LDA, max(NN))
!>          تُستخدم لحفظ المصفوفة B الأصلية. تُستخدم كمدخل فقط
!>          إذا كان NTYPES=MAXTYP+1، وDOTYPE(1:MAXTYP)=.FALSE.، و
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S هي مصفوفة REAL،
!>                                 البُعد (LDA, max(NN))
!>          مصفوفة شكل شور المحسوبة من A بواسطة SGGEV3. عند الخروج، تحتوي S
!>          على مصفوفة شكل شور المقابلة للمصفوفة
!>          الموجودة في A.
!>

T

!>          T هي مصفوفة REAL،
!>                                 البُعد (LDA, max(NN))
!>          المصفوفة المثلثية العليا المحسوبة من B بواسطة SGGEV3.
!>

Q

!>          Q هي مصفوفة REAL،
!>                                 البُعد (LDQ, max(NN))
!>          مصفوفة المتجهات الذاتية (اليسرى) المحسوبة بواسطة SGGEV3.
!>

LDQ

!>          LDQ هي INTEGER
!>          البُعد الرئيسي لـ Q و Z. يجب
!>          أن يكون على الأقل 1 وعلى الأقل max( NN ).
!>

Z

!>          Z هي مصفوفة REAL، البُعد( LDQ, max(NN) )
!>          المصفوفة المتعامدة (اليمنى) المحسوبة بواسطة SGGEV3.
!>

QE

!>          QE هي مصفوفة REAL، البُعد( LDQ, max(NN) )
!>          تحتفظ QE بالمتجهات الذاتية اليمنى أو اليسرى المحسوبة.
!>

LDQE

!>          LDQE هي INTEGER
!>          البُعد الرئيسي لـ QE. LDQE >= max(1,max(NN)).
!>

ALPHAR

!>          ALPHAR هي مصفوفة REAL، البُعد (max(NN))
!>

ALPHAI

!>          ALPHAI هي مصفوفة REAL، البُعد (max(NN))
!>

BETA

!>          BETA هي مصفوفة REAL، البُعد (max(NN))
!> \verbatim
!>          القيم الذاتية المعممة لـ (A,B) المحسوبة بواسطة SGGEV3.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) هي القيمة الذاتية
!>          المعممة رقم k لـ A و B.
!>

ALPHR1

!>          ALPHR1 هي مصفوفة REAL، البُعد (max(NN))
!>

ALPHI1

!>          ALPHI1 هي مصفوفة REAL، البُعد (max(NN))
!>

BETA1

!>          BETA1 هي مصفوفة REAL، البُعد (max(NN))
!>
!>          مثل ALPHAR و ALPHAI و BETA، تحتوي هذه المصفوفات على
!>          القيم الذاتية لـ A و B، لكن تلك المحسوبة عندما يحسب SGGEV3
!>          فقط تحليلًا جزئيًا للقيم الذاتية، أي ليس
!>          القيم الذاتية والمتجهات الذاتية اليسرى واليمنى.
!>

WORK

!>          WORK هي مصفوفة REAL، البُعد (LWORK)
!>

LWORK

!>          LWORK هي INTEGER
!>          عدد العناصر في WORK.  LWORK >= MAX( 8*N, N*(N+1) ).
!>

RESULT

!>          RESULT هي مصفوفة REAL، البُعد (2)
!>          القيم المحسوبة بواسطة الاختبارات الموصوفة أعلاه.
!>          القيم محدودة حاليًا بـ 1/ulp، لتجنب الفائض.
!>

INFO

!>          INFO هي INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط رقم i كانت له قيمة غير قانونية.
!>          > 0:  أعاد روتين رمز خطأ. INFO هي
!>                القيمة المطلقة لقيمة INFO المُعادة.
!>
