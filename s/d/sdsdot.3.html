real function sdsdot (n, sb, sx, incx, sy, incy)
SDSDOT

توثيق الوظيفة/الروتين الفرعي

real function sdsdot (integer n, real sb, real, dimension(*) sx, integer incx, real, dimension(*) sy, integer incy)

SDSDOT

الغرض:

!>
!>   حساب الناتج الداخلي لمتجهين مع تجميع دقة ممتدة.
!>
!>   تُرجع نتيجة S.P. مع تجميع الناتج الداخلي في D.P.
!>   SDSDOT = SB + sum لـ I = 0 إلى N-1 من SX(LX+I*INCX)*SY(LY+I*INCY),
!>   حيث LX = 1 إذا كان INCX .GE. 0، وإلا LX = 1+(1-N)*INCX، ويتم تعريف LY
!>   بطريقة مشابهة باستخدام INCY.
!>

المعلمات

N 
!>          N هو عدد صحيح (INTEGER)
!>          عدد العناصر في المتجه(المتجهات) المدخلة
!>

SB

!>          SB هو قيمة حقيقية (REAL)
!>          ثابت من دقة مفردة يُضاف إلى الناتج الداخلي
!>

SX

!>          SX هو مصفوفة من قيم حقيقية (REAL array)، بأبعاد ( 1 + ( N - 1 )*abs( INCX ) )
!>          متجه بدقة مفردة يحتوي على N عناصر
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)
!>          تباعد التخزين بين عناصر SX
!>

SY

!>          SY هي مصفوفة من قيم حقيقية (REAL array)، بأبعاد ( 1 + ( N - 1 )*abs( INCX ) )
!>          متجه بدقة مفردة يحتوي على N عناصر
!>

INCY

!>          INCY هو عدد صحيح (INTEGER)
!>          تباعد التخزين بين عناصر SY
!>
