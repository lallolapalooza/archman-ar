DESCRIPTION

يسمح كائن sd_bus_track بتتبع دورة حياة كائنات Bus bus. هذا مفيد لضمان عدم فقدان الكائنات التي قد لا تزال قيد الاستخدام.

sd_bus_track_new(): يقوم بإنشاء كائن تتبع جديد متصل بـ bus. سيتم إعلام هذا الكائن بجميع عمليات إزالة الكائنات المرتبطة بـ bus. سيتم تخزين المؤشر إلى كائن التتبع الجديد في track_ptr.

sd_bus_track_ref() و sd_bus_track_unref(): تقوم بزيادة وتقليل عداد المراجع لكائن التتبع. عندما يصل عداد المراجع إلى الصفر، يتم تحرير الكائن.

sd_bus_track_unrefp(): نسخة مساعدة لـ sd_bus_track_unref() تأخذ مؤشرًا إلى مؤشر.

sd_bus_track_get_recursive() و sd_bus_track_set_recursive(): تسمح بالحصول على وتعيين خاصية "التكرار" لكائن التتبع. عندما تكون الخاصية "التكرار" مضبوطة على صحيح، سيتم تتبع الكائنات التي تم إنشاؤها بواسطة كائنات Bus تتبعها. بشكل افتراضي، تكون هذه الخاصية مضبوطة على خطأ.

sd_bus_track_get_bus(): تقوم بإرجاع مؤشر إلى كائن Bus الذي تم إنشاؤه كائن التتبع له.

sd_bus_track_get_userdata() و sd_bus_track_set_userdata(): تسمح بتعيين واسترداد بيانات المستخدم المرتبطة بكائن التتبع. يمكن استخدام cleanup لتحديد دالة يتم استدعاؤها عند تحرير كائن التتبع.

RETURN VALUE

sd_bus_track_new(): ترجع 0 عند النجاح، أو قيمة سالبة عند الفشل.

sd_bus_track_ref(): ترجع مؤشرًا صالحًا لكائن التتبع عند النجاح، أو NULL عند الفشل.

sd_bus_track_unref(): ترجع مؤشرًا فارغًا عند النجاح، أو NULL عند الفشل.

sd_bus_track_unrefp(): ترجع مؤشرًا فارغًا عند النجاح، أو NULL عند الفشل.

sd_bus_track_get_recursive(): ترجع 1 إذا كان التتبع تكراريًا، 0 إذا لم يكن كذلك.

sd_bus_track_set_recursive(): ترجع 0 عند النجاح، أو قيمة سالبة عند الفشل.

sd_bus_track_get_bus(): ترجع مؤشرًا صالحًا لكائن Bus عند النجاح، أو NULL عند الفشل.

sd_bus_track_get_userdata(): ترجع 0 عند النجاح، أو قيمة سالبة عند الفشل. إذا تم تعيين بيانات المستخدم، يتم وضع مؤشر إليها في userdata_ptr.

sd_bus_track_set_userdata(): ترجع 0 عند النجاح، أو قيمة سالبة عند الفشل.

REFERENCE OWNERSHIP

يجب على المستدعي تتبع إشارات الكائنات باستخدام sd_bus_track_ref() و sd_bus_track_unref().
