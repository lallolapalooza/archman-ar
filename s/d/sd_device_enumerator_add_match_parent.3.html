الوصف

تقوم الدالة sd_device_enumerator_add_match_parent() بإضافة مرشح إلى enumerator بحيث لا يتم تعداد الأجهزة إلا تحت شجرة الجهاز parent المحدد. إذا تم استدعاء هذه الدالة عدة مرات، فسيتم مسح جهاز parent المحدد سابقًا ولن يكون لتأثير سوى الاستدعاء الأخير.

تقوم الدالة sd_device_enumerator_add_match_property() بإضافة مرشح إلى enumerator بحيث لا يتم تعداد الأجهزة إلا ذات الخاصية property المحددة التي تساوي القيمة value. يمكن أن تكون كل من property و value نمطًا عالميًا. عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على خاصية واحدة على الأقل من الخصائص المحددة مع القيم المتطابقة. أي، يتم دمج المرشحات بشكل OR.

تقوم الدالة sd_device_enumerator_add_match_property_required() بإضافة مرشح إلى enumerator بحيث لا يتم تعداد الأجهزة إلا ذات الخاصية property المحددة التي تساوي القيمة value. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على جميع الخصائص المحددة مع القيم المتطابقة. أي، يتم دمج المرشحات بشكل AND.

تقوم الدالة sd_device_enumerator_add_match_subsystem() بإضافة مرشح إلى enumerator بحيث يتم تضمين جميع الأجهزة في subsystem المحدد، عندما تكون match true. عندما تكون match false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند استدعاء هذه الدالة عدة مرات، يتم دمج المرشحات الإيجابية بشكل OR، والمرشحات السلبية بشكل AND.

تقوم الدالة sd_device_enumerator_add_match_sysattr() بإضافة مرشح على سمة النظام sysattr تطابق القيمة value. يمكن أن تكون value نمطًا عالميًا. إذا كانت value NULL، فسيتم تضمين الأجهزة التي لديها (إذا كانت match true) أو لا تمتلك (إذا كانت match false) السمة sysattr المحددة، بغض النظر عن قيمتها. أي، NULL يكافئ "*". عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع مرشحات sysattr المحددة فقط. أي، يتم دمج هذه المرشحات بشكل AND.

تقوم الدالة sd_device_enumerator_add_match_sysname() بإضافة مرشح بحيث لا يتم تعداد الأجهزة التي يكون اسم نظامها (sysname) مساويًا لـ sysname. يمكن أن يكون sysname نمطًا عالميًا. عند استدعاء هذه الدالة عدة مرات، يتم دمج المرشحات بشكل OR.

تقوم الدالة sd_device_enumerator_add_nomatch_sysname() بإضافة مرشح بحيث يتم استبعاد الأجهزة التي يكون اسم نظامها (sysname) مساويًا لـ sysname من عملية التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند استدعاء هذه الدالة عدة مرات، يتم دمج الميزات بشكل AND.

تقوم الدالة sd_device_enumerator_add_match_tag() بإضافة مرشح بحيث لا يتم تعداد الأجهزة التي تم تمييزها بالعلامة tag. عند استدعاء هذه الدالة عدة مرات، يتم دمج المرشحات بشكل OR.

تسمح الدالة sd_device_enumerator_allow_uninitialized() بتضمين الأجهزة التي لم يتم تهيئتها بواسطة udev بعد في التعداد.

تقوم الدالة sd_device_enumerator_add_all_parents() بتعداد جميع الأجهزة الأصلية للأجهزة المتطابقة. هذا مفيد للحالات التي ترغب فيها في تضمين جميع الأجهزة الأصلية في التعداد، مثل عندما تكون مهتمًا بشجرة الأجهزة الكاملة التي تؤدي إلى جهاز معين.

قيمة الإرجاع

ترجع جميع الدوال 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا بنمط errno عند الفشل.

الأخطاء

قد تشير الأخطاء التي تم إرجاعها إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد المعلمات غير صالح.

أمثلة

مثال 1. اكتشاف أجهزة USB القابلة للإزالة (باستخدام المطابقة والاستبعاد)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء مُعدد أجهزة جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل في إنشاء مُعدد الأجهزة: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من نظام فرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة مطابقة النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي سمة النظام (sysattr) "removable" لها القيمة "0"
     * هذه عادةً الأجهزة غير القابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل في إضافة مطابقة سمة النظام: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المتطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على المسار النظامي للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}

sd_device_enumerator_add_all_parents(3) — systemd libs

NAME

sd_device_enumerator_add_all_parents - Add all parents of a device to an enumerator

SYNOPSIS

#include <systemd/sd-device.h>
int sd_device_enumerator_add_all_parents(sd_device_enumerator *enumerator,
                                        sd_device *device);

DESCRIPTION

The sd_device_enumerator_add_all_parents() function takes an enumerator object, an sd_device object, and adds all parent devices of the given device to the enumerator. This is useful when you want to enumerate a device and all of its ancestors.

The parent devices are added to the enumerator with the same type and properties as the original device. This means that if you later call sd_device_enumerator_get_device_first() or sd_device_enumerator_get_device_next(), you will receive the parents first, and then the original device.

RETURN VALUE

On success, sd_device_enumerator_add_all_parents() returns a non-negative integer. On failure, it returns a negative error number.

EXAMPLES

This example demonstrates how to add all parents of a device to an enumerator and then retrieve the devices in order.

    sd_device_enumerator *enumerator = NULL;
    sd_device *device = NULL;
    sd_device *parent_device = NULL;
    int r;

    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "Failed to create enumerator: %s\n", strerror(-r));
        goto finish;
    }

    r = sd_device_get_from_syspath(NULL, "/sys/devices/pci0000:00/0000:00:01.0/0000:01:00.0", &device);
    if (r < 0) {
        fprintf(stderr, "Failed to get device: %s\n", strerror(-r));
        goto finish;
    }

    r = sd_device_enumerator_add_all_parents(enumerator, device);
    if (r < 0) {
        fprintf(stderr, "Failed to add parents: %s\n", strerror(-r));
        goto finish;
    }

    // Now, get the devices in order
    while ((r = sd_device_enumerator_get_device_first(enumerator, &parent_device)) > 0) {
        const char *path;
        sd_device_get_syspath(parent_device, &path);
        printf("Found parent: %s\n", path);
        sd_device_unref(parent_device);
    }

    // Finally, get the original device
    r = sd_device_enumerator_get_device_first(enumerator, &parent_device);
    if (r > 0) {
        const char *path;
        sd_device_get_syspath(parent_device, &path);
        printf("Found original device: %s\n", path);
        sd_device_unref(parent_device);
    }


finish:
    sd_device_unref(device);
    sd_device_enumerator_unref(enumerator);
    return r < 0 ? 1 : 0;

HISTORY

sd_device_enumerator_add_all_parents() was added in version 258.
