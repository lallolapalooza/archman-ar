الوصف

بالإضافة إلى أسماء الأخطاء التي تحددها برامج المستخدم، يعرف D-Bus عددًا من الأسماء العامة والموحدة للأخطاء المدرجة أدناه.

بالإضافة إلى هذه القائمة، في sd-bus، يتم استخدام مساحة اسم الخطأ الخاصة "System.Error." لربط أخطاء نظام Linux العشوائية (كما هو محدد بواسطة errno(3)) بأخطاء D-Bus والعكس صحيح. على سبيل المثال، يتم ربط الخطأ EUCLEAN بـ "System.Error.EUCLEAN" والعكس صحيح.

SD_BUS_ERROR_FAILED

إشارة خطأ عامة. انظر رسالة الخطأ لمزيد من التفاصيل. يجب تجنب اسم الخطأ هذا، لصالح اسم خطأ أكثر تعبيرًا.

تمت الإضافة في الإصدار 223.

sd_bus_error(3) — systemd — systemd-libs

NAME

sd_bus_error_has_name, SD_BUS_ERROR_NULL, SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN, SD_BUS_ERROR_INVALID_SIGNATURE, SD_BUS_ERROR_INCONSISTENT_MESSAGE, SD_BUS_ERROR_MATCH_RULE_NOT_FOUND, SD_BUS_ERROR_MATCH_RULE_INVALID, SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED — Check for specific bus errors and common error codes

SYNOPSIS

#include <systemd/sd-bus.h>

bool sd_bus_error_has_name(const sd_bus_error *error, const char *name);

DESCRIPTION

The sd_bus_error_has_name() function checks if the error object, which must not be NULL, refers to an error with the specified name string.

The following constants are defined as possible error names:

SD_BUS_ERROR_NULL

The error object is empty or invalid.

Added in version 223.

SD_BUS_ERROR_ACCESS_DENIED

Access denied. This is often returned when the caller lacks the necessary privileges for the requested operation.

Added in version 223.

SD_BUS_ERROR_AUTH_FAILED

Authentication failed. This error is returned when the authentication mechanism fails.

Added in version 223.

SD_BUS_ERROR_LIMITS_EXCEEDED

One or more limits have been exceeded. This could refer to resource limits, connection limits, or other constraints.

Added in version 223.

SD_BUS_ERROR_NOT_SUPPORTED

The requested operation or feature is not supported by the service.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_INTERFACE

The specified interface is unknown.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_MEMBER

The specified method or signal name is unknown for the given interface.

Added in version 223.

SD_BUS_ERROR_UNKNOWN_OBJECT

The specified object path is unknown.

Added in version 223.

SD_BUS_ERROR_UNIX_INTERFACE_UNKNOWN

The specified UNIX domain socket interface is unknown.

Added in version 223.

SD_BUS_ERROR_UNIX_FD_IS_NOT_AN_OBJECT

The specified UNIX file descriptor is not associated with an object.

Added in version 223.

SD_BUS_ERROR_UNIX_EXEC_IS_NOT_SUPPORTED

The requested operation involving execution is not supported.

Added in version 223.

SD_BUS_ERROR_UNIX_PROPERTY_READONLY

An operation on a read-only property was requested.

Added in version 223.

SD_BUS_ERROR_UNIX_PROCESS_ID_UNKNOWN

The requested PID is not known.

Added in version 223.

SD_BUS_ERROR_INVALID_SIGNATURE

The specified message signature is not valid.

Added in version 223.

SD_BUS_ERROR_INCONSISTENT_MESSAGE

The passed message does not validate correctly.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_NOT_FOUND

The specified match rule does not exist.

Added in version 223.

SD_BUS_ERROR_MATCH_RULE_INVALID

The specified match rule is invalid.

Added in version 223.

SD_BUS_ERROR_INTERACTIVE_AUTHORIZATION_REQUIRED

Access to the requested operation is not permitted. However, it might be available after interactive authentication. This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
