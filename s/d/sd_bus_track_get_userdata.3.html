sd_bus_track_get_userdata(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

NAME

sd_bus_track_get_userdata, sd_bus_track_set_userdata - Get and set arbitrary user data pointer for a bus tracker

SYNOPSIS

#include <systemd/sd-bus.h>

void *sd_bus_track_get_userdata(sd_bus_track *track);
int sd_bus_track_set_userdata(sd_bus_track *track, void *userdata, sd_bus_track_destroy_func_t destroy);

DESCRIPTION

The sd_bus_track_get_userdata() function returns the arbitrary user-defined pointer stored in the track object. This pointer is initially NULL.

The sd_bus_track_set_userdata() function sets an arbitrary user-defined pointer, userdata, in the track object. The destroy parameter is a callback function that will be called when the track object is destroyed, and it may be NULL. The callback receives the track object and the userdata pointer, and is expected to free the associated resources.

The destroy callback is called before the track object itself is deallocated. It is called exactly once, when the track object is destroyed.

RETURN VALUE

sd_bus_track_get_userdata() returns the stored user data pointer.

sd_bus_track_set_userdata() returns 0 on success, or a negative error number on failure. Error number are defined in <systemd/sd-bus.h>.

REFERENCE OWNERSHIP

The user data pointer is owned by the user. The track object does not take ownership of it, unless the destroy callback is provided and specifically manages the lifetime.

NOTES

Functions described here are available as a shared library, which can be compiled and linked to with the pkg-config(1) helper macro.

Include the following header when using these functions:

#include <systemd/sd-bus.h>

الاسم

sd_bus_track_get_userdata, sd_bus_track_set_userdata - الحصول على بيانات المستخدم العشوائية وتعيينها لمتعقب ناقل

ملخص

#include <systemd/sd-bus.h>

void *sd_bus_track_get_userdata(sd_bus_track *track);
int sd_bus_track_set_userdata(sd_bus_track *track, void *userdata, sd_bus_track_destroy_func_t destroy);

الوصف

sd_bus_track_get_userdata() تقوم الدالة بإرجاع المؤشر المحدد من قبل المستخدم والمخزن في كائن track. هذا المؤشر يكون NULL مبدئياً.

sd_bus_track_set_userdata() تقوم الدالة بتعيين مؤشر محدد من قبل المستخدم، userdata، في كائن track. المعلمة destroy هي دالة استدعاء سيتم استدعاؤها عند تدمير كائن المسار، وقد تكون NULL. تستقبل الدالة الاستدعائية كائن track ومؤشر userdata، ومن المتوقع أن تحرر الموارد المرتبطة.

سيتم استدعاء دالة الاستدعاء destroy قبل تخصيص كائن المسار نفسه. سيتم استدعاؤها مرة واحدة بالضبط، عند تدمير كائن المسار.

قيمة الإرجاع

sd_bus_track_get_userdata() ترجع مؤشر بيانات المستخدم المخزن.

sd_bus_track_set_userdata() ترجع 0 عند النجاح، أو رقم خطأ سالب عند الفشل. أرقام الأخطاء معرفة في <systemd/sd-bus.h>.

ملكية المرجع

مؤشر بيانات المستخدم مملوك للمستخدم. لا يأخذ كائن track ملكيته، إلا إذا تم توفير دالة الاستدعاء destroy وهي تدير عمره بشكل خاص.

#include <systemd/sd-bus.h>
