الوصف

تقوم الدالة sd_device_enumerator_add_match_parent() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة الموجودة ضمن شجرة الجهاز parent المحدد. إذا تم استدعاء هذه الدالة عدة مرات، يتم مسح الجهاز parent الذي تم تعيينه سابقًا، وتأخذ المكالمة الأخيرة فقط تأثيرًا.

تقوم الدالة sd_device_enumerator_add_match_property() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة التي يكون فيها property المحدد مساويًا لـ value. يمكن أن يكون كل من property و value نمطًا عامًا (glob pattern). عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على خاصية واحدة على الأقل من الخصائص المحددة ذات القيم المتطابقة. أي أن المرشحات يتم ربطها بـ OR.

تقوم الدالة sd_device_enumerator_add_match_property_required() بإضافة مرشح إلى enumerator بحيث يتم فقط تعداد الأجهزة التي يكون فيها property المحدد مساويًا لـ value. هذه الدالة مشابهة لـ sd_device_enumerator_add_match_property()، ولكن عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تحتوي على جميع الخصائص المحددة ذات القيم المتطابقة. أي أن المرشحات يتم ربطها بـ AND.

تقوم الدالة sd_device_enumerator_add_match_subsystem() بإضافة مرشح إلى enumerator بحيث يتم تضمين جميع الأجهزة في subsystem المحدد، عندما يكون match هو true. عندما يكون match هو false، يتم تعداد جميع الأجهزة باستثناء تلك الموجودة في subsystem المحدد. عند استدعاء هذه الدالة عدة مرات، يتم ربط المرشحات الإيجابية بـ OR، والمرشحات السلبية بـ AND.

تقوم الدالة sd_device_enumerator_add_match_sysattr() بإضافة مرشح على سمة النظام (sysfs attribute) sysattr المطابقة لـ value. يمكن أن يكون value نمطًا عامًا (glob pattern). إذا كان value هو NULL، يتم تضمين الأجهزة التي لديها (إذا كان match هو true) أو ليس لديها (إذا كان match هو false) سمة sysattr المحددة، بغض النظر عن قيمتها. أي أن NULL يعادل تقريبًا "*". عند استدعاء هذه الدالة عدة مرات، يتم تعداد الأجهزة التي تطابق جميع مرشحات sysattr المحددة فقط. أي أن هذه المرشحات يتم ربطها بـ AND.

تقوم الدالة sd_device_enumerator_add_match_sysname() بإضافة مرشح بحيث يتم فقط تعداد الأجهزة التي يتطابق اسمها في النظام (sysname) مع sysname. يمكن أن يكون sysname نمطًا عامًا (glob pattern). عند استدعاء هذه الدالة عدة مرات، يتم ربط المرشحات بـ OR.

تقوم الدالة sd_device_enumerator_add_nomatch_sysname() بإضافة مرشح بحيث يتم استبعاد الأجهزة التي يتطابق اسمها في النظام (sysname) مع sysname من عملية التعداد. هذا مفيد لاستبعاد أجهزة معينة من عملية التعداد. عند استدعاء هذه الدالة عدة مرات، يتم ربط الميزات بـ AND.

تقوم الدالة sd_device_enumerator_add_match_tag() بإضافة مرشح بحيث يتم فقط تعداد الأجهزة التي تحمل العلامة tag. عند استدعاء هذه الدالة عدة مرات، يتم ربط المرشحات بـ OR.

تسمح الدالة sd_device_enumerator_allow_uninitialized() بتضمين الأجهزة التي لم يتم تهيئتها بواسطة udev بعد في عملية التعداد.

تقوم الدالة sd_device_enumerator_add_all_parents() بتعداد جميع الأجهزة الأصلية للأجهزة المتطابقة. هذا مفيد للحالات التي تريد فيها تضمين جميع الأجهزة الأصلية في التعداد، كما هو الحال عندما تكون مهتمًا بشجرة الأجهزة بأكملها التي تؤدي إلى جهاز معين.

قيمة الإرجاع

جميع الدوال ترجع 0 أو عددًا صحيحًا موجبًا عند النجاح، أو رمز خطأ سالبًا بتنسيق errno عند الفشل.

الأخطاء

قد تشير الأخطاء التي يتم إرجاعها إلى المشاكل التالية:

-ENOMEM

فشل تخصيص الذاكرة.

-EINVAL

أحد المعاملات غير صالح.

أمثلة

مثال 1. الكشف عن أجهزة USB القابلة للإزالة (باستخدام التطابق والاستثناء)

/* SPDX-License-Identifier: MIT-0 */
#include <stdbool.h>
#include <stdio.h>
#include <systemd/sd-device.h>
int main(void) {
    __attribute__((cleanup(sd_device_enumerator_unrefp))) sd_device_enumerator *enumerator = NULL;
    sd_device *device;
    int r;
    /* إنشاء مُعدّ أجهزة جديد */
    r = sd_device_enumerator_new(&enumerator);
    if (r < 0) {
        fprintf(stderr, "فشل إنشاء مُعدّ الأجهزة: %s\n", strerror(-r));
        return 1;
    }
    /* تضمين الأجهزة فقط من نظام فرعي "usb" */
    r = sd_device_enumerator_add_match_subsystem(enumerator, "usb", true);
    if (r < 0) {
        fprintf(stderr, "فشل إضافة تطابق النظام الفرعي: %s\n", strerror(-r));
        return 1;
    }
    /*
     * استبعاد الأجهزة التي تكون فيها سمة النظام "removable" هي "0"
     * هذه عادةً ما تكون أجهزة غير قابلة للإزالة مثل واجهات USB المدمجة
     */
    r = sd_device_enumerator_add_match_sysattr(enumerator, "removable", "0", false);
    if (r < 0) {
        fprintf(stderr, "فشل إضافة تطابق سمة النظام: %s\n", strerror(-r));
        return 1;
    }
    /* بدء تعداد الأجهزة المتطابقة */
    for (device = sd_device_enumerator_get_device_first(enumerator);
         device;
         device = sd_device_enumerator_get_device_next(enumerator)) {
        const char *syspath;
        /* الحصول على مسار النظام للجهاز */
        if (sd_device_get_syspath(device, &syspath) >= 0)
            printf("تم العثور على جهاز USB قابل للإزالة: %s\n", syspath);
    }
    return 0;
}
