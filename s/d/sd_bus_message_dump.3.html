sd_bus_message_dump(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_MESSAGE_DUMP(3) sd_bus_message_dump SD_BUS_MESSAGE_DUMP(3)

الاسم

sd_bus_message_dump, sd_bus_message_dump_json - إنتاج تمثيل نصي للرسالة لأغراض التصحيح

ملخص

#include <systemd/sd-bus.h>

int sd_bus_message_dump(sd_bus_message *m, FILE *f, uint64_t flags);

int sd_bus_message_dump_json(sd_bus_message *m, uint64_t flags, sd_json_variant **ret);

الوصف

تقوم الدالة sd_bus_message_dump() بكتابة تمثيل نصي للرسالة m إلى التدفق f. إذا كانت f هي NULL، فسيتم استخدام المخرج القياسي (stdio). هذه الدالة مخصصة للاستخدام لأغراض التصحيح، والإخراج ليس ثابتًا وليس مصممًا ليكون قابلاً للقراءة بواسطة الآلة.

تقوم الدالة sd_bus_message_dump_json() بتحويل رسالة DBus m إلى متغير JSON وتخزينه في ret. يجب على المتصل استدعاء sd_json_variant_unref() للمتغير JSON المكتسب بعد الاستخدام. على عكس sd_bus_message_dump()، لا تطبع الدالة نفسها أي شيء. لطباعة رسالة DBus بتنسيق JSON، يرجى تمرير المتغير JSON المُرجع إلى sd_json_variant_dump().

قد يتم استخدام المعامل flags لتعديل الإخراج، وهو مزيج من صفر أو أكثر من العلامات التالية:

SD_BUS_MESSAGE_DUMP_WITH_HEADER

سيتم طباعة رأس الرسالة الذي يحدد نوع الرسالة، والعلامات، والعديد من البيانات الوصفية الإضافية، أو تضمينها في كائن JSON الناتج.

SD_BUS_MESSAGE_DUMP_SUBTREE_ONLY

سيتم طباعة أو تحويل الحاوية الحالية فقط. عندما لا يتم تحديد العلامة، سيتم طباعة محتويات الرسالة بأكملها أو تحويلها.

لاحظ أن هذه الدوال تحرك مؤشر القراءة للرسالة. قد يكون من الضروري إعادة تعيين الموضع لاحقًا، على سبيل المثال باستخدام sd_bus_message_rewind(3).

أمثلة

الإخراج لرسالة إشارة (مع SD_BUS_MESSAGE_DUMP_WITH_HEADER):

> Type=signal  Endian=l  Flags=1  Version=1  Cookie=22
  Path=/value/a  Interface=org.freedesktop.DBus.Properties  Member=PropertiesChanged
  MESSAGE "sa{sv}as" {
          STRING "org.freedesktop.systemd.ValueTest";
          ARRAY "{sv}" {
                  DICT_ENTRY "sv" {
                          STRING "Value";
                          VARIANT "s" {
                                  STRING "object 0x1e, path /value/a";
                          };
                  };
          };
          ARRAY "s" {
                  STRING "Value2";
                  STRING "AnExplicitProperty";
          };
  };

قيمة الإرجاع

عند النجاح، تعيد هذه الدالة 0 أو عددًا صحيحًا موجبًا. عند الفشل، تعيد رمز خطأ سالبًا بنمط errno. لا توجد رموز خطأ محددة حاليًا.

ملاحظات

الدوال الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها وربطها باستخدام ملف pkg-config(1) الخاص بـ libsystemd.

الكود الموصوف هنا يستخدم getenv(3)، والذي تم تعريفه على أنه غير آمن للاستخدام في مواضيع متعددة. هذا يعني أن الكود الذي يستدعي الدوال الموصوفة هنا يجب ألا يستدعي setenv(3) من موضوع موازٍ. يوصى بإجراء استدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم يتم بدء أي مواضيع أخرى.
