الوصف

بالإضافة إلى أسماء الأخطاء التي تحددها برامج المستخدم، يعرف D-Bus عددًا من أسماء الأخطاء القياسية والعامة المدرجة أدناه.

بالإضافة إلى هذه القائمة، في sd-bus، يتم استخدام مساحة الخطأ الخاصة "System.Error." لربط أخطاء نظام Linux (كما هو محدد بواسطة errno(3)) بأخطاء D-Bus والعكس صحيح. على سبيل المثال، يتم ربط الخطأ EUCLEAN بـ "System.Error.EUCLEAN" والعكس صحيح.

SD_BUS_ERROR_FAILED

علامة خطأ عامة. انظر رسالة الخطأ للحصول على تفاصيل إضافية. يجب تجنب اسم الخطأ هذا، لصالح اسم خطأ أكثر تعبيرًا.

مضاف في الإصدار 223.

SD_BUS_ERROR_NO_MEMORY

فشل في تخصيص الذاكرة، ولم يتمكن من إكمال العملية المطلوبة.

مضاف في الإصدار 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

خدمة الناقل التي تم الاتصال بها غير معروفة ولا يمكن تفعيلها.

مضاف في الإصدار 223.

مضاف في الإصدار 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
