sd_bus_get_property_strv(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

الاسم

sd_bus_set_property, sd_bus_set_propertyv, sd_bus_get_property, sd_bus_get_property_trivial, sd_bus_get_property_string, sd_bus_get_property_strv - تعيين أو الاستعلام عن خصائص خدمة D-Bus

المُلَخَّص

#include <systemd/sd-bus.h>

int sd_bus_set_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, ...);

int sd_bus_set_propertyv(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, const char *type, va_list ap);

int sd_bus_get_property(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, sd_bus_message **reply, const char *type);

int sd_bus_get_property_trivial(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char type, void *ret_ptr);

int sd_bus_get_property_string(sd_bus *bus, const char *destination, const char *path, const char *interface, const char *member, sd_bus_error *ret_error, char **ret);

الوصف

تقوم هذه الدوال بتعيين أو الاستعلام عن خصائص D-Bus. خصائص D-Bus هي حقول خدمة مكشوفة عبر الواجهة org.freedesktop.DBus.Properties. بشكل أساسي، تستدعي هذه الدوال طرق الواجهة org.freedesktop.DBus.Properties ونتيجة لذلك تكون دلالاتها مشابهة لـ sd_bus_call_method(3).

sd_bus_set_property() تقوم بتعيين خاصية D-Bus. إذا فشل تعيين الخاصية أو حدث خطأ داخلي، يتم إرجاع خطأ ووصف موسع للخطأ يتم تخزينه اختياريًا في ret_error إذا لم يكن NULL. type والحجج التي تليه تصف القيمة الجديدة للخاصية ويجب أن تتبع التنسيق الموصوف في sd_bus_message_append(3).

sd_bus_set_propertyv() يعادل sd_bus_set_property()، باستثناء أنه يتم استدعاؤه مع "va_list" بدلاً من عدد متغير من الحجج.

sd_bus_get_property() يستعلم عن خاصية D-Bus. إذا فشل استرداد الخاصية أو حدث خطأ داخلي، يتم إرجاع خطأ ووصف موسع للخطأ يتم تخزينه اختياريًا في ret_error إذا لم يكن NULL. عند النجاح، يتم تخزين الخاصية في reply. type يصف نوع الخاصية ويجب أن يتبع التنسيق الموصوف في sd_bus_message_append(3).

sd_bus_get_property_trivial()، sd_bus_get_property_string() و sd_bus_get_property_strv() هي اختصارات لـ sd_bus_get_property() تستخدم للاستعلام عن الخصائص الأساسية، والنصوص، ومتجهات النصوص على التوالي. يكون المتصل مسؤولاً عن تحرير نتائج النص ومتجهات النصوص المخزنة في ret بواسطة sd_bus_get_property_string() و sd_bus_get_property_strv().

قيمة الإرجاع

عند النجاح، ترجع هذه الدوال عددًا صحيحًا غير سالب. عند الفشل، ترجع رمز خطأ سالب من نوع errno.

الأخطاء

انظر صفحة الدليل sd_bus_call_method(3) لقائمة الأخطاء المحتملة.

ملاحظات

الدوال الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها ضدها وربطها مع ملف libsystemd pkg-config(1).

الكود الموصوف هنا يستخدم getenv(3)، والذي تم الإعلان عنه بأنه ليس آمنًا للاستخدام مع تعدد الخيوط. هذا يعني أن الكود الذي يستدعي الدوال الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط موازٍ. يوصى بإجراء استدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم تبدأ خيوط أخرى بعد.
