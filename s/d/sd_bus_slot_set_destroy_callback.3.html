sd_bus_slot_set_destroy_callback(3)

الحزمة: systemd-libs

التراخيص: LGPL-2.1-or-later, CC0-1.0, GPL-2.0-or-later WITH Linux-syscall-note

SD_BUS_SLOT_SET_DESTROY_CALLBACK(3) sd_bus_slot_set_destroy_callback SD_BUS_SLOT_SET_DESTROY_CALLBACK(3)

الاسم

sd_bus_slot_set_destroy_callback، sd_bus_slot_get_destroy_callback، sd_bus_track_set_destroy_callback، sd_bus_track_get_destroy_callback، sd_bus_destroy_t - تحديد دالة الاستدعاء للأغراض التنظيف الخاصة بالموارد

الملخص

#include <systemd/sd-bus.h>

typedef int (*sd_bus_destroy_t)(void *userdata);

int sd_bus_slot_set_destroy_callback(sd_bus_slot *slot, sd_bus_destroy_t callback);

int sd_bus_slot_get_destroy_callback(sd_bus_slot *slot, sd_bus_destroy_t *callback);

int sd_bus_track_set_destroy_callback(sd_bus_track *track, sd_bus_destroy_t callback);

int sd_bus_track_get_destroy_callback(sd_bus_track *track, sd_bus_destroy_t *callback);

الوصف

sd_bus_slot_set_destroy_callback() تضبط callback كدالة استدعاء يتم استدعاؤها مباشرة قبل إلغاء تخصيص كائن فتحة الناقل slot. سيتم تمرير المؤشر userdata من كائن الفتحة كمعلمة userdata. يمكن تعيين هذا المؤشر بواسطة وسيطة لدوال البناء، راجع sd_bus_add_match(3)، أو مباشرة، راجع sd_bus_slot_set_userdata(3). يتم استدعاء دالة الاستدعاء هذه حتى إذا كان userdata هو NULL. لاحظ أنه يتم استدعاء دالة الاستدعاء هذه في وقت يكون فيه كائن فتحة الناقل نفسه قد تم إبطاله بالفعل، ولا يُسمح بتنفيذ عمليات أو أخذ مراجع جديدة لكائن فتحة الناقل.

sd_bus_slot_get_destroy_callback() تعيد الاستدعاء الحالي لـ slot في معلمة callback.

sd_bus_track_set_destroy_callback() و sd_bus_track_get_destroy_callback() توفران وظائف مكافئة لمؤشر userdata المرتبط بكائنات تتبع نظير الناقل. للتفاصيل حول كائنات تتبع نظير الناقل، راجع sd_bus_track_new(3).

قيمة الإرجاع

عند النجاح، تعيد sd_bus_slot_set_destroy_callback() و sd_bus_track_set_destroy_callback() القيمة 0 أو عددًا صحيحًا موجبًا. عند الفشل، تعيد رمز خطأ سالبًا بأسلوب errno.

sd_bus_slot_get_destroy_callback() و sd_bus_track_get_destroy_callback() تعيدان قيمة موجبة إذا تم تعيين دالة الاستدعاء للإتلاف، و 0 إذا لم يتم تعيينها. عند الفشل، تعيدان رمز خطأ سالبًا بأسلوب errno.

الأخطاء

قد تشير الأخطاء التي تم إرجاعها إلى المشاكل التالية:

-EINVAL

المعلمة slot أو track هي NULL.

ملاحظات

الوظائف الموصوفة هنا متاحة كمكتبة مشتركة، والتي يمكن تجميعها مع ملف pkg-config(1) الخاص بـ libsystemd وربطها به.

الكود الموصوف هنا يستخدم getenv(3)، والتي تم الإعلان عنها على أنها ليست آمنة للاستدعاء من خيوط متعددة. هذا يعني أن الكود الذي يستدعي الوظائف الموصوفة هنا يجب ألا يستدعي setenv(3) من خيط متوازي. يوصى بالقيام باستدعاءات لـ setenv() فقط من مرحلة مبكرة من البرنامج عندما لم يتم بدء أي خيوط أخرى.
