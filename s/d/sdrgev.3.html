SDRGEV

الغرض:

!>
!> SDRGEV يتحقق من روتين القيادة لمسألة القيم الذاتية المعممة غير المتناظرة SGGEV.
!>
!> SGGEV يحسب للزوج من المصفوفات غير المتناظرة بحجم n × n (A,B) القيم الذاتية المعممة، وبشكل اختياري، المتجهات الذاتية اليسرى واليمنى.
!>
!> القيمة الذاتية المعممة لزوج من المصفوفات (A,B) هي قيمة قياسية w أو نسبة alpha/beta = w، بحيث يكون A - w*B منفرداً. وهي
!> تمثل عادة بالزوج (alpha,beta)، حيث يوجد تفسير معقول لـ beta=0، وحتى لكلا القيمتين صفرًا.
!>
!> المتجه الذاتي المعممي الأيمن المقابل للقيمة الذاتية المعممة w لزوج من المصفوفات (A,B) هو متجه r بحيث
!> (A - wB) * r = 0. المتجه الذاتي المعممي الأيسر هو متجه l بحيث
!> l**H * (A - wB) = 0، حيث l**H هو المرافق المتطابق لـ l.
!>
!> عندما يتم استدعاء SDRGEV، يتم تحديد عدد من حجم المصفوفات () و
!> عدد من أنواع المصفوفات (). لكل حجم ()
!> ولكل نوع مصفوفة، سيتم إنشاء زوج من المصفوفات (A, B) واستخدامه للاختبار. لكل زوج مصفوفات، سيتم إجراء الاختبارات التالية
!> ومقارنتها بالعتبة THRESH.
!>
!> النتائج من SGGEV:
!>
!> (1) الحد الأقصى على جميع أزواج القيم الذاتية/المتجهات الذاتية اليسرى (alpha/beta,l) لـ
!>
!> | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!> حيث VL**H هو المرافق المتطابق لـ VL.
!>
!> (2) | |VL(i)| - 1 | / ulp وهل أكبر مكون حقيقي
!>
!> VL(i) يشير إلى العمود i من VL.
!>
!> (3) الحد الأقصى على جميع أزواج القيم الذاتية/المتجهات الذاتية اليسرى (alpha/beta,r) لـ
!>
!> | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4) | |VR(i)| - 1 | / ulp وهل أكبر مكون حقيقي
!>
!> VR(i) يشير إلى العمود i من VR.
!>
!> (5) W(full) = W(partial)
!> W(full) يشير إلى القيم الذاتية المحسوبة عندما يتم حساب كل من l و r أيضًا، و W(partial) يشير إلى النتائج
!> المحسوبة عندما يتم حساب W فقط، أو W و r فقط، أو W و l فقط.
!>
!> (6) VL(full) = VL(partial)
!> VL(full) يشير إلى المتجهات الذاتية اليسرى المحسوبة عندما يتم حساب كل من l و r، و VL(partial) يشير إلى النتائج
!> المحسوبة عندما يتم حساب l فقط.
!>
!> (7) VR(full) = VR(partial)
!> VR(full) يشير إلى المتجهات الذاتية اليمنى المحسوبة عندما يتم حساب كل من l و r أيضًا، و VR(partial) يشير إلى النتائج
!> المحسوبة عندما يتم حساب l فقط.
!>
!>
!> مصفوفات الاختبار
!> ---- --------
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد أنواع المصفوفات بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كان DOTYPE(j) يساوي .TRUE.، فسيتم إنشاء نوع المصفوفة j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1) ( 0, 0 ) (زوج من المصفوفات الصفرية)
!>
!> (2) ( I, 0 ) (مصفوفة هوية ومصفوفة صفرية)
!>
!> (3) ( 0, I ) (مصفوفة صفرية ومصفوفة هوية)
!>
!> (4) ( I, I ) (زوج من مصفوفات الهوية)
!>
!> t t
!> (5) ( J , J ) (زوج من كتل جوردان المنقولة)
!>
!> ( I 0 )
!> (6) ( X, Y ) حيث X = ( J 0 ) و Y = ( t )
!> ( 0 I ) ( 0 J )
!> و I هي مصفوفة هوية بحجم k x k و J كتلة جوردان بحجم (k+1)x(k+1)
!> k=(N-1)/2
!>
!> (7) ( D, I ) حيث D هي مصفوفة قطرية diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!> بهذه الإدخالات القطرية.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) حيث big قريب من الفائض و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!> D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!> t t
!> (16) Q ( J , J ) Z حيث Q و Z مصفوفتان متعامدتان عشوائيتان.
!>
!> (17) Q ( T1, T2 ) Z حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!> بإدخالات عشوائية O(1) فوق القطر الرئيسي
!> والإدخالات القطرية diag(T1) =
!> ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!> ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!> diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!> s = دقة الجهاز.
!>
!> (19) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!> N-5
!> (20) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, 1, a, ..., a =s, 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!> حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z حيث T1 و T2 مصفوفتان مثلثيتان علويتان عشوائيتان.
!>
!>

المعلمات

NSIZES 
!>          NSIZES is INTEGER
!>          عدد أحجام المصفوفات المراد استخدامها. إذا كان صفرًا،
!>          فإن SDRGES لا يفعل شيئًا. NSIZES >= 0.
!>

NN

!>          NN is INTEGER array, dimension (NSIZES)
!>          مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
!>          سيتم تخطي القيم الصفرية. NN >= 0.
!>

NTYPES

!>          NTYPES is INTEGER
!>          عدد العناصر في DOTYPE. إذا كان صفرًا، فإن SDRGES
!>          لا يفعل شيئًا.
