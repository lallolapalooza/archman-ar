الوصف

بالإضافة إلى أسماء الأخطاء التي تحددها البرامج المستخدمة، يعرف D-Bus قائمة بالأخطاء القياسية والعامة مدرجة أدناه.

بالإضافة إلى هذه القائمة، في sd-bus، يتم استخدام مساحة الخطأ الخاصة "System.Error" لربط أخطاء نظام Linux (المحددة بواسطة errno(3)) بأخطاء D-Bus والعكس صحيح. على سبيل المثال، يتم ربط الخطأ EUCLEAN بـ "System.Error.EUCLEAN" والعكس صحيح.

SD_BUS_ERROR_FAILED

مؤشر عام للخطأ. راجع رسالة الخطأ للحصول على تفاصيل إضافية. يجب تجنب اسم الخطأ هذا، لصالح اسم خطأ أكثر تعبيرًا.

تمت الإضافة في الإصدار 223.

SD_BUS_ERROR_NO_MEMORY

فشل في تخصيص الذاكرة، ولا يمكن إكمال العملية المطلوبة.

تمت الإضافة في الإصدار 223.

SD_BUS_ERROR_SERVICE_UNKNOWN

This is usually returned by method calls supporting a framework for additional interactive authorization, when interactive authorization was not enabled with the sd_bus_message_set_allow_interactive_authorization(3) for the method call message.

Added in version 223.

NOTES

Functions described here are available as a shared library, which can be compiled against and linked to with the libsystemd pkg-config(1) file.

The code described here uses getenv(3), which is declared to be not multi-thread-safe. This means that the code calling the functions described here must not call setenv(3) from a parallel thread. It is recommended to only do calls to setenv() from an early phase of the program when no other threads have been started.
