NAME

swapon, swapoff - enable and disable devices and files for paging and swapping

SYNOPSIS

swapon [options] [-a | -d | -s]
swapon [options] specialfile...
swapon [options] -p [priority] specialfile...

swapoff [options] [-a | -d | -s]
swapoff [options] specialfile...

DESCRIPTION

The swapon utility causes the system to start paging and swapping on the specified devices or files. The swapoff utility causes the system to stop paging and swapping on the specified devices or files.

The -a option is used to enable all devices or disable all devices. The argument may be separated by white spaces. The argument for swapon is the name of the swap device or file. For swapoff, it is the name of the device or file to disable.

The swap space is treated as a sequence of blocks. The size of these blocks is specified by the SWAP_BLOCK_SIZE constant in the kernel.

When a new swap file is created with mkswap, it is initialized with a signature that identifies it as swap space. This signature is also written to the swap partition.

The -s option displays the current swap space usage in a tabular format. The -d option indicates that the argument is a device to be disabled.

The -p option sets the priority of the swap device or file. Higher numbers indicate higher priority. If not specified, the default priority is -1.

OPTIONS

The following options are available for both swapon and swapoff:

-a, --all
All of the file systems specified in /etc/fstab will be mounted or unmounted. Only those marked with the type swap will be acted upon.
-d, --discard[=when]
Enable or disable discard operation for the swap device. The discard operation is an operation that informs the underlying storage device that certain blocks are no longer in use and may be freed. This is typically used for SSDs and thinly provisioned storage. The optional argument when specifies when the discard operation should be performed. Possible values are once (perform discard once at swapon, default), max (perform discard as often as possible), once-lazy (perform discard once at swapon, but defer freeing blocks until later), and never (never perform discard). The default is once.
-e, --ifexists
Exit successfully if the swap device or file does not exist.
-h, --help
Display a help message and exit.
-p, --priority priority
Set the priority of the swap device or file. Higher numbers indicate higher priority. If not specified, the default priority is -1.
-s, --show
Show information about the current swap space usage in a tabular format. This option is available for both swapon and swapoff.
-v, --verbose
Be more verbose.
-V, --version
Display version information and exit.

The following options are only available for swapon:

-f, --fixpg/bsd
Fix the partition table if it is incorrect.
-N, --noheadings
Do not print a header line when using the -s option.
-t, --test
Test the swap device or file without actually enabling it.

EXIT STATUS

swapon and swapoff return 0 on success, and non-zero on failure.

ENVIRONMENT

The following environment variables are used by swapon and swapoff:

LIBBLKID_DEBUG=flags
Enable debugging output for the libblkid library.
LIBSMARTCOLS_DEBUG=flags
Enable debugging output for the libsmartcols library.

FILES

/etc/fstab
/proc/swaps

NOTES

NoCow

In version 2.41, the command mkswap --file can create a new swap file with the nocow attribute.

NFS

Swap over NFS may not work.

Suspend

swapon automatically detects and rewrites a swap space signature with old software suspend data (e.g., S1SUSPEND, S2SUSPEND, ...). The problem is that if we don’t do it, then we get data corruption the next time an attempt at unsuspending is made.

HISTORY

The swapon command appeared in 4.0BSD.
