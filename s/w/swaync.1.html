swaync(1)

الحزمة: swaync

التراخيص: GPL-3.0-only

swaync(1) دليل الأوامر العامة swaync(1)

الاسم

swaync - خادم إشعارات بسيط بواجهة رسومية GTK للإشعارات ومركز التحكم

الاستخدام

swaync [خيار]

الخيارات

-h, --help

عرض خيارات المساعدة

-v, --version

طباعة الإصدار

-s, --style <ملف CSS>

استخدام ملف ورقة أنماط مخصصة

--skip-system-css

تخطي محاولة تحليل ملف ورقة الأنماط المعبأة. مفيد لتصحيح أخطاء CSS

-c, --config <ملف الإعدادات>

استخدام ملف إعدادات مخصصة

اختصارات لوحة المفاتيح لمركز التحكم

الأعلى/الأسفل: التنقل بين الإشعارات

الصفحة الرئيسية: الانتقال إلى أحدث إشعار

نهاية: الانتقال إلى أقدم إشعار

Escape/Caps_Lock: إغلاق لوحة الإشعارات

Enter: تنفيذ الإجراء الافتراضي أو إغلاق الإشعار إذا لم يكن هناك إجراء

Delete/BackSpace: إغلاق الإشعار

Shift+C: إغلاق جميع الإشعارات

Shift+D: تبديل وضع "عدم الإزعاج"

الأزرار 1-9: تنفيذ إجراءات بديلة

النقر بزر الفأرة الأيسر / الإجراءات: تفعيل إجراء الإشعار

النقر بزر الفأرة الأوسط/الأيمن على الإشعار: إغلاق الإشعار

الإعدادات

يوجد ملف الإعدادات الرئيسي في /etc/xdg/swaync/config.json. انسخه إلى مجلد ~/.config/swaync/ الخاص بك للتخصيص دون الحاجة إلى صلاحيات الجذر.

لإعادة تحميل الإعدادات، ستحتاج إلى تشغيل swaync-client --reload-config

للحصول على معلومات حول تنسيق ملف الإعدادات، راجع swaync(5)

البرمجة النصية

قواعد ومنطق البرمجة النصية:

1.
يمكن تشغيل نص برمجي واحد فقط لكل إشعار
2.
يتطلب كل نص برمجي `exec` وواحد على الأقل من الخصائص الأخرى
3.
يجب أن تتطابق جميع الخصائص المدرجة مع الإشعار ليتم تشغيل النص البرمجي
4.
إذا لم تتطابق أي من الخصائص، سيتم تخطي النص البرمجي
5.
إذا كان الإشعار لا يتضمن أحد الخصائص، فسيتم تخطي ذلك الخاصية

يمكن طباعة معلومات الإشعار في طرفية عن طريق تشغيل G_MESSAGES_DEBUG=all swaync (عند ظهور إشعار).

خصائص الإعدادات:

{
	"scripts": {
		"example-script": {
			"exec": "أمر Shell أو النص البرمجي الخاص بك هنا...",
			"app-name": "اسم تطبيق الإشعار Regex",
			"summary": "ملخص الإشعار Regex",
			"body": "نص الإشعار Regex",
			"urgency": "منخفض أو عادي أو حرج",
			"category": "فئة الإشعار Regex"
		}
	}
	خصائص أخرى غير نصية...
}

مثال على config.json:

{
	"scripts": {
		// سيتم تشغيل هذا النص البرمجي فقط عندما يرسل Spotify إشعارًا يحتوي
		// على هذا الملخص والنص بالضبط
		"example-script": {
			"exec": "~/.config/swaync/myRickRollScript.sh",
			"app-name": "Spotify"
			"summary": "Never Gonna Give You Up",
			"body": "Rick Astley - Whenever You Need Somebody"
		}
	}
	خصائص أخرى غير نصية...
}

تعطيل البرمجة النصية

لتعطيل البرمجة النصية تمامًا، يجب بناء المشروع على النحو التالي:

meson build -Dscripting=false
ninja -C build
meson install -C build
