type: bool
default: true
description: Sends a notification if a script fails to run

scripts
type: object
script object properties:
exec
type: string
optional: false
description: The script to run. Can also run regular shell commands.
app-name
type: string
optional: true
description: The app-name. Uses Regex.
desktop-entry
type: string
optional: true
description: The desktop-entry. Uses Regex.
summary
type: string
optional: true
description: The summary of the notification. Uses Regex.
body
type: string
optional: true
description: The body of the notification. Uses Regex.
urgency
type: string
optional: true
default: Normal
values: Low, Normal, Critical
description: The urgency of the notification.
category
type: string
optional: true
description: Which category the notification belongs to. Uses Regex.
sound-file
type: string
optional: true
description: Which sound file the notification requested. Uses Regex.
sound-name
type: string
optional: true
des DESCRIPTION: اسم الصوت الذي طلب به الإشعار. يستخدم Regex.
run-on
type: string
optional: true
values: action, receive
default: receive
description: ما إذا كان سيتم تشغيل هذا الإجراء عند استلام الإشعار
أم عند اتخاذ إجراء عليه.
description: النصوص البرمجية التي يجب التحقق منها وتشغيلها بشكل محتمل لكل
إشعار. إذا كان الإشعار لا يتضمن أحد الخصائص،
سيتم تجاهل هذه الخاصية. جميع الخصائص (باستثناء exec) تستخدم regex.
إذا تطابقت جميع الخصائص مع الإشعار المعطى، فسيتم تشغيل النص البرمجي.
سيتم تشغيل النص البرمجي المطابق الأول فقط.
example:

{
	"scripts": {
		"example-script": {
			"exec": "أمر shell أو نص برمجي خاص بك هنا...",
			"app-name": "تطبيق اسم الإشعار Regex",
			"summary": "ملخص الإشعار Regex",
			"body": "نص الإشعار Regex",
			"urgency": "منخفض أو عادي أو حرج",
			"category": "فئة الإشعار Regex"
		}
	}
}
يمكنك أيضًا استخدام متغيرات البيئة هذه في النص البرمجي الخاص بك:
$SWAYNC_BODY="محتوى نص الإشعار"
$SWAYNC_DESKTOP_ENTRY="إدخال سطح المكتب"
$SWAYNC_URGENCY="إلحاح الإشعار"
$SWAYNC_TIME="وقت الإشعار"
$SWAYNC_APP_NAME="اسم تطبيق الإشعار"
$SWAYNC_CATEGORY="فئة إشعار SwayNC"
$SWAYNC_REPLACES_ID="معرف الإشعار المراد استبداله"
$SWAYNC_ID="معرف إشعار SwayNC"
$SWAYNC_SUMMARY="ملخص الإشعار"
$SWAYNC_HINT_[NAME]="قيمة التلميح [NAME]"
$SWAYNC_SOUND_NAME="اسم الصوت المطلوب"
$SWAYNC_SOUND_FILE="مسار ملف الصوت المطلوب"
