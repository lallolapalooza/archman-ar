NAME

swift - OpenStack Swift CLI

SYNOPSIS

swift [options] command [args]

DESCRIPTION

The swift command-line utility provides an interface to the OpenStack Swift object storage system. It allows users to interact with Swift by uploading, downloading, and managing objects and containers.

Before using the swift command, you need to configure your OpenStack credentials. This can be done by setting environment variables or by providing them directly on the command line.

COMMANDS

list
List containers or objects within a container.
stat
Display statistics for an account, container, or object.
upload
Upload a file or directory to a container.
download
Download a file or objects from a container.
delete
Delete a container or object.
post
Update metadata for an account, container, or object.
copy
Copy an object within Swift.
show
Display the content of an object.
tempurl
Generate a temporary URL for an object.
burnafterreadingurl
Generate a burn-after-reading URL for an object.
multi
Manage manifest for large objects.

OPTIONS

The swift command supports several options to configure authentication and connection settings:

-h, --help
Show this help message and exit.
-v, --version
Show program's version number and exit.
-d, --debug
Enable debug logging.
-f, --verbose
Enable verbose output.
-q, --quiet
Suppress output.
-A AUTH_URL, --os-auth-url AUTH_URL

Authentication URL. Defaults to $OS_AUTH_URL environment variable.

-R REGION, --os-region-name REGION

Region name. Defaults to $OS_REGION_NAME environment variable.

-U USER, --os-username USER

Username. Defaults to $OS_USERNAME environment variable.

-P PASSWORD, --os-password PASSWORD

Password. Defaults to $OS_PASSWORD environment variable.

-T TENANT, --os-tenant-name TENANT

Tenant name. Defaults to $OS_TENANT_NAME environment variable.

-I TENANT_ID, --os-tenant-id TENANT_ID

Tenant ID. Defaults to $OS_TENANT_ID environment variable.

-t TOKEN, --os-token TOKEN

Authentication token. Defaults to $OS_TOKEN environment variable.

-E ENDPOINT_TYPE, --os-endpoint-type ENDPOINT_TYPE

Endpoint type (e.g., 'public', 'internal', 'admin'). Defaults to $OS_ENDPOINT_TYPE environment variable.

--os-user-domain-name USER_DOMAIN_NAME

User domain name. Defaults to $OS_USER_DOMAIN_NAME environment variable.

--os-project-domain-name PROJECT_DOMAIN_NAME

Project domain name. Defaults to $OS_PROJECT_DOMAIN_NAME environment variable.

--insecure

Explicitly allow insecure SSL connections.

--cert-file CERT_FILE

Path to SSL certificate authority bundle.

--timeout TIMEOUT

Request timeout in seconds.

EXAMPLE

List account statistics:

swift -A https://127.0.0.1:443/auth/v1.0 -U swiftops:swiftops -K swiftops stat
