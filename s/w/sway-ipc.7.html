model string نموذج المخرج serial string الرقم التسلسلي للمخرج كسلسلة سداسية عشرية active boolean ما إذا كان هذا المخرج نشطًا / ممكّنًا dpms boolean (مهمل، استخدم power بدلاً من ذلك) ما إذا كان هذا المخرج قيد التشغيل / إيقاف التشغيل (عبر DPMS) power boolean ما إذا كان هذا المخرج قيد التشغيل / إيقاف التشغيل primary boolean لتوافق i3، سيكون هذا خطأ. ليس له معنى في Wayland scale float المقياس المستخدم حاليًا على المخرج أو -1 للمخارج المعطلة subpixel_hinting string التلميح الفرعي للبكسل المستخدم حاليًا على المخرج. يمكن أن يكون هذا rgb، bgr، vrgb، vbgr، أو none transform string التحويل المستخدم حاليًا للمخرج. يمكن أن يكون هذا normal، 90، 180، 270، flipped-90، flipped-180، أو flipped-270 current_workspace string مساحة العمل المرئية حاليًا على المخرج أو null للمخارج المعطلة modes array مصفوفة من كائنات الوضع المدعومة. يحتوي كل كائن على width و height و refresh current_mode object كائن يمثل الوضع الحالي الذي يحتوي على width و height و refresh rect object حدود المخرج التي تتكون من x و y و width و height

4. GET_TREE

MESSAGE
استرداد تمثيل JSON للشجرة

REPLY
مصفوفة من الكائنات التي تمثل الشجرة الحالية. يمثل كل كائن عقدة واحدة وسيكون له الخصائص التالية:

PROPERTY DATA TYPE DESCRIPTION
id integer المعرف الفريد الداخلي لهذه العقدة
name string اسم العقدة مثل اسم المخرج أو عنوان النافذة. بالنسبة لـ لوحة الإمساك (scratchpad)، سيكون هذا __i3_scratch للتوافق مع i3.
type string نوع العقدة. يمكن أن يكون root أو output أو workspace أو con أو floating_con
border string نمط الحدود للعقدة. يمكن أن يكون normal أو none أو pixel أو csd
current_border_width integer عدد البكسلات المستخدمة لعرض الحدود
layout string تخطيط العقدة. يمكن أن يكون إما splith أو splitv أو stacked أو tabbed أو output
orientation string اتجاه العقدة. يمكن أن يكون vertical أو horizontal أو none
percent float نسبة العقدة من الأب الذي تشغله أو null للجذر والعقد الخاصة الأخرى مثل لوحة الإمساك
rect object الهندسة المطلقة للعقدة. تستثنى زخارف النوافذ من هذا، ولكن يتم تضمين الحدود.
window_rect object هندسة المحتوى داخل العقدة. هذه الإحداثيات نسبية للعقدة نفسها. زخارف النوافذ والحدود خارج window_rect
deco_rect object هندسة الزخارف للعقدة نسبة إلى العقدة الأم
geometry object الهندسة الطبيعية للمحتويات إذا كان سيتم تغيير حجمها
urgent boolean ما إذا كانت العقدة أو أي من العقد الفرعية لها تلميح الإلحاح (urgent hint) معينًا. ملاحظة: قد لا يكون هذا موجودًا عند التجميع بدون دعم xwayland
sticky boolean ما إذا كانت العقدة ملتصقة (تظهر على جميع مساحات العمل)
marks array قائمة العلامات المعينة للعقدة
focused boolean ما إذا كانت العقدة في التركيز حاليًا بواسطة المقعد الافتراضي (seat0)
focus array مصفوفة من معرفات العقد الفرعية في ترتيب التركيز الحالي
nodes array العقد الفرعية المتجاورة للعقدة
floating_nodes array العقد العائمة الفرعية للعقدة
representation string (مساحات العمل فقط) تمثيل سلسلة نصية لتخطيط مساحة العمل يمكن استخدامه للمساعدة في تقديم خطوات إعادة إنتاج لتقارير الأخطاء
fullscreen_mode integer (الحاويات والنوافذ فقط) وضع ملء الشاشة للعقدة. 0 يعني لا شيء، 1 يعني مساحة عمل كاملة، و 2 يعني ملء الشاشة العالمي
floating string حالة العوم للحاوية. يمكن أن تكون إما "auto_off" أو "user_on"
scratchpad_state string ما إذا كانت النافذة في لوحة الإمساك. يمكن أن تكون إما "none" أو "fresh"
app_id string (النوافذ فقط) بالنسبة لنافذة xdg-shell، اسم التطبيق، إذا تم تعيينه. وإلا، null
pid integer (النوافذ فقط) معرف العملية (PID) للتطبيق الذي يمتلك النافذة
foreign_toplevel_identifier string (النوافذ فقط) معرف المستوى الأعلى ext-foreign-toplevel-list-v1 لهذه العقدة.
visible boolean (النوافذ فقط) ما إذا كانت العقدة مرئية
shell string (النوافذ فقط) shell النافذة، مثل xdg_shell أو xwayland
inhibit_idle boolean (النوافذ فقط) ما إذا كانت النافذة تمنع حالة الخمول
idle_inhibitors object (النوافذ فقط) كائن يحتوي على حالة مثبطات الخمول application و user. يمكن أن تكون application enabled أو none. يمكن أن تكون user focus أو fullscreen أو open أو visible أو none.
sandbox_engine string (النوافذ فقط) محرك sandbox المرتبط (أو null)
sandbox_app_id string (النوافذ فقط) معرف التطبيق الذي يوفره محرك sandbox المرتبط (أو null)
sandbox_instance_id string (النوافذ فقط) معرف المثيل الذي يوفره محرك sandbox المرتبط (أو null)
window integer (نوافذ xwayland فقط) معرف نافذة X11 لـ wi xwayland

6. GET_BARS

MESSAGE
Retrieve information about the bars.

REPLY
An array of objects, with each object representing a bar. The objects contain the following properties:

PROPERTY DATA TYPE DESCRIPTION
id string معرف الشريط
mode string وضع الشريط. يمكن أن يكون dock أو hide أو invisible
position string موضع الشريط. يمكن حاليًا أن يكون bottom أو top
status_command string الأمر الذي يجب تشغيله لتوليد سطر الحالة
font string الخط المراد استخدامه للنص الموجود على الشريط
workspace_buttons boolean ما إذا كان سيتم عرض أزرار مساحات العمل على الشريط
workspace_min_width integer الحد الأدنى للعرض بالبكسل لأزرار مساحات العمل على الشريط
binding_mode_indicator boolean ما إذا كان سيتم عرض وضع الربط الحالي على الشريط
verbose boolean للتوافق مع i3، ستكون هذه القيمة المنطقية false.
colors object كائن يحتوي على ألوان #RRGGBBAA المراد استخدامها للشريط. انظر أدناه لمزيد من المعلومات
gaps object كائن يمثل الفجوات للشريط يتكون من top و right و bottom و left.
bar_height integer الارتفاع المطلق للشريط أو 0 للتغيير التلقائي للحجم بناءً على الخط
status_padding integer الهامش الرأسي المراد استخدامه لسطر الحالة
status_edge_padding integer الهامش الأفقي المراد استخدامه لسطر الحالة عند نهاية الإخراج

يحتوي كائن الألوان على الخصائص التالية، وكلها سلاسل نصية تحتوي على تمثيل #RRGGBBAA للون:

PROPERTY DESCRIPTION
background اللون المراد استخدامه لخلفية الشريط في المخرجات غير المركزة
statusline اللون المراد استخدامه لنص سطر الحالة في المخرجات غير المركزة
separator اللون المراد استخدامه لنص الفاصل في المخرجات غير المركزة
focused_background اللون المراد استخدامه لخلفية الشريط في الإخراج المركز
focused_statusline اللون المراد استخدامه لنص سطر الحالة في الإخراج المركز
focused_separator اللون المراد استخدامه لنص الفاصل في الإخراج المركز
focused_workspace_text اللون المراد استخدامه لنص زر مساحة العمل المركز
focused_workspace_bg اللون المراد استخدامه لخلفية زر مساحة العمل المركز
focused_workspace_border اللون المراد استخدامه لحد زر مساحة العمل المركز
active_workspace_text اللون المراد استخدامه لنص أزرار مساحات العمل للمساحات المرئية في المخرجات غير المركزة
active_workspace_bg اللون المراد استخدامه لخلفية أزرار مساحات العمل للمساحات المرئية في المخرجات غير المركزة
active_workspace_border اللون المراد استخدامه لحد أزرار مساحات العمل للمساحات المرئية في المخرجات غير المركزة
inactive_workspace_text اللون المراد استخدامه لنص أزرار مساحات العمل للمساحات التي ليست مرئية
inactive_workspace_bg اللون المراد استخدامه لخلفية أزرار مساحات العمل للمساحات التي ليست مرئية
inactive_workspace_border اللون المراد استخدامه لحد أزرار مساحات العمل للمساحات التي ليست مرئية
urgent_workspace_text اللون المراد استخدامه لنص أزرار مساحات العمل للمساحات التي تحتوي على نافذة عاجلة
urgent_workspace_bg اللون المراد استخدامه لخلفية أزرار مساحات العمل للمساحات التي تحتوي على نافذة عاجلة
urgent_workspace_border اللون المراد استخدامه لحد أزرار مساحات العمل للمساحات التي تحتوي على نافذة عاجلة
binding_mode_text اللون المراد استخدامه لنص مؤشر وضع الربط
binding_mode_bg اللون المراد استخدامه لخلفية مؤشر وضع الربط
binding_mode_border اللون المراد استخدامه لحد مؤشر وضع الربط

7. GET_VERSION

MESSAGE
استرداد معلومات الإصدار عن عملية sway

REPLY
كائن يحتوي على الخصائص التالية:

PROPERTY DATA TYPE DESCRIPTION
major integer الإصدار الرئيسي لعملية sway
minor integer الإصدار الفرعي لعملية sway
patch integer إصدار التصحيح لعملية sway
human_readable string سلسلة نصية للإصدار قابلة للقراءة البشرية والتي من المحتمل أن تحتوي على معلومات أكثر فائدة مثل تجزئة الالتزام git القصيرة وفرع git
loaded_config_file_name string المسار إلى ملف التكوين المحمل

مثال للرد:

{
	"human_readable": "1.0-rc1-117-g2f7247e0 (Feb 24 2019, branch 'master')",
	"major": 1,
	"minor": 0,
	"patch": 0,
	"loaded_config_file_name": "/home/redsoxfan/.config/sway/config"
}

8. GET_BINDING_MODES

MESSAGE
استرداد قائمة أوضاع الربط التي تم تكوينها حاليًا

REPLY
مصفوفة من السلاسل النصية، حيث تكون كل سلسلة نصية اسم وضع ربط. ستتضمن هذه دائمًا وضعًا واحدًا على الأقل (حاليًا default)، وهو وضع الربط الافتراضي

مثال للرد:

[
	"default",
	"resize",
]

0x80000002. MODE

يتم إرساله كلما تغير وضع الربط. يتكون الحدث من كائن واحد له الخصائص التالية:

خاصية نوع البيانات وصف
change string وضع الربط الذي أصبح نشطًا
pango_markup boolean ما إذا كان يجب تحليل الوضع كعلامات Pango

حدث مثال:

{
	"change": "default",
	"pango_markup": false
}

urgent تغير حالة تلميح استعجال النافذة

0x80000004. BARCONFIG_UPDATE

يتم إرساله كلما تغير تكوين لشريط. الحدث مطابق لـ GET_BAR_CONFIG عندما يتم توفير معرف شريط كحمل. انظر 6. GET_BAR_CONFIG (مع حمولة) أعلاه لمزيد من المعلومات.

0x80000005. BINDING

يتم إرساله كلما تم تنفيذ ربط. الحدث هو كائن واحد مع الخصائص التالية:

خاصية نوع البيانات وصف
change string التغيير الذي حدث للربط. حاليًا سيكون هذا فقط run
command string الأمر المرتبط بالربط
event_state_mask array مصفوفة من السلاسل النصية التي تتوافق مع كل مفتاح تعديل للربط
input_code integer بالنسبة لرموز المفاتيح، هذا هو رمز المفتاح للربط. بالنسبة لربطات الماوس، هذا هو رقم زر X11، إذا كان هناك ما يعادله. في جميع الحالات الأخرى، سيكون هذا 0.
symbol string بالنسبة لرموز الربط، هذا هو رمز الربط للربط. بخلاف ذلك، سيكون هذا null
input_type string نوع الإدخال الذي أدى إلى تشغيل الربط. هذا إما keyboard أو mouse

حدث مثال:

{
	"change": "run",
	"binding": {
		"command": "workspace 2",
		"event_state_mask": [
			"Mod4"
		],
		"input_code": 0,
		"symbol": "2",
		"input_type": "keyboard"
	}
}

0x80000006. SHUTDOWN

يتم إرساله كلما كان IPC في وضع الإغلاق. الحدث هو كائن واحد مع الخاصية change، وهي سلسلة نصية تحتوي على سبب الإغلاق. حاليًا، القيمة الوحيدة لـ change هي exit، والتي يتم إصدارها عند خروج sway.

حدث مثال:

{
	"change": "exit"
}

0x80000007. TICK

يتم إرساله عند الاشتراك لأول مرة في أحداث tick أو بواسطة رسالة SEND_TICK. الحدث هو كائن واحد مع الخصائص التالية:

خاصية نوع البيانات وصف
first boolean ما إذا كان هذا الحدث قد تم تشغيله عن طريق الاشتراك في أحداث tick
payload string الحمولة المعطاة مع رسالة SEND_TICK، إذا وجدت. بخلاف ذلك، سلسلة فارغة

حدث مثال:

{
	"first": true,
	"payload": ""
}

0x80000014. BAR_STATE_UPDATE

يتم إرساله عند تغير رؤية شريط بسبب الضغط على مفتاح تعديل. الحدث هو كائن واحد مع الخصائص التالية:

خاصية نوع البيانات وصف
id string معرف الشريط المتأثر
visible_by_modifier boolean ما إذا كان يجب جعل الشريط مرئيًا بسبب الضغط على مفتاح تعديل

حدث مثال:

{
	"id": "bar-0",
	"visible_by_modifier": true
}

0x80000015. INPUT

خاصية نوع البيانات وصف
change string ما الذي تغير
input object كائن يمثل الإدخال وهو مطابق للكائنات التي يوفرها GET_INPUTS
