NAME

swaylock - screen locker for Wayland

SYNOPSIS

swaylock [options]

OPTIONS

The swaylock utility is a screen locker for Wayland. It supports various options to customize its appearance and behavior.

-h, --help
Show help message and exit.
-v, --version
Show version information and exit.
-c <color>, --color <color>
Set the background color. The color can be in hex format (e.g., #RRGGBB).
-i <image>, --image <image>
Set the background image. The image can be in various formats supported by the image loading library (e.g., PNG, JPEG).
-f, --once
Exit after the first successful authentication.
--daemonize
Fork into the background.
--disable-caps-lock-text
Disable the Caps Lock warning text.
--disable-num-lock-text
Disable the Num Lock warning text.
--disable-scroll-lock-text
Disable the Scroll Lock warning text.
--inside-padding <pixels>
Set the padding around the input field.
--ring-width <pixels>
Set the width of the input ring.
--line-width <pixels>
Set the width of the input line.
--key-increments <pixels>
Set the amount to increase/decrease the ring size on each key press.
--dots-visible
Show the dots for each character entered.
--separator-visible
Show the separator between the ring and the dots.
--text-color <color>
Set the color of the input text.
--text-unicode-locale <locale>
Set the locale for unicode input.
--input-text-color <color>
Set the color of the input text.
--text-verifying-color <color>
Set the color of the text while verifying the password.
--ring-color <color>
Set the color of the ring.
--line-color <color>
Set the color of the line.
--text-clear-color <color>
Set the color of the text when the input is cleared.
--text-delete-color <color>
Set the color of the text when a character is deleted.
--ring-verifying-color <color>
Set the color of the ring while verifying the password.
--inside-clear-color <color>
Set the color of the inside of the ring when the input is cleared.
--inside-verifying-color <color>
Set the color of the inside of the ring while verifying the password.
--fade-in-animation <ms>
Set the fade-in animation duration in milliseconds.
--fade-out-animation <ms>
Set the fade-out animation duration in milliseconds.
--grace-period <ms>
Set the grace period in milliseconds after which the password will be deleted.
--ring-bell
Ring the bell on authentication failure.
--tiling-scroll-direction <direction>
Set the scroll direction for tiling background images.

APPEARANCE

The appearance of swaylock can be customized using various options. You can set a solid background color using --color or a background image using --image. Further customization options include setting the padding, ring width, line width, dot visibility, and colors for different elements like the text, ring, and inside of the ring. Animations for fading in and out, as well as a grace period for password input, can also be configured.

SIGNALS

swaylock responds to the following signals:

SIGUSR1
Reloads the configuration.
SIGUSR2
Toggles between different background images or colors.
