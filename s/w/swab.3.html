swab(3) دليل وظائف المكتبة swab(3)

الاسم

swab - تبديل البايتات المتجاورة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#define _XOPEN_SOURCE       /* انظر feature_test_macros(7) */
#include <unistd.h>
void swab(ssize_t n;
          const void from[restrict n], void to[restrict n],
          ssize_t n);

الوصف

تقوم الدالة swab() بنسخ n بايت من المصفوفة التي يشير إليها from إلى المصفوفة التي يشير إليها to، مع تبديل البايتات الزوجية والفردية المتجاورة. تُستخدم هذه الدالة لتبادل البيانات بين الأجهزة التي لها ترتيب بايت مختلف (منخفض/مرتفع).

هذه الدالة لا تفعل شيئًا عندما تكون n سالبة. عندما تكون n موجبة وفردية، فإنها تعالج n-1 بايت كما هو مذكور أعلاه، وتقوم بشيء غير محدد مع البايت الأخير. (بمعنى آخر، يجب أن تكون n زوجية).

قيمة الإرجاع

الدالة swab() لا تُرجع أي قيمة.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).
