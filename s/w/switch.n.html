switch(n)

الحزمة: tcl

التراخيص: TCL

switch(n) أوامر Tcl المدمجة switch(n)

الاسم

switch - تقييم أحد النصوص البرمجية المتعددة، بناءً على قيمة معينة

الملخص

switch ?خيارات? السلسلة النصية النمط النص البرمجي ?النمط النص البرمجي ...؟

switch ?خيارات? السلسلة النصية {النمط النص البرمجي ?النمط النص البرمجي ...?}

الوصف

يقوم الأمر switch بمطابقة الوسيط السلسلة النصية الخاص به مع كل وسيط نمط بالترتيب. بمجرد العثور على نمط يطابق السلسلة النصية، فإنه يقوم بتقييم وسيط النص البرمجي التالي عن طريق تمريره بشكل تكراري إلى مترجم Tcl وإرجاع نتيجة هذا التقييم. إذا كان آخر وسيط نمط هو default (افتراضي) فإنه يطابق أي شيء. إذا لم يطابق أي وسيط نمط السلسلة النصية ولم يتم تقديم قيمة افتراضية، فإن الأمر switch يُرجع سلسلة نصية فارغة.

إذا بدأت الوسائط الأولية للأمر switch بـ -، فسيتم التعامل معها كخيارات ما لم يكن هناك وسيطان بالضبط للأمر switch (في هذه الحالة، يجب أن يكون الأول هو السلسلة النصية والثاني هو قائمة النمط/النص البرمجي). الخيارات التالية مدعومة حاليًا:

-exact
استخدم المطابقة التامة عند مقارنة السلسلة النصية بنمط. هذا هو الافتراضي.
-glob
عند مطابقة السلسلة النصية مع الأنماط، استخدم المطابقة بنمط glob (أي نفس المطابقة التي ينفذها الأمر string match).
-regexp
عند مطابقة السلسلة النصية مع الأنماط، استخدم مطابقة التعبيرات العادية (كما هو موضح في صفحة مرجع re_syntax).
-nocase
يجعل المقارنات تُعامل بطريقة غير حساسة لحالة الأحرف.
-matchvar اسم_المتغير
هذا الخيار (قانوني فقط عند تحديد -regexp أيضًا) يحدد اسم متغير ستُكتب فيه قائمة المطابقات التي وجدها محرك التعبيرات العادية. العنصر الأول في القائمة المكتوبة سيكون السلسلة الفرعية الكلية للنص المدخل (أي وسيط السلسلة النصية للأمر switch) المطابقة، والعنصر الثاني في القائمة سيكون السلسلة الفرعية المطابقة لقوس الالتقاط الأول في التعبير العادي الذي تطابق، وهكذا. عند اتباع فرع default (افتراضي)، سيكون المتغير لديه قائمة فارغة مكتوبة فيه. يمكن تحديد هذا الخيار في نفس الوقت مع الخيار -indexvar.
-indexvar اسم_المتغير
هذا الخيار (قانوني فقط عند تحديد -regexp أيضًا) يحدد اسم متغير ستُكتب فيه قائمة الفهارس التي تشير إلى السلاسل الفرعية المطابقة التي وجدها محرك التعبيرات العادية. العنصر الأول في القائمة المكتوبة سيكون قائمة ذات عنصرين تحدد فهرس البداية وفهرس الحرف الأول بعد نهاية السلسلة الفرعية الكلية للنص المدخل (أي وسيط السلسلة النصية للأمر switch) المطابقة، بطريقة مشابهة لـ -indices الخيار للأمر regexp يمكن الحصول عليه. وبالمثل، يشير العنصر الثاني في القائمة إلى قوس الالتقاط الأول في التعبير العادي الذي تطابق، وهكذا. عند اتباع فرع default (افتراضي)، سيكون المتغير لديه قائمة فارغة مكتوبة فيه. يمكن تحديد هذا الخيار في نفس الوقت مع الخيار -matchvar.
--
يمثل نهاية الخيارات. سيتم التعامل مع الوسيط التالي لهذا مع أنه سلسلة نصية حتى لو بدأ بـ -. هذا ليس مطلوبًا عندما تكون أنماط المطابقة والنصوص البرمجية مجمعة معًا في وسيط واحد.

يتم توفير صيغتين للوسائط النمط و النص البرمجي. الأولى تستخدم وسيطًا منفصلاً لكل نمط وأمر؛ هذا الشكل مريح إذا كانت هناك حاجة إلى بدائل على بعض الأنماط أو الأوامر. الشكل الثاني يضع جميع الأنماط والأوامر معًا في وسيط واحد؛ يجب أن يكون الوسيط لديه بنية قائمة صحيحة، مع كون عناصر القائمة هي الأنماط والأوامر. الشكل الثاني يجعل من السهل بناء أوامر switch متعددة الأسطر، نظرًا لأن الأقواس حول القائمة بأكملها تجعل من غير الضروري تضمين شرطة مائلة عكسية في نهاية كل سطر. نظرًا لأن وسائط النمط موجودة في أقواس في الشكل الثاني، لا يتم إجراء أي استبدالات للأوامر أو المتغيرات عليها؛ هذا يجعل سلوك الشكل الثاني مختلفًا عن الشكل الأول في بعض الحالات.

إذا تم تحديد النص البرمجي كـ “-” فهذا يعني أن النص البرمجي للنمط التالي يجب استخدامه أيضًا كنص برمجي لهذا النمط (إذا كان النمط التالي لديه أيضًا نص برمجي لـ “-”، فسيتم استخدام النص البرمجي الذي يليه، وهكذا). هذه الميزة تجعل من الممكن مشاركة نص برمجي واحد بين عدة أنماط.

كن حذرًا بشأن كيفية وضع التعليقات في أوامر switch. يجب وضع التعليقات فقط داخل جسم التنفيذ لأحد الأنماط، وليس متداخلة مع الأنماط.

أمثلة

يمكن للأمر switch المطابقة مع المتغيرات وليس فقط القيم الحرفية، كما هو موضح هنا (النتيجة هي 2):

set foo "abc"
switch abc a - b {expr {1}} $foo {expr {2}} default {expr {3}}

استخدام مطابقة glob وجسم السقوط هو بديل لكتابة التعبيرات العادية مع البدائل، كما يمكن رؤيته هنا (هذا يُرجع 1):

switch -glob aaab {
    a*b     -
    b       {expr {1}}
    a*      {expr {2}}
    default {expr {3}}
}

عندما لا تتطابق أي شيء، يتم اتباع عبارة default (التي يجب أن تكون الأخيرة). هذا المثال لديه نتيجة 3:

switch xyz {
    a -
    b {
        # وضع تعليق صحيح
        expr {1}
    }
    c {
        expr {2}
    }
    default {
        expr {3}
    }
}

عند المطابقة مع التعبيرات العادية، يمكن الحصول بسهولة على معلومات حول ما تم مطابقته بالضبط باستخدام الخيار -matchvar:

switch -regexp -matchvar foo -- $bar {
    a(b*)c {
        puts "Found [string length [lindex $foo 1]] 'b's"
    }
    d(e*)f(g*)h {
        puts "Found [string length [lindex $foo 1]] 'e's and\
                [string length [lindex $foo 2]] 'g's"
    }
}
