وصف

تقع الوظائف التي تتعامل مع روابط المتغيرات في أربع مجموعات - تتعامل مع إنشاء، ضبط القيم، إخراج وحذف روابط المتغيرات.

إنشاء

snmp_pdu_add_variable ستنشئ بنية ربط متغير جديدة، مهيأة بالاسم ( objid, objidlen )، الصيغة ( type ) والقيمة ( value , len ) المقدمة. ثم يتم إضافة ربط المتغير هذا إلى نهاية قائمة روابط المتغيرات في PDU المحدد.

snmp_varlist_add_variable مماثلة، لكنها تلحق ربط المتغير الجديد بنهاية قائمة روابط المتغيرات المقدمة. عند إضافة ربط المتغير الأول إلى قائمة فارغة، قم ببساطة بتمرير عنوان رأس القائمة:


netsnmp_variable_list *vl = NULL;
snmp_varlist_add_variable(
&vl, name1, name1_len,
ASN_TYPE, &val1, val1_len);
snmp_varlist_add_variable(
&vl, name2, name2_len,
ASN_TYPE, &val2, val2_len);

في كلتا الحالتين، ستعيد الروتين مؤشرًا إلى بنية ربط المتغير الجديدة (أو NULL إذا فشل إنشاء ربط المتغير).

snmp_add_null_var هي وظيفة مساعدة لإضافة ربط متغير فارغ إلى PDU. دون الحاجة إلى تحديد قيمة NULL صراحةً. هذه هي الآلية العادية لبناء طلب استرجاع معلومات GET (أو ما شابه).
مرة أخرى، هذه تعيد مؤشرًا إلى ربط المتغير الجديد، أو NULL.

snmp_clone_varbind تنشئ نسخة من كل ربط متغير في القائمة المحددة، وتعيد مؤشرًا إلى رأس القائمة الجديدة (أو NULL إذا فشل النسخ).

ضبط القيم

snmp_set_var_objid تضبط اسم بنية ربط المتغير إلى OID المحدد.
snmp_set_var_typed_value تضبط نوع الصيغة وقيمة بنية ربط المتغير.
snmp_set_var_value تضبط قيمة بنية ربط المتغير، مع ترك نوع الصيغة دون تغيير.
snmp_set_var_typed_integer هي وظيفة مساعدة لضبط نوع الصيغة والقيمة لربط متغير قائم على عدد صحيح 32 بت.

جميع هذه الأربعة تعيد 0 إذا كان التعيين ناجحًا، أو 1 إذا لم يكن كذلك.

إخراج

print_variable ستأخذ معرف كائن (كما تم إرجاعه بواسطة read_objid، snmp_parse_oid أو get_module_node) ومثيل متغير من هذا القبيل، وتطبع إلى المخرج القياسي الشكل النصي لمعرف الكائن جنبًا إلى جنب مع قيمة المتغير.

fprint_variable تفعل الشيء نفسه، ولكنها تطبع إلى مؤشر FILE المحدد بواسطة المعلمة الأولية.

snprint_variable تطبع نفس المعلومات في المخزن المؤقت الذي يشير إليه buf والذي طوله len. إنها تعيد عدد الأحرف المطبوعة، أو -1 إذا لم يكن المخزن المؤقت كبيرًا بما فيه الكفاية. في الحالة الأخيرة، سيحتوي buf عادةً على نسخة مقتطعة من المعلومات (ولكن هذا السلوك غير مضمون). تستبدل هذه الوظيفة الوظيفة المهملة sprint_variable.

print_value، fprint_value، و snprint_value تفعل نفس الشيء مثل إجراءات print_variable المكافئة، ولكنها تعرض فقط قيمة المتغير، دون معرف الكائن المقابل.

لعرض OID لربط متغير، راجع netsnmp_mib_api(3).

حذف

snmp_free_var تحرر كل الذاكرة المستخدمة بواسطة بنية ربط المتغير المعطاة.
snmp_free_varbind تحرر كل الذاكرة المستخدمة بواسطة كل بنية ربط متغير في قائمة روابط المتغيرات المقدمة.
