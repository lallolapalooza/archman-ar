snmptest(1)

الحزمة: net-snmp

التراخيص: BSD

SNMPTEST(1) Net-SNMP SNMPTEST(1)

الاسم

snmptest - يتواصل مع كيان شبكة باستخدام طلبات SNMP

الملخص

snmptest [خيارات مشتركة] AGENT

الوصف

snmptest هو تطبيق SNMP مرن يمكنه مراقبة وإدارة المعلومات على كيان شبكة.

بعد استدعاء البرنامج، ينتقل مفسر سطر الأوامر إلى قبول الأوامر. يتيح هذا المفسر للمستخدم إرسال أنواع مختلفة من طلبات SNMP إلى العملاء المستهدفين.

يحدد AGENT عميل SNMP مستهدف، والذي يتم تجهيزه لمراقبة الكائنات المحددة. في أبسط صوره، سيتكون تحديد AGENT من اسم مضيف أو عنوان IPv4. في هذه الحالة، ستحاول الأوامر الاتصال بالعميل، باستخدام UDP/IPv4 إلى المنفذ 161 للمضيف المحدد. انظر snmpcmd(1) للحصول على قائمة كاملة بالتنسيقات الممكنة لـ AGENT.

بمجرد استدعاء snmptest، سيطلب مفسر سطر الأوامر:

متغير:

في هذه المرحلة، يمكنك إدخال اسم متغير واحد أو أكثر، سطرًا واحدًا لكل سطر. يؤدي السطر الفارغ إلى إنهاء إدخال المعلمات وسيرسل الطلب (المتغيرات المدخلة) في حزمة واحدة، إلى الكيان البعيد. يتم إعطاء كل اسم متغير بالتنسيق المحدد في variables(5). على سبيل المثال:

snmptest -c public -v 1 zeus
متغير: system.sysDescr.0
متغير:

سيؤدي ذلك إلى إرجاع بعض المعلومات حول حزم الطلب والاستجابة، بالإضافة إلى المعلومات:

requestid 0x5992478A errstat 0x0 errindex 0x0
system.sysDescr.0 = STRING: "Unix 4.3BSD"

يوضح رمز حالة الخطأ قيمة حالة الخطأ للمكالمة. توجد القيم الممكنة لـ errstat في الملف الرأسي snmp.h. يحدد قيمة errindex المتغير الذي يحمل الخطأ المحدد. يتم تعيين قيم الفهرس لجميع المتغيرات المدخلة عند موجه "متغير:". يتم تعيين القيمة الأولى بفهرس 1.

عند بدء التشغيل، تفترض الأداة إرسال حزمة طلب GET. يمكن تغيير نوع الطلب عن طريق كتابة أحد الأوامر التالية عند موجه "متغير:":

$G - إرسال طلب GET
$N - إرسال طلب GETNEXT
$S - إرسال طلب SET
$B - إرسال طلب GETBULK
     ملاحظة: GETBULK غير متوفر في SNMPv1
$I - إرسال طلب Inform
$T - إرسال طلب SNMPv2 Trap

القيم الأخرى التي يمكن إدخالها عند موجه "متغير:" هي:

$D - تبديل تفريغ كل حزمة مرسلة ومستلمة
$QP - تبديل شكل إخراج أسرع وأقل تفصيلاً
$Q - إنهاء البرنامج

أنواع الطلبات:

طلب GET:

عندما تكون في وضع "طلب GET" ($G أو افتراضي)، يمكن للمستخدم إدخال OID عند موجه "متغير:". يمكن للمستخدم إدخال OIDs متعددة، واحدة لكل موجه. يدخل المستخدم سطرًا فارغًا لإرسال طلب GET.

طلب GETNEXT:

وضع "طلب GETNEXT" ($N) مشابه لوضع "طلب Get"، الموضح أعلاه.

طلب SET:

عندما تكون في وضع "طلب SET" ($S)، يتم طلب المزيد من المعلومات بواسطة الموجه لكل متغير. الموجه:

النوع [i|s|x|d|n|o|t|a]:
يطلب نوع المتغير المراد إدخاله. اعتمادًا على نوع القيمة التي تريد تعيينها، يمكنك كتابة أحد الخيارات التالية: 
i - عدد صحيح
u - عدد صحيح غير موقع
s - سلسلة بايتات بصيغة ASCII
x - سلسلة بايتات بصيغة hex، مفصولة بمسافات
d - سلسلة بايتات بصيغة decimal، مفصولة بمسافات
a - عنوان IP بتنسيق IP النقطي
o - معرف الكائن
n - null
t - timeticks
في هذه المرحلة سيتم طلب قيمة:

القيمة:

إذا كانت قيمة عدد صحيح، فما عليك سوى كتابة العدد الصحيح (بالنظام العشري). إذا كانت سلسلة عشرية، فاكتب أرقامًا عشرية مفصولة بمسافات بيضاء، واحدة لكل بايت من السلسلة. مرة أخرى، اكتب سطرًا فارغًا عند الموجه لاسم المتغير لإرسال الحزمة.

طلب GETBULK:

وضع "طلب GETBULK" ($B) مشابه لوضع "طلب Set". ومع ذلك، فإن GETBULK غير متوفر في SNMPv1.

طلب Inform:

وضع "طلب Inform" ($I) مشابه لوضع "طلب Set". ومع ذلك، فإن هذا النوع من الطلبات غير متوفر في SNMPv1. أيضًا، يجب أن يتوافق _العميل_ المحدد في أمر snmptest مع عميل snmptrapd المستهدف.

طلب SNMPv2 Trap:

وضع "طلب SNMPv2 Trap" ($T) مشابه لوضع "طلب Set". ومع ذلك، فإن هذا النوع من الطلبات غير متوفر في SNMPv1. أيضًا، يجب أن يتوافق _العميل_ المحدد في أمر snmptest مع عميل snmptrapd المستهدف.

الخيارات

تأخذ snmptest الخيارات المشتركة الموضحة في صفحة دليل snmpcmd(1).

NAME

snmptest — A simple SNMP client that tests SNMP access.

SYNOPSIS

snmptest [-h host] [-c community] [-v version] [-p port]

DESCRIPTION

snmptest is a simple command-line utility that allows you to test your access to an SNMP-enabled device. It attempts to retrieve a system description from the specified host using the provided community string and SNMP version.

OPTIONS

-h host
The hostname or IP address of the SNMP agent. Defaults to localhost.
-c community
The SNMP community string to use for authentication. Defaults to public.
-v version
The SNMP version to use. Can be 1, 2c, or 3. Defaults to 1.
-p port
The UDP port to connect to on the remote host. Defaults to 161.

EXAMPLES

Test access to a device at 192.168.1.1 using the default community and version:

snmptest -h 192.168.1.1

Test access to a device with a specific community string:

snmptest -h device.example.com -c private

Test access using SNMPv2c:

snmptest -h 192.168.1.1 -v 2c -c public
