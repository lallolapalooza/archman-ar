الاسم

sndio — واصفات أجهزة الصوت و MIDI

الوصف

تصل البرامج إلى أجهزة الصوت و MIDI باستخدام مكتبة sndio. تسمح بالوصول عبر خادم sndiod(8) والوصول المباشر إلى الأجهزة. يتم تعيين جهاز الصوت أو منفذ MIDI، وكذلك طريقة الوصول، بواسطة واصف sndio. يتم توفيره بواسطة المستخدم مع طريقة اختيار جهاز البرنامج، أو باستخدام متغيرات البيئة AUDIODEVICE و MIDIDEVICE إذا لم تكن هناك طريقة لاختيار الجهاز.

عادةً، تصل البرامج إلى الأجهزة عبر خادم sndiod(8)، لأن الوصول المباشر إلى الأجهزة حصري ويتطلب امتيازات إضافية. يدعم خادم sndiod(8) اتصالات متعددة في وقت واحد، مما يسمح لعدة برامج باستخدام الأجهزة بشكل متزامن. يقوم بمعالجة الصوت الضرورية في الوقت الفعلي للتغلب على أي عدم توافق بين البرامج والأجهزة. يمكن أيضًا إنشاء اتصالات بـ sndiod(8) عبر الشبكة، بما في ذلك من الأجهزة الافتراضية.

يكشف خادم sndiod(8) عن منافذ MIDI thru، مما يسمح لبرنامج بإرسال بيانات MIDI إلى برامج أخرى، على سبيل المثال للسماح للمسلسل بإرسال أحداث إلى جهاز توليف.

بالإضافة إلى ذلك، يكشف sndiod(8) عن منفذ MIDI يستخدم للتحكم في برامج الصوت باستخدام رسائل MIDI Machine Control (MMC) و MIDI Time Code (MTC) ورسائل مستوى الصوت الرئيسية القياسية.

واصفات أجهزة الخادم

من وجهة نظر المستخدم، لكل جهاز صوت أو منفذ MIDI يكشف عنه sndiod(8) واصف بالشكل:

type[@hostname][,servnum]/[devnum|option]

تستخدم هذه المعلومات بواسطة البرامج لتحديد كيفية الوصول إلى جهاز الصوت أو منفذ MIDI.

type
نوع جهاز الصوت أو منفذ MIDI. القيم الممكنة هي:
snd
جهاز صوت يكشف عنه sndiod(8).
midithru
منفذ MIDI thru تم إنشاؤه باستخدام sndiod(8).
midi
منفذ MIDI يكشف عنه sndiod(8).
hostname
اسم المضيف أو العنوان حيث يعمل خادم sndiod(8) البعيد للاتصال به.
servnum
رقم خادم sndiod(8) للاتصال به، وهو يتوافق مع العدد الصحيح المحدد باستخدام الخيار -U لـ sndiod(8). مفيد فقط إذا كانت هناك عدة خوادم sndiod(8) تعمل على نفس النظام.
devnum
رقم الجهاز. يتوافق مع رقم الخيار -f أو -q المقابل في سطر أوامر sndiod(8).
option
يتوافق مع سلسلة الجهاز الفرعي المسجلة باستخدام الخيار -s لـ sndiod(8).

واصفات الأجهزة المباشرة

كل جهاز صوت مباشر أو منفذ MIDI مباشر له واصف بالشكل:

type/devnum

يمكن أن يكون type إما rsnd أو rmidi. واصف الجهاز rsnd/0 يصل إلى الجهاز /dev/audio0، rsnd/1 يصل إلى /dev/audio1، وهكذا. وبالمثل، rmidi/0 يصل إلى /dev/rmidi0 وهكذا.

أجهزة الصوت و MIDI الافتراضية

عندما لا يتم توفير واصف جهاز صوت لبرنامج أو عندما يتم استخدام الكلمة المحجوزة default كوصف لجهاز الصوت، سيستخدم البرنامج الذي تم تحديده في متغيرات البيئة AUDIODEVICE و AUDIOPLAYDEVICE و/أو AUDIORECDEVICE. إذا لم يتم تعيينها، يحاول البرنامج أولاً الاتصال بـ snd/default. إذا فشل ذلك، فإنه يحاول بعد ذلك استخدام rsnd/0.

وبالمثل، إذا لم يتم توفير واصف MIDI لبرنامج أو عند تمرير الكلمة المحجوزة default كوصف للجهاز، يستخدم البرنامج الذي تم تحديده في متغير البيئة MIDIDEVICE. إذا لم يتم تعيينه، يحاول البرنامج أولاً الاتصال بـ midithru/0. إذا فشل ذلك، فإنه يحاول بعد ذلك استخدام rmidi/0. طالما أن sndiod(8) قيد التشغيل، يسمح هذا للبرامج بتبادل بيانات MIDI على الأجهزة التي لا تحتوي على أجهزة MIDI بشكل افتراضي، على سبيل المثال، يمكن لمشغل MIDI استخدام جهاز توليف برمجي بدون تكوين يدوي مطلوب.

المصادقة

لأسباب تتعلق بالخصوصية، قد يكون لدى مستخدم واحد فقط اتصالات بـ sndiod(8) في وقت معين. يتم تحديد المستخدمين بواسطة ملف تعريف ارتباط الجلسة، والذي يتم إنشاؤه تلقائيًا بواسطة برامج الصوت أو MIDI عند أول اتصال بالخادم. يتم تخزين ملف تعريف الارتباط في $HOME/.sndio/cookie ويحتوي على 128 بت من بيانات عشوائية خام.

إذا كانت هناك حاجة لمشاركة جلسة بين عدة مستخدمين، فيمكنهم الاتصال بالخادم باستخدام نفس ملف تعريف الارتباط.

البيئة

AUDIODEVICE
واصف جهاز الصوت الذي سيتم استخدامه عندما لا يتم تحديد واصف صراحةً لبرنامج.
AUDIOPLAYDEVICE
واصف جهاز الصوت الذي سيتم استخدامه لوضع التشغيل فقط عندما لا يتم تحديد واصف صراحةً لبرنامج. يلغي AUDIODEVICE.
AUDIORECDEVICE
واصف جهاز الصوت الذي سيتم استخدامه لوضع التسجيل فقط عندما لا يتم تحديد واصف صراحةً لبرنامج. يلغي AUDIODEVICE.
MIDIDEVICE
واصف منفذ MIDI الذي سيتم استخدامه عندما لا يتم تحديد واصف صراحةً لبرنامج.

يتم تجاهل متغيرات البيئة هذه بواسطة sndio إذا كانت لدى البرنامج بتات set-user-ID أو set-group-ID مضبوطة.

NAME

sndio - sndio audio and MIDI subsystem

DESCRIPTION

The sndio library provides an interface to the sndio(8) sound daemon. It handles audio and MIDI input and output devices.

The library is designed to be simple and efficient. It uses the following device names:

a/0
First audio output port created with sndiod(8).
a/1
Second audio output port created with sndiod(8).
i/0
First audio input port created with sndiod(8).
i/1
Second audio input port created with sndiod(8).
m/0
First MIDI output port created with sndiod(8).
ithru/0
First MIDI thru port created with sndiod(8).
default
Default audio or MIDI device.
rsnd/0
Direct hardware access to /dev/audio0.
rmidi/5
Direct hardware access to /dev/rmidi5.
