أمثلة

لطباعة Pi بخمسة أرقام عشرية:


#include <math.h>
#include <stdio.h>
fprintf(stdout, "pi = %.5f\n", 4 * atan(1.0));

لطباعة التاريخ والوقت بالشكل "Sunday, July 3, 10:02"، حيث weekday و month مؤشران للسلاسل النصية:


#include <stdio.h>
fprintf(stdout, "%s, %s %d, %.2d:%.2d\n",
        weekday, month, day, hour, min);

تستخدم العديد من البلدان ترتيب اليوم-الشهر-السنة. لذلك، يجب أن يكون الإصدار الدولي قادرًا على طباعة الوسائط بترتيب تحدده الصيغة:


#include <stdio.h>
fprintf(stdout, format,
        weekday, month, day, hour, min);

حيث يعتمد format على إعدادات اللغة المحلية، وقد يعيد ترتيب الوسائط. بالقيمة:


"%1$s, %3$d. %2$s, %4$d:%5$.2d\n"

قد يتم الحصول على "Sonntag, 3. Juli, 10:02".

لتخصيص سلسلة نصية كبيرة بما يكفي والطباعة فيها (كود صحيح لكل من glibc 2.0 و glibc 2.1):

#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
char *
make_message(const char *fmt, ...)
{
    int n = 0;
    size_t size = 0;
    char *p = NULL;
    va_list ap;
    /* تحديد الحجم المطلوب.  */
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0)
        return NULL;
    size = (size_t) n + 1;      /* بايت إضافي واحد لـ '\0' */
    p = malloc(size);
    if (p == NULL)
        return NULL;
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0) {
        free(p);
        return NULL;
    }
    return p;
}

إذا حدث اقتطاع في إصدارات glibc السابقة لـ glibc 2.0.6، يتم معاملة ذلك كخطأ بدلاً من التعامل معه بسلاسة.
