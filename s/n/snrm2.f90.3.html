توثيق الوظيفة/الروتين الفرعي

real(wp) function snrm2 (integer n, real(wp), dimension(*) x, integer incx)

SNRM2

الغرض:

!>
!> SNRM2 تُرجع المعيار الإقليدي لمتجه عبر اسم الوظيفة، بحيث
!>
!>    SNRM2 := sqrt( x'*x ).
!>

المعلمات

N 
!>          N هو عدد صحيح (INTEGER)
!>         عدد العناصر في المتجه(المتجهات) المدخلة
!>

X

!>          X هو مصفوفة حقيقية (REAL array)، ذات أبعاد ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)، المسافة التخزينية بين عناصر X
!>          إذا كان INCX > 0، فإن X(1+(i-1)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX < 0، فإن X(1-(n-i)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX = 0، فإن X ليس متجهًا، لذلك لا داعي لاستدعاء
!>          هذا الروتين الفرعي. إذا قمت باستدعائه على أي حال، فسيتم احتساب
!>          x(1) في معيار المتجه N مرة.
!>
