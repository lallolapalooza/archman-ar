snmptrap(1)

الحزمة: net-snmp

التراخيص: BSD

SNMPTRAP(1) Net-SNMP SNMPTRAP(1)

الاسم

snmptrap, snmpinform - إرسال إشعار SNMP إلى مدير

الموجز

snmptrap -v 1 [خيارات مشتركة] AGENT enterprise-oid agent generic-trap specific-trap uptime [OID TYPE VALUE]...

snmptrap -v [2c|3] [خيارات مشتركة] [-Ci] AGENT uptime trap-oid [OID TYPE VALUE]...

snmpinform -v [2c|3] [خيارات مشتركة] AGENT uptime trap-oid [OID TYPE VALUE]...

الوصف

snmptrap هو تطبيق SNMP يستخدم عملية SNMP TRAP لإرسال معلومات إلى مدير الشبكة. يمكن تقديم معرف كائن واحد أو أكثر (OIDs) كوسائط في سطر الأوامر. يجب أن يرافق كل معرف كائن نوع وقيمة. يتم إعطاء كل اسم متغير بالتنسيق المحدد في variables(5).

عند استدعائه باسم snmpinform, أو عند إضافة -Ci إلى أعلام سطر الأوامر لـ snmptrap، فإنه يرسل INFORM-PDU، ويتوقع استجابة من مستقبل الفخ، ويعيد الإرسال إذا لزم الأمر. بخلاف ذلك، فإنه يرسل TRAP-PDU أو TRAP2-PDU.

إذا تم تحديد أي من معلمات الإصدار 1 المطلوبة، enterprise-oid، agent، و uptime كسلسلة فارغة، فإنها تأخذ القيم الافتراضية 1.3.6.1.4.1.3.1.1 (enterprises.cmu.1.1)، hostname، و host-uptime على التوالي.

TYPE هو حرف واحد، واحد مما يلي:

i
عدد صحيح (INTEGER)
u
عدد صحيح غير موقع (UNSIGNED)
c
عداد 32 بت (COUNTER32)
s
سلسلة نصية (STRING)
x
سلسلة نصية بالنظام الست عشري (HEX STRING)
d
سلسلة نصية عشرية (DECIMAL STRING)
n
كائن فارغ (NULLOBJ)
o
معرف كائن (OBJID)
t
وقت (TIMETICKS)
a
عنوان IP (IPADDRESS)
b
بتات (BITS)
والتي يتم التعامل معها بنفس الطريقة التي يتعامل بها الأمر snmpset.

الوسيط AGENT مدمج فقط في SNMP TRAP PDUs ولكن ليس في SNMP INFORM PDUs. إذا لم يكن AGENT سلسلة فارغة، فيجب أن يكون عنوان IPv4. هذا القيد يأتي من RFC 1157، حيث يتم تعريف حقل عنوان الوكيل على النحو التالي:

agent-addr NetworkAddress, -- عنوان الكائن الذي يولد الفخ

من RFC 1155:

NetworkAddress ::=
CHOICE {
internet IpAddress
}
[ ... ]
IpAddress ::=
[APPLICATION 0] -- بترتيب البايت الشبكي
IMPLICIT OCTET STRING (SIZE (4))

مثال على كيفية استخدام snmptrap:

snmptrap -v 1 -c public manager enterprises.spider test-hub 3 0 '' interfaces.iftable.ifentry.ifindex.1 i 1

سيؤدي ذلك إلى إرسال فخ linkUp عام إلى المدير، للواجهة 1.

الخيارات

يأخذ snmptrap الخيارات المشتركة الموصوفة في صفحة دليل snmpcmd(1) بالإضافة إلى خيار -Ci الموصوف أعلاه. لاحظ أن snmptrap يتطلب وسيطًا يحدد الوكيل للاستعلام عنه كما هو موضح هناك.

انظر أيضاً

snmpcmd(1), snmpset(1), variables(5).
