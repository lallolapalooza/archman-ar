إضافة شيء إلى النطاق

قد ترغب في فصل تحقيقاتك، لذا يجب عليك تحديد مساحة عمل تذهب إليها نتائجك:

[sn0int][default] > workspace demo
[+] Connecting to database
[sn0int][demo] >

بعد ذلك، يجب أن نبدأ من مكان ما ونضيف الكيان الأول إلى نطاقنا:

[sn0int][demo] > add domain
Domain: example.com
[sn0int][demo] >

ملاحظة:

هناك مفهوم للنطاق مقابل النطاق الفرعي. نشير إلى نطاق على أنه كل ما هو نطاق فرعي لـ لاحقة عامة. على سبيل المثال، .com هي لاحقة عامة، مما يجعل example.com نطاقًا من منظور sn0int. كل نطاق فرعي منه، مثل www.example.com، يشار إليه على أنه نطاق فرعي.

لاحظ أنه يمكن إضافة example.com كنطاق فرعي أيضًا لأنه يمكن أن يحتوي على سجلات. في هذه الحالة، example.com هو اسم منطقة DNS، بينما هو أيضًا كيان في تلك المنطقة.

يمكنك تأكيد ذلك عن طريق تشغيل تحديد على النطاقات التي لدينا الآن:

[sn0int][demo] > select domains
#1, "example.com"
[sn0int][demo] >

شيء لا نحتاجه الآن، ولكنه سيكون مفيدًا لاحقًا هو القدرة على تصفية كياناتك:

[sn0int][demo] > select domains where id=1
#1, "example.com"
[sn0int][demo] >
[sn0int][demo] > select domains where value like %.com
#1, "example.com"
[sn0int][demo] >
[sn0int][demo] > select domains where ( value like e% and value like %m ) or false
#1, "example.com"
[sn0int][demo] >

ملاحظة:

تقريبًا كل الكيانات لها عمود value يحمل القيمة الأساسية للكيان.

تشغيل وحدات متابعة على النتائج

لقد تم قضاء الكثير من الوقت في جزء قاعدة البيانات. بينما يبدو الأمر وكأنه قاعدة بيانات no-sql، فإننا في الواقع نفرض مخططًا لسبب بدلاً من مجرد استخدام القواميس العامة والانتهاء من ذلك.

من الضروري أن يتمكن الكيان الذي تم إنشاؤه بواسطة وحدة واحدة من التقاطه بواسطة وحدة أخرى، مثل قطع الليغو. دعنا نواصل مع وحدة للاستعلام عن سجلات DNS:

[sn0int][demo][kpcyrd/ctlogs] > use dns-resolve
[sn0int][demo][kpcyrd/dns-resolve] > run

حدث شيئان هنا: اكتشفنا بعض عناوين IP وأضفناها إلى النطاق، وقمنا أيضًا بتحديث كيانات النطاقات الفرعية الخاصة بنا بمعلومات جديدة، حيث نعرف الآن أي منها قابل للحل وأيها ليست كذلك.

لنقم بتشغيل الوحدة التالية، والتي ستبحث بالفعل عن مواقع الويب عليها، ولكننا سنستهدف فقط النطاقات الفرعية التي نعرف أنها قابلة للحل:

http_fetch_json

متطابق مع http_fetch ولكنه يقوم أيضًا بتحليل نص الاستجابة تلقائيًا بتنسيق JSON.

-- الشكل المختصر
data = http_fetch_json(req)
if last_err() then return end
-- الشكل الطويل
resp = http_send(req)
if last_err() then return end
if resp['status'] ~= 200 then return 'http status error: ' .. resp['status'] end
data = json_decode(resp['text'])
if last_err() then return end

img_load

محاولة فك تشفير كائن ثنائي كبير (blob) كصورة وإرجاع بعض البيانات الوصفية الأساسية مثل نوع MIME، والارتفاع، والعرض.

img = img_load(blob)
if last_err() then return end
debug(img)

img_exif

استخراج البيانات الوصفية EXIF من صورة.

exif = img_exif(blob)
if last_err() then return end
debug(exif)

img_ahash

حساب التجزئة الإدراكية المتوسطة (aHash).

hash = img_ahash(blob)
if last_err() then return end
debug(hash)

img_dhash

حساب التجزئة الإدراكية للتدرج (dHash).

hash = img_dhash(blob)
if last_err() then return end
debug(hash)

img_phash

حساب التجزئة الإدراكية DCT (pHash).

hash = img_phash(blob)
if last_err() then return end
debug(hash)

img_nudity

تصنيف صورة للكشف عن العري. تتراوح الدرجة من 0 إلى 2. تشير الدرجة التي تزيد عن 1 إلى اكتشاف العري.

nudity = img_nudity(blob)
if last_err() then return end
debug(nudity)

info

تسجيل معلومة في الطرفية.

info('ohai')

intval

تحليل رقم من سلسلة نصية.

x = strval('1234')

json_decode

فك تشفير قيمة lua من سلسلة JSON.

json_decode("{\"data\":{\"password\":\"fizz\",\"user\":\"bar\"},\"list\":[1,3,3,7]}")

json_decode_stream

شبيه جدًا بـ json_decode، ولكنه يعمل مع كائنات JSON متعددة متسلسلة مباشرة مع بعضها البعض أو مفصولة بأسطر جديدة.

json_decode_stream("{\"data\":1}{\"data\":2}")

json_encode

تشفير بنية بيانات كسلسلة نصية.

x = json_encode({
    some=1,
    fancy={
        data='structures',
    }
})
print(x)

key_trunc_pad

اقتطاع/حشو مفتاح لطول معين.

-- إذا كان أطول من 32 بايت: اقتطع إلى 32
-- إذا كان أقصر من 32 بايت: احش بـ \x00
local key = key_trunc_pad(password, 32, 0)

keyring

طلب جميع المفاتيح من مساحة اسم معينة. انظر قسم keyring للتفاصيل.

creds = keyring('aws')
print(creds[1]['accesskey'])
print(creds[1]['secretkey'])

last_err

يعيد معلومات حول آخر خطأ لاحظناه، إن وجد. يعيد nil بخلاف ذلك.

if last_err() then
    -- حدث خطأ ما، توقف
    return
end

md5

تجزئة مصفوفة بايت باستخدام MD5 وإعادة النتائج كبايت.

hex(md5("\x00\xff"))

mqtt_connect

الاتصال بخادم MQTT.

local sock = mqtt_connect('mqtts://mqtt.example.com', {
    username='foo',
    password='secret',
})
if last_err() then return end

mqtt_subscribe

الاشتراك في موضوع (topic). حاليًا، يدعم فقط QoS 0.

mqtt_subscribe(sock, '#', 0)
if last_err() then return end

mqtt_recv

استلام حزمة MQTT. هذه ليست بالضرورة حزمة نشر وقد تضاف حزم أخرى في المستقبل، لذا تحتاج إلى التحقق من النوع تحديدًا.

إذا تم تعيين مهلة قراءة باستخدام mqtt_connect، فإن هذه الدالة تعيد nil في حالة انتهاء مهلة القراءة.

local pkt = mqtt_recv(sock)
if last_err() then return end
if pkt == nil then
    -- انتهت مهلة القراءة، فكر في إرسال ping أو قطع الاتصال إذا فشل ping السابق
elseif pkt['type'] == 'pong' then
    -- أرسل الخادم pong
elseif pkt['type'] == 'publish' then
    local payload = utf8_decode(pkt['body'])
    if last_err() then return end
    info(payload)
end

mqtt_ping

إرسال حزمة pingreq، مما يتسبب في إرسال الخادم pingresp. يستخدم هذا للتأكد من أن الاتصال لا يزال يعمل بشكل صحيح.

mqtt_ping(sock)
if last_err() then return end

print

اكتب شيئًا مباشرة إلى الطرفية.

print({
    some=1,
    fancy={
        data='structures',
    }
})

تحذير:

تكتب هذه الدالة مباشرة إلى الطرفية وقد تتداخل مع ميزات طرفية أخرى. يجب استخدام هذه الدالة أثناء التطوير فقط.

psl_domain_from_dns_name

يعيد النطاق الأصل وفقًا لقائمة النطاقات العامة (public suffix list). بالنسبة لـ www.a.b.c.d.example.co.uk، سيكون هذا example.co.uk.

domain = psl_domain_from_dns_name('www.a.b.c.d.example.co.uk')
print(domain == 'example.co.uk')

ratelimit_throttle

إنشاء حد معدل يمكن تجاوزه x مرة كل y مللي ثانية. هذا الحد عام لتشغيل واحد (run) ويعمل أيضًا مع الخيوط (threads).

-- اسمح بهذا بالمرور كل 250 مللي ثانية
ratelimit_throttle('foo', 1, 250)
-- اسمح لهذا بالمرور بما لا يزيد عن 4 مرات في الثانية
ratelimit_throttle('foo', 4, 1000)

هذا مفيد إذا كنت بحاجة إلى تنسيق عمليات التنفيذ الخاصة بك للبقاء دون حد معين للطلبات.

regex_find

طبق تعبير عادي (regex) على بعض النصوص. تُرجع nil إذا لم يتطابق التعبير العادي، وتُرجع مجموعات الالتقاط إذا تطابق.

m = regex_find(".(.)", "abcdef")
if m == nil then
    print('لا توجد مجموعات التقاط')
end
print(m[1] == 'ab')
print(m[2] == 'b')

regex_find_all

نفس وظيفة regex_find، ولكنها تُرجع جميع التطابقات.

m = regex_find_all(".(.)", "abcdef")
print(m[1][1] == 'ab')
print(m[1][2] == 'b')
print(m[2][1] == 'cd')
print(m[2][2] == 'd')
print(m[3][1] == 'ef')
print(m[3][2] == 'f')

semver_match

قارن إصدارًا بمتطلب إصدار. يمكن استخدام هذا مع sn0int_version لاختبار ميزات أو سلوكيات معينة.

semver_match('=0.11.2', sn0int_version())
semver_match('>0.11.2', sn0int_version())
semver_match('<0.11.2', sn0int_version())
semver_match('~0.11.2', sn0int_version())
semver_match('^0.11.2', sn0int_version())
semver_match('0.11.2', sn0int_version()) -- مرادف لـ ^0.11.2
semver_match('<=0.11.2', sn0int_version())
semver_match('>=0.11.2', sn0int_version())
semver_match('>=0.4.0, <=0.10.0', sn0int_version())

set_err

تعديل كائن الخطأ العام. إذا كنت ترغب في إنهاء الدالة الرئيسية run بخطأ، يمكنك ببساطة إرجاع سلسلة نصية، ولكن هذه السلاسل يصعب نشرها عبر الدوال. تقوم set_err بتعيين خطأ بشكل خاص لكائن الخطأ العام الذي تستخدمه أيضًا جميع وظائف rust الأخرى.

function foo()
    set_err("حدث خطأ ما")
end
foo()
if last_err() then return end

hex(sha1("\x00\xff"))

sha2_256

تجزئة مصفوفة بايتات باستخدام sha2_256 وإرجاع النتائج كبايتات.

hex(sha2_256("\x00\xff"))

sha2_512

تجزئة مصفوفة بايتات باستخدام sha2_512 وإرجاع النتائج كبايتات.

hex(sha2_512("\x00\xff"))

sha3_256

تجزئة مصفوفة بايتات باستخدام sha3_256 وإرجاع النتائج كبايتات.

hex(sha3_256("\x00\xff"))

sha3_512

تجزئة مصفوفة بايتات باستخدام sha3_512 وإرجاع النتائج كبايتات.

hex(sha3_512("\x00\xff"))

sleep

إيقاف البرنامج الحالي مؤقتًا لعدد الثواني المحدد. يُستخدم هذا عادةً لأغراض التصحيح فقط.

sleep(1)

sn0int_time

إرجاع الوقت الحالي بالتوقيت العالمي المنسق (UTC). هذه الدالة مناسبة لتحديد التواريخ والأوقات لحقول قاعدة البيانات من نوع DATETIME.

now = sn0int_time()

ملاحظة:

هذا التنسيق خاص بـ sn0int، للحصول على الوقت الحالي للاستخدام في البرمجة النصية، استخدم time_unix بدلاً من ذلك.

sn0int_time_from

مطابقة لـ sn0int_time ولكنها تستخدم طابع زمني يونكس بالثواني بدلاً من الوقت الحالي. هذه الدالة متوافقة مع time_unix و strptime.

time = sn0int_time_from(1567931337)

sn0int_version

الحصول على سلسلة إصدار sn0int الحالي. يمكن استخدام هذا مع semver_match لاختبار ميزات أو سلوكيات معينة.

info(sn0int_version())

sock_connect

إنشاء اتصال TCP.

الخيارات التالية متاحة:

tls
تم تعيينه على true لتمكين tls (يتم التحقق من الشهادات)
sni_value
بدلاً من الوسيط المضيف، استخدم سلسلة مخصصة لملحق sni.
disable_tls_verify
خطر: تعطيل التحقق من tls. هذا يعطل كل الأمان على الاتصال. لاحظ أن sn0int لا يزال صارمًا إلى حد ما، وستواجه مشاكل إذا كنت بحاجة إلى دعم لشهادات التشفير غير الآمنة.
proxy
استخدم وكيل socks5 بالصيغة 127.0.0.1:9050. يعمل هذا الخيار فقط إذا لم يتعارض مع إعدادات الوكيل العامة.
connect_timeout
إلغاء محاولات اتصال TCP بعد n ثانية.
read_timeout
إلغاء محاولات القراءة بعد n ثانية. يمكن استخدام هذا لتنبيه الاتصالات بشكل دوري.
write_timeout
إلغاء محاولات الكتابة بعد n ثانية.
sock = sock_connect("127.0.0.1", 1337, {
    tls=true,
})

sock_upgrade_tls

خذ اتصال TCP موجود وابدأ مصافحة tls. الخيارات هي نفسها كما في sock_connect ولكن يُفترض دائمًا أن تكون قيمة tls صحيحة.

يجب تعيين قيمة sni بشكل خاص، وإلا فسيتم تعطيل ملحق sni.

استخدام هذه الدالة يُرجع تحديدًا بعض المعلومات الإضافية التي يتم تجاهلها عند استخدام sock_connect مباشرة مع tls=true.

sock = sock_connect("127.0.0.1", 1337, {})
if last_err() then return end
tls = sock_upgrade_tls(sock, {
    sni_value='example.com',
})
if last_err() then return end
info(tls)

sock_options

تحديث خيارات الاتصال الحالي:

read_timeout
إلغاء محاولات القراءة بعد n ثانية. يمكن استخدام هذا لتنبيه الاتصالات بشكل دوري.
write_timeout
إلغاء محاولات الكتابة بعد n ثانية.
sock_options(sock, {
    read_timeout=3,
})

sock_send

إرسال بيانات إلى المقبس.

sock_send(sock, "hello world")

sock_recv

استقبال ما يصل إلى 4096 بايت من المقبس.

x = sock_recv(sock)

sock_sendline

إرسال سلسلة نصية إلى المقبس. يتم إضافة سطر جديد تلقائيًا إلى السلسلة النصية.

sock_sendline(sock, line)

sock_recvline

استقبال سطر من المقبس. السطر يتضمن السطر الجديد.

x = sock_recvline(sock)

sock_recvall

استقبال كل البيانات من المقبس حتى نهاية الملف (EOF).

x = sock_recvall(sock)

sock_recvline_contains

استقبال سطور من الخادم حتى يحتوي سطر على النص المحدد (needle)، ثم إرجاع هذا السطر.

x = sock_recvline_contains(sock, needle)

sock_recvline_regex

استقبال سطور من الخادم حتى يتطابق سطر مع التعبير العادي (regex)، ثم إرجاع هذا السطر.

x = sock_recvline_regex(sock, "^250 ")

sock_recvn

استقبال عدد n بايت بالضبط من المقبس.

x = sock_recvn(sock, 4)

NAME

sn0int - Web scraping tool

RUNNING YOUR FIRST INVESTIGATION

To get started, you can run sn0int with a simple investigation.

sn0int ~/.config/sn0int/investigations/example.sn0int

This will run the example investigation defined in your sn0int configuration directory. The output will be printed to stdout.

CONFIGURATION

Sn0int looks for its configuration file at ~/.config/sn0int/config.json. If it doesn't exist, it will create one with default settings.

The configuration file allows you to customize:

  • timeout: The timeout for network requests in seconds.
  • threads: The number of concurrent threads to use for investigations.
  • user_agent: The User-Agent string to use for network requests.

Example configuration:

{
    "timeout": 30,
    "threads": 16,
    "user_agent": "Sn0int/0.1"
}

FUNCTION REFERENCE

Sn0int provides a set of built-in functions that can be used within investigations.

ws_recv_json

Receive a JSON object from the websocket connection.

msg = ws_recv_json(sock)

ws_send_text

Send a text frame on the websocket connection.

ws_send_text(sock, "ohai!")

ws_send_binary

Send a binary frame on the websocket connection.

ws_send_binary(sock, "\x00\x01\x02")

ws_send_json

Encode the object as json string and send it as a text frame on the websocket connection.

ws_send_text(sock, {
    foo="ohai!",
    x={
        y={1,3,3,7},
    },
})

xml_decode

Decode a lua value from an xml document.

x = xml_decode('<body><foo fizz="buzz">bar</foo></body>')
if last_err() then return end
body = x['children'][1]
foo = body['children'][1]
print(foo['attrs']['fizz'])
print(foo['text'])

xml_named

Get a named child element from a parent element.

x = xml_decode('<body><foo fizz="buzz">bar</foo></body>')
if last_err() then return end
body = x['children'][1]
foo = xml_named(body, 'foo')
if foo ~= nil then
    print(foo)
end
