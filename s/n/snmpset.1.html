snmpset(1)

الحزمة: net-snmp

التراخيص: BSD

SNMPSET(1) Net-SNMP SNMPSET(1)

الاسم

snmpset - يتواصل مع كيان شبكة باستخدام طلبات SNMP SET

الملخص

snmpset [خيارات مشتركة] AGENT OID TYPE VALUE [OID TYPE VALUE]...

الوصف

snmpset هو تطبيق SNMP يستخدم طلب SNMP SET لتعيين معلومات على كيان شبكة. يجب تقديم معرف كائن واحد أو أكثر (OIDs) كوسائط في سطر الأوامر. يجب أن يرافق كل معرف كائن نوع وقيمة ليتم تعيينها. يتم إعطاء كل اسم متغير بالتنسيق المحدد في variables(5).

النوع هو حرف واحد، أحد هذه الأحرف:

i
INTEGER (عدد صحيح)
u
UNSIGNED (بدون إشارة)
s
STRING (سلسلة نصية)
x
HEX STRING (سلسلة نصية سداسية عشرية)
d
DECIMAL STRING (سلسلة نصية عشرية)
n
NULLOBJ (كائن فارغ)
o
OBJID (معرف كائن)
t
TIMETICKS (وحدات زمنية)
a
IPADDRESS (عنوان IP)
b
BITS (بتات)
سيستخدم معظم هذه الأنواع النوع المقابل بوضوح من ASN.1. 's' و 'x' و 'd' و 'b' هي كلها طرق مختلفة لتحديد قيمة OCTET STRING، ويستخدم النوع غير المؤشر 'u' أيضًا لمعالجة قيم Gauge32.

إذا كان لديك ملف MIB المناسب محملًا، يمكنك في معظم الحالات استبدال النوع بعلامة '='. بالنسبة لكائن من نوع OCTET STRING، سيفترض أنه سلسلة نصية مثل تدوين النوع 's'. بالنسبة لأنواع أخرى، سيفعل "الشيء الصحيح".

على سبيل المثال:

snmpset -c private -v 1 test-hub system.sysContact.0 s dpz@noc.rutgers.edu ip.ipforwarding.0 = 2

سيقوم بتعيين متغيري sysContact.0 و ipForwarding.0:

system.sysContact.0 = STRING: "dpz@noc.rutgers.edu"
ip.ipForwarding.0 = INTEGER: not-forwarding(2)

إذا كان كيان الشبكة لديه خطأ في معالجة حزمة الطلب، فسيتم إرجاع حزمة خطأ وسيتم عرض رسالة، مما يساعد في تحديد طريقة تنسيق الطلب بشكل غير صحيح.

الخيارات

snmpset يأخذ الخيارات المشتركة الموضحة في صفحة دليل snmpcmd(1). لاحظ أن snmpset يتطلب وسيطًا يحدد الوكيل للاستعلام عنه وعلى الأقل مجموعة واحدة من وسائط OID/type/value، كما هو موضح هناك.

انظر أيضًا

snmpcmd(1), variables(5).
