snmpnetstat(1)

الحزمة: net-snmp

التراخيص: BSD

SNMPNETSTAT(1) Net-SNMP SNMPNETSTAT(1)

اسم

snmpnetstat - عرض معلومات حالة وتكوين الشبكة من كيان شبكة عبر SNMP

ملخص

snmpnetstat [خيارات مشتركة] [-Ca] [-Cn] [-Cv] [-Cf عائلة_عناوين] وكيل
snmpnetstat [خيارات مشتركة] [-Cr] [-Cn] [-Cv] [-Cf عائلة_عناوين] وكيل
snmpnetstat [خيارات مشتركة] [-Ci] [-C o | b | d] [-Cn] [-Cv] [-CI واجهة] [-Cw فاصل_زمني] وكيل
snmpnetstat [خيارات مشتركة] [-Cs[s]] [-Cp بروتوكول] وكيل

الوصف

يعرض الأمر snmpnetstat بشكل رمزي قيم معلومات مختلفة متعلقة بالشبكة يتم استردادها من نظام بعيد باستخدام بروتوكول SNMP. هناك عدد من تنسيقات الإخراج، اعتمادًا على الخيارات للمعلومات المعروضة. يعرض الشكل الأول للأمر قائمة بالمقابسيم النشطة. يقدم الشكل الثاني قيم المعلومات الأخرى المتعلقة بالشبكة وفقًا للخاصية المحددة. باستخدام الشكل الثالث، مع تحديد فاصل_زمني، سيعرض snmpnetstat بشكل مستمر المعلومات المتعلقة بحركة مرور الحزم على واجهات الشبكة المهيأة. يعرض الشكل الرابع إحصائيات حول البروتوكول المسمى.

سيقوم snmpnetstat بإصدار طلبات GETBULK للاستعلام عن المعلومات إذا تم استخدام بروتوكول الإصدار v2 على الأقل.

يحدد الوكيل AGENT وكيل SNMP المستهدف، والذي تم تجهيزه لمراقبة الكائنات المحددة. في أبسط صوره، سيتكون مواصفات الوكيل من اسم مضيف أو عنوان IPv4. في هذه الحالة، سيحاول الأمر الاتصال بالوكيل، باستخدام UDP/IPv4 إلى المنفذ 161 من المضيف المستهدف المحدد. راجع snmpcmd(1) للحصول على قائمة كاملة بالتنسيقات الممكنة للوكيل.

الخيارات

الخيارات لها المعنى التالي:

الخيارات المشتركة
يرجى الاطلاع على snmpcmd(1) للحصول على قائمة بالقيم المحتملة للخيارات الشائعة بالإضافة إلى أوصافها.

-CL استخدام عناصر MIB القديمة لـ SNMP، وليس الجداول الحديثة المستقلة عن إصدار IP. سيتراجع snmpnetstat تلقائيًا إلى الجداول القديمة إذا لم تكن الجداول الحديثة متاحة.

-Ca مع العرض الافتراضي، عرض حالة جميع المقابسيم؛ عادةً ما لا يتم عرض المقابسيم التي تستخدمها عمليات الخادم.

-Cf عائلة_عناوين عرض الإدخالات لعائلة العناوين المحددة فقط (inet، inet6)

-Ci عرض حالة جميع واجهات الشبكة. يوفر عرض الواجهة جدولًا إحصائيًا تراكميًا يتعلق بالحزم المنقولة والأخطاء والاصطدامات. يتم أيضًا عرض عناوين الشبكة للواجهة ووحدة النقل القصوى (``mtu'').

-Cd إضافة الحزم التي تم إسقاطها إلى عرض الواجهة.

-Cb عرض حالة واجهة موسعة، مع توفير البايتات بالإضافة إلى الحزم.

-Co عرض حالة واجهة مختصرة، مع توفير البايتات بدلاً من الحزم. هذا مفيد عند الاستعلام عن الواجهات الافتراضية (مثل دوائر Frame-Relay) على جهاز توجيه.

-CI واجهة عرض المعلومات حول هذه الواجهة فقط؛ تستخدم مع فاصل_زمني كما هو موضح أدناه.

-Cn عرض عناوين الشبكة كأرقام (عادةً ما يفسر snmpnetstat العناوين ويحاول عرضها بشكل رمزي). يمكن استخدام هذا الخيار مع أي من تنسيقات العرض.

-Cv السماح لأسماء المضيف أو الخدمة الطويلة بكسر الإخراج العمودي. يمكن استخدام هذا الخيار مع أي من تنسيقات العرض.

-Cp بروتوكول عرض الإحصائيات حول بروتوكول، وهو إما اسم معروف للبروتوكول أو اسم مستعار له. يتم سرد بعض أسماء البروتوكولات والأسماء المستعارة في الملف /etc/protocols. يعني الاستجابة الفارغة عادةً عدم وجود أرقام مثيرة للاهتمام للإبلاغ عنها. سيشتكي البرنامج إذا كان بروتوكول غير معروف أو إذا لم يكن هناك روتين إحصائيات له.

-Cs عرض الإحصائيات لكل بروتوكول. إذا تم تكرار هذا (-Css)، فسيتم قمع إدخالات الإحصائيات التي تساوي صفرًا.

-Cr عرض جداول التوجيه.

-CR المكررات لطلبات GETBULK، يحدد المكررات قيمة الحد الأقصى للمكررات المراد استخدامها.

عند استدعاء snmpnetstat مع وسيط فاصل_زمني، فإنه يعرض عدادًا مستمرًا للإحصائيات المتعلقة بواجهات الشبكة.

عرض المقابسيم النشطة (افتراضي)

يعرض العرض الافتراضي، للمقابسيم النشطة، العناوين المحلية والبعيدة، البروتوكول، والحالة الداخلية للبروتوكول. تنسيقات العناوين هي من الشكل ``مضيف.منفذ'' أو ``شبكة.منفذ'' إذا كان عنوان المقبس يحدد شبكة ولكن لا يوجد عنوان مضيف محدد. عند معرفتها، يتم عرض عناوين المضيف والشبكة بشكل رمزي وفقًا لقواعد البيانات /etc/hosts و /etc/networks على التوالي. إذا كان الاسم الرمزي للعنوان غير معروف، أو إذا تم تحديد الخيار -Cn، يتم طباعة العنوان عدديًا، وفقًا لعائلة العناوين. لمزيد من المعلومات حول تنسيق ``النقطة'' للإنترنت، راجع inet(3N). العناوين والمنافذ غير المحددة، أو ``البرية''، تظهر كـ ``*''.

عرض الواجهة

يوفر عرض الواجهة جدولًا إحصائيًا تراكميًا يتعلق بالحزم المنقولة والأخطاء والاصطدامات. يتم أيضًا عرض عناوين الشبكة للواجهة ووحدة النقل القصوى (``mtu'').

عرض جدول التوجيه

يشير عرض جدول التوجيه إلى المسارات المتاحة وحالتها. يتكون كل مسار من وجهة مضيف أو شبكة وبوابة للاستخدام في توجيه الحزم. يوضح حقل الأعلام حالة المسار (``U'' إذا كان ``up'')، وما إذا كان المسار إلى بوابة (``G'')، وما إذا كان المسار قد تم إنشاؤه ديناميكيًا بواسطة إعادة توجيه (``D'')، وما إذا كان المسار قد تم تعديله بواسطة إعادة توجيه (``M''). يتم إنشاء المسارات المباشرة لكل واجهة متصلة بالمضيف المحلي؛ يوضح حقل البوابة لمثل هذه الإدخالات عنوان الواجهة الخارجية. يشير إدخال الواجهة إلى واجهة الشبكة المستخدمة للمسار.

عرض الواجهة مع فاصل زمني

عند استدعاء snmpnetstat مع وسيط فاصل_زمني، فإنه يعرض عدادًا مستمرًا للإحصائيات المتعلقة بواجهات الشبكة. يتكون هذا العرض من عمود للواجهة الأساسية وعمود يلخص المعلومات لجميع الواجهات. يمكن استبدال الواجهة الأساسية بواجهة أخرى باستخدام الخيار -CI. يحتوي السطر الأول من كل شاشة معلومات على ملخص منذ آخر إعادة تشغيل للنظام. تعرض الأسطر اللاحقة من الإخراج القيم المتراكمة خلال الفاصل الزمني السابق.

عرض المقابسيم النشطة لبروتوكول واحد

عند تحديد بروتوكول باستخدام الخيار -Cp، تكون المعلومات المعروضة مشابهة لتلك الموجودة في العرض الافتراضي للمقابسيم النشطة، باستثناء أن العرض يقتصر على البروتوكول المحدد.

snmpnetstat(8) — Arch Linux man pages

NAME

snmpnetstat - لعرض معلومات حول اتصالات الشبكة والجداول الموجهة وبرامج تشغيل الواجهة

SYNOPSIS

snmpnetstat [ -a | -i | -r ] [ -u ] [ -l ] [ -n ] [ -W ] [ -v ] [ -A AUTHENTICATIONPRIVELEGES ] [ -e ] [ -E EXTENSIONS ] [ -P PASSWORDAUTHENTICATIONPROTOCOL ] [ -Q PASSWORDEnhalueprotocol ] [ -S SECURITYLEVEL ] [ -U SECURITYMODEL ] [ -X PRIVACYPASSWORD ] [ -Y PRIVACYPASSPHRASEPROTOCOL ] [ -Z AUTHPRIVACYPROTOCOL ] [ -f FAMILY ] [ -o OWNER ] [ -p PROTOCOL ] [ HOST ] [ OBJECT(...) ]

DESCRIPTION

يجمع snmpnetstat بين وظائف netstat القياسية و SNMP. يسمح لك بعرض معلومات حول اتصالات الشبكة، والجداول الموجهة، وبرامج تشغيل الواجهة، وما إلى ذلك، عن طريق الاستعلام عن وكيل SNMP.

يقوم snmpnetstat باسترداد المعلومات باستخدام بروتوكول SNMP من نقطة نهاية SNMP. يمكن أن تكون نقطة النهاية هذه جهازًا عن بُعد أو الجهاز المحلي.

البدائل المتاحة هي:

-a
عرض جميع المقابس، سواء كانت معلقة أو غير معلقة.
-i
عرض جدول واجهات الشبكة.
-r
عرض جدول التوجيه.
-u
عرض مقابس UDP.
-l
عرض مقابس الاستماع فقط.
-n
لا تحاول حل أسماء المضيفين وعناوين IP وأرقام المنافذ.
-W
عرض عريض، لا تقطع الأسطر.
-v
مفصل.

هناك العديد من خيارات SNMP التي يمكن تمريرها إلى snmpnetstat:

-A AUTHENTICATIONPRIVELEGES
مجموعة امتيازات المصادقة.
-e
عرض إحصائيات إضافية.
-E EXTENSIONS
ملحقات.
-P PASSWORDAUTHENTICATIONPROTOCOL
بروتوكول المصادقة.
-Q PASSWORDEnhalueprotocol
بروتوكول القيمة.
-S SECURITYLEVEL
مستوى الأمان.
-U SECURITYMODEL
نموذج الأمان.
-X PRIVACYPASSWORD
كلمة مرور الخصوصية.
-Y PRIVACYPASSPHRASEPROTOCOL
بروتوكول عبارة المرور.
-Z AUTHPRIVACYPROTOCOL
بروتوكول المصادقة والخصوصية.
-f FAMILY
تصفية حسب عائلة البروتوكول (مثل inet أو inet6).
-o OWNER
تصفية حسب المالك.
-p PROTOCOL
تصفية حسب البروتوكول (مثل tcp أو udp).

يمكن تحديد HOST لتحديد مضيف SNMP، وسيتم استخدام OBJECT(...) للاستعلام عن معلومات محددة.
