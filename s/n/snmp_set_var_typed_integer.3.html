الوصف

تنقسم الوظائف التي تتعامل مع روابط المتغيرات إلى أربع مجموعات - التعامل مع الإنشاء، تعيين القيم، الخرج وحذف روابط المتغيرات.

الإنشاء

تقوم snmp_pdu_add_variable بإنشاء بنية رابط متغير جديدة، يتم تهيئتها بالاسم ( objid، objidlen )، بناء الجملة ( type ) والقيمة ( value، len ) المقدمة. ثم تتم إضافة رابط المتغير هذا إلى نهاية قائمة روابط المتغيرات في PDU المحدد.

snmp_varlist_add_variable مشابهة، لكنها تضيف رابط متغير جديد إلى نهاية قائمة روابط المتغيرات المقدمة. عند إضافة رابط المتغير الأول إلى قائمة فارغة، مرر ببساطة عنوان بداية القائمة:


netsnmp_variable_list *vl = NULL;
snmp_varlist_add_variable(
&vl, name1, name1_len,
ASN_TYPE, &val1, val1_len);
snmp_varlist_add_variable(
&vl, name2, name2_len,
ASN_TYPE, &val2, val2_len);

في كلتا الحالتين، ستعيد الدالة مؤشرًا إلى بنية رابط المتغير الجديدة (أو NULL إذا فشل إنشاء رابط المتغير).

snmp_add_null_var هي دالة مساعدة لإضافة رابط متغير فارغ إلى PDU. دون الحاجة إلى تحديد قيمة NULL بشكل صريح. هذه هي الآلية العادية لبناء طلب استرجاع معلومات GET (أو ما شابه).
مرة أخرى، تعيد هذه الدالة مؤشرًا إلى رابط المتغير الجديد، أو NULL.

snmp_clone_varbind تنشئ نسخة من كل رابط متغير في القائمة المحددة، وتعيد مؤشرًا إلى بداية القائمة الجديدة (أو NULL إذا فشل النسخ).

تعيين القيم

تقوم snmp_set_var_objid بتعيين اسم بنية رابط المتغير إلى OID المحدد.
تقوم snmp_set_var_typed_value بتعيين نوع بناء الجملة وقيمة بنية رابط المتغير.
تقوم snmp_set_var_value بتعيين قيمة بنية رابط المتغير، مع ترك نوع بناء الجملة دون تغيير.
snmp_set_var_typed_integer هي دالة مساعدة لتعيين نوع بناء الجملة وقيمة لرابط متغير يعتمد على عدد صحيح 32 بت.

جميع هذه الوظائف الأربعة تعيد 0 إذا كان التعيين ناجحًا، أو 1 إذا لم يكن كذلك.

الخرج

تأخذ print_variable معرف الكائن (كما تم إرجاعه بواسطة read_objid، snmp_parse_oid أو get_module_node) ونسخة من مثل هذا المتغير، وتقوم بطباعة الشكل النصي لمعرف الكائن مع قيمة المتغير إلى الإخراج القياسي.

تقوم fprint_variable بنفس الشيء، ولكنها تطبع إلى مؤشر FILE المحدد بواسطة المعلمة الأولية.

تقوم snprint_variable بطباعة نفس المعلومات في المخزن المؤقت الذي يشير إليه buf والذي يبلغ طوله len. تعيد عدد الأحرف المطبوعة، أو -1 إذا لم يكن المخزن المؤقت كبيرًا بما يكفي. في الحالة الأخيرة، سيحتوي buf عادةً على نسخة مقطوعة من المعلومات (ولكن هذا السلوك غير مضمون). تحل هذه الدالة محل الدالة المهملة sprint_variable.

تقوم print_value، fprint_value، و snprint_value بنفس الشيء مثل روتينيات print_variable المكافئة، ولكنها تعرض فقط قيمة المتغير، دون معرف الكائن المقابل.

لعرض OID لرابط متغير، انظر netsnmp_mib_api(3).

الحذف

تقوم snmp_free_var بتحرير كل الذاكرة المستخدمة بواسطة بنية رابط المتغير المعطاة.
تقوم snmp_free_varbind بتحرير كل الذاكرة المستخدمة بواسطة كل بنية رابط متغير في قائمة روابط المتغيرات المقدمة.
