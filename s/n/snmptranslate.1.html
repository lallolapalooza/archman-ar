snmptranslate(1)

الحزمة: net-snmp

التراخيص: BSD

SNMPTRANSLATE(1) Net-SNMP SNMPTRANSLATE(1)

الاسم

snmptranslate - ترجمة أسماء معرفات OID لـ SNMP بين الأشكال الرقمية والنصية

السيناريو

snmptranslate [خيارات] OID [OID]...
snmptranslate [خيارات] -

الوصف

snmptranslate هو تطبيق يقوم بترجمة قيمة أو أكثر من معرفات كائنات SNMP من أشكالها الرمزية (النصية) إلى أشكالها الرقمية (أو العكس).

OID هو معرف كائن رقمي أو نصي.

الوسيط الخاص - يستخدم لترجمة معرفات الكائنات المتعددة في تشغيل واحد. يتم أخذ الإدخال من stdin، ويتم كتابة الإخراج إلى stdout. يمكن أن يكون تنسيق الإدخال معرف كائن واحد في كل سطر، أو يمكن أن يكون ناتج snmpwalk أو snmpget.

الخيارات

-D[TOKEN[,...]]
تشغيل مخرجات التصحيح للـ TOKEN المحدد (أو الرموز). جرب ALL لإخراج مفصل للغاية.
-h
عرض رسالة استخدام موجزة ثم الخروج.
-m MIBLIST
تحديد قائمة وحدات MIB مفصولة بنقطتين (:) لهذا التطبيق. هذا يتجاوز متغير البيئة MIBS.
تستخدم الكلمة المفتاحية الخاصة ALL لتحديد جميع الوحدات في جميع الدلائل عند البحث عن ملفات MIB. سيتم تحليل كل ملف لا يبدأ اسمه بـ "." كما لو كان ملف MIB.
-M DIRLIST
تحديد قائمة دلائل مفصولة بنقطتين (:) للبحث عن MIBs. هذا يتجاوز متغير البيئة MIBDIRS.
-T TRANSOPTS
يوفر تحكمًا في ترجمة قيم OID. TRANSOPTS التالية متاحة:
-TB
طباعة جميع الكائنات المطابقة للبحث عن تعبير عادي.
-Td
طباعة التفاصيل الكاملة لـ OID المحدد.
-Tp
طباعة شجرة رسومية، متجذرة عند OID المحدد.
-Ta
تفريغ MIB المحملة بشكل بسيط.
-Tl
تفريغ شكل موسوم لجميع الكائنات.
-To
تفريغ شكل رقمي لجميع الكائنات.
-Ts
تفريغ شكل رمزي لجميع الكائنات.
-Tt
تفريغ شكل شجري لـ MIBs المحملة (مفيد بشكل أساسي للتصحيح).
-Tz
تفريغ شكل رقمي وموسوم لجميع الكائنات (متوافق مع تنسيق MIB2SCHEMA).
-V
عرض معلومات الإصدار للتطبيق ثم الخروج.
-w WIDTH
تحديد عرض مخرجات -Tp و -Td. الافتراضي كبير جدًا.

بالإضافة إلى الخيارات المذكورة أعلاه، يأخذ snmptranslate خيارات إدخال OID (-I)، وتحليل MIB (-M)، وإخراج OID (-O) الموصوفة في أقسام خيارات الإدخال، خيارات تحليل MIB، و خيارات الإخراج من صفحة دليل snmpcmd(1).

أمثلة

•
snmptranslate -On -IR sysDescr
سيقوم بترجمة "sysDescr" إلى شكل أكثر تأهيلاً:
system.sysDescr
•
snmptranslate -Onf -IR sysDescr
سيقوم بترجمة "sysDecr" إلى:
.iso.org.dod.internet.mgmt.mib-2.system.sysDescr
•
snmptranslate -Td -OS system.sysDescr
سيقوم بترجمة "sysDecr" إلى:
SNMPv2-MIB::sysDescr
sysDescr OBJECT-TYPE
  -- FROM SNMPv2-MIB
  -- TEXTUAL CONVENTION DisplayString
  SYNTAX OCTET STRING (0..255)
  DISPLAY-HINT "255a"
  MAX-ACCESS read-only
  STATUS current
  DESCRIPTION "A textual description of the entity. This
               value should include the full name and
               version identification of the system's
               hardware type, software operating-system,
               and networking software."
::= { iso(1) org(3) dod(6) internet(1) mgmt(2) mib-2(1) system(1) 1 }
•
snmptranslate -Tp -OS system
سيقوم بطباعة الشجرة التالية:
