snmp-ups(8)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

التثبيت

لا يتم بناء هذا المشغل إلا إذا كانت ملفات تطوير Net-SNMP موجودة وقت التكوين. يمكنك أيضًا إجباره على البناء باستخدام configure --with-snmp=yes قبل استدعاء make.

أمثلة

يتم تحديد اسم مضيف UPS باستخدام قيمة "port" في ups.conf، وقد يتضمن منفذ نظير بعيد غير قياسي (161):

        [snmpv1]
                driver = snmp-ups
                port = snmp-ups.example.com
                community = public
                snmp_version = v1
                pollfreq = 15
                desc = "مثال لجهاز SNMP v1"
        [snmpv3]
                driver = snmp-ups
                port = 166.99.224.132:170
                snmp_version = v3
                secLevel = authPriv
                secName = mysecurityname
                authPassword = myauthenticationpassphrase
                privPassword = myprivatepassphrase
                desc = "مثال لجهاز SNMP v3، مع أعلى مستوى أمان"
