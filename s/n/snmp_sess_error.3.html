snmp_sess_error(3)

الحزمة: net-snmp

التراخيص: BSD

NAME

snmp_sess_error - retrieves error message string

SYNOPSIS 

#include <net-snmp/net-snmp-includes.h>

char *
snmp_sess_error(void);

DESCRIPTION

snmp_sess_error() returns a pointer to a static string describing the last SNMP session error encountered.

The string is not null-terminated and the pointer may be overwritten by subsequent calls to this function or other functions that might use the same internal buffer.

This function is usually called after an SNMP operation fails, for example, if snmp_open(3) returns NULL, or if snmp_send(3) returns 0.

DIAGNOSTICS

Possible error strings include:

SNMPERR_UNKNOWN_PDU
SNMPERR_TIMEOUT

الاسم

snmp_sess_error - استرداد سلسلة رسالة الخطأ

الملخص 

#include <net-snmp/net-snmp-includes.h>

char *
snmp_sess_error(void);

الوصف

snmp_sess_error() تعيد مؤشرًا إلى سلسلة ثابتة تصف آخر خطأ في جلسة SNMP تم اكتشافه.

السلسلة ليست منتهية بـ null والمؤشر قد يتم استبداله باستدعاءات لاحقة لهذه الوظيفة أو وظائف أخرى قد تستخدم نفس المخزن المؤقت الداخلي.

عادةً ما يتم استدعاء هذه الوظيفة بعد فشل عملية SNMP، على سبيل المثال، إذا أعادت snmp_open(3) قيمة NULL، أو إذا أعادت snmp_send(3) القيمة 0.

التشخيص

تشمل سلاسل الأخطاء المحتملة:

SNMPERR_UNKNOWN_PDU
SNMPERR_TIMEOUT
