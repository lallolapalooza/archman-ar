الوصف

تقع الوظائف التي تتعامل مع ربط المتغيرات في أربع مجموعات - تتعامل مع إنشاء، تعيين القيم، إخراج وحذف ربطات المتغيرات.

الإنشاء

ستقوم snmp_pdu_add_variable بإنشاء بنية ربط متغير جديدة، مع تهيئتها بالاسم ( objid، objidlen )، الصيغة ( type ) والقيمة ( value، len ) المقدمة. ثم يتم إضافة ربط المتغير هذا إلى نهاية قائمة ربطات المتغيرات في PDU المحدد.

snmp_varlist_add_variable مشابهة، لكنها تلحق ربط المتغير الجديد بنهاية قائمة ربطات المتغيرات المقدمة. عند إضافة ربط المتغير الأول إلى قائمة فارغة، قم ببساطة بتمرير عنوان رأس القائمة:


netsnmp_variable_list *vl = NULL;
snmp_varlist_add_variable(
&vl, name1, name1_len,
ASN_TYPE, &val1, val1_len);
snmp_varlist_add_variable(
&vl, name2, name2_len,
ASN_TYPE, &val2, val2_len);

في كلتا الحالتين، ستعيد الروتين مؤشرًا إلى بنية ربط المتغير الجديدة (أو NULL إذا فشل إنشاء ربط المتغير).

snmp_add_null_var هي وظيفة مساعدة لإضافة ربط متغير فارغ إلى PDU. دون الحاجة إلى تحديد قيمة NULL صراحة. هذه هي الآلية العادية لبناء طلب استرداد معلومات GET (أو ما شابه).
مرة أخرى، هذه تعيد مؤشرًا إلى ربط المتغير الجديد، أو NULL.

snmp_clone_varbind تنشئ نسخة من كل ربط متغير في القائمة المحددة، وتعيد مؤشرًا إلى رأس القائمة الجديدة (أو NULL إذا فشل الاستنساخ).

تعيين القيم

snmp_set_var_objid تحدد اسم بنية ربط المتغير إلى OID المحدد.
snmp_set_var_typed_value تحدد نوع الصيغة وقيمة بنية ربط المتغير.
snmp_set_var_value تحدد قيمة بنية ربط المتغير، تاركة نوع الصيغة بدون تغيير.
snmp_set_var_typed_integer هي وظيفة مساعدة لتحديد نوع الصيغة وقيمة لربط متغير قائم على أعداد صحيحة 32 بت.

جميع هذه الوظائف الأربعة تعيد 0 إذا نجح التعيين، أو 1 إذا لم ينجح.

الإخراج

print_variable ستأخذ معرّف كائن (كما تم إرجاعه بواسطة read_objid، snmp_parse_oid أو get_module_node) ومثيلًا لهذا المتغير، وتطبع إلى الإخراج القياسي الشكل النصي لمعرّف الكائن مع قيمة المتغير.

fprint_variable تفعل الشيء نفسه، ولكنها تطبع إلى مؤشر FILE المحدد بواسطة المعامل الأولي.

snprint_variable تطبع نفس المعلومات في المخزن المؤقت الذي يشير إليه buf والذي يبلغ طوله len. إنها تعيد عدد الأحرف المطبوعة، أو -1 إذا لم يكن المخزن المؤقت كبيرًا بما يكفي. في الحالة الأخيرة، سيحتوي buf عادةً على نسخة مقتطعة من المعلومات (لكن هذا السلوك غير مضمون). تحل هذه الوظيفة محل الوظيفة المهملة sprint_variable.

print_value، fprint_value، و snprint_value تفعل نفس الشيء مثل روتينيات print_variable المكافئة، ولكنها تعرض فقط قيمة المتغير، دون معرّف الكائن المقابل.

لعرض OID لربط متغير، انظر netsnmp_mib_api(3).

الحذف

snmp_free_var تحرر كل الذاكرة المستخدمة بواسطة بنية ربط المتغير المعطاة.
snmp_free_varbind تحرر كل الذاكرة المستخدمة بواسطة كل بنية ربط متغير في قائمة ربطات المتغيرات المقدمة.
