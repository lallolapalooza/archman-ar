skopeo-list-tags(1)

الحزمة: skopeo

التراخيص: Apache-2.0

skopeo-list-tags(1)() skopeo-list-tags(1)()

الاسم

skopeo-list-tags - سرد أسماء الصور في مجموعة صور خاصة بالنقل.

الموجز

skopeo list-tags [خيارات] مصدر-الصورة

إرجاع قائمة بالعلامات من مصدر-الصورة في مستودع أو ملف docker-archive محلي.

مصدر-الصورة اسم المستودع لاسترداد قائمة العلامات منه أو ملف docker-archive محلي.

الخيارات

انظر أيضًا skopeo(1) للخيارات الموضوعة قبل اسم الأمر الفرعي.

--authfile مسار

مسار ملف بيانات اعتماد المستودع المحدثة. في لينكس، الافتراضي هو ${XDG_RUNTIME_DIR}/containers/auth.json. انظر containers-auth.json(5) لمزيد من التفاصيل حول آلية البحث عن بيانات الاعتماد والافتراضيات على المنصات الأخرى.

استخدم skopeo login لإدارة بيانات الاعتماد.

تمت قراءة القيمة الافتراضية لهذا الخيار من متغير البيئة REGISTRY\_AUTH\_FILE.

--creds اسم_المستخدم[:كلمة_المرور] للوصول إلى المستودع.

--cert-dir مسار

استخدام الشهادات في مسار (*.crt, *.cert, *.key) للاتصال بالمستودع.

--help, -h

طباعة بيان الاستخدام

--no-creds

الوصول إلى المستودع بشكل مجهول.

--registry-token رمز Bearer

رمز Bearer للوصول إلى المستودع.

--retry-times

عدد مرات إعادة المحاولة.

--retry-delay

تأخير ثابت بين المحاولات. إذا لم يتم تعيينه (أو تم تعيينه على 0 ثانية)، سيتم زيادة وقت الانتظار لإعادة المحاولة بشكل أسي بناءً على عدد المحاولات الفاشلة.

--tls-verify=قيمة_منطقية

طلب HTTPS والتحقق من الشهادات عند التحدث إلى مستودع أو خادم الحاوية. الافتراضي هو إعداد registry.conf.

--username

اسم المستخدم للوصول إلى المستودع.

--password

كلمة المرور للوصول إلى المستودع.

أسماء_المستودعات

أسماء المستودعات هي مراجع خاصة بالنقل حيث قد يكون لكل نقل مفهومه الخاص لـ "المستودع" و "العلامات".

يشير هذا الأمر إلى المستودعات باستخدام تنسيق نقل:تفاصيل. التنسيقات التالية مدعومة:

docker://مرجع-مستودع-docker
مستودع في مستودع ينفذ "Docker Registry HTTP API V2".
مرجع-مستودع-docker هو من الشكل: اسم-مستضيف-المستودع:المنفذ/اسم-المستودع وهو مشابه لـ مرجع-الصورة ولكن لا يُسمح بأي علامة أو هضم كمكون أخير (على سبيل المثال، لا يوجد :latest أو @sha256:xyz)

  أمثلة لمرجع-مستودع-docker صالحة:
    "docker.io/myuser/myrepo"
    "docker.io/nginx"
    "docker.io/library/fedora"
    "localhost:5000/myrepository"
  أمثلة لمراجع غير صالحة:
    "docker.io/nginx:latest"
    "docker.io/myuser/myimage:v1.0"
    "docker.io/myuser/myimage@sha256:f48c4cc192f4c3c6a069cb5cca6d0a9e34d6076ba7c214fd0cc3ca60e0af76bb"

**docker-archive:مسار[:مرجع-docker]
تم تخزين أكثر من صورة واحدة في ملف بتنسيق docker save.

أمثلة

نقل Docker

للحصول على قائمة العلامات في مستودع "fedora" من مستودع docker.io (يتوسع اسم المستودع إلى "library/fedora" وفقًا للشكل القياسي لنقل docker):

$ skopeo list-tags docker://docker.io/fedora
{
    "Repository": "docker.io/library/fedora",
    "Tags": [
        "20",
        "21",
        "22",
        "23",
        "24",
        "25",
        "26-modular",
        "26",
        "27",
        "28",
        "29",
        "30",
        "31",
        "32",
        "branched",
        "heisenbug",
        "latest",
        "modular",
        "rawhide"
    ]
}

لسرد العلامات في مستودع docker/distribution محلي على المنفذ 5000، في هذه الحالة لمستودع "fedora":

$ skopeo list-tags docker://localhost:5000/fedora
{
    "Repository": "localhost:5000/fedora",
    "Tags": [
        "latest",
        "30",
        "31"
    ]
}

نقل Docker-archive

لسرد العلامات في ملف docker-archive محلي:

$ skopeo list-tags docker-archive:/tmp/busybox.tar.gz
{
    "Tags": [
        "busybox:1.28.3"
    ]
}

يدعم أيضًا أكثر من علامة واحدة في أرشيف:

$ skopeo list-tags docker-archive:/tmp/docker-two-images.tar.gz
{
    "Tags": [
        "example.com/empty:latest",
        "example.com/empty/but:different"
    ]
}

سيشمل إدخال مصدر-الفهرس لكل صورة غير معلمة:

$ skopeo list-tags docker-archive:/tmp/four-tags-with-an-untag.tar
{
    "Tags": [
        "image1:tag1",
        "image2:tag2",
        "@2",
        "image4:tag4"
    ]
}
