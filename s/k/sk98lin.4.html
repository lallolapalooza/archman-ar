Linux Networking

NAME

sk98lin — Realtek 8129/8130/8139 Ethernet driver

SYNOPSIS

sk98lin

DESCRIPTION

The sk98lin driver is a Linux kernel module for the Realtek 8129, 8130, 8139, and 8139too Ethernet adapters.

FILES

/lib/modules/$(uname -r)/kernel/drivers/net/ethernet/realtek/sk98lin.ko

BUGS

Refer to the kernel source for bug reports.

SEE ALSO

etherboot(4), ifconfig(8), ip(8), netstat(8), route(8), modinfo(8), insmod(8), modprobe(8)
