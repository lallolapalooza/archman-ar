الحزمة: skate

التراخيص: MIT

SKATE(1) Skate، مخزن شخصي للقيمة المفتاحية. SKATE(1)

الاسم

skate - Skate، مخزن شخصي للقيمة المفتاحية.

الملخص

skate [خيارات...] [وسيط...]

الوصف

الأوامر

delete KEY[@DB]
حذف مفتاح مع قاعدة بيانات اختيارية @ db.
delete-db [@DB]
حذف قاعدة بيانات
get KEY[@DB]
الحصول على قيمة لمفتاح مع قاعدة بيانات اختيارية @ db.
خيارات
--b --show-binary طباعة القيم الثنائية
help [أمر]
مساعدة حول أي أمر
list [@DB]
سرد أزواج المفتاح والقيمة مع قاعدة بيانات اختيارية @ db.
خيارات
--d --delimiter فاصل للفصل بين المفاتيح والقيم
--k --keys-only
طباعة المفاتيح فقط وعدم جلب القيم من قاعدة البيانات
--r --reverse
سرد بترتيب معكوس أبجدي
--b --show-binary
طباعة القيم الثنائية
--v --values-only
طباعة القيم فقط
list-dbs
سرد قواعد البيانات.
set KEY[@DB] [VALUE]
تعيين قيمة لمفتاح مع قاعدة بيانات اختيارية @ db. إذا تم حذف VALUE، اقرأ القيمة من الإدخال القياسي.
