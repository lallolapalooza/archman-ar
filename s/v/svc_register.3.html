ينشئ هذا الروتين مقبض نقل خدمة RPC قائم على UDP/IP، ويعيد إليه مؤشرًا. يرتبط النقل بالمقبس sock، والذي قد يكون RPC_ANYSOCK، وفي هذه الحالة يتم إنشاء مقبس جديد. إذا لم يكن المقبس مرتبطًا بمنفذ UDP محلي، يقوم هذا الروتين بربطه بمنفذ عشوائي. عند الانتهاء، يكون xprt->xp_sock هو واصف مقبس النقل، و xprt->xp_port هو رقم منفذ النقل. يعيد هذا الروتين NULL إذا فشل.
هذا يسمح للمستخدم بتحديد الحد الأقصى لحجم الحزمة لإرسال واستقبال رسائل RPC المستندة إلى UDP.

NAME

svc_register, svc_unregister, xprt_register, xprt_unregister - register and unregister RPC dispatchers and transport handles

LIBRARY

Portability Functions (-lport)

SYNOPSIS AND DESCRIPTION

#include <rpc/rpc.h>
void svc_register(SVCXPRT *xprt,
    const char *prognum,
    u_long versnum,
    void (*dispatch)(struct svc_req *, SVCXPRT *),
    int nettype);
Register a service with the RPC package. The xprt argument is a transport handle created by one of the svc*_create routines. The prognum argument is the program number assigned to the service. The versnum argument is the version number of the service. The dispatch argument is a pointer to the routine that dispatches calls for this service. The nettype argument specifies the desired network type. This routine modifies the global variable svc_fds. Service implementors usually do not need this routine.
void svc_unregister(const char *prognum,
    u_long versnum);
Unregister a service from the RPC package. The prognum argument is the program number, and versnum is the version number of the service to unregister. This routine modifies the global variable svc_fds. Service implementors usually do not need this routine.

void xprt_register(SVCXPRT *xprt);
After RPC service transport handles are created, they should register themselves with the RPC service package. This routine modifies the global variable svc_fds. Service implementors usually do not need this routine.

Before an RPC service transport handle is destroyed, it should unregister itself with the RPC service package. This routine modifies the global variable svc_fds. Service implementors usually do not need this routine.
