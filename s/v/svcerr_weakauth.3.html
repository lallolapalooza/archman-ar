ماكرو يقوم بنسخ بنية الخطأ من مقبض العميل إلى البنية الموجودة في العنوان errp.
void clnt_pcreateerror(const char *s);
يطبع رسالة إلى الخطأ القياسي توضح سبب عدم إنشاء مقبض عميل RPC. تسبق الرسالة السلسلة s ونقطتين. تستخدم عند فشل استدعاء clnt_create() أو clntraw_create() أو clnttcp_create() أو clntudp_create().
void clnt_perrno(enum clnt_stat stat);
يطبع رسالة إلى الخطأ القياسي تتوافق مع الحالة التي تشير إليها stat. تستخدم بعد callrpc().
clnt_perror(CLIENT *clnt, const char *s);
يطبع رسالة إلى الخطأ القياسي توضح سبب فشل استدعاء RPC؛ clnt هو المقبض المستخدم لإجراء الاستدعاء. تسبق الرسالة السلسلة s ونقطتين. تستخدم بعد clnt_call().
char *clnt_spcreateerror(const char *s);
مثل clnt_pcreateerror()، ولكنها ترجع سلسلة بدلاً من الطباعة إلى الخطأ القياسي.
الأخطاء: ترجع مؤشرًا إلى بيانات ثابتة يتم الكتابة فوقها في كل استدعاء.
char *clnt_sperrno(enum clnt_stat stat);
تأخذ نفس وسائط clnt_perrno()، ولكن بدلاً من إرسال رسالة إلى الخطأ القياسي توضح سبب فشل استدعاء RPC، ترجع مؤشرًا إلى سلسلة تحتوي على الرسالة. تنتهي السلسلة بسطر جديد.
clnt_sperrno() تستخدم بدلاً من clnt_perrno() إذا لم يكن لدى البرنامج خطأ قياسي (كما هو الحال غالبًا مع برنامج يعمل كخادم) ، أو إذا لم يكن المبرمج يريد إخراج الرسالة باستخدام printf(3)، أو إذا كان سيتم استخدام تنسيق رسالة مختلف عن الذي تدعمه clnt_perrno(). ملاحظة: على عكس clnt_sperror() و clnt_spcreateerror()، ترجع clnt_sperrno() مؤشرًا إلى بيانات ثابتة، ولكن لن يتم الكتابة فوق النتيجة في كل استدعاء.
char *clnt_sperror(CLIENT *rpch, const char *s);
مثل clnt_perror()، ولكن (مثل clnt_sperrno()) ترجع سلسلة بدلاً من الطباعة إلى الخطأ القياسي.
الأخطاء: ترجع مؤشرًا إلى بيانات ثابتة يتم الكتابة فوقها في كل استدعاء.
CLIENT *clntraw_create(unsigned long prognum, unsigned long versnum);
يقوم هذا الروتين بإنشاء عميل RPC وهمي للبرنامج البعيد prognum، الإصدار versnum. النقل المستخدم لتمرير الرسائل إلى الخدمة هو في الواقع مخزن مؤقت داخل مساحة عنوان العملية، لذلك يجب أن يعيش خادم RPC المقابل في نفس مساحة العنوان؛ انظر svcraw_create(). هذا يسمح بمحاكاة RPC واكتساب النفقات العامة لـ RPC، مثل أوقات الذهاب والإياب، دون أي تدخل من النواة. يرجع هذا الروتين NULL إذا فشل.
CLIENT *clnttcp_create(struct sockaddr_in *addr,
                unsigned long prognum, unsigned long versnum,
                int *sockp, unsigned int sendsz, unsigned int recvsz);
يقوم هذا الروتين بإنشاء عميل RPC للبرنامج البعيد prognum، الإصدار versnum؛ يستخدم العميل TCP/IP كوسيلة نقل. يقع البرنامج البعيد في عنوان الإنترنت *addr. إذا كان addr->sin_port صفرًا، فسيتم تعيينه إلى المنفذ الفعلي الذي يستمع عليه البرنامج البعيد (يتم استشارة خدمة portmap البعيدة لهذه المعلومات). المعلمة sockp هي مقبس؛ إذا كانت RPC_ANYSOCK، فسيفتح هذا الروتين مقبسًا جديدًا ويقوم بتعيين sockp. نظرًا لأن RPC المستند إلى TCP يستخدم إدخال/إخراج مخزن مؤقتًا، يمكن للمستخدم تحديد حجم مخازن الإرسال والاستقبال باستخدام المعلمتين sendsz و recvsz؛ القيم الصفرية تختار القيم الافتراضية المناسبة. يرجع هذا الروتين NULL إذا فشل.
CLIENT *clntudp_create(struct sockaddr_in *addr,
                unsigned long prognum, unsigned long versnum,
                struct timeval wait, int *sockp);
يقوم هذا الروتين بإنشاء عميل RPC للبرنامج البعيد prognum، الإصدار versnum؛ يستخدم العميل UDP/IP كوسيلة نقل. يقع البرنامج البعيد في عنوان الإنترنت addr. إذا كان addr->sin_port صفرًا، فسيتم تعيينه إلى المنفذ الفعلي الذي يستمع عليه البرنامج البعيد (يتم استشارة خدمة portmap البعيدة لهذه المعلومات). المعلمة sockp هي مقبس؛ إذا كانت RPC_ANYSOCK، فسيفتح هذا الروتين مقبسًا جديدًا ويقوم بتعيين sockp. يعيد نقل UDP إرسال رسالة الاستدعاء بفواصل زمنية قدرها wait حتى يتم استلام استجابة أو حتى ينتهي وقت استدعاء الاستدعاء. الوقت الإجمالي لانقضاء وقت الاستدعاء محدد بواسطة clnt_call().

bool_t pmap_set(unsigned long prognum, unsigned long versnum,
                int protocol, unsigned short port);

bool_t pmap_unset(unsigned long prognum, unsigned long versnum);

int registerrpc(unsigned long prognum, unsigned long versnum,
                unsigned long procnum, typeof(char *(char *)) *procname,
                xdrproc_t inproc, xdrproc_t outproc);
يسجل الإجراء procname مع حزمة خدمة RPC. إذا وصل طلب للبرنامج prognum، الإصدار versnum، والإجراء procnum، يتم استدعاء procname مع مؤشر إلى وسيطته (وسائطه)؛ يجب أن ترجع procname مؤشرًا إلى نتائجه الثابتة (نتائجه)؛ يتم استخدام inproc لفك تشفير الوسائط بينما يتم استخدام outproc لتشفير النتائج. يرجع هذا الروتين صفرًا إذا نجح التسجيل، -1 إذا فشل.

void svcerr_weakauth(XDR *xdrs);
Used for rejecting RPC requests due to weak authentication. This routine is useful for users who wish to generate RPC-style messages without using the RPC package.
void svcerr_systemerr(XDR *xdrs);
Used for rejecting RPC requests due to system errors. This routine is useful for users who wish to generate RPC-style messages without using the RPC package.
void svcerr_progvers(XDR *xdrs);
Used for rejecting RPC requests due to incompatible program versions. This routine is useful for users who wish to generate RPC-style messages without using the RPC package.
void svcerr_noprog(XDR *xdrs);
Used for rejecting RPC requests due to unknown program numbers. This routine is useful for users who wish to generate RPC-style messages without using the RPC package.
void svcerr_noproc(XDR *xdrs);
