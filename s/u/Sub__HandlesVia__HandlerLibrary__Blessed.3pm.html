Sub__HandlesVia__HandlerLibrary__Blessed(3pm)

الحزمة: perl-sub-handlesvia

التراخيص: PerlArtistic, GPL

Sub::HandlesVia::HandlerLibrary::Blessed(3) وثائق Perl التي ساهم بها المستخدم Sub::HandlesVia::HandlerLibrary::Blessed(3)

الاسم

Sub::HandlesVia::HandlerLibrary::Blessed - مكتبة طرق متعلقة بالكائنات

الملخص

package My::Class {
  use Moo;
  use Sub::HandlesVia;
  use Types::Standard 'Object';
  use HTTP::Tiny;
  has http_ua => (
    is => 'rwp',
    isa => Object,
    handles_via => 'Blessed',
    handles => {
      'http_get'  => 'get',
      'http_post' => 'post',
    },
    default => sub { HTTP::Tiny->new },
  );
}

الوصف

هذه مكتبة طرق لـ Sub::HandlesVia.

الطرق القابلة للتفويض

على عكس المكتبات الأخرى التي توفرها Sub::HandlesVia، تسمح لك هذه المكتبة بتفويض أي اسم طريقة.

تفترض أن قيمة الخاصية هي كائن مبارك، وتقوم باستدعاء الطريقة المسماة بالمقابل عليه.

Moo، Moose، Mouse، و Mite كلها لديها هذا النوع من التفويض مدمج على أي حال، ولكن هذه الوحدة تسمح لك بإجراء التفويض باستخدام Sub::HandlesVia. قد يكون هذا مفيدًا لـ Object::Pad و Class::Tiny، والتي لا تحتوي على ميزة تفويض مدمجة.
