subst(n)

الحزمة: tcl

التراخيص: TCL

subst(n) أوامر Tcl المدمجة subst(n)

الاسم

subst - تنفيذ استبدالات الشرطة المائلة العكسية، الأوامر، والمتغيرات

ملخص

subst ?-nobackslashes? ?-nocommands? ?-novariables? string

الوصف

يقوم هذا الأمر بتنفيذ استبدالات المتغيرات، واستبدالات الأوامر، واستبدالات الشرطة المائلة العكسية على وسيط string الخاص به ويعيد النتيجة المستبدلة بالكامل. يتم إجراء الاستبدالات بنفس الطريقة تمامًا كما هو الحال بالنسبة لأوامر Tcl. ونتيجة لذلك، يتم استبدال الوسيط string مرتين، مرة بواسطة محلل Tcl بالطريقة المعتادة لأوامر Tcl، ومرة أخرى بواسطة الأمر subst.

إذا تم تحديد أي من الخيارات -nobackslashes أو -nocommands أو -novariables، فلن يتم إجراء الاستبدالات المقابلة. على سبيل المثال، إذا تم تحديد -nocommands، فلن يتم إجراء استبدال الأوامر: يتم التعامل مع الأقواس المفتوحة والمغلقة كأحرف عادية بدون تفسير خاص.

لاحظ أن استبدال نوع واحد يمكن أن يتضمن استبدال أنواع أخرى. على سبيل المثال، حتى عند تحديد الخيار -novariables، يتم إجراء استبدال الأوامر دون قيود. هذا يعني أنه سيتم إجراء أي استبدال للمتغيرات اللازمة لإكمال الأمر المستبدل. وبالمثل، سيتم إجراء أي استبدال للأوامر اللازم لإكمال استبدال المتغير، حتى عند تحديد -nocommands. انظر أمثلة أدناه.

إذا حدث خطأ أثناء الاستبدال، فسيعيد subst هذا الخطأ. إذا حدث استثناء break أثناء استبدال الأوامر أو المتغيرات، فستكون نتيجة الاستبدال بأكمله هي السلسلة (كما تم استبدالها) حتى بداية الاستبدال الذي أثار الاستثناء. إذا حدث استثناء continue أثناء تقييم استبدال أمر أو متغير، فسيتم استبدال سلسلة فارغة بهذا الاستبدال الكامل للأمر أو المتغير (طالما أنه Tcl جيد التكوين). إذا حدث استثناء return، أو تم إرجاع أي رمز إرجاع آخر أثناء استبدال أمر أو متغير، فسيتم استبدال القيمة المرجعة بهذا الاستبدال. انظر أمثلة أدناه. بهذه الطريقة، يتم "احتواء" جميع رموز الإرجاع الاستثنائية بواسطة subst. سيقوم الأمر subst نفسه إما بإرجاع خطأ، أو سيكمل بنجاح.

أمثلة

عندما يقوم بتنفيذ استبدالاته، لا يعطي subst أي معاملة خاصة للاقتباس المزدوج أو الأقواس المعقوفة (باستثناء داخل استبدالات الأوامر) لذا النص البرمجي

set a 44
subst {xyz {$a}}

يعيد "xyz {44}"، وليس "xyz {$a}" والنص البرمجي

set a "p\} q \{r"
subst {xyz {$a}}

يعيد "xyz {p} q {r}"، وليس "xyz {p\} q \{r}".

عند إجراء استبدال الأوامر، فإنه يتضمن أي استبدال متغيرات ضروري لتقييم النص البرمجي.

set a 44
subst -novariables {$a [format $a]}

يعيد "$a 44"، وليس "$a $a". وبالمثل، عند إجراء استبدال المتغيرات، فإنه يتضمن أي استبدال أوامر ضروري لاسترداد قيمة المتغير.

proc b {} {return c}
array set a {c c [b] tricky}
subst -nocommands {[b] $a([b])}

يعيد "[b] c"، وليس "[b] tricky".

تسمح استثناءات continue و break لاستبدالات الأوامر بمنع استبدال بقية استبدال الأمر وبقية string على التوالي، مما يمنح مؤلفي النصوص البرمجية المزيد من الخيارات عند معالجة النص باستخدام subst. على سبيل المثال، النص البرمجي

subst {abc,[break],def}

يعيد "abc,"، وليس "abc,,def" والنص البرمجي

subst {abc,[continue;expr {1+2}],def}

يعيد "abc,,def"، وليس "abc,3,def".

تقوم رموز الإرجاع الاستثنائية الأخرى باستبدال القيمة المرجعة

subst {abc,[return foo;expr {1+2}],def}

يعيد "abc,foo,def"، وليس "abc,3,def" و

subst {abc,[return -code 10 foo;expr {1+2}],def}

يعيد أيضًا "abc,foo,def"، وليس "abc,3,def".
