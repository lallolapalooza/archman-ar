SUFFIXES(7) دليل المعلومات المتنوعة SUFFIXES(7)

الاسم

suffixes - قائمة لاحقات الملفات

الوصف

من المعتاد الإشارة إلى محتويات الملف باستخدام لاحقة الملف، والتي (عادةً) تتكون من نقطة، متبوعة بحرف واحد أو أكثر. تستخدم العديد من الأدوات القياسية، مثل المترجمات، هذا لتحديد نوع الملف الذي تتعامل معه. الأداة make(1) مدفوعة بقواعد تعتمد على لاحقة الملف.

فيما يلي قائمة باللواحق التي من المحتمل أن تجدها في نظام Linux.

اللاحقة نوع الملف
,v ملفات لنظام RCS (نظام التحكم في المراجعة)
- ملف احتياطي
.C كود مصدر C++، مكافئ لـ .cc
.F مصدر Fortran مع توجيهات cpp(1)
أو ملف مضغوط باستخدام freeze
.S مصدر مجمّع مع توجيهات cpp(1)
.Y ملف مضغوط باستخدام yabba
.Z ملف مضغوط باستخدام compress(1)
.[0-9]+gf ملفات خطوط TeX العامة
.[0-9]+pk ملفات خطوط TeX المعبأة
.[1-9] صفحة دليل للقسم المقابل
.[1-9][a-z] صفحة دليل للقسم بالإضافة إلى القسم الفرعي
.a مكتبة كود ثابتة
.ad ملف موارد تطبيق X
.ada مصدر Ada (قد يكون جسدًا، أو مواصفات، أو مزيجًا)
.adb مصدر جسد Ada
.ads مصدر مواصفات Ada
.afm مقاييس خطوط PostScript
.al ملف Perl تلقائي التحميل

.arc أرشيف arc(1)
.arj أرشيف arj(1)
.asc بيانات PGP المشفرة بنظام ASCII
.asm ملف مصدر مجمّع (GNU)
.au ملف صوتي
.aux ملف مساعد LaTeX
.avi فيلم (msvideo)
.awk برنامج بلغة AWK
.b صورة محمل إقلاع LILO
.bak ملف احتياطي
.bash سكريبت شل bash(1)
.bb بيانات قائمة القطع الأساسية الناتجة عن

gcc -ftest-coverage

.bdf ملف خط X

.bm مصدر نقطة الارتكاز
.bmp نقطة الارتكاز
.bz2 ملف مضغوط باستخدام bzip2(1)
.c مصدر C

.cc مصدر C++
.cf ملف إعدادات
.cfg ملف إعدادات
.cgi سكريبت أو برنامج لتوليد محتوى WWW
.cls تعريف فئة LaTeX
.class كود بايت Java مجمّع
.conf ملف إعدادات
.config ملف إعدادات
.cpp مكافئ لـ .cc
.csh سكريبت شل csh(1)
.cxx مكافئ لـ .cc
.dat ملف بيانات
.deb حزمة برامج Debian
.def مصدر Modula-2 لوحدات التعريف

.desc الجزء الأولي من رسالة بريد تم فك ضغطها باستخدام

.dir ملف دليل قاعدة بيانات dbm
