Sub__HandlesVia__Manual__WithGeneric(3pm)

الحزمة: perl-sub-handlesvia

التراخيص: PerlArtistic, GPL

Sub::HandlesVia::Manual::WithGeneric(3) وثائق Perl المساهمة من المستخدم Sub::HandlesVia::Manual::WithGeneric(3)

الاسم

Sub::HandlesVia::Manual::WithGeneric - استخدام Sub::HandlesVia مع فئات Perl العامة

دليل

يسمح لك Sub::HandlesVia بتفويض الدوال من فئتك إلى قيم سمات كائناتك.

من الناحية المفاهيمية، يسمح لك بتعريف "$object->push_number($n)" كاختصار لـ "$object->numbers->push($n)" باستثناء أن "$object->numbers" هو مصفوفة، وبالتالي لا يحتوي على دوال يمكنك استدعاؤها عليه مثل "push".

بالنسبة لـ Moose و Mouse، يمكن لـ Sub::HandlesVia استخدام بروتوكولات كائناتهم الوصفية للحصول على تعريف سمة وتثبيت الدوال التي يحتاجها. بالنسبة لـ Moo، يمكنه تغليف "has" والقيام بأعماله بهذه الطريقة. بالنسبة للفئات الأخرى، تحتاج إلى أن تكون أكثر وضوحًا وتخبره بالدوال التي يجب تفويضها إلى أي سمات.

package Kitchen {

  # المنشئ
  sub new {
    my ( $class, %arg ) = @_;
    $arg{food} ||= [];
    return bless( \%arg, $class );
  }

  # جالب/مُعين لـ `food`
  sub food {
    (@_ == 1) ? $_[0]{food} : ( $_[0]{food} = $_[1] );
  }

  use Sub::HandlesVia qw( delegations );

  delegations(
    attribute   => 'food'
    handles_via => 'Array',
    handles     => {
      'add_food'    => 'push',
      'find_food'   => 'grep',
    },
  );
}

تعيين "attribute" إلى "food" يعني أنه عندما يحتاج Sub::HandlesVia إلى الحصول على قائمة الطعام، فإنه سيستدعي "$kitchen->food" وعندما يحتاج إلى تعيين قائمة الطعام، فإنه سيستدعي "$kitchen->food($value)". إذا كان لديك دوال جالب ومُعين منفصلة، فما عليك سوى القيام بما يلي:

attribute   => [ 'get_food', 'set_food' ],

أو إذا لم يكن لديك أي مُلحقات وتريد من Sub::HandlesVia الوصول مباشرة إلى الهاشريف الأساسي:

attribute   => '{food}',

أو ربما لديك مُعين، ولكنك تريد استخدام الوصول إلى الهاشريف للجالب:

attribute   => [ '{food}', 'set_food' ],

أو ربما لا تزال تريد الوصول المباشر للجالب، ولكن كائنك عبارة عن مصفوفة مُباركة بدلاً من هاشريف مُبارك:

attribute   => [ '[7]', 'set_food' ],

أو ربما تكون احتياجاتك فريدة للغاية:

attribute   => [ \&getter, \&setter ],

يتم تمرير مراجع الشفرة كأول وسيط لها الكائن، ويتم تمرير المُعين أيضًا بقيمة لتعيينها.

حقًا، لا أعتقد أن هناك نظام كائنات لن يعمل معه هذا!

إذا قمت بتوفير مصفوفة تحتوي على جالب ومُعين، فمن الممكن أيضًا توفير وسيط ثالث وهو مرجع شفرة أو سلسلة نصية سيتم استدعاؤها كدالة عند الحاجة إلى "إعادة تعيين" القيمة. يمكن اعتبار هذا كقيمة افتراضية أو مُنشئ.

(يمكن استيراد الدالة "delegations" إلى فئات Moo/Mouse/Moose أيضًا، وفي هذه الحالة يجب أن يكون "attribute" هو نفس اسم السمة الذي مررته إلى "has". لا يمكنك استخدام مصفوفة، مرجع شفرة، مفتاح هاش، أو فهرس مصفوفة.)
