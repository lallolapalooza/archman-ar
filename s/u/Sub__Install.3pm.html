الاسم

Sub::Install - Perl module for installing subroutines

الملخص

use Sub::Install;

my $installer = Sub::Install->new(
    package   => 'My::Module',
    from_perl => 1,
);

$installer->install;

الوصف

The Sub::Install module provides a way to install subroutines into a Perl package. This is particularly useful for creating modules that dynamically generate or install subroutines.

الدوال

new(%args)
Constructor for Sub::Install. Accepts a hash of arguments to configure the installation.
install()
Performs the installation of subroutines into the target package.

أمثلة

A simple example of using Sub::Install to install a subroutine named hello_world into the My::Module package:

package My::Module;

use strict;
use warnings;

use Sub::Install;

sub hello_world {
    print "Hello, World!\n";
}

my $installer = Sub::Install->new(
    package   => 'My::Module',
    subroutines => {
        'say_hello' => \&hello_world,
    },
);

$installer->install;

# Now you can call My::Module::say_hello
# My::Module::say_hello();
