suexec(8)

الحزمة: apache

التراخيص: Apache-2.0

SUEXEC(8) suexec SUEXEC(8)

الاسم

suexec - تبديل المستخدم قبل تنفيذ البرامج الخارجية

الاستخدام

suexec -V

الملخص

يستخدم suexec بواسطة خادم Apache HTTP للتبديل إلى مستخدم آخر قبل تنفيذ برامج CGI. لتحقيق ذلك، يجب تشغيله كـ root. بما أن خادم HTTP عادة لا يعمل كـ root، فإن الملف التنفيذي suexec يحتاج إلى تعيين بت تعيين المستخدم (setuid bit) ويجب أن يكون مملوكًا لـ root. يجب ألا يكون قابلاً للكتابة لأي شخص بخلاف root.

لمزيد من المعلومات حول مفاهيم ونموذج الأمان لـ suexec، يرجى الرجوع إلى وثائق suexec (http://httpd.apache.org/docs/2.4/suexec.html).

الخيارات

-V
إذا كنت root، فإن هذا الخيار يعرض خيارات الترجمة لـ suexec. لأسباب أمنية، جميع خيارات التكوين قابلة للتغيير فقط وقت الترجمة.
