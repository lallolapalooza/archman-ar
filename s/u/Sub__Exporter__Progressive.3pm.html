Sub__Exporter__Progressive(3pm)

الحزمة: perl-sub-exporter-progressive

التراخيص: PerlArtistic, GPL

Sub::Exporter::Progressive(3) توثيق Perl مقدم من المستخدم Sub::Exporter::Progressive(3)

الاسم

Sub::Exporter::Progressive - استخدم Sub::Exporter فقط إذا كنت بحاجة إليها

الإصدار

version 0.001013

ملخص

package Syntax::Keyword::Gather;
use Sub::Exporter::Progressive -setup => {
  exports => [qw( break gather gathered take )],
  groups => {
    default => [qw( break gather gathered take )],
  },
};
# في مكان آخر
# يستخدم Exporter للسرعة
use Syntax::Keyword::Gather;
# في مكان آخر
# يستخدم Sub::Exporter للميزات
use Syntax::Keyword::Gather 'gather', take => { -as => 'grab' };

الوصف

Sub::Exporter هي وحدة قوية بشكل لا يصدق، ولكن مع تلك القوة تأتي مسؤولية عظيمة، حسنًا - بالإضافة إلى بعض العقوبات وقت التشغيل. هذه الوحدة هي غلاف لـ "Sub::Exporter" ستسمح لمستخدميك باستخدام Exporter فقط إذا كانوا يقومون فقط باختيار المصدرات، ولكن استخدم "Sub::Exporter" إذا حاول المستخدمون استخدام الميزات الأكثر تقدمًا في "Sub::Exporter"، مثل إعادة تسمية المصدرات، إذا حاولوا استخدامها.

لاحظ أن هذه الوحدة ستصدر متغيرات الحزمة @EXPORT و @EXPORT_OK و %EXPORT_TAGS لكي تعمل "Exporter". بالإضافة إلى ذلك، إذا كانت حزمتك تستخدم ميزات "Sub::Exporter" المتقدمة مثل currying، فإن هذه الوحدة ستستخدم دائمًا "Sub::Exporter"، لذلك قد ترغب في استخدامها مباشرة.
