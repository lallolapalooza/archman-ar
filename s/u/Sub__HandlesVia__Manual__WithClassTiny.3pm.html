Sub__HandlesVia__Manual__WithClassTiny(3pm)

الحزمة: perl-sub-handlesvia

التراخيص: PerlArtistic, GPL

Sub::HandlesVia::Manual::WithClassTiny(3) وثائق بيرل من مساهمة المستخدم Sub::HandlesVia::Manual::WithClassTiny(3)

الاسم

Sub::HandlesVia::Manual::WithClassTiny - استخدام Sub::HandlesVia مع Class::Tiny

الملخص

package Kitchen;

use Class::Tiny {
  foods  => sub { [] },
  drinks => sub { [ 'water' ] },
};

use Sub::HandlesVia::Declare 'foods', Array => (
  all_foods  => 'all',
  add_food   => 'push',
);

use Sub::HandlesVia::Declare 'drinks', Array => (
  all_drinks => 'all',
  add_drink  => 'push',
);

يدوي

يتيح لك Sub::HandlesVia تفويض استدعاءات الوظائف من فئتك إلى قيم السمات الكائنية.

من الناحية المفاهيمية، يسمح لك بتعريف "$object->push_number($n)" كاختصار لـ "$object->numbers->push($n)" باستثناء أن "$object->numbers" هو مرجع مصفوفة، لذلك لا يحتوي على وظائف يمكنك استدعاؤها عليه مثل "push".

ما هي الوظائف التي يمكن تفويضها إليها؟

المعلمة الثانية ( "Array" في الملخص) تشير إلى أي مكتبة من الوظائف يجب أن تكون متاحة. القيم الصالحة تشمل Array، Blessed، Bool، Code، Counter، Enum، Hash، Number، Scalar، و String.

يمكن توفير مرجع مصفوفة، على الرغم من أن العديد من الخيارات متناقضة مفاهيميًا.

use Sub::HandlesVia::Declare 'num', [ 'Number', 'Scalar' ] => (
  ...,
);

تفويض وقت التشغيل

بدلاً من استخدام Sub::HandlesVia::Declare الذي يعمل في وقت الترجمة، يمكنك استخدام وظيفة "delegations" في وقت التشغيل. ما تختاره هو إلى حد كبير مسألة أسلوب وتفضيل شخصي.

package Kitchen;

use Class::Tiny {
  foods  => sub { [] },
  drinks => sub { [ 'water' ] },
};

use Sub::HandlesVia qw( delegations );

delegations(
  attribute    => 'foods',
  handles_via  => 'Array',
  handles      => {
    all_foods    => 'all',
    add_food     => 'push',
  },
);

delegations(
  attribute    => 'drinks',
  handles_via  => 'Array',
  handles      => {
    all_drinks   => 'all',
    add_drink    => 'push',
  },
);
