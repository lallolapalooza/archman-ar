Sub__Prototype(3pm)

الحزمة: perl-sub-prototype

التراخيص: Artistic-1.0-Perl

Sub::Prototype(3) توثيق مساهمات المستخدم في Perl Sub::Prototype(3)

الاسم

Sub::Prototype - تعيين نموذج فرعي

الإصدار

الإصدار 0.03

الملخص

use Sub::Prototype;
BEGIN {
    my $code = sub { ... };
    set_prototype($code, '&@');
    *main::my_func = $code;
}
my_func { ... } @list;

الوظائف

هذه الوحدة تحتوي على وظيفة واحدة فقط، والتي يتم تصديرها افتراضيًا:

set_prototype(\&coderef, $prototype)

set_prototype(\&some_function, '$$');

تعيين النموذج لـ "coderef" إلى $prototype.
