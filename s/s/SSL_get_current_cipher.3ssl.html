SSL_get_current_cipher(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

SSL_GET_CURRENT_CIPHER(3ssl) OpenSSL SSL_GET_CURRENT_CIPHER(3ssl)

الاسم

SSL_get_current_cipher, SSL_get_cipher_name, SSL_get_cipher, SSL_get_cipher_bits, SSL_get_cipher_version, SSL_get_pending_cipher - الحصول على SSL_CIPHER لاتصال

الملخص

#include <openssl/ssl.h>
const SSL_CIPHER *SSL_get_current_cipher(const SSL *ssl);
const SSL_CIPHER *SSL_get_pending_cipher(const SSL *ssl);
const char *SSL_get_cipher_name(const SSL *s);
const char *SSL_get_cipher(const SSL *s);
int SSL_get_cipher_bits(const SSL *s, int *np);
const char *SSL_get_cipher_version(const SSL *s);

الوصف

SSL_get_current_cipher() تعيد مؤشرًا إلى كائن SSL_CIPHER يحتوي على وصف التشفير المستخدم حاليًا لاتصال تم إنشاؤه باستخدام كائن ssl. ssl **يجب ألا** يكون NULL. انظر SSL_CIPHER_get_name(3) لمزيد من التفاصيل.

SSL_get_cipher_name() تحصل على اسم التشفير المستخدم حاليًا. SSL_get_cipher() مطابقة لـ SSL_get_cipher_name(). SSL_get_cipher_bits() هو ماكرو للحصول على عدد بتات السر/الخوارزمية المستخدمة، و SSL_get_cipher_version() تعيد اسم البروتوكول.

SSL_get_pending_cipher() تعيد مؤشرًا إلى كائن SSL_CIPHER يحتوي على وصف التشفير (إذا وجد) الذي تم التفاوض عليه للاستخدام المستقبلي في الاتصال المنشأ باستخدام كائن ssl، ولكنه لم يتم استخدامه بعد. قد يكون هذا هو الحال أثناء معالجة المصافحة، عندما يمكن إعادة تدفق التحكم إلى التطبيق عبر أي من عدة طرق استدعاء. لا يضمن استقرار التسلسل الداخلي لمعالجة المصافحة واستدعاء طرق الاستدعاء من إصدار إلى آخر، وفي الوقت الحالي، لا يُضمن أن يكون سوى الاستدعاء الذي تم تعيينه بواسطة SSL_CTX_set_alpn_select_cb() له قيمة غير NULL. قد يتم إضافة استدعاءات أخرى إلى هذه القائمة بمرور الوقت.

قيم الإرجاع

SSL_get_current_cipher() تعيد التشفير المستخدم فعليًا، أو NULL إذا لم يتم إنشاء جلسة.

SSL_get_pending_cipher() تعيد التشفير الذي سيتم استخدامه عند تغيير مجموعة التشفير التالية، أو NULL إذا لم يكن هناك تشفير معروف.

ملاحظات

SSL_get_cipher, SSL_get_cipher_bits, SSL_get_cipher_version, و SSL_get_cipher_name منفذة كـ macros.

انظر أيضًا

ssl(7), SSL_CIPHER_get_name(3)
