SSTEMR

الغرض:

!>
!> SSTEMR تحسب القيم الذاتية المختارة، وبشكل اختياري، المتجهات الذاتية
!> لمصفوفة متماثلة ثلاثية قطرية T. أي مصفوفة غير مختزلة لديها
!> مجموعة محددة من القيم الذاتية الحقيقية المختلفة زوجيًا، والمتجهات الذاتية الحقيقية المقابلة متعامدة زوجيًا.
!>
!> يمكن حساب الطيف إما بالكامل أو جزئيًا عن طريق تحديد
!> إما فترة (VL,VU] أو نطاق فهارس IL:IU للقيم الذاتية المطلوبة.
!>
!> اعتمادًا على عدد القيم الذاتية المطلوبة، يتم حسابها إما
!> عن طريق التنصيف أو خوارزمية dqds. يتم حساب المتجهات الذاتية المتعامدة عدديًا
!> باستخدام عوامل تحليل L D L^T مناسبة مختلفة بالقرب من تجمعات
!> القيم الذاتية القريبة (يشار إليها باسم RRRs، التمثيلات القوية نسبيًا). مخطط غير رسمي للخوارزمية يتبع.
!>
!> لكل كتلة غير مختزلة (مصفوفة فرعية) من T،
!>    (أ) حساب T - sigma I  = L D L^T، بحيث تحدد L و D
!>        جميع القيم الذاتية المطلوبة بدقة نسبية عالية.
!>        هذا يعني أن التغييرات النسبية الصغيرة في إدخالات D و L
!>        تسبب تغييرات نسبية صغيرة فقط في القيم الذاتية و
!>        المتجهات الذاتية. التمثيل القياسي (غير المفكك) للمصفوفة
!>        ثلاثية القطرية T لا يمتلك هذه الخاصية بشكل عام.
!>    (ب) حساب القيم الذاتية بدقة مناسبة.
!>        إذا كانت المتجهات الذاتية مطلوبة، تحقق الخوارزمية دقة كاملة
!>        للقيم الذاتية المحسوبة فقط قبل أن
!>        تضطر المتجهات المقابلة إلى أن تكون محسوبة، انظر الخطوات ج) و د).
!>    (ج) لكل تجمع من القيم الذاتية القريبة، اختر عامل تحول جديد
!>        قريب من التجمع، وابحث عن عامل تحليل جديد، وحسّن
!>        القيم الذاتية المحوّلة بدقة مناسبة.
!>    (د) لكل قيمة ذاتية ذات فصل نسبي كبير بما فيه الكفاية، احسب
!>        المتجه الذاتي المقابل عن طريق تشكيل عامل تحليل ملتوي كاشف للرتبة. عد إلى (ج) لأي تجمعات متبقية.
!>
!> لمزيد من التفاصيل، انظر:
!> - Inderjit S. Dhillon and Beresford N. Parlett: 
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, August 2004.
!> - Inderjit Dhillon and Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  Also LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, May 1997.
!>
!> تفاصيل إضافية
!> 1. SSTEMR تعمل فقط على الأجهزة التي تتبع معيار الفاصلة العائمة IEEE-754
!> في معالجتها لللانهايات و NaNs.
!> هذا يسمح باستخدام حلقات داخلية فعالة تتجنب التحقق من
!> القواسم الصفرية.
!>

المعلمات

JOBZ 
!>          JOBZ هو CHARACTER*1
!>          = 'N':  حساب القيم الذاتية فقط؛
!>          = 'V':  حساب القيم الذاتية والمتجهات الذاتية.
!>

RANGE

!>          RANGE هو CHARACTER*1
!>          = 'A': سيتم العثور على جميع القيم الذاتية.
!>          = 'V': سيتم العثور على جميع القيم الذاتية في الفترة نصف المفتوحة (VL,VU].
!>          = 'I': سيتم العثور على القيم الذاتية من IL إلى IU.
!>

N

!>          N هو صحيح
!>          رتبة المصفوفة.  N >= 0.
!>

D

!>          D هو مصفوفة حقيقية، بعد (N)
!>          عند الدخول، العناصر القطرية N للمصفوفة
!>          ثلاثية القطرية T. عند الخروج، يتم الكتابة فوق D.
!>

E

!>          E هو مصفوفة حقيقية، بعد (N)
!>          عند الدخول، العناصر تحت القطرية (N-1) للمصفوفة
!>          ثلاثية القطرية T في العناصر 1 إلى N-1 من E. E(N) ليس من الضروري تعيينها عند
!>          الدخول، ولكنها تستخدم داخليًا كمساحة عمل.
!>          عند الخروج، يتم الكتابة فوق E.
!>

VL

!>          VL هو حقيقي
!>
!>          إذا كانت RANGE='V'، الحد الأدنى للفترة التي
!>          سيتم البحث فيها عن القيم الذاتية. VL < VU.
!>          غير مستخدمة إذا كانت RANGE = 'A' أو 'I'.
!>

VU

!>          VU هو حقيقي
!>
!>          إذا كانت RANGE='V'، الحد الأعلى للفترة التي
!>          سيتم البحث فيها عن القيم الذاتية. VL < VU.
!>          غير مستخدمة إذا كانت RANGE = 'A' أو 'I'.
!>

IL

!>          IL هو صحيح
!>
!>          إذا كانت RANGE='I'، فهرس
!>          أصغر قيمة ذاتية سيتم إرجاعها.
!>          1 <= IL <= IU <= N، إذا كانت N > 0.
!>          غير مستخدمة إذا كانت RANGE = 'A' أو 'V'.
!>

IU

!>          IU هو صحيح
!>
!>          إذا كانت RANGE='I'، فهرس
!>          أكبر قيمة ذاتية سيتم إرجاعها.
!>          1 <= IL <= IU <= N، إذا كانت N > 0.
!>          غير مستخدمة إذا كانت RANGE = 'A' أو 'V'.
!>

M

!>          M هو صحيح
!>          العدد الإجمالي للقيم الذاتية التي تم العثور عليها.  0 <= M <= N.
!>          إذا كانت RANGE = 'A'، فإن M = N، وإذا كانت RANGE = 'I'، فإن M = IU-IL+1.
!>

W

!>          W هو مصفوفة حقيقية، بعد (N)
!>          العناصر M الأولى تحتوي على القيم الذاتية المختارة في
!>          ترتيب تصاعدي.
!>

Z

!>          Z هو مصفوفة حقيقية، بعد (LDZ, max(1,M) )
!>          إذا كانت JOBZ = 'V'، وإذا كانت INFO = 0، فإن الأعمدة M الأولى من Z
!>          تحتوي على المتجهات الذاتية المتعامدة للمصفوفة T
!>          المقابلة للقيم الذاتية المختارة، مع احتواء العمود i من Z
!>          على المتجه الذاتي المرتبط بـ W(i).
!>          إذا كانت JOBZ = 'N'، فإن Z غير مستخدمة.
!>          ملاحظة: يجب على المستخدم التأكد من توفير ما لا يقل عن max(1,M) أعمدة
!>          في المصفوفة Z؛ إذا كانت RANGE = 'V'، فإن القيمة الدقيقة لـ M
!>          غير معروفة مسبقًا ويمكن حسابها باستخدام استعلام مساحة عمل
!>          عن طريق تعيين NZC = -1، انظر أدناه.
!>

LDZ

!>          LDZ هو صحيح
!>          البعد الرئيسي للمصفوفة Z.  LDZ >= 1، وإذا
!>          كانت JOBZ = 'V'، فإن LDZ >= max(1,N).
!>

NZC

!>          NZC هو صحيح
!>          عدد المتجهات الذاتية التي سيتم الاحتفاظ بها في المصفوفة Z.
!>          إذا كانت RANGE = 'A'، فإن NZC >= max(1,N).
!>          إذا كانت RANGE = 'V'، فإن NZC >= عدد القيم الذاتية في (VL,VU].
!>          إذا كانت RANGE = 'I'، فإن NZC >= IU-IL+1.
!>          إذا كانت NZC = -1، فسيتم افتراض استعلام مساحة عمل؛
!>          تقوم الروتين بحساب عدد أعمدة المصفوفة Z التي
!>          ستكون مطلوبة للاحتفاظ بالمتجهات الذاتية.
!>          يتم إرجاع هذه القيمة كإدخال أول لمصفوفة Z، و
!>          لا يتم إصدار أي رسالة خطأ متعلقة بـ NZC بواسطة XERBLA.
!>

ISUPPZ

!>          ISUPPZ هي مصفوفة صحيحة، بعد ( 2*max(1,M) )
!>          دعم المتجهات الذاتية في Z، أي الفهارس
!>          التي تشير إلى العناصر غير الصفرية في Z. المتجه الذاتي المحسوب i
!>          يكون غير صفري فقط في العناصر ISUPPZ( 2*i-1 ) خلال
!>          ISUPPZ( 2*i ). هذا يكون ذا صلة في حالة تقسيم المصفوفة.
!>          يتم الوصول إلى ISUPPZ فقط عندما تكون JOBZ 'V' و N > 0.
!>

TRYRAC

!>          TRYRAC هو منطقي
!>          إذا كانت TRYRAC = .TRUE.، فإن مؤشر

Function/Subroutine Documentation

This subroutine computes the eigenvalues and optionally the eigenvectors of a real symmetric tridiagonal matrix.

Arguments:

JOBZ

JOBZ is CHARACTER*1

= 'N': Compute only the eigenvalues of A.

= 'V': Compute the eigenvalues and eigenvectors of A.

RANGE

RANGE is CHARACTER*1

= 'A': All eigenvalues will be found.

= 'V': All eigenvalues in the interval (VL, VU] will be found.

= 'I': The IL-th through IU-th eigenvalues will be found.

N

N is INTEGER

The order of the matrix T. 0 <= N.

If N = 0, then the computation is skipped.

D

D is REAL array, dimension at least (max(1,N))

On entry, the diagonal elements of the tridiagonal matrix T.

On exit, the eigenvalues, sorted in ascending order. If eigenvalues are computed, D contains them.

E

E is REAL array, dimension at least (max(1,N-1))

On entry, the off-diagonal elements of the tridiagonal matrix T.

E is overwritten by values of the Schur vectors (if eigenvectors are computed).

M

M is INTEGER

The number of eigenvalues found. 0 <= M <= N.

W

W is REAL array, dimension at least (max(1,N))

If RANGE='I', the interval (W(1), W(2)] for the eigenvalue search.

If RANGE='V', the interval (W(1), W(2)] for the eigenvalue search.

If RANGE='A', W is unused.

Z

Z is REAL array, dimension (LDZ,N)

If JOBZ = 'V', then the eigenvectors of T are computed and stored in the columns of Z. The i-th column of Z is the eigenvector corresponding to the i-th eigenvalue in the array D.

If JOBZ = 'N', then the array Z is not used.

LDZ

LDZ is INTEGER

The leading dimension of the array Z. LDZ >= max(1,N) if JOBZ = 'V', and LDZ >= 1 if JOBZ = 'N'.

TRYRAC

TRYRAC is LOGICAL

TRYRAC specifies whether or not to use algorithms that preserve the relative accuracy of eigenvalues.

If TRYRAC = .TRUE., the code checks whether the tridiagonal matrix defines its eigenvalues to high relative accuracy. If so, the code uses relative-accuracy preserving algorithms that might be (a bit) slower depending on the matrix. If the matrix does not define its eigenvalues to high relative accuracy, the code can use possibly faster algorithms. If TRYRAC = .FALSE., the code is not required to guarantee relatively accurate eigenvalues and can use the fastest possible techniques.

On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix does not define its eigenvalues to high relative accuracy.

WORK

WORK is REAL array, dimension (LWORK)

On exit, if INFO = 0, WORK(1) returns the optimal (and minimal) LWORK.

LWORK

LWORK is INTEGER

The dimension of the array WORK. LWORK >= max(1,18*N) if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

IWORK

IWORK is INTEGER array, dimension (LIWORK)

On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.

LIWORK

LIWORK is INTEGER

The dimension of the array IWORK. LIWORK >= max(1,10*N) if the eigenvectors are desired, and LIWORK >= max(1,8*N) if only the eigenvalues are to be computed.

If LIWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the IWORK array, returns this value as the first entry of the IWORK array, and no error message related to LIWORK is issued by XERBLA.

INFO

INFO is INTEGER

On exit, INFO

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = 1X, internal error in SLARRE, if INFO = 2X, internal error in SLARRV. Here, the digit X = ABS( IINFO ) < 10, where IINFO is the nonzero error code returned by SLARRE or SLARRV, respectively.
