الاسم

sslsplit.conf - ملف إعداد SSLsplit

الوصف

يقوم الملف sslsplit.conf بتكوين SSLsplit، sslsplit(1).

صيغة الملف

يتكون الملف من تعليقات وخيارات مع وسائط. كل سطر يبدأ برمز هاش (#) يتم تجاهله بواسطة المحلل. الخيارات والوسائط لها الصيغة Option Argument. الوسائط من الأنواع التالية:

BOOL
قيمة منطقية (نعم/لا).
STRING
سلسلة نصية.

التوجيهات

عندما لا يتم استخدام خيار (معلق أو غير موجود في ملف الإعداد) يتخذ sslsplit إجراء افتراضيًا. إذا لم يكن للخيار ما يعادله في سطر الأوامر، يمكن استخدام الخيار -o opt=val لتجاوزه في سطر الأوامر.

CACert STRING
استخدم شهادة CA (والمفتاح) للتوقيع على الشهادات المزيفة. يعادل الخيار -c في سطر الأوامر.
CAKey STRING
استخدم مفتاح CA (والشهادة) للتوقيع على الشهادات المزيفة. يعادل الخيار -k في سطر الأوامر.
ClientCert STRING
استخدم شهادة من ملف pemfile عندما يطلب الوجهة شهادة عميل. يعادل الخيار -a في سطر الأوامر.
ClientKey STRING
استخدم مفتاحًا من ملف pemfile عندما تطلب الوجهة شهادة عميل. يعادل الخيار -b في سطر الأوامر.
CAChain STRING
استخدم سلسلة شهادات CA من ملف pemfile (شهادات CA الوسيطة والجذرية). يعادل الخيار -C في سطر الأوامر.
LeafKey STRING
استخدم مفتاحًا من ملف pemfile لتوليد شهادات ورقية. يعادل الخيار -K في سطر الأوامر.
افتراضي: توليد
LeafCRLURL STRING
استخدم عنوان URL كنقطة توزيع CRL لجميع الشهادات الورقية المزيفة. يعادل الخيار -q في سطر الأوامر.
LeafCertDir STRING
استخدم ملفات PEM للشهادات + السلسلة + المفاتيح من مجلد الشهادات لجميع المواقع المطابقة للأسماء المشتركة (غير المطابقة: توليد إذا كانت CA). يعادل الخيار -t في سطر الأوامر.
DefaultLeafCert STRING
استخدم الشهادة + السلسلة + المفتاح من ملف PEM لشهادات الأوراق إذا لم يكن هناك تطابق في LeafCertDir. يعادل الخيار -A في سطر الأوامر.
WriteGenCertsDir STRING
اكتب مفتاح الورقة والشهادات المولدة فقط إلى gendir. يعادل الخيار -w في سطر الأوامر.
WriteAllCertsDir STRING
اكتب مفتاح الورقة وجميع الشهادات إلى gendir. يعادل الخيار -W في سطر الأوامر.
DenyOCSP BOOL
رفض جميع طلبات OCSP على جميع مواصفات الوكيل (proxyspecs). يعادل الخيار -O في سطر الأوامر.
Passthrough BOOL
تجاوز اتصالات SSL إذا لم يكن من الممكن تقسيمها بسبب مصادقة شهادة العميل أو عدم وجود شهادة مطابقة وعدم وجود CA. يعادل الخيار -P في سطر الأوامر.
افتراضي: إسقاط
DHGroupParams STRING
استخدم معلمات مجموعة DH من ملف pemfile. يعادل الخيار -g في سطر الأوامر.
افتراضي: keyfiles أو auto
ECDHCurve STRING
استخدم منحنى ECDH المسمى. يعادل الخيار -G في سطر الأوامر.
افتراضي: prime256v1
SSLCompression BOOL
تمكين/تعطيل ضغط SSL/TLS على جميع الاتصالات. يعادل الخيار -Z في سطر الأوامر.
ForceSSLProto STRING
فرض إصدار بروتوكول SSL/TLS فقط. يعادل الخيار -r في سطر الأوامر.
افتراضي: all
DisableSSLProto STRING
تعطيل إصدار بروتوكول SSL/TLS. يعادل الخيار -R في سطر الأوامر.
افتراضي: none
Ciphers STRING
استخدم مواصفات مجموعة تشفير OpenSSL المعطاة. يعادل الخيار -s في سطر الأوامر.
افتراضي: ALL:-aNULL
OpenSSLEngine STRING
محرك OpenSSL المراد تنشيطه، إما المعرف أو المسار الكامل للمكتبة المشتركة التي تنفذ المحرك. إذا تم إعطاء معرف، يجب أن يكون المحرك معروفًا لتكوين OpenSSL على مستوى النظام. متاح فقط إذا تم بناؤه مقابل إصدار من OpenSSL يدعم المحركات. يعادل الخيار -x في سطر الأوامر.
NATEngine STRING
تحديد محرك NAT الافتراضي للاستخدام. يعادل الخيار -e في سطر الأوامر.
User STRING
تخفيض الامتيازات إلى المستخدم. يعادل الخيار -u في سطر الأوامر.
افتراضي: nobody، إذا تم التشغيل كـ root
Group STRING
تخفيض الامتيازات إلى المجموعة. يعادل الخيار -m في سطر الأوامر.
افتراضي: المجموعة الأساسية للمستخدم
Chroot STRING
chroot() إلى jaildir (يؤثر على مواصفات وكيل sni، انظر sslsplit(1)). يعادل الخيار -j في سطر الأوامر.
PidFile STRING
كتابة معرف العملية إلى ملف. يعادل الخيار -p في سطر الأوامر.
ConnectLog STRING
سجل الاتصالات: تسجيل سطر موجز واحد لكل اتصال في ملف السجل. يعادل الخيار -l في سطر الأوامر.
ContentLog STRING
سجل المحتوى: بيانات كاملة إلى ملف أو أنبوب مسمى (يستثني ContentLogDir/ContentLogPathSpec). يعادل الخيار -L في سطر الأوامر.
ContentLogDir STRING
سجل المحتوى: بيانات كاملة إلى ملفات منفصلة في المجلد (يستثني ContentLog/ContentLogPathSpec). يعادل الخيار -S في سطر الأوامر.
ContentLogPathSpec STRING
سجل المحتوى: بيانات كاملة إلى ملفات منفصلة مع استبدال % (يستثني ContentLog/ContentLogDir). يعادل الخيار -F في سطر الأوامر.
LogProcInfo BOOL
البحث عن العملية المحلية التي تمتلك كل اتصال لتسجيلها. يعادل الخيار -i في سطر الأوامر.
PcapLog STRING
سجل Pcap: حزم إلى ملف pcap (يستثني PcapLogDir/PcapLogPathSpec). يعادل الخيار -X في سطر الأوامر.
PcapLogDir STRING
سجل Pcap: حزم إلى ملفات منفصلة في المجلد (يستثني PcapLog/PcapLogPathSpec). يعادل الخيار -Y في سطر الأوامر.
PcapLogPathSpec STRING
سجل Pcap: حزم إلى ملفات منفصلة مع استبدال % (يستثني PcapLog/PcapLogDir). يعادل الخيار -y في سطر الأوامر.
MirrorIf STRING
نسخ الحزم إلى الواجهة. يعادل الخيار -I في سطر الأوامر.
MirrorTarget STRING
نسخ الحزم إلى عنوان الوجهة (يستخدم مع MirrorIf). يعادل الخيار -T في سطر الأوامر.
MasterKeyLog STRING
تسجيل المفاتيح الرئيسية إلى ملف السجل بتنسيق SSLKEYLOGFILE. يعادل الخيار -M في سطر الأوامر.
Daemon BOOL
وضع الخلفية (Daemon): التشغيل في الخلفية، وتسجيل رسائل الخطأ إلى syslog. يعادل الخيار -d في سطر الأوامر.
Debug BOOL
وضع التصحيح (Debug): التشغيل في المقدمة، وتسجيل

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

رسائل تصحيح الأخطاء على stderr. تعادل الخيار -D في سطر الأوامر.
VerifyPeer BOOL
التحقق من الطرف المقابل باستخدام الشهادات الافتراضية.
الافتراضي: لا
AddSNIToCertificate BOOL
عند التعطيل، لا تقم أبدًا بإضافة SNI إلى الشهادات المزورة، حتى لو كانت SNI المقدمة من العميل لا تتطابق مع CN/SAN لشهادة الخادم. يساعد في اجتياز اختبار wrong.host في https://badssl.com.
الافتراضي: نعم
ProxySpec STRING
مواصفات الوكيل: نوع listenaddr+port [natengine|targetaddr+port|"sni"+port]. تسمح مواصفات متعددة، واحدة في كل سطر.
