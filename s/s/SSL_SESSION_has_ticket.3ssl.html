SSL_SESSION_has_ticket(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

SSL_SESSION_HAS_TICKET(3ssl) OpenSSL SSL_SESSION_HAS_TICKET(3ssl)

الاسم

SSL_SESSION_get0_ticket, SSL_SESSION_has_ticket, SSL_SESSION_get_ticket_lifetime_hint - الحصول على تفاصيل حول التذكرة المرتبطة بالجلسة

الملخص

#include <openssl/ssl.h>
int SSL_SESSION_has_ticket(const SSL_SESSION *s);
unsigned long SSL_SESSION_get_ticket_lifetime_hint(const SSL_SESSION *s);
void SSL_SESSION_get0_ticket(const SSL_SESSION *s, const unsigned char **tick,
                             size_t *len);

الوصف

SSL_SESSION_has_ticket() تُرجع 1 إذا كانت هناك تذكرة جلسة مرتبطة بهذه الجلسة، و 0 بخلاف ذلك.

SSL_SESSION_get_ticket_lifetime_hint تُرجع تلميح العمر بالثواني المرتبط بتذكرة الجلسة.

SSL_SESSION_get0_ticket تحصل على مؤشر للتذكرة المرتبطة بالجلسة. يتم كتابة طول التذكرة إلى *len. إذا كان tick غير NULL، فسيتم كتابة مؤشر إلى التذكرة إلى *tick. المؤشر صالح فقط أثناء استخدام الاتصال. قد تصبح الجلسة (وبالتالي مؤشر التذكرة) غير صالحة أيضًا نتيجة للاستدعاء SSL_CTX_flush_sessions().

قيم الإرجاع

SSL_SESSION_has_ticket() تُرجع 1 إذا كانت تذكرة الجلسة موجودة أو 0 بخلاف ذلك.

SSL_SESSION_get_ticket_lifetime_hint() تُرجع عدد الثواني.

انظر أيضاً

ssl(7), d2i_SSL_SESSION(3), SSL_SESSION_get_time(3), SSL_SESSION_free(3)

التاريخ
