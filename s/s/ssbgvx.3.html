NAME

ssbgvx - Computes the eigenvalues and eigenvectors of a general band matrix A using the packed storage format and given one of the following: (1) the matrix A itself

SYNOPSIS

SUBROUTINE SSBGVX(
  UPLO, JOBZ, RANGE, N, M, NB, AB, LDAB, Q, LDQ, VL, VU, IL, IU,
  KEY, IFAIL, V, LDV, WORK, RWORK, INFO)


CHARACTER(*) UPLO, JOBZ, RANGE, KEY


INTEGER N, M, NB, LDAB, LDQ, IL, IU, INFO


REAL VL, VU


REAL AB( LDAB, * ), Q( LDQ, * ), V( LDV, * ), WORK( * ), RWORK( * )


INTEGER IFAIL( * )

Function/Subroutine Documentation


UPLO

          UPLO is CHARACTER*1
          = 'U':  Upper triangle of A and B(stored in AB) is used.
          = 'L':  Lower triangle of A and B(stored in AB) is used.

JOBZ

          JOBZ is CHARACTER*1
          Specifies whether to compute the eigenvectors.
          = 'V':  Eigenvalues and eigenvectors of the symmetric band
                  or general band matrix A are computed.
          = 'N':  Only the eigenvalues of A are computed.

RANGE

          RANGE is CHARACTER*1
          = 'A': all eigenvalues will be found.
          = 'V': all eigenvalues in the half-open interval (VL, VU]
                 will be found.
          = 'I': the IL-th through IU-th eigenvalues will be found.

N

          N is INTEGER
          The order of the matrix A.  N >= 0.

M

          M is INTEGER
          The number of eigenvalues found.  0 <= M <= N.

NB

          NB is INTEGER
          The number of subdiagonals within the band storage of B.
          If B is a general band matrix, NB is the number of
          super-diagonals of B. 0 <= NB <= N.

AB

          AB is REAL array, dimension (LDAB, N)
          On entry, the upper or lower triangle of the band matrix B,
          in the packed storage format. See the Application Notes for
          the precise format.
          On exit, if JOBZ = 'V', AB is overwritten by information about
          the factorization of B.

LDAB

          LDAB is INTEGER
          The leading dimension of the array AB. LDAB >= NB + 1.

Q

          Q is REAL array, dimension (LDQ, N)
          On exit, if JOBZ = 'V', Q contains the orthogonal matrix
          which reduces B to tridiagonal form T.

LDQ

          LDQ is INTEGER
          The leading dimension of the array Q. LDQ >= max(1, N).

VL

          VL is REAL
          If RANGE='V', the lower bound of the interval for the
          eigenvalues.

VU

          VU is REAL
          If RANGE='V', the upper bound of the interval for the
          eigenvalues.

IL

          IL is INTEGER
          If RANGE='I', the index of the smallest eigenvalue to be
          returned.

IU

          IU is INTEGER
          If RANGE='I', the index of the largest eigenvalue to be
          returned.

KEY

          KEY is CHARACTER*1
          If RANGE='I', KEY specifies the ordering of the eigenvalues:
          = 'S'   Sorted
          = 'U'   Unsorted

IFAIL

          IFAIL is INTEGER array, dimension (N)
          On normal exit, the values in IFAIL are indices of the
          eigenvalues which failed to converge. Their indices are
          stored in IFAIL.
          If JOBZ = 'N', then IFAIL is not referenced.

V

          V is REAL array, dimension (LDV, M)
          On exit, the computed eigenvectors. The eigenvector v(j)
          of A corresponding to the eigenvalue w(j) is returned in the
          j-th column of V, and the corresponding vector in the j-th
          column of WORK, normalized so that on exit SCL(j) = 1.
          The vector is normalized so that the largest component has
          absolute value 1.

LDV

          LDV is INTEGER
          The leading dimension of the array V. LDV >= max(1, N).

WORK

          WORK is REAL array, dimension (4*N)

RWORK

          RWORK is REAL array, dimension (10*N)
          Work array for calculations.

INFO

          INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          <= N: if INFO = i, then i eigenvectors failed to converge.
                  Their indices are stored in IFAIL.
          > N:  SPBSTF returned an error code; i.e.,
                if INFO = N + i, for 1 <= i <= N, then the leading
                principal minor of order i of B is not positive.
                The factorization of B could not be completed and
                no eigenvalues or eigenvectors were computed.

توثيق الدالة/الإجراء الفرعي


UPLO

          UPLO is CHARACTER*1
          = 'U':  يتم استخدام المثلث العلوي لـ A و B (المخزنة في AB).
          = 'L':  يتم استخدام المثلث السفلي لـ A و B (المخزنة في AB).

JOBZ

          JOBZ is CHARACTER*1
          يحدد ما إذا كان سيتم حساب المتجهات الذاتية.
          = 'V':  يتم حساب القيم الذاتية والمتجهات الذاتية للمصفوفة A النطاق المتناظر
                  أو المصفوفة النطاق العامة.
          = 'N':  يتم حساب القيم الذاتية لـ A فقط.

RANGE

          RANGE is CHARACTER*1
          = 'A': سيتم العثور على جميع القيم الذاتية.
          = 'V': سيتم العثور على جميع القيم الذاتية في الفترة النصف مفتوحة (VL, VU].
          = 'I': سيتم العثور على القيم الذاتية من IL إلى IU.

N

          N is INTEGER
          رتبة المصفوفة A. N >= 0.

M

          M is INTEGER
          عدد القيم الذاتية التي تم العثور عليها. 0 <= M <= N.

NB

          NB is INTEGER
          عدد الأقطار الفرعية داخل تخزين النطاق لـ B.
          إذا كانت B مصفوفة نطاق عامة، فإن NB هو عدد
          الأقطار الفائقة لـ B. 0 <= NB <= N.

AB

          AB is REAL array, dimension (LDAB, N)
          عند الدخول، المثلث العلوي أو السفلي للمصفوفة النطاق B،
          بتنسيق تخزين مضغوط. انظر ملاحظات التطبيق لـ
          التنسيق الدقيق.
          عند الخروج، إذا كانت JOBZ = 'V'، يتم الكتابة فوق AB بمعلومات حول
          تحليل B.

LDAB

          LDAB is INTEGER
          البعد الرئيسي للمصفوفة AB. LDAB >= NB + 1.

Q

          Q is REAL array, dimension (LDQ, N)
          عند الخروج، إذا كانت JOBZ = 'V'، فإن Q تحتوي على المصفوفة المتعامدة
          التي تقلل B إلى شكل ثلاثي الأقطار T.

LDQ

          LDQ is INTEGER
          البعد الرئيسي للمصفوفة Q. LDQ >= max(1, N).

VL

          VL is REAL
          إذا كانت RANGE = 'V'، الحد الأدنى للفترة الخاصة بالقيم الذاتية.

VU

          VU is REAL
          إذا كانت RANGE = 'V'، الحد الأعلى للفترة الخاصة بالقيم الذاتية.

IL

          IL is INTEGER
          إذا كانت RANGE = 'I'، فهرس أصغر قيمة ذاتية سيتم إرجاعها.

IU

          IU is INTEGER
          إذا كانت RANGE = 'I'، فهرس أكبر قيمة ذاتية سيتم إرجاعها.

KEY

          KEY is CHARACTER*1
          إذا كانت RANGE = 'I'، يحدد KEY ترتيب القيم الذاتية:
          = 'S'   مرتبة
          = 'U'   غير مرتبة

IFAIL

          IFAIL is INTEGER array, dimension (N)
          عند الخروج العادي، تكون القيم في IFAIL هي مؤشرات القيم الذاتية
          التي فشلت في التقارب. يتم تخزين مؤشراتها
          في IFAIL.
          إذا كانت JOBZ = 'N'، فلن يتم الرجوع إلى IFAIL.

V

          V is REAL array, dimension (LDV, M)
          عند الخروج، المتجهات الذاتية المحسوبة. يتم إرجاع المتجه الذاتي v(j)
          لـ A المقابل للقيمة الذاتية w(j) في
          العمود j من V، والمتجه المقابل في العمود j من WORK،
          مقيسًا بحيث يكون SCL(j) = 1 عند الخروج.
          يتم قياس المتجه بحيث يكون أكبر مكون له قيمة مطلقة 1.

LDV

          LDV is INTEGER
          البعد الرئيسي للمصفوفة V. LDV >= max(1, N).

WORK

          WORK is REAL array, dimension (4*N)

RWORK

          RWORK is REAL array, dimension (10*N)
          مصفوفة عمل للحسابات.

INFO

          INFO is INTEGER
          = 0:  خروج ناجح
          < 0:  إذا كان INFO = -i، كان الوسيط i له قيمة غير قانونية
          <= N: إذا كان INFO = i، فإن i متجه ذاتي فشل في التقارب.
                  يتم تخزين مؤشراتها في IFAIL.
          > N:  أرجع SPBSTF رمز خطأ؛ أي،
                إذا كان INFO = N + i، لـ 1 <= i <= N، فإن الأقل
                فرعي رئيسي من الرتبة i لـ B ليس موجبًا.
                لم يكن من الممكن إكمال تحليل B ولم يتم حساب
                أي قيم ذاتية أو متجهات ذاتية.
