SSL_SESSION_get0_hostname(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

SSL_SESSION_GET0_HOSTNAME(3ssl) OpenSSL SSL_SESSION_GET0_HOSTNAME(3ssl)

الاسم

SSL_SESSION_get0_hostname, SSL_SESSION_set1_hostname, SSL_SESSION_get0_alpn_selected, SSL_SESSION_set1_alpn_selected - الحصول على وتعيين بيانات SNI و ALPN المرتبطة بالجلسة

الملخص

#include <openssl/ssl.h>
const char *SSL_SESSION_get0_hostname(const SSL_SESSION *s);
int SSL_SESSION_set1_hostname(SSL_SESSION *s, const char *hostname);
void SSL_SESSION_get0_alpn_selected(const SSL_SESSION *s,
                                    const unsigned char **alpn,
                                    size_t *len);
int SSL_SESSION_set1_alpn_selected(SSL_SESSION *s, const unsigned char *alpn,
                                   size_t len);

الوصف

SSL_SESSION_get0_hostname() يسترجع قيمة مؤشر اسم الخادم (SNI) التي أرسلها العميل عند إنشاء الجلسة إذا أقر الخادم بامتداد SNI الخاص بالعميل بتضمين امتداد SNI فارغ في الرد. وإلا فإنه يُرجع NULL.

القيمة المعادة هي مؤشر إلى الذاكرة التي تحتفظ بها s ويجب عدم تحريرها.

SSL_SESSION_set1_hostname() تعين قيمة SNI لاسم المضيف إلى نسخة من السلسلة المقدمة في hostname.

SSL_SESSION_get0_alpn_selected() يسترجع بروتوكول ALPN المحدد لهذه الجلسة وطوله المرتبط بالبايتات. القيمة المعادة لـ *alpn هي مؤشر إلى الذاكرة التي تحتفظ بها s ويجب عدم تحريرها.

SSL_SESSION_set1_alpn_selected() تعين بروتوكول ALPN لهذه الجلسة إلى القيمة الموجودة في alpn والتي يجب أن يكون طولها len بايت. يتم إنشاء نسخة من القيمة المدخلة، ويحتفظ المتصل بملكية الذاكرة التي يشير إليها alpn.

قيم الإرجاع

SSL_SESSION_get0_hostname() تُرجع سلسلة SNI إذا كانت متاحة، أو NULL إذا لم تكن كذلك.

SSL_SESSION_set1_hostname() تُرجع 1 عند النجاح أو 0 عند الخطأ.

SSL_SESSION_set1_alpn_selected() تُرجع 1 عند النجاح أو 0 عند الخطأ.
