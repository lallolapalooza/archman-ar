SSL_CTX_set_msg_callback(3SSL), SSL_set_msg_callback(3SSL)

NAME

SSL_CTX_set_msg_callback, SSL_set_msg_callback - set a message callback function

SYNOPSIS

#include <openssl/ssl.h>

void SSL_CTX_set_msg_callback(SSL_CTX *ctx,
                              void (*callback)(int, int, SSL *, int, void *));
void SSL_set_msg_callback(SSL *ssl,
                          void (*callback)(int, int, SSL *, int, void *));

DESCRIPTION

The function SSL_CTX_set_msg_callback() sets a message callback function for the SSL context ctx. The function SSL_set_msg_callback() sets a message callback function for the SSL object ssl.

A message callback function can be registered for an SSL context or for a specific SSL object. If a callback is registered for a specific SSL object, it overrides any callback registered for the context.

The callback function is invoked whenever an SSL record is processed or generated. The callback function is called with the following arguments:

write_ (int): Indicates whether the record is being written (1) or read (0).
version (int): The SSL/TLS protocol version of the record.
ssl (SSL *): The SSL object.
direction (int): The direction of the record (SSL3_RT_HEADER, SSL3_RT_BODY, SSL3_RT_LENGTH, etc.). This parameter is currently unused.
arg (void *): The arbitrary user-defined argument that was passed to SSL_CTX_callback_ctrl() or SSL_callback_ctrl() when setting the callback.

The callback function should not perform any long operations, as it is called in the middle of SSL processing. The callback function can be used for debugging purposes, to log SSL/TLS messages, or to implement custom logic based on message types.

To remove a previously set callback function, call the function with NULL as the callback argument.

NOTES

The callback function is called for both incoming and outgoing records. The write_ parameter indicates whether the record is being written or read.

The version parameter indicates the SSL/TLS protocol version. Common values include SSL3_VERSION, TLS1_VERSION, TLS1_1_VERSION, and TLS1_2_VERSION.

The direction parameter is currently unused and its value is always 0.

The arg parameter can be used to pass arbitrary data to the callback function. This is useful for associating context-specific data with the callback.

RETURN VALUES

These functions do not return a value.

SSL_CTX_callback_ctrl(3ssl), SSL_callback_ctrl(3ssl), ssl.h

HISTORY

The functions SSL_CTX_set_msg_callback() and SSL_set_msg_callback() were added in OpenSSL 1.1.0.
