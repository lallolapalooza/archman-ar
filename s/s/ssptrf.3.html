subroutine ssptrf (character uplo, integer n, real, dimension( * ) ap, integer, dimension( * ) ipiv, integer info)

SSPTRF

الغرض:

!>
!> SSPTRF يحسب تحليل مصفوفة متناظرة حقيقية A مخزنة
!> بتنسيق مضغوط باستخدام طريقة التنفيذ القطري لـ Bunch-Kaufman:
!>
!>    A = U*D*U**T  أو  A = L*D*L**T
!>
!> حيث U (أو L) هو ناتج ضرب مصفوفة تبديل ومصفوفة مثلثة علوية (سفلية)
!> وحدة، و D متناظرة وقطرية كتلة ذات كتل قطرية 1x1 و 2x2.
!>

المعاملات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  يتم تخزين المثلث العلوي لـ A؛
!>          = 'L':  يتم تخزين المثلث السفلي لـ A.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP هو مصفوفة REAL، ذات بُعد (N*(N+1)/2)
!>          عند الإدخال، المثلث العلوي أو السفلي للمصفوفة المتناظرة
!>          A، مضغوطة حسب الأعمدة في مصفوفة خطية.  يتم تخزين العمود j للمصفوفة A
!>          في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>
!>          عند الخروج، يتم تخزين المصفوفة القطرية الكتلية D والعوامل المستخدمة
!>          للحصول على العامل U أو L، كمصفوفة مثلثة مضغوطة
!>          تتجاوز A (انظر أدناه لمزيد من التفاصيل).
!>

IPIV

!>          IPIV هو مصفوفة INTEGER، ذات بُعد (N)
!>          تفاصيل التبادلات وهيكل الكتلة لـ D.
!>          إذا كان IPIV(k) > 0، فقد تم تبديل الصفوف والأعمدة k و IPIV(k)
!>          و D(k,k) هي كتلة قطرية 1x1.
!>          إذا كان UPLO = 'U' و IPIV(k) = IPIV(k-1) < 0، فقد تم تبديل الصفوف والأعمدة k-1 و -IPIV(k)
!>          و D(k-1:k,k-1:k) هي كتلة قطرية 2x2.  إذا كان UPLO = 'L' و IPIV(k) =
!>          IPIV(k+1) < 0، فقد تم تبديل الصفوف والأعمدة k+1 و -IPIV(k)
!>          و D(k:k+1,k:k+1) هي كتلة قطرية 2x2.
!>

INFO

!>          INFO هو INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، كان المعامل i ذو قيمة غير قانونية
!>          > 0: إذا كان INFO = i، فإن D(i,i) هو صفر تمامًا.  تم إكمال التحليل،
!>               ولكن المصفوفة القطرية الكتلية D منفردة تمامًا، وسيحدث قسمة على صفر إذا
!>               تم استخدامها لحل نظام معادلات.
!>

تفاصيل إضافية:

!>
!>  5-96 - بناءً على تعديلات بواسطة J. Lewis، Boeing Computer Services
!>         Company
!>
!>  إذا كان UPLO = 'U'، فإن A = U*D*U**T، حيث
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  أي أن U هو ناتج ضرب حدود P(k)*U(k)، حيث يتناقص k من n إلى
!>  1 بخطوات 1 أو 2، و D هي مصفوفة قطرية كتلة ذات كتل قطرية 1x1
!>  و 2x2 تسمى D(k).  P(k) هي مصفوفة تبديل كما
!>  يتم تعريفها بواسطة IPIV(k)، و U(k) هي مصفوفة مثلثة علوية وحدة، بحيث
!>  إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  إذا كان s = 1، فإن D(k) تتجاوز A(k,k)، و v تتجاوز A(1:k-1,k).
!>  إذا كان s = 2، فإن المثلث العلوي لـ D(k) يتجاوز A(k-1,k-1)، A(k-1,k)،
!>  و A(k,k)، و v تتجاوز A(1:k-2,k-1:k).
!>
!>  إذا كان UPLO = 'L'، فإن A = L*D*L**T، حيث
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  أي أن L هو ناتج ضرب حدود P(k)*L(k)، حيث يزداد k من 1 إلى
!>  n بخطوات 1 أو 2، و D هي مصفوفة قطرية كتلة ذات كتل قطرية 1x1
!>  و 2x2 تسمى D(k).  P(k) هي مصفوفة تبديل كما
!>  يتم تعريفها بواسطة IPIV(k)، و L(k) هي مصفوفة مثلثة سفلية وحدة، بحيث
!>  إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  إذا كان s = 1، فإن D(k) تتجاوز A(k,k)، و v تتجاوز A(k+1:n,k).
!>  إذا كان s = 2، فإن المثلث السفلي لـ D(k) يتجاوز A(k,k)، A(k+1,k)،
!>  و A(k+1,k+1)، و v تتجاوز A(k+2:n,k:k+1).
!>
