z
بالنسبة لـ h، ولكن المؤشر التالي هو مؤشر إلى size_t. تم تقديم هذا المعدّل في C99.

محدّدات التحويل التالية متاحة:

%
يطابق علامة '%' حرفية. أي أن %% في سلسلة التنسيق تطابق حرف إدخال '%' واحد. لا يتم إجراء أي تحويل (ولكن يتم تجاهل الأحرف البيضاء الأولية)، ولا يحدث تعيين.
d
يطابق عددًا صحيحًا عشريًا اختياري التوقيع؛ يجب أن يكون المؤشر التالي مؤشرًا إلى int.
i
يطابق عددًا صحيحًا اختياري التوقيع؛ يجب أن يكون المؤشر التالي مؤشرًا إلى int. تتم قراءة العدد الصحيح بالأساس 16 إذا بدأ بـ 0x أو 0X، بالأساس 8 إذا بدأ بـ 0، وبالأساس 10 بخلاف ذلك. يتم استخدام الأحرف التي تتوافق مع الأساس فقط.
o
يطابق عددًا صحيحًا ثمانيًا غير موقع؛ يجب أن يكون المؤشر التالي مؤشرًا إلى unsigned int.
u
يطابق عددًا صحيحًا عشريًا غير موقع؛ يجب أن يكون المؤشر التالي مؤشرًا إلى unsigned int.
x
يطابق عددًا صحيحًا ست عشريًا غير موقع (قد يبدأ اختياريًا ببادئة 0x أو 0X، والتي يتم تجاهلها)؛ يجب أن يكون المؤشر التالي مؤشرًا إلى unsigned int.
X
مكافئ لـ x.
f
يطابق رقمًا عشريًا اختياري التوقيع؛ يجب أن يكون المؤشر التالي مؤشرًا إلى float.
e
مكافئ لـ f.
g
مكافئ لـ f.
E
مكافئ لـ f.
a
(C99) مكافئ لـ f.
s
يطابق سلسلة من الأحرف غير البيضاء؛ يجب أن يكون المؤشر التالي مؤشرًا إلى العنصر الأولي لمصفوفة أحرف طويلة بما يكفي لاستيعاب تسلسل الإدخال وبايت الإنهاء الصفري ('\0')، والذي يتم إضافته تلقائيًا. تتوقف سلسلة الإدخال عند حرف أبيض أو عند الحد الأقصى لعرض الحقل، أيهما يحدث أولاً.
c
يطابق سلسلة من الأحرف يحدد طولها عرض الحقل الأقصى (الافتراضي 1)؛ يجب أن يكون المؤشر التالي مؤشرًا إلى char، ويجب أن يكون هناك متسع كافٍ لجميع الأحرف (لا يتم إضافة بايت إنهاء صفري). يتم قمع تخطي الأحرف البيضاء الرائدة المعتاد. لتخطي الأحرف البيضاء أولاً، استخدم مساحة صريحة في التنسيق.
[
يطابق سلسلة غير فارغة من الأحرف من مجموعة الأحرف المقبولة المحددة؛ يجب أن يكون المؤشر التالي مؤشرًا إلى char، ويجب أن يكون هناك متسع كافٍ لجميع الأحرف في السلسلة، بالإضافة إلى بايت إنهاء صفري. يتم قمع تخطي الأحرف البيضاء الرائدة المعتاد. يجب أن تتكون السلسلة من أحرف في (أو ليست في) مجموعة معينة؛ يتم تعريف المجموعة بواسطة الأحرف بين القوس المفتوح [ والقوس المغلق ]. المجموعة تستبعد تلك الأحرف إذا كان الحرف الأول بعد القوس المفتوح هو علامة الإقحام (^). لتضمين قوس مغلق في المجموعة، اجعله الحرف الأول بعد القوس المفتوح أو علامة الإقحام؛ أي موضع آخر سينهي المجموعة. حرف الشرطة - مميز أيضًا؛ عند وضعه بين حرفين آخرين، فإنه يضيف جميع الأحرف الفاصلة إلى المجموعة. لتضمين شرطة، اجعلها الحرف الأخير قبل القوس المغلق النهائي. على سبيل المثال، [^]0-9-] تعني المجموعة "كل شيء باستثناء القوس المغلق، وصفر إلى تسعة، والشرطة". تنتهي السلسلة بظهور حرف ليس في (أو، مع علامة الإقحام، في) المجموعة أو عند نفاد عرض الحقل.
p
يطابق قيمة مؤشر (كما تتم طباعتها بواسطة %p في printf(3))؛ يجب أن يكون المؤشر التالي مؤشرًا إلى مؤشر إلى void.
n
لا يُتوقع شيء؛ بدلاً من ذلك، يتم تخزين عدد الأحرف المستهلكة حتى الآن من الإدخال عبر المؤشر التالي، والذي يجب أن يكون مؤشرًا إلى int، أو متغيراً يتطابق حجمه مع معدّل طول العدد الصحيح (المقدم اختياريًا). هذا ليس تحويلًا و لا يزيد عدد القيم التي تُرجعها الدالة. يمكن قمع التعيين باستخدام حرف قمع التعيين *، ولكن التأثير على القيمة المرجعة غير محدد. لذلك، يجب عدم استخدام تحويلات %*n.

قيمة الإرجاع

عند النجاح، تُرجع هذه الدوال عدد عناصر الإدخال التي تمت مطابقتها وتعيينها بنجاح؛ يمكن أن يكون هذا أقل من المطلوب، أو حتى صفرًا، في حالة فشل المطابقة المبكر.

تُرجع القيمة EOF إذا تم الوصول إلى نهاية الإدخال قبل حدوث التحويل الناجح الأول أو فشل المطابقة.

EINVAL
عدد الوسائط غير كافٍ؛ أو format هو NULL.
ENOMEM
نفاد الذاكرة.

ملاحظات

معدّل التعيين-التخصيص 'a'

في الأصل، دعمت مكتبة GNU C التخصيص الديناميكي لمدخلات السلاسل (كتوسيع غير قياسي) عبر الحرف a. (هذه الميزة موجودة على الأقل منذ glibc 2.0). لذلك، يمكن للمرء كتابة ما يلي لجعل sscanf() يخصص مخزنًا مؤقتًا لسلسلة، مع إعادة مؤشر إلى هذا المخزن المؤقت في *buf:


char *buf;
sscanf(str, "%as", &buf);

كان استخدام الحرف a لهذا الغرض إشكاليًا، نظرًا لأن a محدد أيضًا بواسطة معيار ISO C كمرادف لـ f (إدخال الأرقام العشرية). بدلاً من ذلك، يحدد POSIX.1-2008 المعدّل m للتخصيص التعييني (كما هو موصوف في الوصف، أعلاه).

لاحظ أن المعدّل a غير متاح إذا تم تجميع البرنامج باستخدام gcc -std=c99 أو gcc -D_ISOC99_SOURCE (ما لم يتم تحديد _GNU_SOURCE أيضًا)، وفي هذه الحالة يتم تفسير a كمحدد للأرقام العشرية (انظر أعلاه).

تمت إضافة الدعم للمعدّل m إلى glibc 2.7، ويجب على البرامج الجديدة استخدام هذا المعدّل بدلاً من a.

بالإضافة إلى كونه قياسيًا بواسطة POSIX، يتمتع المعدّل m بالمزايا الإضافية التالية مقارنة باستخدام a:

•
يمكن تطبيقه أيضًا على محددات تحويل %c (مثل %3mc).
•
يتجنب الغموض فيما يتعلق بمحدد تحويل الأرقام العشرية %a (ولا يتأثر بـ gcc -std=c99 وما إلى ذلك).

أخطاء

محدّدات التحويل الرقمي

يؤدي استخدام محدّدات التحويل الرقمي إلى سلوك غير محدد للإدخال غير الصالح. انظر C11 7.21.6.2/10. هذا خطأ في معيار ISO C، وليس مشكلة تصميم متأصلة في واجهة برمجة التطبيقات. ومع ذلك، فإن التطبيقات الحالية ليست آمنة من هذا الخطأ، لذلك لا يوصى باستخدامها. بدلاً من ذلك، يجب على البرامج استخدام دوال مثل strtol(3) لتحليل المدخلات الرقمية. بدلاً من ذلك، قم بتخفيفه عن طريق تحديد عرض حقل أقصى.

المعدّلات غير القياسية

هذه الدوال متوافقة تمامًا مع C99، ولكنها توفر المعدّلات الإضافية q و a بالإضافة إلى سلوك إضافي للمعدّلات L و ll. يمكن اعتبار الأخير خطأ، لأنه يغير سلوك المعدّلات المعرفة في C99.

بعض مجموعات معدّلات النوع ومحدّدات التحويل التي حددتها C99 لا معنى لها (على سبيل المثال، %Ld). بينما قد يكون لها سلوك محدد جيدًا على Linux، فإن هذا ليس بالضرورة الحال على الأنظمة الأخرى. لذلك، من الأفضل عادةً استخدام معدّلات غير محددة بواسطة C99 على الإطلاق، أي استخدام q بدلاً من L بالاقتران مع التحويلات d أو i أو o أو u أو x أو X أو ll.

استخدام q ليس هو نفسه كما في 4.4BSD، حيث يمكن استخدامه في تحويلات الأرقام العشرية بشكل مكافئ لـ L.

BUGS

The glibc implementation of sscanf with the %m[...] format specifier also supports character sets beyond the C locale (e.g., UTF-8). This might not be portable.

EXAMPLES

As mentioned above, the %m[...] format specifier allocates memory for the matched string. The caller must free(3) the returned string. Here is an example:


#include <stdio.h>
#include <stdlib.h>
#include <errno.h>
int
main() {
    char *str = "read: hello world";
    char *p;
    int n;
    errno = 0;
    n = sscanf(str, "read: %m[a-z ]", &p);
    if (n == 1) {
        printf("read: %s\n", p);
        free(p);
    } else if (errno != 0) {
        perror("sscanf");
    } else {
        fprintf(stderr, "No matching characters\n");
    }
    return 0;
}

In the example above, sscanf is used to read a string from str into a buffer allocated by sscanf itself. The format string "read: %m[a-z ]" means: match the literal string "read: ", then match and allocate memory (due to the m flag) for zero or more characters that are either lowercase letters ("a-z") or a space character (" ").

If sscanf is successful (i.e., n == 1), the pointer p will point to the newly allocated string, which should then be free(3)d. If sscanf fails for any reason (e.g., the input string does not start with "read: "), errno might be set, or n will be less than 1.

As shown in the above example, it is necessary to call free(3) only if the sscanf() call successfully read a string.
