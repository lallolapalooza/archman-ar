الوصف

جميع الدوال الموصوفة في هذه الصفحة مهملة. لا توجد دوال بديلة متاحة في الوقت الحالي.

توفر هذه الدوال الوصول إلى معلمات SRP (Secure Remote Password)، وهي آلية مصادقة بديلة لـ TLS. يسمح SRP باستخدام أسماء المستخدمين وكلمات المرور عبر قنوات غير مشفرة دون الكشف عن كلمة المرور للمتجسس. يوفر SRP أيضًا سرًا مشتركًا في نهاية تسلسل المصادقة يمكن استخدامه لإنشاء مفاتيح تشفير.

تم تحديد بروتوكول SRP، الإصدار 3، في RFC 2945. تم وصف SRP الإصدار 6 في RFC 5054 مع تطبيقات لمصادقة TLS.

تقوم الدالة SSL_CTX_set_srp_username() بتعيين اسم مستخدم SRP لـ ctx. يجب استدعاء هذا على العميل قبل إنشاء اتصال بالخادم. يجب أن يكون طول name أقصر أو يساوي 255 حرفًا.

تقوم الدالة SSL_CTX_set_srp_password() بتعيين كلمة مرور SRP لـ ctx. يمكن استدعاء هذا على العميل قبل إنشاء اتصال بالخادم. هذا يلغي تأثير SSL_CTX_set_srp_client_pwd_callback().

تقوم الدالة SSL_CTX_set_srp_strength() بتعيين قوة SRP لـ ctx. هذا هو الحد الأدنى لطول عدد أولي SRP بالبتات. إذا لم يتم تحديده، يتم استخدام 1024. إذا لم يتم تلبية ذلك من تبادل مفاتيح الخادم، فسيتم رفض الاتصال.

تقوم الدالة SSL_CTX_set_srp_cb_arg() بتعيين معامل إضافي سيتم تمريره إلى جميع الاستدعاءات اللاحقة كـ arg.

تقوم الدالة SSL_CTX_set_srp_username_callback() بتعيين استدعاء جانب الخادم الذي يتم استدعاؤه عند العثور على اسم مستخدم SRP في ClientHello. معلمات الاستدعاء هي اتصال SSL s، وعلامة خطأ قابلة للكتابة ad، والمعامل الإضافي arg الذي تم تعيينه بواسطة SSL_CTX_set_srp_cb_arg(). يجب أن يقوم هذا الاستدعاء بإعداد الخادم لتبادل المفاتيح عن طريق استدعاء SSL_set_srp_server_param() بالمعلمات المناسبة لاسم المستخدم المستلم. يمكن الحصول على اسم المستخدم عن طريق استدعاء SSL_get_srp_username(). انظر SRP_VBASE_init(3) لتحليل ملف المدقق الذي تم إنشاؤه بواسطة openssl-srp(1) أو SRP_create_verifier(3) لإنشائه. يجب أن يعيد الاستدعاء SSL_ERROR_NONE للمتابعة في تبادل مفاتيح الخادم، SSL3_AL_FATAL لخطأ فادح، أو أي قيمة < 0 لإعادة المحاولة. في حالة SSL3_AL_FATAL، سيتم إرسال علامة التنبيه التي يوفرها *al مرة أخرى. افتراضيًا، سيكون هذا SSL_AD_UNKNOWN_PSK_IDENTITY.

تقوم الدالة SSL_CTX_set_srp_client_pwd_callback() بتعيين استدعاء كلمة مرور العميل على العميل. معلمات الاستدعاء هي اتصال SSL s، والمعامل الإضافي arg الذي تم تعيينه بواسطة SSL_CTX_set_srp_cb_arg(). سيتم استدعاء الاستدعاء كجزء من إنشاء أسرار العميل. يجب أن يعيد كلمة مرور العميل في شكل نصي أو NULL لإلغاء الاتصال. سيتم تحرير الذاكرة الناتجة بواسطة المكتبة كجزء من حل الاستدعاء. هذا يلغي تأثير SSL_CTX_set_srp_password().

تقوم الدالة SSL_CTX_set_srp_verify_param_callback() بتعيين استدعاء التحقق من معلمات gN لـ SRP على العميل. يسمح هذا للعميل بإجراء تحقق مخصص عند استلام معلمات SRP المقترحة من الخادم. معلمات الاستدعاء هي اتصال SSL s، والمعامل الإضافي arg الذي تم تعيينه بواسطة SSL_CTX_set_srp_cb_arg(). يجب أن يعيد الاستدعاء قيمة موجبة لقبول معلمات الخادم. سيؤدي إرجاع 0 أو قيمة سالبة إلى إلغاء الاتصال. يمكن الحصول على معلمات الخادم عن طريق استدعاء SSL_get_srp_N() و SSL_get_srp_g(). يتم إجراء فحوصات السلامة بالفعل بواسطة المكتبة بعد المصافحة (B % N غير صفري، التحقق مقابل معامل القوة) وهي غير ضرورية. إذا لم يتم تعيين استدعاء، فسيتم التحقق من معلمات g و N مقابل القيم المعروفة في RFC 5054.

تقوم الدالة SSL_set_srp_server_param() بتعيين جميع معلمات SRP لاتصال s. N و g هي معلمات مجموعة SRP، sa هو ملح المستخدم، v هو مدقق كلمة المرور، و info هي معلومات المستخدم الاختيارية.

تقوم الدالة SSL_set_srp_server_param_pw() بتعيين جميع معلمات SRP لاتصال s عن طريق إنشاء ملح عشوائي ومدقق كلمة مرور. user هو اسم المستخدم، pass هي كلمة المرور، و grp هو معرف معلمات مجموعة SRP لـ SRP_get_default_gN(3).

تقوم الدالة SSL_get_srp_g() بإرجاع مولد مجموعة SRP لـ s، أو من SSL_CTX الأساسي إذا كان NULL.

تقوم الدالة SSL_get_srp_N() بإرجاع عدد أولي SRP لـ s، أو من SSL_CTX الأساسي إذا كان NULL.

تقوم الدالة SSL_get_srp_username() بإرجاع اسم مستخدم SRP لـ s، أو من SSL_CTX الأساسي إذا كان NULL.

تقوم الدالة SSL_get_srp_userinfo() بإرجاع معلومات مستخدم SRP لـ s، أو من SSL_CTX الأساسي إذا كان NULL.

قيم الإرجاع

جميع دوال SSL_CTX_set_* تعيد 1 عند النجاح و 0 عند الفشل.

SSL_set_srp_server_param() تعيد 1 عند النجاح و -1 عند الفشل.

دوال SSL_get_SRP_* تعيد مؤشرًا إلى البيانات المطلوبة، الذاكرة مملوكة للمكتبة ويجب ألا يقوم المستدعي بتحريرها.

أمثلة

إعداد معلمات SRP على العميل:

#include <openssl/ssl.h>
const char *username = "username";
const char *password = "password";
SSL_CTX *ctx = SSL_CTX_new(TLS_client_method());
if (!ctx)
    /* خطأ */
if (!SSL_CTX_set_srp_username(ctx, username))
    /* خطأ */
if (!SSL_CTX_set_srp_password(ctx, password))
    /* خطأ */

إعداد خادم SRP بملف مدقق:

#include <openssl/srp.h>
#include <openssl/ssl.h>
const char *srpvfile = "password.srpv";
int srpServerCallback(SSL *s, int *ad, void *arg)
{
    SRP_VBASE *srpData = (SRP_VBASE*) arg;
    char *username = SSL_get_srp_username(s);
    SRP_user_pwd *user_pwd = SRP_VBASE_get1_by_user(srpData, username);
    if (!user_pwd)
        /* خطأ */
        return SSL3_AL_FATAL;
    if (SSL_set_srp_server_param(s, user_pwd->N, user_pwd->g,
        user_pwd->s, user_pwd->v, user_pwd->info) < 0)
        /* خطأ */
    SRP_user_pwd_free(user_pwd);
    return SSL_ERROR_NONE;
}
SSL_CTX *ctx = SSL_CTX_new(TLS_server_method());
if (!ctx)
    /* خطأ */
/*
 * يجب أن يحتوي seedKey على تسلسل منتهي بـ NUL
 * من البايتات العشوائية غير المنتهية بـ NUL
 */
const char *seedKey;
SRP_VBASE *srpData = SRP_VBASE_new(seedKey);
if (SRP_VBASE_init(srpData, (char*) srpvfile) != SRP_NO_ERROR)
   /* خطأ */
SSL_CTX_set_srp_cb_arg(ctx, srpData);
SSL_CTX_set_srp_username_callback(ctx, srpServerCallback);
