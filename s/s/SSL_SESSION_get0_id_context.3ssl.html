SSL_SESSION_get0_id_context(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

SSL_SESSION_GET0_ID_CONTEXT(3ssl) OpenSSL SSL_SESSION_GET0_ID_CONTEXT(3ssl)

الاسم

SSL_SESSION_get0_id_context, SSL_SESSION_set1_id_context - الحصول على وتعيين سياق معرف الجلسة (SSL ID context) المرتبط بالجلسة

الملخص

#include <openssl/ssl.h>
const unsigned char *SSL_SESSION_get0_id_context(const SSL_SESSION *s,
                                                 unsigned int *len);
int SSL_SESSION_set1_id_context(SSL_SESSION *s, const unsigned char *sid_ctx,
                               unsigned int sid_ctx_len);

الوصف

راجع SSL_CTX_set_session_id_context(3) لمزيد من التفاصيل حول سياقات معرف الجلسة.

تقوم الدالة SSL_SESSION_get0_id_context() بإرجاع سياق المعرف المرتبط بجلسة SSL/TLS s. يتم كتابة طول سياق المعرف في *len إذا لم يكن len قيمة NULL.

القيمة التي تم إرجاعها هي مؤشر إلى كائن تتم صيانته داخل s ولا ينبغي تحريرها.

تقوم الدالة SSL_SESSION_set1_id_context() بنسخ سياق المعرف المقدم في sid_ctx وربطه بالجلسة s. يتم تحديد طول سياق المعرف بواسطة sid_ctx_len والتي يجب ألا تتجاوز SSL_MAX_SID_CTX_LENGTH بايت.

قيم الإرجاع

تعيد الدالة SSL_SESSION_set1_id_context() القيمة 1 عند النجاح أو 0 عند حدوث خطأ.

راجع أيضًا

ssl(7), SSL_set_session_id_context(3)

التاريخ

تمت إضافة الدالة SSL_SESSION_get0_id_context() في OpenSSL 1.1.0.
