SSL_CTX_get_verify_mode(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

SSL_CTX_GET_VERIFY_MODE(3ssl) OpenSSL SSL_CTX_GET_VERIFY_MODE(3ssl)

الاسم

SSL_CTX_get_verify_mode, SSL_get_verify_mode, SSL_CTX_get_verify_depth, SSL_get_verify_depth, SSL_get_verify_callback, SSL_CTX_get_verify_callback - الحصول على معلمات التحقق المعينة حاليًا

الملخص

#include <openssl/ssl.h>
int SSL_CTX_get_verify_mode(const SSL_CTX *ctx);
int SSL_get_verify_mode(const SSL *ssl);
int SSL_CTX_get_verify_depth(const SSL_CTX *ctx);
int SSL_get_verify_depth(const SSL *ssl);
int (*SSL_CTX_get_verify_callback(const SSL_CTX *ctx))(int, X509_STORE_CTX *);
int (*SSL_get_verify_callback(const SSL *ssl))(int, X509_STORE_CTX *);

الوصف

SSL_CTX_get_verify_mode() تُرجع وضع التحقق المعين حاليًا في ctx.

SSL_get_verify_mode() تُرجع وضع التحقق المعين حاليًا في ssl.

SSL_CTX_get_verify_depth() تُرجع حد عمق التحقق المعين حاليًا في ctx. إذا لم يتم تعيين حد بشكل صريح، يتم إرجاع -1 وسيتم استخدام القيمة الافتراضية.

SSL_get_verify_depth() تُرجع حد عمق التحقق المعين حاليًا في ssl. إذا لم يتم تعيين حد بشكل صريح، يتم إرجاع -1 وسيتم استخدام القيمة الافتراضية.

SSL_CTX_get_verify_callback() تُرجع مؤشر دالة لدالة الاستدعاء العكسي للتحقق المعينة حاليًا في ctx. إذا لم يتم تعيين دالة استدعاء عكسي بشكل صريح، يتم إرجاع المؤشر NULL وسيتم استخدام دالة الاستدعاء العكسي الافتراضية.

SSL_get_verify_callback() تُرجع مؤشر دالة لدالة الاستدعاء العكسي للتحقق المعينة حاليًا في ssl. إذا لم يتم تعيين دالة استدعاء عكسي بشكل صريح، يتم إرجاع المؤشر NULL وسيتم استخدام دالة الاستدعاء العكسي الافتراضية.
