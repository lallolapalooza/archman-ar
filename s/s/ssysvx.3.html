الغرض:

!>
!> SSYSVX تستخدم تفكيك المحاور القطري لحساب
!> حل لنظام المعادلات الخطية الحقيقية A * X = B،
!> حيث A مصفوفة متناظرة N × N و X و B مصفوفتان N × NRHS.
!>
!> يتم أيضًا توفير حدود الخطأ للحل وتقدير الشرط.
!>

الوصف:

!>
!> يتم تنفيذ الخطوات التالية:
!>
!> 1. إذا كان FACT = 'N'، يتم استخدام طريقة المحاور القطرية لتفكيك A.
!>    شكل التفكيك هو
!>       A = U * D * U**T، إذا كان UPLO = 'U'، أو
!>       A = L * D * L**T، إذا كان UPLO = 'L'،
!>    حيث U (أو L) هو حاصل ضرب مصفوفات التبديل والمثلث العلوي (السفلي) الأحادي،
!>    و D متناظرة وقطرية كتليّة مع كتل قطرية بحجم 1x1 و 2x2.
!>
!> 2. إذا كان بعض D(i,i)=0، مما يجعل D مفردة تمامًا، فإن الروتين
!>    يعود بـ INFO = i. بخلاف ذلك، يتم استخدام الشكل المفكك لـ A
!>    لتقدير معامل شرط المصفوفة A. إذا كان
!>    معكوس معامل الشرط أقل من الدقة الآلية،
!>    يتم إرجاع INFO = N+1 كتحذير، ولكن الروتين يستمر
!>    في حل X وحساب حدود الخطأ كما هو موضح أدناه.
!>
!> 3. يتم حل نظام المعادلات لـ X باستخدام الشكل المفكك لـ A.
!>
!> 4. يتم تطبيق التنقيح التكراري لتحسين الحل المحسوب
!>    المصفوفة وحساب حدود الخطأ وتقديرات الخطأ الخلفي
!>    لها.
!>

NAME

ssysvx - solve the general system of linear equations with a symmetric matrix

SYNOPSIS

SUBROUTINE SSYSVX( FACT, UPLO, N, NRHS, A, LDA, AF, LDAF, IPIV, B, LDB, X,
     LDX, RCOND, FERR, BERR, WORK, IWORK, INFO )

Parameters:

FACT
CHARACTER*1. FACT = 'N': the Driver, Equil, and Compute functions are called to factorize the matrix A. FACT = 'F': the matrix AF has already been fully factorized, and AF and IPIV depend on the previous calls to SUBROUTINE SSYTRF.
UPLO
CHARACTER*1. UPLO = 'U': Upper triangle of A is stored and will be used in the computation. UPLO = 'L': Lower triangle of A is stored and will be used in the computation.
N
INTEGER. Order of the matrix A. N >= 0.
NRHS
INTEGER. Number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.
A
REAL array, dimension (LDA,N). On entry, the symmetric matrix A. On exit, the overwritten matrix A.
LDA
INTEGER. Leading dimension of the array A. LDA >= max(1,N).
AF
REAL array, dimension (LDAF,N). On entry, if FACT = 'F', AF contains the fully factorized matrix AF. On exit, if FACT = 'N', AF is used to store the factored matrix A.
LDAF
INTEGER. Leading dimension of the array AF. LDAF >= max(1,N).
IPIV
INTEGER array, dimension (N). On entry, if FACT = 'F', IPIV contains the pivot indices from the factorization. On exit, if FACT = 'N', IPIV contains the pivot indices from the factorization.
B
REAL array, dimension (LDB,NRHS). On entry, the right hand side matrix B. On exit, the solution matrix X if SRFSX is called (or the overwritten matrix B if SRFSX is not called).
LDB
INTEGER. Leading dimension of the array B. LDB >= max(1,N).
X
REAL array, dimension (LDX,NRHS). On exit, the solution matrix X.
LDX
INTEGER. Leading dimension of the array X. LDX >= max(1,N).
RCOND
REAL. On exit, estimate of the reciprocal of the condition number of A. RCOND is computed using SLACON. RCOND is zero if workspace is insufficient for SLACON.
FERR
REAL array, dimension (NRHS). On exit, estimate of the forward error bound for each respective column of X, and it is computed using SCLACON.
BERR
REAL array, dimension (NRHS). On exit, estimate of the backward error bound for each respective column of X, and it is computed using SLACON.
WORK
REAL array, dimension (LWORK). On exit, if FACT = 'N', WORK(1) contains the optimal (and minimal) size of the WORK array.
IWORK
INTEGER array, dimension (N).
INFO
INTEGER. = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value > 0: if INFO = i, and i is <= N: D(i,i) is exactly zero. The factorization has been completed but the factor D is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned. = N+1: D is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.

Function/Subroutine Documentation

Library: LAPACK

Purpose:

 SSYSVX uses the Left/Right Looking Block LU factorization to compute the
 solution to a linear system of equations A * X = B, such as
    A * X = B
 where A is an N x N symmetric matrix and X and B are N x NRHS.

 This routine calls the routines below to perform the following sequence of
 operations:
     1. (If FACT = 'N')
        Factorize the matrix A using the Left/Right Looking Block LU
        factorization.
        (SSYTRF)
     2. Compute the reciprocal condition number of A.
        (SLACON)
     3. Compute the solution X.
        (SSYTRS)
     4. Improve the solution X and compute error bounds.
        (SSYRFS)
