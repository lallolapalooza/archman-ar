ssh-tpm-agent(1)

الحزمة: ssh-tpm-agent

التراخيص: MIT

SSH-TPM-AGENT(1) دليل ssh-tpm-agent SSH-TPM-AGENT(1)

الاسم

ssh-tpm-agent - ssh-agent للمفاتيح TPM 2.0

الملخص

ssh-tpm-agent [خيارات]

ssh-tpm-agent --print-socket

ssh-tpm-agent --install-user-units

الوصف

ssh-tpm-agent هو برنامج ينشئ مفاتيح تستخدم وحدة النظام الأساسي الموثوقة (TPM) لتمكين المفاتيح الخاصة المغلفة للمصادقة بالمفتاح العام.

الخيارات

-l مسار

مسار مقبس UNIX المراد فتحه

الافتراضي هو $XDG_RUNTIME_DIR/ssh-tpm-agent.sock.

-A مسار

مقابس ssh-agent احتياطية للبحث عن مفاتيح إضافية.

--print-socket

يطبع المقبس إلى STDIN.

--key-dir مسار

مسار الدليل الذي سيتم البحث فيه عن مفاتيح TPM المغلفة.

الافتراضي هو ~/.ssh.

--no-load

لا تقم بتحميل مفاتيح TPM المغلفة من ~/.ssh افتراضيًا.

-o, --owner-password

اطلب كلمة مرور المالك.

--no-cache

لن يقوم الوكيل بتخزين كلمات مرور المفاتيح مؤقتًا.

--hierarchy HIERARCHY

قم بتحميل مفاتيح التسلسل الهرمي مسبقًا في الوكيل.

انظر مفاتيح التسلسل الهرمي لمزيد من المعلومات.

التسلسلات الهرمية المتاحة:

•owner, o
•endorsement, e
•null, n
•platform, p

-d

تمكين تسجيل التصحيح.

--install-user-units

يقوم بتثبيت وحدات نظام systemd وتكوينات sshd لاستخدام ssh-tpm-agent كوكيل مفاتيح المضيف.

--swtpm

يخزن المفاتيح داخل مثيل swtpm بدلاً من TPM الفعلي. هذا ليس ميزة أمان ولا يتم تخزين مفاتيحك بشكل آمن.

يمكن تمكينه أيضًا باستخدام متغير البيئة SSH_TPM_AGENT_SWTPM.

أمثلة

الاستخدام العادي للوكيل

يمكن استخدام ssh-tpm-agent كبديل مباشر لـ ssh-agent ويعمل بنفس الطريقة.

$ ssh-tpm-keygen
# أضف ~/.ssh/id_ecdsa.pub إلى حسابات Github الخاصة بك
$ ssh-tpm-agent &
$ export SSH_AUTH_SOCK=$(ssh-tpm-agent --print-socket)
$ ssh git@github.com

انظر ssh-tpm-keygen(1) لاستخدام keygen.

دعم الوكيل الاحتياطي

يدعم ssh-tpm-agent الرجوع إلى ssh-agent مختلف. يمكن إضافة الوكلاء باستخدام المفتاح -A. سيؤدي هذا إلى قيام ssh-tpm-agent بالانتشار إلى جميع الوكلاء المتاحين للمفاتيح.

هذا عملي إذا كان لديك مفاتيح متعددة من تطبيقات وكيل مختلفة ولكنك ترغب في الاعتماد على مقبس واحد.

# ابدأ ssh-agent العادي
$ eval $(ssh-agent)
# إنشاء مفتاح RSA قوي
$ ssh-keygen -t rsa -b 4096 -f id_rsa -C ssh-agent
...
بصمة المفتاح هي:
SHA256:zLSeyU/6NKHGEvyZLA866S1jGqwdwdAxRFff8Z2N1i0 ssh-agent
$ ssh-add id_rsa
تمت إضافة الهوية: id_rsa (ssh-agent)
# اطبع المفتاح الطويل جداً
$ ssh-add -L
ssh-rsa AAAAB3NzaC1yc[...]8TWynQ== ssh-agent
# إنشاء مفتاح على TPM
$ ssh-tpm-keygen -C ssh-tpm-agent
Generating a sealed public/private ecdsa key pair.
Enter file in which to save the key (/home/user/.ssh/id_ecdsa):
Enter passphrase (empty for no passphrase):
Confirm passphrase:
تم حفظ تعريفك في /home/user/.ssh/id_ecdsa.tpm
تم حفظ مفتاحك العام في /home/user/.ssh/id_ecdsa.pub
بصمة المفتاح هي:
SHA256:PoQyuzOpEBLqT+xtP0dnvyBVL6UQTiQeCWN/EXIxPOo
صورة المفتاح العشوائية هي لون التلفزيون، مضبوط على قناة ميتة.
# ابدأ ssh-tpm-agent بمقبس وكيل
$ ssh-tpm-agent -A "${SSH_AUTH_SOCK}" &
$ export SSH_AUTH_SOCK="$(ssh-tpm-agent --print-socket)"
# يقوم ssh-tpm-agent بتمرير المفاتيح من ssh-agent
$ ssh-add -L
ssh-rsa AAAAB3NzaC1yc[...]8TWynQ== ssh-agent
ecdsa-sha2-nistp256 AAAAE2VjZHNhLXNo[...]q4whro= ssh-tpm-agent

استخدام مفاتيح المضيف

يمكن أيضًا استخدام ssh-tpm-agent لخدمة مفاتيح المضيف لخادم ssh. يحتوي ssh-tpm-hostkeys على خيارات ملائمة للمساعدة في تثبيت تكوينات وخدمات systemd للنظام. سيؤدي هذا إلى إنشاء مقبس نظام لـ ssh-tpm-agent تحت /var/tmp/ssh-tpm-agent.sock.

$ sudo ssh-tpm-keygen -A
2023/09/03 17:03:08 INFO Generating new ECDSA host key
2023/09/03 17:03:08 INFO Wrote /etc/ssh/ssh_tpm_host_ecdsa_key.tpm
2023/09/03 17:03:08 INFO Generating new RSA host key
2023/09/03 17:03:15 INFO Wrote /etc/ssh/ssh_tpm_host_rsa_key.tpm
$ sudo ssh-tpm-hostkeys --install-system-units
Installed /usr/lib/systemd/system/ssh-tpm-agent.service
Installed /usr/lib/systemd/system/ssh-tpm-agent.socket
Installed /usr/lib/systemd/system/ssh-tpm-genkeys.service
Enable with: systemctl enable --now ssh-tpm-agent.socket
$ sudo ssh-tpm-hostkeys --install-sshd-config
Installed /etc/ssh/sshd_config.d/10-ssh-tpm-agent.conf
Restart sshd: systemd restart sshd
$ systemctl enable --now ssh-tpm-agent.socket
$ systemd restart sshd
$ sudo ssh-tpm-hostkeys
ecdsa-sha2-nistp256 AAAAE2V[...]YNwqWY0= root@localhost
ssh-rsa AAAAB3NzaC1ycA[...]N1Jg3fLQKSe7f root@localhost
$ ssh-keyscan -t ecdsa localhost
# localhost:22 SSH-2.0-OpenSSH_9.4
localhost ecdsa-sha2-nistp256 AAAAE2V[...]YNwqWY0=

بدلاً من ذلك، يمكن حذف علامات التثبيت المضمنة وتضمين تكوين إسقاط لـ sshd ضمن /etc/ssh/sshd_config.d بالمحتوى التالي.

HostKeyAgent /var/tmp/ssh-tpm-agent.sock
HostKey /etc/ssh/ssh_tpm_host_ecdsa_key.pub
HostKey /etc/ssh/ssh_tpm_host_rsa_key.pub

مفاتيح التسلسل الهرمي

TPMs قادرة على إنشاء مفاتيح ثابتة باستخدام التسلسلات الهرمية العليا. هذا يتيح للمستخدم إنشاء مفاتيح متاحة طوال عمر الجهاز، أو للمالك الحالي للجهاز، أو للجلسة الحالية للجهاز. هذه المفاتيح لا تغادر TPM، مثل المفاتيح الأخرى التي تم إنشاؤها بواسطة ssh-tpm-keygen، ويمكن إعادة إنشائها دائمًا.

يمكن تحميل هذه المفاتيح مسبقًا في ssh-tpm-agent.

$ ssh-tpm-agent --hierarchy owner &
$ export SSH_AUTH_SOCK="$(ssh-tpm-agent --print-socket)"
$ ssh-add -l
2048 SHA256:yt7A20tcRnzgaD2ATgAXSNWy9sP6wznysp3SkoK3Gj8 Owner hierarchy key (RSA)
256 SHA256:PmEsMeh/DwFP04iUaWLNeX4maMR6r1vfqw1BbbdFjIg Owner hierarchy key (ECDSA)

للاستخدام مع sshd، يمكن إنشاء الجزء العام من هذه المفاتيح عن طريق دمج -A مع --hierarchy.

$ ssh-tpm-keygen -A --hierarchy owner
2025/03/10 21:57:08 INFO Generating new hierarcy host key algorithm=RSA hierarchy=owner
2025/03/10 21:57:10 INFO Wrote public key filename=/etc/ssh/ssh_tpm_host_rsa_key.pub
2025/03/10 21:57:10 INFO Generating new hierarcy host key algorithm=ECDSA hierarchy=owner
2025/03/10 21:57:10 INFO Wrote public key filename=/etc/ssh/ssh_tpm_host_ecdsa_key.pub

يمكن استخدام هذه الملفات مع HostKey كالمعتاد في ssh_config.

تختلف التسلسلات الهرمية المختلفة للمفاتيح في خصائصها وعمرها الافتراضي.

يخزن التسلسل الهرمي endorsement المفاتيح التي تم إنشاؤها طوال عمر الجهاز. لا ينبغي تغيير هذا التسلسل الهرمي طوال عمر الجهاز.

يخزن التسلسل الهرمي owner المفاتيح التي تم إنشاؤها لمالك الجهاز. سيتم تدوير هذه المفاتيح عند إصدار tpm2_clear(1) على المنصة، والذي يجب القيام به عندما يحصل الجهاز على مالك جديد.

يخزن التسلسل الهرمي null المفاتيح التي تم إنشاؤها للجلسة الحالية. يجب أن تكون الجلسة دورة طاقة للأجهزة.
