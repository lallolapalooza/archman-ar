SSR(1) أوامر المستخدم SSR(1)

الاسم

SSR - صفحة دليل لـ AAP renderer

الملخص

ssr-aap [خيارات] <ملف-المشهد>

الوصف

SoundScape Renderer (SSR) هي أداة لإعادة إنتاج الصوت المكاني في الوقت الفعلي توفر مجموعة متنوعة من خوارزميات التصيير.

الخيارات

خيارات خاصة بالمُصيّر:

--hrirs=ملف
تحميل HRIRs لمُصيّر ثنائي الأذن من الملف
--hrir-size=N
اقتطاع HRIRs إلى الطول N
--prefilter=ملف
تحميل مرشح WFS الأولي من الملف
-o, --ambisonics-order=قيمة
ترتيب Ambisonics للاستخدام لـ AAP (الافتراضي: الأقصى)
--in-phase-rendering
استخدام تصيير متطابق الطور لمُصيّر AAP

خيارات JACK:

-n, --name=اسم
تعيين اسم عميل JACK إلى الاسم
--input-prefix=بادئة
بادئة منفذ الإدخال (الافتراضي: "system:capture_")
--output-prefix=بادئة
بادئة منفذ الإخراج (الافتراضي: "system:playback_")
-f, --freewheel
استخدام JACK في وضع الدوران الحر

خيارات عامة:

-c, --config=ملف
قراءة الإعدادات من الملف
-s, --setup=ملف
تحميل إعدادات إعادة الإنتاج من الملف
--threads=N
عدد خيوط الصوت (الافتراضي: تلقائي)
-r, --record=ملف
تسجيل إخراج الصوت للمُصيّر إلى الملف
--decay-exponent=قيمة
الأُس الذي يحدد اضمحلال السعة (الافتراضي: 1) (معطل وقت الترجمة!)
--loop
تشغيل جميع ملفات الصوت بشكل متكرر
--master-volume-correction=قيمة
تصحيح مستوى الصوت الرئيسي بالديسيبل (الافتراضي: 0 ديسيبل)
--auto-rotation تدوير اتجاه مصادر الصوت تلقائيًا نحو
المرجع
--no-auto-rotation
عدم تدوير اتجاه مصادر الصوت تلقائيًا نحو المرجع
-i, --ip-server
بدء خادم IP (غير مفعل وقت الترجمة!)
-I, --no-ip-server
عدم بدء خادم IP (افتراضي)
--websocket-server
بدء خادم WebSocket (غير مفعل وقت الترجمة!)
--no-websocket-server
عدم بدء خادم WebSocket (افتراضي)
--fudi-server
بدء خادم FUDI (غير مفعل وقت الترجمة!)
--no-fudi-server
عدم بدء خادم FUDI (افتراضي)
--follow
الانتظار حتى يتصل مثيل SSR آخر
--no-follow
عدم متابعة مثيل SSR آخر (افتراضي)
-g, --gui
بدء واجهة المستخدم الرسومية (غير مفعل وقت الترجمة!)
-G, --no-gui
عدم بدء واجهة المستخدم الرسومية (افتراضي)
-t, --tracker=النوع
تحديد متتبع الرأس، القيم الممكنة: fastrak patriot razor
--tracker-port=المنفذ
اسم/رقم منفذ متتبع الرأس، على سبيل المثال /dev/ttyS1
-T, --no-tracker
عدم استخدام متتبع الرأس (افتراضي)
-h, --help
عرض المساعدة والخروج
-v, --verbose
زيادة مستوى الإسهاب (حتى -vvv)
-V, --version
عرض معلومات الإصدار والخروج

SSR-AAP MANUAL PAGE

NAME

ssr-aap — A wrapper for the SSR client to simplify its connection and configuration.

SYNOPSIS

ssr-aap [-h] [-v] [-c CONFIG] [-l LOGFILE]

DESCRIPTION

ssr-aap is a simple wrapper script that aims to simplify the connection and configuration of the SSR client. It parses a configuration file, extracts the necessary parameters, and launches the SSR client with those parameters.

The primary use case for this script is to manage multiple SSR configurations and switch between them easily, or to automatically connect to a specific SSR server on startup.

OPTIONS

-h, --help
Show a help message and exit.
-v, --version
Show program's version number and exit.
-c CONFIG, --config CONFIG
Specify the configuration file to use. The default configuration file is ~/.ssr-aap/config.
-l LOGFILE, --logfile LOGFILE
Specify the log file to write output to. The default log file is ~/.ssr-aap/ssr-aap.log.

ssr-aap(1)

صفحة دليل SSR-AAP

الاسم

ssr-aap — غلاف لعميل SSR لتبسيط اتصاله وتكوينه.

الملخص

ssr-aap [-h] [-v] [-c CONFIG] [-l LOGFILE]

الوصف

ssr-aap هو سكربت غلاف بسيط يهدف إلى تبسيط الاتصال والتكوين لعميل SSR. يقوم بتحليل ملف تكوين، واستخراج المعلمات الضرورية، وتشغيل عميل SSR بهذه المعلمات.

حالة الاستخدام الأساسية لهذا السكربت هي إدارة تكوينات SSR متعددة والتبديل بينها بسهولة، أو الاتصال تلقائيًا بخادم SSR معين عند بدء التشغيل.

خيارات

-h, --help
عرض رسالة المساعدة والخروج.
-v, --version
عرض رقم إصدار البرنامج والخروج.
-c CONFIG, --config CONFIG
تحديد ملف التكوين المراد استخدامه. ملف التكوين الافتراضي هو ~/.ssr-aap/config.
-l LOGFILE, --logfile LOGFILE
تحديد ملف السجل لكتابة المخرجات إليه. ملف السجل الافتراضي هو ~/.ssr-aap/ssr-aap.log.

المؤلف

كتبه مشرفو SSR-AAP.
