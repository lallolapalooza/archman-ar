Function/Subroutine Documentation

!> @brief `ssytf2_rk` is a subroutine in LAPACK for computing the
!>        factorization of a real symmetric matrix.
!>
!> This subroutine computes the factorization of a real symmetric matrix
!> A of order N using the rook's diagonal bordered   PA = LU
!> factorization, where U is upper triangular and L is lower triangular.
!> P is a permutation matrix.
!>
!> @param[in] UPLO Specifies whether the matrix A is upper or lower triangular.
!>                 'U' or 'u' means upper triangular.
!>                 'L' or 'l' means lower triangular.
!> @param[in] N The order of the matrix A. N must be at least 0.
!> @param[in,out] A The matrix to be factorized. It is a two-dimensional array of
!>                  size (LDA, N). On entry, it contains the symmetric matrix
!>                  to be factorized. On exit, it is overwritten by the factors
!>                  L and U and the multipliers.
!> @param[in] LDA The leading dimension of the array A. LDA must be at least
!>                max(1, N).
!> @param[out] TAU The array TAU contains the scalar multipliers of the
!>                 elementary transformations. The dimension of TAU is (N).
!> @param[out] WORK A workspace array of dimension (LWORK).
!> @param[in] LWORK The dimension of the array WORK. LWORK must be at least N.
!> @param[out] INFO INFO is INTEGER
!>                  = 0: successful exit
!>                  < 0: if INFO = -i, the i-th argument had an illegal value
!>                  > 0: if INFO = i, the factorization failed because the
!>                       pivot element of order i was equal to zero.
!>
