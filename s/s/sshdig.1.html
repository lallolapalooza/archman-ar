NAME

sshdig — استخراج حزم البيانات عبر SSH

SYNOPSIS

sshdig [-i interface] [-f fifo] [-c] [common options] [capture options]

DESCRIPTION

إن sshdig هو أداة مساعدة لاستخراج الحزم عبر SSH. وهي تستخدم لاستخراج حزم البيانات من جهاز بعيد عبر اتصال SSH.

يجب تسمية sshdig بنفس اسم الواجهة المطلوبة في Stratoshark. إذا كنت تريد استخراج البيانات من خادم معين، يمكنك تسمية sshdig بنفس اسم الخادم.

يستخدم sshdig واجهة Stratoshark القياسية لاستخراج الحزم. يمكن استخدامه مع أدوات Stratoshark الأخرى مثل tshark أو Stratoshark GUI.

OPTIONS

-i interface
تحديد اسم واجهة الاستخراج. يجب أن يتطابق هذا مع اسم الملف التنفيذي لـ sshdig (على سبيل المثال، إذا كان اسم الملف التنفيذي هو sshdig-host1، فيجب استخدام -i sshdig-host1).
-f fifo
تحديد مسار ملف FIFO الذي سيتم استخدامه للتواصل بين sshdig وأداة Stratoshark.
-c
تشغيل sshdig في وضع الالتقاط. هذا الوضع هو الافتراضي.
common options
خيارات مشتركة مع أدوات Stratoshark الأخرى، مثل --version و --help.
capture options
خيارات خاصة بالتقاط الحزم، مثل:

EXAMPLES

لالتقاط البيانات:

sshdig --extcap-interface=sshdig --fifo=/tmp/ssh.scap --capture --remote-host 192.168.1.10
--remote-username user

ملاحظة

CTRL + C يجب استخدامها لإيقاف الالتقاط لضمان إنهاء نظيف.

يمكن إعادة تسمية الملف التنفيذي sshdig لدعم مثيلات متعددة. على سبيل المثال، إذا أردنا أن يظهر sshdig مرتين في Stratoshark (على سبيل المثال، لمعالجة ملفات تعريف متعددة)، يمكننا نسخ sshdig إلى sshdig-host1 و sshdig-host2. كل ملف تنفيذي سيظهر اسم واجهة مطابق لاسم الملف التنفيذي. هذه الملفات التنفيذية التي لا تحمل اسم "sshdig" ستظهر باسم "إصدار مخصص" في وصف مصدر الالتقاط.
