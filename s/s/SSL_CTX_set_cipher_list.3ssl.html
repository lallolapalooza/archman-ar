SSL_CTX_set_cipher_list(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

SSL_CTX_set_cipher_list(3ssl) OpenSSL SSL_CTX_set_cipher_list(3ssl)

الاسم

SSL_CTX_set_cipher_list, SSL_set_cipher_list, SSL_CTX_set_ciphersuites, SSL_set_ciphersuites, OSSL_default_cipher_list, OSSL_default_ciphersuites - اختيار قائمة بالتشفيرات المتاحة

الملخص

#include <openssl/ssl.h>
int SSL_CTX_set_cipher_list(SSL_CTX *ctx, const char *str);
int SSL_set_cipher_list(SSL *ssl, const char *str);
int SSL_CTX_set_ciphersuites(SSL_CTX *ctx, const char *str);
int SSL_set_ciphersuites(SSL *s, const char *str);
const char *OSSL_default_cipher_list(void);
const char *OSSL_default_ciphersuites(void);

الوصف

SSL_CTX_set_cipher_list() يضبط قائمة التشفيرات المتاحة (TLSv1.2 والإصدارات السابقة) لـ ctx باستخدام سلسلة التحكم str. يتم وصف تنسيق السلسلة في openssl-ciphers(1). يتم وراثة قائمة التشفيرات من قبل جميع كائنات ssl التي تم إنشاؤها من ctx. لا تؤثر هذه الوظيفة على مجموعات التشفير TLSv1.3. استخدم SSL_CTX_set_ciphersuites() لتكوينها. يجب أن يكون ctx غير فارغ.

SSL_set_cipher_list() يضبط قائمة التشفيرات (TLSv1.2 والإصدارات السابقة) فقط لـ ssl.

SSL_CTX_set_ciphersuites() يستخدم لتكوين مجموعات التشفير TLSv1.3 لـ ctx. هذه قائمة منفصلة بنقطتين رأسيتين (":") لمجموعات التشفير TLSv1.3 بترتيب الأفضلية. أسماء مجموعات التشفير TLSv1.3 الصالحة هي:

TLS_AES_128_GCM_SHA256
TLS_AES_256_GCM_SHA384
TLS_CHACHA20_POLY1305_SHA256
TLS_AES_128_CCM_SHA256
TLS_AES_128_CCM_8_SHA256
TLS_SHA384_SHA384 - التكامل فقط
TLS_SHA256_SHA256 - التكامل فقط

يُسمح بقائمة فارغة. القيمة الافتراضية لهذا التكوين هي:

"TLS_AES_256_GCM_SHA384:TLS_CHACHA20_POLY1305_SHA256:TLS_AES_128_GCM_SHA256"

SSL_set_ciphersuites() هو نفس SSL_CTX_set_ciphersuites() باستثناء أنه يضبط مجموعات التشفير لـ ssl.

OSSL_default_cipher_list() يعيد السلسلة الافتراضية للتشفيرات لـ TLSv1.2 (والإصدارات السابقة). OSSL_default_ciphersuites() يعيد السلسلة الافتراضية لمجموعات التشفير TLSv1.3.

ملاحظات

يجب أن تكون سلسلة التحكم str لـ SSL_CTX_set_cipher_list() و SSL_set_cipher_list() و SSL_CTX_set_ciphersuites() و SSL_set_ciphersuites() قابلة للاستخدام عالميًا ولا تعتمد على تفاصيل تكوين المكتبة (التشفيرات المضمنة). لذلك، لا يوجد فحص للصياغة. يتم تجاهل العناصر غير المعروفة، إما لأن التشفيرات غير مضمنة أو لأنها مكتوبة بشكل خاطئ. لا يتم الإبلاغ عن فشل إلا إذا لم يتمكن من تحديد أي تشفير.

يجب ملاحظة أن تضمين تشفير في القائمة هو شرط ضروري. على جانب العميل، يكون التضمين في القائمة كافيًا أيضًا، ما لم يستبعد مستوى الأمان هذا التشفير. على جانب الخادم، تنطبق قيود إضافية. جميع التشفيرات لها متطلبات إضافية. لا تحتاج تشفيرات ADH إلى شهادة، ولكن يجب تكوين معلمات DH. جميع التشفيرات الأخرى تحتاج إلى شهادة ومفتاح مطابق.

يمكن اختيار تشفير RSA فقط عندما تكون شهادة RSA متاحة. تشفيرات RSA التي تستخدم DHE تحتاج إلى شهادة ومفتاح بالإضافة إلى معلمات DH (انظر SSL_CTX_set_tmp_dh_callback(3)).

يمكن اختيار تشفير DSA فقط عندما تكون شهادة DSA متاحة. تستخدم تشفيرات DSA دائمًا تبادل مفاتيح DH وبالتالي تحتاج إلى معلمات DH (انظر SSL_CTX_set_tmp_dh_callback(3)).

عندما لا يتم استيفاء هذه المتطلبات لأي تشفير في القائمة (على سبيل المثال، يدعم العميل فقط تشفيرات RSA للتصدير بطول مفتاح غير متماثل 512 بت والخادم غير مهيأ لاستخدام مفاتيح RSA مؤقتة)، يتم إنشاء الخطأ "no shared cipher" (SSL_R_NO_SHARED_CIPHER) ويفشل المصافحة.

OSSL_default_cipher_list() و OSSL_default_ciphersuites() يحلان محل SSL_DEFAULT_CIPHER_LIST و SSL_DEFAULT_CIPHERSUITES، على التوالي. قائمة التشفيرات المحددة قديمة منذ 3.0.

قيم الإرجاع

SSL_CTX_set_cipher_list() و SSL_set_cipher_list() يعيدان 1 إذا كان يمكن تحديد أي تشفير و 0 في حالة الفشل الكامل.

SSL_CTX_set_ciphersuites() و SSL_set_ciphersuites() يعيدان 1 إذا تم تكوين قائمة مجموعات التشفير المطلوبة، و 0 بخلاف ذلك.
