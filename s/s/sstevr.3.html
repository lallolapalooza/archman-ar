NAME

sstevr - computes the eigenvalues and eigenvectors of a real symmetric tridiagonal matrix.

SYNOPSIS

SUBROUTINE SSTEVR(
   JOBZ, RANGE, N, D, E, VL, VU, IL, IU, TOL, M, NZ, Z, LDZ, WORK, LWORK,
   IWORK, LIWORK, INFO )


CHARACTER(LEN=1) JOBZ, RANGE


INTEGER N, IL, IU, M, NZ, LDZ, LWORK, LIWORK, INFO


REAL D( * ), E( * ), VL, VU, TOL


REAL WORK( * )


INTEGER IWORK( * )


REAL Z( LDZ, * )

Function/Subroutine Documentation

JOBZ

          JOBZ is CHARACTER*1
          = 'N':  Compute only the eigenvalues of A.
          = 'V':  Compute the eigenvalues and the eigenvectors of A.

RANGE

          RANGE is CHARACTER*1
          = 'A': all eigenvalues will be found.
          = 'V': all eigenvalues in the half-open interval (VL, VU] will be
                 found.
          = 'I': all eigenvalues in the open interval (IL, IU), in terms of
                 indices, will be found.

N

          N is INTEGER
          The order of the matrix A.  N >= 0.

D

          D is REAL array, dimension (N)
          On entry, the diagonal elements of A.
          On exit, the eigenvalues, sorted A(j,j) in ascending order.
          If RANGE = 'I' and IL = IU, then D(IL) is the eigenvalue closest to
          the given value TOL.

E

          E is REAL array, dimension (N-1)
          On entry, the subdiagonal elements of A.
          On exit, E is overwritten by values of the computed eigenvectors if
          JOBZ = 'V'.

VL

          VL is REAL
          If RANGE = 'V', the lower bound of the interval for the eigenvalues.

VU

          VU is REAL
          If RANGE = 'V', the upper bound of the interval for the eigenvalues.

IL

          IL is INTEGER
          If RANGE = 'I', the index of the smallest eigenvalue greater than or
          equal to VL.
          If IL = 0, then 1 is used.

IU

          IU is INTEGER
          If RANGE = 'I', the index of the largest eigenvalue less than or
          equal to VU.
          If IU = N+1, then N is used.

TOL

          TOL is REAL
          The desired tolerance for the eigenvalues.  If TOL <= 0, then the
          machine precision will be used.

M

          M is INTEGER
          The total number of eigenvalues found.
          If RANGE = 'A', M = N.
          If RANGE = 'V' or 'I', M = the number of eigenvalues in the
          specified range.

NZ

          NZ is INTEGER
          The number of eigenvectors computed. If JOBZ = 'V', then NZ = M.

Z

          Z is REAL array, dimension (LDZ, NZ)
          On exit, the computed eigenvectors.  The representation of the
          eigenvectors depends on the symmetries of the matrices A and Z.
          If JOBZ = 'V', then the Z matrix contains the eigenvectors of A.
          The column Z(i,j) is the eigenvector corresponding to the eigenvalue
          D(j).
           eigenvectors are normalized so that the squared Euclidean norm is 1.
          In the case of RANGE = 'I', the eigenvectors are sorted according to
          their corresponding eigenvalues D(i).

LDZ

          LDZ is INTEGER
          The leading dimension of the array Z. LDZ >= max(1, N).

WORK

          WORK is REAL array, dimension (MAX(1,LWORK))
          If LWORK is large enough, WORK is used to store intermediate results.
          On exit, if INFO = 0, WORK(1) returns the optimal (and minimal)
          workspace size.

LWORK

          LWORK is INTEGER
          The dimension of the array WORK. LWORK >= 1.
          For optimal performance, LWORK >= 2*N + N*NZ.
          If LWORK = -1, then a workspace query is assumed; the routine only
          calculates the optimal sizes for the arrays WORK and IWORK, returns
          these values as the first entries of the WORK and IWORK arrays, and
          no error message related to LWORK or LIWORK is issued by XERBLA.

IWORK

          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
          If LIWORK is large enough, IWORK is used to store intermediate
          results.
          On exit, if INFO = 0, IWORK(1) returns the optimal (and minimal)
          workspace size.

LIWORK

          LIWORK is INTEGER
          The dimension of the array IWORK. LIWORK >= 1.
          For optimal performance, LIWORK >= 10*N.
          If LIWORK = -1, then a workspace query is assumed; the routine only
          calculates the optimal sizes for the arrays WORK and IWORK, returns
          these values as the first entries of the WORK and IWORK arrays, and
          no error message related to LWORK or LIWORK is issued by XERBLA.

INFO

          INFO is INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value
          > 0:  Internal error:
                If INFO = i, then the i-th eigenvalue failed to converge.
                (Range [IL, IU] means 1-based indexing).
                If INFO = N+1, then all eigenvalues converged, but eigenvectors
                did not converge.
