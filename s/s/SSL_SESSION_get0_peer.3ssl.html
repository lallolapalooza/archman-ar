NAME

SSL_SESSION_GET0_PEER - الحصول على تفاصيل شهادة الطرف الآخر لجلسة

SYNOPSIS

#include <openssl/ssl.h>
X509 *SSL_SESSION_get0_peer(SSL_SESSION *s);

DESCRIPTION

تقوم SSL_SESSION_get0_peer() بإرجاع شهادة الطرف الآخر المرتبطة بالجلسة s أو NULL إذا لم تكن هناك شهادة طرف آخر متاحة. يجب على المستدعي عدم تحرير القيمة المرجعة (ما لم يتم استدعاء X509_up_ref(3) أيضًا).

RETURN VALUES

تقوم SSL_SESSION_get0_peer() بإرجاع مؤشر إلى شهادة الطرف الآخر أو NULL إذا لم تكن شهادة الطرف الآخر متاحة.
