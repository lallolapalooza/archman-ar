NAME

sslh – SSL/SSH multiplexer

SYNOPSIS

sslh [-v] [-F conf] [-p listen_address] [-P pidfile]
     [-i] [-f] [--background] [-l log] [-d] [-t timeout]
     [-u user] [-r chroot]

DESCRIPTION

sslh listens for incoming TCP connections and forks a handler process to serve them. By default, it forks a handler for each connection. A handler inspects the connection to determine whether it is an SSH connection or an SSL/TLS connection.

It is then able to forward the connection to the appropriate server. By default, it forwards SSL connections to port 443 and SSH connections to port 22.

sslh is intended to be run on port 443, and it accepts both SSL/TLS and SSH connections, forwarding each to their respective servers, which may be running on different ports or even different machines.

OPTIONS

-v, --verbose
Verbose mode. This option can be specified multiple times to increase verbosity.
-F conf, --conf conf
Use configuration file conf instead of the default /etc/default/sslh.
-p listen_address, --listen listen_address
Listen on the specified listen_address. This can be an IP address or a hostname. If not specified, sslh listens on all interfaces.
-P pidfile, --pidfile pidfile
Specifies a file in which to write the PID of the main server.
-i, --inetd
Runs as an inetd server. Options -P (PID file), -p (listen address), -u (user) are ignored.
-f, --foreground
Runs in foreground. The server will not fork and will remain connected to the terminal. Messages normally sent to syslog will also be sent to stderr.
--background
Runs in background. This overrides foreground if set in the configuration file (or on the command line, but there is no point setting both on the command line unless you have a personality disorder).

FILES

/etc/init.d/sslh
Start-up script. The standard actions start, stop and restart are supported.
/etc/default/sslh
Server configuration. These are environment variables loaded by the start-up script and passed to sslh as command-line arguments. Refer to the OPTIONS section for a detailed explanation of the variables used by sslh.

SEE ALSO

The latest version is available from https://github.com/yrutschle/sslh. There you can find a more detailed and recent documentation.
