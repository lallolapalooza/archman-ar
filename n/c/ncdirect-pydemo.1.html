ncdirect-pydemo(1)

الحزمة: notcurses

التراخيص: Apache

ncdirect-pydemo(1) دليل الأوامر العامة ncdirect-pydemo(1)

الاسم

ncdirect-pydemo - التحقق من عمل أغلفة Python الخاصة بـ ncdirect

الملخص

ncdirect-pydemo

الوصف

تقوم ncdirect-pydemo بإخراج بعض المخرجات المصممة إلى الطرفية المتصلة باستخدام قدرة الوضع المباشر (direct mode) لوحدة Python الخاصة بـ notcurses (انظر notcurses_direct(3). هذه المخرجات هي وسيلة دنيا للتحقق من أن الوحدة مثبتة بشكل صحيح ويمكن استخدامها في البيئة الحالية.

للحصول على عرض توضيحي أكثر شمولاً، انظر notcurses-demo(1).

خيارات

ملاحظات

يدعم Notcurses Python 3 فقط.
