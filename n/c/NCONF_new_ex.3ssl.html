NCONF_new_ex(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

NCONF_NEW_EX(3ssl) OpenSSL NCONF_NEW_EX(3ssl)

الاسم

NCONF_new_ex, NCONF_new, NCONF_free, NCONF_default, NCONF_load, NCONF_get0_libctx, NCONF_get_section, NCONF_get_section_names - وظائف لتحميل وتحليل ملفات التكوين يدوياً

الملخص

#include <openssl/conf.h>
typedef struct {
    char *section;
    char *name;
    char *value;
} CONF_VALUE;
CONF *NCONF_new_ex(OSSL_LIB_CTX *libctx, CONF_METHOD *meth);
CONF *NCONF_new(CONF_METHOD *meth);
void NCONF_free(CONF *conf);
CONF_METHOD *NCONF_default(void);
int NCONF_load(CONF *conf, const char *file, long *eline);
OSSL_LIB_CTX *NCONF_get0_libctx(const CONF *conf);
STACK_OF(CONF_VALUE) *NCONF_get_section(const CONF *conf, const char *name);
STACK_OF(OPENSSL_CSTRING) *NCONF_get_section_names(const CONF *conf);

الوصف

NCONF_new_ex() تنشئ كائن CONF جديد في الذاكرة وتعيّنه لسياق libctx يمكن استخدامه أثناء التحميل. إذا تم تعيين جدول الطرق meth إلى NULL، فسيتم استخدام القيمة الافتراضية لـ NCONF_default().

NCONF_new() مشابهة لـ NCONF_new_ex() ولكنها تعيّن libctx إلى NULL.

NCONF_free() تحرر البيانات المرتبطة بـ conf ثم تحرر كائن conf. إذا كان الوسيط NULL، فلن يتم فعل شيء.

NCONF_load() تحلل الملف المسمى filename وتضيف القيم التي تم العثور عليها إلى conf. إذا حدث خطأ، فإن file و eline تحدد الملف والسطر الذي فشل التحميل فيه إذا لم يكونا NULL.

NCONF_default() تحصل على جدول الطرق الافتراضي لمعالجة ملف التكوين.

NCONF_get0_libctx() تحصل على سياق المكتبة المرتبط بمعامل conf.

NCONF_get_section_names() تحصل على أسماء الأقسام المرتبطة بـ conf كسلاسل STACK_OF(OPENSSL_CSTRING). السلاسل الفردية مرتبطة بـ conf وستكون غير صالحة بعد تحرير conf. يجب تحرير المكدس المُرجع باستخدام sk_OPENSSL_CSTRING_free().

NCONF_get_section() تحصل على قيم التكوين المرتبطة بـ conf من قسم التكوين name كهياكل STACK_OF(CONF_VALUE). المكدس المُرجع مرتبط بـ conf وسيكون غير صالح بعد تحرير conf. لا يجب تحريره بواسطة المتصل.

قيم الإرجاع

NCONF_load() تُرجع 1 عند النجاح أو 0 عند حدوث خطأ.

NCONF_new_ex() و NCONF_new() تُرجعان كائن CONF تم إنشاؤه حديثًا أو NULL عند حدوث خطأ.
