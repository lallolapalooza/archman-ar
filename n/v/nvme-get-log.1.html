NAME

nvme-get-log - يسترد صفحة سجل من جهاز NVMe

SYNOPSIS

nvme get-log <device> [--log-id=<log-id> | -i <log-id>]
                        [--log-len=<log-len> | -l <log-len>]
                        [--aen=<aen> | -a <aen>]
                        [--namespace-id=<nsid> | -n <nsid>]
                        [--raw-binary | -b]
                        [--lpo=<offset> | -L <offset>]
                        [--lsp=<field> | -s <field>]
                        [--lsi=<field> | -S <field>]
                        [--rae | -r]
                        [--csi=<command_set_identifier> | -y <command_set_identifier>]
                        [--ot=<offset_type> | -O <offset_type>]
                        [--xfer-len=<length> | -x <length>]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

DESCRIPTION

يسترد صفحة سجل NVMe عشوائية من جهاز NVMe ويوفر البنية المُرجعة.

<device> المعلمة إلزامية وقد تكون إما جهاز حرف NVMe (مثال: /dev/nvme0) أو جهاز كتلة مساحة اسم (مثال: /dev/nvme0n1).

عند النجاح، قد يتم إرجاع بنية السجل المُرجعة بإحدى الطرق العديدة اعتمادًا على أعلام الخيارات؛ قد يتم عرض البنية بالسداسي عشري بواسطة البرنامج أو قد تتم طباعة المخزن المؤقت الخام إلى الإخراج القياسي ليقوم برنامج آخر بتحليله.

OPTIONS

-l <log-len>, --log-len=<log-len>

يخصص مخزنًا مؤقتًا بحجم <log-len> بايت ويطلب إرجاع هذا العدد من البايتات في أمر NVMe المُنشأ. هذه المعلمة إلزامية.

-i <log-id>, --log-id=<log-id>

يضبط معرف السجل المطلوب في الأوامر إلى <log-id>. القيمة الافتراضية هي 0.
القيمة التعريف
0x00 | supported-log-pages صفحات السجل المدعومة
0x01 | error معلومات الخطأ
0x02 | smart معلومات SMART / الصحة
0x03 | fw-slot معلومات فتحة البرامج الثابتة
0x04 | changed-ns قائمة مساحات الأسماء التي تم تغييرها
0x05 | cmd-effects الأوامر المدعومة وتأثيراتها
0x06 | device-self-test الاختبار الذاتي للجهاز
0x07 | telemetry-host القياس عن بعد الذي يبدأه المضيف
0x08 | telemetry-ctrl القياس عن بعد الذي يبدأه المتحكم
0x09 | endurance-group معلومات مجموعة التحمل
0x0a | predictable-lat-nvmset الكمون المتوقع لكل مجموعة NVM
0x0b | predictable-lat-agg تجميع أحداث الكمون المتوقع
0x0c | ana الوصول غير المتماثل لمساحة الأسماء
0x0d | persistent-event سجل الأحداث المستمر
0x0e | lba-status معلومات حالة LBA
0x0f | endurance-grp-evt تجميع أحداث مجموعة التحمل
0x10 | media-unit-status حالة وحدة الوسائط
0x11 | supported-cap-config-list قائمة تكوينات السعة المدعومة
0x12 | fid-supported-effects معرفات الميزات المدعومة وتأثيراتها
0x13 | mi-cmd-supported-effects أوامر NVMe-MI المدعومة وتأثيراتها
0x14 | cmd-and-feat-lockdown تأمين الأوامر والميزات
0x15 | boot-partition قسم التمهيد
0x16 | rotational-media-info معلومات الوسائط الدورانية
0x17 | dispersed-ns-participating-ns مساحات الأسماء الموزعة التي تشارك في أنظمة NVM الفرعية
0x18 | mgmt-addr-list قائمة عناوين الإدارة
0x19 | phy-rx-eom قياس فتحة استقبال الواجهة المادية
0x1a | reachability-groups مجموعات إمكانية الوصول
0x1b | reachability-associations ارتباطات إمكانية الوصول
0x1c | changed-alloc-ns-list قائمة مساحات الأسماء المخصصة التي تم تغييرها
0x20 | fdp-configs تكوينات FDP
0x21 | fdp-ruh-usage استخدام مقبض وحدة الاستعادة
0x22 | fdp-stats إحصائيات FDP
0x23 | fdp-events أحداث FDP
0x70 | discover اكتشاف
0x71 | host-discover اكتشاف المضيف
0x72 | ave-discover اكتشاف AVE
0x73 | pull-model-ddc-req طلب DDC لنموذج السحب
0x80 | reservation إشعار الحجز
0x81 | sanitize حالة التنقية
0xbf | zns-changed-zones قائمة المناطق المتغيرة

-a <aen>, --aen=<aen>

حقل ملائم لاستخراج معلومات السجل بناءً على نتيجة إشعار الحدث غير المتزامن. سيؤدي ذلك إلى تجاوز log-id و log-len، إذا تم تعيينهما.

-n <nsid>, --namespace-id=<nsid>

يضبط قيمة nsid للأمر إلى nsid المحدد. القيمة الافتراضية هي 0xffffffff إذا لم يتم تقديمها. قد لا يؤثر هذا الخيار على شيء اعتمادًا على صفحة السجل، والتي قد تكون خاصة بمساحة أسماء أو لا.

-b, --raw-binary

طباعة المخزن المؤقت الخام للسجل إلى الإخراج القياسي.

-L <offset>, --lpo=<offset>

يحدد إزاحة صفحة السجل موقعًا داخل صفحة السجل لبدء إرجاع البيانات منه. إنه محاذي لـ Dword و 64 بت.

-s <field>, --lsp=<field>

المجال المحدد للسجل من LID.

-S <field>, --lsi=<field>

يحدد معرف السجل للحقل المحدد.

-r, --rae

يتيح الاستعلام عن جميع مساحات الأسماء.

-y <command_set_identifier>, --csi=<command_set_identifier>

يحدد معرف مجموعة الأوامر.

-O <offset_type>, --ot=<offset_type>

يحدد نوع الإزاحة.

-x <length>, --xfer-len=<length>

يحدد طول نقل البيانات.

-o <fmt>, --output-format=<fmt>

يحدد تنسيق الإخراج. القيم الممكنة هي 'json' و 'xml' و 'yaml'.

-v, --verbose

تمكين الإخراج المطول.

EXAMPLES

    Get the SMART health information for the NVMe device
    
    # nvme get-log /dev/nvme0 --log-id=smart --log-len=512
    
    Get the Firmware Slot Information for the NVMe device
    
    # nvme get-log /dev/nvme0 -i fw-slot -l 512
    
    Get the entire log page for namespace 1
    
    # nvme get-log /dev/nvme0n1 --namespace-id=1 --log-id=0 --log-len=4096

NVME-GET-LOG RETURN CODES

The return code from this userspace tool is 0 on success, and non-zero otherwise. The specific meaning of a non-zero return code is dependent on the operation being performed.

nvme-get-log(1) — Arch manual pages

NAME

nvme-get-log — Get log page from an NVMe device

SYNOPSIS

nvme get-log [INDEX] [OPTIONS] <DEVICE>

DESCRIPTION

Retrieves a log page from the NVMe device. Log pages provide information about the state and health of the NVMe controller.

OPTIONS

-i <log_identifier>, --log-id=<log_identifier>

This field specifies the log page identifier. The valid range is 0x01-0xFF.

-l <log_length>, --log-len=<log_length>

This field specifies the length of the log page to be retrieved. The length must be a multiple of 4.

-r, --raw-binary

Dump the raw log page in binary format to stdout.

-s <log_specific_identifier>, --log-specific=<log_specific_identifier>

The log specified field of Log Specific Identifier.

-r, --rae

Retain an Asynchronous Event.

-y <command_set_identifier>, --csi=<command_set_identifier>

This field specifies the identifier of command set. if not issued, NVM Command Set will be selected.

-O, --ot

This field specifies the offset type. If set to false, the Log Page Offset Lower field and the Log Page Offset Upper field specify the byte offset into the log page to be returned. If set to true, the Log Page Offset Lower field and the Log Page Offset Upper field specify the index into the list of data structures in the log page to be returned. The default is byte offset. If the option is specified the index mode is used.

-x <length>

--xfer-len <length>: Specify the read chunk size. The length argument is expected to be a multiple of 4096. The default size is 4096.

-o <fmt>, --output-format=<fmt>

Set the reporting format to normal, json or binary. Only one output format can be used at a time.

-v, --verbose

Increase the information detail in the output.

EXAMPLES

•Get 512 bytes from log page 2 
# nvme get-log /dev/nvme0 --log-id=2 --log-len=512

The above example will get log page 2 (SMART), and request 512 bytes. On success, the returned log will be dumped in hex and not interpreted by the program.

•Have the program return the raw log page in binary: 
# nvme get-log /dev/nvme0 -log-id=2 --log-len=512 --raw-binary > log_page_2.raw
# nvme get-log /dev/nvme0 -i 2 -l 512 -b > log_page_2.raw

It is not a good idea to not redirect stdout when using this mode.
