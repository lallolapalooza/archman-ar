الاسم

nvme-solidigm-log-page-directory - استرداد دليل صفحة السجل

الملخص

nvme solidigm log-page-directory <device> [--output-format=<fmt> | -o <fmt>]

الوصف

يسترد ويعرض دليل صفحة السجل لجهاز Solidigm NVMe المحدد. يوفر هذا الأمر معلومات حول صفحات السجل المتاحة وخصائصها.

المعلمة <device> إلزامية وقد تكون إما جهاز حرف NVMe (مثل: /dev/nvme0) أو جهاز كتلة مساحة اسم (مثل: /dev/nvme0n1).

الخيارات

-o <fmt>, --output-format=<fmt>

قم بتعيين تنسيق الإبلاغ إلى normal أو json. يمكن استخدام تنسيق إخراج واحد فقط في كل مرة.

أمثلة

• استرداد وعرض دليل صفحة السجل: 
# nvme solidigm log-page-directory /dev/nvme0
• استرداد دليل صفحة السجل بتنسيق JSON: 
# nvme solidigm log-page-directory /dev/nvme0 -o json
