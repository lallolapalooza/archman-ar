الاسم

nvme-get-feature - يحصل على ميزة NVMe، ويعيد النتائج المطبقة

الملخص

nvme get-feature <الجهاز> [--namespace-id=<nsid> | -n <nsid>]
                        [--feature-id=<fid> | -f <fid>]
                        [--uuid-index=<uuid-index> | -U <uuid_index>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--sel=<select> | -s <select>]
                        [--raw-binary | -b] [--cdw11=<cdw11> | -c <cdw11>]
                        [--human-readable | -H] [--changed | -C]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--timeout=<timeout> | -t <timeout>]

الوصف

يرسل أمر Get Feature إداري NVMe ويعيد النتائج المطبقة. قد تكون هذه قيمة الميزة، أو قد تتضمن أيضًا بنية الميزة إذا كانت الميزة تتطلب ذلك (مثال: نوع نطاق LBA).

المعلمة <الجهاز> إلزامية وقد تكون إما جهاز حرف NVMe (مثال: /dev/nvme0)، أو جهاز كتلة مساحة اسم (مثال: /dev/nvme0n1).

عند النجاح، قد يتم إرجاع بنية الميزة المُعادة (إذا كانت مطبقة) بإحدى الطرق العديدة اعتمادًا على علامات الخيارات؛ قد يتم تحليل البنية بواسطة البرنامج وطباعتها بتنسيق قابل للقراءة إذا كانت بنية معروفة، أو عرضها بتنسيق سداسي عشري، أو قد تتم طباعة المخزن المؤقت الخام إلى الإخراج القياسي لبرنامج آخر لتحليله.

الخيارات

-n <nsid>, --namespace-id=<nsid>

استرد الميزة لمعرف مساحة الاسم المحدد (nsid). هذا اختياري ومعظم الميزات لا تستخدم هذه القيمة.

-f <fid>, --feature-id=<fid>

معرف الميزة المراد إرساله مع الأمر. يجب أن تكون القيمة المقدمة بالتنسيق السداسي عشري.
القيمة التعريف

0x03 | lba-range نوع نطاق LBA
0x04 | temp-thresh حد درجة الحرارة
0x05 | err-recovery استرداد الأخطاء
0x06 | volatile-wc ذاكرة التخزين المؤقت للكتابة المتقلبة
0x07 | num-queues عدد قوائم الانتظار
0x08 | irq-coalesce تجميع المقاطعات
0x09 | irq-config تكوين متجه المقاطعة
0x0a | write-atomic كتابة ذرية عادية
0x0b | async-event تكوين الأحداث غير المتزامنة
0x0c | auto-pst انتقال حالة الطاقة التلقائي
0x0d | host-mem-buf مخزن مؤقت لذاكرة المضيف
0x0e | timestamp الطابع الزمني
0x0f | kato مؤقت البقاء على قيد الحياة

0x19 | iocs-profile ملف تعريف مجموعة أوامر الإدخال/الإخراج
0x1a | spinup-control التحكم في التشغيل

-s <select>, --sel=<select>

تحديد (SEL): يحدد هذا الحقل أي قيمة من سمات السمات سيتم إرجاعها في البيانات المقدمة:
تحديد الوصف
0 الحالي
1 الافتراضي
2 أقصى
3 غير متغير

-U <uuid-index>, --uuid-index=<uuid-index>

يحدد هذا الحقل مؤشر UUID المستخدم في أمر Get Features. هذا الحقل مطلوب فقط إذا كان Feature ID (معرف الميزة) هو 0x03 (LBA Range Type).

-l <data-len>, --data-len=<data-len>

يحدد هذا الحقل طول البيانات بوحدات 4 بايت. إذا لم يتم تحديده، فإن الأداة ستحاول تحديد الحجم المناسب بناءً على Feature ID.

-b, --raw-binary

يخرج البيانات في شكل ثنائي خام.

-c <cdw11>, --cdw11=<cdw11>

تجاوز قيمة CDW11.

-H, --human-readable

تنسيق البيانات القابلة للقراءة من قبل الإنسان.

-C, --changed

يطبع فقط الميزات التي تم تغييرها عن قيمها الافتراضية.

-o <fmt>, --output-format=<fmt>

قم بتغيير تنسيق خرج سطر الأوامر. القيم الممكنة هي "json" أو "binary".

-v, --verbose

إظهار معلومات إضافية حول العملية.

-t <timeout>, --timeout=<timeout>

تعيين المهلة بالمللي ثانية.

أمثلة

Get the Arbitration feature from the controller:
    # nvme get-feature /dev/nvme0 -f 0x01

Get the LBA Range Type feature from namespace 1:
    # nvme get-feature /dev/nvme0n1 -f 0x03 -n 1

Get the current Power Management settings for namespace 1, with human readable
output:
    # nvme get-feature /dev/nvme0n1 -f 0x02 -n 1 -s 0 -H

Get the default value for the Temperature Threshold feature:
    # nvme get-feature /dev/nvme0 -f 0x04 -s 1

Get the raw binary output for the Host Identifier feature:
    # nvme get-feature /dev/nvme0 -f 0x81 -b

NAME

nvme-get-feature - Get NVMe controller information

SYNOPSIS

nvme get-feature [-a | --all] [-H | --human-readable] [-C | --changed] [-o <fmt> | --output-format=<fmt>] [-v | --verbose] [-t <timeout> | --timeout=<timeout>] [-f <feature-id> | --feature-id=<feature-id>] [-i <id> | --id=<id>] [-U <uuid-index> | --uuid-index=<uuid-index>] [-l <data-len> | --data-len=<data-len>] [-c <cdw11> | --cdw11=<cdw11>] [-b | --raw-binary] <device>

Features with IDs 0-31 are defined by the NVMe specification. Features with IDs 32-67 are defined by the NVM Express Management Interface (NVMe-MI) specification. Features with IDs 68-252 are vendor-specific. Features with IDs 253-255 are reserved.

Features can also have specific attributes associated with them, such as UUID index, data length, or command dword values. These are specified using the following options.

-U <uuid-index>, --uuid-index=<uuid-index>

UUID Index of the feature

-l <data-len>, --data-len=<data-len>

The data length for the buffer returned for this feature. Most known features do not use this value. The exception is LBA Range Type

-c <cdw11>, --cdw11=<cdw11>

The value for command dword 11, if applicable.

-b, --raw-binary

Print the raw feature buffer to stdout if the feature returns a structure.

-H, --human-readable

This option will parse and format many of the bit fields into human-readable formats.

-C, --changed

This option will show feature changed.

-o <fmt>, --output-format=<fmt>

Set the reporting format to normal, json or binary. Only one output format can be used at a time.

-v, --verbose

Increase the information detail in the output.

-t <timeout>, --timeout=<timeout>

Override default timeout value. In milliseconds.

EXAMPLES

•Retrieves the feature for Number of Queues, or feature id 7: 
# nvme get-feature /dev/nvme0 -f 7
•The following retrieves the feature for the LBA Range Type, which implicitly requires a buffer and will be printed to the screen in human readable format: 
# nvme get-feature /dev/nvme0 -f 3
•Retrieves the feature for the some vendor specific feature and specifically requesting a buffer be allocate for this feature, which will be displayed to the user in as a hex dump: 
# nvme get-feature /dev/nvme0 -f 0xc0 -l 512

Get feature with UUID index

# nvme get-feature /dev/nvme0 -f 0xc0 -l 512 -U 0x1
•The following retrieves the feature for the LBA Range Type, which implicitly requires a buffer and will be saved to a file in its raw format: 
# nvme get-feature /dev/nvme0 -f 3 --raw-binary > lba_range.raw

It is probably a bad idea to not redirect stdout when using this mode.
