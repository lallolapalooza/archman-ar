nvme-nvm-id-ctrl(1)

الحزمة: nvme-cli

التراخيص: GPL-2.0-or-later

NVME-NVM-ID-CTRL(1) دليل NVMe NVME-NVM-ID-CTRL(1)

الاسم

nvme-nvm-id-ctrl - إرسال أمر NVMe Identify Controller، وإرجاع بنية مجموعة أوامر NVM

ملخص

nvme nvm-id-ctrl <device> [--output-format=<fmt> | -o <fmt>] [--verbose | -v]

الوصف

بالنسبة لجهاز NVMe المحدد، يقوم بإرسال أمر مجموعة أوامر NVM (Identify Controller) ويوفر النتيجة والبنية المُرجعة.

المعلمة <device> إلزامية وقد تكون إما جهاز حرف NVMe (مثل: /dev/nvme0) أو جهاز كتلة مساحة اسم (مثل: /dev/nvme0n1).

عند النجاح، سيتم فك تشفير بنية البيانات التي تم إرجاعها بواسطة الجهاز وعرضها بإحدى الطرق المتعددة.

خيارات

-o <fmt>, --output-format=<fmt>

يحدد تنسيق التقرير ليكون normal، json، أو binary. يمكن استخدام تنسيق إخراج واحد فقط في كل مرة.

-v, --verbose

زيادة تفاصيل المعلومات في الإخراج.

أمثلة

•يجعل البرنامج يفسر المخزن المؤقت المُرجع ويعرض الحقول المعروفة بتنسيق يمكن قراءته بواسطة الإنسان: 
# nvme nvm-id-ctrl /dev/nvme0
•عرض الإخراج بتنسيق json 
# nvme nvm-id-ctrl /dev/nvme0 -o json
