nvme-ocp-set-dssd-async-event-config(1)

الحزمة: nvme-cli

التراخيص: GPL-2.0-or-later

NVME-OCP-SET-DSSD(1) دليل NVMe NVME-OCP-SET-DSSD(1)

الاسم

nvme-ocp-set-dssd-async-event-config - ضبط تكوين أحداث DSSD غير المتزامنة

الملخص

nvme ocp set-dssd-async-event-config <device> [--enable-panic-notices | -e] [--save | -s]

الوصف

ضبط تكوين أحداث DSSD غير المتزامنة.

المعلمة <device> إلزامية وقد تكون إما جهاز حرف NVMe (مثل: /dev/nvme0) أو جهاز كتلة (مثل: /dev/nvme0n1).

لن يعمل هذا إلا على الأجهزة المتوافقة مع OCP التي تدعم هذه الميزة. النتائج لأي جهاز آخر غير محددة.

عند النجاح، يعيد 0، رمز خطأ بخلاف ذلك.

الخيارات

-e, --enable-panic-notices

تعيين تمكين إشعارات الذعر [0]

-s, --save

حفظ السمة بحيث تستمر عبر جميع حالات الطاقة وإعادة الضبط.

أمثلة

• جعل البرنامج يصدر أمر set-dssd-async-event-config لتمكين إشعارات الذعر، مع الاستمرار عبر حالات الطاقة. 
# nvme ocp set-dssd-async-event-config /dev/nvme0 -e -s
