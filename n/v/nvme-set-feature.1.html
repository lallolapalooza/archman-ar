nvme-set-feature(1)

الحزمة: nvme-cli

التراخيص: GPL-2.0-or-later

NVME-SET-FEATURE(1) يدوي NVMe NVME-SET-FEATURE(1)

الاسم

nvme-set-feature - يضبط ميزة NVMe، ويعيد النتائج المطبقة.

ملخص

nvme set-feature <الجهاز> [--namespace-id=<nsid> | -n <nsid>]
                        [--feature-id=<fid> | -f <fid>] [--value=<value> | -V <value>]
                        [--uuid-index=<uuid-index> | -U <uuid_index>]
                        [--data-len=<data-len> | -l <data-len>]
                        [--data=<data-file> | -d <data-file>] [--save | -s]
                        [--output-format=<fmt> | -o <fmt>] [--verbose | -v]
                        [--cdw12=<cdw12> | -c <cdw12>]
                        [--timeout=<timeout> | -t <timeout>]

الوصف

يقوم بإرسال أمر تعيين ميزة NVMe إداري ويعيد النتائج المطبقة. قد يكون هذا هو قيمة الميزة، أو قد يشمل أيضًا بنية ميزة إذا كانت الميزة تتطلب ذلك (مثل: نوع نطاق LBA).

<الجهاز> المعلمة إلزامية وقد تكون إما جهاز حرف NVMe (مثل /dev/nvme0)، أو جهاز كتلة مساحة اسم (مثل /dev/nvme0n1).

عند النجاح، يتم عرض القيمة المرسلة إلى الجهاز.

الخيارات

-n <nsid>, --namespace-id=<nsid>

يضبط الميزة لمعرف مساحة الاسم المعطى. هذا اختياري ومعظم الميزات لا تستخدم هذه القيمة.

-f <fid>, --feature-id=<fid>

معرف الميزة الذي سيتم إرساله مع الأمر. يجب أن تكون القيمة المقدمة بالترميز الست عشري.

-l <data-len>, --data-len=<data-len>

طول البيانات للمخزن المؤقت المقدم لهذه الميزة. معظم الميزات المعروفة لا تستخدم هذه القيمة. الاستثناءات هي نوع نطاق LBA ومعرف المضيف.

-d <data-file>, --data=<data-file>

ملف البيانات للمخزن المؤقت المقدم لهذه الميزة. معظم الميزات المعروفة لا تستخدم هذه القيمة. الاستثناءات هي نوع نطاق LBA ومعرف المضيف. افتراضياً هو STDIN لذا يمكن تمرير الملفات والطبع إليها.

-V <value>, --value=<value>

القيمة للكلمة 11 من الأمر، وهي القيمة التي تريد تعيين الميزة إليها.

-s, --save

حفظ السمة بحيث تستمر عبر جميع حالات الطاقة وإعادة التشغيل.

nvme-set-feature(1) — Arch Linux

NAME

nvme-set-feature — Get/Set arbitrary NVMe feature values

SYNOPSIS

nvme set-feature [<device>] [-a | --all] [-f <fid> | --fid=<fid>] [-V <value> | --value=<value>] [-l <len> | --length=<len>] [-S <spwid> | --spwid=<spwid>] [-U <uid> | --uid=<uid>] [-o <fmt> | --output-format=<fmt>] [-v | --verbose] [-c <cdw12> | --cdw12=<cdw12>] [-t <timeout> | --timeout=<timeout>]

DESCRIPTION

The nvme set-feature command is used to set an arbitrary NVMe feature value. Features are identified by a feature ID (FID) and may require additional parameters, such as a value, length, or specific sub-identifiers depending on the feature itself.

This command can either target a specific NVMe controller (device) or operate on all discovered NVMe devices if the --all option is used.

OPTIONS

-a, --all

Operate on all available NVMe devices.

-f <fid>, --fid=<fid>

Specify the Feature ID. This is a required parameter unless the --all option is used without a specific FID, in which case it might attempt to set a default or commonly used feature.

-V <value>, --value=<value>

Specify the value to write to the feature. The format of the value (e.g., hexadecimal, decimal, string) depends on the specific feature being set.

-l <len>, --length=<len>

Specify the length of the data to be written for the feature. This is often used when the feature value is represented as a buffer or string.

-S <spwid>, --spwid=<spwid>

Specify the Space ID. Used for features that involve different address spaces.

-U <uid>, --uid=<uid>

Specify the User ID. Used for features that require user identification.

-o <fmt>, --output-format=<fmt>

Set the reporting format to normal, json or binary. Only one output format can be used at a time.

-v, --verbose

Increase the information detail in the output.

-c <cdw12>, --cdw12=<cdw12>

The value for command dword 12, if applicable.

-t <timeout>, --timeout=<timeout>

Override default timeout value. In milliseconds.

EXAMPLES

•Sets the Power State (PS) to 1 in feature id 2: 
# nvme set-feature /dev/nvme0 -f 2 /dev/nvme0n1 -V 0x1
•Sets the host id to the ascii string. 
# echo "abcdefgh" | nvme set-feature /dev/nvme0 -f 0x81 -l 8

nvme set-feature /dev/nvme0 -f 0x81 -l 8 -U 0x1
