nvme-zns-zone-mgmt-recv(1)

الحزمة: nvme-cli

التراخيص: GPL-2.0-or-later

NVME-ZNS-ZONE-MGM(1) دليل NVMe NVME-ZNS-ZONE-MGM(1)

الاسم

nvme-zns-zone-mgmt-recv - أمر استلام إدارة المنطقة

الملخص

nvme zns zone-mgmt-recv <الجهاز> [--namespace-id=<العدد> | -n <العدد>]
                        [--start-lba=<LBA> | -s <LBA>]
                        [--data-len=<عدد الإدخال/الإخراج>, -l <عدد الإدخال/الإخراج>]
                        [--zra=<العدد>, -z <العدد>] [--zrasf=<العدد>, -a <العدد>]
                        [--zra-spec-feat, -f] [--output-format=<الصيغة>, -o <الصيغة>]

الوصف

بالنسبة لجهاز NVMe المحدد، يقوم بتنفيذ أمر استلام إدارة المنطقة مع إجراء الاستلام المطلوب ومعلمات إضافية خاصة بالإجراء. هذا هو الواجهة العامة المقدمة للتوافق المستقبلي حيث يتم إنشاء إجراءات جديدة لا يدركها هذا البرنامج في وقت تطويره. على هذا النحو، هذا أمر عام لا يقوم بأي فك تشفير إضافي لأنواع معينة من البيانات المستلمة. سيقوم هذا فقط بالإبلاغ عن البيانات كملف سداسي عشري، أو ثنائي.

الخيارات

-n <العدد>, --namespace-id=<العدد>

استخدم معرف مساحة الاسم المحدد للأمر. إذا لم يتم توفيره، سيتم استخدام معرف مساحة الاسم للجهاز الكتلي. إذا تم إصدار الأمر لجهاز غير كتلي، فإن المعلمة مطلوبة.

-s <lba>, --start-lba=<lba>

LBA البداية للمنطقة المراد إدارتها واستلامها.

-l <العدد> --data-len=<العدد> طول مخزن البيانات المستلمة

-z <العدد>, --zra=<العدد>

إجراء استلام المنطقة

-a <العدد> --zrasf=<العدد> حقل خاص بإجراء استلام المنطقة

-f, --zra-spec-feat

تمكين الميزات الخاصة بإجراء استلام المنطقة

-o <الصيغة>, --output-format=<الصيغة>

صيغة الإخراج: normal|json|binary

أمثلة

• تفريغ سداسي عشري لجميع المناطق 
# nvme zns zone-mgmt-recv /dev/nvme0 -n 1 -s 0 -z 0 -a 0 -l 4k
• تفريغ ثنائي لجميع المناطق 
# nvme zns zone-mgmt-recv /dev/nvme0 -n 1 -s 0 -z 0 -a 0 -o -l 4k binary > report.out
