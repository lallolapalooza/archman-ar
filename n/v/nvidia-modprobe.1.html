nvidia-modprobe(1)

الحزمة: nvidia-utils

التراخيص: custom

nvidia-modprobe(1) دليل الأوامر العامة nvidia-modprobe(1)

الاسم

nvidia-modprobe - تحميل الوحدة النمطية للنواة NVIDIA وإنشاء ملفات جهاز NVIDIA.

الملخص

nvidia-modprobe [خيارات]
nvidia-modprobe [خيارات] --create-nvidia-device-file=رقم_الجهاز_الصغير
nvidia-modprobe [خيارات] --module-instance=مثيل_الوحدة_النمطية

الوصف

تُستخدم الأداة المساعدة nvidia-modprobe بواسطة مكونات برنامج تشغيل NVIDIA لمساحة المستخدم للتأكد من تحميل الوحدة النمطية للنواة NVIDIA، ووجود ملفات جهاز NVIDIA، وتكوين إعدادات وقت التشغيل معينة في النواة. يتم توفير هذه المرافق عادةً بواسطة أنظمة تكوين توزيع Linux مثل udev. عند الإمكان، يُوصى باستخدام آليات توزيع Linux الأصلية لإدارة تحميل الوحدة النمطية للنواة، وإنشاء ملفات الأجهزة، وإعدادات تكوين وقت التشغيل للنواة. هذه الأداة المساعدة متوفرة كحل بديل للعمل "خارج الصندوق" بطريقة مستقلة عن التوزيع.

عند تثبيتها بواسطة nvidia-installer ، يتم تثبيت nvidia-modprobe بامتيازات المستخدم الجذر (setuid root).

لا يحتاج المستخدمون عادةً إلى تشغيل nvidia-modprobe يدويًا: ستتفرع مكونات برنامج تشغيل NVIDIA لمساحة المستخدم (fork(2)/exec(3)) عند الحاجة.

عند تشغيلها بدون أي خيارات، ستقوم nvidia-modprobe بتحميل الوحدة النمطية للنواة NVIDIA ثم تخرج. عند تحديد الخيار --module-instance على الأنظمة التي تحتوي على وحدات نمطية متعددة للنواة NVIDIA، ستقوم nvidia-modprobe بتحميل الوحدة النمطية للنواة NVIDIA المقابلة ثم تخرج. عند تحديد الخيار --create-nvidia-device-file ، ستقوم nvidia-modprobe أيضًا بإنشاء ملف الجهاز المطلوب.

كود مصدر nvidia-modprobe متاح هنا:
⟨ https://download.nvidia.com/XFree86/nvidia-modprobe/ ⟩

الخيارات

-v, --version
طباعة إصدار الأداة المساعدة والخروج.
-h, --help
طباعة معلومات الاستخدام لخيارات سطر الأوامر والخروج.
-c رقم_الجهاز_الصغير, --create-nvidia-device-file=رقم_الجهاز_الصغير
إنشاء ملف جهاز NVIDIA بالرقم الصغير المحدد؛ يمكن تحديد هذا الخيار عدة مرات لإنشاء ملفات أجهزة NVIDIA متعددة.

خيارات متقدمة

-u, --unified-memory
تحميل الوحدة النمطية للنواة NVIDIA Unified Memory أو إنشاء ملفات أجهزة لها، بدلاً من الوحدة النمطية للنواة NVIDIA.
-m, --modeset
تحميل الوحدة النمطية للنواة NVIDIA modeset وإنشاء ملف جهازها.
-s, --nvswitch
تحميل الوحدة النمطية للنواة NVIDIA وإنشاء ملفات أجهزة NVSwitch لكل رقم جهاز صغير محدد باستخدام العلم -c.
-l, --nvlink
تحميل الوحدة النمطية للنواة NVIDIA وإنشاء ملف جهاز التحكم NVLink.
-f ملف_جهاز_قدرات_NVIDIA, --nvidia-capability-device-file=ملف_جهاز_قدرات_NVIDIA
إنشاء ملفات أجهزة قدرات NVIDIA بالمسار المحدد للملف /proc. يمكن تحديد هذا الخيار عدة مرات لإنشاء ملفات أجهزة قدرات NVIDIA متعددة.
-a, --auto-online-movable
تمكين إعداد نواة "online_movable" تلقائي للمنصات (مثل Grace Hopper) التي تضيف ذاكرة GPU إلى النواة وتجعلها متاحة.

أمثلة

nvidia-modprobe
تشغيل `/sbin/modprobe nvidia`
nvidia-modprobe -c 0 -c 1
تشغيل `/sbin/modprobe nvidia` وإنشاء `/dev/nvidia0` و `/dev/nvidia1`
nvidia-modprobe -i 0
تشغيل `/sbin/modprobe nvidia0`
