nvmetcli(8)

الحزمة: nvmetcli

التراخيص: Apache-2.0

الاسم

nvmetcli - أداة سطر أوامر لتكوين NVMe Target.

الاستخدام

  nvmetcli [options] <command>
  nvmetcli restore <config_file>
  nvmetcli clear
  nvmetcli help

الوصف

nvmetcli هي أداة لسطر الأوامر لتكوين NVMe Target. إنها تتيح لك إنشاء وإدارة NVMe Targets، بما في ذلك تكوين المنافذ، والأجهزة، والمضيفين، والاختيارات. يمكن استخدامها لتطبيق إعدادات NVMe Target من ملف أو لمسح التكوين الحالي.

الخلفية

NVMe Target هو مكون في بروتوكول NVMe over Fabrics (NVMe-oF) يسمح بالوصول إلى أجهزة التخزين NVMe عبر الشبكة. يدعم nvmetcli تكوين NVMe Target من خلال واجهة سطر أوامر، مما يسهل إعداد وإدارة NVMe Targets.

الخيارات

لا توجد خيارات عامة متاحة حاليًا لـ nvmetcli. يتم تحديد الخيارات لكل أمر.

أمثلة

•الدخول إلى وضع سطر الأوامر التفاعلي:
./nvmetcli
•إنشاء NVMe Target جديد:
...> create testnqn
•ضبط عنوان NVMe Target:
...> set addr traddr=nn-0x1000000044001123:pn-0x2000000055001123
•ضبط معرف خدمة النقل:
...> set addr trsvcid=none
•الانتقال إلى دليل الأقسام الفرعية:
...> cd subsystems/
•حفظ تكوين NVMe Target:
./nvmetcli
...> saveconfig test.json
•تحميل تكوين NVMe Target:
  ./nvmetcli restore test.json
•مسح تكوين NVMe Target الحالي:
  ./nvmetcli clear

معلومات إضافية

يمتلك nvmetcli القدرة على بدء وإيقاف تكوين NVMe Target عند الإقلاع والإيقاف عبر أداة systemctl في لينكس باستخدام ملف .service. تأتي حزمة nvmetcli مع nvmet.service، والذي عند تثبيته، يمكنه استعادة تكوين NVMe Target الافتراضي والمحفوظ تلقائيًا من /etc/nvmet/config.json. يمكن تثبيت nvmet.service في أدلة مثل /lib/systemd/system.

لتمكين الخدمة بشكل صريح، اكتب:

  systemctl enable nvmet

لتعطيل الخدمة بشكل صريح، اكتب:

  systemctl disable nvmet

انظر أيضًا systemctl(1).
