ntp_gettime(3) دليل وظائف المكتبة ntp_gettime(3)

الاسم

ntp_gettime, ntp_gettimex - الحصول على معلمات الوقت (واجهة خادم NTP)

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/timex.h>
int ntp_gettime(struct ntptimeval *ntv);
int ntp_gettimex(struct ntptimeval *ntv);

الوصف

كلتا هاتين الواجهتين ترجعان معلومات إلى المتصل عبر الوسيط ntv، وهو هيكل من النوع التالي:


struct ntptimeval {
    struct timeval time;    /* الوقت الحالي */
    long maxerror;          /* الخطأ الأقصى */
    long esterror;          /* الخطأ المقدر */
    long tai;               /* إزاحة TAI */
    /* بايتات حشو إضافية تسمح بالتوسع المستقبلي */
};

الحقول في هذا الهيكل هي كما يلي:

time
الوقت الحالي، معبراً عنه كهيكل timeval:

struct timeval {
    time_t      tv_sec;   /* الثواني منذ الحقبة */
    suseconds_t tv_usec;  /* الميكروثواني */
};

maxerror
الخطأ الأقصى، بالميكروثواني. يمكن تهيئة هذه القيمة بواسطة ntp_adjtime(3)، ويتم زيادتها بشكل دوري (في لينكس: كل ثانية)، ولكنها تُحصر عند حد أقصى (ثابت النواة NTP_PHASE_MAX، بقيمة 16,000).
esterror
الخطأ المقدر، بالميكروثواني. يمكن تعيين هذه القيمة عبر ntp_adjtime(3) لاحتواء تقدير الفرق بين ساعة النظام والوقت الحقيقي. لا تُستخدم هذه القيمة داخل النواة.
tai
إزاحة TAI (الوقت الدولي الذري).

ترجع ntp_gettime() هيكل ntptimeval يتم ملء الحقول time و maxerror و esterror فيه.

تقوم ntp_gettimex() بنفس مهمة ntp_gettime()، ولكنها ترجع أيضًا معلومات في الحقل tai.

قيمة الإرجاع

قيم الإرجاع لـ ntp_gettime() و ntp_gettimex() هي كما في adjtimex(2). بالنظر إلى وسيط مؤشر صحيح، تنجح هذه الوظائف دائمًا.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).
