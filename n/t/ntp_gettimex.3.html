ntp_gettime(3) دليل دوال المكتبة ntp_gettime(3)

الاسم

ntp_gettime, ntp_gettimex - الحصول على معلمات الوقت (واجهة خادم NTP)

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/timex.h>
int ntp_gettime(struct ntptimeval *ntv);
int ntp_gettimex(struct ntptimeval *ntv);

الوصف

كلتا هاتين الواجهتين تعيدان معلومات إلى المتصل عبر الوسيط ntv، وهو بنية من النوع التالي:


struct ntptimeval {
    struct timeval time;    /* الوقت الحالي */
    long maxerror;          /* أقصى خطأ */
    long esterror;          /* الخطأ المقدر */
    long tai;               /* إزاحة TAI */
    /* بايتات حشو إضافية تسمح بالتوسع المستقبلي */
};

حقول هذه البنية هي كما يلي:

time
الوقت الحالي، معبرًا عنه كبنية timeval:

struct timeval {
    time_t      tv_sec;   /* الثواني منذ العصر */
    suseconds_t tv_usec;  /* ميكروثواني */
};

maxerror
أقصى خطأ، بالميكروثواني. يمكن تهيئة هذه القيمة بواسطة ntp_adjtime(3)، ويتم زيادتها بشكل دوري (في لينكس: كل ثانية)، ولكنها تحدد عند حد أقصى (ثابت النواة NTP_PHASE_MAX، بقيمة 16,000).
esterror
الخطأ المقدر، بالميكروثواني. يمكن تعيين هذه القيمة عبر ntp_adjtime(3) لتشمل تقدير الفرق بين ساعة النظام والوقت الحقيقي. لا يتم استخدام هذه القيمة داخل النواة.
tai
إزاحة TAI (الوقت الدولي الذري).

ntp_gettime() تعيد بنية ntptimeval يتم ملء حقلي time و maxerror و esterror فيها.

ntp_gettimex() تقوم بنفس مهمة ntp_gettime()، ولكنها تعيد أيضًا معلومات في حقل tai.

قيمة الإرجاع

قيم الإرجاع لـ ntp_gettime() و ntp_gettimex() هي نفسها لـ adjtimex(2). بالنظر إلى وسيط مؤشر صحيح، تنجح هذه الدوال دائمًا.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).
