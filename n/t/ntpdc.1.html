ntpdc(1) أوامر المستخدم ntpdc(1)

الاسم

ntpdc - برنامج تحكم خاص بالبائع لـ NTPD

الملخص

ntpdc [-flags] [-flag [value]] [--option-name[[=| ]value]] [ host ...]

الوصف

ntpdc مهمل. يرجى استخدام ntpq(1) بدلاً من ذلك - يمكنه فعل كل ما كان يفعله ntpdc ، ويفعل ذلك باستخدام واجهة أكثر منطقية بكثير.

ntpdc هو برنامج مساعد يستخدم للاستعلام عن ntpd(1) حول حالته الحالية ولطلب تغييرات في تلك الحالة. يستخدم تنسيقات رسائل التحكم NTP الوضع 7 الموضحة في الكود المصدري. قد يتم تشغيل البرنامج إما في وضع التفاعل أو التحكم فيه باستخدام وسيطات سطر الأوامر . تتوفر معلومات حالة وإحصائيات شاملة من خلال واجهة ntpdc. بالإضافة إلى ذلك، يمكن تحديد ما يقرب من كل خيارات التهيئة التي يمكن تحديدها عند بدء التشغيل باستخدام ملف تهيئة ntpd في وقت التشغيل باستخدام ntpdc.

الاستخدام

إذا تم تضمين خيار طلب واحد أو أكثر في سطر الأوامر عند تنفيذ ntpdc، فسيتم إرسال كل طلب إلى خوادم NTP التي تعمل على كل من المضيفات المقدمة كوسيطات لسطر الأوامر، أو على localhost افتراضيًا. إذا لم يتم تقديم خيارات طلب، فسيحاول ntpdc قراءة الأوامر من المدخل القياسي وتنفيذها على خادم NTP الذي يعمل على المضيف الأول المقدم في سطر الأوامر، مع العودة إلى localhost افتراضيًا عندما لا يتم تحديد مضيف آخر. سيقوم الأداة المساعدة ntpdc بالمطالبة بالأوامر إذا كان المدخل القياسي جهاز طرفي.

تستخدم الأداة المساعدة ntpdc حزم NTP الوضع 7 للتواصل مع خادم NTP، وبالتالي يمكن استخدامها للاستعلام عن أي خادم متوافق على الشبكة يسمح بذلك. لاحظ أنه نظرًا لأن NTP بروتوكول UDP، سيكون هذا الاتصال غير موثوق به إلى حد ما، خاصة عبر مسافات كبيرة من حيث طوبولوجيا الشبكة. لا تبذل الأداة المساعدة ntpdc أي محاولة لإعادة إرسال الطلبات، وستنتهي مهلة الطلبات إذا لم يتم سماع المضيف البعيد في غضون وقت مهلة مناسب.

تكون عمليات ntpdc خاصة بالتنفيذ المحدد لـ ntpd(1) الخادم ويمكن توقع أن تعمل فقط مع هذا وربما بعض الإصدارات السابقة من الخادم. يجب المصادقة على الطلبات من أداة مساعدة ntpdc بعيدة التي تؤثر على حالة الخادم المحلي، مما يتطلب أن يتشارك كل من البرنامج البعيد والخادم المحلي في مفتاح ومعرف مفتاح مشترك.

لاحظ أنه في السياقات التي يُتوقع فيها اسم مضيف، فإن المؤهل -4 الذي يسبق اسم المضيف يفرض تحليل DNS إلى مساحة أسماء IPv4، بينما يفرض المؤهل -6 تحليل DNS إلى مساحة أسماء IPv6. سيؤدي تحديد خيار سطر أوامر بخلاف -i أو -n إلى إرسال الاستعلام (الاستعلامات) المحددة إلى المضيف (المضيفات) المشار إليها على الفور. بخلاف ذلك، سيحاول ntpdc قراءة الأوامر بالتنسيق التفاعلي من المدخل القياسي.

ntpdc(8) - Network Time Protocol (NTP) daemon control utility

NAME

ntpdc - Network Time Protocol (NTP) daemon control utility

SYNOPSIS

ntpdc [-i] [-p] [-s] [-k keyfile] [-n ntphost] [command ...]

DESCRIPTION

The ntpdc utility is used to control the operation of an ntpd daemon, and to query its status. The program allows you to poll the daemon for information, and to set various operating parameters. It is intended to be used interactively, or from a script. It uses the NTP control message protocol to communicate with the daemon.

When started, ntpdc will attempt to contact the daemon specified by the ntphost argument, or the default host (localhost if none is specified). If the daemon is running and configured to allow control from the local host, ntpdc will prompt for commands. If commands are given on the command line, ntpdc will execute them and exit.

The ntpdc utility requires an access control list (ACL) entry in the ntpd configuration file (usually /etc/ntp.conf) that permits control messages from the host where ntpdc is being run. An example entry would be:

restrict 127.0.0.1 nomodify notrap nopeer

This entry allows control messages from the local host (127.0.0.1) but disallows modifications to the configuration (nomodify), trap messages (notrap), and peering (nopeer).

OPTIONS

The following options are available:

-i
Force interactive mode. This is the default when no commands are given on the command line.
-p
Print a list of hosts currently synchronized with the local daemon. This is equivalent to running the 'pntp' command interactively.
-s
Print statistics since the daemon was started. This is equivalent to running the 'stats' command interactively.
-k keyfile
Use the specified keyfile for authentication. The keyfile should contain the key ID and the key itself, in the format specified by the ntpd.conf man page.
-n ntphost
Specify the host on which the ntpd daemon is running. If this option is omitted, ntpdc will attempt to contact the daemon on the default host (localhost).

OPTION PRESETS

None.

USAGE

When run in interactive mode, ntpdc presents a prompt like this:

ntpdc>

You can then enter commands at the prompt. To exit, type quit or ^D.

The available commands are:

add host
Add a host to the list of monitored hosts. This is equivalent to adding an entry to the configuration file and reloading the configuration.
clear
Clear statistics counters.
clockstats
Show clock discipline statistics.
deltats
Show delta time statistics.
editinputs
Edit the list of input peers.
exit
Exit ntpdc.
getauth
Show authentication information.
getmoodys
Show current state of the internal state machine.
getpeerinfo [associd]
Show information about a specific peer, or all peers if no associd is given.
getsysinfo
Show system variables.
ifstats
Show interface statistics.
keydefaults
Show default keys.
loopstats
Show clock loop filter statistics.
memstats
Show memory statistics.
msas
Show monitored association statistics.
ntpq
Invoke the ntpq utility. This is only available if ntpq is installed.
pstats
Show protocol statistics.
pntp
Print a list of hosts currently synchronized with the local daemon.
quit
Exit ntpdc.
readvar
Read system variables.
reset
Reset the system variables.
rm [associd]
Remove a host from the list of monitored hosts. If no associd is given, all hosts are removed.
save
Save configuration to disk.
setcomm [value]
Set the communication mode. value is a bitmask.
setclk [value]
Set the clock discipline parameters.
setdali [value]
Set the DALI parameters.
setflag [flag] [value]
Set a specific flag. flag is the name of the flag, and value is 0 or 1.
setip [value]
Set the IP address.
setkey [keyid] [key]
Set the authentication key.
setpoll [value]
Set the polling interval.
setrefid [value]
Set the reference ID.
setsys [variable] [value]
Set a system variable.
setvar [variable] [value]
Set a system variable.
stats
Show statistics since the daemon was started.
sysinfo
Show system information.
tams
Show time access monitoring statistics.
trace
Trace packets.
version
Show version information.

ENVIRONMENT

None.

FILES

/etc/ntp.conf
NTP daemon configuration file.

EXIT STATUS

On successful completion, ntpdc returns 0. If an error occurs, it returns a non-zero value.
