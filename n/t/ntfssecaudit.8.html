ntfssecaudit(8)

NAME

ntfssecaudit - audit NTFS security on mounted file systems

SYNOPSIS

ntfssecaudit [-f] [-q] [-v] mount_point

DESCRIPTION

ntfssecaudit is a command-line utility that audits the security of an NTFS file system that is currently mounted. It reports on the ownership and permissions of files and directories, highlighting potential security risks.

OPTIONS

-f
Force checking even if the file system is not marked as clean.
-q
Quiet mode. Suppress informational messages and only report errors or security issues.
-v
Verbose mode. Print more detailed information about the auditing process.

NOTE

This command should be run with root privileges to ensure it can access all files and directories for auditing.

EXAMPLES

Audit the security of the NTFS file system mounted at /mnt/windows:

$ sudo ntfssecaudit /mnt/windows

Perform a quiet audit of the NTFS file system mounted at /media/user/Data:

$ sudo ntfssecaudit -q /media/user/Data

EXIT CODES

0
Auditing completed successfully, no major security issues found.
1
Auditing completed, but security issues were found.
2
An error occurred during auditing.

KNOWN ISSUES

Permissions auditing may not be fully accurate on very large file systems or file systems with a large number of ACLs.
