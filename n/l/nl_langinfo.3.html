nl_langinfo(3) دليل وظائف المكتبة nl_langinfo(3)

الاسم

nl_langinfo, nl_langinfo_l - الاستعلام عن معلومات اللغة والمحلية

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <langinfo.h>
char *nl_langinfo(nl_item item);
char *nl_langinfo_l(nl_item item, locale_t locale);
متطلبات ماكرو اختبار الميزة لـ glibc (انظر feature_test_macros(7)):

nl_langinfo_l():

    منذ glibc 2.24:
        _POSIX_C_SOURCE >= 200809L
    glibc 2.23 والإصدارات السابقة:
        _POSIX_C_SOURCE >= 200112L

الوصف

توفر الوظائف nl_langinfo() و nl_langinfo_l() وصولاً إلى معلومات المحلية بطريقة أكثر مرونة من localeconv(3). ترجع nl_langinfo() سلسلة نصية تمثل القيمة المقابلة للعنصر item في المحلية العامة الحالية للبرنامج. ترجع nl_langinfo_l() سلسلة نصية تمثل القيمة المقابلة للعنصر item للمحلية المحددة بواسطة كائن المحل locale، والذي تم إنشاؤه مسبقًا بواسطة newlocale(3). يمكن الاستعلام عن عناصر فردية وإضافية من فئات المحلية.

أمثلة لعناصر المحل التي يمكن تحديدها في item باستخدام الثوابت المعرفة في <langinfo.h> هي:

CODESET (LC_CTYPE)
إرجاع سلسلة نصية باسم ترميز الأحرف المستخدم في المحل المحددة، مثل "UTF-8"، "ISO-8859-1"، أو "ANSI_X3.4-1968" (المعروفة باسم US-ASCII). هذه هي نفس السلسلة النصية التي تحصل عليها باستخدام "locale charmap". للحصول على قائمة بأسماء ترميزات الأحرف، جرب "locale -m" (انظر locale(1)).
D_T_FMT (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل الوقت والتاريخ بطريقة خاصة بالمحل (مواصفة التحويل %c).
D_FMT (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل تاريخ بطريقة خاصة بالمحل (مواصفة التحويل %x).
T_FMT (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل وقت بطريقة خاصة بالمحل (مواصفة التحويل %X).
AM_STR (LC_TIME)
إرجاع سلسلة نصية تمثل لاحقة لوقت ما قبل الظهيرة (قبل الظهر، "AM"). (تستخدم في مواصفة التحويل %p لـ strftime(3)).
PM_STR (LC_TIME)
إرجاع سلسلة نصية تمثل لاحقة لوقت ما بعد الظهيرة (قبل منتصف الليل، "PM"). (تستخدم في مواصفة التحويل %p لـ strftime(3)).
T_FMT_AMPM (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل وقت بنظام صباحاً/مساءً بطريقة خاصة بالمحل (مواصفة التحويل %r).
ERA (LC_TIME)
إرجاع وصف للعصر، والذي يحتوي على معلومات حول كيفية عد وعرض السنوات لكل عصر في المحل. يجب أن يكون لكل جزء من وصف العصر التنسيق التالي:
direction:offset:start_date:end_date:era_name:era_format
وفقًا للتعريفات أدناه:
direction
إما الحرف "+" أو "-". تعني "+" أن السنوات تزداد من start_date نحو end_date، و "-" تعني العكس.
offset
سنة الحقبة لتاريخ البدء start_date.
start_date
تاريخ بالتنسيق yyyy/mm/dd، حيث yyyy، mm، و dd هي أرقام السنة والشهر واليوم على التوالي لبداية العصر.
end_date
تاريخ نهاية العصر، بنفس تنسيق start_date، أو أحد القيمتين الخاصتين "-*" (ما لا نهاية سلبية) أو "+*" (ما لا نهاية موجبة).
era_name
اسم العصر، المقابل لمواصفة التحويل %EC في strftime(3).
era_format
تنسيق السنة في العصر، المقابل لمواصفات التحويل %EY في strftime(3).
يتم فصل أجزاء وصف العصر بفواصل منقوطة. لا تحدد معظم المحليات هذه القيمة. تشمل أمثلة المحليات التي تحدد هذه القيمة المحليات اليابانية والتايلاندية.
ERA_D_T_FMT (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل بديل للوقت والتاريخ بطريقة خاصة بالمحل (مواصفة التحويل %Ec).
ERA_D_FMT (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل بديل لتاريخ بطريقة خاصة بالمحل (مواصفة التحويل %Ex).
ERA_T_FMT (LC_TIME)
إرجاع سلسلة نصية يمكن استخدامها كسلسلة تنسيق لـ strftime(3) لتمثيل بديل لوقت بطريقة خاصة بالمحل (مواصفة التحويل %EX).
DAY_{1–7} (LC_TIME)
إرجاع اسم اليوم الـ n من الأسبوع. [تحذير: هذا يتبع التقليد الأمريكي DAY_1 = الأحد، وليس التقليد الدولي (ISO 8601) بأن الاثنين هو اليوم الأول من الأسبوع.] (يستخدم في مواصفات التحويل %A لـ strftime(3)).
ABDAY_{1–7} (LC_TIME)
إرجاع الاسم المختصر لليوم الـ n من الأسبوع. (يستخدم في مواصفات التحويل %a لـ strftime(3)).
MON_{1–12} (LC_TIME)
إرجاع اسم الشهر الـ n. (يستخدم في مواصفات التحويل %B لـ strftime(3)).
ABMON_{1–12} (LC_TIME)
إرجاع الاسم المختصر للشهر الـ n. (يستخدم في مواصفات التحويل %b لـ strftime(3)).
RADIXCHAR (LC_NUMERIC)
إرجاع حرف الفاصلة العشرية (نقطة عشرية، فاصلة عشرية، إلخ).
THOUSEP (LC_NUMERIC)
إرجاع حرف فاصل الآلاف (مجموعات من ثلاثة أرقام).
YESEXPR (LC_MESSAGES)
إرجاع تعبير عادي يمكن استخدامه مع وظيفة regex(3) للتعرف على استجابة إيجابية لسؤال بنعم/لا.
NOEXPR (LC_MESSAGES)
إرجاع تعبير عادي يمكن استخدامه مع وظيفة regex(3) للتعرف على استجابة سلبية لسؤال بنعم/لا.

NAME

nl_langinfo, nl_langinfo_l - query language information

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <langinfo.h>

      char *nl_langinfo(nl_item item);
      char *nl_langinfo_l(nl_item item, locale_t locale);

DESCRIPTION

The nl_langinfo() and nl_langinfo_l() functions return information about the current locale. The item argument specifies what information is desired. The possible values for item are defined in <langinfo.h>. The names of these items are of the form ..._, followed by a descriptive name.

The nl_langinfo_l() function is the same as nl_langinfo() except that it queries the language information for the specified locale object locale.

The information available includes:

ABDAY_1, ABDAY_2, ..., ABDAY_7
Abbreviated weekday names (e.g., Sun, Mon).
DAY_1, DAY_2, ..., DAY_7
Full weekday names (e.g., Sunday, Monday).
ABMON_1, ABMON_2, ..., ABMON_12
Abbreviated month names (e.g., Jan, Feb).
MON_1, MON_2, ..., MON_12
Full month names (e.g., January, February).
AMPM_1, AMPM_2
The strings for AM and PM.
D_FMT
The locale's appropriate date format string (e.g., "%%m/%%d/%%y").
D_T_FMT
The locale's appropriate date and time format string.
D_FMT
The locale's appropriate time format string (e.g., "%%H:%%M:%%S").
T_FMT_AMPM
The locale's appropriate time format string for use with am/pm.
T_FMT
The locale's appropriate time format string.
ERA_D_FMT
The locale's appropriate era date format string.
ERA_D_T_FMT
The locale's appropriate era date and time format string.
ERA_T_FMT
The locale's appropriate era time format string.
ALT_DIGITS
A string containing alternative digit symbols.
TH_STR
String used for ordinal numbers (e.g., "th", "st", "nd", "rd").
YESSTR
String to use for affirmative answers (e.g., "yes").
NOSTR
String to use for negative answers (e.g., "no").
CODESET
The name of the character encoding used in the locale (e.g., "UTF-8").
RADIXCHAR
The radix character (decimal point) (e.g., '.').
THOUSEP
The string used to separate groups of thousands (e.g., ',').
CRNCYSTR (LC_MONETARY)
Return the currency symbol, preceded by "-" if the symbol should appear before the value, "+" if the symbol should appear after the value, or "." if the symbol should replace the radix character.

The above list covers just some examples of items that can be requested. For a more detailed list, consult The GNU C Library Reference Manual.

RETURN VALUE

On success, these functions return a pointer to a string which is the value corresponding to item in the specified locale.

If no locale has been selected by setlocale(3) for the appropriate category, nl_langinfo() return a pointer to the corresponding string in the "C" locale. The same is true of nl_langinfo_l() if locale specifies a locale where langinfo data is not defined.

If item is not valid, a pointer to an empty string is returned.

The pointer returned by these functions may point to static data that may be overwritten, or the pointer itself may be invalidated, by a subsequent call to nl_langinfo(), nl_langinfo_l(), or setlocale(3). The same statements apply to nl_langinfo_l() if the locale object referred to by locale is freed or modified by freelocale(3) or newlocale(3).

POSIX specifies that the application may not modify the string returned by these functions.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Attribute Value
nl_langinfo () Thread safety MT-Safe locale

STANDARDS

POSIX.1-2008.

HISTORY

POSIX.1-2001, SUSv2.

NOTES

The behavior of nl_langinfo_l() is undefined if locale is the special locale object LC_GLOBAL_LOCALE or is not a valid locale object handle.

EXAMPLES

The following program sets the character type and the numeric locale according to the environment and queries the terminal character set and the radix character.

#include <langinfo.h>
      #include <locale.h>
      #include <stdio.h>
      #include <stdlib.h>
      int
      main(void)
      {
          setlocale(LC_CTYPE, "");
          setlocale(LC_NUMERIC, "");
          printf("%s\n", nl_langinfo(CODESET));
          printf("%s\n", nl_langinfo(RADIXCHAR));
          exit(EXIT_SUCCESS);
      }
