ne_ssl_cert_hdigest(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_SSL_CERT_CMP(3) مرجع واجهة برمجة تطبيقات neon NE_SSL_CERT_CMP(3)

الاسم

ne_ssl_cert_cmp, ne_ssl_cert_free, ne_ssl_cert_digest, ne_ssl_cert_hdigest, ne_ssl_cert_validity, ne_ssl_cert_validity_time - وظائف للتعامل مع كائنات الشهادات

الملخص

#include <ne_header.h>

int ne_ssl_cert_cmp(const ne_ssl_certificate *c1, const ne_ssl_certificate *c2);

void ne_ssl_cert_free(ne_ssl_certificate *cert);

int ne_ssl_cert_digest(const ne_ssl_certificate *c1, char *digest);

char *ne_ssl_cert_hdigest(const ne_ssl_certificate *c1, unsigned int flags);

void ne_ssl_cert_validity_time(const ne_ssl_certificate *cert, time_t *from, time_t *until);

void ne_ssl_cert_validity(const ne_ssl_certificate *cert, char *from, char *until);

الوصف

يمكن استخدام الدالة ne_ssl_cert_cmp لمقارنة كائنين من الشهادات؛ فهي تُرجع صفرًا إذا كانا يشيران إلى نفس الشهادة، وقيمة غير صفرية بخلاف ذلك.

يمكن استخدام الدالة ne_ssl_cert_free لتدمير كائن الشهادة عندما لا يعود مطلوبًا.

تقوم الدالة ne_ssl_cert_digest بكتابة بصمة قابلة للقراءة البشرية كسلسلة نصية منتهية بـ NUL في المخزن المؤقت digest المقدم، بالتنسيق "aa:bb...:ff". يجب أن يكون المخزن المؤقت digest بطول 32 بايت على الأقل.

تقوم الدالة ne_ssl_cert_hdigest بإرجاع بصمة قابلة للقراءة البشرية لكائن الشهادة. تحدد المعلمة flags خيارات تنسيق التجزئة كما لو تم تمريرها إلى ne_strhash. يتم تخصيص السلسلة النصية المرجعة باستخدام malloc ويجب تحريرها بعد الاستخدام.

تقوم الدالة ne_ssl_cert_validity_time باسترداد كل من وقت الصلاحية الذي تبدأ منه الشهادة ووقت انتهائها. يتم إرجاع كل وقت عبر المعلمات from و until، والتي يتم كتابتها كـ (time_t)-1 إذا لم يمكن تمثيل أي من الوقتين كقيمة time_t. تقوم الدالة ne_ssl_cert_validity بالمثل بكتابة أوقات الصلاحية إلى المخازن المؤقتة للسلاسل النصية المقدمة، باستخدام تنسيق التاريخ بأسلوب RFC 1123 (غير مخصص). يجب أن تكون المعلمات الناتجة بطول 256 بايت على الأقل. يمكن تمرير أي من المعلمتين كـ NULL.

قيمة الإرجاع

تُرجع ne_ssl_cert_cmp 0 إذا كانت الشهادات متطابقة، وغير صفر بخلاف ذلك. تُرجع ne_ssl_cert_digest 0 عند النجاح أو غير صفر عند حدوث خطأ. قيمة الإرجاع لـ ne_ssl_cert_hdigest هي سلسلة نصية مخصصة بـ malloc ومنتهية بـ NUL، أو NULL إذا تعذر إنشاء التجزئة.

التاريخ

ne_ssl_cert_hdigest متاحة في neon 0.32.0 والإصدارات اللاحقة.
