هذا هو المُنشئ لكائنات Net::Telnet. يتم إرجاع كائن جديد في حالة النجاح، بينما يتم تشغيل وضع الخطأ في حالة الفشل - انظر errmode(). الوسائط الاختيارية هي اختصارات لطرق بنفس الاسم.

إذا تم تقديم الوسيط $host، يتم فتح الكائن عن طريق الاتصال بـ TCP $port على $host. انظر أيضًا open(). الكائن الجديد المُرجع له القيم الافتراضية التالية بدون معلمات مقابلة:

  • القيمة الافتراضية لـ Host هي "localhost"
  • القيمة الافتراضية لـ Port هي 23
  • القيمة الافتراضية لـ Family هي "ipv4"
  • القيمة الافتراضية لـ Prompt هي '/[\$%#>] $/'
  • القيمة الافتراضية لـ Timeout هي 10
  • القيمة الافتراضية لـ Errmode هي "die"
  • القيمة الافتراضية لـ Output_record_separator هي "\n". لاحظ أن Ors تعادل Output_record_separator.
  • القيمة الافتراضية لـ Input_record_separator هي "\n". لاحظ أن Rs تعادل Input_record_separator.
  • القيمة الافتراضية لـ Binmode هي 0، مما يعني ترجمة أحرف السطر الجديد.
  • القيمة الافتراضية لـ Telnetmode هي 1، مما يعني الاستجابة لأوامر Telnet في تدفق البيانات.
  • القيمة الافتراضية لـ Cmd_remove_mode هي "auto"
  • القيم الافتراضية لـ Dump_log و Input_log و Option_log و Output_log هي ""، مما يعني تعطيل التسجيل.
  • القيمة الافتراضية لـ Max_buffer_length هي 1048576 بايت، أي 1 ميغابايت.
  • القيمة الافتراضية لـ Output_field_separator هي "". لاحظ أن Ofs تعادل Output_field_separator.
  • القيمة الافتراضية لـ Localhost هي ""
  • القيمة الافتراضية لـ Localfamily هي "ipv4"
binmode - تبديل ترجمة سطر جديد
$mode = $obj->binmode;
$prev = $obj->binmode($mode);

تتحكم هذه الطريقة فيما إذا كانت تسلسلات حرف الإرجاع (CR) وحرف السطر الجديد (LF) (أو بشكل أكثر تحديدًا "\015\012") تُترجم. افتراضيًا، يتم ترجمتها (أي أن وضع binmode هو 0).

إذا لم يتم تقديم أي وسيط، يتم إرجاع الوضع الحالي.

إذا كان $mode هو 1، فإن وضع binmode يكون قيد التشغيل ولا تتم ترجمة أحرف السطر الجديد.

إذا كان $mode هو 0، فإن وضع binmode يكون قيد الإيقاف وتتم ترجمة أحرف السطر الجديد. في تدفق الإدخال، يتم تحويل كل تسلسل CR LF إلى "\n"، وفي تدفق الإخراج، يتم تحويل كل تكرار لـ "\n" إلى تسلسل CR LF.

ملاحظة: يتم تخزين الإدخال دائمًا مؤقتًا. تغيير وضع binmode لا يؤثر على ما تم قراءته بالفعل في المخزن المؤقت. لا يتم تخزين الإخراج مؤقتًا، وسيكون لتغيير وضع binmode تأثير فوري.

break - إرسال حرف المقاطعة TELNET
$ok = $obj->break;

ترسل هذه الطريقة حرف المقاطعة TELNET. يتم توفير هذا الحرف لأنه إشارة خارج مجموعة أحرف ASCII ولها معنى محلي داخل العديد من الأنظمة. الغرض منه هو الإشارة إلى أنه تم الضغط على مفتاح المقاطعة أو مفتاح الانتباه.

تُرجع هذه الطريقة 1 في حالة النجاح، أو تنفذ إجراء وضع الخطأ في حالة الفشل.

buffer - مرجع متغير لمخزن الإدخال للكائن
$ref = $obj->buffer;

تُرجع هذه الطريقة مرجعًا لمتغير إلى مخزن الإدخال للكائن $obj. البيانات الموجودة في مخزن الإدخال هي البيانات التي تم قراءتها من الجانب البعيد ولكن لم يقرأها المستخدم بعد. ستظهر التعديلات على مخزن الإدخال بعد قراءة لاحقة.

buffer_empty - إزالة كافة البيانات في مخزن الإدخال للكائن
$obj->buffer_empty;

تزيل هذه الطريقة كافة البيانات الموجودة في مخزن الإدخال للكائن $obj.

close - إغلاق الكائن
$ok = $obj->close;

تغلق هذه الطريقة المقبس أو الملف أو الأنبوب المرتبط بالكائن. تُرجع دائمًا قيمة 1.

cmd - إصدار أمر واسترداد المخرجات
$ok = $obj->cmd($string);
$ok = $obj->cmd(String   => $string,
                [Output  => $ref,]
                [Cmd_remove_mode => $mode,]
                [Errmode => $mode,]
                [Input_record_separator => $chars,]
                [Ors     => $chars,]
                [Output_record_separator => $chars,]
                [Prompt  => $match,]
                [Rs      => $chars,]
                [Timeout => $secs,]);
@output = $obj->cmd($string);
@output = $obj->cmd(String   => $string,
                    [Output  => $ref,]
                    [Cmd_remove_mode => $mode,]
                    [Errmode => $mode,]
                    [Input_record_separator => $chars,]
                    [Ors     => $chars,]
                    [Output_record_separator => $chars,]
                    [Prompt  => $match,]
                    [Rs      => $chars,]
                    [Timeout => $secs,]);

تُصدر هذه الطريقة الأمر $string، وتقرأ الأحرف المرسلة من الأمر حتى يتم تضمين المطابقة للموجه (prompt). يُفترض أن البرنامج الذي ترسل إليه هو نوع من مترجم الأوامر مثل shell.

يتم إنهاء الأمر $string تلقائيًا باستخدام فاصل سجل الإخراج، وهو افتراضيًا "\n". هذا مشابه لشخص يكتب أمرًا ويضغط على مفتاح الإدخال. قم بتغيير هذا السلوك باستخدام فاصل سجل الإخراج.

في سياق متغير واحد، يتم تجاهل الأحرف التي تم قراءتها من الجانب البعيد وتُرجع 1 في حالة النجاح. في حالة انتهاء الوقت أو نهاية الملف (EOF) أو فشل أخرى، يتم تنفيذ إجراء وضع الخطأ. انظر errmode().

في سياق قائمة، يتم إرجاع المخرجات التي تم إنشاؤها بواسطة الأمر فقط، سطر واحد لكل عنصر. بعبارة أخرى، يتم إرجاع كافة الأسطر بين سلسلة الأوامر المطبوعة وصورة الموجه (prompt). إذا لم يُرجع الأمر أي مخرجات، يتم إرجاع قائمة بعنصر واحد، وهو سلسلة فارغة. هذا بحيث تشير القائمة إلى صحيح في السياق البولياني. في حالة انتهاء الوقت أو نهاية الملف (EOF) أو فشل أخرى، يتم تنفيذ إجراء وضع الخطأ. انظر errmode().

يمكن استرداد الأحرف التي تتطابق مع الموجه باستخدام last_prompt().

العديد من مترجمي الأوامر تطبع الأمر المرسل. في معظم الحالات، تزيل هذه الطريقة السطر الأول المُرجع من الجانب البعيد (أي، الأمر المطبوع). انظر cmd_remove_mode() لمزيد من التحكم في هذه الوظيفة.

استخدم dump_log() لتصحيح الأخطاء عندما تنتهي هذه الطريقة وتكون غير متوقعة. ضع في اعتبارك استخدام مزيج من print() و waitfor() كبديل لهذه الطريقة عندما لا تفعل ما تريده، على سبيل المثال، عندما يطلب الأمر الذي ترسله إدخالًا.

يوفر الوسيط Output بديلاً لتلقي مخرجات الأوامر. إذا قمت بتمرير مرجع لمتغير، فسيتم إرجاع جميع المخرجات (حتى لو كانت تحتوي على أسطر متعددة) في المتغير المشار إليه. إذا قمت بتمرير مصفوفة أو مرجع إلى صفيف، فسيتم إرجاع أسطر المخرجات في المصفوفة أو الصفيف المشار إليه. يمكنك استخدام input_record_separator() لتغيير مفهوم ما يفصل سطرًا.

يتم توفير الوسائط المسماة الاختيارية لتجاوز القيم الحالية لـ cmd_remove_mode و errmode و input_record_separator و ors و output_record_separator و prompt و rs و timeout. Rs تعادل input_record_separator و ors تعادل output_record_separator.

cmd_remove_mode - تبديل إزالة الأوامر المطبوعة
$mode = $obj->cmd_remove_mode;
$prev = $obj->cmd_remove_mode($mode);

تتحكم هذه الطريقة في كيفية التعامل مع الأوامر المطبوعة التي يتم إرجاعها في مخرجات cmd(). افتراضيًا، عند إرسال أمر إلى الجانب البعيد، يكون السطر الأول من المخرجات المُرجعة هو الأمر المطبوع. استخدم هذا الوضع لإزالة السطر الأول من المخرجات التي تُرجعها cmd() عادةً.

إذا لم يتم تقديم أي وسيط، يتم إرجاع الوضع الحالي.

إذا كان $mode هو 0، فلا يتم إزالة أي أسطر من مخرجات cmd(). إذا كان $mode رقمًا موجبًا، فسيتم إزالة أول $mode سطر من مخرجات الأوامر.

يمكن التحكم في سياق سطر المخرجات بواسطة المعلمة cmd_remove_mode.

getlines - قراءة الأسطر التالية
@lines = $obj->getlines([Binmode    => $mode,]
                        [Errmode    => $errmode,]
                        [Input_record_separator => $chars,]
                        [Rs         => $chars,]
                        [Telnetmode => $mode,]
                        [Timeout    => $secs,]
                        [All        => $boolean,]));

يقرأ هذا الأسلوب ويعيد جميع أسطر البيانات من الكائن حتى يتم قراءة نهاية الملف. يمكنك استخدام input_record_separator() لتغيير مفهوم ما يفصل بين الأسطر. الافتراضي هو "\n". يحدث خطأ انتهاء المهلة إذا لم يتمكن من قراءة جميع الأسطر في غضون فترة انتهاء المهلة. انظر timeout().

تم تغيير سلوك هذا الأسلوب في الإصدار 3.03. قبل الإصدار 3.03، كان هذا الأسلوب يعيد الأسطر المتاحة فقط من القراءة التالية. لاستعادة السلوك القديم، استخدم المعلمة الاختيارية All وقم بتعيين $boolean إلى "" أو 0.

إذا تم قراءة نهاية الملف فقط، يتم إرجاع قائمة فارغة. عند انتهاء المهلة أو حدوث أخطاء أخرى، يتم تنفيذ إجراء وضع الخطأ. استخدم eof() للتمييز بين قراءة نهاية الملف فقط أو حدوث خطأ عندما لا يكون وضع الخطأ معينًا على "die".

يتم توفير المعلمات المسماة الاختيارية لتجاوز الإعدادات الحالية لـ binmode و errmode و input_record_separator و rs و telnetmode و timeout. Rs مكافئ لـ input_record_separator.

host - اسم المضيف البعيد أو عنوان IP
$host = $obj->host;
$prev = $obj->host($host);

يحدد هذا الأسلوب المضيف البعيد لـ open(). إنه اسم مضيف أو عنوان IP. بدون وسيطة، يعيد القيمة الحالية المخزنة في الكائن. مع وسيطة، يقوم بتعيين اسم المضيف الحالي إلى $host ويعيد القيمة السابقة. استخدم family() للتحكم في عائلة عنوان IP، IPv4 أو IPv6، التي يشير إليها المضيف.

القيمة الافتراضية هي "localhost". يمكن أيضًا تعيينها عبر open() أو new().

input_log - تسجيل جميع المدخلات
$fh = $obj->input_log;
$fh = $obj->input_log($fh);
$fh = $obj->input_log($tiefh);
$fh = $obj->input_log($filename);

يبدأ هذا الأسلوب أو يوقف تسجيل المدخلات. إنه مفيد عند تصحيح الأخطاء. انظر أيضًا dump_log(). نظرًا لأن معظم الموجهات تطبع الأوامر المستلمة، فمن المحتمل أن يتم تسجيل مخرجاتك أيضًا في هذا السجل. لاحظ أن تسجيل المدخلات يحدث بعد ترجمة سطر جديد. انظر binmode() للحصول على تفاصيل حول ترجمة سطر جديد.

إذا لم يتم توفير وسيطة، يتم إرجاع معالج الملف للسجل. سلسلة فارغة تشير إلى أن التسجيل في وضع الإيقاف.

لإيقاف التسجيل، استخدم سلسلة فارغة كوسيطة. معالج الملف المتوقف لا يتم إغلاقه.

إذا تم توفير معالج ملف مفتوح، يتم استخدامه للتسجيل ويتم إرجاعه. وإلا، يُفترض أن تكون الوسيطة اسم ملف، ويتم فتح الاسم للتسجيل ويتم إرجاع معالج ملف إليه. إذا لم يكن معالج الملف مفتوحًا بالفعل أو لا يمكن فتح الاسم للكتابة، يتم تنفيذ إجراء وضع الخطأ. يمكن أن يكون معالج الملف معالج ملف مربوطًا.

input_record_separator - فاصل سطر الإدخال
$chars = $obj->input_record_separator;
$prev = $obj->input_record_separator($chars);

يحدد هذا الأسلوب فاصل سطر الإدخال. يتم استخدامه مع getline() و getlines() و cmd() لتحديد أسطر الإدخال.

بدون وسيطة، يعيد هذا الأسلوب فاصل سطر الإدخال الحالي في الكائن. مع وسيطة، يقوم بتعيين فاصل سطر الإدخال إلى $chars ويعيد القيمة السابقة. لاحظ أن $chars يجب أن يكون له طول.

يتم طباعة تحذير في STDERR عند محاولة تعيين هذه الخاصية بسلسلة فارغة.

last_prompt - آخر مطالبة مقروءة
$string = $obj->last_prompt;
$prev = $obj->last_prompt($string);

بدون وسيطة، يعيد هذا الأسلوب آخر مطالبة قرأها cmd() أو login(). انظر prompt(). مع وسيطة، يقوم بتعيين آخر مطالبة مقروءة إلى $string ويعيد القيمة السابقة. عادةً، تقوم الأساليب الداخلية فقط بتعيين آخر مطالبة.

lastline - آخر سطر مقروء
$line = $obj->lastline;
$prev = $obj->lastline($line);

يحصل هذا الأسلوب على آخر سطر مقروء من الكائن. قد يكون هذا مفيدًا عندما يغلق الطرف البعيد الاتصال بشكل غير طبيعي. بشكل عام، يطبع الطرف البعيد رسالة خطأ قبل الإغلاق.

بدون وسيطة، يعيد هذا الأسلوب آخر سطر مقروء من الكائن. مع وسيطة، يقوم بتعيين آخر سطر مقروء إلى $line ويعيد القيمة السابقة. عادةً، تقوم الأساليب الداخلية فقط بتعيين آخر سطر.

localfamily - عائلة عنوان IP للمضيف المحلي
$localfamily = $obj->localfamily;
$prev   = $obj->localfamily($family);

يحدد هذا الأسلوب عائلة عنوان IP التي يشير إليها localhost()، أي IPv4 أو IPv6. دعم IPv6 متاح عند استخدام perl 5.14 أو أحدث. بدون وسيطة، يعيد القيمة الحالية المخزنة في الكائن. مع وسيطة، يقوم بتعيين عائلة عنوان IP المحلية الحالية إلى $family ويعيد العائلة السابقة. القيم الصالحة هي "ipv4" و "ipv6" أو "any". عندما يكون "any"، يمكن أن يكون localhost() اسم مضيف أو عنوان IP لكل من IPv4 و IPv6.

القيمة الافتراضية هي "ipv4".

يتم تنفيذ إجراء وضع الخطأ عند محاولة تعيين هذه الخاصية بشيء آخر غير "ipv4" و "ipv6" أو "any". يتم تنفيذه أيضًا عند محاولة تعيينه إلى "ipv6" عندما لا يكون وحدة Socket الإصدار 1.94 أو عندما لا يدعم IPv6 على نظام التشغيل، والذي يشير إليه Socket::AF_INET6 غير المعرف.

localhost - تعيين عنوان IP لواجهة شبكة محددة
$localhost = $obj->localhost;
$prev = $obj->localhost($host);

يحدد هذا الأسلوب عنوان IP للمقبس المحلي لـ open(). إنه اسم مضيف أو عنوان IP أو سلسلة فارغة (أي ""). سلسلة فارغة تعطيل هذه الوظيفة.

عادةً، يختار نظام التشغيل واجهة الشبكة المحلية التي سيتم استخدامها. هذه الوظيفة مفيدة عندما يحتوي الكمبيوتر المحلي على أكثر من واجهة شبكة واحدة وتريد الارتباط بواجهة محددة. بدون وسيطة، يعيد القيمة الحالية المخزنة في الكائن. مع وسيطة، يقوم بتعيين اسم المضيف المحلي الحالي إلى $host ويعيد القيمة السابقة. استخدم localfamily() للتحكم في عائلة عنوان IP، IPv4 أو IPv6، التي يشير إليها المضيف المحلي.

القيمة الافتراضية هي "".

login - تنفيذ تسجيل الدخول القياسي
$ok = $obj->login($username, $password);
$ok = $obj->login(Name     => $username,
                  Password => $password,
                  [Errmode => $mode,]
                  [Prompt  => $match,]
                  [Timeout => $secs,]);

ينفذ هذا الأسلوب تسجيل دخول قياسيًا عن طريق انتظار مطالبة تسجيل الدخول والرد بـ $username، ثم انتظار مطالبة كلمة المرور والرد بـ $password، ثم انتظار مطالبة الموجه. إذا لم تتطابق أي من المطالبات المرسلة من الطرف البعيد مع المتوقعة، فسوف تنتهي مهلة هذا الأسلوب، ما لم يتم تعطيل انتهاء المهلة.

يجب أن تتطابق مطالبة تسجيل الدخول مع أحد هذه الأنماط غير الحساسة لحالة الأحرف:

/login[: ]*$/i
/username[: ]*$/i

يجب أن تتطابق مطالبة كلمة المرور مع هذا النمط غير الحساس لحالة الأحرف:

/password[: ]*$/i

يجب أن تتطابق مطالبة الموجه مع الحالة الحالية لـ prompt(). انظر prompt().

استخدم dump_log() لتصحيح الأخطاء عندما تنتهي مهلة هذا الأسلوب ولا تعتقد أنه ينبغي ذلك. ضع في اعتبارك استخدام مزيج من print() و waitfor() كبديل لهذا الأسلوب عندما لا يقوم بما تريده، على سبيل المثال، عندما لا يطلب الطرف البعيد اسم مستخدم.

في حالة النجاح، يتم إرجاع 1. في حالة انتهاء المهلة أو نهاية الملف أو أخطاء أخرى، يتم تنفيذ إجراء وضع الخطأ. انظر errmode().

يتم توفير المعلمات المسماة الاختيارية لتجاوز الإعدادات الحالية لـ errmode و prompt و timeout.

max_buffer_length - الحد الأقصى لحجم مخزن الإدخال المؤقت
$len = $obj->max_buffer_length;
$prev = $obj->max_buffer_length($len);

يحدد هذا الأسلوب الحد الأقصى لحجم مخزن الإدخال المؤقت. يتم إنشاء خطأ عند تسبب قراءة في تجاوز المخزن المؤقت لهذا الحد. القيمة الافتراضية هي 1،048،576 بايت (1 ميبيبايت). يمكن أن ينمو مخزن الإدخال المؤقت بشكل كبير جدًا مقارنة بحجم الكتلة عند القراءة المستمرة باستخدام getline() أو waitfor() ويحتوي تدفق البيانات على أسطر غير جديدة.

$sockfamily = $obj->sockfamily; ```

تُرجع هذه الطريقة نوع العائلة الخاص بعنوان IP الذي تم استخدامه للاتصال بنجاح. يكون هذا مفيدًا بشكل خاص عندما يكون نوع العنوان المطلوب بواسطة open() هو "any". يمكن أن تكون القيم المعادة هي "ipv4"، أو "ipv6"، أو "" (عند عدم الاتصال).

``` $ipaddr = $obj->sockhost; ```

تُرجع هذه الطريقة سلسلة نصية تمثل عنوان IPv4 أو IPv6 لمقبس الاتصال المحلي المرتبط. تُرجع "" عند عدم الاتصال.

``` $port = $obj->sockport; ```

تُرجع هذه الطريقة رقم المنفذ الذي يرتبط به مقبس الاتصال المحلي. تُرجع "" عند عدم الاتصال.

``` $mode = $obj->telnetmode; $prev = $obj->telnetmode($mode); ```

تتحكم هذه الطريقة فيما إذا كانت أوامر TELNET في تدفق البيانات يتم التعرف عليها وإدارتها. يستخدم بروتوكول TELNET تسلسلات أحرف معينة يتم إرسالها في تدفق البيانات للتحكم في الجلسة. إذا كان المنفذ الذي تتصل به لا يستخدم بروتوكول TELNET، فيجب إيقاف تشغيل هذا الوضع. القيمة الافتراضية هي on.

إذا لم يتم تقديم أي وسيط، فسيتم إرجاع الوضع الحالي.

إذا كانت $mode تساوي 0، فإن وضع TELNET يكون متوقفًا. إذا كانت $mode تساوي 1، فإن وضع TELNET يكون قيد التشغيل.

``` $boolean = $obj->timed_out; $prev = $obj->timed_out($boolean); ```

تشير هذه الطريقة إلى ما إذا كانت طريقة قراءة أو كتابة أو فتح سابقة قد انتهت مهلتها. تذكر أن انتهاء المهلة هو خطأ في حد ذاته. لاستدعاء timed_out() بعد خطأ انتهاء مهلة، ستحتاج إلى تغيير وضع الخطأ إلى شيء بخلاف "die". انظر errmode().

بدون وسائط، تُرجع هذه الطريقة 1 إذا انتهت مهلة الطريقة السابقة. مع وسيط، يتم تعيين المؤشر. عادةً، تقوم الطرق الداخلية فقط بتعيين هذا المؤشر.

``` $secs = $obj->timeout; $prev = $obj->timeout($secs); ```

تحدد هذه الطريقة الفترة الزمنية لانتهاء المهلة التي سيتم استخدامها عند إجراء عملية إدخال/إخراج أو الاتصال بمنفذ. إذا لم تكتمل الطريقة خلال فترة انتهاء المهلة، فسيتم اعتبار ذلك خطأ وسيتم تنفيذ إجراء وضع الخطأ.

يمكن التعبير عن انتهاء المهلة كقيمة نسبية أو مطلقة. إذا كانت $secs أكبر من أو تساوي الوقت الذي بدأ فيه البرنامج، كما هو محدد بواسطة $^T، فهي قيمة مطلقة تحدد وقت حدوث انتهاء المهلة. يمكن استخدام الدالة perl time() للحصول على قيمة مطلقة. بالنسبة لقيمة انتهاء مهلة نسبية أقل من $^T، يحدث انتهاء المهلة $secs منذ بدء الطريقة.

إذا كانت $secs تساوي 0، يحدث انتهاء المهلة إذا تعذر قراءة البيانات أو كتابتها فورًا. استخدم القيمة غير المعرفة لتعطيل انتهاء المهلة تمامًا.

بدون وسائط، تُرجع هذه الطريقة مهلة الانتهاء المعينة في الكائن. مع وسيط، تحدد مهلة الانتهاء إلى $secs وتُرجع القيمة السابقة. القيمة الافتراضية لانتهاء المهلة هي 10 ثوانٍ.

تتم طباعة تحذير في STDERR عند محاولة تعيين هذا السمة إلى شيء بخلاف "undef" أو رقم غير سالب.

``` $ok = $obj->waitfor($matchop); $ok = $obj->waitfor([Match => $matchop,] [String => $string,] [Binmode => $mode,] [Errmode => $errmode,] [Telnetmode => $mode,] [Timeout => $secs,]); ($prematch, $match) = $obj->waitfor($matchop); ($prematch, $match) = $obj->waitfor([Match => $matchop,] [String => $string,] [Binmode => $mode,] [Errmode => $errmode,] [Telnetmode => $mode,] [Timeout => $secs,]); ```

تقرأ هذه الطريقة حتى يتم العثور على تطابق نمط أو سلسلة نصية في تدفق الإدخال. يتم حذف جميع الأحرف قبل التطابق والتي تتضمنه من تدفق الإدخال.

في سياق قائمة، يتم إرجاع الأحرف قبل التطابق وأحرف التطابق في $prematch و $match. في سياق كمية قياسية، يتم حذف أحرف التطابق وجميع الأحرف التي تسبقها، ويتم إرجاع 1 في حالة النجاح. في حالة انتهاء المهلة، أو EOF، أو أخطاء أخرى، يتم تنفيذ إجراء وضع الخطأ في كل من السياقين القياسي وقائمة. انظر errmode().

يمكنك تحديد أكثر من نمط أو سلسلة نصية عن طريق توفير معلمات Match و/أو String متعددة. يجب أن تكون $matchop سلسلة نصية تمثل عامل تطابق صالحًا في Perl. $string هو مجرد سلسلة فرعية للبحث عنها في تدفق الإدخال.

استخدم dump_log() لتصحيح الأخطاء عندما تستمر هذه الطريقة في انتهاء المهلة ولا تتوقع ذلك.

يتم توفير معلمة مسماة اختيارية لاستبدال القيمة الحالية لانتهاء المهلة.

لتجنب تفسير الشرطة المائلة العكسية، استخدم دائمًا علامات الاقتباس الفردية بدلاً من المزدوجة عند بناء وسيط عامل تطابق لـ prompt() و waitfor() (مثال: '/bash\$\$/'). إذا كنت تبني مسار ملف مشابه لنظام DOS، فستحتاج إلى استخدام أربع شرطات مائلة عكسية لتمثيل شرطة مائلة عكسية واحدة (مثال: '/c:\\\\users\\\\bill>$/i').

لا تنسَ الأحرف الخاصة للتعبيرات العادية مثل "."، "[، أو "$. ستحتاج فقط إلى شرطة مائلة عكسية لجعلها. تشير الأحرف الخاصة بعرض الكلمة "^" و "$ إلى مواضع في المخزن المؤقت للإدخال.

يتم توفير المعلمات المسماة الاختيارية لاستبدال القيم الحالية لوضع الثنائي، ووضع الخطأ، ووضع Telnet، ومهلة الانتهاء.

أمثلة

قد يكون ضبط prompt() لمطابقة موجه shell الخاص بالمستخدم أمرًا صعبًا. يتصل هذا المثال بخادم دون معرفة موجه shell، ثم يضبطه لـ prompt(). يتطلب /usr/bin/env و /bin/sh على المضيف البعيد.

my $host = 'your_destination_host_here';
my $user = 'your_username_here';
my $passwd = 'your_password_here';
my ($t, @output);
## إنشاء كائن Net::Telnet.
use Net::Telnet ();
$t = new Net::Telnet (Timeout  => 10);
## الاتصال والمصادقة.
$t->open($host);
$t->waitfor('/login: ?$/i');
$t->print($user);
$t->waitfor('/password: ?$/i');
$t->print($passwd);
## الانتقال إلى shell معروف باستخدام موجه معروف.
$t->prompt('/<xPROMPTx> $/');
$t->errmode("return");
$t->cmd("exec /usr/bin/env 'PS1=<xPROMPTx> ' /bin/sh -i")
    or die "login failed to remote host $host";
$t->errmode("die");
## الآن يمكنك استخدام cmd() حسب رغبتك.
@output = $t->cmd("uname -a");
print @output;
exit;

عادةً ما ترغب في تعيين بيئة الطرفية البعيدة إلى شيء مثل "dumb" لتجنب قراءة تسلسلات الهروب التي يتم تفسيرها بواسطة طرفية عرض. من الأفضل تعيينها باستخدام cmd() أو باستخدام waitfor() و print(). من الممكن أيضًا التفاوض بشأن نوع الطرفية عبر TELNET. إليك كيفية القيام بذلك.

## استيراد الوحدة.
use Net::Telnet qw(TELNET_IAC TELNET_SB TELNET_SE TELOPT_TTYPE);
## متغيرات عامة.
my $Term;
## الكود الرئيسي.
{
    my $host = "your_destination_host_here";
    my $user = "your_username_here";
    my $passwd = "your_password_here";
    my $prompt = '/bash\$ $/';  # موجهك هنا
    my $t;
    $t = new Net::Telnet (Prompt => $prompt);
    ## تعيين ردود الاتصال للتفاوض على نوع الطرفية.
    $t->option_callback(sub {});
    $t->suboption_callback(\&subopt_callback);
    $t->option_accept(Do => TELOPT_TTYPE);
    ## المصادقة وعرض قيمة TERM.
    $Term = "dumb";
    $t->open($host);
    $t->login($user, $passwd);
    print $t->cmd('hostname');
    print "TERM=", $t->cmd('echo $TERM');
    $t->close;
    exit;
} # نهاية البرنامج الرئيسي
sub subopt_callback {
    my ($t, $option, $parameters) = @_;
    my $telcmd;
    if ($option == TELOPT_TTYPE) {
        $telcmd = pack("C4 A* C2", TELNET_IAC, TELNET_SB, TELOPT_TTYPE, 0,
                       $Term, TELNET_IAC, TELNET_SE);
        $t->put(String => $telcmd,
                Telnetmode => 0);
    }
}
