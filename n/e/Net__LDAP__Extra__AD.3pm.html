Net__LDAP__Extra__AD(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Extra::AD(3) وثائق Perl المساهمة من المستخدم Net::LDAP::Extra::AD(3)

الاسم

Net::LDAP::Extra::AD -- طرق مساعدة لـ AD

الملخص

use Net::LDAP::Extra qw(AD);
$ldap = Net::LDAP->new( ... );
...
if ($ldap->is_AD || $ldap->is_ADAM) {
  $ldap->change_ADpassword($dn, $old_password, $new_password);
}

الوصف

يحاول Net::LDAP::Extra::AD توفير الجهد على المستخدمين لتجنب إعادة اختراع العجلة مرارًا وتكرارًا من أجل ترميز سلاسل كلمات المرور بشكل صحيح بحيث يمكن استخدامها في عمليات تغيير كلمة المرور لـ AD.

للقيام بذلك، فإنه يوفر الطرق التالية:

الطرق

is_AD ( )
إخبار ما إذا كان خادم LDAP الذي تم الاستعلام عنه هو Active Directory Domain Controller.

نظرًا لأن الفحص يتم عن طريق الاستعلام عن جذر DSE للدليل، فإنه يعمل دون الحاجة إلى الارتباط بالدليل.

is_ADAM ( )
إخبار ما إذا كان خادم LDAP الذي تم الاستعلام عنه يعمل AD LDS (Active Directory Lightweight Directory Services)، المعروف سابقًا باسم ADAM (Active Directory Application Mode).

نظرًا لأن الفحص يتم عن طريق الاستعلام عن جذر DSE للدليل، فإنه يعمل دون الحاجة إلى الارتباط بالدليل.

change_ADpassword ( DN, OLD_PASSWORD, NEW_PASSWORD )
تغيير كلمة مرور الحساب المعطى بواسطة DN من قيمته القديمة OLD_PASSWORD إلى القيمة الجديدة NEW_PASSWORD.

تتطلب هذه الطريقة اتصالات مشفرة.

reset_ADpassword ( DN, NEW_PASSWORD, OPTIONS )
إعادة تعيين كلمة مرور الحساب المعطى بواسطة DN إلى القيمة المعطاة في NEW_PASSWORD. OPTIONS هي قائمة من أزواج المفتاح/القيمة. المفاتيح التالية معترف بها:
force_change
إذا كانت TRUE، يُطلب من المستخدم المتأثر تغيير كلمة المرور عند تسجيل الدخول التالي.

لكي تعمل هذه الطريقة، يحتاج المتصل إلى الارتباط بـ AD مع أذونات كافية، ويجب أن يكون الاتصال مشفرًا.
