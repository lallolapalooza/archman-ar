Net__LDAP__Control__TreeDelete(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Control::TreeDelete(3) وثائق Perl التي ساهم بها المستخدم Net::LDAP::Control::TreeDelete(3)

الاسم

Net::LDAP::Control::TreeDelete - كائن تحكم حذف الشجرة LDAPv3

الملخص

use Net::LDAP;
use Net::LDAP::Control::TreeDelete;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$treedel = Net::LDAP::Control::TreeDelete->new( critical => 1 );
$msg = $ldap->delete( 'o=University of Michigan,c=US',
                      control  => [ $treedel ] );
die "error: ",$msg->code(),": ",$msg->error()  if ($msg->code());

الوصف

"Net::LDAP::Control::TreeDelete" يوفر واجهة لإنشاء ومعالجة الكائنات التي تمثل تحكم "TreeDelete" كما هو موصوف في draft-armijo-ldap-treedelete-02.txt https://tools.ietf.org/html/draft-armijo-ldap-treedelete-02

يسمح للعميل بحذف شجرة فرعية كاملة.

التحكم مناسب لعمليات حذف LDAP [RFC4511] فقط، وغير مناسب لجميع العمليات الأخرى.

يمكن أن تكون أهميته TRUE أو FALSE؛ ليس له قيمة.

لا يوجد تحكم استجابة مقابل.

وسائط المُنشئ

نظرًا لأن تحكم "TreeDelete" لا يحتوي على أي قيم، يتم دعم وسائط المُنشئ فقط كما هو موضح في Net::LDAP::Control.

الطرق

نظرًا لعدم وجود قيم إضافية في التحكم، فإن الطرق الموجودة في Net::LDAP::Control فقط متاحة لكائنات "Net::LDAP::Control::TreeDelete".
