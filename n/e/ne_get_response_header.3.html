ne_get_response_header(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_GET_RESPONSE_HEAD(3) مرجع واجهة برمجة تطبيقات neon NE_GET_RESPONSE_HEAD(3)

الاسم

ne_get_response_header, ne_response_header_iterate - وظائف للوصول إلى رؤوس الاستجابة

مُلخص

#include <ne_request.h>

const char *ne_get_response_header(ne_request *request, const char *name);

void *ne_response_header_iterate(ne_request *request, void *cursor, const char **name, const char **value);

الوصف

لاسترداد قيمة حقل رأس الاستجابة، يمكن استخدام الدالة ne_get_response_header، ويتم إعطاؤها اسم الرأس المراد إرجاعه.

للتكرار عبر جميع رؤوس الاستجابة التي تم إرجاعها، يمكن استخدام الدالة ne_response_header_iterate. تأخذ هذه الدالة معلمة cursor التي يجب أن تكون NULL لاسترداد الرأس الأول. تقوم الدالة بتخزين اسم وقيمة الرأس التالي في المعلمتين name و value، وترجع مؤشر مؤشر جديد يمكن تمريره إلى ne_response_header_iterate لاسترداد الرأس التالي.

قيمة الإرجاع

ne_get_response_header ترجع سلسلة نصية، أو NULL إذا لم يتم إعطاء رأس بهذا الاسم. إذا تم استخدامها أثناء معالجة الطلب، فإن مؤشر قيمة الإرجاع يكون صالحًا فقط حتى الاستدعاء التالي لـ ne_begin_request، أو بخلاف ذلك، حتى يتم تدمير كائن الطلب.

وبالمثل، فإن المؤشر والأسماء والقيم التي تم إرجاعها بواسطة ne_response_header_iterate صالحة فقط حتى الاستدعاء التالي لـ ne_begin_request أو حتى يتم تدمير كائن الطلب.

أمثلة

سيقوم الكود التالي بإخراج قيمة رأس Last-Modified لمورد:

ne_request *req = ne_request_create(sess, "GET", "/foo.txt");
if (ne_request_dispatch(req) == NE_OK) {
    const char *mtime = ne_get_response_header(req, "Last-Modified");
    if (mtime) {
        printf("/foo.txt has last-modified value %s\n", mtime);
    }
}
ne_request_destroy(req);

انظر أيضًا

ne_request_create, ne_request_destroy.
