ne_buffer_destroy(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_BUFFER_DESTROY(3) مرجع واجهة برمجة تطبيقات neon NE_BUFFER_DESTROY(3)

الاسم

ne_buffer_destroy, ne_buffer_finish - تدمير كائن مخزن مؤقت

الملخص

#include <ne_string.h>

void ne_buffer_destroy(ne_buffer *buf);

char *ne_buffer_finish(ne_buffer *buf);

الوصف

ne_buffer_destroy تحرر كل الذاكرة المرتبطة بالمخزن المؤقت. ne_buffer_finish تحرر بنية المخزن المؤقت، ولكن ليس السلسلة النصية الفعلية المخزنة في المخزن المؤقت، والتي يتم إرجاعها ويجب أن يتم تحريرها بواسطة المستدعي باستخدام free().

أي استخدام لكائن المخزن المؤقت بعد استدعاء أي من هاتين الدالتين يعطي سلوكًا غير محدد.

قيمة الإرجاع

ne_buffer_finish ترجع السلسلة النصية المخصصة بواسطة malloc المخزنة في المخزن المؤقت.

أمثلة

مثال على استخدام ne_buffer_finish؛ الدالة duplicate ترجع سلسلة نصية مكونة من n نسخ من str:

static char *duplicate(int n, const char *str)
{
  ne_buffer *buf = ne_buffer_create();
  while (n--) {
    ne_buffer_zappend(buf, str);
  }
  return ne_buffer_finish(buf);
}
