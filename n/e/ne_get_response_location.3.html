ne_get_response_location(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_GET_STATUS(3) مرجع واجهة برمجة تطبيقات neon NE_GET_STATUS(3)

الاسم

ne_get_status, ne_get_response_location, ne_get_response_retry_after - استرداد خصائص استجابة HTTP

ملخص

#include <ne_request.h>

const ne_status *ne_get_status(const ne_request *request);

ne_uri *ne_get_response_location(ne_request *request);

time_t ne_get_response_retry_after(ne_request *request);

الوصف

تقوم الدالة ne_get_status بإرجاع مؤشر إلى كائن حالة HTTP الذي يعطي نتيجة الطلب. يصبح الكائن المُعاد صالحًا فقط بمجرد إرسال الطلب بنجاح (كانت القيمة المُعادة من ne_request_dispatch أو ne_begin_request صفرًا).

إذا كانت الاستجابة تتضمن رأس Location، تقوم الدالة ne_get_response_location بتحليل مرجع URI وحله بالنسبة لهدف الطلب. إذا كان هناك جزء ( ""#fragment") يمكن تطبيقه على هدف الطلب، فيمكن تمريره كوسيط للسماح بالتحليل النسبي المناسب.

تقوم الدالة ne_get_response_retry_after بتحليل أي رأس Retry-After مضمن في الاستجابة. إذا كانت قيمة الرأس تستخدم وقتًا نسبيًا، فيتم تفسيرها بالنسبة للوقت الذي تم فيه استدعاء الدالة، بدلاً من الوقت الذي تم فيه استلام الاستجابة، لذا يجب استخدام الدالة مباشرة بعد إرسال الطلب.

قيمة الإرجاع

ne_get_status تُرجع مؤشرًا إلى كائن حالة HTTP يعطي نتيجة الطلب. هذا المؤشر يكون صالحًا حتى يتم تدمير كائن الطلب المرتبط به.

ne_get_response_location تُرجع كائن ne_uri تم تخصيصه بواسطة malloc، أو NULL إذا تعذر تحليل URI في رأس Location أو لم يكن رأس Location موجودًا.

ne_get_response_retry_after تُرجع قيمة time_t، أو صفرًا إذا لم يتم تضمين رأس Retry-After أو تعذر تحليل قيمة الرأس.

أمثلة

عرض رمز حالة الاستجابة لطريقة HEAD المطبقة على مورد ما.

ne_request *req = ne_request_create(sess, "HEAD", "/foo/bar");
if (ne_request_dispatch(req))
   /* معالجة الأخطاء... */
else
   printf("Response status code was %d\n", ne_get_status(req)->code);
ne_request_destroy(req);
