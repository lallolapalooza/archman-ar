Net__DNS__RR__LOC(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS::RR::LOC(3) وثائق Perl مساهمة من المستخدم Net::DNS::RR::LOC(3)

الاسم

Net::DNS::RR::LOC - سجل مورد DNS LOC

ملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name LOC latitude longitude altitude size hp vp');

الوصف

سجلات مورد موقع نظام أسماء النطاقات (LOC).

الأساليب

الأساليب المتاحة هي تلك الموروثة من الفئة الأساسية المعززة بالأساليب الخاصة بالنوع المحددة في هذه الحزمة.

لا يُنصح باستخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية وقد يؤدي ذلك إلى إنهاء البرنامج أو سلوك غير متوقع آخر.

خط العرض

$latitude = $rr->latitude;
($deg, $min, $sec, $ns ) = $rr->latitude;
$rr->latitude( 42.357990 );
$rr->latitude( 42, 21, 28.764, 'N' );
$rr->latitude( '42 21 28.764 N' );

عند استدعائه في سياق قياسي، يتم إرجاع خط العرض بالدرجات، حيث يكون الإحداثي السالب جنوب خط الاستواء.

عند استدعائه في سياق قائمة، يتم إرجاع خط العرض كقائمة من قيم الدرجات والدقائق والثواني المنفصلة متبوعة بـ N أو S حسب الاقتضاء.

يمكن تمثيل القيم البديلة الاختيارية كقيمة واحدة، أو قائمة، أو سلسلة منسقة. القيم الصفرية اللاحقة اختيارية.

خط الطول

$longitude = $rr->longitude;
($deg, $min, $sec, $ew ) = $rr->longitude;
$rr->longitude( -71.014338 );
$rr->longitude( 71, 0, 51.617, 'W' );
$rr->longitude( '71 0 51.617 W' );

عند استدعائه في سياق قياسي، يتم إرجاع خط الطول بالدرجات، حيث يكون الإحداثي السالب غرب خط الطول الرئيسي.

عند استدعائه في سياق قائمة، يتم إرجاع خط الطول كقائمة من قيم الدرجات والدقائق والثواني المنفصلة متبوعة بـ E أو W حسب الاقتضاء.

الارتفاع

$altitude = $rr->altitude;

يمثل الارتفاع، بالأمتار، بالنسبة للكرة المرجعية WGS 84 المستخدمة في نظام تحديد المواقع العالمي (GPS).

الحجم

$size = $rr->size;

يمثل قطر، بالأمتار، لكرة تحيط بالكيان الموصوف.

الدقة الأفقية

$hp = $rr->hp;

يمثل الدقة الأفقية للبيانات المعبر عنها كقطر، بالأمتار، لدائرة الخطأ.

الدقة الرأسية

$vp = $rr->vp;

يمثل الدقة الرأسية للبيانات المعبر عنها كمدى إجمالي، بالأمتار، لتوزيع القيم المحتملة.

خط العرض والطول

($lat, $lon) = $rr->latlon;
$rr->latlon($lat, $lon);

تمثيل زوج إحداثيات خط العرض وخط الطول كدرجات عشرية موقعة.

الإصدار

$version = $rr->version;

إصدار بروتوكول LOC.
