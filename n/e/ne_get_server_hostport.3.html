ne_get_server_hostport(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_SET_USERAGENT(3) مرجع واجهة برمجة تطبيقات neon NE_SET_USERAGENT(3)

الاسم

ne_set_useragent, ne_set_read_timeout, ne_set_connect_timeout, ne_get_scheme, ne_get_server_hostport - خصائص مشتركة لجلسات HTTP

الملخص

#include <ne_session.h>

void ne_set_useragent(ne_session *session, const char *product);

void ne_set_read_timeout(ne_session *session, int timeout);

void ne_set_connect_timeout(ne_session *session, int timeout);

const char *ne_get_scheme(ne_sesssion *session);

const char *ne_get_server_hostport(ne_sesssion *session);

الوصف

يُستخدم رأس طلب User-Agent لتحديد البرنامج الذي أنشأ الطلب لأغراض إحصائية أو تصحيحية. لا يرسل neon رأس User-Agent إلا إذا تم استدعاء ne_set_useragent. يجب تمرير سلسلة منتج إلى ne_set_useragent تتوافق مع قواعد ترميز المنتج في RFC2616؛ بالشكل "Product/Version".

عندما يقرأ neon من مقبس، فإن عملية القراءة ستنتهي افتراضيًا بعد 60 ثانية، وسيفشل الطلب مع خطأ NE_TIMEOUT. لتكوين فترة المهلة هذه، اتصل بـ ne_set_read_timeout مع إعطاء عدد الثواني المطلوب كمعامل timeout.

عند إنشاء اتصال بخادم، عادةً ما ينطبق فقط معالجة مهلة TCP الخاصة بالنظام. لتكوين مهلة محددة (وقصيرة على الأرجح)، يمكن استخدام ne_set_connect_timeout، مع إعطاء عدد الثواني المطلوب كمعامل timeout. إذا تم تمرير 0، فسيتم استخدام السلوك الافتراضي لاستخدام مهلة TCP الخاصة بالنظام.

سيتم إرجاع المخطط المستخدم لإنشاء الجلسة في البداية بواسطة ne_get_scheme.

سيتم إرجاع زوج المضيف والمنفذ الذي ترتبط به الجلسة بواسطة ne_get_server_hostport؛ على سبيل المثال www.example.com:8080. لاحظ أنه سيتم حذف :port إذا تم استخدام المنفذ الافتراضي للمخطط.

أمثلة

تعيين سلسلة وكيل مستخدم:

ne_session *sess = ne_session_create(...);
ne_set_useragent(sess, "MyApplication/2.1");

تعيين مهلة قراءة مدتها 30 ثانية:

ne_session *sess = ne_session_create(...);
ne_set_read_timeout(sess, 30);

انظر أيضًا

ne_session_create, ne_set_session_flag.
