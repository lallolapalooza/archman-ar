NAME

NetAddr::IP::Util -- أدوات لمعالجة عناوين IPv4/6 وأرقام 128 بت

SYNOPSIS

INSTALACIÓN

قم بفك ضغط التوزيع في دليل مناسب وقم بتشغيل:

perl Makefile.PL
make
make test
make install

يقوم NetAddr::IP::Util بالتثبيت افتراضيًا مع وظائفه الأساسية المترجمة باستخدام امتدادات Perl XS لإنشاء مكتبة 'C'. إذا لم يكن لديك مترجم C متاحًا أو إذا كنت ترغب في الإصدار الأبطأ في Pure Perl لأي سبب آخر، فقم بتشغيل:

perl Makefile.PL -noxs
make
make test
make install

DESCRIPCIÓN

يوفر NetAddr::IP::Util مجموعة أدوات لمعالجة وتحويل عناوين IPv4 و IPv6 في سياق سلسلة 128 بت والعكس صحيح. يمكن معالجة السلاسل باستخدام عوامل Perl المنطقية:

and     &
or      |
xor     ^
        ~       complement

بنفس أسلوب سلاسل 'vec'.

تدعم وظائف IPv6 جميع تنسيقات rfc1884.

i.e.  x:x:x:x:x:x:x:x:x
      x:x:x:x:x:x:x:d.d.d.d
      ::x:x:x
      ::x:d.d.d.d
and so on...
  • $dotquad = inet_ntoa($netaddr);

    قم بتحويل عنوان شبكة IPv4 المعبأة إلى عنوان IP بتنسيق dot-quad.

    input:        عنوان شبكة IPv4 معبأ
returns:      عنوان IP بتنسيق dot-quad، أي 10.4.12.123
  • $netaddr = inet_aton($dotquad);

    قم بتحويل عنوان IP بتنسيق dot-quad إلى عنوان شبكة IPv4 معبأ.

    input:        عنوان IP بتنسيق dot-quad، أي 192.5.16.32
returns:      عنوان شبكة IPv4 معبأ
  • $ipv6addr = ipv6_aton($ipv6_text);

    تأخذ عنوان IPv6 بالتنسيق الموصوف في rfc1884 وتعيد سلسلة RDATA ثنائية 128 بت.

    input:        عنوان IPv6 بتنسيق rfc1884
returns:      سلسلة RDATA ثنائية 128 بت
  • $ipv6_text = ipv6_ntoa($ipv6naddr);

    تقوم بتحويل سلسلة RDATA ثنائية IPv6 128 بت إلى تمثيل نصي rfc1884.

    input:        سلسلة RDATA ثنائية 128 بت
returns:      تمثيل نصي rfc1884
  • $hex_text = ipv6_n2x($ipv6addr);

    تأخذ سلسلة RDATA IPv6 وتعيد عنوان IPv6 بالتنسيق السداسي عشري مع 8 مقاطع.

    input:        سلسلة RDATA ثنائية 128 بت
returns:      x:x:x:x:x:x:x:x
  • $dec_text = ipv6_n2d($ipv6addr);

    تأخذ سلسلة RDATA IPv6 وتعيد عنوان IPv6 بتنسيق سداسي عشري-عشري مع المقاطع الستة العليا بالسداسي عشري والـ 32 بت السفلية بتنسيق dot-quad.

    input:        سلسلة RDATA ثنائية 128 بت
returns:      x:x:x:x:x:x:d.d.d.d
  • $ipv6naddr = inet_any2n($dotquad or $ipv6_text);

    تقوم هذه الوظيفة بتحويل عنوان IPv4 أو IPv6 بأي تنسيق نصي قياسي إلى عنوان IPv6 128 بت. يتم إضافة '::' مسبقًا لأي عنوان dot-quad يتم العثور عليه وتمريره إلى ipv6_aton.

    input:        dot-quad أو عنوان rfc1844
returns:      عنوان IPv6 128 بت
  • $rv = hasbits($bits128);

    تُرجع هذه الوظيفة true إذا كانت هناك أي وحدات في سلسلة 128 بت و false إذا كانت جميع البتات أصفارًا.

    i.e.  if (hasbits($bits128)) {
        &do_something;
      }
or    if (hasbits($bits128 & $mask128)) {
        &do_something;
      }

    تسمح بتنفيذ وظائف منطقية بالطريقة التالية:

          if ($bits128 & $mask128) {
          ...
input:        سلسلة IPv6 128 بت
returns:      true إذا كان أي بت موجودًا
  • $ipv6naddr = inet_4map6($netaddr or $ipv6naddr);

    تُرجع هذه الوظيفة عنوان شبكة IPv6 مع أول 80 بت تم تعيينها إلى صفر و 16 بت التالية إلى واحد، بينما يتم ملء آخر 32 بت بعنوان IPv4.

    input:        عنوان شبكة IPv4
          or  عنوان شبكة IPv6
returns:      عنوان شبكة IPv6
returns: undef عند حدوث خطأ

    يجب أن يكون عنوان شبكة IPv6 في أحد مساحتي العناوين المتوافقتين مع IPv4. وهما:

    ::ffff::d.d.d.d    or    ::d.d.d.d
  • $rv = isIPv4($bits128);

    تُرجع هذه الوظيفة true إذا لم تكن هناك أي وحدات في جزء IPv6 من سلسلة 128 بت و false بخلاف ذلك.

    i.e.  يجب أن يكون العنوان بالشكل - ::d.d.d.d

    ملاحظة: هذا عنوان IPv6 متوافق مع IPv4 قديم ومهمل

  • $rv = isNewIPv4($bits128);

    تُرجع هذه الوظيفة true إذا كانت سلسلة IPv6 128 بت بالشكل:

    ::ffff::d.d.d.d
  • $rv = isAnyIPv4($bits128);

    تُرجع هذه الوظيفة true إذا كانت سلسلة IPv6 128 بت بالشكل:

    ::d.d.d.d       or      ::ffff::d.d.d.d
  • $dotquad or $hex_text = inet_n2dx($ipv6naddr);

    تقوم هذه الوظيفة بالقيام بالشيء الصحيح وتعيد التمثيل النصي لعنوان IPv4 dot-quad أو عنوان IPv6 بتدوين سداسي عشري.

    input:        سلسلة IPv6 128 بت
returns:      ddd.ddd.ddd.ddd
          or  x:x:x:x:x:x:x:x
  • $dotquad or $dec_text = inet_n2ad($ipv6naddr);

    تقوم هذه الوظيفة بالقيام بالشيء الصحيح وتعيد التمثيل النصي لعنوان IPv4 dot-quad أو عنوان IPv6 بتدوين سداسي عشري-عشري.

    input:        سلسلة IPv6 128 بت
returns:      ddd.ddd.ddd.ddd
          or  x:x:x:x:x:x:ddd.ddd.ddd.dd
  • $netaddr = inet_pton($AF_family,$hex_text);

    تقوم هذه الوظيفة بتحويل عنوان IP بتنسيق نصي (IPv4 أو IPv6) إلى تنسيق ثنائي. يتم التحكم في نوع تحويل IP بواسطة وسيطة FAMILY.

  • $hex_text = inet_ntop($AF_family,$netaddr);

    تقوم هذه الوظيفة بتحويل عنوان IP بتنسيق ثنائي إلى نص. يتم التحكم في نوع IP بواسطة وسيطة FAMILY.
