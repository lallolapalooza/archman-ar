Net::Dropbox::API(3) وثائق Perl مقدمة من المستخدم Net::Dropbox::API(3)

الاسم

Net::Dropbox::API - واجهة واجهة برمجة تطبيقات دروب بوكس

الإصدار

الإصدار 1.9.8

الملخص

واجهة برمجة تطبيقات دروب بوكس هي واجهة برمجة تطبيقات قائمة على OAuth. أحاول تجريد أكبر قدر ممكن، لذا لا يجب أن تحتاج إلى معرفة الكثير عنها. إليك كيفية عملها:

use Net::Dropbox::API;
my $box = Net::Dropbox::API->new({key => 'KEY', secret => 'SECRET'});
my $login_link = $box->login;  # يحتاج المستخدم إلى النقر على هذا الرابط وتسجيل الدخول
$box->auth;                    # يتم تبادل مفاتيح oauth
my $info = $box->account_info; # وهنا لدينا معلومات حسابنا

راجع الأمثلة للحصول على عميل ويب Mojolicious يعمل باستخدام واجهة برمجة تطبيقات دروب بوكس.

يمكنك العثور على توثيق واجهة برمجة تطبيقات دروب بوكس على https://www.dropbox.com/developers/web_docs

الوظائف

login

يقوم هذا بتهيئة مصافحة OAuth الأولية ويعيد عنوان URL لتسجيل الدخول. يجب على المستخدم النقر فوق عنوان URL هذا ثم يجب على المستخدم قبول التطبيق في دروب بوكس.

يقوم دروب بوكس بعد ذلك بإعادة التوجيه إلى عنوان URL الخاص بالرد المحدد باستخدام "$self->callback_url". إذا كان المستخدم قد قبل التطبيق بالفعل، فقد تحدث إعادة التوجيه دون أن ينقر المستخدم فعليًا.

auth

تقوم طريقة المصادقة بتغيير رمز الطلب الأولي إلى رمز الوصول الذي نحتاجه للوصول اللاحق إلى واجهة برمجة التطبيقات. يجب استدعاء هذه الطريقة مرة واحدة فقط بعد تسجيل الدخول.

account_info

يقوم account_info باستطلاع معلومات المستخدم من دروب بوكس.

list

يسرد جميع الملفات في المسار المحدد:

$data = $box->list();           # المستوى الأعلى
$data = $box->list( "/Photos" ); # مجلد

البيانات التي تم إرجاعها هي مرجع إلى تجزئة تحتوي على حقول مختلفة تم إرجاعها بواسطة دروب بوكس، بما في ذلك قيمة "hash"، والتي يمكن استخدامها لاحقًا للتحقق مما إذا كانت بيانات دروب بوكس تحت مجلد محدد قد تغيرت منذ الاستدعاء الأخير.

للقيام بذلك، تقبل list() وسيطة 'hash' اختيارية:

$data = $box->list({ hash => "ce9ccbfb8f255f234c93adcfef33b5a6" },
                   "/Photos");

سيؤدي هذا إما إلى إرجاع

{ http_response_code => 304 }

في هذه الحالة لم يتغير شيء منذ الاستدعاء الأخير، أو

{ http_response_code => 200,
  # ... حقول أخرى متنوعة
}

إذا كانت هناك تعديلات.

copy

نسخ مجلد
copy($from, $to)

move

نقل مجلد
move($from, $to)

mkdir

إنشاء مجلد
mkdir($path)

delete

حذف مجلد
delete($path)

view

إنشاء رابط محمي بملفات تعريف الارتباط للمستخدم لعرضه.
view($path)

metadata

إنشاء رابط محمي بملفات تعريف الارتباط للمستخدم لعرضه.
metadata($path)

putfile

تحميل ملف إلى دروب بوكس

getfile

الحصول على ملف من دروب بوكس

debug

قم بتعيين هذا إلى قيمة غير خاطئة لطباعة بعض معلومات التصحيح إلى STDOUT.
debug(1)

واجهة برمجة التطبيقات الداخلية

_talk

يعالج _talk الوصول إلى الموارد المقيدة. لا يجب عليك عادةً الوصول إلى هذا مباشرة.

nonce

إنشاء nonce مختلف لكل طلب.

NAME

Net::Dropbox::API - Perl interface to the Dropbox API

SYNOPSIS

use Net::Dropbox::API;

my $dropbox = Net::Dropbox::API->new(
    consumer_key    => 'YOUR_CONSUMER_KEY',
    consumer_secret => 'YOUR_CONSUMER_SECRET',
    access_token    => 'YOUR_ACCESS_TOKEN', # Optional
);

# List files in the root directory
my $result = $dropbox->list_folder(path => '');

# Upload a file
$dropbox->upload(
    path        => '/path/to/your/file.txt',
    contents    => 'This is the content of the file.',
    mode        => 'add', # 'add' or 'overwrite'
);

# Download a file
$dropbox->download(path => '/path/to/your/file.txt');

# ... and so on for other API methods

DESCRIPTION

Net::Dropbox::API is a Perl module that provides an interface to the Dropbox API. It allows you to interact with your Dropbox account programmatically, performing actions such as listing files, uploading and downloading files, creating and deleting folders, and more.

METHODS

The module provides methods that correspond to the various Dropbox API endpoints. Each method takes a hash of arguments specific to the API call. Please refer to the official Dropbox API documentation for details on the available endpoints and their parameters.

Some common methods include:

  • list_folder(path => '/path/to/folder'): Lists the contents of a folder.
  • upload(path => '/path/to/upload/file.txt', contents => 'File content', mode => 'add'): Uploads a file.
  • download(path => '/path/to/download/file.txt'): Downloads a file.
  • create_folder(path => '/path/to/new/folder'): Creates a new folder.
  • delete(path => '/path/to/file_or_folder'): Deletes a file or folder.
  • get_metadata(path => '/path/to/file_or_folder'): Retrieves metadata for a file or folder.

Refer to the module's source code and the Dropbox API documentation for a complete list of available methods and their parameters.
