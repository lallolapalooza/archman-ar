RFC-4510 Lightweight Directory Access Protocol (LDAP): Technical Specification Road Map

http://www.ietf.org/rfc/rfc4510.txt

بروتوكول الوصول إلى الدليل الخفيف (LDAP) هو بروتوكول إنترنت للوصول إلى خدمات الدليل الموزعة التي تعمل وفقًا لنماذج بيانات وخدمات X.500. يقدم هذا المستند خارطة طريق لمواصفات LDAP الفنية.

RFC-4511 Lightweight Directory Access Protocol (LDAP): The Protocol

http://www.ietf.org/rfc/rfc4511.txt

يصف هذا المستند عناصر البروتوكول، إلى جانب معانيها وتشفيراتها، لبروتوكول الوصول إلى الدليل الخفيف (LDAP). يوفر LDAP الوصول إلى خدمات الدليل الموزعة التي تعمل وفقًا لنماذج بيانات وخدمات X.500. تستند عناصر البروتوكول هذه إلى تلك الموصوفة في بروتوكول الوصول إلى الدليل X.500 (DAP).

RFC-4512 Lightweight Directory Access Protocol (LDAP): Directory Information Models

http://www.ietf.org/rfc/rfc4512.txt

بروتوكول الوصول إلى الدليل الخفيف (LDAP) هو بروتوكول إنترنت للوصول إلى خدمات الدليل الموزعة التي تعمل وفقًا لنماذج بيانات وخدمات X.500. يصف هذا المستند نماذج معلومات الدليل X.500، كما تستخدم في LDAP.

RFC-4513 Lightweight Directory Access Protocol (LDAP): Authentication Methods and Security Mechanisms

http://www.ietf.org/rfc/rfc4513.txt

يصف هذا المستند طرق المصادقة وآليات الأمان لبروتوكول الوصول إلى الدليل الخفيف (LDAP). يفصل هذا المستند إنشاء أمان طبقة النقل (TLS) باستخدام عملية StartTLS.

يفصل هذا المستند طريقة المصادقة البسيطة Bind بما في ذلك آليات عدم الكشف عن الهوية وغير المصادق عليها وآليات الاسم/كلمة المرور وطريقة المصادقة البسيطة وآلية الأمان (SASL) Bind بما في ذلك آلية EXTERNAL.

يناقش هذا المستند حالات المصادقة والترخيص المختلفة التي قد تمر بها جلسة عمل إلى خادم LDAP والإجراءات التي تؤدي إلى تغييرات الحالة هذه.

RFC-4514 Lightweight Directory Access Protocol (LDAP): String Representation of Distinguished Names

http://www.ietf.org/rfc/rfc4514.txt

يستخدم دليل X.500 الأسماء المميزة (DNs) كمفاتيح أساسية للإدخالات في الدليل. يحدد هذا المستند التمثيل النصي المستخدم في بروتوكول الوصول إلى الدليل الخفيف (LDAP) لنقل الأسماء المميزة. تم تصميم التمثيل النصي لإعطاء تمثيل واضح للأسماء المميزة المستخدمة بشكل شائع، مع القدرة على تمثيل أي اسم مميز.

RFC-4515 Lightweight Directory Access Protocol (LDAP): String Representation of Search Filters

http://www.ietf.org/rfc/rfc4515.txt

يتم نقل مرشحات بحث بروتوكول الوصول إلى الدليل الخفيف (LDAP) في بروتوكول LDAP باستخدام تمثيل ثنائي مناسب للاستخدام على الشبكة. يحدد هذا المستند تمثيلًا نصيًا قابلًا للقراءة البشرية لمرشحات بحث LDAP وهو مناسب للاستخدام في عناوين URL لـ LDAP (RFC 4516) وفي التطبيقات الأخرى.

RFC-4516 Lightweight Directory Access Protocol (LDAP): Uniform Resource Locator

http://www.ietf.org/rfc/rfc4516.txt

يصف هذا المستند تنسيقًا لمحدد موقع الموارد الموحد لبروتوكول الوصول إلى الدليل الخفيف (LDAP). يصف عنوان URL لـ LDAP عملية بحث LDAP المستخدمة لاسترداد المعلومات من دليل LDAP، أو في سياق إحالة LDAP أو مرجع، يصف عنوان URL لـ LDAP خدمة يمكن من خلالها تقدم عملية LDAP.

RFC-4517 Lightweight Directory Access Protocol (LDAP): Syntaxes and Matching Rules

http://www.ietf.org/rfc/rfc4517.txt

لكل سمة مخزنة في دليل بروتوكول الوصول إلى الدليل الخفيف (LDAP)، والتي يمكن نقل قيمها في بروتوكول LDAP، توجد صيغة محددة تقيد بنية وقيم قيمها. لا تعد آليات المقارنة للقيم ذات الصيغة جزءًا من تعريف الصيغة ولكن يتم توفيرها بدلاً من ذلك من خلال قواعد المطابقة المحددة بشكل منفصل. تحدد قواعد المطابقة وسيطة، وقيمة تأكيد، والتي لها أيضًا صيغة محددة. يحدد هذا المستند مجموعة أساسية من الصيغ وقواعد المطابقة لاستخدامها في تعريف السمات لأدلة LDAP.

RFC-4518 Lightweight Directory Access Protocol (LDAP): Internationalized String Preparation

http://www.ietf.org/rfc/rfc4518.txt

لم تحدد مواصفات LDAP الفنية السابقة بدقة كيفية أداء مطابقة السلاسل النصية. أدى ذلك إلى عدد من مشاكل قابلية الاستخدام والتوافقية. يحدد هذا المستند خوارزميات إعداد السلسلة لقواعد المطابقة المستندة إلى الأحرف المعرفة للاستخدام في LDAP.

RFC-4519 Lightweight Directory Access Protocol (LDAP): Schema for User Applications

http://www.ietf.org/rfc/rfc4519.txt

هذا المستند جزء لا يتجزأ من المواصفات الفنية لبروتوكول الوصول إلى الدليل الخفيف (LDAP). يوفر مواصفات فنية لأنواع السمات وفئات الكائنات المعدة للاستخدام من قبل عملاء دليل LDAP للعديد من خدمات الدليل، مثل الدليل الأبيض. تستخدم هذه الكائنات على نطاق واسع كأساس للمخطط في العديد من أدلة LDAP. لا يغطي هذا المستند السمات المستخدمة لإدارة خوادم الدليل، ولا يتضمن كائنات الدليل المعرفة للاستخدامات المحددة في مستندات أخرى.

RFC-3062 عملية LDAP الممتدة لتعديل كلمة المرور

http://www.ietf.org/rfc/rfc3062.txt

RFC-2849 تنسيق تبادل بيانات LDAP (LDIF) - المواصفات التقنية

RFC-2589 امتدادات لخدمات الدليل الديناميكي

http://www.ietf.org/rfc/rfc2589.txt

يدعم LDAP وصولًا خفيفًا إلى خدمات الدليل الثابتة، مما يسمح ببحث سريع نسبيًا وتحديث الوصول. تخزن خدمات الدليل الثابتة معلومات عن الأشخاص التي تظل دقيقة وقيمة على مدى فترة طويلة. تختلف خدمات الدليل الديناميكي في أنها تخزن معلومات عن الأشخاص التي تظل دقيقة وقيمة فقط أثناء تواجد الأشخاص عبر الإنترنت. على الرغم من أن عمليات البروتوكول والسمات التي تستخدمها خدمات الدليل الديناميكي مشابهة لتلك المستخدمة في خدمات الدليل الثابتة، إلا أن العملاء المرتبطين بخدمة دليل ديناميكي يحتاجون إلى تحديث وجودهم بشكل دوري في الخادم لمنع إدخالات الدليل من أن تصبح قديمة في حالة تعطل تطبيق العميل. يتم أيضًا وصف آلية التحكم في التدفق من الخادم التي تسمح للخادم بإعلام العملاء بمدى تكرار تحديث وجودهم.

RFC-2559 بروتوكولات تشغيل البنية التحتية للمفاتيح العامة لـ X.509 للإنترنت - LDAPv2

http://www.ietf.org/rfc/rfc2559.txt

تم تصميم البروتوكول الموضح في هذا المستند لتلبية بعض المتطلبات التشغيلية ضمن البنية التحتية للمفاتيح العامة لـ X.509 للإنترنت. على وجه التحديد، يعالج هذا المستند المتطلبات لتوفير الوصول إلى مستودعات PKI لأغراض استرداد معلومات PKI وإدارة نفس المعلومات. تستند الآلية الموضحة في هذا المستند إلى LDAPv2، المحددة في RFC 1777، وتحدد ملف تعريف لهذا البروتوكول للاستخدام ضمن PKIX وتحديثات الترميزات للشهادات وقوائم الإلغاء من RFC 1778. يتم تحديد آليات إضافية تعالج متطلبات PKIX التشغيلية في مستندات منفصلة.

RFC-2222 طبقة المصادقة والأمان البسيطة (SASL)

http://www.ietf.org/rfc/rfc2222.txt

يصف هذا المستند طريقة لإضافة دعم المصادقة إلى البروتوكولات القائمة على الاتصال. لاستخدام هذه المواصفات، يتضمن البروتوكول أمرًا لتحديد هوية المستخدم والمصادقة عليه للخادم وللتفاوض اختياريًا على حماية تفاعلات البروتوكول اللاحقة. إذا تم التفاوض على استخدامه، يتم إدخال طبقة أمان بين البروتوكول والاتصال. يصف هذا المستند كيف يحدد البروتوكول مثل هذا الأمر، ويحدد العديد من الآليات التي سيستخدمها الأمر، ويحدد البروتوكول المستخدم لحمل طبقة أمان متفاوض عليها عبر الاتصال.

RFC-2218 مخطط مشترك لخدمة دليل الصفحات البيضاء للإنترنت

http://www.ietf.org/rfc/rfc2218.txt

تقترح مجموعة عمل خدمات الدليل المتكاملة (IDS) التابعة لـ IETF مواصفات قياسية لخدمة دليل الصفحات البيضاء بسيطة للإنترنت من خلال تحديد مخطط مشترك لاستخدامه من قبل خوادم الصفحات البيضاء المختلفة. هذا المخطط مستقل عن تطبيقات خدمة الصفحات البيضاء المحددة. تحدد هذه الوثيقة الحد الأدنى من مجموعة السمات الأساسية لإدخال الصفحات البيضاء لفرد وتصف كيفية تعريف ونشر الكائنات الجديدة بهذه السمات. لا تصف كيفية تمثيل الكائنات الأخرى في خدمة الصفحات البيضاء. علاوة على ذلك، لا تعالج توقعات فرز البحث ضمن خدمة معينة.

RFC-2164 استخدام دليل X.500/LDAP لدعم تعيين عناوين MIXER

http://www.ietf.org/rfc/rfc2164.txt

يحدد MIXER (RFC 2156) خوارزمية لاستخدام مجموعة من التعيينات العامة بين عناوين X.400 و RFC 822. تحدد هذه المواصفات كيفية تمثيل هذه التعيينات والحفاظ عليها (تعيينات العناوين العامة المتوافقة مع MIXER أو MCGAMs) في دليل X.500 أو LDAP. آليات لتمثيل عناوين OR وهياكل المجالات الهرمية داخل DIT. تُستخدم هذه التقنيات لتحديد شجرتين فرعيتين مستقلتين في DIT، والتي تحتوي على معلومات التعيين.

RFC-2079 تعريف نوع سمة X.500 وفئة كائن للاحتفاظ بمعرفات الموارد الموحدة

http://www.ietf.org/rfc/rfc2079.txt

تُستخدم عناوين URL على نطاق واسع لتحديد موقع موارد الإنترنت. هناك حاجة ملحة لتضمين عناوين URL في الأدلة التي تتوافق مع نماذج معلومات LDAP و X.500، ورغبة في تضمين أنواع أخرى من معرفات الموارد الموحدة (URIs) عند تعريفها. تقوم العديد من المجموعات المستقلة بالفعل بتجربة تضمين عناوين URL في أدلة LDAP و X.500. يبني هذا المستند على التجريب الذي تم حتى الآن ويحدد نوع سمة جديد وفئة كائن مساعدة للسماح بتخزين معرفات الموارد الموحدة، بما في ذلك عناوين URL، في إدخالات الدليل بطريقة قياسية.

http://www.ietf.org/rfc/rfc2657.txt

RFC-2649 العمليات الموجهة مع S/MIME

http://www.ietf.org/rfc/rfc2649.txt

RFC-2307 استراتيجية لاستخدام LDAP كخدمة معلومات شبكة

http://www.ietf.org/rfc/rfc2307.txt

Net::LDAP::RFC(3pm) - Perl manual page

NAME

Net::LDAP::RFC - LDAP Related RFCs

SYNOPSIS

 use Net::LDAP;

DESCRIPTION

This document provides a list of RFCs and Internet-Drafts related to LDAP. Note that this list is not exhaustive and is subject to change. The primary goal is to list those RFCs and Internet-Drafts that are most directly related to the Net::LDAP module's functionality, and those that define the LDAP protocol itself.

draft-ietf-ldap-transfer -- LDAP Directory Access Protocol

The Lightweight Directory Access Protocol (LDAP) is an application protocol for accessing and maintaining distributed directory information services over an IP network. Directory services may be corporate (e.g. an organization's employees), or may be public (e.g. an area code directory). LDAP is distinct from X.500 in that it uses a simpler data model and is optimized for TCP/IP.

draft-fedorov-ldap-untypedobject -- Structural object class 'namedObject' for LDAP/X.500

This document defines an 'namedObject' structural object class for the Lightweight Directory Access Protocol (LDAP) and X.500. This is useful for entries with no natural choice of structural object class, e.g. if an entry must exist even though its contents are uninteresting.

draft-paterno-ldap-p3p -- P3P Policy Attributes for LDAP

This document defines attributes that can be retrieved via Lightweight Directory Access Protocol version 3 (LDAP) requests, which contain URIs pointing to the privacy policy documents. These documents describe the privacy policy concerning access to a directory server, and the privacy policies that apply to the contents of the directory (a subtree of entries).

draft-chu-ldap-xordered -- Ordered Entries and Values in LDAP

As LDAP is used more extensively for managing various kinds of data, one often encounters a need to preserve both the ordering and the content of data, despite the inherently unordered structure of entries and attribute values in the directory. This document describes a scheme to attach ordering information to attributes in a directory so that the ordering may be preserved and propagated to other LDAP applications.

draft-chu-ldap-logschema -- A Schema for Logging the LDAP Protocol

In order to facilitate remote administration and auditing of LDAP server operation, it is desirable to provide the server's operational logs themselves as a searchable LDAP directory. These logs may also be used as a persistent change log to support various replication mechanisms. This document defines a schema that may be used to represent all of the requests that have been processed by an LDAP server. It may be used by various applications for auditing, flight recorder, replication, and other purposes.

draft-zeilenga-ldap-relax -- The LDAP Relax Rules Control

This document defines the Lightweight Directory Access Protocol (LDAP) Relax Rules Control which allows a directory user agent (a client) to request the directory service temporarily relax enforcement of various data and service model rules.

draft-atherton-dhcp-ldap -- DHCP Option for LDAP Directory Services discovery

This document defines a new DHCP option for delivering configuration information for LDAP services. Through this option, the client receives an LDAP URL [8] of the closest available LDAP server/replica that can be used to authenticate users or look up any useful data.

draft-schleiff-ldap-xri -- LDAP Schema for eXtensible Resource Identifier (XRI)

This document describes Attribute Types and an Object Class for use in representing XRI (eXtensible Resource Identifier) values in LDAP (Lightweight Directory Access Protocol) and X.500 directory services.

draft-wahl-ldap-session -- LDAP Session Tracking Control

Many network devices, application servers, and middleware components of a enterprise software infrastructure generate some form of session tracking identifiers, which are useful when analyzing activity and accounting logs to group activity relating to a particular session. This document discusses how Lightweight Directory Access Protocol version 3 (LDAP) clients can include session tracking identifiers with their LDAP requests. This information is provided through controls in the requests the clients send to LDAP servers. The LDAP server receiving these controls can include the session tracking identifiers the log messages it writes, enabling LDAP requests in the LDAP server's logs to be correlated with activity in logs of other components in the infrastructure. The control also enables session tracking information to be generated by LDAP servers and returned to clients and other servers. Three formats of session tracking identifiers are defined in this document.

draft-wahl-ldap-subtree-source -- LDAP Subtree Data Source URI Attribute

This document defines an attribute that enables administrative clients using the Lightweight Directory Access Protocol (LDAP) to determine the source of directory entries.

draft-ietf-ldapext-psearch -- Persistent Search: A Simple LDAP Change Notification Mechanism

This document defines two controls that extend the LDAPv3 search operation to provide a simple mechanism by which an LDAP client can receive notification of changes that occur in an LDAP server. The mechanism is designed to be very flexible yet easy for clients and servers to implement.

draft-ietf-ldapext-ldapv3-vlv -- LDAP Extensions for Scrolling View Browsing of Search Results

This document describes a Virtual List View control extension for the LDAP Search operation. This control is designed to allow the "virtual list box" feature, common in existing commercial e-mail address book applications, to be supported efficiently by LDAP servers. LDAP servers' inability to support this client feature is a significant impediment to LDAP replacing proprietary protocols in commercial e-mail systems.

The control allows a client to specify that the server return, for a given LDAP search with associated sort keys, a contiguous subset of the search result set. This subset is specified in terms of offsets into the ordered list, or in terms of a greater than or equal comparison value.
