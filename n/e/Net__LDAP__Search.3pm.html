Net__LDAP__Search(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Search(3) وثائق Perl التي ساهم بها المستخدم Net::LDAP::Search(3)

الاسم

Net::LDAP::Search - الكائن الذي تعيده طريقة البحث في Net::LDAP

الملخص

use Net::LDAP;
$mesg = $ldap->search( @search_args );
@entries = $mesg->entries;

الوصف

يتم إرجاع كائن Net::LDAP::Search من طريقة البحث لكائن Net::LDAP. إنه كائن حاوية يحتفظ بنتائج البحث.

الطرق

Net::LDAP::Search يرث من Net::LDAP::Message، وبالتالي يدعم جميع الطرق المعرفة في Net::LDAP::Message.

as_struct ( )
يعيد مرجعًا إلى HASH، حيث تكون المفاتيح هي DNs للنتائج والقيم هي مراجع HASH. تحتفظ هذه الـ HASHes من المستوى الثاني بالسمات بحيث تكون المفاتيح هي أسماء السمات، بالأحرف الصغيرة، والقيم هي مراجع لمصفوفة (ARRAY) تحتوي على القيم.

ستتوقف هذه الطريقة عن الاستجابة حتى ينتهي طلب البحث بالكامل.

count ( )
يعيد عدد الإدخالات التي أعادتها الخادم.

ستتوقف هذه الطريقة عن الاستجابة حتى ينتهي طلب البحث بالكامل.

entry ( INDEX )
يعيد الإدخال N (مبني على الصفر)، والذي سيكون كائن Net::LDAP::Entry. إذا كان INDEX أكبر من أو يساوي العدد الإجمالي للإدخالات المعادة، فسيتم إرجاع "undef".

ستتوقف هذه الطريقة عن الاستجابة حتى يعيد طلب البحث عددًا كافيًا من الإدخالات.

entries ( )
يعيد مصفوفة من كائنات Net::LDAP::Entry التي تم إرجاعها من الخادم.

ستتوقف هذه الطريقة عن الاستجابة حتى ينتهي طلب البحث بالكامل.

pop_entry ( )
يقوم بسحب إدخال من القائمة الداخلية لكائنات Net::LDAP::Entry لهذا البحث. إذا لم تكن هناك إدخالات أخرى، فسيتم إرجاع "undef".

سيؤدي هذا الاستدعاء إلى التوقف إذا كانت القائمة فارغة، حتى يعيد الخادم إدخالًا آخر.

references ( )
يعيد قائمة بالمراجع التي أعادتها الخادم. ستكون هذه قائمة بكائنات Net::LDAP::Reference.
sorted ( )
يعيد قائمة بكائنات Net::LDAP::Entry، مرتبة حسب DNs الخاصة بها.

يتم إجراء الفرز على جانب العميل باستخدام عامل تشغيل الفرز الأبجدي الرقمي لـ Perl "cmp".

sorted ( ATTR, ... )
يعيد قائمة بكائنات Net::LDAP::Entry، مرتبة حسب السمات المحددة. يتم مقارنة السمات بالترتيب المحدد، ولا يتم مقارنة كل منها إلا إذا كانت جميع السمات السابقة متساوية.

يتم إجراء الفرز على جانب العميل باستخدام عامل تشغيل الفرز الأبجدي الرقمي لـ Perl "cmp".

shift_entry ( )
يقوم بتحويل إدخال من القائمة الداخلية لكائنات Net::LDAP::Entry لهذا البحث. إذا لم تكن هناك إدخالات أخرى، فسيتم إرجاع "undef".

سيؤدي هذا الاستدعاء إلى التوقف إذا كانت القائمة فارغة، حتى يعيد الخادم إدخالًا آخر.
