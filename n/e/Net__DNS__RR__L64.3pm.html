Net__DNS__RR__L64(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS::RR::L64(3) وثائق بيرل مساهمة من المستخدم Net::DNS::RR::L64(3)

الاسم

Net::DNS::RR::L64 - سجل مورد L64 لـ DNS

ملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name IN L64 preference locator64');
$rr = Net::DNS::RR->new(
                name       => 'example.com',
                type       => 'L64',
                preference => 10,
                locator64  => '2001:0DB8:1140:1000'
                );

الوصف

فئة لسجلات موارد L64 (محدد الموقع 64 بت) لـ DNS.

يُستخدم سجل المورد L64 للاحتفاظ بقيم محدد الموقع 64 بت للعقد القادرة على ILNPv6.

الأساليب

الأساليب المتاحة هي تلك الموروثة من الفئة الأساسية مع إضافة الأساليب الخاصة بالنوع المحددة في هذه الحزمة.

يُثبط استخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية وقد يؤدي إلى إنهاء البرنامج أو سلوك آخر غير متوقع.

preference

$preference = $rr->preference;
$rr->preference( $preference );

عدد صحيح غير موقع 16 بت بترتيب البايت الشبكي يشير إلى الأفضلية النسبية لسجل L64 هذا بين سجلات L64 الأخرى المرتبطة بهذا الاسم المالك. القيم الأقل مفضلة على القيم الأعلى.

locator64

$locator64 = $rr->locator64;

حقل Locator64 هو عدد صحيح غير موقع 64 بت بترتيب البايت الشبكي له نفس الصيغة والدلالات مثل بادئة توجيه IPv6 64 بت.
