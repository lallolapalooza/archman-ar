ne_set_request_body_provider(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_SET_REQUEST_BODY_(3) مرجع واجهة برمجة تطبيقات neon NE_SET_REQUEST_BODY_(3)

الاسم

ne_set_request_body_buffer, ne_set_request_body_fd, ne_set_request_body_provider - تضمين جسم رسالة مع طلب

ملخص

#include <ne_request.h>

void ne_set_request_body_buffer(ne_request *req, const char *buf, size_t count);

int ne_set_request_body_fd(ne_request *req, int fd, ne_off_t begin, ne_off_t length);

typedef ssize_t (*ne_provide_body)(void *userdata, char *data, size_t buflen);

int ne_set_request_body_provider(ne_request *req, ne_off_t length, ne_provide_body provider, void *userdata);

الوصف

تحدد الدالة ne_set_request_body_buffer أنه يجب تضمين جسم رسالة مع الطلب، والذي يتم تخزينه في المخزن المؤقت buf الذي حجمه count بايت.

يمكن استخدام الدالة ne_set_request_body_fd لتضمين جسم رسالة مع طلب يتم قراءته من واصف ملف. يتم قراءة الجسم من واصف الملف fd، والذي يجب أن يكون مرتبطًا بملف قابل للبحث (ليس أنبوبًا أو مقبسًا أو FIFO). يتم قراءة count بايت، بدءًا من الإزاحة begin (وبالتالي، فإن تمرير begin كصفر يعني قراءة الجسم من بداية الملف).

لكلا الدالتين أعلاه، يجب أن يبقى مصدر جسم الطلب موجودًا حتى يتم إرسال الطلب؛ لا يتم نسخ المخزن المؤقت للذاكرة الممرر إلى ne_set_request_body_buffer ولا واصف الملف الممرر إلى ne_set_request_body_fd داخليًا.

يمكن استخدام الدالة ne_set_request_body_provider لتضمين جسم رسالة مع طلب يتم توفيره بواسطة دالة رد اتصال. يجب أن يكون طول الجسم الممرر في المعامل length موجبًا، أو إذا كان مطلوبًا جسم طلب مجمع، كما هو موضح أدناه، فيمكن استخدام -1.

قبل إرسال الجسم، يتم استدعاء دالة رد الاتصال مرة واحدة مع المعامل buflen كـ 0. يتم بعد ذلك قراءة الجسم عن طريق استدعاء دالة رد الاتصال بشكل متكرر حتى تعود بـ 0 للإشارة إلى نهاية الجسم. يجب أن تكون قيمة الإرجاع لدالة رد الاتصال كما يلي:

أقل من 0

خطأ؛ سيتم إلغاء الطلب. يجب تعيين سلسلة خطأ الجلسة عبر ne_set_error.

0

نهاية الجسم.

بين 0 و buflen

عدد بايتات بيانات جسم الطلب.

أجسام الطلبات المجمعة

يتم إرسال أجسام الطلبات المجمعة فقط عند استخدام ne_set_request_body_provider وتمرير -1 كـ length. في هذه الحالة، لا يجب تحديد طول جسم الطلب مسبقًا. يتم الإشارة إلى نهاية جسم الطلب عن طريق إرجاع 0 من دالة رد الاتصال.

قبل استخدام جسم طلب مجمع، يجب على المستدعي التحقق من أن HTTP/1.1 مدعوم (من قبل الخادم المصدر وأي خادم وكيل HTTP معد). يمكن القيام بذلك عن طريق اختبار أن ne_version_pre_http11 تعود بـ 0 بعد إجراء طلب OPTIONS أو HEAD.
