Net__LDAP__Control__Subentries(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Control::Subentries(3) وثائق Perl المساهمة من المستخدم Net::LDAP::Control::Subentries(3)

الاسم

Net::LDAP::Control::Subentries - كائن تحكم Subentries في LDAPv3

الملخص

use Net::LDAP;
use Net::LDAP::Control::Subentries;
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$subentries = Net::LDAP::Control::Subentries->new( visibility => 1 );
$msg = $ldap->search( base => 'dc=sub,dc=mydomain,dc=eg",
                      filter => '(objectclass=*)',
                      attrs => [ qw/1.1/ ],
                      control => [ $subentries ] );
die "error: ",$msg->code(),": ",$msg->error()  if ($msg->code());

الوصف

"Net::LDAP::Control::Subentries" يوفر واجهة لإنشاء ومعالجة الكائنات التي تمثل تحكم "Subentries" كما هو موضح في RFC 3672.

هذا التحكم، والذي لا يوجد له تحكم استجابة مقابل، مناسب لعمليات بحث LDAP فقط.

في غياب هذا التحكم، تكون الإدخالات الفرعية مرئية فقط لطلبات بحث LDAP مع "scope => 'base'"، ولكن ليس لعمليات البحث مع أي قيمة "scope" أخرى.

وسيطات المنشئ

بالإضافة إلى وسيطات المنشئ الموصوفة في Net::LDAP::Control يتم توفير ما يلي:

visibility
قيمة منطقية تشير إلى رؤية الإدخالات الفرعية أو الإدخالات العادية.

تشير القيمة "TRUE" إلى أن الإدخالات الفرعية مرئية والإدخالات العادية غير مرئية؛ وتشير القيمة "FALSE" إلى أن الإدخالات العادية مرئية والإدخالات الفرعية غير مرئية.

الطرق

كما هو الحال مع Net::LDAP::Control، تتوفر كل وسيطة منشئ موصوفة أعلاه كطريقة على الكائن والتي ستعيد القيمة الحالية للميزة عند استدعائها بدون وسيطة، وستعين قيمة جديدة للميزة عند استدعائها مع وسيطة.
