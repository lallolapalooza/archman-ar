Net__DNS__RR__A(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS::RR::A(3) توثيق بيرل من مساهمين المستخدمين Net::DNS::RR::A(3)

الاسم

Net::DNS::RR::A - سجل موارد DNS A

الملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name IN A address');
$rr = Net::DNS::RR->new(
                name    => 'example.com',
                type    => 'A',
                address => '192.0.2.1'
                );

الوصف

فئة لسجلات موارد عناوين DNS (A).

الطرق

الطرق المتاحة هي تلك الموروثة من الفئة الأساسية المعززة بالطرق الخاصة بالنوع المحددة في هذه الحزمة.

يتم تثبيط استخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية وقد يؤدي ذلك إلى إنهاء البرنامج أو سلوك آخر غير متوقع.

العنوان

$IPv4_address = $rr->address;
$rr->address( $IPv4_address );

عنوان IP الإصدار 4 ممثل باستخدام ترميز النقاط الرباعية.
