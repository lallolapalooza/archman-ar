Net__LDAP__Filter(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Filter(3) وثائق Perl المساهم بها من المستخدم Net::LDAP::Filter(3)

الاسم

Net::LDAP::Filter - تمثيل فلاتر LDAP

الملخص

use Net::LDAP::Filter;
$filter = Net::LDAP::Filter->new( $filter_str );

الوصف

يتيح لك الكائن Net::LDAP::Filter التلاعب مباشرة بفلاتر LDAP دون القلق بشأن التمثيل النصي وجميع آليات الهروب المرتبطة بها.

الباني

new ( [ FILTER ] )
إنشاء كائن جديد. إذا تم توفير FILTER، فقم بتحليله.

الطرق

parse ( FILTER )
تحليل FILTER، وتحديث الكائن لتمثيله.
as_string
إرجاع الفلتر في شكل نصي.
print ( [ FH ] )
طباعة التمثيل النصي للفلتر إلى FH، أو المقبض الإخراج المحدد حاليًا إذا لم يتم توفير FH.
negate ( )
عكس/قلب الكائن منطقياً بحيث يطابق المجموعة المعاكسة من الإدخالات كما في الأصل.

بدلاً من عكس الصيغة النصية ببساطة عن طريق إحاطتها بـ not ، يتم إجراء النفي عن طريق تطبيق قانون دي مورجان بشكل متكرر.

هذا مثال:

(|(&(cn=A)(cn=B))(|(!(cn=C))(cn=D)))

يتم عكسها إلى

(&(|(!(cn=A))(!(cn=B)))(&(cn=C)(!(cn=D))))

صيغة الفلتر

أدناه صيغة فلتر مقدمة في RFC 4515 http://www.ietf.org/rfc/rfc4515.txt

filter       = "(" filtercomp ")"
filtercomp   = and / or / not / item
and          = "&" filterlist
or           = "|" filterlist
not          = "!" filter
filterlist   = 1*filter
item         = simple / present / substring / extensible
simple       = attr filtertype value
filtertype   = equal / approx / greater / less
equal        = "="
approx       = "~="
greater      = ">="
less         = "<="
extensible   = attr [":dn"] [":" matchingrule] ":=" value
               / [":dn"] ":" matchingrule ":=" value
present      = attr "=*"
substring    = attr "=" [initial] any [final]
initial      = value
any          = "*" *(value "*")
final        = value
attr         = AttributeDescription from Section 4.1.4 of RFC 4511
matchingrule = MatchingRuleId from Section 4.1.8 of RFC 4511
value        = AttributeValue from Section 4.1.5 of RFC 4511
Special Character encodings
---------------------------
   *               \2a, \*
   (               \28, \(
   )               \29, \)
   \               \5c, \\
   NUL             \00
