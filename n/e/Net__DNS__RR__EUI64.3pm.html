Net__DNS__RR__EUI64(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS::RR::EUI64(3) وثائق Perl المساهمة من المستخدم Net::DNS::RR::EUI64(3)

الاسم

Net::DNS::RR::EUI64 - سجل موارد DNS EUI64

الملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name IN EUI64 address');
$rr = Net::DNS::RR->new(
                name    => 'example.com',
                type    => 'EUI64',
                address => '00-00-5e-ef-10-00-00-2a'
                );

الوصف

سجلات موارد DNS لمعرفات EUI64 الموسعة المكونة من 64 بت.

يُستخدم سجل الموارد EUI64 لتمثيل معرفات IEEE الموسعة الفريدة المستخدمة في شبكات الطبقة الثانية المختلفة، مثل الإيثرنت.

يجب عدم نشر عناوين EUI64 في DNS العام. تصف RFC7043 آثار خصوصية شديدة محتملة تنتج عن النشر العشوائي لعناوين طبقة الارتباط في DNS.

يُثبط استخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية وقد يؤدي إلى إنهاء البرنامج أو سلوك آخر غير متوقع.

address حقل العنوان هو عنوان طبقة ثانية مكون من 8 بايت بترتيب البايت الشبكي.

التنسيق العرضي هو سداسي عشري مفصول بـ "-".
