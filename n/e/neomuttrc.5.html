reply_regex
النوع: تعبير عادي (regular expression)
الافتراضي: ""^((re|aw|sv)(\[[0-9]+\])*:[ \t]*)*""
تعبير عادي يستخدم للتعرف على رسائل الرد عند التنظيم والرد. القيمة الافتراضية تتوافق مع البادئة اللاتينية القياسية "Re:".
قد تكون هذه القيمة قد تم تعريبها من قبل المترجم للغتك المحلية، مضيفًا بادئات أخرى شائعة في لغتك المحلية. يمكنك إضافة بادئاتك الخاصة عن طريق الإلحاق داخل "^(re)" . على سبيل المثال: "^(re|sv)" أو "^(re|aw|sv)" .
التعبير المقوس الثاني يطابق صفر أو أكثر من الأرقام الموضوعة بين قوسين بعد البادئة، مثل "Re[1]: ". يشير "\[" إلى حرف قوس مربع أيسر حرفي. لاحظ أن الشرطة المائلة يجب مضاعفتها عند استخدامها داخل سلسلة مزدوجة الاقتباس في neomuttrc. "[0-9]+" يعني رقمًا واحدًا أو أكثر. "\]" يعني حرف قوس مربع أيمن حرفي. أخيرًا، يحتوي التعبير المقوس بأكمله على لاحق "*" ، مما يعني أنه يمكن أن يظهر صفر مرة أو أكثر.
الجزء الأخير يطابق نقطتين متبوعتين بمسافة أو علامة جدولة اختيارية. لاحظ أن "\t" يتم تحويله إلى علامة جدولة حرفية داخل سلسلة مزدوجة الاقتباس. إذا استخدمت سلسلة مفردة الاقتباس، فستحتاج إلى كتابة حرف جدولة فعلي، وستحتاج إلى تحويل الشرطات المائلة المزدوجة إلى شرطات مائلة مفردة.
ملاحظة: يتم تخزين نتيجة مطابقة هذا التعبير العادي مع الموضوع في ذاكرة التخزين المؤقت للرأس. Mutt ليس ذكيًا بما يكفي لإبطال إدخال في ذاكرة التخزين المؤقت للرأس بناءً على تغيير $reply_regex، لذا إذا لم تكن ترى قيمًا صحيحة في الفهرس، حاول إيقاف ذاكرة التخزين المؤقت للرأس مؤقتًا. إذا أصلح ذلك المشكلة، فبمجرد تعيين المتغير حسب رغبتك، قم بإزالة ملفات ذاكرة التخزين المؤقت للرأس القديمة وأعد تشغيل ذاكرة التخزين المؤقت للرأس.

النوع: منطقي
الافتراضي: لا
السلوك الافتراضي لـ NeoMutt هو استخدام PGP في جميع عمليات التوقيع/التشفير التلقائي. للتجاوز واستخدام OpenSSL بدلاً من ذلك، يجب تعيين هذا. ومع ذلك، ليس لهذا أي تأثير أثناء الرد، حيث سيقوم NeoMutt تلقائيًا بتحديد
%d
عدد الرسائل الجديدة في صندوق البريد (غير مقروءة، تمت مشاهدتها)
%p
* عدد الرسائل المؤجلة
%P

النسبة المئوية للتقدم في الفهرس

%r

مؤشر الرسائل المعدلة/للقراءة فقط/لن يتم الكتابة/المرفقة، وفقًا لـ $status_chars

%R
* عدد الرسائل المقروءة في صندوق البريد (مقروءة، تمت مشاهدتها)
%s

وضع الفرز الحالي ($sort)

%S

طريقة الفرز المساعدة الحالية ($sort_aux)

%t
* عدد الرسائل المميزة بعلامة في صندوق البريد
%T
* وضع التجميع الحالي ($use_threads)
%u
* عدد الرسائل غير المقروءة في صندوق البريد (تمت مشاهدتها أو لم تتم مشاهدتها)
%v

سلسلة إصدار NeoMutt

%V
* نمط الحد النشط حاليًا، إن وجد
%>X

محاذاة الجزء المتبقي من السلسلة إلى اليمين وملؤها بـ "X"

%|X

ملء حتى نهاية السطر بـ "X"

%*X

ملء ناعم بالحرف "X" كحشو

لشرح "الملء الناعم"، راجع وثائق $index_format.
* = يمكن طباعته اختياريًا إذا لم يكن صفرًا
يمكن استخدام بعض التسلسلات المذكورة أعلاه لطباعة سلسلة اختياريًا إذا كانت قيمتها غير صفرية. على سبيل المثال، قد ترغب فقط في رؤية عدد الرسائل المميزة بعلامة إذا كانت هذه الرسائل موجودة، لأن الصفر ليس ذا مغزى كبير. لطباعة سلسلة اختياريًا بناءً على أحد التسلسلات المذكورة أعلاه، يتم استخدام البنية التالية:
%<sequence_char?optional_string>
حيث sequence_char هو حرف من الجدول أعلاه، و optional_string هي السلسلة التي ترغب في طباعتها إذا كان sequence_char غير صفري. optional_string **يمكن** أن يحتوي على تسلسلات أخرى بالإضافة إلى النص العادي.
هذا مثال يوضح كيفية طباعة عدد الرسائل الجديدة في صندوق بريد اختياريًا:
%<n?%n new messages>
يمكنك أيضًا التبديل بين سلسلتين باستخدام البنية التالية:
%<sequence_char?if_string&else_string>
إذا كانت قيمة sequence_char غير صفرية، فسيتم توسيع if_string، وإلا فسيتم توسيع else_string.
كمثال آخر، إليك كيفية عرض $sort و $sort_aux أو $use_threads و $sort، بناءً على ما إذا كانت سلاسل المحادثات ممكّنة باستخدام $use_threads:
%<T?%s/%S&%T/%s>
يمكنك فرض تحويل نتيجة أي تسلسل يشبه printf(3) إلى أحرف صغيرة عن طريق إضافة شرطة سفلية ("_") قبل حرف التسلسل. على سبيل المثال، إذا كنت ترغب في عرض اسم المضيف المحلي بأحرف صغيرة، فستستخدم: "%_h".
إذا أضفت نقطتين (":") قبل حرف التسلسل، فسيقوم NeoMutt باستبدال أي نقاط في التوسيع بشرطات سفلية. قد يكون هذا مفيدًا مع مجلدات IMAP التي لا تحب النقاط في أسماء المجلدات.

NAME

neomuttrc — NeoMutt configuration file

DESCRIPTION

NeoMutt configuration file.

COMMANDS

See neomutt(1).

PATTERNS

See regex(7).

CONFIGURATION VARIABLES

wrap
Type: boolean
Default: yes
This option controls whether lines longer than the terminal width are wrapped.
If set, NeoMutt will wrap lines longer than the terminal width. If unset, lines longer than the terminal width will be truncated.
Also see $reflow_wrap.
wrap_headers
Type: number
Default: 78
This option specifies the number of characters to use for wrapping an outgoing message's headers. Allowed values are between 78 and 998 inclusive.
Note: This option usually shouldn't be changed. RFC5233 recommends a line length of 78 (the default), so please only change this setting when you know what you're doing.
wrap_search
Type: boolean
Default: yes
Controls whether searches wrap around the end.
When set, searches will wrap around the first (or last) item. When unset, incremental searches will not wrap.
write_bcc
Type: boolean
Default: no
Controls whether NeoMutt writes out the "Bcc:" header when preparing messages to be sent. Some MTAs, such as Exim and Courier, do not strip the "Bcc:" header; so it is advisable to leave this unset unless you have a particular need for the header to be in the sent message.
If NeoMutt is set to deliver directly via SMTP(see $smtp_url), this option does nothing: NeoMutt will never write out the "Bcc:" header in this case.
Note this option only affects the sending of messages. Fcc'ed copies of a message will always contain the "Bcc:" header if one exists.
write_inc
Type: number
Default: 10
When writing a mailbox, a message will be printed every $write_inc messages to indicate progress. If set to 0, only a single message will be displayed before writing a mailbox.
Also see the $read_inc, $net_inc and $time_inc variables and the "tuning" section of the manual for performance considerations.
x_comment_to
Type: boolean
Default: no
If set, NeoMutt will add "X-Comment-To:" field (that contains full name of original article author) to article that followuped to newsgroup.
