Net__LDAPS(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAPS(3) وثائق Perl المساهمة من المستخدم Net::LDAPS(3)

الاسم

Net::LDAPS - استخدام LDAP عبر اتصال SSL

الملخص

use Net::LDAPS;
$ldaps = Net::LDAPS->new('myhost.example.com',
                         port => '10000',
                         verify => 'require',
                         capath => '/usr/local/cacerts/');
# طريقة بديلة
use Net::LDAP;
$ldaps = Net::LDAP->new('ldaps://myhost.example.com:10000',
                        verify => 'require',
                        capath => '/usr/local/cacerts/');

الوصف

التواصل باستخدام بروتوكول LDAP مع خادم الدليل عبر اتصال شبكة مشفر (SSL). هذه الآلية غير قياسية ولكنها مدعومة على نطاق واسع؛ فكر في استخدام LDAPv3 مع امتداد TLS القياسي إن أمكن (لا تدعمه العديد من الخوادم بعد). انظر "start_tls" في Net::LDAP.

يمكن استخدام جميع طرق "Net::LDAP" العادية مع كائن "Net::LDAPS"؛ انظر Net::LDAP للتفاصيل.

المُنشئ

new ( HOST [, OPTIONS ] )
إنشاء اتصال جديد. HOST هو اسم المضيف المراد الاتصال به. OPTIONS هو عدد من أزواج المفتاح/القيمة. انظر "new" في Net::LDAP للتفاصيل.

انظر أيضًا

Net::LDAP, IO::Socket::SSL

الأخطاء

لا يمكنك الحصول على أكثر من اتصال LDAPS واحد في أي وقت، بسبب القيود في شفرة Net::SSLeay الأساسية.
