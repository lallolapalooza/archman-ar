Net__Server__Log__Log__Log4perl(3pm)

الحزمة: perl-net-server

التراخيص: PerlArtistic, GPL

Net::Server::Log::Log::Log4perl(3) وثائق Perl المساهم بها من قبل المستخدم Net::Server::Log::Log::Log4perl(3)

الاسم

Net::Server::Log::Log::Log4perl - التسجيل عبر Log4perl

الملخص

use base qw(Net::Server::PreFork);
__PACKAGE__->run(
    log_file => 'Log::Log4perl',
    log4perl_conf => '/path/to/my/log4perl.conf',
    log4perl_logger => 'myapp',
);

الوصف

توفر هذه الوحدة نمط تسجيل Log::Log4perl لنظام Net::Server.

الإعداد

log_file
لبدء استخدام تسجيل Log::Log4perl، قم ببساطة بتعيين معلمة إعداد Net::Server log_file إلى "Log::Log4perl".

إذا تم استخدام الاسم السحري "Log::Log4perl"، فسيتم توجيه جميع التسجيلات إلى نظام Log4perl. إذا تم استخدامه، يمكن أيضًا تحديد "log4perl_conf"، "log4perl_poll"، "log4perl_logger".

log4perl_conf
متاح فقط إذا كانت "log_file" تساوي "Log::Log4perl". هذا هو اسم ملف إعداد log4perl - انظر Log::Log4perl. إذا لم يتم تعيينه، سيفشل عند بدء التشغيل. إذا كان الملف غير قابل للقراءة، فسيفشل.
log4perl_poll
إذا تم تعيينه إلى قيمة، فسيتم تهيئته باستخدام Log::Log4perl::init_and_watch مع هذه القيمة المستقصية. يمكن أن يكون هذا أيضًا السلسلة "HUP" لإعادة قراءة log4perl_conf عند استلام إشارة HUP. إذا تم تعيينه إلى 0، فلن يتم إجراء أي استقصاء. انظر Log::Log4perl لمزيد من التفاصيل.
log4perl_logger
هذا هو اسم المنشأة. الافتراضي هو "Net::Server".

المعلمات الافتراضية لـ Net::Server

المعلمات التالية متاحة في وحدات "Net::Server" أو "Net::Server::Single" الافتراضية. (قد تستخدم شخصيات أخرى معلمات إضافية وقد لا تستخدم اختياريًا معلمات من الفئة الأساسية.)

Key               Value                    Default
## log4perl parameters (if log_file eq Log::Log4perl)
log4perl_conf     "filename"               will die if not set
log4perl_poll     number or HUP            0 (no polling)
log4perl_logger   "name"                   "Net::Server"

الطرق

"initialize"
يتم استدعاء هذه الطريقة أثناء طريقة initialize_logging الخاصة بـ Net::Server. وهي تعيد مرجع رمز واحد سيتم تخزينه تحت خاصية log_function لكائن Net::Server. يأخذ مرجع الرمز هذا مستوى التسجيل والرسالة كمعلمات ويستدعي نظام log4perl المهيأ.
