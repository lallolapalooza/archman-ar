netdevice(7) دليل معلومات متنوعة netdevice(7)

الاسم

netdevice — وصول منخفض المستوى إلى أجهزة شبكة Linux

الملخص

#include <sys/ioctl.h>
#include <net/if.h>

الوصف

تصف صفحة الدليل هذه واجهة المقابس التي تستخدم لتكوين أجهزة الشبكة.

يدعم Linux بعض أوامر ioctls القياسية لتكوين أجهزة الشبكة. يمكن استخدامها على واصف الملف لأي مقبس بغض النظر عن العائلة أو النوع. معظمها يمرر بنية ifreq:


struct ifreq {
    char ifr_name[IFNAMSIZ];  /* اسم الواجهة */
    union {
        struct sockaddr ifr_addr;
        struct sockaddr ifr_dstaddr;
        struct sockaddr ifr_broadaddr;
        struct sockaddr ifr_netmask;
        struct sockaddr ifr_hwaddr;
        short           ifr_flags;
        int             ifr_ifindex;
        int             ifr_metric;
        int             ifr_mtu;
        struct ifmap    ifr_map;
        char            ifr_slave[IFNAMSIZ];
        char            ifr_newname[IFNAMSIZ];
        char           *ifr_data;
    };
};

AF_INET6 هو استثناء. يمرر بنية in6_ifreq:


struct in6_ifreq {
    struct in6_addr     ifr6_addr;
    u32                 ifr6_prefixlen;
    int                 ifr6_ifindex;  /* فهرس الواجهة */
};

عادة، يحدد المستخدم الجهاز المراد التأثير عليه عن طريق تعيين ifr_name لاسم الواجهة أو ifr6_ifindex لفهرس الواجهة. قد تشترك جميع الأعضاء الأخرى في البنية في الذاكرة.

أوامر ioctls

إذا تم تمييز أمر ioctl بأنه خاص (privileged)، فإن استخدامه يتطلب معرف مستخدم فعال 0 أو القدرة CAP_NET_ADMIN. إذا لم يكن الأمر كذلك، فسيتم إرجاع EPERM.

SIOCGIFNAME
بالنظر إلى ifr_ifindex، يتم إرجاع اسم الواجهة في ifr_name. هذا هو أمر ioctl الوحيد الذي يعيد نتيجته في ifr_name.
SIOCGIFINDEX
استرداد فهرس الواجهة للواجهة إلى ifr_ifindex.
SIOCGIFFLAGS
SIOCSIFFLAGS
الحصول على أو تعيين كلمة العلامات النشطة للجهاز. ifr_flags تحتوي على قناع بت للقيم التالية:
علامات الجهاز
IFF_UP الواجهة قيد التشغيل.
IFF_BROADCAST تم تعيين عنوان بث صالح.
IFF_DEBUG علامة تصحيح أخطاء داخلية.
IFF_LOOPBACK الواجهة هي واجهة loopback.
IFF_POINTOPOINT الواجهة هي رابط نقطة إلى نقطة.
IFF_RUNNING تم تخصيص الموارد.
IFF_NOARP لا يوجد بروتوكول arp، لم يتم تعيين عنوان وجهة L2.
IFF_PROMISC الواجهة في وضع promiscuous.
IFF_NOTRAILERS تجنب استخدام trailers.
IFF_ALLMULTI استقبال جميع حزم multicast.
IFF_MASTER الرئيس لمجموعة موازنة التحميل.
IFF_SLAVE تابع لمجموعة موازنة التحميل.
IFF_MULTICAST يدعم multicast
IFF_PORTSEL قادر على تحديد نوع الوسائط عبر ifmap.
IFF_AUTOMEDIA اختيار الوسائط التلقائي نشط.
IFF_DYNAMIC العناوين مفقودة عندما يتم إيقاف تشغيل الواجهة.
IFF_LOWER_UP إشارة برنامج التشغيل L1 لأعلى (منذ Linux 2.6.17)
IFF_DORMANT إشارة برنامج التشغيل dormant (منذ Linux 2.6.17)
IFF_ECHO صد الحزم المرسلة (منذ Linux 2.6.25)

تعيين كلمة العلامات النشطة هو عملية خاصة، ولكن يمكن لأي عملية قراءتها.

SIOCGIFPFLAGS
SIOCSIFPFLAGS
الحصول على أو تعيين علامات موسعة (خاصة) للجهاز. ifr_flags تحتوي على قناع بت للقيم التالية:
علامات خاصة
IFF_802_1Q_VLAN الواجهة هي جهاز 802.1Q VLAN.
IFF_EBRIDGE الواجهة هي جهاز جسر Ethernet.
IFF_SLAVE_INACTIVE الواجهة هي تابع ربط غير نشط.
IFF_MASTER_8023AD الواجهة هي رئيس ربط 802.3ad.
IFF_MASTER_ALB الواجهة هي رئيس ربط ALB متوازن.
IFF_BONDING الواجهة هي رئيس ربط أو تابع.
IFF_SLAVE_NEEDARP تحتاج الواجهة إلى ARPs للتحقق.
IFF_ISATAP الواجهة هي واجهة RFC4214 ISATAP.

تعيين علامات الواجهة الموسعة (الخاصة) هو عملية خاصة.

SIOCGIFADDR
SIOCSIFADDR
SIOCDIFADDR
الحصول على، تعيين، أو حذف عنوان الجهاز باستخدام ifr_addr، أو ifr6_addr مع ifr6_prefixlen. تعيين أو حذف عنوان الواجهة هو عملية خاصة. للتوافق، SIOCGIFADDR يعيد فقط عناوين AF_INET، SIOCSIFADDR يقبل عناوين AF_INET و AF_INET6، و SIOCDIFADDR يحذف عناوين AF_INET6 فقط. يمكن حذف عنوان AF_INET عن طريق تعيينه إلى صفر عبر SIOCSIFADDR.
SIOCGIFDSTADDR
SIOCSIFDSTADDR
الحصول على أو تعيين عنوان الوجهة لجهاز نقطة إلى نقطة باستخدام ifr_dstaddr. للتوافق، يتم قبول أو إرجاع عناوين AF_INET فقط. تعيين عنوان الوجهة هو عملية خاصة.
SIOCGIFBRDADDR
SIOCSIFBRDADDR
الحصول على أو تعيين عنوان البث لجهاز باستخدام ifr_brdaddr. للتوافق، يتم قبول أو إرجاع عناوين AF_INET فقط. تعيين عنوان البث هو عملية خاصة.
SIOCGIFNETMASK
SIOCSIFNETMASK
الحصول على أو تعيين قناع الشبكة لجهاز باستخدام ifr_netmask. للتوافق، يتم قبول أو إرجاع عناوين AF_INET فقط. تعيين قناع الشبكة هو عملية خاصة.
SIOCGIFMETRIC
SIOCSIFMETRIC
الحصول على أو تعيين المقياس (metric) للجهاز باستخدام ifr_metric. هذا غير مطبق حاليًا؛ يقوم بتعيين ifr_metric إلى 0 إذا حاولت قراءته ويرجع EOPNOTSUPP إذا حاولت تعيينه.
SIOCGIFMTU

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

netdevice.7 - Arch Linux man pages

netdevice.7

NAME

netdevice - low-level network device ioctls

SYNOPSIS

<#include <sys/socket.h>>
#include <linux/if.h>
#include <linux/if_arp.h>
#include <linux/if_ether.h>
#include <linux/if_packet.h>

int ioctl(int fd, unsigned long request, ...);

DESCRIPTION

The ioctl() system call, in conjunction with a socket file descriptor fd, is used to perform various device-specific operations. The exact set of operations depends on the device driver and the protocol family. This man page describes the generic network device ioctl()s. The request argument specifies the operation to perform. For many operations, the third argument is a pointer to an ifreq structure defined in <linux/if.h>:


struct ifreq {
    char    ifr_name[IFNAMSIZ]; /* interface name */
    union {
        struct sockaddr ifr_addr;
        struct sockaddr ifr_dstaddr;
        struct sockaddr ifr_broadaddr;
        struct sockaddr ifr_netmask;
        struct sockaddr ifr_hwaddr;
        short           ifr_flags;     /* interface flags */
        int             ifr_metric;    /* metric forwarding */
        int             ifr_mtu;       /* mtu value */
        struct ifconf   ifr_ifconf;
        struct ifmap    ifr_map;
        char            ifr_slave[IFNAMSIZ]; /* alias forifr_name */
        char            ifr_newname[IFNAMSIZ]; /* new value forifr_name */
        char            ifr_downtime;  /* downtime */
        char            ifr_upcount;   /* number of times interface was up */
        char            ifr_lastchange;/* time of last change */
        struct ethtool_value *ifr_data;
    } ifr_ifru;
};

SIOCGIFADDR
Get the current protocol address (e.g. IP address) for the interface named in ifr_name, returning it in ifr_addr. This is currently only supported for AF_INET addresses.
SIOCSIFADDR
Set the protocol address for the interface named in ifr_name to the value in ifr_addr. This is a privileged operation.
SIOCGLIFADDR
Get the current primary protocol address for the interface named in ifr_name, returning it in ifr_addr. This is intended for IPv6 addresses.
SIOCSLIFADDR
Set the primary protocol address for the interface named in ifr_name to the value in ifr_addr. This is a privileged operation. This is intended for IPv6 addresses.
SIOCADDLI
SIOCDELBI
Add or delete an alias address for the interface named in ifr_name, using ifr_addr. These are privileged operations.
SIOCDIFADDR
Delete the protocol address for the interface named in ifr_name. This is a privileged operation.
SIOCGIFBRADDR
Get the broadcast address for the interface named in ifr_name, returning it in ifr_broadaddr.
SIOCSIFBRADDR
Set the broadcast address for the interface named in ifr_name to the value in ifr_broadaddr. This is a privileged operation.
SIOCGIFDSTADDR
Get the destination address (for point-to-point links) for the interface named in ifr_name, returning it in ifr_dstaddr.
SIOCSIFDSTADDR
Set the destination address for the interface named in ifr_name to the value in ifr_dstaddr. This is a privileged operation.
SIOCGIFNETMASK
Get the network mask for the interface named in ifr_name, returning it in ifr_netmask.
SIOCSIFNETMASK
Set the network mask for the interface named in ifr_name to the value in ifr_netmask. This is a privileged operation.
SIOCGIFMTU
SIOCSIFMTU
Get or set the MTU (Maximum Transfer Unit) of a device using ifr_mtu. Setting the MTU is a privileged operation. Setting the MTU to too small values may cause kernel crashes.
SIOCGIFHWADDR
Get the hardware address of a device using ifr_hwaddr.
SIOCSIFHWADDR
Get or set the hardware address of a device using ifr_hwaddr. The hardware address is specified in a struct sockaddr. sa_family contains the ARPHRD_* device type, sa_data the L2 hardware address starting from byte 0. Setting the hardware address is a privileged operation.
SIOCSIFHWBROADCAST
Set the hardware broadcast address of a device from ifr_hwaddr. This is a privileged operation.
SIOCGIFMAP
Get the hardware parameters of a device using ifr_map.
SIOCSIFMAP
Get or set the interface's hardware parameters using ifr_map. Setting the parameters is a privileged operation.

struct ifmap {
    unsigned long   mem_start;
    unsigned long   mem_end;
    unsigned short  base_addr;
    unsigned char   irq;
    unsigned char   dma;
    unsigned char   port;
};

The interpretation of the ifmap structure depends on the device driver and the architecture.
SIOCADDMULTI
Add a multicast address to the device's link layer multicast filters using ifr_hwaddr. This is a privileged operation.
SIOCDELMULTI
Add an address to or delete an address from the device's link layer multicast filters using ifr_hwaddr. These are privileged operations. See also packet(7) for an alternative.
SIOCGIFTXQLEN
Get the transmit queue length of a device using ifr_qlen.
SIOCSIFTXQLEN
Get or set the transmit queue length of a device using ifr_qlen. Setting the transmit queue length is a privileged operation.
SIOCSIFNAME
Changes the name of the interface specified in ifr_name to ifr_newname. This is a privileged operation. It is allowed only when the interface is not up.
SIOCGIFCONF
Return a list of interface (network layer) addresses. This currently means only addresses of the AF_INET (IPv4) family for compatibility. Unlike the others, this ioctl passes an ifconf structure:

struct ifconf {
    int               ifc_len; /* size of buffer */
    union {
        char         *ifc_buf; /* buffer address */
        struct ifreq *ifc_req; /* array of structures */
    };
};

If ifc_req is NULL, SIOCGIFCONF returns the necessary buffer size in bytes for receiving all available addresses in ifc_len. Otherwise, ifc_req contains a pointer to an array of ifreq structures to be filled with all currently active L3 interface addresses. ifc_len contains the size of the array in bytes. Within each ifreq structure, ifr_name will receive the interface name, and ifr_addr the address. The actual number of bytes transferred is returned in ifc_len.
If the size specified by ifc_len is insufficient to store all the addresses, the kernel will skip the exceeding ones and return success. There is no reliable way of detecting this condition once it has occurred. It is therefore recommended to either determine the necessary buffer size beforehand by calling SIOCGIFCONF with ifc_req set to NULL, or to retry the call with a bigger buffer whenever ifc_len upon return differs by less than sizeof(struct ifreq) from its original value.
If an error occurs accessing the ifconf or ifreq structures, EFAULT will be returned.

Most protocols support their own ioctls to configure protocol-specific interface options. See the protocol man pages for a description. For configuring IP addresses, see ip(7).

In addition, some devices support private ioctls. These are not described here.

NOTES

SIOCGIFCONF and the other ioctls that accept or return only AF_INET socket addresses are IP-specific and perhaps should rather be documented in ip(7).

The names of interfaces with no addresses or that don't have the IFF_RUNNING flag set can be found via /proc/net/dev.

AF_INET6 IPv6 addresses can be read from /proc/net/if_inet6 or via rtnetlink(7). Adding a new IPv6 address and deleting an existing IPv6 address can be done via SIOCSIFADDR and SIOCDIFADDR or via rtnetlink(7). Retrieving or changing destination IPv6 addresses of a point-to-point interface is possible only via rtnetlink(7).

BUGS

glibc 2.1 is missing the ifr_newname macro in <net/if.h>. Add the following to your program as a workaround:


#ifndef ifr_newname
#define ifr_newname     ifr_ifru.ifru_slave
#endif

SEE ALSO

proc(5), capabilities(7), ip(7), rtnetlink(7)
