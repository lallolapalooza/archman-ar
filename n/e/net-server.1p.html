net-server(1p)

الحزمة: perl-net-server

التراخيص: PerlArtistic, GPL

NET-SERVER(1p) وثائق Perl مقدمة من المستخدم NET-SERVER(1p)

الاسم

net-server - وحدة بدء تشغيل Net::Server الأساسية

الملخص

net-server [نوع أساسي] [وسيطات خادم الشبكة]
net-server PreFork ipv '*'
net-server HTTP
net-server HTTP app foo.cgi
net-server HTTP app foo.cgi app /=bar.cgi
net-server HTTP port 8080 port 8443/ssl ipv '*' server_type PreFork --SSL_key_file=my.key --SSL_cert_file=my.crt access_log_file STDERR

الوصف

يوفر برنامج net-server طريقة بسيطة لاختبار التعليمات البرمجية وتجربة معلمات منفذ الاتصال. على الرغم من أن الخادم قيد التشغيل يمكن أن يكون قويًا بما يكفي للإنتاج، فمن المتوقع أن تستخدم هذه الثنائية فقط للاختبار الأساسي لمنافذ net-server، والتي تعمل كخادم صدى بسيط، أو لتشغيل نصوص برمجية للتطوير كـ CGI.

الخيارات

"نوع أساسي"
قد يكون الوسيط الأول عبارة عن نكهة Net::Server. يتم تقديم هذا كاختصار لكتابة server_type "ServerFlavor". بالإضافة إلى ذلك، يسمح هذا لأنواع مثل HTTP و PSGI، والتي ليست أنواعًا أساسية لـ Net::Server، بالوراثة من أنواع خادم أخرى عبر وسيط server_type إضافي. 
net-server PreFork
net-server HTTP  # يصبح خادم HTTP في نكهة Fork
net-server HTTP server_type PreFork  # خادم HTTP مفرد
"port"
المنفذ للربط عليه. الافتراضي هو 80 إذا تم تشغيل خادم HTTP كـ root، 8080 إذا تم تشغيل خادم HTTP كمستخدم غير root، أو 20203 بخلاف ذلك.

يمكن إعطاء قيم متعددة للربط بمنافذ متعددة. تتوفر هنا جميع طرق تحديد سمات المنفذ الموضحة في Net::Server و Net::Server::Proto.

net-server port 20201
net-server port 20202
net-server port 20203/IPv6
"host"
المضيف للربط إليه. الافتراضي هو *. سيرتبط بمقبس IPv4 إذا تم إعطاء عنوان IPv4. سيرتبط بمقبس IPv6 إذا تم إعطاء عنوان IPv6 (يتطلب تثبيت IO::Socket::INET6).

إذا تم إعطاء اسم مضيف ولا يزال "ipv" مضبوطًا على 4، فسيتم إنشاء مقبس IPv4. إذا تم إعطاء اسم مضيف وتم ضبط "ipv" على 6، فسيتم إنشاء مقبس IPv6. إذا تم إعطاء اسم مضيف وتم ضبط "ipv" على * (الافتراضي)، فسيتم إجراء بحث وسيتم ربط أي عناوين IPv4 أو IPv6 متاحة. يمكن ضبط معلمة "ipv" مباشرة، أو تمريرها في المنفذ، أو بالإضافة إلى ذلك يمكن تمريرها كجزء من اسم المضيف.

net-server host localhost
net-server host localhost/IPv4

هناك العديد من الخيارات المتاحة. يرجى الرجوع إلى وثائق Net::Server.
