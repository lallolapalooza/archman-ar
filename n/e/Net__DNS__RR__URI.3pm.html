Net__DNS__RR__URI(3pm)

الحزمة: perl-net-dns

Net::DNS::RR::URI(3) وثائق بيرل مساهمة من المستخدم Net::DNS::RR::URI(3)

الاسم

Net::DNS::RR::URI - سجل مورد URI لـ DNS

الملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name URI priority weight target');

الوصف

فئة لسجلات مورد خدمة DNS (URI).

الوظائف

الوظائف المتاحة هي تلك الموروثة من الفئة الأساسية المعززة بالوظائف الخاصة بالنوع المحدد في هذه الحزمة.

لا يُنصح باستخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية وقد يؤدي ذلك إلى إنهاء البرنامج أو سلوك آخر غير متوقع.

الأولوية

$priority = $rr->priority;
$rr->priority( $priority );

أولوية هدف URI في سجل المورد هذا. نطاق هذا الرقم هو 0-65535. يجب على العميل محاولة الاتصال بـ URI ذات الأولوية ذات الرقم الأقل التي يمكنه الوصول إليها؛ ويتم استخدام الاختيار الموزون لتوزيع الحمل عبر الأهداف ذات الأولوية المتساوية.

الوزن

$weight = $rr->weight;
$rr->weight( $weight );

آلية اختيار الخادم. يحدد حقل الوزن وزنًا نسبيًا للإدخالات ذات الأولوية المتساوية. يجب أن تحصل الأوزان الأكبر على احتمالية أعلى نسبيًا للاختيار. نطاق هذا الرقم هو 0-65535.

الهدف

$target = $rr->target;
$rr->target( $target );

URI للهدف. يكون حل URI وفقًا لتعريفات مخطط URI.
