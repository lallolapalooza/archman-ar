NAME

netsnmp_sess_api - session API for the Net-SNMP library

SYNOPSIS

#include <net-snmp/net-snmp-includes.h>

netsnmp_session *netsnmp_open( netsnmp_session *sessionp );

void netsnmp_close( netsnmp_session *sessionp );

int netsnmp_send( netsnmp_session *sessionp, netsnmp_pdu *pdu );

int netsnmp_get_next( netsnmp_session *sessionp, netsnmp_pdu *pdu );

int netsnmp_get( netsnmp_session *sessionp, netsnmp_pdu *pdu );

int netsnmp_get_bulk( netsnmp_session *sessionp, netsnmp_pdu *pdu, int nonrepeaters, int maxrepetitions );

int netsnmp_set( netsnmp_session *sessionp, netsnmp_pdu *pdu );

int netsnmp_inform( netsnmp_session *sessionp, netsnmp_pdu *pdu );

int netsnmp_trap( netsnmp_session *sessionp, netsnmp_pdu *pdu );

netsnmp_pdu * netsnmp_create_pdu( int type );

void netsnmp_free_pdu( netsnmp_pdu *pdu );

int netsnmp_add_null_var( netsnmp_pdu *pdu, const oid *objid, size_t objidlen );

int netsnmp_add_var( netsnmp_pdu *pdu, const oid *objid, size_t objidlen, int type, const void *value, size_t len );

int netsnmp_add_vip( netsnmp_pdu *pdu, const oid *objid, size_t objidlen, int type, const void *value, size_t len );

int netsnmp_add_var_by_text( netsnmp_pdu *pdu, const char *objid_text, int type, const void *value, size_t len );

int netsnmp_add_var_by_text_vip( netsnmp_pdu *pdu, const char *objid_text, int type, const void *value, size_t len );

int netsnmp_add_leaf( netsnmp_pdu *pdu, netsnmp_variable_list *leaf );

netsnmp_variable_list * netsnmp_get_next_variable( netsnmp_pdu *pdu );

netsnmp_variable_list * netsnmp_get_first_variable( netsnmp_pdu *pdu );

void netsnmp_free_variable( netsnmp_variable_list *var );

void netsnmp_free_variables( netsnmp_variable_list *vars );

DESCRIPTION

The Net-SNMP library provides a C API for developing SNMP managers and agents. The netsnmp_sess_api family of functions provides the core functionality for establishing and managing SNMP sessions, constructing and sending PDUs, and processing incoming responses.

A netsnmp_session structure holds the configuration and state for an SNMP communication channel. It is initialized and then passed to netsnmp_open to establish a connection with an SNMP agent.

The netsnmp_open function initializes an SNMP session based on the parameters provided in the netsnmp_session structure. These parameters can include the agent's hostname or IP address, the SNMP port, the SNMP version, community string, and various other configuration options.

Once a session is open, you can send various types of PDUs to the agent using functions like netsnmp_send, netsnmp_get_next, netsnmp_get, netsnmp_set, netsnmp_inform, and netsnmp_trap.

Before sending a PDU, you must first create it using netsnmp_create_pdu, specifying the PDU type (e.g., GET, SET, GETNEXT). Then, you add variables to the PDU using functions like netsnmp_add_null_var, netsnmp_add_var, or netsnmp_add_var_by_text.

After sending a PDU, the library will typically receive a response from the agent. The response PDU is then processed, and its variables can be accessed using functions like netsnmp_get_first_variable and netsnmp_get_next_variable.

Finally, when you are finished with a session, you should close it using netsnmp_close. Similarly, PDUs and variables should be freed using netsnmp_free_pdu and netsnmp_free_variable, respectively, to prevent memory leaks.

DIAGNOSTICS

The Net-SNMP library returns status codes or error messages to indicate the success or failure of operations. Common errors include:

SNMPERR_UNKNOWN_PDU
SNMPERR_TIMEOUT
