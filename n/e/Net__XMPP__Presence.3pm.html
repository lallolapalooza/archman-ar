NAME

Net::XMPP::Presence - represents an XMPP presence stanza

SYNOPSIS

    use Net::XMPP::Presence;

    # Constructor
    my $Pres = Net::XMPP::Presence->new(
        to       => 'user@example.com',
        from     => 'another@example.com/resource',
        type     => 'available',
        show     => 'away',
        status   => 'Gone fishing',
        priority => 5
    );

    # Methods
    my $to = $Pres->to();
    my $from = $Pres->from();
    my $type = $Pres->type();
    my $show = $Pres->show();
    my $status = $Pres->status();
    my $priority = $Pres->priority();

    # Check for defined attributes
    $Pres->DefinedTo();
    $Pres->DefinedFrom();
    $Pres->DefinedType();
    $Pres->DefinedStatus();
    $Pres->DefinedPriority();
    $Pres->DefinedShow();

    # String representation
    my $string = $Pres->as_string();

DESCRIPTION

Net::XMPP::Presence is a class for representing XMPP presence stanzas.

Presence stanzas are used to indicate a user's availability, mood, and activity.

METHODS

new()
Creates a new Net::XMPP::Presence object. Accepts a hash of attributes:
to()
Returns the value of the to attribute.
from()
Returns the value of the from attribute.
type()
Returns the value of the type attribute.
show()
Returns the value of the show attribute.
status()
Returns the value of the status attribute.
priority()
Returns the value of the priority attribute.
as_string()
Returns the XML string representation of the presence stanza.
DefinedTo
returns 1 if the to attribute is defined in the <presence/>, 0 otherwise. 
$test = $Pres->DefinedTo();
DefinedFrom
returns 1 if the from attribute is defined in the <presence/>, 0 otherwise. 
$test = $Pres->DefinedFrom();
DefinedType
returns 1 if the type attribute is defined in the <presence/>, 0 otherwise. 
$test = $Pres->DefinedType();
DefinedStatus
returns 1 if <status/> is defined in the <presence/>, 0 otherwise. 
$test = $Pres->DefinedStatus();
DefinedPriority
returns 1 if <priority/> is defined in the <presence/>, 0 otherwise. 
$test = $Pres->DefinedPriority();
DefinedShow
returns 1 if <show/> is defined in the <presence/>, 0 otherwise. 
$test = $Pres->DefinedShow();
