ne_set_request_flag(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_SET_REQUEST_FLAG(3) مرجع واجهة برمجة تطبيقات neon NE_SET_REQUEST_FLAG(3)

الاسم

ne_set_request_flag, ne_get_request_flag - تعيين واسترجاع علامات لكل طلب

الملخص

#include <ne_request.h>

void ne_set_request_flag(ne_request *req, ne_request_flag flag, int value);

int ne_get_request_flag(ne_request *req, ne_request_flag flag);

الوصف

تقوم الدالة ne_set_request_flag بتمكين أو تعطيل علامة لكل طلب. تمرير وسيطة value غير صفرية تمكن العلامة، وصفر يعطلها.

العلامات التالية محددة:

NE_REQFLAG_EXPECT100

قم بتمكين هذه العلامة لاستخدام ميزة "Expect: 100-continue" في HTTP/1.1، والتي تسمح للخادم بمعالجة رؤوس الطلب دون قراءة كامل نص الطلب. هذا يوفر الوقت وعرض النطاق الترددي إذا قدم الخادم تحديًا للمصادقة (يتطلب إعادة إرسال الطلب)، ولكنه يواجه مشاكل توافق مع بعض الخوادم القديمة.

NE_REQFLAG_IDEMPOTENT

قم بتعطيل هذه العلامة إذا كان الطلب يستخدم طريقة غير متكررة مثل POST

NE_REQFLAG_1XXTIMEOUT (افتراضي قيد التشغيل)

قم بتعطيل هذه العلامة لتعطيل انتهاء المهلة الإجمالي عند قراءة استجابات مؤقتة (1xx)؛

قيمة الإرجاع

تعيد الدالة ne_get_request_flag صفرًا إذا تم تعطيل علامة، وأقل من الصفر إذا لم تكن العلامة مدعومة، أو أكبر من الصفر إذا كانت العلامة ممكّنة.
