الحصول على معلومات حول جميع مجموعات الأخبار النشطة. النتيجة هي مرجع إلى تجزئة حيث المفتاح هو اسم مجموعة وكل قيمة هي مرجع إلى مصفوفة. العناصر في هذه المصفوفة هي: - رقم آخر مقال في المجموعة ، ورقم أول مقال في المجموعة وأي علامات معلومات حول المجموعة.

$since هي قيمة وقت و $distributions هي إما نمط توزيع أو مرجع إلى قائمة بأنماط التوزيع. النتيجة هي نفس نتيجة "list"، ولكن المجموعات المعادة ستكون محدودة بتلك التي تم إنشاؤها بعد $since ، وإذا تم تحديدها ، في إحدى مناطق التوزيع في $distributions.
"newnews($since[, $groups[, $distributions]])"
$since هي قيمة وقت. $groups هو إما نمط مجموعة أو مرجع إلى قائمة بأنماط المجموعات. $distributions هو إما نمط توزيع أو مرجع إلى قائمة بأنماط التوزيع.

يُرجع مرجعًا إلى قائمة تحتوي على معرفات الرسائل لجميع الأخبار التي تم نشرها بعد $since ، والتي توجد في مجموعات تتطابق مع $groups وتوزيع يطابق $distributions.

NAME

Net::NNTP - Perl interface to the NNTP protocol

SYNOPSIS

    use Net::NNTP;

    my $conn = Net::NNTP->new("news.example.com");
    unless ($conn) {
        die "Could not connect to server: $!";
    }

    if ($conn->banner) {
        print $conn->banner, "\n";
    }

    if ($conn->login) {
        print "Logged in successfully.\n";
    } else {
        print "Login failed: ", $conn->message, "\n";
        # Use anonymous login if available
        if ($conn->login("anonymous", "me@example.com")) {
            print "Logged in anonymously.\n";
        } else {
            die "Anonymous login failed: ", $conn->message, "\n";
        }
    }

    my ($ok, $headers, $message) = $conn->head("1234-5678");
    if ($ok) {
        print $headers;
        print $message;
    } else {
        die "Could not retrieve article: ", $conn->message, "\n";
    }

    $conn->quit;

DESCRIPTION

The Net::NNTP module provides an object-oriented interface to the Network News Transfer Protocol (NNTP).

You can use this module to connect to NNTP servers, authenticate, select newsgroups, retrieve articles, post articles and perform other NNTP operations.

Constructor

$conn = Net::NNTP->new(HOST, OPTIONS)
Connects to the NNTP server specified by HOST. HOST can be a hostname or an IP address. OPTIONS is a hash of options that are passed directly to the underlying LWP::UserAgent object. Possible options are:
Host
The hostname or IP address of the NNTP server. This is the default behavior if HOST is not specified.
Port
The port number to connect to. Defaults to 119 (NNTP).
Debug
If set to a true value, the module will print debugging information to STDERR.
Timeout
The timeout value for network operations. Defaults to 300 seconds.
Passive
If set to a true value, the module will use passive FTP semantics if the NNTP server supports it. This is useful for getting around firewalls. Defaults to false.
Proto
The protocol to use for the connection. Defaults to NNTP. This is mainly used when interacting with servers that provide multiple protocols over different ports.

Methods

The following methods are available on a Net::NNTP object:

$conn->banner
Returns the initial greeting banner from the NNTP server.
$conn->login(USER, PASS)
Logs the user in to the NNTP server. USER and PASS are optional. If not provided, an attempt will be made to log in anonymously. Returns true on success, false on failure.
$conn->logout
Logs the user out from the NNTP server.
$conn->quit
Disconnects from the NNTP server.
$conn->list( [PATTERN] )
Returns a list of newsgroups. If PATTERN is provided, only newsgroups matching the pattern are returned. The pattern is in the WILDMAT format (see below).
$conn->group(GROUP)
Selects the specified newsgroup GROUP. Returns a list containing:
  • True on success, false on failure.
  • The total number of articles in the group.
  • The first article number in the group.
  • The last article number in the group.
$conn->help
Returns the help message from the server.
$conn->stat(MESSAGE-ID | NUMBER)
Returns information about a specific article. MESSAGE-ID or NUMBER can be used to identify the article. Returns a list containing:
  • True on success, false on failure.
  • The message ID of the article.
  • The size of the article.
$conn->next
Moves to the next article in the current newsgroup. Returns the same information as stat.
$conn->last
Moves to the previous article in the current newsgroup. Returns the same information as stat.
$conn->head(MESSAGE-ID | NUMBER)
Retrieves the headers of a specific article. Returns a list containing:
  • True on success, false on failure.
  • The headers of the article as a single string.
  • The article body as a single string.
$conn->body(MESSAGE-ID | NUMBER)
Retrieves the body of a specific article. Returns a list containing:
  • True on success, false on failure.
  • The body of the article as a single string.
$conn->article(MESSAGE-ID | NUMBER)
Retrieves the entire article (headers and body). Returns a list containing:
  • True on success, false on failure.
  • The headers of the article as a single string.
  • The article body as a single string.
$conn->post(MESSAGE)
Posts a new article. MESSAGE should be the complete article, including headers. Returns true on success, false on failure.
$conn->ihave(MESSAGE-ID, HEADERS, BODY)
Posts an article that you already have locally. MESSAGE-ID is the message ID of the article, HEADERS and BODY are the respective parts of the article. Returns true on success, false on failure.
$conn->xover(MESSAGE-SPEC)
Retrieves article overview information. MESSAGE-SPEC can be a single article number, a range of article numbers, or a list of article numbers.
$conn->xapfrom(MESSAGE-SPEC)
Retrieves articles from a specific sender. MESSAGE-SPEC is the same as for xover.
$conn->getarticle( [MESSAGE-SPEC] )
Retrieves article(s). If MESSAGE-SPEC is not provided, the current article is retrieved. Otherwise, it retrieves the specified article(s). Returns a list containing:
  • True on success, false on failure.
  • A hash reference where keys are article numbers and values are anonymous arrays containing the headers and body of the article.
$conn->gethead( [MESSAGE-SPEC] )
Retrieves the headers of article(s). See getarticle for details.
$conn->getbody( [MESSAGE-SPEC] )
Retrieves the body of article(s). See getarticle for details.
$conn->error
Returns the last error message.
$conn->message
Returns the last message returned by the server.

Message Specification

Several methods accept a MESSAGE-SPEC argument. This can be:

  • A single article number (e.g., 1234).
  • A range of article numbers (e.g., 1234-5678).
  • A reference to an array of article numbers (e.g., [1234, 5678, 9012]).

If a range is specified, the start and end numbers are inclusive.

NOTE

For compatibility reasons only with earlier versions of Net::NNTP a message spec can be passed as a list of two numbers, this is deprecated and a reference to the list should now be passed.

$pattern
The "NNTP" protocol uses the "WILDMAT" format for patterns. The WILDMAT format was first developed by Rich Salz based on the format used in the UNIX "find" command to articulate file names. It was developed to provide a uniform mechanism for matching patterns in the same manner that the UNIX shell matches filenames.

Patterns are implicitly anchored at the beginning and end of each string when testing for a match.

There are five pattern matching operations other than a strict one-to-one match between the pattern and the source to be checked for a match.

The first is an asterisk "*" to match any sequence of zero or more characters.

The second is a question mark "?" to match any single character. The third specifies a specific set of characters.

The set is specified as a list of characters, or as a range of characters where the beginning and end of the range are separated by a minus (or dash) character, or as any combination of lists and ranges. The dash can also be included in the set as a character it if is the beginning or end of the set. This set is enclosed in square brackets. The close square bracket "]" may be used in a set if it is the first character in the set.

The fourth operation is the same as the logical not of the third operation and is specified the same way as the third with the addition of a caret character "^" at the beginning of the test string just inside the open square bracket.

The final operation uses the backslash character to invalidate the special meaning of an open square bracket "[", the asterisk, backslash or the question mark. Two backslashes in sequence will result in the evaluation of the backslash as a character with no special meaning.

Examples
"[^]-]"
matches any single character other than a close square bracket or a minus sign/dash.
*bdc
matches any string that ends with the string "bdc" including the string "bdc" (without quotes).
"[0-9a-zA-Z]"
matches any single printable alphanumeric ASCII character.
"a??d"
matches any four character string which begins with a and ends with d.
