Net__LDAP__LDIF(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::LDIF(3) توثيق مساهمات Perl Net::LDAP::LDIF(3)

الاسم

Net::LDAP::LDIF - قراءة وكتابة ملفات LDIF

ملخص

use Net::LDAP::LDIF;
$ldif = Net::LDAP::LDIF->new( "file.ldif", "r", onerror => 'undef' );
while ( not $ldif->eof ( ) ) {
  $entry = $ldif->read_entry ( );
  if ( $ldif->error ( ) ) {
    print "Error msg: ", $ldif->error ( ), "\n";
    print "Error lines:\n", $ldif->error_lines ( ), "\n";
  } else {
    # do stuff
  }
}
$ldif->done ( );

الوصف

يوفر Net::LDAP::LDIF طريقة لتحويل بين كائنات "Net::LDAP::Entry" وإدخالات LDAP ممثلة بتنسيق LDIF. يتم دعم القراءة والكتابة، ويمكنهما معالجة إدخالات فردية أو قوائم الإدخالات.

عند قراءة ملف LDIF في الذاكرة باستخدام Perl بشكل طبيعي، يجب الانتباه إلى الاستخدام العالي المحتمل للذاكرة عند تحميل ملف LDIF دفعة واحدة.

ميزات خاصة

بشكل افتراضي، يدعم Net::LDAP::LDIF قراءة قيم السمات من عناوين URL من نوع "file://".

عند تثبيت وحدة LWP من Gisle Aas، يستخدم Net::LDAP::LDIF هذه الوحدة لدعم قراءة البيانات أيضًا من عناوين URL من أنواع تدعمها هذه الوحدات؛ أبرزها "http://"، "https://" و "ftp://". يتم الكشف عن هذه الميزة الموسعة ديناميكيًا في وقت التشغيل.

منشئ

new ( FILE [[, MODE ], OPTIONS ] )
افتح الملف بالوضع المحدد.
encode => 'none' | 'canonical' | 'base64'
بعض قيم DN في LDIF لا يمكن كتابتها بشكل حرفي ويجب ترميزها بطريقة ما:
'none'
الوضع الافتراضي.
'canonical'
راجع "canonical_dn" في Net::LDAP::Util.
'base64'
استخدم base64.
onerror => 'die' | 'warn' | 'undef'
ماذا يحدث عند اكتشاف خطأ؟
'die'
سيتعطل Net::LDAP::LDIF برسالة مناسبة.
'warn'
سيحذر Net::LDAP::LDIF برسالة مناسبة.
'undef'
إذا كان المعامل -w قيد الاستخدام، سيحذر Net::LDAP::LDIF برسالة مناسبة. ستعيد الطريقة المسماة 'undef'.
ملاحظة: هذه القيمة هي السلسلة 'undef'، وليس القيمة 'undef'.
change => 1
اكتب تغييرات الإدخال في ملف LDIF بدلاً من الإدخالات نفسها. أي، اكتب عمليات LDAP على الإدخالات في الملف بدلاً من محتوياتها.
lowercase => 1
حوّل أسماء السمات إلى أحرف صغيرة عند الكتابة.
sort => 1
رتّب أسماء السمات عند كتابة الإدخالات وفقًا للقاعدة: أولاً سمات فئة الكائن، ثم الباقي مرتبة أبجديًا.
version => '1'
اضبط رقم إصدار LDIF للكتابة في الملف الناتج. وفقًا لـ RFC 2849، فإن القيمة القانونية الوحيدة الحالية لهذا الخيار هي 1.
إذا تم تعيين هذا الخيار، سيحاول Net::LDAP::LDIF الالتزام بمعيار LDIF الخاص بـ RFC 2489 بشكل أكثر صرامة في بعض الأماكن.
القيمة الافتراضية هي undef، مما يشير إلى أنه لن يتم كتابة معلومات الإصدار في ملف LDIF.
wrap => 78
عدد الأعمدة التي سيحدث عندها التفاف للأسطر في المخرجات. القيمة الافتراضية هي 78. إذا تم تعيينها إلى 40 أو أقل، يتم تعطيل التفاف الأسطر.
raw => REGEX
استخدم REGEX لتمييز أسماء السمات التي تعتبر ثنائية عند القراءة.
إذا تم توفير هذا الخيار، فسيقوم Net::LDAP بتحويل قيم السمات التي لا تتطابق مع هذا REGEX إلى سلاسل UTF-8 نصية في Perl، مما يسمح لعمليات Perl (مطابقة النمط، إلخ) بالعمل كما هو متوقع حتى مع الأحرف الدولية في السلاسل.
إذا لم يتم توفير هذا الخيار، يتم التعامل مع قيم السمات كسلاسل بايت.
مثال: raw => qr/(?i:^jpegPhoto|;binary)/

طرق

read_entry ( )
اقرأ إدخالًا من الملف وأعيده ككائن "Net::LDAP::Entry".
في الوضع القياسي، يتم إرجاع كائن "Net::LDAP::Entry" وحده، بينما في وضع القائمة، يتم إرجاع قائمة بكائن "Net::LDAP::Entry" كعنصر أول يليه جميع كائنات "Net::LDAP::Control" التي كانت جزءًا من إدخال LDIF. راجع RFC 2849 لمزيد من التفاصيل.
eof ( )
يعيد true عند الوصول إلى نهاية الملف.
write_entry ( ENTRY [, OPTIONS ], ... )
اكتب إدخالات في ملف LDIF.
الوسائط المقبولة هي قائمة بالإدخالات، تتخللها اختياريًا خيارات خاصة بالإدخال السابق.
لكل إدخال، OPTIONS هي قائمة بأزواج مفتاح-قيمة، والتي تتعرف على:
control => CONTROL
control => [ CONTROL, ... ]
راجع "CONTROLS" في Net::LDAP.
write_version ( )
إذا كان الكائن لديه إصدار محدد، تسمح هذه الطريقة بكتابة الإصدار بشكل صريح قبل كتابة إدخال. إذا لم يتم استدعاؤها صراحةً، فسيتم استدعاؤها تلقائيًا عند كتابة الإدخال الأول.
version ( [ VERSION ] )
إذا لم يتم تحديد وسيط، فإنها تعيد إصدار ملف LDIF أو undef إذا لم يتم تعيين أي شيء. إذا تم تحديد وسيط، فإنها تضبط إصدار LDIF إلى VERSION. وفقًا لـ RFC 2849، فإن القيمة الصالحة الوحيدة لـ VERSION هي 1.
إذا تم استدعاؤها بدون وسائط، فإنها تعيد إصدار ملف LDIF أو undef إذا لم يتم تعيين أي شيء. إذا تم استدعاؤها مع وسيط، فإنها تضبط إصدار LDIF إلى VERSION. وفقًا لـ RFC 2849، فإن القيمة الصالحة الوحيدة لـ VERSION هي 1.
إذا لم يتم استدعاؤها صراحةً، فسيتم استدعاؤها تلقائيًا عند كتابة الإدخال الأول.
handle ( )
يعيد مقبض الملف الذي يقرأه أو يكتبه كائن "Net::LDAP::LDIF".
done ( )
هذه الطريقة signature

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

nals أن كائن LDIF لم يعد مطلوبًا. إذا تم فتح ملف تلقائيًا عند إنشاء الكائن، فسيتم إغلاقه. يتم استدعاء هذه الدالة تلقائيًا عبر DESTROY عندما يخرج الكائن من النطاق.
error ( )
يعيد رسالة الخطأ إذا تم العثور على خطأ.
error_lines ( )
يعيد الأسطر التي أدت إلى الخطأ.
current_entry ( )
يعيد كائن "Net::LDAP::Entry" الحالي.
current_lines ( )
يعيد الأسطر التي أنتجت كائن "Net::LDAP::Entry" الحالي.
next_lines ( )
يعيد الأسطر التي ستنتج كائن "Net::LDAP::Entry" التالي.
