Net__LDAP__Control__EntryChange(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Control::EntryChange(3) وثائق Perl المقدمة من المستخدم Net::LDAP::Control::EntryChange(3)

الاسم

Net::LDAP::Control::EntryChange - كائن تحكم إخطار تغيير الإدخال LDAPv3

الملخص

use Net::LDAP;
use Net::LDAP::Control::PersistentSearch;
use Net::LDAP::Constant qw(LDAP_CONTROL_ENTRYCHANGE);
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
$persist = Net::LDAP::Control::PersistentSearch->new( changeTypes => 15,
                                                      changesOnly => 1,
                                                      returnECs => 1 );
$srch = $ldap->search( base     => "cn=People,dc=mydomain,dc=eg",
                       filter   => "(objectClass=person)",
                       callback => \&process_entry, # استدعاء لكل إدخال
                       control  => [ $persist ] );
die "error: ",$srch->code(),": ",$srch->error()  if ($srch->code());
sub process_entry {
  my $message = shift;
  my $entry = shift;
  my ($control) = $message->control(LDAP_CONTROL_ENTRYCHANGE);
  print $control->changeType()."\t".$entry->dn()."\n";
}

الوصف

"Net::LDAP::Control::EntryChange" يوفر واجهة لإنشاء ومعالجة الكائنات التي تمثل تحكم "EntryChangeNotification" كما هو موصوف في draft-smith-psearch-ldap-03.txt.

وسائط الباني

بالإضافة إلى وسائط الباني الموصوفة في Net::LDAP::Control يتم توفير ما يلي.

changeType
قيمة عددية تخبر بنوع عملية LDAP التي خضع لها الإدخال. إنها واحدة من القيم التالية (التي تمثل عمليات LDAP المشار إليها بجانبها):
1 = add
2 = delete
4 = modify
8 = modDN
previousDN
عندما يكون changeType 8 (لـ modDN) تحدد هذه الوسيطة DN الإدخال قبل عملية modDN. في جميع الحالات الأخرى هذه القيمة غير معرفة.
changeNumber
هذا هو رقم التغيير وفقًا لـ <draft-good-ldap-changelog-03.txt> الذي تم تعيينه بواسطة خادم للتغيير. إذا كان الخادم يدعم سجل تغييرات LDAP فيجب أن يتضمن هذا الحقل.

عادة لا تحتاج إلى إنشاء تحكم "Net::LDAP::Control::EntryChange" بنفسك لأنه يتم توفيره بواسطة الخادم استجابةً لخيار مع تحكم "Net::LDAP::Control::PersistentSearch".

الأساليب

كما هو الحال مع Net::LDAP::Control فإن كل وسيطة باني موصوفة أعلاه متاحة أيضًا كأسلوب على الكائن الذي سيعيد القيمة الحالية للسمة إذا تم استدعاؤه بدون وسيطة، ويقوم بتعيين قيمة جديدة للسمة إذا تم استدعاؤه بوسيطة.
