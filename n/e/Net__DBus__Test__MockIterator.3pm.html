NOMBRE

Net::DBus::Test::MockIterator - Un iterador de prueba para la clase Net::DBus::Binding::Iterator

RESUMEN

  use Net::DBus::Test::MockIterator;

  my $mock_iter = Net::DBus::Test::MockIterator->new();
  $mock_iter->set_elements(1, 'hello', 3.14, [ 'a', 'b' ]);
  
  while (my $elem = $mock_iter->get_next()) {
      print Dumper($elem);
  }

DESCRIPCIÓN

Este módulo proporciona un iterador de prueba que implementa la interfaz Net::DBus::Binding::Iterator. Se utiliza para probar código que consume iteradores de Net::DBus::Binding::Iterator sin necesidad de un objeto Net::DBus::Binding::Message real.

Los elementos se pueden establecer en el iterador utilizando el método set_elements.

MÉTODOS

$iter->get_element_type
Si el iterador apunta a un array, devuelve el código de tipo de los elementos del array. El código devuelto corresponderá a una de las constantes "Net::DBus::Binding::Message::TYPE_*"

BUGS

No reproduce completamente la API de Net::DBus::Binding::Iterator, pero lo suficiente para que las bindings de nivel superior funcionen en un escenario de prueba.
