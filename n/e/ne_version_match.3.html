ne_version_match(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_VERSION_MATCH(3) مرجع واجهة برمجة تطبيقات neon NE_VERSION_MATCH(3)

الاسم

ne_version_match, ne_version_string - إصدار المكتبة

ملخص

#include <ne_utils.h>

int ne_version_match(int major, int minor);

const char *ne_version_string(void);

الوصف

تقوم الدالة ne_version_match بإرجاع قيمة غير صفرية إذا كان إصدار المكتبة ليس من الإصدار الرئيسي major، أو كان الإصدار الثانوي أقل من minor. بالنسبة لإصدارات neon 0.x، يُفترض أن كل إصدار ثانوي غير متوافق مع كل إصدار ثانوي آخر.

تقوم الدالة ne_version_string بإرجاع سلسلة نصية تعطي إصدار المكتبة.

أمثلة

للمتطلبات neon 1.x، الإصدار 1.2 أو أحدث:

if (ne_version_match(1, 2)) {
    printf("Library version out of date: 1.2 required, found %s.",
           ne_version_string());
    exit(1);
}
