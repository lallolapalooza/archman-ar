NAME

Net::LDAP::Entry - LDAP entry object

SYNOPSIS

  use Net::LDAP;
  use Net::LDAP::Entry;

  my $entry = Net::LDAP::Entry->new(
    dn => 'cn=John Doe,dc=example,dc=com',
    attributes => [
      cn       => 'John Doe',
      mail     => 'jdoe@example.com',
      telephoneNumber => '+1 555 555 5555',
    ]
  );

  # Add attributes
  $entry->add(
    description => 'A user',
    uid         => 'jdoe',
  );

  # Replace attributes
  $entry->replace(
    mail => 'john.doe@example.com',
  );

  # Delete attributes
  $entry->delete('telephoneNumber');

  # Get attributes
  my $uid = $entry->get_value('uid');
  my @mails = $entry->get_value('mail');

  # Update the directory server
  my $result = $entry->update($ldap);

  # Add the entry to the directory server
  my $result = $entry->add($ldap);

DESCRIPTION

An object of this class represents an LDAP entry. It holds the distinguished name (DN) of the entry and its attributes. The attributes are stored as a hash reference where the keys are the attribute names and the values are arrays of attribute values.

This class is mostly used internally by the Net::LDAP module, but it is exported so that you may create your own Net::LDAP::Entry objects if you wish.

CONSTRUCTORS

new ( DN [, OPTIONS ] )
Creates a new Net::LDAP::Entry object.

The DN argument is the distinguished name of the entry. It is optional.

The OPTIONS argument is a hash reference of options. The following options are supported:

attributes => ARRAYREF | HASHREF
An array reference or hash reference of attributes to be added to the entry when it is created. See "add" for the format of the attributes.
dn => STRING
The distinguished name of the entry. This is equivalent to passing the DN as the first argument to "new".

METHODS

add ( ATTR => VALUE, ... )
Adds one or more attributes to the entry. If an attribute already exists, the new values will be appended to the existing values.

The attributes are specified as a list of key-value pairs, where the key is the attribute name and the value is the attribute value. If an attribute has multiple values, they can be provided as an array reference.

  $entry->add(
    uid  => 'jdoe',
    mail => [ 'jdoe@example.com', 'john.doe@example.com' ],
  );

NOTE: these changes are local to the client and will not appear on the directory server until the "update" method is called.

dn ( [ DN ] )
Returns the distinguished name of the entry. If an optional DN argument is provided, it will be used to set the DN of the entry.

NOTE: changing the DN of an entry is a complex operation and should only be done when the entry is being added or modified on the directory server using the "update" method with a "changetype" of "moddn" or "modrdn".

attributes ( [ ATTR => VALUE, ... ] )
Returns a hash reference of all the attributes in the entry. If arguments are provided, they are treated as attributes to be added or replaced.

If the attribute already exists, the new values will replace the existing ones. If you want to append values to an existing attribute, use the "add" method.

See also "add" and "replace".

NOTE: these changes are local to the client and will not appear on the directory server until the "update" method is called.

delete ( ATTR, ... )
Deletes one or more attributes from the entry.

NOTE: these changes are local to the client and will not appear on the directory server until the "update" method is called.

get_value ( ATTR [, OPTIONS ] )
Returns the value(s) for the given attribute name.
alloptions => 1
The result will be a hash reference. The keys of the hash will be the attribute names (including any type qualifiers) and the hash value will be the values for those attributes. For example if an entry had: 
name: Graham Barr
name;en-us: Bob

Then a get for attribute "name" with alloptions set to a true value

$ref = $entry->get_value ( 'name', alloptions => 1 );

will return a hash reference that would be like

{
  ''       => [ 'Graham Barr' ],
  ';en-us' => [ 'Bob' ]
}

If alloptions is not set or is set to false only the attribute values for the exactly matching attribute name are returned.

nooptions => 1
Instead of only returning the values of the exactly matching attribute name, get the attribute values of all attributes with the base name given. I.e. in the example above, calling 
$ref = $entry->get_value ( 'name', nooptions => 1 );

will yield

[ 'Graham Barr', 'Bob' ]

The name of this option has been chosen for consistency with the equally named option in the attributes method.

asref => 1
The result will be a reference to an array containing all the values for the attribute, or "undef" if the attribute does not exist. 
$scalar = $entry->get_value ( 'name' );

$scalar will be the first value for the "name" attribute, or "undef" if the entry does not contain a "name" attribute.

$ref = $entry->get_value ( 'name', asref => 1 );

$ref will be a reference to an array, which will have all the values for the "name" attribute. If the entry does not have an attribute called "name" then $ref will be "undef".

If no options are specified, the first value of the attribute is returned as a scalar, or "undef" if the attribute does not exist.

alloptions => 1
The result will be a hash reference. The keys of the hash will be the options and the hash value will be the values for those attributes. For example if an entry had: 
name: Graham Barr
name;en-us: Bob

Then a get for attribute "name" with alloptions set to a true value

$ref = $entry->get_value ( 'name', alloptions => 1 );

will return a hash reference that would be like

{
  ''       => [ 'Graham Barr' ],
  ';en-us' => [ 'Bob' ]
}

If alloptions is not set or is set to false only the attribute values for the exactly matching name are returned.

nooptions => 1
Instead of only returning the values of the exactly matching attribute name, get the attribute values of all attributes with the base name given. I.e. in the example above, calling 
@array = $entry->get_value ( 'name', nooptions => 1 );

will yield

( 'Graham Barr', 'Bob' )

The name of this option has neen chosen for consistency with the equally named option in the attributes method.

asref => 1
The result will be a reference to an array containing all the values for the attribute, or "undef" if the attribute does not exist. 
$scalar = $entry->get_value ( 'name' );

$scalar will be the first value for the "name" attribute, or "undef" if the entry does not contain a "name" attribute.

$ref = $entry->get_value ( 'name', asref => 1 );

$ref will be a reference to an array, which will have all the values for the "name" attribute. If the entry does not have an attribute called "name" then $ref will be "undef".

NOTE: In the interest of performance the array references returned by "get_value" may be references to structures held inside the entry object. These values and their contents should NOT be modified directly.

replace ( ATTR => VALUE, ... )
Similar to "add", except that the values given will replace any values that already exist for the given attributes.

NOTE: these changes are local to the client and will not appear on the directory server until the "update" method is called.

update ( CLIENT [, OPTIONS ] )
Update the directory server with any changes that have been made locally to the attributes of this entry. This means any calls that have been made to add, replace or delete since the last call to changetype or update was made.

This method can also be used to modify the DN of the entry on the server, by specifying moddn or modrdn as the changetype, and setting the entry attributes newrdn, deleteoldrdn, and (optionally) newsuperior.

"CLIENT" is a "Net::LDAP" object where the update will be sent to.

"OPTIONS" may be options to the "Net::LDAP" actions on CLIENT corresponding to the entry's changetype.

The result will be an object of type Net::LDAP::Message as returned by the add, modify or delete method called on CLIENT.

Alternatively "CLIENT" can also be a "Net::LDAP::LDIF" object, that must be an LDIF file opened for writing.

In this case, the entry, together with any "OPTIONS" is passed as arguments to the "write_entry" method of the "CLIENT" object.

Here too, the result is an object class "Net::LDAP::Message". On error, the error code is "LDAP_OTHER" with the LDIF error message in the error text.
