NAME

NetAddr::IP - Manages IPv4 and IPv6 addresses and subnets

SYNOPSIS

use NetAddr::IP qw(
      Compact
      Coalesce
      Zeros
      Ones
      V4mask
      V4net
      netlimit
      :aton           DEPRECATED
      :lower
      :upper
      :old_storable
      :old_nth
      :rfc3021
      :nofqdn
);
NOTE: NetAddr::IP::Util has a full complement of network address
      utilities to convert back and forth between binary and text.
      inet_aton, inet_ntoa, ipv6_aton, ipv6_ntoa 
      ipv6_n2x, ipv6_n2d inet_any2d, inet_n2dx, 
      inet_n2ad, inetanyto6, ipv6to4

See NetAddr::IP::Util

my $ip = new NetAddr::IP '127.0.0.1';
       or if you prefer
my $ip = NetAddr::IP->new('127.0.0.1);
      or from a packed IPv4 address
my $ip = new_from_aton NetAddr::IP (inet_aton('127.0.0.1'));
      or from an octal filtered IPv4 address
my $ip = new_no NetAddr::IP '127.012.0.0';
print "The address is ", $ip->addr, " with mask ", $ip->mask, "\n" ;
if ($ip->within(new NetAddr::IP "127.0.0.0", "255.0.0.0")) {
    print "Is a loopback address\n";
}
                              # This prints 127.0.0.1/32
print "You can also say $ip...\n";

* The following four functions return ipV6 representations of:

::                                       = Zeros();
FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF:FFFF  = Ones();
FFFF:FFFF:FFFF:FFFF:FFFF:FFFF::          = V4mask();
::FFFF:FFFF                              = V4net();
Will also return an ipV4 or ipV6 representation of a
resolvable Fully Qualified Domanin Name (FQDN).

###### DEPRECATED, will be remove in version 5 ############

* To accept addresses in the format as returned by
inet_aton, invoke the module as:
use NetAddr::IP qw(:aton);

###### USE new_from_aton instead ##########################

* To enable usage of legacy data files containing NetAddr::IP objects stored using the Storable module.

use NetAddr::IP qw(:old_storable);

* To compact many smaller subnets (see: "$me->compact($addr1,$addr2,...)"

@compacted_object_list = Compact(@object_list)

* Return a reference to list of "NetAddr::IP" subnets of $masklen mask length, when $number or more addresses from @list_of_subnets are found to be contained in said subnet.

$arrayref = Coalesce($masklen, $number, @list_of_subnets)

* By default NetAddr::IP functions and methods return string IPv6 addresses in uppercase. To change that to lowercase:

NOTE: the AUGUST 2010 RFC5952 states:

4.3. Lowercase
  The characters "a", "b", "c", "d", "e", and "f" in an IPv6
  address MUST be represented in lowercase.

It is recommended that all NEW applications using NetAddr::IP be invoked as shown on the next line.

use NetAddr::IP qw(:lower);

* To ensure the current IPv6 string case behavior even if the default changes:

use NetAddr::IP qw(:upper);

* To set a limit on the size of nets processed or returned by NetAddr::IP.

Set the maximum number of nets beyond which NetAddr::IP will return an error as a power of 2 (default 16 or 65536 nets). Each 2**16 consumes approximately 4 megs of memory. A 2**20 consumes 64 megs of memory, A 2**24 consumes 1 gigabyte of memory.

use NetAddr::IP qw(netlimit);
netlimit 20;

The maximum netlimit allowed is 2**24. Attempts to set limits below the default of 16 or above the maximum of 24 are ignored.

Returns true on success, otherwise "undef".

INSTALLATION

Un-tar the distribution in an appropriate directory and type:

perl Makefile.PL
make
make test
make install

NetAddr::IP depends on NetAddr::IP::Util which installs by default with its primary functions compiled using Perl's XS extensions to build a C library. If you do not have a C complier available or would like the slower Pure Perl version for some other reason, then type:

perl Makefile.PL -noxs
make
make test
make install

DESCRIPTION

This module provides an object-oriented abstraction on top of IP addresses or IP subnets that allows for easy manipulations. Version 4.xx of NetAddr::IP will work with older versions of Perl and is compatible with Math::BigInt.

The internal representation of all IP objects is in 128 bit IPv6 notation. IPv4 and IPv6 objects may be freely mixed.

Overloaded Operators

Many operators have been overloaded, as described below:

Assignment ("=")
Has been optimized to copy one NetAddr::IP object to another very quickly.
"->copy()"
The assignment ("=") operation is only put in to operation when the copied object is further mutated by another overloaded operation. See overload SPECIAL SYMBOLS FOR "use overload" for details.

"->copy()" actually creates a new object when called.

Stringification
An object can be used just as a string. For instance, the following code 
my $ip = new NetAddr::IP '192.168.1.123';
print "$ip\n";

Will print the string 192.168.1.123/32.

Equality
You can test for equality with either "eq" or "==". "eq" allows comparison with arbitrary strings as well as NetAddr::IP objects. The following example: 
if (NetAddr::IP->new('127.0.0.1','255.0.0.0') eq '127.0.0.1/8')
   { print "Yes\n"; }

will print out "Yes".

Comparison with "==" requires both operands to be NetAddr::IP objects.

In both cases, a true value is returned if the CIDR representation of the operands is equal.

Comparison via >, <, >=, <=, <=> and "cmp"
Internally, all network objects are represented in 128 bit format. The numeric representation of the network is compared through the corresponding operation. Comparisons are tried first on the address portion of the object and if that is equal then the NUMERIC cidr portion of the masks are compared. This leads to the counterintuitive result that 
/24 > /16

Comparison should not be done on netaddr objects with different CIDR as this may produce indeterminate - unexpected results, rather the determination of which netblock is larger or smaller should be done by comparing

$ip1->masklen <=> $ip2->masklen
Addition of a constant ("+")
Add a 32 bit signed constant to the address part of a NetAddr object. This operation changes the address part to point so many hosts above the current objects start address. For instance, this code: 
print NetAddr::IP->new('127.0.0.1/8') + 5;

will output 127.0.0.6/8. The address will wrap around at the broadcast back to the network address. This code:

print NetAddr::IP->new('10.0.0.1/24') + 255;
outputs 10.0.0.0/24.

Returns the the unchanged object when the constant is missing or out of range.

2147483647 <= constant >= -2147483648
Subtraction of a constant ("-")
The complement of the addition of a constant.
Difference ("-")
Returns the difference between the address parts of two NetAddr::IP objects address parts as a 32 bit signed number.

Returns undef if the difference is out of range.

الطرق

"->new([$addr, [ $mask|IPv6 ]])"
"->new6([$addr, [ $mask]])"
"->new_no([$addr, [ $mask]])"
"->new_from_aton($netaddr)"
new_cis و new_cis6 هي طرق مهملة
"->new_cis("$addr $mask)"
"->new_cis6("$addr $mask)"
تقوم الطريقتان الأوليان بإنشاء عنوان جديد مع العنوان المقدم في $addr وقناع شبكة اختياري $mask، والذي يمكن حذفه للحصول على قناع شبكة /32 أو /128 لعناوين IPv4 / IPv6 على التوالي.

الطريقة الثالثة "new_no" مخصصة حصريًا لعناوين IPv4 وتقوم بتصفية سلاسل quad الرباعية غير المهيأة بشكل صحيح للصفرات البادئة التي قد يتم تفسيرها عادةً كتنسيق ثماني بواسطة NetAddr وفقًا لمواصفات inet_aton.

تأخذ new_from_aton عنوان IPv4 مجمع وتفترض قناع /32. تستبدل هذه الوظيفة وظيفة :aton المهملة وهي معطلة بشكل أساسي.

تختلف الطريقتان الأخيرتان new_cis و new_cis6 عن new و new6 فقط في أنهما تقبلان تدوين Cisco الشائع للعناوين/الأقنعة باستخدام المسافة كفاصل بدلاً من الشرطة المائلة (/)

تم إهمال هذه الطرق لأن الوظيفة مدرجة الآن في طرق "new" الأخرى

على سبيل المثال:  ->new_cis('1.2.3.0 24')
      أو
      ->new_cis6('::1.2.3.0 120')

"->new6" و "->new_cis6" تميزان العنوان على أنه في مساحة عنوان ipV6 حتى لو أشار التنسيق إلى خلاف ذلك.

على سبيل المثال:  ->new6('1.2.3.4') سيؤدي إلى ::102:304
العناوين المقدمة إلى ->new بتدوين ipV6 ستبقى بتدوين ipV6 بشكل دائم. على سبيل المثال:
      ->new('::1.2.3.4') سيؤدي إلى ::102:304
بينما new('1.2.3.4') ستتم طباعتها كـ 1.2.3.4

اسم نطاق مؤهل بالكامل (Fully Qualified Domain Name) يعيد عنوان IPv4 أو عنوان IPv6، مدمجين بهذا الترتيب. قد يتم تعطيل هذه الميزة التي لم تكن موثقة سابقًا باستخدام:

use NetAddr::IP::Lite ':nofqdn';

إذا تم استدعاؤها بدون وسائط، فسيتم افتراض 'default'.

إذا تم استدعاؤها بسلسلة فارغة كوسيط، فإنها تعيد 'undef'.

"->broadcast()"
تعيد كائنًا جديدًا يشير إلى عنوان البث لشبكة فرعية معينة. يحتوي عنوان البث على جميع الآحاد في جميع مواضع البت التي تحتوي فيها قناع الشبكة على بتات صفرية. يستخدم هذا عادةً لعنونة جميع المضيفين في شبكة فرعية معينة.
"->network()"
تعيد كائنًا جديدًا يشير إلى عنوان الشبكة لشبكة فرعية معينة. يحتوي عنوان الشبكة على جميع بتات الصفر حيث تكون بتات قناع الشبكة صفرية. يستخدم هذا عادةً للإشارة إلى شبكة فرعية.
"->addr()"
تعيد قيمة قياسية مع جزء العنوان للكائن كسلسلة نصية IPv4 أو IPv6 حسب الاقتضاء. هذا مفيد للطباعة أو لتمرير جزء العنوان لكائن NetAddr::IP إلى مكونات أخرى تتوقع عنوان IP. إذا كان الكائن عنوان IPv6 أو تم إنشاؤه باستخدام ->new6($ip) فسيتم الإبلاغ عنه بتنسيق سداسي عشري لـ IPv6 بخلاف ذلك سيتم الإبلاغ عنه بتنسيق dot quad فقط إذا كان موجودًا في مساحة عنوان IPv4.
"->mask()"
تعيد قيمة قياسية مع القناع كسلسلة نصية IPv4 أو IPv6 كما هو موضح أعلاه.
"->masklen()"
تعيد قيمة قياسية لعدد البتات (1) في القناع.
"->bits()"
تعيد عرض العنوان بالبتات. عادةً 32 لـ v4 و 128 لـ v6.
"->version()"
تعيد إصدار العنوان أو الشبكة الفرعية. حاليًا يمكن أن يكون هذا إما 4 أو 6.
"->cidr()"
تعيد قيمة قياسية مع العنوان والقناع بتدوين CIDR. كائن NetAddr::IP *يتحول إلى قيمة نصية* إلى نتيجة هذه الوظيفة. (انظر التعليقات حول ->new6() و ->addr() لأشكال الإخراج)
"->aton()"
تعيد جزء العنوان لكائن NetAddr::IP بنفس التنسيق مثل دالة inet_aton() أو "ipv6_aton" على التوالي. إذا تم إنشاء الكائن باستخدام ->new6($ip)، فسيكون العنوان المعاد دائمًا بتنسيق ipV6، حتى للعناوين الموجودة في مساحة عنوان ipV4.
"->range()"
تعيد قيمة قياسية مع عنوان الأساس وعنوان البث مفصولين بشرطة ومسافات. هذا يسمى تدوين النطاق.
"->prefix()"
تعيد قيمة قياسية مع العنوان والقناع بتمثيل بادئة ipV4. هذا مفيد لبعض البرامج التي تتوقع إدخالها بهذا التنسيق. ستتضمن هذه الطريقة عنوان البث في الترميز.
"->nprefix()"
تمامًا مثل "->prefix()"، ولكنه لا يتضمن عنوان البث.
"->numeric()"
عند استدعائها في سياق قياسي، ستعيد تمثيلًا رقميًا لجزء العنوان لعنوان IP. عند استدعائها في سياق مصفوفة، تعيد قائمة من عنصرين. العنصر الأول كما هو موضح، والعنصر الثاني هو التمثيل الرقمي لقناع الشبكة.

هذه الطريقة ضرورية لتسلسل تمثيل الشبكة الفرعية.

"->bigint()"
عند استدعائها في سياق قياسي، ستعيد تمثيل Math::BigInt لجزء العنوان لعنوان IP. عند استدعائها في سياق مصفوفة، تعيد قائمة من عنصرين. العنصر الأول كما هو موضح، والعنصر الثاني هو تمثيل Math::BigInt لقناع الشبكة.
"->wildcard()"
عند استدعائها في سياق قياسي، تعيد البتات الوايلد كارد المقابلة للقناع، بتنسيق dotted-quad أو ipV6 حسب الاقتضاء.

عند استدعائها في سياق مصفوفة، تعيد مصفوفة من عنصرين. العنصر الأول هو جزء العنوان. العنصر الثاني هو ترجمة البتات الوايلد كارد للقناع.

"->short()"
تعيد جزء العنوان بتدوين قصير أو مضغوط. 
(على سبيل المثال، 127.0.0.1 يصبح 127.1).

يعمل مع كل من V4 و V6.

"->canon()"
تعيد جزء العنوان بتدوين قياسي كسلسلة نصية. بالنسبة لـ ipV4، يكون هذا هو dot quad، وهو نفس القيمة المعادة من "->addr()". بالنسبة لـ ipV6، يكون وفقًا لـ RFC5952، وهو نفس القيمة بالحروف الصغيرة المعادة من "->short()".
"->full()"
تعيد جزء العنوان بتدوين كامل لـ ipV4 و ipV6 على التوالي. 
على سبيل المثال، لـ ipV4
  0000:0000:0000:0000:0000:0000:127.0.0.1
     لـ ipV6
  0000:0000:0000:0000:0000:0000:0000:0000

لإجبار عناوين ipV4 على تنسيق ipV6 كامل استخدم:

"->full6()"
تعيد جزء العنوان بتدوين ipV6 كامل
"->full6m()"
تعيد جزء القناع بتدوين ipV6 كامل
"$me->contains($other)"
تعيد true عندما يحتوي $me بالكامل على $other. تعيد false بخلاف ذلك، وتعيد "undef" إذا لم يكن $me و $other كلاهما كائنات "NetAddr::IP".
"$me->within($other)"
مكمل "->contains()". تعيد true عندما يكون $me ضمن $other بالكامل.

لاحظ أن $me و $other يجب أن يكونا كائنات "NetAddr::IP".

C->is_rfc1918()>
تعيد true عندما يكون $me عنوان RFC 1918.
10.0.0.0      -   10.255.255.255  (بادئة 10/8)
172.16.0.0    -   172.31.255.255  (بادئة 172.16/12)
192.168.0.0   -   192.168.255.255 (بادئة 192.168/16)
"->is_local()"
تُرجع true عندما يكون $me عنوان شبكة محلية. 
      مثال:    ipV4    127.0.0.0 - 127.255.255.255
أو            ipV6    === ::1
"->splitref($bits,[اختياري $bits1,$bits2,...])"
تُرجع مرجعًا لقائمة كائنات، تمثل شبكات فرعية للـ "bits" القناع الذي تم إنتاجه عن طريق تقسيم الكائن الأصلي، والذي يظل دون تغيير. لاحظ أن $bits يجب أن يكون أطول من القناع الأصلي لكي يكون قابلاً للتقسيم.

->splitref تُرجع undef عندما C<bits> أو (قائمة bits)
  لن تتناسب مع الكائن الأصلي.
->splitref تُرجع undef إذا كان عنوان ipV4، ipV6، أو NetAddr
  القناع بتنسيق غير مناسب،

"->first()"
تُرجع كائنًا جديدًا يمثل أول عنوان IP قابل للاستخدام داخل الشبكة الفرعية (أي، أول عنوان مضيف).

تُرجع كائنًا جديدًا يمثل آخر عنوان IP قابل للاستخدام داخل الشبكة الفرعية (أي، أقل بواحد من عنوان البث).
"->nth($index)"
تُرجع كائنًا جديدًا يمثل عنوان IP القابل للاستخدام رقم *n* داخل الشبكة الفرعية (أي، عنوان المضيف رقم *n*). إذا لم يكن هناك عنوان متاح (على سبيل المثال، عندما تكون الشبكة صغيرة جدًا لـ $index مضيفين)، يتم إرجاع "undef".

تحذير:

سيقوم NetAddr::IP بحساب وإرجاع سلسلة رقمية لنطاقات الشبكات الكبيرة حتى 2**128. هذه القيم هي سلاسل نصية ويمكن لـ perl التعامل معها كأعداد صحيحة للحسابات الرقمية.

لا يتعامل Perl على منصات 32 بت إلا مع الأعداد الصحيحة حتى 2**32 وعلى منصات 64 بت حتى 2**64.

إذا كنت ترغب في معالجة السلاسل الرقمية التي تم إرجاعها بواسطة NetAddr::IP والتي تكون أكبر من 2**32 أو 2**64، على التوالي، يجب عليك تحميل وحدات إضافية مثل Math::BigInt أو bignum أو حزمة مشابهة للقيام بالحسابات الصحيحة.
