Net__DNS__RR__APL(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS::RR::APL(3) وثائق بيرل من مساهمة المستخدم Net::DNS::RR::APL(3)

الاسم

Net::DNS::RR::APL - سجل مورد DNS APL

الملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name IN APL aplist');

الوصف

سجل قائمة بادئات العناوين (APL) لنظام أسماء النطاقات (DNS).

الأساليب

الأساليب المتاحة هي تلك الموروثة من الفئة الأساسية مع إضافة الأساليب الخاصة بالنوع المحدد في هذه الحزمة.

يُثبط استخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية، وقد يؤدي ذلك إلى إنهاء البرنامج أو سلوك غير متوقع.

aplist

@aplist = $rr->aplist;

@aplist = $rr->aplist( '1:192.168.32.0/21', '!1:192.168.38.0/28' );

@aplist = $rr->aplist( '1:224.0.0.0/4', '2:FF00:0:0:0:0:0:0:0/8' );

@aplist = $rr->aplist(
                negate  => 1,
                family  => 1,
                address => '192.168.38.0',
                prefix  => 28,
                );

قائمة مرتبة، ربما فارغة، من عناصر بادئة العناوين. تُضاف العناصر الإضافية، إذا كانت موجودة، إلى القائمة الحالية دون تجميع البادئة أو إعادة ترتيبها.

Net::DNS::RR::APL::Item

كل عنصر في قائمة البادئات هو كائن Net::DNS::RR::APL::Item مرتبط بشكل لا ينفصل بسجل APL الذي أنشأه.

negate

$rr->negate(1);
if ( $rr->negate ) {
        ...
}

سمة منطقية تشير إلى أن البادئة هي استبعاد لنطاق عناوين.

family

$family = $rr->family;
$rr->family( $family );

محدد عائلة العناوين.

prefix

$prefix = $rr->prefix;
$rr->prefix( $prefix );

عدد البتات التي تشكل بادئة العنوان.

address

$address = $object->address;

جزء العنوان من عنصر قائمة البادئة.

string

$string = $object->string;

يعيد عنصر قائمة البادئة بالشكل المطلوب في ملفات المنطقة.
