ne_strparam(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_STRPARAM(3) مرجع واجهة برمجة تطبيقات neon NE_STRPARAM(3)

الاسم

ne_strparam - ترميز قيمة معلمة HTTP الموسعة

الملخص

#include <ne_string.h>

char *ne_strparam(const char *charset, const char *lang, const char *value);

الوصف

يمكن استخدام الدالة ne_strparam لترميز قيمة معلمة موسعة لرأس HTTP، كما هو محدد في RFC 5987. تأخذ الدالة كوسائط value المراد ترميزها، باستخدام مجموعة أحرف charset MIME معينة، وعلامة اللغة lang. يستخدم ترميز المعلمات الموسعة في مواصفات بروتوكول HTTP للسماح بتضمين الأحرف الخاصة بسهولة (مثل علامات الاقتباس، الفواصل، أو الأحرف غير ASCII) في قيم الرأس.

وفقًا لـ RFC 5987، يجب أن تكون الوسيطة charset إما "UTF-8" أو "IS0-8859-1"، ولكن قد تكون الوسيطة lang فارغة (NULL).

قيمة الإرجاع

القيمة المرجعة هي إما:

NULL

إذا كانت الوسيطة value "معلمة عادية" ولا تحتاج إلى ترميز موسع

غير NULL

ترميز القيمة المدخلة كمعلمة موسعة كسلسلة نصية مخصصة بنهاية فارغة، مخصصة باستخدام malloc

التاريخ

ne_strparam متاحة في neon 0.32.0 وما بعده.
