Net__XMPP__Message(3pm)

الحزمة: perl-net-xmpp

التراخيص: GPL, PerlArtistic

Net::XMPP::Message(3pm) وثائق Perl مقدمة من المستخدم Net::XMPP::Message(3pm)

الاسم

Net::XMPP::Message - وحدة رسائل XMPP

الملخص

Net::XMPP::Message هي وحدة مصاحبة لوحدة Net::XMPP.
توفر للمستخدم واجهة بسيطة لتعيين واسترداد جميع أجزاء رسالة XMPP.

الوصف

يتم تمرير كائن Net::XMPP::Message إلى الدالة الاستدعائية للرسالة.
أيضًا، الوسيط الأول للدوال الاستدعائية هو معرف الجلسة من XML::Stream.
هناك بعض الحالات التي قد ترغب فيها في هذه المعلومات، مثل إذا قمت بإنشاء
عميل يتصل بخادمين في وقت واحد، أو لكتابة خادم مصغر.
  use Net::XMPP;
  sub message {
    my ($sid,$Mess) = @_;
    .
    .
    .
  }
لديك الآن وصول إلى جميع وظائف الاسترداد المتاحة.
لإنشاء رسالة لإرسالها إلى الخادم:
  use Net::XMPP;
  $Mess = Net::XMPP::Message->new();
الآن يمكنك استدعاء وظائف الإنشاء أدناه لتعبئة الوسم
قبل إرسالها.

               فإنه يتم إعادة كائن Net::XMPP::JID ويمكنك

                 $fromJID = $Mess->GetFrom("jid");

            رسالة هي واحدة من أربعة أنواع:
              normal        رسالة عادية (الافتراضي إذا كان النوع فارغًا)
              chat          محادثة فردية
              groupchat     محادثة جماعية
              headline      عنوان رئيسي
              error         رسالة خطأ

               $subject = $Mess->GetSubject();

              $thread = $Mess->GetThread();
GetError() - يعيد سلسلة نصية مع بيانات الوسم <error/>.
             $error = $Mess->GetError();
GetErrorCode() - يعيد سلسلة نصية مع السمة code='' للوسم
                 <error/>.
                 $errCode = $Mess->GetErrorCode();
GetTimeStamp() - يعيد سلسلة نصية تمثل الوقت الذي تم فيه إنشاء
                 كائن الرسالة هذا (وربما استلامه)
                 لإرساله إلى العميل. إذا كان هناك وسم
                 jabber:x:delay، فسيتم استخدام هذا الوقت لإظهار
                 متى تم إرسال الرسالة.

وظائف الإنشاء

SetMessage(to=>string|JID,    - تعيين حقول متعددة في الوسم <message/>
           from=>string|JID,    في وقت واحد. هذا إجراء تراكمي
           type=>string,        وغطاء. إذا قمت بتعيين
           subject=>string,     السمة "to" مرتين، فإن الإعداد الثاني
           body=>string,        هو ما يتم استخدامه. إذا قمت بتعيين
           thread=>string,      الموضوع، ثم قمت بتعيين النص
           errorcode=>string,   فسيكون كلاهما في الوسم <message/>.
           error=>string)       لإعدادات صالحة اقرأ وظائف
                                Set المحددة أدناه.
                          $Mess->SetMessage(TO=>"bob\@jabber.org",
                                            Subject=>"Lunch",
                                            BoDy=>"Let's do lunch!");
                          $Mess->SetMessage(to=>"bob\@jabber.org",
                                            from=>"jabber.org",
                                            errorcode=>404,
                                            error=>"Not found");
SetTo(string) - يضبط السمة to=''. يمكنك تمرير
SetTo(JID)      سلسلة نصية أو كائن JID. يجب أن تكون JIDs صالحة
                وإلا فسيعيد الخادم رسالة خطأ.
                (أي، bob@jabber.org/Work)
                $Mess->SetTo("test\@jabber.org");
SetFrom(string) - يضبط السمة from=''. يمكنك تمرير
SetFrom(JID)      سلسلة نصية أو كائن JID. يجب أن تكون JIDs صالحة
                  وإلا فسيعيد الخادم رسالة خطأ. (أي،
                  jabber:bob@jabber.org/Work) هذه السمة ليست
                  مطلوبة إذا كنت تكتب عميلًا لأن الخادم
                  سيضع JID الخاص باتصالك فيه لمنع البريد العشوائي.
                  $Mess->SetFrom("me\@jabber.org");
SetType(string) - يضبط السمة type. الإعدادات الصالحة هي:
                    normal         رسالة عادية (افتراضي إذا كانت فارغة)
                    chat           رسالة بنمط محادثة فردية
                    groupchat      رسالة غرفة دردشة جماعية
                    headline       عنوان رئيسي، مؤشر أسهم، إلخ...
                    error          رسالة خطأ
                  $Mess->SetType("groupchat");
SetSubject(string) - يضبط موضوع الوسم <message/>.
                     $Mess->SetSubject("This is a test");
SetBody(string) - يضبط نص الوسم <message/>.
                  $Mess->SetBody("To be or not to be...");
SetThread(string) - يضبط سلسلة المحادثة للوسم <message/>. يجب عليك
                    نسخ هذا من الرسالة التي يتم الرد عليها للحفاظ على
                    سلسلة المحادثة.
                    $Mess->SetThread("AE912B3");
SetErrorCode(string) - يضبط رمز الخطأ للوسم <message/>.
                       $Mess->SetErrorCode(403);
SetError(string) - يضبط نص الخطأ للوسم <message/>.
                   $Mess->SetError("Permission Denied");
Reply(hash) - ينشئ كائن رسالة جديد ويملأ
              to/from، والموضوع عن طريق وضع "re: " في
              الواجهة. إذا حددت مفتاحًا بنفس طريقة
              SetMessage، فستقوم هذه القيم بتجاوز
              قيم الرد.
              $Reply = $Mess->Reply();
              $Reply = $Mess->Reply(type=>"chat");

Net::XMPP::Message(3pm) - man pages

NAME

Net::XMPP::Message - Class for handling XMPP messages

SYNOPSIS

    use Net::XMPP::Message;

    # Create a new message object
    my $message = Net::XMPP::Message->new(
        to      => 'recipient@example.com',
        from    => 'sender@example.com',
        body    => 'Hello, world!',
        type    => 'chat', # 'chat', 'normal', 'headline', 'groupchat'
        subject => 'Greeting',
        id      => 'message123',
    );

    # Get message properties
    my $to      = $message->to;
    my $from    = $message->from;
    my $body    = $message->body;
    my $type    = $message->type;
    my $subject = $message->subject;
    my $id      = $message->id;

    # Set message properties
    $message->body('Updated message text');

    # Add extensions (e.g., XEP-0030 Service Discovery)
    $message->add_extension(
        name    => 'x-iq-query',
        element => XML::LibXML::Element->new('query')
    );

    # Check for extensions
    if ($message->has_extension('x-iq-query')) {
        my $extension = $message->get_extension('x-iq-query');
        # ... process extension
    }

    # Check if an error attribute is defined
    if ($message->DefinedError) {
        print "Message contains an error attribute.\n";
    }

DESCRIPTION

This class represents an XMPP message stanza. It provides methods for creating, manipulating, and accessing the properties of XMPP messages.

METHODS

add_extension NAME, ELEMENT
Adds an extension element to the message. NAME is a unique identifier for the extension, and ELEMENT is an XML::LibXML::Element object representing the extension.
[SETTER] GETTER
Gets or sets the body (content) of the message.
DefinedError
Returns 1 if the code attribute is defined in the <error/>, 0 otherwise. $test = $Mess->DefinedError();
[SETTER] GETTER
Gets or sets the 'from' JID of the message.
get_extension NAME
Retrieves an extension element by its NAME.
has_extension NAME
Returns true if the message has an extension with the given NAME, false otherwise.
[SETTER] GETTER
Gets or sets the message ID.
new ARGS
Creates a new Net::XMPP::Message object. ARGS is a hash of attributes like 'to', 'from', 'body', 'type', 'subject', 'id'.
[SETTER] GETTER
Gets or sets the subject of the message.
[SETTER] GETTER
Gets or sets the 'to' JID of the message.
[SETTER] GETTER
Gets or sets the message type ('chat', 'normal', 'headline', 'groupchat').
