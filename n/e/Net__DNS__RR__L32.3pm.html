Net__DNS__RR__L32(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS::RR::L32(3) توثيق Perl مساهمة من المستخدم Net::DNS::RR::L32(3)

الاسم

Net::DNS::RR::L32 - سجل مورد موجه DNS L32

الملخص

use Net::DNS;
$rr = Net::DNS::RR->new('name IN L32 preference locator32');
$rr = Net::DNS::RR->new(
                name       => 'example.com',
                type       => 'L32',
                preference => 10,
                locator32  => '10.1.02.0'
                );

الوصف

فئة لسجلات موارد موجه DNS ذات 32 بت (L32).

يُستخدم سجل مورد L32 لتخزين قيم موجه 32 بت للعقد القادرة على ILNPv4.

الطرق

الطرق المتاحة هي تلك الموروثة من الفئة الأساسية مع إضافة الطرق الخاصة بالنوع المحدد في هذه الحزمة.

يُثبط استخدام ميزات الحزمة غير الموثقة أو الوصول المباشر إلى هياكل البيانات الداخلية وقد يؤدي إلى إنهاء البرنامج أو سلوك غير متوقع آخر.

preference

$preference = $rr->preference;
$rr->preference( $preference );

عدد صحيح غير موقّع 16 بت بترتيب بايت الشبكة يشير إلى الأفضلية النسبية لسجل L32 هذا من بين سجلات L32 الأخرى المرتبطة بهذا الاسم المالك. القيم الأقل مفضلة على القيم الأعلى.

locator32

$locator32 = $rr->locator32;

حقل Locator32 هو عدد صحيح غير موقّع 32 بت بترتيب بايت الشبكة له نفس بناء ودلالات بادئة التوجيه IPv4 ذات 32 بت.
