الحزمة: dnssec-tools

التراخيص: BSD

REALM INTERNAL INTERFACES

The following methods are provided for internal use, and are not intended for direct use by the user.

realmlist
Return the list of realms currently loaded into memory.
realmadd
Add a new realm to the list of loaded realms. The new realm is added to the end of the list. The realm data structure is cloned before being added to the list.
realmadopt
Add an option to an existing realm. Options are added to the beginning of the realm's option list. A realm is identified by its name.
realmgetopt
Get the value of a specific option for a specific realm. A realm is identified by its name.
realmget
Get a specific realm by its name.

REALM DEBUGGING INTERFACES

The following methods are provided for debugging purposes. They return values that are useful for understanding the internal state of the realm object.

realmverbose
Set the verbosity level for the realm object. The verbosity level controls how much debugging information is printed. A verbosity level of 0 means no debugging information is printed. A verbosity level of 1 means that some debugging information is printed. A verbosity level of 2 means that a lot of debugging information is printed.
realmdebug
Print debugging information about the realm object. The debugging information includes the list of realms, the options for each realm, and the status of each realm.

REALM FILE FORMAT

The realm file is a text file that contains a list of realms. Each realm is represented by a block of text that starts with the realm name followed by a colon. The realm name is followed by a list of options, one per line. Each option is a key-value pair, separated by an equals sign. The options are followed by a list of realms, one per line. The realms are separated by commas.

For example, the following is a realm file that contains two realms:

        . :
          debug = 1
          logging = /var/log/realm.log
        . , .vn :
          debug = 2
          logging = /var/log/realm.log

The realm file is read by the realminit(8) command. The realminit(8) command reads the realm file and loads the realms into memory. The realms are stored in an array of realm structures. The realm structures are ordered in the same manner as they appear in the realm file. New realms are appended to the end of the array. realm fields added to existing realms are added at the beginning of the realm entry. Comments and vertical whitespace are preserved as given in the realm file.
