Net__DNS__SEC__Tools__realmmgr(3pm)

realmmgr(3) وثائق مستخدمة مقدمة من بيرل realmmgr(3)

الاسم

Net::DNS::SEC::Tools::realmmgr - التواصل مع مدير نطاقات DNSSEC-Tools.

الملخص

use Net::DNS::SEC::Tools::realmmgr;
$dir = realmmgr_dir();
$idfile = realmmgr_idfile();
$id = realmmgr_getid();
realmmgr_dropid();
realmmgr_rmid();
realmmgr_cmdint();
$runflag = realmmgr_running();
realmmgr_halt();
realmmgr_channel(1);
($cmd,$data) = realmmgr_getcmd();
$ret = realmmgr_verifycmd($cmd);
realmmgr_sendcmd(CHANNEL_CLOSE,REALMCMD_STARTREALM,"example-realm");
realmmgr_sendcmd(CHANNEL_WAIT,REALMCMD_STARTREALM,"example-realm");
($retcode, $respmsg) = realmmgr_getresp();

الوصف

توفر الوحدة Net::DNS::SEC::Tools::realmmgr طرقًا قياسية، مستقلة عن المنصة، للبرنامج للتواصل مع مديري نطاقات dtrealms الخاصة بـ DNSSEC-Tools. هناك واجهتان وصفان هنا: واجهات عامة وواجهات اتصال.

واجهات عامة

الواجهات إلى الوحدة Net::DNS::SEC::Tools::realmmgr معطاة أدناه.

realmmgr_dir()
يعيد هذا الروتين دليل dtrealms.
realmmgr_idfile()
يعيد هذا الروتين ملف هوية dtrealms.
realmmgr_getid()
يعيد هذا الروتين معرف عملية dtrealms. إذا تم تمرير قيمة غير صفرية كمعامل، فسيتم ترك ملف الهوية مفتوحًا ويمكن الوصول إليه عبر مقبض الملف PIDFILE. انظر قسم التحذيرات أدناه.

قيم الإرجاع:

عند النجاح، يتم إرجاع الجزء الأول من محتويات الملف
    (حتى 80 حرفًا).
يتم إرجاع -1 إذا كان ملف الهوية غير موجود.
realmmgr_dropid()
تضمن هذه الواجهة عدم تشغيل نسخة أخرى من dtrealms ثم تنشئ ملف هوية للرجوع إليه مستقبلاً.

قيم الإرجاع:

 1 - تم إنشاء ملف الهوية بنجاح لهذه العملية
 0 - عملية أخرى تعمل بالفعل كـ dtrealms
-1 - غير قادر على إنشاء ملف الهوية
realmmgr_rmid()
تحذف هذه الواجهة ملف هوية dtrealms.

قيم الإرجاع:

 1 - تم حذف ملف الهوية بنجاح
 0 - لا يوجد ملف هوية
-1 - العملية المتصلة ليست dtrealms
-2 - غير قادر على حذف ملف الهوية
realmmgr_cmdint()
تُعلم هذه الواجهة dtrealms بأنه تم إرسال أمر عبر realmmgr_sendcmd().

قيم الإرجاع:

-1 - تم العثور على معرف عملية غير صالح لـ dtrealms
أي شيء آخر يشير إلى عدد العمليات التي تم
إرسال إشارة إليها.
(يجب أن يكون هذا دائمًا 1.)
realmmgr_running()
تحدد هذه الواجهة ما إذا كان dtrealms قيد التشغيل وتعيد قيمة تشير إلى الحالة.

قيم الإرجاع:

 1 - dtrealms قيد التشغيل.
 0 - العملية المدرجة في ملف معرف عملية dtrealms
     ليست قيد التشغيل.
-1 - غير قادر على الحصول على معرف عملية dtrealms.
realmmgr_halt()
تُعلم هذه الواجهة dtrealms بإيقاف التشغيل.

في التنفيذ الحالي، يتم إرجاع رمز الاستجابة من الأمر kill().

-1 - تم العثور على معرف عملية غير صالح لـ dtrealms
أي شيء آخر يشير إلى عدد العمليات التي تم
إرسال إشارة إليها.
(يجب أن يكون هذا دائمًا 1.)

واجهات اتصالات DTREALMS

realmmgr_channel(serverflag)
تقوم هذه الواجهة بإعداد قناة مستمرة للتواصل مع dtrealms. إذا كانت serverflag صحيحة، يتم إنشاء جانب الخادم من القناة. إذا كانت serverflag خاطئة، يتم إنشاء جانب العميل من القناة.

حاليًا، لا يمكن إجراء الاتصال إلا مع الجهاز المحلي. يمكن تغيير ذلك للسماح بالاتصالات عن بعد، إذا وجد أن هذا ضروري.

قيم الإرجاع:

 1 - تم إنشاء قناة الاتصال بنجاح.
 0 - غير قادر على الاتصال بالخادم.
-1 - غير قادر على إنشاء مقبس Unix.
-2 - غير قادر على الربط بمقبس Unix. (للخادم فقط)
-3 - غير قادر على تغيير أذونات مقبس Unix. (للخادم فقط)
-4 - غير قادر على الاستماع على مقبس Unix. (للخادم فقط)
-5 - اسم المقبس كان أطول من المسموح به لمقبس Unix.
realmmgr_queuecmd(cmdname, value)
تتذكر هذه الواجهة داخليًا أمرًا وقيمته الاختيارية للمعالجة لاحقًا. انظر realmmgr_getcmd() تاليًا لمزيد من التفاصيل.
realmmgr_getcmd()
realmmgr_getcmd() يعالج الأوامر التي تحتاج إلى التعامل معها. إذا كانت هناك أي أوامر مخزنة داخليًا تم وضعها في قائمة انتظار عبر الدالة realmmgr_queuecmd()، يتم التعامل معها أولاً. بعد ذلك، يسترد أمرًا تم إرساله عبر قناة الاتصال الخاصة بـ dtrealms بواسطة برنامج عميل. يتم إرسال الأمر وبيانات الأمر في كل رسالة.

يتم إرجاع الأمر وبيانات الأمر إلى المتصل.

realmmgr_sendcmd(closeflag,cmd,data)
ترسل realmmgr_sendcmd() أمرًا إلى dtrealms. يجب أن يكون الأمر أحد الأوامر من الجدول أدناه. تنشئ هذه الواجهة قناة اتصال مع dtrealms وترسل الرسالة. لا يتم إغلاق القناة، في حالة رغبة المتصل في تلقي رد من dtrealms.

الأوامر المتاحة وبياناتها المطلوبة هي:

command              data            purpose
-------              ----            -------
REALMCMD_COMMAND     realm, command  run command in a realm
REALMCMD_DISPLAY     1/0             start/stop dtrealms'
                                     graphical display
REALMCMD_GETSTATUS   none            currently unused
REALMCMD_LOGFILE     log filename    change the log file
REALMCMD_LOGLEVEL    log level       set a new logging level
REALMCMD_LOGMSG      log message     add a message to the log
REALMCMD_LOGTZ       timezone        set timezone for log messages
REALMCMD_NODISPLAY   0               stop dtrealms' graphical display
REALMCMD_REALMSTATUS none            get status of the realms
REALMCMD_SHUTDOWN    none            stop dtrealms and its realms
REALMCMD_STARTALL    none            start all stopped realms
REALMCMD_STOPALL     none            stop all running realms
REALMCMD_STARTREALM  realm name      restart a suspended realm
REALMCMD_STOPREALM   realm name      stop realm
REALMCMD_STATUS      none            get status of dtrealms

لا يتم التحقق من صحة البيانات بواسطة realmmgr_sendcmd()؛ التحقق من الصحة هو مسؤولية dtrealms.

إذا لم يكن المتصل بحاجة إلى رد من dtrealms، فيجب تعيين closeflag إلى CHANNEL_CLOSE؛ إذا كان الرد مطلوبًا، فيجب تعيين closeflag إلى CHANNEL_WAIT. هذه القيم هي قيم منطقية، ولا يلزم الثوابت.

عند النجاح، يتم إرجاع 1. إذا تم تقديم أمر غير صالح، يتم إرجاع 0.

realmmgr_getresp()
بعد تنفيذ أمر العميل المرسل عبر realmmgr_sendcmd()، سيرسل dtrealms ردًا إلى العميل. تتيح realmmgr_getresp() للعميل استرداد الرد.

يتم إرجاع رمز استجابة وسلسلة رد، بهذا الترتيب. كلاهما خاص بالأمر المرسل.

realmmgr_verifycmd(cmd)
