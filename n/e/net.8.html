RAP LOGIN

تحقق مما إذا كان يمكن للمستخدم المحدد تسجيل الدخول إلى الخادم البعيد. إذا لم يتم تحديد كلمة المرور في سطر الأوامر، فسيتم مطالبتك بها.


ملاحظة

غير مطبق حاليًا.

RAP GROUPMEMBER

RAP GROUPMEMBER LIST GROUP

قائمة بجميع أعضاء المجموعة المحددة.

RAP GROUPMEMBER DELETE GROUP USER

حذف عضو من المجموعة.

RAP GROUPMEMBER ADD GROUP USER

إضافة عضو إلى المجموعة.

RAP ADMIN command

تنفيذ الأمر المحدد على الخادم البعيد. يعمل فقط مع خوادم OS/2.

ملاحظة

RAP PASSWORD USER OLDPASS NEWPASS

LOOKUP

LOOKUP HOST HOSTNAME [TYPE]

البحث عن عنوان IP للمضيف المحدد بالنوع المحدد (لاحقة netbios). النوع الافتراضي هو 0x20 (محطة عمل).

LOOKUP LDAP [DOMAIN]

تقديم عنوان IP لخادم LDAP للنطاق المحدد. الافتراضي هو النطاق المحلي.

LOOKUP KDC [REALM]

تقديم عنوان IP لـ KDC للمجال المحدد. الافتراضي هو المجال المحلي.

LOOKUP DC [DOMAIN]

تقديم عناوين IP لوحدات تحكم المجال للنطاق المحدد. الافتراضي هو النطاق المحلي.

LOOKUP MASTER DOMAIN

تقديم عنوان IP لأهم متصفح للنطاق أو مجموعة العمل المحددة. الافتراضي هو النطاق المحلي.

LOOKUP NAME [NAME]

البحث عن معرف الأمان (sid) ونوعه للمستخدم المحدد.

LOOKUP SID [SID]

تقديم اسم المستخدم ومعرفه ونوعه للمعرف المحدد.

LOOKUP DSGETDCNAME [NAME] [FLAGS] [SITENAME]

تقديم معلومات حول وحدة تحكم المجال للنطاق المحدد.

CACHE

يستخدم Samba واجهة تخزين مؤقت عامة تسمى 'gencache'. يمكن التحكم فيها باستخدام 'NET CACHE'.

تدعم جميع معلمات المهلة اللاحقات التالية:

ث - ثواني
د - دقائق
س - ساعات
ي - أيام
أ - أسابيع

CACHE ADD key data time-out

إضافة المفتاح/البيانات المحددة إلى ذاكرة التخزين المؤقت مع المهلة المحددة.

CACHE DEL key

حذف مفتاح من ذاكرة التخزين المؤقت.

CACHE SET key data time-out

تحديث بيانات إدخال ذاكرة التخزين المؤقت الموجود.

CACHE SEARCH PATTERN

البحث عن النمط المحدد في بيانات ذاكرة التخزين المؤقت.

CACHE LIST

قائمة بجميع العناصر الحالية في ذاكرة التخزين المؤقت.

CACHE FLUSH

إزالة جميع العناصر الحالية من ذاكرة التخزين المؤقت.

GETLOCALSID [DOMAIN]

طباعة معرف الأمان (SID) للنطاق المحدد، أو إذا تم حذف المعلمة، فسيتم طباعة معرف الأمان للخادم المحلي.

SETLOCALSID S-1-5-21-x-y-z

تعيين معرف الأمان (SID) للخادم المحلي إلى المعرف المحدد.

GETDOMAINSID

طباعة معرف الأمان (SID) للجهاز المحلي ومعرف الأمان للنطاق الحالي.

SETDOMAINSID

تعيين معرف الأمان (SID) للنطاق الحالي.

GROUPMAP

إدارة تعيينات بين معرفات الأمان (SIDs) لمجموعات Windows ومجموعات UNIX. تشمل الخيارات الشائعة:

•unixgroup - اسم مجموعة UNIX
•ntgroup - اسم مجموعة Windows NT (يجب أن تكون قابلة للحل إلى SID
•rid - عدد صحيح غير موقع 32 بت
•sid - SID كامل بالشكل "S-1-..."
•type - نوع المجموعة؛ إما 'domain' أو 'local' أو 'builtin'
•comment - وصف نصي حر للمجموعة

GROUPMAP ADD

إضافة إدخال تعيين مجموعة جديد:

net groupmap add {rid=int|sid=string} unixgroup=string \
	[type={domain|local}] [ntgroup=string] [comment=string]

GROUPMAP DELETE

حذف إدخال تعيين مجموعة. إذا تطابق أكثر من اسم مجموعة واحد، يتم حذف الإدخال الأول الذي تم العثور عليه.

net groupmap delete {ntgroup=string|sid=SID}

GROUPMAP MODIFY

تحديث إدخال مجموعة موجود.

net groupmap modify {ntgroup=string|sid=SID} [unixgroup=string] \
       [comment=string] [type={domain|local}]

GROUPMAP LIST

قائمة بإدخالات تعيين المجموعة الموجودة.

net groupmap list [verbose] [ntgroup=string] [sid=SID]

MAXRID

طباعة أعلى معرف نسبي (RID) مستخدم حاليًا في الخادم المحلي (بواسطة "backend" قاعدة تمرير نشطة).

RPC INFO

طباعة معلومات حول نطاق الخادم البعيد، مثل اسم النطاق، ومعرف الأمان (SID) للنطاق، وعدد المستخدمين والمجموعات.

[RPC|ADS] TESTJOIN

التحقق مما إذا كانت المشاركة في نطاق لا تزال صالحة.

[RPC|ADS] CHANGETRUSTPW

فرض تغيير كلمة مرور الثقة في النطاق.

RPC TRUSTDOM

RPC TRUSTDOM ADD DOMAIN

إضافة حساب ثقة بين النطاقات لـ DOMAIN. هذا في الواقع حساب Samba يسمى DOMAIN$ مع علامة الحساب 'I' (حساب ثقة بين النطاقات). هذا مطلوب لعمليات الثقة الواردة. يجعل Samba نطاقًا موثوقًا به من المجال الأجنبي (الموثوق). سيتم جعل مستخدمي نطاق Samba متاحين في النطاق الأجنبي. إذا تم استخدام الأمر ضد localhost، فله نفس تأثير smbpasswd -a -i DOMAIN. يرجى ملاحظة أن كلا الأمرين يتوقعان حساب UNIX مناسب.

RPC TRUSTDOM DEL DOMAIN

إزالة حساب الثقة بين النطاقات لـ DOMAIN. إذا تم استخدامه ضد localhost، فله نفس تأثير smbpasswd -x DOMAIN $.
