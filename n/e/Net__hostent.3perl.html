Net::hostent(3perl) دليل مبرمجي بيرل Net::hostent(3perl)

الاسم

Net::hostent - واجهة بالاسم لوظائف Perl المدمجة gethost*()

ملخص

use Net::hostent;

الوصف

تقوم الصادرات الافتراضية لهذه الوحدة بتجاوز وظائف gethostbyname() و gethostbyaddr() الأساسية، واستبدالها بإصدارات تُرجع كائنات "Net::hostent". يحتوي هذا الكائن على طرق تُرجع اسم حقل البنية المسمى بشكل مشابه من بنية hostent الخاصة بـ C من netdb.h؛ وهي name، aliases، addrtype، length، و addr_list. تُرجع طرائق aliases و addr_list مرجع مصفوفة، بينما تُرجع البقية قيماً عددية. طريقة addr مكافئة للعنصر الصفري في مرجع مصفوفة addr_list.

يمكنك أيضًا استيراد جميع حقول البنية مباشرة إلى مساحة الأسماء الخاصة بك كمتغيرات عادية باستخدام وسم الاستيراد :FIELDS. (لاحظ أن هذا لا يزال يتجاوز وظائفك الأساسية.) قم بالوصول إلى هذه الحقول كمتغيرات مسماة مع بادئة "h_". وبالتالي، فإن "$host_obj->name()" يتوافق مع $h_name إذا قمت باستيراد الحقول. مراجع المصفوفات متاحة كمتغيرات مصفوفة عادية، لذا على سبيل المثال "@{ $host_obj->aliases() }" ستكون ببساطة @h_aliases.

وظيفة gethost() هي واجهة أمامية بسيطة تقوم بتمرير وسيط رقمي إلى gethostbyaddr() عن طريق Socket::inet_aton، والباقي إلى gethostbyname().

للوصول إلى هذه الوظيفة دون تجاوزات أساسية، مرر إلى "use" قائمة استيراد فارغة، ثم قم بالوصول إلى وظائف الوظائف بأسمائها المؤهلة بالكامل. من ناحية أخرى، لا تزال الوظائف المدمجة متاحة عبر الحزمة الزائفة "CORE::".

أمثلة

use Net::hostent;
use Socket;
@ARGV = ('netscape.com') unless @ARGV;
for $host ( @ARGV ) {
   unless ($h = gethost($host)) {
       warn "$0: no such host: $host\n";
       next;
   }
   printf "\n%s is %s%s\n",
           $host,
           lc($h->name) eq lc($host) ? "" : "*really* ",
           $h->name;
   print "\taliases are ", join(", ", @{$h->aliases}), "\n"
               if @{$h->aliases};
   if ( @{$h->addr_list} > 1 ) {
       my $i;
       for $addr ( @{$h->addr_list} ) {
           printf "\taddr #%d is [%s]\n", $i++, inet_ntoa($addr);
       }
   } else {
       printf "\taddress is [%s]\n", inet_ntoa($h->addr);
   }
   if ($h = gethostbyaddr($h->addr)) {
       if (lc($h->name) ne lc($host)) {
           printf "\tThat addr reverses to host %s!\n", $h->name;
           $host = $h->name;
           redo;
       }
   }
}
