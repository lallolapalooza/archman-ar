ne_session_proxy(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_SESSION_PROXY(3) مرجع واجهة برمجة تطبيقات neon NE_SESSION_PROXY(3)

الاسم

ne_session_proxy, ne_session_socks_proxy, ne_session_system_proxy, ne_set_addrlist - تكوين خوادم الوكيل

ملخص

#include <ne_session.h>

void ne_session_proxy(ne_session *session, const char *hostname, unsigned int port);

void ne_session_system_proxy(ne_session *session, unsigned int flags);

void ne_session_socks_proxy(ne_session *session, enum ne_sock_sversion version, const char *hostname, unsigned int port, const char *username, const char *password);

void ne_set_addrlist(ne_session *session, const ne_inet_addr **addrlist, size_t count);

الوصف

يمكن استخدام واحدة (وليس أكثر من واحدة) من الدوال ne_session_proxy أو ne_session_system_proxy أو ne_session_socks_proxy أو ne_set_addrlist لتكوين خادم وكيل لمعطيات الجلسة المحددة. إذا تم استدعاء أكثر من دالة واحدة لأي معطيات جلسة معينة، فإن الاستدعاء الأخير فقط هو الذي يكون له تأثير. إذا كان سيتم استخدام إحدى الدوال، فيجب استخدامها قبل إنشاء أي كائن طلب للجلسة.

تحديد وكيل HTTP

تقوم الدالة ne_session_proxy بتكوين استخدام خادم وكيل HTTP للجلسة، والذي يتم تحديد موقعه بواسطة المعاملين hostname و port. إذا كان الوكيل يتطلب مصادقة، يجب استخدام ne_set_proxy_auth.

تكوين وكيل النظام

تقوم الدالة ne_session_system_proxy بتكوين الجلسة لاستخدام أي خوادم وكيل محددة بواسطة تكوين النظام. دعم هذه الدالة خاص بالمنصة؛ إذا لم يتم دعمها، فلن يكون للدالة أي تأثير.

تكوين وكيل SOCKS

تقوم الدالة ne_session_socks_proxy بتكوين الجلسة لاستخدام وكيل SOCKS. يشير المعامل version إلى أي إصدار من بروتوكول SOCKS يجب استخدامه. يحدد المعاملان hostname و port موقع وكيل SOCKS. لاحظ أنه لا يمكن استخدام خادم بعنوان IPv6 فقط مع SOCKS v4 أو v4A. يعتمد تفسير المعاملات الأخرى على الإصدار المحدد:

NE_SOCK_SOCKSV4 (الإصدار 4)

يجب أن يكون المعامل username غير NULL؛ يتم تجاهل المعامل password.

NE_SOCK_SOCKSV4A (الإصدار 4A)

يجب أن يكون المعامل username غير NULL؛ يتم تجاهل المعامل password.

NE_SOCK_SOCKSV5 (الإصدار 5)

قد يكون المعامل username NULL؛ إذا لم يكن NULL، فيجب أن يكون المعامل password غير NULL أيضًا؛ بخلاف ذلك، يتم تجاهله.

تجاوز عنوان الخادم الأصلي

تقوم الدالة ne_set_addrlist بفرض استخدام عنوان ومنفذ في قائمة محددة عند إنشاء اتصال TCP، متجاهلة العنوان والمنفذ "الحقيقيين" اللذين يحددان الخادم الأصلي للجلسة (كما تم تمريره إلى ne_session_create). سيظل عنوان الخادم الأصلي ومنفذه "الحقيقيين" مستخدمين في رأس Host في طلبات HTTP. عندما يكون الاتصال مطلوبًا، ستقوم المكتبة بالتكرار عبر قائمة addrlist، ومحاولة الاتصال بالعنوان addrlist[0] إلى addrlist[count-1] بالتناوب، حتى يمكن إنشاء اتصال.

قيم الإرجاع

لا تحتوي أي من الدوال الموصوفة هنا على قيمة إرجاع.

أمثلة

إنشاء وتدمير جلسة:

ne_session *sess;
sess = ne_session_create("http", "host.example.com", 80);
ne_session_proxy(sess, "proxy.example.com", 3128);
/* ... استخدام sess ... */
ne_session_destroy(sess);
