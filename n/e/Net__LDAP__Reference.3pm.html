Net__LDAP__Reference(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Reference(3) وثائق Perl المساهمة من المستخدم Net::LDAP::Reference(3)

الاسم

Net::LDAP::Reference - مرجع بحث

الملخص

use Net::LDAP;
$ldap->search( @search_args, callback => \&process);
sub process {
  my $mesg = shift;
  my $obj = shift;
  if (!$obj) {
    # البحث مكتمل
  }
  elsif ($obj->isa('Net::LDAP::Reference')) {
    my $ref;
    foreach $ref ($obj->references) {
      # معالجة المرجع
    }
  }
  else {
    # معالجة Net::LDAP::Entry
  }
}

الوصف

يمثل كائن Net::LDAP::Reference مرجعًا (يُسمى أحيانًا "إحالة") تم إرجاعه من الدليل من عملية بحث.

الأساليب

references
يعيد قائمة بالمراجع من الخادم.

انظر أيضًا
