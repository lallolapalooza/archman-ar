Net__DNS(3pm)

الحزمة: perl-net-dns

التراخيص: PerlArtistic

Net::DNS(3) توثيق Perl المساهم به من قبل المستخدم Net::DNS(3)

الاسم

Net::DNS - واجهة Perl لنظام أسماء النطاقات (DNS)

الملخص

use Net::DNS;
my $resolver = Net::DNS::Resolver->new(...);
my $response = $resolver->send(...);

الوصف

Net::DNS هي مجموعة من وحدات Perl تعمل كـ محلل لنظام أسماء النطاقات (DNS). تسمح للمبرمج بإجراء استعلامات DNS تتجاوز قدرات "gethostbyname" و "gethostbyaddr".

يجب أن يكون المبرمج على دراية ببنية حزمة DNS وتنسيق تقديم ملف المنطقة الموصوف في RFC1035.

كائنات المحلل

كائن المحلل هو نسخة من فئة Net::DNS::Resolver. قد يحتوي البرنامج على عدة كائنات محلل، كل منها يحتفظ بمعلومات حالته الخاصة مثل خوادم الأسماء التي سيتم الاستعلام عنها، وما إذا كان التكرار مطلوبًا، وما إلى ذلك.

كائنات الحزمة

استعلامات Net::DNS::Resolver تُرجع كائنات Net::DNS::Packet. يحتوي كائن الحزمة على خمسة أقسام:

  • header، ممثل بكائن Net::DNS::Header
  • question، قائمة بكائن Net::DNS::Question واحد على الأكثر
  • answer، قائمة بكائنات Net::DNS::RR
  • authority، قائمة بكائنات Net::DNS::RR
  • additional، قائمة بكائنات Net::DNS::RR

كائنات التحديث

Net::DNS::Update هي فئة فرعية من Net::DNS::Packet مفيدة لإنشاء طلبات التحديث الديناميكي.

كائن الرأس

يتوسط كائن Net::DNS::Header الوصول إلى بيانات الرأس الموجودة داخل Net::DNS::Packet المقابلة.

كائن السؤال

يمثل كائن Net::DNS::Question محتوى قسم السؤال في حزمة DNS.

كائنات RR

Net::DNS::RR هي الفئة الأساسية لكائنات سجلات الموارد DNS (RR) في أقسام الإجابة، السلطة، والإضافية لحزمة DNS.

لا تفترض أن كائنات RR ستكون من النوع المطلوب. يجب التحقق من نوع كائن RR قبل استدعاء أي طرق.

الطرق

يقوم Net::DNS بتصدير طرق ووظائف مساعدة لدعم تحديثات DNS، وإدارة ترقيم تسلسل المنطقة، واستعلامات DNS البسيطة.

version

use Net::DNS;
print Net::DNS->version, "\n";

يُرجع إصدار Net::DNS.

rr

# استخدام محلل افتراضي -- لا يمكن الحصول على سلسلة خطأ بهذه الطريقة.
use Net::DNS;
my @rr = rr("example.com");
my @rr = rr("example.com", "AAAA");
my @rr = rr("example.com", "AAAA", "IN");
# استخدام كائن المحلل الخاص بك.
my $res = Net::DNS::Resolver->new;
my @rr  = rr($res, "example.com" ... );
my ($ptr) = rr("2001:DB8::dead:beef");

توفر طريقة rr() بحثًا بسيطًا عن RR للسيناريوهات التي لا تتطلب المرونة الكاملة لـ Net::DNS.

تُرجع قائمة بكائنات Net::DNS::RR للاسم المحدد أو قائمة فارغة إذا فشل الاستعلام أو لم يتم العثور على سجل.

راجع "أمثلة" لمزيد من الأمثلة الكاملة.

mx

# استخدام محلل افتراضي -- لا يمكن الحصول على سلسلة خطأ بهذه الطريقة.
use Net::DNS;
my @mx = mx("example.com");
# استخدام كائن المحلل الخاص بك.
my $res = Net::DNS::Resolver->new;
my @mx  = mx($res, "example.com");

تُرجع قائمة بكائنات Net::DNS::RR::MX التي تمثل سجلات MX للاسم المحدد. سيتم فرز القائمة حسب الأولوية. تُرجع قائمة فارغة إذا فشل الاستعلام أو لم يتم العثور على سجل MX.

هذه الطريقة لا تبحث عن سجلات العناوين؛ بل تقوم بحل MX فقط.

دعم تحديث DNS الديناميكي

توفر وحدة Net::DNS وظائف مساعدة تدعم طلبات تحديث DNS الديناميكية.

$update = Net::DNS::Update->new( 'example.com' );
$update->push( prereq => nxrrset('example.com. AAAA') );
$update->push( update => rr_add('example.com. 86400 AAAA 2001::DB8::F00') );

yxrrset

استخدم هذه الطريقة لإضافة شرط مسبق "مجموعة سجلات موجودة" إلى حزمة تحديث ديناميكي. هناك شكلان، مستقل عن القيمة ومعتمد على القيمة:

# مجموعة سجلات موجودة (مستقلة عن القيمة)
$update->push( pre => yxrrset("host.example.com AAAA") );

المعنى: يجب أن توجد سجلات واحدة على الأقل بالاسم والنوع المحددين.

# مجموعة سجلات موجودة (معتمدة على القيمة)
$update->push( pre => yxrrset("host.example.com AAAA 2001:DB8::1") );

المعنى: يجب أن توجد سجلات واحدة على الأقل بالاسم والنوع المحددين ويجب أن تحتوي على بيانات مطابقة.

تُرجع كائن Net::DNS::RR أو "undef" إذا لم يكن من الممكن إنشاء الكائن.

nxrrset

استخدم هذه الطريقة لإضافة شرط مسبق "مجموعة سجلات غير موجودة" إلى حزمة تحديث ديناميكي.

$update->push( pre => nxrrset("host.example.com AAAA") );

المعنى: لا يمكن أن توجد أي سجلات بالاسم والنوع المحددين.

تُرجع كائن Net::DNS::RR أو "undef" إذا لم يكن من الممكن إنشاء الكائن.

yxdomain

استخدم هذه الطريقة لإضافة شرط مسبق "الاسم قيد الاستخدام" إلى حزمة تحديث ديناميكي.

$update->push( pre => yxdomain("host.example.com") );

المعنى: يجب أن توجد سجلات واحدة على الأقل بالاسم المحدد.

تُرجع كائن Net::DNS::RR أو "undef" إذا لم يكن من الممكن إنشاء الكائن.

nxdomain

استخدم هذه الطريقة لإضافة شرط مسبق "الاسم غير مستخدم" إلى حزمة تحديث ديناميكي.

$update->push( pre => nxdomain("host.example.com") );

المعنى: لا يمكن أن توجد أي سجلات بالاسم المحدد.

تُرجع كائن Net::DNS::RR أو "undef" إذا لم يكن من الممكن إنشاء الكائن.

rr_add

استخدم هذه الطريقة لإضافة سجلات إلى منطقة.

$update->push( update => rr_add("host.example.com AAAA 2001:DB8::c001:a1e") );

المعنى: أضف هذا السجل إلى المنطقة.

يجب إضافة كائنات RR التي تم إنشاؤها بواسطة هذه الطريقة إلى قسم "update" لحزمة تحديث ديناميكي. القيمة الافتراضية لـ TTL هي 86400 ثانية (24 ساعة) إذا لم يتم تحديدها.

تُرجع كائن Net::DNS::RR أو "undef" إذا لم يكن من الممكن إنشاء الكائن.

rr_del

استخدم هذه الطريقة لحذف سجلات من منطقة. هناك ثلاثة أشكال: حذف جميع مجموعات السجلات، حذف مجموعة سجلات، وحذف سجل معين.

# حذف جميع مجموعات السجلات.
$update->push( update => rr_del("host.example.com") );

المعنى: حذف جميع السجلات التي تحمل الاسم المحدد.

# حذف مجموعة سجلات.
$update->push( update => rr_del("host.example.com AAAA") );

المعنى: حذف جميع السجلات التي تحمل الاسم والنوع المحددين.

# حذف سجل معين.
$update->push( update => rr_del("host.example.com AAAA 2001:DB8::dead:beef") );

المعنى: حذف السجل الذي يتطابق مع الوسيط المحدد.

يجب إضافة كائنات RR التي تم إنشاؤها بواسطة هذه الطريقة إلى قسم "update" لحزمة تحديث ديناميكي.

تُرجع كائن Net::DNS::RR أو "undef" إذا لم يكن من الممكن إنشاء الكائن.

أمثلة

توضح الأمثلة الموجزة التالية بعض ميزات Net::DNS. توفر وثائق الوحدات الفردية ونصوص العرض التوضيحية المضمنة مع التوزيع أمثلة أكثر شمولاً.

انظر Net::DNS::Update للحصول على مثال حول إجراء التحديثات الديناميكية.

البحث عن عناوين المضيف.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->search( "www.example.com", "AAAA" );
die "query failed: ", $res->errorstring unless $reply;
foreach my $rr ( $reply->answer ) {
        print $rr->address, "\n" if $rr->can("address");
}

البحث عن خوادم الأسماء لنطاق.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->query( "example.com", "NS");
die "query failed: ", $res->errorstring unless $reply;
foreach $rr ( grep {$_->type eq "NS"} $reply->answer ) {
        print $rr->nsdname, "\n";
}

البحث عن سجلات MX لنطاق.

use Net::DNS;
my $name = "example.com";
my $res  = Net::DNS::Resolver->new;
my @mx   = mx( $res, $name );
foreach $rr (@mx) {
        print $rr->preference, "\t", $rr->exchange, "\n";
}

طباعة سجل SOA للنطاق بتنسيق ملف المنطقة.

use Net::DNS;
my $res   = Net::DNS::Resolver->new;
my $reply = $res->query( "example.com", "SOA" );
die "query failed: ", $res->errorstring unless $reply;
foreach my $rr ( $reply->answer ) {
        $rr->print;
}

إجراء نقل منطقة وطباعة جميع السجلات.

use Net::DNS;
my $res  = Net::DNS::Resolver->new(
        nameservers => ["a.iana-servers.net", "b.iana-servers.net"],
        tcp_timeout => 20
        );
my @zone = $res->axfr("example.com");
warn $res->errorstring if $res->errorstring;
foreach $rr (@zone) {
        $rr->print;
}

إجراء استعلام في الخلفية وطباعة الرد.

use Net::DNS;
my $res    = Net::DNS::Resolver->new;
$res->udp_timeout(10);
$res->tcp_timeout(20);
my $socket = $res->bgsend( "www.example.com", "AAAA" );
while ( $res->bgbusy($socket) ) {
        # do some work here whilst awaiting the response
        # ...and some more here
}
my $packet = $res->bgread($socket);
die "query failed: ", $res->errorstring unless $packet;
$packet->print;
