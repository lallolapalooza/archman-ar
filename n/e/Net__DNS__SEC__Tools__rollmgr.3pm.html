Net__DNS__SEC__Tools__rollmgr(3pm)

الحزمة: dnssec-tools

التراخيص: BSD

rollmgr(3) توثيق مساهمة مستخدم Perl rollmgr(3)

الاسم

Net::DNS::SEC::Tools::rollmgr - التواصل مع مدير تدوير DNSSEC-Tools.

الملخص

use Net::DNS::SEC::Tools::rollmgr;
$dir = rollmgr_dir();
$idfile = rollmgr_idfile();
$id = rollmgr_getid();
rollmgr_dropid();
rollmgr_rmid();
rollmgr_cmdint();
$runflag = rollmgr_running();
rollmgr_halt();
rollmgr_phasemsg('long');
rollmgr_channel(1);
($cmd,$data) = rollmgr_getcmd();
$ret = rollmgr_verifycmd($cmd);
rollmgr_sendcmd(CHANNEL_CLOSE,ROLLCMD_ROLLZSK,"example.com");
rollmgr_sendcmd(CHANNEL_WAIT,ROLLCMD_ROLLZSK,"example.com");
($retcode, $respmsg) = rollmgr_getresp();
$descr = rollmgr_get_phase('KSK', $phasecnt);

الوصف

توفر الوحدة Net::DNS::SEC::Tools::rollmgr طرقًا قياسية، مستقلة عن النظام الأساسي، لبرنامج للتواصل مع مدير تدوير rollerd الخاص بـ DNSSEC-Tools. هناك واجهتان موصوفتان هنا: واجهات عامة وواجهات اتصالات.

الواجهات العامة

الواجهات إلى الوحدة Net::DNS::SEC::Tools::rollmgr معطاة أدناه.

rollmgr_dir()
تقوم هذه الروتين بإرجاع دليل rollerd.
rollmgr_idfile()
تقوم هذه الروتين بإرجاع ملف هوية rollerd.
rollmgr_getid()
تقوم هذه الروتين بإرجاع معرف عملية rollerd. إذا تم تمرير قيمة غير صفرية كوسيط، فسيتم ترك ملف الهوية مفتوحًا ويمكن الوصول إليه عبر مقبض الملف PIDFILE. انظر قسم التحذيرات أدناه.

قيم الإرجاع:

عند النجاح، يتم إرجاع الجزء الأول من محتويات الملف
    (حتى 80 حرفًا).
    يتم إرجاع -1 إذا كان ملف الهوية غير موجود.
rollmgr_dropid()
تضمن هذه الواجهة عدم تشغيل مثيل آخر لـ rollerd ثم تنشئ ملف هوية للرجوع إليه مستقبلاً.

قيم الإرجاع:

 1 - تم إنشاء ملف الهوية بنجاح لهذه العملية
 0 - عملية أخرى تعمل بالفعل كـ rollerd
-1 - غير قادر على إنشاء ملف الهوية
rollmgr_rmid()
تقوم هذه الواجهة بحذف ملف هوية rollerd.

قيم الإرجاع:

 1 - تم حذف ملف الهوية بنجاح
 0 - لا يوجد ملف هوية
-1 - العملية المتصلة ليست rollerd
-2 - غير قادر على حذف ملف الهوية
rollmgr_cmdint()
تُعلم هذه الروتين rollerd بأنه تم إرسال أمر عبر rollmgr_sendcmd().

قيم الإرجاع:

-1 - تم العثور على معرف عملية غير صالح لـ rollerd
أي شيء آخر يشير إلى عدد العمليات التي تم
إرسال إشارة إليها.
(يجب أن يكون هذا دائمًا 1.)
rollmgr_running()
تحدد هذه الروتين ما إذا كان rollerd قيد التشغيل وترجع قيمة تشير إلى الحالة.

قيم الإرجاع:

 1 - rollerd قيد التشغيل.
 0 - العملية المدرجة في ملف معرف عملية rollerd
     ليست قيد التشغيل.
-1 - غير قادر على الحصول على معرف عملية rollerd.
rollmgr_halt()
تُعلم هذه الروتين rollerd بالإغلاق.

في التنفيذ الحالي، يتم إرجاع رمز الإرجاع من الأمر kill().

-1 - تم العثور على معرف عملية غير صالح لـ rollerd
أي شيء آخر يشير إلى عدد العمليات التي تم
إرسال إشارة إليها.
(يجب أن يكون هذا دائمًا 1.)
rollmgr_loadzone(ctlprog,opts,zone)
تُعلم هذه الروتين خادم الأسماء بإعادة تحميل ملف منطقة المنطقة. ال وسيط $ctlprog هو الأمر الذي سيتم تشغيله للتحكم في خادم الأسماء. إذا كان هذا سلسلة فارغة، ف سيتم استخدام القيمة الافتراضية لـ DNSSEC-Tools. ال $opts الوسيط هو مجموعة من الخيارات التي سيتم تمريرها إلى ctlprog. ال $zone الوسيط هو اسم المنطقة التي سيتم إعادة تحميلها.

يتم بناء سطر الأوامر المراد تشغيله بهذا التنسيق:

<$zone> <$opts> reload <$zone>

يفترض هذا التنسيق أنه سيتم استخدام الأمر rndc للإشارة إلى خادم الأسماء.

سيكون رمز الإرجاع هو رمز الإرجاع من تشغيل $ctlprog.

rollmgr_phasemsg()
تقوم هذه الروتين بتعيين طول رسالة المرحلة. لرسائل السجل المتعلقة بالمرحلة التي يستخدمها rollerd. المستويات الصالحة هي "long" و "short"، مع كون "long" هي القيمة الافتراضية.

يعني طول الرسالة الطويلة أنه سيتم تضمين وصف للمرحلة مع بعض رسائل السجل. على سبيل المثال، سيكون الشكل الطويل لرسالة حول مرحلة التدوير ZSK 3: "ZSK phase 3 (Waiting for old zone data to expire from caches)".

يعني طول الرسالة القصيرة أنه لن يتم تضمين وصف للمرحلة مع بعض رسائل السجل. على سبيل المثال، سيكون الشكل القصير لرسالة حول مرحلة التدوير ZSK 3: "ZSK phase 3".

قيم الإرجاع:

1 - تم تعيين طول رسالة المرحلة
0 - تم تحديد طول رسالة مرحلة غير صالح

واجهات اتصالات ROLLERD

rollmgr_channel(serverflag)
تقوم هذه الواجهة بإعداد قناة دائمة للتواصل مع rollerd. إذا كان serverflag صحيحًا، فسيتم إنشاء جانب الخادم من القناة. إذا كان serverflag خاطئًا، فسيتم إنشاء جانب العميل من القناة.

حاليًا، لا يمكن إنشاء الاتصال إلا مع localhost. قد يتم تغيير هذا للسماح بالاتصالات البعيدة، إذا تبين أن هذا ضروري.

قيم الإرجاع:

 1 - تم إنشاء قناة الاتصال بنجاح.
 0 - غير قادر على الاتصال بالخادم.
-1 - غير قادر على إنشاء مقبس Unix.
-2 - غير قادر على ربط مقبس Unix. (خادم فقط)
-3 - غير قادر على تغيير أذونات مقبس Unix. (خادم فقط)
-4 - غير قادر على الاستماع على مقبس Unix. (خادم فقط)
-5 - كان اسم المقبس أطول من المسموح به لمقبس Unix.
rollmgr_queuecmd(cmdname, value)
تتذكر هذه الواجهة داخليًا أمرًا وقيمته الاختيارية للمعالجة لاحقًا. انظر rollmgr_getcmd() تاليًا لمزيد من التفاصيل.
rollmgr_getcmd()
rollmgr_getcmd() تعالج الأوامر التي تحتاج إلى معالجتها. إذا كانت هناك أي أوامر مخزنة داخليًا تم وضعها في قائمة انتظار عبر الدالة rollmgr_queuecmd()، فسيتم معالجتها أولاً. بعد ذلك، تسترد أمرًا تم إرساله عبر قناة الاتصالات الخاصة بـ rollerd بواسطة برنامج عميل. يتم إرسال الأمر وبيانات الأمر في كل رسالة.

يتم إرجاع الأمر وبيانات الأمر إلى المتصل.

rollmgr_sendcmd(closeflag,cmd,data)
rollmgr_sendcmd() ترسل أمرًا إلى rollerd. يجب أن يكون الأمر أحد الأوامر من الجدول أدناه. تقوم هذه الواجهة بإنشاء قناة اتصالات مع rollerd وترسل الرسالة. لا يتم إغلاق القناة، في حال كان المتصل يرغب في تلقي استجابة من rollerd.

الأوامر المتاحة والبيانات المطلوبة هي:

command              data            purpose
-------              ----            -------
ROLLCMD_DISPLAY      1/0             start/stop rollerd's

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

The data aren't checked for validity by rollmgr_sendcmd(); validity checking is a responsibility of rollerd.

If the caller does not need a response from rollerd, then closeflag should be set to CHANNEL_CLOSE; if a response is required then closeflag should be CHANNEL_WAIT. These values are boolean values, and the constants aren't required.

On success, 1 is returned. If an invalid command is given, 0 is returned.

rollmgr_getresp()
After executing a client command sent via rollmgr_sendcmd(), rollerd will send a response to the client. rollmgr_getresp() allows the client to retrieve the response.
A return code and a response string are returned, in that order. Both are specific to the command sent.
rollmgr_verifycmd(cmd)
rollmgr_verifycmd() verifies that cmd is a valid command for rollerd. 1 is returned for a valid command; 0 is returned for an invalid command.
1 is returned for a valid command; 0 is returned for an invalid command.
rollmgr_get_phase(phasetype, phasenum)
rollmgr_get_phase() returns a description of a particular phase for a particular type of rollover. phasetype specifies the type of rollover, and may be "KSK" or "ZSK". phasenum specifies the phase number whose description is desired. This must be an integer between 0 and 7 (KSK) or 0 and 4 (ZSK). If an invalid phase type or phase number is specified, an empty string is returned.

WARNINGS

1. rollmgr_getid() attempts to exclusively lock the id file. Set a timer if this matters to you.

2. rollmgr_getid() has a nice little race condition. We should lock the file prior to opening it, but we can't do so without it being open.
