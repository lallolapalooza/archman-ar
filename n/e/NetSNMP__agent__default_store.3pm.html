NetSNMP__agent__default_store(3pm)

الحزمة: net-snmp

التراخيص: BSD

default_store(3) توثيق Perl مساهمة من المستخدم default_store(3)

الاسم

NetSNMP::agent::default_store - امتداد Perl لتخزين الوكيل الافتراضي لـ Net-SNMP

الملخص

use NetSNMP::agent::default_store qw(:all);

الوصف

تحدد الوحدة النمطية NetSNMP::agent::default_store متغيرات التخزين الافتراضية الخاصة بالوكيل لـ Net-SNMP.

التصدير

لا شيء افتراضيًا.
