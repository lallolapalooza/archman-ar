Net__LDAP__Extra__eDirectory(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Extra::eDirectory(3) وثائق Perl المساهمة من المستخدم Net::LDAP::Extra::eDirectory(3)

الاسم

Net::LDAP::Extra::eDirectory -- امتدادات لـ Novell eDirectory

الملخص

use Net::LDAP::Extra qw(eDirectory);
$ldap = Net::LDAP->new( ... );
...
if ($ldap->is_eDirectory)
  my $mesg $ldap->list_replicas($server_dn);
  print "Replicas on $server_dn\n* " . join("\n* ", $mesg->replicas) . "\n"
    if (!$mesg->code);
}

الوصف

توفر Net::LDAP::Extra::eDirectory وظائف / امتدادات LDAP خاصة بـ Novell eDirectory.

للقيام بذلك، توفر الطرق التالية:

الطرق

is_eDirectory ( )
تحديد ما إذا كان خادم LDAP الذي تم الاستعلام عنه هو خادم Novell eDirectory.

نظرًا لأن التحقق يتم عن طريق الاستعلام عن جذر DSE في الدليل، فإنه يعمل دون الحاجة إلى الارتباط بالدليل.

على عكس طرق Net::LDAP الأخرى، تقوم هذه الطريقة بإرجاع TRUE / FALSE على التوالي undef في حالة حدوث خطأ.

list_replicas ( SERVER_DN, OPTIONS )
الاستعلام عن النسخ المتماثلة على الخادم المحدد SERVER_DN.

عند النجاح، يدعم كائن Net::LDAP::Message الناتج الطريقة "replicas" التي تُرجع قائمة النسخ المتماثلة على SERVER_DN.

get_replica_info ( SERVER_DN, REPLICA_DN, OPTIONS )
الاستعلام عن معلومات REPLICA_DN على SERVER_DN.

عند النجاح، يدعم كائن Net::LDAP::Message الناتج الطريقة "replica_info" التي تُرجع تجزئة تحتوي على معلومات حول REPLICA_DN.

trigger_backlinker ( OPTIONS )
تشغيل عملية BackLinker، التي تحل المراجع الخارجية لضمان أنها تشير إلى إدخالات حقيقية.
trigger_janitor ( OPTIONS )
تشغيل عملية Janitor، التي تتحقق من الاتصال بجميع الخوادم في قاعدة البيانات.
trigger_limber ( OPTIONS )
تشغيل عملية Limber، التي تتحقق من اسم الخادم، وعنوان IPX الداخلي، واتصال الشجرة لجميع النسخ المتماثلة.
trigger_skulker ( OPTIONS )
تشغيل عملية Skulker، التي تتحقق من حالة المزامنة لكل خادم في حلقة النسخ المتماثل.
trigger_schemasync ( OPTIONS )
تشغيل SchemaSync.
trigger_partitionpurge ( OPTIONS )
تشغيل PartitionPurge.
refresh_ldap_server ( OPTIONS )
تشغيل تحديث خدمة NLDAP.
