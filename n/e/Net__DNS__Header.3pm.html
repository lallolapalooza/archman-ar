NAME

Net::DNS::Header - DNS header packet object

SYNOPSIS

use Net::DNS;

DESCRIPTION

The Net::DNS::Header object is used to store the header section of a DNS message.

The header section consists of the following fields:

  ID              Identification field.
  QR              Query/Response flag.
  OPCODE          Operation code.
  AA              Authoritative Answer flag.
  TC              Truncated Response flag.
  RD              Recursion Desired flag.
  RA              Recursion Available flag.
  Z               Reserved field.
  RCODE           Response code.
  QDCOUNT         Question count.
  ANCOUNT         Answer record count.
  NSCOUNT         Authority record count.
  ARCOUNT         Additional record count.

METHODS

The following methods are available:

new()
Creates a new Net::DNS::Header object.
id()
Gets and sets the ID field.
qr()
Gets and sets the QR flag.
opcode()
Gets and sets the opcode.
aa()
Gets and sets the AA flag.
tc()
Gets and sets the TC flag.
rd()
Gets and sets the RD flag.
ra()
Gets and sets the RA flag.
z()
Gets and sets the Z field.
rcode()
Gets and sets the RCODE field.
qdcount()
Gets and sets the QDCOUNT field.
ancount()
Gets and sets the ANCOUNT field.
nscount()
Gets and sets the NSCOUNT field.
arcount()
Gets and sets the ARCOUNT field.

EDNS Protocol Extensions

This module implements the EDNS extensions to DNS.

See RFC 6891 for more information.

The EDNS extensions are indicated by an OPT pseudo-record in the additional records section.
