Net__XMPP__Roster(3pm)

Net::XMPP::Roster(3pm) أدلة Arch Linux قابلة للمساهمة Net::XMPP::Roster(3pm)

NAME

كائن قائمة جهات الاتصال XMPP

SYNOPSIS

Net::XMPP::Roster هو وحدة توفر واجهة سهلة الاستخدام للتفاعل مع قائمة جهات الاتصال الخاصة بالمستخدم. وهي تسمح بوظائف عالية المستوى للاستعلام عن قائمة جهات الاتصال الخاصة بالمستخدم وتحديثها وإدارتها.

DESCRIPTION

يهدف كائن قائمة جهات الاتصال إلى توفير واجهة سهلة الاستخدام للتفاعل مع قائمة جهات الاتصال الخاصة بالمستخدم. عند إنشائه، يسجل نفسه تلقائيًا مع الاتصال لاستقبال الحزم الصحيحة وكذلك لمواصلة مراقبة جميع التغييرات في قائمة جهات الاتصال وحزم الحضور.

وظائف أساسية

my $Client = Net::XMPP::Client->new(...);
my $Roster = Net::XMPP::Roster->new(connection=>$Client);
  أو
my $Roster = $Client->Roster();
$Roster->clear();
if ($Roster->exists('bob@jabber.org')) { ... }
if ($Roster->exists(Net::XMPP::JID)) { ... }
if ($Roster->groupExists("Friends")) { ... }
my @groups = $Roster->groups();
my @jids    = $Roster->jids();
my @friends = $Roster->jids("group","Friends");
my @unfiled = $Roster->jids("nogroup");
if ($Roster->online('bob@jabber.org')) { ... }
if ($Roster->online(Net::XMPP::JID)) { ... }
my %hash = $Roster->query('bob@jabber.org');
my %hash = $Roster->query(Net::XMPP::JID);
my $name = $Roster->query('bob@jabber.org',"name");
my $ask  = $Roster->query(Net::XMPP::JID,"ask");
my $resource = $Roster->resource('bob@jabber.org');
my $resource = $Roster->resource(Net::XMPP::JID);
my %hash = $Roster->resourceQuery('bob@jabber.org',"Home");
my %hash = $Roster->resourceQuery(Net::XMPP::JID,"Club");
my $show   = $Roster->resourceQuery('bob@jabber.org',"Home","show");
my $status = $Roster->resourceQuery(Net::XMPP::JID,"Work","status");
my @resource = $Roster->resources('bob@jabber.org');
my @resource = $Roster->resources(Net::XMPP::JID);
$Roster->resourceStore('bob@jabber.org',"Home","gpgkey",key);
$Roster->resourceStore(Net::XMPP::JID,"logged on","2004/04/07 ...");
$Roster->store('bob@jabber.org',"avatar",avatar);
$Roster->store(Net::XMPP::JID,"display_name","Bob");

وظائف متقدمة

هذه الوظائف مطلوبة فقط إذا كنت ترغب في التحكم يدويًا في قائمة جهات الاتصال.

$Roster->add('bob@jabber.org',
             name=>"Bob",
             groups=>["Friends"]
            );
$Roster->add(Net::XMPP::JID);
$Roster->addResource('bob@jabber.org',
                     "Home",
                     show=>"dnd",
                     status=>"Working"
                    );
$Roster->addResource(Net::XMPP::JID,"Work");
$Roster->remove('bob@jabber.org');
$Roster->remove(Net::XMPP::JID);
$Roster->removeResource('bob@jabber.org',"Home");
$Roster->removeResource(Net::XMPP::JID,"Work");
$Roster->handler(Net::XMPP::IQ);
$Roster->handler(Net::XMPP::Presence);

METHODS

وظائف أساسية

new
new(connection=>object)

يقوم بإنشاء وتهيئة كائن قائمة جهات الاتصال. كائن الاتصال مطلوب لقائمة جهات الاتصال للتفاعل مع كائن الاتصال الرئيسي. يجب أن يكون كائنًا يرث من Net::XMPP::Connection.

clear
clear()

يمسح كل شيء من قاعدة البيانات.

exists
exists(jid)

يعيد 1 إذا كان JID موجودًا في قاعدة البيانات، وإلا فإنه يعيد undef. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

groupExists
groupExists(group)

يعيد 1 إذا كانت المجموعة موجودة في قاعدة البيانات، وإلا فإنه يعيد undef.

groups
groups()

يعيد قائمة بجميع المجموعات في قائمة جهات الاتصال.

jids
jids([type, [group]])

يعيد قائمة بجميع JIDs المتطابقة. الأنواع الصالحة هي:

all     - يعيد جميع JIDs في قائمة جهات الاتصال. (الافتراضي)
nogroup - يعيد جميع JIDs التي ليست في مجموعة.
group   - يعيد جميع JIDs في المجموعة المحددة.
online
online(jid)

يعيد 1 إذا كان JID متصلاً بالإنترنت، وإلا فإنه يعيد undef. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

query
query(jid, [key])

يعيد hash يمثل جميع معلومات قاعدة البيانات لهذا JID. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID. إذا حددت مفتاحًا، فسيتم إرجاع القيمة لهذا المفتاح فقط.

resource
resource(jid)

يعيد السلسلة النصية التي تمثل المورد ذو الأولوية الأعلى لـ JID. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

resourceQuery
resourceQuery(jid,     
              resource,
              [key])

يعيد hash يمثل جميع معلومات المورد لهذا JID في قاعدة البيانات. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID. إذا حددت مفتاحًا، فسيتم إرجاع القيمة لهذا المفتاح فقط.

resources
resources(jid)

يعيد قائمة الموارد لـ JID بالترتيب من الأعلى أولوية إلى الأقل. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

resourceStore
resourceStore(jid,     
              resource,
              key,     
              value)

يخزن القيمة المحددة في قاعدة البيانات تحت المفتاح المعطى للمورد الخاص بهذا JID. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

store
store(jid, key, value)

يخزن القيمة المحددة في قاعدة البيانات تحت المفتاح المعطى لهذا JID. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

وظائف متقدمة

add(jid, - يضيف JID إلى قائمة جهات الاتصال يدويًا مع خيارات الاستعلام، كما هو محدد في عنصر قائمة جهات الاتصال. لا يتعامل هذا مع الاشتراك في المستخدمين الآخرين، بل يتلاعب بكائن قائمة جهات الاتصال فقط. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

addResource(jid, - يضيف المورد إلى JID في قائمة جهات الاتصال مع خيارات الحضور المحددة. لا يتعامل هذا مع الاشتراك في المستخدمين الآخرين، بل يتلاعب بكائن قائمة جهات الاتصال فقط. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

remove(jid) - يزيل جميع المراجع إلى JID من كائن قائمة جهات الاتصال. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

removeResource(jid, - يزيل المورد من JID في قائمة جهات الاتصال. يمكن أن يكون jid سلسلة نصية أو كائن Net::XMPP::JID.

handler(packet) - يأخذ حزمة من نوع Net::XMPP::IQ أو Net::XMPP::Presence ويقوم بتحليلها وفقًا لقواعد كائن قائمة جهات الاتصال. ملاحظة: سيضيع وقت وحدة المعالجة المركزية فقط إذا قمت بتمرير حزم غير متعلقة بقائمة جهات الاتصال.
