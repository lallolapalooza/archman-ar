Net__DNS__SEC__Private(3pm)

الحزمة: perl-net-dns-sec

التراخيص: PerlArtistic, GPL

Net::DNS::SEC::Private(3) وثائق بيرل المساهمة من المستخدم Net::DNS::SEC::Private(3)

الاسم

Net::DNS::SEC::Private - كائن المفتاح الخاص DNSSEC

الملخص

use Net::DNS::SEC::Private;
$private = Net::DNS::SEC::Private->new( $keypath );
$private = Net::DNS::SEC::Private->new(
    'algorithm'  => '13',
    'keytag'     => '26512',
    'privatekey' => 'h/mc+iq9VDUbNAjQgi8S8JzlEX29IALchwJmNM3QYKk=',
    'signame'    => 'example.com.'
    );

الوصف

فئة تمثل المفاتيح الخاصة كما تُقرأ من ملف مفتاح تم إنشاؤه بواسطة BIND dnssec-keygen. تم كتابة الفئة ليتم استخدامها فقط في سياق الدالة الإنشائية لـ Net::DNS::RR::RRSIG. هذه الفئة ليست مصممة للتفاعل مع أي نظام آخر.

الأساليب

new (من ملف المفتاح الخاص)

$keypath = '/home/foo/Kexample.com.+013+26512.private';
$private = Net::DNS::SEC::Private->new( $keypath );

الوسيط هو المسار الكامل لملف المفتاح الخاص الذي تم إنشاؤه بواسطة أداة BIND dnssec-keygen. لاحظ أن اسم الملف يحتوي على معلومات حول الخوارزمية وعلامة المفتاح.

new (من معلمات المفتاح الخاص)

$private = Net::DNS::SEC::Private->new(
    'algorithm'  => '13',
    'keytag'     => '26512',
    'privatekey' => 'h/mc+iq9VDUbNAjQgi8S8JzlEX29IALchwJmNM3QYKk=',
    'signame'    => 'example.com.'
    );

تحدد الوسائط معلمات المفتاح الخاص كأزواج (اسم، قيمة). الاسم وتمثيل البيانات متطابقان مع ما يُستخدم في ملف مفتاح خاص لـ BIND.

تنسيق المفتاح الخاص

$format = $private->private_key_format;

تُرجع سلسلة تحدد تنسيق ملف المفتاح الخاص.

الخوارزمية، علامة المفتاح، اسم التوقيع

$algorithm = $private->algorithm;
$keytag    = $private->keytag;
$signame   = $private->signame;

تُرجع السمة المقابلة التي تم تحديدها من اسم الملف.

سمات المفتاح الخاص

$attribute = $private->attribute;

تُرجع القيمة كما تظهر في ملف المفتاح الخاص. تتوافق أسماء السمات مع العلامة في ملف المفتاح، مع تعديلها لتشكيل اسم إجراء مقبول في Perl.

تم الإنشاء، النشر، التنشيط

$created  = $private->created;
$publish  = $private->publish;
$activate = $private->activate;

تُرجع سلسلة تمثل تاريخًا بالتنسيق 20141212123456. تُرجع قيمة غير معرفة لتنسيقات المفاتيح الأقدم من v1.3.
