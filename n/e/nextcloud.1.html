الاسم

nextcloud - أداة سطح مكتب لمزامنة الملفات.

الملخص

nextcloud [خيارات...]

الوصف

عميل NextCloud هو أداة سطح مكتب لمزامنة الملفات. يقوم بمزامنة الملفات على جهاز الكمبيوتر المحلي أو الجهاز اللوحي أو الجهاز المحمول الخاص بك مع خادم NextCloud. إذا قمت بإجراء تغيير على الملفات على جهاز واحد، يتم نشر التغيير إلى جميع الأجهزة الأخرى المتزامنة باستخدام عملاء مزامنة سطح المكتب.

عادةً، تبدأ العميل بالنقر على أيقونة سطح المكتب أو بتشغيله من قائمة تطبيقات العميل. بعد البدء، تظهر أيقونة NextCloud في منطقة إشعارات النظام على الكمبيوتر أو على جهازك اللوحي أو المحمول.

الخيارات

لديك خيار تشغيل عميل Nextcloud لسطح المكتب الخاص بك باستخدام الأمر nextcloud. يتم دعم الخيارات التالية:

nextcloud -h أو nextcloud --help
يعرض جميع خيارات الأوامر.

الخيارات الأخرى هي:

--logwindow
يفتح نافذة تعرض مخرجات السجل.
--logfile <اسم الملف>
اكتب مخرجات السجل إلى الملف المحدد. للكتابة إلى stdout، حدد - كاسم للملف.
--logdir <الاسم>
يكتب مخرجات سجل كل مزامنة في ملف جديد في الدليل المحدد.
--logexpire <ساعات>
يزيل السجلات الأقدم من القيمة المحددة (بالساعات). يستخدم هذا الأمر مع --logdir.
--logflush
يمسح (يفرغ) ملف السجل بعد كل إجراء كتابة.
--logdebug
يخرج أيضًا رسائل مستوى التصحيح في السجل (مكافئ لتعيين متغير البيئة QT_LOGGING_RULES="qt.*=true;*.debug=true").
--confdir <اسم الدليل>
يستخدم دليل التكوين المحدد.
--background
تشغيل التطبيق في الخلفية (أي بدون فتح الحوار الرئيسي).

ملف التكوين

يقرأ عميل Nextcloud ملف تكوين. يمكنك تحديد موقع ملف التكوين هذا على النحو التالي:

على توزيعات Linux:
$HOME/.config/Nextcloud/nextcloud.cfg
على أنظمة Microsoft Windows:
%APPDATA%\Nextcloud\nextcloud.cfg
على أنظمة macOS:
$HOME/Library/Preferences/Nextcloud/nextcloud.cfg

يحتوي ملف التكوين على إعدادات باستخدام تنسيق ملف .ini الخاص بـ Microsoft Windows. يمكنك تجاوز التغييرات باستخدام حوار تكوين Nextcloud.

ملاحظة:

توخ الحذر عند إجراء تغييرات على ملف تكوين عميل Nextcloud. يمكن أن تؤدي الإعدادات غير الصحيحة إلى نتائج غير مقصودة.

بعض القيم المثيرة للاهتمام التي يمكن تعيينها في ملف التكوين هي:

قسم [Nextcloud]
المتغير الافتراضي المعنى
remotePollInterval 30000 يحدد وقت الاستطلاع للمستودع البعيد بالمللي ثانية.
forceSyncInterval 7200000 مدة عدم النشاط التي بعد انقضائها سيتم تشغيل مزامنة تلقائيًا.
fullLocalDiscoveryInterval 3600000 الفاصل الزمني الذي بعده ستقوم المزامنة التالية بإجراء اكتشاف محلي كامل.
notificationRefreshInterval 300000 يحدد الفاصل الزمني الافتراضي للتحقق من إشعارات الخادم الجديدة بالمللي ثانية.
قسم [General]
المتغير الافتراضي المعنى
chunkSize 10000000 (10 ميجابايت) يحدد حجم الجزء الخاص بالملفات التي تم تحميلها بالبايت. سيقوم العميل بتعديل هذا الحجم ديناميكيًا ضمن الحدود القصوى والدنيا (انظر أدناه).
forceLoginV2 false إذا كان يجب على العميل فرض تدفق تسجيل الدخول الجديد، حتى لو تطلبت بعض الظروف التدفق القديم.
minChunkSize 5000000 (5 ميجابايت) يحدد الحد الأدنى لحجم الجزء للملفات التي تم تحميلها بالبايت.
maxChunkSize 5000000000 (5000 ميجابايت) يحدد الحد الأقصى لحجم الجزء للملفات التي تم تحميلها بالبايت.
targetChunkUploadDuration 60000 (1 دقيقة) المدة المستهدفة بالمللي ثانية لتحميل الأجزاء. يقوم العميل بتعديل حجم الجزء حتى يستغرق تحميل كل جزء حوالي هذا الوقت. قم بتعيينه إلى 0 لتعطيل تغيير حجم الجزء الديناميكي.
promptDeleteAllFiles false إذا كان يجب أن يطلب حوار واجهة المستخدم تأكيدًا إذا تم اكتشاف حذف جميع الملفات والمجلدات.
timeout 300 مهلة اتصالات الشبكة بالثواني.
moveToTrash false إذا كان يجب نقل الملفات المحذوفة غير المحلية إلى سلة المحذوفات بدلاً من حذفها بالكامل.
showExperimentalOptions false ما إذا كان سيتم عرض الخيارات التجريبية التي لا تزال قيد الاختبار في واجهة المستخدم. تفعيل هذا لا يقوم بتفعيل السلوك التجريبي من تلقاء نفسه. إنه يمكن خيارات واجهة المستخدم التي يمكن استخدامها للاشتراك في الميزات التجريبية.
showMainDialogAsNormalWindow false ما إذا كان يجب عرض الحوار الرئيسي كنافذة عادية حتى لو كانت أيقونات شريط المهام متاحة.

NAME

nextcloud - A simple, fast, self-hosted file sync and share solution.

SYNOPSIS

nextcloud [OPTIONS]

DESCRIPTION

The nextcloud command-line client synchronizes files between a local directory and a Nextcloud server.

OPTIONS

The nextcloud client supports the following options:

--help, -h
Display help message and exit.
--version, -v
Display version information and exit.
--config, -c FILE
Specify an alternative configuration file.
--user, -u USERNAME
Specify the Nextcloud username.
--password, -p PASSWORD
Specify the Nextcloud password.
--remote-path, -r PATH
Specify the remote path on the Nextcloud server.
--local-path, -l PATH
Specify the local path for synchronization.
--sync
Perform a synchronization.
--upload
Upload local files to the Nextcloud server.
--download
Download files from the Nextcloud server to the local directory.
--list
List files on the Nextcloud server.
--status
Display the status of the synchronization.
--daemon
Run the client as a background daemon.
--log LEVEL
Set the logging level (e.g., DEBUG, INFO, WARNING, ERROR).

CONFIG FILE

The configuration file is typically located at ~/.config/nextcloud/nextcloud.cfg. The following options can be set in the configuration file:

Default Meaning
host 127.0.0.1 The address of the proxy server.
port 8080 The port were the proxy is listening.
type 2 0 for System Proxy.
1 for SOCKS5 Proxy.
2 for No Proxy.
3 for HTTP(S) Proxy.
