Net__HTTP__NB(3pm)

الحزمة: perl-net-http

التراخيص: PerlArtistic, GPL

Net::HTTP::NB(3) توثيق من مساهمي المستخدم Perl Net::HTTP::NB(3)

الاسم

Net::HTTP::NB - عميل HTTP غير حاجب

الإصدار

الإصدار 6.24

الملخص

use Net::HTTP::NB;
my $s = Net::HTTP::NB->new(Host => "www.perl.com") || die $@;
$s->write_request(GET => "/");
use IO::Select;
my $sel = IO::Select->new($s);
READ_HEADER: {
   die "Header timeout" unless $sel->can_read(10);
   my($code, $mess, %h) = $s->read_response_headers;
   redo READ_HEADER unless $code;
}
while (1) {
   die "Body timeout" unless $sel->can_read(10);
   my $buf;
   my $n = $s->read_entity_body($buf, 1024);
   last unless $n;
   print $buf;
}

الوصف

نفس الواجهة مثل "Net::HTTP" ولكنها لن تحاول قراءات متعددة أبدًا عند استدعاء الدوال read_response_headers() أو read_entity_body(). هذا يجعل من الممكن تعدد إرسال Net::HTTP::NB متعدد باستخدام select بدون خطر الحجب.

إذا لم ترى read_response_headers() بيانات كافية لإكمال الرؤوس، يتم إرجاع قائمة فارغة.

إذا لم ترى read_entity_body() بيانات كيان جديدة في قراءتها، يتم إرجاع القيمة -1.
