NAME

Net::Config - Interface to the Net configuration files.

SYNOPSIS

    use Net::Config;

    # Get a configuration value
    $value = &get_config_value($attribute);

    # Set a configuration value
    &set_config_value($attribute, $value);

    # Read configuration file
    &read_config_files();

DESCRIPTION

The Net::Config module provides an interface to read and write configuration values from and to the Net configuration files. These files are typically located in /etc/net.

EXPORTS

This module exports the following subroutines:

  • get_config_value
  • set_config_value
  • read_config_files
