ne_add_request_header(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_ADD_REQUEST_HEADE(3) مرجع واجهة برمجة تطبيقات neon NE_ADD_REQUEST_HEADE(3)

الاسم

ne_add_request_header, ne_print_request_header - إضافة رؤوس إلى طلب

الملخص

#include <ne_request.h>

void ne_add_request_header(ne_request *request, const char *name, const char *value);

void ne_print_request_header(ne_request *request, const char *name, const char *format, ...);

الوصف

يمكن استخدام الدالتين ne_add_request_header و ne_print_request_header لإضافة رؤوس إلى طلب، قبل إرساله.

تقوم ne_add_request_header ببساطة بإضافة رأس بالاسم name المعطى، مع القيمة value المعطاة.

تقوم ne_print_request_header بإضافة رأس بالاسم name المعطى، وتأخذ القيمة من المعامل format لسلسلة نصية شبيهة بـ printf وقائمة المتغيرات اللاحقة.
