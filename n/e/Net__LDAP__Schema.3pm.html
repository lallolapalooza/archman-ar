Net__LDAP__Schema(3pm)

الحزمة: perl-ldap

التراخيص: GPL

Net::LDAP::Schema(3) توثيق مساهمة Perl Net::LDAP::Schema(3)

الاسم

Net::LDAP::Schema - تحميل ومعالجة مخطط LDAP v3

ملخص

use Net::LDAP;
use Net::LDAP::Schema;
#
# قراءة المخطط من الخادم
#
$ldap = Net::LDAP->new ( $server );
$ldap->bind ( );
$schema = $ldap->schema ( );
#
# تحميل من LDIF
#
$schema = Net::LDAP::Schema->new;
$schema->parse ( "schema.ldif" ) or die $schema->error;

الوصف

"Net::LDAP::Schema" يوفر طريقة لتحميل مخطط LDAP والاستعلام عن المعلومات المتعلقة بفئات الكائنات والسمات والأنماط المدعومة.

الأساليب

حيث يُشار إلى طريقة بأنها تأخذ اسم أو OID لعنصر مخطط (والذي يمكن أن يكون فئة كائن أو سمة أو نمط)، فيمكنك تقديم اسم أو OID (في شكل معرف كائن، بتنسيق سلسلة رقمية، على سبيل المثال 2.5.4.0) بأحرف كبيرة أو بصيغة سلسلة خام.

كل عنصر مخطط يتم إرجاعه (على سبيل المثال، تعريف سمة) يتم إرجاعه في HASH. مفاتيح HASH هذه هي إصدارات بأحرف صغيرة من المفاتيح المقروءة من الخادم. فيما يلي قائمة جزئية (لا تحدد جميع HASHs جميع المفاتيح)، على الرغم من أنه يجب ملاحظة أن RFC 4512 يسمح بأنواع مفاتيح أخرى أيضًا:

تأخذ وسيطة يمكن أن تكون كائن نتيجة بحث LDAP، أو كائن "Net::LDAP::Entry"، أو اسم ملف يحتوي على تمثيل LDIF للمخطط.

إذا كانت الوسيطة هي نتيجة بحث LDAP، فإن "Net::LDAP::Schema" يحلل المخطط من الإدخال الأول الذي تم إرجاعه.

ترجع صحيحًا في حالة النجاح و "undef" في حالة حدوث خطأ.

matchingrule_for_attribute ( NAME, RULE )
ترجع القاعدة الفعلية مع مراعاة أنواع السمات الفرعية، بالنظر إلى قاعدة مطابقة (مثل "equality"، "substr"، إلخ).
