NAME

Net::LDAP::Control::VLV - تحكم القائمة الافتراضية لـ LDAP (v3)

SYNOPSIS

use Net::LDAP;
use Net::LDAP::Control::VLV;
use Net::LDAP::Constant qw( LDAP_CONTROL_VLVRESPONSE );
$ldap = Net::LDAP->new( "ldap.mydomain.eg" );
# الحصول على أول 20 سجل
$vlv  = Net::LDAP::Control::VLV->new(
          before  => 0,        # عدد السجلات قبل السجل الهدف
          after   => 19,       # 19 سجل بعد السجل الهدف
          content => 0,        # حجم القائمة غير معروف
          offset  => 1,        # السجل الهدف هو الأول
        );
$sort = Net::LDAP::Control::Sort->new( order => 'cn' );
@args = ( base     => "o=Ace Industry, c=us",
          scope    => "subtree",
          filter   => "(objectClass=inetOrgPerson)",
          callback => \&process_entry, # استدعاء هذه الدالة الفرعية لكل سجل
          control  => [ $vlv, $sort ],
);
$mesg = $ldap->search( @args );
# الحصول على تحكم استجابة VLV
($resp)  = $mesg->control( LDAP_CONTROL_VLVRESPONSE )  or die;
$vlv->response( $resp );
# تعيين التحكم للحصول على آخر 20 سجل
$vlv->end;
$mesg = $ldap->search( @args );
# الحصول على تحكم استجابة VLV
($resp)  = $mesg->control( LDAP_CONTROL_VLVRESPONSE )  or die;
$vlv->response( $resp );
# الآن الحصول على الصفحة السابقة
$vlv->scroll_page( -1 );
$mesg = $ldap->search( @args );
# الحصول على تحكم استجابة VLV
($resp)  = $mesg->control( LDAP_CONTROL_VLVRESPONSE )  or die;
$vlv->response( $resp );
# الآن عرض أول سجل يبدأ بحرف "B" في المنتصف
$vlv->before(9);       # تغيير الصفحة لعرض 9 سجلات قبل
$vlv->after(10);       # تغيير الصفحة لعرض 10 سجلات بعد
$vlv->assert("B");     # تأكيد "B"
$mesg = $ldap->search( @args );

الوصف

"Net::LDAP::Control::VLV" يوفر واجهة لإنشاء ومعالجة الكائنات التي تمثل قائمة LDAP الافتراضية كما هو موضح في draft-ietf-ldapext-ldapv3-vlv-09.txt.

عند استخدام تحكم قائمة LDAP الافتراضية في بحث، يجب أن يكون مصحوبًا بتحكم ترتيب. انظر Net::LDAP::Control::Sort.

وسيطات المنشئ

بالإضافة إلى وسيطات المنشئ الموصوفة في Net::LDAP::Control، يتم توفير ما يلي:

after
يحدد عدد السجلات التي سيعيدها الخادم من القائمة بعد السجل الهدف.
assert
يحدد قيمة التأكيد للمستخدم لتحديد السجل الهدف. يجب أن تكون هذه القيمة قيمة قانونية للمقارنة مع السمة الأولى في تحكم الترتيب الذي يتم تمريره مع تحكم VLV. السجل الهدف هو أول سجل في القائمة يكون أكبر من أو يساوي قيمة التأكيد.
before
يحدد عدد السجلات التي سيعيدها الخادم من القائمة قبل السجل الهدف.
content
يحدد عدد السجلات في القائمة. في البحث الأول، يجب تعيين هذه القيمة إلى صفر. في عمليات البحث اللاحقة، يجب تعيينها إلى طول القائمة، كما تم إرجاعه بواسطة تحكم VLVResponse.
context
يحدد معرف السياق. في البحث الأول، يجب تعيين هذه القيمة إلى صفر. في عمليات البحث اللاحقة، يجب تعيينها إلى قيمة السياق التي تم إرجاعها بواسطة تحكم VLVResponse.
offset
يحدد الإزاحة للسجل الهدف.

الأساليب

كما هو الحال مع Net::LDAP::Control، كل وسيطة منشئ موصوفة أعلاه متاحة أيضًا كطريقة للكائن، والتي ستعيد القيمة الحالية للخاصية إذا تم استدعاؤها بدون وسيطات، وستقوم بتعيين قيمة جديدة للخاصية إذا تم تمرير وسيطة إليها.

السمتان "offset" و "assert" متعارضتان. سيؤدي تعيين إحداهما أو الأخرى إلى نسيان القيم التي تم تعيينها سابقًا بواسطة الأخرى. السمة "content" مرتبطة أيضًا بالسمة "offset"، لذا فإن تعيين "assert" سيؤدي إلى نسيان أي قيمة لـ "content".

end
يحدد السجل الهدف إلى آخر إدخال في القائمة. ستقوم هذه الطريقة بتغيير السمتين "before" و "after" بحيث يكون السجل الهدف هو الأخير في الصفحة.
response VLV_RESPONSE
يحدد السمات في التحكم وفقًا لـ VLV_RESPONSE. يجب أن يكون VLV_RESPONSE تحكمًا من نوع Net::LDAP::Control::VLVResponse تم إرجاعه بواسطة الخادم. ستقوم "response" بملء السمات "context" و "offset" و "content" للتحكم بالقيم من VLV_RESPONSE. نظرًا لأن هذا يحدد السمة "offset"، سيتم نسيان أي تعيين سابق للسمة "assert".
scroll NUM
ينقل السجل الهدف بمقدار NUM إدخال. القيمة الموجبة تنقل السجل الهدف نحو نهاية القائمة، والقيمة السالبة نحو البداية. تعيد فهرس السجل الهدف الجديد، أو "undef" إذا كان السجل الحالي محددًا بواسطة تأكيد.

"scroll" يمكن أن تغير السمتين "before" و "after" إذا كانت قيمة الانتقال ستتسبب في خروج الصفحة عن أحد أطراف القائمة. ومع ذلك، سيتم الحفاظ على حجم الصفحة.

scroll_page NUM
ينقل الصفحة بمقدار NUM صفحة. تحسب هذه الطريقة حجم الصفحة الحالي وتستدعي "scroll" مع "NUM * $page_size"
start
يحدد السجل الهدف إلى بداية القائمة. ستقوم هذه الطريقة بتغيير السمتين "before" و "after" بحيث يكون السجل الهدف هو الإدخال الأول في الصفحة.
