Net__Server__Log__Sys__Syslog(3pm)

الحزمة: perl-net-server

التراخيص: PerlArtistic, GPL

Net::Server::Log::Sys::Syslog(3) وثائق Perl مقدمة من المستخدم Net::Server::Log::Sys::Syslog(3)

الاسم

Net::Server::Log::Sys::Syslog - التسجيل عبر Syslog

الملخص

use base qw(Net::Server::PreFork);
__PACKAGE__->run(
    log_file => 'Sys::Syslog',
    syslog_ident => 'myapp',
);

الوصف

توفر هذه الوحدة التسجيل عبر Sys::Syslog لنظام Net::Server.

الإعداد

log_file
لبدء استخدام التسجيل عبر Sys::Syslog، ما عليك سوى تعيين معلمة إعداد Net::Server log_file إلى "Sys::Syslog".

إذا تم استخدام الاسم السحري "Sys::Syslog"، فسيتم إجراء جميع عمليات التسجيل عبر الوحدة Sys::Syslog. إذا تم استخدام syslog، فقد يتم أيضًا تحديد المعلمات "syslog_logsock" و "syslog_ident" و "syslog_logopt" و "syslog_facility".

syslog_logsock
متوفر فقط إذا كانت "log_file" تساوي "Sys::Syslog". قد تكون unix أو inet أو native أو console أو stream أو udp أو tcp، أو مصفوفة من الأنواع لمحاولة. الافتراضي هو "unix" إذا كان إصدار Sys::Syslog < 0.15 - بخلاف ذلك، يكون الافتراضي هو عدم استدعاء setlogsock.

انظر Sys::Syslog.

syslog_ident
متوفر فقط إذا كانت "log_file" تساوي "Sys::Syslog". المعرف الذي سيتم تقديمه على إدخالات syslog. الافتراضي هو "net_server". انظر Sys::Syslog.
syslog_logopt
متوفر فقط إذا كانت "log_file" تساوي "Sys::Syslog". قد تكون صفرًا أو أكثر من "pid" و "cons" و "ndelay" و "nowait". الافتراضي هو "pid". انظر Sys::Syslog.
syslog_facility
متوفر فقط إذا كانت "log_file" تساوي "Sys::Syslog". انظر Sys::Syslog و syslog. الافتراضي هو "daemon".

معلمات افتراضية لـ Net::Server

المعلمات التالية متاحة في الوحدات الافتراضية "Net::Server" أو "Net::Server::Single". (قد تستخدم الشخصيات الأخرى معلمات إضافية وقد لا تستخدم اختياريًا معلمات من الفئة الأساسية.)

Key               Value                    Default
## syslog parameters (if log_file eq Sys::Syslog)
syslog_logsock    (native|unix|inet|udp
                   |tcp|stream|console)    unix (on Sys::Syslog < 0.15)
syslog_ident      "identity"               "net_server"
syslog_logopt     (cons|ndelay|nowait|pid) pid
syslog_facility   \w+                      daemon

الأساليب

"initialize"
يتم استدعاء هذه الطريقة أثناء طريقة initilize_logging الخاصة بـ Net::Server. تقوم بإرجاع مرجع رمز واحد سيتم تخزينه تحت خاصية log_function لكائن Net::Server. يأخذ مرجع الرمز هذا log_level والرسالة كوسائط ويستدعي نظام log4perl المهيأ.
"handle_log_error"
يتم استدعاء هذه الطريقة إذا فشلت log_function لسبب ما. يتم تمرير كائن Net::Server، والخطأ الذي حدث أثناء التسجيل، ومصفوفة تحتوي على مستوى السجل والرسالة. بدوره، يستدعي هذا طريقة Net::Server::handle_syslog_error القديمة.
