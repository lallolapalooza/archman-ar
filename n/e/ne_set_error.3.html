ne_set_error(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_GET_ERROR(3) مرجع واجهة برمجة تطبيقات neon NE_GET_ERROR(3)

الاسم

ne_get_error, ne_set_error - معالجة الأخطاء لجلسات HTTP

الملخص

#include <ne_session.h>

const char *ne_get_error(ne_sesssion *session);

void ne_set_error(ne_sesssion *session, const char *format, ...);

الوصف

يُستخدم سلسلة الخطأ الخاصة بالجلسة لتخزين أي معلومات خطأ قابلة للقراءة بشريًا مرتبطة بأي أخطاء تحدث أثناء استخدام جلسة HTTP.

تقوم الدالة ne_get_error بإرجاع سلسلة الخطأ الحالية للجلسة. تستمر هذه السلسلة فقط حتى يتم تغييرها بواسطة عملية لاحقة على الجلسة. إذا تم تمكين التوطين وقت البناء، وإذا لزم الأمر تمكين وقت التشغيل إذا لزم الأمر باستخدام ne_i18n_init، فقد تكون السلسلة المرجعة قد تمت ترجمتها إلى المنطقة المحلية الحالية للمستخدم.

يمكن استخدام الدالة ne_set_error لتعيين سلسلة خطأ جديدة للجلسة، باستخدام واجهة سلسلة تنسيق بنمط printf.

قيمة الإرجاع

ne_set_error ترجع سلسلة ثابتة منتهية بـ NUL. في المنطقة الإنجليزية الافتراضية، لن تحتوي السلسلة المرجعة على حرف نقطة "." في النهاية.

أمثلة

استرداد سلسلة الخطأ الحالية:

ne_session *sess = ne_session_create(...);
...
printf("Error was: %s\n", ne_get_error(sess));

تعيين سلسلة خطأ جديدة:

ne_session *sess = ne_session_create(...);
...
ne_set_error(sess, "Response missing header %s", "somestring");
