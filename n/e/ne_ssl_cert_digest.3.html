ne_ssl_cert_digest(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_SSL_CERT_CMP(3) مرجع واجهة برمجة تطبيقات neon NE_SSL_CERT_CMP(3)

الاسم

ne_ssl_cert_cmp, ne_ssl_cert_free, ne_ssl_cert_digest, ne_ssl_cert_hdigest, ne_ssl_cert_validity, ne_ssl_cert_validity_time - وظائف للعمل على كائنات الشهادات

الملخص

#include <ne_header.h>

int ne_ssl_cert_cmp(const ne_ssl_certificate *c1, const ne_ssl_certificate *c2);

void ne_ssl_cert_free(ne_ssl_certificate *cert);

int ne_ssl_cert_digest(const ne_ssl_certificate *c1, char *digest);

char *ne_ssl_cert_hdigest(const ne_ssl_certificate *c1, unsigned int flags);

void ne_ssl_cert_validity_time(const ne_ssl_certificate *cert, time_t *from, time_t *until);

void ne_ssl_cert_validity(const ne_ssl_certificate *cert, char *from, char *until);

الوصف

يمكن استخدام الدالة ne_ssl_cert_cmp لمقارنة كائنين من الشهادات؛ وهي تُرجع صفر إذا كانا يشيران إلى نفس الشهادة، وغير صفر إذا لم يكونا كذلك.

يمكن استخدام الدالة ne_ssl_cert_free لتدمير كائن شهادة عندما لا يعود هناك حاجة إليه.

تقوم الدالة ne_ssl_cert_digest بكتابة بصمة إصبع سهلة القراءة كسلسلة منتهية بـ NUL إلى المخزن المؤقت digest المقدم، بالتنسيق "aa:bb...:ff". يجب أن يكون المخزن المؤقت digest بطول NE_SSL_DIGESTLEN على الأقل.

تقوم الدالة ne_ssl_cert_hdigest بإرجاع بصمة إصبع سهلة القراءة لكائن الشهادة. تحدد المعلمة flags خيارات تنسيق التجزئة كما لو تم تمريرها إلى ne_strhash. يتم تخصيص السلسلة المرجعة باستخدام malloc ويجب تحريرها بعد الاستخدام.

تسترجع الدالة ne_ssl_cert_validity_time كلاً من الوقت الذي تبدأ فيه الشهادة بالصلاحية والوقت الذي تنتهي فيه. يتم إرجاع كل وقت عبر المعلمات from و until، والتي يتم كتابتها كـ (time_t)-1 إذا لم يكن أي من الوقتين قابلاً للتمثيل كقيمة time_t. تقوم الدالة ne_ssl_cert_validity بالمثل بكتابة أوقات الصلاحية إلى المخازن المؤقتة للسلاسل النصية المقدمة، باستخدام تنسيق تاريخ نمط RFC 1123 (غير مُوطّن). يجب أن تكون المعلمات الناتجة بطول NE_SSL_VDATELEN على الأقل. يمكن تمرير أي من المعلمات كـ NULL.

قيمة الإرجاع

تُرجع ne_ssl_cert_cmp 0 إذا كانت الشهادات متطابقة، وغير صفر إذا لم تكن كذلك. تُرجع ne_ssl_cert_digest 0 عند النجاح أو قيمة غير صفرية عند حدوث خطأ. القيمة المرجعة لـ ne_ssl_cert_hdigest هي سلسلة مخصصة باستخدام malloc ومنتهية بـ NUL، أو NULL إذا تعذر إنشاء التجزئة.

التاريخ

ne_ssl_cert_hdigest متاحة في neon 0.32.0 والإصدارات الأحدث.
