Net__IPv4Addr(3pm)

الحزمة: perl-net-ipv4addr

التراخيص: GPL, PerlArtistic

IPv4Addr(3) توثيق Perl مقدم من المستخدم IPv4Addr(3)

الاسم

Net::IPv4Addr - امتداد Perl لمعالجة عناوين IPv4.

ملخص

use Net::IPv4Addr qw( :all );
my ($ip,$cidr) = ipv4_parse( "127.0.0.1/24" );
my ($ip,$cidr) = ipv4_parse( "192.168.100.10 / 255.255.255.0" );
my ($net,$msk) = ipv4_network( "192.168.100.30" );
my $broadcast  = ipv4_broadcast( "192.168.100.30/26" );
if ( ipv4_in_network( "192.168.100.0", $her_ip ) ) {
  print "Welcome !";
}
etc.

الوصف

يوفر Net::IPv4Addr وظائف لتحليل عناوين IPv4 بكل من تنسيق العنوان/الشبكة التقليدي وتنسيق CIDR الجديد. توجد أيضًا طرق لحساب عنوان الشبكة وعنوان البث وكذلك للتحقق مما إذا كان عنوان معين ضمن شبكة معينة.

العناوين

تقبل جميع وظائف Net::IPv4Addr العناوين بتنسيقات عديدة. التحليل متساهل جدًا.

سيتم قبول جميع هذه العناوين:

127.0.0.1
192.168.001.010/24
192.168.10.10/255.255.255.0
192.168.30.10 / 21
10.0.0.0 / 255.0.0.0
255.255.0.0

لكن هذه لن يتم قبولها:

272.135.234.0
192.168/16

تقبل معظم الوظائف العنوان وقناع الشبكة أو طول القناع بنفس القيمة العددية أو كقيم منفصلة. وهذا يعني إما

my($ip,$masklength) = ipv4_parse($cidr_str);
my($ip,$masklength) = ipv4_parse($ip_str,$msk_str);

الاستخدام

لا يتم تصدير أي وظائف افتراضيًا. استخدم العلامة ":all" لاستيرادها جميعًا أو استورد صراحةً تلك التي تحتاجها.

الوظائف

ipv4_parse
my ($ip,$msklen) = ipv4_parse($cidr_str);
my $cidr = ipv4_parse($ip_str,$msk_str);
my ($ip) = ipv4_parse($ip_str,$msk_str);

تحليل عنوان IPv4 في سياق قياسي بعنوان بصيغة CIDR وفي سياق مصفوفة بعنوان وطول القناع.

إذا لم تحتوِ المعلمات على قناع شبكة أو طول قناع، ففي السياق القياسي يتم إرجاع عنوان IPv4 فقط، وفي سياق مصفوفة يكون طول القناع غير محدد.

إذا لم تتمكن الوظيفة من تحليل مدخلاتها، فإنها تنهار (croaks). قم بحبسها باستخدام "eval" إذا لم يعجبك ذلك.

ipv4_network
my $cidr = ipv4_network($ip_str);
my $cidr = ipv4_network($cidr_str);
my ($net,$msk) = ipv4_network( $net_str, $msk_str);

في السياق القياسي، تعيد هذه الوظيفة الشبكة بتنسيق CIDR التي يوجد بها العنوان. في سياق مصفوفة، تعيد عنوان الشبكة وطول قناعها كمصفوفة من عنصرين. إذا كان الإدخال هو مضيف بدون قناع شبكة أو طول قناع، فسيتم افتراض قناع الشبكة الافتراضي.

مرة أخرى، تنهار الوظيفة إذا كانت المدخلات غير صالحة.

ipv4_broadcast
my ($broadcast) = ipv4_broadcast($ip_str);
my $broadcast   = ipv4_broadcast($ip_str,$msk_str);

تعيد هذه الوظيفة عنوان البث. إذا لم يحتوِ الإدخال على قناع شبكة أو طول قناع، فسيتم افتراض قناع الشبكة الافتراضي.

تنهار هذه الوظيفة إذا كانت المدخلات غير صالحة.

ipv4_network
my $cidr = ipv4_network($net_str);
my $cidr = ipv4_network($cidr_sstr);
my ($net,$msk) = ipv4_network( $ip_str, $mask_str);

في السياق القياسي، تعيد هذه الوظيفة الشبكة بتنسيق CIDR التي يوجد بها العنوان. في سياق مصفوفة، تعيد عنوان الشبكة وطول قناعها كمصفوفة من عنصرين. إذا كان الإدخال هو مضيف بدون قناع شبكة أو طول قناع، فسيتم افتراض قناع الشبكة الافتراضي.

مرة أخرى، تنهار الوظيفة إذا كانت المدخلات غير صالحة.

ipv4_in_network
print "Yes" if ipv4_in_network( $cidr_str1, $cidr_str2);
print "Yes" if ipv4_in_network( $ip_str1, $mask_str1, $cidr_str2 );
print "Yes" if ipv4_in_network( $ip1, $mask1, $ip2, $msk2 );

تقوم هذه الوظيفة بالتحقق مما إذا كانت الشبكة الثانية محتواة في الشبكة الأولى وتطبق الدلالات التالية:

If net1 or net2 is a magic address (0.0.0.0 or 255.255.255.255)
than this function returns true.
If net1 is an host, net2 will be in the same net only if
it is the same host.
If net2 is an host, it will be contained in net1 only if
it is part of net1.
If net2 is only part of net1 if it is entirely contained in
net1.

تعامل مع المدخلات الخاطئة باستخدام "eval" أو غير ذلك.

ipv4_checkip
if ($ip = ipv4_checkip($str) ) {
    # Do something
}

إرجاع عنوان IPv4 في السلسلة أو undef إذا كانت المدخلات لا تحتوي على عنوان IPv4 صالح.

ipv4_cidr2msk
my $netmask = ipv4_cidr2msk( $cidr );

إرجاع قناع الشبكة المقابل لطول القناع المعطى في المدخلات. كالمعتاد، تنهار الوظيفة إذا لم يعجبها إدخالك (في هذه الحالة رقم بين 0 و 32).

ipv4_msk2cidr
my $masklen = ipv4_msk2cidr( $msk );

إرجاع طول قناع الشبكة للمدخلات. كالمعتاد، تنهار الوظيفة إذا لم يعجبها إدخالك.
