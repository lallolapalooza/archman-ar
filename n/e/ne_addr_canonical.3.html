ne_addr_canonical(3)

الحزمة: neon

التراخيص: LGPL-2.0-or-later

NE_ADDR_RESOLVE(3) مرجع واجهة برمجة تطبيقات neon NE_ADDR_RESOLVE(3)

الاسم

ne_addr_resolve، ne_addr_result، ne_addr_first، ne_addr_next، ne_addr_error، ne_addr_canonical، ne_addr_destroy - وظائف لحل أسماء المضيفين إلى عناوين

الملخص

#include <ne_socket.h>

ne_sock_addr *ne_addr_resolve(const char *hostname، int flags)؛

int ne_addr_result(const ne_sock_addr *addr)؛

const ne_inet_addr *ne_addr_first(ne_sock_addr *addr)؛

const ne_inet_addr *ne_addr_next(ne_sock_addr *addr)؛

char *ne_addr_error(const ne_sock_addr *addr، char *buffer، size_t bufsiz)؛

const char *ne_addr_canonical(const ne_sock_addr *addr)؛

void ne_addr_destroy(ne_sock_addr *addr)؛

الوصف

تقوم الدالة ne_addr_resolve بحل اسم المضيف المحدد hostname، وإرجاع كائن ne_sock_addr يمثل العنوان (أو العناوين) المرتبطة باسم المضيف. يجب أن تكون المعلمة flags صفرًا، أو إذا تم استخدام NE_ADDR_CANON، فسيتم تحديد الاسم القياسي لاسم المضيف.

يمكن أن يكون hostname الذي تم تمريره إلى ne_addr_resolve اسم مضيف DNS (مثل "www.example.com") أو عنوان IPv4 رباعي متقطّع (مثل "192.0.34.72")؛ أو، على الأنظمة التي تدعم IPv6، عنوان IPv6 سداسي عشري، والذي قد يكون محاطًا بأقواس، على سبيل المثال، "[::1]"..

لتحديد ما إذا كان اسم المضيف قد تم حله بنجاح، يتم استخدام الدالة ne_addr_result، والتي تُرجع قيمة غير صفرية إذا حدث خطأ. إذا حدث خطأ، يمكن استخدام الدالة ne_addr_error، والتي ستنسخ سلسلة الخطأ إلى buffer معين (بحجم bufsiz).

تُستخدم الدالتان ne_addr_first و ne_addr_next لاسترداد عناوين الإنترنت المرتبطة بكائن عنوان تم حله بنجاح. تُرجع ne_addr_first العنوان الأول؛ تُرجع ne_addr_next العنوان التالي بعد آخر استدعاء للدالة ne_addr_next أو ne_addr_first، أو NULL إذا لم تكن هناك عناوين أخرى. يمكن تمرير المؤشر ne_inet_addr الذي تُرجعه هاتان الدالتان إلى ne_sock_connect لتوصيل مقبس.

إذا تم استخدام علامة NE_ADDR_CANON مع ne_addr_resolve، يمكن استرداد اسم المضيف القياسي باستخدام ne_addr_canonical.

بعد استخدام كائن العنوان، يجب تدميره باستخدام ne_addr_destroy.

قيمة الإرجاع

تُرجع ne_addr_resolve مؤشرًا إلى كائن عنوان، ولا تُرجع NULL أبدًا. تُرجع ne_addr_error المعلمة buffer.

أمثلة

يطبع الكود أدناه مجموعة العناوين المرتبطة باسم المضيف www.google.com.

ne_sock_addr *addr؛
char buf [256]؛
addr = ne_addr_resolve("www.google.com"، 0)؛
if (ne_addr_result(addr)) {
    printf("Could not resolve www.google.com: %s\n"،
           ne_addr_error(addr, buf, sizeof buf))؛
} else {
    const ne_inet_addr *ia؛
    printf("www.google.com:")؛
    for (ia = ne_addr_first(addr)؛ ia != NULL؛ ia = ne_addr_next(addr)) {
        printf(" %s"، ne_iaddr_print(ia, buf, sizeof buf))؛
    }
    putchar('\n')؛
}
ne_addr_destroy(addr)؛
