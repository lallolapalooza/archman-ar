netconfig(5)

الحزمة: libtirpc

التراخيص: SISSL, BSD-3-Clause

NETCONFIG(5) دليل تنسيقات الملفات NETCONFIG(5)

الاسم

netconfig — قاعدة بيانات تكوين الشبكة

الملخص

/etc/netconfig

الوصف

يحدد ملف netconfig قائمة بـ "أسماء النقل"، واصفًا دلالاتها وبروتوكولها. في FreeBSD، يتم استخدام هذا الملف فقط بواسطة شفرة مكتبة RPC.

تتبع الإدخالات التنسيق التالي:

network_id semantics flags family protoname device libraries

تتكون الإدخالات من الحقول التالية:

network_id
اسم النقل الموصوف.
semantics
يصف دلالات النقل. يمكن أن يكون هذا أحد الخيارات التالية:
tpi_clts
نقل بدون اتصال.
tpi_cots
نقل موجه بالاتصال.
tpi_cots_ord
نقل موجه بالاتصال، بترتيب.
tpi_raw
اتصال خام.
flags
هذا الحقل فارغ (محدد بـ "-")، أو يحتوي على "v"، مما يعني أنه مرئي لدالة getnetconfig(3).
family
عائلة بروتوكول النقل. حاليًا، يمكن أن يكون هذا أحد الخيارات التالية:
inet6
عائلة بروتوكولات IPv6 (PF_INET6).
inet
عائلة بروتوكولات IPv4 (PF_INET).
loopback
عائلة بروتوكول PF_LOCAL.
protoname
اسم البروتوكول المستخدم لهذا النقل. حاليًا يمكن أن يكون إما udp، tcp أو فارغًا.
device
هذا الحقل فارغ دائمًا في FreeBSD.
libraries
هذا الحقل فارغ دائمًا في FreeBSD.

سيحدد ترتيب الإدخالات في هذا الملف أي نقل سيكون مفضلًا بواسطة شفرة مكتبة RPC، بالنظر إلى تطابق نوع شبكة محدد. على سبيل المثال، إذا كان ملف تكوين شبكة نموذجي سيبدو كالتالي:

udp6       tpi_clts      v     inet6    udp     -       -
tcp6       tpi_cots_ord  v     inet6    tcp     -       -
udp        tpi_clts      v     inet     udp     -       -
tcp        tpi_cots_ord  v     inet     tcp     -       -
rawip      tpi_raw       -     inet      -      -       -
local      tpi_cots_ord  -     loopback  -      -       -

udp6

فإن استخدام نوع الشبكة udp في استدعاءات دالة مكتبة RPC (انظر rpc(3)) سيجعل الشفرة تحاول أولاً udp6، ثم udp.

ستقوم getnetconfig(3) والدوال المرتبطة بها بتحليل هذا الملف وإرجاع هياكل بالتنسيق التالي:

struct netconfig {
    char *nc_netid;              /* Network ID */
    unsigned long nc_semantics;  /* Semantics (see below) */
    unsigned long nc_flag;       /* Flags (see below) */
    char *nc_protofmly;          /* Protocol family */
    char *nc_proto;              /* Protocol name */
    char *nc_device;             /* Network device pathname (unused) */
    unsigned long nc_nlookups;   /* Number of lookup libs (unused) */
    char **nc_lookups;           /* Names of the libraries (unused) */
    unsigned long nc_unused[9];  /* reserved */
};
