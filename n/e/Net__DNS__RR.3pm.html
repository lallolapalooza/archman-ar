Net::DNS::RR(3) وثائق مقدمة من مستخدمي Perl Net::DNS::RR(3)

الاسم

Net::DNS::RR - الفئة الأساسية لسجلات أسماء DNS (RR)

ملخص

use Net::DNS;
$rr = Net::DNS::RR->new('example.com IN AAAA 2001:DB8::1');
$rr = Net::DNS::RR->new(
                owner   => 'example.com',
                type    => 'AAAA',
                address => '2001:DB8::1'
                );

الوصف

Net::DNS::RR هي الفئة الأساسية لكائنات سجلات أسماء DNS (RR). انظر أيضًا صفحات الوثائق لكل نوع سجل RR محدد.

الطرق

تحذير!!! لا تفترض أن كائنات RR التي تتلقاها من استعلام هي من نوع معين. يجب عليك دائمًا التحقق من نوع الكائن قبل استدعاء أي طريقة. إذا قمت باستدعاء طريقة غير معروفة، فستتلقى رسالة خطأ وسيتم إنهاء المنفذ.

جديد (من سلسلة)

$aaaa   = Net::DNS::RR->new('host.example.com. 86400 AAAA 2001:DB8::1');
$mx     = Net::DNS::RR->new('example.com. 7200 MX 10 mailhost.example.com.');
$cname  = Net::DNS::RR->new('www.example.com 300 IN CNAME host.example.com');
$txt    = Net::DNS::RR->new('txt.example.com 3600 HS TXT "text data"');

تُرجع كائن RR من النوع المناسب، أو كائن Net::DNS::RR إذا لم يكن النوع منفذًا. يتم استخراج قيم السمات من السلسلة المقدمة من المستخدم. يتبع بناء جملة الوسيط مواصفات RFC1035 لملفات المنطقة وهو متوافق مع المخرجات التي تم إرجاعها بواسطة طريقة السلسلة.

المالك ونوع RR إلزامي؛ كل شيء آخر اختياري. يعد تخطي الحقول الاختيارية مفيدًا لإنشاء أقسام بيانات فارغة مطلوبة لبعض عمليات التحديث الديناميكي. انظر صفحة وثائق Net::DNS::Update للحصول على أمثلة إضافية.

يتم تفسير جميع الأسماء كأسماء نطاقات مؤهلة بالكامل. النقطة النهائية (.) اختيارية.

جديد (من هاش)

$rr = Net::DNS::RR->new(%hash);
$rr = Net::DNS::RR->new(
                owner   => 'host.example.com',
                ttl     => 86400,
                class   => 'IN',
                type    => 'AAAA',
                address => '2001:DB8::1'
                );

$rr = Net::DNS::RR->new(
                owner   => 'txt.example.com',
                type    => 'TXT',
                txtdata => [ 'one', 'two' ]
                );

تُرجع كائن RR من النوع المناسب، أو كائن Net::DNS::RR إذا لم يكن النوع منفذًا. راجع صفحات الوثائق المقابلة لاستخدام السمات الخاصة بالنوع.

المالك ونوع RR إلزامي؛ كل شيء آخر اختياري. يعد تخطي السمات الاختيارية مفيدًا لإنشاء أقسام بيانات فارغة مطلوبة لبعض عمليات التحديث الديناميكي.

فك التشفير

( $rr, $next ) = Net::DNS::RR->decode( \$data, $offset, @opaque );

يقوم بفك تشفير سجل اسم (RR) في الموضع المحدد داخل حزمة DNS.

يتكون الوسيط من مرجع إلى المخزن المؤقت الذي يحتوي على بيانات الحزمة وإزاحة تشير إلى مكان بدء سجل الاسم (RR). يتم تمرير أي وسائط متبقية كبيانات غير شفافة إلى مفكات التشفير التابعة ولا تشكل جزءًا من الواجهة العامة.

تُرجع كائن "Net::DNS::RR" وإزاحة السجل التالي في الحزمة.

يتم إطلاق استثناء إذا كان المخزن المؤقت للبيانات يحتوي على بيانات غير كافية أو تالفة.

تشفير

$data = $rr->encode( $offset, @opaque );

تُرجع التنسيق الثنائي "Net::DNS::RR" المناسب لتضمينه في مخزن مؤقت لحزمة DNS.

تشير الإزاحة إلى الموضع المطلوب داخل بيانات الحزمة حيث يجب تخزين "Net::DNS::RR".

يتم تمرير أي وسائط متبقية كبيانات غير شفافة بشكل كامل إلى المشفرات التابعة.

القياسي

$data = $rr->canonical;

تُرجع التنسيق الثنائي "Net::DNS::RR" المناسب للتحقق من صحة توقيعات DNSSEC.

يشير عدم وجود وسيط اقتران إلى المشفرات التابعة أنه سيتم استخدام الشكل غير المضغوط لاسم النطاق المضمن.

طباعة

$rr->print;

يطبع سجل الاسم (RR) إلى ملف الإخراج الحالي. يستدعي طريقة السلسلة للحصول على التمثيل المنسق لـ RR.

سلسلة

print $rr->string, "\n";

تُرجع تمثيل سلسلة لـ RR باتباع تنسيق ملف المنطقة الذي يفرضه RFC1035. يتم تفسير جميع أسماء النطاقات كأسماء مؤهلة بالكامل مع نقطة نهاية. هذا يختلف عن طرق سمات RR، التي تتجاهل النقطة النهائية.

واضح

$plain = $rr->plain;

تُرجع تمثيل مبسط من سطر واحد لـ RR. هذا يسهل التفاعل مع البرامج مثل nsupdate التي لديها محللات أساسية.

رمز

@token = $rr->token;

تُرجع قائمة رموز تمثل سلسلة ملف المنطقة.

عام

$generic = $rr->generic;

تُرجع التمثيل العام لـ RR المحدد في RFC3597. هذا يسهل إنشاء ملفات منطقة مع RR غير معروفة بواسطة الخوادم القديمة وبرامج التزويد.

اسم المالك

$name = $rr->owner;

تُرجع اسم مالك السجل.

النوع

$type = $rr->type;

تُرجع نوع السجل.

الفئة

$class = $rr->class;

فئة سجل الاسم (RR).

ttl

$ttl = $rr->ttl;
$ttl = $rr->ttl(3600);

وقت انتهاء صلاحية سجل الاسم (RR) بالثواني.

rdata

$rr = Net::DNS::RR->new( type => NULL, rdata => 'arbitrary' );

قسم بيانات RR عند النظر إليه كبايتات غير مضغوطة.

سلسلة بيانات RR

$rdstring = $rr->rdstring;

تُرجع تمثيل سلسلة لبيانات RR المحددة.

طول بيانات RR

$rdlength = $rr->rdlength;

تُرجع الطول غير المضغوط لبيانات RR المحددة.

فرز مصفوفات RR

يتم فرز مصفوفات RR باستخدام Net::DNS::rrsort()، انظر وثائق Net::DNS. توفر هذه الحزمة طرق فئة لتعيين وظيفة المقارنة المستخدمة لـ RR معين بناءً على سماته.

تعيين وظيفة فرز RR

my $function = sub {    ## فرز رقمي تصاعدي
        $Net::DNS::a->{'preference'} <=> $Net::DNS::b->{'preference'};
        };
Net::DNS::RR::MX->set_rrsort_func( 'preference', $function );
Net::DNS::RR::MX->set_rrsort_func( 'default_sort', $function );

يجب استدعاء set_rrsort_func() كطريقة فئة. الوسيط الأول هو اسم السمة التي سيتم الفرز عليها. إذا قمت بتحديد "default_sort"، فسيتم استخدام خوارزمية الفرز هذه عند استدعاء get_rrsort_func() بدون وسيط سمة RR.

الوسيط الثاني هو مرجع إلى وظيفة مقارنة تستخدم المتغيرات العامة $a و $b.

Net::DNS::RR::MX(3pm) — Perl net-dns documentation

NAME

Net::DNS::RR::MX — MX resource record

SYNOPSIS

    use Net::DNS;
    use Net::DNS::RR::MX;

    my $rr = Net::DNS::RR::MX->new(
        name     => 'example.com.',
        type     => 'MX',
        ttl      => 3600,
        preference => 10,
        exchange => 'mail.example.com.',
    );

    print $rr->name, "\t", $rr->type, "\t", $rr->preference, "\t", $rr->exchange, "\n";

DESCRIPTION

The Net::DNS::RR::MX class represents an MX resource record.

MX records are used to specify mail exchanges for a domain name.

METHODS

This class inherits methods from the Net::DNS::RR class.

preference
The preference value for the mail exchange. Lower values indicate higher preference.
exchange
The hostname of the mail exchange server.

Sorting of RR arrays

An MX RR array can be sorted by preference using the sort_rrs() method in the Net::DNS::RR class. sort_rrs() takes a reference to an array of Net::DNS::RR objects. The objects are sorted in place.

You can customize the sorting algorithm by passing a subroutine reference to the sort_rrs() method. The subroutine will be called with two arguments, $a and $b. These arguments will be references to objects of the class whose set_rrsort_func() was called. The above sorting function will only be applied to Net::DNS::RR::MX objects.

The above example is the sorting function implemented in MX.

get_rrsort_func

$function = Net::DNS::RR::MX->get_rrsort_func('preference');
$function = Net::DNS::RR::MX->get_rrsort_func();

get_rrsort_func() returns a reference to the comparator function.

المثال أعلاه هو دالة الفرز المطبقة في MX.
