Net__Jabber__Protocol(3pm)

الحزمة: perl-net-jabber

التراخيص: GPL, PerlArtistic

Net::Jabber::Protocol(3) توثيق Perl مقدم من المستخدم Net::Jabber::Protocol(3)

الاسم

Net::Jabber::Protocol - مكتبة بروتوكول Jabber

الملخص

Net::Jabber::Protocol هي وحدة توفر للمطور وصولاً سهلاً إلى بروتوكول Jabber للمراسلة الفورية. إنها توفر وظائف عالية المستوى لكائنات Net::Jabber Client و Component و Server. يتم تضمين هذه الوظائف تلقائيًا في تلك الوحدات من خلال AUTOLOAD والوفود.

الوصف

يسعى Protocol.pm إلى توفير واجهات برمجة تطبيقات عالية المستوى بما يكفي وأتمتة لواجهات برمجة التطبيقات المنخفضة المستوى بحيث يكون كتابة عميل/ناقل Jabber في Perl أمرًا بسيطًا. بالنسبة لأولئك الذين يرغبون في العمل مع المستوى المنخفض، يمكنك القيام بذلك أيضًا، ولكن هذه الوظائف مغطاة في وثائق كل وحدة.
توفر Net::Jabber::Protocol وظائف لتسجيل الدخول، وإرسال واستقبال الرسائل، وتعيين المعلومات الشخصية، وإنشاء حساب مستخدم جديد، وإدارة قائمة الاتصال، وتسجيل الخروج. يمكنك استخدام كل الوظائف أو لا شيء منها، لا يوجد شرط.
لمزيد من المعلومات حول كيفية كتابة Net::Jabber، يرجى الرجوع إلى المساعدة الخاصة بـ Net::Jabber نفسها.
لمزيد من المعلومات حول كتابة عميل، راجع Net::Jabber::Client.
لمزيد من المعلومات حول كتابة ناقل، راجع Net::Jabber::Transport.

الأنماط

تأخذ العديد من الوظائف وسيط نمط يسمح لك بتحديد كيفية سلوك الوظيفة:
  block - إرسال الحزمة بمعرف، ثم الحظر حتى تأتي استجابة. يمكنك اختياريًا تحديد مهلة حتى لا تحظر إلى الأبد.

  nonblock - إرسال الحزمة بمعرف، ثم إرجاع هذا المعرف والتحكم إلى البرنامج الرئيسي. لا تزال Net::Jabber تتعقب هذه الحزمة، لذلك يجب عليك استخدام وظيفة CheckID لمعرفة متى تأتي. (قد لا يكون هذا مفيدًا جدًا...)
  passthru - إرسال الحزمة بمعرف، ولكن لا تقم بتسجيلها في Net::Jabber، ثم إرجاع المعرف. هذا مفيد عند دمجه مع وظيفة XPath لأنك يمكنك تسجيل وظيفة ذات مرة واحدة مرتبطة بالمعرف الذي تحصل عليه.

NAME

Net::Jabber::Protocol - Protocol-specific methods for Net::Jabber

SYNOPSIS

 use Net::Jabber::Protocol;

 my $proto = Net::Jabber::Protocol->new($host, $port);

 # Example usage - see METHODS section for details
 my $hashref = $proto->SearchRequest(to => 'user@example.com');
 $proto->SearchSend(to => 'user@example.com', hash => $hashref);

 my $time = $proto->TimeQuery(to => 'user@example.com', mode => 'block');
 print "Current time at user@example.com is: ", $time->{display}, "\n";
 $proto->TimeSend(to => 'user@example.com');

 my $version = $proto->VersionQuery(to => 'user@example.com', mode => 'block');
 print "User $version->{name} ($version->{os}) is running version $version->{ver}\n";
 $proto->VersionSend(to => 'user@example.com', name => 'MyBot', ver => '0.1', os => 'Linux');

DESCRIPTION

This module implements the various XMPP protocols that Net::Jabber supports. This module is typically not used directly, but rather through the Net::Jabber module. The methods defined here are separated into different groups: Search, Time, and Version.

METHODS

Search Functions

SearchRequest(to=>string,  - Send an <iq/> request to the specified
              mode=>string,  server/transport, if not specified it
              timeout=>int)  sends to the current active server.
SearchRequest()              The function returns a hash that
                             contains the required fields.   Here
                             is an example of the hash:
                             $hash{fields}    - The raw fields from
                                                the iq:register.  To
                                                be used if there is
                                                no x:data in the
                                                packet.
                             $hash{instructions} - How to fill out
                                                   the form.
                             $hash{form}   - The new dynamic forms.
                             In $hash{form}, the fields that are
                             present are the required fields the
                             server needs.

                             See MODES above for using the mode
                             and timeout.
SearchSend(to=>string|JID, - Takes the contents of the hash and
           hash)             passes it to the SetSearch function
                             in the Net::Jabber::Query
                             jabber:iq:search namespace.  And then
                             sends the packet.
SearchSendData(string|JID, - Takes the contents of the hash and
               hash)         builds a jabber:x:data return packet
                             which it sends in a Net::Jabber::Query
                             jabber:iq:search namespace packet.
                             The first argument is the JID to send
                             the packet to.

Time Functions

TimeQuery(to=>string,     - Asks the JID specified for its localtime.
          mode=>string,     If the to is blank, then it queries the
          timeout=>int)     server.  Returns a hash with the various
TimeQuery()                 items set if mode is set to "block":
                              $time{utc}     - Time in UTC
                              $time{tz}      - Timezone
                              $time{display} - Display string
                            See MODES above for using the mode
                            and timeout.
TimeSend(to=>string) - Sends the current UTC time to the specified
                       JID.

Version Functions

VersionQuery(to=>string,     - Asks the JID specified for its
             mode=>string,     client version information.  If the
             timeout=>int)     to is blank, then it queries the
VersionQuery()                 server.  Returns a hash with the
                               various items set if mode is set to
                               "block":
                                 $version{name} - Name
                                 $version{ver}  - Version
                                 $version{os}   - Operating System/
                                                    Platform
                              See MODES above for using the mode
                              and timeout.
VersionSend(to=>string,   - Sends the specified version information
            name=>string,   to the JID specified in the to.
            ver=>string,
            os=>string)
