Net::DBus::Binding::Message::Signal(3) وثائق Perl المقدمة من المستخدم Net::DBus::Binding::Message::Signal(3)

الاسم

Net::DBus::Binding::Message::Signal - رسالة تشفير إشارة

ملخص

use Net::DBus::Binding::Message::Signal;
my $signal = Net::DBus::Binding::Message::Signal->new(
    object_path => "/org/example/myobject",
    interface => "org.example.myobject",
    signal_name => "foo_changed");
$connection->send($signal);

الوصف

هذه الوحدة هي جزء من واجهات الربط منخفضة المستوى لـ DBus، ولا ينبغي استخدامها من قبل كود التطبيق. لا يتم تقديم أي ضمانات بشأن استقرار الواجهات تحت اسم الفضاء "Net::DBus::Binding::" عبر الإصدارات.

توفر هذه الوحدة مُنشئًا مساعدًا لإنشاء رسالة تمثل إشارة.

الطرق

my $signal = Net::DBus::Binding::Message::Signal->new( object_path => $path, interface => $interface, signal_name => $name);
ينشئ رسالة جديدة، تمثل إشارة [سيتم] بثها بواسطة الكائن الموجود تحت المسار المعطى بالمعامل "object_path". اسم الإشارة معطى بالمعامل "signal_name"، وهو مقيد بالواجهة المعطاة بالمعامل "interface".
