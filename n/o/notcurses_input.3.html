NAME

notcurses_input - input via notcurses

SYNOPSIS

#include <notcurses/notcurses.h>

struct timespec;
struct notcurses;
typedef enum {
  NCTYPE_UNKNOWN,
  NCTYPE_PRESS,
  NCTYPE_REPEAT,
  NCTYPE_RELEASE,
} ncintype_e;
// An input event. Cell coordinates are currently defined only for mouse
// events. It is not guaranteed that we can set the modifiers for a given
// ncinput. We encompass single Unicode codepoints, not complete EGCs.
// FIXME for abi4, combine the bools into |modifiers|
typedef struct ncinput {
  uint32_t id;       // Unicode codepoint or synthesized NCKEY event
  int y, x;          // y/x cell coordinate of event, -1 for undefined
  char utf8[5];      // utf8 representation, if one exists
  // DEPRECATED do not use! going away in 4.0
  bool alt;          // was alt held?
  bool shift;        // was shift held?
  bool ctrl;         // was ctrl held?
  // END DEPRECATION
  ncintype_e evtype;
  unsigned modifiers;// bitmask over NCKEY_MOD_*
  int ypx, xpx;      // pixel offsets within cell, -1 for undefined
  uint32_t eff_text[5];  // Effective utf32 representation, taking 
                     // modifier keys into account. This can be multiple
                     // codepoints. Array is zero-terminated.
} ncinput;
#define NCMICE_NO_EVENTS     0
#define NCMICE_MOVE_EVENT    0x1
#define NCMICE_BUTTON_EVENT  0x2
#define NCMICE_DRAG_EVENT    0x4
#define NCMICE_ALL_EVENTS    0x7

int notcurses_mice_disable(struct notcurses* n);

int notcurses_inputready_fd(struct notcurses* n);

static inline bool ncinput_equal_p(const ncinput* n1, const ncinput* n2);

int notcurses_linesigs_disable(struct notcurses* n);

DESCRIPTION

notcurses supports input from keyboards and mice, and any device that looks like them. Mouse support requires a broker such as GPM, Wayland, or Xorg, and must be explicitly enabled via notcurses_mice_enable. The full 32-bit range of Unicode is supported (see unicode(7)), with synthesized events mapped above the 1,114,112 codepoints of Unicode 14.0's seventeen Planes. Unicode characters are returned directly as UCS-32, one codepoint at a time. When the input has a UTF8 representation, it is written to utf8; this field is always NUL-terminated.

notcurses takes its keyboard input from stdin, which will be placed into non-blocking mode for the duration of operation. The terminal is put into non-canonical mode (see termios(3)), and thus keys are received without line-buffering. notcurses maintains its own buffer of input characters, which it will attempt to fill whenever it reads.

notcurses_get allows a struct timespec to be specified as a timeout. If ts is NULL, notcurses_get will block until it reads input, or is interrupted by a signal. If its values are zeroes, there will be no blocking. Otherwise, ts specifies an absolute deadline (taken against CLOCK_MONOTONIC; see clock_gettime(2)). On timeout, 0 is returned. Event details will be reported in ni, unless ni is NULL.

notcurses_inputready_fd provides a file descriptor suitable for use with I/O multiplexors such as poll(2). This file descriptor might or might not be the actual input file descriptor. If it readable, notcurses_get can be called without the possibility of blocking.

ncinput_equal_p compares two ncinput structs for data equality (i.e. not considering padding), returning true if they represent the same input (though not necessarily the same input event). Note that NCTYPE_UNKNOWN and NCTYPE_PRESS are considered equivalent for the purposes of ncinput_equal_p.

notcurses_linesigs_disable disables conversion of inputs INTR, QUIT, SUSP, and DSUSP into SIGINT, SIGQUIT, and SIGTSTP. These conversions are enabled by default. notcurses_linesigs_enable undoes this action, but signals in the interim are permanently lost.

ncinput_shift_p, ncinput_ctrl_p, ncinput_alt_p, and ncinput_meta_p test n to see if the relevant modifier is set. This is preferably to directly accessing the struct members.

Mice

For mouse events, the additional fields y, x, ypx, and xpx are set. These fields are not meaningful for keypress events. Mouse events can be distinguished using the nckey_mouse_p predicate. NCMICE_MOVE_EVENT requests events whenever the mouse moves when no buttons are held down. NCMICE_DRAG_EVENT requests events when the mouse is moving with buttons held down. NCMICE_BUTTON_EVENT requests events then the button state changes. NCMICE_ALL_EVENTS is provided for convenience and future-proofing against API (though not ABI) changes.

Synthesized keypresses

Many keys do not have a Unicode representation, let alone ASCII. Examples include the modifier keys (Alt, Meta, etc.), the "function" keys, and the arrow keys on the numeric keypad. The special keys available to the terminal are defined in the terminfo(5) entry, which notcurses loads on startup. Upon receiving an escape code matching a terminfo input capability, notcurses synthesizes a special value. An escape sequence must arrive in its entirety to notcurses; running out of input in the middle of an escape sequence will see it rejected. Likewise, any error while handling an escape sequence will see the lex aborted, and the sequence thus thus far played back as independent literal keystrokes.

The full list of synthesized keys (there are well over one hundred) can be found in <notcurses/notcurses.h>. For more details, consult terminfo(5).

NCKEY_RESIZE

Unless the SIGWINCH handler has been inhibited (see notcurses_init), Notcurses will automatically catch screen resizes, and synthesize an NCKEY_RESIZE event. Upon receiving this event, the user may call notcurses_refresh to force an immediate reflow, or just wait until the next call to notcurses_render, when notcurses will pick up the resize itself. If the SIGWINCH handler is inhibited, NCKEY_RESIZE is never generated.

NCKEY_SIGNAL

Unless the SIGWINCH handler has been inhibited (see notcurses_init), Notcurses will catch SIGCONT

الوصف

تُستخدم هذه الوظائف لجلب مدخلات المستخدم من الجهاز الطرفي. يمكن أن تكون هذه المدخلات عبارة عن مدخلات لوحة مفاتيح، أو أحداث فأرة، أو أحداث مُصطنعة.

تقوم notcurses_get بقراءة مدخل واحد. إذا تم توفير `target`، يتم تخزين الرمز الخاص بـ Unicode أو الحدث المُصطنع فيه. إذا لم يتم توفير `target`، يتم تجاهل القيمة. ترجع الوظيفة قيمة غير صفرية عند النجاح، و 0 عند انتهاء المهلة، و -1 عند حدوث خطأ.

تقوم notcurses_getvec بقراءة ما يصل إلى `maxread` من مدخلات المستخدم وتخزينها في الصفيف `targets`. ترجع عدد المدخلات التي تم قراءتها، أو 0 عند انتهاء المهلة، أو -1 عند حدوث خطأ.

تقوم notcurses_input_sample بإرجاع عينة من المدخلات المتوفرة دون استهلاكها.

تقوم notcurses_input_prev بإرجاع آخر مدخل تم استهلاكه.

تقوم notcurses_input_poll بقراءة المدخلات المتوفرة في المخزن المؤقت دون حظر. ترجع عدد المدخلات التي تم قراءتها، أو 0 إذا لم تكن هناك مدخلات متوفرة، أو -1 عند حدوث خطأ.

تقوم notcurses_input_peek بفحص المدخلات المتوفرة دون استهلاكها. ترجع عدد المدخلات التي تم فحصها، أو 0 إذا لم تكن هناك مدخلات متوفرة، أو -1 عند حدوث خطأ.

تقوم notcurses_input_available_p بإرجاع `true` إذا كانت هناك مدخلات متاحة، و `false` بخلاف ذلك.

تقوم notcurses_input_set_defunct بتعيين حالة "معطل" لمكدس الإدخال. عندما يكون معطلاً، يتم تجاهل جميع المدخلات المستقبلية.

تقوم notcurses_input_defunct_p بإرجاع `true` إذا كان مكدس الإدخال معطلاً، و `false` بخلاف ذلك.

تقوم notcurses_input_get_fd بإرجاع واصف الملف الذي يمكن استخدامه للاستعلام عن جاهزية الإدخال.

تقوم notcurses_mice_enable بتمكين أحداث الفأرة المحددة بواسطة `enabled_mask`. يجب أن تكون القيمة `~0ULL` لتمكين جميع أحداث الفأرة.

تقوم notcurses_mice_disable بتعطيل أحداث الفأرة المحددة بواسطة `disabled_mask`.

تقوم ncinput_equal_p بإرجاع `true` إذا كان كائن `ncinput` متساويين.

تقوم ncinput_shift_p و ncinput_alt_p و ncinput_meta_p و ncinput_numlock_p و ncinput_capslock_p و ncinput_scrolllock_p و ncinput_ctrl_p و ncinput_real_p و ncinput_effective_p بإرجاع `true` إذا كانت المفاتيح أو الأزرار المقابلة مضغوطة.

تقوم ncinput_id بإرجاع الرمز الخاص بـ Unicode أو الحدث المُصطنع.

تقوم ncinput_seq بإرجاع رقم تسلسلي فريد لكل حدث إدخال.

تقوم ncinput_egid بإرجاع المعرف الفريد للحدث (مفيد للتمييز بين أحداث الإدخال المتطابقة).

تقوم ncinput_eff_rows و ncinput_eff_cols بإرجاع الأبعاد الفعالة للإدخال (مفيد لأحداث الفأرة).

تقوم ncinput_eff_text بإرجاع النص الفعال للمدخل (مثل الأحرف الكبيرة أو الصغيرة).

تقوم ncinput_eff_modifiers بإرجاع قناع بت لجميع المعدلات المضغوطة.

تقوم ncinput_eff_type بإرجاع نوع الحدث.

تقوم ncinput_eff_mousebtn بإرجاع أزرار الفأرة المضغوطة.

تقوم ncinput_eff_y و ncinput_eff_x بإرجاع إحداثيات الفأرة.

تقوم ncinput_eff_ypx و ncinput_eff_xpx بإرجاع إحداثيات الفأرة بالبكسل.

في حالة إعادة بناء الشاشة الكاملة، يتم إرسال حدث NCKEY_RESIZE. هذا يشير عادةً إلى أن البرنامج قد أعيد تشغيله بعد الإيقاف المؤقت أو وضعه في الخلفية. سيكون عملية التجسيم التالية إعادة بناء كاملة للشاشة، كما لو تم استدعاء notcurses_refresh؛ قد يرغب المستخدم في استدعاء notcurses_refresh بأنفسهم فوراً.

NCKEY_EOF

عند الوصول إلى نهاية الإدخال، سيتم إرجاع NCKEY_EOF. عند هذه النقطة، ستعيد أي استدعاءات لاحقة NCKEY_EOF على الفور. لاحظ أن هذا لا ينتج بالضرورة عن الضغط على Ctrl+D على سبيل المثال.

قيم الإرجاع

عند حدوث خطأ، تُرجع عائلة وظائف get القيمة (uint32_t)-1. يمكن تحديد سبب الخطأ باستخدام errno(3). ما لم يكن الخطأ مؤقتًا (خاصةً مثل EINTR)، فمن المحتمل أن notcurses_get لا يمكن استدعاؤها بشكل مفيد على الفور. عند انتهاء المهلة، يتم إرجاع 0. بخلاف ذلك، يتم إرجاع قيمة UCS-32 لنقطة رمز Unicode، أو حدث مُصطنع.

إذا تم اكتشاف خطأ قبل أن تقرأ notcurses_getvec أي مدخلات، فسترجع -1. إذا انتهت مهلتها قبل قراءة أي مدخلات، فسترجع 0. بخلاف ذلك، تُرجع عدد كائنات ncinput التي تم كتابتها.

تُرجع notcurses_mice_enable القيمة 0 عند النجاح، وقيمة غير صفرية عند الفشل، وكذلك notcurses_mice_disable. النجاح لا يعني بالضرورة توفر فأرة ولا أن جميع الأحداث المطلوبة سيتم إنشاؤها.

تُرجع ncinput_equal_p القيمة `true` إذا كان هيكلا ncinput يمثلان نفس الإدخال (ولكن ليس بالضرورة نفس حدث الإدخال)، و `false` بخلاف ذلك.

ملاحظات

مثل أي وظيفة أخرى في notcurses، يعتبر من الخطأ استدعاء notcurses_get أثناء أو بعد استدعاء notcurses_stop. إذا كان خيط يظل دائمًا في انتظار مدخلات محظورة، فقد يكون من الصعب ضمان عدم حدوث ذلك.

يمكن لخيط واحد فقط استدعاء مكدس الإدخال في وقت واحد، ولكن على عكس جميع الوظائف الأخرى تقريبًا في notcurses، يمكن استدعاء notcurses_get ووظائفها المساعدة بالتزامن مع notcurses_render.

لا تستخدم poll ببساطة واصف الملف المرتبط بـ stdin لاختبار جاهزية الإدخال. بدلاً من ذلك، استخدم واصف الملف الذي تم إرجاعه بواسطة notcurses_inputready_fd لضمان التوافق مع الإصدارات المستقبلية من Notcurses (من الممكن أن تعالج الإصدارات المستقبلية الإدخال في سياقاتها الخاصة).

القائمة الكاملة للأحداث المُصطنعة متاحة في <notcurses/nckeys.h>.

في API4، ستختفي حقول المعدلات المختلفة من نوع bool، وسيتم دمج هذه الحالات في قناع البت modifiers. يتم تشجيعك على استخدام ncinput_shift_p ووظائفها المماثلة لجعل كودك متوافقًا مع المستقبل.

أخطاء

تحاول Notcurses استخدام بروتوكولات XTMODKEYS و Kitty لتفسير لوحة المفاتيح. عند دعمها، فإنها تقضي على معظم هذه المشكلات.

لا يتم الإشارة تقليديًا إلى مفتاح Shift بالاقتران مع نص Unicode النموذجي. إذا تم استخدام Shift، على سبيل المثال، لإنشاء حرف كبير 'A'، فسيكون id مساويًا لـ 'A'، وسيكون shift هو false. وبالمثل، عند الضغط على Ctrl مع حرف، سيتم دائمًا الإبلاغ عن الحرف بحالته الكبيرة. على سبيل المثال، إذا تم الضغط على Shift و Ctrl و 'a' جميعًا، فلا يمكن تمييز ذلك عن Ctrl و 'A'.

يتم حاليًا تسجيل Ctrl المضغوط مع 'J' أو 'M'، سواء تم الضغط على Shift أم لا، كـ NCKEY_ENTER. من المحتمل أن يتغير هذا في المستقبل.

عند استخدام بروتوكول Kitty لتفسير لوحة المفاتيح، يتم حل معظم هذه المشكلات. يمكنك تحديد ما إذا كان البروتوكول قيد الاستخدام عن طريق فحص مخرجات notcurses-info(1). إذا تم الإشارة إلى خاصية kbd، فأنت تستخدم بروتوكول Kitty.

لاحظ أن eff_text ستُرجع دائمًا القيمة النصية الفعالة للمفتاح، مع الأخذ في الاعتبار أي مفاتيح meta مضغوطة. (لذا فإن shift-a ستُرجع دائمًا 'A' في هذا الحقل، بغض النظر عما إذا كان بروتوكول Kitty لتفسير لوحة المفاتيح مستخدمًا أم لا.) يمكن عادةً الوثوق بهذا الحقل فقط في أحداث NCTYPE_PRESS و NCTYPE_REPEAT. لاحظ أيضًا أن هذا مصفوفة (تنتهي بصفر) حيث يمكن أن تُرجع نقاط رمز متعددة.

لن يتم تسليم أحداث الفأرة في الهوامش اليسرى أبدًا إلى التطبيق (كما هو مقصود)، ولكن أحداث الفأرة في الهوامش السفلية واليمنى يمكن أحيانًا تسليمها إذا حدث الحدث قبل تغيير حجم النافذة.

الحقول ypx و xpx ليست صالحة حاليًا (أي أنها دائمًا -1). يجب إصلاح هذا في المستقبل باستخدام بروتوكول SGR PixelMode للفأرة.

في بعض أنظمة التشغيل، يتم استخدام CLOCK_REALTIME كأساس لانتهاء المهلة بدلاً من CLOCK_MONOTONIC. يجب إصلاح هذا.
