notcurses_tabbed(3)

NAME

notcurses_tabbed - Notcurses tabbed widget

SYNOPSIS

#include <notcurses/notcurses.h>

struct ncplane* notcurses_tabbed(struct ncplane* nctl, const char* title, ...);

DESCRIPTION

Creates a tabbed widget. The first argument is the plane on which to create the widget. The second argument is the title. Subsequent arguments are pairs of const char*, each pair being a tab title and a null-terminated array of ncinput structures. The entire list must be terminated by a NULL pointer. The contents of the tab are loaded from the provided ncinput structures. The function returns a pointer to the plane on which the tabbed widget was created.

RETURN VALUES

On success, returns a pointer to the plane containing the tabbed widget. On failure, returns NULL.

SEE ALSO

notcurses(3), notcurses_plane(3)

notcurses_tabbed(3)

NAME

notcurses_tabbed - Notcurses tabbed widget

SYNOPSIS

#include <notcurses/notcurses.h>

struct ncplane* notcurses_tabbed(struct ncplane* nctl, const char* title, ...);

DESCRIPTION

ينشئ أداة بعلامات تبويب. الوسيط الأول هو المستوى الذي سيتم إنشاء الأداة عليه. الوسيط الثاني هو العنوان. الوسائط اللاحقة هي أزواج من const char* ، كل زوج هو عنوان علامة تبويب ومصفوفة من هياكل ncinput منتهية بـ null. يجب إنهاء القائمة بأكملها بمؤشر NULL. يتم تحميل محتويات علامة التبويب من هياكل ncinput المقدمة. تعيد الدالة مؤشرًا إلى المستوى الذي تم إنشاؤه عليه أداة علامات التبويب.

RETURN VALUES

عند النجاح ، يعيد مؤشرًا إلى المستوى الذي يحتوي على أداة علامات التبويب. عند الفشل ، يعيد NULL.

notcurses(3), notcurses_plane(3)
