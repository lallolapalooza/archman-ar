الأمر 'nominatim serve'

الاستخدام: nominatim serve [-h] [-q] [-v] [--project-dir DIR] [-j NUM]
[--server SERVER] [--engine {falcon,starlette}]

بدء خادم ويب بسيط لخدمة واجهة برمجة التطبيقات.

يبدأ هذا الأمر خادم ويب مدمج لخدمة موقع الويب من دليل المشروع الحالي. هذا الخادم مناسب فقط للاختبار والتطوير. لا تستخدمه في إعدادات الإنتاج!

هناك تطبيقان مختلفان لخادم الويب متاحان لـ Python: falcon (الافتراضي) و starlette. تحتاج إلى التأكد من تثبيت حزم Python المناسبة بالإضافة إلى حزمة uvicorn لاستخدام هذه الوظيفة.

بشكل افتراضي، يمكن الوصول إلى خادم الويب على: http://127.0.0.1:8088

NAME

nominatim — Tool to search and administer Nominatim

SYNOPSIS

nominatim [COMMAND] [OPTIONS]

DESCRIPTION

Nominatim is a tool for searching and administrating the Nominatim geocoder.

It offers various commands for importing data, managing replication, and querying the geocoder.

AVAILABLE COMMANDS

import, replication, special-phrases, add-data, refresh, admin, convert, serve, search, status

Run nominatim help <command> for more details on a specific command.

REQUIRED ARGUMENTS 'nominatim import'

--config FILE
Path to the configuration file.
--data-dir DIR
Path to the data directory.
--osm-file FILE
Path to the OSM PBF file.

OPTIONAL ARGUMENTS 'nominatim import'

-j NUM, --threads NUM
Number of parallel threads to use.

EXPERT OPTIONS 'nominatim import'

--batch-size NUM
Number of objects per batch.
--flush- every NUM
Flush database every NUM objects.

ARGUMENTS FOR INITIALISATION 'nominatim replication'

--config FILE
Path to the configuration file.
--data-dir DIR
Path to the data directory.

ARGUMENTS FOR UPDATES 'nominatim replication'

--interval SEC
Replication interval in seconds.

DOWNLOAD PARAMETERS 'nominatim replication'

--download-dir DIR
Directory to download replication files to.

INPUT ARGUMENTS 'nominatim special-phrases'

--config FILE
Path to the configuration file.
--input FILE
Path to the input file (default: stdin).
--output FILE
Path to the output file (default: stdout).

SOURCE 'nominatim add-data'

--config FILE
Path to the configuration file.
--data-dir DIR
Path to the data directory.
--source FILE
Path to the source file (e.g., CSV, JSON).

EXTRA ARGUMENTS 'nominatim add-data'

-j NUM, --threads NUM
Number of parallel threads to use.

DATA ARGUMENTS 'nominatim refresh'

--config FILE
Path to the configuration file.
--data-dir DIR
Path to the data directory.

ARGUMENTS FOR FUNCTION REFRESH 'nominatim refresh'

--all
Refresh all data.
--type TYPE
Refresh only specified type (e.g., places, addresses).

ADMIN TASKS 'nominatim admin'

--config FILE
Path to the configuration file.
--data-dir DIR
Path to the data directory.

ARGUMENTS FOR CACHE WARMING 'nominatim admin'

--cache-warm
Warm the cache.

ARGUMENTS FOR INDEX ANAYSIS 'nominatim admin'

--analyze
Analyze the database indexes.

OPTIONS 'nominatim convert'

--config FILE
Path to the configuration file.
--data-dir DIR
Path to the data directory.
--output-format FORMAT
Output format (e.g., pbf, o5m).

SWITCHES TO DEFINE DATABASE LAYOUT(CURRENTLY NO EFFECT) 'nominatim convert'

--tables TABLES
Comma-separated list of tables to convert.

SERVER ARGUMENTS 'nominatim serve'

--config FILE
Path to the configuration file.
--port PORT
Port to listen on (default: 8080).
--host HOST
Host to listen on (default: 127.0.0.1).

RESULT LIMITATION 'nominatim search'

--limit NUM
Maximum number of results to return.
--skip NUM
Number of results to skip.

API PARAMETERS 'nominatim search'

--addressdetails
Include details of places lower in the address hierarchy.
--group-hierarchy
Group the places by type.
--polygon-geojson
Include geometry of result.
--lang LANGS, --accept-language LANGS
Preferred language order for presenting search results.

OTHER OPTIONS 'nominatim search'

--list-formats
List supported output formats and exit.

COMMAND 'nominatim status'

usage: nominatim status [-h] [-q] [-v] [--project-dir DIR] [-j NUM]
[--format FORMAT] [--list-formats]

Execute API status query.

This command works exactly the same as if calling the /status endpoint on the web API. See the online documentation for more details on the various parameters: https://nominatim.org/release-docs/latest/api/Status/

DEFAULT ARGUMENTS 'nominatim status'

-q, --quiet
Print only error messages.
-v, --verbose
Increase verboseness of output.
--project-dir DIR
Base directory of the Nominatim installation (default: /var/lib/nominatim/).
-j NUM, --threads NUM
Number of parallel threads to use.

API PARAMETERS 'nominatim status'

--format FORMAT
Format of result (use --list-formats to see supported formats).

OTHER OPTIONS 'nominatim status'

--list-formats
List supported output formats and exit.
