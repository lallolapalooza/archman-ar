nbd_aio_connect_uri(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

nbd_aio_connect_uri(3) LIBNBD nbd_aio_connect_uri(3)

الاسم

nbd_aio_connect_uri - الاتصال بـ URI الخاص بـ NBD

الملخص

#include <libnbd.h>
int nbd_aio_connect_uri (
      struct nbd_handle *h, const char *uri
    );

الوصف

بدء الاتصال بـ URI الخاص بـ NBD "uri". تعمل المعلمات كما هو موثق في nbd_connect_uri(3).

يمكنك التحقق مما إذا كان محاولة الاتصال لا تزال قيد التنفيذ عن طريق استدعاء nbd_aio_is_connecting(3). إذا تم تمكين nbd_set_opt_mode(3)، يكون الاتصال جاهزًا للتفاوض اليدوي على الخيارات بمجرد أن يعيد nbd_aio_is_negotiating(3) القيمة true؛ بخلاف ذلك، ستتضمن محاولة الاتصال المصافحة الخاصة بـ NBD، وتكون جاهزة للاستخدام بمجرد أن يعيد nbd_aio_is_ready(3) القيمة true.

قيمة الإرجاع

إذا نجح الاستدعاء، تعيد الدالة 0.

الأخطاء

عند حدوث خطأ، تعيد الدالة -1.

راجع "معالجة الأخطاء" في libnbd(3) للحصول على مزيد من التفاصيل حول الخطأ.

يجب ألا تكون المعلمات التالية NULL: "h"، "uri". لمزيد من المعلومات، راجع "المعلمات غير الخالية" في libnbd(3).

حالة المقبض

يمكن استدعاء nbd_aio_connect_uri عندما يكون المقبض في الحالة التالية:

┌─────────────────────────────────────┬─────────────────────────┐
│ تم إنشاء المقبض، قبل الاتصال │ ✅ مسموح به │
│ جارٍ الاتصال │ ❌ خطأ │
│ جارٍ الاتصال والمصافحة (opt_mode) │ ❌ خطأ │
│ متصل بالخادم │ ❌ خطأ │
│ تم إغلاق الاتصال │ ❌ خطأ │
│ المقبض ميت │ ❌ خطأ │
└─────────────────────────────────────┴─────────────────────────┘

الإصدار

ظهرت هذه الدالة لأول مرة في libnbd 1.0.

إذا كنت بحاجة إلى التحقق مما إذا كانت هذه الدالة متاحة في وقت الترجمة، تحقق مما إذا كان الماكرو التالي معرفًا:

#define LIBNBD_HAVE_NBD_AIO_CONNECT_URI 1

انظر أيضاً

nbd_aio_is_connecting(3)، nbd_aio_is_negotiating(3)، nbd_aio_is_ready(3)، nbd_connect_uri(3)، nbd_create(3)، nbd_set_opt_mode(3)، libnbd(3)، https://github.com/NetworkBlockDevice/nbd/blob/master/doc/uri.md.
