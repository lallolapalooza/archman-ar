nbd_set_debug_callback(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

nbd_set_debug_callback(3) LIBNBD nbd_set_debug_callback(3)

الاسم

nbd_set_debug_callback - تعيين دالة رد الاتصال للتصحيح

الملخص

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *context,
                   const char *msg);
  void *user_data;
  void (*free) (void *user_data);
} nbd_debug_callback;
int nbd_set_debug_callback (
      struct nbd_handle *h,
      nbd_debug_callback debug_callback
    );

الوصف

تعيين دالة رد الاتصال للتصحيح. يتم استدعاء هذه الدالة عندما تصدر المكتبة رسائل تصحيح، عندما يتم تمكين التصحيح على مقبض. معلمات رد الاتصال هي "user_data" التي تم تمريرها إلى هذه الدالة، اسم دالة libnbd التي تصدر رسالة التصحيح ("context")، والرسالة نفسها ("msg"). إذا لم يتم تعيين دالة رد اتصال على مقبض، فسيتم طباعة الرسائل على "stderr".

يجب ألا تقوم دالة رد الاتصال باستدعاء واجهات برمجة التطبيقات "nbd_*" على نفس المقبض لأنها قد يتم استدعاؤها أثناء الاحتفاظ بقفل المقبض وستتسبب في جمود.

قيمة الإرجاع

إذا نجح الاستدعاء، تعيد الدالة 0.

الأخطاء

عند حدوث خطأ، يتم إرجاع -1.

ارجع إلى "معالجة الأخطاء" في libnbd(3) للحصول على مزيد من التفاصيل حول الخطأ.

يجب ألا تكون المعلمات التالية فارغة (NULL): "h". لمزيد من المعلومات، راجع "المعلمات غير الفارغة" في libnbd(3).

الإصدار

ظهرت هذه الدالة لأول مرة في libnbd 1.0.

إذا كنت بحاجة إلى اختبار ما إذا كانت هذه الدالة متاحة وقت الترجمة، فتحقق مما إذا كان ما يلي المعرّف معرفًا:

#define LIBNBD_HAVE_NBD_SET_DEBUG_CALLBACK 1

انظر أيضًا

nbd_create(3), libnbd(3).
