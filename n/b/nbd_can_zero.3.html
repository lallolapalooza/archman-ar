nbd_can_zero(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

DESCRIPTION

nbd_can_zero is a function that ... [Description of the function] ...

SYNOPSIS

int nbd_can_zero(NbdClient *client);

PARAMETERS

  • client: A pointer to an NbdClient structure.

RETURN VALUE

Returns 1 if the client can handle zero-sized requests, 0 otherwise.

EXAMPLE

#include <libnbd.h>

int main() {
    NbdClient *client = nbd_connect("example.com");
    if (client) {
        if (nbd_can_zero(client)) {
            // Client can handle zero-sized requests
        }
        nbd_shutdown(client);
    }
    return 0;
}
