nbd_aio_connect_unix(3)

nbd_aio_connect_unix — connect to an NBD server over a UNIX domain socket asynchronously

SYNOPSIS

#include <libnbd.h>

void nbd_aio_connect_unix (
    NBDClient *client,
    const char *path,
    nbd_completion_callback *callback,
    void *user_data
);

DESCRIPTION

nbd_aio_connect_unix is a non-blocking function that initiates a connection to an NBD server listening on a UNIX domain socket at the specified path. The connection attempt is asynchronous.

When the connection attempt finishes (either successfully or with an error), the callback function is called with user_data. The callback function receives the client object as its first argument.

This function is a lower-level API. For most uses, you should prefer nbd_connect_unix.

The client must have been previously created with nbd_client_create.

RETURN VALUE

This function does not return a value. Use the callback to check for success or failure.

ERRORS

If the connection attempt fails, the callback function will be called with an error. You can check for errors within the callback by examining the state of the client object using nbd_is_error and retrieving the error message with nbd_get_error.

HANDLE STATE

Before the connection is established, the client is in a connecting state. After a successful connection, it transitions to the connected state. If an error occurs, it transitions to the error state.

VERSION

This function was added in libnbd version 1.0.

EXAMPLE

#include <libnbd.h>
#include <stdio.h>
#include <stdlib.h>

void connect_callback (NBDClient *client, void *user_data) {
    if (nbd_is_error (client)) {
        fprintf (stderr, "Connection failed: %s\n", nbd_get_error (client));
        nbd_client_destroy (client);
        exit (EXIT_FAILURE);
    } else {
        printf ("Successfully connected!\n");
        // Proceed with NBD operations
        nbd_shutdown (client); // Example: close connection after success
    }
}

int main (int argc, char **argv) {
    if (argc != 2) {
        fprintf (stderr, "Usage: %s /path/to/socket\n", argv[0]);
        exit (EXIT_FAILURE);
    }

    const char *socket_path = argv[1];
    NBDClient *client = nbd_client_create (NULL);
    if (!client) {
        fprintf (stderr, "Failed to create NBD client\n");
        exit (EXIT_FAILURE);
    }

    nbd_aio_connect_unix (client, socket_path, connect_callback, NULL);

    // Enter the libnbd event loop to process asynchronous operations
    nbd_run_event_loop (client);

    nbd_client_destroy (client);
    return 0;
}
