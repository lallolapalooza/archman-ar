nbd_aio_opt_set_meta_context(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

nbd_aio_opt_set_meta_context(3) LIBNBD nbd_aio_opt_set_meta_context(3)

الاسم

nbd_aio_opt_set_meta_context - تحديد سياقات البيانات الوصفية المحددة، مع قائمة استعلام ضمنية

ملخص

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_set_meta_context (
      struct nbd_handle *h,
      nbd_context_callback context_callback,
      nbd_completion_callback completion_callback
    );

الوصف

طلب أن يقوم الخادم بتوفير جميع سياقات البيانات الوصفية المعترف بها والمسجلة من خلال استدعاءات سابقة لـ nbd_add_meta_context(3)، بالاقتران مع التصدير المحدد مسبقًا بواسطة أحدث استدعاء لـ nbd_set_export_name(3) أو nbd_connect_uri(3). لا يمكن استخدام هذا إلا إذا قام nbd_set_opt_mode(3) بتمكين وضع الخيارات. في العادة، تكون هذه الدالة زائدة عن الحاجة، حيث يقوم nbd_opt_go(3) تلقائيًا بنفس المهمة إذا تم التفاوض على الردود المنظمة أو الرؤوس الموسعة بالفعل. ولكن يمكن أن يكون التحكم اليدوي في طلبات سياقات البيانات الوصفية مفيدًا للاختبار الدقيق لكيفية تعامل الخادم مع تسلسلات التفاوض غير العادية. غالبًا، يتم إقران استخدام هذه الدالة مع nbd_set_request_meta_context(3) لتجاوز طلب السياق التلقائي الذي يقوم به nbd_opt_go(3) عادةً.

لتحديد متى يكتمل الطلب، انتظر حتى يعود nbd_aio_is_connecting(3) بالقيمة false. أو قم بتوفير "completion_callback" الاختياري الذي سيتم استدعاؤه كما هو موضح في "ردود الاتصال" في libnbd(3)، باستثناء أنه يتم سحبه تلقائيًا بغض النظر عن قيمة الإرجاع. لاحظ أن اكتشاف ما إذا كان الخادم يرجع خطأ (كما يتم فعله بواسطة قيمة الإرجاع للبديل المتزامن) لا يمكن تحقيقه إلا مع رد اتصال.

قيمة الإرجاع

تعود هذه المكالمة بقيمة صحيحة ≥ 0.

الأخطاء

عند حدوث خطأ، يتم إرجاع -1.

ارجع إلى "معالجة الأخطاء" في libnbd(3) للحصول على مزيد من التفاصيل حول الخطأ.

يجب ألا تكون المعلمات التالية NULL: "h". لمزيد من المعلومات، راجع "المعلمات غير الفارغة" في libnbd(3).

حالة المقبض

يمكن استدعاء nbd_aio_opt_set_meta_context عندما يكون المقبض في الحالة التالية:

┌─────────────────────────────────────┬─────────────────────────┐
│ تم إنشاء المقبض، قبل الاتصال   │ ❌ خطأ                │
│ جارٍ الاتصال                      │ ❌ خطأ                │
│ جارٍ الاتصال والمصافحة (opt_mode) │ ✅ مسموح به              │
│ تم الاتصال بالخادم             │ ❌ خطأ                │
│ تم إغلاق الاتصال                │ ❌ خطأ                │
│ المقبض ميت                         │ ❌ خطأ                │
└─────────────────────────────────────┴─────────────────────────┘

NAME

nbd_aio_opt_set_meta_context - Set the per-operation metadata context

SYNOPSIS

void nbd_aio_opt_set_meta_context (struct nbd_aio_context *ctx,
                                  void *meta_context);

DESCRIPTION

Set the metadata context for the asynchronous I/O operations associated with ctx. This metadata context can be used by the callback function to identify the specific operation.

PARAMETERS

ctx
The asynchronous I/O context.
meta_context
The metadata context to set for this operation. This can be any pointer value, and will be passed to the callback function when the operation completes.

RETURN VALUE

None.

EXAMPLE

struct nbd_aio_context *ctx;
void *my_data = /* ... */ ;

ctx = nbd_aio_context_new ();
nbd_aio_opt_set_meta_context (ctx, my_data);
/* ... perform async operations using ctx ... */
