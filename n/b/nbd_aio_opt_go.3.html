nbd_aio_opt_go(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

nbd_aio_opt_go(3) LIBNBD nbd_aio_opt_go(3)

الاسم

nbd_aio_opt_go - إنهاء التفاوض والانتقال إلى استخدام تصدير

الملخص

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_go (
      struct nbd_handle *h,
      nbd_completion_callback completion_callback
    );

الوصف

يطلب من الخادم إنهاء التفاوض والانتقال إلى تقديم التصدير المحدد مسبقًا بواسطة أحدث nbd_set_export_name(3) أو nbd_connect_uri(3). لا يمكن استخدام هذا إلا إذا كان nbd_set_opt_mode(3) قد قام بتمكين وضع الخيارات.

لتحديد وقت اكتمال الطلب، انتظر حتى ترجع nbd_aio_is_connecting(3) قيمة خاطئة. أو قم بتوفير "completion_callback" الاختياري الذي سيتم استدعاؤه كما هو موضح في "استدعاءات الإكمال" في libnbd(3)، باستثناء أنه يتم إيقافه تلقائيًا بغض النظر عن القيمة المرجعة. لاحظ أن الكشف المباشر عما إذا كان الخادم يعيد خطأ (كما هو الحال مع نظيره المتزامن) ممكن فقط مع استدعاء إكمال؛ ومع ذلك، من الممكن أيضًا اكتشاف خطأ بشكل غير مباشر عندما ترجع nbd_aio_is_negotiating(3) قيمة صحيحة.

القيمة المرجعة

إذا كان الاستدعاء ناجحًا، فإن الدالة ترجع 0.

الأخطاء

عند حدوث خطأ، ترجع -1.

ارجع إلى "معالجة الأخطاء" في libnbd(3) للحصول على تفاصيل إضافية حول الخطأ.

يجب ألا تكون المعلمات التالية فارغة: "h". لمزيد من المعلومات، راجع "المعلمات غير الفارغة" في libnbd(3).

حالة المقبض

يمكن استدعاء nbd_aio_opt_go عندما يكون المقبض في الحالة التالية:

┌─────────────────────────────────────┬─────────────────────────┐
│ تم إنشاء المقبض، قبل الاتصال   │ ❌ خطأ                │
│ جارٍ الاتصال                       │ ❌ خطأ                │
│ جارٍ الاتصال والمصافحة (opt_mode) │ ✅ مسموح به             │
│ متصل بالخادم                  │ ❌ خطأ                │
│ تم إغلاق الاتصال                │ ❌ خطأ                │
│ المقبض غير صالح                 │ ❌ خطأ                │
└─────────────────────────────────────┴─────────────────────────┘

الإصدار

ظهرت هذه الدالة لأول مرة في libnbd 1.4.

إذا كنت بحاجة إلى اختبار ما إذا كانت هذه الدالة متاحة في وقت الترجمة، فتحقق مما إذا كان الماكرو التالي معرفًا:

#define LIBNBD_HAVE_NBD_AIO_OPT_GO 1

انظر أيضًا
