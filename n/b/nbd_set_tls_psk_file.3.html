nbd_set_tls_psk_file(3)

الاسم

nbd_set_tls_psk_file - اضبط ملف مفتاح سري مشترك (PSK) لـ TLS

الملخص

#include <libnbd.h>

int nbd_set_tls_psk_file (NBD_HANDLE *h,
                         const char *psk_identity,
                         const char *psk_file);

الوصف

تستخدم الدالة nbd_set_tls_psk_file ملف مفتاح سري مشترك (PSK) لتكوين TLS للاتصال. إذا كان psk_identity هو NULL، فسيتم استخدامه كاسم مستعار إذا كان موجودًا في الملف، وإلا فسيتم استخدام اسم الملف الذي تم تمريره كـ psk_file. وإلا، يتم استخدام psk_identity المحدد. يجب أن يحتوي الملف psk_file على سطر واحد في كل مرة: معرف مفتاح سري مشترك (PSK) متبوعًا بمسافة بيضاء ثم المفتاح السري المشترك (PSK) نفسه، على شكل سداسي عشري. لا يمكن استخدام هذه الدالة إلا إذا تم تكوين libnbd مع دعم OpenSSL.

قيمة الإرجاع

تُرجع الدالة 0 عند النجاح، أو -1 عند الفشل. استخدم nbd_get_last_error للحصول على تفاصيل الخطأ.

الأخطاء

nbd_set_tls_psk_file يفشل إذا:

  • فشل تخصيص الذاكرة.
  • فشل تحميل المفتاح السري المشترك (PSK) من الملف.

حالة المقبض

يمكن استدعاء هذه الدالة في أي وقت قبل استدعاء nbd_connect.

الإصدار

تم تقديم هذه الدالة لأول مرة في libnbd 1.10.

مثال

```c #include <libnbd.h> #include <stdio.h> #include <stdlib.h> int main(void) { NBD_HANDLE *h = nbd_create (); if (!h) { fprintf (stderr, "nbd_create failed\n"); return 1; } // Create a temporary PSK file FILE *fp = fopen ("my.psk", "w"); if (!fp) { fprintf (stderr, "fopen failed\n"); nbd_destroy (h); return 1; } fprintf (fp, "mypskidentity mysecretkeyinhx\n"); fclose (fp); if (nbd_set_tls_psk_file (h, "mypskidentity", "my.psk") == -1) { fprintf (stderr, "nbd_set_tls_psk_file failed\n"); // ... cleanup and exit return 1; } // Proceed with nbd_connect, etc. // ... nbd_destroy (h); remove ("my.psk"); // Clean up the temporary file return 0; } ```
