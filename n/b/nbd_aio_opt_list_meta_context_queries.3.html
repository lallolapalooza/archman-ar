nbd_aio_opt_list_meta_context_queries(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

nbd_aio_opt_list_meta_context_queries(3) LIBNBD nbd_aio_opt_list_meta_context_queries(3)

الاسم

nbd_aio_opt_list_meta_context_queries - طلب قائمة السياقات الوصفية المتاحة، باستخدام استعلام صريح

الملخص

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name);
  void *user_data;
  void (*free) (void *user_data);
} nbd_context_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_list_meta_context_queries (
      struct nbd_handle *h, char **queries,
      nbd_context_callback context_callback,
      nbd_completion_callback completion_callback
    );

الوصف

يطلب من الخادم سرد السياقات الوصفية المتاحة المرتبطة بالتصدير الذي تم تحديده مسبقًا بواسطة أحدث استدعاء لـ nbd_set_export_name(3) أو nbd_connect_uri(3)، مع قائمة استعلامات صريحة مقدمة كمعامل (انظر nbd_aio_opt_list_meta_context(3) إذا كنت ترغب في إعادة استخدام قائمة استعلامات ضمنية بدلاً من ذلك). لا يمكن استخدام هذا إلا إذا قام nbd_set_opt_mode(3) بتمكين وضع الخيارات.

لتحديد وقت اكتمال الطلب، انتظر حتى يعيد nbd_aio_is_connecting(3) القيمة false. أو قم بتوفير "completion_callback" الاختياري الذي سيتم استدعاؤه كما هو موضح في "ردود الاتصال عند الاكتمال" في libnbd(3)، باستثناء أنه يتم سحبه تلقائيًا بغض النظر عن قيمة الإرجاع. لاحظ أن اكتشاف ما إذا كان الخادم يعيد خطأ (كما هو الحال مع القيمة المرجعة للوظيفة المتزامنة) ممكن فقط باستخدام رد اتصال عند الاكتمال.

قيمة الإرجاع

تعيد هذه المكالمة قيمة صحيحة ≥ 0.

الأخطاء

عند حدوث خطأ، يتم إرجاع -1.

راجع "معالجة الأخطاء" في libnbd(3) للحصول على مزيد من التفاصيل حول الخطأ.

يجب ألا تكون المعلمات التالية NULL: "h"، "queries". لمزيد من المعلومات، راجع "المعلمات غير الفارغة" في libnbd(3).

حالة المقبض

يمكن استدعاء nbd_aio_opt_list_meta_context_queries عندما يكون المقبض في الحالة التالية:

┌─────────────────────────────────────┬─────────────────────────┐
│ المقبض تم إنشاؤه، قبل الاتصال   │ ❌ خطأ                │
│ جاري الاتصال                       │ ❌ خطأ                │
│ جاري الاتصال والمصافحة (opt_mode) │ ✅ مسموح به              │
│ تم الاتصال بالخادم              │ ❌ خطأ                │
│ تم إغلاق الاتصال                │ ❌ خطأ                │
│ المقبض ميت                        │ ❌ خطأ                │
└─────────────────────────────────────┴─────────────────────────┘

الإصدار

ظهرت هذه الوظيفة لأول مرة في libnbd 1.16.

إذا كنت بحاجة إلى اختبار ما إذا كانت هذه الوظيفة متاحة وقت الترجمة، فتحقق مما إذا كان ما يلي معرّفًا:

#define LIBNBD_HAVE_NBD_AIO_OPT_LIST_META_CONTEXT_QUERIES 1

راجع أيضًا

nbd_aio_is_connecting(3)، nbd_aio_opt_list_meta_context(3)، nbd_connect_uri(3)، nbd_create(3)، nbd_opt_list_meta_context_queries(3)، nbd_set_export_name(3)، nbd_set_opt_mode(3)، libnbd(3).
