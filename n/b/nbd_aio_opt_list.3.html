nbd_aio_opt_list(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

nbd_aio_opt_list(3) LIBNBD nbd_aio_opt_list(3)

الاسم

nbd_aio_opt_list - طلب من الخادم سرد جميع الصادرات أثناء التفاوض

الملخص

#include <libnbd.h>
typedef struct {
  int (*callback) (void *user_data, const char *name,
                   const char *description);
  void *user_data;
  void (*free) (void *user_data);
} nbd_list_callback;
typedef struct {
  int (*callback) (void *user_data, int *error);
  void *user_data;
  void (*free) (void *user_data);
} nbd_completion_callback;
int nbd_aio_opt_list (
      struct nbd_handle *h,
      nbd_list_callback list_callback,
      nbd_completion_callback completion_callback
    );

الوصف

يطلب من الخادم سرد جميع الصادرات التي يدعمها. لا يمكن استخدام هذا إلا إذا كان nbd_set_opt_mode(3) قد مكّن وضع الخيارات.

لتحديد وقت اكتمال الطلب، انتظر حتى تعود nbd_aio_is_connecting(3) إلى قيمة خاطئة. أو قم بتوفير "completion_callback" الاختياري الذي سيتم استدعاؤه كما هو موضح في "إرجاع الاستدعاءات" في libnbd(3)، باستثناء أنه يتم إتلافه تلقائيًا بغض النظر عن قيمة الإرجاع. لاحظ أن اكتشاف ما إذا كان الخادم يُرجع خطأ (كما هو الحال مع قيمة الإرجاع للنظير المتزامن) لا يمكن تحقيقه إلا باستخدام رد استدعاء الإكمال.

قيمة الإرجاع

إذا نجح الاستدعاء، تُرجع الدالة 0.

الأخطاء

عند حدوث خطأ، تُرجع -1.

ارجع إلى "معالجة الأخطاء" في libnbd(3) للحصول على مزيد من التفاصيل حول الخطأ.

يجب ألا تكون المعلمات التالية فارغة (NULL): "h". لمزيد من المعلومات، راجع "المعلمات غير الفارغة (Non-NULL)" في libnbd(3).

حالة المقبض

يمكن استدعاء nbd_aio_opt_list عندما يكون المقبض في الحالة التالية:

┌─────────────────────────────────────┬─────────────────────────┐
│ تم إنشاء المقبض، قبل الاتصال   │ ❌ خطأ                │
│ قيد الاتصال                       │ ❌ خطأ                │
│ قيد الاتصال والمصافحة (opt_mode) │ ✅ مسموح              │
│ متصل بالخادم              │ ❌ خطأ                │
│ تم إيقاف اتصال              │ ❌ خطأ                │
│ المقبض ميت                         │ ❌ خطأ                │
└─────────────────────────────────────┴─────────────────────────┘

الإصدار

ظهرت هذه الدالة لأول مرة في libnbd 1.4.

إذا كنت بحاجة إلى اختبار ما إذا كانت هذه الدالة متاحة وقت الترجمة، فتحقق مما إذا كان ماكرو التالي معرفًا:

#define LIBNBD_HAVE_NBD_AIO_OPT_LIST 1

انظر أيضًا

nbd_aio_is_connecting(3)، nbd_create(3)، nbd_opt_list(3)، nbd_set_opt_mode(3)، libnbd(3).
