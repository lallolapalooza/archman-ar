nbd_block_status(3)

الحزمة: libnbd

التراخيص: LGPL-2.1-or-later

NAME

nbd_block_status — get block status

SYNOPSIS

#include <libnbd.h>

int nbd_block_status(
    NBD_HANDLE *h,
    uint64_t offset,
    uint64_t count,
    struct nbd_block_status *status
);

DESCRIPTION

This function is a wrapper around the NBD_CMD_BLOCK_STATUS NBD export command. It retrieves block status information for a range of data from the NBD server.

The h parameter is a handle returned by nbd_connect_simple or nbd_connect_preconnect.

The offset parameter is the starting byte offset of the range for which to get block status.

The count parameter is the number of bytes in the range.

The status parameter is a pointer to a struct nbd_block_status which will be filled with the block status information by the function. The structure is defined as follows:

struct nbd_block_status {
    uint64_t allocation;    // Allocated size of the block
    uint64_t size;          // Total size of the block
    uint32_t flags;         // Flags, see below
};

The flags field can contain the following bits:

  • NBD_BLOCK_STATUS_HOLE: The block is a hole (empty).
  • NBD_BLOCK_STATUS_ZERO: The block contains only zeros.
  • NBD_BLOCK_STATUS_PM: The block contains only physically-minor data (e.g. copy-on-write data).

RETURN VALUE

On success, 0 is returned. On error, a negative errno value is returned.

ERRORS

Errors can include:

  • EFAULT: The provided pointers are invalid.
  • EINVAL: Invalid arguments were provided (e.g. count is zero, or status is NULL).
  • ENOTSUP: The NBD server does not support NBD_CMD_BLOCK_STATUS.
  • EIO: An I/O error occurred.
  • And other errors returned by the NBD protocol.

HANDLE STATE

This function may block indefinitely if the NBD server does not respond. It may also modify the state of the NBD connection.

VERSION

This function was added in libnbd 1.8.
