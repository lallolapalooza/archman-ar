nginx(8)

الحزمة: nginx-mainline

التراخيص: BSD-2-Clause

NGINX(8) دليل مدير النظام NGINX(8)

الاسم

nginx — خادم HTTP وخادم وكيل عكسي، خادم وكيل بريد

الملخص

nginx [-?hqTtVv] [-c ملف] [-e ملف] [-g توجيهات] [-p بادئة] [-s إشارة]

الوصف

nginx (يُنطق "engine x") هو خادم HTTP وخادم وكيل عكسي، وخادم وكيل بريد، وخادم وكيل TCP/UDP عام. يُعرف بأدائه العالي، واستقراره، ومجموعة ميزاته الغنية، وتكوينه البسيط، واستهلاكه المنخفض للموارد.

الخيارات هي كالتالي:

-?, -h
طباعة المساعدة.
-c ملف
استخدام ملف تكوين بديل ملف.
-e ملف
استخدام ملف سجل خطأ بديل ملف. القيمة الخاصة stderr تشير إلى أنه يجب استخدام مخرج الخطأ القياسي.
-g توجيهات
تعيين توجيهات تكوين عامة. انظر أمثلة للتفاصيل.
-p بادئة
تعيين مسار البادئة. القيمة الافتراضية هي /etc/nginx.
-q
قم بقمع الرسائل غير المتعلقة بالأخطاء أثناء اختبار التكوين.
-s إشارة
إرسال إشارة إلى العملية الرئيسية. يمكن أن يكون الوسيط إشارة واحدًا مما يلي: stop، quit، reopen، reload. يوضح الجدول التالي الإشارات النظامية المقابلة:
stop
SIGTERM
quit
SIGQUIT
reopen
SIGUSR1
reload
SIGHUP
-T
مثل -t، ولكن بالإضافة إلى ذلك يقوم بتفريغ ملفات التكوين إلى المخرج القياسي.
-t
لا تقم بالتشغيل، فقط اختبر ملف التكوين. nginx يتحقق من بناء جملة ملف التكوين ثم يحاول فتح الملفات المشار إليها في ملف التكوين.
-V
طباعة إصدار nginx، وإصدار المترجم، و configure معلمات البرنامج النصي.
-v
طباعة إصدار nginx.

الإشارات

يمكن للعملية الرئيسية لـ nginx معالجة الإشارات التالية:

SIGINT, SIGTERM
إيقاف التشغيل بسرعة.
SIGHUP
إعادة تحميل التكوين، بدء عملية عامل جديدة بتكوين جديد، وإنهاء عمليات العامل القديمة بشكل رشيق.
SIGQUIT
إيقاف التشغيل بشكل رشيق.
SIGUSR1
إعادة فتح ملفات السجل.
SIGUSR2
ترقية الملف التنفيذي nginx أثناء التشغيل.
SIGWINCH
إنهاء عمليات العامل بشكل رشيق.

بينما لا توجد حاجة للتحكم بشكل صريح في عمليات العامل عادةً، إلا أنها تدعم بعض الإشارات أيضًا:

SIGTERM
إيقاف التشغيل بسرعة.
SIGQUIT
إيقاف التشغيل بشكل رشيق.
SIGUSR1
إعادة فتح ملفات السجل.

سجل التصحيح

لتمكين سجل التصحيح، أعد تكوين nginx للبناء مع التصحيح:

./configure --with-debug ...

ثم قم بتعيين مستوى debug لـ error_log:

error_log /path/to/log debug;

من الممكن أيضًا تمكين التصحيح لعنوان IP معين:

events {
	debug_connection 127.0.0.1;
}

البيئة

يتم استخدام متغير البيئة NGINX داخليًا بواسطة nginx ولا يجب تعيينه مباشرة من قبل المستخدم.

الملفات

/run/nginx.pid
يحتوي على معرف عملية nginx. محتويات هذا الملف ليست حساسة، لذا يمكن قراءتها عالميًا.
/etc/nginx/nginx.conf
ملف التكوين الرئيسي.
stderr
ملف سجل الأخطاء.

حالة الخروج

حالة الخروج هي 0 عند النجاح، أو 1 إذا فشل الأمر.

أمثلة

اختبر ملف التكوين ~/mynginx.conf مع توجيهات عامة لمعرف العملية (PID) وكمية عمليات العامل:

nginx -t -c ~/mynginx.conf \
	-g "pid /var/run/mynginx.pid; worker_processes 2;"

انظر أيضاً

التوثيق في http://nginx.org/en/docs/.

للأسئلة والدعم الفني، يرجى الرجوع إلى http://nginx.org/en/support.html.
