nfsd(8)

الحزمة: nfs-utils

التراخيص: GPL-2.0-or-later

الاسم

nfsd — خادم NFS (Network File System)

الملخص

nfsd [-h] [-v] [-r] [-s] [-S] [-N nfsvers] [-V] [-L logfile] [-l facility] [-d debug_level] [-m max_connections]

الوصف

nfsd هو خادم NFS الذي يوفر خدمة تصدير نظام الملفات لعملاء NFS. يسمح للعملاء بالوصول إلى الملفات والمجلدات الموجودة على الخادم عبر الشبكة.

يمكن تهيئة nfsd عبر ملف التهيئة /etc/nfs.conf أو عبر خيارات سطر الأوامر.

الخيارات

-h
عرض رسالة المساعدة.
-v
عرض معلومات الإصدار.
-r
تشغيل كخدمة مستقلة.
-s
تشغيل مع دعم NFSv4.1.
-S
تشغيل مع دعم NFSv4.2.
-N nfsvers
تحديد إصدارات NFS التي سيتم دعمها (مثل 2، 3، 4).
-V
عرض معلومات حول إصدارات NFS المدعومة.
-L logfile
تحديد ملف السجل.
-l facility
تحديد تسهيلات التسجيل (syslog facility).
-d debug_level
تحديد مستوى التصحيح.
-m max_connections
تحديد الحد الأقصى لعدد الاتصالات.

ملف التهيئة

يمكن تكوين nfsd باستخدام ملف /etc/nfs.conf. يتبع الملف تنسيق INI ويتضمن أقسامًا مثل [nfsd] و [mountd] و [statd].

مثال على ملف /etc/nfs.conf:

[nfsd]
port = 2049
threads = 8

[mountd]
port = 20048
num_threads = 4

ملاحظات

يتطلب تشغيل nfsd صلاحيات الجذر (root).

يجب تكوين rpcbind (أو systemd-rpc-rpcbind.service) وتشغيله قبل تشغيل nfsd.

يجب أيضًا تكوين ملفات تصدير NFS في /etc/exports.

انظر أيضًا

exports(5), rpc.mountd(8), rpc.statd(8), nfs.conf(5)
