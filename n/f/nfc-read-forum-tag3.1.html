nfc-read-forum-tag3(1)

الحزمة: libnfc

التراخيص: LGPL3

nfc-read-forum-tag3(1) أدوات NFC nfc-read-forum-tag3(1)

الاسم

nfc-read-forum-tag3 - استخراج رسالة NDEF من علامة NFC Forum Type 3

المُلَخَّص

nfc-read-forum-tag3 [ -q ] -o ملف

الوصف

nfc-read-forum-tag3 هذه الأداة تستخرج (إذا كانت متاحة) رسائل NDEF الموجودة في علامة NFC Forum Type 3 إلى ملف.

الخيارات

-o ملف : إخراج رسالة NDEF المستخرجة إلى ملف (استخدم -o - للإخراج إلى الإخراج القياسي).

-q : كن هادئًا، لا تعرض معلومات تحليل كتلة السمات.

الأخطاء

يرجى الإبلاغ عن أي أخطاء على متعقب المشكلات الخاص بـ libnfc على العنوان:


https://github.com/nfc-tools/libnfc/issues
