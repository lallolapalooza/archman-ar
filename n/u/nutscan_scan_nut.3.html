nutscan_scan_nut(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

NUTSCAN_SCAN_NUT(3) دليل NUT NUTSCAN_SCAN_NUT(3)

الاسم

nutscan_scan_nut - مسح الشبكة بحثًا عن خدمات NUT المتاحة.

الملخص

        #include <nut-scan.h>
        #include <unistd.h> /* useconds_t */
        nutscan_device_t * nutscan_scan_nut(
                const char * startIP,
                const char * stopIP,
                const char * port,
                useconds_t usec_timeout);
        nutscan_device_t * nutscan_scan_ip_range_nut(
                nutscan_ip_range_list_t * irl,
                const char * port,
                useconds_t usec_timeout);

الوصف

تحاول الدوال nutscan_scan_nut() و nutscan_scan_ip_range_nut() اكتشاف خدمات NUT المتاحة والأجهزة المرتبطة بها. تقوم الأولى بإصدار طلب NUT على كل عنوان IP يتراوح بين startIP و stopIP، حيث startIP إلزامي و stopIP اختياري (يتم مسح عنوان startIP واحد إذا كان stopIP هو NULL)؛ بينما يمكن للثانية السير عبر نطاقات عناوين IP متعددة ممثلة بهيكل nutscan_ip_range_list_t.

يمكن أن تكون وسائط IP هذه عناوين IPv4 أو IPv6 أو أسماء مضيفين.

يجب عليك استدعاء nutscan_init(3) قبل استخدام هذه الدالة.

يمكن تمرير رقم منفذ port معين، أو NULL لاستخدام منفذ NUT الافتراضي.

تنتظر هذه الدالة حتى usec_timeout ميكرو ثانية قبل اعتبار أن عنوان IP لا يستجيب لاستعلامات NUT.

قيمة الإرجاع

تُرجع الدالة nutscan_scan_nut() مؤشرًا إلى هيكل nutscan_device_t يحتوي على جميع الأجهزة التي تم العثور عليها أو NULL إذا حدث خطأ أو لم يتم العثور على جهاز.
