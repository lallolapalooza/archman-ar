nutclient_logout(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_MISC(3) دليل NUT LIBNUTCLIENT_MISC(3)

الاسم

libnutclient_misc, nutclient_authenticate, nutclient_logout, nutclient_device_login, nutclient_get_device_num_logins, nutclient_device_master, nutclient_device_forced_shutdown - دوال متنوعة في مكتبة الوصول عالية المستوى لـ Network UPS Tools

الملخص

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        void nutclient_authenticate(
                NUTCLIENT_t client,
                const char* login, const char* passwd);
        void nutclient_logout(NUTCLIENT_t client);
        void nutclient_device_login(NUTCLIENT_t client, const char* dev);
        int nutclient_get_device_num_logins(NUTCLIENT_t client, const char* dev);
        void nutclient_device_primary(NUTCLIENT_t client, const char* dev);
        /* اسم مهمل: */
        void nutclient_device_master(NUTCLIENT_t client, const char* dev);
        void nutclient_device_forced_shutdown(NUTCLIENT_t client, const char* dev);

الوصف

•الدالة nutclient_authenticate() تقوم بتصديق المستخدم.
•login هو اسم المستخدم.
•passwd هي كلمة مرور المستخدم.
•الدالة nutclient_logout() تقوم بالقطع بأمان من الخادم.
•الدالة nutclient_device_login() تسجل حقيقة أن نظامًا ما يسحب الطاقة من وحدة UPS هذه.
•الدالة nutclient_get_device_num_logins() تسترجع عدد العملاء الذين تم تسجيلهم لهذا الجهاز.
•الدالتان nutclient_device_master() و nutclient_device_primary() (ملاحظة: الأولى تم إهمالها منذ NUT v2.8.0 لصالح الأخيرة) تتأكدان من أن الدوال ذات الوضع الأساسي مثل FSD متاحة إذا لزم الأمر.
•الدالة nutclient_device_forced_shutdown() تقوم بتعيين علامة "الإغلاق القسري" (FSD) على الجهاز.

الوسائط الشائعة:

•dev هو اسم الجهاز.
