nutclient_get_device_commands(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_COMMAND(3) NUT Manual LIBNUTCLIENT_COMMAND(3)

الاسم

libnutclient_commands, nutclient_get_device_commands, nutclient_has_device_command, nutclient_get_device_command_description, nutclient_execute_device_command - وظائف متعلقة بالأوامر الفورية في مكتبة الوصول عالية المستوى لعميل NUT

الملخص

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_commands(
                NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_command(
                NUTCLIENT_t client,
                const char* dev, const char* cmd);
        char* nutclient_get_device_command_description(
                NUTCLIENT_t client,
                const char* dev, const char* cmd);
        void nutclient_execute_device_command(
                NUTCLIENT_t client,
                const char* dev, const char* cmd,
                const char* param="");

الوصف

تسمح هذه الدوال بإدارة الأوامر الفورية للأجهزة.

•تقوم الدالة nutclient_get_device_commands() باسترداد قائمة بأسماء الأوامر لجهاز معين.

يجب تحرير strarr المُعادة بواسطة strarr_free.

•تقوم الدالة nutclient_has_device_command باختبار ما إذا كان الأمر المحدد مدعومًا بواسطة الجهاز.

تُرجع 1 إذا كان مدعومًا و 0 إذا لم يكن كذلك.

•تقوم الدالة nutclient_get_device_command_description باسترداد وصف الأمر، إن وجد.

يجب تحرير السلسلة المُعادة بواسطة free(3) (انظر libnutclient_general(3)).

•تهدف الدالة nutclient_execute_device_command إلى تنفيذ الأمر الفوري، مع معامل اختياري.

المعاملات الشائعة:

•dev هو اسم الجهاز.
•cmd هو اسم الأمر الفوري.
