nutclient_tcp_disconnect(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_TCP(3) دليل NUT LIBNUTCLIENT_TCP(3)

الاسم

libnutclient_tcp, nutclient_tcp_create_client, nutclient_tcp_is_connected, nutclient_tcp_disconnect, nutclient_tcp_reconnect, nutclient_tcp_set_timeout, nutclient_tcp_get_timeout - وظائف بروتوكول TCP للوصول عالي المستوى لمكتبة عميل Network UPS Tools

الملخص

        #include <nutclient.h>
        #include <cstdint> /* uint16_t */
        #include <ctime> /* time_t */
        typedef NUTCLIENT_t NUTCLIENT_TCP_t;
        NUTCLIENT_TCP_t nutclient_tcp_create_client(
                const char* host, uint16_t port);
        int nutclient_tcp_is_connected(NUTCLIENT_TCP_t client);
        void nutclient_tcp_disconnect(NUTCLIENT_TCP_t client);
        int nutclient_tcp_reconnect(NUTCLIENT_TCP_t client);
        void nutclient_tcp_set_timeout(NUTCLIENT_TCP_t client, time_t timeout);
        time_t nutclient_tcp_get_timeout(NUTCLIENT_TCP_t client);

الوصف

تسمح هذه الوظائف بإدارة الاتصالات بـ upsd(8) باستخدام بروتوكول TCP الخاص بـ NUT.

•تقوم الوظيفة nutclient_tcp_create_client() بإنشاء سياق NUTCLIENT_TCP_t وتعيين الاتصال بـ upsd على host و port.

يجب تحرير السياق بواسطة nutclient_destroy().

•يمكن أن يكون host اسم خادم أو عنوان IPv4 أو IPv6 صالح مثل "localhost" أو "127.0.0.1" أو "::1".
•port هو منفذ TCP صالح، عادةً 3493.
•تختبر الوظيفة nutclient_tcp_is_connected() ما إذا كان الاتصال صالحًا.
•تجبر الوظيفة nutclient_tcp_disconnect() على قطع الاتصال المحدد.
•تجبر الوظيفة nutclient_tcp_reconnect() على إعادة توصيل اتصال، مع قطع الاتصال إذا لزم الأمر.
•تقوم الوظيفة nutclient_tcp_set_timeout() بتعيين مدة المهلة لعمليات الإدخال/الإخراج.
•تقوم الوظيفة nutclient_tcp_get_timeout() باسترجاع مدة المهلة لعمليات الإدخال/الإخراج.

timeout يتم تحديد القيم بالثواني، استخدم القيم السالبة للانتظار.
