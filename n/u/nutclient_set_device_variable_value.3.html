nutclient_set_device_variable_value(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_VARIABL(3) دليل NUT LIBNUTCLIENT_VARIABL(3)

الاسم

libnutclient_variables, nutclient_get_device_variables, nutclient_get_device_rw_variables, nutclient_has_device_variable, nutclient_get_device_variable_description, nutclient_get_device_variable_values, nutclient_set_device_variable_value, nutclient_set_device_variable_values - دوال متعلقة بالمتغيرات في مكتبة الوصول العالي المستوى لأدوات UPS الشبكية

الملخص

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_variables(NUTCLIENT_t client,
                const char* dev);
        strarr nutclient_get_device_rw_variables(NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_variable(NUTCLIENT_t client,
                const char* dev, const char* var);
        char* nutclient_get_device_variable_description(NUTCLIENT_t client,
                const char* dev, const char* var);
        strarr nutclient_get_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var);
        void nutclient_set_device_variable_value(NUTCLIENT_t client,
                const char* dev, const char* var, const char* value);
        void nutclient_set_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var, const strarr values);

الوصف

تسمح هذه الدوال بإدارة متغيرات الأجهزة.

•الدالة nutclient_get_device_variables() تسترد قائمة بأسماء المتغيرات لجهاز معين.

يجب تحرير strarr المعاد بواسطة strarr_free (انظر libnutclient_general(3)).

•الدالة nutclient_get_device_rw_variables تسترد قائمة بأسماء المتغيرات للقراءة والكتابة لجهاز معين.

يجب تحرير strarr المعاد بواسطة strarr_free (انظر libnutclient_general(3)).

•الدالة nutclient_has_device_variable تختبر ما إذا كان المتغير المحدد مدعومًا من قبل الجهاز.

تعيد 1 إذا كان مدعومًا و 0 إذا لم يكن كذلك.

•الدالة nutclient_get_device_variable_description تسترد وصف المتغير، إن وجد.

يجب تحرير السلسلة النصية المعادة بواسطة free(3).

•الدالة nutclient_get_device_variable_values تعيد قيم المتغير (عادةً قيمة واحدة).

يجب تحرير strarr المعاد بواسطة strarr_free (انظر libnutclient_general(3)).

•الدالة nutclient_set_device_variable_value تهدف إلى تعيين قيمة المتغير المحدد.
•الدالة nutclient_set_device_variable_values تهدف إلى تعيين قيم متعددة للمتغير المحدد.

الحجج الشائعة:

•dev هو اسم الجهاز.
•var هو اسم المتغير.
•value هي قيمة المتغير.
•values هي مصفوفة قيم المتغير.
