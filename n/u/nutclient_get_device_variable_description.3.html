nutclient_get_device_variable_description(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_VARIABL(3) دليل NUT LIBNUTCLIENT_VARIABL(3)

الاسم

libnutclient_variables, nutclient_get_device_variables, nutclient_get_device_rw_variables, nutclient_has_device_variable, nutclient_get_device_variable_description, nutclient_get_device_variable_values, nutclient_set_device_variable_value, nutclient_set_device_variable_values - وظائف متعلقة بالمتغيرات في مكتبة الوصول عالية المستوى لأدوات UPS الشبكية

الملخص

        #include <nutclient.h>
        typedef void* NUTCLIENT_t;
        typedef char** strarr;
        strarr nutclient_get_device_variables(NUTCLIENT_t client,
                const char* dev);
        strarr nutclient_get_device_rw_variables(NUTCLIENT_t client,
                const char* dev);
        int nutclient_has_device_variable(NUTCLIENT_t client,
                const char* dev, const char* var);
        char* nutclient_get_device_variable_description(NUTCLIENT_t client,
                const char* dev, const char* var);
        strarr nutclient_get_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var);
        void nutclient_set_device_variable_value(NUTCLIENT_t client,
                const char* dev, const char* var, const char* value);
        void nutclient_set_device_variable_values(NUTCLIENT_t client,
                const char* dev, const char* var, const strarr values);

الوصف

تسمح هذه الوظائف بإدارة متغيرات الأجهزة.

•تقوم الدالة nutclient_get_device_variables() باسترداد قائمة بأسماء المتغيرات لجهاز معين.

يجب تحرير strarr المُرجعة بواسطة strarr_free (راجع libnutclient_general(3)).

•تقوم الدالة nutclient_get_device_rw_variables باسترداد قائمة بأسماء المتغيرات القابلة للقراءة والكتابة لجهاز معين.

يجب تحرير strarr المُرجعة بواسطة strarr_free (راجع libnutclient_general(3)).

•تختبر الدالة nutclient_has_device_variable ما إذا كان المتغير المحدد مدعومًا من قبل الجهاز.

تُرجع 1 إذا كان مدعومًا و 0 إذا لم يكن كذلك.

•تقوم الدالة nutclient_get_device_variable_description باسترداد وصف المتغير، إن وجد.

يجب تحرير السلسلة النصية المُرجعة بواسطة free(3).

•تُرجع الدالة nutclient_get_device_variable_values قيم المتغير (عادةً قيمة واحدة).

يجب تحرير strarr المُرجعة بواسطة strarr_free (راجع libnutclient_general(3)).

•تهدف الدالة nutclient_set_device_variable_value إلى تعيين قيمة المتغير المحدد.
•تهدف الدالة nutclient_set_device_variable_values إلى تعيين قيم متعددة للمتغير المحدد.

الوسائط الشائعة:

•dev هو اسم الجهاز.
•var هو اسم المتغير.
•value هي قيمة المتغير.
•values هي مصفوفة قيم المتغير.
