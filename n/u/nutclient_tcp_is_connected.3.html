nutclient_tcp_is_connected(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

LIBNUTCLIENT_TCP(3) دليل NUT LIBNUTCLIENT_TCP(3)

الاسم

libnutclient_tcp, nutclient_tcp_create_client, nutclient_tcp_is_connected, nutclient_tcp_disconnect, nutclient_tcp_reconnect, nutclient_tcp_set_timeout, nutclient_tcp_get_timeout - وظائف بروتوكول TCP للوصول عالي المستوى لمكتبة عملاء Network UPS Tools

ملخص

        #include <nutclient.h>
        #include <cstdint> /* uint16_t */
        #include <ctime> /* time_t */
        typedef NUTCLIENT_t NUTCLIENT_TCP_t;
        NUTCLIENT_TCP_t nutclient_tcp_create_client(
                const char* host, uint16_t port);
        int nutclient_tcp_is_connected(NUTCLIENT_TCP_t client);
        void nutclient_tcp_disconnect(NUTCLIENT_TCP_t client);
        int nutclient_tcp_reconnect(NUTCLIENT_TCP_t client);
        void nutclient_tcp_set_timeout(NUTCLIENT_TCP_t client, time_t timeout);
        time_t nutclient_tcp_get_timeout(NUTCLIENT_TCP_t client);

الوصف

تسمح هذه الوظائف بإدارة الاتصالات بـ upsd(8) باستخدام بروتوكول NUT TCP.

•تقوم الدالة nutclient_tcp_create_client() بإنشاء سياق NUTCLIENT_TCP_t وتهدف إلى الاتصال بـ upsd على host و port.

يجب تحرير السياق بواسطة nutclient_destroy().

•يمكن أن يكون host اسم خادم أو عنوان IPv4 أو IPv6 صالح مثل "localhost" أو "127.0.0.1" أو "::1".
•port هو منفذ TCP صالح، عادةً 3493.
•تختبر الدالة nutclient_tcp_is_connected() ما إذا كان الاتصال صالحًا.
•تجبر الدالة nutclient_tcp_disconnect() على قطع الاتصال المحدد.
•تجبر الدالة nutclient_tcp_reconnect() على إعادة توصيل اتصال، مع فصله إذا لزم الأمر.
•تقوم الدالة nutclient_tcp_set_timeout() بتعيين مدة مهلة عمليات الإدخال/الإخراج.
•تقوم الدالة nutclient_tcp_get_timeout() باسترداد مدة مهلة عمليات الإدخال/الإخراج.

يتم تحديد قيم timeout بالثواني، استخدم قيمًا سالبة للحظر.
