Network UPS Tools

NAME

nutdrv_siemens_sitop - Driver for Siemens SITOP UPS modules

SYNOPSIS

nutdrv_siemens_sitop

As a user, you should never run this program directly. It is intended to be run by the upsd(8) daemon.

SUPPORTED HARDWARE

This driver supports Siemens SITOP DC UPS modules with a serial interface (RS-232 or RS-485) and the appropriate communication interface module (e.g., 6EP1334-2BA00, 6EP1334-2BF00, 6EP1336-2BA00, 6EP1336-2BF00).

DEVICE SETTINGS

The following settings can be configured in the ups.conf(5) file:

port
The serial port to which the UPS is connected. Example: /dev/ttyS0 or /dev/ttyUSB0.
slaveAddress
The address of the UPS module on the serial bus. This is usually 1.
baudrate
The baud rate of the serial connection. Common values are 9600 or 19200.
parity
The parity setting for the serial connection. Usually none.
stopbits
The number of stop bits. Usually 1.
databits
The number of data bits. Usually 8.

USB DRIVER

If you are using a USB-to-serial adapter, you may need to install a USB serial driver (e.g., usbserial or ftdi_sio) and ensure that the device node is created correctly (e.g., /dev/ttyUSB0).

POLLING

The driver polls the UPS module at regular intervals to retrieve status information.

EXTRA ARGUMENTS

No extra arguments are supported.

INSTANT_COMMANDS

This driver does not support instant commands.

INSTALLATION

  1. Install the Network UPS Tools package.

  2. Configure the nutdrv_siemens_sitop driver in ups.conf(5).

    [siemens_sitop]
    driver = nutdrv_siemens_sitop
    port = /dev/ttyUSB0
    slaveAddress = 1
    baudrate = 9600
    parity = none
    stopbits = 1
    databits = 8

  3. Start the upsd(8) daemon.

    # upsd

  4. Verify that the UPS is detected and reporting status.

    # upscli show siemens_sitop

DIAGNOSTICS

Check the upsd(8) log file for any error messages related to the nutdrv_siemens_sitop driver.

KNOWN ISSUES AND BUGS

None known at this time.

AUTHOR

The initial development of this driver was done by Christian Weisgerber.
