nutscan_add_ip_range(3)

الحزمة: nut

التراخيص: GPL-2.0-or-later AND GPL-3.0-or-later

NUTSCAN_ADD_IP_RANGE(3) دليل NUT NUTSCAN_ADD_IP_RANGE(3)

الاسم

nutscan_add_ip_range - إضافة إدخال بنطاق عنوان IP (عناوين البدء والانتهاء) إلى بنية `nutscan_ip_range_list_t`.

ملخص

        #include <nut-scan.h>
        /* نطاق عنوان IP واحد: */
        typedef struct nutscan_ip_range_s {
                char * start_ip;
                char * end_ip;
                struct nutscan_ip_range_s * next;
        } nutscan_ip_range_t;
        /* قائمة نطاقات عناوين IP والبيانات المساعدة: */
        typedef struct nutscan_ip_range_list_s {
                nutscan_ip_range_t * ip_ranges;         /* قائمة مرتبطة فعلية للإدخالات، الإدخال الأول */
                nutscan_ip_range_t * ip_ranges_last;    /* مؤشر إلى نهاية القائمة لإضافات أسرع */
                size_t ip_ranges_count;                 /* عداد للإدخالات المضافة */
        } nutscan_ip_range_list_t;
        size_t nutscan_add_ip_range(
                nutscan_ip_range_list_t *irl,
                char * start_ip,
                char * end_ip);

الوصف

يمكن للدالة nutscan_add_ip_range() إنشاء وإضافة إدخال nutscan_ip_range_t بناءً على المدخلات المقدمة إلى بنية nutscan_ip_range_list_t المحددة. يتم إرجاع عدد الإدخالات الناتجة في البنية، أو 0 في حالة الأخطاء غير القاتلة.

تتخطى هذه الدالة العمل إذا:

•مؤشر البنية هو NULL (يتم إرجاع 0)؛
•لم يتم تقديم أي من start_ip أو end_ip، أي أنهما كلاهما بقيم NULL (يتم إرجاع الطول الحالي للقائمة من البنية)؛
•فشل تخصيص الإدخال (قاتل).

إذا تم توفير قيمة واحدة فقط من start_ip أو end_ip (غير NULL)، يتم إنشاء نطاق عنوان واحد مع تعيين كلا العنوانين إلى نفس قيمة المؤشر.

يجب تهيئة البنية قبل استخدامها بواسطة nutscan_init_ip_ranges().

يجب على المتصل تحرير محتويات البنية بعد الانتهاء من استخدامها عن طريق استدعاء nutscan_free_ip_ranges() (بعد ذلك يمكن إعادة استخدام البنية لقائمة جديدة)، وتحرير كائن البنية نفسه صراحةً إذا تم تخصيصه ديناميكيًا (على سبيل المثال، عن طريق استدعاء nutscan_init_ip_ranges(NULL)).

ملاحظات

تقنيًا، يتم تعريف الدالة حاليًا في الملف nutscan-ip.h.

حاليًا لا توجد فحوصات للإدخالات المكررة أو المتداخلة، لذلك يمكن إضافة نفس عناوين IP ونطاقات عناوين IP بالكامل إلى القائمة (وسيتم فحصها في النهاية) عدة مرات.
