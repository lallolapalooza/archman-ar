nmbug(1)

الحزمة: notmuch-runtime

التراخيص: GPL3

NMBUG(1) notmuch NMBUG(1)

الاسم

nmbug - إدارة أخطاء notmuch باستخدام git

الملخص

notmuch git [-h] [-N] [-C repo] [-p prefix] [-v] [-l log level] subcommand

nmbug [-h] [-C repo] [-p prefix] [-v] [-l log level] subcommand

الوصف

إدارة علامات notmuch باستخدام Git.

الخيارات

الخيارات المدعومة لـ notmuch git تشمل

-h, --help
عرض رسالة المساعدة والخروج
-N, --nmbug
تعيين القيم الافتراضية لـ --tag-prefix و --git-dir المناسبة لمتعقب أخطاء notmuch
-C <repo>, --git-dir <repo>
العمل على مستودع git repo. انظر موقع المستودع للقيم الافتراضية.
-p <prefix>, --tag-prefix <prefix>
العمل فقط على العلامات التي تبدأ بالبادئة prefix. انظر قيمة البادئة للقيم الافتراضية.
-v, --version
عرض رقم إصدار notmuch-git والخروج
-l <level>, --log-level <level>
مستوى تفصيل السجل، أحد الخيارات التالية: critical، error، warning، info، debug. الافتراضي هو warning.

الأوامر الفرعية

للحصول على مساعدة حول أمر فرعي معين، قم بتشغيل: 'notmuch-git ... <command> --help'.

archive [tree-ish] [arg ...]

تصدير أرشيف tar لمجموعة علامات ملتزم بها باستخدام 'git archive'. انظر محتويات المستودع لمزيد من التفاصيل حول محتويات الأرشيف.

tree-ish

الشجرة أو الالتزام لإنتاج أرشيف له. الافتراضي هو 'HEAD'.

arg
checkout [-f|--force]

تحديث قاعدة بيانات notmuch من git.

هذا مفيد بشكل أساسي للتخلي عن تغييراتك في notmuch فيما يتعلق بـ git.

[-f|--force]

تجاوز الفحوصات التي تمنع تعديل العلامات لأجزاء كبيرة من الرسائل في قاعدة البيانات. انظر أيضًا git.safe_fraction.

clone <repository>

إنشاء مستودع notmuch git محلي من مصدر بعيد.

هذا يغلف 'git clone'، ويضيف بعض الخيارات لتجنب إنشاء شجرة عمل مع الحفاظ على فروع التتبع البعيد والمستودعات الأصل.

repository
commit [-f|--force] [message]

التزام العلامات المطابقة للبادئة من قاعدة بيانات notmuch إلى git.

message

نص اختياري لرسالة الالتزام.

-f|--force

تجاوز الفحوصات التي تمنع تعديل العلامات لأجزاء كبيرة من الرسائل في قاعدة البيانات. انظر أيضًا git.safe_fraction.

fetch [remote]

جلب التغييرات من المستودع البعيد.

remote

تجاوز الإعداد الافتراضي المحدد في branch.<name>.remote لجلب التغييرات من مستودع بعيد معين (على سبيل المثال، origin).

help

عرض مساعدة موجزة لأمر notmuch git.

init [--format-version=N]

إنشاء مستودع notmuch git فارغ.

هذا يغلف 'git init' مع بعض الخطوات الإضافية لدعم أوامر status و commit اللاحقة.

--format-version=N

إنشاء مستودع بتنسيق الإصدار N. افتراضيًا، يستخدم notmuch-git أعلى إصدار مدعوم، وهو أفضل خيار لمعظم حالات الاستخدام.

log [arg ...]

غلاف لأمر 'git log'.

arg

سيتم تمرير وسيطات إضافية إلى 'git log'.

بعد تشغيل notmuch git fetch، يمكنك فحص التغييرات باستخدام

$ notmuch git log HEAD..@{upstream}
merge [reference]

دمج التغييرات من 'reference' في HEAD وتحميل النتيجة في notmuch.

reference

المرجع، عادةً رؤوس الفروع الأخرى، لدمجها في فرعنا. الافتراضي هو @{upstream}.

pull [repository] [refspec ...]

سحب (دمج) تغييرات المستودع البعيد إلى notmuch.

pull يعادل fetch متبوعًا بـ merge. نستخدم المستودع المعد افتراضيًا لـ git لفرعك الحالي (branch.<name>.repository، عادةً origin، و branch.<name>.merge، عادةً master أو main).

repository

المستودع "البعيد" الذي هو مصدر السحب. يمكن أن يكون هذا الوسيط إما URL (انظر قسم GIT URLS في

الاسم

nmbug - واجهة لـ notmuch و git

الملخص

nmbug [option ...] [command [args ...]]

الوصف

أداة مساعدة لربط قاعدة بيانات notmuch ومستودع git. تُستخدم لتتبع حالات رسائل البريد الإلكتروني (التي تم تمييزها أو تصنيفها) كعلامات في مستودع git.

يمكن لـ nmbug تشغيل عدة أوامر. إذا لم يتم تحديد أمر، فسيتم افتراض الأمر status.

add message-id

إضافة رسالة message-id إلى قاعدة بيانات notmuch.

refspec
push [repository] [refspec]

دفع حالة notmuch git المحلية إلى مستودع بعيد.

repository
refspec
status

عرض التحديثات المعلقة في notmuch أو مستودع git.

يطبع أسطرًا بالشكل

ng Message-Id tag

حيث n هو حرف واحد يمثل حالة قاعدة بيانات notmuch

A

العلامة موجودة في قاعدة بيانات notmuch، ولكن لم يتم الالتزام بها في git (بشكل مكافئ، تم حذف العلامة في مستودع git، مثلًا عن طريق السحب، ولكن لم يتم استعادتها إلى قاعدة بيانات notmuch).

D

العلامة موجودة في مستودع git، ولكن لم يتم استعادتها إلى قاعدة بيانات notmuch (بشكل مكافئ، تم حذف العلامة في notmuch).

U

الرسالة غير معروفة (مفقودة من قاعدة بيانات notmuch المحلية).

يمثل الحرف الثاني g (إذا كان موجودًا) اختلافًا بين الفروع المحلية والبعيدة. عادةً ما يحتاج تشغيل notmuch git fetch لتحديث هذا.

a

العلامة موجودة في المستودع البعيد، ولكن ليست في فرع git المحلي.

d

العلامة موجودة في فرع git المحلي، ولكن ليست في المستودع البعيد.

محتويات المستودع

يتم تخزين العلامات في مستودع git (ويتم تصديرها) كمجموعة من الملفات الفارغة. هذه الملفات الفارغة موجودة داخل دليل مسمى باسم معرف الرسالة.

فيما يلي، تمثل encode() ترميزًا آمنًا لنظام ملفات POSIX. يحافظ الترميز على الأحرف الأبجدية الرقمية، والأحرف +-_@=.,:. يتم استبدال جميع البايتات الأخرى بـ % متبوعة برقم ست عشري مكون من رقمين.

حاليًا، يمكن لـ notmuch-git قراءة أي إصدار من التنسيق، ولكن يمكنه فقط إنشاء مستودعات الإصدار 1 (عبر init).

الإصدار 0

هذا هو التنسيق القديم الذي أنشأته أداة nmbug قبل الإصدار 0.37. بالنسبة لرسالة بمعرف رسالة id، ولكل علامة tag، يوجد ملف فارغ بالمسار

tags/ encode (id) / encode (tag)

الإصدار 1

في الإصدار 1 من التنسيق والإصدارات الأحدث، يتم احتواء إصدار التنسيق في ملف علوي يسمى FORMAT.

بالنسبة لرسالة بمعرف رسالة id، ولكل علامة tag، يوجد ملف فارغ بالمسار

tags/ hash1 (id) / hash2 (id) encode (id) / encode (tag)

تمثل وظائف التجزئة كل بايت واحد من ناتج blake2b الست عشري.

مقارنة بـ الإصدار 0، هذا يقلل عدد الدلائل الفرعية داخل كل دليل.

موقع المستودع

يستخدم notmuch-git أول ما يلي ذو قيمة غير فارغة لتحديد موقع مستودع git.

  • الخيار --git-dir.
  • متغير البيئة NOTMUCH_GIT_DIR.
  • عنصر التكوين git.path
  • إذا تم استدعاؤه كـ nmbug أو مع الخيار --nmbug، فإن $HOME/.nmbug؛ وإلا فإن $XDG_DATA_HOME/notmuch/$NOTMUCH_PROFILE/git.

قيمة البادئة

يستخدم notmuch-git أول ما يلي ذو قيمة غير فارغة لتحديد بادئة العلامة.

  • الخيار --tag-prefix.
  • متغير البيئة NOTMUCH_GIT_PREFIX.
  • عنصر التكوين git.tag_prefix.
  • إذا تم استدعاؤه كـ nmbug أو مع الخيار --nmbug، فإن notmuch::؛ وإلا فإن السلسلة الفارغة.

البيئة

يؤثر المتغير NOTMUCH_PROFILE على موقع المستودع. إذا لم يتم تعيينه، فسيتم افتراض 'default'.

NOTMUCH_GIT_DIR
الموقع الافتراضي لمستودع git. يتم تجاوزه بواسطة --git-dir.
NOTMUCH_GIT_PREFIX
البادئة الافتراضية للعلامة (المرشح). يتم تجاوزها بواسطة --tag-prefix.
