--no-demangle
لا تفك تشفير أسماء الرموز منخفضة المستوى. هذا هو الإعداد الافتراضي.
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
يمكّن أو يعطّل حدًا لمقدار التكرار الذي يتم إجراؤه أثناء فك تشفير السلاسل النصية. نظرًا لأن تنسيقات ترميز الأسماء تسمح بمستوى لا نهائي من التكرار، فمن الممكن إنشاء سلاسل نصية قد يؤدي فك تشفيرها إلى استنفاد مساحة المكدس المتاحة على الجهاز المضيف، مما يؤدي إلى حدوث خطأ في الذاكرة. يحاول الحد منع حدوث ذلك عن طريق تقييد التكرار إلى 2048 مستوى من التداخل.

الإعداد الافتراضي هو تمكين هذا الحد، ولكن قد يكون تعطيله ضروريًا لفك تشفير الأسماء المعقدة حقًا. لاحظ مع ذلك أنه إذا تم تعطيل حد التكرار، فقد يحدث استنفاد للمكدس وسيتم رفض أي تقارير أخطاء حول مثل هذا الحدث.

-D
--dynamic
عرض الرموز الديناميكية بدلاً من الرموز العادية. هذا له معنى فقط للكائنات الديناميكية، مثل أنواع معينة من المكتبات المشتركة.
-f format
--format=format
استخدم تنسيق الإخراج format، والذي يمكن أن يكون "bsd"، "sysv"، "posix" أو "just-symbols". الإعداد الافتراضي هو "bsd". الحرف الأول فقط من format له أهمية؛ يمكن أن يكون كبيرًا أو صغيرًا.
-g
--extern-only
عرض الرموز الخارجية فقط.
-h
--help
عرض ملخص للخيارات الخاصة بـ nm والخروج.
--ifunc-chars=CHARS
عند عرض رموز دالة GNU غير المباشرة، ستقوم nm افتراضيًا باستخدام الحرف "i" لكل من الدوال غير المباشرة المحلية والدوال غير المباشرة العامة. يتيح الخيار --ifunc-chars للمستخدم تحديد سلسلة نصية تحتوي على حرف واحد أو حرفين. سيتم استخدام الحرف الأول لرموز الدالة غير المباشرة العامة وسيتم استخدام الحرف الثاني، إذا كان موجودًا، لرموز الدالة غير المباشرة المحلية.
j
نفس معنى --format=just-symbols.
-l
--line-numbers
لكل رمز، استخدم معلومات التصحيح لمحاولة العثور على اسم ملف ورقم سطر. بالنسبة للرمز المعرّف، ابحث عن رقم سطر عنوان الرمز. بالنسبة للرمز غير المعرّف، ابحث عن رقم سطر إدخال إعادة التعيين الذي يشير إلى الرمز. إذا كان من الممكن العثور على معلومات رقم السطر، فقم بطباعتها بعد معلومات الرمز الأخرى.
--inlines
عندما يكون الخيار -l نشطًا، إذا كان العنوان ينتمي إلى دالة تم تضمينها، فإن هذا الخيار يتسبب في طباعة معلومات المصدر لجميع النطاقات المحيطة وصولًا إلى أول دالة غير مضمنة أيضًا. على سبيل المثال، إذا قامت "main" بتضمين "callee1" التي قامت بتضمين "callee2"، وكان العنوان من "callee2"، فسيتم أيضًا طباعة معلومات المصدر الخاصة بـ "callee1" و "main".
-n
-v
--numeric-sort
فرز الرموز عدديًا حسب عناوينها، بدلاً من أبجديًا حسب أسمائها.
-p
--no-sort
لا تهتم بفرز الرموز بأي ترتيب؛ اطبعها بالترتيب الذي تم العثور عليها به.
-P
--portability
استخدم تنسيق الإخراج القياسي POSIX.2 بدلاً من التنسيق الافتراضي. يعادل -f posix.
-r
--reverse-sort
اعكس ترتيب الفرز (سواء كان رقميًا أو أبجديًا)؛ اجعل الأخير يأتي أولاً.
-S
--print-size
اطبع كل من القيمة والحجم للرموز المعرّفة لنمط الإخراج "bsd". هذا الخيار ليس له تأثير للكائنات التي لا تسجل أحجام الرموز، ما لم يتم استخدام --size-sort أيضًا، وفي هذه الحالة يتم عرض حجم محسوب.
-s
--print-armap
عند سرد الرموز من أعضاء الأرشيف، قم بتضمين الفهرس: خريطة (مخزنة في الأرشيف بواسطة ar أو ranlib) توضح أي الوحدات تحتوي على تعريفات لأي أسماء.
-t radix
--radix=radix
استخدم radix كأساس لطباعة قيم الرموز. يجب أن يكون d للعشري، o للثماني، أو x للسداسي عشري.
-u
--undefined-only
عرض الرموز غير المعرّفة فقط (تلك الخارجية لكل ملف كائن). افتراضيًا، يتم عرض كل من الرموز المعرّفة وغير المعرّفة.
-U
--defined-only
عرض الرموز المعرّفة فقط لكل ملف كائن. افتراضيًا، يتم عرض كل من الرموز المعرّفة وغير المعرّفة.
-V
--version
عرض رقم إصدار nm والخروج.
-X
يتم تجاهل هذا الخيار للتوافق مع إصدار AIX من nm. يأخذ معاملًا واحدًا يجب أن يكون السلسلة النصية 32_64. يتوافق الوضع الافتراضي لـ AIX nm مع -X 32، وهو غير مدعوم بواسطة GNU nm.
--plugin name
تحميل المكون الإضافي المسمى name لإضافة دعم لأنواع الأهداف الإضافية. هذا الخيار متاح فقط إذا تم بناء مجموعة الأدوات مع تمكين دعم المكونات الإضافية.

إذا لم يتم توفير --plugin، ولكن تم تمكين دعم المكونات الإضافية، فإن nm يقوم بالتكرار فوق الملفات في ${libdir}/bfd-plugins بترتيب أبجدي ويتم استخدام أول مكون إضافي يدعي الكائن المعني.

يرجى ملاحظة أن دليل البحث عن المكونات الإضافية هذا ليس هو نفسه المستخدم بواسطة خيار -plugin الخاص بـ ld. لكي يقوم nm باستخدام مكون إضافي للرابط، يجب نسخه إلى دليل ${libdir}/bfd-plugins. للتجميعات المستندة إلى GCC، يسمى مكون إضافي الرابط liblto_plugin.so.0.0.0. للتجميعات المستندة إلى Clang، يسمى LLVMgold.so. مكون إضافي GCC متوافق دائمًا مع الإصدارات السابقة، لذلك يكفي فقط نسخ الأحدث.

--size-sort
فرز الرموز حسب الحجم. بالنسبة لكائنات ELF، تتم قراءة أحجام الرموز من ELF، بالنسبة لأنواع الكائنات الأخرى، يتم حساب أحجام الرموز كفرق بين قيمة الرمز وقيمة الرمز ذي القيمة الأعلى التالية. إذا تم استخدام تنسيق الإخراج "bsd"، فسيتم طباعة حجم الرمز، بدلاً من القيمة، ويجب استخدام -S لطباعة كل من الحجم والقيمة.

ملاحظة - هذا الخيار لا يعمل إذا تم تمكين --undefined-only لأن الرموز غير المعرّفة ليس لها حجم.

--special-syms
عرض الرموز التي لها معنى خاص خاص بالهدف. تُستخدم هذه الرموز عادةً بواسطة الهدف لمعالجة خاصة ولا تكون مفيدة بشكل طبيعي عند تضمينها في قوائم الرموز العادية. على سبيل المثال، بالنسبة لأهداف ARM، سيتخطى هذا الخيار رموز التعيين المستخدمة لوضع علامة على الانتقالات بين كود ARM، وكود THUMB، والبيانات.
--synthetic
تضمين الرموز الاصطناعية في الإخراج. هذه رموز خاصة تم إنشاؤها بواسطة الرابط لأغراض مختلفة. لا يتم عرضها افتراضيًا لأنها ليست جزءًا من الكود المصدري الأصلي للملف الثنائي.
--unicode=[default|invalid|locale|escape|hex|highlight]
يتحكم في عرض الأحرف متعددة البايت المشفرة بـ UTF-8 في السلاسل النصية. الإعداد الافتراضي (--unicode=default) هو عدم إعطائها أي معاملة خاصة. يعرض الخيار --unicode=locale التسلسل في اللغة الحالية، والتي قد تدعمها أو لا تدعمها. تعرض الخيارات --unicode=hex و --unicode=invalidها كسلاسل بايت سداسية عشرية محاطة بأقواس زاوية أو أقواس معقوفة.

يعرض الخيار --unicode=escapeها كسلاسل هروب (\uxxxx) ويعرض الخيار --unicode=highlightها كسلاسل هروب مظللة باللون الأحمر (إذا كان الجهاز المستهدف يدعم ذلك). المقصود من التلوين هو لفت الانتباه إلى وجود تسلسلات يونيكود حيث قد لا تكون متوقعة.

-W
--no-weak
لا تعرض الرموز الضعيفة.
--with-symbol-versions
--without-symbol-versions
يمكّن أو يعطّل عرض إصدارات الرموز.

NAME

nm – list symbols from object files

SYNOPSIS

nm [options] [FILES]...

DESCRIPTION

nm lists the symbols from object files. Each symbol is described by an object name and a symbol name. If the input files are archives, the symbols are listed from the object files within the archive. The default action is to display symbols in the following order: undefined symbols, then symbols sorted alphabetically.

The output format is:

  symbol_name, section, size, symbol_type, symbol_binding, symbol_other, symbol_visibility

The symbol type character indicates the symbol's binding and type:

a
Local symbol.
A
a symbol that is always true.
b
Symbol in the bss section.
B
a symbol that is always false.
c
Common symbol.
d
Symbol in the data section.
D
a debug flag.
f
Symbol in the text section (function).
F
a flag.
g
Global symbol.
G
a variable.
i
Symbol is in the .i section.
I
Indirect symbol.
l
Local symbol.
m
Symbol is in the .m section.
M
a mut symbol.
n
Symbol is in the .n section.
N
a string constant.
o
Symbol is in the .o section.
O
a constant.
p
Symbol is in the .p section.
P
a parameter.
r
Symbol is in the .r section.
R
a register.
s
Symbol is in the .s section.
S
a section name.
t
Symbol is in the .t section.
T
a type.
u
Undefined symbol.
U
a union.
v
Symbol is in the .v section.
V
a void.
w
Warning: Symbol is deprecated.
W
a weak symbol.
x
Symbol is in the .x section.
X
a variable.
y
Symbol is in the .y section.
Y
a string.
z
Symbol is in the .z section.
Z
a zero-sized symbol.
(space)
Symbol is not assigned to a section.
-
The symbol is not defined.

The symbol binding character indicates the symbol's binding:

local
Local symbol.
global
Global symbol.
weak
Weak symbol.

The symbol visibility character indicates the symbol's visibility:

default
Default visibility.
internal
Internal visibility.
hidden
Hidden visibility.
protected
Protected visibility.

Symbol version information is displayed as a suffix to the symbol name, preceded by an @ character. For example foo@VER_1. If the version is the default version to be used when resolving unversioned references to the symbol then it is displayed as a suffix preceded by two @ characters. For example foo@@VER_2. By default, symbol version information is displayed.

OPTIONS

-a
Print only absolute symbols.
-A
Print the name of the input file for each symbol.
-C
Demangle C++ symbol names.
-c
Print only global symbols.
-d
Print only undefined symbols.
-e
Print only external symbols.
-f
Print only non-common symbols.
-g
Print only global symbols.
-h
Print only symbols defined in the text section.
-i
Print only symbols defined in the init section.
-j
Print only symbols defined in the jcr section.
-k
Print only symbols defined in the .kdata section.
-l
Print only local symbols.
-m
Print the linker map.
-n
Print only symbols defined in the .note section.
-o
Print only symbols defined in the .o section.
-p
Print the symbols in reverse order.
-r
Print only symbols defined in the .rdata section.
-s
Print only symbols defined in the .sdata section.
-t
Print only symbols defined in the .tdata section.
-u
Print only undefined symbols.
-v
Print version information.
-w
Do not display symbol version information.
-x
Print symbols in hexadecimal format.
-X
Print symbols in hexadecimal format.
-z
Print only symbols defined in the .zdebug section.
--target=bfdname
Specify an object code format other than your system's default format.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
