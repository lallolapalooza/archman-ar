nms2dlf(1)

الحزمة: lire

التراخيص: GPL-2.0-only

NMS2DLF.IN(1) وثائق LogReport's Lire NMS2DLF.IN(1)

الاسم

nms2dlf - تحويل ملفات سجل SMTP الخاصة بخادم Netscape Messaging Server إلى صيغة البريد الإلكتروني DLF

الملخص

nms2dlf STDIN STDOUT

الوصف

يقوم هذا البرنامج بتحويل ملف السجل الذي تم إنشاؤه بواسطة خدمة SMTP الخاصة بخادم Netscape Messaging Server إلى صيغة البريد الإلكتروني DLF.

لمعالجة ملف السجل بشكل صحيح، تحتاج إلى تمكين تسجيل الوحدات التالية:

- SMTP-Accept
- SMTP-Deliver
- Error-Handler
- Mailbox-Deliver (يجب تمكينها)

القيود

تم تطوير محول DLF هذا لإصدار Netscape Messaging Server 4.1. قد تعمل الإصدارات الأخرى أو قد لا تعمل. اتصل بمطوري LogReport إذا واجهت مشاكل مع هذا المحول.

يمكنك العثور على معلومات حول تنسيق السجل الذي يستخدمه Netscape Messaging Server على الرابط التالي:

http://developer.netscape.com/docs/manuals/messaging/41/ag/logging.htm

ليست كل الرسائل موثقة. ووجدنا أخطاء في التوثيق. تم عكس حقلي msgID و mailFrom في كل من SMTP-Accept و SMTP-Deliver مقارنة بما وصفه التوثيق.

تهيئة تسجيل وحدة Mailbox-Deliver

وجدنا أنه لا توجد سجلات من وحدة Mailbox-Delivery افتراضيًا. لإصلاح هذه المشكلة، يرجى التأكد من قيامك بما يلي:

1.
انتقل إلى خادم Netscape Messaging Server 4 MTA أو Message Store
2.
تولى دور مستخدم خادم البريد (عادةً لا ينبغي أن يكون هذا الجذر، ولكن عادةً مستخدم مثل mailsrv أو أي اسم تم تحديده وقت التثبيت، تحقق من ملكية الملفات في مثيل خادم البريد الخاص بك على سبيل المثال)
3.
انتقل إلى الموقع الصحيح، شيء مثل: server-root/msg-instance

على سبيل المثال، قد يكون: /usr/netscape/server4/msg-mymailserver

4.
نفذ الأمر: 
$ ./configutil -o service.smtp.mailbox-deliver.log -v yes
OK SET
5.
ثم تولى دور الجذر، وانتقل مرة أخرى إلى دليل المثيل الخاص بك مثل: /usr/netscape/server4/msg-mymailserver ونفذ الأمر: 
# ./stop-msg smtp
/usr/netscape/server4: Stopping SMTP daemon 16279 .... done: 16279
# ./start-msg smtp
/usr/netscape/server4: Starting SMTP daemon ..... done: 10820

وبعد ذلك ستبدأ في رؤية أسطر تبدو كالتالي:

[19/Jul/2002:08:31:54 +0200] amail2 smtpd[10820]: \
General Notice: SMTP-Accept:GZHGT501.C01:<200207190632.g6J6W7Y01389@\
esmtp.orangemail.ch>:[192.168.30.2]:192.168.30.2: \
<newsletter@gamezone.com>:19514:1:<hmarmy@orangemail.ch>
[19/Jul/2002:08:31:54 +0200] amail2 smtpd[10820]: General Notice: \
Mailbox-Deliver:GZHGT501.C01:<200207190632.g6J6W7Y01389@\
esmtp.orangemail.ch>:19516:1:hmarmy;

إذا لم يتم ذلك، فإن السطر الذي يحتوي على نمط Mailbox-Deliver أعلاه لن يكون موجودًا وسيقدم البرنامج نتائج خاطئة. سيتم عرض تحذير في سجل الأخطاء.

أمثلة

لمعالجة سجل كما ينتجه خادم Netscape Messaging Server

$ nms2dlf < mail.log

نادراً ما سيتم استخدام nms2dlf بمفرده، ولكنه على الأرجح سيتم استدعاؤه بواسطة lr_log2report:

$ lr_log2report nms < /var/log/mail.log
