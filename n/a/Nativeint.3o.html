Nativeint

Nativeint - Signed native integers.

module Nativeint : sig ... end

This module defines the type nativeint, which represents signed integers whose size is the machine's word size. The functions provided by this module are the same as those provided by the Int module, except that they operate on signed native integers.

The type nativeint is an alias for the type int, which is also an alias for the type Sys.int_code. This type is representation-compatible with the C int type, and the integers are interpreted as signed native integers.
