nix3-store-sign(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-store-sign(1) دليل الأوامر العام nix3-store-sign(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix store sign - توقيع مسارات المتجر بمفتاح محلي

الملخص

nix store sign [خيار…] تركيبات…

الخيارات

•
--key-file / -k ملف
الملف الذي يحتوي على المفتاح السري للتوقيع.
•
--stdin
قراءة التركيبات من الإدخال القياسي. لا يتم تطبيق تركيبة افتراضية.

خيارات التقييم الشائعة

•
--arg اسم تعبير
تمرير القيمة تعبير كوسيط اسم لدوال Nix.
•
--arg-from-file اسم مسار
تمرير محتويات الملف مسار كوسيط اسم لدوال Nix.
•
--arg-from-stdin اسم
تمرير محتويات الإدخال القياسي كوسيط اسم لدوال Nix.
•
--argstr اسم سلسلة
تمرير السلسلة سلسلة كوسيط اسم لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-المتجر
عنوان متجر Nix المستخدم للتقييم، أي لتخزين المشتقات (.drv) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I مسار
إضافة مسار إلى مدخلات المسار المستخدمة لحل مسارات البحث
يمكن تقديم هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake مرجع-أصلي مرجع-محلول
تجاوز سجلات الـ flake، وإعادة توجيه مرجع-أصلي إلى مرجع-محلول.

خيارات شائعة متعلقة بالـ Flake

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الـ flake.
•
--inputs-from flake-url
استخدام مدخلات الـ flake المحدد كسجلات.
•
--no-registries
عدم السماح بالبحث في سجلات الـ flake.
مهمل
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
عدم السماح بأي تحديثات لملف قفل الـ flake.
•
--no-write-lock-file
عدم كتابة ملف قفل الـ flake الجديد الذي تم إنشاؤه.
•
--output-lock-file مسار-قفل-flake
كتابة ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الجذر.
•
--override-input مسار-المدخل flake-url
تجاوز مدخل flake محدد (مثل dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الـ flake من الصفر.
مهمل
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file مسار-قفل-flake
قراءة ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الجذر.
•
--update-input مسار-المدخل
تحديث مدخل flake محدد (تجاهل إدخاله السابق في ملف القفل).
مهمل
استخدم nix flake update بدلاً من ذلك.

خيارات متعلقة بالتسجيل

•
--debug
ضبط مستوى تفصيل التسجيل إلى 'debug'.
•
--log-format التنسيق
ضبط تنسيق إخراج السجل؛ أحد الخيارات: raw, internal-json, bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل تفصيل التسجيل.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--all
Apply the operation to every store path.
•
--derivation
Operate on the store derivation rather than its outputs.
•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.
•
--recursive / -r
Apply operation to closure of the specified paths.
