nix3-flake-update(1)

nix3-flake-update(1) دليل الأوامر العامة nix3-flake-update(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix flake update - تحديث ملف قفل الـ flake

الخلاصة

nix flake update [خيار•] مدخلات•

أمثلة

•
تحديث جميع المدخلات (أي إعادة إنشاء ملف القفل من الصفر):
# nix flake update
تحذير: تحديث ملف القفل '/home/myself/repos/testflake/flake.lock':

• تم تحديث المدخل 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)

•
تحديث مدخل واحد فقط:
# nix flake update nixpkgs

• تم تحديث المدخل 'nixpkgs':

• تم تحديث المدخل 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)

ملاحظة
عند محاولة الإشارة إلى flake في دليل فرعي، اكتب ./another بدلاً من another. بخلاف ذلك، سيحاول Nix البحث عن الـ flake في السجل.

الوصف

يقوم هذا الأمر بتحديث المدخلات في ملف القفل (flake.lock). بشكل افتراضي، يتم تحديث جميع المدخلات. إذا لم يكن ملف القفل موجودًا، فسيتم إنشاؤه. إذا كانت المدخلات غير موجودة في ملف القفل، فستتم إضافتها.

على عكس أوامر nix flake الأخرى، يأخذ nix flake update قائمة بأسماء المدخلات لتحديثها كوسيطات موضعية ويتعامل مع الـ flake في الدليل الحالي. يمكنك تمرير flake-url مختلفة باستخدام --flake لتجاوز هذا الإعداد الافتراضي.

الأمر ذي الصلة nix flake lock ينشئ أيضًا ملفات قفل ويضيف المدخلات المفقودة، ولكنه أكثر أمانًا لأنه لن يقوم أبدًا بتحديث المدخلات الموجودة بالفعل في ملف القفل.

خيارات

•
--flake flake-url
الـ flake الذي سيتم العمل عليه. الافتراضي هو الدليل الحالي.

خيارات التقييم الشائعة

•
--arg name expr
مرر القيمة expr كوسيطة name لوظائف Nix.
•
--arg-from-file name path
مرر محتويات الملف path كوسيطة name لوظائف Nix.
•
--arg-from-stdin name
مرر محتويات الإدخال القياسي كوسيطة name لوظائف Nix.
•
--argstr name string
مرر السلسلة النصية string كوسيطة name لوظائف Nix.
•
--debugger
ابدأ بيئة تفاعلية إذا فشل التقييم.
•
--eval-store store-url
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين التعيينات (.drv files) والمدخلات التي تشير إليها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
أضف path إلى مسارات البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد التكوين nix-path و متغير البيئة NIX_PATH .
•
--override-flake original-ref resolved-ref
تجاوز سجلات الـ flakes، مع إعادة توجيه original-ref إلى resolved-ref.

خيارات شائعة متعلقة بالـ flakes

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الـ flake.
•
--inputs-from flake-url
استخدام مدخلات الـ flake المحدد كإدخالات للسجل.
•
--no-registries
لا تسمح بالبحث في سجلات الـ flakes.
تم إيقافه
استخدم --no-use-registries بدلاً من ذلك.
•
--output-lock-file flake-lock-path
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الـ flake العلوي.
•
--override-input input-path flake-url
تجاوز مدخل flake محدد (مثل dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الـ flake من الصفر.
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
