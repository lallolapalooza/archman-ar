nix3-store-copy-log(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-store-copy-log(1) دليل الأوامر العامة nix3-store-copy-log(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix store copy-log - نسخ سجلات البناء بين مخازن Nix

الملخص

nix store copy-log [خيار•••] قابل للتثبيت•••

أمثلة

•
لنسخ سجل بناء حزمة hello من https://cache.nixos.org إلى المخزن المحلي:
# nix store copy-log --from https://cache.nixos.org --eval-store auto nixpkgs#hello
يمكنك التحقق من أن السجل متاح محليًا:
# nix log --substituters '' nixpkgs#hello
(العلامة --substituters '' تتجنب الاستعلام عن https://cache.nixos.org للسجل.)
•
لنسخ السجل لـ اشتقاق مخزن محدد عبر SSH:
# nix store copy-log --to ssh-ng://machine /nix/store/ilgm50plpmcgjhcp33z6n4qbnpqfhxym-glibc-2.33-59.drv

الوصف

nix store copy-log ينسخ سجلات البناء بين مخزنين Nix. يتم تحديد مخزن المصدر باستخدام --from والمخزن الوجهة باستخدام --to. إذا تم حذف أحدهما، فسيتم استخدام المخزن المحلي افتراضيًا.

خيارات

•
--from مخزن-uri
عنوان URL لمخزن Nix المصدر.
•
--stdin
قراءة العناصر القابلة للتثبيت من المدخل القياسي. لا يتم تطبيق عنصر قابل للتثبيت افتراضي.
•
--to مخزن-uri
عنوان URL لمخزن Nix الوجهة.

خيارات التقييم الشائعة

•
--arg اسم تعبير
تمرير القيمة تعبير كوسيط اسم لدوال Nix.
•
--arg-from-file اسم مسار
تمرير محتويات الملف مسار كوسيط اسم لدوال Nix.
•
--arg-from-stdin اسم
تمرير محتويات المدخل القياسي كوسيط اسم لدوال Nix.
•
--argstr اسم سلسلة
تمرير السلسلة سلسلة كوسيط اسم لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-url-المخزن
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين الاشتقاقات (ملفات .drv) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I مسار
إضافة مسار إلى مسارات البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake مرجع-أصلي مرجع-تم-حله
تجاوز سجلات الـ flake، وإعادة توجيه مرجع-أصلي إلى مرجع-تم-حله.

خيارات شائعة متعلقة بالـ Flake

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الـ flake.
•
--inputs-from flake-url
استخدام مدخلات الـ flake المحدد كسجلات.
•
--no-registries
لا تسمح بالبحث في سجلات الـ flake.
تم إيقافه
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
لا تسمح بأي تحديثات لملف قفل الـ flake.
•
--no-write-lock-file
لا تكتب ملف قفل الـ flake الذي تم إنشاؤه حديثًا.
•
--output-lock-file مسار-قفل-flake
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--override-input مسار-المدخل flake-url
تجاوز مدخل flake محدد (على سبيل المثال dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
أعد إنشاء ملف قفل الـ flake من الصفر.
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file مسار-قفل-flake
اقرأ ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.

Name

nix — Manipulate the Nix package and function collector

Synopsis

nix [option...] command

Description

The Nix command-line tool is a powerful interface for managing Nix packages and executing Nix functions.

It supports a wide range of subcommands and options for various tasks related to Nix package management, flake operations, and system configuration.
