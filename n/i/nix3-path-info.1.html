nix3-path-info(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

الاسم

nix3-flake-update - تحديث مدخلات الشفرة.

الملخص

nix3-flake-update [--commit-lock-file] [--inputs-from flake-url] [--no-registries] [--no-update-lock-file] [--no-write-lock-file] [--output-lock-file flake-lock-path] [--override-input input-path flake-url] [--recreate-lock-file] [--reference-lock-file flake-lock-path] [--update-input input-path] [--debug] [--log-format format] [--print-build-logs / -L] [--quiet] [--verbose / -v] [--help] [--offline] [--option name value] [--refresh] [--repair] [--version] [--all] [--derivation] [--expr expr] [--file / -f file] [--recursive / -r] flake-url...

الوصف

هذا الأمر مشابه لـ nix3-flake-lock، ولكنه مخصص فقط لتحديث ملف القفل. يتم تجاهل أي خيارات أخرى قد تغير كيفية تفسير الشفرة.

خيارات شائعة متعلقة بالشفرة

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الشفرة.
•
--inputs-from flake-url
استخدام مدخلات الشفرة المحددة كإدخالات سجل.
•
--no-registries
عدم السماح بالبحث في سجلات الشفرة.
تم إهمالها
استخدام --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
عدم السماح بأي تحديثات لملف قفل الشفرة.
•
--no-write-lock-file
عدم كتابة ملف قفل الشفرة الذي تم إنشاؤه حديثًا.
•
--output-lock-file flake-lock-path
كتابة ملف القفل المحدد بدلاً من flake.lock داخل الشفرة العليا.
•
--override-input input-path flake-url
تجاوز مدخل شفرة معين (مثل dwarffs/nixpkgs). هذا يعني ضمنياً --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الشفرة من الصفر.
تم إهمالها
استخدام nix flake update بدلاً من ذلك.
•
--reference-lock-file flake-lock-path
قراءة ملف القفل المحدد بدلاً من flake.lock داخل الشفرة العليا.
•
--update-input input-path
تحديث مدخل شفرة معين (متجاهلاً إدخاله السابق في ملف القفل).
تم إهمالها
استخدام nix flake update بدلاً من ذلك.

خيارات متعلقة بالتسجيل

•
--debug
تعيين مستوى تفاصيل التسجيل إلى 'debug'.
•
--log-format format
تعيين تنسيق مخرجات السجل؛ أحد الخيارات: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفاصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفاصيل التسجيل.

خيارات عامة متنوعة

•
--help
إظهار معلومات الاستخدام.
•
--offline
تعطيل البدائل واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (يتجاوز nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا غير محدثة.
•
--repair
أثناء التقييم، إعادة كتابة الملفات المفقودة أو التالفة في مخزن Nix. أثناء البناء، إعادة بناء مسارات المخزن المفقودة أو التالفة.
•
--version
إظهار معلومات الإصدار.

خيارات تغير تفسير installables

•
--all
تطبيق العملية على كل مسار في المخزن.
•
--derivation
العمل على استنتاج المخزن بدلاً من مخرجاته.
•
--expr expr
تفسير installables كمسارات سمات نسبة إلى تعبير Nix expr.
•
--file / -f file
تفسير installables كمسارات سمات نسبة إلى تعبير Nix المخزن في file. إذا كان file هو الحرف -، فسيتم قراءة تعبير Nix من الإدخال القياسي. يعني ضمنياً --impure.
•
--recursive / -r
تطبيق العملية على إغلاق المسارات المحددة.

ملاحظة

راجع man nix.conf لتجاوز إعدادات التكوين باستخدام علامات سطر الأوامر.
