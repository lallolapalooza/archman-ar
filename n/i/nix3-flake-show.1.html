nix manual

NAME

nix-flake-show, nix-flake-install, nix-flake-update, nix-flake-remove, nix-flake-enter, nix-flake-build, nix-flake-check, nix-flake-run, nix-flake-clone, nix-flake-logic, nix-flake-lock, nix-flake-new, nix-flake-edit, nix-flake-path, nix-flake-diff, nix-flake-cat, nix-flake-init, nix-flake-add, nix-flake-update-input, nix-flake-override-input, nix-flake-recreate-lock-file, nix-flake-reference-lock-file — High-level flake commands

SYNOPSIS

nix flake command

DESCRIPTION

Nix flakes are a new approach to packaging and NixOS system configuration. Flakes provide improved reproducibility and composability. This page describes the high-level commands for interacting with flakes.

The following commands are available:

•
nix flake add
Add an input to a flake.
•
nix flake cat
Print files from a flake.
•
nix flake check
Check a flake's outputs.
•
nix flake clone
Clone a flake's inputs.
•
nix flake diff
Show differences between two flakes.
•
nix flake edit
Edit a flake's inputs.
•
nix flake enter
Enter a flake's development environment.
•
nix flake init
Initialize a new flake.
•
nix flake install
Install a flake's outputs.
•
nix flake lock
Lock a flake's inputs.
•
nix flake new
Create a new flake.
•
nix flake path
Get the Nix store path of a flake's outputs.
•
nix flake remove
Remove an input from a flake.
•
nix flake run
Run an app provided by a flake.
•
nix flake show
Show information about a flake.
•
nix flake update
Update flake inputs.

OPTIONS

•
--apply-overrides flake-url ...
Apply the given flake URLs as overrides. This implies --no-write-lock-file.
•
--command-path path
The command to run (e.g. flake.outputs.devShell). This option is experimental and may be removed in the future.
•
--commit-lockfile
Commit the updated lock file to Git.
•
--eval-cache path
Use the given path as the evaluation cache.
•
--experimental-features features
Enable experimental features. Supported values are nix-command and flakes. nix is a shortcut for nix-command flakes.
•
--file path
Use the flake file at path instead of flake.nix.
•
--go-to-source
When showing flake information, print the Nix store path of the flake source.
•
--inputs-from flake-url
When evaluating a flake, use the inputs from the given flake URL. This is useful for testing changes to inputs without modifying the lock file. This implies --no-write-lock-file.
•
--log-filter expression
Filter evaluation logs. The expression is a string containing a Nix expression that returns a boolean.
•
--no-eval-cache
Disable the evaluation cache.
•
--no-write-lock-file
Do not write the lock file.
•
--override-input input-path flake-url
Override a specific flake input (e.g. dwarffs/nixpkgs). This implies --no-write-lock-file.
•
--recreate-lock-file
Recreate the flake’s lock file from scratch.
DEPRECATED
Use nix flake update instead.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Note

See man nix.conf for overriding configuration settings with command line flags.
