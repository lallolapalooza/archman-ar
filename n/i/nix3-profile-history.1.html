nix3-profile-history(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-profile-history(1) دليل الأوامر العامة nix3-profile-history(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix profile history - عرض جميع إصدارات ملف تعريف

الملخص

nix profile history [خيار•]

أمثلة

•
عرض التغييرات بين كل إصدار من ملف التعريف الافتراضي الخاص بك:
# nix profile history
Version 508 (2020-04-10):
flake:nixpkgs#legacyPackages.x86_64-linux.awscli: ∅ -> 1.17.13
Version 509 (2020-05-16) <- 508:
flake:nixpkgs#legacyPackages.x86_64-linux.awscli: 1.17.13 -> 1.18.211

الوصف

يعرض هذا الأمر الحزم التي تمت إضافتها، أو إزالتها، أو ترقيتها بين الإصدارات المتتالية لملف التعريف. يعرض فقط الحزم ذات المستوى الأعلى، وليس التبعيات؛ لهذا الغرض، استخدم nix profile diff-closures.

يتم تمييز إضافة حزمة إلى ملف تعريف بالسلسلة ∅ -> الإصدار، بينما يتم تمييز الإزالة بالسلسلة الإصدار -> ∅.

خيارات

•
--profile مسار
ملف التعريف المراد العمل عليه.

خيارات التقييم الشائعة

•
--arg اسم تعبير
تمرير القيمة تعبير كوسيط اسم لوظائف Nix.
•
--arg-from-file اسم مسار
تمرير محتويات الملف مسار كوسيط اسم لوظائف Nix.
•
--arg-from-stdin اسم
تمرير محتويات الإدخال القياسي كوسيط اسم لوظائف Nix.
•
--argstr اسم سلسلة
تمرير السلسلة سلسلة كوسيط اسم لوظائف Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-URL-للمخزن
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين الاشتقاقات (.drv) والمدخلات التي تشير إليها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I مسار
إضافة مسار إلى مدخلات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد التكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake المرجع-الأصلي المرجع-المحلول
تجاوز سجلات الـ flake، وإعادة توجيه المرجع-الأصلي إلى المرجع-المحلول.

خيارات متعلقة بالتسجيل

•
--debug
تعيين مستوى تفصيل التسجيل إلى 'debug'.
•
--log-format التنسيق
تعيين تنسيق إخراج السجل؛ أحد الخيارات: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلين واعتبار جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option اسم قيمة
تعيين إعداد التكوين Nix اسم إلى قيمة (متجاوزًا nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها مسبقًا غير محدثة.
•
--repair
أثناء التقييم، أعد كتابة الملفات المفقودة أو التالفة في مخزن Nix. أثناء البناء، أعد بناء مسارات المخزن المفقودة أو التالفة.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام أعلام سطر الأوامر.
