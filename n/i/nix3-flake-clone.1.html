nix3-flake-clone(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-flake-clone(1) دليل الأوامر العامة nix3-flake-clone(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix flake clone - استنساخ مستودع الفليكه (flake)

الملخص

nix flake clone [خيار…] عنوان-الفليكه

أمثلة

•
استعراض الكود المصدري للفليكه dwarffs وبنائه:
# nix flake clone dwarffs --dest dwarffs
# cd dwarffs
# nix build

الوصف

ينفذ هذا الأمر استنساخ Git أو Mercurial للمستودع الذي يحتوي على الكود المصدري للفليكه flake-url.

خيارات

•
--dest / -f مسار
استنساخ الفليكه إلى المسار dest.

خيارات التقييم الشائعة

•
--arg اسم تعبير
تمرير القيمة expr كوسيط name لدوال Nix.
•
--arg-from-file اسم مسار
تمرير محتويات الملف path كوسيط name لدوال Nix.
•
--arg-from-stdin اسم
تمرير محتويات المدخل القياسي (stdin) كوسيط name لدوال Nix.
•
--argstr اسم سلسلة نصية
تمرير السلسلة النصية string كوسيط name لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-المخزن
عنوان URL للمخزن لاستخدامه في التقييم، أي لتخزين المشتقات (ملفات .drv) والمدخلات المشار إليها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I مسار
إضافة path إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث.
يمكن إعطاء هذا الخيار عدة مرات.
تأخذ المسارات المضافة عبر -I الأسبقية على إعداد تهيئة nix-path و متغير البيئة NIX_PATH.
•
--override-flake مرجع-أصلي مرجع-محلول
تجاوز سجلات الفليكه، مع إعادة توجيه original-ref إلى resolved-ref.

خيارات شائعة متعلقة بالفليكه

•
--commit-lock-file
الالتزام بالتغييرات في ملف قفل الفليكه.
•
--inputs-from عنوان-الفليكه
استخدام مدخلات الفليكه المحددة كإدخالات للسجل.
•
--no-registries
عدم السماح بالبحث في سجلات الفليكه.
تم إيقافه
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
عدم السماح بأي تحديثات لملف قفل الفليكه.
•
--no-write-lock-file
عدم كتابة ملف قفل الفليكه الذي تم إنشاؤه حديثًا.
•
--output-lock-file مسار-قفل-الفليكه
كتابة ملف القفل المحدد بدلاً من flake.lock داخل الفليكه العلوية.
•
--override-input مسار-المدخل عنوان-الفليكه
تجاوز مدخل فليكه محدد (على سبيل المثال dwarffs/nixpkgs). هذا يتضمن --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الفليكه من الصفر.
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file مسار-قفل-الفليكه
قراءة ملف القفل المحدد بدلاً من flake.lock داخل الفليكه العلوية.
•
--update-input مسار-المدخل
تحديث مدخل فليكه محدد (متجاهلاً إدخاله السابق في ملف القفل).
تم إيقافه
استخدم nix flake update بدلاً من ذلك.

خيارات متعلقة بالتسجيل

•
--debug
ضبط مستوى تفاصيل التسجيل على "debug" (تصحيح).
•
--log-format تنسيق
ضبط تنسيق مخرجات السجل؛ أحد الخيارات التالية: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

/ -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلات واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (متجاوزًا nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا قديمة.
•
--repair
أثناء التقييم، أعد كتابة الملفات المفقودة أو التالفة في مخزن Nix. أثناء البناء، أعد بناء مسارات المخزن المفقودة أو التالفة.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام خيارات سطر الأوامر.
