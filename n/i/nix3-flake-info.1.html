تحذير

الاسم

nix flake info - عرض بيانات تعريف الـ flake

الملخص

nix flake info [خيار••…] عنوان-الـ-flake

الوصف

يعرض هذا الأمر معلومات حول الـ flake المحدد بواسطة مرجع الـ flake عنوان-الـ-flake. يقوم بحل مرجع الـ flake باستخدام سجل الـ flakes، ويقوم بجلبها، ويعرض بعض البيانات الوصفية. يتضمن ذلك:

  • عنوان URL الذي تم حله: إذا كان عنوان-الـ-flake معرفًا للـ flake، فهذا هو مرجع الـ flake الذي يحدد موقعه الفعلي، والذي تم البحث عنه في سجل الـ flakes.
  • عنوان URL المقفل: مرجع flake يحتوي على تجزئة التزام أو محتوى، وبالتالي يحدد نسخة flake معينة بشكل فريد.
  • الوصف: وصف من سطر واحد للـ flake، مأخوذ من حقل description في flake.nix.
  • المسار: مسار المتجر الذي يحتوي على الكود المصدري للـ flake.
  • المراجعة: تجزئة الالتزام Git أو Mercurial للـ flake المقفل.
  • المراجعات: عدد الأسلاف لتجزئة الالتزام Git أو Mercurial للـ flake المقفل. لاحظ أن هذا غير متاح لـ flakes github.
  • آخر تعديل: بالنسبة لـ flakes Git أو Mercurial، هذا هو وقت الالتزام لتجزئة الالتزام للـ flake المقفل؛ بالنسبة لـ flakes الأرشيف، فهو أحدث طابع زمني لأي ملف داخل الأرشيف.
  • المدخلات: مدخلات الـ flake مع إدخالات ملف القفل المقابلة لها.

مع --json، يكون الإخراج كائن JSON بالحقول التالية:

  • original و originalUrl: مرجع الـ flake الذي حدده المستخدم (عنوان-الـ-flake) في مجموعة السمات وتمثيل عنوان URL.
  • resolved و resolvedUrl: مرجع الـ flake الذي تم حله (انظر أعلاه) في مجموعة السمات وتمثيل عنوان URL.
  • locked و lockedUrl: مرجع الـ flake المقفل (انظر أعلاه) في مجموعة السمات وتمثيل عنوان URL.
  • description: انظر الوصف أعلاه.
  • path: انظر المسار أعلاه.
  • revision: انظر المراجعة أعلاه.
  • revCount: انظر المراجعات أعلاه.
  • lastModified: انظر آخر تعديل أعلاه.
  • locks: محتويات flake.lock.

خيارات

•
--json
إنتاج الإخراج بتنسيق JSON، مناسب للاستهلاك بواسطة برنامج آخر.

خيارات التقييم الشائعة

•
--arg اسم تعبير
تمرير القيمة تعبير كوسيط اسم لدوال Nix.
•
--arg-from-file اسم مسار
تمرير محتويات الملف مسار كوسيط اسم لدوال Nix.
•
--arg-from-stdin اسم
تمرير محتويات stdin كوسيط اسم لدوال Nix.
•
--argstr اسم سلسلة نصية
تمرير السلسلة النصية سلسلة نصية كوسيط اسم لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-المخزن
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين المشتقات (.drv) والمدخلات التي تشير إليها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I مسار
إضافة مسار إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake مرجع-أصلي مرجع-محلول
تجاوز سجلات الـ flakes، وإعادة توجيه مرجع-أصلي إلى مرجع-محلول.

خيارات شائعة متعلقة بالـ flake

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الـ flake.
•
--inputs-from flake-url
استخدام المدخلات من الـ flake المحدد كإدخالات في السجل.
•
--no-registries
لا تسمح بالبحث في سجلات الـ flake.
تم إيقافه
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
لا تسمح بأي تحديثات لملف قفل الـ flake.
•
--no-write-lock-file
لا تكتب ملف قفل الـ flake الذي تم إنشاؤه حديثًا.
•
--output-lock-file flake-lock-path
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--override-input input-path flake-url
تجاوز مدخل flake محدد (على سبيل المثال، dwarffs/nixpkgs). هذا يعني ضمنيًا --no-write-lock-file.
•
--recreate-lock-file
أعد إنشاء ملف قفل الـ flake من الصفر.
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file flake-lock-path
اقرأ ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--update-input input-path
قم بتحديث مدخل flake محدد (مع تجاهل إدخاله السابق في ملف القفل).
تم إيقافه
استخدم nix flake update بدلاً من ذلك.

خيارات متعلقة بالتسجيل

•
--debug
اضبط مستوى تفاصيل التسجيل على "debug".
•
--log-format format
اضبط تنسيق مخرجات السجل؛ أحد الخيارات التالية: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
اطبع سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
قلل مستوى تفاصيل التسجيل.
•
--verbose / -v
زد مستوى تفاصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلين واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
اضبط إعداد تكوين Nix name على value (متجاوزًا nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا غير محدثة.
•
--repair
أثناء التقييم، أعد كتابة الملفات المفقودة أو التالفة في متجر Nix. أثناء البناء، أعد بناء المسارات المفقودة أو التالفة في المتجر.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام خيارات سطر الأوامر.
