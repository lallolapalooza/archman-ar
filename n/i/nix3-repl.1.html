الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-repl(1) دليل الأوامر العامة nix3-repl(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix repl - بدء بيئة تفاعلية لتقييم تعبيرات Nix

الملخص

nix repl [خيار…] قابل-للتثبيت…

أمثلة

•
عرض جميع الأوامر الخاصة داخل REPL:
# nix repl
nix-repl> :?
•
تقييم بعض تعبيرات Nix البسيطة:
# nix repl
nix-repl> 1 + 2
3
nix-repl> map (x: x * 2) [1 2 3]
[ 2 4 6 ]
•
التفاعل مع Nixpkgs في REPL:
# nix repl --file example.nix
Loading Installable ''...
Added 3 variables.
# nix repl --expr '{a={b=3;c=4;};}'
Loading Installable ''...
Added 1 variables.
# nix repl --expr '{a={b=3;c=4;};}' a
Loading Installable ''...
Added 1 variables.
# nix repl --extra-experimental-features 'flakes' nixpkgs
Loading Installable 'flake:nixpkgs#'...
Added 5 variables.
nix-repl> legacyPackages.x86_64-linux.emacs.name
"emacs-27.1"
nix-repl> :q
# nix repl --expr 'import <nixpkgs>{}'
Loading Installable ''...
Added 12439 variables.
nix-repl> emacs.name
"emacs-27.1"
nix-repl> emacs.drvPath
"/nix/store/lp0sjrhgg03y2n0l10n70rg0k7hhyz0l-emacs-27.1.drv"
nix-repl> drv = runCommand "hello" { buildInputs = [ hello ]; } "hello; hello > $out"
nix-repl> :b drv
this derivation produced the following outputs:
out -> /nix/store/0njwbgwmkwls0w5dv9mpc1pq5fj39q0l-hello
nix-repl> builtins.readFile drv
"Hello, world!\n"
nix-repl> :log drv
Hello, world!

الوصف

يوفر هذا الأمر بيئة تفاعلية لتقييم تعبيرات Nix. (REPL اختصار لـ ‘حلقة القراءة–التقييم–الطباعة’.)

عند بدء التشغيل، يقوم بتحميل تعبيرات Nix المسماة ملفات ويضيفها إلى النطاق المعجمي. يمكنك تحميل ملفات إضافية باستخدام الأمر :l <اسم-الملف>، أو إعادة تحميل جميع الملفات باستخدام :r.

الخيارات

•
--stdin
قراءة العناصر القابلة للتثبيت من الإدخال القياسي. لا يتم تطبيق أي عنصر قابل للتثبيت افتراضي.

خيارات التقييم الشائعة

•
--arg الاسم التعبير
تمرير القيمة التعبير كوسيط الاسم إلى دوال Nix.
•
--arg-from-file الاسم المسار
تمرير محتويات الملف المسار كوسيط الاسم إلى دوال Nix.
•
--arg-from-stdin الاسم
تمرير محتويات الإدخال القياسي كوسيط الاسم إلى دوال Nix.
•
--argstr الاسم السلسلة
تمرير السلسلة السلسلة كوسيط الاسم إلى دوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-المخزن
عنوان URL لمخزن Nix المراد استخدامه للتقييم، أي لتخزين الاشتقاقات (ملفات .drv) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I المسار
إضافة المسار إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأولوية على إعداد nix-path في ملف التكوين و متغير البيئة NIX_PATH.
•
--override-flake المرجع-الأصلي المرجع-المحلول
تجاوز سجلات flake، بإعادة توجيه المرجع-الأصلي إلى المرجع-المحلول.

خيارات flake الشائعة

•
--commit-lock-file
تثبيت التغييرات على ملف قفل flake.
•
--inputs-from عنوان-url-flake
استخدام مدخلات flake المحدد كإدخالات في السجل.
•
--no-registries
عدم السماح بالبحث في سجلات flake.
مهمل
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
عدم السماح بأي تحديثات لملف قفل flake.
•
--no-write-lock-file
عدم كتابة ملف قفل flake المُنشأ حديثاً.
•
--output-lock-file مسار-قفل-flake
كتابة ملف القفل المحدد بدلاً من flake.lock داخل flake الأعلى مستوى.
•
--override-input مسار-المدخل عنوان-url-flake
تجاوز مدخل flake محدد (مثل dwarffs/nixpkgs). هذا يستلزم --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل flake من الصفر.
مهمل
استخدم nix flake update بدلاً من ذلك.

Flake-related options

•
--commit-lockfile
Commits the new flake.lock file to Git, or if the file is not tracked, adds it to the Git index. The command is run inside a temporary Git repository if the current directory is not a Git repository.
•
--rebuild
In addition to updating the lock file, also rebuilds all inputs that have changed.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

خيارات متعلقة بالتسجيل

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

خيارات عامة متنوعة

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

خيارات تغير تفسير القابلة للتثبيت

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
