nix3-search(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-search(1) دليل الأوامر العامة nix3-search(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix search - البحث عن حزم

الخلاصة

nix search [خيار…] القابل_للتثبيت التعبير_المنتظم…

أمثلة

•
عرض جميع الحزم في مسرع nixpkgs:
# nix search nixpkgs ^
* legacyPackages.x86_64-linux.AMB-plugins (0.8.1)
مجموعة من إضافات ladspa ambisonics
* legacyPackages.x86_64-linux.ArchiSteamFarm (4.3.1.0)
تطبيق هدفه الأساسي هو تعطيل بطاقات Steam من حسابات متعددة في نفس الوقت
...
•
عرض الحزم في مسرع nixpkgs التي تحتوي على blender في اسمها أو وصفها:
# nix search nixpkgs blender
* legacyPackages.x86_64-linux.blender (2.91.0)
نظام إنشاء / تحريك / نشر ثلاثي الأبعاد
•
البحث عن الحزم تحت السمة gnome3 في Nixpkgs:
# nix search nixpkgs#gnome3 vala
* legacyPackages.x86_64-linux.gnome3.vala (0.48.9)
مترجم لنظام أنواع GObject
•
عرض جميع الحزم في المسرع في الدليل الحالي:
# nix search . ^
•
البحث عن Firefox أو Chromium:
# nix search nixpkgs 'firefox|chromium'
•
البحث عن الحزم التي تحتوي على git و إما frontend أو gui:
# nix search nixpkgs git 'frontend|gui'
•
البحث عن الحزم التي تحتوي على neovim ولكن إخفاء تلك التي تحتوي على إما gui أو python:
# nix search nixpkgs neovim --exclude 'python|gui'
أو
# nix search nixpkgs neovim --exclude 'python' --exclude 'gui'

الوصف

nix search تبحث في القابل_للتثبيت (والتي يمكن تقييمها، أي مسرع أو تعبير Nix، ولكن ليس مسار مخزن أو مسار اشتقاق مخزن) عن الحزم التي تتطابق أسماؤها أو أوصافها مع جميع التعابير المنتظمة regex. لكل حزمة مطابقة، تطبع اسم السمة الكامل (من جذر القابل_للتثبيت)، والإصدار، وحقل meta.description، مع إبراز الأجزاء التي تمت مطابقتها بواسطة التعابير المنتظمة.

لعرض جميع الحزم، استخدم التعبير المنتظم ^. على عكس .*، فإنه يتجنب إبراز الاسم والوصف الكاملين لكل حزمة.

لاحظ أنه في هذا السياق، ^ هو حرف التعبير المنتظم لمطابقة بداية سلسلة، وليس المحدد لـ تحديد ناتج الاشتقاق.

سمات ناتج المسرع

إذا لم يتم تحديد سمة ناتج مسرع، فإن nix search تبحث عن الحزم:

  • مباشرة تحت packages.<system>.
  • تحت legacyPackages.<system>، مع الاستمرار في مجموعات السمات التي تحتوي على سمة recurseForDerivations = true.

خيارات

•
--exclude / -e regex
إخفاء الحزم التي يحتوي مسار سمتها أو اسمها أو وصفها على regex.
•
--json
إنتاج الإخراج بصيغة JSON، مناسب للاستهلاك بواسطة برنامج آخر.

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كوسيط name لدوال Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كوسيط name لدوال Nix.
•
--arg-from-stdin name
تمرير محتويات المدخل القياسي كوسيط name لدوال Nix.
•
--argstr name string
تمرير السلسلة string كوسيط name لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store store-url
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين الاشتقاقات (.drv files) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
إضافة path إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد التكوين nix-path ومتغير البيئة NIX_PATH .
•
--override-flake original-ref resolved-ref
تجاوز سجلات المسرعات، وإعادة توجيه original-ref إلى resolved-ref.

خيارات شائعة متعلقة بالمسرعات

•
--commit-lock-file
تثبيت التغييرات في ملف قفل المسرع.
•
--inputs-from flake-url
استخدام مدخلات المسرع المحدد كإدخالات سجل.
•
--no-registries
عدم السماح بالبحث في سجلات المسرعات.
