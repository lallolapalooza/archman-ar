nix3-develop(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-develop(1) دليل الأوامر العامة nix3-develop(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix develop - تشغيل بيئة bash التي توفر بيئة البناء لمشتق

الملخص

nix develop [خيار•] قابل للتثبيت

أمثلة

•
بدء shell مع بيئة بناء الحزمة الافتراضية للملف الموجود في الدليل الحالي:
# nix develop
الأوامر النموذجية للتشغيل داخل هذا shell هي:
# configurePhase
# buildPhase
# installPhase
بدلاً من ذلك، يمكنك تشغيل أدوات البناء التي يستخدمها مشروعك مباشرة، على سبيل المثال لمشروع Unix نموذجي:
# ./configure --prefix=$out
# make
# make install
•
تشغيل مرحلة بناء معينة مباشرة:
# nix develop --unpack
# nix develop --configure
# nix develop --build
# nix develop --check
# nix develop --install
# nix develop --installcheck
•
بدء shell مع بيئة بناء GNU Hello:
# nix develop nixpkgs#hello
•
تسجيل بيئة بناء في ملف تعريف:
# nix develop --profile /tmp/my-build-env nixpkgs#hello
•
استخدام بيئة بناء مسجلة مسبقًا في ملف تعريف:
# nix develop /tmp/my-build-env
•
استبدال جميع تكرارات مسار المتجر المقابلة لـ glibc.dev بدليل قابل للكتابة:
# nix develop --redirect nixpkgs#glibc.dev ~/my-glibc/outputs/dev
لاحظ أن هذا مفيد إذا كنت تقوم بتشغيل shell nix develop لـ nixpkgs#glibc في ~/my-glibc وتريد بناء حزمة أخرى ضده.
•
تشغيل سلسلة من أوامر السكربت:
# nix develop --command bash -c "mkdir build && cmake .. && make"

الوصف

nix develop يبدأ shell bash الذي يوفر بيئة بناء تفاعلية مطابقة تقريبًا لما سيستخدمه Nix لبناء القابل للتثبيت. داخل هذا shell، يتم تعيين متغيرات البيئة ووظائف shell بحيث يمكنك بناء الحزمة الخاصة بك بشكل تفاعلي وتدريجي.

يحدد Nix بيئة البناء عن طريق بناء نسخة معدلة من المشتق القابل للتثبيت الذي يسجل فقط البيئة التي تم تهيئتها بواسطة stdenv ويخرج. يمكن تسجيل بيئة البناء هذه في ملف تعريف باستخدام --profile.

يمكن تخصيص المطالبة التي يستخدمها shell bash عن طريق تعيين إعدادات bash-prompt، bash-prompt-prefix، و bash-prompt-suffix في nix.conf أو في سمة nixConfig للملف.

سمات مخرجات الملف

إذا لم يتم تحديد سمة مخرجات للملف، يحاول nix develop سمات المخرجات التالية للملف:

  • devShells.<system>.default
  • packages.<system>.default

إذا تم تحديد *اسم* مخرجات للملف، يحاول nix develop سمات المخرجات التالية للملف:

  • devShells.<system>.<name>
  • packages.<system>.<name>
  • legacyPackages.<system>.<name>

خيارات

•
--build
تشغيل مرحلة build.
•
--check
تشغيل مرحلة check.
•
--command / -c command args
بدلاً من بدء shell تفاعلي، قم بتشغيل الأمر والوسيطات المحددة.
•
--configure
تشغيل مرحلة configure.
•
--ignore-environment / -i
مسح البيئة بأكملها (باستثناء تلك المحددة بـ --keep).
•
--install
تشغيل مرحلة install.
•
--installcheck
تشغيل مرحلة installcheck.
•
--keep / -k name
الاحتفاظ بمتغير البيئة name.
•
--phase phase-name
مرحلة stdenv المراد تشغيلها (على سبيل المثال build أو configure).
•
--profile path
ملف التعريف المراد العمل عليه.
•
--redirect installable outputs-dir
إعادة توجيه مسار متجر إلى موقع قابل للتغيير.
•
--unpack
تشغيل مرحلة unpack.
•
--unset / -u name
إلغاء تعيين متغير البيئة name.

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كـ name كوسيط إلى وظائف Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كـ name كوسيط إلى وظائف Nix.
•
--arg-from-stdin name
تمرير محتويات stdin كـ name كوسيط إلى وظائف Nix.
•
--argstr name string
تمرير السلسلة النصية string كـ name كوسيط إلى وظائف Nix.
•

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
