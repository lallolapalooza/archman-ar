nitrocli(1)

الحزمة: nitrocli

التراخيص: GPL3

ملف الإعدادات

يحاول nitrocli قراءة ملف الإعدادات في ${XDG_CONFIG_HOME}/nitrocli/config.toml (أو ${HOME}/nitrocli/config.toml إذا لم يكن متغير البيئة XDG_CONFIG_HOME معينًا). يُستخدم لتعيين القيم الافتراضية للخيار ات المدرجة أدناه.

يمكنك أيضًا تعيين متغير البيئة NITROCLI_KEY لتجاوز الإعدادات الخاصة بـ key (انظر قسم البيئة). لاحظ أن وسيطات سطر الأوامر تتجاوز كلاً من ملف الإعدادات ومتغيرات البيئة.

يمكن تعيين القيم التالية في ملف الإعدادات:

model
تقييد الاتصالات بنموذج الجهاز المحدد (سلسلة نصية، الافتراضي: غير معين، راجع --model).
serial_numbers
تقييد الاتصالات بأرقام المسلسلات المحددة (قائمة سلاسل نصية، الافتراضي: فارغ، راجع --serial-number).
usb_path
تقييد الاتصالات بمسار USB المحدد (سلسلة نصية، الافتراضي: غير معين، راجع --usb-path).
no_cache
إذا تم تعيينه على true، فلا تقم بتخزين أي أسرار مستفسر عنها مؤقتًا (قيمة منطقية، الافتراضي: false، راجع --no-cache).
verbosity
تعيين مستوى السجل (عدد صحيح، الافتراضي: 0، راجع --verbose).

يجب أن يستخدم ملف الإعدادات تنسيق TOML، على سبيل المثال:
model = "pro"
serial_numbers = ["0xf00baa", "deadbeef"]
usb_path = "0001:0006:02"
no_cache = false
verbosity = 0

البيئة

يدعم البرنامج مجموعتين من متغيرات البيئة، وجميعها تبدأ بالبادئة "NITROCLI_".

الإعدادات

تتحكم المجموعة الأولى في الإعدادات الأساسية للبرنامج. تعكس هذه المتغيرات خيارات سطر الأوامر وإعدادات ملف الإعدادات المعنية. وهي:

NITROCLI_MODEL
تقييد الاتصالات بنموذج الجهاز المحدد (سلسلة نصية، الافتراضي: غير معين، راجع --model).
NITROCLI_SERIAL_NUMBERS
تقييد الاتصالات بقائمة أرقام المسلسلات المحددة (قائمة سلاسل نصية مفصولة بفواصل، الافتراضي: فارغ، راجع --serial-number).
NITROCLI_USB_PATH
تقييد الاتصالات بمسار USB المحدد (سلسلة نصية، الافتراضي: غير معين، راجع --usb-path).
NITROCLI_NO_CACHE
إذا تم تعيينه على true، فلا تقم بتخزين أي أسرار مستفسر عنها مؤقتًا (قيمة منطقية، الافتراضي: false، راجع --no-cache).
NITROCLI_VERBOSITY
تعيين مستوى السجل (عدد صحيح، الافتراضي: 0، راجع --verbose).

إدخال كلمة المرور والرقم السري

يمكن استخدام المجموعة الثانية لتوفير بيانات كلمة المرور والرقم السري للبرنامج لقمع الإدخال التفاعلي عبر pinentry(1) للعمليات التي تطلبها بخلاف ذلك. يتم التعرف على المتغيرات التالية:

NITROCLI_ADMIN_PIN
الرقم السري للمسؤول للاستخدام.
NITROCLI_USER_PIN
الرقم السري للمستخدم للاستخدام.
NITROCLI_NEW_ADMIN_PIN
الرقم السري الجديد للمسؤول لتعيينه. يستخدم هذا المتغير فقط من قبل أمر pin set لنوع admin.
NITROCLI_NEW_USER_PIN
الرقم السري الجديد للمستخدم لتعيينه. يستخدم هذا المتغير فقط من قبل أمر pin set لنوع user.
NITROCLI_PASSWORD
كلمة مرور تستخدمها الأوامر التي تتطلب واحدة (على سبيل المثال، hidden open).

ملحقات

يدعم nitrocli الملحقات التي يوفرها المستخدم والتي تكون ملفات قابلة للتنفيذ يبدأ اسمها بـ "nitrocli-" ويتم اكتشافها من خلال البحث عبر متغير البيئة PATH.

ينقل البرنامج معلومات الإعداد الأساسية إلى أي ملحق يتم تشغيله بهذه الطريقة. على وجه التحديد، سيقوم بتعيين كل متغير بيئة كما هو موضح في قسم الإعدادات في قسم البيئة أعلاه، إذا تم تعيين تكوين برنامج nitrocli المقابل. بالإضافة إلى ذلك، سيتم تعيين المتغيرات التالية:

NITROCLI_BINARY
المسار المطلق لملف nitrocli الثنائي الذي تم استدعاء الملحق من خلاله. يمكن استخدام هذا المسار لاستدعاء nitrocli بشكل متكرر لتنفيذ وظائف معينة.
NITROCLI_RESOLVED_USB_PATH
مسار USB للجهاز الذي سيتصل به nitrocli بناءً على خيارات --model و --serial-number و --usb-path. إذا لم يكن هناك جهاز Nitrokey مطابق، أو إذا تطابقت أجهزة متعددة مع الخيارات، فلن يتم تعيين متغير البيئة.

سيتم تمرير جميع المتغيرات الأخرى الموجودة في البيئة إلى الملحق كما هي.

تحتفظ الإصدارات الأحدث من البرنامج بالحق في تعيين متغيرات بيئة إضافية داخل مساحة الاسم "NITROCLI_". على هذا النحو، يُنصح الملحقات بعدم تعريف متغيرات مخصصة بهذا البادئة. ومع ذلك، يتم توفير "NITROCLI_EXT_" خصيصًا لهذا الغرض. لتجنب المزيد من التعارضات بين الملحقات، يوصى بأن تتبع هذه البادئة اسم الملحق (بالأحرف الكبيرة).

يجوز للملحقات اختياريًا قراءة أو كتابة بيانات دائمة بأشكال مختلفة. على غرار البرنامج الرئيسي، يجب على الملحقات اتباع مواصفات دليل XDG الأساسي كإرشادات لمكان تخزين هذه البيانات. وبشكل أكثر تحديدًا، يجب اتباع الاتفاقيات التالية:

بالنسبة لبيانات الإعدادات، فإن ${XDG_CONFIG_HOME}/extension/ هو الدليل المفضل، حيث extension هو اسم الملحق الكامل، بما في ذلك البادئة "nitrocli-". تنسيق الإعدادات الموصى به هو TOML. إذا تم استخدام ملف إعدادات واحد فقط، فإن config.toml هو الاسم الموصى به.

وبالمثل، يجب أن تكون البيانات العادية موجودة في ${XDG_DATA_HOME}/extension/ ويجب تخزين البيانات المؤقتة في ${XDG_CACHE_HOME}/extension/.

الملفات

${XDG_CONFIG_HOME}/nitrocli/config.toml
${HOME}/nitrocli/config.toml
ملف إعدادات المستخدم، راجع قسم ملف الإعدادات.

أمثلة

التخزين

إنشاء مجلد مخفي في أول خانة متاحة، بدءًا من نصف حجم المجلد المشفر (أي 50٪) ويمتد إلى نهايته بالكامل (100٪):
$ nitrocli hidden create 0 50 100

كلمات المرور لمرة واحدة

تكوين خانة كلمة مرور لمرة واحدة بتمثيل سري سداسي عشري:
$ nitrocli otp set 0 test-rfc4226 3132333435363738393031323334353637383930 --format hex --algorithm hotp
$ nitrocli otp set 1 test-foobar 666F6F626172 --format hex --algorithm hotp
$ nitrocli otp set 0 test-rfc6238 3132333435363738393031323334353637383930 --format hex --algorithm totp --digits 8

تكوين خانة كلمة مرور لمرة واحدة بتمثيل سري ASCII:
$ nitrocli otp set 0 test-rfc4226 12345678901234567890 --format ascii --algorithm hotp
$ nitrocli otp set 1 test-foobar foobar --format ascii --algorithm hotp
$ nitrocli otp set 0 test-rfc6238 12345678901234567890 --format ascii --algorithm totp --digits 8

تكوين خانة كلمة مرور لمرة واحدة بتمثيل سري base32:
$ nitrocli otp set 0 test-rfc4226 gezdgnbvgy3tqojqgezdgnbvgy3tqojq --algorithm hotp
$ nitrocli otp set 1 test-foobar mzxw6ytboi====== --algorithm hotp
$ nitrocli otp set 0 test-rfc6238 gezdgnbvgy3tqojqgezdgnbvgy3tqojq --algorithm totp --digits 8

إنشاء كلمة مرور لمرة واحدة:
$ nitrocli otp get 0 --algorithm hotp
755224
$ nitrocli otp get 0 --algorithm totp --time 1234567890
89005924

مسح خانة كلمة مرور لمرة واحدة:
$ nitrocli otp clear 0 --algorithm hotp

الإعدادات

الاستعلام عن الإعدادات:
$ nitrocli config get
Config:
numlock binding: not set
capslock binding: not set
scrollock binding: not set
require user PIN for OTP: true

تغيير الإعدادات:
$ nitrocli config set --otp-pin

خزانة كلمات المرور

تكوين خانة PWS:
$ nitrocli pws add example.org john.doe passw0rd
Added PWS slot 0

الحصول على البيانات من خانة:
$ nitrocli pws get 0
name: example.org
login: john.doe
password: passw0rd

نسخ كلمة المرور إلى الحافظة (يتطلب xclip(1)).
$ nitrocli pws get 0 --password --quiet | xclip -in

الاستعلام عن خانات PWS:
$ nitrocli pws status
slot name
0 example.org
