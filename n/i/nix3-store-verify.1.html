خيارات متعلقة بالتسجيل

•
--debug
تعيين مستوى تفصيل التسجيل إلى "debug".
•
--log-format format
تعيين تنسيق مخرجات السجل؛ أحد الخيارات التالية: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
إظهار معلومات الاستخدام.
•
--offline
تعطيل البدائل واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (تجاوز nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا غير محدثة.
•
--repair
أثناء التقييم، قم بإعادة كتابة الملفات المفقودة أو التالفة في مخزن Nix. أثناء البناء، قم بإعادة بناء مسارات المتجر المفقودة أو التالفة.
•
--version
إظهار معلومات الإصدار.

خيارات تغير تفسير installables

•
--all
تطبيق العملية على كل مسار في المتجر.
•
--derivation
العمل على store derivation بدلاً من مخرجاتها.
•
--expr expr
تفسير installables كمسارات سمات نسبية إلى تعبير Nix expr.
•
--file / -f file
تفسير installables كمسارات سمات نسبية إلى تعبير Nix المخزن في file. إذا كان file هو حرف -, فسيتم قراءة تعبير Nix من المدخل القياسي. يعني --impure.
•
--recursive / -r
تطبيق العملية على إغلاق المسارات المحددة.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام علامات سطر الأوامر.
