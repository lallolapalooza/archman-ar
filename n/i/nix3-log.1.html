nix3-log(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-log(1) دليل الأوامر العامة nix3-log(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix log - عرض سجل البناء للحزم أو المسارات المحددة، إن وجدت

الملخص

nix log [خيار…] قابل-للتثبيت

أمثلة

•
الحصول على سجل بناء GNU Hello:
# nix log nixpkgs#hello
•
الحصول على سجل بناء لمسار تخزين محدد:
# nix log /nix/store/lmngj4wcm9rkv3w4dfhzhcyij3195hiq-thunderbird-52.2.1
•
الحصول على سجل بناء من ذاكرة تخزين ثنائية محددة:
# nix log --store https://cache.nixos.org nixpkgs#hello

الوصف

هذا الأمر يطبع سجل بناء سابق لـ قابل-للتثبيت إلى المخرج القياسي.

يبحث Nix عن سجلات البناء في مكانين:

  • في الدليل /nix/var/log/nix/drvs، الذي يحتوي على سجلات للتشتقات المبنية محليًا.
  • في ذاكرات التخزين الثنائية المدرجة في إعداد substituters. يجب أن تكون السجلات مسماة <cache>/log/<base-name-of-store-path>، حيث store-path هو اشتقاق، مثال: https://cache.nixos.org/log/dvmig8jgrdapvbyxb1rprckdmdqx08kv-hello-2.10.drv. بالنسبة لمسارات التخزين غير الاشتقاقية، سيحاول Nix أولاً تحديد المشتق عن طريق جلب ملف .narinfo لهذا المسار.

خيارات

خيارات التقييم الشائعة

•
--arg الاسم التعبير
يمرر القيمة التعبير كوسيط اسم لدوال Nix.
•
--arg-from-file الاسم المسار
يمرر محتويات الملف المسار كوسيط اسم لدوال Nix.
•
--arg-from-stdin الاسم
يمرر محتويات الإدخال القياسي كوسيط اسم لدوال Nix.
•
--argstr الاسم السلسلة
يمرر السلسلة السلسلة كوسيط اسم لدوال Nix.
•
--debugger
يبدأ بيئة تفاعلية إذا فشل التقييم.
•
--eval-store عنوان-التخزين
عنوان Nix store المستخدم للتقييم، أي لتخزين الاشتقاقات (.drv) والمدخلات المشار إليها.
•
--impure
يسمح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I مسار
يضيف مسار إلى مسارات البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد nix-path و متغير البيئة NIX_PATH.
•
--override-flake مرجع-أصلي مرجع-محلول
يتجاوز سجلات الـ flake، بإعادة توجيه مرجع-أصلي إلى مرجع-محلول.

خيارات متعلقة بالـ Flake الشائعة

•
--commit-lock-file
يتعهد بالتغييرات في ملف قفل الـ flake.
•
--inputs-from عنوان-flake
استخدم مدخلات الـ flake المحدد كإدخالات للسجل.
•
--no-registries
لا تسمح بالبحث في سجلات الـ flake.
تم إيقافه
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
لا تسمح بأي تحديثات لملف قفل الـ flake.
•
--no-write-lock-file
لا تكتب ملف قفل الـ flake الجديد الذي تم إنشاؤه.
•
--output-lock-file مسار-قفل-flake
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--override-input مسار-المدخل عنوان-flake
تجاوز مدخل flake محدد (مثل dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
أعد إنشاء ملف قفل الـ flake من البداية.
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file مسار-قفل-flake
اقرأ ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--update-input مسار-المدخل
قم بتحديث مدخل flake محدد (متجاهلاً إدخاله السابق في ملف القفل).
تم إيقافه
استخدم nix flake update بدلاً من ذلك.

Description

The nix command is a universal command for interacting with the Nix package manager. It replaces the older Nix commands like nix-build, nix-shell, nix-env, nix-collect-garbage, etc. It supports both the legacy Nix expression language and the newer Nix Flakes feature.

The nix command can perform a wide variety of operations, including installing, building, running, and managing packages. It can also be used to manage Nix channels and flakes, and to configure Nix settings.

The command takes a list of installables as arguments, which can be package names, Nix expressions, or flake references. The behavior of the command depends on the sub-command and options provided.

Note

This is a partial list of options. For a full list, see the Nix manual.

Options

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
