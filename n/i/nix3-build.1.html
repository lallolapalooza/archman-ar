nix3-build(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

خيارات شائعة متعلقة بالـ Flakes

•
--commit-lock-file
Commit changes to the flake’s lock file.
•
--inputs-from flake-url
استخدم المدخلات الخاصة بالـ flake المحدد كإدخالات في السجل.
•
--no-registries
لا تسمح بالبحث في سجلات الـ flakes.
تم إهماله
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
لا تسمح بأي تحديثات لملف قفل الـ flake.
•
--no-write-lock-file
لا تكتب ملف قفل الـ flake الجديد الذي تم إنشاؤه.
•
--output-lock-file flake-lock-path
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--override-input input-path flake-url
قم بتجاوز مدخل flake معين (مثل dwarffs/nixpkgs). هذا يعني ضمنيًا --no-write-lock-file.
•
--recreate-lock-file
أعد إنشاء ملف قفل الـ flake من البداية.
تم إهماله
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file flake-lock-path
اقرأ ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--update-input input-path
قم بتحديث مدخل flake معين (متجاهلاً إدخاله السابق في ملف القفل).
تم إهماله
استخدم nix flake update بدلاً من ذلك.

خيارات متعلقة بالتسجيل

•
--debug
قم بتعيين مستوى تفصيل التسجيل إلى 'debug'.
•
--log-format format
قم بتعيين تنسيق إخراج السجل؛ أحد الخيارات التالية: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
اطبع سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
قلل مستوى تفصيل التسجيل.
•
--verbose / -v
زد مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
عطّل البدائل واعتبر جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
قم بتعيين إعداد تكوين Nix name إلى value (متجاوزًا nix.conf).
•
--refresh
اعتبر جميع الملفات التي تم تنزيلها سابقًا على أنها غير محدثة.
•
--repair
أثناء التقييم، أعد كتابة الملفات المفقودة أو التالفة في متجر Nix. أثناء البناء، أعد بناء مسارات المتجر المفقودة أو التالفة.
•
--version
عرض معلومات الإصدار.

خيارات تغير تفسير <b>القابلة للتثبيت</b>

•
--expr expr
فسّر القابلة للتثبيت كمسارات سمات بالنسبة لتعبير Nix expr.
•
--file / -f file
فسّر القابلة للتثبيت كمسارات سمات بالنسبة لتعبير Nix المخزن في file. إذا كان file هو الحرف -، فسيتم قراءة تعبير Nix من الإدخال القياسي. يعني ضمنيًا --impure.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام أعلام سطر الأوامر.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
