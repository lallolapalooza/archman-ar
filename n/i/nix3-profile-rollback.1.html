nix3-profile-rollback(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-profile-rollback(1) دليل الأوامر العامة nix3-profile-rollback(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix profile rollback - العودة إلى الإصدار السابق أو إصدار محدد من ملف التعريف

الملخص

nix profile rollback [خيار…]

أمثلة

•
العودة بملف التعريف الافتراضي إلى الإصدار السابق:
# nix profile rollback
switching profile from version 519 to 518
•
التبديل بملف التعريف الافتراضي إلى الإصدار 510:
# nix profile rollback --to 510
switching profile from version 518 to 510

الوصف

يقوم هذا الأمر بتبديل ملف التعريف إلى أحدث إصدار أقدم من الإصدار النشط حاليًا، أو إذا تم تمرير --to N، فإنه يبدل إلى الإصدار N من ملف التعريف. لرؤية الإصدارات المتاحة لملف التعريف، استخدم nix profile history.

خيارات

•
--dry-run
عرض ما سيفعله هذا الأمر دون تنفيذه.
•
--profile path
ملف التعريف المراد العمل عليه.
•
--to version
إصدار ملف التعريف الذي سيتم العودة إليه.

خيارات متعلقة بالتسجيل

•
--debug
تعيين مستوى تفاصيل التسجيل إلى 'debug'.
•
--log-format format
تعيين تنسيق إخراج السجل؛ أحد الخيارات التالية: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفاصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفاصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلات واعتبار جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (لتجاوز nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها مسبقًا غير محدثة.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام خيارات سطر الأوامر.
