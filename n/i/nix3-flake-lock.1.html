nix3-flake-lock(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-flake-lock(1) دليل الأوامر العامة nix3-flake-lock(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix flake lock - إنشاء مدخلات ملف القفل المفقودة

الملخص

nix flake lock [خيار•] flake-url

أمثلة

•
إنشاء ملف القفل للملف الشجري في الدليل الحالي:
# nix flake lock
warning: creating lock file '/home/myself/repos/testflake/flake.lock':
• Added input 'nix':
  'github:NixOS/nix/9fab14adbc3810d5cc1f88672fde1eee4358405c' (2023-06-28)
• Added input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
•
إضافة مدخلات مفقودة إلى ملف القفل لملف شجري في دليل آخر:
# nix flake lock ~/repos/another
warning: updating lock file '/home/myself/repos/another/flake.lock':
• Added input 'nixpkgs':
  'github:NixOS/nixpkgs/3d2d8f281a27d466fa54b469b5993f7dde198375' (2023-06-30)
ملاحظة
عند محاولة الإشارة إلى ملف شجري في دليل فرعي، اكتب ./another بدلاً من another. بخلاف ذلك، سيحاول Nix البحث عن الملف الشجري في السجل.

الوصف

يضيف هذا الأمر مدخلات إلى ملف القفل لملف شجري (flake.lock) بحيث يحتوي على قفل لكل مدخل ملف شجري محدد في flake.nix. لا يتم تحديث إدخالات ملف القفل الموجودة.

إذا كنت ترغب في تحديث إدخالات القفل الحالية، استخدم nix flake update

خيارات

خيارات التقييم الشائعة

•
--arg name expr
مرر القيمة expr كوسيط name لوظائف Nix.
•
--arg-from-file name path
مرر محتويات الملف path كوسيط name لوظائف Nix.
•
--arg-from-stdin name
مرر محتويات الإدخال القياسي كوسيط name لوظائف Nix.
•
--argstr name string
مرر السلسلة النصية string كوسيط name لوظائف Nix.
•
--debugger
ابدأ بيئة تفاعلية إذا فشل التقييم.
•
--eval-store store-url
عنوان URL لمتجر Nix لاستخدامه للتقييم، أي لتخزين المشتقات (.drv files) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
أضف path إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake original-ref resolved-ref
تجاوز سجلات الملفات الشجرية، وإعادة توجيه original-ref إلى resolved-ref.

خيارات شائعة متعلقة بالملفات الشجرية

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الملف الشجري.
•
--inputs-from flake-url
استخدام مدخلات الملف الشجري المحدد كإدخالات في السجل.
•
--no-registries
لا تسمح بالبحث في سجلات الملفات الشجرية.
مهمل
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
لا تسمح بأي تحديثات لملف قفل الملف الشجري.
•
--output-lock-file flake-lock-path
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الملف الشجري الأعلى.
•
--override-input input-path flake-url
تجاوز مدخل ملف شجري محدد (مثل dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الملف الشجري من الصفر.
مهمل
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file flake-lock-path
اقرأ ملف القفل المحدد بدلاً من flake.lock داخل الملف الشجري الأعلى.
•
--update-input input-path
تحديث مدخل ملف شجري محدد (متجاهلاً إدخاله السابق في ملف القفل).
مهمل
استخدم nix flake update بدلاً من ذلك.
