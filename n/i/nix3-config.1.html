nix3-config(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-config(1) دليل الأوامر العامة nix3-config(1)

تحذير
هذا البرنامج تجريبي وواجهته قابلة للتغيير.

الاسم

nix config - معالجة إعدادات Nix

الملخص

nix config [خيار•…] أمر فرعي

حيث أمر فرعي هو أحد ما يلي:

:

•
nix config show - عرض إعدادات Nix أو قيمة إعداد معين

:

•
nix config check - تحقق من نظامك بحثًا عن مشاكل محتملة واعرض اجتياز أو فشل لكل تحقق

خيارات

خيارات متعلقة بالتسجيل

•
--debug
ضبط مستوى تفاصيل التسجيل على 'debug'.
•
--log-format التنسيق
ضبط تنسيق إخراج السجل؛ أحد الخيارات: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفاصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفاصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلين واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option الاسم القيمة
ضبط إعداد Nix configuration الاسم على القيمة (تجاوز nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا منتهية الصلاحية.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام خيارات سطر الأوامر.
