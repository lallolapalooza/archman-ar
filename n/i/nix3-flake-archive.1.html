nix3-flake-archive(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-flake-archive(1) دليل الأوامر العامة nix3-flake-archive(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix flake archive - نسخ شريحة (flake) وجميع مدخلاتها إلى مخزن

الملخص

nix flake archive [خيار•] flake-url

أمثلة

•
نسخ الشريحة dwarffs وتبعياتها إلى ذاكرة تخزين مؤقت ثنائية:
# nix flake archive --to file:///tmp/my-cache dwarffs
•
جلب الشريحة dwarffs وتبعياتها إلى مخزن Nix المحلي:
# nix flake archive dwarffs
•
طباعة مسارات مخزن مصادر الشرائح لـ NixOps دون جلبها:
# nix flake archive --json --dry-run nixops

خيارات

•
--dry-run
عرض ما ستقوم به هذه الأوامر دون تنفيذه.
•
--json
إنشاء مخرجات بصيغة JSON، مناسبة للاستهلاك بواسطة برنامج آخر.
•
--to store-uri
URI الخاص بمخزن Nix الوجهة

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كوسيط name لدوال Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كوسيط name لدوال Nix.
•
--arg-from-stdin name
تمرير محتويات الإدخال القياسي كوسيط name لدوال Nix.
•
--argstr name string
تمرير السلسلة النصية string كوسيط name لدوال Nix.
•
--debugger
بدء بيئة تفاعلية في حالة فشل التقييم.
•
--eval-store store-url
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين المشتقات (.drv) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
إضافة path إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake original-ref resolved-ref
تجاوز سجلات الشرائح، مع إعادة توجيه original-ref إلى resolved-ref.

خيارات شائعة متعلقة بالشرائح

•
--commit-lock-file
تنفيذ التغييرات على ملف قفل الشريحة.
•
--inputs-from flake-url
استخدام مدخلات الشريحة المحددة كإدخالات في السجل.
•
--no-registries
لا تسمح بالبحث في سجلات الشرائح.
مهمل
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
لا تسمح بأي تحديثات لملف قفل الشريحة.
•
--no-write-lock-file
لا تكتب ملف قفل الشريحة الجديد الذي تم إنشاؤه.
•
--output-lock-file flake-lock-path
اكتب ملف القفل المحدد بدلاً من flake.lock داخل الشريحة الرئيسية.
•
--override-input input-path flake-url
تجاوز مدخل شريحة محدد (على سبيل المثال dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الشريحة من الصفر.
مهمل
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file flake-lock-path
اقرأ ملف القفل المحدد بدلاً من flake.lock داخل الشريحة الرئيسية.
•
--update-input input-path
تحديث مدخل شريحة محدد (متجاهلاً إدخاله السابق في ملف القفل).
مهمل
استخدم nix flake update بدلاً من ذلك.
