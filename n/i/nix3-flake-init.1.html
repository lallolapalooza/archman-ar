nix3-flake-init(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-flake-init(1) دليل الأوامر العامة nix3-flake-init(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix flake init - إنشاء موقد (flake) في الدليل الحالي من قالب

الملخص

nix flake init [خيار•••]

أمثلة

•
إنشاء موقد باستخدام القالب الافتراضي:
# nix flake init
•
سرد القوالب المتاحة:
# nix flake show templates
•
إنشاء موقد من قالب محدد:
# nix flake init -t templates#simpleContainer

الوصف

يقوم هذا الأمر بإنشاء موقد في الدليل الحالي عن طريق نسخ ملفات القالب. لن يقوم بالكتابة فوق الملفات الموجودة. القالب الافتراضي هو templates#templates.default، ولكن يمكن تجاوز ذلك باستخدام -t.

تعريفات القوالب

يمكن للموقد أن يعلن عن قوالب من خلال خاصية الإخراج templates الخاصة به. يحتوي القالب على السمات التالية:

  • description: وصف من سطر واحد للقالب، بصيغة CommonMark.
  • path: مسار الدليل المراد نسخه.
  • welcomeText: كتلة من نص markdown لعرضها عند قيام المستخدم بتهيئة موقد جديد بناءً على هذا القالب.

هذا مثال:

outputs = { self }: {
  templates.rust = {
    path = ./rust;
    description = "مشروع Rust/Cargo بسيط";
    welcomeText = ''
      # قالب Rust/Cargo بسيط
      ## الاستخدام المقصود
      الاستخدام المقصود لهذا الموقد هو...
      ## مزيد من المعلومات
      - [لغة Rust](https://www.rust-lang.org/)
      - [Rust على Wiki NixOS](https://wiki.nixos.org/wiki/Rust)
      - ...
    '';
  };
  templates.default = self.templates.rust;
}

خيارات

•
--template / -t template
القالب المراد استخدامه.

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كوسيط name لدوال Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كوسيط name لدوال Nix.
•
--arg-from-stdin name
تمرير محتويات المدخل القياسي كوسيط name لدوال Nix.
•
--argstr name string
تمرير السلسلة النصية string كوسيط name لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store store-url
عنوان URL لمتجر Nix المراد استخدامه للتقييم، أي لتخزين المشتقات (.drv files) والمدخلات التي تشير إليها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
إضافة path إلى مدخلات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد التكوين nix-path و متغير البيئة NIX_PATH .
•
--override-flake original-ref resolved-ref
تجاوز سجلات الموقد، وإعادة توجيه original-ref إلى resolved-ref.

خيارات متعلقة بالتسجيل

•
--debug
ضبط مستوى تفصيل التسجيل على 'debug'.
•
--log-format format
ضبط تنسيق مخرجات السجل؛ أحد الخيارات التالية: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
إظهار معلومات الاستخدام.
•
--offline
تعطيل المستبدلين واعتبار جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (متجاوزًا nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها مسبقًا غير محدثة.
•
--repair
أثناء التقييم، إعادة كتابة الملفات المفقودة أو التالفة في متجر Nix. أثناء البناء، إعادة بناء مسارات المتجر المفقودة أو التالفة.
•
--version
إظهار معلومات الإصدار.
