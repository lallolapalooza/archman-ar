nix3-store-prefetch-file(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-store-prefetch-file(1) دليل الأوامر العامة nix3-store-prefetch-file(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix store prefetch-file - تنزيل ملف إلى مخزن Nix

الملخص

nix store prefetch-file [خيار…] عنوان url

أمثلة

•
تنزيل ملف إلى مخزن Nix:
# nix store prefetch-file https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz
تم تنزيل 'https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz' إلى
'/nix/store/vbdbi42hgnc4h7pyqzp6h2yf77kw93aw-source' (الهاش
'sha256-qKheVd5D0BervxMDbt+1hnTKE2aRWC8XCAwc0SeHt6s=').
•
تنزيل ملف والحصول على هاش SHA-512:
# nix store prefetch-file --json --hash-type sha512 \
  https://releases.nixos.org/nix/nix-2.3.10/nix-2.3.10.tar.xz \
| jq -r .hash
sha512-6XJxfym0TNH9knxeH4ZOvns6wElFy3uahunl2hJgovACCMEMXSy42s69zWVyGJALXTI+86tpDJGlIcAySEKBbA==

الوصف

يقوم هذا الأمر بتنزيل الملف url إلى مخزن Nix. يقوم بطباعة مسار المتجر الناتج والهاش التشفيري لمحتويات الملف.

يتم تعيين مكون الاسم لمسار المتجر افتراضيًا إلى المكون الأخير من url، ولكن يمكن تجاوز ذلك باستخدام --name.

خيارات

•
--executable
اجعل الملف الناتج قابلاً للتنفيذ. لاحظ أن هذا يسبب أن يكون الهاش الناتج هاش NAR بدلاً من هاش ملف مسطح.
•
--expected-hash hash
الهاش المتوقع للملف.
•
--hash-type hash-algo
خوارزمية الهاش (md5، sha1، sha256، أو sha512).
•
--json
إنتاج المخرجات بتنسيق JSON، مناسبة للاستهلاك بواسطة برنامج آخر.
•
--name name
تجاوز مكون الاسم لمسار المتجر الناتج. افتراضيًا، يكون الاسم الأساسي لـ url.
•
--unpack
فك ضغط الأرشيف (الذي يجب أن يكون tarball أو ملف zip) وأضف النتيجة إلى مخزن Nix.

خيارات متعلقة بتسجيل الدخول

•
--debug
ضبط مستوى تفاصيل تسجيل الدخول إلى 'debug'.
•
--log-format format
ضبط تنسيق مخرجات السجل؛ أحد الخيارات: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفاصيل تسجيل الدخول.
•
--verbose / -v
زيادة مستوى تفاصيل تسجيل الدخول.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلات واعتبار جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (تجاوز nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها مسبقًا غير محدثة.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام علامات سطر الأوامر.
