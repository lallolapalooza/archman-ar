nix3-profile-wipe-history(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-profile-wipe-history(1) دليل الأوامر العامة nix3-profile-wipe-history(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix profile wipe-history - حذف الإصدارات غير الحالية لملف تعريف

ملخص

nix profile wipe-history [خيار•]

أمثلة

•
حذف جميع إصدارات ملف التعريف الافتراضي الأقدم من 100 يوم:
# nix profile wipe-history --profile /tmp/profile --older-than 100d
removing profile version 515
removing profile version 514

الوصف

يقوم هذا الأمر بحذف الإصدارات غير الحالية لملف تعريف، مما يجعل من المستحيل التراجع إلى هذه الإصدارات. افتراضياً، يتم حذف جميع الإصدارات غير الحالية. مع --older-than Nd، يتم حذف جميع الإصدارات غير الحالية الأقدم من N يوم.

خيارات

•
--dry-run
عرض ما سيفعله هذا الأمر دون تنفيذه.
•
--older-than age
حذف الإصدارات الأقدم من العمر المحدد. يجب أن يكون age بالتنسيق Nd، حيث N يمثل عدد الأيام.
•
--profile path
ملف التعريف المراد العمل عليه.

خيارات متعلقة بالتسجيل

•
--debug
ضبط مستوى تفاصيل التسجيل على 'debug'.
•
--log-format format
ضبط تنسيق مخرجات السجل؛ أحد الخيارات: raw, internal-json, bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفاصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفاصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل البدائل واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
ضبط إعداد تهيئة Nix name إلى value (يتجاوز nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا على أنها غير محدثة.
•
--version
عرض معلومات الإصدار.

ملاحظة

راجع man nix.conf لتجاوز إعدادات التهيئة باستخدام خيارات سطر الأوامر.
