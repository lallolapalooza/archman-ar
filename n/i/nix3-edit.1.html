nix3-edit(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

>--debug
اضبط مستوى تفاصيل التسجيل إلى 'debug'.
•
--log-format format
اضبط تنسيق إخراج السجل؛ أحد الخيارات: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
اطبع سجلات الإنشاء الكاملة على الخطأ القياسي.
•
--quiet
قلل مستوى تفاصيل التسجيل.
•
--verbose / -v
زد مستوى تفاصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
عطّل البدائل واعتبر جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option name value
اضبط إعداد تكوين Nix name إلى value (تجاوز nix.conf).
•
--refresh
اعتبر جميع الملفات التي تم تنزيلها مسبقًا قديمة.
•
--repair
أثناء التقييم، أعد كتابة الملفات المفقودة أو التالفة في مخزن Nix. أثناء البناء، أعد بناء مسارات المتجر المفقودة أو التالفة.
•
--version
عرض معلومات الإصدار.

خيارات تغير تفسير installables

•
--expr expr
فسّر installables كمسارات سمات بالنسبة لتعبير Nix expr.
•
--file / -f file
فسّر installables كمسارات سمات بالنسبة لتعبير Nix المخزن في file. إذا كان file هو الرمز -، فسيتم قراءة تعبير Nix من الإدخال القياسي. يعني ضمنيًا --impure.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام علامات سطر الأوامر.
