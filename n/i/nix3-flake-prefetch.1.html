nix3-flake-prefetch(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-flake-prefetch(1) دليل الأوامر العامة nix3-flake-prefetch(1)

تحذير
هذا البرنامج تجريبي وواجهته قابلة للتغيير.

الاسم

nix flake prefetch - تنزيل شجرة المصدر المشار إليها بواسطة مرجع الـ flake إلى مخزن Nix

الملخص

nix flake prefetch [خيار•] flake-url

أمثلة

•
تنزيل ملف tar وفك ضغطه:
# nix flake prefetch https://cdn.kernel.org/pub/linux/kernel/v5.x/linux-5.10.5.tar.xz
تم تنزيل 'https://cdn.kernel.org/pub/linux/kernel/v5.x/linux-5.10.5.tar.xz?narHash=sha256-3XYHZANT6AFBV0BqegkAZHbba6oeDkIUCDwbATLMhAY='
إلى '/nix/store/sl5vvk8mb4ma1sjyy03kwpvkz50hd22d-source' (الهاش
'sha256-3XYHZANT6AFBV0BqegkAZHbba6oeDkIUCDwbATLMhAY=').
•
تنزيل الـ flake dwarffs (تم البحث عنه في سجل الـ flakes):
# nix flake prefetch dwarffs --json
{"hash":"sha256-VHg3MYVgQ12LeRSU2PSoDeKlSPD8PYYEFxxwkVVDRd0="
,"storePath":"/nix/store/hang3792qwdmm2n0d9nsrs5n6bsws6kv-source"}

الوصف

يقوم هذا الأمر بتنزيل شجرة المصدر المشار إليها بواسطة مرجع الـ flake flake-url. لاحظ أن هذا لا يتطلب أن يكون ملف flake (أي أنه لا يحتاج إلى احتواء ملف flake.nix).

خيارات

•
--json
إنشاء مخرجات بتنسيق JSON، مناسبة للاستهلاك بواسطة برنامج آخر.

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كـ الوسيط name لوظائف Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كـ الوسيط name لوظائف Nix.
•
--arg-from-stdin name
تمرير محتويات stdin كـ الوسيط name لوظائف Nix.
•
--argstr name string
تمرير السلسلة النصية string كـ الوسيط name لوظائف Nix.
•
--debugger
بدء بيئة تفاعلية في حال فشل التقييم.
•
--eval-store store-url
عنوان URL لمخزن Nix لاستخدامه في التقييم، أي لتخزين المشتقات (ملفات .drv) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتعديل.
•
--include / -I path
إضافة path إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد التكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake original-ref resolved-ref
تجاوز سجلات الـ flakes، مع إعادة توجيه original-ref إلى resolved-ref.

خيارات متعلقة بالـ Flake الشائعة

•
--commit-lock-file
تثبيت التغييرات في ملف قفل الـ flake.
•
--inputs-from flake-url
استخدام مدخلات الـ flake المحدد كإدخالات في السجل.
•
--no-registries
عدم السماح بالبحث في سجلات الـ flakes.
تم إيقافه
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
عدم السماح بأي تحديثات لملف قفل الـ flake.
•
--no-write-lock-file
عدم كتابة ملف قفل الـ flake الذي تم إنشاؤه حديثًا.
•
--output-lock-file flake-lock-path
كتابة ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--override-input input-path flake-url
تجاوز مدخل flake معين (مثل dwarffs/nixpkgs). هذا يعني --no-write-lock-file.
•
--recreate-lock-file
إعادة إنشاء ملف قفل الـ flake من الصفر.
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
•
--reference-lock-file flake-lock-path
قراءة ملف القفل المحدد بدلاً من flake.lock داخل الـ flake الرئيسي.
•
--update-input input-path
تحديث مدخل flake معين (مع تجاهل إدخاله السابق في ملف القفل).
تم إيقافه
استخدم nix flake update بدلاً من ذلك.
