nix3-profile-upgrade(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

Name

nix - A universal package manager

Synopsis

nix command

Examples

Build the flake in the current directory:
$ nix build .#somePackage
Enter a shell environment for the default package in the current flake:
$ nix shell
Install the default package in the current flake:
$ nix profile install .
Run a command in a shell derived from the flake:
$ nix shell .#somePackage -- command --arg x 1
Show build information for the default package in the current flake:
$ nix build --info
Update all flake inputs:
DEPRECATED
Use nix flake update instead.

Description

The nix command is the entry point to the new Nix command-line interface (CLI). It provides subcommands for interacting with Nix features such as flakes, profiles, garbage collection, and more.

The new CLI is designed to be more user-friendly and consistent than the legacy CLI (e.g., `nix-build`, `nix-env`). It aims to provide a unified interface for common package management tasks.

This manual page primarily focuses on the global options and options that modify the interpretation of installables.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
