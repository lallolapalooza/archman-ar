nix3-nar-ls(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-nar-ls(1) دليل الأوامر العامة nix3-nar-ls(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix nar ls - عرض معلومات حول مسار داخل ملف NAR

التركيب

nix nar ls [خيار…] nar مسار

أمثلة

•
لعرض ملف معين في NAR:
# nix nar ls --long ./hello.nar /bin/hello
-r-xr-xr-x                38184 hello
•
لعرض محتويات دليل داخل NAR بشكل متكرر، بتنسيق JSON:
# nix nar ls --json --recursive ./hello.nar /bin
{"type":"directory","entries":{"hello":{"type":"regular","size":38184,"executable":true,"narOffset":400}}}

الوصف

يعرض هذا الأمر معلومات حول مسار داخل ملف Nix Archive (NAR).

خيارات

•
--directory / -d
عرض الأدلة بدلاً من محتوياتها.
•
--json
إنتاج المخرجات بتنسيق JSON، مناسبة للاستهلاك من قبل برنامج آخر.
•
--long / -l
عرض معلومات مفصلة عن الملف.
•
--recursive / -R
عرض الأدلة الفرعية بشكل متكرر.

خيارات متعلقة بالتسجيل

•
--debug
ضبط مستوى تفصيل التسجيل على 'debug'.
•
--log-format format
ضبط تنسيق مخرجات السجل؛ أحد الخيارات: raw, internal-json, bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
خفض مستوى تفصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل البدائل واعتبار جميع الملفات التي تم تنزيلها سابقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (متجاوزًا nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها سابقًا غير محدثة.
•
--version
عرض معلومات الإصدار.

ملاحظة

راجع man nix.conf لتجاوز إعدادات التكوين باستخدام أعلام سطر الأوامر.
