nix3-bundle(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-bundle(1) دليل الأوامر العامة nix3-bundle(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix bundle - تجميع تطبيق ليعمل خارج مخزن Nix

الملخص

nix bundle [خيار…] قابل للتثبيت

أمثلة

•
تجميع Hello:
# nix bundle nixpkgs#hello
# ./hello
Hello, world!
•
تجميع إصدار معين من Nix:
# nix bundle github:NixOS/nix/e3ddffb27e5fc37a209cfd843c6f7f6a9460a8ec
# ./nix --version
nix (Nix) 2.4pre20201215_e3ddffb
•
تجميع Hello باستخدام مجمّع محدد:
# nix bundle --bundler github:NixOS/bundlers#toDockerImage nixpkgs#hello
# docker load < hello-2.10.tar.gz
# docker run hello-2.10:latest hello
Hello, world!

الوصف

nix bundle، افتراضيًا، يجمع إغلاق القابل للتثبيت في ملف تنفيذي واحد ذاتي الاستخراج. انظر صفحة المجمعين للمزيد من التفاصيل.

ملاحظة

هذا الأمر يعمل فقط على Linux.

سمات مخرجات Flake

إذا لم يتم تحديد سمة مخرجات flake، يحاول nix bundle سمات المخرجات التالية:

•
bundlers.<system>.default

إذا تم تحديد اسم سمة، يحاول nix bundle سمات المخرجات التالية:

•
bundlers.<system>.<name>

المجمعون

يتم تحديد المجمّع بواسطة سمة مخرجات flake تسمى bundlers.<system>.<name>. تبدو كالتالي:

bundlers.x86_64-linux = rec {
  identity = drv: drv;
  blender_2_79 = drv: self.packages.x86_64-linux.blender_2_79;
  default = identity;
};

يجب أن يكون المجمّع دالة تقبل قيمة اعتباطية (عادةً تعريف اشتقاق أو تطبيق) وتعيد اشتقاقًا.

خيارات

•
--bundler flake-url
استخدام مجمّع مخصص بدلاً من الافتراضي (github:NixOS/bundlers).
•
--out-link / -o مسار
تجاوز اسم الرابط الرمزي لنتيجة البناء. الافتراضي هو الاسم الأساسي للتطبيق.

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كمعامل name لدوال Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كمعامل name لدوال Nix.
•
--arg-from-stdin name
تمرير محتويات المدخل القياسي كمعامل name لدوال Nix.
•
--argstr name string
تمرير السلسلة النصية string كمعامل name لدوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store store-url
عنوان URL لمخزن Nix المستخدم للتقييم، أي لتخزين المشتقات (.drv files) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
إضافة path إلى مسارات البحث المستخدمة لحل مسارات البحث
يمكن إعطاء هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path ومتغير البيئة NIX_PATH .
•
--override-flake original-ref resolved-ref
تجاوز سجلات flake، وإعادة توجيه original-ref إلى resolved-ref.

خيارات شائعة متعلقة بـ Flake

•
--commit-lock-file
تثبيت التغييرات في ملف قفل flake.
•
--inputs-from flake-url
استخدام مدخلات flake المحدد كمدخلات سجل.
•
--no-registries
عدم السماح بالبحث في سجلات flake.
تم إهماله
استخدم --no-use-registries بدلاً من ذلك.
•
--no-update-lock-file
عدم السماح بأي تحديثات لملف قفل flake.
•
--no-write-lock-file
عدم كتابة ملف قفل flake الذي تم إنشاؤه حديثًا.
•
--output-lock-file flake-lock-path
كتابة ملف القفل المحدد بدلاً من flake.lock داخل flake المستوى الأعلى.
•
--override-input input-path flake-url
تجاوز مدخل flake معين (مثل dwarffs/nixpkgs). هذا يتضمن --no-write-lock-file

NAME

nix3-bundle - A command for creating and managing NixOS configurations.

SYNOPSIS

nix3-bundle [options] installables...

EXAMPLES

Build a flake output:

  • $ nix3-bundle '/path/to/my/flake#some-package'

Build multiple flake outputs:

  • $ nix3-bundle --option build-userspace-root true /path/to/my/flake#package1 /path/to/my/flake#package2

Build a flake output, ignoring the lock file:

  • $ nix3-bundle --recreate-lock-file /path/to/my/flake#package

Build a flake output without accessing the network:

  • $ nix3-bundle --offline /path/to/my/flake#package

DESCRIPTION

The nix3-bundle command is used to build and manage Nix flake outputs. It allows you to specify flake inputs, manage lock files, and control build behavior.

Flake output attributes

The installables argument is a list of flake references. A flake reference is of the form:

/path/to/flake#attribute

where

/path/to/flake is a path to a flake directory or a Git repository containing a flake, and
attribute is an attribute path within the flake's outputs (e.g., packages.x86_64-linux.default or nixosConfigurations.myVM.config.system.build.toplevel).

If the attribute is omitted, it defaults to defaultPackage.${system}, where ${system} is the host system's platform.

Bundlers

Flakes can expose different types of outputs, such as packages, NixOS configurations, or development shells. The nix3-bundle command is designed to work with these various outputs.

Options

Flake options

•
--recreate-lock-file
Recreate the flake’s lock file from scratch.
DEPRECATED
Use nix flake update instead.
•
--reference-lock-file flake-lock-path
Read the given lock file instead of flake.lock within the top-level flake.
•
--update-input input-path
Update a specific flake input (ignoring its previous entry in the lock file).
DEPRECATED
Use nix flake update instead.

Logging-related options

•
--debug
Set the logging verbosity level to ‘debug’.
•
--log-format format
Set the format of log output; one of raw, internal-json, bar or bar-with-logs.
•
--print-build-logs / -L
Print full build logs on standard error.
•
--quiet
Decrease the logging verbosity level.
•
--verbose / -v
Increase the logging verbosity level.

Miscellaneous global options

•
--help
Show usage information.
•
--offline
Disable substituters and consider all previously downloaded files up-to-date.
•
--option name value
Set the Nix configuration setting name to value (overriding nix.conf).
•
--refresh
Consider all previously downloaded files out-of-date.
•
--repair
During evaluation, rewrite missing or corrupted files in the Nix store. During building, rebuild missing or corrupted store paths.
•
--version
Show version information.

Options that change the interpretation of installables

•
--expr expr
Interpret installables as attribute paths relative to the Nix expression expr.
•
--file / -f file
Interpret installables as attribute paths relative to the Nix expression stored in file. If file is the character -, then a Nix expression will be read from standard input. Implies --impure.

Note

See man nix.conf for overriding configuration settings with command line flags.
