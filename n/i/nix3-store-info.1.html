nix3-store-info(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-store-info(1) دليل الأوامر العامة nix3-store-info(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix store info - اختبار ما إذا كان يمكن الوصول إلى المتجر

الملخص

nix store info [خيار…]

أمثلة

•
اختبار ما إذا كان الاتصال بمتجر Nix عن بعد عبر SSH يعمل:
# nix store info --store ssh://mac1
•
اختبار ما إذا كان عنوان URL هو مخزن ثنائي صالح:
# nix store info --store https://cache.nixos.org
•
اختبار ما إذا كان خادم Nix يعمل:
# nix store info --store daemon

الوصف

يختبر هذا الأمر ما إذا كان يمكن الوصول إلى متجر Nix معين (محدد بالوسيط --store url). ما يعنيه هذا يعتمد على نوع المتجر. على سبيل المثال، بالنسبة لمتجر SSH، يعني أنه يمكن لـ Nix الاتصال بالجهاز المحدد.

إذا نجح الأمر، فإن Nix يعيد رمز خروج 0 ولا يطبع أي مخرجات.

خيارات

•
--json
إنتاج المخرجات بتنسيق JSON، مناسب للاستهلاك بواسطة برنامج آخر.

خيارات متعلقة بالتسجيل

•
--debug
تعيين مستوى تفاصيل التسجيل إلى "debug".
•
--log-format format
تعيين تنسيق مخرجات السجل؛ أحد الخيارات: raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات الإنشاء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفاصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفاصيل التسجيل.

خيارات عامة أخرى

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل المستبدلات واعتبار جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (متجاوزًا nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها مسبقًا غير محدثة.
•
--version
عرض معلومات الإصدار.

ملاحظة

انظر man nix.conf لتجاوز إعدادات التكوين باستخدام علامات سطر الأوامر.
