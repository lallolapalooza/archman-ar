nix3-flake-metadata(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

nix3-flake-metadata(1) دليل الأوامر العامة nix3-flake-metadata(1)

تحذير
هذا البرنامج تجريبي وواجهته عرضة للتغيير.

الاسم

nix flake metadata - عرض بيانات تعريف الـ flake

الملخص

nix flake metadata [خيار•] flake-url

أمثلة

•

الوصف

يعرض هذا الأمر معلومات حول الـ flake المحدد بواسطة مرجع الـ flake flake-url. يقوم بحل مرجع الـ flake باستخدام سجل الـ flake، ويقوم بجلبها، ثم يطبع بعض البيانات الوصفية. يشمل ذلك:

  • عنوان URL المحلول: إذا كان flake-url معرفًا للـ flake، فهذا هو مرجع الـ flake الذي يحدد موقعه الفعلي، والذي تم البحث عنه في سجل الـ flake.
  • عنوان URL المقفل: مرجع للـ flake يحتوي على تجزئة الالتزام أو المحتوى، وبالتالي يحدد إصدارًا معينًا للـ flake بشكل فريد.
  • الوصف: وصف من سطر واحد للـ flake، مأخوذ من حقل description في flake.nix.
  • المسار: مسار المتجر الذي يحتوي على الكود المصدري للـ flake.
  • المراجعة: تجزئة الالتزام (Commit hash) من Git أو Mercurial للـ flake المقفل.
  • المراجعات: عدد الأسلاف لتجزئة الالتزام (Commit hash) من Git أو Mercurial للـ flake المقفل. لاحظ أن هذا غير متاح لـ github flakes.
  • آخر تعديل: بالنسبة لـ Git أو Mercurial flakes، يكون هذا هو وقت الالتزام (Commit time) للالتزام (Commit) للـ flake المقفل؛ بالنسبة لـ tarball flakes، يكون هذا هو أحدث طابع زمني لأي ملف داخل الـ tarball.
  • المدخلات: مدخلات الـ flake مع إدخالات ملف القفل المقابلة لها.

باستخدام --json، يكون الإخراج عبارة عن كائن JSON يحتوي على الحقول التالية:

  • original و originalUrl: مرجع الـ flake الذي حدده المستخدم (flake-url) في مجموعة السمات وتمثيل عنوان URL.
  • resolved و resolvedUrl: مرجع الـ flake المحلول (انظر أعلاه) في مجموعة السمات وتمثيل عنوان URL.
  • locked و lockedUrl: مرجع الـ flake المقفل (انظر أعلاه) في مجموعة السمات وتمثيل عنوان URL.
  • description: انظر الوصف أعلاه.
  • path: انظر المسار أعلاه.
  • revision: انظر المراجعة أعلاه.
  • revCount: انظر المراجعات أعلاه.
  • lastModified: انظر آخر تعديل أعلاه.
  • locks: محتويات flake.lock.

خيارات

•
--json
إنتاج الإخراج بتنسيق JSON، مناسب للاستهلاك بواسطة برنامج آخر.

خيارات التقييم الشائعة

•
--arg name expr
تمرير القيمة expr كالسمة name إلى دوال Nix.
•
--arg-from-file name path
تمرير محتويات الملف path كالسمة name إلى دوال Nix.
•
--arg-from-stdin name
تمرير محتويات الإدخال القياسي كالسمة name إلى دوال Nix.
•
--argstr name string
تمرير السلسلة النصية string كالسمة name إلى دوال Nix.
•
--debugger
بدء بيئة تفاعلية إذا فشل التقييم.
•
--eval-store store-url
عنوان URL لمتجر Nix المراد استخدامه للتقييم، أي لتخزين الاشتقاقات (.drv files) والمدخلات المشار إليها بها.
•
--impure
السماح بالوصول إلى المسارات والمستودعات القابلة للتغيير.
•
--include / -I path
إضافة path إلى إدخالات مسار البحث المستخدمة لحل مسارات البحث
يمكن تقديم هذا الخيار عدة مرات.
المسارات المضافة عبر -I لها الأسبقية على إعداد تكوين nix-path و متغير البيئة NIX_PATH.
•
--override-flake original-ref resolved-ref
تجاوز سجلات الـ flake، مع إعادة توجيه original-ref إلى resolved-r
