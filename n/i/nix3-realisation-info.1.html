nix3-realisation-info(1)

الحزمة: nix

التراخيص: LGPL-2.1-only

خيارات التسجيل

•
--log-format format
تعيين تنسيق إخراج السجل؛ أحد الخيارات التالية raw، internal-json، bar أو bar-with-logs.
•
--print-build-logs / -L
طباعة سجلات البناء الكاملة على الخطأ القياسي.
•
--quiet
تقليل مستوى تفصيل التسجيل.
•
--verbose / -v
زيادة مستوى تفصيل التسجيل.

خيارات عامة متنوعة

•
--help
عرض معلومات الاستخدام.
•
--offline
تعطيل البدائل واعتبار جميع الملفات التي تم تنزيلها مسبقًا محدثة.
•
--option name value
تعيين إعداد تكوين Nix name إلى value (الكتابة فوق nix.conf).
•
--refresh
اعتبار جميع الملفات التي تم تنزيلها مسبقًا غير محدثة.
•
--repair
أثناء التقييم، قم بإعادة كتابة الملفات المفقودة أو التالفة في متجر Nix. أثناء البناء، قم بإعادة بناء مسارات المتجر المفقودة أو التالفة.
•
--version
عرض معلومات الإصدار.

خيارات تغير تفسير المثبتات

•
--all
تطبيق العملية على كل مسار متجر.
•
--derivation
العمل على مشتق المتجر بدلاً من مخرجاته.
•
--expr expr
تفسير المثبتات كمسارات سمات نسبة إلى تعبير Nix expr.
•
--file / -f file
تفسير المثبتات كمسارات سمات نسبة إلى تعبير Nix المخزن في file. إذا كان file هو الرمز -، فسيتم قراءة تعبير Nix من الإدخال القياسي. يتضمن --impure.
•
--recursive / -r
تطبيق العملية على إغلاق المسارات المحددة.

ملاحظة

راجع man nix.conf للكتابة فوق إعدادات التكوين باستخدام علامات سطر الأوامر.
