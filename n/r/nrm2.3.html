LAPACK

NAME

nrm2 - computes the Euclidean norm of a vector.

SYNOPSIS

double precision function nrm2(n, x, incx)

integer n

double precision x(incx, *)

integer incx

Detailed Description

This function computes the Euclidean norm of a vector. The Euclidean norm is defined as the square root of the sum of the squares of the elements of the vector.

Function Documentation

The nrm2 function takes the following arguments:

  • n: The number of elements in the vector.
  • x: The vector itself.
  • incx: The increment between elements of the vector.

The function returns the Euclidean norm of the vector as a double precision floating-point number.
