nds32le-elf-size(1)

الحزمة: nds32le-elf-binutils

التراخيص: GPL

SIZE(1) أدوات تطوير GNU SIZE(1)

الاسم

size - يسرد أحجام الأقسام والحجم الإجمالي للملفات الثنائية

ملخص

size [-A|-B|-G|--format=compatibility]
[--help]
[-d|-o|-x|--radix=number]
[--common]
[-t|--totals]
[--target=bfdname] [-V|--version]
[-f]
[objfile...]

الوصف

يقوم أداة size الخاصة بـ GNU بسرد أحجام الأقسام والحجم الإجمالي لكل ملف من الملفات الثنائية objfile في قائمة الوسائط الخاصة بها. افتراضياً، يتم إنشاء سطر واحد من الإخراج لكل ملف أو لكل وحدة نمطية إذا كان الملف عبارة عن أرشيف.

objfile... هي الملفات التي سيتم فحصها. إذا لم يتم تحديد أي ملفات، فسيتم استخدام الملف "a.out" بدلاً من ذلك.

الخيارات

الخيارات الموجودة في سطر الأوامر لها المعاني التالية:

-A
-B
-G
--format=compatibility
باستخدام أحد هذه الخيارات، يمكنك اختيار ما إذا كان الإخراج من size الخاص بـ GNU يشبه إخراج size الخاص بـ System V (باستخدام -A، أو --format=sysv)، أو size الخاص بـ Berkeley (باستخدام -B، أو --format=berkeley). الافتراضي هو التنسيق المكون من سطر واحد مشابه لتنسيق Berkeley. بدلاً من ذلك، يمكنك اختيار تنسيق إخراج GNU (باستخدام -G، أو --format=gnu)، وهذا مشابه لتنسيق إخراج Berkeley، ولكن يتم حساب الأحجام بشكل مختلف.

إليك مثال على تنسيق Berkeley (الافتراضي) للإخراج من size:

$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

يحسب إخراج نمط Berkeley البيانات المقروءة فقط في عمود "text"، وليس في عمود "data"، ويعرض كل من العمودين "dec" و "hex" مجموع الأعمدة "text" و "data" و "bss" بالترتيب العشري والسداسي عشري على التوالي.

يقوم تنسيق GNU بحساب البيانات المقروءة فقط في عمود "data"، وليس في عمود "text"، ويعرض فقط مجموع الأعمدة "text" و "data" و "bss" مرة واحدة، في عمود "total". يمكن استخدام الخيار --radix لتغيير قاعدة الأرقام لجميع الأعمدة. إليك نفس البيانات معروضة وفقًا لاتفاقيات GNU:

$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

هذه هي نفس البيانات، ولكنها معروضة بشكل أقرب إلى اتفاقيات System V:

$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--help
-h
-H
-?
عرض ملخص للوسائط والخيارات المقبولة.
-d
-o
-x
--radix=number
باستخدام أحد هذه الخيارات، يمكنك التحكم فيما إذا كان حجم كل قسم يتم تقديمه بالعشري (-d، أو --radix=10)؛ الثماني (-o، أو --radix=8)؛ أو السداسي عشري (-x، أو --radix=16). في --radix=number، يتم دعم القيم الثلاث فقط (8، 10، 16). يتم دائمًا تقديم الحجم الإجمالي في قاعدتين؛ عشري وسداسي عشري لإخراج -d أو -x، أو ثماني وسداسي عشري إذا كنت تستخدم -o.
--common
طباعة الحجم الإجمالي للرموز المشتركة في كل ملف. عند استخدام نمط Berkeley أو GNU، يتم تضمين هذه الرموز في حجم bss.
-t
--totals
إظهار إجمالي جميع الكائنات المدرجة (في وضع نمط Berkeley أو GNU فقط).
--target=bfdname
تحديد أن تنسيق الشيفرة الثنائية لـ objfile هو bfdname. قد لا يكون هذا الخيار ضروريًا؛ يمكن لـ size التعرف تلقائيًا على العديد من التنسيقات.
-v
-V
--version
عرض رقم إصدار size.
-f
تم التجاهل. يتم استخدام هذا الخيار بواسطة إصدارات أخرى من برنامج size، ولكنه غير مدعوم بواسطة إصدار GNU Binutils.
@file
قراءة خيارات سطر الأوامر من file. يتم إدراج الخيارات المقروءة في مكان خيار @file الأصلي. إذا كان file غير موجود، أو لا يمكن قراءته، فسيتم التعامل مع الخيار حرفيًا، ولن يتم إزالته.

يتم فصل الخيارات في file بواسطة مسافات بيضاء. يمكن تضمين حرف مسافة بيضاء في خيار عن طريق إحاطة الخيار بأكمله بعلامات اقتباس مفردة أو مزدوجة. يمكن تضمين أي حرف (بما في ذلك الشرطة المائلة للخلف) عن طريق وضع البادئة للحرف المراد تضمينه بشرطة مائلة للخلف. قد يحتوي file نفسه على خيارات @file إضافية؛ سيتم معالجة أي خيارات من هذا القبيل بشكل متكرر.

انظر أيضًا

ar(1)، objdump(1)، readelf(1)، وإدخالات Info الخاصة بـ binutils.
