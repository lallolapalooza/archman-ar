ndctl-freeze-security(1)

الحزمة: ndctl

التراخيص: LGPL

NAME

ndctl-freeze-security, ndctl-unfreeze-security, ndctl-passphrase, ndctl-clear, ndctl-smart-log, ndctl-sanitize-dimm, ndctl-wait-sanitize — NVDIMM security and sanitization operations

SYNOPSIS

ndctl freeze-security [-d DimmSpec] --timeout seconds

ndctl unfreeze-security [-d DimmSpec]

ndctl passphrase [-d DimmSpec] { setup | update | disable }

ndctl clear [-d DimmSpec]

ndctl smart-log [-d DimmSpec]

ndctl sanitize-dimm [-d DimmSpec] { --overwrite | --crypto-erase }

ndctl wait-sanitize [-d DimmSpec]

DESCRIPTION

The ndctl utility provides a means to manage NVDIMMs, including operations related to security and data sanitization.

The following security and sanitization commands are available:

freeze-security

The freeze-security command is used to prevent access to security features of the NVDIMMs. This is primarily useful to prevent accidental modification or erasure of security-related data. The command takes a --timeout argument, specifying the duration in seconds for which the security freeze will remain active. After the timeout expires, the security features are automatically unfrozen. If no timeout is specified, the freeze remains active until the next system boot.

unfreeze-security

The unfreeze-security command removes any active security freeze, restoring access to security features.

passphrase

The passphrase command manages the NVDIMM security passphrase. It supports the following subcommands:

setup

Sets a new security passphrase for the NVDIMM(s). If a passphrase is already set, this command will fail unless the current passphrase is provided.

update

Updates the existing security passphrase. The current passphrase must be provided to change it.

disable

Disables the security passphrase protection. The current passphrase must be provided to disable it.

Note: For security reasons, it is strongly recommended to set a passphrase to protect your NVDIMMs.

clear

The clear command is a shortcut for performing a crypto erase operation on the NVDIMM(s). This operation erases all data stored on the NVDIMM by encrypting it with a new encryption key, rendering the previous data unrecoverable.

smart-log

Retrieves and displays the SMART (Self-Monitoring, Analysis, and Reporting Technology) log from the NVDIMM(s). This log contains information about the health and status of the device.

sanitize-dimm

Initiates a sanitization process for the NVDIMM(s). This command supports two methods:

--overwrite

Performs a block-by-block overwrite of the entire NVDIMM's storage. This is a destructive operation that aims to make data unrecoverable. The process can take a considerable amount of time.

--crypto-erase

Performs a cryptographic erase of the NVDIMM. This operation is generally faster than overwriting as it involves generating a new encryption key and discarding the old one. Data encrypted under the old key becomes irrecoverable.

wait-sanitize

Waits for an ongoing sanitization operation (either overwrite or crypto erase) to complete. This command is useful because sanitize-dimm only initiates the process, and it may take a long time to finish.

EXAMPLES

To freeze security on all NVDIMMs for 3600 seconds (1 hour):

ndctl freeze-security --timeout 3600

To unfreeze security on a specific NVDIMM (e.g., namespace0.0):

ndctl unfreeze-security -d namespace0.0

To set up a new user passphrase:

ndctl passphrase setup

To disable the security passphrase:

ndctl passphrase disable

To perform a crypto erase on all NVDIMMs:

ndctl sanitize-dimm --crypto-erase

To initiate an overwrite sanitization and then wait for its completion:

ndctl sanitize-dimm --overwrite
ndctl wait-sanitize

OPTIONS

-d DimmSpec
Specifies the target NVDIMM(s) or namespace(s) to operate on. This can be a DIMM ID, namespace ID, or a pattern matching them.
--timeout seconds
Specifies the duration in seconds for which the security freeze should remain active. If omitted, the freeze lasts until the next system reboot.
--overwrite
Initiates an overwrite sanitization process.
--crypto-erase
Initiates a crypto erase sanitization process.

THEORY OF OPERATION

The sanitize-dimm command, when used with the --overwrite option, invokes the overwrite operation for a specified NVDIMM. The overwrite operation is designed to securely erase all data on the NVDIMM. This process can be time-consuming, depending on the size of the NVDIMM and the system's capabilities.

It is important to note that a successful return from sanitize-dimm --overwrite indicates that the overwrite operation has been *started* successfully, not that it has been *completed*. To monitor the progress and wait for the completion of the overwrite operation, the ndctl wait-sanitize command should be used subsequently.

Upon successful completion of an overwrite sanitization, the kernel issues a WBINVD (Write Back and Invalidate Cache) instruction. This ensures that all cached data is written back to memory before the caches are invalidated, contributing to the data integrity and security of the operation.

If both the --crypto-erase and --overwrite options are provided to sanitize-dimm, the --crypto-erase operation will be performed first. This means the NVDIMM will be cryptographically erased before the overwrite process begins.

SECURITY FREEZE

This operation does not require a passphrase. This will cause any security command other than a status query to be locked out until the next boot.

MASTER PASSPHRASE SETUP, UPDATE, and CRYPTO ERASE

These operations are similar to the user passphrase enable and update. The only difference is that a different passphrase is used. The master passphrase has no relation to the master key (kek) which is used for encryption of either passphrase.
