ndctl-start-scrub(1)

الحزمة: ndctl

التراخيص: LGPL

NDCTL-START-SCRUB(1) دليل ndctl NDCTL-START-SCRUB(1)

الاسم

ndctl start-scrub - بدء عملية فحص نطاق العنوان (ARS)

الملخص

ndctl start-scrub [<معرف الناقل> <معرف الناقل2> ... <معرف الناقلN>] [<خيارات>]

الوصف

فحص نطاق عنوان NVDIMM هي قدرة توفرها البرامج الثابتة للمنصة تسمح للبرامج النظام باكتشاف أخطاء الذاكرة. وهي تمكن برامج النظام من تجنب الوصول الذي قد يؤدي إلى أحداث معالجة أخطاء ذاكرة غير قابلة للتصحيح بشكل استباقي، وتسمح بخلاف ذلك بتعداد أخطاء الذاكرة.

يوفر النواة ملف sysfs (scrub) والذي عند الكتابة إليه بالسلسلة النصية "1\n" يبدأ عملية ARS. تبدأ عملية ndctl start-scrub عملية ARS، عبر جميع نواقل الناقل المحددة، ويواصل النواة بدوره فحص كل منطقة ذاكرة مستمرة على نواقل الناقل المحددة.

مثال

بدء فحص على جميع نواقل nvdimm في النظام. يتضمن تقرير قائمة JSON فقط النواقل التي تدعم عمليات ARS.

# ndctl start-scrub
[
  {
    "provider":"nfit_test.1",
    "dev":"ndbus3",
    "scrub_state":"active"
  },
  {
    "provider":"nfit_test.0",
    "dev":"ndbus2",
    "scrub_state":"active"
  }
]

عند تحديد ناقل فردي، أو إذا كان هناك ناقل واحد فقط في النظام، يقوم الأمر بالإبلاغ عما إذا كان دعم ARS متاحًا.

# ndctl start-scrub e820
error starting scrub: Operation not supported

خيارات

-v, --verbose

إخراج رسائل التصحيح لعملية بدء ARS
