ndctl-list(1)

الحزمة: ndctl

التراخيص: LGPL

NDCTL-LIST(1) دليل ndctl NDCTL-LIST(1)

الاسم

ndctl-list - تفريغ طوبولوجيا جهاز nvdimm المنصة وخصائصها بتنسيق JSON

ملخص

ndctl list [<خيارات>]

يتنقل عبر جميع ناقلات nvdimm في النظام ويسرد جميع الأجهزة المتصلة مع بعض خصائصها الرئيسية.

يمكن تحديد الخيارات لتقييد الإخراج إلى أجهزة فئة معينة. حيث تكون الفئات هي ناقلات (buses)، وحدات dimms، مناطق (regions)، ومساحات الأسماء (namespaces). افتراضيًا، ndctl list بدون خيارات يعادل:

ndctl list --namespaces --bus=all --region=all

مثال

# ndctl list --buses --namespaces
{
  "provider":"nfit_test.1",
  "dev":"ndbus2",
  "namespaces":[
    {
      "dev":"namespace9.0",
      "mode":"raw",
      "size":33554432,
      "blockdev":"pmem9"
    }
  ]
}
{
  "provider":"nfit_test.0",
  "dev":"ndbus1"
}
{
  "provider":"e820",
  "dev":"ndbus0",
  "namespaces":[
    {
      "dev":"namespace0.0",
      "mode":"fsdax",
      "size":8589934592,
      "blockdev":"pmem0"
    }
  ]
}

خيارات

-r, --region=

اسم جهاز regionX، أو رقم معرف المنطقة. يقيّد العملية على المنطقة (المناطق) المحددة. يمكن تحديد الكلمة المفتاحية all للإشارة إلى عدم وجود أي تقييد، ومع ذلك هذا نفس الشيء مثل عدم توفير خيار --region على الإطلاق.

-b, --bus=

رقم معرف الناقل، أو سلسلة موفر (مثل "ACPI.NFIT"). يقيّد العملية على الناقل (النواقل) المحدد. يمكن تحديد الكلمة المفتاحية all للإشارة إلى عدم وجود أي تقييد، ومع ذلك هذا نفس الشيء مثل عدم توفير خيار --bus على الإطلاق.

-d, --dimm=

اسم جهاز nmemX، أو رقم معرف dimm. رقم معرف dimm هنا هو X في nmemX. يقوم بتصفية القائمة حسب الأجهزة التي تشير إلى dimm المعطى. على سبيل المثال لرؤية جميع مساحات الأسماء المكونة من سعة تخزين على nmem0:
# ndctl list --dimm=nmem0 --namespaces

-n, --namespace=

اسم جهاز namespaceX.Y، أو زوج منطقة مساحة الأسماء بالإضافة إلى المعرف X.Y. يحد قائمة مساحة الأسماء بالجهاز الفردي المحدد إذا كان موجودًا.

-m, --mode=

يقوم بتصفية القائمة حسب الوضع (raw، fsdax، sector أو devdax) لمساحة (مساحات) الأسماء.

-U, --numa-node=

يقوم بتصفية القائمة حسب عقدة numa

-B, --buses

تضمين معلومات الناقل في القائمة

-D, --dimms

تضمين معلومات dimm في القائمة
{
  "dev":"nmem0",
  "id":"cdab-0a-07e0-ffffffff",
  "handle":0,
  "phys_id":0,
  "security:":"disabled"
}

-H, --health

تضمين معلومات صحة dimm في القائمة. على سبيل المثال:
{
  "dev":"nmem0",
  "health":{
    "health_state":"non-critical",
    "temperature_celsius":23,
    "spares_percentage":75,
    "alarm_temperature":true,
    "alarm_spares":true,
    "temperature_threshold":40,
    "spares_threshold":5,
    "life_used_percentage":5,
    "shutdown_state":"clean"
  }
}

-F, --firmware

تضمين معلومات البرامج الثابتة في القائمة، بما في ذلك حالة وقدرة تفعيل البرامج الثابتة وقت التشغيل:
# ndctl list -BDF
[
  {
    "provider":"nfit_test.0",
    "dev":"ndbus2",
    "scrub_state":"idle",
    "firmware":{
      "activate_method":"suspend",
      "activate_state":"idle"
    },
    "dimms":[
      {
        "dev":"nmem1",
        "id":"cdab-0a-07e0-ffffffff",
        "handle":0,
        "phys_id":0,
        "security":"disabled",
        "firmware":{
          "current_version":0,
          "can_update":true
        }
      },
...
]

-X, --device-dax

تضمين تفاصيل device-dax ("daxregion") عندما تكون مساحة الأسماء في وضع "devdax".
{
  "dev":"namespace0.0",
  "mode":"devdax",
  "size":4225761280,
  "uuid":"18ae1bbb-bb62-4efc-86df-4a5caacb5dcc",
  "daxregion":{
    "id":0,
    "size":4225761280,
    "align":2097152,
    "devices":[
      {
        "chardev":"dax0.0",
        "size":4225761280
      }
    ]
  }
}

-R, --regions

تضمين معلومات المنطقة في القائمة

-N, --namespaces

تضمين معلومات مساحة الأسماء في القائمة. يتم سرد معلومات مساحة الأسماء افتراضيًا إذا لم يتم تحديد أي خيارات أخرى للأمر.

-i, --idle

تضمين الأجهزة الخاملة (غير المفعلة) في القائمة

-c, --configured

تضمين الأجهزة المهيأة (مساحات أسماء بحجم غير صفري) بغض النظر عما إذا كانت مفعلة أم لا. تعتبر الأجهزة الأخرى بخلاف مساحات الأسماء دائمًا "مهيأة".

-C, --capabilities

تضمين قدرات المنطقة في القائمة، أي الأوضاع المدعومة لمساحة الأسماء والخصائص المتغيرة مثل أحجام القطاعات والمحاذاة.

-M, --media-errors

تضمين أخطاء الوسائط (badblocks) في القائمة. لاحظ أن خاصية badblock_count مدرجة في القائمة افتراضيًا عندما يكون العدد غير صفري، وإلا فإنه مخفي. أيضًا، إذا كانت مساحة الأسماء في وضع sector فإن قائمة badblocks غير مدرجة وقد تتضمن خاصية badblock_count كتلًا تقع في البيانات الوصفية، أو سعة غير مستخدمة في مساحة الأسماء. قم بتحويل مساحة أسماء sector إلى وضع raw لسرد إزاحات badblocks الدقيقة.
{
  "dev":"namespace7.0",
  "mode":"raw",
  "size":33554432,
  "blockdev":"pmem7",
  "badblock_count":17,
  "badblocks":[
    {
      "offset":4,
      "length":1
    },
    {
      "offset":32768,
      "length":8
    },
    {
      "offset":65528,
      "length":8
    }
  ]
}

-v, --verbose

زيادة تفصيل الإخراج. يمكن تحديد هذا عدة مرات ليكون أكثر تفصيلًا في المعلومات والإخراج المتنوع، ويمكن استخدامه لتجاوز العلامات المحذوفة لعرض معلومات محددة.
•-v بالإضافة إلى إخراج مساحات الأسماء المفعلة الافتراضي، عرض عقدة numa، raw_uuid، وأخطاء وسائط الكتل السيئة.
•-vv كل ما يقدمه -v، بالإضافة إلى تفعيل --dimms، --buses، و --regions تلقائيًا.
•-vvv كل ما يقدمه -vv، بالإضافة إلى --health، --capabilities، --idle، و --firmware. :: يمكن أيضًا تحديد نطاق التفصيل حسب نوع الكائن. على سبيل المثال لسرد المناطق فقط مع معلومات القدرات وأخطاء الوسائط.
# ndctl list -Ru -vvv -r 0
{
  "dev":"region0",
  "size":"4.00 GiB (4.29 GB)",
  "available_size":0,
  "max_available_extent":0,
  "type":"pmem",
  "numa_node":0,
  "target_node":2,
  "capabilities":[
    {
      "mode":"sector",
      "sector_sizes":[
        512,
        520,
        528,
        4096,
        4104,
        4160,
        4224
      ]
    },
    {
      "mode":"fsdax",
      "alignments":[
        4096,
        2097152,
        1073741824
      ]
    },
    {
      "mode":"devdax",
      "alignments":[
        4096,
        2097152,
        1073741824
      ]
    }
  ],
  "persistence_domain":"unknown"
}

-u, --human

تنسيق الأرقام التي تمثل أحجام التخزين، أو الإزاحات كسلاسل قابلة للقراءة البشرية مع وحدات بدلًا من البيانات الرقمية الخام الافتراضية الصديقة للآلة. تحويل الحقول الرقمية الأخرى إلى سلاسل سداسية عشرية.
# ndctl list --region=7
{
  "dev":"region7",
  "size":67108864,
