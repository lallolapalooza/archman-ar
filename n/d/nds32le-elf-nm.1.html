nds32le-elf-nm(1)

الحزمة: nds32le-elf-binutils

التراخيص: GPL

OPTIONS

-a
Same as --debug-syms.
-g
Same as --debugging.
-l
Same as --dynamic-syms.
-P
Same as --external-syms.
-u
Same as --undefined-syms.
-v
Same as --version-syms.
--debug-syms
Print local, static, and external symbols, in addition to the normal symbols.
--debugging
Print debugging symbols. By default, only symbols that are global or undefined are printed. This option is equivalent to the -g option for the GDB debugger.
--dynamic-syms
Print dynamic symbols. These are the symbols that are visible to the dynamic linker. This is equivalent to the -l option.
--external-syms
Print only external symbols. This is equivalent to the -P option.
--format=format
Use the format when printing symbols. The possible values for format are default, sysv, posix, and gnu. The default format is determined by the default symbol versioning. See the description of --version-script for details of the other formats.
--gnu-label
If a symbol has version information, display the version information after the symbol name. For example, foo@VER_1. If the version is the default version to be used when resolving unversioned references to the symbol then it is displayed as a suffix preceded by two @ characters. For example foo@@VER_2. By default, symbol version information is displayed.
--target=bfdname
Specify an object code format other than your system's default format.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
