NAME

cblas_ztbsv - performs the matrix-vector operation Y = A*X

SYNOPSIS

#include <cblas.h>

void
cblas_ztbsv(const enum 

DESCRIPTION


The routines compute the solve of a triangular band matrix-vector system. Specifically, they compute:


  x = A-1*x



where A is a triangular band matrix.
