DESCRIPTION

These routines provide a 64-bit integer interface to the CBLAS library. The 64-bit integer interface allows the use of matrices and vectors with dimensions larger than what can be represented by a 32-bit integer. All routines in this interface accept integer arguments of type int64_t instead of int.

The following routines are provided:

  • cblas_zher2_64, cblas_zhpr2_64: complex Hermitian rank 2 update, packed and non-packed
  • cblas_sgemm_64, cblas_sgemmtr_64: single-precision general matrix multiply, transpose and non-transpose for packed matrices
  • cblas_ssymm_64: single-precision symmetric matrix multiply
  • cblas_ssyrk_64: single-precision symmetric rank k update
  • cblas_ssyr2k_64: single-precision symmetric rank 2k update
  • cblas_strmm_64: single-precision triangular matrix multiply
  • cblas_strsm_64: single-precision triangular solve with multiple right-hand sides
  • cblas_dgemm_64, cblas_dgemmtr_64: double-precision general matrix multiply, transpose and non-transpose for packed matrices
  • cblas_dsymm_64: double-precision symmetric matrix multiply
  • cblas_dsyrk_64: double-precision symmetric rank k update
  • cblas_dsyr2k_64: double-precision symmetric rank 2k update
  • cblas_dtrmm_64: double-precision triangular matrix multiply
  • cblas_dtrsm_64: double-precision triangular solve with multiple right-hand sides
  • cblas_cgemm_64, cblas_cgemmtr_64: single-precision complex general matrix multiply, transpose and non-transpose for packed matrices
  • cblas_csymm_64: single-precision complex symmetric matrix multiply
  • cblas_csyrk_64: single-precision complex symmetric rank k update
  • cblas_csyr2k_64: single-precision complex symmetric rank 2k update
  • cblas_ctrmm_64: single-precision complex triangular matrix multiply
  • cblas_ctrsm_64: single-precision complex triangular solve with multiple right-hand sides
  • cblas_zgemm_64, cblas_zgemmtr_64: double-precision complex general matrix multiply, transpose and non-transpose for packed matrices
  • cblas_zsymm_64: double-precision complex symmetric matrix multiply
  • cblas_zsyrk_64: double-precision complex symmetric rank k update
  • cblas_zsyr2k_64: double-precision complex symmetric rank 2k update
  • cblas_ztrmm_64: double-precision complex triangular matrix multiply
  • cblas_ztrsm_64: double-precision complex triangular solve with multiple right-hand sides
  • cblas_chemm_64: single-precision complex Hermitian matrix multiply
  • cblas_cherk_64: single-precision complex Hermitian rank k update
  • cblas_cher2k_64: single-precision complex Hermitian rank 2k update
  • cblas_zhemm_64: double-precision complex Hermitian matrix multiply
  • cblas_zherk_64: double-precision complex Hermitian rank k update
  • cblas_zher2k_64: double-precision complex Hermitian rank 2k update
  • cblas_xerbla_64: CBLAS error reporting routine

The parameters layout, Uplo, Side, TransA, TransB, Diag, N, M, K, incX, incY, lda, ldb, ldc, alpha, beta, X, Y, A, B, C, Ap, Ai, As, At, Ar, Ar2 are described in the corresponding CBLAS man pages.

The routine cblas_xerbla_64 is the error reporting routine. It is called when an error is detected by any of the CBLAS routines. The parameter p indicates the number of the invalid parameter, rout is the name of the routine that detected the error, and form describes the expected format of the invalid parameter.
