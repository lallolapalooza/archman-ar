Description

The CBLAS library provides a set of routines for the BLAS operations, which have been implemented in C. The routines are named according to the CBLAS interface specification.

The routines defined in this man page are the 64-bit integer versions of the BLAS routines. They differ from the standard BLAS routines in that they use int64_t for dimensions and increments, and double pointers where appropriate.

The specific routines are:

cblas_zher2_64
Computes the rank-2 update of a Hermitian matrix.
cblas_zhpr2_64
Computes the rank-2 update of a Hermitian matrix, packed storage.
cblas_sgemm_64
Single-precision general matrix-matrix multiplication.
cblas_sgemmtr_64
Single-precision general matrix-matrix multiplication, triangular part.
cblas_ssymm_64
Single-precision symmetric matrix-matrix multiplication.
cblas_ssyrk_64
Single-precision symmetric rank-K update.
cblas_ssyr2k_64
Single-precision symmetric rank-2K update.
cblas_strmm_64
Single-precision triangular matrix-matrix multiplication.
cblas_strsm_64
Single-precision triangular matrix-matrix multiplication, solve.
cblas_dgemm_64
Double-precision general matrix-matrix multiplication.
cblas_dgemmtr_64
Double-precision general matrix-matrix multiplication, triangular part.
cblas_dsymm_64
Double-precision symmetric matrix-matrix multiplication.
cblas_dsyrk_64
Double-precision symmetric rank-K update.
cblas_dsyr2k_64
Double-precision symmetric rank-2K update.
cblas_dtrmm_64
Double-precision triangular matrix-matrix multiplication.
cblas_dtrsm_64
Double-precision triangular matrix-matrix multiplication, solve.
cblas_cgemm_64
Single-precision complex general matrix-matrix multiplication.
cblas_cgemmtr_64
Single-precision complex general matrix-matrix multiplication, triangular part.
cblas_csymm_64
Single-precision complex symmetric matrix-matrix multiplication.
cblas_csyrk_64
Single-precision complex symmetric rank-K update.
cblas_csyr2k_64
Single-precision complex symmetric rank-2K update.
cblas_ctrmm_64
Single-precision complex triangular matrix-matrix multiplication.
cblas_ctrsm_64
Single-precision complex triangular matrix-matrix multiplication, solve.
cblas_zgemm_64
Double-precision complex general matrix-matrix multiplication.
cblas_zgemmtr_64
Double-precision complex general matrix-matrix multiplication, triangular part.
cblas_zsymm_64
Double-precision complex symmetric matrix-matrix multiplication.
cblas_zsyrk_64
Double-precision complex symmetric rank-K update.
cblas_zsyr2k_64
Double-precision complex symmetric rank-2K update.
cblas_ztrmm_64
Double-precision complex triangular matrix-matrix multiplication.
cblas_ztrsm_64
Double-precision complex triangular matrix-matrix multiplication, solve.
cblas_chemm_64
Single-precision complex Hermitian matrix-matrix multiplication.

CBLAS error reporting routine.

Arguments

The arguments are self-explanatory and follow the CBLAS interface specification.

CBLAS_LAYOUT layout

Specifies whether matrix storage is row-major or column-major.

CBLAS_ROW_MAJOR
Row-major storage.
CBLAS_COL_MAJOR
Column-major storage.

CBLAS_UPLO Uplo

Specifies which part of the matrix to access.

CBLAS_UPPER
Upper triangle.
CBLAS_LOWER
Lower triangle.

CBLAS_TRANSPOSE TransA, CBLAS_TRANSPOSE TransB, CBLAS_TRANSPOSE Trans

Specifies the form of the matrix.

CBLAS_NO_TRANS
No transpose.
CBLAS_TRANS
Transpose.
CBLAS_CONJ_TRANS
Conjugate transpose.

CBLAS_SIDE Side

Specifies whether to modify the left or right side of the matrix.

CBLAS_LEFT
Left side.
CBLAS_RIGHT
Right side.

CBLAS_DIAG Diag

Specifies whether the matrix has a unit diagonal.

CBLAS_UNIT
Unit diagonal.
CBLAS_NON_UNIT
Non-unit diagonal.

int64_t N, M, K, incX, incY, lda, ldb, ldc

Dimensions and increments.

const void * alpha, const void * beta, const void * X, const void * Y, void * A, void * Ap, void * B, void * C

Pointers to the matrices and vectors.

Note that for single and double precision routines, alpha and beta are passed as floats and doubles respectively, while for complex routines, they are passed as pointers to void. The library internally determines the correct data type.

int64_t p, const char *rout, const char *form

Arguments for the error reporting routine cblas_xerbla_64.
