Curses__UI__Window(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Window(3) وثائق Perl مقدمة من المستخدم Curses::UI::Window(3)

الاسم

Curses::UI::Window - إنشاء ومعالجة عناصر واجهة المستخدم الرسومية (Widgets) للنافذة

تسلسل الفئات

Curses::UI::Widget
   |
   +----Curses::UI::Container   
           |
           +----Curses::UI::Window

ملخص

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add(
    'window_id', 'Window',
    %options,
);

الوصف

Curses::UI::Window هو عنصر واجهة مستخدم رسومية (widget) يمثل نافذة. يمكن إضافته إلى كائن Curses::UI. بعد ذلك، يمكن ملء النافذة بعناصر واجهة مستخدم رسومية أخرى لإنشاء نافذة تطبيق. للحصول على معلومات حول كيفية ملء النافذة بعناصر واجهة المستخدم الرسومية، انظر Curses::UI::Container.

الخيارات القياسية

-parent, -x, -y, -width, -height, -pad, -padleft, -padright, -padtop, -padbottom, -ipad, -ipadleft, -ipadright, -ipadtop, -ipadbottom, -title, -titlefullwidth, -titlereverse, -onfocus, -onblur

لشرح هذه الخيارات القياسية، انظر Curses::UI::Widget.

خيارات خاصة بالعنصر الرسومي

•
-centered < BOOLEAN >

يمكن رسم النافذة تلقائيًا في وسط الشاشة. لتمكين هذا الخيار استخدم قيمة صحيحة ولتعطيله استخدم قيمة خاطئة. الافتراضي هو عدم توسيط النافذة. مثال:

$cui->add('mywindow', 'Window', -centered => 1);

الطرق

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )
  • onFocus ( CODEREF )
  • onBlur ( CODEREF )
  • intellidraw ( )

    هذه طرق قياسية. انظر Curses::UI::Widget لشرحها.

  • modalfocus ( )

    إذا تم استدعاء هذه الطريقة، ستحصل النافذة على التركيز (focus) الخاص. هذا يعني أن جميع الأحداث سيتم إرسالها إلى هذه النافذة. عن طريق استدعاء طريقة loose_focus، ستفقد النافذة تركيزها.

  • loose_focus ( )

    ستجعل هذه الطريقة النافذة تفقد تركيزها (باستخدام هذه الطريقة يمكنك أيضًا جعل نافذة ذات تركيز خاص تفقد تركيزها).
