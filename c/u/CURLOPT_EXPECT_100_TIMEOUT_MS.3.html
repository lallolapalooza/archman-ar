CURLOPT_EXPECT_100_TIMEOUT_MS(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_EXPECT_100_TIMEOUT_MS(3) دليل وظائف المكتبة CURLOPT_EXPECT_100_TIMEOUT_MS(3)

الاسم

CURLOPT_EXPECT_100_TIMEOUT_MS - مهلة الاستجابة لـ Expect: 100-continue

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_EXPECT_100_TIMEOUT_MS,
                          long milliseconds);

الوصف

مرر قيمة long لتحديد عدد المللي ثانية التي ستنتظرها مكتبة libcurl للحصول على استجابة من الخادم مع رمز الحالة HTTP 100 (Continue)، 417 (Expectation Failed) أو ما شابه ذلك، بعد إرسال طلب HTTP يحتوي على رأس Expect: 100-continue. إذا انتهت هذه المهلة قبل استلام استجابة، فسيتم إرسال نص الطلب على أي حال.

الافتراضي

1000 مللي ثانية

البروتوكولات

تؤثر هذه الوظيفة على HTTP فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* انتظر 3 ثوانٍ لـ 100-continue */
    curl_easy_setopt(curl, CURLOPT_EXPECT_100_TIMEOUT_MS, 3000L);
    curl_easy_perform(curl);
  }
}

التوفر

تمت الإضافة في curl 7.36.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، بينما تشير القيمة غير الصفرية إلى حدوث خطأ، انظر libcurl-errors(3).
