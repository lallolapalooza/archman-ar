CURLINFO_NUM_CONNECTS(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_NUM_CONNECTS(3) دليل وظائف المكتبة CURLINFO_NUM_CONNECTS(3)

الاسم

CURLINFO_NUM_CONNECTS - الحصول على عدد الاتصالات المنشأة

الملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_NUM_CONNECTS, long *nump);

الوصف

قم بتمرير مؤشر إلى عدد صحيح طويل لاستلام عدد الاتصالات الجديدة التي اضطرت مكتبة curl لإنشائها لتحقيق النقل السابق (يتم حساب الاتصالات الناجحة فقط). بالاقتران مع CURLINFO_REDIRECT_COUNT(3)، يمكنك معرفة عدد المرات التي أعادت فيها مكتبة curl استخدام الاتصالات الحالية بنجاح أم لا. راجع خيارات الاتصال في curl_easy_setopt(3) لمعرفة كيف تحاول مكتبة curl إجراء اتصالات دائمة لتوفير الوقت.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      long connects;
      res = curl_easy_getinfo(curl, CURLINFO_NUM_CONNECTS, &connects);
      if(!res)
        printf("It needed %ld connects\n", connects);
    }
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت إضافته في curl 7.12.3

قيمة الإرجاع

curl_easy_getinfo(3) تُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تعني حدوث خطأ، راجع libcurl-errors(3).
