curl_easy_nextheader(3)

الحزمة: curl

التراخيص: MIT

curl_easy_nextheader(3) دليل الوظائف المكتبية curl_easy_nextheader(3)

الاسم

curl_easy_nextheader - الحصول على ترويسة HTTP التالية

ملخص

#include <curl/curl.h>
struct curl_header *curl_easy_nextheader(CURL *easy,
                                         unsigned int origin,
                                         int request,
                                         struct curl_header *prev);

الوصف

تتيح هذه الوظيفة للتطبيق المرور على جميع ترويسات HTTP التي تم استلامها مسبقًا.

وسيط origin مخصص لتحديد الترويسات التي سيتم استلامها، حيث قد توفر عملية نقل HTTP واحدة ترويسات من أماكن مختلفة، وقد يكون لها أهمية مختلفة للمستخدم، وقد يتم استخدام ترويسات بنفس الاسم. origin هو قناع بت لمصادر الترويسات التي تريدها. انظر دليل curl_easy_header(3) للحصول على أوصاف المصدر.

وسيط request يخبر libcurl من أي طلب تريد الترويسات. قد تتكون عملية نقل واحدة من سلسلة من طلبات HTTP، ويسمح لك هذا الوسيط بتحديد الطلب الفردي الذي تريد الترويسات منه. 0 هو الطلب الأول ثم يزداد الرقم لعمليات إعادة التوجيه اللاحقة أو عند استخدام المصادقة متعددة الحالات. تمرير -1 هو اختصار لـ "الأخير" في السلسلة، بغض النظر عن العدد الفعلي للطلبات المستخدمة.

يُقترح تمرير نفس origin و request عند المرور على نطاق من الترويسات، حيث قد يؤدي تغيير القيمة أثناء التكرار إلى نتائج غير متوقعة.

إذا كان prev هو NULL، فإن هذه الوظيفة تُرجع مؤشرًا إلى أول ترويسة مخزنة ضمن النطاق المحدد (المصدر + الطلب).

إذا كان prev مؤشرًا إلى هيكل ترويسة تم إرجاعه سابقًا، فإن curl_easy_nextheader(3) تُرجع مؤشرًا إلى الترويسة التالية المخزنة ضمن النطاق المحدد. بهذه الطريقة، يمكن للتطبيق المرور على جميع الترويسات المتاحة.

الذاكرة الخاصة بالهيكل الذي يشير إليه هذا، مملوكة وتدار بواسطة libcurl وهي مرتبطة بالمقبض السهل. يجب على التطبيقات نسخ البيانات إذا كانت تريدها أن تظل موجودة بعد استدعاءات API اللاحقة أو طوال عمر المقبض السهل.

بروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  struct curl_header *prev = NULL;
  struct curl_header *h;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    /* استخراج الترويسات العادية من الطلب الأول */
    while((h = curl_easy_nextheader(curl, CURLH_HEADER, 0, prev))) {
      printf("%s: %s\n", h->name, h->value);
      prev = h;
    }
    /* استخراج الترويسات العادية + 1xx + ترويسات الذيل من الطلب الأخير */
    unsigned int origin = CURLH_HEADER| CURLH_1XX | CURLH_TRAILER;
    while((h = curl_easy_nextheader(curl, origin, -1, prev))) {
      printf("%s: %s\n", h->name, h->value);
      prev = h;
    }
  }
}

التوفر

تمت الإضافة في curl 7.83.0

قيمة الإرجاع

ترجع هذه الوظيفة الترويسة التالية، أو NULL عندما لا تكون هناك ترويسات أخرى (مطابقة) أو حدث خطأ.

إذا أرجعت هذه الوظيفة NULL عندما تم تعيين prev إلى NULL، فلا توجد ترويسات متاحة ضمن النطاق لإرجاعها.
