CURLOPT_CHUNK_END_FUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_CHUNK_END_FUNCTION(3) دليل وظائف المكتبة CURLOPT_CHUNK_END_FUNCTION(3)

اسم

CURLOPT_CHUNK_END_FUNCTION - وظيفة استدعاء بعد نقل مطابق للنمط البري FTP

ملخص

#include <curl/curl.h>
long chunk_end_callback(void *ptr);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CHUNK_END_FUNCTION,
                          chunk_end_callback);

الوصف

قم بتمرير مؤشر إلى وظيفتك الاستدعائية، والتي يجب أن تتطابق مع النموذج الأولي الموضح أعلاه.

يتم استدعاء هذه الوظيفة بواسطة libcurl فور نقل جزء من التدفق (أو تخطيه).

إرجاع CURL_CHUNK_END_FUNC_OK إذا كان كل شيء على ما يرام أو CURL_CHUNK_END_FUNC_FAIL لإخبار المكتبة بالتوقف إذا حدث خطأ.

افتراضي

NULL

بروتوكولات

تؤثر هذه الوظيفة على FTP فقط

مثال

#include <stdio.h>
struct callback_data {
   FILE *output;
};
static long file_is_downloaded(void *ptr)
{
  struct callback_data *data = ptr;
  if(data->output) {
    fclose(data->output);
    data->output = 0x0;
  }
  return CURL_CHUNK_END_FUNC_OK;
}
int main()
{
  /* بيانات للاستدعاء */
  struct callback_data callback_info;
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_CHUNK_END_FUNCTION, file_is_downloaded);
  curl_easy_setopt(curl, CURLOPT_CHUNK_DATA, &callback_info);
}

التوفر

تمت إضافتها في curl 7.21.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
