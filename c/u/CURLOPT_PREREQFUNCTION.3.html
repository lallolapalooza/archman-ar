CURLOPT_PREREQFUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PREREQFUNCTION(3) دليل وظائف المكتبة CURLOPT_PREREQFUNCTION(3)

الاسم

CURLOPT_PREREQFUNCTION - دالة استدعاء مخصصة يتم استدعاؤها عند إنشاء اتصال، ولكن قبل إرسال طلب.

الملخص

#include <curl/curl.h>
/* هذه هي رموز الإرجاع لدالة الاستدعاء قبل الطلب. */
#define CURL_PREREQFUNC_OK 0
#define CURL_PREREQFUNC_ABORT 1 /* فشل النقل بالكامل */
int prereq_callback(void *clientp,
                    char *conn_primary_ip,
                    char *conn_local_ip,
                    int conn_primary_port,
                    int conn_local_port);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PREREQFUNCTION, prereq_callback);

الوصف

مرر مؤشرًا إلى دالة الاستدعاء الخاصة بك، والتي يجب أن تتطابق مع النموذج الأولي الموضح أعلاه.

يتم استدعاء هذه الدالة بواسطة libcurl بعد إنشاء اتصال أو إعادة استخدام اتصال (بما في ذلك أي مصافحة SSL)، ولكن قبل إرسال أي طلب فعلي على الاتصال. على سبيل المثال، بالنسبة لـ HTTP، يتم استدعاء دالة الاستدعاء هذه بمجرد إنشاء اتصال بالخادم، ولكن قبل إرسال طلب GET/HEAD/POST/إلخ.

قد يتم استدعاء هذه الدالة عدة مرات إذا تم تمكين عمليات إعادة التوجيه ويتم اتباعها (راجع CURLOPT_FOLLOWLOCATION(3)).

يجب أن تُرجع دالة الاستدعاء CURL_PREREQFUNC_OK عند النجاح، أو CURL_PREREQFUNC_ABORT للتسبب في فشل النقل مع النتيجة CURLE_ABORTED_BY_CALLBACK.

يتم تمرير الوسائط التالية إلى هذه الدالة:

conn_primary_ip
مؤشر إلى سلسلة C منتهية بصفر تحتوي على عنوان IP الأساسي للخادم البعيد الذي تم إنشاؤه بهذا الاتصال. بالنسبة لـ FTP، هذا هو عنوان IP لاتصال التحكم. يتم تمثيل عناوين IPv6 بدون أقواس محيطة.
conn_local_ip
مؤشر إلى سلسلة C منتهية بصفر تحتوي على عنوان IP الأصلي لهذا الاتصال. يتم تمثيل عناوين IPv6 بدون أقواس محيطة.
conn_primary_port
رقم المنفذ الأساسي على الخادم البعيد الذي تم إنشاؤه بهذا الاتصال. بالنسبة لـ FTP، هذا هو منفذ اتصال التحكم. يمكن أن يكون هذا رقم منفذ TCP أو UDP حسب البروتوكول.
conn_local_port
رقم المنفذ الأصلي لهذا الاتصال. يمكن أن يكون هذا رقم منفذ TCP أو UDP حسب البروتوكول.
clientp
المؤشر الذي قمت بتعيينه باستخدام CURLOPT_PREREQDATA(3).

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct priv {
  void *custom;
};
static int prereq_callback(void *clientp,
                           char *conn_primary_ip,
                           char *conn_local_ip,
                           int conn_primary_port,
                           int conn_local_port)
{
  printf("تم إجراء الاتصال بـ %s:%d\n", conn_primary_ip, conn_primary_port);
  return CURL_PREREQFUNC_OK;
}
int main(void)
{
  struct priv prereq_data;
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_PREREQFUNCTION, prereq_callback);
    curl_easy_setopt(curl, CURLOPT_PREREQDATA, &prereq_data);
    curl_easy_perform(curl);
  }
}

التوفر

تمت الإضافة في curl 7.80.0

قيمة الإرجاع

curl_easy_setopt(3) تُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، راجع libcurl-errors(3).
