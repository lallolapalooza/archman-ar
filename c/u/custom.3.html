custom(3)

الحزمة: libmtp

التراخيص: LGPL-2.1-or-later

custom(3) دليل وظائف المكتبة custom(3)

الاسم

custom - واجهة برمجة تطبيقات للعمليات المخصصة.

ملخص

الوظائف


int LIBMTP_Custom_Operation (LIBMTP_mtpdevice_t *, uint16_t, int,...)

وصف تفصيلي

توثيق الوظائف

int LIBMTP_Custom_Operation (LIBMTP_mtpdevice_t * device, uint16_t code, int n_param, ...)

إصدار عملية مخصصة (مثل عملية خاصة بالبائع) (بدون مرحلة بيانات)

المعاملات

device مؤشر إلى الجهاز لإرسال العملية المخصصة إليه.
code رمز العملية المراد إرساله.
n_param عدد المعاملات التي تم تمريرها.
... معاملات خاصة بالعملية من نوع uint32_t.

المراجع LIBMTP_mtpdevice_struct::params.

المؤلف

تم إنشاؤه تلقائيًا بواسطة Doxygen لمكتبة libmtp من الكود المصدري.
