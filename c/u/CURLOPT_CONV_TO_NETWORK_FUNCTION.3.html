CURLOPT_CONV_TO_NETWORK_FUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_CONV_TO_NETWORK_FUNCTION(3) دليل وظائف المكتبة CURLOPT_CONV_TO_NETWORK_FUNCTION(3)

الاسم

CURLOPT_CONV_TO_NETWORK_FUNCTION - تحويل البيانات إلى شبكة من ترميز المضيف

الملخص

#include <curl/curl.h>
CURLcode conv_callback(char *ptr, size_t length);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CONV_TO_NETWORK_FUNCTION,
                          conv_callback);

الوصف

مرر مؤشرًا إلى دالة الاستدعاء الخاصة بك، والتي يجب أن تطابق النموذج الأولي الموضح أعلاه.

ينطبق على المنصات غير ASCII. curl_version_info(3) تعيد البتة الميزة CURL_VERSION_CONV تم تعيينها إذا تم توفير هذا الخيار.

البيانات التي سيتم تحويلها موجودة في مخزن مؤقت يشير إليه المعامل ptr. يشير مقدار البيانات التي سيتم تحويلها بواسطة المعامل length. تتداخل البيانات المحولة مع بيانات الإدخال في المخزن المؤقت الذي يشير إليه المعامل ptr. يجب إرجاع CURLE_OK عند نجاح التحويل. يجب إرجاع قيمة CURLcode محددة بواسطة curl.h، مثل CURLE_CONV_FAILED، إذا تم اكتشاف خطأ.

CURLOPT_CONV_TO_NETWORK_FUNCTION(3) يحول من ترميز المضيف إلى ترميز الشبكة. يستخدم عند إرسال الأوامر أو بيانات ASCII عبر الشبكة.

إذا قمت بتعيين مؤشر استدعاء إلى NULL، أو لم تقم بتعيينه على الإطلاق، فستتم استخدام وظائف iconv المضمنة في libcurl. إذا لم يتم تعريف HAVE_ICONV عند بناء libcurl، ولم يتم تعيين استدعاء، فإن التحويل يعيد رمز الخطأ CURLE_CONV_REQD.

إذا تم تعريف HAVE_ICONV، فيجب أيضًا تعريف CURL_ICONV_CODESET_OF_HOST. على سبيل المثال:

define CURL_ICONV_CODESET_OF_HOST "IBM-1047"

تعين أيقونة iconv في libcurl أسماء مجموعات رموز الشبكة و UTF8 افتراضيًا على النحو التالي:

#define CURL_ICONV_CODESET_OF_NETWORK "ISO8859-1"
#define CURL_ICONV_CODESET_FOR_UTF8   "UTF-8"

تحتاج إلى تجاوز هذه التعريفات إذا كانت مختلفة على نظامك.

افتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

static CURLcode my_conv_from_ebcdic_to_ascii(char *buffer, size_t length)
{
  int rc = 0;
  /* تحويل في المكان 'buffer' من EBCDIC إلى ASCII */
  if(rc == 0) {
    /* نجاح */
    return CURLE_OK;
  }
  else {
    return CURLE_CONV_FAILED;
  }
}
int main(void)
{
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_CONV_TO_NETWORK_FUNCTION,
                   my_conv_from_ebcdic_to_ascii);
}

مهمل

غير متاح ومهمل منذ 7.82.0.

متاح فقط إذا تم تعريف CURL_DOES_CONVERSIONS عند بناء libcurl.

التوفر

تمت الإضافة في curl 7.15.4

قيمة الإرجاع

curl_easy_setopt(3) يعيد CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، راجع libcurl-errors(3).
