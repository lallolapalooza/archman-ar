توثيق الوظيفة/الإجراء الفرعي

subroutine cunbdb4 (integer m, integer p, integer q, complex, dimension(ldx11,*) x11, integer ldx11, complex, dimension(ldx21,*) x21, integer ldx21, real, dimension(*) theta, real, dimension(*) phi, complex, dimension(*) taup1, complex, dimension(*) taup2, complex, dimension(*) tauq1, complex, dimension(*) phantom, complex, dimension(*) work, integer lwork, integer info)

CUNBDB4

الغرض:

!>
!> CUNBDB4 تقوم بإجراء تخفيض ثنائي متزامن للمصفوفات المدمجة في مصفوفة X طويلة ونحيلة بأعمدة متعامدة:
!>
!>                            [ B11 ]
!>      [ X11 ]   [ P1 |    ] [  0  ]
!>      [-----] = [---------] [-----] Q1**T .
!>      [ X21 ]   [    | P2 ] [ B21 ]
!>                            [  0  ]
!>
!> X11 هي P-by-Q، و X21 هي (M-P)-by-Q. يجب أن يكون M-Q أصغر من أو يساوي P،
!> M-P، أو Q. الإجراءات الفرعية CUNBDB1، CUNBDB2، و CUNBDB3 تتعامل مع الحالات التي
!> يكون فيها M-Q ليس الحد الأدنى.
!>
!> P1، P2، و Q1 هي مصفوفات وحدوية P-by-P، (M-P)-by-(M-P)،
!> و (M-Q)-by-(M-Q)، على التوالي. يتم تمثيلها ضمنيًا بواسطة
!> متجهات هاوسهولدر.
!>
!> B11 و B12 هي مصفوفات ثنائية القطر (M-Q)-by-(M-Q) ممثلة
!> ضمنيًا بالزوايا THETA، PHI.
!>
!>

المعلمات

M 
!>          M is INTEGER
!>           عدد الصفوف في X11 زائد عدد الصفوف في X21.
!>

P

!>          P is INTEGER
!>           عدد الصفوف في X11. 0 <= P <= M.
!>

Q

!>          Q is INTEGER
!>           عدد الأعمدة في X11 و X21. 0 <= Q <= M و
!>           M-Q <= min(P,M-P,Q).
!>

X11

!>          X11 is COMPLEX array, dimension (LDX11,Q)
!>           عند الإدخال، الكتلة العلوية للمصفوفة X المراد تخفيضها. عند
!>           الخروج، أعمدة tril(X11) تحدد المنعكسات لـ P1
!>           وصفوف triu(X11,1) تحدد المنعكسات لـ Q1.
!>

LDX11

!>          LDX11 is INTEGER
!>           البعد الرائد لـ X11. LDX11 >= P.
!>

X21

!>          X21 is COMPLEX array, dimension (LDX21,Q)
!>           عند الإدخال، الكتلة السفلية للمصفوفة X المراد تخفيضها. عند
!>           الخروج، أعمدة tril(X21) تحدد المنعكسات لـ P2.
!>

LDX21

!>          LDX21 is INTEGER
!>           البعد الرائد لـ X21. LDX21 >= M-P.
!>

THETA

!>          THETA is REAL array, dimension (Q)
!>           تُعرّف مدخلات الكتل الثنائية القطر B11، B21 بواسطة
!>           THETA و PHI. انظر التفاصيل الإضافية.
!>

PHI

!>          PHI is REAL array, dimension (Q-1)
!>           تُعرّف مدخلات الكتل الثنائية القطر B11، B21 بواسطة
!>           THETA و PHI. انظر التفاصيل الإضافية.
!>

TAUP1

!>          TAUP1 is COMPLEX array, dimension (M-Q)
!>           العوامل القياسية للمنعكسات الأولية التي تحدد
!>           P1.
!>

TAUP2

!>          TAUP2 is COMPLEX array, dimension (M-Q)
!>           العوامل القياسية للمنعكسات الأولية التي تحدد
!>           P2.
!>

TAUQ1

!>          TAUQ1 is COMPLEX array, dimension (Q)
!>           العوامل القياسية للمنعكسات الأولية التي تحدد
!>           Q1.
!>

PHANTOM

!>          PHANTOM is COMPLEX array, dimension (M)
!>           يقوم الإجراء بحساب متجه عمودي Y بحجم M-by-1
!>           متعامد مع أعمدة [ X11; X21 ]. تحتوي PHANTOM(1:P) و
!>           PHANTOM(P+1:M) على متجهات هاوسهولدر لـ Y(1:P) و
!>           Y(P+1:M) على التوالي.
!>

WORK

!>          WORK is COMPLEX array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>           بعد المصفوفة WORK. LWORK >= M-Q.
!>
!>           إذا كان LWORK = -1، يتم افتراض استعلام مساحة العمل؛ يقوم الإجراء
!>           فقط بحساب الحجم الأمثل للمصفوفة WORK، ويعيد
!>           هذه القيمة كإدخال أول للمصفوفة WORK، ولا يتم إصدار أي رسالة خطأ
!>           متعلقة بـ LWORK بواسطة XERBLA.
!>

INFO

!>          INFO is INTEGER
!>           = 0:  انتهاء ناجح.
!>           < 0:  إذا كان INFO = -i، فإن المعلمة i كان لها قيمة غير قانونية.
!>

التفاصيل الإضافية:

!>
!>  يتم تمثيل الكتل الثنائية القطر العليا B11، B21 ضمنيًا بواسطة
!>  الزوايا THETA(1)، ..., THETA(Q) و PHI(1)، ..., PHI(Q-1). كل مدخل
!>  في كل نطاق ثنائي القطر هو حاصل ضرب جيب أو جيب تمام لـ THETA
!>  مع جيب أو جيب تمام لـ PHI. انظر [1] أو CUNCSD للتفاصيل.
!>
!>  يتم تمثيل P1، P2، و Q1 كحواصل ضرب لمنعكسات أولية.
!>  انظر CUNCSD2BY1 للتفاصيل حول توليد P1، P2، و Q1 باستخدام CUNGQR
!>  و CUNGLQ.
!>

المراجع:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
