CURLOPT_TIMECONDITION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_TIMECONDITION(3) دليل الوظائف المكتبية CURLOPT_TIMECONDITION(3)

الاسم

CURLOPT_TIMECONDITION - تحديد شرط لطلب الوقت

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TIMECONDITION, long cond);

الوصف

مرر قيمة طويلة (long) كمعامل. هذا يحدد كيف يتم التعامل مع قيمة الوقت في CURLOPT_TIMEVALUE(3). يمكنك تعيين هذا المعامل إلى CURL_TIMECOND_IFMODSINCE أو CURL_TIMECOND_IFUNMODSINCE.

وقت آخر تعديل للملف ليس معروفًا دائمًا، وفي هذه الحالات لا يكون لهذه الميزة أي تأثير حتى لو لم يتحقق شرط الوقت المحدد. يمكن استخدام curl_easy_getinfo(3) مع الخيار CURLINFO_CONDITION_UNMET بعد نقل البيانات لمعرفة ما إذا كان نقل ناجح بحجم صفر يرجع إلى عدم تطابق هذا الشرط.

الافتراضي

CURL_TIMECOND_NONE (0)

البروتوكولات

تؤثر هذه الوظيفة على الملفات (file) و FTP و HTTP

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* 1 يناير 2020 هو 1577833200 */
    curl_easy_setopt(curl, CURLOPT_TIMEVALUE, 1577833200L);
    /* If-Modified-Since الطابع الزمني أعلاه */
    curl_easy_setopt(curl, CURLOPT_TIMECONDITION, CURL_TIMECOND_IFMODSINCE);
    /* تنفيذ الطلب */
    curl_easy_perform(curl);
  }
}

التاريخ

أصبحت تعدادات CURL_TIMECOND_* من نوع long في الإصدار 8.13.0، قبل هذا الإصدار كان تحويل النوع إلى long ضروريًا عند تمريره إلى curl_easy_setopt(3).
