CURLOPT_INTERFACE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_INTERFACE(3) دليل وظائف المكتبة CURLOPT_INTERFACE(3)

الاسم

CURLOPT_INTERFACE - واجهة المصدر لحركة المرور الصادرة

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INTERFACE, char *interface);

الوصف

قم بتمرير مؤشر حرف كمعامل. هذا يحدد اسم الواجهة المستخدمة كواجهة شبكة صادرة. يمكن أن يكون الاسم اسم واجهة، أو عنوان IP، أو اسم مضيف. إذا كنت تفضل أحد هؤلاء، يمكنك استخدام البادئات الخاصة التالية:

* if!<name> - اسم الواجهة * host!<name> - عنوان IP أو اسم مضيف * ifhost!<interface>!<host> - اسم الواجهة وعنوان IP أو اسم المضيف

إذا تم تحديد if! أو ifhost! ولكن المعامل لم يتطابق مع واجهة موجودة، يتم إرجاع CURLE_INTERFACE_FAILED من وظيفة libcurl المستخدمة لتنفيذ النقل.

لا تدعم libcurl استخدام أسماء واجهات الشبكة لهذا الخيار على نظام التشغيل Windows.

ننصح بشدة بعدم تحديد الواجهة باسم مضيف، لأن ذلك يتسبب في قيام libcurl بإجراء استدعاء اسم حظر لاسترداد عنوان IP. لا تستخدم عملية حل الاسم هذه CURLOPT_DOH_URL(3) حتى لو تم تعيين CURLOPT_DOH_URL(3).

لا يتعين على التطبيق الاحتفاظ بالسلسلة النصية بعد تعيين هذا الخيار.

يجعل استخدام هذا الخيار عدة مرات السلسلة النصية الأخيرة المعينة تتجاوز السلاسل السابقة. قم بتعيينها على NULL لتعطيل استخدامها مرة أخرى.

الافتراضي

NULL، استخدم ما تجده مكدس TCP مناسبًا

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_INTERFACE, "eth0");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التاريخ

تمت إضافة بناء الجملة if! و host! في الإصدار 7.24.0.

تمت إضافة بناء الجملة ifhost! في الإصدار 8.9.0.

التوفر

تمت إضافته في curl 7.3

قيمة الإرجاع

curl_easy_setopt(3) ترجع CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، راجع libcurl-errors(3).
