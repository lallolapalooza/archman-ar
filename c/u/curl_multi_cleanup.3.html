curl_multi_cleanup(3)

الحزمة: curl

التراخيص: MIT

curl_multi_cleanup(3) دليل الدوال المكتبية curl_multi_cleanup(3)

الاسم

curl_multi_cleanup - إغلاق جلسة متعددة

ملخص

#include <curl/curl.h>
CURLMcode curl_multi_cleanup(CURLM *multi_handle);

الوصف

هذه الدالة هي عكس curl_multi_init(3). تقوم بتنظيف وإزالة مكدس متعدد بالكامل. لا تقوم بتحرير أو المساس بأي مقابض سهلة فردية بأي شكل من الأشكال - لا يزال يتعين إغلاقها بشكل فردي، باستخدام الطريقة المعتادة لـ curl_easy_cleanup(3). يجب أن يكون ترتيب التنظيف كالتالي:

1 - curl_multi_remove_handle(3) قبل تنظيف أي مقابض سهلة

2 - يمكن الآن استدعاء curl_easy_cleanup(3) بشكل مستقل نظرًا لأن المقبض السهل لم يعد متصلاً بالمقبض المتعدد

3 - يجب استدعاء curl_multi_cleanup(3) عندما تتم إزالة جميع المقابض السهلة

عند استدعاء هذه الدالة، يتم إغلاق الإدخالات المتبقية في مجمع الاتصالات الذي يحتفظ به المقبض المتعدد، مما قد يؤدي إلى استدعاء دالة رد الاتصال CURLMOPT_SOCKETFUNCTION(3).

تمرير مؤشر NULL في multi_handle يجعل هذه الدالة ترجع CURLM_BAD_HANDLE فورًا دون أي إجراء آخر.

أي استخدام لـ multi_handle بعد استدعاء هذه الدالة وعودتها، يعتبر غير قانوني.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURLM *multi = curl_multi_init();
  /* عندما ينتهي النقل المتعدد ... */
  /* قم بإزالة جميع المقابض السهلة، ثم: */
  curl_multi_cleanup(multi);
}

التوفر

تمت الإضافة في curl 7.9.6

قيمة الإرجاع

ترجع هذه الدالة قيمة CURLMcode تشير إلى النجاح أو الخطأ.
