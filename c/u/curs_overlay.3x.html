curs_overlay(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_overlay(3x) استدعاءات المكتبة curs_overlay(3x)

الاسم

overlay, overwrite, copywin - تراكب نوافذ curses والتعامل معها

ملخص

#include <curses.h>
int overlay(const WINDOW *srcwin, WINDOW *dstwin);
int overwrite(const WINDOW *srcwin, WINDOW *dstwin);
int copywin(const WINDOW *srcwin, WINDOW *dstwin, int sminrow,
      int smincol, int dminrow, int dmincol, int dmaxrow,
      int dmaxcol, int overlay);

الوصف

overlay, overwrite

تقوم الإجراءات overlay و overwrite بتراكب srcwin فوق dstwin. لا يُشترط أن يكون scrwin و dstwin بنفس الحجم؛ يتم نسخ النص فقط حيث تتداخل النافذتان. الفرق هو أن overlay غير مدمرة (لا يتم نسخ المساحات الفارغة) بينما overwrite مدمرة.

copywin

توفر الإجراء copywin تحكمًا أدق في الإجراءات overlay و overwrite. كما هو الحال في الإجراء prefresh، يتم تحديد مستطيل في النافذة الوجهة (dminrow, dmincol) و (dmaxrow, dmaxcol)، وإحداثيات الزاوية العلوية اليسرى للنافذة المصدر (sminrow, smincol). إذا كان الوسيط overlay صحيحًا true، فإن النسخ غير مدمرة، كما في overlay.

قيمة الإرجاع

تعيد هذه الإجراءات القيمة الصحيحة ERR عند الفشل، و OK (يحدد SVr4 فقط "قيمة صحيحة بخلاف ERR") عند اكتمالها بنجاح.

لا تحدد X/Open أي شروط خطأ. في هذا التنفيذ، تعيد copywin و overlay و overwrite خطأ إذا كان أي من مؤشرات النافذة فارغة، أو إذا تم وضع جزء من النافذة خارج الشاشة.

ملاحظات

لاحظ أن overlay و overwrite قد تكونا وحدات ماكرو.

قابلية النقل

تم وصف هذه الوظائف في X/Open Curses، الإصدار 4، والذي يضيف مؤهلات const إلى الوسائط. كما أنه يحدد سلوكها في وجود أحرف ذات تمثيلات متعددة البايت (لم يتم دعمها بعد في هذا التنفيذ).
