CURLMOPT_TIMERFUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLMOPT_TIMERFUNCTION(3) دليل الوظائف المكتبية CURLMOPT_TIMERFUNCTION(3)

الاسم

CURLMOPT_TIMERFUNCTION - استدعاء لاستقبال قيم المهلة

ملخص

#include <curl/curl.h>
int timer_callback(CURLM *multi,    /* مقبض متعدد */
                   long timeout_ms, /* المهلة بالمللي ثانية */
                   void *clientp);  /* مؤشر استدعاء خاص */
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_TIMERFUNCTION, timer_callback);

الوصف

مرر مؤشرًا إلى دالة الاستدعاء الخاصة بك، والتي يجب أن تتطابق مع النموذج الأولي الموضح أعلاه.

تتطلب بعض الميزات، مثل المهلات وإعادة المحاولة، منك استدعاء libcurl حتى عندما لا يكون هناك نشاط على واجهات الملفات.

يجب على دالة الاستدعاء الخاصة بك timer_callback تثبيت مؤقت واحد غير متكرر بانتهاء وقت قدره timeout_ms مللي ثانية. عند انتهاء هذا المؤقت، قم باستدعاء إما curl_multi_socket_action(3) أو curl_multi_perform(3)، اعتمادًا على الواجهة التي تستخدمها.

إذا تم استدعاء دالة الاستدعاء هذه عندما يكون مؤقت قيد التشغيل بالفعل، فإن وقت الانتهاء الجديد هذا يحل محل المهلة السابقة. يجب على التطبيق بعد ذلك إلغاء المهلة القديمة فعليًا وتعيين مهلة جديدة باستخدام وقت الانتهاء الجديد هذا.

القيمة timeout_ms البالغة -1 التي تم تمريرها إلى دالة الاستدعاء هذه تعني أنه يجب عليك حذف المؤقت. جميع القيم الأخرى هي أوقات انتهاء صالحة بالمللي ثانية - بما في ذلك صفر مللي ثانية.

يتم استدعاء دالة الاستدعاء timer_callback عند تغيير وقت انتهاء المهلة.

يتم تعيين المؤشر clientp باستخدام CURLMOPT_TIMERDATA(3).

يجب أن تعيد دالة استدعاء المؤقت 0 عند النجاح، و -1 عند الخطأ. إذا أعادت دالة الاستدعاء هذه خطأ، يتم إلغاء جميع عمليات النقل قيد التنفيذ حاليًا في هذا المقبض المتعدد وفشلها.

يمكن استخدام دالة الاستدعاء هذه بدلاً من، أو بالإضافة إلى، curl_multi_timeout(3).

تحذير: لا تستدعِ libcurl مباشرة من داخل دالة الاستدعاء نفسها عندما تكون قيمة timeout_ms صفرًا، لأن ذلك يخاطر بتشغيل سلوك متكرر مزعج يستدعي فورًا استدعاءً آخر لدالة الاستدعاء بمهلة صفرية...

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct priv {
  void *custom;
};
static int timerfunc(CURLM *multi, long timeout_ms, void *clientp)
{
  struct priv *mydata = clientp;
  printf("our ptr: %p\n", mydata->custom);
  if(timeout_ms >= 0) {
    /* this is the new single timeout to wait for, including zero */
  }
  else {
    /* delete the timeout, nothing to wait for now */
  }
  return 0;
}
int main(void)
{
  struct priv mydata;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_TIMERFUNCTION, timerfunc);
  curl_multi_setopt(multi, CURLMOPT_TIMERDATA, &mydata);
}

التوفر

تمت الإضافة في curl 7.16.0

قيمة الإرجاع

curl_multi_setopt(3) تعيد قيمة CURLMcode تشير إلى النجاح أو الخطأ.

CURLM_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
