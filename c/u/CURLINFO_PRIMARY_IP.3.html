CURLINFO_PRIMARY_IP(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_PRIMARY_IP(3) دليل الدوال المكتبية CURLINFO_PRIMARY_IP(3)

الاسم

CURLINFO_PRIMARY_IP - الحصول على عنوان IP للاتصال الأخير

الملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_PRIMARY_IP, char **ip);

الوصف

مرر مؤشرًا إلى مؤشر حرف لاستقبال المؤشر إلى سلسلة نصية منتهية بصفر تحتوي على عنوان IP للاتصال الأخير الذي تم إجراؤه بواسطة مقبض curl هذا. قد تكون هذه السلسلة نصية IPv6 عند تفعيلها. لاحظ أنك تحصل على مؤشر إلى منطقة ذاكرة يتم إعادة استخدامها في الطلب التالي، لذا تحتاج إلى نسخ السلسلة النصية إذا كنت تريد الاحتفاظ بالمعلومات.

المؤشر ip هو NULL أو يشير إلى ذاكرة خاصة. يجب عليك عدم إلغاء تخصيصه. يتم تحرير الذاكرة تلقائيًا عند استدعاء curl_easy_cleanup(3) على مقبض curl المقابل.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  char *ip;
  CURLcode res;
  CURL *curl = curl_easy_init();
  curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
  /* إجراء النقل */
  res = curl_easy_perform(curl);
  /* التحقق من الأخطاء */
  if((res == CURLE_OK) &&
     !curl_easy_getinfo(curl, CURLINFO_PRIMARY_IP, &ip) && ip) {
    printf("IP: %s\n", ip);
  }
  /* التنظيف دائمًا */
  curl_easy_cleanup(curl);
}

التوفر

تمت إضافته في curl 7.19.0

قيمة الإرجاع

curl_easy_getinfo(3) ترجع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
