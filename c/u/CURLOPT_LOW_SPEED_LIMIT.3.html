CURLOPT_LOW_SPEED_LIMIT(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_LOW_SPEED_LIMIT(3) دليل الدوال المكتبية CURLOPT_LOW_SPEED_LIMIT(3)

الاسم

CURLOPT_LOW_SPEED_LIMIT - حد السرعة المنخفضة بالبايت في الثانية

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_LOW_SPEED_LIMIT,
                          long speedlimit);

الوصف

قم بتمرير قيمة طويلة (long) كمعامل. تحتوي على متوسط سرعة النقل بالبايت في الثانية والتي يجب أن تكون أقل منها عملية النقل خلال CURLOPT_LOW_SPEED_TIME(3) ثانية لكي تعتبرها مكتبة libcurl بطيئة للغاية وتقوم بإلغائها.

الافتراضي

0، معطل

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* إلغاء العملية إذا كانت أبطأ من 30 بايت/ثانية خلال 60 ثانية */
    curl_easy_setopt(curl, CURLOPT_LOW_SPEED_TIME, 60L);
    curl_easy_setopt(curl, CURLOPT_LOW_SPEED_LIMIT, 30L);
    res = curl_easy_perform(curl);
    if(CURLE_OPERATION_TIMEDOUT == res) {
      printf("انتهت المهلة.\n");
    }
    /* دائماً قم بالتنظيف */
    curl_easy_cleanup(curl);
  }
}

التوفر

أضيفت في curl 7.1

قيمة الإرجاع

curl_easy_setopt(3) ترجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، أي قيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).
