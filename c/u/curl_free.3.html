curl_free(3)

الحزمة: curl

التراخيص: MIT

curl_free(3) دليل وظائف المكتبة curl_free(3)

الاسم

curl_free - استعادة الذاكرة التي تم الحصول عليها من خلال استدعاء libcurl

الخلاصة

#include <curl/curl.h>
void curl_free(void *ptr);

الوصف

تقوم curl_free(3) باستعادة الذاكرة التي تم الحصول عليها من خلال استدعاء libcurl. استخدم curl_free(3) بدلاً من free() لتجنب الحالات الشاذة التي قد تنجم عن اختلافات في إدارة الذاكرة بين تطبيقك و libcurl.

تمرير مؤشر NULL في ptr يجعل هذه الوظيفة تعود فوراً دون اتخاذ أي إجراء.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  char *width = curl_getenv("COLUMNS");
  if(width) {
    /* تم تعيينها */
    curl_free(width);
  }
}
