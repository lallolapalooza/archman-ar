CURLINFO_CONTENT_LENGTH_DOWNLOAD(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_CONTENT_LENGTH_DOWNLOAD(3) دليل وظائف المكتبة CURLINFO_CONTENT_LENGTH_DOWNLOAD(3)

الاسم

CURLINFO_CONTENT_LENGTH_DOWNLOAD - الحصول على طول المحتوى للتنزيل

ملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONTENT_LENGTH_DOWNLOAD,
                           double *content_length);

الوصف

مرر مؤشرًا إلى قيمة مزدوجة لاستقبال طول المحتوى للتنزيل. هذه هي القيمة المقروءة من حقل Content-Length:. ترجع هذه الوظيفة -1 إذا لم يكن الحجم معروفًا.

CURLINFO_CONTENT_LENGTH_DOWNLOAD_T(3) هو بديل أحدث يرجع نوع متغير أكثر منطقية.

بروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة.

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* قم بإجراء الطلب */
    res = curl_easy_perform(curl);
    if(!res) {
      /* تحقق من الحجم */
      double cl;
      res = curl_easy_getinfo(curl, CURLINFO_CONTENT_LENGTH_DOWNLOAD, &cl);
      if(!res) {
        printf("الحجم: %.0f\n", cl);
      }
    }
  }
}

مهمل

مهمل منذ الإصدار 7.55.0.

التوفر

تمت إضافته في curl 7.6.1.

قيمة الإرجاع

curl_easy_getinfo(3) ترجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء على ما يرام، وقيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).
