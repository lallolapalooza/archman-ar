CURLOPT_RANGE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_RANGE(3) دليل الدوال المكتبية CURLOPT_RANGE(3)

الاسم

CURLOPT_RANGE - نطاق بايت المطلوب

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RANGE, char *range);

الوصف

مرر مؤشر حرف كمعامل، والذي يجب أن يحتوي على النطاق المحدد الذي تريد استرداده. يجب أن يكون بالصيغة "X-Y"، حيث يمكن ترك X أو Y فارغين و X و Y هما فهارس البايت.

تنقل HTTP تدعم أيضًا نطاقات متعددة، مفصولة بفواصل كما في "X-Y,N-M". استخدام هذه النوعية من النطاقات المتعددة يؤدي إلى إرسال الخادم HTTP لوثيقة الاستجابة على شكل أجزاء (باستخدام تقنيات فصل MIME القياسية) كاستجابة متعددة الأجزاء يعيدها libcurl كما هي. تحتوي على معلومات وصفية إضافية إلى جانب البايتات المطلوبة. تحليل أو تحويل هذه الاستجابة مسؤولية المتصل.

للأسف، يسمح معيار HTTP (RFC 7233 القسم 3.1) للخوادم بتجاهل طلبات النطاق، لذا حتى عند تعيين CURLOPT_RANGE(3) لطلب، قد ينتهي بك الأمر باستلام الاستجابة الكاملة.

بالنسبة لـ RTSP، يجب أن يتبع تنسيق النطاق RFC 2326 القسم 12.29. بالنسبة لـ RTSP، لا يُسمح بنطاقات البايت. بدلاً من ذلك، يجب إعطاء النطاقات بتنسيقات npt أو utc أو smpte.

بالنسبة لعمليات رفع HTTP PUT، لا ينبغي استخدام هذا الخيار، حيث قد يتعارض مع خيارات أخرى.

استخدام هذا الخيار عدة مرات يجعل السلسلة الأخيرة المضبوطة تتجاوز السابقات. اضبطها على NULL لتعطيل استخدامها مرة أخرى.

لا يحتاج التطبيق إلى الاحتفاظ بالسلسلة بعد تعيين هذا الخيار.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على الملفات، ftp، http، rtsp و sftp

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* الحصول على أول 200 بايت */
    curl_easy_setopt(curl, CURLOPT_RANGE, "0-199");
    /* تنفيذ الطلب */
    curl_easy_perform(curl);
  }
}

التاريخ

FILE منذ 7.18.0، RTSP منذ 7.20.0

التوفر

تمت الإضافة في curl 7.1

قيمة الإرجاع

curl_easy_setopt(3) يعيد CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).

انظر أيضًا

CURLOPT_LOW_SPEED_LIMIT(3)، CURLOPT_MAXFILESIZE_LARGE(3)، CURLOPT_MAX_RECV_SPEED_LARGE(3)، CURLOPT_RESUME_FROM(3)
