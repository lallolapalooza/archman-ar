CURLOPT_CAPATH(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_CAPATH(3) دليل الدوال المكتبية CURLOPT_CAPATH(3)

اسم

CURLOPT_CAPATH - دليل يحتوي على شهادات CA

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_CAPATH, char *capath);

الوصف

مرر مؤشر حرف إلى سلسلة نصية منتهية بـ NULL تحدد دليلاً يحتوي على شهادات CA متعددة للتحقق من الند. إذا تم بناء libcurl مع OpenSSL، فيجب أن يكون دليل الشهادات معدًا باستخدام أداة c_rehash الخاصة بـ OpenSSL. هذا له معنى فقط عند استخدامه بالاقتران مع الخيار CURLOPT_SSL_VERIFYPEER(3).

يبدو أن الدالة CURLOPT_CAPATH(3) لا تعمل في نظام Windows بسبب بعض القيود في OpenSSL.

لا يحتاج التطبيق إلى الاحتفاظ بالسلسلة النصية بعد تعيين هذا الخيار.

استخدام هذا الخيار عدة مرات يجعل السلسلة الأخيرة المعينة تتجاوز السابقات. قم بتعيينها إلى NULL لتعطيل استخدامها مرة أخرى.

يمكن معرفة القيمة الافتراضية لهذا باستخدام CURLINFO_CAPATH(3).

الافتراضي

مسار تم اكتشافه وقت البناء.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المستندة إلى TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية لـ TLS التالية: GnuTLS، OpenSSL، mbedTLS و wolfSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_CAPATH, "/etc/cert-dir");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.9.8

CURLE_OUT_OF_MEMORY
