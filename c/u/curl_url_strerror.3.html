curl_url_strerror(3)

الحزمة: curl

التراخيص: MIT

curl_url_strerror(3) دليل وظائف المكتبة curl_url_strerror(3)

الاسم

curl_url_strerror - إرجاع سلسلة نصية تصف رمز الخطأ

الملخص

#include <curl/curl.h>
const char *curl_url_strerror(CURLUcode errornum);

الوصف

هذه الوظيفة تعيد سلسلة نصية تصف رمز الخطأ CURLUcode الذي تم تمريره في الوسيط errornum.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURLUcode rc;
  CURLU *url = curl_url();
  rc = curl_url_set(url, CURLUPART_URL, "https://example.com", 0);
  if(rc)
    printf("URL error: %s\n", curl_url_strerror(rc));
  curl_url_cleanup(url);
}

التوفر

تمت الإضافة في curl 7.80.0

قيمة الإرجاع

مؤشر إلى سلسلة نصية منتهية بصفر.
