CURLOPT_PROTOCOLS_STR(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROTOCOLS_STR(3) دليل وظائف المكتبة CURLOPT_PROTOCOLS_STR(3)

اسم

CURLOPT_PROTOCOLS_STR - البروتوكولات المسموح بها

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROTOCOLS_STR, char *spec);

الوصف

مرر مؤشرًا إلى سلسلة نصية تحتوي على قائمة مفصولة بفواصل بأسماء البروتوكولات (مخططات URL) غير حساسة لحالة الأحرف التي يُسمح بها في عملية النقل. يسمح هذا الخيار للتطبيقات باستخدام مكتبة curl المبنية لدعم مجموعة واسعة من البروتوكولات ولكن لا يزال يحد عمليات النقل المحددة لتكون مسموحًا بها فقط لمجموعة فرعية منها. افتراضيًا، تقبل مكتبة curl جميع البروتوكولات التي تم بناؤها لدعمها. انظر أيضًا CURLOPT_REDIR_PROTOCOLS_STR(3).

إذا حاولت تعيين بروتوكول غير موجود أو إذا لم يتم تعيين أي بروتوكول مطابق على الإطلاق، فسيتم إرجاع خطأ.

هذه هي البروتوكولات المتاحة:

DICT, FILE, FTP, FTPS, GOPHER, GOPHERS, HTTP, HTTPS, IMAP, IMAPS, LDAP, LDAPS, MQTT, POP3, POP3S, RTMP, RTMPE, RTMPS, RTMPT, RTMPTE, RTMPTS, RTSP, SCP, SFTP, SMB, SMBS, SMTP, SMTPS, TELNET, TFTP, WS, WSS

يمكنك تعيين "ALL" كاختصار لتمكين جميع البروتوكولات. لاحظ أنه من خلال تعيين الكل، قد تقوم بتمكين بروتوكولات لم تكن مدعومة في اليوم الذي كتبت فيه هذا ولكن تم تقديمها في إصدار مستقبلي من مكتبة curl.

curl_version_info(3) يمكن استخدامه للحصول على قائمة بجميع البروتوكولات المدعومة في مكتبة curl الحالية. CURLINFO_SCHEME(3) هي الطريقة الموصى بها لمعرفة البروتوكول المستخدم في عملية نقل سابقة.

استخدام هذا الخيار عدة مرات يجعل السلسلة النصية الأخيرة المعينة تلغي السلاسل السابقة. قم بتعيينه إلى NULL لاستعادة الإعدادات الافتراضية الداخلية.

الافتراضي

جميع البروتوكولات المبنية داخليًا

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(int argc, char **argv)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* تمرير عنوان URL من مصدر خارجي */
    curl_easy_setopt(curl, CURLOPT_URL, argv[1]);
    /* السماح فقط بـ HTTP و TFTP و SFTP */
    curl_easy_setopt(curl, CURLOPT_PROTOCOLS_STR, "http,tftp,sftp");
    /* تنفيذ الطلب */
    curl_easy_perform(curl);
  }
}

التوفر

تمت الإضافة في curl 7.85.0

قيمة الإرجاع

تُرجع CURLE_UNKNOWN_OPTION إذا لم يتم تنفيذ الخيار، و CURLE_UNSUPPORTED_PROTOCOL إذا كان البروتوكول المذكور غير مدعوم أو معطل، و CURLE_BAD_FUNCTION_ARGUMENT إذا لم يتم سرد أي بروتوكول، وإلا فإنها تُرجع CURLE_OK.

انظر أيضًا

CURLINFO_SCHEME(3)، CURLOPT_DEFAULT_PROTOCOL(3)، CURLOPT_REDIR_PROTOCOLS_STR(3)، CURLOPT_URL(3)، curl_version_info(3)
