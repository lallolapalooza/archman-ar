CURLOPT_PROXYAUTH(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROXYAUTH(3) دليل وظائف المكتبة CURLOPT_PROXYAUTH(3)

الاسم

CURLOPT_PROXYAUTH - طرق مصادقة وكيل HTTP

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYAUTH, long bitmask);

الوصف

قم بتمرير قيمة طويلة (long) كمعامل، والتي يتم تعيينها إلى قناع بت (bitmask)، لإخبار libcurl بطرق المصادقة HTTP التي تريدها لاستخدامها في مصادقة الوكيل الخاص بك. إذا تم تعيين أكثر من بت واحد، فإن libcurl يستعلم أولاً من الموقع لمعرفة طرق المصادقة التي يدعمها ثم يختار أفضل طريقة تسمح بها. بالنسبة لبعض الطرق، يتسبب هذا في جولة شبكة إضافية. قم بتعيين الاسم وكلمة المرور الفعليين باستخدام الخيار CURLOPT_PROXYUSERPWD(3).

يمكن بناء قناع البت باستخدام البتات المدرجة والموصوفة في صفحة الدليل CURLOPT_HTTPAUTH(3).

الافتراضي

CURLAUTH_BASIC

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* استخدم هذا الوكيل */
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://local.example.com:1080");
    /* اسمح بأي مصادقة يتحدثها الوكيل */
    curl_easy_setopt(curl, CURLOPT_PROXYAUTH, CURLAUTH_ANY);
    /* قم بتعيين بيانات اعتماد الوكيل */
    curl_easy_setopt(curl, CURLOPT_PROXYUSERPWD, "james:007");
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التاريخ

أصبحت ماكرو CURLAUTH_* من أنواع long في الإصدار 7.26.0، قبل هذا الإصدار كان من الضروري تحويلها إلى long عند تمريرها إلى curl_easy_setopt(3).

التوفر

تمت الإضافة في curl 7.10.7

قيمة الإرجاع

curl_easy_setopt(3) ترجع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء على ما يرام، وأي قيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).
