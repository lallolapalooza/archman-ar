CURLINFO_PROXY_SSL_VERIFYRESULT(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_PROXY_SSL_VERIFYRESULT(3) دليل الدوال المكتبية CURLINFO_PROXY_SSL_VERIFYRESULT(3)

الاسم

CURLINFO_PROXY_SSL_VERIFYRESULT - الحصول على نتيجة التحقق من شهادة الوكيل

الملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_PROXY_SSL_VERIFYRESULT,
                           long *result);

الوصف

مرر مؤشرًا إلى قيمة طويلة (long) لتلقي نتيجة التحقق من الشهادة التي تم طلبها (باستخدام الخيار CURLOPT_PROXY_SSL_VERIFYPEER(3). يتم استخدام هذا فقط للوكلاء HTTPS.

القيمة 0 تعني نتيجة إيجابية. أي قيمة غير صفرية تعني وجود خطأ.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات القائمة على TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS، إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية لـ TLS التالية: GnuTLS و OpenSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    long verifyresult;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy:443");
    res = curl_easy_perform(curl);
    if(res) {
      printf("error: %s\n", curl_easy_strerror(res));
      curl_easy_cleanup(curl);
      return 1;
    }
    res = curl_easy_getinfo(curl, CURLINFO_PROXY_SSL_VERIFYRESULT,
                            &verifyresult);
    if(!res) {
      printf("The peer verification said %s\n",
             (verifyresult ? "bad" : "fine"));
    }
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت إضافته في curl 7.52.0

قيمة الإرجاع

curl_easy_getinfo(3) ترجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، وقيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).
