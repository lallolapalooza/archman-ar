CURLOPT_FILETIME(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_FILETIME(3) دليل الوظائف المكتبية CURLOPT_FILETIME(3)

الاسم

CURLOPT_FILETIME - الحصول على وقت آخر تعديل للمورد البعيد

التركيب

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_FILETIME, long gettime);

الوصف

يمرر قيمة طويلة. إذا كانت 1، تحاول مكتبة libcurl الحصول على وقت آخر تعديل للمستند البعيد في هذه العملية. يتطلب هذا أن يرسل الخادم البعيد الوقت أو يرد على أمر استعلام الوقت. يمكن استخدام الدالة curl_easy_getinfo(3) مع الوسيط CURLINFO_FILETIME(3) بعد النقل لاستخراج الوقت المستلم (إن وجد).

الافتراضي

0

البروتوكولات

تؤثر هذه الوظيفة على الملفات، ftp، http، sftp و smb

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/path.html");
    /* طلب وقت الملف */
    curl_easy_setopt(curl, CURLOPT_FILETIME, 1L);
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      long filetime;
      res = curl_easy_getinfo(curl, CURLINFO_FILETIME, &filetime);
      if((CURLE_OK == res) && (filetime >= 0)) {
        time_t file_time = (time_t)filetime;
        printf("وقت الملف: %s", ctime(&file_time));
      }
    }
    /* التنظيف دائمًا */
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.5

قيمة الإرجاع

curl_easy_setopt(3) ترجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، راجع libcurl-errors(3).

راجع أيضًا

CURLINFO_FILETIME(3)، curl_easy_getinfo(3)
