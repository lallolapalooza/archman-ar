CURLINFO_CAPATH(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_CAPATH(3) دليل الوظائف المكتبية CURLINFO_CAPATH(3)

الاسم

CURLINFO_CAPATH - الحصول على سلسلة المسار الافتراضي المدمج للمرجعية

موجز

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CAPATH, char **path);

الوصف

مرر مؤشرًا إلى مؤشر حرف لاستلام المؤشر إلى سلسلة منتهية بـ NULL تحتوي على المسار الافتراضي المدمج المستخدم للخيار CURLOPT_CAPATH(3) ما لم يقم المستخدم بتعيينه.

لاحظ أنه في الحالات التي تم فيها بناء libcurl لدعم مكتبات TLS متعددة، قد تعيد هذه الخيار سلسلة حتى لو كانت مكتبة TLS المحددة المستخدمة حاليًا لا تدعم CURLOPT_CAPATH(3).

هذا مسار يحدد دليلاً.

يتم تعيين المؤشر path إلى NULL إذا لم يكن هناك مسار افتراضي.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات القائمة على TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS، إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية لـ TLS التالية: GnuTLS، OpenSSL، mbedTLS و wolfSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char *capath = NULL;
    curl_easy_getinfo(curl, CURLINFO_CAPATH, &capath);
    if(capath) {
      printf("default ca path: %s\n", capath);
    }
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.84.0

قيمة الإرجاع

curl_easy_getinfo(3) تعيد قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
