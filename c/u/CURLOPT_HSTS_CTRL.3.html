CURLOPT_HSTS_CTRL(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_HSTS_CTRL(3) دليل وظائف المكتبة CURLOPT_HSTS_CTRL(3)

الاسم

CURLOPT_HSTS_CTRL - التحكم في سلوك HSTS

الملخص

#include <curl/curl.h>
#define CURLHSTS_ENABLE       (1L<<0)
#define CURLHSTS_READONLYFILE (1L<<1)
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTS_CTRL, long bitmask);

الوصف

HSTS (HTTP Strict Transport Security) يعني أن خادم HTTPS يمكنه إخبار العميل بعدم الاتصال به مرة أخرى عبر نص HTTP الواضح لفترة زمنية معينة في المستقبل. تقوم libcurl بعد ذلك تلقائيًا بإعادة توجيه محاولات HTTP إلى هذه المضيفات لاستخدام HTTPS بدلاً من ذلك. يتم ذلك عن طريق الاحتفاظ بهذا المعرفة في ذاكرة التخزين المؤقت للذاكرة بواسطة libcurl.

املأ bitmask الطويل بمجموعة الميزات الصحيحة لإخبار libcurl بكيفية التعامل مع HSTS لعمليات النقل التي تستخدم هذا المقبض.

البتات

CURLHSTS_ENABLE
تمكين ذاكرة التخزين المؤقت لـ HSTS في الذاكرة لهذا المقبض.
CURLHSTS_READONLYFILE
جعل ملف HSTS (إذا تم تحديده) للقراءة فقط - يجعل libcurl لا يحفظ ذاكرة التخزين المؤقت في الملف عند إغلاق المقبض.

الافتراضي

0

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HSTS_CTRL, CURLHSTS_ENABLE);
    curl_easy_perform(curl);
  }
}
