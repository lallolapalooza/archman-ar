CURLOPT_MAXREDIRS(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_MAXREDIRS(3) دليل وظائف المكتبة CURLOPT_MAXREDIRS(3)

الاسم

CURLOPT_MAXREDIRS - الحد الأقصى لعدد عمليات إعادة التوجيه المسموح بها

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_MAXREDIRS, long amount);

الوصف

مرر قيمة طويلة (long). الرقم المحدد هو حد إعادة التوجيه amount. إذا تم اتباع هذا العدد من عمليات إعادة التوجيه، فإن عملية إعادة التوجيه التالية تؤدي إلى حدوث الخطأ (CURLE_TOO_MANY_REDIRECTS). لا يكون لهذا الخيار معنى إلا إذا تم استخدام CURLOPT_FOLLOWLOCATION(3) في نفس الوقت.

تحديد الحد إلى 0 يجعل libcurl يرفض أي إعادة توجيه.

قم بتعيينه على -1 لعدد غير محدود من عمليات إعادة التوجيه. هذا يسمح لتطبيقك بالوقوع في حلقات إعادة توجيه لا نهائية.

الافتراضي

30 (منذ 8.3.0)، كان سابقًا غير محدود.

البروتوكولات

هذه الوظيفة تؤثر على http فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* تمكين تتبع إعادة التوجيه */
    curl_easy_setopt(curl, CURLOPT_FOLLOWLOCATION, 1L);
    /* السماح بثلاث عمليات إعادة توجيه */
    curl_easy_setopt(curl, CURLOPT_MAXREDIRS, 3L);
    /* تنفيذ الطلب */
    curl_easy_perform(curl);
  }
}

التوفر

تمت إضافته في curl 7.5

قيمة الإرجاع

curl_easy_setopt(3) يعيد CURLcode يشير إلى النجاح أو الخطأ.

CURL_OK (0) يعني أن كل شيء كان على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، راجع libcurl-errors(3).
