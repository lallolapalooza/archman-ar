CURLINFO_CONN_ID(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_CONN_ID(3) دليل وظائف المكتبة CURLINFO_CONN_ID(3)

الاسم

CURLINFO_CONN_ID - الحصول على معرف الاتصال الأخير الذي تم استخدامه بواسطة المقبض.

الاختصار

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONN_ID,
                           curl_off_t *conn_id);

الوصف

مرر مؤشراً إلى curl_off_t لاستقبال معرف الاتصال الأخير الذي تم استخدامه بواسطة المقبض. يخزن -1 إذا لم يتم استخدام أي اتصال.

معرف الاتصال فريد بين جميع الاتصالات التي تستخدم نفس ذاكرة التخزين المؤقت للاتصالات. هذا هو الحال ضمنياً لجميع الاتصالات في نفس المقبض المتعدد.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة.

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* قم بتنفيذ الطلب */
    res = curl_easy_perform(curl);
    if(!res) {
      curl_off_t conn_id;
      res = curl_easy_getinfo(curl, CURLINFO_CONN_ID, &conn_id);
      if(!res) {
        printf("الاتصال المستخدم: %" CURL_FORMAT_CURL_OFF_T "\n", conn_id);
      }
    }
  }
}

التوفر

تمت إضافته في curl 8.2.0.

قيمة الإرجاع

curl_easy_getinfo(3) ترجع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، راجع libcurl-errors(3).

انظر أيضاً

CURLINFO_XFER_ID(3)، curl_easy_getinfo(3)، curl_easy_setopt(3).
