curl_global_sslset(3)

الحزمة: curl

التراخيص: MIT

curl_global_sslset(3) دليل دوال المكتبة curl_global_sslset(3)

الاسم

curl_global_sslset - اختيار الواجهة الخلفية لـ SSL للاستخدام

الملخص

#include <curl/curl.h>
CURLsslset curl_global_sslset(curl_sslbackend id,
                              const char *name,
                              const curl_ssl_backend ***avail);

الوصف

تُكوّن هذه الدالة وقت التشغيل الواجهة الخلفية لـ SSL التي سيتم استخدامها مع libcurl. يمكن استخدام هذه الدالة لاختيار واجهة خلفية لـ SSL مرة واحدة فقط، ويجب استدعاؤها قبل curl_global_init(3).

يمكن تحديد الواجهة الخلفية بواسطة id (على سبيل المثال، CURLSSLBACKEND_OPENSSL). يمكن أيضًا تحديد الواجهة الخلفية عبر المعلمة name للمطابقة غير الحساسة لحالة الأحرف (بتمرير CURLSSLBACKEND_NONE كـ id). إذا تم تحديد كل من id و name، يتم تجاهل name.

إذا لم يتم تحديد id ولا name، تفشل الدالة مع CURLSSLSET_UNKNOWN_BACKEND وتعيين المؤشر avail إلى قائمة متاحة من الواجهات الخلفية المنتهية بـ NULL. الواجهات الخلفية المتاحة هي تلك التي تدعمها هذه النسخة المحددة من libcurl.

منذ libcurl 7.60.0، يتم دائمًا تعيين المؤشر avail إلى قائمة البدائل إذا لم يكن NULL.

عند النجاح، تُرجع الدالة CURLSSLSET_OK.

إذا كانت الواجهة الخلفية لـ SSL المحددة غير متاحة، تُرجع الدالة CURLSSLSET_UNKNOWN_BACKEND وتعيين المؤشر avail إلى قائمة متاحة من الواجهات الخلفية لـ SSL المنتهية بـ NULL. في هذه الحالة، يمكنك استدعاء الدالة مرة أخرى لمحاولة اختيار واجهة خلفية مختلفة.

يمكن تعيين الواجهة الخلفية لـ SSL مرة واحدة فقط. إذا تم تكوينها مسبقًا، فإن محاولة تغييرها لاحقًا ينتج عنها إرجاع CURLSSLSET_TOO_LATE.

هذه الدالة آمنة للمسارات المتزامنة (thread-safe) منذ libcurl 7.84.0 إذا كان curl_version_info(3) يحتوي على بت الميزة CURL_VERSION_THREADSAFE المحدد (معظم الأنظمة).

إذا لم تكن آمنة للمسارات المتزامنة، يجب عليك عدم استدعاء هذه الدالة عندما يعمل أي مسار آخر في البرنامج (أي مسار يشارك نفس الذاكرة). هذا لا يعني فقط عدم وجود مسار آخر يستخدم libcurl.

الأسماء

أسماء الواجهات الخلفية لـ SSL (غير حساسة لحالة الأحرف): GnuTLS، mbedTLS، OpenSSL، Rustls، Schannel، wolfSSL

يُستخدم الاسم "OpenSSL" لجميع إصدارات OpenSSL والتفرعات/النكهات المرتبطة بها في هذه الدالة. يتم دعم OpenSSL، BoringSSL، LibreSSL، quictls، و AmiSSL بواسطة libcurl، ولكن من وجهة نظر curl_global_sslset(3)، كلها مجرد "OpenSSL". كلها توفر نفس الواجهة البرمجية تقريبًا. يمكن لـ curl_version_info(3) إرجاع معلومات أكثر تحديدًا حول النكهة الدقيقة لإصدار OpenSSL المستخدم.

الهيكل

typedef struct {
  curl_sslbackend id;
  const char *name;
} curl_ssl_backend;
typedef enum {
  CURLSSLBACKEND_NONE = 0,
  CURLSSLBACKEND_OPENSSL = 1, /* أو أحد تفرعاته */
  CURLSSLBACKEND_GNUTLS = 2,
  CURLSSLBACKEND_NSS = 3,
  CURLSSLBACKEND_GSKIT = 5, /* مهمل */
  CURLSSLBACKEND_POLARSSL = 6, /* مهمل */
  CURLSSLBACKEND_WOLFSSL = 7,
  CURLSSLBACKEND_SCHANNEL = 8,
  CURLSSLBACKEND_SECURETRANSPORT = 9, /* مهمل */
  CURLSSLBACKEND_AXTLS = 10, /* مهمل */
  CURLSSLBACKEND_MBEDTLS = 11,
  CURLSSLBACKEND_MESALINK = 12, /* مهمل */
  CURLSSLBACKEND_BEARSSL = 13, /* مهمل */
  CURLSSLBACKEND_RUSTLS = 14
} curl_sslbackend;

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  int i;
  /* اختر واجهة خلفية معينة */
  curl_global_sslset(CURLSSLBACKEND_WOLFSSL, NULL, NULL);
  /* قم بإدراج الواجهات المتاحة */
  const curl_ssl_backend **list;
  curl_global_sslset(CURLSSLBACKEND_NONE, NULL, &list);
  for(i = 0; list[i]; i++)
    printf("SSL backend #%d: '%s' (ID: %d)\n",
           i, list[i]->name, list[i]->id);
}

التوفر

تمت الإضافة في curl 7.56.0

قيمة الإرجاع

إذا أعادت هذه الدالة CURLSSLSET_OK، فقد تم تحديد الواجهة الخلفية بنجاح.

إذا كانت الواجهة الخلفية المختارة غير معروفة (أو لم يتم تجميع دعم الواجهة الخلفية المختارة في libcurl)، تُرجع الدالة CURLSSLSET_UNKNOWN_BACKEND.

إذا تم تكوين الواجهة الخلفية مسبقًا، أو إذا تم استدعاء curl_global_init(3) بالفعل، تُرجع الدالة CURLSSLSET_TOO_LATE.

إذا تم بناء libcurl هذا تمامًا بدون دعم SSL، وبدون أي واجهات خلفية على الإطلاق، تُرجع هذه الدالة CURLSSLSET_NO_BACKENDS.
