CURLMOPT_TIMERDATA(3)

الحزمة: curl

التراخيص: MIT

CURLMOPT_TIMERDATA(3) دليل وظائف المكتبة CURLMOPT_TIMERDATA(3)

الاسم

CURLMOPT_TIMERDATA - مؤشر مخصص لتمريره إلى دالة رد الاتصال للمؤقت

الخلاصة

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_TIMERDATA, void *pointer);

الوصف

مؤشر بيانات لتمريره إلى دالة رد الاتصال للمؤقت المحددة بالخيار CURLMOPT_TIMERFUNCTION(3).

هذا المؤشر لا يتم التعامل معه بواسطة libcurl ولكنه يتم تمريره فقط إلى وسيطة clientp لدالة رد الاتصال للمؤقت.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct priv {
  void *custom;
};
static int timerfunc(CURLM *multi, long timeout_ms, void *clientp)
{
  struct priv *mydata = clientp;
  printf("our ptr: %p\n", mydata->custom);
  if(timeout_ms >= 0) {
    /* this is the new single timeout to wait for */
  }
  else {
    /* delete the timeout, nothing to wait for now */
  }
  return 0;
}
int main(void)
{
  struct priv mydata;
  CURLM *multi = curl_multi_init();
  curl_multi_setopt(multi, CURLMOPT_TIMERFUNCTION, timerfunc);
  curl_multi_setopt(multi, CURLMOPT_TIMERDATA, &mydata);
}

التوفر

تمت إضافته في curl 7.16.0

قيمة الإرجاع

curl_multi_setopt(3) ترجع قيمة CURLMcode تشير إلى النجاح أو الخطأ.

CURLM_OK (0) تعني أن كل شيء كان على ما يرام، وقيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).
