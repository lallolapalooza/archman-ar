curl_mime_filedata(3)

الحزمة: curl

التراخيص: MIT

curl_mime_filedata(3) دليل وظائف المكتبة curl_mime_filedata(3)

الاسم

curl_mime_filedata - تعيين بيانات جسم جزء mime من محتويات ملف

الملخص

#include <curl/curl.h>
CURLcode curl_mime_filedata(curl_mimepart *part,
                            const char *filename);

الوصف

curl_mime_filedata(3) يقوم بتعيين محتويات جسم جزء mime من محتويات الملف المسمى. هذا بديل لـ curl_mime_data(3) لتعيين البيانات لجزء mime.

part هو الجزء المطلوب تعيين محتوياته له.

filename يشير إلى اسم مسار الملف المنتهي بـ NULL. يمكن إعادة استخدام تخزين المؤشر بأمان بعد هذه المكالمة. يمكن إعادة استخدام تخزين اسم الملف بأمان بعد هذه المكالمة.

كأثر جانبي، يتم تعيين اسم الملف البعيد للجزء إلى اسم الأساس للملف filename المعطى إذا كان ملفًا باسم صالحًا. يمكن إلغاء هذا أو تجاوزه بمكالمة لاحقة لـ curl_mime_filename(3).

تتم قراءة محتويات الملف أثناء نقل الملف بطريقة التدفق للسماح بنقل الملفات الضخمة دون استخدام الكثير من الذاكرة. لذلك يتطلب أن يظل الملف سليمًا خلال الطلب بأكمله.

إذا كان حجم الملف لا يمكن تحديده قبل قراءته فعليًا (مثل جهاز أحرف أو أنبوب مسمى)، يتم نقل بنية mime بأكملها التي تحتوي على الجزء باستخدام أجزاء بواسطة HTTP ولكن يتم رفضها بواسطة IMAP.

تعيين محتويات جزء ما عدة مرات أمر صالح: فقط القيمة التي تم تعيينها بواسطة المكالمة الأخيرة يتم الاحتفاظ بها.

البروتوكولات

هذه الوظيفة تؤثر على http، imap و smtp

مثال

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* إنشاء مقبض mime */
    mime = curl_mime_init(curl);
    /* إضافة جزء */
    part = curl_mime_addpart(mime);
    /* إرسال بيانات من هذا الملف */
    curl_mime_filedata(part, "image.png");
    /* تعيين الاسم */
    curl_mime_name(part, "data");
  }
}

التوفر

تمت الإضافة في curl 7.56.0

قيمة الإرجاع

تعيد هذه الوظيفة قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، وأي قيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3). إذا تم تعيين CURLOPT_ERRORBUFFER(3) باستخدام curl_easy_setopt(3) فقد تكون هناك رسالة خطأ مخزنة في مخزن الخطأ عند إرجاع قيمة غير صفرية.

CURLE_READ_ERROR هو مجرد مؤشر على أن الملف ليس قابلاً للقراءة بعد: يمكن تجاهله بأمان في هذا الوقت، ولكن يجب جعل الملف قابلاً للقراءة قبل تنفيذ المقبض السهل المعني.
