curs_ins_wstr(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_ins_wstr(3x) استدعاءات المكتبة curs_ins_wstr(3x)

الاسم

ins_wstr, ins_nwstr, wins_wstr, wins_nwstr, mvins_wstr, mvins_nwstr, mvwins_wstr, mvwins_nwstr - إدراج سلسلة أحرف واسعة في نافذة curses

الملخص

#include <curses.h>
int ins_wstr(const wchar_t *wstr);
int ins_nwstr(const wchar_t *wstr, int n);
int wins_wstr(WINDOW *win, const wchar_t *wstr);
int wins_nwstr(WINDOW *win, const wchar_t *wstr, int n);
int mvins_wstr(int y, int x, const wchar_t *wstr);
int mvins_nwstr(int y, int x, const wchar_t *wstr, int n);
int mvwins_wstr(WINDOW *win, int y, int x, const wchar_t *wstr);
int mvwins_nwstr(WINDOW *win, int y, int x, const wchar_t *wstr, int n);

الوصف

تقوم هذه الروتينات بإدراج سلسلة أحرف wchar_t (بقدر ما يمكن وضعه في السطر) قبل الحرف الموجود تحت المؤشر، كما لو كان استدعاء wins_wch(3X). يتم إزاحة جميع الأحرف الموجودة على يمين المؤشر إلى اليمين، مع احتمال فقدان الأحرف الموجودة في أقصى اليمين من السطر. لا يتم إجراء التفاف.

لا يتغير موضع المؤشر (بعد الانتقال إلى y، x، إذا تم تحديده).

الوظائف التي تحتوي على n كوسيطة أخيرة تقوم بإدراج جزء فرعي بادئ بحد أقصى n حرف wchar_t. إذا كان n أقل من الصفر، يتم إدراج السلسلة بأكملها (التوقف عند حرف L'\0').

يتم التعامل مع الأحرف الخاصة كما هو الحال في wadd_wch(3X).

قيمة الإرجاع

جميع الوظائف تعيد القيمة الصحيحة ERR عند الفشل و OK عند النجاح.

لا تحدد X/Open Curses أي شروط خطأ. تقوم هذه التنفيذات بإرجاع خطأ

  • إذا كان الوسيط win فارغًا أو
  • إذا كان الوسيط wstr فارغًا أو
  • إذا أعادت وظيفة wins_wch خطأ.

الوظائف التي تبدأ بـ "mv" تقوم أولاً بتحريك المؤشر وتفشل إذا كان الموضع (y، x) خارج حدود النافذة.

ملاحظات

قد تكون جميع الوظائف باستثناء wins_nwstr وحدات ماكرو.

إذا كان الحرف الأول في السلسلة حرفًا غير مساف، فستفشل هذه الوظائف. لا تحدد X/Open Curses ما سيحدث إذا تبع حرف التحكم حرف غير مساف.

قابلية النقل

تم وصف هذه الوظائف في X/Open Curses، الإصدار 4، والذي يضيف مؤهلات const إلى الوسائط.

تنص X/Open على أنه يتم إدراج السلسلة بأكملها إذا كان n أقل من 1. من المحتمل أن يكون هذا خطأ، لأنه غير متسق مع الوظائف الأخرى، ويختلف عن تنفيذ X/Open على Solaris.
