CURLOPT_DNS_USE_GLOBAL_CACHE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_DNS_USE_GLOBAL_CACHE(3) دليل الوظائف المكتبية CURLOPT_DNS_USE_GLOBAL_CACHE(3)

الاسم

CURLOPT_DNS_USE_GLOBAL_CACHE - ذاكرة التخزين المؤقت لنظام أسماء النطاقات (DNS) العالمية

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_USE_GLOBAL_CACHE,
                          long enable);

الوصف

لا وظيفة لها منذ الإصدار 7.62.0. لا تستخدم.

مرر قيمة من نوع long. إذا كانت قيمة enable تساوي 1، فإنها تخبر curl باستخدام ذاكرة تخزين مؤقت لنظام أسماء النطاقات (DNS) عالمية تستمر بين إنشاء وإزالة المقابض السهلة (easy handles). هذا ليس آمنًا للخيوط (thread-safe) ويستخدم متغيرًا عالميًا.

راجع CURLOPT_SHARE(3) و curl_share_init(3) لمعرفة الطريقة الصحيحة لمشاركة ذاكرة التخزين المؤقت لنظام أسماء النطاقات (DNS) بين عمليات النقل.

الافتراضي

0

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* قم بإيقاف استخدام ذاكرة تخزين مؤقت عالمية غير آمنة للخيوط */
    curl_easy_setopt(curl, CURLOPT_DNS_USE_GLOBAL_CACHE, 0L);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

مهمل

مهمل منذ الإصدار 7.11.1. تمت إزالة الوظيفة في الإصدار 7.62.0.

التوفر

تمت الإضافة في curl الإصدار 7.9.3

قيمة الإرجاع

curl_easy_setopt(3) ترجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، أي قيمة غير صفرية تعني حدوث خطأ، راجع libcurl-errors(3).
