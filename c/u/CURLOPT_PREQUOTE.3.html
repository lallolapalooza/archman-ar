CURLOPT_PREQUOTE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PREQUOTE(3) دليل وظائف المكتبة CURLOPT_PREQUOTE(3)

الاسم

CURLOPT_PREQUOTE - الأوامر التي سيتم تشغيلها قبل نقل FTP

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PREQUOTE,
                          struct curl_slist *cmds);

الوصف

مرر مؤشرًا إلى قائمة مرتبطة بأوامر FTP ليتم تمريرها إلى الخادم بعد تحديد نوع النقل. يجب أن تكون القائمة المرتبطة قائمة صالحة بالكامل من هياكل struct curl_slist مملوءة بشكل صحيح كما هو موضح لـ CURLOPT_QUOTE(3).

استخدام هذا الخيار عدة مرات يجعل السلسلة الأخيرة المعينة تلغي الساب قة. قم بتعيينها إلى NULL لتعطيل استخدامها مرة أخرى.

لا يقوم libcurl بنسخ القائمة، يجب الاحتفاظ بها حتى اكتمال النقل.

بينما تعمل CURLOPT_QUOTE(3) و CURLOPT_POSTQUOTE(3) لـ SFTP، هذا الخيار لا يعمل.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على ftp فقط

مثال

int main(void)
{
  struct curl_slist *cmdlist = NULL;
  cmdlist = curl_slist_append(cmdlist, "SYST");
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com/foo.bin");
    /* تمرير أوامر FTP ليتم تشغيلها */
    curl_easy_setopt(curl, CURLOPT_PREQUOTE, cmdlist);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(cmdlist);
}

التوفر

تمت إضافته في curl 7.9.5

قيمة الإرجاع

curl_easy_setopt(3) يرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، وغير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
