CURLOPT_DISALLOW_USERNAME_IN_URL(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_DISALLOW_USERNAME_IN_URL(3) دليل وظائف المكتبة CURLOPT_DISALLOW_USERNAME_IN_URL(3)

الاسم

CURLOPT_DISALLOW_USERNAME_IN_URL - منع تحديد اسم المستخدم في عنوان URL

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DISALLOW_USERNAME_IN_URL,
                          long disallow);

الوصف

تخبر المعلمة الطويلة التي تم تعيينها إلى 1 المكتبة بعدم السماح بعناوين URL التي تتضمن اسم مستخدم.

هذا يعادل العلامة CURLU_DISALLOW_USER لوظيفة curl_url_set(3).

الافتراضي

0 (معطل)

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_DISALLOW_USERNAME_IN_URL, 1L);
    curl_easy_perform(curl);
  }
}

التوفر

تمت إضافته في curl 7.61.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، أي قيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).

curl_easy_perform(3) ترجع CURLE_LOGIN_DENIED إذا تم تمكين هذا الخيار وتم تحديد عنوان URL يحتوي على اسم مستخدم.
