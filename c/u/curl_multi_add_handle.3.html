curl_multi_add_handle(3)

الحزمة: curl

التراخيص: MIT

curl_multi_add_handle(3) دليل المكتبة curl_multi_add_handle(3)

الاسم

curl_multi_add_handle - إضافة مقبض سهل إلى جلسة متعددة

الملخص

#include <curl/curl.h>
CURLMcode curl_multi_add_handle(CURLM *multi_handle, CURL *easy_handle);

الوصف

يضيف مقبض سهل إلى مقبض متعدد.

بينما يكون المقبض السهل مضافًا إلى مكدس متعدد، لا يمكنك ويجب عليك عدم استخدام curl_easy_perform(3) على هذا المقبض. بعد إزالة المقبض السهل من المكدس المتعدد مرة أخرى، يصبح من المناسب تمامًا استخدامه مع الواجهة السهلة مرة أخرى.

إذا لم يتم ضبط المقبض السهل لاستخدام ذاكرة تخزين مؤقت مشتركة (CURLOPT_SHARE(3))، فسيتم ضبطه لاستخدام ذاكرة تخزين مؤقت DNS مشتركة بين جميع المقابض السهلة داخل المقبض المتعدد عند استدعاء curl_multi_add_handle(3).

عند إضافة واجهة سهلة إلى مقبض متعدد، يتم ضبطها لاستخدام ذاكرة تخزين مؤقت للاتصالات مشتركة مملوكة للمقبض المتعدد. إزالة وإضافة المقابض السهلة الجديدة لا يؤثر على مجموعة الاتصالات أو القدرة على إعادة استخدام الاتصالات.

إذا كان لديك CURLMOPT_TIMERFUNCTION(3) مضبوطًا في المقبض المتعدد (كما يجب إذا كنت تعمل بناءً على الأحداث مع curl_multi_socket_action(3) والأصدقاء)، فسيتم استدعاء دالة الاستدعاء هذه من داخل هذه الدالة لطلب مؤقت محدث حتى تحصل حلقة الأحداث الرئيسية لديك على النشاط على هذا المقبض لبدء التشغيل.

يبقى المقبض السهل مضافًا إلى المقبض المتعدد حتى تزيله مرة أخرى باستخدام curl_multi_remove_handle(3) - حتى عند اكتمال نقل باستخدام هذا المقبض السهل المحدد.

يجب عليك إزالة المقبض السهل من المكدس المتعدد قبل إنهاء المقبض السهل أولاً، ثم المقبض المتعدد:

1 - curl_multi_remove_handle(3)

2 - curl_easy_cleanup(3)

3 - curl_multi_cleanup(3)

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  /* تهيئة مكدس متعدد */
  CURLM *multi = curl_multi_init();
  /* إنشاء مقبضين سهلَيْن */
  CURL *http_handle = curl_easy_init();
  CURL *http_handle2 = curl_easy_init();
  /* إضافة عمليات نقل فردية */
  curl_multi_add_handle(multi, http_handle);
  curl_multi_add_handle(multi, http_handle2);
}
