CURLOPT_PROXYTYPE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROXYTYPE(3) دليل الدوال المكتبية CURLOPT_PROXYTYPE(3)

الاسم

CURLOPT_PROXYTYPE - نوع بروتوكول الوكيل (proxy)

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYTYPE, long type);

الوصف

مرر إحدى القيم التالية لتعيين نوع الوكيل.

CURLPROXY_HTTP
وكيل HTTP. الافتراضي.
CURLPROXY_HTTPS
وكيل HTTPS باستخدام HTTP/1. (تمت إضافته في 7.52.0 لـ OpenSSL و GnuTLS. منذ 7.87.0، يعمل أيضًا لـ mbedTLS و Rustls و Schannel و wolfSSL.)
CURLPROXY_HTTPS2
وكيل HTTPS ومحاولة التحدث HTTP/2 فوقه. (تمت إضافته في 8.1.0)
CURLPROXY_HTTP_1_0
وكيل HTTP 1.0. هذا مشابه لـ CURLPROXY_HTTP باستثناء أنه يستخدم HTTP/1.0 لأي نفق CONNECT. لا يغير إصدار HTTP للطلبات HTTP الفعلية، والذي يتم التحكم فيه بواسطة CURLOPT_HTTP_VERSION(3).
CURLPROXY_SOCKS4
وكيل SOCKS4.
CURLPROXY_SOCKS4A
وكيل SOCKS4a. يقوم الوكيل بحل اسم مضيف URL.
CURLPROXY_SOCKS5
وكيل SOCKS5.
CURLPROXY_SOCKS5_HOSTNAME
وكيل SOCKS5. يقوم الوكيل بحل اسم مضيف URL.

غالبًا ما يكون من الملائم تحديد نوع الوكيل باستخدام جزء المخطط (scheme) من سلسلة CURLOPT_PROXY(3).

الافتراضي

CURLPROXY_HTTP

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "local.example.com:1080");
    /* تعيين نوع الوكيل */
    curl_easy_setopt(curl, CURLOPT_PROXYTYPE, CURLPROXY_SOCKS5);
    ret = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التاريخ

أصبحت تعدادات CURLPROXY_* من النوع long في الإصدار 8.16.0، قبل هذا الإصدار كان التحويل إلى long ضروريًا عند تمريره إلى curl_easy_setopt(3).

التوفر

تمت الإضافة في curl 7.10

قيمة الإرجاع

curl_easy_setopt(3) تُرجع CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
