CURLOPT_INFILESIZE_LARGE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_INFILESIZE_LARGE(3) دليل وظائف المكتبة CURLOPT_INFILESIZE_LARGE(3)

الاسم

CURLOPT_INFILESIZE_LARGE - حجم الملف المدخل لإرساله

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_INFILESIZE_LARGE,
                          curl_off_t filesize);

الوصف

عند تحميل ملف إلى موقع بعيد، يجب استخدام filesize لإخبار مكتبة curl بالحجم المتوقع للملف المدخل. يجب تمرير هذه القيمة كـ curl_off_t.

لتحميل باستخدام SCP، هذا الخيار أو CURLOPT_INFILESIZE(3) إلزامي.

لإلغاء هذه القيمة مرة أخرى، قم بتعيينها إلى -1.

عند إرسال رسائل البريد الإلكتروني باستخدام SMTP، يمكن استخدام هذه الأمر لتحديد المعلمة الاختيارية SIZE لأمر MAIL FROM.

هذا الخيار لا يحد من مقدار البيانات التي ترسلها مكتبة curl فعليًا، حيث يتم التحكم في ذلك بالكامل بواسطة ما تعيده دالة الاستدعاء، ولكن إخبار قيمة واحدة وإرسال كمية مختلفة قد يؤدي إلى أخطاء.

الافتراضي

غير معين

البروتوكولات

هذه الوظيفة تؤثر على جميع البروتوكولات المدعومة

مثال

#define FILE_SIZE 123456
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_off_t uploadsize = FILE_SIZE;
    curl_easy_setopt(curl, CURLOPT_URL,
                     "ftp://example.com/destination.tar.gz");
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, uploadsize);
    curl_easy_perform(curl);
  }
}

التاريخ

تمت إضافة دعم SMTP في الإصدار 7.23.0

التوفر

تمت إضافته في curl الإصدار 7.11.0

قيمة الإرجاع

curl_easy_setopt(3) تعيد قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، أي قيمة غير صفرية تعني حدوث خطأ، راجع libcurl-errors(3).
