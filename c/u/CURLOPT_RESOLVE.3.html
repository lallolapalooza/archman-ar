CURLOPT_RESOLVE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_RESOLVE(3) دليل وظائف المكتبة CURLOPT_RESOLVE(3)

الاسم

CURLOPT_RESOLVE - توفير اسم مضيف مخصص لحلول عنوان IP

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESOLVE,
                          struct curl_slist *hosts);

الوصف

قم بتمرير مؤشر إلى قائمة مرتبطة من السلاسل النصية بمعلومات حل اسم المضيف لاستخدامها في الطلبات باستخدام هذا المقبض. يجب أن تكون القائمة المرتبطة قائمة كاملة وصحيحة من هياكل struct curl_slist مملوءة بشكل صحيح. استخدم curl_slist_append(3) لإنشاء القائمة و curl_slist_free_all(3) لتنظيف قائمة كاملة.

لا تقوم مكتبة libcurl بنسخ القائمة، بل يجب الاحتفاظ بها حتى اكتمال النقل.

يجب كتابة كل قاعدة حل لإضافتها باستخدام الصيغة

[+]HOST:PORT:ADDRESS[,ADDRESS]

HOST هو الاسم الذي تريد مكتبة libcurl حله، PORT هو رقم منفذ الخدمة حيث تريد مكتبة libcurl الاتصال به بـ HOST، و ADDRESS هو عنوان IP رقمي واحد أو أكثر. إذا قمت بتحديد عناوين IP متعددة، فيجب فصلها بفاصلة. إذا تم بناء مكتبة libcurl لدعم IPv6، يمكن أن يكون كل إدخال من عناوين ADDRESS عبارة عن عناوين IPv4 أو IPv6.

حدد المضيف كرمز نجمة واحد (*) لمطابقة جميع الأسماء. يتم حل هذه العلامة العامة في النهاية، لذا يتم إعطاء الأولوية لأي حل باسم مضيف ورقم منفذ محدد.

يعمل هذا الخيار على ملء ذاكرة التخزين المؤقت لنظام أسماء النطاقات (DNS) بإدخالات لزوج اسم المضيف + المنفذ، بحيث تستخدم عمليات إعادة التوجيه وكل ما يتعلق بالعمليات مقابل اسم المضيف + المنفذ عناوين IP التي قدمتها بدلاً من ذلك.

تشير علامة الجمع (+) الاختيارية في البداية إلى أن الإدخال الجديد سيؤدي إلى انتهاء صلاحيته. الإدخالات التي تمت إضافتها بدون حرف الزائد في البداية تنتهي صلاحيتها تمامًا مثل إدخالات ذاكرة التخزين المؤقت العادية لنظام أسماء النطاقات (DNS)؛ الإدخالات التي تمت إضافتها مع +HOST:... تنتهي صلاحيتها تمامًا مثل إدخالات ذاكرة التخزين المؤقت العادية لنظام أسماء النطاقات (DNS).

إذا كانت ذاكرة التخزين المؤقت لنظام أسماء النطاقات (DNS) تحتوي بالفعل على إدخال لزوج اسم المضيف + المنفذ المحدد، فإن الإدخال الجديد يحل محل الإدخال السابق.

يتم استخدام عنوان IP (ADDRESS) المقدم بهذا الخيار فقط إذا لم يتم تقييده بواسطة إعداد CURLOPT_IPRESOLVE(3) إلى إصدار IP مختلف.

لإزالة الأسماء من ذاكرة التخزين المؤقت لنظام أسماء النطاقات (DNS) مرة أخرى، ولإيقاف توفير هذه الحلول الزائفة، قم بتضمين سلسلة نصية في القائمة المرتبطة تستخدم الصيغة

-HOST:PORT

يجب أن يكون الإدخال المراد إزالته مسبوقًا بشرطة (-)، ويجب أن يتطابق اسم المضيف ورقم المنفذ تمامًا مع ما تم إضافته سابقًا.

قم بتوفير عناوين IPv6 داخل أقواس مربعة [].

يؤدي استخدام هذا الخيار عدة مرات إلى أن تقوم القائمة المحددة مؤخرًا باستبدال القوائم السابقة. قم بتعيينها إلى NULL لتعطيل استخدامها مرة أخرى.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl;
  struct curl_slist *host = NULL;
  host = curl_slist_append(NULL, "example.com:443:127.0.0.1");
  host = curl_slist_append(host, "example.com:443:[2001:db8::252f:efd6]");
  curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_RESOLVE, host);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    /* always cleanup */
    curl_easy_cleanup(curl);
  }
  curl_slist_free_all(host);
}

تمت الإضافة في الإصدار 7.21.3. تمت إضافة دعم الإزالة في الإصدار 7.42.0.

تمت إضافة دعم توفير عنوان IP (ADDRESS) داخل أقواس مربعة [] في الإصدار 7.57.0.

تمت إضافة دعم توفير عناوين IP متعددة لكل إدخال في الإصدار 7.59.0.

تمت إضافة دعم لإضافة إدخالات غير دائمة باستخدام البادئة "+ " في الإصدار 7.75.0.

تمت إضافة دعم لتحديد مكون المضيف كعنوان IPv6 في الإصدار 8.13.0.

قيمة الإرجاع

تقوم curl_easy_setopt(3) بإرجاع رمز خطأ CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).

انظر أيضًا

CURLOPT_CONNECT_TO(3)، CURLOPT_DNS_CACHE_TIMEOUT(3)، CURLOPT_IPRESOLVE(3)
