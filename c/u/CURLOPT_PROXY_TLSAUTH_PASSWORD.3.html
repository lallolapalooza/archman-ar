CURLOPT_PROXY_TLSAUTH_PASSWORD(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROXY_TLSAUTH_PASSWORD(3) دليل الوظائف المكتبية CURLOPT_PROXY_TLSAUTH_PASSWORD(3)

الاسم

CURLOPT_PROXY_TLSAUTH_PASSWORD - كلمة المرور المستخدمة للمصادقة عبر الوكيل TLS

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_TLSAUTH_PASSWORD,
                          char *pwd);

الوصف

مرر مؤشر حرف كمعامل، والذي يجب أن يشير إلى كلمة المرور المنتهية بـ NULL المستخدمة لطريقة المصادقة TLS المحددة باستخدام الخيار CURLOPT_PROXY_TLSAUTH_TYPE(3). يتطلب ذلك تعيين خيار CURLOPT_PROXY_TLSAUTH_USERNAME(3) أيضًا.

لا يحتاج التطبيق إلى الاحتفاظ بالسلسلة النصية بعد تعيين هذا الخيار.

استخدام هذا الخيار عدة مرات يجعل السلسلة الأخيرة المعينة تتجاوز السلاسل السابقة. قم بتعيينه إلى NULL لتعطيل استخدامه مرة أخرى.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات القائمة على TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS، إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية لـ TLS التالية: GnuTLS و OpenSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://proxy");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_TYPE, "SRP");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_USERNAME, "user");
    curl_easy_setopt(curl, CURLOPT_PROXY_TLSAUTH_PASSWORD, "secret");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.52.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
