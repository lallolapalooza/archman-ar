curs_ins_wch(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_ins_wch(3X) استدعاءات المكتبة curs_ins_wch(3X)

الاسم

ins_wch، mvins_wch، mvwins_wch، wins_wch - إدراج حرف curses مركب في نافذة

موجز

#include <curses.h>
int ins_wch(const cchar_t *wch);
int wins_wch(WINDOW *win, const cchar_t *wch);
int mvins_wch(int y, int x, const cchar_t *wch);
int mvwins_wch(WINDOW *win, int y, int x, const cchar_t *wch);

الوصف

تقوم هذه الوظائف بإدراج حرف curses المركب wch في مؤشر في النافذة المحددة win (أو stdscr). يتم نقل الحرف الذي كان في المؤشر سابقًا وأي حرف إلى يمينه خلية واحدة إلى اليمين؛ يتم تجاهل الحرف الأقصى يمينًا في السطر. لا يتقدم المؤشر.

قيمة الإرجاع

تعيد هذه الوظائف OK عند النجاح و ERR عند الفشل.

تفشل الوظائف التي تأخذ وسيطًا من نوع المؤشر WINDOW إذا كان المؤشر NULL.

الوظائف التي تسبقها "mv" تقوم أولاً بتحريك المؤشر وتفشل إذا كان الموضع (y، x) خارج حدود النافذة.

ملاحظات

لا يتم بالضرورة استخدام قدرة insert_character (ich1) للطرفية.

قد يتم تنفيذ ins_wch، mvins_wch، و mvwins_wch كمؤشرات.

قابلية النقل

يصف X/Open Curses، الإصدار 4 هذه الوظائف.

يصف SVr4 قيم الإرجاع الناجحة فقط بأنها "قيمة عدد صحيح بخلاف ERR".

التاريخ

نفذ SVr4 (1989) هذه الوظائف تحت الأسماء inswch، winswch، mvinswch، و mvwinswch.

انظر أيضًا

curs_insch(3X) تصف وظائف مماثلة في تكوين curses الذي لا يستخدم الأحرف العريضة.
