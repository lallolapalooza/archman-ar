curl_multi_info_read(3)

الحزمة: curl

التراخيص: MIT

curl_multi_info_read(3) دليل الوظائف المكتبية curl_multi_info_read(3)

الاسم

curl_multi_info_read - قراءة معلومات المكدس المتعدد

الملخص

#include <curl/curl.h>
CURLMsg *curl_multi_info_read(CURLM *multi_handle, int *msgs_in_queue);

الوصف

اسأل المكدس المتعدد إذا كانت هناك أي رسائل من عمليات النقل الفردية. قد تشمل الرسائل معلومات مثل رمز خطأ من عملية النقل أو مجرد حقيقة اكتمال عملية النقل. يجب توضيح المزيد من التفاصيل حول هذه الأمور أيضًا.

تعيد الاستدعاءات المتكررة لهذه الوظيفة بنية جديدة في كل مرة، حتى يتم إرجاع NULL كإشارة إلى عدم وجود المزيد للحصول عليه في هذه النقطة. يحتوي العدد الصحيح المشار إليه بواسطة msgs_in_queue على عدد الرسائل المتبقية بعد استدعاء هذه الوظيفة.

عند جلب رسالة باستخدام هذه الوظيفة، يتم إزالتها من قائمة الانتظار الداخلية، لذا فإن استدعاء هذه الوظيفة مرة أخرى لا يعيد نفس الرسالة مرة أخرى. بدلاً من ذلك، يعيد رسائل جديدة في كل استدعاء جديد حتى يتم إفراغ قائمة الانتظار.

تحذير: البيانات التي يشير إليها المؤشر المرتجع لا تبقى عند استدعاء curl_multi_cleanup(3)، curl_multi_remove_handle(3) أو curl_easy_cleanup(3).

بنية CURLMsg بسيطة وتحتوي فقط على معلومات أساسية. إذا كانت هناك حاجة إلى معلومات أكثر تفصيلاً، فإن "مقبض سهل" معين موجود في تلك البنية ويمكن استخدامه في استدعاءات curl_easy_getinfo(3) اللاحقة العادية (أو ما شابه):

 struct CURLMsg {
   CURLMSG msg;       /* ما تعنيه هذه الرسالة */
   CURL *easy_handle; /* المقبض الذي تتعلق به */
   union {
     void *whatever;    /* بيانات خاصة بالرسالة */
     CURLcode result;   /* رمز النتيجة لعملية النقل */
   } data;
 };

عندما تكون msg هي CURLMSG_DONE، تحدد الرسالة عملية نقل مكتملة، ثم تحتوي result على رمز النتيجة للمقبض السهل الذي اكتمل للتو.

في هذه المرحلة، لا توجد أنواع msg أخرى محددة.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURLM *multi = curl_multi_init();
  CURL *curl = curl_easy_init();
  if(curl) {
    struct CURLMsg *m;
    /* استدعاء curl_multi_perform أو curl_multi_socket_action أولاً، ثم المرور عبر
       والتحقق مما إذا كانت هناك أي عمليات نقل اكتملت */
    do {
      int msgq = 0;
      m = curl_multi_info_read(multi, &msgq);
      if(m && (m->msg == CURLMSG_DONE)) {
        CURL *e = m->easy_handle;
        /* m->data.result يحتوي على رمز الخطأ لعملية النقل */
        curl_multi_remove_handle(multi, e);
        curl_easy_cleanup(e);
      }
    } while(m);
  }
}

التوفر

تمت الإضافة في curl 7.9.6

القيمة المعادة

مؤشر إلى بنية مملوءة، أو NULL إذا فشل أو نفدت البنى. كما أنه يكتب عدد الرسائل المتبقية في قائمة الانتظار (بعد هذا القراءة) في العدد الصحيح الذي يشير إليه الوسيط الثاني.
