CURLOPT_XFERINFOFUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_XFERINFOFUNCTION(3) دليل وظائف المكتبة CURLOPT_XFERINFOFUNCTION(3)

الاسم

CURLOPT_XFERINFOFUNCTION - دالة رد نداء لقياس التقدم

الملخص

#include <curl/curl.h>
int progress_callback(void *clientp,
                      curl_off_t dltotal,
                      curl_off_t dlnow,
                      curl_off_t ultotal,
                      curl_off_t ulnow);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_XFERINFOFUNCTION,
                          progress_callback);

الوصف

مرر مؤشرًا إلى دالة رد النداء الخاصة بك، والتي يجب أن تتطابق مع النموذج الأولي الموضح أعلاه.

سيتم استدعاء هذه الدالة بواسطة libcurl بدلاً من نظيرتها الداخلية بفاصل زمني متكرر. أثناء نقل البيانات، يتم استدعاؤها بشكل متكرر، وخلال فترات البطء مثل عندما لا يتم نقل أي شيء، يمكن أن تبطئ إلى حوالي مكالمة واحدة في الثانية.

clientp هو المؤشر الذي تم تعيينه باستخدام CURLOPT_XFERINFODATA(3)، ولا يستخدمه libcurl ولكن يتم تمريره فقط من التطبيق إلى دالة رد النداء.

يتم إخبار دالة رد النداء بكمية البيانات التي تتوقع libcurl نقلها والتي تم نقلها بالفعل، بعدد البايتات. dltotal هو العدد الإجمالي للبايتات التي تتوقع libcurl تنزيلها في هذا النقل. dlnow هو عدد البايتات التي تم تنزيلها حتى الآن. ultotal هو العدد الإجمالي للبايتات التي تتوقع libcurl تحميلها في هذا النقل. ulnow هو عدد البايتات التي تم تحميلها حتى الآن.

القيم الوسيطة غير المعروفة/غير المستخدمة التي تم تمريرها إلى دالة رد النداء يتم تعيينها إلى صفر (مثل إذا كنت تقوم بتنزيل البيانات فقط، فإن حجم التحميل يظل 0). في كثير من الأحيان، يتم استدعاء دالة رد النداء مرة واحدة أو أكثر أولاً، قبل أن تعرف أحجام البيانات، لذا يجب أن يكون البرنامج قادرًا على التعامل مع ذلك.

أرجع صفرًا من دالة رد النداء إذا كان كل شيء على ما يرام.

أرجع 1 من دالة رد النداء هذه لجعل libcurl يوقف النقل ويرجع CURLE_ABORTED_BY_CALLBACK.

إذا قامت دالة رد النداء الخاصة بك بإرجاع CURL_PROGRESSFUNC_CONTINUE، فإنها تجعل libcurl يواصل تنفيذ دالة التقدم الافتراضية.

إذا كنت تنقل البيانات باستخدام الواجهة المتعددة، فلن يتم استدعاء هذه الدالة خلال فترات الخمول ما لم تستدعي دالة libcurl المناسبة التي تنفذ عمليات النقل.

CURLOPT_NOPROGRESS(3) يجب تعيينها إلى 0 لجعل هذه الدالة يتم استدعاؤها فعليًا.

الافتراضي

NULL - استخدم مقياس التقدم الداخلي. نادرًا ما يرغب المستخدمون في ذلك.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct progress {
  char *private;
  size_t size;
};
static int xferinfo_callback(void *clientp,
                             curl_off_t dltotal,
                             curl_off_t dlnow,
                             curl_off_t ultotal,
                             curl_off_t ulnow)
{
  struct progress *memory = clientp;
  printf("my ptr: %p\n", memory->private);
  /* Use the values */
  return 0; /* all is good */
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct progress data;
    /* Pass struct to callback  */
    curl_easy_setopt(curl, CURLOPT_XFERINFODATA, &data);
    /* Enable progress callback getting called */
    curl_easy_setopt(curl, CURLOPT_NOPROGRESS, 0L);
    curl_easy_setopt(curl, CURLOPT_XFERINFOFUNCTION, xferinfo_callback);
  }
}

التوفر

تمت الإضافة في curl 7.32.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء على ما يرام، وغير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
