curl_formget(3)

الحزمة: curl

التراخيص: MIT

curl_formget(3) دليل الوظائف المكتبية curl_formget(3)

الاسم

curl_formget - تسلسل سلسلة POST لتشكل متعدد الأجزاء

الملخص

#include <curl/curl.h>
int curl_formget(struct curl_httppost * form, void *userp,
                 curl_formget_callback append);

الوصف

تم إيقاف واجهة برمجة تطبيقات النموذج (بما في ذلك هذه الوظيفة) منذ libcurl 7.56.0.

تقوم curl_formget() بتسلسل البيانات التي تم بناؤها مسبقًا باستخدام curl_formadd(3). تقبل مؤشر void كوسيط ثانٍ يسمى userp والذي يتم تمريره كوسيط أول لوظيفة curl_formget_callback.

 typedef size_t (*curl_formget_callback)(void *userp, const char *buf,
                                         size_t len);"

يتم استدعاء curl_formget_callback لكل جزء من سلسلة HTTP POST. يجب عدم تحرير المخزن المؤقت للأحرف الذي تم تمريره إلى الاستدعاء. يجب أن تعيد الاستدعاء طول المخزن المؤقت الذي تم تمريره إليها عند النجاح.

إذا تم استخدام خيار CURLFORM_STREAM في نموذج POST، فإنه يمنع curl_formget(3) من العمل حتى تقوم بإجراء طلب HTTP الفعلي. هذا، لأن libcurl يعرف فقط أي استدعاء قراءة فعلي يجب استخدامه.

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

size_t print_httppost_callback(void *arg, const char *buf, size_t len)
{
  fwrite(buf, len, 1, stdout);
  (*(size_t *) arg) += len;
  return len;
}
size_t print_httppost(struct curl_httppost *post)
{
  size_t total_size = 0;
  if(curl_formget(post, &total_size, print_httppost_callback)) {
    return (size_t) -1;
  }
  return total_size;
}
