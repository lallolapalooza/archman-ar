CURLOPT_TRAILERFUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_TRAILERFUNCTION(3) دليل وظائف المكتبة CURLOPT_TRAILERFUNCTION(3)

الاسم

CURLOPT_TRAILERFUNCTION - دالة رد اتصال لإرسال رؤوس زائدة

الملخص

#include <curl.h>
int curl_trailer_callback(struct curl_slist ** list, void *userdata);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRAILERFUNCTION,
                          curl_trailer_callback *func);

الوصف

مرر مؤشرًا إلى دالة رد اتصال.

يتم استدعاء دالة رد الاتصال هذه مرة واحدة قبل إرسال رمز CR LF النهائي في نقل HTTP مجزأ لملء قائمة الرؤوس الزائدة التي سيتم إرسالها قبل إنهاء نقل HTTP.

يمكنك تعيين وسيطة userdata باستخدام الخيار CURLOPT_TRAILERDATA(3).

يجب ألا تكون الرؤوس الزائدة المتضمنة في القائمة المترابطة منتهية بـ CRLF، لأن libcurl تضيف أحرف الإنهاء المناسبة لكل عنصر رأس.

إذا استخدمت curl_slist_append(3) لإضافة رؤوس زائدة إلى curl_slist، فإن libcurl تقوم بتكرار السلاسل النصية، وتحرر curl_slist بمجرد إرسال الرؤوس الزائدة.

إذا لم يتم تنسيق أحد حقول الرأس الزائدة بشكل صحيح، فسيتم تجاهله وإصدار رسالة معلومات.

يمكن أن تكون قيمة الإرجاع إما CURL_TRAILERFUNC_OK أو CURL_TRAILERFUNC_ABORT، والتي ستوجه libcurl إما للاستمرار في إرسال الرؤوس الزائدة أو إلغاء الطلب.

إذا قمت بتعيين هذا الخيار إلى NULL، فإن النقل يستمر كالمعتاد بدون أي مقاطعات.

NULL

البروتوكولات

تؤثر هذه الوظيفة على HTTP فقط

مثال

extern size_t read_cb(char *ptr, size_t size,
                      size_t nmemb, void *userdata);
static int trailer_cb(struct curl_slist **tr, void *data)
{
  /* libcurl تحرر القائمة */
  *tr = curl_slist_append(*tr, "My-super-awesome-trailer: trailer-stuff");
  return CURL_TRAILERFUNC_OK;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    /* تعيين عنوان URL للطلب */
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* الآن قم بتعيينه كـ put */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* نفترض أن لدينا دالة تعيد البيانات المراد دفعها
       لتكن تلك الدالة read_cb */
    curl_easy_setopt(curl, CURLOPT_READFUNCTION, read_cb);
    struct curl_slist *headers = NULL;
    headers = curl_slist_append(headers, "Trailer: My-super-awesome-trailer");
    res = curl_easy_setopt(curl, CURLOPT_HTTPHEADER, headers);
    /* تعيين دالة رد الاتصال لملء الرؤوس الزائدة */
    curl_easy_setopt(curl, CURLOPT_TRAILERFUNCTION, trailer_cb);
    /* إجراء النقل */
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
    curl_slist_free_all(headers);
  }
}

التوفر

تمت الإضافة في curl 7.64.0

قيمة الإرجاع

curl_easy_setopt(3) تعيد CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
