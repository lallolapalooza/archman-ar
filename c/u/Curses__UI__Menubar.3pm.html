Curses__UI__Menubar(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Menubar(3) وثائق Perl من مساهمي المستخدم Curses::UI::Menubar(3)

الاسم

Curses::UI::Menubar - إنشاء ومعالجة عناصر واجهة القوائم

تسلسل الفئة

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Menubar

الملخص

use Curses::UI;
my $cui = new Curses::UI;
# تحديد بنية بيانات القائمة.
my $menu_data = [....]; 
my $menu = $cui->add( 
    'menu', 'Menubar',
    -menu => $menu_data
);
$menu->focus();

الوصف

يمكن استخدام هذه الفئة لإضافة شريط قوائم إلى Curses::UI. يمكن أن يحتوي شريط القوائم هذا على هرم فرعي كامل للقوائم. يبدو (عن بعد :-) كالتالي:

-------------------------------------
menu1 | menu2 | menu3 | ....
-------------------------------------
      +-------------+ 
      |menuitem 1   |
      |menuitem 2   |+--------------+
      |menuitem 3 >>||submenuitem 1 |
      |menuitem 4   ||submenuitem 2 |
      +-------------+|submenuitem 3 | 
                     |submenuitem 4 | 
                     |submenuitem 5 |
                     +--------------+

راجع exampes/demo-Curses::UI::Menubar في التوزيع التجريبي لفترة قصيرة.

خيارات قياسية

لا تستخدم هذه الفئة أيًا من الخيارات القياسية التي توفرها Curses::UI::Widget.

خيارات خاصة بالعنصر

يوجد خيار واحد فقط: -menu. قيمة هذا الخيار هي ARRAYREF. يتصرف ARRAYREF هذا تمامًا كما هو موصوف في Curses::UI::MenuListbox. الفرق هو أنه بالنسبة للقائمة الرئيسية، ستستخدم فقط -submenu. هيكل بيانات مثال:

my $menu1 = [
    { -label => 'option 1', -value => '1-1' },
    { -label => 'option 2', -value => '1-2' },
    { -label => 'option 3', -value => '1-3' },
];
my $menu2 = [
    { -label => 'option 1', -value => \&sel1 },
    { -label => 'option 2', -value => \&sel2 },
    { -label => 'option 3', -value => \&sel3 },
];
my $submenu = [
    { -label => 'suboption 1', -value => '3-3-1' },
    { -label => 'suboption 2', -callback=> \&do_it },
];
my $menu3 = [
    { -label => 'option 1', -value => \&sel2 },
    { -label => 'option 2', -value => \&sel3 },
    { -label => 'submenu 1', -submenu => $submenu },
];
my $menu = [
    { -label => 'menu 1', -submenu => $menu1 },
    { -label => 'menu 2', -submenu => $menu2 }
    { -label => 'menu 3', -submenu => $menu3 }
];

الروابط الافتراضية

  • <escape>

    استدعاء روتين 'escape'. سيؤدي هذا إلى فقدان شريط القوائم للتركيز وإعادة القيمة 'ESCAPE' إلى الروتين المستدعي.

  • <tab>

    استدعاء روتين 'return'. سيؤدي هذا إلى فقدان شريط القوائم للتركيز وإعادة القيمة 'LOOSE_FOCUS' إلى الروتين المستدعي.

  • <cursor-down>, <j>, <enter>

    استدعاء روتين 'pulldown'. سيؤدي هذا إلى فتح menulistbox للقائمة الحالية ومنح menulistbox هذا التركيز. ما يحدث بعد أن يفقد menulistbox التركيز يعتمد على القيمة المعادة منه:

    * القيمة 'CURSOR_LEFT'

    استدعاء روتين 'cursor-left' وبعد ذلك
استدعاء روتين 'pulldown'. لذلك سيفتح
menulistbox للقائمة السابقة.

    * القيمة 'CURSOR_RIGHT'

    استدعاء روتين 'cursor-right' وبعد ذلك
استدعاء روتين 'pulldown'. لذلك سيفتح
menulistbox للقائمة التالية.

    * القيمة 'LOOSE_FOCUS'

    سيحتفظ شريط القوائم بالتركيز، ولكن لن
يتم فتح أي menulistbox.

    * القيمة 'ESCAPE'

    سيفقد شريط القوائم تركيزه وسيعيد
القيمة 'ESCAPE' إلى الروتين المستدعي.

    * مرجع CODE

    سيتم تنفيذ الكود، وسيفقد شريط القوائم تركيزه
وسيتم إعادة قيمة CODE إلى
الروتين المستدعي.

    * أي قيمة أخرى

    سيفقد شريط القوائم تركيزه وسيتم
إعادة القيمة إلى الروتين المستدعي.
  • <cursor-left>, <h>

    استدعاء روتين 'cursor-left'. سيؤدي هذا إلى تحديد القائمة السابقة. إذا تم تحديد القائمة الأولى بالفعل، فسيتم تحديد القائمة الأخيرة.

  • <cursor-right>, <l>

    استدعاء روتين 'cursor-right'. سيؤدي هذا إلى تحديد القائمة التالية. إذا تم تحديد القائمة الأخيرة بالفعل، فسيتم تحديد القائمة الأولى.
