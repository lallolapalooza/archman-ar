curs_border(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_border(3X) استدعاءات المكتبة curs_border(3X)

الاسم

border, wborder, box, hline, whline, vline, wvline, mvhline, mvwhline, mvvline, mvwvline - رسم حدود وخطوط في نافذة curses من الأحرف

الملخص

#include <curses.h>
int border(chtype ls, chtype rs, chtype ts, chtype bs,
           chtype tl, chtype tr, chtype bl, chtype br);
int wborder(WINDOW *win, chtype ls, chtype rs,
            chtype ts, chtype bs, chtype tl, chtype tr,
            chtype bl, chtype br);
int box(WINDOW *win, chtype verch, chtype horch);
int hline(chtype ch, int n);
int whline(WINDOW *win, chtype ch, int n);
int vline(chtype ch, int n);
int wvline(WINDOW *win, chtype ch, int n);
int mvhline(int y, int x, chtype ch, int n);
int mvwhline(WINDOW *win, int y, int x, chtype ch, int n);
int mvvline(int y, int x, chtype ch, int n);
int mvwvline(WINDOW *win, int y, int x, chtype ch, int n);

الوصف

تقوم الإجراءات border و wborder و box برسم مربع حول حواف النافذة. بخلاف النافذة، كل وسيط هو حرف مع سمات:

ls - الجانب الأيسر،
rs - الجانب الأيمن،
ts - الجانب العلوي،
bs - الجانب السفلي،
tl - الزاوية العلوية اليسرى،
tr - الزاوية العلوية اليمنى،
bl - الزاوية السفلية اليسرى، و
br - الزاوية السفلية اليمنى.

إذا كان أي من هذه الوسائط صفراً، فسيتم استخدام القيم الافتراضية المقابلة (المعرفة في curses.h) بدلاً من ذلك:

ACS_VLINE،
ACS_VLINE،
ACS_HLINE،
ACS_HLINE،
ACS_ULCORNER،
ACS_URCORNER،
ACS_LLCORNER،
ACS_LRCORNER.

box(win, verch, horch) هو اختصار للاستدعاء التالي: wborder(win, verch, verch, horch, horch, 0, 0, 0, 0).

ترسم الوظائف hline و whline خطًا أفقيًا (من اليسار إلى اليمين) باستخدام ch بدءًا من الموضع الحالي للمؤشر في النافذة. لا يتغير موضع المؤشر الحالي. طول الخط هو n حرفًا على الأكثر، أو بقدر ما يتسع في النافذة.

ترسم الوظائف vline و wvline خطًا رأسيًا (من أعلى إلى أسفل) باستخدام ch بدءًا من الموضع الحالي للمؤشر في النافذة. لا يتغير موضع المؤشر الحالي. طول الخط هو n حرفًا على الأكثر، أو بقدر ما يتسع في النافذة.

قيمة الإرجاع

تُرجع جميع الإجراءات القيمة الصحيحة OK. تقول وثائق SVr4.0 "أو عدد صحيح غير سالب إذا تم تعيين immedok"، ولكن يبدو أن هذا خطأ.

لا تحدد X/Open Curses أي ظروف خطأ. يُرجع هذا التنفيذ خطأ إذا كان مؤشر النافذة فارغًا.

الوظائف التي تبدأ بـ "mv" تقوم أولاً بتحريك المؤشر وتفشل إذا كان الموضع (y، x) خارج حدود النافذة.

ملاحظات

الحدود التي تم إنشاؤها بواسطة هذه الوظائف هي حدود داخلية (وهذا ينطبق أيضًا على curses SVr4، على الرغم من أن هذه الحقيقة ليست موثقة).

لاحظ أن border و box قد تكون وحدات ماكرو.

قابلية النقل

تم وصف هذه الوظائف في X/Open Curses، الإصدار 4.
