CURLOPT_KEEP_SENDING_ON_ERROR(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_KEEP_SENDING_ON_ERROR(3) دليل وظائف المكتبة CURLOPT_KEEP_SENDING_ON_ERROR(3)

الاسم

CURLOPT_KEEP_SENDING_ON_ERROR - استمر في الإرسال عند استجابة HTTP مبكرة >= 300

الخلاصة

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_KEEP_SENDING_ON_ERROR,
                          long keep_sending);

الوصف

يعمل المعامل الطويل الذي يتم تعيينه على 1 على إخبار المكتبة بالاستمرار في إرسال جسم الطلب إذا كان رمز HTTP المُعاد يساوي 300 أو أكبر. الإجراء الافتراضي هو إيقاف الإرسال وإغلاق التدفق أو الاتصال.

هذا الخيار مناسب للمصادقة اليدوية NTLM، أي إذا لم يستخدم التطبيق CURLOPT_HTTPAUTH(3)، ولكنه بدلاً من ذلك يضبط رؤوس "Authorization: NTLM ..." يدويًا باستخدام CURLOPT_HTTPHEADER(3).

معظم التطبيقات لا تحتاج إلى هذا الخيار.

الافتراضي

0، توقف عن الإرسال عند الخطأ

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode ret;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_POSTFIELDS, "sending data");
    curl_easy_setopt(curl, CURLOPT_KEEP_SENDING_ON_ERROR, 1L);
    ret = curl_easy_perform(curl);
  }
}

التوفر

تمت إضافته في curl 7.51.0

قيمة الإرجاع

curl_easy_setopt(3) تُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).

انظر أيضًا
