CURLOPT_HSTSREADDATA(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_HSTSREADDATA(3) دليل وظائف المكتبة CURLOPT_HSTSREADDATA(3)

الاسم

CURLOPT_HSTSREADDATA - مؤشر يتم تمريره إلى دالة قراءة HSTS.

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSREADDATA, void *pointer);

الوصف

مؤشر pointer يتم تمريره إلى وظيفة قراءة HSTS. إذا كنت تستخدم خيار CURLOPT_HSTSREADFUNCTION(3)، فهذا هو المؤشر الذي تحصل عليه كمدخل في الوسيطة الثالثة للدالة الراجعة.

هذا الخيار لا يمكّن HSTS، تحتاج إلى استخدام CURLOPT_HSTS_CTRL(3) للقيام بذلك.

الافتراضي

NULL

البروتوكولات

هذه الوظيفة تؤثر على HTTP فقط.

مثال

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "http://example.com");
    /* تمرير مؤشر يتم تمريره إلى دالة
       CURLOPT_HSTSREADFUNCTION الراجعة */
    curl_easy_setopt(curl, CURLOPT_HSTSREADDATA, &this);
    curl_easy_perform(curl);
  }
}

التوفر

تمت الإضافة في curl 7.74.0

قيمة الإرجاع

هذه تعيد CURLE_OK.
