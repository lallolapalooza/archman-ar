Curses__UI__Common(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Common(3) وثائق Perl المساهمة من المستخدم Curses::UI::Common(3)

الاسم

Curses::UI::Common - طرق مشتركة لـ Curses::UI

هيكل الفئة

Curses::UI::Common - الفئة الأساسية

الملخص

package MyPackage;
use Curses::UI::Common;
use vars qw(@ISA);
@ISA = qw(Curses::UI::Common);

الوصف

Curses::UI::Common هي مجموعة من الطرق المشتركة بين فئات Curses::UI.

الطرق

طرق متنوعة

  • parent ( )

    تُرجع العضو البيانات $this->{-parent}.

  • root ( )

    تُرجع العضو البيانات الأعلى -parent (مثيل Curses::UI).

  • delallwin ( )

    هذه الطريقة ستجتاز جميع أعضاء البيانات الخاصة بمثيل الفئة. سيتم حذف كل عضو بيانات ينحدر من Curses::Window.

  • accessor ( NAME, [VALUE] )

    إذا تم تعيين VALUE، فسيتم تغيير قيمة عضو البيانات $this->{NAME}. ستُرجع الطريقة القيمة الحالية لعضو البيانات $this->{NAME}.

  • keys_to_lowercase ( HASHREF )

    سيتم تحويل جميع المفاتيح في الـ hash المشار إليها بواسطة HASHREF إلى أحرف صغيرة.

معالجة النص

split_to_lines ( TEXT )
ستقسم هذه الطريقة TEXT إلى قائمة من الأسطر المنفصلة. تُرجع مرجعًا لهذه القائمة.
scrlength ( LINE )
تُرجع طول الشاشة للسلسلة LINE. الفرق مع الدالة perl length() هو أن هذه الطريقة ستوسع أحرف TAB. يتم تصديرها بواسطة هذه الفئة وقد يتم استدعاؤها كروتين مستقل.
text_dimension ( TEXT )
ستُرجع هذه الطريقة مصفوفة تحتوي على العرض (طول أطول سطر) والارتفاع (عدد الأسطر) للنص TEXT.
text_wrap ( LINE, LENGTH, WORDWRAP )
WORDWRAP ( )
NO_WORDWRAP ( )
ستقوم هذه الطريقة بلف سطر النص (LINE) إلى طول معين (LENGTH). إذا كان الوسيط WORDWRAP صحيحًا، فسيتم تمكين التفاف الكلمات (وهذا هو الوضع الافتراضي لـ WORDWRAP). ستُرجع مرجعًا لقائمة بالأسطر الملفوفة. يتم تصديرها بواسطة هذه الفئة وقد يتم استدعاؤها كروتين مستقل.

ستُرجع الروتينات WORDWRAP و NO_WORDWRAP القيمة الصحيحة للوسيط WORDWRAP. يتم تصدير هذه الروتينات بواسطة هذه الفئة.

مثال:

$this->text_wrap($line, 50, NO_WORDWRAP);

قراءة إدخال المفاتيح

CUI_ESCAPE ( )
CUI_TAB ( )
CUI_SPACE ( )
هذه بضعة روتينات ليست معرفة بواسطة وحدة Curses، ولكن قد تكون مفيدة على أي حال. يتم تصدير هذه الروتينات بواسطة هذه الفئة.
get_key ( BLOCKTIME, CURSOR )
ستحاول هذه الطريقة قراءة مفتاح من لوحة المفاتيح. ستُرجع المفتاح المضغوط أو -1 إذا لم يتم الضغط على أي مفتاح. يتم تصديرها بواسطة هذه الفئة وقد يتم استدعاؤها كروتين مستقل.

يمكن استخدام الوسيط BLOCKTIME لتعيين نصف التأخير لـ curses (الوقت اللازم للانتظار قبل أن تقرر الطريقة عدم الضغط على أي مفتاح). يتم إعطاء BLOCKTIME بالعشر من الثانية. القيمة الافتراضية هي 0 (قراءة مفتاح غير مانعة).

مثال:

my $key = $this->get_key(5)
