curl_mime_filename(3)

الحزمة: curl

التراخيص: MIT

curl_mime_filename(3) دليل الوظائف المكتبية curl_mime_filename(3)

الاسم

curl_mime_filename - تعيين اسم ملف بعيد لجزء MIME

الملخص

#include <curl/curl.h>
CURLcode curl_mime_filename(curl_mimepart *part,
                            const char *filename);

الوصف

curl_mime_filename(3) يعين اسم ملف بعيد لجزء MIME. عند تعيين اسم ملف بعيد، يتم معالجة بيانات المحتوى كملف، بغض النظر عن مصدر محتوى الجزء. يتم إرسال اسم الملف البعيد للجزء إلى الخادم في ترويسة Content-Disposition المرتبطة والتي تم إنشاؤها.

part هو مقبض الجزء الذي سيتم تعيين اسم الملف البعيد له.

filename يشير إلى سلسلة اسم الملف المنتهية بصفر؛ يمكن تعيينه إلى NULL لإزالة اسم ملف بعيد تم إرفاقه مسبقًا.

يتم نسخ سلسلة اسم الملف البعيد إلى الجزء، وبالتالي يمكن تحرير التخزين المرتبط أو إعادة استخدامه بأمان بعد الاستدعاء. يعد تعيين اسم ملف لجزء عدة مرات أمرًا صالحًا: فقط القيمة التي تم تعيينها بواسطة آخر استدعاء يتم الاحتفاظ بها.

البروتوكولات

تؤثر هذه الوظيفة على http، imap و smtp

مثال

static char imagebuf[]="imagedata";
int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* إنشاء مقبض mime */
    mime = curl_mime_init(curl);
    /* إضافة جزء */
    part = curl_mime_addpart(mime);
    /* إرسال بيانات الصورة من الذاكرة */
    curl_mime_data(part, imagebuf, sizeof(imagebuf));
    /* تعيين اسم ملف لجعله يبدو وكأنه تحميل ملف */
    curl_mime_filename(part, "image.png");
    /* تعيين الاسم */
    curl_mime_name(part, "data");
  }
}

التوفر

تمت الإضافة في curl 7.56.0

قيمة الإرجاع

تقوم هذه الوظيفة بإرجاع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيم غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3). إذا تم تعيين CURLOPT_ERRORBUFFER(3) باستخدام curl_easy_setopt(3) فقد توجد رسالة خطأ مخزنة في مخزن الأخطاء عند إرجاع قيمة غير صفرية.
