curs_add_wch(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_add_wch(3X) استدعاءات المكتبة curs_add_wch(3X)

الاسم

add_wch, wadd_wch, mvadd_wch, mvwadd_wch, echo_wchar, wecho_wchar - إضافة حرف مركب curses إلى نافذة وتقدم المؤشر

الملخص

#include <curses.h>
int add_wch(const cchar_t *wch);
int wadd_wch(WINDOW *win, const cchar_t *wch);
int mvadd_wch(int y, int x, const cchar_t *wch);
int mvwadd_wch(WINDOW *win, int y, int x, const cchar_t *wch);
int echo_wchar(const cchar_t *wch);
int wecho_wchar(WINDOW *win, const cchar_t *wch);

الوصف

add_wch

تقوم الدوال add_wch، wadd_wch، mvadd_wch، و mvwadd_wch بوضع الحرف المركب wch في النافذة المعطاة في موضعها الحالي، والذي يتم تقديمه بعد ذلك. تقوم هذه الدوال بإجراءات التفاف ومعالجة الأحرف الخاصة كما يلي:

•
إذا كان wch يشير إلى حرف فاصل، فيتم إزالة أي حرف سابق في هذا الموقع. يتم وضع حرف جديد محدد بواسطة wch في هذا الموقع مع التصيير المحدد بواسطة wch. ثم يتقدم المؤشر بعد هذا الحرف الفاصل، للتحضير لكتابة الحرف التالي على الشاشة.
الحرف الفاصل المضاف حديثًا هو أساس الحرف المركب النشط. يمكن إضافة أحرف غير فاصلة لاحقة إلى هذا الأساس حتى يتم كتابة حرف فاصل آخر على الشاشة، أو يتم نقل المؤشر، على سبيل المثال، باستخدام wmove.
•
إذا كان wch يشير إلى حرف غير فاصل، فسيتم إلحاقه بالحرف المركب النشط، مع الاحتفاظ بالأحرف السابقة في هذا الموقع. يتم تجاهل التصيير المحدد بواسطة wch.
لا يتقدم المؤشر بعد إضافة حرف غير فاصل. ستقوم استدعاءات الأحرف غير الفاصلة اللاحقة بتحديث نفس الموقع.
•
إذا كان جزء الحرف من wch هو علامة جدولة، أو سطر جديد، أو حرف مسافة للخلف، أو رمز تحكم آخر، فسيتم تحديث النافذة وسيتحرك المؤشر كما لو تم استدعاء addch.

echo_wchar

الدالة echo_wchar مكافئة وظيفيًا لاستدعاء add_wch يليه استدعاء لـ refresh(3X). وبالمثل، فإن الدالة wecho_wchar مكافئة وظيفيًا لاستدعاء wadd_wch يليه استدعاء لـ wrefresh. يتم أخذ المعرفة بأن حرفًا واحدًا فقط يتم إخراجه في الاعتبار، وبالنسبة للأحرف غير الخاصة بالتحكم، يمكن رؤية مكسب كبير في الأداء باستخدام دوال *echo* بدلاً من مكافئاتها.
