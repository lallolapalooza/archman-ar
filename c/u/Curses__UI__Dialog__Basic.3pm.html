Curses__UI__Dialog__Basic(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Dialog::Basic(3) توثيق Perl مساهمة من المستخدم Curses::UI::Dialog::Basic(3)

الاسم

Curses::UI::Dialog::Basic - إنشاء ومعالجة مربعات الحوار الأساسية

تسلسل الفئات

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
           |
           +----Curses::UI::Dialog::Basic

الملخص

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# الطريقة الصعبة.
# -------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Basic',
-message   => 'Hello, world!'
);
$dialog->focus;
$win->delete('mydialog');
# الطريقة السهلة (انظر توثيق Curses::UI).
# --------------------------------------------
my $buttonvalue = $cui->dialog(-message => 'Hello, world!');
# أو حتى
$cui->dialog('Hello, world!');

الوصف

Curses::UI::Dialog::Basic هو مربع حوار أساسي. يحتوي هذا النوع من مربعات الحوار على رسالة وزر واحد أو أكثر. يمكن استخدامه لعرض رسالة لمستخدم برنامجك ("تم تحديث الشيء") أو للحصول على نوع من التأكيد من المستخدم ("هل أنت متأكد من رغبتك في تحديث الشيء؟").

راجع exampes/demo-Curses::UI::Dialog::Basic في التوزيع لعرض توضيحي قصير.

خيارات

  • -title < نص >

    تعيين عنوان نافذة مربع الحوار إلى نص.

  • -message < نص >

    يقوم هذا الخيار بتعيين الرسالة المراد عرضها إلى نص. قد يحتوي النص على أحرف سطر جديد (\n).

  • -buttons < ARRAYREF >
  • -selected < INDEX >
  • -buttonalignment < VALUE >

    تحدد هذه الخيارات الأزرار التي يجب استخدامها. لشرح هذه الخيارات، راجع توثيق Curses::UI::Buttonbox.

طرق

  • new ( HASH )
  • layout ( )
  • draw ( BOOLEAN )
  • focus ( )

    هذه طرق قياسية. راجع Curses::UI::Container لشرحها.

  • get ( )

    ستقوم هذه الطريقة باستدعاء get على كائن الأزرار الخاص بمربع الحوار وإرجاع قيمته. راجع Curses::UI::Buttonbox لمزيد من المعلومات حول هذا.

انظر أيضًا

Curses::UI, Curses::UI::Container, Curses::UI::Buttonbox
