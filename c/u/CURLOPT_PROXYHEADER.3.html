CURLOPT_PROXYHEADER(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROXYHEADER(3) دليل الدوال المكتبية CURLOPT_PROXYHEADER(3)

الاسم

CURLOPT_PROXYHEADER - مجموعة رؤوس HTTP التي سيتم تمريرها إلى الوكيل

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXYHEADER,
                          struct curl_slist *headers);

الوصف

تمرير مؤشر إلى قائمة مرتبطة برؤوس HTTP ليتم إرسالها في طلب HTTP الخاص بك إلى وكيل. قواعد هذه القائمة متطابقة مع قواعد خيار CURLOPT_HTTPHEADER(3).

الرؤوس المعينة باستخدام هذا الخيار تُستخدم فقط في الطلبات المرسلة إلى وكيل - عندما يكون هناك أيضًا طلب مرسل إلى مضيف.

السطر الأول في الطلب (الذي يحتوي على الطريقة، عادةً GET أو POST) ليس رأسًا ولا يمكن استبداله باستخدام هذا الخيار. فقط الأسطر التي تلي سطر الطلب هي رؤوس. إضافة سطر الطريقة هذا في قائمة الرؤوس هذه يتسبب في إرسال طلب غير صالح.

استخدام هذا الخيار عدة مرات يجعل القائمة الأخيرة المعينة تلغي ما قبلها. قم بتعيينها إلى NULL لتعطيل استخدامها مرة أخرى.

libcurl لا ينسخ القائمة، يجب الاحتفاظ بها حتى اكتمال النقل.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  struct curl_slist *list;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_PROXY, "http://proxy.example.com:80");
    list = curl_slist_append(NULL, "Shoesize: 10");
    list = curl_slist_append(list, "Accept:");
    curl_easy_setopt(curl, CURLOPT_PROXYHEADER, list);
    curl_easy_perform(curl);
    curl_slist_free_all(list); /* free the list again */
  }
}

التوفر

تمت الإضافة في curl 7.37.0

قيمة الإرجاع

curl_easy_setopt(3) تُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
