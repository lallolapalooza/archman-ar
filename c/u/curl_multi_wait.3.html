curl_multi_wait(3)

الحزمة: curl

التراخيص: MIT

curl_multi_wait(3) دليل وظائف المكتبة curl_multi_wait(3)

الاسم

curl_multi_wait - استقصاء جميع الواجهات السهلة في واجهة متعددة

المختصر

#include <curl/curl.h>
CURLMcode curl_multi_wait(CURLM *multi_handle,
                          struct curl_waitfd extra_fds[],
                          unsigned int extra_nfds,
                          int timeout_ms,
                          int *numfds);

الوصف

curl_multi_wait(3) تستقصي جميع واجهات الملفات المستخدمة بواسطة الواجهات السهلة لـ curl الموجودة في مجموعة الواجهة المتعددة المعطاة. إنها تحظر حتى يتم اكتشاف نشاط على مقبض واحد على الأقل أو انقضاء timeout_ms. بدلاً من ذلك، إذا كان لدى الواجهة المتعددة مهلة داخلية معلقة لها وقت انتهاء صلاحية أقصر من timeout_ms، فسيتم استخدام هذا الوقت الأقصر بدلاً من ذلك لضمان الحفاظ على دقة المهلة بشكل معقول.

قد يمرر التطبيق المتصل هياكل curl_waitfd إضافية مشابهة لهياكل pollfd الخاصة بـ poll(2) ليتم انتظارها في نفس الاستدعاء.

عند الانتهاء، إذا كان numfds غير فارغ (non-NULL)، فسيتم ملؤه بالعدد الإجمالي لواجهات الملفات التي حدثت عليها أحداث مثيرة للاهتمام. يمكن أن يشمل هذا العدد واجهات libcurl الداخلية بالإضافة إلى الواجهات المقدمة في extra_fds.

إذا لم يتم توفير واجهات ملفات إضافية ولم يكن لدى libcurl واجهة ملف لتقديمها للانتظار، تعود هذه الوظيفة على الفور. (ضع في اعتبارك استخدام curl_multi_poll(3) لتجنب هذا السلوك.)

يُشجع على استخدام هذه الوظيفة بدلاً من select(3) عند استخدام الواجهة المتعددة للسماح للتطبيقات بتجاوز مشكلة الحد الشائع البالغ 1024 واجهة ملف بسهولة.

curl_waitfd

struct curl_waitfd {
  curl_socket_t fd;
  short events;
  short revents;
};
CURL_WAIT_POLLIN
علامة بت لـ curl_waitfd.events تشير إلى أنه يجب على المقبس الاستقصاء عن أحداث القراءة مثل تلقي بيانات جديدة.
CURL_WAIT_POLLPRI
علامة بت لـ curl_waitfd.events تشير إلى أنه يجب على المقبس الاستقصاء عن أحداث القراءة ذات الأولوية العالية مثل البيانات خارج النطاق.
CURL_WAIT_POLLOUT
علامة بت لـ curl_waitfd.events تشير إلى أنه يجب على المقبس الاستقصاء عن أحداث الكتابة مثل أن يكون المقبس جاهزًا للكتابة دون حظر.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *easy;
  CURLM *multi = curl_multi_init();
  int still_running;
  easy = curl_easy_init();
  /* إضافة الواجهة الفردية السهلة */
  curl_multi_add_handle(multi, easy);
  do {
    CURLMcode mc;
    int numfds;
    mc = curl_multi_perform(multi, &still_running);
    if(mc == CURLM_OK) {
      /* الانتظار للنشاط، أو انتهاء المهلة، أو "لا شيء" */
      mc = curl_multi_wait(multi, NULL, 0, 1000, &numfds);
    }
    if(mc != CURLM_OK) {
      fprintf(stderr, "curl_multi failed, code %d.\n", mc);
      break;
    }
  } while(still_running);
  curl_multi_remove_handle(multi, easy);
}

التوفر

تمت الإضافة في curl 7.28.0

قيمة الإرجاع

ترجع هذه الوظيفة قيمة CURLMcode تشير إلى النجاح أو الخطأ.

CURLM_OK (0) يعني أن كل شيء كان على ما يرام، وقيمة غير صفرية تعني حدوث خطأ، انظر libcurl-errors(3).
