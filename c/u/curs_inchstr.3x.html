curs_inchstr(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_inchstr(3X) استدعاءات المكتبة curs_inchstr(3X)

الاسم

inchstr، inchnstr، winchstr، winchnstr، mvinchstr، mvinchnstr، mvwinchstr، mvwinchnstr - الحصول على سلسلة أحرف curses من نافذة

الملخص

#include <curses.h>
int inchstr(chtype *chstr);
int inchnstr(chtype *chstr, int n);
int winchstr(WINDOW *win, chtype *chstr);
int winchnstr(WINDOW *win, chtype *chstr, int n);
int mvinchstr(int y, int x, chtype *chstr);
int mvinchnstr(int y, int x, chtype *chstr, int n);
int mvwinchstr(WINDOW *win, int y, int x, chtype *chstr);
int mvwinchnstr(WINDOW *win, int y, int x, chtype *chstr, int n);

الوصف

تقوم هذه الروتينات بإرجاع مصفوفة من قيم chtype منتهية بـ NULL، بدءًا من موضع المؤشر الحالي في النافذة المسماة وتنتهي عند الهامش الأيمن للنافذة.

الوظائف الأربع التي تحتوي على n كوسيط أخير، ترجع سلسلة فرعية رائدة لا يزيد طولها عن n حرفًا (باستثناء (chtype)0 اللاحقة). يتوقف النقل عند نهاية السطر الحالي، أو عندما يتم تخزين n حرفًا في الموقع المشار إليه بواسطة chstr.

يمكن استخدام الثوابت المعرفة في <curses.h> مع المعامل & (AND المنطقي) لاستخراج الحرف أو السمات وحدها من أي موضع في chstr [راجع curs_inch(3X)].

قيمة الإرجاع

ترجع جميع الروتينات القيمة الصحيحة ERR عند الفشل وقيمة صحيحة بخلاف ERR عند النجاح (عدد الأحرف المسترجعة، باستثناء الـ 0 اللاحقة).

لا تحدد X/Open Curses أي ظروف خطأ. هذا التطبيق يرجع خطأ

  • إذا كان الوسيط win فارغًا أو
  • إذا كان الوسيط chstr فارغًا.

الوظائف التي تبدأ بـ "mv" تقوم أولاً بتحريك المؤشر وتفشل إذا كان الموضع (y، x) خارج حدود النافذة.

ملاحظات

جميع الروتينات باستثناء winchnstr قد تكون وحدات ماكرو.

لا توثق SVr4 ما إذا كانت سلسلة النتيجة منتهية بصفر؛ ولا توثق ما إذا كان وسيط حد الطول يشمل أي صفر لاحق؛ ولا توثق معنى قيمة الإرجاع.

قراءة سطر يتجاوز المصفوفة المشار إليها بواسطة chstr باستخدام inchstr، mvinchstr، mvwinchstr أو winchstr تؤدي إلى نتائج غير محددة. لذلك، يوصى باستخدام inchnstr، mvinchnstr، mvwinchnstr، أو winchnstr.

قابلية النقل

تم وصف هذه الوظائف في X/Open Curses، الإصدار 4. وهي ليست أكثر تحديدًا من توثيق SVr4 بشأن الصفر اللاحق. وهي تحدد أن الإرجاع الناجح للوظائف هو OK.
