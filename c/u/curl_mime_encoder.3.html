curl_mime_encoder(3)

الحزمة: curl

التراخيص: MIT

curl_mime_encoder(3) دليل وظائف المكتبة curl_mime_encoder(3)

الاسم

curl_mime_encoder - تعيين مشفّر جزء mime وترميز نقل المحتوى

الملخص

#include <curl/curl.h>
CURLcode curl_mime_encoder(curl_mimepart *part, const char *encoding);

الوصف

curl_mime_encoder() يطلب ترميز محتوى جزء mime قبل نقله.

part هو مقبض الجزء لتعيين مشفّر. encoding هو مؤشر إلى مخطط ترميز منتهي بـ NULL. قد يتم تعيينه إلى NULL لتعطيل مشفّر تم إرفاقه مسبقًا بالجزء. يمكن إعادة استخدام مساحة مخطط الترميز بأمان بعد إرجاع هذه الدالة.

يعد تعيين مشفّر جزء عدة مرات أمرًا صالحًا: فقط القيمة التي تم تعيينها بواسطة المكالمة الأخيرة يتم الاحتفاظ بها.

عند عرض أجزاء متعددة، يتم ترميز محتوى الجزء وفقًا للمخطط المعني، ويتم إضافة رأس "Content-Transfer-Encoding" المقابل إلى الجزء.

مخططات الترميز المدعومة هي:

"binary": يتم ترك البيانات دون تغيير، ويتم إضافة الرأس.

"8bit": يتم إضافة الرأس، ولا يتم تغيير البيانات.

"7bit": تظل البيانات دون تغيير، ولكن يتم التحقق من كل بايت للتأكد من أنه قيمة 7 بت؛ إذا لم يكن كذلك، يحدث خطأ في القراءة.

"base64": يتم تحويل البيانات إلى ترميز base64، ثم تقسيمها إلى أسطر تنتهي بـ CRLF بحد أقصى 76 حرفًا.

"quoted-printable": يتم ترميز البيانات في أسطر quoted-printable بحد أقصى 76 حرفًا. نظرًا لأنه لا يمكن تحديد الحجم الناتج للبيانات النهائية قبل قراءة البيانات الأصلية، يتم تركها على أنها غير معروفة، مما يتسبب في نقل مجمّع في HTTP. لنفس السبب، لا يمكن استخدام هذا المشفّر مع IMAP. يستهدف هذا المشفّر البيانات النصية التي هي في الغالب ASCII ولا ينبغي استخدامه مع أنواع أخرى من البيانات.

إذا كانت البيانات الأصلية مرمّزة بالفعل بهذا المخطط، فيجب إضافة رأس Content-Transfer-Encoding مخصص باستخدام curl_mime_headers(3) بدلاً من تعيين مشفّر للجزء.

لا ينبغي تطبيق الترميز على الأجزاء المتعددة، وبالتالي فإن استخدام هذه الدالة على جزء تم تعيين محتواه باستخدام curl_mime_subparts(3) غير مستحسن بشدة.

البروتوكولات

تؤثر هذه الوظيفة على http، imap، و smtp

مثال

int main(void)
{
  curl_mime *mime;
  curl_mimepart *part;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* إنشاء مقبض mime */
    mime = curl_mime_init(curl);
    /* إضافة جزء */
    part = curl_mime_addpart(mime);
    /* إرسال ملف */
    curl_mime_filedata(part, "image.png");
    /* ترميز بيانات الملف بـ base64 للنقل */
    curl_mime_encoder(part, "base64");
  }
}
