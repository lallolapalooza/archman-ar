curl_url_cleanup(3)

الحزمة: curl

التراخيص: MIT

curl_url_cleanup(3) دليل الدوال المكتبية curl_url_cleanup(3)

الاسم

curl_url_cleanup - تحرير مؤشر عنوان URL

ملخص

#include <curl/curl.h>
void curl_url_cleanup(CURLU *handle);

الوصف

يقوم بتحرير جميع الموارد المرتبطة بمؤشر CURLU المحدد.

تمرير مؤشر NULL في handle يجعل هذه الدالة تعود فورًا دون اتخاذ أي إجراء.

أي استخدام للمؤشر handle بعد استدعاء هذه الدالة وعودتها، يعتبر غير قانوني.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURLU *url = curl_url();
  curl_url_set(url, CURLUPART_URL, "https://example.com", 0);
  curl_url_cleanup(url);
}

التوفر

تمت الإضافة في curl 7.62.0
