CURLOPT_RESOLVER_START_FUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_RESOLVER_START_FUNCTION(3) دليل وظائف المكتبة CURLOPT_RESOLVER_START_FUNCTION(3)

الاسم

CURLOPT_RESOLVER_START_FUNCTION - دالة رد اتصال يتم استدعاؤها قبل بدء تحليل اسم جديد

الملخص

#include <curl/curl.h>
int resolver_start_cb(void *resolver_state, void *reserved, void *userdata);
CURLcode curl_easy_setopt(CURL *handle,
                          CURLOPT_RESOLVER_START_FUNCTION,
                          resolver_start_cb);

الوصف

قم بتمرير مؤشر إلى دالة رد الاتصال الخاصة بك، والتي يجب أن تتطابق مع النموذج الأولي الموضح أعلاه.

يتم استدعاء دالة رد الاتصال هذه بواسطة libcurl في كل مرة قبل بدء طلب تحليل جديد.

resolver_state يشير إلى حالة محلل خاصة بالواجهة الخلفية. حاليًا، لا يوجد لدى الواجهة الخلفية للمحلل ares سوى حالة محلل. يمكن استخدامه لإعداد أي خيار مرغوب فيه على قناة ares قبل استخدامها، على سبيل المثال إعداد خيارات رد اتصال المقبس.

reserved محجوز.

userdata هو مؤشر المستخدم الذي تم تعيينه باستخدام خيار CURLOPT_RESOLVER_START_DATA(3).

يجب أن تعيد الدالة 0 عند النجاح. إرجاع قيمة غير صفرية يتسبب في فشل التحليل.

الافتراضي

NULL (لا توجد دالة رد اتصال)

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

static int start_cb(void *resolver_state, void *reserved,
                    void *userdata)
{
  (void)reserved;
  printf("Received resolver_state=%p userdata=%p\n",
         resolver_state, userdata);
  return 0;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_RESOLVER_START_FUNCTION, start_cb);
    curl_easy_setopt(curl, CURLOPT_RESOLVER_START_DATA, curl);
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.59.0

قيمة الإرجاع

curl_easy_setopt(3) يعيد CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
