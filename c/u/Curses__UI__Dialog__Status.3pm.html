Curses__UI__Dialog__Status(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Dialog::Status(3) وثائق Perl مساهمة من المستخدم Curses::UI::Dialog::Status(3)

الاسم

Curses::UI::Dialog::Status - إنشاء ومعالجة مربعات حوار الحالة

تسلسل الفئات

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Status

الملخص

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# الطريقة الصعبة.
# -------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Status',
-message   => 'Hello, world!',
);
$dialog->draw();
$win->delete('mydialog');
# الطريقة السهلة (انظر توثيق Curses::UI).
# --------------------------------------------
$cui->status( -message => 'Some message' );
# أو حتى:
$cui->status( 'Some message' );
$cui->nostatus;

الوصف

Curses::UI::Dialog::Status ليس في الواقع مربع حوار، حيث لا توجد طريقة للمستخدم للتفاعل معه. إنها مجرد طريقة لتقديم معلومات الحالة للمستخدم في برنامجك.

راجع exampes/demo-Curses::UI::Dialog::Status في التوزيع للحصول على عرض توضيحي قصير.

خيارات

  • -title < نص >

    يحدد عنوان نافذة مربع الحوار إلى النص.

  • -message < نص >

    يحدد هذا الخيار الرسالة الأولية التي سيتم عرضها إلى النص.

أساليب

  • new ( خيارات )
  • layout ( )
  • draw ( منطقي )

    هذه أساليب قياسية. انظر Curses::UI::Container للحصول على شرح لهذه.

  • message ( نص )

    يقوم هذا الأسلوب بتحديث رسالة مربع حوار الحالة إلى النص. لإظهار هذا التحديث، ستحتاج إلى استدعاء أسلوب draw لمربع الحوار التقدمي.
