curl_multi_waitfds(3)

الحزمة: curl

التراخيص: MIT

curl_multi_waitfds(3) دليل وظائف المكتبة curl_multi_waitfds(3)

الاسم

curl_multi_waitfds - استخراج معلومات واصف الملف من مقبض متعدد

الملخص

#include <curl/curl.h>
#include <stdlib.h>
CURLMcode curl_multi_waitfds(CURLM *multi,
                             struct curl_waitfd *ufds,
                             unsigned int size,
                             unsigned int *fd_count);

الوصف

تستخرج هذه الوظيفة هياكل curl_waitfd التي تشبه هيكل pollfd الخاص بـ poll(2) من مقبض متعدد معين.

يمكن استخدام هذه الهياكل للاستطلاع على واصفات ملفات المقبض المتعدد بطريقة مشابهة لـ curl_multi_poll(3). يجب استدعاء وظيفة curl_multi_perform(3) بمجرد أن يصبح أحد هذه الواصفات جاهزًا للقراءة منه أو الكتابة إليه.

تقوم مكتبة libcurl بملء مصفوفة ufds المقدمة حتى الحجم size. إذا كان عدد الواصفات التي يستخدمها المقبض المتعدد أكبر من المعلمة size، فإن libcurl ترجع خطأ CURLM_OUT_OF_MEMORY.

إذا لم يكن الوسيط fd_count مؤشرًا فارغًا، فإنه يشير إلى متغير يحدد عند الإرجاع عدد الواصفات التي يستخدمها المقبض المتعدد ليتم فحصها لتكون جاهزة للقراءة أو الكتابة.

يمكن لرمز العميل تمرير size مساوٍ لصفر للحصول فقط على عدد الواصفات وتخصيص مساحة تخزين مناسبة لها لاستخدامها في استدعاء وظيفة لاحق. في هذه الحالة، يتلقى fd_count عددًا أكبر من أو يساوي عدد الواصفات.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

#include <stdlib.h>
int main(void)
{
  CURLMcode mc;
  struct curl_waitfd *ufds;
  CURLM *multi = curl_multi_init();
  do {
    /* استدعاء curl_multi_perform() */
    /* الحصول على عدد واصفات الملف من عمليات النقل */
    unsigned int fd_count = 0;
    mc = curl_multi_waitfds(multi, NULL, 0, &fd_count);
    if(mc != CURLM_OK) {
      fprintf(stderr, "curl_multi_waitfds() failed, code %d.\n", mc);
      break;
    }
    if(!fd_count)
      continue; /* لا توجد واصفات بعد */
    /* تخصيص مساحة تخزين لواصفاتنا */
    ufds = malloc(fd_count * sizeof(struct curl_waitfd));
    /* الحصول على واصفات الانتظار من عمليات النقل ووضعها في المصفوفة. */
    mc = curl_multi_waitfds(multi, ufds, fd_count, &fd_count);
    if(mc != CURLM_OK) {
      fprintf(stderr, "curl_multi_waitfds() failed, code %d.\n", mc);
      free(ufds);
      break;
    }
    /* إجراء الاستطلاع على الواصفات في ufds */
    free(ufds);
  } while(!mc);
}

التوفر

تمت الإضافة في curl 8.8.0

قيمة الإرجاع

ترجع هذه الوظيفة قيمة CURLMcode تشير إلى النجاح أو الخطأ.

CURLM_OK (0) يعني أن كل شيء كان على ما يرام، والقيم غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
