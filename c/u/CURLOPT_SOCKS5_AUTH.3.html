CURLOPT_SOCKS5_AUTH(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_SOCKS5_AUTH(3) دليل الوظائف المكتبية CURLOPT_SOCKS5_AUTH(3)

الاسم

CURLOPT_SOCKS5_AUTH - طرق المصادقة للوكيل SOCKS5

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SOCKS5_AUTH, long bitmask);

الوصف

قم بتمرير قيمة طويلة (long) كمعامل، والتي يتم تعيينها إلى قناع بت (bitmask)، لإخبار مكتبة libcurl بطرق المصادقة المسموح بها لمصادقة الوكيل SOCKS5. الأعلام المدعومة الوحيدة هي CURLAUTH_BASIC، والتي تسمح بمصادقة اسم المستخدم/كلمة المرور، CURLAUTH_GSSAPI، والتي تسمح بمصادقة GSS-API، و CURLAUTH_NONE، والتي لا تسمح بأي مصادقة. قم بتعيين اسم المستخدم وكلمة المرور الفعليين باستخدام الخيار CURLOPT_PROXYUSERPWD(3).

الافتراضي

CURLAUTH_BASIC|CURLAUTH_GSSAPI

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* طلب استخدام وكيل SOCKS5 */
    curl_easy_setopt(curl, CURLOPT_PROXY, "socks5://user:pass@myproxy.com");
    /* تمكين المصادقة باسم المستخدم/كلمة المرور فقط */
    curl_easy_setopt(curl, CURLOPT_SOCKS5_AUTH, CURLAUTH_BASIC);
    /* إجراء الطلب */
    curl_easy_perform(curl);
  }
}

التاريخ

أصبحت وحدات CURLAUTH_* من النوع long في الإصدار 7.26.0، وقبل هذا الإصدار، كان من الضروري تحويل النوع إلى long عند تمريره إلى curl_easy_setopt(3).

التوفر

تمت الإضافة في curl 7.55.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، أما القيمة غير الصفرية فتعني حدوث خطأ، راجع libcurl-errors(3).
