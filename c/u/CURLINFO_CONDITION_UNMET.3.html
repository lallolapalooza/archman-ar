CURLINFO_CONDITION_UNMET(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_CONDITION_UNMET(3) دليل الوظائف المكتبية CURLINFO_CONDITION_UNMET(3)

الاسم

CURLINFO_CONDITION_UNMET - الحصول على معلومات حول شرط الوقت غير المتحقق أو استجابة HTTP 304.

الاستخدام

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONDITION_UNMET,
                           long *unmet);

الوصف

مرر مؤشرًا إلى قيمة طويلة (long) لاستقبال القيمة 1 إذا لم يتطابق الشرط المقدم في الطلب السابق (انظر CURLOPT_TIMECONDITION(3)). للأسف، إذا أعادت هذه القيمة 1، فأنت تعرف أن سبب عدم حصولك على بيانات رداً على ذلك هو أن الشرط لم يتحقق. يتم تخزين القيمة صفر في المؤشر الذي يشير إليه هذا الوسيط إذا تم تحقيق الشرط بدلاً من ذلك. يمكن أن تعيد هذه الوظيفة أيضًا القيمة 1 إذا استجاب الخادم برمز الحالة HTTP 304، على سبيل المثال بعد إرسال رأس مخصص "If-Match-*".

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* 1 يناير 2020 هو 1577833200 */
    curl_easy_setopt(curl, CURLOPT_TIMEVALUE, 1577833200L);
    /* إذا تم التعديل منذ الطابع الزمني أعلاه */
    curl_easy_setopt(curl, CURLOPT_TIMECONDITION, CURL_TIMECOND_IFMODSINCE);
    /* قم بتنفيذ الطلب */
    res = curl_easy_perform(curl);
    if(!res) {
      /* تحقق من شرط الوقت */
      long unmet;
      res = curl_easy_getinfo(curl, CURLINFO_CONDITION_UNMET, &unmet);
      if(!res) {
        printf("تم %sتحقيق شرط الوقت\n", unmet?"عدم":"");
      }
    }
  }
}
