curs_inwstr(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_inwstr(3X) استدعاءات المكتبة curs_inwstr(3X)

الاسم

inwstr, innwstr, winwstr, winnwstr, mvinwstr, mvinnwstr, mvwinwstr, mvwinnwstr - الحصول على سلسلة أحرف واسعة من نافذة curses

الملخص

#include <curses.h>
int inwstr(wchar_t *wstr);
int innwstr(wchar_t *wstr, int n);
int winwstr(WINDOW *win, wchar_t *wstr);
int winnwstr(WINDOW *win, wchar_t *wstr, int n);
int mvinwstr(int y, int x, wchar_t *wstr);
int mvinnwstr(int y, int x, wchar_t *wstr, int n);
int mvwinwstr(WINDOW *win, int y, int x, wchar_t *wstr);
int mvwinnwstr(WINDOW *win, int y, int x, wchar_t *wstr, int n);

الوصف

تقوم هذه الروتينات بإرجاع سلسلة من أحرف wchar_t الواسعة في wstr، بدءًا من موضع المؤشر الحالي في النافذة المسماة.

تقوم الوظائف الأربعة التي تحتوي على n كمعامل أخير بإرجاع سلسلة فرعية رائدة لا يزيد طولها عن n حرفًا (باستثناء حرف NUL اللاحق). يتوقف النقل عند نهاية السطر الحالي، أو عندما يتم تخزين n حرفًا في الموقع المشار إليه بواسطة wstr.

إذا لم يكن الحجم n كبيرًا بما يكفي لتخزين حرف معقد كامل، يتم إنشاء خطأ.

قيمة الإرجاع

ترجع جميع الروتينات ERR عند الفشل. عند اكتمال التنفيذ بنجاح، ترجع روتينات *inwstr القيمة OK، وترجع روتينات *innwstr عدد الأحرف المقروءة في السلسلة.

لا يعرف X/Open شروط خطأ. هذه التنفيذة ترجع خطأ

  • إذا كان المعامل win فارغًا أو
  • إذا كان المعامل wstr فارغًا، أو
  • إذا لم يتمكن من قراءة أي أحرف.

الوظائف التي تبدأ بـ "mv" تقوم أولاً بتحريك المؤشر وتفشل إذا كان الموضع (y, x) خارج حدود النافذة.

ملاحظات

قد تكون جميع الروتينات باستثناء winnwstr وحدات ماكرو.

تحتوي كل خلية في النافذة على حرف معقد (حرف مسافات وصفر أو أكثر من الأحرف غير المسافات) مع السمات والألوان. تقوم هذه الوظائف بتخزين الأحرف الواسعة فقط، وتتجاهل السمات والألوان. استخدم in_wchstr لإرجاع الأحرف المعقدة من النافذة.

قراءة سطر يتجاوز المصفوفة المشار إليها بواسطة wstr باستخدام inwstr أو mvinwstr أو mvwinwstr أو winwstr يؤدي إلى نتائج غير محددة. لذلك، يوصى باستخدام innwstr أو mvinnwstr أو mvwinnwstr أو winnwstr.

قابلية النقل

تم وصف هذه الوظائف في X/Open Curses، الإصدار 4.
