CURLOPT_KEYPASSWD(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_KEYPASSWD(3) دليل الدوال المكتبية CURLOPT_KEYPASSWD(3)

الاسم

CURLOPT_KEYPASSWD - كلمة مرور المفتاح الخاص

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_KEYPASSWD, char *pwd);

الوصف

تمرير مؤشر إلى سلسلة نصية منتهية بـ NULL كمعامل. تُستخدم كلمة المرور المطلوبة لاستخدام المفتاح الخاص لـ CURLOPT_SSLKEY(3) أو CURLOPT_SSH_PRIVATE_KEYFILE(3). لا تحتاج أبدًا إلى كلمة مرور لتحميل شهادة، ولكنك تحتاج إليها لتحميل مفتاحك الخاص.

لا يحتاج التطبيق إلى الاحتفاظ بالسلسلة النصية بعد تعيين هذا الخيار.

استخدام هذا الخيار عدة مرات يجعل السلسلة النصية الأخيرة المعينة تتجاوز السلاسل السابقة. قم بتعيينه إلى NULL لإلغاء تفعيله مرة أخرى.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المستندة إلى TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية التالية لـ TLS: OpenSSL، Schannel، mbedTLS، و wolfSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_SSLCERT, "client.pem");
    curl_easy_setopt(curl, CURLOPT_SSLKEY, "key.pem");
    curl_easy_setopt(curl, CURLOPT_KEYPASSWD, "superman");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التاريخ

كان هذا الخيار يُعرف باسم CURLOPT_SSLKEYPASSWD حتى الإصدار 7.16.4 و CURLOPT_SSLCERTPASSWD حتى الإصدار 7.9.2.

التوفر

تمت إضافته في curl 7.17.0

قيمة الإرجاع

curl_easy_setopt(3) تُرجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيم غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
