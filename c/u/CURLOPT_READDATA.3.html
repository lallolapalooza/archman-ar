CURLOPT_READDATA(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_READDATA(3) دليل وظائف المكتبة CURLOPT_READDATA(3)

اسم

CURLOPT_READDATA - مؤشر يتم تمريره إلى استدعاء قراءة البيانات

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_READDATA, void *pointer);

الوصف

البيانات pointer التي يتم تمريرها إلى وظيفة قراءة الملف. إذا كنت تستخدم خيار CURLOPT_READFUNCTION(3)، فهذا هو المؤشر الذي تحصل عليه كوسيط للحجة الرابعة للدالة الاستدعائية.

إذا لم تحدد استدعاء قراءة ولكن بدلاً من ذلك تعتمد على وظيفة القراءة الداخلية الافتراضية، فيجب أن تكون هذه البيانات عبارة عن FILE * قابل للقراءة (تم تحويله إلى 'void *').

إذا كنت تستخدم libcurl كمكتبة ديناميكية (DLL) على نظام Windows، فيجب عليك استخدام استدعاء CURLOPT_READFUNCTION(3) إذا قمت بتعيين هذا الخيار، وإلا فقد تواجه أعطال.

افتراضي

stdin

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* تمرير المؤشر الذي يتم تمريره إلى استدعاء
       CURLOPT_READFUNCTION */
    curl_easy_setopt(curl, CURLOPT_READDATA, &this);
    curl_easy_perform(curl);
  }
}

تاريخ

كان هذا الخيار يُعرف سابقًا بالاسم القديم CURLOPT_INFILE، وتم تقديم الاسم CURLOPT_READDATA(3) في الإصدار 7.9.7.
