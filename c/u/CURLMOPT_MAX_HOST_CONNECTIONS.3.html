CURLMOPT_MAX_HOST_CONNECTIONS(3)

الحزمة: curl

التراخيص: MIT

CURLMOPT_MAX_HOST_CONNECTIONS(3) Library Functions Manual CURLMOPT_MAX_HOST_CONNECTIONS(3)

NAME

CURLMOPT_MAX_HOST_CONNECTIONS - الحد الأقصى لعدد الاتصالات بمضيف واحد

SYNOPSIS

#include <curl/curl.h>
CURLMcode curl_multi_setopt(CURLM *handle, CURLMOPT_MAX_HOST_CONNECTIONS,
                            long max);

DESCRIPTION

مرر قيمة عددية طويلة (long) للإشارة إلى max، وهي الحد الأقصى لعدد الاتصالات المفتوحة في وقت واحد التي يمكن أن تحتفظ بها مكتبة libcurl لمضيف واحد (المضيف هو نفس زوج اسم المضيف + رقم المنفذ). لكل عملية نقل جديدة إلى نفس المضيف، قد تفتح libcurl اتصالًا جديدًا حتى الحد المعين بواسطة CURLMOPT_MAX_HOST_CONNECTIONS(3). عند الوصول إلى الحد، تظل الجلسات الجديدة معلقة حتى يصبح الاتصال متاحًا.

القيمة الافتراضية لـ max هي 0، أي غير محدودة. يتم استخدام هذا الحد المعين أيضًا لاتصالات الوكيل (proxy)، ويعتبر الوكيل هو المضيف الذي يُحسب هذا الحد من أجله.

عند إضافة عمليات نقل إلى مقبض الـ multi أكثر مما يمكن تنفيذه بسبب الحد المعين، يتم وضعها في قائمة انتظار انتظارًا لفرصتها.

أثناء انتظار عملية النقل داخليًا للاتصال، يتم احتساب مهلة CURLOPT_TIMEOUT_MS(3) بما في ذلك وقت الانتظار، مما يعني أنه إذا قمت بتعيين مهلة ضيقة جدًا، فقد لا تبدأ عملية النقل على الإطلاق قبل انتهاء مهلتها. يتم أيضًا معاملة مهلة CURLOPT_CONNECTTIMEOUT_MS(3) بنفس الطريقة كمهلة لكل اتصال وقد تنتهي صلاحيتها حتى قبل السماح بإنشاء اتصال جديد.

تغيير هذه القيمة أثناء وجود عمليات نقل قيد التقدم أمر ممكن. يتم استخدام القيمة الجديدة في المرة التالية التي يتم فيها إجراء عمليات الفحص. خفض القيمة لا يغلق أي عمليات نقل نشطة، بل ببساطة لا يسمح بإنشاء عمليات جديدة.

DEFAULT

0

PROTOCOLS

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

EXAMPLE

int main(void)
{
  CURLM *m = curl_multi_init();
  /* لا تقم بأكثر من اتصالين لكل مضيف */
  curl_multi_setopt(m, CURLMOPT_MAX_HOST_CONNECTIONS, 2L);
}

AVAILABILITY

تمت الإضافة في curl 7.30.0

RETURN VALUE

curl_multi_setopt(3) تُرجع قيمة CURLMcode تشير إلى النجاح أو الخطأ.

CURLM_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تشير إلى حدوث خطأ، راجع libcurl-errors(3).
