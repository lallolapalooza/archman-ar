cupsenable(8)

الحزمة: cups

التراخيص: Apache-2.0 WITH LLVM-exception AND BSD-3-Clause AND Zlib AND BSD-2-Clause

cupsenable(8) OpenPrinting cupsenable(8)

الاسم

cupsdisable, cupsenable - إيقاف/بدء الطابعات والفئات

الملخص

cupsdisable [ -E ] [ -U اسم المستخدم ] [ -c ] [ -h الخادم[:المنفذ] ] [ -r السبب ] [ --hold ] الوجهة(الوجهات)
cupsenable [ -E ] [ -U اسم المستخدم ] [ -c ] [ -h الخادم[:المنفذ] ] [ --release ] الوجهة(الوجهات)

الوصف

يقوم الأمر cupsenable ببدء الطابعات أو الفئات المسماة بينما يقوم الأمر cupsdisable بإيقاف الطابعات أو الفئات المسماة.

الخيارات

يمكن استخدام الخيارات التالية:

-E
يجبر على تشفير الاتصال بالخادم.
-U اسم المستخدم
يستخدم اسم المستخدم المحدد عند الاتصال بالخادم.
-c
يلغي جميع المهام على الوجهة المسماة.
-h الخادم[:المنفذ]
يستخدم الخادم والمنفذ المحددين.
--hold
يحتفظ بالمهام المتبقية على الطابعة المسماة. مفيد للسماح للمهمة الحالية بالانتهاء قبل إجراء الصيانة.
-r "السبب"
يحدد الرسالة المرتبطة بالحالة المتوقفة. إذا لم يتم تحديد سبب، يتم تعيين الرسالة إلى "Reason Unknown" (سبب غير معروف).
--release
يحرر المهام المعلقة للطباعة. استخدمه بعد تشغيل cupsdisable مع الخيار --hold لاستئناف الطباعة.

التوافق مع

على عكس نظام الطباعة System V، يسمح CUPS بأسماء الطابعات التي تحتوي على أي حرف قابل للطباعة باستثناء المسافة (SPACE) والتاب (TAB) و "/" و "#". أيضًا، أسماء الطابعات والفئات ليست حساسة لحالة الأحرف.

إصدارات System V من هذه الأوامر هي disable و enable، على التوالي. تم تغيير اسمها لتجنب التعارض مع أوامر Bash المضمنة التي تحمل نفس الأسماء.

قد تطلب إصدارات CUPS من disable و enable كلمة مرور وصول من المستخدم اعتمادًا على تكوين نظام الطباعة. يختلف هذا عن إصدارات System V التي تتطلب من المستخدم الجذر (root) تنفيذ هذه الأوامر.
