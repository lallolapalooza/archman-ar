CURLOPT_SSLENGINE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_SSLENGINE(3) دليل وظائف المكتبة CURLOPT_SSLENGINE(3)

الاسم

CURLOPT_SSLENGINE - تعيين محرك أو مزود SSL

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLENGINE, char *id);

الوصف

مرر مؤشرًا إلى سلسلة منتهية بـ NULL كمعامل. يتم استخدامه كمعرف لـ المحرك أو المزود الذي تريد استخدامه لمفتاحك الخاص. كان لدى OpenSSL 1 محركات، بينما لدى OpenSSL 3 مزودين.

لا يحتاج التطبيق إلى الاحتفاظ بالسلسلة بعد تعيين هذا الخيار.

عند مطالبة libcurl باستخدام مزود، يمكن للتطبيق أيضًا توفير خاصية اختيارية، وهي مجموعة من أزواج الاسم والقيمة. يمكن تحديد خاصية كهذه مفصولة عن الاسم بنقطتين رأسيتين (:).

استخدام هذا الخيار عدة مرات يجعل السلسلة الأخيرة المعينة تتجاوز السابقة. قم بتعيينه إلى NULL لتعطيل استخدامه مرة أخرى.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات القائمة على TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية لـ TLS التالية: OpenSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE, "dynamic");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.9.3

قيمة الإرجاع

CURLE_OK - تم العثور على المحرك.

CURLE_SSL_ENGINE_NOTFOUND - لم يتم العثور على المحرك، أو لم يتم بناء OpenSSL مع دعم المحركات.

CURLE_SSL_ENGINE_INITFAILED - تم العثور على المحرك ولكن فشلت التهيئة.

CURLE_NOT_BUILT_IN - الخيار غير مضمن، OpenSSL ليس الواجهة الخلفية لـ SSL.

CURLE_UNKNOWN_OPTION - لم يتم التعرف على الخيار.

CURLE_OUT_OF_MEMORY - مساحة كومة غير كافية.
