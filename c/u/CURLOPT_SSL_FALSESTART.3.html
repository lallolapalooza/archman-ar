CURLOPT_SSL_FALSESTART(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_SSL_FALSESTART(3) دليل وظائف المكتبة CURLOPT_SSL_FALSESTART(3)

الاسم

CURLOPT_SSL_FALSESTART - بدء زائف SSL

ملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSL_FALSESTART, long enable);

الوصف

مرر قيمة طويلة (long) كمعامل، يتم تعيينها إلى 1L للتمكين أو 0 للإيقاف.

يحدد هذا الخيار ما إذا كان يجب على libcurl استخدام البدء الزائف (false start) أثناء مصافحة TLS. البدء الزائف هو وضع يبدأ فيه عميل TLS بإرسال بيانات التطبيق قبل التحقق من رسالة الإنهاء (Finished message) الخاصة بالخادم، مما يوفر رحلة ذهاب وإياب عند إجراء مصافحة كاملة.

الافتراضي

0

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المستندة إلى TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS، إلخ.

لا يوجد دعم من واجهة TLS الخلفية لهذا الخيار.

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_SSL_FALSESTART, 1L);
    curl_easy_perform(curl);
  }
}

مهمل

مهمل منذ الإصدار 8.15.0.

التوفر

تمت الإضافة في curl 7.42.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، القيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
