CURLINFO_PRETRANSFER_TIME(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_PRETRANSFER_TIME(3) دليل وظائف المكتبة CURLINFO_PRETRANSFER_TIME(3)

الاسم

CURLINFO_PRETRANSFER_TIME - الحصول على الوقت حتى بدء نقل الملف

ملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_PRETRANSFER_TIME,
                           double *timep);

الوصف

مرر مؤشرًا إلى double لتلقي الوقت، بالثواني، الذي استغرقه من البداية حتى أصبح نقل الملف على وشك البدء.

يشتمل طابع الوقت هذا على جميع الأوامر والتفاوضات قبل النقل الخاصة بالبروتوكولات المحددة المتضمنة. يتضمن إرسال التعليمات الخاصة بالبروتوكول التي تؤدي إلى نقل.

عند متابعة إعادة توجيه، يتم جمع الوقت من كل طلب.

انظر أيضًا نظرة عامة على الأوقات في دليل curl_easy_getinfo(3).

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    double pretransfer;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(CURLE_OK == res) {
      res = curl_easy_getinfo(curl, CURLINFO_PRETRANSFER_TIME, &pretransfer);
      if(CURLE_OK == res) {
        printf("الوقت: %.1f", pretransfer);
      }
    }
    /* تنظيف دائمًا */
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.4.1

قيمة الإرجاع

curl_easy_getinfo(3) ترجع CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).

انظر أيضًا
