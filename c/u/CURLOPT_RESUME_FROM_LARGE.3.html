CURLOPT_RESUME_FROM_LARGE(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_RESUME_FROM_LARGE(3) دليل وظائف المكتبة CURLOPT_RESUME_FROM_LARGE(3)

الاسم

CURLOPT_RESUME_FROM_LARGE - الإزاحة لاستئناف النقل منها

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_RESUME_FROM_LARGE,
                          curl_off_t from);

الوصف

مرر قيمة من نوع curl_off_t كمعامل. تحتوي هذه القيمة على الإزاحة بالبايت التي تريد أن يبدأ النقل منها. قم بتعيين هذا الخيار إلى 0 لجعل النقل يبدأ من البداية (مما يؤدي فعليًا إلى تعطيل الاستئناف). بالنسبة لـ FTP، قم بتعيين هذا الخيار إلى -1 لجعل النقل يبدأ من نهاية الملف المستهدف (مفيد لاستئناف تحميل متوقف).

عند إجراء عمليات تحميل باستخدام FTP، يكون موضع الاستئناف هو الموضع في الملف المحلي/المصدر الذي ستحاول مكتبة curl استئناف التحميل منه، وتقوم بإلحاق الملف المصدر بالملف المستهدف البعيد.

الافتراضي

0، غير مستخدم

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_off_t resume_position = 1234; /* الحصول عليها بطريقة ما */
    curl_off_t file_size = 9876; /* الحصول عليها بطريقة ما أيضًا */
    curl_easy_setopt(curl, CURLOPT_URL, "ftp://example.com");
    /* استئناف التحميل في هذا الموضع، ربما بعد 2 جيجابايت */
    curl_easy_setopt(curl, CURLOPT_RESUME_FROM_LARGE, resume_position);
    /* طلب التحميل */
    curl_easy_setopt(curl, CURLOPT_UPLOAD, 1L);
    /* تعيين إجمالي كمية البيانات المتوقعة */
    curl_easy_setopt(curl, CURLOPT_INFILESIZE_LARGE, file_size);
    /* تنفيذ الطلب */
    curl_easy_perform(curl);
  }
}

التوفر

تمت إضافته في curl 7.11.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء على ما يرام، وقيمة غير صفرية تعني حدوث خطأ، راجع libcurl-errors(3).
