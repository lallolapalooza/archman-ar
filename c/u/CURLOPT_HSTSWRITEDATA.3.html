CURLOPT_HSTSWRITEDATA(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_HSTSWRITEDATA(3) دليل وظائف المكتبة CURLOPT_HSTSWRITEDATA(3)

الاسم

CURLOPT_HSTSWRITEDATA(3) - مؤشر يتم تمريره إلى دالة استدعاء HSTS للكتابة

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HSTSWRITEDATA, void *pointer);

الوصف

المؤشر pointer الذي سيتم تمريره إلى دالة استدعاء HSTS للكتابة. إذا كنت تستخدم الخيار CURLOPT_HSTSWRITEFUNCTION(3)، فهذا هو المؤشر الذي تحصل عليه كوسيطة رابعة للدالة الاستدعائية.

هذا الخيار لا يمكّن HSTS، تحتاج إلى استخدام CURLOPT_HSTS_CTRL(3) للقيام بذلك.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

struct MyData {
  void *custom;
};
int main(void)
{
  CURL *curl = curl_easy_init();
  struct MyData this;
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "http://example.com");
    /* تمرير المؤشر الذي يتم تمريره إلى دالة الاستدعاء
       CURLOPT_HSTSWRITEFUNCTION */
    curl_easy_setopt(curl, CURLOPT_HSTSWRITEDATA, &this);
    curl_easy_perform(curl);
  }
}
