Curses__UI__Dialog__Filebrowser(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Dialog::Filebrowser(3) وثائق Perl المساهمة من المستخدم Curses::UI::Dialog::Filebrowser(3)

الاسم

Curses::UI::Dialog::Filebrowser - إنشاء ومعالجة نوافذ متصفح الملفات

تسلسل الفئة

Curses::UI::Widget
   |
   +----Curses::UI::Container
           |
           +----Curses::UI::Window
                   |
                   +----Curses::UI::Dialog::Filebrowser

الملخص

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
# الطريقة الصعبة.
# -------------
my $dialog = $win->add(
    'mydialog', 'Dialog::Filebrowser'
);
$dialog->focus;
my $file = $dialog->get();
$win->delete('mydialog');
# الطريقة السهلة (انظر توثيق Curses::UI).
# --------------------------------------------
$file = $cui->filebrowser();
$file = $cui->loadfilebrowser();
$file = $cui->savefilebrowser();

الوصف

Curses::UI::Dialog::Filebrowser هو نافذة متصفح ملفات. يمكن استخدام هذا النوع من النوافذ لاختيار ملف، في أي مكان على نظام الملفات.

انظر أمثلة/العرض التوضيحي-Curses::UI::Dialog::Filebrowser في التوزيع لعرض توضيحي قصير.

خيارات

  • -title < نص >

    يضبط عنوان نافذة الحوار إلى النص.

  • -path < مسار >

    يضبط المسار الذي ستبدأ منه إلى المسار. إذا لم يكن هذا المسار موجودًا، فسيبدأ متصفح الملفات من الدليل الجذر.

  • -file < ملف >

    يضبط اسم الملف الذي ستبدأ منه إلى الملف.

  • -editfilename < قيمة منطقية >

    إذا كانت القيمة المنطقية تحتوي على قيمة صحيحة، يمكن للمستخدم تعديل اسم الملف. هذا مفيد على سبيل المثال لمتصفح ملفات يستخدم لاختيار اسم ملف للحفظ. افتراضيًا، يتم تعيين هذا الخيار إلى false.

  • -show_hidden < قيمة منطقية >

    إذا كانت القيمة المنطقية تحتوي على قيمة صحيحة، فسيتم أيضًا عرض الملفات المخفية (يبدأ اسم الملف بنقطة). افتراضيًا، يتم تعيين هذا الخيار إلى false.

  • -mask < REF إلى مصفوفة >

    إذا تم تعريف -mask، فسيتم إضافة مربع حوار قناع (filemask popupbox) إلى نافذة حوار متصفح الملفات. سيقوم هذا المربع بتصفية قائمة الملفات المعروضة، باستخدام تعبير عادي (غير حساس لحالة الأحرف). يحتوي REF إلى مصفوفة على قائمة من REF إلى مصفوفات. يحتوي كل REF إلى مصفوفة على عنصرين: تعبير عادي ووصف. إليك مثال لـ -mask:

    my $mask = [
    [ '.',        'All files (*)'       ],
    [ '\.txt$',   'Text files (*.txt)'  ]
    [ 'howto',    'HOWTO documentation' ],
    [ 'core',     'Core files'          ],
];
  • -mask_selected < فهرس >

    عادةً ما يتم تنشيط القناع الأول في قائمة الأقنعة عند إنشاء متصفح الملفات. إذا كنت تريد قناعًا آخر ليتم تنشيطه، فاستخدم الخيار -mask_selected. قم بتعيين هذه القيمة إلى فهرس القناع الذي تريد تنشيطه. على سبيل المثال: إذا كنت تريد أن يكون قناع "howto" في المثال أعلاه نشطًا، فستستخدم القيمة 2 لـ -mask_selected.

الطرق

  • new ( خيارات )
  • layout ( )
  • draw ( قيمة منطقية )
  • focus ( )

    هذه طرق قياسية. انظر Curses::UI::Container لشرح هذه الطرق.

  • get ( )

    ستعيد هذه الطريقة المسار الكامل للملف الذي تم تحديده باستخدام متصفح الملفات. إذا لم يتم تحديد أي ملف، فسسترجع هذه الطريقة قيمة غير معرفة.

روابط خاصة

  • escape

    سيؤدي هذا إلى استدعاء زر الإلغاء، لذلك ستعود أداة متصفح الملفات بدون تحديد أي ملف.

  • ~

    إذا كان مربع قائمة الدلائل أو الملفات في نافذة الحوار لديه التركيز وتم الضغط على مفتاح الشرطة المائلة (~)، فسيقوم متصفح الملفات بتغيير الدليل إلى الدليل الرئيسي للمستخدم الحالي.
