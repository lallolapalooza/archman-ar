curl_mime_free(3)

الحزمة: curl

التراخيص: MIT

curl_mime_free(3) دليل الوظائف المكتبية curl_mime_free(3)

الاسم

curl_mime_free - تحرير بنية mime مبنية مسبقًا

الملخص

#include <curl/curl.h>
void curl_mime_free(curl_mime *mime);

الوصف

curl_mime_free(3) تُستخدم لتنظيف البيانات التي تم بناؤها/إلحاقها سابقًا باستخدام curl_mime_addpart(3) ووظائف معالجة mime الأخرى. يجب استدعاء هذا بعد استخدام البيانات، والذي يعني عادةً بعد استدعاء curl_easy_perform(3).

المقبض الذي يجب تحريره هو الذي مررته إلى الخيار CURLOPT_MIMEPOST(3): يجب عدم تحرير مقبض الأجزاء الفرعية المرفقة صراحةً، حيث يتم ذلك بواسطة تحرير المقبض العلوي.

mime هو المقبض كما تم إرجاعه من استدعاء سابق لـ curl_mime_init(3) وقد يكون NULL.

تمرير مؤشر NULL في mime يجعل هذه الوظيفة تعود فورًا بدون اتخاذ أي إجراء.

البروتوكولات

تؤثر هذه الوظيفة على http، imap و smtp

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* بناء رسالة mime. */
    curl_mime *mime = curl_mime_init(curl);
    /* إرسال النقل */
    /* تحرير رسالة متعددة الأجزاء. */
    curl_mime_free(mime);
  }
}
