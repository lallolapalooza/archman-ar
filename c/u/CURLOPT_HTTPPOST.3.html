CURLOPT_HTTPPOST(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_HTTPPOST(3) دليل وظائف المكتبة CURLOPT_HTTPPOST(3)

الاسم

CURLOPT_HTTPPOST - محتوى POST بالنموذج المتعدد

الموجز

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HTTPPOST,
                          struct curl_httppost *formpost);

الوصف

تم إهمال هذا الخيار. استخدم CURLOPT_MIMEPOST(3) بدلاً من ذلك.

يُعلم libcurl أنك تريد إجراء HTTP POST من نوع multipart/formdata وأنك تحدد البيانات التي سيتم تمريرها إلى الخادم في الوسيط formpost. قم بتمرير مؤشر إلى قائمة مرتبطة من هياكل curl_httppost كوسيط. أسهل طريقة لإنشاء مثل هذه القائمة هي استخدام curl_formadd(3) كما هو موثق. يجب أن تظل البيانات في هذه القائمة سليمة طالما أن عملية النقل الخاصة بـ curl قيد التشغيل وتستخدمها.

استخدام POST مع HTTP 1.1 يعني استخدام رأس "Expect: 100-continue". يمكنك تعطيل هذا الرأس باستخدام CURLOPT_HTTPHEADER(3).

عند تعيين CURLOPT_HTTPPOST(3)، تقوم libcurl تلقائيًا بتعيين CURLOPT_NOBODY(3) إلى 0.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  struct curl_httppost *formpost;
  struct curl_httppost *lastptr;
  /* املأ حقل تحميل الملف. هذا يجعل libcurl يقوم بتحميل البيانات من
     اسم الملف المحدد عند استدعاء curl_easy_perform(). */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "sendfile",
               CURLFORM_FILE, "postit2.c",
               CURLFORM_END);
  /* املأ حقل اسم الملف */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "filename",
               CURLFORM_COPYCONTENTS, "postit2.c",
               CURLFORM_END);
  /* املأ حقل الإرسال أيضًا، على الرغم من أن هذا نادرًا ما يكون ضروريًا */
  curl_formadd(&formpost,
               &lastptr,
               CURLFORM_COPYNAME, "submit",
               CURLFORM_COPYCONTENTS, "send",
               CURLFORM_END);
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_HTTPPOST, formpost);
    curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
  curl_formfree(formpost);
}

قيمة الإرجاع

curl_easy_setopt(3) تُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، القيم غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
