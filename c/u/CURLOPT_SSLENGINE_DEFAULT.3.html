CURLOPT_SSLENGINE_DEFAULT(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_SSLENGINE_DEFAULT(3) دليل وظائف المكتبة CURLOPT_SSLENGINE_DEFAULT(3)

الاسم

CURLOPT_SSLENGINE_DEFAULT - جعل محرك SSL افتراضيًا

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_SSLENGINE_DEFAULT, long val);

الوصف

مرر قيمة طويلة (long) مضبوطة على 1 لجعل محرك التشفير المحدد بالفعل هو الافتراضي لعمليات التشفير (غير المتماثلة).

ليس لهذا الخيار أي تأثير ما لم يتم ضبطه بعد CURLOPT_SSLENGINE(3).

الافتراضي

لا يوجد

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المستندة إلى TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS إلخ.

يعمل هذا الخيار فقط مع الواجهات الخلفية لـ TLS التالية: OpenSSL

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE, "dynamic");
    curl_easy_setopt(curl, CURLOPT_SSLENGINE_DEFAULT, 1L);
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت إضافته في curl 7.9.3

قيمة الإرجاع

CURLE_OK - تم ضبط المحرك كافتراضي.

CURLE_SSL_ENGINE_SETFAILED - لم يتمكن المحرك من الضبط كافتراضي.

CURLE_NOT_BUILT_IN - الخيار غير مدمج، OpenSSL ليس الواجهة الخلفية لـ SSL.

CURLE_UNKNOWN_OPTION - لم يتم التعرف على الخيار.

CURLE_OUT_OF_MEMORY - مساحة ذاكرة كافية.

انظر أيضًا
