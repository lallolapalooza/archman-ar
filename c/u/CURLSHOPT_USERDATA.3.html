CURLSHOPT_USERDATA(3)

الحزمة: curl

التراخيص: MIT

CURLSHOPT_USERDATA(3) دليل الوظائف المكتبية CURLSHOPT_USERDATA(3)

الاسم

CURLSHOPT_USERDATA - مؤشر يتم تمريره إلى وظائف القفل والإلغاء

الخلاصة

#include <curl/curl.h>
CURLSHcode curl_share_setopt(CURLSH *share, CURLSHOPT_USERDATA, void *clientp);

الوصف

يتم الاحتفاظ بالمعامل clientp حرفيًا بواسطة libcurl ويتم تمريره كمعامل clientp إلى الوظائف التي تم تعيينها باستخدام CURLSHOPT_LOCKFUNC(3) و CURLSHOPT_UNLOCKFUNC(3).

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct secrets {
  void *custom;
};
int main(void)
{
  CURLSHcode sh;
  struct secrets private_stuff;
  CURLSH *share = curl_share_init();
  sh = curl_share_setopt(share, CURLSHOPT_USERDATA, &private_stuff);
  if(sh)
    printf("Error: %s\n", curl_share_strerror(sh));
}

التوفر

تمت الإضافة في curl 7.10.3
