curs_instr(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

curs_instr(3x) استدعاءات المكتبة curs_instr(3x)

الاسم

instr, innstr, winstr, winnstr, mvinstr, mvinnstr, mvwinstr, mvwinnstr - الحصول على سلسلة نصية من نافذة curses

الاختصار

#include <curses.h>
int instr(char *str);
int innstr(char *str, int n);
int winstr(WINDOW *win, char *str);
int winnstr(WINDOW *win, char *str, int n);
int mvinstr(int y, int x, char *str);
int mvinnstr(int y, int x, char *str, int n);
int mvwinstr(WINDOW *win, int y, int x, char *str);
int mvwinnstr(WINDOW *win, int y, int x, char *str, int n);

الوصف

تقوم هذه الروتينات بإرجاع سلسلة من الأحرف في str، بدءًا من الموضع الحالي للمؤشر في النافذة المسماة. يتم تجريد السمات من الأحرف.

تقوم الدوال الأربع التي تحتوي على n كوسيط أخير بإرجاع سلسلة فرعية بادئة بحد أقصى n حرفًا (باستثناء الحرف الفارغ اللاحق). يتوقف النقل عند نهاية السطر الحالي، أو عندما يتم تخزين n حرفًا في الموقع الذي يشير إليه str.

قيمة الإرجاع

ترجع جميع الدوال ERR عند الفشل، أو عدد الأحرف التي تمت قراءتها فعليًا في السلسلة.

لا تحدد X/Open Curses أي شروط خطأ. تقوم هذه التنفيذات بإرجاع خطأ

  • إذا كان الوسيط win فارغًا أو
  • إذا كان الوسيط chstr فارغًا.

تقوم الدوال التي تبدأ بـ "mv" أولاً بتحريك المؤشر وتفشل إذا كان الموضع (y, x) خارج حدود النافذة.

ملاحظات

قد تكون جميع الروتينات باستثناء winnstr عبارة عن وحدات ماكرو.

تؤدي قراءة سطر يتجاوز المصفوفة المشار إليها بواسطة str باستخدام instr, mvinstr, mvwinstr أو winstr إلى نتائج غير محددة. لذلك، يوصى باستخدام innstr, mvinnstr, mvwinnstr، أو winnstr.

قابلية النقل

لا توثق SVr4 ما إذا كان حد الطول يشمل أو يستبعد الحرف الفارغ اللاحق.

تقوم مكتبة ncurses بتوسيع وصف X/Open Curses بالسماح بقيمة سالبة لـ n. في هذه الحالة، ترجع الدوال السلسلة التي تنتهي عند الهامش الأيمن.
