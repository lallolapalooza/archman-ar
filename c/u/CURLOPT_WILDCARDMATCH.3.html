CURLOPT_WILDCARDMATCH(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_WILDCARDMATCH(3) دليل الوظائف المكتبية CURLOPT_WILDCARDMATCH(3)

الاسم

CURLOPT_WILDCARDMATCH - نقل الملفات بالنمط البديل

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_WILDCARDMATCH, long onoff);

الوصف

عيّن onoff إلى 1 إذا كنت تريد نقل ملفات متعددة وفقًا لنمط اسم الملف. يمكن تحديد النمط كجزء من خيار CURLOPT_URL(3)، باستخدام نمط يشبه fnmatch (مطابقة نمط shell) في الجزء الأخير من عنوان URL (اسم الملف).

افتراضيًا، تستخدم مكتبة libcurl تطبيق مطابقة النمط البديل الخاص بها. يمكنك توفير دالة مطابقة خاصة بك باستخدام خيار CURLOPT_FNMATCH_FUNCTION(3).

فيما يلي مقدمة موجزة لصياغتها:

* - النجمة
ftp://example.com/some/path/*.txt

يطابق جميع ملفات .txt في الدليل الجذر. يُسمح بنجمتين فقط ضمن نفس سلسلة النمط.

? - علامة الاستفهام
علامة الاستفهام تطابق أي حرف (حرف واحد بالضبط). 
ftp://example.com/some/path/photo?.jpg
[ - تعبير القوس
القوس الأيسر يفتح تعبير القوس. لا يكون لعلامة الاستفهام والنجمة معنى خاص في تعبير القوس. ينتهي كل تعبير قوس بالقوس الأيمن ويطابق حرفًا واحدًا بالضبط. فيما يلي بعض الأمثلة:

[a-zA-Z0-9] أو [f-gF-G] - فترة الأحرف

[abc] - تعداد الأحرف

[^abc] أو [!abc] - نفي

[[:name:]] تعبير الفئة. الفئات المدعومة هي alnum، lower، space، alpha، digit، print، upper، blank، graph، xdigit.

[][-!^] - حالة خاصة - تطابق فقط '-'، ']'، '['، '!' أو '^'. ليس لهذه الأحرف غرض خاص.

[[]] - صيغة الهروب. تطابق '['، ']' أو 'e'.

باستخدام القواعد المذكورة أعلاه، يمكن بناء نمط اسم ملف:

ftp://example.com/some/path/[a-z[:upper:]\].jpg

البروتوكولات

تؤثر هذه الوظيفة على بروتوكول ftp فقط.

مثال

extern long begin_cb(struct curl_fileinfo *, void *, int);
extern long end_cb(void *ptr);
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    /* تشغيل مطابقة النمط البديل */
    curl_easy_setopt(curl, CURLOPT_WILDCARDMATCH, 1L);
    /* يتم استدعاء دالة الاستدعاء قبل بدء تنزيل الملف المحدد */
    curl_easy_setopt(curl, CURLOPT_CHUNK_BGN_FUNCTION, begin_cb);
    /* يتم استدعاء دالة الاستدعاء بعد نقل البيانات من الملف */
    curl_easy_setopt(curl, CURLOPT_CHUNK_END_FUNCTION, end_cb);
    /* انظر المزيد على https://curl.se/libcurl/c/ftp-wildcard.html */
  }
}

التوفر

تمت إضافته في curl 7.21.0

قيمة الإرجاع

curl_easy_setopt(3) تُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، أما القيمة غير الصفرية فتعني حدوث خطأ، انظر libcurl-errors(3).
