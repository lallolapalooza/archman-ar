CURLINFO_OS_ERRNO(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_OS_ERRNO(3) دليل وظائف المكتبة CURLINFO_OS_ERRNO(3)

الاسم

CURLINFO_OS_ERRNO - الحصول على رقم خطأ errno من فشل الاتصال الأخير

الملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_OS_ERRNO, long *errnop);

الوصف

مرر مؤشرًا إلى long لاستقبال متغير errno من فشل الاتصال. لاحظ أن القيمة يتم تعيينها فقط عند الفشل، ولا يتم إعادة تعيينها عند عملية ناجحة. الرقم خاص بالنظام ونظام التشغيل.

أخطاء libcurl المتعلقة بالشبكة التي قد تحتوي على errno محفوظ هي: CURLE_COULDNT_CONNECT، CURLE_FAILED_INIT، CURLE_INTERFACE_FAILED، CURLE_OPERATION_TIMEDOUT، CURLE_RECV_ERROR، CURLE_SEND_ERROR.

منذ الإصدار 8.8.0، تقوم libcurl بمسح errno المحفوظ للمقبض السهل قبل تنفيذ عملية النقل. الإصدارات السابقة لم تقم بمسح errno المحفوظ، مما يعني أنه إذا تم استرجاع errno محفوظ، فقد يكون من عملية نقل سابقة على نفس المقبض.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    res = curl_easy_perform(curl);
    if(res != CURLE_OK) {
      long error;
      res = curl_easy_getinfo(curl, CURLINFO_OS_ERRNO, &error);
      if(!res && error) {
        printf("Errno: %ld\n", error);
      }
    }
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت إضافته في curl 7.12.2

قيمة الإرجاع

curl_easy_getinfo(3) ترجع CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، وقيم غير الصفر تشير إلى حدوث خطأ، انظر libcurl-errors(3).
