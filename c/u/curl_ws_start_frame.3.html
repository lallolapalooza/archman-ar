curl_ws_start_frame(3)

الحزمة: curl

التراخيص: MIT

curl_ws_start_frame(3) دليل دوال المكتبة curl_ws_start_frame(3)

الاسم

curl_ws_start_frame - بدء إطار WebSocket جديد

الخلاصة

#include <curl/curl.h>
CURLcode curl_ws_start_frame(CURL *curl,
                             unsigned int flags,
                             curl_off_t frame_len);

الوصف

تضيف رأس إطار WebSocket للعلامات والطول المعطاة إلى مخزن إرسال المعاملة لبيانات WebSocket المشفرة. مخصص للاستخدام في دالة رد اتصال CURLOPT_READFUNCTION(3).

عند استخدام CURLOPT_READFUNCTION(3) في معاملة WebSocket، يتم إرسال أي بيانات تعيدها هذه الدالة كإطار CURLWS_BINARY مع كون الطول هو كمية البيانات المقروءة.

لإرسال أطر أكبر أو أطر من نوع مختلف، قم باستدعاء curl_ws_start_frame() من داخل دالة القراءة ثم أعد البيانات التابعة للإطار.

تفشل الدالة إذا لم يتم بعد قراءة إطار سابق بالكامل. كما تفشل في وضع CURLWS_RAW_MODE.

عادةً ما تعالج دالة القراءة في libcurl قيمة إرجاع 0 كإشارة لنهاية الملف وتوقف أي قراءات أخرى. هذا سيمنع إرسال أطر WebSocket بطول 0.

إذا قامت دالة القراءة باستدعاء curl_ws_start_frame() ومع ذلك، فإن قيمة الإرجاع 0 لا تُعامل كنهاية للملف ويستدعي libcurl دالة القراءة مرة أخرى.

علامات

تدعم جميع العلامات الموثقة في curl_ws_meta(3).

بروتوكولات

تؤثر هذه الوظيفة على ws فقط

مثال

#include <string.h> /* for strlen */
struct read_ctx {
  CURL *easy;
  char *message;
  size_t msg_len;
  size_t nsent;
};
static size_t readcb(char *buf, size_t nitems, size_t buflen, void *p)
{
  struct read_ctx *ctx = p;
  size_t len = nitems * buflen;
  size_t left = ctx->msg_len - ctx->nsent;
  CURLcode result;
  if(!ctx->nsent) {
    /* Want to send TEXT frame. */
    result = curl_ws_start_frame(ctx->easy, CURLWS_TEXT,
                                 (curl_off_t)ctx->msg_len);
    if(result) {
      fprintf(stderr, "error starting frame: %d\n", result);
      return CURL_READFUNC_ABORT;
    }
  }
  if(left) {
    if(left < len)
      len = left;
    memcpy(buf, ctx->message + ctx->nsent, len);
    ctx->nsent += len;
    return len;
  }
  return 0;
}
int main(void)
{
  CURL *easy;
  struct read_ctx rctx;
  CURLcode res;
  easy = curl_easy_init();
  if(!easy)
    return 1;
  curl_easy_setopt(easy, CURLOPT_URL, "wss://example.com");
  curl_easy_setopt(easy, CURLOPT_READFUNCTION, readcb);
  /* tell curl that we want to send the payload */
  memset(&rctx, 0, sizeof(rctx));
  rctx.easy = easy;
  rctx.message = "Hello, friend!";
  rctx.msg_len = strlen(rctx.message);
  curl_easy_setopt(easy, CURLOPT_READDATA, &rctx);
  curl_easy_setopt(easy, CURLOPT_UPLOAD, 1L);
  /* Perform the request, res gets the return code */
  res = curl_easy_perform(easy);
  /* Check for errors */
  if(res != CURLE_OK)
    fprintf(stderr, "curl_easy_perform() failed: %s\n",
            curl_easy_strerror(res));
  /* always cleanup */
  curl_easy_cleanup(easy);
  return 0;
}

التوفر

تمت الإضافة في curl 8.16.0

قيمة الإرجاع

تعيد هذه الدالة رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، أي قيمة غير صفر تعني حدوث خطأ، انظر libcurl-errors(3). إذا تم تعيين CURLOPT_ERRORBUFFER(3) باستخدام curl_easy_setopt(3)، فقد يتم تخزين رسالة خطأ في مخزن الخطأ عند إرجاع قيمة غير صفر.

بدلاً من الحظر، تعيد الدالة CURLE_AGAIN. السلوك الصحيح بعد ذلك هو الانتظار حتى يقوم المقبس بالإشارة إلى إمكانية القراءة قبل استدعاء هذه الدالة مرة أخرى.

أي قيمة غير صفر أخرى تشير إلى خطأ. انظر صفحة الدليل libcurl-errors(3) للحصول على القائمة الكاملة مع الأوصاف.
