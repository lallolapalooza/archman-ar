CURLOPT_DNS_LOCAL_IP4(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_DNS_LOCAL_IP4(3) دليل الدوال المكتبية CURLOPT_DNS_LOCAL_IP4(3)

الاسم

CURLOPT_DNS_LOCAL_IP4 - عنوان IPv4 الذي ترتبط به عمليات البحث عن DNS

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_DNS_LOCAL_IP4, char *address);

الوصف

اضبط عنوان IPv4 المحلي address الذي يجب أن يرتبط به محلل DNS. يجب أن يكون الوسيط من النوع char * ويحتوي على عنوان IPv4 رقمي واحد كسلسلة نصية. قم بتعيين هذا الخيار إلى NULL لاستخدام الإعداد الافتراضي (عدم الارتباط بعنوان IP محدد).

لا يلزم أن تحتفظ التطبيقات بالسلسلة النصية بعد تعيين هذا الخيار.

استخدام هذا الخيار عدة مرات يجعل السلسلة النصية الأخيرة المعينة تتجاوز السابقة. قم بتعيينها إلى NULL لتعطيل استخدامها مرة أخرى.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/foo.bin");
    curl_easy_setopt(curl, CURLOPT_DNS_LOCAL_IP4, "192.168.0.14");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

ملاحظات

يتطلب هذا الخيار أن يتم بناء مكتبة curl مع واجهة خلفية لمحلل DNS تدعم هذه العملية. واجهة c-ares الخلفية هي الوحيدة التي تدعم ذلك.

التوفر

تمت الإضافة في curl 7.33.0

قيمة الإرجاع

curl_easy_setopt(3) ترجع CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) تعني أن كل شيء كان على ما يرام، غير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
