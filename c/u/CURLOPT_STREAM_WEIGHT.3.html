CURLOPT_STREAM_WEIGHT(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_STREAM_WEIGHT(3) دليل الدوال المكتبية CURLOPT_STREAM_WEIGHT(3)

الاسم

CURLOPT_STREAM_WEIGHT - وزن التدفق الرقمي

الاختصار

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_STREAM_WEIGHT, long weight);

الوصف

قم بتعيين weight الطويل إلى رقم بين 1 و 256.

عند استخدام HTTP/2، يقوم هذا الخيار بتعيين الوزن الفردي لهذا التدفق المعين الذي يستخدمه المقبض easy. تحديد الأوزان واستخدامها لا معنى له إلا عندما يتم نقل تدفقات متعددة عبر نفس الاتصالات، مما يعني أنك تستخدم CURLMOPT_PIPELINING(3).

يمكن تعيين هذا الخيار أثناء النقل ويتسبب في إرسال معلومات الوزن المحدثة إلى الخادم في المرة التالية التي يتم فيها إرسال إطار HTTP/2 إلى الخادم.

راجع القسم 5.3 من RFC 7540 للحصول على تفاصيل البروتوكول.

يجب تخصيص الموارد للتدفقات التي لها نفس الأصل بشكل نسبي بناءً على وزنها. إذا كان لديك تدفقان، التدفق A بوزن 16 والتدفق B بوزن 32، فسيحصل التدفق B على ثلثي (32/48) عرض النطاق الترددي المتاح (بافتراض أن الخادم يمكنه إرسال البيانات بالتساوي لكلا التدفقين).

الافتراضي

16

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  CURL *curl2 = curl_easy_init(); /* مقبض ثانٍ */
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/one");
    curl_easy_setopt(curl, CURLOPT_STREAM_WEIGHT, 10L);
    /* الثاني له ضعف الوزن */
    curl_easy_setopt(curl2, CURLOPT_URL, "https://example.com/two");
    curl_easy_setopt(curl2, CURLOPT_STREAM_WEIGHT, 20L);
    /* ثم أضف كليهما إلى مقبض متعدد وانقلهما */
  }
}

قيمة الإرجاع

curl_easy_setopt(3) يُرجع رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، وغير الصفر يعني حدوث خطأ، انظر libcurl-errors(3).
