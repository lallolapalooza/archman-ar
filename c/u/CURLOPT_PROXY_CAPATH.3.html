CURLOPT_PROXY_CAPATH(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROXY_CAPATH(3) دليل الوظائف المكتبية CURLOPT_PROXY_CAPATH(3)

الاسم

CURLOPT_PROXY_CAPATH - دليل يحتوي على شهادات CA لـ HTTPS الوكيل.

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROXY_CAPATH, char *capath);

الوصف

قم بتمرير مؤشر حرف إلى سلسلة نصية منتهية بصفر تحدد دليلاً يحتوي على شهادات CA متعددة للتحقق من وكيل HTTPS. إذا تم بناء libcurl ضد OpenSSL، فيجب إعداد دليل الشهادات باستخدام أداة OpenSSL c_rehash. يكون هذا منطقيًا فقط عندما يتم تمكين CURLOPT_PROXY_SSL_VERIFYPEER(3) (وهو ما يتم افتراضياً).

لا يحتاج التطبيق إلى الاحتفاظ بالسلسلة النصية بعد تعيين هذا الخيار.

استخدام هذا الخيار عدة مرات يجعل السلسلة النصية الأخيرة التي تم تعيينها تلغي ما قبلها. قم بتعيينها إلى NULL لتعطيل استخدامها مرة أخرى والعودة إلى الافتراضي الداخلي.

يمكن معرفة القيمة الافتراضية لهذا باستخدام CURLINFO_CAPATH(3).

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المستندة إلى TLS: HTTPS، FTPS، IMAPS، POP3S، SMTPS إلخ.

يعمل هذا الخيار فقط مع الخلفيات TLS التالية: GnuTLS، OpenSSL و mbedTLS

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com/");
    /* استخدام وكيل HTTPS */
    curl_easy_setopt(curl, CURLOPT_PROXY, "https://localhost:443");
    curl_easy_setopt(curl, CURLOPT_PROXY_CAPATH, "/etc/cert-dir");
    res = curl_easy_perform(curl);
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.52.0

CURLE_UNKNOWN_OPTION

CURLE_OUT_OF_MEMORY
