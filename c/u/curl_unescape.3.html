curl_unescape(3)

الحزمة: curl

التراخيص: MIT

curl_unescape(3) دليل وظائف المكتبة curl_unescape(3)

الاسم

curl_unescape - فك تشفير سلسلة URL

الملخص

#include <curl/curl.h>
char *curl_unescape(const char *input, int length);

الوصف

مهمل. استخدم curl_easy_unescape(3) بدلاً من ذلك.

تقوم هذه الوظيفة بتحويل سلسلة URL المشفرة input إلى "سلسلة نصية عادية" وإعادتها كسلسلة جديدة مخصصة. يتم تحويل جميع أحرف الإدخال المشفرة بـ URL (%XX حيث XX هو رقم ست عشري مكون من رقمين) إلى إصداراتها النصية العادية.

إذا تم تعيين الوسيط length إلى 0، فإن curl_unescape(3) يستدعي strlen() على input لمعرفة الحجم.

يجب عليك curl_free(3) السلسلة المعاد إرجاعها عند الانتهاء منها.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    char *decoded = curl_unescape("%63%75%72%6c", 12);
    if(decoded) {
      /* لا تفترض أن printf() تعمل على البيانات المفككة */
      printf("مفكوك: ");
      /* ... */
      curl_free(decoded);
    }
  }
}

مهمل

منذ الإصدار 7.15.4، يجب استخدام curl_easy_unescape(3). قد تتم إزالة هذه الوظيفة في إصدار مستقبلي.

التوفر

تمت الإضافة في curl 7.1

القيمة المعادة

مؤشر إلى سلسلة منتهية بالصفر أو NULL إذا فشلت.
