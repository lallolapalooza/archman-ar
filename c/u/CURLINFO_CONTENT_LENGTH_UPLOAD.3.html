CURLINFO_CONTENT_LENGTH_UPLOAD(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_CONTENT_LENGTH_UPLOAD(3) دليل الوظائف المكتبية CURLINFO_CONTENT_LENGTH_UPLOAD(3)

الاسم

CURLINFO_CONTENT_LENGTH_UPLOAD - الحصول على حجم التحميل المحدد

ملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_CONTENT_LENGTH_UPLOAD,
                           double *content_length);

الوصف

مرر مؤشرًا إلى مضاعف (double) لاستقبال حجم التحميل المحدد. منذ الإصدار 7.19.4، يقوم هذا بإرجاع -1 إذا كان الحجم غير معروف.

CURLINFO_CONTENT_LENGTH_UPLOAD_T(3) هو بديل أحدث يعيد نوع متغير أكثر منطقية.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* قم بالتحميل */
    res = curl_easy_perform(curl);
    if(!res) {
      /* تحقق من الحجم */
      double cl;
      res = curl_easy_getinfo(curl, CURLINFO_CONTENT_LENGTH_UPLOAD, &cl);
      if(!res) {
        printf("الحجم: %.0f\n", cl);
      }
    }
  }
}

مهمل

تم إهماله منذ الإصدار 7.55.0.

التوفر

تمت إضافته في curl 7.6.1

قيمة الإرجاع

curl_easy_getinfo(3) يعيد رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، والقيمة غير الصفرية تعني حدوث خطأ، انظر libcurl-errors(3).
