Curses__UI__Progressbar(3pm)

الحزمة: perl-curses-ui

التراخيص: GPL, PerlArtistic

Curses::UI::Progressbar(3) وثائق Perl المساهمة من المستخدم Curses::UI::Progressbar(3)

الاسم

Curses::UI::Progressbar - إنشاء ومعالجة عناصر شريط التقدم

تسلسل الفئات

Curses::UI::Widget
   |
   +----Curses::UI::Progressbar

الملخص

use Curses::UI;
my $cui = new Curses::UI;
my $win = $cui->add('window_id', 'Window');
my $progressbar = $win->add(
    'myprogressbar', 'Progressbar',
    -max       => 250,
    -pos       => 42,
);
$progressbar->draw;

الوصف

Curses::UI::Progressbar هو عنصر واجهة مستخدم يمكن استخدامه لتوفير نوع من معلومات التقدم لمستخدم برنامجك. يبدو شريط التقدم هكذا:

+------------------------------------------+
|||||||||---------- 14% ------------------ |
+------------------------------------------+

راجع أمثلة/demo-Curses::UI::Progressbar في التوزيع التجريبي لعرض توضيحي قصير.

خيارات قياسية

-parent، -x، -y، -width، -height، -pad، -padleft، -padright، -padtop، -padbottom، -ipad، -ipadleft، -ipadright، -ipadtop، -ipadbottom، -title، -titlefullwidth، -titlereverse

لشرح هذه الخيارات القياسية، انظر Curses::UI::Widget.

خيارات خاصة بالعنصر

  • -min < VALUE >

    يحدد هذا الخيار الحد الأدنى لقيمة شريط التقدم. القيمة الافتراضية هي 0.

  • -max < VALUE >

    يحدد هذا الخيار الحد الأقصى لقيمة شريط التقدم.

  • -pos < VALUE >

    يحدد هذا الخيار موضع البداية لشريط التقدم.

  • -nopercentage < BOOLEAN >

    يتحكم هذا الخيار فيما إذا كان سيتم رسم مؤشر نسبة مئوية في العنصر. القيمة الافتراضية لـ BOOLEAN هي false، لذلك سيتم رسم مؤشر النسبة المئوية.

  • -showvalue < BOOLEAN >

    إذا تم تعيين هذا الخيار إلى قيمة صحيحة، فسيتم رسم قيمة الموضع الحالية في العنصر.

  • -nocenterline < BOOLEAN >

    يتحكم هذا الخيار فيما إذا كان سيتم رسم خط أفقي في العنصر. القيمة الافتراضية لـ BOOLEAN هي false، لذلك سيتم رسم خط أفقي.

الأساليب

  • new ( OPTIONS )
  • layout ( )
  • draw ( BOOLEAN )
  • intellidraw ( )
  • focus ( )

    هذه أساليب قياسية. انظر Curses::UI::Widget لشرحها.

  • get ( )

    سيعيد هذا الأسلوب قيمة -pos الحالية للعنصر.

  • pos ( VALUE )

    سيقوم هذا الأسلوب بتعيين قيمة -pos للعنصر إلى SCALAR.

الربطات الافتراضية

نظرًا لأن شريط التقدم هو عنصر غير تفاعلي، فإنه لا يحتوي على أي ربطات.

انظر أيضًا

Curses::UI, Curses::UI::Widget, Curses::UI::Common
