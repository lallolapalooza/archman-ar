CURLOPT_TRANSFER_ENCODING(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_TRANSFER_ENCODING(3) دليل الوظائف المكتبية CURLOPT_TRANSFER_ENCODING(3)

الاسم

CURLOPT_TRANSFER_ENCODING - طلب الترميز الانتقالي HTTP

الملخص

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_TRANSFER_ENCODING,
                          long enable);

الوصف

مرر قيمة طويلة (long) مضبوطة على 1L لـ تمكين أو 0 لـ تعطيل.

يضيف طلبًا لترميز انتقالي مضغوط في طلب HTTP الصادر. إذا كان الخادم يدعم ذلك ويرغب فيه، يمكنه الاستجابة مع استجابة HTTP مرسلة باستخدام ترميز انتقالي مضغوط يتم فك ضغطه تلقائيًا بواسطة libcurl عند الاستقبال.

يختلف الترميز الانتقالي (Transfer-Encoding) قليلاً عن الترميز اللاحق (Content-Encoding) الذي تطلبه باستخدام CURLOPT_ACCEPT_ENCODING(3)، حيث أن الترميز الانتقالي مخصص بشكل صارم للنقل وبالتالي يجب فك ترميزه قبل وصول البيانات إلى العميل. تقليديًا، تم استخدام الترميز الانتقالي بشكل أقل بكثير ودعمه من قبل كل من عملاء HTTP وخوادم HTTP.

الافتراضي

0

البروتوكولات

تؤثر هذه الوظيفة على http فقط

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_TRANSFER_ENCODING, 1L);
    curl_easy_perform(curl);
  }
}
