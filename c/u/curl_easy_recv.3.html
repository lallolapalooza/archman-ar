curl_easy_recv(3)

الحزمة: curl

التراخيص: MIT

curl_easy_recv(3) دليل الدوال المكتبية curl_easy_recv(3)

الاسم

curl_easy_recv - يستقبل بيانات خام على اتصال "سهل"

الملخص

#include <curl/curl.h>
CURLcode curl_easy_recv(CURL *curl, void *buffer, size_t buflen, size_t *n);

الوصف

تستقبل هذه الدالة بيانات خام من الاتصال المُنشأ. يمكنك استخدامها مع curl_easy_send(3) لتنفيذ بروتوكولات مخصصة باستخدام libcurl. يمكن أن تكون هذه الوظيفة مفيدة بشكل خاص إذا كنت تستخدم بروكسيات و/أو تشفير SSL: libcurl يعتني بتفاوض البروكسي وإعداد الاتصال.

buffer هو مؤشر إلى ذاكرة المخزن المؤقت الخاص بك التي يتم ملؤها بالبيانات المستلمة. buflen هو الحد الأقصى للبيانات التي يمكنك الحصول عليها في ذلك المخزن المؤقت. المتغير n يشير إلى عدد البايتات المستلمة.

لإنشاء الاتصال، قم بتعيين الخيار CURLOPT_CONNECT_ONLY(3) قبل استدعاء curl_easy_perform(3) أو curl_multi_perform(3). لاحظ أن curl_easy_recv(3) لا تعمل على الاتصالات التي تم إنشاؤها بدون هذا الخيار.

تعود الاستدعاء بقيمة CURLE_AGAIN إذا لم تكن هناك بيانات للقراءة - يتم استخدام المقبس في وضع غير متزامن داخليًا. عندما تعود قيمة CURLE_AGAIN، استخدم تسهيلات نظام التشغيل الخاصة بك مثل select(2) للانتظار للبيانات. يمكن الحصول على المقبس باستخدام curl_easy_getinfo(3) مع CURLINFO_ACTIVESOCKET(3).

انتظر على المقبس فقط إذا عادت curl_easy_recv(3) بقيمة CURLE_AGAIN. السبب في ذلك هو أن libcurl أو مكتبة SSL قد تقوم بتخزين بعض البيانات مؤقتًا داخليًا، لذلك يجب عليك استدعاء curl_easy_recv(3) حتى يتم قراءة جميع البيانات، والتي قد تشمل أي بيانات مخزنة مؤقتًا.

علاوة على ذلك، إذا انتظرت على المقبس وأخبرك بأن هناك بيانات للقراءة، فقد تعود curl_easy_recv(3) بقيمة CURLE_AGAIN إذا كانت البيانات الوحيدة التي تمت قراءتها مخصصة لمعالجة SSL الداخلية، ولم تتوفر أي بيانات أخرى.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* لا تقم بالنقل - فقط اتصل بالمضيف */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res == CURLE_OK) {
      char buf[256];
      size_t nread;
      curl_socket_t sockfd;
      /* استخرج المقبس من مقبض curl - نحتاجه للانتظار. */
      res = curl_easy_getinfo(curl, CURLINFO_ACTIVESOCKET, &sockfd);
      /* اقرأ البيانات */
      res = curl_easy_recv(curl, buf, sizeof(buf), &nread);
    }
  }
}

التوفر

تمت إضافتها في curl 7.18.2

قيمة الإرجاع

عند النجاح، تعود بقيمة CURLE_OK، وتقوم بتخزين البيانات المستلمة في buffer، وعدد البايتات التي قرأتها فعليًا في *n.

عند الفشل، تعود برمز الخطأ المناسب.

قد تعود الدالة بقيمة CURLE_AGAIN. في هذه الحالة، استخدم تسهيلات نظام التشغيل الخاص بك للانتظار حتى يمكن قراءة البيانات، ثم أعد المحاولة.

قراءة 0 بايت بالضبط تشير إلى اتصال مغلق.

إذا لم يكن هناك مقبس متاح للاستخدام من النقل السابق، فإن هذه الدالة تعود بقيمة CURLE_UNSUPPORTED_PROTOCOL.
