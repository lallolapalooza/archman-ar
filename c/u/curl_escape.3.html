curl_escape(3)

الحزمة: curl

التراخيص: MIT

curl_escape(3) دليل وظائف المكتبة curl_escape(3)

الاسم

curl_escape - ترميز سلسلة نصية لـ URL

التركيب

#include <curl/curl.h>
char *curl_escape(const char *string, int length);

الوصف

وظيفة مهملة. استخدم curl_easy_escape(3) بدلاً من ذلك.

تقوم هذه الوظيفة بتحويل string المدخل المعطى إلى سلسلة نصية مرمزة لـ URL وتعيدها كسلسلة نصية مخصصة جديدة. يتم تحويل جميع أحرف الإدخال التي ليست a-z أو A-Z أو 0-9 إلى نسختها "المهربة لـ URL" (%NN حيث NN هو رقم ست عشري من خانتين).

إذا تم تعيين الوسيط length إلى 0، فإن curl_escape(3) تستخدم strlen() على string لمعرفة الحجم.

يجب عليك استدعاء curl_free(3) على السلسلة النصية المعادة عند الانتهاء منها.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  char *output = curl_escape("data to convert", 15);
  if(output) {
    printf("Encoded: %s\n", output);
    curl_free(output);
  }
}

تاريخ

منذ الإصدار 7.15.4، يجب استخدام curl_easy_escape(3). قد تتم إزالة هذه الوظيفة في إصدار مستقبلي.

التوفر

تمت الإضافة في curl 7.1

قيمة الإرجاع

مؤشر إلى سلسلة نصية منتهية بـ null أو NULL إذا فشلت.
