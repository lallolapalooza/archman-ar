CURLINFO_ACTIVESOCKET(3)

الحزمة: curl

التراخيص: MIT

CURLINFO_ACTIVESOCKET(3) دليل وظائف المكتبة CURLINFO_ACTIVESOCKET(3)

اسم

CURLINFO_ACTIVESOCKET - الحصول على المقبس النشط

ملخص

#include <curl/curl.h>
CURLcode curl_easy_getinfo(CURL *handle, CURLINFO_ACTIVESOCKET,
                           curl_socket_t *socket);

الوصف

قم بتمرير مؤشر إلى curl_socket_t لتلقي المقبس النشط الأخير المستخدم لاتصال النقل بواسطة جلسة curl هذه. إذا لم يعد المقبس صالحًا، فسيتم إرجاع CURL_SOCKET_BAD. عندما تنتهي من العمل مع المقبس، يجب عليك استدعاء curl_easy_cleanup(3) كالمعتاد على مقبض الاستخدام البسيط والسماح لمكتبة libcurl بإغلاق المقبس وتنظيف الموارد الأخرى المرتبطة بالمقبض. يعيد هذا الخيار المقبس النشط فقط بعد اكتمال النقل، ويتم استخدامه عادةً بالاشتراك مع CURLOPT_CONNECT_ONLY(3)، الذي يتخطى مرحلة النقل.

CURLINFO_ACTIVESOCKET(3) تمت إضافته كبديل لـ CURLINFO_LASTSOCKET(3) نظرًا لأن الأخير لا يعمل على جميع المنصات.

بروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    CURLcode res;
    curl_socket_t sockfd;
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    /* لا تقم بالنقل - فقط اتصل بالمضيف */
    curl_easy_setopt(curl, CURLOPT_CONNECT_ONLY, 1L);
    res = curl_easy_perform(curl);
    if(res != CURLE_OK) {
      printf("خطأ: %s\n", curl_easy_strerror(res));
      curl_easy_cleanup(curl);
      return 1;
    }
    /* استخراج المقبس من مقبض curl */
    res = curl_easy_getinfo(curl, CURLINFO_ACTIVESOCKET, &sockfd);
    if(!res && sockfd != CURL_SOCKET_BAD) {
      /* عامل المقبس sockfd */
    }
    curl_easy_cleanup(curl);
  }
}

التوفر

تمت الإضافة في curl 7.45.0

قيمة الإرجاع

curl_easy_getinfo(3) تعيد قيمة CURLcode تشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، وقيمة غير صفرية تعني حدوث خطأ، راجع libcurl-errors(3).
