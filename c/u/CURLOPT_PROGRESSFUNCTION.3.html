CURLOPT_PROGRESSFUNCTION(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_PROGRESSFUNCTION(3) دليل وظائف المكتبة CURLOPT_PROGRESSFUNCTION(3)

الاسم

CURLOPT_PROGRESSFUNCTION - وظيفة استدعاء لإظهار التقدم

الملخص

#include <curl/curl.h>
int progress_callback(void *clientp,
                      double dltotal,
                      double dlnow,
                      double ultotal,
                      double ulnow);
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_PROGRESSFUNCTION,
                          progress_callback);

الوصف

مرر مؤشرًا إلى دالة الاستدعاء الخاصة بك، والتي يجب أن تطابق النموذج الأولي المعروض أعلاه.

هذا الخيار مهمل ونشجع المستخدمين على استخدام CURLOPT_XFERINFOFUNCTION(3) الأحدث بدلاً منه، إذا استطعتم.

يتم استدعاء هذه الدالة بواسطة libcurl بدلاً من مكافئها الداخلي بفواصل زمنية متكررة. أثناء نقل البيانات، يتم استدعاؤها بشكل متكرر، وخلال فترات البطء مثل عدم نقل أي بيانات، يمكن أن تنخفض إلى حوالي استدعاء واحد في الثانية.

clientp هو المؤشر المعين باستخدام CURLOPT_PROGRESSDATA(3)، ولا تستخدمه libcurl ولكنه يتم تمريره فقط من التطبيق إلى دالة الاستدعاء.

يتم إعلام دالة الاستدعاء بكمية البيانات التي تتوقع libcurl نقلها وكم تم نقله، بالبايت. dltotal هو إجمالي عدد البايتات التي تتوقع libcurl تنزيلها في هذا النقل. dlnow هو عدد البايتات التي تم تنزيلها حتى الآن. ultotal هو إجمالي عدد البايتات التي تتوقع libcurl تحميلها في هذا النقل. ulnow هو عدد البايتات التي تم تحميلها حتى الآن.

يتم تعيين قيم الوسائط غير المعروفة/غير المستخدمة التي يتم تمريرها إلى دالة الاستدعاء إلى صفر (مثل إذا كنت تقوم فقط بتنزيل البيانات، يظل حجم التحميل 0). في كثير من الأحيان، يتم استدعاء دالة الاستدعاء مرة واحدة أو أكثر أولاً، قبل أن تعرف أحجام البيانات، لذا يجب أن يكون البرنامج قادرًا على التعامل مع ذلك.

أرجع صفرًا من دالة الاستدعاء إذا كان كل شيء على ما يرام.

إذا أعادت دالة الاستدعاء الخاصة بك CURL_PROGRESSFUNC_CONTINUE، فإنها تتسبب في قيام libcurl بمتابعة تنفيذ دالة التقدم الافتراضية.

أرجع 1 من دالة الاستدعاء هذه لجعل libcurl تتوقف عن النقل وإرجاع CURLE_ABORTED_BY_CALLBACK.

إذا كنت تنقل البيانات باستخدام الواجهة المتعددة، فلن يتم استدعاء هذه الدالة خلال فترات الخمول ما لم تقم باستدعاء دالة libcurl المناسبة التي تنفذ عمليات النقل.

يجب تعيين CURLOPT_NOPROGRESS(3) إلى 0 لجعل هذه الدالة يتم استدعاؤها فعليًا.

الافتراضي

NULL. لدى libcurl مؤشر تقدم داخلي. لا يرغب المستخدمون في ذلك غالبًا.

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct progress {
  char *private;
  size_t size;
};
static int progress_callback(void *clientp,
                             double dltotal,
                             double dlnow,
                             double ultotal,
                             double ulnow)
{
  struct progress *memory = clientp;
  printf("private: %p\n", memory->private);
  /* استخدم القيم */
  return 0; /* كل شيء على ما يرام */
}
int main(void)
{
  struct progress data;
  CURL *curl = curl_easy_init();
  if(curl) {
    /* تمرير الهيكل إلى دالة الاستدعاء  */
    curl_easy_setopt(curl, CURLOPT_PROGRESSDATA, &data);
    curl_easy_setopt(curl, CURLOPT_PROGRESSFUNCTION, progress_callback);
    curl_easy_perform(curl);
  }
}

مهمل

مهمل منذ الإصدار 7.32.0.

قيمة الإرجاع
