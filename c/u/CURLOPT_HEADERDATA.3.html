CURLOPT_HEADERDATA(3)

الحزمة: curl

التراخيص: MIT

CURLOPT_HEADERDATA(3) دليل الدوال المكتبية CURLOPT_HEADERDATA(3)

الاسم

CURLOPT_HEADERDATA - مؤشر لتمريره لدالة رد الاتصال بالترويسة

الخلاصة

#include <curl/curl.h>
CURLcode curl_easy_setopt(CURL *handle, CURLOPT_HEADERDATA, void *pointer);

الوصف

مرر مؤشر لاستخدامه في كتابة جزء الترويسة من البيانات المستلمة إليه.

إذا تم استخدام CURLOPT_WRITEFUNCTION(3) أو CURLOPT_HEADERFUNCTION(3)، يتم تمرير المؤشر إلى دالة رد الاتصال المقابلة.

إذا لم يتم تعيين أي من هذين الخيارين، يجب أن يكون المؤشر عبارة عن FILE * صالح ويتم استخدامه بواسطة fwrite() عادي لكتابة الترويسات إليه.

إذا كنت تستخدم libcurl كملف DLL لنظام Windows، فيجب عليك استخدام CURLOPT_WRITEFUNCTION(3) أو CURLOPT_HEADERFUNCTION(3) إذا قمت بتعيين هذا الخيار وإلا فقد تواجه أعطالاً.

الافتراضي

NULL

البروتوكولات

تؤثر هذه الوظيفة على جميع البروتوكولات المدعومة

مثال

struct my_info {
  int shoesize;
  char *secret;
};
static size_t header_callback(char *buffer, size_t size,
                              size_t nitems, void *userdata)
{
  struct my_info *i = userdata;
  printf("shoe size: %d\n", i->shoesize);
  /* الآن يمكن لدالة رد الاتصال الوصول إلى بنية my_info */
  return nitems * size;
}
int main(void)
{
  CURL *curl = curl_easy_init();
  if(curl) {
    struct my_info my = { 10, "the cookies are in the cupboard" };
    curl_easy_setopt(curl, CURLOPT_URL, "https://example.com");
    curl_easy_setopt(curl, CURLOPT_HEADERFUNCTION, header_callback);
    /* تمرير بيانات مخصصة لدالة رد الاتصال */
    curl_easy_setopt(curl, CURLOPT_HEADERDATA, &my);
    curl_easy_perform(curl);
  }
}

التوفر

تمت إضافته في curl 7.10

قيمة الإرجاع

curl_easy_setopt(3) يعيد رمز CURLcode يشير إلى النجاح أو الخطأ.

CURLE_OK (0) يعني أن كل شيء كان على ما يرام، أي قيمة غير صفرية تعني حدوث خطأ، راجع libcurl-errors(3).
