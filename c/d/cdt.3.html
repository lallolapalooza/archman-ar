الوصف

Cdt يدير قواميس وقت التشغيل باستخدام أنواع بيانات الحاويات القياسية: مجموعات/مجموعات متعددة غير مرتبة، مجموعات/مجموعات متعددة مرتبة، قائمة، ومكدس.

أنواع القواميس

Dt_t

هذا هو نوع مقبض القاموس.

Dtdisc_t

يحدد هذا نوع بنية الانضباط الذي يصف تنسيق الكائن ووظائف التعامل معه.

Dtmethod_t

يحدد هذا نوع طريقة الحاوية.

Dtlink_t

هذا هو نوع حامل كائن القاموس (انظر dtdisc()).

Dtstat_t

هذا هو نوع بنية لإرجاع إحصائيات القاموس (انظر dtstat()).

التحكم في القاموس

Dt_t* dtopen(const Dtdisc_t* disc, const Dtmethod_t* meth)

يقوم هذا بإنشاء قاموس جديد. disc هو بنية انضباط لوصف تنسيق الكائن. meth يحدد طريقة المعالجة. dtopen() تعيد القاموس الجديد أو NULL عند حدوث خطأ.

int dtclose(Dt_t* dt)

يقوم هذا بحذف dt وكائناته. ملاحظة أن dtclose() تفشل إذا كان dt يتم عرضه بواسطة قواميس أخرى (انظر dtview()). dtclose() تعيد 0 عند النجاح و -1 عند حدوث خطأ.

void dtclear(Dt_t* dt)

يقوم هذا بحذف جميع الكائنات في dt دون إغلاق dt.

Dtmethod_t dtmethod(Dt_t* dt, const Dtmethod_t* meth)

إذا كان meth هو NULL، فإن dtmethod() تعيد الطريقة الحالية. بخلاف ذلك، تقوم بتغيير طريقة تخزين dt إلى meth. قد يتسبب التبديل إلى Dtset ومن Dtoset/Dtobag أو العكس في إعادة تجزئة الكائنات، أو إعادة ترتيبها، أو إزالتها حسب الاقتضاء. dtmethod() تعيد الطريقة السابقة أو NULL عند حدوث خطأ.

Dtdisc_t* dtdisc(Dt_t* dt, const Dtdisc_t* disc)

إذا كان disc هو NULL، فإن dtdisc() تعيد الانضباط الحالي. بخلاف ذلك، تقوم بتغيير انضباط dt إلى disc. قد يتم إعادة تجزئة الكائنات، أو إعادة ترتيبها، أو إزالتها حسب الاقتضاء. dtdisc() تعيد الانضباط السابق عند النجاح و NULL عند حدوث خطأ.

Dt_t* dtview(Dt_t* dt, Dt_t* view)

يسمح مسار العرض للبحث أو المشي بدءًا من قاموس بالاستمرار إلى قاموس آخر. dtview() تقوم أولاً بإنهاء أي عرض حالي من dt إلى قاموس آخر. ثم، إذا كان view هو NULL، فإن dtview() تعيد قاموس العرض الذي تم إنهاؤه. إذا كان view ليس NULL، يتم إنشاء مسار عرض من dt إلى view. dtview() تعيد dt عند النجاح و NULL عند حدوث خطأ.

يعد وجود قواميس على مسار العرض بطرق تخزين مختلفة خطأ. بالإضافة إلى ذلك، يجب أن تعامل القواميس الموجودة على نفس مسار العرض الكائنات بطريقة متسقة فيما يتعلق بالمقارنة أو التجزئة. إذا لم يكن الأمر كذلك، فقد تنتج سلوكيات غير محددة.

طرق التخزين

طرق التخزين من النوع Dtmethod_t*. تدعم Cdt الطرق التالية:

Dtoset

Dtobag

يتم ترتيب الكائنات حسب المقارنات. Dtoset تحتفظ بكائنات فريدة. Dtobag يسمح بكائنات متكررة.

Dtset

الكائنات غير مرتبة. Dtset تحتفظ بكائنات فريدة. تستخدم هذه الطريقة جدول تجزئة مع سلسلة لإدارة الكائنات.

الانضباط

يتم تعريف تنسيق الكائن ووظائف الإدارة المرتبطة به في نوع Dtdisc_t:

    typedef struct
    { int        key, size;
      int        link;
      Dtmake_f   makef;
      Dtfree_f   freef;
      Dtcompar_f comparf;
    } Dtdisc_t;

int key, size

يتم تحديد كل كائن obj بواسطة مفتاح يستخدم لمقارنة الكائن أو تجزئته. يجب أن يكون المفتاح غير سالب ويحدد إزاحة داخل obj. إذا كان size سالبًا، فإن المفتاح هو سلسلة منتهية بصفر مع عنوان بدء *(void**)((char*)obj+key). إذا كان size صفرًا، فإن المفتاح هو سلسلة منتهية بصفر مع عنوان بدء (void*)((char*)obj+key). أخيرًا، إذا كان size موجبًا، فإن المفتاح هو مصفوفة بايت بطول size تبدأ عند (void*)((char*)obj+key).

int link

ليكن obj كائنًا سيتم إدخاله في dt كما هو موضح أدناه. إذا كان link سالبًا، يتم استخدام كائن حامل مخصص داخليًا للاحتفاظ بـ obj. بخلاف ذلك، يجب أن يحتوي obj على بنية Dtlink_t مضمنة مسافة link بايت بداخله، أي عند العنوان (Dtlink_t*)((char*)obj+link).

void* (*makef)(void* obj, Dtdisc_t* disc)

إذا كان makef ليس NULL، فسيقوم dtinsert(dt,obj) باستدعائه لإنشاء نسخة من obj مناسبة للإدراج في dt. إذا كان makef NULL، فسيتم إدراج obj نفسه في dt.
