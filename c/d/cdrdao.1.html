NAME

cdrdao

manual for burning CDs

SYNOPSIS

cdrdao [-v level] [-n] [-f] [-h] [toc-file]

cdrdao [-v level] [-n] [-f] [-h] [--device <device>] [--driver <driver>] [--speed <speed>] [--buffers <buffers>] [toc-file]

cdrdao [-v level] [-n] [-f] [-h] [--device <device>] [--driver <driver>] [--source-device <device>] [--source-driver <driver>] [--paranoia-mode <mode>] [--cddb-servers <servers>] [--cddb-timeout <timeout>] [--cddb-directory <dir>] [--tmpdir <dir>] read-cd <device> <toc-file>

cdrdao [-v level] [-n] [-f] [-h] [--device <device>] [--driver <driver>] [read-toc <device> <toc-file>]

cdrdao [-v level] [-n] [-f] [-h] [--device <device>] [--driver <driver>] blank <device>

cdrdao [-v level] [-n] [-f] [-h] [--device <device>] [--driver <driver>] [disk-info <device>]

cdrdao [-v level] [-n] [-f] [-h] [--device <device>] [--driver <driver>] [unlock <device>]

cdrdao [-v level] [-n] [-f] [-h] [copy <device> <device>]

cdrdao [-v level] [-n] [-f] [-h] [--read-subchannels <mode>] [--device <device>] [--driver <driver>] read-cddb <toc-file>

DESCRIPTION

cdrdao is a command line tool for burning CDs. It is designed to be a successor of cdrecord(1) but with a simpler interface.

The cdrdao command can be used for the following tasks:

Burning CDs
Create audio or data CDs from disk images or files.
Copying CDs
Duplicate audio or data CDs.
Reading CDs
Create disk images from audio or data CDs.
Blanking CDs
Erase rewritable CDs.
Querying CD drives
Get information about the CD drive and its capabilities.

The primary interface for defining CD layouts is the TOC file. A TOC file describes the structure of the CD, including the tracks, their types (audio or data), their positions, and the files to be used for each track.

COMMANDS

The following commands are supported by cdrdao:

write
Writes a CD according to the specified TOC file. This is the default command if no other command is specified.
simulate
Simulates writing a CD. No data is actually written to the CD.
copy
Copies a CD from one drive to another.
read-toc
Reads the Table of Contents (TOC) from a CD and saves it to a TOC file.
read-cd
Reads the entire content of a CD and saves it to a disk image file.
blank
Blanks a rewritable CD.
disk-info
Prints information about the CD drive and the inserted CD.
unlock
Unlocks a CD drive.
read-cddb
Reads CDDB information for the inserted CD.

OPTIONS

cdrdao supports the following options:

-v level
Sets the verbosity level. Higher levels print more detailed information about the burning process.
-n
No simulation. Forces cdrdao to actually write the CD, even if a simulation is already performed.
-f
Forces cdrdao to overwrite existing files or overwrite safety checks.
-h
Prints a help message and exits.
--device <device>
Specifies the CD/DVD writer device. If not specified, cdrdao tries to auto-detect the device.
--driver <driver>
Specifies the driver to use for the CD/DVD writer. If not specified, cdrdao tries to auto-detect the driver.
--speed <speed>
Specifies the writing speed. The speed is usually represented as a multiplier of the original CD speed (e.g., 24x, 48x).
--buffers <buffers>
Specifies the number of FIFO buffers to use for writing. This can influence the writing performance and stability.
--source-device <device>
Specifies the source CD drive for copying or reading.
--source-driver <driver>
Specifies the driver for the source CD drive.
--paranoia-mode <mode>
Specifies the paranoia mode for reading CDs. Paranoia mode is used to detect and correct read errors.
--cddb-servers <servers>
Specifies a list of CDDB servers to query for CD information.
--cddb-timeout <timeout>
Sets the connection timeout in seconds for CDDB queries.
--cddb-directory <dir>
Specifies the directory where CDDB data will be stored locally.
--tmpdir <dir>
Specifies the directory for temporary files, such as decoded audio files.
--read-subchannels <mode>
Specifies the mode for reading subchannel data. Supported modes are auto, force, and none.

TOC FILES

TOC files are plain text files that describe the structure of a CD. They are used by cdrdao to create audio or data CDs.

A TOC file consists of several sections, each starting with a keyword followed by its parameters. The following keywords are supported:

CD_DA
Specifies that the CD is an audio CD.
CD_ROM
Specifies that the CD is a data CD.
TRACK
Defines a track on the CD. The track type (e.g., AUDIO, MODE1, MODE2) follows the keyword.
FILE
Specifies the file to be used for the current track. The file name is followed by an optional time offset and size. For example, FILE "track.wav" 0:10:0 1:0:0 means that the track starts at 10 seconds into the file and the first minute of the file is used.
START
Specifies the start time of the current track. This is used when the track data is taken from a larger file.
PREGAP
Specifies the length of the pre-gap for the current track. The pre-gap is the silence before the actual track data.
SILENCE
Inserts silence of the specified duration.
INDEX
Defines an index point within a track. Index points are used to mark specific locations within a track, for example, for chapter points in an audiobook.
ISRC
Specifies the ISRC (International Standard Recording Code) for the current track.
POSTGAP
Specifies the length of the post-gap for the current track. The post-gap is the silence after the actual track data.
CD_TEXT
Specifies CD-TEXT information for the CD or a track. This includes title, performer, and other metadata.
LANGUAGE
Specifies the language for CD-TEXT information.
LANGUAGE_MAP
Maps language codes to language IDs.
TITLE
Specifies the title of the CD or track.
PERFORMER
Specifies the performer of the CD or track.
DISC_ID
Specifies the unique identifier for the CD.
UPC_EAN
Specifies the UPC/EAN barcode for the CD.
DATAFILE
Specifies the data file for a data track.
ZERO
Inserts a specified amount of zero data. This is typically used for post-gaps in data tracks.

Here are some examples of TOC file entries:

Audio CD with one track:

CD_DA
TRACK AUDIO
PREGAP 0:0:2
FILE "audio.wav" 0
CD_TEXT {
  LANGUAGE 0 {
    TITLE "Audio Track"
    PERFORMER "Artist Name"
  }
}
ISRC "US-ABC-00-12345"

Audio CD with title and performer from CD-TEXT and CD-TEXT:

CD_DA
CD_TEXT {
  LANGUAGE_MAP {
    0 : EN
  }
  LANGUAGE 0 {
    TITLE "CD Title"
    PERFORMER "Performer"
    DISC_ID "XY12345"
    UPC_EAN ""
  }
}
TRACK AUDIO
ISRC "DEXXX9800001"
CD_TEXT {
  LANGUAGE 0 {
    TITLE "Track Title"
    PERFORMER "Performer"
    ISRC "DE-XXX-98-00001"
  }
}
PREGAP 0:2:0
FILE "data.wav" 0

Track with 10 second pre-gap containing audio data from raw file "data.cdr":

CD_DA
TRACK AUDIO
FILE "data.cdr" 0
START 0:10:0

Composed track with data from different files. Pre-gap data and length is taken from "pregapdata.wav". The first minute of "track.cdr" is omitted and two seconds silence are inserted at '2:0:0'. Index will be incremented after 2 and 4 minutes past track start:

CD_DA
TRACK AUDIO
FILE "pregapdata.wav" 0
START
FILE "track.cdr" 1:0:0 1:0:0
SILENCE 0:2:0
FILE "track.cdr" 2:0:0
INDEX 2:0:0
INDEX 4:0:0

Mixed mode CD with a data track as first track followed by two audio tracks.

CD_ROM
TRACK MODE1
DATAFILE "data_1"
ZERO 00:02:00 // post-gap
TRACK AUDIO
SILENCE 00:02:00 // pre-gap
START
FILE "data_2.wav" 0
TRACK AUDIO
FILE "data_3.wav" 0

CUE FILES

Cue files may be used wherever a toc-file is expected. The corresponding bin file is not taken from the FILE statement of a cue file but constructed from the cue file name by replacing ".cue" by ".bin". The cue file must have exactly one FILE statement.

Currently, following track modes are supported: MODE1/2048, MODE1/2352, MODE2/2336, MODE2/2352. The CATALOG, ISRC and POSTGAP statements are parsed but not evaluated, yet.

SETTINGS

Some of the command line options can be stored as settings at following locations. The files will be read on startup of cdrdao in that order:

1. /etc/cdrdao.conf

2. /etc/defaults/cdrdao

3. /etc/default/cdrdao

4. $HOME/.cdrdao

Command line options will overwrite the loaded settings. The settings file contains name - value pairs separated by a colon. String values must be enclosed by ". The file is automatically written if the command line option --save is used but it is also possible to modify it manually. Following values are defined:

write_device
Device used for operations simulate, write, copy, blank, disk-info and unlock. Corresponding option: --device
write_driver
Driver (including driver options) that is used for operations simulate, write, copy, blank, disk-info and unlock. Corresponding option: --driver
write_speed
Specifies writing speed. Corresponding option: --speed
write_buffers
Specifies fifo buffers used for recording. Corresponding option: --buffers
read_device
Device used for operations read-toc, read-cd and copy. Corresponding option: --device or --source-device
read_driver
Driver (including driver options) used for operations read-toc, read-cd and copy. Corresponding option: --driver or --source-driver
read_paranoia_mode
Paranoia mode used for operations read-cd and copy. Corresponding option: --paranoia-mode
cddb_server_list
CDDB server list for read-cddb. Corresponding option: --cddb-servers
cddb_timeout
CDDB connection timeout in seconds used by read-cddb. Corresponding option: --cddb-timeout
cddb_directory
Local directory where fetched CDDB records will be stored, used by read-cddb. Corresponding option: --cddb-directory
tmp_file_dir
Directory where temporary WAV files will be created from decoding MP3 and Ogg Vorbis files. Corresponding option: --tmpdir

BUGS

If the program is terminated during the write/simulation process used IPC resources may not be released. Use ipcs(8) and ipcrm(8) to delete them.
