csvpy(1)

الحزمة: csvkit

التراخيص: MIT

CSVPY(1) csvkit CSVPY(1)

الاسم

csvpy - وثائق csvpy

الوصف

يقوم بتحميل ملف CSV في كائن agate.csv.Reader ثم ينتقل إلى shell Python حتى يتمكن المستخدم من فحص البيانات بالطريقة التي يراها مناسبة:

usage: csvpy [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
             [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-L LOCALE]
             [-S] [--blanks] [--null-value NULL_VALUES [NULL_VALUES ...]]
             [--date-format DATE_FORMAT] [--datetime-format DATETIME_FORMAT]
             [-H] [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [--dict] [--agate]
             [--no-number-ellipsis] [-y SNIFF_LIMIT] [-I]
             [FILE]
تحميل ملف CSV في قارئ CSV ثم الانتقال إلى shell Python.
arguments positionnels:
  FILE                  ملف CSV المراد العمل عليه. إذا تم حذفه، فسيقبل المدخلات
                        كبيانات ممررة عبر STDIN.
arguments facultatifs:
  -h, --help            إظهار رسالة المساعدة هذه والخروج
  --dict                تحميل ملف CSV في DictReader.
  --agate               تحميل ملف CSV في جدول agate.
  --no-number-ellipsis  تعطيل علامة الحذف إذا تم تجاوز الحد الأقصى للدقة.
  -y SNIFF_LIMIT, --snifflimit SNIFF_LIMIT
                        تقييد استنشاق لهجة CSV إلى عدد البايتات المحدد.
                        حدد "0" لتعطيل الاستنشاق تمامًا، أو
                        "-1" لاستنشاق الملف بأكمله.
  -I, --no-inference    تعطيل استنتاج النوع (و --locale، --date-format،
                        --datetime-format، --no-leading-zeroes) عند تحليل
                        المدخلات.

ستقوم هذه الأداة تلقائيًا باستخدام shell IPython إذا كان مثبتًا، وإلا فسوف تستخدم shell Python قيد التشغيل.

ملاحظة:

نظرًا لقيود المنصة، لا يقبل csvpy مدخلات الملفات كبيانات ممررة عبر STDIN.

انظر أيضًا: الوسائط المشتركة لجميع الأدوات.

أمثلة

الاستخدام الأساسي:

$ csvpy examples/dummy.csv
أهلاً بك! تم تحميل "examples/dummy.csv" في كائن قارئ يسمى "reader". >>> next(reader) ['a', 'b', 'c']

كقاموس:

$ csvpy --dict examples/dummy.csv
أهلاً بك! تم تحميل "examples/dummy.csv" في كائن DictReader يسمى "reader".
>>> next(reader)
{'a': '1', 'c': '3', 'b': '2'}

كجدول agate:

$ csvpy --agate examples/dummy.csv
أهلاً بك! تم تحميل "examples/dummy.csv" في كائن from_csv يسمى "reader".
>>> reader.print_table()
|    a | b | c |
| ---- | - | - |
| True | 2 | 3 |
