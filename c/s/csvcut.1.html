الحزمة: csvkit

التراخيص: MIT

CSVCUT(1) csvkit CSVCUT(1)

الاسم

csvcut - وثائق csvcut

الوصف

يقوم بتصفية واقتصاص ملفات CSV. مثل أمر "cut" في يونكس، ولكنه للبيانات الجدولية:

usage: csvcut [-h] [-d DELIMITER] [-t] [-q QUOTECHAR] [-u {0,1,2,3}] [-b]
              [-p ESCAPECHAR] [-z FIELD_SIZE_LIMIT] [-e ENCODING] [-S] [-H]
              [-K SKIP_LINES] [-v] [-l] [--zero] [-V] [-n] [-c COLUMNS]
              [-C NOT_COLUMNS] [-x]
              [FILE]
تصفية واقتصاص ملفات CSV. مثل أمر "cut" في يونكس، ولكنه للبيانات الجدولية.
arguments positional:
  FILE                  ملف CSV المراد تشغيله. إذا تم حذفه، فسيتم قبول الإدخال كبيانات
                        مُمررة عبر STDIN.
optional arguments:
  -h, --help            عرض رسالة المساعدة هذه والخروج.
  -n, --names           عرض أسماء وأرقام أعمدة CSV المدخلة والخروج.
  -c COLUMNS, --columns COLUMNS
                        قائمة مفصولة بفواصل من أرقام الأعمدة، أو الأسماء، أو
                        النطاقات المراد استخراجها، على سبيل المثال "1,id,3-5".
                        الافتراضي هو جميع الأعمدة.
  -C NOT_COLUMNS, --not-columns NOT_COLUMNS
                        قائمة مفصولة بفواصل من أرقام الأعمدة، أو الأسماء، أو
                        النطاقات المراد استبعادها، على سبيل المثال "1,id,3-5".
                        الافتراضي هو عدم استبعاد أعمدة. يتجاهل الأعمدة غير
                        المعروفة.
  -x, --delete-empty-rows
                        بعد القص، احذف الصفوف الفارغة تمامًا.

انظر أيضاً: Arguments common to all tools.

ملاحظة:

لا يقوم csvcut بتنفيذ تصفية الصفوف، لهذا يجب تمرير البيانات إلى csvgrep.

ملاحظة:

إذا كان صف البيانات أطول من صف الرأس، فسيتم اقتصاص الأعمدة الإضافية فيه.

أمثلة

طباعة الأعمدة

طباعة أرقام وأسماء جميع الأعمدة:

$ csvcut -n examples/realdata/FY09_EDU_Recipients_by_State.csv
  1: State Name
  2: State Abbreviate
  3: Code
  4: Montgomery GI Bill-Active Duty
  5: Montgomery GI Bill- Selective Reserve
  6: Dependents' Educational Assistance
  7: Reserve Educational Assistance Program
  8: Post-Vietnam Era Veteran's Educational Assistance Program
  9: TOTAL
 10:

طباعة أسماء جميع الأعمدة فقط، عن طريق إزالة الأرقام باستخدام أمر cut:

$ csvcut -n examples/realdata/FY09_EDU_Recipients_by_State.csv | cut -c6-
State Name
State Abbreviate
Code
Montgomery GI Bill-Active Duty
Montgomery GI Bill- Selective Reserve
Dependents' Educational Assistance
Reserve Educational Assistance Program
Post-Vietnam Era Veteran's Educational Assistance Program
TOTAL

استخراج الأعمدة

استخراج العمودين الأول والثالث:

csvcut -c 1,3 examples/realdata/FY09_EDU_Recipients_by_State.csv

استخراج الأعمدة المسماة "TOTAL" و "State Name" (بهذا الترتيب):

csvcut -c TOTAL,"State Name" examples/realdata/FY09_EDU_Recipients_by_State.csv

استخراج عمود قد لا يكون موجوداً في جميع الملفات:

echo d, | csvjoin examples/dummy.csv - | csvcut -c d
 echo d, | csvjoin examples/join_no_header_row.csv - | csvcut -c d

أخرى

إضافة أرقام أسطر إلى ملف، دون إجراء أي تغييرات أخرى:

csvcut -l examples/realdata/FY09_EDU_Recipients_by_State.csv

عرض القيم الفريدة لعمود:

csvcut -c 1 examples/realdata/FY09_EDU_Recipients_by_State.csv | sed 1d | sort | uniq

أو:

csvcut -c 1 examples/realdata/FY09_EDU_Recipients_by_State.csv | csvsql --query 'SELECT DISTINCT("State Name") FROM stdin'
