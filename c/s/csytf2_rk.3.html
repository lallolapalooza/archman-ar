csytf2_rk(3)

الحزمة: lapack-doc

التراخيص: custom

NAME

csytf2_rk — csytf2_rk

SYNOPSIS

SUBROUTINE CSYTF2_RK(
    UPLO, N, NB, A, LDA, D, E, WORK, LWORK, INFO
)
INTEGER N, NB, LDA, LWORK, INFO
COMPLEX A( LDA, * )
REAL D( * ), E( * )
CHARACTER UPLO
COMPLEX WORK( * )

Function/Subroutine Documentation

CSYTF2_RK performs a factorization of a complex Hermitian band matrix that is suitable for solving systems of equations. The factorization is of the form

A = P*U*T*U**H*P**H

where U is a real upper triangular matrix, P is a permutation matrix, and T is a block diagonal matrix with 1-by-1 and 2-by-2 diagonal blocks. All blocks are positive definite. The factorization is obtained using an exact recursively blocked algorithm.

Arguments:

UPLO
CHARACTER*1. Required.
Specifies whether the matrix A is upper or lower Hermitian.
‘U’
A is upper Hermitian.
‘L’
A is lower Hermitian.
N
INTEGER. Required.
The order of the matrix A. N >= 0.
NB
INTEGER. Required.
The block size for the recursively blocked algorithm. NB >= 1.
A
COMPLEX array, dimension (LDA,N).
On entry, the n-by-n matrix A.
On exit, the upper or lower triangular part of A is overwritten by the factors U and T.
LDA
INTEGER. Required.
The leading dimension of the array A. LDA >= max(1,N).
D
REAL array, dimension (N).
On exit, D contains the diagonal elements of T.
E
REAL array, dimension (N-1).
On exit, E contains the subdiagonal elements of T. Only E(i) corresponding to a 2-by-2 block T(i:i+1,i:i+1) is significant.
WORK
COMPLEX array, dimension (LWORK).
Work array.
LWORK
INTEGER. Required.
The dimension of the array WORK. LWORK >= max(1,N).
INFO
INTEGER. Required.
INFO = 0: successful exit
INFO < 0: if INFO = -i, the i-th argument had an illegal value.
INFO > 0: if INFO = i, the leading minor of order i of A is not positive definite, and the factorization could not be completed.

Note

The exact specification of the local array dimensions for WORK and IWORK is implementation-dependent.
