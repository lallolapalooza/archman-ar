توثيق الوظيفة/الروتين الفرعي

subroutine cqlt02 (integer m, integer n, integer k, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, complex, dimension( lda, * ) q, complex, dimension( lda, * ) l, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CQLT02

الغرض:

!>
!> CQLT02 تختبر CUNGQL، التي تنشئ مصفوفة Q بحجم m × n بأعمدة متعامدة
!> متعامدة تُعرَّف بأنها حاصل ضرب k من الانعكاسات الأولية.
!>
!> بالنظر إلى تحليل QL لمصفوفة A بحجم m × n، تقوم CQLT02 بإنشاء
!> المصفوفة المتعامدة Q التي يعرّفها تحليل الأعمدة k الأخيرة
!> من A؛ وتقارن L(m-n+1:m,n-k+1:n) مع
!> Q(1:m,m-n+1:m)'*A(1:m,n-k+1:n)، وتتحقق من أن أعمدة Q
!> متعامدة.
!>

المعلمات

M 
!>          M هو عدد صحيح
!>          عدد صفوف المصفوفة Q التي سيتم إنشاؤها. M >= 0.
!>

N

!>          N هو عدد صحيح
!>          عدد أعمدة المصفوفة Q التي سيتم إنشاؤها.
!>          M >= N >= 0.
!>

K

!>          K هو عدد صحيح
!>          عدد الانعكاسات الأولية التي يُعرّف حاصل ضربها المصفوفة Q.
!>          N >= K >= 0.
!>

A

!>          A هي مصفوفة مركبة (COMPLEX)، البعد (LDA,N)
!>          المصفوفة A بحجم m × n التي تم تحليلها بواسطة CQLT01.
!>

AF

!>          AF هي مصفوفة مركبة (COMPLEX)، البعد (LDA,N)
!>          تفاصيل تحليل QL للمصفوفة A، كما تم إرجاعها بواسطة CGEQLF.
!>          راجع CGEQLF لمزيد من التفاصيل.
!>

Q

!>          Q هي مصفوفة مركبة (COMPLEX)، البعد (LDA,N)
!>

L

!>          L هي مصفوفة مركبة (COMPLEX)، البعد (LDA,N)
!>

LDA

!>          LDA هو عدد صحيح
!>          البعد الرئيسي لمصفوفات A، AF، Q، و L. LDA >= M.
!>

TAU

!>          TAU هي مصفوفة مركبة (COMPLEX)، البعد (N)
!>          العوامل العددية للانعكاسات الأولية المقابلة لتحليل QL في AF.
!>

WORK

!>          WORK هي مصفوفة مركبة (COMPLEX)، البعد (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح
!>          بعد مصفوفة WORK.
!>

RWORK

!>          RWORK هي مصفوفة حقيقية (REAL)، البعد (M)
!>

RESULT

!>          RESULT هي مصفوفة حقيقية (REAL)، البعد (2)
!>          نسب الاختبار:
!>          RESULT(1) = norm( L - Q'*A ) / ( M * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q'*Q ) / ( M * EPS )
!>
