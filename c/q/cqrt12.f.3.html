توثيق الوظيفة/الروتين الفرعي

real function cqrt12 (integer m, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) s, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork)

CQRT12

الغرض:

!>
!> CQRT12 يحسب القيم المنفردة `svlues' للشبه المنحرف العلوي
!> لـ A(1:M,1:N) ويعيد النسبة
!>
!>      || svlues -s ||/( ||s||*eps*max(M,N) )
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>          عدد صفوف المصفوفة A.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>          عدد أعمدة المصفوفة A.
!>

A

!>          A هي مصفوفة مركبة (COMPLEX)، البعد (LDA,N)
!>          المصفوفة A ذات الأبعاد M×N. يتم الرجوع فقط إلى الشبه المنحرف العلوي.
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البعد الرائد للمصفوفة A.
!>

S

!>          S هي مصفوفة حقيقية (REAL)، البعد (min(M,N))
!>          القيم المنفردة للمصفوفة A.
!>

WORK

!>          WORK هي مصفوفة مركبة (COMPLEX)، البعد (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح (INTEGER)
!>          طول المصفوفة WORK. LWORK >= M*N + 2*min(M,N) +
!>          max(M,N).
!>

RWORK

!>          RWORK هي مصفوفة حقيقية (REAL)، البعد (4*min(M,N))
!>
