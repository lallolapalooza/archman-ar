الاسم

coin_sensors - فئات المستشعرات


- المستشعرات هي كائنات تراقب كائنات أخرى بحثًا عن التغييرات وتستدعي دوال الاستدعاء عند حدوث التغييرات.

الملخص

الفئات


class SoAlarmSensor
الفئة SoAlarmSensor هي مستشعر يتم تشغيله مرة واحدة في وقت محدد. class SoDataSensor
الفئة SoDataSensor هي الفئة الأساسية المجردة للمستشعرات التي تراقب التغييرات في رسم بياني للمشهد. class SoDelayQueueSensor
الفئة SoDelayQueueSensor هي الفئة الأساسية المجردة للمستشعرات ذات الأولوية المجدولة. class SoFieldSensor
الفئة SoFieldSensor تكتشف التغييرات في حقل. class SoIdleSensor
الفئة SoIdleSensor هي مستشعر يتم تشغيله بمجرد أن يصبح التطبيق خاملاً. class SoNodeSensor
الفئة SoNodeSensor تكتشف التغييرات في العقد. class SoOneShotSensor
الفئة SoOneShotSensor هي مستشعر يتم تشغيله مرة واحدة. class SoPathSensor
الفئة SoPathSensor تكتشف التغييرات في المسارات. class SoSensor
الفئة SoSensor هي الفئة الأساسية المجردة لجميع المستشعرات. class SoSensorManager
الفئة SoSensorManager تدير قوائم المستشعرات. class SoTimerQueueSensor
الفئة SoTimerQueueSensor هي الفئة الأساسية المجردة للمستشعرات التي يتم تشغيلها عند أحداث مؤقتة معينة. class SoTimerSensor
الفئة SoTimerSensor هي مستشعر يتم تشغيله على فترات زمنية معينة.
