الفئات


class SoScXMLNavigation
فئة ثابتة لبعض الدوال الثابتة للتهيئة/التنظيف/المزامنة. class SoScXMLNavigationTarget
فئة أساسية لخدمات أهداف أحداث نظام التنقل SCXML. class SoScXMLPanTarget
هدف أحداث نظام التنقل لعمليات التحريك. class SoScXMLRotateTarget
هدف أحداث نظام التنقل لعمليات الدوران. class SoScXMLSeekTarget
هدف أحداث نظام التنقل لعمليات motion seek. class SoScXMLSpinTarget
هدف أحداث نظام التنقل لعمليات الدوران. class SoScXMLZoomTarget
خدمة هدف أحداث SCXML لسلوك التكبير. class SoScXMLDollyTarget
خدمة هدف أحداث SCXML لسلوك التكبير. class SoScXMLMiscTarget
دوال مساعدة متنوعة للتنقل. class SoScXMLFlightControlTarget
