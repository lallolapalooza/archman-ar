coin_shaders_page - التظليل (Shaders) في Coin

أضاف Coin 2.5 دعمًا للتظليل. العقد الرئيسية المستخدمة هي SoShaderProgram و SoVertexShader و SoFragmentShader و SoGeometryShader. عادةً ما يبدو الرسم البياني للمشهد مع التظليل كما يلي:

Separator {
  ShaderProgram {
    shaderObject [
      VertexShader {
        sourceProgram "myvertexshader.glsl"
        parameter [
          ShaderParameter1f { name "myvertexparam" value 1.0 }
        ]
      }
      FragmentShader {
        sourceProgram "myfragmentshader.glsl"
        parameter [
          ShaderParameter1f { name "myfragmentparam" value 2.0 }
        ]
      }
    ]
  }
  Cube { }
}

سيؤدي هذا إلى عرض المكعب باستخدام تظليل الرأس (vertex shader) وتظليل الجزء (fragment shader) المحدد في myvertexshader.glsl و myfragmentshader.glsl. يدعم Coin أيضًا تظليل ARB وتظليل Cg (إذا تم تثبيت مكتبة Cg). ومع ذلك، نوصي باستخدام GLSL لأننا سنركز في الغالب على دعم لغة التظليل هذه.

يحدد Coin بعض المعلمات المسماة التي يمكن للمبرمج التطبيق إضافتها، والتي سيتم تحديثها تلقائيًا بواسطة Coin أثناء عبور الرسم البياني للمشهد.

•
coin_texunit[n]_model - يتم تعيينه إلى 0 عند تعطيل تتبع الملمس، وإلى SoTextureImageElement::Model إذا كان هناك نسيج حالي في الحالة للوحدة n.
•
coin_light_model - يتم تعيينه إلى 1 لـ PHONG، و 0 لإضاءة BASE_COLOR.
•
coin_two_sided_lighting - يتم تعيينه إلى 1 للجانبين، و 0 للعادي

مثال على رسم بياني للمشهد يعرض إضاءة Phong الخاصة بـ OpenGL لكل جزء لمصدر ضوء واحد. تفترض التظليلات أن مصدر الضوء الأول هو ضوء اتجاهي. هذا هو الحال إذا قمت بفتح الملف في عارض فاحص قياسي.

تظليل الرأس (perpixel_vertex.glsl):

varying vec3 ecPosition3;
varying vec3 fragmentNormal;
void main(void)
{
  vec4 ecPosition = gl_ModelViewMatrix * gl_Vertex;
  ecPosition3 = ecPosition.xyz / ecPosition.w;
  fragmentNormal = normalize(gl_NormalMatrix * gl_Normal);
  gl_Position = ftransform();
  gl_FrontColor = gl_Color;
}

تظليل الجزء (perpixel_fragment.glsl):

varying vec3 ecPosition3;
varying vec3 fragmentNormal;
void DirectionalLight(in int i,
                      in vec3 normal,
                      inout vec4 ambient,
                      inout vec4 diffuse,
                      inout vec4 specular)
{
  float nDotVP; // normal . light direction
  float nDotHV; // normal . light half vector
  float pf;     // power factor
  nDotVP = max(0.0, dot(normal, normalize(vec3(gl_LightSource[i].position))));
  nDotHV = max(0.0, dot(normal, vec3(gl_LightSource[i].halfVector)));
  if (nDotVP == 0.0)
    pf = 0.0;
  else
    pf = pow(nDotHV, gl_FrontMaterial.shininess);
  ambient += gl_LightSource[i].ambient;
  diffuse += gl_LightSource[i].diffuse * nDotVP;
  specular += gl_LightSource[i].specular * pf;
}
void main(void)
{
  vec3 eye = -normalize(ecPosition3);
  vec4 ambient = vec4(0.0);
  vec4 diffuse = vec4(0.0);
  vec4 specular = vec4(0.0);
  vec3 color;
  DirectionalLight(0, normalize(fragmentNormal), ambient, diffuse, specular);
  color =
    gl_FrontLightModelProduct.sceneColor.rgb +
    ambient.rgb * gl_FrontMaterial.ambient.rgb +
    diffuse.rgb * gl_Color.rgb +
    specular.rgb * gl_FrontMaterial.specular.rgb;
  gl_FragColor = vec4(color, gl_Color.a);
}
