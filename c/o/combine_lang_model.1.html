combine_lang_model(1)

الحزمة: tesseract

التراخيص: APACHE

COMBINE_LANG_MODEL(1)   COMBINE_LANG_MODEL(1)

الاسم

combine_lang_model - إنشاء ملف تدريب بيانات ابتدائي

ملخص

combine_lang_model --input_unicharset ملف --script_dir دليل --output_dir دليل_جذر --lang لغة [--lang_is_rtl] [pass_through_recoder] [--words ملف --puncs ملف --numbers ملف]

الوصف

يقوم combine_lang_model(1) بإنشاء ملف تدريب بيانات ابتدائي يمكن استخدامه لتدريب نموذج شبكة عصبية قائمة على LSTM. يأخذ كمدخل مجموعة أحرف (unicharset) ومجموعة اختيارية من قوائم الكلمات. إنه يلغي الحاجة إلى تشغيل set_unicharset_properties(1) و wordlist2dawg(1) وبرنامج ثنائي غير موجود لإنشاء المشفر (ضاغط يونيكود)، وأخيراً combine_tessdata(1).

الخيارات

--lang lang

اللغة المراد استخدامها. يستخدم Tesseract رموز لغة ISO 639-2 المكونة من 3 أحرف. (انظر اللغات)

--script_dir PATH

اسم الدليل لمجموعات الأحرف النصية المدخلة. يجب أن يشير إلى موقع دليل langdata (مستودع github). (النوع: سلسلة، الافتراضي:)

--input_unicharset FILE

مجموعة الأحرف (unicharset) لإكمالها واستخدامها في الترميز. يمكن أن تكون ملفًا تم إنشاؤه يدويًا بحقول غير مكتملة. سيتم تعيين خصائصه الأساسية والخاصة بالنص قبل استخدامه. (النوع: سلسلة، الافتراضي:)

--lang_is_rtl BOOL

صحيح إذا كانت اللغة قيد المعالجة مكتوبة من اليمين إلى اليسار (مثل العربية/العبرية). (النوع: منطقي، الافتراضي: خطأ)

--pass_through_recoder BOOL

إذا كان صحيحًا، فإن المشفر هو مجرد تمرير لمجموعة الأحرف. خلاف ذلك، قد يكون ضغطًا لها عن طريق ترميز Hangul في Jamos، وتحليل الرموز متعددة يونيكود إلى تسلسلات من يونيكود، وترميز Han باستخدام البيانات الموجودة في radical_table_data، والتي يجب أن تكون محتويات الملف: langdata/radical-stroke.txt. (النوع: منطقي، الافتراضي: خطأ)

--version_str STRING

تسمية إصدار عشوائية لإضافتها إلى ملف traineddata (النوع: سلسلة، الافتراضي:)

--words FILE

(اختياري) ملف يسرد الكلمات لاستخدامها في قاموس النظام (النوع: سلسلة، الافتراضي:)

--numbers FILE

(اختياري) ملف يسرد أنماط الأرقام (النوع: سلسلة، الافتراضي:)

--puncs FILE

(اختياري) ملف يسرد أنماط علامات الترقيم. قد تكون قوائم الكلمات/علامات الترقيم/الأرقام فارغة. إذا كان أي منها غير فارغ، فيجب أن تكون علامات الترقيم غير فارغة. (النوع: سلسلة، الافتراضي:)

--output_dir PATH

الدليل الجذر للملفات المخرجة. سيتم كتابة الملفات المخرجة في <output_dir>/<lang>/<lang>.* (النوع: سلسلة، الافتراضي:)
