CORE(3perl) دليل مبرمجي Perl CORE(3perl)

الاسم

CORE - مساحة اسم للروتينات الأساسية في Perl

الملخص

BEGIN {
    *CORE::GLOBAL::hex = sub { 1; };
}
print hex("0x50"),"\n";                     # يطبع 1
print CORE::hex("0x50"),"\n";               # يطبع 80
CORE::say "yes";                            # يطبع yes
BEGIN { *shove = \&CORE::push; }
shove @array, 1,2,3;                        # يدفع إلى @array

الوصف

توفر مساحة الاسم "CORE" الوصول إلى الوظائف المضمنة الأصلية في Perl. الحزمة "CORE" مضمنة في Perl، وبالتالي لا تحتاج إلى استخدام أو طلب وحدة "CORE" افتراضية قبل الوصول إلى الروتينات في مساحة الاسم هذه.

يمكن العثور على قائمة بالوظائف المضمنة في Perl في perlfunc.

لجميع كلمات Perl المفتاحية، فإن البادئة "CORE::" ستجبر على استخدام الوظيفة المضمنة، حتى لو تم تجاوزها أو كانت تتطلب عادةً الـ pragma feature. على الرغم من المظاهر، لا علاقة لهذا بحزمة CORE، ولكنه جزء من بناء جملة Perl.

بالنسبة للعديد من وظائف Perl، تحتوي حزمة CORE على إجراءات حقيقية. هذه الميزة جديدة في Perl 5.16. يمكنك أخذ مراجع لهذه الإجراءات وإنشاء أسماء مستعارة. ومع ذلك، لا يمكن استدعاء بعضها إلا كـ barewords؛ أي، لا يمكنك استخدام صيغة ampersand (&foo) أو استدعائها من خلال المراجع. انظر مثال "shove" أعلاه. هذه الإجراءات موجودة لجميع الكلمات المفتاحية باستثناء ما يلي:

"__DATA__"، "__END__"، "and"، "cmp"، "default"، "do"، "dump"، "else"، "elsif"، "eq"، "eval"، "for"، "foreach"، "format"، "ge"، "given"، "goto"، "grep"، "gt"، "if"، "last"، "le"، "local"، "lt"، "m"، "map"، "my"، "ne"، "next"، "no"، "or"، "our"، "package"، "print"، "printf"، "q"، "qq"، "qr"، "qw"، "qx"، "redo"، "require"، "return"، "s"، "say"، "sort"، "state"، "sub"، "tr"، "unless"، "until"، "use"، "when"، "while"، "x"، "xor"، "y"

الاستدعاء باستخدام صيغة ampersand ومن خلال المراجع لا يعمل للوظائف التالية، حيث أن لها بناء جملة خاص لا يمكن دائمًا ترجمته إلى قائمة بسيطة (على سبيل المثال، "eof" مقابل eof()):

"chomp"، "chop"، "defined"، "delete"، "eof"، "exec"، "exists"، "lstat"، "split"، "stat"، "system"، "truncate"، "unlink"

تجاوز الوظائف الأساسية

لتجاوز روتين Perl مضمن بإصدارك الخاص، تحتاج إلى استيراده في وقت الترجمة. يمكن تحقيق ذلك بسهولة باستخدام pragma "subs". سيؤثر هذا فقط على الحزمة التي استوردت فيها الإجراء المذكور:

use subs 'chdir';
sub chdir { ... }
chdir $somewhere;

لتجاوز وظيفة مضمنة بشكل عام (أي، في جميع مساحات الأسماء)، تحتاج إلى استيراد وظيفتك إلى مساحة الاسم الزائفة "CORE::GLOBAL" في وقت الترجمة:

BEGIN {
    *CORE::GLOBAL::hex = sub {
        # ... الكود الخاص بك هنا
    };
}

سيتم استدعاء الروتين الجديد كلما تم استدعاء وظيفة مضمنة دون حزمة مؤهلة:

print hex("0x50"),"\n";                     # يطبع 1

في كلتا الحالتين، إذا كنت تريد الوصول إلى الروتين الأصلي غير المعدل، استخدم البادئة "CORE::":

print CORE::hex("0x50"),"\n";               # يطبع 80
