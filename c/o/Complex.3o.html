الأعداد المركبة.

توفر هذه الوحدة عمليات حسابية على الأعداد المركبة. يتم تمثيل الأعداد المركبة بأجزائها الحقيقية والتخيلية (التمثيل الديكارتي). يتم تمثيل كل جزء بعدد نقطة عائمة مزدوجة الدقة (النوع float).

type t = {
re : float ;
im : float ;
}

نوع الأعداد المركبة. re هو الجزء الحقيقي و im هو الجزء التخيلي.

النفي الأحادي.

المرافق: بالنظر إلى العدد المركب x + i.y، يعيد x - i.y.

val div : t -> t -> t

القسمة

val sqrt : t -> t

الجذر التربيعي. النتيجة x + i.y تكون بحيث x > 0 أو x = 0 و y >= 0. هذه الدالة لديها انقطاع على طول المحور الحقيقي السالب.

val norm2 : t -> float

مربع المعيار: بالنظر إلى x + i.y، يعيد x^2 + y^2.

val norm : t -> float

المعيار: بالنظر إلى x + i.y، يعيد sqrt(x^2 + y^2).

val arg : t -> float

الزاوية. زاوية العدد المركب هي الزاوية في المستوى المركب بين المحور الحقيقي الموجب وخط يمر بالصفر والعدد. تتراوح هذه الزاوية من -pi إلى pi. هذه الدالة لديها انقطاع على طول المحور الحقيقي السالب.

val polar : float -> float -> t

polar norm arg يعيد العدد المركب الذي له المعيار norm والزاوية arg.

val exp : t -> t

الأس. exp z يعيد e مرفوعة للقوة z.

val log : t -> t

اللوغاريتم الطبيعي (بالأساس e).

val pow : t -> t -> t

دالة القوة. pow z1 z2 يعيد z1 مرفوعة للقوة z2.
