Color__Calc__WWW(3pm)

الحزمة: perl-color-calc

التراخيص: GPL, PerlArtistic

Color::Calc::WWW(3) وثائق Perl مساهمة من المستخدم Color::Calc::WWW(3)

الاسم

Color::Calc::WWW - حسابات بسيطة مع الألوان للشبكة العالمية.

ملخص

use Color::Calc::WWW;
my $background = 'green';
print 'background: ', color($background),';';
print 'border-top: solid 1px ', color_light($background),';';
print 'border-bottom: solid 1px ', color_dark($background),';';
print 'color: ', color_contrast_bw($background),';';

الوصف

الوحدة "Color::Calc::WWW" تطبق حسابات بسيطة مع ألوان RGB للشبكة العالمية (WWW). يمكن استخدام هذا لإنشاء مخطط ألوان كامل من بضعة ألوان.

هذه الوحدة متطابقة تقريبًا مع استخدام ما يلي:

use Color::Calc('ColorScheme' => 'WWW', 'OutputFormat' => 'html');

ومع ذلك، فإن هذه الوحدة تجعل الوظائف متاحة أيضًا عند عدم استيرادها:

use Color::Calc::WWW();               # لا تستورد
Color::Calc::WWW::color('F00');

الاستخدام

افتراضيًا، يتم استيراد جميع الوظائف.

جميع الوظائف تتعرف على جميع الكلمات المفتاحية للألوان في HTML (من خلال Graphics::ColorNames::WWW) وتخرج النتائج بتنسيقات متوافقة مع WWW، أي كواحدة من 16 كلمة مفتاحية أساسية في HTML (انظر Graphics::ColorNames::WWW) أو كـ #RRGGBB.

color, color_mix, ...
انظر L<Color::Calc> لقائمة وظائف الحساب المتاحة.
