الحزمة: colord

COLORMGR(1) أوامر المستخدم COLORMGR(1)

الاسم

colormgr - أداة اختبار مدير الألوان

الملخص

colormgr [--verbose] [--version]

الوصف

توثق صفحة الدليل هذه باختصار أمر colormgr.

يسمح colormgr للمسؤول بعرض وتغيير تعيينات ملفات تعريف الألوان للأجهزة.

الخيارات

يتبع هذا البرنامج صيغة سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (‘-’). يتم تضمين ملخص للخيارات أدناه.

--help

عرض ملخص للخيارات.

الأوامر

يأخذ هذا البرنامج أوامر مع عدد متغير من الوسائط.

create-device device_id scope

إنشاء جهاز

create-profile profile_id scope

إنشاء ملف تعريف

delete-device device

حذف جهاز

delete-profile profile

حذف ملف تعريف

device-add-profile device profile

إضافة ملف تعريف إلى جهاز موجود بالفعل

device-get-default-profile device

الحصول على ملف التعريف الافتراضي لجهاز

device-get-profile-for-qualifier device qualifier

إرجاع جميع ملفات التعريف التي تطابق المحدد

device-inhibit device timeout

منع ملفات تعريف الألوان لهذا الجهاز

device-make-profile-default device profile

جعل ملف تعريف افتراضي لجهاز

device-set-enabled

تمكين أو تعطيل الجهاز

device-set-kind device kind

تعيين نوع الجهاز

device-set-model device model

تعيين طراز الجهاز

device-set-serial device serial

تعيين الرقم التسلسلي للجهاز

device-set-vendor device vendor

تعيين بائع الجهاز

find-device device_id

البحث عن جهاز من معرف الجهاز

find-device-by-property key value

البحث عن جهاز بقيمة خاصية معينة

find-profile profile_id

البحث عن ملف تعريف من معرف ملف التعريف

find-profile-by-filename filename

البحث عن ملف تعريف بواسطة اسم الملف

get-devices

الحصول على جميع الأجهزة التي تتم إدارتها بالألوان

get-devices-by-kind kind

الحصول على جميع الأجهزة التي تتم إدارتها بالألوان من نوع معين

get-profiles

الحصول على جميع ملفات تعريف الألوان المتاحة

get-sensor-reading display_type

الحصول على قراءة من المستشعر

get-sensors

الحصول على جميع مستشعرات الألوان المتاحة

get-standard-space standard_space

الحصول على مساحة لونية قياسية

import-profile filename

ينسخ ملف .icc إلى الدليل الصحيح لكل مستخدم ويعرض معلومات حول ملف التعريف المستورد.

profile-set-property profile name value

تعيين خصائص إضافية لملف التعريف

sensor-lock

قفل مستشعر الألوان

sensor-set-options name value

تعيين خيار أو أكثر للمستشعر
