Config::Extensions(3perl) دليل مبرمجي Perl Config::Extensions(3perl)

الاسم

Config::Extensions - بحث تجزيئي للإضافات الأساسية التي تم بناؤها.

الملخص

use Config::Extensions '%Extensions';
if ($Extensions{PerlIO::via}) {
    # هذا الـ perl لديه PerlIO::via مبنية
}

الوصف

توفر الوحدة Config::Extensions تجزيئًا %Extensions يحتوي على جميع الإضافات الأساسية التي تم تمكينها لهذا الـ perl. يتم فهرسة التجزيء حسب اسم الإضافة، مع كل إدخال لديه إحدى القيم الثلاث الممكنة:

ديناميكي
الإضافة مرتبطة ديناميكيًا
غير xs
الإضافة perl خالصة، لذا لا تحتاج إلى ربطها بملف perl التنفيذي
ثابت
الإضافة مرتبطة ثابتًا بالملف الثنائي لـ perl

بما أن جميع القيم تقيّم إلى صحيح، فإن اختبار "if" بسيط يكفي لتحديد ما إذا كانت الإضافة موجودة.

جميع البيانات المستخدمة لإنشاء تجزيء %Extensions موجودة بالفعل في الوحدة "Config"، ولكن ليس بتنسيق مناسب للإشارة السريعة.
