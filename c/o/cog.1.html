cog(1)

الحزمة: cocogitto

التراخيص: MIT

cog(1) دليل الأوامر العامة cog(1)

الاسم

cog - أداة سطر أوامر لمواصفات الالتزامات التقليدية و semver

ملخص

cog [-v|--verbose]... [-q|--quiet] [--config] [-h|--help] [-V|--version] <الأوامر الفرعية>

الوصف

أداة سطر أوامر لمواصفات الالتزامات التقليدية و semver

خيارات

-v, --verbose
مستوى التفصيل: -v لـ ERROR، -vv لـ WARNING، -vvv لـ INFO
-q, --quiet
كتم كل المخرجات، بغض النظر عن قيمة التفصيل
--config <CONFIG> [الافتراضي: cog.toml]
المسار إلى ملف الإعدادات
-h, --help
طباعة المساعدة
-V, --version
طباعة الإصدار

الأوامر الفرعية

cog-check(1)
التحقق من جميع رسائل الالتزام مقابل مواصفات الالتزام التقليدي
cog-commit(1)
إنشاء التزام تقليدي جديد
cog-edit(1)
إعادة تسمية رسائل الالتزام غير الصالحة بشكل تفاعلي
cog-log(1)
مثل git log ولكن لرسائل الالتزام التقليدية
cog-verify(1)
التحقق من رسالة التزام واحدة
cog-changelog(1)
عرض سجل التغييرات لنطاق معرف الالتزام المحدد
cog-get-version(1)
الحصول على الإصدار الحالي
cog-bump(1)
الالتزام بسجل التغييرات من آخر علامة إلى HEAD وإنشاء علامة جديدة
cog-init(1)
تثبيت ملفات إعدادات cog
cog-install-hook(1)
إضافة خطافات git إلى المستودع
cog-generate-completions(1)
إنشاء إكمال للصدفة
cog-help(1)
طباعة هذه الرسالة أو المساعدة للأوامر الفرعية المحددة
