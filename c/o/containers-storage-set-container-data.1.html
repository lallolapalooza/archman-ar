containers-storage-set-container-data 1 أغسطس 2016

الاسم

containers-storage set-container-data - تعيين بيانات خارجية للحاوية

الملخص

containers-storage set-container-data [خيارات [...]] اسم_أو_معرف_الحاوية اسم_البيانات

الوصف

يقوم بتعيين قطعة بيانات مسماة مرتبطة بالحاوية.

الخيارات

-f | --file اسم_الملف

قراءة محتويات البيانات من ملف بدلاً من الإدخال القياسي.

مثال

containers-storage set-container-data -f ./config.json my-container configuration
