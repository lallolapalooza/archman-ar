الاسم

coin_caches - فئات التخزين المؤقت


- فئات التخزين المؤقت هي جزء داخلي من Coin.

ملخص

الفئات


class SoBoundingBoxCache
تُستخدم الفئة SoBoundingBoxCache لتخزين الصناديق المحيطة مؤقتًا. class SoCache
الفئة SoCache هي الفئة الأصل لجميع فئات التخزين المؤقت الداخلية. class SoConvexDataCache
تُستخدم الفئة SoConvexDataCache لتخزين المضلعات المحدبة مؤقتًا. class SoGLCacheList
تُستخدم الفئة SoGLCacheList لتخزين وإدارة مخازن OpenGL المؤقتة. class SoGLRenderCache
تُستخدم الفئة SoGLRenderCache لتخزين استدعاءات OpenGL مؤقتًا. class SoNormalCache
تُستخدم الفئة SoNormalCache للاحتفاظ بالمنظمات المخزنة مؤقتًا. class SoTextureCoordinateCache
تُستخدم الفئة SoTextureCoordinateCache لتخزين الإحداثيات النسيجية التي تم إنشاؤها مؤقتًا. class SoPrimitiveVertexCache
يحتوي هذا المخزن المؤقت على نسخة منظمة من الهندسة في شكل مصفوفة رؤوس.
