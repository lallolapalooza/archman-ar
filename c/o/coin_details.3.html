الاسم

coin_details - فئات التفاصيل


- فئات التفاصيل هي كائنات توفر معلومات إضافية حيثما يتم استخدام الفئة SoPrimitiveVertex.

الملخص

الفئات


class SoDetail
الفئة SoDetail هي الفئة الأساسية لجميع الفئات التي تخزن معلومات مفصلة حول أشكال معينة. class SoConeDetail
تحتوي الفئة SoConeDetail على معلومات حول أجزاء شكل SoCone. class SoCubeDetail
تحتوي الفئة SoCubeDetail على معلومات حول أجزاء شكل SoCube. class SoCylinderDetail
تحتوي الفئة SoCylinderDetail على معلومات حول أجزاء شكل SoCylinder. class SoFaceDetail
الفئة SoFaceDetail مخصصة لتخزين معلومات تفصيلية عن المضلعات. class SoLineDetail
الفئة SoLineDetail مخصصة لتخزين معلومات تفصيلية عن الخطوط ثلاثية الأبعاد. class SoNodeKitDetail
الفئة SoNodeKitDetail لم يتم توثيقها بعد. class SoPointDetail
الفئة SoPointDetail مخصصة لتخزين معلومات تفصيلية عن نقطة ثلاثية الأبعاد واحدة. class SoTextDetail
الفئة SoTextDetail تخزن معلومات حول حرف في سلسلة نصية. class SoDetailList
الفئة SoDetailList هي حاوية لمؤشرات إلى كائنات SoDetail.

وصف مفصل

فئات التفاصيل هي كائنات توفر معلومات إضافية حيثما يتم استخدام الفئة SoPrimitiveVertex.

وينطبق هذا على نتائج التقاط الأشعة، وينطبق أيضًا على توليد الأشكال الأساسية بواسطة فئات SoShape لفئة SoCallbackAction والعرض الاحتياطي للشكل من خلال توليد الأشكال الأساسية (وهي حيلة تصحيح مفيدة عند تصحيح الأخطاء، على سبيل المثال، عند التقاط الأشعة).

المؤلف

تم إنشاؤه تلقائيًا بواسطة Doxygen لـ Coin من الكود المصدري.
