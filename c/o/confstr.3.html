confstr(3) دليل الدوال المكتبية confstr(3)

الاسم

confstr - الحصول على متغيرات نصية تعتمد على التكوين

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <unistd.h>
size_t confstr(size_t size;
               int name, char buf[size], size_t size);
متطلبات ميزة الاختبار في glibc (انظر feature_test_macros(7)):

confstr():

    _POSIX_C_SOURCE >= 2 || _XOPEN_SOURCE

الوصف

confstr() تحصل على قيمة المتغيرات النصية التي تعتمد على التكوين.

الوسيط name هو المتغير النظامي المراد الاستعلام عنه. المتغيرات التالية مدعومة:

_CS_GNU_LIBC_VERSION (مكتبة GNU C فقط؛ منذ glibc 2.3.2)
سلسلة نصية تحدد إصدار مكتبة GNU C في هذا النظام (مثل، "glibc 2.3.4").
_CS_GNU_LIBPTHREAD_VERSION (مكتبة GNU C فقط؛ منذ glibc 2.3.2)
سلسلة نصية تحدد تنفيذ POSIX المقدم من مكتبة C هذه (مثل، "NPTL 2.3.4" أو "linuxthreads-0.10").
_CS_PATH
قيمة للمتغير PATH تشير إلى مكان العثور على جميع أدوات POSIX.2 القياسية.

إذا لم يكن buf فارغًا (NULL) ولم يكن size صفرًا، تقوم confstr() بنسخ القيمة النصية إلى buf مقطوعة إلى size - 1 بايت إذا لزم الأمر، مع إضافة حرف null ('\0') كفاصل. يمكن اكتشاف ذلك عن طريق مقارنة القيمة المرجعة من confstr() مقابل size.

إذا كان size صفرًا وكان buf فارغًا (NULL)، تقوم confstr() فقط بإرجاع القيمة كما هو محدد أدناه.

قيمة الإرجاع

إذا كان name متغير تكوين صالحًا، فإن confstr() ترجع عدد البايتات (بما في ذلك حرف Null الفاصل) التي ستكون مطلوبة للاحتفاظ بالقيمة الكاملة لهذا المتغير. قد تكون هذه القيمة أكبر من size، مما يعني أن القيمة في buf مقطوعة.

إذا كان name متغير تكوين صالحًا، ولكن هذا المتغير لا يمتلك قيمة، فإن confstr() ترجع 0. إذا كان name لا يتطابق مع متغير تكوين صالح، فإن confstr() ترجع 0، ويتم تعيين errno إلى EINVAL.

الأخطاء

EINVAL
قيمة name غير صالحة.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
confstr () سلامة المواضيع (Thread safety) MT-Safe

المعايير

POSIX.1-2008.

التاريخ

POSIX.1-2001.

أمثلة

جزء التعليمات البرمجية التالي يحدد المسار الذي يجب العثور فيه على أدوات نظام POSIX.2:


char *pathbuf;
size_t n;
n = confstr(_CS_PATH, NULL, (size_t) 0);
pathbuf = malloc(n);
if (pathbuf == NULL)
    abort();
confstr(_CS_PATH, pathbuf, n);
