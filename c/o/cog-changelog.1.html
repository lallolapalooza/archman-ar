الاسم

cog-changelog - عرض سجل التغييرات لنطاق معرف الالتزام المعطى

الملخص

cog-changelog [-a|--at] [-t|--template] [-r|--remote] [-o|--owner] [--repository] [-u|--unified] [-h|--help] [PATTERN]

الوصف

عرض سجل التغييرات لنطاق معرف الالتزام المعطى

خيارات

-a, --at <AT>
إنشاء سجل التغييرات لعلامة git محددة
-t, --template <TEMPLATE>
إنشاء سجل التغييرات باستخدام القالب المعطى.

القيم الممكنة هي 'remote'، 'full_hash'، 'default' أو المسار إلى القالب الخاص بك. إذا لم يتم تحديده، سيستخدم cog إعداد قالب cog.toml أو سيعود إلى 'default'.

-r, --remote <REMOTE>
عنوان URL المراد استخدامه أثناء إنشاء القالب
-o, --owner <OWNER>
مالك المستودع المراد استخدامه أثناء إنشاء القالب
--repository <REPOSITORY>
اسم المستودع المستخدم أثناء إنشاء القالب
-u, --unified
دمج تغييرات الحزم والتغييرات العامة في سجل تغييرات واحد
-h, --help
طباعة المساعدة (انظر الملخص مع '-h')
[PATTERN]
إنشاء سجل التغييرات في نطاق المواصفات المعطى
