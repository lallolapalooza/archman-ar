الاسم

containers-storage config - إخراج تكوين مكتبة التخزين

الخلاصة

containers-storage config [ملف_التكوين]

الوصف

تقرأ وتخرج التكوين الحالي لمكتبة التخزين، أو التكوين الحالي مع تحميل محتويات ملف تكوين محدد، بتنسيق JSON.

مثال

containers-storage config

انظر أيضًا

containers-storage-version(1)
