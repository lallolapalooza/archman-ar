code(n)

الحزمة: tcl

التراخيص: TCL

code(n) [incr Tcl] code(n)

الاسم

itcl::code - التقاط سياق مساحة الاسم لشظية التعليمات البرمجية

الخلاصة

itcl::code ?-namespace name? command ?arg arg ...?

الوصف

ينشئ قيمة ذات نطاق محدد للأمر command المحدد ووسيطاته arg المرتبطة به. القيمة ذات النطاق هي قائمة بثلاثة عناصر: الكلمة المفتاحية "@scope"، وسياق مساحة الاسم، وسلسلة القيمة. على سبيل المثال، الأمر

namespace foo {
    code puts "Hello World!"
}
ينتج القيمة ذات النطاق: 
@scope ::foo {puts {Hello World!}}
لاحظ أن الأمر code يلتقط سياق مساحة الاسم الحالي. إذا تم تحديد علامة -namespace، فسيتم تجاهل السياق الحالي، وسيتم استخدام السلسلة name كسياق لمساحة الاسم.

الامتدادات مثل Tk تنفذ شظايا التعليمات البرمجية العادية في مساحة الاسم العامة. القيمة ذات النطاق تلتقط شظية التعليمات البرمجية مع سياق مساحة الاسم الخاص بها بطريقة تسمح بتنفيذها بشكل صحيح لاحقًا. وهي مطلوبة، على سبيل المثال، لتغليف شظايا التعليمات البرمجية عند استخدام عنصر واجهة مستخدم Tk داخل مساحة اسم:

namespace foo {
    private proc report {mesg} {
        puts "click: $mesg"
    }
    button .b1 -text "Push Me"         -command [code report "Hello World!"]
    pack .b1
}
شظية التعليمات البرمجية المرتبطة بالعنصر .b1 ذات معنى فقط في سياق مساحة الاسم "foo". علاوة على ذلك، فإن الإجراء "report" خاص، ولا يمكن الوصول إليه إلا داخل مساحة الاسم تلك. الأمر code يغلف شظية التعليمات البرمجية بطريقة تسمح بتنفيذها بشكل صحيح عند الضغط على الزر.

أيضًا، لاحظ أن الأمر code يحافظ على سلامة الوسائط على سطر الأوامر. هذا يجعله بديلاً طبيعيًا للأمر list، والذي يستخدم غالبًا لتنسيق شظايا التعليمات البرمجية Tcl. بعبارة أخرى، بدلاً من استخدام الأمر list كما يلي:

after 1000 [list puts "Hello $name!"]
استخدم الأمر code كما يلي: 
after 1000 [code puts "Hello $name!"]
هذا لا يقوم فقط بتنسيق الأمر بشكل صحيح، ولكنه يلتقط أيضًا سياق مساحة الاسم الخاص به.

يمكن استدعاء الأوامر ذات النطاق مثل شظايا التعليمات البرمجية العادية، مع أو بدون الأمر eval. على سبيل المثال، العبارات التالية تعمل بشكل صحيح:

set cmd {@scope ::foo .b1}
$cmd configure -background red
set opts {-bg blue -fg white}
eval $cmd configure $opts
لاحظ أن الأوامر ذات النطاق تتجاوز آليات الحماية المعتادة؛ الأمر: 
@scope ::foo {report {Hello World!}}
يمكن استخدامه للوصول إلى الإجراء "foo::report" من أي سياق لمساحة اسم، على الرغم من أنه خاص.
