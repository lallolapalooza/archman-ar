containers-storage-changes 1 August 2016

الاسم

containers-storage changes - إنتاج قائمة بالتغييرات في طبقة

الملخص

containers-storage changes اسم_الطبقة_أو_معرفها [اسم_الطبقة_المرجعية_أو_معرفها]

الوصف

عند إنشاء طبقة لأول مرة، فإنها لا تحتوي على أي تغييرات بالنسبة للطبقة الأم. بعد إجراء تغييرات عليها، يمكن استخدام أمر containers-storage changes للحصول على ملخص للملفات التي تم إضافتها أو حذفها أو تعديلها في الطبقة.

مثال

containers-storage changes f3be6c6134d0d980936b4c894f1613b69a62b79588fdeda744d0be3693bde8ec

انظر أيضًا

containers-storage-applydiff(1) containers-storage-diff(1) containers-storage-diffsize(1)
