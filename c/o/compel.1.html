compel(1)

الحزمة: criu

التراخيص: GPL-2.0-only, LGPL-2.1-only

COMPEL(1) دليل CRIU COMPEL(1)



الاسم
compel - تنفيذ شفرة طفيلية داخل عملية أخرى.



الملخص

compel hgen [خيار ...]

compel plugins [اسم_البرنامج_الإضافي ...]

compel [--compat] includes | cflags | ldflags

compel [--compat] [--static] libs



الوصف

compel هي أداة مساعدة لتنفيذ شفرة عشوائية، تسمى أيضًا شفرة طفيلية، في سياق عملية أجنبية. الشفرة الطفيلية، بمجرد تجميعها بأعلام compel وتعبئتها، يمكن تنفيذها في سياق مهام أخرى. حاليًا هناك طريقة واحدة فقط لتحميل الكتلة الطفيلية في مهمة الضحية باستخدام libcompel.a، تسمى c-header.



الوسائط



الوسائط الموضعية

hgen

إنشاء رأس من ملف .po، وهو ثنائي الطفيل.

plugins

طباعة البرامج الإضافية المتاحة.

ldflags

طباعة علامات الربط (ldflags) المتاحة لـ compel أثناء ربط الشفرة الطفيلية.

cflags

طباعة علامات التجميع (cflags) لـ compel لاستخدامها أثناء تجميع الشفرة الطفيلية.

includes

طباعة قائمة بمسارات التضمين القياسية.

libs

طباعة قائمة بالمكتبات الثابتة أو الديناميكية التي يمكن لـ compel الربط بها.



الخيارات

-f, --file ملف

المسار إلى الملف الثنائي، الملف، الذي يجب على compel تحويله إلى رأس.

-o, --output ملف

المسار إلى ملف الرأس، الملف، حيث يجب على compel كتابة الرأس الناتج.

-p, --prefix اسم

تحديد البادئة لأسماء المتغيرات.

-l, --log-level رقم

مستوى التسجيل الافتراضي لـ compel.

-h, --help

طباعة الاستخدام والخروج.

-V, --version

طباعة رقم إصدار compel.



أمثلة على المصدر



شفرة طفيلية

#include <compel/plugins/std.h>

int parasite_trap_cmd(int cmd, void *args); // يتم استدعاؤه بواسطة compel_run_in_thread()

int parasite_daemon_cmd(int cmd, void *arg); // يتم استدعاؤه بواسطة compel_rpc_call() و compel_rpc_call_sync()

void parasite_cleanup(void); // يتم استدعاؤه عند إلغاء تحميل الطفيل بواسطة compel_cure()



شفرة العدوى

يتم تجميع الشفرة الطفيلية وتحويلها إلى رأس باستخدام compel، ويتم تضمينها هنا.

#include <compel/infect.h>

#include "parasite.h"

تتم الخطوات التالية لإصابة العملية الضحية:

•إيقاف المهمة: int compel_stop_task(int pid);
•إعداد معالج العدوى: struct parasite_ctl *compel_prepare(int pid);
•تنفيذ استدعاء النظام: int compel_syscall(ctl, int syscall_nr, long *ret, int arg ...);
•إصابة الضحية: int compel_infect(ctl, nr_thread, size_of_args_area);
•علاج الضحية: int compel_cure(ctl); // يتم تحرير المؤشر ctl بواسطة هذا الاستدعاء
•استئناف الضحية: int compel_resume_task(pid, orig_state, state) أو int compel_resume_task_sig(pid, orig_state, state, stop_signo). //يمكن استخدام compel_resume_task_sig() في حالة أن الضحية في حالة متوقفة. يمكن قراءة stop_signo عن طريق استدعاء compel_parse_stop_signo().

يجب تكوين ctl بمعلومات الكتلة عن طريق استدعاء PREFIX_setup_c_header()، مع ctl كوسيط. PREFIX هو الوسيط المعطى لـ -p عند استدعاء hgen، وإلا يتم استنتاجه من اسم الملف.



أمثلة

لتوليد ملف رأس (.h) من ملف ثنائي طفيلي (.po) استخدم:

    compel hgen -f parasite.po -o parasite.h

يتم الحصول على ملف parasite.po عن طريق تجميع المصدر الطفيلي باستخدام علامات compel وربطه مع برامج compel الإضافية.
