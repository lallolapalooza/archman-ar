containers-storage-set-names 1 أغسطس 2016

الاسم

containers-storage set-names - تعيين أسماء لطبقة/صورة/حاوية

النبذة

containers-storage set-names [-n name [...]] layerOrImageOrContainerNameOrID

الوصف

بالإضافة إلى المعرفات، يمكن تعيين أسماء قابلة للقراءة للبشر لـ الطبقات و الصور و الحاويات في containers-storage. يمكن استخدام الأمر set-names لإعادة تعيين قائمة الأسماء لأي منها.

الخيارات

-n | --name name

يحدد اسمًا لتعيينه للطبقة أو الصورة أو الحاوية. إذا كان اسم محدد مستخدمًا بالفعل من قبل طبقة أو صورة أو حاوية أخرى، فسيتم إزالته من تلك الطبقة أو الصورة أو الحاوية الأخرى. سيتم إزالة أي أسماء تم تعيينها حاليًا لهذه الطبقة أو الصورة أو الحاوية، والتي لم يتم تحديدها باستخدام هذا الخيار، من الطبقة أو الصورة أو الحاوية.

مثال

containers-storage set-names -n my-one-and-only-name f3be6c6134d0d980936b4c894f1613b69a62b79588fdeda744d0be3693bde8ec
