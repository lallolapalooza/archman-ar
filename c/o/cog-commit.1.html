cog-commit(1) دليل الأوامر العامة cog-commit(1)

الاسم

cog-commit - إنشاء التزام تقليدي جديد

ملخص

cog-commit [-B|--breaking-change] [-e|--edit] [-s|--sign] [--skip-ci] [--skip-ci-override] [-a|--add] [-u|--update] [-h|--help] <النوع> <الرسالة> [النطاق]

الوصف

إنشاء التزام تقليدي جديد

الخيارات

-B, --breaking-change
إنشاء التزام تغيير كسر (BREAKING CHANGE)
-e, --edit
فتح رسالة الالتزام في محرر
-s, --sign
توقيع هذا الالتزام
--skip-ci
إضافة السلسلة skip-ci المحددة في cog.toml (أو الافتراضية [skip ci]) إلى الالتزام
--skip-ci-override <SKIP_CI_OVERRIDE>
تجاوز وإضافة السلسلة <SKIP_CI_OVERRIDE> إلى الالتزام
-a, --add
إضافة ملفات إلى الالتزام (مشابه لـ git add .)
-u, --update
تحديث ولكن لا تضيف ملفات إلى الالتزام (مشابه لـ git add -u .)
-h, --help
طباعة المساعدة
<النوع>
نوع الالتزام التقليدي

[القيم الممكنة: build, chore, ci, docs, feat, fix, perf, refactor, revert, style, test]

<الرسالة>
وصف الالتزام
[النطاق]
نطاق الالتزام التقليدي
cog-commit
