CMS_digest_create(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

CMS_DIGEST_CREATE(3ssl) OpenSSL CMS_DIGEST_CREATE(3ssl)

الاسم

CMS_digest_create_ex, CMS_digest_create - إنشاء كائن CMS DigestedData

الملخص

#include <openssl/cms.h>
CMS_ContentInfo *CMS_digest_create_ex(BIO *in, const EVP_MD *md,
                                      unsigned int flags, OSSL_LIB_CTX *ctx,
                                      const char *propq);
CMS_ContentInfo *CMS_digest_create(BIO *in, const EVP_MD *md,
                                   unsigned int flags);

الوصف

CMS_digest_create_ex() تنشئ بنية CMS_ContentInfo بننوع NID_pkcs7_digest. يتم هضم البيانات المقدمة عبر BIO in باستخدام md. يتم استخدام سياق المكتبة libctx وطلب الخاصية propq عند استرداد الخوارزميات من الموفرين. الحقل flags يدعم الرايات CMS_DETACHED و CMS_STREAM. داخليًا يتم استدعاء CMS_final() ما لم يتم تحديد CMS_STREAM.

يمكن تحرير بنية CMS_ContentInfo باستخدام CMS_ContentInfo_free(3).

CMS_digest_create() مشابه لـ CMS_digest_create_ex() ولكنه يستخدم القيم الافتراضية NULL لسياق المكتبة libctx وطلب الخاصية propq.

قيم الإرجاع

إذا فشل التخصيص، ترجع CMS_digest_create_ex() و CMS_digest_create() القيمة NULL وتعيين رمز خطأ يمكن الحصول عليه بواسطة ERR_get_error(3). بخلاف ذلك، ترجع مؤشرًا إلى البنية المخصصة حديثًا.

انظر أيضًا

ERR_get_error(3)، CMS_final(3)>
