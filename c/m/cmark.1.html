cmark(1)

الحزمة: cmark

التراخيص: BSD-2-Clause

cmark(1) دليل الأوامر العامة cmark(1)

الاسم

cmark - تحويل نص بصيغة CommonMark إلى HTML

الملخص

cmark [خيارات] ملف*

الوصف

cmark يقوم بتحويل النص العادي بصيغة Markdown إلى HTML أو groff man أو CommonMark XML أو LaTeX أو CommonMark، باستخدام الاتفاقيات الموضحة في مواصفات CommonMark. يقرأ الإدخال من stdin أو الملفات المحددة (يضم محتوياتها) ويكتب الإخراج إلى stdout.

الخيارات

--to, -t التنسيق
تحديد تنسيق الإخراج (html، man، xml، latex، commonmark).
--width العرض
تحديد عرض عمود لتغليف الإخراج. لعدم وجود تغليف، استخدم القيمة 0 (الافتراضية). يؤثر هذا الخيار حاليًا فقط على عارضي commonmark و latex و man.
--hardbreaks
عرض الفواصل الناعمة (الأسطر الجديدة داخل الفقرات في مصدر CommonMark) كفواصل أسطر صلبة في التنسيق المستهدف. إذا تم تحديد هذا الخيار، يتم تعطيل التجاهل الصلب لإخراج CommonMark، بغض النظر عن القيمة المعطاة مع --width.
--nobreaks
عرض الفواصل الناعمة كمسافات. إذا تم تحديد هذا الخيار، يتم تعطيل التجاهل الصلب لجميع تنسيقات الإخراج، بغض النظر عن القيمة المعطاة مع --width.
--sourcepos
تضمين سمة موضع المصدر.
--validate-utf8
التحقق من صحة UTF-8، استبدال التسلسلات غير القانونية بـ U+FFFD.
--smart
استخدام علامات ترقيم ذكية. سيتم عرض علامات الاقتباس المزدوجة والفردية المستقيمة كعلامات اقتباس منحنية، اعتمادًا على موضعها. سيتم عرض -- كشرطة مسافة. --- سيتم عرضها كشرطة تامة. ... سيتم عرضها كعلامات حذف.
--safe
استبعاد HTML الخام وعناوين URL التي قد تكون خطرة (افتراضي). يتم استبدال HTML الخام بتعليق مؤقت وعناوين URL التي قد تكون خطرة بسلاسل فارغة. عناوين URL التي قد تكون خطرة هي تلك التي تبدأ بـ `javascript:` أو `vbscript:` أو `file:` أو `data:` (باستثناء أنواع الوسائط `image/png` أو `image/gif` أو `image/jpeg` أو `image/webp`).
--unsafe
عرض HTML خام أو عناوين URL التي قد تكون خطرة، متجاوزًا السلوك الافتراضي (--safe).
--help
طباعة معلومات الاستخدام.
--version
طباعة الإصدار.
