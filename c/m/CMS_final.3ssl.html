CMS_final(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

CMS_FINAL(3ssl) OpenSSL CMS_FINAL(3ssl)

الاسم

CMS_final, CMS_final_digest - إنهاء بنية CMS_ContentInfo

الملخص

#include <openssl/cms.h>
int CMS_final(CMS_ContentInfo *cms, BIO *data, BIO *dcont, unsigned int flags);
int CMS_final_digest(CMS_ContentInfo *cms, const unsigned char *md,
                     unsigned int mdlen, BIO *dcont, unsigned int flags);

الوصف

تقوم CMS_final() بإنهاء البنية cms. هدفها هو تنفيذ أي عمليات ضرورية على cms (مثل حساب التجزئة) وتعيين الحقول المناسبة. يحتوي المعامل data على المحتوى المراد معالجته. يحتوي المعامل dcont على BIO لكتابة المحتوى إليه بعد المعالجة: يتم استخدامه فقط مع البيانات المنفصلة وعادة ما يتم تعيينه إلى NULL.

تقوم CMS_final_digest() بإنهاء البنية cms باستخدام تجزئة محسوبة مسبقًا، بدلاً من حساب التجزئة من البيانات الأصلية.

ملاحظات

عادةً ما يتم استدعاء هذه الدوال عند استخدام العلامة CMS_PARTIAL. يجب استخدامها فقط عندما لا يتم إجراء التدفق (streaming) لأن دوال الإدخال / الإخراج للتدفق تنفذ عمليات الإنهاء داخليًا.

لتوقيع تجزئة محسوبة مسبقًا، يتم استدعاء CMS_sign(3) أو CMS_sign_ex() مع تعيين المعامل data إلى NULL قبل إنهاء بنية CMS بالتجزئة المقدمة إلى CMS_final_digest() في شكل ثنائي. عند توقيع تجزئة محسوبة مسبقًا، تعتمد الأمان على التجزئة وحسابها من الرسالة الأصلية.

قيم الإرجاع

ترجع CMS_final() و CMS_final_digest() القيمة 1 للنجاح أو 0 للفشل.

انظر أيضًا

ERR_get_error(3)، CMS_sign(3)، CMS_encrypt(3)

التاريخ

تمت إضافة CMS_final_digest() في OpenSSL 3.2.
