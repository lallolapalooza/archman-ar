cmark-gfm(1)

الحزمة: cmark-gfm

التراخيص: custom:BSD2

cmark-gfm(1) دليل الأوامر العامة cmark-gfm(1)

الاسم

cmark - تحويل نص بتنسيق CommonMark مع امتدادات GitHub Flavored Markdown إلى HTML

الاستخدام

cmark-gfm [خيارات] ملف*

الوصف

يقوم cmark-gfm بتحويل النص العادي بتنسيق Markdown إلى HTML أو groff man أو CommonMark XML أو LaTeX أو CommonMark، باستخدام الاتفاقيات الموصوفة في مواصفات CommonMark. يقرأ المدخلات من stdin أو الملفات المحددة (بدمج محتوياتها) ويكتب المخرجات إلى stdout.

الخيارات

--to, -t التنسيق
تحديد تنسيق المخرجات (html، man، xml، latex، commonmark).
--width العرض
تحديد عرض العمود الذي سيتم التفاف المخرجات إليه. لعدم التفاف، استخدم القيمة 0 (الافتراضي). يؤثر هذا الخيار حاليًا فقط على عارضات commonmark و latex و man.
--hardbreaks
عرض فواصل الأسطر الناعمة (الأسطر الجديدة داخل الفقرات في مصدر CommonMark) كفواصل أسطر قوية في التنسيق الهدف. إذا تم تحديد هذا الخيار، يتم تعطيل التفاف الأسطر القوية لمخرجات CommonMark، بغض النظر عن القيمة المعطاة مع --width.
--nobreaks
عرض فواصل الأسطر الناعمة كمسافات. إذا تم تحديد هذا الخيار، يتم تعطيل التفاف الأسطر القوية لجميع تنسيقات المخرجات، بغض النظر عن القيمة المعطاة مع --width.
--sourcepos
تضمين سمة موضع المصدر.
--normalize
دمج عقد النص المجاورة.
--extension, -e اسم_الامتداد
تحديد اسم امتداد للاستخدام.
--list-extensions
عرض قائمة بالامتدادات المتاحة والخروج.
--validate-utf8
التحقق من صحة UTF-8، واستبدال التسلسلات غير الصالحة بـ U+FFFD.
--smart
استخدام علامات الترقيم الذكية. سيتم عرض علامات الاقتباس المزدوجة والفردية المستقيمة كعلامات اقتباس منحنية، اعتمادًا على موضعها. -- سيتم عرضه كشرطة وصل (en-dash). --- سيتم عرضه كشرطة ممدودة (em-dash). ... سيتم عرضه كعلامات حذف.
--unsafe
عرض HTML الخام وعناوين URL التي يحتمل أن تكون خطيرة. (لا يتم استبدال HTML الخام بتعليق نائب؛ لا يتم استبدال عناوين URL التي يحتمل أن تكون خطيرة بسلاسل فارغة). عناوين URL الخطيرة هي تلك التي تبدأ بـ `javascript:` أو `vbscript:` أو `file:` أو `data:` (باستثناء أنواع MIME `image/png` أو `image/gif` أو `image/jpeg` أو `image/webp`).
--help
طباعة معلومات الاستخدام.
--version
طباعة الإصدار.
