CPANPLUS__Internals__Search(3pm)

الحزمة: perl-cpanplus

التراخيص: PerlArtistic, GPL

CPANPLUS::Internals::Search(3) وثائق بيرل المساهمة من المستخدم CPANPLUS::Internals::Search(3)

الاسم

CPANPLUS::Internals::Search - داخليات البحث عن الوحدات

ملخص

my $aref = $cpan->_search_module_tree(
                    type    => 'package',
                    allow   => [qr/DBI/],
                );
my $aref = $cpan->_search_author_tree(
                    type    => 'cpanid',
                    data    => \@old_results,
                    verbose => 1,
                    allow   => [qw|KANE AUTRIJUS|],
                );
my $aref = $cpan->_all_installed( );

الوصف

تم تصميم الوظائف في هذه الوحدة للعثور على كائنات الوحدات بناءً على معايير معينة وإرجاعها.

الأساليب

_search_module_tree( type => TYPE, allow => \@regexes, [data => \@previous_results ] )

يبحث في شجرة الوحدات عن كائنات الوحدات التي تطابق المعايير التي تحددها. يُرجع مرجع مصفوفة لكائنات الوحدات عند النجاح، وقيمة خاطئة عند الفشل.

يأخذ الوسائط التالية:

type
يمكن أن يكون هذا أيًا من الموصلات الخاصة بكائنات "CPANPLUS::Module". هذه وسيطة مطلوبة.
allow
مجموعة من القواعد، أو بشكل أكثر تحديدًا، قائمة بالتعبيرات العادية (عبر "qr//" أو سلاسل نصية عادية)، والتي يجب على "type" الالتزام بها. يمكنك تحديد أكبر عدد تريده، وسيتم التعامل معها كبحث "OR". للحصول على بحث "AND"، انظر وسيطة "data".

هذه وسيطة مطلوبة.

data
مرجع مصفوفة لنتائج البحث السابقة. هذه هي الطريقة لإجراء بحث "AND" - سيقوم "_search_module_tree" بالبحث فقط في كائنات الوحدات المحددة في "data" إذا تم توفيرها، بدلاً من شجرة الوحدات نفسها.

_search_author_tree( type => TYPE, allow => \@regexex, [data => \@previous_results ] )

يبحث في شجرة المؤلفين عن كائنات المؤلفين التي تطابق المعايير التي تحددها. يُرجع مرجع مصفوفة لكائنات المؤلفين عند النجاح، وقيمة خاطئة عند الفشل.

يأخذ الوسائط التالية:

type
يمكن أن يكون هذا أيًا من الموصلات الخاصة بكائنات "CPANPLUS::Module::Author". هذه وسيطة مطلوبة.
allow
مجموعة من القواعد، أو بشكل أكثر تحديدًا، قائمة بالتعبيرات العادية (عبر "qr//" أو سلاسل نصية عادية)، والتي يجب على "type" الالتزام بها. يمكنك تحديد أكبر عدد تريده، وسيتم التعامل معها كبحث "OR". للحصول على بحث "AND"، انظر وسيطة "data".

هذه وسيطة مطلوبة.

data
مرجع مصفوفة لنتائج البحث السابقة. هذه هي الطريقة لإجراء بحث "and" - سيقوم "_search_author_tree" بالبحث فقط في كائنات المؤلفين المحددة في "data" إذا تم توفيرها، بدلاً من شجرة المؤلفين نفسها.

_all_installed()

تقوم هذه الوظيفة بإرجاع مرجع مصفوفة لكائنات الوحدات الخاصة بالوحدات المثبتة على هذا النظام.
