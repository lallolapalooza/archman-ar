subroutine cppsv (uplo, n, nrhs, ap, b, ldb, info)
CPPSV تحسب حل نظام المعادلات الخطية A * X = B للمصفوفات الأخرى

توثيق الوظيفة/الإجراء الفرعي

subroutine cppsv (character uplo, integer n, integer nrhs, complex, dimension( * ) ap, complex, dimension( ldb, * ) b, integer ldb, integer info)

CPPSV تحسب حل نظام المعادلات الخطية A * X = B للمصفوفات الأخرى

الغرض:

!>
!> CPPSV تحسب حل نظام المعادلات الخطية المعقد A * X = B،
!> حيث A هي مصفوفة N-بـ N هرميتية موجبة محددة مخزنة بتنسيق مكدس و X و B هما مصفوفتان N-بـ NRHS.
!>
!> يتم استخدام تحليل تشولسكي لتحليل A إلى:
!>    A = U**H * U، إذا كان UPLO = 'U'، أو
!>    A = L * L**H، إذا كان UPLO = 'L'،
!> حيث U مصفوفة مثلثة علوية و L مصفوفة مثلثة سفلية. ثم يتم استخدام الشكل المحلل لـ A لحل نظام المعادلات A * X = B.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  يتم تخزين المثلث العلوي من A؛
!>          = 'L':  يتم تخزين المثلث السفلي من A.
!>

N

!>          N هو INTEGER
!>          عدد المعادلات الخطية، أي رتبة المصفوفة A. N >= 0.
!>

NRHS

!>          NRHS هو INTEGER
!>          عدد الأطراف اليمنى، أي عدد أعمدة المصفوفة B. NRHS >= 0.
!>

AP

!>          AP هو مصفوفة COMPLEX، الأبعاد (N*(N+1)/2)
!>          عند الإدخال، المثلث العلوي أو السفلي للمصفوفة الهرميتية A، مكدس عمودياً في مصفوفة خطية. يتم تخزين العمود j من A
!>          في المصفوفة AP على النحو التالي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>          انظر أدناه لمزيد من التفاصيل.
!>
!>          عند الخروج، إذا كان INFO = 0، فإن العامل U أو L من تحليل تشولسكي
!>          A = U**H*U أو A = L*L**H، بنفس تنسيق التخزين لـ A.
!>

B

!>          B هي مصفوفة COMPLEX، الأبعاد (LDB,NRHS)
!>          عند الإدخال، مصفوفة الطرف الأيمن B بحجم N-بـ NRHS.
!>          عند الخروج، إذا كان INFO = 0، فإن مصفوفة الحل X بحجم N-بـ NRHS.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرائد للمصفوفة B. LDB >= max(1,N).
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت لها قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن المحدد الرئيسي الرائد من الرتبة i
!>                لـ A ليس موجباً، لذلك لم يكن من الممكن إكمال التحليل،
!>                ولم يتم حساب الحل.
!>

!>
!>  مخطط التخزين المكدس موضح بالمثال التالي
!>  عندما N = 4، UPLO = 'U':
!>
!>  التخزين ثنائي الأبعاد للمصفوفة الهرميتية A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  التخزين المكدس للمثلث العلوي من A:
!>
!>  AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
!>
