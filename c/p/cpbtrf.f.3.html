وثائق الوظيفة/الروتين الفرعي

subroutine cpbtrf (character uplo, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, integer info)

CPBTRF

الغرض:

!>
!> CPBTRF يحسب تحليل Cholesky لمصفوفة فرقة هرميتية موجبة محددة معقدة A.
!>
!> التحليل له الشكل
!>    A = U**H * U,  if UPLO = 'U', or
!>    A = L  * L**H,  if UPLO = 'L',
!> حيث U مصفوفة مثلثية عليا و L مصفوفة مثلثية سفلى.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  الجزء العلوي من A مخزن;
!>          = 'L':  الجزء السفلي من A مخزن.
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          عدد الأقطار الفائقة للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفرعية إذا كان UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB is COMPLEX array, dimension (LDAB,N)
!>          عند الدخول، الجزء العلوي أو السفلي من المصفوفة الفرقة الهرميتية
!>          A، مخزنة في أول KD+1 صف من المصفوفة.  الـ
!>          العمود j من A مخزن في العمود j من المصفوفة AB
!>          على النحو التالي:
!>          if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)    = A(i,j) for j<=i<=min(n,j+kd).
!>
!>          عند الخروج، إذا كان INFO = 0، فإن عامل المثلث U أو L من
!>          تحليل Cholesky A = U**H*U أو A = L*L**H للمصفوفة الفرقة
!>          A، بنفس تنسيق التخزين مثل A.
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= KD+1.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  if INFO = -i, the i-th argument had an illegal value (كان الوسيط i غير قانوني)
!>          > 0:  if INFO = i, the leading principal minor of order i
!>                is not positive, and the factorization could not be
!>                completed. (المحدد الرئيسي الرائد من الدرجة i ليس موجباً، ولم يتمكن من إكمال التحليل.)
!>

تفاصيل إضافية:

!>
!>  مخطط تخزين النطاق موضحة بالمثال التالي، عندما
!>  N = 6, KD = 2, and UPLO = 'U':
!>
!>  عند الدخول:                       عند الخروج:
!>
!>      *    *   a13  a24  a35  a46      *    *   u13  u24  u35  u46
!>      *   a12  a23  a34  a45  a56      *   u12  u23  u34  u45  u56
!>     a11  a22  a33  a44  a55  a66     u11  u22  u33  u44  u55  u66
!>
!>  وبالمثل، إذا كان UPLO = 'L' فإن تنسيق A هو كالتالي:
!>
!>  عند الدخول:                       عند الخروج:
!>
!>     a11  a22  a33  a44  a55  a66     l11  l22  l33  l44  l55  l66
!>     a21  a32  a43  a54  a65   *      l21  l32  l43  l54  l65   *
!>     a31  a42  a53  a64   *    *      l31  l42  l53  l64   *    *
!>
!>  العناصر الموجودة في المصفوفة والمشار إليها بـ * لا تستخدمها الروتين.
!>
