توثيق الوظيفة/الإجراء الفرعي

subroutine cpocon (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real anorm, real rcond, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPOCON

الغرض:

!>
!> CPOCON تقدر مقلوب رقم الشرط (في
!> المعيار 1-norm) لمصفوفة مركبة هرمية موجبة محددة باستخدام
!> تحليل Cholesky A = U**H*U أو A = L*L**H المحسوب بواسطة CPOTRF.
!>
!> يتم الحصول على تقدير للمعيار norm(inv(A))، ويتم حساب مقلوب
!> رقم الشرط كـ RCOND = 1 / (ANORM * norm(inv(A))).
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  يتم تخزين المثلث العلوي لـ A؛
!>          = 'L':  يتم تخزين المثلث السفلي لـ A.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

A

!>          A هي مصفوفة COMPLEX، البعد (LDA,N)
!>          العامل المثلثي U أو L من تحليل Cholesky
!>          A = U**H*U أو A = L*L**H، كما تم حسابه بواسطة CPOTRF.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM هو REAL
!>          المعيار 1 (أو المعيار اللانهائي) للمصفوفة الهرمية A.
!>

RCOND

!>          RCOND هو REAL
!>          مقلوب رقم شرط المصفوفة A،
!>          محسوب كـ RCOND = 1/(ANORM * AINVNM)، حيث AINVNM هو تقدير
!>          للمعيار 1 للمصفوفة inv(A) المحسوب في هذا الروتين.
!>

WORK

!>          WORK هي مصفوفة COMPLEX، البعد (2*N)
!>

RWORK

!>          RWORK هي مصفوفة REAL، البعد (N)
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت ذات قيمة غير قانونية
!>
