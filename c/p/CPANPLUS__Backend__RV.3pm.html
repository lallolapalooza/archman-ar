CPANPLUS__Backend__RV(3pm)

الحزمة: perl-cpanplus

التراخيص: PerlArtistic, GPL

CPANPLUS::Backend::RV(3) وثائق بيرل المساهمة من المستخدم CPANPLUS::Backend::RV(3)

الاسم

CPANPLUS::Backend::RV - كائنات القيمة المرجعة

الملخص

### إنشاء كائن CPANPLUS::Backend::RV
$backend_rv     = CPANPLUS::Backend::RV->new(
                            ok          => $boolean,
                            args        => $args,
                            rv          => $return_value
                            function    => $calling_function );
### إذا كان لديك كائن CPANPLUS::Backend::RV
$passed_args    = $backend_rv->args;    # الوسائط التي تم تمريرها إلى الدالة
$ok             = $backend_rv->ok;      # مؤشر منطقي للنتيجة الإجمالية
                                        # للاتصال
$function       = $backend_rv->function # اسم الدالة
                                        # التي تم استدعاؤها
$rv             = $backend_rv->rv       # القيمة المرجعة الفعلية
                                        # للدالة التي تم استدعاؤها

الوصف

توفر هذه الوحدة كائنات قيمة مرجعة لاستدعاءات الوحدات المتعددة إلى CPANPLUS::Backend. في السياق المنطقي، فإنها تُرجع حالة النتيجة الإجمالية (أي، نفس ما ستُرجعه الطريقة "ok").

الطرق

new( ok => BOOL, args => DATA, rv => DATA, [function => $method_name] )

تنشئ كائن CPANPLUS::Backend::RV جديدًا من البيانات المقدمة. يجب استدعاء هذه الطريقة فقط بواسطة دوال CPANPLUS::Backend. يمكن استخدام الوصولين لاحقًا بواسطة المستخدمين الذين يفحصون كائن RV.

يمكن استخدام جميع أسماء الوسائط كوصولين لاحقًا لاسترداد البيانات.

الوسائط:

ok
قيمة منطقية تشير إلى النجاح الإجمالي
args
الوسائط التي تم تقديمها إلى الدالة التي أعادت كائن rv هذا. مفيد للفحص لاحقًا لمعرفة ما تم تمريره فعليًا إلى الدالة في حالة وجود خطأ.
rv
هيكل بيانات عشوائي يحتوي على القيم المرجعة التفصيلية لكل من استدعاءات الوحدات المتعددة الخاصة بك.
function
اسم الدالة التي أنشأت كائن rv هذا. يمكن تمريره بشكل صريح. إذا لم يتم تمريره، ستحاول new() استنتاج الاسم من معلومات caller().
