Function/Subroutine Documentation

CPOSVXX is a subroutine in the LAPACK library.

It computes the solution to a complex system of linear equations:

A * X = B

where A is a complex Hermitian positive definite matrix, and B is a complex matrix. Eigenvalue computations are used and handled by the routine `CPOSVX`.

The routine performs the following steps:

  1. Computes the Cholesky factorization of A.
  2. Computes the solution X to the system of equations.
  3. Estimates the condition number of A.
  4. Computes error bounds for the solution X.

The parameters are:

UPLO
Character*1. Specifies whether the matrix A is upper or lower triangular.
'U': Upper triangular
'L': Lower triangular
N
Integer. The order of the matrix A (N x N).
NRHS
Integer. The number of right-hand sides (number of columns in B).
A
Complex array of dimension (LDA, N). On entry, the array A contains the matrix A.
LDA
Integer. The leading dimension of the array A.
AF
Complex array of dimension (LDAF, N). If INFO = 0, AF contains the Cholesky factor of A.
LDAF
Integer. The leading dimension of the array AF.
IPIV
Integer array of dimension N. If INFO = 0, IPIV contains the pivot indices.
B
Complex array of dimension (LDB, NRHS). On entry, the array B contains the matrix B. On exit, B contains the solution matrix X.
LDB
Integer. The leading dimension of the array B.
RCOND
Double Precision. Estimate of the reciprocal condition number of A. RCOND is computed using the diagonal elements of the Cholesky factor.
SRCOND
Double Precision. Estimate of the reciprocal condition number of A with respect to the scaled matrix. SRCOND is computed using the diagonal elements of the Cholesky factor.
ERR_BNDS_NORM
Complex array of dimension (NRHS). Contains the forward error bound for each solution vector X(J, K).
ERR_BNDS_COMP
Complex array of dimension (NRHS). Contains the component-wise error bound for each solution vector X(J, K).
DWORK
Complex array of dimension (N).
TWORK
Complex array of dimension (N).
INFO
Integer. INFO = 0: successful exit. INFO < 0: if INFO = -i, the i-th argument had an illegal value. INFO > 0: if INFO = i, A is not positive definite, and the factorization could not be completed. The factorization has been completed up to the given column i.

The error bounds are computed as follows:

ERR_BNDS_NORM(J, 1) is an upper bound on the infinity norm of the absolute error |X(J, 1) - XTRUE(J, 1)|, where XTRUE is the exact solution.

ERR_BNDS_COMP(J, 1) is an upper bound on the component-wise relative error |X(J, 1) - XTRUE(J, 1)| / |X(J, 1)|.

If ERR_BNDS_NORM(J, 1) or ERR_BNDS_COMP(J, 1) is large, then the computed solution X(J, 1) is not accurate.

To get information about all of the right-hand sides, check ERR_BNDS_NORM or ERR_BNDS_COMP.

See the definition of ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1).

If ERR_BNDS_NORM(J,1) = 0.0 or ERR_BNDS_COMP(J,1) = 0.0, then the error bound is zero.
