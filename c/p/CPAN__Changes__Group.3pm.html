الحزمة: perl-cpan-changes

التراخيص: GPL, PerlArtistic

CPAN::Changes::Group(3) توثيق مساهمات مستخدمي Perl CPAN::Changes::Group(3)

الاسم

CPAN::Changes::Group - مجموعة إدخال في ملف تغييرات CPAN

الملخص

my $group = CPAN::Changes::Group->new(
  name    => 'مجموعة تغيير',
  changes => [
    'إدخال تغيير',
    'إدخال تغيير آخر',
  ],
);

الوصف

يمثل مجموعة من إدخالات التغيير في إصدار سجل التغييرات. هذه واجهة قديمة لـ ويُثبط استخدامها.

تعمل هذه الواجهة في الخلفية كوكيل لكائنات CPAN::Changes::Entry الحقيقية.
