cpanp(1p)

الحزمة: perl-cpanplus

التراخيص: PerlArtistic, GPL

CPANP(1p) وثائق Perl المساهمة من المستخدم CPANP(1p)

الاسم

cpanp - مشغل CPANPLUS

المُلَخَّص

cpanp

cpanp [-]a [ --[no-]option... ]  author... 

cpanp [-]mfitulrcz [ --[no-]option... ]  module... 

cpanp [-]d [ --[no-]option... ] [ --fetchdir=... ]  module... 

cpanp [-]xb [ --[no-]option... ]

cpanp [-]o [ --[no-]option... ] [ module... ]

الوصف

يقوم هذا السكربت بتشغيل أداة CPANPLUS لإجراء عمليات مختلفة من سطر الأوامر. إذا تم استدعاؤه بدون وسائط، يتم تنفيذ واجهة shell تفاعلية افتراضياً.

اختيارياً، يمكن أن يأخذ مفتاح حرف واحد ووسيط واحد أو أكثر، لإجراء الإجراء المرتبط بكل وسيط. يتم سرد ملخص للأوامر المتاحة أدناه؛ "cpanp -h" يوفر قائمة مفصلة.

h                   # معلومات المساعدة
v                   # معلومات الإصدار
a AUTHOR ...        # البحث حسب المؤلف(ين)
m MODULE ...        # البحث حسب الوحدة(الوحدات)
f MODULE ...        # قائمة بجميع إصدارات الوحدة
i MODULE ...        # تثبيت الوحدة(الوحدات)
t MODULE ...        # اختبار الوحدة(الوحدات)
u MODULE ...        # إلغاء تثبيت الوحدة(الوحدات)
d MODULE ...        # تنزيل الوحدة(الوحدات)
l MODULE ...        # عرض معلومات مفصلة حول الوحدة(الوحدات)
r MODULE ...        # عرض ملفات README للوحدة(الوحدات)
c MODULE ...        # التحقق من تقرير(تقارير) الوحدة من cpan-testers
z MODULE ...        # استخراج الوحدة(الوحدات) وفتح موجه الأوامر فيها
x                   # إعادة تحميل فهارس CPAN
o [ MODULE ... ]    # قائمة بالوحدات المثبتة التي ليست محدثة
b                   # كتابة ملف حزمة لتكوينك

يمكن أن يتبع كل أمر واحد أو أكثر من الخيارات. إذا سبقته "no"، فسيتم تعيين الخيار المقابل إلى 0، وإلا فسيتم تعيينه إلى 1.

مثال: لتخطي اختبارات الوحدة،

cpanp -i --skiptest MODULE ...

الخيارات الصالحة لمعظم الأوامر هي "cpantest"، "debug"، "flush"، "force"، "prereqs"، "storable"، "verbose"، "md5"، "signature"، و "skiptest"؛ الأمر 'd' يقبل أيضًا "fetchdir". يرجى الرجوع إلى CPANPLUS::Configure لشرح معانيها.

مثال: لتنزيل ملف tarball لوحدة إلى الدليل الحالي،

cpanp -d --fetchdir=. MODULE ...
2025-07-13 perl v5.42.0
