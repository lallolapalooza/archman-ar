CPANPLUS__Internals__Report(3pm)

الحزمة: perl-cpanplus

التراخيص: PerlArtistic, GPL

CPANPLUS::Internals::Report(3) وثائق Perl المساهمة من المستخدم CPANPLUS::Internals::Report(3)

الاسم

CPANPLUS::Internals::Report - داخليات لإرسال تقارير الاختبار

الملخص

### تمكين إبلاغ الاختبار
$cb->configure_object->set_conf( cpantest => 1 );
### تعيين مضيف mx مخصص، لا ينبغي أن يكون ضرورياً في العادة
$cb->configure_object->set_conf( cpantest_mx => 'smtp.example.com' );

الوصف

توفر هذه الوحدة كل الوظائف اللازمة لإرسال تقارير الاختبار إلى "http://testers.cpan.org" باستخدام الوحدة "Test::Reporter".

سيتم استدعاء جميع الطرق تلقائيًا إذا قمت بتكوين "CPANPLUS" لتمكين إبلاغ الاختبار (انظر "الملخص").

الطرق

$bool = $cb->_have_query_report_modules

تتحقق هذه الوظيفة مما إذا كانت جميع الوحدات المطلوبة موجودة للاستعلام عن التقارير. تُرجع صحيحة وتحملها إذا كانت موجودة، أو تُرجع خاطئة بخلاف ذلك.

$bool = $cb->_have_send_report_modules

تتحقق هذه الوظيفة مما إذا كانت جميع الوحدات المطلوبة موجودة لإرسال التقارير. تُرجع صحيحة وتحملها إذا كانت موجودة، أو تُرجع خاطئة بخلاف ذلك.

@list = $cb->_query_report( module => $modobj, [all_versions => BOOL, verbose => BOOL] )

تستعلم هذه الوظيفة من قاعدة بيانات مختبري CPAN على http://testers.cpan.org/ للحصول على نتائج الاختبار لكائنات الوحدات أو أسماء الوحدات أو التوزيعات المحددة.

الوسيط الاختياري "all_versions" يتحكم فيما إذا كان سيتم جلب جميع إصدارات توزيع معين. القيمة الافتراضية هي خاطئة (جلب التقارير للإصدار الحالي فقط).

تُرجع قائمة بهياكل البيانات التالية (لإصدار CPANPLUS 0.042) عند النجاح، أو خاطئة عند الفشل. يعتمد محتوى هيكل البيانات على ما تُرجعه http://testers.cpan.org، ولكنه يبدو بشكل عام كالتالي:

{
  'grade' => 'PASS',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'i686-pld-linux-thread-multi'
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/98316'
  ...
},
{
  'grade' => 'PASS',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'i686-linux-thread-multi'
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/99416'
  ...
},
{
  'grade' => 'FAIL',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'cygwin-multi-64int',
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/99371'
  ...
},
{
  'grade' => 'FAIL',
  'dist' => 'CPANPLUS-0.042',
  'platform' => 'i586-linux',
  'details' => 'http://nntp.x.perl.org/group/perl.cpan.testers/99396'
  ...
},

يمكن أن تكون حالة الاختبار واحدة مما يلي: UNKNOWN (غير معروف)، PASS (نجاح)، FAIL (فشل)، أو NA (غير قابل للتطبيق).

$bool = $cb->_send_report( module => $modobj, buffer => $make_output, failed => BOOL, [save => BOOL, address => $email_to, verbose => BOOL, force => BOOL]);

ترسل هذه الوظيفة تقرير مختبرين إلى "cpan-testers@perl.org" لتوزيع معين. تُرجع صحيحة عند النجاح، وخاطئة عند الفشل.

تأخذ الخيارات التالية:

module
كائن الوحدة لهذا التوزيع المحدد
buffer
مخزن الإخراج من عملية 'make/make test'
failed
قيمة منطقية تشير إلى ما إذا كانت عملية 'make/make test' قد فشلت
save
قيمة منطقية تشير إلى ما إذا كان يجب حفظ التقرير محليًا بدلاً من إرساله بالبريد. إذا تم توفيرها، فستُرجع هذه الوظيفة الموقع الذي تم حفظ التقرير فيه، بدلاً من قيمة منطقية بسيطة 'TRUE'.

القيمة الافتراضية: خاطئة.

address
عنوان البريد الإلكتروني لإرسال التقرير إليه. لا يجب عليك تجاوز هذا أبداً، ولكنه قد يكون مفيدًا لأغراض التصحيح.

القيمة الافتراضية: "cpan-testers@perl.org".

verbose
قيمة منطقية تشير إلى ما إذا كان سيتم عرض التفاصيل أم لا.

القيمة الافتراضية: إعدادات التكوين الخاصة بك

force
قيمة منطقية تشير إلى ما إذا كان سيتم فرض الإرسال، حتى لو تم الوصول إلى الحد الأقصى لعدد التقارير للأخطاء، أو إذا كنت قد أرسلته من قبل.
