CPANPLUS__Internals__Fetch(3pm)

الحزمة: perl-cpanplus

التراخيص: PerlArtistic, GPL

CPANPLUS::Internals::Fetch(3) وثائق Perl المساهمة من المستخدم CPANPLUS::Internals::Fetch(3)

الاسم

CPANPLUS::Internals::Fetch - داخليات لجلب الملفات

الملخص

my $output = $cb->_fetch(
                    module      => $modobj,
                    fetchdir    => '/path/to/save/to',
                    verbose     => BOOL,
                    force       => BOOL,
                );
$cb->_add_fail_host( host => 'foo.com' );
$cb->_host_ok(       host => 'foo.com' );

الوصف

CPANPLUS::Internals::Fetch تجلب الملفات من خوادم ftp أو http أو file أو rsync.

هذا هو التسلسل التقريبي للعملية:

$cb->_fetch
    Delegate to File::Fetch;

الأساليب

$path = _fetch( module => $modobj, [fetchdir => '/path/to/save/to', fetch_from => 'scheme://path/to/fetch/from', verbose => BOOL, force => BOOL, prefer_bin => BOOL, ttl => $seconds] )

"_fetch" سيقوم بجلب الملفات بناءً على المعلومات الموجودة في كائن الوحدة. أنت بحاجة دائمًا إلى كائن وحدة. إذا كنت تريد كائن وحدة وهمي لجلب لمرة واحدة، فراجع "CPANPLUS::Module::Fake".

"fetchdir" هو المكان الذي يتم فيه حفظ الملف. عادةً ما تأتي هذه المعلومات من تكوينك، ولكن يمكنك تجاوزها صراحةً إذا لزم الأمر.

"fetch_from" يتيح لك تحديد URI للحصول على هذا الملف منه. إذا لم تحدد واحدًا، فسيتم فحص قائمة الخوادم المكونة لديك لتنزيل الملف منها.

"force" يجبر على تنزيل جديد، حتى لو كان الملف موجودًا بالفعل.

"verbose" يشير ببساطة إلى ما إذا كان سيتم طباعة رسائل إضافية أم لا.

"prefer_bin" يشير إلى ما إذا كنت تفضل استخدام برامج سطر الأوامر على وحدات Perl. الافتراضي هو إعداد التكوين المقابل لك.

"ttl" (بالثواني) يشير إلى مدة صلاحية النسخة المخزنة مؤقتًا. إذا كان وقت جلب النسخة المحلية ضمن مدة الصلاحية (ttl)، فسيتم إرجاع النسخة المخزنة مؤقتًا. خلاف ذلك، سيتم إعادة جلب الملف.

"_fetch" يحدد، بناءً على قائمة الخوادم، المخطط (scheme) الذي سيتم استخدامه ومن هناك، يفوض إلى "File::Fetch" للقيام بعملية الجلب الفعلية.

يُرجع مسار ملف الإخراج عند النجاح، و false عند الفشل.

لاحظ أنه يمكنك تعيين "blacklist" على طرق معينة في التكوين. ببساطة أضف الاسم التعريفي للطريقة (على سبيل المثال، "lwp") إلى:
$conf->_set_fetch( blacklist => ['lwp'] );

وسيتم تخطي وظيفة "LWP" بواسطة "File::Fetch".

_add_fail_host( host => $host_hashref )

ضع علامة على خادم معين كخادم سيء. هذا يجعل "CPANPLUS::Internals::Fetch" يتجاهله في عمليات الجلب حتى يتم مسح هذه ذاكرة التخزين المؤقت.

_host_ok( host => $host_hashref )

استعلم عن ذاكرة التخزين المؤقت لمعرفة ما إذا كان هذا الخادم جيدًا، أو ما إذا كان قد تم وضع علامة عليه كخادم سيء.

يُرجع true إذا كان الخادم جيدًا، و false بخلاف ذلك.
