CPAN__Changes(3pm)

الحزمة: perl-cpan-changes

التراخيص: GPL, PerlArtistic

CPAN::Changes(3) توثيق Perl من مساهمات المستخدم CPAN::Changes(3)

الاسم

CPAN::Changes - محلل سجلات التغييرات بأسلوب CPAN

ملخص

use CPAN::Changes;
my $changes = CPAN::Changes->load('Changes');
$changes->release('0.01');

الوصف

من الممارسات القياسية تضمين ملف التغييرات في توزيعك. الغرض من ملف التغييرات هو مساعدة المستخدم في معرفة ما تغير منذ الإصدار الأخير.

ابتكر الناس العديد من الطرق لكتابة ملف التغييرات. تم إنشاء مواصفات أولية (CPAN::Changes::Spec) لتشجيع مؤلفي الوحدات على كتابة تغييرات واضحة وموجزة.

ستساعد هذه الوحدة المستخدمين على قراءة وكتابة ملفات التغييرات التي تتوافق مع المواصفات بشكل برمجي.

الأساليب

جديد ( %args )

ينشئ كائن CPAN::Changes.

%args

مقدمة
قسم المقدمة في سجل التغييرات.
إصدارات
مرجع مصفوفة لكائنات CPAN::Changes::Release.

تحميل ( $filename, %args )

ينشئ كائن CPAN::Changes جديد عن طريق تحليل الملف المحدد عبر CPAN::Changes::Parser.

تحميل_سلسلة ( $filename, %args )

ينشئ كائن CPAN::Changes جديد عن طريق تحليل السلسلة المحددة عبر CPAN::Changes::Parser.

مقدمة ( [ $preamble ] )

يحصل على قسم المقدمة أو يعيّنه.

إصدارات ( [ @releases ] )

يحصل على قائمة الإصدارات ككائنات CPAN::Changes::Release أو يعيّنها.

إضافة_إصدار ( @releases )

يضيف الإصدارات المعطاة إلى سجل التغييرات. إذا كان هناك إصدار بنفس الإصدار موجودًا، فسيتم الكتابة فوقه.

حذف_إصدار ( @versions )

يزيل الإصدارات المعطاة من سجل التغييرات.

بحث_عن_إصدار ( $version )

يبحث عن إصدار بالإصدار المحدد.

معكوس

يعيد كائن CPAN::Changes جديد مع عكس ترتيب الإصدارات.

نسخ ( %attrs )

يعيد كائن "CPAN::Changes" جديد مع تغيير السمات المعطاة.

تسلسل ( %options )

يعيد سجل التغييرات كسلسلة نصية مناسبة للحفظ كملف Changes.

عرض
العرض الذي سيتم التفاف الأسطر عنده. افتراضيًا، سيتم التفاف الأسطر عند 75 حرفًا.
أنماط
مرجع مصفوفة للأنماط التي سيتم استخدامها عند إخراج الإدخالات، واحد لكل مستوى من التغيير. يتم استخدام الإدخال الأول لإدخال الإصدار نفسه.

يمكن أن تكون الأنماط حرفًا واحدًا لبادئة أسطر التغيير أو حرفين لاستخدامهما كبادئة ولاحقة.

مسافات_بادئة
مرجع مصفوفة لسلاسل المسافات البادئة التي سيتم استخدامها عند إخراج الإدخالات.
عكس (قديم)
إذا كان صحيحًا، سيتم إخراج الإصدارات بترتيب معكوس.
فرز_المجموعات (قديم)
مرجع كود يستخدم لفرز المجموعات في الإصدارات.

أساليب_قديمة

حذف_المجموعات_الفارغة

يزيل المجموعات الفارغة.

إصدار

اسم مستعار لـ find_release.
