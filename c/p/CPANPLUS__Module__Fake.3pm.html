CPANPLUS__Module__Fake(3pm)

الحزمة: perl-cpanplus

التراخيص: PerlArtistic, GPL

CPANPLUS::Module::Fake(3) توثيق مساهمة المستخدم من بيرل CPANPLUS::Module::Fake(3)

الاسم

CPANPLUS::Module::Fake - كائن وحدة وهمي للاستخدام الداخلي

ملخص

my $obj = CPANPLUS::Module::Fake->new(
            module  => 'Foo',
            path    => 'ftp/path/to/foo',
            author  => CPANPLUS::Module::Author::Fake->new,
            package => 'fake-1.1.tgz',
            _id     => $cpan->_id,
        );

الوصف

فئة لإنشاء كائنات وحدات وهمية، للاستخدام المختصر داخليًا بواسطة CPANPLUS.

ترث من "CPANPLUS::Module".

الأساليب

new( module => $mod, path => $path, package => $pkg, [_id => DIGIT] )

ينشئ كائن وحدة وهمي من المعلمات المذكورة أعلاه. يمكنه قبول خيارات إضافية (نفس خيارات "CPANPLUS::Module->new" ولكن ما سبق إلزامي).
