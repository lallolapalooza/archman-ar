CPAN::Version(3perl) دليل مبرمجي Perl CPAN::Version(3perl)

الاسم

CPAN::Version - وظائف مساعدة لمقارنة إصدارات CPAN

الملخص

use CPAN::Version;
CPAN::Version->vgt("1.1","1.1.1");    # 1 bc. 1.1 > 1.001001
CPAN::Version->vlt("1.1","1.1");      # 0 bc. 1.1 not < 1.1
CPAN::Version->vcmp("1.1","1.1.1");   # 1 bc. first is larger
CPAN::Version->vcmp("1.1.1","1.1");   # -1 bc. first is smaller
CPAN::Version->readable(v1.2.3);      # "v1.2.3"
CPAN::Version->vstring("v1.2.3");     # v1.2.3
CPAN::Version->float2vv(1.002003);    # "v1.2.3"

الوصف

تتوسط هذه الوحدة بين بعض الإصدارات التي تراها Perl في حزمة ما والإصدار المنشور بواسطة مفهرس CPAN.

لقد كُتبت فقط كوحدة مساعدة لكل من CPAN.pm و CPANPLUS.pm.

حتى الآن، سبقت وحدة version.pm ولكن لها نفس الهدف: جعل سلاسل الإصدارات مرئية وقابلة للمقارنة.
