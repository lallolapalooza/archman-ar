توثيق الوظيفة/الروتين الفرعي

subroutine clqt02 (integer m, integer n, integer k, complex, dimension( lda, * ) a, complex, dimension( lda, * ) af, complex, dimension( lda, * ) q, complex, dimension( lda, * ) l, integer lda, complex, dimension( * ) tau, complex, dimension( lwork ) work, integer lwork, real, dimension( * ) rwork, real, dimension( * ) result)

CLQT02

الغرض:

!>
!> CLQT02 تختبر CUNGLQ، التي تنشئ مصفوفة m x n تسمى Q لها صفوف متعامدة
!> وتُعرّف كناتج لمُبدِّلات ابتدائية k.
!>
!> بالنظر إلى تحليل LQ لمصفوفة m x n تسمى A، تقوم CLQT02 بإنشاء
!> المصفوفة المتعامدة Q المعرفة بتحليل أول k صفوف من A؛ وتقارن
!> L(1:k,1:m) مع A(1:k,1:n)*Q(1:m,1:n)'، وتتحقق من أن صفوف Q متعامدة.
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>          عدد صفوف المصفوفة Q المراد إنشاؤها. M >= 0.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>          عدد أعمدة المصفوفة Q المراد إنشاؤها.
!>          N >= M >= 0.
!>

K

!>          K هو عدد صحيح (INTEGER)
!>          عدد المُبدِّلات الابتدائية التي يُعرّف ناتجها المصفوفة Q.
!>          M >= K >= 0.
!>

A

!>          A هي مصفوفة مركبة (COMPLEX)، ذات بُعد (LDA,N)
!>          المصفوفة A ذات الأبعاد m x n والتي تم تحليلها بواسطة CLQT01.
!>

AF

!>          AF هي مصفوفة مركبة (COMPLEX)، ذات بُعد (LDA,N)
!>          تفاصيل تحليل LQ للمصفوفة A، كما تم إرجاعها بواسطة CGELQF.
!>          راجع CGELQF لمزيد من التفاصيل.
!>

Q

!>          Q هي مصفوفة مركبة (COMPLEX)، ذات بُعد (LDA,N)
!>

L

!>          L هي مصفوفة مركبة (COMPLEX)، ذات بُعد (LDA,M)
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البُعد الرائد للمصفوفات A، AF، Q، و L. LDA >= N.
!>

TAU

!>          TAU هي مصفوفة مركبة (COMPLEX)، ذات بُعد (M)
!>          العوامل القياسية للمُبدِّلات الابتدائية المقابلة لتحليل LQ في AF.
!>

WORK

!>          WORK هي مصفوفة مركبة (COMPLEX)، ذات بُعد (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح (INTEGER)
!>          بُعد مصفوفة WORK.
!>

RWORK

!>          RWORK هي مصفوفة حقيقية (REAL)، ذات بُعد (M)
!>

RESULT

!>          RESULT هي مصفوفة حقيقية (REAL)، ذات بُعد (2)
!>          نسب الاختبار:
!>          RESULT(1) = norm( L - A*Q' ) / ( N * norm(A) * EPS )
!>          RESULT(2) = norm( I - Q*Q' ) / ( N * EPS )
!>
