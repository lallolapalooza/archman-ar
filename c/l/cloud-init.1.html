CLOUD-INIT(1) دليل الأوامر العامة CLOUD-INIT(1)

الاسم

cloud-init - تهيئة مثيل السحابة

الملخص

cloud-init [-h] [-d] [--force] [-v] [SUBCOMMAND]

الوصف

يوفر cloud-init آلية لتهيئة مثيل السحابة. يتم ذلك عن طريق تحديد منصة السحابة المستخدمة، وقراءة بيانات التعريف الخاصة بالسحابة وبيانات البائع وبيانات المستخدم، ثم تهيئة المثيل كما هو مطلوب.

خيارات

-h, --help
عرض رسالة المساعدة والخروج.
-v, --version
عرض رقم إصدار البرنامج والخروج.
--all-stages
داخلي: تشغيل مراحل cloud-init تحت عملية واحدة باستخدام بروتوكول تزامن. هذا غير مخصص للاستخدام عبر سطر الأوامر.

الأوامر الفرعية

يرجى الرجوع إلى مخرجات المساعدة لكل أمر فرعي للحصول على تفاصيل إضافية، وعلامات، وأوامر فرعية.

analyze
تحليل سجلات وبيانات cloud-init.
collect-logs
جمع وتجميع كل معلومات تصحيح أخطاء cloud-init.
clean
إزالة السجلات والقطع الأثرية حتى يتمكن cloud-init من إعادة التشغيل.
devel
تشغيل أدوات التطوير. انظر مخرجات المساعدة لتفاصيل الأوامر الفرعية.
features
قائمة الميزات المعرفة.
query
الاستعلام عن بيانات التعريف الموحدة للمثيل من سطر الأوامر.
schema
التحقق من صحة ملفات cloud-config باستخدام jsonschema.
single
تشغيل وحدة نمطية واحدة يدويًا. مفيدة للاختبار أثناء التطوير.
status
الإبلاغ عن حالة cloud-init أو الانتظار حتى الاكتمال.

مهمل

-d, --debug
عرض تسجيل إضافي قبل الإجراء (الافتراضي: False).
--force
فرض التشغيل حتى لو لم يتم العثور على مصدر بيانات (استخدمه على مسؤوليتك الخاصة).
init
تهيئة cloud-init وتنفيذ الوحدات النمطية الأولية.
modules
تنشيط الوحدات النمطية باستخدام مفتاح تكوين معين.

حالة الخروج

0 - نجاح
1 - خطأ - فشل cloud-init.
2 - خطأ قابل للاسترداد - اكتمل cloud-init ولكنه واجه أخطاء.
