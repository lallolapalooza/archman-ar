CLOSE(7)

الحزمة: postgresql

CLOSE(7) توثيق PostgreSQL 18.1 CLOSE(7)

الاسم

CLOSE - إغلاق مؤشر

الاختصار

CLOSE { name | ALL }

الوصف

CLOSE يحرر الموارد المرتبطة بمؤشر مفتوح. بعد إغلاق المؤشر، لا يُسمح بأي عمليات لاحقة عليه. يجب إغلاق المؤشر عندما لا يعود هناك حاجة إليه.

يتم ضمنيًا إغلاق كل مؤشر غير محتفظ به مفتوح عند إنهاء معاملة بواسطة COMMIT أو ROLLBACK. يتم ضمنيًا إغلاق المؤشر المحتفظ به إذا تم إلغاء المعاملة التي أنشأته عبر ROLLBACK. إذا نجحت المعاملة المنشئة في الالتزام، يظل المؤشر المحتفظ به مفتوحًا حتى يتم تنفيذ CLOSE صريح، أو ينقطع اتصال العميل.

المعلمات

name

اسم مؤشر مفتوح لإغلاقه.

ALL

إغلاق جميع المؤشرات المفتوحة.

ملاحظات

لا يحتوي PostgreSQL على عبارة OPEN صريحة للمؤشر؛ يعتبر المؤشر مفتوحًا عند تعريفه. استخدم عبارة DECLARE لتعريف مؤشر.

يمكنك رؤية جميع المؤشرات المتاحة عن طريق الاستعلام عن طريقة العرض النظامية pg_cursors.

إذا تم إغلاق مؤشر بعد نقطة حفظ تم التراجع عنها لاحقًا، فلا يتم التراجع عن CLOSE؛ أي، يظل المؤشر مغلقًا.

أمثلة

إغلاق المؤشر liahona:

CLOSE liahona;

التوافق

CLOSE متوافق تمامًا مع معيار SQL. CLOSE ALL هو امتداد لـ PostgreSQL.
