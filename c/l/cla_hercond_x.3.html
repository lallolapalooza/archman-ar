الوظائف/الروتينات الفرعية


real function cla_hercond_x (uplo, n, a, lda, af, ldaf, ipiv, x, info, work, rwork)
CLA_HERCOND_X يحسب معامل الشرط في المعيار اللانهائي لـ op(A)*diag(x) للمصفوفات الهرمية غير المحددة.

توثيق الوظيفة/الروتين الفرعي

real function cla_hercond_x (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex, dimension( * ) x, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_HERCOND_X يحسب معامل الشرط في المعيار اللانهائي لـ op(A)*diag(x) للمصفوفات الهرمية غير المحددة.

الغرض:

!>
!>    CLA_HERCOND_X يحسب معامل الشرط في المعيار اللانهائي لـ
!>    op(A) * diag(X) حيث X هو متجه COMPLEX.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>       = 'U':  يتم تخزين المثلث العلوي للمصفوفة A؛
!>       = 'L':  يتم تخزين المثلث السفلي للمصفوفة A.
!>

N

!>          N is INTEGER
!>     عدد معادلات النظام، أي رتبة المصفوفة A. N >= 0.
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>     عند الإدخال، المصفوفة A بحجم N*N.
!>

LDA

!>          LDA is INTEGER
!>     البعد الرائد للمصفوفة A. LDA >= max(1,N).
!>

AF

!>          AF is COMPLEX array, dimension (LDAF,N)
!>     المصفوفة القطرية الفرعية D والمعاملات المستخدمة للحصول على
!>     العامل U أو L كما تم حسابه بواسطة CHETRF.
!>

LDAF

!>          LDAF is INTEGER
!>     البعد الرائد للمصفوفة AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>     تفاصيل التبادلات والبنية الفرعية لـ D كما تم تحديدها بواسطة CHETRF.
!>

X

!>          X is COMPLEX array, dimension (N)
!>     المتجه X في الصيغة op(A) * diag(X).
!>

INFO

!>          INFO is INTEGER
!>       = 0:  انتهاء ناجح.
!>     i > 0:  المعلمة i غير صالحة.
!>

WORK

!>          WORK is COMPLEX array, dimension (2*N).
!>     مساحة عمل.
!>

RWORK

!>          RWORK is REAL array, dimension (N).
!>     مساحة عمل.
!>
