subroutine clarfg (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFG تولد عاكسًا أوليًا (مصفوفة هاوسهولدر).

الغرض:

!>
!> CLARFG تولد عاكسًا أوليًا مركبًا H من الرتبة n، بحيث
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> حيث alpha و beta قيمتان عدديتان، مع كون beta حقيقية، و x متجه
!> مركب من (n-1) عنصر. يتم تمثيل H بالشكل
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> حيث tau قيمة عددية مركبة و v متجه مركب من (n-1) عنصر. لاحظ أن H ليست هرميتية.
!>
!> إذا كانت جميع عناصر x صفرية و alpha حقيقية، فإن tau = 0
!> وتُعتبر H مصفوفة الوحدة.
!>
!> خلاف ذلك  1 <= real(tau) <= 2  و  abs(tau-1) <= 1 .
!>
