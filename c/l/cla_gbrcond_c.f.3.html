تابع حقيقي cla_gbrcond_c (trans, n, kl, ku, ab, ldab, afb, ldafb, ipiv, c, capply, info, work, rwork)
CLA_GBRCOND_C تحسب رقم شرط المعيار اللانهائي لـ op(A)*inv(diag(c)) للمصفوفات العادية ذات النطاق.

توثيق الوظيفة/الروتين الفرعي

تابع حقيقي cla_gbrcond_c (حرف trans, عدد صحيح n, عدد صحيح kl, عدد صحيح ku, مصفوفة مركبة، ذات بعد (ldab, * ) ab, عدد صحيح ldab, مصفوفة مركبة، ذات بعد (ldafb, * ) afb, عدد صحيح ldafb, مصفوفة أعداد صحيحة، ذات بعد ( * ) ipiv, مصفوفة أعداد حقيقية، ذات بعد ( * ) c, قيمة منطقية capply, عدد صحيح info, مصفوفة مركبة، ذات بعد ( * ) work, مصفوفة أعداد حقيقية، ذات بعد ( * ) rwork)

CLA_GBRCOND_C تحسب رقم شرط المعيار اللانهائي لـ op(A)*inv(diag(c)) للمصفوفات العادية ذات النطاق.

الغرض:

!>
!>    CLA_GBRCOND_C تحسب رقم شرط المعيار اللانهائي لـ
!>    op(A) * inv(diag(C)) حيث C هو متجه حقيقي.
!>

المعاملات

TRANS 
!>          TRANS هو حرف بطول 1
!>     يحدد شكل نظام المعادلات:
!>       = 'N':  A * X = B     (بدون تبديل)
!>       = 'T':  A**T * X = B  (تبديل)
!>       = 'C':  A**H * X = B  (تبديل مرافق = تبديل)
!>

N

!>          N هو عدد صحيح
!>     عدد المعادلات الخطية، أي رتبة
!>     المصفوفة A.  N >= 0.
!>

KL

!>          KL هو عدد صحيح
!>     عدد الأقطار الفرعية داخل نطاق A.  KL >= 0.
!>

KU

!>          KU هو عدد صحيح
!>     عدد الأقطار الفائقة داخل نطاق A.  KU >= 0.
!>

AB

!>          AB هي مصفوفة مركبة، ذات بعد (LDAB,N)
!>     عند الإدخال، المصفوفة A بتخزين النطاق، في الصفوف 1 إلى KL+KU+1.
!>     يتم تخزين العمود j للمصفوفة A في العمود j للمصفوفة
!>     AB كما يلي:
!>     AB(KU+1+i-j,j) = A(i,j) for max(1,j-KU)<=i<=min(N,j+kl)
!>

LDAB

!>          LDAB هو عدد صحيح
!>     البعد الرائد للمصفوفة AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB هي مصفوفة مركبة، ذات بعد (LDAFB,N)
!>     تفاصيل تحليل LU للمصفوفة ذات النطاق A، كما
!>     تم حسابها بواسطة CGBTRF.  U مخزنة كمصفوفة مثلثة عليا
!>     ذات نطاق مع KL+KU من الأقطار الفائقة في الصفوف 1 إلى KL+KU+1،
!>     والمضاعفات المستخدمة أثناء التحليل مخزنة
!>     في الصفوف KL+KU+2 إلى 2*KL+KU+1.
!>

LDAFB

!>          LDAFB هو عدد صحيح
!>     البعد الرائد للمصفوفة AFB.  LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV هي مصفوفة أعداد صحيحة، ذات بعد (N)
!>     فهارس المحور من تحليل A = P*L*U
!>     كما تم حسابها بواسطة CGBTRF؛ تم تبديل الصف i للمصفوفة
!>     مع الصف IPIV(i).
!>

C

!>          C هي مصفوفة أعداد حقيقية، ذات بعد (N)
!>     المتجه C في الصيغة op(A) * inv(diag(C)).
!>

CAPPLY

!>          CAPPLY هي قيمة منطقية
!>     إذا كانت .TRUE. فيمكن الوصول إلى المتجه C في الصيغة أعلاه.
!>

INFO

!>          INFO هو عدد صحيح
!>       = 0:  خروج ناجح.
!>     i > 0:  المعامل i غير صالح.
!>

WORK

!>          WORK هي مصفوفة مركبة، ذات بعد (2*N).
!>     مساحة عمل.
!>

RWORK

!>          RWORK هي مصفوفة أعداد حقيقية، ذات بعد (N).
!>     مساحة عمل.
!>
