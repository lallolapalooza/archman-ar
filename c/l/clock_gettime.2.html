NAME
clock_gettime - get time of specified clock
LIBRARY
Realtime library (librt, -lrt)
SYNOPSIS
#include <time.h>

int clock_gettime(clockid_t clk_id, struct timespec *tp);
DESCRIPTION
The clock_gettime() function shall return the value of the clock specified by clk_id broken out into seconds and nanoseconds, which are stored in the location pointed to by tp. The sources of time for the clocks are described in clock_getres(3). The clk_id argument is an identifier for a realtime clock. The following POSIX-defined clock IDs are supported: CLOCK_REALTIME System-wide real-time clock. This clock can be manipulated by userspace operations (e.g., clock_settime(3)) and its time can be set backward or forward by the system administrator. CLOCK_MONOTONIC A monotonic clock, meaning that it always moves forward. This clock is not affected by system time changes. It is typically used for measuring time intervals. CLOCK_PROCESS_CPUTIME_ID A clock that measures CPU time consumed by the calling process. CLOCK_THREAD_CPUTIME_ID A clock that measures CPU time consumed by the calling thread. The timespec structure is defined in <time.h> as: 
struct timespec {
            time_t tv_sec;        /* Seconds */
            long   tv_nsec;       /* Nanoseconds */
        };
The resolution of the clocks is determined by clock_getres(3). If tp is not NULL, the current value of the clock is stored in the timespec structure pointed to by tp. The field tp->tv_sec contains the number of seconds and tp->tv_nsec contains the number of nanoseconds. The clk_id values are of type clockid_t. A clockid_t value is a system-wide identifier for a clock. The system guarantees that the following values are defined for clockid_t: CLOCK_REALTIME, CLOCK_MONOTONIC, CLOCK_PROCESS_CPUTIME_ID, and CLOCK_THREAD_CPUTIME_ID. Further POSIX-defined clockid_t values include: CLOCK_MONOTONIC_RAW Similar to CLOCK_MONOTONIC, but without any prioritization and without adjustment from NTP. CLOCK_BOOTTIME Like CLOCK_MONOTONIC, this clock is a monotonic clock. However, it also includes time elapsed during system suspend. This clock helps measure the time since the system was booted. The system may support additional implementation-defined clock IDs. These are typically named like CLOCK_.... For example, Linux supports CLOCK_HYPERV_PERF on Hyper-V virtualized systems. The CLOCK_PROCESS_CPUTIME_ID and CLOCK_THREAD_CPUTIME_ID clocks are per-process and per-thread clocks, respectively. They measure the CPU time that has been used by the process or thread. The CPU time is the sum of the system and user time used respectively by the process or thread. The CLOCK_REALTIME clock represents the system's wall clock time. It can be adjusted by administrators or NTP. The CLOCK_MONOTONIC clock is a clock that always moves forward. It is not affected by system time changes. It is typically used for measuring time intervals. The CLOCK_MONOTONIC_RAW clock is similar to CLOCK_MONOTONIC but it is not subject to NTP adjustments. It is useful for measuring real time intervals where clock drift is not desired. The CLOCK_BOOTTIME clock is similar to CLOCK_MONOTONIC but it also includes time elapsed during suspend periods. It is useful for measuring the time since system boot. The CLOCK_PROCESS_CPUTIME_ID and CLOCK_THREAD_CPUTIME_ID clocks are for measuring CPU usage. They are not affected by wall clock adjustments.
RETURN VALUE
On success, clock_gettime() shall return 0. On failure, it shall return -1 and set errno to indicate the error.
ERRORS
EINVAL The value of clk_id is not recognized.

VERSIONS
The clock_gettime() function first appeared in POSIX.1b extensions.
STANDARDS
The clock_gettime() function is defined by the POSIX.1-2001 and later standards.
HISTORY
The clock_gettime() function was introduced in POSIX.1b.
EXAMPLES
The following example demonstrates how to use clock_gettime() to measure the execution time of a piece of code: 
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main() {
    struct timespec start, end;
    double elapsed;

    // Record start time
    if (clock_gettime(CLOCK_MONOTONIC, &start) == -1) {
        perror("clock_gettime");
        exit(EXIT_FAILURE);
    }

    // Code to measure
    // ... (your code here) ...
    for (long long i = 0; i < 1000000000; ++i) {
        // Busy loop to simulate work
    }

    // Record end time
    if (clock_gettime(CLOCK_MONOTONIC, &end) == -1) {
        perror("clock_gettime");
        exit(EXIT_FAILURE);
    }

    // Calculate elapsed time in seconds
    elapsed = (end.tv_sec - start.tv_sec) + (end.tv_nsec - start.tv_nsec) / 1e9;

    printf("Elapsed time: %.9f seconds\n", elapsed);

    return 0;
}
