subroutine claic1 (integer job, integer j, complex, dimension( j ) x, real sest, complex, dimension( j ) w, complex gamma, real sestpr, complex s, complex c)

CLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي.

الغرض:

!>
!> CLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي في
!> أبسط نسخه:
!>
!> لتكن x، twonorm(x) = 1، متجهًا منفردًا تقريبيًا لمصفوفة مثلثية سفلية j-by-j L، بحيث
!>          twonorm(L*x) = sest
!> عندها تحسب CLAIC1 sestpr، s، c بحيث
!> المتجه
!>                 [ s*x ]
!>          xhat = [  c  ]
!> هو متجه منفرد تقريبي للمصفوفة
!>                 [ L      0  ]
!>          Lhat = [ w**H gamma ]
!> بمعنى أن
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> اعتمادًا على JOB، يتم حساب تقدير للقيمة المنفردة الأكبر أو الأصغر.
!>
!> لاحظ أن [s c]**H و sestpr**2 هو زوج من القيم الذاتية للنظام
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> حيث alpha =  x**H*w.
!>
