real function clantb (norm, uplo, diag, n, k, ab, ldab, work)
CLANTB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة شريطية مثلثية.

وثائق الوظيفة/الروتين الفرعي

real function clantb (character norm, character uplo, character diag, integer n, integer k, complex, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) work)

CLANTB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة شريطية مثلثية.

الغرض:

!>
!> CLANTB  تُرجع قيمة المعيار الواحد،  أو معيار فروبينيوس، أو
!> المعيار اللانهائي،  أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> مثلثية شريطية A بحجم n × n،  تحتوي على ( k + 1 ) أقطار.
!>

تُرجع

CLANTB 
!>
!>    CLANTB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى  المعيار الواحد لمصفوفة (أكبر مجموع أعمدة)،
!> normI  يشير إلى  المعيار اللانهائي  لمصفوفة (أكبر مجموع صفوف) و
!> normF  يشير إلى  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابتًا.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي يجب إرجاعها في CLANTB كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A علوية أو سفلية مثلثة.
!>          = 'U':  مثلثية علوية
!>          = 'L':  مثلثية سفلية
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A وحدية مثلثة أم لا.
!>          = 'N':  غير وحدية مثلثة
!>          = 'U':  وحدية مثلثة
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANTB
!>          إلى صفر.
!>

K

!>          K is INTEGER
!>          عدد الأقطار الفائقة للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفرعية للمصفوفة A إذا كان UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB is COMPLEX array, dimension (LDAB,N)
!>          المصفوفة الشريطية المثلثية العلوية أو السفلية A، مخزنة في
!>          أول k+1 صفوف من AB.  يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(k+1+i-j,j) = A(i,j) لـ max(1,j-k)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)   = A(i,j) لـ j<=i<=min(n,j+k).
!>          لاحظ أنه عندما يكون DIAG = 'U'، فإن العناصر في المصفوفة AB
!>          المقابلة للعناصر القطرية للمصفوفة A
!>          لا يتم الرجوع إليها، ولكن يُفترض أنها واحد.
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= K+1.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I'؛ خلاف ذلك، لا يتم
!>          الرجوع إلى WORK.
!>
