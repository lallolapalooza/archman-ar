توثيق الوظيفة/الإجراء الفرعي

subroutine clacon (integer n, complex, dimension( n ) v, complex, dimension( n ) x, real est, integer kase)

CLACON تقدر قيمة المعيار 1 لمصفوفة مربعة معقدة، باستخدام الاتصال العكسي لتقييم نواتج ضرب المصفوفة في متجه.

الغرض

!>
!> CLACON تقدر قيمة المعيار 1 لمصفوفة مربعة معقدة A.
!> يستخدم الاتصال العكسي لتقييم نواتج ضرب المصفوفة في متجه.
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>         رتبة المصفوفة.  N >= 1.
!>

V

!>          V هو مصفوفة أعداد معقدة (COMPLEX)، بُعدها (N)
!>         عند العودة النهائية، V = A*W، حيث EST = norm(V)/norm(W)
!>         (W لا يتم إرجاعها).
!>

X

!>          X هو مصفوفة أعداد معقدة (COMPLEX)، بُعدها (N)
!>         عند العودة الوسيطة، يجب استبدال X بـ
!>               A * X،   إذا كان KASE=1،
!>               A**H * X،  إذا كان KASE=2،
!>         حيث A**H هي المرافق المنقول لـ A، ويجب إعادة استدعاء CLACON
!>         مع بقاء جميع المعاملات الأخرى دون تغيير.
!>

EST

!>          EST هو عدد حقيقي (REAL)
!>         عند الدخول مع KASE = 1 أو 2 و JUMP = 3، يجب أن يكون EST
!>         دون تغيير من الاستدعاء السابق لـ CLACON.
!>         عند الخروج، EST هو تقدير (حد أدنى) لـ norm(A).
!>

KASE

!>          KASE هو عدد صحيح (INTEGER)
!>         عند الاستدعاء الأولي لـ CLACON، يجب أن يكون KASE = 0.
!>         عند العودة الوسيطة، سيكون KASE = 1 أو 2، مما يشير
!>         إلى ما إذا كان يجب استبدال X بـ A * X  أو A**H * X.
!>         عند العودة النهائية من CLACON، سيكون KASE = 0 مرة أخرى.
!>
