real function cla_porcond_x (uplo, n, a, lda, af, ldaf, x, info, work, rwork)
CLA_PORCOND_X يحسب رقم الشرط اللانهائي للمعيار op(A)*diag(x) للمصفوفات الهرمية الموجبة المحددة.

توثيق الوظيفة/الروتين الفرعي

real function cla_porcond_x (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, complex, dimension( * ) x, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_PORCOND_X يحسب رقم الشرط اللانهائي للمعيار op(A)*diag(x) للمصفوفات الهرمية الموجبة المحددة.

الغرض:

!>
!>    CLA_PORCOND_X يحسب رقم الشرط اللانهائي لـ
!>    op(A) * diag(X) حيث X هو متجه معقد.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>       = 'U':  يتم تخزين المثلث العلوي من A؛
!>       = 'L':  يتم تخزين المثلث السفلي من A.
!>

N

!>          N هو INTEGER
!>     عدد المعادلات الخطية، أي، ترتيب المصفوفة
!>     A.  N >= 0.
!>

A

!>          A هو مصفوفة COMPLEX، حجم (LDA,N)
!>     عند الإدخال، المصفوفة A ذات الحجم N-by-N.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة COMPLEX، حجم (LDAF,N)
!>     العامل المثلثي U أو L من تحليل Cholesky
!>     A = U**H*U أو A = L*L**H، كما تم حسابه بواسطة CPOTRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرئيسي للمصفوفة AF.  LDAF >= max(1,N).
!>

X

!>          X هو مصفوفة COMPLEX، حجم (N)
!>     المتجه X في الصيغة op(A) * diag(X).
!>

INFO

!>          INFO هو INTEGER
!>       = 0:  انتهاء ناجح.
!>     i > 0:  المعلمة i غير صالحة.
!>

WORK

!>          WORK هي مصفوفة COMPLEX، حجم (2*N).
!>     مساحة عمل.
!>

RWORK

!>          RWORK هي مصفوفة REAL، حجم (N).
!>     مساحة عمل.
!>
