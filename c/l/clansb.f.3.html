الوظائف/الروتينات الفرعية


real function clansb (norm, uplo, n, k, ab, ldab, work)
CLANSB ترجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة نطاق متماثل.

توثيق الوظيفة/الروتين الفرعي

real function clansb (character norm, character uplo, integer n, integer k, complex, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) work)

CLANSB ترجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة نطاق متماثل.

الغرض:

!>
!> CLANSB  ترجع قيمة المعيار واحد،  أو معيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> نطاق متماثل A بحجم n × n،  مع k قطر فائق.
!>

العودة

CLANSB 
!>
!>    CLANSB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على  المعيار واحد لمصفوفة (مجموع العمود الأقصى)،
!> normI  يدل على  المعيار اللانهائي  لمصفوفة (مجموع الصف الأقصى) و
!> normF  يدل على  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابت.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANSB كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي المثلثي لمصفوفة النطاق A
!>          مقدمًا.
!>          = 'U':  الجزء العلوي المثلثي مقدم
!>          = 'L':  الجزء السفلي المثلثي مقدم
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANSB
!>          إلى صفر.
!>

K

!>          K is INTEGER
!>          عدد الأقطار الفائقة أو الأقطار الفرعية لمصفوفة النطاق A.  K >= 0.
!>

AB

!>          AB is COMPLEX array, dimension (LDAB,N)
!>          الجزء العلوي أو السفلي المثلثي لمصفوفة النطاق المتماثل A،
!>          مخزن في أول K+1 صفوف من AB.  يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(k+1+i-j,j) = A(i,j) لـ max(1,j-k)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)   = A(i,j) لـ j<=i<=min(n,j+k).
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الأمامي للمصفوفة AB.  LDAB >= K+1.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I' or '1' or 'O'; خلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
