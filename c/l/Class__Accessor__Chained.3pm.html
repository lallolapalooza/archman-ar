Class__Accessor__Chained(3pm)

الحزمة: perl-class-accessor-chained

التراخيص: GPL, PerlArtistic

Class::Accessor::Chained(3) توثيق Perl المساهم به من قبل المستخدم Class::Accessor::Chained(3)

الاسم

Class::Accessor::Chained - إنشاء مُلحقات متسلسلة

ملخص

package Foo;
use base qw( Class::Accessor::Chained );
__PACKAGE__->mk_accessors(qw( foo bar baz ));
my $foo = Foo->new->foo(1)->bar(2)->baz(4);
print $foo->bar; # يطبع 2

الوصف

الملحق المتسلسل هو ملحق يعيد دائمًا الكائن عند استدعائه بمعاملات (للتعيين)، وقيمة الحقل عند استدعائه بدون حجج.

هذه الوحدة ترث من Class::Accessor لتوفير نفس واجهة mk_accessors.
