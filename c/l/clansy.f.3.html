real function clansy (norm, uplo, n, a, lda, work)
CLANSY ترجع قيمة النورم 1، أو نورم فروبينيوس، أو نورم اللانهاية، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة معقدة متماثلة.

توثيق الوظيفة/الإجراء الفرعي

real function clansy (character norm, character uplo, integer n, complex, dimension( lda, * ) a, integer lda, real, dimension( * ) work)

CLANSY ترجع قيمة النورم 1، أو نورم فروبينيوس، أو نورم اللانهاية، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة معقدة متماثلة.

الغرض:

!>
!> CLANSY  ترجع قيمة النورم الواحد،  أو نورم فروبينيوس، أو
!> نورم اللانهاية،  أو  العنصر ذو القيمة المطلقة الأكبر لمصفوفة
!> معقدة متماثلة A.
!>

الإرجاع

CLANSY 
!>
!>    CLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تمثل النورم الواحد لمصفوفة (أقصى مجموع عمودي)،
!> normI  تمثل نورم اللانهاية  لمصفوفة (أقصى مجموع صفي) و
!> normF  تمثل نورم فروبينيوس للمصفوفة (الجذر التربيعي لمجموع المربعات).
!> لاحظ أن  max(abs(A(i,j)))  ليس نورم مصفوفة متناسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          تحدد القيمة التي سيتم إرجاعها في CLANSY كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          تحدد ما إذا كان سيتم الرجوع إلى الجزء العلوي أو السفلي المثلثي
!>          للمصفوفة المتماثلة A.
!>          = 'U':  يتم الرجوع إلى الجزء العلوي المثلثي من A
!>          = 'L':  يتم الرجوع إلى الجزء السفلي المثلثي من A
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANSY
!>          إلى صفر.
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>          المصفوفة المتماثلة A.  إذا كان UPLO = 'U'، فإن الجزء العلوي
!>          المثلثي الرائد الذي حجمه n × n من A يحتوي على الجزء العلوي
!>          المثلثي للمصفوفة A، ولا يتم الرجوع إلى الجزء السفلي المثلثي
!>          الصارم من A.  إذا كان UPLO = 'L'، فإن الجزء السفلي المثلثي
!>          الرائد الذي حجمه n × n من A يحتوي على الجزء السفلي المثلثي
!>          للمصفوفة A، ولا يتم الرجوع إلى الجزء العلوي المثلثي الصارم
!>          من A.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'. بخلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
