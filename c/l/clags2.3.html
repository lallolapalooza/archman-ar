subroutine clags2 (logical upper, real a1, complex a2, real a3, real b1, complex b2, real b3, real csu, complex snu, real csv, complex snv, real csq, complex snq)

CLAGS2

الغرض:

!>
!> CLAGS2 تحسب مصفوفات وحدوية 2x2 U، V و Q، بحيث إذا ( UPPER ) كان
!>
!>           U**H *A*Q = U**H *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> و
!>           V**H*B*Q = V**H *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> أو إذا ( .NOT.UPPER ) كان
!>
!>           U**H *A*Q = U**H *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> و
!>           V**H *B*Q = V**H *( B1 0  )*Q = ( x  x  )
!>                             ( B2 B3 )     ( 0  x  )
!> حيث
!>
!>   U = (   CSU    SNU ), V = (  CSV    SNV ),
!>       ( -SNU**H  CSU )      ( -SNV**H CSV )
!>
!>   Q = (   CSQ    SNQ )
!>       ( -SNQ**H  CSQ )
!>
!> صفوف A و B المحولة متوازية. علاوة على ذلك، إذا كانت المصفوفة A المدخلة 2x2 ليست صفرية،
!> فإن العنصر (1,1) المحول للمصفوفة A ليس صفرياً. إذا كانت المصفوفتان A و B المدخلتان
!> ليستا صفريتين، فإن العنصر (2,2) المحول للمصفوفة B ليس صفرياً، إلا عندما تكون
!> الصفوف الأولى للمدخلتين A و B متوازية والصفوف الثانية صفرية.
!>
