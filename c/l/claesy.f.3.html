توثيق الوظائف/الإجراءات الفرعية

subroutine claesy (complex a, complex b, complex c, complex rt1, complex rt2, complex evscal, complex cs1, complex sn1)

CLAESY تحسب القيم الذاتية والمتجهات الذاتية لمصفوفة معقدة متناظرة بحجم 2x2.

الغرض:

!>
!> CLAESY تحسب التحلل الذاتي لمصفوفة متناظرة بحجم 2x2
!>    ( ( A, B );( B, C ) )
!> بشرط أن يكون معيار مصفوفة المتجهات الذاتية أكبر من
!> قيمة عتبة معينة.
!>
!> RT1 هي القيمة الذاتية ذات القيمة المطلقة الأكبر، و RT2 ذات
!> القيمة المطلقة الأصغر. إذا تم حساب المتجهات الذاتية، فعند
!> العودة يكون ( CS1, SN1 ) هو المتجه الذاتي الموحد لـ RT1، لذا
!>
!> [  CS1     SN1   ] . [ A  B ] . [ CS1    -SN1   ] = [ RT1  0  ]
!> [ -SN1     CS1   ]   [ B  C ]   [ SN1     CS1   ]   [  0  RT2 ]
!>

المعلمات

A 
!>          A هو COMPLEX
!>          العنصر ( 1, 1 ) للمصفوفة المدخلة.
!>

B

!>          B هو COMPLEX
!>          العنصر ( 1, 2 ) للمصفوفة المدخلة. العنصر ( 2, 1 )
!>          معطى أيضًا بواسطة B، نظرًا لأن المصفوفة 2x2 متناظرة.
!>

C

!>          C هو COMPLEX
!>          العنصر ( 2, 2 ) للمصفوفة المدخلة.
!>

RT1

!>          RT1 هو COMPLEX
!>          القيمة الذاتية ذات القيمة المطلقة الأكبر.
!>

RT2

!>          RT2 هو COMPLEX
!>          القيمة الذاتية ذات القيمة المطلقة الأصغر.
!>

EVSCAL

!>          EVSCAL هو COMPLEX
!>          القيمة المعقدة التي تم بها قياس مصفوفة المتجهات الذاتية
!>          لجعلها متعامدة. إذا كان EVSCAL صفرًا، فلم يتم حساب
!>          المتجهات الذاتية. هذا يعني شيئًا واحدًا من اثنين: إما أنه
!>          لا يمكن قطريّة المصفوفة 2x2، أو أن معيار مصفوفة
!>          المتجهات الذاتية قبل القياس كان أكبر من قيمة العتبة
!>          THRESH (المحددة أدناه).
!>

CS1

!>          CS1 هو COMPLEX
!>

SN1

!>          SN1 هو COMPLEX
!>          إذا كان EVSCAL .NE. 0، فإن ( CS1, SN1 ) هو المتجه الذاتي
!>          الأيمن الموحد لـ RT1.
!>
