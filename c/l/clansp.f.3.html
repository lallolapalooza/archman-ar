real function clansp (norm, uplo, n, ap, work)
CLANSP تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة يتم توفيرها بصيغة مجمعة.

وثائق الوظيفة/الإجراء الفرعي

real function clansp (character norm, character uplo, integer n, complex, dimension( * ) ap, real, dimension( * ) work)

CLANSP تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة مركبة A، يتم توفيرها بصيغة مجمعة.

الغرض:

!>
!> CLANSP  تُرجع قيمة المعيار واحد، أو معيار فروبنيوس، أو
!> المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة مركبة متماثلة A،
!> يتم توفيرها بصيغة مجمعة.
!>

تُرجع

CLANSP 
!>
!>    CLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تشير إلى المعيار 1 للمصفوفة (أكبر مجموع أعمدة)،
!> normI  تشير إلى المعيار اللانهائي للمصفوفة (أكبر مجموع صفوف)،
!> normF  تشير إلى معيار فروبنيوس للمصفوفة (الجذر التربيعي لمجموع المربعات).
!> لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANSP كما هو موضح أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي من الجزء المثلثي للمصفوفة
!>          المتماثلة A يتم توفيره.
!>          = 'U':  يتم توفير الجزء العلوي من A
!>          = 'L':  يتم توفير الجزء السفلي من A
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANSP إلى صفر.
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          الجزء العلوي أو السفلي المثلثي للمصفوفة المتماثلة A، مجمعة
!>          حسب العمود في مصفوفة خطية.  يتم تخزين العمود j من A
!>          في المصفوفة AP على النحو التالي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I' أو '1' أو 'O'؛ بخلاف ذلك،
!>          لا يتم الإشارة إلى WORK.
!>
