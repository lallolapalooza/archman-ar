حقيقي الوظيفة clanhs (المعيار، n، a، lda، work)
CLANHS تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة هسنبرغ علوية.

وثائق الوظيفة/الروتين الفرعي

الوظيفة الحقيقية clanhs (المعيار الحرفي، العدد الصحيح n، المعقد، البعد (lda، *) a، العدد الصحيح lda، الحقيقي، البعد (*) work)

CLANHS تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة هسنبرغ علوية.

الغرض:

!>
!> CLANHS  تُرجع قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> معيار اللانهاية، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هسنبرغ A.
!>

الإرجاع

CLANHS 
!>
!>    CLANHS = ( max(abs(A(i,j))) ، NORM = 'M' أو 'm'
!>             (
!>             ( norm1(A)،         NORM = '1' أو 'O' أو 'o'
!>             (
!>             ( normI(A)،         NORM = 'I' أو 'i'
!>             (
!>             ( normF(A)،         NORM = 'F' أو 'f' أو 'E' أو 'e'
!>
!> حيث  norm1  يشير إلى المعيار واحد للمصفوفة (أقصى مجموع أعمدة)،
!> normI  يشير إلى معيار اللانهاية للمصفوفة (أقصى مجموع صفوف) و
!> normF  يشير إلى معيار فروبينيوس للمصفوفة (الجذر التربيعي لمجموع المربعات).
!> لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متناسق.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة المراد إرجاعها في CLANHS كما هو موضح
!>          أعلاه.
!>

N

!>          N هو INTEGER
!>          مرتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANHS
!>          إلى الصفر.
!>

A

!>          A هي مصفوفة COMPLEX ، البعد (LDA,N)
!>          مصفوفة هسنبرغ العلوية n × n A؛ الجزء السفلي من A دون القطر الفرعي الأول غير مستخدم.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK هي مصفوفة REAL ، البعد (MAX(1,LWORK))،
!>          حيث LWORK >= N عندما NORM = 'I'؛ بخلاف ذلك، لا يتم استخدام WORK.
!>
