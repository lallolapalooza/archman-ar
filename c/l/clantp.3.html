real function clantp (norm, uplo, diag, n, ap, work)
CLANTP تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة مثلثية مقدمة في شكل مضغوط.

وثائق الوظيفة/الروتين الفرعي

real function clantp (character norm, character uplo, character diag, integer n, complex, dimension( * ) ap, real, dimension( * ) work)

CLANTP تُرجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة مثلثية مقدمة في شكل مضغوط.

الغرض:

!>
!> CLANTP  تُرجع قيمة المعيار واحد،  أو معيار فروبنيوس،  أو المعيار
!> اللانهائي،  أو  العنصر ذي القيمة المطلقة الأكبر لمصفوفة مثلثية A، مقدمة
!> في شكل مضغوط.
!>

تُرجع

CLANTP 
!>
!>    CLANTP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى المعيار واحد للمصفوفة (أكبر مجموع أعمدة)،
!> normI  يشير إلى المعيار اللانهائي  للمصفوفة (أكبر مجموع صفوف) و
!> normF  يشير إلى معيار فروبنيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابت.
!>

المعلمات:

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANTP كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية عليا أو سفلى.
!>          = 'U':  مثلثية عليا
!>          = 'L':  مثلثية سفلى
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية وحدوية أم لا.
!>          = 'N':  غير وحدوية
!>          = 'U':  وحدوية
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANTP
!>          إلى صفر.
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          المصفوفة المثلثية العليا أو السفلى A، مضغوطة حسب العمود في
!>          مصفوفة خطية.  يتم تخزين العمود j من A في المصفوفة
!>          AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>          لاحظ أنه عندما يكون DIAG = 'U'، فإن عناصر المصفوفة AP
!>          المقابلة للعناصر القطرية للمصفوفة A
!>          لا يتم الرجوع إليها، ولكن يفترض أنها واحد.
!>

WORK

!>          WORK is REAL array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I'. بخلاف ذلك، لا يتم
!>          الرجوع إلى WORK.
!>
