الوظائف/الروتينات الفرعية


real function cla_porcond_x (uplo, n, a, lda, af, ldaf, x, info, work, rwork)
CLA_PORCOND_X يحسب عدد الشرط للمتجه اللانهائي للمصفوفة op(A)*diag(x) للمصفوفات المتشابهة الهرمية الموجبة المحددة.

توثيق الوظيفة/الروتين الفرعي

real function cla_porcond_x (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, complex, dimension( * ) x, integer info, complex, dimension( * ) work, real, dimension( * ) rwork)

CLA_PORCOND_X يحسب عدد الشرط للمتجه اللانهائي للمصفوفة op(A)*diag(x) للمصفوفات المتشابهة الهرمية الموجبة المحددة.

الغرض:

!>
!>    CLA_PORCOND_X يحسب عدد الشرط للمتجه اللانهائي لـ
!>    op(A) * diag(X) حيث X هو متجه COMPLEX.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>       = 'U':  يتم تخزين المثلث العلوي من A؛
!>       = 'L':  يتم تخزين المثلث السفلي من A.
!>

N

!>          N is INTEGER
!>     عدد معادلات الخطية، أي ترتيب
!>     المصفوفة A.  N >= 0.
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>     عند الإدخال، المصفوفة A ذات الأبعاد N-by-N.
!>

LDA

!>          LDA is INTEGER
!>     البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF is COMPLEX array, dimension (LDAF,N)
!>     العامل المثلثي U أو L من تحليل Cholesky
!>     A = U**H*U أو A = L*L**H، كما تم حسابه بواسطة CPOTRF.
!>

LDAF

!>          LDAF is INTEGER
!>     البعد الرائد للمصفوفة AF.  LDAF >= max(1,N).
!>

X

!>          X is COMPLEX array, dimension (N)
!>     المتجه X في الصيغة op(A) * diag(X).
!>

INFO

!>          INFO is INTEGER
!>       = 0:  انتهاء ناجح.
!>     i > 0:  المعامل i غير صالح.
!>

WORK

!>          WORK is COMPLEX array, dimension (2*N).
!>     مساحة عمل.
!>

RWORK

!>          RWORK is REAL array, dimension (N).
!>     مساحة عمل.
!>
