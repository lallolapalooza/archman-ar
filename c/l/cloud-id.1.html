CLOUD-ID(1) دليل الأوامر العامة CLOUD-ID(1)

الاسم

cloud-id - الإبلاغ عن معرف السحابة القياسي لهذه المثيل

الملخص

cloud-id [-h] [-j] [-l] [-i <بيانات_المثيل>]

الوصف

cloud-id هو الاسم بأحرف صغيرة لمصدر بيانات السحابة المكتشف.

سيكون معرف السحابة 'لم يتم التشغيل' عندما لم يتم تشغيل مولد systemd بعد. سيكون معرف السحابة 'معطل' عندما يكون cloud-init معطلاً أو عندما لم يكتشف ds-identify مصدر بيانات صالح.

راجع cloud-init status --long لمزيد من المعلومات.

الخيارات

-h, --help
عرض رسالة المساعدة والخروج
-j, --json
الإبلاغ عن جميع معلومات معرف السحابة القياسية بصيغة json
-l, --long
الإبلاغ عن معلومات معرف السحابة الموسعة كسلسلة نصية مفصولة بعلامات جدولة
-i <data>, --instance-data <data>
المسار إلى ملف instance-data.json. الافتراضي هو /run/cloud-init/instance-data.json

حالة الخروج

0
عند النجاح
1
بسبب خطأ
2
بسبب تعطيل cloud-init. انظر: cloud-init status --long
3
لم يتم تشغيل مولد cloud-init واكتشافه بعد.
