NAME

clamd.conf - Configuration file for Clam AntiVirus Daemon

DESCRIPTION

clamd.conf configures the Clam AntiVirus daemon, clamd(8).

FILE FORMAT

The file consists of comments and options with arguments. Each line which starts with a hash (#) symbol is ignored by the parser. Options and arguments are case sensitive and of the form Option Argument. The arguments are of the following types:

BOOL
Boolean value (yes/no or true/false or 1/0).
STRING
String without blank characters.
SIZE
Size in bytes. You can use 'M' or 'm' modifiers for megabytes and 'K' or 'k' for kilobytes. To specify the size in bytes just don't use modifiers.
NUMBER
Unsigned integer.

DIRECTIVES

When some option is not used (commented out or not included in the configuration file at all) clamd takes a default action.

Example
If this option is set clamd will not run.
LogFile STRING
Save all reports to a log file.
Default: disabled
LogFileUnlock BOOL
By default the log file is locked for writing and only a single daemon process can write to it. This option disables the lock.
Default: no
LogFileMaxSize SIZE
Maximum size of the log file.
Value of 0 disables the limit.
Default: 1048576
LogTime BOOL
Log time for each message.
Default: no
LogClean BOOL
Log all clean files.
Useful in debugging but drastically increases the log size.
Default: no
LogSyslog BOOL
Use the system logger (can work together with LogFile).
Default: no
LogFacility STRING
Type of syslog messages
Please refer to 'man syslog' for facility names.
Default: LOG_LOCAL6
LogVerbose BOOL
Enable verbose logging.
Default: no
LogRotate BOOL
Rotate log file. Requires LogFileMaxSize option set prior to this option.
Default: no
ExtendedDetectionInfo BOOL
Log additional information about the infected file, such as its size and hash, together with the virus name.
Default: no
PidFile STRING
Write the daemon's pid to the specified file.
Default: disabled
TemporaryDirectory STRING
This option allows you to change the default temporary directory.
Default: system specific (usually /tmp or /var/tmp).
DatabaseDirectory STRING
This option allows you to change the default database directory. If you enable it, please make sure it points to the same directory in both clamd and freshclam.
Default: defined at configuration (/usr/local/share/clamav)
CVDCertsDirectory STRING
Path to a directory containing ClamAV CA certificate files used to verify signed database archives (e.g. CVD files). This directory must already exist, be an absolute path, be readable by freshclam, clamd, clamscan, and sigtool.
Default: /etc/clamav/certs
FIPSCryptoHashLimits BOOL
Enforce FIPS-like limits on using hash algorithms for cryptographic purposes. Will disable MD5 & SHA1 FP sigs and will require '.sign' files to verify CVD authenticity.
Default: no
OfficialDatabaseOnly BOOL
Only load the official signatures published by the ClamAV project.
Default: no
FailIfCvdOlderThan NUMBER
Return with a nonzero error code if the virus database is older than the specified number of days.
Default: -1
LocalSocket STRING
Path to a local (Unix) socket the daemon will listen on.
Default: disabled
LocalSocketGroup STRING
Sets the group ownership on the unix socket.
Default: the primary group of the user running clamd
LocalSocketMode STRING
Sets the permissions on the unix socket to the specified mode.
Default: socket is world readable and writable
FixStaleSocket BOOL
Remove stale socket after unclean shutdown.
Default: yes
TCPSocket NUMBER
TCP port number the daemon will listen on.
Default: disabled
TCPAddr STRING
By default clamd binds to INADDR_ANY.
This option allows you to restrict the TCP address and provide some degree of protection from the outside world. This option can be specified multiple times in order to listen on multiple IPs. IPv6 is now supported.
Default: disabled
EnableShutdownCommand BOOL
Enables the SHUTDOWN command. Setting this to no prevents a client to stop clamd via the protocol.
When disabled, clamd responds to this command with COMMAND UNAVAILABLE.
Default: yes
EnableReloadCommand BOOL
Enables the RELOAD command. Setting this to no prevents a client to reload the database.
When disabled, clamd responds to this command with COMMAND UNAVAILABLE.
Default: yes
EnableVersionCommand BOOL
Enables the VERSION command. Setting this to no prevents a client from querying version information.
When disabled, clamd responds to this command with COMMAND UNAVAILABLE.
Default: yes
EnableStatsCommand BOOL
Enables the STATS command. Setting this to no prevents a client from querying statistics.
When disabled, clamd responds to this command with COMMAND UNAVAILABLE.
Default: yes
MaxConnectionQueueLength NUMBER
Maximum length the queue of pending connections may grow to.
Default: 200
StreamMaxLength SIZE
Close the STREAM session when the data size limit is exceeded.
The value should match your MTA's limit for the maximum attachment size.
Default: 100M
StreamMinPort NUMBER
The STREAM command uses an FTP-like protocol.
This option sets the lower boundary for the port range.
Default: 1024
StreamMaxPort NUMBER
The STREAM command uses an FTP-like protocol.
This option sets the upper boundary for the port range.
Default: 1024
MaxQueuePerUser NUMBER
Maximum queue length per user.
Default: 100
MaxFilesystemRecursion NUMBER
Maximum filesystem recursion depth.
Default: 100
MaxRecursion NUMBER
Maximum archive recursion depth.
Default: 100
MaxParsingLimits NUMBER
Maximum number of parsing instructions.
Default: 10000
MaxScanSize SIZE
Maximum file size to scan.
Default: 100M
MaxEmbeddedPE SIZE
Maximum size of embedded Portable Executable files.
Default: 50M
MaxHTMLNormalize SIZE
Maximum size of HTML file to normalize.
Default: 10M
MaxHTMLNoTagsImage SIZE
Maximum size of image to embed in HTML.
Default: 5M
MaxScriptrenzia SIZE
Maximum script size to be recognized.
Default: 500K
MaxZipContentScale SIZE
Maximum zip content scale.
Default: 1000
MaxPartitions NUMBER
Maximum number of partitions to scan.
Default: 50
MaxIconsScanSize SIZE
Maximum size of icon to scan.
Default: 1M
DetectBrokenEncryptedArchive BOOL
Detect broken encrypted archives.
Default: no
ScanPDFOnlyEncrypted BOOL
Scan only encrypted PDF files.
Default: no
ScanSWF BOOL
Scan SWF files.
Default: yes
ScanArchive BOOL
Scan archive files.
Default: yes
ScanOLE2 BOOL
Scan OLE2 archives (e.g. Microsoft Office documents).
Default: yes
ScanMail BOOL
Scan Mail files.
Default: yes
ScanMIME BOOL
Scan MIME files.
Default: yes
ScanRtf BOOL
Scan RTF files.
Default: yes
ScanHtml BOOL
Scan HTML files.
Default: yes
ScanDoc BOOL
Scan Document files.
Default: yes
ScanMsOfficeGroken BOOL
Scan broken Microsoft Office documents.
Default: yes
ScanCompressedSizeLimit SIZE
This option specifies the maximum size of compressed data that ClamAV will decompress.
Default: 128M
MaxScanFileCount NUMBER
Maximum number of files to scan.
Default: 10000
MaxContainersScanCount NUMBER
Maximum number of containers to scan.
Default: 10000
MaxContainersFileSize SIZE
Maximum size of containers to scan.
Default: 2G
ArchiveMaxArchiveNotify NUMBER
Maximum number of archives to notify.
Default: 1000
ArchiveMaxArchiveRecursion NUMBER
Maximum archive recursion depth.
Default: 100
ArchiveMaxZipNotify NUMBER
Maximum number of zip archives to notify.
Default: 1000
ArchiveMaxZipRecursion NUMBER
Maximum zip archive recursion depth.
Default: 100
ArchiveMaxRarNotify NUMBER
Maximum number of rar archives to notify.
Default: 1000
ArchiveMaxRarRecursion NUMBER
Maximum rar archive recursion depth.
Default: 100
ArchiveMaxTarNotify NUMBER
Maximum number of tar archives to notify.
Default: 1000
ArchiveMaxTarRecursion NUMBER
Maximum tar archive recursion depth.
Default: 100
ArchiveMaxArNotify NUMBER
Maximum number of ar archives to notify.
Default: 1000
ArchiveMaxArRecursion NUMBER
Maximum ar archive recursion depth.
Default: 100
ArchiveMaxMboxNotify NUMBER
Maximum number of mbox archives to notify.
Default: 1000
ArchiveMaxMboxRecursion NUMBER
Maximum mbox archive recursion depth.
Default: 100
ArchiveMaxEmlNotify NUMBER
Maximum number of eml archives to notify.
Default: 1000
ArchiveMaxEmlRecursion NUMBER
Maximum eml archive recursion depth.
Default: 100
PhishingAlwaysUnmarkup BOOL
Always unmarkup phishing signatures.
Default: no
PhishingScanText BOOL
Scan for phishing signatures in text files.
Default: yes
PhishingAlertText STRING
The text to be displayed for phishing alerts.
Default: ALERT: Phishing domain detected
PhishingNoBalanceHtml BOOL
Disable HTML balancing for phishing detection.
Default: no
PhishingSalt STRING
Salt for phishing detection.
Default: disabled
HeuristicScanThreshold NUMBER
A value between 1 and 100. The higher the value, the more permissive the heuristic analysis.
Default: 40
HeuristicMaximumFilesize SIZE
Maximum file size for heuristic analysis.
Default: 50M
HeuristicScanPartialSize SIZE
Scan partial files using heuristic analysis.
Default: 10M
ScanEmailSubject BOOL
Scan email subjects for viruses.
Default: no
SelfCHClvl NUMBER
Configure the level of self-checking.
0: disable self-checking
1: check signature status
2: check signature status and scan
Default: 1
UserExcludedFromSigCheck STRING
A comma separated list of users to be excluded from signature checks.
Default: nobody
VirusEventDummy STRING
This option is for testing purposes only. When this option is enabled, clamd will trigger a VirusEvent for each scanned file, regardless of its content.
Default: disabled
Check for issues with clamdscan
This option is for testing purposes only. When this option is enabled, clamd will trigger a generic error event for each scanned file, regardless of its content.
Default: disabled
DetectPUA BOOL
Detect Potentially Unwanted Applications.
Default: no
Include STRING
Include another configuration file. Multiple include directives are allowed.
The included files are parsed as if their content were part of the main configuration file.
Example: Include /etc/clamav/clamd.d/*.conf
AllowSupplementaryGroups BOOL
If set to yes, clamd will allow users to be members of supplementary groups. This means that the group ownership check on the clamd socket will not be strict, and any user belonging to a supplementary group will be allowed access.
Default: no
