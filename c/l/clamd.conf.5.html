clamd.conf(5)

clamd.conf(5) Clam AntiVirus clamd.conf(5)

الاسم

clamd.conf - ملف التكوين لخدمة Clam AntiVirus

الوصف

يقوم clamd.conf بتكوين خدمة Clam AntiVirus، clamd(8).

تنسيق الملف

يتكون الملف من تعليقات وخيارات مع وسائط. يتم تجاهل كل سطر يبدأ برمز الشباك (#) من قبل المحلل. الخيارات والوسائط حساسة لحالة الأحرف وتكون بالشكل Option Argument. الوسائط من الأنواع التالية:

BOOL
قيمة منطقية (yes/no أو true/false أو 1/0).
STRING
سلسلة نصية بدون أحرف فارغة.
SIZE
الحجم بالبايت. يمكنك استخدام المعدلات 'M' أو 'm' للميجابايت و'K' أو 'k' للكيلوبايت. لتحديد الحجم بالبايت فقط لا تستخدم المعدلات.
NUMBER
عدد صحيح غير سالب.

التوجيهات

عندما لا يتم استخدام بعض الخيارات (معلقة أو غير مضمنة في ملف التكوين على الإطلاق) يتخذ clamd إجراءً افتراضيًا.

Example
إذا تم تعيين هذا الخيار فلن يعمل clamd.
LogFile STRING
حفظ جميع التقارير في ملف سجل.
الافتراضي: معطل
LogFileUnlock BOOL
بشكل افتراضي يتم قفل ملف السجل للكتابة ويمكن لعملية خدمة واحدة فقط الكتابة إليه. يعطل هذا الخيار القفل.
الافتراضي: لا
LogFileMaxSize SIZE
الحد الأقصى لحجم ملف السجل.
القيمة 0 تعطل الحد.
الافتراضي: 1048576
LogTime BOOL
تسجيل الوقت لكل رسالة.
الافتراضي: لا
LogClean BOOL
تسجيل جميع الملفات النظيفة.
مفيد في تصحيح الأخطاء لكنه يزيد حجم السجل بشكل كبير.
الافتراضي: لا
LogSyslog BOOL
استخدام مسجل النظام (يمكن أن يعمل مع LogFile).
الافتراضي: لا
LogFacility STRING
نوع رسائل syslog
يرجى الرجوع إلى 'man syslog' لأسماء المرافق.
الافتراضي: LOG_LOCAL6
LogVerbose BOOL
تمكين التسجيل المطوّل.
الافتراضي: لا
LogRotate BOOL
تدوير ملف السجل. يتطلب تعيين خيار LogFileMaxSize قبل هذا الخيار.
الافتراضي: لا
ExtendedDetectionInfo BOOL
تسجيل معلومات إضافية حول الملف المصاب، مثل حجمه وتجزئته، مع اسم الفيروس.
الافتراضي: لا
PidFile STRING
كتابة معرف العملية (pid) للخدمة في الملف المحدد.
الافتراضي: معطل
TemporaryDirectory STRING
يتيح لك هذا الخيار تغيير الدليل المؤقت الافتراضي.
الافتراضي: خاص بالنظام (عادةً /tmp أو /var/tmp).
DatabaseDirectory STRING
يتيح لك هذا الخيار تغيير دليل قاعدة البيانات الافتراضي. إذا قمت بتمكينه، يرجى التأكد من أنه يشير إلى نفس الدليل في كل من clamd وfreshclam.
الافتراضي: محدد عند التكوين (/usr/local/share/clamav)
CVDCertsDirectory STRING
المسار إلى دليل يحتوي على ملفات شهادة CA الخاصة بـ ClamAV المستخدمة للتحقق من أرشيفات قواعد البيانات الموقعة (مثل ملفات CVD). يجب أن يكون هذا الدليل موجودًا بالفعل، وأن يكون مسارًا مطلقًا، وأن يكون قابلاً للقراءة من قبل freshclam وclamd وclamscan وsigtool.
الافتراضي: /etc/clamav/certs
FIPSCryptoHashLimits BOOL
فرض حدود شبيهة بـ FIPS على استخدام خوارزميات التجزئة للأغراض التشفيرية. سيعطل توقيعات MD5 وSHA1 FP وسيتطلب ملفات '.sign' للتحقق من أصالة CVD.
الافتراضي: لا
OfficialDatabaseOnly BOOL
تحميل التوقيعات الرسمية المنشورة من قبل مشروع ClamAV فقط.
الافتراضي: لا
FailIfCvdOlderThan NUMBER
العودة برمز خطأ غير صفري إذا كانت قاعدة بيانات الفيروسات أقدم من عدد الأيام المحدد.
الافتراضي: -1
LocalSocket STRING
المسار إلى مقبس محلي (Unix) ستستمع عليه الخدمة.
الافتراضي: معطل
LocalSocketGroup STRING
تعيين ملكية المجموعة على مقبس unix.
الافتراضي: المجموعة الأساسية للمستخدم الذي يشغل clamd
LocalSocketMode STRING
تعيين أذونات مقبس unix إلى الوضع المحدد.
الافتراضي: المقبس قابل للقراءة والكتابة للجميع
FixStaleSocket BOOL
إزالة المقبس القديم بعد إيقاف التشغيل غير النظيف.
الافتراضي: نعم
TCPSocket NUMBER
رقم منفذ TCP الذي ستستمع عليه الخدمة.
الافتراضي: معطل
TCPAddr STRING
بشكل افتراضي يرتبط clamd بـ INADDR_ANY.
يتيح لك هذا الخيار تقييد عنوان TCP وتوفير درجة معينة من الحماية من العالم الخارجي. يمكن تحديد هذا الخيار عدة مرات للاستماع على عناوين IP متعددة. IPv6 مدعوم الآن.
الافتراضي: معطل
EnableShutdownCommand BOOL
تمكين أمر SHUTDOWN. تعيين هذا إلى no يمنع العميل من إيقاف clamd عبر البروتوكول.
عند التعطيل، يستجيب clamd لهذا الأمر بـ COMMAND UNAVAILABLE.
الافتراضي: نعم
EnableReloadCommand BOOL
تمكين أمر RELOAD. تعيين هذا إلى no يمنع العميل من إعادة تحميل قاعدة البيانات.
عند التعطيل، يستجيب clamd لهذا الأمر بـ COMMAND UNAVAILABLE.
الافتراضي: نعم
EnableVersionCommand BOOL
تمكين أمر VERSION. تعيين هذا إلى no يمنع العميل من الاستعلام عن معلومات الإصدار.
عند التعطيل، يستجيب clamd لهذا الأمر بـ COMMAND UNAVAILABLE.
الافتراضي: نعم
EnableStatsCommand BOOL
تمكين أمر STATS. تعيين هذا إلى no يمنع العميل من الاستعلام عن الإحصائيات.
عند التعطيل، يستجيب clamd لهذا الأمر بـ COMMAND UNAVAILABLE.
الافتراضي: نعم
MaxConnectionQueueLength NUMBER
الحد الأقصى للطول الذي قد ينمو إليه طابور الاتصالات المعلقة.
الافتراضي: 200
StreamMaxLength SIZE
إغلاق جلسة STREAM عند تجاوز حد حجم البيانات.
يجب أن تتطابق القيمة مع حد MTA الخاص بك للحد الأقصى لحجم المرفقات.
الافتراضي: 100M
StreamMinPort NUMBER
يستخدم أمر STREAM بروتوكولًا مشابهًا لـ FTP.
يحدد هذا الخيار الحد الأدنى لنطاق المنافذ.
الافتراضي: 1024
StreamMaxPort NUMBER
