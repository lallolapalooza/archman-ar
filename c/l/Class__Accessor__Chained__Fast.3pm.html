Class__Accessor__Chained__Fast(3pm)

الحزمة: perl-class-accessor-chained

التراخيص: GPL, PerlArtistic

Class::Accessor::Chained::Fast(3) وثائق Perl مقدمة من المستخدم Class::Accessor::Chained::Fast(3)

الاسم

Class::Accessor::Chained::Fast - مسلّطات وصول متسلسلة أسرع، ولكن أقل قابلية للتوسع

الملخص

package Foo;
use base qw(Class::Accessor::Chained::Fast);
 # الباقي كما في Class::Accessor::Chained باستثناء عدم وجود set() أو get().

الوصف

قياساً على Class::Accessor و Class::Accessor::Fast، توفر هذه الوحدة صانع مسلّطات وصول متسلسلة أسرع وأقل مرونة.
