real function clangb (norm, n, kl, ku, ab, ldab, work)
CLANGB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة النطاق العامة.

توثيق الوظيفة/الروتين الفرعي

real function clangb (character norm, integer n, integer kl, integer ku, complex, dimension( ldab, * ) ab, integer ldab, real, dimension( * ) work)

CLANGB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة النطاق العامة.

الغرض:

!>
!> CLANGB  تُرجع قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> مربعة بحجم n × n، مع kl تحت الأقطار و ku فوق الأقطار.
!>

القيم المُرجعة

CLANGB 
!>
!>    CLANGB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى المعيار واحد للمصفوفة (أكبر مجموع أعمدة)،
!> normI  يشير إلى المعيار اللانهائي للمصفوفة (أكبر مجموع صفوف)، و
!> normF  يشير إلى معيار فروبينيوس للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANGB كما هو موضح
!>          أعلاه.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANGB
!>          إلى الصفر.
!>

KL

!>          KL هو INTEGER
!>          عدد تحت الأقطار للمصفوفة A.  KL >= 0.
!>

KU

!>          KU هو INTEGER
!>          عدد فوق الأقطار للمصفوفة A.  KU >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX، حجمها (LDAB,N)
!>          مصفوفة النطاق A، مخزنة في الصفوف من 1 إلى KL+KU+1.  العمود j
!>          للمصفوفة A مخزن في العمود j للمصفوفة AB كما يلي:
!>          AB(ku+1+i-j,j) = A(i,j) لـ max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= KL+KU+1.
!>

WORK

!>          WORK هو مصفوفة REAL، حجمها (MAX(1,LWORK))،
!>          حيث LWORK >= N عندما NORM = 'I'؛ بخلاف ذلك، لا يتم استخدام WORK.
!>
