NAME

claqz0 - computes the Schur factorization of a pair of complex matrices (A, B) in reduced form

SYNOPSIS

subroutine claqz0(A, LDA, B, LDB, ALPHA, BETA, Q, LDQ, Z, LDZ, WORK, LWORK, RWORK, REC, INFO)
!
!  Input/Output Parameters
!
complex(4)          A(LDA,*)
complex(4)          B(LDB,*)
complex(8)          ALPHA(*)
complex(8)          BETA(*)
complex(4)          Q(LDQ,*)
complex(4)          Z(LDZ,*)
complex(4)          WORK(LWORK)
real(4)             RWORK(N)
integer             REC
integer             INFO
!
!  Input Parameters
!
integer             LDA
integer             LDB
integer             LDQ
integer             LDZ
integer             LWORK
!
end subroutine claqz0

Description:

claqz0 computes the Schur factorization of a pair of complex matrices (A, B) in reduced form.

This subroutine is intended to be called only by other LAPACK routines.

Function/Subroutine Documentation

A

!> A is COMPLEX(8) array, dimension (LDA, N)
!> On entry, A contains the upper triangular matrix.
!> On exit, A is overwritten by the upper triangular matrix of the Schur
!> factorization.

LDA

!> LDA is INTEGER
!> The leading dimension of the array A. LDA >= max(1, N).

B

!> B is COMPLEX(8) array, dimension (LDB, N)
!> On entry, B contains the upper triangular matrix.
!> On exit, B is overwritten by the upper triangular matrix of the Schur
!> factorization.

LDB

!> LDB is INTEGER
!> The leading dimension of the array B. LDB >= max(1, N).

ALPHA

!> ALPHA is COMPLEX(8) array, dimension (N)
!> On exit, the complex scalar Alpha_i such that A(i,i) = Alpha_i / Beta_i.

BETA

!> BETA is COMPLEX(8) array, dimension (N)
!> On exit, the complex scalar Beta_i such that B(i,i) = Beta_i.

Q

!> Q is COMPLEX(4) array, dimension (LDQ, N)
!> On exit, Q is an upper triangular unitary matrix such that
!> if UPLO = 'U', A = Q*A*Q**H and B = Q*B*Q**H,
!> if UPLO = 'L', A = Q*A*Q**H and B = Q*B*Q**H.
!> Q is not used if COMPZ = 'N'.

LDQ

!> LDQ is INTEGER
!> The leading dimension of the array Q. LDQ >= 1 if COMPZ = 'V' or 'I'.
!> LDQ >= N if COMPZ = 'V' or 'I'.

Z

!> Z is COMPLEX(4) array, dimension (LDZ, N)
!> On exit, Z is an upper triangular unitary matrix such that
!> if UPLO = 'U', A = Z*A*Z**H and B = Z*B*Z**H,
!> if UPLO = 'L', A = Z*A*Z**H and B = Z*B*Z**H.
!> Z is not used if COMPZ = 'N'.

LDZ

!> LDZ is INTEGER
!> The leading dimension of the array Z. LDZ >= 1.
!> If COMPZ='V' or 'I', then LDZ >= N.

WORK

!> WORK is COMPLEX array, dimension (MAX(1,LWORK))
!> On exit, if INFO >= 0, WORK(1) returns the optimal LWORK.

LWORK

!> LWORK is INTEGER
!> The dimension of the array WORK. LWORK >= max(1,N).
!>
!> If LWORK = -1, then a workspace query is assumed; the routine
!> only calculates the optimal size of the WORK array, returns
!> this value as the first entry of the WORK array, and no error
!> message related to LWORK is issued by XERBLA.

RWORK

!> RWORK is REAL array, dimension (N)

REC

!> REC is INTEGER
!>    REC indicates the current recursion level. Should be set
!>    to 0 on first call.

INFO

!> INFO is INTEGER
!> = 0: successful exit
!> < 0: if INFO = -i, the i-th argument had an illegal value
!> = 1,...,N: the QZ iteration did not converge.  (A,B) is not
!>            in Schur form, but ALPHA(i) and
!>            BETA(i), i=INFO+1,...,N should be correct.
