cccheck(1)

الحزمة: mono

التراخيص: GPL, LGPL2.1, MPL

Mono(cccheck) Mono(cccheck)

الاسم

cccheck - إجراء التحقق الثابت من عقود الكود للتجميعات CLR.

الملخص

cccheck --assembly=<assembly> [options]

الوصف

إجراء التحقق الثابت من عقود الكود للعثور على الأخطاء والتناقضات بين الكود والمواصفات. يشمل هذا تحليلات غير خالية وتحليلات أعداد صحيحة.

يجب بناء التجميعة مع تعريف الثابت CONTRACTS_FULL، وإلا سيتم إزالة استدعاءات دوال العقد بواسطة المترجم.

في الوقت الحالي، يتم دعم دوال Contract.Assume() و Contract.Assert() فقط. يتم دعم التحليل غير الخالي فقط، والتحليلات المتتالية قيد التطوير. سيتم عرض رسالة خطأ إذا فشل cccheck في معالجة جميع أو بعض دوال التجميعة المحددة.

خيارات التكوين

--assembly <assembly-name>
التجميعة لإجراء التحقق الثابت.
--debug
يعرض معلومات التصحيح حول عملية إثبات التأكيدات. يعرض أربع طبقات من التجريد: الطبقة الخام، طبقة المكدس، طبقة الكومة، ومستوى التعبير المستبدل.
--method=<method-name-substring>
سلسلة نصية للعثور على الدالة. تقوم بتصفية جميع الدوال في التجميعة حيث اسم الدالة يحتوي على هذه المعلمة كسلسلة فرعية.
--help
عرض المساعدة لـ cccheck، مع سرد خيارات التكوين.

أمثلة

لنفترض أن لديك دالة:

void Method() {
object x = null;
int y = 1;
if (y % 2 == 1)
x = new object();
else
x = new string();


Contract.Assert(x != null); }

بعد التحقق، ستحصل الأداة على النتائج بالتنسيق التالي: "Assertion at : [Subroutine: <id> Block <blockId> PC <id>] :
is (true|false|unproven|unreachable)". (PC هو عداد البرنامج)
