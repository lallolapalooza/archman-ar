!>
!> CCHKGG  يتحقق من إجراءات مسألة القيم الذاتية المعممة غير المتناظرة.
!>                                H          H        H
!> CGGHRD تقوم بتحليل A و B على الصورة U H V  و U T V ، حيث   تعني مترافقة
!> تبديل، H هسنبرغ، T مثلثية و U و V وحدتان.
!>
!>                                 H          H
!> CHGEQZ تقوم بتحليل H و T على الصورة  Q S Z  و Q P Z ، حيث P و S مثلثيتان علويتان
!> و Q و Z وحدتان. كما أنها تحسب القيم الذاتية المعممة (alpha(1)،beta(1))،...،(alpha(n)،beta(n))، حيث
!> alpha(j)=S(j,j) و beta(j)=P(j,j) -- وبالتالي، فإن w(j) = alpha(j)/beta(j)
!> هو جذر مسألة القيم الذاتية المعممة
!>
!>     det( A - w(j) B ) = 0
!>
!> و m(j) = beta(j)/alpha(j) هو جذر المسألة المكافئة جوهريًا
!>
!>     det( m(j) A - B ) = 0
!>
!> CTGEVC تحسب المصفوفة L للقيم الذاتية اليسرى والمصفوفة R
!> للقيم الذاتية اليمنى لزوج المصفوفات ( S, P ). في الوصف أدناه،
!> l و r هما قيمتان ذاتيتان يسريتان ويمينتان تتوافقان مع القيم الذاتية المعممة (alpha,beta).
!>
!> عندما يتم استدعاء CCHKGG، يتم تحديد عدد من المصفوفات  () و
!> عدد من المصفوفات . لكل حجم ()
!> ولكل نوع من المصفوفات، سيتم إنشاء مصفوفة واحدة واستخدامها
!> لاختبار الإجراءات الذاتية غير المتناظرة. لكل مصفوفة، سيتم إجراء 13
!> اختبارًا. يجب أن تكون أول اثني عشر  صغيرة -- O(1).  سيتم مقارنتها مع العتبة THRESH:
!>
!>                  H
!> (1)   | A - U H V  | / ( |A| n ulp )
!>
!>                  H
!> (2)   | B - U T V  | / ( |B| n ulp )
!>
!>               H
!> (3)   | I - UU  | / ( n ulp )
!>
!>               H
!> (4)   | I - VV  | / ( n ulp )
!>
!>                  H
!> (5)   | H - Q S Z  | / ( |H| n ulp )
!>
!>                  H
!> (6)   | T - Q P Z  | / ( |T| n ulp )
!>
!>               H
!> (7)   | I - QQ  | / ( n ulp )
!>
!>               H
!> (8)   | I - ZZ  | / ( n ulp )
!>
!> (9)  بحد أقصى لجميع أزواج القيم الذاتية/الذاتية اليسرى (beta/alpha,l)
!>                           H
!>       | (beta A - alpha B) l | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (10)  بحد أقصى لجميع أزواج القيم الذاتية/الذاتية اليسرى (beta/alpha,l')
!>                           H
!>       | (beta H - alpha T) l' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       حيث القيم الذاتية l' هي نتيجة تمرير Q إلى
!>       STGEVC وإعادة التحويل (JOB='B').
!>
!> (11)  بحد أقصى لجميع أزواج القيم الذاتية/الذاتية اليمنى (beta/alpha,r)
!>
!>       | (beta A - alpha B) r | / ( ulp max( |beta A|, |alpha B| ) )
!>
!> (12)  بحد أقصى لجميع أزواج القيم الذاتية/الذاتية اليمنى (beta/alpha,r')
!>
!>       | (beta H - alpha T) r' | / ( ulp max( |beta H|, |alpha T| ) )
!>
!>       حيث القيم الذاتية r' هي نتيجة تمرير Z إلى
!>       STGEVC وإعادة التحويل (JOB='B').
!>
!> نسب الاختبار الثلاث الأخيرة ستكون عادة صغيرة، ولكن لا يوجد
!> شرط رياضي يجعلها كذلك. لذلك
!> تتم مقارنتها مع THRESH فقط إذا كان TSTDIF هو .TRUE.
!>
!> (13)  | S(Q,Z محسوبة) - S(Q,Z غير محسوبة) | / ( |S| ulp )
!>
!> (14)  | P(Q,Z محسوبة) - P(Q,Z غير محسوبة) | / ( |P| ulp )
!>
!> (15)  max( |alpha(Q,Z محسوبة) - alpha(Q,Z غير محسوبة)|/|S| ,
!>            |beta(Q,Z محسوبة) - beta(Q,Z غير محسوبة)|/|P| ) / ulp
!>
!> بالإضافة إلى ذلك، يتم التحقق من تسوية L و R، ومقارنتها
!> مع العتبة THRSHN.
!>
!> مصفوفات الاختبار
!> ---- --------
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد   بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كان DOTYPE(j) هو .TRUE.، فسيتم إنشاء نوع المصفوفة .
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة هوية ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة هوية ومصفوفة صفرية)
!>
!> (4)  ( I, I )         (زوج من مصفوفات الهوية)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان مبدلة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I مصفوفة هوية k x k و J كتلة جوردان (k+1)x(k+1)
!>                       k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هي P*D1، P هي مصفوفة قطرية وحدوية عشوائية
!>                       (أي، مع مدخلات ذات حجم 1 عشوائي على القطر)
!>                       و D1=diag( 0, 1,..., N-1 )
!>                       (أي، مصفوفة قطرية مع D1(1,1)=0،
!>                       D1(2,2)=1، ...، D1(N,N)=N-1.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث  قريبة من الفائض و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        حيث D1=P*diag( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2=Q*diag( 0, N-3, N-4,..., 1, 0, 0 )، و
!>                        P و Q هما مصفوفتان قطريتان وحدويتان عشوائيتان.
!>           t   t
!> (16) U ( J , J ) V     حيث U و V مصفوفتان وحدويتان عشوائيتان.
!>
!> (17) U ( T1, T2 ) V    حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!>                        مع مدخلات O(1) عشوائية فوق القطر
!>                        ومدخلات قطرية diag(T1) =
!>
