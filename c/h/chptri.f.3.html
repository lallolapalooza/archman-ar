توثيق الوظيفة/الإجراء الفرعي

subroutine chptri (character uplo, integer n, complex, dimension( * ) ap, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer info)

CHPTRI

الغرض:

!>
!> CHPTRI يحسب معكوس مصفوفة هرميتية معقدة غير محددة
!> A في تخزين مكدس باستخدام التحليل A = U*D*U**H أو
!> A = L*D*L**H الذي تم حسابه بواسطة CHPTRF.
!>

المعاملات

UPLO 
!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت تفاصيل التحليل مخزنة
!>          كمصفوفة مثلثية عليا أو سفلى.
!>          = 'U':  مثلثية عليا، الشكل هو A = U*D*U**H؛
!>          = 'L':  مثلثية سفلى، الشكل هو A = L*D*L**H.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          عند الإدخال، المصفوفة القطرية الفرعية D والمعاملات
!>          المستخدمة للحصول على العامل U أو L كما تم حسابه بواسطة CHPTRF،
!>          مخزنة كمصفوفة مثلثية مكدسة.
!>
!>          عند الخروج، إذا كان INFO = 0، معكوس المصفوفة الأصلية (الهرميتية)
!>          مخزنة كمصفوفة مثلثية مكدسة. العمود j
!>          من inv(A) مخزن في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = inv(A)(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'،
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) لـ j<=i<=n.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          تفاصيل المبادلات والبنية الفرعية لـ D
!>          كما تم تحديدها بواسطة CHPTRF.
!>

WORK

!>          WORK is COMPLEX array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، كان المعامل i ذو قيمة غير قانونية
!>          > 0: إذا كان INFO = i، D(i,i) = 0؛ المصفوفة منفردة ولا يمكن
!>               حساب معكوسها.
!>
