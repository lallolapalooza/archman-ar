CHE EVR

!> @brief The complex Hermitian eigenvalue problem: Scaled                 Problem (example).
!>
!> @details For the complex Hermitian eigenvalue problem Ax = λx, where A is
!>          a complex Hermitian matrix, we compute the eigenvalues λ and
!>          eigenvectors x of A.
!>
!> @param JOBZ
!>          JOBZ is CHARACTER*1
!>          Specifies whether to compute eigenvalues and eigenvectors.
!>          If JOBZ = 'E', then only eigenvalues are computed.
!>          If JOBZ = 'V', then eigenvalues and the corresponding eigenvectors
!>          are computed.
!>
!> @param RANGE
!>          RANGE is CHARACTER*1
!>          Specifies the range of eigenvalues to be computed.
!>          If RANGE = 'A', all eigenvalues are computed.
!>          If RANGE = 'V', all eigenvalues in the interval (VL, VU] are computed.
!>          If RANGE = 'I', all eigenvalues in the positions IL to IU are computed.
!>
!> @param UPLO
!>          UPLO is CHARACTER*1
!>          Specifies whether A is upper or lower triangular.
!>          If UPLO = 'U', then A stores the upper triangular part of A.
!>          If UPLO = 'L', then A stores the lower triangular part of A.
!>
!> @param N
!>          N is INTEGER
!>          The order of the matrix A. 0 <= N.
!>
!> @param A
!>          A is COMPLEX array, dimension (LDA, N)
!>          On entry, the complex Hermitian matrix A.
!>          Only UPLO part of A is accessed.
!>
!> @param LDA
!>          LDA is INTEGER
!>          The leading dimension of the array A. LD >= max(1, N).
!>
!> @param VL
!>          VL is REAL
!>          If RANGE = 'V', the lower bound of the eigenvalue interval.
!>
!> @param VU
!>          VU is REAL
!>          If RANGE = 'V', the upper bound of the eigenvalue interval.
!>
!> @param IL
!>          IL is INTEGER
!>          If RANGE = 'I', the lower bound of the range of indices for the
!>          eigenvalues. 1 <= IL <= IU, and the number of eigenvalues in the
!>          range is IU-IL+1.
!>
!> @param IU
!>          IU is INTEGER
!>          If RANGE = 'I', the upper bound of the range of indices for the
!>          eigenvalues. 1 <= IU <= N.
!>
!> @param ABSTOL
!>          ABSTOL is REAL
!>          The tolerance for the convergence test.
!>          If ABSTOL is set to the default value abs( D( I ) )*eps,
!>          where eps is the machine precision, the algorithm is guaranteed
!>          to find the correct eigenvalues for most of the matrices.
!>          If high relative accuracy is important, set ABSTOL to
!!>          SLAMCH( 'Safe minimum' ). Doing so will guarantee that
!>          eigenvalues are computed to high relative accuracy when
!>          possible in future releases. The current code does not
!>          make any guarantees about high relative accuracy, but
!>          future releases will. See J. Barlow and J. Demmel,
!>          , LAPACK Working Note #7, for a discussion
!>          of which matrices define their eigenvalues to high relative
!>          accuracy.
!>
!> @param M
!>          M is INTEGER
!>          The total number of eigenvalues found. 0 <= M <= N.
!>          If RANGE = 'A', M = N, and if RANGE = 'I', M = IU-IL+1.
!>
!> @param W
!>          W is COMPLEX array, dimension (N)
!>          The first M elements contain the selected eigenvalues in
!>          ascending order.
!>
!> @param Z
!>          Z is COMPLEX array, dimension (LDZ, max(1,M))
!>          If JOBZ = 'V', then if INFO = 0, the first M columns of Z
!>          contain the orthonormal eigenvectors of the matrix A
!>          corresponding to the selected eigenvalues, with the i-th
!>          column of Z holding the eigenvector associated with W(i).
!>          If JOBZ = 'N', then Z is not referenced.
!>          Note: the user must ensure that at least max(1,M) columns are
!>          supplied in the array Z; if RANGE = 'V', the exact value of M
!>          is not known in advance and an upper bound must be used.
!>          Supplying N columns is always safe.
!>
!> @param LDZ
!>          LDZ is INTEGER
!>          The leading dimension of the array Z. LDZ >= 1, and if
!>          JOBZ = 'V', LDZ >= max(1,N).
!>
!> @param ISUPPZ
!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is an output of CSTEMR (tridiagonal
!>          matrix). The support of the eigenvectors of A is typically
!>          1:N because of the unitary transformations applied by CUNMTR.
!>          Implemented only for RANGE = 'A' or 'I' and IU - IL = N - 1
!>
!> @param WORK
!>          WORK is COMPLEX array, dimension (MAX(1,LWORK))
!>          On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
!>
!> @param LWORK
!>          LWORK is INTEGER
!>          The length of the array WORK.
!>          If N <= 1, LWORK >= 1, else LWORK >= 2*N.
!>          For optimal efficiency, LWORK >= (NB+1)*N,
!>          where NB is the max of the blocksize for CHETRD and for
!>          CUNMTR as returned by ILAENV.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK, RWORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>
!> @param RWORK
!>          RWORK is REAL array, dimension (MAX(1,LRWORK))
!>          On exit, if INFO = 0, RWORK(1) returns the optimal
!>          (and minimal) LRWORK.
!>
!> @param LRWORK
!>          LRWORK is INTEGER
!>          The length of the array RWORK.
!>          If N <= 1, LRWORK >= 1, else LRWORK >= 24*N.
!>
!>          If LRWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK, RWORK
!>          and IWORK arrays, returns these values as the first entries
!>          of the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>
!> @param IWORK
!>          IWORK is INTEGER array, dimension (MAX(1,LIWORK))
!>          On exit, if INFO = 0, IWORK(1) returns the optimal
!>          (and minimal) LIWORK.
!>
!> @param LIWORK
!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          If N <= 1, LIWORK >= 1, else LIWORK >= 10*N.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal sizes of the WORK, RWORK
!>          and IWORK arrays, returns these values as the first entries
!>          of the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>
!> @param INFO
!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  Internal error
