Char.Ascii - دعم مجموعة أحرف ASCII.

الوحدة Char.Ascii

التوثيق

الوحدة Ascii
: sig end

دعم مجموعة أحرف ASCII.

هذه الدوال تعطي معنى للأعداد الصحيحة [ 0x00 ; 0x7F ] في مجموعة أحرف ASCII.

نظرًا لأن ترميز UTF-8 لليونيكود له نفس الترميز والدلالات للأحرف (U+0000 إلى U+001F) لهذه البايتات، يمكن استخدام الدوال بأمان على عناصر من قيم string و bytes المشفرة بـ UTF-8. ومع ذلك، تتعامل الدوال مع الأمور المتعلقة بـ ASCII فقط. على سبيل المثال، مفهوم المسافة البيضاء في اليونيكود أكبر بكثير من المسافة البيضاء في ASCII التي تحددها Char.Ascii.is_white .

منذ 5.4

الأحرف

val min : char

min هو '\x00' .

val max : char

max هو '\x7F' .

المحددات

val is_valid : char -> bool

is_valid c تكون true إذا وفقط إذا كان c حرف ASCII، أي بايت في النطاق [ Char.Ascii.min ; Char.Ascii.max ].

val is_upper : char -> bool

is_upper c تكون true إذا وفقط إذا كان c حرفًا أبجديًا كبيرًا في ASCII من 'A' إلى 'Z' ، أي بايت في النطاق [ 0x41 ; 0x5A ].

val is_lower : char -> bool

is_lower c تكون true إذا وفقط إذا كان c حرفًا أبجديًا صغيرًا في ASCII من 'a' إلى 'z' ، أي بايت في النطاق [ 0x61 ; 0x7A ].

val is_letter : char -> bool

is_letter c هي Char.Ascii.is_lower c || Char.Ascii.is_upper c .

val is_alphanum : char -> bool

is_alphanum c هي Char.Ascii.is_letter c || Char.Ascii.is_digit c .

val is_white : char -> bool

is_white c تكون true إذا وفقط إذا كان c حرف مسافة بيضاء في ASCII، أي أحد الأحرف التالية: tab '\t' ( 0x09 )، newline '\n' ( 0x0A )، vertical tab ( 0x0B )، form feed ( 0x0C )، carriage return '\r' ( 0x0D ) أو space ' ' ( 0x20 ).

val is_blank : char -> bool

is_blank c تكون true إذا وفقط إذا كان c حرف مسافة بيضاء في ASCII، أي إما space ' ' ( 0x20 ) أو tab '\t' ( 0x09 ).

val is_graphic : char -> bool

is_graphic c تكون true إذا وفقط إذا كان c حرفًا رسوميًا في ASCII، أي بايت في النطاق [ 0x21 ; 0x7E ].

val is_print : char -> bool

is_print c هي Char.Ascii.is_graphic c || c = ' ' .

val is_control : char -> bool

is_control c تكون true إذا وفقط إذا كان c حرف تحكم في ASCII، أي بايت في النطاق [ 0x00 ; 0x1F ] أو 0x7F .

الأرقام العشرية

val is_digit : char -> bool

is_digit c تكون true إذا وفقط إذا كان c رقمًا عشريًا في ASCII من '0' إلى '9' ، أي بايت في النطاق [ 0x30 ; 0x39 ].

val digit_to_int : char -> int

digit_to_int c هي القيمة العددية لرقم يحقق Char.Ascii.is_digit . تثير Invalid_argument إذا كانت Char.Ascii.is_digit c تساوي false .

val digit_of_int : int -> char

digit_of_int n هو رقم عشري في ASCII للقيمة العشرية abs (n mod 10) .

الأرقام الست عشرية

val is_hex_digit : char -> bool

is_hex_digit c تكون true إذا وفقط إذا كان c رقمًا ست عشريًا في ASCII من '0' إلى '9' ، 'a' إلى 'f' أو 'A' إلى 'F' ، أي بايت في أحد النطاقات [ 0x30 ; 0x39 ]، [ 0x41 ; 0x46 ]، [ 0x61 ; 0x66 ].

val hex_digit_to_int : char -> int

hex_digit_to_int c هي القيمة العددية لرقم يحقق Char.Ascii.is_hex_digit . تثير Invalid_argument إذا كانت Char.Ascii.is_hex_digit c تساوي false .

val lower_hex_digit_of_int : int -> char

lower_hex_digit_of_int n هو رقم ست عشري صغير في ASCII للقيمة الست عشرية abs (n mod 16) .

val upper_hex_digit_of_int : int -> char

upper_hex_digit_of_int n هو رقم ست عشري كبير في ASCII للقيمة الست عشرية abs (n mod 16) .

تحويلات الحالة

val uppercase : char -> char

uppercase c هي c مع الأحرف ASCII 'a' إلى 'z' قابلة للتحويل إلى أحرف كبيرة 'A' إلى 'Z' . الأحرف الأخرى تبقى كما هي.

val lowercase : char -> char

lowercase c هي c مع الأحرف ASCII 'A' إلى 'Z' قابلة للتحويل إلى أحرف صغيرة 'a' إلى 'z' . الأحرف الأخرى تبقى كما هي.
