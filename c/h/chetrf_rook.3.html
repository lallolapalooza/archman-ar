CHETRF_ROOK تحسب تحليل مصفوفة هيرميتية غير محددة معقدة باستخدام طريقة التحويل القطري لـ Bunch-Kaufman (rook") (خوارزمية مجمعة، تستدعي BLAS المستوى 3).

توثيق الوظيفة/الروتين الفرعي

subroutine chetrf_rook (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer lwork, integer info)

CHETRF_ROOK تحسب تحليل مصفوفة هيرميتية غير محددة معقدة باستخدام طريقة التحويل القطري لـ Bunch-Kaufman ("rook") (خوارزمية مجمعة، تستدعي BLAS المستوى 3).

الغرض:

!>
!> CHETRF_ROOK تحسب تحليل مصفوفة هيرميتية معقدة A
!> باستخدام طريقة التحويل القطري المحدود لـ Bunch-Kaufman ().
!> شكل التحليل هو
!>
!>    A = U*D*U**T  أو  A = L*D*L**T
!>
!> حيث U (أو L) هو ناتج ضرب مصفوفات التبديل والمثلثات العليا (السفلى)
!> الواحدة، و D هي مصفوفة هيرميتية وقطرية كتلة مع كتل قطرية
!> بحجم 1x1 و 2x2.
!>
!> هذه هي النسخة المجمعة من الخوارزمية، والتي تستدعي BLAS المستوى 3.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  المثلث العلوي لـ A مخزن؛
!>          = 'L':  المثلث السفلي لـ A مخزن.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

A

!>          A هو مصفوفة COMPLEX، أبعادها (LDA,N)
!>          عند الدخول، المصفوفة الهيرميتية A.  إذا كان UPLO = 'U'، فإن
!>          الجزء المثلثي العلوي N-by-N من A يحتوي على الجزء
!>          المثلثي العلوي للمصفوفة A، والجزء المثلثي السفلي الصارم
!>          لـ A لا تتم الإشارة إليه.  إذا كان UPLO = 'L'، فإن
!>          الجزء المثلثي السفلي N-by-N من A يحتوي على الجزء
!>          المثلثي السفلي للمصفوفة A، والجزء المثلثي العلوي الصارم
!>          لـ A لا تتم الإشارة إليه.
!>
!>          عند الخروج، المصفوفة القطرية الكتلة D والمعاملات المستخدمة
!>          للحصول على العامل U أو L (انظر أدناه لمزيد من التفاصيل).
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV هو مصفوفة INTEGER، أبعادها (N)
!>          تفاصيل التبادلات وهيكل الكتلة لـ D.
!>
!>          إذا كان UPLO = 'U':
!>             يتم تعيين آخر KB عنصر من IPIV فقط.
!>
!>             إذا كان IPIV(k) > 0، فقد تم تبديل الصفوف والأعمدة k و IPIV(k)
!>             وكان D(k,k) كتلة قطرية 1x1.
!>
!>             إذا كان IPIV(k) < 0 و IPIV(k-1) < 0، فقد تم تبديل الصفوف
!>             والأعمدة k و -IPIV(k) وتم تبديل الصفوف
!>             والأعمدة k-1 و -IPIV(k-1)،
!>             وكان D(k-1:k,k-1:k) كتلة قطرية 2x2.
!>
!>          إذا كان UPLO = 'L':
!>             يتم تعيين أول KB عنصر من IPIV فقط.
!>
!>             إذا كان IPIV(k) > 0، فقد تم تبديل الصفوف والأعمدة k و IPIV(k)
!>             وكان D(k,k) كتلة قطرية 1x1.
!>
!>             إذا كان IPIV(k) < 0 و IPIV(k+1) < 0، فقد تم تبديل الصفوف
!>             والأعمدة k و -IPIV(k) وتم تبديل الصفوف
!>             والأعمدة k+1 و -IPIV(k+1)،
!>             وكان D(k:k+1,k:k+1) كتلة قطرية 2x2.
!>

WORK

!>          WORK هي مصفوفة COMPLEX، أبعادها (MAX(1,LWORK)).
!>          عند الخروج، إذا كان INFO = 0، فإن WORK(1) يعيد LWORK الأمثل.
!>

LWORK

!>          LWORK هو INTEGER
!>          طول WORK.  LWORK >= 1.  لأفضل أداء
!>          LWORK >= N*NB، حيث NB هو حجم الكتلة الذي تعيده ILAENV.
!>
!>          إذا كان LWORK = -1، فيفترض أن يكون استعلام مساحة العمل؛ الروتين
!>          يحسب فقط الحجم الأمثل للمصفوفة WORK، ويعيد
!>          هذه القيمة كإدخال أول للمصفوفة WORK، ولا يتم إصدار أي رسالة خطأ
!>          متعلقة بـ LWORK بواسطة XERBLA.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن D(i,i) يساوي صفرًا تمامًا.  تم
!>                إكمال التحليل، ولكن المصفوفة القطرية الكتلة D
!>                فردية تمامًا، وسيحدث قسمة على صفر إذا
!>                تم استخدامها لحل نظام معادلات.
!>

تفاصيل إضافية:

!>
!>  إذا كان UPLO = 'U'، فإن A = U*D*U**T، حيث
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  أي، U هو ناتج ضرب المصطلحات P(k)*U(k)، حيث k تنقص من n إلى
!>  1 بخطوات 1 أو 2، و D هي مصفوفة قطرية كتلة مع كتل قطرية
!>  1x1 و 2x2 هي D(k).  P(k) هي مصفوفة تبديل كما
!>  يتم تعريفها بواسطة IPIV(k)، و U(k) هي مصفوفة مثلثية علوية وحدة، بحيث
!>  إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  إذا كان s = 1، فإن D(k) تحل محل A(k,k)، و v تحل محل A(1:k-1,k).
!>  إذا كان s = 2، فإن المثلث العلوي لـ D(k) يحل محل A(k-1,k-1)، A(k-1,k)،
!>  و A(k,k)، و v تحل محل A(1:k-2,k-1:k).
!>
!>  إذا كان UPLO = 'L'، فإن A = L*D*L**T، حيث
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  أي، L هو ناتج ضرب المصطلحات P(k)*L(k)، حيث k تزداد من 1 إلى
!>  n بخطوات 1 أو 2، و D هي مصفوفة قطرية كتلة مع كتل قطرية
!>  1x1 و 2x2 هي D(k).  P(k) هي مصفوفة تبديل كما
!>  يتم تعريفها بواسطة IPIV(k)، و L(k) هي مصفوفة مثلثية سفلى وحدة، بحيث
!>  إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  إذا كان s = 1، فإن D(k) تحل محل A(k,k)، و v تحل محل A(k+1:n,k).
!>  إذا كان s = 2، فإن المثلث السفلي لـ D(k) يحل محل A(k,k)، A(k+1,k)،
!>  و A(k+1,k+1)، و v تحل محل A(k+2:n,k:k+1).
!>
