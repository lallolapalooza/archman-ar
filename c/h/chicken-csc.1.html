NAME

csc — The CHICKEN Scheme compiler

SYNOPSIS

csc [csc-option ...] [compiler-option ...] [file ...]

DESCRIPTION

The csc program is the command-line interface to the CHICKEN compiler. It accepts a list of files (which should be Scheme source files ending in .scm, or C source files ending in .c) and compiles them into an executable file. The name of the executable file is derived from the first file name in the list (e.g. if foo.scm is the first file, the executable will be named foo). If no files are specified, csc will read from standard input and write to the executable a.out.

Options are passed to csc itself, or to the compiler, or to the linker. Options that start with - are parsed by csc. Options that are not recognized by csc are passed to the compiler. Arguments that do not start with a - are treated as source files.

The compiler and linker options are passed to the compiler and linker (which are invoked by the compiler). These options are processed by the compiler in the order in which they appear on the command line.

-c
Compile only; do not link. Produces an object file for each source file. These object files can then be linked together or with other object files to form an executable file.
-g
Add debugging information to the compiled output. This includes line number information and variable names.
-h
Print a summary of the available options.
-k
Enable support for foreign function calls.
-O
Perform optimizations on the generated code. This can make the resulting executable run faster, but may also increase the compilation time.
-O2
Perform more aggressive optimizations than -O. This may result in even faster executables, but could also increase compilation time and potentially introduce subtle bugs.
-f
Generate fast code. This is equivalent to -O.
-i
Inline procedures. This can improve performance by reducing function call overhead.
-fixnum-arithmetic
Enable fixnum arithmetic. This can improve the performance of integer operations.
-optimize
Enable optimizations.
-v
Print the commands being executed. This can be useful for debugging compilation problems.
-V
Print the compiler version and exit.
-o file
Use file as the name of the executable file. This option can only be used once.
-l library
Link with the specified library. This option can be used multiple times.
-L path
Add path to the list of directories searched for libraries. This option can be used multiple times.
-private-repository
Load extensions from executable path.
-deployed
Link support file to be used from a deployed executable (sets ‘rpath’ accordingly, if supported on this platform.)
-no-elevation
Embed manifest on Windows to supress elevation warnings for programs named ‘install’ or ‘setup’.

Options can be collapsed if unambiguous, so “-vkfO” is the same as “-v -k -fixnum-arithmetic -optimize”.

ENVIRONMENT

The following environment variables change the behaviour of csc:

CSC_OPTIONS
Can hold default options that should be passed to every invocation of csc.

EXIT STATUS

The csc utility exits 0 on success, and >0 if an error occurs.
