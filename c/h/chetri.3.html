subroutine chetri (uplo, n, a, lda, ipiv, work, info)
CHETRI

توثيق الدالة/الروتين الفرعي

subroutine chetri (character uplo, integer n, complex, dimension( lda, * ) a, integer lda, integer, dimension( * ) ipiv, complex, dimension( * ) work, integer info)

CHETRI

الغرض:

!>
!> CHETRI تحسب معكوس مصفوفة هيرميتية مركبة غير محددة
!> A باستخدام التحليل A = U*D*U**H أو A = L*D*L**H المحسوبة بواسطة
!> CHETRF.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          تحدد ما إذا كانت تفاصيل التحليل مخزنة
!>          كمصفوفة مثلثية علوية أو سفلية.
!>          = 'U':  مثلثية علوية، الشكل هو A = U*D*U**H؛
!>          = 'L':  مثلثية سفلية، الشكل هو A = L*D*L**H.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

A

!>          A هي مصفوفة COMPLEX، البعد (LDA,N)
!>          عند الإدخال، المصفوفة القطرية الجزئية D والمعاملات
!>          المستخدمة للحصول على العامل U أو L كما هو محسوب بواسطة CHETRF.
!>
!>          عند الخروج، إذا كان INFO = 0، معكوس المصفوفة الأصلية
!>          (الهيرميتية). إذا كان UPLO = 'U'، يتم تشكيل الجزء العلوي
!>          من المعكوس ولا يتم الرجوع إلى الجزء السفلي من A؛ إذا كان UPLO = 'L'
!>          يتم تشكيل الجزء السفلي من المعكوس ولا يتم الرجوع إلى الجزء العلوي
!>          من A.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

IPIV

!>          IPIV هي مصفوفة INTEGER، البعد (N)
!>          تفاصيل التبادلات والبنية الجزئية لـ D
!>          كما تم تحديدها بواسطة CHETRF.
!>

WORK

!>          WORK هي مصفوفة COMPLEX، البعد (N)
!>

INFO

!>          INFO هو INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، كان الوسيط i غير قانوني
!>          > 0: إذا كان INFO = i، D(i,i) = 0؛ المصفوفة مفردة ولا يمكن
!>               حساب معكوسها.
!>
