Function/Subroutine Documentation

Purpose:

chegvx computes the eigenvalues and eigenvectors of a complex Hermitian-definite generalized eigenvalue problem:

A*x = lambda*B*x

where A and B are Hermitian and B is positive-definite.

A possible improvement to the subroutine is to use the factorization of B by CHETRF if B is not positive definite.

Arguments:

ITYPE
CHARACTER*1.
Must be 1, 2, or 3.
  • If ITYPE = 1, compute the eigenvalues and eigenvectors for A*x = lambda*B*x.
  • If ITYPE = 2, compute the eigenvalues and eigenvectors for A*lambda*B*x.
  • If ITYPE = 3, compute the eigenvalues and eigenvectors for lambda*A*x = B*x.
JOBZ
CHARACTER*1.
= 'V': Compute the eigenvectors of A and B.
= 'N': Compute the eigenvalues of A and B only.
Unspecified.
RANGE
CHARACTER*1.
= 'A': all eigenvalues will be found.
= 'V': all eigenvalues in the half-open interval (VL, VU] will be found.
= 'I': the IL-th througth the IU-th eigenvalues will be found.
Unspecified.
UPLO
CHARACTER*1.
= 'U': Upper triangle of A and B will be used.
= 'L': Lower triangle of A and B will be used.
Unspecified.
N
INTEGER.
The order of the matrices A and B. N >= 0.
A
COMPLEX*16 array, dimension (LDA, N).
On entry, the upper or lower triangle of the Hermitian matrix A.
On exit, if JOBZ = 'F' or 'f', A is overwritten by values generated during the process.
LDA
INTEGER.
The leading dimension of A. LDA >= max(1, N).
B
COMPLEX*16 array, dimension (LDB, N).
On entry, the upper or lower triangle of the Hermitian matrix B.
If UPLO = 'U' or 'L', B must have the same UPLO configuration as A.
On exit, if JOBZ = 'F' or 'f', B is overwritten by values generated during the process.
LDB
INTEGER.
The leading dimension of B. LDB >= max(1, N).
VL
DOUBLE PRECISION.
If RANGE = 'V', the lower bound of the interval for the desired eigenvalues.
VU
DOUBLE PRECISION.
If RANGE = 'V', the upper bound of the interval for the desired eigenvalues.
IL
INTEGER.
If RANGE = 'I', the index of the first desired eigenvalue, where 1 <= IL <= IU.
IU
INTEGER.
If RANGE = 'I', the index of the last desired eigenvalue, where IL <= IU <= N.
ABSTOL
DOUBLE PRECISION.
The absolute error tolerance for the eigenvalues.
If ABSTOL <= 0, ADAPTIVE strategy is used.
M
INTEGER.
The total number of eigenvalues found.
If RANGE = 'A', M = N.
If RANGE = 'I' or 'V', 0 <= M <= N.
W
DOUBLE PRECISION array, dimension (N).
The computed eigenvalues, in the following order:
If RANGE = 'A', W is sorted in ascending order.
If RANGE = 'I' or 'V', W(1:M) contains the computed eigenvalues.
Z
COMPLEX*16 array, dimension (LDZ, max(1, M)).
If JOBZ = 'V', then the approximate eigenvectors, normalized and orthogonalized. The K-th column of Z contains the eigenvector corresponding to the K-th eigenvalue in the array W.
If JOBZ = 'N', then Z is not accessed.
LDZ
INTEGER.
The leading dimension of Z. LDZ >= max(1, N).
WORK
COMPLEX*16 array, dimension (LWORK).
On exit, WORK(1) contains the optimal LWORK.
LWORK
INTEGER.
The dimension of the array WORK. LWORK = -1 or LWORK >= (NB+1)*N,
where NB is the blocksize for CHETRD returned by ILAENV.
If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.
RWORK
DOUBLE PRECISION array, dimension (7*N)
IWORK
INTEGER array, dimension (5*N)
IFAIL
INTEGER array, dimension (N)
If JOBZ = 'V', then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge.
If JOBZ = 'N', then IFAIL is not referenced.
INFO
INTEGER.
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value
> 0: CPOTRF or CHEEVX returned an error code:
<= N: if INFO = i, CHEEVX failed to converge;
i eigenvectors failed to converge. Their indices are stored in array IFAIL.
> N: if INFO = N + i, for 1 <= i <= N, then the leading principal minor of order i of B is not positive. The factorization of B could not be completed and no eigenvalues or eigenvectors were computed.
