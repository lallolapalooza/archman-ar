توثيق الوظيفة/الروتين الفرعي

subroutine chpcon (character uplo, integer n, complex, dimension( * ) ap, integer, dimension( * ) ipiv, real anorm, real rcond, complex, dimension( * ) work, integer info)

CHPCON

الغرض:

!>
!> CHPCON تقدر المقلوب لرقم الشرط لمصفوفة هرمية معقدة A باستخدام التحلل A = U*D*U**H أو
!> A = L*D*L**H الذي تم حسابه بواسطة CHPTRF.
!>
!> يتم الحصول على تقدير لـ norm(inv(A))، ويتم حساب مقلوب رقم الشرط على أنه RCOND = 1 / (ANORM * norm(inv(A))).
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت تفاصيل التحلل مخزنة
!>          كمصفوفة مثلثية علوية أو سفلية.
!>          = 'U':  مثلثية علوية، الشكل هو A = U*D*U**H؛
!>          = 'L':  مثلثية سفلية، الشكل هو A = L*D*L**H.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          المصفوفة القطرية الفرعية D والمعاملات المستخدمة
!>          للحصول على العامل U أو L كما تم حسابه بواسطة CHPTRF، مخزنة كـ
!>          مصفوفة مثلثية معبأة.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          تفاصيل التبادلات والبنية الفرعية لـ D
!>          كما تم تحديدها بواسطة CHPTRF.
!>

ANORM

!>          ANORM is REAL
!>          المعيار 1 للمصفوفة الأصلية A.
!>

RCOND

!>          RCOND is REAL
!>          مقلوب رقم شرط المصفوفة A،
!>          محسوب على أنه RCOND = 1/(ANORM * AINVNM)، حيث AINVNM هو
!>          تقدير للمعيار 1 لـ inv(A) محسوب في هذا الروتين.
!>

WORK

!>          WORK is COMPLEX array, dimension (2*N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت لها قيمة غير قانونية
!>
