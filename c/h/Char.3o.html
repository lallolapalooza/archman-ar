عمليات الحروف.

الحروف هي عناصر قيم string و bytes. تمثل الحروف وحدات بايت، أي عدد صحيح في النطاق [ 0x00 ; 0xFF ].

تقوم بعض وظائف هذه الوحدة بتفسير الحروف في النطاق [ 0x00 ; 0x7F ] كحروف في مجموعة أحرف ASCII.

الحروف

type t = char

اسم مستعار لنوع الحروف.

val code : char -> int

إرجاع الرمز العددي للحرف.

val chr : int -> char

إرجاع الحرف بالرمز العددي المعطى.

يثير Invalid_argument إذا كان الوسيط خارج النطاق [ 0x00 ; 0xFF ].

val escaped : char -> string

إرجاع سلسلة نصية تمثل الحرف المعطى، مع تهريب الأحرف الخاصة وفقًا للاصطلاحات المعجمية لـ OCaml. يتم تهريب جميع الأحرف خارج نطاق ASCII القابل للطباعة [ 0x20 ; 0x7E ]، وكذلك الشرطة المائلة العكسية، علامة الاقتباس المزدوجة، وعلامة الاقتباس المفردة.

منذ 4.03

حروف ASCII

module Ascii : sig end

دعم مجموعة أحرف ASCII.

تعطي هذه الوظائف معنى للأعداد الصحيحة [ 0x00 ; 0x7F ] في مجموعة أحرف ASCII.

نظرًا لأن ترميز UTF-8 لـ Unicode له نفس الترميز ودلالات الأحرف (U+0000 إلى U+001F) لهذه البايتات، يمكن استخدام الوظائف بأمان على عناصر قيم string و bytes المشفرة بـ UTF-8. ومع ذلك، تتعامل الوظائف فقط مع الأمور المتعلقة بـ ASCII. على سبيل المثال، مفهوم المسافات البيضاء في Unicode أكبر بكثير من المسافات البيضاء في ASCII التي تحددها Char.Ascii.is_white.
