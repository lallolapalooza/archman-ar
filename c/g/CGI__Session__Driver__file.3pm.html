CGI__Session__Driver__file(3pm)

الحزمة: perl-cgi-session

التراخيص: GPL, PerlArtistic

CGI::Session::Driver::file(3) وثائق Perl مساهمة من المستخدم CGI::Session::Driver::file(3)

الاسم

CGI::Session::Driver::file - مشغل CGI::Session الافتراضي

الملخص

$s = CGI::Session->new();
$s = CGI::Session->new("driver:file", $sid);
$s = CGI::Session->new("driver:file", $sid, {Directory=>'/tmp'});

الوصف

عند إنشاء كائن CGI::Session بدون تحديد driver بشكل صريح، سيتم افتراض file. سيقوم مشغل file بتخزين بيانات الجلسة في ملفات عادية، حيث يتم تخزين كل جلسة في ملف منفصل.

يتم تعريف اصطلاحات تسمية ملفات الجلسة بواسطة المتغير العام $CGI::Session::Driver::file::FileName. القيمة الافتراضية لهذا المتغير هي cgisess_%s، حيث سيتم استبدال %s بمعرف الجلسة المقابل. إذا كنت ترغب في تعيين قالب FileName الخاص بك، فقم بذلك قبل طلب كائن الجلسة:

use CGI::Session::Driver::file; # هذا السطر إلزامي.
# الوقت يمر...
$CGI::Session::Driver::file::FileName = "%s.dat";
$s = CGI::Session->new();

للتوافق مع الإصدارات السابقة 3.x، يمكنك أيضًا استخدام اسم المتغير $CGI::Session::File::FileName، والذي سيتجاوز المتغير المذكور أعلاه.

وسائط المشغل

إذا كنت ترغب في تحديد دليل للجلسة، استخدم خيار Directory، الذي يحدد موقع الدليل حيث سيتم الاحتفاظ بمعرفات الجلسة. إذا لم يتم تعيين Directory، فسيتم استخدام القيمة الافتراضية التي يوفرها File::Spec->tmpdir(). لذلك، فإن الأسطر الثلاثة في قسم الملخص من هذه الوثيقة تنتج نفس النتيجة على جهاز يعمل بنظام UNIX.

إذا كان الدليل المحدد Directory غير موجود، فسيتم إنشاء التسلسل الهرمي للدليل الضروري.

افتراضيًا، يتم إنشاء الجلسات باستخدام umask بقيمة 0660. إذا كنت ترغب في تغيير umask للجلسة، قم بتمرير خيار UMask مع تمثيل ثماني للـ umask الذي تريده لتلك الجلسة.

ملاحظات

إذا كان نظام التشغيل الخاص بك لا يدعم flock، فيجب أن تفهم مخاطر العمل بدون قفل ملفات الجلسة. نظرًا لأن الجلسات تميل إلى الاستخدام في بيئات قد تحدث فيها حالات سباق بسبب الوصول المتزامن للملفات بواسطة عمليات مختلفة، فإن القفل يعتبر شيئًا جيدًا وضروريًا للغاية. إذا كنت لا تزال ترغب في استخدام هذا المشغل ولكنك لا تريد flock، فقم بتعيين $CGI::Session::Driver::file::NoFlock إلى 1 أو قم بتمرير "NoFlock => 1" وسيعمل هذا المشغل بدون أقفال.
