توثيق الوظيفة/الإجراء الفرعي

subroutine cgtt05 (character trans, integer n, integer nrhs, complex, dimension( * ) dl, complex, dimension( * ) d, complex, dimension( * ) du, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, complex, dimension( ldxact, * ) xact, integer ldxact, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) reslts)

CGTT05

الغرض:

!>
!> CGTT05 تختبر حدود الخطأ من التنقيح التكراري للحل المحسوب لنظام المعادلات
!> A*X = B، حيث A مصفوفة ثلاثية قطرية عامة من الرتبة n والعملية (op(A)) = A أو A**T،
!> اعتمادًا على TRANS.
!>
!> RESLTS(1) = اختبار حد الخطأ
!>           = norm(X - XACT) / ( norm(X) * FERR )
!>
!> قيمة كبيرة تُعاد إذا لم تكن هذه النسبة أقل من واحد.
!>
!> RESLTS(2) = المتبقي من إجراء التنقيح التكراري
!>           = الحد الأقصى لـ BERR / ( NZ*EPS + (*) )، حيث
!>             (*) = NZ*UNFL / (min_i (abs(op(A))*abs(X) +abs(b))_i )
!>             و NZ = الحد الأقصى لعدد العناصر غير الصفرية في أي صف من A، بالإضافة إلى 1
!>

المعلمات

TRANS 
!>          TRANS is CHARACTER*1
!>          يحدد شكل نظام المعادلات.
!>          = 'N':  A * X = B     (بدون تبديل)
!>          = 'T':  A**T * X = B  (تبديل)
!>          = 'C':  A**H * X = B  (تبديل مترافق = تبديل)
!>

N

!>          N is INTEGER
!>          عدد الصفوف في المصفوفات X و XACT.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          عدد الأعمدة في المصفوفات X و XACT.  NRHS >= 0.
!>

DL

!>          DL is COMPLEX array, dimension (N-1)
!>          العناصر الفرعية القطرية (n-1) للمصفوفة A.
!>

D

!>          D is COMPLEX array, dimension (N)
!>          العناصر القطرية للمصفوفة A.
!>

DU

!>          DU is COMPLEX array, dimension (N-1)
!>          العناصر فوق القطرية (n-1) للمصفوفة A.
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          متجهات الطرف الأيمن لنظام المعادلات الخطية.
!>

LDB

!>          LDB is INTEGER
!>          البعد الرائد للمصفوفة B.  LDB >= max(1,N).
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          متجهات الحل المحسوبة. يتم تخزين كل متجه كعمود في المصفوفة X.
!>

LDX

!>          LDX is INTEGER
!>          البعد الرائد للمصفوفة X.  LDX >= max(1,N).
!>

XACT

!>          XACT is COMPLEX array, dimension (LDX,NRHS)
!>          متجهات الحل الدقيقة. يتم تخزين كل متجه كعمود في المصفوفة XACT.
!>

LDXACT

!>          LDXACT is INTEGER
!>          البعد الرائد للمصفوفة XACT.  LDXACT >= max(1,N).
!>

FERR

!>          FERR is REAL array, dimension (NRHS)
!>          تقديرات حدود الخطأ الأمامي لكل متجه حل X. إذا كان XTRUE هو الحل الحقيقي،
!>          فإن FERR يحد من حجم أكبر عنصر في (X - XTRUE) مقسومًا على حجم أكبر عنصر
!>          في X.
!>

BERR

!>          BERR is REAL array, dimension (NRHS)
!>          الخطأ الخلفي النسبي المكون لكل متجه حل (أي، أصغر تغيير نسبي في أي عنصر
!>          من A أو B يجعل X حلًا دقيقًا).
!>

RESLTS

!>          RESLTS is REAL array, dimension (2)
!>          الحد الأقصى لمتجهات الحل NRHS للنسب التالية:
!>          RESLTS(1) = norm(X - XACT) / ( norm(X) * FERR )
!>          RESLTS(2) = BERR / ( NZ*EPS + (*) )
!>
