توثيق الوظيفة/الروتين الفرعي

subroutine cgebal (character job, integer n, complex, dimension( lda, * ) a, integer lda, integer ilo, integer ihi, real, dimension( * ) scale, integer info)

CGEBAL

الغرض:

!>
!> CGEBAL توازن مصفوفة معقدة عامة A. يتضمن ذلك، أولاً،
!> إعادة ترتيب A عبر تحويل تشابه لعزل القيم الذاتية
!> في العناصر من 1 إلى ILO-1 ومن IHI+1 إلى N على
!> القطر؛ وثانياً، تطبيق تحويل تشابه قطري
!> للصفوف والأعمدة ILO إلى IHI لجعل الصفوف والأعمدة
!> متقاربة في المعيار قدر الإمكان. كلا الخطوتين اختياريتان.
!>
!> قد يؤدي التوازن إلى تقليل معيار 1 للمصفوفة، وتحسين
!> دقة القيم الذاتية و/أو المتجهات الذاتية المحسوبة.
!>

المعلمات

JOB 
!>          JOB هو CHARACTER*1
!>          يحدد العمليات التي سيتم تنفيذها على A:
!>          = 'N':  لا شيء:  ببساطة تعيين ILO = 1، IHI = N، SCALE(I) = 1.0
!>                  لـ i = 1,...,N؛
!>          = 'P':  إعادة ترتيب فقط؛
!>          = 'S':  قياس فقط؛
!>          = 'B':  كلاهما إعادة ترتيب وقياس.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A. N >= 0.
!>

A

!>          A هي مصفوفة COMPLEX، البعد (LDA,N)
!>          عند الدخول، المصفوفة A المدخلة.
!>          عند الخروج، يتم استبدال A بالمصفوفة المتوازنة.
!>          إذا كان JOB = 'N'، لا يتم الرجوع إلى A.
!>          انظر التفاصيل الإضافية.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرائد للمصفوفة A. LDA >= max(1,N).
!>

ILO

!>          ILO هو INTEGER
!>

IHI

!>          IHI هو INTEGER
!>          يتم تعيين ILO و IHI إلى أعداد صحيحة بحيث عند الخروج
!>          A(i,j) = 0 إذا كان i > j و j = 1,...,ILO-1 أو I = IHI+1,...,N.
!>          إذا كان JOB = 'N' أو 'S'، فإن ILO = 1 و IHI = N.
!>

SCALE

!>          SCALE هي مصفوفة REAL، البعد (N)
!>          تفاصيل التباديل وعوامل القياس المطبقة على
!>          A. إذا كان P(j) هو فهرس الصف والعمود المتناوبين
!>          مع الصف والعمود j وعامل القياس D(j)
!>          المطبق على الصف والعمود j، فإن
!>          SCALE(j) = P(j)    لـ j = 1,...,ILO-1
!>                   = D(j)    لـ j = ILO,...,IHI
!>                   = P(j)    لـ j = IHI+1,...,N.
!>          ترتيب التبادلات هو N إلى IHI+1،
!>          ثم 1 إلى ILO-1.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح.
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت قيمة غير قانونية.
!>

تفاصيل إضافية:

!>
!>  تتكون التباديل من تبديلات الصفوف والأعمدة التي تضع
!>  المصفوفة في الشكل
!>
!>             ( T1   X   Y  )
!>     P A P = (  0   B   Z  )
!>             (  0   0   T2 )
!>
!>  حيث T1 و T2 مصفوفتان مثلثيتان علويتان تقع قيمهما الذاتية
!>  على طول القطر. تحدد فهارس الأعمدة ILO و IHI بداية
!>  ونهاية المصفوفة الفرعية B. يتكون التوازن من تطبيق
!>  تحويل تشابه قطري inv(D) * B * D لجعل
!>  معايير 1 لكل صف من B وعموده المقابل متساوية تقريبًا.
!>  المصفوفة الخارجة هي
!>
!>     ( T1     X*D          Y    )
!>     (  0  inv(D)*B*D  inv(D)*Z ).
!>     (  0      0           T2   )
!>
!>  تتم إرجاع معلومات حول التباديل P والمصفوفة القطرية D
!>  في المتجه SCALE.
!>
!>  يعتمد هذا الروتين الفرعي على روتين EISPACK CBAL.
!>
!>  تم تعديله بواسطة Tzu-Yi Chen، قسم علوم الكمبيوتر، جامعة
!>    كاليفورنيا في بيركلي، الولايات المتحدة الأمريكية
!>
!>  تمت إعادة هيكلته بواسطة Evert Provoost، قسم علوم الكمبيوتر،
!>    KU Leuven، بلجيكا
!>
