NAME

cgesvd - compute the singular value decomposition of a complex matrix

SYNOPSIS

SUBROUTINE CGESVD(
 JOBU, JOBV, M, N, A, LDA, S, U, LDU, V, LDV, WORK, LWORK, RWORK, INFO
)
    CHARACTER * 1 JOBU, JOBV
    INTEGER M, N, LDA, LDU, LDV, LWORK, INFO
    REAL S( * )
    COMPLEX A( LDA, * ), U( LDU, * ), V( LDV, * )
    REAL RWORK( * )
    COMPLEX WORK( * )

Function/Subroutine Documentation

CGESVD computes the singular value decomposition (SVD) of a complex matrix A:

A = U * S * V**H

where S is a real diagonal matrix with non-negative real numbers s(i) on the diagonal (the singular values), and U and V are unitary matrices.

V**H denotes the conjugate transpose of V.

Parameters

  • JOBU (CHARACTER*1)
  • JOBV (CHARACTER*1)
  • M (INTEGER)
  • N (INTEGER)
  • A (COMPLEX array, dimension (LDA,N))
  • LDA (INTEGER)
  • S (REAL array, dimension (min(M,N)))
  • U (COMPLEX array, dimension (LDU,k))
  • LDU (INTEGER)
  • V (COMPLEX array, dimension (LDV,k))
  • LDV (INTEGER)
  • WORK (COMPLEX array, dimension (LWORK))
  • LWORK (INTEGER)
  • RWORK (REAL array, dimension (lrwork))
  • INFO (INTEGER)

Description

JOBU specifies the form of the decomposition of U:

  • 'A' = all M columns of U are computed.
  • 'S' = the first min(M,N) columns of U are computed.
  • 'O' = the first min(M,N) columns of U are computed, and then overwritten in A.
  • 'N' = U is not computed.

JOBV specifies the form of the decomposition of V: 'A', 'S', 'O', 'N'.

M is the number of rows of A.

N is the number of columns of A.

LDA is the leading dimension of A.

S contains the singular values of A, sorted in descending order.

U is a unitary matrix. The dimension of U depends on JOBU.

LDU is the leading dimension of U.

V is a unitary matrix. The dimension of V depends on JOBV.

LDV is the leading dimension of V.

WORK is a complex workspace array. The size of WORK depends on LWORK.

LWORK is the dimension of the array WORK. LWORK >= max(1,2*min(M,N)). If LWORK = -1, then LWORK is determined automatically and the workspace is not used.

RWORK is a real workspace array. The dimension of RWORK depends on the algorithm used.

INFO is an integer output variable. If INFO = 0, the execution has been completed successfully. If INFO < 0, the i-th parameter had an illegal value.
