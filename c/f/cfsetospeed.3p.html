CFSETOSPEED(3P) دليل مبرمجي POSIX CFSETOSPEED(3P)

PROLOG

هذه الصفحة الدليلية جزء من دليل مبرمجي POSIX. قد يختلف تنفيذ هذا الواجهة في Linux (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا يتم تنفيذ الواجهة في Linux.

NAME

cfsetospeed — تعيين معدل الباود للإخراج

SYNOPSIS

#include <termios.h>
int cfsetospeed(struct termios *termios_p, speed_t speed);

DESCRIPTION

تقوم الدالة cfsetospeed() بتعيين معدل الباود للإخراج المخزن في الهيكل الذي يشير إليه termios_p إلى speed.

لن يكون هناك أي تأثير على معدلات الباود المعينة في الجهاز حتى يتم استدعاء tcsetattr() بنجاح بنفس الهيكل termios. وبالمثل، فإن الأخطاء الناتجة عن محاولات تعيين معدلات الباود التي لا يدعمها جهاز الطرفية لا يلزم اكتشافها حتى يتم استدعاء الدالة tcsetattr().

RETURN VALUE

عند اكتمالها بنجاح، تعيد الدالة cfsetospeed() القيمة 0؛ وإلا، فإنها تعيد -1 وقد يتم تعيين errno للإشارة إلى الخطأ.

ERRORS

قد تفشل الدالة cfsetospeed() إذا:

EINVAL
قيمة speed ليست معدل باود صالح.
EINVAL
قيمة speed خارج نطاق قيم السرعة الممكنة كما هو محدد في <termios.h>.
