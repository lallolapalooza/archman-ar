cfree(3) دليل دوال المكتبة cfree(3)

الاسم

cfree - تحرير الذاكرة المخصصة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <stdlib.h>
/* في SunOS 4 */
int cfree(void *ptr);
/* في glibc أو FreeBSD libcompat */
void cfree(void *ptr);
/* في SCO OpenServer */
void cfree(unsigned int n, unsigned int size;
           char ptr[size * n], unsigned int n, unsigned int size);
/* في Solaris watchmalloc.so.1 */
void cfree(size_t n, size_t size;
           void ptr[size * n], size_t n, size_t size);
متطلبات ميزة الاختبار Macro لـ glibc (انظر feature_test_macros(7)):

cfree():

    منذ glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 والإصدارات الأقدم:
        _BSD_SOURCE || _SVID_SOURCE

الوصف

يجب عدم استخدام هذه الدالة أبداً. استخدم free(3) بدلاً منها. بدءاً من glibc 2.26، تم إزالتها من glibc.

cfree بحجة واحدة

في glibc، الدالة cfree() هي مرادف لـ free(3)، "تمت إضافتها للتوافق مع SunOS".

الأنظمة الأخرى لديها دوال أخرى بهذا الاسم. التعريف يكون أحياناً في <stdlib.h> وأحياناً في <malloc.h>.

cfree بثلاث حجج

بعض إصدارات SCO و Solaris لديها مكتبات malloc مع cfree() بثلاث حجج، ويبدو أنها نظير لـ calloc(3).

إذا احتجت إليها أثناء نقل شيء ما، أضف


#define cfree(p, n, s) free((p))

إلى ملفك.

سؤال شائع هو "هل يمكنني استخدام free(3) لتحرير الذاكرة المخصصة بـ calloc(3)، أم أحتاج إلى cfree؟". الإجابة: استخدم free(3).

دليل SCO يكتب: "تم توفير الروتين cfree للامتثال للمعيار iBCSe2 ويستدعي ببساطة free. لا يتم استخدام وسيطي n و size لـ cfree."

قيمة الإرجاع

إصدار SunOS من cfree() (وهو مرادف لـ free(3)) يعيد 1 عند النجاح و 0 عند الفشل. في حالة حدوث خطأ، يتم تعيين errno إلى EINVAL: قيمة ptr لم تكن مؤشراً إلى كتلة تم تخصيصها سابقاً بواسطة إحدى الروتينات في عائلة malloc(3).

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
cfree () سلامة الخيوط MT-Safe /* في glibc */

الإصدارات

إصدار cfree() بثلاث حجج كما تستخدمه SCO يتوافق مع معيار iBCSe2: Intel386 Binary Compatibility Specification, Edition 2.

المعايير

لا شيء.
