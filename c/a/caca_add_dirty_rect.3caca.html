وصف تفصيلي

تعالج هذه الوظائف المستطيلات المتسخة للرسم الأمثل.

توثيق الوظائف

__extern int caca_disable_dirty_rect (caca_canvas_t * cv)

تعطيل معالجة المستطيلات المتسخة لجميع استدعاءات رسومات libcaca. هذا مفيد عندما يحتاج التطبيق المتصل إلى إجراء عمليات بطيئة ضمن منطقة معروفة. فقط قم باستدعاء caca_add_dirty_rect() بعد ذلك.

هذه الوظيفة متكررة. يتم إعادة تمكين المستطيلات المتسخة فقط عندما يتم استدعاء caca_enable_dirty_rect() بنفس العدد من المرات.

هذه الوظيفة لا تفشل أبداً.

المعلمات

cv لوحة libcaca.

يعيد

هذه الوظيفة تعيد دائماً 0.

__extern int caca_enable_dirty_rect (caca_canvas_t * cv)

يمكن استدعاء هذه الوظيفة فقط بعد استدعاء caca_disable_dirty_rect().

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL لم يتم تعطيل المستطيلات المتسخة.

المعلمات

cv لوحة libcaca.

يعيد

0 في حالة النجاح، -1 إذا حدث خطأ.

__extern int caca_get_dirty_rect_count (caca_canvas_t * cv)

الحصول على عدد المستطيلات المتسخة في اللوحة. المستطيلات المتسخة هي مناطق تحتوي على خلايا تغيرت منذ آخر إعادة تعيين.

تستخدم برامج تشغيل العرض المستطيلات المتسخة داخليًا لتحسين العرض عن طريق تجنب إعادة رسم الشاشة بأكملها. بمجرد أن يقوم برنامج تشغيل العرض بعرض اللوحة، فإنه يعيد تعيين قائمة المستطيلات المتسخة.

يضمن عدم تداخل المستطيلات المتسخة.

هذه الوظيفة لا تفشل أبداً.

المعلمات

cv لوحة libcaca.

يعيد

عدد المستطيلات المتسخة في اللوحة المعطاة.

__extern int caca_get_dirty_rect (caca_canvas_t * cv, int r, int * x, int * y, int * width, int * height)

الحصول على إحداثيات المستطيل المتسخ المعطى للوحة. يجب أن يكون الفهرس ضمن عدد المستطيلات المتسخة. انظر caca_get_dirty_rect_count() لمعرفة كيفية حساب هذا العدد.

إذا حدث خطأ، لا يتم كتابة أي إحداثيات في وسيطات المؤشر، ويتم إرجاع -1، ويتم تعيين errno وفقًا لذلك:

•
EINVAL فهرس المستطيل المحدد خارج الحدود.

المعلمات

cv لوحة libcaca.
r فهرس المستطيل المطلوب.
x مؤشر إلى عدد صحيح حيث سيتم تخزين الحافة اليسرى للمستطيل المتسخ.
y مؤشر إلى عدد صحيح حيث سيتم تخزين الحافة العلوية للمستطيل المتسخ.
width مؤشر إلى عدد صحيح حيث سيتم تخزين عرض المستطيل المتسخ.
height مؤشر إلى عدد صحيح حيث سيتم تخزين ارتفاع المستطيل المتسخ.

يعيد

0 في حالة النجاح، -1 إذا حدث خطأ.

__extern int caca_add_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

إضافة منطقة إبطال صلاحية إلى قائمة المستطيلات المتسخة للوحة. لمزيد من المعلومات حول المستطيلات المتسخة، انظر caca_get_dirty_rect().

قد تكون هذه الوظيفة مفيدة لفرض تحديث لمنطقة معينة من اللوحة حتى لو أشارت تتبع المستطيلات المتسخة إلى أنها لم تتغير. قد يحدث هذا إذا تم تعديل محتويات اللوحة مباشرة.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL إحداثيات المستطيل المحدد خارج الحدود.

المعلمات

cv لوحة libcaca.
x الحافة اليسرى للمستطيل المتسخ الإضافي.
y الحافة العلوية للمستطيل المتسخ الإضافي.
width عرض المستطيل المتسخ الإضافي.
height ارتفاع المستطيل المتسخ الإضافي.

يعيد

0 في حالة النجاح، -1 إذا حدث خطأ.

تمت الإشارة إليها بواسطة caca_blit()، caca_clear_canvas()، caca_fill_box()، caca_flip()، caca_flop()، caca_free_frame()، caca_invert()، caca_put_attr()، caca_put_char()، caca_rotate_180()، caca_rotate_left()، caca_rotate_right()، caca_set_canvas_boundaries()، caca_set_frame()، caca_stretch_left()، و caca_stretch_right().

__extern int caca_remove_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

وضع علامة على منطقة خلايا في اللوحة على أنها ليست متسخة. لمزيد من المعلومات حول المستطيلات المتسخة، انظر caca_get_dirty_rect().

القيم التي تكون فيها xmin > xmax أو ymin > ymax تشير إلى أن المستطيل المتسخ فارغ. سيتم تجاهلها بصمت.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL إحداثيات المستطيل المحدد خارج الحدود.

y الحافة العلوية للمستطيل النظيف.
width عرض المستطيل النظيف.
height ارتفاع المستطيل النظيف.

يعيد

0 في حالة النجاح، -1 إذا حدث خطأ.
