الوصف التفصيلي

تقوم هذه الوظائف بالتعامل مع المستطيلات المتسخة لتحسين عملية الرسم.

توثيق الوظائف

__extern int caca_disable_dirty_rect (caca_canvas_t * cv)

تعطيل التعامل مع المستطيلات المتسخة لجميع استدعاءات الرسوميات في libcaca. هذا مفيد عندما يحتاج التطبيق المتصل إلى القيام بعمليات بطيئة ضمن منطقة معروفة. ما عليك سوى استدعاء caca_add_dirty_rect() بعد ذلك.

هذه الوظيفة تكرارية. يتم إعادة تمكين المستطيلات المتسخة فقط عند استدعاء caca_enable_dirty_rect() بنفس العدد من المرات.

هذه الوظيفة لا تفشل أبدًا.

المعاملات

cv لوحة libcaca.

الإرجاع

تعيد هذه الوظيفة 0 دائمًا.

__extern int caca_enable_dirty_rect (caca_canvas_t * cv)

يمكن استدعاء هذه الوظيفة فقط بعد استدعاء caca_disable_dirty_rect().

في حالة حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL لم يتم تعطيل المستطيلات المتسخة.

الإرجاع

0 في حالة النجاح، -1 في حالة حدوث خطأ.

__extern int caca_get_dirty_rect_count (caca_canvas_t * cv)

الحصول على عدد المستطيلات المتسخة في لوحة. المستطيلات المتسخة هي مناطق تحتوي على خلايا تغيرت منذ آخر إعادة تعيين.

تستخدم برامج تشغيل العرض المستطيلات المتسخة داخليًا لتحسين عملية العرض عن طريق تجنب إعادة رسم الشاشة بأكملها. بمجرد عرض برنامج تشغيل العرض للوحة، فإنه يعيد تعيين قائمة المستطيلات المتسخة.

من المضمون ألا تتداخل المستطيلات المتسخة.

هذه الوظيفة لا تفشل أبدًا.

المعاملات

cv لوحة libcaca.

الإرجاع

عدد المستطيلات المتسخة في اللوحة المعطاة.

__extern int caca_get_dirty_rect (caca_canvas_t * cv, int r, int * x, int * y, int * width, int * height)

الحصول على إحداثيات المستطيل المتسخ المحدد للوحة. يجب أن يكون الفهرس ضمن عدد المستطيلات المتسخة. انظر caca_get_dirty_rect_count() لكيفية حساب هذا العدد.

في حالة حدوث خطأ، لا يتم كتابة أي إحداثيات في وسيطات المؤشر، ويتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL فهرس المستطيل المحدد خارج الحدود.

المعاملات

cv لوحة libcaca.
r فهرس المستطيل المطلوب.
x مؤشر إلى عدد صحيح سيتم تخزين الحافة اليسرى للمستطيل المتسخ فيه.
y مؤشر إلى عدد صحيح سيتم تخزين الحافة العلوية للمستطيل المتسخ فيه.
width مؤشر إلى عدد صحيح سيتم تخزين عرض المستطيل المتسخ فيه.
height مؤشر إلى عدد صحيح سيتم تخزين ارتفاع المستطيل المتسخ فيه.

الإرجاع

0 في حالة النجاح، -1 في حالة حدوث خطأ.

__extern int caca_add_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

إضافة منطقة غير صالحة إلى قائمة المستطيلات المتسخة للوحة. لمزيد من المعلومات حول المستطيلات المتسخة، انظر caca_get_dirty_rect().

قد تكون هذه الوظيفة مفيدة لفرض تحديث منطقة معينة من اللوحة حتى لو كان تتبع المستطيلات المتسخة يشير إلى أنها لم تتغير. قد يحدث هذا إذا تم تعديل محتويات اللوحة مباشرة.

في حالة حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL إحداثيات المستطيل المحددة خارج الحدود.

المعاملات

y الحافة العلوية للمستطيل المتسخ الإضافي.
width عرض المستطيل المتسخ الإضافي.
height ارتفاع المستطيل المتسخ الإضافي.

الإرجاع

0 في حالة النجاح، -1 في حالة حدوث خطأ.

تم الإشارة إليها بواسطة caca_blit()، caca_clear_canvas()، caca_fill_box()، caca_flip()، caca_flop()، caca_free_frame()، caca_invert()، caca_put_attr()، caca_put_char()، caca_rotate_180()، caca_rotate_left()، caca_rotate_right()، caca_set_canvas_boundaries()، caca_set_frame()، caca_stretch_left()، و caca_stretch_right().

__extern int caca_remove_dirty_rect (caca_canvas_t * cv, int x, int y, int width, int height)

وضع علامة على منطقة خلايا في اللوحة على أنها غير متسخة. لمزيد من المعلومات حول المستطيلات المتسخة، انظر caca_get_dirty_rect().

القيم التي يكون فيها xmin > xmax أو ymin > ymax تشير إلى أن المستطيل المتسخ فارغ. سيتم تجاهلها بصمت.

في حالة حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL إحداثيات المستطيل المحددة خارج الحدود.
