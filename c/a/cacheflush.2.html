cacheflush(2) دليل استدعاءات النظام cacheflush(2)

الاسم

cacheflush - مسح محتويات ذاكرة التخزين المؤقت للتعليمات و/أو البيانات

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/cachectl.h>
int cacheflush(int nbytes;
               void addr[nbytes], int nbytes, int cache);

ملاحظة: على بعض البنيات، لا توجد لفة تغليف glibc لاستدعاء النظام هذا؛ انظر VERSIONS.

الوصف

يقوم cacheflush() بمسح محتويات ذاكرة التخزين المؤقت المشار إليها لعناوين المستخدم في النطاق addr إلى (addr+nbytes-1). يمكن أن تكون cache إحدى القيم التالية:

ICACHE
مسح ذاكرة التخزين المؤقت للتعليمات.
DCACHE
الكتابة إلى الذاكرة وإلغاء صلاحية أسطر ذاكرة التخزين المؤقت الصالحة المتأثرة.
BCACHE
نفس (ICACHE|DCACHE).

قيمة الإرجاع

يرجع cacheflush() القيمة 0 عند النجاح. عند حدوث خطأ، فإنه يرجع -1 ويعين errno للإشارة إلى الخطأ.

الأخطاء

EFAULT
بعض أو كل نطاق العنوان addr إلى (addr+nbytes-1) غير قابل للوصول.
EINVAL
cache ليست إحدى القيم ICACHE أو DCACHE أو BCACHE (لكن انظر BUGS).

الإصدارات

لا ينبغي استخدام cacheflush() في البرامج المخصصة لتكون قابلة للتوافق. في Linux، ظهر هذا الاستدعاء لأول مرة على بنية MIPS، ولكن في الوقت الحاضر، يوفر Linux استدعاء نظام cacheflush() على بعض البنيات الأخرى، ولكن مع وسائط مختلفة.

المتغيرات الخاصة بالبنية

توفر glibc لفة تغليف لاستدعاء النظام هذا، مع النموذج الأولي الموضح في SYNOPSIS، للبنيات التالية: ARC، CSKY، MIPS، و NIOS2.

على بعض البنيات الأخرى، يوفر Linux استدعاء النظام هذا، مع وسائط مختلفة:

M68K:
int cacheflush(unsigned long addr, int scope, int cache,
               unsigned long size);
SH:
int cacheflush(unsigned long addr, unsigned long size, int op);
NDS32:
int cacheflush(unsigned int start, unsigned int end, int cache);

على البنيات المذكورة أعلاه، لا توفر glibc لفة تغليف لاستدعاء النظام هذا؛ قم باستدعائه باستخدام syscall(2).

بديل GCC

ما لم تكن بحاجة إلى تحكم أدق يوفر استدعاء النظام هذا، فمن المحتمل أنك تريد استخدام الدالة المضمنة في GCC __builtin___clear_cache()، والتي توفر واجهة قابلة للتوافق عبر الأنظمة المدعومة من قبل GCC والمترجمات المتوافقة:


void __builtin___clear_cache(void *begin, void *end);

على المنصات التي لا تتطلب مسح ذاكرة التخزين المؤقت للتعليمات، فإن __builtin___clear_cache() ليس لها تأثير.

ملاحظة: على بعض المترجمات المتوافقة مع GCC، يستخدم النموذج الأولي لهذه الدالة المضمنة char * بدلاً من void * للمعلمات.

المعايير

تاريخيًا، كان استدعاء النظام هذا متاحًا في جميع متغيرات UNIX لـ MIPS بما في ذلك RISC/os، IRIX، Ultrix، NetBSD، OpenBSD، و FreeBSD (وأيضًا على بعض أنظمة التشغيل MIPS غير UNIX)، لذلك فإن وجود هذا الاستدعاء في أنظمة تشغيل MIPS هو معيار فعلي.

الأخطاء

تتجاهل أنوية Linux الأقدم من Linux 2.6.11 وسائط addr و nbytes، مما يجعل هذه الوظيفة مكلفة للغاية. لذلك، يتم دائمًا مسح ذاكرة التخزين المؤقت بالكامل.

تتصرف هذه الوظيفة دائمًا كما لو تم تمرير BCACHE كوسيط cache ولا تقوم بأي تدقيق للأخطاء على الوسيط cache.
