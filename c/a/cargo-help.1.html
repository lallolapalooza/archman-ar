cargo-help(1)

الحزمة: rust

التراخيص: Apache-2.0 OR MIT

CARGO-HELP(1) دليل الأوامر العامة CARGO-HELP(1)

الاسم

cargo-help — الحصول على مساعدة لأمر Cargo

الملخص

cargo help [أمر فرعي]

الوصف

يطبع رسالة مساعدة للأمر المحدد.

أمثلة

1. الحصول على مساعدة لأمر: 
cargo help build
2. المساعدة متاحة أيضًا باستخدام العلامة --help: 
cargo build --help
