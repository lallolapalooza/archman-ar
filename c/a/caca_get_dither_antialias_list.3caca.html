وصف تفصيلي

توفر هذه الوظائف روتينات عالية المستوى لتخصيص وعرض صور التحويل.

توثيق الوظائف

__extern caca_dither_t * caca_create_dither (int bpp, int w, int h, int pitch, uint32_t rmask, uint32_t gmask, uint32_t bmask, uint32_t amask)

إنشاء بنية تحويل من إحداثياتها (العمق، العرض، الارتفاع، والميل) وقيم قناع البكسل. إذا كان العمق 8 بت لكل بكسل، يتم تجاهل قيم القناع ويجب تعيين لوحة الألوان باستخدام الوظيفة caca_set_dither_palette(). بالنسبة للأعماق التي تزيد عن 8 بت لكل بكسل، يتسبب قناع ألفا صفر في تجاهل قيم ألفا.

إذا حدث خطأ، يتم إرجاع NULL ويتم تعيين errno وفقًا لذلك:

  • EINVAL كانت قيمة العرض أو الارتفاع أو الميل أو البتات لكل بكسل المطلوبة غير صالحة.
  • ENOMEM لا توجد ذاكرة كافية لتخصيص بنية التحويل.

المعلمات

bpp عمق الصورة النقطية بالبتات لكل بكسل.
w عرض الصورة النقطية بالبكسلات.
h ارتفاع الصورة النقطية بالبكسلات.
pitch ميل الصورة النقطية بالبايت.
rmask قناع البت لقيم الأحمر.
gmask قناع البت لقيم الأخضر.
bmask قناع البت لقيم الأزرق.
amask قناع البت لقيم ألفا.

الإرجاع

كائن التحويل عند النجاح، NULL في حالة حدوث خطأ.

__extern int caca_set_dither_palette (caca_dither_t * d, uint32_t red[], uint32_t green[], uint32_t blue[], uint32_t alpha[])

تعيين لوحة الألوان لصورة نقطية بعمق 8 بت لكل بكسل. يجب أن تكون القيم بين 0 و 4095 (0xfff).

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL قيمة البت لكل بكسل للتحويل ليست 8، أو كانت إحدى قيم البكسل خارج النطاق 0 - 4095.

المعلمات

d كائن التحويل.
red مصفوفة من 256 قيمة حمراء.
green مصفوفة من 256 قيمة خضراء.
blue مصفوفة من 256 قيمة زرقاء.
alpha مصفوفة من 256 قيمة ألفا.

الإرجاع

0 في حالة النجاح، -1 في حالة حدوث خطأ.

__extern int caca_dither_bitmap (caca_canvas_t * canvas, int x, int y, int width, int height, caca_dither_t const * dither, void const * bitmap)

تحويل صورة نقطية على اللوحة.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL قيمة x، y، width، height، أو dither كانت غير صالحة.
•
ENOMEM لا توجد ذاكرة كافية لتخصيص البيانات الوسيطة.

المعلمات

canvas كائن اللوحة.
x الإحداثي السيني للزاوية العلوية اليسرى للصورة النقطية على اللوحة.
y الإحداثي الصادي للزاوية العلوية اليسرى للصورة النقطية على اللوحة.
width عرض الصورة النقطية.
height ارتفاع الصورة النقطية.
dither كائن التحويل.
bitmap مؤشر إلى البيانات الخام للصورة النقطية.

الإرجاع

0 في حالة النجاح، -1 في حالة حدوث خطأ.
