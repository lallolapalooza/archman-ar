الوصف التفصيلي

توفر هذه الوظائف روتينات لمعالجة الخطوط النقطية ورسم اللوحات عالي الجودة إلى صور نقطية.

توثيق الوظائف

__extern caca_font_t * caca_load_font (void const * data, size_t size)

تقوم هذه الوظيفة بتحميل خط وإرجاع مقبض لبنيته الداخلية. يمكن بعد ذلك استخدام المقبض مع caca_render_canvas() للإخراج النقطي.

يمكن أيضًا تحميل الخطوط الداخلية: إذا تم تعيين الحجم إلى 0، فيجب أن تكون البيانات سلسلة نصية تحتوي على اسم الخط الداخلي.

إذا كان الحجم غير صفري، فسيتم تحميل بايتات الذاكرة بالحجم المحدد في العنوان data كخط. يجب ألا يتم تحرير هذه الذاكرة بواسطة البرنامج المستدعي حتى يتم تحرير مقبض الخط باستخدام caca_free_font().

إذا حدث خطأ، يتم إرجاع NULL ويتم تعيين errno وفقًا لذلك:

  • ENOENT الخط المدمج المطلوب غير موجود.
  • EINVAL بيانات خط غير صالحة في منطقة الذاكرة.
  • ENOMEM لا توجد ذاكرة كافية لتخصيص بنية الخط.

المعلمات

data منطقة الذاكرة التي تحتوي على الخط أو اسمه.
size حجم منطقة الذاكرة، أو 0 إذا تم تقديم اسم الخط.

الإرجاع

مقبض خط أو NULL في حالة حدوث خطأ.

مراجع caca_load_font().

يشار إليه بواسطة caca_load_font().

هذه الوظيفة لا تفشل أبدًا.

الإرجاع

الارتفاع القياسي للحرف.

__extern uint32_t const * caca_get_font_blocks (caca_font_t const * f)

تقوم هذه الوظيفة بإرجاع قائمة بكتل Unicode التي يدعمها الخط المحدد. القائمة هي قائمة منتهية بالصفر للفهارس. هذا مثال:

{
   0x0000, 0x0080,   // اللاتينية الأساسية: A, B, C, a, b, c
   0x0080, 0x0100,   // ملحق لاتيني-1: "A, 'e, ^u
   0x0530, 0x0590,   // الأرمنية
   0x0000, 0x0000,   // نهاية
};

هذه الوظيفة لا تفشل أبدًا.

المعلمات

f الخط، كما تم إرجاعه بواسطة caca_load_font()

الإرجاع

قائمة كتل Unicode التي يدعمها الخط.

__extern int caca_render_canvas (caca_canvas_t const * cv, caca_font_t const * f, void * buf, int width, int height, int pitch)

تقوم هذه الوظيفة بتصيير اللوحة المعطاة على مخزن مؤقت للصور باستخدام خط محدد. تنسيق البكسل ثابت (ARGB 32 بت، 8 بت لكل مكون).

يمكن حساب عرض الصورة المطلوب باستخدام caca_get_canvas_width() و caca_get_font_width(). يمكن حساب الارتفاع المطلوب باستخدام caca_get_canvas_height() و caca_get_font_height().

الحروف التي لا تتناسب مع مخزن مؤقت للصورة لا يتم تصييرها حاليًا على الإطلاق. قد يتم قصها بدلاً من ذلك في الإصدارات المستقبلية.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL العرض أو الارتفاع أو المسافة المحددة غير صالحة.

المعلمات

cv اللوحة المراد تصييرها
f الخط، كما تم إرجاعه بواسطة caca_load_font()
buf مخزن مؤقت للصورة
width العرض (بالبكسل) لمخزن مؤقت للصورة
height الارتفاع (بالبكسل) لمخزن مؤقت للصورة
pitch المسافة (بالبايت) لسطر مخزن مؤقت للصورة.

الإرجاع

0 في حالة النجاح، -1 إذا حدث خطأ.

__extern int caca_free_font (caca_font_t * f)

تقوم هذه الوظيفة بتحرير جميع البيانات التي تم تخصيصها بواسطة caca_load_font(). لم تعد بنية الخط قابلة للاستخدام بواسطة وظائف libcaca الأخرى. بمجرد أن تقوم هذه الوظيفة بالإرجاع، يمكن تحرير منطقة الذاكرة التي تم تقديمها إلى caca_load_font().

هذه الوظيفة لا تفشل أبدًا.

المعلمات

f الخط، كما تم إرجاعه بواسطة caca_load_font()

الإرجاع
