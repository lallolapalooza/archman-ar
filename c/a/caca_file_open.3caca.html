الوصف التفصيلي

تسمح هذه الوظائف بقراءة وكتابة الملفات بطريقة مستقلة عن المنصة.

وثائق الوظائف

__extern caca_file_t * caca_file_open (char const * path, const char * mode)

إنشاء مقبض ملف caca لملف. إذا كان الملف مضغوطًا، فسيتم فك ضغطه أثناء التشغيل.

إذا حدث خطأ، فسيتم إرجاع NULL وسيتم تعيين errno وفقًا لذلك:

  • ENOSTS الوظيفة غير مطبقة.
  • EINVAL الملف غير موجود أو تم رفض الإذن.

المعلمات

path مسار الملف
mode وضع فتح الملف

الإرجاع

مقبض ملف إلى path.

تمت الإشارة إليه بواسطة caca_import_canvas_from_file().

__extern int caca_file_close (caca_file_t * fp)

إغلاق وتدمير الموارد المرتبطة بمقبض ملف caca.

هذه الوظيفة هي غلاف لـ fclose() أو، إذا كانت متاحة، gzclose().

المعلمات

fp مقبض الملف

الإرجاع

القيمة المرجعة من fclose() أو gzclose().

تمت الإشارة إليه بواسطة caca_import_canvas_from_file().

__extern uint64_t caca_file_tell (caca_file_t * fp)

__extern char * caca_file_gets (caca_file_t * fp, char * s, int size)

اقرأ سطرًا واحدًا من البيانات من مقبض ملف، حتى أقل من عدد البايتات المحدد بواحد. تتم إضافة صفر لاحق إلى البيانات.
