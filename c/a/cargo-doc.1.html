NAME

cargo-doc - Build documentation for a Rust crate

SYNOPSIS

cargo doc [-h | --help] [--version] [--verbose | -v] [--quiet | -q] [--color <when>] [--frozen] [--locked] [--offline] [-Z <arg>] [--config <KEY=VALUE>] [--target <TRIPLE>] [-p <SPEC>] [--workspace] [--all] [--no-deps] [--document-private-items] [--open | -o] [--no-deps] [--compile-docs]

DESCRIPTION

This command builds the documentation for your crate and all its dependencies.

The documentation is generated in HTML format and placed in the target/doc directory.

By default, cargo doc only builds documentation for the current crate. To build documentation for all crates in the workspace, use the --workspace flag.

OPTIONS

-h, --help
Print help information.
--version
Print version information.
--verbose, -v
Use verbose output. Measure execution time of cargo instructions.
--quiet, -q
No output printed to standard output other than the compilation results.
--color <when>
Coloring of output. Should be one of auto, always, never.
--frozen
A previously built artifact is assumed to be fresh. See cargo help build for more information.
--locked
A previously built artifact is assumed to be fresh. See cargo help build for more information.
--offline
Run without accessing the network. See cargo help build for more information.
-Z <arg>
Run a nightly-only feature of Cargo, in stability order. See cargo help -Z for information about unstable features.
--config <KEY=VALUE>
Overrides a Cargo configuration value. See cargo help config for more information.
--target <TRIPLE>
The target triple for which to build documentation. See cargo help build for more information.
-p <SPEC>

Package to document. See cargo help pkgid for more information.

This flag implies --no-deps.

--workspace
Document all packages in the workspace.
--all
Alias for --workspace.
--no-deps
Do not build documentation for dependencies.
--document-private-items

Document private items (fields, functions, modules, etc.).

This flag is only available when using the rustdoc feature of the nightly toolchain.

--open, -o

Open the documentation in the default web browser after building.

This flag is only available when using the rustdoc feature of the nightly toolchain.

--compile-docs

Whether to compile documentation for dependencies. Defaults to true.

This flag is only available when using the rustdoc feature of the nightly toolchain.

ENVIRONMENT

See cargo help build for environment variables that affect compilation.

EXIT STATUS

The exit status is 0 if all documentation was built successfully, and non-zero otherwise.

EXAMPLES

Build documentation for the current crate and its dependencies:

cargo doc

Build documentation for all crates in the workspace:

cargo doc --workspace

Build documentation for a specific crate and open it in the browser:

cargo doc -p my-crate --open
