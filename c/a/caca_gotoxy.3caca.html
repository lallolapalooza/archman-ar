NAME

caca_gotoxy — move the text cursor to a given position

SYNOPSIS

#include <caca.h>

void caca_gotoxy( caca_display_t *dp, int x, int y );

DESCRIPTION

The caca_gotoxy function moves the text cursor to the given coordinates (x, y). The coordinates are zero-based, meaning that the top-left corner of the text is (0, 0).

If the coordinates are out of bounds, they are clamped to the bounds of the display.

REMARKS

This function does not flush the display. You need to call caca_refresh to see the changes.

SEE ALSO

caca_clear(3caca), caca_refresh(3caca), caca_text_output(3caca)

AUTHOR

The libcaca team.

الاسم

caca_gotoxy — تحريك مؤشر النص إلى موضع معين

الملخص

#include <caca.h>

void caca_gotoxy( caca_display_t *dp, int x, int y );

الوصف

تقوم الدالة caca_gotoxy بتحريك مؤشر النص إلى الإحداثيات المعطاة (x, y). الإحداثيات تبدأ من الصفر، مما يعني أن الزاوية العلوية اليسرى للنص هي (0, 0).

إذا كانت الإحداثيات خارج الحدود، فسيتم قصها لتناسب حدود الشاشة.

ملاحظات

هذه الدالة لا تقوم بمسح الشاشة. تحتاج إلى استدعاء caca_refresh لرؤية التغييرات.
