NAME

cal — displays a calendar

SYNOPSIS

cal [-j] [-m] [-s] [-u] [-w] [-W] [[month] year]
cal [-j] [-m] [-s] [-u] [-w] [-W] [-y [year]]
cal [-A <num>] [-B <num>] [-c] [-d] [-e] [-F] [-L] [-m] [-n] [-p] [-s] [-S] [-t] [-u] [-V] [-w] [-W] [-y [year]]

DESCRIPTION

cal prints a calendar for a given month or year. If no arguments are given, it prints the current month. The calendar is displayed in the Gregorian calendar, starting with Monday for the first day of the week, unless the LC_TIME environment variable is set to a locale that uses a different convention, or if the -s option is used.

The cal command supports the use of XDG Base Directory Specification. See the terminal-colors.d(5) manual page for more details about the directory locations, file formats and supported color names.

OPTIONS

Options can be specified either before or after the month and year arguments.

-A <num>
Print num months after the specified month. (Since version 2.24)

-B <num>
Print num months before the specified month. (Since version 2.24)

-c
Print a calendar for the Cyrillic (Julian) calendar. This option only affects the display of the calendar dates; the calculation of weekdays and leap years is still based on the Gregorian calendar.

-d
Print a calendar for the Julian calendar. This option influences the displayed dates and the calculation of weekdays and leap years.

-e
Print a calendar for the Gregorian calendar. This is the default behavior.

-F
Print a calendar for the French Republican calendar. This option influences the displayed dates and the calculation of weekdays and leap years.

-j
Print the day number of the year (1-366).

-L
Print a calendar for the Lutheran calendar. This option influences the displayed dates and the calculation of weekdays and leap years.

-m
Print only the name of the month and year.

-n
Display the week number. This option is equivalent to -w.

-p
Print a calendar for the Proleptic Gregorian calendar. This option influences the displayed dates and the calculation of weekdays and leap years.

-s
Display the week starting on Sunday. By default, the week starts on Monday.

-S
Print a calendar for the Islamic calendar. This option influences the displayed dates and the calculation of weekdays and leap years.

-t
Print a calendar for the Thai calendar. This option influences the displayed dates and the calculation of weekdays and leap years.

-u
Print a calendar for the Julian day count. The Julian day count starts from January 1, 4713 BC. This option influences the displayed dates and the calculation of weekdays and leap years.

-V
Display version information.

-w
Display the week number. The week number is the number of days since the beginning of the year, divided by seven.

-W
Display the week number, following ISO 8601 standard. The week number is the number of the week of the year.

-y [year]
Print a calendar for the entire year. If no year is specified, the current year is used.

PARAMETERS

month
A number from 1 to 12, specifying the month. If no month is specified, the current month is used.

year
A year number. If no year is specified, the current year is used.

NOTES

When specifying a month and year, the month can be a number from 1 to 12. If the month is not specified, the current month is displayed. If the year is not specified, the current year is displayed. If only the year is specified, the entire year is displayed.

The cal command supports colorization through the terminal-colors.d directory structure. Color schemes can be defined in files within /etc/terminal-colors.d/ or $HOME/.config/terminal-colors.d/.

To disable colorization for all commands, create an empty file named /etc/terminal-colors.d/disable or $HOME/.config/terminal-colors.d/disable.

To disable colorization for a specific command, create an empty file named after the command, e.g., /etc/terminal-colors.d/cal.disable for the cal command or /etc/terminal-colors.d/disable for all tools.

Since version 2.41, the $NO_COLOR environment variable is also supported to disable output colorization unless explicitly enabled by a command-line option.

The user-specific $XDG_CONFIG_HOME/terminal-colors.d or $HOME/.config/terminal-colors.d overrides the global setting.

Note that the output colorization may be enabled by default, and in this case terminal-colors.d directories do not have to exist yet.

COLORS

The logical color names supported by cal are:

today

The current day.

weeknumber

The week number requested by the --week=<number> command line option.

weeks

The number of the week.

header

The header of a month.

workday

Days that fall within the work-week.

weekend

Days that fall outside the work-week.

For example:

echo -e 'weekend 35\ntoday 1;41\nheader yellow' > $HOME/.config/terminal-colors.d/cal.scheme

HISTORY

A cal command appeared in Version 6 AT&T UNIX.

BUGS

The default cal output uses 3 September 1752 as the Gregorian calendar reform date. The historical reform dates for the other locales, including its introduction in October 1582, are not implemented.

Alternative calendars, such as the Umm al-Qura, the Solar Hijri, the Ge’ez, or the lunisolar Hindu, are not supported.
