__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

رسم خط متعدد على لوحة الرسم باستخدام الحرف المحدد ومصفوفات الإحداثيات. لا يتم توصيل النقطتين الأولى والأخيرة، لذلك لرسم مضلع تحتاج إلى تحديد نقطة البداية في نهاية القائمة أيضًا.

هذه الوظيفة لا تفشل أبداً.

المعاملات

cv مؤشر إلى لوحة الرسم libcaca.
x مصفوفة الإحداثيات السينية. يجب أن تحتوي على n + 1 عناصر.
y مصفوفة الإحداثيات الصادية. يجب أن تحتوي على n + 1 عناصر.
n عدد الخطوط المراد رسمها.
ch حرف UTF-32 المراد استخدامه لرسم الخطوط.
