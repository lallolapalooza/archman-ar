__extern int caca_draw_polyline (caca_canvas_t * cv, int const x[], int const y[], int n, uint32_t ch)

ارسم خطًا متعددًا على لوحة الرسم باستخدام الحرف المحدد ومصفوفات الإحداثيات. لا يتم توصيل النقطة الأولى والأخيرة، لذا لرسم شكل مغلق، تحتاج إلى تحديد نقطة البداية في نهاية القائمة أيضًا.

هذه الدالة لا تفشل أبدًا.

المعلمات

cv مؤشر إلى لوحة الرسم libcaca.
x مصفوفة الإحداثيات السينية. يجب أن تحتوي على n + 1 عناصر.
y مصفوفة الإحداثيات الصادية. يجب أن تحتوي على n + 1 عناصر.
n عدد الخطوط المطلوب رسمها.
ch حرف UTF-32 المستخدم لرسم الخطوط.
