NAME

\n

calibre-server - calibre-server

\n
\n
\n
calibre-server [options] [path to library folder...]
\n
\n
\n

Start the calibre Content server. The calibre Content server\n exposes your calibre libraries over the internet. You can specify the path\n to the library folders as arguments to calibre-server. If you do not\n specify any paths, all the libraries that the main calibre program knows\n about will be used.

\n

Whenever you pass arguments to calibre-server that have\n spaces in them, enclose the arguments in quotation marks. For example:\n "/some path/with spaces"

\n
\n
\n

[OPTIONS]

\n
\n
\n
--access-log
\n
Path to the access log file. This log contains information about clients\n connecting to the server and making requests. By default no access logging\n is done.
\n
\n
\n
\n
\n
--ajax-timeout
\n
Time (in seconds) to wait for a response from the server when making\n queries.
\n
\n
\n
\n
\n
--auth-mode
\n
Choose the type of authentication used. Set the HTTP authentication mode\n used by the server. Set to "basic" if you are\n putting this server behind an SSL proxy. Otherwise, leave it as\n "auto", which will use\n "basic" if SSL is configured otherwise it will use\n "digest".
\n
\n
\n
\n
\n
--auto-reload
\n
Automatically reload server when source code changes. Useful for\n development. You should also specify a small value for the shutdown\n timeout.
\n
\n
\n
\n
\n
--ban-after
\n
Number of login failures for ban. The number of login failures after which\n an IP address is banned
\n
\n
\n
\n
\n
--ban-for
\n
Ban IP addresses that have repeated login failures. Temporarily bans\n access for IP addresses that have repeated login failures for the\n specified number of minutes. Useful to prevent attempts at guessing\n passwords. If set to zero, no banning is done.
\n
\n
\n
\n
\n
--book-list-mode
\n
Choose the default book list mode. Set the default book list mode that\n will be used for new users. Individual users can override the default in\n their own settings. The default is to use a cover grid.
\n
\n
\n
\n
\n
--compress-min-size
\n
Minimum size for which responses use data compression (in bytes).
\n
\n
\n
\n
\n
--custom-list-template
\n
Path to a JSON file containing a template for the custom book list mode. \n The easiest way to create such a template file is to go to\n Preferences-> Sharing over the net-> Book list template in calibre,\n create the template and export it.
\n
\n
\n
\n
\n
--daemonize
\n
Run process in background as a daemon (Linux only).
\n
\n
\n
\n
\n
--displayed-fields
\n
Restrict displayed user-defined fields. Comma separated list of\n user-defined metadata fields that will be displayed by the Content server\n in the /opds and /mobile views. If you specify this option, any fields not\n in this list will not be displayed. For example: my_rating,my_tags
\n
\n
\n
\n
\n
--enable-allow-socket-preallocation, \n --disable-allow-socket-preallocation
\n
Socket pre-allocation, for example, with systemd socket activation. By\n default, this option is enabled.
\n
\n
\n
\n
\n
--enable-auth, \n --disable-auth
\n
Password based authentication to access the server. Normally, the server\n is unrestricted, allowing anyone to access it. You can restrict access to\n predefined users with this option. By default, this option is\n disabled.
\n
\n
\n
\n
\n
--enable-fallback-to-detected-interface, \n --disable-fallback-to-detected-interface
\n
Fallback to auto-detected interface. If for some reason the server is\n unable to bind to the interface specified in the listen_on option, then it\n will try to detect an interface that connects to the outside world and\n bind to that. By default, this option is enabled.
\n
\n
\n
\n
\n
--enable-local-write, \n --disable-local-write
\n
