CABS(3P) دليل مبرمج POSIX CABS(3P)

PROLOG

هذه الصفحة اليدوية جزء من دليل مبرمج POSIX. قد يختلف تنفيذ Linux لهذا الواجهة (راجع الصفحة اليدوية المقابلة لـ Linux لتفاصيل سلوك Linux)، أو قد لا يتم تنفيذ الواجهة على Linux.

NAME

cabs, cabsf, cabsl — إرجاع قيمة مطلقة مركبة

SYNOPSIS

#include <complex.h>
double cabs(double complex z);
float cabsf(float complex z);
long double cabsl(long double complex z);

DESCRIPTION

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C هو غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

ستقوم هذه الدوال بحساب القيمة المطلقة المركبة (تسمى أيضًا المعيار، أو المقدار، أو الحجم) لـ z.

RETURN VALUE

سترجع هذه الدوال القيمة المطلقة المركبة.

ERRORS

لا توجد أخطاء محددة.
