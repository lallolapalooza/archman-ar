الوصف التفصيلي

توفر هذه الوظائف روتينيات التعامل مع خطوط libcaca النقطية وعرض لوحة الرسم عالي الجودة على صورة نقطية.

توثيق الوظائف

__extern caca_font_t * caca_load_font (void const * data, size_t size)

تقوم هذه الوظيفة بتحميل خط وتعيد مقبضًا لهيكله الداخلي. يمكن بعد ذلك استخدام المقبض مع caca_render_canvas() للإخراج النقطي.

يمكن أيضًا تحميل الخطوط الداخلية: إذا تم تعيين size إلى 0، فيجب أن يكون data عبارة عن سلسلة نصية تحتوي على اسم الخط الداخلي.

إذا كان size غير صفري، فسيتم تحميل حجم bytes من الذاكرة في العنوان data كخط. يجب ألا يتم تحرير هذه الذاكرة بواسطة البرنامج المتصل حتى يتم تحرير مقبض الخط باستخدام caca_free_font().

إذا حدث خطأ، يتم إرجاع NULL ويتم تعيين errno وفقًا لذلك:

  • ENOENT خط مدمج مطلوب غير موجود.
  • EINVAL بيانات خط غير صالحة في منطقة الذاكرة.
  • ENOMEM لا توجد ذاكرة كافية لتخصيص بنية الخط.

المعلمات

data منطقة الذاكرة التي تحتوي على الخط أو اسمه.
size حجم منطقة الذاكرة، أو 0 إذا تم توفير اسم الخط.

المرتجعات

مقبض خط أو NULL في حالة حدوث خطأ.

الارتفاع القياسي للحرف.

__extern uint32_t const * caca_get_font_blocks (caca_font_t const * f)

تقوم هذه الوظيفة بإرجاع قائمة بنطاقات Unicode التي يدعمها الخط المحدد. القائمة عبارة عن قائمة منتهية بالصفر من الفهارس. إليك مثال:

{
   0x0000, 0x0080,   // الأساسية اللاتينية: A, B, C, a, b, c
   0x0080, 0x0100,   // ملحق لاتيني-1: "A, 'e, ^u
   0x0530, 0x0590,   // الأرمنية
   0x0000, 0x0000,   // النهاية
};

هذه الوظيفة لا تفشل أبداً.

المعلمات

f الخط، كما تم إرجاعه بواسطة caca_load_font()

المرتجعات

قائمة نطاقات Unicode التي يدعمها الخط.

__extern int caca_render_canvas (caca_canvas_t const * cv, caca_font_t const * f, void * buf, int width, int height, int pitch)

تقوم هذه الوظيفة بعرض لوحة الرسم المعطاة على مخزن مؤقت للصورة باستخدام خط محدد. تنسيق البكسل ثابت (ARGB 32 بت، 8 بت لكل مكون).

يمكن حساب عرض الصورة المطلوب باستخدام caca_get_canvas_width() و caca_get_font_width(). يمكن حساب الارتفاع المطلوب باستخدام caca_get_canvas_height() و caca_get_font_height().

الأحرف التي لا تتناسب مع مخزن الصورة المؤقت لا يتم عرضها حاليًا على الإطلاق. قد يتم اقتصاصها بدلاً من ذلك في الإصدارات المستقبلية.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL العرض أو الارتفاع أو الملعب المحدد غير صالح.

المعلمات

cv لوحة الرسم المراد عرضها
f الخط، كما تم إرجاعه بواسطة caca_load_font()
buf مخزن الصورة المؤقت
width العرض (بالبكسل) لمخزن الصورة المؤقت
height الارتفاع (بالبكسل) لمخزن الصورة المؤقت
pitch الملعب (بالبايت) لسطر مخزن الصورة المؤقت.

المرتجعات

0 في حالة النجاح، -1 إذا حدث خطأ.

__extern int caca_free_font (caca_font_t * f)

تقوم هذه الوظيفة بتحرير جميع البيانات المخصصة بواسطة caca_load_font(). لم تعد بنية الخط قابلة للاستخدام بواسطة وظائف libcaca الأخرى. بمجرد عودة هذه الوظيفة، يمكن تحرير منطقة الذاكرة التي تم توفيرها لـ caca_load_font().

هذه الوظيفة لا تفشل أبداً.

المعلمات

f الخط، كما تم إرجاعه بواسطة caca_load_font()

المرتجعات
