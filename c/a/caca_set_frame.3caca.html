القيمة المعادة

عدد الإطارات

مشار إليها بواسطة caca_set_canvas_boundaries().

__extern int caca_set_frame (caca_canvas_t * cv, int id)

تعيين إطار القماش النشط. ستتم جميع عمليات الرسم اللاحقة على هذا الإطار. يتم توريث سياق الرسم الحالي الذي تم تعيينه بواسطة caca_set_attr().

إذا كان فهرس الإطار خارج نطاق إطارات القماش، فلن يحدث شيء.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL الإطار المطلوب خارج النطاق.

id الإطار المراد تفعيله في القماش

القيمة المعادة

0 في حالة النجاح، -1 في حالة حدوث خطأ.

يشير إلى caca_add_dirty_rect().

مشار إليها بواسطة caca_set_canvas_boundaries().

__extern char const * caca_get_frame_name (caca_canvas_t const * cv)

إرجاع اسم الإطار الحالي. يكون السلسلة النصية المعادة صالحة حتى يتم حذف الإطار أو استدعاء caca_set_frame_name() لتغيير اسم الإطار مرة أخرى.

هذه الوظيفة لا تفشل أبداً.

القيمة المعادة

اسم الإطار الحالي.

__extern int caca_set_frame_name (caca_canvas_t * cv, char const * name)

تعيين اسم الإطار الحالي. عند الإنشاء، يكون للإطار اسم افتراضي هو 'frame#xxxxxxxx' حيث xxxxxxxx هو رقم سداسي عشري يزداد ذاتيًا.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
ENOMEM لا توجد ذاكرة كافية لتخصيص إطار جديد.

القيمة المعادة

0 في حالة النجاح، -1 في حالة حدوث خطأ.

__extern int caca_create_frame (caca_canvas_t * cv, int id)

إنشاء إطار جديد داخل القماش المحدد. يتم نسخ محتوياته وسماته من الإطار النشط حاليًا.

يشير فهرس الإطار إلى مكان إدراج الإطار. تتراوح القيم الصالحة من 0 إلى العدد الحالي لإطارات القماش. إذا كان فهرس الإطار أكبر من أو يساوي العدد الحالي لإطارات القماش، يتم إلحاق الإطار الجديد في نهاية القماش. إذا كان فهرس الإطار أقل من الصفر، يتم إدراج الإطار الجديد في الفهرس 0.

لا يتغير الإطار النشط، ولكن قد يتم إعادة ترقيم فهرسه بسبب الإدراج.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
ENOMEM لا توجد ذاكرة كافية لتخصيص إطار جديد.

المعلمات

cv قماش libcaca
id الفهرس الذي سيتم إدراج الإطار الجديد فيه

القيمة المعادة

0 في حالة النجاح، -1 في حالة حدوث خطأ.

مشار إليها بواسطة caca_set_canvas_boundaries().

__extern int caca_free_frame (caca_canvas_t * cv, int id)

حذف إطار من قماش محدد.

يشير فهرس الإطار إلى الإطار المراد حذفه. تتراوح القيم الصالحة من 0 إلى العدد الحالي لإطارات القماش مطروحًا منه 1. إذا كان فهرس الإطار أكبر من أو يساوي العدد الحالي لإطارات القماش، يتم حذف الإطار الأخير.

إذا تم حذف الإطار النشط، يصبح الإطار 0 هو الإطار النشط الجديد. بخلاف ذلك، لا يتغير الإطار النشط، ولكن قد يتم إعادة ترقيم فهرسه بسبب الحذف.

إذا حدث خطأ، يتم إرجاع -1 ويتم تعيين errno وفقًا لذلك:

•
EINVAL الإطار المطلوب خارج النطاق، أو محاولة حذف آخر إطار في القماش.

id فهرس الإطار المراد حذفه

القيمة المعادة

0 في حالة النجاح، -1 في حالة حدوث خطأ.

يشير إلى caca_add_dirty_rect().
