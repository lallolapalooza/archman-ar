إرجاع قائمة خوارزميات التدرج المتوفرة لتدرج معين. القائمة عبارة عن مصفوفة من السلاسل النصية المنتهية بـ NULL، تتداخل سلسلة تحتوي على القيمة الداخلية لخوارزمية التدرج، لاستخدامها مع caca_set_dither_dithering()، وسلسلة تحتوي على وصف اللغة الطبيعية لهذه الخوارزمية.

هذه الدالة لا تفشل أبداً.

المعلمات

d كائن التدرج.

الإرجاع

مصفوفة من السلاسل النصية.

__extern char const * caca_get_dither_algorithm (caca_dither_t const * d)

إرجاع خوارزمية التدرج الحالية للكائن المحدد.

هذه الدالة لا تفشل أبداً.

المعلمات

d كائن التدرج.

الإرجاع

سلسلة نصية ثابتة.

__extern int caca_dither_bitmap (caca_canvas_t * cv, int x, int y, int w, int h, caca_dither_t const * d, void const * pixels)

تدرج صورة نقطية بالإحداثيات المحددة. يمكن أن يكون التدرج بأي حجم وسيتم تمديده إلى منطقة النص.

هذه الدالة لا تفشل أبداً.

المعلمات

cv مقبض لقماش libcaca.
x الإحداثي السيني للزاوية العلوية اليسرى لمنطقة الرسم.
y الإحداثي الصادي للزاوية العلوية اليسرى لمنطقة الرسم.
w عرض منطقة الرسم.
h ارتفاع منطقة الرسم.
d كائن التدرج المراد رسمه.
pixels وحدات البكسل للصورة النقطية.
