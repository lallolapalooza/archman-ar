cap_to_name(3)

الحزمة: libcap

التراخيص: BSD-3-Clause OR GPL-2.0-only

CAP_FROM_TEXT(3) دليل مبرمج لينكس CAP_FROM_TEXT(3)

الاسم

cap_from_text، cap_to_text، cap_to_name، cap_from_name - تحويل التمثيل النصي لحالة القدرة

الملخص

#include <sys/capability.h>
cap_t cap_from_text(const char *buf_p);
char *cap_to_text(cap_t caps, ssize_t *len_p);
int cap_from_name(const char *name, cap_value_t *cap_p);
char *cap_to_name(cap_value_t cap);

الربط مع -lcap.

الوصف

تقوم هذه الدوال بترجمة حالة القدرة بين تمثيل داخلي وتمثيل نصي. يتم إدارة التمثيل الداخلي بواسطة دوال القدرة في مساحة العمل. التمثيل النصي هو سلسلة نصية منظمة، قابلة للقراءة البشرية، ومناسبة للعرض.

تقوم cap_from_text() بتخصيص وتهيئة حالة القدرة في مساحة العمل. ثم تقوم بتعيين محتويات حالة القدرة المنشأة حديثًا هذه للحالة التي تمثلها سلسلة نصية بشرية، منتهية بصفر، يشير إليها buf_p. تقوم بإرجاع مؤشر إلى حالة القدرة المنشأة حديثًا. عندما لا تكون حالة القدرة في مساحة العمل مطلوبة بعد الآن، يجب على المستدعي تحرير أي ذاكرة قابلة للإصدار عن طريق استدعاء cap_free() مع cap_t كوسيط. ترجع الدالة خطأ إذا لم تتمكن من تحليل محتويات السلسلة التي يشير إليها buf_p أو لم تتعرف على أي capability_name أو حرف علامة على أنه صالح. ترجع الدالة أيضًا خطأ إذا تم تعيين أي علامة وإلغاؤها ضمن قسم واحد.

تقوم cap_to_text() بتحويل حالة القدرة في مساحة العمل المحددة بواسطة caps إلى سلسلة نصية بشرية، منتهية بصفر. تقوم هذه الدالة بتخصيص أي ذاكرة ضرورية لاحتواء السلسلة، وترجع مؤشرًا إلى السلسلة. إذا لم يكن المؤشر len_p NULL، فيجب على الدالة أيضًا إرجاع الطول الكامل للسلسلة (غير شاملة الختم الصفري) في الموقع الذي يشير إليه len_p. حالة القدرة في مساحة العمل، المحددة بواسطة caps، ممثلة بالكامل في السلسلة النصية. عندما لا تكون حالة القدرة في مساحة العمل مطلوبة بعد الآن، يجب على المستدعي تحرير أي ذاكرة قابلة للإصدار عن طريق استدعاء cap_free() مع مؤشر السلسلة المرتجع كوسيط.

تقوم cap_from_name() بتحويل تمثيل نصي للقدرة، مثل "cap_chown"، إلى تمثيله الرقمي (CAP_CHOWN=0)، وكتابة القيمة المفككة في *cap_p. إذا كان cap_p NULL، فلا يتم كتابة نتيجة، ولكن رمز الإرجاع للدالة يشير إلى ما إذا كانت القدرة المحددة يمكن تمثيلها بواسطة المكتبة أم لا.

تقوم cap_to_name() بتحويل قيمة فهرس القدرة، cap، إلى سلسلة نصية مخصصة من قبل libcap. يجب إلغاء تخصيص هذه السلسلة باستخدام cap_free().

التمثيل النصي

تم وصف تنسيق النص في صفحة الدليل cap_text_formats(7).

قيمة الإرجاع

cap_from_text() و cap_to_text() و cap_to_name() ترجع قيمة غير NULL عند النجاح، و NULL عند الفشل. ترجع cap_from_name() 0 للنجاح، و -1 عند الفشل (قدرة غير معروفة).

عند الفشل، يتم تعيين errno إلى EINVAL، أو ENOMEM.

متوافق مع

cap_from_text() و cap_to_text() محددة بواسطة مسودة مواصفات POSIX.1e المسحوبة. cap_from_name() و cap_to_name() هي امتدادات لينكس.

مثال

يوضح برنامج المثال أدناه استخدام cap_from_text() و cap_to_text(). تظهر جلسة shell التالية بعض الأمثلة التشغيلية:

$ ./a.out "cap_chown=p cap_chown+e"
caps_to_text() returned "cap_chown=ep"
$ ./a.out "all=pe cap_chown-e cap_kill-pe"
caps_to_text() returned "=ep cap_chown-e cap_kill-ep"

الكود المصدري للبرنامج هو كما يلي:

#include <stdlib.h>
#include <stdio.h>
#include <sys/capability.h>
#define handle_error(msg) \
    do { perror(msg); exit(EXIT_FAILURE); } while (0)
int
main(int argc, char *argv[])
{
    cap_t caps;
    char *txt_caps;
    if (argc != 2) {
        fprintf(stderr, "%s <textual-cap-set>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    caps = cap_from_text(argv[1]);
    if (caps == NULL)
        handle_error("cap_from_text");
    txt_caps = cap_to_text(caps, NULL);
    if (txt_caps == NULL)
        handle_error("cap_to_text");
    printf("caps_to_text() returned \"%s\"\n", txt_caps);
    if (cap_free(txt_caps) != 0 || cap_free(caps) != 0)
        handle_error("cap_free");
    exit(EXIT_SUCCESS);
}
