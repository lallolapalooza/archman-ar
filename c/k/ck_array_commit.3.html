ck_array_commit(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_ARRAY_COMMIT(3) دليل وظائف المكتبة CK_ARRAY_COMMIT(3)

الاسم

ck_array_commit — نقطة تسلسل للتحويرات قبل استدعاء الالتزام

المكتبة

مجموعة التزامن (libck, -lck)

الملخص

#include <ck_array.h>

bool
ck_array_commit(ck_array_t *array);

الوصف

ستقوم الدالة ck_array_commit(3) بالالتزام بأي عمليات وضع أو إزالة معلقة مرتبطة بالمصفوفة. قد تنتهي الدالة بطلب الاستعادة الآمنة للذاكرة التي يتم تكرارها بنشاط بواسطة خيوط أخرى.

قيم الإرجاع

تعيد هذه الدالة قيمة صحيحة إذا نجحت عملية الالتزام. ستعيد قيمة خاطئة بخلاف ذلك، ولن يتم تطبيق العمليات المعلقة.
