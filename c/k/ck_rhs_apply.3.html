ck_rhs_apply(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_RHS_APPLY(3) دليل وظائف المكتبة CK_RHS_APPLY(3)

الاسم

ck_rhs_apply — تطبيق دالة على قيمة مجموعة الهاش

المكتبة

مجموعة التزامن (libck, -lck)

الملخص

#include <ck_rhs.h>

void *
ck_rhs_apply_fn_t(void *key, void *closure);

bool
ck_rhs_apply(ck_rhs_t *hs, unsigned long hash, const void *key, ck_rhs_apply_fn_t *function, void *argument);

الوصف

ستقوم الدالة ck_rhs_apply(3) بالبحث عن خانة مجموعة الهاش المرتبطة بالمفتاح key وتمريرها إلى الدالة التي يشير إليها function لمزيد من الإجراءات. قد تقوم هذه الدالة الاستدعائية بإزالة أو استبدال القيمة عن طريق إرجاع NULL أو مؤشر إلى كائن آخر بنفس المفتاح على التوالي. الوسيط الأول الذي يتم تمريره إلى function هو مؤشر إلى الكائن الموجود في مجموعة الهاش والوسيط الثاني هو مؤشر argument الذي تم تمريره إلى ck_rhs_apply(3). إذا كان المؤشر الذي تم إرجاعه بواسطة function مساويًا للوسيط الأول، فلن يتم إجراء أي تعديل على مجموعة الهاش.

قيم الإرجاع

عند الانتهاء بنجاح، تعيد الدالة ck_rhs_apply(3) قيمة صحيحة (true) وإلا فإنها تعيد قيمة خاطئة (false) عند الفشل.
