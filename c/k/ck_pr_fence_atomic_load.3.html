ck_pr_fence_atomic_load(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_PR_FENCE_ATOMIC_LOAD(3) دليل وظائف المكتبة CK_PR_FENCE_ATOMIC_LOAD(3)

الاسم

ck_pr_fence_atomic_load — فرض ترتيب عمليات القراءة-التعديل-الكتابة الذرية لعمليات التحميل

المكتبة

مجموعة أدوات التزامن (libck, -lck)

ملخص

#include <ck_pr.h>

void
ck_pr_fence_atomic_load(void);

void
ck_pr_fence_strict_atomic_load(void);

الوصف

تقوم الدالة ck_pr_fence_atomic_load() بفرض ترتيب أي عمليات قراءة-تعديل-كتابة ذرية بالنسبة لأي عمليات تحميل تتبع استدعاء الدالة. تعمل هذه الدالة دائمًا كحاجز ضمني للمترجم. على المعماريات التي تنفذ CK_MD_TSO، لا تؤدي هذه العملية إلا كحاجز للمترجم ولا يتم إصدار أي أسوار. لفرض إصدار سياج غير مشروط، استخدم ck_pr_fence_strict_atomic_load().

مثال

#include <ck_pr.h>

static int a = 0;
static int b = 0;

void
function(void)
{
	int c;

	ck_pr_fas_int(&a, 1);

	/*
	 * ضمان اكتمال التحديث إلى a
	 * فيما يتعلق بتحميل *b.
	 */
	ck_pr_fence_atomic_load();
	c = ck_pr_load_int(&b);

	return;
}

قيم الإرجاع

ليس لهذه الدالة قيمة إرجاع.
