ck_pr_fence_atomic_store(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_PR_FENCE_ATOMIC_STORE(3) دليل وظائف المكتبة CK_PR_FENCE_ATOMIC_STORE(3)

الاسم

ck_pr_fence_atomic_store — فرض ترتيب عمليات القراءة-التعديل-الكتابة الذرية على عمليات التخزين

المكتبة

مجموعة التزامن (libck, -lck)

الملخص

#include <ck_pr.h>

void
ck_pr_fence_atomic_store(void);

void
ck_pr_fence_strict_atomic_store(void);

الوصف

تقوم الدالة ck_pr_fence_atomic_store() بفرض ترتيب عمليات القراءة-التعديل-الكتابة الذرية فيما يتعلق بأي عمليات تخزين تتبع استدعاء الدالة. تعمل هذه الدالة دائمًا كحاجز ضمني للمترجم. على المعماريات التي تطبق CK_MD_TSO، تعمل هذه العملية كحاجز للمترجم فقط ولا يتم إصدار أي حواجز. لفرض إصدار حاجز غير مشروط، استخدم ck_pr_fence_strict_atomic_store().

مثال

#include <ck_pr.h>

static int a = 0;
static int b = 0;

void
function(void)
{
	int c;

	ck_pr_fas_int(&a, 1);

	/*
	 * ضمان اكتمال التحديث لـ a
	 * بالنسبة للتخزين في القيمة المشار إليها بواسطة b.
	 */
	ck_pr_fence_atomic_store();
	c = ck_pr_store_int(&b, 2);

	return;
}

قيم الإرجاع

هذه الدالة لا تحتوي على قيمة إرجاع.
