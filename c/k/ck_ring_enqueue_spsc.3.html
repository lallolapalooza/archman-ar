ck_ring_enqueue_spsc(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

ck_ring_enqueue_spsc(3) دليل وظائف المكتبة ck_ring_enqueue_spsc(3)

الاسم

ck_ring_enqueue_spsc — إضافة مؤشر إلى طابور FIFO محدود

المكتبة

Concurrency Kit (libck, -lck)

الملخص

#include <ck_ring.h>

bool
ck_ring_enqueue_spsc(ck_ring_t *ring, ck_ring_buffer_t *buffer, void *entry);

الوصف

تقوم الدالة ck_ring_enqueue_spsc(3) بإضافة المؤشر entry إلى المخزن المؤقت المحدود الذي يشير إليه ring بترتيب FIFO. يجب أن يكون المخزن المؤقت الذي يشير إليه buffer فريدًا لـ ring ويشير إلى مصفوفة من ck_ring_buffer_t بطول كافٍ (وفقًا للقوة الثنائية للعناصر في المخزن المؤقت). يعمل فصل الحلقة عن المخزن المؤقت على معالجة حالات الاستخدام التي تتضمن مساحات عنوان متعددة و DMA، من بين أمور أخرى. إذا كنت على أنظمة غير POSIX أو ترغب في الامتثال الصارم لـ C، فمن المستحسن تمرير مؤشر من نوع void ** لـ entry. هذه الدالة آمنة للاستدعاء بدون قفل لعدد يصل إلى استدعاء متزامن واحد لـ ck_ring_dequeue_spsc(3). توفر هذه الدالة ضمانات تقدم خالية من الانتظار.

مثال

#include <ck_ring.h>

/* تم تهيئة هذه الحلقة مسبقًا باستخدام ck_ring_init. */
ck_ring_t ring;

/* تم تهيئة الحلقة لـ 1023 عنصرًا. */
ck_ring_buffer_t buffer[1024];

void
enqueue(void)
{
	void *entry = some_object;

	/* محاولة إضافة مؤشر إلى some_object إلى المخزن المؤقت. */
	if (ck_ring_enqueue_spsc(&ring, &buffer, &entry) == false) {
		/*
		 * كان المخزن المؤقت ممتلئًا وفشلت عملية الإضافة.
		 */
		return;
	}

	/* اكتملت عملية الإضافة بنجاح. */
	return;
}

قيم الإرجاع

تُرجع الدالة true إذا تم إضافة قيمة entry بنجاح إلى ring. ستُرجع الدالة false إذا لم يكن من الممكن إضافة قيمة entry، وهذا يحدث فقط إذا كان ring ممتلئًا.
