ck_rhs_remove(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_RHS_REMOVE(3) دليل وظائف المكتبة CK_RHS_REMOVE(3)

الاسم

ck_rhs_remove — إزالة مفتاح من مجموعة تجزئة

المكتبة

Concurrency Kit (libck, -lck)

الملخص

#include <ck_rhs.h>

void *
ck_rhs_remove(ck_rhs_t *hs, unsigned long hash, const void *key);

الوصف

ستحاول الدالة ck_rhs_remove(3) إزالة المفتاح المحدد بواسطة الوسيط key في مجموعة التجزئة المشار إليها بواسطة الوسيط hs. يُتوقع أن يكون للمفتاح المحدد بواسطة key قيمة التجزئة المحددة بواسطة الوسيط hash (الذي تم إنشاؤه مسبقًا باستخدام الماكرو CK_RHS_HASH(3)).

إذا نجح استدعاء ck_rhs_remove(3) فإنه سيتم إرجاع المفتاح الموجود في مجموعة التجزئة. إذا لم يكن المفتاح عضوًا في مجموعة التجزئة، فسيتم إرجاع NULL.

قيم الإرجاع

عند الانتهاء بنجاح، تُرجع ck_rhs_remove(3) مؤشرًا إلى مفتاح، وإلا فإنها تُرجع NULL عند الفشل.

الأخطاء

السلوك غير محدد إذا كان key أو hs غير مهيأين.
