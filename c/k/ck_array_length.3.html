الحزمة: libck

CK_ARRAY_LENGTH(3) دليل وظائف المكتبة CK_ARRAY_LENGTH(3)

الاسم

ck_array_length — تُرجع عدد المؤشرات الملتزمة بمصفوفة

المكتبة

Concurrency Kit (libck, -lck)

الاختصار

#include <ck_array.h>

unsigned int
ck_array_length(ck_array_t *array);

الوصف

تقوم وظيفة ck_array_length(3) بإرجاع عدد العناصر التي ستصادفها عملية المسح المتزامنة عند اكتمالها.

قيم الإرجاع

يتم إرجاع عدد المؤشرات المرئية للمسح.
