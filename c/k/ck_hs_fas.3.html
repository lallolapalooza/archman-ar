ck_hs_fas(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_HS_FAS(3) دليل وظائف المكتبة CK_HS_FAS(3)

الاسم

ck_hs_fas — جلب وتخزين المفتاح في مجموعة هاش

المكتبة

مجموعة التزامن (libck, -lck)

الملخص

#include <ck_hs.h>

bool
ck_hs_fas(ck_hs_t *hs, unsigned long hash, const void *key, void **previous);

الوصف

وظيفة ck_hs_fas(3) ستقوم بجلب وتخزين المفتاح المحدد بواسطة الوسيط key في مجموعة الهاش التي يشير إليها الوسيط hs. يُتوقع أن يكون للمفتاح المحدد بواسطة key قيمة هاش محددة بواسطة الوسيط hash (والتي تم إنشاؤها مسبقًا باستخدام الماكرو CK_HS_HASH(3)).

إذا كانت استدعاء ck_hs_fas(3) ناجحًا، فقد تم تخزين المفتاح المحدد بواسطة key بنجاح في مجموعة الهاش التي يشير إليها hs. يجب أن يكون المفتاح موجودًا بالفعل في مجموعة الهاش، ويتم استبداله بـ key ويتم تخزين القيمة السابقة في المؤشر الفارغ الذي يشير إليه الوسيط previous. إذا لم يكن المفتاح موجودًا في مجموعة الهاش، فسوف ترجع الدالة خطأ وتبقى مجموعة الهاش دون تغيير. هذه الدالة مضمونة أن تكون مستقرة فيما يتعلق باستخدام الذاكرة.

قيم الإرجاع

عند الانتهاء بنجاح، ترجع ck_hs_fas(3) القيمة true وإلا ترجع false عند الفشل.

الأخطاء

السلوك غير معرف إذا كانت key أو hs غير مهيأة.
