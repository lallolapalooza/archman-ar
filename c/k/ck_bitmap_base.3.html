ck_bitmap_base(3)

الحزمة: libck

التراخيص: BSD, Apache, Custom

CK_BITMAP_BASE(3) دليل وظائف المكتبة CK_BITMAP_BASE(3)

الاسم

ck_bitmap_base — تحديد حجم مصفوفة البتات بالبايت

المكتبة

Concurrency Kit (libck, -lck)

ملخص

#include <ck_bitmap.h>

unsigned int
ck_bitmap_base(unsigned int n_bits);

الوصف

تقوم الدالة ck_bitmap_base() بإرجاع عدد البايتات التي سيتم استخدامها لتخزين عدد البتات المحدد بواسطة n_bits.

قيم الإرجاع

تُرجع هذه الدالة قيمة غير صفرية مضمونة لتكون مضاعفة لـ sizeof(CK_BITMAP_WORD).
