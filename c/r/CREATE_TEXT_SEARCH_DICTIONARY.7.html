CREATE_TEXT_SEARCH_DICTIONARY(7)

الحزمة: postgresql

التراخيص: PostgreSQL

CREATE TEXT SEARCH DICTIONARY(7) توثيق PostgreSQL 18.1 CREATE TEXT SEARCH DICTIONARY(7)

الاسم

CREATE_TEXT_SEARCH_DICTIONARY - تعريف قاموس جديد للبحث النصي

ملخص

CREATE TEXT SEARCH DICTIONARY name (
    TEMPLATE = template
    [, option = value [, ... ]]
)

الوصف

CREATE TEXT SEARCH DICTIONARY ينشئ قاموسًا جديدًا للبحث النصي. يحدد قاموس البحث النصي طريقة التعرف على الكلمات المثيرة للاهتمام أو غير المثيرة للاهتمام للبحث. يعتمد القاموس على قالب بحث نصي، والذي يحدد الوظائف التي تقوم بالعمل الفعلي. عادةً ما يقدم القاموس بعض الخيارات التي تتحكم في السلوك التفصيلي لوظائف القالب.

إذا تم توفير اسم مخطط، يتم إنشاء قاموس البحث النصي في المخطط المحدد. بخلاف ذلك، يتم إنشاؤه في المخطط الحالي.

المستخدم الذي يعرف قاموس البحث النصي يصبح مالكه.

ارجع إلى الفصل 12 لمزيد من المعلومات.

المعلمات

name

اسم قاموس البحث النصي المراد إنشاؤه. يمكن تحديد الاسم مؤهلاً بالمخطط.

template

اسم قالب البحث النصي الذي سيحدد السلوك الأساسي لهذا القاموس.

option

اسم خيار خاص بالقالب ليتم تعيينه لهذا القاموس.

value

القيمة المراد استخدامها لخيارات خاصة بالقالب. إذا لم تكن القيمة معرفًا بسيطًا أو رقمًا، فيجب اقتباسها (ولكن يمكنك دائمًا اقتباسها إذا كنت ترغب في ذلك).

يمكن ظهور الخيارات بأي ترتيب.

أمثلة

يقوم أمر المثال التالي بإنشاء قاموس يعتمد على Snowball مع قائمة غير قياسية من الكلمات المتوقفة.

CREATE TEXT SEARCH DICTIONARY my_russian (
    template = snowball,
    language = russian,
    stopwords = myrussian
);

التوافق

لا يوجد عبارة CREATE TEXT SEARCH DICTIONARY في معيار SQL.

انظر أيضًا

ALTER TEXT SEARCH DICTIONARY (ALTER_TEXT_SEARCH_DICTIONARY(7)), DROP TEXT SEARCH DICTIONARY (DROP_TEXT_SEARCH_DICTIONARY(7))
