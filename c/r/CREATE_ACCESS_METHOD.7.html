CREATE_ACCESS_METHOD(7)

الحزمة: postgresql

CREATE ACCESS METHOD(7) توثيق PostgreSQL 18.1 CREATE ACCESS METHOD(7)

الاسم

CREATE_ACCESS_METHOD - تعريف طريقة وصول جديدة

الملخص

CREATE ACCESS METHOD name
    TYPE access_method_type
    HANDLER handler_function

الوصف

CREATE ACCESS METHOD تنشئ طريقة وصول جديدة.

يجب أن يكون اسم طريقة الوصول فريدًا داخل قاعدة البيانات.

يمكن للمستخدمين الخارقين فقط تعريف طرق وصول جديدة.

المعلمات

name

اسم طريقة الوصول المراد إنشاؤها.

access_method_type

تحدد هذه العبارة نوع طريقة الوصول المراد تعريفها. حاليًا، يتم دعم TABLE و INDEX فقط.

handler_function

handler_function هو اسم (قد يكون مؤهلًا للمخطط) لدالة مسجلة سابقًا تمثل طريقة الوصول. يجب تعريف دالة المعالج لتأخذ وسيطًا واحدًا من النوع internal، ويعتمد نوع الإرجاع الخاص بها على نوع طريقة الوصول؛ بالنسبة لطرق وصول TABLE، يجب أن يكون table_am_handler، وبالنسبة لطرق وصول INDEX، يجب أن يكون index_am_handler. تختلف واجهة برمجة تطبيقات مستوى C التي يجب أن تنفذها دالة المعالج اعتمادًا على نوع طريقة الوصول. واجهة برمجة تطبيقات طريقة وصول الجدول موصوفة في الفصل 62، وواجهة برمجة تطبيقات طريقة وصول الفهرس موصوفة في الفصل 63.

أمثلة

إنشاء طريقة وصول فهرس heptree مع دالة معالج heptree_handler:

CREATE ACCESS METHOD heptree TYPE INDEX HANDLER heptree_handler;

التوافق

CREATE ACCESS METHOD هي إضافة من PostgreSQL.

انظر أيضًا

DROP ACCESS METHOD (DROP_ACCESS_METHOD(7))، CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7))، CREATE OPERATOR FAMILY (CREATE_OPERATOR_FAMILY(7))
