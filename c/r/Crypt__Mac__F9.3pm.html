Crypt__Mac__F9(3pm)

الحزمة: perl-cryptx

التراخيص: PerlArtistic, GPL

Crypt::Mac::F9(3) وثائق Perl المساهمة من المستخدم Crypt::Mac::F9(3)

الاسم

Crypt::Mac::F9 - رمز مصادقة الرسالة F9

الملخص

### واجهة وظيفية:
use Crypt::Mac::F9 qw( f9 f9_hex );
# حساب MAC من سلسلة/مخزن مؤقت
$f9_raw  = f9($cipher_name, $key, 'data buffer');
$f9_hex  = f9_hex($cipher_name, $key, 'data buffer');
$f9_b64  = f9_b64($cipher_name, $key, 'data buffer');
$f9_b64u = f9_b64u($cipher_name, $key, 'data buffer');
### واجهة كائنية:
use Crypt::Mac::F9;
$d = Crypt::Mac::F9->new($cipher_name, $key);
$d->add('any data');
$d->addfile('filename.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->mac;     # بايت خام
$result_hex  = $d->hexmac;  # شكل سداسي عشري
$result_b64  = $d->b64mac;  # شكل Base64
$result_b64u = $d->b64umac; # شكل Base64 آمن لـ URL

الوصف

يوفر واجهة لخوارزمية رمز مصادقة الرسالة (MAC) F9.

تصدير

لا شيء يتم تصديره افتراضيًا.

يمكنك تصدير دوال محددة:

use Crypt::Mac::F9 qw(f9 f9_hex );

أو كلها مرة واحدة:

use Crypt::Mac::F9 ':all';

الدوال

f9

تضم منطقياً جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة الرسالة F9 الخاص بها مشفرًا كسلسلة ثنائية.

$f9_raw = f9($cipher_name, $key, 'data buffer');
# أو
$f9_raw = f9($cipher_name, $key, 'any data', 'more data', 'even more data');

f9_hex

تضم منطقياً جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة الرسالة F9 الخاص بها مشفرًا كسلسلة سداسية عشرية.

$f9_hex = f9_hex($cipher_name, $key, 'data buffer');
# أو
$f9_hex = f9_hex($cipher_name, $key, 'any data', 'more data', 'even more data');

f9_b64

تضم منطقياً جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة الرسالة F9 الخاص بها مشفرًا كسلسلة Base64.

$f9_b64 = f9_b64($cipher_name, $key, 'data buffer');
# أو
$f9_b64 = f9_b64($cipher_name, $key, 'any data', 'more data', 'even more data');

f9_b64u

تضم منطقياً جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة الرسالة F9 الخاص بها مشفرًا كسلسلة Base64 آمنة لـ URL (انظر RFC 4648 القسم 5).

$f9_b64url = f9_b64u($cipher_name, $key, 'data buffer');
# أو
$f9_b64url = f9_b64u($cipher_name, $key, 'any data', 'more data', 'even more data');
