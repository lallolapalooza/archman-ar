cryptbuf.3bobcat

الحزمة: libbobcat

التراخيص: GPL

FBB::CryptBuf(3bobcat) فئة أساسية لـ DecryptBuf و EncryptBuf FBB::CryptBuf(3bobcat)

الاسم

FBB::CryptBuf - فئة أساسية مشتقة من std::streambuf لـ DecryptBuf و EncryptBuf

الملخص

#include <bobcat/cryptbuf>
خيار الربط: -lbobcat -lcrypto

الوصف

تم إيقاف هذه الفئة ولن تتم إزالتها من Bobcat في إصدار مستقبلي. إنها ترث من FBB::EoiBuf. قد تستخدم الفئات التي تستخدم CryptBuf EoiBuf بدلاً من ذلك. يمكن تنفيذ العضو EVP_CIPHER const *md() الخاص بـ CryptBuf على النحو التالي:

    #include <openssl/evp.h>
    EVP_CIPHER const *md(char const *cipherName)
    {
        return EVP_CIPHER_fetch(0, cipherName, 0);
    }

ترث من

EoiBuf (وبالتالي من: std::streambuf)

باني محمي

بشكل مشابه لـ std::streambuf، يتوفر فقط باني محمي.

o
CryptBuf(char const *type, size_t bufSize):
النوع هو سلسلة بايتات منتهية بـ null تحدد طريقة فك/تشفير البيانات. على سبيل المثال، aes-128-cbc. للاطلاع على نظرة عامة، راجع صفحة دليل encryptbuf(3bobcat). تحدد المعلمة bufSize الحجم الأولي للمخزن المؤقت المستخدم داخليًا (المعرف بواسطة EoiBuf).

بانيات النسخ والنقل (وعوامل التعيين) غير متاحة.

دالة عضو محمية

جميع أعضاء std:streambuf و EoiBuf متاحة، حيث ترث FBB::CryptBuf من هذه الفئات.

o
EVP_CIPHER const *md() const:
يتم إرجاع مؤشر إلى معلومات التشفير.
