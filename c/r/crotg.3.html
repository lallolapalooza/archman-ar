subroutine crotg (complex(wp) a, complex(wp) b, real(wp) c, complex(wp) s)

CROTG تولد دوران جيفنز مع جيب تمام حقيقي وجيب مركب.

الغرض:

!>
!> CROTG تبني دوران مستوى
!>    [  c         s ] [ a ] = [ r ]
!>    [ -conjg(s)  c ] [ b ]   [ 0 ]
!> حيث c حقيقي، s مركب، و c**2 + conjg(s)*s = 1.
!>
!> الحساب يستخدم الصيغ
!>    |x| = sqrt( Re(x)**2 + Im(x)**2 )
!>    sgn(x) = x / |x|  if x /= 0
!>           = 1        if x  = 0
!>    c = |a| / sqrt(|a|**2 + |b|**2)
!>    s = sgn(a) * conjg(b) / sqrt(|a|**2 + |b|**2)
!>    r = sgn(a)*sqrt(|a|**2 + |b|**2)
!> عندما تكون a و b حقيقيتين و r /= 0، الصيغ تبسط إلى
!>    c = a / r
!>    s = b / r
!> نفس ما في SROTG عندما |a| > |b|. عندما |b| >= |a|،
!> سيكون إشارة c و s مختلفة عن تلك التي تحسبها SROTG
!> إذا لم تكن إشارات a و b متماثلة.
!>
!>
