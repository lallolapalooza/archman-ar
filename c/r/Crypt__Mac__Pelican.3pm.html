Crypt__Mac__Pelican(3pm)

الحزمة: perl-cryptx

التراخيص: PerlArtistic, GPL

Crypt::Mac::Pelican(3) وثائق بيرل مقدمة من المستخدم Crypt::Mac::Pelican(3)

الاسم

Crypt::Mac::Pelican - رمز مصادقة الرسالة Pelican (MAC يعتمد على AES)

الملخص

### الواجهة الوظيفية:
use Crypt::Mac::Pelican qw( pelican pelican_hex );
# حساب MAC من سلسلة/مخزن مؤقت
$pelican_raw  = pelican($key, 'buffer data');
$pelican_hex  = pelican_hex($key, 'buffer data');
$pelican_b64  = pelican_b64($key, 'buffer data');
$pelican_b64u = pelican_b64u($key, 'buffer data');
### الواجهة الكائنية:
use Crypt::Mac::Pelican;
$d = Crypt::Mac::Pelican->new($key);
$d->add('any data');
$d->addfile('filename.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->mac;     # raw bytes
$result_hex  = $d->hexmac;  # hexadecimal form
$result_b64  = $d->b64mac;  # Base64 form
$result_b64u = $d->b64umac; # Base64 URL Safe form

الوصف

يوفر واجهة لخوارزمية رمز مصادقة الرسالة Pelican (MAC).

تصدير

لا شيء يتم تصديره افتراضيًا.

يمكنك تصدير دوال محددة:

use Crypt::Mac::Pelican qw(pelican pelican_hex );

أو كلها مرة واحدة:

use Crypt::Mac::Pelican ':all';

الدوال

pelican

تجمع منطقيًا جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة رسالة Pelican الخاص بها مشفرًا كسلسلة ثنائية.

$pelican_raw = pelican($key, 'buffer data');
# أو
$pelican_raw = pelican($key, 'any data', 'more data', 'even more data');

pelican_hex

تجمع منطقيًا جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة رسالة Pelican الخاص بها مشفرًا كسلسلة سداسية عشرية.

$pelican_hex = pelican_hex($key, 'buffer data');
# أو
$pelican_hex = pelican_hex($key, 'any data', 'more data', 'even more data');

pelican_b64

تجمع منطقيًا جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة رسالة Pelican الخاص بها مشفرًا كسلسلة Base64.

$pelican_b64 = pelican_b64($key, 'buffer data');
# أو
$pelican_b64 = pelican_b64($key, 'any data', 'more data', 'even more data');

pelican_b64u

تجمع منطقيًا جميع الوسائط في سلسلة واحدة، وتعيد رمز مصادقة رسالة Pelican الخاص بها مشفرًا كسلسلة Base64 آمنة لـ URL (انظر RFC 4648 القسم 5).

$pelican_b64url = pelican_b64u($key, 'buffer data');
# أو
$pelican_b64url = pelican_b64u($key, 'any data', 'more data', 'even more data');
