CREATE_TEXT_SEARCH_CONFIGURATION(7)

الحزمة: postgresql

التراخيص: PostgreSQL

CREATE TEXT SEARCH CONFIGURATION(7) وثائق PostgreSQL 18.1 CREATE TEXT SEARCH CONFIGURATION(7)

الاسم

CREATE_TEXT_SEARCH_CONFIGURATION - تعريف تكوين بحث نصي جديد

ملخص

CREATE TEXT SEARCH CONFIGURATION name (
    PARSER = parser_name |
    COPY = source_config
)

الوصف

CREATE TEXT SEARCH CONFIGURATION ينشئ تكوين بحث نصي جديد. يحدد تكوين البحث النصي محلل بحث نصي يمكنه تقسيم سلسلة نصية إلى رموز (tokens)، بالإضافة إلى قواميس يمكن استخدامها لتحديد الرموز ذات الأهمية للبحث.

إذا تم تحديد المحلل فقط، فإن تكوين البحث النصي الجديد لا يحتوي مبدئيًا على أي تعيينات من أنواع الرموز إلى القواميس، وبالتالي سيتجاهل جميع الكلمات. يجب استخدام أوامر ALTER TEXT SEARCH CONFIGURATION اللاحقة لإنشاء تعيينات لجعل التكوين مفيدًا. بدلاً من ذلك، يمكن نسخ تكوين بحث نصي موجود.

إذا تم تحديد اسم مخطط، فسيتم إنشاء تكوين البحث النصي في المخطط المحدد. وإلا فسيتم إنشاؤه في المخطط الحالي.

المستخدم الذي يعرف تكوين بحث نصي يصبح مالكه.

ارجع إلى الفصل 12 لمزيد من المعلومات.

المعلمات

name

اسم تكوين البحث النصي المراد إنشاؤه. يمكن أن يكون الاسم مؤهلاً بالمخطط.

parser_name

اسم محلل البحث النصي لاستخدامه في هذا التكوين.

source_config

اسم تكوين بحث نصي موجود لنسخه.

ملاحظات

خيارات PARSER و COPY متعارضة، لأنه عند نسخ تكوين موجود، يتم نسخ اختياره للمحلل أيضًا.

التوافق

لا يوجد بيان CREATE TEXT SEARCH CONFIGURATION في معيار SQL.

انظر أيضًا

ALTER TEXT SEARCH CONFIGURATION (ALTER_TEXT_SEARCH_CONFIGURATION(7)), DROP TEXT SEARCH CONFIGURATION (DROP_TEXT_SEARCH_CONFIGURATION(7))
