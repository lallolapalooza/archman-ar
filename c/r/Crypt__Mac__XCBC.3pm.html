Crypt__Mac__XCBC(3pm)

الحزمة: perl-cryptx

التراخيص: PerlArtistic, GPL

Crypt::Mac::XCBC(3) وثائق مساهمة من مستخدمي بيرل Crypt::Mac::XCBC(3)

الاسم

Crypt::Mac::XCBC - رمز مصادقة الرسالة XCBC (RFC 3566)

الملخص

### واجهة وظيفية:
use Crypt::Mac::XCBC qw( xcbc xcbc_hex );
# حساب MAC من سلسلة/مخزن مؤقت
$xcbc_raw  = xcbc($cipher_name, $key, 'data buffer');
$xcbc_hex  = xcbc_hex($cipher_name, $key, 'data buffer');
$xcbc_b64  = xcbc_b64($cipher_name, $key, 'data buffer');
$xcbc_b64u = xcbc_b64u($cipher_name, $key, 'data buffer');
### واجهة الكائن:
use Crypt::Mac::XCBC;
$d = Crypt::Mac::XCBC->new($cipher_name, $key);
$d->add('any data');
$d->addfile('filename.dat');
$d->addfile(*FILEHANDLE);
$result_raw  = $d->mac;     # بايت خام
$result_hex  = $d->hexmac;  # شكل سداسي عشري
$result_b64  = $d->b64mac;  # شكل Base64
$result_b64u = $d->b64umac; # شكل Base64 آمن لـ URL

الوصف

يوفر واجهة لخوارزمية رمز مصادقة الرسالة (MAC) XCBC.

التصدير

لا يتم تصدير شيء افتراضيًا.

يمكنك تصدير دوال مختارة:

use Crypt::Mac::XCBC qw(xcbc xcbc_hex );

أو كلها مرة واحدة:

use Crypt::Mac::XCBC ':all';

الدوال

xcbc

ينضم منطقياً إلى جميع الوسائط في سلسلة واحدة، ويعيد رمز مصادقة الرسالة XCBC المشفر كسلسلة ثنائية.

$xcbc_raw = xcbc($cipher_name, $key, 'data buffer');
# أو
$xcbc_raw = xcbc($cipher_name, $key, 'any data', 'more data', 'even more data');

xcbc_hex

ينضم منطقياً إلى جميع الوسائط في سلسلة واحدة، ويعيد رمز مصادقة الرسالة XCBC المشفر كسلسلة سداسية عشرية.

$xcbc_hex = xcbc_hex($cipher_name, $key, 'data buffer');
# أو
$xcbc_hex = xcbc_hex($cipher_name, $key, 'any data', 'more data', 'even more data');

xcbc_b64

ينضم منطقياً إلى جميع الوسائط في سلسلة واحدة، ويعيد رمز مصادقة الرسالة XCBC المشفر كسلسلة Base64.

$xcbc_b64 = xcbc_b64($cipher_name, $key, 'data buffer');
# أو
$xcbc_b64 = xcbc_b64($cipher_name, $key, 'any data', 'more data', 'even more data');

xcbc_b64u

ينضم منطقياً إلى جميع الوسائط في سلسلة واحدة، ويعيد رمز مصادقة الرسالة XCBC المشفر كسلسلة Base64 آمنة لـ URL (انظر RFC 4648 القسم 5).

$xcbc_b64url = xcbc_b64u($cipher_name, $key, 'data buffer');
# أو
$xcbc_b64url = xcbc_b64u($cipher_name, $key, 'any data', 'more data', 'even more data');
