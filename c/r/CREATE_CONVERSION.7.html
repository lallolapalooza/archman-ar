CREATE_CONVERSION(7)

الحزمة: postgresql

التراخيص: PostgreSQL

CREATE CONVERSION(7) توثيق PostgreSQL 18.1 CREATE CONVERSION(7)

الاسم

CREATE_CONVERSION - تعريف تحويل ترميز جديد

الملخص

CREATE [ DEFAULT ] CONVERSION name
    FOR source_encoding TO dest_encoding FROM function_name

الوصف

CREATE CONVERSION يحدد تحويلًا جديدًا بين مجموعتي ترميز حرفيين.

التحويلات التي تم تمييزها كـ DEFAULT يمكن استخدامها للتحويل التلقائي للترميز بين العميل والخادم. لدعم هذا الاستخدام، يجب تعريف تحويلين، من الترميز A إلى B و من الترميز B إلى A.

لكي تتمكن من إنشاء تحويل، يجب أن يكون لديك صلاحية EXECUTE على الدالة وصلاحية CREATE على المخطط الوجهة.

المعلمات

DEFAULT

تشير عبارة DEFAULT إلى أن هذا التحويل هو الافتراضي لزوج ترميز المصدر إلى الوجهة هذا. يجب أن يكون هناك افتراضي ترميز واحد فقط في مخطط لزوج الترميز.

name

اسم التحويل. يمكن أن يكون اسم التحويل مؤهلًا بالمخطط. إذا لم يكن كذلك، يتم تعريف التحويل في المخطط الحالي. يجب أن يكون اسم التحويل فريدًا داخل المخطط.

source_encoding

اسم ترميز المصدر.

dest_encoding

اسم ترميز الوجهة.

function_name

الدالة المستخدمة لإجراء التحويل. يمكن أن يكون اسم الدالة مؤهلًا بالمخطط. إذا لم يكن كذلك، فسيتم البحث عن الدالة في المسار.

يجب أن تحتوي الدالة على التوقيع التالي:

conv_proc(
    integer,  -- معرف ترميز المصدر
    integer,  -- معرف ترميز الوجهة
    cstring,  -- سلسلة المصدر (سلسلة C تنتهي بـ null)
    internal, -- الوجهة (املأها بسلسلة C تنتهي بـ null)
    integer,  -- طول سلسلة المصدر
    boolean   -- إذا كان صحيحًا، لا تقم بإطلاق خطأ إذا فشل التحويل
) RETURNS integer;

قيمة الإرجاع هي عدد بايتات المصدر التي تم تحويلها بنجاح. إذا كانت الحجة الأخيرة خاطئة، يجب أن تطلق الدالة خطأً على المدخلات غير الصالحة، وقيمة الإرجاع تساوي دائمًا طول سلسلة المصدر.

ملاحظات

لا يمكن أن يكون ترميز المصدر أو الوجهة SQL_ASCII، لأن سلوك الخادم في الحالات التي تتضمن ترميز SQL_ASCII محدد مسبقًا.

استخدم DROP CONVERSION لإزالة التحويلات المعرفة بواسطة المستخدم.

قد يتم تغيير الصلاحيات المطلوبة لإنشاء تحويل في إصدار مستقبلي.

أمثلة

لإنشاء تحويل من ترميز UTF8 إلى LATIN1 باستخدام myfunc:

CREATE CONVERSION myconv FOR 'UTF8' TO 'LATIN1' FROM myfunc;

التوافق

CREATE CONVERSION هو امتداد لـ PostgreSQL. لا يوجد عبارة CREATE CONVERSION في معيار SQL، ولكن توجد عبارة CREATE TRANSLATION ذات غرض وبنية متشابهة جدًا.

انظر أيضًا

ALTER CONVERSION (ALTER_CONVERSION(7)), CREATE FUNCTION (CREATE_FUNCTION(7)), DROP CONVERSION (DROP_CONVERSION(7))
