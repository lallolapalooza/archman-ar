CREATE_TEXT_SEARCH_PARSER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

CREATE TEXT SEARCH PARSER(7) توثيق PostgreSQL 18.1 CREATE TEXT SEARCH PARSER(7)

اسم

CREATE_TEXT_SEARCH_PARSER - تعريف محلل بحث نصي جديد

الملخص

CREATE TEXT SEARCH PARSER name (
    START = start_function ,
    GETTOKEN = gettoken_function ,
    END = end_function ,
    LEXTYPES = lextypes_function
    [, HEADLINE = headline_function ]
)

الوصف

CREATE TEXT SEARCH PARSER ينشئ محلل بحث نصي جديد. يحدد محلل البحث النصي طريقة لتقسيم سلسلة نصية إلى كلمات (tokens) وتعيين أنواع (فئات) لهذه الكلمات. المحلل بحد ذاته ليس مفيدًا بشكل خاص، ولكنه يجب أن يتم ربطه في تكوين بحث نصي مع بعض قواميس البحث النصي ليتم استخدامه في البحث.

إذا تم توفير اسم مخطط، فسيتم إنشاء محلل البحث النصي في المخطط المحدد. بخلاف ذلك، سيتم إنشاؤه في المخطط الحالي.

يجب أن تكون مستخدمًا خارقًا لاستخدام CREATE TEXT SEARCH PARSER. (هذا القيد مفروض لأن تعريف محلل بحث نصي خاطئ قد يربك الخادم أو حتى يتسبب في تعطله).

ارجع إلى الفصل 12 لمزيد من المعلومات.

المعلمات

name

اسم محلل البحث النصي الذي سيتم إنشاؤه. يمكن أن يكون الاسم مؤهلاً بمخطط.

start_function

اسم دالة البدء للمحلل.

gettoken_function

اسم دالة الحصول على الكلمة التالية للمحلل.

end_function

اسم دالة النهاية للمحلل.

lextypes_function

اسم دالة أنواع الكلمات للمحلل (دالة تعيد معلومات حول مجموعة أنواع الكلمات التي تنتجها).

headline_function

اسم دالة العناوين للمحلل (دالة تلخص مجموعة من الكلمات).

يمكن أن تكون أسماء الدوال مؤهلة بمخطط إذا لزم الأمر. لا يتم إعطاء أنواع الوسائط، لأن قائمة الوسائط لكل نوع من الدوال محددة مسبقًا. كل الدوال ما عدا دالة العناوين مطلوبة.

يمكن أن تظهر الوسائط بأي ترتيب، وليس فقط بالترتيب الموضح أعلاه.

التوافق

لا يوجد بيان CREATE TEXT SEARCH PARSER في معيار SQL.

انظر أيضًا

ALTER TEXT SEARCH PARSER (ALTER_TEXT_SEARCH_PARSER(7)), DROP TEXT SEARCH PARSER (DROP_TEXT_SEARCH_PARSER(7))
