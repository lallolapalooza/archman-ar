cxl_new(3)

الحزمة: ndctl

التراخيص: LGPL

CXL_NEW(3) دليل libcxl CXL_NEW(3)

الاسم

cxl_new - إنشاء كائن سياق مكتبة جديد يعمل كمقبض لجميع عمليات المكتبة

ملخص

#include <cxl/libcxl.h>
int cxl_new(struct cxl_ctx **ctx);

الوصف

يقوم بتهيئة سياق مكتبة جديد، ويخزن مؤشرًا غير شفاف في ctx. يتم تحرير السياق بواسطة linklibcxl:cxl_unref[3]، أي أن cxl_new(3) يتضمن linklibcxl:cxl_ref[3] داخليًا.

قيمة الإرجاع

يعيد 0 عند النجاح، ورمز خطأ سالب (errno) عند الفشل. رموز الخطأ المحتملة هي:

•-ENOMEM
•-ENXIO
