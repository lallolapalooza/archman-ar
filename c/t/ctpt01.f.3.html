توثيق الوظيفة/الروتين الفرعي

subroutine ctpt01 (character uplo, character diag, integer n, complex, dimension( * ) ap, complex, dimension( * ) ainvp, real rcond, real, dimension( * ) rwork, real resid)

CTPT01

الغرض:

!>
!> CTPT01 يحسب الباقي لمصفوفة مثلثية A مضروبة في معكوسها عندما يتم تخزين A
!> بتنسيق مضغوط:
!>    RESID = norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS ),
!> حيث EPS هو خطأ الآلة.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A علوية أم سفلية.
!>          = 'U':  علوية
!>          = 'L':  سفلية
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A وحدة مثلثية أم لا.
!>          = 'N':  غير وحدة مثلثية
!>          = 'U':  وحدة مثلثية
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

AP

!>          AP is COMPLEX array, dimension (N*(N+1)/2)
!>          المصفوفة المثلثية الأصلية A، مضغوطة
!>          عمودياً في مصفوفة خطية. يتم تخزين العمود j من A
!>          في المصفوفة AP كالتالي:
!>          إذا كان UPLO = 'U'، فإن AP((j-1)*j/2 + i) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'،
!>             AP((j-1)*(n-j) + j*(j+1)/2 + i-j) = A(i,j) لـ j<=i<=n.
!>

AINVP

!>          AINVP is COMPLEX array, dimension (N*(N+1)/2)
!>          عند الدخول، معكوس (المثلثي) للمصفوفة A، مضغوط
!>          عمودياً في مصفوفة خطية كما في AP.
!>          عند الخروج، يتم تدمير محتويات AINVP.
!>

RCOND

!>          RCOND is REAL
!>          الشرط العكسي للمصفوفة A، محسوب كـ
!>          1/(norm(A) * norm(AINV)).
!>

RWORK

!>          RWORK is REAL array, dimension (N)
!>

RESID

!>          RESID is REAL
!>          norm(A*AINV - I) / ( N * norm(A) * norm(AINV) * EPS )
!>
