ctags-lang-tcl(7)

الحزمة: ctags

التراخيص: GPL-2.0-only

ctags-lang-tcl(7) Universal Ctags ctags-lang-tcl(7)

الاسم

ctags-lang-tcl - ملاحظات عشوائية حول وضع علامات على كود Tcl المصدري باستخدام Universal Ctags

الملخص

ctags ... --languages=+Tcl ...
ctags ... --language-force=Tcl ...
ctags ... --map-Tcl=+.tcl ...

الوصف

تجمع صفحة الدليل هذه ملاحظات عشوائية حول وضع علامات على كود Tcl المصدري.

تمييز كائنات لغة الامتدادات البرمجية الكائنية (OO Extensions)

محلل TclOO ومحلل ITcl هما محللان فرعيان يعملان على محلل Tcl. كما توضح أسماء المحللات، فهما مخصصان لوضع علامات على كائنات لغة امتدادات البرمجة الكائنية للغة Tcl.

النمط "namespace import oo" في ملف الإدخال ينشط محلل TclOO. النمط "namespace import itcl" في ملف الإدخال ينشط محلل ITcl.

هناك حالات يتم فيها استخدام أحد الامتدادات الكائنية على الرغم من عدم ظهور أي من النمطين في ملف الإدخال.

ضع في اعتبارك ملفات الإدخال التالية:

"main.tcl"

package require Itcl
namespace import itcl::*
source input.tcl

"input.tcl"

class MyClass {
        public method foo {} {
        }
}

النمط لتنشيط محلل ITcl غير موجود في "input.tcl" على الرغم من استخدام الأمر "class". نتيجة لذلك، لا يمكن لـ ctags استخراج "MyClass".

المعلمات TclOO.forceUse=true|[false] و ITcl.forceuse=true|[false] لمعالجة هذا الموقف. باستخدام المعلمات، يمكنك إجبار ctags على تنشيط أحد المحللات الفرعية.

يمكنك استخدام المعلمات مثل --param-ITcl.forceuse=true في سطر الأوامر.

لاحظ أنه يمكنك تمكين محلل ITcl أو محلل TclOO فقط. تمكين كلا المحللين بتحديد المعلمات يمكن أن يؤدي إلى نتائج غير متوقعة.
