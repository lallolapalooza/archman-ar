توثيق الوظيفة/الروتين الفرعي

subroutine ctrtri (character uplo, character diag, integer n, complex, dimension( lda, * ) a, integer lda, integer info)

CTRTRI

الغرض:

!>
!> CTRTRI تحسب معكوس مصفوفة مثلثية معقدة علوية أو سفلية
!> A.
!>
!> هذا هو الإصدار من المستوى 3 BLAS للخوارزمية.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular; (A مصفوفة مثلثية علوية)
!>          = 'L':  A is lower triangular. (A مصفوفة مثلثية سفلية)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular; (A غير أحادية)
!>          = 'U':  A is unit triangular. (A أحادية)
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0. (مرتبة المصفوفة A. N أكبر من أو تساوي 0)
!>

A

!>          A is COMPLEX array, dimension (LDA,N)
!>          On entry, the triangular matrix A.  If UPLO = 'U', the
!>          leading N-by-N upper triangular part of the array A contains
!>          the upper triangular matrix, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of the array A contains
!>          the lower triangular matrix, and the strictly upper
!>          triangular part of A is not referenced.  If DIAG = 'U', the
!>          diagonal elements of A are also not referenced and are
!>          assumed to be 1.
!>          On exit, the (triangular) inverse of the original matrix, in
!>          the same storage format.
!> (عند الإدخال، المصفوفة المثلثية A. إذا كانت UPLO = 'U'، فإن الجزء العلوي المثلثي الرئيسي N×N من المصفوفة A يحتوي على المصفوفة المثلثية العلوية، ولا يتم الإشارة إلى الجزء المثلثي السفلي الصارم من A. إذا كانت UPLO = 'L'، فإن الجزء السفلي المثلثي الرئيسي N×N من المصفوفة A يحتوي على المصفوفة المثلثية السفلية، ولا يتم الإشارة إلى الجزء المثلثي العلوي الصارم من A. إذا كانت DIAG = 'U'، فإن عناصر القطر الرئيسي لـ A لا يتم الإشارة إليها أيضًا ويفترض أنها 1.
!> عند الخروج، معكوس المصفوفة الأصلية (المثلثية) بنفس صيغة التخزين.)
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N). (البعد الرائد للمصفوفة A. LDA أكبر من أو تساوي الحد الأقصى (1، N))
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit (خروج ناجح)
!>          < 0: if INFO = -i, the i-th argument had an illegal value (إذا كانت INFO = -i، فإن الوسيط i كان له قيمة غير قانونية)
!>          > 0: if INFO = i, A(i,i) is exactly zero.  The triangular
!>               matrix is singular and its inverse can not be computed.
!> (إذا كانت INFO = i، فإن A(i,i) تساوي صفرًا تمامًا. المصفوفة المثلثية منفردة ولا يمكن حساب معكوسها.)
!>
