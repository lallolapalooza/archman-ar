CTLOG_STORE_new(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

CTLOG_STORE_NEW(3ssl) OpenSSL CTLOG_STORE_NEW(3ssl)

الاسم

CTLOG_STORE_new_ex, CTLOG_STORE_new, CTLOG_STORE_free, CTLOG_STORE_load_default_file, CTLOG_STORE_load_file - إنشاء وتعبئة قائمة سجلات شفافية الشهادات

الملخص

#include <openssl/ct.h>
CTLOG_STORE *CTLOG_STORE_new_ex(OSSL_LIB_CTX *libctx, const char *propq);
CTLOG_STORE *CTLOG_STORE_new(void);
void CTLOG_STORE_free(CTLOG_STORE *store);
int CTLOG_STORE_load_default_file(CTLOG_STORE *store);
int CTLOG_STORE_load_file(CTLOG_STORE *store, const char *file);

الوصف

CTLOG_STORE هو حاوية لقائمة من سجلات شفافية الشهادات (CT logs). يمكن تحميل القائمة من ملف واحد أو أكثر ثم البحث فيها بواسطة LogID (انظر RFC 6962، القسم 3.2، لتعريف LogID).

CTLOG_STORE_new_ex() تنشئ قائمة فارغة من سجلات CT مرتبطة بسياق المكتبة libctx وسلسلة استعلام الخصائص propq.

CTLOG_STORE_new() تفعل نفس الشيء مثل CTLOG_STORE_new_ex() ولكن باستخدام سياق المكتبة الافتراضي وسلسلة استعلام الخصائص.

يتم بعد ذلك تعبئة CTLOG_STORE بواسطة CTLOG_STORE_load_default_file() أو CTLOG_STORE_load_file(). CTLOG_STORE_load_default_file() التحميل من الملف الافتراضي، والذي يُطلق عليه اسم ct_log_list.cnf في OPENSSLDIR (انظر مخرجات openssl-version(1)). يمكن تجاوز هذا باستخدام متغير بيئة يُسمى CTLOG_FILE. CTLOG_STORE_load_file() التحميل من مسار ملف محدد بواسطة المتصل بدلاً من ذلك. كلا هاتين الدالتين تضيفان أي سجلات CT محملة إلى CTLOG_STORE.

التنسيق المتوقع للملف هو:

enabled_logs=foo,bar
[foo]
description = Log 1
key = <base64-encoded DER SubjectPublicKeyInfo here>
[bar]
description = Log 2
key = <base64-encoded DER SubjectPublicKeyInfo here>

بمجرد عدم الحاجة إلى CTLOG_STORE، يجب تمريره إلى CTLOG_STORE_free(). سيؤدي ذلك إلى حذف جميع سجلات CT المخزنة بداخله، جنبًا إلى جنب مع CTLOG_STORE نفسه. إذا كان الوسيط NULL، فلن يتم فعل أي شيء.

ملاحظات

إذا كانت هناك أي سجلات CT غير صالحة في ملف، فسيتم تخطيها وسيتم إضافة السجلات الصالحة المتبقية إلى CTLOG_STORE. سيتم اعتبار سجل CT غير صالح إذا كان يفتقر إلى حقل "key" أو "description".

قيم الإرجاع

كل من CTLOG_STORE_load_default_file و CTLOG_STORE_load_file ترجع 1 إذا تم تحليل وتحميل جميع سجلات CT في الملف بنجاح، و 0 بخلاف ذلك.

انظر أيضاً

ct(7), CTLOG_STORE_get0_log_by_id(3), SSL_CTX_set_ctlog_list_file(3)

التاريخ

تمت إضافة CTLOG_STORE_new_ex في OpenSSL 3.0. تم إضافة جميع الوظائف الأخرى في OpenSSL 1.1.0.
