ctags-json-output(5)

الحزمة: ctags

التراخيص: GPL-2.0-only

ctags-json-output(5) Universal Ctags ctags-json-output(5)

الاسم

ctags-json-output - إخراج ctags المستند إلى JSON

الملخص

ctags --output-format=json ...

الوصف

يدعم Universal Ctags تنسيق الإخراج JSON https://www.json.org/ (بشكل أكثر تحديدًا JSON Lines https://jsonlines.org/) إذا تم بناء قابل التنفيذ ctags مع libjansson. ينتقل إخراج JSON إلى الإخراج القياسي افتراضيًا.

التنسيق

يمثل كل سطر JSON علامة.

$ ctags --extras=+p --output-format=json --fields=-s input.py
{"_type": "ptag", "name": "JSON_OUTPUT_VERSION", "path": "1.0", "pattern": "in development"}
{"_type": "ptag", "name": "TAG_FILE_SORTED", "path": "1", "pattern": "0=unsorted, 1=sorted, 2=foldcase"}
...
{"_type": "tag", "name": "Klass", "path": "/tmp/input.py", "pattern": "/^class Klass:$/", "language": "Python", "kind": "class"}
{"_type": "tag", "name": "method", "path": "/tmp/input.py", "pattern": "/^    def method(self):$/", "language": "Python", "kind": "member", "scope": "Klass", "scopeKind": "class"}
...

يتم تعيين المفتاح الذي لا يبدأ بـ _ إلى حقل من ctags. الخياران "--output-format=json --list-fields" يسردان الحقول.

يمثل المفتاح الذي يبدأ بـ _ معلومات وصفية لسطر JSON. حاليًا، المفتاح الوحيد المستخدم هو _type. إذا كانت القيمة للمفتاح هي tag، فإن سطر JSON يمثل علامة عادية. إذا كانت القيمة ptag، فإن السطر يمثل علامة زائفة.

يمكن تغيير تنسيق الإخراج في المستقبل. يوفر المفتاح الزائف JSON_OUTPUT_VERSION أدوات عميل لمعالجة التغييرات. الإصدار الحالي هو "1.0". يمكن لأداة العميل استخراج الإصدار باستخدام المفتاح path من العلامة الزائفة.

تنسيق إخراج JSON مصمم حديثًا وليس له قيود موجودة في تنسيق ملف العلامات الافتراضي.

  • تتمثل القيم للمفتاح kind في علامات الاسم الطويل. لا توجد هنا علامة ذات حرف واحد.
  • تم تمييز أسماء النطاق وأنواع النطاقات بمفاتيح مميزة: scope و scopeKind. يتم دمجهما في تنسيق ملف العلامات الافتراضي.

نوع البيانات المستخدم في الحقل

تتمثل القيم لمعظم جميع المفاتيح في نوع سلسلة JSON. ومع ذلك، يتم تمثيل بعضها كسلسلة، أو عدد صحيح، أو / أو قيمة منطقية.

الخياران "--output-format=json --list-fields" يوضحان نوع البيانات المستخدم في حقل JSON.

$ ctags --output-format=json --list-fields
#LETTER NAME           ENABLED LANGUAGE         JSTYPE FIXED DESCRIPTION
F       input          yes     NONE             s--    no    input file
...
P       pattern        yes     NONE             s-b    no    pattern
...
f       file           yes     NONE             --b    no    File-restricted scoping
...
e       end            no      NONE             -i-    no    end lines of various items
...

يوضح عمود JSTYPE أنواع البيانات.

's'
سلسلة
'i'
عدد صحيح
'b'
قيمة منطقية (صحيح أو خطأ)

على سبيل المثال، قيمة الحقل pattern لـ ctags تأخذ قيمة سلسلة أو قيمة منطقية.

الإصدارات

التغيير منذ "0.0"

•
مفتاح جديد kindName للعلامة الزائفة TAG_ROLE_DESCRIPTION

تمت إضافة kindName لتخزين اسم النوع في العلامات الزائفة TAG_ROLE_DESCRIPTION.

في الإصدار 0.0، تمت طباعة علامة "TAG_ROLE_DESCRIPTION" الزائفة بالشكل التالي:

{"_type": "ptag", "name": "TAG_ROLE_DESCRIPTION",
                  "parserName": "LANG!KIND", }

في الإصدار 1.0، تتم طباعتها بالشكل التالي:

{"_type": "ptag", "name": "TAG_ROLE_DESCRIPTION",
                  "parserName": "LANG",
                  "kindName": "KIND",  }
