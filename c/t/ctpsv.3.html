subroutine ctpsv (character uplo, character trans, character diag, integer n, complex, dimension(*) ap, complex, dimension(*) x, integer incx)

CTPSV

الغرض:

!>
!> CTPSV  يحل أحد أنظمة المعادلات
!>
!>    A*x = b,   أو   A**T*x = b,   أو   A**H*x = b,
!>
!> حيث b و x متجهان يتكونان من n عنصر، و A مصفوفة مثلثية عليا أو سفلى
!> بحجم n × n، إما مفردة، أو غير مفردة، مقدمة في شكل مضغوط.
!>
!> لا يتضمن هذا الإجراء أي اختبارات للانفراد أو القرب من الانفراد.
!> يجب إجراء هذه الاختبارات قبل استدعاء هذا الإجراء.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>           عند الإدخال، يحدد UPLO ما إذا كانت المصفوفة مصفوفة مثلثية عليا أو سفلى
!>           على النحو التالي:
!>
!>              UPLO = 'U' or 'u'   A is an upper triangular matrix.
!>
!>              UPLO = 'L' or 'l'   A is a lower triangular matrix.
!>

TRANS

!>          TRANS is CHARACTER*1
!>           عند الإدخال، يحدد TRANS المعادلات التي سيتم حلها على النحو التالي:
!>
!>              TRANS = 'N' or 'n'   A*x = b.
!>
!>              TRANS = 'T' or 't'   A**T*x = b.
!>
!>              TRANS = 'C' or 'c'   A**H*x = b.
!>

DIAG

!>          DIAG is CHARACTER*1
!>           عند الإدخال، يحدد DIAG ما إذا كانت A مصفوفة مثلثية مفردة أم لا
!>           على النحو التالي:
!>
!>              DIAG = 'U' or 'u'   A is assumed to be unit triangular.
!>
!>              DIAG = 'N' or 'n'   A is not assumed to be unit
!>                                  triangular.
!>

N

!>          N is INTEGER
!>           عند الإدخال، يحدد N رتبة المصفوفة A.
!>           يجب أن يكون N على الأقل صفرًا.
!>

AP

!>          AP is COMPLEX array, dimension at least
!>           ( ( n*( n + 1 ) )/2 ).
!>           قبل الإدخال مع UPLO = 'U' أو 'u'، يجب أن يحتوي الصف AP على
!>           المصفوفة المثلثية العليا مضغوطة بالتتابع،
!>           عمودًا بعمود، بحيث يحتوي AP( 1 ) على a( 1, 1 )،
!>           ويحتوي AP( 2 ) و AP( 3 ) على a( 1, 2 ) و a( 2, 2 )
!>           على التوالي، وهكذا.
!>           قبل الإدخال مع UPLO = 'L' أو 'l'، يجب أن يحتوي الصف AP على
!>           المصفوفة المثلثية السفلى مضغوطة بالتتابع،
!>           عمودًا بعمود، بحيث يحتوي AP( 1 ) على a( 1, 1 )،
!>           ويحتوي AP( 2 ) و AP( 3 ) على a( 2, 1 ) و a( 3, 1 )
!>           على التوالي، وهكذا.
!>           لاحظ أنه عندما يكون DIAG = 'U' أو 'u'، لا يتم الرجوع إلى عناصر القطر
!>           لـ A، ولكنها مفترضة أنها الوحدة.
!>

X

!>          X is COMPLEX array, dimension at least
!>           ( 1 + ( n - 1 )*abs( INCX ) ).
!>           قبل الإدخال، يجب أن يحتوي الصف X ذو الزيادة على متجه الطرف الأيمن b
!>           المكون من n عنصر. عند الخروج، يتم الكتابة فوق X بالمتجه الحل x.
!>

INCX

!>          INCX is INTEGER
!>           عند الإدخال، يحدد INCX الزيادة لعناصر X.
!>           يجب ألا يكون INCX صفرًا.
!>
