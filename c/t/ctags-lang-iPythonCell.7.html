ctags-lang-iPythonCell(7)

الحزمة: ctags

التراخيص: GPL-2.0-only

ctags-lang-iPythonCell(7) Universal Ctags ctags-lang-iPythonCell(7)

الاسم

ctags-lang-iPythonCell - صفحة الدليل للمحلل iPythonCell لـ Universal Ctags

الملخص

ctags ... --extras=+{subparser} --languages=+iPythonCell,Python \
[--extras-IPythonCell=+{doubleSharps}] \
[--regex-IPythonCell=/<PATTERN>/\n/c/] ...

الوصف

محلل iPythonCell هو محلل فرعي مكدس فوق محلل Python. يعمل عندما:

  • يكون محلل Python ممكّنًا،
  • يكون المحلل الفرعي الإضافي ممكّنًا، و
  • يكون محلل iPythonCell نفسه ممكّنًا.

يقوم محلل iPythonCell باستخراج الخلايا المشروحة كما في vim-ipython-cell (https://github.com/hanschen/vim-ipython-cell/blob/master/README.md).

النوع (الأنواع)

يحدد محلل iPythonCell نوع cell فقط.

الإضافات

تم تعطيل وضع العلامات على الخلايا التي تبدأ بـ ##... بشكل افتراضي لأن النمط عام جدًا؛ مع هذا النمط، يمكن استخراج علامات غير مرغوب فيها.

قم بتمكين الإضافة الخاصة باللغة doubleSharps لوضع العلامات على الخلايا التي تبدأ بـ ##....

التخصيص

إذا لم يكن نمط الخلية المفضل لديك مدعومًا في المحلل، يمكنك تحديد النمط في .ctagd.d/your.ctags أو في أسطر الأوامر. إليك مثال لدعم "# CTAGS: ...":

"input.py"

x=1
# CTAGS: DEFINE F
def F():
        # CTAGS: DO NOTING
        pass

"output.tags" مع "--options=NONE --sort=no --extras=+{subparser} --regex-IPythonCell=/[ t]*# CTAGS:[ ]?(.*)$/1/c/ -o - input.py"

x    input.py        /^x=1$/;"       v
DEFINE F     input.py        /^# CTAGS: DEFINE F$/;" c
F    input.py        /^def F():$/;"  f
DO NOTING    input.py        /^      # CTAGS: DO NOTING$/;"  c

يمكنك وضع "--regex-IPythonCell=/[ \t]*# CTAGS:[ ]?(.*)$/\1/c/" في your.ctags لتجنب تحديد النمط بشكل متكرر.
