ctags-lang-sql(7)

الحزمة: ctags

التراخيص: GPL-2.0-only

ctags-lang-sql(7) Universal Ctags ctags-lang-sql(7)

الاسم

ctags-lang-sql - صفحة دليل محلل SQL لـ Universal Ctags

ملخص

ctags ... [--extras={guest}] --languages=+SQL ...

الوصف

يدعم محلل SQL لهجات SQL المختلفة. PostgreSQL هو أحدها.

تسمح PostgreSQL بإنشاء وظائف معرفة من قبل المستخدم بلغات أخرى (لغات إجرائية) بالإضافة إلى SQL و C [PL].

يقوم محلل SQL بإنشاء علامات للكائنات اللغوية في الوظائف المعرفة من قبل المستخدم المكتوبة باللغات الإجرائية إذا تم تمكين الإضافة guest.

يبحث محلل SQL عن رمز يأتي بعد الكلمة المفتاحية LANGUAGE في الكود المصدري لاختيار محلل ضيف مناسب.

... LANGUAGE plpythonu AS '... user-defined function ' ...
... AS $$ user-defined function $$ LANGUAGE plv8 ...

في الأمثلة أعلاه، plpythonu و plv8 هما اسما لغات إجرائية. يقوم محلل SQL بإزالة pl في البداية و u في نهاية الاسم قبل العثور على محلل ctags. بالنسبة لـ plpythonu و plv8، يستخرج محلل SQL python و v8 كمرشحين للمحللين الضيوف.

بالنسبة لـ plpythonu، يمكن لـ ctags تشغيل محلله بلغة Python. لا يمتلك ctags محللاً باسم v8. ومع ذلك، فإن محلل JavaScript في ctags لديه v8 كاسم مستعار. لذا يمكن لـ ctags تشغيل محلل JavaScript كمحلل ضيف لـ plv8.

أمثلة

وضع علامات على الكود بما في ذلك وظيفة معرفة من قبل المستخدم في سلسلة نصية [GH3006]:

"input.sql"

CREATE OR REPLACE FUNCTION fun1() RETURNS VARCHAR AS '
DECLARE
        test1_var1 VARCHAR(64) := $$ABC$$;
        test1_var2 VARCHAR(64) := $xyz$XYZ$xyz$;
        test1_var3     INTEGER := 1;
BEGIN
        RETURN  TO_CHAR(test_var3, ''000'') || test1_var1 || test1_var2;
END;
' LANGUAGE plpgsql;

"output.tags" مع "--options=NONE -o - --sort=no --extras=+{guest} input.sql"

fun1    input.sql       /^CREATE OR REPLACE FUNCTION fun1() RETURNS VARCHAR AS '$/;"    f       typeref:typename:VARCHAR
test1_var1      input.sql       /^      test1_var1 VARCHAR(64) := $$ABC$$;$/;"  v
test1_var2      input.sql       /^      test1_var2 VARCHAR(64) := $xyz$XYZ$xyz$;$/;"    v
test1_var3      input.sql       /^      test1_var3     INTEGER := 1;$/;"        v

وضع علامات على الكود بما في ذلك وظيفة معرفة من قبل المستخدم في علامة الدولار [GH3006]:

"input.sql"

CREATE OR REPLACE FUNCTION fun2() RETURNS VARCHAR LANGUAGE plpgsql AS $$
DECLARE
        test2_var1 VARCHAR(64) := 'ABC2';
        test2_var2 VARCHAR(64) := 'XYZ2';
        test2_var3        INTEGER := 2;
BEGIN
        RETURN  TO_CHAR(test2_var3, '000') || test2_var1 || test2_var2;
END;
$$;

"output.tags" مع "--options=NONE -o - --sort=no --extras=+{guest} input.sql"

fun2    input.sql       /^CREATE OR REPLACE FUNCTION fun2() RETURNS VARCHAR LANGUAGE plpgsql AS $\$$/;" f       typeref:typename:VARCHAR
test2_var1      input.sql       /^      test2_var1 VARCHAR(64) := 'ABC2';$/;"   v
test2_var2      input.sql       /^      test2_var2 VARCHAR(64) := 'XYZ2';$/;"   v
test2_var3      input.sql       /^      test2_var3        INTEGER := 2;$/;"     v

وضع علامات على الكود بما في ذلك وظيفة مكتوبة بلغة JavaScript:

-- Derived from https://github.com/plv8/plv8/blob/r3.0alpha/sql/plv8.sql
CREATE FUNCTION test(keys text[], vals text[]) RETURNS text AS
$$
        var o = {};
        for (var i = 0; i < keys.length; i++)
                o[keys[i]] = vals[i];
        return JSON.stringify(o);
$$
LANGUAGE plv8 IMMUTABLE STRICT;

"output.tags" مع "--options=NONE -o - --sort=no --extras=+{guest} input.sql"

test    input.sql       /^CREATE FUNCTION test(keys text[], vals text[]) RETURNS text AS$/;"    f
o       input.sql       /^      var o = {};$/;" v

أخطاء معروفة

قد تتسبب تسلسلات الهروب ('') في سلسلة نصية في إرباك المحلل الضيف.
