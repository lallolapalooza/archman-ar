bup-web(1)

الحزمة: bup

التراخيص: GPL-2.0-only

bup-web(1) bup-web(1)

الاسم

bup-web - بدء خادم الويب لتصفح مستودعات bup

الملخص

bup web [[hostname]:port]

bup web unix://path

الوصف

bup web يبدأ خادم ويب يمكنه تصفح مستودعات bup. التسلسل الهرمي للملفات هو نفسه الذي تعرضه bup-fuse(1), bup-ls(1) و bup-ftp(1).

hostname و port افتراضيًا هما 127.0.0.1 و 8080 على التوالي، وبالتالي فإن bup web سيقدم فقط خادم الويب للعملاء الذين يعملون محليًا. إذا كنت ترغب في تعريض خادم الويب لأي شخص على شبكتك (خطير!) يمكنك حذف عنوان الربط لربطه بجميع الواجهات المتاحة: :8080.

عند تحديد unix://path، سيستمع الخادم على مقبس نظام الملفات في path بدلاً من مقبس شبكة.

يمكن إرسال إشارة SIGTERM إلى الخادم لطلب إيقاف تشغيل منظم.

الخيارات

--human-readable
عرض أحجام الملفات بشكل قابل للقراءة (أي 3.9K، 4.7M)
--browser
فتح الموقع في المتصفح الافتراضي

أمثلة

$ bup web
Serving HTTP on 127.0.0.1:8080...
^C
Interrupted.
$ bup web :8080
Serving HTTP on 0.0.0.0:8080...
^C
Interrupted.
$ bup web unix://socket &
Serving HTTP on filesystem socket 'socket'
$ curl --unix-socket ./socket http://localhost/
$ fg
bup web unix://socket
^C
Interrupted.
$ bup web &
[1] 30980
Serving HTTP on 127.0.0.1:8080...
$ kill -s TERM 30980
Shutdown requested
$ wait 30980
$ echo $?
0
