btrfs-property(8)

الحزمة: btrfs-progs

التراخيص: GPL-2.0-only

BTRFS-PROPERTY(8) BTRFS BTRFS-PROPERTY(8)

الاسم

btrfs-property - الحصول/تعيين/سرد الخصائص لكائن نظام الملفات المحدد

ملخص

btrfs property <أمر فرعي> <وسائط>

الوصف

يُستخدم btrfs property للحصول/تعيين/سرد الخصائص لكائن نظام ملفات معين. يمكن أن يكون الكائن عبارة عن inod (ملف أو دليل)، أو وحدة فرعية (subvolume)، أو نظام الملفات بالكامل.

يوفر btrfs property طريقة موحدة وسهلة الاستخدام لضبط خصائص btrfs المختلفة بدلاً من استخدام الطريقة التقليدية مثل chattr(1) https://man7.org/linux/man-pages/man1/chattr.1.html أو lsattr(1) https://man7.org/linux/man-pages/man1/lsattr.1.html.

أنواع الكائنات

قد تنطبق الخاصية على عدة أنواع من الكائنات، لذلك في بعض الحالات من الضروري تحديد ذلك صراحةً، ومع ذلك، فإنه ليس ضروريًا في الحالة الأكثر شيوعًا للملفات والأدلة.

تأخذ الأوامر الفرعية المعلمة -t، استخدم الحرف الأول كاختصار ( f/s/d/i) للنوع:

  • نظام الملفات (filesystem)
  • وحدة فرعية (subvolume)
  • جهاز (device)
  • inod (ملف أو دليل)

خصائص inod

compression
خوارزمية الضغط المعينة لـ inod (لا يمكن تعيين مستوى الضغط بهذه الطريقة)، القيم الممكنة:
  • lzo
  • zlib
  • zstd
  • no أو none - تعطيل الضغط (يعادل chattr +m)
  • "" (سلسلة فارغة) - تعيين القيمة الافتراضية

ملاحظة:

لقد تغير هذا في الإصدار 5.18 من btrfs-progs ويتطلب نواة 5.14 أو أحدث للعمل.

خصائص الوحدة الفرعية

ro
علامة القراءة فقط (read-only) للوحدة الفرعية: true أو false. يرجى أيضًا الرجوع إلى القسم علامات الوحدة الفرعية في btrfs-subvolume(8) <> للآثار المحتملة فيما يتعلق بالإرسال التدريجي.

خصائص نظام الملفات

label
تسمية نظام الملفات. بالنسبة لنظام ملفات غير مثبت، قم بتوفير مسار إلى جهاز كتلة (block device) ككائن. بالنسبة لنظام ملفات مثبت، حدد نقطة تحميل.

الأمر الفرعي

get [-t <type>] <object> [<name>]
قراءة قيمة خاصية name لكائن btrfs object من النوع المحدد، سيؤدي name الفارغ إلى قراءة جميع الخصائص.
list [-t <type>] <object>
سرد الخصائص المتاحة مع وصفها للكائن المحدد.
set [-f] [-t <type>] <object> <name> <value>
تعيين value للخاصية name على كائن btrfs محدد.

الخيارات

-f
فرض التغيير. قد يتضمن تغيير بعض الخصائص فحوصات السلامة أو تغييرات إضافية تعتمد على دلالات الخصائص.

أمثلة

تعيين الضغط على ملف:

$ touch file1
$ btrfs prop get file1
[ empty output ]
$ btrfs prop set file1 compression zstd
$ btrfs prop get file1
compression=zstd

جعل وحدة فرعية قابلة للكتابة للقراءة فقط:

$ btrfs subvol create subvol1
[ fill subvol1 with data ]
$ btrfs prop get subvol1
ro=false
$ btrfs prop set subvol1 ro true
ro=true

حالة الخروج

يعيد btrfs property حالة خروج صفرية في حالة النجاح. يتم إرجاع قيمة غير صفرية في حالة الفشل.

التوفر
