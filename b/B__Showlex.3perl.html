B::Showlex(3perl) دليل مبرمجي Perl B::Showlex(3perl)

الاسم

B::Showlex - عرض المتغيرات المعجمية المستخدمة في الدوال أو الملفات

الملخص

perl -MO=Showlex[,-OPTIONS][,SUBROUTINE] foo.pl

الوصف

عندما يتم إعطاء قائمة مفصولة بفواصل بأسماء الدوال كخيارات، يعرض Showlex المتغيرات المعجمية المستخدمة في تلك الدوال. بخلاف ذلك، يعرض المتغيرات المعجمية على نطاق الملف في الملف.

أمثلة

الشكل التقليدي:

$ perl -MO=Showlex -e 'my ($i,$j,$k)=(1,"foo")'
Pad of lexical names for comppadlist has 4 entries
0: (0x8caea4) undef
1: (0x9db0fb0) $i
2: (0x9db0f38) $j
3: (0x9db0f50) $k
Pad of lexical values for comppadlist has 5 entries
0: SPECIAL #1 &PL_sv_undef
1: NULL (0x9da4234)
2: NULL (0x9db0f2c)
3: NULL (0x9db0f44)
4: NULL (0x9da4264)
-e syntax OK

الشكل الجديد:

$ perl -MO=Showlex,-newlex -e 'my ($i,$j,$k)=(1,"foo")'
main Pad has 4 entries
0: (0x8caea4) undef
1: (0xa0c4fb8) "$i" = NULL (0xa0b8234)
2: (0xa0c4f40) "$j" = NULL (0xa0c4f34)
3: (0xa0c4f58) "$k" = NULL (0xa0c4f4c)
-e syntax OK

شكل جديد، بدون مميزات خاصة، خارج إطار O:

$ perl -MB::Showlex -e \
   'my ($i,$j,$k)=(1,"foo"); B::Showlex::compile(-newlex,-nosp)->()'
main Pad has 4 entries
1: (0x998ffb0) "$i" = IV (0x9983234) 1
2: (0x998ff68) "$j" = PV (0x998ff5c) "foo"
3: (0x998ff80) "$k" = NULL (0x998ff74)

لاحظ أن هذا المثال يعرض قيم المتغيرات المعجمية، بينما لم تعرض الأمثلة الأخرى ذلك (لأنها خاصة بوقت الترجمة).

الخيارات

الخيار "-newlex" ينتج تنسيقًا أكثر قابلية للقراءة "name => value"، ويظهر في المثال الثاني أعلاه.

الخيار "-nosp" يزيل الإبلاغ عن المميزات الخاصة (SPECIALs)، مثل "0: SPECIAL #1 &PL_sv_undef" أعلاه. الإبلاغ عن المميزات الخاصة يمكن أن يطغى أحيانًا على المتغيرات المعجمية التي أعلنتها.

انظر أيضًا

يمكن استخدام B::Showlex أيضًا خارج إطار O، كما في المثال الثالث. انظر B::Concise لشرح أوفى للأسباب.

مهام مستقبلية

بعض المعلومات المعروضة، مثل العناوين السداسية العشرية، ليست ذات قيمة كبيرة. معلومات أخرى ستكون أكثر فائدة للمبرمج العادي، مثل أرقام الأسطر، وإعادة استخدام أماكن الـ pad، وما إلى ذلك. بالنظر إلى هذا، فإن -newlex ليس اسم علم جيد بشكل خاص.
