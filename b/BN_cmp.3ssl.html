BN_cmp(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

BN_CMP(3ssl) OpenSSL BN_CMP(3ssl)

الاسم

BN_cmp, BN_ucmp, BN_is_zero, BN_is_one, BN_is_word, BN_abs_is_word, BN_is_odd, BN_are_coprime - وظائف مقارنة واختبار BIGNUM

الملخص

#include <openssl/bn.h>
int BN_cmp(const BIGNUM *a, const BIGNUM *b);
int BN_ucmp(const BIGNUM *a, const BIGNUM *b);
int BN_is_zero(const BIGNUM *a);
int BN_is_one(const BIGNUM *a);
int BN_is_word(const BIGNUM *a, const BN_ULONG w);
int BN_abs_is_word(const BIGNUM *a, const BN_ULONG w);
int BN_is_odd(const BIGNUM *a);
int BN_are_coprime(BIGNUM *a, const BIGNUM *b, BN_CTX *ctx);

الوصف

BN_cmp() تقارن الأرقام a و b. BN_ucmp() تقارن القيم المطلقة لها.

BN_is_zero()، BN_is_one()، BN_is_word() و BN_abs_is_word() تختبر ما إذا كانت a تساوي 0، 1، w، أو |w| على التوالي. BN_is_odd() تختبر ما إذا كانت a فردية.

BN_are_coprime() تحدد ما إذا كانت a و b أولية نسبياً. ctx تستخدم داخليًا لتخزين المتغيرات المؤقتة. يجب ألا تكون قيم a و b و ctx فارغة (NULL).

قيم الإرجاع

BN_cmp() ترجع -1 إذا كان a < b، 0 إذا كان a == b، و 1 إذا كان a > b. BN_ucmp() هي نفسها باستخدام القيم المطلقة لـ a و b.

BN_is_zero()، BN_is_one() BN_is_word()، BN_abs_is_word() و BN_is_odd() ترجع 1 إذا كان الشرط صحيحًا، 0 بخلاف ذلك.

BN_are_coprime() ترجع 1 إذا كانت BIGNUM's أولية نسبياً، وإلا فإنها ترجع 0.

التاريخ

قبل OpenSSL 1.1.0، كانت BN_is_zero()، BN_is_one()، BN_is_word()، BN_abs_is_word() و BN_is_odd() عبارة عن وحدات ماكرو.

تمت إضافة الوظيفة BN_are_coprime() في OpenSSL 3.1.
