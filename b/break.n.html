break(n)

الحزمة: tcl

التراخيص: TCL

break(n) أوامر Tcl المدمجة break(n)

الاسم

break - إلغاء أمر التكرار

الموجز

break

الوصف

عادةً ما يتم استدعاء هذا الأمر داخل جسم أمر تكرار مثل for أو foreach أو while. يقوم بإرجاع رمز نتيجة 3 (TCL_BREAK)، مما يؤدي إلى حدوث استثناء فواصل. يعالج الاستثناء إلغاء البرنامج النصي الحالي وصولاً إلى أقرب أمر تكرار يحتوي عليه، والذي يقوم بعد ذلك بإلغاء تنفيذه والإرجاع بشكل طبيعي. يتم أيضًا التعامل مع استثناءات الفواصل في بعض الحالات الأخرى، مثل الأمر catch، وربط أحداث Tk، والبرامج النصية الخارجية لجسم الإجراء.

مثال

طباعة سطر لكل عدد صحيح من 0 إلى 5:

for {set x 0} {$x<10} {incr x} {
    if {$x > 5} {
        break
    }
    puts "x is $x"
}

انظر أيضًا

catch(n)، continue(n)، for(n)، foreach(n)، return(n)، while(n)
