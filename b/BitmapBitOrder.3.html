BitmapBitOrder(3)

الحزمة: libx11

التراخيص: MIT AND X11

ImageByteOrder(3) وظائف XLIB ImageByteOrder(3)

الاسم

ImageByteOrder, BitmapBitOrder, BitmapPad, BitmapUnit, DisplayHeight, DisplayHeightMM, DisplayWidth, DisplayWidthMM, XListPixmapFormats, XPixmapFormatValues - وظائف ووحدات ماكرو لتنسيق الصور

الصيغة

XPixmapFormatValues *XListPixmapFormats(Display *display, int *count_return);

int ImageByteOrder(Display *display);

int BitmapBitOrder(Display *display);

int BitmapPad(Display *display);

int BitmapUnit(Display *display);

int DisplayHeight(Display *display, int screen_number);

int DisplayHeightMM(Display *display, int screen_number);

int DisplayWidth(Display *display, int screen_number);

int DisplayWidthMM(Display *display, int screen_number);

المعاملات

display
يحدد الاتصال بخادم X.
count_return
يعيد عدد تنسيقات البكسل المدعومة بواسطة الشاشة.
screen_number
يحدد رقم الشاشة المناسب على الخادم المضيف.

الوصف

تقوم الدالة XListPixmapFormats بإرجاع مصفوفة من هياكل XPixmapFormatValues التي تصف أنواع تنسيقات Z للصور المدعومة بواسطة الشاشة المحددة. إذا لم تكن هناك ذاكرة كافية متاحة، ترجع XListPixmapFormats قيمة NULL. لتحرير مساحة الذاكرة المخصصة لهياكل XPixmapFormatValues، استخدم XFree.

تحدد وحدة الماكرو ImageByteOrder ترتيب البايت المطلوب للصور لكل وحدة مسح ضوئي بتنسيق XY (bitmap) أو لكل قيمة بكسل بتنسيق Z.

تعيد وحدة الماكرو BitmapBitOrder إما LSBFirst أو MSBFirst للإشارة إلى ما إذا كان البت الأقصى الأيسر في الخريطة النقطية كما تظهر على الشاشة هو البت الأقل أو الأكثر أهمية في الوحدة.

تعيد وحدة الماكرو BitmapPad عدد البتات التي يجب حشو كل سطر مسح ضوئي بها.

تعيد وحدة الماكرو BitmapUnit حجم وحدة المسح الضوئي للخريطة النقطية بالبت.

تعيد وحدة الماكرو DisplayHeight ارتفاع الشاشة المحددة بالبكسل.

تعيد وحدة الماكرو DisplayHeightMM ارتفاع الشاشة المحددة بالملليمتر.

تعيد وحدة الماكرو DisplayWidth عرض الشاشة بالبكسل.

تعيد وحدة الماكرو DisplayWidthMM عرض الشاشة المحددة بالملليمتر.

الهياكل

يوفر هيكل XPixmapFormatValues واجهة لمعلومات تنسيق البكسل التي يتم إرجاعها وقت إعداد الاتصال. يحتوي على:

typedef struct {
        int depth;
        int bits_per_pixel;
        int scanline_pad;
} XPixmapFormatValues;
