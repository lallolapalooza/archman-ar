bpftool-feature(8)

الحزمة: bpf

التراخيص: GPL-2.0-only

BPFTOOL-FEATURE(8) دليل مدير النظام BPFTOOL-FEATURE(8)

الاسم

bpftool-feature - أداة لفحص المعلمات المتعلقة بـ eBPF لنواة Linux أو جهاز الشبكة

الملخص

bpftool [خيارات] feature أمر

خيارات := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

أوامر := { probe | help }

أوامر الميزات

bpftool feature probe [مكون] [full] [unprivileged] [macros [prefix بادئة]]
bpftool feature list_builtins مجموعة
bpftool feature help
مكون := { kernel | dev اسم }
مجموعة := { prog_types | map_types | attach_types | link_types | helpers }

الوصف

bpftool feature probe [kernel] [full] [macros [prefix PREFIX]]
فحص النواة قيد التشغيل وإلغاء تحميل عدد من المعلمات المتعلقة بـ eBPF، مثل توفر استدعاء النظام bpf()، وحالة JIT، وتوفر أنواع برامج eBPF، وتوفر دوال مساعدة eBPF، والمزيد.

افتراضيًا، لا يقوم bpftool بتشغيل اختبارات لدوال bpf_probe_write_user() و bpf_trace_printk() التي تطبع تحذيرات إلى سجلات النواة. لتمكينها وتشغيل جميع الاختبارات، يجب استخدام الكلمة المفتاحية full.

إذا تم تمرير الكلمة المفتاحية macros (ولكن ليس الخيار -j)، يتم إلغاء تحميل جزء من الإخراج كقائمة من وحدات الماكرو #define الجاهزة لتضمينها في ملف رأس C، على سبيل المثال. إذا تم استخدام prefix بشكل إضافي لتحديد PREFIX، فسيتم استخدام السلسلة المقدمة كبادئة لأسماء وحدات الماكرو: يمكن استخدام هذا لتجنب تضاربات أسماء وحدات الماكرو عند تضمين إخراج هذا الأمر كملف رأس.

يمكن حذف الكلمة المفتاحية kernel. إذا لم يتم تحديد هدف اختبار، فإن اختبار النواة هو السلوك الافتراضي.

عند استخدام الكلمة المفتاحية unprivileged، سيقوم bpftool بإلغاء تحميل الميزات المتاحة فقط للمستخدم الذي لا يمتلك صلاحية CAP_SYS_ADMIN. الميزات المتاحة في هذه الحالة تمثل عادةً مجموعة فرعية صغيرة من المعلمات التي يدعمها النظام. يجب على المستخدمين غير المميزين استخدام الكلمة المفتاحية unprivileged: هذا لتجنب الكشف الخاطئ إذا تم تشغيل bpftool عن طريق الخطأ كغير جذري، على سبيل المثال. هذه الكلمة المفتاحية غير متاحة إذا تم تجميع bpftool بدون libcap.

bpftool feature probe dev NAME [full] [macros [prefix PREFIX]]
فحص جهاز الشبكة بحثًا عن ميزات eBPF المدعومة وإلغاء تحميل النتائج إلى وحدة التحكم.

الكلمات المفتاحية full و macros و prefix لها نفس الدور كما هو الحال عند فحص النواة.

bpftool feature list_builtins GROUP
سرد العناصر المعروفة لـ bpftool. يمكن أن تكون هذه أنواع برامج BPF (prog_types)، أو أنواع خرائط BPF (map_types)، أو أنواع الإرفاق (attach_types)، أو أنواع الارتباط (link_types)، أو دوال مساعدة BPF (helpers). لا يقوم الأمر بفحص النظام، ولكنه يسرد ببساطة العناصر التي يعرفها bpftool من وقت التجميع، كما يتم توفيرها من libbpf (لجميع أنواع الكائنات) أو من رأس BPF UAPI (قائمة الدوال المساعدة). يمكن استخدام هذا في البرامج النصية للتكرار فوق أنواع BPF أو الدوال المساعدة.
bpftool feature help
طباعة رسالة مساعدة قصيرة.

خيارات

-h, --help
طباعة رسالة مساعدة قصيرة (مشابهة لـ bpftool help).
-V, --version
طباعة رقم إصدار bpftool (مشابه لـ bpftool version)، ورقم إصدار libbpf قيد الاستخدام، والميزات الاختيارية التي تم تضمينها عند تجميع bpftool. تشمل الميزات الاختيارية الربط بـ LLVM أو libbfd لتوفير المفكك للبرامج المترجمة JIT (bpftool prog dump jited) واستخدام هياكل BPF (بعض الميزات مثل bpftool prog profile أو عرض معرفات العمليات المرتبطة بكائنات BPF قد تعتمد عليها).
-j, --json
إنشاء إخراج JSON. بالنسبة للأوامر التي لا يمكنها إنتاج JSON، لا يكون لهذا الخيار تأثير.
-p, --pretty
إنشاء إخراج JSON سهل القراءة. يتضمن -j.
-d, --debug
طباعة جميع السجلات المتاحة، حتى معلومات مستوى التصحيح. يشمل ذلك السجلات من libbpf وكذلك من المدقق، عند محاولة تحميل البرامج.
