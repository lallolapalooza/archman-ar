brctl(8)

الحزمة: bridge-utils

التراخيص: GPL

brctl is used to configure the spanning tree protocol and to create, delete and show a network interface bridge.

SYNOPSIS

    brctl [options] command [arguments]

DESCRIPTION

The brctl utility is used to control the Linux Ethernet bridge. Ethernet bridges are used to connect multiple Ethernet network segments together to make them appear as a single network segment. This utility can be used to create, maintain, and inspect the software bridge interface.

The following commands are supported:

addbr bridge
Create a new bridge named bridge.
delbr bridge
Delete the bridge named bridge.
addif bridge interface
Add the network interface interface to the bridge named bridge. The interface must be up.
delif bridge interface
Delete the network interface interface from the bridge named bridge.
show
Show the current list of bridges and their interfaces.
stp bridge
Enable Spanning Tree Protocol on bridge. The bridge must be up.
rstp bridge
Enable Rapid Spanning Tree Protocol on bridge. The bridge must be up.
setageing bridge time
Set the ageing time on bridge to time (in seconds).
setpathcost bridge interface cost
Set the path cost on bridge for the interface interface to cost.
setportprio bridge interface prio
Set the port priority on bridge for the interface interface to prio.
setbridgeprio bridge prio
Set the bridge priority on bridge to prio.
setfd bridge time
Set the forward delay on bridge to time (in seconds).
sethello bridge time
Set the hello time on bridge to time (in seconds).
setmaxage bridge time
Set the maximum age on bridge to time (in seconds).
setgmactime bridge time
Set the group multicast forward time on bridge to time (in seconds).
setproto bridge { 802.1d | none }
Set the STP protocol on bridge to 802.1d (traditional STP) or none (no STP). Default is 802.1d.
list
List all available bridges.

OPTIONS

-f
Do not exit when a command fails. This is useful for batch mode.

SEE ALSO

ip(8), bridge(8)

brctl يُستخدم لتهيئة بروتوكول الشجرة الممتدة (spanning tree protocol) ولإنشاء، حذف، وعرض جسر واجهة الشبكة.

ملخص

    brctl [options] command [arguments]

الوصف

تُستخدم أداة brctl للتحكم في جسر إيثرنت لينكس. تُستخدم جسور إيثرنت لربط عدة مقاطع شبكة إيثرنت معًا لجعلها تبدو كقطعة شبكة واحدة. يمكن استخدام هذه الأداة لإنشاء وصيانة وفحص واجهة الجسر البرمجية.

الأوامر التالية مدعومة:

addbr bridge
إنشاء جسر جديد باسم bridge.
delbr bridge
حذف الجسر المسمى bridge.
addif bridge interface
إضافة واجهة الشبكة interface إلى الجسر المسمى bridge. يجب أن تكون الواجهة نشطة.
delif bridge interface
حذف واجهة الشبكة interface من الجسر المسمى bridge.
show
عرض القائمة الحالية للجسر والواجهات الخاصة بها.
stp bridge
تمكين بروتوكول الشجرة الممتدة (Spanning Tree Protocol) على bridge. يجب أن يكون الجسر نشطًا.
rstp bridge
تمكين بروتوكول الشجرة الممتدة السريع (Rapid Spanning Tree Protocol) على bridge. يجب أن يكون الجسر نشطًا.
setageing bridge time
تعيين وقت الشيخوخة (ageing time) على bridge إلى time (بالثواني).
setpathcost bridge interface cost
تعيين تكلفة المسار (path cost) على bridge للواجهة interface إلى cost.
setportprio bridge interface prio
تعيين أولوية المنفذ (port priority) على bridge للواجهة interface إلى prio.
setbridgeprio bridge prio
تعيين أولوية الجسر (bridge priority) على bridge إلى prio.
setfd bridge time
تعيين تأخير الإرسال (forward delay) على bridge إلى time (بالثواني).
sethello bridge time
تعيين وقت الترحيب (hello time) على bridge إلى time (بالثواني).
setmaxage bridge time
تعيين الحد الأقصى للعمر (maximum age) على bridge إلى time (بالثواني).
setgmactime bridge time
تعيين وقت توجيه المجموعات المتعددة (group multicast forward time) على bridge إلى time (بالثواني).
setproto bridge { 802.1d | none }
تعيين بروتوكول STP (802.1d) على bridge إلى 802.1d (STP التقليدي) أو none (بدون STP). الافتراضي هو 802.1d.
list
قائمة بجميع الجسور المتاحة.

خيارات

-f
لا تخرج عند فشل أمر ما. هذا مفيد في وضع الدُفعات.
