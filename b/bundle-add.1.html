bundle-add(1)

الحزمة: ruby-bundler

التراخيص: MIT

BUNDLE-ADD(1) دليل الأوامر العامة BUNDLE-ADD(1)

الاسم

bundle-add - إضافة جوهرة إلى Gemfile وتشغيل bundle install

ملخص

bundle add GEM_NAME [--group=GROUP] [--version=VERSION] [--source=SOURCE] [--path=PATH] [--git=GIT|--github=GITHUB] [--branch=BRANCH] [--ref=REF] [--quiet] [--skip-install] [--strict|--optimistic]

الوصف

يضيف الجوهرة المسماة إلى [Gemfile(5)][Gemfile(5)] ويقوم بتشغيل bundle install. يمكن تجنب bundle install باستخدام العلامة --skip-install.

خيارات

--version=VERSION, -v=VERSION
تحديد المتطلبات (المتطلب) للإصدار للجوهرة المضافة.
--group=GROUP, -g=GROUP
تحديد المجموعة (المجموعات) للجوهرة المضافة. يجب فصل المجموعات المتعددة بفواصل.
--source=SOURCE, -s=SOURCE
تحديد المصدر للجوهرة المضافة.
--require=REQUIRE, -r=REQUIRE
يضيف مسار يتطلب الجوهرة. قدم false، أو مسار كسلسلة نصية.
--path=PATH
تحديد مسار نظام الملفات للجوهرة المضافة.
--git=GIT
تحديد مصدر git للجوهرة المضافة.
--github=GITHUB
تحديد مصدر github للجوهرة المضافة.
--branch=BRANCH
تحديد فرع git للجوهرة المضافة.
--ref=REF
تحديد مرجع git للجوهرة المضافة.
--glob=GLOB
تحديد موقع ملف .gemspec التابع للتبعية، موسع داخل Ruby (يوصى باقتباس مفرد).
--quiet
لا تقم بطباعة معلومات التقدم إلى المخرج القياسي.
--skip-install
يضيف الجوهرة إلى Gemfile ولكنه لا يقوم بتثبيتها.
--optimistic
يضيف إعلانًا تفاؤليًا للإصدار.
--strict
يضيف إعلانًا صارمًا للإصدار.

أمثلة

1.
يمكنك إضافة الجوهرة rails إلى Gemfile بدون أي تقييد للإصدار. سيكون مصدر الجوهرة هو المصدر العام.
bundle add rails
2.
يمكنك إضافة الجوهرة rails بإصدار أكبر من 1.1 (لا يشمل 1.1) وأقل من 3.0.
bundle add rails --version "> 1.1, < 3.0"
3.
يمكنك استخدام المصدر المخصص https://gems.example.com وتعيين الجوهرة إلى مجموعة.
bundle add rails --version "~> 5.0.0" --source "https://gems.example.com" --group "development"
4.
يضيف ما يلي إدخال gem إلى Gemfile دون تثبيت الجوهرة. يمكنك تثبيت الجواهر لاحقًا عبر bundle install.
bundle add rails --skip-install
5.
يمكنك تعيين الجوهرة إلى أكثر من مجموعة واحدة.
bundle add rails --group "development, test"
