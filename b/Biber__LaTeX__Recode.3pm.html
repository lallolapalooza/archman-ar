Biber__LaTeX__Recode(3pm)

الحزمة: biber

التراخيص: Artistic-2.0

Biber::LaTeX::Recode(3pm) توثيق Perl للمساهمة من المستخدمين Biber::LaTeX::Recode(3pm)

الاسم

Biber::LaTeX::Recode - ترميز/فك ترميز الأحرف إلى/من UTF-8/lacros في LaTeX

الملخص

use Biber::LaTeX:Recode
my $string = 'Muḥammad ibn Mūsā al-Khwārizmī';
my $latex_string = latex_encode($string);
    # => 'Mu\d{h}ammad ibn M\=us\=a al-Khw\=arizm\={\i}'
my $string = 'Mu\d{h}ammad ibn M\=us\=a al-Khw\=arizm\={\i}';
my $utf8_string   = latex_decode($string);
    # => 'Muḥammad ibn Mūsā al-Khwārizmī'

الوصف

يسمح بالتحويل بين أحرف Unicode وماكرو LaTeX.

خيارات عامة

القيم الممكنة لمجموعة الترميز/فك الترميز المستخدمة هي 'null'، 'base'، و 'full'؛ القيمة الافتراضية هي 'base'.

null => لا تحويل

base => معظم الماكرو الشائعة والعلامات المميزة (كافية للغات الغربية
والرموز الشائعة)

full => يقوم أيضًا بتحويل علامات الترقيم، نطاق أوسع من العلامات المميزة والماكرو
(مثل IPA، Latin Extended Additional، إلخ)، الرموز، الأحرف اليونانية،
رموز dingbats، الرموز المنفية، والأحرف والرموز الفوقية...

init_sets(<مجموعة_فك_الترميز>, <مجموعة_الترميز>)

تهيئة مجموعات إعادة الترميز. لا يمكننا القيام بذلك عند تحميل الوحدة النمطية لأننا لا نملك معلومات التكوين
 للقيام بذلك بعد

latex_decode($text, @options)

يحول ماكرو LaTeX في $text إلى أحرف Unicode.

تقبل الدالة عددًا من الخيارات:

* normalize => $bool (الافتراضي 1)
    ما إذا كان يجب تطبيع السلسلة الناتجة باستخدام Unicode::Normalize
* normalization => <شكل التطبيع> (الافتراضي 'NFD')
    وإذا كان الأمر كذلك، فشكل التطبيع المراد استخدامه (انظر توثيق Unicode::Normalize)

latex_encode($text, @options)

يحول UTF-8 إلى LaTeX
