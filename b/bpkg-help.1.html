NAME

bpkg-help - Display help messages for bpkg commands

SYNOPSIS

bpkg help [command...]

DESCRIPTION

Displays help messages for the specified commands. If no command is given, it will display a list of all available commands.

OPTIONS

This command does not accept any options.

EXAMPLES

Display help for the 'install' command:

$ bpkg help install

Display a list of all available commands:

$ bpkg help
