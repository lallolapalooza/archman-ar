BIO_s_fd(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

BIO_S_FD(3ssl) OpenSSL BIO_S_FD(3ssl)

الاسم

BIO_s_fd, BIO_set_fd, BIO_get_fd, BIO_new_fd - واجهة إدخال/إخراج واصف الملف

الملخص

#include <openssl/bio.h>
const BIO_METHOD *BIO_s_fd(void);
int BIO_set_fd(BIO *b, int fd, int c);
int BIO_get_fd(BIO *b, int *c);
BIO *BIO_new_fd(int fd, int close_flag);

الوصف

BIO_s_fd() تُرجع طريقة واجهة إدخال/إخراج واصف الملف. هذه طبقة تغليف حول روتينات واصف الملف الخاصة بالمنصة مثل read() و write().

BIO_read_ex() و BIO_write_ex() تقرأ أو تكتب الواصف الأساسي. BIO_puts() مدعومة ولكن BIO_gets() غير مدعومة.

إذا تم تعيين علامة الإغلاق، فسيتم استدعاء close() على واصف الملف الأساسي عند تحرير واجهة الإدخال/الإخراج.

BIO_reset() تحاول تغيير مؤشر الملف إلى بداية الملف باستخدام شيء مثل lseek(fd, 0, 0).

BIO_seek() تحدد مؤشر الملف إلى الموضع ofs من بداية الملف باستخدام شيء مثل lseek(fd, ofs, 0).

BIO_tell() تُرجع موضع الملف الحالي باستخدام شيء مثل استدعاء lseek(fd, 0, 1).

BIO_set_fd() تحدد واصف الملف لواجهة الإدخال/الإخراج b إلى fd وعلامة الإغلاق إلى c.

BIO_get_fd() تضع واصف الملف لواجهة الإدخال/الإخراج b في c إذا لم يكن NULL. كما أنها تُرجع واصف الملف.

BIO_new_fd() تُرجع واجهة إدخال/إخراج واصف ملف باستخدام fd و close_flag.

ملاحظات

يعتمد سلوك BIO_read_ex() و BIO_write_ex() على سلوك استدعاءات read() و write() الخاصة بالمنصة على الواصف. إذا كان واصف الملف الأساسي في وضع غير حاظر، فإن واجهة الإدخال/الإخراج ستتصرف بالطريقة الموضحة في صفحات دليل BIO_read_ex(3) و BIO_should_retry(3).

يجب عدم استخدام واجهات إدخال/إخراج واصفات الملف لإدخال/إخراج المقابس. استخدم واجهات إدخال/إخراج المقابس بدلاً من ذلك.

BIO_set_fd() و BIO_get_fd() مُنفذتان كـ macros.

قيم الإرجاع

BIO_s_fd() تُرجع طريقة واجهة إدخال/إخراج واصف الملف.

BIO_set_fd() تُرجع 1 عند النجاح أو <=0 عند الفشل.

BIO_get_fd() تُرجع واصف الملف أو -1 إذا لم تتم تهيئة واجهة الإدخال/الإخراج. كما أنها تُرجع قيمًا صفرية وسلبية إذا حدث خطأ آخر.

BIO_new_fd() تُرجع واجهة الإدخال/الإخراج الجديدة المخصصة أو NULL إذا حدث خطأ.

أمثلة

هذا مثال على "Hello World" باستخدام واجهة إدخال/إخراج واصف الملف:

BIO *out;
out = BIO_new_fd(fileno(stdout), BIO_NOCLOSE);
BIO_printf(out, "Hello World\n");
BIO_free(out);
