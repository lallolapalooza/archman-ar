الحزمة: bluez-tools

التراخيص: GPL

bt-device(1) bluez-tools bt-device(1)

اسم

bt-device - مدير أجهزة البلوتوث

ملخص

bt-device [خيار...]

خيارات المساعدة:
-h, --help

خيارات التطبيق:
-a, --adapter=<اسم|ماك>
-l, --list
-c, --connect=<ماك>
-d, --disconnect=<اسم|ماك>
-r, --remove=<اسم|ماك>
-i, --info=<اسم|ماك>
-s, --services <اسم|ماك> [<نمط>]
--set <اسم|ماك> <خاصية> <قيمة>
-v, --verbose

الوصف

تُستخدم هذه الأداة لإدارة أجهزة البلوتوث. يمكنك سرد الأجهزة المضافة، الاتصال بجهاز جديد، قطع الاتصال بالجهاز، إزالة جهاز مضاف، عرض معلومات عن الجهاز، اكتشاف خدمات الجهاز البعيد أو تغيير خصائص الجهاز.

خيارات

-h, --help
عرض المساعدة

-a, --adapter <اسم|ماك>
تحديد المحول المراد استخدامه بالاسم أو عنوان MAC
(إذا لم يتم تعريف هذا الخيار - يتم استخدام المحول الافتراضي)

-l, --list
سرد الأجهزة المضافة

-c, --connect <ماك>
الاتصال بالجهاز البعيد باستخدام عنوان MAC الخاص به، استرداد جميع سجلات
SDP ثم بدء الاقتران

-d, --disconnect <اسم|ماك>
قطع اتصال جهاز بعيد محدد عن طريق إنهاء اتصال ACL
منخفض المستوى.

-r, --remove
إزالة الجهاز (وكذلك معلومات الاقتران)

-i, --info
عرض معلومات حول الجهاز (يعيد جميع الخصائص)

-s, --services <اسم|ماك> [<نمط>]
بدء اكتشاف الخدمة لاسترداد سجلات الخدمة البعيدة،
يمكن استخدام المعلمة `pattern` لتحديد UUIDs محددة

--set <خاصية> <قيمة>
تغيير خصائص الجهاز (انظر قسم خصائص الجهاز للحصول على قائمة
بالخصائص المتاحة)

-v, --verbose
عرض سجلات الخدمة البعيدة بشكل مطول (يؤثر على وضع اكتشاف الخدمة)

خصائص الجهاز

string Address [ro]
عنوان جهاز البلوتوث (MAC) للجهاز البعيد.

string Name [ro]
اسم جهاز البلوتوث البعيد.

string Icon [ro]
اسم أيقونة مقترح وفقًا لمواصفات تسمية الأيقونات
من freedesktop.org.

uint32 Class [ro]
فئة جهاز البلوتوث للجهاز البعيد.

list UUIDs [ro]
قائمة UUIDs مكونة من 128 بت والتي تمثل الخدمات البعيدة
المتوفرة.

boolean Paired [ro]
يشير إلى ما إذا كان الجهاز البعيد مقترنًا.

boolean Connected [ro]
يشير إلى ما إذا كان الجهاز البعيد متصلاً حاليًا.

boolean Trusted [rw]
يشير إلى ما إذا كان الجهاز البعيد يعتبر موثوقًا به.

boolean Blocked [rw]
إذا تم تعيينه على true، فسيتم رفض أي اتصالات واردة من
الجهاز على الفور.

string Alias [rw]
اسم مستعار للجهاز البعيد. يمكن استخدام الاسم المستعار
للحصول على اسم صديق مختلف للجهاز البعيد.

في حالة عدم تعيين اسم مستعار، سيعيد اسم الجهاز
البعيد. تعيين سلسلة فارغة كاسم مستعار سيعيده إلى
اسم الجهاز البعيد.

boolean LegacyPairing [ro]
تم تعيينه على true إذا كان الجهاز يدعم آلية الاقتران
القديمة (ما قبل 2.1) فقط.
