الحزمة: docbook-utils

BACKEND-SPEC(7) BACKEND-SPEC(7)

الاسم

backend-spec - الواجهة بين jw والخلفيات الخاصة به

الوصف

jw(1) يستدعي الخلفيات مثل backends/html للقيام بأعمال التحويل "الحقيقية". يتلقى الخلفية جميع البيانات الضرورية عبر متغيرات البيئة جاهزة للاستخدام.

هذه الوثيقة تصف متغيرات البيئة هذه.

يتم تشغيل الخلفية في الدليل الذي سيتم فيه إنشاء ملفات الإخراج. يجب أن تعود بـ 0 إذا لم تكن هناك مشاكل، وتعيد قيمة موجبة خلاف ذلك.

المتغيرات

SGML_FILE_NAME
الاسم المجرد للملف المصدر
SGML_FILE
الاسم الكامل والمسار للملف المصدر
SGML_JADE
اسم المحلل (عادة Jade أو OpenJade)
SGML_ARGUMENTS
سلسلة الوسائط الكاملة لـ Jade أو OpenJade
SGML_CATALOG_FILES
قائمة ملفات الكتالوج المطلوبة بواسطة Jade أو OpenJade
SGML_STYLESHEET
ورقة الأنماط المراد استخدامها
SGML_BASE_DIR
الدليل الأساسي لنظام SGML (الافتراضي هو /usr/share/sgml)
