\n
\n
\n

Update the library (and, by default, move files) to reflect\n out-of-band metadata changes and file deletions.

\n

\n

To perform a "dry run" of an update, just use the\n -p (for "pretend") flag. This will show you all the\n proposed changes but won't actually change anything on disk.

\n
