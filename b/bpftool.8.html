الحزمة: bpf

التراخيص: GPL-2.0-only

BPFTOOL(8) دليل مدير النظام BPFTOOL(8)

الاسم

BPFTOOL - أداة لفحص ومعالجة بسيطة لبرامج وخرائط eBPF

الموجز

bpftool [خيارات] كائن { أمر | help }

bpftool batch file ملف

bpftool version

كائن := { map | prog | link | cgroup | perf | net | feature | btf | gen | struct_ops | iter }

خيارات := { { -V | --version } | { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

أوامر-الخريطة := { show | list | create | dump | update | lookup | getnext | delete | pin | event_pipe | help }

أوامر-البرنامج := { show | list | dump jited | dump xlated | pin | load | attach | detach | help }

أوامر-الرابط := { show | list | pin | detach | help }

أوامر-cgroup := { show | list | attach | detach | help }

أوامر-perf := { show | list | help }

أوامر-net := { show | list | help }

أوامر-feature := { probe | help }

أوامر-btf := { show | list | dump | help }

أوامر-gen := { object | skeleton | min_core_btf | help }

أوامر-struct_ops := { show | list | dump | register | unregister | help }

أوامر-iter := { pin | help }

الوصف

bpftool يسمح بفحص وتعديل بسيط لكائنات BPF على النظام.

لاحظ أن تنسيق ناتج جميع الأدوات غير مضمون أن يكون ثابتًا ولا ينبغي الاعتماد عليه.

الخيارات

-h, --help
طباعة رسالة مساعدة مختصرة (مشابهة لـ bpftool help).
-V, --version
طباعة رقم إصدار bpftool (مشابه لـ bpftool version)، ورقم إصدار libbpf المستخدم، والميزات الاختيارية التي تم تضمينها عند تجميع bpftool. تشمل الميزات الاختيارية الربط مع LLVM أو libbfd لتوفير أداة فك التجميع للبرامج المترجمة (JIT) (bpftool prog dump jited) واستخدام هياكل BPF (بعض الميزات مثل bpftool prog profile أو عرض معرفات العمليات المرتبطة بكائنات BPF قد تعتمد عليها).
-j, --json
إنشاء مخرج JSON. بالنسبة للأوامر التي لا يمكنها إنتاج JSON، لا يؤثر هذا الخيار.
-p, --pretty
إنشاء مخرج JSON قابل للقراءة البشرية. يتضمن -j.
-d, --debug
طباعة جميع السجلات المتاحة، حتى معلومات مستوى التصحيح. يشمل ذلك السجلات من libbpf ومن المدقق (verifier) عند محاولة تحميل البرامج.
-m, --mapcompat
السماح بتحميل الخرائط بتعريفات خرائط غير معروفة.
-n, --nomount
لا تحاول تلقائيًا تحميل أي نظام ملفات افتراضي (مثل tracefs أو نظام ملفات BPF الافتراضي) عند الضرورة.
