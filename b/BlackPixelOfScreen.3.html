BlackPixelOfScreen(3)

الحزمة: libx11

التراخيص: MIT AND X11

BlackPixelOfScreen(3) وظائف XLIB BlackPixelOfScreen(3)

الاسم

BlackPixelOfScreen, WhitePixelOfScreen, CellsOfScreen, DefaultColormapOfScreen, DefaultDepthOfScreen, DefaultGCOfScreen, DefaultVisualOfScreen, DoesBackingStore, DoesSaveUnders, DisplayOfScreen, XScreenNumberOfScreen, EventMaskOfScreen, HeightOfScreen, HeightMMOfScreen, MaxCmapsOfScreen, MinCmapsOfScreen, PlanesOfScreen, RootWindowOfScreen, WidthOfScreen, WidthMMOfScreen - وظائف ووحدات ماكرو لمعلومات الشاشة

الصيغة

unsigned long BlackPixelOfScreen(Screen *screen);

unsigned long WhitePixelOfScreen(Screen *screen);

int CellsOfScreen(Screen *screen);

Colormap DefaultColormapOfScreen(Screen *screen);

int DefaultDepthOfScreen(Screen *screen);

GC DefaultGCOfScreen(Screen *screen);

Visual *DefaultVisualOfScreen(Screen *screen);

int DoesBackingStore(Screen *screen);

Bool DoesSaveUnders(Screen *screen);

Display *DisplayOfScreen(Screen *screen);

int XScreenNumberOfScreen(Screen *screen);

long EventMaskOfScreen(Screen *screen);

int HeightOfScreen(Screen *screen);

int HeightMMOfScreen(Screen *screen);

int MaxCmapsOfScreen(Screen *screen);

int MinCmapsOfScreen(Screen *screen);

int PlanesOfScreen(Screen *screen);

Window RootWindowOfScreen(Screen *screen);

int WidthOfScreen(Screen *screen);

int WidthMMOfScreen(Screen *screen);

المعاملات

screen
يحدد هيكل Screen المناسب.

الوصف

ترجع الوحدة الماكرو BlackPixelOfScreen قيمة البكسل الأسود للشاشة المحددة.

ترجع الوحدة الماكرو WhitePixelOfScreen قيمة البكسل الأبيض للشاشة المحددة.

ترجع الوحدة الماكرو CellsOfScreen عدد خلايا خريطة الألوان في خريطة الألوان الافتراضية للشاشة المحددة.

ترجع الوحدة الماكرو DefaultColormapOfScreen خريطة الألوان الافتراضية للشاشة المحددة.

ترجع الوحدة الماكرو DefaultDepthOfScreen العمق الافتراضي للنافذة الجذر للشاشة المحددة.

ترجع الوحدة الماكرو DefaultGCOfScreen GC الافتراضي للشاشة المحددة، والذي له نفس عمق النافذة الجذر للشاشة.

ترجع الوحدة الماكرو DefaultVisualOfScreen التصور الافتراضي للشاشة المحددة.

ترجع الوحدة الماكرو DoesBackingStore القيمة WhenMapped أو NotUseful أو Always، والتي تشير إلى ما إذا كانت الشاشة تدعم مخازن الدعم.

ترجع الوحدة الماكرو DoesSaveUnders قيمة منطقية تشير إلى ما إذا كانت الشاشة تدعم الحفظ السفلي.

ترجع الوحدة الماكرو DisplayOfScreen شاشة الشاشة المحددة.

ترجع الدالة XScreenNumberOfScreen رقم فهرس الشاشة للشاشة المحددة.

ترجع الوحدة الماكرو EventMaskOfScreen قناع حدث الجذر للنافذة الجذر للشاشة المحددة عند إعداد الاتصال.

ترجع الوحدة الماكرو HeightOfScreen ارتفاع الشاشة المحددة.

ترجع الوحدة الماكرو HeightMMOfScreen ارتفاع الشاشة المحددة بالمليمتر.

ترجع الوحدة الماكرو MaxCmapsOfScreen الحد الأقصى لعدد خرائط الألوان المثبتة التي تدعمها الشاشة المحددة.

ترجع الوحدة الماكرو MinCmapsOfScreen الحد الأدنى لعدد خرائط الألوان المثبتة التي تدعمها الشاشة المحددة.

ترجع الوحدة الماكرو PlanesOfScreen عدد المستويات في النافذة الجذر للشاشة المحددة.

ترجع الوحدة الماكرو RootWindowOfScreen النافذة الجذر للشاشة المحددة.

ترجع الوحدة الماكرو WidthOfScreen عرض الشاشة المحددة.

ترجع الوحدة الماكرو WidthMMOfScreen عرض الشاشة المحددة بالمليمتر.
