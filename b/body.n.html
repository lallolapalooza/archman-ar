body(n)

الحزمة: tcl

التراخيص: TCL

body(n) [incr Tcl] body(n)

الاسم

itcl::body - تغيير جسم الطريقة/الاستدعاء لفئة

الملخص

itcl::body اسم_الفئة::الوظيفة الوسائط الجسم

الوصف

يُستخدم الأمر body خارج تعريف فئة [incr Tcl] لتعريف أو إعادة تعريف جسم طريقة الفئة أو استدعائها. تسمح هذه الميزة لتعريف الفئة بأن يكون لها أجزاء "واجهة" و"تطبيق" منفصلة. جزء "الواجهة" هو أمر class مع تعريفات للطرق والاستدعاءات ومتغيرات الكائن والمتغيرات المشتركة. جزء "التطبيق" هو سلسلة من أوامر body و configbody. إذا تم الاحتفاظ بجزء "التطبيق" في ملف منفصل، فيمكن تحميله بشكل متكرر مع إصلاح الأخطاء، لدعم التطوير التفاعلي. عند استخدام وضع "tcl" في محرر emacs، يمكن الاحتفاظ بأجزاء "الواجهة" و "التطبيق" في نفس الملف؛ مع إصلاح الأخطاء، يمكن تمييز الأجسام الفردية وإرسالها إلى تطبيق الاختبار.

يحدد الاسم "اسم_الفئة::الوظيفة" الطريقة/الاستدعاء الذي يتم تغييره.

إذا تم تحديد قائمة وسائط عند تعريف الوظيفة في تعريف الفئة، فيجب أن تتطابق قائمة الوسائط لأمر body في المعنى. يمكن أن تتغير أسماء المتغيرات، ولكن يجب أن تحتوي قوائم الوسائط على نفس الوسائط المطلوبة ونفس القيم الافتراضية للوسائط الاختيارية. الوسيط الخاص args يعمل كرمز بدل عند تضمينه في قائمة الوسائط في تعريف الفئة؛ سيطابق صفرًا أو أكثر من الوسائط من أي نوع عند إعادة تعريف الجسم.

إذا بدأ السلسلة الجسم بـ "@"، يتم التعامل معها كاسم رمزي لإجراء C. قائمة الوسائط لها معنى قليل لإجراء C، باستثناء توثيق الاستخدام المتوقع. (لا يُضمن أن يستخدم إجراء C الوسائط بهذه الطريقة.) إذا لم يبدأ الجسم بـ "@"، يتم التعامل معه كبرنامج نصي لأمر Tcl. عند استدعاء الوظيفة، تتم مطابقة وسائط سطر الأوامر مع قائمة الوسائط، ويتم إنشاء متغيرات محلية لتمثيل كل وسيط. هذا هو السلوك المعتاد لاستدعاء Tcl.

يتم إنشاء الأسماء الرمزية لإجراءات C عن طريق تسجيل الإجراءات عبر Itcl_RegisterC(). يتم ذلك عادةً في الإجراء Tcl_AppInit()، والذي يتم استدعاؤه تلقائيًا عند بدء تشغيل المفسر. في المثال التالي، يتم تسجيل الإجراء My_FooCmd() بالاسم الرمزي "foo". يمكن الإشارة إلى هذا الإجراء في أمر body كـ "@foo".

int
Tcl_AppInit(interp)
    Tcl_Interp *interp;     /* المفسر للتطبيق. */
{
    if (Itcl_Init(interp) == TCL_ERROR) {
        return TCL_ERROR;
    }
    if (Itcl_RegisterC(interp, "foo", My_FooCmd) != TCL_OK) {
        return TCL_ERROR;
    }
}

مثال

في المثال التالي، يتم تعريف فئة "File" لتمثيل الملفات المفتوحة. يتم تضمين أجسام الطرق أدناه تعريف الفئة عبر أمر body. لاحظ أنه يجب تضمين أجسام المنشئ/المُدمر في تعريف الفئة، ولكن يمكن إعادة تعريفهما عبر أمر body أيضًا.

itcl::class File {
    private variable fid ""
    constructor {name access} {
        set fid [open $name $access]
    }
    destructor {
        close $fid
    }
    method get {}
    method put {line}
    method eof {}
}
itcl::body File::get {} {
    return [gets $fid]
}
itcl::body File::put {line} {
    puts $fid $line
}
itcl::body File::eof {} {
    return [::eof $fid]
}
#
# انظر فئة File قيد العمل:
#
File x /etc/passwd "r"
while {![x eof]} {
    puts "=> [x get]"
}
itcl::delete object x
