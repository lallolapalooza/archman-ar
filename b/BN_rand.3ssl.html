BN_rand(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

BN_RAND(3ssl) OpenSSL BN_RAND(3ssl)

الاسم

BN_rand_ex, BN_rand, BN_priv_rand_ex, BN_priv_rand, BN_pseudo_rand, BN_rand_range_ex, BN_rand_range, BN_priv_rand_range_ex, BN_priv_rand_range - توليد رقم عشوائي زائف

ملخص

#include <openssl/bn.h>
int BN_rand_ex(BIGNUM *rnd, int bits, int top, int bottom,
               unsigned int strength, BN_CTX *ctx);
int BN_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_priv_rand_ex(BIGNUM *rnd, int bits, int top, int bottom,
                    unsigned int strength, BN_CTX *ctx);
int BN_priv_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_rand_range_ex(BIGNUM *rnd, const BIGNUM *range, unsigned int strength,
                     BN_CTX *ctx);
int BN_rand_range(BIGNUM *rnd, const BIGNUM *range);
int BN_priv_rand_range_ex(BIGNUM *rnd, const BIGNUM *range, unsigned int strength,
                          BN_CTX *ctx);
int BN_priv_rand_range(BIGNUM *rnd, const BIGNUM *range);

تم إيقاف الدوال التالية منذ OpenSSL 3.0، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

int BN_pseudo_rand(BIGNUM *rnd, int bits, int top, int bottom);
int BN_pseudo_rand_range(BIGNUM *rnd, const BIGNUM *range);

الوصف

تولد BN_rand_ex() رقمًا زائفًا عشوائيًا قويًا من الناحية التشفيرية بطول bits وقوة أمان لا تقل عن strength بت باستخدام مولد الأرقام العشوائية للسياق الخاص بالمكتبة المرتبط بـ ctx. تقوم الدالة بتخزين البيانات المولدة في rnd. قد يكون المعلم ctx قيمته NULL، وفي هذه الحالة يتم استخدام سياق المكتبة الافتراضي. إذا كان bits أقل من الصفر، أو صغيرًا جدًا لاستيعاب المتطلبات المحددة بواسطة معلمات top و bottom، يتم إرجاع خطأ. تحدد معلمات top المتطلبات على البت الأكثر أهمية للرقم المولّد. إذا كانت BN_RAND_TOP_ANY، فلا يوجد قيد. إذا كانت BN_RAND_TOP_ONE، يجب أن يكون البت العلوي واحدًا. إذا كانت BN_RAND_TOP_TWO، سيتم تعيين البتين الأكثر أهمية للرقم إلى 1، بحيث يكون حاصل ضرب رقمين عشوائيين من هذا القبيل دائمًا بطول 2 * bits. إذا كانت bottom هي BN_RAND_BOTTOM_ODD، فسيكون الرقم فرديًا؛ إذا كانت BN_RAND_BOTTOM_ANY يمكن أن يكون فرديًا أو زوجيًا. إذا كان bits يساوي 1، فلا يمكن أن يكون top أيضًا BN_RAND_TOP_TWO.

BN_rand() هي نفسها BN_rand_ex() باستثناء أنها تستخدم دائمًا سياق المكتبة الافتراضي.

تولد BN_rand_range_ex() رقمًا زائفًا عشوائيًا قويًا من الناحية التشفيرية rnd، بقوة أمان لا تقل عن strength بت، في النطاق 0 <= rnd < range باستخدام مولد الأرقام العشوائية للسياق الخاص بالمكتبة المرتبط بـ ctx. قد يكون المعلم ctx قيمته NULL، وفي هذه الحالة يتم استخدام سياق المكتبة الافتراضي.

BN_rand_range() هي نفسها BN_rand_range_ex() باستثناء أنها تستخدم دائمًا سياق المكتبة الافتراضي.

BN_priv_rand_ex()، BN_priv_rand()، BN_priv_rand_rand_ex() و BN_priv_rand_range() لها نفس دلالات BN_rand_ex()، BN_rand()، BN_rand_range_ex() و BN_rand_range() على التوالي. وهي مخصصة للاستخدام في توليد القيم التي يجب أن تظل خاصة، وتعكس نفس الفرق بين RAND_bytes(3) و RAND_priv_bytes(3).

ملاحظات

تحقق دائمًا من قيمة الإرجاع للخطأ لهذه الدوال ولا تأخذ العشوائية كأمر مسلم به: يحدث خطأ إذا لم يتم تهيئة CSPRNG بكمية كافية من العشوائية لضمان تسلسل بايت غير قابل للتنبؤ.

قيم الإرجاع

تعيد الدوال 1 عند النجاح، و 0 عند الخطأ. يمكن الحصول على رموز الخطأ بواسطة ERR_get_error(3).

انظر أيضًا

ERR_get_error(3)، RAND_add(3)، RAND_bytes(3)، RAND_priv_bytes(3)، RAND(7)، EVP_RAND(7)

التاريخ

  • بدءًا من إصدار OpenSSL 1.1.0، كانت BN_pseudo_rand() متطابقة مع BN_rand() وكانت BN_pseudo_rand_range() متطابقة مع BN_rand_range(). تم إيقاف الدوال BN_pseudo_rand() و BN_pseudo_rand_range() في OpenSSL 3.0.
  • تمت إضافة الدوال BN_priv_rand() و BN_priv_rand_range() في OpenSSL 1.1.1.
  • تمت إضافة الدوال BN_rand_ex()، BN_priv_rand_ex()، BN_rand_range_ex() و BN_priv_rand_range_ex() في OpenSSL 3.0.
