bpftool-struct_ops(8)

الحزمة: bpf

التراخيص: GPL-2.0-only

BPFTOOL-STRUCT_OPS(8) دليل مدير النظام BPFTOOL-STRUCT_OPS(8)

الاسم

bpftool-struct_ops - أداة لتسجيل/إلغاء تسجيل/فحص BPF struct_ops

الملخص

bpftool [خيارات] struct_ops أمر

خيارات := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

أوامر := { show | list | dump | register | unregister | help }

أوامر struct_ops

bpftool struct_ops { show | list } [خريطة_struct_ops]
bpftool struct_ops dump [خريطة_struct_ops]
bpftool struct_ops register كائن [دليل_الربط]
bpftool struct_ops unregister خريطة_struct_ops
bpftool struct_ops help
خريطة_struct_ops := { id معرف_خريطة_struct_ops | name اسم_خريطة_struct_ops }
كائن := /a/file/of/bpf_struct_ops.o

الوصف

bpftool struct_ops { show | list } [خريطة_struct_ops]
يعرض معلومات موجزة عن struct_ops في النظام. إذا تم تحديد خريطة_struct_ops، فإنه يعرض معلومات فقط لـ struct_ops المحدد. بخلاف ذلك، فإنه يسرد جميع struct_ops الموجودة حاليًا في النظام.

سيبدأ الإخراج بمعرف خريطة struct_ops، متبوعًا باسم خريطتها ونوع kernel الخاص بها.

bpftool struct_ops dump [خريطة_struct_ops]
يفرغ معلومات مفصلة حول struct_ops في النظام. إذا تم تحديد خريطة_struct_ops، فإنه يفرغ معلومات فقط لـ struct_ops المحدد. بخلاف ذلك، فإنه يفرغ جميع struct_ops الموجودة حاليًا في النظام.
bpftool struct_ops register كائن [دليل_الربط]
يسجل bpf struct_ops من كائن. سيتم تسجيل جميع struct_ops الموجودة تحت قسم ELF ".struct_ops" و ".struct_ops.link" في نظام kernel الفرعي الخاص بها. لكل struct_ops في قسم ".struct_ops.link"، سيتم إنشاء ربط. يمكنك توفير دليل_الربط لتوفير مسار دليل حيث سيتم تثبيت هذه الروابط بنفس الاسم مثل اسم الخريطة المقابل لها.
bpftool struct_ops unregister خريطة_struct_ops
يلغي تسجيل خريطة_struct_ops من نظام kernel الفرعي.
bpftool struct_ops help
يطبع رسالة مساعدة موجزة.

خيارات

-h, --help
يطبع رسالة مساعدة موجزة (مشابهة لـ bpftool help).
-V, --version
يطبع رقم إصدار bpftool (مشابه لـ bpftool version)، ورقم إصدار libbpf المستخدم، والميزات الاختيارية التي تم تضمينها عند تجميع bpftool. تشمل الميزات الاختيارية الربط بـ LLVM أو libbfd لتوفير برنامج فك التجميع للبرامج المترجمة بشكل JIT (bpftool prog dump jited) واستخدام هياكل BPF (بعض الميزات مثل bpftool prog profile أو عرض pids المرتبطة بكائنات BPF قد تعتمد عليها).
-j, --json
ينشئ إخراج JSON. بالنسبة للأوامر التي لا يمكنها إنتاج JSON، لا يكون لهذا الخيار تأثير.
-p, --pretty
ينشئ إخراج JSON قابل للقراءة بواسطة الإنسان. يتضمن -j.
-d, --debug
يطبع جميع السجلات المتاحة، حتى معلومات مستوى التصحيح. يشمل ذلك السجلات من libbpf وكذلك من المدقق (verifier) عند محاولة تحميل البرامج.

أمثلة

# bpftool struct_ops show

100: dctcp           tcp_congestion_ops
105: cubic           tcp_congestion_ops

# bpftool struct_ops unregister id 105

Unregistered tcp_congestion_ops cubic id 105

# bpftool struct_ops register bpf_cubic.o

Registered tcp_congestion_ops cubic id 110
