الاسم

bdep-argument-grouping - تسهيل تجميع الوسائط

الملخص

bdep { options }+ argument +{ options }

الوصف

بالنسبة لبعض الأوامر، يمكن تجميع بعض الخيارات ومتغيرات سطر الأوامر لتطبيقها فقط على وسائط محددة. يصف موضوع المساعدة هذا تسهيل تجميع الوسائط المستخدم لهذا الغرض.

يمكن تحديد المجموعات قبل (بادئة) و/أو بعد (لاحقة) الوسيط الذي تطبق عليه. تبدأ المجموعة البادئة بـ '{' وتنتهي بـ '}+' بينما تبدأ المجموعة اللاحقة بـ '+{' وتنتهي بـ '}'. على سبيل المثال:

{ --foo --bar }+ arg   # 'arg' مع '--foo' '--bar'
arg +{ fox=1 baz=2 }   # 'arg' مع 'fox=1' 'baz=2'

يمكن تحديد مجموعات بادئة و/أو لاحقة متعددة لنفس الوسيط. على سبيل المثال:

{ -f }+ { -b }+ arg +{ f=1 } +{ b=2 } # 'arg' مع '-f' 'b' 'f=1' 'b=2'

تطبق المجموعة على وسيط واحد فقط ما لم يتم تجميع وسائط متعددة بحد ذاتها باستخدام '{' و '}'. على سبيل المثال:

{ --foo }+ arg1  arg2 +{ --bar }      # 'arg1' مع '--foo'
                                      # 'arg2' مع '--bar'
{ --foo }+ { arg1  arg2 } +{ --bar }  # 'arg1' مع '--foo' '--bar'
                                      # 'arg2' مع '--foo' '--bar'

يجب أن تكون فواصل المجموعة ('{', '}+'، إلخ) وسائط منفصلة في سطر الأوامر. على وجه الخصوص، يجب ألا تكون متجاورة إما مع الوسائط داخل المجموعة أو مع الوسيط الذي تطبق عليه. سيتم التعامل مع جميع الحالات من هذا القبيل كوسائط عادية. على سبيل المثال:

{--foo}+ arg   # '{--foo}+' ...
arg+{ --foo }  # 'arg+{' ...

إذا كانت إحدى فواصل المجموعة تحتاج إلى تحديد كوسيط حرفيًا، فيجب الهروب منها بـ '\'. على سبيل المثال:

}             # خطأ: فاصل مجموعة غير متوقع
}x            # '}x'
\}            # '}'
{ \}+ }+ arg  # 'arg' مع '}+'
