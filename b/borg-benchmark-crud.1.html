borg-benchmark-crud(1)

الحزمة: borg

التراخيص: BSD

BORG-BENCHMARK-CRUD(1) أداة borg backup BORG-BENCHMARK-CRUD(1)

الاسم

borg-benchmark-crud - قياس أداء عمليات الإنشاء، القراءة، التحديث، الحذف للأرشيفات.

ملخص

borg [خيارات مشتركة] benchmark crud [خيارات] REPOSITORY PATH

الوصف

يقيس هذا الأمر أداء عمليات CRUD (إنشاء، قراءة، تحديث، حذف) في borg.

يقوم بإنشاء بيانات إدخال في المسار المحدد ونسخ هذه البيانات احتياطيًا إلى المستودع المحدد (REPO). يجب أن يكون المستودع موجودًا بالفعل (يمكن أن يكون مستودعًا جديدًا فارغًا أو مستودعًا موجودًا، سيقوم الأمر بإنشاء / قراءة / تحديث / حذف بعض الأرشيفات المسماة borg-benchmark-crud* فيه.

تأكد من أن لديك مساحة خالية هناك، ستحتاج إلى حوالي 1 جيجابايت لكل منها (+ تكاليف إضافية).

إذا كان مستودعك مشفرًا ويحتاج borg إلى عبارة مرور لفك تشفير المفتاح، استخدم:

BORG_PASSPHRASE=mysecret borg benchmark crud REPO PATH

تتم القياسات باستخدام أحجام وعدد مختلف من ملفات الإدخال. محتويات الملفات اصطناعية للغاية (إما كلها أصفار أو كلها عشوائية)، وبالتالي فإن نتائج القياس لا تعكس بالضرورة الأداء مع البيانات الحقيقية. أيضًا، نظرًا لنوع المحتوى المستخدم، لا يتم استخدام أي ضغط في هذه القياسات.

C- == borg create (إنشاء الأرشيف الأول، بدون ضغط، لا تستخدم ذاكرة التخزين المؤقت للملفات)
C-Z- == ملفات جميعها أصفار. إزالة بيانات مكررة بالكامل؛ هذا يقيس بشكل أساسي القارئ/المقطع/الهاشر. C-R- == ملفات عشوائية. عدم إزالة البيانات المكررة، قياس معدل النقل عبر جميع مراحل المعالجة.
R- == borg extract (استخراج الأرشيف، تشغيل تجريبي، قم بكل شيء، ولكن لا تكتب الملفات إلى القرص)
R-Z- == ملفات جميعها أصفار. قياس الملفات المكررة بكثرة. R-R- == ملفات عشوائية. عدم وجود تكرار هنا، قياس معدل النقل عبر جميع مراحل المعالجة، باستثناء الكتابة إلى القرص.
U- == borg create (إنشاء الأرشيف الثاني لملفات الإدخال التي لم تتغير، قياس سرعة ذاكرة التخزين المؤقت للملفات)
قيمة معدل النقل افتراضية هنا، فهي لا تقرأ الملف فعليًا. U-Z- == تحتاج إلى التحقق من وجود القطعتين المكونتين من الأصفار في المستودع. U-R- == تحتاج إلى التحقق من وجود الكثير من القطع المختلفة في المستودع.
D- == borg delete archive (حذف آخر أرشيف متبقٍ، قياس الحذف + الضغط)
D-Z- == قطع قليلة للحذف / شرائح قليلة للضغط/الإزالة. D-R- == قطع كثيرة للحذف / شرائح كثيرة للضغط/الإزالة.

يرجى ملاحظة أنه قد يكون هناك تباين كبير في هذه القياسات. جرب قياسات متعددة واجعل الآلة خاملة (والشبكة، إذا كنت تستخدمها).

خيارات

انظر borg-common(1) للخيارات المشتركة لأوامر Borg.
