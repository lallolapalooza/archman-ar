الدالة rewrite_first : map -> path -> path option

rewrite_first map path تحاول العثور على مصدر في map يكون بادئة للمسار المدخل path . إذا نجحت، فإنها تستبدل هذه البادئة بالهدف المقابل. إذا فشلت، فإنها تعيد فقط None .

الدالة rewrite_all : map -> path -> path list

rewrite_all map path تجد جميع المصادر في map التي هي بادئة للمسار المدخل path . لكل مصدر مطابق، بترتيب الأولوية، تستبدل هذه البادئة بالهدف المقابل وتضيف النتيجة إلى القائمة المعادة. إذا لم يكن هناك تطابقات، فإنها تعيد فقط [] .

الدالة rewrite : map -> path -> path

rewrite path تستخدم rewrite_first لمحاولة العثور على تعيين للمسار. إذا تم العثور عليه، فإنها تعيد ذلك، وإلا فإنها تعيد فقط path .
