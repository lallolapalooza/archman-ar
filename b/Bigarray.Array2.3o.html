الوحدة Bigarray.Array2

توثيق

الوحدة Array2
: sig end

مصفوفات ثنائية الأبعاد. توفر بنية Array2 عمليات مشابهة لتلك الخاصة بـ Bigarray.Genarray ، ولكنها متخصصة لحالة المصفوفات ثنائية الأبعاد.

type (!'a, !'b, !'c) t

نوع المصفوفات Bigarrays ثنائية الأبعاد التي تحتوي عناصرها على نوع OCaml 'a ، ونوع تمثيل 'b ، وتخطيط ذاكرة 'c .

val create : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> ('a, 'b, 'c) t

Array2.create kind layout dim1 dim2 تُرجع مصفوفة Bigarray جديدة ثنائية الأبعاد، بحجم dim1 في البعد الأول و dim2 في البعد الثاني. يحدد kind و layout نوع عناصر المصفوفة وتخطيطها كما هو موصوف لـ Bigarray.Genarray.create .

val init : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> int -> int -> (int -> int -> 'a) -> ('a, 'b, 'c) t

Array2.init kind layout dim1 dim2 f تُرجع مصفوفة Bigarray جديدة b ثنائية الأبعاد، بحجم dim1 في البعد الأول و dim2 في البعد الثاني. يحدد kind و layout نوع عناصر المصفوفة وتخطيطها كما هو موصوف لـ Bigarray.Genarray.create .

يتم تهيئة كل عنصر Array2.get b i j من المصفوفة بنتيجة f i j .

بمعنى آخر، Array2.init kind layout dim1 dim2 f يُجدول نتائج f مطبقة على فهارس مصفوفة Bigarray جديدة موصوفة بتخطيط kind و layout و dim1 و dim2 .

منذ 4.12

val dim1 : ('a, 'b, 'c) t -> int

تُرجع البعد الأول لمصفوفة Bigarray ثنائية الأبعاد المحددة.

val dim2 : ('a, 'b, 'c) t -> int

تُرجع البعد الثاني لمصفوفة Bigarray ثنائية الأبعاد المحددة.

val kind : ('a, 'b, 'c) t -> ('a, 'b) Bigarray.kind

تُرجع نوع مصفوفة Bigarray المحددة.

val layout : ('a, 'b, 'c) t -> 'c Bigarray.layout

تُرجع تخطيط مصفوفة Bigarray المحددة.

val change_layout : ('a, 'b, 'c) t -> 'd Bigarray.layout -> ('a, 'b, 'd) t

Array2.change_layout a layout تُرجع مصفوفة Bigarray بالتخطيط المحدد layout ، وتتشارك البيانات مع a (وبالتالي لها نفس الأبعاد مثل a ). لا يتم نسخ العناصر: تتشارك المصفوفة الجديدة والمصفوفة الأصلية نفس مساحة التخزين. يتم عكس الأبعاد، بحيث يصبح get v [| a; b |] في تخطيط C هو get v [| b+1; a+1 |] في تخطيط Fortran.

منذ 4.06

val size_in_bytes : ('a, 'b, 'c) t -> int

size_in_bytes a هو عدد العناصر في a مضروبًا في a 's Bigarray.kind_size_in_bytes .

منذ 4.03

val get : ('a, 'b, 'c) t -> int -> int -> 'a

Array2.get a x y ، والتي تُكتب أيضًا a.{x,y} ، تُرجع العنصر من a عند الإحداثيات ( x ، y ). يجب أن تكون x و y ضمن حدود a ، كما هو موصوف لـ Bigarray.Genarray.get ؛ وإلا، يتم إطلاق Invalid_argument.

val set : ('a, 'b, 'c) t -> int -> int -> 'a -> unit

Array2.set a x y v ، أو بدلاً من ذلك a.{x,y} <- v ، تخزن القيمة v عند الإحداثيات ( x ، y ) في a . يجب أن تكون x و y ضمن حدود a ، كما هو موصوف لـ Bigarray.Genarray.set ؛ وإلا، يتم إطلاق Invalid_argument.

val sub_left : ('a, 'b, Bigarray.c_layout) t -> int -> int -> ('a, 'b, Bigarray.c_layout) t

تستخرج مصفوفة فرعية ثنائية الأبعاد من مصفوفة Bigarray ثنائية الأبعاد المحددة عن طريق تقييد البعد الأول. انظر Bigarray.Genarray.sub_left لمزيد من التفاصيل. Array2.sub_left تنطبق فقط على المصفوفات ذات التخطيط C.

val sub_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> int -> ('a, 'b, Bigarray.fortran_layout) t

تستخرج مصفوفة فرعية ثنائية الأبعاد من مصفوفة Bigarray ثنائية الأبعاد المحددة عن طريق تقييد البعد الثاني. انظر Bigarray.Genarray.sub_right لمزيد من التفاصيل. Array2.sub_right تنطبق فقط على المصفوفات ذات تخطيط Fortran.

val slice_left : ('a, 'b, Bigarray.c_layout) t -> int -> ('a, 'b, Bigarray.c_layout) Bigarray.Array1.t

تستخرج صفًا (شريحة أحادية البعد) من مصفوفة Bigarray ثنائية الأبعاد المحددة. المعامل الصحيح هو فهرس الصف المراد استخراجه. انظر Bigarray.Genarray.slice_left لمزيد من التفاصيل. Array2.slice_left تنطبق فقط على المصفوفات ذات التخطيط C.

val slice_right : ('a, 'b, Bigarray.fortran_layout) t -> int -> ('a, 'b, Bigarray.fortran_layout) Bigarray.Array1.t

تستخرج عمودًا (شريحة أحادية البعد) من مصفوفة Bigarray ثنائية الأبعاد المحددة. المعامل الصحيح هو فهرس العمود المراد استخراجه. انظر Bigarray.Genarray.slice_right لمزيد من التفاصيل. Array2.slice_right تنطبق فقط على المصفوفات ذات تخطيط Fortran.

val blit : ('a, 'b, 'c) t -> ('a, 'b, 'c) t -> unit

تنسخ مصفوفة Bigarray الأولى إلى مصفوفة Bigarray الثانية. انظر Bigarray.Genarray.blit لمزيد من التفاصيل.

val fill : ('a, 'b, 'c) t -> 'a -> unit

تملأ مصفوفة Bigarray المحددة بالقيمة المحددة. انظر Bigarray.Genarray.fill لمزيد من التفاصيل.

val of_array : ('a, 'b) Bigarray.kind -> 'c Bigarray.layout -> 'a array array -> ('a, 'b, 'c) t

تبني مصفوفة Bigarray ثنائية الأبعاد مهيأة من مصفوفة المصفوفات المحددة.
