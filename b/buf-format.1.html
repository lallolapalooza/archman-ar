buf-format(1)

الحزمة: buf

التراخيص: Apache-2.0

Buf(1) Buf(1)

الاسم

buf-format - تنسيق ملفات Protobuf

الاستخدام

buf format [flags]

الوصف

افتراضيًا، المصدر هو الدليل الحالي ويتم كتابة المحتوى المنسق إلى stdout.

أمثلة:

كتابة المحتوى المنسق للدليل الحالي إلى stdout:

$ buf format

سيقوم معظم الأشخاص بإعادة كتابة الملفات المعرفة في الدليل الحالي في مكانها باستخدام -w:

$ buf format -w

عرض فرق بين المحتوى الأصلي والمنسق باستخدام -d كتابة فرق بدلاً من الملف المنسق:

$ buf format simple/simple.proto -d
$ diff -u simple/simple.proto.orig simple/simple.proto
--- simple/simple.proto.orig	2022-03-24 09:44:10.000000000 -0700
+++ simple/simple.proto	2022-03-24 09:44:10.000000000 -0700
@@ -2,8 +2,7 @@
package simple;
-
message Object {
-    string key = 1;
-   bytes value = 2;
+  string key = 1;
+  bytes value = 2;
}

استخدم العلامة --exit-code للخروج برمز خروج غير صفري إذا كان هناك فرق:

$ buf format --exit-code
$ buf format -w --exit-code
$ buf format -d --exit-code

تنسيق ملف أو دليل أو مرجع وحدة نمطية عن طريق تحديد مصدر، على سبيل المثال كتابة الملف المنسق إلى stdout:

$ buf format simple/simple.proto
syntax = "proto3";
package simple;
message Object {
  string key = 1;
  bytes value = 2;
}

كتابة الدليل المنسق إلى stdout:

$ buf format simple
...

كتابة مرجع الوحدة النمطية المنسق إلى stdout:

$ buf format buf.build/acme/petapis
...

كتابة النتيجة إلى ملف أو دليل محدد باستخدام -o، على سبيل المثال:

كتابة الملف المنسق إلى ملف آخر:

$ buf format simple/simple.proto -o simple/simple.formatted.proto

كتابة الدليل المنسق إلى دليل آخر، وإنشائه إذا لم يكن موجودًا:

$ buf format proto -o formatted

يعمل هذا أيضًا مع مراجع الوحدات النمطية:

$ buf format buf.build/acme/weather -o formatted

إعادة كتابة الملف (الملفات) في مكانها باستخدام -w. على سبيل المثال:

إعادة كتابة ملف واحد في مكانه:

$ buf format simple.proto -w

إعادة كتابة دليل كامل في مكانه:

$ buf format proto -w

كتابة فرق وإعادة كتابة الملف (الملفات) في مكانها:

$ buf format simple -d -w
$ diff -u simple/simple.proto.orig simple/simple.proto
...

لا يمكن استخدام العلامتين -w و -o معًا في استدعاء واحد.

الخيارات

--config="" ملف buf.yaml أو البيانات المستخدمة للتكوين

-d, --diff[=false] عرض الفروقات بدلاً من إعادة كتابة الملفات

--disable-symlinks[=false] لا تتبع الروابط الرمزية عند قراءة المصادر أو التكوين من نظام الملفات المحلي. افتراضيًا، يتم اتباع الروابط الرمزية في سطر الأوامر هذا، ولكن لا يتم اتباعها أبدًا في سجل Buf Schema.

--error-format="text" تنسيق أخطاء البناء المطبوعة إلى stderr. يجب أن تكون واحدة من [text,json,msvs,junit,github-actions,gitlab-code-quality]

--exclude-path=[] استبعاد ملفات أو أدلة محددة، على سبيل المثال "proto/a/a.proto"، "proto/a". إذا تم تحديدها عدة مرات، يتم أخذ الاتحاد.

--exit-code[=false] الخروج برمز خروج غير صفري إذا لم تكن الملفات منسقة بالفعل

-h, --help[=false] مساعدة للتنسيق

-o, --output="-" موقع الإخراج للملفات المنسقة. يجب أن يكون أحد تنسيقات [dir,protofile]. إذا تم حذفه، يتم كتابة النتيجة إلى stdout.

--path=[] الحد إلى ملفات أو أدلة محددة، على سبيل المثال "proto/a/a.proto"، "proto/a". إذا تم تحديدها عدة مرات، يتم أخذ الاتحاد.

-w, --write[=false] إعادة كتابة الملفات في مكانها

الخيارات الموروثة من الأوامر الأصل

--debug[=false] تشغيل تسجيل التصحيح

--log-format="color" تنسيق السجل [text,color,json]

--timeout=0s المدة حتى انتهاء المهلة، تعيينها إلى 0 يعني عدم وجود مهلة
