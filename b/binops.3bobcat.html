binops.3bobcat

الحزمة: libbobcat

التراخيص: GPL

binops(3bobcat) المعاملات الثنائية binops(3bobcat)

الاسم

binops - قوالب دوال للمعاملات الثنائية من نوع الفئة

الملخص

#include <utility>
#include <bobcat/typetrait>
#include <bobcat/binops>

الوصف

يمكن للفئات إعادة تعريف المعاملات الثنائية. قد تعيد فئة باسم Class تعريف المعاملات الثنائية لتناسب احتياجاتها الخاصة، مما يسمح، على سبيل المثال، بجمع كائنين من نوع Class بعد إعادة تعريف operator+. يمكن إعادة تعريف المعاملات الثنائية *, /, %, +, -, <<, >>, &, |, و ^ (في صفحة الدليل هذه يتم الإشارة إليها بشكل عام باسم معامل `@`) عن طريق تعريف الدالة operator@.

إذا كانت الفئة تدعم النسخ بالبناء وإذا كانت توفر معاملات تعيين ثنائية (أي، توفر أعضاء بالشكل operator@=)، فيمكن تطبيق المعاملات الثنائية المطابقة جميعها بنفس الطريقة. يمكن بسهولة تطبيق move-aware Class &operator@(Class &&lhs, Class const &rhs) بناءً على operator@= (لاحظ أن الفئة نفسها لا تحتاج إلى أن تكون `move-aware` لتعريف هذه الدالة). يتطلب المعامل الثنائي move-aware تنفيذاً من سطر واحد، وبما أن تنفيذه لا يتغير أبداً، يمكن تعريفه بأمان inline:

Class operator@(Class &&lhs, Class const &rhs)
{
    return std::move(std::move(lhs) @= rhs);
}
يمكن تطبيق المعامل الثنائي التقليدي باستخدام شكله القياسي: 
Class operator@(Class const &lhs, Class const &rhs)
{
    Class tmp(lhs);
    tmp @= rhs;
    return tmp;
}
التنفيذ في bobcat/binops أكثر تعقيدًا قليلاً لأنه يسمح بالترقيات من lhs أو rhs.

بما أن المعاملات الثنائية يمكن تنفيذها جميعًا بنفس الطريقة، فإن تعريفاتها مناسبة تمامًا للقوالب: الفئة التي توفر operator@= معينة، ستوفر تلقائيًا المعاملات الثنائية المطابقة بعد تضمين bobcat/binops. نظرًا لأن قوالب الدوال الثنائية لا يتم إنشاؤها إلا عند استخدامها، يمكن معالجتها بواسطة المترجم حتى لو كانت الفئة تنفذ مجموعة فرعية فقط من معاملات التعيين الثنائية المتاحة.

المساحة الاسمية

قوالب دوال المعاملات الثنائية في bobcat/binops *لا* يتم تنفيذها في مساحة اسمية معينة. هذا يسمح للمصادر بتضمين bobcat/binops في مساحات اسمية متعددة.

إذا كان سيتم استخدام bobcat/binops في مساحات اسمية متعددة، فيجب إلغاء حماية التضمين (باستخدام المعرف INCLUDED_BOBCAT_BINOPS_) بين عمليات تضمين bobcat/binops في مساحات اسمية مختلفة.

على سبيل المثال، لجعل قوالب دوال المعاملات الثنائية متاحة في ملف مصدر يستخدم namespace FBB وفي ملف مصدر يستخدم المساحة الاسمية الافتراضية، يمكن استخدام المخطط التالي:

#include <utility>              // تأكد من أن std::move متاح
#include <bobcat/typetrait>     // مطلوب بواسطة binops
namespace MY_NAMESPACE
{
    #include <bobcat/binops>    // المعاملات الثنائية متاحة في MY_NAMESPACE
}
#undef INCLUDED_BOBCAT_BINOPS_  // إلغاء حماية التضمين
#include <bobcat/binops>        // قراءة binops مرة أخرى حتى يمكن استخدام المعاملات
                                // الثنائية في المساحة الاسمية الافتراضية أيضًا

المعاملات المعاد تعريفها

تنفيذ قوالب الدالة في bobcat/binops جميع المعاملات الحسابية الثنائية، سواء كانت move-aware أو المعاملات الثنائية التقليدية، وتتوقع مراجع lvalue ثابتة. يمكن استخدامها إذا تم تنفيذ معاملات التعيين الثنائية المقابلة في الفئات التي يجب إنشاء القوالب لها. المعاملات التالية متاحة:

المعاملات Move-aware، باستخدام الكائنات المؤقتة لمعاملاتها اليسرى:

o
Class operator/(Class &&lhs, Class const &rhs):
o
Class operator%(Class &&lhs, Class const &rhs):
o
Class operator+(Class &&lhs, Class const &rhs):
o
Class operator-(Class &&lhs, Class const &rhs):
o
Class operator<<(Class &&lhs, Class const &rhs):
o
Class operator>>(Class &&lhs, Class const &rhs):
o
Class operator&(Class &&lhs, Class const &rhs):
o
Class operator|(Class &&lhs, Class const &rhs):
o
Class operator^(Class &&lhs, Class const &rhs):

المعاملات `التقليدية`، باستخدام مراجع lvalue للكائنات الثابتة لمعاملاتها اليسرى:

المجموعة الأخيرة من المعاملات تدعم أيضًا الترقيات.

مثال

#include <iostream>
#include <utility>
#include "../../typetrait/typetrait"
#include "../binops"
class Demo
{
    friend std::ostream &operator<<(std::ostream &out, Demo const &demo);
    int d_value;
    public:
        Demo(int value = 0)
        :
            d_value(value)
        {}
        Demo(Demo const &other)
        :
            d_value(other.d_value)
        {
            std::cout << "Demo CC called\n";
        }
        Demo &operator+=(Demo const &rhs)
        {
            d_value += rhs.d_value;
            return *this;
        }
};
std::ostream &operator<<(std::ostream &out, Demo const &demo)
{
    return out << demo.d_value;
}
using namespace std;
int main()
{
    Demo four(4);
    Demo five(5);
    cout << four + five << ’\n’ <<
            four + 5 << ’\n’ <<
            4  + five << ’\n’;
}
