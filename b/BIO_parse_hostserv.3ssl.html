BIO_parse_hostserv(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

BIO_PARSE_HOSTSERV(3ssl) OpenSSL BIO_PARSE_HOSTSERV(3ssl)

الاسم

BIO_hostserv_priorities, BIO_parse_hostserv - روتينات مساعدة لتحليل سلسلة مضيف وخدمة قياسية

الملخص

#include <openssl/bio.h>
enum BIO_hostserv_priorities {
    BIO_PARSE_PRIO_HOST, BIO_PARSE_PRIO_SERV
};
int BIO_parse_hostserv(const char *hostserv, char **host, char **service,
                       enum BIO_hostserv_priorities hostserv_prio);

الوصف

سيقوم BIO_parse_hostserv() بتحليل المعلومات المقدمة في hostserv، وإنشاء سلاسل نصية باسم المضيف واسم الخدمة وتقديمها عبر host و service. ستحتاج هذه إلى تحريرها بعد استخدامها. يساعد hostserv_prio في تحديد ما إذا كان ينبغي تفسير hostserv في المقام الأول كمضيف أو اسم خدمة في الحالات الغامضة.

الصيغة التي يتعرف عليها BIO_parse_hostserv() هي:

host + ':' + service
host + ':' + '*'
host + ':'
       ':' + service
'*'  + ':' + service
host
service

يمكن أن يكون جزء المضيف اسمًا أو عنوان IP. إذا كان عنوان IPv6، فيجب أن يكون محاطًا بأقواس مربعة، مثل '[::1]'.

يمكن أن يكون جزء الخدمة اسم خدمة أو رقم منفذها. سيتم تعيين اسم خدمة إلى رقم منفذ باستخدام دالة النظام getservbyname().

ستعتمد القيم المرجعة على سلسلة hostserv المعطاة و hostserv_prio، على النحو التالي:

host + ':' + service  => *host = "host", *service = "service"
host + ':' + '*'      => *host = "host", *service = NULL
host + ':'            => *host = "host", *service = NULL
       ':' + service  => *host = NULL, *service = "service"
 '*' + ':' + service  => *host = NULL, *service = "service"
في حالة عدم وجود ':' في السلسلة، تعتمد النتيجة على
hostserv_prio، على النحو التالي:
عندما يكون hostserv_prio == BIO_PARSE_PRIO_HOST
host                 => *host = "host", *service لم يتم المساس به
عندما يكون hostserv_prio == BIO_PARSE_PRIO_SERV
service              => *host لم يتم المساس به, *service = "service"

قيم الإرجاع

BIO_parse_hostserv() ترجع 1 عند النجاح أو 0 عند الخطأ.
