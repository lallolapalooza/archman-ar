BIO_printf(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

BIO_PRINTF(3ssl) OpenSSL BIO_PRINTF(3ssl)

الاسم

BIO_printf, BIO_vprintf, BIO_snprintf, BIO_vsnprintf - إخراج منسق إلى BIO

الملخص

#include <openssl/bio.h>
int BIO_printf(BIO *bio, const char *format, ...);
int BIO_vprintf(BIO *bio, const char *format, va_list args);
int BIO_snprintf(char *buf, size_t n, const char *format, ...);
int BIO_vsnprintf(char *buf, size_t n, const char *format, va_list args);

الوصف

BIO_printf() مشابهة لدالة C القياسية printf()، باستثناء أن الإخراج يتم إرساله إلى BIO المحدد، bio، بدلاً من المخرج القياسي. يتم دعم جميع محددات التنسيق الشائعة.

BIO_vprintf() مشابهة لدالة vprintf() الموجودة على العديد من المنصات، يتم إرسال الإخراج إلى BIO المحدد، bio، بدلاً من المخرج القياسي. يتم دعم جميع محددات التنسيق الشائعة. قائمة الوسائط args هي قائمة وسائط stdarg.

BIO_snprintf() مخصصة للمنصات التي لا تحتوي على دالة snprintf() الشائعة. إنها مثل sprintf() باستثناء أن معامل الحجم، n، يحدد حجم المخزن المؤقت للإخراج.

BIO_vsnprintf() بالنسبة إلى BIO_snprintf() كما هي BIO_vprintf() بالنسبة إلى BIO_printf().

قيم الإرجاع

جميع الدوال ترجع عدد البايتات المكتوبة، أو -1 عند حدوث خطأ. بالنسبة لـ BIO_snprintf() و BIO_vsnprintf()، يشمل ذلك عندما يكون مخزن الإخراج المؤقت صغيرًا جدًا.

ملاحظات

باستثناء عندما يكون n يساوي 0، تقوم كل من BIO_snprintf() و BIO_vsnprintf() دائمًا بإنهاء إخراجهما بـ '\0'. ويشمل ذلك الحالات التي يتم فيها إرجاع -1، مثل عندما تكون المساحة غير كافية لإخراج السلسلة بأكملها.
