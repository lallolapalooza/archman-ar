BEGIN(7)

الحزمة: postgresql

التراخيص: PostgreSQL

BEGIN(7) توثيق PostgreSQL 18.1 BEGIN(7)

الاسم

BEGIN - بدء كتلة معاملة

الملخص

BEGIN [ WORK | TRANSACTION ] [ transaction_mode [, ...] ]
where transaction_mode is one of:
    ISOLATION LEVEL { SERIALIZABLE | REPEATABLE READ | READ COMMITTED | READ UNCOMMITTED }
    READ WRITE | READ ONLY
    [ NOT ] DEFERRABLE

الوصف

BEGIN تبدأ كتلة معاملة، أي أن جميع الأوامر بعد أمر BEGIN سيتم تنفيذها في معاملة واحدة حتى يتم إعطاء أمر COMMIT أو ROLLBACK صريح. افتراضياً (بدون BEGIN)، يقوم PostgreSQL بتنفيذ المعاملات في وضع "التأكيد التلقائي"، أي أن كل أمر يتم تنفيذه في معاملته الخاصة ويتم تأكيد ضمني في نهاية الأمر (إذا كان التنفيذ ناجحاً، وإلا يتم التراجع).

يتم تنفيذ الأوامر بشكل أسرع في كتلة معاملة، لأن بدء/تأكيد المعاملة يتطلب نشاطاً كبيراً للمعالج القرص. كما أن تنفيذ أوامر متعددة داخل معاملة مفيد لضمان الاتساق عند إجراء عدة تغييرات مرتبطة: لن تتمكن الجلسات الأخرى من رؤية الحالات الوسيطة التي لم يتم فيها إجراء جميع التحديثات المرتبطة.

إذا تم تحديد مستوى العزل، أو وضع القراءة/الكتابة، أو وضع التأجيل، فإن المعاملة الجديدة تتمتع بهذه الخصائص، كما لو تم تنفيذ SET TRANSACTION.

المعاملات

WORK
TRANSACTION

كلمات مفتاحية اختيارية. ليس لها تأثير.

راجع SET TRANSACTION (SET_TRANSACTION(7)) للحصول على معلومات حول معنى المعاملات الأخرى لهذا الأمر.

ملاحظات

START TRANSACTION له نفس وظيفة BEGIN.

استخدم COMMIT أو ROLLBACK لإنهاء كتلة معاملة.

إصدار BEGIN عند وجودك بالفعل داخل كتلة معاملة سيؤدي إلى رسالة تحذير. حالة المعاملة لا تتأثر. لتداخل المعاملات داخل كتلة معاملة، استخدم نقاط الحفظ (انظر SAVEPOINT(7)).

لأسباب التوافقية مع الإصدارات السابقة، يمكن حذف الفواصل بين transaction_modes المتتالية.

أمثلة

لبدء كتلة معاملة:

BEGIN;

التوافق

BEGIN هو امتداد لغة PostgreSQL. إنه مكافئ لأمر SQL القياسي START TRANSACTION، والذي تحتوي صفحته المرجعية على معلومات توافق إضافية.

الوضع transaction_mode DEFERRABLE هو امتداد لغة PostgreSQL.

بالمصادفة، تُستخدم الكلمة المفتاحية BEGIN لغرض مختلف في SQL المضمن. يُنصح بتوخي الحذر بشأن دلالات المعاملات عند نقل تطبيقات قواعد البيانات.

انظر أيضاً

COMMIT(7), ROLLBACK(7), START TRANSACTION (START_TRANSACTION(7)), SAVEPOINT(7)
