التراخيص: GPL-2.0-only

BIND8_QUERY2DLF.IN(1) وثائق LogReport's Lire BIND8_QUERY2DLF.IN(1)

الاسم

bind8_query2dlf - تحويل سجلات استعلامات BIND8 إلى dlf

الملخص

bind8_query2dlf

الوصف

يقوم هذا النص البرمجي بتحويل كل سطر في سجل استعلامات bind8 إلى سجل dlf dns.

ينشئ BIND هذه السجلات عندما يكون شيء مثل

logging {
    channel query_logging {
        file "/var/log/named_querylog"
        versions 3 size 100M;
        print-time yes;                 // timestamp log entries              
     };
     category queries {
         query_logging;
     };
};

موجودًا في named.conf الخاص بـ bind. سيؤدي هذا إلى حفظ ما يصل إلى ثلاثة ملفات سجل بحد أقصى 100 ميجابايت في الدليل /var/log.

تبدو ملفات السجل هذه:

10-Apr-2000 00:01:20.307 XX /10.2.3.4/1.2.3.in-addr.arpa/SOA/IN
10-Apr-2000 00:01:20.308 XX+/10.4.3.2/host.foo.com/A/IN

أمثلة

لمعالجة سجل كما ينتجه bind8:

$ bind8_query2dlf < dns-query

نادراً ما يتم استخدام bind8_query2dlf بمفرده، ولكن من المرجح أن يتم استدعاؤه بواسطة lr_log2report:

$ lr_log2report bind8_query < /var/log/dns-query
