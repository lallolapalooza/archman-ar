القيم المنطقية

type t = bool =
| false
| true

نوع القيم المنطقية (قيم الحقيقة).

المُنشِئان false و true مدرجان هنا بحيث يكون لهما مسارات، ولكنهما غير مخصصين للاستخدام في أنواع بيانات يحددها المستخدم.

val not : bool -> bool

not b هو النفي المنطقي لـ b.

val (&&) : bool -> bool -> bool

e0 && e1 هو الاقتران المنطقي الكسول للتعبيرين e0 و e1. إذا كان e0 يقيّم إلى false، فلن يتم تقييم e1. عامل تشغيل مرتبط باليمين في مستوى الأسبقية 3/11.

val (||) : bool -> bool -> bool

e0 || e1 هو الفصل المنطقي الكسول للتعبيرين e0 و e1. إذا كان e0 يقيّم إلى true، فلن يتم تقييم e1. عامل تشغيل مرتبط باليمين في مستوى الأسبقية 2/11.

val logand : bool -> bool -> bool

logand b1 b2 هو true إذا وفقط إذا كان كل من b1 و b2 هما true.

val logor : bool -> bool -> bool

logor b1 b2 هو true إذا وفقط إذا كان إما b1 أو b2 هو true.

val logxor : bool -> bool -> bool

logxor b1 b2 هو true إذا كان واحد فقط من b1 و b2 هو true.

المناديات والمقارنات

val equal : bool -> bool -> bool

equal b0 b1 هو true إذا وفقط إذا كان كل من b0 و b1 هما true أو كليهما false.

val compare : bool -> bool -> int

compare b0 b1 هو ترتيب كلي على القيم المنطقية. false أصغر من true.

التحويل

val to_int : bool -> int

to_int b هو 0 إذا كان b هو false و 1 إذا كان b هو true.

val to_float : bool -> float

to_float b هو 0. إذا كان b هو false و 1. إذا كان b هو true.

val to_string : bool -> string

to_string b هو "true" إذا كان b هو true و "false" إذا كان b هو false.

val seeded_hash : int -> bool -> int

دالة تجزئة مع بذرة للقيم المنطقية، مع نفس قيمة الإخراج مثل Hashtbl.seeded_hash. تسمح هذه الدالة بتمرير هذه الوحدة كمعلمة للمُنشئ Hashtbl.MakeSeeded.
