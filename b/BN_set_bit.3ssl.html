BN_set_bit(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

BN_SET_BIT(3ssl) OpenSSL BN_SET_BIT(3ssl)

الاسم

BN_set_bit, BN_clear_bit, BN_is_bit_set, BN_mask_bits, BN_lshift, BN_lshift1, BN_rshift, BN_rshift1 - عمليات بت على BIGNUMs

الملخص

#include <openssl/bn.h>
int BN_set_bit(BIGNUM *a, int n);
int BN_clear_bit(BIGNUM *a, int n);
int BN_is_bit_set(const BIGNUM *a, int n);
int BN_mask_bits(BIGNUM *a, int n);
int BN_lshift(BIGNUM *r, const BIGNUM *a, int n);
int BN_lshift1(BIGNUM *r, BIGNUM *a);
int BN_rshift(BIGNUM *r, BIGNUM *a, int n);
int BN_rshift1(BIGNUM *r, BIGNUM *a);

الوصف

BN_set_bit() تضبط البت n في a إلى 1 ("a|=(1<<n)"). يتم توسيع الرقم إذا لزم الأمر.

BN_clear_bit() تضبط البت n في a إلى 0 ("a&=~(1<<n)"). يحدث خطأ إذا كان a أقصر من n بت.

BN_is_bit_set() تختبر ما إذا كان البت n في a مضبوطًا.

BN_mask_bits() تقطع a إلى رقم مكون من n بت ("a&=~((~0)<<n)"). يحدث خطأ إذا كان n سالبًا. يتم أيضًا إرجاع خطأ إذا كان التمثيل الداخلي لـ a أقصر بالفعل من n بت. يعتمد التمثيل الداخلي على حجم الكلمة الخاص بالمنصة، ويمكن تجاهل هذا الخطأ بأمان. استخدم BN_num_bits(3) لتحديد العدد الدقيق للبتات إذا لزم الأمر.

BN_lshift() تزحف a إلى اليسار بمقدار n بت وتضع النتيجة في r ("r=a*2^n"). لاحظ أن n يجب أن يكون غير سالب. BN_lshift1() تزحف a إلى اليسار بمقدار واحد وتضع النتيجة في r ("r=2*a").

BN_rshift() تزحف a إلى اليمين بمقدار n بت وتضع النتيجة في r ("r=a/2^n"). لاحظ أن n يجب أن يكون غير سالب. BN_rshift1() تزحف a إلى اليمين بمقدار واحد وتضع النتيجة في r ("r=a/2").

بالنسبة لوظائف الإزاحة، يمكن أن يكون r و a نفس المتغير.

قيم الإرجاع

BN_is_bit_set() ترجع 1 إذا كان البت مضبوطًا، و 0 بخلاف ذلك.

جميع الوظائف الأخرى ترجع 1 للنجاح، و 0 عند حدوث خطأ. يمكن الحصول على رموز الأخطاء بواسطة ERR_get_error(3).
