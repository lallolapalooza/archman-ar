bpftool-perf(8)

الحزمة: bpf

التراخيص: GPL-2.0-only

BPFTOOL-PERF(8) دليل مدير النظام BPFTOOL-PERF(8)

الاسم

bpftool-perf - أداة لفحص المرفقات المتعلقة بـ perf BPF

الملخص

bpftool [خيارات] perf أمر

خيارات := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

أوامر := { show | list | help }

أوامر PERF

bpftool perf { show | list }
bpftool perf help

الوصف

bpftool perf { show | list }
يسرد جميع مرفقات raw_tracepoint، tracepoint، kprobe في النظام.

سيبدأ الإخراج بمعرف العملية (pid) وموصّف الملف (fd) في تلك العملية، متبوعًا بمعرف برنامج bpf، ومعلومات المرفق، ونقطة المرفق. نقطة المرفق لـ raw_tracepoint/tracepoint هي اسم مسبار التتبع (probe). نقطة المرفق لـ k[ret]probe هي اسم الرمز (symbol) والإزاحة (offset)، أو عنوان ظاهري للنواة (kernel virtual address). نقطة المرفق لـ u[ret]probe هي اسم الملف وإزاحة الملف.

bpftool perf help
طباعة رسالة مساعدة مختصرة.

الخيارات

-h, --help
طباعة رسالة مساعدة مختصرة (مشابهة لـ bpftool help).
-V, --version
طباعة رقم إصدار bpftool (مشابه لـ bpftool version)، ورقم إصدار libbpf المستخدم، والميزات الاختيارية التي تم تضمينها عند تجميع bpftool. تشمل الميزات الاختيارية الربط مع LLVM أو libbfd لتوفير المترجم (disassembler) للبرامج المترجمة بـ JIT (bpftool prog dump jited) واستخدام هياكل BPF (BPF skeletons) (بعض الميزات مثل bpftool prog profile أو عرض معرفات العمليات (pids) المرتبطة بكائنات BPF قد تعتمد عليها).
-j, --json
توليد مخرجات JSON. بالنسبة للأوامر التي لا يمكنها إنتاج JSON، هذا الخيار ليس له تأثير.
-p, --pretty
توليد مخرجات JSON قابلة للقراءة للبشر. يعني ضمنيًا -j.
-d, --debug
طباعة جميع السجلات المتاحة، حتى معلومات مستوى التصحيح (debug). يشمل هذا السجلات من libbpf وكذلك من المدقق (verifier)، عند محاولة تحميل البرامج.
