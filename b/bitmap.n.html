bitmap(n)

الحزمة: tk

bitmap(n) أوامر Tk المدمجة bitmap(n)

الاسم

bitmap - صور تعرض لونين

ملخص

image create bitmap ?name? ?options?
imageName cget option
imageName configure ?option? ?value option value ...?

الوصف

صورة نقطية هي صورة يمكن أن تعرض بكسلاتها لونين أو تكون شفافة. يتم تعريف الصورة النقطية بأربعة أشياء: لون خلفية، ولون مقدمة، وصورتين نقطيتين، تسمى المصدر و القناع. تحدد كل صورة نقطية قيم 0/1 لمصفوفة مستطيلة من البكسلات، ويجب أن يكون للصورتين النقطيتين نفس الأبعاد. بالنسبة للبكسلات التي يكون فيها القناع صفرًا، لا تعرض الصورة شيئًا، مما ينتج عنه تأثير شفاف. بالنسبة للبكسلات الأخرى، تعرض الصورة لون المقدمة إذا كانت بيانات المصدر واحدًا ولون الخلفية إذا كانت بيانات المصدر صفرًا.

إنشاء صور نقطية

مثل جميع الصور، يتم إنشاء الصور النقطية باستخدام الأمر image create. تدعم الصور النقطية خيارات (options) التالية:

-background color
يحدد لون خلفية للصورة بأي من الطرق القياسية التي تقبلها Tk. إذا تم تعيين هذا الخيار إلى سلسلة فارغة، فستكون بكسلات الخلفية شفافة. يتم تحقيق هذا التأثير باستخدام الصورة النقطية المصدر كصورة نقطية للقناع، وتجاهل أي خيارات -maskdata أو -maskfile.
-data string
يحدد محتويات الصورة النقطية المصدر كسلسلة. يجب أن تلتزم السلسلة بتنسيق X11 bitmap (على سبيل المثال، كما تم إنشاؤها بواسطة برنامج bitmap). إذا تم تحديد كل من الخيارين -data و -file، فإن الخيار -data له الأسبقية.
-file name
name يعطي اسم ملف محتوياته تحدد الصورة النقطية المصدر. يجب أن يلتزم الملف بتنسيق X11 bitmap (على سبيل المثال، كما تم إنشاؤها بواسطة برنامج bitmap).
-foreground color
يحدد لون مقدمة للصورة بأي من الطرق القياسية التي تقبلها Tk.
-maskdata string
يحدد محتويات القناع كسلسلة. يجب أن تلتزم السلسلة بتنسيق X11 bitmap (على سبيل المثال، كما تم إنشاؤها بواسطة برنامج bitmap). إذا تم تحديد كل من الخيارين -maskdata و -maskfile، فإن الخيار -maskdata له الأسبقية.
-maskfile name
name يعطي اسم ملف محتوياته تحدد القناع. يجب أن يلتزم الملف بتنسيق X11 bitmap (على سبيل المثال، كما تم إنشاؤها بواسطة برنامج bitmap).

أمر الصورة

عند إنشاء صورة نقطية، تنشئ Tk أيضًا أمرًا جديدًا اسمه هو نفس اسم الصورة. يمكن استخدام هذا الأمر لاستدعاء عمليات مختلفة على الصورة. له الشكل العام التالي:

imageName option ?arg arg ...?
يحدد Option و args السلوك الدقيق للأمر. الأوامر التالية ممكنة للصور النقطية:
imageName cget option
يعيد القيمة الحالية للخيار التكويني المحدد بواسطة option. قد يأخذ Option أيًا من القيم التي يقبلها أمر image create bitmap.
imageName configure ?option? ?value option value ...?
استعلم أو عدّل خيارات التكوين للصورة. إذا لم يتم تحديد option، فإنه يعيد قائمة تصف جميع الخيارات المتاحة لـ imageName (انظر Tk_ConfigureInfo لمعلومات حول تنسيق هذه القائمة). إذا تم تحديد option بدون value، فإن الأمر يعيد قائمة تصف الخيار المسمى واحدًا (ستكون هذه القائمة متطابقة مع القائمة الفرعية المقابلة للقيمة التي تم إرجاعها إذا لم يتم تحديد option). إذا تم تحديد زوج واحد أو أكثر من option-value، فإن الأمر يعدّل الخيار (الخيارات) المحدد ليكون له القيمة (القيم) المعطاة؛ في هذه الحالة، يعيد الأمر سلسلة فارغة. قد يأخذ Option أيًا من القيم التي يقبلها أمر image create bitmap.
