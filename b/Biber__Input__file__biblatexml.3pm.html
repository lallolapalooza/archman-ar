Biber__Input__file__biblatexml(3pm)

الحزمة: biber

التراخيص: Artistic-2.0

Biber::Input::file::biblatexml(3pm) توثيق بيرل المساهم من قبل المستخدم Biber::Input::file::biblatexml(3pm)

extract_entries

الروتين الرئيسي لاستخلاص البيانات.
يقبل معرّف مصدر البيانات (ملف في هذه الحالة)،
يعالج الملف مسبقاً ثم يبحث عن المفاتيح الممررة،
وينشئ إدخالات عند العثور عليها ويمرر مصفوفة بالمفاتيح التي لم يتم العثور عليها.

create_entry

ينشئ كائن Biber::Entry من إدخال تم العثور عليه في مصدر بيانات biblatexml

parsename

بالنظر إلى عقدة اسم، هذه الدالة تعيد كائن Biber::Entry::Name
تعيد كائناً يبدو داخلياً كالتالي:
{ given             => {string => 'John', initial => ['J']},
  family            => {string => 'Doe', initial => ['D']},
  middle            => {string => 'Fred', initial => ['F']},
  prefix            => {string => undef, initial => undef},
  suffix            => {string => undef, initial => undef},
  basenamestring    => 'Doe',
  namestring        => 'Doe, John Fred',
  nameinitstring    => 'Doe_JF',
  gender            => sm,
  useprefix         => 1,
  hashid            => 'someid',
  sortingnamekeytemplatename => 'templatename'
}

الاسم

Biber::Input::file::biblatexml - يبحث في ملف BibLaTeXML عن إدخال وينشئه إذا تم العثور عليه

الوصف

يوفر الطريقة extract_entries() للحصول على إدخالات من مصدر بيانات biblatexml وتثبيت كائنات Biber::Entry لما يتم العثور عليه.
