Biber__Input__file__bibtex(3pm)

الحزمة: biber

التراخيص: Artistic-2.0

Biber::Input::file::bibtex(3pm) وثائق مساهمة من مستخدمي Perl Biber::Input::file::bibtex(3pm)

init_cache

إبطال صلاحية ذاكرة التخزين المؤقت لكائن T::B. تستخدم فقط في الاختبارات عندما، على سبيل المثال، نغير إعدادات الترميز وبالتالي يجب فرض إعادة قراءة البيانات

TBSIG

معالج إشارة لالتقاط أخطاء Text::BibTex SEGFAULTS الفادحة. لديها أخطاء ونريد أن نقول شيئًا على الأقل إذا تعطلت

extract_entries

الروتين الرئيسي لاستخلاص البيانات.
يقبل معرف مصدر البيانات، يعالج الملف مسبقًا ثم
يبحث عن المفاتيح المقدمة، وينشئ إدخالات عندما يجدها ويمرر مصفوفة بالمفاتيح التي لم يعثر عليها.

create_entry

إنشاء كائن Biber::Entry من كائن Text::BibTeX
كن حذرًا هنا، جميع طرق التعيين الخاصة بـ T::B هي حدود UTF-8/NFC
لذا كن حذرًا في تشفير (NFC()) عند الاستدعاءات. لن تتعامل Windows مع UTF-8
في T::B btparse بشكل جيد وستنهار.

cache_data

يخزن بيانات الملف مؤقتًا في كائنات T::B مفهرسة بواسطة
مفتاح المصدر الأصلي، مشفرة إلى UTF8

preprocess_file

تحويل الملف إلى UTF-8 وربما فك تشفير ماكرو LaTeX إلى UTF-8

parse_decode

تحليل جزئي لمصدر .bib وفك تشفير بيانات LaTeX للمحتويات.
نقوم بذلك لأن فك تشفير LaTeX للمخزن المؤقت بأكمله أمر صعب نظرًا لأن هذا الفك يعتمد على التعبيرات النمطية وبسبب استخدام الأقواس لحماية البيانات في
ملفات .bib، يصبح من الصعب إجراء بعض التحليل.

parsename

بإعطائه سلسلة اسم، تعيد هذه الوظيفة كائن Biber::Entry::Name
مع جميع أجزاء الاسم محلولة وفقًا لاتفاقيات BibTeX.
parsename('John Doe', 'author', 'key')
يعيد كائنًا يبدو داخليًا شيئًا كهذا:
{ given          => {string => 'John', initial => ['J']},
  family         => {string => 'Doe', initial => ['D']},
  prefix         => {string => undef, initial => undef},
  suffix         => {string => undef, initial => undef},
  id             => 32RS0Wuj0P,
  strip          => {'given'  => 0,
                     'family' => 0,
                     'prefix' => 0,
                     'suffix' => 0}
  }

parsename_x

بإعطائه سلسلة اسم بالتنسيق الموسع، تعيد هذه الوظيفة كائن Biber::Entry::Name
مع جميع أجزاء الاسم محلولة وفقًا لاتفاقيات BibTeX.
parsename_x('given=John, family=Doe')
يعيد كائنًا يبدو داخليًا شيئًا كهذا:
{ given          => {string => 'John', initial => ['J']},
  family         => {string => 'Doe', initial => ['D']},
  prefix         => {string => undef, initial => undef},
  suffix         => {string => undef, initial => undef},
  id             => 32RS0Wuj0P,
  hashid         => 'someid',
  sortingnamekeytemplatename => 'template name',
}

الاسم

Biber::Input::file::bibtex - البحث في ملف BibTeX عن إدخال وإنشائه إذا تم العثور عليه

الوصف

يوفر طريقة extract_entries() للحصول على الإدخالات من مصدر بيانات BibTeX وإنشاء كائنات Biber::Entry لما يجده

المؤلف

فيليب كيم "<philip at kime.org.uk>"
