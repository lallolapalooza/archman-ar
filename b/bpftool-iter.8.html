BPFTOOL-ITER(8) دليل مدير النظام BPFTOOL-ITER(8)

الاسم

bpftool-iter - أداة لإنشاء مكررات BPF

ملخص

bpftool [خيارات] iter أمر

خيارات := { { -j | --json } [{ -p | --pretty }] | { -d | --debug } }

أوامر := { pin | help }

أوامر المكررات

bpftool iter pin OBJ PATH [map MAP]
bpftool iter help
OBJ := /a/file/of/bpf_iter_target.o
MAP := { id MAP_ID | pinned FILE }

الوصف

bpftool iter pin OBJ PATH [map MAP]
يجمع مكرر bpf بين تكرار نواة لبيانات نواة معينة (مثل المهام، خرائط bpf، إلخ) وبرنامج bpf يتم استدعاؤه لكل كائن بيانات نواة (مثل مهمة واحدة، خريطة bpf واحدة، إلخ). يمكن لمساحة المستخدم قراءة مخرجات مكرر النواة من خلال استدعاء النظام read().

يقوم الأمر pin بإنشاء مكرر bpf من OBJ، ويثبته في PATH. يجب أن يكون PATH موجودًا في وحدة تحميل bpffs. يجب ألا يحتوي على حرف نقطة ('.')، المحجوز للتوسعات المستقبلية لـ bpffs.

يتطلب مكرر عناصر الخريطة bpf معلمة إضافية MAP حتى يتمكن برنامج bpf من التكرار فوق عناصر الخريطة لتلك الخريطة. يمكن أن يكون لديك برنامج bpf في النواة ليعمل مع كل عنصر خريطة، ويقوم بالتحقق، والتصفية، والتجميع، وما إلى ذلك، دون نسخ البيانات إلى مساحة المستخدم.

يمكن للمستخدم بعد ذلك cat PATH لرؤية مخرجات مكرر bpf.

bpftool iter help
طباعة رسالة مساعدة موجزة.

خيارات

-h, --help
طباعة رسالة مساعدة موجزة (مشابهة لـ bpftool help).
-V, --version
طباعة رقم إصدار bpftool (مشابهة لـ bpftool version)، ورقم إصدار libbpf المستخدم، والميزات الاختيارية التي تم تضمينها عند تجميع bpftool. تشمل الميزات الاختيارية الربط مع LLVM أو libbfd لتوفير برنامج فك التجميع للبرامج المترجمة في الوقت المناسب (JIT) (bpftool prog dump jited) واستخدام هياكل BPF (بعض الميزات مثل bpftool prog profile أو عرض pids المرتبطة بكائنات BPF قد تعتمد عليها).
-j, --json
إنشاء مخرجات JSON. بالنسبة للأوامر التي لا يمكنها إنتاج JSON، لا يكون لهذا الخيار أي تأثير.
-p, --pretty
إنشاء مخرجات JSON قابلة للقراءة للبشر. تتضمن -j.
-d, --debug
طباعة جميع السجلات المتاحة، حتى معلومات مستوى التصحيح. يشمل ذلك السجلات من libbpf وكذلك من المدقق، عند محاولة تحميل البرامج.

أمثلة

# bpftool iter pin bpf_iter_netlink.o /sys/fs/bpf/my_netlink

إنشاء مكرر bpf قائم على الملف من bpf_iter_netlink.o وتثبيته
في /sys/fs/bpf/my_netlink

# bpftool iter pin bpf_iter_hashmap.o /sys/fs/bpf/my_hashmap map id 20

إنشاء مكرر bpf قائم على الملف من bpf_iter_hashmap.o وخريطة ذات
معرف 20، وتثبيته في /sys/fs/bpf/my_hashmap
