mtx-interface(1) أدوات متعلقة بواجهة ConTeXt mtx-interface(1)

الاسم


mtx-interface - أدوات متعلقة بواجهة ConTeXt

الخلاصة

mtxrun --script interface [ خيارات ... ] [ أسماء الملفات ]

الوصف

أدوات متعلقة بواجهة ConTeXt

الخيارات

--scite
توليد واجهة scite
--bbedit
توليد ملفات واجهة bbedit
--jedit
توليد ملفات واجهة jedit
--textpad
توليد ملفات واجهة textpad
--vim
توليد ملفات واجهة vim
--text
إنشاء ملفات نصية للأوامر والبيئات
--raw
الإبلاغ عن الأوامر إلى وحدة التحكم
--check
توليد ملف تدقيق
--meaning
الإبلاغ عن معنى الأوامر
--tokens
عرض التمثيل الداخلي للأوامر
--toutf
استبدال الأحرف المسماة بـ utf
--preprocess
معالجة مسبقة لملفات mkvi إلى ملفات tex [فرض، لاحقة]
--suffix
استخدام اللاحقة المعطاة لملفات الإخراج
--force
فرض الإجراء حتى عند الشك
--pattern
نمط لعمليات البحث عن المعنى

المؤلف

يمكن العثور على مزيد من المعلومات حول ConTeXt والأدوات التي تأتي معه على:

قائمة بريدية: ntg-context@ntg.nl / http://www.ntg.nl/mailman/listinfo/ntg-context

صفحة الويب: http://www.pragma-ade.nl / http://tex.aanhet.net

ويكي: http://contextgarden.net
