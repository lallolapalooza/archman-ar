الحزمة: texlive-doc

mtx-pdf(1) أدوات مساعدة ConTeXt PDF mtx-pdf(1)

الاسم


mtx-pdf - أدوات مساعدة ConTeXt PDF

الملخص

mtxrun --script pdf [ خيارات ... ] [ أسماء الملفات ]

الوصف

أدوات مساعدة ConTeXt PDF

الخيارات

--info
عرض بعض المعلومات حول الملف المحدد
--metadata
عرض كتلة XML للبيانات الوصفية
--formdata
عرض بيانات النموذج
--pretty
استبدال الأسطر الجديدة في البيانات الوصفية
--fonts
عرض الخطوط المستخدمة (--detail)
--object
عرض الكائن
--links
عرض الروابط
--highlights
عرض التمييزات
--comments
عرض التعليقات
--sign
توقيع المستند (يفترض وجود قالب توقيع)
--verify
التحقق من المستند
--detail
طباعة التفاصيل على الوحدة الطرفية
--userdata
طباعة بيانات المستخدم على الوحدة الطرفية

المؤلف

يمكن العثور على مزيد من المعلومات حول ConTeXt والأدوات التي تأتي معه على:

قائمة بريدية: ntg-context@ntg.nl / http://www.ntg.nl/mailman/listinfo/ntg-context

صفحة الويب: http://www.pragma-ade.nl / http://tex.aanhet.net

ويكي: http://contextgarden.net
