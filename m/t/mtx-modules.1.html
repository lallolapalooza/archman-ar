mtx-modules(1) مولدات وثائق وحدات ConTeXt mtx-modules(1)

الاسم


mtx-modules - مولدات وثائق وحدات ConTeXt

الموجز

mtxrun --script modules [ خيارات ... ] [ أسماء الملفات ]

الوصف

مولدات وثائق وحدات ConTeXt

الخيارات

--convert
تحويل الملفات المصدرية (tex, mkii, mkiv, mp, إلخ) إلى ملفات 'ted'
--process
معالجة الملفات المصدرية (tex, mkii, mkiv, mp, إلخ) إلى ملفات 'pdf'
--prep
استخدام الاسم الأصلي مع إضافة اللاحقة 'prep'
--direct
استخدام الطريقة القديمة بدلاً من الإضافية

المؤلف

يمكن العثور على مزيد من المعلومات حول ConTeXt والأدوات التي تأتي معه على:

قائمة البريد: ntg-context@ntg.nl / http://www.ntg.nl/mailman/listinfo/ntg-context

صفحة الويب: http://www.pragma-ade.nl / http://tex.aanhet.net

ويكي: http://contextgarden.net
