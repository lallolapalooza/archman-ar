NAME

mutool - أداة لجميع الأغراض للتعامل مع ملفات PDF

SYNOPSIS

mutool <sub-command> [options]

VERSION

mutool -v

يعرض إصدار MuPDF المستخدم لبناء mutool.

DESCRIPTION

mutool هي أداة تعتمد على MuPDF للتعامل مع ملفات المستندات بطرق مختلفة. هناك العديد من الأوامر الفرعية المتاحة، كما هو موضح أدناه.

DRAW

mutool draw [options] file [pages]

سيقوم الأمر draw بإنشاء مستند إلى ملفات صور، أو تحويله إلى تنسيق متجه آخر، أو استخراج محتوى النص.

تنسيقات المستندات المدعومة هي: pdf, xps, cbz, و epub.

تنسيقات الصور الناتجة المدعومة هي: pbm, pgm, ppm, pam, png, pwg, pcl, و ps. تنسيقات المتجهات الناتجة المدعومة هي: svg, pdf, وتتبع التصحيح (مثل xml). تنسيقات النص الناتجة المدعومة هي: نص عادي، html، ونص منظم (مثل xml).

-p password
استخدم كلمة المرور المحددة إذا كان الملف مشفرًا.
-o output
يتم استنتاج تنسيق الإخراج من اسم ملف الإخراج. قم بتضمين %d في الاسم لتحديد رقم الصفحة (على سبيل المثال: "page%d.png"). يتم دعم معدلات printf، على سبيل المثال "%03d". إذا لم يتم تحديد إخراج، فسيتم إرسال الإخراج إلى stdout.
-F format
فرض تنسيق إخراج معين. ضروري فقط عند الإخراج إلى stdout نظرًا لأنه يتم عادةً استخدام اسم ملف الإخراج لاستنتاج تنسيق الإخراج.
-q
كن هادئًا، لا تطبع رسائل التقدم.
-R angle
قم بالتدوير في اتجاه عقارب الساعة بعدد الدرجات المحدد.
-r resolution
قم بإنشاء الصفحة بالدقة المحددة. الدقة الافتراضية هي 72 نقطة في البوصة.
-w width
قم بإنشاء الصفحة بالعرض المحدد (أو، إذا تم استخدام العلامة -r، قم بالإنشاء بحد أقصى للعرض).
-h height
قم بإنشاء الصفحة بالارتفاع المحدد (أو، إذا تم استخدام العلامة -r، قم بالإنشاء بحد أقصى للارتفاع).
-f
قم بالملاءمة بالضبط؛ تجاهل نسبة العرض إلى الارتفاع عند مطابقة العرض/الارتفاع المحدد.
-b box
استخدم صندوق الصفحة المحدد (`MediaBox`، `CropBox`، `BleedBox`، `TrimBox`، أو `ArtBox`)، انظر :ref:`defined boxes<mutool_trim_defined_boxes>`.
-B bandheight
قم بالإنشاء في وضع النطاقات مع عدم تجاوز عرض كل نطاق للارتفاع المحدد. هذا يستخدم ذاكرة أقل أثناء الإنشاء. متوافق فقط مع تنسيقات الإخراج pam، pgm، ppm، pnm، و png. لا يمكن استخدام إنشاء النطاقات والتحقق من صحة md5 في نفس الوقت.
-T threads
عدد الخيوط المستخدمة للإنشاء (وضع النطاقات فقط).
-W width
عرض الصفحة بالنقاط لتخطيط EPUB.
-H height
ارتفاع الصفحة بالنقاط لتخطيط EPUB.
-S size
حجم الخط بالنقاط لتخطيط EPUB.
-U filename
ملف ورقة أنماط CSS للمستخدم لتخطيط EPUB.
-X
تعطيل أنماط المستند لتخطيط EPUB.
-a
تعطيل استخدام ملف المعجل.
-c colorspace
قم بالإنشاء في مساحة الألوان المحددة. مساحات الألوان المدعومة هي: mono، gray، grayalpha، rgb، rgbalpha، cmyk، cmykalpha. بعض الاختصارات مسموحة: m، g، ga، rgba، cmyka. يتم اختيار الافتراضي بناءً على تنسيق الإخراج.
-e filename
اسم ملف ملف تعريف ICC لإثبات الألوان المراد استخدامه للإنشاء.
-G gamma
تطبيق تصحيح جاما. بعض القيم النموذجية هي 0.7 أو 1.4 لتمثيل النص الرفيع أو الداكن.
-I
عكس الألوان.
-s [mft5]
إظهار أجزاء مختلفة من المعلومات: m لذاكرة ذاكرة التخزين المؤقت للرموز والذاكرة الإجمالية، f لميزات الصفحة مثل ما إذا كانت الصفحة رمادية أو ملونة، t لأوقات إنشاء كل صفحة بالإضافة إلى الإحصائيات، و 5 لملفات التدقيق md5 للصور المنشأة التي يمكن استخدامها للتحقق مما إذا كان الإنشاء قد تغير.
-A bits
حدد عدد بتات التنعيم المستخدمة. الافتراضي هو 8.
-A bits/bits
حدد عدد بتات التنعيم المستخدمة. الافتراضي هو 8. البتات للرسومات قبل الشرطة المائلة، البتات للنص بعد الشرطة المائلة.
-l width
الحد الأدنى لعرض الخط المرسوم (بالبكسل).
-K
لا تقم بإنشاء النص.
-KK
قم بإنشاء النص فقط.
-D
تعطيل استخدام قوائم العرض. قد يتسبب في تباطؤ، ولكنه يجب أن يقلل من كمية الذاكرة المستخدمة.
-i
تجاهل الأخطاء.
-m limit
الحد من استخدام الذاكرة بالبايت.
-L
وضع الذاكرة المنخفضة (تجنب تخزين الكائنات مؤقتًا عن طريق مسح الذاكرة المؤقتة بعد كل صفحة).
-P
قم بتشغيل التفسير والإنشاء في نفس الوقت.
-N
تعطيل سير عمل ICC.
-O overprint
التحكم في إنشاء الألوان الموضعية/الطباعة الزائدة: 0 لعدم إنشاء الألوان الموضعية، 1 لمحاكاة الطباعة الزائدة (افتراضي)، أو 2 لإنشاء كامل للألوان الموضعية.
-t language
حدد اللغة/الخط للتعرف الضوئي على الحروف (افتراضي: eng)
-d ocr-file-path
حدد المسار لملفات التعرف الضوئي على الحروف (افتراضي: الاعتماد على متغير البيئة TESSDATA_PREFIX.
-k correction
اضبط تصحيح الميل، إما auto، 0 لزيادة الحجم، 1 للحفاظ على الحجم، أو 2 لتقليل الحجم.
-k correction,angle
اضبط تصحيح الميل وكذلك الزاوية.
-y l
اطبع تكوينات الطبقة إلى stderr.
-y layer-number
حدد تكوين الطبقة (بالرقم من -y l).
-y layer-number,item1,item2,...
حدد تكوين الطبقة (بالرقم من -y l) وقم بتبديل العناصر المدرجة.
-Y
اطبع الطبقات الفردية إلى stderr.
-z layer-number
إخفاء طبقة فردية.
-Z layer-number
إظهار طبقة فردية.
pages
قائمة مفصولة بفواصل لأرقام الصفحات والنطاقات (على سبيل المثال: 1,5,10-15,20-N)، حيث يمثل الحرف N الصفحة الأخيرة. إذا لم يتم تحديد صفحات، فسيتم إنشاء جميع الصفحات.

CLEAN

mutool clean [options] input.pdf [output.pdf] [pages]

يقوم الأمر clean بإعادة تنسيق وكتابة بناء جملة ملف PDF. يمكن استخدامه لإصلاح الملفات التالفة، وتوسيع التدفقات المضغوطة، وتصفية نطاق من الصفحات، وما إلى ذلك.

إذا لم يتم تحديد ملف إخراج، فسيتم كتابة ملف PDF المنظف إلى "out.pdf" في الدليل الحالي.

-p password
استخدم كلمة المرور المحددة إذا كان الملف مشفرًا.
-g
جمع البيانات المهملة للكائنات التي ليس لها مراجع من كائنات أخرى. قم بتوفير الخيار مرتين لإعادة ترقيم جميع الكائنات وضغط جدول المراجع المتقاطع. قم بتوفيره ثلاث مرات لدمج وإعادة استخدام الكائنات المكررة. قم بتوفيره أربع مرات لدمج وإعادة استخدام التدفقات المكررة.
-s
إعادة كتابة تدفقات المحتوى.
-l
اجعل الإخراج خطيًا. لم يعد مدعومًا

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

mutool

mutool - an application for manipulating MuPDF files

SYNOPSIS

mutool clean [options] input.pdf [output.pdf]
mutool poster [options] input.pdf [output.pdf]
mutool banner [options] input.pdf [output.pdf]
mutool cat file.txt pages
mutool grep [options] file [object ...]
mutool run script.js [arguments]
mutool convert [options] file [pages]
mutool merge [options] file1 [pages] file2 [pages] ...
mutool bake [options] input.pdf [output.pdf]
mutool recolor [options] input.pdf
mutool trace [options] file1 [pages] file2 [pages] ...
mutool trim [options] input.pdf
mutool sign [options] input.pdf [signature object number]
mutool audit [options] file1.pdf file2.pdf ...

DESCRIPTION

The mutool command is a collection of utilities for manipulating MuPDF files. It provides subcommands for cleaning, converting, merging, baking, recoloring, tracing, trimming, signing, and auditing PDF files, as well as running Javascript scripts and extracting text.

COMMANDS

clean
Make a clean copy of a PDF file. This utility rebuilds the PDF file from scratch, which can be used to repair corrupted files, remove redundant data, and optimize the file structure.
poster
Create a poster from each page of a PDF file. Each page is divided into tiles, and each tile is saved as a separate PDF file.
banner
Create a banner from each page of a PDF file. Each page is divided into tiles, and each tile is saved as a separate PDF file.
cat
Concatenate text files and pages from PDF files. This is useful for extracting text from PDF documents and combining it with other text files.
grep
Print all the objects in the file in a compact one-line format suitable for piping to grep.
outline
Print the outline (table of contents).

RUN

mutool run script.js [arguments]

Executes a Javascript program which has access to most of the features of the MuPDF library. The command supports ECMAScript 5 syntax in strict mode. All of the MuPDF constructors and function live in the global object, and the command line arguments are accessible from the global argv object.

If invoke without any arguments, it will drop you into an interactive REPL (read-eval-print-loop). On the interactive prompt, if you prefix a line with an equal character it will automatically print the results of the line.

See the MuPDF documentation for details about the Javascript interfaces.

CONVERT

mutool convert [options] file [pages]

The convert command is used to convert a file from one format to another.

-p password
Use the specified password if the file is encrypted.
-b box
Use name page box (`MediaBox`, `CropBox`, `BleedBox`, `TrimBox`, or `ArtBox`), see :ref:`defined boxes<mutool_trim_defined_boxes>`.
-A bits
Specify how many bits of anti-aliasing to use. The default is 8.
-W width
Page width in points for EPUB layout.
-H height
Page height in points for EPUB layout.
-S size
Font size in points for EPUB layout.
-U filename
User CSS stylesheet for EPUB layout.
-o output
The output format is inferred from the output filename. Embed %d in the name to indicate the page number (for example: "page%d.png"). Printf modifiers are supported, for example "%03d". If no output is specified, the output will go to stdout.
-F format
Enforce a specific output format. Only necessary when outputting to stdout since normally the output filename is used to infer the output format.
-O options
Comma separated list of format specific output options, see OUTPUT OPTIONS below.

MERGE

mutool merge [options] file1 [pages] file2 [pages] ...

The merge command is used to pick out pages from two or more files and merge them in order into a new PDF output file.

-o output
The output filename.
-O options
Comma separated list of format specific output options, see OUTPUT OPTIONS below.

BAKE

mutool bake [options] input.pdf [output.pdf]

Normally annotations and form field widgets are separate content streams that get drawn on top of the page contents. This command bakes annotations and/or widgets into the page contents, making them inseparable. After baking in annotations and widgets they are just visual representaitons of what the original annotation/widget looked like, their properties can no longer be edited since they no longer exist as proper annotation/widgets.

-A
Do not bake in annotations.
-F
Do not bake in form field widgets.
-O options
A comma separated list of PDF options. See OUTPUT OPTIONS below.

RECOLOR

mutool recolor [options] input.pdf

Change the color space used in a PDF to a desired one. This command can, for example, change a color PDF to be grayscale.

-c colorspace
Desired output colorspace, choose one of gray (default), rgb, or cmyk.
-r
Remove any output intents.
-o filename
The output filename.

TRACE

mutool trace [options] file1 [pages] file2 [pages] ...

Prints a trace of device calls needed to render the desired pages from the given document.

-p password
Use the specified password if the file is encrypted.
-W width
Page width in points for EPUB layout.
-H height
Page height in points for EPUB layout.
-S size
Font size in points for EPUB layout.
-U filename
User CSS stylesheet for EPUB layout.
-X
Disable document styles for EPUB layout.
-d
Enable use of display lists. pages Comma separated list of page numbers and ranges (for example: 1,5,10-15,20-N), where the character N denotes the last page. If no pages are specified, then all pages will be rendered.

TRIM

mutool trim [options] input.pdf

Makes a modified version of a PDF with content that falls inside (or outside) of the given box removed.

-b box
Which box to trim to, either one of: MediaBox (default) CropBox BleedBox TrimBox, or ArtBox.
-f
Fallback to mediabox if specified box not available.
-m all
Add same margins to all sides of the box, where all is positive for inwards, negative for outwards.
-m vertical,horizontal
Add specific margins for vertical and horizontal sides of the box, where vertical and horizonal are positive for inwards, negative for outwards.
-m top,right,bottom,left
Add specific margins for top, right, bottom and left sides of the box, where top, right, bottom, and left each are positive for inwards, negative for outwards.
-e
Exclude contents of box rather than include them.
-o filename
The output filename.

SIGN

mutool sign [options] input.pdf [signature object number]

Reads a PDF file and prints infromation about each signature field object. With suitable options all or specified signatures can be verified, cleared or signed.

-p password
Use the specified password if the file is encrypted.
-v
Verify all signatures, or only the specified signature.
-c
Clear all signatures, or only the specified signature.
-s certificate-filename
Read a certificate from the given filename and use it to sign all, or just the specified signature.
-P certificate-password
Use the specified password when opening the certificate.
-o filename
The output filename. signature object numbers A list of PDF object number for signatures to verify/clear/sign. If no such object numbers are given, all signatures will be processed.

AUDIT

mutool audit [options] file1.pdf file2.pdf ...

Outputs a report of operator and space usage for each given PDF file.

-o filename
The output filename for the report.
