Munin__Common__TLS(3pm)

الحزمة: munin-node

التراخيص: GPL

Munin::Common::TLS(3pm) وثائق Perl المساهمة من المستخدم Munin::Common::TLS(3pm)

الاسم

Munin::Node::TLS - فئة أساسية مجردة تطبق بروتوكول STARTTLS

ملخص

لا ينبغي استدعاؤها مباشرة. انظر الملخص لـ Munin::Common::TLSServer و Munin::Common::TLSClient.

الوظائف

جديد
my $tls = Munin::Common::TLSFoo->new({ # استبدل Foo بـ Client أو Server
    # سمات إلزامية:  
    logger      => \&a_logger_func,
    read_fd     => fileno($socket),
    read_func   => \&a_socket_read_func,
    write_fd    => fileno($socket),
    write_func  => \&a_socket_read_func,
    # سمات اختيارية                          الافتراضيات
    DEBUG              => 0,                       # 0
    tls_ca_cert        => "path/to/ca/cert.pem",   # ''
    tls_cert           => "path/to/cert.pem",      # ''
    tls_paranoia       => 1,                       # 0
    tls_priv           => "path/to/priv_key.pem",  # ''
    tls_vdepth         => 5,                       # 0
    tls_verify         => 1,                       # 0
});

المنشئ. لا ينبغي استدعاؤه مباشرة. هذه الوثائق توضح السمات المشتركة لـ Munin::Common::TLSServer و Munin::Common::TLSClient.

اقرأ
my $msg = $tls->read();

قراءة مشفرة.

اكتب
$tls->write($msg);

كتابة مشفرة.

بدأت_الجلسة
my $bool = $tls->session_started();

تُرجع صحيحًا إذا كان كائن TLS جاهزًا لقراءة/كتابة البيانات المشفرة.
