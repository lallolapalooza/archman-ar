NAME

mupdf-gl

OpenGL—accelerated PDF, XPS, CBZ, EPUB, and FictionBook viewer

SYNOPSIS

mupdf-gl

[ options ] [ mutool-options ] [ file ... ]

DESCRIPTION

mupdf-gl is a fast, lightweight PDF, XPS, CBZ, EPUB, and FictionBook viewer with OpenGL acceleration.

OPTIONS

-L
List available glyph names.
-S
List available shaders.
-a width
Set the initial aspect ratio. The default is 1.0 for fit page, 0.0 for fit width, and 2.0 for fit height.
-c file
Read colors from the specified color map file.
-d
Disable hardware acceleration.
-f
Set fullscreen mode.
-g name
Use the specified glyph name for text search.
-h
Show help message.
-i
Invert colors.
-l file
Load annotations from the specified annotation file.
-m file
Set the current page to the specified page number.
-o file
Save the document to the specified output file.
-p password
Set the document password.
-r resolution
Set the rendering resolution in DPI. The default is 72.
-s shader
Use the specified shader for rendering. See -S to list available shaders.
-t file
Set the document title.
-v
Show version information.
-w width
Set the window width.
-x height
Set the window height.
-y file
Save annotations to the specified annotation file.

MOUSE BEHAVIOR

Right click
Show context menu.
Mouse wheel
Scroll up and down.
