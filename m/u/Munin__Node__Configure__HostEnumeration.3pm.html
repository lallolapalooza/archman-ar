Munin::Node::Configure::HostEnumeration(3pm) توثيق Perl مساهمة المستخدم Munin::Node::Configure::HostEnumeration(3pm)

الاسم

Munin::Node::Configure::HostEnumeration - يأخذ قائمة بالمضيفين، ويعيد عناوين IP المقابلة لهم في صيغة النقطة الرباعية.

الملخص

@hosts = ('switch1', 'host1/24', '10.0.0.60/30');
foreach my $host (expand_hosts(@hosts)) {
    # ...
}

الإجراءات الفرعية

expand_hosts
@expanded = expand_hosts(@list);

تأخذ قائمة بالمضيفين، وتعيد عناوين IP المقابلة لهم في صيغة النقطة الرباعية.

يمكن تحديد العناصر كاسم مضيف أو عنوان IP بنقطة رباعية، مع أو بدون قناع شبكة.

تدعم حاليًا عناوين IPv4 فقط.
