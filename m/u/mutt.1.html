اسم

mutt - وكيل مستخدم البريد Mutt

ملخص

mutt
[-nRyzZ] [-e command] [-F rcfile] [-m type] [-f mailbox]
mutt
[-Enx] [-e command] [-F rcfile] [-H draft] [-i include]
[-b bcc-addr] [-c cc-addr] [-s subject]
[-a file ... --] to-addr ...
mutt
[-nx] [-e command] [-F rcfile] [-b bcc-addr] [-c cc-addr]
[-s subject] [-a file ... --] to-addr ... < message
mutt
[-n] [-e command] [-F rcfile] -p
mutt
[-n] [-e command] [-F rcfile] -A alias
mutt
[-n] [-e command] [-F rcfile] -Q variable
mutt
-v[v]
mutt
-D

الوصف

Mutt هو برنامج صغير ولكنه قوي جداً يعتمد على النص لقراءة وإرسال البريد الإلكتروني على أنظمة التشغيل Unix، بما في ذلك دعم الطرفيات الملونة، MIME، OpenPGP، ووضع الفرز المتسلسل.

ملاحظة: تقدم صفحة الدليل هذه نظرة عامة موجزة على خيارات سطر أوامر التنفيذ mutt. توجد نسخة من الدليل الكامل في /usr/share/doc/mutt، بتنسيق نصي، HTML، و/أو PDF. يرجى الرجوع إلى الدليل لمعرفة كيفية استخدام وتكوين Mutt.

الخيارات

-A alias
يطبع نسخة موسعة من alias المعطاة ويخرج.
-a file ...
إرفاق ملف باستخدام MIME. يجب الفصل بين وسيطات file وto-addr بـ “--”. على سبيل المثال: 


mutt -a image.jpg -- to-addr
mutt -a img.jpg *.png -- to-addr-1 to-addr-2

يجب وضع الخيار -a في نهاية خيارات سطر الأوامر.

-b bcc-addr
تحديد عنوان نسخة كربونية مخفية (BCC).
-c cc-addr
تحديد عنوان نسخة كربونية (CC).
-d level
إذا تم تجميع Mutt مع +DEBUG، يتم تسجيل مخرجات التصحيح في ~/.muttdebug0. يمكن أن يتراوح المستوى من -5 إلى 5 ويؤثر على الإسهاب. قيمة الصفر تعطّل التصحيح. قيمة أقل من الصفر تعطّل تدوير ملف السجل تلقائيًا؛ مستوى السجل هو قيمته المطلقة. يوصى بقيمة 2 (-2) لمعظم التشخيصات.
-D
طباعة قيمة جميع خيارات التكوين إلى المخرج القياسي.
-E
تعديل ملف المسودة المحدد بواسطة -H أو ملف التضمين المحدد بواسطة -i أثناء تأليف الرسالة.
-e command
تحديد أمر تكوين لتشغيله بعد معالجة ملفات التهيئة.
-f mailbox
تحديد صندوق بريد لتحميله.
-F rcfile
استخدام rcfile بدلاً من ملف تكوين المستخدم.
-h
عرض ملخص خيارات موجز والخروج.
-H draft
تحديد ملف مسودة يحتوي على رؤوس وجسم لإرسال رسالة. إذا كانت المسودة “-”، يتم قراءة البيانات من stdin. يُتوقع أن يحتوي ملف المسودة على بريد إلكتروني RFC822 فقط - رؤوس وجسم. على الرغم من أنه ليس ملف mbox، إذا كان سطر "From " الخاص بـ mbox موجودًا، فسيتم تجاهله بصمت. تتم معالجة ملفات المسودة بنفس الطريقة في الوضع التفاعلي والدفعة؛ لا يتم تمريرها دون تغيير. على سبيل المثال، سيتم فك تشفير ملفات المسودة المشفرة.
-i include
تحديد ملف تضمين سيتم إدراجه في جسم الرسالة. يتم تجاهله إذا تم تعيين -H. إذا كان التضمين “-”، يتم قراءة البيانات من stdin.
-m type
تحديد نوع صندوق بريد افتراضي للمجلدات التي تم إنشاؤها حديثًا. يمكن أن يكون أحد الخيارات التالية: mbox، MMDF، MH أو Maildir. انظر أيضًا $mbox_type في الدليل.
-n
لا تقرأ ملف تكوين Muttrc على مستوى النظام.
-p
استئناف رسالة مؤجلة. اخرج فورًا إذا لم تكن هناك رسائل مؤجلة.
-Q variable
استعلام عن متغير تكوين. يتم إجراء الاستعلام بعد تحليل جميع ملفات التكوين، وبعد تنفيذ أي أوامر معطاة في سطر الأوامر.
-R
افتح صندوق بريد في وضع القراءة فقط.
-s subject
تحديد موضوع الرسالة. يجب أن يتم وضعه بين علامتي اقتباس إذا كان يحتوي على مسافات.
-v
عرض رقم إصدار Mutt وتعريفات وقت التجميع.
-vv
عرض معلومات الترخيص وحقوق النشر.
-x
محاكاة وضع تأليف mailx(1).
-y
ابدأ Mutt بقائمة بجميع صناديق البريد المحددة بواسطة أمر تكوين mailboxes.
-z
اخرج فورًا بالرمز 1 إذا كان صندوق البريد المحدد بواسطة -f لا يحتوي على أي رسائل.
-Z
افتح أول صندوق بريد محدد بواسطة أمر تكوين mailboxes يحتوي على بريد جديد. اخرج فورًا بالرمز 1 إذا لم يكن هناك بريد جديد في أي منها.
--
عامل باقي الوسيطات كـ to-addr حتى لو بدأت بشرطة. انظر أيضًا -a أعلاه. يمكن أن يكون To-addr عنوان بريد محلي أو شبكة بالإضافة إلى عنوان URL بصيغة mailto:.

البيئة

EDITOR, VISUAL
يحدد المحرر المستخدم عند تأليف الرسائل. إذا تم تعيين كل من EDITOR و VISUAL، فإن VISUAL له الأسبقية. إذا لم يتم تعيين أي منهما، يكون الافتراضي هو vi(1).
EGDSOCKET, RANDFILE
المسارات المستخدمة لتهيئة مولد الأرقام العشوائية لمكتبة SSL.
EMAIL
عنوان البريد الإلكتروني للمستخدم.
HOME
المسار الكامل للمجلد الرئيسي للمستخدم.
MAIL
المسار الكامل لصندوق بريد المستخدم.
MAILDIR
المسار الكامل لصندوق بريد المستخدم إذا كان MAIL غير معين. يستخدم بشكل شائع عندما يكون صندوق البريد مجلد maildir(5).
MAILCAPS
المسار للبحث عن ملفات mailcap.
MM_NOASK
إذا كان هذا المتغير

NAME

mutt — Mail User Agent (text-based)

SYNOPSIS

mutt [-abdChHjJkKlmNnOopPqQRsS] [-e command] [-F rcfile] [-f mailbox] [-r file] [-t] [-u type] [-B count] [-T type] [-U command] [-v num] [-X file] [~M

DESCRIPTION

mutt is a text-based mail user agent that reads mail from a local mailbox, processes it, and sends mail. It supports the POP3, IMAP, and local mail spool protocols. Mutt supports threading, extensive search and filter capabilities, and multiple mailbox handling.

OPTIONS

The options are:

-a <file>
Attach a file to the message you are composing. This option can be used multiple times.
-b <address>
Set the From: address. Default is taken from the ``from'' variable.
-B <count>
Number of backup files to keep. See also the ``max_backup'' variable.
-c <address>
Add a carbon copy to address. This option can be used multiple times.
-C <file>
Use the specified file as a configuration file instead of the default muttrc. See also the muttrc(5) man page.
-d <file>
Write debugging output to the specified file. If the file already exists, it will be appended to. See also the ``debug_level'' variable.
-e <command>
Execute a mutt command before reading the configuration file.
-f <mailbox>
Read mail from the specified mailbox file. Mutt's default behavior is to read from the user's default mailbox, usually mbox(5) or Maildir. See also the ``folder'' variable.
-F <rcfile>
Use the specified file as a configuration file instead of the default muttrc. See also the muttrc(5) man page.
-h
Print a list of options.
-H <file>
Read message headers from the specified file and use them as the initial context for the mail search.
-j
Junk the current message. Same as the ``j'' command.
-J
Mark the current message as read. Same as the ``J'' command.
-k
Use the given character set for incoming mail. Mutt's default is to try and guess, but this allows you to override it.
-K <type>
Set the Content-Type for incoming mail. Mutt's default is to try and guess, but this allows you to override it.
-l <limit>
Limit the displayed messages to those matching the given limit. The limit syntax is the same as Mutt's search syntax.
-m <mailbox>
Read mail from the specified mailbox file. Same as -f.
-n
Do not read the system-wide muttrc file.
-N
Do not read the user's personal muttrc file.
-O <mailbox>
Set the folder to read mail from. This option can be used multiple times. See also the ``folder'' variable.
-o
Save read messages to a new file instead of appending.
-p
Exit Mutt without saving changes to the mailbox. Similar to quit.
-P <file>
Use the specified file as the PGP public keyring instead of the default. See also the PGPPATH variable.
-q
Quit Mutt without saving changes to the mailbox. Similar to quit.
-Q <mailbox>
Quit Mutt and save changes to the mailbox. This is the default behavior.
-r <file>
Read the given file and use its contents as the message body. Useful for sending pre-written messages.
-R
Read-only mode. Do not allow changes to the mailbox.
-s <subject>
Set the subject of the message you are composing.
-S
Enable the secure-MIME functionality. See also the SMIME_KEY, SMIME_CERT, SMIME_SIGN, and SMIME_ENCRYPT variables.
-t
Read recipient addresses from the message body. This option is useful when sending mail to multiple recipients using the To:, Cc:, and Bcc: headers.
-T <type>
Set the Content-Type for outgoing mail. Mutt's default is to try and guess, but this allows you to override it.
-u <type>
Set the Content-Type for incoming mail. Mutt's default is to try and guess, but this allows you to override it.
-U <command>
Execute a mutt command after reading the configuration file.
-v <num>
Set the initial number of lines to display in the pager. Mutt's default is to use the full screen.
-X <file>
Write the message headers to the specified file. This option is useful for debugging and for creating message archives.
~M
This argument is not a standard command-line option. It is used to indicate that Mutt should process all messages in the current mailbox. This option is typically used in conjunction with other options, such as `-d` for debugging or `-U` for executing a command.

ENVIRONMENT

Mutt checks the following environment variables:

EDITOR
The editor to use when editing mail. If unset, vi(1) is used. See also the editor variable.
MAILCAPS
A colon-separated list of directories to search for mailcap(5) files. If unset, the directories in the user's mailcap directory and system-wide directories are searched. mailcap and mailcap are always used without prompting.
PGPPATH
Directory in which the user's PGP public keyring can be found. When used with the original PGP program, mutt and mutt_pgpring(1) rely on this being set.
REPLYTO
Default Reply-To address.
TMPDIR
Directory in which temporary files are created. If unset, /tmp is used. See also $tmpdir configuration variable.
LC_ALL, LC_CTYPE, LANG
Used to determine charset and locale to use.
TEXTDOMAINDIR
Directory containing translation files. If set, this path overwrite the Mutt installation directory. Used for testing translation changes.

FILES

~/.muttrc
~/.mutt/muttrc
$XDG_CONFIG_HOME/mutt/muttrc
User configuration files.
/etc/mutt/Muttrc or /usr/share/mutt/Muttrc
System-wide configuration file.
/tmp/muttXXXXXX
Temporary files created by Mutt.
~/.muttdebug0
File containing debugging output. Log files are automatically rotated by mutt changing the number at the end. See -d option above.
~/.mailcap
User definition for handling non-text MIME types.
/etc/mutt/mailcap
System definition for handling non-text MIME types.
~/.mime.types
User's personal mapping between MIME types and file extensions.
/etc/mutt/mime.types
System mapping between MIME types and file extensions.
/usr/bin/mutt_dotlock
The privileged dotlocking program.
/usr/share/doc/mutt/manual.txt
The Mutt manual.

BUGS

None. Mutts have fleas, not bugs.

FLEAS

Suspend/resume while editing a file with an external editor does not work under SunOS 4.x if you use the curses lib in /usr/5lib. It does work with the S-Lang library, however.

Resizing the screen while using an external pager causes Mutt to go haywire on some systems.

Suspend/resume does not work under Ultrix.

The help line for the index menu is not updated if you change the bindings for one of the functions listed while Mutt is running.

For a more up-to-date list of bugs, errm, fleas, please visit the mutt project's bug tracking system under https://gitlab.com/muttmua/mutt/issues.
