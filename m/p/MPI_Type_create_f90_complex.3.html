NAME

MPI_Type_create_f90_complex - Creates a Fortran complex datatype

SYNOPSIS

FORTRAN


integer function MPI_Type_create_f90_complex(realtype, kind, newtype)
    integer, intent(in) :: realtype
    integer, intent(in) :: kind
    integer, intent(out) :: newtype
end function MPI_Type_create_f90_complex

INPUT PARAMETERS

realtype

Handle of the basic MPI datatype representing the real type (e.g. MPI_REAL, MPI_REAL4, MPI_REAL8, MPI_REAL16).

kind

The kind type parameter of the Fortran complex type.

OUTPUT PARAMETERS

newtype

Handle of the new complex datatype.

DESCRIPTION

MPI_Type_create_f90_complex creates a new MPI datatype that corresponds to the Fortran 90 COMPLEX type. The first argument, realtype, must be a handle to a basic MPI datatype that corresponds to the real part of the complex type. The second argument, kind, specifies the kind parameter of the Fortran 90 complex type.

For example, if you want to create a complex datatype corresponding to COMPLEX(8), you would call:


MPI_Type_create_f90_complex(MPI_REAL8, 8, newtype)

This will create a new MPI datatype newtype that represents COMPLEX(8).

NOTES

The MPI standard does not mandate a specific mapping between Fortran kinds and MPI types. You may need to consult your compiler's documentation to determine the correct MPI type for a given Fortran kind.

ERRORS

This routine may fail if the new datatype cannot be created. The specific error code returned is MPI_ERR_TYPE.

الاسم

MPI_Type_create_f90_complex - ينشئ نوع بيانات مركب Fortran

الملخص

FORTRAN


integer function MPI_Type_create_f90_complex(realtype, kind, newtype)
    integer, intent(in) :: realtype
    integer, intent(in) :: kind
    integer, intent(out) :: newtype
end function MPI_Type_create_f90_complex

معاملات الإدخال

realtype

مقبض نوع بيانات MPI الأساسي الذي يمثل النوع الحقيقي (مثل MPI_REAL، MPI_REAL4، MPI_REAL8، MPI_REAL16).

kind

معلمة نوع النوع لنوع Fortran المركب.

معاملات الإخراج

newtype

مقبض نوع البيانات المركب الجديد.

الوصف

تقوم MPI_Type_create_f90_complex بإنشاء نوع بيانات MPI جديد يتوافق مع نوع COMPLEX في Fortran 90. يجب أن يكون الوسيط الأول، realtype، مقبضًا لنوع بيانات MPI أساسي يتوافق مع الجزء الحقيقي من النوع المركب. الوسيط الثاني، kind، يحدد معلمة النوع لنوع COMPLEX في Fortran 90.

على سبيل المثال، إذا كنت ترغب في إنشاء نوع بيانات مركب يتوافق مع COMPLEX(8)، يمكنك استدعاء:


MPI_Type_create_f90_complex(MPI_REAL8, 8, newtype)

سيؤدي هذا إلى إنشاء نوع بيانات MPI جديد newtype يمثل COMPLEX(8).

ملاحظات

لا يفرض معيار MPI تعيينًا محددًا بين أنواع Fortran وأنواع MPI. قد تحتاج إلى الرجوع إلى وثائق المترجم الخاص بك لتحديد نوع MPI الصحيح لنوع Fortran معين.

الأخطاء

قد تفشل هذه الروتين إذا لم يكن من الممكن إنشاء نوع البيانات الجديد. رمز الخطأ المحدد الذي يتم إرجاعه هو MPI_ERR_TYPE.
