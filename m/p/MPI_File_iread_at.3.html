MPI_File_iread_at(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_IREAD_AT(3) Open MPI MPI_FILE_IREAD_AT(3)

MPI_File_iread_at — قراءة ملف عند إزاحة محددة بوضوح (غير متزامن، غير جماعي).

صيغة الاستدعاء (SYNTAX)

صيغة C (C Syntax)

#include <mpi.h>
int MPI_File_iread_at(MPI_File fh, MPI_Offset offset,
     void *buf, int count, MPI_Datatype datatype,
     MPI_Request *request)

صيغة Fortran (Fortran Syntax)

USE MPI
! أو الصيغة الأقدم: INCLUDE 'mpif.h'
MPI_FILE_IREAD_AT(FH, OFFSET, BUF, COUNT, DATATYPE, REQUEST, IERROR)
     <type>  BUF(*)
     INTEGER FH, COUNT, DATATYPE, REQUEST, IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   OFFSET

صيغة Fortran 2008 (Fortran 2008 Syntax)

USE mpi_f08
MPI_File_iread_at(fh, offset, buf, count, datatype, request, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: offset
     TYPE(*), DIMENSION(..), ASYNCHRONOUS :: buf
     INTEGER, INTENT(IN) :: count
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     TYPE(MPI_Request), INTENT(OUT) :: request
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معاملات الإدخال (INPUT PARAMETERS)

  • fh: مقبض الملف (File handle).
  • offset: إزاحة الملف (File offset).
  • count: عدد العناصر في المخزن المؤقت (Number of elements in the buffer).
  • datatype: نوع بيانات كل عنصر في المخزن المؤقت (Data type of each buffer element).

معاملات الإخراج (OUTPUT PARAMETERS)

  • buf: العنوان الأولي للمخزن المؤقت (Initial address of the buffer).
  • request: كائن الطلب (Request object).
  • ierror: Fortran فقط: حالة الخطأ (Fortran only: Error status).

الوصف (DESCRIPTION)

MPI_File_iread_at هي النسخة غير المتزامنة من MPI_File_read_at.

MPI_File_iread_at هي روتينية غير متزامنة تحاول القراءة من الملف المرتبط بـ fh عند الموضع offset، عدد إجمالي count من عناصر البيانات من نوع datatype إلى المخزن المؤقت للمستخدم buf. الإزاحة offset تكون بوحدات etype بالنسبة للعرض الحالي. أي، لا يتم حساب الفجوات عند تحديد موضع الإزاحة. يتم أخذ البيانات من الأجزاء المحددة من الملف بواسطة العرض الحالي. تقوم MPI_File_iread_at بتخزين عدد عناصر datatype التي تم قراءتها فعليًا في status. جميع الحقول الأخرى في status غير معرفة.

الأخطاء (ERRORS)

تقريبًا جميع روتينات MPI تعيد قيمة خطأ؛ في روتينات C كنتيجة لإرجاع الدالة، وفي روتينات Fortran في المعامل الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل، المتواصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الأخطاء المرتبط به. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيطة CLI mpi_initial_errhandler لـ mpiexec أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج أخطاء مناسب آخر، فسيتم استدعاء معالج أخطاء MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج أخطاء MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

تتضمن Open MPI ثلاثة معالجات أخطاء محددة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج أخطاء يمكن استدعاؤه على متواصل، نافذة، ملف، أو جلسة. عند استدعائه على متواصل، يعمل كما لو تم استدعاء MPI_Abort على هذا المتواصل. إذا تم استدعاؤه على نافذة أو ملف، يعمل كما لو تم استدعاء MPI_Abort على متواصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، يقوم بإنهاء العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler
