MPI_T_pvar_session_create(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_T_PVAR_SESSION_CREATE(3) Open MPI MPI_T_PVAR_SESSION_CREATE(3)

MPI_T_pvar_session_create, MPI_T_pvar_session_free - إنشاء/تحرير جلسة متغيرات الأداء

صيغة

صيغة C

#include <mpi.h>
int MPI_T_pvar_session_create(MPI_T_pvar_session *session)
int MPI_T_pvar_session_free(MPI_T_pvar_session *session)

الوصف

MPI_T_pvar_session_create تنشئ جلسة للوصول إلى متغيرات الأداء. يتم إرجاع الجلسة الجديدة في المعلمة session.

MPI_T_pvar_session_free تحرر جلسة تم تخصيصها بواسطة MPI_T_pvar_session_create وتعين المعلمة session إلى MPI_T_PVAR_SESSION_NULL.

الأخطاء

MPI_T_pvar_session_create ستفشل إذا:

  • MPI_T_ERR_NOT_INITIALIZED: لم يتم تهيئة واجهة أدوات MPI
  • MPI_T_ERR_MEMORY: نفاد الذاكرة
  • MPI_T_ERR_OUT_OF_SESSIONS: لا توجد جلسات متاحة

MPI_T_pvar_session_free ستفشل إذا:

  • MPI_T_ERR_NOT_INITIALIZED: لم يتم تهيئة واجهة أدوات MPI
  • MPI_T_ERR_INVALID_SESSION: المعلمة session ليست جلسة صالحة
