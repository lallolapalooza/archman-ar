MPI_File_iwrite_at_all(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_IWRITE_AT_ALL(3) Open MPI MPI_FILE_IWRITE_AT_ALL(3)

MPI_File_iwrite_at_all — يكتب في ملف عند إزاحة محددة بشكل صريح (غير متزامن، جماعي).

الصيغة

صيغة C

#include <mpi.h>
int MPI_File_iwrite_at_all(MPI_File fh, MPI_Offset offset,
     const void *buf, int count, MPI_Datatype datatype, MPI_Request *request)

صيغة Fortran

USE MPI
! أو الشكل القديم: INCLUDE 'mpif.h'
MPI_FILE_IWRITE_AT_ALL(FH, OFFSET, BUF, COUNT, DATATYPE, REQUEST, IERROR)
     <type>  BUF(*)
     INTEGER FH, COUNT, DATATYPE, REQUEST, IERROR
     INTEGER(KIND=MPI_OFFSET_KIND)   OFFSET

صيغة Fortran 2008

USE mpi_f08
MPI_File_iwrite_at_all(fh, offset, buf, count, datatype, request, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: offset
     TYPE(*), DIMENSION(..) :: buf
     INTEGER, INTENT(IN) :: count
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     TYPE(MPI_Request), INTENT(OUT) :: request
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معامل الإدخال/الإخراج

•
fh: مقبض الملف (handle).

معاملات الإدخال

  • offset: إزاحة الملف (integer).
  • buf: العنوان الأولي للمخزن المؤقت (choice).
  • count: عدد العناصر في المخزن المؤقت (integer).
  • datatype: نوع بيانات كل عنصر في المخزن المؤقت (handle).

معاملات الإخراج

  • request: كائن الطلب (handle).
  • ierror: Fortran فقط: حالة الخطأ (integer).

الوصف

MPI_File_iwrite_at_all هو إصدار غير متزامن من MPI_File_write_at_all. يحاول الكتابة في الملف المرتبط بـ fh (عند موضع offset) إجمالي عدد count عناصر بيانات من نوع datatype من المخزن المؤقت للمستخدم buf. الإزاحة تكون بوحدات etype بالنسبة للعرض الحالي. أي، لا يتم حساب الثقوب عند تحديد إزاحة. يتم كتابة البيانات في الأجزاء من الملف التي يحددها العرض الحالي. MPI_File_iwrite_at_all يخزن عدد عناصر datatype التي تمت كتابتها فعليًا في status. جميع الحقول الأخرى لـ status غير محددة. يمكن تمرير بنية الطلب إلى MPI_Wait أو MPI_Test، والتي ستعيد حالة مع عدد البايتات التي تم الوصول إليها فعليًا.

يعد استدعاء هذه الوظيفة خطأً إذا تم تحديد وضع MPI_MODE_SEQUENTIAL عند فتح الملف.

الأخطاء

تقوم جميع إجراءات MPI تقريبًا بإرجاع قيمة خطأ؛ إجراءات C كنتيجة لإرجاع الوظيفة وإجراءات Fortran في الوسيط الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكيان الاتصال (مثل، المتصل، النافذة، الملف). إذا لم يكن هناك كيان اتصال مرتبط باستدعاء MPI، فيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الأخطاء المعين. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يرفع الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو الوسيط CLI mpi_initial_errhandler لـ mpiexec أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج أخطاء مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء محددة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متصل، نافذة، ملف، أو جلسة. عند استدعائه على متصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتصل. عند استدعائه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على متصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، ينهي العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا يضمن أن برنامج MPI يمكن أن يستمر بعد الخطأ.
