MPI_Info_get(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_INFO_GET(3) Open MPI MPI_INFO_GET(3)

MPI_Info_get — يسترد القيمة المرتبطة بالمفتاح في كائن معلومات.

بناء الجملة

بناء جملة C

#include <mpi.h>
int MPI_Info_get(MPI_Info info, const char *key, int valuelen, char *value, int *flag)

بناء جملة Fortran

USE MPI
! أو الشكل الأقدم: INCLUDE 'mpif.h'
MPI_INFO_GET(INFO, KEY, VALUELEN, VALUE, FLAG, IERROR)
     INTEGER INFO, VALUELEN, IERROR
     CHARACTER*(*) KEY, VALUE
     LOGICAL FLAG

بناء جملة Fortran 2008

USE mpi_f08
MPI_Info_get(info, key, valuelen, value, flag, ierror)
     TYPE(MPI_Info), INTENT(IN) :: info
     CHARACTER(LEN=*), INTENT(IN) :: key
     INTEGER, INTENT(IN) :: valuelen
     CHARACTER(LEN=valuelen), INTENT(OUT) :: value
     LOGICAL, INTENT(OUT) :: flag
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمات الإدخال

  • info: كائن المعلومات (مقبض).
  • key: المفتاح (سلسلة نصية).
  • valuelen: طول وسيط القيمة (عدد صحيح).

معلمة الإخراج

  • value: القيمة (سلسلة نصية).
  • flag: يتم تعيينه إلى صحيح إذا كان المفتاح معرفًا، أو خطأ إذا لم يكن كذلك (قيمة منطقية).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Info_get تسترد القيمة المرتبطة بـ key في استدعاء سابق لـ MPI_Info_set. إذا كان هذا المفتاح موجودًا، فإنه يقوم بتعيين flag إلى صحيح ويعيد القيمة في value؛ وإلا فإنه يقوم بتعيين flag إلى خطأ ويترك value دون تغيير. valuelen هو عدد الأحرف المتاحة في value. إذا كان أقل من الحجم الفعلي للقيمة، يتم اقتطاع القيمة المعادة. في C، يجب أن يكون valuelen أقل بواحد من مساحة التخصيص للسماح بالمُنهي الصفري.

إذا كان key أكبر من MPI_MAX_INFO_KEY، فإن الاستدعاء يكون خطأ.

الأخطاء

تقريبًا جميع إجراءات MPI تعيد قيمة خطأ؛ إجراءات C كنتيجة إرجاع للدالة وإجراءات Fortran في الوسيط الأخير.

قبل إعادة قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (على سبيل المثال، المتواصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج أخطاء MPI المرتبط به. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيط CLI mpi_initial_errhandler لـ mpiexec أو مفتاح المعلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج أخطاء مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء مسبقة يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يؤدي إلى إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متواصل، نافذة، ملف، أو جلسة. عند استدعائه على متواصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتواصل. عند استدعائه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على متواصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، يقوم بإنهاء العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق الاستدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا يضمن أن برنامج MPI يمكن أن يستمر بعد الخطأ.
