NAME

mpif77 - Open MPI Fortran 77 compiler wrapper

SYNTAX

mpif77 [compiler options] [source files] [libraries]

DESCRIPTION

The mpif77 command is a wrapper around the underlying Fortran 77 compiler (e.g., gfortran, ifort). It is responsible for including the correct compiler and linker flags so that Fortran 77 programs can use the MPI API.

When mpif77 is invoked, it does the following:

  1. It prepends the appropriate Fortran 77 compiler and its flags to the command line.

  2. It appends the appropriate MPI Fortran 77 interface library and its dependencies to the command line.

The exact compiler and flags used are determined at Open MPI build time. See the FILES section for details on how to customize this behavior.

OPTIONS

All command line options are passed directly to the underlying Fortran 77 compiler.

BACKGROUND

MPI is a message-passing interface standard. It provides a standard set of functions that users can employ to write distributed-memory parallel applications.

MPI has been implemented on a wide variety of hardware platforms, from high-performance computing clusters to desktops. Open MPI is one such implementation.

Open MPI provides a Fortran 77 interface to the MPI API. This interface is provided by a Fortran 77 library that is linked in at compile time.

FORTRAN NOTES

The Open MPI Fortran 77 interface is compatible with the Fortran 77 standard. However, there are a few differences between the Fortran 77 interface and the C/C++ interface:

  • All MPI function names are converted to all uppercase. For example, MPI_Init becomes MPI_INIT.

  • All MPI constants are converted to all uppercase. For example, MPI_COMM_WORLD becomes MPI_COMM_WORLD.

  • All MPI data types are passed by value. For example, MPI_INTEGER is passed by value, not by reference.

  • All MPI routines that take a communicator as an argument will automatically map the Fortran integer constant representing the communicator to the underlying MPI implementation's communicator type. For example, the Fortran integer constant 0 will map to MPI_COMM_WORLD.

OVERVIEW

The mpif77 compiler wrapper is used to compile and link Fortran 77 programs that use the MPI message-passing library. It is a front-end to the underlying Fortran 77 compiler, and it automatically includes the necessary flags and libraries to link against the MPI libraries.

NOTES

It is important to use the mpif77 compiler wrapper to compile and link all MPI Fortran 77 programs. Failure to do so may result in programs that do not link correctly or that do not run correctly.

The mpif77 compiler wrapper is part of the Open MPI message-passing library. For more information about Open MPI, please visit the Open MPI website at https://www.open-mpi.org.

FILES

The wrappers use configuration files to determine which compilers to use and what flags to pass to them. These files are typically located in the Open MPI installation directory, in a subdirectory named “openmpi” or similar.

The specific files are:

share/openmpi/openmpif.h
Header file for Fortran 77 programs. This file defines the MPI constants and types.
share/openmpi/mpif77-wrapper-data.txt
Text file containing compiler and linker flags for the Fortran 77 wrapper.

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

ENVIRONMENT VARIABLES

By default, the wrappers use the compilers that were selected when Open MPI was configured. These compilers were either found automatically by Open MPI’s “configure” script, or were selected by the user in the CC, CXX, and/or FC environment variables before configure was invoked. Additionally, other arguments specific to the compiler may have been selected by configure.

These values can be selectively overridden by either editing the text files containing this configuration information (see the FILES section), or by setting selected environment variables of the form ompi_value.

Valid value names are:

  • CPPFLAGS: Flags added when invoking the preprocessor (C or C++)
  • LDFLAGS: Flags added when invoking the linker (C, C++, or Fortran)
  • LIBS: Libraries added when invoking the linker (C, C++, or Fortran)
  • CC: C compiler
  • CFLAGS: C compiler flags
  • CXX: C++ compiler
  • CXXFLAGS: C++ compiler flags
  • FC: Fortran compiler
  • FCFLAGS: Fortran compiler flags
