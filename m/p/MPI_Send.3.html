MPI_Send(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_SEND(3) Open MPI MPI_SEND(3)

MPI_Send — تقوم بإرسال مانع بوضع قياسي.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Send(const void *buf, int count, MPI_Datatype datatype, int dest,
     int tag, MPI_Comm comm)

صيغة Fortran

USE MPI
! أو الصيغة الأقدم: INCLUDE 'mpif.h'
MPI_SEND(BUF, COUNT, DATATYPE, DEST, TAG, COMM, IERROR)
     <type>  BUF(*)
     INTEGER COUNT, DATATYPE, DEST, TAG, COMM, IERROR

صيغة Fortran 2008

USE mpi_f08
MPI_Send(buf, count, datatype, dest, tag, comm, ierror)
     TYPE(*), DIMENSION(..), INTENT(IN) :: buf
     INTEGER, INTENT(IN) :: count, dest, tag
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معاملات الإدخال

  • buf: عنوان مخزن الإرسال الأولي (اختياري).
  • count: عدد العناصر في مخزن الإرسال (عدد صحيح غير سالب).
  • datatype: نوع بيانات كل عنصر في مخزن الإرسال (مقبض).
  • dest: رتبة الوجهة (عدد صحيح).
  • tag: علامة الرسالة (عدد صحيح).
  • comm: المتواصل (مقبض).

معامل الإخراج

•
ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Send تقوم بإرسال مانع بوضع قياسي.

ملاحظة

ستتوقف هذه الروتين مؤقتًا حتى يتم إرسال الرسالة إلى الوجهة. للحصول على شرح متعمق لمعاني الإرسال القياسي، ارجع إلى معيار MPI.

الأخطاء

تقريبًا جميع روتينات MPI ترجع قيمة خطأ؛ روتينات C كنتيجة إرجاع للدالة وروتينات Fortran في المعامل الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج خطأ MPI الحالي المرتبط بكائن الاتصال (مثل المتواصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الخطأ MPI المرتبط. عندما لا يكون MPI_COMM_SELF مهيئًا (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيطة سطر الأوامر mpi_initial_errhandler لـ mpiexec أو مفتاح المعلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متواصل، نافذة، ملف، أو جلسة. عند استدعائه على متواصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتواصل. عند استدعائه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على متواصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، يقوم فقط بإنهاء العملية المحلية.
  • MPI_ERRORS_RETURN يرجع رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات أخطاء خاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا يضمن إمكانية استمرار برنامج MPI بعد حدوث خطأ.
