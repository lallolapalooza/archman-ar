MPI_Type_create_indexed_block(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_TYPE_CREATE_INDEXED_BLOCK(3) Open MPI MPI_TYPE_CREATE_INDEXED_BLOCK(3)

MPI_Type_create_indexed_block, MPI_Type_create_hindexed_block - إنشاء نوع بيانات مفهرس بكتلة بنفس الطول لجميع الكتل.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Type_create_indexed_block(int count, int blocklength, const int array_of_displacements[], MPI_Datatype oldtype, MPI_Datatype *newtype)
int MPI_Type_create_hindexed_block(int count, int blocklength, const MPI_Aint array_of_displacements[], MPI_Datatype oldtype, MPI_Datatype *newtype)

صيغة Fortran

USE MPI
! أو الشكل الأقدم: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_INDEXED_BLOCK(COUNT, BLOCKLENGTH,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, BLOCKLENGTH, ARRAY_OF_DISPLACEMENTS(*),
             OLDTYPE, NEWTYPE, IERROR
MPI_TYPE_CREATE_HINDEXED_BLOCK(COUNT, BLOCKLENGTH,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, BLOCKLENGTH, OLDTYPE, NEWTYPE
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_DISPLACEMENTS(*)
     INTEGER IERROR

صيغة Fortran 2008

USE mpi_f08
MPI_Type_create_indexed_block(count, blocklength, array_of_displacements,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, blocklength,
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Type_create_hindexed_block(count, blocklength, array_of_displacements,
             oldtype, newtype, ierror)
     INTEGER, INTENT(IN) :: count, blocklength
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) ::
     array_of_displacements(count)
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معاملات الإدخال

  • count: طول مصفوفة الإزاحات (عدد صحيح).
  • blocklength: حجم الكتلة (عدد صحيح).
  • array_of_displacements: مصفوفة الإزاحات (مصفوفة أعداد صحيحة). بوحدات مدى oldtype لـ MPI_Type_create_indexed_block وبايت لـ MPI_Type_create_hindexed_block.
  • oldtype: نوع البيانات القديم (مقبض).

معاملات الإخراج

  • newtype: نوع البيانات الجديد (مقبض).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Type_create_indexed_block و MPI_Type_create_hindexed_block ينشئان نوع بيانات مفهرس بنفس طول الكتلة لجميع الكتل. الفرق الوحيد بين الدالتين هو أن MPI_Type_create_indexed_block تأخذ مصفوفة إزاحات بوحدات مدى oldtype بينما MPI_Type_create_hindexed_block تأخذ إزاحات بالبايت.

الأخطاء

تقريبًا جميع روتينات MPI ترجع قيمة خطأ؛ في روتينات C كناتج إرجاع الدالة وفي روتينات Fortran في المعامل الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل، المنسق، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فإن الاستدعاء يعتبر ملحقًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الأخطاء المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو الوسيطة `mpi_initial_errhandler` لـ mpiexec أو مفتاح المعلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين معالج أخطاء مناسب آخر، فسيتم استدعاء معالج الأخطاء MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الأخطاء MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء محددة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج أخطاء يمكن استدعاؤه على منسق، نافذة، ملف، أو جلسة. عند استدعائه على منسق، يعمل كما لو تم استدعاء MPI_Abort على هذا المنسق. إذا تم استدعاؤه على نافذة أو ملف، يعمل كما لو تم استدعاء MPI_Abort على منسق يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، فإنه ينهي العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا تضمن إمكانية استمرار برنامج MPI بعد حدوث خطأ.
