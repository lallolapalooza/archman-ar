mpstat(1)

الحزمة: sysstat

التراخيص: GPL-2.0-only

MPSTAT(1) دليل مستخدم لينكس MPSTAT(1)

الاسم

mpstat - تقرير إحصائيات المعالجات ذات الصلة.

ملخص

mpstat [ -A ] [ --dec={ 0 | 1 | 2 } ] [ -H ] [ -n ] [ -U ] [ -u ] [ -T ] [ -V ] [ -I { كلمة_مفتاحية[,...] | ALL } ] [ -N { قائمة_عقد | ALL } ] [ -o JSON ] [ -P { قائمة_معالجات | ALL } ] [ فترة [ عدد ] ]

الوصف

يقوم أمر mpstat بالكتابة إلى المخرج القياسي للأنشطة لكل معالج متاح، ويكون المعالج 0 هو الأول. كما يتم الإبلاغ عن متوسط الأنشطة العالمي بين جميع المعالجات. يمكن استخدام أمر mpstat على كل من أجهزة SMP و UP، ولكن في النوع الأخير، سيتم طباعة متوسط الأنشطة العالمي فقط. إذا لم يتم تحديد أي نشاط، فإن التقرير الافتراضي هو تقرير استخدام وحدة المعالجة المركزية.

تحدد معلمة الفترة مقدار الوقت بالثواني بين كل تقرير. قيمة 0 (أو عدم وجود معلمات على الإطلاق) تشير إلى أن إحصائيات المعالجات يجب الإبلاغ عنها منذ بدء تشغيل النظام (الإقلاع). يمكن تحديد معلمة عدد بالاشتراك مع معلمة الفترة إذا لم يتم تعيينها على صفر. تحدد قيمة عدد عدد التقارير التي تم إنشاؤها بمسافة الفترة ثوانٍ. إذا تم تحديد معلمة الفترة بدون معلمة عدد، فإن أمر mpstat يقوم بإنشاء تقارير بشكل مستمر.

خيارات

-A
هذا الخيار يعادل تحديد -n -u -I ALL. هذا الخيار يتضمن أيضًا تحديد -N ALL -P ALL ما لم يتم تعيين هذه الخيارات صراحةً في سطر الأوامر.
--dec={ 0 | 1 | 2 }
تحديد عدد المنازل العشرية المراد استخدامها (من 0 إلى 2، القيمة الافتراضية هي 2).
-H
الكشف عن إحصائيات وحدات المعالجة المركزية الافتراضية (vCPUs) التي تم تبديلها فعليًا وعرضها.
-I { كلمة_مفتاحية[,...] | ALL }
تقرير إحصائيات المقاطعات. الكلمات_المفتاحية الممكنة هي CPU، SCPU، و SUM.
مع الكلمة_المفتاحية CPU، يتم عرض عدد كل مقاطعة فردية تم استلامها في الثانية بواسطة المعالج أو المعالجات. المقاطعات هي تلك المدرجة في الملف /proc/interrupts.

مع الكلمة_المفتاحية SCPU، يتم عرض عدد كل مقاطعة برمجية فردية تم استلامها في الثانية بواسطة المعالج أو المعالجات. يعمل هذا الخيار فقط مع الأنوية 2.6.31 والإصدارات الأحدث. المقاطعات البرمجية هي تلك المدرجة في الملف /proc/softirqs.

مع الكلمة_المفتاحية SUM، يقوم أمر mpstat بالإبلاغ عن العدد الإجمالي للمقاطعات لكل معالج. يتم عرض القيم التالية:

CPU
رقم المعالج. الكلمة_المفتاحية all تشير إلى أن الإحصائيات يتم حسابها كمتوسطات بين جميع المعالجات.
intr/s
عرض العدد الإجمالي للمقاطعات التي تم استلامها في الثانية بواسطة المعالج أو المعالجات.
الكلمة_المفتاحية ALL تعادل تحديد جميع الكلمات_المفتاحية أعلاه، وبالتالي يتم عرض جميع إحصائيات المقاطعات.
-N { قائمة_عقد | ALL }
تحديد عقد NUMA التي سيتم الإبلاغ عن إحصائياتها. قائمة_عقد هي قائمة بقيم مفصولة بفواصل أو نطاقات قيم (على سبيل المثال، 0,2,4-7,12-). لاحظ أن العقدة all هي المتوسط العالمي بين جميع العقد. الكلمة_المفتاحية ALL تشير إلى أنه سيتم الإبلاغ عن الإحصائيات لجميع العقد.
-n
تقرير إحصائيات وحدة المعالجة المركزية الموجزة بناءً على وضع عقدة NUMA. يتم عرض القيم التالية:
NODE
رقم عقدة NUMA المنطقية. الكلمة_المفتاحية all تشير إلى أن الإحصائيات يتم حسابها كمتوسطات بين جميع العقد.
جميع الحقول الأخرى هي نفسها تلك المعروضة مع الخيار -u (انظر أدناه).
-o JSON
عرض الإحصائيات بتنسيق JSON (JavaScript Object Notation). ترتيب حقول مخرج JSON غير محدد، وقد تتم إضافة حقول جديدة في المستقبل.
-P { قائمة_معالجات | ALL }
تحديد المعالجات التي سيتم الإبلاغ عن إحصائياتها. قائمة_معالجات هي قائمة بقيم مفصولة بفواصل أو نطاقات قيم (على سبيل المثال، 0,2,4-7,12-). لاحظ أن المعالج 0 هو المعالج الأول، والمعالج all هو المتوسط العالمي بين جميع المعالجات. لا يتم عرض المعالجات غير المتصلة.
-T
عرض عناصر الطوبولوجيا في تقرير وحدة المعالجة المركزية (انظر الخيار -u أدناه). يتم عرض العناصر التالية:
CORE
رقم النواة المنطقية.
SOCK
رقم المقبس المنطقي.
NODE
رقم عقدة NUMA المنطقية.
-U
عرض الطابع الزمني (UTC - التوقيت العالمي المنسق) بالثواني منذ الحقبة الزمنية.
-u
تقرير استخدام وحدة المعالجة المركزية. يتم عرض القيم التالية:
CPU
رقم المعالج. الكلمة_المفتاحية all تشير إلى أن الإحصائيات يتم حسابها كمتوسطات بين جميع المعالجات.
%usr
عرض النسبة المئوية لاستخدام وحدة المعالجة المركزية التي حدثت أثناء التنفيذ على مستوى المستخدم (التطبيق).
%nice
عرض النسبة المئوية لاستخدام وحدة المعالجة المركزية التي حدثت أثناء التنفيذ على مستوى المستخدم بأولوية nice.
%sys
عرض النسبة المئوية لاستخدام وحدة المعالجة المركزية التي حدثت أثناء التنفيذ على مستوى النظام (النواة). لاحظ أن هذا لا يشمل الوقت المستغرق في خدمة المقاطعات العتادية والبرمجية.
%iowait
عرض النسبة المئوية للوقت الذي كانت فيه وحدة المعالجة المركزية أو وحدات المعالجة المركزية خاملة خلالها وكان للنظام طلب إدخال/إخراج قرص معلق.
%irq
عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لخدمة مقاطعات العتاد.
%soft
عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لخدمة المقاطعات البرمجية.
%steal
عرض النسبة المئوية للوقت الذي قضاه المعالج أو المعالجات الافتراضية في انتظار غير طوعي بينما كان الـ hypervisor يخدم معالجًا افتراضيًا آخر.
%guest
عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لتشغيل معالج افتراضي.
%gnice
عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لتشغيل ضيف niced.
%idle
عرض النسبة المئوية للوقت الذي كانت فيه وحدة المعالجة المركزية أو وحدات المعالجة المركزية خاملة ولم يكن للنظام طلب إدخال/إخراج قرص معلق.
-V
طباعة رقم الإصدار ثم الخروج.

بيئة

يأخذ أمر mpstat في الاعتبار متغير البيئة التالي:

S_COLORS
افتراضيًا، يتم عرض الإحصائيات بالألوان عندما يكون المخرج متصلاً بطرفية. استخدم هذا المتغير لتغيير الإعدادات. القيم الممكنة لهذا المتغير هي never، always أو auto (الأخير يعادل الإعدادات الافتراضية).
يرجى ملاحظة أن اللون (كونه أحمر، أصفر، أو أي لون آخر) المستخدم لعرض قيمة ليس مؤشرًا على أي نوع من المشاكل ببساطة بسبب اللون. إنه يشير فقط إلى نطاقات مختلفة من القيم.
S_COLORS_SGR
تحديد الألوان والسمات الأخرى المستخدمة لعرض الإحصائيات على الطرفية. قيمتها هي قائمة مفصولة بنقطتين رئيسيتين من القدرات التي تكون افتراضيًا I=32;22:N=34;1:W=35;1:X=

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
