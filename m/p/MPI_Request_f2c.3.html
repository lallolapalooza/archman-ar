MPI_Request_f2c(3) Open MPI MPI_Request_f2c(3)

MPI_Comm_f2c, MPI_Comm_c2f, MPI_File_f2c, MPI_File_c2f, MPI_Info_f2c, MPI_Info_c2f, MPI_Message_f2c, MPI_Message_c2f, MPI_Op_f2c, MPI_Op_c2f, MPI_Request_f2c, MPI_Request_c2f, MPI_Type_f2c, MPI_Type_c2f, MPI_Win_f2c, MPI_Win_c2f - يقوم بترجمة مقبض C إلى مقبض Fortran، أو العكس.

MPI_Group MPI_Group_f2c(MPI Fint group)
MPI_Fint MPI_Group_c2f(MPI Group group)
MPI_Info MPI_Info_f2c(MPI_Fint info)
MPI_Fint MPI_Info_c2f(MPI_Info info)
MPI_Message MPI_Message_f2c(MPI_Fint message)
MPI_Fint MPI_Message_c2f(MPI_Message message)
MPI_Op MPI_Op_f2c(MPI_Fint op)
MPI_Fint MPI_Op_c2f(MPI_Op op)
MPI_Request MPI_Request_f2c(MPI_Fint request)

DESCRIPTION

يتم تمرير المقابض بين Fortran و C باستخدام غلاف C صريح لتحويل مقبض Fortran إلى مقبض C. لا يوجد وصول مباشر إلى مقبض C في Fortran. يتم توفير تعريف النوع MPI_Fint في C لعدد صحيح بحجم يطابق Fortran INTEGER؛ عادةً، سيكون MPI_Fint مكافئًا لـ int. يتم توفير دوال ترجمة المقبض في C للتحويل من مقبض Fortran (وهو عدد صحيح) إلى مقبض C، والعكس صحيح.

على سبيل المثال، إذا كان comm مقبض Fortran صالحًا للمتصل، فإن MPI_Comm_f2c يعيد مقبض C صالحًا لنفس المتصل؛ إذا كان comm = MPI_COMM_NULL (قيمة Fortran)، فإن MPI_Comm_f2c يعيد مقبض C فارغًا؛ إذا كان comm مقبض Fortran غير صالح، فإن MPI_Comm_f2c يعيد مقبض C غير صالح.

NOTE

هذه الدالة لا تعيد قيمة خطأ. بالتالي، فإن نتيجة استدعائها قبل MPI_Init أو بعد MPI_Finalize غير محددة.
