MPI_T_cvar_handle_free(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_T_CVAR_HANDLE_FREE(3) Open MPI MPI_T_CVAR_HANDLE_FREE(3)

MPI_T_cvar_handle_alloc, MPI_T_cvar_handle_free - تخصيص/تحرير مقابض المتغيرات التحكمية

الصيغة

صيغة C

#include <mpi.h>
int MPI_T_cvar_handle_alloc(int cvar_index, void *obj_handle,
                            MPI_T_cvar_handle *handle, int *count)
int MPI_T_cvar_handle_free(MPI_T_cvar_handle *handle)

الوصف

MPI_T_cvar_handle_alloc يربط المتغير التحكمي المحدد في cvar_index بالكائن MPI المحدد في obj_handle. إذا أعادت MPI_T_cvar_get_info القيمة MPI_T_BIND_NO_OBJECT كربط للمتغير، يتم تجاهل المعلمة obj_handle. يتم إرجاع عدد القيم التي يمثلها هذا المتغير التحكمي في المعلمة count. إذا كان المتغير التحكمي يمثل سلسلة نصية، فإن count سيكون الحد الأقصى لطول السلسلة النصية.

MPI_T_cvar_handle_free يحرر مقبضًا تم تخصيصه بواسطة MPI_T_cvar_handle_alloc ويضبط المعلمة handle إلى MPI_T_CVAR_HANDLE_NULL.

ملاحظات

Open MPI لا يدعم حاليًا ربط كائنات MPI بالمتغيرات التحكمية، لذلك يتم تجاهل المعلمة obj_handle دائمًا.

الأخطاء

MPI_T_cvar_handle_alloc ستفشل إذا:

  • MPI_T_ERR_NOT_INITIALIZED: لم يتم تهيئة واجهة أدوات MPI
  • MPI_T_ERR_INVALID_INDEX: فهرس المتغير التحكمي غير صالح
  • MPI_T_ERR_OUT_OF_HANDLES: لا توجد مقابض متاحة أخرى

MPI_T_cvar_handle_free ستفشل إذا:

  • MPI_T_ERR_NOT_INITIALIZED: لم يتم تهيئة واجهة أدوات MPI
  • MPI_T_ERR_INVALID_HANDLE: المقبض غير صالح
