MPI_Comm_remote_size(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_COMM_REMOTE_SIZE(3) Open MPI MPI_COMM_REMOTE_SIZE(3)

MPI_Comm_remote_size — يحدد حجم المجموعة البعيدة المرتبطة بمتصل بيني.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Comm_remote_size(MPI_Comm comm, int *size)

صيغة Fortran

USE MPI
! أو الصيغة القديمة: INCLUDE 'mpif.h'
MPI_COMM_REMOTE_SIZE(COMM, SIZE, IERROR)
     INTEGER COMM, SIZE, IERROR

صيغة Fortran 2008

USE mpi_f08
MPI_Comm_remote_size(comm, size, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     INTEGER, INTENT(OUT) :: size
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمة الإدخال

•
comm: المتصل (مقبض).

معلمات الإخراج

  • size: عدد العمليات في المجموعة البعيدة للمتصل comm (عدد صحيح).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Comm_remote_size يحدد حجم المجموعة البعيدة المرتبطة بمتصل بيني.

مُلحقات المتصل البيني (MPI_Comm_test_inter، MPI_Comm_remote_size، MPI_Comm_remote_group) كلها عمليات محلية.

الأخطاء

تقوم جميع روتينات MPI تقريبًا بإرجاع قيمة خطأ؛ روتينات C كالنتيجة المرتجعة للدالة وروتينات Fortran في الوسيط الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل المتصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فإن الاستدعاء يعتبر متصلًا بـ MPI_COMM_SELF وسيستدعي معالج الأخطاء MPI المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيط سطر الأوامر mpi_initial_errhandler لـ mpiexec أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج أخطاء مناسب آخر، فسيتم استدعاء معالج الأخطاء MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI وسيتم استدعاء معالج الأخطاء MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

تتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متصل، نافذة، ملف، أو جلسة. عند استدعائه على متصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتصل. إذا تم استدعاؤه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على متصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، فإنه ينهي العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق الاستدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا يضمن أن برنامج MPI يمكن أن يستمر بعد خطأ.
