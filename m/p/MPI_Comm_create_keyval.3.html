MPI_Comm_create_keyval(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_Comm_create_keyval(3) Open MPI MPI_Comm_create_keyval(3)

MPI_Comm_create_keyval — يولد قيمة سمة جديدة.

صيغة

صيغة C

#include <mpi.h>
int MPI_Comm_create_keyval(MPI_Comm_copy_attr_function
    *comm_copy_attr_fn, MPI_Comm_delete_attr_function
    *comm_delete_attr_fn, int *comm_keyval,
    void *extra_state)

صيغة Fortran

USE MPI
! o r d e r: INCLUDE 'mpif.h'
MPI_COMM_CREATE_KEYVAL(COMM_COPY_ATTR_FN, COMM_DELETE_ATTR_FN,
    COMM_KEYVAL, EXTRA_STATE, IERROR)
    EXTERNAL COMM_COPY_ATTR_FN, COMM_DELETE_ATTR_FN
    INTEGER COMM_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE

صيغة Fortran 2008

USE mpi_f08
MPI_Comm_create_keyval(comm_copy_attr_fn, comm_delete_attr_fn, comm_keyval,
        extra_state, ierror)
    PROCEDURE(MPI_Comm_copy_attr_function) :: comm_copy_attr_fn
    PROCEDURE(MPI_Comm_delete_attr_function) :: comm_delete_attr_fn
    INTEGER, INTENT(OUT) :: comm_keyval
    INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: extra_state
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمات الإدخال

•
comm_copy_attr_fn
دالة رد نداء لـ comm_keyval (دالة).
•
comm_delete_attr_fn
دالة رد نداء لـ comm_keyval (دالة).
•
extra_state : حالة إضافية لدوال رد النداء.

معلمة الإخراج

  • comm_keyval : مفتاح الوصول المستقبلي (عدد صحيح).
  • ierror : Fortran فقط: رمز الخطأ (عدد صحيح).

الوصف

هذه الوظيفة تستبدل MPI_Keyval_create، والتي تعتبر مهملة. ربط C مطابق. ربط Fortran يختلف في أن extra_state هو عدد صحيح بحجم العنوان. أيضاً، دوال رد النداء للنسخ والحذف لها ربطات Fortran متسقة مع سمات بحجم العنوان. يمكن تحديد المعلمة comm_copy_attr_fn على أنها MPI_COMM_NULL_COPY_FN أو MPI_COMM_DUP_FN في C أو Fortran. MPI_COMM_NULL_COPY_FN هي دالة ترجع فقط flag = 0 و MPI_SUCCESS . MPI_COMM_DUP_FN هي دالة نسخ بسيطة تعين flag = 1 ، وترجع قيمة attribute_val_in إلى attribute_val_out ، وترجع MPI_SUCCESS . هذه تستبدل دوال رد النداء المعرفة مسبقاً في MPI-1 MPI_NULL_COPY_FN و MPI_DUP_FN ، والتي تعتبر مهملة. دالتا رد النداء C هما:

typedef int MPI_Comm_copy_attr_function(MPI_Comm oldcomm, int comm_keyval,
             void *extra_state, void *attribute_val_in,
             void *attribute_val_out, int *flag);
typedef int MPI_Comm_delete_attr_function(MPI_Comm comm, int comm_keyval,
             void *attribute_val, void *extra_state);

وهي نفس استدعاءات MPI-1.1، ولكن باسم جديد. الأسماء القديمة تعتبر مهملة. دالتا رد النداء Fortran هما:

SUBROUTINE COMM_COPY_ATTR_FN(OLDCOMM, COMM_KEYVAL, EXTRA_STATE,
             ATTRIBUTE_VAL_IN, ATTRIBUTE_VAL_OUT, FLAG, IERROR)
    INTEGER OLDCOMM, COMM_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE, ATTRIBUTE_VAL_IN,
        ATTRIBUTE_VAL_OUT
    LOGICAL FLAG
SUBROUTINE COMM_DELETE_ATTR_FN(COMM, COMM_KEYVAL, ATTRIBUTE_VAL, EXTRA_STATE,
             IERROR)
    INTEGER COMM, COMM_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE_VAL, EXTRA_STATE

الأخطاء

معظم روتينيات MPI ترجع قيمة خطأ؛ في C، يتم إرجاع النتيجة كقيمة إرجاع للدالة، وفي Fortran في المعلمة الأخيرة.

قبل أن يتم إرجاع قيمة الخطأ، يتم استدعاء معالج الخطأ المرتبط بكائن الاتصال (على سبيل المثال، الموصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط بالاستدعاء MPI، فيعتبر الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الخطأ المرتبط. عند عدم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسة حصريًا)، يتم إطلاق الخطأ المشار إليه. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو من خلال وسيطة سطر الأوامر mpi_initial_errhandler في mpiexec أو من خلال مفتاح المعلومات في MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين معالج خطأ مناسب آخر، يتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI ومعالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

تتضمن Open MPI ثلاثة معالجات أخطاء افتراضية يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL : يوقف جميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT : معالج خطأ يمكن استدعاؤه على موصل، نافذة، ملف، أو جلسة. عند استدعائه على موصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا الموصل. إذا تم استدعاؤه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على موصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، يوقف العملية المحلية فقط.
  • MPI_ERRORS_RETURN : يرجع رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضاً تنفيذ معالجات أخطاء خاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler متبوعاً بـ MPI_Comm_set_errhandler
  • MPI_File_create_errhandler متبوعاً بـ MPI_File_set_errhandler
  • MPI_Session_create_errhandler متبوعاً بـ MPI_Session_set_errhandler أو في MPI_Session_init
  • MPI_Win_create_errhandler متبوعاً بـ MPI_Win_set_errhandler

ملاحظة: لا تضمن تطبيقات MPI قدرتها على الاستمرار بعد حدوث خطأ.
