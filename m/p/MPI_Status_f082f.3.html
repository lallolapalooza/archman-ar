MPI_Status_f082f(3)

الحزمة: openmpi

MPI_STATUS_F082F(3) Open MPI MPI_STATUS_F082F(3)

MPI_Status_f082f, MPI_Status_c2f08 - ترجمة حالة Fortran 2008 إلى حالة Fortran بنمط INTEGER، أو العكس.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Status_f082f(const MPI_F08_status *f08_status, MPI_Fint *f_status)
int MPI_Status_f2f08(const MPI_Fint *f_status, MPI_F08_status *f08_status)

USE MPI

    INTEGER :: STATUS(MPI_STATUS_SIZE), IERROR
MPI_STATUS_F2F08(F_STATUS, F08_STATUS, IERROR)
    INTEGER :: F_STATUS(MPI_STATUS_SIZE), IERROR
    TYPE(MPI_Status) :: F08_STATUS

    INTEGER, INTENT(OUT) :: f_status(MPI_STATUS_SIZE)

المعاملات

  • f08_status : كائن حالة MPI بنمط mpi_f08
  • f_status : كائن حالة MPI بنمط INTEGER بنمط mpi

الوصف

تم توفير هذين الإجرائين لتحويل حالة Fortran 2008 (وهي نوع مشتق يتكون من أعداد صحيحة) إلى حالة Fortran (وهي مصفوفة من الأعداد الصحيحة)، والعكس صحيح. يحدث التحويل على جميع المعلومات الموجودة في الحالة، بما في ذلك المعلومات المخفية. أي أنه لا يتم فقدان أي معلومات حالة في التحويل.

عند استخدام MPI_Status_f082f، إذا كانت f08_status حالة Fortran صالحة، ولكنها ليست القيمة Fortran لـ MPI_F08_STATUS_IGNORE (في C)، MPI_STATUS_IGNORE (في Fortran) أو MPI_F08_STATUSES_IGNORE (في C) أو MPI_STATUSES_IGNORE (في Fortran)، فإن MPI_Status_f082f تعيد في f_status مصفوفة صالحة بنفس المحتوى. إذا كانت f08_status هي قيمة C لـ MPI_F08_STATUS_IGNORE أو MPI_F08_STATUSES_IGNORE أو قيمة Fortran لـ MPI_STATUS_IGNORE أو MPI_STATUSES_IGNORE، أو إذا لم تكن f08_status حالة Fortran صالحة، فإن الاستدعاء يكون خاطئًا.

عند استخدام MPI_Status_f2f08، يتم تطبيق التحويل العكسي. إذا كانت f_status هي MPI_STATUS_IGNORE أو MPI_STATUSES_IGNORE، أو إذا لم تكن f_status حالة Fortran صالحة، فإن الاستدعاء يكون خاطئًا.

الحالة المدخلة لها نفس المصدر، العلامة، ورموز الخطأ مثل الحالة المخرجة، وتعيد نفس الإجابات عند الاستعلام عن العدد، العناصر، والإلغاء. قد يتم استدعاء دالة التحويل بمعامل حالة مدخل لديه حقل خطأ غير محدد، وفي هذه الحالة تكون قيمة حقل الخطأ في معامل الحالة المخرجة غير محددة.

ملاحظات

روتينات Fortran لهذه الإجراءات MPI متوفرة فقط في وحدتي mpi و mpi_f08 (بما في ذلك تحديد النوع لـ TYPE(MPI_Status)؛ وهي (عمدًا) غير متوفرة في mpif.h.
