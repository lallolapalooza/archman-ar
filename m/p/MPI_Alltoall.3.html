MPI_ALLTOALL(3) Open MPI MPI_ALLTOALL(3)

MPI_Alltoall، MPI_Ialltoall، MPI_Alltoall_init - ترسل جميع العمليات بيانات إلى جميع العمليات

الصيغة

صيغة C

#include <mpi.h>
int MPI_Alltoall(const void *sendbuf, int sendcount,
     MPI_Datatype sendtype, void *recvbuf, int recvcount,
     MPI_Datatype recvtype, MPI_Comm comm)
int MPI_Ialltoall(const void *sendbuf, int sendcount,
     MPI_Datatype sendtype, void *recvbuf, int recvcount,
     MPI_Datatype recvtype, MPI_Comm comm, MPI_Request *request)
int MPI_Alltoall_init(const void *sendbuf, int sendcount,
     MPI_Datatype sendtype, void *recvbuf, int recvcount,
     MPI_Datatype recvtype, MPI_Comm comm, MPI_Info info, MPI_Request *request)

معلمات الإدخال

  • sendbuf: عنوان بداية مخزن الإرسال (اختياري).
  • sendcount: عدد العناصر المراد إرسالها إلى كل عملية (عدد صحيح).
  • sendtype: نوع بيانات عناصر مخزن الإرسال (معالج).
  • recvcount: عدد العناصر المراد استقبالها من كل عملية (عدد صحيح).
  • recvtype: نوع بيانات عناصر مخزن الاستقبال (معالج).
  • comm: الموصل الذي سيتم تبادل البيانات فوقه (معالج).
  • info: معلومات (معالج، فقط للعمليات المستمرة)

معلمات الإخراج

  • recvbuf: عنوان بداية مخزن الاستقبال (اختياري).
  • request: طلب (معالج، غير متزامن فقط).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Alltoall هي عملية جماعية تقوم فيها جميع العمليات بإرسال نفس كمية البيانات إلى بعضها البعض، واستقبال نفس كمية البيانات من بعضها البعض. يمكن تمثيل عملية هذه الروتين على النحو التالي، حيث تقوم كل عملية بإجراء 2ن (حيث ن هو عدد العمليات في الموصل comm) اتصالات نقطة إلى نقطة مستقلة (بما في ذلك الاتصال مع نفسها).

MPI_Comm_size(comm, &n);
for (i = 0, i < n; i++)
    MPI_Send(sendbuf + i * sendcount * extent(sendtype),
        sendcount, sendtype, i, ..., comm);
for (i = 0, i < n; i++)
    MPI_Recv(recvbuf + i * recvcount * extent(recvtype),
        recvcount, recvtype, i, ..., comm);

تقسم كل عملية مخزن الإرسال المحلي الخاص بها sendbuf إلى ن مجموعات - تحتوي كل منها على sendcount من العناصر من نوع sendtype - وتقسم مخزن الاستقبال الخاص بها recvbuf بشكل مشابه وفقًا لـ recvcount و recvtype. ترسل العملية j الكتلة k من مخزن الإرسال المحلي الخاص بها sendbuf إلى العملية k، والتي تضع البيانات في الكتلة j من مخزن الاستقبال المحلي الخاص بها recvbuf. يجب أن تكون كمية البيانات المرسلة مساوية لكمية البيانات المستلمة، بشكل زوجي، بين كل زوج من العمليات.

عندما يكون الموصل موصلاً بينياً (INTER-COMMUNICATOR)

عندما يكون الموصل موصلاً بينياً، تحدث عملية التجميع على مرحلتين. يتم تجميع البيانات من جميع أعضاء المجموعة الأولى واستقبالها من قبل جميع أعضاء المجموعة الثانية. ثم يتم تجميع البيانات من جميع أعضاء المجموعة الثانية واستقبالها من قبل جميع أعضاء المجموعة الأولى. تظهر العملية سلوكًا متماثلًا مزدوج الاتجاه بالكامل.

تحدد المجموعة الأولى العملية الجذر. تستخدم العملية الجذر MPI_ROOT كقيمة لـ root. تستخدم جميع العمليات الأخرى في المجموعة الأولى **MPI_PROC_NULL** كقيمة لـ root. تستخدم جميع العمليات في المجموعة الثانية رتبة العملية الجذر في المجموعة الأولى كقيمة لـ root.

عندما يكون الموصل موصلاً داخلياً (INTRA-COMMUNICATOR)، تكون هذه المجموعات متطابقة، وتحدث العملية في مرحلة واحدة.

استخدام خيار في المكان (IN-PLACE OPTION)

عندما يكون الموصل موصلاً داخلياً، يمكنك إجراء عملية "الكل إلى الكل" في المكان (يتم استخدام مخزن الإخراج كمخزن إدخال). استخدم المتغير MPI_IN_PLACE كقيمة لـ sendbuf. في هذه الحالة، يتم تجاهل sendcount و sendtype. يُفترض أن تكون بيانات الإدخال لكل عملية في المنطقة التي تستقبل فيها تلك العملية مساهمتها الخاصة في مخزن الاستقبال.

ملاحظات

جميع المعلمات على جميع العمليات ذات مغزى. يجب أن يصف الموصل comm، على وجه الخصوص، نفس الموصل على جميع العمليات.

هناك وظيفتان في مكتبة MPI أكثر عمومية من MPI_Alltoall. تسمح MPI_Alltoallv بتبادل بيانات الكل إلى الكل من وإلى المخازن التي لا تحتاج إلى أن تكون متجاورة؛ قد ترسل العمليات المختلفة وتستقبل كميات مختلفة من البيانات. MPI_Alltoallw توسع وظائف MPI_Alltoallv للسماح بتبادل البيانات بأنواع بيانات مختلفة.

الأخطاء

تقوم جميع روتينات MPI تقريبًا بإرجاع قيمة خطأ؛ روتينات C كنتيجة إرجاع للدالة وروتينات Fortran في المعلمة الأخيرة.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل الموصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيستدعي معالج أخطاء MPI المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيطة سطر الأوامر mpiexec لـ mpi_initial_errhandler أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FA

ERRORS

All MPI functions must be called with a communicator or window, and all MPI operations are potentially asynchronous. These operations might fail. MPI provides a mechanism to handle these failures. The default error handler causes the MPI program to abort all MPI processes. The following error handlers are predefined by MPI:

  • MPI_ERRORS_ARE_FATAL Causes the program to abort all connected MPI processes.
  • MPI_ERRORS_ABORT An error handler that can be invoked on a communicator, window, file, or session. When called on a communicator, it acts as if MPI_Abort was called on that communicator. If called on a window or file, acts as if MPI_Abort was called on a communicator containing the group of processes in the corresponding window or file. If called on a session, aborts only the local process.
  • MPI_ERRORS_RETURN Returns an error code to the application.

MPI applications can also implement their own error handlers by calling:

  • MPI_Comm_create_errhandler then MPI_Comm_set_errhandler
  • MPI_File_create_errhandler then MPI_File_set_errhandler
  • MPI_Session_create_errhandler then MPI_Session_set_errhandler or at MPI_Session_init
  • MPI_Win_create_errhandler then MPI_Win_set_errhandler

Note that MPI does not guarantee that an MPI program can continue past an error.

See the MPI man page for a full list of MPI error codes.

See the Error Handling section of the MPI-3.1 standard for more information.
