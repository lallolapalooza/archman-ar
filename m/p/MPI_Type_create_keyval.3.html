MPI_Type_create_keyval(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_Type_create_keyval(3) Open MPI MPI_Type_create_keyval(3)

MPI_Type_create_keyval ينشئ مفتاح سمة جديد لذاكرة التخزين المؤقت لأنواع البيانات.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Type_create_keyval(MPI_Type_copy_attr_function *type_copy_attr_fn,
     MPI_Type_delete_attr_function *type_delete_attr_fn,
     int *type_keyval, void *extra_state)

صيغة فورتران

USE MPI
! أو الطريقة القديمة: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_KEYVAL(TYPE_COPY_ATTR_FN, TYPE_DELETE_ATTR_FN,
             TYPE_KEYVAL, EXTRA_STATE, IERROR)
     EXTERNAL TYPE_COPY_ATTR_FN, TYPE_DELETE_ATTR_FN
     INTEGER TYPE_KEYVAL, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE

صيغة فورتران 2008

USE mpi_f08
MPI_Type_create_keyval(type_copy_attr_fn, type_delete_attr_fn, type_keyval,
             extra_state, ierror)
     PROCEDURE(MPI_Type_copy_attr_function) :: type_copy_attr_fn
     PROCEDURE(MPI_Type_delete_attr_function) :: type_delete_attr_fn
     INTEGER, INTENT(OUT) :: type_keyval
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: extra_state
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معاملات الإدخال

  • type_copy_attr_fn: دالة رد اتصال لـ type_keyval (دالة).
  • type_delete_attr_fn: دالة رد اتصال للحذف لـ type_keyval (دالة).
  • extra_state: حالة إضافية لدوال رد الاتصال.

معاملات الإخراج

  • type_keyval: مفتاح وصول مستقبلي (عدد صحيح).
  • ierror: فورتران فقط: رمز الخطأ (عدد صحيح).

الوصف

MPI_Type_create_keyval ينشئ مفتاح سمة جديد لذاكرة التخزين المؤقت لأنواع البيانات. هذه الروتينية تحل جزئيًا محل MPI_Keyval_create.

يمكن تحديد المعامل type_copy_attr_fn كـ MPI_TYPE_NULL_COPY_FN أو MPI_TYPE_DUP_FN من C أو Fortran. MPI_TYPE_NULL_COPY_FN هي دالة تعيد فقط flag = 0 و MPI_SUCCESS. MPI_TYPE_DUP_FN هي دالة نسخ بسيطة تعين flag = 1، وتعيد قيمة attribute_val_in إلى attribute_val_out، وتعيد MPI_SUCCESS.

يمكن تحديد المعامل type_delete_attr_fn كـ MPI_TYPE_NULL_DELETE_FN من C أو Fortran. MPI_TYPE_NULL_DELETE_FN هي دالة لا تفعل شيئًا سوى إعادة MPI_SUCCESS. دوال رد الاتصال C هي:

typedef int MPI_Type_copy_attr_function(MPI_Datatype oldtype,
            int type_keyval, void *extra_state, void *attribute_val_in,
            void *attribute_val_out, int *flag);
typedef int MPI_Type_delete_attr_function(MPI_Datatype type, int type_keyval,
             void *attribute_val, void *extra_state);

دوال رد الاتصال فورتران هي:

SUBROUTINE TYPE_COPY_ATTR_FN(OLDTYPE, TYPE_KEYVAL, EXTRA_STATE,
             ATTRIBUTE_VAL_IN, ATTRIBUTE_VAL_OUT, FLAG, IERROR)
    INTEGER OLDTYPE, TYPE KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) EXTRA_STATE,
        ATTRIBUTE_VAL_IN, ATTRIBUTE_VAL_OUT
    LOGICAL FLAG
SUBROUTINE TYPE_DELETE_ATTR_FN(TYPE, TYPE_KEYVAL, ATTRIBUTE_VAL, EXTRA_STATE,
             IERROR)
    INTEGER TYPE, TYPE_KEYVAL, IERROR
    INTEGER(KIND=MPI_ADDRESS_KIND) ATTRIBUTE VAL, EXTRA_STATE

الأخطاء

تقوم كل روتينات MPI تقريبًا بإرجاع قيمة خطأ؛ يتم إرجاعها كناتج للدالة في روتينات C، وفي المعامل الأخير في روتينات Fortran.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل مجموعة الاتصال، النافذة، الملف). إذا لم يكن لاستدعاء MPI كائن اتصال مرتبط، فإنه يعتبر مرفقًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الأخطاء المناسب. عندما لا يتم تهيئة MPI_COMM_SELF (أي بعد MPI_Init/MPI_Init_thread، أو عند الاستخدام الحصري لنموذج الجلسة)، سيقوم معالج الأخطاء الأولي بالتشغيل. يمكن تعيين معالج الأخطاء الأولي باستخدام MPI_Comm_set_errhandler على نموذج العالم، أو تحديده في mpiexec أو مفتاح info باستخدام معلمة سطر الأوامر mpi_initial_errhandler. إذا لم يتم تعيين معالج أخطاء مناسب آخر، فسيتم استدعاء MPI_ERRORS_RETURN لروتينات MPI I/O، و MPI_ERRORS_ABORT للروتينات الأخرى لـ MPI.

يتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL تجعل البرنامج ينهي جميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT هو معالج خطأ يمكن استدعاؤه على مجموعة اتصال، نافذة، ملف، أو جلسة. عند استدعائه على مجموعة اتصال، فإنه يتصرف كما لو تم استدعاء MPI_Abort على تلك المجموعة. عند استدعائه على نافذة أو ملف، فإنه يتصرف كما لو تم استدعاء MPI_Abort على مجموعة الاتصال التي تتضمن مجموعة العمليات المقابلة. عند استدعائه على جلسة، فإنه ينهي العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز الخطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا إنشاء معالجات أخطاء مخصصة عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا يضمن أن برنامج MPI يمكن أن يستمر في التنفيذ بعد حدوث خطأ.
