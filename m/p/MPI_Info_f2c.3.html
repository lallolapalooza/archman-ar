MPI_INFO_F2C(3) Open MPI MPI_INFO_F2C(3)

MPI_Comm_f2c، MPI_Comm_c2f، MPI_File_f2c، MPI_File_c2f، MPI_Info_f2c، MPI_Info_c2f، MPI_Message_f2c، MPI_Message_c2f، MPI_Op_f2c، MPI_Op_c2f، MPI_Request_f2c، MPI_Request_c2f، MPI_Type_f2c، MPI_Type_c2f، MPI_Win_f2c، MPI_Win_c2f - تحويل معرف C إلى معرف Fortran، أو العكس.

صيغة C (C Syntax)

MPI_Info MPI_Info_f2c(MPI_Fint info)
MPI_Fint MPI_Info_c2f(MPI_Info info)

MPI_Fint MPI_Message_c2f(MPI_Message message)
MPI_Op MPI_Op_f2c(MPI_Fint op)
MPI_Fint MPI_Op_c2f(MPI_Op op)
MPI_Request MPI_Request_f2c(MPI_Fint request)
MPI_Fint MPI_Request_c2f(MPI_Request request)

الوصف (DESCRIPTION)

يتم تمرير المعرفات بين Fortran و C باستخدام غلاف C صريح لتحويل معرفات Fortran إلى معرفات C. لا يوجد وصول مباشر لمعرفات C في Fortran. يتم توفير تعريف النوع MPI_Fint في C لرقم صحيح بحجم يتطابق مع Fortran INTEGER؛ عادةً، سيكون MPI_Fint مكافئًا لـ int. يتم توفير دوال ترجمة المعرفات في C للتحويل من معرف Fortran (وهو رقم صحيح) إلى معرف C، والعكس صحيح.

على سبيل المثال، إذا كان comm معرفًا صالحًا لـ Fortran لمُتَّصِل، فإن MPI_Comm_f2c تُرجع معرف C صالحًا لنفس المُتَّصِل؛ إذا كان comm = MPI_COMM_NULL (قيمة Fortran)، فإن MPI_Comm_f2c تُرجع معرف C فارغًا؛ إذا كان comm معرفًا غير صالح لـ Fortran، فإن MPI_Comm_f2c تُرجع معرف C غير صالح.

ملاحظة (NOTE)

هذه الدالة لا تُرجع قيمة خطأ. وبالتالي، فإن نتيجة استدعائها قبل MPI_Init أو بعد MPI_Finalize غير معرفة.
