MPI_Testany(3)

Propósito

MPI_Testany - تختبر ما إذا كان أي طلب من مجموعة طلبات MPI قد اكتمل.

الصيغة

int MPI_Testany(int count, MPI_Request array_of_requests[], int *index, MPI_Status *status);

المدخلات

  • count: عدد الطلبات في المصفوفة.
  • array_of_requests: مصفوفة من طلبات MPI.

المخرجات

  • index: مؤشر إلى متغير صحيح سيحتوي على فهرس الطلب المكتمل في array_of_requests. إذا لم يكتمل أي طلب، فسيتم تعيينه على MPI_UNDEFINED.
  • status: مؤشر إلى بنية MPI_Status التي تحتوي على معلومات حول الطلب المكتمل.

الوصف

تختبر الدالة MPI_Testany ما إذا كان أي طلب من مجموعة طلبات MPI قد اكتمل. إذا اكتمل طلب واحد أو أكثر، فإنها تحدد أحد هذه الطلبات، وتُرجع فهرسه في المصفوفة array_of_requests، ومعلومات الحالة الخاصة به. إذا لم يكتمل أي طلب، فإنها تُرجع MPI_UNDEFINED في index ولا تُرجع معلومات الحالة. يجب أن تكون الطلبات الموجودة في array_of_requests قد تم تعيينها مسبقًا.

أمثلة

مثال بسيط لاستخدام MPI_Testany:


int count = 2;
MPI_Request requests[2];
int index;
MPI_Status status;

// ... قم ببدء طلبات MPI ...

int flag;
MPI_Testany(count, requests, &index, &status);

if (index != MPI_UNDEFINED) {
    // اكتمل طلب
    if (index == 0) {
        // الطلب الأول اكتمل
    } else {
        // الطلب الثاني اكتمل
    }
    // ... معالجة الطلب المكتمل ...
} else {
    // لم يكتمل أي طلب بعد
}

أخطاء

يمكن أن تفشل MPI_Testany في حالة وجود خطأ داخلي في MPI.
