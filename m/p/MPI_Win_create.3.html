MPI_Win_create(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

SYNTAX

C++


cpp

int MPI_Win_create(const void *base, MPI_Aint size, int disp_unit, MPI_Info info, MPI_Comm comm, MPI_Win *win)


MPI::Win::Create(const void *base, int size, int disp_unit, const MPI::Info &info, const MPI::Comm &comm)MPI::Win create(MPI::Win const& win)

INPUT PARAMETERS

base
Puntero al inicio del buffer de memoria que se usará para la ventana.
size
Tamaño en bytes del buffer de memoria.
disp_unit
Unidad de visualización. Especifica la unidad en la que se expresan las visualizaciones relativas (por ejemplo, bytes, elementos de tipo, etc.). Debe ser una potencia de dos.
info
Tabla de claves/valores de información para optimizar la creación de la ventana.
comm
Comunicador que se utilizará para la creación de la ventana.

OUTPUT PARAMETERS

win
Identificador del nuevo objeto de ventana.

DESCRIPTION

MPI_Win_create crea un nuevo objeto de ventana para usar con los primitivos de memoria remota de MPI. La ventana se asocia con un objeto comunicador especificado y se le da una vista de una región de memoria remota.

El argumentobase ysize definen la región de memoria que se expondrá. Si base es NULL, entonces size debe ser 0. Esto significa que no se expone ninguna memoria.

El argumentodisp_unit se utiliza para interpretar las distancias relativas. Por ejemplo, sidisp_unit es el tamaño de un entero, entonces una distancia de 1 se refiere al siguiente entero en la memoria. Si disp_unit es 1, entonces todas las distancias se interpretan en bytes.

El argumentoinfo se puede utilizar para proporcionar pistas de optimización para la creación de la ventana. Consulte la documentación de MPI para obtener más detalles sobre las claves deinfo disponibles.

El objeto comunicadorcomm debe ser un comunicador intracomunicador.

NOTES

El constructorMPI::Win::Create de C++ es una envoltura para MPI_Win_create. El métodocreate de C++ es una sobrecarga que crea una ventana vacía.

ERRORS

Cuando ocurre un error, el nombre del subrutina se devuelve en el argumento func_name y el código de error se devuelve en el argumentorc. El código de errorMPI_SUCCESS indica éxito. Si ocurre un error, el valor derc es un código de error distinto de cero.
