MPATH_PERSISTENT_RESERVE_IN(3) دليل وظائف المكتبة MPATH_PERSISTENT_RESERVE_IN(3)

الاسم

mpath_persistent_reserve_in - إرسال أمر PRIN إلى جهاز DM

الملخص

#include <mpath_persist.h>

int mpath_persistent_reserve_in(int fd, int rq_servact, struct prin_resp *resp, int noisy, int verbose)

الوصف

تقوم الدالة في mpath_persistent_reserve_in () بإرسال أمر PRIN إلى جهاز DM والحصول على الاستجابة.

المعلمات:
fd
واصف الملف لجهاز مسارات متعددة. مدخل.
rq_servact
إجراء خدمة أمر PRIN. مدخل.
resp
الاستجابة من إجراء خدمة PRIN. يجب على المتصل إدارة تخصيص الذاكرة لهذا الهيكل.
noisy
تشغيل تتبع التصحيح: مدخل. 0->تعطيل، 1->تمكين.
verbose
تعيين مستوى الإسهاب. مدخل. القيمة: [0-3]. 0->أخطاء، 1->تحذيرات، 2->معلومات، 3->تصحيح.

القيمة المرجعة

MPATH_PR_SUCCESS
إذا كان أمر PR ناجحًا.
MPATH_PR_SYNTAX_ERROR
إذا كان هناك خطأ في بناء الجملة أو معامل غير صالح.
MPATH_PR_SENSE_NOT_READY
إذا فشل الأمر مع [sk,asc,ascq: 0x2,*,*].
MPATH_PR_SENSE_MEDIUM_ERROR
إذا فشل الأمر مع [sk,asc,ascq: 0x3,*,*].
MPATH_PR_SENSE_HARDWARE_ERROR
إذا فشل الأمر مع [sk,asc,ascq: 0x4,*,*].
MPATH_PR_SENSE_INVALID_OP
إذا فشل الأمر مع [sk,asc,ascq: 0x5,0x20,0x0].
MPATH_PR_ILLEGAL_REQ
إذا فشل الأمر مع [sk,asc,ascq: 0x5,*,*].
MPATH_PR_SENSE_UNIT_ATTENTION
إذا فشل الأمر مع [sk,asc,ascq: 0x6,*,*].
MPATH_PR_SENSE_ABORTED_COMMAND
إذا فشل الأمر مع [sk,asc,ascq: 0xb,*,*].
MPATH_PR_NO_SENSE
إذا فشل الأمر مع [sk,asc,ascq: 0x0,*,*].
MPATH_PR_SENSE_MALFORMED
إذا فشل الأمر مع وجود خطأ في تكوين أمر SCSI.
MPATH_PR_FILE_ERROR
إذا فشل الأمر أثناء الوصول إلى ملف (عقدة الجهاز) مشاكل (مثل عدم العثور عليه).
MPATH_PR_DMMP_ERROR
إذا كان هناك خطأ متعلق بـ Device Mapper (مثل خطأ في الحصول على معلومات dm).
MPATH_PR_OTHER
إذا حدث خطأ/تحذير آخر (مثل خطأ في النقل أو برنامج التشغيل).
