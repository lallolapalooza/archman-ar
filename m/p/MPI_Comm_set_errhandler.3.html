MPI_Comm_set_errhandler(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_COMM_SET_ERRHANDLER(3) Open MPI MPI_Comm_set_errhandler(3)

MPI_Comm_set_errhandler — يربط معالج أخطاء جديد بمُرسِل.

صيغة الاستدعاء

صيغة C

#include <mpi.h>
int MPI_Comm_set_errhandler(MPI_Comm comm,
     MPI_Errhandler errhandler)

صيغة Fortran

USE MPI
! or the older form: INCLUDE 'mpif.h'
MPI_COMM_SET_ERRHANDLER(COMM, ERRHANDLER, IERROR)
     INTEGER COMM, ERRHANDLER, IERROR

صيغة Fortran 2008

USE mpi_f08
MPI_Comm_set_errhandler(comm, errhandler, ierror)
     TYPE(MPI_Comm), INTENT(IN) :: comm
     TYPE(MPI_Errhandler), INTENT(IN) :: errhandler
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معامل الإدخال/الإخراج

•
comm: المُرسِل (مقبض).

معاملات الإخراج

  • errhandler: معالج الأخطاء الجديد للمُرسِل (مقبض).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Comm_set_errhandler يربط معالج أخطاء جديد بمُرسِل. يجب أن يكون معالج الأخطاء إما معالج أخطاء مُعرّف مسبقًا أو معالج أخطاء تم إنشاؤه بواسطة استدعاء لـ MPI_Comm_create_errhandler. هذا الاستدعاء مطابق لـ MPI_Errhandler_set، والتي يعتبر استخدامها مهملًا.

الأخطاء

تقوم جميع روتينات MPI تقريبًا بإرجاع قيمة خطأ؛ روتينات C كنتيجة إرجاع للدالة وروتينات Fortran في المعامل الأخير.

قبل إعادة قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل المُرسِل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فإن الاستدعاء يعتبر مرتبطًا بـ MPI_COMM_SELF وسيقوم باستدعاء معالج الأخطاء MPI المرتبط به. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيطة سطر الأوامر mpi_initial_errhandler لـ mpiexec أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج أخطاء مناسب آخر، فسيتم استدعاء معالج الأخطاء MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الأخطاء MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

تتضمن Open MPI ثلاثة معالجات أخطاء مُعرّفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج أخطاء يمكن استدعاؤه على مُرسِل، نافذة، ملف، أو جلسة. عند استدعائه على مُرسِل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المُرسِل. عند استدعائه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على مُرسِل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، يقوم بإنهاء العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا تضمن أن برنامج MPI يمكن أن يستمر بعد خطأ.
