MPI_Iallreduce(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_IALLREDUCE(3) Open MPI MPI_IALLREDUCE(3)

MPI_Allreduce, MPI_Iallreduce, MPI_Allreduce_init - يجمع القيم من جميع العمليات ويوزع النتيجة مرة أخرى إلى جميع العمليات.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Allreduce(const void *sendbuf, void *recvbuf, int count,
                  MPI_Datatype datatype, MPI_Op op, MPI_Comm comm)
int MPI_Iallreduce(const void *sendbuf, void *recvbuf, int count,
                   MPI_Datatype datatype, MPI_Op op, MPI_Comm comm,
                   MPI_Request *request)
int MPI_Allreduce_init(const void *sendbuf, void *recvbuf, int count,
                       MPI_Datatype datatype, MPI_Op op, MPI_Comm comm,
                       MPI_Info info, MPI_Request *request)

معلمات الإدخال

  • sendbuf: عنوان بداية مخزن الإرسال (اختيار).
  • count: عدد العناصر في مخزن الإرسال (عدد صحيح).
  • datatype: نوع بيانات عناصر مخزن الإرسال (مقبض).
  • op: العملية (مقبض).
  • comm: المتواصل (مقبض).
  • info: معلومات (مقبض، دائم فقط).

معلمات الإخراج

  • recvbuf: عنوان بداية مخزن الاستقبال (اختيار).
  • request: طلب (مقبض، غير متزامن فقط).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

نفس MPI_Reduce باستثناء أن النتيجة تظهر في مخزن الاستقبال لجميع أعضاء المجموعة.

مثال 1: روتين يحسب حاصل ضرب متجه ومصفوفة موزعة عبر مجموعة من العمليات ويعيد الإجابة إلى جميع العقد (قارن مع المثال 2، مع MPI_Reduce، أدناه).

SUBROUTINE PAR_BLAS2(m, n, a, b, c, comm)
REAL a(m), b(m,n)    ! شريحة محلية من المصفوفة
REAL c(n)            ! النتيجة
REAL sum(n)
INTEGER n, comm, i, j, ierr
! المجموع المحلي
DO j= 1, n
  sum(j) = 0.0
  DO i = 1, m
    sum(j) = sum(j) + a(i)*b(i,j)
  END DO
END DO
! المجموع العام
CALL MPI_ALLREDUCE(sum, c, n, MPI_REAL, MPI_SUM, comm, ierr)
! إعادة النتيجة إلى جميع العقد
RETURN

مثال 2: روتين يحسب حاصل ضرب متجه ومصفوفة موزعة عبر مجموعة من العمليات ويعيد الإجابة إلى العقدة صفر.

SUBROUTINE PAR_BLAS2(m, n, a, b, c, comm)
REAL a(m), b(m,n)    ! شريحة محلية من المصفوفة
REAL c(n)            ! النتيجة
REAL sum(n)
INTEGER n, comm, i, j, ierr
! المجموع المحلي
DO j= 1, n
  sum(j) = 0.0
  DO i = 1, m
    sum(j) = sum(j) + a(i)*b(i,j)
  END DO
END DO
! المجموع العام
CALL MPI_REDUCE(sum, c, n, MPI_REAL, MPI_SUM, 0, comm, ierr)
! إعادة النتيجة إلى العقدة صفر (وقمامة في العقد الأخرى)
RETURN

استخدام خيار في المكان

عندما يكون المتواصل متواصلاً داخلياً، يمكنك إجراء عملية all-reduce في المكان (يتم استخدام مخزن الإخراج كمخزن إدخال).

استخدم المتغير MPI_IN_PLACE كقيمة لـ sendbuf في جميع العمليات.

لاحظ أن MPI_IN_PLACE هو نوع خاص من القيمة؛ له نفس القيود على استخدامه مثل MPI_BOTTOM.

نظرًا لأن خيار في المكان يحول مخزن الاستقبال إلى مخزن إرسال واستقبال، فإن ربط Fortran الذي يتضمن INTENT يجب أن يضع علامة عليه كـ INOUT، وليس OUT.

عندما يكون المتواصل متواصلاً خارجياً

عندما يكون المتواصل متواصلاً خارجياً، تحدث عملية الاختزال على مرحلتين. يتم اختزال البيانات من جميع أعضاء المجموعة الأولى واستقبالها من قبل جميع أعضاء المجموعة الثانية. ثم يتم اختزال البيانات من جميع أعضاء المجموعة الثانية واستقبالها من قبل جميع أعضاء المجموعة الأولى. تظهر العملية سلوكًا متماثلًا وشاملًا.

عندما يكون المتواصل متواصلاً داخلياً، تكون هاتان المجموعتان متماثلتين، وتحدث العملية في مرحلة واحدة.

ملاحظات على العمليات الجماعية

لا تعيد دوال الاختزال ( MPI_Op ) قيمة خطأ. نتيجة لذلك، إذا اكتشفت الدوال خطأ، فإن كل ما يمكنها فعله هو إما استدعاء MPI_Abort أو تخطي المشكلة بصمت. لذلك، إذا قمت بتغيير معالج الأخطاء من MPI_ERRORS_ARE_FATAL إلى شيء آخر، على سبيل المثال، MPI_ERRORS_RETURN، فقد لا يتم الإشارة إلى أي خطأ.

الأخطاء

تقريبًا جميع روتينات MPI تعيد قيمة خطأ؛ روتينات C كالنتيجة العائدة للدالة وروتينات Fortran في الوسيط الأخير.

قبل إعادة قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل المتواصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فيعتبر الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيستدعي معالج أخطاء MPI المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيط سطر الأوامر mpiexec الأولي info key إلى MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج أخطاء مناسب آخر، فسيتم استدعاء معالج الأخطاء MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الأخطاء MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء محددة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متواصل، نافذة، ملف، أو جلسة. عند استدعائه على متواصل، يعمل كما لو تم استدعاء MPI_Abort على هذا المتواصل. عند استدعائه على نافذة أو ملف، يعمل كما

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

SYNTAX

إذا تم استدعاء MPI_Abort على ميسّر اتصالات يحتوي على مجموعة العمليات في النافذة المقابلة أو في الملف المذكور. إذا تم استدعاؤه في جلسة، فإنه يقوم فقط بإلغاء العملية المحلية.

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو في MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

ملاحظة: لا تضمن MPI أن يتمكن برنامج MPI من الاستمرار بعد حدوث خطأ.

الوصف

تنشئ هذه الدالة ميسّر اتصالات جديدًا أو ملفًا أو جلسة أو نافذة من ميسّر اتصالات موجود أو ملف أو جلسة أو نافذة. يمكن استخدام المعلمة Comm كمدخل لإنشاء ميسّر اتصالات جديد، والمعلمات File و Session و Win كمدخلات لإنشاء ملف أو جلسة أو نافذة جديدة.

استخدام خيار المكان نفسه

يمكن استخدام خيار الاستخدام في المكان نفسه (in-place) لإنشاء ميسّر اتصالات جديد أو ملف أو جلسة أو نافذة من ميسّر اتصالات موجود أو ملف أو جلسة أو نافذة. يمكن استخدام المعلمة Comm كمدخل لإنشاء ميسّر اتصالات جديد، والمعلمات File و Session و Win كمدخلات لإنشاء ملف أو جلسة أو نافذة جديدة.

عندما يكون ميسّر الاتصالات ميسّر اتصالات متبادل

إذا كان ميسّر الاتصالات ميسّر اتصالات متبادلًا، فيمكن استخدام المعلمات Comm و File و Session و Win كمدخلات لإنشاء ميسّر اتصالات جديد أو ملف أو جلسة أو نافذة.
