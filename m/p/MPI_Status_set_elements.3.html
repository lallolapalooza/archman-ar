MPI_Status_set_elements(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_Status_set_elements(3) Open MPI MPI_Status_set_elements(3)

MPI_Status_set_elements, MPI_Status_set_elements_x - تعديل الجزء غير الشفاف من status للسماح لـ MPI_Get_elements بإرجاع count.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Status_set_elements(MPI_Status *status, MPI_Datatype datatype, int count)
int MPI_Status_set_elements_x(MPI_Status *status, MPI_Datatype datatype, MPI_Count count)

صيغة Fortran

USE MPI
! أو الصيغة القديمة: INCLUDE 'mpif.h'
MPI_STATUS_SET_ELEMENTS(STATUS, DATATYPE, COUNT, IERROR)
     INTEGER STATUS(MPI_STATUS_SIZE), DATATYPE, COUNT, IERROR
MPI_STATUS_SET_ELEMENTS_X(STATUS, DATATYPE, COUNT, IERROR)
     INTEGER STATUS(MPI_STATUS_SIZE), DATATYPE
        INTEGER(KIND=MPI_COUNT_KIND) COUNT
        INTEGER IERROR

صيغة Fortran 2008

USE mpi_f08
MPI_Status_set_elements(status, datatype, count, ierror)
     TYPE(MPI_Status), INTENT(INOUT) :: status
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER, INTENT(IN) :: count
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror
MPI_Status_set_elements_x(status, datatype, count, ierror)
     TYPE(MPI_Status), INTENT(INOUT) :: status
     TYPE(MPI_Datatype), INTENT(IN) :: datatype
     INTEGER(KIND = MPI_COUNT_KIND), INTENT(IN) :: count
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمة الإدخال/الإخراج

•
status: الحالة المراد ربطها بـ count (status).

معلمات الإدخال

  • datatype: نوع البيانات المرتبط بـ count (handle).
  • count: عدد العناصر المراد ربطها بـ status (integer).

معلمة الإخراج

•
ierror: حالة الخطأ في Fortran فقط: رمز الخطأ (integer).

الوصف

MPI_Status_set_elements تعدل الجزء غير الشفاف من status بطريقة تجعل استدعاء MPI_Get_elements أو MPI_Get_elements_x يرجع count. MPI_Get_count سترجع قيمة متوافقة.

يجب أن يستخدم استدعاء لاحق لـ MPI_Get_count(status, datatype, count), MPI_Get_elements(status, datatype, count) أو MPI_Get_elements_x(status, datatype, count) وسيط نوع بيانات له نفس التوقيع مثل وسيط نوع البيانات المستخدم في استدعاء MPI_Status_set_elements.*

ملاحظات

يجب أن يحذر المستخدمون من إعادة استخدام حقول الحالة لقيم خارج النطاق المتوقع. قد يؤدي هذا إلى نتائج غير متوقعة عند استخدام كائن الحالة. على سبيل المثال، قد يؤدي استدعاء MPI_Get_elements إلى خطأ إذا كانت القيمة خارج النطاق، أو قد لا يتم اكتشاف مثل هذا الخطأ. يمكن استخدام الوسيط extra_state المقدم مع طلب عام لإرجاع معلومات لا تنتمي منطقياً إلى الحالة. علاوة على ذلك، قد يؤدي تعديل القيم في حالة تم تعيينها داخليًا بواسطة MPI، مثل MPI_Recv، إلى نتائج غير قابلة للتنبؤ به وهو أمر غير مستحسن بشدة.

الأخطاء

تقوم معظم روتينات MPI بإرجاع قيمة خطأ؛ في روتينات C، تكون النتيجة هي القيمة المرجعة للدالة، وفي روتينات Fortran، المعلمة الأخيرة.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج الخطأ الحالي المرتبط بكائن الاتصال (مثل، المرسل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الخطأ المقابل. عندما لا يكون MPI_COMM_SELF مهيئًا (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا)، يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو الوسيط mpi_initial_errhandler لـ mpiexec أو مفتاح المعلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يكن هناك معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI و MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء افتراضية يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL: يوقف كل عملية MPI متصلة.
  • MPI_ERRORS_ABORT: معالج خطأ يمكن استدعاؤه على مرسل، نافذة، ملف، أو جلسة. عند استدعائه على مرسل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المرسل. إذا تم استدعاؤه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على مرسل يحتوي على مجموعة عمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، فإنه يوقف العملية المحلية فقط.
  • MPI_ERRORS_RETURN: يرجع رمز الخطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler و MPI_Comm_set_errhandler
  • MPI_File_create_errhandler و MPI_File_set_errhandler
  • MPI_Session_create_errhandler و MPI_Session_set_errhandler أو في MPI_Session_init
  • MPI_Win_create_errhandler و MPI_Win_set_errhandler

ملاحظة: لا يضمن MPI أن برنامج MPI يمكن أن يستمر بعد حدوث خطأ.
