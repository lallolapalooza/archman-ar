MPI_FILE_SET_VIEW(3) Open MPI MPI_FILE_SET_VIEW(3)

MPI_File_set_view — يغير عرض العملية للبيانات في الملف (تجميعي).

الصيغة

صيغة C

#include <mpi.h>
int MPI_File_set_view(MPI_File fh, MPI_Offset disp,
     MPI_Datatype etype, MPI_Datatype filetype,
     const char *datarep, MPI_Info info)

صيغة Fortran

USE MPI
! أو الصيغة الأقدم: INCLUDE 'mpif.h'
MPI_FILE_SET_VIEW(FH, DISP, ETYPE,
     FILETYPE, DATAREP, INFO, IERROR)
     INTEGER FH, ETYPE, FILETYPE, INFO, IERROR
     CHARACTER*(*)   DATAREP
     INTEGER(KIND=MPI_OFFSET_KIND)   DISP

صيغة Fortran 2008

USE mpi_f08
MPI_File_set_view(fh, disp, etype, filetype, datarep, info, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(IN) :: disp
     TYPE(MPI_Datatype), INTENT(IN) :: etype, filetype
     CHARACTER(LEN=*), INTENT(IN) :: datarep
     TYPE(MPI_Info), INTENT(IN) :: info
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معامل الإدخال/الإخراج

•
fh: معالج الملف (handle).

معاملات الإدخال

  • disp: الإزاحة (عدد صحيح).
  • etype: نوع البيانات الأولي (handle).
  • filetype: نوع الملف (handle). انظر القيود، أدناه.
  • datarep: تمثيل البيانات (سلسلة نصية).
  • info: كائن المعلومات (handle).

معامل الإخراج

•
ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

تقوم الروتين MPI_File_set_view بتغيير عرض العملية للبيانات في الملف — يبدأ الجزء الذي يمكن الوصول إليه في الملف من خلال هذا العرض بالقيمة disp؛ نوع البيانات هو etype؛ وتوزيع البيانات على العمليات هو filetype. بالإضافة إلى ذلك، تقوم MPI_File_set_view بإعادة تعيين مؤشرات الملف المستقلة ومؤشر الملف المشترك إلى الصفر. MPI_File_set_view هو إجراء تجميعي عبر fh؛ يجب على جميع العمليات في المجموعة تمرير قيم متطابقة لـ datarep وتوفير etype بامتداد متطابق. قد تختلف القيم لـ disp و filetype و info. من الخطأ استخدام روتينات الوصول إلى البيانات ذات المؤشر المشترك للملف ما لم يتم تقديم قيم متطابقة لـ disp و filetype. يجب أن تكون أنواع البيانات المقدمة في etype و filetype ملتزمة.

تحدد معامل الإزاحة disp الموضع (الإزاحة المطلقة بالبايت من بداية الملف) حيث يبدأ العرض.

تسمح واجهة MPI_File_set_view للمستخدم بتمرير سلسلة تمثيل بيانات إلى MPI I/O عبر المعامل datarep. للحصول على القيمة الافتراضية، مرر القيمة “native”. يمكن للمستخدم أيضًا تمرير معلومات عبر المعامل info. انظر قسم HINTS للحصول على قائمة بالتلميحات التي يمكن تعيينها.

تلميحات

يمكن استخدام التلميحات التالية كقيم للمعامل info.

تلميحات قابلة للتعيين

  • MPI_INFO_NULL
  • shared_file_timeout: مقدار الوقت (بالثواني) للانتظار للوصول إلى المؤشر المشترك للملف قبل الخروج مع MPI_ERR_TIMEDOUT.
  • rwlock_timeout: مقدار الوقت (بالثواني) للانتظار للحصول على قفل قراءة أو كتابة على جزء متصل من ملف UNIX قبل الخروج مع MPI_ERR_TIMEDOUT.
  • noncoll_read_bufsize: الحد الأقصى لحجم المخزن المؤقت المستخدم بواسطة MPI I/O لتلبية طلبات القراءة في روتينات الوصول إلى البيانات غير التجميعية.

    ملاحظة:

حجم مخزن مؤقت أصغر من المسافة (بالبايت) في ملف UNIX بين البايت الأول والأخير لطلب الوصول يتسبب في قيام MPI I/O بالتكرار وإجراء مكالمات read() أو write() متعددة في UNIX. إذا كان الطلب يتضمن أجزاء متعددة غير متصلة من البيانات، وكان حجم المخزن المؤقت أكبر من حجم تلك الأجزاء، فستصل مكالمة read() أو write() في UNIX (المصنوعة على مستوى MPI I/O) إلى بيانات لم يطلبها هذا المعالج لتقليل العدد الإجمالي لطلبات write() التي تم إجراؤها. إذا كان هذا سلوكًا غير مرغوب فيه، فيجب عليك تقليل حجم المخزن المؤقت هذا ليكون مساويًا لحجم الأجزاء المتصلة داخل الطلب المجمع.
  • noncoll_write_bufsize: الحد الأقصى لحجم المخزن المؤقت المستخدم بواسطة MPI I/O لتلبية طلبات الكتابة في روتينات الوصول إلى البيانات غير التجميعية.

    انظر الملاحظة أعلاه في noncoll_read_bufsize.

  • coll_read_bufsize: الحد الأقصى لحجم المخزن المؤقت المستخدم بواسطة MPI I/O لتلبية طلبات القراءة في روتينات الوصول إلى البيانات التجميعية.

    انظر الملاحظة أعلاه في noncoll_read_bufsize.

  • coll_write_bufsize: الحد الأقصى لحجم المخزن المؤقت المستخدم بواسطة MPI I/O لتلبية طلبات الكتابة في روتينات الوصول إلى البيانات التجميعية.

    انظر الملاحظة أعلاه في noncoll_read_bufsize.

  • mpiio_concurrency: (قيمة منطقية) تتحكم فيما إذا كانت روتينات الإدخال/الإخراج غير المتزامنة يمكنها ربط خيط إضافي بـ LWP.
  • mpiio_coll_contiguous: (قيمة منطقية) تتحكم فيما إذا كانت عمليات الوصول إلى البيانات التجميعية اللاحقة ستطلب مناطق متصلة تجميعيًا من الملف.

تلميحات غير قابلة للتعيين

•
filename: الوصول إلى هذا التلميح للحصول على اسم الملف.

الأخطاء

جميع روتينات MPI تقريبًا تعيد قيمة خطأ؛ روتينات C كالنتيجة الإرجاعية للدالة وروتينات Fortran في المعامل الأخير.

قبل إعادة قيمة الخطأ، يتم استدعاء معالج الخطأ MPI الحالي المرتبط بكيان الاتصال (مثل، المتحكم، النافذة، الملف). إذا لم يكن هناك كيان اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الخطأ MPI المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيط سطر الأوامر mpiexec لـ MPI_ERRORS_RETURN أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متحكم، نافذة، ملف، أو جلسة. عند استدعائه على متحكم، يعمل كما لو تم استدعاء MPI_Abort على ذلك المتحكم. عند استدعائه على نافذة أو ملف، يعمل كما لو تم استدعاء MPI_Abort على متحكم يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، يقوم بإنهاء العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات أخطاء خاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

MPI_File_set_view(3) — Open MPI 5.0.9

NAME

MPI_File_set_view - Sets the MPI file view.

SYNTAX

C

int MPI_File_set_view(MPI_File fh, MPI_Offset disp, MPI_Datatype datarep,
                      MPI_Datatype count, const char *filetype,
                      MPI_Info info);
int MPI_File_set_view_c(MPI_File fh, MPI_Offset disp, MPI_Datatype datarep,
                        MPI_Datatype count, MPI_Offset *array_of_displacements,
                        MPI_Info info);

Fortran

CALL MPI_FILE_SET_VIEW(FH, DISP, DATAREP, COUNT, FILETYPE, INFO,
                        IOERROR)

Fortran Old

CALL MPI_FILE_SET_VIEW(FH, DISP, DATAREP, COUNT, FILETYPE, INFO,
                        IOERROR)

INPUT/OUTPUT PARAMETER

fh
MPI file handle (input).
disp
Displacement in the file, relative to the beginning of the file (input).
datarep
MPI datatype describing the data (input).
count
array_of_displacements
Integer array specifying the displacements of the elements of the filetype in the file (input).
filetype
MPI datatype describing the file (input).
info
MPI info object (input).
ioerror
Fortran only: MPI status code (output).

INPUT PARAMETERS

fh
MPI file handle.
disp
Displacement in the file, relative to the beginning of the file.
datarep
MPI datatype describing the data.
count
Number of elements in the data.
filetype
MPI datatype describing the file.
info
MPI info object.

OUTPUT PARAMETER

ioerror
Fortran only: MPI status code.

DESCRIPTION

MPI_File_set_view sets the MPI file view. The file view defines how data is organized in the file. The view consists of a displacement, a datatype, and a filetype. The displacement is the offset in the file where the view begins. The datatype describes the basic data elements in the file, and the filetype describes the arrangement of these data elements in the file.

The displacement, datatype, and filetype are used to define the file's internal structure. The displacement is given in bytes from the beginning of the file. The datatype describes the elementary data type of each element in the file. The filetype describes the overall structure of the file, including any holes or noncontiguous data. The info object can be used to provide hints to the file system about how the file should be accessed.

The MPI-3.1 standard provides two routines for setting the file view:
MPI_File_set_view and MPI_File_set_view_c. The MPI_File_set_view routine uses MPI datatypes to describe the filetype, while MPI_File_set_view_c uses an array of displacements to describe the filetype. The latter routine is useful when the filetype is very complex or cannot be represented by a single MPI datatype.

HINTS

The MPI_Info object can be used to provide hints to the file system about how the file should be accessed. For example, the access_style hint can be used to specify whether the file should be accessed sequentially or randomly. The striping_unit hint can be used to specify the size of the stripe unit for parallel file systems.

ERRORS

When the MPI library detects an error, no MPI * error code is returned. Instead, the error handler attached to the communicator is called. The default error handler is MPI_ERRORS_ARE_FATAL, which causes the process to abort. In addition, the error code is saved in the global variable MPI_ERRNO for backward compatibility. For a full list of MPI error codes, see the MPI man page.

See the Error Handling section of the MPI-3.1 standard for more information.
