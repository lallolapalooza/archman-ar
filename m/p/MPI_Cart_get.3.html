MPI_Cart_get(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_CART_GET(3) Open MPI MPI_CART_GET(3)

MPI_Cart_get — استرجاع معلومات الطوبولوجيا الكارتيزية المرتبطة بمتصل.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Cart_get(MPI_Comm comm, int maxdims, int dims[], int periods[],
    int coords[])

صيغة Fortran

USE MPI
! أو الصيغة الأقدم: INCLUDE 'mpif.h'
MPI_CART_GET(COMM, MAXDIMS, DIMS, PERIODS, COORDS, IERROR)
    INTEGER COMM, MAXDIMS, DIMS(*), COORDS(*), IERROR
    LOGICAL PERIODS(*)

صيغة Fortran 2008

USE mpi_f08
MPI_Cart_get(comm, maxdims, dims, periods, coords, ierror)
    TYPE(MPI_Comm), INTENT(IN) :: comm
    INTEGER, INTENT(IN) :: maxdims
    INTEGER, INTENT(OUT) :: dims(maxdims), coords(maxdims)
    LOGICAL, INTENT(OUT) :: periods(maxdims)
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معاملات الإدخال

  • comm : متصل به هيكل كارتيزي (معالج).
maxdims
طول المتجهات dims، periods، و coords في البرنامج المستدعي (عدد صحيح).

معاملات الإخراج

•
dims
عدد العمليات لكل بعد كارتيزي (مصفوفة من الأعداد الصحيحة).
•
periods
دورية (صحيح/خطأ) لكل بعد كارتيزي (مصفوفة من القيم المنطقية).
•
coords
إحداثيات العملية المستدعية في الهيكل الكارتيزي (مصفوفة من الأعداد الصحيحة).
•
ierror : Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

الدالتان MPI_Cartdim_get و MPI_Cart_get تعيدان معلومات الطوبولوجيا الكارتيزية التي تم ربطها بمتصل بواسطة MPI_Cart_create.

الأخطاء

تقوم جميع روتينات MPI تقريبًا بإرجاع قيمة خطأ؛ وظائف C كناتج إرجاع للدالة ووظائف Fortran في المعامل الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج الخطأ MPI الحالي المرتبط بكائن الاتصال (مثل المتصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فيعتبر الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيستدعي معالج الخطأ MPI المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيطة سطر الأوامر mpi_initial_errhandler إلى mpiexec أو مفتاح المعلومات إلى MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف MPI I/O وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يؤدي إلى إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متصل، نافذة، ملف، أو جلسة. عند استدعائه على متصل، يعمل كما لو تم استدعاء MPI_Abort على هذا المتصل. إذا تم استدعاؤه على نافذة أو ملف، فإنه يعمل كما لو تم استدعاء MPI_Abort على متصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، فإنه ينهي العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات الأخطاء الخاصة بها عن طريق الاستدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا تضمن أن برنامج MPI يمكن أن يستمر بعد خطأ.
