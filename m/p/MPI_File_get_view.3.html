MPI_File_get_view(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_FILE_GET_VIEW(3) Open MPI MPI_FILE_GET_VIEW(3)

MPI_File_get_view — الحصول على عرض العملية للبيانات في الملف.

الصيغة

صيغة C

#include <mpi.h>
int MPI_File_get_view(MPI_File fh, MPI_Offset *disp,
     MPI_Datatype *etype, MPI_Datatype *filetype,
     char *datarep)

صيغة Fortran

USE MPI
! أو الشكل القديم: INCLUDE 'mpif.h'
MPI_FILE_GET_VIEW(FH, DISP, ETYPE,
     FILETYPE, DATAREP, IERROR)
     INTEGER FH, ETYPE, FILETYPE, IERROR
     CHARACTER*(*)   DATAREP
     INTEGER(KIND=MPI_OFFSET_KIND)   DISP

صيغة Fortran 2008

USE mpi_f08
MPI_File_get_view(fh, disp, etype, filetype, datarep, ierror)
     TYPE(MPI_File), INTENT(IN) :: fh
     INTEGER(KIND=MPI_OFFSET_KIND), INTENT(OUT) :: disp
     TYPE(MPI_Datatype), INTENT(OUT) :: etype, filetype
     CHARACTER(LEN=*), INTENT(OUT) :: datarep
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمة الإدخال

•
fh: مقبض الملف (handle).

معلمات الإخراج

  • disp: الإزاحة (integer).
  • etype: نوع البيانات الأولي (handle).
  • filetype: نوع الملف (handle). انظر القيود، أدناه.
  • datarep: تمثيل البيانات (string).
  • ierror: Fortran فقط: حالة الخطأ (integer).

الوصف

تقوم الدالة MPI_File_get_view بإرجاع عرض العملية للبيانات في الملف. يتم إرجاع القيم الحالية للإزاحة، etype، و filetype في disp, etype, و filetype، على التوالي.

تسمح واجهة MPI_File_get_view للمستخدم بتمرير سلسلة تمثيل البيانات عبر معلمة datarep.

الأخطاء

تقوم جميع دوال MPI تقريبًا بإرجاع قيمة خطأ؛ دوال C كنتيجة إرجاع للدالة ودوال Fortran في المعلمة الأخيرة.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (على سبيل المثال، المتصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فإن الاستدعاء يعتبر ملحقًا بـ MPI_COMM_SELF وسيستدعي معالج الأخطاء المعين. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو وسيطة سطر الأوامر mpi_initial_errhandler لـ mpiexec أو مفتاح معلومات لـ MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لدوال إدخال/إخراج MPI وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع دوال MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء محددة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متصل، نافذة، ملف، أو جلسة. عند استدعائه على متصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتصل. عند استدعائه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على متصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، يقوم بإنهاء العملية المحلية فقط.
  • MPI_ERRORS_RETURN يرجع رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات أخطاء خاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا تضمن أن برنامج MPI يمكن أن يستمر بعد حدوث خطأ.
