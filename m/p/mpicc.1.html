mpicc(1)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

FILES

The Open MPI wrapper compilers (e.g. mpicc, mpicxx, mpifort) are installed in the Open MPI installation’s bin directory. The exact location depends on how Open MPI was installed. The wrapper compilers are implemented by scripts which are installed in the same location.

The configuration information used by these wrapper scripts is stored in the Open MPI installation’s share/openmpi directory. Specifically, the scripts will look for files named:

  • openmpi-compiler-wrapper-data.txt
  • openmpi-compiler-wrapper-definitions.txt

These files contain configuration information, such as the paths to the underlying compilers and any compiler flags that were chosen during the Open MPI configuration process.

It is rarely necessary to edit these files, but they can be examined to gain insight into what flags the wrappers are placing on the command line.

متغيرات البيئة

افتراضيًا، تستخدم المغلِّفات المترجمات التي تم اختيارها عند تكوين Open MPI. تم العثور على هذه المترجمات تلقائيًا بواسطة نص "configure" الخاص بـ Open MPI، أو تم اختيارها بواسطة المستخدم في متغيرات البيئة CC و CXX و/أو FC قبل استدعاء configure. بالإضافة إلى ذلك، قد تكون تم تحديد وسائط أخرى خاصة بالمترجم بواسطة configure.

يمكن تجاوز هذه القيم بشكل انتقائي إما عن طريق تحرير ملفات النص التي تحتوي على معلومات التكوين هذه (انظر قسم الملفات)، أو عن طريق تعيين متغيرات البيئة المختارة بالشكل ompi_value.

أسماء القيم الصالحة هي:

  • CPPFLAGS: العلامات التي تتم إضافتها عند استدعاء المعالج المسبق (C أو C++)
  • LDFLAGS: العلامات التي تتم إضافتها عند استدعاء الرابط (C أو C++ أو Fortran)
  • LIBS: المكتبات التي تتم إضافتها عند استدعاء الرابط (C أو C++ أو Fortran)
  • CC: مترجم C
  • CFLAGS: علامات مترجم C
  • CXX: مترجم C++
  • CXXFLAGS: علامات مترجم C++
  • FC: مترجم Fortran
  • FCFLAGS: علامات مترجم Fortran
