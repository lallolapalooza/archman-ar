MPIX_Comm_agree

MPI Commands

NAME

MPIX_Comm_agree - Checks for process failures and failures in communicators.

SYNTAX

int MPIX_Comm_agree(MPI_Comm comm);

INPUT PARAMETERS

‐ comm
The communicator in which to check for failures (handle).

OUTPUT PARAMETERS

None.

DESCRIPTION

The MPIX_Comm_agree() function checks for process failures and failures in communicators.

This function is intended to be used as a mechanism for detecting failures in MPI applications.

When MPIX_Comm_agree() is called, all processes in the communicator comm must call it. The function will return an error code of MPI_ERR_PROC_FAILED if any processes in the communicator have failed. Otherwise, it will return MPI_SUCCESS.

The function returns MPI_ERR_REVOKED if the communicator has been revoked.

The function returns MPI_ERR_INTERN if the communicator is an inter-communicator.

The function returns MPI_ERR_ARG if the communicator is invalid.

PROCESS FAILURES

When a process fails, the MPI implementation marks the process as failed. Subsequent operations involving the failed process may return MPI_ERR_PROC_FAILED. MPIX_Comm_agree() provides a way to detect these failures.

WHEN THE COMMUNICATOR CONTAINS ACKNOWLEDGED FAILURES

If a process in the communicator has already been acknowledged as failed, MPIX_Comm_agree() will return MPI_ERR_PROC_FAILED.

WHEN THE COMMUNICATOR IS REVOKED

If the communicator has been revoked using MPI_Comm_revoke, MPIX_Comm_agree() will return MPI_ERR_REVOKED.

WHEN COMMUNICATOR IS AN INTER-COMMUNICATOR

If the communicator is an inter-communicator, MPIX_Comm_agree() will return MPI_ERR_INTERN.

ERRORS

When the communicator contains failed processes, MPI_ERR_PROC_FAILED is returned.

When the communicator has been revoked, MPI_ERR_REVOKED is returned.

When the communicator is an inter-communicator, MPI_ERR_INTERN is returned.

When the communicator is invalid, MPI_ERR_ARG is returned.

A typical use case is to detect process failures and then handle them appropriately, possibly by continuing the computation with the remaining processes if the MPI implementation supports it.

See the MPI man page for a full list of MPI error codes.

See the Error Handling section of the MPI-3.1 standard for more information.
