DESCRIPTION

\n

This function is a non-blocking version of MPI_Reduce_scatter_block. It is identical to MPI_Reduce_scatter_block except that it returns immediately with a request handle. The operation is then completed asynchronously in the background. The request handle can be used with MPI_Wait or MPI_Test to check for completion.

\n

This function allows for overlapping communication and computation.

\n

The arguments comm, sendbuf, recvbuf, recvcount, datatype, op, and info are the same as for MPI_Reduce_scatter_block.

\n

The argument request is the handle of the request associated with the operation.

\n
\n\n
\n

USE OF IN-PLACE OPTION

\n

When the communicator is a Cartesian communicator, a communicator for a global process group, or a derived communicator, then the in-place collective operation is available. The in-place option indicates that the receive buffer is the same buffer as the send buffer. MPI_IN_PLACE is a special sendbuf value that indicates this. When MPI_IN_PLACE is specified for sendbuf, the value of recvbuf is significant and is used as the starting address of the buffer where the result is to be stored.

\n
\n\n
\n

WHEN COMMUNICATOR IS AN INTER-COMMUNICATOR

\n

When the communicator is an inter-communicator, then the receive buffer on the processes in the left communicator, and the send buffer on the processes in the right communicator, must contain values of recvcount elements. The result is placed in the receive buffer on the processes in the left communicator.

\n
\n\n
\n

NOTES ON COLLECTIVE OPERATIONS

\n

To use a user-defined operation, the call MPI_Op_create must be used to create it, and MPI_Op_free to free it. The operation must be commutative if MPI_Reduce_scatter_block_init is invoked on a non-communicating communicator.

\n

For the MPI_Reduce_scatter_block_init operation, MPI_Info allows the user to specify hints that may optimize the performance of the operation. The possible hints are implementation-dependent.

\n

When the info argument is MPI_INFO_NULL, no hints are provided.
