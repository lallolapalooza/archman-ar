MPI_Intercomm_create_from_groups(3)

MPI_Intercomm_create_from_groups - Creates an intercommunicator from two groups.

LIBRARY

MPI

SYNOPSIS

#include <mpi.h>
int MPI_Intercomm_create_from_groups(MPI_Group group1, MPI_Group group2,
                                     MPI_Comm comm1, MPI_Comm comm2,
                                     MPI_Info info, MPI_Request *request,
                                     MPI_Comm *intercomm);

DESCRIPTION

MPI_Intercomm_create_from_groups() creates a new intercommunicator. An intercommunicator is a communicator that supports communication between two distinct groups of processes. The two groups are specified by group1 and group2, and the two communicators that provide the context for the groups are comm1 and comm2.

The communicator comm1 must contain all processes in group1. The communicator comm2 must contain all processes in group2. The intersection of the processes in comm1 and comm2 must be empty.

The processes in group1 will form one endpoint of the intercommunicator, and the processes in group2 will form the other endpoint.

The info argument can be used to provide hints to the MPI implementation about how to create the intercommunicator.

The request argument is used to specify a handle for the pending communication, which is returned by the function. The intercomm argument is used to specify the handle for the newly created intercommunicator.

RETURN VALUE

MPI_SUCCESS on success. An error code on failure.

NOTES

This function is a non-blocking version of MPI_Intercomm_create().

SEE ALSO

MPI_Intercomm_create(3), MPI_Comm_create_group(3), MPI_Comm_split_type(3)

ERRORS

When the value of the error handler attached to the communicator is MPI_ERRORS_ARE_FATAL, then the MPI program is terminated when MPI_Intercomm_create_from_groups() fails.

When the value of the error handler attached to the communicator is MPI_ERRORS_RETURN, then the return value of MPI_Intercomm_create_from_groups() is the error code returned as the value of the error variable of the called function.

Otherwise, the error handler is called.
