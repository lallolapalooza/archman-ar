MPI_Bsend(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_BSEND(3) Open MPI MPI_BSEND(3)

MPI_Bsend — إرسال أساسي مع تخزين مؤقت محدد بواسطة المستخدم.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Bsend(const void *buf, int count, MPI_Datatype datatype,
   int dest, int tag, MPI_Comm comm)

صيغة Fortran

USE MPI
! أو الصيغة الأقدم: INCLUDE 'mpif.h'
MPI_BSEND(BUF, COUNT,DATATYPE, DEST, TAG, COMM, IERROR)
    <type>  BUF(*)
    INTEGER COUNT, DATATYPE, DEST, TAG, COMM, IERROR

صيغة Fortran 2008

USE mpi_f08
MPI_Bsend(buf, count, datatype, dest, tag, comm, ierror)
    TYPE(*), DIMENSION(..), INTENT(IN) :: buf
    INTEGER, INTENT(IN) :: count, dest, tag
    TYPE(MPI_Datatype), INTENT(IN) :: datatype
    TYPE(MPI_Comm), INTENT(IN) :: comm
    INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمات الإدخال

  • buf: العنوان الأولي لمخزن الإرسال (اختياري).
  • count: عدد العناصر في مخزن الإرسال (عدد صحيح غير سالب).
  • datatype: نوع بيانات كل عنصر في مخزن الإرسال (مقبض).
  • dest: رتبة الوجهة (عدد صحيح).
  • tag: علامة الرسالة (عدد صحيح).
  • comm: المتواصل (مقبض).

معلمات الإخراج

•
ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Bsend تنفذ إرسالًا بوضع مخزن مؤقت، إيقافي.

ملاحظات

تم توفير هذا الإرسال كوظيفة مريحة؛ فهو يسمح للمستخدم بإرسال رسائل دون القلق بشأن مكان تخزينها مؤقتًا (لأن المستخدم يجب أن يكون قد وفر مساحة تخزين مؤقتة مع MPI_Buffer_attach).

عند تحديد مقدار مساحة التخزين المؤقت التي يجب تخصيصها، تذكر أن مساحة التخزين المؤقت ليست متاحة لإعادة الاستخدام بواسطة MPI_Bsends لاحقة ما لم تكن متأكدًا من أن الرسالة قد تم استلامها (وليس فقط أنه كان يجب استلامها). على سبيل المثال، هذا الكود لا يخصص مساحة تخزين مؤقت كافية:

MPI_Buffer_attach( b, n*sizeof(double) + MPI_BSEND_OVERHEAD );
for (i=0; i<m; i++) {
    MPI_Bsend( buf, n, MPI_DOUBLE, ... );
}

لأن مساحة التخزين المؤقت المخصصة تكفي لإرسال واحد فقط، وقد تبدأ الحلقة إرسال MPI_Bsend ثانٍ قبل اكتمال الأول في استخدام المخزن المؤقت.

في C، يمكنك فرض تسليم الرسائل بواسطة MPI_Buffer_detach( &b, &n ); MPI_Buffer_attach( b, n ); (لن يكتمل MPI_Buffer_detach حتى يتم تسليم جميع الرسائل المخزنة مؤقتًا).

الأخطاء

تقريبًا جميع روتينات MPI ترجع قيمة خطأ؛ روتينات C كنتيجة إرجاع للدالة وروتينات Fortran في المعلمة الأخيرة.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل المتواصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط بمكالمة MPI، فسيتم اعتبار المكالمة متصلة بـ MPI_COMM_SELF وسيتم استدعاء معالج أخطاء MPI المرتبط. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو الوسيطة CLI mpi_initial_errhandler إلى mpiexec أو مفتاح المعلومات إلى MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI، وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يتضمن Open MPI ثلاثة معالجات أخطاء معرفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متواصل، نافذة، ملف، أو جلسة. عند استدعائه على متواصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتواصل. إذا تم استدعاؤه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على متواصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، فإنه ينهي العملية المحلية فقط.
  • MPI_ERRORS_RETURN يرجع رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات أخطاء خاصة بها عن طريق الاستدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو عند MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا تضمن أن برنامج MPI يمكن أن يستمر بعد حدوث خطأ.
