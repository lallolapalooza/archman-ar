MPIX_Query_rocm_support(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPIX_Query_rocm_support(3) Open MPI MPIX_Query_rocm_support(3)

MPIX_Query_rocm_support - تُرجع 1 إذا كان هناك دعم مدرك لـ AMD ROCm و 0 إذا لم يكن هناك.

الصيغة

صيغة C

#include <mpi.h>
#include <mpi-ext.h>
int MPIX_Query_rocm_support(void)

صيغة Fortran

لا توجد ربطة Fortran لهذه الوظيفة.

صيغة C++

لا توجد ربطة C++ لهذه الوظيفة.

الوصف

هذه الوظيفة هي جزء من امتداد Open MPI؛ وهي ليست جزءًا من MPI القياسي.

ترجع هذه الروتينية 1 إذا تم بناء مكتبة MPI مع مكتبة AMD ROCm وأن وقت التشغيل يدعم مخازن ROCm. بخلاف ذلك، فإنها ترجع 0. يجب استدعاء هذه الروتينية بعد تهيئة MPI، على سبيل المثال، عن طريق استدعاء MPI_Init(3) أو MPI_Init_thread(3).

يتضمن ملف <mpi-ext.h> الخاص بـ Open MPI، تعريف الماكرو المسبق للمعالج OMPI_HAVE_MPI_EXT إلى 1. بخلاف ذلك، سيتم إلغاء تعريفه. يمكن للتطبيقات استخدام هذا الماكرو كعلامة لمعرفة ما إذا كان قد تم تضمين <mpi-ext.h> أم لا.

يتم بناء امتداد ROCm الخاص بـ Open MPI افتراضيًا (بغض النظر عما إذا كان Open MPI قد تم بناؤه مع دعم ROCm أم لا)، ولكن كان يمكن تعطيله بإجراء إداري. لذلك، من الأسلم للتطبيقات التحقق من أن الماكرو المسبق للمعالج OMPI_HAVE_MPI_EXT_ROCM معرف وأن قيمته 1 لمعرفة ما إذا كانت الوظيفة MPIX_Query_rocm_support() متاحة. كما أن التحقق من هذا الماكرو يحمي استخدام هذه الوظيفة عند تجميع التطبيق مع إصدارات أقدم من Open MPI أو تطبيقات MPI أخرى لا تحتوي على هذه الوظيفة.

أمثلة

#include <stdio.h>
#include <mpi.h>
#include <mpi-ext.h> /* ضروري لفحص ROCm المدرك */
int main(int argc, char *argv[])
{
    MPI_Init(&argc, &argv);
    bool happy = false;
#if defined(OMPI_HAVE_MPI_EXT_ROCM) && OMPI_HAVE_MPI_EXT_ROCM
    happy = (bool) MPIX_Query_rocm_support();
#endif
    if (happy) {
        printf("This Open MPI installation has ROCm-aware support.\n");
    } else {
        printf("This Open MPI installation does not have ROCm-aware support.\n");
    }
    MPI_Finalize();
    return 0;
}
