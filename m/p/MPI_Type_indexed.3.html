MPI_Type_indexed(3) Open MPI MPI_Type_indexed(3)

MPI_Type_indexed, MPI_Type_create_hindexed - إنشاء نوع بيانات مفهرس.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Type_indexed(int count, const int array_of_blocklengths[],
     const int array_of_displacements[], MPI_Datatype oldtype,
     MPI_Datatype *newtype)
int MPI_Type_create_hindexed(int count,
     const int array_of_blocklengths[],
     const MPI_Aint array_of_displacements[], MPI_Datatype oldtype,
     MPI_Datatype *newtype)

صيغة Fortran

USE MPI
! أو الطريقة القديمة: INCLUDE 'mpif.h'
MPI_TYPE_INDEXED(COUNT, ARRAY_OF_BLOCKLENGTHS,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, ARRAY_OF_BLOCKLENGTHS(*)
     INTEGER ARRAY_OF_DISPLACEMENTS(*), OLDTYPE, NEWTYPE
     INTEGER IERROR
MPI_TYPE_CREATE_HINDEXED(COUNT, ARRAY_OF_BLOCKLENGTHS,
             ARRAY_OF_DISPLACEMENTS, OLDTYPE, NEWTYPE, IERROR)
     INTEGER COUNT, ARRAY_OF_BLOCKLENGTHS(*)
     INTEGER OLDTYPE, NEWTYPE
     INTEGER(KIND=MPI_ADDRESS_KIND) ARRAY_OF_DISPLACEMENTS(*)
     INTEGER IERROR

صيغة Fortran 2008

USE mpi_f08

     array_of_displacements(count)

MPI_Type_create_hindexed(count, array_of_blocklengths,

     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) ::
     array_of_displacements(count)

     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمات الإدخال

  • count: عدد الكتل - أيضًا عدد الإدخالات في array_of_displacements و array_of_blocklengths (عدد صحيح غير سالب).
  • array_of_blocklengths: عدد العناصر لكل كتلة (مصفوفة أعداد صحيحة غير سالبة).
  • array_of_displacements: إزاحة كل كتلة، بالوحدات القياسية لنوع البيانات القديم لـ MPI_Type_indexed وبالبايت لـ MPI_Type_create_hindexed (مصفوفة أعداد صحيحة لـ MPI_TYPE_INDEXED، مصفوفة MPI_Aint لـ MPI_TYPE_CREATE_HINDEXED).
  • oldtype: نوع البيانات القديم (مقبض).

معلمات الإخراج

  • newtype: نوع البيانات الجديد (مقبض).
  • ierror: في Fortran فقط: رمز الخطأ (عدد صحيح).

الوصف

تسمح الدالة MPI_Type_indexed بتكرار نوع بيانات قديم في تسلسل من الكتل (كل كتلة هي تسلسل للنوع القديم)، حيث يمكن أن تحتوي كل كتلة على عدد مختلف من النسخ وأن يكون لها إزاحة مختلفة. جميع إزاحات الكتل هي مضاعفات للامتداد النوعي للبيانات القديم.

مثال: افترض أن النوع القديم لديه نوع خريطة {(double, 0), (char, 8)}، بامتداد 16. لتكن B = (3, 1) و D = (4, 0). يؤدي استدعاء MPI_Type_indexed(2, B, D, oldtype, newtype) إلى إرجاع نوع بيانات له نوع خريطة

{(double, 64), (char, 72), (double, 80), (char, 88),
(double, 96), (char, 104),
(double, 0), (char, 8)}

وهذا يعني، ثلاث نسخ من النوع القديم تبدأ عند الإزاحة 4 × 16 = 64، ونسخة واحدة تبدأ عند الإزاحة 0.

بشكل عام، افترض أن النوع القديم لديه نوع خريطة

{(type(0), disp(0)), ..., (type(n-1), disp(n-1))},
مع امتداد ex. لتكن B مصفوفة طول الكتلة و D مصفوفة الإزاحات. النوع الجديد لديه
n × S ^count-1
    i = 0           B[i]  إدخالات:
    {(type(0), disp(0) + D[0] * ex), ...,
    (type(n-1), disp(n-1) + D[0] * ex), ...,
    (type(0), disp(0) + (D[0] + B[0] -1) * ex), ...,
    (type(n-1), disp(n-1) + (D[0] + B[0] -1) * ex), ...,
    (type(0), disp(0) + D[count-1] * ex), ...,
    (type(n-1), disp(n-1) + D[count-1] * ex), ...,
    (type(0), disp(0) +  (D[count-1] + B[count-1] -1) * ex), ...,
    (type(n-1), disp(n-1) + (D[count-1] + B[count-1] -1) * ex)}

استدعاء MPI_Type_vector(count, blocklength, stride, oldtype, newtype) يعادل استدعاء MPI_Type_indexed(count, B, D, oldtype, newtype) حيث

    D[j] = j * stride, j = 0,..., count-1
و
    B[j] = blocklength, j = 0, .., count-1

الدالة MPI_Type_create_hindexed مطابقة لـ MPI_Type_indexed، باستثناء أن إزاحات الكتل في array_of_displacements محددة بالبايت، وليس بمضاعفات امتداد النوع القديم.

الأخطاء

معظم روتينات MPI تعيد قيمة خطأ؛ في روتينات C، تكون النتيجة هي قيمة الإرجاع للدالة، وفي روتينات Fortran، في المعلمة الأخيرة.

قبل إعادة قيمة الخطأ، يتم استدعاء معالج الخطأ المرتبط بكائن الاتصال (على سبيل المثال، المتصل، النافذة، الملف) الحالي. إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، يعتبر الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيتم استدعاء معالج الخطأ المرتبط بـ MPI_COMM_SELF. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسة فقط)، فإن الخطأ يؤدي إلى معالج الخطأ الأولي. يمكن تغيير المعالج الأولي للخطأ عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو مفتاح المعلومات mpi_initial_errhandler الخاص بـ mpiexec أو MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تكوين أي معالج خطأ آخر مناسب، يتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI ومعالج الخطأ MPI_ERRORS_ABORT لوظائف MPI الأخرى.

تتضمن Open MPI ثلاثة معالجات خطأ افتراضية يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إنهاء البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على متصل، نافذة، ملف، أو جلسة. عند استدعائه على متصل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المتصل. إذا تم استدعاؤه على نافذة أو ملف، فإنه يتصرف كما لو تم استدعاء MPI_Abort على متصل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. إذا تم استدعاؤه على جلسة، يتم إيقاف العملية المحلية فقط.
  • MPI_ERRORS_RETURN يعيد رمز خطأ إلى التطبيق.

يمكن للتطبيقات MPI أيضًا تنفيذ معالجات خطأ خاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو أثناء MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

ملاحظة: لا يضمن MPI أن البرنامج MPI يمكن أن يستمر بعد حدوث خطأ.
