Track Options

Options:

-new-tkid

force track ID creation, not use default or provided one
-tkid tkID=ID

set the track ID to ID
-add FILE[:OPTIONS]

add a new track from FILE, see below for OPTIONS
-dup tkID=ID[:OPTIONS]

duplicate existing track ID
-del tkID

delete track ID
-chg tkID=ID

change track ID to ID
-in tkID=FILE[:START[:DURATION]]

set input file and range for track ID
-out tkID=FILE[:OPTIONS]

set output file and options for track ID
-srate tkID=STRING

set track sample rate
-lang tkID=LANG

set track language (3 letter code, see ISO-639-2)
-desc tkID=STRING

set track description (UTF-8 string)
-par tkID=PAR

set visual track pixel aspect ratio. PAR is:
* N:D: set PAR to N:D in track, do not modify the bitstream
* wN:D: set PAR to N:D in track and try to modify the bitstream
* none: remove PAR info from track, do not modify the bitstream
* auto: retrieve PAR info from bitstream and set it in track
* force: force 1:1 PAR in track, do not modify the bitstream
-clap tkID=CLAP

set visual track clean aperture. CLAP is Wn,Wd,Hn,Hd,HOn,HOd,VOn,VOd or none
* n, d: numerator, denominator
* W, H, HO, VO: clap width, clap height, clap horizontal offset, clap vertical offset
-mx tkID=MX

set track matrix, with MX is M1:M2:M3:M4:M5:M6:M7:M8:M9 in 16.16 fixed point integers or hexa
-kind tkID=schemeURI=value

set kind for the track or for all tracks using all=schemeURI=value
-kind-rem tkID=schemeURI=value

remove kind if given schemeID for the track or for all tracks with all=schemeURI=value
-name tkID=NAME

set track handler name to NAME (UTF-8 string)
-tags,-itags (string)

set iTunes tags to file, see -h tags
-group-add (string)

create a new grouping information in the file. Format is a colon-separated list of following options:
* refTrack=ID: track used as a group reference. If not set, the track will belong to the same group as the previous trackID specified. If 0 or no previous track specified, a new alternate group will be created
* switchID=ID: ID of the switch group to create. If 0, a new ID will be computed for you. If <0, disables SwitchGroup
* criteria=string: list of space-separated 4CCs
* trackID=ID: track to add to this group

Warning: Options modify state as they are parsed, trackID=1:criteria=lang:trackID=2 is different from criteria=lang:trackID=1:trackID=2

-group-rem-track (int)

remove given track from its group
-group-rem (int)

remove the track's group
-group-clean

remove all group information from all tracks
-ref tkID:R4CC:refID

add a reference of type R4CC from track ID to track refID (remove track reference if refID is 0)
-keep-utc

keep UTC timing in the file after edit
-udta tkID:[OPTS]

set udta for given track or movie if tkID is 0. OPTS is a colon separated list of:
* type=CODE: 4CC code of the UDTA (not needed for box= option)
* box=FILE: location of the udta data, formatted as serialized boxes
* box=base64,DATA: base64 encoded udta data, formatted as serialized boxes
* src=FILE: location of the udta data (will be stored in a single box of type CODE)
* src=base64,DATA: base64 encoded udta data (will be stored in a single box of type CODE)
* str=STRING: use the given string as payload for the udta box
Note: If no source is set, UDTA of type CODE will be removed
-patch [tkID=]FILE

apply box patch described in FILE, for given trackID if set
-bo

freeze the order of boxes in input file
-init-seg (string)

use the given file as an init segment for dumping or for encryption
-zmov

compress movie box according to ISOBMFF box compression or QT if mov extension
-xmov

same as zmov and wraps ftyp in otyp
-edits tkID=EDITS

set edit list. The following syntax is used (no separators between entries):
* `r`: removes all edits
* `eSTART`: add empty edit with given start time. START can be
- VAL: start time in seconds (int, double, fraction), media duration used as edit duration
- VAL-DUR: start time and duration in seconds (int, double, fraction)
* `eSTART,MEDIA[,RATE]`: add regular edit with given start, media start time in seconds (int, double, fraction) and rate (fraction or INT)
* Examples:
- re0-5e5-3,4: remove edits, add empty edit at 0s for 5s, then add regular edit at 5s for 3s starting at 4s in media track
- re0-4,0,0.5: remove edits, add single edit at 0s for 4s starting at 0s in media track and playing at speed 0.5
-moovpad (int)

specify amount of padding to keep after moov box for later inplace editing - if 0, moov padding is disabled
-no-inplace

disable inplace rewrite
-hdr (string)

update HDR information based on given XML, 'none' removes HDR info
-time [tkID=]DAY/MONTH/YEAR-H:M:S

set movie or track creation time
-mtime tkID=DAY/MONTH/YEAR-H:M:S

set media creation time

Extracting Options

MP4Box can be used to extract media tracks from MP4 files. If you need to convert these tracks however, please check the filters doc.

Options:

-raw (string)

extract given track in raw format when supported. Use tkID:output=FileName to set output file name
-raws (string)

extract each sample of the given track to a file. Use tkID:N to extract the Nth sample
-nhnt (int)

extract given track to NHNT format
-nhml (string)

extract given track to NHML format. Use tkID:full for full NHML dump with all packet properties
-webvtt-raw (string)

extract given track as raw media in WebVTT as metadata. Use tkID:embedded to include media data in the WebVTT file
-single (int)

extract given track to a new mp4 file
-six (int)

extract given track as raw media in experimental XML streaming instructions
-mux (string)

multiplex input file to given destination
-qcp (int)

same as .I raw but defaults to QCP file for EVRC/SMV
-saf

multiplex input file to SAF multiplex
-dvbhdemux

-raw-layer (int)

same as .I raw but skips SVC/MVC/LHVC extractors when extracting

Specifying input files

Input media files to dash can use the following modifiers
* #trackID=N: only use the track ID N from the source file
* #N: only use the track ID N from the source file (mapped to .I -tkid)
* #video: only use the first video track from the source file
* #audio: only use the first audio track from the source file
* :id=NAME: set the representation ID to NAME. Reserved value NULL disables representation ID for multiplexed inputs. If not set, a default value is computed and all selected tracks from the source will be in the same output multiplex.
* :dur=VALUE: process VALUE seconds (fraction) from the media. If VALUE is longer than media duration, last sample duration is extended.

تقسيم الملف

يمكن لـ MP4Box تقسيم الملفات المدخلة حسب الحجم أو المدة أو استخراج جزء معين من الملف إلى ملفات IsoMedia جديدة.
يتطلب هذا أن يكون لدى مسار واحد على الأكثر في الملف المدخل نقاط وصول عشوائي غير صحيحة (عادةً مسار فيديو واحد على الأكثر).
سيتجاهل التقسيم جميع مسارات MPEG-4 Systems ومسارات التلميحات، ولكنه سيحاول تقسيم مسارات الوسائط الخاصة.
يجب أن يحتوي الملف المدخل على نقاط وصول عشوائي كافية ليتم تقسيمه. إذا لم يكن الأمر كذلك، فسيتعين عليك إعادة ترميز المحتوى.
يمكنك إضافة وسائط إلى ملف وتقسيمه في نفس العملية. في هذه الحالة، لن يتم تخزين الملف الوجهة (الملف الذي سيتم الحصول عليه بدون تقسيم).

يتم تحديد نطاقات الوقت على النحو التالي:
* `S-E`: وقت البدء S ووقت الانتهاء E، بتنسيق HH:MM:SS.ms أو MM:SS.ms أو الوقت بالثواني (int، double، fraction)
* `S:E`: وقت البدء S ووقت الانتهاء E بالثواني (int، double، fraction). إذا كان E مسبوقًا بـ D، فإن هذا يعين E = S + time
* `S:end` أو `S:end-N`: وقت البدء S بالثواني (int، double)، N عدد الثواني (int، double) قبل النهاية

يقوم MP4Box بتقسيم الملفات بتشغيل جلسة تصفية باستخدام مرشح reframer على النحو التالي:
- يتم دائمًا تعيين خيار splitrange للمرشح. - يتم فك تعدد المصدر باستخدام خيار alltk. - يتم تمرير نطاقات البدء والنهاية إلى خيارات xs و xe للمرشح. - بالنسبة لـ -splitz، يتم فرض خيارات xadjust و xround=after. - بالنسبة لـ -splitg، يتم فرض خيارات xadjust و xround=before. - بالنسبة لـ -splitf، يتم فرض خيار xround=seek و propbe_refset إذا لم يتم تحديده عند المطالبة. - بالنسبة لـ -splitx، يتم فرض خيار xround=closest و propbe_ref إذا لم يتم تحديده عند المطالبة.

وضع التخزين الافتراضي للمخرجات هو التداخل الكامل وسيتطلب ملفًا مؤقتًا لكل مخرج. يمكن تعديل هذا السلوك باستخدام -flat، -newfs، -inter و -frag.
يمكن تحديد أسماء ملفات المخرجات باستخدام -out والقوالب (على سبيل المثال، -out split$num%04d$.mp4 ينتج split0001.mp4، split0002.mp4، ...).
يمكن تحديد نطاقات زمنية متعددة كقائمة مفصولة بفواصل لـ -splitx، -splitz و -splitg.

-split (string)

تقسيم إلى ملفات بمدة قصوى محددة (رقم عشري) بالثواني. يمكن تحديد وحدة لاحقة:
* `M`, `m`: المدة بالدقائق
* `H`, `h`: المدة بالساعات
-split-rap,-splitr (string)

تقسيم إلى ملفات عند كل RAP جديد
-split-size,-splits (string)

تقسيم إلى ملفات بحجم أقصى محدد (رقم صحيح) بالكيلوبايت. يمكن تحديد وحدة لاحقة:
* `M`, `m`: الحجم بالميجابايت
* `G`, `g`: الحجم بالجيجابايت
-split-chunk,-splitx (string)

استخراج نطاق الوقت المحدد على النحو التالي:
- يتم نقل وقت البدء إلى أقرب عينة RAP إلى وقت البدء المحدد
- يبقى وقت الانتهاء كما هو مطلوب
-splitz (string)

استخراج نطاق الوقت المحدد بحيث تشترك النطاقات A:B و B:C في نفس الحد B بالضبط:
- يتم نقل وقت البدء إلى عينة RAP عند وقت البدء المحدد أو بعده
- يتم نقل وقت الانتهاء إلى الإطار السابق لعينة RAP عند وقت الانتهاء المحدد أو بعده
-splitg (string)

استخراج نطاق الوقت المحدد على النحو التالي:
- يتم نقل وقت البدء إلى عينة RAP عند وقت البدء المحدد أو قبله
- يتم نقل وقت الانتهاء إلى الإطار السابق لعينة RAP عند وقت الانتهاء المحدد أو بعده
-splitf (string)

استخراج نطاق الوقت المحدد وإدراج تعديلات بحيث يكون المخرج المستخرج هو النطاق المحدد بالضبط

خيارات الاستيراد

استيراد الملفات

الصيغة هي .I add / .I cat URL[#FRAGMENT][:opt1...:optN=val]
ستقوم هذه العملية بإنشاء الملف الوجهة إذا لم يكن موجودًا، وإضافة المسار (المسارات) إليه. إذا كنت ترغب دائمًا في إنشاء ملف وجهة جديد، أضف .I -new.
أنواع الوسائط المدعومة تعتمد على تثبيتك، تحقق من وثائق المرشحات لمزيد من المعلومات.

لتحديد مسار وسائط مرغوب فيه من مصدر، يمكن تحديد معرف تجزئة '#'، قبل أي خيارات أخرى. يتم استخدام الصيغة التالية:
* `#video`: يضيف أول مسار فيديو تم العثور عليه في المصدر
* `#audio`: يضيف أول مسار صوتي تم العثور عليه في المصدر
* `#auxv`: يضيف أول مسار فيديو مساعد تم العثور عليه في المصدر
* `#pict`: يضيف أول مسار صور تم العثور عليه في المصدر
* `#trackID=ID` أو `#ID`: يضيف المسار المحدد. بالنسبة لملفات IsoMedia، ID هو معرف المسار. بالنسبة لملفات الوسائط الأخرى، ID هو القيمة المشار إليها بواسطة MP4Box -info inputFile
* `#pid=ID`: رقم PID المطلوب لمصادر MPEG-2 TS
* `#prog_id=ID`: رقم البرنامج المطلوب لمصادر MPEG-2 TS
* `#program=NAME`: اسم البرنامج المطلوب لمصادر MPEG-2 TS

افتراضيًا، تتم جميع عمليات الاستيراد بشكل تسلسلي، ويتم القيام بالتشابك النهائي في النهاية؛ ومع ذلك، يتطلب هذا ملفًا مؤقتًا يحتوي على ملف ISOBMF الأصلي (إذا كان موجودًا) والملفات المضافة قبل إنشاء المخرج النهائي. نظرًا لأن هذا يمكن أن يصبح كبيرًا جدًا، فمن الممكن إضافة وسائط إلى ملف جديد بدون تخزين مؤقت، باستخدام الخيار .I -flat، ولكنه يعطل تشابك الوسائط.

إذا كنت ترغب في إنشاء ملف جديد متشابك بدون تخزين مؤقت، استخدم الخيار .I -newfs. قد لا يكون التشابك دقيقًا كما هو الحال عند استخدام .جديد نظرًا لأنه يعتمد على جدولة مدخلات المعدد (قد يؤدي كل تنفيذ إلى نتيجة مختلفة قليلاً). بالإضافة إلى ذلك في هذا الوضع:
- سيتم تنشيط بعض خيارات التجميع (المميزة بحرف X أدناه) لجميع المدخلات (على سبيل المثال، لا يمكن استيراد مسار AVC واحد مع xps_inband وآخر بدونه).
- لا يمكن استخدام بعض خيارات التجميع (المميزة بحرف D أدناه) لأنها تتطلب مساحة تخزين مؤقتة لتعديل الملف.
- يمكن استخدام .I cat، ولكن المصادر المدمجة لن تتداخل في الإخراج. إذا كنت ترغب في إجراء عمليات cat/add أكثر تعقيدًا بدون ملف مؤقت، استخدم قائمة تشغيل.

يمكن أن يكون عنوان URL للمصدر أي عنوان URL تدعمه GPAC، ولا يقتصر على الملفات المحلية.

ملاحظة: عند استيراد ملفات SRT أو SUB، سيختار MP4Box خيارات تخطيط افتراضية لجعل الترجمة تظهر في أسفل الفيديو. يجب عليك عدم استيراد مثل هذه الملفات قبل إضافة أي مسار فيديو إلى الملف الوجهة، وإلا فإن النتائج لن تكون مفيدة على الأرجح (الاستيراد الافتراضي لـ SRT/SUB يستخدم خط serif افتراضي، وحجم خط 18، وحجم عرض 400x60). لمزيد من التفاصيل، راجع وثائق TTXT.

عند استيراد عدة مسارات/مصادر في تمريرة واحدة، سيتم تطبيق جميع الخيارات إذا كانت ذات صلة بكل مصدر. يتم تعيين هذه الخيارات لجميع المسارات المستوردة. إذا كنت بحاجة إلى تحديد هذه الخيارات لكل مسار، فقم بتعيين خيارات لكل ملف باستخدام الصيغة -add stream[:opt1:...:optN].

يمكن تعيين اسم ملف الاستيراد ليكون فارغًا أو "self"، مما يشير إلى أنه يجب تطبيق خيارات الاستيراد على مسار (مسارات) الملف الوجهة.
مثال
-add self:moovts=-1:noedit src.mp4

سيؤدي هذا إلى تطبيق خيار moovts و noedit على جميع المسارات في src.mp4
مثال
-add self#2:moovts=-1:noedit src.mp4

سيؤدي هذا إلى تطبيق خيار moovts و noedit على المسار ذي المعرف = 2 في src.mp4

يمكن لـ MP4Box ترميز تدفقات BIFS أو LASeR وإدراج نقاط وصول عشوائي بالتردد المحدد. هذا مفيد عند حزم المحتوى للبث، حيث لن يقوم المستخدمون بالانضمام في نفس الوقت. في مصطلحات MPEG-4، يُطلق على هذا اسم مشغل المشهد.## معالجة مقطع BIFS
يسمح وضع ترميز مقطع BIFS بترميز وحدات وصول BIFS منفردة من سياق أولي ومجموعة من الأوامر.
تكون وحدات الوصول (AUs) التي تم إنشاؤها خام BIFS (غير مجمعة في حزم SL)، في ملفات تسمى FILE-ESID-AUIDX.bifs، حيث FILE هو الاسم الأساسي للملف المدخل.

خيارات Meta و HEIF

يمكن استخدام ملفات IsoMedia كحاويات بيانات وصفية عامة، على سبيل المثال تخزين معلومات XML وصور عينات لفيلم. قد لا يحتوي الملف الناتج دائمًا على فيلم كما هو الحال مع بعض ملفات HEIF أو ملفات MPEG-21.

يمكن تخزين هذه المعلومات على مستوى جذر الملف، كما هو الحال بالنسبة لتنسيقات ملفات HEIF/IFF و MPEG-21، أو على مستوى الفيلم أو المسار لفيلم عادي.

-set-meta ABCD[:tk=tkID]

تعيين نوع مربع البيانات الوصفية، مع ABCD نوع البيانات الوصفية المكون من أربعة أحرف (NULL أو 0 لإزالة البيانات الوصفية)
* tk غير محدد: استخدام بيانات وصفية جذرية (ملف)
* tkID == 0: استخدام بيانات وصفية moov
* tkID != 0: استخدام بيانات وصفية للمسار المحدد
-add-item (string)

إضافة مورد إلى البيانات الوصفية، بصيغة معامل file_path[:opt1:optN]
* file_path `this` أو `self`: العنصر هو الملف نفسه
* tk=tkID: موقع البيانات الوصفية (ملف، moov، مسار)
* name=str: اسم العنصر، لا شيء إذا لم يتم تعيينه
* type=itype: نوع 4cc للعنصر (غير ضروري إذا تم توفير mime)
* mime=mtype: نوع mime للعنصر، لا شيء إذا لم يتم تعيينه
* encoding=enctype: نوع ترميز المحتوى للعنصر، لا شيء إذا لم يتم تعيينه
* id=ID: معرف العنصر
* ref=4cc,id: مرجع من نوع 4cc إلى عنصر آخر (يمكن تعيينه عدة مرات)
* group=id,type: يشير إلى معرف ونوع مجموعة بديلة لهذا العنصر
* replace: استبدال العنصر الموجود بعنصر جديد
-add-image (string)

إضافة الملف المحدد كعنصر صورة HEIF، بصيغة معامل file_path[:opt1:optN]. إذا تم حذف filepath، يكون المصدر هو ملف MP4 المدخل
* name, id, ref: انظر .I add-item
* primary: يشير إلى أن هذا العنصر يجب أن يكون العنصر الأساسي
* time=t[-e][/i]: استخدام عينة المزامنة التالية بعد الوقت t (عدد عشري، بالثواني، افتراضي 0). الوقت السلبي يستورد جميع إطارات i كعناصر
- إذا تم تعيين e (عدد عشري، بالثواني)، يستورد جميع عينات المزامنة بين t و e
- إذا تم تعيين i (عدد عشري، بالثواني)، يضبط الفترة الزمنية بين العينات للاستيراد
* split_tiles: بالنسبة لصورة HEVC مقسمة إلى بلاطات، يتم تخزين كل بلاطة كعنصر منفصل
* image-size=wxh: فرض تعيين حجم الصورة وتجاهل معلومات مسار البت، يستخدم للصور المشتقة من الشبكة، التراكب، والهوية أيضًا
* rotation=a: تعيين زاوية الدوران لهذه الصورة بمقدار 90*a درجة عكس اتجاه عقارب الساعة
* mirror-axis=axis: تعيين محور المرآة: رأسي، أفقي
* clap=Wn,Wd,Hn,Hd,HOn,HOd,VOn,VOd: انظر clap المسار
* image-pasp=axb: فرض نسبة العرض إلى الارتفاع للصورة
* image-pixi=(a|a,b,c): فرض عمق البت (1 أو 3 قنوات)
* hidden: يشير إلى أن عنصر الصورة هذا يجب أن يكون مخفيًا
* icc_path: المسار إلى بيانات icc لإضافتها كمعلومات ألوان
* alpha: يشير إلى أن الصورة هي صورة ألفا (يجب استخدام ref=auxl أيضًا)
* depth: يشير إلى أن الصورة هي صورة عمق (يجب استخدام ref=auxl أيضًا)
* it=ID: يشير إلى معرف العنصر للمصدر المراد استيراده
* itp=ID: نفس it= ولكن يتم نسخ جميع خصائص العنصر المصدر
* tk=tkID: يشير إلى معرف المسار للعينة المصدر. إذا كان 0، يستخدم أول مسار فيديو في الملف
* samp=N: يشير إلى رقم العينة للعينة المصدر
* ref: لا تقم بنسخ البيانات ولكن أشِر إلى موقع العينة/العنصر النهائي، يتم تجاهله إذا تم تعيين filepath
* agrid[=AR]: ينشئ شبكة تلقائية من عناصر الصور الموجودة في الملف، بترتيب تعريفها. ستحاول الشبكة الحصول على نسبة العرض إلى الارتفاع AR إذا تم تحديدها (عدد عشري)، أو نسبة العرض إلى الارتفاع للمصدر بخلاف ذلك. ستكون الشبكة هي العنصر الأساسي وسيتم إخفاء جميع الصور الأخرى
* av1_op_index: تحديد نقطة تشغيل AV1 للاستخدام عبر صندوق a1op
* replace: استبدال الصورة الحالية بصورة جديدة، مع الاحتفاظ بالخصائص المدرجة في keep_props
* keep_props=4CCs: قائمة خصائص مفصولة بفواصل يجب الاحتفاظ بها عند استبدال الصورة، على سبيل المثال keep_props=auxC
* auxt=URN: تمييز الصورة كمساعدة باستخدام URN المحدد
* auxd=FILE: استخدام البيانات من FILE كملحقات مساعدة (راجع صندوق auxC)
- سيتم تمرير أي خيارات أخرى كخيارات لمستورد الوسائط، راجع .I add

دعم العلامات

يتم تحديد العلامات كقائمة مفصولة بنقطتين رأسيتين tag_name=tag_value[:tag2=val2]
وضع علامة بدون قيمة أو قيمة NULL يزيل العلامة.
قيمة العلامة الخاصة clear (أو reset) تزيل جميع العلامات.
يمكن إضافة علامات غير مدعومة باستخدام رمزها المكون من أربعة أحرف كاسم علامة، ويفترض أن تكون القيمة نصية.
إذا كان طول اسم العلامة 3، يتم استخدام البادئة 0xA9 لإنشاء رمز الأربعة أحرف.

يمكن أيضًا تحميل العلامات من ملف نصي باستخدام -itags filename. يجب أن يكون الملف بتنسيق UTF8 مع:
- الأسطر التي تبدأ بـ tag_name=value تحدد بداية العلامة
- الأسطر الأخرى تحدد باقي العلامة الأخيرة المعلنة

إذا بدأ اسم العلامة بـ WM/، تتم إضافة العلامة إلى مربع Xtra (علامة WMA، نص فقط).

مفتاح بيانات QT الوصفية

تتم إضافة العلامة كمفتاح بيانات وصفية لـ QT إذا:
- بدأ اسم العلامة بـ QT/
- أو لم يتم التعرف على اسم العلامة وكان أطول من 4 أحرف

يمكن أن يتم إضافة اسم العلامة اختياريًا بالبادئة HDLR@، مما يشير إلى 4CC مساحة اسم العلامة، ومساحة الاسم الافتراضية هي mdta.
يمكن أن يتم إضافة بادئة لقيمة العلامة:
* S: فرض ترميز نصي (يجب وضعه أولاً) بدلاً من تحليل قيمة العلامة
* b: استخدام ترميز 8 بت للأعداد الصحيحة الموقعة أو غير الموقعة
* s: استخدام ترميز 16 بت للأعداد الصحيحة الموقعة أو غير الموقعة
* l: استخدام ترميز 32 بت للأعداد الصحيحة الموقعة أو غير الموقعة
* L: استخدام ترميز 64 بت للأعداد الصحيحة الموقعة أو غير الموقعة
* f: فرض ترميز عائم للأرقام
يتم تحويل الأرقام افتراضيًا وتخزينها في وضع متغير الحجم.
لفرض استخدام عدد صحيح موجب للتخزين الموقّع، أضف + قبل الرقم.
مثال
-tags io.gpac.some_tag=s+32

سيؤدي ذلك إلى فرض تخزين القيمة 32 بتنسيق 16 بت موقّع.
يمكن أيضًا تنسيق قيمة العلامة على النحو التالي:
* XxY@WxH: نوع مستطيل
* XxY: نوع نقطة
* W@H: نوع حجم
* A,B,C,D,E,F,G,H,I: مصفوفة 3x3
* FNAME: يتم تحميل البيانات من FNAME، ويتم تعيين النوع إلى jpeg أو png إذا لزم الأمر
