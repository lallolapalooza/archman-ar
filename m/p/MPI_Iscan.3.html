معلمات الإدخال

  • sendbuf: مخزن الإرسال (اختياري).
  • count: عدد العناصر في مخزن الإدخال (عدد صحيح).
  • datatype: نوع بيانات عناصر مخزن الإدخال (مقبض).
  • op: العملية (مقبض).
  • comm: المتواصل (مقبض).
  • info: معلومات (مقبض، دائم فقط)

معلمات الإخراج

  • recvbuf: مخزن الاستقبال (اختياري).
  • request: الطلب (مقبض، غير متزامن فقط).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

تُستخدم MPI_Scan لإجراء تقليل بادئة شامل على البيانات الموزعة عبر العمليات المتصلة. تُرجع العملية، في recvbuf للعملية ذات الرتبة i، التقليل (المحسوب وفقًا للدالة op) للقيم في sendbuf للعمليات ذات الرتب 0، …، i (شاملة). نوع العمليات المدعومة، ودلالاتها، والقيود على مخازن الإرسال والاستقبال هي كما في MPI_Reduce.

مثال

يستخدم هذا المثال عملية معرفة من قبل المستخدم لإنتاج مسح مقطعي. يأخذ المسح المقطعي، كمدخل، مجموعة من القيم ومجموعة من القيم المنطقية، حيث تحدد القيم المنطقية أجزاء المسح المختلفة. على سبيل المثال،

values     v1      v2      v3      v4      v5      v6      v7      v8
logicals   0       0       1       1       1       0       0       1
result     v1    v1+v2     v3    v3+v4  v3+v4+v5   v6    v6+v7     v8

وبالتالي، تكون النتيجة للرتبة j هي المجموع v(i) + … + v(j)، حيث i هي أدنى رتبة بحيث لكل الرتب n، i <= n <= j، logical(n) = logical(j). العملية التي تنتج هذا التأثير هي

      [ u ]     [ v ]     [ w ]
      [   ]  o  [   ]  =  [   ]
      [ i ]     [ j ]     [ j ]
حيث
    ( u + v إذا كان i = j w = ( ( v إذا كان i != j

لاحظ أن هذه عملية غير تبادلية. كود C الذي ينفذها معطى أدناه.

typedef struct {
        double val;
        int log;
} SegScanPair;
/*
 * الدالة المعرفة من قبل المستخدم
 */
void segScan(SegScanPair *in, SegScanPair *inout, int *len,
        MPI_Datatype *dptr)
{
        int i;
        SegScanPair c;
        for (i = 0; i < *len; ++i) {
                if (in->log == inout->log)
                        c.val = in->val + inout->val;
                else
                        c.val = inout->val;
                c.log = inout->log;
                *inout = c;
                in++;
                inout++;
        }
}

لاحظ أن الوسيط inout للدالة المعرفة من قبل المستخدم يتوافق مع الطرف الأيمن للعملية. عند استخدام هذه العملية، يجب أن نكون حذرين لتحديد أنها غير تبادلية، كما في ما يلي:

int                     i, base;
SeqScanPair     a, answer;
MPI_Op          myOp;
MPI_Datatype    type[2] = {MPI_DOUBLE, MPI_INT};
MPI_Aint                disp[2];
int                     blocklen[2] = {1, 1};
MPI_Datatype    sspair;
/*
 * شرح لـ MPI كيفية تعريف النوع SegScanPair
 */
MPI_Get_address(a, disp);
MPI_Get_address(a.log, disp + 1);
base = disp[0];
for (i = 0; i < 2; ++i)
        disp[i] -= base;
MPI_Type_struct(2, blocklen, disp, type, &sspair);
MPI_Type_commit(&sspair);
/*
 * إنشاء عملية المسح المقطعي المعرفة من قبل المستخدم
 * غير تبادلية - تعيين commute (الوسيط 2) إلى 0
 */
MPI_Op_create((MPI_User_function *)segScan, 0, &myOp);
...
MPI_Scan(a, answer, 1, sspair, myOp, comm);

استخدام خيار في المكان

عندما يكون المتواصل متواصلاً داخليًا، يمكنك إجراء عملية مسح في المكان (يُستخدم مخزن الإخراج كمخزن الإدخال). استخدم المتغير MPI_IN_PLACE كقيمة للوسيط sendbuf. تؤخذ بيانات الإدخال من مخزن الاستقبال ويتم استبدالها ببيانات الإخراج.

ملاحظات على العمليات الجماعية

لا تُرجع دوال التقليل من نوع MPI_Op قيمة خطأ. نتيجة لذلك، إذا اكتشفت الدوال خطأ، كل ما يمكنها فعله هو إما استدعاء MPI_Abort أو تخطي المشكلة بصمت. وبالتالي، إذا تم تغيير معالج الأخطاء من MPI_ERRORS_ARE_FATAL إلى شيء آخر (على سبيل المثال، MPI_ERRORS_RETURN)، فلن يتم الإشارة إلى أي خطأ.

السبب وراء ذلك هو مشاكل الأداء في ضمان أن جميع الروتينات الجماعية تُرجع نفس قيمة الخطأ.

الأخطاء

تقريبًا جميع روتينات MPI تُرجع قيمة خطأ؛ روتينات C كنتيجة إرجاع للدالة، وروتينات Fortran في الوسيط الأخير.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل، المتواصل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، يعتبر الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيستدعي معالج الأخطاء المرتبط به. عندما لا يتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا)، يثير الخطأ معالج الأخطاء الأولي. يمكن تغيير معالج الأخطاء الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو mpi_initial_errhandl

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
