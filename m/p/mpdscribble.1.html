mpdscribble(1)

الحزمة: mpdscribble

التراخيص: GPL

mpdscribble(1) أدلة المستخدم mpdscribble(1)

الاسم

mpdscribble - عميل Music Player Daemon (MPD) يقوم بإرسال معلومات حول المسارات التي يتم تشغيلها إلى خدمة تسجيل (مثل last.fm).

الملخص

mpdscribble [خيارات]

الوصف

mpdscribble هو عميل لـ MPD، وهو خادم تشغيل الموسيقى. يتصل mpdscribble بـ MPD يعمل على الشبكة المحلية ويعمل بالتوازي مع عملاء MPD آخرين على الشبكة.

افتراضيًا، سيحصل على اسم المضيف ومنفذ mpd من متغيرات البيئة MPD_HOST و MPD_PORT. سيستخدم mpdscribble localhost:6600 إذا لم يتم تعيين هذه المتغيرات. يمكن أيضًا تحديد اسم المضيف والمنفذ في ملف التكوين أو على سطر الأوامر.

$ mpdscribble --host myhost --port=12345

القيم المحددة في سطر الأوامر تتجاوز القيم الموجودة في ملف التكوين أو متغيرات البيئة.

إذا كنت ترغب في استخدام mpdscribble مع MPD محمي بكلمة مرور، قم بتعيين متغير البيئة MPD_HOST إلى password@host، أو حدد المضيف في ملف التكوين بشكل مشابه.

عند فشل الإرسال، ينتظر mpdscribble بعض الوقت ثم يعيد المحاولة. إرسال إشارة USR1 إلى عملية mpdscribble قيد التشغيل تجعلها ترسل فورًا.

خيارات

--help
عرض المساعدة والخروج.
--version
عرض معلومات الإصدار والخروج.
--no-daemon
لا تقم بتشغيل mpdscribble كعملية خلفية (daemon)، قم بتشغيله في المقدمة.
--pidfile FILE
اكتب معرف العملية إلى هذا الملف.
--daemon-user USERNAME
قم بالتغيير إلى هذا المستخدم النظام بعد تشغيل العملية الخلفية.
--log FILE
تحديد ملف السجل. القيمة الخاصة "syslog" تجعل mpdscribble يستخدم خادم syslog المحلي (وهو الافتراضي). "-" يعني تسجيل إلى stderr.
--conf FILE
قراءة خيارات التكوين من الملف. يتم استخدام /etc/mpdscribble.conf افتراضيًا (إذا كان --sysconfdir=/etc). يمكن تجاوز هذا.
--host [PASSWORD@]HOSTNAME
تحديد المضيف المحمي بكلمة مرور. للاتصال عبر Unix Domain Socket، حدد مسارًا مطلقًا هنا.
--port PORT
تحديد المنفذ الذي يستمع عليه MPD.
--proxy URL
عنوان URL لـ HTTP proxy.
--verbose LEVEL
تحديد مدى تفصيل تسجيل mpdscribble. القيم الممكنة هي من 0 إلى 3، القيمة الافتراضية هي 1.

التكوين

يبحث mpdscribble عن ملف التكوين الخاص به بالترتيب التالي: $XDG_CONFIG_HOME/mpdscribble/mpdscribble.conf، ~/.config/mpdscribble/mpdscribble.conf، ~/.mpdscribble/mpdscribble.conf، /etc/mpdscribble.conf (إذا كان --sysconfdir=/etc) ولكن يمكن تجاوز هذا عن طريق تحديد ملف تكوين بديل باستخدام خيار سطر الأوامر --conf.

خيارات التكوين المدعومة:

pidfile = FILE
اكتب معرف العملية إلى هذا الملف.
log = FILE
الملف الذي يجب على mpdscribble إخراج معلومات التصحيح إليه. القيمة الخاصة "syslog" تجعل mpdscribble يستخدم خادم syslog المحلي (وهو الافتراضي). "-" يعني تسجيل إلى stderr.
host = [PASSWORD@]HOSTNAME
المضيف الذي يعمل عليه MPD، وقد يكون محميًا بكلمة مرور. للاتصال عبر Unix Domain Socket، حدد مسارًا مطلقًا هنا.
port = PORT
المنفذ الذي يستمع عليه MPD والذي يجب على mpdscribble محاولة الاتصال به.
proxy = URL
عنوان URL لـ HTTP proxy.
verbose = 0, 1, 2, 3
مدى تفصيل تسجيل mpdscribble. الافتراضي هو 1. "0" يعني تسجيل الأخطاء الحرجة فقط (مثل "نفاد الذاكرة")؛ "1" يسجل أيضًا الأخطاء غير الحرجة (مثل "الخادم غير قابل للوصول")؛ "2" يسجل الرسائل المعلوماتية (مثل "أغنية جديدة")؛ "3" يطبع الكثير من رسائل التصحيح.

مسجلات الأغاني (SCROBBLERS)

تتبع هذه الخيارات قسم مسجل أغاني واحد على الأقل (اختر اسم قسم فريد مثل "libre.fm" الذي يظهر فقط في ملف السجل؛ اسم "mpdscribble" محجوز).

file = PATH
تسجيل في ملف بدلاً من إرسال الأغاني إلى خادم AudioScrobbler.
url = URL
عنوان URL الخاص بـ handshake لمسجل الأغاني. مثال: "https://post.audioscrobbler.com/", "http://turtle.libre.fm/"
username = USERNAME
اسم المستخدم الخاص بك على audioscrobbler.
password = MD5SUM
كلمة مرور Last.fm الخاصة بك، إما كنص عادي أو مجموع MD5 الخاص بها.
journal = FILE
الملف الذي يجب على mpdscribble تخزين سجله فيه في حال عدم وجود اتصال بمسجل الأغاني. كان هذا الخيار يسمى سابقًا "cache". إنه اختياري.

الملفات

/etc/mpdscribble.conf

ملف التكوين على مستوى النظام.

~/.config/mpdscribble/mpdscribble.conf

ملف التكوين لكل مستخدم.

/var/cache/mpdscribble/mpdscribble.cache

ملف ذاكرة التخزين المؤقت لـ Last.fm على مستوى النظام.

~/.cache/mpdscribble/mpdscribble.cache

ملف ذاكرة التخزين المؤقت لـ Last.fm لكل مستخدم.

/var/log/mpdscribble/mpdscribble.log

ملف السجل على مستوى النظام.

الأخطاء

قد تكون أذونات الملفات على ملف ذاكرة التخزين المؤقت/السجل غير آمنة افتراضيًا.

يرجى الإبلاغ عن الأخطاء الجديدة إلى متتبع أخطاء MPD: http://www.musicpd.org/mantis
