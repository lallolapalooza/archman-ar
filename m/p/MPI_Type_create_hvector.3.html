MPI_Type_create_hvector(3)

الحزمة: openmpi

التراخيص: BSD-3-Clause AND LicenseRef-MPICH

MPI_Type_create_hvector(3) Open MPI MPI_Type_create_hvector(3)

MPI_Type_create_hvector — إنشاء نوع بيانات متجه (مُرقِّم) بإزاحة بالبايت.

الصيغة

صيغة C

#include <mpi.h>
int MPI_Type_create_hvector(int count, int blocklength,
     MPI_Aint stride, MPI_Datatype oldtype, MPI_Datatype *newtype)

صيغة Fortran

USE MPI
! أو الصيغة الأقدم: INCLUDE 'mpif.h'
MPI_TYPE_CREATE_HVECTOR(COUNT, BLOCKLENGTH, STRIDE, OLDTYPE,
     NEWTYPE, IERROR)
     INTEGER COUNT, BLOCKLENGTH, OLDTYPE, NEWTYPE, IERROR
     INTEGER(KIND=MPI_ADDRESS_KIND) STRIDE

صيغة Fortran 2008

USE mpi_f08
MPI_Type_create_hvector(count, blocklength, stride, oldtype, newtype,
             ierror)
     INTEGER, INTENT(IN) :: count, blocklength
     INTEGER(KIND=MPI_ADDRESS_KIND), INTENT(IN) :: stride
     TYPE(MPI_Datatype), INTENT(IN) :: oldtype
     TYPE(MPI_Datatype), INTENT(OUT) :: newtype
     INTEGER, OPTIONAL, INTENT(OUT) :: ierror

معلمات الإدخال

  • count: عدد الكتل (عدد صحيح غير سالب).
  • blocklength: عدد العناصر في كل كتلة (عدد صحيح غير سالب).
  • stride: عدد البايتات بين بداية كل كتلة (عدد صحيح).
  • oldtype: نوع البيانات القديم (مقبض).

معلمات الإخراج

  • newtype: نوع البيانات الجديد (مقبض).
  • ierror: Fortran فقط: حالة الخطأ (عدد صحيح).

الوصف

MPI_Type_create_hvector ينشئ نوع بيانات متجه (مُرقِّم) بإزاحة بالبايت. هذه الدالة تحل محل MPI_Type_hvector، التي تم إيقافها.

الدالة MPI_Type_create_hvector مطابقة للدالة MPI_Type_vector، باستثناء أن الإزاحة تُعطى بالبايت، بدلاً من العناصر. يتم توضيح استخدام كلا النوعين من منشئي المتجهات في الأمثلة في فصل أنواع البيانات من معيار MPI.

بافتراض أن oldtype لديه خريطة نوع

{(type(0), disp(0)), ..., (type(n-1), disp(n-1))}

مع مدى ex. لتكن bl هي طول الكتلة. نوع البيانات المُنشأ حديثًا لديه خريطة نوع مع count * bl * n إدخالات:

{(type(0), disp(0)), ..., (type(n-1), disp(n-1)),
(type(0), disp(0) + ex), ..., (type(n-1), disp(n-1) + ex),
..., (type(0), disp(0) + (bl -1) * ex),...,(type(n-1),
disp(n-1) + (bl -1) * ex), (type(0), disp(0) + stride),
...,(type(n-1), disp(n-1) + stride), ..., (type(0),
disp(0) + stride + (bl - 1) * ex), ..., (type(n-1),
disp(n-1) + stride + (bl -1) * ex), ..., (type(0),
disp(0) + stride * (count -1)), ...,(type(n-1),
disp(n-1) + stride * (count -1)), ..., (type(0),
disp(0) + stride * (count -1) + (bl -1) * ex), ...,
(type(n-1), disp(n-1) + stride * (count -1) + (bl -1) * ex)}

الأخطاء

تقوم جميع روتينات MPI تقريبًا بإرجاع قيمة خطأ؛ روتينات C كالنتيجة العائدة من الدالة وروتينات Fortran في المعلمة الأخيرة.

قبل إرجاع قيمة الخطأ، يتم استدعاء معالج أخطاء MPI الحالي المرتبط بكائن الاتصال (مثل، المراسل، النافذة، الملف). إذا لم يكن هناك كائن اتصال مرتبط باستدعاء MPI، فسيتم اعتبار الاستدعاء مرتبطًا بـ MPI_COMM_SELF وسيستدعي معالج أخطاء MPI المرتبط به. عندما لا تتم تهيئة MPI_COMM_SELF (أي، قبل MPI_Init/MPI_Init_thread، بعد MPI_Finalize، أو عند استخدام نموذج الجلسات حصريًا) يثير الخطأ معالج الخطأ الأولي. يمكن تغيير معالج الخطأ الأولي عن طريق استدعاء MPI_Comm_set_errhandler على MPI_COMM_SELF عند استخدام نموذج العالم، أو الوسيطة CLI mpi_initial_errhandler إلى mpiexec أو مفتاح المعلومات إلى MPI_Comm_spawn/MPI_Comm_spawn_multiple. إذا لم يتم تعيين أي معالج خطأ مناسب آخر، فسيتم استدعاء معالج الخطأ MPI_ERRORS_RETURN لوظائف إدخال/إخراج MPI وسيتم استدعاء معالج الخطأ MPI_ERRORS_ABORT لجميع وظائف MPI الأخرى.

يشتمل Open MPI على ثلاثة معالجات أخطاء مُعرّفة مسبقًا يمكن استخدامها:

  • MPI_ERRORS_ARE_FATAL يتسبب في إيقاف البرنامج لجميع عمليات MPI المتصلة.
  • MPI_ERRORS_ABORT معالج خطأ يمكن استدعاؤه على مراسل، نافذة، ملف، أو جلسة. عند استدعائه على مراسل، يتصرف كما لو تم استدعاء MPI_Abort على هذا المراسل. عند استدعائه على نافذة أو ملف، يتصرف كما لو تم استدعاء MPI_Abort على مراسل يحتوي على مجموعة العمليات في النافذة أو الملف المقابل. عند استدعائه على جلسة، يقوم بإيقاف العملية المحلية فقط.
  • MPI_ERRORS_RETURN يُرجع رمز خطأ إلى التطبيق.

يمكن لتطبيقات MPI أيضًا تنفيذ معالجات أخطاء خاصة بها عن طريق استدعاء:

  • MPI_Comm_create_errhandler ثم MPI_Comm_set_errhandler
  • MPI_File_create_errhandler ثم MPI_File_set_errhandler
  • MPI_Session_create_errhandler ثم MPI_Session_set_errhandler أو في MPI_Session_init
  • MPI_Win_create_errhandler ثم MPI_Win_set_errhandler

لاحظ أن MPI لا تضمن أن برنامج MPI يمكن أن يستمر بعد حدوث خطأ.
