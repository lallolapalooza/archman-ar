MPI_Op_c2f(3) Open MPI MPI_Op_c2f(3)

MPI_Comm_f2c، MPI_Comm_c2f، MPI_File_f2c، MPI_File_c2f، MPI_Info_f2c، MPI_Info_c2f، MPI_Message_f2c، MPI_Message_c2f، MPI_Op_f2c، MPI_Op_c2f، MPI_Request_f2c، MPI_Request_c2f، MPI_Type_f2c، MPI_Type_c2f، MPI_Win_f2c، MPI_Win_c2f - ترجمة مقبض C إلى مقبض Fortran، أو العكس.

الوصف

يتم تمرير المقابض بين Fortran و C باستخدام غلاف C صريح لتحويل مقابض Fortran إلى مقابض C. لا يوجد وصول مباشر إلى مقابض C في Fortran. يتم توفير تعريف النوع MPI_Fint في C لعدد صحيح بالحجم الذي يتطابق مع Fortran INTEGER؛ عادةً، سيكون MPI_Fint مكافئًا لـ int. يتم توفير وظائف ترجمة المقابض في C للتحويل من مقبض Fortran (وهو عدد صحيح) إلى مقبض C، والعكس صحيح.

على سبيل المثال، إذا كان comm مقبض Fortran صالحًا للمتصل، فإن MPI_Comm_f2c يعيد مقبض C صالحًا لنفس المتصل؛ إذا كان comm = MPI_COMM_NULL (قيمة Fortran)، فإن MPI_Comm_f2c يعيد مقبض C فارغًا؛ إذا كان comm مقبض Fortran غير صالح، فإن MPI_Comm_f2c يعيد مقبض C غير صالح.

ملاحظة

هذه الوظيفة لا تعيد قيمة خطأ. وبالتالي، فإن نتيجة استدعائها قبل MPI_Init أو بعد MPI_Finalize غير محددة.
