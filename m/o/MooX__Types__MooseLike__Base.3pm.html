MooX__Types__MooseLike__Base(3pm)

الحزمة: perl-moox-types-mooselike

التراخيص: PerlArtistic, GPL

MooX::Types::MooseLike::Base(3) وثائق مقدمة من مستخدمي Perl MooX::Types::MooseLike::Base(3)

الاسم

MooX::Types::MooseLike::Base - مجموعة من أنواع Moose-like الأساسية لـ Moo

الملخص

package MyPackage;
use Moo;
use MooX::Types::MooseLike::Base qw(:all);
has "beers_by_day_of_week" => (
    isa => HashRef
);
has "current_BAC" => (
    isa => Num
);
# كما يدعم is_$type. على سبيل المثال، يمكن استخدامه كما يلي
has 'legal_age' => (
    is => 'ro',
    isa => sub { die "$_[0] ليس قانونيًا"
                 unless (is_Int($_[0]) && $_[0] > 17) },
);

الوصف

سمات Moose (مثل Moose) لديها خاصية 'isa'. تقدم هذه الوحدة بعض الأنواع الأساسية لهذه الخاصية. يمكنك استيراد جميع الأنواع باستخدام العلامة ':all' أو استيراد قائمة من الأنواع مثل:

use MooX::Types::MooseLike::Base qw/HashRef ArrayRef/;

بحيث يمكنك الإعلان عن بعض السمات مثل:

has 'contact' => (
  is => 'ro',
  isa => HashRef,
);
has 'guest_list' => (
  is => 'ro',
  isa => ArrayRef[HashRef],
);

توفر هذه الأنواع تحكمًا في أن سمة contact هي مرجع "مصفوفة"، وأن guest_list هي مرجع "مصفوفة هاش".

نوع مرجعي

Int

نوع صحيح

نوع مرجع المصفوفة (ARRAY)

أنواع مُعَلَّمة

تعلِيم الأنواع بنوع واحد

يمكن تعليق الأنواع التالية بأنواع أخرى.

ArrayRef

على سبيل المثال، ArrayRef[HashRef]

HashRef

ScalarRef

Maybe

على سبيل المثال، Maybe[Int] سيكون صحيحًا أو undef

تعلِيم الأنواع بأنواع متعددة

AnyOf

يتحقق مما إذا كانت السمة هي أي من الأنواع المدرجة (أي اتحاد). يأخذ قائمة من الأنواع كوسيط.

isa => AnyOf[Int, ArrayRef[Int], HashRef[Int]]

ملاحظة: يتم تمرير AnyOf كـ ArrayRef[CodeRef]

AllOf

يتحقق مما إذا كانت السمة هي جميع الأنواع المدرجة (أي تقاطع). يأخذ قائمة من الأنواع كوسيط. على سبيل المثال:

isa => AllOf[
  InstanceOf['Human'],
  ConsumerOf['Air'],
  HasMethods['breath', 'dance']
],

تعلِيم الأنواع بسلاسل نصية (متعددة)

بالإضافة إلى ذلك، لدينا بعض الأنواع المعلمة التي تقبل وسائط سلسلة نصية.

InstanceOf

يتحقق مما إذا كانت السمة هي مثيل لكائن من فئة واحدة أو أكثر. يستخدم "blessed" و "isa" للقيام بذلك. يأخذ قائمة بأسماء الفئات كوسيط. على سبيل المثال:

isa => InstanceOf['MyClass','MyOtherClass']

ملاحظة: يتم تمرير InstanceOf كـ ArrayRef[Str]

ConsumerOf

يتحقق مما إذا كانت السمة هي كائن وتستهلك دورًا واحدًا أو أكثر. يستخدم "blessed" و "does" للقيام بذلك. يأخذ قائمة بأسماء الأدوار كوسائط. على سبيل المثال:

isa => ConsumerOf['My::Role', 'My::AnotherRole']

HasMethods

يتحقق مما إذا كانت السمة هي كائن ولديها طريقة واحدة أو أكثر. يستخدم "blessed" و "can" للقيام بذلك. يأخذ قائمة بأسماء الطرق كوسائط. على سبيل المثال:

isa => HasMethods[qw/postulate contemplate liberate/]

Enum

يتحقق مما إذا كانت السمة هي واحدة من القيم المحصورة. يأخذ قائمة بالقيم الممكنة كوسيط. على سبيل المثال:

isa => Enum['rock', 'spock', 'paper', 'lizard', 'scissors']

انظر أيضًا

MooX::Types::MooseLike::Numeric - مثال على بناء أنواع فرعية.

MooX::Types::SetObject - مثال على بناء أنواع معلمات.
