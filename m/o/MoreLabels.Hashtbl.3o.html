جداول التجزئة والمتواليات

val to_seq : ('a, 'b) t -> ('a * 'b) Seq.t

يتكرر عبر الجدول بأكمله. ترتيب ظهور الإدخالات في المتوالية غير قابل للتنبؤ. ومع ذلك، إذا كان الجدول يحتوي على إدخالات متعددة بنفس المفتاح، فإنها تظهر بترتيب عكسي للإدخال، أي أن الأحدث يظهر أولاً.

السلوك غير محدد إذا تم تعديل الجدول أثناء التكرار.

Since 4.07

واجهة functorial

تسمح الواجهة functorial باستخدام وظائف تجزئة ومقارنة محددة، سواء لأسباب تتعلق بالأداء أو الأمان، أو لأن المفاتيح ليست قابلة للتجزئة / قابلة للمقارنة باستخدام الدوال المدمجة متعددة الأشكال.

على سبيل المثال، قد يرغب المرء في تخصيص جدول لمفاتيح من نوع الأعداد الصحيحة:

        module IntHash =
          struct
            type t = int
            let equal i j = i=j
            let hash i = i land max_int
          end
        module IntHashtbl = Hashtbl.Make(IntHash)
        let h = IntHashtbl.create 17 in
        IntHashtbl.add h 12 "hello"

ينشئ هذا وحدة نمطية جديدة IntHashtbl، بنوع جديد 'a IntHashtbl.t للجداول من int إلى 'a. في هذا المثال، يحتوي h على قيم من نوع string، لذلك نوعه هو string IntHashtbl.t.

ملاحظة: النوع الجديد 'a IntHashtbl.t غير متوافق مع نوع ('a,'b) Hashtbl.t من الواجهة العامة. على سبيل المثال، Hashtbl.length h لن يتم التحقق منه بواسطة نظام الأنواع، يجب عليك استخدام IntHashtbl.length.

وظائف التجزئة متعددة الأشكال

val hash : 'a -> int

تربط الوظيفة Hashtbl.hash x رقمًا غير سالب بأي قيمة من أي نوع. من المضمون أنه إذا كان x = y أو Stdlib.compare x y = 0، فإن hash x = hash y. بالإضافة إلى ذلك، تنتهي hash دائمًا، حتى في الهياكل الدورية.

val seeded_hash : int -> 'a -> int

متغير من MoreLabels.Hashtbl.hash مع معلمة بذرة صحيحة.

Since 4.00

val hash_param : int -> int -> 'a -> int

تحسب الوظيفة Hashtbl.hash_param meaningful total x قيمة تجزئة لـ x، بنفس خصائص hash. المعلمات الإضافية meaningful و total توفر تحكمًا أكبر في التجزئة. تقوم وظيفة التجزئة بإجراء مسح للعرض، من اليسار إلى اليمين، لهيكل x، وتتوقف بعد meaningful عقد ذات مغزى أو total عقد (ذات مغزى أو لا). إذا تجاوزت قيمة total المحددة من قبل المستخدم قيمة معينة (حالياً 256)، فإنها تحدد لهذه القيمة. العقد ذات المغزى هي أعداد صحيحة، أعداد فاصلة عائمة، سلاسل نصية، أحرف، قيم منطقية، وبنيات ثابتة. تعني القيم الأعلى لـ meaningful و total أن المزيد من العقد تؤخذ في الاعتبار لحساب قيمة التجزئة النهائية، مما يقلل من التصادمات. ومع ذلك، فإن التجزئة تكون أبطأ. المعلمات meaningful و total تنظم التوازن بين الدقة والسرعة. كخيارات افتراضية، تستخدم MoreLabels.Hashtbl.hash و MoreLabels.Hashtbl.seeded_hash meaningful = 10 و total = 100.
