Moo__Role(3pm)

الحزمة: perl-moo

التراخيص: PerlArtistic, GPL

Moo::Role(3) وثائق Perl المساهمة من المستخدم Moo::Role(3)

الاسم

Moo::Role - دعم التوجيه الكائني الأدنى للأدوار

ملخص

package My::Role;
use Moo::Role;
use strictures 2;
sub foo { ... }
sub bar { ... }
has baz => (
  is => 'ro',
);
1;

وفي مكان آخر:

package Some::Class;
use Moo;
use strictures 2;
# يتم استيراد bar، ولكن ليس foo
with 'My::Role';
sub foo { ... }
1;

الوصف

"Moo::Role" يبني على Role::Tiny، لذا انظر هناك لمعظم التوثيق حول كيفية عمل هذا (على وجه الخصوص، استخدام "Moo::Role" يمكّن أيضًا strict و warnings). الإضافة الرئيسية هنا هي أجزاء إضافية لجعل الأدوار أكثر "Moosey;"، وهذا يعني أنها تضيف "has".

الإجراءات الفرعية المستوردة

انظر "الإجراءات الفرعية المستوردة" في Role::Tiny لجميع الإجراءات الفرعية الأخرى التي يتم استيرادها بواسطة هذه الوحدة.

has

has attr => (
  is => 'ro',
);

يعلن عن سمة للفئة التي سيتم تكوينها. انظر "has" في Moo لجميع الخيارات.

تنظيف الاستيرادات

تقوم Moo::Role بتنظيف أساليبها المستوردة وأي استيرادات تم الإعلان عنها قبل عبارة "use Moo::Role" تلقائيًا. أي شيء يتم استيراده بعد "use Moo::Role" سيتم تركيبه في الحزم المستهلكة. حزمة تستهلك هذا الدور:

package My::Role::ID;
use Digest::MD5 qw(md5_hex);
use Moo::Role;
use Digest::SHA qw(sha1_hex);
requires 'name';
sub as_md5  { my ($self) = @_; return md5_hex($self->name);  }
sub as_sha1 { my ($self) = @_; return sha1_hex($self->name); }
1;

.. سيكون لديها الآن طريقة "$self->sha1_hex()" متاحة لها قد لا تفعل ما تتوقعه. من ناحية أخرى، سيموت استدعاء "$self->md5_hex()" برسالة خطأ مفيدة: "Can't locate object method "md5_hex".

انظر "تنظيف الاستيرادات" في Moo لمزيد من التفاصيل.
