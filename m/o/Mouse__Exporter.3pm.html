Mouse__Exporter(3pm)

الحزمة: perl-mouse

التراخيص: PerlArtistic, GPL

Mouse::Exporter(3pm) وثائق Perl المقدمة من المستخدم Mouse::Exporter(3pm)

الاسم

Mouse::Exporter - إنشاء دالة استيراد() وإلغاء استيراد() تمامًا مثل Mouse.pm

الإصدار

يوثق هذا المستند إصدار Mouse v2.6.0

الملخص

package MyApp::Mouse;
use Mouse ();
use Mouse::Exporter;
Mouse::Exporter->setup_import_methods(
  as_is => [ 'has_rw', 'other_sugar', \&Some::Random::thing ],
  also  => 'Mouse',
);
sub has_rw {
    my $meta = caller->meta;
    my ( $name, %options ) = @_;
    $meta->add_attribute(
      $name,
      is => 'rw',
      %options,
    );
}
# ثم لاحقًا ...
package MyApp::User;
use MyApp::Mouse;
has 'name';
has_rw 'size';
thing;
no MyApp::Mouse;

الوصف

تغلف هذه الوحدة تصدير دوال السكر (sugar functions) بطريقة مشابهة لـ "Mouse.pm". تقوم بذلك عن طريق بناء دوال "import" و "unimport" مخصصة لوحدتك، بناءً على مواصفات تقدمها.

لاحظ أن "Mouse::Exporter" لا توفر الخيار "with_meta"، ولكن يمكنك بسهولة الحصول على الفئة الوصفية (metaclass) عن طريق "caller->meta" كما هو موضح في "الملخص".

الدوال

setup_import_methods( ARGS )

"build_import_methods( ARGS ) -> (\&import, \&unimport)"
