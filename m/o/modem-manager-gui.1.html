modem-manager-gui(1)

الحزمة: modem-manager-gui

التراخيص: GPL3

modem-manager-gui(1) أوامر المستخدم modem-manager-gui(1)

الاسم

modem-manager-gui - واجهة رسومية بسيطة لخدمة Modem Manager.

الملخص

modem-manager-gui [ -i ] [ -m module ] [ -c module ] [ -l ]...

الوصف

هذا البرنامج هو واجهة رسومية بسيطة لخدمات Modem Manager 0.6/0.7 و Wader و oFono باستخدام واجهة dbus.

-i, --invisible
لا تظهر النافذة عند البدء
-m, --mmmodule
استخدم وحدة إدارة المودم المحددة
-c, --cmmodule
استخدم وحدة إدارة الاتصال المحددة
-l, --listmodules
قم بإدراج جميع الوحدات المتاحة واخرج

المؤلف

كتبه Alex. انظر مربع "حول" لجميع المساهمين.

الإبلاغ عن الأخطاء

أبلغ عن الأخطاء إلى <alex@linuxonly.ru>، أو إلى قسم الدعم في المنتدى على https://linuxonly.ru/forum/modem-manager-gui/.
