MODF(3P) دليل مبرمج POSIX MODF(3P)

PROLOG

هذه الصفحة اليدوية جزء من دليل مبرمج POSIX. قد يختلف تنفيذ لينكس لهذه الواجهة (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة على لينكس.

NAME

modf, modff, modfl — تقسيم رقم الفاصلة العائمة

SYNOPSIS

#include <math.h>
double modf(double x, double *iptr);
float modff(float value, float *iptr);
long double modfl(long double value, long double *iptr);

DESCRIPTION

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع المعيار ISO C. أي تعارض بين المتطلبات الموضحة هنا والمعيار ISO C هو غير مقصود. يستند هذا المجلد من POSIX.1-2017 إلى المعيار ISO C.

تقوم هذه الوظائف بتقسيم الوسيط x إلى أجزاء صحيحة وكسرية، ولكل منها نفس إشارة الوسيط. تقوم بتخزين الجزء الصحيح كـ double (للوظيفة modf())، أو float (للوظيفة modff())، أو long double (للوظيفة modfl())، في الكائن المشار إليه بواسطة iptr.

RETURN VALUE

عند اكتمالها بنجاح، تعيد هذه الوظائف الجزء الكسري المشارة إليه من x.

إذا كان x هو NaN، فسيتم إرجاع NaN، وسيتم تعيين *iptr إلى NaN.

إذا كان x هو ±Inf، فسيتم إرجاع ±0، وسيتم تعيين *iptr إلى ±Inf.

ERRORS

لا توجد أخطاء محددة.

الأقسام التالية إعلامية.

EXAMPLES

لا يوجد.

APPLICATION USAGE

تقوم الوظيفة modf() بحساب نتيجة الوظيفة و *iptr بحيث:

a = modf(x, iptr) ;
x == a+*iptr ;

مع مراعاة الأخطاء المعتادة في الفاصلة العائمة.
