الاسم

mount.glusterfs - برنامج نصي لتركيب وحدات تخزين GlusterFS الأصلية

الملخص

mount -t glusterfs [-o <options>] <volumeserver>:/<volume>[/<subdir>] <mountpoint>

mount -t glusterfs [-o <options>] <server1>,<server2>,
<server3>,..<serverN>:/<volname>[/<subdir>] <mount_point>
mount -t glusterfs [-o <options>] <path/to/volumefile> <mountpoint>

الوصف

هذه الأداة جزء من حزمة glusterfs(8)، والتي تستخدم للتركيب باستخدام ملف GlusterFS الثنائي الأصلي.

mount.glusterfs مخصص للاستخدام بواسطة الأمر mount(8) لتركيب عميل GlusterFS الأصلي. ومع ذلك، يمكن استخدام هذا الأمر الفرعي أيضًا كأمر مستقل بوظائف محدودة.

الخيارات

خيارات أساسية

log-file=LOG-FILE
الملف المراد استخدامه للتسجيل [الافتراضي: /var/log/glusterfs/glusterfs.log]
log-level=LOG-LEVEL
مستوى خطورة التسجيل. الخيارات الصحيحة هي TRACE، DEBUG، WARNING، ERROR، CRITICAL INFO و NONE [الافتراضي: INFO]
acl
تركيب نظام الملفات مع دعم POSIX ACL
fopen-keep-cache[=BOOL]
لا تقم بتطهير ذاكرة التخزين المؤقت عند فتح الملف (الافتراضي: false)
worm
تركيب نظام الملفات في وضع 'worm'
aux-gfid-mount
تمكين الوصول إلى نظام الملفات عبر gfid مباشرة
ro
تركيب نظام الملفات للقراءة فقط
enable-ino32=BOOL
استخدام inodes 32 بت عند التركيب لتجاوز التطبيقات المعطلة التي لا تدعم inodes 64 بت
mem-accounting
تمكين محاسبة الذاكرة الداخلية
capability
تمكين تعيين واسترداد قدرات الملفات
thin-client
تمكين التركيب الخفيف والاتصال عبر خادم gfproxyd
localtime-logging
استخدام طوابع زمنية محلية بدلاً من UTC في إدخالات سجل التركيب

خيارات متقدمة

attribute-timeout=SECONDS
تعيين مهلة السمات إلى ثوانٍ للـ inodes في وحدة نواة fuse [الافتراضي: 1]
entry-timeout=SECONDS
تعيين مهلة الإدخال إلى ثوانٍ في وحدة نواة fuse [الافتراضي: 1]
background-qlen=N
تعيين طول طابور الخلفية لوحدة fuse إلى N [الافتراضي: 64]
gid-timeout=SECONDS
تعيين مهلة قائمة المجموعات المساعدة إلى ثوانٍ لمترجم fuse [الافتراضي: 0]
negative-timeout=SECONDS
تعيين المهلة السلبية إلى ثوانٍ في وحدة نواة fuse [الافتراضي: 0]
volume-name=VOLUME-NAME
اسم الوحدة المراد استخدامه لـ MOUNT-POINT [الافتراضي: أعلى وحدة في VOLUME-FILE]
direct-io-mode=BOOL|auto
تحديد استراتيجية الإدخال / الإخراج المباشر لـ fuse [الافتراضي: auto]
congestion-threshold=N
تعيين عتبة الازدحام لوحدة fuse إلى N [الافتراضي: 48]
ubdir-mount=N
تعيين خيار تركيب الدليل الفرعي [الافتراضي: NULL، أي، لا يوجد تركيب دليل فرعي]
backup-volfile-servers=SERVERLIST
توفير قائمة بخوادم volfile الاحتياطية بالتنسيق التالي [الافتراضي: None] إذا كنت تستخدم عنوان IPv6 في SERVERLIST، فيجب استخدام '[' و ']' لإحاطة عنوان IPv6.

$ mount -t glusterfs -obackup-volfile-servers=<server2>: <server3>:...:<serverN> <server1>:/<volname> <mount_point> $ mount -t glusterfs -obackup-volfile-servers=<[ipv6_addr2]>: <[ipv6_addr3]>:...:<[ipv6_addrN]> <ipv6_addr1>:/<volname> <mount_point>

backupvolfile-server=SERVER
توفير قائمة بخوادم volfile الاحتياطية بالتنسيق التالي [الافتراضي: None]

$ mount -t glusterfs -obackupvolfile-server=<server2> <server1>:/<volname> <mount_point>

fetch-attempts=N
خيار **مهمل** - موجود هنا للتوافق مع الإصدارات السابقة [الافتراضي: 1]
lru-limit=N
تعيين الحد الأقصى لعدد الـ inodes المحفوظة في قائمة LRU لوحدة fuse إلى N [الافتراضي: 65536]
inode-table-size=N
تعيين حجم جدول تجزئة الـ inodes إلى N - يجب أن يكون هذا قوة للرقم 2 أكبر من أو يساوي 65536 وسيتم تقريبه إذا لم يكن كذلك [الافتراضي: 65536]
invalidate-limit=N
تعليق تعطيلات fuse الضمنية بواسطة 'lru-limit' إذا وصل عدد التعطيلات المعلقة إلى N
background-qlen=N
تعيين طول طابور الخلفية لوحدة fuse إلى N [الافتراضي: 64]
no-root-squash=BOOL
تعطيل تقليص الجذر للعميل الموثوق [الافتراضي: off]
root-squash=BOOL
تمكين تقليص الجذر للعميل الموثوق [الافتراضي: on]
use-readdirp=BOOL
استخدام وضع readdirp() في وحدة نواة fuse [الافتراضي: on]
dump-fuse=PATH
تفريغ حركة مرور fuse إلى PATH
kernel-writeback-cache=BOOL
تمكين ذاكرة التخزين المؤقت للكتابة الخلفية في نواة fuse [الافتراضي: off]
attr-times-granularity=NS
تحديد دقة سمات الملف المدعومة [الافتراضي: 0]
auto-invalidation=BOOL
يتحكم فيما إذا كانت نواة fuse يمكنها تعطيل السمات و dentry و page-cache تلقائيًا. قم بتعطيل هذا فقط إذا لم يتم الوصول إلى نفس الملفات / الدلائل عبر تركيبين مختلفين في وقت واحد [الافتراضي: on]

الملفات

/etc/fstab
إدخال GlusterFS نموذجي في /etc/fstab يبدو كما يلي

server1:/mirror /mnt/mirror glusterfs log-file=/var/log/mirror.log,acl 0 0

/proc/mounts
مثال لإدخال نقطة تركيب GlusterFS في /proc/mounts يبدو كما يلي

server1:/mirror /mnt/glusterfs fuse.glusterfs rw,allow_other,default_permissions,max_read=131072 0 0

NAME

mount.glusterfs - mount a GlusterFS volume

SYNOPSIS

mount.glusterfs [<glusterfs-server>:]<volume-name> <mount-point> [-o <options>]

DESCRIPTION

mount.glusterfs is used to mount a GlusterFS volume onto a specified mount point. GlusterFS is a scalable network filesystem that combines many servers into a single coherent volume.

OPTIONS

The following options can be passed to mount.glusterfs using the -o flag:

  • ro: Mount the volume in read-only mode.
  • rw: Mount the volume in read-write mode (default).
  • acl: Enable POSIX Access Control Lists.
  • noacl: Disable POSIX Access Control Lists (default).
  • checksum-algo=<algorithm>: Specify the checksum algorithm to use. Supported algorithms include crc32, crc32c, md5, and sha1. Default is crc32c.
  • log-level=<level>: Set the logging level. Possible values are TRACE, DEBUG, INFO, WARNING, ERROR, FATAL. Default is WARNING.
  • log-file=<file>: Specify a file to log messages to. If not specified, logs go to syslog.

FILES

  • /etc/glusterfs/glusterfs.conf: GlusterFS configuration file.
