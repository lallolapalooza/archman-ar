Module::Metadata(3perl) دليل مبرمجي بيرل Module::Metadata(3perl)

الاسم

Module::Metadata - جمع معلومات الحزمة و POD من ملفات وحدات بيرل

الإصدار

version 1.000038

الملخص

use Module::Metadata;
# معلومات عن ملف .pm
my $info = Module::Metadata->new_from_file( $file );
my $version = $info->version;
# حقل 'provides' في CPAN META لملفات .pm في دليل
my $provides = Module::Metadata->provides(
  dir => 'lib', version => 2
);

الوصف

توفر هذه الوحدة طريقة قياسية لجمع البيانات الوصفية لملف .pm من خلال (في الغالب) التحليل الثابت و (بعض) تنفيذ الكود. عند تحديد إصدار الوحدة، يتم تقييم تعيين $VERSION، كما هو تقليدي في سلسلة أدوات CPAN.

طرق الفئة

"new_from_file($filename, collect_pod => 1, decode_pod => 1)"

ينشئ كائن "Module::Metadata" بالنظر إلى المسار إلى ملف. يعيد undef إذا كان اسم الملف غير موجود.

تعد "collect_pod" وسيطة منطقية اختيارية تحدد ما إذا كانت بيانات POD يتم جمعها وتخزينها للرجوع إليها. لا يتم جمع بيانات POD افتراضيًا. يتم دائمًا جمع عناوين POD.

إذا بدأ الملف بـ UTF-8، UTF-16BE أو UTF-16LE byte-order mark، فسيتم تخطيه قبل المعالجة، وسيتم أيضًا فك ترميز محتويات الملف بشكل مناسب بدءًا من perl 5.8.

بدلاً من ذلك، إذا تم تعيين "decode_pod"، فسيتم فك ترميز أقسام POD المجمعة وفقًا لإعلان "=encoding".

"new_from_handle($handle, $filename, collect_pod => 1, decode_pod => 1)"

يعمل هذا تمامًا مثل "new_from_file"، باستثناء أنه يمكن توفير معالج كوسيط أول.

لاحظ أنه لا يوجد تحقق للتأكد من أن المعالج هو معالج أو شيء يمكن أن يتصرف مثله. سيؤدي تمرير شيء ليس معالجًا إلى حدوث استثناء عند محاولة القراءة منه. الوسيط "filename" إلزامي أو سيتم إرجاع undef.

أنت مسؤول عن تعيين طبقات فك التشفير على $handle إذا لزم الأمر.

"new_from_module($module, collect_pod => 1, inc => \@dirs, decode_pod => 1)"

ينشئ كائن "Module::Metadata" بالنظر إلى اسم وحدة أو حزمة. يعيد undef إذا تعذر العثور على الوحدة.

بالإضافة إلى قبول الوسيطين "collect_pod" و "decode_pod" كما هو موضح أعلاه، تقبل هذه الطريقة وسيطة "inc" وهي مرجع لمصفوفة من الأدلة للبحث عن الوحدة. إذا لم يتم توفير أي منها، فالافتراضي هو @INC.

إذا بدأ الملف الذي يحتوي على الوحدة بـ UTF-8، UTF-16BE أو UTF-16LE byte-order mark، فسيتم تخطيه قبل المعالجة، وسيتم أيضًا فك ترميز محتويات الملف بشكل مناسب بدءًا من perl 5.8.

"find_module_by_name($module, \@dirs)"

يعيد المسار إلى وحدة بالنظر إلى اسم الوحدة أو الحزمة. يمكن تمرير قائمة من الأدلة كوسيط اختياري، وإلا فسيتم البحث في @INC.

يمكن استدعاؤها ككائن أو طريقة فئة.

"find_module_dir_by_name($module, \@dirs)"

يعيد الدخول في @dirs (أو @INC افتراضيًا) الذي يحتوي على الوحدة $module. يمكن تمرير قائمة من الأدلة كوسيط اختياري، وإلا فسيتم البحث في @INC.

يمكن استدعاؤها ككائن أو طريقة فئة.

provides( %options )

هذه لفة مريحة حول "package_versions_from_directory" لإنشاء بنية بيانات CPAN META "provides". تأخذ أزواج مفتاح/قيمة. تشمل مفاتيح الخيارات الصالحة:

version (مطلوب)
يحدد أي إصدار من CPAN::Meta::Spec يجب استخدامه كشكل ناتج "provides". حاليًا فقط '1.4' و '2' مدعومان (وشكلهما متطابق). قد يتغير هذا في المستقبل مع تغير تعريف "provides".

الخيار "version" مطلوب. إذا تم حذفه أو إذا تم تقديم إصدار غير مدعوم، فستقوم "provides" بإطلاق خطأ.

dir
الدليل للبحث فيه بشكل متكرر عن ملفات .pm. لا يجوز تحديده مع "files".
files
مرجع مصفوفة للملفات التي سيتم فحصها. لا يجوز تحديده مع "dir".
prefix
سلسلة لإلحاقها بحقل "file" في الناتج. افتراضياً 'lib'، وهو الحالة الشائعة لمعظم توزيعات CPAN مع ملفاتها .pm في lib. يضمن هذا الخيار أن معلومات META لها المسار النسبي الصحيح حتى عندما تكون وسائط "dir" أو "files" مطلقة أو لها مسارات نسبية من موقع آخر غير جذر التوزيع.

على سبيل المثال، بالنظر إلى "dir" 'lib' و "prefix" 'lib'، فإن القيمة المرجعة هي hashref بالشكل:

{
  'Package::Name' => {
    version => '0.123',
    file => 'lib/Package/Name.pm'
  },
  'OtherPackage::Name' => ...
}

"package_versions_from_directory($dir, \@files?)"

يمسح $dir بحثًا عن ملفات .pm (ما لم يتم تقديم @files، وفي هذه الحالة يبحث عن تلك الملفات في $dir - ويقرأ كل ملف بحثًا عن حزم وإصدارات، ويعيد hashref بالشكل:

{
  'Package::Name' => {
    version => '0.123',
    file => 'Package/Name.pm'
  },
  'OtherPackage::Name' => ...
}

يتم دائمًا استبعاد حزم "DB" و "main"، وكذلك أي حزم "خاصة" لها شرطات سابقة في مساحة الاسم (على سبيل المثال "Foo::_private")

لاحظ أن مسار الملف نسبي لـ $dir إذا تم تحديده. لا يجب استخدام هذا مباشرة لـ CPAN META "provides". انظر طريقة "provides" بدلاً من ذلك.
