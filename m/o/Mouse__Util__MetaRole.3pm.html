Mouse__Util__MetaRole(3pm)

الحزمة: perl-mouse

التراخيص: PerlArtistic, GPL

Mouse::Util::MetaRole(3pm) توثيق مقدم من مستخدم Perl Mouse::Util::MetaRole(3pm)

الاسم

Mouse::Util::MetaRole - تطبيق الأدوار على أي فئة وصفية، بالإضافة إلى فئة الكائن الأساسية

الملخص

package MyApp::Mouse;
use Mouse ();
use Mouse::Exporter;
use Mouse::Util::MetaRole;
use MyApp::Role::Meta::Class;
use MyApp::Role::Meta::Method::Constructor;
use MyApp::Role::Object;
Mouse::Exporter->setup_import_methods( also => 'Mouse' );
sub init_meta {
    shift;
    my %args = @_;
    Mouse->init_meta(%args);
    Mouse::Util::MetaRole::apply_metaroles(
        for             => $args{for_class},
        class_metaroles => {
            class       => ['MyApp::Role::Meta::Class'],
            constructor => ['MyApp::Role::Meta::Method::Constructor'],
        },
    );
    Mouse::Util::MetaRole::apply_base_class_roles(
        for   => $args{for_class},
        roles => ['MyApp::Role::Object'],
    );
    return $args{for_class}->meta();
}

الوصف

تم تصميم وحدة الأدوات هذه لمساعدة مؤلفي إضافات Mouse على كتابة إضافات قادرة على التعاون مع إضافات Mouse الأخرى. للقيام بذلك، يجب عليك كتابة إضافاتك كأدوار، والتي يمكن بعد ذلك تطبيقها ديناميكيًا على الفئات الوصفية للمتصل.

تضمن هذه الوحدة الحفاظ على أي فئات فائقة وأدوار موجودة تم تعيينها بالفعل للكائنات الوصفية، مما يعني أنه يمكن لأي عدد من الإضافات تطبيق الأدوار بأي ترتيب.

الاستخدام

من المهم جدًا أن تستدعي وظائف هذه الوحدة فقط عندما يتم استيراد وحدتك بواسطة المتصل. عملية تطبيق الأدوار على الفئة الوصفية تعيد تهيئة كائن الفئة الوصفية، مما يؤدي إلى مسح أي سمات موجودة تم تعريفها بالفعل. ومع ذلك، طالما أنك تفعل ذلك عند استيراد وحدتك، يجب ألا يكون لدى المتصل أي سمات معرفة بعد.

أسهل طريقة لضمان حدوث ذلك هي استخدام Mouse::Exporter، والتي يمكنها إنشاء طريقة "init_meta" المناسبة لك، والتأكد من استدعائها عند استيرادها.

الوظائف

توفر هذه الوحدة وظيفتين.

apply_metaroles( ... )

ستقوم هذه الوظيفة بتطبيق الأدوار على فئة وصفية واحدة أو أكثر للفئة المحددة. تقبل المعلمات التالية:

  • for => $name

    يحدد هذا الفئة أو التي سيتم تعديل فئاتها الوصفية. يمكن أن يكون هذا اسم حزمة، أو كائن وصفي مناسب (Mouse::Meta::Class أو Mouse::Meta::Role).

  • class_metaroles => \%roles

    هذا هو مرجع تجزئة يحدد الأدوار الوصفية التي سيتم تطبيقها على الفئة الوصفية للفئة والفئات الوصفية المضمنة فيها والفئات المساعدة.

    يجب أن يشير كل مفتاح بدوره إلى مرجع مصفوفة لأسماء الأدوار.

    تقبل المفاتيح التالية:

class
attribute
method
constructor
destructor
•
role_metaroles => \%roles

هذا هو مرجع تجزئة يحدد الأدوار الوصفية التي سيتم تطبيقها على الفئة الوصفية للدور والفئات الوصفية المضمنة فيها والفئات المساعدة.

تقبل المفاتيح التالية:

role
method

apply_base_class_roles( for => $class, roles => \@roles )

ستقوم هذه الوظيفة بتطبيق الأدوار المحددة على الفئة الأساسية للكائن.
