motion(1)

الحزمة: motion

التراخيص: GPL

MOTION(1) خيارات وملفات إعداد Motion MOTION(1)

الاسم

motion - اكتشاف الحركة باستخدام جهاز video4linux أو كاميرا شبكة

الملخص

motion [ -hbnsm ] [ -c مسار ملف الإعداد ] [ -d مستوى ] [ -k مستوى ] [ -p ملف pid ][ -l ملف log ]

الوصف

يستخدم Motion جهاز video4linux أو كاميرا شبكة لاكتشاف الحركة. إذا تم اكتشاف الحركة، يمكن التقاط صور عادية وصور للحركة. يمكن لـ Motion أيضًا اتخاذ إجراءات لإعلامك عند الحاجة. إنشاء لقطات شاشة آلية ممكن أيضًا.

خيارات

-c
المسار الكامل واسم ملف الإعداد. على سبيل المثال: /home/kurt/motion.conf الافتراضي هو /usr/local/etc/motion ما لم يتم تحديده بشكل مختلف عند بناء Motion. العديد من حزم RPM و Debian تستخدم /etc أو /etc/motion كافتراضي.
-h
عرض شاشة المساعدة.
-b
التشغيل في وضع الخادم (daemon).
-n
التشغيل في الوضع غير الخادم.
-s
التشغيل في وضع الإعداد. يفرض أيضًا الوضع غير الخادم.
-d
التشغيل مع مستوى تسجيل الرسائل 1-9.
-k
التشغيل مع نوع تسجيل الرسائل 1-9.
-l
المسار الكامل واسم ملف السجل.
-p
المسار الكامل واسم ملف معرف العملية (pid file). مثال: /var/run/motion.pid. الافتراضي غير محدد. يتم إنشاء ملف pid فقط عند بدء تشغيل Motion في وضع الخادم.
-m
البدء في وضع الإيقاف المؤقت.

خيارات ملف الإعداد

هذه هي الخيارات التي يمكن استخدامها في ملف الإعداد. يتم تجاوزها بواسطة سطر الأوامر! جميع القيم الرقمية هي أعداد صحيحة (لا يُسمح بالكسور). خيارات القيم المنطقية يمكن أن تكون قيد التشغيل أو إيقاف (القيم "1"، "yes" و "on" تعني جميعها صحيحة وأي قيمة أخرى تعني خاطئة).

sql_query
القيم: سلسلة نصية محددة من قبل المستخدم
الافتراضي: غير محدد
الوصف:
عبارة SQL لتنفيذها عندما يحفظ Motion ملف صورة أو يبدأ في تسجيل فيلم، ويتم تشغيل خيار التكوين sql_log_* المقابل لنوع الملف. استخدم نفس محددات التحويل كما في ميزات النص. محددات تحويل خاصة إضافية هي:
%n = الرقم الذي يمثل file_type %f = اسم الملف مع المسار الكامل
إعداد جدول نموذجي (ليس sql_query):
Mysql: CREATE TABLE security (camera INTEGER NOT NULL, filename CHAR(80) NOT NULL, frame INTEGER, file_type INTEGER NOT NULL, time_stamp DATETIME NOT NULL, text_event CHAR(255));
Postgresql: CREATE TABLE security (camera INTEGER NOT NULL, filename VARCHAR NOT NULL, frame INTEGER, file_type INTEGER NOT NULL, time_stamp TIMESTAMP NOT NULL, text_event VARCHAR);
sql_query نموذجي
INSERT INTO security(camera, filename, frame, file_type, time_stamp, text_event) VALUES(%t, '%f', %q, %n, '%Y-%m-%d %T', '%C')

الافتراضي: غير محدد
الوصف:
عبارة SQL لتنفيذها عند بداية حدث حركة. عندما يوفر مخطط الجدول ذي الصلة (و، بالنسبة لـ PostgreSQL، عبارة RETURNING مضمنة في هذه العبارة) ذلك، فإن قاعدة البيانات تنشئ معرف حدث فريد للجدول يتم إرجاعه واستبداله بمحدد التحويل %{dbeventid}. عند عدم إرجاع قيمة صالحة، يتم استبدال %{dbeventid} بالصفر.
