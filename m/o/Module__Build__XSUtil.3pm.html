Module__Build__XSUtil(3pm)

الحزمة: perl-module-build-xsutil

التراخيص: PerlArtistic, GPL

Module::Build::XSUtil(3pm) وثائق بيرل المساهمة من المستخدم Module::Build::XSUtil(3pm)

الاسم

Module::Build::XSUtil - فئة Module::Build لبناء وحدات XS

الملخص

استخدم في ملف Build.PL الخاص بك

use strict;
use warnings;
use Module::Build::XSUtil;

my $builder = Module::Build::XSUtil->new(
    dist_name            => 'Your-XS-Module',
    license              => 'perl',
    dist_author          => 'Your Name <yourname@example.com>',
    dist_version_from    => 'lib/Your/XS/Module',
    generate_ppport_h    => 'lib/Your/XS/ppport.h',
    generate_xshelper_h  => 'lib/Your/XS/xshelper.h',
    needs_compiler_c99   => 1,
);

$builder->create_build_script();

استخدم في وحدة بناة مخصصة.

package builder::MyBuilder;
use strict;
use warnings;
use base 'Module::Build::XSUtil';

sub new {
    my ($class, %args) = @_;
    my $self = $class->SUPER::new(
        %args,
        generate_ppport_h    => 'lib/Your/XS/ppport.h',
        generate_xshelper_h  => 'lib/Your/XS/xshelper.h',
        needs_compiler_c99   => 1,
    );
    return $self;
}

1;

الوصف

Module::Build::XSUtil هي فئة فرعية من Module::Build لدعم بناء وحدات XS.

هذه قائمة بالمعلمات الجديدة في طريقة Module::Build::new:

needs_compiler_c99
يتحقق هذا الخيار من توفر مترجم C99. إذا لم يكن متاحًا، يخرج Build.PL بالرمز 0.
needs_compiler_cpp
يتحقق هذا الخيار من توفر مترجم C++. إذا لم يكن متاحًا، يخرج Build.PL بالرمز 0.

بالإضافة إلى ذلك، أضف 'extra_compiler_flags' و 'extra_linker_flags' لـ C++.

generate_ppport_h
توليد ppport.h بواسطة Devel::PPPort.
generate_xshelper_h
توليد xshelper.h وهو ملف رأس مساعد لتضمين EXTERN.h و perl.h و XSUB.h و ppport.h، ويعرف بعض الأشياء المتعلقة بالتوافقية التي لا يدعمها ppport.h.

تم نقله من Module::Install::XSUtil.

cc_warnings
تمكين علامة تحذيرات المترجم. وهي ممكّنة افتراضيًا.
-g options
إذا تم استدعاء Build.PL بالخيار '-g'، فسيتم البناء باستخدام خيارات التصحيح.
