من 4.05

val find_first : f:(elt -> bool) -> t -> elt

find_first ~f s، حيث f هي دالة متزايدة رتيبة، تُرجع أدنى عنصر e في s بحيث f e، أو تطرح Not_found إذا لم يكن مثل هذا العنصر موجودًا.

على سبيل المثال، find_first (fun e -> Ord.compare e x >= 0) s تُرجع أول عنصر e في s حيث Ord.compare e x >= 0 (بشكل بديهي: e >= x)، أو تطرح Not_found إذا كان x أكبر من أي عنصر في s.

التجول

val iter : f:(elt -> unit) -> t -> unit

يطبق iter ~f s الدالة f بترتيب على جميع عناصر s. يتم تقديم عناصر s إلى f بترتيب تصاعدي وفقًا لترتيب أنواع العناصر.

val fold : f:(elt -> 'acc -> 'acc) -> t -> init:'acc -> 'acc

يحسب fold ~f s init (f xN ... (f x2 (f x1 init))...)، حيث x1 ... xN هي عناصر s بترتيب تصاعدي.

التحويل

val map : f:(elt -> elt) -> t -> t

map ~f s هي المجموعة التي عناصرها هي f a0، f a1، ...، f aN، حيث a0، a1، ...، aN هي عناصر s.

يتم تقديم العناصر إلى f بترتيب تصاعدي وفقًا لترتيب أنواع العناصر.

إذا لم يتم تعديل أي عنصر من s بواسطة f، تُرجع s دون تغيير. (إذا كانت كل نتيجة لـ f متساوية فيزيائيًا مع مدخلاتها، فإن المجموعة المرجعة تكون متساوية فيزيائيًا مع s.)

من 4.04

val filter : f:(elt -> bool) -> t -> t

تُرجع filter ~f s مجموعة جميع عناصر s التي تحقق الشرط f. إذا حقق f جميع عناصر s، تُرجع s دون تغيير (تكون نتيجة الدالة متساوية فيزيائيًا مع s).

قبل 4.03 لا يتم ضمان التساوي الفيزيائي.

val filter_map : f:(elt -> elt option) -> t -> t

تُرجع filter_map ~f s مجموعة جميع v بحيث f x = Some v لعنصر ما x في s.

على سبيل المثال،

filter_map (fun n -> if n mod 2 = 0 then Some (n / 2) else None) s
هي مجموعة أنصاف العناصر الزوجية في s.

إذا لم يتم تعديل أو إزالة أي عنصر من s بواسطة f (إذا كان f x = Some x لكل عنصر x)، فإن s تُرجع دون تغيير: نتيجة الدالة متساوية فيزيائيًا مع s.

من 4.11

val partition : f:(elt -> bool) -> t -> t * t

تُرجع partition ~f s زوجًا من المجموعات (s1, s2)، حيث s1 هي مجموعة جميع عناصر s التي تحقق الشرط f، و s2 هي مجموعة جميع عناصر s التي لا تحقق الشرط f.

This module type is implemented by the functors Set.Make and MoreLabels.Set.Make.

Return an arbitrary element of a non-empty set.

val split : elt -> t -> t * bool * t

split x s returns a triple (l, present, r) , where l is the set of elements of s that are strictly less than x ; r is the set of elements of s that are strictly greater than x ; present is false if s contains no element equal to x , or true if s contains an element equal to x .

val find_split : elt -> t -> elt * elt

find_split x s returns a pair (pred, succ) , where pred is the largest element of s less than or equal to x (or choose s if no such element exists), and succ is the smallest element of s greater than or equal to x (or choose s if no such element exists).

val filter : f:(elt -> bool) -> t -> t

Return a set containing only the elements that satisfy the predicate f.

val partition : f:(elt -> bool) -> t -> t * t

Return a pair of sets (s1, s2) where s1 contains elements satisfying f and s2 contains elements not satisfying f.

val map : f:(elt -> elt) -> t -> t

Map a function over the elements of a set. Note that the resulting set might be smaller if the function is not injective.

val fold_map : f:(elt -> elt) -> t -> t

Map a function over the elements of a set. This is a variant of map that may be more efficient.

val filter_map : f:(elt -> elt option) -> t -> t

Filter and map elements at the same time. Yields a set of the results.

val fold : f:(elt -> 'a -> 'a) -> t -> 'a -> 'a

Injectivity is not assumed for the mapping function.

val fold_right : f:(elt -> 'a -> 'a) -> t -> 'a -> 'a

Same as fold but iterates in decreasing order.

val fold_left : f:('a -> elt -> 'a) -> 'a -> t -> 'a

Same as fold but iterates in increasing order.

val fold_interval : f:(elt -> 'a -> 'a) -> t -> elt -> elt -> 'a

fold_interval f s a b iterates over the elements x of s such that a <= x <= b in increasing order.

val split_interval : t -> elt -> elt -> t * t * t

split_interval s a b returns a triple (l, m, r) where l contains elements of s less than a, m contains elements of s between a and b inclusive, and r contains elements of s greater than b.
