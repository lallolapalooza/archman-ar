الاسم

mfsipmap.cfg - تعيينات عناوين IP لخادم القطع في MooseFS

الوصف

يحتوي الملف mfsipmap.cfg على قوائم تعيينات عناوين IP لخوادم القطع في MooseFS.

الصيغة

صيغة الملف العامة: يحتوي المحتوى على إعادة تعيين واحدة أو أكثر لشبكات LAN مختلفة. تتكون كل إعادة تعيين لشبكة LAN أولاً من قائمة عناوين IP للعملاء التي سيتم إعادة تعيين عناوين IP لخادم القطع لها، ثم تعيينات خادم القطع نفسها. يتم بناء الملف الصحيح بهذه الطريقة: قائمة عناوين IP للعملاء - قائمة التعيينات - قائمة عناوين IP للعملاء - قائمة التعيينات وهكذا.

يمكن تعريف عناوين IP للعملاء كفئات في صيغتين: IP/MASK أو IP/BITS:
n.n.n.n/m.m.m.m
n.n.n.n/b
يمكن لتعريفات الفئات استخدام عناوين IP مختصرة، على سبيل المثال a.b.c.0/24 نفس الشيء مثل a.b.c/24، و a.b.0.0/255.255.0.0 نفس الشيء مثل a.b/255.255.0.0.

يمكن أيضًا تعريف عناوين IP للعملاء كالنطاقات في الصيغة IP - IP:
f.f.f.f-t.t.t.t

وأخيرًا، يمكن تعريف عناوين IP للعملاء كعناوين IP فردية، عنوان IP واحد لكل سطر:
n.n.n.n
x.x.x.x

دائمًا ما يتم تعريف تعيينات عناوين IP لخوادم القطع بصيغة IP:IP:
n.n.n.n:r.r.r.r
إذا تم تعريف عنوان IP للعميل في القائمة التي تسبق هذا التعيين مباشرة، فسيتم تقديم خادم القطع الذي يحتوي على عنوان IP على الجانب الأيسر من التعيين لهذا العميل بعنوان IP على الجانب الأيمن من التعيين.

يتم تجاهل الأسطر التي تبدأ بالرمز # كتعليقات.

ملاحظات

يسمح هذا الملف بتعريف تعيينات شبكات LAN في الحالات التي لا يوجد فيها مخطط ترقيم مشترك في شبكات LAN، أي حيث يكون للخوادم نفسها لواحق IP مختلفة في كل شبكة LAN. إذا كانت الأجهزة تحتوي على لواحق مشتركة، فاستخدم خيارات MULTILAN_BITS و MULTILAN_CLASSES من ملف mfsmaster.cfg بدلاً من ذلك.

أمثلة

محتوى الملف:

192.168.1/24
192.168.2.1-192.168.2.24
192.168.3.20

10.10.10.3:10.20.30.7
10.10.10.4:10.20.33.19

السلوك:

أي عميل لديه عنوان IP يبدأ بـ 192.168.1، أو يبدأ بـ 192.168.2 وينتهي بـ 1 إلى 24، أو لديه عنوان IP 192.168.3.20، إذا أراد التواصل مع خادم القطع بعنوان IP 10.10.10.3، فسيفعل ذلك بدلاً من ذلك باستخدام عنوان IP 10.20.30.7، ومع خادم القطع بعنوان IP 10.10.10.4 سيستخدم عنوان IP 10.20.33.19.

محتوى الملف:

192.168.1/24

10.10.10.3:10.20.30.7
10.10.10.4:10.20.33.19

192.168.2.1-192.168.2.24

10.10.10.3:10.20.38.8
10.10.10.5:10.20.38.37

السلوك:

أي عميل لديه عنوان IP يبدأ بـ 192.168.1، إذا أراد التواصل مع خادم القطع بعنوان IP 10.10.10.3، فسيفعل ذلك بدلاً من ذلك باستخدام عنوان IP 10.20.30.7، ومع خادم القطع بعنوان IP 10.10.10.4 سيستخدم عنوان IP 10.20.33.1. أي عميل لديه عنوان IP يبدأ بـ 192.168.2 وينتهي بـ 1 إلى 24، إذا أراد التواصل مع خادم القطع بعنوان IP 10.10.10.3، فسيفعل ذلك بدلاً من ذلك باستخدام عنوان IP 10.20.38.8، ومع خادم القطع بعنوان IP 10.10.10.5 سيستخدم عنوان IP 10.20.38.37. لاحظ أن نفس خادم القطع (بعنوان IP 10.10.10.3) سيتم تقديمه للعملاء من قوائم IP مختلفة بعنوان IP معاد تعيينه مختلف.

ملاحظة: الأسطر الفارغة بين الأقسام ليست ضرورية، يتم استخدامها في الأمثلة أعلاه فقط لسهولة القراءة.
