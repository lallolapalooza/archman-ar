mftraining(1)

الحزمة: tesseract

التراخيص: APACHE

MFTRAINING(1)   MFTRAINING(1)

الاسم

mftraining - تدريب الميزات لـ Tesseract

الملخص

mftraining -U unicharset -O lang.unicharset FILE...

الوصف

يأخذ mftraining قائمة بملفات .tr، والتي ينتج منها ملفات inttemp (النماذج الأولية للأشكال)، و shapetable، و pffmtable (عدد الميزات المتوقعة لكل حرف). (يتم أيضًا كتابة ملف رابع يسمى Microfeat بواسطة هذا البرنامج، ولكنه غير مستخدم.)

خيارات

-U FILE

(مدخل) الـ unicharset الذي تم إنشاؤه بواسطة unicharset_extractor(1)

-F font_properties_file

(مدخل) ملف خصائص الخط، كل سطر بالشكل التالي، حيث كل حقل بخلاف اسم الخط هو 0 أو 1: 
*font_name* *italic* *bold* *fixed_pitch* *serif* *fraktur*

-X xheights_file

(مدخل) ملف ارتفاعات x، كل سطر بالشكل التالي، حيث يتم حساب ارتفاع x على أنه ارتفاع x بالبكسل لحرف مرسوم بحجم 32 نقطة بدقة 300 نقطة في البوصة. [ أي، إذا كان ارتفاع x الأساسي + الصاعدات + الهابطات = 133، فما مقدار ارتفاع x؟ ] 
*font_name* *xheight*

-D dir

الدليل لكتابة ملفات المخرجات فيه.

-O FILE

(مخرج) الـ unicharset الناتج الذي سيتم تقديمه إلى combine_tessdata(1)
