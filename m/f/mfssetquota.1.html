mfssetquota(1)

الحزمة: moosefs

التراخيص: GPL-2.0-only

NAME

mfssetquota - set disk quota for a specific user or group on MooseFS

SYNOPSIS

mfssetquota [-h] [-v] [-r|-u] [-q] [-d|-i] <quota> <user or group name>

DESCRIPTION

The mfssetquota utility allows to set disk quota for a specific user or group on MooseFS. Quotas can be set for number of files (inodes) or for disk space (blocks).

User quotas are set for the user specified by name. Group quotas are set for the group specified by name.

If a user is a member of multiple groups, the most restrictive quota will be applied.

OPTIONS

-h
Display help message and exit.
-v
Verbose output.
-r
Set quota for a directory (path must be specified as <user or group name>).
-u
Set quota for a user (default).
-g
Set quota for a group.
-q
Set quota for number of files (inodes) instead of disk space.
-d
Set quota for disk space (blocks) (default).
-i
Set quota for number of files (inodes) (alias for -q).
<quota>
The quota value. It can be specified in human-readable format (e.g. 10G, 500M, 2K) or in bytes/inodes.
<user or group name>
The name of the user or group for which to set the quota. If -r is used, this should be the path to the directory.

NOTES

MooseFS quotas are managed by the Metadata Server (Metaserver). The quotas are stored in the Metaserver's storage.

The user or group must exist on the system where the command is run, and also in MooseFS.

EXAMPLES

Set 10GB disk quota for user 'john':

mfssetquota 10G john

Set 10000 files quota for group 'developers':

mfssetquota -g -q 10000 developers

Set 5GB disk quota for directory '/mnt/moosefs/shared':

mfssetquota -r 5G /mnt/moosefs/shared
