mfsgui(8)

الحزمة: moosefs

التراخيص: GPL-2.0-only

mfsgui(8) هذا جزء من MooseFS mfsgui(8)

الاسم

mfsgui - تشغيل، إعادة تشغيل أو إيقاف خادم واجهة المستخدم الرسومية لـ MooseFS

الملخص

mfsgui [-c CFGFILE] [-f] [-d] [-u] [-n] [-t LOCKTIMEOUT] [ACTION]

mfsgui -v

mfsgui -h

الوصف

mfsgui هو خادم واجهة المستخدم الرسومية لـ MooseFS. يتكون من خادم HTTP و نصوص برمجية تشكل الواجهة الرسومية لـ MooseFS. يمكن للمستخدم الوصول إلى الواجهة الرسومية عبر أي متصفح ويب، باستخدام عنوان IP (أو اسم النطاق المناسب) والمنفذ المحدد في mfsgui.cfg.

الخيارات

-v
طباعة معلومات الإصدار والخروج
-h
طباعة معلومات الاستخدام والخروج
-c CFGFILE
تحديد مسار بديل لملف التكوين (الافتراضي هو mfsgui.cfg في دليل التكوين الخاص بالنظام)
-f
التشغيل في المقدمة، عدم التشغيل كعملية خلفية (daemonize)
-d
التشغيل بخيارات خطيرة (الأسماء: DANGEROUS_*)
-u
تسجيل قيم التكوين غير المعرفة (عند افتراض القيمة الافتراضية)
-n
عدم محاولة زيادة حد حجم تفريغ الذاكرة الأساسية (core dump)
-t LOCKTIMEOUT
مدة الانتظار لملف القفل (بالثواني؛ الافتراضي هو 60 ثانية)
ACTION
يخبر خادم واجهة المستخدم الرسومية لـ MooseFS بتنفيذ أحد الإجراءات التالية:
start
تشغيل عملية خادم واجهة المستخدم الرسومية لـ MooseFS إذا لم تكن العملية قيد التشغيل بالفعل، وإلا عرض رسالة خطأ.
stop
إيقاف عملية خادم واجهة المستخدم الرسومية لـ MooseFS إذا كانت العملية قيد التشغيل، وإلا عرض رسالة خطأ.
restart
(الإجراء الافتراضي) إذا كانت عملية خادم واجهة المستخدم الرسومية لـ MooseFS قيد التشغيل، قم بإعادة تشغيلها، وإذا لم تكن قيد التشغيل، فقم بتشغيلها.
reload
إرسال إشارة إلى عملية خادم واجهة المستخدم الرسومية لـ MooseFS لإعادة تحميل ملفات التكوين.
info
إرسال إشارة إلى عملية خادم واجهة المستخدم الرسومية لـ MooseFS لتفريغ ملف معلومات التصحيح في دليل العمل.
test
يعرض "mfsgui pid: PID" إذا كان خادم واجهة المستخدم الرسومية لـ MooseFS قيد التشغيل (ويعيد 0) أو "mfsgui is not running" بخلاف ذلك (ويعيد 1).
kill
إرسال إشارة إنهاء إلى عملية خادم واجهة المستخدم الرسومية لـ MooseFS.
restore
لم يتم التنفيذ.

الملفات

mfsgui.cfg
ملف التكوين لعملية خادم واجهة المستخدم الرسومية لـ MooseFS؛ ارجع إلى دليل mfsgui.cfg(5) للتفاصيل
.mfsgui.lock
ملف قفل لعملية خادم واجهة المستخدم الرسومية لـ MooseFS قيد التشغيل (يتم إنشاؤه في دليل البيانات)
scripts
ملفات بايثون وجافاسكريبت مختلفة وغيرها (ثابتة) تستخدم لتقديم الواجهة الرسومية عبر HTTP؛ يتم تثبيت هذه الملفات في أي دليل هو الافتراضي في وقت التثبيت لـ ROOT_DIR في mfsgui.cfg
