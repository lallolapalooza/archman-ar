الاسم

mq_getsetattr - الحصول/تعيين سمات طابور الرسائل

الموجز

#include <mqueue.h>           /* تعريف struct mq_attr */
#include <sys/syscall.h>      /* تعريف الثوابت SYS_* */
#include <unistd.h>
int syscall(SYS_mq_getsetattr, mqd_t mqdes,
            const struct mq_attr *newattr, struct mq_attr *oldattr);

الوصف

لا تستخدم استدعاء النظام هذا.

هذا هو استدعاء النظام منخفض المستوى المستخدم لتنفيذ mq_getattr(3) و mq_setattr(3). لشرح كيفية عمل استدعاء النظام هذا، انظر وصف mq_setattr(3).
