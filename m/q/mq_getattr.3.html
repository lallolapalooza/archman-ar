mq_getattr(3) دليل وظائف المكتبة mq_getattr(3)

الاسم

mq_getattr, mq_setattr - الحصول/تعيين سمات طابور الرسائل

المكتبة

مكتبة الوقت الحقيقي (librt, -lrt)

الملخص

#include <mqueue.h>
int mq_getattr(mqd_t mqdes, struct mq_attr *attr);
int mq_setattr(mqd_t mqdes, const struct mq_attr *restrict newattr,
               struct mq_attr *restrict oldattr);

الوصف

يقوم mq_getattr() و mq_setattr() باسترداد وتعديل سمات طابور الرسائل المشار إليه بواسطة واصف طابور الرسائل mqdes على التوالي.

يقوم mq_getattr() بإرجاع بنية mq_attr في المخزن المؤقت الذي يشير إليه attr. يتم تعريف هذه البنية كالتالي:


struct mq_attr {
    long mq_flags;       /* علامات: 0 أو O_NONBLOCK */
    long mq_maxmsg;      /* الحد الأقصى لعدد الرسائل في الطابور */
    long mq_msgsize;     /* الحد الأقصى لحجم الرسالة (بايت) */
    long mq_curmsgs;     /* عدد الرسائل الموجودة حاليًا في الطابور */
};

يحتوي حقل mq_flags على علامات مرتبطة بوصف طابور الرسائل المفتوح. يتم تهيئة هذا الحقل عند إنشاء الطابور بواسطة mq_open(3). العلامة الوحيدة التي يمكن أن تظهر في هذا الحقل هي O_NONBLOCK.

يتم تعيين حقلي mq_maxmsg و mq_msgsize عند إنشاء طابور الرسائل بواسطة mq_open(3). حقل mq_maxmsg هو حد أعلى لعدد الرسائل التي يمكن وضعها في الطابور باستخدام mq_send(3). حقل mq_msgsize هو حد أعلى لحجم الرسائل التي يمكن وضعها في الطابور. يجب أن يكون لكلا هذين الحقلين قيمة أكبر من الصفر. تم وصف ملفي /proc اللذين يضعان حدودًا عليا لقيم هذه الحقول في mq_overview(7).

يعرض حقل mq_curmsgs عدد الرسائل الموجودة حاليًا في الطابور.

يقوم mq_setattr() بتعيين سمات طابور الرسائل باستخدام المعلومات المقدمة في بنية mq_attr التي يشير إليها newattr. السمة الوحيدة التي يمكن تعديلها هي تعيين علامة O_NONBLOCK في mq_flags. يتم تجاهل الحقول الأخرى في newattr. إذا كان الحقل oldattr ليس NULL، فإن المخزن المؤقت الذي يشير إليه يتم استخدامه لإرجاع بنية mq_attr تحتوي على نفس المعلومات التي يتم إرجاعها بواسطة mq_getattr().

قيمة الإرجاع

عند النجاح، تعيد mq_getattr() و mq_setattr() القيمة 0؛ عند حدوث خطأ، يتم إرجاع -1، مع تعيين errno للإشارة إلى الخطأ.

الأخطاء

EBADF
واصف طابور الرسائل المحدد في mqdes غير صالح.
EINVAL
newattr->mq_flags احتوى على بتات مضبوطة بخلاف O_NONBLOCK.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، راجع attributes(7).

الواجهة السمة القيمة
mq_getattr (), mq_setattr () سلامة الخيوط MT-Safe

الإصدارات

في لينكس، mq_getattr() و mq_setattr() هي وظائف مكتبة مستندة إلى استدعاء النظام mq_getsetattr(2).

المعايير

POSIX.1-2008.

التاريخ

POSIX.1-2001.

أمثلة

يمكن استخدام البرنامج أدناه لعرض القيم الافتراضية mq_maxmsg و mq_msgsize التي يتم تعيينها لطابور رسائل تم إنشاؤه باستدعاء mq_open(3) حيث يكون الوسيط attr هو NULL. إليك مثال لتشغيل البرنامج:


$ ./a.out /testq;
الحد الأقصى لعدد الرسائل في الطابور:   10
الحد الأقصى لحجم الرسالة:             8192

منذ لينكس 3.5، يمكن استخدام ملفات /proc التالية (الموصوفة في mq_overview(7)) للتحكم في القيم الافتراضية:


$ uname -sr;
Linux 3.8.0
$ cat /proc/sys/fs/mqueue/msg_default;
10
$ cat /proc/sys/fs/mqueue/msgsize_default;
8192

مصدر البرنامج

#include <err.h>
#include <fcntl.h>
#include <mqueue.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    mqd_t mqd;
    struct mq_attr attr;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s mq-name\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    mqd = mq_open(argv[1], O_CREAT | O_EXCL, 0600, NULL);
    if (mqd == (mqd_t) -1)
        err(EXIT_FAILURE, "mq_open");
    if (mq_getattr(mqd, &attr) == -1)
        err(EXIT_FAILURE, "mq_getattr");
    printf("Maximum # of messages on queue:   %ld\n", attr.mq_maxmsg);
    printf("Maximum message size:             %ld\n", attr.mq_msgsize);
    if (mq_unlink(argv[1]) == -1)
        err(EXIT_FAILURE, "mq_unlink");
    exit(EXIT_SUCCESS);
}
