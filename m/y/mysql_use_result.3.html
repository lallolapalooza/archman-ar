mysql_use_result(3)

الحزمة: mariadb

التراخيص: GPL-2.0-only

mysql_use_result(3) MariaDB Connector/C mysql_use_result(3)

الاسم

mysql_use_result - ترجع مجموعة نتائج غير مخزنة مؤقتًا

الملخص

#include <mysql.h>
MYSQL_RES * mysql_use_result(MYSQL * mysql);

الوصف

تُستخدم لبدء استرداد مجموعة نتائج من آخر استعلام تم تنفيذه باستخدام الدالة mysql_real_query() على اتصال قاعدة البيانات. يجب استدعاء إما هذه الدالة أو الدالة mysql_store_result(3) قبل استرداد نتائج الاستعلام، ويجب استدعاء إحداهما لمنع فشل الاستعلام التالي على اتصال قاعدة البيانات هذا.

المعلمات

•
mysql هو معرف اتصال، تم تخصيصه مسبقًا بواسطة mysql_init(3) وتم توصيله بواسطة mysql_real_connect(3).

ملاحظات

الدالة mysql_use_result() لا تنقل مجموعة النتائج بأكملها. لذلك، لا يمكن استخدام دوال متعددة مثل mysql_num_rows(3) أو mysql_data_seek(3). ستؤدي الدالة mysql_use_result() إلى حظر الاتصال الحالي حتى يتم استرداد جميع مجموعات النتائج أو تم تحرير مجموعة النتائج بواسطة mysql_free_result(3).

قيمة الإرجاع

ترجع مجموعة نتائج غير مخزنة مؤقتًا أو NULL إذا حدث خطأ.

انظر أيضًا

•

•
