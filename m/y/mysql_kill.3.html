mysql_kill(3)

الحزمة: mariadb

التراخيص: GPL-2.0-only

mysql_kill(3) MariaDB Connector/C mysql_kill(3)

الاسم

mysql_kill - يقتل اتصالاً

الملخص

#include <mysql.h>
int mysql_kill(MYSQL * mysql,
               unsigned long);

الوصف

تُستخدم هذه الدالة لطلب إنهاء خادم MariaDB لخيط (thread) معين بواسطة المعامل processid. يجب الحصول على هذه القيمة بواسطة [show-processlist()](SHOW PROCESSLIST]]. إذا كنت تحاول قتل الاتصال الخاص بك، فيجب استخدام mysql_thread_id(3).

المعاملات

•
mysql - معرف اتصال، تم تخصيصه مسبقًا بواسطة mysql_init(3) وتم توصيله بواسطة mysql_real_connect(3). تُرجع 0 عند النجاح، وإلا تُرجع قيمة غير صفرية.
•
long - معرف العملية

ملاحظات

•
لإيقاف أمر قيد التشغيل دون قتل الاتصال، استخدم KILL QUERY.
•
الدالة mysql_kill() تقتل الاتصال فقط، ولا تحرر أي ذاكرة - يجب القيام بذلك صراحةً عن طريق استدعاء mysql_close(3).

قيمة الإرجاع

تُرجع صفر عند النجاح، وقيمة غير صفرية عند حدوث خطأ.
