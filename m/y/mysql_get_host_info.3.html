mysql_get_host_info(3)

الحزمة: mariadb

التراخيص: GPL-2.0-only

mysql_get_host_info(3) MariaDB Connector/C mysql_get_host_info(3)

الاسم

mysql_get_host_info - يعيد معلومات المضيف

الملخص

#include <mysql.h>
const char * mysql_get_host_info(MYSQL * mysql);

الوصف

يصف نوع الاتصال المستخدم للاتصال، بما في ذلك اسم مضيف الخادم. يعيد سلسلة نصية، أو NULL إذا كان الاتصال غير صالح.

المعلمة

•
mysql - معرف اتصال، تم تخصيصه مسبقًا بواسطة mysql_init(3) وتم توصيله بواسطة mysql_real_connect(3).

قيمة الإرجاع

يعيد سلسلة نصية، تصف معلومات المضيف أو NULL إذا كان الاتصال غير صالح.
