mysql_change_user(3)

الحزمة: mariadb

التراخيص: GPL-2.0-only

mysql_change_user(3) MariaDB Connector/C mysql_change_user(3)

Name

mysql_change_user - يغير المستخدم وقاعدة البيانات الافتراضية

Synopsis

#include <mysql.h>
my_bool mysql_change_user(MYSQL * mysql,
                          const char * user,
                          const char * passwd,
                          const char * db);

Description

يغير المستخدم وقاعدة البيانات الافتراضية للاتصال الحالي.

لكي يتغير المستخدم بنجاح، يجب توفير اسم مستخدم وكلمة مرور صالحين، ويجب أن يكون لدى هذا المستخدم أذونات كافية للوصول إلى قاعدة البيانات المطلوبة. إذا فشل المصادقة لأي سبب، فستبقى مصادقة المستخدم الحالية.

Parameters

•
mysql هو معرف الاتصال، والذي تم تخصيصه مسبقًا بواسطة mysql_init(3) وتم توصيله بواسطة mysql_real_connect(3).
•
user - اسم المستخدم للمصادقة على الخادم
•
passwd - كلمة المرور للمصادقة على الخادم
•
db - قاعدة البيانات الافتراضية. إذا رغبت في ذلك، يمكن تمرير القيمة NULL مما يؤدي فقط إلى تغيير المستخدم وعدم تحديد قاعدة بيانات. لتحديد قاعدة بيانات في هذه الحالة، استخدم الدالة mysql_select_db(3).

Notes

•
سيؤدي `mysql_change_user` دائمًا إلى أن يتصرف اتصال قاعدة البيانات الحالي كما لو كان اتصال قاعدة بيانات جديد تمامًا، بغض النظر عما إذا كانت العملية قد اكتملت بنجاح. يشمل هذا الإعادة تعيين تنفيذ التراجع عن أي معاملات نشطة، وإغلاق جميع الجداول المؤقتة، وإلغاء قفل جميع الجداول.
•
لمنع هجمات رفض الخدمة والهجمات العشوائية، سيقوم الخادم بحظر الاتصال إذا فشلت mysql_change_user() ثلاث مرات متتالية.

Return value

يعيد صفر عند النجاح، ورقم غير صفر إذا حدث خطأ.
