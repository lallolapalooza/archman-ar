mysql_set_character_set(3)

الحزمة: mariadb

التراخيص: GPL-2.0-only

mysql_set_character_set(3) MariaDB Connector/C mysql_set_character_set(3)

الاسم

mysql_set_character_set - يضبط مجموعة الأحرف الافتراضية للاتصال

الملخص

#include <mysql.h>
int mysql_set_character_set(MYSQL * mysql,
                            const char * csname);

الوصف

يضبط مجموعة الأحرف الافتراضية للاتصال الحالي. يعيد صفرًا عند النجاح، وغير صفر عند الفشل.

المعلمات

•
mysql - مقبض mysql، تم تخصيصه مسبقًا بواسطة mysql_init(3) أو mysql_real_connect(3).
•
csname - اسم مجموعة الأحرف ### ملاحظات
•
يوصى بشدة باستخدام mysql_set_character_set() بدلاً من SET NAMES ... حيث أن mysql_real_escape_string(3) قد تفشل أو تقدم نتائج غير متوقعة.

قيمة الإرجاع

صفر عند النجاح، غير صفر إذا حدث خطأ
