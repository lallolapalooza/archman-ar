mysql_stmt_execute(3)

الحزمة: mariadb

التراخيص: GPL-2.0-only

mysql_stmt_execute(3) MariaDB Connector/C mysql_stmt_execute(3)

الاسم

mysql_stmt_execute - تنفيذ عبارة مُعدة مسبقًا

الملخص

#include <mysql.h>
int mysql_stmt_execute(MYSQL_STMT * stmt);

الوصف

تنفيذ عبارة مُعدة مسبقًا تم إعدادها سابقًا بواسطة mysql_stmt_prepare(3). عند التنفيذ، سيتم استبدال أي علامات معاملات موجودة تلقائيًا بالبيانات المناسبة.

المعامل

•
stmt - مقبض عبارة، تم تخصيصه سابقًا بواسطة mysql_stmt_init(3).

قيمة الإرجاع

تُرجع صفرًا عند النجاح، وقيمة غير صفرية عند الفشل.

ملاحظات

•
إذا كانت العبارة UPDATE أو REPLACE أو DELETE أو INSERT، فيمكن تحديد العدد الإجمالي للصفوف المتأثرة باستخدام الدالة mysql_stmt_affected_rows(3). وبالمثل، إذا كانت الاستعلام ينتج مجموعة نتائج، فسيتم استخدام الدالة mysql_stmt_fetch(3).
