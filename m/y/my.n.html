my(n)

الحزمة: tcl

التراخيص: TCL

my(n) أوامر TclOO my(n)

الاسم

my - استدعاء أي طريقة للكائن الحالي

ملخص

package require TclOO
my methodName ?arg ...?

الوصف

يُستخدم الأمر my للسماح لطرق الكائنات باستدعاء أي طريقة للكائن (أو فئته). على وجه الخصوص، مجموعة القيم الصالحة لـ methodName هي مجموعة جميع الطرق التي يدعمها كائن وفئاته الأصلية، بما في ذلك تلك التي لم يتم تصديرها. الكائن الذي يتم استدعاء الطريقة عليه هو دائمًا الكائن الذي هو السياق الحالي للطريقة (أي الكائن الذي تم إرجاعه بواسطة self object) الذي تم منه استدعاء الأمر my.

كل كائن له أمر my الخاص به، وهو موجود في مساحة اسم المثيل الخاص به.

أمثلة

يوضح هذا المثال الاستخدام الأساسي لـ my لاستخدام طريقة variables من فئة oo::object، والتي ليست مرئية للجمهور بشكل افتراضي:

oo::class create c {
    method count {} {
        my variable counter
        puts [incr counter]
    }
}
c create o
o count              → يطبع "1"
o count              → يطبع "2"
o count              → يطبع "3"
