mysql_config_editor(1)

الحزمة: percona-server

التراخيص: GPL

MYSQL_CONFIG_EDITOR(1) MySQL Database System MYSQL_CONFIG_EDITOR(1)

الاسم

mysql_config_editor - تهيئة معلومات المصادقة للاتصال بخادم MySQL

ملخص

mysql_config_editor options command

الوصف

تتيح أداة mysql_config_editor تخزين بيانات الاعتماد للمصادقة في ملف مسارات تسجيل دخول مشفر اسمه .mylogin.cnf. يقع الملف في دليل %APPDATA%\MySQL على أنظمة Windows وفي الدليل الرئيسي للمستخدم الحالي على الأنظمة غير التابعة لنظام Windows. يمكن قراءة الملف لاحقًا بواسطة برامج عميل MySQL للحصول على بيانات اعتماد المصادقة للاتصال بخادم MySQL.

الشكل غير المشفر لملف مسار تسجيل الدخول .mylogin.cnf يتكون من مجموعات خيارات، مشابهة لملفات الخيارات الأخرى. يطلق على كل مجموعة خيارات في .mylogin.cnf اسم "مسار تسجيل دخول"، وهو مجموعة تسمح فقط بخيارات معينة: host، user، password، port و socket. فكر في مجموعة خيارات مسار تسجيل الدخول على أنها مجموعة من الخيارات التي تحدد خادم MySQL الذي سيتم الاتصال به والحساب الذي سيتم المصادقة به. هذا مثال غير مشفر:

[client]
user = mydefaultname
password = mydefaultpass
host = 127.0.0.1
[mypath]
user = myothername
password = myotherpass
host = localhost

عند استدعاء برنامج عميل للاتصال بالخادم، يستخدم العميل .mylogin.cnf بالاقتران مع ملفات الخيارات الأخرى. أولوية هذا الملف أعلى من ملفات الخيارات الأخرى، ولكنها أقل من الخيارات المحددة صراحةً في سطر أوامر العميل. للحصول على معلومات حول الترتيب الذي يتم به استخدام ملفات الخيارات، راجع القسم 6.2.2.2، "استخدام ملفات الخيارات".

لتحديد اسم ملف مسار تسجيل دخول بديل، قم بتعيين متغير البيئة MYSQL_TEST_LOGIN_FILE. يتعرف mysql_config_editor و عملاء MySQL القياسيون (mysql، mysqladmin، وما إلى ذلك) وأداة الاختبار mysql-test-run.pl على هذا المتغير.

تستخدم البرامج المجموعات في ملف مسار تسجيل الدخول على النحو التالي:

• يعمل mysql_config_editor على مسار تسجيل الدخول للعميل افتراضيًا إذا لم تحدد خيار --login-path=name للإشارة صراحةً إلى مسار تسجيل الدخول المراد استخدامه.
• بدون خيار --login-path، تقرأ برامج العميل مجموعات الخيارات نفسها من ملف مسار تسجيل الدخول التي تقرأها من ملفات الخيارات الأخرى. ضع في اعتبارك هذا الأمر: 
mysql

افتراضيًا، يقرأ العميل mysql مجموعات [client] و [mysql] من ملفات الخيارات الأخرى، لذا يقرأها من ملف مسار تسجيل الدخول أيضًا.

• مع خيار --login-path، تقرأ برامج العميل مسار تسجيل الدخول المسمى بالإضافة إلى ذلك من ملف مسار تسجيل الدخول. تظل مجموعات الخيارات المقروءة من ملفات الخيارات الأخرى كما هي. ضع في اعتبارك هذا الأمر: 
mysql --login-path=mypath

يقرأ العميل mysql مجموعات [client] و [mysql] من ملفات الخيارات الأخرى، و [client] و [mysql] و [mypath] من ملف مسار تسجيل الدخول.

• تقرأ برامج العميل ملف مسار تسجيل الدخول حتى عند استخدام الخيار --no-defaults، ما لم يتم تعيين --no-login-paths. يسمح هذا بتحديد كلمات المرور بطريقة أكثر أمانًا من سطر الأوامر حتى إذا كان --no-defaults موجودًا.

يقوم mysql_config_editor بتشفير ملف .mylogin.cnf بحيث لا يمكن قراءته كنص عادي، وتستخدم محتوياته عند فك تشفيرها بواسطة برامج العميل في الذاكرة فقط. بهذه الطريقة، يمكن تخزين كلمات المرور في ملف بتنسيق غير نصي عادي واستخدامها لاحقًا دون الحاجة إلى كشفها أبدًا في سطر الأوامر أو في متغير بيئة. يوفر mysql_config_editor أمر طباعة لعرض محتويات ملف مسار تسجيل الدخول، ولكن حتى في هذه الحالة، يتم إخفاء قيم كلمات المرور بحيث لا تظهر أبدًا بطريقة يمكن للمستخدمين الآخرين رؤيتها.

التشفير الذي يستخدمه mysql_config_editor يمنع ظهور كلمات المرور كنص عادي في .mylogin.cnf ويوفر مقياسًا للأمان عن طريق منع الكشف غير المقصود عن كلمات المرور. على سبيل المثال، إذا عرضت ملف خيارات my.cnf غير المشفر العادي على الشاشة، فإن أي كلمات مرور يحتوي عليها تكون مرئية لأي شخص. مع .mylogin.cnf، هذا ليس هو الحال، ولكن التشفير المستخدم ليس من المرجح أن يردع مهاجمًا مصممًا ولا يجب اعتباره غير قابل للكسر. يمكن لمستخدم يمكنه الحصول على صلاحيات إدارة النظام على جهازك للوصول إلى ملفاتك فك تشفير ملف .mylogin.cnf ببعض الجهد.

يجب أن يكون ملف مسار تسجيل الدخول قابلاً للقراءة والكتابة للمستخدم الحالي، وغير قابل للوصول للمستخدمين الآخرين. بخلاف ذلك، يتجاهل mysql_config_editor الملف، ولا تستخدمه برامج العميل أيضًا.

استدعاء mysql_config_editor بهذا الشكل:

mysql_config_editor [program_options] command [command_options]

إذا كان ملف مسار تسجيل الدخول غير موجود، يقوم mysql_config_editor بإنشائه.

تُعطى وسيطات الأوامر على النحو التالي:

• program_options تتكون من خيارات mysql_config_editor العامة.
• يشير الأمر (command) إلى الإجراء الذي سيتم تنفيذه على ملف مسار تسجيل الدخول .mylogin.cnf. على سبيل المثال، يقوم set بكتابة مسار تسجيل دخول إلى الملف، و remove يزيل مسار تسجيل دخول، و print يعرض محتويات مسار تسجيل الدخول.
• command_options تشير إلى أي خيارات إضافية خاصة بالأمر، مثل اسم مسار تسجيل الدخول والقيم المراد استخدامها في مسار تسجيل الدخول.

موقع اسم الأمر ضمن مجموعة وسيطات البرنامج مهم. على سبيل المثال، هذه الأوامر لها نفس الوسيطات، ولكنها تنتج نتائج مختلفة:

mysql_config_editor --help set
mysql_config_editor set --help

يعرض الأمر الأول رسالة مساعدة عامة لـ mysql_config_editor، ويتجاهل أمر set. يعرض الأمر الثاني رسالة مساعدة خاصة بأمر set.

افترض أنك تريد إنشاء مسار تسجيل دخول للعميل يحدد معلمات الاتصال الافتراضية الخاصة بك، ومسار تسجيل دخول إضافي يسمى remote للاتصال بخادم MySQL على المضيف remote.example.com. تريد تسجيل الدخول على النحو التالي:

• افتراضيًا، إلى الخادم المحلي باسم مستخدم وكلمة مرور localuser و localpass
• إلى الخادم البعيد باسم مستخدم وكلمة مرور remoteuser و remotepass

لإعداد مسارات تسجيل الدخول في ملف .mylogin.cnf، استخدم أوامر set التالية. أدخل كل أمر في سطر واحد، وأدخل كلمات المرور المناسبة عند المطالبة:

$> mysql_config_editor set --login-path=client
         --host=localhost --user=localuser --password
Enter password: enter password "localpass" here
$> mysql_config_editor set --login-path=remote
         --host=remote.example.com --user=remoteuser --password
Enter password: enter password "remotepass" here

يستخدم mysql_config_editor مسار تسجيل الدخول للعميل افتراضيًا، لذا يمكن حذف الخيار --login-path=client من الأمر الأول دون تغيير تأثيره.

لرؤية ما يكتبه mysql_config_editor في ملف .mylogin.cnf، استخدم أمر print:

$> mysql_config_editor print --all
[client]
user = localuser
password = *****
host = localhost
[remote]
user = remoteuser
password = *****
host = remote.example.com

يعرض أمر print كل مسار تسجيل دخول كمجموعة من الأسطر التي تبدأ برأس مجموعة يشير إلى اسم مسار تسجيل الدخول بين قوسين مربعين، متبوعًا بقيم الخيارات لمسار تسجيل الدخول. يتم إخفاء قيم كلمات المرور ولا تظهر كنص عادي.

إذا لم تحدد --all لعرض جميع مسارات تسجيل الدخول أو --login-path=name لعرض مسار تسجيل دخول مسمى، فإن أمر print يعرض مسار تسجيل الدخول للعميل افتراضيًا، إذا كان موجودًا.

كما هو موضح في المثال السابق، يمكن أن يحتوي ملف مسار تسجيل الدخول على مسارات تسجيل دخول متعددة. بهذه الطريقة، يسهل mysql_config_editor إعداد "شخصيات" متعددة للاتصال بخوادم MySQL مختلفة، أو للاتصال بخادم معين باستخدام حسابات مختلفة. يمكن تحديد أي من هذه لاحقًا بالاسم باستخدام الخيار --login-path عند استدعاء برنامج عميل. على سبيل المثال، للاتصال بالخادم البعيد، استخدم هذا الأمر:

mysql --login-path=remote

هنا، يقرأ mysql مجموعات الخيارات [client] و [mysql] من ملفات الخيارات الأخرى، ومجموعات [client] و [mysql] و [remote] من ملف مسار تسجيل الدخول.

mysql_config_editor(1) - Arch Linux

NAME

mysql_config_editor - MySQL configuration file utility

SYNOPSIS

mysql_config_editor [options]

DESCRIPTION

The mysql_config_editor utility enables you to store connection parameters in an option file (the default is ~/.my.cnf). This utility is useful for connecting to MySQL servers without having to specify connection parameters on the command line or in scripts.

The utility encrypts the values for connection parameters using a passphrase that you specify. For more information about the utility and how to use it, refer to the MySQL documentation at http://dev.mysql.com/doc/.
