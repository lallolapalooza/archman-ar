mysql_get_server_info(3) MariaDB Connector/C mysql_get_server_info(3)

الاسم

mysql_get_server_info - يعيد إصدار الخادم كسلسلة نصية

الملخص

#include <mysql.h>
const char * mysql_get_server_info(MYSQL * mysql);

الوصف

يعيد إصدار الخادم أو NULL عند الفشل.

المعامل

•
mysql - معرف الاتصال، والذي تم تخصيصه سابقًا بواسطة mysql_init(3) وتم اتصاله بواسطة mysql_real_connect(3).

ملاحظات

للحصول على رقم إصدار الخادم، يرجى استخدام mysql_get_server_version(3).

قيمة الإرجاع

يعيد إصدار الخادم كسلسلة نصية منتهية بصفر أو NULL عند الفشل.
