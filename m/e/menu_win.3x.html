menu_win(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

menu_win(3X) استدعاءات المكتبة menu_win(3X)

الاسم

menu_win - ربط وفك ربط نافذة القائمة ونافذة فرعية

الملخص

#include <menu.h>
int set_menu_win(MENU *menu, WINDOW *win);
WINDOW *menu_win(const MENU *menu);
int set_menu_sub(MENU *menu, WINDOW *sub);
WINDOW *menu_sub(const MENU *menu);
int scale_menu(const MENU *menu, int *rows, int *columns);

الوصف

لكل قائمة زوج من نوافذ curses المرتبطة بها. تعرض نافذة القائمة أي عنوان وحدود مرتبطة بالنافذة؛ وتعرض النافذة الفرعية للقائمة العناصر المتاحة حاليًا للاختيار.

الدوال الأربع الأولى تحصل على وتعين هذه النوافذ. ليس من الضروري تعيين أي من النافذتين؛ افتراضيًا، يستخدم كود القيادة stdscr لكليهما.

في دوال set_، يتم التعامل مع وسيط النافذة NULL كما لو كانت stsdcr. يتم التعامل مع وسيط القائمة NULL على أنه طلب لتغيير نافذة القائمة الافتراضية للنظام أو النافذة الفرعية.

تقوم الدالة scale_menu بإرجاع الحد الأدنى للحجم المطلوب للنافذة الفرعية لـ menu.

قيمة الإرجاع

تُرجع الروتينات التي تُرجع مؤشرات NULL عند حدوث خطأ. تُرجع الروتينات التي تُرجع عددًا صحيحًا أحد رموز الخطأ التالية:

E_OK
نجح الروتين.
E_SYSTEM_ERROR
حدث خطأ في النظام (انظر errno(3)).
E_BAD_ARGUMENT
اكتشف الروتين وسيطًا غير صحيح أو خارج النطاق.
E_POSTED
تم نشر القائمة بالفعل.
E_NOT_CONNECTED
لم يتم توصيل أي عناصر بالقائمة.

قابلية النقل

تحاكي هذه الروتينات مكتبة القائمة System V. لم يتم دعمها في الإصدار 7 أو إصدارات BSD.
