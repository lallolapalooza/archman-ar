NAME

memcached_strerror — get a string representation of a memcached error code

SYNOPSIS

#include <libmemcached/memcached.h>

char *memcached_strerror(memcached_return_t rc);

DESCRIPTION

The memcached_strerror function is used to get a human readable string representation of a memcached error code. The memcached library returns error codes of type memcached_return_t for many operations.

For example, if a call to memcached_get fails with MEMCACHED_NOTFOUND, you can pass this error code to memcached_strerror to get the string "Server has noted that the key is not found".

The returned string is a static string and should not be freed.

RETURN VALUE

Returns a pointer to a null-terminated string that describes the error code. If the error code is unknown, a string indicating this will be returned.
