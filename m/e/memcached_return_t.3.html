memcached_return_t - قيم نوع الإرجاع

الملخص

#include <libmemcached/memcached.h>
قم بالترجمة والربط مع -lmemcached
bool memcached_success(memcached_return_t rc)
bool memcached_continue(memcached_return_t rc)
bool memcached_failed(memcached_return_t rc)
bool memcached_fatal(memcached_return_t rc)
typedef enum memcached_return_t memcached_return_t
enum memcached_return_t
enumerator MEMCACHED_AUTH_CONTINUE
تم إيقاف المصادقة مؤقتًا.
enumerator MEMCACHED_AUTH_FAILURE
بيانات الاعتماد المقدمة غير صالحة لهذا الخادم.
enumerator MEMCACHED_AUTH_PROBLEM
حدثت مشكلة غير معروفة أثناء المصادقة.
enumerator MEMCACHED_BAD_KEY_PROVIDED
المفتاح المقدم ليس مفتاحًا صالحًا.
enumerator MEMCACHED_BUFFERED
تم تخزين الطلب مؤقتًا.
enumerator MEMCACHED_CLIENT_ERROR
حدث خطأ غير معروف من جانب العميل داخليًا.
enumerator MEMCACHED_CONNECTION_BIND_FAILURE
مهمل منذ الإصدار <0.30.

لم نتمكن من الربط() بالمقبس.

enumerator MEMCACHED_CONNECTION_FAILURE
حدث خطأ غير معروف أثناء محاولة الاتصال بخادم.
enumerator MEMCACHED_CONNECTION_SOCKET_CREATE_FAILURE
مهمل منذ الإصدار <0.30.

حدث خطأ أثناء محاولة الاتصال بخادم. من المحتمل أن يكون عدد واصفات الملفات بحاجة إلى زيادة أو أنك نفدت الذاكرة.

enumerator MEMCACHED_DATA_DOES_NOT_EXIST
البيانات المطلوبة باستخدام المفتاح المعطى لم يتم العثور عليها.
enumerator MEMCACHED_DATA_EXISTS
البيانات المطلوبة باستخدام المفتاح المعطى لم يتم العثور عليها.
enumerator MEMCACHED_DELETED
تم حذف الكائن المطلوب بالمفتاح.
enumerator MEMCACHED_DEPRECATED
الدالة المطلوبة تم إهمالها.
enumerator MEMCACHED_E2BIG
العنصر كبير جدًا بحيث لا يمكن للخادم تخزينه.
enumerator MEMCACHED_END
أكمل الخادم إرجاع جميع الكائنات المطلوبة.
enumerator MEMCACHED_ERRNO
حدث خطأ في المشغل الذي قام بتعيين errno.
enumerator MEMCACHED_FAIL_UNIX_SOCKET
لم يتم إنشاء اتصال بخادم عبر مقبس نطاق unix.
enumerator MEMCACHED_FAILURE
مهمل منذ الإصدار <0.30.

حدث فشل غير معروف في الخادم.

enumerator MEMCACHED_FETCH_NOTFINISHED
تم تقديم طلب، لكن الخادم لم يكمل جلب الطلب الأخير.
enumerator MEMCACHED_HOST_LOOKUP_FAILURE
حدث فشل في DNS.
enumerator MEMCACHED_INVALID_ARGUMENTS
الوسائط المقدمة للدالة المعطاة لم تكن صالحة.
enumerator MEMCACHED_INVALID_HOST_PROTOCOL
الخادم الذي تتصل به لديه بروتوكول غير صالح. على الأرجح أنك تتصل بخادم أقدم لا يتحدث البروتوكول الثنائي.
enumerator MEMCACHED_ITEM
تم جلب عنصر (هذا خطأ داخلي فقط).
enumerator MEMCACHED_KEY_TOO_BIG
المفتاح المقدم كبير جدًا بالنسبة للخادم المعطى.
enumerator MEMCACHED_MAXIMUM_RETURN
هذه حالة داخلية فقط.
enumerator MEMCACHED_MEMORY_ALLOCATION_FAILURE
حدث خطأ أثناء محاولة تخصيص الذاكرة.
enumerator MEMCACHED_NO_KEY_PROVIDED
مهمل منذ الإصدار <0.30: استخدم MEMCACHED_BAD_KEY_PROVIDED بدلاً من ذلك.

لم يتم تقديم أي مفتاح.

enumerator MEMCACHED_NO_SERVERS
لم تتم إضافة أي خوادم إلى كائن memcached_st.
enumerator MEMCACHED_NOTFOUND
لم يتم العثور على الكائن المطلوب.
enumerator MEMCACHED_NOTSTORED
فشل طلب تخزين كائن.
enumerator MEMCACHED_NOT_SUPPORTED
الدالة المعطاة غير مدعومة في الخادم.
enumerator MEMCACHED_PARSE_ERROR

NAME

memcached_return_t — return values for libmemcached

SYNOPSIS

  MEMCACHED_SUCCESS,
  MEMCACHED_FAILURE,
  MEMCACHED_HOST_LOOKUP_FAILURE,
  MEMCACHED_CONNECTION_FAILURE,

  MEMCACHED_CONNECTION_REMOTE_ERROR,
  MEMCACHED_CONNECTION_TIMEOUT,
  MEMCACHED_NOT_STORED,

DESCRIPTION

The memcached_return_t is an enumeration of all the possible error codes returned by the libmemcached library.

enumerator MEMCACHED_SUCCESS
The request was successfully executed.
enumerator MEMCACHED_FAILURE
A generic failure.
enumerator MEMCACHED_HOST_LOOKUP_FAILURE
The host name could not be resolved.
enumerator MEMCACHED_CONNECTION_FAILURE
A failure occurred while trying to connect to the memcached server.
enumerator MEMCACHED_CONNECTION_LOCAL_ERROR
An error occurred on the client side during connection.
enumerator MEMCACHED_CONNECTION_REMOTE_ERROR
An error occurred on the server side during connection.
enumerator MEMCACHED_CONNECTION_TIMEOUT
The connection to the memcached server timed out.
enumerator MEMCACHED_NOT_STORED
The object was not stored on the server.
enumerator MEMCACHED_ERROR
An unknown error occurred.
enumerator MEMCACHED_DATA_EXISTS
The object already exists on the server.
enumerator MEMCACHED_DATA_NOT_EXISTS
The object does not exist on the server.
enumerator MEMCACHED_NOT_IMPLEMENTED
The requested command is not implemented.
enumerator MEMCACHED_INVALID_ARGUMENTS
The arguments provided to the function are invalid.
enumerator MEMCACHED_INVALID_COMMAND
The command provided is invalid.
enumerator MEMCACHED_OUT_OF_MEMORY_RESERVES
Not enough memory is available.
enumerator MEMCACHED_TIMEOUT
The operation timed out.
enumerator MEMCACHED_ERROR_UNKNOWN_STORE_KEY
An unknown error occurred while storing the object.
enumerator MEMCACHED_ERROR_FAIL_USER_REQUEST
A user request failed.
enumerator MEMCACHED_PARSE_ERROR
An error has occurred while trying to parse the configuration string. You should use memparse to determine what the error was.
enumerator MEMCACHED_PARSE_USER_ERROR
An error has occurred in parsing the configuration string.
enumerator MEMCACHED_PARTIAL_READ
The read was only partially successful.
enumerator MEMCACHED_PROTOCOL_ERROR
An unknown error has occurred in the protocol.
enumerator MEMCACHED_CLIENT_ERROR
An unknown error has occurred in the client.
enumerator MEMCACHED_SERVER_ERROR
An unknown error has occurred in the server.
enumerator MEMCACHED_READ_FAILURE
A read failure has occurred.
enumerator MEMCACHED_WRITE_FAILURE
An error has occurred while trying to write to a server.
enumerator MEMCACHED_FLUSH_FAILED
The flush command failed.
enumerator MEMCACHED_SOME_ERRORS
A multi request has been made, and some undetermined number of errors have occurred.
enumerator MEMCACHED_NO_SERVERS
No servers are available to handle the request.
enumerator MEMCACHED_BINARY_PROTOCOL_ERROR
An error occurred in the binary protocol.
enumerator MEMCACHED_EBADMESSAGE
Bad message.
enumerator MEMCACHED_ENOMSG
No message.
enumerator MEMCACHED_ESMALL
Too small.
enumerator MEMCACHED_CONNECTION_BAD_HANDLE
Bad connection handle.
enumerator MEMCACHED_GETMESSAGE_ERROR
An error occurred while retrieving a message.
enumerator MEMCACHED_POOL_EXHAUSTED
The connection pool is exhausted.
enumerator MEMCACHED_END
End of results.
enumerator MEMCACHED_STORED
The requested object has been successfully stored on the server.
enumerator MEMCACHED_NOTFOUND
The requested object was not found on the server.
enumerator MEMCACHED_DELETED
The requested object has been successfully deleted from the server.
enumerator MEMCACHED_ERROR_MAX
The maximum error value.
enumerator MEMCACHED_STAT
A "stat" command has been returned in the protocol.
enumerator MEMCACHED_VALUE
A value has been returned from the server (this is an internal condition only).
enumerator MEMCACHED_SERVER_MARKED_DEAD
The requested server has been marked dead.
enumerator MEMCACHED_UNKNOWN_STAT_KEY
The server you are communicating with has a stat key which has not be defined in the protocol.
enumerator MEMCACHED_UNBRIEFCASE
Error with briefcase.
enumerator MEMCACHED_EBADVALUE
Bad value.
enumerator MEMCACHED_CONNECTION_RETRY
Connection retry.
enumerator MEMCACHED_INVALID_HOST_PROTOCOL
The host protocol is invalid.
enumerator MEMCACHED_INJECTOR_ERROR
An error occurred in the injector.
enumerator MEMCACHED_OUT_OF_ORDER
Results are out of order.
enumerator MEMCACHED_UNSUPPORTED_OPERATION
The requested operation is unsupported.
enumerator MEMCACHED_PARTIAL_CMD_MEMCACHED_ERRNO
Partial command, memcached errno.
enumerator MEMCACHED_UNKNOWN_READ_FAILURE
An unknown read failure only occurs when either there is a bug in the server, or in rare cases where an ethernet nic is reporting dubious information.
enumerator MEMCACHED_CONFIG_ERROR
An error occurred while parsing the configuration.
