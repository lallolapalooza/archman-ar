memcached_increment(3)

The memcached_increment() function is used to atomically increment a value in memcached.

Syntax

memcached_return_t memcached_increment(memcached_st *mem,
    const char *key, size_t key_length, uint64_t offset, uint64_t *value);

Description

The memcached_increment() function atomically increments the value associated with the given key by the specified offset. The new value is returned in the value argument. If the key does not exist, it will be created with the value set to the offset.

Parameters

  • mem: A pointer to the memcached_st structure.
  • key: The key of the value to increment.
  • key_length: The length of the key.
  • offset: The amount by which to increment the value.
  • value: A pointer to a uint64_t where the new value will be stored.

Return Values

Returns MEMCACHED_SUCCESS on success, or an error code on failure.
