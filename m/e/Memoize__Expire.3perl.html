Memoize__Expire.3perl

الحزمة: perl

التراخيص: Artistic-1.0-Perl OR GPL-1.0-or-later

Memoize::Expire(3perl) دليل مبرمجي Perl Memoize::Expire(3perl)

الاسم

Memoize::Expire - وحدة توصيل لانتهاء صلاحية القيم المخزنة مؤقتًا تلقائيًا

الملخص

use Memoize;
use Memoize::Expire;
tie my %cache => 'Memoize::Expire',
                   LIFETIME => $lifetime,    # بالثواني
                   NUM_USES => $n_uses;
memoize 'function', SCALAR_CACHE => [HASH => \%cache ];

الوصف

Memoize::Expire هي وحدة توصيل لوحدة Memoize. تسمح للقيم المخزنة مؤقتًا للدوال التي تم تذكرها بالانتهاء تلقائيًا. يفترض هذا الدليل أنك على دراية بالفعل بوحدة Memoize. إذا لم تكن كذلك، يجب عليك دراسة هذا الدليل بعناية أولاً، مع إيلاء اهتمام خاص لميزة HASH.

Memoize::Expire هي طبقة من البرامج يمكن إدراجها بين Memoize نفسها وأي حزمة أساسية تنفذ التخزين المؤقت. تقدم الطبقة متغير تجزئة تنتهي صلاحية قيمه عندما تصبح قديمة جدًا، أو تم استخدامها كثيرًا جدًا، أو كليهما. تخبر "Memoize" باستخدام تجزئة النسيان هذه كقاعدة بيانات تخزين مؤقت لها بدلاً من الافتراضية، وهي تجزئة عادية.

لتحديد مهلة في الوقت الفعلي، قم بتوفير الخيار "LIFETIME" بقيمة رقمية. ستنتهي صلاحية البيانات المخزنة مؤقتًا بعد هذا العدد من الثواني، وسيتم البحث عنها مجددًا عند انتهاء صلاحيتها. عند البحث عن عنصر بيانات مجددًا، يتم إعادة تعيين عمره.

إذا حددت "NUM_USES" بقيمة n، فسيتم التخلص من كل عنصر بيانات مخزن مؤقتًا والبحث عنه مجددًا بعد المرة n التي تصل إليها. عند البحث عن عنصر بيانات مجددًا، يتم إعادة تعيين عدد مرات استخدامه.

إذا قمت بتحديد كلا الوسيطين، فسيتم التخلص من البيانات من ذاكرة التخزين المؤقت عند تحقق أي من شروط انتهاء الصلاحية.

تستخدم Memoize::Expire تجزئة فعلية داخليًا لتخزين البيانات المخزنة مؤقتًا. يمكنك استخدام الخيار "HASH" لـ Memoize::Expire لتوفير تجزئة مرتبطة بدلاً من التجزئة العادية التي ستستخدمها Memoize::Expire عادةً. يمكنك استخدام هذه الميزة لإضافة Memoize::Expire كطبقة بين تجزئة قرص مستمرة و Memoize. إذا قمت بذلك، تحصل على ذاكرة تخزين مؤقتة للقرص مستمرة تنتهي صلاحية إدخالاتها تلقائيًا. على سبيل المثال:

#   Memoize
#      |
#   Memoize::Expire  تطبق سياسة انتهاء صلاحية البيانات
#      |
#   DB_File  تنفذ استمرارية البيانات في ملف قرص
#      |
#   ملف القرص
use Memoize;
use Memoize::Expire;
use DB_File;
# إعداد الاستمرارية
tie my %disk_cache => 'DB_File', $filename, O_CREAT|O_RDWR, 0666];
# إعداد سياسة انتهاء الصلاحية، مع توفير التجزئة المستمرة كهدف
tie my %cache => 'Memoize::Expire', 
                   LIFETIME => $lifetime,    # بالثواني
                   NUM_USES => $n_uses,
                   HASH => \%disk_cache; 
# إعداد التذكر، مع توفير تجزئة مستمرة منتهية الصلاحية للتخزين المؤقت
memoize 'function', SCALAR_CACHE => [ HASH => \%cache ];

الواجهة

لا يوجد شيء خاص بـ Memoize::Expire. إنها مجرد مثال. إذا كنت لا تحب السياسة التي تنفذها، فأنت حر في كتابة وحدة سياسة انتهاء صلاحية خاصة بك تنفذ أي سياسة ترغب فيها. إليك كيفية القيام بذلك. لنفترض أن وحدتك ستسمى MyExpirePolicy.

ملخص موجز: تحتاج إلى إنشاء حزمة تحدد أربعة أساليب:

TIEHASH
إنشاء وإرجاع كائن ذاكرة التخزين المؤقت.
EXISTS
بالنظر إلى وسيط الدالة، هل قيمة الدالة المقابلة موجودة في ذاكرة التخزين المؤقت، وإذا كان الأمر كذلك، هل هي جديدة بما يكفي لاستخدامها؟
FETCH
بالنظر إلى وسيط الدالة، ابحث عن قيمة الدالة المقابلة في ذاكرة التخزين المؤقت وقم بإرجاعها.
STORE
بالنظر إلى وسيط الدالة وقيمة الدالة المقابلة، قم بتخزينها في ذاكرة التخزين المؤقت.
CLEAR
(اختياري.) مسح ذاكرة التخزين المؤقت بالكامل.

سيقول المستخدم الذي يريد أن يتم انتهاء صلاحية ذاكرة التخزين المؤقتة للتذكر وفقًا لسياستك عن طريق كتابة

tie my %cache => 'MyExpirePolicy', args...;
memoize 'function', SCALAR_CACHE => [HASH => \%cache];

سيؤدي هذا إلى استدعاء "MyExpirePolicy->TIEHASH(args)". يجب على MyExpirePolicy::TIEHASH القيام بما هو مناسب لإعداد ذاكرة التخزين المؤقت، ويجب أن تعيد كائن ذاكرة التخزين المؤقت إلى المتصل.

على سبيل المثال، قد يقوم MyExpirePolicy::TIEHASH بإنشاء كائن يحتوي على تجزئة Perl عادية (التي سيستخدمها لتخزين القيم المخزنة مؤقتًا) وبعض المعلومات الإضافية حول الوسائط ومدى قدم البيانات وما إلى ذلك. لنسمي هذا الكائن "C".

عندما تحتاج Memoize إلى التحقق مما إذا كان الإدخال موجودًا بالفعل في ذاكرة التخزين المؤقت، فستقوم باستدعاء "C->EXISTS(key)". "key" هو وسيط الدالة العادي. يجب أن يعيد MyExpirePolicy::EXISTS 0 إذا لم يكن المفتاح موجودًا في ذاكرة التخزين المؤقت، أو إذا انتهت صلاحيته، و 1 إذا كان هناك قيمة غير منتهية الصلاحية في ذاكرة التخزين المؤقت. يجب عليها * عدم * إرجاع "undef"، نظرًا لوجود خطأ في بعض إصدارات Perl سيؤدي إلى استدعاء FETCH بشكل عابر إذا أعادت طريقة EXISTS "undef".

إذا أعادت دالة EXISTS الخاصة بك قيمة صحيحة، فستحاول Memoize جلب القيمة المخزنة مؤقتًا عن طريق استدعاء "C->FETCH(key)". يجب أن تعيد MyExpirePolicy::FETCH القيمة المخزنة مؤقتًا. وإلا، فستقوم Memoize باستدعاء الدالة التي تم تذكرها لحساب القيمة المناسبة، وستقوم بتخزينها في ذاكرة التخزين المؤقت عن طريق استدعاء "C->STORE(key, value)".

إليك مثال موجز لوحدة سياسة تنتهي صلاحية كل عنصر ذاكرة تخزين مؤقت بعد عشر ثوانٍ.

package Memoize::TenSecondExpire;
sub TIEHASH {
  my ($package, %args) = @_;
  my $cache = $args{HASH} || {};
  bless $cache => $package;
}
sub EXISTS {
  my ($cache, $key) = @_;
  if (exists $cache->{$key} && 
      $cache->{$key}{EXPIRE_TIME} > time) {
    return 1
  } else {
    return 0;  # لا ترجع undef هنا
  }
}
sub FETCH {
  my ($cache, $key) = @_;
  return $cache->{$key}{VALUE};
}
sub STORE {
  my ($cache, $key, $newvalue) = @_;
  $cache->{$key}{VALUE} = $newvalue;
  $cache->{$key}{EXPIRE_TIME} = time + 10;
}

لاستخدام سياسة انتهاء الصلاحية هذه، سيقول المستخدم

use Memoize;
tie my %cache10sec => 'Memoize::TenSecondExpire';
memoize 'function', SCALAR_CACHE => [HASH => \%cache10sec];

ستقوم Memoize بعد ذلك باستدعاء "function" كلما كانت قيمة مخزنة مؤقتًا مفقودة تمامًا أو أقدم من عشر ثوانٍ.

يجب عليك دائمًا دعم وسيط "HASH" لـ "TIEHASH" الذي يربط ذاكرة التخزين المؤقت الأساسية حتى يتمكن المستخدم من تحديد أن ذاكرة التخزين المؤقت مستمرة أيضًا أو أن لها دلالات أخرى مثيرة للاهتمام. يوضح المثال أعلاه كيفية القيام بذلك، وكذلك "Memoize::Expire".

وحدة نموذج أخرى، Memoize::Saves، متاحة في توزيع منفصل على CPAN. إنها تنفذ سياسة تسمح لك بتحديد أن بعض قيم الدوال سيتم البحث عنها دائمًا مجددًا. راجع التوثيق للحصول على التفاصيل.

بدائل

لدى Brent Powers وحدة Memoize::ExpireLRU التي تم تصميمها للعمل مع Memoize وتوفر انتهاء صلاحية البيانات الأقل استخدامًا مؤخرًا. يتم الاحتفاظ بذاكرة التخزين المؤقت بعدد ثابت من الإدخالات، وعندما تأتي بيانات جديدة، يتم إنهاء صلاحية البيانات الأقل استخدامًا مؤخرًا.

قد تكون وحدة Tie::Cache من Joshua Chamas مفيدة كمدير لانتهاء الصلاحية. (إذا جربت هذا، أخبرني كيف سار الأمر.)

إذا قمت بتطوير أي مديري انتهاء صلاحية مفيدين تعتقد أنه يجب توزيعهم مع Memoize، فيرجى إخباري.
