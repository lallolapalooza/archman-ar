memcached_pool_release(3)

الحزمة: libmemcached-awesome

التراخيص: BSD

RETURN VALUE

On success, memcached_pool_release returns MEMCACHED_SUCCESS. On failure, it returns a memcached_return code:

MEMCACHED_INVALID_ARGUMENTS is returned if pool or memc is NULL.
