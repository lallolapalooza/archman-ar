NAME

memcached_callback_get – retrieve the callback for a specific event.

SYNOPSIS

#include <libmemcached/callbacks.h>

memcached_callback_st *memcached_callback_get(memcached_st *ptr, memcached_callback_type type);

DESCRIPTION

This function will retrieve the callback that has been registered for the given event type.

This function will return NULL if no callback is registered for the specified event type.

RETURN VALUE

A pointer to the callback structure for the given event type. NULL if no callback is set.
