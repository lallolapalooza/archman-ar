الإرجاع
memcached_return_t تشير إلى النجاح

الوصف

memcached_increment() يأخذ key و key_length ويزيد القيمة بمقدار offset الذي يتم تمريره إليه. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليه.

memcached_decrement() يأخذ key و key_length وينقص القيمة بمقدار offset الذي يتم تمريره إليه. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليه.

memcached_increment_with_initial() يأخذ key و key_length ويزيد القيمة بمقدار offset الذي يتم تمريره إليه. إذا كان الكائن المحدد بواسطة key غير موجود، فقد يحدث أحد أمرين: إذا كانت قيمة expiration هي MEMCACHED_EXPIRATION_NOT_ADD، فسيفشل التشغيل. لجميع قيم expiration الأخرى، سينجح التشغيل عن طريق تغذية القيمة لهذا المفتاح بقيمة أولية لتنتهي صلاحيتها مع الوقت المحدد. سيتم تعيين flags إلى صفر. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليه. memcached_increment_with_initial متاح فقط عند استخدام بروتوكول الثنائي.

memcached_decrement_with_initial() يأخذ key و key_length وينقص القيمة بمقدار offset الذي يتم تمريره إليه. إذا كان الكائن المحدد بواسطة key غير موجود، فقد يحدث أحد أمرين: إذا كانت قيمة expiration هي MEMCACHED_EXPIRATION_NOT_ADD، فسيفشل التشغيل. لجميع قيم expiration الأخرى، سينجح التشغيل عن طريق تغذية القيمة لهذا المفتاح بقيمة أولية لتنتهي صلاحيتها مع الوقت المحدد. سيتم تعيين flags إلى صفر. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليه. memcached_decrement_with_initial() متاح فقط عند استخدام بروتوكول الثنائي.

memcached_increment_by_key() و memcached_decrement_by_key() و memcached_increment_with_initial_by_key() و memcached_decrement_with_initial_by_key() هي مكافئات مفتاح رئيسي لما سبق.

قيمة الإرجاع

يتم إرجاع قيمة من نوع memcached_return_t. عند النجاح، ستكون هذه القيمة MEMCACHED_SUCCESS. استخدم memcached_strerror() لترجمة هذه القيمة إلى سلسلة نصية قابلة للطباعة.
