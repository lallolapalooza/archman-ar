memcached_dump(3)

الحزمة: libmemcached-awesome

التراخيص: BSD

MEMCACHED_DUMP(3) libmemcached-awesome MEMCACHED_DUMP(3)

الاسم

memcached_dump - وثائق libmemcached

ملخص

#include <libmemcached/memcached.h>
قم بالترجمة والربط مع -lmemcached
typedef memcached_return_t (*memcached_dump_fn)(memcached_st *ptr, const char *key, size_t key_length, void *context)
Param ptr
مؤشر إلى كائن memcached_st
Param key
سلسلة المفتاح التي يتم تفريغها
Param key_length
طول المفتاح بدون أي صفر نهائي
Param context
مؤشر إلى السياق الذي يقدمه المستخدم
المرجع
memcached_return_t يشير إلى النجاح
memcached_return_t memcached_dump(memcached_st *ptr, memcached_dump_fn *function, void *context, uint32_t number_of_callbacks)
المعلمات
  • ptr -- مؤشر إلى هيكل memcached_st تم تهيئته
  • function -- مؤشر إلى استدعاءات memcached_dump_fn عددها number_of_callbacks
  • context -- مؤشر إلى سياق يديره المستخدم
  • number_of_callbacks -- عدد الاستدعاءات في مصفوفة function
المرجع
memcached_return_t يشير إلى النجاح

الوصف

حالياً، لم يتم اختبار البروتوكول الثنائي.

قيمة الإرجاع

يتم إرجاع قيمة من نوع memcached_return_t. عند النجاح، ستكون هذه القيمة MEMCACHED_SUCCESS. استخدم memcached_strerror() لترجمة هذه القيمة إلى سلسلة قابلة للطباعة.
