الوصف

تقوم libmemcached بتنفيذ عمليات على قائمة من المضيفين. يحدد ترتيب هؤلاء المضيفين التوجيه للمفاتيح. يتم توفير وظائف لإضافة مفاتيح إلى هياكل memcached_st. للتلاعب بقوائم الخوادم، راجع memcached_server_st.

memcached_server_count() توفر لك عدد الخوادم الحالية التي يستخدمها هيكل memcached_st.

memcached_server_add() تدفع خادم TCP واحد إلى هيكل memcached_st. سيتم وضع هذا الخادم في النهاية. يُسمح بالخوادم المكررة، لذا لا يتم التحقق من التكرار. سيؤدي تنفيذ هذه الوظيفة مع تعيين السلوك MEMCACHED_BEHAVIOR_USE_UDP إلى MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() تدفع خادم UDP واحد إلى هيكل memcached_st. سيتم وضع هذا الخادم في النهاية. يُسمح بالخوادم المكررة، لذا لا يتم التحقق من التكرار. سيؤدي تنفيذ هذه الوظيفة بدون تعيين السلوك MEMCACHED_BEHAVIOR_USE_UDP إلى MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() تدفع مقبس UNIX واحد إلى هيكل memcached_st. سيتم وضع مقبس UNIX هذا في النهاية. يُسمح بالخوادم المكررة، لذا لا يتم التحقق من التكرار. يجب أن يكون طول اسم الملف أقل بحرف واحد من MEMCACHED_MAX_HOST_LENGTH.

NAME

memcached_server_st, memcached_server_free, memcached_server_add, memcached_server_add_udp, memcached_server_add_unix, memcached_server_add_parse, memcached_server_clone, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor — structure for storing memcached server information

SYNOPSIS

#include <libmemcached/memcached.h>

typedef struct memcached_server_st { ... } memcached_server_st;

void memcached_server_free(memcached_server_st *ptr);

memcached_return_t memcached_server_add(memcached_st *ptr, const char *hostname, size_t hostname_length);

memcached_return_t memcached_server_add_udp(memcached_st *ptr, const char *hostname, size_t hostname_length);

memcached_return_t memcached_server_add_unix(memcached_st *ptr, const char *socket_path);

memcached_return_t memcached_server_add_parse(memcached_st *ptr, const char *server_string);

memcached_server_st *memcached_server_clone(memcached_server_st *dst, const memcached_server_st *src);

memcached_server_st *memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);

memcached_server_st *memcached_server_get_last_disconnect(memcached_st *ptr);

memcached_return_t memcached_server_cursor(memcached_st *ptr, memcached_server_fn *callbacks, void *context, unsigned int count);

DESCRIPTION

The memcached_server_st structure is used to store information about a single memcached server, including its hostname, port, and other connection-related details. The libmemcached library manages a list of these structures within a memcached_st context.

memcached_server_free() frees the memory associated with a memcached_server_st pointer. This should be called when you are finished with a server structure obtained from functions like memcached_server_clone().

memcached_server_add() adds a new memcached server to the list associated with the provided memcached_st context. The server is identified by its hostname and port (if not specified, the default port is used). You can specify the port by appending it to the hostname with a colon (e.g., "127.0.0.1:11211").

memcached_server_add_udp() is similar to memcached_server_add(), but it adds the server for UDP communication instead of the default TCP.

memcached_server_add_unix() adds a memcached server that is accessible via a UNIX domain socket.

memcached_server_add_parse() parses a string containing one or more server definitions and adds them to the memcached_st context. The string can contain hostnames, host:port combinations, and UNIX domain socket paths, separated by commas.

memcached_server_clone() creates a copy of a memcached_server_st structure. If dst is not NULL, the contents of src will be copied into dst. If dst is NULL, a new memcached_server_st structure will be allocated and returned. The caller is responsible for freeing the returned structure if it was allocated.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment. This function helps in determining which server a particular key would be mapped to, based on the hashing and distribution strategy configured in the memcached_st context.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
