memcached_touch(3)

الحزمة: libmemcached-awesome

التراخيص: BSD

MEMCACHED_TOUCH(3) libmemcached-awesome MEMCACHED_TOUCH(3)

الاسم

memcached_touch - توثيق libmemcached

ملخص

#include <libmemcached/memcached.h>
قم بالتجميع والربط باستخدام -lmemcached
memcached_return_t memcached_touch(memcached_st *ptr, const char *key, size_t key_length, time_t expiration)
المعلمات
  • ptr -- مؤشر إلى بنية memcached_st مهيأة
  • key -- المفتاح للمس
  • key_length -- طول key بدون أي صفر نهائي
  • expiration -- وقت انتهاء صلاحية جديد كختم زمني يونكس أو كوقت انتهاء صلاحية نسبي بالثواني
القيم المعادة
memcached_return_t تشير إلى النجاح
memcached_return_t memcached_touch_by_key(memcached_st *ptr, const char *group_key, size_t group_key_length, const char *key, size_t key_length, time_t expiration)
المعلمات
  • ptr -- مؤشر إلى بنية memcached_st مهيأة
  • group_key -- مساحة أسماء key
  • group_key_length -- طول group_key بدون أي صفر نهائي
  • key -- المفتاح للمس
  • key_length -- طول key بدون أي صفر نهائي
  • expiration -- وقت انتهاء صلاحية جديد كختم زمني يونكس أو كوقت انتهاء صلاحية نسبي بالثواني
القيم المعادة
memcached_return_t تشير إلى النجاح

الوصف

memcached_touch() تستخدم لتحديث وقت انتهاء الصلاحية على مفتاح موجود. memcached_touch_by_key() تعمل بنفس الطريقة، ولكنها تأخذ مفتاحًا رئيسيًا للعثور على القيمة المعطاة.

القيمة المعادة

يتم إرجاع قيمة من نوع memcached_return_t. عند النجاح، ستكون هذه القيمة MEMCACHED_SUCCESS. استخدم memcached_strerror() لترجمة هذه القيمة إلى سلسلة نصية قابلة للطباعة.
