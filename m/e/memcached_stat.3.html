libmemcached — A C client library for memcached

SYNOPSIS

#include <libmemcached/memcached.h>

DESCRIPTION

The libmemcached library is a C client library for the memcached distributed memory caching system. It provides a simple and efficient API for interacting with memcached servers.

RETURN VALUE

The functions in this library return various values depending on their success or failure. Error codes can be translated using memcached_strerror(3).

SEE ALSO

libmemcached(3), memcached_strerror(3)
