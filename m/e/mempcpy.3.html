mempcpy(3) دليل الوظائف المكتبية mempcpy(3)

الاسم

mempcpy, wmempcpy - نسخ منطقة الذاكرة

المكتبة

مكتبة C القياسية (libc،  -lc)

الملخص

#define _GNU_SOURCE         /* انظر feature_test_macros(7) */
#include <string.h>
void *mempcpy(size_t n;
              void dest[restrict n], const void src[restrict n],
              size_t n);
#define _GNU_SOURCE         /* انظر feature_test_macros(7) */
#include <wchar.h>
wchar_t *wmempcpy(size_t n;
              wchar_t dest[restrict n], const wchar_t src[restrict n],
              size_t n);

الوصف

وظيفة mempcpy() تشبه إلى حد كبير وظيفة memcpy(3). تقوم بنسخ n بايت من الكائن الذي يبدأ عند src إلى الكائن الذي يشير إليه dest. ولكن بدلاً من إرجاع قيمة dest، فإنها ترجع مؤشرًا إلى البايت التالي للبايت الأخير الذي تمت كتابته.

هذه الوظيفة مفيدة في الحالات التي يتم فيها نسخ عدد من الكائنات إلى مواقع ذاكرة متتالية.

وظيفة wmempcpy() متطابقة ولكنها تأخذ وسيطات من نوع wchar_t وتقوم بنسخ n حرفًا عريضًا.

قيمة الإرجاع

dest + n.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
mempcpy ()، wmempcpy () السلامة في الخيوط آمنة للخيوط (MT-Safe)

المعايير

GNU.

التاريخ

glibc 2.1.

أمثلة

void *
combine(void *o1, size_t s1, void *o2, size_t s2)
{
    void *result = malloc(s1 + s2);
    if (result != NULL)
        mempcpy(mempcpy(result, o1, s1), o2, s2);
    return result;
}
