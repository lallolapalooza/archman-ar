أمر الاختبار

meson test هي أداة مساعدة لتشغيل مجموعات الاختبار للمشاريع التي تستخدم Meson. الطريقة الافتراضية لتشغيل الاختبارات هي استدعاء أمر البناء الافتراضي:

ninja [ test ]

meson test يوفر مجموعة أدوات أغنى لاستدعاء الاختبارات.

meson test يعيد بناء الأهداف الضرورية تلقائيًا لتشغيل الاختبارات عند استخدامه مع الواجهة الخلفية Ninja. عند فشل البناء، سيعيد meson test رمز خروج قدره 125. يخبر رمز الخروج هذا git bisect run بتخطي الالتزام الحالي. وبالتالي يمكن إجراء الفصل باستخدام git بشكل ملائم مثل هذا.

git bisect run meson test -C build_dir

الخيارات:

--repeat
تشغيل الاختبارات بالعدد المحدد من المرات.
--gdb
تشغيل الاختبارات تحت gdb.
--list
عرض جميع الاختبارات المتاحة.
--wrapper
استدعاء جميع الاختبارات عبر الملتف المحدد (مثل valgrind).
-C
الانتقال إلى المجلد المحدد قبل تشغيل الاختبارات (يجب أن يكون جذر مجلد البناء).
--suite
تشغيل الاختبارات في هذه المجموعة.
--no-suite
عدم تشغيل الاختبارات في هذه المجموعة.
--no-stdsplit
عدم فصل stderr و stdout في سجلات الاختبار.
--benchmark
تشغيل المعايير القياسية بدلاً من الاختبارات.
--logbase
أساس اسم الملف المستخدم لكتابة سجلات الاختبار.
--num-processes
عدد العمليات المتوازية المستخدمة لتشغيل الاختبارات.
--verbose
عدم إعادة توجيه stdout و stderr.
-t
مضاعف لاستخدامه في قيم مهلة الاختبار (عادة شيء مثل 100 لـ Valgrind).
--setup
استخدام إعداد الاختبار المحدد. --slice SLICE/NUM_SLICES تقسيم الاختبارات إلى NUM_SLICES شريحة وتنفيذ الشريحة رقم SLICE. (منذ 1.8.0).

أمر الالتفاف

Wraptool هي أداة مساعدة لإدارة تبعيات المصدر باستخدام خدمة wrapdb عبر الإنترنت.

meson wrap < command > [ options ]

يجب تشغيل هذا الأمر في المجلد المصدر الأعلى لمشروعك.

الأوامر:

list
عرض جميع المشاريع المتاحة.
search
البحث عن المشاريع بالاسم.
install
تثبيت مشروع بالاسم المحدد.
update
تحديث المشروع المحدد إلى أحدث إصدار متاح.
info
عرض الإصدارات المتاحة للمشروع المحدد.
status
عرض الإصدارات المثبتة والمتاحة للمشاريع الفرعية المستخدمة حاليًا.

أمر المشاريع الفرعية

meson subprojects يستخدم لإدارة المشاريع الفرعية.

meson subprojects [ options ] [ command ]

الخيارات:

-h, --help
عرض رسالة المساعدة هذه والخروج.

الأوامر:

update
تحديث جميع المشاريع الفرعية من ملفات الالتفاف.
checkout
سحب فرع (git فقط).
download
تأكد من جلب المشاريع الفرعية، حتى لو لم تكن قيد الاستخدام. المشاريع الفرعية التي تم تنزيلها بالفعل لا يتم تعديلها. يمكن استخدام هذا لجلب جميع المشاريع الفرعية مسبقًا وتجنب التنزيلات أثناء التكوين.
foreach
تنفيذ أمر في كل مجلد مشروع فرعي.
purge
إزالة جميع القطع الأثرية للمشروع الفرعي القائمة على الالتفاف.
packagefiles
إدارة تراكب ملفات الحزمة.

أمر إعادة الكتابة

meson rewrite يعدل تعريف المشروع.

meson rewrite [ options ] [ command ]

الخيارات:

-h, --help
عرض رسالة المساعدة هذه والخروج.
-s SRCDIR, --sourcedir SRCDIR
المسار إلى مجلد المصدر.
-V, --verbose
تمكين الإخراج المفصل.
-S, --skip-errors
تجاوز الأخطاء بدلاً من الإنهاء.

الأوامر:

target (tgt)
تعديل هدف.
kwargs
تعديل وسائط الكلمات الرئيسية.
default-options (def)
تعديل خيارات المشروع الافتراضية.
command (cmd)
تنفيذ مصفوفة JSON من الأوامر.

أمر البناء

meson compile يبني المشروع.

meson compile [ options ] [ TARGET... ]

الوسائط الموضعية:

TARGET
الأهداف التي سيتم بناؤها. الهدف له التنسيق التالي: [PATH_TO_TARGET/]TARGET_NAME.TARGET_SUFFIX[:TARGET_TYPE].

الخيارات:

-h, --help
عرض رسالة المساعدة هذه والخروج.
--clean
تنظيف مجلد البناء.
-C WD
المجلد الذي سيتم الانتقال إليه قبل التشغيل.
-j JOBS, --jobs JOBS
عدد مهام العمال التي سيتم تشغيلها (إذا كانت مدعومة). إذا كانت القيمة أقل من 1، فسوف يخمن برنامج البناء.
-l LOAD_AVERAGE, --load-average LOAD_AVERAGE
متوسط تحميل النظام الذي سيتم محاولة الحفاظ عليه (إذا كان مدعومًا).
-v, --verbose
عرض إخراج أكثر تفصيلاً.
--ninja-args NINJA_ARGS
الوسائط التي سيتم تمريرها إلى `ninja` (تطبق فقط على الواجهة الخلفية `ninja`).
--vs-args VS_ARGS
الوسائط التي سيتم تمريرها إلى `msbuild` (تطبق فقط على الواجهة الخلفية `vs`).
--xcode-args XCODE_ARGS
الوسائط التي سيتم تمريرها إلى `xcodebuild` (تطبق فقط على الواجهة الخلفية `xcode`).

أمر البيئة التطويرية

meson devenv [ options ] [ command ]

الوسائط الموضعية:

command
الأمر المراد تشغيله في البيئة التطويرية (الافتراضي: واجهة أوامر تفاعلية).

الخيارات:

-h, --help
عرض رسالة المساعدة هذه والخروج.
-C BUILDDIR

--workdir WORKDIR, -w WORKDIR

--dump [DUMP]
