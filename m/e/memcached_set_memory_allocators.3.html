الوصف

تسمح لك libmemcached بتحديد مخصصات الذاكرة الخاصة بك، والتي تم تحسينها لتطبيقك. هذا يمكّن libmemcached من الاستخدام داخل التطبيقات التي لديها تطبيق تخصيص خاص بها.

تُستخدم memcached_set_memory_allocators() لتعيين مخصصات الذاكرة المستخدمة بواسطة مثيل memcached المحدد بواسطة ptr. يرجى ملاحظة أنه لا يمكنك تجاوز مخصص ذاكرة واحد فقط، بل يجب عليك تحديد مجموعة جديدة كاملة إذا كنت ترغب في تجاوز أحدها. يجب أن تتصرف جميع وظائف تخصيص الذاكرة كما هو محدد في معيار C99. حدد NULL لجميع الوظائف لإعادتها إلى القيم الافتراضية.

تُستخدم memcached_get_memory_allocators() للحصول على مخصصات الذاكرة المستخدمة حاليًا بواسطة مقبض memcached.

memcached_get_memory_allocators_context() تُعيد مؤشر void * الذي تم تمريره أثناء استدعاء memcached_set_memory_allocators().

الوسيط الأول لوظائف تخصيص الذاكرة هو مؤشر إلى بنية memcached، يتم تمريره على أنه const وستحتاج إلى استنساخه للاستفادة من أي عملية قد تعدله.

ملاحظات

في الإصدار 0.38، تم تعديل جميع الوظائف لتمرير وسيط سياق void * إليها. كان ذلك حتى تتمكن المخصصات المخصصة من الحصول على مساحتها الخاصة للذاكرة.

قيمة الإرجاع

تُعيد memcached_set_memory_allocators() MEMCACHED_SUCCESS عند النجاح، و MEMCACHED_FAILURE إذا لم تمرر مجموعة كاملة من مؤشرات الوظائف.

memcached_set_memory_allocators(3)

NAME

memcached_set_memory_allocators - Set the memory allocators used by the library.

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_set_memory_allocators(memcached_st *ptr,
                                                   memcached_malloc_fn *malloc_fn,
                                                   memcached_realloc_fn *realloc_fn,
                                                   memcached_free_fn *free_fn);

DESCRIPTION

The memcached_set_memory_allocators function allows you to specify custom memory allocation functions for the libmemcached library. This can be useful for memory debugging, profiling, or using specialized allocators.

You need to provide pointers to your implementation of malloc, realloc, and free functions that conform to the standard C library signatures.

ptr: A pointer to the memcached_st structure for which to set the memory allocators.

malloc_fn: A pointer to the custom malloc function.

realloc_fn: A pointer to the custom realloc function.

free_fn: A pointer to the custom free function.

If you pass NULL for any of the function pointers, the library will revert to using the standard C library's memory allocation functions (malloc, realloc, free) for that specific function.

NOTES

This function should be called before any other operations that might allocate memory, such as connecting to a memcached server or adding servers.

Ensure that your custom memory allocation functions are thread-safe if you intend to use libmemcached in a multi-threaded environment.

RETURN VALUE

Returns MEMCACHED_SUCCESS on success, or an error code on failure.

Possible error codes include:

  • MEMCACHED_INVALID_ARGUMENTS: If ptr is NULL.
