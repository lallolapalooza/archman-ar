memcached_return_t تشير إلى النجاح

الوصف

memcached_increment() تأخذ key و key_length وتزيد القيمة بمقدار offset الممرر إليها. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليها.

memcached_decrement() تأخذ key و key_length وتنقص القيمة بمقدار offset الممرر إليها. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليها.

memcached_increment_with_initial() تأخذ key و key_length وتزيد القيمة بمقدار offset الممرر إليها. إذا لم يكن الكائن المحدد بواسطة key موجودًا، فقد يحدث أحد أمرين: إذا كانت قيمة expiration هي MEMCACHED_EXPIRATION_NOT_ADD، فسيفشل الأمر. لجميع قيم expiration الأخرى، سينجح الأمر عن طريق بذرة القيمة لذلك المفتاح بقيمة أولية لتنتهي صلاحيتها بالوقت المحدد. سيتم تعيين flags إلى صفر. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليها. memcached_increment_with_initial متاح فقط عند استخدام البروتوكول الثنائي.

memcached_decrement_with_initial() تأخذ key و key_length وتنقص القيمة بمقدار offset الممرر إليها. إذا لم يكن الكائن المحدد بواسطة key موجودًا، فقد يحدث أحد أمرين: إذا كانت قيمة expiration هي MEMCACHED_EXPIRATION_NOT_ADD، فسيفشل الأمر. لجميع قيم expiration الأخرى، سينجح الأمر عن طريق بذرة القيمة لذلك المفتاح بقيمة أولية لتنتهي صلاحيتها بالوقت المحدد. سيتم تعيين flags إلى صفر. ثم يتم إرجاع القيمة عبر المؤشر uint32_t value الذي تمرره إليها. memcached_decrement_with_initial() متاح فقط عند استخدام البروتوكول الثنائي.

memcached_increment_by_key()، memcached_decrement_by_key()، memcached_increment_with_initial_by_key()، و memcached_decrement_with_initial_by_key() هي مكافئات للمفاتيح الرئيسية للوظائف المذكورة أعلاه.

القيمة المرجعة

يتم إرجاع قيمة من نوع memcached_return_t. عند النجاح، ستكون هذه القيمة MEMCACHED_SUCCESS. استخدم memcached_strerror() لترجمة هذه القيمة إلى سلسلة نصية قابلة للطباعة.
