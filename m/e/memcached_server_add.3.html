الوصف

تقوم libmemcached بتنفيذ عمليات على قائمة من المضيفين. يحدد ترتيب هؤلاء المضيفين التوجيه إلى المفاتيح. يتم توفير دوال لإضافة مفاتيح إلى هياكل memcached_st. لمعالجة قوائم الخوادم، انظر memcached_server_st.

memcached_server_count() تزودك بعدد الخوادم الحالية التي تستخدمها بنية memcached_st.

memcached_server_add() تدفع خادم TCP واحد إلى بنية memcached_st. سيتم وضع هذا الخادم في النهاية. الخوادم المكررة مسموح بها، لذلك لا يتم التحقق من التكرار. سيؤدي تنفيذ هذه الدالة مع تعيين سلوك MEMCACHED_BEHAVIOR_USE_UDP إلى حدوث MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_udp() تدفع خادم UDP واحد إلى بنية memcached_st. سيتم وضع هذا الخادم في النهاية. الخوادم المكررة مسموح بها، لذلك لا يتم التحقق من التكرار. سيؤدي تنفيذ هذه الدالة بدون تعيين سلوك MEMCACHED_BEHAVIOR_USE_UDP إلى حدوث MEMCACHED_INVALID_HOST_PROTOCOL.

memcached_server_add_unix_socket() تدفع مقبس UNIX واحد إلى بنية memcached_st. سيتم وضع مقبس UNIX هذا في النهاية. الخوادم المكررة مسموح بها، لذلك لا يتم التحقق من التكرار. يجب أن يكون طول اسم الملف أقل بحرف واحد من MEMCACHED_MAX_HOST_LENGTH.

memcached_server_push() تدفع مصفوفة من memcached_server_st إلى بنية memcached_st. ستكون هذه الخوادم

NAME

memcached_server_add, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - Add servers to libmemcached

SYNOPSIS

#include <libmemcached/memcached.h>

void memcached_server_add(memcached_st *ptr, const char *hostname, size_t hostname_length);
void memcached_server_add_parse(memcached_st *ptr, const char *string);
void memcached_server_add_udp(memcached_st *ptr, const char *hostname, size_t hostname_length);
void memcached_server_add_unix(memcached_st *ptr, const char *filename);
memcached_server_st *memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);
memcached_server_st *memcached_server_get_last_disconnect(memcached_st *ptr);
void memcached_server_cursor(memcached_st *ptr, memcached_server_fn *function, void *context, unsigned int flags);

DESCRIPTION

The memcached_server_add() family of functions are used to add servers to a memcached_st structure. The structure can then be used for operations against the added servers.

memcached_server_add() adds a server by hostname and port. The port is included in the hostname as :port.

memcached_server_add_parse() adds a server by parsing a string in the format of host:port or unix:/path/to/socket.

memcached_server_add_udp() adds a server for UDP communication.

memcached_server_add_unix() adds a server by providing the path to a Unix domain socket.

The list of servers is not saved, and servers are added to the end. Duplicate servers are allowed, so duplication is not checked. A copy is made of the structure so the list provided (and any operations on the list) are not saved.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.
