الوصف

memcached_pool() تُستخدم لإنشاء مجموعة اتصالات من الكائنات التي يمكنك استخدامها لإزالة الحمل الزائد لاستخدام memcached_clone للكائنات memcached_st قصيرة العمر. يرجى الاطلاع على تكوين libmemcached للتفاصيل حول تنسيق سلسلة التكوين.

memcached_pool_destroy() تُستخدم لتدمير مجموعة الاتصالات المنشأة بواسطة memcached_pool_create() وتحرير جميع الموارد المخصصة. ستعيد مؤشر إلى بنية memcached_st الممررة كمعامل لـ memcached_pool_create()، وتعيد ملكية المؤشر إلى المتصل عند إنشائها باستخدام memcached_pool_create()، وإلا يتم إرجاع NULL.

memcached_pool_fetch() تُستخدم لجلب بنية اتصال من مجموعة الاتصالات. يحدد المعامل relative_time ما إذا كانت الدالة يجب أن تحظر وتنتظر حتى تصبح بنية الاتصال متاحة إذا حاولنا تجاوز الحد الأقصى للحجم. تحتاج إلى تحديد الوقت بالوقت النسبي.

memcached_pool_release() تُستخدم لإعادة بنية اتصال إلى المجموعة.

memcached_pool_behavior_get() و memcached_pool_behavior_set() تُستخدمان لجلب / تعيين علامات السلوك على جميع الاتصالات في المجموعة.

كل من memcached_pool_release() و memcached_pool_fetch() آمنان للاستخدام في سلاسل متعددة.

القيمة المرجعة

memcached_pool_destroy() تعيد المؤشر (والملكية) إلى بنية memcached_st المستخدمة لإنشاء المجموعة. إذا كانت هناك اتصالات قيد الاستخدام، فإنها تعيد NULL.

memcached_pool_pop() تعيد مؤشرًا إلى بنية memcached_st من المجموعة (أو NULL إذا لم يكن بالإمكان تلبية تخصيص).

memcached_pool_release() تعيد MEMCACHED_SUCCESS عند النجاح.

memcached_pool_behavior_get() و memcached_pool_behavior_get() تعيدان MEMCACHED_SUCCESS عند النجاح.

memcached_pool_fetch() قد تعيد MEMCACHED_TIMEOUT إذا حدث انتهاء مهلة أثناء انتظار مثيل memcached_st مجاني، MEMCACHED_NOTFOUND إذا لم يكن هناك مثيل memcached_st متاح، على التوالي.

memcached_pool_behavior_get(3)

NAME

memcached_pool_behavior_get - get pool behavior, MEMCACHED_INVALID_ARGUMENTS will be returned.

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_return_t memcached_pool_behavior_get(
    memcached_pool_st *pool,
    memcached_behavior_t flag
);

DESCRIPTION

memcached_pool_behavior_get() is used to get the value of a behavior on a pool.

Behaviors are configuration settings that affect the behavior of the memcached client library. Some behaviors can be set globally for all pools, while others can be set per-pool.

The following behaviors are supported:

MEMCACHED_BEHAVIOR_SUPPORT_CAS
Check if the CAS (Check And Set) protocol is supported.
MEMCACHED_BEHAVIOR_KETAMA
Check if Ketama consistent hashing is enabled.
MEMCACHED_BEHAVIOR_BINARY_PROTOCOL
Check if the binary protocol is enabled.
MEMCACHED_BEHAVIOR_NO_BLOCK
Check if non-blocking operations are enabled.
MEMCACHED_BEHAVIOR_TCP_NODELAY
Check if TCP_NODELAY is enabled.
MEMCACHED_BEHAVIOR_HASH_WITH_PREFIX_KEY
Check if hashing with prefix key is enabled.
MEMCACHED_BEHAVIOR_VERIFY_KEY
Check if key verification is enabled.
MEMCACHED_BEHAVIOR_USE_UDP
Check if UDP is used.
MEMCACHED_BEHAVIOR_AUTO_EJECT_HOSTS
Check if auto ejection of hosts is enabled.
MEMCACHED_BEHAVIOR_NUMBER_OF_REPLICAS
Get the number of replicas.
MEMCACHED_BEHAVIOR_SORT_HOSTS
Check if hosts are sorted.
MEMCACHED_BEHAVIOR_VERBATIM_KEY
Check if verbatim key is used.
MEMCACHED_BEHAVIOR_CLIENT_MODE
Get the client mode.
MEMCACHED_BEHAVIOR_SOCKET_SEND_SIZE
Get the socket send size.
MEMCACHED_BEHAVIOR_SOCKET_RECV_SIZE
Get the socket receive size.
MEMCACHED_BEHAVIOR_CONNECT_TIMEOUT
Get the connect timeout.
MEMCACHED_BEHAVIOR_RETRY_TIMEOUT
Get the retry timeout.
MEMCACHED_BEHAVIOR_DEAD_TIMEOUT
Get the dead timeout.
MEMCACHED_BEHAVIOR_REMOVE_DEAD_SERVERS
Check if removing dead servers is enabled.
MEMCACHED_BEHAVIOR_SERVER_FAILURE_LIMIT
Get the server failure limit.
MEMCACHED_BEHAVIOR_MAX_KEY_SIZE
Get the maximum key size.
MEMCACHED_BEHAVIOR_MAX_VALUE
Get the maximum value size.
MEMCACHED_BEHAVIOR_DELETE_TRIGGER_ENABLE
Check if delete trigger is enabled.
MEMCACHED_BEHAVIOR_TCP_KEEPALIVE_INTERVAL
Get the TCP keepalive interval.
MEMCACHED_BEHAVIOR_TCP_KEEPALIVE_PROBES
Get the TCP keepalive probes.
MEMCACHED_BEHAVIOR_TCP_KEEPALIVE_USER_TIMEOUT
Get the TCP keepalive user timeout.
MEMCACHED_BEHAVIOR_USER_RKEY_LEN
Get the user rkey length.
MEMCACHED_BEHAVIOR_USER_ID
Get the user ID.
MEMCACHED_BEHAVIOR_USER_TOKEN
Get the user token.
MEMCACHED_BEHAVIOR_NO_BLOCK_AUTO_RETURN
Check if non-blocking auto return is enabled.
MEMCACHED_BEHAVIOR_athl
Check if ATHL (Active Thread Hashing) is enabled.
MEMCACHED_BEHAVIOR_BUFFER_REQUESTS
Check if requests are buffered.

RETURN VALUE

A value greater than or equal to zero indicates success and is the value of the behavior. Otherwise, a memcached_return_t error is returned. This indicates an error condition. On success, the value returned is the value of the behavior requested. You can use the function `memcached_strerror()` to get the string representation of the error.

If an invalid flag is passed to the function, `MEMCACHED_INVALID_ARGUMENTS` will be returned.
