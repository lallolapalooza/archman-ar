الوصف

تسمح لك libmemcached بتحديد مخصصات الذاكرة الخاصة بك، المحسّنة لتطبيقك. وهذا يتيح استخدام libmemcached داخل التطبيقات التي لديها تنفيذ malloc خاص بها.

memcached_set_memory_allocators() تُستخدم لتعيين مخصصات الذاكرة المستخدمة بواسطة مثيل memcached المحدد بواسطة ptr. يرجى ملاحظة أنه لا يمكنك تجاوز مخصص واحد فقط، بل يجب عليك تحديد مجموعة جديدة كاملة إذا كنت ترغب في تجاوز أحدها. يجب أن تتصرف جميع وظائف تخصيص الذاكرة كما هو محدد في معيار C99. قم بتحديد NULL لجميع الوظائف لإعادة تعيينها إلى القيم الافتراضية.

memcached_get_memory_allocators() تُستخدم للحصول على مخصصات الذاكرة المستخدمة حاليًا بواسطة مقبض memcached.

memcached_get_memory_allocators_context() تُرجع المؤشر void * الذي تم تمريره أثناء استدعاء memcached_set_memory_allocators().

المعامل الأول لوظائف مخصصات الذاكرة هو مؤشر إلى هيكل memcached، يتم تمريره على أنه ثابت (const) وستحتاج إلى استنساخه للاستفادة من أي عملية تعدل عليه.

ملاحظات

في الإصدار 0.38، تم تعديل جميع الوظائف لتمرير مؤشر سياق void إليهم. كان ذلك حتى تتمكن المخصصات المخصصة من الحصول على مساحتها الخاصة بالذاكرة.

القيمة المرجعة

memcached_set_memory_allocators() تُرجع MEMCACHED_SUCCESS عند النجاح، و MEMCACHED_FAILURE إذا لم تقم بتمرير مجموعة كاملة من مؤشرات الوظائف.

NAME

memcached_strerror - Return a string description of an error.

SYNOPSIS

#include <libmemcached/memcached.h>

const char *
memcached_strerror(memcached_return_t rc);

DESCRIPTION

The memcached_strerror() function returns a pointer to a static string that describes the error code passed in the rc parameter. This function is useful for providing human-readable error messages to end users.

RETURN VALUE

Returns a pointer to a constant string describing the error code.
