memcached_servers(3)

الحزمة: libmemcached-awesome

التراخيص: BSD

NAME

memcached_servers, memcached_server_by_key, memcached_server_get_last_disconnect, memcached_server_cursor - Server list management for libmemcached

SYNOPSIS

#include <libmemcached/memcached.h>

memcached_server_st *
memcached_servers(memcached_st *ptr);

memcached_server_st *
memcached_server_by_key(memcached_st *ptr, const char *key, size_t key_length);

memcached_server_st *
memcached_server_get_last_disconnect(memcached_st *ptr);

void
memcached_server_cursor(memcached_st *ptr,
    memcached_server_fn *callback,
    void *context);

DESCRIPTION

The functions listed here are used to manage the list of servers attached to a libmemcached context. The list of servers is what libmemcached uses to determine where to store and retrieve data.

memcached_servers() will return a pointer to the list of servers. This is a copy of the list that is internal to the structure and is not the actual list. Duplicate servers are allowed, so duplication is not checked. A copy is made of structure so the list provided (and any operations on the list) are not saved.

memcached_server_by_key() allows you to provide a key and retrieve the server which would be used for assignment.

memcached_server_get_last_disconnect() returns a pointer to the last server for which there was a connection problem. It does not mean this particular server is currently dead but if the library is reporting a server is, the returned server is a very good candidate.

memcached_server_cursor() takes a memcached_st and loops through the list of hosts currently in the cursor calling the list of callback functions provided. You can optionally pass in a value via context which will be provided to each callback function. An error return from any callback will terminate the loop. memcached_server_cursor() is passed the original caller memcached_st in its current state.

RETURN VALUE

Varies, see particular functions.

الوصف

الوظائف المدرجة هنا تستخدم لإدارة قائمة الخوادم المرفقة بسياق libmemcached. قائمة الخوادم هي ما تستخدمه libmemcached لتحديد مكان تخزين البيانات واسترجاعها.

memcached_servers() ستعيد مؤشرًا إلى قائمة الخوادم. هذه نسخة من القائمة الداخلية للهيكل وليست القائمة الفعلية. يُسمح بالخوادم المكررة، لذا لا يتم فحص التكرار. يتم إنشاء نسخة من الهيكل لذلك فإن القائمة المقدمة (وأي عمليات على القائمة) لا يتم حفظها.

memcached_server_by_key() تسمح لك بتوفير مفتاح واسترجاع الخادم الذي سيتم استخدامه للتعيين.

memcached_server_get_last_disconnect() تعيد مؤشرًا إلى آخر خادم كانت هناك مشكلة في اتصاله. هذا لا يعني أن هذا الخادم المحدد ميت حاليًا، ولكن إذا كانت المكتبة تبلغ عن خادم بأنه كذلك، فإن الخادم المُعاد هو مرشح جيد جدًا.

memcached_server_cursor() تأخذ memcached_st وتمر عبر قائمة المضيفات الموجودة حاليًا في المؤشر وتستدعي قائمة وظائف الاستدعاء المرتد المقدمة. يمكنك اختياريًا تمرير قيمة عبر السياق التي سيتم توفيرها لكل وظيفة استدعاء مرتجع. ستؤدي عودة خطأ من أي استدعاء مرتجع إلى إنهاء الحلقة. يتم تمرير memcached_st الأصلي للمتصل في حالته الحالية إلى memcached_server_cursor().
