الحزمة: gettext

MSGEN(1) أوامر المستخدم MSGEN(1)

الاسم

msgen - إنشاء كتالوج رسائل إنجليزية

الملخص

msgen [خيار] ملف_إدخال

الوصف

يقوم بإنشاء كتالوج ترجمة إنجليزي. ملف الإدخال هو آخر ملف PO إنجليزي تم إنشاؤه، أو قالب ملف PO (عادة ما يتم إنشاؤه بواسطة xgettext). يتم تعيين ترجمة متطابقة لـ msgid للإدخالات غير المترجمة.

الوسائط الإلزامية للخيار الطويل إلزامية للخيارات القصيرة أيضًا.

موقع ملف الإدخال:

ملف_إدخال
ملف PO أو POT للإدخال
-D, --directory=الدليل
أضف الدليل إلى قائمة البحث عن ملفات الإدخال

إذا كان ملف الإدخال هو -، تتم قراءة المدخل القياسي.

موقع ملف الإخراج:

-o, --output-file=ملف
اكتب الإخراج إلى الملف المحدد

تتم كتابة النتائج إلى المخرج القياسي إذا لم يتم تحديد ملف إخراج أو إذا كان "-".

صيغة ملف الإدخال:

-P, --properties-input
ملف الإدخال بصيغة Java .properties
--stringtable-input
ملف الإدخال بصيغة NeXTstep/GNUstep .strings

تفاصيل الإخراج:

--lang=اسم_الكتالوج
تعيين حقل 'اللغة' في إدخال الرأس
--color
استخدام الألوان والسمات النصية الأخرى دائمًا
--color=متى
استخدام الألوان والسمات النصية الأخرى إذا كان WHEN. يمكن أن يكون WHEN 'always'، 'never'، 'auto'، أو 'html'.
--style=ملف_النمط
تحديد ملف قاعدة نمط CSS لـ --color
-e, --no-escape
عدم استخدام تسلسلات C الهروب في الإخراج (افتراضي)
-E, --escape
استخدام تسلسلات C الهروب في الإخراج، لا رموز موسعة
--force-po
كتابة ملف PO حتى لو كان فارغًا
-i, --indent
نمط إخراج مسافة بادئة
--no-location
كبت أسطر '#: filename:line'
-n, --add-location
الحفاظ على أسطر '#: filename:line' (افتراضي)
--strict
نمط إخراج Uniforum صارم
-p, --properties-output
كتابة ملف Java .properties
--stringtable-output
كتابة ملف NeXTstep/GNUstep .strings
-w, --width=رقم
تعيين عرض صفحة الإخراج
--no-wrap
لا تقم بتقسيم أسطر الرسائل الطويلة، الأطول من عرض صفحة الإخراج، إلى عدة أسطر
-s, --sort-output
إنشاء إخراج مرتب
-F, --sort-by-file
ترتيب الإخراج حسب موقع الملف

إخراج إعلامي:

-h, --help
عرض هذا المساعدة والخروج
-V, --version
إخراج معلومات الإصدار والخروج

المؤلف

كتبه برونو هايبلي.
