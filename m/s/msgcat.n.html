msgcat(n)

الحزمة: tcl

التراخيص: TCL

msgcat(n) حزم Tcl المجمعة msgcat(n)

الاسم

msgcat - كتالوج رسائل Tcl

ملخص

package require Tcl 8.5

package require msgcat 1.6

::msgcat::mc src-string ?arg arg ...?

::msgcat::mcmax ?src-string src-string ...?

::msgcat::mcexists ?-exactnamespace? ?-exactlocale? src-string

::msgcat::mclocale ?newLocale?

::msgcat::mcpreferences

::msgcat::mcloadedlocales subcommand ?locale?

::msgcat::mcload dirname

::msgcat::mcset locale src-string ?translate-string?

::msgcat::mcmset locale src-trans-list

::msgcat::mcflset src-string ?translate-string?

::msgcat::mcflmset src-trans-list

::msgcat::mcunknown locale src-string ?arg arg ...?

::msgcat::mcpackagelocale subcommand ?locale?

::msgcat::mcpackageconfig subcommand option ?value?

::msgcat::mcforgetpackage

الوصف

توفر حزمة msgcat مجموعة من الوظائف التي يمكن استخدامها لإدارة واجهات المستخدم متعددة اللغات. يتم تعريف سلاسل النص في "كتالوج رسائل" يكون مستقلاً عن التطبيق، ويمكن تحريره أو توطينه دون تعديل كود مصدر التطبيق. يمكن توفير لغات أو مواقع جديدة بإضافة ملف جديد إلى كتالوج الرسائل.

msgcat يميز الحزم حسب مساحات الأسماء الخاصة بها. كل حزمة لها كتالوج رسائل وإعدادات تكوين خاصة بها في msgcat.

الموقع (locale) هو سلسلة مواصفات تصف لغة المستخدم مثل de_ch للألمانية السويسرية. في msgcat، يوجد موقع عام يتم تهيئته بالموقع المحلي للنظام الحالي. قد تقرر كل حزمة استخدام الموقع العام أو استخدام موقع خاص بالحزمة.

يمكن تغيير الموقع العام عند الطلب، على سبيل المثال، عن طريق تغيير لغة يبدأها المستخدم أو داخل تطبيق متعدد المستخدمين مثل خادم الويب.

الأوامر

::msgcat::mc src-string ?arg arg ...?
يعيد ترجمة src-string وفقًا للموقع الحالي. إذا تم إعطاء حجج إضافية بعد src-string، يتم استخدام الأمر format لاستبدال الحجج الإضافية في ترجمة src-string.

سيبحث ::msgcat::mc عن الرسائل المعرفة في مساحة الأسماء الحالية للحصول على ترجمة لـ src-string؛ إذا لم يتم العثور على ترجمة، فسيبحث في مساحة الأسماء الأصلية، وهكذا حتى يصل إلى مساحة الأسماء العامة. إذا لم يكن هناك سلسلة ترجمة موجودة، يتم استدعاء ::msgcat::mcunknown ويتم إرجاع السلسلة المستلمة من ::msgcat::mcunknown.

::msgcat::mc هو الوظيفة الرئيسية المستخدمة لتوطين تطبيق. بدلاً من استخدام سلسلة نصية باللغة الإنجليزية مباشرة، يمكن للتطبيق تمرير السلسلة الإنجليزية عبر ::msgcat::mc واستخدام النتيجة. إذا تم كتابة تطبيق بلغة واحدة بهذه الطريقة، فمن السهل إضافة دعم للغات إضافية لاحقًا ببساطة عن طريق تحديد إدخالات جديدة في كتالوج الرسائل.

::msgcat::mcmax ?src-string src-string ...?
بالنظر إلى عدة سلاسل مصدر، يعيد ::msgcat::mcmax طول أطول سلسلة مترجمة. هذا مفيد عند تصميم واجهات المستخدم المحلية، والتي قد تتطلب أن تكون جميع الأزرار، على سبيل المثال، ذات عرض ثابت (والذي سيكون عرض أوسع زر).
::msgcat::mcexists ?-exactnamespace? ?-exactlocale? src-string
يعيد صحيحة، إذا كانت هناك ترجمة لـ src-string المعطاة.
قد يتم تقييد البحث بالخيار -exactnamespace للتحقق فقط في مساحة الأسماء الحالية وليس في أي مساحات أسماء أصلية.

قد يتم تقييده أيضًا بالخيار -exactlocale للتحقق فقط من الموقع المفضل الأول (على سبيل المثال، أول عنصر تم إرجاعه بواسطة ::msgcat::mcpreferences إذا تم استخدام الموقع العام).

::msgcat::mclocale ?newLocale?
يقوم هذا الأمر بتعيين الموقع إلى newLocale. إذا تم حذف newLocale، يتم إرجاع الموقع الحالي، وإلا يتم تعيين الموقع الحالي إلى newLocale. يقوم msgcat بتخزين ومقارنة الموقع بشكل غير حساس لحالة الأحرف، ويعيد المواقع بحروف صغيرة. يتم تحديد الموقع الأولي بواسطة الموقع المحدد في بيئة المستخدم. انظر مواصفات الموقع (LOCALE SPECIFICATION) أدناه لوصف تنسيق سلسلة الموقع.

إذا تم تعيين الموقع، يتم تقييم قائمة المواقع المفضلة. يتم تحميل المواقع في هذه القائمة الآن، إذا لم يتم تحميلها بعد.

::msgcat::mcpreferences
يعيد قائمة مرتبة بالمواقع التي يفضلها المستخدم، بناءً على مواصفات لغة المستخدم. القائمة مرتبة من الأكثر تحديدًا إلى الأقل تفضيلاً. يتم اشتقاق القائمة من الموقع الحالي المحدد في msgcat بواسطة ::msgcat::mclocale، ولا يمكن تعيينها بشكل مستقل. على سبيل المثال، إذا كان الموقع الحالي هو en_US_funky، فإن ::msgcat::mcpreferences يعيد {en_us_funky en_us en {}}.
::msgcat::mcloadedlocales subcommand ?locale?
تدير هذه المجموعة من الأوامر قائمة المواقع المحملة للحزم التي لم تقم بتعيين موقع حزمة.
يعيد الأمر الفرعي get قائمة بالمواقع المحملة حاليًا.

يتطلب الأمر الفرعي present الوسيط locale ويعيد صحيحًا، إذا كان هذا الموقع محملًا.

يقوم الأمر الفرعي clear بإزالة جميع المواقع وبياناتها، التي ليست في قائمة التفضيلات الحالية.

::msgcat::mcload dirname
يبحث في الدليل المحدد عن الملفات التي تتطابق مع مواصفات اللغة التي تم إرجاعها بواسطة ::msgcat::mcloadedlocales get (أو msgcat::mcpackagelocale preferences إذا تم تعيين موقع حزمة) (لاحظ أن هذه كلها بأحرف صغيرة)، ممتدة بالامتداد ".msg". تتم قراءة كل ملف مطابق بالترتيب، بافتراض ترميز UTF-8. ثم يتم تقييم محتويات الملف كبرنامج Tcl نصي. هذا يعني أن أحرف Unicode قد تكون موجودة في ملف الرسالة إما مباشرة في شكلها المشفر بـ UTF-8، أو باستخدام الاقتباس المائل العكسي u المعروف لتقييم Tcl. يتم إرجاع عدد ملفات الرسائل التي طابقت المواصفات وتم تحميلها.

بالإضافة إلى ذلك، يتم تخزين المجلد المحدد في خيار تكوين حزمة msgcat mcfolder لتحميل ملفات كتالوج الرسائل المطلوبة لتغيير الموقع في النهاية.

::msgcat::mcset locale src-string ?translate-string?
يعين ترجمة src-string إلى translate-string في locale المحددة وفي مساحة الأسماء الحالية. إذا لم يتم تحديد translate-string، يتم استخدام src-string لكليهما. يعيد الأمر translate-string.
::msgcat::mcmset locale src-trans-list
يعين ترجمة لسلاسل مصدر متعددة في src-trans-list في locale المحددة وفي مساحة الأسماء الحالية. يجب أن يحتوي src-trans-list على عدد زوجي من العناصر ويكون بالتنسيق {src-string translate-string ?src-string translate-string ...?} يمكن أن يكون ::msgcat::mcmset أسرع بكثير من الاستدعاءات المتعددة لـ ::msgcat::mcset. يعيد الأمر عدد الترجمات التي تم تعيينها.
::msgcat::mcflset src-string ?translate-string?
يعين ترجمة src-string إلى translate-string في مساحة الأسماء الحالية للموقع المستدل عليه من اسم كتالوج الرسائل الذي يتم تحميله عبر ::msgcat::mcload. إذا لم يتم تحديد translate-string، يتم استخدام src-string لكليهما. يعيد الأمر translate-string.
::msgcat::mcflmset src-trans-list
يعين ترجمة لسلاسل مصدر متعددة في src-trans-list في مساحة الأسماء الحالية للموقع المستدل عليه من اسم كتالوج الرسائل الذي يتم تحميله عبر ::msgcat::mcload. يجب أن يحتوي src-trans-list على عدد زوجي من العناصر ويكون بالتنسيق {src-string translate-string ?src-string translate-string ...?} يمكن أن يكون ::msgcat::mcflmset أسرع بكثير من الاستدعاءات المتعددة لـ ::msgcat::mcflse

The ::msgcat::mcunknown command is called by ::msgcat::mc when a translation for a given src-string is not found. The default implementation simply returns the src-string. This command may be overridden by a package to provide a custom behaviour, for example logging the missing string or returning a generic placeholder.

::msgcat::mcpackagelocale subcommand ?locale?
This group of commands manage the list of loaded locales for packages. This is mainly useful for packages that depend on other packages (e.g. themes).
The subcommand get returns the list of currently loaded locales for the current package.

The subcommand set requires the argument locale and sets the locale for the current package. This locale is used when calling ::msgcat::mc within the context of the package.

The subcommand preferences requires the argument locale and returns an ordered list of the locales preferred by the user for the current package. This is derived from the locale set with the set subcommand, similar to how ::msgcat::mcpreferences works for the global locale.

::msgcat::mcpackageconfig subcommand option ?value?
This group of commands manage package specific configuration settings.
The subcommand mcfolder requires the argument value and sets the directory where message catalogs are looked for. This is stored in the package configuration and is used by ::msgcat::mcload.

The subcommand locale requires the argument value and sets the locale for the current package. This locale is used when calling ::msgcat::mc within the context of the package. This is equivalent to calling ::msgcat::mcpackagelocale set.

::msgcat::mcforgetpackage
Removes all configuration and message catalog data associated with the current package's namespace. This is useful for situations where a package might be unloaded or reloaded, and its message catalog needs to be cleared from memory.

مواصفات الموقع

A locale is a string that specifies the language, and optionally region and character set. The format is typically: language[_region][.codeset][@modifier].

Examples:

en
English
en_US
American English
de_CH
German in Switzerland
POSIX
POSIX locale

msgcat requires the locale names to be in lowercase. When a locale is set using ::msgcat::mclocale, it is converted to lowercase. The region and codeset specifiers are also converted to lowercase. For example, if the user's environment sets the locale to LANG=en_US.UTF-8, msgcat will internally use en_us.

The ::msgcat::mcpreferences command returns a list of locales, ordered by preference, starting with the most specific. For example, if the current locale is en_US.UTF-8, then ::msgcat::mcpreferences will return the list {en_us_utf-8 en_us en}.

مثال

The following example demonstrates how to use msgcat to internationalize a simple Tcl script:

Suppose we have a file named /usr/share/my_app/en.msg with the following content:

    package require msgcat

    # English messages
    ::msgcat::mcset en_US Hello World
    ::msgcat::mcset en_US Ask question "Enter your name:"

And a file named /usr/share/my_app/de.msg with the following content:

    package require msgcat

    # German messages
    ::msgcat::mcset de_DE Hallo Welt
    ::msgcat::mcset de_DE Ask question "Geben Sie Ihren Namen ein:"

And a main script named my_app.tcl:

    package require Tcl 8.5
    package require msgcat

    # Load the message catalogs from the /usr/share/my_app directory
    ::msgcat::mcload /usr/share/my_app

    # Set the locale (e.g., based on environment or user preference)
    # For demonstration, we'll explicitly set it. In a real app,
    # you'd likely get this from the environment or a user setting.
    # Example: set locale "de_DE"
    # Example: set locale "en_US"
    set locale [::msgcat::mclocale]
    puts "Using locale: $locale"

    # Use the mc command to display localized messages
    puts [::msgcat::mc "Hello World"]
    set name [gets stdin]
    puts [::msgcat::mc "Ask question" $name]

If you run this script with the locale set to "de_DE", the output will be:

    Using locale: de_de
    Hallo Welt
    Geben Sie Ihren Namen ein:

If you run this script with the locale set to "en_US", the output will be:

    Using locale: en_us
    Hello World
    Enter your name:

This example illustrates how msgcat allows you to separate your application's text from its code, making it easier to translate and maintain.

FUNCTIONS

::msgcat::mc src-string ?arg arg ...?
Translate the src-string using the current locale. If any arguments are given, they are used for substitution into the translated string, using Tcl's format command. The translated string is returned.
::msgcat::mcbuild
Builds the internal message catalogs from the list of message files. This is usually done automatically by ::msgcat::mcload.
::msgcat::mcload ?dir dir ...?
This command loads all the message catalog files from the specified directories. The message catalog files are expected to be named using the locale specifier (e.g. en_US.msg, fr.msg). If no arguments are given, the command tries to load message catalogs from the directories specified in the msgcat package's internal list of directories. This command may cause the load of locales.
::msgcat::mclocale ?locale?
Get or set the current locale. If locale is specified, the current locale is set to this value. If not, the current locale is returned. The command returns the actual locale set, which might be different from the requested one (e.g. if the requested locale is not available). The command may cause the load of locales.
::msgcat::mcset locale src-string ?string?
Add a translation string string for the source string src-string in the specified locale. If string is not given, the current value is removed. The source string and the locale are automatically associated with the namespace from which the command is called. The return value is the number of translations set.
::msgcat::mcunknown locale src-string ?arg arg ...?
This routine is called by ::msgcat::mc in the case when a translation for src-string is not defined in the current locale. The default action is to return src-string passed by format if there are any arguments. This procedure can be redefined by the application, for example to log error messages for each unknown string. The ::msgcat::mcunknown procedure is invoked at the same stack context as the call to ::msgcat::mc. The return value of ::msgcat::mcunknown is used as the return value for the call to ::msgcat::mc.

Note that this routine is only called if the concerned package did not set a package locale unknown command name.

::msgcat::mcforgetpackage
The calling package clears all its state within the msgcat package including all settings and translations.

LOCALE SPECIFICATION

The locale is specified to msgcat by a locale string passed to ::msgcat::mclocale. The locale string consists of a language code, an optional country code, and an optional system-specific code, each separated by “_”. The country and language codes are specified in standards ISO-639 and ISO-3166. For example, the locale “en” specifies English and “en_US” specifies U.S. English.

When the msgcat package is first loaded, the locale is initialized according to the user's environment. The variables env(LC_ALL), env(LC_MESSAGES), and env(LANG) are examined in order. The first of them to have a non-empty value is used to determine the initial locale. The value is parsed according to the XPG4 pattern

language[_country][.codeset][@modifier]

to extract its parts. The initial locale is then set by calling ::msgcat::mclocale with the argument

language[_country][_modifier]

On Windows and Cygwin, if none of those environment variables is set, msgcat will attempt to extract locale information from the registry. From Windows Vista on, the RFC4747 locale name "lang-script-country-options" is transformed to the locale as "lang_country_script" (Example: sr-Latn-CS -> sr_cs_latin). For Windows XP, the language id is transformed analoguously (Example: 0c1a -> sr_yu_cyrillic). If all these attempts to discover an initial locale from the user's environment fail, msgcat defaults to an initial locale of “C”.

When a locale is specified by the user, a “best match” search is performed during string translation. For example, if a user specifies en_GB_Funky, the locales “en_gb_funky”, “en_gb”, “en” and “” (the empty string) are searched in order until a matching translation string is found. If no translation string is available, then the unknown handler is called.

NAMESPACES AND MESSAGE CATALOGS

Strings stored in the message catalog are stored relative to the namespace from which they were added. This allows multiple packages to use the same strings without fear of collisions with other packages. It also allows the source string to be shorter and less prone to typographical error.

For example, executing the code

::msgcat::mcset en hello "hello from ::"
namespace eval foo {
    ::msgcat::mcset en hello "hello from ::foo"
}
puts [::msgcat::mc hello]
namespace eval foo {puts [::msgcat::mc hello]}

will print

hello from ::
hello from ::foo

When searching for a translation of a message, the message catalog will search first the current namespace, then the parent of the current namespace, and so on until the global namespace is reached. This allows child namespaces to “inherit” messages from their parent namespace.

For example, executing (in the “en” locale) the code

::msgcat::mcset en m1 ":: message1"
::msgcat::mcset en m2 ":: message2"
::msgcat::mcset en m3 ":: message3"
namespace eval ::foo {
    ::msgcat::mcset en m2 "::foo message2"
    ::msgcat::mcset en m3 "::foo message3"
}
namespace eval ::foo::bar {
    ::msgcat::mcset en m3 "::foo::bar message3"
}
namespace import ::msgcat::mc
puts "[mc m1]; [mc m2]; [mc m3]"
namespace eval ::foo {puts "[mc m1]; [mc m2]; [mc m3]"}
namespace eval ::foo::bar {puts "[mc m1]; [mc m2]; [mc m3]"}

will print

:: message1; :: message2; :: message3
:: message1; ::foo message2; ::foo message3
:: message1; ::foo message2; ::foo::bar message3

LOCATION AND FORMAT OF MESSAGE FILES

Message files can be located in any directory, subject to the following conditions:

[1]
All message files for a package are in the same directory.
[2]
The message file name is a msgcat locale specifier (all lowercase) followed by “.msg”. For example:
es.msg    — spanish
en_gb.msg — United Kingdom English

Exception: The message file for the root locale “” is called “ROOT.msg”. This exception is made so as not to cause peculiar behavior, such as marking the message file as “hidden” on Unix file systems.

[3]
The file contains a series of calls to mcflset and mcflmset, setting the necessary translation strings for the language, likely enclosed in a namespace eval so that all source strings are tied to the namespace of the package. For example, a short es.msg might contain:
namespace eval ::mypackage {
    ::msgcat::mcflset "Free Beer" "Cerveza Gratis"
}

RECOMMENDED MESSAGE SETUP FOR PACKAGES

If a package is installed into a subdirectory of the tcl_pkgPath and loaded via package require, the following procedure is recommended.

[1]
During package installation, create a subdirectory msgs under your package directory.
[2]
Copy your *.msg files into that directory.
[3]
Add the following command to your package initialization script:
# load language files, stored in msgs subdirectory
::msgcat::mcload [file join [file dirname [info script]] msgs]

POSITIONAL CODES FOR FORMAT AND SCAN COMMANDS

It is possible that a message string used as an argument to format might have positionally dependent parameters that might need to be repositioned. For example, it might be syntactically desirable to rearrange the sentence structure while translating.

format "We produced %d units in location %s" $num $city
format "In location %s we produced %d units" $city $num

This can be handled by using the positional parameters:

format "We produced %1\$d units in location %2\$s" $num $city
format "In location %2\$s we produced %1\$d units" $num $city

Similarly, positional parameters can be used with scan to extract values from internationalized strings. Note that it is not necessary to pass the output of ::msgcat::mc to format directly; by passing the values to substitute in as arguments, the formatting substitution is done directly.

msgcat::mc {Produced %1$d at %2$s} $num $city
# ... where that key is mapped to one of the
# human-oriented versions by msgcat::mcset

Package private locale

A package using msgcat may choose to use its own package private locale and its own set of loaded locales, independent to the global locale set by ::msgcat::mclocale.

This allows a package to change its locale without causing any locales load or removal in other packages and not to invoke the global locale change callback (see below).

This action is controled by the following ensemble:

::msgcat::mcpackagelocale set ?locale?
Set or change a package private locale. The package private locale is set to the given locale if the locale is given. If the option locale is not given, the package is set to package private locale mode, but no locale is changed (e.g. if the global locale was valid for the package before, it is copied to the package private locale).
This command may cause the load of locales.
::msgcat::mcpackagelocale get
Return the package private locale or the global locale, if no package private locale is set.
::msgcat::mcpackagelocale preferences
Return the package private preferences or the global preferences, if no package private locale is set.
::msgcat::mcpackagelocale loaded
Return the list of locales loaded for this package.
::msgcat::mcpackagelocale isset
Returns true, if a package private locale is set.
::msgcat::mcpackagelocale unset
Unset the package private locale and use the globale locale. Load and remove locales to adjust the list of loaded locales for the package to the global loaded locales list.
::msgcat::mcpackagelocale present locale
Returns true, if the given locale is loaded for the package.
::msgcat::mcpackagelocale clear
Clear any loaded locales of the package not present in the package preferences.

Changing package options

This section describes how to change options of a package for which a package private locale is set.

::msgcat::mcsetpackage option value ?option value ...?
Set the specified options for the calling package. If package private locale is not used, this command has no effect. The following options are supported:
unknown cmdName
Replace the default unknown message handler (::msgcat::mcunknown) with the command cmdName for this package.

تغيير خيارات الحزمة

كل حزمة تستخدم msgcat لديها مجموعة من الخيارات داخل msgcat. يتم وصف خيارات الحزمة في القسم التالي "خيارات الحزمة". يمكن تعيين أو إلغاء تعيين كل خيار حزمة بشكل فردي باستخدام المجموعة التالية:

::msgcat::mcpackageconfig get option
إرجاع القيمة الحالية لـ option المعطى. يستدعي هذا الاستدعاء خطأ إذا لم يتم تعيين الخيار للحزمة.
::msgcat::mcpackageconfig isset option
يرجع 1، إذا تم تعيين option المعطى للحزمة، و 0 بخلاف ذلك.
::msgcat::mcpackageconfig set option value
تعيين option المعطى إلى value المعطى. قد يستدعي هذا إجراءات إضافية تبعاً لـ option. القيمة المرجعة هي 0 أو عدد الحزم المحملة لـ mcfolder option.
::msgcat::mcpackageconfig unset option
إلغاء تعيين option المعطى للحزمة. لا يتم اتخاذ أي إجراء إذا لم يتم تعيين option للحزمة. يتم إرجاع سلسلة فارغة.

خيارات الحزمة

خيارات الحزمة التالية متاحة لكل حزمة:

mcfolder
هذا هو مجلد الرسائل الخاص بالحزمة. يتم تعيين هذا الخيار بواسطة mcload وبواسطة الأمر الفرعي set. كلاهما متطابق وكلاهما يعيد عدد ملفات كتالوج الرسائل المحملة.

سيؤدي تعيين أو تغيير هذه القيمة إلى تحميل جميع اللغات المحددة في التفضيلات الصالحة للحزمة. وهذا يعني أيضًا استدعاء أي أمر تحميل (انظر أدناه).

سيؤدي إلغاء تعيين هذه القيمة إلى تعطيل تحميل ملفات الرسائل للحزمة.

loadcmd
يتم استدعاء رد الاتصال هذا قبل تحميل مجموعة من ملفات كتالوج الرسائل للحزمة التي لديها هذه الخاصية مضبوطة.

يمكن استخدام رد الاتصال هذا للقيام بأي عمل تحضيري لتحميل ملف الرسائل أو للحصول على بيانات الرسائل من مصدر آخر مثل قاعدة بيانات. في هذه الحالة، لا يتم استخدام ملفات الرسائل (يتم إلغاء تعيين mcfolder).

انظر قسم استدعاء رد الاتصال أدناه. قائمة المعلمات الملحقة برد الاتصال هذا هي قائمة اللغات المراد تحميلها.

إذا تم تغيير رد الاتصال هذا، يتم استدعاؤه مع التفضيلات الصالحة للحزمة.

changecmd
يتم استدعاء رد الاتصال هذا عند إجراء تغيير افتراضي للغة. والغرض منه هو السماح للحزمة بتحديث أي اعتماديات على اللغة الافتراضية مثل عرض واجهة المستخدم الرسومية بلغة أخرى.

انظر قسم استدعاء رد الاتصال أدناه. قائمة المعلمات الملحقة برد الاتصال هذا هي mcpreferences. يتم استدعاء ردود الاتصال المسجلة بترتيب غير محدد.

unknowncmd
استخدم إجراء لغة حزمة mcunknown بدلاً من الإصدار القياسي الذي توفره حزمة msgcat (msgcat::mcunknown).

يجب أن يعيد الإجراء المستدعى الرسالة المنسقة التي سيتم إرجاعها في النهاية بواسطة msgcat::mc.

يتم استخدام معالج عام غير معروف إذا تم تعيينه إلى سلسلة فارغة. يتكون هذا من إرجاع المفتاح إذا لم يتم تقديم وسائط. مع الوسائط المقدمة، يتم استخدام التنسيق لمعالجة الوسائط.

انظر قسم استدعاء رد الاتصال أدناه. الوسائط الملحقة متطابقة مع ::msgcat::mcunknown.

استدعاء رد الاتصال

قد تقرر الحزمة تسجيل رد اتصال واحد أو أكثر، كما هو موضح أعلاه.

يتم استدعاء ردود الاتصال، إذا:

1. أمر رد الاتصال مضبوط،

2. الأمر ليس سلسلة فارغة،

3. مساحة الاسم المسجلة موجودة.

إذا فشل روتين مستدعى بخطأ، يتم استدعاء روتين bgerror للمترجم بعد اكتمال الأمر. الاستثناء الوحيد هو رد الاتصال unknowncmd، حيث يتسبب الخطأ في فشل أمر mc المستدعي بهذا الخطأ.

أمثلة

قد تقوم الحزم التي تعرض واجهة مستخدم رسومية بتحديث عناصرها عند تغيير اللغة العامة. للتسجيل في رد اتصال، استخدم:

namespace eval gui {
    msgcat::mcpackageconfig changecmd updateGUI
    proc updateGUI args {
        puts "New locale is '[lindex $args 0]'."
    }
}
% msgcat::mclocale fr
fr
% New locale is 'fr'.

إذا كانت اللغات (أو اللغات الإضافية) موجودة في مصدر آخر مثل قاعدة بيانات، فقد تستخدم الحزمة رد الاتصال تحميل ولا تستخدم mcload:

namespace eval db {
    msgcat::mcpackageconfig loadcmd loadMessages
    proc loadMessages args {
        foreach locale $args {
            if {[LocaleInDB $locale]} {
                msgcat::mcmset $locale [GetLocaleList $locale]
            }
        }
    }
}

يستخدم تنفيذ الأمر clock msgcat مع لغة حزمة لتنفيذ معلمة سطر الأوامر -locale. إليك بعض الرسومات التوضيحية للتنفيذ:

أولاً، يتم تهيئة لغة حزمة ويتم تعطيل دالة غير معروفة عامة:

msgcat::mcpackagelocale set
msgcat::mcpackageconfig unknowncmd ""
كمثال، يتطلب المستخدم يوم الأسبوع بلغة معينة على النحو التالي: 
clock format [clock seconds] -format %A -locale fr
يقوم clock بتعيين لغة الحزمة إلى fr ويبحث عن اسم اليوم على النحو التالي: 
msgcat::mcpackagelocale set $locale
return [lindex [msgcat::mc DAYS_OF_WEEK_FULL] $day]
### Returns "mercredi"
داخل clock، تكون بعض عناصر كتالوج الرسائل ثقيلة في الحساب وبالتالي يتم تخزينها مؤقتًا ديناميكيًا باستخدام: 
proc ::tcl::clock::LocalizeFormat { locale format } {
    set key FORMAT_$format
    if { [::msgcat::mcexists -exactlocale -exactnamespace $key] } {
        return [mc $key]
    }
    #...expensive computation of format clipped...
    mcset $locale $key $format
    return $format
}
