الحزمة: gettext

التراخيص: GFDL-1.2-only, GPL-2.0-only, GPL-2.0-or-later, LGPL-2.0-only

MSGUNFMT(1) أوامر المستخدم MSGUNFMT(1)

اسم

msgunfmt - إلغاء تجميع كتالوج الرسائل من صيغة ثنائية

ملخص

msgunfmt [خيار] [ملف]...

وصف

تحويل كتالوج الرسائل الثنائي إلى ملف .po بأسلوب Uniforum.

الحجج الإلزامية للخيارات الطويلة إلزامية للخيارات القصيرة أيضًا.

وضع التشغيل:

-j, --java
وضع Java: المدخل هو فئة Java ResourceBundle
--csharp
وضع C#: المدخل هو ملف .NET .dll
--csharp-resources
وضع موارد C#: المدخل هو ملف .NET .resources
--tcl
وضع Tcl: المدخل هو ملف tcl/msgcat .msg

موقع ملف الإدخال:

ملف ...
ملفات .mo المدخلة

إذا لم يتم تقديم ملف إدخال أو إذا كان '-', يتم قراءة الإدخال القياسي.

موقع ملف الإدخال في وضع Java:

-r, --resource=المورد
اسم المورد
-l, --locale=اللغة
اسم اللغة، إما لغة أو لغة_بلد

يتم تحديد اسم الفئة عن طريق إلحاق اسم اللغة باسم المورد، مفصولًا بشرطة سفلية. يتم تحديد موقع الفئة باستخدام CLASSPATH.

موقع ملف الإدخال في وضع C#:

-r, --resource=المورد
اسم المورد
-l, --locale=اللغة
اسم اللغة، إما لغة أو لغة_بلد
-d المجلد
المجلد الأساسي لملفات .dll الخاصة باللغة

الخياران -l و -d إجباريان. يتم تحديد موقع ملف .dll في مجلد فرعي للمجلد المحدد يعتمد اسمه على اللغة.

موقع ملف الإدخال في وضع Tcl:

-l, --locale=اللغة
اسم اللغة، إما لغة أو لغة_بلد
-d المجلد
المجلد الأساسي لكتالوجات رسائل .msg

الخياران -l و -d إجباريان. يتم تحديد موقع ملف .msg في المجلد المحدد.

موقع ملف الإخراج:

-o, --output-file=ملف
اكتب الإخراج إلى الملف المحدد

تتم كتابة النتائج إلى الإخراج القياسي إذا لم يتم تحديد ملف إخراج أو إذا كان '-'.

تفاصيل الإخراج:

--color
استخدم الألوان والسمات النصية الأخرى دائمًا
--color=متى
استخدم الألوان والسمات النصية الأخرى إذا متى. يمكن أن تكون متى 'دائمًا' أو 'أبدًا' أو 'تلقائي' أو 'html'.
--style=ملف_النمط
تحديد ملف قواعد CSS لـ --color
-e, --no-escape
لا تستخدم تسلسلات C في الإخراج (الافتراضي)
-E, --escape
استخدم تسلسلات C في الإخراج، لا توجد أحرف موسعة
--force-po
اكتب ملف PO حتى لو كان فارغًا
-i, --indent
اكتب نمط إخراج مسافة بادئة
--strict
اكتب نمط uniforum صارم
-p, --properties-output
اكتب ملف .properties الخاص بـ Java
--stringtable-output
اكتب ملف .strings الخاص بـ NeXTstep/GNUstep
-w, --width=رقم
اضبط عرض صفحة الإخراج
--no-wrap
لا تقم بتقسيم أسطر الرسائل الطويلة، الأطول من عرض صفحة الإخراج، إلى أسطر متعددة
-s, --sort-output
إنشاء إخراج مرتب

إخراج معلوماتي:

-h, --help
عرض هذه المساعدة والخروج
-V, --version
إخراج معلومات الإصدار والخروج
-v, --verbose
زيادة مستوى الإسهاب

الوثائق الكاملة لـ msgunfmt تتم صيانتها كدليل Texinfo. إذا كانت برامج info و msgunfmt مثبتة بشكل صحيح في موقعك، فإن الأمر

info msgunfmt
