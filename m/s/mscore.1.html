الوصف

MuseScore هو برنامج مجاني ومفتوح المصدر ومتعدد اللغات ومتعدد المنصات لإنشاء وتدوين الموسيقى WYSIWYG، تم إصداره بموجب رخصة GNU General Public Licence (GPLv2).

تشغيل mscore بدون أي خيارات إضافية يقوم بتشغيل برنامج MuseScore الرسومي الكامل ويفتح أي ملفات محددة في سطر الأوامر.

الخيارات هي كما يلي:

-b | --bitrate معدل البت
تعيين معدل بت MP3 الناتج بالكيلوبت في الثانية.
-c | --config-folder مسار المجلد
تجاوز مجلد التكوين والإعدادات.
-D | --monitor-resolution DPI
تحديد دقة الشاشة (تجاوز الكشف التلقائي).
-d | --debug
بدء MuseScore في وضع التصحيح.
-E | --install-extension ملف الامتداد
تثبيت ملف امتداد؛ يتم تحميل soundfonts افتراضيًا ما لم يتم تحديد -e أيضًا.
-e | --experimental
تمكين الميزات التجريبية، مثل الطبقات.
-F | --factory-settings
استعادة جميع الإعدادات، الاختصارات، مساحات العمل، الامتدادات، الترجمات، إلخ. إلى الإعدادات الافتراضية للمصنع؛ قارن مع الخيار -R.
-f | --force
تجاهل تحذيرات تلف النوتة وعدم تطابق الإصدار في "وضع المحول".
-h | --help
عرض نظرة عامة على تعليمات الاستدعاء.
-I | --dump-midi-in
عرض كل مدخلات MIDI على وحدة التحكم.
-i | --load-icons
تحميل الأيقونات من نظام الملفات؛ مفيد إذا كنت ترغب في تعديل أيقونات MuseScore ومعاينة التغييرات.
-j | --job ملف.json
معالجة مهمة تحويل (انظر أمثلة أدناه).
-L | --layout-debug
بدء MuseScore في وضع تصحيح التخطيط.
-M | --midi-operations ملف
تحديد ملف عمليات استيراد MIDI (انظر أمثلة أدناه).
-m | --no-midi
تعطيل مدخلات MIDI.
-n | --new-score
بدء تشغيل معالج "نوتة جديدة" بغض النظر عما إذا كان ممكّنًا أو معطلاً في تفضيلات المستخدم.
-O | --dump-midi-out
عرض كل مخرجات MIDI على وحدة التحكم.
-o | --export-to ملف
تصدير الملف المحدد (أو المفتوح حاليًا) إلى ملف الإخراج المحدد. يعتمد نوع الملف على امتداد اسم الملف المحدد. يقوم هذا الخيار بالتبديل إلى "وضع المحول" ويتجنب واجهة المستخدم الرسومية.
-P | --export-score-parts
عند التحويل إلى PDF باستخدام الخيار -o، قم بإلحاق صفحات كل جزء بالملف PDF الذي تم إنشاؤه. إذا لم يكن للنوتة أجزاء، فسيتم إنشاء جميع الأجزاء الافتراضية تلقائيًا مؤقتًا.
-p | --plugin اسم
تنفيذ المكون الإضافي المسمى.
-R | --revert-settings
استعادة تفضيلات المستخدم إلى الإعدادات الافتراضية للمصنع ولكن مع الاحتفاظ بالاختصارات ومساحات العمل والامتدادات والترجمات وما إلى ذلك؛ قارن مع -F.
-r | --image-resolution

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

mscore(1) — MuseScore

NAME

mscore

command-line conversion utility for MuseScore scores

SYNOPSIS

mscore [-a action] [-c directory] [-D] [-e encoder] [-f format] [-h] [-i directory] [-j job] [-M midilog] [-o outfile] [-P preset] [-s] [-T timeout] [-v] [--transpose transpose_spec] [-w] [infile ...]

DESCRIPTION

The mscore utility is a command-line batch processor for MuseScore scores. It can be used to convert MuseScore files (.mscz, .mxl, .xml) to other formats, such as PDF, PNG, SVG, MIDI, and MusicXML. It can also perform actions like transposing, applying plugins, and exporting parts.

ENVIRONMENT

The MuseScore application looks for its configuration files in several locations. The default locations for user-specific configuration and data are under the user's home directory. Specifically, configuration files are expected under $XDG_CONFIG_HOME/MuseScore/, and data files under $XDG_DATA_HOME/MuseScore/. If $XDG_CONFIG_HOME is not set, it defaults to $HOME/.config/. Similarly, if $XDG_DATA_HOME is not set, it defaults to $HOME/.local/share/. The location of user documents is determined by the environment variable $XDG_DOCUMENTS_DIR, which defaults to $HOME/Documents/.

Note that MuseScore also supports the normal Qt environment variables such as QT_QPA_GENERIC_PLUGINS, QT_QPA_PLATFORM, QT_QPA_PLATFORMTHEME, QT_QPA_PLATFORM_PLUGIN_PATH, QT_STYLE_OVERRIDE, DISPLAY, etc.

FILES

/usr/share/mscore-4.5/ contains the application support data (demos, instruments, localisation, system-wide plugins, soundfonts, styles, chords, templates and wallpapers). In the Debian packages, system-wide soundfonts are installed into /usr/share/sounds/sf2/, /usr/share/sounds/sf3/ or /usr/share/sounds/sfz/, respectively, instead.

The per-user data (extensions, plugins, soundfonts, styles, templates) and files (images, scores) are normally installed into subdirectories under $XDG_DOCUMENTS_DIR/MuseScore3/ but may be changed in the configuration. Note that snapshot, alpha and beta versions use MuseScore3Development instead of MuseScore3 in all of these paths.

$XDG_CONFIG_HOME/MuseScore/MuseScore3.ini contains the user preferences, list of recently used files and their locations, window sizes and positions, etc. See above for development version paths.

$XDG_DATA_HOME/MuseScore/MuseScore3/ contains updated localisation files downloaded from within the program, plugin information, cached scores, credentials for the musescore.com community site, session information, synthesiser settings, custom key and time signatures and shortcuts. See above for development version paths.

EXAMPLES

Convert a score to PDF from the command line:

mscore -o 'My Score.pdf' 'My Score.mscz'

Transpose, then convert a score to PDF from the command line:

-o 'My Transposed Score.pdf' --transpose '{"mode": "by_interval",
"direction": "up", "transposeInterval": 12,
"transposeKeySignatures": true}' 'My Score.mscz'

Transpose to another score from the command line:

-o 'My Transposed Score.mscz' --transpose '{"mode": "diatonically",
"direction": "down", "transposeInterval": 3,
"useDoubleSharpsFlats": true}' 'My Score.mscz'

Run a batch job converting multiple documents:

mscore -j job.json

This requires the file job.json in the current working directory to have content similar to the following:

[
  {
    "in": "Reunion.mscz",
    "out": "Reunion-coloured.pdf",
    "plugin": "colornotes.qml"
  },
  {
    "in": "Reunion.mscz",
    "out": [
      "Reunion.pdf",
      [ "Reunion (part for ", ").pdf" ],
      "Reunion.musicxml",
      "Reunion.mid"
    ]
  },
  {
    "in": "Reunion.mscz",
    "out": "Reunion-transposed.mscz",
    "transpose":
	{
	  "mode": "by_interval",
	  "direction": "up",
	  "transposeInterval": 12,
	  "transposeKeySignatures": true
	}
  },
  {
    "in": "Reunion.mscz",
    "out": "Reunion-transposed.pdf",
    "transpose":
	{
	  "mode": "diatonically",
	  "direction": "down",
	  "transposeInterval": 2,
	  "useDoubleSharpsFlats": true
	}
  },
  {
    "in": "Piece with excerpts.mscz",
    "out": [
      "Piece with excerpts (Partitura).pdf",
      [ "Piece with excerpts (part for ", ").pdf" ],
      "Piece with excerpts.mid"
    ]
  }
]

The last part of the job would, for example, cause files like “Piece with excerpts (part for Violin).pdf” to be generated alongside the conductor's partitura and a MIDI file with the full orchestra sound, whereas the equivalent part of the Reunion conversion will be silently ignored (because the Reunion piece (a MuseScore demo) has no excerpts defined).

https://musescore.org/sites/musescore.org/files/midi_import_options_0.xml is a sample MIDI import operations file for the -M option.

DIAGNOSTICS

The mscore utility exits 0 on success, and >0 if an error occurs.

STANDARDS

MuseScore attempts to implement the following standards:

  • MusicXML 4.0 (score interchange format)
  • SF2 (SoundFont 2.01)
  • SF3 (SoundFont with OGG Vorbis-compressed samples)
  • SMuFL (Standard Music Font Layout 1.4)

HISTORY

MuseScore was split off the MusE sequencer in 2002 and has since become the foremost Open Source notation software.

CAVEATS

The automatic Qt command line options are removed from the argument vector before the application has a chance at option processing; this means that an invocation like

mscore -S -reverse

has no chance at working because the -reverse is removed by Qt first.

BUGS

MuseScore does not honour /etc/papersize.
