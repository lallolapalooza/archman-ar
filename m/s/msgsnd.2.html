'permalink' href='#ERRORS'>ERRORS

msgsnd() يمكن أن تفشل مع الأخطاء التالية:

EACCES
لا تملك العملية المتصلة إذن الكتابة على طابور الرسائل، ولا تملك القدرة CAP_IPC_OWNER في مساحة اسم المستخدم التي تحكم مساحة اسم IPC الخاصة بها.
EAGAIN
لا يمكن إرسال الرسالة بسبب حد msg_qbytes للطابور و تم تحديد IPC_NOWAIT في msgflg.
EFAULT
العنوان الذي يشير إليه msgp غير قابل للوصول.
EIDRM
تمت إزالة طابور الرسائل.
EINTR
كانت العملية نائمة بسبب حالة طابور رسائل ممتلئ، وقد تلقت العملية إشارة.
EINVAL
قيمة msqid غير صالحة، أو قيمة mtype غير موجبة، أو قيمة msgsz غير صالحة (أقل من 0 أو أكبر من القيمة النظامية MSGMAX).
ENOMEM
لا يملك النظام ذاكرة كافية لإنشاء نسخة من الرسالة التي يشير إليها msgp.

msgrcv() يمكن أن تفشل مع الأخطاء التالية:

E2BIG
طول نص الرسالة أكبر من msgsz و لم يتم تحديد MSG_NOERROR في msgflg.
EACCES
لا تملك العملية المتصلة إذن القراءة على طابور الرسائل، ولا تملك القدرة CAP_IPC_OWNER في مساحة اسم المستخدم التي تحكم مساحة اسم IPC الخاصة بها.
EFAULT
العنوان الذي يشير إليه msgp غير قابل للوصول.
EIDRM
بينما كانت العملية نائمة لاستقبال رسالة، تم إزالة طابور الرسائل.
EINTR
بينما كانت العملية نائمة لاستقبال رسالة، تلقت العملية إشارة؛ انظر signal(7).
EINVAL
msqid كانت غير صالحة، أو msgsz كانت أقل من 0.
EINVAL (منذ Linux 3.14)
msgflg حدد MSG_COPY، ولكن ليس IPC_NOWAIT.
EINVAL (منذ Linux 3.14)
msgflg حدد كلاً من MSG_COPY و MSG_EXCEPT.
ENOMSG
تم تحديد IPC_NOWAIT في msgflg ولم توجد رسالة من النوع المطلوب على طابور الرسائل.
ENOMSG
تم تحديد IPC_NOWAIT و MSG_COPY في msgflg و يحتوي الطابور على أقل من msgtyp رسالة.
ENOSYS (منذ Linux 3.8)
تم تحديد كلاً من MSG_COPY و IPC_NOWAIT في msgflg، ولم يتم تكوين النواة هذه مع CONFIG_CHECKPOINT_RESTORE.

المعايير

POSIX.1-2024.

العلمان MSG_EXCEPT و MSG_COPY خاصان بـ Linux؛ يمكن الحصول على تعريفهما عن طريق تحديد ماكرو اختبار الميزة _GNU_SOURCE.

التاريخ

POSIX.1-2001, SVr4.

تم تعريف الوسيط msgp على أنه struct msgbuf * في glibc 2.0 و 2.1. وتم تعريفه على أنه void * في glibc 2.2 وما بعدها، كما هو مطلوب بموجب SUSv2 و SUSv3.

ملاحظات

الحدود التالية لموارد طوابير الرسائل تؤثر على استدعاء msgsnd():

MSGMAX
الحد الأقصى لحجم نص الرسالة، بالبايت (القيمة الافتراضية: 8192 بايت). على Linux، يمكن قراءة هذا الحد وتعديله عبر /proc/sys/kernel/msgmax.
MSGMNB
الحد الأقصى لعدد البايتات التي يمكن الاحتفاظ بها في طابور رسائل (القيمة الافتراضية: 16384 بايت). على Linux، يمكن قراءة هذا الحد وتعديله عبر /proc/sys/kernel/msgmnb. يمكن لعملية متميزة (Linux: عملية ذات قدرة CAP_SYS_RESOURCE) زيادة حجم طابور الرسائل بما يتجاوز MSGMNB باستخدام عملية msgctl(2) IPC_SET.

لا يملك التنفيذ حدوداً نظامية جوهرية على عدد رؤوس الرسائل (MSGTQL) وعدد البايتات في مجمع الرسائل (MSGPOOL).

الأخطاء

في Linux 3.13 وما قبله، إذا تم استدعاء msgrcv() بالعلم MSG_COPY، ولكن بدون IPC_NOWAIT، وكان طابور الرسائل يحتوي على أقل من msgtyp رسالة، فإن الاستدعاء كان سيحظر حتى كتابة الرسالة التالية إلى الطابور. عند تلك النقطة، كان الاستدعاء سيعيد نسخة من الرسالة، بغض النظر عما إذا كانت تلك الرسالة في الموضع الترتيبي msgtyp. تم إصلاح هذا الخطأ في Linux 3.14.

تحديد كلاً من MSG_COPY و MSC_EXCEPT في msgflg هو خطأ منطقي (نظرًا لأن هذين العلمين يفرضان تفسيرات مختلفة على msgtyp). في Linux 3.13 وما قبله، لم يتم تشخيص هذا الخطأ بواسطة msgrcv(). تم إصلاح هذا الخطأ في Linux 3.14.

أمثلة

يوضح البرنامج أدناه استخدام msgsnd() و msgrcv().

يتم تشغيل البرنامج المثال أولاً مع الخيار -s لإرسال رسالة، ثم يتم تشغيله مرة أخرى مع الخيار -r لاستقبال رسالة.

توضح جلسة shell التالية تشغيلًا نموذجيًا للبرنامج:


$ ./a.out -s
sent: a message at Wed Mar  4 16:25:45 2015
$ ./a.out -r
message received: a message at Wed Mar  4 16:25:45 2015

مصدر البرنامج

#include <errno.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/ipc.h>
#include <sys/msg.h>
#include <time.h>
#include <unistd.h>
struct msgbuf {
    long mtype;
    char mtext[80];
};
static void
usage(char *prog_name, char *msg)
{
    if (msg != NULL)
        fputs(msg, stderr);
    fprintf(stderr, "Usage: %s [options]\n", prog_name);
    fprintf(stderr, "Options are:\n");
    fprintf(stderr, "-s        send message using msgsnd()\n");
    fprintf(stderr, "-r        read message using msgrcv()\n");
    fprintf(stderr, "-t        message type (default is 1)\n");
    fprintf(stderr, "-k        message queue key (default is 1234)\n");
    exit(EXIT_FAILURE);
}
static void
send_msg(int qid, int msgtype)
{
    time_t         t;
    struct msgbuf  msg;
    msg.mtype = msgtype;
    time(&t);
    snprintf(msg.mtext, sizeof(msg.mtext), "a message at %s",
             ctime(&t));
    if (msgsnd(qid, &msg, sizeof(msg.mtext),
               IPC_NOWAIT) == -1)
    {
        perror("msgsnd error");
        exit(EXIT_FAILURE);
    }
    printf("sent: %s\n", msg.mtext);
}
static void
get_msg(int qid, int msgtype)
{
    struct msgbuf msg;
    if (msgrcv(qid, &msg, sizeof(msg.mtext), msgtype,
               MSG_NOERROR | IPC_NOWAIT) == -1) {
        if (errno != ENOMSG) {
            perror("msgrcv");
            exit(EXIT_FAILURE);
        }
        printf("No message available for msgrcv()\n");
    } else {
        printf("message received: %s\n", msg.mtext);
    }
}
int
main(int argc, char *argv[])
{
    int  qid, opt;
    int  mode = 0;               /* 1 = send, 2 = receive */
    int  msgtype = 1;
    int  msgkey = 1234;
    while ((opt = getopt(argc, argv, "srt:k:")) != -1) {
        switch (opt) {
        case 's':
            mode = 1;
            break;
        case 'r':
            mode = 2;
            break;
        case 't':
            msgtype = atoi(optarg);
            if (msgtype <= 0)
                usage(argv[0], "-t option must be greater than 0\n");
            break;
        case 'k':
            msgkey = atoi(optarg);
            break;
        default:
            usage(argv[0], "Unrecognized option\n");
        }
    }
    if (mode == 0)
        usage(argv[0], "must use either -s or -r option\n");
    qid = msgget(msgkey, IPC_CREAT | 0666);
    if (qid == -1) {
        perror("msgget");
        exit(EXIT_FAILURE);
    }
    if (mode == 2)
        get_msg(qid, msgtype);
    else
        send_msg(qid, msgtype);
    exit(EXIT_SUCCESS);
}

msgsnd(2)

msgsnd - إرسال رسالة إلى طابور رسائل

الاسم

msgsnd - إرسال رسالة إلى طابور رسائل

المكتبة

عملية الرسائل (IPC) - مكتبة C القياسية (libc)

الملخص


                #include <sys/msg.h>

                int msgsnd(int msqid, const void *msgp, size_t msgsz, int msgflg);

الوصف

الدالة msgsnd ترسل النسخة المتوفرة من الرسالة التي تشير إليها msgp إلى طابور الرسائل الذي يعرّفه msqid.

msgsz هو حجم الرسالة بالبايت.

msgflg هو مجموعة من الأعلام التي تتحكم في سلوك الدالة.

  • IPC_NOWAIT: إذا كان الطابور ممتلئًا، فإن الدالة تعود فوراً.
  • IPC_HIGH | IPC_LOW: يستخدمان معاً مع IPC_NOWAIT لتحديد أولوية الرسالة.

قيمة الإرجاع

عند النجاح، تعود msgsnd بالصفر.

عند الفشل، تعود -1 ويتم تعيين متغير errno بشكل مناسب.

الأخطاء

  • EACCES: لا توجد أذونات للكتابة إلى طابور الرسائل.
  • EAGAIN: msgflg تتضمن IPC_NOWAIT والطابور ممتلئ.
  • EINTR: تم اعتراض الاستدعاء بواسطة إشارة.
  • EINVAL: msqid غير صالح، أو msgsz سالبة، أو أن الرسالة في msgp غير صالحة.
  • ENOMEM: ذاكرة النظام غير كافية لتخصيص مساحة الرسالة.
  • ENOSPC: تجاوز حجم طابور الرسائل الحد الأقصى، أو أن عدد الرسائل في الطابور يتجاوز الحد الأقصى، و msgflg لا تتضمن IPC_NOWAIT.
  • ENOSYM: msgsz أكبر من الحد الأقصى المسموح به للرسالة.

المعايير

تتوافق مع POSIX.1-2001.

التاريخ

تم تقديمها في POSIX.1-2001.
