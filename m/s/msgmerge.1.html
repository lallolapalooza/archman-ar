NAME

msgmerge - merge or unmerge fuzzy gettext string translations

SYNOPSIS

msgmerge [OPTION...] msgfile templatefile

msgmerge [OPTION...] msgfile -o msgfile

DESCRIPTION

This manual page describes the msgmerge utility.

The msgmerge utility is used to merge changes from a template file (usually a `.pot` file) into an existing message file (usually a `.po` file), or to merge changes from a message file into a template file.

When merging from a template file into a message file, new `msgid` entries are added to the message file, and `msgstr` entries for obsolete `msgid` entries are removed.

When merging from a message file into a template file, new `msgid` entries are added to the template file, and `msgstr` entries for obsolete `msgid` entries are removed.

The utility can also be used to update a message file based on changes in a previous version of itself.

msgmerge uses the template file to determine which `msgid` entries are new or have changed. It then updates the message file accordingly.

The default behavior is to merge the template file into the message file. If the template file is given as '-' or omitted, then msgmerge merges the previous version of the message file into the current version.

The options can be used to control the merging process, such as whether to keep or discard fuzzy translations, or whether to update obsolete entries.

For more detailed information and examples, you can refer to the full documentation.

The command

info msgmerge

should give you access to the complete manual.

الاسم

msgmerge - دمج أو إلغاء دمج ترجمات سلاسل gettext الضبابية

الملخص

msgmerge [خيار...] ملف_الرسائل ملف_القالب

msgmerge [خيار...] ملف_الرسائل -o ملف_الرسائل

الوصف

تصف صفحة الدليل هذه الأداة المساعدة msgmerge.

تُستخدم الأداة المساعدة msgmerge لدمج التغييرات من ملف قالب (عادةً ملف `.pot`) في ملف رسائل موجود (عادةً ملف `.po`)، أو لدمج التغييرات من ملف رسائل في ملف قالب.

عند الدمج من ملف قالب إلى ملف رسائل، تتم إضافة إدخالات `msgid` جديدة إلى ملف الرسائل، ويتم إزالة إدخالات `msgstr` لإدخالات `msgid` القديمة.

عند الدمج من ملف رسائل إلى ملف قالب، تتم إضافة إدخالات `msgid` جديدة إلى ملف القالب، ويتم إزالة إدخالات `msgstr` لإدخالات `msgid` القديمة.

يمكن استخدام الأداة أيضًا لتحديث ملف رسائل بناءً على التغييرات في نسخة سابقة منه.

تستخدم msgmerge ملف القالب لتحديد إدخالات `msgid` الجديدة أو التي تم تغييرها. ثم تقوم بتحديث ملف الرسائل وفقًا لذلك.

السلوك الافتراضي هو دمج ملف القالب في ملف الرسائل. إذا تم تقديم ملف القالب كـ '-' أو تم حذفه، فإن msgmerge يدمج النسخة السابقة من ملف الرسائل في النسخة الحالية.

يمكن استخدام الخيارات للتحكم في عملية الدمج، مثل ما إذا كان سيتم الاحتفاظ بالترجمات الضبابية أو تجاهلها، أو ما إذا كان سيتم تحديث الإدخالات القديمة.

لمزيد من المعلومات التفصيلية والأمثلة، يمكنك الرجوع إلى الوثائق الكاملة.
