msggrep(1)

الحزمة: gettext

التراخيص: GFDL-1.2-only, GPL-2.0-only, GPL-2.0-or-later, LGPL-2.0-only

MSGGREP(1) أوامر المستخدم MSGGREP(1)

الاسم

msggrep - مطابقة الأنماط على كتالوج الرسائل

الملخص

msggrep [خيار] [ملف_الإدخال]

الوصف

يستخرج جميع الرسائل من كتالوج ترجمة تتطابق مع نمط معين أو تنتمي إلى ملفات مصدر معينة.

الوسائط الإلزامية للخيارات الطويلة إلزامية أيضًا للخيارات القصيرة.

موقع ملف الإدخال:

ملف_الإدخال
ملف PO الإدخال
-D, --directory=الدليل
أضف الدليل إلى قائمة ملفات البحث عن ملفات الإدخال

إذا لم يتم تحديد ملف إدخال أو إذا كان '-'، يتم قراءة الإدخال القياسي.

موقع ملف الإخراج:

-o, --output-file=ملف
اكتب الإخراج إلى الملف المحدد

تتم كتابة النتائج إلى الإخراج القياسي إذا لم يتم تحديد ملف إخراج أو إذا كان '-'.

تحديد الرسالة:

[-N ملف_المصدر]... [-M اسم_النطاق]... [-J نمط_سياق_الرسالة] [-K نمط_معرف_الرسالة] [-T نمط_ترجمة_الرسالة] [-C نمط_تعليق_المترجم] [-X نمط_التعليق_المستخرج] [-W علامة_سير_العمل] [-S علامة_التثبيت]

يتم تحديد الرسالة إذا كانت تأتي من أحد ملفات المصدر المحددة، أو إذا كانت تأتي من أحد النطاقات المحددة، أو إذا تم إعطاء -J وتطابق سياقها (msgctxt) مع نمط_سياق_الرسالة، أو إذا تم إعطاء -K وتطابق مفتاحها (msgid أو msgid_plural) مع نمط_معرف_الرسالة، أو إذا تم إعطاء -T وتطابق ترجمتها (msgstr) مع نمط_ترجمة_الرسالة، أو إذا تم إعطاء -C وتطابق تعليق المترجم مع نمط_تعليق_المترجم، أو إذا تم إعطاء -X وتطابق التعليق المستخرج مع نمط_التعليق_المستخرج، أو إذا تم إعطاء -W وتتضمن علاماتها علامة_سير_العمل، أو إذا تم إعطاء -S وتتضمن علاماتها علامة_التثبيت.

عندما يتم تحديد أكثر من معيار تحديد، فإن مجموعة الرسائل المحددة هي اتحاد الرسائل المحددة لكل معيار.

صيغة نمط_سياق_الرسالة أو نمط_معرف_الرسالة أو نمط_ترجمة_الرسالة أو نمط_تعليق_المترجم أو نمط_التعليق_المستخرج:

[-E | -F] [-e نمط | -f ملف]...

الأنماط هي تعبيرات عادية أساسية بشكل افتراضي، أو تعبيرات عادية ممتدة إذا تم إعطاء -E، أو سلاسل نصية ثابتة إذا تم إعطاء -F.

-N, --location=ملف_المصدر
حدد الرسائل المستخرجة من ملف_المصدر
-M, --domain=اسم_النطاق
حدد الرسائل التي تنتمي إلى اسم_النطاق
-J, --msgctxt
بداية الأنماط لسياق الرسالة (msgctxt)
-K, --msgid
بداية الأنماط لمعرف الرسالة (msgid)
-T, --msgstr
بداية الأنماط لترجمة الرسالة (msgstr)
-C, --comment
بداية الأنماط لتعليق المترجم
-X, --extracted-comment
بداية الأنماط للتعليق المستخرج
-E, --extended-regexp
النمط هو تعبير عادي ممتد
-F, --fixed-strings
النمط هو مجموعة من السلاسل النصية المفصولة بأسطر جديدة
-e, --regexp=نمط
استخدم النمط كتعبير عادي
-f, --file=ملف
احصل على النمط من الملف
-i, --ignore-case
تجاهل فروق حالة الأحرف
-W, --workflow-flag=علامة
حدد الرسائل ذات العلامة
-S, --sticky-flag=علامة
حدد الرسائل ذات العلامة
-v, --invert-match
اخرج فقط الرسائل التي لا تتطابق مع أي معيار تحديد

صيغة ملف الإدخال:

-P, --properties-input
ملف الإدخال بصيغة Java .properties
--stringtable-input
ملف الإدخال بصيغة NeXTstep/GNUstep .strings

تفاصيل الإخراج:

--color
استخدم الألوان وسمات النص الأخرى دائمًا
--color=متى
استخدم الألوان وسمات النص الأخرى إذا كان متى. قد يكون متى 'دائمًا'، 'أبدًا'، 'تلقائي'، أو 'html'.
--style=ملف_الأنماط
حدد ملف قاعدة نمط CSS لـ --color
--no-escape
لا تستخدم تسلسلات C النصية في الإخراج (افتراضي)
--escape
استخدم تسلسلات C النصية في الإخراج، ولا تستخدم أحرفًا ممتدة
--force-po
اكتب ملف PO حتى لو كان فارغًا
--indent
نمط إخراج بمسافات بادئة
--no-location
قم بقمع أسطر '#: اسم_الملف:رقم_السطر'
-n, --add-location
احتفظ بأسطر '#: اسم_الملف:رقم_السطر' (افتراضي)
--strict
نمط إخراج Uniforum صارم
-p, --properties-output
اكتب ملف Java .properties
--stringtable-output
اكتب ملف NeXTstep/GNUstep .strings
-w, --width=رقم
اضبط عرض صفحة الإخراج
--no-wrap
لا تقم بكسر أسطر الرسائل الطويلة، الأطول من عرض صفحة الإخراج، إلى عدة أسطر
--sort-output
إنشاء إخراج مرتب
--sort-by-file
فرز الإخراج حسب موقع الملف

إخراج مفيد:

-h, --help
اعرض هذه المساعدة واخرج
-V, --version
اخرج معلومات الإصدار واخرج

كتبه برونو هايبله.
