msgattrib(1)

الحزمة: gettext

التراخيص: GFDL-1.2-only, GPL-2.0-only, GPL-2.0-or-later, LGPL-2.0-only

MSGATTRIB(1) أوامر المستخدم MSGATTRIB(1)

الاسم

msgattrib - مطابقة التعبيرات والتلاعب بها في كتالوج الرسائل

الملخص

msgattrib [خيار] [ملف_إدخال]

الوصف

يقوم بتصفية رسائل كتالوج الترجمة وفقًا لسماتها، ويتلاعب بالسمات.

الوسائط الإلزامية للخيار الطويل إلزامية أيضًا للخيار القصير.

موقع ملف الإدخال:

ملف_إدخال
ملف PO للإدخال
-D، --directory=دليل
إضافة دليل إلى قائمة البحث عن ملفات الإدخال

إذا لم يتم تقديم ملف إدخال أو إذا كان -، يتم قراءة المدخلات القياسية.

موقع ملف الإخراج:

-o، --output-file=ملف
كتابة الإخراج إلى الملف المحدد

تتم كتابة النتائج إلى الإخراج القياسي إذا لم يتم تحديد ملف إخراج أو إذا كان -.

اختيار الرسائل:

--translated
الاحتفاظ بالرسائل المترجمة، إزالة الرسائل غير المترجمة
--untranslated
الاحتفاظ بالرسائل غير المترجمة، إزالة الرسائل المترجمة
--no-fuzzy
إزالة الرسائل المحددة كـ 'fuzzy' (غامضة)
--only-fuzzy
الاحتفاظ بالرسائل المحددة كـ 'fuzzy' (غامضة)
--no-obsolete
إزالة الرسائل المهملة #~
--only-obsolete
الاحتفاظ بالرسائل المهملة #~

التلاعب بالسمات:

--set-fuzzy
تعيين جميع الرسائل كـ 'fuzzy' (غامضة)
--clear-fuzzy
تعيين جميع الرسائل كـ 'non-fuzzy' (غير غامضة)
--set-obsolete
تعيين جميع الرسائل كمهملة
--clear-obsolete
تعيين جميع الرسائل كغير مهملة
--previous
عند تعيين 'fuzzy'، احتفظ بمعرفات الرسائل السابقة للرسائل المترجمة.
--clear-previous
إزالة "معرف الرسالة السابق" من جميع الرسائل
--empty
عند إزالة 'fuzzy'، قم أيضًا بتعيين msgstr فارغة
--only-file=ملف.po
التلاعب فقط بالإدخالات المدرجة في FILE.po
--ignore-file=ملف.po
التلاعب فقط بالإدخالات غير المدرجة في FILE.po
--fuzzy
مرادف لـ --only-fuzzy --clear-fuzzy
--obsolete
مرادف لـ --only-obsolete --clear-obsolete

صيغة ملف الإدخال:

-P، --properties-input
الملف المدخل بصيغة Java .properties
--stringtable-input
الملف المدخل بصيغة NeXTstep/GNUstep .strings

تفاصيل الإخراج:

--color
استخدم الألوان وسمات النص الأخرى دائمًا
--color=متى
استخدم الألوان وسمات النص الأخرى إذا كانت WHEN. WHEN يمكن أن تكون 'always' (دائما)، 'never' (أبدا)، 'auto' (تلقائي)، أو 'html' (HTML).
--style=ملف_نمط
حدد ملف قواعد CSS للـ --color
-e، --no-escape
لا تستخدم فواصل C في الإخراج (افتراضي)
-E، --escape
استخدم فواصل C في الإخراج، لا أحرف موسعة
--force-po
كتابة ملف PO حتى لو كان فارغًا
-i، --indent
اكتب ملف .po باستخدام صيغة الإزاحة
--no-location
لا تكتب سطور '#: filename:line'
-n، --add-location
إنشاء سطور '#: filename:line' (افتراضي)
--strict
اكتب ملف .po متوافقًا مع Uniforum بدقة
-p، --properties-output
اكتب ملف Java .properties
--stringtable-output
اكتب ملف NeXTstep/GNUstep .strings
-w، --width=عدد
تعيين عرض صفحة الإخراج
--no-wrap
لا تكسر سطور الرسائل الطويلة، الأطول من عرض صفحة الإخراج، إلى أسطر متعددة
-s، --sort-output
إنشاء إخراج مرتب
-F، --sort-by-file
ترتيب الإخراج حسب موقع الملف

إخراج معلوماتي:

-h، --help
عرض هذه المساعدة والخروج
-V، --version
إخراج معلومات الإصدار والخروج

المؤلف

كتبه برونو هايبل.
