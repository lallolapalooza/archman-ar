msgop(2)

msgop(2)

NAME
msgop - operate on message queues
LIBRARY
Realtime extensions (libc, -lrt)
SYNOPSIS
#include <mqueue.h>

ssize_t msgop(int msgid, struct msgbuf *msgp, size_t maxlen, int msgflg);
ssize_t msgsnd(int msqid, const void *msg_ptr, size_t msglen, int msgflg);
ssize_t msgrcv(int msqid, void *msg_ptr, size_t msglen, long type, int msgflg);
int msgctl(int msqid, int cmd, struct msqid_ds *buf);
int msgget(key_t key, int msgflg);
int msgremove(int msqid);
int msgrmid(int msqid);
DESCRIPTION
The functions described in this page are used to access System V message queues. These functions are part of the POSIX real-time extensions and are provided by glibc. They are functionally equivalent to the System V IPC message queue functions described in mq_overview(7).
RETURN VALUE
On success, msgop returns the number of bytes copied into the message buffer. msgsnd returns 0 on success. msgrcv returns the number of bytes in the received message on success. msgget returns the message queue identifier on success. msgctl, msgremove, and msgrmid return 0 on success. On error, all functions return -1, and errno is set to indicate the error.
ERRORS
These functions can fail for the following reasons:
  • EACCES: Permission denied for the requested operation.
  • EEXIST: The queue already exists, and IPC_CREAT was specified.
  • EINTR: The operation was interrupted by a signal.
  • EINVAL: Invalid argument provided.
  • ENOMSG: No message of the requested type found.
  • ENOSPC: The system limit for the number of messages or message size has been reached.
  • ENOENT: The queue does not exist.
  • EPERM: Operation not permitted.
STANDARDS
POSIX.1-2001, POSIX.1-2008.
HISTORY
These functions were introduced in POSIX.1-2001.
NOTES
The System V IPC message queue functions are older and have some differences from the POSIX message queue functions. It is generally recommended to use the POSIX functions (mq_open(3), mq_send(3), etc.) when possible, as they offer better control and portability.
BUGS
None known.
EXAMPLES
The following example demonstrates the usage of msgget, msgsnd, and msgrcv. 
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/ipc.h>
#include <sys/msg.h>

struct msgbuf {
    long mtype;
    char mtext[256];
};

int main() {
    int msgid;
    struct msgbuf msg;
    key_t key = 1234;

    // Create or open a message queue
    msgid = msgget(key, IPC_CREAT | 0666);
    if (msgid == -1) {
        perror("msgget");
        exit(1);
    }

    // Send a message
    msg.mtype = 1;
    strcpy(msg.mtext, "Hello, message queue!");
    if (msgsnd(msgid, &msg, sizeof(msg.mtext), 0) == -1) {
        perror("msgsnd");
        exit(1);
    }

    printf("Message sent.\n");

    // Receive a message
    if (msgrcv(msgid, &msg, sizeof(msg.mtext), 1, 0) == -1) {
        perror("msgrcv");
        exit(1);
    }

    printf("Received message: %s\n", msg.mtext);

    // Remove the message queue
    if (msgctl(msgid, IPC_RMID, NULL) == -1) {
        perror("msgctl");
        exit(1);
    }

    printf("Message queue removed.\n");

    return 0;
}
