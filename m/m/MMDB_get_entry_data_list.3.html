أعداد صحيحة 128 بت

يعتمد التعامل مع بيانات uint128 على كيفية دعم منصتك للأعداد الصحيحة ذات 128 بت، وما إذا كانت تدعمها أم لا. مع GCC 4.4 و 4.5، يمكننا كتابة unsigned int __attribute__ ((__mode__ (TI))). مع إصدارات أحدث من GCC (4.6+) و clang (3.2+)، يمكننا ببساطة كتابة "unsigned __int128".

للتحايل على هذه الاختلافات، تحدد هذه المكتبة النوع mmdb_uint128_t. يتم تعريف هذا النوع في ملف maxminddb.h حتى تتمكن من استخدامه في الكود الخاص بك.

مع المترجمات الأقدم، لا يمكننا استخدام عدد صحيح، لذا نستخدم مصفوفة مكونة من 16 بايت من uint8_t. هذه هي البيانات الخام للقاعدة.

توفر هذه المكتبة ماكرو عام MMDB_UINT128_IS_BYTE_ARRAY. إذا كان هذا صحيحًا (1)، فسيتم إرجاع قيم uint128 كمصفوفة بايت، وإذا كان خاطئًا، فسيتم إرجاعها كعدد صحيح mmdb_uint128_t.

الماكروات لأنواع البيانات

توفر هذه المكتبة ماكرو لكل نوع بيانات معرف حسب مواصفات MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

هناك أيضًا بعض الأنواع التي تستخدم داخليًا فقط:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

إذا رأيت أحد هذه في البيانات المرجعة، فهذا يعني أن شيئًا ما حدث بشكل خاطئ للغاية. القاعدة تالفة أو تم إنشاؤها بشكل غير صحيح أو هناك خطأ في كود libmaxminddb.

قيم المؤشر و MMDB_close()

تعتبر الأعضاء utf8_string و bytes و (ربما) uint128 في هذا الهيكل كلها مؤشرات مباشرة إلى قسم بيانات القاعدة. قد يكون هذا كتلة calloc أو كتلة mmap من الذاكرة. في كلتا الحالتين، ستصبح هذه المؤشرات غير صالحة بعد استدعاء MMDB_close().

إذا كنت بحاجة إلى الإشارة إلى هذه البيانات بعد ذلك، فقم بنسخ البيانات باستخدام وظيفة مناسبة (strdup، memcpy، إلخ).

MMDB_entry_data_list_s

يغلف هذا الهيكل قائمة مرتبطة بهياكل MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

يتيح لك هذا الهيكل رؤية بيانات الخريطة أو المصفوفة بأكملها عند المرور على القائمة المرتبطة.

MMDB_search_node_s

يغلف هذا الهيكل سجلين لعقدة بحث. هذا مفيد حقًا إذا كنت ترغب في كتابة كود يتكرر عبر شجرة البحث بأكملها بدلاً من البحث عن IP محدد.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

سيكون لنوعي السجلات قيمتان من القيم التالية:

  • MMDB_RECORD_TYPE_SEARCH_NODE - يشير السجل إلى عقدة البحث التالية.
  • MMDB_RECORD_TYPE_EMPTY - السجل هو عنصر نائب يشير إلى عدم وجود بيانات لـ IP. يجب أن ينتهي البحث هنا.
  • MMDB_RECORD_TYPE_DATA - يحتوي السجل على بيانات في قسم بيانات القاعدة. استخدم السجل عند البحث عن بيانات السجل.
  • MMDB_RECORD_TYPE_INVALID - السجل غير صالح. قد يكون هذا بسبب البحث عن عقدة غير صالحة أو قاعدة بيانات تالفة.

يكون سجل MMDB_entry_s صالحًا فقط إذا كان النوع MMDB_RECORD_TYPE_DATA. سيؤدي استخدام سجل لأنواع السجلات الأخرى إلى حدوث خطأ أو بيانات غير صالحة.

رموز الحالة

تُرجع هذه المكتبة (أو تملأ) رموز الحالة للعديد من الوظائف. رموز الحالة هذه هي:

  • MMDB_SUCCESS - نجحت كل شيء
  • MMDB_FILE_OPEN_ERROR - حدث خطأ أثناء فتح ملف MaxMind DB.
  • MMDB_IO_ERROR - فشلت عملية إدخال/إخراج. تحقق من errno لمزيد من التفاصيل.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - عند البحث عن IP في شجرة البحث، تم الحصول على نتيجة مستحيلة. القاعدة تالفة أو تم إنشاؤها بشكل غير صحيح أو هناك خطأ في كود libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - شيء ما في القاعدة غير صحيح. وهذا يشمل مفاتيح البيانات الوصفية المفقودة أو القيم المستحيلة (مثل ip_version يساوي 7).
  • MMDB_OUT_OF_MEMORY_ERROR - فشل استدعاء الذاكرة (malloc، إلخ).
  • MMDB_INVALID_DATA_ERROR - يحتوي حقل في قسم البيانات على بيانات غير صالحة. على سبيل المثال، يدعي حقل uint16 أنه أطول من 2 بايت. القاعدة على الأرجح تالفة أو تم إنشاؤها بشكل غير صحيح.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - يحتوي مسار البحث الذي تم تمريره إلى MMDB_get_value أو MMDB_vget_value أو MMDB_aget_value على إزاحة مصفوفة أكبر من LONG_MAX أو أصغر من LONG_MIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - مسار البحث الذي تم تمريره إلى MMDB_get_value أو MMDB_vget_value أو MMDB_aget_value لا يتطابق مع هيكل بيانات الإدخال. هناك عدة أسباب لحدوث ذلك. قد يتضمن مسار البحث مفتاحًا غير موجود في خريطة. قد يتضمن مسار البحث فهرس مصفوفة أكبر من مصفوفة أو أصغر من الحد الأدنى لإزاحة نهاية المصفوفة. قد يحدث أيضًا عندما يتوقع المسار العثور على خريطة أو مصفوفة حيث لا يوجد شيء.

يجب التعامل مع جميع رموز الحالة كقيم int.

MMDB_strerror()

const char *MMDB_strerror(int error_code)

تأخذ هذه الوظيفة رمز حالة وتعيد سلسلة باللغة الإنجليزية تشرح الحالة.

الوظائف

توفر هذه المكتبة الوظائف المصدرة التالية:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

تفتح هذه الوظيفة مرجعًا لملف MaxMind DB. قيمة الإرجاع هي رمز حالة كما هو محدد أعلاه. تحقق دائمًا من قيمة الإرجاع لهذا الاستدعاء.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

filename يجب أن يكون مشفرًا كـ UTF-8 على Windows.

الهيكل MMDB_s الذي تمرره يمكن أن يكون على المكدس أو مخصصًا في ذاكرة الكومة. ومع ذلك، إذا كان الفتح ناجحًا، فسيحتوي على بيانات مخصصة في ذاكرة الكومة، لذا تحتاج إلى إغلاقه باستخدام MMDB_close(). إذا لم يكن الحالة المرجعة MMDB_SUCCESS، تضمن هذه المكتبة تحرير أي ذاكرة تم تخصيصها قبل الإرجاع.

الأعلام المقدمة حاليًا هي:

•
MMDB_MODE_MMAP - يفتح الملف باستخدام mmap().

قد يؤدي تمرير قيم أخرى للأعلام إلى نتائج غير متوقعة. في المستقبل، قد نضيف أعلامًا أخرى يمكنك ربطها بالوضع، بالإضافة إلى الأوضاع الأخرى.

يمكنك أيضًا تمرير 0 كقيمة للأعلام، وفي هذه الحالة سيتم فتح الملف باستخدام الأعلام الافتراضية. ومع ذلك، قد تتغير هذه القيم الافتراضية في التحديثات المستقبلية. القيمة الافتراضية الحالية هي MMDB_MODE_MMAP.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

تقوم هذه المكتبة بتحرير أي ذاكرة تم تخصيصها أو mapping باستخدام mmap موجودة في هيكل MMDB_s. *لا تقوم بتحرير الذاكرة*

MMDB_get_entry_data_list(3)

الحزمة: libmaxminddb

التراخيص: Apache-2.0

الاسم

MMDB_get_entry_data_list, MMDB_get_entry_data - الحصول على بيانات إدخال قاعدة بيانات MaxMind DB

الملخص

struct MMDB_entry_data_list_s *MMDB_get_entry_data_list(
    MMDB_lookup_result_s *result,
    int *const status);
void MMDB_free_entry_data_list(
    struct MMDB_entry_data_list_s *entry_data_list);
void MMDB_dump_entry_data_list(
    FILE *const file,
    struct MMDB_entry_data_list_s *entry_data_list,
    int spaces);

الوصف

The MMDB_get_entry_data_list() function retrieves the data for a found entry, returning it as a list of MMDB_entry_data_s structures. This is useful for retrieving data that might not be a simple scalar type (e.g. maps, arrays).

The MMDB_lookup_result_s structure is returned from MMDB_lookup_string() and MMDB_lookup_sockaddr().

If the entry was found, the function returns a pointer to a MMDB_entry_data_list_s structure. If the entry was not found, or if an error occurred during lookup, the function returns NULL.

The MMDB_free_entry_data_list() function frees the memory allocated for the MMDB_entry_data_list_s structure and its contents.

The MMDB_dump_entry_data_list() function prints the contents of the MMDB_entry_data_list_s structure to the given file pointer. The spaces argument specifies the number of spaces to use for indentation.

The return value of MMDB_get_entry_data_list() is a status code. If the entry was found and data was retrieved successfully, the status code will be MMDB_SUCCESS. Otherwise, it will be one of the error codes defined in this document.

هياكل البيانات

MMDB_entry_data_list_s: This structure represents a list of entry data. It contains a pointer to the first MMDB_entry_data_s structure and a pointer to the next MMDB_entry_data_list_s structure, forming a linked list.

MMDB_entry_data_s: This structure represents a single entry data. It contains the type of the data, the number of values, and a pointer to the actual data. The data is stored as a union, allowing it to hold different data types (integer, string, double, boolean, etc.).

رموز الحالة

The following status codes are returned by MMDB_get_entry_data_list():

MMDB_SUCCESS
The operation was successful.
MMDB_MMDB_ERROR
An error occurred while reading the database.
MMDB_INVALID_DATA_ERROR
The database contains invalid data.
MMDB_OUT_OF_MEMORY_ERROR
Not enough memory available.

الوظائف

MMDB_get_entry_data_list()

struct MMDB_entry_data_list_s *MMDB_get_entry_data_list(
    MMDB_lookup_result_s *result,
    int *const status);

Retrieves the data for a found entry as a list of MMDB_entry_data_s structures. The status argument will be set to a status code indicating the success or failure of the operation.

The return value is a pointer to a MMDB_entry_data_list_s structure, or NULL if the entry was not found or an error occurred.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(
    struct MMDB_entry_data_list_s *entry_data_list);

Frees the memory allocated for the MMDB_entry_data_list_s structure and its contents.

MMDB_dump_entry_data_list()

void MMDB_dump_entry_data_list(
    FILE *const file,
    struct MMDB_entry_data_list_s *entry_data_list,
    int spaces);

Prints the contents of the MMDB_entry_data_list_s structure to the given file pointer. The spaces argument specifies the number of spaces to use for indentation.

Note: The formatting produced by this function is intended for debugging and display purposes and may change in future releases. Do not rely on the specific formatting.

The return value of the function is a status code as defined above.

MMDB_read_node()

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

This reads a specific node in the search tree. The third argument is a reference to an MMDB_search_node_s structure that will be populated by this function.

The return value is a status code. If you pass a node_number that is greater than the number of nodes in the database, this function will return MMDB_INVALID_NODE_NUMBER_ERROR, otherwise it will return MMDB_SUCCESS.

The first node in the search tree is always node 0. If you wanted to iterate over the whole search tree, you would start by reading node 0 and then following the the records that make up this node, based on the type of each record. If the type is MMDB_RECORD_TYPE_SEARCH_NODE then the record contains an integer for the next node to look up.

MMDB_lib_version()

const char *MMDB_lib_version(void)

This function returns the library version as a string, something like "2.0.0".

مثال

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
