lated you should look at the type member. The pointer member of the union should never be populated in any data returned by the API. Pointers should always be resolved internally.

The data_size member is only relevant for utf8_string and bytes data. utf8_string is not null terminated and data_size must be used to determine its length.

The type member can be compared to one of the MMDB_DATA_TYPE_* macros.

الأعداد الصحيحة 128 بت

يعتمد التعامل مع بيانات uint128 على كيفية دعم منصتك للأعداد الصحيحة 128 بت، إذا كانت تدعمها على الإطلاق. مع GCC 4.4 و 4.5 يمكننا كتابة unsigned int __attribute__ ((__mode__ (TI))). مع الإصدارات الأحدث من GCC (4.6+) و clang (3.2+) يمكننا ببساطة كتابة "unsigned __int128".

لتجاوز هذه الاختلافات، تحدد هذه المكتبة نوع mmdb_uint128_t. يتم تعريف هذا النوع في رأس maxminddb.h حتى تتمكن من استخدامه في التعليمات البرمجية الخاصة بك.

مع المترجمات القديمة، لا يمكننا استخدام عدد صحيح وبدلاً من ذلك نستخدم مصفوفة من 16 بايت من قيم uint8_t. هذه هي البيانات الأولية من قاعدة البيانات.

توفر هذه المكتبة ماكرو عام MMDB_UINT128_IS_BYTE_ARRAY. إذا كان هذا صحيحًا (1)، فسيتم إرجاع قيم uint128 كمصفوفة بايت، وإذا كان خاطئًا فسيتم إرجاعها كعدد صحيح mmdb_uint128_t.

قيم المؤشرات و MMDB_close()

utf8_string و bytes و (ربما) uint128 في هذا الهيكل هي مؤشرات مباشرة إلى قسم بيانات قاعدة البيانات. يمكن أن يكون هذا كتلة ذاكرة مخصصة بواسطة calloc أو mmap. في كلتا الحالتين، ستصبح هذه المؤشرات غير صالحة بعد استدعاء MMDB_close().

إذا كنت بحاجة إلى الإشارة إلى هذه البيانات بعد ذلك الوقت، فيجب عليك نسخ البيانات باستخدام دالة مناسبة (مثل strdup أو memcpy، إلخ).

MMDB_entry_data_list_s

يلخص هذا الهيكل قائمة مرتبطة من هياكل MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

يتيح لك هذا الهيكل فحص بيانات خريطة أو مصفوفة كاملة عن طريق التكرار على القائمة المرتبطة.

MMDB_search_node_s

يلخص هذا الهيكل السجلين في عقدة بحث. هذا مفيد فقط إذا كنت ترغب في كتابة تعليمات برمجية تتكرر على شجرة البحث بأكملها بدلاً من البحث عن عنوان IP معين.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

ستأخذ أنواع السجلات هذين أحد القيم التالية:

  • MMDB_RECORD_TYPE_SEARCH_NODE - يشير السجل إلى عقدة البحث التالية.
  • MMDB_RECORD_TYPE_EMPTY - السجل هو عنصر نائب يشير إلى عدم وجود بيانات لعنوان IP. يجب أن ينتهي البحث هنا.
  • MMDB_RECORD_TYPE_DATA - السجل مخصص للبيانات في قسم بيانات قاعدة البيانات. استخدم الإدخال للسجل عند البحث عن بيانات السجل.
  • MMDB_RECORD_TYPE_INVALID - السجل غير صالح. إما تم البحث عن عقدة غير صالحة أو قاعدة البيانات تالفة.

يكون MMDB_entry_s للسجل صالحًا فقط إذا كان النوع MMDB_RECORD_TYPE_DATA. سيؤدي محاولة استخدام إدخال لأنواع سجلات أخرى إلى خطأ أو بيانات غير صالحة.

رموز الحالة

تقوم هذه المكتبة بإرجاع (أو ملء) رموز الحالة للعديد من الوظائف. رموز الحالة هذه هي:

  • MMDB_SUCCESS - كل شيء نجح
  • MMDB_FILE_OPEN_ERROR - كان هناك خطأ أثناء محاولة فتح ملف MaxMind DB.
  • MMDB_IO_ERROR - فشلت عملية إدخال/إخراج. تحقق من errno لمزيد من التفاصيل.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - البحث عن عنوان IP في شجرة البحث أعطانا نتيجة مستحيلة. قاعدة البيانات تالفة أو تم إنشاؤها بشكل غير صحيح أو يوجد خطأ في كود libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - هناك خطأ في بيانات التعريف الخاصة بقاعدة البيانات. ويشمل ذلك مفاتيح البيانات الوصفية المفقودة وكذلك القيم المستحيلة (مثل ip_version بقيمة 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - تشير بيانات التعريف الخاصة بقاعدة البيانات إلى أن إصدارها الرئيسي ليس 2. هذه المكتبة يمكنها فقط التعامل مع الإصدار الرئيسي 2.
  • MMDB_OUT_OF_MEMORY_ERROR - فشل استدعاء تخصيص الذاكرة ( malloc، إلخ).
  • MMDB_INVALID_DATA_ERROR - يحتوي إدخال في قسم البيانات على بيانات غير صالحة. على سبيل المثال، يدعي حقل uint16 أنه أطول من بايتين. قاعدة البيانات على الأرجح تالفة أو تم إنشاؤها بشكل غير صحيح.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - يحتوي المسار الذي تم تمريره إلى MMDB_get_value أو MMDB_vget_value أو MMDB_aget_value على فهرس مصفوفة أكبر من LONGMAX أو أصغر من LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - المسار الذي تم تمريره إلى MMDB_get_value أو MMDB_vget_value أو MMDB_aget_value لا يتطابق مع بنية بيانات الإدخال. هناك عدد من الأسباب التي يمكن أن يحدث بها هذا. يمكن أن يتضمن مسار البحث مفتاحًا غير موجود في خريطة. يمكن أن يتضمن مسار البحث فهرس مصفوفة أكبر من مصفوفة أو أصغر من الحد الأدنى للإزاحة من نهاية مصفوفة. يمكن أن يحدث أيضًا عندما يتوقع المسار العثور على خريطة أو مصفوفة حيث لا توجد.

يجب معاملة جميع رموز الحالة كقيم int.

MMDB_open()

MMDB_s *MMDB_open(
    const char *filename,
    uint32_t flags,
    int *const mmdb_error);

This function opens a MaxMind DB file and returns a pointer to an MMDB_s structure. The structure should be passed to all other functions in this library. You are responsible for freeing this structure when you are done with it by calling MMDB_close().

The flags parameter can be used to control how the database is opened. It can be one or more of the following values:

MMDB_MODE_MMAP
Memory-map the database file. This is the fastest method, but it requires the database file to be accessible via the filesystem.
MMDB_MODE_FILE
Read the database file from disk. This is slower than memory-mapping but might be useful on systems where memory-mapping is not available or desirable.
MMDB_MODE_STDIO
Read the database file using standard I/O functions. This is the slowest method.

If you do not specify a flag, MMDB_MODE_MMAP will be used if available, otherwise MMDB_MODE_FILE. Note that MMDB_MODE_STDIO is not a fallback; it must be explicitly requested.

The mmdb_error parameter is a pointer to an integer that will receive an error code if the function fails. If the function succeeds, the value pointed to by mmdb_error will be MMDB_SUCCESS.

The following error codes can be returned:

MMDB_SUCCESS
No error occurred.
MMDB_FILE_NOT_FOUND_ERROR
The specified database file could not be found.
MMDB_INVALID_FILE_ERROR
The database file is not a valid MaxMind DB file or is corrupted.
MMDB_IO_ERROR
An error occurred while reading the database file.
MMDB_OUT_OF_MEMORY_ERROR
Not enough memory was available to open the database.
int error;
MMDB_s *mmdb = MMDB_open("db.mmdb", MMDB_MODE_MMAP, &error);
if (MMDB_SUCCESS != error) {
    // handle error
    exit(1);
}
// Use mmdb ...
MMDB_close(mmdb);

MMDB_close()

void MMDB_close(MMDB_s *mmdb);

This function closes a MaxMind DB file and frees the associated MMDB_s structure. If the structure was allocated from the heap by MMDB_open(), it will be freed here.

MMDB_close(mmdb);

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *const ipstr,
    int *const gai_error,
    int *const mmdb_error);

This function looks up an IP address that is passed in as a null-terminated string. Internally it calls getaddrinfo() to resolve the address into a binary form. It then calls MMDB_lookup_sockaddr() to look the address up in the database. If you have already resolved an address you can call MMDB_lookup_sockaddr() directly, rather than resolving the address twice.

int gai_error, mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_string(&mmdb, "1.2.3.4", &gai_error, &mmdb_error);
if (0 != gai_error) { ... }
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

This function always returns an MMDB_lookup_result_s structure, but you should also check the gai_error and mmdb_error parameters. If either of these indicates an error then the returned structure is meaningless.

If no error occurred you still need to make sure that the found_entry member in the returned result is true. If it's not, this means that the IP address does not have an entry in the database.

This function will work with IPv4 addresses even when the database contains data for both IPv4 and IPv6 addresses. The IPv4 address will be looked up as '::xxx.xxx.xxx.xxx' rather than being remapped to the ::ffff:xxx.xxx.xxx.xxx block allocated for IPv4-mapped IPv6 addresses.

If you pass an IPv6 address to a database with only IPv4 data then the found_entry member will be false, but the mmdb_error status will still be MMDB_SUCCESS.

MMDB_lookup_sockaddr()

MMDB_lookup_result_s MMDB_lookup_sockaddr(
    MMDB_s *const mmdb,
    const struct sockaddr *const sockaddr,
    int *const mmdb_error);

This function looks up an IP address that has already been resolved by getaddrinfo().

Other than not calling getaddrinfo() itself, this function is identical to the MMDB_lookup_string() function.

int mmdb_error;
MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
if (MMDB_SUCCESS != mmdb_error) { ... }
if (result.found_entry) { ... }

Data Lookup Functions

There are three functions for looking up data associated with an IP address.

int MMDB_get_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    ...);
int MMDB_vget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    va_list va_path);
int MMDB_aget_value(
    MMDB_entry_s *const start,
    MMDB_entry_data_s *const entry_data,
    const char *const *const path);

The three functions allow three slightly different calling styles, but they all do the same thing.

The first parameter is an MMDB_entry_s value. In most cases this will come from the MMDB_lookup_result_s value returned by MMDB_lookup_string() or MMDB_lookup_sockaddr().

The second parameter is a reference to an MMDB_entry_data_s structure. This will be populated with the data that is being looked up, if any is found. If nothing is found, then the has_data member of this structure will be false. If has_data is true then you can look at the data_type member.

The final parameter is a lookup path. The path consists of a set of strings representing either map keys (e.g, "city") or array indexes (e.g., "0", "1", "-1") to use in the lookup.

Negative array indexes will be treated as an offset from the end of the array. For instance, "-1" refers to the last element of the array.

The lookup path allows you to navigate a complex data structure. For example, given this data:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

We could look up the English name with this code:

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_s entry_data;
int status =
    MMDB_get_value(&result.entry, &entry_data,
                   "names", "en", NULL);
if (MMDB_SUCCESS != status) { ... }
if (entry_data.has_data) { ... }

If we wanted to find the first city the lookup path would be "cities", "0". If you don't provide a lookup path at all, you'll get the entry which corresponds to the top level map. The lookup path must always end with NULL, regardless of which function you call.

The MMDB_get_value function takes a variable number of arguments. All of the arguments after the MMDB_entry_data_s * structure pointer are the lookup path. The last argument must be NULL.

The MMDB_vget_value function accepts a va_list as the lookup path. The last element retrieved by va_arg() must be NULL.

Finally, the MMDB_aget_value accepts an array of strings as the lookup path. The last member of this array must be NULL.

If you want to get all of the entry data at once you can call MMDB_get_entry_data_list() instead.

For each of the three functions, the return value is a status code as defined above.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    MMDB_entry_s *start,
    MMDB_entry_data_list_s **const entry_data_list);

This function allows you to get all of the data for a complex data structure at once, rather than looking up each piece using repeated calls to MMDB_get_value().

MMDB_lookup_result_s result =
    MMDB_lookup_sockaddr(&mmdb, address->ai_addr, &mmdb_error);
MMDB_entry_data_list_s *entry_data_list, *first;
int status =
    MMDB_get_entry_data_list(&result.entry, &entry_data_list);
if (MMDB_SUCCESS != status) { ... }
// save this so we can free this data later
first = entry_data_list;
while (1) {
    MMDB_entry_data_list_s *next = entry_data_list = entry_data_list->next;
    if (NULL == next) {
        break;
    }
    switch (next->entry_data.type) {
        case MMDB_DATA_TYPE_MAP: { ... }
        case MMDB_DATA_TYPE_UTF8_STRING: { ... }
        ...
    }
}
MMDB_free_entry_data_list(first);

It's up to you to interpret the entry_data_list data structure. The list is linked in a depth-first traversal. Let's use this structure as an example:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

The list will consist of the following items:

1.
MAP - top level map
2.
UTF8_STRING - "names" key
3.
MAP - map for "names" key
4.
UTF8_STRING - "en" key
5.
UTF8_STRING - value for "en" key
6.
UTF8_STRING - "de" key
7.
UTF8_STRING - value for "de" key
8.
UTF8_STRING - "cities" key
9.
ARRAY - value for "cities" key
10.
UTF8_STRING - array[0]
11.
UTF8_STRING - array[1]

The return value of the function is a status code as defined above.

The MMDB_get_entry_data_list() and MMDB_get_metadata_as_entry_data_list() functions will allocate the linked list structure from the heap. Call this function to free the MMDB_entry_data_list_s structure.

MMDB_get_metadata_as_entry_data_list()

int MMDB_get_metadata_as_entry_data_list(

This function allows you to retrieve the database metadata as a linked list of MMDB_entry_data_list_s structures. This can be a more convenient way to deal with the metadata than using the metadata structure directly.

int MMDB_dump_entry_data_list(
    FILE *const stream,

This function takes a linked list of MMDB_entry_data_list_s structures and stringifies it to the given stream. The indent parameter is the starting indent level for the generated output. It is incremented for nested data structures (maps, array, etc.).

الوصف

تستخدم هذه الدوال لفتح وإغلاق قاعدة بيانات MaxMind DB (بصيغة MMDB) وقراءة العقد منها، والحصول على رقم إصدار المكتبة.

MMDB_open(): تفتح ملف قاعدة بيانات MaxMind DB المحدد بواسطة filename. يعتمد سلوك فتح الملف على قيمة mode. يمكن أن تكون MMDB_MODE_MMAP (للاستخدام الأمثل للذاكرة) أو MMDB_MODE_FILE (لقراءة الملف بالكامل في الذاكرة). يتم إرجاع مقبض لقاعدة البيانات المفتوحة في mmdb. إذا نجحت العملية، يتم إرجاع MMDB_SUCCESS، وإلا يتم إرجاع رمز خطأ.

MMDB_close(): تغلق قاعدة بيانات MaxMind DB التي تم فتحها مسبقًا بواسطة MMDB_open() وتحرر الموارد المرتبطة بها.

MMDB_strerror(): ترجع وصفًا نصيًا لرمز حالة تم إرجاعه بواسطة دوال المكتبة الأخرى. هذا مفيد لتصحيح الأخطاء.

MMDB_read_node(): تقرأ عقدة محددة في شجرة البحث. يتم تمرير رقم العقدة المطلوب قراءتها كرقم صحيح غير موقع uint32_t. يتم تخزين بيانات العقدة المقروءة في بنية MMDB_search_node_s التي يتم تمريرها كمرجع. إذا كان رقم العقدة أكبر من عدد العقد الموجودة في قاعدة البيانات، فسترجع الدالة MMDB_INVALID_NODE_NUMBER_ERROR. العقدة الأولى في شجرة البحث هي دائمًا العقدة رقم 0.

MMDB_lib_version(): ترجع رقم إصدار المكتبة كسلسلة نصية، على سبيل المثال "2.0.0".

هياكل البيانات

MMDB_s
يمثل قاعدة بيانات MaxMind DB مفتوحة. يتم تمرير مؤشر إلى هذا الهيكل بين دوال المكتبة.
MMDB_search_node_s
يستخدم لتخزين بيانات عقدة البحث. سيتم تعيينه بواسطة MMDB_read_node(). يحتوي على معلومات حول المفاتيح والقيم الموجودة في العقدة.

رموز الحالة

ترجع دوال المكتبة رموز حالة تشير إلى نجاح العملية أو فشلها. بعض رموز الحالة الشائعة هي:

MMDB_SUCCESS
تمت العملية بنجاح.
MMDB_FILE_NOT_FOUND_ERROR
لم يتم العثور على ملف قاعدة البيانات.
MMDB_INVALID_FILE_ERROR
الملف المحدد ليس بصيغة MaxMind DB صالحة.
MMDB_IO_ERROR
حدث خطأ أثناء قراءة الملف.
MMDB_INVALID_NODE_NUMBER_ERROR
رقم العقدة غير صالح.
MMDB_OUT_OF_MEMORY_ERROR
نفاد الذاكرة.

هذه القائمة ليست شاملة. راجع توثيق المكتبة للحصول على قائمة كاملة.

الدوال

MMDB_open():

int MMDB_open(
    const char *filename,
    MMDB_mode_e mode,
    MMDB_s *mmdb);

تفتح ملف قاعدة بيانات MaxMind DB.

filename
اسم الملف الخاص بقاعدة بيانات MMDB.
mode
وضع الفتح: MMDB_MODE_MMAP أو MMDB_MODE_FILE.
mmdb
مؤشر إلى بنية MMDB_s سيتم تعبئتها.

القيمة المرجعة هي رمز حالة.

MMDB_close():

void MMDB_close(MMDB_s *mmdb);

تغلق قاعدة بيانات MMDB.

MMDB_strerror():

const char *MMDB_strerror(int status);

ترجع وصفًا نصيًا لرمز حالة.

MMDB_read_node():

int MMDB_read_node(
    MMDB_s *const mmdb,
    uint32_t node_number,
    MMDB_search_node_s *const node);

تقرأ عقدة بحث محددة. الوسيط الثالث هو مرجع إلى بنية MMDB_search_node_s التي سيتم تعبئتها بواسطة هذه الدالة.

القيمة المرجعة هي رمز حالة. إذا قمت بتمرير node_number أكبر من عدد العقد في قاعدة البيانات، فسترجع هذه الدالة MMDB_INVALID_NODE_NUMBER_ERROR، وإلا فسترجع MMDB_SUCCESS.

العقدة الأولى في شجرة البحث هي دائمًا العقدة 0. إذا كنت ترغب في التكرار فوق شجرة البحث بأكملها، فستبدأ بقراءة العقدة 0 ثم تتبع السجلات التي تشكل هذه العقدة، بناءً على نوع كل سجل. إذا كان النوع هو MMDB_RECORD_TYPE_SEARCH_NODE، فإن السجل يحتوي على عدد صحيح للعقدة التالية التي يجب البحث عنها.

MMDB_lib_version():

const char *MMDB_lib_version(void)

ترجع هذه الدالة إصدار المكتبة كسلسلة نصية، شيء مثل "2.0.0".

مثال

#include <errno.h>
#include <maxminddb.h>
#include <stdlib.h>
#include <string.h>
int main(int argc, char **argv)
{
    char *filename = argv[1];
    char *ip_address = argv[2];
    MMDB_s mmdb;
    int status = MMDB_open(filename, MMDB_MODE_MMAP, &mmdb);
    if (MMDB_SUCCESS != status) {
        fprintf(stderr, "\n  Can't open %s - %s\n",
                filename, MMDB_strerror(status));
        if (MMDB_IO_ERROR == status) {
            fprintf(stderr, "    IO error: %s\n", strerror(errno));
        }
        exit(1);
    }
    int gai_error, mmdb_error;
    MMDB_lookup_result_s result =
        MMDB_lookup_string(&mmdb, ip_address, &gai_error, &mmdb_error);
    if (0 != gai_error) {
        fprintf(stderr,
                "\n  Error from getaddrinfo for %s - %s\n\n",
                ip_address, gai_strerror(gai_error));
        exit(2);
    }
    if (MMDB_SUCCESS != mmdb_error) {
        fprintf(stderr,
                "\n  Got an error from libmaxminddb: %s\n\n",
                MMDB_strerror(mmdb_error));
        exit(3);
    }
    MMDB_entry_data_list_s *entry_data_list = NULL;
    int exit_code = 0;
    if (result.found_entry) {
        int status = MMDB_get_entry_data_list(&result.entry,
                                              &entry_data_list);
        if (MMDB_SUCCESS != status) {
            fprintf(
                stderr,
                "Got an error looking up the entry data - %s\n",
                MMDB_strerror(status));
            exit_code = 4;
            goto end;
        }
        if (NULL != entry_data_list) {
            MMDB_dump_entry_data_list(stdout, entry_data_list, 2);
        }
    } else {
        fprintf(
            stderr,
            "\n  No entry for this IP address (%s) was found\n\n",
            ip_address);
        exit_code = 5;
    }
    end:
        MMDB_free_entry_data_list(entry_data_list);
        MMDB_close(&mmdb);
        exit(exit_code);
}
