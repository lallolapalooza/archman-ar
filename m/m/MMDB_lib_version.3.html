الوصف

توفر مكتبة libmaxminddb وظائف للتعامل مع ملفات MaxMind DB. انظر https://maxmind.github.io/MaxMind-DB/ لمواصفات تنسيق MaxMind DB. يتم تمثيل قواعد البيانات والنتائج ببنى بيانات مختلفة. يتم فتح قواعد البيانات عن طريق استدعاء MMDB_open(). يمكنك البحث عن عناوين IP كسلسلة نصية باستخدام MMDB_lookup_string() أو كمؤشر إلى بنية sockaddr باستخدام MMDB_lookup_sockaddr().

إذا عثر البحث عن عنوان IP في قاعدة البيانات، فإنه يُرجع بنية MMDB_lookup_result_s. إذا أشارت هذه البنية إلى أن قاعدة البيانات تحتوي على بيانات لعنوان IP، فهناك عدد من الوظائف التي يمكن استخدامها لجلب هذه البيانات. وتشمل هذه MMDB_get_value() و MMDB_get_entry_data_list(). انظر توثيق الوظيفة أدناه لمزيد من التفاصيل.

عندما تنتهي من مقبض قاعدة البيانات، يجب عليك استدعاء MMDB_close().

جميع الوظائف والبنى والوحدات الظاهرة للعامة تبدأ بـ "MMDB_".

بنى البيانات

جميع بنى البيانات المصدرة من رأس maxminddb.h لهذه المكتبة تم تعريفها بشكل نوعي (typedef) في شكل typedef struct foo_s { ... } foo_s، لذلك يمكنك الإشارة إليها بدون البادئة struct.

توفر هذه المكتبة بنى البيانات التالية:

MMDB_s

هذا هو مقبض لملف MaxMind DB. نحن نوثق فقط بعض الحقول المخصصة للاستخدام العام لهذه البنية. جميع الحقول الأخرى تخضع للتغيير ومخصصة للاستخدام الداخلي فقط.

typedef struct MMDB_s {
    uint32_t flags;
    const char *filename;
    ...
    MMDB_metadata_s metadata;
} MMDB_s;
  • uint32_t flags - العلامات التي تم فتح قاعدة البيانات بها. انظر توثيق MMDB_open() لمزيد من التفاصيل.
  • const char *filename - اسم الملف الذي تم فتحه، كما تم تمريره إلى MMDB_open().
  • MMDB_metadata_s metadata - البيانات الوصفية لقاعدة البيانات.

MMDB_metadata_s و MMDB_description_s

يمكن استرداد هذه البنية من بنية MMDB_s. تحتوي على البيانات الوصفية التي تم قراءتها من ملف قاعدة البيانات. لاحظ أنه قد تجد أنه من الأسهل الوصول إلى هذه البيانات الوصفية عن طريق استدعاء MMDB_get_metadata_as_entry_data_list() بدلاً من ذلك.

typedef struct MMDB_metadata_s {
    uint32_t node_count;
    uint16_t record_size;
    uint16_t ip_version;
    const char *database_type;
    struct {
        size_t count;
        const char **names;
    } languages;
    uint16_t binary_format_major_version;
    uint16_t binary_format_minor_version;
    uint64_t build_epoch;
    struct {
        size_t count;
        MMDB_description_s **descriptions;
    } description;
} MMDB_metadata_s;
typedef struct MMDB_description_s {
    const char *language;
    const char *description;
} MMDB_description_s;

يجب أن تكون هذه البنى واضحة بذاتها في الغالب.

يجب أن يكون العضو ip_version دائمًا 4 أو 6. يجب أن يكون binary_format_major_version دائمًا 2.

لا يوجد شرط بأن تحتوي البيانات الوصفية لقاعدة البيانات على لغات أو أوصاف، لذلك يمكن أن يكون count لهذه الأجزاء من البيانات الوصفية صفرًا. يجب أن تكون جميع حقول MMDB_metadata_s الأخرى مملوءة.

MMDB_lookup_result_s

تُرجع هذه البنية كنتيجة للبحث عن عنوان IP.

typedef struct MMDB_lookup_result_s {
    bool found_entry;
    MMDB_entry_s entry;
    uint16_t netmask;
} MMDB_lookup_result_s;

إذا كان العضو found_entry خاطئًا، فلن تحتوي الحقول الأخرى في هذه البنية على قيم ذات معنى. تحقق دائمًا من أن found_entry صحيح أولاً.

يُستخدم العضو entry للبحث عن البيانات المرتبطة بعنوان IP.

يخبرك العضو netmask بالشبكة الفرعية التي ينتمي إليها عنوان IP في قاعدة البيانات هذه. على سبيل المثال، إذا قمت بالبحث عن العنوان 1.1.1.1 في قاعدة بيانات IPv4 وكان netmask المُعاد هو 16، فإن العنوان جزء من الشبكة الفرعية 1.1.0.0/16.

إذا كانت قاعدة البيانات هي قاعدة بيانات IPv6، فإن قناع الشبكة المُعاد هو دائمًا طول بادئة IPv6 (من 0-128)، حتى لو كانت قاعدة البيانات هذه تحتوي *أيضًا* على شبكات IPv4. إذا بحثت عن عنوان IPv4 وأردت تحويل قناع الشبكة إلى قيمة قناع شبكة IPv4، يمكنك ببساطة طرح 96 من القيمة.

MMDB_result_s

لست بحاجة حقًا إلى التعمق في هذه البنية. ستحصل عليها من بنية MMDB_lookup_result_s وتمررها إلى وظائف مختلفة.

MMDB_entry_data_s

تُستخدم هذه البنية لإرجاع إدخال قسم بيانات واحد لعنوان IP. يمكن أن تشير هذه الإدخالات بدورها إلى إدخالات أخرى، كما هو الحال في أشياء مثل الخرائط والمصفوفات. بعض حقول هذه البنية غير موثقة لأنها للاستخدام الداخلي فقط.

typedef struct MMDB_entry_data_s {
    bool has_data;
    union {
        uint32_t pointer;
        const char *utf8_string;
        double double_value;
        const uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        int32_t int32;
        uint64_t uint64;
        {mmdb_uint128_t or uint8_t[16]} uint128;
        bool boolean;
        float float_value;
    };
    ...
    uint32_t data_size;
    uint32_t type;
} MMDB_entry_data_s;

العضو has_data صحيح إذا تم العثور على بيانات للبحث المحدد. انظر MMDB_get_value() لمزيد من التفاصيل. إذا كان هذا العضو خاطئًا، فإن أيًا من القيم الأخرى في البنية ليست ذات معنى.

يحدد الاتحاد في بداية البنية البيانات الفعلية. لتحديد عضو الاتحاد

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

هياكل البيانات

يوجد هيكلان للبيانات. الأول هو MMDB_entry_s والذي يمثل مدخل بيانات في قاعدة بيانات MaxMind. الثاني هو MMDB_entry_data_s والذي يمثل البيانات الفعلية للمدخل.

MMDB_entry_s

يمثل هذا الهيكل مدخل بيانات في قاعدة بيانات MaxMind. تتكون هذه البنية من الحقول التالية:

typedef struct MMDB_entry_s {
    uint32_t canonical_node;
    uint32_t prefix_node;
    uint32_t data_section_offset;
    uint8_t record_type;
} MMDB_entry_s;

في حال كانت record_type تشير إلى MMDB_RECORD_TYPE_SEARCH_NODE، يجب عليك التعامل مع canonical_node و prefix_node كعقد بحث. عند البحث عن عنوان IP، تكون كلتاهما تشيران إلى نفس العقدة. ومع ذلك، يتم تعيين data_section_offset إلى 0.

إذا كانت record_type تشير إلى MMDB_RECORD_TYPE_DATA، فسيتم تعيين data_section_offset إلى موقع البيانات في قسم البيانات لقاعدة البيانات. سيتم تعيين canonical_node و prefix_node إلى 0.

MMDB_entry_data_s

يمثل هذا الهيكل البيانات الفعلية لمدخل بيانات في قاعدة بيانات MaxMind. يمكن أن تكون البيانات من أنواع مختلفة، ويتم التعامل مع كل نوع بطريقة مختلفة.

typedef struct MMDB_entry_data_s {
    union {
        char *utf8_string;
        uint8_t *bytes;
        uint16_t uint16;
        uint32_t uint32;
        uint64_t uint64;
        uint128_t uint128;
        double dbl;
        float fl;
        void *pointer;
    } object;
    uint8_t type;
    uint32_t data_size;
    uint32_t pointer_value;
} MMDB_entry_data_s;

الحقول المتاحة هي:

  • type: يحدد نوع البيانات المخزنة. يمكن مقارنته مع ثوابت MMDB_DATA_TYPE_*.
  • object: اتحاد يحتوي على البيانات الفعلية. يعتمد الحقل المستخدم في الاتحاد على قيمة type.
  • data_size: حجم البيانات بالبايت. هذا الحقل ذو صلة فقط لأنواع MMDB_DATA_TYPE_UTF8_STRING و MMDB_DATA_TYPE_BYTES. بالنسبة لسلاسل UTF-8، لا يتم إنهاؤها بحرف فارغ، ويجب استخدام data_size لتحديد طولها.
  • pointer_value: يتم استخدام هذا الحقل داخليًا فقط ولا يجب استخدامه بواسطة المطورين.

إذا كانت type تشير إلى MMDB_DATA_TYPE_POINTER، يجب عليك فحص العضو pointer_value. لا يجب أبدًا ملء العضو pointer الخاص بالاتحاد بأي بيانات يتم إرجاعها بواسطة واجهة برمجة التطبيقات (API). يجب دائمًا حل المؤشرات داخليًا.

العضو data_size ذو صلة فقط لأنواع MMDB_DATA_TYPE_UTF8_STRING و MMDB_DATA_TYPE_BYTES. سلسلة MMDB_DATA_TYPE_UTF8_STRING غير منتهية بحرف فارغ ويجب استخدام data_size لتحديد طولها.

يمكن مقارنة العضو type بأحد ثوابت MMDB_DATA_TYPE_*.

الأعداد الصحيحة 128 بت

يعتمد التعامل مع بيانات uint128 على كيفية دعم منصتك للأعداد الصحيحة 128 بت، إن كانت تدعمها على الإطلاق. مع GCC 4.4 و 4.5، يمكننا كتابة unsigned int __attribute__ ((__mode__ (TI))). مع الإصدارات الأحدث من GCC (4.6+) و clang (3.2+)، يمكننا ببساطة كتابة "unsigned __int128".

لتجنب هذه الاختلافات، تعرّف هذه المكتبة نوع mmdb_uint128_t. يتم تعريف هذا النوع في ترويسة maxminddb.h حتى تتمكن من استخدامه في الكود الخاص بك.

مع المترجمات القديمة، لا يمكننا استخدام عدد صحيح، لذا نستخدم بدلاً من ذلك مصفوفة من 16 بايت من قيم uint8_t. هذه هي البيانات الأولية من قاعدة البيانات.

توفر هذه المكتبة ماكرو عام MMDB_UINT128_IS_BYTE_ARRAY. إذا كانت هذه القيمة صحيحة (1)، فيتم إرجاع قيم uint128 كمصفوفة بايت، وإذا كانت خاطئة، يتم إرجاعها كعدد صحيح mmdb_uint128_t.

ثوابت أنواع البيانات

توفر هذه المكتبة ثابتًا لكل نوع بيانات تم تعريفه بواسطة مواصفات MaxMind DB.

  • MMDB_DATA_TYPE_UTF8_STRING
  • MMDB_DATA_TYPE_DOUBLE
  • MMDB_DATA_TYPE_BYTES
  • MMDB_DATA_TYPE_UINT16
  • MMDB_DATA_TYPE_UINT32
  • MMDB_DATA_TYPE_MAP
  • MMDB_DATA_TYPE_INT32
  • MMDB_DATA_TYPE_UINT64
  • MMDB_DATA_TYPE_UINT128
  • MMDB_DATA_TYPE_ARRAY
  • MMDB_DATA_TYPE_BOOLEAN
  • MMDB_DATA_TYPE_FLOAT

هناك أيضًا بعض الأنواع المخصصة للاستخدام الداخلي فقط:

  • MMDB_DATA_TYPE_EXTENDED
  • MMDB_DATA_TYPE_POINTER
  • MMDB_DATA_TYPE_CONTAINER
  • MMDB_DATA_TYPE_END_MARKER

إذا رأيت أحد هذه الأنواع في البيانات المرجعة، فهذا يعني أن هناك خطأ ما. قاعدة البيانات تالفة أو تم إنشاؤها بشكل غير صحيح أو أن هناك خطأ في كود libmaxminddb.

قيم المؤشرات و MMDB_close()

الأعضاء utf8_string، bytes، و (ربما) uint128 في هذا الهيكل هي مؤشرات مباشرة إلى قسم بيانات قاعدة البيانات. يمكن أن يكون هذا كتلة ذاكرة مخصصة بواسطة calloc أو mmap. في كلتا الحالتين، ستصبح هذه المؤشرات غير صالحة بعد استدعاء MMDB_close().

إذا كنت بحاجة إلى الإشارة إلى هذه البيانات بعد ذلك الوقت، يجب عليك نسخ البيانات باستخدام دالة مناسبة (مثل strdup، memcpy، إلخ).

MMDB_entry_data_list_s

يغلف هذا الهيكل قائمة مرتبطة من هياكل MMDB_entry_data_s.

typedef struct MMDB_entry_data_list_s {
    MMDB_entry_data_s entry_data;
    struct MMDB_entry_data_list_s *next;
} MMDB_entry_data_list_s;

يتيح لك هذا الهيكل عرض بيانات الخريطة أو المصفوفة بأكملها عن طريق التكرار عبر القائمة المرتبطة.

MMDB_search_node_s

يغلف هذا الهيكل السجلين في عقدة بحث. هذا مفيد حقًا فقط إذا كنت ترغب في كتابة كود يتكرر عبر شجرة البحث بأكملها بدلاً من البحث عن عنوان IP محدد.

typedef struct MMDB_search_node_s {
    uint64_t left_record;
    uint64_t right_record;
    uint8_t left_record_type;
    uint8_t right_record_type;
    MMDB_entry_s left_record_entry;
    MMDB_entry_s right_record_entry;
} MMDB_search_node_s;

ستأخذ أنواع السجلات هذين القيمتين:

  • MMDB_RECORD_TYPE_SEARCH_NODE - يشير السجل إلى عقدة البحث التالية.
  • MMDB_RECORD_TYPE_EMPTY - السجل هو عنصر نائب يشير إلى عدم وجود بيانات لعنوان IP. يجب أن ينتهي البحث هنا.
  • MMDB_RECORD_TYPE_DATA - السجل مخصص للبيانات في قسم البيانات من قاعدة البيانات. استخدم المدخل للسجل عند البحث عن بيانات السجل.
  • MMDB_RECORD_TYPE_INVALID - السجل غير صالح. إما تم البحث عن عقدة غير صالحة أو أن قاعدة البيانات تالفة.

يكون MMDB_entry_s للسجل صالحًا فقط إذا كان النوع هو MMDB_RECORD_TYPE_DATA. محاولات استخدام مدخل لأنواع سجلات أخرى ستؤدي إلى خطأ أو بيانات غير صالحة.

رموز الحالة

تقوم هذه المكتبة بإرجاع (أو ملء) رموز الحالة للعديد من الوظائف. رموز الحالة هذه هي:

  • MMDB_SUCCESS - كل شيء عمل بنجاح
  • MMDB_FILE_OPEN_ERROR - حدث خطأ أثناء محاولة فتح ملف MaxMind DB.
  • MMDB_IO_ERROR - فشلت عملية إدخال/إخراج. تحقق من errno لمزيد من التفاصيل.
  • MMDB_CORRUPT_SEARCH_TREE_ERROR - أدى البحث عن عنوان IP في شجرة البحث إلى نتيجة مستحيلة. قاعدة البيانات تالفة أو تم إنشاؤها بشكل غير صحيح أو أن هناك خطأ في كود libmaxminddb.
  • MMDB_INVALID_METADATA_ERROR - هناك خطأ ما في قاعدة البيانات. يشمل ذلك مفاتيح بيانات وصفية مفقودة وكذلك قيم مستحيلة (مثل ip_version بقيمة 7).
  • MMDB_UNKNOWN_DATABASE_FORMAT_ERROR - تشير البيانات الوصفية لقاعدة البيانات إلى أن إصدارها الرئيسي ليس 2. هذه المكتبة يمكنها فقط التعامل مع الإصدار الرئيسي 2.
  • MMDB_OUT_OF_MEMORY_ERROR - فشل استدعاء تخصيص الذاكرة (malloc، إلخ).
  • MMDB_INVALID_DATA_ERROR - يحتوي مدخل في قسم البيانات على بيانات غير صالحة. على سبيل المثال، يدعي حقل uint16 أنه أطول من بايتين. قاعدة البيانات على الأرجح تالفة أو تم إنشاؤها بشكل غير صحيح.
  • MMDB_INVALID_LOOKUP_PATH_ERROR - يحتوي المسار الذي تم تمريره إلى MMDB_get_value، MMDB_vget_value، أو MMDB_aget_value على إزاحة مصفوفة أكبر من LONGMAX أو أصغر من LONGMIN.
  • MMDB_LOOKUP_PATH_DOES_NOT_MATCH_DATA_ERROR - المسار الذي تم تمريره إلى MMDB_get_value، MMDB_vget_value، أو MMDB_aget_value لا يتطابق مع بنية بيانات المدخل. هناك عدد من الأسباب التي يمكن أن يحدث هذا من أجلها. قد يتضمن مسار البحث مفتاحًا غير موجود في خريطة. قد يتضمن مسار البحث فهرس مصفوفة أكبر من مصفوفة أو أصغر من الحد الأدنى للإزاحة من نهاية مصفوفة. يمكن أن يحدث هذا أيضًا عندما يتوقع المسار العثور على خريطة أو مصفوفة حيث لا توجد.

يجب معاملة جميع رموز الحالة كقيم int.

MMDB_strerror()

تأخذ هذه الدالة رمز حالة وترجع سلسلة نصية باللغة الإنجليزية توضح الحالة.

الوظائف

توفر هذه المكتبة الوظائف المصدرة التالية:

MMDB_open()

int MMDB_open(
    const char *const filename,
    uint32_t flags,
    MMDB_s *const mmdb);

تفتح هذه الدالة مقبضًا لملف MaxMind DB. قيمة الإرجاع الخاصة بها هي رمز حالة كما هو محدد أعلاه. تحقق دائمًا من قيمة إرجاع هذا الاستدعاء.

MMDB_s mmdb;
int status =
    MMDB_open("/path/to/file.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) { ... }
...
MMDB_close(&mmdb);

يجب تشفير filename بنظام UTF-8 على نظام Windows.

يمكن أن يكون هيكل MMDB_s الذي تمرره على المكدس أو مخصصًا من الكومة. ومع ذلك، إذا نجحت عملية الفتح، فستحتوي على بيانات مخصصة من الكومة، لذا تحتاج إلى إغلاقها باستخدام MMDB_close(). إذا لم تكن الحالة المعادة MMDB_SUCCESS، فإن هذه المكتبة تضمن تحرير جميع الذاكرة المخصصة قبل الإرجاع.

الأعلام المتوفرة حاليًا هي:

•
MMDB_MODE_MMAP - فتح قاعدة البيانات باستخدام mmap().

قد يؤدي تمرير قيم أخرى للمعلمات flags إلى نتائج غير متوقعة. في المستقبل، قد نضيف أعلامًا إضافية يمكنك دمجها مع الوضع باستخدام عملية OR البتية، بالإضافة إلى أوضاع إضافية.

يمكنك أيضًا تمرير 0 كقيمة للمعلمات flags، وفي هذه الحالة سيتم فتح قاعدة البيانات باستخدام الأعلام الافتراضية. ومع ذلك، قد تتغير هذه الافتراضيات في الإصدارات المستقبلية. الافتراض الحالي هو MMDB_MODE_MMAP.

NAME

libmaxminddb - C library for reading MaxMind DB files

SYNOPSIS

#include <maxminddb.h>
MMDB_s mmdb;
int status = MMDB_open("database.mmdb", MMDB_MODE_MMAP, &mmdb);
if (MMDB_SUCCESS != status) {
    // error handling
}
// ... use mmdb ...
MMDB_close(&mmdb);

DESCRIPTION

The libmaxminddb library provides a reader for the MaxMind DB file format. This format is used by MaxMind GeoIP2 and other databases.

libmaxminddb is a standalone library with no external dependencies beyond a standard C library.

This library is thread-safe when compiled and linked with a thread-safe malloc and free implementation.

DATA STRUCTURES

MMDB_s

    The main structure for a MaxMind DB file. You will get a pointer to
    this structure from MMDB_open(). This structure
    is opaque and should not be accessed directly.

MMDB_lookup_result_s

    The result of a lookup. This structure is populated by
    MMDB_lookup() and related functions. It contains
    a boolean indicating whether an entry was found, and an MMDB_entry_s
    structure that contains the actual data.

MMDB_entry_s

    Contains the data for a specific entry in the database. This structure
    is populated by MMDB_lookup() and related
    functions.

MMDB_entry_data_list_s

    A linked list of MMDB_entry_data_s. This is returned
    by MMDB_get_entry_data_list().

MMDB_entry_data_s

    Contains the data for a specific key within an entry. The data itself
    is stored in the MMDB_entry_data_list_s structure,
    and this structure contains a pointer to it, along with a type and a
    size.

MMDB_search_node_s

    Contains data for a node within the MaxMind DB search tree. This
    structure is populated by MMDB_read_node().

STATUS CODES

The following status codes are returned by most libmaxminddb functions.

MMDB_SUCCESS
The operation was successful.
MMDB_MMAP_ERROR
An error occurred during mmap().
MMDB_IO_ERROR
An error occurred performing I/O on the database file.
MMDB_INVALID_FILE_ERROR
The database file is invalid or corrupt.
MMDB_INVALID_METADATA_ERROR
The database file metadata is invalid or corrupt.
MMDB_INVALID_DATA_ERROR
The database file data is invalid or corrupt.
MMDB_OUT_OF_MEMORY_ERROR
An error occurred allocating memory.
MMDB_INVALID_ARGUMENT_ERROR
An invalid argument was passed to the function.
MMDB_FILE_NOT_FOUND_ERROR
The database file could not be found.
MMDB_INVALID_NODE_NUMBER_ERROR
The provided node number is invalid.

FUNCTIONS

MMDB_open()

int MMDB_open(
    const char *filename,
    int mode,
    MMDB_s *const mmdb);

Opens a MaxMind DB file for reading. The `mode` argument can be one of the following:

MMDB_MODE_MMAP
Memory-map the database file. This is the most efficient mode, as the operating system handles loading the file into memory.
MMDB_MODE_FILE
Read the database file into memory. This uses more memory than MMDB_MODE_MMAP but may be faster on systems that do not support mmap() well.
MMDB_MODE_SHARED_MEM
Load the database file into shared memory. This is useful when multiple processes need to access the same database. The first process to open the database in this mode will create the shared memory segment. Subsequent processes will attach to it.

The return value is a status code. If successful, it will be MMDB_SUCCESS.

MMDB_close()

void MMDB_close(MMDB_s *const mmdb);

Closes an opened MaxMind DB database file and frees any resources associated with it.

MMDB_lookup()

MMDB_lookup_result_s MMDB_lookup(
    MMDB_s *const mmdb,
    const char *ip_address,
    int *gai_error,
    int *mmdb_error);

Looks up an IP address in the database. The `ip_address` can be either an IPv4 or IPv6 address. The `gai_error` and `mmdb_error` arguments are pointers to integers that will be populated with error codes from getaddrinfo() and libmaxminddb, respectively. If no error occurred, these will be set to 0.

The return value is an MMDB_lookup_result_s structure. If MMDB_lookup_result_s.found_entry is true, then the lookup was successful and the data is available in MMDB_lookup_result_s.entry.

MMDB_lookup_string()

MMDB_lookup_result_s MMDB_lookup_string(
    MMDB_s *const mmdb,
    const char *ip_string,
    int *gai_error,
    int *mmdb_error);

This is a convenience function that is equivalent to calling MMDB_lookup(). It takes the IP address as a string and returns the lookup result.

MMDB_get_entry_data_list()

int MMDB_get_entry_data_list(
    const MMDB_entry_s *const entry,
    MMDB_entry_data_list_s **const entry_data_list);

Retrieves the data for an entry as a linked list of MMDB_entry_data_s structures. This is useful for iterating over the data in an entry, especially when the structure of the data is unknown.

The return value is a status code. If successful, it will be MMDB_SUCCESS.

The `entry_data_list` argument is a pointer to a pointer to MMDB_entry_data_list_s. If the lookup is successful, this will be populated with the linked list of entry data.

You must call MMDB_free_entry_data_list() to free the memory allocated by this function.

MMDB_free_entry_data_list()

void MMDB_free_entry_data_list(MMDB_entry_data_list_s *const entry_data_list);

Frees the memory allocated by MMDB_get_entry_data_list().

MMDB_strerror()

const char *MMDB_strerror(int status);

Returns a human-readable string representation of a status code returned by a libmaxminddb function.
