mmdbresolve(1)

الحزمة: wireshark-cli

التراخيص: GPL-2.0-only

MMDBRESOLVE(1)   MMDBRESOLVE(1)

الاسم

mmdbresolve - قراءة عناوين IPv4 و IPv6 وطباعة معلومات تحديد الموقع الجغرافي للـ IP الخاصة بها.

ملخص

mmdbresolve [ -v ]

mmdbresolve [ -h ]

mmdbresolve -f <dbfile> [ -f <dbfile> ] ...

الوصف

mmdbresolve يقرأ عناوين IPv4 و IPv6 من المدخل القياسي ويطبع معلومات تحديد الموقع الجغرافي للـ IP الخاصة بها إلى المخرج القياسي. يجب أن يحتوي كل سطر إدخال على عنوان واحد بالضبط. يكون الإخراج بصيغة INI، مع فاصل قسم مسمى باسم العنوان المطلوب متبوعًا بمجموعة من أزواج "مفتاح: قيمة". يتم إلحاق تعليق يبدأ بـ "# End" لكل قسم.

عند بدء التشغيل، يتم طباعة قسم "[init]" يوضح حالة كل قاعدة بيانات وحالة mmdbresolve نفسها.

خيارات

-v

طباعة معلومات الإصدار والخروج.

-h

طباعة معلومات المساعدة والخروج.

-f

مسار ملف قاعدة بيانات MaxMind. يمكن تحديد ملفات قواعد بيانات متعددة.

أمثلة

لتحديد عنوان واحد:

echo 4.4.4.4 | mmdbresolve -f /usr/share/GeoIP/GeoLite2-City.mmdb

مثال للإخراج

[init]
db.0.path: /usr/share/GeoIP/GeoLite2-City.mmdb
db.0.status: OK
mmdbresolve.status: true
# End init
[4.4.4.4]
# GeoLite2-City
country.iso_code: US
country.names.en: United States
location.latitude: 37.751000
location.longitude: -97.822000
# End 4.4.4.4
