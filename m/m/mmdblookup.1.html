mmdblookup(1)

الحزمة: mmdblookup

التراخيص: Apache-2.0

mmdblookup(1) دليل الأوامر العامة mmdblookup(1)

الاسم

mmdblookup - أداة للبحث عن عنوان IP في ملف MaxMind DB

موجز

mmdblookup --file [مسار الملف] --ip [عنوان IP] [مسار البيانات]

الوصف

mmdblookup يبحث عن عنوان IP في ملف MaxMind DB المحدد. يتم عرض السجل الخاص بعنوان IP مع {} للإشارة إلى الخرائط و [] للإشارة إلى المصفوفات. تتبع القيم بتعليقات توضيحية للنوع. هذا الإخراج *ليس* JSON وليس مخصصًا للاستخدام على هذا النحو. إذا كنت بحاجة إلى JSON، يرجى الرجوع إلى mmdbinspect https://github.com/maxmind/mmdbinspect.

إذا كان إدخال بيانات IP يحل إلى خريطة أو مصفوفة، يمكنك توفير مسار بحث لعرض جزء فقط من تلك البيانات.

على سبيل المثال، بالنظر إلى بنية JSON كهذه:

{
    "names": {
        "en": "Germany",
        "de": "Deutschland"
    },
    "cities": [ "Berlin", "Frankfurt" ]
}

يمكنك البحث عن الاسم الإنجليزي فقط عن طريق استدعاء mmdblookup مع مسار بحث:

mmdblookup --file ... --ip ... names en

أو يمكنك البحث عن المدينة الثانية في القائمة مع:

mmdblookup --file ... --ip ... cities 1

يبدأ ترقيم المصفوفات من الصفر (0).

إذا لم تقدم مسارًا للبحث، فسيتم عرض جميع المعلومات الخاصة بعنوان IP معين.

خيارات

يقبل هذا التطبيق الخيارات التالية:

-f, --file
المسار إلى ملف MMDB. مطلوب.
-i, --ip
عنوان IP للبحث عنه. مطلوب.
-v, --verbose
تشغيل الإخراج المطول. على وجه التحديد، يتسبب هذا في قيام التطبيق بإخراج بيانات التعريف الخاصة بقاعدة البيانات.
--version
طباعة رقم إصدار البرنامج والخروج.
-h, -?, --help
عرض معلومات الاستخدام.
