MCKEY(1) librdmacm MCKEY(1)

الاسم

mckey - إعداد multicast لـ RDMA واختبار نقل بيانات بسيط.

السيناريو

mckey -m عنوان_multicast [-s] [-b عنوان_الربط] [-c اتصالات]
		[-C عدد_الرسائل] [-S حجم_الرسالة] [-p مساحة_المنفذ]
mckey -m عنوان_multicast -s [-b عنوان_الربط] [-c اتصالات]
		[-C عدد_الرسائل] [-S حجم_الرسالة] [-p مساحة_المنفذ]
mckey -M عنوان_multicast_غير_مُعَيَّن -b عنوان_الربط [-s] [-c اتصالات]
		[-C عدد_الرسائل] [-S حجم_الرسالة] [-p مساحة_المنفذ]

الوصف

ينشئ مجموعة من مسارات اتصال multicast لـ RDMA باستخدام librdmacm، وينقل اختياريًا datagrams إلى العقد المستقبلة، ثم ينهي الاتصال.

الخيارات

-m عنوان_multicast
عنوان IP multicast للانضمام إليه.
-M عنوان_multicast_غير_مُعَيَّن
عنوان multicast خاص بنقل RDMA للانضمام إليه.
-s
إرسال datagrams إلى مجموعة multicast.
-b عنوان_الربط
عنوان الشبكة المحلي للربط به.
-c اتصالات
عدد QPs للانضمام إلى مجموعة multicast. (الافتراضي 1)
-C عدد_الرسائل
عدد الرسائل التي سيتم نقلها عبر كل اتصال. (الافتراضي 10)
-S حجم_الرسالة
حجم كل رسالة يتم نقلها، بالبايت. يجب أن يكون هذا الحجم أصغر من MTU لنقل RDMA الأساسي، وإلا سيحدث خطأ. (الافتراضي 100)
-o
الانضمام إلى مجموعة multicast كعضو كامل للإرسال فقط. بخلاف ذلك، يتم الانضمام إلى المجموعة كعضو كامل.
-l
منع تكرار رسائل multicast. لن تستقبل العقد المستقبلة الأخرى على النظام المحلي رسائل multicast. بخلاف ذلك، يتم إرسال جميع رسائل multicast أيضًا إلى المضيف الذي نشأت منه وستتلقى المستمعون المحليون (وربما العملية المرسلة نفسها) الرسائل. -p مساحة_المنفذ مساحة منفذ اتصال datagram. يمكن أن تكون إما مساحة منفذ RDMA UDP (0x0111) أو IPoIB (0x0002). (الافتراضي RDMA_PS_UDP)

ملاحظات

الاستخدام الأساسي هو بدء mckey -m عنوان_multicast على نظام خادم، ثم تشغيل mckey -m عنوان_multicast -s على نظام عميل.

يمكن استرداد GIDs multicast المعينة فريدًا بواسطة SA لـ Infiniband عن طريق استدعاء mckey بعنوان MGID أو عنوان IP صفري. (مثال، -M 0 أو -m 0.0.0.0). سيتم عرض العنوان المعين للسماح لعملاء mckey بالانضمام إلى المجموعة المنشأة.

نظرًا لأن هذا الاختبار يعين موارد RDMA إلى مساحة المستخدم، يجب على المستخدمين التأكد من أن لديهم موارد وأذونات نظام متاحة. راجع ملف README الخاص بـ libibverbs للحصول على تفاصيل إضافية.
