Key bindings

C-<chr>
يعني الضغط على مفتاح Control أثناء كتابة الحرف <chr>. بالتالي C-f سيكون: اضغط على مفتاح Control واكتب f.
Alt-<chr>
يعني الضغط على مفتاح Meta أو Alt أثناء كتابة <chr>. إذا لم يكن هناك مفتاح Meta أو Alt، اضغط على Esc، حرره، ثم اكتب الحرف <chr>.
S-<chr>
يعني الضغط على مفتاح Shift أثناء كتابة <chr>.

تستخدم جميع أسطر الإدخال في Midnight Commander تقريبًا ربطات مفاتيح محرر GNU Emacs (افتراضيًا).

يمكنك إعادة تعريف ربطات المفاتيح. انظر إعادة تعريف ربطات المفاتيح الساخنة

لمزيد من المعلومات. جميع ربطات المفاتيح الأخرى (الموضحة في هذا الدليل) تكون نسبية للسلوك الافتراضي.

هناك العديد من الأقسام التي تتحدث عن المفاتيح. الأقسام التالية هي الأكثر أهمية.

يوثق قسم قائمة الملفات الاختصارات لوحة المفاتيح للأوامر التي تظهر في قائمة الملفات. يشمل هذا القسم مفاتيح الوظائف. معظم هذه الأوامر تقوم بإجراء ما، عادةً على الملف المحدد أو الملفات الموسومة.

يوثق قسم لوحات الدليل المفاتيح التي تحدد ملفًا أو توسم ملفات كهدف لإجراء لاحق (الإجراء عادةً ما يكون أحد الإجراءات من قائمة الملفات).

يسرد قسم سطر أوامر shell المفاتيح المستخدمة لإدخال وتحرير أسطر الأوامر. يقوم معظم هذه الأوامر بنسخ أسماء الملفات وما شابه ذلك من لوحات الدليل إلى سطر الأوامر (لتجنب الكتابة المفرطة) أو الوصول إلى سجل أوامر الأوامر.

تستخدم مفاتيح سطر الإدخال لتحرير أسطر الإدخال. هذا يعني كل من سطر الأوامر وأسطر الإدخال في مربعات الحوار الاستقصائية.

إعادة تعريف ربطات المفاتيح الساخنة

يمكن قراءة ربطات المفاتيح الساخنة من ملف خارجي (ملف keymap). مبدئيًا، ينشئ Midnight Commander ربطات المفاتيح باستخدام keymap معرف في الكود المصدري. بعد ذلك، يتم تحميل الملفين /usr/share/mc/mc.keymap و/etc/mc/mc.keymap دائمًا، مع إعادة تعيين ربطات المفاتيح المعرفة سابقًا بالتسلسل. يتم البحث عن ملف keymap المعرّف من قبل المستخدم باستخدام الخوارزمية التالية (إلى أول ملف يتم العثور عليه):


1) خيار سطر الأوامر -K <keymap> أو --keymap=<keymap>
2) متغير البيئة MC_KEYMAP
3) المعلمة keymap في قسم [Midnight-Commander] من ملف التكوين.
4) الملف ~/.config/mc/mc.keymap

قد يحتوي خيار سطر الأوامر، متغير البيئة، والمعلمة في ملف التكوين على المسار المطلق لملف keymap (مع امتداد .keymap أو بدونه). سيحدث البحث عن ملف keymap في (إلى أول ملف يتم العثور عليه):


1) ~/.config/mc
2) /etc/mc/
3) /usr/share/mc/

مفاتيح متنوعة

هنا بعض المفاتيح التي لا تندرج ضمن أي فئات أخرى:

Enter
إذا كان هناك بعض النص في سطر الأوامر (الذي في أسفل اللوحات)، فسيتم تنفيذ ذلك الأمر. إذا لم يكن هناك نص في سطر الأوامر، فإذا كان شريط التحديد فوق دليل، فإن Midnight Commander يقوم بتنفيذ chdir(2) للدليل المحدد وإعادة تحميل المعلومات في اللوحة؛ إذا كان التحديد ملفًا قابلاً للتنفيذ، فسيتم تنفيذه. أخيرًا، إذا كان امتداد اسم الملف المحدد يتطابق مع أحد الامتدادات في ملف الامتدادات، فسيتم تنفيذ الأمر المقابل.
C-l
إعادة رسم جميع المعلومات في Midnight Commander.
C-x c
تشغيل أمر Chmod على ملف أو على الملفات الموسومة.
C-x o
تشغيل أمر Chown على الملف الحالي أو على الملفات الموسومة.
C-x l
تشغيل أمر الرابط الصلب.
C-x s
تشغيل أمر الرابط الرمزي المطلق.
C-x v
تشغيل أمر الرابط الرمزي النسبي. انظر قسم قائمة الملفات لمزيد من المعلومات حول الروابط الرمزية.
C-x i
تعيين وضع عرض اللوحة الأخرى إلى معلومات.
C-x q
تعيين وضع عرض اللوحة الأخرى إلى عرض سريع.
C-x !
تنفيذ أمر panelize الخارجي.
C-x h
تشغيل أمر إضافة دليل إلى قائمة المفاتيح الساخنة.
Alt-!
ينفذ أمر العرض المصفى، الموضح في أمر العرض.
Alt-?
ينفذ أمر البحث عن ملف.
Alt-c
يظهر مربع حوار cd السريع.
C-o
عند تشغيل البرنامج في وحدة تحكم Linux أو FreeBSD أو تحت xterm، سيعرض لك مخرجات الأمر السابق. عند تشغيله على وحدة تحكم Linux، يستخدم Midnight Commander برنامجًا خارجيًا (cons.saver) للتعامل مع حفظ واستعادة المعلومات على الشاشة.

عند تجميع دعم shell الفرعي، يمكنك كتابة C-o في أي وقت وسيتم نقلك إلى الشاشة الرئيسية لـ Midnight Commander، للعودة إلى تطبيقك اكتب C-o. إذا كان لديك تطبيق معلق باستخدام هذه الحيلة، فلن تتمكن من تنفيذ برامج أخرى من Midnight Commander حتى تقوم بإنهاء التطبيق المعلق.

لوحات الدليل

يسرد هذا القسم المفاتيح التي تعمل على لوحات الدليل. إذا كنت ترغب في معرفة كيفية تغيير مظهر اللوحات، فراجع القسم الخاص بالقوائم اليسرى واليمنى.

Tab, C-i
تغيير اللوحة الحالية. تصبح اللوحة الأخرى القديمة لوحة حالية جديدة وتصبح اللوحة الحالية القديمة لوحة أخرى جديدة. ينتقل شريط التحديد من اللوحة الحالية القديمة إلى اللوحة الحالية الجديدة.
Insert, C-t
لتوسيم الملفات، يمكنك استخدام مفتاح Insert (تسلسل terminfo kich1). لإلغاء توسيم الملفات، قم فقط بإعادة توسيم ملف موسوم.
Alt-e
لتغيير ترميز اللوحة، يمكنك استخدام Alt-e (M-e). يتم إجراء إعادة الترميز من صفحة الترميز المحددة إلى صفحة الترميز النظامية. لإلغاء إعادة الترميز، حدد "No translation" في مربع حوار الترميزات.
Alt-g, Alt-r, Alt-j
تستخدم لتحديد الملف العلوي في لوحة، الملف الأوسط، والملف السفلي، على التوالي.
Alt-t
تبديل قائمة العرض الحالية لإظهار تنسيق قائمة العرض التالي. مع هذا، يصبح من الممكن التبديل بسرعة إلى قائمة موجزة، قائمة طويلة، تنسيق قائمة معرف من قبل المستخدم، والعودة إلى الافتراضي.
C- (control-backslash)
عرض قائمة الدلائل الساخنة والانتقال إلى الدليل المحدد.
+ (plus)
يستخدم هذا لتحديد (توسيم) مجموعة من الملفات. سيطلب Midnight Commander خيارات التحديد. عند تشغيل مربع الاختيار Files only، سيتم تحديد الملفات فقط. إذا كان Files only متوقفًا، سيتم تحديد كل من الملفات والدلائل. عند تشغيل Shell Patterns، يكون التعبير العادي مشابهًا لـ filename globbing في shell (* يمثل صفرًا أو أكثر من الأحرف و؟ يمثل حرفًا واحدًا). إذا كان Shell Patterns متوقفًا، فسيتم توسيم الملفات باستخدام تعبيرات عادية طبيعية (انظر ed (1)). عند تشغيل مربع الاختيار Case sensitive، سيكون التحديد حساسًا لحالة الأحرف. إذا كان Case sensitive متوقفًا، سيتم تجاهل الحالة.
\ (backslash)
استخدم مفتاح "\" لإلغاء تحديد مجموعة من الملفات. هذا هو عكس مفتاح Plus.
up-key, C-p
تحريك شريط التحديد إلى الإدخال السابق في اللوحة.
down-key, C-n
تحريك شريط التحديد إلى الإدخال التالي في اللوحة.
home, a1, Alt-<
تحريك شريط التحديد إلى الإدخال الأول في اللوحة.
end, c1, Alt->
تحريك شريط التحديد إلى الإدخال الأخير في اللوحة.
next-page, C-v
تحريك شريط التحديد صفحة واحدة لأسفل.
prev-page, Alt-v
تحريك شريط التحديد صفحة واحدة لأعلى.
Alt-o
إذا كان الملف المحدد حاليًا دليلًا، قم بتحميل هذا الدليل في اللوحة الأخرى وانتقل بالتحديد إلى الملف التالي. إذا لم يكن الملف المحدد حاليًا دليلًا، قم بتحميل الدليل الأب في اللوحة الأخرى وانتقل بالتحديد إلى الملف التالي.
Alt-i
اجعل الدليل الحالي للوحة الحالية هو أيضًا الدليل الحالي للوحة الأخرى. قم بتعيين اللوحة الأخرى إلى وضع العرض إذا لزم الأمر. إذا كانت اللوحة الحالية مُدخلة، فلن تصبح اللوحة الأخرى مُدخلة.
C-PageUp, C-PageDown
فقط عندما يدعم الطرفية: انتقل إلى ".." وإلى الدليل المحدد حاليًا، على التوالي.
Alt-y
ينتقل إلى الدليل السابق في السجل، وهو ما يعادل النقر على < باستخدام الماوس.
Alt-u
ينتقل إلى الدليل التالي في السجل، وهو ما يعادل النقر على > باستخدام الماوس.
Alt-S-h, Alt-H
يعرض سجل الدلائل، وهو ما يعادل الضغط على 'v' بالماوس.

البحث السريع

Panel Layout

The panel layout is defined by a string containing keywords that represent individual fields or layout elements. Here are the available keywords:

ngid
معرف المجموعة (رقمي).
nuid
معرف المستخدم (رقمي).
owner
مالك الملف.
group
مجموعة الملف.
inode
inode الملف.

يمكنك أيضًا استخدام الكلمات المفتاحية التالية لتحديد تخطيط اللوحة:

space
مسافة في تنسيق العرض.
|
إضافة خط عمودي إلى تنسيق العرض.

لإجبار حقل ما على حجم ثابت (محدد حجم)، فقط أضف : متبوعًا برقم الأحرف الذي تريده للحقل. إذا تبع الرقم الرمز +، فإن الحجم يحدد الحد الأدنى لحجم الحقل - إذا اكتشف البرنامج أن هناك مساحة أكبر على الشاشة، فسيقوم بتوسيع هذا الحقل.

على سبيل المثال، يتوافق عرض Full مع هذا التنسيق:

half type name | size | mtime

ويتوافق عرض Long مع هذا التنسيق:

full perm space nlink space owner space group space size space mtime space name

هذا تنسيق عرض مستخدم لطيف:

half name | size:7 | type mode:3

يمكن أيضًا تعيين الألواح إلى الأوضاع التالية:

Info
يعرض عرض المعلومات معلومات متعلقة بالملف المحدد حاليًا وإذا أمكن معلومات حول نظام الملفات الحالي.
Tree
عرض الشجرة مشابه جدًا لميزة شجرة الدلائل. راجع القسم الخاص بها لمزيد من المعلومات.
Quick View
في هذا الوضع، ستتحول اللوحة إلى عارض مخفض يعرض محتويات الملف المحدد حاليًا. إذا حددت اللوحة (باستخدام مفتاح علامة التبويب أو الماوس)، فستتمكن من الوصول إلى أوامر العارض المعتادة.

ترتيب الفرز...

ترتيبات الفرز الثمانية هي حسب الاسم، حسب الامتداد، حسب وقت التعديل، حسب وقت الوصول، وحسب وقت تعديل معلومات inode، حسب الحجم، حسب inode، وغير مرتبة. في مربع حوار ترتيب الفرز، يمكنك اختيار ترتيب الفرز وقد تحدد أيضًا ما إذا كنت تريد الفرز بترتيب عكسي عن طريق تحديد مربع العكس.

افتراضيًا، يتم فرز الدلائل قبل الملفات ولكن يمكن تغيير ذلك من قائمة خيارات اللوحة (الخيار Mix all files).

التصفية...

يسمح لك أمر التصفية بتحديد نمط shell (على سبيل المثال *.tar.gz) الذي يجب أن تتطابق معه الملفات والدلائل ليتم عرضها. يسمح سطر الإدخال بإدخال نمط أسماء الملفات/الدلائل التي سيتم عرضها في اللوحة.

عندما يكون مربع الاختيار Files only نشطًا، سيتم مطابقة الملفات فقط مع التصفية، وسيتم عرض جميع الدلائل. بخلاف ذلك، سيتم تصفية الملفات والدلائل. عندما يكون مربع الاختيار Shell Patterns نشطًا، يكون التعبير العادي مشابهًا جدًا لتحديد أسماء الملفات في shell (حيث يمثل * صفرًا أو أكثر من الأحرف ويمثل ؟ حرفًا واحدًا). بخلاف ذلك، تتم مطابقة الملفات/الدلائل باستخدام التعبيرات العادية العادية (انظر ed(1)). عندما يكون مربع الاختيار Case sensitive نشطًا، ستكون التصفية حساسة لحالة الأحرف. بخلاف ذلك، سيتم تجاهل الحالة.

إعادة القراءة

يعيد أمر إعادة القراءة تحميل قائمة الملفات في الدليل. إنه مفيد إذا قامت عمليات أخرى بإنشاء أو إزالة ملفات.

قائمة الملفات

يستخدم Midnight Commander المفاتيح F1 - F10 كمختصرات لوحة مفاتيح للأوامر التي تظهر في قائمة الملفات. تسلسلات الهروب للمفاتيح الوظيفية هي قدرات terminfo kf1 إلى kf10. على الطرفيات التي لا تدعم المفاتيح الوظيفية، يمكنك تحقيق نفس الوظيفة بالضغط على مفتاح Esc ثم رقم في النطاق من 1 إلى 9 و 0 (المقابلة لـ F1 إلى F9 و F10 على التوالي).

تحتوي قائمة الملفات على الأوامر التالية (اختصارات لوحة المفاتيح بين قوسين):

Help (F1)

يستدعي عارض المساعدة النصية التشعبية المدمج. داخل عارض المساعدة، يمكنك استخدام مفتاح علامة التبويب لتحديد الرابط التالي ومفتاح Enter لتتبع هذا الرابط. تُستخدم مفاتيح Space و Backspace للتحرك للأمام والخلف في صفحة مساعدة. اضغط F1 مرة أخرى للحصول على القائمة الكاملة للمفاتيح المقبولة.

Menu (F2)

استدعاء قائمة المستخدم. توفر قائمة المستخدم طريقة سهلة لتزويد المستخدمين بقائمة وإضافة ميزات إضافية إلى Midnight Commander.

View (F3, F13)

عرض الملف المحدد حاليًا. افتراضيًا، يستدعي هذا عارض الملفات الداخلي ولكن إذا كان الخيار "Use internal view" معطلاً، فإنه يستدعي عارض ملفات خارجي محدد بواسطة متغير البيئة VIEWER. إذا كان VIEWER غير معرف، تتم محاولة متغير البيئة PAGER. إذا كان PAGER غير معرف أيضًا، يتم استدعاء الأمر "view". إذا استخدمت F13 بدلاً من ذلك، فسيتم استدعاء العارض دون إجراء أي تنسيق أو معالجة مسبقة للملف.

انظر المعلمات لعارض خارجي لشرح كيفية تحديد خيارات سطر الأوامر الموسعة للعارضات الخارجية.

Filtered View (Alt-!)

يطلب هذا الأمر أمرًا ومعاملاته (الافتراضي للمعامل هو اسم الملف المحدد حاليًا)، ويتم عرض ناتج هذا الأمر في عارض الملفات الداخلي.

Edit (F4, F14)

اضغط F4 لتحرير الملف المميز. اضغط F14 (عادةً F14) لبدء المحرر بملف جديد وفارغ. حاليًا، يستدعيان المحرر vi، أو المحرر المحدد في متغير البيئة EDITOR، أو محرر الملفات الداخلي إذا كان الخيار use_internal_edit نشطًا.

انظر المعلمات للمحرر الخارجي لشرح كيفية تحديد خيارات سطر الأوامر الموسعة للمحررات الخارجية.

Copy (F5, F15)

اضغط F5 لفتح مربع حوار إدخال لنسخ الملف المحدد حاليًا (أو الملفات المميزة، إذا كان هناك ملف واحد مميز على الأقل) إلى الدليل/اسم الملف الذي تحدده في مربع الحوار. الافتراضي هو الدليل الموجود في اللوحة غير المحددة. قد يتم تخصيص مساحة لملف الوجهة فيما يتعلق بخيار التكوين preallocate_space. خلال هذه العملية، يمكنك الضغط على C-c أو Esc لإلغاء العملية. للحصول على تفاصيل حول قناع المصدر (والذي سيكون عادةً إما * أو ^\(.*\)$ اعتمادًا على إعداد Use shell patterns) والرموز الشائعة المحتملة في الوجهة، راجع قناع النسخ/إعادة التسمية.

F15 (عادةً F15) مشابه، ولكنه افتراضيًا إلى الدليل الموجود في اللوحة المحددة. يعمل دائمًا على الملف المحدد، بغض النظر عن أي ملفات مميزة.

في بعض الأنظمة، من الممكن إجراء النسخ في الخلفية عن طريق النقر على زر الخلفية (أو الضغط على Alt-b في مربع الحوار). تُستخدم مهام الخلفية للتحكم في عملية الخلفية.

Link (C-x l)

إنشاء رابط ثابت للملف الحالي.

Absolute symlink (C-x s)

إنشاء رابط رمزي مطلق للملف الحالي.

Relative symLink (C-x v)

إنشاء رابط رمزي نسبي للملف الحالي.

للراغبين الذين لا يعرفون ما هي الروابط: إنشاء رابط لملف يشبه نسخ الملف، ولكن كل من اسم ملف المصدر واسم ملف الوجهة يمثلان نفس صورة الملف. على سبيل المثال، إذا قمت بتحرير أحد هذه الملفات، فستظهر جميع التغييرات في كلا الملفين. يسمي بعض الأشخاص الروابط بالأسماء المستعارة أو الاختصارات.

يظهر الرابط الثابت كملف حقيقي. بعد إنشائه، لا توجد طريقة لمعرفة أي منهما هو الأصلي وأي منهما هو الرابط. إذا قمت بحذف أي منهما، يظل الآخر سليمًا. من الصعب جدًا ملاحظة أن الملفات تمثل نفس الصورة. استخدم الروابط الثابتة عندما لا تريد حتى أن تعرف.

الرابط الرمزي هو مرجع لاسم الملف الأصلي. إذا تم حذف الملف الأصلي، فإن الرابط الرمزي عديم الفائدة. من السهل جدًا ملاحظة أن الملفات تمثل نفس الصورة. يعرض Midnight Commander علامة "@"- أمام اسم الملف إذا كان رابطًا رمزيًا إلى مكان ما (باستثناء الدليل، حيث يعرض علامة تلدة (~)). يتم عرض الملف الأصلي الذي يشير إليه الرابط في سطر الحالة المصغرة إذا كان الخيار Show mini-status ممكّنًا. استخدم الروابط الرمزية عندما تريد تجنب الارتباك الذي يمكن أن تسببه الروابط الثابتة.

عند الضغط على "C-x s"، سيقوم Midnight Commander تلقائيًا بملء المسار الكامل + اسم الملف للملف الأصلي واقتراح اسم للرابط. يمكنك تغيير أي منهما.

في بعض الأحيان قد ترغب في تغيير المسار المطلق للملف الأصلي إلى مسار نسبي. يبدأ المسار المطلق من الدليل الجذر:

/home/frodo/mc/mc -> /home/frodo/new/mc

يصف الرابط النسبي موقع الملف الأصلي بدءًا من موقع الرابط نفسه:

/home/frodo/mc/mc -> ../new/mc

يمكنك إجبار Midnight Commander على اقتراح مسار نسبي بالضغط على "C-x v" بدلاً من "C-x s".

Rename/Move (F6, F16)

اضغط F6 لفتح مربع حوار إدخال لنسخ الملف المحدد حاليًا (أو الملفات المميزة، إذا كان هناك ملف واحد مميز على الأقل) إلى الدليل/اسم الملف الذي تحدده في مربع الحوار. الافتراضي هو الدليل الموجود في اللوحة غير المحددة. للمزيد من التفاصيل، انظر عملية النسخ (F5)، معظم الأشياء متشابهة جدًا.

F16 (عادةً F16) مشابه، ولكنه افتراضيًا إلى الدليل الموجود في اللوحة المحددة. يعمل دائمًا على الملف المحدد، بغض النظر عن أي ملفات مميزة.

في بعض الأنظمة، من الممكن إجراء النسخ في الخلفية عن طريق النقر على زر الخلفية (أو الضغط على Alt-b في مربع الحوار). تُستخدم مهام الخلفية للتحكم في عملية الخلفية.

Mkdir (F7)

فتح مربع حوار إدخال وإنشاء الدليل المحدد.

Delete (F8)

حذف الملف المحدد حاليًا أو الملفات المميزة في اللوحة المحددة حاليًا. خلال العملية، يمكنك الضغط على C-c أو Esc لإلغاء العملية.

Quick cd (Alt-c) استخدم أمر quick cd إذا كان لديك سطر أوامر كامل وتريد الانتقال إلى دليل.

Select group (+)

يُستخدم هذا لتحديد (تمييز) مجموعة من الملفات. سيطلب Midnight Commander خيارات التحديد. عندما يكون مربع الاختيار Files only نشطًا، سيتم تحديد الملفات فقط.

اعرض المساعدة. وينطبق الشيء نفسه على مفاتيح الأسهم. يجب أن تعمل مفتاح Tab دائمًا.

إذا لم تعمل بعض المفاتيح بشكل صحيح، فلن ترى "موافق" تظهر بعد الضغط على أحد هذه المفاتيح. عندئذٍ قد ترغب في إعادة تعريفها. قم بذلك عن طريق الضغط على الزر الذي يحمل اسم هذا المفتاح (إما بالماوس أو بالضغط على Enter أو Space بعد تحديد الزر باستخدام Tab أو الأسهم). بعد ذلك، ستظهر مربع رسالة يطلب منك الضغط على هذا المفتاح. قم بذلك وانتظر حتى تختفي مربع الرسالة. إذا كنت تريد الإلغاء، فما عليك سوى الضغط على Escape مرة واحدة والانتظار.

عند الانتهاء من جميع المفاتيح، يمكنك حفظها. سيتم كتابة التعريفات للمفاتيح التي قمت بإعادة تعريفها في قسم [terminal:TERM] من ملف ~/.config/mc/ini الخاص بك (حيث TERM هو اسم الطرفية الحالية لديك). تعريفات المفاتيح التي كانت تعمل بشكل صحيح بالفعل لا يتم حفظها.

نظام الملفات الافتراضي

يمنحك هذا الخيار التحكم في إعدادات نظام الملفات الافتراضي.

تحتفظ Midnight Commander بالمعلومات المتعلقة ببعض أنظمة الملفات الافتراضية في الذاكرة لتسريع الوصول إلى الملفات في نظام الملفات (على سبيل المثال، قوائم الدلائل التي تم جلبها من خوادم FTP).

أيضًا، للوصول إلى محتويات الملفات المضغوطة (على سبيل المثال، ملفات tar المضغوطة)، تحتاج Midnight Commander إلى إنشاء ملفات مؤقتة غير مضغوطة على القرص الخاص بك.

نظرًا لأن كل من المعلومات في الذاكرة والملفات المؤقتة على القرص تستهلك الموارد، فقد ترغب في ضبط معلمات المعلومات المخزنة مؤقتًا لتقليل استخدام الموارد الخاصة بك أو لزيادة سرعة الوصول إلى أنظمة الملفات المستخدمة بشكل متكرر.

بسبب تنسيق أرشيفات tar، يحتاج نظام ملفات Tar إلى قراءة الملف بالكامل فقط لتحميل إدخالات الملف. نظرًا لأن معظم ملفات tar عادة ما تكون مضغوطة (ملفات tar العادية في طريق الانقراض)، يتعين على نظام ملفات tar فك ضغط الملف على القرص في موقع مؤقت ثم الوصول إلى الملف غير المضغوط كملف tar عادي.

الآن، بما أننا جميعًا نحب تصفح الملفات وملفات tar في جميع أنحاء القرص، فمن الشائع أن تترك ملف tar ثم تعود إليه لاحقًا. نظرًا لأن فك الضغط بطيء، ستقوم Midnight Commander بتخزين المعلومات مؤقتًا في الذاكرة لفترة محدودة. عند انتهاء المهلة، يتم تحرير جميع الموارد المرتبطة بنظام الملفات. المهلة الافتراضية محددة بدقيقة واحدة.

يسمح نظام ملفات FTP (ftpfs) لك بتصفح الدلائل على خوادم FTP البعيدة. لديها العديد من الخيارات.

كلمة مرور FTP المجهولة هي كلمة المرور المستخدمة عند تسجيل الدخول كـ "مجهول". تتطلب بعض المواقع عنوان بريد إلكتروني صالحًا. من ناحية أخرى، قد لا ترغب في تقديم عنوان بريدك الإلكتروني الحقيقي لمواقع غير موثوق بها، خاصة إذا كنت لا تستخدم تصفية البريد المزعج.

يحتفظ ftpfs بقائمة الدلائل التي يجلبها من خادم FTP في ذاكرة تخزين مؤقت. يمكن تكوين وقت انتهاء صلاحية ذاكرة التخزين المؤقت باستخدام خيار مهلة ذاكرة التخزين المؤقت لدليل ftpfs. قد يؤدي انخفاض قيمة هذا الخيار إلى إبطاء كل عملية على ftpfs لأن كل عملية ستتطلب إرسال طلب إلى خادم FTP.

يمكنك تحديد مضيف وكيل FTP للقيام بعمليات FTP. لاحظ أن معظم جدران الحماية الحديثة شفافة تمامًا على الأقل لـ FTP السلبي (انظر أدناه)، لذا تعتبر وكلاء FTP قديمة.

إذا لم يتم تعيين استخدام وكيل FTP دائمًا، يمكنك استخدام علامة التعجب لتمكين الوكيل لمضيفات معينة. انظر نظام ملفات FTP للحصول على أمثلة.

إذا تم تعيين هذا الخيار، فسيقوم البرنامج بشيئين: استشارة الملف /etc/mc/mc.no_proxy للأسطر التي تحتوي على أسماء مضيفات محلية (إذا بدأ اسم المضيف بنقطة، فيفترض أنه نطاق) وافتراض أن أي أسماء مضيفات بدون نقاط في أسمائها يمكن الوصول إليها مباشرة. سيتم الوصول إلى جميع المضيفات الأخرى عبر وكيل FTP المحدد.

يمكنك تمكين استخدام ملف ~/.netrc، الذي يحتفظ بأسماء تسجيل الدخول وكلمات المرور لخوادم FTP. انظر netrc (5) لوصف تنسيق .netrc.

استخدام الوضع السلبي يتيح استخدام وضع FTP السلبي، حيث تبدأ اتصال نقل البيانات من قبل العميل، وليس من قبل الخادم. يوصى بهذا الخيار وهو ممكّن افتراضيًا. إذا تم إيقاف تشغيل هذا الخيار، يتم بدء اتصال البيانات بواسطة الخادم. قد لا يعمل هذا مع بعض جدران الحماية.

حفظ الإعداد

عند بدء التشغيل، تحاول Midnight Commander تحميل معلومات التهيئة من الملف ~/.config/mc/ini. إذا لم يكن هذا الملف موجودًا، يتم استخدام الملف الخاص بالنظام /etc/mc/mc.ini. إذا لم يكن هذا الملف موجودًا، يتم استخدام الملف الخاص بالنظام /usr/share/mc/mc.ini. إذا لم يكن هذا الملف موجودًا، تستخدم MC الإعدادات الافتراضية.

يقوم أمر حفظ الإعداد بإنشاء الملف ~/.config/mc/ini عن طريق حفظ الإعدادات الحالية لقوائم Left و Right و Options.

إذا قمت بتنشيط خيار حفظ الإعداد تلقائيًا، فستقوم MC دائمًا بحفظ الإعدادات الحالية عند الخروج.

توجد أيضًا إعدادات لا يمكن تغييرها من القوائم. لتغيير هذه الإعدادات، عليك تحرير ملف الإعدادات باستخدام محرر النصوص المفضل لديك. انظر قسم الإعدادات الخاصة لمزيد من المعلومات.

تنفيذ أوامر نظام التشغيل

يمكنك تنفيذ الأوامر عن طريق كتابتها مباشرة في سطر الإدخال الخاص بـ Midnight Commander، أو عن طريق تحديد البرنامج الذي تريد تنفيذه باستخدام شريط التحديد في أحد اللوحات والضغط على Enter.

إذا ضغطت على Enter فوق ملف غير قابل للتنفيذ، فإن Midnight Commander يتحقق من امتداد الملف المحدد مقابل الامتدادات الموجودة في ملف الامتدادات. إذا تم العثور على تطابق، يتم تنفيذ الرمز المرتبط بهذا الامتداد. يتم إجراء توسيع ماكرو بسيط جدًا قبل تنفيذ الأمر.

الأمر الداخلي cd

يتم تفسير الأمر cd بواسطة Midnight Commander، ولا يتم تمريره إلى shell الأوامر للتنفيذ. وبالتالي قد لا يتعامل مع جميع توسيعات الماكرو والتعويضات اللطيفة التي يقوم بها shell الخاص بك، على الرغم من أنه يقوم ببعضها:

استبدال العلامة ~ (tilde). سيتم استبدال (~) بدليل المنزل الخاص بك، إذا قمت بإلحاق اسم مستخدم بعد العلامة ~، فسيتم استبدالها بدليل تسجيل الدخول للمستخدم المحدد.

على سبيل المثال، ~guest هو دليل المنزل للمستخدم guest، بينما ~/guest هو الدليل guest في دليل المنزل الخاص بك.

الدليل السابق. يمكنك الانتقال إلى الدليل الذي كنت فيه سابقًا باستخدام اسم الدليل الخاص '-' مثل هذا: cd -

دلائل CDPATH. إذا لم يكن الدليل المحدد للأمر cd موجودًا في الدليل الحالي، فستستخدم Midnight Commander القيمة الموجودة في متغير البيئة CDPATH للبحث عن الدليل في أي من الدلائل المسماة.

على سبيل المثال، يمكنك تعيين متغير CDPATH الخاص بك إلى ~/src:/usr/src، مما يسمح لك بتغيير دليلك إلى أي من الدلائل الموجودة داخل دلائل ~/src و /usr/src، من أي مكان في نظام الملفات باستخدام اسمه النسبي (على سبيل المثال، يمكن لـ cd linux نقلك إلى /usr/src/linux).

استبدال الماكرو

عند الوصول إلى قائمة مستخدم، أو تنفيذ أمر يعتمد على الامتدادات، أو تشغيل أمر من سطر أوامر الإدخال، يحدث استبدال ماكرو بسيط.

الماكروات هي:

%i
مسافة بادئة من الفراغ، تساوي موضع عمود المؤشر. لقائمة التحرير فقط.
%y
نوع الصيغة للملف الحالي. لقائمة التحرير فقط.
%k
اسم ملف الكتلة.
%e
اسم ملف الخطأ.
%m
اسم القائمة الحالية.
%f و %p
في قائمة المستخدم لمدير الملفات: اسم الملف الحالي في اللوحة المحددة. في قائمة المستخدم لـ mcedit: اسم الملف المفتوح.
%x
امتداد اسم الملف الحالي.
%b
اسم الملف الحالي بدون امتداد.
%d
اسم الدليل الحالي.
%F
الملف الحالي في اللوحة غير المحددة.
%D
اسم دليل اللوحة غير المحددة.
%t
الملفات الموسومة حاليًا.
%T
الملفات الموسومة في اللوحة غير المحددة.
%u و %U
مشابهة لماكرو %t و %T، ولكن بالإضافة إلى ذلك، يتم إلغاء تحديد الملفات. يمكنك استخدام هذا الماكرو مرة واحدة فقط لكل إدخال ملف قائمة أو إدخال ملف امتداد، لأنه في المرة القادمة لن تكون هناك ملفات موسومة.
%s و %S
الملفات المحددة: الملفات الموسومة إذا كان هناك أي منها. بخلاف ذلك، الملف الحالي.
%cd
هذا ماكرو خاص يستخدم لتغيير الدليل الحالي إلى الدليل المحدد أمامه. يستخدم بشكل أساسي كواجهة لنظام الملفات الافتراضي.
%view
يستخدم هذا الماكرو لاستدعاء العارض الداخلي. يمكن استخدام هذا الماكرو بمفرده، أو مع وسائط. إذا قمت بتمرير أي وسائط لهذا الماكرو، فيجب أن تكون محاطة بأقواس.
الوسائط هي: ascii لفرض العارض في وضع ascii؛ hex لفرض العارض في وضع hex؛ nroff لإخبار العارض بأنه يجب أن يفسر تسلسلات nroff الجريئة والتسطير؛ unformatted لإخبار العارض بعدم تفسير أوامر nroff لجعل النص جريئًا أو مسطرًا.
%%
حرف %
%{some text}
يطالب بالاستبدال. يتم عرض مربع إدخال ويستخدم النص الموجود داخل الأقواس كطلب. يتم استبدال الماكرو بالنص الذي يكتبه المستخدم. يمكن للمستخدم الضغط على Esc أو F10 للإلغاء. هذا الماكرو لا يعمل في سطر الأوامر حتى الآن.
%var{ENV:default}
إذا تم إلغاء تعيين متغير البيئة ENV، فسيتم استبداله بـ default. بخلاف ذلك، سيتم استبداله بقيمة ENV.

دعم الـ subshell

دعم الـ subshell هو خيار وقت الترجمة، يعمل مع الـ shells: bash، ash (BusyBox و Debian)، (o/m)ksh، tcsh، zsh، و fish.

عندما يكون دعم الـ subshell نشطًا، ستقوم Midnight Commander بتشغيل نسخة متزامنة من الـ shell الخاص بك (المعرف في متغير SHELL وإذا لم يتم تعريفه، فالذي في ملف /etc/passwd) وتشغيله في طرفية زائفة، بدلاً من استدعاء shell جديد في كل مرة تقوم فيها بتنفيذ أمر، سيتم تمرير الأمر إلى الـ subshell

TERMINAL DATABASES

Midnight Commander provides a way to fix your system terminal database without requiring root privileges. Midnight Commander searches in the system initialization file (the mc.lib file located in Midnight Commander's library directory) and in the ~/.config/mc/ini file for the section "terminal:your-terminal-name" and then for the section "terminal:general", each line of the section contains a key symbol that you want to define, followed by an equal sign and the definition for the key. You can use the special \e form to represent the escape character and the ^x to represent the control-x character.

The possible key symbols are:

f0 to f20     Function keys f0-f20
bs            backspace
home          home key
end           end key
up            up arrow key
down          down arrow key
left          left arrow key
right         right arrow key
pgdn          page down key
pgup          page up key
insert        the insert character
delete        the delete character
complete      to do completion

For example, to define the key insert to be the Escape + [ + O + p, you set this in the ini file:

insert=\e[Op

Also now you can use extended learn keys. For example:

    ctrl-alt-right=\e[[1;6C
    ctrl-alt-left=\e[[1;6D

This means that ctrl+alt+left sends a \e[[1;6D escape sequence and therefore Midnight Commander interprets "\e[[1;6D" as C-Alt-Left.

The complete key symbol represents the escape sequences used to invoke the completion process, this is invoked with Alt-tab, but you can define other keys to do the same work (on those keyboard with tons of nice and unused keys everywhere).

FILES

Full paths below may vary between installations. They are also affected by the MC_DATADIR environment variable. If it's set, its value is used instead of /usr/share/mc in the paths below.

/usr/share/mc/help/mc.hlp

The help file for the program.

/usr/share/mc/mc.ext.ini

The default system-wide extensions file.

~/.config/mc/mc.ext.ini

User's own extension, view configuration and edit configuration file. They override the contents of the system wide files if present.

/etc/mc/mc.ini
/usr/share/mc/mc.ini

System-wide setup files for Midnight Commander, used only if the user doesn't have his own ~/.config/mc/ini file. If /etc/mc/mc.ini exists, /usr/share/mc/mc.ini isn't used.

/usr/share/mc/mc.lib

Global settings for Midnight Commander. Settings in this file affect all users, whether they have ~/.config/mc/ini or not. Currently, only terminal settings are loaded from mc.lib.

~/.config/mc/ini

User's own setup. If this file is present then the setup is loaded from here instead of the system-wide startup file.

/usr/share/mc/hints/mc.hint

This file contains the hints displayed by the program.

/usr/share/mc/mc.menu

This file contains the default system-wide applications menu.

~/.config/mc/menu

User's own application menu. If this file is present it is used instead of the system-wide applications menu.

~/.cache/mc/Tree

The directory list for the directory tree and tree view features.

~/.local/share/mc.menu

Local user-defined menu. If this file is present, it is used instead of the home or system-wide applications menu.

To change default root directory of MC, you can use MC_PROFILE_ROOT environment variable. The value of MC_PROFILE_ROOT must be an absolute path. If MC_PROFILE_ROOT is unset or empty, HOME variable is used. If HOME is unset or empty, MC directories are get from GLib library.
