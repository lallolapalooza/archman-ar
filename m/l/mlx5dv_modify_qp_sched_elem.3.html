الاسم

mlx5dv_modify_qp_sched_elem - ربط QP مع عنصر جدولة طالب و/أو مستجيب

ملخص

int mlx5dv_modify_qp_sched_elem(struct ibv_qp *qp,
                struct mlx5dv_sched_leaf *requestor,
                struct mlx5dv_sched_leaf *responder);

الوصف

يسمح عنصر جدولة QP (SE) بربط QP بشجرة SE. يتم وصف SE في صفحة الدليل mlx5dv_sched_node_create(3).

افتراضيًا، لا يتم ربط QPs بـ SE. الإعداد الافتراضي هو ضمان تخصيص عرض النطاق الترددي العادل بدون حد أقصى لعرض النطاق الترددي.

يمكن ربط QP بعنصر SE طالب و/أو مستجيب وفقًا لتعريف مواصفات IB.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0 أو قيمة errno عند الفشل.

انظر أيضًا

mlx5dv_sched_node_create(3)
