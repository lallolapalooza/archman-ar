mlx5dv_alloc_var / mlx5dv_free_var(3) دليل وظائف المكتبة mlx5dv_alloc_var / mlx5dv_free_var(3)

الاسم

mlx5dv_alloc_var - تخصيص VAR

mlx5dv_free_var - تحرير VAR

المُلَخَّص

#include <infiniband/mlx5dv.h>
struct mlx5dv_var *
mlx5dv_alloc_var(struct ibv_context *context, uint32_t flags);
void mlx5dv_free_var(struct mlx5dv_var *dv_var);

الوصف

إنشاء / تحرير VAR يمكن استخدامه لبعض أوامر الجهاز عبر واجهة DEVX.

تسمح واجهة DEVX بالوصول المباشر من مساحة المستخدم إلى مشغل جهاز mlx5، وتكون معلومات VAR مطلوبة لعدد قليل من الأوامر المتعلقة بـ Virtio.

الحُجَج

context
سياق جهاز RDMA للعمل عليه.
flags
علامات التخصيص لـ UAR.

dv_var

struct mlx5dv_var {
    uint32_t page_id;
    uint32_t length;
    off_t mmap_off;
    uint64_t comp_mask;
};
page_id
معرف صفحة الجهاز الذي سيتم استخدامه.
length
معامل طول mmap الذي سيتم استخدامه لربط VA بمدخل VAR المخصص.
mmap_off
معامل إزاحة mmap الذي سيتم استخدامه لربط VA بمدخل VAR المخصص.

قيمة الإرجاع

عند النجاح، تُرجع mlx5dv_alloc_var مؤشرًا إلى VAR المنشأ، وفي حالة الخطأ، تُرجع NULL وسيتم تعيين errno.

انظر أيضًا

mlx5dv_open_device, mlx5dv_devx_obj_create
