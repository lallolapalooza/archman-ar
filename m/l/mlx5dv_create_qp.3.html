NAME

mlx5dv_create_qp, mlx5dv_create_qp_ex - create a queue pair

SYNOPSIS

#include <infiniband/mlx5dv.h>

struct ibv_qp *
mlx5dv_create_qp(struct ibv_pd *pd, struct mlx5dv_qp_init_attr *qp_init_attr);

struct ibv_qp *
mlx5dv_create_qp_ex(struct ibv_context *context,
    struct mlx5dv_qp_init_attr_ex *qp_init_attr_ex);

DESCRIPTION

The mlx5dv_create_qp() function creates a queue pair (QP) associated with the protection domain pd. The QP attributes and settings are defined by the qp_init_attr structure.

The mlx5dv_create_qp_ex() function is an extended version that allows specifying the context directly and uses a different initialization attributes structure qp_init_attr_ex.

ARGUMENTS

pd
A pointer to the protection domain under which the QP will be created.
qp_init_attr
A pointer to a mlx5dv_qp_init_attr structure that specifies the QP attributes. This structure includes fields like qp_type, sq_sig_all, send_cq, recv_cq, srq, and extended attributes via the dv_cq_mod and comp_mask fields.
context
A pointer to the IBV context.
qp_init_attr_ex
A pointer to a mlx5dv_qp_init_attr_ex structure, which is an extended version of mlx5dv_qp_init_attr, providing more flexibility and options for QP creation.

NOTES

These functions are specific to the Mellanox MLX5 driver. They extend the functionality of the standard ibv_create_qp(3) function by providing more fine-grained control over QP creation, especially for advanced features and performance tuning.

The comp_mask field in mlx5dv_qp_init_attr and mlx5dv_qp_init_attr_ex allows enabling specific MLX5 extensions. For example, MLX5DV_QP_INIT_ATTR_MASK_CQ_HANDLERS can be used to enable direct handling of completion queue events.

RETURN VALUE

On success, these functions return a pointer to the created ibv_qp structure. On failure, they return NULL and set errno to indicate the error.

SEE ALSO

ibv_query_device_ex(3), ibv_create_qp_ex(3), mlx5dv_query_device(3)

الاسم

mlx5dv_create_qp, mlx5dv_create_qp_ex - إنشاء زوج صفوف

الملخص

#include <infiniband/mlx5dv.h>

struct ibv_qp *
mlx5dv_create_qp(struct ibv_pd *pd, struct mlx5dv_qp_init_attr *qp_init_attr);

struct ibv_qp *
mlx5dv_create_qp_ex(struct ibv_context *context,
    struct mlx5dv_qp_init_attr_ex *qp_init_attr_ex);

الوصف

تقوم الدالة mlx5dv_create_qp() بإنشاء زوج صفوف (QP) مرتبط بنطاق الحماية pd. يتم تحديد سمات وإعدادات زوج الصفوف بواسطة البنية qp_init_attr.

الدالة mlx5dv_create_qp_ex() هي نسخة موسعة تسمح بتحديد السياق مباشرة وتستخدم بنية سمات تهيئة مختلفة qp_init_attr_ex.

المعاملات

pd
مؤشر إلى نطاق الحماية الذي سيتم إنشاء زوج الصفوف تحته.
qp_init_attr
مؤشر إلى بنية mlx5dv_qp_init_attr تحدد سمات زوج الصفوف. تتضمن هذه البنية حقولًا مثل qp_type، sq_sig_all، send_cq، recv_cq، srq، وسمات موسعة عبر حقول dv_cq_mod و comp_mask.
context
مؤشر إلى سياق IBV.
qp_init_attr_ex
مؤشر إلى بنية mlx5dv_qp_init_attr_ex، وهي نسخة موسعة من mlx5dv_qp_init_attr، توفر مرونة وخيارات أكبر لإنشاء زوج الصفوف.

ملاحظات

هذه الدوال خاصة ببرنامج تشغيل Mellanox MLX5. وهي توسع وظائف الدالة القياسية ibv_create_qp(3) من خلال توفير تحكم أدق في إنشاء زوج الصفوف، خاصة للميزات المتقدمة وضبط الأداء.

يسمح حقل comp_mask في mlx5dv_qp_init_attr و mlx5dv_qp_init_attr_ex بتمكين ملحقات MLX5 محددة. على سبيل المثال، يمكن استخدام MLX5DV_QP_INIT_ATTR_MASK_CQ_HANDLERS لتمكين المعالجة المباشرة لأحداث قائمة الانتظار.

قيمة الإرجاع

عند النجاح، تعيد هذه الدوال مؤشرًا إلى بنية ibv_qp التي تم إنشاؤها. عند الفشل، تعيد NULL وتضبط errno لتحديد الخطأ.

انظر أيضًا

ibv_query_device_ex(3)، ibv_create_qp_ex(3)، mlx5dv_query_device(3)
