mlx5dv_create_mkey / mlx5dv_destroy_mkey(3) دليل وظائف المكتبة mlx5dv_create_mkey / mlx5dv_destroy_mkey(3)

الاسم

mlx5dv_create_mkey - إنشاء مفتاح mkey غير مباشر

mlx5dv_destroy_mkey - تدمير مفتاح mkey غير مباشر

الملخص

#include <infiniband/mlx5dv.h>
struct mlx5dv_mkey_init_attr {
    struct ibv_pd   *pd;
    uint32_t    create_flags;
    uint16_t    max_entries;
};
struct mlx5dv_mkey {
    uint32_t    lkey;
    uint32_t    rkey;
};
struct mlx5dv_mkey *
mlx5dv_create_mkey(struct mlx5dv_mkey_init_attr *mkey_init_attr);
int mlx5dv_destroy_mkey(struct mlx5dv_mkey *mkey);

الوصف

إنشاء / تدمير مفتاح mkey غير مباشر.

إنشاء مفتاح mkey غير مباشر لتمكين التطبيق من استخدام وظائف جهاز معينة.

الوسائط

##mkey_init_attr##

pd
مجال حماية ibv.
create_flags
MLX5DV_MKEY_INIT_ATTR_FLAGS_INDIRECT: يتم إنشاء مفتاح mkey غير مباشر. MLX5DV_MKEY_INIT_ATTR_FLAGS_BLOCK_SIGNATURE: تمكين دعم تفريغ توقيع الكتلة لمفتاح mkey. MLX5DV_MKEY_INIT_ATTR_FLAGS_CRYPTO: تمكين دعم تفريغ التشفير لمفتاح mkey. يعني تعيين هذا العلم أن عمليات التشفير سيتم إجراؤها وبالتالي يجب تكوينها. أي، إذا تم تعيين هذا العلم ولم يتم تكوين MKey لخصائص التشفير باستخدام mlx5dv_wr_set_mkey_crypto()، فسيفشل تشغيل المرور باستخدام MKey، مما يؤدي إلى توليد CQE مع خطأ. MLX5DV_MKEY_INIT_ATTR_FLAGS_UPDATE_TAG: تمكين دعم تحديث العلامة (tag) لمفتاح mkey. يسمح تعيين هذا العلم للتطبيق بتعيين علامة MKey بعد إنشاء MKey. إذا لم يكن النظام الأساسي يدعم تحديث علامة MKey، فسيفشل إنشاء MKey. MLX5DV_MKEY_INIT_ATTR_FLAGS_REMOTE_INVALIDATE: تمكين دعم الإلغاء عن بعد (remote invalidation) لمفتاح mkey.
max_entries
العدد الأقصى المطلوب للمدخلات المشار إليها بواسطة مفتاح mkey غير المباشر هذا. ستقوم الوظيفة بتحديث mkey_init_attr->max_entries بالقيمة الفعلية لمفتاح mkey الذي تم إنشاؤه؛ ستكون أكبر من أو تساوي القيمة المطلوبة.

قيمة الإرجاع

عند النجاح، ستعيد mlx5dv_create_mkey هيكل mlx5dv_mkey جديدًا. عند حدوث خطأ، سيتم إرجاع NULL وسيتم تعيين errno.

عند النجاح، يتم إرجاع 0 للتدمير، أو قيمة errno عند حدوث فشل.

ملاحظات

لجعل هذه الوظيفة تعمل، يجب فتح سياق DEVX باستخدام mlx5dv_open_device.

مفتاح mkey غير المباشر الذي تم إنشاؤه لا يمكنه العمل مع ميزة التبعثر إلى CQE، ضع في اعتبارك mlx5dv_create_qp() مع MLX5DV_QP_CREATE_DISABLE_SCATTER_TO_CQE للرسائل الصغيرة.

انظر أيضا

mlx5dv_open_device(3)، mlx5dv_create_qp(3)
