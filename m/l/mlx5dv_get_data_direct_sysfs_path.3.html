mlx5dv_get_data_direct_sysfs_path(3) دليل وظائف المكتبة mlx5dv_get_data_direct_sysfs_path(3)

الاسم

mlx5dv_get_data_direct_sysfs_path - الحصول على مسار sysfs لجهاز البيانات المباشر

الشكل

#include <infiniband/mlx5dv.h>
int mlx5dv_get_data_direct_sysfs_path(struct ibv_context *context, char *buf,
                                      size_t buf_len)

الوصف

الحصول على مسار sysfs لجهاز البيانات المباشر المرتبط بـ context المقدم.

يسمح هذا للتطبيق باكتشاف ما إذا كان / أي جهاز بيانات مباشر مرتبط بـ context المقدم.

المعاملات

context
سياق جهاز RDMA للعمل عليه.
buf
المخزن المؤقت الذي سيتم وضع مسار sysfs لجهاز البيانات المباشر المرتبط فيه.
buf_len
طول المخزن المؤقت.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0 أو قيمة errno عند الفشل.

الأخطاء

يجب اعتبار قيم الأخطاء المحددة أدناه.

ENODEV
لا يوجد جهاز بيانات مباشر مرتبط بـ *context* المقدم.
ENOSPC
حجم المخزن المؤقت المدخل صغير جدًا لاستيعاب مسار sysfs الكامل.

ملاحظات

عند النجاح، يجب على المتصل إضافة البادئة /sys/ للحصول على مسار sysfs الكامل.
