MLX4DV_QUERY_DEVICE(3) دليل وظائف المكتبة MLX4DV_QUERY_DEVICE(3)

الاسم

mlx4dv_query_device - الاستعلام عن قدرات الجهاز الخاصة بـ mlx4

المُلَخَّص

#include <infiniband/mlx4dv.h>

int mlx4dv_query_device(struct ibv_context *ctx_in,
                        struct mlx4dv_context *attrs_out);

الوصف

mlx4dv_query_device() يستعلم عن معلومات الجهاز الخاصة بـ mlx4 التي يمكن استخدامها عبر واجهة الأفعال المباشرة.

ترجع هذه الدالة قناع إصدار وتوافق. يمثل الإصدار تنسيق الهياكل الداخلية للجهاز التي تكشف عنها mlx4dv.h. تتم معالجة الإضافات المستقبلية للحقول الجديدة إلى الهياكل الحالية بواسطة حقل comp_mask.

struct mlx4dv_context {
uint8_t         version;
uint32_t        max_inl_recv_sz; /* الحد الأقصى المدعوم لحجم الاستلام المضمن */
uint64_t        comp_mask;
};

قيمة الإرجاع

0 عند النجاح أو قيمة errno عند الفشل (والتي تشير إلى سبب الفشل).

ملاحظات


* قناع التوافق (comp_mask) هو حقل إدخال/إخراج.
