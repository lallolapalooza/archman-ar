mlx5dv_devx_umem_reg, mlx5dv_devx_umem_dereg(3) دليل الدوال المكتبية mlx5dv_devx_umem_reg, mlx5dv_devx_umem_dereg(3)

الاسم

mlx5dv_devx_umem_reg - تسجيل ذاكرة مستخدم لاستخدامها بواسطة واجهة devx

mlx5dv_devx_umem_reg_ex - تسجيل ذاكرة مستخدم لاستخدامها بواسطة واجهة devx

mlx5dv_devx_umem_dereg - إلغاء تسجيل كائن UMEM devx

الشكل

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_umem {
    uint32_t umem_id;
};
struct mlx5dv_devx_umem *
mlx5dv_devx_umem_reg(struct ibv_context *context, void *addr, size_t size,
             uint32_t access)
struct mlx5dv_devx_umem_in {
    void *addr;
    size_t size;
    uint32_t access;
    uint64_t pgsz_bitmap;
    uint64_t comp_mask;
    int dmabuf_fd;
};
struct mlx5dv_devx_umem *
mlx5dv_devx_umem_reg_ex(struct ibv_context *ctx, struct mlx5dv_devx_umem_in *umem_in);
int mlx5dv_devx_umem_dereg(struct mlx5dv_devx_umem *dv_devx_umem)

الوصف

تسجيل أو إلغاء تسجيل ذاكرة مستخدم لاستخدامها بواسطة واجهة devx.

يقوم أمر التسجيل بكشف كائن UMEM DEVX لتسجيل ذاكرة المستخدم لـ DMA. يأخذ واجهة برمجة التطبيقات لتسجيل ذاكرة المستخدم كمدخلات عنوان المستخدم وطوله وعلامات الوصول، ويوفر للمستخدم كائنًا يحتوي على معرف UMEM الذي أعاده البرنامج الثابت لهذه الذاكرة المسجلة.

يمكن للمستخدم طلب أحجام صفحات معينة للعنوان والطول المحددين، وفي هذه الحالة يجب استخدام mlx5dv_devx_umem_reg_ex(). في حالة عدم تمكن النواة من العثور على حجم صفحة مطابق من خريطة البت umem_in->pgsz_bitmap المعطاة، ستفشل واجهة برمجة التطبيقات.

سيستخدم المستخدم معرف UMEM هذا في أوامر الجهاز المباشرة التي تستخدم هذه الذاكرة بدلاً من قائمة العناوين الفعلية، على سبيل المثال عند mlx5dv_devx_obj_create لإنشاء QP.

المعلمات

context
سياق جهاز RDMA لإنشاء الإجراء.
addr
عنوان الذاكرة الذي سيتم تسجيله.
size
حجم المخزن المؤقت لـ *addr*.
access
سمات الحماية المطلوبة للذاكرة؛ وهي إما 0 أو OR البتية لواحدة أو أكثر من enum ibv_access_flags.
umem_in
هيكل يحمل حزمة المعلمات.
pgsz_bitmap
يمثل أحجام الصفحات المطلوبة. سيفشل إنشاء UMEM إذا لم يكن من الممكن إنشاؤه بهذه الأحجام.
comp_mask
علامات تشير إلى الحقول الإضافية.
dmabuf_fd
إذا تم تعيين MLX5DV_UMEM_MASK_DMABUF في comp_mask، فيجب أن تكون هذه القيمة FD لـ dmabuf. في هذا الوضع، يتم استخدام dmabuf كذاكرة داعمة لإنشاء umem منها. يجب أن يكون dmabuf قابلاً للتثبيت. يتم تفسير addr على أنه الإزاحة البادئة لـ dmabuf.

قيمة الإرجاع

عند النجاح، ستعيد mlx5dv_devx_umem_reg / mlx5dv_devx_umem_reg_ex كائن struct mlx5dv_devx_umem جديدًا، وعند حدوث خطأ، سيتم إرجاع NULL وسيتم تعيين errno.

mlx5dv_devx_umem_dereg تعيد 0 عند النجاح، أو قيمة errno عند الفشل (والتي تشير إلى سبب الفشل).
