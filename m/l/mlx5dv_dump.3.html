MLX5DV_DUMP API(3) دليل مبرمج mlx5 MLX5DV_DUMP API(3)

الاسم

mlx5dv_dump_dr_domain - تفريغ نطاق DR

mlx5dv_dump_dr_table - تفريغ جدول DR

mlx5dv_dump_dr_matcher - تفريغ مطابقة DR

mlx5dv_dump_dr_rule - تفريغ قاعدة DR

ملخص

#include <infiniband/mlx5dv.h>
int mlx5dv_dump_dr_domain(FILE *fout, struct mlx5dv_dr_domain *domain);
int mlx5dv_dump_dr_table(FILE *fout, struct mlx5dv_dr_table *table);
int mlx5dv_dump_dr_matcher(FILE *fout, struct mlx5dv_dr_matcher *matcher);
int mlx5dv_dump_dr_rule(FILE *fout, struct mlx5dv_dr_rule *rule);

الوصف

تسمح واجهة برمجة التطبيقات (API) الخاصة بالتفريغ (mlx5dv_dump_*) بتفريغ موارد rdma-core الموجودة إلى الملف المقدم. تنسيق ملف الإخراج خاص بالمورد.

mlx5dv_dump_dr_domain() تقوم بتفريغ خصائص كائن نطاق DR إلى ملف محدد.

mlx5dv_dump_dr_table() تقوم بتفريغ خصائص كائن جدول DR إلى ملف محدد.

mlx5dv_dump_dr_matcher() تقوم بتفريغ خصائص كائن مطابقة DR إلى ملف محدد.

mlx5dv_dump_dr_rule() تقوم بتفريغ خصائص كائن قاعدة DR إلى ملف محدد.

قيمة الإرجاع

تعيد استدعاءات واجهة برمجة التطبيقات (API) القيمة 0 عند النجاح، أو قيمة errno عند الفشل (مما يشير إلى سبب الفشل). الاستدعاءات تكون مانعة - تعود الدالة فقط عندما يتم كتابة جميع معلومات الموارد ذات الصلة إلى الملف.
