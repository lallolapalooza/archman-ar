mlx5dv_devx_create_event_channel, mlx5dv_devx_destroy_event_channel(3) دليل وظائف المكتبة mlx5dv_devx_create_event_channel, mlx5dv_devx_destroy_event_channel(3)

الاسم

mlx5dv_devx_create_event_channel - إنشاء قناة أحداث لاستخدامها للأحداث غير المتزامنة لـ DEVX.

mlx5dv_devx_destroy_event_channel - تدمير قناة أحداث DEVX.

الملخص

#include <infiniband/mlx5dv.h>
struct mlx5dv_devx_event_channel {
    int fd;
};
struct mlx5dv_devx_event_channel *
mlx5dv_devx_create_event_channel(struct ibv_context *context,
                                 enum mlx5dv_devx_create_event_channel_flags flags)
void mlx5dv_devx_destroy_event_channel(struct mlx5dv_devx_event_channel *event_channel)

الوصف

إنشاء أو تدمير قناة لاستخدامها للأحداث غير المتزامنة لـ DEVX.

يقوم استدعاء الإنشاء بكشف كائن mlx5dv_devx_event_channel يمكن استخدامه لقراءة أحداث DEVX غير المتزامنة. هذا يسمح للتطبيق بالاشتراك في تلقي أحداث الجهاز وبمجرد حدوث حدث، قراءته من هذا الكائن.

المعاملات

context
سياق جهاز RDMA لإنشاء القناة عليه.
flags
MLX5DV_DEVX_CREATE_EVENT_CHANNEL_FLAGS_OMIT_EV_DATA: تجاهل بيانات الحدث في هذه القناة.

قيمة الإرجاع

عند النجاح، ستعيد mlx5dv_devx_create_event_channel كائن struct mlx5dv_devx_event_channel جديدًا، وفي حالة الخطأ، ستعيد NULL وسيتم تعيين errno.

انظر أيضًا

mlx5dv_open_device(3)، mlx5dv_devx_obj_create(3)
