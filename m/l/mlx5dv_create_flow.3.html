mlx5dv_create_flow(3) دليل مبرمج mlx5 mlx5dv_create_flow(3)

الاسم

mlx5dv_create_flow - إنشاء قاعدة توجيه للتدفق

الشكل العام

#include <infiniband/mlx5dv.h>
struct ibv_flow *
mlx5dv_create_flow(struct mlx5dv_flow_matcher *flow_matcher,
           struct mlx5dv_flow_match_parameters *match_value,
           size_t num_actions,
           struct mlx5dv_flow_action_attr actions_attr[])

الوصف

mlx5dv_create_flow() تنشئ قاعدة توجيه للتدفق مع القدرة على تحديد خصائص برنامج تشغيل معينة.

المعاملات

يرجى الاطلاع على mlx5dv_create_flow_matcher(3) بالنسبة لـ flow_matcher و match_value.

num_actions
يحدد عدد الإجراءات التي تم تمريرها في actions_attr

actions_attr

struct mlx5dv_flow_action_attr {
    enum mlx5dv_flow_action_type type;
    union {
        struct ibv_qp *qp;
        struct ibv_counters *counter;
        struct ibv_flow_action *action;
        uint32_t tag_value;
        struct mlx5dv_devx_obj *obj;
        struct {
            struct mlx5dv_devx_obj *obj;
            uint32_t offset;
        } bulk_obj;
    };
};
type
MLX5DV_FLOW_ACTION_DEST_IBV_QP سيتم استقبال الحزم المطابقة بواسطة QP المحدد. MLX5DV_FLOW_ACTION_IBV_FLOW_ACTION إجراء التدفق الذي سيتم تطبيقه. MLX5DV_FLOW_ACTION_TAG علامة التدفق لتوفيرها في إكمال العمل. MLX5DV_FLOW_ACTION_DEST_DEVX كائن DEVX الوجهة للحزم المطابقة. MLX5DV_FLOW_ACTION_COUNTERS_DEVX كائن عداد DEVX للحزم المطابقة. MLX5DV_FLOW_ACTION_DEFAULT_MISS توجيه الحزمة إلى وجهة عدم المطابقة الافتراضية. MLX5DV_FLOW_ACTION_DROP إجراء إسقاط الحزمة المطابقة. MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET كائن عداد DEVX المجمع وإزاحته للعدادات للحزم المطابقة.
qp
QP تم تمريره، ليتم استخدامه مع type MLX5DV_FLOW_ACTION_DEST_IBV_QP.
action
إجراء تدفق، ليتم استخدامه مع type MLX5DV_FLOW_ACTION_IBV_FLOW_ACTION انظر mlx5dv_create_flow_action_modify_header(3) و mlx5dv_create_flow_action_packet_reformat(3).
tag_value
قيمة العلامة التي سيتم تمريرها في إكمال العمل، ليتم استخدامها مع type MLX5DV_FLOW_ACTION_TAG انظر ibv_create_cq_ex(3).
obj
كائن DEVX، ليتم استخدامه مع type MLX5DV_FLOW_ACTION_DEST_DEVX أو بواسطة MLX5DV_FLOW_ACTION_COUNTERS_DEVX أو بواسطة MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET.
offset
إزاحة إلى العداد المستهدف داخل كائن DEVX مجمع، ليتم استخدامه مع type MLX5DV_FLOW_ACTION_COUNTERS_DEVX_WITH_OFFSET

قيمة الإرجاع

mlx5dv_create_flow ترجع مؤشرًا إلى قاعدة التدفق التي تم إنشاؤها، وفي حالة الخطأ سيتم إرجاع NULL وسيتم تعيين errno.
