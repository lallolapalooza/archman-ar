Mail__SpamAssassin__Plugin__ASN(3pm)

الحزمة: spamassassin

التراخيص: APACHE

Mail::SpamAssassin::Plugin::ASN(3) وثائق Perl المساهمة من المستخدم Mail::SpamAssassin::Plugin::ASN(3)

الاسم

Mail::SpamAssassin::Plugin::ASN - إضافة SpamAssassin للبحث عن رقم النظام المستقل (ASN) لعنوان IP المتصل.

الملخص

loadplugin Mail::SpamAssassin::Plugin::ASN
# الإعدادات الافتراضية / الموصى بها
asn_use_geodb 1
asn_use_dns 1
asn_prefer_geodb 1
# قم بإجراء عمليات البحث وأضف علامات / رأس X-Spam-ASN
asn_lookup asn.routeviews.org _ASN_ _ASNCIDR_
asn_lookup_ipv6 origin6.asn.cymru.com _ASN_ _ASNCIDR_
add_header all ASN _ASN_ _ASNCIDR_
# قواعد لاختبار ASN أو المؤسسة
# ملاحظة: لا تستخدم القواعد التي تتحقق من بيانات تعريف رأس X-ASN،
# فإن دالة eval check_asn() فقط تعمل بشكل صحيح.
# وسيطة القاعدة هي تعبير عادي كامل للمطابقة.
# رقم ASN: GeoIP ASN أو DNS
# السلسلة المطابقة تتضمن asn_prefix إذا تم تعريفها، وعادةً
# تبدو مثل "AS1234" (DNS) أو "AS1234 Google LLC" (GeoIP)
header AS_1234 eval:check_asn('/^AS1234\b/')
# مؤسسة ASN: GeoIP ASN لديها، قد لا تكون مناطق DNS متاحة
# لاحظ الوسيطة الثانية التي تتحقق من علامة MYASN (الافتراضي هو ASN)
asn_lookup myview.example.com _MYASN_ _MYASNCIDR_
header AS_GOOGLE eval:check_asn('/\bGoogle\b/i', 'MYASN')

الوصف

تستخدم هذه الإضافة عمليات بحث DNS لخدمات منطقة DNS خارجية مثل "https://www.routeviews.org/" للقيام بالعمل الفعلي. يرجى التأكد من أن استخدامك للإضافة لا يفرط في تحميل بنيتهم التحتية - هذا يعني بشكل عام أنه يجب عليك عدم استخدام هذه الإضافة في بيئة ذات حجم كبير أو أنه يجب عليك استخدام نسخة محلية من المنطقة (انظر "ftp://ftp.routeviews.org/dnszones/"). قد يتم استخدام مناطق أخرى مماثلة.

يتم دعم عمليات بحث قاعدة بيانات GeoDB (GeoIP ASN) منذ SpamAssassin 4.0 ويوصى باستخدامها بدلاً من استعلامات DNS، ما لم يكن "_ASNCIDR_" مطلوبًا.

علامات القالب

تسمح لك هذه الإضافة بإنشاء علامات قوالب تحتوي على رقم AS الخاص بـ IP المتصل ومعلومات التوجيه الخاصة بهذا الرقم AS.

إذا استخدمت add_header كما هو موثق في المثال أعلاه، فسيتم إضافة حقل رأس يبدو كالتالي:

X-Spam-ASN: AS24940 213.239.192.0/18

حيث "24940" هو ASN و "213.239.192.0/18" هو المسار الذي أعلنت عنه ASN والذي جاء منه عنوان IP المتصل. إذا أعلنت ASN عن شبكات متعددة (أكثر/أقل تحديدًا)، فسيتم إضافتها جميعًا إلى علامة "_ASNCIDR_"، مفصولة بمسافات، على سبيل المثال:

X-Spam-ASN: AS1680 89.138.0.0/15 89.139.0.0/16

لاحظ أن الحرف "AS" قبل ASN في علامة _ASN_ قابل للتكوين من خلال التوجيه asn_prefix وقد يتم تعيينه إلى سلسلة فارغة.

"_ASNCIDR_" غير متاح مع عمليات بحث GeoDB ASN المحلية.

إعدادات المستخدم

clear_asn_lookups
يزيل جميع إدخالات asn_lookup أو asn_lookup_ipv6 المعلنة سابقًا من قائمة الاستعلامات.
asn_prefix 'prefix_string' (الافتراضي: 'AS')
يتم إضافة السلسلة المحددة في الوسيطة إلى كل ASN عند تخزينه كعلامة. هذه البادئة زائدة عن الحاجة، ولكن تم الاحتفاظ بقيمتها الافتراضية 'AS' للتوافق مع الإصدارات السابقة من SpamAssassin قبل 3.4.0. إعداد معقول هو سلسلة فارغة. قد تكون الوسيطة (ولكن ليس بالضرورة) محاطة بعلامات اقتباس فردية أو مزدوجة للوضوح.

تعريفات القواعد والإعدادات المميزة

asn_lookup asn-zone.example.com [ _ASNTAG_ _ASNCIDRTAG_ ]
استخدم هذا للبحث عن معلومات ASN في المنطقة المحددة لأول عنوان IPv4 خارجي وإضافة رقم AS إلى العلامة الأولى المحددة ومعلومات التوجيه إلى العلامة الثانية المحددة.

إذا لم يتم تحديد علامات، فسيتم إضافة رقم AS إلى علامة _ASN_ وسيتم إضافة معلومات التوجيه إلى علامة _ASNCIDR_. يجب عليك تحديد إما عدم تحديد أسماء العلامات أو كليهما. يجب أن تبدأ أسماء العلامات وتنتهي بشرطة سفلية.

إذا استخدمت اثنتان أو أكثر من asn_lookups نفس مجموعة علامات القوالب، فسيتم إلحاق نتائج عمليات البحث الخاصة بها بقيم علامات القالب بترتيب غير محدد. سيتم تجاهل النتائج المكررة عند دمج النتائج. بنفس الطريقة، يمكنك أيضًا استخدام نفس علامة القالب لكل من علامة رقم AS وعلامة معلومات التوجيه.

أمثلة:

asn_lookup asn.routeviews.org
asn_lookup asn.routeviews.org _ASN_ _ASNCIDR_
asn_lookup myview.example.com _MYASN_ _MYASNCIDR_
asn_lookup asn.routeviews.org _COMBINEDASN_ _COMBINEDASNCIDR_
asn_lookup myview.example.com _COMBINEDASN_ _COMBINEDASNCIDR_
asn_lookup in1tag.example.net _ASNDATA_ _ASNDATA_
asn_lookup_ipv6 asn-zone6.example.com [_ASN_ _ASNCIDR_]
استخدم المنطقة المحددة لعمليات البحث عن عناوين IPv6. إذا كانت المنطقة تدعم استعلامات IPv4 و IPv6، فاستخدم كل من asn_lookup و asn_lookup_ipv6 لنفس المنطقة.

إعدادات المسؤول

asn_use_geodb ( 0 / 1 ) (الافتراضي: 1)
استخدم وحدة Mail::SpamAssassin::GeoDB للبحث عن أرقام ASN. تحتاج إلى وحدة مدعومة مناسبة مثل GeoIP2 أو GeoIP مع قاعدة بيانات ISP أو ASN مثبتة (على سبيل المثال، أضف EditionIDs GeoLite2-ASN في GeoIP.conf لبرنامج geoipupdate).

يمكن لـ GeoDB تعيين علامة _ASN_ فقط، ولا تحتوي على بيانات لـ _ASNCIDR_. إذا كنت بحاجة إلى كليهما، فقم بتعيين asn_prefer_geodb 0 حتى يتم تجربة قواعد DNS.

asn_prefer_geodb ( 0 / 1 ) (الافتراضي: 1)
إذا تم تعيينه، فلن يتم تشغيل عمليات بحث DNS (قواعد asn_lookup) إذا وجدت GeoDB ASN بنجاح. قم بتعيين هذا إلى 0 للحصول على _ASNCIDR_ حتى إذا وجدت GeoDB _ASN_.
asn_use_dns ( 0 / 1 ) (الافتراضي: 1)
قم بتعيين إلى 0 لعدم السماح أبدًا باستعلامات DNS.

BAYES

سيستخدم محلل Bayes بيانات ASN لحسابات Bayes، وبالتالي يؤثر على أي قاعدة BAYES_* سيتم تشغيلها لرسالة معينة. لم يتم إجراء تحليل متعمق لفائدة تحليل Bayes لبيانات ASN.
