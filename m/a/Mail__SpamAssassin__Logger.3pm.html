Mail__SpamAssassin__Logger(3pm)

الحزمة: spamassassin

التراخيص: APACHE

Mail::SpamAssassin::Logger(3) وثائق Perl المساهمة من المستخدم Mail::SpamAssassin::Logger(3)

الاسم

Mail::SpamAssassin::Logger - وحدة تسجيل SpamAssassin

الملخص

use Mail::SpamAssassin::Logger;
$SIG{__WARN__} = sub {
  log_message("warn", $_[0]);
};
$SIG{__DIE__} = sub {
  log_message("error", $_[0])  if !$^S;
};

الوظائف

add_facilities(facilities)
تفعيل تسجيل التصحيح لمرافق محددة. كل مرفق هو منطقة الكود التي سيتم تصحيحها. يمكن تحديد المرافق كمرجع هاش (تُستخدم أسماء المفاتيح) أو مرجع مصفوفة أو مصفوفة أو سلسلة نصية مفصولة بفواصل. أسماء المرافق حساسة لحالة الأحرف.

إذا تم إدراج "all"، فسيتم تفعيل جميع مرافق التصحيح ضمنيًا، باستثناء تلك التي تم تعطيلها صراحةً. قد يسبق اسم المرفق "no" (غير حساس لحالة الأحرف)، مما يعطله صراحةً، متجاوزًا "all". على سبيل المثال: all,norules,noconfig,nodcc. عندما تُعطى أسماء المرافق كقائمة مرتبة (مصفوفة أو سلسلة نصية، وليس هاش)، فإن الإدخال الأخير هو الذي ينطبق، على سبيل المثال 'nodcc,dcc,dcc,noddc' يعادل 'nodcc'. لاحظ أنه لا يوجد حاليًا اسم مرفق يبدأ بـ "no"، يُنصح بالحفاظ على هذه الممارسة مع أسماء المرافق المضافة حديثًا لتسهيل الأمور.

الرسائل المعلوماتية ذات الأولوية الأعلى والمناسبة للتسجيل في الظروف العادية متاحة بمنطقة "info". تتطلب بعض الرسائل المطولة للغاية تمكين المرفق بشكل خاص (انظر "would_log" أدناه).

log_message($level, @message)
تسجيل رسالة بمستوى معين. تُحدد المستويات كسلاسل نصية: "warn"، "error"، "info"، و "dbg". يجب أن يكون العنصر الأول من الرسالة مسبوقًا باسم مرفق متبوعًا بنقطتين مباشرة.
dbg("facility: message")
يُستخدم هذا لجميع رسائل التصحيح ذات الأولوية المنخفضة.
info("facility: message")
يُستخدم هذا للرسائل المعلوماتية التي تشير إلى شرط طبيعي ولكنه مهم. يجب استدعاء هذا بشكل غير متكرر. عادةً ما يتم تسجيل هذه الرسائل عند تشغيل SpamAssassin كخادم.
add(method => 'syslog', socket => $socket, facility => $facility, escape => $escape)
"socket" هو نوع syslog ("unix" أو "inet"). "facility" هو مرفق syslog (عادة "mail").

إذا كان "escape" اختياريًا صحيحًا، فسيتم تجاوز جميع الأحرف غير ASCII لتمثيل آمن: تتغير الشرطات المائلة العكسية إلى \\ والأحرف غير ASCII إلى \x{XX} أو \x{XXXX} (Unicode). إذا لم يتم تحديده، يتم استخدام أسلوب التطهير قبل الإصدار 4.0 ( tr/\x09\x20\x00-\x1f/_/s ).

يمكن تجاوز قيمة الهروب بواسطة متغير البيئة "SA_LOGGER_ESCAPE".

add(method => 'file', filename => $file, escape => $escape)
"filename" هو اسم ملف السجل. "escape" يعمل كما هو موضح أعلاه.
add(method => 'stderr', escape => $escape)
لا توجد خيارات مطلوبة لتسجيل stderr، فقط لا تغلق stderr أولاً. "escape" يعمل كما هو موضح أعلاه.
remove(method)
إزالة طريقة تسجيل. تحتاج فقط إلى تمرير اسم الطريقة كسلسلة نصية.
would_log($level, $facility)
تُرجع خطأ إذا لم يتم تسجيل رسالة بالمستوى والمرفق المعطيين. تُرجع 1 إذا تم تسجيل رسالة بالمستوى والمرفق المعطيين بشكل طبيعي. تُرجع 2 إذا تم تمكين المرفق بشكل خاص.

وسيطة المرفق اختيارية.

close_log()
إغلاق جميع السجلات.
