الاسم

Mail::Message::Field::Attribute - خاصية لحقل كامل

الوراثة

Mail::Message::Field::Attribute
  هو Mail::Reporter

الملخص

my $field    = $msg->head->get('Content-Disposition') or return;
my $full     = $field->study;   # فهم كامل في اليونيكود
my $filename = $full->attribute('filename')           or return;
print ref $filename;     # اسم الفئة هذا
print $filename;         # محتوى الخصائص في utf-8
print $filename->value;  # نفسه
print $filename->string; # طباعة كما وجدت في الملف
$filename->print(\*OUT); # طباعة كما وجدت في الملف

الوصف

يمكن أن تكون الخصائص داخل حقول MIME معقدة للغاية، وبالتالي يمكن أن تكون بطيئة وتستهلك الكثير من الذاكرة. وحدات Mail::Message::Field::Fast و Mail::Message::Field::Flex تبسط الخصائص كثيرًا، مما قد يؤدي إلى سلوكيات خاطئة في حالات نادرة. مع زيادة اللغات غير الغربية على الإنترنت، تزداد الحاجة إلى العناوين المعقدة.

يمكن العثور على "Mail::Message::Field::Attribute" في أي حقل منظم من Mail::Message::Field::Full.

يمتد "الوصف" في Mail::Reporter.

المُنشِئات

يمتد "المُنشِئات" في Mail::Reporter.

$class->new( <$name, [$value] | STRING>, %options )
إنشاء خاصية جديدة $name مع $value اختياري. إذا لم يتم تحديد $value، يتم فحص الوسيط الأول لهذه الطريقة لمعرفة ما إذا كانت هناك علامة يساوي '='. إذا كان هذا الحرف موجودًا، فسيتم أخذ الوسيط كسلسلة نصية "STRING"، والتي تحتوي على خاصية مُعدة مسبقًا سيتم معالجتها. بخلاف ذلك، يتم أخذ الوسيط كاسم بدون قيمة $value: سيتم تعيين القيمة لاحقًا باستخدام value().

يعتمد نوع الترميز الذي يحدث على %options ووجود أحرف غير ASCII في $value. يمكن أن يحتوي $name فقط على أحرف ASCII، لذا فهو غير مرمّز.

لتسريع، لا يتم استخلاص الخصائص من الفئة الأساسية لـ Mail::Reporter. تحسين الأساس، انظر المُنشِئات في Mail::Reporter.

-Opción           --Definida en     --Valor por defecto
 charset                             'us-ascii'
 language                            undef
 log                Mail::Reporter   'WARNINGS'
 trace              Mail::Reporter   'WARNINGS'
 use_continuations                   <C<true>>
charset => STRING
يتم ترجمة $value من utf-8 (داخلي Perl) إلى مجموعة الأحرف هذه، ويتم ترميز السلسلة الناتجة إذا لزم الأمر. "us-ascii" هو الترميز العادي للبريد. يمكن العثور على ميزات الأحرف الصالحة باستخدام Encode::encodings(':all').
language => STRING
يضيف RFC2231 إمكانية تحديد لغة مع الحقل. إذا لم يتم تحديد لغة، فلن يتم تضمين أي لغة في الترميز. أسماء اللغات الصالحة محددة بواسطة RFC2130. هذا الوحد لديه دعم محدود فقط لهذه الميزة.
log => LEVEL
---
trace => LEVEL
---
use_continuations => BOOLEAN
تُستخدم الاستمراريات لتقسيم المعلمات الطويلة إلى أجزاء لا تتجاوز 76 حرفًا. يتم تحديد الترميزات في RFC2231، ولكنها غير مدعومة من قبل بعض برامج المستخدم.

» مثال:

my $fn    = Mail::Message::Field::Attribute->new(filename => 'xyz');
my $fattr = 'Mail::Message::Field::Attribute';  # اختصار
my $fn    = $fattr->new(
  filename => "Re\xC7u",
  charset  => 'iso-8859-15',
  language => 'nl-BE'
);
print $fn;
  # -->  filename*=iso-8859-15'nl-BE'Re%C7u

Mail::Message::Field::Attribute(3pm)

NAME

Mail::Message::Field::Attribute - object representation of the content of a mail header field

INHERITANCE

Mail::Message::Field::Attribute

    isa Mail::Message::Field
    does RO::Object

SYNOPSIS

  use Mail::Message::Field::Attribute;

  my $attr <= Mail::Message::Field::Attribute->new( ... );
  $attr->parse( $value );
  my $value = $attr->as_string;

  # Access the parsed components
  my @components = $attr->components;
  my $component  = $attr->getComponent( 'name' );

  # Use the encoded value
  $attr->encode_to_bytes;
  $attr->decode;

  # Internals
  $attr->mergeComponent( $other_attr );

DESCRIPTION

This class represents the structured content of a mail header field. A field like Content-Type: text/plain; charset=utf-8 has a main value (text/plain) and parameters (charset=utf-8). This class manages these parts.

The parameters are often called "attributes" in RFC-speak. This class focuses on the representation of these attributes.

OVERLOADED

stringification
Returns the content of the attribute as a string.

METHODS

In addition to the methods inherited from Mail::Message::Field, the following methods are available:

$obj->components
Returns an array with all the components found in this attribute value. Each component is a Mail::Message::Field::Attribute::Component object.
$obj->getComponent($name)
Find and return the component with the given name. Returns undef when not found.
$obj->parse($value)
Parse the given string value and store the found components. This method is called by the constructor or by Mail::Message::Field->new(). You usually do not need to call this explicitly, unless you want to re-parse an existing attribute value. The result is returned.
$obj->as_string
Returns the value of the attribute as a plain string, without any parameter encoding.
$obj->as_bytes
Returns the value of the attribute as a byte string. This may involve encoding, for example, when the value contains non-ASCII characters. Returns undef when the attribute could not be encoded optionally after setting it first.

Attribute encoding

$obj->decode()
Translate all known continuations into a value. The produced value is returned and may be utf-8 encoded or a plain string.
$obj->encode()

Internals

$obj->mergeComponent($attribute)
Merge the components from the specified attribute into this attribute. This is needed when components of the same attribute are created separately. Merging is required by the field parsing.

DIAGNOSTICS

Warning: Illegal character in parameter name '$name'
The specified parameter name contains characters which are not permitted by the RFCs. You can better change the name into something which is accepted, or risk applications to corrupt or ignore the message. Cast by new()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
Error: Too late to merge: value already changed.
Cast by mergeComponent()
