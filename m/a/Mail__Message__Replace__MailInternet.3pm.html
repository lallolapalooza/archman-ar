NAME وثائق حزم Perl المساهمة Mail::Message::Replace::MailInternet(3)

NAME

Mail::Message::Replace::MailInternet - غلاف لـ Mail::Internet

INHERITANCE

Mail::Message::Replace::MailInternet
  يرث من Mail::Message
  يرث من Mail::Reporter

SYNOPSIS

# استبدال
use Mail::Internet;
# بدلاً من
use Mail::Message::Replace::MailInternet;
# في الكود الموجود، سيستمر الكود في العمل، ولكن
# مع ميزات Mail::Message.

DESCRIPTION

هذه الوحدة هي غلاف لـ Mail::Message، تحاكي كائن Mail::Internet. يتم اختطاف مساحة اسم هذه الوحدة وإضافة العديد من الدوال.

معظم الدوال ستعمل دون تغيير، ولكن قد تحتاج إلى مراجعة استدعاءات smtpsend() و send().

ممتد من "DESCRIPTION" في Mail::Message.

التشخيصات

خطأ: لا يمكن تضمين مصدر البريد كـ $include.
قيمة بديلة غير معروفة للبريد (forward(include)). القيم الصالحة هي "NO"، "INLINE"، "ATTACH" و "ENCAPSULATE". يتم استدعاؤها باستخدام forward()
خطأ: Mail::Internet لا يدعم هذا النوع من البيانات
بيانات ARGS يمكن أن تكون فقط ملف إدخال أو مصفوفة. الأنواع الأخرى غير مدعومة (انظر read() لمزيد من التفاصيل). يتم استدعاؤها باستخدام new()
خطأ: الطريقة bounce تتطلب To, Cc أو Bcc
الطريقة bounce() ترسل رسالة مستلمة إلى أخرى دون تعديلات؛ يجب عليك تحديد To, Cc أو Bcc.
Mail::Message::Replace::MailInternet(3pm) — Perl v5.42.0

NAME

Mail::Message::Replace::MailInternet - abstract base class for internet mail messages

INHERITANCE

Mail::Message::Replace::MailInternet is a subclass of Mail::Message::MailBox.

SYNOPSIS

  use Mail::Message::Replace::MailInternet;

  my $obj = Mail::Message::Replace::MailInternet->new(%arg);
  ...

DESCRIPTION

This is an abstract base class. It provides the common functionality for internet-style mail messages, like those you store in Mail::Box::MailBox.

The concrete implementation classes are Mail::Message::MailFolder, Mail::Message::MailFile, and Mail::Message::MailVirtual.

OVERLOADED

The following methods are overloaded:

  Method       Action
  ------       --------------------------------------------------
  "<=="       call add()
  "=="       call isSame()
  "cmp"      call compare()
  "eq"       call isEqual()
  "ne"       call isNotEqual()
  "lt"       call isLess()
  "le"       call isLessOrEqual()
  "gt"       call isGreater()
  "ge"       call isGreaterOrEqual()
  "=~"       call match()
  "!~"      call notMatch()
  "print"    call print()
  "Store"    call store()
  "clone"    call clone()
  "transfer" call transfer()
