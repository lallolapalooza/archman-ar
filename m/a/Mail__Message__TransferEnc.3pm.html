الاسم

Mail::Message::TransferEnc - مشفّر/مفكّك تشفير رسائل النقل

الوراثة

Mail::Message::TransferEnc
  هو Mail::Reporter
Mail::Message::TransferEnc ممتد بواسطة
  Mail::Message::TransferEnc::Base64
  Mail::Message::TransferEnc::Binary
  Mail::Message::TransferEnc::EightBit
  Mail::Message::TransferEnc::QuotedPrint

الملخص

my Mail::Message $msg = ...;
my $decoded = $msg->decoded;
my $encoded = $msg->encode(transfer => 'base64');

الوصف

هذه الفئة هي الأساس لمختلف المشفرات والمفككات، والتي تستخدم أثناء نقل الرسالة. هذه الحزم، وكل ما هو مشتق منها، يتم استدعاؤها بواسطة طرق الرسالة Mail::Message::decoded() و Mail::Message::encode():

my $message = $folder->message(3);
my $decoded_body = $message->decoded;
my $encoded_body = $message->encode(transfer => 'base64');

تُحدد قواعد تشفير النقل في RFC4289. يمكن العثور على القائمة الكاملة لتشفيرات النقل المسموح بها في https://www.iana.org/assignments/transfer-encodings/transfer-encodings.xhtml

المشفرات/المفككات التالية مدعومة حاليًا (أبريل 2025، القائمة الكاملة في IANA):

  • Mail::Message::TransferEnc::Base64

    "base64" للمعلومات الثنائية.

  • Mail::Message::TransferEnc::SevenBit

    "7bit" للأحرف النصية العادية فقط.

  • Mail::Message::TransferEnc::EightBit

    "8bit" لبيانات مجموعات الأحرف الموسعة، غير مشفرة.

  • Mail::Message::TransferEnc::QuotedPrint

    بيانات مجموعات الأحرف الموسعة مشفرة بـ "quoted-printable".

التشخيصات

خطأ: مشفر تشفير النقل $type لا يعمل: $@
تجميع تشفير النقل المطلوب نتج عنه أخطاء، مما يعني أن المفكك لا يمكن استخدامه. تم طرحه بواسطة create()
تحذير: لا يوجد مفكك لتشفير النقل $type.
لم يتم تنفيذ مفكك لنوع تشفير النقل المحدد. تم طرحه بواسطة create()
خطأ: الحزمة $package لا تنفذ $method.
خطأ فادح: الحزمة المحددة (أو إحدى فئاتها الفائقة) لا تنفذ هذه الطريقة حيث ينبغي. تعني هذه الرسالة أن بعض الفئات الأخرى ذات الصلة تنفذ هذه الطريقة ومع ذلك الفئة المعنية لا تفعل ذلك. ربما يجب عليك التحقيق في هذا وربما إبلاغ مؤلف الحزمة. تم طرحه بواسطة notImplemented()

NAME

Mail::Message::TransferEnc - handle message transfer encodings

INHERITANCE

Mail::Message::TransferEnc is a subclass of Mail::Message.

SYNOPSIS

use Mail::Message::TransferEnc;

my $te = Mail::Message::TransferEnc->new(
    ...
);

DESCRIPTION

This class implements the handling of message transfer encodings like quoted-printable and base64.

METHODS

This class provides no additional methods beyond those inherited from its parent class.

DIAGNOSTICS

This class does not produce any diagnostics.

SEE ALSO

Mail, Mail::Message, Mail::Message::Field, Mail::Header.
