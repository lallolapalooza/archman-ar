Mail__Field__AddrList(3pm)

الحزمة: perl-mailtools

التراخيص: PerlArtistic, GPL

Mail::Field::AddrList(3) وثائق Perl من مساهمي المستخدم Mail::Field::AddrList(3)

الاسم

Mail::Field::AddrList - تمثيل كائني لقوائم عناوين البريد الإلكتروني

الوراثة

Mail::Field::AddrList
  هي Mail::Field

الموجز

use Mail::Field::AddrList;
$to   = Mail::Field->new('To');
$from = Mail::Field->new('From', 'poe@daimi.aau.dk (Peter Orbaek)');

$from->create('foo@bar.com' => 'Mr. Foo', poe => 'Peter');
$from->parse('foo@bar.com (Mr Foo), Peter Orbaek <poe>');
# إنشاء سلسلة رأس RFC822
print $from->stringify(),"\n";
# استخراج عناوين البريد الإلكتروني والأسماء
@addresses = $from->addresses(); # سلاسل نصية
@names     = $from->names();     # سلاسل نصية
@addr      = $from->addr_list(); # كائنات Mail::Address (v2.00)
# إضافة عنوان جديد إلى القائمة
$from->set_address('foo@bar.com', 'Mr. Foo');

الوصف

يعرّف تحليل وتنسيق حقل العنوان، للحقول التالية: "To"، "From"، "Cc"، "Reply-To"، و "Sender".

تم تنفيذ جميع الميزات المستخدمة عادةً لمواصفات حقل العنوان في RFC2822، ولكن بعض التراكيب المعقدة (وبالتالي نادراً ما تستخدم) لن يتم فهمها. استخدم Mail::Message::Field::Full في MailBox إذا كنت بحاجة إلى توافق كامل مع RFC.

يمتد "DESCRIPTION" في Mail::Field.
