NAME

Mail::Box::Locker::DotLock - a locker for dotlock files

INHERITANCE

This module is part of the Mail::Box distribution.

SYNOPSIS

use Mail::Box::Locker::DotLock;

my $locker = Mail::Box::Locker::DotLock->new();
$locker->lock("~/.maillock");
$locker->unlock();

DESCRIPTION

The Mail::Box::Locker::DotLock class implements the locking mechanism to be used with Mail::Box. It uses the standard dotlock mechanism, where a lock file is created by prefixing the target file name with a dot. This mechanism is common on Unix-like systems.

METHODS

new()
Constructs a new Mail::Box::Locker::DotLock object.
lock( $filename )
Attempts to create a lock file for the given $filename. The lock file is created by prefixing the filename with a dot (e.g., .mail for mail). If the lock file already exists, the method will wait until it is removed or until a timeout occurs. Returns 1 on success, 0 on failure.
unlock()
Removes the lock file created by lock(). Returns 1 on success, 0 on failure.

DIAGNOSTICS

The module may produce the following errors:

  • Cannot create lock file "%s": %s: Failed to create the lock file, likely due to permissions issues.
  • Lock file "%s" not removed: Failed to remove the lock file during unlock.
