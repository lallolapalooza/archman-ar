maketestzone(1p)

الحزمة: dnssec-tools

التراخيص: BSD

MAKETESTZONE(1p) وثائق Perl المساهمة من المستخدم MAKETESTZONE(1p)

الاسم

generaterecords - يولد منطقة اختبار يمكن استخدامها لـ DNSSEC

الملخص

generaterecords -v -d mytestzone.example.com

الوصف

ينشئ البرنامج النصي generaterecords ملف منطقة، بالنظر إلى اسم نطاق، والذي يتم توقيعه وتعديله بعد ذلك لإبطال أجزاء من البيانات بطرق معينة. يتم تسمية كل سجل تم إنشاؤه بشكل مناسب لكيفية تعديل بيانات الأمان (سجل gooda سيحتوي على سجل A مع بيانات DNSSEC صالحة، ولكن سجل badseca سيحتوي على سجل A حيث تم تعديل التوقيع لإبطاله).

يمكن بعد ذلك تقديم نتائج هذه العملية واختبار المدققين الآمنين، والتطبيقات، والبرامج الأخرى يمكن توجيهها إليها لمعرفة ما إذا كانت تفشل أو تنجح بشكل صحيح ضمن سياسات أمان DNS التي يتم نشرها.

بعد إنشاء الملفات، ضع في اعتبارك تشغيل donuts عليها لمعرفة كيف تم التلاعب بالبيانات فيها لتكون غير صالحة.

المتطلبات المسبقة

zonesigner من مشروع dnssec-tools، برنامج bind الإصدار 9.3.1 أو أعلى

البدء

للبدء في إنشاء منطقة جديدة، ستحتاج إلى إخبار zonesigner بإنشاء مفاتيح جديدة لجميع المناطق الجديدة التي ينشئها maketestzone. وبالتالي، يجب أن يبدو التشغيل الأول لـ maketestzone كالتالي:

المرة الأولى:
maketestzone -k [خيارات أخرى مرغوبة]

بعد ذلك، يمكن تحميل ملفات المنطقة التي تم إنشاؤها وتقديمها في خادم اختبار.

مرة كل 30 يومًا (افتراضيًا عبر zonesigner) سيحتاج البرنامج النصي إلى إعادة التشغيل لإعادة إنشاء السجلات وتوقيع البيانات مرة أخرى حتى تظل طوابع تاريخ التوقيع صالحة (أو في بعض الحالات غير صالحة).

كل 30 يومًا:
maketestzone [خيارات أخرى مرغوبة]

الخيارات

فيما يلي الخيارات التي يقبلها أداة maketestzone.

تسمية ملفات الإخراج:

-o STRING
--output-file-prefix=STRING
بادئة الإخراج لاستخدامها في ملفات المنطقة (الافتراضي = db.)
-O STRING
--output-suffix-signed-file=STRING
لاحقة الإخراج لإعطائها لـ zonesigner (الافتراضي = .zs)
-M STRING
--output-modified-file=STRING
لاحقة الإخراج لملف المنطقة المعدل (الافتراضي = .modified)
-D
--run-donuts
تشغيل donuts على النتائج
--donuts-output-suffix=STRING
لاحقة الملف المراد استخدامها لإخراج donuts (الافتراضي = .donuts)

معلومات منطقة الإخراج:

-d STRING
--domain=STRING
اسم النطاق لإنشاء سجلات له
--ns=STRING
--name-servers=STRING
-n STRING
سجلات خوادم الأسماء المسماة = العنوان مفصولة بفواصل
--a-addr=STRING
--a-record-address=STRING
عنوان سجل A (IPv4) المراد استخدامه في البيانات
--aaaa-addr=STRING
--a-record-address=STRING
عنوان سجل AAAA (IPv6) المراد استخدامه في البيانات

اختيار نوع بيانات الإخراج:

-p STRING
--record-prefixes=STRING
قائمة مفصولة بفواصل من بادئات السجلات المراد استخدامها
-P STRING
--ns-prefixes=STRING
قائمة مفصولة بفواصل من بادئات سجلات NS المراد استخدامها
-c
--no-cname-records
لا تنشئ سجلات CNAME
-s
--no-ns-records
لا تنشئ سجلات النطاقات الفرعية

اختيار المهمة:

-g
--dont-generate-zone
لا تنشئ المنطقة؛ استخدم الموجودة وقم بتوقيعها/تعديلها
-z
--dont-run-zonesigner
لا تقم بتشغيل zonesigner لتوقيع السجلات
-Z
--dont-destroy
لا تقم بتدمير السجلات واتركها موقعة بشكل صحيح
--bind-config=STRING
إنشاء مقتطف ملف تكوين bind لتحميل مجموعات DB
--html-out=STRING
إنشاء صفحة HTML تحتوي على قائمة بأسماء السجلات
--apache-out=STRING
إنشاء مقتطف تكوين Apache لتكوين Apache لكل سجل منطقة
--sh-test-out=STRING
إنشاء برنامج نصي اختباري لتشغيل أوامر dig
-v
--verbose
إخراج تفصيلي

تكوين Zonesigner:

-a STRING
--zonesigner-arguments=STRING
وسائط لتمريرها إلى zonesigner
-k
--generate-keys
اجعل zonesigner يولد المفاتيح المطلوبة

خيارات تكوين Bind

--bind-db-dir=STRING
الدليل الأساسي حيث سيتم وضع ملفات قاعدة بيانات bind

تكوين إخراج HTML

--html-out-add-links
اجعل كل اسم سجل في HTML رابطًا HTTP لهذا العنوان
--html-out-add-db-links
أضف رابطًا لكل ملف DB تم إنشاؤه.
--html-out-add-donuts-links
أضف رابطًا لكل ملف قائمة أخطاء donuts التي تم إنشاؤها.

خيارات تكوين برنامج نصي لاختبار SH

--sh-test-resolver=STRING
عنوان الدقة الذي سيتم فرضه
