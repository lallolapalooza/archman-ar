Mat_CreateVer(3)

الحزمة: libmatio

التراخيص: BSD-2-Clause

MAT_CREATEVER(3) دليل وظائف المكتبة MAT_CREATEVER(3)

الاسم

Mat_CreateVer، Mat_Create — إنشاء ملف MAT الخاص بـ MATLAB.

الشكل

#include <matio.h>

mat_t *
Mat_CreateVer(const char *matname, const char *hdr_str, enum mat_ft mat_file_ver);

mat_t *
Mat_Create(const char *matname, const char *hdr_str);

الوصف

تقوم الدالة Mat_CreateVer() بإنشاء ملف MAT الخاص بـ MATLAB مفتوح للكتابة. hdr_str هو سلسلة نصية تُكتب في رأس ملفات MAT من الإصدار 5 و 7.3 (HDF). يتم كتابة أول 128 بايت من السلسلة فقط. إذا كان hdr_str هو NULL، فسيتم كتابة سلسلة نصية افتراضية تحتوي على المنصة والتاريخ وإصدار مكتبة matio.

يحدد الوسيط mat_file_ver إصدار ملف MAT المراد إنشاؤه. يمكن لمكتبة matio كتابة ملفات الإصدار 4 (MAT_FT_MAT4)، وملفات الإصدار 5 (MAT_FT_MAT5)، وتنسيق ملف HDF5 الذي تم تقديمه في إصدار MATLAB 7.3 (MAT_FT_MAT73).

الدالة Mat_Create() تعادل استدعاء Mat_CreateVer() مع MAT_FT_DEFAULT كإصدار للملف.

أمثلة

#include <stdlib.h>
#include <stdio.h>
#include "matio.h"

int main(int argc, char **argv)
{
    mat_t *matfp;

    matfp = Mat_CreateVer(argv[1], NULL, MAT_FT_73);
    if ( NULL == matfp ) {
        fprintf(stderr, "Error creating MAT file %s0, argv[1]);
        return EXIT_FAILURE;
    }

    Mat_Close(matfp);
    return EXIT_SUCCESS;
}
