Mat_VarGetStructs(3)

الحزمة: libmatio

التراخيص: BSD-2-Clause

MAT_VARGETSTRUCTS(3) دليل الدوال المكتبية MAT_VARGETSTRUCTS(3)

الاسم

Mat_VarGetStructs — فهرسة متغير هيكلي باستخدام شرائح من كل بُعد

الشكل العام

#include <matio.h>

matvar_t *
Mat_VarGetStructs(const matvar_t *matvar, const int *start, const int *stride, const int *edge, int copy_fields);

الوصف

الدالة Mat_VarGetStructs() تحدد مصفوفة فرعية من مصفوفة الهياكل matvar. تحتوي كل عناصر المصفوفة الفرعية على جميع حقول الهيكل. يبدأ فهرس كل بُعد عند العنصر start في المصفوفة (0 هو العنصر الأول)، ويقرأ كل stride قيم (1 هو كل عنصر، 2 كل عنصر آخر، إلخ). يتم تحديد العدد الإجمالي للعناصر في المصفوفة الفرعية بواسطة edge. تحدد الخيار copy_fields ما إذا كانت حقول الهيكل الأصلي سيتم نسخها للمصفوفة الفرعية الجديدة. إذا تم تعيينها إلى 0، فإن الحقول الخاصة بالمصفوفة الفرعية المعادة لها نفس المؤشر الخاص بالمصفوفة الأصلية، وكذلك حقل data الخاص بالهيكل الفرعي. يتم وضع علامة على المصفوفة الفرعية بعلم حفظ الذاكرة الذي يشير إلى أنه لا ينبغي تحرير الحقول. يتم تحريرها عند تحرير الهيكل الأصلي.

قيم الإرجاع

مصفوفة فرعية من مصفوفة الهياكل الأصلية، أو NULL في حالة حدوث خطأ.
