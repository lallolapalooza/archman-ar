malloc_get_state(3) دليل وظائف المكتبة malloc_get_state(3)

الاسم

malloc_get_state, malloc_set_state - تسجيل واستعادة حالة تنفيذ malloc

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <malloc.h>
void *malloc_get_state(void);
int malloc_set_state(void *state);

الوصف

ملاحظة: تم إزالة هذه الوظائف في glibc 2.25.

تقوم وظيفة malloc_get_state() بتسجيل الحالة الحالية لجميع متغيرات البرمجة الداخلية لـ malloc(3) (ولكن ليس المحتويات الفعلية للمكدس أو حالة مؤشرات وظائف malloc_hook(3)). يتم تسجيل الحالة في هيكل بيانات خاص بالنظام ومبهم يتم تخصيصه ديناميكيًا عبر malloc(3)، ويتم إرجاع مؤشر إلى هذا الهيكل كقيمة إرجاع للوظيفة. (تقع على عاتق المتصل مسؤولية free(3) هذه الذاكرة.)

تقوم وظيفة malloc_set_state() باستعادة حالة جميع متغيرات البرمجة الداخلية لـ malloc(3) إلى القيم المسجلة في هيكل البيانات المبهم الذي يشير إليه state.

قيمة الإرجاع

عند النجاح، تُرجع malloc_get_state() مؤشرًا إلى هيكل بيانات مبهم تم تخصيصه حديثًا. عند حدوث خطأ (على سبيل المثال، تعذر تخصيص الذاكرة لهيكل البيانات)، تُرجع malloc_get_state() القيمة NULL.

عند النجاح، تُرجع malloc_set_state() القيمة 0. إذا اكتشف التنفيذ أن state لا يشير إلى هيكل بيانات صحيح التكوين، تُرجع malloc_set_state() القيمة -1. إذا اكتشف التنفيذ أن إصدار هيكل البيانات المشار إليه بواسطة state هو إصدار أحدث لا يعرفه هذا التنفيذ، تُرجع malloc_set_state() القيمة -2.

ملاحظات

هذه الوظائف مفيدة عند استخدام تنفيذ malloc(3) هذا كجزء من مكتبة مشتركة، ويتم حفظ/استعادة محتويات المكدس عبر طريقة أخرى. يتم استخدام هذه التقنية بواسطة GNU Emacs لتنفيذ وظيفة "التفريغ" الخاصة به.

لم يتم حفظ أو استعادة مؤشرات وظائف الخطاف أبدًا بواسطة هذه الوظائف، مع استثناءين: إذا كان فحص malloc (راجع mallopt(3)) قيد الاستخدام عند استدعاء malloc_get_state()، ثم تقوم malloc_set_state() بإعادة تعيين خطافات فحص malloc إن أمكن؛ إذا لم يكن فحص malloc قيد الاستخدام في الحالة المسجلة، ولكن طلب المتصل فحص malloc، فسيتم إعادة تعيين الخطافات إلى 0.
