MARKDOWN(1) دليل الأوامر العامة MARKDOWN(1)

الاسم

markdown — أداة تحويل النص إلى HTML

نبذة

markdown [-d] [-T] [-V] [-b url-base] [-C prefix] [-F bitmap] [-f flags] [-n] [-o file] [-S] [-s text] [-t text] [-toc] [textfile]

الوصف

تقوم الأداة markdown بقراءة ملف النص textfile بتنسيق markdown(7) (أو الإدخال القياسي إذا لم يتم تحديده)، وتجميعه، وتكتب ناتج HTML إلى الإخراج القياسي.

الخيارات هي كما يلي:

-b url-base
سيتم إضافة البادئة url-base إلى الروابط في المصدر التي تبدأ بـ / في الناتج.
-C
عند معالجة الملاحظات التذييلية بأسلوب Markdown الإضافي، استخدم البادئة المعطاة بدلاً من الافتراضي fn.
-d
بدلاً من كتابة ملف HTML، قم بإلقاء شجرة تحليل إلى الإخراج القياسي.
-f flags
تعيين أو مسح علامات ترجمة مختلفة. العلامات موجودة في قائمة مفصولة بفواصل، مع علامة + اختيارية (تمكين)، - (تعطيل)، أو no (تعطيل) بادئة لكل علامة.
links
السماح بالروابط.
image
السماح بالصور.
smarty
تمكين SmartyPants.
pants
تمكين SmartyPants.
html
السماح بـ HTML الخام.
strict
تعطيل علامات الأس والجمل المشطوبة والتأكيد المرن.
ext
تمكين البروتوكولات الزائفة.
cdata
إنشاء كود لـ XML ![CDATA[...]].
superscript
تمكين معالجة علامات الأس.
emphasis
يحدث التأكيد في كل مكان.
tables
لا تقم بمعالجة جداول PHP Markdown Extra.
del
تمكين ~~شطب~~.
strikethrough
تمكين ~~شطب~~.
toc
تمكين معالجة جدول المحتويات.
1.0
التوافق مع MarkdownTest_1.0
autolink
جعل http://foo.com رابطًا حتى بدون <>.
safelink
فحص دقيق لبروتوكول الرابط.
header
معالجة كتل الرأس بأسلوب Pandoc.
tabstop
توسيع علامات الجدولة إلى 4 مسافات.
divquote
السماح بكتل >%class%.
alphalist
السماح بقوائم أبجدية.
definitionlist
السماح بقوائم التعريف بشكل عام (افتراضي). استخدم dldiscount و dlextra للتحكم في أي الصيغ يتم احترامها.
dldiscount
تمكين قوائم التعريف بأسلوب Discount (افتراضي).
dlextra
تمكين قوائم التعريف بأسلوب Extra (غير افتراضي). يمكن تمكين كلا الأسلوبين في نفس الوقت.
footnote
السماح بالملاحظات التذييلية بأسلوب Markdown Extra.
style
استخراج كتل <style> من الناتج.
fencedcode
السماح بكتل التعليمات البرمجية المسورة (غير افتراضي).
idanchor
استخدام id= لروابط جدول المحتويات بدلاً من <a name=/> (غير افتراضي).
githubtags
السماح بالشرطة السفلية والواصلة في أسماء العناصر التي تم تمريرها (غير افتراضي).
urlencodedanchor
استخدام أحرف مشفرة بالـ URL للأحرف متعددة البايت وغير الأبجدية الرقمية بدلاً من النقاط في روابط جدول المحتويات.

على سبيل المثال، يخبر الخيار -f nolinks,smarty markdown بعدم السماح بعلامات <a ، والقيام بمعالجة Smarty Pants.

-F bitmap
تعيين علامات الترجمة. Bitmap هي خريطة بت للخيارات المختلفة الموصوفة في markdown(3) (تم تعريف قيم العلامات في mkdio.h)
-n
لا تكتب HTML تم إنشاؤه.
-o file
اكتب HTML الذي تم إنشاؤه إلى file.
-S
إخراج كتل <style>.
-V
إظهار رقم الإصدار وبيانات التكوين وقت التجميع.

إذا كان الإصدار يتضمن السلسلة DEBUG، فقد تم تكوين markdown مع تصحيح تخصيص الذاكرة.

إذا كان الإصدار يتضمن السلسلة TAB، فقد تم تكوين markdown لاستخدام نقطة التوقف المحددة للجدولة.

-VV
إظهار رقم الإصدار، وتكوين وقت التجميع، وتكوين وقت التشغيل.
-t text
استخدم mkd_text(3) لتنسيق text بدلاً من معالجة الإدخال القياسي باستخدام الدالة markdown(3).
-T
إذا تم تشغيله مع علامة جدول المحتويات، قم بإلقاء جدول المحتويات قبل النص المنسق.
-s text
استخدم الدالة markdown(3) لتنسيق text.
-toc
تعيين علامة جدول المحتويات، ثم قم بإلقاء جدول المحتويات قبل النص المنسق (اختصار لـ --T --toc).

قيم الإرجاع

تخرج الأداة markdown بقيمة 0 عند النجاح، و >0 إذا حدث خطأ.

انظر أيضًا

markdown(3), markdown(7), mkd-extensions(7).

NAME

markdown - Implements the Markdown document format

SYNOPSIS

#include <markdown.h>

char * markdown(const char *text, size_t size, markdown_hook *callbacks);

DESCRIPTION

The markdown(3) function is used to convert plain text documents from the Markdown format to HTML. It takes a pointer to the input text, the size of the input text, and an optional set of callbacks for custom rendering. The function returns a pointer to the newly allocated HTML string, which must be freed by the caller using free().

RETURN VALUES

Returns a pointer to the generated HTML string, or NULL if memory allocation fails. The returned string is null-terminated.

discount(3)

الاسم

markdown - تطبيق تنسيق مستندات Markdown

المُلخَّص

#include <markdown.h>

char * markdown(const char *text, size_t size, markdown_hook *callbacks);

الوصف

تُستخدم الدالة markdown(3) لتحويل مستندات النص العادي من تنسيق Markdown إلى HTML. تأخذ مؤشرًا إلى نص الإدخال، وحجم نص الإدخال، ومجموعة اختيارية من ردود الاتصال للعرض المخصص. تُرجع الدالة مؤشرًا إلى سلسلة HTML المخصصة حديثًا، والتي يجب على المتصل تحريرها باستخدام free().

قيم الإرجاع

تُرجع مؤشرًا إلى سلسلة HTML المُنشأة، أو NULL إذا فشل تخصيص الذاكرة. السلسلة المُرجعة تنتهي بـ NULL.
