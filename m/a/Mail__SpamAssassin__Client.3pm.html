Mail__SpamAssassin__Client(3pm)

الحزمة: spamassassin

التراخيص: APACHE

Mail::SpamAssassin::Client(3) وثائق Perl من مساهمات المستخدم Mail::SpamAssassin::Client(3)

الاسم

Mail::SpamAssassin::Client - عميل لبروتوكول spamd

الملخص

my $client = Mail::SpamAssassin::Client->new({
                              port => 783,
                              host => 'localhost',
                              username => 'someuser'});
or
my $client = Mail::SpamAssassin::Client->new({
                              socketpath => '/path/to/socket',
                              username => 'someuser'});
Optionally takes timeout, which is applied to IO::Socket for the
initial connection.  If not supplied, it defaults to 30 seconds.
if ($client->ping()) {
  print "Ping is ok\n";
}
my $result = $client->process($testmsg);
if ($result->{isspam} eq 'True') {
  do something with spam message here
}

الوصف

Mail::SpamAssassin::Client هو وحدة توفر تطبيق Perl لبروتوكول spamd.

الطرق العامة

new

public class (Mail::SpamAssassin::Client) new (\% $args)

الوصف: تنشئ هذه الطريقة كائن Mail::SpamAssassin::Client جديد.

process

public instance (\%) process (String $msg)

الوصف: تستدعي هذه الطريقة خادم spamd باستخدام أمر PROCESS.

انظر طريقة process لمعرفة القيمة المعادة.

learn

public instance (Boolean) learn (String $msg, Integer $learntype)

الوصف: تطبق هذه الطريقة استدعاء learn. يجب أن يكون $learntype عددًا صحيحًا، 0 للبريد العشوائي، 1 للبريد العادي، و 2 للنسيان. القيمة المعادة هي قيمة منطقية تشير إلى ما إذا كانت الرسالة قد تم تعلمها أم لا.

القيمة المعادة undef تشير إلى حدوث خطأ ويجب عليك التحقق من قيم resp_code/resp_msg لتحديد الخطأ.

الطرق الخاصة

_create_connection

private instance (IO::Socket) _create_connection ()

الوصف: تقوم هذه الطريقة بإعداد اتصال IO::Socket مناسب بناءً على الوسائط المستخدمة عند إنشاء كائن العميل.

عند الفشل، تقوم بتعيين رمز خطأ داخلي وتعيد undef.

_parse_response_line

private instance (@) _parse_response_line (String $line)

الوصف: تقوم هذه الطريقة بتحليل سطر الاستجابة الأولي/الرأس من الخادم وإعادة أجزائه.

لدينا هذه الطريقة كطريقة منفصلة في حال قررنا أن نكون مبتكرين مع سطر الاستجابة.

_clear_errors

private instance () _clear_errors ()

الوصف: تقوم هذه الطريقة بمسح أي أخطاء حالية.

_filter

private instance (\%) _filter (String $msg, String $command)

الوصف: تقوم بالاستدعاء الفعلي لخادم spamd لطرق التصفية المختلفة (مثل PROCESS، CHECK، HEADERS، إلخ). يتم إرسال الأمر الذي تم تمريره إلى خادم spamd.
