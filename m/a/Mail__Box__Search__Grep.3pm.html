NAME

Mail::Box::Search::Grep - grep on the content of messages

INHERITANCE

Extends Mail::Box::Search.

SYNOPSIS

  my $box = Mail::Box::Manager->new(folder => '~/Mail');
  my $searcher = Mail::Box::Search::Grep->new($box);

  my @found = $searcher->search('subject: test');
  my @found = $searcher->searchPart($message, 'BODY', 'xyz');
  my @found = $searcher->inBody($message, 'xyz');
  my @found = $searcher->inHead($message, 'FROM: .*overmeer');

DESCRIPTION

This searcher implements the searching on the content of messages. It is focused on the grep-like features that are often needed.

The search terms are interpreted as regular expressions (see perlre). The search is case-insensitive by default. Use the Mail::Box::Search::CaseSensitive wrapper class if you need case-sensitive searching.
