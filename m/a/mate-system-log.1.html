الاسم

mate-system-log - عارض سجلات نظام MATE

الملخص

mate-system-log

أو حدد System Log من القائمة الفرعية System Tools في قائمة التطبيقات.

الوصف

MATE System Log Viewer هو أداة بسيطة لعرض ملفات سجلات النظام.

المؤلف

تمت كتابة MATE System Log Viewer بواسطة Cesar Miquel <miquel@df.uba.ar>.

تمت كتابة صفحة الدليل هذه بواسطة Jochen Voss <voss@mathematik.uni-kl.de>.

الملفات

/var/log/messages
ملف السجل الرئيسي للنظام.
/etc/syslog.conf
ملف تكوين syslogd. انظر syslog.conf(5) للحصول على معلومات دقيقة.

انظر أيضًا

syslogd(8), sysklogd(8), syslog.conf(5), syslogd-listfiles(8)
