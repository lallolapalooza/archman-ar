Mail__SPF__MacroString(3pm)

الحزمة: perl-mail-spf

التراخيص: custom

Mail::SPF::MacroString(3) وثائق بيرل المساهمة من المستخدم Mail::SPF::MacroString(3)

الاسم

Mail::SPF::MacroString - فئة سلسلة الماكرو لسجل SPF

الإصدار

الإصدار 3.20250505

ملخص

توفير سياق التوسع مبكرًا

use Mail::SPF::MacroString;
my $macrostring = Mail::SPF::MacroString->new(
    text    => '%{ir}.%{v}._spf.%{d2}',
    server  => $server,
    request => $request
);
my $expanded = $macrostring->expand;

توفير سياق التوسع متأخرًا

use Mail::SPF::MacroString;
my $macrostring = Mail::SPF::MacroString->new(
    text    => '%{ir}.%{v}._spf.%{d2}'
);
my $expanded1 = $macrostring->expand($server, $request1);
$macrostring->context($server, $request2);
my $expanded2 = $macrostring->expand;

الوصف

يمثل كائن الفئة Mail::SPF::MacroString سلسلة ماكرو يمكن توسيعها إلى سلسلة نصية عادية في سياق طلب SPF.

المُنشئ

يتم توفير المُنشئ التالي:

new(%options): يعيد Mail::SPF::MacroString
ينشئ كائن سلسلة ماكرو سجل SPF جديد.

%options هي قائمة من أزواج المفاتيح/القيم التي تمثل أيًا من الخيارات التالية:

text
مطلوب. النص غير الموسع لسلسلة الماكرو الجديدة.
server
كائن Mail::SPF::Server الذي سيتم استخدامه عند توسيع سلسلة الماكرو. لا يلزم ربط كائن الخادم ثابتًا بسلسلة الماكرو؛ يمكن تحديده ديناميكيًا عند استدعاء التابع "expand".
request
كائن Mail::SPF::Request الذي سيتم استخدامه عند توسيع سلسلة الماكرو. لا يلزم ربط كائن الطلب ثابتًا بسلسلة الماكرو؛ يمكن تحديده ديناميكيًا عند استدعاء التابع "expand".
is_explanation
قيمة منطقية تحدد ما إذا كانت سلسلة الماكرو هي سلسلة شرح تم الحصول عليها عبر معدِّل "exp". إذا كانت **صحيحة**، فقد تظهر وحدات الماكرو "c" و "r" و "t" في سلسلة الماكرو، وإلا فلا يجوز لها ذلك، وإذا فعلت، فسيتم طرح استثناء Mail::SPF::EInvalidMacro عند توسيع سلسلة الماكرو. الافتراضي هو **خطأ**.

توابع المثيل

يتم توفير توابع المثيل التالية:

text: يعيد string
يعيد النص غير الموسع لسلسلة الماكرو.
context($server, $request): يطرح Mail::SPF::EOptionRequired
يربط كائنات Mail::SPF::Server و Mail::SPF::Request المعطاة كسياق لسلسلة الماكرو.
expand: يعيد string؛ يطرح Mail::SPF::EMacroExpansionCtxRequired، Mail::SPF::EInvalidMacroString، Mail::SPF::Result::PermError
expand($server, $request): يعيد string؛ يطرح Mail::SPF::EMacroExpansionCtxRequired، Mail::SPF::EInvalidMacroString، Mail::SPF::Result::PermError
يقوم بتوسيع نص سلسلة الماكرو باستخدام إما السياق المحدد من خلال استدعاء سابق للتابع context()، أو السياق المعطى، ويعيد السلسلة الناتجة. انظر RFC 4408، 8، لكيفية توسيع وحدات الماكرو.
is_explanation: يعيد boolean
يعيد **صحيح** إذا كانت سلسلة الماكرو سلسلة شرح تم الحصول عليها عبر معدِّل "exp". انظر وصف خيار "is_explanation" في المُنشئ "new".
stringify: يعيد string
يعيد النص الموسع لسلسلة الماكرو إذا كان السياق مرتبطًا بالكائن. يعيد النص غير الموسع بخلاف ذلك. يمكنك ببساطة استخدام كائن Mail::SPF::MacroString كسلسلة بنفس التأثير، انظر "OVERLOADING".

التحميل الزائد

إذا تم استخدام كائن Mail::SPF::MacroString كسلسلة string، يتم استخدام التابع "stringify" لتحويل الكائن إلى سلسلة.
