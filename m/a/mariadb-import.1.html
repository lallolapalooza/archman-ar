الحزمة: mariadb-clients

التراخيص: GPL-2.0-only

MARIADB-IMPORT(1) نظام قواعد بيانات MariaDB MARIADB-IMPORT(1)

الاسم

mariadb-import - برنامج استيراد بيانات (mariadb-import هو الآن رابط رمزي لـ mariadb-import)

الملخص

mariadb-import [خيارات] اسم_قاعدة_البيانات ملف_نصي1 ...

الوصف

يوفر عميل mariadb-import واجهة سطر أوامر لبيان SQL SQL DATA INFILE. معظم الخيارات لـ mariadb-import تقابل مباشرة جمل LOAD DATA INFILE.

قم بتشغيل mariadb-import بهذا الشكل:

shell> mariadb-import [خيارات]
    اسم_قاعدة_البيانات
    ملف_نصي1 [ملف_نصي2 ...]

لكل ملف نصي مسمى في سطر الأوامر، يقوم mariadb-import بإزالة أي امتداد من اسم الملف ويستخدم النتيجة لتحديد اسم الجدول الذي سيتم استيراد محتويات الملف إليه. على سبيل المثال، الملفات المسماة patient.txt و patient.text و patient سيتم استيرادها جميعًا إلى جدول يسمى patient.

يدعم mariadb-import الخيارات التالية، والتي يمكن تحديدها في سطر الأوامر أو في مجموعات ملفات الخيارات [mariadb-import] و [client]. يدعم mariadb-import أيضًا خيارات معالجة ملفات الخيارات.

•--help, -?

عرض رسالة مساعدة والخروج.

•--character-sets-dir=مسار

الدليل الذي تم تثبيت مجموعات الأحرف فيه.

•--columns=قائمة_الأعمدة, -c قائمة_الأعمدة

يأخذ هذا الخيار قائمة مفصولة بفواصل من أسماء الأعمدة كقيمة له. يشير ترتيب أسماء الأعمدة إلى كيفية مطابقة أعمدة ملف البيانات بأعمدة الجدول.

•--compress, -C

ضغط جميع المعلومات المرسلة بين العميل والخادم إذا كان كلاهما يدعم الضغط.

•--debug[=خيارات_التصحيح], -# [خيارات_التصحيح]

كتابة سجل تصحيح. سلسلة خيارات_التصحيح النموذجية هي 'd:t:o،اسم_الملف'. الافتراضي هو 'd:t:o'.

•--debug-check

طباعة بعض معلومات التصحيح عند خروج البرنامج.

•--debug-info

طباعة معلومات التصحيح وإحصائيات استخدام الذاكرة ووحدة المعالجة المركزية عند خروج البرنامج.

•--default-auth=اسم_الإضافة

إضافة المصادقة الافتراضية للعميل المراد استخدامها.

•--default-character-set=اسم_مجموعة_الأحرف

استخدام اسم_مجموعة_الأحرف كمجموعة الأحرف الافتراضية.

•--defaults-extra-file=اسم_الملف

تعيين اسم_الملف كملف لقراءة الخيارات الافتراضية منه بعد قراءة ملفات الخيارات الافتراضية العامة. يجب إعطاؤه كأول خيار.

•--defaults-file=اسم_الملف

تعيين اسم_الملف كملف لقراءة الخيارات الافتراضية منه، وتجاوز ملفات الخيارات الافتراضية العامة. يجب إعطاؤه كأول خيار.

•--delete, -d

مسح الجدول قبل استيراد الملف النصي.

•--fields-terminated-by=..., --fields-enclosed-by=..., --fields-optionally-enclosed-by=..., --fields-escaped-by=...

هذه الخيارات لها نفس معنى الجمل المقابلة لـ LOAD DATA INFILE.

•--force, -f

تجاهل الأخطاء. على سبيل المثال، إذا لم يكن الجدول الخاص بملف نصي موجودًا، فاستمر في معالجة أي ملفات متبقية. بدون --force، يخرج mariadb-import إذا لم يكن الجدول موجودًا.

•--host=اسم_المضيف, -h اسم_المضيف

استيراد البيانات إلى خادم MariaDB على المضيف المحدد. المضيف الافتراضي هو localhost.

•--ignore, -i

انظر وصف الخيار --replace.

•--ignore-foreign-keys, -k

تعطيل فحوصات المفاتيح الخارجية أثناء استيراد البيانات.

•--ignore-lines=N

تجاهل أول N سطر من ملف البيانات.

•--innodb-optimize-keys

إنشاء فهارس ثانوية بعد تحميل البيانات، مما يسرع عملية التحميل (InnoDB فقط). الافتراضي هو التشغيل؛ استخدم --skip-innodb-optimize-keys لتعطيله.

•--lines-terminated-by=...

هذا الخيار له نفس معنى الجملة المقابلة لـ LOAD DATA INFILE. على سبيل المثال، لاستيراد ملفات Windows التي تنتهي أسطرها بزوج حرفي العودة/سطر جديد، استخدم --lines-terminated-by="\r\n". (قد تحتاج إلى مضاعفة الشرطات المائلة العكسية، اعتمادًا على اصطلاحات الإفلات لمفسر الأوامر الخاص بك.).

•--local, -L

قراءة الملفات المدخلة محليًا من جهاز العميل.

•--lock-tables, -l

قفل جميع الجداول للكتابة قبل معالجة أي ملفات نصية. هذا يضمن أن جميع الجداول متزامنة على الخادم.

•--low-priority

استخدام LOW_PRIORITY عند تحميل الجدول. يؤثر هذا فقط على محركات التخزين التي تستخدم أقفال المستوى فقط (مثل MyISAM و MEMORY و MERGE).

•--no-defaults

لا تقرأ الخيارات الافتراضية من أي ملف خيارات. يجب إعطاؤه كأول وسيط.

•--parallel=N, -j N

عدد عمليات LOAD DATA التي يتم تنفيذها بالتوازي. --use-threads هو مرادف.

•--password[=كلمة_المرور], -p[كلمة_المرور]

كلمة المرور المراد استخدامها عند الاتصال بالخادم. إذا استخدمت الصيغة القصيرة للخيار (-p)، فلا يمكنك ترك مسافة بين الخيار وكلمة المرور. إذا حذفت قيمة كلمة_المرور بعد الخيار --password أو -p في سطر الأوامر، فسيطلب منك mariadb-import إدخالها.

يجب اعتبار تحديد كلمة مرور في سطر الأوامر غير آمن. يمكنك استخدام ملف خيارات لتجنب إعطاء كلمة المرور في سطر الأوامر.

•--pipe, -W

على نظام Windows، اتصل بالخادم عبر أنبوب مسمى. ينطبق هذا الخيار فقط إذا كان الخادم يدعم اتصالات الأنابيب المسماة.

•--plugin-dir=الاسم


دليل إضافات جانب العميل.

•--port=رقم_المنفذ, -P رقم_المنفذ

رقم منفذ TCP/IP المراد استخدامه للاتصال. يفرض --protocol=tcp عند تحديده في سطر الأوامر بدون خصائص اتصال أخرى.

•--protocol={TCP|SOCKET|PIPE|MEMORY}

بروتوكول الاتصال المراد استخدامه للاتصال بالخادم. إنه مفيد عندما تتسبب معلمات الاتصال الأخرى عادةً في استخدام بروتوكول غير الذي تريده.

•--print-defaults

طباعة قائمة وسائط البرنامج والخروج. يجب إعطاؤه كأول وسيط.

•--replace, -r

يتحكم الخياران --replace و --ignore في التعامل مع صفوف الإدخال التي تكرر الصفوف الموجودة على قيم المفاتيح الفريدة. إذا حددت --replace، فإن الصفوف الجديدة تحل محل الصفوف الموجودة التي لها نفس قيمة المفتاح الفريد. إذا حددت --ignore، فسيتم تخطي صفوف الإدخال التي تكرر صفًا موجودًا على قيمة مفتاح فريد. إذا لم تحدد أيًا من الخيارين، فسيحدث خطأ عند العثور على قيمة مفتاح مكررة، وسيتم تجاهل بقية الملف النصي.

•--silent, -s

الوضع الصامت. إنتاج إخراج فقط عند حدوث أخطاء.

•--socket=مسار, -S مسار

للاتصالات إلى localhost، ملف socket Unix المراد استخدامه، أو، على نظام Windows، اسم الأنبوب المسمى المراد استخدامه. يفرض --protocol=socket عند تحديده في سطر الأوامر بدون خصائص اتصال أخرى؛ على نظام Windows، يفرض --protocol=pipe.

NAME

\n

mariadb-import – data import utility

\n
\n
\n

SYNOPSIS

\n

mariadb-import [options] [--] [<file> ...]

\n

mariadb-import [options] db_name table_name <file>

\n

mariadb-import [options] db_name <file>

\n
\n
\n

DESCRIPTION

\n

The mariadb-import utility is a client for the mariadb program that provides a convenient interface for importing data files into MariaDB tables. It is functionally equivalent to executing the LOAD DATA SQL statement. mariadb-import supports both standard input and files as sources for data.

\n

Options are given on the command line. They can be given in the same order as for the mariadb client. mariadb-import supports the --help option to display the available options.

\n

The following options are supported:

\n
\n

--binary-mode, -b

\n

Interpret input files in binary mode. This is equivalent to using the --binary-mode option for LOAD DATA. By default, input files are interpreted in text mode.

\n
\n
\n

--character-sets-dir=dir_name

\n

The directory in which to look for character set files. By default, this is the directory specified by the character_sets_dir system variable.

\n
\n
\n

--compress, -C

\n

Use compression in the connection protocol. If the server also supports compressed protocols, the clients and server will use compression to speed up data transfer.

\n
\n
\n

--database=db_name, -D db_name

\n

The database to use. This option is equivalent to specifying the database name as the first argument to mariadb-import.

\n
\n
\n

--debug[=debug_options], -# debug_options

\n

Write a debug log to a socket or a file. See mysqld_safe(1) for information about the format of debug options.

\n
\n
\n

--default-auth=method

\n

Use the specified authentication plugin. The default is determined by the server.

\n
\n
\n

--fields-enclosed-by=char

\n

Enclose field values in this character. See LOAD DATA for more details.

\n
\n
\n

--fields-optionally-enclosed-by=char

\n

Optionally enclose field values in this character. See LOAD DATA for more details.

\n
\n
\n

--fields-terminated-by=char

\n

Terminate field values with this character. See LOAD DATA for more details.

\n
\n
\n

--force, -f

\n

Continue even if the import encounters errors. Errors are reported, but the program continues processing the rest of the input.

\n
\n
\n

--host=host_name, -h host_name

\n

Connect to the specified host. Default is 'localhost'.

\n
\n
\n

--ignore-lines=N

\n

Skip the first N lines of input. See LOAD DATA for more details.

\n
\n
\n

--local, -L

\n

Read input files from the client host. This is equivalent to using the --local option for LOAD DATA. By default, input files are read from the server host.

\n
\n
\n

--lines-terminated-by=string

\n

Terminate lines with this string. Default is \n\\n. See LOAD DATA for more details.

\n
\n
\n

--null-value=string

\n

Interpret this string as NULL. See LOAD DATA for more details.

\n
\n
\n

--password[=password], -p[password]

\n

The password to use when connecting to the server. If you specify the -p option without a value, it prompts you for the password.

\n
\n
\n

--port=port_num, -P port_num

\n

The TCP/IP port number to use for the connection. Default is 3306.

\n
\n
\n

--protocol=protocol

\n

The connection protocol to use (e.g., TCP, SOCKET, PIPE, MEMORY).

\n
\n

--quiet, -q

\n

Suppress all output except for errors. Equivalent to --silent.

\n
\n

--replace

\n

Continue even if the import encounters duplicate-key errors. Instead of aborting, replace the old row with the new row. See LOAD DATA for more details.

\n
\n

--silent, -s

Silent mode. Produce only error messages.
