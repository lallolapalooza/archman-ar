Mail::Box::Dir::Message(3pm)

Mail::Box - Base class for mail-box implementations

NAME

Mail::Box::Dir::Message - Directory based message object

INHERITANCE

This class is part of Mail-Box. It inherits methods from Mail::Message(3pm).

SYNOPSIS

Requires: Mail::Mailbox(3pm), Mail::File(3pm).

  # This class is not meant to be used directly.
  # Use Mail::Box::new() instead.

DESCRIPTION

This class represents a single message file within a directory based mailbox. The methods are overloaded to read/write the message content from/to a file.

METHODS

This class does not introduce new public methods. It overloads several methods from the parent class.

Overloaded methods:
  .read()      reads the message from the file
  .write()     writes the message to the file
  .delete()    deletes the message file
  .move($to)   moves the message file to another folder
  .copy($to)   copies the message file to another folder

The actual file operations are delegated to Mail::File(3pm).

DETAILS

The content of the message is stored in a file named after the message ID. When the folder is opened, only the filenames are collected. The content is read on demand.

DIAGNOSTICS

Error: Cannot open file $filename: $!
The message object is associated with a file. This file could not be opened for reading or writing. This might be a permission problem. Cast by open(), write().
Error: Cannot create file $filename: $!
A new file could not be created. This is probably a permission problem in the directory where the file should be created. Cast by create().
Error: Cannot delete file $filename: $!
The message file could not be deleted. This might be a permission problem. Cast by delete().
Error: Cannot rename $from to $to: $!
The message file could not be renamed. This is needed when the message content is written to disk. Cast by write(), move(), copy().
Error: Cannot create directory $filename: $!
This error happens when a new folder is created. The directory specified could not be created. This is probably a permission problem. Cast by create().
Error: Failed to move file $filename
When a modified or new message is written to disk, it is first written to a temporary file in the folder directory. Then, the new file is moved to replace the existing file. Apparently, the latter fails. Cast by create()
Error: Failed to move $new to $filename: $!
When a modified or new message is written to disk, it is first written to a temporary file in the folder directory. Then, the new file is moved to replace the existing file. Apparently, the latter fails. Cast by create()
Error: Method bounce requires To, Cc, or Bcc
The message bounce() method forwards a received message off to someone else without modification; you must specified it's new destination. If you have the urge not to specify any destination, you probably are looking for reply(). When you wish to modify the content, use forward(). Cast by bounce()
