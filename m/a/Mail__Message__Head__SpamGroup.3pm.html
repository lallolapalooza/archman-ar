Mail__Message__Head__SpamGroup(3pm)

الحزمة: perl-mail-message

التراخيص: PerlArtistic, GPL

Mail::Message::Head::SpamGroup(3) وثائق Perl من مساهمات المستخدم Mail::Message::Head::SpamGroup(3)

الاسم

Mail::Message::Head::SpamGroup - حقول رأس متعلقة بمكافحة البريد العشوائي

الوراثة

Mail::Message::Head::SpamGroup
  هو Mail::Message::Head::FieldGroup
  هو Mail::Reporter

الملخص

my $sg = Mail::Message::Head::SpamGroup->new(head => $head, ...);
$head->addSpamGroup($sg);
my $sg = $head->addSpamGroup( <options> );
$sg->delete;
my @sgs = $head->spamGroups;

الوصف

مجموعة البريد العشوائي هي مجموعة من حقول الرأس التي تمت إضافتها بواسطة برنامج اكتشاف البريد العشوائي ومكافحته. تعرف هذه الفئة التفاصيل المختلفة حول هذا البرنامج.

موسعة من الوصف في Mail::Message::Head::FieldGroup.

الطرق

موسعة من الطرق في Mail::Message::Head::FieldGroup.

البناة

موسعة من البناة في Mail::Message::Head::FieldGroup.

$obj->clone()
موروثة، انظر البناة في Mail::Message::Head::FieldGroup
$any->fighter($name, %options)
يحصل على إعدادات لمقاتل بريد عشوائي معين، ربما بعد تعيينها. الطريقة knownFighters() تعيد الأسماء المعرفة. الأسماء حساسة لحالة الأحرف.

تُمرر خيارات %options كإعدادات لبرنامج فلترة البريد العشوائي، باستثناء تلك المحددة هنا بشكل خاص.

-Option --Default
 fields   <required>
 isspam   <required>
 version  undef
fields => REGEXP
التعبير العادي الذي يشير إلى أي من حقول الرأس التي تتم إضافتها بواسطة برنامج اكتشاف البريد العشوائي ومكافحته.
isspam => COD
يجب أن يعيد COD "true" أو "false"، للإشارة إلى ما إذا كان مقاتل البريد العشوائي يعتقد أن الرسالة تحتوي على بريد عشوائي. يتم استدعاء مرجع COD مع كائن مجموعة البريد العشوائي (قيد الإنشاء) والرأس الذي يتم فحصه.
version => COD
يمكن استدعاؤه لجمع الاسم الرسمي وإصدار البرنامج المستخدم للكشف عن البريد العشوائي. يتم استدعاء مرجع COD مع كائن مجموعة البريد العشوائي (قيد الإنشاء) والرأس الذي يتم فحصه.

» مثال: إضافة تعريفات خاصة بك لمقاتل البريد العشوائي

Mail::Message::Head::SpamGroup->fighter( 'MY-OWN',
   fields => qw/^x-MY-SPAM-DETECTOR-/,
   isspam => sub { my ($sg, $head) = @_; $head->fields > 100 },
);
$obj->from($head|$message, %options)
يعيد قائمة بكائنات "Mail::Message::Head::SpamGroup"، بناءً على $message أو رأس $head المحدد. تحسين القاعدة، انظر البناة في Mail::Message::Head::FieldGroup 
-Option--Default
 types   undef
types => ARRAY-OF-NAMES
سيتم اختبار الأنواع المحددة فقط. إذا كان المصفوفة فارغة، فسيتم إرجاع قائمة فارغة. بدون هذا الخيار، سيتم إرجاع جميع المجموعات.
$any->habeasSweFieldsCorrect( [$message|$head] )
يعيد قيمة "true" إذا كان $message أو $head يحتوي على رؤوس "Habeas-SWE" صحيحة. بدون وسيط، يتم استخدامه كطريقة مثيل على مجموعة بريد عشوائي موجودة.

» مثال: التحقق من رؤوس Habeas-SWE

if(Mail::Message::Head::SpamGroup->habeasSweFieldsCorrect($message))
{   $message->label(spam => 0);
}
my $sg = $message->head->spamGroups('Habeas-SWE');
if($sg->habeasSweFieldsCorrect) { ... };
use List::Util 'first';
if(first {$_->habeasSweFieldsCorrect} $head->spamGroups)
{   ...
}
$any->implementedTypes()
موروثة، انظر البناة في Mail::Message::Head::FieldGroup
$any->isSpamGroupFieldName($name)
$any->knownFighters()
يعيد قائمة غير مرتبة بجميع الأسماء التي تمثل برامج مقاتلة بريد عشوائي معرفة مسبقًا. يمكنك الاستعلام عن التفاصيل حولها، وتسجيل مقاتلين إضافيين باستخدام الطريقة fighter().
$class->new($fields, %options)
ينشئ كائنًا يحتفظ بمجموعة من الحقول التي تمت إضافتها بواسطة برنامج مكافحة البريد العشوائي. تحسين القاعدة، انظر البناة في Mail::Message::Head::FieldGroup 
-Option--Default
 head      Mail::Message::Head::FieldGroup  undef
 log       Mail::Reporter                   'WARNINGS'
 software  Mail::Message::Head::FieldGroup  undef
 trace     Mail::Reporter                   'WARNINGS'
 type      Mail::Message::Head::FieldGroup  undef
 version   Mail::Message::Head::FieldGroup  undef
head => $head
log => LEVEL
software => STRING
trace => LEVEL
type => STRING
version => STRING
$obj->spamDetected( [BOOLEAN] )
يعيد (بعد التعيين) ما إذا كانت مجموعة رؤوس البريد العشوائي هذه تعتقد أن هذا بريد عشوائي. انظر Mail::Message::Head::Complete::spamDetected().

» مثال:

die if $head->spamDetected;
foreach my $sg ($head->spamGroups)
{   print $sg->type." found spam\n" if $sg->spamDetected;
}

التشخيصات

خطأ: الحزمة $package لا تنفذ $method.
خطأ فادح: الحزمة المحددة (أو إحدى فئاتها العليا) لا تنفذ هذه الطريقة حيث ينبغي. هذه الرسالة تعني أن بعض الفئات الأخرى ذات الصلة تنفذ هذه الطريقة بينما الفئة المعنية لا تفعل ذلك. ربما يجب عليك التحقق من هذا وربما إبلاغ مؤلف الحزمة. تم رميها بواسطة notImplemented()
