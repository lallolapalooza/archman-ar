MARIADBD-MULTI(1) نظام قواعد بيانات ماريا دي بي MARIADBD-MULTI(1)

الاسم

mariadbd-multi - إدارة خوادم ماريا دي بي متعددة (mariadbd-multi هو الآن رابط رمزي لـ mariadbd-multi)

الملخص

mariadbd-multi [خيارات] {start|stop|report} [GNR[,GNR] ...]

الوصف

تم تصميم mariadbd-multi لإدارة عدة عمليات mariadbd التي تستمع للاتصالات على ملفات مقبس Unix مختلفة ومنافذ TCP/IP. يمكنه بدء أو إيقاف الخوادم، أو الإبلاغ عن حالتها الحالية.

يبحث mariadbd-multi عن مجموعات تسمى [mariadbdN] في my.cnf (أو في الملف المسمى بواسطة الخيار --config-file). N يمكن أن تكون أي عدد صحيح موجب. يُشار إلى هذا الرقم في المناقشة التالية برقم مجموعة الخيارات، أو GNR. تميز أرقام المجموعات مجموعات الخيارات عن بعضها البعض وتُستخدم كمعاملات لـ mariadbd-multi لتحديد الخوادم التي تريد بدءها، أو إيقافها، أو الحصول على تقرير حالة لها. الخيارات المدرجة في هذه المجموعات هي نفس الخيارات التي تستخدمها في المجموعة [mariadbd] المستخدمة لبدء mariadbd. ومع ذلك، عند استخدام خوادم متعددة، من الضروري أن يستخدم كل منها قيمته الخاصة لخيارات مثل ملف مقبس Unix ورقم منفذ TCP/IP.

لاستدعاء mariadbd-multi، استخدم الصيغة التالية:

shell> mariadbd-multi [خيارات] {start|stop|report} [GNR[,GNR] ...]

يشير start، stop، و report إلى العملية المراد تنفيذها. يمكنك تنفيذ العملية المحددة لخادم واحد أو عدة خوادم، اعتمادًا على قائمة GNR التي تتبع اسم الخيار. إذا لم تكن هناك قائمة، فسيقوم mariadbd-multi بتنفيذ العملية لجميع الخوادم في ملف الخيارات.

يمثل كل قيمة GNR رقم مجموعة خيارات أو نطاقًا من أرقام المجموعات. يجب أن تكون القيمة هي الرقم الموجود في نهاية اسم المجموعة في ملف الخيارات. على سبيل المثال، GNR للمجموعة المسماة [mariadbd17] هو 17. لتحديد نطاق من الأرقام، افصل بين الرقم الأول والأخير بشرطة. القيمة GNR 10-13 تمثل المجموعات [mariadbd10] حتى [mariadbd13]. يمكن تحديد مجموعات أو نطاقات مجموعات متعددة في سطر الأوامر، مفصولة بفواصل. يجب ألا تكون هناك أي مسافات بيضاء (مسافات أو علامات جدولة) في قائمة GNR؛ سيتم تجاهل أي شيء بعد مسافة بيضاء.

يبدأ هذا الأمر خادمًا واحدًا باستخدام مجموعة الخيارات [mariadbd17]:

shell> mariadbd-multi start 17

يوقف هذا الأمر عدة خوادم، باستخدام مجموعات الخيارات [mariadbd8] و [mariadbd10] حتى [mariadbd13]:

shell> mariadbd-multi stop 8,10-13

لمثال على كيفية إعداد ملف خيارات، استخدم هذا الأمر:

shell> mariadbd-multi --example

يبحث mariadbd-multi عن ملفات الخيارات كما يلي:

•مع --no-defaults، لا تتم قراءة أي ملفات خيارات.
•مع --defaults-file=file_name، تتم قراءة الملف المسمى فقط.
•بخلاف ذلك، تتم قراءة ملفات الخيارات في قائمة المواقع القياسية، بما في ذلك أي ملف مسمى بواسطة الخيار --defaults-extra-file=file_name، إذا تم توفيره. (إذا تم توفير الخيار عدة مرات، يتم استخدام القيمة الأخيرة.)

تبحث ملفات الخيارات التي تتم قراءتها عن مجموعات الخيارات [mariadbd-multi] و [mariadbdN]. يمكن استخدام المجموعة [mariadbd-multi] للخيارات الخاصة بـ mariadbd-multi نفسه. يمكن استخدام مجموعات [mariadbdN] للخيارات التي يتم تمريرها إلى مثيلات mariadbd المحددة.

يمكن استخدام مجموعات [mariadbd] أو [mariadbd_safe] للخيارات المشتركة التي تقرأها جميع مثيلات mariadbd أو mariadbd_safe. يمكنك تحديد خيار --defaults-file=file_name لاستخدام ملف تكوين مختلف لهذا المثيل، وفي هذه الحالة سيتم استخدام مجموعات [mariadbd] أو [mariadbd_safe] من هذا الملف لهذا المثيل.

يدعم mariadbd-multi الخيارات التالية.

•--help

عرض رسالة مساعدة والخروج.

•--example

عرض ملف خيارات نموذجي.

•--log=file_name

تحديد اسم ملف السجل. إذا كان الملف موجودًا، تتم إضافة مخرجات السجل إليه.

•--mariadb-admin=prog_name

الثنائي mariadb-admin الذي سيتم استخدامه لإيقاف الخوادم.

•--mariadbd=prog_name

الثنائي mariadbd الذي سيتم استخدامه. لاحظ أنه يمكنك تحديد mariadbd_safe كقيمة لهذا الخيار أيضًا. إذا استخدمت mariadbd_safe لبدء الخادم، يمكنك تضمين خيارات mariadbd أو ledir في مجموعة الخيارات [mariadbdN] المقابلة. تشير هذه الخيارات إلى اسم الخادم الذي يجب على mariadbd_safe بدءه واسم المسار للدليل الذي يوجد فيه الخادم. (انظر وصف هذه الخيارات في mariadbd_safe(1).) مثال:

[mariadbd38]
mariadbd = mariadbd-debug
ledir  = /opt/local/mysql/libexec
•--no-log

طباعة معلومات السجل إلى stdout بدلاً من ملف السجل. افتراضيًا، تذهب المخرجات إلى ملف السجل.

•--password=password

كلمة المرور لحساب MariaDB المراد استخدامه عند استدعاء mariadb-admin. لاحظ أن قيمة كلمة المرور ليست اختيارية لهذا الخيار، على عكس برامج MariaDB الأخرى.

•--silent

الوضع الصامت؛ تعطيل التحذيرات.

•--tcp-ip

الاتصال بخوادم MariaDB عبر منفذ TCP/IP بدلاً من مقبس UNIX. يؤثر هذا على الإيقاف والإبلاغ. إذا كان ملف المقبس مفقودًا، فقد لا يزال الخادم يعمل، ولكن لا يمكن الوصول إليه إلا عبر منفذ TCP/IP. افتراضيًا، يتم الاتصال عبر مقبس UNIX. يؤثر هذا الخيار على عمليات الإيقاف والإبلاغ.

•--user=user_name

اسم المستخدم لحساب MariaDB المراد استخدامه عند استدعاء mariadb-admin.

•--verbose

كن أكثر تفصيلاً.

•--version

عرض معلومات الإصدار والخروج.

•--wsrep-new-cluster

بدء تشغيل مجموعة.

بعض الملاحظات حول mariadbd-multi:

•الأهم: قبل استخدام mariadbd-multi، تأكد من فهمك لمعاني الخيارات التي يتم تمريرها إلى خوادم mariadbd ولماذا تريد أن يكون لديك عمليات mariadbd منفصلة. احذر من مخاطر استخدام عدة خوادم mariadbd بنفس دليل البيانات. استخدم أدلة بيانات منفصلة، إلا إذا كنت تعرف ما تفعله. بدء عدة خوادم بنفس دليل البيانات لا يمنحك أداءً إضافيًا في نظام متعدد الخيوط.
•مهم: تأكد من أن دليل بيانات كل خادم متاح بالكامل لحساب Unix الذي تبدأ به عملية mariadbd المحددة. لا تستخدم حساب Unix root لهذا الغرض، إلا إذا كنت تعرف ما تفعله.
•تأكد من أن حساب MariaDB المستخدم لإيقاف خوادم mariadbd (باستخدام برنامج mariadbadmin) له نفس اسم المستخدم وكلمة المرور لكل خادم. أيضًا، تأكد من أن الحساب لديه إذن SHUTDOWN. إذا كانت الخوادم التي تريد إدارتها لديها أسماء مستخدمين أو كلمات مرور مختلفة للحسابات الإدارية، فقد ترغب في إنشاء حساب على كل خادم له نفس اسم المستخدم وكلمة المرور. على سبيل المثال، يمكنك إعداد حساب multi_admin مشترك عن طريق تنفيذ الأوامر التالية لكل خادم: 
shell> mariadb -u root -S /tmp/mariadb.sock -p
Enter password:
mariadb> GRANT SHUTDOWN ON *.*
    -> TO 'multi_admin'@'localhost' IDENTIFIED BY 'multipass';

NAME

mariadbd-multi — manage multiple MariaDB server instances

\n
\n\n
\n

SYNOPSIS

mariadbd-multi [options] command

\n

mariadbd-multi [options] command group...

\n
\n\n
\n

DESCRIPTION

The mariadb-multi script is designed to manage multiple MariaDB database servers running on the same machine. Each server instance can have its own data directory, log files, and configuration settings.

\n

The script relies on an option file, typically named my.cnf, which should contain sections for each server instance you wish to manage. These sections are identified by the prefix [mariadbdN], where N is a unique number for each server instance.

\n

The following commands are supported:

\n
\n
start
\n
Starts all MariaDB server instances defined in the option file.
\n
stop
\n
Stops all MariaDB server instances defined in the option file.
\n
restart
\n
Restarts all MariaDB server instances.
\n
status
\n
Shows the status of all MariaDB server instances.
\n
\n

You can also specify a group number to perform an action on a specific instance. For example, mariadbd-multi start 2 will start only the server instance defined in the [mariadbd2] section.

\n
The --bind-address option can be used to specify which network interface a particular server instance should listen on. This is useful if the host has
\nmultiple network addresses, you can use --bind-address to cause
\ndifferent servers to listen to different interfaces.
\n

\nmariadbd is that mariadbd-safe monitors its mariadbd
