Math::BigInt::Calc(3perl) دليل مبرمجي Perl Math::BigInt::Calc(3perl)

الاسم

Math::BigInt::Calc - وحدة Perl خالصة لدعم Math::BigInt

الملخص

# للاستخدام مع Math::BigInt
use Math::BigInt lib => 'Calc';
# للاستخدام مع Math::BigFloat
use Math::BigFloat lib => 'Calc';
# للاستخدام مع Math::BigRat
use Math::BigRat lib => 'Calc';
# تحديد طول الأساس بشكل صريح وما إذا كان سيتم "استخدام الأعداد الصحيحة"
use Math::BigInt::Calc base_len => 4, use_int => 1;
use Math::BigInt lib => 'Calc';

الوصف

Math::BigInt::Calc ترث من Math::BigInt::Lib.

في هذه المكتبة، يتم تمثيل الأرقام داخليًا في الأساس B = 10**N، حيث N هو أكبر عدد صحيح ممكن لا يسبب تجاوزًا في الحسابات الوسيطة. يتم تخزين عناصر الأساس B في مصفوفة، مع تخزين العنصر الأقل أهمية في العنصر صفر من المصفوفة. لا توجد عناصر صفرية بادئة، باستثناء عنصر صفر واحد عندما يكون الرقم صفرًا. على سبيل المثال، إذا كان B = 10000، فسيتم تمثيل الرقم 1234567890 داخليًا كـ [7890, 3456, 12].

خيارات

عند تحميل الوحدة، تقوم بحساب الأسي الأقصى، أي قوة 10، التي يمكن استخدامها مع وبدون "استخدام الأعداد الصحيحة" في الحسابات. الافتراضي هو استخدام هذا الأسي الأقصى. إذا تجاوزت تركيبة قيمة 'base_len' وقيمة 'use_int' القيمة القصوى، يتم إطلاق خطأ.

base_len
يمكن تحديد طول الأساس بشكل صريح باستخدام الخيار 'base_len'. يجب أن تكون القيمة عددًا صحيحًا موجبًا. 
use Math::BigInt::Calc base_len => 4;  # استخدم 10000 كأساس داخلي
use_int
يستخدم هذا الخيار لتحديد ما إذا كان سيتم استخدام "استخدام الأعداد الصحيحة" في الحسابات الداخلية. يتم تفسير القيمة كقيمة منطقية، لذا استخدم 0 أو "" للقيمة False وأي شيء آخر للقيمة True. إذا لم يتم تحديد 'base_len' مع 'use_int'، فسيتم استخدام القيمة الحالية لطول الأساس. 
use Math::BigInt::Calc use_int => 1;   # استخدم "استخدام الأعداد الصحيحة" داخليًا

الأساليب

يحتوي هذا الملخص فقط على الأساليب الخاصة بـ "Math::BigInt::Calc". بالنسبة للأساليب الأخرى، راجع Math::BigInt::Lib.

_base_len()
تحديد طول الأساس المطلوب وما إذا كان سيتم تمكين "استخدام الأعداد الصحيحة" في الحسابات. 
Math::BigInt::Calc -> _base_len($base_len, $use_int);

لاحظ أنه من الأفضل تحديد طول الأساس وما إذا كان سيتم استخدام الأعداد الصحيحة كخيارات عند تحميل الوحدة، على سبيل المثال بهذا الشكل

use Math::BigInt::Calc base_len => 6, use_int => 1;

انظر أيضًا

Math::BigInt::Lib لوصف واجهة برمجة التطبيقات.

مكتبات بديلة Math::BigInt::FastCalc, Math::BigInt::GMP, Math::BigInt::Pari, Math::BigInt::GMPz, و Math::BigInt::BitVect.

بعض الوحدات التي تستخدم هذه المكتبات Math::BigInt, Math::BigFloat, و Math::BigRat.
