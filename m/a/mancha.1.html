الحزمة: chawan

MANCHA(1) دليل الأوامر العامة MANCHA(1)

الاسم

mancha - عرض صفحات الدليل عبر cha(1)

الملخص

mancha [-M path] [section] name

mancha [-M path] [section] -k keyword

mancha -l file

الوصف

mancha يتيح عرض صفحات الدليل باستخدام متصفح Chawan. وهو مشابه للأداة المساعدة w3mman(1).

سيقوم mancha باستدعاء cha(1) مع عناوين URL المناسبة من نوع man: أو man-k: أو man-l:. يقوم محول البروتوكول بعد ذلك بفتح صفحة الدليل وحقن ترميز إليها، على سبيل المثال، يتم تحويل مراجع صفحات الدليل إلى روابط من نوع man:.

الخيارات

خيارات سطر الأوامر هي:

-M path
قم بتعيين path كمتغير البيئة MANPATH. انظر man(1) للحصول على تفاصيل حول كيفية تفسير ذلك.
-k keyword
استخدم keyword للبحث عن صفحة الدليل بناءً على الكلمات المفتاحية.
-l file
افتح الملف المحلي المحدد file كصفحة دليل.

البيئة

تُستخدم متغيرات البيئة التالية:

MANCHA_CHA
إذا تم تعيينه، يتم استخدام محتويات المتغير بدلاً من cha. (لاحظ أن الأمر cha يتم استدعاؤه عبر system(3)، لذا لا تحتاج إلى استبداله طالما تم العثور على cha في PATH الخاص بك.)
MANCHA_MAN
إذا تم تعيينه، يتم استخدام محتويات المتغير بدلاً من /usr/bin/man.
MANCHA_APROPOS
إذا تم تعيينه، يتم استخدام محتويات المتغير بدلاً من /usr/bin/man.

(هذا ليس خطأ إملائي؛ بشكل طبيعي (باستثناء FreeBSD)، يفترض mancha أن man(1) متوافق مع apropos(1) ويقبل المعلمة -s. لذلك، فإن استبدال MANCHA_MAN يستبدل أيضًا الأمر المستخدم لـ man-k، طالما أن MANCHA_APROPOS غير معين.)

انظر أيضاً
