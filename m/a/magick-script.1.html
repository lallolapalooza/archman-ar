NAME

magick-script - Magick Image Processing Language (MIP) script

SYNOPSIS

magick input-file [input-option] [operation ...] [output-option] output-file

magick-script input-file [input-option] [operation ...] [output-option] output-file

OVERVIEW

The magick program is a powerful multi-threaded command-line interface to the MagickWand imaging library. Use it to create, edit, compose, or convert bitmap images. It supports over 100 image formats including PNG, JPEG, GIF, TIFF, DPX, EXR, WebP, HEIC, and RAW. Use magick to process your images in seconds.

The Magick Image Processing Language (MIP) is a high-level scripting language that lets you perform image processing operations with great flexibility and control. It offers a vast array of image processing operations, from basic transformations like resizing and cropping to complex effects like compositing, special effects, and animation.

DESCRIPTION

The magick command performs image processing operations specified by a sequence of operands and options. It supports a wide range of operations that can be applied to images. The operations are described below.

Use any setting or operator as an output-option. Only a limited number of setting are input-option. They include: -antialias, -caption, -density, -define, -encoding, -font, -pointsize, -size, and -texture as well as any of the miscellaneous options.

By default, the image format of `file' is determined by its magic number. To specify a particular image format, precede the filename with an image format name and a colon (i.e. ps:image) or specify the image type as the filename suffix (i.e. image.ps). Specify 'file' as '-' for standard input or output.
