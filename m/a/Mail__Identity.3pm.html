NAME

Mail::Identity::Collection - collection of identities

INHERITANCE

Inherits methods from Mail::Identity::Item.

SYNOPSIS

  use Mail::Identity;
  my $coll = Mail::Identity::Collection->new (%options);
  # add a single identity object
  $coll->add (Mail::Identity->new (%options));
  # add a collection of identity objects
  $coll->add ($another_collection);
  # add a collection by defining the type and options
  $coll->addCollection ($type, %options);
  # get a specific identity object
  my $item = $coll->find ($role);
  # iterate over all identities in the collection
  for my $item ($coll->list) { ... }
  # get the collection type name
  my $type = $coll->type;
  # get the collection class name
  my $class = $coll->class;
  # get the collection options
  my $options = $coll->options;
  # get the number of items in the collection
  my $count = $coll->count;
  # remove a specific identity object
  $coll->remove ($item);
  # remove all identities from the collection
  $coll->flush;
  # create a new collection based on an existing one
  my $new_coll = $coll->clone;
  # load an existing collection from a file
  my $loaded_coll = Mail::Identity::Collection->load ($file, %options);
  # store the collection to a file
  $coll->store ($file);
  # get the user associated with this collection
  my $user = $coll->user;

DESCRIPTION

This is the abstract base class for all collections of Mail::Identity objects. It defines the interface that all collection classes must implement.

A collection is a container for one or more identity objects. It provides methods to add, remove, find, and iterate over the identities it contains. Collections can be created directly or loaded from a file. They can also be stored to a file.

The actual implementation of the collection (e.g., how the identities are stored and retrieved) is done by concrete subclasses like Mail::Identity::List, Mail::Identity::Database, etc.

METHODS

The following methods are available:

$obj->add($item)
Adds the given $item to the collection. The $item must be a Mail::Identity object or a Mail::Identity::Collection object.
$obj->addCollection($type, %options)
Adds a new collection of the specified $type with the given %options to the current collection. The new collection becomes a sub-collection of the current one.
$obj->class()
Returns the class name of the collection object.
$obj->clone()
Creates and returns a deep copy of the collection.
$obj->count()
Returns the number of identities in the collection.
$obj->find($role)
Returns the first identity object in the collection that matches the given $role. If no match is found, it returns undef.
$obj->flush()
Removes all identities from the collection.
$obj->load($file, %options)
A class method that loads a collection from the specified $file. The %options are passed to the constructor of the collection class.
$obj->list()
Returns a list of all identity objects in the collection.
$obj->options()
Returns the options that were used to create the collection.
$obj->remove($item)
Removes the specified $item from the collection.
$obj->store($file)
Stores the collection to the specified $file.
$obj->type()
Returns the type name of the collection.
$obj->user()
Inherited, see "Collections" in User::Identity::Item

Searching

Extends "Searching" in User::Identity::Item.

$obj->find($collection, $role)
Inherited, see "Searching" in User::Identity::Item

DIAGNOSTICS

Error: $object is not a collection.
The first argument is an object, but not of a class which extends User::Identity::Collection. Cast by addCollection()
Error: Cannot load collection module for $type ($class).
Either the specified $type does not exist, or that module named $class returns compilation errors. If the type as specified in the warning is not the name of a package, you specified a nickname which was not defined. Maybe you forgot the 'require' the package which defines the nickname. Cast by addCollection()
Error: Creation of a collection via $class failed.
The $class did compile, but it was not possible to create an object of that class using the options you specified. Cast by addCollection()
Error: Don't know what type of collection you want to add.
If you add a collection, it must either by a collection object or a list of options which can be used to create a collection object. In the latter case, the type of collection must be specified. Cast by addCollection()
Warning: No collection $name
The collection with $name does not exist and can not be created. Cast by add()
