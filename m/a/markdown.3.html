markdown(3)

الحزمة: discount

التراخيص: BSD-3-Clause

MARKDOWN(3) دليل وظائف المكتبة MARKDOWN(3)

الاسم

markdown — معالجة مستندات Markdown

المكتبة

Markdown (libmarkdown, -lmarkdown)

الملخص

#include <mkdio.h>

MMIOT
*mkd_in(FILE *input, int flags);

MMIOT
*mkd_string(char *string, int size, int flags);

int
markdown(MMIOT *doc, FILE *output, int flags);

الوصف

تقوم هذه الدوال بتحويل مستندات وسلاسل Markdown إلى HTML. markdown() تعالج مستندًا كاملاً، بينما mkd_text() تعالج سلسلة واحدة.

لمعالجة ملف، تقوم بتمرير FILE* إلى mkd_in()، وإذا أعادت قيمة غير صفرية، فإنك تمررها إلى markdown()، والتي تقوم بعد ذلك بكتابة المستند المحوّل إلى FILE* المحدد. إذا تمت كتابة مدخلاتك بالفعل في سلسلة (مدخلات تم إنشاؤها أو ملف تم فتحه باستخدام mmap(2)) يمكنك تغذية تلك السلسلة إلى mkd_string() وتمرير قيمتها المرتجعة إلى markdown.()

Markdown() تقبل القيم التالية للعلامات (أو-ed معًا إذا لزم الأمر) لتقييد كيفية معالجتها للمدخلات:

MKD_NOLINKS
لا تقم بمعالجة الروابط، وحظر <a> علامات.
MKD_NOIMAGE
لا تقم بمعالجة الصور، وحظر <img>.
MKD_NOPANTS
لا تقم بتشغيل smartypants().
MKD_NOHTML
لا تسمح بـ HTML خام على الإطلاق
MKD_STRICT
تعطيل الخطوط العريضة والتركيز المرن.
MKD_TAGTEXT
معالجة النص لوضعه داخل علامة html (ID=, NAME=, <title>, &tc)؛ لا <em>، لا <bold>، لا html أو [] توسيع.
MKD_NO_EXT
لا تسمح بالبروتوكولات الزائفة.
MKD_CDATA
إنشاء رمز لـ XML ![CDATA[...]].
MKD_NOSUPERSCRIPT
لا تنشئ أُسسًا. يحدث التركيز في كل مكان
MKD_NOTABLES
منع الجداول.
MKD_NOSTRIKETHROUGH
منع ~~strikethrough~~.
MKD_TOC
قم بمعالجة جدول المحتويات.
MKD_1_COMPAT
التوافق مع MarkdownTest_1.0
MKD_AUTOLINK
اجعل http://foo.com رابطًا حتى بدون <> s.
MKD_SAFELINK
فحص متشكك لبروتوكول الرابط.
MKD_NOHEADER
لا تعالج كتل الرأس.
MKD_TABSTOP
قم بتوسيع علامات الجدولة إلى 4 مسافات.
MKD_NODIVQUOTE
منع >%class% كتل.
MKD_NOALPHALIST
منع القوائم الأبجدية.
MKD_NODLIST
منع قوائم التعريف.
MKD_NODLDISCOUNT
تعطيل أسلوب بناء الجملة الخاص بقائمة تعريف الخصم.
MKD_DLEXTRA
تمكين أسلوب بناء الجملة الإضافي لقائمة التعريف.
MKD_EXTRA_FOOTNOTE
تمكين الحواشي السفلية بأسلوب Markdown الإضافي.
MKD_NOSTYLE
لا تستخرج (تتجاهل) كتل <style/> من المخرجات.
MKD_FENCEDCODE
السماح بكتل التعليمات البرمجية المحاطة بسياج.
MKD_IDANCHOR
استخدم علامات id= بدلاً من <a name=/> للروابط في جدول المحتويات.
MKD_GITHUBTAGS
السماح بالشرطة السفلية والشرطة في أسماء العناصر التي تم تمريرها.
MKD_URLENCODEDANCHOR
استخدم الترميز html5 للأحرف متعددة البايت وغير الأبجدية الرقمية بدلاً من التوسع السداسي في روابط جدول المحتويات.

قيم الإرجاع

markdown() تعيد 0 عند النجاح، 1 عند الفشل. تعيد الدوال mkd_in() و mkd_string() قيمة MMIOT* عند النجاح، null عند الفشل.

انظر أيضًا

markdown(1)، mkd-callbacks(3)، mkd-functions(3)، mkd-line(3)، markdown(7)، mkd-extensions(7)، mmap(2).

http://daringfireball.net/projects/markdown/syntax

الأخطاء

معالجة الأخطاء محدودة في أفضل الأحوال.

يتم حذف MMIOT الذي أنشأته mkd_string() بواسطة الدالة markdown.
