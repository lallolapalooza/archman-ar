Mail__Message__Construct__Build(3pm)

الحزمة: perl-mail-message

التراخيص: PerlArtistic, GPL

Mail::Message::Construct::Build(3) وثائق مقدمة من المستخدم Perl Mail::Message::Construct::Build(3)

الاسم

Mail::Message::Construct::Build - بناء رسالة بريد

الملخص

my $msg1 = Mail::Message->build(
  From => 'me',
  data => 'only two\nlines\n',
);
my $msg2 = Mail::Message->buildFromBody($body);
Mail::Message->build(
  From     => 'me@myhost.com',
  To       => 'you@yourhost.com',
  Subject  => 'Read our folder!',
  data     => \@lines,
  file     => 'folder.pdf',
)->send(via => 'postfix');

الوصف

يتم تنفيذ الوظائف المعقدة في كائنات Mail::Message في ملفات مختلفة يتم تحميلها تلقائيًا. يقوم هذا الملف بتنفيذ بناء الرسائل من مكونات أبسط.

الطرق

بناء رسالة

$class->build( [$message|$part|$body], @fields, %options )
منشئ كائن رسالة مبسط. في حالة تحديد $message أو $part، يتم إنشاء رسالة جديدة بنفس الجسم، ولكن برؤوس جديدة. يمكن أيضًا تحديد $body. ومع ذلك، هناك طرق أخرى لإضافة البيانات ببساطة.

يمكنك تمرير @fields ككائنات، حتى مختلطة مع أزواج خيارات. يتم إرسال الحقول بالترتيب الذي تم إنشاؤها به، لذلك قد يكون ذلك ضروريًا.

في قائمة %options، تستخدم الحقول التي تبدأ بحرف كبير كخطوط رأس. تستخدم الحقول ذات الأحرف الصغيرة لأغراض أخرى، كما هو مدرج أدناه. يمكن استخدام كل حقل أكثر من مرة. يتم تجاهل الأزواج التي تكون فيها القيمة undef.

إذا تم تحديد أكثر من $data، أو $file، أو $attach، يتم إنشاء رسالة متعددة الأجزاء. يتم التعامل مع بعض حقول من نوع "Content-*" بشكل منفصل: لفرض خطوط جسم الرسالة الناتجة، يجب تحديدها بعد إنشاء الجسم. على سبيل المثال، لتحديد صراحة أنك تريد $multipart/alternative بدلاً من الافتراضي $multipart/mixed. إذا كنت تريد تحديد النوع لكل جزء من البيانات، يجب عليك التعامل مع كائنات Mail::Message::Body بنفسك.

ستستخدم طريقة الإنشاء build() هذه buildFromBody() عند إنشاء كائن الجسم. معًا، ينتجون رسالتك.

-Option-Default Value
 attach  undef
 data    undef
 file    undef
 files   [ ]
 head    undef
attach => $body|$part|$message|\@attach
مرفق برسالة. يمكن أن يكون كل مرفق $message، أو $part، أو $body. يتم تغليف أي $message في جسم $message/rfc822. يمكنك تحديد العديد من العناصر (يمكن أن تكون من أنواع مختلفة) في نفس الوقت.
data => $text|\@lines
النص $text لجزء، محدد كسلسلة، أو مصفوفة @lines. يجب أن ينتهي كل سطر، بما في ذلك الأخير، بسطر جديد. يتم تمرير هذه الوسيطة إلى Mail::Message::Body::new(data) لإنشاء جسم.
file => $file|$fh|$io|\@files
ينشئ جسمًا حيث يتم قراءة البيانات من الملف المحدد بالاسم، أو مقبض الملف $fh، أو كائن IO::Handle $io. يستخدم هذا الجسم أيضًا لإنشاء Mail::Message::Body. [2.119] يمكنك حتى تمرير أكثر من ملف واحد في نفس الوقت: 'file' و 'files' متكافئان.
files => \@files
اسم بديل للوسيطة "file".
head => $head
ابدأ برأس معد مسبقًا، وإلا يتم إنشاء رأس.

» مثال:

my $msg = Mail::Message->build(
  From    => 'me@home.nl',
  To      => Mail::Address->new('your name', 'you@yourplace.aq'),
  Cc      => 'everyone@example.com',
  Subject => 'Let\'s talk',
  $other_message->get('Bcc'),
  data   => [ 'This is\n', 'the first part of\n', 'the message\n' ],
  file   => 'myself.gif',
  file   => 'you.jpg',
  attach => $signature,
);
my $msg = Mail::Message->build(
  To     => 'you',
  'Content-Type' => 'text/html',
  data   => '<html></html>',
);
$class->buildFromBody($body, [$head], $headers)
يشكل رسالة حول $body. تحتوي الأجسام على معلومات حول محتواها تستخدم لبناء رأس الرسالة. يمكنك تحديد كائن $head تم تهيئته مسبقًا، أو يتم إنشاء واحد لك (أيضًا عندما يكون $head هو undef). بالإضافة إلى ذلك، يمكن تحديد المزيد من $headers التي يتم تخزينها في هذا الرأس.

تتم إضافة حقول الرأس بالترتيب، وقبل سطور الرأس المحددة بواسطة الجسم. يمكن توفيرها كأزواج مفتاح-قيمة أو كائنات Mail::Message::Field. في حالة زوج مفتاح-قيمة، يستخدم اسم الحقل كمفتاح، والقيمة عبارة عن سلسلة، أو عنوان (كائن Mail::Address)، أو قائمة عناوين.

تتم إضافة حقول Date و Message-Id و MIME-Version ما لم يتم تحديدها.

» مثال:

my $type = Mail::Message::Field->new('Content-Type', 'text/html',
'charset="us-ascii"');
my @to   = (
  Mail::Address->new('Your name', 'you@example.com'),
  'world@example.info',
);
my $msg  = Mail::Message->buildFromBody($body,
From => 'me@example.nl',
To   => \@to,
$type,
);

التفاصيل

بناء رسالة

بناء سريع

الرسائل التي تحتاج إلى إنشائها بسيطة نسبيًا. لهذا السبب، توفر هذه الوحدة طريقة لإعداد رسالة بمكالمة طريقة واحدة فقط: build().

مقارنة بـMIME::Entity::build()

تم تصميم طريقة build() في MailBox على غرار طريقة build() في MIMETools، ولكن مع بعض التبسيطات:

عندما يبدأ مفتاح بحرف كبير، فإنه دائمًا حقل رأس
عندما يكون المفتاح بأحرف صغيرة، فهو دائمًا شيء آخر
أستخدم أسماء الحقول الفعلية، وليس الاختصارات
يتم قبول جميع أسماء الحقول
يمكنك تحديد كائنات الحقول بين أزواج مفتاح-قيمة
يتم اكتشاف العديد من العوامل تلقائيًا، مثل نوع المحتوى والترميز
يمكنك إنشاء رسالة متعددة الأجزاء في خطوة واحدة
