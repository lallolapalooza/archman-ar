الحزمة: mariadb

MARIADB-HOTCOPY(1) نظام قاعدة بيانات MariaDB MARIADB-HOTCOPY(1)

الاسم

mariadb-hotcopy - برنامج نسخ احتياطي لقاعدة البيانات (mariadb-hotcopy هو الآن رابط رمزي لـ mariadb-hotcopy)

الملخص

mariadb-hotcopy الوسائط

الوصف

mariadb-hotcopy هو سكربت Perl تم كتابته في الأصل وساهم به Tim Bunce. يستخدم FLUSH TABLES و LOCK TABLES و cp أو scp لعمل نسخة احتياطية من قاعدة البيانات. إنها طريقة سريعة لعمل نسخة احتياطية من قاعدة البيانات أو الجداول الفردية، ولكن لا يمكن تشغيلها إلا على نفس الجهاز الذي توجد فيه مجلدات قاعدة البيانات. يعمل mariadb-hotcopy فقط لعمل نسخ احتياطية للجداول من نوع MyISAM و ARCHIVE. يعمل على أنظمة Unix و NetWare.

لاستخدام mariadb-hotcopy، يجب أن يكون لديك حق القراءة لملفات الجداول التي تقوم بعمل نسخة احتياطية لها، وامتياز SELECT لهذه الجداول، وامتياز RELOAD (لتكون قادرًا على تنفيذ FLUSH TABLES)، وامتياز LOCK TABLES (لتكون قادرًا على قفل الجداول).

shell> mariadb-hotcopy اسم_قاعدة_البيانات [/مسار/إلى/المجلد_الجديد]
shell> mariadb-hotcopy اسم_قاعدة_البيانات_1 ... اسم_قاعدة_البيانات_n /مسار/إلى/المجلد_الجديد

عمل نسخة احتياطية للجداول في قاعدة البيانات المحددة التي تطابق تعبيرًا عاديًا:

shell> mariadb-hotcopy اسم_قاعدة_البيانات./التعبير_العادي/

يمكن عكس التعبير العادي لاسم الجدول عن طريق إضافة علامة ~ (مد) قبله:

shell> mariadb-hotcopy اسم_قاعدة_البيانات./~التعبير_العادي/

يدعم mariadb-hotcopy الخيارات التالية، والتي يمكن تحديدها في سطر الأوامر أو في مجموعات ملفات الخيارات [mariadb-hotcopy] و [client].

•--help, -?

عرض رسالة مساعدة والخروج.

•--addtodest

لا تقم بإعادة تسمية المجلد الهدف (إذا كان موجودًا)؛ فقط أضف الملفات إليه.

•--allowold

لا تتوقف إذا كان الهدف موجودًا؛ أعد تسميته بإضافة لاحقة _old.

•--checkpoint=اسم_قاعدة_البيانات.اسم_الجدول

إدراج إدخالات نقطة فحص في قاعدة البيانات المحددة اسم_قاعدة_البيانات والجدول اسم_الجدول.

•--chroot=مسار

مجلد الأساس لسجن chroot الذي يعمل فيه mariadbd. يجب أن تتطابق قيمة المسار مع قيمة خيار --chroot المقدم إلى mariadbd.

•--debug

تمكين إخراج التصحيح.

•--dryrun, -n

الإبلاغ عن الإجراءات دون تنفيذها.

•--flushlog

مسح السجلات بعد قفل جميع الجداول.

•--host=اسم_المضيف, -h اسم_المضيف

اسم مضيف المضيف المحلي للاستخدام لعمل اتصال TCP/IP بالخادم المحلي. افتراضيًا، يتم عمل الاتصال بـ localhost باستخدام ملف مقبس Unix.

•--keepold

لا تقم بحذف الهدف السابق (الذي تمت إعادة تسميته) عند الانتهاء.

•--method=الأمر

الطريقة لنسخ الملفات (cp أو scp). الافتراضي هو cp.

•--noindices

لا تقم بتضمين ملفات الفهرس الكاملة لجداول MyISAM في النسخة الاحتياطية. هذا يجعل النسخة الاحتياطية أصغر وأسرع. يمكن إعادة بناء فهارس الجداول التي تم إعادة تحميلها لاحقًا باستخدام myisamchk -rq.

•--old-server

الاتصال بـ MySQL-server قديم (قبل الإصدار 5.5) الذي لا يملك FLUSH TABLE WITH READ LOCK مطبقًا بالكامل.

•--password=كلمة_المرور, -pكلمة_المرور

كلمة المرور للاستخدام عند الاتصال بالخادم. قيمة كلمة المرور ليست اختيارية لهذا الخيار، على عكس برامج MariaDB الأخرى.

يجب اعتبار تحديد كلمة مرور في سطر الأوامر غير آمن. يمكنك استخدام ملف خيارات لتجنب إعطاء كلمة المرور في سطر الأوامر.

•--port=رقم_المنفذ, -P رقم_المنفذ

رقم منفذ TCP/IP للاستخدام عند الاتصال بالخادم المحلي.

•--quiet, -q

كن صامتًا باستثناء الأخطاء.

•--record_log_pos=اسم_قاعدة_البيانات.اسم_الجدول

تسجيل وضع الرئيسية والتابعة في قاعدة البيانات المحددة اسم_قاعدة_البيانات والجدول اسم_الجدول.

•--regexp=التعبير

نسخ جميع قواعد البيانات ذات الأسماء التي تطابق التعبير العادي المحدد.

•--resetmaster

إعادة تعيين سجل التغييرات الثنائية بعد قفل جميع الجداول.

•--resetslave

إعادة تعيين ملف master.info بعد قفل جميع الجداول.

•--socket=مسار, -S مسار

ملف مقبس Unix للاستخدام في الاتصالات بـ localhost.

•--suffix=سلسلة

اللاحقة للاستخدام لأسماء قواعد البيانات المنسوخة.

•--tmpdir=مسار

المجلد المؤقت. الافتراضي هو /tmp.

•--user=اسم_المستخدم, -u اسم_المستخدم

اسم مستخدم MariaDB للاستخدام عند الاتصال بالخادم.

استخدم perldoc للحصول على وثائق إضافية لـ mariadb-hotcopy، بما في ذلك معلومات حول بنية الجداول المطلوبة لخيارات --checkpoint و --record_log_pos:

shell> perldoc mariadb-hotcopy

mariadb-hotcopy

mariadb-hotcopy(1)
MariaDB-LTS

SYNOPSIS

mariadb-hotcopy [options] database_name [table1 [table2 ...]]

DESCRIPTION

mariadb-hotcopy is a script that uses LOCK TABLES to create a hot backup of a MariaDB database. It copies the database files to a specified directory.

The script uses mysqldump to get the table definitions, and then copies the actual data files. This ensures that the backup is consistent even if the database is being written to.

OPTIONS

The following options are supported:

  • --host=host_name: The host to connect to.
  • --password=password: The password to use when connecting to the server.
  • --port=port_number: The TCP/IP port number to use for the connection.
  • --user=user_name: The user name to use when connecting to the server.
  • --output-dir=directory: The directory where the backup will be stored.

EXAMPLE

To create a hot backup of the database named 'mydatabase' and store it in the directory '/backup/mydatabase', use the following command: 

                            mariadb-hotcopy --user=root --password=mypassword --host=localhost \
                            --output-dir=/backup/mydatabase mydatabase
