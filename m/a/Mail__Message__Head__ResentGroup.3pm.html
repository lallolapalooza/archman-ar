Mail__Message__Head__ResentGroup(3pm)

الحزمة: perl-mail-message

التراخيص: PerlArtistic, GPL

Mail::Message::Head::ResentGroup(3) وثائق Perl التي ساهم بها المستخدم Mail::Message::Head::ResentGroup(3)

الاسم

Mail::Message::Head::ResentGroup - حقول رأس تتبع تسليم الرسالة

الوراثة

Mail::Message::Head::ResentGroup
  هو Mail::Message::Head::FieldGroup
  هو Mail::Reporter

ملخص

use Mail::Message::Head::ResentGroup;
my $rg = Mail::Message::Head::ResentGroup->new(head => $head,
             From => 'me@home.nl', To => 'You@tux.aq');
$head->addResentGroup($rg);
my $rg = $head->addResentGroup(From => 'me');
my @from = $rg->From;
my @rgs = $head->resentGroups;
$rg[2]->delete if @rgs > 2;

الوصف

مجموعة إعادة الإرسال هي مجموعة من حقول الرأس التي تصف خطوة وسيطة واحدة في نقل الرسالة. مجموعات إعادة الإرسال **ليس لها علاقة** بنشاط المستخدم؛ لا يوجد أي علاقة بمعنى "المستخدم" لإنشاء رد، إعادة توجيه، أو رسائل ارتداد على الإطلاق!

يمتد "الوصف" في Mail::Message::Head::FieldGroup.

مع أي وسائط، يتم إرجاع قائمة بـ "Mail::Message::Head::ResentGroup" الكائنات، مأخوذة من $message أو $head الرسالة المحدد. تحسينات أساسية، انظر "المنشئات" في Mail::Message::Head::FieldGroup

سيتم استخدام جميع %options التي تبدأ بحروف كبيرة لإنشاء حقول إضافية. تتم إضافة البادئة "Resent-*" إلى أسماء الخيارات هذه، مع الحفاظ على الأحرف الكبيرة لما هو محدد. تحسينات أساسية، انظر "المنشئات" في Mail::Message::Head::FieldGroup

عندما يتم إرسال مجموعة إعادة الإرسال هذه بواسطة مرسل الرسالة. مثل حقل "Date"، ليس هذا هو التاريخ والوقت الذي تم فيه نقل الرسالة فعليًا.
Delivered-To => $text|$field
From => $text|$field|\@fields
Message-ID => $text|$field
"Resent-Message-ID" الذي يحدد مجموعة إعادة الإرسال هذه. يجب أن يحتوي الحقل على معرف رسالة.
Received => $text
"Received" هو السطر الأول لمجموعة إعادة إرسال أسطر الرأس. إذا لم يتم تعريفه، يتم إنشاء واحد باستخدام createReceived().
Return-Path => $text|$field
Sender => $text|$field
مسموح به فقط عندما يتم تحديد أكثر من عنوان مرسل واحد. في هذه الحالة، يختار أحد هذه العناوين كمرسل رئيسي للرسالة.
To => $text|$field|\@fields
head => $head
الكائن $head الذي يتم تخزين البيانات فيه. افتراضيًا، يتم إنشاء Mail::Message::Head::Partial لك.
log => LEVEL
message_head => $head
الرأس الحقيقي $head للرسالة التي تنتمي إليها مجموعة إعادة الإرسال هذه. "head" المستخدم في هذه الفئة هو مجرد حاوية لمجموعة فرعية من الحقول.
software => STRING
trace => LEVEL
type => STRING
version => STRING
