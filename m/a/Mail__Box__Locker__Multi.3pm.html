Mail::Box::Locker::Multi - قفل مجلد بكل الطرق الممكنة

  هو Mail::Box::Locker

الملخص

انظر Mail::Box::Locker

الوصف

القفل "::Multi" يقفل مجلدًا بكل طريقة يمكنه بها. بهذه الطريقة، تكون فرصة أن تتجنب البرامج الأخرى المجلد أثناء وصولنا إليه هي الأعلى.

يتم تجربة NFS-lock و Flock. قد تتم إضافة المزيد عندما يتم توسيع طرق القفل. يتداخل DotLock مع NFS-lock، لكن NFS-lock أكثر أمانًا، لذا يُفضل هذا الإصدار.

يمتد "الوصف" في Mail::Box::Locker.

المنشئات

يمتد "المنشئات" في Mail::Box::Locker.

$class->new(%options)
يمكنك أيضًا تمرير جميع %options التي تفهمها الأقفال المبادر بها والتي يستخدمها القفل المتعدد. يحسن الأساس، انظر "الأساليب" في Mail::Box::Locker 
-Option --Defined in       --Default
 expires  Mail::Box::Locker  1 hour
 file     Mail::Box::Locker  undef
 folder   Mail::Box::Locker  <C<undef>>
 log      Mail::Reporter     'WARNINGS'
 method   Mail::Box::Locker  'MULTI'
 timeout  Mail::Box::Locker  10
 trace    Mail::Reporter     'WARNINGS'
 use                         <all possible>
expires => $seconds
file => $file
folder => $folder
log => LEVEL
method => $name|CLASS|\@names
timeout => $seconds|'NOTIMEOUT'
trace => LEVEL
use => ARRAY-of-(NAMES|LOCKER)
مصفوفة من أسماء أنواع الأقفال أو كائنات الأقفال لاستخدامها لقفل مجلد واحد. يتم تحويل أسماء الأنواع إلى كائنات. عند إنشاء كائنات القفل الخاصة بك، تأكد من ضبط المهلة قصيرة جدًا (يفضل أن تكون 1).

بعض أنواع الأقفال غير متاحة على بعض الأنظمة، لذلك لن يتم استبعادها من القائمة الافتراضية (NFS POSIX Flock).

» مثال: استخدام مجموعة فرعية من الأقفال المتعددة

my $locker = Mail::Box::Locker::Multi->new(use => ['DOTLOCK','FLOCK']);

التشخيص

خطأ: الحزمة $package لا تطبق $method.
خطأ فادح: الحزمة المحددة (أو إحدى فئاتها العليا) لا تطبق هذا الأسلوب حيث ينبغي. هذه الرسالة تعني أن بعض الفئات الأخرى ذات الصلة تطبق هذا الأسلوب بينما الفئة المعنية لا تفعل ذلك. ربما يجب عليك التحقيق في هذا وربما إبلاغ مؤلف الحزمة. تم رميه بواسطة notImplemented()
