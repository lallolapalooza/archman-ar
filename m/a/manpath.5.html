NAME

manpath.conf – manual path configuration file

DESCRIPTION

The file manpath.conf is used to configure the search path for manual pages. The directory specified in the environment variable MANPATH(5) takes precedence over the settings in this file, followed by the default path, which is defined by the mandb command.

The configuration file consists of lines, which are either comments, empty, or contain directives.

#
Lines beginning with a hash (#) character are comments and are ignored.
Empty lines are also ignored.
MANDATORY_SECTION_IDENTIFIERS
If this directive is present, the manual page system requires that all manual pages be tagged with a section identifier.
SECTION
The SECTION directive allows you to specify a list of manual page sections. The list is comma-separated, and the sections are ordered according to precedence. This ordering is used by the man(1) command when searching for manual pages. For example, a SECTION directive might look like this:
SECTION=1,2,3,4,5,6,7,8,9,0,n,l,p
MANPATH
The MANPATH directive specifies directories to be searched for manual pages. These directories are searched in the order they appear in the directive. The search path may be absolute or relative. Relative paths are interpreted with respect to the root of the manual page hierarchy, which is typically configured during the build process of the man-db package. For example, a MANPATH directive might look like this:
MANPATH=/usr/share/man
MANPATH=/usr/local/share/man
MANPATH=/opt/my_app/share/man

Multiple MANPATH directives are concatenated in the order they appear in the file.

ALLMAN ，ALLMANPATH
These directives are used to specify paths to man pages that are not part of the standard distribution but were installed by package managers. ALLMAN should be used to specify the directory containing the man pages, and ALLMANPATH should specify the directory containing the package information. mandb(8) uses this information to create the cat pages automatically. For example:
ALLMAN=/usr/local/share/man
ALLMANPATH=/usr/local/share/man/local

SEARCH PATH

When the man(1) command is invoked, it constructs a search path for manual pages based on the following criteria, in order of precedence:

  1. The MANPATH environment variable, if set.
  2. The paths specified by MANPATH directives in manpath.conf.
  3. The paths specified by ALLMANPATH directives in manpath.conf.
  4. The default search path, which is determined by the mandb command during its execution.

FORMAT

The manpath.conf file is parsed line by line. Each line is processed as follows:

#
Lines starting with '#' are comments and are ignored.
Empty lines are ignored.
MANDATORY_SECTION_IDENTIFIERS
Enables mandatory section identifiers for manual pages.
SECTION=section_list
Sets the order of manual page sections. section_list is a comma-separated list of section names.
MANPATH=directory
Adds directory to the manual page search path.
ALLMAN=directory
Specifies a directory containing man pages installed by package managers.
ALLMANPATH=directory
Specifies a directory containing package information for mandb(8) to use when creating cat pages.

If a line does not match any of the above formats, it is ignored. Whitespace at the beginning and end of lines is ignored.

Note that the man(1) command itself does not create cat pages. That task is performed by the mandb(8) command, which uses the information in manpath.conf (specifically the ALLMAN and ALLMANPATH directives) to prevent mandb(8) from creating cat pages automatically.

BUGS

Unless the rules above are followed and observed precisely, the manual pager utilities will not function as desired. The rules are overly complicated.

الاسم

manpath.conf – ملف إعداد مسار الدليل

الوصف

يُستخدم الملف manpath.conf لإعداد مسار البحث لصفحات الدليل. يأخذ الدليل المحدد في متغير البيئة MANPATH(5) الأسبقية على الإعدادات في هذا الملف، يليه المسار الافتراضي، والذي يتم تعريفه بواسطة الأمر mandb.

يتكون ملف الإعداد من أسطر، وهي إما تعليقات، أو فارغة، أو تحتوي على توجيهات.

#
الأسطر التي تبدأ بحرف هاش (#) هي تعليقات ويتم تجاهلها.
الأسطر الفارغة يتم تجاهلها أيضًا.
MANDATORY_SECTION_IDENTIFIERS
إذا كان هذا التوجيه موجودًا، فإن نظام صفحات الدليل يتطلب أن يتم وضع علامة على جميع صفحات الدليل بمعرف قسم.
SECTION
يسمح لك التوجيه SECTION بتحديد قائمة بأقسام صفحات الدليل. القائمة مفصولة بفواصل، والأقسام مرتبة وفقًا للأسبقية. يتم استخدام هذا الترتيب بواسطة الأمر man(1) عند البحث عن صفحات الدليل. على سبيل المثال، قد يبدو توجيه SECTION كالتالي:
SECTION=1,2,3,4,5,6,7,8,9,0,n,l,p
MANPATH
يحدد التوجيه MANPATH الدلائل التي سيتم البحث فيها عن صفحات الدليل. يتم البحث في هذه الدلائل بالترتيب الذي تظهر به في التوجيه. قد يكون مسار البحث مطلقًا أو نسبيًا. يتم تفسير المسارات النسبية بالنسبة إلى جذر هرمية صفحات الدليل، والذي يتم تهيئته عادةً أثناء عملية بناء حزمة man-db. على سبيل المثال، قد يبدو توجيه MANPATH كالتالي:
MANPATH=/usr/share/man
MANPATH=/usr/local/share/man
MANPATH=/opt/my_app/share/man

يتم تجميع توجيهات MANPATH المتعددة بالترتيب الذي تظهر به في الملف.

ALLMAN ،ALLMANPATH
تُستخدم هذه التوجيهات لتحديد المسارات إلى صفحات الدليل التي ليست جزءًا من التوزيع القياسي ولكن تم تثبيتها بواسطة مديري الحزم. يجب استخدام ALLMAN لتحديد الدليل الذي يحتوي على صفحات الدليل، ويجب استخدام ALLMANPATH لتحديد الدليل الذي يحتوي على معلومات الحزمة. يستخدم mandb(8) هذه المعلومات لإنشاء الصفحات المختصرة تلقائيًا. على سبيل المثال:
ALLMAN=/usr/local/share/man
ALLMANPATH=/usr/local/share/man/local

مسار البحث

عند استدعاء الأمر man(1)، يقوم ببناء مسار بحث لصفحات الدليل بناءً على المعايير التالية، بالترتيب حسب الأسبقية:

  1. متغير البيئة MANPATH، إذا تم تعيينه.
  2. المسارات المحددة بواسطة توجيهات MANPATH في manpath.conf.
  3. المسارات المحددة بواسطة توجيهات ALLMANPATH في manpath.conf.
  4. المسار الافتراضي، والذي يتم تحديده بواسطة الأمر mandb أثناء تنفيذه.

التنسيق

يتم تحليل الملف manpath.conf سطرًا بسطر. يتم معالجة كل سطر كالتالي:

#
الأسطر التي تبدأ بـ '#' هي تعليقات ويتم تجاهلها.
الأسطر الفارغة يتم تجاهلها.
MANDATORY_SECTION_IDENTIFIERS
يُمكّن معرفات الأقسام الإلزامية لصفحات الدليل.
SECTION=قائمة_الأقسام
يحدد ترتيب أقسام صفحات الدليل. قائمة_الأقسام هي قائمة مفصولة بفواصل بأسماء الأقسام.
MANPATH=الدليل
يضيف الدليل إلى مسار البحث لصفحات الدليل.
ALLMAN=الدليل
يحدد دليلًا يحتوي على صفحات دليل مثبتة بواسطة مديري الحزم.
ALLMANPATH=الدليل
يحدد دليلًا يحتوي على معلومات الحزمة ليستخدمها mandb(8) عند إنشاء الصفحات المختصرة.

إذا لم يتطابق سطر ما مع أي من التنسيقات المذكورة أعلاه، فسيتم تجاهله. يتم تجاهل المسافات البيضاء في بداية ونهاية الأسطر.

لاحظ أن الأمر man(1) نفسه لا يقوم بإنشاء الصفحات المختصرة. يتم تنفيذ هذه المهمة بواسطة الأمر mandb(8)، الذي يستخدم المعلومات الموجودة في manpath.conf (خاصة توجيهات ALLMAN و ALLMANPATH) لمنع mandb(8) من إنشاء الصفحات المختصرة تلقائيًا.

أخطاء

ما لم يتم اتباع القواعد المذكورة أعلاه وملاحظتها بدقة، فلن تعمل أدوات تصفح الدليل كما هو مرغوب. القواعد معقدة للغاية.
