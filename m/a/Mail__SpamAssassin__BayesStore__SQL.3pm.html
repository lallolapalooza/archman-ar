Mail__SpamAssassin__BayesStore__SQL(3pm)

Mail::SpamAssassin::BayesStore::SQL(3) وثائق Perl المساهمة من المستخدم Mail::SpamAssassin::BayesStore::SQL(3)

الاسم

Mail::SpamAssassin::BayesStore::SQL - تطبيق وحدة تخزين بايز SQL

الوصف

تنفذ هذه الوحدة وحدة تخزين بايز قائمة على SQL. إنها متوافقة مع SQLite وربما خوادم SQL قياسية أخرى.

لا تستخدم هذا لـ MySQL/MariaDB أو PgSQL، لديهم وحداتهم الخاصة.

الأساليب

جديد

public class (Mail::SpamAssassin::BayesStore::SQL) new (Mail::Spamassassin::Plugin::Bayes $bayes)

الوصف: تنشئ هذه الطريقة مثيلًا جديدًا لكائن Mail::SpamAssassin::BayesStore::SQL. تتوقع أن يتم تمرير مثيل لكائن Mail::SpamAssassin::Bayes الذي يتم تمريره إلى الكائن الأم Mail::SpamAssassin::BayesStore.

تقوم هذه الطريقة بإعداد اتصال قاعدة البيانات وتحديد اسم المستخدم لاستخدامه في الاستعلامات.

get_storage_variables

public instance (@) get_storage_variables ()

الوصف: تسترجع هذه الطريقة متغيرات الإدارة المختلفة التي يستخدمها عملية وقاعدة بيانات Bayes.

القيم المعادة في المصفوفة تكون بالترتيب التالي:

0: عدد عمليات المسح الأساسي

1: عدد رسائل البريد العشوائي

2: عدد رسائل البريد غير العشوائي

3: عدد الرموز في قاعدة البيانات

4: آخر وقت انتهاء صلاحية

5: أقدم وقت وصول للرمز في قاعدة البيانات

6: قيمة إصدار قاعدة البيانات

7: آخر مزامنة للسجل

8: آخر دلتا لوقت الوصول

9: عدد تقليل انتهاء الصلاحية الأخير

10: أحدث وقت وصول للرمز في قاعدة البيانات
