Markdown.pl(1p)

الحزمة: perl-text-markdown

التراخيص: GPL, PerlArtistic

MARKDOWN(1p) توثيق Perl مساهمة المستخدم MARKDOWN(1p)

الاسم

Markdown.pl - تحويل صيغة Markdown إلى (X)HTML

الوصف

يتم توزيع هذا البرنامج كجزء من وحدة Text::Markdown الخاصة بـ Perl، لتوضيح الاستخدام النموذجي.

يمكن استدعاء Markdown على أي ملف يحتوي على صيغة Markdown، وسينتج (X)HTML المقابل على STDOUT:

$ cat file.txt
This is a *test*.
Absolutely _nothing_ to see here. _Just a **test**_!
* test
* Yup, test.
$ Markdown.pl file.txt
<p>This is a <em>test</em>.</p>
<p>Absolutely <em>nothing</em> to see here. <em>Just a <strong>test</strong></em>!</p>
<ul>
<li>test</li>
<li>Yup, test.</li>
</ul>

إذا لم يتم تحديد ملف، فسيتم توقع الإدخال من STDIN:

$ echo "A **simple** test" | markdown
<p>A <strong>simple</strong> test</p>

خيارات

version
يعرض المعلومات الكاملة لهذا الإصدار
shortversion
يعرض رقم الإصدار فقط
html4tags
ينتج علامات نمط HTML 4 بدلاً من XHTML - تتطلب XHTML العناصر التي لا تغلف كتلة (مثل علامة "hr") أن تشير إلى أنها لن تُغلق، عن طريق الإغلاق بـ "/>". سيعرض نمط HTML 4 العلامة كما هي: 
$ echo '---' | markdown
<hr />
$ echo '---' | markdown --html4tags
<hr>
help
يعرض هذا التوثيق
