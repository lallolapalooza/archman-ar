Mail__SpamAssassin__Plugin__HashBL(3pm)

الحزمة: spamassassin

التراخيص: APACHE

Mail::SpamAssassin::Plugin::HashBL(3) توثيق مقدم من Perl Mail::SpamAssassin::Plugin::HashBL(3)

الاسم

HashBL - استعلامات قوائم الحظر المستندة إلى التجزئة (وغير التجزئة) عبر DNS

الملخص

loadplugin Mail::SpamAssassin::Plugin::HashBL
# أمثلة استخدام غير وظيفية (استبدل xxx.example.invalid بقائمة حقيقية)
# استعلامات موثقة في القسم التالي
header   HASHBL_EMAIL eval:check_hashbl_emails('ebl.example.invalid')
describe HASHBL_EMAIL Message contains email address found in EBL
tflags   HASHBL_EMAIL net
# تغيير googlemail.com إلى gmail.com، يتم تطبيقه قبل acl/welcomelist
hashbl_email_domain_alias gmail.com googlemail.com
# استعلام gmail.com فقط
hashbl_acl_freemail gmail.com
header   HASHBL_OSENDR eval:check_hashbl_emails('rbl.example.invalid/A', 'md5/max=10/shuffle', 'X-Original-Sender', '^127\.', 'freemail')
describe HASHBL_OSENDR Message contains email address found in HASHBL
tflags   HASHBL_OSENDR net
body     HASHBL_BTC eval:check_hashbl_bodyre('btcbl.example.invalid', 'sha1/max=10/shuffle', '\b([13][a-km-zA-HJ-NP-Z1-9]{25,34})\b')
describe HASHBL_BTC Message contains Bitcoin address found in BTCBL
tflags   HASHBL_BTC net
header   HASHBL_URI eval:check_hashbl_uris('rbl.example.invalid', 'sha1', '^127\.', 'X-Some-ID')
describe HASHBL_URI Message contains URI found in rbl
tflags   HASHBL_URI net
body     HASHBL_ATTACHMENT eval:check_hashbl_attachments('attbl.example.invalid', 'sha256')
describe HASHBL_ATTACHMENT Message contains attachment found in attbl
tflags   HASHBL_ATTACHMENT net
# التقاط علامة باستخدام وظيفة التقاط التعبير النمطي لـ SA 4.0
header   __X_SOME_ID X-Some-ID =~ /^(?<XSOMEID>\d{10,20})$/
# استعلام قيمة العلامة كما هي، من DNSBL
header   HASHBL_TAG eval:check_hashbl_tag('idbl.example.invalid/A', 'raw', 'XSOMEID', '^127\.')

الوصف

يدعم هذا المكون الإضافي أنواعًا مختلفة من استعلامات قوائم الحظر المستندة إلى DNS (المجزأة أو غير المجزأة).

خيارات شائعة تنطبق على جميع الوظائف:
raw      بدون تجزئة، استعلام كما هو (قد يتعطل إذا لم يكن القيمة اسم نطاق صالح)
md5      تجزئة بـ MD5
sha1     تجزئة بـ SHA1
sha256   تجزئة بـ SHA256 مشفرة بـ Base32
case     احتفظ بحالة الأحرف قبل التجزئة، الافتراضي هو الأحرف الكبيرة
max=x    الحد الأقصى لعدد الاستعلامات (الافتراضي هو 10 إذا لم يتم تحديده)
shuffle  إذا تم تجاوز الحد الأقصى، قم بخلط الاستعلامات قبل الاقتصاص إلى الحد

يمكن فصل خيارات متعددة بشرطة مائلة.

إذا كانت الخيارات فارغة أو لم يتم تحديدها، يتم استخدام القيمة الافتراضية، كما هو موثق لكل نوع استعلام. إذا تم تحديد خيارات، يجب تحديد جميع المتطلبات بشكل صريح.

قاعدة رأس check_hashbl_emails('bl.example.invalid/A', 'OPTS', 'HEADERS', '^127\.')
التحقق من عناوين البريد الإلكتروني لقوائم الحظر المستندة إلى DNS. ملاحظة: يمكن تحديد الجسم مع رؤوس البحث عن عناوين البريد الإلكتروني في جسم الرسالة. يجب أن يكون نوع القاعدة "header".

يمكن إضافة نوع استعلام DNS إلى القائمة باستخدام /A (افتراضي) أو /TXT.

القيمة الافتراضية للخيارات هي sha1/notag/noquote/max=10/shuffle.

خيارات أخرى مدعومة:

nodot    إزالة النقاط من جزء اسم المستخدم لعنوان البريد الإلكتروني
notag    إزالة العلامات من جزء اسم المستخدم لعنوان البريد الإلكتروني
nouri    تجاهل عناوين البريد الإلكتروني داخل عناوين URI
noquote  تجاهل عناوين البريد الإلكتروني داخل < > أو الاقتباسات المحتملة
user     استعلام جزء المستخدم فقط من عنوان البريد الإلكتروني
host     استعلام جزء المضيف فقط من عنوان البريد الإلكتروني
domain   استعلام جزء النطاق فقط من عنوان البريد الإلكتروني (جزء المضيف + إزالة النطاق)

الرؤوس الافتراضية هي ALLFROM/Reply-To/body.

يشير HEADERS إلى قائمة مفصولة بشرطة من الرؤوس التي يجب معالجتها:

ALL           جميع الرؤوس
ALLFROM       جميع رؤوس From كما تم إرجاعها بواسطة $pms->all_from_addrs()
EnvelopeFrom  رأس الإرسال (Return-Path إلخ)
<HeaderName>  أي رأس كما هو مستخدم مع قواعد الرأس أو $pms->get()
body          جميع عناوين البريد الإلكتروني التي تم العثور عليها في جسم الرسالة

إذا كانت الرؤوس فارغة ('') أو لم يتم تحديدها، يتم استخدام القيمة الافتراضية.

اختياري تعبير نمطي فرعي لمطابقة استجابة DNS (افتراضي: '^127\.').

لحظر البريد العام، راجع: http://msbl.org/ebl.html

# مثال للاستخدام، راجع https://msbl.org/ebl.html قبل استخدامه
header   HASHBL_EMAIL eval:check_hashbl_emails('ebl.msbl.org')
describe HASHBL_EMAIL Message contains email address found in EBL
tflags   HASHBL_EMAIL net

يمكن تجاوز التعبير النمطي الافتراضي لمطابقة والتقاط رسائل البريد الإلكتروني باستخدام "hashbl_email_regex". بالإضافة إلى ذلك، يمكن تغيير قائمة الترحيب الافتراضية باستخدام "hashbl_email_welcomelist". لا تقم بالتغيير إلا إذا كنت تعرف ما تفعله، راجع الكود المصدري للمكون الإضافي للقيم الافتراضية. مثال: hashbl_email_regex \S+@\S+.com

قاعدة رأس check_hashbl_uris('bl.example.invalid/A', 'OPTS', '^127\.')
التحقق من جميع عناوين URI التي تم تحليلها من الرسالة لقوائم الحظر المستندة إلى DNS.

يمكن إضافة نوع استعلام DNS إلى القائمة باستخدام /A (افتراضي) أو /TXT.

القيمة الافتراضية للخيارات هي sha1/max=10/shuffle.

اختياري تعبير نمطي فرعي لمطابقة استجابة DNS (افتراضي: '^127\.').

[raw]body RULE check_hashbl_bodyre('bl.example.invalid/A', 'OPTS', '\b(match)\b', '^127\.')
البحث في جسم الرسالة عن تطابق تعبير نمطي والاستعلام عن النص الملتقط. يجب أن يحتوي التعبير النمطي على مستوعب واحد ( ) للنص ($1). يجب أن يكون نوع القاعدة "body" أو "rawbody".

يمكن إضافة نوع استعلام DNS إلى القائمة باستخدام /A (افتراضي) أو /TXT.

القيمة الافتراضية للخيارات هي sha1/max=10/shuffle.

خيارات أخرى مدعومة:

num      إزالة الأحرف غير الرقمية

اختياري تعبير نمطي فرعي لمطابقة استجابة DNS (افتراضي: '^127\.').

قاعدة رأس check_hashbl_tag('bl.example.invalid/A', 'OPTS', 'TAGNAME', '^127\.')
استعلام قيمة علامة SpamAssassin _TAGNAME_ من قائمة الحظر المستندة إلى DNS.

يمكن إضافة نوع استعلام DNS إلى القائمة باستخدام /A (افتراضي) أو /TXT.

القيمة الافتراضية للخيارات هي sha1/max=10/shuffle.

خيارات أخرى مدعومة:

ip        استعلام فقط إذا كانت القيمة عنوان IPv4/IPv6 صالح
ipv4      استعلام فقط إذا كانت القيمة عنوان IPv4 صالح
ipv6      استعلام فقط إذا كانت القيمة عنوان IPv6 صالح
revip     عكس عنوان IP قبل الاستعلام
fqdn      استعلام فقط إذا كانت القيمة عنوان FQDN صالح (es_fqdn_valid)
tld       استعلام فقط إذا كانت القيمة تحتوي على TLD صالح (es_domain_valid)
trim      إزالة اسم المضيف حتى النطاق (trim_domain)
إذا تم تنشيط كل من ip/ipv4/ipv6 و fqdn/tld، يلزم أحدهما فقط للمطابقة. مطلوب كل من fqdn و tld للتحقق الكامل من FQDN+TLD.

اختياري تعبير نمطي فرعي لمطابقة استجابة DNS (افتراضي: '^127\.').

قاعدة رأس check_hashbl_attachments('bl.example.invalid/A', 'OPTS', '^127\.')
التحقق من جميع المرفقات (أجزاء MIME) للرسالة لقوائم الحظر المستندة إلى DNS.

يمكن إضافة نوع استعلام DNS إلى القائمة باستخدام /A (افتراضي) أو /TXT.

القيمة الافتراضية للخيارات هي sha1/max=10/shuffle.

خيارات أخرى مدعومة:

minsize=x  تجاوز أي جزء أقل من x بايت
maxsize=x  تجاوز أي جزء أكبر من x بايت

اختياري تعبير نمطي فرعي لمطابقة استجابة DNS (افتراضي: '^127\.').

يمكن تجاوز أسماء الملفات المحددة للمرفقات باستخدام "hashbl_ignore". مثال: hashbl_ignore safe.pdf

يمكن تجاوز أنواع MIME المحددة للمرفقات باستخدام "hashbl_ignore". مثال: hashbl_ignore text/plain

قيمة hashbl_ignore [value...]
تجاوز أي استعلام إذا تطابقت قيمة التجزئة أو القيمة الأصلية (على سبيل المثال، البريد الإلكتروني). يمكن تحديد قيم متعددة مفصولة بمسافات. المطابقة غير حساسة لحالة الأحرف.

سيتم أيضًا تجاوز أي مضيف أو جزء نطاقه يتطابق مع uridnsbl_skip_domains بشكل افتراضي.
