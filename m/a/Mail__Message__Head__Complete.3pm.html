الوصول إلى الرأس

يمتد "الوصول إلى الرأس" في Mail::Message::Head.

$obj->add( $field | $line | <$name, $body, [$attrs]> )
إضافة حقل إلى الرأس. إذا تم إضافة حقل أكثر من مرة، يتم تخزين جميع القيم في الرأس، بالترتيب الذي تمت إضافتها به.

عند تحديد كائن $field (مثيل Mail::Message::Field ما)، سيتم إضافته. احتمال آخر هو تحديد سطر رأس خام $line، أو سطر رأس مقسم بشكل جيد إلى $name و $body، وفي هذه الحالة يتم استدعاء منشئ الحقل لك.

تعتبر المواصفات $line أو $body التي تنتهي بسطر جديد مطوية بشكل صحيح. سيتم طي الأسطر التي لا تنتهي بسطر جديد عند الحاجة: سيتم إضافة أسطر جديدة حيثما لزم الأمر. ينصح بشدة بالسماح لـ MailBox بالقيام بالطي نيابة عنك.

قيمة الإرجاع لهذه الطريقة هي كائن Mail::Message::Field الذي تم إنشاؤه (أو تم تحديده).

» مثال:

my $head  = Mail::Message::Head->new;
$head->add('Subject: hi!');
$head->add(From => 'me@home');
my $field = Mail::Message::Field->new('To: you@there');
$head->add($field);
my Mail::Message::Field $s = $head->add(Sender => 'I');
$obj->addListGroup($object)

» مثال: لإضافة مجموعة قائمة إلى رأس

NAME

Mail::Message::Head - encapsulate the header of a mail message

SYNOPSIS

  use Mail::Message::Head;

  my $head = Mail::Message::Head->new;
  $head->parse($fh);

  my $obj  = Mail::Message->new;
  $obj->head($head);

  # Access
  my $subject = $obj->subject;
  my $date    = $obj->date;

  # Modify
  $obj->subject('new subject');
  $obj->add('X-MyHeader', 'value');

  # Output
  print $head->as_string;

DESCRIPTION

This class represents the header of an electronic mail message. The header contains the meta-information about the message, like the sender, recipient, subject, date, etc. The body of the message is handled by Mail::Message::Body.

This class is an extension of Mail::Message::Head. The methods defined here are additions or overloads.

Access to the header

Extends "Access to the header" in Mail::Message::Head.

$obj->ALL()
Returns all header lines that were explicitly parsed. This includes comments and folded lines. When the header was constructed manually, then only the lines added explicitly are returned.
$obj->date()
Returns the value of the "Date" header field. Returns "undef" when the field is not found.
$obj->field( $name )
Returns the value of the header field named $name. Case-insensitive. Returns "undef" if the field is not found. If there are multiple fields with the same name, only the first one is returned.
$obj->fields( $name )
Returns all values of the header field named $name. Case-insensitive. Returns an empty list when the field is not found. If there is only one field, it is returned in a list.
$obj->find( $name )
Returns the first header field object with the given name. Returns "undef" if not found.
$obj->findAll( $name )
Returns a list of all header field objects with the given name.
$obj->get( $name, [$index] )
Returns the value of the header field named $name. If $index is specified, it returns the $index-th value of that field. Case-insensitive. Returns "undef" if the field or index is not found.
$obj->messageId()
Returns the value of the "Message-ID" header field. Returns "undef" when the field is not found.
$obj->parse( $fh )
Read the header from the given filehandle $fh. The parsing stops when an empty line is encountered, or when the end of the file is reached. Existing header information is preserved.
$obj->parseString( $string )
Parse the header from the given string. Existing header information is preserved.
$obj->remove( $name )
Removes all header fields with the given name. Case-insensitive.
$obj->removeField( $field_object )
Removes the specified header field object from the header.
$obj->set( $name, $value )
Sets the value of the header field named $name to $value. If the field already exists, it is overwritten. If the field does not exist, it is added.
$obj->study( $name, [$index] )
Inherited, see "Access to the header" in Mail::Message::Head

$obj->guessTimeStamp()
Make a guess about when the message was origanally posted, based on the information found in the header's "Date" field.

For some kinds of folders, Mail::Message::guessTimestamp() may produce a better result, for instance by looking at the modification time of the file in which the message is stored. Also some protocols, like POP can supply that information.

$obj->isMultipart()
Inherited, see "About the body" in Mail::Message::Head
$obj->recvstamp()
Returns an indication about when the message was sent, but only using the "Date" field in the header as last resort: we do not trust the sender of the message to specify the correct date. See timestamp() when you do trust the sender.

Many spam producers fake a date, which mess up the order of receiving things. The timestamp which is produced is derived from the Received headers, if they are present, and "undef" otherwise.

The timestamp is encoded as "time" is on your system (see perldoc -f time), and as such usable for the "gmtime" and "localtime" methods.

» example: of time-sorting folders with received messages

my $folder = $mgr->open('InBox');
my @messages = sort {$a->recvstamp <=> $b->recvstamp}
                  $folder->messages;

» example: of time-sorting messages of mixed origin

my $folder = $mgr->open('MyFolder');
# Pre-calculate timestamps to be sorted (for speed)
my @stamps = map +[ ($_->timestamp || 0), $_ ],
  $folder->messages;
my @sorted =
  map { $_->[1] }      # get the message for the stamp
    sort {$a->[0] <=> $b->[0]}   # stamps are numerics
       @stamps;
$obj->timestamp()
Returns an indication about when the message was sent, with as little guessing as possible. In this case, the date as specified by the sender is trusted. See recvstamp() when you do not want to trust the sender.

The timestamp is encoded as "time" is on your system (see perldoc -f time), and as such usable for the "gmtime" and "localtime" methods.

$any->messageIdPrefix( [$prefix, [$hostname]|CODE] )
When options are provided, it sets a new way to create message-ids, as used by createMessageId(). You have two choices: either by providing a $prefix and optionally a $hostname, or a "CODE" reference.

The "CODE" reference will be called with the header as first argument. You must ensure yourself that the returned value is RFC compliant.

The $prefix defaults to "mailbox-$$", the $hostname defaults to the return of Net::Domains's function hostfqdn(), or when not installed, the Sys::Hostname's function hostname(). Inbetween the two, a nano-second time provided by Time::HiRes is used. If that module is not available, "time" is called at the start of the program, and incremented for each newly created id.

In any case, a subroutine will be created to be used. A reference to that will be returned. When the method is called without arguments, but no subroutine is defined yet, one will be created.

DIAGNOSTICS

Warning: Cannot remove field $name from header: not found.
You ask to remove a field which is not known in the header. Using delete(), reset(), or set() to do the job will not result in warnings: those methods check the existence of the field first. Cast by removeField()
Warning: Field objects have an implied name ($name)
Cast by build()
Error: Package $package does not implement $method.
Fatal error: the specific package (or one of its superclasses) does not implement this method where it should. This message means that some other related classes do implement this method however the class at hand does not. Probably you should investigate this and probably inform the author of the package. Cast by notImplemented()
