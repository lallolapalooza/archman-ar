NAME

Mail::Message::Body::Delayed - Delayed loading of a mail message body

SYNOPSIS

use Mail::Message::Body::Delayed;

# Create a delayed body object
my $delayed = Mail::Message::Body::Delayed->new(
    'file.eml',
    'utf8',
    'quoted-printable',
);

# Get the actual body object when needed
my $body = $delayed->get();

# Access body methods
my $content = $body->content();
my $headers = $body->headers();

DESCRIPTION

This class represents a mail message body that is loaded on demand. It is useful for reducing memory usage when dealing with large mail messages, as the body content is only read from the source (e.g., a file) when it is actually needed.

ATTRIBUTES

The following attributes are available:

  • source: The source of the mail body (e.g., a filename).
  • charset: The character encoding of the body.
  • encoding: The transfer encoding of the body (e.g., 'quoted-printable').

METHODS

  • new(source, charset, encoding): Constructor to create a new Mail::Message::Body::Delayed object.
  • get(): Loads and returns the actual mail body object. If the body has already been loaded, it returns the cached object.
  • is_loaded(): Returns true if the body has been loaded, false otherwise.

DIAGNOSTICS

No specific diagnostics are defined for this class. Errors will be reported by the underlying Mail::Message::Body classes when the body is loaded.

الاسم

Mail::Message::Body::Delayed - تحميل مؤجل لجسم رسالة البريد

ملخص

use Mail::Message::Body::Delayed;

# إنشاء كائن جسم مؤجل
my $delayed = Mail::Message::Body::Delayed->new(
    'file.eml',
    'utf8',
    'quoted-printable',
);

# الحصول على كائن الجسم الفعلي عند الحاجة
my $body = $delayed->get();

# الوصول إلى طرق الجسم
my $content = $body->content();
my $headers = $body->headers();

الوصف

يمثل هذا الكلاس جسم رسالة بريد يتم تحميله عند الطلب. وهو مفيد لتقليل استخدام الذاكرة عند التعامل مع رسائل بريد كبيرة، حيث لا تتم قراءة محتوى الجسم من المصدر (مثل ملف) إلا عند الحاجة إليه فعليًا.

السمات

السمات التالية متاحة:

  • source: مصدر جسم البريد (مثل اسم ملف).
  • charset: ترميز أحرف الجسم.
  • encoding: ترميز النقل للجسم (مثل 'quoted-printable').

الطرق

  • new(source, charset, encoding): المنشئ لإنشاء كائن Mail::Message::Body::Delayed جديد.
  • get(): يقوم بتحميل وإرجاع كائن الجسم الفعلي للبريد. إذا تم تحميل الجسم بالفعل، فإنه يرجع الكائن المخزن مؤقتًا.
  • is_loaded(): يرجع true إذا تم تحميل الجسم، و false إذا لم يتم تحميله.

التشخيص

لا توجد تشخيصات محددة محددة لهذا الكلاس. سيتم الإبلاغ عن الأخطاء بواسطة كلاسات Mail::Message::Body الأساسية عند تحميل الجسم.
