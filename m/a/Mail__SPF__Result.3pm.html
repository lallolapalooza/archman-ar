Mail__SPF__Result(3pm)

الحزمة: perl-mail-spf

التراخيص: custom

Mail::SPF::Result(3) وثائق حزم Perl المساهمة Mail::SPF::Result(3)

الاسم

Mail::SPF::Result - فئة نتيجة SPF

الإصدار

الإصدار 3.20250505

الملخص

للاستخدام العام لكائنات Mail::SPF::Result في التعليمات البرمجية التي تستدعي Mail::SPF، راجع Mail::SPF. للحصول على الواجهة التفصيلية لـ Mail::SPF::Result ومشتقاته، راجع أدناه.

إطلاق النتائج

package Mail::SPF::Foo;
use Error ':try';
use Mail::SPF::Result;
sub foo {
    if (...) {
        $server->throw_result('pass', $request)
    }
    else {
        $server->throw_result('permerror', $request, 'Invalid foo');
    }
}

التقاط النتائج

package Mail::SPF::Bar;
use Error ':try';
use Mail::SPF::Foo;
try {
    Mail::SPF::Foo->foo();
}
catch Mail::SPF::Result with {
    my ($result) = @_;
    ...
};

استخدام النتائج

my $result_name     = $result->name;
my $result_code     = $result->code;
my $request         = $result->request;
my $local_exp       = $result->local_explanation;
my $authority_exp   = $result->authority_explanation
    if $result->can('authority_explanation');
my $spf_header      = $result->received_spf_header;

الوصف

يمثل كائن من فئة Mail::SPF::Result نتيجة لطلب SPF.

بشكل عام، لا تحتاج إلى إنشاء كائن من فئة Mail::SPF::Result بشكل صريح باستخدام الباني "new". بدلاً من ذلك، استخدم طريقة الفئة "throw" للإشارة إلى التعليمات البرمجية المستدعية بأنه قد تم تحديد نتيجة نهائية لـ SPF. أي، استخدم Mail::SPF::Result ومشتقاته بطريقة مشابهة للاستثناءات. راجع Error أو "eval" في perlfunc لكيفية معالجة الاستثناءات في Perl.

الباني

الباني التالي مقدم:

new($server, $request): يرجع Mail::SPF::Result
new($server, $request, $text): يرجع Mail::SPF::Result
إنشاء كائن نتيجة SPF وربط كائنات Mail::SPF::Server و Mail::SPF::Request المعطاة به. يمكن تحديد نص نتيجة اختياري.

طرق الفئة

الطرق التالية للفئة مقدمة:

throw($server, $request): يرمي Mail::SPF::Result
throw($server, $request, $text): يرمي Mail::SPF::Result
يرمي كائن نتيجة SPF جديد، مع ربط كائنات Mail::SPF::Server و Mail::SPF::Request المعطاة به. يمكن تحديد نص نتيجة اختياري.
name: يرجع string
مجرد. يرجع اسم نتيجة الفئة (أو الكائن). بالنسبة لفئات التسلسل الهرمي Mail::SPF::Result::*، يتوافق هذا تقريبًا مع الجزء الأخير من اسم الفئة. على سبيل المثال، يرجع "neutral-by-default" إذا تم استدعاء Mail::SPF::Result::NeutralByDefault. انظر أيضًا طريقة "code". يمكن استخدام هذه الطريقة أيضًا كطريقة مثيل.
class: يرجع class
class($name): يرجع class
يقوم بربط اسم النتيجة المعطاة بفئة Mail::SPF::Result::* المقابلة، أو يرجع الفئة الأساسية (الفئة التي يتم الاستدعاء عليها) إذا لم يتم تحديد اسم نتيجة. إذا تم تحديد اسم نتيجة غير معروف، فإنه يرجع undef.
isa_by_name($name): يرجع boolean
إذا كان الكائن (أو الكائن) الذي يتم استدعاء هذه الطريقة عليه يمثل الفئة المعطاة (أو مشتقة منها)، فإنه يرجع true. يرجع false بخلاف ذلك. يمكن استخدام هذه الطريقة أيضًا كطريقة مثيل.
code: يرجع string
مجرد. يرجع رمز نتيجة الفئة النتيجة التي يتم الاستدعاء عليها. (pass, fail, softfail, neutral, none, error, permerror, temperror). جميع رموز النتائج الصالحة صالحة أيضًا كأسماء نتائج، ولكن العكس ليس صحيحًا. يمكن استخدام هذه الطريقة أيضًا كطريقة مثيل.
is_code($code): يرجع boolean
إذا كان الكائن (أو الكائن) الذي يتم استدعاء هذه الطريقة عليه يمثل الرمز المعطى، فإنه يرجع true. يرجع false بخلاف ذلك. يمكن استخدام هذه الطريقة أيضًا كطريقة مثيل.
received_spf_header_name: يرجع string
يرجع 'Received-SPF' كاسم المجال للحقول "Received-SPF". يجب أن يتم تجاوز هذه الطريقة بواسطة امتدادات Mail::SPF التي توفر ميزات غير قياسية (مثل السياسة المحلية) مع القدرة على تخفيف نقاء نتائج SPF، حتى لا تربك مستخدمي حقول الرأس بالاعتقاد بأنها نتيجة طبيعية لـ SPF.

طرق المثيل

طرق المثيل التالية مقدمة:

throw: يرمي Mail::SPF::Result
throw($server, $request): يرمي Mail::SPF::Result
throw($server, $request, $text): يرمي Mail::SPF::Result
يعيد رمي كائن نتيجة SPF موجود. إذا تم تحديد كائنات Mail::SPF::Server و Mail::SPF::Request، فسيتم ربطها بكائن النتيجة، مما يحل محل الكائنات السابقة. إذا تم تحديد نص نتيجة، فإنه يتجاوز النص السابق.
server: يرجع Mail::SPF::Server
يرجع كائن Mail::SPF::Server الذي أنتج النتيجة المعنية.
request: يرجع Mail::SPF::Request
يرجع Mail::SPF::Request الذي أدى إلى النتيجة المعنية.
text: يرجع string
يرجع نص كائن النتيجة.
