جداول الارتباط على الأنواع المرتبة.

تنفذ هذه الوحدة جداول ارتباط تطبيقية، والمعروفة أيضًا بالخرائط المحدودة أو القواميس، نظرًا لوجود دالة ترتيب كامل على المفاتيح. جميع العمليات على الخرائط تطبيقية بحتة (لا توجد آثار جانبية). يعتمد التنفيذ على أشجار ثنائية متوازنة، وبالتالي تستغرق عمليات البحث والإدراج وقتًا لوغاريتميًا بالنسبة لحجم الخريطة.

على سبيل المثال:

     module IntPairs =
       struct
         type t = int * int
         let compare (x0,y0) (x1,y1) =
           match Stdlib.compare x0 x1 with
               0 -> Stdlib.compare y0 y1
             | c -> c
       end
     module PairsMap = Map.Make(IntPairs)
     let m = PairsMap.(empty |> add (0,1) "hello" |> add (1,0) "world")

ينشئ هذا وحدة جديدة PairsMap ، مع نوع جديد 'a PairsMap.t من الخرائط من int * int إلى 'a . في هذا المثال، تحتوي m على قيم string لذا فإن نوعها هو string PairsMap.t .

module type OrderedType = sig end

توقيع الإدخال للمُصنِّع Map.Make .

module type S = sig end

توقيع الإخراج للمُصنِّع Map.Make .

module Make : (Ord : OrderedType) -> sig end

مُصنِّع يبني تنفيذًا لهيكل الخريطة معطى نوع مرتب ترتيبًا كاملاً.
