INHERITANCE

Mail::Message::Convert inherits from Mail::Message.

SYNOPSIS

    use Mail::Message::Convert;

    # Object oriented interface
    my $c = Mail::Message::Convert->new( ... );
    my $m = $c->message( ... );
    my $x = $c->field( ... );

    # Accessor for the message object
    my $msg = $c->message;

    # Example: convert a message
    use Mail::Message;
    my $msg = Mail::Message->new;
    $msg->header->from( "sender@example.com" );
    $msg->header->to( "recipient@example.com" );
    $msg->body->text( "Hello world!\n" );

    my $conv = Mail::Message::Convert->new(
        message => $msg,
        type    => "html",
    );

    print $conv->text;

DESCRIPTION

The Mail::Message::Convert class provides methods to convert a Mail::Message object into a different format. The conversion is done on demand.

This class is intended to be used as a wrapper around a Mail::Message object, providing an interface to get representations of the message in various formats (like HTML, plain text, etc.).

The conversion itself is often delegated to other modules (e.g. Mail::Message::Convert::HTML, Mail::Message::Convert::Text, Mail::Message::Convert::RTF).

METHODS

new( OPTIONS )
Creates a new converter object. The following options are accepted:
message
The Mail::Message object to convert. This option is mandatory.
type
The desired output format. Defaults to text. Supported types depend on the installed conversion modules. Common types include: text, html, rtf.
message()
Returns the Mail::Message object that this converter is wrapping.
type()
Returns the desired output format of this converter.
text()
Returns the message content as plain text.
html()
Returns the message content as HTML.
rtf()
Returns the message content as Rich Text Format (RTF).
field( NAME )
Returns the value of a specific header field, converted to the desired format.

DIAGNOSTICS

This class does not generate any specific diagnostics beyond those generated by the underlying Mail::Message class or the conversion modules it uses. Errors may occur if the specified output format is not supported or if the necessary conversion modules are not installed.
