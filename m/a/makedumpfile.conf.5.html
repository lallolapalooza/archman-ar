NAME

makedumpfile.conf - Configuration file for makedumpfile(8)

DESCRIPTION

The makedumpfile.conf file is used to specify the filtering rules for the crash dump. Each rule is used to identify and filter specific fields from the kernel memory during the dump generation process. This can be used to reduce the size of the dump file or to exclude sensitive information.

The file consists of filter commands, which are processed in the order they appear. The available filter commands are:

Memory access commands

<id>
اسم عشوائي يستخدم للإشارة مؤقتًا إلى عناصر القائمة. يُطلق عليه أيضًا متغير التكرار.
<ArrayVar>
تعبير بسيط في شكل <Symbol>[.member[...]] ينتج عنه متغير مصفوفة.
<StructVar>
تعبير بسيط في شكل <Symbol>[.member[...]] ينتج عنه متغير يشير إلى بنية.
<NextMember>
عضو داخل <StructVar> يشير إلى كائن من نفس نوع <StructVar>.
<ListHeadVar>
تعبير بسيط في شكل <Symbol>[.member[...]] ينتج عنه متغير من نوع struct list_head.
<StructName>
اسم نوع البنية التي يمكن اجتيازها باستخدام متغير HEAD <ListHeadVar> ويحتوي على عضو يسمى <ListHeadMember>.
<ListHeadMember>
اسم عضو في <StructName>، من نوع struct list_head.
<MemberExpression>
تعبير بسيط في شكل [.member[...]] لتحديد عضو أو مكون لعنصر في <ArrayVar> أو <StructVar> أو <StructName>.
<SizeExpression>
قيمة الحجم في شكل <SizeValue>، <id>[.MemberExpression] أو <Symbol>[.member[...]].

يسمح بناء حلقة for بالتكرار على قائمة العناصر في مصفوفة أو قوائم مرتبطة. يتم تعيين كل عنصر في القائمة لمتغير التكرار <id>. يتم تحديد نوع متغير التكرار بواسطة نوع عناصر القائمة. يُطلق على الإدخال المحدد بعد الطرف 'in' إدخال LIST. يمكن أن يكون إدخال LIST متغير مصفوفة، متغير/مؤشر بنية، أو متغير من نوع struct list_head. سيتم تنفيذ مجموعة أوامر erase المحددة بين for و endfor لكل عنصر في إدخال LIST.

إذا كان إدخال LIST المحدد هو متغير مصفوفة، فسيتم تنفيذ الحلقة لكل عنصر مصفوفة. سيتم تحديد حجم المصفوفة باستخدام معلومات dwarf.

إذا كان إدخال LIST المحدد هو متغير/مؤشر بنية، فيجب تحديد عضو اجتياز (<NextMember>) باستخدام الطرف 'via'. ستستمر حلقة for حتى تكون قيمة عضو الاجتياز NULL أو تتطابق مع عنوان العقدة الأولى <StructVar> إذا كانت قائمة مرتبطة دائرية.

إذا تم تحديد إدخال LIST باستخدام متغير من نوع struct list_head، فيجب استخدام الطرف within لتحديد اسم البنية <StructName> التي تحيط به مع عضو نوع struct list_head بعد ':' وهو جزء من القائمة المرتبطة. في عبارة erase، يمثل <id> البنية التي تحتوي على list_head (ELEMENT_OF).

يوضح المثال أدناه كيفية استخدام بناء الحلقة لاجتياز المصفوفة، والقائمة المرتبطة عبر العضو التالي، و list_head.

مثال:

بافتراض أن المقطع التالي من الكود هو من الوحدة النمطية 'mymodule':

struct s1 {
struct *next;
struct list_head list;
char private[100];
void *key;
long key_size;
};

/* Global symbols */
struct s1 mystruct1;
static LIST_HEAD(s1_list_head);
struct s1 myarray[100];

void foo()
{
struct s1 *s1_ptr;
...
...
s1_ptr = malloc(...);
...
...
list_add(&s1_ptr->list, &s1_list_head);
...
}

makedumpfile.conf:
[mymodule]
# erase private fields from list starting with mystruct1 connected via
# 'next' member:
for mys1 in mystruct1 via next
erase mys1.private
erase mys1.key size mys1.key_size
endfor

# erase private fields from list starting with list_head variable
# s1_list_head.
for mys1 in s1_list_head.next within s1:list
erase mys1.private
erase mys1.key size mys1.key_size
endfor

# erase private fields from all elements of the array myarray:
for mys1 in myarray
erase mys1.private
erase mys1.key size mys1.key_size
endfor
EOF

في المثال أعلاه، يجتاز بناء for الأول القائمة المرتبطة من خلال متغير بنية محدد mystruct1 من نوع struct s1. يمكن اجتياز القائمة المرتبطة باستخدام العضو 'next' من mystruct1. لذلك تم استخدام طرف via لتحديد اسم عضو الاجتياز 'next'.

يجتاز بناء for الثاني القائمة المرتبطة من خلال متغير struct list_head محدد s1_list_head.next. الرمز العام s1_list_head هو عنوان بداية القائمة المرتبطة وعضوه next يشير إلى عنوان العضو من نوع struct list_head 'list' من struct s1. لذلك يتم استخدام طرف within لتحديد اسم البنية 's1' التي يمكن اجتيازها باستخدام متغير s1_list_head.next مع اسم عضو نوع struct list_head 'list' الذي هو جزء من القائمة المرتبطة التي تبدأ من الرمز العام s1_list_head.

يجتاز بناء for الثالث عناصر المصفوفة المحددة من خلال متغير مصفوفة myarray.

FILE FORMAT

The configuration file consists of a sequence of filter commands. Each command is on a single line and can be followed by comments starting with '#'. Blank lines are ignored.

The filter commands can be grouped under module names. When makedumpfile is invoked with a module name, only the rules specified under that module name are applied.

General syntax:

[module_name]
*for id in LIST_ENTRY [via NextMember] [within StructName:ListHeadMember]
*filter_command1
*filter_command2
...
*endfor

module_name: Optional name of the kernel module. If specified, the enclosed filter commands are only applied when processing the specified module.

for: Keyword to start a loop.

id: Iteration variable name. Each element in the LIST_ENTRY will be assigned to this variable during iteration.

in: Keyword to specify the list or array to iterate on.

LIST_ENTRY: Can be an array variable, a structure variable/pointer, or a struct list_head type variable.

via: Optional keyword used when iterating over a linked list represented by a structure variable/pointer. It specifies the member name (<NextMember>) used to traverse the list.

within: Optional keyword used when iterating over a linked list represented by a struct list_head type variable. It specifies the name of the structure (<StructName>) containing the list_head and the name of the list_head member (<ListHeadMember>).

endfor: Keyword to end the loop.

FILTER COMMANDS

The following commands can be used within a for loop to filter memory regions:

erase MemberExpression
Erase the specified member of the current element. The size of the member is determined automatically.
erase MemberExpression size SizeExpression
Erase the specified member with the given size. This is useful when the member's size cannot be determined automatically or when you want to erase a portion of the member.
fill MemberExpression with Value
Fill the specified member with the given value. The value can be a hexadecimal number (e.g., 0x00).
fill MemberExpression size SizeExpression with Value
Fill the specified member with the given size and value.

Special Symbols:

ELEMENT_OF
Represents the current element being processed in the loop. Used in conjunction with the within keyword to specify the structure containing the list head.

Example:

The following example erases the 'private' field and a portion of the 'key' field from each element of the 'myarray' array:

for mys1 in myarray
erase mys1.private
erase mys1.key size mys1.key_size
endfor
