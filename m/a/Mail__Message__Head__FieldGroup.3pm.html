Mail::Message::Head::FieldGroup(3) وثائق المستخدم للمساهمين في Perl Mail::Message::Head::FieldGroup(3)

الاسم

Mail::Message::Head::FieldGroup - مجموعة فرعية من الحقول في رأس

الوراثة

Mail::Message::Head::FieldGroup
  هو Mail::Reporter
Mail::Message::Head::FieldGroup يتم توسيعه بواسطة
  Mail::Message::Head::ListGroup
  Mail::Message::Head::ResentGroup
  Mail::Message::Head::SpamGroup

الملخص

لا يتم استدعاء هذا مباشرة.

الوصف

بعض الحقول لها معنى مدمج: مجموعة من الحقول التي تمثل خطوة وسيطة أثناء نقل الرسالة (مجموعة resent group، تم تنفيذها في Mail::Message::Head::ResentGroup)، حقول مضافة بواسطة برامج القوائم (تم تنفيذها في Mail::Message::Head::ListGroup)، أو حقول مضافة بواسطة برامج اكتشاف البريد العشوائي (تم تنفيذها بواسطة Mail::Message::Head::SpamGroup). يمكن استخراج كل مجموعة حقول أو إضافتها كمجموعة باستخدام كائنات تستند إلى التنفيذ في هذه الفئة.

يمتد "DESCRIPTION" في Mail::Reporter.

يمتد "METHODS" في Mail::Reporter.

المُنشِئات

يمتد "Constructors" في Mail::Reporter.

$obj->clone()
قم بعمل نسخة من هذا الكائن. يتم نسخ أسماء الحقول المجمعة ويتم الاحتفاظ بمعلومات نوع القائمة. لا يتم عمل نسخة عميقة للرأس: يتم نسخه كمرجع فقط.
$obj->from($head|$message)
قم بإنشاء مجموعة حقول بناءً على الرسالة المحددة $message أو الرأس $head. قد يعيد هذا واحدًا أو أكثر من الكائنات، والتي تعتمد على نوع المجموعة. يتم تخزين حقول القائمة جميعها في كائن واحد، حيث يمكن أن تظهر مجموعات إعادة الإرسال والبريد العشوائي أكثر من مرة.
$any->implementedTypes()
يعيد قائمة من السلاسل النصية تحتوي على جميع القيم الممكنة لـ type().
$class->new(@fields, %options)
ينشئ كائنًا يحتفظ بمجموعة من الحقول @fields. يمكن تحديد @fields ككائنات "Mail::Message::Field" أو كأزواج مفتاح-قيمة. يمكن خلط %options و @fields (كأزواج مفتاح-قيمة): يتم تمييزها حسب اسمها، حيث تبدأ الحقول دائمًا بحرف كبير. يجب أن تأتي كائنات الحقول دائمًا قبل %options. يحسن القاعدة، انظر "Constructors" في Mail::Reporter

head => $head
يُستخدم الكائن $head لتخزين الحقول المجمعة فيه. إذا لم يتم تحديد رأس، فسيتم إنشاء Mail::Message::Head::Partial لك. إذا كنت ترغب في مسح الحقول الموجودة في رأس، فاستخدم الطريقة from().

الرأس

$obj->add( <$field, $value> | $object )
أضف حقلًا إلى الرأس، باستخدام مجموعة الحقول. عندما تكون مجموعة الحقول مرتبطة بالفعل برأس حقيقي، فستظهر في هذا الرأس بالإضافة إلى تسجيلها في هذه المجموعة. إذا لم يتم تحديد رأس، فسيظهر الحقل داخليًا فقط.

» مثال: إضافة حقل إلى مجموعة قوائم غير مرتبطة

my $this = Mail::Message::Head::ListGroup->new(...);
$this->add('List-Id' => 'mailbox');
$msg->addListGroup($this);
$msg->send;

» مثال: إضافة حقل إلى مجموعة قوائم مرتبطة

my $lg = Mail::Message::Head::ListGroup->from($msg);
$lg->add('List-Id' => 'mailbox');
$obj->addFields( [$fieldnames] )
أضف بعض $fieldnames إلى المجموعة.
$obj->attach($head)
أضف مجموعة حقول إلى رسالة $head. يتم نسخ الحقول (! - أي إنشاء نسخة) إلى الرأس، حتى يمكن استخدام كائن المجموعة مرة أخرى.

» مثال: ربط مجموعة قوائم برسالة

my $lg = Mail::Message::Head::ListGroup->new(...);
$lg->attach($msg->head);
$msg->head->addListGroup($lg);   # نفس الشيء
$msg->head->addSpamGroup($sg);   # تم تنفيذه أيضًا باستخدام attach
$obj->delete()
احذف جميع أسطر الرأس المرتبطة بمجموعة الحقول هذه.
$obj->fieldNames()
يعيد أسماء الحقول المستخدمة في هذه المجموعة.
$obj->fields()
يعيد الحقول المحددة لهذه المجموعة.
$obj->head()
يعيد كائن الرأس، الذي يشمل هذه الحقول.

الوصول إلى الرأس

$obj->software()
يعيد اسم البرنامج كما هو محدد في الرؤوس. قد يكون مختلفًا قليلاً عن نتيجة type()، ولكنه عادةً لا يختلف كثيرًا.
$obj->type()
يعيد اسمًا مجردًا لمجموعة الحقول؛ البرنامج الذي يتحكم فيها. يتم إرجاع "undef" في حالة عدم تحديد النوع. الأسماء الصالحة تعتمد على نوع المجموعة: انظر صفحات الدليل المقابلة. يمكن الحصول على قائمة كاملة بجميع الأنواع باستخدام implementedTypes().
$obj->version()
يعيد رقم إصدار البرنامج الذي أنتج الحقول. تترك بعض أنواع البرامج مثل هذا الأثر، وحالات أخرى ستعيد "undef".

الداخلية

$obj->collectFields( [$name] )
يمسح الرأس بحثًا عن الحقول التي عادة ما تكون في مجموعة حقول بالاسم المحدد $name. بالنسبة لمجموعات القوائم، لا يمكنك تحديد $name: سيتم العثور على مجموعة رؤوس واحدة فقط (تعتبر جميع الرؤوس ناتجة عن حزمة برامج قائمة واحدة بالضبط).

يتم استدعاء هذه الطريقة تلقائيًا عند إنشاء مجموعة حقول باستخدام from() على رأس أو رسالة موجودة.

النتائج هي أسماء حقول الرأس الموجودة، في سياق عددي للحقول. تشير القائمة الفارغة / 0 إلى عدم العثور على مجموعة.

تأكد من إبلاغ مؤلف MailBox إذا رأيت أنه تم تضمين الكثير أو القليل جدًا من الحقول.

$obj->detected($type, $software, $version)
يضبط القيم لنوع المجموعة والبرنامج والإصدار، ربما إلى "undef".

Mail::Message::Head::FieldGroup(3pm)

NAME

Mail::Message::Head::FieldGroup - collection of Mail::Message::Head::Field objects

INHERITANCE

This class is a subclass of Mail::Reporter.

SYNOPSIS

  use Mail::Message::Head::FieldGroup;

  my $group = Mail::Message::Head::FieldGroup->new;
  $group->add( Mail::Message::Head::Field->new( 'Subject', 'Hello' ));
  $group->add( Mail::Message::Head::Field->new( 'From',    'me@example.com' ));

  print $group->print;
  print $group->details;

DESCRIPTION

A FieldGroup is a container for a set of Mail::Message::Head::Field objects. It is used to represent the fields with the same name in the header of a mail message.

For example, all Received fields are grouped together in one FieldGroup.

METHODS

$obj->add( $field )
Add a Mail::Message::Head::Field object to the group.
$obj->child( [$index] )
Return the field at the given index. If no index is specified, return the first field in the group.
$obj->count()
Return the number of fields in the group.
$obj->details()
Produce information about the detected/created field group, which may be helpful during debugging. A nicely formatted string is returned.
$obj->fields()
Return a list of all fields in the group.
$obj->find( $name )
Find a field in the group by name. Returns the first field found, or undef if no field is found.
$obj->findFirst( $name )
Find the first field with the given name.
$obj->findLast( $name )
Find the last field with the given name.
$obj->name()
Return the name of the fields in this group.
$obj->print( [$fh] )
Print the group to the specified $fh. This is probably only useful for debugging purposed. The output defaults to the selected file handle.
$obj->remove( $field )
Remove a field from the group.
$obj->removeFirst( $field )
Remove the first occurrence of a field from the group.
$obj->removeLast( $field )
Remove the last occurrence of a field from the group.
$obj->replaceFirst( $old_field, $new_field )
Replace the first occurrence of $old_field with $new_field.
$obj->replaceLast( $old_field, $new_field )
Replace the last occurrence of $old_field with $new_field.
