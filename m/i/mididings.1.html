mididings(1) دليل الأوامر العامة mididings(1)

الاسم

mididings - موجه ومعالج MIDI يعتمد على Python.

الوصف

توفر أداة سطر الأوامر mididings طرقًا مختلفة لتشغيل الرقع دون كتابة برامج Python متكاملة.

الخيارات

--version

عرض رقم إصدار Python و mididings.

-h, --help

عرض رسالة المساعدة.

خيارات الواجهة الخلفية

-A

استخدام متسلسل ALSA.

-J

استخدام JACK MIDI (مخزن مؤقتًا).

-R

استخدام JACK MIDI (في الوقت الفعلي).

-c اسم العميل

اسم عميل ALSA أو JACK.

-i منافذ

عدد منافذ الإدخال.

-o منافذ

عدد منافذ الإخراج.

-I اتصالات

اتصالات منفذ الإدخال. تعبير عادي.

-O اتصالات

اتصالات منفذ الإخراج. تعبير عادي.

خيارات عامة

-d تأخير

تأخير (بالثواني) قبل بدء المعالجة.

-t إزاحة

إزاحة الأوكتاف.

-z إزاحة

إزاحة للمنفذ والقناة وأرقام البرنامج.

خيارات الوضع

-f اسم الملف

اسم ملف البرنامج النصي المراد تشغيله.

-s

صدفة تفاعلية.

-S

صدفة تفاعلية مع تنفيذ رقعة تلقائي.

-p

طباعة أحداث MIDI. لا تتم معالجة.

انظر أيضًا

راجع التوثيق عبر الإنترنت على https://mididings.github.io/mididings/ للحصول على معلومات حالية حول mididings وأدواته ذات الصلة.

الأخطاء

أخطاء؟ هل تمزح؛ لا توجد أخطاء في هذا البرنامج. ولكن إذا حدث أننا كنا مخطئين، فقدم تقرير خطأ بأكبر قدر ممكن من التفاصيل على https://github.com/mididings/mididings/issues.
