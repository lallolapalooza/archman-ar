val add : key -> 'a -> 'a t -> 'a t

add key data m تُرجع خريطة تحتوي على نفس الارتباطات مثل m، بالإضافة إلى ارتباط key بـ data. إذا كان key مرتبطًا بالفعل في m بقيمة مساوية جسديًا لـ data، فسيتم إرجاع m دون تغيير (وستكون نتيجة الدالة مساوية جسديًا لـ m). وإلا، فإن الارتباط السابق لـ key في m يختفي.

منذ 5.1

val update : key -> ('a option -> 'a option) -> 'a t -> 'a t

update key f m تُرجع خريطة تحتوي على نفس الارتباطات مثل m، باستثناء ارتباط key. اعتمادًا على قيمة y حيث y هي f (find_opt key m)، يتم إضافة الارتباط لـ key أو إزالته أو تحديثه. إذا كانت y هي None، يتم إزالة الارتباط إذا كان موجودًا؛ وإلا، إذا كانت y هي Some z فإن key يرتبط بـ z في الخريطة الناتجة. إذا كان key مرتبطًا بالفعل في m بقيمة مساوية جسديًا لـ z، فسيتم إرجاع m دون تغيير (وستكون نتيجة الدالة مساوية جسديًا لـ m).

منذ 3.12

val remove : key -> 'a t -> 'a t

remove x m تُرجع خريطة تحتوي على نفس الارتباطات مثل m، باستثناء x الذي يكون غير مرتبط في الخريطة الناتجة. إذا لم يكن x موجودًا في m، فسيتم إرجاع m دون تغيير (وستكون نتيجة الدالة مساوية جسديًا لـ m).

قبل 4.03 لم تكن المساواة الجسدية مضمونة.

val merge : (key -> 'a option -> 'b option -> 'c option) -> 'a t -> 'b t -> 'c t

merge f m1 m2 تحسب خريطة تكون مفاتيحها مجموعة فرعية من مفاتيح m1 و m2. يتم تحديد وجود كل ارتباط وقيمته المقابلة باستخدام الدالة f. من حيث عملية find_opt، لدينا find_opt x (merge f m1 m2) = f x (find_opt x m1) (find_opt x m2) لأي مفتاح x، بشرط أن f x None None = None.

منذ 3.12

val union : (key -> 'a -> 'a -> 'a option) -> 'a t -> 'a t -> 'a t

union f m1 m2 تحسب خريطة تكون مفاتيحها مجموعة فرعية من مفاتيح m1 و m2. عندما يكون الارتباط نفسه معرفًا في كلا الوسيطين، يتم استخدام الدالة f لدمجهما. هذه حالة خاصة من merge: union f m1 m2 يعادل merge f' m1 m2، حيث

- f' _key None None = None

- f' _key (Some v) None = Some v

- f' _key None (Some v) = Some v

- f' key (Some v1) (Some v2) = f key v1 v2

الارتباطات

val bindings : 'a t -> (key * 'a) list

إرجاع قائمة بجميع ارتباطات الخريطة المعطاة. تكون القائمة المرجعة مرتبة بترتيب تصاعدي للمفاتيح بالنسبة للترتيب Ord.compare، حيث Ord هو الوسيط المعطى لـ Map.Make.

إرجاع الارتباط ذي المفتاح الأصغر في الخريطة المعطاة (بالنسبة لترتيب Ord.compare)، أو None إذا كانت الخريطة فارغة.

منذ 4.05

البحث

val find : key -> 'a t -> 'a

find x m تُرجع القيمة الحالية لـ x في m، أو ترفع Not_found إذا لم يكن هناك ارتباط لـ x.

val find_opt : key -> 'a t -> 'a option

find_opt x m تُرجع Some v إذا كانت القيمة الحالية لـ x في m هي v، أو None إذا لم يكن هناك ارتباط لـ x.

منذ 4.05

val find_first : (key -> bool) -> 'a t -> key * 'a

find_first f m، حيث f دالة متزايدة بشكل رتيب، تُرجع ارتباط m ذي المفتاح الأصغر k بحيث f k، أو ترفع Not_found إذا لم يوجد مثل هذا المفتاح.

على سبيل المثال، find_first (fun k -> Ord.compare k x >= 0) m سترجع أول ارتباط k, v من m حيث Ord.compare k x >= 0 (بشكل بديهي: k >= x)، أو ترفع Not_found إذا كان x أكبر من أي عنصر في m.

منذ 4.05

val find_first_opt : (key -> bool) -> 'a t -> (key * 'a) option

find_first_opt f m، حيث f دالة متزايدة بشكل رتيب، تُرجع خيارًا يحتوي على ارتباط m ذي المفتاح الأصغر k بحيث f k، أو None إذا لم يوجد مثل هذا المفتاح.
