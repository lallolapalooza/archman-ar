الوحدة Magic_number
: sig end

عادة ما يكون الرقم السحري هو "Caml1999I011". يتكون من بادئة أبجدية رقمية، هنا Caml1990I، متبوعة بإصدار، هنا 011. تحدد البادئة نوع البيانات المرقّمة: هنا يشير I إلى أن هذا هو الرقم السحري لملفات .cmi.

جميع الأرقام السحرية لها نفس طول البايت، magic_length ، وهذا مهم للمستخدمين لأنه يمنحهم عدد البايتات التي يجب قراءتها للحصول على التسلسل البايتي الذي يجب أن يكون رقمًا سحريًا. سيبدو رمز المستخدم النموذجي كما يلي:

        let ic = open_in_bin path in
        let magic =
          try really_input_string ic Magic_number.magic_length
          with End_of_file -> ... in
        match Magic_number.parse magic with
        | Error parse_error -> ...
        | Ok info -> ...

يتوقع إصدار مترجم معين إصدارًا محددًا لكل نوع من أنواع الملفات الكائنة، وسيفشل إذا تم إعطاؤه إصدارًا غير مدعوم. نظرًا لأن الإصدارات تنمو بشكل رتيب، يمكنك مقارنة الإصدار المحلل بـ "الإصدار الحالي" المتوقع لنوع ما، لمعرفة ما إذا كان ملف الكائن ذو السحر الخاطئ يأتي من الماضي أو من المستقبل.

كتلة رمز مثال تتوقع "الإصدار الحالي" المدعوم لنوع معين من الأرقام السحرية، هنا Cmxa ، هي كما يلي:

        let ic = open_in_bin path in
        begin
          try Magic_number.(expect_current Cmxa (get_info ic)) with
          | Parse_error error -> ...
          | Unexpected error -> ...
        end;
        ...

تفرق أخطاء التحليل بين المدخلات التي هي Not_a_magic_number str ، والتي من المرجح أن تأتي من الملف المختلف تمامًا، و Truncated str ، التي تثيرها الرؤوس التي تمثل البادئة (ربما فارغة) لرقم سحري صالح.

تتوافق الأخطاء غير المتوقعة مع الأرقام السحرية الصالحة التي ليست هي الرقم المتوقع، إما لأنها تتوافق مع نوع مختلف، أو لإصدار أحدث أو أقدم.

ستقوم الوظائف المساعدة explain_parse_error و explain_unexpected_error بإنشاء شرح نصي لكل خطأ، للاستخدام في رسائل الخطأ.

تحليل الأرقام السحرية

type parse_error =
| Truncated of string
| Not_a_magic_number of string

val explain_parse_error : kind option -> parse_error -> string

ينتج شرحًا لخطأ تحليل. إذا لم يتم توفير نوع، نستخدم صيغة غير محددة تقترح أن أي ملف كائن تم إنتاجه بواسطة المترجم سيكون مرضياً.

val parse : raw -> (info, parse_error) result

يحلل رقمًا سحريًا خامًا

val read_info : in_channel -> (info, parse_error) result

يقرأ رقمًا سحريًا خامًا من قناة إدخال.

إذا كانت البيانات المقروءة str ليست رقمًا سحريًا صالحًا، فيمكن استردادها من حمولة Truncated str | Not_a_magic_number str لحالة Error parse_error.

إذا نجح التحليل بنتيجة Ok info، فإننا نعلم أنه تم استهلاك magic_length بايت بالضبط من قناة الإدخال.

إذا كنت ترغب أيضًا في فرض أن الرقم السحري هو الإصدار الحالي، فراجع Misc.Magic_number.read_current_info أدناه.

val magic_length : int

التحقق من أن الأرقام السحرية حديثة

type 'a unexpected = {
expected : 'a ;
actual : 'a ;
}

type unexpected_error =
| Kind of kind unexpected
| Version of kind * version unexpected

val check_current : kind -> info -> (unit, unexpected_error) result

check_current kind info تتحقق من أن info السحري المقدم هو الإصدار الحالي لرأس السحر الخاص بالنوع kind.

val explain_unexpected_error : unexpected_error -> string

يقدم شرحًا لـ unexpected_error.

type error =
| Parse_error of parse_error
| Unexpected_error of unexpected_error

val read_current_info : expected_kind:kind option -> in_channel -> (info, error) result

يقرأ رقمًا سحريًا مثل read_info، ويتحقق من أنه الإصدار الحالي لنوعه. إذا كان الوسيط expected_kind هو None، يتم قبول أي نوع.
