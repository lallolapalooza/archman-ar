MIME__Field__ParamVal(3pm)

الحزمة: perl-mime-tools

التراخيص: GPL, PerlArtistic

MIME::Field::ParamVal(3) توثيق Perl المساهم به من قبل المستخدم MIME::Field::ParamVal(3)

الاسم

MIME::Field::ParamVal - فئة فرعية من Mail::Field، للحقول المنظمة من MIME

ملخص

# إنشاء كائن لحقل نوع المحتوى:
$field = new Mail::Field 'Content-type';
# تعيين بعض السمات:
$field->param('_'        => 'text/html');
$field->param('charset'  => 'us-ascii');
$field->param('boundary' => '---ABC---');
# نفس الشيء:
$field->set('_'        => 'text/html',
            'charset'  => 'us-ascii',
            'boundary' => '---ABC---');
# الحصول على سمة، أو undefined إذا لم تكن موجودة:
print "no id!"  if defined($field->param('id'));
# نفس الشيء، ولكن استخدم سلسلة فارغة للقيم المفقودة:
print "no id!"  if ($field->paramstr('id') eq '');
# الإخراج كسلسلة نصية:
print $field->stringify, "\n";

الوصف

هذه فئة رئيسية مجردة لمعظم حقول MIME. تتعامل مع الحقول ذات الصيغة العامة مثل هذه:

Content-Type: Message/Partial;
    number=2; total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

التعليقات مدعومة *بين* العناصر، مثل هذا:

Content-Type: Message/Partial; (a comment)
    number=2  (another comment) ; (yet another comment) total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

الواجهة العامة

set [\%PARAMHASH | KEY=>VAL,...,KEY=>VAL]
طريقة الكائن. تعيين هذا الحقل. يجب أن تحتوي paramhash على أسماء المعلمات بأحرف *صغيرة تمامًا*، مع استخدام اسم المعلمة الخاص "_" للإشارة إلى المعلمة "الافتراضية" (غير المسماة) للحقل: 
# Set up to be...
#
#     Content-type: Message/Partial; number=2; total=3; id="ocj=pbe0M2"
#
$conttype->set('_'       => 'Message/Partial',
               'number'  => 2,
               'total'   => 3,
               'id'      => "ocj=pbe0M2");

لاحظ أنه يتم اعتبار وسيط واحد *مرجعًا* إلى paramhash، بينما يتم اعتبار الوسائط المتعددة عناصر paramhash نفسها.

توفير undef لـ hashref، أو مجموعة قيم فارغة، يمسح الكائن فعليًا.

يتم إرجاع الكائن الذاتي.

parse_params STRING
طريقة صنف/كائن مساعدة. استخراج معلومات المعلمات من حقل منظم، وإرجاعها كمرجع إلى hash. على سبيل المثال، هذا حقل بمعلمات: 
Content-Type: Message/Partial;
    number=2; total=3;
    id="oc=jpbe0M2Yt4s@thumper.bellcore.com"

هذا هو كيف يمكنك استخراجها:

$params = $class->parse_params('content-type');
if ($$params{'_'} eq 'message/partial') {
    $number = $$params{'number'};
    $total  = $$params{'total'};
    $id     = $$params{'id'};
}

مثل أسماء الحقول، يتم تحويل أسماء المعلمات إلى أحرف صغيرة. المعلمة الخاصة '_' تعني المعلمة الافتراضية للحقل.

ملاحظة: تم توفير هذه كطريقة عامة لدعم التوافق مع الإصدارات السابقة، ولكن ربما لا ينبغي عليك استخدامها.

parse STRING
طريقة صنف/كائن. تحليل السلسلة إلى الكائن. يتم مسح أي معلومات سابقة. يتم إرجاع الكائن الذاتي.

يمكن استخدامها أيضًا كمنشئ.

param PARAMNAME,[VALUE]
طريقة الكائن. إرجاع المعلمة المعطاة، أو undef إذا لم تكن هناك. مع وسيط، قم بتعيين المعلمة إلى تلك القيمة. اسم المعلمة لا يميز بين الأحرف الكبيرة والصغيرة. تشير "_" إلى المعلمة "الافتراضية".
paramstr PARAMNAME,[VALUE]
طريقة الكائن. مثل param(): إرجاع المعلمة المعطاة، أو *سلسلة فارغة* إذا لم تكن موجودة. مع وسيط، قم بتعيين المعلمة إلى تلك القيمة. اسم المعلمة لا يميز بين الأحرف الكبيرة والصغيرة. تشير "_" إلى المعلمة "الافتراضية".
stringify
طريقة الكائن. تحويل الحقل إلى سلسلة نصية، وإرجاعها.
tag
طريقة الكائن، مجردة. إرجاع علامة هذا الحقل.
