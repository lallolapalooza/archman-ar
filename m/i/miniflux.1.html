CONFIGURATION FILE

\n

The configuration file is a text file that follow these rules:

\n

- Miniflux expects each line to be in KEY=VALUE format.\n
\n - Lines beginning with # are processed as comments and ignored.\n
\n - Blank lines are ignored.\n
\n - There is no variable interpolation.

\n

Keys are the same as the environment variables described below.\n
\n Environment variables override the values defined in the config file.

\n
\n
\n

ADMIN_PASSWORD
\n
Admin user password, used only if $CREATE_ADMIN is enabled.\n
\n Default is empty.

ADMIN_PASSWORD_FILE
\n
Path to a secret key exposed as a file, it should contain $ADMIN_PASSWORD\n value.\n
\n Default is empty.
\n
ADMIN_USERNAME
\n
Admin user login, used only if $CREATE_ADMIN is enabled.\n
\n Default is empty.
\n
ADMIN_USERNAME_FILE

\n Default is empty.
\n

AUTH_PROXY_USER_CREATION

ملف التكوين

\n

ملف التكوين هو ملف نصي يتبع القواعد التالية:

\n

- يتوقع Miniflux أن يكون كل سطر بتنسيق KEY=VALUE.\n
\n - تتم معالجة الأسطر التي تبدأ بـ # كتعليقات ويتم تجاهلها.\n
\n - يتم تجاهل الأسطر الفارغة.\n
\n - لا يوجد استيفاء للمتغيرات.

\n

المفاتيح هي نفس متغيرات البيئة الموصوفة أدناه.\n
\n تتجاوز متغيرات البيئة القيم المحددة في ملف التكوين.

\n
\n
\n

OPTIONS

ALLOW_UNSUBSCRIBE
Allow users to unsubscribe from feeds.
Default is enabled.
ALWAYS_FETCH_ICONS
Force fetching feed icons.
Default is disabled.
CREATE_DEMO_ACCOUNT
Create a demo account with username "demo" and password "demo".
Disabled by default.
DATABASE_DRIVER
Database driver. Supported values are:
"mysql", "postgres", "sqlite".
Default is "sqlite".
DATABASE_OPEN_MAX_CONNS
Maximum number of open connections to the database.
Default is 25.
DATABASE_RETRY_MAX_ATTEMPTS
Maximum number of connection retries.
Default is 5.
DATABASE_URL
Database connection URL. Example for PostgreSQL:
postgres://user:password@host:port/database?sslmode=disable
Example for MySQL:
mysql://user:password@host:port/database
Example for SQLite:
sqlite:///path/to/database.db
FETCH_ALL_FEEDS
Fetch all feeds even if they are disabled.
Default is disabled.
FETCH_ATTEMPT_DELAY
Delay in minutes before retrying a failed feed fetch.
Default is 10 minutes.
FETCH_CPU_LIMIT
CPU limit for fetching feeds.
Default is 100%.
FETCH_DUPLICATE_ENTRIES_LIMIT
Maximum number of duplicate entries to keep.
Default is 10.
FETCH_EMAIL_NOTIFICATIONS_ENABLED
Enable email notifications for new entries.
Disabled by default.
FETCH_EXTERNAL_FEEDS
Fetch feeds from external services like YouTube.
Default is enabled.
FETCH_MAX_ITEMS
Maximum number of entries to fetch per feed.
Default is 100.
FETCH_PARALLEL_LIMIT
Maximum number of feeds to fetch in parallel.
Default is 10.
FETCH_USER_AGENT
User-Agent string for fetching feeds.
Default is miniflux/2.0.
FETCH_YOUTUBE_WATCH_TIME
Fetch video duration from YouTube API.
Disabled by default.
GUEST_USER_ENABLED
Enable guest user.
Disabled by default.
HEALTHCHECK_URL
Healthcheck.io URL.
Default is empty.
HTTP_CLIENT_TIMEOUT
HTTP client timeout in seconds.
Default is 30 seconds.
HTTPS_ONLY
Force HTTPS connections.
Default is enabled.
LANGUAGE
Default language for the web interface.
Default is en.
LISTEN_ADDR
Network address to listen on.
Default is "127.0.0.1:8080".
OAUTH2_CLIENT_ID
OAuth2 Client ID for external authentication providers.
Default is empty.
OAUTH2_CLIENT_SECRET
OAuth2 Client Secret for external authentication providers.
Default is empty.
OAUTH2_REDIRECT_URL
OAuth2 Redirect URL.
Default is empty.
OAUTH2_SCOPES
OAuth2 Scopes.
Default is empty.
OAUTH2_TOKEN_URL
OAuth2 Token URL.
Default is empty.
OAUTH2_USERINFO_URL
OAuth2 UserInfo URL.
Default is empty.
PARSER_MAX_LINKS_PER_PAGE
Maximum number of links to parse per page.
Default is 500.
PORT
Override LISTEN_ADDR to 0.0.0.0:$PORT.
Default is empty.
RUN_MIGRATIONS
Set to 1 to run database migrations.
Disabled by default.
SCHEDULER_ENTRY_FREQUENCY_FACTOR
Factor to increase refresh frequency for the entry frequency scheduler.
Default is 1.
SCHEDULER_ENTRY_FREQUENCY_MAX_INTERVAL
Maximum interval in minutes for the entry frequency scheduler.
Default is 1440 minutes (24 hours).
SCHEDULER_ENTRY_FREQUENCY_MIN_INTERVAL
Minimum interval in minutes for the entry frequency scheduler.
Default is 5 minutes.
SCHEDULER_ROUND_ROBIN_MAX_INTERVAL
Maximum interval in minutes for the round robin scheduler.
Default is 1440 minutes (24 hours).
SCHEDULER_ROUND_ROBIN_MIN_INTERVAL
Minimum interval in minutes for the round robin scheduler.
Default is 60 minutes.
WATCHDOG
Enable or disable Systemd watchdog.
Enabled by default.
WEBAUTHN
Enable or disable WebAuthn/Passkey authentication.
You must provide a username on the login page if you are using non-residential keys. However, this is not required for discoverable credentials.
Default is disabled.
WORKER_POOL_SIZE
Number of background workers.
Default is 16 workers.
YOUTUBE_API_KEY
YouTube API key for use with FETCH_YOUTUBE_WATCH_TIME. If nonempty, the duration will be fetched from the YouTube API. Otherwise, the duration will be fetched from the YouTube website.
Default is empty.
YOUTUBE_EMBED_URL_OVERRIDE
YouTube URL which will be used for embeds.
Default is https://www.youtube-nocookie.com/embed/.
