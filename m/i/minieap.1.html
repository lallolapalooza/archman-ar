minieap(1)

الحزمة: minieap

التراخيص: GPL

SYNOPSIS

minieap [options]

DESCRIPTION

minieap is a minimal EAP authentication tool. It can be used to authenticate to a network using various EAP methods.

OPTIONS

-h, --help
Show help message and exit.
-v, --version
Show version and exit.
-c, --config FILE
Use configuration file FILE.
-i, --interface INTERFACE
Use network interface INTERFACE.
-s, --server SERVER
Authentication server SERVER.
-p, --port PORT
Authentication server port PORT.
-m, --method METHOD
EAP method METHOD.
-u, --username USERNAME
Username USERNAME.
-P, --password PASSWORD
Password PASSWORD.
-d, --debug
Enable debug output.

Available network modules

  • eth0
  • wlan0

Available package modifier

  • wpa_supplicant
  • netplan

SEE ALSO

eap.conf(5), wpa_supplicant.conf(5)
