mdoc-export-html(1)

الحزمة: mono

التراخيص: GPL, LGPL2.1, MPL

mdoc-export-html(1) دليل الأوامر العامة mdoc-export-html(1)

الاسم

mdoc export-html - تحويل mdoc(5) XML إلى HTML.

الملخص

mdoc export-html [خيار]* أدلة

الوصف

ينشئ mdoc export-html ملفات HTML من ملفات XML الموثقة بتنسيق mdoc(5) الموجودة داخل الأدلة.

الخيارات

--default-template
يكتب XSLT الافتراضي المستخدم إلى stdout.
--ext=امتداد
امتداد الملف المراد استخدامه للملفات المنشأة.

الافتراضي هو html.

--force-update
إنشاء ملفات جديدة دائمًا. إذا لم يتم تحديده، فسيتم إنشاء ملف إخراج جديد فقط إذا كان ملف التوثيق المصدر أحدث من ملف الإخراج الهدف.
-o, --out=دليل
اكتب الملفات المنشأة داخل الدليل دليل.
--template=ملف
ملف XSLT يستخدم لإنشاء الملفات المنشأة.

إذا لم يتم تحديده، فإنه يستخدم القالب الذي تنتجه --dump-template.

راجع قسم تنسيق القالب أدناه لمزيد من المعلومات.

--with-profile=ملف شخصي
معالجة الأنواع والأعضاء داخل ملف تعريف .NET ملف شخصي فقط. يمكن تحديده عدة مرات. إذا لم يتم تحديده، فسيتم معالجة جميع الأنواع والأعضاء، بغض النظر عن الإصدار.

الملفات الشخصية الصالحة هي:

monotouch
net_1_0
net_1_1
net_2_0
net_3_0
net_3_5
net_4_0
silverlight
--with-version=إصدار
معالجة الأنواع والأعضاء داخل إصدار التجميع إصدار فقط. يمكن تحديده عدة مرات. إذا لم يتم تحديده، فسيتم معالجة جميع الأنواع والأعضاء، بغض النظر عن الإصدار.

الإصدار هو إصدار تجميع، على سبيل المثال 2.0.5.0.

-h, -?, --help
عرض رسالة مساعدة والخروج.

تنسيق القالب

ملف القالب هو XSLT يحتاج إلى معالجة مستند XML الإدخال التالي:

  <Page>
    <CollectionTitle>عنوان المجموعة</CollectionTitle>
    <PageTitle>عنوان الصفحة</PageTitle>
    <Summary>ملخص الصفحة</Summary>
    <Signature>إعلان النوع</Signature>
    <Remarks>ملاحظات النوع</Remarks>
    <Members>أعضاء النوع</Members>
    <Copyright>حقوق نشر التوثيق</Copyright>
  </Page>

يستخدم HTML المنشأ أيضًا العديد من فئات CSS. يمكنك إما استخدام ال قالب المسمى create-default-style الموجود ضمن إخراج --default-template لإنشاء هذه الفئات، أو تحديد فئات CSS التالية بشكل صريح:

.CollectionTitle
.PageTitle
.Summary
.Signature
.Remarks
.Members
.Copyright
.Section
.SectionBox
.NamespaceName
.NamespaceSummary
.MemberName
.MemberSignature
.MemberBox
.Subsection
.SubsectionBox
.SignatureTable
.EnumerationsTable
.CodeExampleTable
.MembersListing
.TypesListing
.InnerSignatureTable
.TypePermissionsTable

روابط HTML

جميع الأعضاء داخل ملف HTML لديهم سمة id للسماح بالربط بعضو معين. قيمة سمة id هي معرف السلسلة للعضو المحدد.

راجع قسم CREF FORMAT من mdoc(5) لمزيد من المعلومات.
