NAME

mdsearch - search file metadata

SYNOPSIS

mdsearch [OPTIONS] [QUERY]

DESCRIPTION

The mdsearch utility allows you to search for files based on their metadata attributes. It uses the Spotlight query language for specifying search criteria.

OPTIONS

--use-kerberos=mode

Use Kerberos authentication. Possible modes are:
never
Do not use Kerberos.
ask
Ask the user for a Kerberos ticket.
always
Always use Kerberos.
This will enforce --use-kerberos=required.

--use-winbind-ccache

Try to use the credential cache by winbind.

--client-protection=sign|encrypt|off

Sets the connection protection the client tool should use.

Note that specifying this parameter here will override the client protection parameter in the /etc/samba/smb.conf file.

In case you need more fine grained control you can use: --option=clientsmbencrypt=OPTION, --option=clientipcsigning=OPTION, --option=clientsigning=OPTION.

EXAMPLES

Search all indexed metadata attributes, exact match:

      '*=="Samba"'

Search all indexed metadata attributes, prefix match:

      '*=="Samba*"'

Search by filename:

      'kMDItemFSName=="Samba*"'

Search by date:

      'kMDItemFSContentChangeDate<$time.iso(2018-10-01T10:00:00Z)'

Search files's content:

      'kMDItemTextContent=="Samba*"'

Expressions:

      'kMDItemFSName=="Samba*"||kMDItemTextContent=="Tango*"'

SEE ALSO

File Metadata Search Programming Guide https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/SpotlightQuery/Concepts/Introduction.html

الاسم

mdsearch - البحث في بيانات التعريف للملفات

الملخص

mdsearch [خيارات] [استعلام]

الوصف

تتيح الأداة المساعدة mdsearch البحث عن الملفات بناءً على سمات بيانات التعريف الخاصة بها. تستخدم لغة استعلام Spotlight لتحديد معايير البحث.

خيارات

--use-kerberos=mode

استخدم مصادقة Kerberos. الأوضاع الممكنة هي:
never
لا تستخدم Kerberos.
ask
اسأل المستخدم عن تذكرة Kerberos.
always
استخدم Kerberos دائمًا.
سيؤدي هذا إلى فرض --use-kerberos=required.

--use-winbind-ccache

حاول استخدام ذاكرة التخزين المؤقت للاعتماد من winbind.

--client-protection=sign|encrypt|off

يحدد حماية الاتصال التي يجب أن تستخدمها أداة العميل.

لاحظ أن تحديد هذه المعلمة هنا سيتجاوز معلمة client protection في ملف /etc/samba/smb.conf.

في حال احتجت إلى تحكم أكثر دقة، يمكنك استخدام: --option=clientsmbencrypt=OPTION, --option=clientipcsigning=OPTION, --option=clientsigning=OPTION.

أمثلة

ابحث عن جميع سمات بيانات التعريف المفهرسة، مطابقة تامة:

      '*=="Samba"'

ابحث عن جميع سمات بيانات التعريف المفهرسة، مطابقة بادئة:

      '*=="Samba*"'

البحث حسب اسم الملف:

      'kMDItemFSName=="Samba*"'

البحث حسب التاريخ:

      'kMDItemFSContentChangeDate<$time.iso(2018-10-01T10:00:00Z)'

البحث في محتوى الملفات:

      'kMDItemTextContent=="Samba*"'

التعبيرات:

      'kMDItemFSName=="Samba*"||kMDItemTextContent=="Tango*"'

انظر أيضًا

دليل برمجة البحث في بيانات التعريف للملفات https://developer.apple.com/library/archive/documentation/Carbon/Conceptual/SpotlightQuery/Concepts/Introduction.html
