mdoc-update(1)

الحزمة: mono

التراخيص: GPL, LGPL2.1, MPL

NAME

mdoc-update - convert mdoc to man format

SYNOPSIS

mdoc-update [-f | -t] [-I path] [-O dir] [-S subdir] [-W width] [-w] [-C] [-d] [-e] [-h] [-i] [-m] [-n] [-p] [-s] [-v] [-V] [-x] [ file ... ]

DESCRIPTION

The mdoc-update utility converts mdoc source files to groff(7) manual page source files. It is a wrapper for the mandoc(1) utility with the -m option.

This command is typically used by the make(1) command to generate the groff(7) source files from the mdoc source files.

The default behaviour of mdoc-update is to convert the given mdoc source files to groff(7) manual page source files and write them to standard output. If the -o option is specified, the output files will be written to the specified directory.

See mandoc(1) for a complete description of the available options.

OPTIONS

The mdoc-update utility supports the following options:

-f
Force conversion even if the mdoc source files are not newer than the output files.
-t
Convert to text format instead of groff(7) manual page source format.
-I path
Add path to the list of directories to search for include files.
-O dir
Write output files to dir.
-S subdir
Write output files to subdir relative to the input files.
-W width
Set the output width to width characters. The default is 72.
-w
Use the width specified by the -W option for output.
-C
Keep comments in the output.
-d
Enable debugging output.
-e
Don't use the .ie macro.
-h
Break lines at the nearest white space.
-i
Ignore invalid characters.
-m
Use the man(7) macro set instead of the mdoc(7) macro set.
-n
Don't use the .in macro.
-p
Don't use the .sp macro.
-s
Don't use the .ss macro.
-v
Enable verbose output.
-V
Print version information and exit.
-x
Use the xroff(7) macro set instead of the mdoc(7) macro set.

SEE ALSO

mandoc(1), groff(1), man(7), mdoc(7)
