md2(3)

الحزمة: libmd

التراخيص: BSD

MD2(3) دليل وظائف المكتبة MD2(3)

الاسم

MD2Init، MD2Update، MD2Pad، MD2Final، MD2Transform، MD2End، MD2File، MD2FileChunk، MD2Data – حساب تجزئة رسالة RSA Data Security, Inc., "MD2"

المكتبة

مكتبة دعم تجزئة الرسائل (MD4, MD5, etc.) (libmd, -lmd)

ملخص

#include <sys/types.h>
#include <md2.h>

void
MD2Init(MD2_CTX *context);

void
MD2Update(MD2_CTX *context, const uint8_t *data, size_t len);

void
MD2Pad(MD2_CTX *context);

void
MD2Final(uint8_t digest[MD2_DIGEST_LENGTH], MD2_CTX *context);

void
MD2Transform(uint32_t state[4], uint8_t block[MD2_BLOCK_LENGTH]);

char *
MD2End(MD2_CTX *context, char *buf);

char *
MD2File(const char *filename, char *buf);

char *
MD2FileChunk(const char *filename, char *buf, off_t offset, off_t length);

char *
MD2Data(const uint8_t *data, size_t len, char *buf);

الوصف

تحسب وظائف MD2 مجموع تحقق تشفيري (تجزئة) بطول 128 بت لأي عدد من البايتات المدخلة. مجموع التحقق التشفيري هو دالة تجزئة أحادية الاتجاه، أي أنه لا يمكنك العثور (باستثناء البحث الشامل) على المدخل المقابل لمخرج معين. النتيجة الصافية هي "بصمة" للبيانات المدخلة، والتي لا تكشف عن المدخل الفعلي.

MD2 هو الأبطأ، MD4 هو الأسرع، و MD5 هو في مكان ما في الوسط. يمكن استخدام MD2 فقط للبريد المعزز للخصوصية (Privacy-Enhanced Mail). تم انتقاد MD4 لكونه ضعيفًا جدًا، لذلك تم تطوير MD5 استجابةً كـ "MD4 مع أحزمة أمان". تم اختراق MD4 و MD5؛ يجب استخدامهما فقط عند الضرورة للتوافق مع الإصدارات السابقة. الهجمات على كل من MD4 و MD5 هي في طبيعة إيجاد "تصادمات" - أي، مدخلات متعددة تتجزأ إلى نفس القيمة؛ لا يزال من غير المحتمل أن يتمكن المهاجم من تحديد المدخل الأصلي الدقيق بالنظر إلى قيمة التجزئة.

الوظائف MD2Init()، MD2Update()، و MD2Final() هي الوظائف الأساسية. قم بتخصيص MD2_CTX، قم بتهيئته باستخدام MD2Init()، قم بتشغيله على البيانات باستخدام MD2Update()، وأخيرًا استخرج النتيجة باستخدام MD2Final().

يمكن استخدام الوظيفة MD2Pad() لتطبيق الحشو على تجزئة الرسالة كما في MD2Final()، ولكن لا يزال يمكن استخدام السياق الحالي مع MD2Update().

تستخدم الوظيفة MD2Transform() من قبل MD2Update() لتجزئة كتل بحجم 512 بت وتشكل جوهر الخوارزمية. يجب على معظم البرامج استخدام الواجهة التي توفرها MD2Init()، MD2Update()، و MD2Final() بدلاً من استدعاء MD2Transform() مباشرة.

MD2End() هي غلاف لـ MD2Final() تقوم بتحويل القيمة المرجعة إلى سلسلة نصية ASCII بطول MD2_DIGEST_STRING_LENGTH (بما في ذلك حرف الإنهاء '\0') تمثل 128 بت بالنظام الست عشري.

MD2File() تحسب تجزئة ملف، وتستخدم MD2End() لإرجاع النتيجة. إذا تعذر فتح الملف، يتم إرجاع مؤشر فارغ (null pointer).

MD2FileChunk() تعمل مثل MD2File() ولكنها تحسب التجزئة فقط لجزء الملف الذي يبدأ عند offset ويستمر لمدة length بايت أو حتى نهاية الملف، أيهما يحدث أولاً. يمكن تحديد length صفر للقراءة حتى نهاية الملف. سيتم تجاهل length أو offset سالبة. MD2Data() تحسب تجزئة جزء من البيانات في الذاكرة، وتستخدم MD2End() لإرجاع النتيجة.

عند استخدام MD2End()، MD2File()، MD2FileChunk()، أو MD2Data()، يمكن أن يكون الوسيط buf مؤشرًا فارغًا (null pointer)، وفي هذه الحالة يتم تخصيص السلسلة النصية المرجعة باستخدام malloc(3) ويجب لاحقًا تحريرها صراحةً باستخدام free(3) بعد الاستخدام. إذا كان الوسيط buf غير فارغ، يجب أن يشير إلى مساحة تخزين لا تقل عن MD2_DIGEST_STRING_LENGTH حرف.

LIBRARY

libmd (libmd, -lmd)

SYNOPSIS

#include <sys/types.h>
#include <sys/md2.h>

void md2_init(MD2_CTX *c);

void md2_update(MD2_CTX *c, const unsigned char *data, size_t len);

void md2_final(unsigned char [MD2_DIGEST_LENGTH], MD2_CTX *c);

void md2_destroy(MD2_CTX *c);

unsigned char * MD2End(MD2_CTX *c, char *buf);

char * MD2File(const char *filename, char *digest);

char * MD2FileChunk(const char *filename, char *digest, off_t offset, size_t length);

char * MD2Data(const unsigned char *data, size_t len, char *digest);

DESCRIPTION

The MD2 algorithm is a cryptographic hash function developed by RSA Laboratories. It computes a 128-bit (16-byte) message digest from an input message of variable length. The algorithm is described in RFC 1319.

The functions md2_init(), md2_update(), and md2_final() provide a standard interface for computing message digests. First, md2_init() is called with a pointer to an MD2_CTX structure. Then, md2_update() can be called one or more times with arbitrary amounts of data. Finally, md2_final() computes the digest and stores it in the provided buffer, which must be at least MD2_DIGEST_LENGTH bytes long. The md2_destroy() function clears the context structure to prevent reuse.

The helper functions MD2End(), MD2File(), MD2FileChunk(), and MD2Data() are convenience functions for common use cases. MD2End() computes the final digest and returns it as a hexadecimal string in the provided buffer buf. MD2File() computes the MD2 digest of a file. MD2FileChunk() computes the MD2 digest of a specific chunk of a file. MD2Data() computes the MD2 digest of a memory buffer.

The digest is always returned as a 32-character hexadecimal string.

Note that MD2 is considered insecure by modern standards and should not be used for new applications. It is primarily of historical interest.

HISTORY

These functions appeared in OpenBSD 2.0 and NetBSD 1.3.

AUTHORS

The original MD2 routines were developed by RSA Data Security, Inc., and published in the above references. This code is derived from a public domain implementation written by Colin Plumb.

The MD2End(), MD2File(), MD2FileChunk(), and MD2Data() helper functions are derived from code written by Poul-Henning Kamp.

BUGS

Collisions have been found for the full versions of both MD4 and MD5. The use of sha2(3) is recommended instead.
