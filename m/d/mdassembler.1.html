mdassembler(1)

The mdassembler program can be used to construct simple and complex data representations based on a description language. This description language can also be used to define assembly languages.

It currently supports construction of:

  • Data representations based on a specification. See the ‘FORMATS’ section for more information.
  • Instruction set architectures. See the ‘FORMATS’ section for more information.

NAME

mdassembler - construct data representations based on a description language

SYNOPSIS

mdassembler [-v] [-d] [-s] [-o output-file] [-p prefix] [-f format-file] [description-file ...]

DESCRIPTION

The mdassembler program can be used to construct simple and complex data representations based on a description language. This description language can also be used to define assembly languages.

It currently supports construction of:

  • Data representations based on a specification. See the ‘FORMATS’ section for more information.
  • Instruction set architectures. See the ‘FORMATS’ section for more information.

OPTIONS

-v
Enable verbose output.
-d
Generate documentation for the description files.
-s
Generate syntax highlighting definitions for the description files.
-o output-file
Specify the output file name. If not specified, output will be written to standard output.
-p prefix
Specify a prefix for generated identifiers.
-f format-file
Specify a file containing format definitions.

FORMATS

The mdassembler description language supports the following formats:

  • data: Used to describe data structures.

    Example:

    data Point {
    x: integer;
    y: integer;
};
  • assembly: Used to describe assembly languages.

    Example:

    assembly Add {
    opcode: 0x01;
    operands: [integer, integer];
};

EXAMPLES

Assemble a simple data description: 

mdassembler -o data.bin data.desc
Assemble an assembly language description and generate documentation: 
mdassembler -d -o assembly.doc assembly.desc
