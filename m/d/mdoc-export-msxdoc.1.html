mdoc-export-msxdoc(1)

الحزمة: mono

التراخيص: GPL, LGPL2.1, MPL

mdoc-export-msxdoc(1) دليل الأوامر العامة mdoc-export-msxdoc(1)

الاسم

mdoc export-msxdoc - تحويل XML mdoc(5) إلى توثيق Microsoft XML

الملخص

mdoc export-msxdoc [خيار]* مجلدات

الوصف

ينشئ mdoc export-msxdoc توثيق Microsoft XML (كما ينتجه csc /doc) من ملفات توثيق mdoc(5) ذات التنسيق XML داخل مجلدات.

الخيارات

-o, --out=ملف
ملف XML المراد إنشاؤه.

إذا لم يتم تحديده، فسيتم استخدام مجموعة من الملفات التي تطابق قيم //AssemblyInfo/AssemblyName داخل التوثيق.

استخدم - للكتابة إلى المخرج القياسي.

-h, -?, --help
عرض رسالة مساعدة والخروج.

القوائم البريدية

قم بزيارة http://lists.ximian.com/mailman/listinfo/mono-docs-list للتفاصيل.
