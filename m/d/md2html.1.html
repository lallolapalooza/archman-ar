md2html(1)

الحزمة: md4c

التراخيص: MIT

MD2HTML(1) دليل الأوامر العامة MD2HTML(1)

الاسم

md2html - تحويل Markdown إلى HTML

الملخص

md2html [خيار]... [ملف]

الخيارات

خيارات عامة:

-o, --output=ملف_الخارج
اكتب المخرجات إلى ملف_الخارج بدلاً من stdout(3)
-f, --full-html
إنشاء مستند HTML كامل، بما في ذلك الرأس
-s, --stat
قياس وقت تحليل المدخلات
-h, --help
عرض المساعدة والخروج
-v, --version
عرض الإصدار والخروج

خيارات لهجة Markdown:

--commonmark
CommonMark (الافتراضي)
--github
Github Flavored Markdown

ملاحظة: خيارات اللهجة تعادل بعض التركيبات من الأعلام أدناه.

خيارات امتداد Markdown:

--fcollapse-whitespace
دمج المسافات البيضاء غير البديهية
--fverbatim-entities
لا تقم بترجمة الكيانات
--fpermissive-atx-headers
اسمح لعناوين ATX بدون مسافة فاصلة
--fpermissive-url-autolinks
اسمح بالروابط التلقائية للعناوين URL بدون محددات "<" و ">"
--fpermissive-www-autolinks
اسمح بالروابط التلقائية لـ WWW بدون أي مخطط (على سبيل المثال، "www.example.com")
--fpermissive-email-autolinks
اسمح بالروابط التلقائية للبريد الإلكتروني بدون "<" و ">" و "mailto:"
--fpermissive-autolinks
تمكين جميع خيارات الروابط التلقائية التسامحية الثلاثة المذكورة أعلاه
--fhard-soft-breaks
فرض أن تعمل جميع الفواصل اللينة كفواصل صلبة
--fno-indented-code
تعطيل كتل التعليمات البرمجية ذات المسافة البادئة
--fno-html-blocks
تعطيل كتل HTML الخام
--fno-html-spans
تعطيل امتدادات HTML الخام
--fno-html
نفس الأمر --fno-html-blocks --fno-html-spans
--ftables
تمكين الجداول
--fstrikethrough
تمكين امتدادات الخط المشطوب
--ftasklists
تمكين قوائم المهام
