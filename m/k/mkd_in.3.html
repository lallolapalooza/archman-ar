MARKDOWN(3) دليل وظائف المكتبة MARKDOWN(3)

الاسم

markdown — معالجة مستندات Markdown

المكتبة

Markdown (libmarkdown, -lmarkdown)

الملخص

#include <mkdio.h>

MMIOT
*mkd_in(FILE *input, int flags);

MMIOT
*mkd_string(char *string, int size, int flags);

int
markdown(MMIOT *doc, FILE *output, int flags);

الوصف

تقوم هذه الوظائف بتحويل مستندات وسلاسل Markdown إلى HTML. markdown() تعالج مستندًا كاملاً، بينما mkd_text() تعالج سلسلة واحدة.

لمعالجة ملف، قم بتمرير FILE* إلى mkd_in()، وإذا أعادت قيمة غير صفرية، قم بتمريرها إلى markdown()، والتي تكتب بعد ذلك المستند المحول إلى FILE* المحدد. إذا تمت كتابة مدخلاتك بالفعل في سلسلة (مدخلات تم إنشاؤها أو ملف تم فتحه باستخدام mmap(2)) يمكنك تغذية تلك السلسلة إلى mkd_string() وتمرير قيمتها المعادة إلى markdown.()

Markdown() تقبل القيم الراسية التالية (مجمعة معًا إذا لزم الأمر) لتقييد كيفية معالجتها للمدخلات:

MKD_NOLINKS
لا تقم بمعالجة الروابط، حظر <a> علامات.
MKD_NOIMAGE
لا تقم بمعالجة الصور، حظر <img>.
MKD_NOPANTS
لا تقم بتشغيل smartypants().
MKD_NOHTML
لا تسمح بـ HTML خام على الإطلاق
MKD_STRICT
تعطيل العلامات الفائقة والتركيز المخفف.
MKD_TAGTEXT
معالجة النص لوضعه داخل علامة HTML (ID=, NAME=, <title>, &tc)؛ لا يوجد <em>، لا يوجد <bold>، لا HTML أو [] توسيع.
MKD_NO_EXT
لا تسمح بالبروتوكولات الزائفة.
MKD_CDATA
إنشاء رمز لـ XML ![CDATA[...]].
MKD_NOSUPERSCRIPT
لا تنشئ علامات فائقة. يحدث التركيز في كل مكان
MKD_NOTABLES
منع الجداول.
MKD_NOSTRIKETHROUGH
منع ~~strikethrough~~.
MKD_TOC
قم بمعالجة جدول المحتويات.
MKD_1_COMPAT
التوافق مع MarkdownTest_1.0
MKD_AUTOLINK
اجعل http://foo.com رابطًا حتى بدون <> s.
MKD_SAFELINK
فحص مشبوه لبروتوكول الرابط.
MKD_NOHEADER
لا تقم بمعالجة كتل الرأس.
MKD_TABSTOP
توسيع علامات الجدولة إلى 4 مسافات.
MKD_NODIVQUOTE
منع >%class% كتل.
MKD_NOALPHALIST
منع القوائم الأبجدية.
MKD_NODLIST
منع قوائم التعريف.
MKD_NODLDISCOUNT
تعطيل نمط بناء جملة قائمة التعريف الخصم.
MKD_DLEXTRA
تمكين نمط بناء جملة قائمة التعريف الإضافي.
MKD_EXTRA_FOOTNOTE
تمكين علامات التذييل بأسلوب Markdown الإضافي.
MKD_NOSTYLE
لا تستخرج (تحذف) كتل <style/> من المخرجات.
MKD_FENCEDCODE
السماح بكتل التعليمات البرمجية المسورة.
MKD_IDANCHOR
استخدم معرفات= كمرتكزات بدلاً من <a name=/> لروابط جدول المحتويات.
MKD_GITHUBTAGS
السماح بالشرطة السفلية والواصلة في أسماء العناصر التي تم تمريرها.
MKD_URLENCODEDANCHOR
استخدم ترميز html5 للأحرف متعددة البايتات وغير الأبجدية الرقمية بدلاً من التوسع الست عشري في روابط جدول المحتويات.

قيم الإرجاع

markdown() تعيد 0 عند النجاح، 1 عند الفشل. الوظائف mkd_in() و mkd_string() تعيد MMIOT* عند النجاح، و null عند الفشل.

معالجة الأخطاء بسيطة في أفضل الأحوال.

NAME

mkd_in - Markdown parser library

SYNOPSIS

#include <mkdio.h>

int mkd_in(char *output, const char *input, int offset, int flags);

DESCRIPTION

The mkd_in function parses the given Markdown-formatted string input and writes the resulting HTML to the buffer output. The offset argument specifies the starting position within the input string to begin parsing. The flags argument can be used to control the parsing behavior.

RETURN VALUE

Returns the number of bytes written to the output buffer, or -1 on error.

Other formats: txt, raw

الاسم

mkd_in - مكتبة محلل Markdown

الملخص

#include <mkdio.h>

int mkd_in(char *output, const char *input, int offset, int flags);

الوصف

تقوم الدالة mkd_in بتحليل السلسلة النصية input المنسقة بـ Markdown وتكتب HTML الناتج إلى المخزن المؤقت output. يحدد الوسيط offset موضع البداية داخل السلسلة input لبدء التحليل. يمكن استخدام الوسيط flags للتحكم في سلوك التحليل.

قيمة الإرجاع

تُرجع عدد البايتات التي تمت كتابتها إلى المخزن المؤقت output، أو -1 في حالة حدوث خطأ.

تنسيقات أخرى: txt, raw
