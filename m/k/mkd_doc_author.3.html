MKD_FUNCTIONS(3) دليل وظائف المكتبة MKD_FUNCTIONS(3)

الاسم

mkd_functions — الوصول إلى مستندات Markdown ومعالجتها.

المكتبة

Markdown (libmarkdown, -lmarkdown)

الصيغة

#include <mkdio.h>

int
mkd_compile(MMIOT *document, int flags);

int
mkd_css(MMIOT *document, char **doc);

int
mkd_generatecss(MMIOT *document, FILE *output);

int
mkd_document(MMIOT *document, char **doc);

int
mkd_generatehtml(MMIOT *document, FILE *output);

int
mkd_xhtmlpage(MMIOT *document, int flags, FILE *output);

int
mkd_toc(MMIOT *document, char **doc);

void
mkd_generatetoc(MMIOT *document, FILE *output);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

الوصف

تتضمن صيغة markdown المدعومة في هذا التنفيذ كتل رأس Pandoc ذات النمط المضمن وكتل <style> المضمنة، ووظائف markdown(3) القياسية لا توفر الوصول إلى البيانات المقدمة من أي من هذين الامتدادين. تمنحك هذه الوظائف الوصول إلى هذه البيانات، بالإضافة إلى أنها توفر طريقة ذات دقة أعلى لتحويل مستندات Markdown إلى HTML.

بالمعطى MMIOT* تم إنشاؤه بواسطة mkd_in() أو mkd_string()، تقوم mkd_compile() بتجميع المستند إلى أقسام <style>، Pandoc، و html.

بعد التجميع، يمكن فحص المستند وكتابته بواسطة الوظائف mkd_css()، mkd_document()، mkd_generatecss()، mkd_generatehtml()، mkd_generatetoc()، mkd_toc()، mkd_xhtmlpage()، mkd_doc_title()، mkd_doc_author()، و mkd_doc_date().

mkd_css() تخصص سلسلة نصية وتملأها بأي أقسام <style> مقدمة في المستند، mkd_generatecss() تكتب أي أقسام <style> إلى الإخراج، mkd_document() تشير text إلى نص المستند وتعيد حجم المستند، mkd_generatehtml() تكتب باقي المستند إلى الإخراج، و mkd_doc_title()، mkd_doc_author()، mkd_doc_date() تستخدم لقراءة محتويات رأس Pandoc، إن وجد.

mkd_xhtmlpage() تكتب صفحة xhtml تحتوي على المستند. يمكن تمرير المجموعة العادية من الأعلام.

mkd_toc() تكتب مخططًا للمستند، على شكل مجموعة من القوائم المتداخلة مع روابط لكل رأس في المستند، إلى سلسلة نصية مخصصة باستخدام malloc()، وتعيد الحجم.

mkd_generatetoc() تشبه mkd_toc()، باستثناء أنها تكتب مخطط المستند إلى وسيط FILE* المعطى.

mkd_cleanup() تحذف MMIOT* بعد اكتمال المعالجة.

mkd_compile() تقبل نفس الأعلام التي تقبلها markdown() و mkd_string()؛

MKD_NOIMAGE
لا تقم بمعالجة `![]' وإزالة علامات <img> من الإخراج.
MKD_NOLINKS
لا تقم بمعالجة `[]' وإزالة علامات <a> من الإخراج.
MKD_NOPANTS
لا تقم بتشويه الاقتباسات، الواصلات، أو النقاط بالنمط Smartypants.
MKD_TAGTEXT
قم بمعالجة الإدخال كما لو كنت داخل وسم html. هذا يعني أنه لن يتم إنشاء أي وسوم html، وستحاول mkd_compile() تهريب أي شيء قد يربك متصفح الويب بشكل فظيع.
MKD_NO_EXT
لا تقم بمعالجة أي بروتوكولات وهمية لـ markdown عند التعامل مع روابط [][].
MKD_NOHEADER
لا تحاول تحليل أي رؤوس بنمط Pandoc.
MKD_TOC
قم بتسمية جميع الرؤوس لاستخدامها مع الدالة mkd_generatetoc().
MKD_1_COMPAT
علم توافق MarkdownTest_1.0؛ قم بقص المسافات اللاحقة من السطر الأول لكتل الشفرة وتعطيل روابط الإشارة الضمنية.
MKD_NOSTRIKETHROUGH
تعطيل دعم الخط المشطوب.

قيم الإرجاع

تعيد الدالة mkd_compile() القيمة 1 في حالة النجاح، أو 0 إذا تم تجميع المستند بالفعل. تعيد الدالة mkd_generatecss() عدد البايتات المكتوبة في حالة النجاح، أو EOF إذا حدث خطأ. تعيد الدالة mkd_generatehtml() القيمة 0 عند النجاح، و -1 عند الفشل.
