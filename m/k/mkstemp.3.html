NAME

mkstemp - create a uniquely named temporary file

SYNOPSIS

#include <stdlib.h>

int mkstemp(char *template);

DESCRIPTION

The mkstemp() function generates a unique file name based on the given template and creates and opens a file with that name. The last six characters of template must be XXXXXX; these are replaced by characters from a unique file name. The file is created with the permissions specified by the 0600 mode (read and write for the owner only).

The file is created using the open() system call with the flags O_RDWR and O_CREAT. The file mode is set to 0600.

If mkstemp() successfully creates a file, the function replaces the trailing XXXXXX in the template string with the characters that form the unique file name. The function then returns the file descriptor of the newly created file, opened for reading and writing.

If mkstemp() fails to create a file, the contents of the template string are undefined. The function returns -1 and sets errno to indicate the error.

RETURN VALUE

On success, mkstemp() returns a file descriptor for the opened temporary file. On failure, it returns -1 and sets errno.

ERRORS

The following errors can occur:

  • EEXIST: A file with the generated name already exists.
  • EINVAL: The template string does not end with six XXXXXX.
  • EMFILE: Too many file descriptors are open.
  • ENFILE: Too many files are open in the system.
  • ENOENT: The directory specified in template does not exist.
  • ENOSPC: The directory where the file is to be created does not contain enough free space.
  • ENOTDIR: A component of the template path prefix is not a directory.
  • EROFS: The file system is mounted read-only.

EXAMPLES

The following example creates a temporary file in the current directory:

#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>

int main() {
    char template[] = "/tmp/myapp-XXXXXX";
    int fd;

    fd = mkstemp(template);
    if (fd == -1) {
        perror("mkstemp");
        exit(EXIT_FAILURE);
    }

    printf("Temporary file created: %s\n", template);

    // Use the temporary file (e.g., write to it)
    if (dprintf(fd, "Hello, temporary file!\n") == -1) {
        perror("dprintf");
        close(fd);
        unlink(template);
        exit(EXIT_FAILURE);
    }

    // Close the file descriptor
    close(fd);

    // Optionally, remove the temporary file when done
    // unlink(template);

    return 0;
}

CONFORMING TO

POSIX.1-2001, POSIX.1-2008.
