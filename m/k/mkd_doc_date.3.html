mkd_doc_date(3)

الحزمة: discount

التراخيص: BSD-3-Clause

MKD_FUNCTIONS(3) دليل وظائف المكتبة MKD_FUNCTIONS(3)

الاسم

mkd_functions — الوصول إلى مستندات Markdown ومعالجتها.

المكتبة

Markdown (libmarkdown, -lmarkdown)

الملخص

#include <mkdio.h>

int
mkd_generatehtml(MMIOT *document, FILE *output);

int
mkd_xhtmlpage(MMIOT *document, int flags, FILE *output);

int
mkd_toc(MMIOT *document, char **doc);

void
mkd_generatetoc(MMIOT *document, FILE *output);

mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

الوصف

يتضمن تنسيق markdown المدعوم في هذا التنفيذ كتل نمط Pandoc للتنسيق المضمن، وكتل <style> المضمنة القياسية. وظائف markdown(3) القياسية لا توفر الوصول إلى البيانات المقدمة من أي من هذين الامتدادين. تمنحك هذه الوظائف الوصول إلى تلك البيانات، بالإضافة إلى أنها توفر طريقة أكثر دقة لتحويل مستندات Markdown إلى HTML.

بالنظر إلى MMIOT* تم إنشاؤه بواسطة mkd_in() أو mkd_string()، تقوم mkd_compile() بتجميع المستند إلى أقسام <style>، و Pandoc، و html.

بمجرد التجميع، يمكن فحص المستند وكتابته بواسطة وظائف mkd_css()، mkd_document()، mkd_generatecss()، mkd_generatehtml()، mkd_generatetoc()، mkd_toc()، mkd_xhtmlpage()، mkd_doc_title()، mkd_doc_author()، و mkd_doc_date().

mkd_css() تخصص سلسلة نصية وتملؤها بأي أقسام <style> متوفرة في المستند، mkd_generatecss() تكتب أي أقسام <style> إلى المخرجات، mkd_document() تشير text إلى نص المستند وتعيد حجم المستند، mkd_generatehtml() تكتب باقي المستند إلى المخرجات، و mkd_doc_title()، mkd_doc_author()، mkd_doc_date() تستخدم لقراءة محتويات رأس Pandoc، إن وجدت.

mkd_xhtmlpage() تكتب صفحة xhtml تحتوي على المستند. يمكن تمرير مجموعة العلامات العادية.

mkd_toc() تكتب مخططًا للمستند، في شكل مجموعة من القوائم المتداخلة مع روابط لكل عنوان في المستند، في سلسلة نصية مخصصة بواسطة malloc()، وتعيد الحجم.

mkd_generatetoc() تشبه mkd_toc()، باستثناء أنها تكتب مخطط المستند إلى وسيط FILE* المحدد.

mkd_cleanup() تحذف MMIOT* بعد الانتهاء من المعالجة.

mkd_compile() تقبل نفس العلامات التي تفعلها markdown() و mkd_string();

MKD_NOIMAGE
لا تعالج `![]' وقم بإزالة وسوم <img> من المخرجات.
MKD_NOLINKS
لا تعالج `[]' وقم بإزالة وسوم <a> من المخرجات.
MKD_NOPANTS
لا تقم بتعديل علامات الاقتباس، الشرطات، أو النقاط بطريقة Smartypants.
MKD_TAGTEXT
عالج المدخلات كما لو كنت داخل وسم html. هذا يعني أنه لن يتم إنشاء أي وسوم html، وستحاول mkd_compile() استبدال أي شيء قد يربك متصفح الويب بشدة.
MKD_NO_EXT
لا تعالج أي بروتوكولات زائفة لـ markdown عند التعامل مع روابط [][].
MKD_NOHEADER
لا تحاول تحليل أي رؤوس بنمط Pandoc.
MKD_TOC
قم بتسمية جميع الرؤوس للاستخدام مع وظيفة mkd_generatetoc().
MKD_1_COMPAT
علامة توافق MarkdownTest_1.0؛ قم بقص المسافات اللاحقة من السطر الأول لكتل الرموز وقم بتعطيل روابط المراجع الضمنية.
MKD_NOSTRIKETHROUGH
تعطيل دعم الخط الشطب.

قيم الإرجاع

تعيد الوظيفة mkd_compile() القيمة 1 في حالة النجاح، أو 0 إذا تم تجميع المستند بالفعل. تعيد الوظيفة mkd_generatecss() عدد البايتات المكتوبة في حالة النجاح، أو EOF إذا حدث خطأ. تعيد الوظيفة mkd_generatehtml() القيمة 0 عند النجاح، و -1 عند الفشل.
