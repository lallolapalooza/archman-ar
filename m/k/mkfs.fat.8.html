الحزمة: dosfstools

NAME

mkfs.fat

create an MS-DOS filesystem (FAT)

SYNOPSIS

mkfs.fat [options] [-n VOLUME-NAME] DEVICE [SIZE]

DESCRIPTION

mkfs.fat is used to create an MS-DOS filesystem (also known as FAT or FAT file system) on a previously created partition or empty device. The DEVICE is typically a hard disk partition (e.g. /dev/sda1) or a floppy disk (e.g. /dev/fd0).

A FAT filesystem stores metadata like volume label, filesystem type and total size in the boot sector of the filesystem. This information is used by DOS and Windows operating systems.

A filesystem can be created on a whole device or on a partition within a device. In the latter case, the partition table is usually located within the first sector of the device. The MBR partition table is placed on the device such that the partition table overlaps with the end of the first FAT sector (boot code location), therefore there is no additional space usage. Default is auto mode in which mkfs.fat put MBR table only for non-removable disks when formatting whole unpartitioned disk.

OPTIONS

-a
Align the filesystem structures (FAT table, root directory) to the cluster boundaries. This is good for performance on some types of media, and it's required for some devices (e.g. some USB storage devices).
-b BOOTSECTOR
Use the specified BOOTSECTOR file instead of the default one. This file must be exactly 512 bytes long.
-C
Create a FAT filesystem on the device, but don't put it on the first partition. Instead, put it on the whole device and add an MBR partition table. This option is mainly for creating bootable floppy disk images.
-f NUMBER-OF-FREESPACE-ENTRIES
Sets the number of free space entries in the FAT table. The default is 16 (or 224 for FAT32). The value must be a power of 2. Maximum is 224.
-F FAT-SIZE
Use the specified FAT size. Possible values are 12, 16, and 32. If not specified, mkfs.fat chooses the smallest possible FAT size for the filesystem.
-i VOLUME-ID
Use the specified 32-bit hexadecimal number as the volume ID. By default, a random number is generated.
-k
Use FAT12 for the filesystem. This is useful for creating bootable floppy disk images.
-m BACKUP-BOOT-SECTOR
Use the specified BACKUP-BOOT-SECTOR file instead of the default one. This file must be exactly 512 bytes long.
-n VOLUME-NAME
Sets the volume name (label) of the filesystem. The volume name can be up to 11 characters long. Supplying an empty string, a string consisting only of white space or the string "NO NAME" as VOLUME-NAME has the same effect as not giving the -n option. The default is no label.
--codepage=PAGE
Use DOS codepage PAGE to encode label. By default codepage 850 is used.
-r ROOT-DIR-ENTRIES
Select the minimal number of entries available in the root directory. The default is 112 or 224 for floppies and 512 for hard disks. Note that this is minimal number and it may be increased by mkfs.fat due to alignment of structures. See also mkfs.fat option -a.
-R NUMBER-OF-RESERVED-SECTORS
Select the minimal number of reserved sectors. With FAT32 format at least 2 reserved sectors are needed, the default is 32. Otherwise the default is 1 (only the boot sector). Note that this is minimal number and it may be increased by mkfs.fat due to alignment of structures. See also mkfs.fat option -a.
-s SECTORS-PER-CLUSTER
Specify the number of disk sectors per cluster. Must be a power of 2, i.e. 1, 2, 4, 8, ... 128.
-S LOGICAL-SECTOR-SIZE
Specify the number of bytes per logical sector. Must be a power of 2 and greater than or equal to 512, i.e. 512, 1024, 2048, 4096, 8192, 16384, or 32768. Values larger than 4096 are not conforming to the FAT file system specification and may not work everywhere.
-v
Verbose execution.
--offset SECTOR
Write the filesystem at a specific sector into the device file. This is useful for creating a filesystem in a partitioned disk image without having to set up a loop device.
--variant TYPE
Create a filesystem of variant TYPE. Acceptable values are standard and atari (in any combination of upper/lower case). See above under DESCRIPTION for the differences.
--help
Display option summary and exit.
--invariant
Use constants for normally randomly generated or time based data such as volume ID and creation time. Multiple runs of mkfs.fat on the same device create identical results with this option. Its main purpose is testing mkfs.fat.

BUGS

mkfs.fat can not create boot-able filesystems. This isn't as easy as you might think at first glance for various reasons and has been discussed a lot already. mkfs.fat simply will not support it ;)
