الاسم

mkd_functions — الوصول إلى مستندات Markdown ومعالجتها.

المكتبة

Markdown (libmarkdown, -lmarkdown)

الملخص

#include <mkdio.h>

int
mkd_compile(MMIOT *document, int flags);

int
mkd_css(MMIOT *document, char **doc);

int
mkd_generatecss(MMIOT *document, FILE *output);

int
mkd_document(MMIOT *document, char **doc);

int
mkd_generatehtml(MMIOT *document, FILE *output);

int
mkd_xhtmlpage(MMIOT *document, int flags, FILE *output);

int
mkd_toc(MMIOT *document, char **doc);

void
mkd_generatetoc(MMIOT *document, FILE *output);

void
mkd_cleanup(MMIOT*);

char*
mkd_doc_title(MMIOT*);

char*
mkd_doc_author(MMIOT*);

char*
mkd_doc_date(MMIOT*);

الوصف

يشتمل تنسيق markdown المدعوم في هذا التنفيذ على كتل <style> النمطية من Pandoc والمضمنة، ووظائف markdown(3) القياسية لا توفر الوصول إلى البيانات المقدمة من أي من هذين الامتدادين. تمنحك هذه الوظائف الوصول إلى هذه البيانات، بالإضافة إلى أنها توفر طريقة أكثر تفصيلاً لتحويل مستندات Markdown إلى HTML.

بالنظر إلى MMIOT* تم إنشاؤه بواسطة mkd_in() أو mkd_string() ، يقوم mkd_compile() بتجميع المستند إلى أقسام <style> و Pandoc و html.

بمجرد تجميعها، يمكن فحص المستند وكتابته بواسطة وظائف mkd_css() و mkd_document() و mkd_generatecss() و mkd_generatehtml() و mkd_generatetoc() و mkd_toc() و mkd_xhtmlpage() و mkd_doc_title() و mkd_doc_author() و mkd_doc_date().

mkd_css() تخصص سلسلة نصية وتملأها بأي أقسام <style> متوفرة في المستند، mkd_generatecss() تكتب أي أقسام <style> إلى الإخراج، mkd_document() تشير text إلى نص المستند وتعيد حجم المستند، mkd_generatehtml() تكتب بقية المستند إلى الإخراج، و mkd_doc_title() و mkd_doc_author() و mkd_doc_date() تستخدم لقراءة محتويات رأس Pandoc، إن وجدت.

mkd_xhtmlpage() تكتب صفحة xhtml تحتوي على المستند. يمكن تمرير مجموعة الأعلام العادية.

mkd_toc() تكتب مخططًا للمستند، في شكل مجموعة من القوائم المتداخلة مع روابط لكل رأس في المستند، إلى سلسلة نصية تم تخصيصها باستخدام malloc()، وتعيد الحجم.

mkd_generatetoc() تشبه mkd_toc()، باستثناء أنها تكتب مخطط المستند إلى وسيط FILE* المحدد.

mkd_cleanup() تحذف MMIOT* بعد الانتهاء من المعالجة.

mkd_compile() تقبل نفس الأعلام التي تقبلها markdown() و mkd_string()؛

MKD_NOIMAGE
لا تعالج `![]' وتحذف علامات <img> من الإخراج.
MKD_NOLINKS
لا تعالج `[]' وتحذف علامات <a> من الإخراج.
MKD_NOPANTS
لا تقم بتشويه علامات الاقتباس أو الشرطات أو النقاط بأسلوب Smartypants.
MKD_TAGTEXT
عالج المدخلات كما لو كنت داخل علامة html. هذا يعني أنه لن يتم إنشاء أي علامات html، وسيحاول mkd_compile() تجاوز أي شيء قد يربك متصفح الويب بشدة.
MKD_NO_EXT
لا تعالج أي بروتوكولات زائفة لـ markdown عند التعامل مع روابط [][].
MKD_NOHEADER
لا تحاول تحليل أي رؤوس بأسلوب Pandoc.
MKD_TOC
قم بتسمية جميع الرؤوس لاستخدامها مع الوظيفة mkd_generatetoc().
MKD_1_COMPAT
علم التوافق مع MarkdownTest_1.0؛ قم بإزالة المسافات اللاحقة من السطر الأول من كتل التعليمات البرمجية وتعطيل الروابط المرجعية الضمنية.
MKD_NOSTRIKETHROUGH
تعطيل دعم الشطب.

قيم الإرجاع

تعيد الوظيفة mkd_compile() القيمة 1 في حالة النجاح، أو 0 إذا كان المستند مجمعًا بالفعل. تعيد الوظيفة mkd_generatecss() عدد البايتات المكتوبة في حالة النجاح، أو EOF إذا حدث خطأ. تعيد الوظيفة mkd_generatehtml() القيمة 0 عند النجاح، -1 عند الفشل.
