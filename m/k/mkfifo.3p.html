NAME

mkfifo, mkfifoat — create FIFOs (named pipes)

SYNOPSIS

#include <sys/stat.h>

int mkfifo(const char *pathname, mode_t mode);
int mkfifoat(int dirfd, const char *pathname, mode_t mode);

DESCRIPTION

The mkfifo() function creates a new FIFO special file with the name pointed to by pathname, and with the access permissions specified by mode. The FIFO is created with protection bits set to mode & ~ (umask | ~umask), where ~umask are the bits of the process's umask. See umask(2).

The mkfifoat() function is equivalent to mkfifo() except that the FIFO is created relative to the directory referred to by the file descriptor dirfd. If pathname is an absolute path, then dirfd is ignored.

If dirfd is AT_FDCWD, the FIFO is created relative to the current working directory.

mkfifoat() allows the calling process to create a FIFO in a directory other than the current working directory without obtaining a directory change of ownership or permissions.

The mode argument specifies the file mode for the new FIFO. It is the bitwise OR of:

  • S_IFIFO (already set by the system)
  • S_IRUSR, S_IWUSR, S_IRGRP, S_IWGRP, S_IROTH, S_IWOTH
(read and write permissions for owner, group, and others).

The FIFO's owner ID is set to the effective user ID of the calling process. The FIFO's group ID is set to the effective group ID of the calling process.

RETURN VALUE

On success, mkfifo() and mkfifoat() return 0. On failure, they return -1, and errno is set to indicate the error.

ERRORS

The permissions of the directory in which the FIFO is to be created must allow writing.

EACCES
Search permission denied for a component of the path prefix, or write permission denied for the directory in which the FIFO file is to be created.
EEXIST
The file specified by pathname already exists.
EINTR
A signal was caught during the system call.
EINVAL
mkfifoat(): dirfd is not a valid file descriptor.
EISDIR
The file specified by pathname is a directory.
ELOOP
Too many symbolic links encountered while processing pathname.
EMLINK
The directory in which the FIFO is to be created has the maximum number of links to it already.
ENAMETOOLONG
pathname is too long.
ENOENT
pathname does not exist and dirfd is AT_FDCWD, or a component of pathname is a dangling symbolic link, or dirfd is a file descriptor referring to a file other than a directory, or pathname is not an absolute path and dirfd is AT_REMOVEDIR.
ENOSPC
The directory in which the FIFO is to be created has no room for the new file.
ENOTDIR
pathname's a component prefix is not a directory, or dirfd refers to a file other than a directory.
EROFS
The FIFO cannot be created because the file system is mounted read-only.
ENOSYS
mkfifoat() is not implemented.

EXAMPLES

Create a FIFO named myfifo with read and write permissions for the owner:

int mkfifo(const char *pathname, mode_t mode);

mode_t mode = S_IRUSR | S_IWUSR;
if (mkfifo("myfifo", mode) == -1 && errno != EEXIST) {
    perror("mkfifo");
    exit(EXIT_FAILURE);
}

Create a FIFO named myfifo relative to a directory referred to by file descriptor dirfd:

int dirfd; // Assume dirfd is already opened and points to a directory
mode_t mode = S_IRUSR | S_IWUSR;
if (mkfifoat(dirfd, "myfifo", mode) == -1 && errno != EEXIST) {
    perror("mkfifoat");
    exit(EXIT_FAILURE);
}

APPLICATION USAGE

The mkfifoat() function is useful in the following situations:

  • When a process needs to create a FIFO in a directory whose path is not known, but a file descriptor for the directory is available.
  • When a process wants to create a FIFO without opening the directory, and without race conditions.

RATIONALE

The mkfifo() function creates a FIFO special file. FIFOs are similar to pipes, but they exist in the file system by name. They are useful for interprocess communication between unrelated processes.

The mkfifoat() function was added to allow the creation of FIFOs in directories other than the current working directory. This is useful for security reasons, as it allows a process to create a FIFO in a directory without needing to change its current working directory. It also allows for atomic creation of FIFOs in directories that may not be accessible via relative paths.

The mkfifoat() function takes a file descriptor for the target directory and using the mkfifoat() function it can be guaranteed that the newly created FIFO is located relative to the desired directory.
