s meaning the last day of the preceding month.

According to POSIX.1, localtime() is required to behave as though tzset(3) was called, while localtime_r() does not have this requirement. For portable code, tzset(3) should be called before localtime_r().

تنبيهات

سلامة الخيوط

The four functions asctime(), ctime(), gmtime(), and localtime() return a pointer to static data and hence are not thread-safe. The thread-safe versions, asctime_r(), ctime_r(), gmtime_r(), and localtime_r(), are specified by SUSv2.

POSIX.1 says: "The asctime(), ctime(), gmtime(), and localtime() functions shall return values in one of two static objects: a broken-down time structure and an array of type char. Execution of any of the functions that return a pointer to one of these object types may overwrite the information in any object of the same type pointed to by the value returned from any previous call to any of them." This can occur in the glibc implementation.

mktime()

(time_t) -1 can represent a valid time (one second before the Epoch). To determine whether mktime() failed, one must use the tm->tm_wday field. See the example program in EXAMPLES.

The handling of a non-negative tm_isdst in mktime() is poorly specified, and passing a value that is incorrect for the time specified yields unspecified results. Since mktime() is one of the few functions that knows when DST is in effect, providing a correct value may be difficult. One workaround for this is to call mktime() twice, once with tm_isdst set to zero, and once with tm_isdst set to a positive value, and discarding the results from the call that changes it. If neither call changes tm_isdst then the time specified probably happens during a fall-back period where DST begins or ends, and both results are valid but represent two different times. If both calls change it, that could indicate a fall-forward transition, or some other reason why the time specified does not exist.

The specification of time zones and daylight saving time are up to regional governments, change often, and may include discontinuities beyond mktime's ability to document a result. For example, a change in the timezone definition may cause a clock time to be repeated or skipped without a corresponding DST change.

#include <err.h>
#include <errno.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <time.h>
#define is_signed(T)  ((T) -1 < 1)
static time_t my_mktime(struct tm *tp);
int
main(int argc, char *argv[])
{
    char       **p;
    time_t     t;
    struct tm  tm;
    if (argc != 8) {
        fprintf(stderr, "Usage: %s yyyy mm dd HH MM SS isdst\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    p = &argv[1];
    tm.tm_year  = atoi(*p++) - 1900;
    tm.tm_mon   = atoi(*p++) - 1;
    tm.tm_mday  = atoi(*p++);
    tm.tm_hour  = atoi(*p++);
    tm.tm_min   = atoi(*p++);
    tm.tm_sec   = atoi(*p++);
    tm.tm_isdst = atoi(*p++);
    errno = 0;
    tm.tm_wday = -1;
    t = my_mktime(&tm);
    if (tm.tm_wday == -1)
        err(EXIT_FAILURE, "mktime");
    if (errno == EINVAL || errno == ENOTUNIQ)
        warn("my_mktime");
    if (is_signed(time_t))
        printf("%jd\n", (intmax_t) t);
    else
        printf("%ju\n", (uintmax_t) t);
    exit(EXIT_SUCCESS);
}
static time_t
my_mktime(struct tm *tp)
{
    int            e, isdst;
    time_t         t;
    struct tm      tm;
    unsigned char  wday[sizeof(tp->tm_wday)];
    e = errno;
    tm = *tp;
    isdst = tp->tm_isdst;
    memcpy(wday, &tp->tm_wday, sizeof(wday));
    tp->tm_wday = -1;
    t = mktime(tp);
    if (tp->tm_wday == -1) {
        memcpy(&tp->tm_wday, wday, sizeof(wday));
        return -1;
    }
    if (isdst == -1)
        tm.tm_isdst = tp->tm_isdst;
    if (   tm.tm_sec   != tp->tm_sec
        || tm.tm_min   != tp->tm_min
        || tm.tm_hour  != tp->tm_hour
        || tm.tm_mday  != tp->tm_mday
        || tm.tm_mon   != tp->tm_mon
        || tm.tm_year  != tp->tm_year
        || tm.tm_isdst != tp->tm_isdst)
    {
        errno = EINVAL;
        return t;
    }
    if (isdst != -1)
        goto out;
    tm = *tp;
    tm.tm_isdst = !tm.tm_isdst;
    tm.tm_wday = -1;
    mktime(&tm);
    if (tm.tm_wday == -1)
        goto out;
    if (tm.tm_isdst != tp->tm_isdst) {
        errno = ENOTUNIQ;
        return t;
    }
out:
    errno = e;
    return t;
}

    mktime(3)

    mktime - convert a tm structure to a time_t value

    NAME

    mktime - convert a tm structure to a time_t value

    LIBRARY

    Standard C Library (libc, -lc)

    SYNOPSIS

    #include <time.h>

time_t mktime(struct tm *timeptr);

    DESCRIPTION

    The mktime() function converts the broken-down time expressed by the struct tm *timeptr into a time_t value, which represents seconds since the Epoch (00:00:00 UTC, January 1, 1970).

    The original values of the tm_sec, tm_min, tm_hour, tm_mday, tm_mon, tm_year, and tm_isdst members of the structure pointed to by timeptr are used to represent the time.

    If the structure pointed to by timeptr represents a date and time that is valid, mktime() returns the corresponding time_t value.

    If the structure pointed to by timeptr represents a date and time that is not valid, mktime() attempts to correct it. For example, if tm_mday is 35, mktime() will adjust the month and day accordingly.

    The mktime() function also fills in the fields of the structure pointed to by timeptr that have not been explicitly set by the caller. Specifically, it fills in the tm_wday and tm_yday fields.

    The tm_isdst field is used to indicate whether DST is in effect. If tm_isdst is positive, DST is in effect. If tm_isdist is 0, DST is not in effect. If tm_isdst is negative, the function will determine whether DST is in effect.

    RETURN VALUE

    If the input structure is valid, mktime() returns the corresponding time_t value. If the input structure cannot be represented as a time_t value, mktime() returns (time_t)−1 and sets errno to indicate the error.

    ERRORS

    The following error codes may be set for errno:

    • EINVAL: The input structure cannot be represented as a time_t value.

    STANDARDS

    The mktime() function conforms to the IEEE Std 1003.1-2001 standard.

    HISTORY

    The mktime() function first appeared in the AT&T UNIX System V.

    CAVEATS

    The mktime() function is not thread-safe because it uses static internal data. If you need a thread-safe version, use mktime64() or localtime_r() and gmtime_r().

    EXAMPLES

    #include <stdio.h>
#include <time.h>

int main() {
    struct tm t;
    time_t now;

    // Get the current time
    now = time(NULL);

    // Convert time_t to struct tm
    localtime_r(&now, &t);

    // Print the broken-down time
    printf("Current time: %s", asctime(&t));

    // Adjust the time by adding one day
    t.tm_mday += 1;

    // Convert the adjusted struct tm back to time_t
    now = mktime(&t);

    // Print the new time
    printf("One day later: %s", asctime(&t));

    return 0;
}
