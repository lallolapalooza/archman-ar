mkd_generateline(3)

الحزمة: discount

التراخيص: BSD-3-Clause

MKD_LINE(3) دليل وظائف المكتبة MKD_LINE(3)

الاسم

mkd_line — ترجمة Markdown للعناصر الصغيرة

المكتبة

Markdown (libmarkdown, -lmarkdown)

الملخص

#include <mkdio.h>

int
mkd_line(char *string, int size, char **doc, int flags);

int
mkd_generateline(char *string, int size, FILE *output, int flags);

الوصف

في بعض الأحيان قد ترغب في إجراء ترجمات Markdown على أجزاء من البيانات، مثل عنوان مقالة مدونة، أو تاريخ، أو سطر توقيع بسيط. تتيح لك mkd_line و mkd_generateline إجراء ترجمات Markdown على كتل نصية صغيرة. تقوم mkd_line بتخصيص مخزن مؤقت، ثم تكتب النص المترجم في هذا المخزن المؤقت، وتكتب mkd_generateline الإخراج إلى FILE* المحدد.

انظر أيضاً

markdown(1)، markdown(3)، markdown(7)، mkd-extensions(7)، mmap(2).

http://daringfireball.net/projects/markdown/syntax
