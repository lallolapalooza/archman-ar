mknmz(1)

الحزمة: namazu

التراخيص: GPL

MKNMZ(1) مشروع Namazu MKNMZ(1)

الاسم

mknmz - فهرسة Namazu

الملخص

mknmz [خيارات] <هدف>...

الوصف

mknmz 2.0.21، مفهرس Namazu.

ملفات الهدف:

-a, --all
استهداف جميع الملفات.
-t, --media-type=MTYPE
تعيين نوع الوسائط لجميع ملفات الهدف إلى MTYPE.
-h, --mailnews
نفس الأمر --media-type='message/rfc822'
--mhonarc
نفس الأمر --media-type='text/html; x-type=mhonarc'
-F, --target-list=FILE
تحميل FILE الذي يحتوي على قائمة بملفات الهدف.
--allow=PATTERN
تعيين PATTERN لأسماء الملفات التي يجب السماح بها.
--deny=PATTERN
تعيين PATTERN لأسماء الملفات التي يجب منعها.
--exclude=PATTERN
تعيين PATTERN لمسارات الملفات التي يجب استبعادها.
-e, --robots
استبعاد ملفات HTML التي تحتوي على <meta name="ROBOTS" content="NOINDEX">
-M, --meta
معالجة علامات HTML meta للبحث المحدد بالحقل.
-r, --replace=CODE
تعيين CODE لاستبدال URI.
--html-split
تقسيم ملف HTML باستخدام علامات الربط <a name="...">.
--mtime=NUM
تحديد حسب وقت التعديل (mtime) بنفس طريقة الخيار -mtime في find(1). على سبيل المثال، -50 للأيام الـ 50 الأخيرة، +50 للأقدم من 50.

التحليل المورفولوجي:

-b, --use-mecab
استخدام MeCab لتحليل اللغة اليابانية.
-c, --use-chasen
استخدام ChaSen لتحليل اللغة اليابانية.
-k, --use-kakasi
استخدام KAKASI لتحليل اللغة اليابانية.
-m, --use-chasen-noun
استخدام ChaSen لاستخراج الأسماء فقط.

-L, --indexing-lang=LANG الفهرسة باستخدام معالجة خاصة باللغة.

عمليات النص:

-E, --no-edge-symbol
إزالة الرموز على حافة الكلمة.
-G, --no-okurigana
إزالة Okurigana في الكلمة.
-H, --no-hiragana
تجاهل الكلمات التي تتكون من هيراغانا فقط.
-K, --no-symbol
إزالة الرموز.
--decode-base64
فك تشفير أجزاء base64 داخل الكيانات متعددة الأجزاء.

التلخيص:

-U, --no-encode-uri
لا تقم بتشفير URI.

-x, --no-heading-summary لا تقم بإنشاء ملخص باستخدام عناوين HTML.

بناء الفهرس:

--update=INDEX
تعيين INDEX للتحديث.
-z, --check-filesize
الكشف عن تغيير حجم الملف.
-Y, --no-delete
لا تقم بالكشف عن المستندات المحذوفة.
-Z, --no-update
لا تقم بالكشف عن المستندات المحدثة والمحذوفة.

متفرقات:

-s, --checkpoint
تشغيل آلية نقطة التحقق.
-C, --show-config
عرض التكوين الحالي.
-f, --config=FILE
استخدام FILE كملف تكوين.
-I, --include=FILE
تضمين ملف التخصيص الخاص بك.
-O, --output-dir=DIR
تعيين DIR لإخراج الفهرس.
-T, --template-dir=DIR
تعيين DIR الذي يحتوي على NMZ.{head,foot,body}.*.
-q, --quiet
كتم رسائل الحالة أثناء التنفيذ.
-v, --version
عرض إصدار namazu والخروج.
-V, --verbose
كن مطولاً.
-d, --debug
كن في وضع التصحيح.
--help
عرض هذا المساعدة والخروج.
--norc
لا تقرأ ملفات التهيئة الشخصية.
--
إنهاء قائمة الخيارات.
