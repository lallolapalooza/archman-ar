The reason for this switch is that it is technically impossible to automatically tell normal AAC data from SBR AAC data without decoding a complete AAC frame. If the source file is a Matroska(TM) file then the CodecID should be enough to detect SBR AAC. However, if the CodecID is wrong then this switch can be used to correct that.

Windows

في نظام التشغيل Windows، يتم تحديد مجموعة الأحرف الافتراضية المستخدمة لتحويل الملفات النصية عن طريق استدعاء استدعاء النظام GetACP().

يتم قراءة سطر الأوامر باستخدام الدالة GetCommandLineW() التي تُرجع بالفعل سلسلة Unicode. لذلك، يتم تجاهل الخيار --command-line-charset في نظام التشغيل Windows.

يتكون الإخراج إلى وحدة التحكم من ثلاثة سيناريوهات:

1. إذا تم إعادة توجيه الإخراج باستخدام الخيار --redirect-output، فإن مجموعة الأحرف الافتراضية هي UTF-8. يمكن تغيير ذلك باستخدام --output-charset.
2. إذا تم إعادة توجيه الإخراج باستخدام cmd.exe نفسه، على سبيل المثال، باستخدام mkvinfo file.mkv > info.txt، فإن مجموعة الأحرف تكون دائمًا UTF-8 ولا يمكن تغييرها.
3. بخلاف ذلك (عند الكتابة مباشرة إلى وحدة التحكم) يتم استخدام دالة Windows WriteConsoleW() ويتم تجاهل الخيار --output-charset. يجب أن تكون وحدة التحكم قادرة على إخراج جميع أحرف Unicode التي يتم تثبيت دعم اللغة المقابل لها (على سبيل المثال، قد لا يتم عرض الأحرف الصينية على إصدارات Windows الإنجليزية).

خيارات سطر الأوامر

الخيارات التالية متاحة تسمح بتحديد مجموعات الأحرف:

•--sub-charset لملفات الترجمة النصية ومسارات الترجمة النصية المخزنة في تنسيقات الحاويات التي لا يمكن تحديد مجموعة الأحرف لها بشكل لا لبس فيه (مثل ملفات Ogg)،
•--chapter-charset لملفات نصوص الفصول والفصول وعناوين الملفات المخزنة في تنسيقات الحاويات التي لا يمكن تحديد مجموعة الأحرف لها بشكل لا لبس فيه (مثل ملفات Ogg لمعلومات الفصول، وعناوين المسارات والملفات وما إلى ذلك؛ وملفات MP4 لمعلومات الفصول)،
•--command-line-charset لجميع السلاسل النصية في سطر الأوامر،
•--output-charset لجميع السلاسل النصية المكتوبة إلى وحدة التحكم أو إلى ملف إذا تم إعادة توجيه الإخراج باستخدام الخيار --redirect-output. في الأنظمة غير التابعة لنظام Windows، تكون القيمة الافتراضية لمجموعة أحرف الإخراج هي مجموعة الأحرف الحالية للنظام. في نظام Windows، تكون القيمة الافتراضية هي UTF-8 لكل من إعادة التوجيه باستخدام --redirect-output وباستخدام cmd.exe نفسه، على سبيل المثال، mkvinfo file.mkv > info.txt.

ملفات الخيارات

ملف الخيارات هو ملف يمكن لـ mkvmerge(1) قراءة وسائط سطر الأوامر الإضافية منه. يمكن استخدام هذا لتجاوز قيود معينة في shell أو نظام التشغيل عند تنفيذ برامج خارجية مثل طول سطر الأوامر المحدود.

يحتوي ملف الخيارات على بيانات بتنسيق JSON. يجب أن يكون محتواه مصفوفة JSON صالحة تتكون فقط من سلاسل JSON. يجب أن تكون ترميز الملف UTF-8. يجب ألا يبدأ الملف بـ byte order marker (BOM)، ولكن إذا كان موجودًا، فسيتم تخطيه.

قواعد الهروب من الأحرف الخاصة داخل JSON هي تلك الموجودة في مواصفات JSON الرسمية، RFC 7159[4].

يجب تحديد اسم ملف الخيارات نفسه كوسيط سطر أوامر مسبوقًا بحرف '@'.

يمكن تحويل سطر الأوامر 'mkvmerge -o "my file.mkv" -A "a movie.avi" sound.ogg' إلى ملف خيارات JSON التالي المسمى، على سبيل المثال، 'options.json':

[
  "-o",
  "c:\\Matroska\\my file.mkv",
  "--title",
  "#65",
  "-A",
  "a movie.avi",
  "sound.ogg"
]

سيكون الأمر المقابل بعد ذلك 'mkvmerge @options.json'.

ربط الملفات

يدعم Matroska(TM) ربط الملفات الذي يشير ببساطة إلى أن ملفًا معينًا هو السلف أو الخلف الحالي. لتكون دقيقًا، لا يتم ربط الملفات حقًا ولكن مقاطع Matroska(TM). نظرًا لأن معظم الملفات ستحتوي على مقطع Matroska(TM) واحد فقط، فإن التفسيرات التالية تستخدم مصطلح 'ربط الملفات' على الرغم من أن 'ربط المقاطع' سيكون أكثر ملاءمة.

يتم تحديد كل مقطع بواسطة معرف مقطع فريد بعرض 128 بت. يتم إنشاء هذا المعرف تلقائيًا بواسطة mkvmerge(1). يتم الربط بشكل أساسي عن طريق وضع معرفات المقاطع (SID) للملف السابق/التالي في معلومات رأس المقطع. يطبع mkvinfo(1) هذه المعرفات إذا وجدها.

إذا تم تقسيم ملف إلى عدة ملفات أصغر واستخدام الربط، فلن تبدأ الطوابع الزمنية من 0 مرة أخرى ولكن ستستمر حيث توقف الملف الأخير. بهذه الطريقة يتم الاحتفاظ بالوقت المطلق حتى لو لم تكن الملفات السابقة متاحة (على سبيل المثال، عند البث). إذا لم يتم استخدام الربط، فيجب أن تبدأ الطوابع الزمنية من 0 لكل ملف. بشكل افتراضي، لا يستخدم mkvmerge(1) ربط الملفات. إذا كنت ترغب في ذلك، يمكنك تفعيله باستخدام الخيار --link. هذا الخيار مفيد فقط إذا كان التقسيم نشطًا أيضًا.

بغض النظر عما إذا كان التقسيم نشطًا أم لا، يمكن للمستخدم إخبار mkvmerge(1) بربط الملفات المنتجة بمعرفات مقطع محددة. يتم تحقيق ذلك باستخدام الخيارات --link-to-previous و --link-to-next. تقبل هذه الخيارات معرف مقطع بتنسيق يخرجه mkvinfo(1): 16 رقمًا سداسيًا عشريًا بين 0x00 و 0xff مسبوقة بـ '0x' لكل منها، على سبيل المثال، '0x41 0xda 0x73 0x66 0xd9 0xcf 0xb2 0x1e 0xae 0x78 0xeb 0xb4 0x5e 0xca 0xb3 0x93'. بدلاً من ذلك، يمكن استخدام شكل أقصر: 16 رقمًا سداسيًا عشريًا بين 0x00 و 0xff بدون بادئات '0x' وبدون مسافات، على سبيل المثال، '41da7366d9cfb21eae78ebb45ecab393'.

إذا تم استخدام التقسيم، فسيتم ربط الملف الأول بمعرف المقطع المحدد باستخدام --link-to-previous وسيتم ربط الملف الأخير بمعرف المقطع المحدد باستخدام --link-to-next. إذا لم يتم استخدام التقسيم، فسيتم ربط ملف الإخراج الواحد بكلا معرفي المقطع.

القيم الافتراضية

تنص مواصفات Matroska(TM) على أن بعض العناصر لها قيمة افتراضية. عادةً لا يتم كتابة عنصر إلى الملف إذا كانت قيمته تساوي قيمته الافتراضية لتوفير المساحة. العناصر التي قد يفتقدها المستخدم في إخراج mkvinfo(1) هي عناصر *اللغة* و *علم المسار الافتراضي*. القيمة الافتراضية *للغة* هي الإنجليزية ('eng')، والقيمة الافتراضية *لعلم المسار الافتراضي* هي *صحيح*. لذلك، إذا استخدمت --language 0:eng لمسار، فلن يظهر في إخراج mkvinfo(1).

المرفقات

ربما ترغب أيضًا في الاحتفاظ ببعض الصور مع ملف Matroska(TM) الخاص بك، أو أنك تستخدم ترجمات SSA وتحتاج إلى خط TrueType(TM) خاص نادر جدًا. في هذه الحالات، يمكنك إرفاق هذه الملفات بملف Matroska(TM). لن يتم إلحاقها بالملف فحسب، بل سيتم تضمينها فيه. يمكن لمشغل تشغيل هذه الملفات (حالة 'الصور') أو استخدامها لعرض الترجمات (حالة 'خطوط TrueType(TM)').

إليك مثال على كيفية إرفاق صورة وخط TrueType(TM) بالملف الناتج:

$ mkvmerge -o output.mkv -A video.avi sound.ogg \
  --attachment-description "Me and the band behind the stage in a small get-together" \
  --attachment-mime-type image/jpeg \
  --attach-file me_and_the_band.jpg \
  --attachment-description "The real rare and unbelievably good looking font" \
  --attachment-mime-type application/octet-stream \
  --attach-file really_cool_font.ttf

إذا تم استخدام ملف Matroska(TM) يحتوي على مرفقات كملف إدخال، فسيقوم mkvmerge(1) بنسخ المرفقات إلى الملف الجديد. يمكن تغيير اختيار المرفقات التي يتم نسخها والتي لا يتم نسخها باستخدام الخيارات --attachments و --no-attachments.

الفصول

نظام فصول Matroska(TM) أقوى من النظام القديم المعروف المستخدم في ملفات OGM. المواصفات الكاملة يمكن العثور عليها في موقع Matroska(TM)[1].

يدعم mkvmerge(1) نوعين من ملفات الفصول كمدخلات. التنسيق الأول، المسمى 'تنسيق الفصل البسيط'، هو نفس التنسيق الذي تتوقعه أدوات OGM. التنسيق الثاني هو تنسيق فصل يعتمد على XML يدعم جميع وظائف فصول Matroska(TM).

بصرف النظر عن ملفات الفصول المخصصة، يمكن لـ mkvmerge(1) أيضًا قراءة الفصول من تنسيقات ملفات أخرى (مثل MP4، Ogg، Blu-ray أو DVD).

تنسيق الفصل البسيط

يتكون هذا التنسيق من أزواج من الأسطر تبدأ بـ 'CHAPTERxx=' و 'CHAPTERxxNAME=' على التوالي. يحتوي الأول على الطابع الزمني للبدء بينما يحتوي الثاني على العنوان. إليك مثال:

CHAPTER01=00:00:00.000
CHAPTER01NAME=Intro
CHAPTER02=00:02:30.000
CHAPTER02NAME=Baby prepares to rock
CHAPTER03=00:02:42.300
CHAPTER03NAME=Baby rocks the house

سيقوم mkvmerge(1) بتحويل كل زوج من الأسطر إلى Matroska(TM) ChapterAtom واحد. لا يقوم بتعيين أي ChapterTrackNumber مما يعني أن جميع الفصول تنطبق على جميع المسارات في الملف.

نظرًا لأن هذا ملف نصي، قد يلزم إجراء تحويل ترميز النص. انظر القسم الخاص بالملفات النصية ومجموعات الأحرف للحصول على شرح لكيفية قيام mkvmerge(1) بالتحويل بين مجموعات الأحرف.

NAME

mkvmerge — Muxes (combines) video, audio and other data into an Matroska file.

SYNOPSIS

mkvmerge [OPTIONS] [-o | --output] OUTPUTFILE [FILE ...]

DESCRIPTION

mkvmerge is a tool to merge existing files into Matroska files. The name mkvmerge comes from the fact that it is the merge part of the MKVToolNix suite.

mkvmerge is capable of merging the following kinds of files:

  • Video files (AVI, FLV, MKV, MOV, MP4, MPEG, MPG, OGM, RAW video, etc.)
  • Audio files (AAC, AC3, DTS, FLAC, M4A, MP3, OGG, OPUS, PCM, RAW audio, TRUEAUDIO, VOC, WAV, WEBM, etc.)
  • Subtitle files (ASS, SRT, SSA, VDM, VOB, VOBSUB, etc.)
  • Matroska files (MKV, MKA, MKS)
  • MPLS files (from Blu-rays)
  • PVA files (from PVRs)
  • EVO files (from HD DVD)
  • BDMV files (from Blu-rays)

The list of supported file formats is not exhaustive. mkvmerge also supports a number of RAW formats. See the section on RAW formats for more information.

mkvmerge can also be used to split existing Matroska files. See the section on splitting Matroska files for more information.

OPTIONS

The options can be split into several categories:

  • Output options
  • Track options
  • Splitting options
  • Chapter options
  • Tag options
  • Error handling options
  • File identification options
  • File linking options
  • WebM options
  • General options

EXAMPLES

Merge two video files and one audio file into an MKV file:

mkvmerge -o output.mkv video1.mp4 video2.mp4 audio.mp3

Merge a video file and a subtitle file, setting the subtitle language to English:

mkvmerge -o output.mkv video.mp4 --language 0:eng subtitles.srt

Split an MKV file into multiple files, each 1 hour long:

mkvmerge -o output.mkv --split-duration 1h input.mkv

Load chapter information from a file:

mkvmerge -o output.mkv --chapters chapters.xml input.mkv
