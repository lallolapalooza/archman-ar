mkstemps(3) دليل وظائف المكتبة mkstemps(3)

الاسم

mkstemp, mkostemp, mkstemps, mkostemps - إنشاء ملف مؤقت فريد

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdlib.h>
int mkstemp(char *template);
int mkostemp(char *template, int flags);
int mkstemps(char *template, int suffixlen);
int mkostemps(char *template, int suffixlen, int flags);
متطلبات ميزة الاختبار (Feature Test Macro) لـ glibc (انظر feature_test_macros(7)):

    _XOPEN_SOURCE >= 500
        || /* glibc >= 2.12: */ _POSIX_C_SOURCE >= 200809L
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

mkostemp():

mkstemps():

mkostemps():

    _GNU_SOURCE

الوصف

تقوم الوظيفة mkstemp() بإنشاء اسم ملف مؤقت فريد من template، وتقوم بإنشاء وفتح الملف، وتعيد واصف ملف مفتوح للملف.

يجب أن تكون الأحرف الستة الأخيرة من template هي "XXXXXX" ويتم استبدالها بسلسلة تجعل اسم الملف فريدًا. بما أنها ستتغير، يجب ألا يكون template ثابتًا نصيًا، بل يجب تعريفه كمصفوفة أحرف.

يتم إنشاء الملف بأذونات 0600، أي القراءة والكتابة للمالك فقط. يوفر واصف الملف المُعاد الوصول للقراءة والكتابة إلى الملف. يتم فتح الملف باستخدام علامة open(2) O_EXCL، مما يضمن أن المتصل هو العملية التي أنشأت الملف.

الوظيفة mkostemp() تشبه mkstemp()، مع الاختلاف أن البتات التالية — بنفس المعنى كما في open(2) — قد يتم تحديدها في flags: O_APPEND، O_CLOEXEC، و O_SYNC. لاحظ أنه عند إنشاء الملف، تقوم mkostemp() بتضمين القيم O_RDWR، O_CREAT، و O_EXCL في وسيط flags المعطى لـ open(2)؛ تضمين هذه القيم في وسيط flags المعطى لـ mkostemp() غير ضروري، وينتج عنه أخطاء في بعض الأنظمة.

الوظيفة mkstemps() تشبه mkstemp()، باستثناء أن السلسلة في template تحتوي على لاحقة بطول suffixlen أحرف. وبالتالي، يكون template بالصيغة prefixXXXXXXsuffix، ويتم تعديل السلسلة XXXXXX كما في mkstemp().

الوظيفة mkostemps() هي لـ mkstemps() كما أن mkostemp() لـ mkstemp().

قيمة الإرجاع

عند النجاح، تعيد هذه الوظائف واصف ملف الملف المؤقت. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EEXIST
تعذر إنشاء اسم ملف مؤقت فريد. الآن محتويات template غير محددة.
EINVAL
بالنسبة لـ mkstemp() و mkostemp(): آخر ستة أحرف من template لم تكن XXXXXX؛ الآن template لم تتغير.
بالنسبة لـ mkstemps() و mkostemps(): template أقصر من (6 + suffixlen) أحرف، أو آخر 6 أحرف قبل اللاحقة في template لم تكن XXXXXX.

قد تفشل هذه الوظائف أيضًا مع أي من الأخطاء الموصوفة في open(2).

في إصدارات glibc 2.06 والإصدارات الأقدم، يتم إنشاء الملف بأذونات 0666، أي القراءة والكتابة لجميع المستخدمين. قد يكون هذا السلوك القديم خطرًا أمنيًا، خاصة وأن نكهات UNIX الأخرى تستخدم 0600، وقد يتغاضى شخص ما عن هذه التفاصيل عند نقل البرامج. يضيف POSIX.1-2008 شرطًا بأن يتم إنشاء الملف بالوضع 0600.

بشكل عام، لا يذكر مواصفات POSIX لـ mkstemp() أي شيء عن أوضاع الملفات، لذا يجب على التطبيق التأكد من أن قناع إنشاء وضع الملف الخاص به (انظر umask(2)) تم تعيينه بشكل مناسب قبل استدعاء mkstemp() (و mkostemp()).

mkstemps.3.en

mkstemps, mkstemp, mkstemps64, mkstemp64

Section: 3
Date: 2023-01-24

NAME

mkstemps, mkstemp, mkstemps64, mkstemp64 - create a unique temporary file

SYNOPSIS

#include <stdlib.h>

int mkstemp(char *template);
int mkstemps(char *template, int suffixlen);

/* Since glibc 2.1, mkstemp and mkstemps are wrappers for mkstemps64 and mkstemp64 */

int mkstemps64(char *template, int suffixlen);
int mkstemp64(char *template);

DESCRIPTION

The mkstemp() function generates a unique file name based on template, creates a file with that name, and opens the file for reading and writing.

The template argument must be a string ending in at least six consecutive `X' characters. These `X's will be replaced by characters (from `A' to `Z' followed by `0' to `9', and then wrapped around) to generate unique file names.

The mkstemps() function is similar to mkstemp(), but it requires the template to end in suffixlen `X's. The last suffixlen characters of the generated filename will not be replaced, but instead will contain the specified suffix. If suffixlen is 0, mkstemps() behaves like mkstemp().

The file is created with default file permissions.

The file descriptor returned by mkstemp() and mkstemps() is suitable for use with file operations like read(2), write(2), and close(2).

The functions mkstemp64() and mkstemps64() are identical to mkstemp() and mkstemps() respectively, but they create files that can be larger than 2 GiB on systems that support large files.

After the file has been created and opened, the template string is modified to contain the name of the created file.

RETURN VALUE

On success, mkstemp(), mkstemp64(), mkstemps(), and mkstemps64() return the file descriptor of the created file.

On error, -1 is returned, and errno is set appropriately.

ERRORS

EEXIST: A file with the generated name already exists.
EINVAL: The template argument does not end in at least six `X' characters, or suffixlen is invalid.
EMFILE: Too many file descriptors are in use by the process.
ENFILE: The system-wide limit on the total number of open files has been reached.
ENOENT: A component of the path prefix specified in template does not exist, or template is an empty string.
ENOSPC: The directory in which the file is to be created has no room for the new file, or an operation to create the file failed due to a lack of disk space.
ENOTDIR: A component of the path prefix specified in template is not a directory.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7). 


        Interface, Attributes, Cancellation point
        mkstemp, mkstemp64       default,       asynchronous-signal-safe
        mkstemps, mkstemps64    default,       asynchronous-signal-safe

CONFORMING TO

mkstemp() is specified by POSIX.1-2008.
mkstemps() is a non-standard extension.
The 64-bit versions are specific to glibc.

NOTES

The template string should be given as a path, e.g. "/tmp/tmpXXXXXX".

The file permissions of the created file are determined by the O_CREAT mode argument to open(2), which is typically 0600.

The mkstemp() and mkstemps() functions are thread-safe.

EXAMPLE

Create a temporary file in the current directory: 


        #include <stdio.h>
        #include <stdlib.h>
        #include <unistd.h>

        int main() {
            char template[] = "/tmp/mytemp-XXXXXX";
            int fd;

            fd = mkstemp(template);
            if (fd == -1) {
                perror("mkstemp");
                exit(EXIT_FAILURE);
            }

            printf("Created temporary file: %s\\n", template);

            // Use the file descriptor 'fd' here ...

            if (close(fd) == -1) {
                perror("close");
                exit(EXIT_FAILURE);
            }

            // unlink(template); // Optional: remove the file when done

            return 0;
        }
