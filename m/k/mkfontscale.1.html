mkfontscale(1)

الحزمة: xorg-mkfontscale

التراخيص: MIT-open-group, X11, MIT, HPND-sell-variant

MKFONTSCALE(1) دليل الأوامر العامة MKFONTSCALE(1)

الاسم

mkfontscale - إنشاء فهرس لملفات الخطوط القابلة للتطوير لـ X

الملخص

mkfontscale [ -b ] [ -s ] [ -o اسم_الملف ] [ -x لاحقة ] [ -a ترميز ] ... [ -f ضوضاء ] [ -l ] [ -e دليل ] [ -p بادئة ] [ -r بادئة ] [ -n بادئة ] [ -u | -U ] [ -v ] [ -- ] [ دليل ] ...

الوصف

لكل وسيط دليل، يقوم mkfontscale بقراءة جميع ملفات الخطوط القابلة للتطوير في الدليل. لكل ملف خط يتم العثور عليه، يتم إنشاء اسم خط X11 (XLFD)، ويتم كتابته مع اسم الملف إلى ملف fonts.scale في الدليل.

يجب فحص ملف fonts.scale الناتج وربما تحريره يدويًا قبل استخدامه كمدخل لبرنامج mkfontdir(1).

خيارات

-b
قراءة خطوط النقط (bitmap fonts). افتراضيًا، يتم تجاهل خطوط النقط.
-s
تجاهل الخطوط القابلة للتطوير. افتراضيًا، يتم قراءة الخطوط القابلة للتطوير. إذا تم تعيين -b، فإن هذا العلم له تأثير جانبي يتمثل في تمكين قراءة ملفات fonts.scale.
-o اسم_الملف
إرسال إخراج البرنامج إلى اسم_الملف؛ الافتراضي هو fonts.scale إذا لم يتم قراءة خطوط النقط، و fonts.dir إذا تم ذلك. إذا كان اسم_الملف نسبيًا، فسيتم إنشاؤه في الدليل الذي تتم معالجته. إذا كانت القيمة الخاصة -، يتم كتابة الإخراج إلى المخرج القياسي.
-x لاحقة
استبعاد جميع الملفات ذات اللاحقة المحددة.
-a ترميز
إضافة ترميز إلى قائمة الترميزات التي يتم البحث عنها.
-f ضوضاء
تعيين نسبة الأحرف التي قد تكون مفقودة في الترميزات الكبيرة إلى ضوضاء بالمائة. الافتراضي هو 2٪.
-l
كتابة ملفات fonts.dir مناسبة للتطبيقات التي لا يمكنها إعادة ترميز الخطوط القديمة (BDF و PCF). افتراضيًا، يُفترض أن التطبيق يمكنه إعادة ترميز الخطوط القديمة المشفرة بـ Unicode.
-e
يحدد دليلًا لملفات الترميز. يتم مسح كل دليل من هذه الأدلة بحثًا عن ملفات الترميز، ثم يتم كتابة قائمة بها إلى ملف "encodings.dir" في كل دليل خط.
-p
يحدد بادئة يتم إلحاقها بأسماء مسارات ملفات الترميز عند كتابتها إلى ملف "encodings.dir". يتم إلحاق البادئة حرفيًا: إذا كان المطلوب هو `/' بين البادئة وأسماء المسارات، فيجب توفيره صراحة كجزء من البادئة.
-r
الاحتفاظ بالأدلة غير المطلقة للترميز في شكلها النسبي عند كتابة ملف "encodings.dir". الافتراضي هو تحويل أدلة الترميز النسبية إلى أدلة مطلقة عن طريق إلحاق الدليل الحالي. موقع هذه الخيارات مهم، حيث ينطبق هذا الخيار فقط على خيارات -e اللاحقة.
-n
لا تبحث عن خطوط، لا تكتب ملفات دليل الخطوط. هذا الخيار مفيد عند إنشاء أدلة الترميز فقط.
-u, -U
تعطيل (-u) أو تمكين (-U) فهرسة ترميزات الخطوط ISO 10646:1 (الافتراضي: ممكّن).
-v
طباعة إصدار البرنامج والخروج.
--
نهاية الخيارات.

ملاحظات

تم توثيق تنسيق ملفات fonts.scale و fonts.dir و encodings.dir في صفحة دليل mkfontdir(1).

سيقوم Mkfontscale بالكتابة فوق أي ملف fonts.scale حتى لو تم تحريره يدويًا.

mkfontscale -b -s -l يعادل mkfontdir.

المؤلف

تمت كتابة إصدار mkfontscale المضمن في إصدار مؤسسة X.Org هذا في الأصل بواسطة Juliusz Chroboczek <jch@freedesktop.org> لمشروع XFree86. استلهمت وظيفة هذا البرنامج من الأداة المساعدة ttmkfdir بواسطة Joerg Pommnitz.
