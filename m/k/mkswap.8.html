MKSWAP(8) إدارة النظام MKSWAP(8)

الاسم

mkswap - إعداد مساحة تبديل في لينكس

الملخص

mkswap [خيارات] جهاز [كتل]

mkswap [خيارات] --size حجم --file ملف

الوصف

يقوم mkswap بإعداد مساحة تبديل في لينكس على جهاز أو في ملف.

عادة ما يكون الوسيط جهاز قسمًا على القرص (شيئًا مثل /dev/sdb7) ولكن يمكن أن يكون أيضًا ملفًا. لا ينظر نواة لينكس إلى معرفات الأقسام، ولكن العديد من نصوص التثبيت ستفترض أن أقسام النوع السداسي عشري 82 (LINUX_SWAP) مخصصة لأقسام التبديل. (تحذير: Solaris تستخدم هذا النوع أيضًا. كن حذرًا من عدم قتل أقسام Solaris الخاصة بك.)

الوسيط كتل زائد عن الحاجة ولكنه محفوظ للتوافق مع الإصدارات السابقة. (يحدد الحجم المطلوب لمساحة التبديل بالكتل 1024 بايت. سيستخدم mkswap القسم أو الملف بأكمله إذا تم حذفه. تحديدها غير مستحسن - قد يؤدي الخطأ المطبعي إلى تدمير قرصك.)

بعد إنشاء مساحة التبديل، تحتاج إلى أمر swapon(8) لبدء استخدامه. عادة ما يتم إدراج مساحات التبديل في /etc/fstab حتى يمكن استخدامها عند بدء التشغيل بواسطة أمر swapon -a في نص برمجي لبدء التشغيل.

تحذير

لا يمس رأس التبديل الكتلة الأولى. يمكن أن يكون محمل الإقلاع أو تسمية القرص موجودًا هناك، ولكنه ليس إعدادًا موصى به. الإعداد الموصى به هو استخدام قسم منفصل لمساحة تبديل لينكس.

mkswap، مثل العديد من الأدوات الأخرى من نوع mkfs، يمحو كتلة القسم الأولى لجعل أي نظام ملفات سابق غير مرئي.

ومع ذلك، يرفض mkswap محو الكتلة الأولى على جهاز يحتوي على جدول أقسام (SUN، BSD، ...).

خيارات

-c، --check

تحقق من الجهاز (إذا كان جهاز كتلة) بحثًا عن كتل تالفة قبل إنشاء مساحة التبديل. إذا تم العثور على أي كتل تالفة، يتم طباعة العدد.

-F، --file

إنشاء ملف تبديل بأذونات الملف المناسبة وتعبئة الكتل على القرص.

-f، --force

المتابعة حتى لو كان الأمر غبيًا. هذا يسمح بإنشاء مساحة تبديل أكبر من الملف أو القسم الذي يقيم عليه.

أيضًا، بدون هذا الخيار، سيرفض mkswap محو الكتلة الأولى على جهاز يحتوي على جدول أقسام.

-q، --quiet

كتم الإخراج ورسائل التحذير.

-L، --label تسمية

تحديد تسمية للجهاز، للسماح لـ swapon(8) بالعمل حسب التسمية.

--lock[=وضع]

استخدم قفل BSD حصريًا للجهاز أو الملف الذي يعمل عليه. يمكن أن يكون الوسيط الاختياري وضع yes أو no (أو 1 و 0) أو nonblock. إذا تم حذف الوسيط وضع، فإنه افتراضيًا إلى yes. هذا الخيار يستبدل متغير البيئة $LOCK_BLOCK_DEVICE. الافتراضي هو عدم استخدام أي قفل على الإطلاق، ولكن يوصى بتجنب التعارضات مع systemd-udevd(8) أو أدوات أخرى.

-p، --pagesize حجم

تحديد حجم الصفحة (بالبايت) للاستخدام. هذا الخيار غير ضروري عادة؛ يقرأ mkswap الحجم من النواة.

-U، --uuid UUID

تحديد UUID للاستخدام. الافتراضي هو إنشاء UUID. تنسيق UUID هو سلسلة من الأرقام السداسية العشرية مفصولة بشرطات، مثل هذا: "c1b9d5a2-f162-11cf-9ece-0020afc76f16". قد يكون الوسيط UUID أيضًا أحد ما يلي:

clear

مسح UUID نظام الملفات

random

إنشاء UUID جديد تم إنشاؤه عشوائيًا

time

إنشاء UUID جديد يعتمد على الوقت

-e، --endianness ENDIANNESS

تحديد endianness للاستخدام، الوسائط الصالحة هي native، little أو big. الافتراضي هو native.

-o، --offset offset

تحديد offset لكتابة مساحة التبديل إليها.

-s، --size size

تحديد حجم ملف التبديل المنشأ بالبايت وقد يتبعه لاحقة ضربية: KiB (=1024)، MiB (=1024*1024)، وهكذا لـ GiB، TiB، PiB، EiB، ZiB، و YiB (الـ "iB" اختياري، على سبيل المثال، "K" لها نفس المعنى مثل "KiB"). إذا كان الملف موجودًا وأكبر من size، فسيتم اقتطاعه إلى هذا الحجم. هذا الخيار منطقي فقط عند استخدامه مع --file.

-v، --swapversion 1

تحديد إصدار مساحة التبديل. (هذا الخيار عديم الفائدة حاليًا، حيث أصبح الخيار القديم -v 0 قديمًا ولم يعد مدعومًا سوى -v 1. لم تدعم النواة تنسيق مساحة التبديل v0 منذ 2.5.22 (يونيو 2002). الإصدار الجديد v1 مدعوم منذ 2.1.117 (أغسطس 1998).).

--verbose

تنفيذ مفصل. مع هذا الخيار، سيعرض mkswap المزيد من التفاصيل حول المشاكل المكتشفة أثناء إعداد مساحة التبديل.

-h، --help

عرض نص المساعدة والخروج.

-V، --version

عرض الإصدار والخروج.

البيئة

LIBBLKID_DEBUG=all

تمكين إخراج تصحيح أخطاء libblkid.

LOCK_BLOCK_DEVICE=<mode>

استخدم قفل BSD حصريًا. الوضع هو "1" أو "0". راجع --lock لمزيد من التفاصيل.

ملاحظات

يعتمد الحد الأقصى للحجم المفيد لمساحة التبديل على البنية وإصدار النواة.

الحد الأقصى لعدد الصفحات التي يمكن معالجتها بواسطة رأس مساحة التبديل هو 4294967295 (عدد صحيح غير مؤشر 32 بت). يتم تجاهل المساحة المتبقية في جهاز التبديل.

في الوقت الحاضر، يسمح لينكس بـ 32 مساحة تبديل. يمكن رؤية المساحات قيد الاستخدام في الملف /proc/swaps.

يرفض mkswap المساحات الأصغر من 10 صفحات.

إذا لم تكن تعرف حجم الصفحة الذي تستخدمه آلتك، يمكنك البحث عنه باستخدام getconf PAGESIZE.

بصرف النظر عن mkswap --file، من الممكن أيضًا إنشاء ملف التبديل يدويًا قبل تهيئته باستخدام mkswap، على سبيل المثال باستخدام أمر مثل

منذ الإصدار 2.41، يضبط mkswap --file سمة nocow للملفات المنشأة حديثًا لدعم ملفات التبديل على Btrfs.

# dd if=/dev/zero of=swapfile bs=1MiB count=$((8*1024))

لإنشاء ملف تبديل بحجم 8GiB.

في هذه الحالة، يرجى قراءة الملاحظات من swapon(8) حول قيود استخدام ملف التبديل (الثقوب، التخصيص المسبق، وقضايا النسخ عند الكتابة).

انظر أيضًا

fdisk(8), swapon(8)

mkswap(8)

NAME

mkswap - set up an Linux swap area

SYNOPSIS

mkswap [options] device [size]

DESCRIPTION

Set up a Linux swap area (file or partition) for use by swapon(8).

The device is the swap file or partition to be set up. It may be a regular file, a block device, or loop device.

The optional size is the number of 1024-byte blocks to use. If omitted, mkswap uses the entire remaining space of the device. The size is rounded down to the nearest multiple of 256 (for hibernation support).

WARNING

Do not use mkswap on a device that contains or might contain an existing operating system or important data. mkswap erases all data on the specified device (or partition).

OPTIONS

-c, --wipe-devices

Detect and clear existing corrupted blocks on the device before setting up the swap area. This is recommended if you suspect that the device may have bad blocks.

-f, --force

Finish setup even if there were errors (e.g. bad blocks found with -c). This option implies -w.

-L, --label label

Choose a label for the swap area.

-m, --swap-mb size_in_MiB

Specify the size of the swap area in mebibytes (1024*1024 bytes).

--offset offset_in_KiB

Specify the offset where the swap area should be created, in KiB. The default is to start at the beginning of the partition/file.

--swap-file-offset offset_in_KiB

Similar to --offset, but used for swap files.

--swap-file-sectors offset_in_512-byte_sectors

Similar to --offset, but used for swap files and specified in 512-byte sectors. Note that this option is used internally by mkswap and may be removed in the future.

-p, --pagesize bytes

Specify the required pagesize (in bytes) for the swap area. This is typically 4KiB. This option is only needed on architectures that do not support the standard Linux pagesizes. The default is detected automatically.

-U, --uuid uuid

Choose a UUID for the swap area. The default is to generate a new random UUID.

-v, --version

Display version information and exit.

-h, --help

Display help text and exit.

ENVIRONMENT

The following environment variables can be used to override some options:

LIBBLKID_DEBUG

Enable debug output from libblkid.

LIBSWAP_DEBUG

Enable debug output from libswap.

NOTES

The swap area can be a regular file or a partition. For performance reasons, a partition is usually preferred. If you use a file, it is recommended to create it with `dd` and `fallocate` and not to use a sparse file.

The default label is usually derived from the partition name.

The UUID is generated using `uuidgen(1)`. The label and UUID are stored in the superblock of the swap area.

The swap area should not be larger than the available RAM plus any swap partitions already configured. This is especially important for hibernation support.

mkswap writes a swap signature and some bookkeeping information to the specified device. The signature is typically:

0x82 C1 C1 C1 (hex) for a Linux swap area.

The first 1024 bytes are used for the superblock. The next 1024 bytes are used for swap signature and the remaining space is available for use as swap.

If the hibernation support is enabled (e.g. by specifying a size that is a multiple of 256), then the swap space is aligned to 1MiB boundaries and the offset of the swap space is stored in the superblock. This is necessary for the suspend-to-disk functionality (hibernation) to work correctly.

The default size for hibernation support is determined by the kernel's pagesize. For hibernation support, the swap space must be at least twice the size of RAM plus 1 byte, and at least 1MB in size.

SEE ALSO

swapon(8), swapoff(8), uuidgen(1), fdisk(8), parted(8)
