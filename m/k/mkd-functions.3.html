الوصف

يحتوي تنسيق markdown المدعوم في هذا التنفيذ على كتل رأس Pandoc-style وكتل <style> المضمنة، ولا توفر وظائف markdown(3) القياسية الوصول إلى البيانات المقدمة من أي من هذين الامتدادين. تمنحك هذه الوظائف الوصول إلى تلك البيانات، بالإضافة إلى أنها توفر طريقة أكثر تفصيلاً لتحويل مستندات Markdown إلى HTML.

بالنظر إلى MMIOT* الذي تم إنشاؤه بواسطة mkd_in() أو mkd_string()، تقوم mkd_compile() بتجميع المستند في أقسام <style>، Pandoc، و html.

بمجرد تجميعها، يمكن فحص المستند وكتابته بواسطة الوظائف mkd_css()، mkd_document()، mkd_generatecss()، mkd_generatehtml()، mkd_generatetoc()، mkd_toc()، mkd_xhtmlpage()، mkd_doc_title()، mkd_doc_author()، و mkd_doc_date().

mkd_css() تخصص سلسلة نصية وتملأها بأي أقسام <style> مقدمة في المستند، mkd_generatecss() تكتب أي أقسام <style> إلى المخرجات، mkd_document() تشير text إلى نص المستند وتعيد حجم المستند، mkd_generatehtml() تكتب بقية المستند إلى المخرجات، و mkd_doc_title()، mkd_doc_author()، mkd_doc_date() تستخدم لقراءة محتويات رأس Pandoc، إن وجدت.

mkd_xhtmlpage() تكتب صفحة xhtml تحتوي على المستند. يمكن تمرير المجموعة العادية من العلامات.

mkd_toc() تكتب مخطط المستند، في شكل مجموعة من القوائم المتداخلة مع روابط لكل رأس في المستند، إلى سلسلة نصية تم تخصيصها بواسطة malloc()، وتعيد الحجم.

mkd_generatetoc() تشبه mkd_toc()، باستثناء أنها تكتب مخطط المستند إلى الوسيط FILE* المحدد.

mkd_cleanup() تحذف MMIOT* بعد الانتهاء من المعالجة.

mkd_compile() تقبل نفس العلامات التي تستخدمها markdown() و mkd_string()؛

MKD_NOIMAGE
لا تعالج `![]' وتزيل علامات <img> من المخرجات.
MKD_NOLINKS
لا تعالج `[]' وتزيل علامات <a> من المخرجات.
MKD_NOPANTS
لا تقم بتعديل علامات التنصيص، أو الواصلات، أو النقاط بطريقة Smartypants.
MKD_TAGTEXT
عالج الإدخال كما لو كنت داخل علامة html. هذا يعني أنه لن يتم إنشاء أي علامات html، وستحاول mkd_compile() تشفير أي شيء قد يربك متصفح الويب بشدة.
MKD_NO_EXT
لا تعالج أي بروتوكولات Markdown زائفة عند التعامل مع روابط [][].
MKD_NOHEADER
لا تحاول تحليل أي رؤوس Pandoc-style.
MKD_TOC
قم بتسمية جميع الرؤوس للاستخدام مع وظيفة mkd_generatetoc().
MKD_1_COMPAT
علامة توافق MarkdownTest_1.0؛ قم بقص المسافات اللاحقة من السطر الأول لكتل الشفرة وتعطيل روابط المراجع الضمنية.
MKD_NOSTRIKETHROUGH
تعطيل دعم الشطب.

قيم الإرجاع

تُعيد الوظيفة mkd_compile() القيمة 1 في حالة النجاح، أو 0 إذا تم تجميع المستند بالفعل. تُعيد الوظيفة mkd_generatecss() عدد البايتات المكتوبة في حالة النجاح، أو EOF إذا حدث خطأ. تُعيد الوظيفة mkd_generatehtml() القيمة 0 عند النجاح، و -1 عند الفشل.

mkd-functions(3) - Arch Linux

NAME

mkd-functions - Markdown extension functions

LIBRARY

Discount library (libdiscount)

SYNOPSIS

#include <discount/mkdn.h>

char *mkd_compile(const char *text, size_t size, int flags,
    enum mkd_version version);
void mkd_compile_css(FILE *css_file, const char *css_text,
    size_t css_size, int flags);
char *mkd_css(const char *text, size_t size, int flags);
void mkd_cleanup(char *output);
char *mkd_version_string(void);
enum mkd_version mkd_version(void);
char *mkd_html(const char *text, size_t size, int flags,
    enum mkd_version version);
char *mkd_toc(const char *text, size_t size, int flags,
    enum mkd_version version);
char *mkd_toc_css(const char *text, size_t size, int flags,
    enum mkd_version version);

DESCRIPTION

The Discount library provides functions for converting Markdown to HTML. The functions in this manual page are the primary interface to the library.

The mkd_compile() function takes a Markdown-formatted string text of length size and returns a string containing the HTML representation. The flags argument specifies various options for the conversion (see BUGS for more details). The version argument specifies which version of the Markdown specification to use.

The mkd_compile_css() function writes CSS to the provided css_file. The css_text and css_size arguments specify the CSS to be written.

The mkd_css() function returns a string containing the CSS representation of the input text.

The mkd_cleanup() function should be called to free the memory allocated by mkd_compile(), mkd_css(), mkd_html(), mkd_toc(), or mkd_toc_css().

The mkd_version_string() function returns a string representing the version of the Discount library. The mkd_version() function returns the version number.

The mkd_html() function is an alias for mkd_compile().

The mkd_toc() function generates a table of contents from the input text.

The mkd_toc_css() function generates a table of contents with CSS styling.

RETURN VALUES

On success, the functions that return a string allocate and return a pointer to a null-terminated string containing the result. On failure, they return NULL.

The mkd_cleanup() function does not return a value.
