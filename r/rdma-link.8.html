rdma-link(8)

الحزمة: iproute2

RDMA-LINK(8) لينكس RDMA-LINK(8)

اسم

rdma-link - تهيئة رابط RDMA

الملخص


rdma [ خيارات ] link { أمر | help }

خيارات := { -V[ersion] | -d[etails] }

rdma link show [ DEV/PORT_INDEX ]

rdma link add NAME type TYPE netdev NETDEV

rdma link delete NAME

rdma link help

الوصف

rdma link show - عرض سمات رابط RDMA

DEV/PORT_INDEX - يحدد رابط RDMA المراد عرضه. إذا تم حذف هذه الحجة ، سيتم سرد جميع الروابط.

rdma link add NAME type TYPE netdev NETDEV - إضافة رابط RDMA للنوع المحدد إلى جهاز الشبكة

NAME - يحدد الاسم الجديد لرابط RDMA المراد إضافته

TYPE - يحدد نوع RDMA المراد استخدامه. أنواع الروابط:


rxe - برنامج تشغيل RoCE البرمجي

siw - برنامج تشغيل iWARP البرمجي

NETDEV - يحدد جهاز الشبكة الذي يرتبط به الرابط

rdma link delete NAME - حذف رابط RDMA

NAME - يحدد اسم رابط RDMA المراد حذفه

أمثلة

rdma link show

يعرض حالة جميع روابط RDMA على النظام.

rdma link show mlx5_2/1

يعرض حالة رابط RDMA المحدد.

rdma link add rxe_eth0 type rxe netdev eth0

يضيف رابط RXE يسمى rxe_eth0 إلى جهاز الشبكة eth0

rdma link del rxe_eth0

يزيل رابط RXE rxe_eth0
