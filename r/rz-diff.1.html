NAME

rz-diff - diff between two rbin files

SYNOPSIS

rz-diff [options] file1 file2

DESCRIPTION

This command compares two rbin files and shows the differences between them.

EXAMPLE

Compare two rbin files named file1.rbin and file2.rbin:

rz-diff file1.rbin file2.rbin

SEE ALSO

rz(1), rz-asm(1), rz-bin(1)
