NAME

windres - Microsoft Windows resource compiler

\n\n
\n

SYNOPSIS

windres [-i input-file] [-o output-file] [--target=<target>] [-v|--version] [-h|--help] [-f|--preprocess] [--no-preprocess] [--use-temp-file|--no-use-temp-file] [--] [input-files... ]

\n\n
\n

DESCRIPTION

windres is used to compile. resource files. Resource files contain information for the Microsoft Windows operating system, such as icons, dialogs, menus, bitmaps, version information, etc. These resource files are then linked into Windows executables.

windres reads a resource script file (often with a .rc extension), processes it, and writes a resource object file (often with a .o extension). This resource object file can then be linked into an executable by a linker.

Resource script files are not C source files. They contain directives that describe the resources. windres supports a subset of the Microsoft Visual C++ resource compiler syntax.

When windres is used to pre-process a resource file, it will invoke the C pre-processor (usually cpp) on the input file. The pre-processor directives ("#include", "#define", etc.) are processed and then the file is compiled.

By default, windres uses the C pre-processor to process include files and macros. However, if you wish to compile a resource file which does not require pre-processing, you may use the --no-preprocess option.

In addition, windres supports the use of temporary files for reading the output of the preprocessor. This is useful on systems where popen might be buggy (it is known to have buggy popen where the output will instead go the console).

\n\n
\n

OPTIONS

-i input-file
--input=input-file
Read input from input-file. If this option is not specified, then the first non-option argument is used as the input file. If no input file is specified, then windres will read from the standard input.
-o output-file
--output=output-file
Write output to output-file. If this option is not specified, then the output is written to the standard output. If the output file name is specified as "-", then the output is written to standard output.
--target=<target>
Specify the target architecture for the compiled resource file. <target> can be any target supported by binutils.
-v
--version
Print the version number of windres and exit.
-h
--help
Print a usage summary and exit.
-f
--preprocess
Preprocess the input file using the C preprocessor. This is the default behavior.
--no-preprocess
Do not preprocess the input file. This option is useful if the input file does not contain any preprocessor directives.
--use-temp-file
Use a temporary file to read the output of the preprocessor. This is useful on systems where popen might be buggy (it is known to have buggy popen where the output will instead go the console).
--no-use-temp-file
Use popen, not a temporary file, to read the output of the preprocessor. This is the default behaviour.
--yydebug
If windres is compiled with "YYDEBUG" defined as 1, this will turn on parser debugging.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
