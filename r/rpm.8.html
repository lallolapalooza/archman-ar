NAME

rpm - RPM Package Manager

SYNOPSIS

rpm {-q|--query} [select-options] [query-options]

rpm --querytags

rpm {-e|--erase} [--allmatches] [--justdb] [--nodb] [--nodeps] [--noscripts] [--notriggers] [--test] PACKAGE_NAME ...

DESCRIPTION

rpm is a powerful Package Manager, which can be used to build, install, query, verify, update, and erase individual software packages. A package consists of an archive of files and meta-data used to install and erase the archive files. The meta-data includes helper scripts, file attributes, and descriptive information about the package. Packages come in two varieties: binary packages, used to encapsulate software to be installed, and source packages, containing the source code and recipe necessary to produce binary packages.

One of the following basic modes must be selected: Query, Verify, Install/Upgrade/Freshen/Reinstall, Uninstall, Set Owners/Groups, Show Querytags, and Show Configuration.

GENERAL OPTIONS

These options can be used in all the different modes.

-?, --help
Print a longer usage message than normal.
--version
Print a single line containing the version number of rpm being used.
--quiet
Print as little as possible - normally only error messages will be displayed.
-v, --verbose
Print verbose information - normally routine progress messages will be displayed.
-vv
Print lots of ugly debugging information.
--rcfile FILELIST
Replace the default list of configuration files to be read with FILELIST. See rpmrc Configuration for details.
--load FILE
Load an individual macro file.
--macros FILELIST
Replace the list of macro files to be loaded with FILELIST. See Macro Configuration for details.
--pipe CMD
Pipes the output of rpm to the command CMD.
--dbpath DIRECTORY
Use the database in DIRECTORY rather than the default path /var/lib/rpm.
--root DIRECTORY
Use the file system tree rooted at DIRECTORY for all operations. Note that this means the database within DIRECTORY will be used for dependency checks and any scriptlet(s) (e.g. %post if installing, or %prep if building, a package) will be run after a chroot(2) to DIRECTORY.

Note that rpm assumes the environment inside the root is set up by the caller, such as any mounts needed for the operation inside the root directory.

-D, --define='MACRO EXPR'
Defines MACRO with value EXPR.
--undefine='MACRO'
Undefines MACRO.
-E, --eval='EXPR'
Prints macro expansion of EXPR.

More - less often needed - options can be found on the rpm-misc(8) man page.

INSTALL OPTIONS

All of the install, upgrade, freshen, and reinstall operations will download the specified packages before installing them. See FTP/HTTP OPTIONS for information on rpm's ftp and http client support.

The general form of an rpm install command is

rpm {-i|--install} [install-options] PACKAGE_FILE ...

This installs a new package.

The general form of an rpm upgrade command is

rpm {-U|--upgrade} [install-options] PACKAGE_FILE ...

This upgrades or installs the package currently installed to a newer version. This is the same as install, except all other version(s) of the package are removed after the new package is installed.

rpm {-F|--freshen} [install-options] PACKAGE_FILE ...

This will upgrade packages, but only ones for which an earlier version is installed.

The general form of an rpm reinstall command is

rpm {--reinstall} [install-options] PACKAGE_FILE ...

This reinstalls a previously installed package.

--allfiles
Installs or upgrades all the missingok files in the package, regardless if they exist.
--badreloc
Used with --relocate, permit relocations on all file paths, not just those OLDPATH's included in the binary package relocation hint(s).
--excludepath OLDPATH
Don't install files whose name begins with OLDPATH.
--excludeartifacts
Don't install any files which are marked as artifacts, such as build-id links.

--force

--ignoresize
Don't check mount file systems for sufficient disk space before installing this package.
--ignorearch

--ignoreos
Allow installation or upgrading even if the operating systems of the binary package and host don't match.

--justdb
Update only the database, not the filesystem.
--nodb

--nodigest

--nodeps

--nopre --nopost --nopreun --nopostun --nopretrans --noposttrans --nopreuntrans --nopostuntrans

--notriggerprein --notriggerin --notriggerun --notriggerpostun

and turns off execution of the corresponding %triggerprein, %triggerin, %triggerun, and %triggerpostun scriptlet(s).

--nosysusers
Don’t create sysusers from packages

Allow an upgrade to replace a newer package with an older one.
--percent
Print percentages as files are unpacked from the package archive. This is intended to make rpm easy to run from other tools.
--prefix NEWPATH
For relocatable binary packages, translate all file paths that start with the installation prefix in the package relocation hint(s) to NEWPATH.

For relocatable binary packages, translate all file paths that start with OLDPATH in the package relocation hint(s) to NEWPATH. This option can be used repeatedly if several OLDPATH's in the package are to be relocated.

Install the packages even if they replace files from other, already installed, packages.
--replacepkgs
Install the packages even if some of them are already installed on this system.
--test
Do not install the package, simply check for and report potential conflicts.

ERASE OPTIONS

The general form of an rpm erase command is

rpm {-e|--erase} [--allmatches] [--justdb] [--nodeps] [--noscripts] [--notriggers] [--test] PACKAGE_NAME ...

The following options may also be used:

--allmatches
Remove all versions of the package which match PACKAGE_NAME. Normally an error is issued if PACKAGE_NAME matches multiple packages.
--justdb
Update only the database, not the filesystem.
--nodeps
Don't check dependencies before uninstalling the packages.
--noscripts, --nopreun, --nopostun
Don't execute the scriptlet of the same name. The --noscripts option during package erase is equivalent to

--nopreun --nopostun

and turns off the execution of the corresponding %preun, and %postun scriptlet(s).

--notriggers, --notriggerun, --notriggerpostun
Don't execute any trigger scriptlet of the named type. The --notriggers option is equivalent to

--notriggerun --notriggerpostun

and turns off execution of the corresponding %triggerun, and %triggerpostun scriptlet(s).

--test
Don't really uninstall anything, just go through the motions. Useful in conjunction with the -vv option for debugging.

QUERY OPTIONS

The general form of an rpm query command is

rpm {-q|--query} [select-options] [query-options]

You may specify the format that package information should be printed in. To do this, you use the

--qf|--queryformat QUERYFMT

option, followed by the QUERYFMT format string. Query formats are modified versions of the standard printf(3) formatting. The format is made up of static strings (which may include standard C character escapes for newlines, tabs, and other special characters (not including \0)) and printf(3) type formatters. As rpm already knows the type to print, the type specifier must be omitted however, and replaced by the name of the header tag to be printed, enclosed by {} characters. Tag names are case insensitive, and the leading RPMTAG_ portion of the tag name may be omitted as well.

Alternate output formats may be requested by following the tag with :typetag. Currently, the following types are supported:

:armor
Wrap a public key in ASCII armor.
:arraysize
Display number of elements in array tags.
:base64
Encode binary data using base64.
:date
Use strftime(3) "%c" format.
:day
استخدم تنسيق strftime(3) "%a %b %d %Y".
:depflags
تنسيق معامل مقارنة الاعتماديات.
:deptype
نوع الاعتماديات الخاص بالتنسيق.
:expand
قم بتوسيع الماكرو.
:fflags
تنسيق علامات الملف.
:fstate
تنسيق حالة الملف.
:fstatus
تنسيق حالة التحقق من الملف.
:hex
تنسيق بالأعداد الستة عشرية.
:octal
تنسيق بالأعداد الثمانية.
:humaniec
رقم سهل القراءة (وفقًا لـ IEC 80000). اللاحقة K = 1024، M = 1048576، ...
:humansi
رقم سهل القراءة (وفقًا لـ SI). اللاحقة K = 1000، M = 1000000، ...
:json

:pgpsig

:tagname

على سبيل المثال، لطباعة أسماء الحزم التي تم الاستعلام عنها فقط، يمكنك استخدام %{NAME} كسلسلة تنسيق. لطباعة اسم الحزم ومعلومات التوزيع في عمودين، يمكنك استخدام %-30{NAME}%{DISTRIBUTION}. سيقوم rpm بطباعة قائمة بجميع العلامات التي يعرفها عند استدعائه باستخدام الوسيط --querytags.

خيارات اختيار الحزمة

اسم_الحزمة
استعلام عن الحزمة المثبتة المسماة اسم_الحزمة. لتحديد الحزمة بشكل أكثر دقة، يمكن أن يتبع اسم الحزمة الإصدار أو الإصدار والإصدار كلاهما مفصولين بشرطة أو اسم بنية مفصول بنقطة. انظر مخرجات rpm -qa أو rpm -qp ملف_الحزمة كمثال.
-a, --all [محدد]
استعلام عن جميع الحزم المثبتة.

يمكن توفير محدد اختياري في شكل علامة=نمط لتضييق نطاق الاختيار، على سبيل المثال name="b*" للاستعلام عن الحزم التي يبدأ اسمها بـ "b".

--dupes
قائمة الحزم المكررة.
-f, --file ملف
استعلام عن الحزمة التي تمتلك ملف مثبت.
--filecaps
قائمة أسماء الملفات ذات صلاحيات POSIX1.e.
--fileclass
قائمة أسماء الملفات مع فئاتها (تصنيف libmagic).
--filecolor
قائمة أسماء الملفات مع ألوانها (0 لـ noarch، 1 لـ 32bit، 2 لـ 64 bit).
--fileprovide
قائمة أسماء الملفات مع ما توفره.
--filerequire
قائمة أسماء الملفات مع ما تتطلبه.
-g, --group مجموعة
استعلام عن الحزم ذات المجموعة مجموعة.
--hdrid SHA1
استعلام عن الحزمة التي تحتوي على معرف رأس معين، أي تجزئة SHA1 لمنطقة الرأس الثابتة.
-p, --package ملف_الحزمة
استعلام عن حزمة (غير مثبتة) ملف_الحزمة. يمكن تحديد ملف_الحزمة كعنوان URL من نوع ftp أو http، وفي هذه الحالة سيتم تنزيل رأس الحزمة والاستعلام عنه. انظر خيارات FTP/HTTP للمعلومات حول دعم عميل ftp و http في rpm. سيتم تفسير الوسيط (الوسائط) ملف_الحزمة، إذا لم يكن حزمة ثنائية، كقائمة حزم نصية ما لم يتم استخدام الخيار --nomanifest. في القوائم، يُسمح بالتعليقات، بدءًا من '#'، وقد تتضمن كل سطر في ملف قائمة الحزم تعبيرات glob مفصولة بمسافات بيضاء، بما في ذلك عناوين URL، والتي سيتم توسيعها إلى مسارات يتم استبدالها مكان قائمة الحزم كوسيطات ملف_الحزمة إضافية للاستعلام.
--path مسار
استعلام عن الحزمة (الحزم) التي تمتلك مسار، سواء كان الملف مثبتًا أم لا. قد تمتلك حزم متعددة مسار، ولكن الملف مملوك فقط للحزمة المثبتة أخيرًا.
--pkgid MD5
استعلام عن الحزمة التي تحتوي على معرف حزمة معين، أي تجزئة MD5 لمحتويات الرأس والحمولة المجمعة.
--querybynumber رقم_الرأس
استعلام عن إدخال قاعدة البيانات رقم رقم_الرأس مباشرة؛ هذا مفيد للتصحيح فقط.
--specfile ملف_المواصفات
قم بتحليل والاستعلام عن ملف_المواصفات كما لو كان حزمة. على الرغم من أن المعلومات ليست كلها متاحة (مثل قوائم الملفات)، إلا أن هذا النوع من الاستعلام يسمح باستخدام rpm لاستخراج المعلومات من ملفات المواصفات دون الحاجة إلى كتابة محلل لملف المواصفات.
--tid معرف_المعاملة
استعلام عن الحزمة (الحزم) التي لها معرف معاملة معرف_المعاملة معين. يتم استخدام طابع زمني لـ UNIX حاليًا كمعرف معاملة. جميع الحزم (الحزم) المثبتة أو المحذوفة ضمن معاملة واحدة لها معرف مشترك.
--triggeredby اسم_الحزمة
استعلام عن الحزم التي يتم تشغيلها بواسطة الحزمة (الحزم) اسم_الحزمة.
--whatobsoletes قدرة
استعلام عن جميع الحزم التي تلغي (obsolete) قدرة لكي تعمل بشكل صحيح.
--whatprovides قدرة
استعلام عن جميع الحزم التي توفر القدرة قدرة.
--whatrequires قدرة
استعلام عن جميع الحزم التي تتطلب قدرة لكي تعمل بشكل صحيح.
--whatconflicts قدرة
استعلام عن جميع الحزم التي تتعارض مع قدرة.
--whatrecommends قدرة
استعلام عن جميع الحزم التي توصي بـ قدرة.
--whatsuggests قدرة
استعلام عن جميع الحزم التي تقترح قدرة.
--whatsupplements قدرة
استعلام عن جميع الحزم التي تكمل قدرة.
--whatenhances قدرة
استعلام عن جميع الحزم التي تعزز قدرة.

خيارات التحقق

الشكل العام لأمر rpm للتحقق هو

rpm {-V|--verify} [select-options] [verify-options]

يقارن التحقق من حزمة ما بين معلومات الملفات المثبتة في الحزمة والمعلومات المأخوذة من بيانات الحزمة الوصفية المخزنة في قاعدة بيانات rpm. من بين أمور أخرى، يقارن التحقق حجم كل ملف، والتلخيص، والأذونات، والنوع، والمالك، والمجموعة. يتم عرض أي اختلافات. يتم تجاهل الملفات التي لم يتم تثبيتها من الحزمة، على سبيل المثال، ملفات الوثائق المستبعدة عند التثبيت باستخدام الخيار "--excludedocs"، بصمت.

خيارات تحديد الحزم والملفات هي نفسها المستخدمة في استعلام الحزم (بما في ذلك ملفات بيان الحزم كوسائط). الخيارات الأخرى الفريدة لوضع التحقق هي:

--nodeps
لا تحقق من تبعيات الحزم.
--nodigest
لا تحقق من ملخصات الحزمة أو الرأس عند القراءة.
--nofiles
لا تحقق من أي سمات لملفات الحزمة.
--noscripts
لا تقم بتنفيذ برنامج نصي %verifyscript (إن وجد).
--nosignature
لا تحقق من توقيعات الحزمة أو الرأس عند القراءة.
--nolinkto
--nofiledigest (كان سابقًا --nomd5)
--nosize
--nomtime
--nomode
--nordev
لا تحقق من سمة الملف المقابلة.
--nouser
--nogroup
لا تحقق من ملكية المستخدم/المجموعة للملف. لاحظ أنه يتم استشارة قواعد بيانات passwd(5) و group(5) المحلية فقط.
--nocaps
لا تحقق من إمكانيات الملف.

تنسيق الإخراج عبارة عن سلسلة من 9 أحرف، وهي علامة سمة محتملة:

**a** %**a**rtifact ملف ناتج ثانوي للبناء (مثل روابط معرف البناء).
**c** %**c**onfig ملف تكوين.
**d** %**d**oc ملف وثائق.
**g** %**g**host ملف (أي أن محتويات الملف غير مضمنة في حمولة الحزمة).
**l** %**l**icense ملف ترخيص.
**m** %**m**issingok عدم وجود الملف ليس فشل تحقق.
**n** %%config(**n**oreplace) (عدم استبدال الملف).
**r** %**r**eadme ملف اقرأني.
**s** **s**pecfile في حزمة المصدر.

من رأس الحزمة، يتبعها اسم الملف. كل حرف من الأحرف التسعة يدل على نتيجة مقارنة سمة (أو سمات) الملف بقيمة تلك السمة (أو السمات) المسجلة في قاعدة البيانات. علامة النقطة (".") المفردة تعني أن الاختبار قد نجح، بينما علامة الاستفهام ("?") المفردة تشير إلى أنه لا يمكن إجراء الاختبار (على سبيل المثال، أذونات الملف تمنع القراءة). خلاف ذلك، فإن الحرف (المميز بخط عريض بشكل ذاكري) يدل على فشل اختبار --verify المقابل:

**S** حجم **S**file يختلف
**M** **M**ode يختلف (يشمل الأذونات ونوع الملف)
**5** تلخيص (سابقًا MD**5**) يختلف
**D** **D**evice لا يتطابق رقم الجهاز الرئيسي/الفرعي
**L** مسار read**L**ink(2) لا يتطابق
**U** ملكية **U**ser تختلف
**G** ملكية **G**roup تختلف
**T** وقت **T**ime يختلف
**P** ca**P**abilities تختلف

خيارات FTP/HTTP

يمكن لـ rpm العمل كعميل FTP و/أو HTTP بحيث يمكن استعلام الحزم أو تثبيتها من الإنترنت. يمكن تحديد ملفات الحزم لعمليات التثبيت والترقية والاستعلام كعنوان URL من نمط ftp أو http:

http://HOST[:PORT]/path/to/package.rpm

ftp://[USER:PASSWORD]@HOST[:PORT]/path/to/package.rpm

إذا تم حذف كل من المستخدم وكلمة المرور، يتم استخدام ftp للمجهول.

يسمح rpm باستخدام الخيارات التالية مع عناوين URL لـ ftp:

يسمح rpm باستخدام الخيارات التالية مع عناوين URL لـ http و ftp:

--httpproxy HOST
سيتم استخدام المضيف HOST كخادم وكيل لجميع عمليات نقل http و ftp. يمكن أيضًا تحديد هذا الخيار عن طريق تكوين الماكرو %_httpproxy.
--httpport PORT
رقم منفذ TCP PORT للاستخدام لاتصال http على خادم http الوكيل بدلاً من المنفذ الافتراضي. يمكن أيضًا تحديد هذا الخيار عن طريق تكوين الماكرو %_httpport.

مشاكل الإرث

تنفيذ rpmbuild

تقيم أوضاع البناء الخاصة بـ rpm الآن في الملف التنفيذي /usr/bin/rpmbuild. قم بتثبيت الحزمة التي تحتوي على rpmbuild (عادةً rpm-build) وانظر rpmbuild(8) للحصول على توثيق لجميع أوضاع بناء rpm.

الملفات

تكوين rpmrc

يتم قراءة كل ملف في مسار rpmrc المفصول بنقطتين رأسيتين (:) بشكل متسلسل بواسطة rpm للحصول على معلومات التكوين. يجب أن يكون الملف الأول في القائمة موجودًا، وسيتم توسيع علامات المد (\~) إلى قيمة $HOME. مسار rpmrc الافتراضي هو كالتالي:

/usr/lib/rpm/rpmrc:
/usr/lib/rpm//rpmrc:
/etc/rpmrc:
~/.config/rpm/rpmrc

إذا تم تعيين متغير البيئة XDG_CONFIG_HOME، فإنه يستبدل ~/.config في المسار.

في إصدارات rpm الأقدم، كان مسار rpmrc الخاص بالمستخدم هو ~/.rpmrc. لا يزال هذا يعالج إذا كان موجودًا ولم يكن دليل التكوين الجديد موجودًا.

تكوين الماكرو

يتم قراءة كل ملف أو نمط glob(7) في مسار الماكرو المفصول بنقطتين رأسيتين (:) بشكل متسلسل بواسطة rpm لتعريفات الماكرو. سيتم توسيع علامات المد (\~) إلى قيمة متغير البيئة HOME. مسار الماكرو الافتراضي هو كالتالي:

/usr/lib/rpm/macros:
/usr/lib/rpm/macros.d/macros.*:
/usr/lib/rpm/platform/%{_target}/macros:
/usr/lib/rpm/fileattrs/*.attr:
/usr/lib/rpm//macros:
/etc/rpm/macros.*:
/etc/rpm/macros:
/etc/rpm/%{_target}/macros:
~/.config/rpm/macros

إذا تم تعيين متغير البيئة XDG_CONFIG_HOME، فإنه يستبدل ~/.config في المسار.

في الإصدارات القديمة من rpm، كان مسار وحدات الماكرو الخاصة بالمستخدم هو ~/.rpmmacros. لا يزال هذا يعالج إذا كان موجودًا ولم يكن دليل التكوين الجديد موجودًا.
