riscv64-linux-gnu-size(1)

الحزمة: riscv64-linux-gnu-binutils

التراخيص: GPL-2.0-or-later

SIZE(1) أدوات تطوير GNU SIZE(1)

اسم

size - يسرد أحجام الأقسام والحجم الإجمالي للملفات الثنائية

ملخص

size [-A|-B|-G|--format=compatibility]
[--help]
[-d|-o|-x|--radix=number]
[--common]
[-t|--totals]
[--target=bfdname] [-V|--version]
[-f]
[objfile...]

الوصف

يقوم أداة size الخاصة بـ GNU بسرد أحجام الأقسام والحجم الإجمالي لكل من الملفات الثنائية objfile في قائمة وسائطها. افتراضيًا، يتم إنشاء سطر إخراج واحد لكل ملف أو لكل وحدة نمطية إذا كان الملف أرشيفًا.

objfile... هي الملفات التي سيتم فحصها. إذا لم يتم تحديد أي ملفات، فسيتم استخدام الملف "a.out" بدلاً من ذلك.

خيارات

خيارات سطر الأوامر لها المعاني التالية:

-A
-B
-G
--format=compatibility
باستخدام أحد هذه الخيارات، يمكنك اختيار ما إذا كان الإخراج من GNU size يشبه الإخراج من System V size (باستخدام -A، أو --format=sysv)، أو Berkeley size (باستخدام -B، أو --format=berkeley). الافتراضي هو تنسيق السطر الواحد الذي يشبه تنسيق Berkeley. بدلاً من ذلك، يمكنك اختيار إخراج تنسيق GNU (باستخدام -G، أو --format=gnu)، وهذا يشبه تنسيق الإخراج لـ Berkeley، ولكن يتم حساب الأحجام بشكل مختلف.

هذا مثال على تنسيق Berkeley (الافتراضي) للإخراج من size:

$ size --format=Berkeley ranlib size
   text    data     bss     dec     hex filename
 294880   81920   11592  388392   5ed28 ranlib
 294880   81920   11888  388688   5ee50 size

يحسب إخراج نمط Berkeley البيانات للقراءة فقط في عمود "text"، وليس في عمود "data"، ويعرض كل من عمود "dec" و "hex" مجموع أعمدة "text" و "data" و "bss" بالصيغة العشرية و السداسية عشرية على التوالي.

يحسب تنسيق GNU البيانات للقراءة فقط في عمود "data"، وليس في عمود "text"، ويعرض فقط مجموع أعمدة "text" و "data" و "bss" مرة واحدة، في عمود "total". يمكن استخدام الخيار --radix لتغيير قاعدة الأرقام لجميع الأعمدة. هذا هو نفس البيانات المعروضة باتباع اتفاقيات GNU:

$ size --format=GNU ranlib size
      text       data        bss      total filename
    279880      96920      11592     388392 ranlib
    279880      96920      11888     388688 size

هذه هي نفس البيانات، ولكنها معروضة بشكل أقرب إلى اتفاقيات System V:

$ size --format=SysV ranlib size
ranlib  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11592       385024
Total         388392


size  :
section         size         addr
.text         294880         8192
.data          81920       303104
.bss           11888       385024
Total         388688
--help
-h
-H
-?
عرض ملخص للحجج والخيارات المقبولة.
-d
-o
-x
--radix=number
باستخدام أحد هذه الخيارات، يمكنك التحكم فيما إذا كان حجم كل قسم يتم تقديمه بالصيغة العشرية (-d، أو --radix=10)؛ الثمانية (-o، أو --radix=8)؛ أو السداسية عشرية (-x، أو --radix=16). في --radix=number، يتم دعم القيم الثلاث فقط (8، 10، 16). يتم دائمًا تقديم الحجم الإجمالي في قاعدتين؛ عشرية وسداسية عشرية لإخراج -d أو -x، أو ثمانية وسداسية عشرية إذا كنت تستخدم -o.
--common
طباعة الحجم الإجمالي للرموز المشتركة في كل ملف. عند استخدام تنسيق Berkeley أو GNU، يتم تضمين هذه الرموز في حجم bss.
-t
--totals
عرض إجمالي جميع الكائنات المدرجة (في وضع تنسيق Berkeley أو GNU فقط).
--target=bfdname
تحديد أن تنسيق كود الكائن لـ objfile هو bfdname. قد لا يكون هذا الخيار ضروريًا؛ يمكن لـ size التعرف تلقائيًا على العديد من التنسيقات.
-v
-V
--version
عرض رقم إصدار size.
-f
تم التجاهل. يتم استخدام هذا الخيار بواسطة إصدارات أخرى من برنامج size، ولكنه غير مدعوم من قبل إصدار GNU Binutils.
@file
قراءة خيارات سطر الأوامر من file. يتم إدراج الخيارات المقروءة في مكان خيار @file الأصلي. إذا كان file غير موجود، أو لا يمكن قراءته، فسيتم التعامل مع الخيار حرفيًا، ولن يتم إزالته.

يتم فصل الخيارات في file بمسافات بيضاء. يمكن تضمين حرف مسافة بيضاء في خيار عن طريق إحاطة الخيار بأكمله بعلامات اقتباس مفردة أو مزدوجة. يمكن تضمين أي حرف (بما في ذلك الشرطة المائلة العكسية) عن طريق وضع البادئة للحرف المراد تضمينه بشرطة مائلة عكسية. قد يحتوي file نفسه على خيارات @file إضافية؛ سيتم معالجة أي خيارات من هذا القبيل بشكل متكرر.

راجع أيضًا

ar(1), objdump(1), readelf(1)، ومدخلات Info لـ binutils.
