NAME

rizin

the rizin file analysis and reverse engineering framework

SYNOPSIS

rizin [-|--] [-A|--analyze] [-a arch] [-b bits] [-c cmd] [-C] [-d|--debug] [-D dbg-flags] [-e flag] [-f format] [-F file] [-g file] [-H arch] [-i file] [-I file] [-j|--json] [-k key] [-K key] [-L] [-m dir] [-M dir] [-n|--no-editor] [-N] [-O file] [-p perm] [-P file] [-q|--quiet] [-Q] [-r file] [-R] [-s section] [-S|--strings] [-t type] [-T file] [-u|--un ascii] [-U] [-v|--version] [-w|--write] [-x] [-X] [-y] [--] [file] [args...]

DESCRIPTION

Rizin is a free and open-source reverse engineering framework that allows you to disassemble, analyze, debug, and modify binaries.

Rizin is a fork of radare2. It aims to provide a stable and powerful environment for reverse engineers.

This manual page describes the main rizin command and its common options. For a full list of commands and features, refer to the official Rizin documentation.

OPTIONS

-A, --analyze
Perform an analysis of the given file. This includes detecting the architecture, bits, endianness, and finding functions, strings, and other useful information.
-a arch
Set the architecture. Example: rizin -a arm file
-b bits
Set the number of bits. Example: rizin -b 64 file
-c cmd
Execute a single rizin command. This is useful for scripting and automation.
-C
Count occurrences of instructions. This can be useful for analyzing code density.
-d, --debug
Start rizin in debug mode. This allows you to debug the specified executable.
-D dbg-flags
Set debugger flags. See rizin-dbg(1) for more information.
-e flag
Set a flag. Flags are used to mark specific locations in the binary.
-f format
Specify the file format. Rizin usually detects this automatically.
-F file
Load a file for patch analysis. This is useful for comparing two binaries.
-g file
Start rizin with gdb server enabled. Useful for remote debugging.
-H arch
Set the hardcoded architecture. This overrides automatic detection.
-i file
Specify an input file. Equivalent to providing the file as the last argument.
-I file
Include a file. This can be used to load scripts or configuration files.
-j, --json
Output results in JSON format. Useful for programmatic access.
-k key
Set a configuration key. Equivalent to using the 'e' command in rizin.
-K key
Set a configuration key from a file.
-L
List all available plugins and their versions.
-m dir
Set the library path for plugins and modules.
-M dir
Set the metadata path.
-n, --no-editor
Do not open the editor after loading the file. This means rizin will drop you to the command line immediately.
-N
Do not load configuration files. This starts rizin with default settings.
-O file
Specify an output file for saving changes. Use with caution.
-p perm
Set the initial permissions for a file. Example: rizin -p r2 file
-P file
Open a file in patch mode. This allows you to modify the file.
-q, --quiet
Run rizin in quiet mode, suppressing most output.
-Q
Quit rizin immediately after loading the file. Useful in conjunction with other commands.
-r file
Specify a user configuration file to load.
-R
Print the rizin banner and exit.
-s section
Seek to the specified section. Example: rizin -s .text file
-S, --strings
Find and display strings in the file.
-t type
Specify the file type. Rizin usually detects this automatically.
-T file
Load a trace file. This can be used to analyze execution flow.
-u, --un ascii
Treat the file as non-ASCII data.
-U
Show the rizin update banner and exit.
-v, --version
Show rizin version information and exit.
-w, --write
Open the file in write mode, allowing modifications.
-x
Open the file in hex-dump mode.
-X
Perform a quick analysis and exit.
-y
Perform a deep analysis and exit.

ENVIRONMENT

RZ_PIPE_IN
rzpipe cmd input (file descriptor)
RZ_PIPE_OUT
rzpipe cmd output (file descriptor)
RZ_PREFIX
default prefix rizin was compiled for
RZ_RCFILE
user config file
SFLIBPATH
SFLib syscall library path

EXAMPLE

Start rizin in analysis mode (-A) on the /bin/ls executable:

rizin -A /bin/ls

Open the file /bin/ls in write mode, allowing you to make changes to the binary:

rizin -w /bin/ls

Start rizin's debugger (-d) on /bin/ls and passes arguments "-l" and "/tmp" to the program for debugging:

rizin -d /bin/ls -l /tmp

الاسم

rizin

إطار عمل تحليل الملفات والهندسة العكسية rizin

الملخص

rizin [-|--] [-A|--analyze] [-a arch] [-b bits] [-c cmd] [-C] [-d|--debug] [-D dbg-flags] [-e flag] [-f format] [-F file] [-g file] [-H arch] [-i file] [-I file] [-j|--json] [-k key] [-K key] [-L] [-m dir] [-M dir] [-n|--no-editor] [-N] [-O file] [-p perm] [-P file] [-q|--quiet] [-Q] [-r file] [-R] [-s section] [-S|--strings] [-t type] [-T file] [-u|--un ascii] [-U] [-v|--version] [-w|--write] [-x] [-X] [-y] [--] [file] [args...]

الوصف

Rizin هو إطار عمل مجاني ومفتوح المصدر للهندسة العكسية يسمح لك بتفكيك وتحليل وتصحيح وتعديل الملفات التنفيذية.

Rizin هو تشعب من radare2. يهدف إلى توفير بيئة مستقرة وقوية للمهندسين العكسيين.

تصف صفحة الدليل هذه الأمر الرئيسي rizin وخياراته الشائعة. للحصول على قائمة كاملة بالأوامر والميزات، ارجع إلى وثائق Rizin الرسمية.

خيارات

-A, --analyze
قم بتحليل الملف المحدد. يشمل ذلك اكتشاف البنية (architecture)، وعدد البتات (bits)، والترتيب البايتي (endianness)، والعثور على الوظائف والسلاسل النصية وغيرها من المعلومات المفيدة.
-a arch
تحديد البنية. مثال: rizin -a arm file
-b bits
تحديد عدد البتات. مثال: rizin -b 64 file
-c cmd
تنفيذ أمر rizin واحد. هذا مفيد للنصوص البرمجية (scripting) والأتمتة.
-C
عد تكرارات التعليمات. يمكن أن يكون هذا مفيدًا لتحليل كثافة التعليمات.
-d, --debug
بدء rizin في وضع التصحيح. هذا يسمح لك بتصحيح الملف التنفيذي المحدد.
-D dbg-flags
تعيين علامات مصحح الأخطاء (debugger flags). انظر rizin-dbg(1) لمزيد من المعلومات.
-e flag
تعيين علامة (flag). تُستخدم العلامات لوضع علامات على مواقع محددة في الملف الثنائي.
-f format
تحديد تنسيق الملف. عادةً ما يكتشف Rizin هذا تلقائيًا.
-F file
تحميل ملف لتحليل التعديلات. هذا مفيد لمقارنة ملفين ثنائيين.
-g file
بدء rizin مع تمكين خادم gdb. مفيد للتصحيح عن بعد.
-H arch
تعيين البنية الثابتة. هذا يتجاوز الاكتشاف التلقائي.
-i file
تحديد ملف إدخال. يعادل توفير الملف كوسيط أخير.
-I file
تضمين ملف. يمكن استخدام هذا لتحميل البرامج النصية أو ملفات التكوين.
-j, --json
إخراج النتائج بتنسيق JSON. مفيد للوصول البرمجي.
-k key
تعيين مفتاح تكوين. يعادل استخدام الأمر 'e' في rizin.
-K key
تعيين مفتاح تكوين من ملف.
-L
قائمة بجميع المكونات الإضافية المتاحة وإصداراتها.
-m dir
تعيين مسار المكتبة للمكونات الإضافية والوحدات.
-M dir
تعيين مسار البيانات الوصفية (metadata).
-n, --no-editor
لا تفتح المحرر بعد تحميل الملف. هذا يعني أن rizin سيقوم بإعادتك إلى سطر الأوامر فورًا.
-N
لا تقم بتحميل ملفات التكوين. هذا يبدأ rizin بالإعدادات الافتراضية.
-O file
تحديد ملف إخراج لحفظ التغييرات. استخدم بحذر.
-p perm
تعيين الأذونات الأولية للملف. مثال: rizin -p r2 file
-P file
فتح ملف في وضع التعديل (patch mode). هذا يسمح لك بتعديل الملف.
-q, --quiet
تشغيل rizin في الوضع الهادئ، مما يمنع معظم المخرجات.
-Q
الخروج من rizin فورًا بعد تحميل الملف. مفيد بالاقتران مع الأوامر الأخرى.
-r file
تحديد ملف تكوين مستخدم ليتم تحميله.
-R
طباعة شعار rizin والخروج.
-s section
الانتقال إلى القسم المحدد. مثال: rizin -s .text file
-S, --strings
العثور على السلاسل النصية في الملف وعرضها.
-t type
تحديد نوع الملف. عادةً ما يكتشف Rizin هذا تلقائيًا.
-T file
تحميل ملف تتبع (trace file). يمكن استخدام هذا لتحليل تدفق التنفيذ.
-u, --un ascii
معاملة الملف كبيانات غير ASCII.
-U
عرض شعار تحديث rizin والخروج.
-v, --version
عرض معلومات إصدار rizin والخروج.
-w, --write
فتح الملف في وضع الكتابة، مما يسمح بالتعديلات.
-x
فتح الملف في وضع العرض السداسي العشري (hex-dump mode).
-X
إجراء تحليل سريع والخروج.
-y
إجراء تحليل عميق والخروج.

البيئة

RZ_PIPE_IN
مدخلات أوامر rzpipe (واصف الملف)
RZ_PIPE_OUT
مخرجات أوامر rzpipe (واصف الملف)
RZ_PREFIX
البادئة الافتراضية التي تم تجميع rizin بها
RZ_RCFILE
ملف تكوين المستخدم
SFLIBPATH
مسار مكتبة استدعاءات النظام SFLib

مثال

بدء rizin في وضع التحليل (-A) على الملف التنفيذي /bin/ls:

rizin -A /bin/ls

فتح الملف /bin/ls في وضع الكتابة، مما يسمح لك بإجراء تغييرات على الملف الثنائي:

rizin -w /bin/ls

بدء مصحح الأخطاء (-d) الخاص بـ rizin على /bin/ls وتمرير الوسائط "-l" و "/tmp" إلى البرنامج لتصحيحه:

rizin -d /bin/ls -l /tmp
