التراخيص: Apache

rtcSetGeometryBoundsFunction(3) Embree Ray Tracing Kernels 3 rtcSetGeometryBoundsFunction(3)

الاسم

rtcSetGeometryBoundsFunction - تعيين دالة استدعاء للاستعلام عن
  الصندوق المحيط للبدائيات المعرفة من قبل المستخدم

الملخص

#include <embree3/rtcore.h>
struct RTCBoundsFunctionArguments
{
  void* geometryUserPtr;
  unsigned int primID;
  unsigned int timeStep;
  struct RTCBounds* bounds_o;
};
typedef void (*RTCBoundsFunction)(
  const struct RTCBoundsFunctionArguments* args
);
void rtcSetGeometryBoundsFunction(
  RTCGeometry geometry,
  RTCBoundsFunction bounds,
  void* userPtr
);

الوصف

تقوم دالة rtcSetGeometryBoundsFunction بتسجيل دالة استدعاء للصندوق المحيط (الوسيط bounds) مع حمولة (الوسيط userPtr) للهندسة المعرفة من قبل المستخدم (الوسيط geometry).

يمكن تسجيل دالة استدعاء واحدة فقط لكل هندسة، وستقوم الاستدعاءات اللاحقة بالكتابة فوق دالة الاستدعاء المعينة سابقًا. تمرير NULL كعنوان دالة يعطل دالة الاستدعاء المسجلة.

يتم استدعاء دالة استدعاء الصندوق المحيط المسجلة لحساب الصناديق المحيطة المحاذية للمحاور للبدائيات للهندسة المعرفة من قبل المستخدم أثناء بناء بنية التسريع المكاني. يتم استدعاء استدعاء الصندوق المحيط من نوع RTCBoundsFunction مع مؤشر إلى هيكل من نوع RTCBoundsFunctionArguments يحتوي على وسائط مختلفة، مثل: بيانات المستخدم للهندسة (عضو geometryUserPtr)، ومعرف البدائي لحساب الحدود له (عضو primID)، وخطوة الوقت لحساب الحدود (عضو timeStep)، وموقع ذاكرة لكتابة الحد المحسوب إليه (عضو bounds_o).

في سيناريو استخدام نموذجي، يمكنك تخزين مؤشر إلى التمثيل الداخلي لكائن الهندسة المستخدمة باستخدام rtcSetGeometryUserData. يمكن لدالة الاستدعاء بعد ذلك قراءة هذا المؤشر من حقل geometryUserPtr وحساب الصندوق المحيط المناسب للبدائي والوقت المطلوبين، وتخزين هذا الصندوق المحيط في الهيكل الوجهة (عضو bounds_o).

حالة الخروج

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.
