NAME

rz-run - A command to run scripts in Rizin

SYNOPSIS

rz-run [options] [file...]

DESCRIPTION

rz-run is a command-line tool that allows you to execute scripts written in Rizin's scripting language. These scripts can be used to automate tasks, perform analysis, and interact with the Rizin debugger.

DIRECTIVES

rz-run supports various directives that control its behavior and the execution of scripts. Some common directives include:

  • -f, --file: Specify the script file to execute.
  • -s, --script: Provide a script directly as a string.
  • -d, --debug: Enable debug output for the script execution.
  • -i, --interactive: Run in interactive mode, allowing commands to be entered manually.
  • -p, --project: Specify a Rizin project file to load.
  • -q, --quiet: Suppress output from the script.
  • -v, --verbose: Increase the verbosity of output.

VALUE PREFIXES

The Rizin scripting language uses prefixes to denote different data types and bases:

  • 0x: Hexadecimal
  • 0b: Binary
  • 0o: Octal
  • 0t: Ternary
  • 0d: Decimal (default)

EXAMPLES

Here are a few examples of how to use rz-run:

# Execute a script file named 'my_script.rzs'
rz-run -f my_script.rzs

# Execute a script directly
rz-run -s "pi @ entrypoint; ps @ rip;"

# Run in interactive mode
rz-run -i

# Load a project and execute a script
rz-run -p my_project.rzp -f analyze.rzs
