RSA_sign(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

RSA_SIGN(3ssl) OpenSSL RSA_SIGN(3ssl)

الاسم

RSA_sign, RSA_verify - توقيعات RSA

الاختصار

#include <openssl/rsa.h>

تم إيقاف الدوال التالية اعتبارًا من OpenSSL 3.0، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

int RSA_sign(int type, const unsigned char *m, unsigned int m_len,
             unsigned char *sigret, unsigned int *siglen, RSA *rsa);
int RSA_verify(int type, const unsigned char *m, unsigned int m_len,
               unsigned char *sigbuf, unsigned int siglen, RSA *rsa);

الوصف

تم إيقاف جميع الدوال الموصوفة في هذه الصفحة. يجب على التطبيقات استخدام EVP_PKEY_sign_init(3) و EVP_PKEY_sign(3) و EVP_PKEY_verify_init(3) و EVP_PKEY_verify(3) بدلاً من ذلك.

تقوم RSA_sign() بتوقيع تلخيص الرسالة m بحجم m_len باستخدام المفتاح الخاص rsa باستخدام RSASSA-PKCS1-v1_5 كما هو محدد في RFC 3447. تقوم بتخزين التوقيع في sigret وحجم التوقيع في siglen. يجب أن يشير sigret إلى ذاكرة بحجم RSA_size(rsa). لاحظ أن PKCS #1 يضيف بيانات وصفية، مما يضع قيودًا على حجم المفتاح الذي يمكن استخدامه. انظر RSA_private_encrypt(3) لعمليات ذات مستوى أدنى.

يشير type إلى خوارزمية تلخيص الرسالة التي تم استخدامها لإنشاء m. إذا كان type هو NID_md5_sha1، يتم إنشاء توقيع SSL (تلاخيص MD5 و SHA1 مع حشو PKCS #1 وبدون معرف خوارزمية).

تقوم RSA_verify() بالتحقق من أن التوقيع sigbuf بحجم siglen يتطابق مع تلخيص الرسالة المعطى m بحجم m_len. يشير type إلى خوارزمية تلخيص الرسالة التي تم استخدامها لإنشاء التوقيع. rsa هو المفتاح العام للموقّع.

قيم الإرجاع

ترجع RSA_sign() القيمة 1 عند النجاح و 0 عند الفشل. ترجع RSA_verify() القيمة 1 عند التحقق الناجح و 0 عند الفشل.

يمكن الحصول على رموز الخطأ عن طريق ERR_get_error(3).

متوافق مع

SSL، PKCS #1 v2.0

انظر أيضًا

ERR_get_error(3)، RSA_private_encrypt(3)، RSA_public_decrypt(3)
