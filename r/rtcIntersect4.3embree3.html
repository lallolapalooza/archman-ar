الحزمة: embree3

التراخيص: Apache

rtcIntersect4/8/16(3) Embree Ray Tracing Kernels 3 rtcIntersect4/8/16(3)

الاسم

rtcIntersect4/8/16 - يجد أقرب الاصطدامات لحزمة أشعة

الملخص

#include <embree3/rtcore.h>
void rtcIntersect4(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit4* rayhit
);
void rtcIntersect8(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit8* rayhit
);
void rtcIntersect16(
  const int* valid,
  RTCScene scene,
  struct RTCIntersectContext* context,
  struct RTCRayHit16* rayhit
);

الوصف

تبحث الدوال rtcIntersect4/8/16 عن أقرب الاصطدامات لحزمة أشعة بحجم 4 أو 8 أو 16 (المعامل rayhit) مع المشهد (المعامل scene). يحتوي إدخال الأشعة/الاصطدامات على حزمة أشعة وحزمة اصطدامات. راجع القسم [rtcIntersect1] لوصف كيفية إعداد وتتبع الأشعة.

يجب توفير قناع صلاحية للأشعة (المعامل valid) والذي يخزن عددًا صحيحًا بـ 32 بت (-1 يعني صالح و 0 غير صالح) لكل شعاع في الحزمة. تتم معالجة الأشعة النشطة فقط، ولا يتم تغيير بيانات الاصطدام للأشعة غير النشطة.

يُضمن تنفيذ هذه الدوال استدعاء دوال الاستدعاء العكسي دائمًا بنفس حجم حزمة الأشعة وترتيب الأشعة كما هو محدد في البداية.

بالنسبة لـ rtcIntersect4، يجب أن تكون حزمة الأشعة محاذاة إلى 16 بايت، وبالنسبة لـ rtcIntersect8، يجب أن تكون المحاذاة 32 بايت، وبالنسبة لـ rtcIntersect16، يجب أن تكون المحاذاة 64 بايت.

قد تقوم الدوال rtcIntersect4 و rtcIntersect8 و rtcIntersect16 بتغيير حجم حزمة الأشعة وترتيب الأشعة عند الاستدعاء إلى دوال تصفية الأشعة أو دوال الهندسة الخاصة بالمستخدم. تحت بعض الظروف، يمكن للتطبيق افتراض أن الحزم ستظل سليمة، والتي يمكن تحديدها عن طريق الاستعلام عن خصائص RTC_DEVICE_PROPERTY_NATIVE_RAY4_SUPPORTED و RTC_DEVICE_PROPERTY_NATIVE_RAY8_SUPPORTED و RTC_DEVICE_PROPERTY_NATIVE_RAY16_SUPPORTED من خلال الدالة rtcGetDeviceProperty. راجع [rtcGetDeviceProperty] لمزيد من المعلومات.
