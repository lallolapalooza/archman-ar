RDMA-SYSTEM(8) Linux RDMA-SYSTEM(8)

الاسم

rdma-system - تكوين نظام RDMA الفرعي

الملخص


rdma [ خيارات ] sys { أمر | help }

خيارات := { -V[ersion] | -d[etails] }

rdma system show

rdma system set netns NEWMODE

rdma system set privileged-qkey NEWSTATE

rdma system help

الوصف

rdma system set - تعيين وضع مساحة اسم شبكة نظام RDMA الفرعي أو

وضع qkey مميز

rdma system show - عرض وضع مساحة اسم شبكة نظام RDMA الفرعي،

حالة qkey المميزة وما إذا كان رصد RDMA مدعومًا.

NEWMODE - يحدد وضع نظام RDMA الفرعي. إما حصري أو مشترك. عندما يريد المستخدم تعيين جهاز RDMA مخصص لمساحة اسم شبكة معينة، يجب تعيين الوضع الحصري قبل إنشاء أي مساحة اسم شبكة. إذا كانت هناك مساحات اسم شبكة نشطة وإذا كان هناك جهاز RDMA واحد أو أكثر موجودًا، فإن تغيير الوضع من مشترك إلى حصري يعيد رمز الخطأ EBUSY.

عندما يكون نظام RDMA الفرعي في وضع مشترك، يمكن الوصول إلى جهاز RDMA في جميع مساحات أسماء الشبكة. عندما لا تكون هناك حاجة لعزل جهاز RDMA بين مساحات أسماء شبكات متعددة، يمكن استخدام الوضع المشترك.

يفضل عدم تغيير وضع النظام الفرعي عندما يكون هناك حركة مرور RDMA نشطة قيد التشغيل، على الرغم من أنه مدعوم.

NEWSTATE - يحدد الحالة الجديدة لمعلمة privileged-qkey، إما التشغيل أو الإيقاف. تحدد هذه المعلمة ما إذا كان يُسمح للمستخدم غير المميز بتحديد QKEY مضبوط أم لا.

أمثلة

rdma system show

يعرض حالة وضع مساحة اسم شبكة نظام RDMA الفرعي على النظام، وحالة معلمة qkey المميزة، وما إذا كان مراقب RDMA مدعومًا.

rdma system set netns exclusive

يعين نظام RDMA الفرعي في وضع مساحة اسم شبكة حصري. في هذا الوضع، تكون أجهزة RDMA مرئية فقط في مساحة اسم شبكة واحدة.

rdma system set netns shared

يعين نظام RDMA الفرعي في وضع مساحة اسم شبكة مشترك. في هذا الوضع، تكون أجهزة RDMA مشتركة بين مساحات أسماء الشبكات.

rdma system set privileged-qkey on

يعين معلمة privileged-qkey على التشغيل. في هذه الحالة، يُسمح للمستخدم غير المميز بتحديد QKEY مضبوط.

rdma system set privileged-qkey off

يعين معلمة privileged-qkey على الإيقاف. في هذه الحالة، لا يُسمح للمستخدم غير المميز بتحديد QKEY مضبوط.
