DESCRIPTION

These routines provide a mechanism for handling RPC service errors. They allow you to insert, dequeue, list, and count error messages. You can also get and set various fields related to the RPC error, such as status, version, caller, program, procedure, reply message, and the error code itself.

rpc_svc_err_insert: Inserts an error message into the error queue.

rpc_svc_err_dequeue: Removes and returns the oldest error message from the queue.

rpc_svc_err_list: Lists all error messages currently in the queue.

rpc_svc_err_count: Returns the number of error messages in the queue.

rpc_svc_err_get_status: Gets the current RPC status.

rpc_svc_err_set_status: Sets the current RPC status.

rpc_svc_err_get_vers: Gets the RPC version.

rpc_svc_err_set_vers: Sets the RPC version.

rpc_svc_err_get_caller: Gets the caller's RPC message.

rpc_svc_err_set_caller: Sets the caller's RPC message.

rpc_svc_err_get_prog: Gets the RPC program number.

rpc_svc_err_set_prog: Sets the RPC program number.

rpc_svc_err_get_proc: Gets the RPC procedure number.

rpc_svc_err_set_proc: Sets the RPC procedure number.

rpc_svc_err_get_reply_msg: Gets the reply message.

rpc_svc_err_set_reply_msg: Sets the reply message.

rpc_svc_err_get_error: Gets the RPC error code.

rpc_svc_err_set_error: Sets the RPC error code.

Routines

The following routines are available:

rpc_svc_err_insert(), rpc_svc_err_dequeue(), rpc_svc_err_list(), rpc_svc_err_count() manage the RPC error queue.

rpc_svc_err_get_status() and rpc_svc_err_set_status() manage the RPC status.

rpc_svc_err_get_vers() and rpc_svc_err_set_vers() manage the RPC version.

rpc_svc_err_get_caller() and rpc_svc_err_set_caller() manage the caller's RPC message.

rpc_svc_err_get_prog() and rpc_svc_err_set_prog() manage the RPC program number.

rpc_svc_err_get_proc() and rpc_svc_err_set_proc() manage the RPC procedure number.

rpc_svc_err_get_reply_msg() and rpc_svc_err_set_reply_msg() manage the reply message.

rpc_svc_err_get_error() and rpc_svc_err_set_error() manage the RPC error code.
