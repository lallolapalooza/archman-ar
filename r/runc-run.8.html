runc-run(8)

الحزمة: runc

التراخيص: Apache

runc-run(8) دليل مدير النظام runc-run(8)

الاسم

runc run - إنشاء وبدء حاوية

ملخص

runc run [خيار ...] معرّف-الحاوية

الوصف

يقوم الأمر run بإنشاء مثيل لحاوية من حزمة، ويبدأها. يمكنك اعتبار run اختصارًا للأمرين create متبوعًا بـ start.

الخيارات

--bundle|-b مسار
مسار جذر دليل الحزمة. الافتراضي هو الدليل الحالي.
--console-socket مسار
مسار لمقبس AF_UNIX سيستقبل واصف ملف يشير إلى النهاية الرئيسية لمحطة الحواسيب الطرفية الافتراضية. انظر docs/terminals ⟨https://github.com/opencontainers/runc/blob/master/docs/terminals.md⟩.
--detach|-d
الانفصال عن عملية الحاوية.
--pid-file مسار
تحديد الملف لكتابة معرف العملية (PID) الخاص بعملية الحاوية الأولية إليه.
--no-subreaper
تعطيل استخدام التابع الفرعي (subreaper) لإعادة تجميع العمليات التي تم إعادة توجيهها.
--no-pivot
لا تستخدم pivot root لتقييد العملية داخل جذر نظام الملفات (rootfs). يجب عدم استخدام هذا إلا في ظروف استثنائية، وقد يكون غير آمن من ناحية الأمان.
--no-new-keyring
لا تنشئ سلسلة مفاتيح جلسة جديدة للحاوية. سيؤدي ذلك إلى وراثة الحاوية لمفتاح الجلسة الخاص بالعمليات المستدعاة.
--preserve-fds N
تمرير N واصفات ملف إضافية إلى الحاوية (stdio + $LISTEN_FDS + N إجمالاً). الافتراضي هو 0.
--keep
احتفظ بدليل حالة الحاوية ووحدة التحكم في المجموعة (cgroup). يمكن أن يكون هذا مفيدًا إذا أراد المستخدم التحقق من الحالة (على سبيل المثال، وحدات التحكم في cgroup) بعد انتهاء الحاوية. إذا تم استخدام هذا الخيار، فستحتاج إلى تشغيل runc delete يدويًا بعد ذلك لتنظيف آثار الحاوية المنتهية.
