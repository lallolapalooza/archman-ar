الحزمة: embree

التراخيص: Apache

rtcSetGeometryTransform(3) Embree Ray Tracing Kernels 4 rtcSetGeometryTransform(3)

الاسم

rtcSetGeometryTransform - يضبط التحويل لخطوة زمنية معينة لهندسة النسخة

الملخص

#include <embree4/rtcore.h>
void rtcSetGeometryTransform(
  RTCGeometry geometry,
  unsigned int timeStep,
  enum RTCFormat format,
  const float* xfm
);

الوصف

تقوم الدالة `rtcSetGeometryTransform` بضبط التحويل المماثل (المحلي إلى العالمي) (المعلمة `xfm`) لهندسة النسخة (المعلمة `geometry`) لخطوة زمنية معينة (المعلمة `timeStep`). يتم تحديد التحويل كمصفوفة 3x4 (تحويل خطي 3x3 بالإضافة إلى الإزاحة)، والتي تدعم التنسيقات التالية (المعلمة `format`):

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: يتم ترتيب مصفوفة floats 3x4 بشكل رئيسي للصفوف.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: يتم ترتيب مصفوفة floats 3x4 بشكل رئيسي للأعمدة.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: يتم ترتيب مصفوفة floats 3x4 بشكل رئيسي للأعمدة كمصفوفة متجانسة 4x4 مع كون الصف الأخير مساويًا لـ (0، 0، 0، 1).

حالة الخروج

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام `rtcGetDeviceError`.
