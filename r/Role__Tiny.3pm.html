Role__Tiny(3pm)

الحزمة: perl-role-tiny

التراخيص: PerlArtistic, GPL

Role::Tiny(3) وثائق الحزم المساهمة في Perl Role::Tiny(3)

الاسم

Role::Tiny - أدوار: جزء بحجم طبق جديد من Moose

الملخص

package Some::Role;
use Role::Tiny;
sub foo { ... }
sub bar { ... }
around baz => sub { ... };
1;

في مكان آخر

package Some::Class;
use Role::Tiny::With;
# يتم استيراد bar، ولكن ليس foo
with 'Some::Role';
sub foo { ... }
# يتم تغليف baz في معدّل around بواسطة Class::Method::Modifiers
sub baz { ... }
1;

إذا كنت تريد سمات أيضًا، فانظر Moo::Role.

الوصف

Role::Tiny هي أداة تركيب أدوار بسيطة.

تركيب الأدوار

يمكن التفكير في تركيب الأدوار على أنه أذكى وأكثر دلالة من الوراثة المتعددة. التنفيذ الأساسي للأدوار هو:

  • إذا تم تعريف طريقة بالفعل في فئة، فلن يتم تركيب هذه الطريقة من الدور. يتم استبدال طريقة موروثة بواسطة فئة بنفس الاسم بطريقة الدور.
  • إذا فشل تطبيق الدور في تنفيذ طريقة يتطلب الدور تنفيذها، فسيفشل تطبيق الدور برسالة واضحة.

بخلاف Class::C3، حيث تفوز الفئة الموروثة الأخيرة، فإن تركيب الأدوار هو الطريقة الأخرى، حيث تفوز الفئة. إذا تم تطبيق أدوار متعددة في استدعاء واحد (عبارة `with` واحدة)، وكان هناك تعارض بين طرقها، فسيتم طرح استثناء، ما لم توفر الفئة طريقة، لأن هذا التعارض يشير إلى مشكلة محتملة.

طرق الأدوار

تعتبر جميع الدوال الفرعية التي تم إنشاؤها بعد استيراد Role::Tiny طرقًا لتركيبها. على سبيل المثال:

package MyRole;
use List::Util qw(min);
sub mysub { }
use Role::Tiny;
use List::Util qw(max);
sub mymethod { }

في هذا الدور، يتم تضمين "max" و "mymethod" عند تركيب MyRole، بينما لا يتم تضمين "min" و "mysub". لمزيد من التحكم، يمكن استخدام namespace::clean لاستبعاد الدوال الفرعية غير المرغوب فيها من الأدوار.

الدوال الفرعية المستوردة

requires

requires qw(foo bar);

يعلن عن قائمة بالطرق التي يجب تعريفها لتركيب الدور.

with

with 'Some::Role1';
with 'Some::Role1', 'Some::Role2';

يركب دورًا آخر في الدور الحالي (أو فئة عبر Role::Tiny::With).

إذا كانت لديك تعارضات وتريد حلها لصالح Some::Role1، يمكنك كتابة:

with 'Some::Role1';
with 'Some::Role2';

إذا كانت لديك تعارضات وتريد حل تعارضات مختلفة لصالح أدوار مختلفة، يرجى إعادة هيكلة الكود الخاص بك.

before

before foo => sub { ... };

راجع "before method(s) => sub { ... };" في Class::Method::Modifiers للحصول على وثائق كاملة.

لاحظ أنك لم تعد ملزمًا باستخدام معدّلات الطرق، لذا يتم تحميل Class::Method::Modifiers ببطء ولا يتم الإعلان عنه كاعتمادية. إذا كان دور Role::Tiny الخاص بك يستخدم معدّلات، فيجب عليك الاعتماد على كل من Class::Method::Modifiers و Role::Tiny.

around

around foo => sub { ... };

راجع "around method(s) => sub { ... };" في Class::Method::Modifiers للحصول على وثائق كاملة.

لاحظ أنك لم تعد ملزمًا باستخدام معدّلات الطرق، لذا يتم تحميل Class::Method::Modifiers ببطء ولا يتم الإعلان عنه كاعتمادية. إذا كان دور Role::Tiny الخاص بك يستخدم معدّلات، فيجب عليك الاعتماد على كل من Class::Method::Modifiers و Role::Tiny.

after

after foo => sub { ... };

راجع "after method(s) => sub { ... };" في Class::Method::Modifiers للحصول على وثائق كاملة.

لاحظ أنك لم تعد ملزمًا باستخدام معدّلات الطرق، لذا يتم تحميل Class::Method::Modifiers ببطء ولا يتم الإعلان عنه كاعتمادية. إذا كان دور Role::Tiny الخاص بك يستخدم معدّلات، فيجب عليك الاعتماد على كل من Class::Method::Modifiers و Role::Tiny.

التشدد والتحذيرات

بالإضافة إلى استيراد الدوال الفرعية، يطبق Role::Tiny التشدد (strict) والتحذيرات (warnings) على المتصل.

الدوال الفرعية

does_role

if (Role::Tiny::does_role($foo, 'Some::Role')) {
  ...
}

يعيد `true` إذا تم تركيب الفئة بالدور.

يتم تثبيت هذه الدالة الفرعية أيضًا كـ `->does` في أي فئة تم تركيبها بواسطة Role::Tiny، لذا:

if ($foo->does('Some::Role')) {
  ...
}

يعمل للفئات، ولكن لاختبار دور، يجب على المرء استخدام `::does_role` مباشرة.

بالإضافة إلى ذلك، سيستبدل Role::Tiny طريقة Perl القياسية "DOES" لفئة الخاص بك. ومع ذلك، إذا قدمت أي فئة في تسلسل الوراثة لفئة الخاص بك "DOES"، فلن يستبدلها Role::Tiny.

الطرق

make_role

Role::Tiny->make_role('Some::Role');

ينشئ حزمة في دور، ولكنه لا يصدر أي دوال فرعية.

apply_roles_to_package

Role::Tiny->apply_roles_to_package(
  'Some::Package', 'Some::Role', 'Some::Other::Role'
);

يركب الأدوار في حزمة. انظر أيضًا Role::Tiny::With.

apply_roles_to_object

Role::Tiny->apply_roles_to_object($foo, qw(Some::Role1 Some::Role2));

يركب الأدوار بالترتيب في كائن مباشرة. تتم إعادة تقديم الكائن إلى الفئة الناتجة. لاحظ أن طرق الكائن يتم استبدالها بطرق الأدوار.

create_class_with_roles

Role::Tiny->create_class_with_roles('Some::Base', qw(Some::Role1 Some::Role2));

ينشئ فئة جديدة تستند إلى الفئة الأساسية، مع تركيب الأدوار فيها. يتم إرجاع الفئة الجديدة.

is_role

Role::Tiny->is_role('Some::Role1')

يعيد `true` إذا كانت الحزمة المعطاة دورًا.

محاذير

  • في Perl 5.8.8 والإصدارات الأقدم، لن يؤدي تطبيق دور على كائن إلى تطبيق أي تجاوزات للدور على نسخ الكائنات.
  • في Perl 5.16 والإصدارات الأقدم، لن يؤدي تطبيق دور على فئة إلى تطبيق أي تجاوزات للدور على أي مثيلات موجودة للفئة.

انظر أيضًا

Role::Tiny هو مجموعة فرعية بدون سمات من Moo::Role؛ Moo::Role هو بروتوكول فرعي بدون بيانات وصفية من ملكة أنظمة الأدوار، Moose::Role.

يقدم Ovid's Role::Basic أدوارًا بنطاق مماثل، ولكن بدون معدّلات طرق ومع قيود إضافية.
