الحزمة: recoll

التراخيص: GPL

RECOLLQ(1) دليل الأوامر العامة RECOLLQ(1)

اسم

recollq - أمر استعلام Recoll سطر الأوامر / الإخراج القياسي.

الملخص

recollq [ -c <configdir> ] [ -o | -f | -a ] [ -b ] [ -d ] [ -A ] [ -p | -q ] [ -e ] [ -m ] [ -n <[first-]cnt> ] [ -Q ] [ -s <stemming language> ] [ -S <fldname> ] [ -D ] [ -i <additional index directory> ] [ -F <quoted space separated field name list> ] [ --extract-to <file path> ] <query string>

recollq -P

الوصف

سيقوم الأمر recollq بتنفيذ استعلام Recoll المحدد في سطر الأوامر وطباعة النتائج إلى الإخراج القياسي. تم تصميمه بشكل أساسي للتشخيص، أو لتمرير البيانات إلى برنامج آخر. يمكن أن يكون التنسيق الأساسي وتنويعاته مفيدًا للاستعلام عبر سطر الأوامر. يجب استخدام الخيار -F حصريًا لاستخدام بيانات الإخراج في برنامج آخر، حيث إنه الوحيد الذي يضمن أن يكون الإخراج قابلاً للتحليل بالكامل.

يحدد الخيار -c اسم دليل التكوين، متجاوزًا الافتراضي أو $RECOLL_CONFDIR.

يتم بناء سلسلة الاستعلام عن طريق ضم جميع الوسائط الموجودة في نهاية سطر الأوامر (بعد الخيارات). سيتم تفسيرها افتراضيًا كسلسلة لغة استعلام. يجب استخدام علامات الاقتباس حسب الحاجة للهروب من الأحرف التي قد يتم تفسيرها بواسطة shell (مثل: الأحرف البديلة). إذا تم تحديد -a، فسيتم تفسير سلسلة الاستعلام كاستعلام بحث بسيط *لجميع الكلمات*. إذا تم تحديد -o، فسيتم تفسير سلسلة الاستعلام كاستعلام بحث بسيط *لأي كلمة*. إذا تم تحديد -f، فسيتم تفسير سلسلة الاستعلام كاستعلام بحث بسيط *لأسماء الملفات*.

يمكن تحديد -b (أساسي) لطباعة عناوين URL للنتائج فقط في دفق الإخراج.

إذا تم تعيين -d، فسيتم تفريغ النص لمحتويات ملفات النتائج إلى stdout.

إذا تم تعيين -m، فسيتم تفريغ مصفوفة البيانات الوصفية بأكملها لكل مستند.

إذا تم تعيين -A، فسيتم طباعة ملخصات المستندات. مع خيار إضافي -p (أو -q) (أو) (الأرقام)، سيتم عرض مقتطفات مع أرقام الصفحات (أو أرقام الأسطر)، إن وجدت، بدلاً من ذلك.

يقوم -S <fieldname> بفرز النتائج وفقًا للحقل المحدد. استخدم -D للترتيب التنازلي.

يمكن استخدام -n <[first-]cnt> لتعيين الحد الأقصى لعدد النتائج التي يجب طباعتها. الافتراضي هو 2000. استخدم قيمة 0 لعدم وجود حد. إذا كان الوسيط بتنسيق first-cnt، فإنه يحدد أيضًا النتيجة الأولى للإخراج (بدءًا من 0).

-s <language> يحدد لغة التجذير للكلمات. يجب أن تتطابق القيمة مع قاعدة بيانات تجذير موجودة (كما هو محدد في التكوين أو تم إضافتها باستخدام recollindex -s).

-i <extra dbdir> يضيف فهرس Xapian المحدد إلى المجموعة المستخدمة للاستعلام. يمكن تحديده عدة مرات.

-F <space separated field list> (وسيط واحد، على سبيل المثال "author title") يجب استخدامه لتمرير البيانات إلى برنامج آخر. بعد سطرين أوليين يعرضان الاستعلام الفعلي وعدد النتائج المقدر، سيقوم بطباعة سطر واحد لكل مستند نتيجة. سيكون لكل سطر الحقول المطلوبة بالضبط في سطر الأوامر. يتم تشفير الحقول في base64 وفصلها بحرف مسافة واحد. يتم الإشارة إلى الحقول الفارغة بأحرف مسافة متتالية. هناك حرف مسافة إضافي واحد في نهاية كل سطر.

--extract-to <file path> سيقوم باستخراج المستند الأول للنتيجة للاستعلام إلى المسار المحدد، والذي يجب ألا يكون موجودًا. استخدم -n first-cnt لتحديد المستند.

recollq -P (نقطة) ستطبع الحد الأدنى والأقصى لسنوات التعديل للمستندات في الفهرس.
