الاسم

rpc_secure — روتينات مكتبة لمكالمات الإجراءات عن بعد الآمنة

الملخص

#include <rpc/rpc.h>

AUTH *
authdes_create(char *name, unsigned window, struct sockaddr *addr, des_block *ckey);

AUTH *
authdes_pk_create(char *name, netobj *publickey, unsigned window, struct sockaddr *addr, des_block *ckey);

authdes_getucred(struct authdes_cred *adc, uid_t *uid, gid_t *gid, int *grouplen, gid_t *groups);

int
getnetname(char *name);

int
host2netname(char *name, const char *host, const char *domain);

int
key_decryptsession(const char *remotename, des_block *deskey);

int
key_encryptsession(const char *remotename, des_block *deskey);

key_gendes(des_block *deskey);

user2netname(char *name, const uid_t uid, const char *domain);

الوصف

هذه الروتينات جزء من مكتبة RPC. إنها تنفذ مصادقة DES. انظر rpc(3) لمزيد من التفاصيل حول RPC.

تعتبر الدالة authdes_create() الأولى من دالتين تتفاعلان مع نظام المصادقة الآمن لـ RPC، المعروف باسم مصادقة DES. الثانية هي authdes_getucred()، أدناه.

ملاحظة: يجب أن تكون خدمة خادم المفاتيح keyserv(8) قيد التشغيل ليعمل نظام مصادقة DES.

تقوم الدالة authdes_create()، المستخدمة على جانب العميل، بإرجاع مقبض مصادقة يتيح استخدام نظام المصادقة الآمن. الوسيطة الأولى name هي الاسم الشبكي، أو netname، لمالك عملية الخادم. تمثل هذه الحقل عادةً hostname مشتق من الروتين المساعد host2netname()، ولكن يمكن أن تمثل أيضًا اسم مستخدم باستخدام user2netname(). الوسيطة الثانية هي نافذة على صلاحية بيانات اعتماد العميل، معطاة بالثواني. نافذة صغيرة أكثر أمانًا من نافذة كبيرة، ولكن اختيار نافذة صغيرة جدًا سيزيد من تكرار إعادة المزامنة بسبب انحراف الساعة. الوسيطة الثالثة addr اختيارية. إذا كانت NULL، فسيقوم نظام المصادقة بافتراض أن الساعة المحلية متزامنة دائمًا مع ساعة الخادم، ولن يحاول إعادة المزامنة. ومع ذلك، إذا تم توفير عنوان، فسيستخدم النظام العنوان لاستشارة خدمة الوقت البعيد كلما دعت الحاجة إلى إعادة المزامنة. هذه الوسيطة عادة ما تكون عنوان خادم RPC نفسه. الوسيطة النهائية ckey اختيارية أيضًا. إذا كانت NULL، فسيقوم نظام المصادقة بإنشاء مفتاح DES عشوائي لاستخدامه في تشفير بيانات الاعتماد. ومع ذلك، إذا تم توفيرها، فسيتم استخدامها بدلاً من ذلك.

الدالة authdes_pk_create() مطابقة للدالة authdes_create()، باستثناء أنه يجب توفير المفتاح العام عند الاستدعاء ولن تبحث عنه هذه الدالة بنفسها.

الدالة authdes_getucred()، الثانية من روتينات مصادقة DES، تستخدم على جانب الخادم لتحويل بيانات اعتماد DES، وهي مستقلة عن نظام التشغيل، إلى بيانات اعتماد UNIX. تختلف هذه الدالة عن الروتين المساعد netname2user() في أن authdes_getucred() تسحب معلوماتها من ذاكرة تخزين مؤقت، ولا يتعين عليها إجراء بحث Yellow Pages في كل مرة يتم استدعاؤها للحصول على معلوماتها.

تقوم الدالة getnetname() بتثبيت الاسم الشبكي الفريد والمستقل عن نظام التشغيل للمتصل في المصفوفة ذات الطول الثابت name. تُرجع TRUE إذا نجحت و FALSE إذا فشلت.

تقوم الدالة host2netname() بالتحويل من اسم مضيف خاص بالنطاق إلى اسم شبكي مستقل عن نظام التشغيل. تُرجع TRUE إذا نجحت و FALSE إذا فشلت. هي عكس الدالة netname2host().

الدالة key_decryptsession() هي واجهة لخدمة خادم المفاتيح، المرتبطة بنظام المصادقة الآمن لـ RPC (مصادقة DES). نادرًا ما تحتاج برامج المستخدمين إلى استدعائها، أو روتينات مرتبطة بها مثل key_encryptsession() و key_gendes() و key_setsecret(). أوامر النظام مثل login(1) ومكتبة RPC هي العملاء الرئيسيون لهذه الروتينات الأربعة.

تأخذ الدالة key_decryptsession() اسم شبكة خادم ومفتاح DES، وتقوم بفك تشفير المفتاح باستخدام المفتاح العام للخادم والمفتاح السري المرتبط بـ uid الفعال للعملية المستدعية. وهي عكس الدالة key_encryptsession().

الدالة key_encryptsession() هي روتين واجهة لخادم المفاتيح. تأخذ اسم شبكة خادم ومفتاح des، وتقوم بتشفيره باستخدام المفتاح العام للخادم والمفتاح السري المرتبط بـ uid الفعال للعملية المستدعية. وهي عكس الدالة key_decryptsession().

الدالة key_gendes() هي روتين واجهة لخادم المفاتيح. تستخدم لطلب مفتاح محادثة آمن من خادم المفاتيح. اختيار واحد "عشوائي" ليس جيدًا بما فيه الكفاية عادةً، لأن الطرق الشائعة لتوليد أرقام عشوائية، مثل استخدام الوقت الحالي، سهلة جدًا.

NAME

rpc_secure, key_setsecret, netname2host, netname2user, user2netname — functions for secure RPC

SYNOPSIS

#include <rpc/rpc.h>

bool_t
key_setsecret(const char *secret);

char *
netname2host(netname2host *netname);

bool_t
netname2user(netname2user *netname, char *uid);

bool_t
user2netname(user2netname *netname, const char *uid);

DESCRIPTION

The rpc_secure routines provide an interface to the secure RPC mechanism.

The key_setsecret() function is a keyserver interface routine. It is used to set the key for the effective uid of the calling process.

The netname2host() function converts from an operating-system independent netname to a domain-specific hostname. Returns TRUE if it succeeds and FALSE if it fails. Inverse of host2netname().

The netname2user() function converts from an operating-system independent netname to a domain-specific user ID. Returns TRUE if it succeeds and FALSE if it fails. Inverse of user2netname().

The user2netname() function converts from a domain-specific username to an operating-system independent netname. Returns TRUE if it succeeds and FALSE if it fails. Inverse of netname2user().

AVAILABILITY

These functions are part of libtirpc.

تقوم الدالة netname2user() بالتحويل من اسم شبكة مستقل عن نظام التشغيل إلى معرّف مستخدم خاص بالمجال. تُرجع TRUE إذا نجحت و FALSE إذا فشلت. هي عكس الدالة user2netname().

تقوم الدالة user2netname() بالتحويل من اسم مستخدم خاص بالمجال إلى اسم شبكة مستقل عن نظام التشغيل. تُرجع TRUE إذا نجحت و FALSE إذا فشلت. هي عكس الدالة netname2user().
