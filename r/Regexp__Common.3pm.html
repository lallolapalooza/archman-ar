Regexp__Common(3pm)

Regexp::Common(3) توثيق مقدم من مستخدمي Perl Regexp::Common(3)

الاسم

Regexp::Common - توفير تعابير نمطية مطلوبة بشكل شائع

الملخص

# الاستخدام القياسي
use Regexp::Common;
while (<>) {
    /$RE{num}{real}/               and print q{a number};
    /$RE{quoted}/                  and print q{a string in [ " ]};
   m[$RE{delimited}{-delim=>'/'}]  and print q{a sequence /.../};
    /$RE{balanced}{-parens=>'()'}/ and print q{balanced parentheses};
    /$RE{profanity}/               and print q{an #*@%-ing word};
}
# واجهة الوظائف
use Regexp::Common 'RE_ALL';
while (<>) {
    $_ =~ RE_num_real()              and print q{a number};
    $_ =~ RE_quoted()                and print q{a string in [ " ]};
    $_ =~ RE_delimited(-delim=>'/') and print q{a sequence /.../};
    $_ =~ RE_balanced(-parens=>'()'} and print q{balanced parentheses};
    $_ =~ RE_profanity()             and print q{an #*@%-ing word};
}
# استخدام المطابقة المضمنة...
if ( $RE{num}{int}->matches($text) ) {...}
# ... واستبدال
my $cropped = $RE{ws}{crop}->subs($uncropped);
# إنشاء أنماط مقترحة
use Regexp::Common 'pattern';
pattern name   => ['name', 'mine'],
        create => '(?i:J[.]?\s+A[.]?\s+Perl-Hacker)',
        ;
my $name_matcher = $RE{name}{mine};
pattern name    => [ 'lineof', '-char=_' ],
        create  => sub {
                       my $flags = shift;
                       my $char = quotemeta $flags->{-char};
                       return '(?:^$char+$)';
                   },
        match   => sub {
                       my ($self, $str) = @_;
                       return $str !~ /[^$self->{flags}{-char}]/;
                   },
        subs   => sub {
                       my ($self, $str, $replacement) = @_;
                       $_[1] =~ s/^$self->{flags}{-char}+$//g;
                  },
        ;
my $asterisks = $RE{lineof}{-char=>'*'};
# اختيار الأنماط التي سيتم تحميلها.
use Regexp::Common qw /comment number/;  # التعليق والرقم
use Regexp::Common qw /no_defaults/;     # لا تحمل الأنماط
use Regexp::Common qw /!delimited/;      # الكل، ولكن الأنماط المحددة

الوصف

بشكل افتراضي، تقوم هذه الوحدة بتصدير مفتاح واحد (%RE) يخزن أو ينشئ أنماطًا شائعة مستخدمة في التعابير النمطية (انظر "قائمة الأنماط المتاحة").

هناك صيغة بديلة، تعتمد على الوظائف، موصوفة في "الواجهة المعتمدة على الوظائف".

الصيغة العامة لطلب الأنماط

للوصول إلى نمط معين، يتم التعامل مع %RE كـ hash هرمي من hashes (من hashes...)، حيث يكون كل مفتاح تالي معرفًا. على سبيل المثال، للوصول إلى النمط الذي يحتفظ بالأرقام الحقيقية، يتم تحديده:

$RE{num}{real}

وللوصول إلى النمط الذي يحتفظ بالأعداد الصحيحة:

$RE{num}{int}

تُستخدم الطبقات الأعمق من الـ hash لتحديد الأعلام (الوسائط التي تعدل النمط الناتج بطريقة ما). المفاتيح المستخدمة للوصول إلى هذه الطبقات تبدأ بإشارة ناقص ويمكن أن يكون لها قيمة؛ إذا تم إعطاء قيمة، يتم استخدام مفتاح متعدد الأبعاد. على سبيل المثال، للوصول إلى النمط الذي يحتفظ بالأرقام الحقيقية مع فواصل تفصل مجموعات من ثلاثة أرقام (على سبيل المثال، 10,101,110.110101101):

$RE{num}{real}{-base => 2}{-sep => ','}{-group => 3}

من خلال سحر Perl، يمكن تحديد طبقات الأعلام هذه بأي ترتيب (وحتى خلطها مع معرفات المفاتيح!)، لذلك يمكنك الحصول على نفس النمط باستخدام:

$RE{num}{real}{-sep => ','}{-group => 3}{-base => 2}

أو:

$RE{num}{-base => 2}{real}{-group => 3}{-sep => ','}

أو حتى:

$RE{-base => 2}{-group => 3}{-sep => ','}{num}{real}

إلخ.

لاحظ، مع ذلك، أن الترتيب النسبي بين معرفات المفاتيح ذو أهمية. لذلك:

$RE{list}{set}

ليس هو نفسه مثل:

$RE{set}{list}

صيغة الأعلام

في الإصدارات قبل 2.113، كانت الأعلام يمكن كتابتها أيضًا كـ "{-flag=value}". هذا لم يعد يعمل، على الرغم من أن "{-flag$;value}" لا يزال يعمل. ومع ذلك، فإن "{-flag => 'value'}" هي الصيغة المفضلة.

الأعلام العالمية

عادةً، تكون الأعلام خاصة بنمط معين. ومع ذلك، هناك علامان يمكن تحديدهما لجميع الأنماط.

"-keep"
بشكل افتراضي، لا تحتوي الأنماط التي يوفرها %RE على أقواس التقاط. ومع ذلك، إذا تم تحديد العلامة "-keep" (بدون قيمة)، فإن أي استخلاصات مهمة يحتفظ بها النمط سيتم التقاطها. على سبيل المثال: 
if ($str =~ $RE{num}{real}{-keep}) {
    $number   = $1;
    $whole    = $3;
    $decimals = $5;
}

يلزم توخي الحذر الخاص إذا تم استيفاء نمط "kept" في تعبير نمطي أكبر، لأن وجود أقواس التقاط أخرى قد يغير "أرقام المتغيرات" التي يتم حفظ السلاسل المهمة فيها.

انظر أيضًا "إضافة تعابير نمطية جديدة"، والتي تصف كيفية إنشاء أنماط جديدة مع "أقواس التقاط اختيارية" تستجيب لـ "-keep".

"-i"
بعض الأنماط أو الأنماط الفرعية تتطابق فقط مع الأحرف الصغيرة أو الكبيرة. إذا كنت ترغب في المطابقة غير الحساسة لحالة الأحرف، فإن أحد الخيارات هو استخدام معدل التعبير النمطي "/i" أو التسلسل الخاص "(?i)". ومع ذلك، إذا كنت تستخدم الواجهة الوظيفية، فلا يوجد هذا الخيار. العلامة "-i" تحل هذه المشكلة؛ عند استخدامها، سيقوم النمط بالمطابقة غير الحساسة لحالة الأحرف.

واجهة الكائنية والمطابقة/الاستبدال المضمن

الأنماط التي تم إرجاعها بواسطة %RE هي كائنات، لذلك بدلاً من الكتابة:

if ($str =~ /$RE{some}{pattern}/ ) {...}

يمكنك الكتابة:

if ( $RE{some}{pattern}->matches($str) ) {...}

المطابقة تبدو وكأنها ميزة للقراءة فقط (ولكن انظر أدناه).

بالنسبة للاستبدالات، لديك مزايا مهمة أخرى. غالبًا ما ترغب في إجراء استبدال في سلسلة دون تغيير الأصل. يستخدم معظم المستخدمين هذا:

$changed = $original;
$changed =~ s/$RE{some}{pattern}/$replacement/;

الاستخدام الأكثر تقدمًا:

$changed = $original;
($changed =~ s/$RE{some}{pattern}/$replacement/);

يسمح Regexp::Common بكتابة هذا:

$changed = $RE{some}{pattern}->subs($original=>$replacement);

بالإضافة إلى تقليل أسبقية البادئة، فإن هذا الشكل له مزايا إضافية مثل تحسين استبدال التعبير النمطي وتوفير سلسلة الاستبدال الافتراضية (انظر "إضافة تعابير نمطية جديدة").

على سبيل المثال، في تنفيذ هذا الاستبدال:

$cropped = $RE{ws}{crop}->subs($uncropped);

يتم توفير السلسلة الفارغة الافتراضية تلقائيًا، ويتم تحسين الاستبدال لاستخدام:

$uncropped =~ s/^\s+//;
$uncropped =~ s/\s+$//;

بدلاً من:

$uncropped =~ s/^\s+|\s+$//g;

الواجهة المعتمدة على الوظائف

تم اختيار واجهة الـ hash لأنها تسمح باستيفاء التعابير النمطية بسهولة وتسمح أيضًا بأن تكون "curried" (curried). على سبيل المثال:

my $num = $RE{num}{int};
my $commad     = $num->{-sep=>','}{-group=>3};
my $duodecimal = $num->{-base=>12};

ومع ذلك، فإن استخدام hashes الموقعة يجعل الوصول إلى أنماط Regexp::Common بطيئًا مقارنة بما يمكن أن يكون عليه. في السياقات التي تتغلب فيها نفاد الصبر على الكسل، توفر Regexp::Common واجهة بديلة قائمة على الوظائف.

لكل إدخال (فرعي) في hash %RE ("$RE{key1}{key2}{etc}")، هناك وظيفة قابلة للتصدير مقابلة:

RE_key1_key2_etc()

اسم كل وظيفة هو مفصول بالشرطات السفلية (_).
