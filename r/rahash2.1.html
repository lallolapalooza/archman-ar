الحزمة: radare2

التراخيص: GPL-3.0-only, LGPL-3.0-only

RAHASH2(1) دليل الأوامر العامة RAHASH2(1)

الاسم

rahash2 — أداة تجزئة، ترميز وتشفير قائمة على الكتل

ملخص

rahash2 [-BbdehjkLqrv] [-a algo] [-b size] [-c hash] [-D deco] [-e] [-E enco] [-f from] [-i num] [-I iv] [-j] [-J] [-L] [-S seed] [-k] [-s string] [-t to] [-x hexstr] [-X] [-v] [[file] ...]

الوصف

هذا البرنامج جزء من مشروع radare.

إنه مفيد بشكل خاص لتجزئة الملفات الكبيرة وتحديد التعديلات في تحليل أنظمة الملفات الجنائية.

يوفر هذا الأمر نفس ميزات الأمر 'ph' الخاص بـ radare.

-a algo
قائمة مفصولة بفواصل للخوارزميات المراد استخدامها عند تجزئة الملفات أو السلاسل النصية. ارجع إلى -L لسرد خوارزميات التجزئة المدعومة. يمكن تمرير هذا العلم عدة مرات بدلاً من فصلها بفواصل.
-b size
تحديد حجم الكتلة.
-c hash
مقارنة التجزئة المحسوبة مع التجزئة المقدمة. هذا مسموح به فقط عندما يتم حساب تجزئة واحدة.
-D deco
فك التشفير باستخدام الخوارزمية المحددة. استخدم -S لتعيين المفتاح و -I لتعيين متجه التهيئة.
-e
تبديل ترتيب البايتات لعرض الملخصات أو استيعاب المفاتيح بالترتيب الكبير أو الصغير.
-E enco
تشفير باستخدام الخوارزمية المحددة. استخدم -S لتعيين المفتاح و -I لتعيين متجه التهيئة.
-f from
بدء التجزئة من العنوان المحدد.
-i num
كرر التجزئة `num` مرات.
-I iv
استخدم متجه التهيئة (IV) المحدد (سداسي عشري أو سلسلة نصية).
-j
عرض المخرجات بتنسيق JSON.
-J
تنسيق مخرجات JSON مبسط جديد (مكافئ لـ -jj).
-k
عرض التجزئة باستخدام خوارزمية randomkey الخاصة بـ OpenSSH.
-L
سرد مكونات التجزئة، المجموع الاختباري، والإضافات المشفرة المتاحة. يمكن دمج هذا العلم مع -j لقراءة النتائج بتنسيق JSON.
-s string
تجزئة السلسلة النصية المقدمة بدلاً من استخدام وسيطات 'source' و 'hash-file'.
-S seed
استخدم البذرة المحددة (سداسي عشري أو سلسلة نصية). استخدم ^ للبادئة (مفتاح لـ -E). '-' ستجلب المفتاح من stdin، و '@' تشير إلى ملف.
-t to
إيقاف التجزئة عند العنوان المحدد.
-x hexstr
تجزئة السلسلة السداسية عشرية المقدمة بدلاً من استخدام وسيطات 'source' و 'hash-file'.
-X
مخرجات التشفير بتنسيق سداسي عشري بدلاً من الخام (انظر -j للمخرجات بتنسيق json)
-v
عرض معلومات الإصدار.

أمثلة

حساب تجزئة MD5 لملف 'ls' الثنائي:


$ rahash2 -qqa md5 /bin/ls

حساب تجزئة SHA256 لسلسلة نصية من stdin:


$ echo -n "Hello, World" | rahash2 -a sha256 -
$ rahash2 -a sha256 -s "Hello, World"

مقارنة CRC32 لملف معين لم يتغير:


$ rahash2 -qqa crc32 /bin/ls
63212007
$ rahash2 -a crc32 -c 63212007 /bin/ls
INFO: Computed hash matches the expected one
$ echo $?
0

سرد المكونات المشفرة فقط التي تم تحميلها:


$ rahash2 -L | grep ^c


$ rahash2 -qqa crc32 /bin/ls

ترميز السلسلة النصية "Hello World" باستخدام base64:


$ rahash2 -E base64 -s "Hello World"

حساب تجزئة SHA256 لجزء معين من ملف:


$ rahash2 -qqa sha256 -f 0x1000 -t 0x2000 file_to_hash

تشفير وفك تشفير السلسلة النصية "hello" باستخدام مكونات ror و rol:


$ rahash2 -S 12333 -E ror -s hello && echo
Cell{
$ rahash2 -S 12333 -E rol -s Cell{ && echo
hello

تشفير وفك تشفير باستخدام AES-CBC:


$ export AES_KEY="11111111111111111111111111113211"
$ rahash2 -E aes-ecb -S "$AES_KEY" -s "hello world you bastard" > .file
$ cat .file | rahash2 -D aes-ecb -S "$AES_KEY" -s - && echo

تشفير ملف باستخدام Blowfish وترميزه في JSON:


$ rahash2 -E blowfish -S "11111111111111111111111111113211" -j /bin/ls > ls.json

التشخيص

يخرج الأمر rahash2 بالرمز 0 عند النجاح، و >0 إذا حدث خطأ.

عند استخدام العلم -c، يشير رمز الخروج 0 إلى تطابق بين التجزئات المتوقعة والمحسوبة.

الاسم

rahash2 - أداة لحساب التجزئات باستخدام خوارزميات مختلفة

الملخص

rahash2 [-a alg] [-b] [-B] [-C] [-c file] [-d] [-e] [-f] [-h] [-i] [-l] [-m] [-n] [-p nchars] [-q] [-r] [-s] [-S] [-t timeout] [-u] [-v] [-w] [-x] [-z] [--] [file...]

الوصف

rahash2 هي أداة لحساب تجزئات الملفات باستخدام خوارزميات مختلفة. تدعم مجموعة واسعة من خوارزميات التجزئة، بما في ذلك MD5، SHA1، SHA256، وغيرها.

الخيارات

-a alg
تحديد خوارزمية التجزئة المراد استخدامها. الخيارات المتاحة تشمل: md5، sha1، sha256، sha512، sha3، blake2b، blake2s، xxh32، xxh64، fnv1a32، fnv1a64.
-b
عرض التجزئة بالترميز الأساسي 64.
-B
عرض التجزئة كسلسلة خام.
-C
حساب التجزئة لكل سطر.
-c file
التحقق من التجزئات الموجودة في file.
-d
فك ترميز الإدخال قبل حساب التجزئة.
-e
ترميز الإدخال قبل حساب التجزئة.
-f
تجاهل الأخطاء.
-h
عرض رسالة المساعدة.
-i
تجاهل حالة الأحرف عند التحقق من التجزئات.
-l
عرض قائمة بجميع الخوارزميات المتاحة.
-m
حساب التجزئة لعدة ملفات.
-n
عدم عرض اسم الملف.
-p nchars
تحديد عدد الأحرف الأولى التي سيتم استخدامها لحساب التجزئة.
-q
وضع التشغيل الصامت.
-r
عرض النتيجة بتنسيق label:hash:filename.
-s
حساب تجزئة السلسلة المدخلة.
-S
حساب تجزئة السلسلة المدخلة مع إضافة حرف السطر الجديد.
-t timeout
تعيين مهلة زمنية بالثواني.
-u
عرض التجزئة بأحرف كبيرة.
-v
عرض معلومات الإصدار.
-w
عرض التجزئة بالترميز السداسي عشري.
-x
حساب التجزئة باستخدام ملفات Hex.
-z
حساب تجزئة سلاسل فارغة.
--
إنهاء خيارات سطر الأوامر.

أمثلة

حساب تجزئة SHA256 لملف:

rahash2 -a sha256 file.txt

التحقق من تجزئة ملف:

rahash2 -c checksums.txt file.txt
