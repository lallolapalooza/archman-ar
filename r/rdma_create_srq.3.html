RDMA_CREATE_SRQ(3) دليل مبرمج Librdmacm RDMA_CREATE_SRQ(3)

الاسم

rdma_create_srq - تخصيص قائمة استقبال مشتركة.

الملخص

#include <rdma/rdma_verbs.h>

int rdma_create_srq (struct rdma_cm_id *id, struct ibv_pd *pd, struct ibv_srq_init_attr *attr);

المعاملات

id
معرف RDMA.
pd
نطاق حماية اختياري لـ SRQ.
attr
سمات SRQ الأولية.

الوصف

تخصيص SRQ مرتبط بـ rdma_cm_id المحدد.

قيمة الإرجاع

ترجع 0 عند النجاح، أو -1 عند الخطأ. إذا حدث خطأ، فسيتم تعيين errno لإظهار سبب الفشل.

ملاحظات

يجب ربط rdma_cm_id بجهاز RDMA محلي قبل استدعاء هذه الدالة، ويجب أن يكون نطاق الحماية، إذا تم توفيره، لنفس الجهاز. بعد تخصيصه، سيكون SRQ جاهزًا لمعالجة نشر عمليات الاستقبال.

إذا لم يتم توفير نطاق حماية - المعامل pd هو NULL - فسيتم إنشاء rdma_cm_id باستخدام نطاق حماية افتراضي. يتم تخصيص نطاق حماية افتراضي واحد لكل جهاز RDMA.

يتم تحديد سمات SRQ الأولية بواسطة المعامل attr. الحقول ext.xrc.cq في ibv_srq_init_attr اختيارية. إذا لم يتم تحديد قائمة إكمال لـ XRC SRQ، فسيتم تخصيص CQ بواسطة rdma_cm لـ SRQ، إلى جانب قنوات إكمال مقابلة. يتم عرض قنوات الإكمال وبيانات CQ التي تم إنشاؤها بواسطة rdma_cm للمستخدم من خلال بنية rdma_cm_id.

سيتم إرجاع القدرات والخصائص الفعلية لـ SRQ الذي تم إنشاؤه إلى المستخدم من خلال المعامل attr. يمكن ربط rdma_cm_id بـ SRQ واحد فقط.
