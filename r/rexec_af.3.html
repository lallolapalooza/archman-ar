rexec(3) دليل وظائف المكتبة rexec(3)

الاسم

rexec, rexec_af - إرجاع دفق لأمر بعيد

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <netdb.h>
[[deprecated]]
int rexec(char **restrict ahost, int inport,
          const char *restrict user, const char *restrict passwd,
          const char *restrict cmd, int *restrict fd2p);
[[deprecated]]
int rexec_af(char **restrict ahost, int inport,
          const char *restrict user, const char *restrict passwd,
          const char *restrict cmd, int *restrict fd2p,
          sa_family_t af);

rexec(), rexec_af():

    منذ glibc 2.19:
        _DEFAULT_SOURCE
    في glibc حتى 2.19 وشاملة:
        _BSD_SOURCE

الوصف

تم إهمال هذه الواجهة بواسطة rcmd(3).

تبحث الدالة rexec() عن المضيف *ahost باستخدام gethostbyname(3)، وترجع -1 إذا لم يكن المضيف موجودًا. خلاف ذلك، يتم تعيين *ahost إلى الاسم القياسي للمضيف. إذا تم تحديد اسم مستخدم وكلمة مرور، فيتم استخدامهما للمصادقة على المضيف الأجنبي؛ بخلاف ذلك، يتم البحث في البيئة ثم في ملف .netrc الموجود في الدليل الرئيسي للمستخدم للحصول على المعلومات المناسبة. إذا فشل كل هذا، يتم مطالبة المستخدم بالمعلومات.

يحدد المنفذ inport منفذ DARPA Internet المعروف الذي يجب استخدامه للاتصال؛ تستدعي الدالة getservbyname("exec", "tcp") (انظر getservent(3)) لإرجاع مؤشر إلى بنية تحتوي على المنفذ الضروري. تم وصف بروتوكول الاتصال بالتفصيل في rexecd(8).

إذا نجح الاتصال، يتم إرجاع مقبس في نطاق الإنترنت من النوع SOCK_STREAM إلى المتصل، ويتم تقديمه إلى الأمر البعيد كـ stdin و stdout. إذا كان fd2p غير صفري، فيتم إعداد قناة مساعدة لعملية تحكم، ويتم وضع واصف ملف لها في *fd2p. سترجع عملية التحكم مخرجات تشخيصية من الأمر (الوحدة 2) على هذه القناة، كما ستقبل بايتات على هذه القناة كأرقام إشارات UNIX، ليتم توجيهها إلى مجموعة العمليات للأمر. لا تتضمن المعلومات التشخيصية المرجعة فشل ترخيص عن بعد، حيث يتم إعداد الاتصال الثانوي بعد التحقق من صحة الترخيص. إذا كان fd2p يساوي 0، فسيتم جعل stderr (الوحدة 2 للأمر البعيد) مطابقًا لـ stdout ولا يتم توفير أي وسيلة لإرسال إشارات عشوائية إلى العملية البعيدة، على الرغم من أنه قد يكون بإمكانك لفت انتباهها باستخدام بيانات خارج النطاق.

rexec_af()

تعمل الدالة rexec() عبر IPv4 (AF_INET). على النقيض من ذلك، توفر الدالة rexec_af() وسيطة إضافية، af، تسمح للمتصل بتحديد البروتوكول. يمكن تحديد هذه الوسيطة كـ AF_INET أو AF_INET6 أو AF_UNSPEC ( للسماح للتنفيذ باختيار البروتوكول).

الأخطاء

ترسل الدالة rexec() كلمة المرور غير المشفرة عبر الشبكة.

تعتبر الخدمة الأساسية ثغرة أمنية كبيرة، ولذلك، لا يتم تمكينها في العديد من المواقع؛ انظر rexecd(8) للشرح.
