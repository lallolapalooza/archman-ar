rtcSetDeviceErrorFunction.3embree3

الحزمة: embree3

التراخيص: Apache

rtcSetDeviceErrorFunction(3) Kernels تتبع الأشعة Embree 3 rtcSetDeviceErrorFunction(3)

الاسم

rtcSetDeviceErrorFunction - يحدد وظيفة رد اتصال للأخطاء للجهاز

الملخص

#include <embree3/rtcore.h>
typedef void (*RTCErrorFunction)(
  void* userPtr,
  RTCError code,
  const char* str
);
void rtcSetDeviceErrorFunction(
  RTCDevice device,
  RTCErrorFunction error,
  void* userPtr
);

الوصف

باستخدام استدعاء rtcSetDeviceErrorFunction، يمكن تحديد وظيفة رد اتصال (حجة الخطأ) مع حمولة (حجة userPtr) والتي يتم استدعاؤها كلما حدث خطأ للجهاز المحدد (حجة device).

يمكن تسجيل وظيفة رد اتصال واحدة فقط لكل جهاز، وتؤدي الاستدعاءات اللاحقة إلى الكتابة فوق وظيفة رد الاتصال التي تم تعيينها مسبقًا. يؤدي تمرير NULL كعنوان وظيفة إلى تعطيل وظيفة رد الاتصال المسجلة.

عند استدعاء وظيفة رد الاتصال المسجلة، يتم تمرير الحمولة المعرفة من قبل المستخدم (حجة userPtr كما تم تحديدها عند التسجيل) ورمز الخطأ (حجة code) للخطأ الذي حدث، بالإضافة إلى سلسلة نصية (حجة str) تصف الخطأ بشكل أكبر.

يتم أيضًا تعيين رمز الخطأ إذا تم تسجيل وظيفة رد اتصال للأخطاء.

حالة الخروج

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.

انظر أيضًا

[rtcGetDeviceError]
