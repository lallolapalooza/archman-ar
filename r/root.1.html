root(1) دليل الأوامر العامة root(1)

ملخص

الاستخدام: root [-b B] [-x X] [-e E] [-n N] [-t T] [-q Q] [-l L] [-a A]
[-config CONFIG] [-h HELP] [--version VERSION]
[--notebook NOTEBOOK] [--web WEB] [--web=<type> WEB=<TYPE>]
[--web=off WEB=OFF]
[dir] [data1.root...dataN.root] [file1.C...fileN.C]
[file1_C.so...fileN_C.so] [anyfile1..anyfileN]

الوصف

root هو مفسر تفاعلي لكود C++ باستخدام Cling وإطار عمل ROOT. لمزيد من المعلومات حول ROOT، يرجى الرجوع إلى https://root.cern/ دليل مستخدم شامل ومرجع API متاحان من هذا الموقع.

خيارات

-b
تشغيل في وضع الدُفعة بدون رسومات
-x
الخروج عند حدوث استثناءات
-e
تنفيذ الأمر المقدم بين علامتي اقتباس مفردتين
-n
لا تقم بتنفيذ وحدات الماكرو للتسجيل والخروج كما هو محدد في .rootrc
-t
تمكين دعم الخيوط والتزامن الضمني المتعدد (IMT)
-q
الخروج بعد معالجة ملفات الماكرو في سطر الأوامر
-l
لا تظهر شعار ROOT
-a
عرض شاشة البداية لـ ROOT (خاص بنظام Windows)
-config
طباعة خيارات ./configure
-h
عرض ملخص الخيارات
--version
عرض إصدار ROOT
--notebook
تنفيذ دفتر ملاحظات ROOT
--web
استخدام العرض المستند إلى الويب للرسومات، المتصفح، الهندسة
--web=<type>
استخدام العرض المستند إلى الويب المحدد مثل chrome، firefox، qt6
لمزيد من الخيارات، راجع وثائق TROOT::SetWebDisplay()
--web=off
تعطيل أي نوع من أنواع العرض المستند إلى الويب
[dir]
إذا كان dir دليلًا صالحًا، انتقل إليه قبل التنفيذ
[data1.root...dataN.root]
فتح ملفات ROOT المحددة؛ بروتوكولات الوصول عن بعد (مثل http://) مدعومة
[file1.C...fileN.C]
تنفيذ ملفات الماكرو الخاصة بـ ROOT file1.C ... fileN.C
يمكن تمرير علامات الترجمة وكذلك وسائط الماكرو، راجع التنسيق في https://root.cern/manual/root_macros_and_shared_libraries/
[file1_C.so...fileN_C.so]
تحميل وتنفيذ file1_C.so ... fileN_C.so (أو .dll إذا كان على Windows)
يجب أن تكون وحدات ماكرو ROOT مجمعة مسبقًا (مكتبات مشتركة) أو:
مكتبات مشتركة عادية للمستخدم، على سبيل المثال userlib.so مع دالة userlib(args)
[anyfile1..anyfileN]
سيتم فحص جميع الوسائط الأخرى التي تشير إلى ملفات موجودة لمعرفة ما إذا كانت ملفات ROOT (فحص نوع MIME داخل الملف) وإذا لم تكن كذلك، فسيتم التعامل معها كملف ماكرو ROOT
