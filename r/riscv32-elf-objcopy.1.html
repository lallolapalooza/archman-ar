SYNOPSIS

objcopy [general-options] [traditional-options] [script-options] objfile [outfile]

objcopy [general-options] [traditional-options] [script-options] objfile...

DESCRIPTION

The objcopy utility is used to copy information from one object file to another. The copy is performed selectively, and is sometimes needed in order to translate object files from one format to another. The default operation is to create a second version of the object file, with a name made by appending the suffix ".new" to the original file name. If a second file name is given, then that file is created as the copy. If the input is from standard input (-), then the output is to standard output.

objcopy can be used to create a stripped version of an object file. If the --strip-all option is used, then all symbol-debugging information is removed from the file. If the --strip-debug option is used, then only the symbol-debugging information is removed.

objcopy can also be used to change the format of an object file by using the -F or --target option. The list of supported formats can be obtained by running objcopy with no options.

objcopy can be used to extract specific sections from an object file, or to add new sections.

If the input object file contains multiple copies of the same section (for example, in PIE executables), objcopy will by default create a copy of the section for each input section in the output file. This can be controlled using the --all-sections option.

OPTIONS

<@file>
Read options from the specified file. This is useful for invoking objcopy with a large number of options, or to specify the same set of options in multiple invocations. The options are read from the file one per line. If a line begins with a whitespace character, then it and the following lines are treated as arguments for a single option. If a line begins with the character '@', then the remainder of the line is treated as the name of another file from which to read options. This can be used to process options recursively. If a file does not exist or cannot be read, then the option will be treated literally and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
