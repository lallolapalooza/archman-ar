Return__Value(3pm)

الحزمة: perl-return-value

التراخيص: GPL, PerlArtistic

Return::Value(3) وثائق Perl ساهم بها المستخدم Return::Value(3)

الاسم

Return::Value - (مهمل) قيم إرجاع متعددة الأشكال

الإصدار

version 1.666005

الملخص

يستخدم مع واجهة استدعاء الدوال الأساسية:

use Return::Value;

sub send_over_network {
    my ($net, $send) = @_:
    if ( $net->transport( $send ) ) {
        return success;
    } else {
        return failure "Was not able to transport info.";
    }
}

my $result = $net->send_over_network(  "Data" );

# boolean
unless ( $result ) {
    # string
    print $result;
}

أو، قم ببناء قيمة الإرجاع الخاصة بك ككائن:

sub build_up_return {
    my $return = failure;

    if ( ! foo() ) {
        $return->string("Can't foo!");
        return $return;
    }

    if ( ! bar() ) {
        $return->string("Can't bar");
        $return->prop(failures => \@bars);
        return $return;
    }

    # we're okay if we made it this far.
    $return++;
    return $return; # success!
}

الوصف

قيم الإرجاع متعددة الأشكال فكرة سيئة للغاية، ولكن تم كتابة هذه المكتبة بناءً على فكرة أنها مفيدة. غالبًا، نريد فقط معرفة ما إذا كان شيء ما قد نجح أم لا. في أوقات أخرى، قد نرغب في معرفة نص الخطأ. لا يزال هناك، قد نرغب في معرفة رمز الخطأ، وما هي خصائص الخطأ. لا نريد التعامل مع كائنات أو هياكل بيانات لكل قيمة إرجاع، ولكننا نريد التحقق من شروط الخطأ في الكود الخاص بنا لأن هذا ما يفعله المبرمجون الجيدون.

عندما تكون الدوال ناجحة، قد ترجع قيمة منطقية، أو ربما بعض البيانات المفيدة. في السعي لتوفير قيم إرجاع متسقة، يصبح هذا مربكًا بين الأخطاء المعقدة والمعلوماتية وقيم الإرجاع الناجحة.

توفر هذه الوحدة هذه الميزات بواجهة بسيطة يجب أن تحصل لك على ما تبحث عنه في كل سياق تستخدم فيه قيمة الإرجاع.

السمات

جميع قيم الإرجاع لديها مجموعة من السمات التي تجمع المعلومات المرتجعة. يمكن الوصول إلى جميع السمات أو تغييرها عبر الدوال التابعة (methods) بنفس الاسم، ما لم يُنص على خلاف ذلك. يمكن الوصول إلى العديد منها أيضًا عبر العمليات المفرطة (overloaded operations) على الكائن، كما هو موضح أدناه.

type
نوع القيمة هو إما "success" (نجاح) أو "failure" (فشل) ويعكس (بشكل واضح) ما إذا كانت القيمة تعود بنجاح أو فشل.
errno
تخزن السمة errno رقم الخطأ لقيمة الإرجاع. بالنسبة لنتائج نوع النجاح، فهي غير محددة بشكل افتراضي. بالنسبة للنتائج الأخرى، تكون قيمتها الافتراضية 1.
string
سمة النص (string) للقيمة هي رسالة بسيطة تصف القيمة.
data
تخزن سمة البيانات (data) مرجعًا إلى تجزئة (hash) أو مصفوفة، ويمكن استخدامها كطريقة بسيطة لإرجاع بيانات إضافية. يمكن الوصول إلى البيانات المخزنة في سمة البيانات عن طريق إلغاء مرجع (dereferencing) قيمة الإرجاع نفسها. (انظر أدناه).
prop
السمة الأكثر عمومية على الإطلاق، prop هي تجزئة مرجعية (hashref) يمكن استخدامها لتمرير عدد اعتباطي من هياكل البيانات، تمامًا مثل سمة البيانات. على عكس سمة البيانات، يجب استرداد هذه الهياكل عبر استدعاءات الدوال.

لا تستخدم هذه المكتبة

Return::Value كانت فكرة سيئة. أنا آسف لأنني استخدمتها، آسف لأنني أكملتها، وآسف لأنها استخدمت في مكتبات أخرى مفيدة. لحسن الحظ، ليست هناك الكثير من الأشياء التي تستخدمها. أحد هذه الأشياء هو Email::Send الذي تم إهماله أيضًا لصالح Email::Sender.

لا يوجد سبب لتحديد وحدة جديدة لتحل محل Return::Value. بشكل عام، يجب أن ترجع الروتينات قيمًا من نوع موحد أو تطلق استثناءات. حاولت Return::Value أن تكون نوعًا موحدًا لجميع الروتينات، ولكن لديها الكثير من السلوك الغريب الذي ينتهي به الأمر إلى أن يكون مربكًا وغير شبيه بـ Perl.

الكائنات التي تعتبر خاطئة هي مجرد فكرة مروعة في معظم الظروف، خاصة عندما يكون للكائن خصائص مفيدة.

يرجى عدم استخدام هذه المكتبة. سوف تندم عليها لاحقًا.

وعد إصدار من هذه المكتبة في يونيو 2009 بأن تحذيرات الإهمال ستبدأ في الصدار في يونيو 2010. الآن هو ديسمبر 2012، والتحذيرات تصدر الآن. يمكن تعطيلها من خلال الوسائل الموضحة في المصدر.

الدوال

توصى بشدة باستخدام الواجهة الوظيفية داخل الدوال التي تستخدم "Return::Value" لقيم الإرجاع. إنها بسيطة ومباشرة، وتقوم ببناء قيمة الإرجاع بأكملها في بيان واحد.

success
الدالة "success" ترجع "Return::Value" بنوع "success".

يمكن تمرير معلمات إضافية مسماة لتعيين سمات الكائن المرتجع. المعلمة الأولى الاختيارية هي سمة النص ولا تحتاج إلى تسمية. يجب تمرير جميع المعلمات الأخرى بالاسم.

# أبسط حالة ممكنة
return success;
failure
"failure" مطابق لـ "success"، ولكنه يرجع كائنًا بنوع "failure".

الدوال التابعة (Methods)

واجهة الكائن مفيدة في الكود الذي يلتقط كائنات "Return::Value".

new
my $return = Return::Value->new(
    type   => 'failure',
    string => "YOU FAIL",
    prop   => {
        failed_objects => \@objects,
    },
);

ينشئ كائن "Return::Value" جديدًا. يمكن استخدام المعلمات المسماة لتعيين سمات الكائن.

bool
print "it worked" if $result->bool;

يرجع النتيجة في سياق منطقي: صحيح للنجاح، خاطئ للفشل.

prop
printf "%s: %s',
  $result->string, join ' ', @{$result->prop('strings')}
    unless $result->bool;

يرجع خصائص قيمة الإرجاع. يقبل اسم خاصية مرجعة، أو يرجع مرجع التجزئة للخصائص إذا لم يتم تمرير اسم.

other attribute accessors
توجد دوال وصول بسيطة لسمات الكائن الأخرى: "type"، "errno"، "string"، و "data".

الإفراط (Overloading)

تم إفراط العديد من المعاملات لكائنات "Return::Value". تم سردها هنا.

التحويل إلى نص
print "$result\n";

يتم تحويلها إلى نص باستخدام سمة النص.

المنطقي
print $result unless $result;

يرجع تمثيل "bool".

الرقمي
يرجع أيضًا قيمة "bool".
إلغاء المرجع
سيؤدي إلغاء مرجع القيمة كتجزئة أو مصفوفة إلى إرجاع قيمة سمة البيانات، إذا كانت تطابق هذا النوع، أو مرجع فارغ بخلاف ذلك. يمكنك التحقق من "ref $result->data" لتحديد نوع البيانات (إن وجدت) التي تم تمريرها.
