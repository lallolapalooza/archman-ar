قيم النتائج.

قيم النتائج تتعامل مع نتائج العمليات والأخطاء بطريقة صريحة وتعريفية دون اللجوء إلى الاستثناءات.

منذ 4.08

النتائج

type ('a, 'e) t = ('a, 'e) result =
| Ok of 'a
| Error of 'e

النوع لقيم النتائج. إما قيمة Ok v أو خطأ Error e .

val ok : 'a -> ('a, 'e) result

ok v هو Ok v .

val error : 'e -> ('a, 'e) result

error e هو Error e .

val value : ('a, 'e) result -> default:'a -> 'a

value r ~default هو v إذا كان r هو Ok v و default بخلاف ذلك.

val get_ok : ('a, 'e) result -> 'a

get_ok r هو v إذا كان r هو Ok v ويرفع استثناءً بخلاف ذلك.

يثير استثناء Invalid_argument إذا كان r هو Error _ .

val get_ok' : ('a, string) result -> 'a

get_ok' مثل Result.get_ok ولكن في حالة الخطأ يستخدم رسالة الخطأ لرفع Invalid_argument .

منذ 5.4

val get_error : ('a, 'e) result -> 'e

get_error r هو e إذا كان r هو Error e ويرفع استثناءً بخلاف ذلك.

يثير استثناء Invalid_argument إذا كان r هو Ok _ .

val error_to_failure : ('a, string) result -> 'a

error_to_failure r هو v إذا كان r هو Ok v ويرفع Failure e إذا كان r هو Error e .

منذ 5.4

val bind : ('a, 'e) result -> ('a -> ('b, 'e) result) -> ('b, 'e) result

bind r f هو f v إذا كان r هو Ok v و r إذا كان r هو Error _ .

val join : (('a, 'e) result, 'e) result -> ('a, 'e) result

join rr هو r إذا كان rr هو Ok r و rr إذا كان rr هو Error _ .

val map : ('a -> 'b) -> ('a, 'e) result -> ('b, 'e) result

map f r هو Ok (f v) إذا كان r هو Ok v و r إذا كان r هو Error _ .

val product : ('a, 'e) result -> ('b, 'e) result -> ('a * 'b, 'e) result

product r0 r1 هو Ok (v0, v1) إذا كان r0 هو Ok v0 و r1 هو Ok v2 وبخلاف ذلك يعيد خطأ r0 ، إن وجد، أو خطأ r1 .

منذ 5.4

val map_error : ('e -> 'f) -> ('a, 'e) result -> ('a, 'f) result

map_error f r هو Error (f e) إذا كان r هو Error e و r إذا كان r هو Ok _ .

val fold : ok:('a -> 'c) -> error:('e -> 'c) -> ('a, 'e) result -> 'c

fold ~ok ~error r هو ok v إذا كان r هو Ok v و error e إذا كان r هو Error e .

val retract : ('a, 'a) result -> 'a

retract r هو v إذا كان r هو Ok v أو Error v .

iter f r هو f v إذا كان r هو Ok v و () بخلاف ذلك.

iter_error f r هو f e إذا كان r هو Error e و () بخلاف ذلك.

المحددات والمقارنات

val is_ok : ('a, 'e) result -> bool

is_ok r هو true إذا وفقط إذا كان r هو Ok _ .

val is_error : ('a, 'e) result -> bool

is_error r هو true إذا وفقط إذا كان r هو Error _ .

val equal : ok:('a -> 'a -> bool) -> error:('e -> 'e -> bool) -> ('a, 'e) result -> ('a, 'e) result -> bool

equal ~ok ~error r0 r1 يختبر المساواة لـ r0 و r1 باستخدام ok و error لمقارنة القيم المغلفة بواسطة Ok _ و Error _ على التوالي.

val compare : ok:('a -> 'a -> int) -> error:('e -> 'e -> int) -> ('a, 'e) result -> ('a, 'e) result -> int

compare ~ok ~error r0 r1 يرتب تمامًا r0 و r1 باستخدام ok و error لمقارنة القيم المغلفة بواسطة Ok _ و Error _ على التوالي. قيم Ok _ أصغر من قيم Error _ .

التحويل

val to_option : ('a, 'e) result -> 'a option

to_option r هو r كخيار، يقوم بتحويل Ok v إلى Some v و Error _ إلى None .

val to_list : ('a, 'e) result -> 'a list

to_list r هو [v] إذا كان r هو Ok v و [] بخلاف ذلك.

val to_seq : ('a, 'e) result -> 'a Seq.t

to_seq r هو r كمتتالية. Ok v هي المتتالية ذات العنصر الواحد التي تحتوي على v و Error _ هي المتتالية الفارغة.
