الاسم

rdma_listen - الاستماع لطلبات الاتصال الواردة.

الملخص

#include <rdma/rdma_cma.h>

int rdma_listen (struct rdma_cm_id *id, int backlog);

المعاملات

id
معرف RDMA.
backlog
مخزن مؤقت لطلبات الاتصال الواردة.

الوصف

يبدأ الاستماع لطلبات الاتصال الواردة أو البحث عن خدمة datagram. سيتم تقييد الاستماع إلى العنوان المصدر المرتبط محليًا.

قيمة الإرجاع

يعيد 0 عند النجاح، أو -1 عند حدوث خطأ. في حالة حدوث خطأ، سيتم تعيين errno للإشارة إلى سبب الفشل.

ملاحظات

يجب على المستخدمين ربط rdma_cm_id بعنوان محلي عن طريق استدعاء rdma_bind_addr قبل استدعاء هذا الإجراء. إذا كان rdma_cm_id مرتبطًا بعنوان IP معين، فسيتم تقييد الاستماع لهذا العنوان وجهاز RDMA المرتبط. إذا كان rdma_cm_id مرتبطًا برقم منفذ RDMA فقط، فسيحدث الاستماع عبر جميع أجهزة RDMA.
