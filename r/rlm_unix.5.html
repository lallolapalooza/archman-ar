rlm_unix(5) FreeRADIUS Module rlm_unix(5)

الاسم

rlm_unix - وحدة FreeRADIUS

الوصف

تقوم وحدة rlm_unix بقراءة كلمات المرور المشفرة (crypt(3)) من ملف كلمة المرور الخاص بالنظام، وتسمح للخادم باستخدامها للمصادقة. توفر الوحدة أيضًا لـ FreeRADIUS واجهة إلى ملف radwtmp (يستخدمه "radlast") عند إضافته إلى قسم المحاسبة.

يجب إدراج وحدة rlm_unix في قسم "authenticate". يرجى الاطلاع على ملف radiusd.conf الافتراضي الذي يتم شحنه مع الخادم كمثال للاستخدام الصحيح لهذه الوحدة.

اعتبارًا من FreeRADIUS 1.1.0، لم تعد الوحدة تقرأ أو تخزن مؤقتًا ملفات /etc/passwd أو /etc/shadow أو /etc/group. إذا كنت ترغب في تخزين هذه الملفات مؤقتًا، فانظر rlm_passwd. معظم التكوينات، إن لم يكن كلها، لن تحتاج إلى تخزين هذه الملفات مؤقتًا.

عناصر التكوين الرئيسية التي يجب الانتباه إليها هي:

radwtmp
مسار ملف wtmp الخاص بالنظام الذي سيتم استخدامه للاحتفاظ بقاعدة بيانات المستخدمين المتصلين كما يقرأها برنامج 'radlast'.

التكوين

modules {
  ...
  unix {
    radwtmp = ${logdir}/radwtmp
  }
  ...
}

الأقسام

authentication, accounting
