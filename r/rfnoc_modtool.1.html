rfnoc_modtool(1) أوامر المستخدم rfnoc_modtool(1)

الاسم

rfnoc_modtool - أداة إدارة وحدات RFNoC OOT

الوصف

إنشاء وإدارة وحدات RFNoC OOT.

الملخص

rfnoc_modtool [أمر] [خيارات]

الأوامر

قم بتشغيل rfnoc_modtool أمر --help لمزيد من المعلومات حول أمر محدد.

create
إنشاء وحدة RFNoC OOT جديدة.
add
إضافة كتلة جديدة إلى وحدة RFNoC OOT موجودة.
add-gr-oot
إضافة وحدة GNU Radio OOT.
add-gr-block
إضافة كتلة GNU Radio إلى وحدة GNU Radio OOT موجودة.
add-grc
إضافة روابط GNU Radio GRC لكتلة موجودة في وحدة RFNoC OOT هذه.
make-yaml
معالج إنشاء YAML -- إنشاء ملف واصف لكتلة RFNoC بتنسيق YAML بناءً على إدخال المستخدم.

إنشاء وحدات جديدة

عند تشغيل rfnoc_modtool create، سيتم إنشاء دليل جديد يحتوي على الملفات اللازمة لوحدة RFNoC OOT جديدة. سيحتوي هذا الدليل فقط على رمز تمهيدي، وسيحتاج المستخدم إلى إضافة الكتل الخاصة به إلى الوحدة.

من خلال استدعاء 'rfnoc_modtool add-gr-oot'، يمكن للمستخدم إضافة وحدة GNU Radio OOT داخل وحدة RFNoC OOT.

إضافة الكتل

عند تشغيل rfnoc_modtool add، ستتم إضافة كتلة جديدة إلى وحدة RFNoC OOT موجودة. يتطلب هذا تشغيل rfnoc_modtool create سابقًا لإنشاء الوحدة.

لاحظ أنه لكي ينجح 'rfnoc_modtool add'، يجب على المستخدم توفير ملف واصف للكتلة بتنسيق YAML. يصف هذا الملف الكتلة ومعلماتها. يمكن للمستخدم إنشاء هذا الملف يدويًا، أو استخدام معالج إنشاء YAML عن طريق تشغيل rfnoc_modtool make-yaml. سيقوم المعالج بطلب المعلومات الضرورية من المستخدم لإنشاء ملف YAML صالح.

بمجرد إنشاء الكتل، يمكن للمستخدم إضافة كتل GNU Radio أصلية لتمكين تحكم أكثر دقة في كتل RFNoC من GNU Radio عن طريق تشغيل 'rfnoc_modtool add-gr-block'.

لإضافة روابط GNU Radio GRC للكتل، قم باستدعاء 'rfnoc_modtool add-grc'.

أمثلة

إنشاء وحدة RFNoC OOT جديدة تسمى filter

rfnoc_modtool create filter
cd rfnoc-filter

استخدام معالج إنشاء YAML لإنشاء ملف واصف للكتلة

rfnoc_modtool make-yaml

بعد تحرير ملف fir.yml لوصف كتلة مرشح FIR، أضف كتلة تسمى fir إلى وحدة filter

rfnoc_modtool add fir

الآن أضف وحدة GNU Radio OOT

rfnoc_modtool add-gr-oot

أضف كتلة GNU Radio إلى وحدة filter للتحكم في كتلة RFNoC FIR (على سبيل المثال، لتحسين التكامل في أداة تصميم مرشحات GNU Radio)

rfnoc_modtool add-gr-block --gr-blockname rfnoc_fir fir

كشف هذه الكتلة الجديدة في GRC

rfnoc_modtool add-grc --binding-type native fir
