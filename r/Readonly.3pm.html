Readonly(3pm)

الحزمة: perl-readonly

التراخيص: GPL, PerlArtistic

..);
ينشئ مصفوفة غير قابلة للتعديل، @arr، ويعين قائمة القيم المحددة لها. بعد ذلك، لا يمكن تغيير أي من قيمها؛ لا يمكن إطالة المصفوفة أو تقصيرها أو تقسيمها. أي محاولة للقيام بذلك ستتسبب في توقف برنامجك.

إذا كانت أي من القيم التي تم تمريرها مرجعًا إلى قيمة عددية، أو مصفوفة، أو جدول هاش، فستقوم هذه الدالة بتمييز القيمة العددية أو المصفوفة أو جدول الهاش الذي تشير إليه بأنها للقراءة فقط أيضًا، وستقوم بتتبع البنية بشكل متكرر، وتمييز الشيء بأكمله على أنه للقراءة فقط. عادةً، هذا ما تريده. ومع ذلك، إذا كنت تريد فقط تمييز جدول الهاش %@arr نفسه على أنه للقراءة فقط، استخدم "Array1".

إذا كانت @arr بالفعل متغيرًا للقراءة فقط، فسيتوقف البرنامج بخطأ حول إعادة تعيين المتغيرات للقراءة فقط.

Readonly::Hash %h => (key => value, key => value, ...);
Readonly::Hash %h => {key => value, key => value, ...};
ينشئ جدول هاش غير قابل للتعديل، %h، ويعين المفاتيح والقيم المحددة له. بعد ذلك، لا يمكن تغيير مفاتيحه أو قيمه. أي محاولة للقيام بذلك ستتسبب في توقف برنامجك.

يمكن تحديد قائمة مفاتيح وقيم (بأقواس في الملخص أعلاه)، أو يمكن تحديد مرجع لجدول هاش (أقواس معقوفة في الملخص أعلاه). إذا تم تحديد قائمة، فيجب أن تحتوي على عدد زوجي من العناصر، وإلا فسيتوقف البرنامج.

إذا كانت أي من القيم مرجعًا إلى قيمة عددية، أو مصفوفة، أو جدول هاش، فستقوم هذه الدالة بتمييز القيمة العددية أو المصفوفة أو جدول الهاش الذي تشير إليه بأنها للقراءة فقط أيضًا، وستقوم بتتبع البنية بشكل متكرر، وتمييز الشيء بأكمله على أنه للقراءة فقط. عادةً، هذا ما تريده. ومع ذلك، إذا كنت تريد فقط تمييز جدول الهاش %h نفسه على أنه للقراءة فقط، استخدم "Hash1".

إذا كانت %h بالفعل متغيرًا للقراءة فقط، فسيتوقف البرنامج بخطأ حول إعادة تعيين المتغيرات للقراءة فقط.

Readonly $var => $value;
Readonly @arr => (value, value, ...);
Readonly %h => (key => value, ...);
Readonly %h => {key => value, ...};
Readonly $var;
الدالة "Readonly" هي بديل للدوال "Scalar" و "Array" و "Hash". لها ميزة (إذا كنت تعتبرها ميزة) كونها دالة واحدة. قد يجعل ذلك برنامجك يبدو أنظف، إذا كنت تهيئ مجموعة كاملة من الثوابت دفعة واحدة. قد تفضل أو لا تفضل هذا الأسلوب الموحد.

لها عيب وجود بناء جملة مختلف قليلاً للإصدارات السابقة لـ Perl 5.8. للإصدارات الأقدم، يجب عليك توفير شرطة سفلية، لأنها تتطلب مرجعًا كمعامل أول.

Readonly \$var => $value;
Readonly \@arr => (value, value, ...);
Readonly \%h   => (key => value, ...);
Readonly \%h   => {key => value, ...};

قد تعتبر هذا قبيحًا أو لا.

لاحظ أنه يمكنك إنشاء متغيرات غير معرفة ضمنية باستخدام هذه الدالة كما يلي "Readonly my $var;" بينما يجب تمرير قيمة غير معرفة بشكل صريح إلى الدوال القياسية "Scalar" و "Array" و "Hash".

Readonly::Scalar1 $var => $value;
Readonly::Array1 @arr => (value, value, ...);
Readonly::Hash1 %h => (key => value, key => value, ...);
Readonly::Hash1 %h => {key => value, key => value, ...};
تقوم هذه الدوال البديلة بإنشاء متغيرات للقراءة فقط سطحية، بدلاً من متكررة. على سبيل المثال: 
Readonly::Array1 @shal => (1, 2, {perl=>'Rules', java=>'Bites'}, 4, 5);
Readonly::Array  @deep => (1, 2, {perl=>'Rules', java=>'Bites'}, 4, 5);
$shal[1] = 7;           # خطأ
$shal[2]{APL}='Weird';  # مسموح به! لأن جدول الهاش ليس للقراءة فقط
$deep[1] = 7;           # خطأ
$deep[2]{APL}='Weird';  # خطأ، لأن جدول الهاش للقراءة فقط

الاستنساخ

عند الاستنساخ باستخدام Storable أو Clone ستلاحظ أن القيمة تظل للقراءة فقط، وهذا صحيح. إذا كنت ترغب في استنساخ القيمة دون نسخ علامة القراءة فقط، استخدم الدالة "Clone":

Readonly::Scalar my $scalar => {qw[this that]};
# $scalar->{'eh'} = 'foo'; # محاولة تعديل قيمة للقراءة فقط
my $scalar_clone = Readonly::Clone $scalar;
$scalar_clone->{'eh'} = 'foo';
# $scalar_clone هو الآن {this => 'that', eh => 'foo'};

المتغير الجديد ($scalar_clone) هو نسخة قابلة للتعديل من $scalar الأصلي.

أمثلة

هذه بعض الأمثلة البسيطة جدًا:

قيم عددية

قيمة عادية للقراءة فقط

Readonly::Scalar $a => "A string value";

ليست هناك حاجة لأن تكون القيمة ثابتة وقت التصريف:

Readonly::Scalar $a => $computed_value;

مصفوفات/قوائم

مصفوفة للقراءة فقط:

Readonly::Array @a => (1, 2, 3, 4);

الأقواس اختيارية:

Readonly::Array @a => 1, 2, 3, 4;

يمكنك استخدام بناء جملة اقتباس المصفوفة المدمج في Perl:

Readonly::Array @a => qw/1 2 3 4/;

يمكنك تهيئة مصفوفة للقراءة فقط من مصفوفة متغيرة:

Readonly::Array @a => @computed_values;

يمكن أن تكون المصفوفة للقراءة فقط فارغة أيضًا:

Readonly::Array @a => ();
Readonly::Array @a;        # مكافئ

جداول هاش

الاستخدام النموذجي:

Readonly::Hash %a => (key1 => 'value1', key2 => 'value2');

يمكن تهيئة جدول هاش للقراءة فقط من جدول هاش متغير:

Readonly::Hash %a => %computed_values;

يمكن أن يكون جدول الهاش للقراءة فقط فارغًا:

Readonly::Hash %a => ();
Readonly::Hash %a;        # مكافئ

إذا مررت عددًا فرديًا من القيم، فسيتوقف البرنامج:

Readonly::Hash %a => (key1 => 'value1', "value2");
# هذا يتوقف مع "لا يمكن تخزين عدد فردي من القيم في جدول هاش"

التصدير

تاريخيًا، تقوم هذه الوحدة بتصدير الرمز "Readonly" إلى مساحة اسم البرنامج المستدعي افتراضيًا. الرموز التالية متاحة أيضًا للاستيراد إلى برنامجك، إذا كنت ترغب في ذلك: "Scalar" و "Scalar1" و "Array" و "Array1" و "Hash" و "Hash1".

الداخلية

بعض الناس ببساطة لا يفهمون العلاقة بين هذه الوحدة و Readonly::XS لذلك أضيف هذا القسم. على الأرجح، ما زالوا لا يفهمون، لكنني أحب الكتابة لذلك...

في الماضي، كان "سحر" Readonly يتم عن طريق ربط المتغيرات (tie-ing) بحزم "Readonly::Scalar" و "Readonly::Array" و "Readonly::Hash" (حتى لا يتم الخلط بينها وبين الدوال التي تحمل نفس الأسماء) والعمل على "WRITE" و "READ" وما إلى ذلك. بينما نجح هذا بشكل جيد، كان بطيئًا. بطيئًا جدًا. أبطأ بحوالي 20-30 مرة من الوصول المباشر للمتغيرات أو استخدام إحدى وحدات الثوابت الأخرى ذات الصلة التي ظهرت منذ إصدار Readonly في عام 2003.

لـ "إصلاح" هذا، تم إنشاء Readonly::XS. إذا تم تثبيته، استخدم Readonly::XS الطرق الداخلية "SvREADONLY" و "SvREADONLY_on" لقفل القيم العددية البسيطة. على السطح، كان كل شيء على ما يرام ولكن الأمور لم تكن كما هي خلف الكواليس. في حالات الحافة، كان أداء الكود مختلفًا جدًا إذا تم تثبيت Readonly::XS وبما أنه لم يكن تبعية مطلوبة في معظم التعليمات البرمجية، فقد جعل أخطاء المصب صعبة التتبع للغاية.

في السنوات التي تلت إصدار Readonly::XS، تم الكشف عن الطرق الداخلية الخاصة سابقًا ويمكن استخدامها في pure perl. تم كتابة وحدات مماثلة للاستفادة من ذلك وتم إنشاء تصحيح لـ Readonly. لم نعد بحاجة إلى بناء وتثبيت وحدة أخرى لجعل Readonly مفيدًا على الإصدارات الحديثة من perl.

  • لا تحتاج إلى تثبيت Readonly::XS.
  • يجب عليك التوقف عن سرد Readonly::XS كاعتمادية أو توقع تثبيته.
  • توقف عن اختبار المتغير $Readonly::XSokay!

المتطلبات

يرجى ملاحظة أن معظم مستخدمي Readonly لم يعودوا بحاجة إلى تثبيت الوحدة المصاحبة Readonly::XS التي يوصى بها ولكنها غير مطلوبة لـ perl 5.6.x وما دون. يرجى عدم فرضها كمتطلب في التعليمات البرمجية الجديدة وعدم استخدام متغير الحزمة $Readonly::XSokay في التعليمات البرمجية/الاختبارات. لمزيد من المعلومات، انظر "Internals" في القسم الخاص بالداخلية الجديدة لـ Readonly.

لا توجد متطلبات خارج core.
