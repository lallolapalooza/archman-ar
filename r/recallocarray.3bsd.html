recallocarray(3bsd)

الحزمة: libbsd

التراخيص: custom

reallocarray(3bsd) 3bsd reallocarray(3bsd)

الاسم

reallocarray، recallocarray، freezero — تخصيص وإلغاء تخصيص الذاكرة

المكتبة

المكتبة «libbsd»

الملخص

#include <stdlib.h> (انظر libbsd(7) لاستخدام التضمين.)
void *
reallocarray(void *ptr, size_t nmemb, size_t size);

void *
recallocarray(void *ptr, size_t oldnmemb, size_t nmemb, size_t size);

void
freezero(void *ptr, size_t size);

الوصف

تم تصميم الدالة reallocarray() لتخصيص المصفوفات بأمان، وهي مشابهة للدالة realloc() باستثناء أنها تعمل على nmemb عضو بحجم size وتتحقق من تجاوز الأعداد الصحيحة في عملية الحساب nmemb * size.

تُستخدم الدالة recallocarray() لتخصيص الذاكرة التي تحتوي على بيانات حساسة، وتضمن الدالة recallocarray() أن الذاكرة التي تم إلغاء تخصيصها يتم التخلص منها بشكل صريح، مما يعني أن الكائنات المجانية المخزنة مؤقتًا يتم مسحها باستخدام explicit_bzero(3).

الدالة recallocarray() مشابهة للدالة reallocarray() باستثناء أنها تضمن مسح الذاكرة المخصصة حديثًا بشكل مشابه للدالة calloc(). إذا كان ptr يساوي NULL، يتم تجاهل oldnmemb وتكون المكالمة مكافئة للمكالمة calloc(). إذا كان ptr لا يساوي NULL، يجب أن تكون oldnmemb قيمة تجعل oldnmemb * size هو حجم التخصيص السابق الذي أعاد ptr، وإلا فإن السلوك غير معرف. الدالة freezero() مشابهة للدالة free() باستثناء أنها تضمن التخلص من الذاكرة بشكل صريح. إذا كان ptr يساوي NULL، فلا يتم اتخاذ أي إجراء. إذا كان ptr لا يساوي NULL، يجب أن تكون قيمة الوسيط size مساوية أو أصغر من حجم التخصيص السابق الذي أعاد ptr. تضمن freezero() مسح نطاق الذاكرة الذي يبدأ من ptrsize أثناء إلغاء تخصيص الكائن بأكمله الذي تم تخصيصه في الأصل.

قيم الإرجاع

تُرجع الدالتان reallocarray() و recallocarray() مؤشرًا إلى المساحة المخصصة إذا نجحت؛ وإلا، يتم إرجاع مؤشر فارغ ويتم تعيين errno إلى ENOMEM.

إذا أدت ضرب nmemb و size إلى تجاوز عدد صحيح، فإن reallocarray() و recallocarray() ترجعان NULL وتعيّنان errno إلى ENOMEM.

إذا كان ptr لا يساوي NULL وأدت ضرب oldnmemb و size إلى تجاوز عدد صحيح، فإن recallocarray() ترجع NULL وتعيّن errno إلى EINVAL.

أساليب شائعة

ضع في اعتبارك calloc() أو امتدادات reallocarray() و recallocarray() عندما يكون هناك ضرب في الوسيط size للدالة malloc() أو realloc(). على سبيل المثال، تجنب هذا الأسلوب الشائع لأنه قد يؤدي إلى تجاوز الأعداد الصحيحة:

if ((p = malloc(num * size)) == NULL)
	err(1, NULL);

البديل المباشر هو reallocarray():

if ((p = reallocarray(NULL, num, size)) == NULL)
	err(1, NULL);

بدلاً من ذلك، يمكن استخدام calloc() بتكلفة تكلفة التهيئة.

عند استخدام realloc()، كن حذرًا لتجنب الأسلوب التالي:

size += 50;
if ((p = realloc(p, size)) == NULL)
	return (NULL);

لا تقم بتعديل المتغير الذي يصف مقدار الذاكرة التي تم تخصيصها حتى تنجح عملية التخصيص. هذا يمكن أن يسبب سلوكًا شاذًا للبرنامج إذا تم استخدام قيمة حجم غير صحيحة. في معظم الحالات، ستؤدي العينة أعلاه أيضًا إلى تسرب في الذاكرة. كما ذكرنا سابقًا، يشير إرجاع قيمة NULL إلى أن الكائن القديم لا يزال مخصصًا. الكود الأفضل يبدو كالتالي:

newsize = size + 50;
if ((newp = realloc(p, newsize)) == NULL) {
	free(p);
	p = NULL;
	size = 0;
	return (NULL);
}
p = newp;
size = newsize;

كما هو الحال مع malloc()، من المهم التأكد من أن قيمة الحجم الجديدة لن تتجاوز؛ أي تجنب التخصيصات مثل التالية:

if ((newp = realloc(p, num * size)) == NULL) {
	...

بدلاً من ذلك، استخدم reallocarray():

if ((newp = reallocarray(p, num, size)) == NULL) {
	...

استدعاء realloc() مع ptr يساوي NULL يكافئ استدعاء malloc(). بدلاً من هذا الأسلوب:

if (p == NULL)
	newp = malloc(newsize);
else
	newp = realloc(p, newsize);

استخدم ما يلي:

newp = realloc(p, newsize);

يجب استخدام الدالة recallocarray() لتغيير حجم الكائنات التي تحتوي على بيانات حساسة مثل المفاتيح. لتجنب تسريب المعلومات، تضمن مسح الذاكرة قبل وضعها في قائمة الذاكرة المجانية الداخلية. يجب أن يتم إلغاء تخصيص مثل هذا الكائن عن طريق استدعاء freezero().

recallocarray(3bsd)

NAME

recallocarray - allocate and initialize memory with calloc(3) and realloc(3)

LIBRARY

Math library (libbsd), C library (libc)

SYNOPSIS

void *recallocarray(void *ptr, size_t nmemb, size_t size);

DESCRIPTION

The recallocarray() function is similar to realloc(3), but initializes the allocated memory with calloc(3) semantics. It allocates a new memory block of size nmemb * size bytes, copies the old data to the new memory block, and initializes the rest of the memory with zeros. If ptr is NULL, the behavior is the same as calloc(3). If nmemb or size is zero, the behavior is the same as realloc(3). recallocarray() returns a pointer to the newly allocated memory block, or NULL if the allocation fails. The allocated memory is automatically freed when the program terminates.

RETURN VALUES

On success, recallocarray() returns a pointer to the allocated memory. On failure, it returns NULL.

IDIOMS

The recallocarray() function is useful for allocating and resizing arrays of elements, ensuring that the newly allocated memory is initialized to zero. This can help prevent common programming errors caused by uninitialized memory.

SEE ALSO

calloc(3bsd), malloc(3bsd), realloc(3bsd)

HISTORY

The recallocarray() function first appeared in DragonFly 5.5.
