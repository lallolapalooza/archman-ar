ratbagctl(1)

الحزمة: libratbag

التراخيص: MIT

RATBAGCTL(1) دليل الأوامر العامة RATBAGCTL(1)

الاسم

ratbagctl - فحص وتعديل الفئران القابلة للتكوين

الملخص

ratbagctl [<خيارات>] list
ratbagctl [<خيارات>] <جهاز> <أمر> ...

الوصف

تقوم أداة ratbagctl بالاستعلام عن إعدادات الجهاز أو تغييرها.

عادة ما تتطلب هذه الأداة أن يكون ratbagd قيد التشغيل.

خيارات

--version, -V
عرض رقم إصدار البرنامج والخروج.
--verbose, -v
طباعة مخرجات التصحيح. خيارات -v المتعددة تزيد من مستوى التفاصيل. على سبيل المثال، -vvv ستعرض مخرجات البروتوكول.
--nocommit
لا تقم بكتابة الإعدادات إلى الماوس على الفور. هذا يسمح بتعيين معلمات متعددة في برنامج نصي، وسيتم كتابة جميعها بواسطة استدعاء ratbagctl الأخير.
--help, -h
طباعة المساعدة.

الأوامر العامة

list
قائمة الأجهزة المدعومة (لا تأخذ وسيطة جهاز)

أوامر الجهاز

info
طباعة معلومات حول جهاز
name
طباعة اسم الجهاز

أوامر الملف الشخصي

profile active get
طباعة الملف الشخصي النشط حاليًا
profile active set N
تعيين الملف الشخصي N كملف شخصي نشط
profile N {COMMAND}
استخدام الملف الشخصي N للأمر COMMAND

الأوامر المتاحة:

get
طباعة معلومات الملف الشخصي المحدد
name get
طباعة اسم الملف الشخصي
name set blah
تعيين اسم الملف الشخصي
enable
تمكين ملف شخصي
disable
تعطيل ملف شخصي
[resolution|dpi|rate|button|led] ...
استخدام الملف الشخصي N للأمر المحدد.

أوامر الدقة

تعمل أوامر الدقة على الملف الشخصي المحدد، أو على الملف الشخصي النشط إذا لم يتم تحديد أي شيء.

resolution active get
طباعة الدقة النشطة حاليًا
resolution active set N
تعيين الدقة N كدقة نشطة
resolution default get
طباعة الدقة الافتراضية الحالية
resolution default set N
تعيين الدقة N كدقة افتراضية
resolution N {COMMAND}
استخدام الدقة N للأمر COMMAND

الأوامر المتاحة:

get
طباعة الدقة المحددة
[dpi|rate] ...
استخدام الدقة N للأمر المحدد.

أوامر DPI

تعمل أوامر DPI على الملف الشخصي والدقة المحددين، أو على الدقة النشطة للملف الشخصي النشط إذا لم يتم تحديد أي شيء.

dpi get
طباعة قيمة DPI
dpi get-all
طباعة قيم DPI المدعومة
dpi set N
تعيين قيمة DPI إلى N

أوامر المعدل

تعمل أوامر المعدل على الملف الشخصي والدقة المحددين، أو على الدقة النشطة للملف الشخصي النشط إذا لم يتم تحديد أي شيء.

rate get
طباعة معدل الإبلاغ بالمللي ثانية
rate get-all
طباعة معدلات الإبلاغ المدعومة بالمللي ثانية
rate set N
تعيين معدل الإبلاغ إلى N مللي ثانية

أوامر الأزرار

تعمل أوامر الأزرار على الملف الشخصي المحدد، أو على الملف الشخصي النشط إذا لم يتم تحديد أي شيء.

button count
طباعة عدد الأزرار
button N get
طباعة الزر المحدد
button N action get
طباعة إجراء الزر
button N action set button B
تعيين إجراء الزر إلى الزر B
button N action set special S
تعيين إجراء الزر إلى الإجراء الخاص S
button N action set macro ...
تعيين إجراء الزر إلى الماكرو المحدد

صيغة الماكرو:

الماكرو هو سلسلة من أحداث المفاتيح أو فترات الانتظار. يجب تحديد المفاتيح بأسماء المفاتيح في linux/input-event-codes.h.

KEY_A
الضغط على 'a' ثم تحريرها
+KEY_A
الضغط على 'a'
-KEY_A
تحرير 'a'
t300
الانتظار 300 مللي ثانية

أوامر LED

تعمل أوامر LED على الملف الشخصي المحدد، أو على الملف الشخصي النشط إذا لم يتم تحديد أي شيء.

led get
طباعة قيم LED الحالية
led N get
طباعة قيمة LED المحددة
led N {COMMAND}
استخدام LED N للأمر COMMAND

الأوامر المتاحة:

mode [on|off|cycle|breathing]
الوضع المراد تعيينه كحالي
color RRGGBB
اللون المراد تعيينه كحالي (يجب أن يكون اللون بتنسيق سداسي عشري).
rate R
المعدل المراد تعيينه كحالي
brightness B
السطوع المراد تعيينه كحالي

أمثلة

ratbagctl profile active get eventX
ratbagctl profile 0 resolution active set 4 eventX
ratbagctl profile 0 resolution 1 dpi get eventX

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
