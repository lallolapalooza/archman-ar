NAME

ragg2 - rainbow generating tool

SYNOPSIS

ragg2 [-a] [-b bit] [-c count] [-d] [-e] [-f file] [-F fmt] [-g] [-h] [-i] [-l len] [-m mask] [-n nbytes] [-o offset] [-O] [-p ptr] [-r] [-R] [-s size] [-S] [-t nthreads] [-u] [-v] [-w width] [-x] [-z] [in]

DESCRIPTION

ragg2 is a rainbow table generating tool. It is used to generate rainbow tables, which are precomputed tables used in cryptography for reversing cryptographic hash functions, usually for password cracking.

The tool can generate tables for various hash functions and supports different configuration options to customize the table generation process.

DIRECTIVES

ragg2 supports various directives to control its behavior:

  • -a: Enable ASCII output.
  • -b bit: Set the bit size for the hash function.
  • -c count: Specify the number of chains in the table.
  • -d: Dump the generated table.
  • -e: Enable entropy calculation.
  • -f file: Read input from a file.
  • -F fmt: Set the output format.
  • -g: Generate a grayscale table.
  • -h: Display help message.
  • -i: Invert the color scheme.
  • -l len: Set the length of the chains.
  • -m mask: Apply a mask to the input.
  • -n nbytes: Specify the number of bytes for the hash.
  • -o offset: Set the offset for the table.
  • -O: Overwrite existing files.
  • -p ptr: Set a pointer for the table.
  • -r: Generate a raw table.
  • -R: Generate a reversed table.
  • -s size: Set the size of the table.
  • -S: Use a simple hash function.
  • -t nthreads: Set the number of threads to use.
  • -u: Use Unicode characters.
  • -v: Show version information.
  • -w width: Set the width of the output.
  • -x: Generate hexadecimal output.
  • -z: Zero-fill the table.
  • in: The input data to be used for table generation.

EXAMPLE

Generate a simple rainbow table for MD5 hashes:

ragg2 -c 1000 -l 1000 md5sum < passwords.txt > rainbow.db
