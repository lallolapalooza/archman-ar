RSA_print(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

RSA_PRINT(3ssl) OpenSSL RSA_PRINT(3ssl)

الاسم

RSA_print, RSA_print_fp, DSAparams_print, DSAparams_print_fp, DSA_print, DSA_print_fp, DHparams_print, DHparams_print_fp - طباعة المعلمات التشفيرية

مُلَخَّص

#include <openssl/rsa.h>

تم إيقاف الدوال التالية اعتبارًا من OpenSSL 3.0، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

int RSA_print(BIO *bp, const RSA *x, int offset);
int RSA_print_fp(FILE *fp, const RSA *x, int offset);
#include <openssl/dsa.h>

تم إيقاف الدوال التالية اعتبارًا من OpenSSL 3.0، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

int DSAparams_print(BIO *bp, const DSA *x);
int DSAparams_print_fp(FILE *fp, const DSA *x);
int DSA_print(BIO *bp, const DSA *x, int offset);
int DSA_print_fp(FILE *fp, const DSA *x, int offset);
#include <openssl/dh.h>

تم إيقاف الدوال التالية اعتبارًا من OpenSSL 3.0، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

int DHparams_print(BIO *bp, DH *x);
int DHparams_print_fp(FILE *fp, const DH *x);

الوصف

جميع الدوال الموصوفة في هذه الصفحة قد تم إيقافها. يجب على التطبيقات استخدام EVP_PKEY_print_params(3) و EVP_PKEY_print_private(3) بدلاً من ذلك.

تتم طباعة إخراج سداسي عشري قابل للقراءة من قبل الإنسان لمكونات مفتاح RSA، أو معلمات DSA أو مفتاحه، أو معلمات DH إلى bp أو fp.

تتم إزاحة الأسطر الناتجة بمقدار offset مسافة.

قيم الإرجاع

DSAparams_print()، DSAparams_print_fp()، DSA_print()، و DSA_print_fp() تُرجع 1 للنجاح و 0 أو قيمة سالبة للفشل.

DHparams_print() و DHparams_print_fp() تُرجع 1 عند النجاح، و 0 عند الخطأ.

انظر أيضًا

L<EVP_PKEY_print_params(3)>,
L<EVP_PKEY_print_private(3)>,
L<BN_bn2bin(3)>
