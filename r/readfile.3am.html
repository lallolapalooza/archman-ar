readfile(3am)

الحزمة: gawk

التراخيص: GPL-3.0-or-later

READFILE(3am) وحدات ملحقات GNU Awk READFILE(3am)

الاسم

readfile - إرجاع محتويات ملف كاملة كسلسلة نصية

الملخص

@load "readfile"

result = readfile("/some/path")

لجعل الملفات بأكملها سجلات فردية:

@load "readfile"
BEGIN { PROCINFO["readfile"] = 1 }

الوصف

تضيف الملحقة readfile دالة واحدة تسمى readfile(). الوسيط هو اسم الملف المراد قراءته. القيمة المرتجعة هي سلسلة نصية تحتوي على المحتويات الكاملة للملف المطلوب.

عند حدوث خطأ، ترجع الدالة سلسلة فارغة وتعين ERRNO.

بالإضافة إلى ذلك، تضيف محلل إدخال يتم تنشيطه إذا كان PROCINFO["readfile"] موجودًا. عند التنشيط، يتم إرجاع كل ملف إدخال بكامله كـ $0. يتم تعيين RT إلى سلسلة فارغة.

مثال

@load "readfile"
...
contents = readfile("/path/to/file");
if (contents == "" && ERRNO != "") {
    print("problem reading file", ERRNO) > "/dev/stderr"
    ...
}
