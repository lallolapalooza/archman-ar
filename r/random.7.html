random(7)

NAME

random, urandom - cryptographically strong pseudo-random number generator

SYNOPSIS

/dev/random /dev/urandom

DESCRIPTION

/dev/random and /dev/urandom are special files that serve as a **random number generator**. The primary difference between them is the way they handle entropy exhaustion.

ENTROPY

/dev/random generates pseudo-random numbers using an entropy pool. This pool is fed by various sources of randomness, such as hardware interrupts (mouse movements, keyboard input, disk activity), and other system events. When the entropy pool is depleted, /dev/random will block until enough new entropy is gathered. This means that reads from /dev/random may block indefinitely if the system does not have sufficient entropy.

NON-BLOCKING BEHAVIOR

/dev/urandom is a pseudo-random number generator that does not block. It uses a cryptographically secure pseudo-random number generator (CSPRNG) that is seeded from the same entropy pool as /dev/random . Once the pool has been sufficiently initialized, /dev/urandom will not block. Instead, it will return data from the CSPRNG, which is considered secure for most cryptographic purposes.

USE CASES

For most applications, including cryptographic ones, /dev/urandom is the preferred source of randomness. It provides a good balance between security and performance, as it does not block.

/dev/random should only be used when absolute certainty about the randomness quality is required, and blocking is acceptable. This might be the case for generating very long-term keys or in highly sensitive environments where the risk of entropy exhaustion is a critical concern.

random(7)

الاسم

random, urandom - مولد أرقام عشوائية زائف قوي تشفيريًا

ملخص

/dev/random /dev/urandom

الوصف

/dev/random و /dev/urandom هما ملفان خاصان يعملان كـ **مولد أرقام عشوائية**. الفرق الرئيسي بينهما هو الطريقة التي يتعاملان بها مع استنفاد الإنتروبيا.

الإنتروبيا

/dev/random يولد أرقامًا عشوائية زائفة باستخدام مجمع إنتروبيا. يغذي هذا المجمع بمصادر عشوائية متنوعة، مثل مقاطعات الأجهزة (حركات الماوس، إدخال لوحة المفاتيح، نشاط القرص)، وأحداث النظام الأخرى. عندما يستنفد مجمع الإنتروبيا، /dev/random سيتم حظره حتى يتم جمع ما يكفي من الإنتروبيا الجديدة. هذا يعني أن القراءات من /dev/random قد يتم حظرها إلى أجل غير مسمى إذا لم يكن لدى النظام إنتروبيا كافية.

السلوك غير الحاجب

/dev/urandom هو مولد أرقام عشوائية زائف لا يتم حجبه. يستخدم مولد أرقام عشوائية زائف آمن تشفيريًا (CSPRNG) يتم بذره من نفس مجمع الإنتروبيا مثل /dev/random . بمجرد تهيئة المجمع بشكل كافٍ، /dev/urandom لن يتم حظره. بدلاً من ذلك، سيعيد بيانات من CSPRNG، والتي تعتبر آمنة لمعظم الأغراض التشفيرية.

حالات الاستخدام

بالنسبة لمعظم التطبيقات، بما في ذلك التطبيقات التشفيرية، /dev/urandom هو المصدر المفضل للعشوائية. يوفر توازنًا جيدًا بين الأمان والأداء، لأنه لا يتم حجبه.

/dev/random يجب استخدامه فقط عندما يكون التأكد المطلق من جودة العشوائية مطلوبًا، والحجب مقبول. قد يكون هذا هو الحال لتوليد مفاتيح طويلة الأمد جدًا أو في البيئات شديدة الحساسية حيث يكون خطر استنفاد الإنتروبيا مصدر قلق حرج.
