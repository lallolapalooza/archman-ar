الحزمة: rspamd

التراخيص: Apache-2.0

NAME

rspamc — Rspamd client utility

SYNOPSIS

rspamc [-a | --action ] action [-i | --ip ] ip [-H | --host ] host [-p | --port ] port [-k | --key ] key [-d | --daemon ] daemon [-t | --timeout ] timeout [-f | --config ] config [-v | --verbose ] [-n | --no-decode ] [-c | --compact ] [--sleep ] [-h | --help ] [--version ] file ...

DESCRIPTION

The rspamc utility is a client for Rspamd mail filter. It sends mail messages to the specified Rspamd instance for processing. The following actions are supported:

check
Check the message and return its scores. This is the default action if no action is specified.
reject
Check the message and return verdict for rejection. This is useful for scripts that should exit with a non-zero status if the message is considered spam.
headers
Check the message and return modified headers. This is useful for integrating Rspamd into mail transfer agents.
symbols
Check the message and return symbols list without scores.

If rspamc is invoked without any arguments, it will read messages from standard input and print their processing results to standard output. If one or more filenames are specified, rspamc will process these files sequentially.

By default, rspamc connects to the Rspamd instance listening on 127.0.0.1:11334. The -i, -H, and -p options can be used to override these defaults.

The rspamc utility sends mail messages using the SMTP protocol over the connection specified by the options. It injects mail by using the standard SMTP protocol commands:

EHLO dummy.example.com
MAIL FROM: <sender@example.com>
RCPT TO: <recipient@example.com>
DATA
... mail content ...
.
QUIT

The sender and recipients are faked in this process. The original sender and recipient information is passed using Rspamd specific protocol extensions.

OPTIONS

-a action
--action=action
Perform specified action. Supported actions: check, reject, headers, symbols.
-i ip
--ip=ip
IP address of Rspamd instance. Defaults to 127.0.0.1.
-H host
--host=host
Hostname of Rspamd instance. If not specified, then rspamc tries to connect using IP address.
-p port
--port=port
Port of Rspamd instance. Defaults to 11334.
-k key
--key=key
Password for authentication. This option is ignored if Rspamd instance does not require authentication.
-d daemon
--daemon=daemon
Name of Rspamd daemon to connect to. Defaults to resque.
-t timeout
--timeout=timeout
Connection timeout in seconds. Defaults to 10.
-f config
--config=config
Rspamd configuration file. This option is not used by client utility and is present only for compatibility with older versions.
-v
--verbose
Increase verbosity level.
-n
--no-decode
Do not decode message parts.
-c
--compact
Use compact output format for scores.
--sleep
Add a sleep command to the end of mail.
-h
--help
Print help message.
--version
Print version information.

RETURN VALUE

The exit status is 0 if the message was processed successfully. For the reject action, the exit status is 1 if the message is considered spam, and 0 otherwise. If any error occurs during processing, rspamc exits with status 2.

EXAMPLES

Check a single mail message:

$ rspamc check < message.eml

Reject a single mail message, exiting with status 1 if it is spam:

$ rspamc reject < message.eml
$ echo $?

Check multiple mail messages:

$ rspamc check file1.eml file2.eml

Connect to a remote Rspamd instance:

$ rspamc -H 192.168.1.100 -p 11334 check < message.eml

Use specific action reject:

add_action reject 7.1
