rlm_sqlippool_tool(8)

الحزمة: freeradius

التراخيص: GPL-2.0-or-later

RLM_SQLIPPOOL_TOOL(8) دليل مدير النظام RLM_SQLIPPOOL_TOOL(8)

الاسم

rlm_sqlippool_tool - إدارة مجموعات عناوين IP في SQL

ملخص

rlm_sqlippool_tool -p اسم_المجموعة -s بداية_النطاق -e نهاية_النطاق -t اسم_الجدول -d -f دليل_raddb -i مثيل [-c السعة] [-x ملف_العناوين_الموجودة]

rlm_sqlippool_tool -y ملف_تعريفات_المجموعات_yaml -t اسم_الجدول -d -f دليل_raddb -i مثيل [-x ملف_العناوين_الموجودة]

الوصف

rlm_sqlippool_tool هي أداة لإدارة عناوين IP في مجموعات IP المستندة إلى SQL كما يستخدمها FreeRADIUS. ستقوم إما بإخراج SQL الذي يمكن استخدامه لمعالجة قاعدة البيانات أو التفاعل مباشرة مع قاعدة بيانات لتعبئة جدول لمجموعات IP.

يعتمد تنسيق إخراج SQL أو الأوامر التي تم تشغيلها على قاعدة البيانات على مخططات FreeRADIUS ippool الافتراضية. الحقول التي يتم ملؤها هي اسم_المجموعة و framedipaddress. تُترك جميع الحقول الأخرى ليتم ملؤها بقيمها الافتراضية في قاعدة البيانات.

الخيارات

-c السعة
عدد عناوين IP لملء المجموعة بها. القيمة الافتراضية هي 65536، أو الحد الأقصى لعدد يمكن توفيره بين بداية ونهاية النطاق.
-d اللهجة
لهجة SQL المستخدمة لإنتاج الإخراج.
-e نهاية_النطاق
عنوان IP النهائي في نطاق المجموعة. يُسمح بعناوين IPv4 أو IPv6.
-f دليل_raddb
الدليل الذي يحتوي على تكوين FreeRADIUS. إذا تم تحديد هذا الخيار، فسيقوم rlm_sqlippool_tool بتحليل التكوين ومحاولة التحدث مباشرة إلى خادم قاعدة البيانات المحدد في تكوين FreeRADIUS.
-i مثيل
يستخدم بالاقتران مع -f. يحدد اسم مثيل وحدة SQL المراد تحليله في تكوين FreeRADIUS. القيمة الافتراضية هي sql.
-p اسم_المجموعة
اسم المجموعة المراد ملؤها.
-s بداية_النطاق
عنوان IP الأولي في نطاق المجموعة. يُسمح بعناوين IPv4 أو IPv6.
-t اسم_الجدول
اسم الجدول في قاعدة البيانات المراد ملؤها.
-x ملف_العناوين_الموجودة
ملف يحتوي على عناوين IP الموجودة في المجموعة. يسمح استخدامه بالنمو المتحكم فيه بشكل أكبر لمجموعة ذات عدد قليل من العناوين.
-y ملف_تعريفات_المجموعات_yaml
ملف بتنسيق YAML يحتوي على مواصفات لعدد من المجموعات.

أمثلة

لإنتاج SQL بتنسيق MySQL لمجموعة تسمى local مملوءة بعناوين من 10.0.0.1 إلى 10.0.0.199:

$ rlm_sqlippool_tool -p local -s 10.0.0.1 -e 10.0.0.199 \
    -t dhcpippool -d mysql

للقيام بنفس الشيء ولكن بالتفاعل مباشرة مع وحدة SQL المكونة في تكوين FreeRADIUS تحت /etc/raddb:

$ rlm_sqlippool_tool -p local -s 10.0.0.1 -e 10.0.0.199 \
    -t dhcpippool -f /etc/raddb

لاستخدام ملف YAML لتحديد نطاقات المجموعات التي سيتم ملؤها، وإخراج SQL بتنسيق PostgreSQL:

$ rlm_sqlippool_tool -y pools.yaml -t dhcpippool -d postgresql

تنسيق YAML

يجب تنسيق ملف YAML لملء مجموعات متعددة كما يلي:

pool_with_a_single_contiguous_range:
  - start:    192.0.2.3
    end:      192.0.2.250
pool_with_a_single_sparse_range:
  - start:    10.10.10.0
    end:      10.10.20.255
    capacity: 200
pool_with_multiple_ranges:
  - start:    10.10.10.1
    end:      10.10.10.253
  - start:    10.10.100.0
    end:      10.10.199.255
    capacity: 1000
v6_pool_with_contiguous_range:
  - start:    '2001:db8:1:2:3:4:5:10'
    end:      '2001:db8:1:2:3:4:5:7f'
v6_pool_with_sparse_range:
  - start:    '2001:db8:1:2::'
    end:      '2001:db8:1:2:ffff:ffff:ffff:ffff'
    capacity: 200

متطلبات

لإخراج SQL بتنسيق، يلزم وجود وحدة Perl Template::Toolkit.

يتم الاتصال المباشر بقواعد البيانات باستخدام Perl DBI. يجب تثبيت مشغل Perl DBD المناسب لتمكين هذه الوظيفة.
