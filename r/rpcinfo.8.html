RPCINFO(8) دليل مدير النظام RPCINFO(8)

الاسم

rpcinfo — تقرير معلومات RPC

الاختصار

rpcinfo [-m | -s] [المضيف]

rpcinfo -p [المضيف]

rpcinfo -T النقل المضيف رقم_البرنامج [رقم_الإصدار]

rpcinfo -l [-T النقل] المضيف رقم_البرنامج رقم_الإصدار

rpcinfo [-n رقم_المنفذ] -u المضيف رقم_البرنامج [رقم_الإصدار]

rpcinfo [-n رقم_المنفذ] [-t] المضيف رقم_البرنامج [رقم_الإصدار]

rpcinfo -a عنوان_الخادم -T النقل رقم_البرنامج [رقم_الإصدار]

rpcinfo -b [-T النقل] رقم_البرنامج رقم_الإصدار

rpcinfo -d [-T النقل] رقم_البرنامج رقم_الإصدار

الوصف

rpcinfo يقوم بإجراء استدعاء RPC إلى خادم RPC ويبلغ عما يجده.

في الاختصار الأول، تسرد rpcinfo جميع خدمات RPC المسجلة مع rpcbind على المضيف. إذا لم يتم تحديد المضيف، يكون المضيف المحلي هو الافتراضي. إذا تم استخدام -s، يتم عرض المعلومات بتنسيق موجز.

في الاختصار الثاني، تسرد rpcinfo جميع خدمات RPC المسجلة مع rpcbind، الإصدار 2. لاحظ أيضًا أن تنسيق المعلومات مختلف في الاختصار الأول والثاني. هذا لأنه بروتوكول أقدم مستخدم لجمع المعلومات المعروضة (الإصدار 2 من بروتوكول rpcbind).

يجري الاختصار الثالث استدعاء RPC للإجراء 0 من رقم_البرنامج و رقم_الإصدار على المضيف المحدد ويبلغ عما إذا تم تلقي استجابة. النقل هو وسيلة النقل التي يجب استخدامها للاتصال بالخدمة المعطاة. يتم الحصول على العنوان البعيد للخدمة عن طريق إجراء استدعاء إلى rpcbind البعيد.

الوسيط رقم_البرنامج هو رقم يمثل رقم برنامج RPC. إذا تم تحديد رقم_الإصدار، تحاول rpcinfo استدعاء هذا الإصدار من رقم_البرنامج المحدد. بخلاف ذلك، تحاول rpcinfo العثور على جميع أرقام الإصدارات المسجلة لـ رقم_البرنامج المحدد عن طريق استدعاء الإصدار 0، الذي يُفترض أنه غير موجود؛ إذا كان موجودًا، تحاول rpcinfo الحصول على هذه المعلومات عن طريق استدعاء رقم إصدار مرتفع للغاية بدلاً من ذلك، وتحاول استدعاء كل إصدار مسجل. ملاحظة: يلزم رقم الإصدار لخيار -b و -d.

الخيارات

-T النقل
تحديد وسيلة النقل المطلوبة للخدمة. إذا لم يتم تحديد هذا الخيار، تستخدم rpcinfo وسيلة النقل المحددة في متغير البيئة NETPATH، أو إذا كان فارغًا أو غير معين، يتم استخدام وسيلة النقل في قاعدة بيانات netconfig(5). هذا خيار عام، ويمكن استخدامه بالاشتراك مع خيارات أخرى كما هو موضح في الاختصار.
-a عنوان_الخادم
استخدم عنوان_الخادم كعنوان (عالمي) للخدمة على النقل لاختبار الإجراء 0 لـ رقم_البرنامج المحدد والإبلاغ عما إذا تم تلقي استجابة. يلزم الخيار -T مع الخيار -a.

إذا لم يتم تحديد رقم_الإصدار، تحاول rpcinfo اختبار جميع أرقام الإصدارات المتاحة لـ رقم_البرنامج. يتجنب هذا الخيار استدعاءات إلى rpcbind البعيد للعثور على عنوان الخدمة. يتم تحديد عنوان_الخادم بتنسيق العنوان العالمي لوسيلة النقل المعطاة.

-b
قم بإجراء بث RPC إلى الإجراء 0 لـ رقم_البرنامج و رقم_الإصدار المحددين وأبلغ عن جميع المضيفين الذين يستجيبون. إذا تم تحديد النقل، فإنه يبث طلبه فقط على وسيلة النقل المحددة. إذا لم تدعم أي وسيلة نقل البث، يتم طباعة رسالة خطأ. يجب الحد من استخدام البث بسبب التأثير الضار المحتمل على الأنظمة الأخرى.
-d
حذف تسجيل خدمة RPC لـ رقم_البرنامج و رقم_الإصدار المحددين. إذا تم تحديد النقل، قم بإلغاء تسجيل الخدمة على هذا النقل فقط، وإلا قم بإلغاء تسجيل الخدمة على جميع وسائل النقل التي تم تسجيلها عليها. يمكن فقط مالك الخدمة حذف التسجيل، باستثناء المستخدم الخارق الذي يمكنه حذف أي خدمة.
-l
اعرض قائمة بالإدخالات لـ رقم_البرنامج و رقم_الإصدار المحددين على المضيف المحدد. يتم إرجاع الإدخالات لجميع وسائل النقل في نفس عائلة البروتوكول المستخدمة للاتصال بـ rpcbind البعيد.
-m
عرض جدول إحصائيات عمليات rpcbind على المضيف المحدد. يعرض الجدول إحصائيات لكل إصدار من rpcbind (الإصدارات 2 و 3 و 4)، مع إعطاء عدد المرات التي تم فيها طلب كل إجراء وخدمته بنجاح، وعدد وأنواع طلبات الاستدعاء البعيد التي تم إجراؤها، ومعلومات حول عمليات البحث عن عناوين RPC التي تم التعامل معها. هذا مفيد لمراقبة أنشطة RPC على المضيف.
-n رقم_المنفذ
استخدم رقم_المنفذ كرقم منفذ لخياري -t و -u بدلاً من رقم المنفذ الذي يمنحه rpcbind. يتجنب استخدام هذا الخيار استدعاء rpcbind البعيد لمعرفة عنوان الخدمة. أصبح هذا الخيار مهملًا بواسطة الخيار -a.
-p
قم بفحص rpcbind على المضيف باستخدام الإصدار 2 من بروتوكول rpcbind، واعرض قائمة بجميع برامج RPC المسجلة. إذا لم يتم تحديد المضيف، فإنه افتراضيًا للمضيف المحلي. ملاحظة: كان الإصدار 2 من بروتوكول rpcbind يُعرف سابقًا ببروتوكول portmapper.
-s
Dis

rpcinfo(8) — Arch manual pages

NAME

rpcinfo — show remote procedure call (RPC) program information

SYNOPSIS

rpcinfo [-s] [host]

rpcinfo [-T transport] host prognum [versnum]

rpcinfo [-u | -t] host prognum

rpcinfo [-a host] prognum [versnum]

rpcinfo [-p [host]] [-t | -u]

rpcinfo [-b prognum [versnum]] [-t | -u]

rpcinfo [-d prognum [versnum]] [-t | -u]

DESCRIPTION

The rpcinfo command provides information about the RPC services registered with an RPC server. It can be used to make RPC calls to remote procedure call (RPC) programs for testing purposes.

The rpcinfo command can only query RPC services that are registered with an RPC binder (see rpcbind(8)).

OPTIONS

-a host
Make an RPC call to procedure 0 of prognum on the specified host using any available transport, and report whether a response was received. This option is made obsolete by the -T option as shown in the third synopsis.
-b prognum [versnum]
Broadcast an RPC call to procedure 0 of prognum (version versnum if specified) on the specified transport (see -t and -u), and report all responses received. If versnum is not specified, it defaults to version 1.
-d prognum [versnum]
Delete the RPC registration for program prognum (version versnum if specified) on the specified transport (see -t and -u). If versnum is not specified, it defaults to version 1. Only a super-user can delete registrations.
-p [host]
Contact the RPC binder on the specified host, and display a list of all registered RPC programs. If host is not specified, it defaults to the local host.
-s
Play a concise list of all registered RPC programs on host. If host is not specified, it defaults to the local host.
-t
Make an RPC call to procedure 0 of prognum on the specified host using TCP, and report whether a response was received. This option is made obsolete by the -T option as shown in the third synopsis.
-u
Make an RPC call to procedure 0 of prognum on the specified host using UDP, and report whether a response was received. This option is made obsolete by the -T option as shown in the third synopsis.

EXAMPLES

To show all of the RPC services registered on the local machine use:

example% rpcinfo

To show all of the RPC services registered with rpcbind on the machine named klaxon use:

example% rpcinfo klaxon

The information displayed by the above commands can be quite lengthy. Use the -s option to display a more concise list:

example$ rpcinfo -s klaxon
program version(s) netid(s) service owner
100000 2,3,4 local,tcp,udp,tcp6,udp6 rpcbind super-user
100008 1 udp,tcp,udp6,tcp6 walld super-user
100002 2,1 udp,udp6 rusersd super-user
100001 2,3,4 udp,udp6 rstatd super-user
100012 1 udp,tcp sprayd super-user
100007 3 udp,tcp ypbind super-user

To show whether the RPC service with program number prognum and version versnum is registered on the machine named klaxon for the transport TCP use:

example% rpcinfo -T tcp klaxon prognum versnum

To show all RPC services registered with version 2 of the rpcbind protocol on the local machine use:

example% rpcinfo -p

To delete the registration for version 1 of the walld (program number 100008 ) service for all transports use:

example# rpcinfo -d 100008 1

or

example# rpcinfo -d walld 1
