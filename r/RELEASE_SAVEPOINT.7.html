RELEASE_SAVEPOINT(7)

الحزمة: postgresql

التراخيص: PostgreSQL

RELEASE SAVEPOINT(7) توثيق PostgreSQL 18.1 RELEASE SAVEPOINT(7)

الاسم

RELEASE_SAVEPOINT - تحرير نقطة حفظ محددة مسبقًا

الملخص

RELEASE [ SAVEPOINT ] savepoint_name

الوصف

RELEASE SAVEPOINT تحرر نقطة الحفظ المسماة وجميع نقاط الحفظ النشطة التي تم إنشاؤها بعد نقطة الحفظ المسماة، وتحرر مواردها. يتم دمج جميع التغييرات التي تم إجراؤها منذ إنشاء نقطة الحفظ والتي لم يتم التراجع عنها بالفعل في العملية أو نقطة الحفظ التي كانت نشطة عند إنشاء نقطة الحفظ المسماة. ستكون التغييرات التي تم إجراؤها بعد RELEASE SAVEPOINT جزءًا من هذه العملية أو نقطة الحفظ النشطة.

المعلمات

savepoint_name

اسم نقطة الحفظ المراد تحريرها.

ملاحظات

تحديد اسم نقطة حفظ لم يتم تعريفه مسبقًا هو خطأ.

لا يمكن تحرير نقطة حفظ عندما تكون العملية في حالة إلغاء؛ للقيام بذلك، استخدم ROLLBACK TO SAVEPOINT (ROLLBACK_TO_SAVEPOINT(7)).

إذا كان هناك عدة نقاط حفظ بنفس الاسم، فقط أحدث نقطة حفظ غير محررة يتم تحريرها. الأوامر المتكررة ستحرر نقاط حفظ أقدم تدريجياً.

أمثلة

لإنشاء نقطة حفظ ثم تحريرها لاحقًا:

BEGIN;
    INSERT INTO table1 VALUES (3);
    SAVEPOINT my_savepoint;
    INSERT INTO table1 VALUES (4);
    RELEASE SAVEPOINT my_savepoint;
COMMIT;

ستقوم العملية المذكورة أعلاه بإدراج كل من 3 و 4.

مثال أكثر تعقيدًا مع العديد من المعاملات الفرعية المتداخلة:

BEGIN;
    INSERT INTO table1 VALUES (1);
    SAVEPOINT sp1;
    INSERT INTO table1 VALUES (2);
    SAVEPOINT sp2;
    INSERT INTO table1 VALUES (3);
    RELEASE SAVEPOINT sp2;
    INSERT INTO table1 VALUES (4))); -- يولد خطأ

في هذا المثال، يطلب التطبيق تحرير نقطة الحفظ sp2، التي أدخلت 3. هذا يغير سياق العملية للإدراج إلى sp1. عندما يولد الأمر الذي يحاول إدراج القيمة 4 خطأ، يتم فقدان إدراج 2 و 4 لأنهما في نفس نقطة الحفظ التي تم التراجع عنها الآن، والقيمة 3 في نفس سياق العملية. يمكن للتطبيق الآن اختيار أحد هذين الأمرين فقط، حيث سيتم تجاهل جميع الأوامر الأخرى:

ROLLBACK;
ROLLBACK TO SAVEPOINT sp1;

اختيار ROLLBACK سيلغي كل شيء، بما في ذلك القيمة 1، بينما ROLLBACK TO SAVEPOINT sp1 سيحتفظ بالقيمة 1 ويسمح للعملية بالاستمرار.

التوافق

هذا الأمر يتوافق مع معيار SQL. يحدد المعيار أن الكلمة المفتاحية SAVEPOINT إلزامية، ولكن PostgreSQL تسمح بتجاوزها.
