roqet(1) دليل الأوامر العامة roqet(1)

الاسم

roqet - أداة استعلام Rasqal RDF

ملخص

roqet [خيارات] <استعلام-URI> [قاعدة-URI]
roqet [خيارات]-e سلسلة-الاستعلام [قاعدة-URI]
roqet [خيارات]-p sparql-protocol-service-URI استعلام-URI [قاعدة-URI]
roqet [خيارات]-p sparql-protocol-service-URI [-e سلسلة-الاستعلام ] [قاعدة-URI]
roqet [خيارات]-t ملف-نتائج-الاستعلام [قاعدة-URI]

الوصف

تسمح الأداة roqet بالاستعلام عن محتوى RDF باستخدام مكتبة استعلامات Rasqal RDF، وطباعة النتائج لربط المتغيرات، أو رسم بياني RDF، أو نتائج منطقية في مجموعة متنوعة من التنسيقات. يتم قراءة الاستعلام من query-URI ويتم استخدام base-URI الاختياري كـ URI الأساسي للاستعلام إذا كان موجودًا.

الخيارات الرئيسية

يستخدم roqet صيغة سطر الأوامر المعتادة لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-') إذا كانت مدعومة بواسطة الدالة getopt_long. بخلاف ذلك، تتوفر الخيارات القصيرة فقط.

-e, --exec استعلام
قم بتنفيذ سلسلة الاستعلام في الوسيط QUERY بدلاً من قراءة الاستعلام من URI (عندما لا يتم إعطاء -e / --exec).
-i, --input اللغة
قم بتعيين اللغة لغة الاستعلام المدخلة إلى إحدى اللغات المدعومة التي تشمل 'sparql' (لغة استعلام SPARQL لـ RDF، افتراضي)، 'sparql11'، و 'laqrs'. القائمة الكاملة للغات الفرعية والمدعومة معطاة في ملخص المساعدة مع الخيار -h / --help.
-p, --protocol SERVICE-URI
قم باستدعاء بروتوكول SPARQL HTTP SERVICE-URI لتنفيذ الاستعلام بدلاً من تنفيذه داخل محرك استعلام Rasqal محليًا (عندما يتم إعطاء -e، أو سلسلة استعلام معطاة).
-r, --results التنسيق
قم بتعيين تنسيق إخراج نتائج الاستعلام.
بالنسبة لربط المتغيرات، تختلف قيم FORMAT بناءً على ما يدعمه Rasqal ولكنها تشمل 'simple' لتنسيق نصي بسيط (افتراضي)، 'xml' لتنسيق نتائج استعلام SPARQL XML، 'csv' لـ SPARQL CSV، 'tsv' لـ SPARQL TSV، 'rdfxml' و 'turtle' لتنسيقات بناء جملة RDF، و 'json' لإصدار JSON من النتائج.
بالنسبة لنتائج الرسم البياني RDF، فإن قيم FORMAT هي 'ntriples' (N-Triples، افتراضي)، 'rdfxml-abbrev' (RDF/XML مختصر)، 'rdfxml' (RDF/XML)، 'turtle' (Turtle)، 'json' (RDF/JSON محور مركزي)، 'json-triples' (RDF/JSON Triples)، أو 'rss-1.0' (RSS 1.0، وهو أيضًا بناء جملة RDF/XML).
تعتمد القائمة الدقيقة للتنسيقات على ما تم بناء libraptor2(3) به، ولكنها معطاة بشكل صحيح في رسالة الاستخدام مع -h.
-R, --results-input-format التنسيق
قم بتعيين تنسيق إدخال نتائج الاستعلام.
هذا للاستخدام مع -t ويأخذ قيم 'xml' لتنسيق نتائج استعلام SPARQL XML، 'csv' لـ SPARQL CSV، 'tsv' لـ SPARQL TSV، 'turtle' و 'rdfxml' لتنسيقات بناء جملة RDF.
-t, --results-input ملف
قم بقراءة نتائج الاستعلام من FILE.

خيارات أخرى

-c, --count
قم فقط بعد الثلاثيات ولا تنتج أي مخرجات أخرى.
-d, --dump-query التنسيق
قم بطباعة الاستعلام الذي تم تحليله بتنسيق FORMAT معين، وهو إما 'none' (افتراضي)، 'debug'، 'structure'، أو 'sparql'.
-D, --data URI
أضف URI لمصدر بيانات RDF (وليس رسم بياني مسمى). إذا لم يتم إعطاء مصادر بيانات، يجب أن يشير الاستعلام نفسه إلى البيانات، مثل عبر عبارات SPARQL FROM uri.
-E, --ignore-errors
لا تقم بطباعة رسائل الخطأ ولا تخرج بحالة غير 0.
-f, --feature الاسم(=القيمة)
قم بتعيين ميزة الاستعلام NAME إلى VALUE أو العدد الصحيح 1 إذا تم حذفه. يمكن عرض الميزات المعروفة باستخدام -f help أو --feature help.
-F, --format NAME
قم بتعيين اسم تنسيق مصدر البيانات للرسوم البيانية للبيانات اللاحقة المستدعاة باستخدام -D / --data أو -G / --named. الافتراضي إذا لم يتم تحديد ذلك هو أن يقوم محرك الاستعلام بالتخمين. NAME هو اسم محلل Raptor.
-G, --named URI
أضف URI لمصدر بيانات RDF (رسم بياني مسمى).
-h, --help
اعرض ملخصًا للخيارات.
-n, --dryrun
قم بإعداد الاستعلام ولكن لا تنفذه.
-q, --quiet
لا توجد رسائل معلومات إضافية.
-s, --source URI
أضف URI لمصدر بيانات RDF (رسم بياني مسمى) URI عن طريق إضافته إلى قائمة URIs مصادر بيانات الاستعلام. FORMAT إلى 'simple' (افتراضي) أو 'xml' (تنسيق XML تجريبي).
-v, --version
قم بطباعة إصدار مكتبة rasqal واخرج.
-W, --warnings المستوى
قم بتعيين مستوى التحذير في النطاق من 0 (لا تحذر بشأن أي شيء) إلى 100 (اعرض كل تحذير). الافتراضي لـ Rasqal في المنتصف (50).

أمثلة

roqet sparql-query-file.rq

قم بتشغيل استعلام SPARQL الموجود في الملف المحلي sparql-query-file.rq. البيانات المستخدمة سيتم وصفها في عبارات FROM في ملف الاستعلام.

roqet -q -i sparql http://example.org/sparql-query.rq

قم بتشغيل استعلام SPARQL الموجود على الويب في URI http://example.org/sparql-query.rq بدون رسائل إضافية (هادئ، -q).

roqet -q query-file.rq http://example.org/base/

قم بتشغيل استعلام (اللغة الافتراضية SPARQL) من ملف محلي query-file.rq ولكن باستخدام URI أساسي http://example.org/base/ لحل أي URIs نسبية.

roqet -q -i sparql -r xml http://example.org/sparql-query.rq

قم بتشغيل استعلام SPARQL الموجود على الويب في URI http://example.org/sparql-query.rq وتنسيق النتائج في تنسيق نتائج استعلام SPARQL XML بدون رسائل إضافية.

roqet -i sparql -e 'SELECT * WHERE { ?s ?p ?o }' -D stuff.rdf

قم بتشغيل استعلام SPARQL معطى على سطر الأوامر مقابل البيانات في الملف stuff.rdf. سيتم تخمين نوع الملف ومن المرجح أن يكون بتنسيق RDF/XML.

roqet -t result.srx -r html

قم بقراءة نتائج استعلام SPARQL بتنسيق نتائج استعلام SPARQL XML (افتراضي) وقم بطباعتها بتنسيق HTML.

roqet -t result.ttl -R turtle -r csv

قم بقراءة نتائج استعلام SPARQL بتنسيق RDF/Turtle وقم بطباعتها بتنسيق CSV.
