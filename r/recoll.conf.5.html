الاسم

recoll.conf - ملف التكوين الشخصي الرئيسي لـ Recoll

الوصف

يحدد هذا الملف تكوين الفهرسة لنظام البحث النصي الكامل Recoll.

عادةً ما يكون ملف التكوين الخاص بالنظام موجودًا داخل /usr/[local]/share/recoll/examples. يمكن تجاوز أي معلمة تم تعيينها في الملف المشترك عن طريق تعيينها في ملف تكوين الفهرس المحدد، افتراضيًا: $HOME/.recoll/recoll.conf

ستقبل جميع أوامر recoll خيار -c أو تستخدم متغير البيئة $RECOLL_CONFDIR لتحديد دليل تكوين فهرس غير افتراضي.

قد يبدو مقتطف قصير من الملف كما يلي:

# قائمة مفصولة بمسافات للدلائل التي يجب فهرستها.
topdirs =  ~/docs /usr/share/doc
[~/somedirectory-with-utf8-txt-files]
defaultcharset = utf-8

هناك ثلاثة أنواع من الأسطر:

  • تعليق أو سطر فارغ.
  • تعيين معلمة.
  • تعريف قسم.

يتم تجاهل الأسطر الفارغة أو الأسطر التي تبدأ بـ #.

أسطر التعيين تكون بالشكل 'name = value'. في الوصف التالي، لها أيضًا نوع، وهو مؤشر إلى حد كبير. النوعان غير البديهيين هما 'fn': مسار ملف، و 'dfn': مسار دليل.

تسمح أسطر القسم بإعادة تعريف معلمة لشجرة فرعية من الدليل. يتم البحث عن بعض المعلمات المستخدمة في الفهرسة بشكل هرمي من الأكثر تحديدًا إلى الأقل تحديدًا. لا يمكن إعادة تعريف جميع المعلمات بشكل منطقي، وهذا محدد لكل منها في القسم التالي.

يتم توسيع الحرف tilde (~) في أسماء الملفات إلى اسم الدليل الرئيسي للمستخدم.

بعض قيم 'string' هي قوائم، وهذا مشار إليه فقط بوصفها. في هذه الحالة، يتم استخدام المسافات للفصل، ويمكن اقتباس العناصر ذات المسافات المضمنة باستخدام علامات الاقتباس المزدوجة.

خيارات

topdirs = string
قائمة مفصولة بمسافات للملفات أو الدلائل لفهرستها بشكل متكرر. يمكنك استخدام الروابط الرمزية في القائمة، وسيتم اتباعها، بغض النظر عن قيمة المتغير followLinks. القيمة الافتراضية هي ~: فهرسة $HOME بشكل متكرر.
monitordirs = string
قائمة مفصولة بمسافات للملفات أو الدلائل لمراقبة التحديثات. عند تشغيل الفهرسة في الوقت الفعلي، يسمح هذا بمراقبة مجموعة فرعية فقط من منطقة الفهرسة بأكملها. يجب أن تكون العناصر مدرجة في الشجرة المحددة بأعضاء 'topdirs'.
skippedNames = string
أسماء الملفات والدلائل التي يجب تجاهلها. قائمة مفصولة بمسافات من أنماط البدل (بسيطة، وليست مسارات، يجب ألا تحتوي على

ألقِ نظرة على التكوين الافتراضي للقيمة الأولية، قد لا تناسبك بعض الإدخالات. أسهل طريقة لرؤيتها هي من خلال لوحة "المعلمات المحلية" لتكوين الفهرس في الواجهة الرسومية.

القائمة في التكوين الافتراضي لا تستبعد الدلائل المخفية (الأسماء التي تبدأ بنقطة)، مما يعني أنها قد تفهرس أشياء كثيرة لا تريدها. من ناحية أخرى، عادةً ما تخزن وكلاء البريد الإلكتروني مثل Thunderbird الرسائل في دلائل مخفية، وربما تريد فهرستها. أحد الحلول الممكنة هو وجود ".*" في "skippedNames"، وإضافة أشياء مثل "~/.thunderbird" "~/.evolution" إلى "topdirs".

لا يتم حتى فهرست أسماء الملفات للأنماط الموجودة في هذه القائمة، انظر المتغير "noContentSuffixes" للحصول على نهج بديل يقوم بفهرسة أسماء الملفات. يمكن إعادة تعريفه لأي شجرة فرعية.

skippedNames- = string
قائمة بأنماط الأسماء المراد إزالتها من قائمة skippedNames الافتراضية. تسمح بتعديل القائمة في التكوين المحلي دون نسخها.
skippedNames+ = string
قائمة بأنماط الأسماء المراد إضافتها إلى قائمة skippedNames الافتراضية. تسمح بتعديل القائمة في التكوين المحلي دون نسخها.
onlyNames = string
أنماط فلترة أسماء الملفات العادية. هذه فارغة عادةً. إذا تم تعيينها، فسيتم النظر فقط في أسماء الملفات التي ليست في skippedNames وتطابق أحد الأنماط للفهرسة. يمكن إعادة تعريفها لكل شجرة فرعية. لا تنطبق على الدلائل.
noContentSuffixes = string
قائمة بنهايات الأسماء (ليس بالضرورة لواحق مفصولة بنقطة) التي لا نحاول فيها تحديد نوع MIME، ولا نقوم بفك ضغط المحتوى أو فهرسته. سيتم فهرست أسماء الملفات فقط. هذا يكمل القائمة recoll_noindex المهملة الآن من ملف mimemap، والتي ستتم إزالتها في إصدار مستقبلي (الانتقال من mimemap إلى recoll.conf يسمح بتحرير القائمة عبر الواجهة الرسومية). هذا يختلف عن skippedNames لأنه مطابقات لنهايات الأسماء فقط (وليس أنماط البدل)، واسم الملف نفسه يتم فهرسته بشكل طبيعي. يمكن إعادة تعريفه للدلائل الفرعية.
noContentSuffixes- = string
قائمة بنهايات الأسماء المراد إزالتها من قائمة noContentSuffixes الافتراضية.
noContentSuffixes+ = string
قائمة بنهايات الأسماء المراد إضافتها إلى قائمة noContentSuffixes الافتراضية.
skippedPaths = string
مسارات مطلقة لا ينبغي علينا الدخول إليها. قائمة مفصولة بمسافات لتعبيرات البدل للمسارات المطلقة لنظام الملفات (للملفات أو الدلائل). يجب تعريف المتغير في المستوى الأعلى من ملف التكوين، وليس في قسم فرعي.

يجب أن تكون أي قيمة في القائمة متسقة نصيًا مع القيم في topdirs، ولا يتم بذل أي محاولة لحل الروابط الرمزية. عمليًا، إذا كان /home، كما هو الحال غالبًا، رابطًا إلى /usr/home، فإن topdirs الافتراضي سيحتوي على إدخال واحد "~" والذي سيتم ترجمته إلى "/home/yourlogin". في هذه الحالة، يجب أن يبدأ أي إدخال skippedPaths بـ "/home/yourlogin" *وليس* بـ "/usr/home/yourlogin".

ستتم إضافة دليل الفهرس والتكوين تلقائيًا إلى القائمة.

تتم مطابقة التعبيرات باستخدام "fnmatch(3)" مع تعيين علامة FNM_PATHNAME افتراضيًا. هذا يعني أنه يجب مطابقة أحرف "/" بشكل صريح. يمكنك تعيين "skippedPathsFnmPathname" إلى 0 لتعطيل استخدام FNM_PATHNAME (مما يعني أن "/*/dir3" سيطابق "/dir1/dir2/dir3").

تحتوي القيمة الافتراضية على نقطة تحميل وسائط قابلة للإزالة المعتادة لتذكيرك بأن العمل على هذه الوسائط في معظم الحالات فكرة سيئة. سيؤدي إضافة "/media/xxx" صراحةً إلى متغير "topdirs" إلى تجاوز هذا.

skippedPathsFnmPathname = bool
تم التعيين إلى 0 لتجاوز استخدام FNM_PATHNAME لمطابقة المسارات المتخطاة.
nowalkfn = string
اسم الملف الذي سيؤدي إلى تخطي دليله الأب. سيتم تخطي أي دليل يحتوي على ملف بهذا الاسم كما لو كان جزءًا من قائمة skippedPaths. مثال: .recoll-noindex
daemSkippedPaths = string
ما يعادل skippedPaths الخاص بالفهرسة في الوقت الفعلي. هذا يسمح بوجود أجزاء من الشجرة التي تتم فهرستها مبدئيًا ولكن لا تتم مراقبتها. إذا لم يتم تعيين daemSkippedPaths، فإن البرنامج الخفي يستخدم skippedPaths.
followLinks = bool
اتبع الروابط الرمزية أثناء الفهرسة. الافتراضي هو تجاهل الروابط الرمزية لتجنب الفهرسة المتعددة للملفات المرتبطة. لا يتم بذل أي جهد لتجنب الازدواجية عند تعيين هذا الخيار إلى صحيح. يمكن تعيين هذا الخيار بشكل فردي لكل عضو من أعضاء "topdirs" عن طريق استخدام الأقسام. لا يمكن تغييره أسفل مستوى "topdirs". يتم دائمًا اتباع الروابط في قائمة "topdirs" نفسها.
indexedmimetypes = string
قائمة مقيدة بأنواع MIME المفهرسة. ليست معينة عادةً (وفي هذه الحالة، كل أنواع MIME المدعومة

NAME

recoll.conf

configuration file for recoll indexing

DESCRIPTION

This file contains the configuration parameters for the recollindex(1) indexing program. The configuration is read from recollindex(1). It is possible to override parameters for specific subdirectories by creating a recoll.conf file in that subdirectory. The configuration is parsed in shell format.

The default location for the configuration file is $RECOLL_CONFDIR/recoll.conf which is usually ~/.config/recoll/recoll.conf.

A list of configuration variables follows:

OPTIONS

pdfdraftmode = bool
Enable draft mode for PDF processing. If set, the PDF text extraction will be done in a faster, lower-quality mode. This can be useful for large numbers of PDFs where the content is not critically important, or when performing initial indexing of a large collection.
pdftextflags = string
Flags to pass to the PDF text extraction program. This can be used to control the behavior of the PDF text extraction, such as specifying the extraction mode or output format. Consult the documentation of your PDF text extraction tool for available flags.
pdfpassword = string
Default password for encrypted PDF files. If a PDF file is encrypted and requires a password for access, this value will be used as the default password. If the password is not known, the file will not be indexed.
pdfencoding = string
Encoding of the text extracted from PDF files. If set, this encoding will be used to interpret the text. If not set, the system default encoding will be used. Common values include 'UTF-8', 'ISO-8859-1', etc. It is recommended to set this to 'UTF-8' if possible.
pdfextractimages = bool
Extract text from images within PDF files using OCR. If set to true, Recoll will attempt to perform Optical Character Recognition (OCR) on images embedded within PDF documents to extract text. This requires additional OCR software to be installed and configured. See also imgocr and ocrprogs.
pdfocrtextflags = string
Flags to pass to the OCR engine when extracting text from PDF images. This allows fine-grained control over the OCR process. Refer to the documentation of your OCR engine for available flags.
fields = string
Specify which fields from the extracted data should be processed and how. This setting allows you to define rules for handling specific metadata or content fields. For example, you can specify fields to be indexed, fields to be stored, or fields to be excluded from the index. This is essential for directing the processing of the extracted data.
pdfextrametafix = fn
Define name of XMP field editing script. This defines the name of a script to be loaded for editing XMP field values. The script should define a "MetaFixer" class with a metafix() method which will be called with the qualified tag name and value of each selected field, for editing or erasing. A new instance is created for each document, so that the object can keep state for, e.g. eliminating duplicate values.
zipUseSkippedNames = bool
Use skippedNames inside Zip archives. Fetched directly by the rclzip.py handler. Skip the patterns defined by skippedNames inside Zip archives. Can be redefined for subdirectories. See https://www.recoll.org/faqsandhowtos/FilteringOutZipArchiveMembers.html
zipSkippedNames = string
Space-separated list of wildcard expressions for names that should be ignored inside zip archives. This is used directly by the zip handler. If zipUseSkippedNames is not set, zipSkippedNames defines the patterns to be skipped inside archives. If zipUseSkippedNames is set, the two lists are concatenated and used. Can be redefined for subdirectories. See https://www.recoll.org/faqsandhowtos/FilteringOutZipArchiveMembers.html
zipMetaEncoding = string
File path encoding. Needs Python 3.11+. Set to "detect" for using chardet. This is useful for non-standard zip files where the metadata is neither UTF-8 (indicated by a file flag), nor CP437 (default). The parameter can be set for specific subtrees. You need to install the Python3 "chardet" package if the value is set to "detect".
orgmodesubdocs = bool
Index org-mode level 1 sections as separate sub-documents This is the default. If set to false, org-mode files will be indexed as plain text
mhmboxquirks = string
Enable thunderbird/mozilla-seamonkey mbox format quirks Set this for the directory(ies) where the email mbox files are stored.
imgocr = bool
Tell the non-default Python image handler to run OCR. See the PDF section for PDF OCR. The image OCR also needs mimeconf changes. See the manual. imgocr can be defined for subdirectories.
ocrprogs = string
OCR modules to try. The top OCR script will try to load the corresponding modules in order and use the first which reports being capable of performing OCR on the input file. Modules for tesseract (tesseract) and ABBYY FineReader (abbyy) are present in the standard distribution. For compatibility with the previous version, if this is not defined at all, the default value is "tesseract". Use an explicit empty value if needed. A value of "abbyy tesseract" will try everything.
ocrcachedir = dfn
Location for caching OCR data. The default if this is empty or undefined is to store the cached OCR data under $RECOLL_CONFDIR/ocrcache.
tesseractlang = string
Language to assume for tesseract OCR. Important for improving the OCR accuracy. This can also be set through the contents of a file in the currently processed directory. See the rclocrtesseract.py script. Example values: eng, fra... See the tesseract documentation.
tesseractcmd = fn
Path for the tesseract command. Do not quote. This is mostly useful on Windows, or for specifying a non-default tesseract command. E.g. on Windows. tesseractcmd = C:/ProgramFiles(x86)/Tesseract-OCR/tesseract.exe
abbyylang = string
Language to assume for abbyy OCR. Important for improving the OCR accuracy. This can also be set through the contents of a file in the currently processed directory. See the rclocrabbyy.py script. Typical values: English, French... See the ABBYY documentation.
abbyyocrcmd = fn
Path for the abbyy command The ABBY directory is usually not in the path, so you should set this.
speechtotext = string
Activate speech to text conversion The only possible value at the moment is "whisper" for using the OpenAI whisper program.
sttmodel = string
Name of the whisper model
sttdevice = string
Name of the device to be used by for whisper
