الحزمة: net-tools

التراخيص: GPL2

NAME

route — show or manipulate the IP routing table

SYNOPSIS

route [all] [[-nee] [-ädtc]] [get] [del] [add] [--verbose] [--statistics] [--tick] [--cache] [target] [OPTIONS]

DESCRIPTION

The route command manipulates entries in the IP routing table. It can be used to create, delete, and view routes.

When no command is given, the contents of the routing table are printed.

The output of the kernel routing table is organized in the following columns:

Destination
The destination network or destination host.
Gateway
The gateway address or '*' if none set.
Genmask
The netmask for the destination net; '255.255.255.255' for a host destination and '0.0.0.0' for the default route.
Flags
Possible flags include
U (route is up)
H (target is a host)
G (use gateway)
R (reinstate route for dynamic routing)
D (dynamically installed by daemon or redirect)
M (modified from routing daemon or redirect)
A (installed by addrconf)
C (cache entry)
! (reject route)
Metric
The 'distance' to the target (usually counted in hops).
Ref
Number of references to this route. (Not used in the Linux kernel.)
Use
Count of lookups for the route. Depending on the use of -F and -C this will be either route cache misses (-F) or hits (-C).
Iface
Interface to which packets for this route will be sent.
MSS
Default maximum segment size for TCP connections over this route.
Window
Default window size for TCP connections over this route.
irtt
Initial RTT (Round Trip Time). The kernel uses this to guess about the best TCP protocol parameters without waiting on (possibly slow) answers.
HH (cached only)
The number of ARP entries and cached routes that refer to the hardware header cache for the cached route. This will be -1 if a hardware address is not needed for the interface of the cached route (e.g. lo).
Arp (cached only)
Whether or not the hardware address for the cached route is up to date.

OPTIONS

-A FAMILY
Address family. The only supported family is INET (IP). May be specified as inet, inet6 or link.
-F
Flush the routing table. This option can only be used when the routing table is not needed. This is dangerous!
-C
Display cache routing statistics.
-e
Extended listing (equivalent to netstat -e).
-n
Do not try to resolve numeric addresses into symbolic host names. When this option is used, the route command prints the numerical addresses and their associated names directly.
-t
Show timer information.
-d
Only show deleted routes.
-a
Show all routes (including hidden ones).
-i
Show the gateway lists for all interfaces.
-L
List routing tables.
-m
Show timer information.
-V
Show version information.
-h
Show help message.

Specific commands:

add
Add a route.
del
Delete a route.
get
Find the route to a target.
show
Print the routing table.

Specific arguments for add and del:

target
The target network. Can be a network, a host or a wildcard.
netmask
The netmask for the target network. Defaults to 255.255.255.255 for hosts and 255.255.255.0 for networks.
gw
Gateway to use. If not specified, the destination is assumed to be directly connected.
dev
Interface to be used for the route. If not specified, the kernel tries to determine the best interface.
metric
Metric for the route. Lower metric values indicate preferred routes.

EXAMPLES

Add a route to network 192.168.1.0/24 with gateway 10.0.0.1:

      route add -net 192.168.1.0 netmask 255.255.255.0 gw 10.0.0.1

Add a default route:

      route add default gw 192.168.1.1

Delete the default route:

      route del default

Add a route for host 10.1.2.3 via interface eth1:

      route add -host 10.1.2.3 dev eth1

Add a route for the private network

      "10.x.x.x."

This adds a IPv6 route with the specified metric to be directly reachable via eth0.

      route -6 add 2001:0002::/48 metric 1 dev eth0

HISTORY

Route for Linux was originally written by Fred N. van Kempen, <waltje@uwalt.nl.mugnet.org> and then modified by Johannes Stille and Linus Torvalds for pl15. Alan Cox added the mss and window options for Linux 1.1.22. irtt support and merged with netstat from Bernd Eckenfels.
