rollrec-editor(1p)

الحزمة: dnssec-tools

التراخيص: BSD

ROLLREC-EDITOR(1p) وثائق Perl من مساهمة المستخدم ROLLREC-EDITOR(1p)

الاسم

rollrec-editor - محرر واجهة المستخدم الرسومية لملفات rollrec الخاصة بأدوات DNSSEC

الملخص

rollrec-editor [خيارات] <ملف-rollrec>

الوصف

يوفر rollrec-editor القدرة على إدارة ملفات rollrec بسهولة عبر واجهة المستخدم الرسومية. يحتوي ملف rollrec على سجل واحد أو أكثر من سجلات rollrec. تُستخدم هذه السجلات بواسطة أدوات تدوير DNSSEC (مثل rollerd، وما إلى ذلك) لوصف حالة تدوير النطاقات. يحتوي سجل rollrec الخاص بكل نطاق على معلومات مثل ملف النطاق، مرحلة التدوير، ومستوى التسجيل. ملفات rollrec هي ملفات نصية ويمكن تحريرها بواسطة أي محرر نصوص. يسمح rollrec-editor بتحرير السجلات التي يجب على المستخدم تغييرها فقط ويقوم بفحص الأخطاء على البيانات.

عند بدء تشغيل rollrec-editor، يتم إنشاء نافذة تحتوي على "أزرار" لكل سجل rollrec في ملف rollrec المحدد. (في هذا التوثيق، تسمى هذه النافذة نافذة الأزرار.) يؤدي النقر على الأزرار إلى تحديد (أو إلغاء تحديد) هذا النطاق. بعد تحديد نطاق واحد أو أكثر، يمكن تنفيذ أحد الأوامر المتعددة. تسمح الأوامر بتعديل وحذف سجلات rollrec الموجودة، وإنشاء سجلات rollrec جديدة، ودمج ملفات rollrec، والتحقق من صحة الملف.

تتوفر أوامر rollrec-editor من خلال القوائم ومعظمها له مسرع لوحة مفاتيح. تم وصف الأوامر أدناه في قسم الأوامر.

عند تحديد سجل rollrec للتعديل، يتم إنشاء نافذة جديدة للاحتفاظ بالحقول القابلة للتحرير للسجل. يمكن تعديل الحقول في مكانها. عند اكتمال التحرير، يتم "حفظ" السجل. هذا لا يحفظ rollrec المعدل في ملفه على القرص؛ يجب حفظ الملف صراحةً من نافذة الأزرار.

كما ذكرنا أعلاه، يتم إجراء فحوصات التحقق عند حفظ سجل rollrec تم تحريره. تضمن مجموعة واحدة من الفحوصات وجود الملفات والأدلة المرتبطة بالنطاق بالفعل. يمكن إيقاف تشغيل هذا الفحص عند بدء تشغيل الأمر باستخدام الخيار -ignore-warns. يمكن تعديله أثناء التنفيذ باستخدام أمر القائمة "تجاهل تحذيرات التحرير".

تخطيط نافذة الأزرار

تحتوي نافذة الأزرار على زر لكل سجل rollrec في الملف المحدد. يتم ترتيب الأزرار في جدول يحتوي على ثلاثة أعمدة على الأقل. يمكن تعيين عدد الأعمدة عند بدء تشغيل الأمر باستخدام الخيار -columns. يمكن تعديله أثناء التنفيذ باستخدام أمر القائمة "عدد الأعمدة في نافذة الأزرار".

عند تعيين عدد الأعمدة، يقلل rollrec-editor من المساحة المطلوبة لعرض أزرار rollrec الخاصة بالملف المحدد. سيؤدي هذا أحيانًا إلى اختلاف عدد الأعمدة عن المطلوب.

على سبيل المثال، افترض أن ملف rollrec يحتوي على 12 سجل rollrec. يوضح الجدول التالي عدد الصفوف والأعمدة لكل اختيار من خيارات الأعمدة المحددة.

عدد الأعمدة    الصفوف    الأعمدة
      1          12        1
      2          6         2
      3          4         3
      4          3         4
      5          3         4
      6          2         6
      7          2         6
      8          2         6
      9          2         6
      10         2         6
      11         2         6
      12         1         12

ستختلف الصفوف والأعمدة الفعلية لعدد الأعمدة المطلوب للسماح "بالملاءمة الأفضل".

التراجع عن التعديلات

قدرة "التراجع" غير مطبقة حاليًا.

يمتلك rollrec-editor القدرة على عكس التعديلات التي أجراها على ملف rollrec. سيعمل هذا الاستعادة التاريخية فقط للتعديلات التي تم إجراؤها خلال تنفيذ معين لـ rollrec-editor؛ قد لا يتم التراجع عن التعديلات التي تم إجراؤها خلال تنفيذ سابق.

بعد عملية "الحفظ"، يتم حذف البيانات المطلوبة لعكس التعديلات. هذا ليس هو الحال بالنسبة لعملية "الحفظ باسم".

الخيارات

يدعم rollrec-editor الخيارات التالية.

-columns عدد-الأعمدة
يسمح هذا الخيار للمستخدم بتحديد عدد الأعمدة التي سيتم استخدامها في نافذة الأزرار.
-ignore-warns
يتسبب هذا الخيار في أن يتجاهل rollrec-editor تحذيرات التحرير عند إجراء فحوصات التحقق على محتويات سجلات rollrec.
-no-filter
يقوم هذا الخيار بإيقاف تصفية الأسماء عندما يعرض rollrec-editor مربع حوار اختيار الملف لاختيار ملف rollrec جديد. إذا لم يتم تقديم هذا الخيار، فإن مربع حوار اختيار الملف سيقوم فقط بإدراج الملفات العادية ذات لاحقة .rrf.
-Version
يعرض معلومات الإصدار لـ rollrec-editor وحزمة DNSSEC-Tools.

الأوامر

يوفر rollrec-editor الأوامر التالية، منظمة حسب القوائم: ملف، تحرير، أوامر، سجلات، وخيارات.

قائمة الملف

تحتوي قائمة الملف على أوامر لمعالجة ملفات rollrec وإيقاف التنفيذ.

فتح
فتح ملف rollrec جديد. إذا لم يكن الملف المحدد موجودًا، سيتم مطالبتك بالإجراء المطلوب اتخاذه. إذا اختار المستخدم إجراء "المتابعة"، فسيستمر rollrec-editor في تحرير ملف rollrec الحالي. إذا تم تحديد إجراء "خروج"، فسيتم إنهاء rollrec-editor.
حفظ
حفظ ملف rollrec الحالي. يتم حذف بيانات أمر "التراجع عن التغييرات"، لذلك سيبدو هذا الملف غير معدل.

لن يحدث شيء إذا لم يتم إجراء أي تغييرات.

حفظ باسم
حفظ ملف rollrec الحالي باسم يختاره المستخدم.
خروج
إنهاء rollrec-editor.

قائمة التحرير

تحتوي قائمة التحرير على أوامر لعمليات التحرير العامة.

التراجع عن التغييرات
عكس التعديلات التي تم إجراؤها على سجلات rollrec. هذا مخصص فقط للإصدار الموجود في الذاكرة لملف rollrec.

غير مطبق حاليًا.

قائمة الأوامر

تحتوي قائمة الأوامر على أوامر لتعديل سجلات rollrec.

سجل rollrec جديد
إنشاء سجل rollrec جديد. يتم منح المستخدم نافذة جديدة لتحرير حقول rollrec القابلة للتحرير. سيتم إدراج زر لسجل rollrec الجديد في نافذة الأزرار.

بعد اكتمال التحرير، سيضيف زر "حفظ" سجل rollrec الجديد إلى ملف rollrec الموجود في الذاكرة. يجب حفظ الملف للحصول على سجل rollrec الجديد المضاف إلى الملف.

سيتم إبلاغ المستخدم بالحالات التي يحتمل أن تكون خاطئة عند الحفظ. إذا تم تشغيل علامة ignore-warnings، فلن يتم الإبلاغ عن هذه التحذيرات. سيتم دائمًا الإبلاغ عن الأخطاء (مثل شروط السجل غير الصالحة).

حذف سجلات rollrec المحددة
حذف سجلات rollrec المحددة. سيتم إزالة الأزرار لكل سجل محدد من نافذة الأزرار.

rollrec-editor(1p) — DNSSEC-Tools Documentation

NAME

rollrec-editor — A graphical user interface for editing DNSSEC rollrec records

SYNOPSIS

rollrec-editor [-q] [file...]

DESCRIPTION

The rollrec-editor is a Tk-based graphical user interface for the editing of DNSSEC rollrec records. Rollrec records are used for specifying how to handle DNSSEC signed zones, and are used by various DNSSEC Tools utilities such as zonesigner(8).

The rollrec-editor allows users to easily create, edit, delete, rename, merge, verify, and summarize DNSSEC rollrec files.

When rollrec-editor is invoked with no arguments, it opens an empty buffer into which a new rollrec file may be created. If one or more file arguments are provided, then rollrec-editor will attempt to load and display each of the specified files.

THE BUTTON WINDOW

The main window of the rollrec-editor is the Button Window. This window displays buttons, one for each rollrec record in the currently open file. Clicking on a button will select or deselect that rollrec record.

THE EDIT WINDOW

When a rollrec button is double-clicked, or when an edit command is invoked on a selected rollrec, an Edit Window will appear. This window contains the fields of the rollrec record, which may be edited.

The Edit Window contains the following buttons:

Save
Saves the changes made in the Edit Window to the in-memory rollrec record. The edit window goes away (after a "Save" or "Cancel"), the rollrec record's button is deselected.

After editing is completed, the "Save" button will add the new rollrec record to the in-memory rollrec file. The file must be saved in order to have the new rollrec added to the file.

Potentially erroneous conditions will be reported to the user at save time. If the ignore-warnings flag has been turned on, then these warnings will not be reported. Errors (e.g., invalid log conditions) will always be reported.

Cancel
Discards any changes made in the Edit Window and returns to the Button Window. The selected rollrec record is deselected.

MENUS

The rollrec-editor has four menus: File, Edit, View, and Options.

File Menu

The File Menu contains commands for opening and saving rollrec files, and for quitting the rollrec-editor.

New
Clears the current rollrec file buffer and allows the user to start a new file. If the current file has unsaved changes, the user will be prompted to save them first.
Open...
Opens an existing rollrec file. If the current file has unsaved changes, the user will be prompted to save them first. A file-selection dialog box will appear, allowing the user to select the file to be opened.
Save
Saves the current in-memory rollrec file to disk. If the file has not been previously saved, the user will be prompted for a filename.
Save As...
Saves the current in-memory rollrec file to disk under a new filename. The user will be prompted for the new filename.
Merge...
Merges an external rollrec file with the current rollrec file. The user will be prompted to select the external file. See the description of the Merge command in the Edit Menu for more details.
Quit
Exits the rollrec-editor. If the current file has unsaved changes, the user will be prompted to save them first.

Edit Menu

The Edit Menu contains commands for manipulating rollrec records.

New Rollrec
Adds a new, empty rollrec record to the end of the current rollrec file. An Edit Window will be opened for the new record.
Edit Selected Rollrecs
Opens an Edit Window for each of the selected rollrec records. If no rollrec records are selected, this command does nothing.
Delete Selected Rollrecs
Deletes the selected rollrec records from the current rollrec file. The user will be prompted to confirm the deletion.
Rename Selected Rollrec
Rename the selected rollrec record. The name in the rollrec's "roll" or "skip" line will be changed to the new name. Only one rollrec may be renamed at a time, and it may not be edited while the rename is taking place.

If the rollrec has been modified, the new contents must be written to disk prior to the rename happening. The user will be prompted to ensure that this the user wishes to continue.

Merge Rollrec Files
Merge a rollrec file with the currently open rollrec file. After a successful merge, the rollrec records in the second file will be added to the end of the currently open rollrec file.

If there are any rollrec name collisions in the files, then the user will be asked whether to continue with the merge or cancel it. If the merge continues, then the conflicting rollrec records from the "new" file will be discarded in favor of the currently open rollrec file.

Verify Rollrec File
Verify the validity of the rollrec file. The user-editable fields in the open rollrec file are checked for validity. An edit window is opened for each rollrec record that registers an error or warning.

If the ignore-warnings flag has been turned on, then potentially erroneous conditions will not be reported. Errors (e.g., invalid log conditions) will always be reported.

Summarize Problems
Summarize the warning and error counts of the rollrec file. Each rollrec record in the open rollrec file is checked for validity. If any warnings or errors are found, a window is displayed that lists the name of each rollrec record and its warning and error counts.

If the ignore-warnings flag has been turned on, then potentially erroneous conditions will not be reported. Errors (e.g., invalid log conditions) will always be reported.

View Menu

The View Menu contains miscellaneous commands for viewing edit windows.

Select All Rollrecs/Unselect All Rollrecs
Select or unselect all rollrec buttons. All the buttons in the Button Window will be selected or unselected. If any of the buttons are not selected, this command will cause all the buttons to become selected. If all of the buttons are selected, this command will cause all the buttons to be deselected.

This command is a toggle that switches between Select All Rollrecs and Unselect All Rollrecs.

Reveal Rollrec Edit Windows
Raise all rollrec edit windows. This command brings all rollrec edit windows to the front so that any that are hidden behind other windows will become visible.
Close Rollrec Edit Windows
Close all rollrec edit windows. This command closes and deselects all rollrec edit windows.

Options Menu

The Options Menu allows the user to set several options that control rollrec-editor behavior.

Ignore Edit Warnings/Don't Ignore Edit Warnings
Certain operations perform validation checks on the contents of rollrec records. Warnings and errors may be reported by these checks. This option controls whether or not warnings are flagged during validation. If they are flagged, then the operation will not continue until the warning condition is fixed or the operation canceled. If the warnings are ignored, then the operation will complete without the condition being fixed.

This command is a toggle that switches between Ignore Edit Warnings mode and Don't Ignore Edit Warnings mode.

Filter Name Selection/Don't Filter Name Selection
When opening rollrec files for editing or merging, a file-selection dialog box is displayed to allow the user to select a rollrec file. This option controls whether a filename filter is used by the dialog box. If Filter Names Selection mode is used, then only regular files with a suffix of .rrf will be displayed by the dialog box. If Don't Filter Name Selection mode is used, then all regular files will be displayed by the dialog box.

This command is a toggle that switches between Filter Name Selection display and Don't Filter Name Selection display.

Columns in Button Window
Set the number of columns used in the Button Window. See the Button Window Layout section for more information on columns in the Button Window.

Help Menu

The Help Menu contains commands for getting assistance.

Help
Display a help window.

KEYBOARD ACCELERATORS

Below are the keyboard accelerators for the rollrec-editor commands:

Ctrl-A  Select All Rollrecs
Ctrl-D  Delete Selected Rollrecs
Ctrl-E  Edit Selected Rollrecs
Ctrl-H  Help
Ctrl-K  Close Rollrec Edit Windows
Ctrl-M  Merge Rollrec Files
Ctrl-N  New Rollrec
Ctrl-O  Open
Ctrl-Q  Quit
Ctrl-R  Reveal Rollrec Edit Windows
Ctrl-S  Save
Ctrl-U  Undo Changes  (not currently implemented)
Ctrl-V  Verify Rollrec File

These accelerators are all lowercase letters.

REQUIREMENTS

rollrec-editor is implemented in Perl/Tk, so both Perl and Perl/Tk must be installed on your system.

KNOWN ISSUES

The following are known issues. These will be resolved in the fullness of time.

  • There is an issue with the column count and adding new rollrecs. It doesn't always work properly, thus occasionally leaving some rollrec buttons undisplayed.
  • There is no undo command.
