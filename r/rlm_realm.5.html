rlm_realm(5) وحدة FreeRADIUS rlm_realm(5)

الاسم

rlm_realm - وحدة FreeRADIUS

الوصف

تقوم وحدة rlm_realm بتقسيم سمة اسم المستخدم (User-Name) إلى قسم المستخدم (User section) وقسم النطاق (Realm section). يستخدم هذا بشكل أساسي في حالات الوكيل (proxy)، ومع ذلك، يمكن أيضًا استخدام النطاقات محليًا لتوفير ملفات تعريف خدمة مختلفة بناءً على النطاق المستخدم.

عناصر التكوين الرئيسية التي يجب الانتباه إليها هي:

format
يمكن أن تكون 'prefix' أو 'suffix'. تحدد ما إذا كان النطاق يأتي قبل أو بعد جزء المستخدم في سلسلة اسم المستخدم.
delimiter
حرف واحد بين علامتي اقتباس، يستخدم كحرف فاصل يفصل بين قسم النطاق وقسم المستخدم في السلسلة.
ignore_default
يتم تعيين هذا إلى 'yes' أو 'no'. إذا تم تعيينه إلى 'yes'، فسيمنع مثيل الوحدة من مطابقة نطاق مع الإدخال DEFAULT. قد يكون هذا مفيدًا إذا كان لديك مثيلات متعددة لوحدة النطاق. القيمة الافتراضية هي 'no'.
ignore_null
يتم تعيين هذا إلى 'yes' أو 'no'. إذا تم تعيينه إلى 'yes'، فسيمنع مثيل الوحدة من مطابقة نطاق مع الإدخال NULL. قد يكون هذا مفيدًا إذا كان لديك مثيلات متعددة لوحدة النطاق. القيمة الافتراضية هي 'no'.

تقوم هذه الوحدة بتقسيم النطاق من سمة اسم المستخدم (User-Name) وفقًا لتكوين المثيل، ثم تجري بحثًا للعثور على نطاق مطابق في ملف '/etc/raddb/proxy.conf'. اعتمادًا على تكوين النطاق كما هو مطابق في الملف، قد تتم إعادة كتابة اسم المستخدم بتنسيق 'stripped' (مُجرد)، أو بإزالة جزء النطاق. في كلتا الحالتين، يتم إنشاء سمة نطاق (Realm attribute) وإضافتها إلى الحزمة عند المطابقة، والتي يمكن استخدامها بواسطة وحدات أخرى.

التكوين

modules {
  ... أشياء هنا ...
  # صيغة اسم المستخدم@نطاق
  realm suffix {
    format = suffix
    delimiter = "@"
  }
   # صيغة نطاق/اسم المستخدم
   realm prefix {
    format = prefix
    delimiter = "/"
  }
  ... أشياء هنا ...
}

الأقسام

authorization, pre-accounting

الملفات

/etc/raddb/radiusd.conf, /etc/raddb/proxy.conf
