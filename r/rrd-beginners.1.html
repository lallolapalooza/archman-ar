الحزمة: rrdtool

التراخيص: GPL-2.0-or-later

NAME

rrd-beginners - دليل RRDtool للمبتدئين

SYNOPSIS

هذا الدليل سيقدم شرحاً لأدوات RRDtool.

DESCRIPTION

RRDtool هو نظام لجمع وتخزين وعرض البيانات الزمنية. إنه مفيد بشكل خاص لمراقبة أداء النظام والشبكات.

تخزين البيانات

يتم تخزين البيانات في قاعدة بيانات RRD. تحتفظ قاعدة البيانات بعدة أرشيفات، تسمى RRAs (Round Robin Archives). كل RRA لديه دقة معينة ومدة احتفاظ معينة. على سبيل المثال، قد يكون لديك RRA لتخزين البيانات كل دقيقة لمدة يوم واحد، و RRA آخر لتخزين البيانات كل ساعة لمدة شهر واحد.

بمجرد امتلاء RRA، يتم تجاهل أقدم البيانات لتوفير مساحة. هذا هو السبب في أن RRA هو أرشيف لمدة شهر واحد. يمكن لقاعدة بيانات واحدة أن تحتوي على العديد من RRAs. إذا كان هناك مصادر بيانات متعددة (DSs)، فإن كل RRA فردي سيقوم بتخزين البيانات لجميع مصادر البيانات في قاعدة البيانات. على سبيل المثال، إذا كانت قاعدة بيانات تحتوي على 3 مصادر بيانات وتم الإعلان عن RRAs يومية، أسبوعية، شهرية، وسنوية، فسيحتوي كل RRA على بيانات من جميع مصادر البيانات الثلاثة.

السحر الرسومي

ميزة أخرى مهمة في RRDtool هي قدرته على إنشاء الرسوم البيانية. يستخدم الأمر "graph" الأمر "fetch" داخليًا لاسترداد القيم من قاعدة البيانات. باستخدام القيم المستردة، يرسم رسومًا بيانية كما هو محدد بواسطة المعلمات المقدمة في سطر الأوامر. يمكن لرسم بياني واحد عرض مصادر بيانات مختلفة (DSs) من قاعدة بيانات. من الممكن أيضًا عرض قيم من أكثر من قاعدة بيانات واحدة في رسم بياني واحد. غالبًا، يكون من الضروري إجراء بعض العمليات الرياضية على القيم المستردة من قاعدة البيانات قبل رسمها. على سبيل المثال، في ردود SNMP، عادةً ما يتم تحديد قيم استهلاك الذاكرة بالكيلوبايت وتدفق حركة المرور على الواجهات بالبايت. ستكون الرسوم البيانية لهذه القيم أكثر فائدة إذا تم تمثيل القيم بالميجابايت والميجابت في الثانية. يسمح أمر رسم RRDtool بتعريف مثل هذه التحويلات. بالإضافة إلى الحسابات الرياضية، من الممكن أيضًا إجراء عمليات منطقية مثل أكبر من، أقل من، وشرطي/ثم/غير ذلك. إذا كانت قاعدة بيانات تحتوي على أكثر من أرشيف RRA واحد، فقد ينشأ سؤال - كيف يقرر RRDtool أي أرشيف RRA سيتم استخدامه لاسترداد القيم؟ يبحث RRDtool في عدة أشياء عند اتخاذ قراره. أولاً، يتأكد من أن RRA يغطي أكبر قدر ممكن من إطار الرسم الزمني. ثانيًا، ينظر إلى دقة RRA مقارنة بدقة الرسم البياني. يحاول العثور على واحد له دقة مماثلة أو أعلى. باستخدام الخيار "-r"، يمكنك إجبار RRDtool على افتراض دقة مختلفة عن تلك المحسوبة من عرض البكسل للرسم البياني.

يمكن تقديم قيم المتغيرات المختلفة في 5 أشكال مختلفة في الرسم البياني - AREA، LINE1، LINE2، LINE3، و STACK. يتم تمثيل AREA بمنطقة ملونة صلبة مع القيم كحد لهذه المنطقة. LINE1/2/3 (زيادة العرض) هي خطوط عادية تمثل القيم. STACK هي أيضًا منطقة ولكنها "مكدسة" فوق AREA أو LINE1/2/3. شيء آخر مهم يجب ملاحظته هو أن المتغيرات يتم رسمها بالترتيب الذي يتم تحديده به في أمر الرسم البياني. لذلك يجب توخي الحذر لتحديد STACK فقط بعد تحديد AREA/LINE. من الممكن أيضًا وضع تعليقات منسقة داخل الرسم البياني. يمكن العثور على تعليمات مفصلة في دليل الرسم البياني.

تغليف RRDtool داخل سكربت Shell/Perl

بعد فهم RRDtool، حان الوقت الآن لاستخدام RRDtool فعليًا في السكربتات. تشمل المهام المعنية بإدارة الشبكات جمع البيانات وتخزين البيانات واسترجاع البيانات. في المثال التالي، يتم استخدام قاعدة بيانات target.rrd التي تم إنشاؤها سابقًا. يتم جمع البيانات وتخزينها باستخدام سكربتات Shell. يتم استرجاع البيانات وإنشاء التقارير باستخدام سكربتات Perl. يتم عرض هذه السكربتات أدناه:

سكربت Shell (يجمع البيانات، ويحدث قاعدة البيانات)

#!/bin/sh
a=0
while [ "$a" == 0 ]; do
snmpwalk -c public 192.168.1.250 hrSWRunPerfMem > snmp_reply
    total_mem=`awk 'BEGIN {tot_mem=0}
                          { if ($NF == "KBytes")
                            {tot_mem=tot_mem+$(NF-1)}
                          }
                    END {print tot_mem}' snmp_reply`
    # يمكنني استخدام N كبديل للوقت الحالي
    rrdtool update target.rrd N:$total_mem
    # النوم حتى اكتمال الـ 300 ثانية التالية
    perl -e 'sleep 300 - time % 300'
done # نهاية حلقة while

سكربت Perl (يسترجع البيانات من قاعدة البيانات وينشئ الرسوم البيانية والإحصائيات)

#!/usr/bin/perl -w
# يقوم هذا السكربت باسترجاع البيانات من target.rrd، وينشئ رسمًا بيانيًا لاستهلاك الذاكرة
# على الهدف (معالج Dual P3 بسرعة 1 جيجاهرتز، ذاكرة وصول عشوائي 656 ميجابايت)
# استدعاء وحدة RRD Perl
use lib qw( /usr/local/rrdtool-1.0.41/lib/perl ../lib/perl );
use RRDs;
my $cur_time = time();                # تعيين الوقت الحالي
my $end_time = $cur_time - 86400;     # تعيين وقت النهاية إلى 24 ساعة مضت
my $start_time = $end_time - 2592000; # تعيين البداية إلى 30 يومًا في الماضي
# استرجاع القيم المتوسطة من قاعدة بيانات RRD بين وقت البداية والنهاية
my ($start,$step,$ds_names,$data) =
    RRDs::fetch("target.rrd", "AVERAGE",
                "-r", "600", "-s", "$start_time", "-e", "$end_time");
# حفظ القيم المسترجعة في مصفوفة ثنائية الأبعاد
my $rows = 0;
my $columns = 0;
my $time_variable = $start;
foreach $line (@$data) {
  $vals[$rows][$columns] = $time_variable;
  $time_variable = $time_variable + $step;
  foreach $val (@$line) {
          $vals[$rows][++$columns] = $val;}
  $rows++;
  $columns = 0;
}
my $tot_time = 0;
my $count = 0;
# حفظ القيم من ثنائية الأبعاد إلى مصفوفة أحادية البعد
for $i ( 0 .. $#vals ) {
    $tot_mem[$count] = $vals[$i][1];
    $count++;
}
my $tot_mem_sum = 0;
# حساب مجموع جميع القيم
for $i ( 0 .. ($count-1) ) {
    $tot_mem_sum = $tot_mem_sum + $tot_mem[$i];
}
# حساب متوسط المصفوفة
my $tot_mem_ave = $tot_mem_sum/($count);
# إنشاء الرسم البياني
RRDs::graph ("/images/mem_$count.png",
            "--title= Memory Usage",
            "--vertical-label=Memory Consumption (MB)",
            "--start=$start_time",
            "--end=$end_time",
            "--color=BACK#CCCCCC",
            "--color=CANVAS#CCFFFF",
            "--color=SHADEB#9999CC",
            "--height=125",
            "--upper-limit=656",
            "--lower-limit=0",
            "--rigid",
            "--base=1024",
            "DEF:tot_mem=target.rrd:mem:AVERAGE",
            "CDEF:tot_mem_cor=tot_mem,0,671744,LIMIT,UN,0,tot_mem,IF,1024,/",
            "CDEF:machine_mem=tot_mem,656,+,tot_mem,-",
            "COMMENT:Memory Consumption between $start_time",
            "COMMENT:    and $end_time                     ",
            "HRULE:656#000000:Maximum Available Memory - 656 MB",
            "AREA:machine_mem#CCFFFF:Memory Unused",
            "AREA:tot_mem_cor#6699CC:Total memory consumed in MB");
my $err=RRDs::error;
if ($err) {print "problem generating the graph: $err\n";}
# طباعة المخرجات
print "Average memory consumption is ";
printf "%5.2f",$tot_mem_ave/1024;
print " MB. Graphical representation can be found at /images/mem_$count.png.";
