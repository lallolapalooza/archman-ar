-m num, -m name, -monitor num, -monitor name
تحديد الشاشة لعرض rofi عليها. يقبل كمدخلات: primary (إذا تم تعيين الشاشة الأساسية)، اسم الإخراج xrandr، أو رقم صحيح (حسب ترتيب الكشف). يتم التعامل مع الأرقام السالبة بشكل مختلف:
•
-1: الشاشة الحالية المركزة.
•
-2: النافذة الحالية المركزة (أي، سيتم عرض rofi فوق النافذة المركزة).
•
-3: موضع الفأرة (يتجاوز إعداد الموقع للحصول على سلوك قائمة السياق العادي).
•
-4: الشاشة التي تحتوي على النافذة المركزة.
•
-5: الشاشة التي تعرض مؤشر الفأرة.

الافتراضي: -5

راجع مخرجات rofi -h للشاشات المكتشفة وموضعها وحجمها.

-theme filename
المسار إلى ملف السمة، أو اسم سمة مثبتة. انظر صفحة الدليل rofi-theme(5) حول كيفية معالجة السمات.
-theme-str string
السماح بتحديد أجزاء السمة على سطر الأوامر كاستبدال.

على سبيل المثال:

    rofi -theme-str '#window { fullscreen: true; }'

يمكن تحديد هذا الخيار عدة مرات. هذه هي الآن الطريقة لتعديل السمة عبر سطر الأوامر.

-dpi number
تجاوز إعداد DPI الافتراضي.

على X11:

•
إذا تم تعيينه على 0، فإنه يحاول الكشف التلقائي بناءً على حجم شاشة X11 (مشابه لـ i3 و GTK).
•
إذا تم تعيينه على 1، فإنه يحاول الكشف التلقائي بناءً على حجم الشاشة التي يتم عرض rofi عليها (مشابه لـ Qt 5 الأحدث).

على Wayland:

•
إذا تم تعيينه على 0 أو 1، فإنه يحاول الكشف التلقائي إذا كانت هناك شاشة واحدة، أو إذا تم تحديد اسم -monitor.

تحديد صف معين.

Run settings

-run-command cmd
تعيين الأمر ({cmd}) للتنفيذ عند تشغيل تطبيق. انظر PATTERN.

الافتراضي: {cmd}

مثال لتشغيل التطبيقات في مجموعة cgroup مخصصة مع systemd. يتطلب shell للهروب وتفسير اسم الوحدة بشكل صحيح.

"bash -c 'systemd-run --user --unit=app-rofi-\$(systemd-escape {cmd})-\$RANDOM {cmd}'"
-run-shell-command cmd
تعيين الأمر للتنفيذ عند تشغيل تطبيق في shell. انظر PATTERN.

الافتراضي: {terminal} -e {cmd}

-run-list-command cmd
إذا تم تعيينه، استخدم أداة خارجية لإنشاء قائمة بالأوامر القابلة للتنفيذ. يستخدم run-command.

الافتراضي: {cmd}

Window switcher settings

-window-format format
تنسيق ما يتم عرضه للنوافذ.

format: {field[:len]}

field:

•
w: اسم سطح المكتب
•
t: عنوان النافذة
•
n: الاسم
•
r: الدور
•
c: الفئة

len: الحد الأقصى لطول الحقل (0 للحجم التلقائي). إذا كان الطول سالبًا، سيظل الإدخال دون تغيير. إذا كان الطول موجبًا، سيتم اقتطاع الإدخال أو ملئه لملء هذا الطول.

الافتراضي: {w} {c} {t}

-window-command cmd
تعيين الأمر للتنفيذ على النافذة المحددة لإجراء بديل (-kb-accept-alt). انظر PATTERN.

الافتراضي: “wmctrl -i -R {window}”

-window-thumbnail
عرض مصغر للنافذة (إذا كان متاحًا) كأيقونة في مبدل النوافذ.

يمكنك منع rofi من الخروج عند إغلاق نافذة (مما يسمح بإغلاق عدة نوافذ متتالية).

configuration {
  window {
      close-on-delete: false;
  }
}

يمكنك إخفاء النافذة النشطة حاليًا باستخدام الإعداد `hide-active-window':

configuration {
  window {
      hide-active-window: true;
  }
}

أو تمرير -window-hide-active-window true على سطر الأوامر.

يمكنك تفضيل سمة الأيقونات فوق الأيقونة المعينة للنافذة باستخدام الإعداد `prefer-icon-theme':

configuration {
  window {
      prefer-icon-theme: true;
  }
}

أو تمرير -window-prefer-icon-theme true على سطر الأوامر.

Combi settings

-combi-modes mode1,mode2
الأوضاع التي سيتم دمجها في وضع combi. لبناء جملة -combi-modes، انظر -modes. للحصول على عرض دمج واحد، لـ window و run و ssh:
    rofi -show combi -combi-modes "window,run,ssh" -modes combi

ملاحظة: مدير نوافذ i3 لا يحب الفواصل في الأمر عند تحديد أمر التنفيذ. في هذه الحالة، يمكن استخدام # كفاصل.

-combi-display-format
سلسلة التنسيق للإدخالات في مربع الحوار combi:
•
mode: اسم عرض الوضع
•
text: نص الإدخال

يمكن استخدام علامات Pango لتنسيق المخرجات.

الافتراضي: {mode} {text}

ملاحظة: يتم تجاهل هذا الإعداد إذا كان combi-hide-mode-prefix ممكّنًا.

File browser settings

سلوك مستعرض الملفات

يمكن التحكم به عبر الخيارات التالية:

configuration {
   filebrowser {
      /** الدليل الذي يبدأ فيه متصفح الملفات. */
      directory: "/some/directory";
      /**
        * طريقة الفرز. يمكن ضبطها على:
        *   - "name"
        *   - "mtime" (وقت التعديل)
        *   - "atime" (وقت الوصول)
        *   - "ctime" (وقت التغيير)
        */
      sorting-method: "name";
      /** ضع الدلائل قبل الملفات. */
      directories-first: true;
      /** عرض الملفات المخفية. */
      show-hidden: false;
      /** إرجاع 1 عند الإلغاء. */
      cancel-returns-1: true;
      /** الأمر */
      command: "xdg-open";
   }
}

يمكن أيضًا تمرير هذه الخيارات عبر سطر الأوامر، على سبيل المثال:

rofi -filebrowser-cancel-returns-1 true -show filebrowser

يمكن أيضًا تشغيل show-hidden باستخدام ربط المفتاح kb-delete-entry.

إعدادات متصفح الملفات المتكرر

يمكن التحكم في سلوك متصفح الملفات المتكرر عبر الخيارات التالية:

configuration {
   recursivebrowser {
      /** الدليل الذي يبدأ فيه متصفح الملفات. */
      directory: "/some/directory";
      /** إرجاع 1 عند الإلغاء. */
      cancel-returns-1: true;
      /** تصفية الإدخالات باستخدام تعبير عادي */
      filter-regex: "(.*cache.*|.*\.o)";
      /** الأمر */
      command: "xdg-open";
   }
}

سجل الإدخالات

يمكن تعديل عدد المدخلات السابقة لمربع الإدخال عن طريق تعيين max-history في مربع الإدخال.

configuration {
    entry  {
        max-history: 30;
    }
}

بشكل افتراضي، يتم تخزين الملف في دليل ذاكرة التخزين المؤقت للنظام، في ملف يسمى rofi-entry-history.txt.

-drun-reload-desktop-cache

-drun-url-launcher command

-replace
إذا كان rofi قيد التشغيل بالفعل، استنادًا إلى ملف pid، حاول إنهاء هذا المثيل.
-display-{mode} string

configuration {
  {mode} {
    display-name: *string*;
  }

الافتراضي: معطّل

نمط

لتشغيل الأوامر (على سبيل المثال، عند استخدام مشغل ssh)، يمكن للمستخدم إدخال سطر الأوامر المستخدم. يمكن استخدام المفاتيح التالية التي سيتم استبدالها في وقت التشغيل:

•
{host}: المضيف للاتصال به
•
{terminal}: الطرفية المكونة (انظر -terminal)
•
{ssh-client}: عميل ssh المكون (انظر -ssh-client)
•
{cmd}: الأمر المراد تنفيذه
•
{window}: معرف النافذة المحددة (في window-command)

يعالج السلسلة كما يلي: يتم استبدال {key} بقيمته، إذا لم يتم تعيين {key} فسيتم إزالته. إذا كان {key} بين [] فسيتم إزالة كل النص بين [] إذا لم يتم تعيين {key}. وإلا فسيتم استبدال المفتاح وإزالة [].

على سبيل المثال: {ssh-client} [-p {port}] {host}

التمثيل البصري

يرجى مراجعة صفحة الدليل rofi-theme(5) لمزيد من المعلومات حول التمثيل البصري.

ربط المفاتيح

يرجى مراجعة صفحة الدليل rofi-keys(5) لربط المفاتيح وكيفية إعدادها.

يمكن أيضًا استخدام ربط المفاتيح للإجراءات، عند تنفيذ الإجراء يتم إدراج الضغطة المذكورة على المفتاح:

مهلة

يمكنك تكوين إجراء ليتم اتخاذه عندما لا يتم التفاعل مع rofi لفترة معينة من الثواني. يمكنك تحديد ربط مفتاح لتشغيله بعد X ثوانٍ.

configuration {
  timeout {
      delay:  15;
      action: "kb-cancel";
  }
}

تغيير الإدخال

عندما يتغير إدخال مربع النص:

configuration {
  inputchange {
      action: "kb-row-first";
  }
}

الأوضاع المتاحة

window

يعرض قائمة بجميع النوافذ ويسمح بالتبديل بينها. الضغط على ربط delete-entry (shift-delete) سيغلق النافذة. الضغط على ربط accept-custom (control-enter أو shift-enter) سيشغل أمرًا على النافذة. (انظر الخيار window-command).

إذا لم يكن هناك تطابق، فسيحاول تشغيل الإدخال.

windowcd

يعرض قائمة بالنوافذ الموجودة على سطح المكتب الحالي ويسمح بالتبديل بينها. الضغط على ربط delete-entry (shift-delete) سيقوم بقتل النافذة. الضغط على ربط accept-custom (control-enter أو shift-enter) سيشغل أمرًا على النافذة. (انظر الخيار window-command).

إذا لم يكن هناك تطابق، فسيحاول تشغيل الإدخال.

run

يعرض قائمة بالملفات التنفيذية في $PATH ويمكن تشغيلها (اختياريًا في طرفية).

•
الضغط على ربط delete-entry (shift-delete) سيقوم بإزالة هذا الإدخال من سجل التشغيل.
•
الضغط على ربط accept-custom (control-enter) سيشغل الأمر كما تم إدخاله في مربع الإدخال.
•
الضغط على ربط accept-alt (shift-enter) سيشغل الأمر في طرفية.

عند الضغط على ربط mode-complete (Control-l)، يمكنك استخدام وضع متصفح الملفات لتشغيل التطبيق بملف كوسيط أول.

drun

نفس الشيء مثل تشغيلات run، ولكن يتم إنشاء القائمة من ملفات سطح المكتب المثبتة. يقوم بتشغيلها تلقائيًا في طرفية إذا تم تحديد ذلك في ملف سطح المكتب.

•
الضغط على ربط delete-entry (shift-delete) سيقوم بإزالة هذا الإدخال من سجل التشغيل.
•
الضغط على ربط accept-custom (control-enter) سيشغل الأمر كما تم إدخاله في مربع الإدخال.
•
الضغط على ربط accept-alt (shift-enter) سيشغل الأمر في طرفية.

عند الضغط على ربط mode-complete (Control-l)، يمكنك استخدام وضع متصفح الملفات لتشغيل التطبيق وتمرير ملف كوسيط إذا تم تحديده في ملف سطح المكتب.

يحاول وضع DRUN اتباع مواصفات إدخال سطح المكتب XDG ويجب أن يكون متوافقًا مع التطبيقات التي تستخدم هذا المعيار. تنشئ بعض التطبيقات ملفات سطح مكتب غير صالحة، وسيتم تجاهلها بواسطة rofi. انظر قسم التصحيح لمزيد من المعلومات حول وضع DRUN، سيقوم هذا بطباعة سبب تجاهل ملفات سطح المكتب.

هناك بعض الخيارات المتقدمة لتعديل السلوك:

configuration {
   drun {
      /** مسح سطح المكتب الحالي للمستخدم بحثًا عن ملفات سطح المكتب. */
      scan-desktop: true;
      /** تحليل ملفات سطح مكتب المستخدم. */
      parse-user:   true;
      /** تحليل ملفات سطح مكتب النظام. */
      parse-system: false;
      /** تعطيل DBusActivatable */
      DBusActivatable: false;
   }
}
