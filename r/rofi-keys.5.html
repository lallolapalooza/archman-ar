NAME

\n

rofi keys - Rofi Key and Mouse bindings

\n
\n
\n

DESCRIPTION

\n

rofi supports overriding of any of it key and mouse\n binding.

\n
\n
\n

Setting binding

\n

Bindings can be done on the commandline (-{bindingname}):

\n
\n
\n
\n 
rofi -show run -kb-accept-entry 'Control+Shift+space'\n
\n
\n
\n

or via the configuration file:

\n
\n
\n
\n 
configuration {\n  kb-accept-entry: \"Control+Shift+space\";\n}\n
\n
\n
\n

The key can be set by its name (see above) or its keycode:

\n
\n
\n
\n 
configuration {\n  kb-accept-entry: \"Control+Shift+[65]\";\n}\n
\n
\n
\n

An easy way to look up keycode is xev(1).

\n

Multiple keys can be specified for an action as a comma separated\n list:

\n
\n
\n
\n 
configuration {\n  kb-accept-entry: \"Control+Shift+space,Return\";\n}\n
\n
\n
\n

By Default rofi reacts on pressing, to act on the release\n of all keys prepend the binding with !:

\n
\n
\n
\n 
configuration {\n  kb-accept-entry: \"!Control+Shift+space,Return\";\n}\n
\n
\n
\n
\n
\n

Unsetting a binding

\n

To unset a binding, pass an empty string.

\n
\n
\n
\n 
configuration {\n  kb-clear-line: \"\";\n}\n
\n
\n
\n
\n
