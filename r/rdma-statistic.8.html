NAME

\n

rdma-statistic - RDMA statistic counter configuration

\n
\n
\n

SYNOPSIS

\n
\n

rdma [ OPTIONS ] statistic { COMMAND |\n help }

\n

rdma statistic { OBJECT } show

\n

rdma statistic [ OBJECT ] show link [ \n DEV/PORT_INDX ] [ FILTER_NAME FILTER_VALUE ]

\n

rdma statistic OBJECT mode

\n

rdma statistic OBJECT set\n COUNTER_SCOPE [ DEV/PORT_INDEX ] auto { CRITERIA\n | off } [ optional-counters | on/off ]

\n

rdma statistic OBJECT bind\n COUNTER_SCOPE [ DEV/PORT_INDEX ] [ OBJECT-ID ] [ \n COUNTER-ID ]

\n

rdma statistic OBJECT unbind\n COUNTER_SCOPE [ DEV/PORT_INDEX ] [ COUNTER-ID ] [ \n OBJECT-ID ]

\n

rdma statistic mode [ supported ] link\n [ DEV/PORT_INDEX ]

\n

rdma statistic set link [ \n DEV/PORT_INDEX ] optional-counters [ OPTIONAL-COUNTERS\n ]

\n

rdma statistic unset link [ \n DEV/PORT_INDEX ] optional-counters

\n

COUNTER_SCOPE := { link | dev }

\n

OBJECT := { qp | mr }

\n

CRITERIA := { type | pid }

\n

FILTER_NAME := { cntn | lqpn | pid |\n qp-type }

\n
\n
\n

DESCRIPTION

\n
\n

rdma statistic [object] show - Queries the specified RDMA device for RDMA and driver-specific statistics. Show the default hw counters if object is not specified

\n

DEV - specifies counters on this RDMA device to show.

\n

PORT_INDEX - specifies counters on this RDMA port to\n show.

\n

FILTER_NAME - specifies a filter to show only the results\n matching it.

\n
\n
\n

rdma statistic <object> set - configure counter statistic auto-mode for a specific device/port

\n

In auto mode all objects belong to one category are bind\n automatically to a single counter set. The "off" is global for all\n auto modes together. Not applicable for MR's.

\n
\n
\n

rdma statistic <object> bind - manually bind an object (e.g., a qp) with a counter

\n

When bound the statistics of this object are available in this\n counter. Not applicable for MR's.

\n
\n
\n

rdma statistic <object> unbind - manually unbind an object (e.g., a qp) from the counter previously bound

\n

When unbound the statistics of this object are no longer available\n in this counter; And if object id is not specified then all objects on this\n counter will be unbound. Not applicable for MR's.

\n

COUNTER-ID - specifies the id of the counter to be bound.\n If this argument is omitted then a new counter will be allocated.

\n
\n
\n

rdma statistic mode - Display the enabled optional counters for each link.

\n
\n
\n

rdma statistic mode supported - Display the supported optional counters for each link.

\n
\n
\n

rdma statistic set - Enable a set of optional counters for a specific device/port.

\n

OPTIONAL-COUNTERS - specifies the name of the optional\n counters to enable. Optional counters that are not specified will be\n disabled. Note that optional counters are driver-specific.

\n
\n
\n

rdma statistic unset - Disable all optional counters for a specific device/port.

\n
\n
\n
\n

EXAMPLES

\n

rdma statistic show

\n
Shows the state of the default counter of all RDMA\n devices on the system.
\n

rdma statistic show link mlx5_2/1

\n
Shows the state of the default counter of specified RDMA\n port
\n

rdma statistic qp show

\n
Shows the state of all qp counters of all RDMA devices on\n the system.
\n

rdma statistic qp show link mlx5_2/1

\n
Shows the state of all qp counters of specified RDMA\n port.
\n

rdma statistic qp show link mlx5_2 pid 30489

\n
Shows the state of all qp counters of specified RDMA port\n and belonging to pid 30489
\n

rdma statistic qp show link mlx5_2 qp-type UD

\n
Shows the state of all qp counters of specified RDMA port\n and with QP type UD
\n

rdma statistic qp mode

\n
List current counter mode on all devices
\n

rdma statistic qp mode link mlx5_2/1

\n
List current counter mode of device mlx5_2 port 1
\n

rdma statistic qp set link mlx5_2/1 auto type on

\n
On device mlx5_2 port 1, for each new user QP bind it\n with a counter automatically. Per counter for QPs with same qp type.
\n

rdma statistic qp set link mlx5_2/1 auto type on optional-counters\n on

\n
On device mlx5_2 port 1, for each new user QP bind it\n with a counter automatically. Per counter for QPs with same qp type. Whilst\n also binding the currently enabled optional-counters.
\n

rdma statistic qp set link mlx5_2/1 auto pid on

\n
On device mlx5_2 port 1, for each new user QP bind it\n with a counter automatically. Per counter for QPs with same pid.
\n

rdma statistic qp set link mlx5_2/1 auto pid,type on

\n
On device mlx5_2 port 1, for each new user QP bind it\n with a counter automatically. Per counter for QPs with same pid and same\n type.
\n

rdma statistic qp set link mlx5_2/1 auto off

\n
Turn-off auto mode on device mlx5_2 port 1. The allocated\n counters can be manually accessed.
\n

rdma statistic qp bind link mlx5_2/1 lqpn 178

\n
On device mlx5_2 port 1, allocate a counter and bind the\n specified qp on it
\n

rdma statistic qp unbind link mlx5_2/1 cntn 4 lqpn 178

\n
On device mlx5_2 port 1, bind the specified qp on the\n specified counter
\n

rdma statistic qp unbind link mlx5_2/1 cntn 4

\n
On device mlx5_2 port 1, unbind all QPs on the specified\n counter. After that this counter will be released automatically by the\n kernel.
\n

rdma statistic show mr

\n
List all currently allocated MR's and their\n counters.
\n

rdma statistic show mr mrn 6

\n
Dump a specific MR statistics with mrn 6. Dumps nothing\n if does not exists.
\n

rdma statistic mode link mlx5_2/1

\n
Display the optional counters that was enabled on\n mlx5_2/1.
\n

rdma statistic mode supported link mlx5_2/1

\n
