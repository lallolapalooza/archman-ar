recno(3)

RECNO - record number access

NAME

recno - record number access

LIBRARY

Record access library (libdb)

SYNOPSIS

#include <db.h>

int recno_open(DB **dbpp, const char *file, u_int32_t flags, int mode);

int recno_close(DB *dbp);

int recno_del(DB *dbp, const DBT *key, u_int32_t flags);

int recno_get(DB *dbp, const DBT *key, DBT *data, u_int32_t flags);

int recno_put(DB *dbp, const DBT *key, const DBT *data, u_int32_t flags);

DESCRIPTION

The recno access method is an implementation of the record number access method for IEEE Std 1003.1d (POSIX.1d) Databases. It is described in the dbm(3) and hsearch(3) manual pages.

The recno access method supports access to files of records, where each record is identified by a 32-bit unsigned integer. The records are not necessarily ordered in the file. Records may be deleted and inserted anywhere in the file. The recno access method maintains the record numbers in the file and assigns new record numbers as needed.

The recno_open function opens a database file and returns a pointer to a DB handle. The file argument is the name of the file to be opened. The flags argument is a bitwise OR of the following constants:

  • DB_CREATE: Create the database if it does not exist.
  • DB_TRUNCATE: Truncate the database if it exists.
  • DB_EXCL: Exclusive access to the database.
  • DB_RDONLY: Read-only access to the database.

The mode argument is the file mode for the database if it is created.

The recno_close function closes the database file.

The recno_del function deletes a record from the database. The key argument is a pointer to a DBT structure that specifies the record number to be deleted.

The recno_get function retrieves a record from the database. The key argument is a pointer to a DBT structure that specifies the record number to be retrieved. The data argument is a pointer to a DBT structure that will store the retrieved record data.

The recno_put function stores a record in the database. The key argument is a pointer to a DBT structure that specifies the record number to be stored. If the record number is 0, a new record number will be assigned. The data argument is a pointer to a DBT structure that specifies the record data to be stored.

ERRORS

The recno functions may return the following error values:

  • DB_BADDB: The database file is corrupted.
  • DB_DEADLOCK: A deadlock was detected.
  • DB_LOCKINVALID: The lock could not be acquired.
  • DB_NOPERM: Permission denied.
  • DB_NOMEM: Out of memory.
  • DB_NOTFOUND: The key was not found.
  • DB_RUNRECOVERY: A recovery operation is required.
  • DB_RMW_ERROR: An error occurred during a read-modify-write operation.
  • DB_VERIFY: The database needs to be verified.
  • EINVAL: An invalid argument was provided.
  • ENOSPC: No space left on device.

BUGS

None.
