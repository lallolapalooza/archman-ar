RZ_AX(1) دليل الأوامر العامة RZ_AX(1)

الاسم

rz-ax — محول أساس rizin

الملخص

rz-ax [-ebBdDeEfFhiIklLosStuvwx] [[تعبير] ...]

الوصف

هذا الأمر جزء من مشروع Rizin.

يسمح لك هذا الأمر بتحويل القيم بين الأعداد الصحيحة الموجبة والسالبة، الأعداد العشرية، الثمانية، الثنائية، الثلاثية، والسداسية عشرية.

خيارات

-a
عرض جدول ASCII
-b
التحويل من ثنائي إلى سلسلة (rz-ax -b 01000101 01110110)
-B
التحويل من سلسلة إلى ثنائي (rz-ax -B hello)
-d
فرض الإخراج كعدد صحيح (rz-ax -d 3 يخرج 3 بدلاً من 0x3)
-D
فك ترميز Base64
-e
تبديل ترتيب البايت (rz-ax -e 0x33)
-E
ترميز Base64
-f
حسابات الأعداد العشرية (rz-ax -f 6.3+2.1)
-F
قراءة سلاسل C من الإدخال القياسي وإخراجها في أزواج سداسية عشرية. مفيد لتحميل الشل كود (rz-ax -F < shellcode.[c/py/js])
-h
عرض رسالة المساعدة للاستخدام
-i
تفريغ الإدخال القياسي إلى مصفوفة C في الإخراج القياسي (rz-ax -i < bytes)
-I
تحويل LONG إلى/من عنوان IP (rz-ax -I 3530468537)
-k
الحفاظ على نفس الأساس مثل بيانات الإدخال (rz-ax -k 33+3 -> 36)
-l
إضافة سطر جديد إلى الإخراج المفكوك
-L
التحويل من ثنائي إلى سداسي عشري (rz-ax -L 111111111 يخرج 0x1ff)
-n
عرض أزواج سداسية عشرية من قيمة عدد صحيح (rz-ax -n 0x1234 # 34120000)
-N
عرض سلسلة C سداسية عشرية من قيمة عدد صحيح (rz-ax -N 0x1234 # 4200)
-o
التحويل من سلسلة ثمانية إلى حرف (rz-ax -o 162 172 # rz)
-r
إخراج نمط Rz (rz-ax -r 0x1234)
-s
التحويل من سلسلة سداسية عشرية إلى حرف (rz-ax -s 43 4a 50)
-S
التحويل من حرف إلى سلسلة سداسية عشرية (rz-ax -S < /bin/ls > ls.hex)
-t
تحويل طابع زمني Unix إلى سلسلة (rz-ax -t 1234567890)
-m
تحويل طابع زمني MS-DOS إلى سلسلة (rz-ax -m 0x12345678)
-W
تحويل طابع زمني Win32 إلى سلسلة (rz-ax -W 1234567890)
-u
تحويل القيمة المعطاة إلى تنسيق وحدات قابل للقراءة (rz-ax -u 389289238 # 317.0M)
-v
عرض معلومات الإصدار
-w
تحويل كلمة موقعة (rz-ax -w 16 0xffff)
-x
تحويل سلسلة إلى تجزئة (rz-ax -x linux osx)
-p
عرض موضع البتات المضبوطة في التمثيل الثنائي (rz-ax -p 0xb3)

الاستخدام

فرض وضع الإخراج (الأس العددي)


=f عشري
=2 ثنائي
=3 ثلاثي
=8 ثماني
=10 عشري
=16 سداسي عشري

أنواع المتغيرات المتاحة هي:


int -> hex rz-ax 10
hex -> int rz-ax 0xa
-int -> hex rz-ax -77
-hex -> int rz-ax 0xffffffb3
int -> bin rz-ax b30
int -> ternary rz-ax t42
ternary -> int rz-ax 1010dt
bin -> int rz-ax 1010d
float -> hex rz-ax 3.33f
hex -> float rz-ax Fx40551ed8
oct -> hex rz-ax 35o
hex -> oct rz-ax 0x12 (O هو حرف)
bin -> hex rz-ax 1100011b
hex -> bin rz-ax Bx63
ternary -> hex rz-ax 212t
hex -> ternary z-ax Tx23
raw -> hex rz-ax -S < /binfile
hex -> raw rz-ax -s 414141

بدون وسائط، يقرأ rz-ax القيم من الإدخال القياسي. يمكنك تمرير قيمة واحدة أو أكثر كوسائط.


$ rz-ax 33 0x41 0101b
0x21
65
0x5

يمكنك "فك" السلاسل المشفرة بالأزواج السداسية عشرية بسهولة.


$ rz-ax -s 41 42 43
ABC

وهو يدعم بعض عمليات الرياضيات.


$ rz-ax
0x5*101b+5
30

إنه أداة مفيدة جدًا للبرمجة النصية، بحيث يمكنك قراءة قيم الأعداد العشرية، أو الحصول على الإزاحة العددية للقفزة أو دلتا المكدس عند تحليل البرامج.
