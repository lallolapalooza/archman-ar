DESCRIPTION

GNU as is really a family of assemblers. If you use (or\n have used) the GNU assembler on one architecture, you should find a fairly\n similar environment when you use it on another architecture. Each version\n has much in common with the others, including object file formats, most\n assembler directives (often called pseudo-ops) and assembler\n syntax.

\n

as is primarily intended to assemble the output of the GNU\n C compiler "gcc" for use by the linker\n "ld". Nevertheless, we've tried to make\n as assemble correctly everything that other assemblers for the same\n machine would assemble. Any exceptions are documented explicitly. This\n doesn't mean as always uses the same syntax as another assembler for\n the same architecture; for example, we know of several incompatible versions\n of 680x0 assembly language syntax.

\n

Each time you run as it assembles exactly one source\n program. The source program is made up of one or more files. (The standard\n input is also a file.)

\n

You give as a command line that has zero or more input file\n names. The input files are read (from left file name to right). A\n command-line argument (in any position) that has no special meaning is taken\n to be an input file name.

\n

If you give as no file names it attempts to read one input\n file from the as standard input, which is normally your terminal. You\n may have to type ctl-D to tell as there is no more program to\n assemble.

\n

Use -- if you need to explicitly name the standard input\n file in your command line.

\n

If the source is empty, as produces a small, empty object\n file.

\n

as may write warnings and error messages to the standard\n error file (usually your terminal). This should not happen when a compiler\n runs as automatically. Warnings report an assumption made so that\n as could keep assembling a flawed program; errors report a grave\n problem that stops the assembly.

\n

If you are invoking as via the GNU C compiler, you can use\n the -Wa option to pass arguments through to the assembler. The\n assembler arguments must be separated from each other (and the -Wa)\n by commas. For example:

\n
gcc -c -g -O -Wa,-alh,-L file.c
\n

This passes two options to the assembler: -alh (emit a\n listing to standard output with high-level and assembly source) and\n -L (retain local symbols in the symbol table).

\n

Usually you do not need to use this -Wa mechanism, since\n many compiler command-line options are automatically passed to the assembler\n by the compiler. (You can call the GNU compiler driver with the -v\n option to see precisely what options it passes to each compilation pass,\n including the assembler.)

@chapter ميزات Z80 التابعة

خيارات سطر الأوامر

-march=CPU[-EXT...][+EXT...]

يحدد هذا الخيار المعالج المستهدف. سيصدر المجمع رسالة خطأ إذا تم محاولة تجميع تعليمة لن يتم تنفيذها على المعالج المستهدف. أسماء المعالجات التالية معترف بها: "z80"، "z180"، "ez80"، "gbz80"، "z80n"، "r800". بالإضافة إلى مجموعة التعليمات الأساسية، يمكن إخبار المجمع بقبول بعض امتدادات الاختصارات. على سبيل المثال، "-march=z180+sli+infc" يوسع z180 مع تعليمات SLI و IN F,(C). الامتدادات التالية مدعومة حاليًا: "full" (جميع التعليمات المعروفة)، "adl" (وضع وحدة المعالجة المركزية ADL افتراضيًا، eZ80 فقط)، "sli" (التعليمة المعروفة باسم SLI، SLL أو SL1)، "xyhl" (تعليمات مع أنصاف سجلات الفهرس: IXL، IXH، IYL، IYH)، "xdcb" (تعليمات مثل RotOp (II+d)،R و BitOp n,(II+d)،R)، "infc" (التعليمة IN F,(C) أو IN (C))، "outc0" (التعليمة OUT (C)،0). لاحظ أنه بدلاً من توسيع مجموعة تعليمات أساسية، فإن اختصارات الامتداد التي تبدأ بـ "-" تلغي الوظائف المقابلة: "-march=z80-full+xyhl" تزيل أولاً جميع الامتدادات الافتراضية وتضيف دعمًا لأنصاف سجلات الفهرس فقط.

إذا لم يتم تحديد هذا الخيار، فسيتم افتراض "-march=z80+xyhl+infc".

-local-prefix=prefix

وضع علامة على جميع التسميات ذات البادئة المحددة على أنها محلية. ولكن يمكن وضع علامة على مثل هذه التسمية على أنها عامة بشكل صريح في الكود. هذا الخيار لا يغير بادئة التسمية المحلية الافتراضية ".L"، بل يضيف واحدة جديدة فقط.

-colonless

قبول التسميات التي لا تحتوي على نقطتين رأسيتين. يتم التعامل مع جميع الرموز في بداية السطر كتسميات.

-sdcc

قبول كود المجمع الذي تم إنتاجه بواسطة SDCC.

-fp-s=FORMAT

تنسيق الأرقام ذات الفاصلة العائمة بدقة فردية. الافتراضي: ieee754 (32 بت).

-fp-d=FORMAT

تنسيق الأرقام ذات الفاصلة العائمة بدقة مزدوجة. الافتراضي: ieee754 (64 بت).
