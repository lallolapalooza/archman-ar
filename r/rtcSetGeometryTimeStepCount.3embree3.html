rtcSetGeometryTimeStepCount(3) Embree Ray Tracing Kernels 3 rtcSetGeometryTimeStepCount(3)

الاسم

rtcSetGeometryTimeStepCount - تحدد عدد خطوات الزمن للهندسة

الملخص

#include <embree3/rtcore.h>
void rtcSetGeometryTimeStepCount(
  RTCGeometry geometry,
  unsigned int timeStepCount
);

الوصف

تحدد الدالة `rtcSetGeometryTimeStepCount` عدد خطوات الزمن (المعلمة `timeStepCount`) للتمويه متعدد الشرائح (multi-segment motion blur) للهندسة المحددة (المعلمة `geometry`).

بالنسبة لشبكات المثلثات (RTC_GEOMETRY_TYPE_TRIANGLE) وشبكات الرباعيات (RTC_GEOMETRY_TYPE_QUAD) والمنحنيات (RTC_GEOMETRY_TYPE_CURVE) والنقاط (RTC_GEOMETRY_TYPE_POINT) والهندسات التقسيمية (RTC_GEOMETRY_TYPE_SUBDIVISION)، يتوافق عدد خطوات الزمن مباشرة مع عدد فتحات مخزن الرؤوس المتاحة (نوع المخزن RTC_BUFFER_TYPE_VERTEX). لهذه الهندسات، يجب تحديد مخزن رؤوس واحد لكل خطوة زمن عند إنشاء هندسات تمويه متعدد الشرائح.

بالنسبة لهندسات النسخ (RTC_GEOMETRY_TYPE_INSTANCE)، يجب تحديد تحويل لكل خطوة زمن (انظر `rtcSetGeometryTransform`).

بالنسبة للهندسات المخصصة، يجب أن توفر دالة الاستدعاء الخاصة بالمربعات المحيطة (bounding callback) مربعًا محيطًا لكل شكل أولي وخطوة زمن، ويجب أن تقوم دوال الاستدعاء الخاصة بالتقاطع والإخفاء (intersection and occlusion callback functions) بتقاطع الهندسة المُموهة بشكل صحيح عند وقت الشعاع (ray time).

حالة الخروج

عند حدوث فشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام `rtcGetDeviceError`.
