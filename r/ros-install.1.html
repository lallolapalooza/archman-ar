التراخيص: MIT

ros-install(1) ros-install(1)

ros-install - تثبيت تطبيقات ليسب أو نظام quicklisp

الملخص

•
ros install system [system ...]
•
ros install impl[/version] [param ...]

الوصف

system
اسم يحدد نظامًا.
impl
اسم يحدد تطبيق ليسب.

تثبيت تطبيق ليسب

عندما يتطابق impl أو system مع أحد التطبيقات المدعومة، فإنه يقوم بجلب وتنزيل وتثبيته في أحد الدلائل الداخلية التي يديرها roswell (~/.roswell، أو ROSWELL_INSTALL_DIR). لاستخدام التطبيق المثبت، يجب عليك تشغيل ros-use(1).

على سبيل المثال، يقوم الأمر التالي بتنزيل أحدث ملف ثنائي sbcl من sbcl.org. لاحظ أن هذا قد يختلف عن الملف الثنائي الافتراضي الذي تم تثبيته بواسطة roswell، المسمى sbcl-bin. sbcl-bin هو إصدار مستقر ومختبر جيدًا من الملف الثنائي sbcl والذي من المفترض أن يكون أقدم قليلاً من أحدث sbcl.

$ ros install sbcl

عند استدعائه بدون اسم، فإنه يعرض قائمة بالتطبيقات القابلة للتثبيت. (لا تخلط بينه وبين ros list installed، الذي يعرض التطبيقات المثبتة بالفعل.)

Usage: ros install impl [OPTIONS]
For more details on impl specific options, type:
ros help install impl
Candidates impls for installation are:
ecl
sbcl
clisp
ccl-bin
sbcl-bin

يمكن أن يتبع الاسم اختياريًا شرطة مائلة / وإصدار التطبيق.

$ ros install sbcl/1.2.14

قد تكون هناك بعض التطبيقات 'المخفية' التي لم يتم سردها هنا - فهي في مرحلة ألفا، ولكن جرب ما تفضله أو راقب الموقع (https://github.com/roswell/roswell).

$ ros install ccl
$ ros install abcl
$ ...

تثبيت نظام quicklisp ونصوص roswell المرفقة

إذا كان الاسم المحدد لا يتطابق مع أي من التطبيقات، فسيحاول roswell العثور على نظام quicklisp بالاسم المحدد.

$ ros install alexandria

بعد تجميع وتحميل النظام، يقوم باستدعاء المتغير الخاص ros:*build-hook* بدون وسيطات، إذا تم تعيين دالة ما أثناء التجميع/التحميل.

عندما يأتي النظام مع نص roswell تم إنشاؤه بواسطة ros-init(1) في الدليل الفرعي roswell، يتم تثبيتها في ROSWELL_INSTALL_DIR/bin. يؤدي تعيين المسار إلى هذا الدليل إلى جعل هذه النصوص متاحة من سطر أوامر shell.

$ ros install qlot
System 'qlot' found. Loading the system..
Processing build-hook..
Found 1 scripts: qlot
Attempting to install the scripts in roswell/ subdirectory of the system...
/home/user/.roswell/bin/qlot
$ qlot
Usage: qlot [install | update | bundle | exec shell-args..]
