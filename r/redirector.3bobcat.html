NAME

redirector — redirecting standard streams

SYNOPSIS

    #include <bobcat/redirector>
class FBB::Redirector

    public:
        enum { STDIN, STDOUT, STDERR };

        Redirector(int otherFd, bool swallow = false);
        Redirector(int otherFd, int otherFd2, bool swallow = false);

        ~Redirector();

        // specifically for STDOUT and STDERR
        void swallow(int otherFd);
        void swallow(int otherFd1, int otherFd2);

        // needed for `dup2`
        int fd() const;

    private:
        int stdio_[3];
        int original_[3];
        bool swallow_;
};

DESCRIPTION

The Redirector class allows you to redirect standard input, output, and error streams to a specified file descriptor. This is particularly useful for capturing or redirecting program output without modifying the program's source code.

The constructor takes one or two file descriptors as arguments. These file descriptors specify the new destinations for the standard streams.

By default, the Redirector redirects STDOUT_FILENO to the specified file descriptor. You can also redirect STDIN_FILENO and STDERR_FILENO by passing them as arguments to the constructor or by using the swallow member function.

When a Redirector object is created, the original standard streams are saved, and the new streams are set up using dup2(2). When the Redirector object goes out of scope (e.g., at the end of a function), the original standard streams are restored.

If the swallow parameter is set to true, any output written to the original standard streams after redirection will be discarded.

The fd member function returns the file descriptor associated with the Redirector object.

If redirection fails (e.g., due to invalid file descriptors), an FBB::Exception object is thrown, and its which() member will contain the system's errno value set by the failing dup2(2) call.

NAMESPACE

namespace FBB

INHERITS FROM

none

ENUM

Redirector::STDIN
Corresponds to standard input (file descriptor 0).
Redirector::STDOUT
Corresponds to standard output (file descriptor 1).
Redirector::STDERR
Corresponds to standard error (file descriptor 2).

CONSTRUCTORS

Redirector(int otherFd, bool swallow = false);
Redirects STDOUT_FILENO to otherFd. If swallow is true, subsequent writes to the original STDOUT_FILENO will be discarded.
Redirector(int otherFd1, int otherFd2, bool swallow = false);
Redirects STDOUT_FILENO to otherFd1 and STDERR_FILENO to otherFd2. If swallow is true, subsequent writes to the original STDOUT_FILENO and STDERR_FILENO will be discarded.

Additionally, you can redirect standard input by providing STDIN_FILENO as one of the arguments. For example, Redirector(STDIN_FILENO, STDOUT_FILENO) would redirect standard input to the file descriptor provided for standard output, and standard output to the same file descriptor.

If otherFd is STDIN_FILENO and k and otherFd is STDIN_FILENO then all information extracted from the standard input stream is actually read from the file on disk.

    information extracted from otherFd <- is read from the constructor’s Fd
    (e.g., otherFd = STDIN_FILENO)

Before setting up the redirection, the original otherFd is closed by close(2). Following through only otherFd can be used, and it refers to (i.e., reads or writes) the constructor’s file descriptor.

If redirection fails an FBB::Exception object is thrown, whose which() member shows the system’s errno value set by the failing dup2(2) function.

EXAMPLE

    #include <iostream>
    #include <bobcat/redirector>
    using namespace std;
    using namespace FBB;
    int main()
    {
        Redirector redirector(Redirector::STDOUT);
        redirector.swallow(Redirector::STDERR);
        cerr << "This appears at the standard output stream\n"
                "use `a.out > /dev/null’ to suppress this message" << endl;
    }
