NAME

riscv64-elf-strings — print the strings in an object file

SYNOPSIS

riscv64-elf-strings [] object_file ...

DESCRIPTION

The riscv64-elf-strings utility prints the printable 32-character or longer sequences of characters that are in the specified files. A sequence of characters is considered to be a string if it contains at least four characters and all four are printable. The string must end with a non-printable character. This command is useful for finding ASCII strings in binary files, such as symbols that were not stripped from an object file.

The riscv64-elf-strings utility supports the following options:

OPTIONS

-a, --all
Scan all sections of the object file, not just those that contain data.
-d, --data
Scan only the data sections of the object file.
-f, --print-file-name
Precede each string by the name of the file it came from.
-n minlen, --bytes=minlen
Specify the minimum string length to print. The default is 4.
-t radix, --radix=radix
Output an offset from the beginning of the file to each string. The radix can be d for decimal, o for octal, or x for hexadecimal.

الاسم

riscv64-elf-strings — طباعة السلاسل النصية في ملف كائني

ملخص

riscv64-elf-strings [] ملف_كائني ...

الوصف

الأداة المساعدة riscv64-elf-strings تطبع تسلسلات الأحرف القابلة للطباعة بطول 32 حرفًا أو أطول والتي توجد في الملفات المحددة. يُعتبر تسلسل الأحرف سلسلة نصية إذا كان يحتوي على أربعة أحرف على الأقل وجميعها قابلة للطباعة. يجب أن تنتهي السلسلة النصية بحرف غير قابل للطباعة. هذه الأداة مفيدة للعثور على السلاسل النصية ASCII في الملفات الثنائية، مثل الرموز التي لم يتم تجريدها من ملف كائني.

تدعم الأداة المساعدة riscv64-elf-strings الخيارات التالية:

خيارات

-a, --all
مسح جميع أقسام الملف الكائني، وليس فقط تلك التي تحتوي على بيانات.
-d, --data
مسح أقسام البيانات فقط في الملف الكائني.
-f, --print-file-name
يسبق كل سلسلة نصية باسم الملف الذي أتت منه.
-n minlen, --bytes=minlen
تحديد الحد الأدنى لطول السلسلة النصية المراد طباعتها. القيمة الافتراضية هي 4.
-t radix, --radix=radix
إخراج إزاحة من بداية الملف لكل سلسلة نصية. يمكن أن يكون radix d للعشري، o للثماني، أو x للسداسي عشري.
