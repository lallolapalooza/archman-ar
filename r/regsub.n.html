regsub(n)

الحزمة: tcl

التراخيص: TCL

regsub(n) أوامر Tcl المضمنة regsub(n)

الاسم

regsub - إجراء عمليات استبدال بناءً على مطابقة تعبير قياسي

الملخص

regsub ?مفاتيح? تعبير نص_بديل ?اسم_متغير?

الوصف

يقوم هذا الأمر بمطابقة التعبير القياسي exp مع string، وإما نسخ string إلى المتغير الذي اسمه varName أو إرجاع string إذا لم يكن varName موجودًا. (تتم مطابقة التعبيرات القياسية في صفحة مرجع re_syntax.) إذا كان هناك تطابق، فإنه أثناء نسخ string إلى varName (أو إلى نتيجة هذا الأمر إذا لم يكن varName موجودًا) يتم استبدال الجزء من string الذي طابق exp بـ subSpec. إذا كان subSpec يحتوي على “&” أو “\0”، فسيتم استبداله في الاستبدال بالجزء من string الذي طابق exp. إذا كان subSpec يحتوي على “\n”، حيث n هو رقم بين 1 و 9، فسيتم استبداله في الاستبدال بالجزء من string الذي طابق التعبير الفرعي ذي الأقواس n لـ exp. يمكن استخدام الشرطات المائلة الإضافية في subSpec لمنع التفسير الخاص لـ “&”، “\0”، “\n” والشرطات المائلة. تميل طريقة استخدام الشرطات المائلة في subSpec إلى التفاعل بشكل سيء مع استخدام محلل Tcl للشرطات المائلة، لذا من الآمن بشكل عام إحاطة subSpec بأقواس معقوفة إذا كانت تحتوي على شرطات مائلة.

إذا بدأت الوسائط الأولية لـ regsub بـ - فإنها تُعامل كمفاتيح. المفاتيح التالية مدعومة حاليًا:

-all
يتم العثور على جميع النطاقات في string التي تطابق exp ويتم إجراء الاستبدال لكل من هذه النطاقات. بدون هذا المفتاح، يتم العثور على النطاق المطابق الأول واستبداله فقط. إذا تم تحديد -all، يتم التعامل مع تسلسلات “&” و “\n” لكل استبدال باستخدام المعلومات من المطابقة المقابلة.
-expanded
يُمكّن استخدام بناء جملة التعبير القياسي الموسع حيث يتم تجاهل المسافات البيضاء والتعليقات. هذا هو نفس تحديد الخيار المضمن (?x) (انظر صفحة دليل re_syntax).
-line
يُمكّن المطابقة الحساسة لأسطر جديدة. بشكل افتراضي، يكون السطر الجديد حرفًا عاديًا تمامًا بدون معنى خاص. مع هذا العلم، لا تطابق تعبيرات الأقواس “[^” و “.” السطر الجديد أبدًا، ويطابق “^” سلسلة فارغة بعد أي سطر جديد بالإضافة إلى وظيفته العادية، ويطابق “$” سلسلة فارغة قبل أي سطر جديد بالإضافة إلى وظيفته العادية. هذا العلم يعادل تحديد كل من -linestop و -lineanchor، أو الخيار المضمن (?n) (انظر صفحة دليل re_syntax).
-linestop
يغير سلوك تعبيرات الأقواس “[^” و “.” بحيث تتوقف عند أسطر جديدة. هذا هو نفس تحديد الخيار المضمن (?p) (انظر صفحة دليل re_syntax).
-lineanchor
يغير سلوك “^” و “$” (الـ "مرساة") بحيث تطابق بداية ونهاية السطر على التوالي. هذا هو نفس تحديد الخيار المضمن (?w) (انظر صفحة دليل re_syntax).
-nocase
سيتم تحويل الأحرف الكبيرة في string إلى أحرف صغيرة قبل مطابقتها مع exp؛ ومع ذلك، تستخدم الاستبدالات التي يحددها subSpec الشكل الأصلي غير المحول لـ string.
-start index
يحدد إزاحة فهرس حرف في السلسلة لبدء مطابقة التعبير القياسي عندها. يتم تفسير قيمة index بنفس طريقة الوسيط index للأمر string index. عند استخدام هذا المفتاح، لن تطابق “^” بداية السطر، وسيظل \A يطابق بداية السلسلة عند index. سيتم تقييد index بحدود السلسلة المدخلة.
--
يشير إلى نهاية المفاتيح. سيتم التعامل مع الوسيط الذي يليه كـ exp حتى لو بدأ بـ -.

إذا تم توفير varName، يقوم الأمر بإرجاع عدد النطاقات المطابقة التي تم العثور عليها واستبدالها، وإلا يتم إرجاع السلسلة بعد الاستبدال. انظر دليل regexp للحصول على تفاصيل حول تفسير التعبيرات القياسية.

أمثلة

استبدال (في السلسلة في المتغير string) كل مثيل لـ foo التي هي كلمة بحد ذاتها بـ bar:

regsub -all {\mfoo\M} $string bar string

أو (باستخدام بناء جملة "التعبير القياسي الأساسي"):

regsub -all {(?b)\<foo\>} $string bar string

إدراج علامات اقتباس مزدوجة حول المثيل الأول للكلمة interesting، مهما كانت طريقة كتابتها بأحرف كبيرة.

regsub -nocase {\yinteresting\y} $string {"&"} string

تحويل جميع الأحرف غير ASCII وذات الأهمية لـ Tcl إلى تسلسلات هروب \u باستخدام regsub و subst معًا:

# هذا RE هو مجرد فئة أحرف لكل شيء "سيء" تقريبًا
set RE {[][{};#\\\$ \r\t\u0080-\uffff]}
# سنستبدل بجزء من سكريبت Tcl بين أقواس
set substitution {[format \\\\u%04x [scan "\\&" %c]]}
# الآن نطبق الاستبدال للحصول على سلسلة فرعية
# ستقوم بالأجزاء الحسابية للتحويل. لاحظ أن
# السطر الجديد يتم التعامل معه بشكل خاص من خلال string map
# لأن \_n هو تسلسل خاص.
set quoted [subst [string map {\n {\\u000a}} \
        [regsub -all $RE $string $substitution]]]
