rocqide(1) دليل الأوامر العامة rocqide(1)

الاسم

rocqide - واجهة رسومية لمثبت Rocq

الملخص

rocqide [ خيارات ]

الوصف

rocqide هي واجهة رسومية تعتمد على GTK لمثبت Rocq.

للاستخدام الموجه بسطر الأوامر أو للاستخدام الدفعي لـ Rocq، راجع rocq(1).

الخيارات

-h
عرض القائمة الكاملة للخيارات التي يقبلها rocqide.
-I dir, -include dir
أضف الدليل dir إلى مسار التضمين.
-R dir rocqdir
قم بتعيين الدليل المادي dir بشكل متكرر إلى الدليل المنطقي rocqdir.
-src
أضف أدلة المصدر إلى مسار التضمين.
-nois
ابدأ بحالة فارغة.
-load-ml-object f
تحميل ملف كائن ML f.
-load-ml-source f
تحميل ملف ML f.
-l f, -load-vernac-source f
تحميل ملف Rocq f.v (تحميل f.).
-lv f, -load-vernac-source-verbose f
تحميل ملف Rocq f.v (تحميل مطول f.).
-load-vernac-object path
تحميل مكتبة Rocq path (طلب path.).
-require-import path
تحميل مكتبة Rocq path واستيرادها (طلب استيراد path.).
-compile f
ترجمة ملف Rocq f.v (يعني -batch).
-compile-verbose f
ترجمة مطولة لملف Rocq f.v (يعني -batch).
-where
طباعة موقع المكتبة القياسية لـ Rocq والخروج.
-v
طباعة إصدار Rocq والخروج.
-q
تخطي تحميل ملف rcfile.
-init-file f
تعيين ملف rcfile إلى f.
-emacs
يخبر Rocq أنه يتم تشغيله تحت Emacs.
-dump-glob f
تفريغ العولمة في الملف f (ليتم استخدامه بواسطة rocq(1)doc).
-impredicative-set
تعيين الفرز Set impredicative.
-dont-load-proofs
لا تقم بتحميل البراهين المعتمة في الذاكرة.
