revtwoway(3am)

الحزمة: gawk

التراخيص: GPL-3.0-or-later

REVTWOWAY(3am) وحدات امتداد GNU Awk REVTWOWAY(3am)

الاسم

revtwoway - امتداد معالج ثنائي الاتجاه بسيط لعكس السلاسل النصية

الملخص

@load "revtwoway"

BEGIN {
    cmd = "/magic/mirror"
    print "hello, world" |& cmd
    cmd |& getline result
    print result
    close(cmd)
}

الوصف

يضيف الامتداد revtwoway معالجًا بسيطًا ثنائي الاتجاه يعكس الأحرف في كل سطر يتم إرساله إليه للقراءة مرة أخرى بواسطة برنامج AWK. غرضه الرئيسي هو إظهار كيفية كتابة امتداد ثنائي الاتجاه، على الرغم من أنه قد يكون مضحكًا بشكل طفيف.

GAWK: Effective AWK Programming, filefuncs(3am), fnmatch(3am), fork(3am), inplace(3am), ordchr(3am), readdir(3am), readfile(3am), revoutput(3am), rwarray(3am), time(3am).
