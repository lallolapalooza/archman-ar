NAME

z - Signature generation and matching for radare2

SYNOPSIS

z [options]
Manage and use function signatures in radare2.
za [options]
Generate signatures.
zb [options]
Search for signatures.
zc [options]
Compare signatures.
zd [options]
Delete signatures.
ze [options]
Export signatures.
zi [options]
Import signatures.
zl [options]
List signatures.
zo [options]
Open signature databases.
zq [options]
Query signatures.
zr [options]
Rename signatures.
zz [options]
Commit changes to signature databases.

DESCRIPTION

The z command in radare2 provides a powerful framework for generating, matching, and managing function signatures (zignatures). Zignatures are used to identify and classify functions within binaries, enabling features like function identification, vulnerability detection, and code similarity analysis.

The various subcommands allow for granular control over the zignature process, from loading and saving signature databases to generating new signatures from analyzed code and searching for matching functions.

OPTIONS

The following options apply to the main z command and its subcommands:

-f
Force overwrite or operation.
-i
Interactive mode.
-q
Quiet mode.
-v
Verbose output.
@addr
Address to perform the operation on.
file
Filename for loading, saving, or exporting signatures.

USAGE EXAMPLES

This section demonstrates common use cases for the z command and its subcommands.

THE Z COMMAND IN RADARE2

The z command is the entry point for all zignature-related operations in radare2. It allows you to manage and utilize function signatures to enhance your binary analysis workflow.

CONFIGURATION OPTIONS

Several configuration options can influence the behavior of the zignature commands:

z.nbytes
Number of bytes to consider for hashing.
z.minlen
Minimum function length for signature generation.
z.maxlen
Maximum function length for signature generation.
z.threads
Number of threads to use for signature generation/scanning.
z.db
Default path for signature databases.

ADDING ZIGNATURES

You can add new zignatures to radare2 in several ways:

zo file
Load zignatures from a file (e.g., zo lib.sdb).
zaF
Generate zignatures for all functions in the current binary.
za addr
Generate a signature for the function at the specified address.

ZIGNATURE COMMANDS

The following are key subcommands for managing zignatures:

z
List all loaded zignatures.
za
Generate zignatures.
zb
Search for the closest matching zignatures.
zc
Compare zignatures.
zd
Delete zignatures.
ze
Export zignatures.
zi
Import zignatures.
zl
List zignatures.
zo
Open (load) zignature databases.
zq
Query zignatures.
zr
Rename zignatures.
zz
Commit (save) changes to zignature databases.
z.
Find matching zignatures at the current offset.
z/
Scan all functions to find matching zignatures.

SUPPORTED ZIGNATURE METRICS

The zignature system supports various metrics for matching functions:

h: bbhash
Uses hashing of function basic blocks for matching.
v: vars (and args)
Matches based on variables and arguments.

Each metric allows for a nuanced approach to identifying and comparing functions across binaries, enabling more accurate and comprehensive analysis.

USAGE EXAMPLES FOR THE Z COMMAND

The z command in radare2 is versatile, offering various functionalities through its subcommands. Here are five usage examples:

Show all zignatures
z
Displays all zignatures currently loaded in radare2.
Find matching zignatures at the current offset
z.
Searches for and displays zignatures that match at the current offset in the binary.
Scan all functions to find matching zignatures
z/
Searches and match all signatures loaded against all the analyzed functions in order to give a name to every one.
Load zignature files
zo libc.sdb
Loads zignatures from the specified SDB file into the current session.
Generate zignatures for all functions
zaF
Generates zignatures for all identified functions in the binary and adds them to the current session.
Search for the closest matching zignatures
zb
Searches for and displays the closest matching zignatures to the function at the current offset, helping identify similar functions across binaries.

These examples showcase the `z` command's ability to manage zignatures efficiently, aiding in the binary analysis process by leveraging the power of zignatures for function identification and comparison.
