rz-bin(1)

RZ_BIN(1) دليل الأوامر العامة RZ_BIN(1)

الاسم

rz-bin — مستخرج معلومات البرامج الثنائية

الملخص

rz-bin [-AcdeEghHiIjlLMqrRsSUvVxzZ] [-@ عنوان] [-a بنية] [-b بت] [-B عنوان] [-C F:C:D] [-f سلسلة] [-m عنوان] [-n سلسلة] [-N m:M] [-P pdb] [-o سلسلة] [-O سلسلة] [-k استعلام] [-D لغة اسم_الرمز] ملف

الوصف

هذا الأمر هو جزء من مشروع Rizin.

يمكن لـ rz-bin تحليل واستخراج معلومات مفيدة من الملفات التنفيذية الثنائية مثل ELF، PE، Mach-O، إلخ. يدعم معماريات متعددة مثل x86، ARM، MIPS، PowerPC، إلخ.

الخيارات

-@ عنوان
عرض القسم أو الرمز أو الاستيراد في العنوان المحدد
-A
قائمة البرامج الثنائية الفرعية وأزواج البنية-البتات الخاصة بها
-a بنية
تعيين البنية (x86، arm، .. أو <بنية>_<بت>)
-b بت
تعيين عدد البتات (32، 64 ...)
-B عنوان
تجاوز عنوان القاعدة (برامج PIE الثنائية)
-c
قائمة الفئات
-cc
قائمة الفئات بتنسيق الرأس
-C fmt:C:D
إنشاء [elf، mach0، pe] مع أزواج الأكواد والبيانات بالست عشري (انظر -a)
-d
عرض معلومات التصحيح/dwarf
-dd
تحميل معلومات التصحيح/dwarf من خادم debuginfod
-D لغة اسم_الرمز
فك ترميز اسم الرمز (-D all لـ bin.demangle=true)
-e
نقطة الدخول
-E
الرموز القابلة للتصدير عالمياً
-f سلسلة
تحديد البرنامج الثنائي الفرعي المسمى سلسلة
-F binfmt
فرض استخدام هذا المكون الإضافي الثنائي (تجاهل فحص الرأس)
-g
نفس الشيء مثل -SMZIHVResizcld -SS -SSS -ee (عرض جميع المعلومات)
-G عنوان
عنوان التحميل . إزاحة إلى الرأس
-h
عرض رسالة المساعدة
-H
حقول الرأس
-i
استيراد (الرموز المستوردة من المكتبات)
-I
معلومات الملف الثنائي
-j
إخراج بتنسيق JSON
-k استعلام sdb
تشغيل استعلام sdb. على سبيل المثال: '* '
-K خوارزمية
حساب المجموع الاختباري (md5، sha1، ..)
-l
المكتبات المرتبطة
-L ملحق
قائمة المكونات الإضافية الثنائية المدعومة أو تفاصيل المكون الإضافي
-m عنوان
عرض سطر المصدر في العنوان
-M
الدالة الرئيسية (عرض عنوان الدالة الرئيسية)
-n سلسلة
عرض القسم أو الرمز أو الاستيراد المسمى سلسلة
-N min:max
فرض الحد الأدنى/الأقصى لعدد الأحرف لكل سلسلة (انظر -z و -zz)
-o سلسلة
الملف/المجلد الناتج لعمليات الكتابة (الخارج افتراضياً)
-O سلسلة
عمليات الكتابة/الاستخراج (-O help)
-p
عرض العناوين المادية
-P
عرض معلومات التصحيح/pdb
-PP
تنزيل ملف pdb للملف الثنائي
-q
كن هادئًا، اعرض بيانات أقل فقط
-qq
عرض معلومات أقل (لا يوجد إزاحة/حجم لـ -z على سبيل المثال)
-Q
عرض عنوان التحميل المستخدم بواسطة dlopen (مكتبات غير aslr)
-r
عرض الإخراج بتنسيق rizin
-R
عرض عمليات إعادة التوطين
-s
الرموز
-S
الأقسام
-SS
الشرائح
-SSS
الأقسام التي ترتبط بالشرائح
-T
عرض توقيع الملف
-u
غير مصفاة (لا تعيد تسمية الرموز/الأقسام المكررة)
-U
الموارد
-v
عرض معلومات الإصدار
-V
عرض معلومات الإصدار الثنائي
-w
عرض كتل try/catch
-x
استخراج البرامج الثنائية الموجودة في الملف
-X fmt [f] ..
التغليف في fat أو zip الملفات المحددة والبرامج الثنائية الموجودة في الملف
-Y fw file
حساب جميع مرشحات عنوان القاعدة الممكنة لبرنامج firmware الثنائي
-z
عرض السلاسل النصية (من قسم البيانات)
-zz
عرض السلاسل النصية (من السلاسل الخام من الملف الثنائي)
-zzz
تفريغ السلاسل النصية الخام إلى المخرج القياسي (للملفات الكبيرة جدًا)
-Z
تخمين حجم البرنامج الثنائي
