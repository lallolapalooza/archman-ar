radeon - برنامج تشغيل الفيديو ATI/AMD RADEON

الوصف

radeon هو برنامج تشغيل Xorg لبطاقات الفيديو المستندة إلى ATI/AMD RADEON يتميز بالميزات التالية:

•
دعم كامل لأعماق البكسل 8، 15، 16، و 24 بت، وعمق 30 بت على Linux 3.16 وما بعده؛
•
دعم RandR 1.2 و RandR 1.3؛
•
تسريع ثنائي الأبعاد كامل باستخدام EXA؛
•
تسريع الفيديو XVideo المدعوم بالنسيج بما في ذلك دعم منع تمزق الصورة (التصفية التكعيبية متاحة فقط على R/RV3xx، R/RV/RS4xx، R/RV5xx، و RS6xx/RS740)؛
•
تسريع ثلاثي الأبعاد؛

تفاصيل التكوين

يرجى الرجوع إلى xorg.conf(5) للحصول على تفاصيل التكوين العامة. يغطي هذا القسم فقط تفاصيل التكوين الخاصة ببرنامج التشغيل هذا.

خيارات برنامج التشغيل التالية مدعومة:

Option "SWcursor" "قيمة_منطقية"
يحدد مؤشر البرنامج. القيمة الافتراضية هي off.
Option "Accel" "قيمة_منطقية"
تمكين أو تعطيل كل تسريع الأجهزة.
القيمة الافتراضية هي on.
Option "ZaphodHeads" "سلسلة_نصية"
حدد مخرجات RandR لاستخدامها مع وضع zaphod لمثيل برنامج التشغيل هذا. إذا استخدمت هذا الخيار، فيجب عليك استخدام هذا الخيار لجميع مثيلات برنامج التشغيل.
على سبيل المثال: Option "ZaphodHeads" "LVDS,VGA-0" سيقوم بتعيين مخرجات xrandr LVDS و VGA-0 لهذا المثيل من برنامج التشغيل.
Option "ColorTiling" "قيمة_منطقية"
يمكن الوصول إلى إطار المخزن المؤقت إما في وضع خطي أو متجانب. يمكن أن يوفر الوضع المتجانب توفيرًا كبيرًا في استهلاك الطاقة.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

CONFIGURATION DETAILS

The following driver Options are supported:

Option "Tiling" "boolean"
Tiling can improve performance for 3D applications. It will be disabled if the drm module is too old or if the current display configuration does not support it. On R600+ this enables 1D tiling mode.
The default value is on for R/RV3XX, R/RV4XX, R/RV5XX, RS6XX, RS740, R/RV6XX, R/RV7XX, RS780, RS880, EVERGREEN, CAYMAN, ARUBA, Southern Islands, and Sea Islands and off for R/RV/RS1XX, R/RV/RS2XX, RS3XX, and RS690/RS780/RS880 when fast fb feature is enabled.
Option "ColorTiling" "boolean"
The framebuffer can be addressed either in linear or 1D tiled modes. 1D tiling mode can provide significant performance benefits with 3D applications. Tiling will be disabled if the drm module is too old or if the current display configuration does not support it. On R600+ this enables 1D tiling mode.
The default value is on for R/RV3XX, R/RV4XX, R/RV5XX, RS6XX, RS740, R/RV6XX, R/RV7XX, RS780, RS880, EVERGREEN, CAYMAN, ARUBA, Southern Islands, and Sea Islands and off for R/RV/RS1XX, R/RV/RS2XX, RS3XX, and RS690/RS780/RS880 when fast fb feature is enabled.
Option "Tiling2D" "boolean"
The framebuffer can be addressed either in linear, 1D, or 2D tiled modes. 2D tiled mode can provide significant performance benefits over 1D tiling with 3D applications. Tiling will be disabled if the drm module is too old or if the current display configuration does not support it. On R600+ this enables 1D tiling mode.
The default value is on for R/RV3XX, R/RV4XX, R/RV5XX, RS6XX, RS740, R/RV6XX, R/RV7XX, RS780, RS880, EVERGREEN, CAYMAN, ARUBA, Southern Islands, and Sea Islands and off for R/RV/RS1XX, R/RV/RS2XX, RS3XX, and RS690/RS780/RS880 when fast fb feature is enabled.
Option "ColorTiling2D" "boolean"
The framebuffer can be addressed either in linear, 1D, or 2D tiled modes. 2D tiled mode can provide significant performance benefits over 1D tiling with 3D applications. Tiling will be disabled if the drm module is too old or if the current display configuration does not support it. KMS ColorTiling2D is only supported on R600 and newer chips and requires Mesa 9.0 or newer for R6xx-ARUBA, Mesa 9.2 or newer for Southern Islands, and Mesa 10.1 or newer for Sea Islands.
The default value is on for R/RV6XX, R/RV7XX, RS780, RS880, EVERGREEN, CAYMAN, ARUBA, Southern Islands, and Sea Islands.
Option "DRI" "integer"
Define the maximum level of DRI to enable. Valid values are 2 for DRI2 or 3 for DRI3. The default is 3 for DRI3 if the Xorg version is >= 1.18.3 and glamor is enabled, otherwise 2 for DRI2. Note: DRI3 may not work correctly in all cases with EXA, enable at your own risk.
Option "EnablePageFlip" "boolean"
Enable DRI2 page flipping. The default is on. Pageflipping is supported on all radeon hardware.
Option "TearFree" "boolean"
Set the default value of the per-output 'TearFree' property, which controls tearing prevention using the hardware page flipping mechanism. TearFree is on for any CRTC associated with one or more outputs with TearFree on. Two separate scanout buffers need to be allocated for each CRTC with TearFree on. If this option is set, the default value of the property is 'on' or 'off' accordingly. If this option isn't set, the default value of the property is auto, which means that TearFree is on for rotated outputs, outputs with RandR transforms applied and for RandR 1.4 secondary outputs, otherwise off.
Option "AccelMethod" "string"
Chooses between available acceleration architectures. Valid values are EXA (for pre-TAHITI GPUs) and glamor (for R300 or higher). The default is glamor with R600 or newer (with Xorg >= 1.18.3, otherwise with TAHITI or newer), otherwise EXA.

The following driver Options are supported for glamor :

Option "ShadowPrimary" "boolean"
This option enables a so-called "shadow primary" buffer for fast CPU access to pixel data, and separate scanout buffers for each display controller (CRTC). This may improve performance for some 2D workloads, potentially at the expense of other (e.g. 3D, video) workloads. Note in particular that enabling this option currently disables page flipping. The default is off.

The following driver Options are supported for EXA :

Option "EXAVSync" "boolean"
This option attempts to avoid tearing by stalling the engine until the display controller has passed the destination region. It reduces tearing at the cost of performance and has been known to cause instability on some chips. The default is off.
Option "EXAPixmaps" "boolean"
Under KMS, to avoid thrashing pixmaps in/out of VRAM on low memory cards, we use a heuristic based on VRAM amount to determine whether to allow EXA to use VRAM for non-essential pixmaps. This option allows us to override the heuristic. The default is on with > 32MB VRAM, off with < 32MB or when fast fb feature is enabled for RS690/RS780/RS880.
Option "SwapbuffersWait" "boolean"
This option controls the behavior of glXSwapBuffers and glXCopySubBufferMESA calls by GL applications. If enabled, the calls will avoid tearing by making sure the display scanline is outside of the area to be copied before the copy occurs. If disabled, no scanline synchronization is performed, meaning tearing will likely occur. Note that when enabled, this option can adversely affect the framerate of applications that render frames at less than refresh rate.
The default value is on.

خصائص الفيديو المظلل

يدعم برنامج التشغيل سمات X11 Xv التالية للفيديو المظلل. يمكنك استخدام الأداة "xvattr" للاستعلام/تعيين هذه السمات في وقت التشغيل.

XV_VSYNC
يُستخدم XV_VSYNC للتحكم فيما إذا كان المحول المظلل يقوم بمزامنة تحديث الشاشة مع تحديث الشاشة الرأسي للقضاء على التمزق. له قيمتان: 'off'(0) و 'on'(1). القيمة الافتراضية هي 'on'(1).
XV_CRTC
يُستخدم XV_CRTC للتحكم في وحدة التحكم في العرض (crtc) التي يزامنة المحول المظلل تحديث الشاشة معها عند تمكين XV_VSYNC. القيمة الافتراضية، 'auto'(-1)، ستتزامن مع وحدة التحكم في العرض التي يقع عليها معظم الفيديو؛ عندما يكون هذا غامضًا، يتم تفضيل وحدة التحكم في العرض المرتبطة بالمخرج الأساسي لـ RandR. هذه السمة مفيدة لأشياء مثل وضع الاستنساخ حيث يمكن للمستخدم تحديد أفضل عرض يمكن مزامنته. القيمة الافتراضية هي 'auto'(-1).
XV_BICUBIC
يُستخدم XV_BICUBIC للتحكم فيما إذا كان المحول المظلل يجب أن يطبق مرشحًا مكعبًا مزدوجًا لتنعيم الإخراج. له ثلاث قيم: 'off'(0)، 'on'(1)، و 'auto'(2). 'off' تعني عدم تطبيق المرشح أبدًا، 'on' تعني تطبيق المرشح دائمًا، و 'auto' تعني تطبيق المرشح فقط إذا تم قياس أحجام X و Y إلى أكثر من الضعف لتجنب الإخراج الباهت. الترشيح المكعب المزدوج غير متوافق حاليًا مع سمات Xv الأخرى مثل الصبغة والتباين والسطوع، ويجب تعطيله لاستخدام هذه السمات. القيمة الافتراضية هي 'off'(0).
