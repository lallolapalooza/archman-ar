rofi-script(5)

الحزمة: rofi

التراخيص: MIT

rofi-script(5) دليل صيغ الملفات rofi-script(5)

الاسم

وضع rofi-script - صيغة Rofi للوضع القابل للبرمجة.

الوصف

يدعم rofi الأوضاع التي تستخدم نصوصًا برمجية بسيطة في الخلفية لإنشاء قائمة ومعالجة النتيجة من إجراءات المستخدم. يوفر هذا واجهة بسيطة لإنشاء امتدادات بسيطة لـ rofi.

الاستخدام

لتحديد وضع نص برمجي، قم بتعيين وضع بالصيغة التالية: “{الاسم}:{الملف التنفيذي}”

على سبيل المثال:

rofi -show fb -modes "fb:file_browser.sh"

يجب أن يكون الاسم فريدًا.

واجهة برمجة التطبيقات

يقوم Rofi باستدعاء الملف التنفيذي بدون وسائط عند بدء التشغيل. يجب أن يقوم هذا بإنشاء قائمة من الخيارات، مفصولة بسطر جديد (\n) (يمكن تغيير هذا بواسطة النص البرمجي). إذا اختار المستخدم خيارًا، فإن rofi يستدعي الملف التنفيذي مع نص هذا الخيار كوسيط أول. إذا لم يرجع النص البرمجي أي إدخالات، يخرج rofi.

نص برمجي بسيط سيكون:

#!/usr/bin/env bash
if [ x"$@" = x"quit" ]
then
    exit 0
fi
echo "reload"
echo "quit"

هذا يعرض إدخالين، reload و quit. عند اختيار إدخال quit، يغلق rofi.

البيئة

يقوم Rofi بتعيين متغير البيئة التالي عند تنفيذ النص البرمجي:

ROFI_RETV

رقم صحيح يمثل الحالة الحالية:

•
0: استدعاء أولي للنص البرمجي.
•
1: تم اختيار إدخال.
•
2: تم اختيار إدخال مخصص.
•
3: تم حذف إدخال.
•
10-28: ربط مفتاح مخصص 1-19 (يجب تمكينه صراحة بواسطة النص البرمجي).

ROFI_INFO

يتم تعيين البيئة عند تعيين الإدخال المحدد بقيمة الخاصية لـ `info' خيار الصف، إذا تم تعيينه.

ROFI_DATA

يتم تعيين البيئة عند قيام النص البرمجي بتعيين خيار data في الرأس.

تمرير خيارات الوضع

يمكن تعيين خيارات إضافية، مثل تعيين المطالبة، بواسطة النص البرمجي. الخيارات الإضافية هي سطور تبدأ بحرف NULL (\0) متبوعًا بمفتاح، فاصل (\x1f) وقيمة.

على سبيل المثال لتعيين المطالبة:

    echo -en "\0prompt\x1fChange prompt\n"

الخيارات الإضافية التالية موجودة:

•
prompt: تحديث نص المطالبة.
•
message: تحديث نص الرسالة.
•
markup-rows: إذا كانت `true' فإنها تعرض ترميزًا في الصف.
•
urgent: تمييز الصفوف كـ عاجلة. (للنحو انظر خيار urgent في وضع dmenu)
•
active: تمييز الصفوف كـ نشطة. (للنحو انظر خيار active في وضع dmenu)
•
delim: تعيين الفاصل للصفوف التالية. الافتراضي هو `' ويجب أن ينتهي هذا الخيار به. قم باستدعاء هذا فقط في الاستدعاء الأول للنص البرمجي، ويتم تذكره للاستدعاءات المتتالية.
•
no-custom: إذا تم تعيينه إلى `true'؛ قبول الإدخالات المدرجة فقط، وتجاهل الإدخال المخصص.
•
use-hot-keys: إذا تم تعيينه إلى true، فإنه يتيح ربط المفاتيح المخصصة للنص البرمجي. تحذير هذا يكسر تدفق rofi العادي.
•
keep-selection: إذا تم التعيين، لا يتم نقل التحديد إلى الإدخال الأول، ولكن يتم الحفاظ على الموضع الحالي. يتم مسح عامل التصفية.
•
keep-filter: إذا تم التعيين، لا يتم مسح عامل التصفية.
•
new-selection: إذا تم تعيين keep-selection، فهذا يسمح لك بتجاوز الإدخال المحدد (موضع مطلق).
•
data: تمرير البيانات إلى الاستدعاء التالي للنص البرمجي عبر ROFI_DATA.
•
theme: مقتطف ثيم صغير لتغيير لون الخلفية لويدجت على سبيل المثال.

لا يمكن لخاصية theme تغيير الواجهة أثناء التشغيل، وهي قابلة للاستخدام فقط للتغييرات الصغيرة في، على سبيل المثال، لون الخلفية، للويدجتات التي يتم تحديثها أثناء العرض مثل لون صف قائمة العرض.

تحليل خيارات الصف

يمكن تعيين خيارات إضافية للصفوف الفردية. يمكن تحديد الخيار الإضافي باتباع نفس الصيغة مثل خيار الوضع، ولكن باتباع الإدخال.

على سبيل المثال:

    echo -en "aap\0icon\x1ffolder\n"

الخيارات التالية مدعومة:

•
icon: تعيين الأيقونة لهذا الصف.
•
display: استبدال السلسلة المعروضة. (سيظل السلسلة الأصلية مستخدمة للتصفية)
•
meta: تحديد مصطلحات بحث غير مرئية تستخدم للتصفية.
•
nonselectable: إذا كان true فلا يمكن تنشيط الصف.
•
permanent: إذا كان true فإن الصف يظهر دائمًا، بغض النظر عن عامل التصفية.
•
info: معلومات، عند الاختيار، يتم وضعها في متغير البيئة ROFI_INFO. لا يتم البحث عن هذا الإدخال للتصفية.
•
urgent: تعيين علامة عاجلة على الإدخال (true/false)
•
active: تعيين علامة نشطة على الإدخال (true/false)

يمكن تمرير إدخالات متعددة باستخدام الفاصل \x1f.

    echo -en "aap\0icon\x1ffolder\x1finfo\x1ftest\n"

تنفيذ برنامج خارجي

إذا كنت تريد تشغيل برنامج خارجي من النص البرمجي، فأنت بحاجة إلى التأكد من تشغيله في الخلفية. إذا لم يكن الأمر كذلك، فسوف ينتظر rofi مخرجاته (لعرضها).

في bash، أفضل طريقة للقيام بذلك هي استخدام coproc.

 coproc ( myApp  > /dev/null  2>&1 )

شل DASH

إذا كنت تستخدم شل dash للنص البرمجي الخاص بك، فخذ عناية خاصة بكيفية معالجة dash للقيم المحولة للفاصل. انظر القضية #1201 على github.

مواقع النصوص البرمجية

لتحديد نص برمجي، هناك الخيارات التالية:

•
تحديد مسار مطلق للنص البرمجي.
•
النص البرمجي قابل للتنفيذ ويقع في $PATH الخاص بك

النصوص البرمجية الموجودة في الموقع التالي يتم تحميلها عند بدء التشغيل ويمكن تشغيلها مباشرة بناءً على اسم الملف (بدون امتداد):

•
النص البرمجي موجود في $XDG_CONFIG_HOME/rofi/scripts/، وعادة ما يكون ~/.config/rofi/scripts/.

إذا كان لديك نص برمجي `mymode.sh' في هذا المجلد، يمكنك فتحه باستخدام:

rofi -show mymode

انظر ناتج rofi -h للحصول على قائمة بالنصوص البرمجية المكتشفة.

rofi-script(5)

NAME rofi-script - scripting interface for rofi
SYNOPSIS rofi -show [-modi ] [-show-icons]
DESCRIPTION rofi is a window switcher, application launcher and dmenu replacement. This manual page describes the scripting interface for rofi. rofi can be used to show a list of custom entries to the user. These entries can be generated by an external script. To use an external script, you need to tell rofi to use it as a mode. This is done using the -show and -modi flags. Example: rofi -show myapp -modi myapp:/path/to/my/script.sh When rofi is launched like this, it will execute the script and display its output as a list of selectable items. The script is expected to output a list of strings, one per line. Each line represents an entry in the rofi menu. rofi will then wait for the user to select an item. When an item is selected (e.g., by pressing Enter), rofi will print the selected string to standard output and exit. The script can also receive input from rofi. This is useful for implementing interactive modes where rofi sends user input back to the script. This is done by providing input to the script via stdin. For example, if the script needs to perform a search based on user input, rofi can send the search query to the script's stdin. The script can also be configured to display icons next to the entries. This is enabled by the -show-icons flag. If this flag is used, the script should output lines in the following format: ; The icon name is the name of the icon theme icon to be displayed. rofi also supports parsing row options from the script output. This allows for more advanced customization of each row, such as setting background colors, foreground colors, fonts, and widths. The format for parsing row options is as follows: ; ; ; ... Example: "Hello World" ; "background=red" ; "color=#00FF00" The script can also execute external programs based on user selection. When an item is selected, rofi will print the selected string to stdout. The script can then parse this string and execute a corresponding command. Special script modes: - DASH shell: If the script is a shell script (e.g., a bash script), rofi can execute it directly. - Script locations: rofi looks for scripts in the following locations: ~/.config/rofi/scripts/ /usr/local/share/rofi/scripts/ /etc/rofi/scripts/
ENVIRONMENT XDG_CONFIG_HOME XDG_DATA_HOME
