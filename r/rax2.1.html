rax2(1)

NAME

rax2 - hexadecimal and text converter, encoder, decoder and more

SYNOPSIS

rax2 [<options>] [<input> ...]

DESCRIPTION

rax2 is a command-line tool that converts data between hexadecimal and text representations, and performs various encoding and decoding operations.

OPTIONS

-a, --ascii: Convert input to ASCII

-b, --binary: Convert input to binary

-c, --color: Enable color output

-d, --decode: Decode input

-e, --encode: Encode input

-h, --help: Show help message

-H, --hex: Convert input to hexadecimal

-i, --input-endian: Specify input endianness (le, be)

-o, --output-endian: Specify output endianness (le, be)

-r, --radix: Convert input to specified radix (2-64)

-s, --string: Interpret input as a string

-v, --version: Show version information

EXAMPLES

Convert "hello" to hexadecimal:

rax2 -H hello

Convert "68656c6c6f" (hex) to text:

rax2 -d 68656c6c6f

Convert "hello" to Base64:

rax2 -e -r 64 hello

Convert "aGVsbG8=" (Base64) to text:

rax2 -d -r 64 aGVsbG8=
