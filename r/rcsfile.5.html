rcsfile - format of the RCS file

NAME

rcsfile - format of the RCS file

DESCRIPTION

RCS (Revision Control System) files store the revision history of a given file. Each file in RCS is identified by a name ending in ',v'. A file named 'file' in the working directory, if it is under RCS control, will have its RCS version stored in 'file,v' in the same directory or in a subdirectory named 'RCS'.

An RCS file consists of a header and a series of deltas. The header contains metadata about the file, such as its name, owner, locker, expand keyword options, and the number of branches. The deltas represent the changes made to the file over time. Each delta contains information about the revision number, author, date, the difference (diff) between this revision and the previous one, and the log message associated with the change.

The format is text-based and human-readable, although it is not intended for direct editing. RCS commands are used to interact with and modify these files.

IDENTIFICATION

The RCS file format is described by the rcsfile(5) manual page.
