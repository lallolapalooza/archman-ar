res_ninit(3)

NAME

res_ninit, res_nquery, res_nmkquery, res_nsend, res_nclose - Resolver routines for non-specific queries

LIBRARY

Name Service Switch library (libnss, -lnss)

SYNOPSIS

#include <resolv.h>

int res_ninit(res_state statp);

int res_nquery(res_state statp, const char *dname, int class, int type, unsigned char *buf, int len);

int res_nmkquery(res_state statp, const char *dname, int class, int type, const unsigned char *ப்புகளை, int pnamelen, const unsigned char *targets, unsigned char *buf, int len);

int res_nsend(res_state statp, const unsigned char *msg, int len, unsigned char *answer, int anslen);

void res_nclose(res_state statp);

DESCRIPTION

The resolver routines provide an interface to the Domain Name System (DNS). They are used to translate host names to Internet addresses and vice versa.

The functions described in this page are thread-safe versions of the traditional resolver functions. They operate on a res_state structure, pointed to by statp, which holds the resolver's state. For thread-unsafe compatibility, see resolver(3).

res_ninit(3) initializes the resolver state structure pointed to by statp. It reads the system configuration files (e.g., /etc/resolv.conf) to determine the local domain name, the Internet addresses of the name servers, and other options. The res_state structure must be initialized before calling any other resolver functions.

res_nquery(3) performs a query for the specified domain name dname, in the given class and type. The query is sent to the name servers specified in statp. The reply is placed in the buffer buf with a maximum size of len bytes. The size of the reply is returned. This function is a wrapper around res_nmkquery(3) and res_nsend(3).

res_nmkquery(3) constructs a query message. It takes the domain name dname, class, and type to query for, optional additional information specified by ப்புகளை (length pnamelen) and targets, and places the resulting query message into the buffer buf with a maximum size of len bytes. The actual size of the query message is returned. If ப்புகளை or targets are NULL, the corresponding parameters are omitted.

res_nsend(3) sends the query message msg (of length len) to the name servers specified in statp, and receives the reply in the buffer answer (with a maximum size of anslen bytes). The actual size of the reply is returned. If the query times out, it is retransmitted up to statp->retry times. If it still fails, a different name server is tried. This function handles UDP and TCP transport.

res_nclose(3) frees any resources allocated by res_ninit(3) for the given res_state structure.

RETURN VALUE

On success, res_ninit(3) returns 0. On failure, it returns -1 and sets errno.

On success, res_nquery(3), res_nmkquery(3), and res_nsend(3) return the size of the reply. On failure, they return -1 and set errno.

res_nclose(3) does not return a value.

FILES

/etc/resolv.conf
Resolver configuration file.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

Interface Attribute Value
res_ninit, res_nquery, res_nmkquery, res_nsend, res_nclose Thread safety Yes

STANDARDS

These functions conform to RFC 1123 and RFC 2535. The POSIX standard specifies resolver functions in POSIX.1-2001 and later, but does not mandate the thread-safe variants.

HISTORY

The resolver routines first appeared in BIND 4.8.3.
