rtmon(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

RTMON(8) دليل مدير النظام RTMON(8)

الاسم

rtmon - يستمع إلى RTnetlink ويراقبه

الملخص


rtmon [ خيارات ] ملف ملف [ الكل | الكائنات ]

خيارات := { f[amily] { inet | inet6 | link | مساعدة } | -4 | -6 | -0 | -V[ersion] }

كائنات := [ link ] [ address ] [ route ]

الوصف

توثق صفحة الدليل هذه باختصار الأمر rtmon.

rtmon يستمع إلى مقبس netlink ويراقب تغييرات جدول التوجيه.

يمكن تشغيل rtmon قبل إصدار أمر تهيئة الشبكة الأول. على سبيل المثال، إذا قمت بإدخال:

rtmon file /var/log/rtmon.log

في برنامج بدء التشغيل، ستتمكن من عرض السجل الكامل لاحقًا. بالتأكيد، من الممكن بدء تشغيل rtmon في أي وقت. إنه يضيف إلى السجل لقطة للحالة تم تفريغها في لحظة البدء.

الخيارات

يدعم rtmon الخيارات التالية:

-Version
طباعة الإصدار والخروج.
مساعدة
عرض ملخص الخيارات.
ملف FILE [ الكل | الكائنات ]
تسجيل الإخراج إلى الملف. الكائنات هي قائمة بأنواع الكائنات التي نريد مراقبتها. قد تحتوي على 'link'، 'address'، 'route' و 'all'. 'link' تحدد جهاز الشبكة، 'address' البروتوكول (IP أو IPv6) على جهاز، 'route' إدخال جدول التوجيه، و 'all' تفعل ما يقوله الاسم.
-family [ inet | inet6 | link | مساعدة ]
تحديد عائلة البروتوكول. 'inet' هو IPv4، 'inet6' هو IPv6، 'link' يعني أنه لا يتم إشراك بروتوكول شبكة، و 'help' يطبع معلومات الاستخدام.
-4
استخدام IPv4. اختصار لـ -family inet.
-6
استخدام IPv6. اختصار لـ -family inet6.
-0
استخدام معرف عائلة خاص يعني عدم إشراك بروتوكول شبكة. اختصار لـ -family link.

أمثلة الاستخدام

# rtmon file /var/log/rtmon.log
تسجيل الإخراج إلى الملف /var/log/rtmon.log، ثم تشغيل:
# ip monitor file /var/log/rtmon.log
لعرض الإخراج المسجل من الملف.
