RADARE2(1) دليل الأوامر العامة RADARE2(1)

الاسم

radare2 — محرر سداسي عشري متقدم سطر الأوامر، ومفكك تجميع، ومصحح أخطاء

الملخص

radare2 [-a arch] [-b bits] [-B baddr] [-c cmd] [-e k=v] [-i file] [-I prefile] [-k kernel] [-m addr] [-p project] [-P patch] [-r rarun2] [-R rr2rule] [-s addr] [-012AdDjwntLquvVxX] -|--|=|file

الوصف

radare2 هو محرر سداسي عشري سطر الأوامر.

"r2" هو اسم البرنامج البديل لـ radare2.

صفحة الدليل هذه لم يتم تحديثها بعد. لا تتردد في المساهمة.

الخيارات هي:

--
فتح radare2 على ملف فارغ
-
يعادل 'r2 malloc://512'
-0
طباعة \x00 بعد التهيئة وبعد كل أمر يتم تنفيذه
-1
إعادة توجيه stderr إلى stdout
-2
إغلاق stderr قبل بدء RCore
-a arch
فرض asm.arch (x86، ppc، arm، mips، bf، java، ...)
-A
تشغيل الأمر 'aaa' قبل الموجه أو التصحيح لتحليل كل الكود المشار إليه. استخدم -AA لتشغيل aaaa
-b bits
فرض asm.bits (16، 32، 64)
-B baddr
تحديد عنوان الأساس المراد استخدامه عند تحميل ملف ثنائي جديد. انظر 'e?bin.baddr'
-c cmd
تنفيذ الأمر المحدد قبل تقديم الموجه
-d
البدء في وضع المصحح
-D dbg.backend
تمكين وضع التصحيح. ضبط cfg.debug=true
-e k=v
تعيين متغير تقييم الإعداد k=v. على سبيل المثال -e scr.color=false. عند تمرير -e بعد -j، سيتم تعيين مصدر النص البرمجي للتشغيل بدلاً من تعيين متغيرات التقييم.
-f
حجم الكتلة = حجم الملف
-j
تشغيل نص QJS البرمجي إذا تم تمرير وسيطة أو الدخول إلى shell qjs إذا لم يتم تحديد ملف. يمكنك تقييم التعبيرات عند تمرير العلامة -e بعد -j.
-i file
تشغيل ملف النص البرمجي. بعد تحميل الملف
-I file
تشغيل ملف النص البرمجي. قبل تحميل الملف
-k kernel
اختيار النواة (asm.os) لحل استدعاءات النظام
-l plugfile
تحميل ملف المكون الإضافي المحدد
-L
عرض المكونات الإضافية للإدخال/الإخراج المحملة.
-LL
عرض المكونات الإضافية الأساسية المحملة.
-m addr
تعيين الملف في العنوان المحدد
-M
تعطيل فك التشفير
-n
عدم إجراء أي تحليل (r_bin). تحميل الملف الخام فقط
-nn
تحميل هياكل rbin فقط (elf، mach0، ...)
-N
عدم تحميل إعدادات المستخدم/المشاريع من ~/.radare2rc، ~/.config/radare2/radare2rc والنصوص البرمجية داخل دليل .../radare2rc.d/.
-NN
نفس -N ولكنها تعطل أيضًا التحميل التلقائي للمكونات الإضافية عند بدء التشغيل
-q
وضع هادئ (بدون موجه) والخروج بعد تشغيل الأوامر المحددة بـ -i أو -c
-qq
الخروج قبل عرض الموجه. مباشرة بعد تقييم جميع الوسائط -e و -c و -i.
-Q
نفس q، ولكن الخروج دون تحرير RCore، ينتج عن هذا تسربات عند الخروج، ولكن يوفر بعض المللي ثانية القيمة لتشغيل مجموعة الاختبارات في وضع سريع.
-p prj
تعيين ملف المشروع
-P file
تطبيق ملف rapatch والخروج (انظر doc/rapatch.md لمزيد من التفاصيل)
-r rarun2
تحديد ملف تعريف rarun2 لـ dbg.profile للاستخدام عند إنشاء برنامج للتصحيح
-R rarun2-directive
تحديد توجيهات rarun2 مخصصة دون الحاجة إلى إنشاء ملف تعريف rarun2
-s addr
البدء في البحث في هذا العنوان
-S
تمكين الوضع المحمي (نفس -e cfg.sandbox=true)
-t
الحصول على معلومات الملف الثنائي وتحليل الملف الثنائي في مؤشر ترابط خلفي
-T
تجنب حساب تجزئات الملف
-u
تعيين bin.filter=false لتحميل معلومات rbin دون تصفية الأسماء
-v
عرض معلومات الإصدار والخروج (استخدم -qv للحصول على رقم الإصدار فقط)
-V
عرض إصدارات مكتبة radare2 (تطبع بتنسيق JSON إذا تم استخدام -j)
-w
فتح في وضع الكتابة
-h
عرض رسالة المساعدة
-H
عرض المساعدة للملفات والبيئة
-x
فتح خريطة الملف بدون أذونات تنفيذ
-X
نفس -e bin.usextr=false، لا تستخدم مكونات استخراج إضافية، مفيدة لـ dyldcache

الصدفة

اكتب '؟' للمساعدة

مرئي

للدخول إلى الوضع المرئي استخدم الأمر 'V'. ثم اضغط '؟' للمساعدة

مصحح الأخطاء

في r2، يتم تنفيذ أوامر المصحح تحت الأمر 'd'. اكتب 'd؟' للمساعدة

البيئة


R2_ARGS تشغيل radare2 مع وسيطات محددة في البيئة وتجاهل وسيطات سطر الأوامر
R2_IGNVER تحميل الإضافات مع تجاهل الإصدار المحدد. (كن حذرًا)
R2_DEBUG إذا تم تعريفه، عرض رسائل الخطأ وإشارة الانهيار
R2_DEBUG=1 تعيين نقطة توقف عند الوصول إلى تأكيد
R2_MAGICPATH /Users/pancake/.local/share/radare2/share/radare2/4.5.0-git/magic
R2_NOPLUGINS عدم تحميل إضافات r2 المشتركة
R2_RCFILE ~/.radare2rc (تفضيلات المستخدم، نص برمجي دفعي)
R2_RDATAHOME /usr/local FILE المسار إلى الملف الحالي قيد العمل.
