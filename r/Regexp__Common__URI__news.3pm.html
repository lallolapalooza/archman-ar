Regexp__Common__URI__news(3pm)

الحزمة: perl-regexp-common

التراخيص: PerlArtistic, Artistic2.0, BSD, MIT

Regexp::Common::URI::news(3) وثائق Perl المساهمة من المستخدم Regexp::Common::URI::news(3)

الاسم

Regexp::Common::URI::news -- تُرجع نمطًا لـ URIs للملفات.

الملخص

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{news}/       and  print "Contains a news URI.\n";
}

الوصف

$RE{URI}{news}

تُرجع نمطًا يطابق URIs news، كما هو محدد في RFC 1738. URIs الأخبار لها الشكل:

"news:" ( "*" | group | article "@" host )

ضمن "{-keep}"، يتم إرجاع ما يلي:

$1
الـ URI الكامل.
$2
المخطط.
$3
الجزء من الـ URI الذي يلي "news://".

$RE{URI}{NNTP}

تُرجع نمطًا يطابق URIs NNTP، كما هو محدد في RFC 1738. URIs NNTP لها الشكل:

"nntp://" host [ ":" port ] "/" group [ "/" digits ]

ضمن "{-keep}"، يتم إرجاع ما يلي:

$1
الـ URI الكامل.
$2
المخطط.
$3
الجزء من الـ URI الذي يلي "nntp://".
$4
المضيف والمنفذ، مفصولان بنقطتين. إذا لم يتم تحديد منفذ، فالمضيف فقط.
$5
المضيف.
$6
المنفذ، إذا تم تحديده.
$7
المجموعة.
$8
الأرقام، إذا تم تحديدها.

المراجع

[RFC 1738]
Berners-Lee, Tim, Masinter, L., McCahill, M.: Uniform Resource Locators (URL). December 1994.

انظر أيضًا

Regexp::Common::URI لـ URIs أخرى مدعومة.
