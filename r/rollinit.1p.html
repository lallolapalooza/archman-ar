rollinit(1p)

الحزمة: dnssec-tools

التراخيص: BSD

NAME

rollinit

initialize rollrec file

SYNOPSIS

rollinit [-h] [-v] [-f file] [-z] [-g zonegroup] [zone ...]

DESCRIPTION

The rollinit utility creates a rollrec.pm(5) file for the named zone or zones.

The zone is described by its zone name and by the value of the zonefile and keyrec parameters. If the zone is to be signed, the zonefile should be the name of the signed zonefile (e.g. example.com.signed). If the zone is not to be signed, it should be the name of the zonefile (e.g. example.com).

The keyrec parameter is the name of the key record file for the zone. This file is used by the DNSSEC tools to determine the zone's keys.

A zonegroup is a way to group related zones. The zonegroup parameter specifies the zonegroup to which the zone belongs.

The program will create the rollrec file and append it to the current rollrec file if it exists, or create a new one.

If the -f file option is given, the output will be written to file instead of the default rollrec file.

If the -z option is given, the zone is assumed to be signed, and the zonefile will be created with the suffix .signed.

The -g zonegroup option is used to specify the zonegroup for the zone(s).

If the -v option is given, rollinit will print verbose output.

The -h option will print a help message and exit.

If no zones are specified on the command line, rollinit will read zone names from standard input.

INFO ROLLRECS

A rollrec file is a text file that contains information about the zones that are to be rolled over.

Each entry in the rollrec file describes a single zone and contains the following fields:

  • roll: The name of the zone.
  • zonename: The name of the zone.
  • zonefile: The name of the zonefile.
  • keyrec: The name of the key record file.
  • zonegroup: The name of the zonegroup.

ZONEFILE and KEYREC FIELDS

The zonefile field is the name of the zone file. If the -z option is given, the zone file will be assumed to be signed and the file name will have .signed appended to it.

The keyrec field is the name of the key record file. This file contains the keys for the zone.

OPTIONS

-f file
Specify the output file to write the rollrec information to. Defaults to rollrec.
-g zonegroup
Specify the zonegroup for the zone(s).
-h
Print a help message and exit.
-v
Print verbose output.
-z
Assume the zone is signed. The zonefile will be created with the suffix .signed.

EXAMPLES

Example 14. Two zones, One zonegroup

This example shows the rollrec generated by giving rollinit a set of two zones and a single zonegroup.

$ rollinit -zg "example zones" example1.com example2.com
    roll    "example1.com"
        zonename        "example1.com"
        zonefile        "example1.com.signed"
        keyrec          "example1.com.krf"
        zonegroup       "example zones"
    roll    "example2.com"
        zonename        "example2.com"
        zonefile        "example2.com.signed"
        keyrec          "example2.com.krf"
        zonegroup       "example zones"

Example 15. One zone, Two zonegroups

This example shows the rollrec generated by giving rollinit a set of two zonegroups for a single zone.

$ rollinit -zg "customers, paid up" example.com
    roll    "example1.com"
        zonename        "example.com"
        zonefile        "example.com.signed"
        keyrec          "example.com.krf"
        zonegroup       "customers, paid up"
