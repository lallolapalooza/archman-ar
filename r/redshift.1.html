REDSHIFT(1) دليل الأوامر العامة REDSHIFT(1)

الاسم

redshift - ضبط درجة حرارة لون الشاشة وفقًا لوقت اليوم

الملخص

redshift [-l LAT:LON | -l PROVIDER:OPTIONS] [-t DAY:NIGHT] [OPTIONS...]

الوصف

يقوم redshift بضبط درجة حرارة لون شاشتك وفقًا لمحيطك. قد يساعد ذلك في تقليل إجهاد عينيك أو تقليل خطر الإصابة بمتلازمة اضطراب طور النوم المتأخر إذا كنت تعمل أمام الشاشة ليلاً.

يتم ضبط درجة حرارة اللون وفقًا لموقع الشمس. يتم ضبط درجة حرارة لون مختلفة خلال الليل والنهار. خلال الشفق والصباح الباكر، تنتقل درجة حرارة اللون بسلاسة من درجة حرارة الليل إلى درجة حرارة النهار للسماح لعينيك بالتكيف ببطء على مدار ساعة تقريبًا. في الليل، يجب ضبط درجة حرارة اللون لتتناسب مع المصابيح في غرفتك. عادة ما تكون درجة حرارة منخفضة حوالي 3000 كلفن - 4000 كلفن (الافتراضي هو 4500 كلفن). خلال النهار، يجب أن تتناسب درجة حرارة اللون مع الضوء من الخارج، وعادة ما تكون حوالي 5500 كلفن - 6500 كلفن (الافتراضي هو 6500 كلفن). الضوء له درجة حرارة أعلى في يوم غائم.

بالإضافة إلى أداة سطر الأوامر redshift، يوفر الواجهة الرسومية redshift-gtk واجهة بديلة تظهر كرمز إشعار في بيئة سطح المكتب.

خيارات

-h
عرض رسالة المساعدة.
-v
تمكين الإخراج المطول.
-V
عرض إصدار البرنامج.
-b DAY:NIGHT
سطوع الشاشة المطلوب تطبيقه (بين 0.1 و 1.0).
-c FILE
تحميل الإعدادات من ملف الإعدادات المحدد.
-g R:G:B
تصحيح جاما إضافي للتطبيق.
-l LAT:LON
موقعك الحالي، بالدرجات، معطى كأرقام عشرية، باتجاه الشمال والشرق، مع أرقام سالبة تمثل الجنوب والغرب، على التوالي.
-l PROVIDER[:OPTIONS]
تحديد المزود لتحديثات الموقع التلقائي (استخدم "-l list" لرؤية المزودين المتاحين).
-m METHOD[:OPTIONS]
الطريقة المستخدمة لضبط درجة حرارة اللون (استخدم "-m list" لرؤية الطرق المتاحة).
-o
وضع التشغيل مرة واحدة (لا تضبط درجة حرارة اللون باستمرار). استخدم هذا مع خيار -P لمسح منحنيات جاما الموجودة قبل تطبيق درجة حرارة اللون الجديدة.
-O TEMP
وضع التشغيل اليدوي لمرة واحدة (ضبط درجة حرارة اللون). استخدم هذا مع خيار -P لمسح منحنيات جاما الموجودة قبل تطبيق تأثير اللون الجديد.
-p
وضع الطباعة (فقط اطبع المعلمات واخرج).
-P
إعادة تعيين منحنيات جاما الحالية قبل تطبيق تأثير اللون الجديد.
-x
وضع إعادة التعيين (إزالة التعديل من الشاشة).
-r
تعطيل التلاشي بين درجات حرارة اللون.
-t DAY:NIGHT
درجة حرارة اللون المراد ضبطها في النهار/الليل.

درجة الحرارة المحايدة هي 6500 كلفن. استخدام هذه القيمة لن يغير درجة حرارة لون الشاشة. ضبط درجة حرارة اللون إلى قيمة أعلى من ذلك يؤدي إلى مزيد من الضوء الأزرق، وضبط قيمة أقل يؤدي إلى مزيد من الضوء الأحمر.

قيم درجة الحرارة الافتراضية:

النهار: 6500 كلفن، الليل: 4500 كلفن

ملف الإعدادات

يمكن وضع ملف إعدادات باسم redshift.conf اختياريًا في ~/.config/. يحتوي الملف على تنسيق INI قياسي. توضع خيارات البرنامج العامة تحت قسم redshift، بينما توضع خيارات مزودي الموقع وطرق التعديل تحت قسم يحمل اسم مزود الموقع أو طريقة التعديل. الخيارات العامة هي:

temp-day = integer
درجة حرارة النهار
temp-night = integer
درجة حرارة الليل
fade = 0 or 1
تعطيل أو تمكين التلاشي بين درجات حرارة اللون عند بدء Redshift أو إيقافه
brightness-day = 0.1-1.0
سطوع الشاشة في النهار
brightness-night = 0.1-1.0
سطوع الشاشة في الليل
elevation-high = decimal
ارتفاع الشمس بالدرجات للانتقال إلى النهار
elevation-low = decimal
ارتفاع الشمس بالدرجات للانتقال إلى الليل
dawn-time = HH:MM[-HH:MM]
الفترة الزمنية المخصصة للانتقال من الليل إلى النهار في الصباح. عند تحديده، لن يتم استخدام ارتفاع الشمس لتحديد فترة النهار/الليل الحالية. إذا تم تعيين هذا الخيار، فيجب أيضًا تحديد وقت الغروب.
dusk-time = HH:MM[-HH:MM]
الفترة الزمنية المخصصة للانتقال من النهار إلى الليل في المساء. عند تحديده، لن يتم استخدام ارتفاع الشمس لتحديد فترة النهار/الليل الحالية. إذا تم تعيين هذا الخيار، فيجب أيضًا تحديد وقت الفجر.
gamma = R:G:B
تعديل جاما المطلوب تطبيقه (النهار والليل)
gamma-day = R:G:B
تعديل جاما المطلوب تطبيقه في النهار
gamma-night = R:G:B
تعديل جاما المطلوب تطبيقه في الليل
adjustment-method = name
تحديد طريقة التعديل. يمكن إعطاء خيارات لطريقة التعديل تحت قسم ملف الإعدادات بنفس الاسم.
location-provider = name
تحديد مزود الموقع. يمكن إعطاء خيارات لمزود الموقع تحت قسم ملف الإعدادات بنفس الاسم.

يمكن العثور على خيارات مزودي الموقع وطرق التعديل في إخراج المساعدة للمزودين والطرق.

مثال

مثال لكوبنهاجن، الدنمارك:

$ redshift -l 55.7:12.6 -t 5700:3600 -g 0.8 -m randr -v

مثال لملف إعدادات بنفس تأثير أمر سطر الأوامر أعلاه:

[redshift]
temp-day=5700
temp-night=3600
gamma=0.8
adjustment-method=randr
location-provider=manual
[manual]
lat=55.7
lon=12.6

خطافات

سيتم تشغيل الملفات التنفيذية (مثل البرامج النصية) الموضوعة في المجلد ~/.config/redshift/hooks عند حدوث حدث معين. المعامل الأول للبرنامج النصي يشير إلى الحدث، وقد تشير المعاملات الإضافية إلى مزيد من التفاصيل حول الحدث. الحدث period-changed يتم الإشارة إليه عند تغير الفترة (night، daytime، transition). المعامل الثاني هو الفترة القديمة والثالث هو الفترة الجديدة. يتم أيضًا إشارة الحدث

HOOKS

When redshift detects a change in the period, it will execute the script specified in hook-script option. The script is executed with the following arguments:

$1
The event that triggered the script. Possible values are period-changed, start, and stop.
$2
The previous period. This is set to none when redshift starts up with the old period set to none. Any dotfiles in the folder are skipped.
$3
The current period.

A simple script to handle these events can be written like this:

#!/bin/sh
case $1 in
    period-changed)
        exec notify-send "Redshift" "Period changed to $3"
esac
