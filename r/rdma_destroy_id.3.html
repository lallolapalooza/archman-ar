RDMA_DESTROY_ID(3) دليل مبرمج Librdmacm RDMA_DESTROY_ID(3)

الاسم

rdma_destroy_id - تحرير معرف الاتصال.

الملخص

#include <rdma/rdma_cma.h>

int rdma_destroy_id (struct rdma_cm_id *id);

المعاملات

id
معرف الاتصال المراد تدميره.

الوصف

يقوم بتدمير rdma_cm_id المحدد وإلغاء أي عملية غير متزامنة معلقة.

قيمة الإرجاع

يعيد 0 عند النجاح، أو -1 عند حدوث خطأ. إذا حدث خطأ، فسيتم تعيين errno لتحديد سبب الفشل.

ملاحظات

يجب على المستخدمين تحرير أي QP مرتبط بـ rdma_cm_id قبل استدعاء هذه الروتين وإقرار جميع الأحداث ذات الصلة.

انظر أيضاً

rdma_create_id(3)، rdma_destroy_qp(3)، rdma_ack_cm_event(3)
