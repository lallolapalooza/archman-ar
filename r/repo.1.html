repo(1)

الحزمة: repo

التراخيص: Apache-2.0

REPO(1) دليل Repo REPO(1)

الاسم

repo - أداة إدارة مستودعات مبنية فوق git

الملخص

repo [-p|--paginate|--no-pager] COMMAND [ARGS]

خيارات

-h, --help
عرض رسالة المساعدة هذه والخروج
--help-all
عرض رسالة المساعدة هذه مع جميع الأوامر الفرعية والخروج
-p, --paginate
عرض مخرجات الأمر في المستعرض
--no-pager
تعطيل المستعرض
--color=COLOR
التحكم في استخدام الألوان: auto, always, never (تلقائي، دائمًا، أبدًا)
--trace
تتبع تنفيذ أوامر git (REPO_TRACE=1)
--trace-to-stderr
تذهب مخرجات التتبع إلى stderr بالإضافة إلى TRACE_FILE في .repo/
--trace-python
تتبع تنفيذ أوامر بايثون
--time
قياس وقت تنفيذ أوامر repo
--version
عرض هذا الإصدار من repo
--show-toplevel
عرض مسار الدليل العلوي لنسخة عميل repo
--event-log=EVENT_LOG
اسم ملف سجل الأحداث لإلحاق الجدول الزمني به
--git-trace2-event-log=GIT_TRACE2_EVENT_LOG
الدليل لكتابة سجل أحداث git trace2 إليه
--submanifest-path=REL_PATH
مسار المستند الفرعي

القائمة الكاملة للأوامر المعترف بها في repo هي:

abandon
التخلي عن فرع تطوير بشكل دائم
branch
عرض فروع الموضوع الحالية
branches
عرض فروع الموضوع الحالية
checkout
نسخ فرع للتطوير
cherry-pick
انتقاء تغيير بشكل انتقائي.
diff
عرض التغييرات بين الالتزام وشجرة العمل
diffmanifests
أداة مقارنة المستندات
download
تنزيل ونسخ تغيير
forall
تشغيل أمر shell في كل مشروع
gc
تنظيف الحالة الداخلية لـ repo و Git.
grep
طباعة الأسطر التي تطابق نمطًا
help
عرض مساعدة مفصلة حول أمر
info
الحصول على معلومات حول فرع المستند، الفرع الحالي أو الفروع غير المدمجة
init
تهيئة نسخة عميل repo في الدليل الحالي
list
قائمة المشاريع والمجلدات المرتبطة بها
manifest
أداة فحص المستند
overview
عرض نظرة عامة على فروع المشاريع غير المدمجة
prune
تقليم (حذف) المواضيع التي تم دمجها بالفعل
rebase
إعادة قاعدة الفروع المحلية على فرع علوي
selfupdate
تحديث repo إلى أحدث إصدار
smartsync
تحديث شجرة العمل إلى آخر مراجعة معروفة وجيدة
stage
إعداد الملفات للالتزام
start
بدء فرع جديد للتطوير
status
عرض حالة شجرة العمل
sync
تحديث شجرة العمل إلى أحدث مراجعة
upload
تحميل التغييرات لمراجعة الكود
version
عرض إصدار repo

انظر 'repo help <command>' لمزيد من المعلومات حول أمر معين. تقارير الأخطاء: https://issues.gerritcodereview.com/issues/new?component=1370071
