RTCRayN.4embree4

الحزمة: embree

التراخيص: Apache

RTCRayN(3) أنوية تتبع الأشعة Embree 4 RTCRayN(3)

الاسم

RTCRayN - حزمة أشعة بحجم وقت التشغيل

الملخص

#include <embree4/rtcore_ray.h>
struct RTCRayN;
float& RTCRayN_org_x(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_org_y(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_org_z(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_tnear(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_x(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_y(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_dir_z(RTCRayN* ray, unsigned int N, unsigned int i);
float& RTCRayN_time (RTCRayN* ray, unsigned int N, unsigned int i);
float&        RTCRayN_tfar (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_mask (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_id   (RTCRayN* ray, unsigned int N, unsigned int i);
unsigned int& RTCRayN_flags(RTCRayN* ray, unsigned int N, unsigned int i);

الوصف

عندما لا يكون حجم حزمة الأشعة معروفًا وقت الترجمة (على سبيل المثال، عندما تُرجع Embree حزمة أشعة في دالة رد الاتصال RTCFilterFuncN)، تستخدم Embree النوع RTCRayN لحزم الأشعة. يمكن أن يكون لهذه الحزم حجم 1 أو 4 أو 8 أو 16 فقط. لن يتم استخدام أي حجم حزمة آخر.

يمكنك إما تنفيذ مسارات تعليمات برمجية منفصلة لكل من أحجام الحزم الممكنة هذه وتحويل الحزمة إلى نوع حزمة الأشعة المناسب، أو تنفيذ مسار تعليمات برمجية عام واحد يستخدم وظائف المساعدة RTCRayN_XXX للوصول إلى مكونات حزمة الأشعة.

تحصل دوال المساعدة هذه على مؤشر إلى حزمة الأشعة (وسيط ray)، حجم الحزمة (وسيط N)، وتعيد مرجعًا إلى مكون (على سبيل المثال، المكون x للمنشأ) للشعاع i في الحزمة (وسيط i).
