Regexp::Common::URI::pop(3) وثائق مساهمة من مستخدمي Perl Regexp::Common::URI::pop(3)

الاسم

Regexp::Common::URI::pop -- يعيد نمطًا لـ POP URIs.

الملخص

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{POP}/       and  print "يحتوي على POP URI.\n";
}

الوصف

$RE{URI}{POP}

يعيد نمطًا يطابق POP URIs، كما هو محدد في RFC 2384. POP URIs لها الشكل:

"pop:" "//" [ user [ ";AUTH" ( "*" | auth_type ) ] "@" ]
              host [ ":" port ]

ضمن "{-keep}"، يتم إرجاع ما يلي:

$1
URI كامل.
$2
المخطط (scheme).
$3
المستخدم (user)، إذا تم تقديمه.
$4
نوع المصادقة (authentication type)، إذا تم تقديمه (يمكن أن يكون *).
$5
المضيف (host).
$6
المنفذ (port)، إذا تم تقديمه.

المراجع

[RFC 2384]
Gellens, R.: POP URL Scheme. August 1998.

انظر أيضًا

Regexp::Common::URI لـ URIs أخرى مدعومة.
