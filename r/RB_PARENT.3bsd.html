الاسم

ملاحظات

محاولة تحرير شجرة بالطريقة التالية خطأ شائع:

SPLAY_FOREACH(var, NAME, &head) {
	SPLAY_REMOVE(NAME, &head, var);
	free(var);
}

نظرًا لتحرير `var`، فإن الماكرو FOREACH() يشير إلى مؤشر ربما تم إعادة تخصيصه. يتطلب الكود الصحيح متغيرًا إضافيًا.

for (var = SPLAY_MIN(NAME, &head); var != NULL; var = nxt) {
	nxt = SPLAY_NEXT(NAME, &head, var);
	SPLAY_REMOVE(NAME, &head, var);
	free(var);
}
