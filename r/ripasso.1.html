التراخيص: GPL3

RIPASSO-CURSIVE(1) دليل الأوامر العامة RIPASSO-CURSIVE(1)

الاسم

ripasso-cursive - مدير كلمات مرور يستخدم تنسيق ملف مدير كلمات المرور القياسي في يونكس 'pass'، مطبق بلغة rust.

الملخص

ripasso-cursive [علامات]

الوصف

ripasso-cursive هو تطبيق curses يسمح لك بإدارة كلمات المرور الخاصة بك أو بفرقك. يتم تشفير كلمات المرور باستخدام pgp ويتم تخزينها اختياريًا في مستودع git. يتم تخزين قائمة أعضاء الفريق في الملف .gpg-id، مفتاح pgp واحد لكل سطر.

العلامات

اختصارات لوحة المفاتيح

Enter : نسخ كلمة المرور المحددة حاليًا إلى مخزن النسخ لمدة 40 ثانية

Delete : حذف كلمة المرور المميزة

Insert : إنشاء إدخال كلمة مرور جديد

Control + y : نفس وظيفة Enter

Control + b : إذا كانت كلمة المرور تحتوي على عنوان url بتنسيق otpauth://، فقم بإنشاء رمز وتخزينه في مخزن النسخ

Control + n : نقل المؤشر لأسفل

Control + p : نقل المؤشر لأعلى

Control + r : إعادة تسمية كلمة المرور دون تغيير محتواها

Control + u : نسخ اسم ملف كلمة المرور

Control + h : عرض سجل git لكلمة المرور

Control + v : عرض قائمة أعضاء الفريق

Control + o : فتح مربع حوار تحرير كلمة المرور

Control + f : سحب من مستودع git

Control + g : دفع إلى مستودع git

Escape : خروج

ملاحظة الاستخدام

يقرأ ripasso-cursive $HOME/.password-store/ افتراضيًا، يمكنك تجاوز ذلك عن طريق تعيين متغير البيئة PASSWORD_STORE_DIR.

إذا قمت بتحديد متغير البيئة PASSWORD_STORE_SIGNING_KEY، فسيقوم ripasso بالتحقق من أن ملف .gpg-id تم توقيعه بشكل صحيح. القيم الصالحة هي بصمات مفاتيح pgp واحدة أو أكثر بطول 40 حرفًا، مفصولة بفواصل.

ملف التكوين

يقرأ ripasso التكوين من $XDG_CONFIG_HOME/ripasso/settings.toml

مثال لملف التكوين

[stores]


[stores.default]


path = "/home/user/.password-store/"


valid_signing_keys = "AF77DAC5B3882EAD316B7312D5B659E1D2FDF0C3"


[stores.work]


path = "/home/user/.work_pass/"


style_path = "/home/user/.config/ripasso/work-style.toml"

الإعدادات الصالحة للمخزن هي:

path : هذا هو المسار الجذر لدليل مخزن كلمات المرور

valid_signing_keys : يتوافق هذا الإعداد مع متغير البيئة PASSWORD_STORE_SIGNING_KEY

style_path : معلومات اللون والنمط للمخزن، يمكن أن تحتوي المخازن المختلفة على أنماط مختلفة وسيتم تغييرها عند تبديل المخزن. يمكن العثور على وثائق حول التنسيق هنا https://docs.rs/cursive_core/0.1.1/cursive_core/theme/index.html

pgp : تطبيق pgp المستخدم للمخزن، القيم الصالحة هي gpg أو sequoia

own_fingerprint : إذا تم تعيين خيار pgp على sequoia، فسيحتاج ripasso إلى معرفة بصمة المفتاح الخاص بك للتواصل مع gpg-agent
