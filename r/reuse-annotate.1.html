NAME

reuse-annotate - Annotate files with copyright and license information.

SYNOPSIS

reuse annotate [--copyright=COPYRIGHT] [--license=LICENSE] [--merge] [--remove-header] [FILE...])

DESCRIPTION

The reuse annotate command adds copyright and license information to files.

MANDATORY OPTIONS

--copyright=COPYRIGHT
Specify the copyright holder. This option can be used multiple times.
--license=LICENSE
Specify the license(s). This option can be used multiple times.

OTHER OPTIONS

--merge
If the file already contains copyright and license information, merge the new information with the existing one instead of replacing it.
--remove-header
Remove the existing copyright and license header from the file.
