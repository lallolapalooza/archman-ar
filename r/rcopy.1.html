RCOPY(1) librdmacm RCOPY(1)

الاسم

rcopy - نسخ ملف بسيط عبر RDMA.

ملخص

rcopy source server[:destination] [-p port]
rcopy [-p port]

الوصف

يستخدم مآخذ التوصيل عبر واجهة RDMA لنسخ ملف المصدر إلى الوجهة المحددة.

الخيارات

source
اسم ومسار الملف المصدر المراد نسخه.
server
اسم أو عنوان الخادم الوجهة.
:destination
اسم ملف ومسار اختياري للوجهة. إذا لم يتم توفيره، فسيتطابق اسم ملف الوجهة مع اسم المصدر.
-p server_port
رقم منفذ الخادم.

ملاحظات

الاستخدام الأساسي هو تشغيل rcopy على نظام خادم، ثم تشغيل rcopy sourcefile servername. سيستمر تطبيق الخادم في العمل بعد نسخ الملف، ولكنه حاليًا أحادي المسار.

نظرًا لأن هذا الاختبار يقوم بتعيين موارد RDMA إلى مساحة المستخدم، يجب على المستخدمين التأكد من أن لديهم موارد النظام والأذونات المتاحة. راجع ملف README الخاص بـ libibverbs للحصول على تفاصيل إضافية.
