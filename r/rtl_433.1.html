RTL_433(1) أوامر rtl_433 RTL_433(1)

الاسم

rtl_433 - جهاز استقبال بيانات RF عام ومفكك تشفير لأجهزة نطاق ISM باستخدام RTL-SDR و SoapySDR.

الوصف

توثق صفحة الدليل هذه بإيجاز أمر rtl_433.

rtl_433 هو جهاز استقبال بيانات عام، بشكل أساسي لنطاقات ISM بتردد 433.92 ميجاهرتز، 868 ميجاهرتز (SRD)، 315 ميجاهرتز، و 915 ميجاهرتز. يعمل مع RTL-SDR و/أو SoapySDR. تشمل الأجهزة التي تم اختبارها ودعمها بنشاط دونجل DVB المستندة إلى RTL2832 (باستخدام RTL-SDR) و LimeSDR (عينات هندسية من LimeSDR USB و LimeSDR mini مقدمة بلطف من MyriadRf)، PlutoSDR، HackRF One (باستخدام برامج تشغيل SoapySDR)، بالإضافة إلى SoapyRemote.

الموجز

rtl_433 [خيار]... ملف...

الخيارات

يتضمن الملخص التالي خيارات. تليها معلومات مفصلة حول بعض الخيارات.


يتم البحث عن ملف "rtl_433.conf" في "./"، XDG_CONFIG_HOME مثل "$HOME/.config/rtl_433/"، SYSCONFDIR مثل "/usr/local/etc/rtl_433/"، ثم سيتم تحليل وسائط سطر الأوامر بالترتيب.

خيارات عامة

[ -V ]
طباعة سلسلة الإصدار والخروج
[ -v ]
زيادة الإسهاب (يمكن استخدامه عدة مرات).
-v : إشعار مفصل، -vv : معلومات مفصلة، -vvv : تصحيح الأخطاء، -vvvv : تتبع.
[ -c <مسار> ]
قراءة خيارات التكوين من ملف

خيارات الموالف

[ -d <مؤشر جهاز USB RTL-SDR> | :<الرقم التسلسلي لجهاز USB RTL-SDR> | <استعلام جهاز SoapySDR> | rtl_tcp | مساعدة ]
[-g <كسب> | مساعدة] (الافتراضي: تلقائي)
[ -t <إعدادات> ]
تطبيق قائمة إعدادات مفتاح=قيمة على جهاز SDR
على سبيل المثال، لـ SoapySDR -t "antenna=A,bandwidth=4.5M,rfnotch_ctrl=false"
لاستخدام RTL-SDR "direct_samp[=1]"، "offset_tune[=1]"، "digital_agc[=1]"، "biastee[=1]"
[ -f <تردد> ]
تردد (ترددات) الاستقبال (الافتراضي: 433920000 هرتز)
[ -H <ثواني> ]
فاصل القفز لمسح ترددات متعددة (الافتراضي: 600 ثانية)
[ -p <خطأ ppm> ]
تصحيح خطأ تردد موالف rtl-sdr (الافتراضي: 0)
[ -s <معدل العينة> ]
تعيين معدل العينة (الافتراضي: 250000 هرتز)
[ -D إعادة تشغيل | إيقاف مؤقت | إنهاء | يدوي ]
خيارات وضع تشغيل جهاز الإدخال.

خيارات فك التضمين

[ -R <جهاز> | مساعدة ]
تمكين بروتوكول فك تشفير الجهاز المحدد فقط (يمكن استخدامه عدة مرات)
تحديد رقم سالب لتعطيل بروتوكول فك تشفير جهاز (يمكن استخدامه عدة مرات)
[ -X <مواصفات> | مساعدة ]
إضافة مفكك تشفير عام الأغراض (بادئة -R 0 لتعطيل جميع مفككات التشفير)
[ -Y تلقائي | كلاسيكي | minmax ]
وضع كاشف نبضات FSK.
[ -Y level=<مستوى dB> ]
يدوي كشف المستوى المستخدم لتحديد النبضات (من -1.0 إلى -30.0) (0=تلقائي).
[ -Y minlevel=<مستوى dB> ]
يدوي الحد الأدنى لمستوى الكشف المستخدم لتحديد النبضات (من -1.0 إلى -99.0).
[ -Y minsnr=<مستوى dB> ]
الحد الأدنى لنسبة الإشارة إلى الضوضاء (SNR) لتحديد النبضات (من 1.0 إلى 99.0).
[ -Y autolevel ]
تعيين minlevel تلقائيًا بناءً على متوسط الضوضاء المقدر.
[ -Y squelch ]
تخطي الإطارات تحت مستوى الضوضاء المقدر لتقليل حمل وحدة المعالجة المركزية.
[ -Y ampest | magest ]
اختر مقدر مستوى السعة أو المقدار.

خيارات التحليل/التصحيح

[ -A ]
محلل النبضات. تمكين تحليل النبضات ومحاولة فك التشفير.
عطّل جميع مفككات التشفير باستخدام -R 0 إذا كنت تريد مخرجات المحلل فقط.
[ -y <رمز> ]
التحقق من فك تشفير بيانات الاختبار المفككة (على سبيل المثال، "{"25"}fb2dd58") مع الأجهزة الممكّنة

خيارات الإدخال/الإخراج للملفات

[ -S لا شيء | الكل | غير معروف | معروف ]
حفظ الإشارة تلقائيًا. ينشئ ملفًا واحدًا لكل إشارة.
ملاحظة: يحفظ عينات I/Q الخام (uint8 pcm، قناتان). الوضع المفضل لإنشاء ملفات اختبار.
[ -r <اسم الملف> | مساعدة ]
قراءة البيانات من ملف الإدخال بدلاً من جهاز استقبال
[ -w <اسم الملف> | مساعدة ]
حفظ تيار البيانات في ملف الإخراج ( '-' يلقي العينات إلى stdout)
[ -W <اسم الملف> | مساعدة ]
حفظ تيار البيانات في ملف الإخراج، الكتابة فوق الملف الموجود

خيارات مخرجات البيانات

[ -F سجل | kv | json | csv | mqtt | influx | syslog | trigger | null | مساعدة ]
إنتاج مخرجات مفككة بالتنسيق المحدد.
إلحاق المخرجات بملف باستخدام: <اسم الملف> (على سبيل المثال، -F csv:log.csv)، الافتراضي هو stdout.
تحديد المضيف/المنفذ لـ syslog باستخدام، على سبيل المثال، -F syslog:127.0.0.1:1514
[ -M time[:<options>] | protocol | level | noise[:<secs>] | stats | bits | مساعدة ]
إضافة بيانات تعريف مختلفة إلى كل مخرج.
[ -K FILE | PATH | <tag> | <key>=<tag> ]
إضافة رمز موسع أو علامة ثابتة إلى كل سطر إخراج.
[ -C native | si | customary ]
تحويل الوحدات في المخرجات المفككة.
[ -n <القيمة> ]
تحديد عدد العينات المراد أخذها (كل عينة هي زوج I/Q)
[ -T <ثواني> ]
تحديد عدد الثواني للتشغيل، وكذلك 12:34 أو 1h23m45s
[ -E hop | quit ]
القفز/الإنهاء بعد إخراج الحدث (الأحداث) الناجح(ة)
[ -h ]
طباعة تعليمات الاستخدام هذه والخروج
استخدم -d، -g، -R، -X، -F، -M، -r، -w، أو -W بدون وسيطة لمزيد من المساعدة

اختيار جهاز الإدخال

برنامج تشغيل جهاز RTL-SDR متاح.
[ -d <مؤشر جهاز USB RTL-SDR> ]
(الافتراضي: 0)
[ -d :<الرقم التسلسلي لجهاز USB RTL-SDR (يمكن تعيينه باستخدام rtl_eeprom -s)> ]
لتعيين الكسب لـ RTL-SDR استخدم -g <كسب> لتعيين كسب إجمالي بالديسيبل.
برنامج تشغيل جهاز SoapySDR متاح.
[ -d "" ]
فتح جهاز SoapySDR الافتراضي
[ -d driver=rtlsdr ]
فتح، على سبيل المثال، جهاز SoapySDR محدد
لتعيين الكسب لـ SoapySDR استخدم -g ELEM=val,ELEM=val,... على سبيل المثال، -g LNA=20,TIA=8,PGA=2 (لـ LimeSDR).
[ -d rtl_tcp[:[//]host[:port] ]
(الافتراضي: localhost:1234)
تحديد المضيف/المنفذ للاتصال به باستخدام، على سبيل المثال، -d rtl_tcp:127.0.0.1:1234

خيار الكسب

[ -g <كسب> ]
(الافتراضي: تلقائي)
لـ RTL-SDR: الكسب بالديسيبل ("0" يعني تلقائي).
لـ SoapySDR: الكسب بالديسيبل للتوزيع التلقائي ("" يعني تلقائي)، أو سلسلة من عناصر الكسب.
على سبيل المثال، "LNA=20,TIA=8,PGA=2" لـ LimeSDR.
