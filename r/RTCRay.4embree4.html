RTCRay.4embree4

الحزمة: embree

التراخيص: Apache

RTCRay(3) أنوية تتبع الأشعة Embree 4 RTCRay(3)

الاسم

RTCRay - هيكل شعاع مفرد

الملخص

#include <embree4/rtcore_ray.h>
struct RTC_ALIGN(16) RTCRay
{
  float org_x;        // إحداثي x لأصل الشعاع
  float org_y;        // إحداثي y لأصل الشعاع
  float org_z;        // إحداثي z لأصل الشعاع
  float tnear;        // بداية مقطع الشعاع
  float dir_x;        // إحداثي x لاتجاه الشعاع
  float dir_y;        // إحداثي y لاتجاه الشعاع
  float dir_z;        // إحداثي z لاتجاه الشعاع
  float time;         // وقت هذا الشعاع لحركة التمويه
  float tfar;         // نهاية مقطع الشعاع (تُضبط على مسافة الاصطدام)
  unsigned int mask;  // قناع الشعاع
  unsigned int id;    // معرف الشعاع
  unsigned int flags; // أعلام الشعاع
};

الوصف

يحدد هيكل RTCRay تخطيط الشعاع لشعاع مفرد. يحتوي الشعاع على الأصل (الأعضاء org_x، org_y، org_z)، ومتجه الاتجاه (الأعضاء dir_x، dir_y، dir_z)، ومقطع الشعاع (الأعضاء tnear و tfar). لا يلزم أن يكون اتجاه الشعاع موحدًا، ويتم اعتبار نطاق المعلمة المحدد بواسطة الفاصل الزمني tnear/tfar فقط صالحًا.

يجب أن يكون مقطع الشعاع في النطاق [0،∞؛]، وبالتالي فإن النطاقات التي تبدأ خلف أصل الشعاع غير مسموح بها، ولكن النطاقات يمكن أن تصل إلى ما لا نهاية.

يحتوي الشعاع أيضًا على وقت حركة تمويه في النطاق [0,1] (عضو time)، وقناع شعاع (عضو mask)، ومعرف شعاع (عضو id)، وأعلام شعاع (عضو flags). يمكن استخدام قناع الشعاع لإخفاء بعض الأشكال الهندسية لبعض الأشعة (انظر rtcSetGeometryMask لمزيد من التفاصيل). يمكن استخدام معرف الشعاع لتحديد شعاع داخل دالة رد اتصال، حتى لو تغير ترتيب الأشعة داخل حزمة أشعة.

يعرّف رأس التضمين embree4/rtcore_ray.h أيضًا نفس هيكل الشعاع في تخطيط هيكل المصفوفات (SOA) لوظائف API التي تقبل حزم أشعة بحجم 4 (نوع RTCRay4)، وحجم 8 (نوع RTCRay8)، وحجم 16 (نوع RTCRay16). يحدد رأس التضمين أيضًا قالب RTCRayNt لحزم الأشعة بحجم تعسفي في وقت التصريف.
