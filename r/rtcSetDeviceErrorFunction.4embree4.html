rtcSetDeviceErrorFunction.4embree4

الحزمة: embree

التراخيص: Apache

rtcSetDeviceErrorFunction(3) مجموعة نواة تتبع الأشعة Embree 4 rtcSetDeviceErrorFunction(3)

الاسم

rtcSetDeviceErrorFunction - يضبط دالة استدعاء خطأ للجهاز

الملخص

#include <embree4/rtcore.h>
typedef void (*RTCErrorFunction)(
  void* userPtr,
  RTCError code,
  const char* str
);
void rtcSetDeviceErrorFunction(
  RTCDevice device,
  RTCErrorFunction error,
  void* userPtr
);

الوصف

باستخدام استدعاء rtcSetDeviceErrorFunction، يمكن ضبط دالة استدعاء (الوسيط error) مع حمولة (الوسيط userPtr)، والتي يتم استدعاؤها كلما حدث خطأ بالجهاز المحدد (الوسيط device).

يمكن تسجيل دالة استدعاء واحدة فقط لكل جهاز، وتؤدي الاستدعاءات اللاحقة إلى الكتابة فوق دالة الاستدعاء السابقة. تمرير NULL كـ مؤشر دالة يعطل دالة الاستدعاء المسجلة.

عند استدعاء دالة الاستدعاء المسجلة، يتم تمرير حمولة محددة بواسطة المستخدم (الوسيط userPtr كما هو محدد وقت التسجيل)، رمز الخطأ (الوسيط code) للخطأ الذي حدث، بالإضافة إلى سلسلة نصية (الوسيط str) تصف الخطأ بمزيد من التفصيل.

يتم أيضًا تعيين رمز الخطأ إذا تم تسجيل دالة استدعاء خطأ.

حالة الخروج

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.

انظر أيضًا

[rtcGetDeviceError]
