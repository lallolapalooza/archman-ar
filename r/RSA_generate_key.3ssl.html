RSA_generate_key(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

RSA_GENERATE_KEY(3ssl) OpenSSL RSA_GENERATE_KEY(3ssl)

الاسم

EVP_RSA_gen, RSA_generate_key_ex, RSA_generate_key, RSA_generate_multi_prime_key - توليد زوج مفاتيح RSA

الملخص

#include <openssl/rsa.h>
EVP_PKEY *EVP_RSA_gen(unsigned int bits);

تم إيقاف الدوال التالية منذ OpenSSL 3.0، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

int RSA_generate_key_ex(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);
int RSA_generate_multi_prime_key(RSA *rsa, int bits, int primes, BIGNUM *e, BN_GENCB *cb);

تم إيقاف الدالة التالية منذ OpenSSL 0.9.8، ويمكن إخفاؤها بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

RSA *RSA_generate_key(int bits, unsigned long e,
                      void (*callback)(int, int, void *), void *cb_arg);

الوصف

تقوم EVP_RSA_gen() بتوليد زوج مفاتيح RSA جديد بحجم معامل bits.

جميع الدوال الموضحة أدناه تم إيقافها. يجب على التطبيقات استخدام EVP_RSA_gen() أو EVP_PKEY_Q_keygen(3) أو EVP_PKEY_keygen_init(3) و EVP_PKEY_keygen(3) بدلاً من ذلك.

تقوم RSA_generate_key_ex() بتوليد زوج مفاتيح RSA بـ 2 أولي وتخزينه في بنية RSA المقدمة في rsa.

تقوم RSA_generate_multi_prime_key() بتوليد زوج مفاتيح RSA متعدد الأولي وتخزينه في بنية RSA المقدمة في rsa. يتم تحديد عدد الأعداد الأولية بواسطة المعامل primes. إذا فشل التهيئة التلقائية أو إعادة تهيئة مولد الأرقام العشوائية المشفرة (CSPRNG) الخاص بـ OpenSSL بسبب ظروف خارجية (انظر RAND(7))، ستفشل العملية.

سيكون حجم المعامل بطول bits، وعدد الأعداد الأولية التي تشكل المعامل سيكون primes، والأس العام سيكون e. يجب اعتبار أحجام المفاتيح التي يكون فيها num < 1024 غير آمنة. الأس هو رقم فردي، عادةً 3 أو 17 أو 65537.

للحفاظ على مستوى الأمان الكافي، يعتمد الحد الأقصى لعدد الأعداد الأولية المسموح به على طول بت المعامل:

<1024 | >=1024 | >=4096 | >=8192
------+--------+--------+-------
  2   |   3    |   4    |   5

يمكن استخدام دالة استدعاء لتوفير ملاحظات حول تقدم توليد المفتاح. إذا لم يكن cb NULL، فسيتم استدعاؤه على النحو التالي باستخدام الدالة BN_GENCB_call() الموضحة في صفحة BN_generate_prime(3).

RSA_generate_key() مشابهة لـ RSA_generate_key_ex() ولكنها تتوقع دالة استدعاء قديمة؛ انظر BN_generate_prime(3) للمعلومات حول دالة الاستدعاء القديمة.

  • أثناء توليد رقم أولي عشوائي، يتم استدعاؤه كما هو موضح في BN_generate_prime(3).
  • عند رفض الرقم الأولي العشوائي رقم n لعدم ملاءمته للمفتاح، يتم استدعاء BN_GENCB_call(cb, 2, n).
  • عند العثور على رقم أولي عشوائي p بحيث يكون p-1 أوليًا بالنسبة لـ e، يتم استدعاؤه كـ BN_GENCB_call(cb, 3, 0).

ثم يتم تكرار العملية للرقم الأولي q والأعداد الأولية الأخرى (إن وجدت) مع BN_GENCB_call(cb, 3, i) حيث يشير i إلى الرقم الأولي رقم i.

قيم الإرجاع

تعود EVP_RSA_gen() بـ EVP_PKEY أو NULL في حالة الفشل.

تعود RSA_generate_multi_prime_key() بالقيمة 1 عند النجاح أو 0 عند حدوث خطأ. تعود RSA_generate_key_ex() بالقيمة 1 عند النجاح أو 0 عند حدوث خطأ. يمكن الحصول على رموز الخطأ بواسطة ERR_get_error(3).

تعود RSA_generate_key() بمؤشر إلى بنية RSA أو NULL إذا فشل توليد المفتاح.

الأخطاء

يتم استخدام BN_GENCB_call(cb, 2, x) بمعنيين مختلفين.

انظر أيضا

التاريخ
