الوصف

التصنيف

تُستخدم regcomp() لتصنيف تعبير عادي إلى صيغة مناسبة لعمليات البحث اللاحقة باستخدام regexec().

عند النجاح، يتم تهيئة مخزن الأنماط المؤقت في *preg. regex هو سلسلة نصية تنتهي بحرف null. يجب أن تكون الإعدادات المحلية (locale) كما هي عند تشغيل regexec().

بعد نجاح regcomp()، يحتوي preg->re_nsub على عدد التعبيرات الفرعية في regex. وبالتالي، فإن قيمة preg->re_nsub + 1 التي تمرر كـ n إلى regexec() كافية لالتقاط جميع التطابقات.

cflags هو OR الثنائي لصفر أو أكثر من العلامات التالية:

REG_EXTENDED
استخدم صيغة تعبيرات POSIX الموسعة عند تفسير regex. إذا لم يتم تعيينها، يتم استخدام صيغة تعبيرات POSIX الأساسية.
REG_ICASE
لا تميز بين حالة الأحرف. عمليات البحث اللاحقة باستخدام regexec() باستخدام مخزن الأنماط هذا ستكون غير حساسة لحالة الأحرف.
REG_NOSUB
أبلغ عن النجاح العام فقط. ستستخدم regexec() pmatch فقط لـ REG_STARTEND، متجاهلة n.
REG_NEWLINE
عوامل مطابقة أي حرف لا تطابق حرف سطر جديد.
قائمة عدم المطابقة ([^...]) التي لا تحتوي على حرف سطر جديد لا تطابق حرف سطر جديد.
عامل بداية السطر (^) يطابق السلسلة الفارغة مباشرة بعد حرف سطر جديد، بغض النظر عما إذا كانت eflags، علامات التنفيذ لـ regexec()، تحتوي على REG_NOTBOL.
عامل نهاية السطر ($) يطابق السلسلة الفارغة مباشرة قبل حرف سطر جديد، بغض النظر عما إذا كانت eflags تحتوي على REG_NOTEOL.

المطابقة

تُستخدم regexec() لمطابقة سلسلة نصية تنتهي بحرف null مقابل مخزن الأنماط المترجم في *preg، والذي يجب أن يكون قد تم تهيئته باستخدام regcomp(). eflags هي OR الثنائي لصفر أو أكثر من العلامات التالية:

REG_NOTBOL
يفشل عامل بداية السطر دائمًا في المطابقة (ولكن انظر علامة التصنيف REG_NEWLINE أعلاه). يمكن استخدام هذه العلامة عند تمرير أجزاء مختلفة من سلسلة نصية إلى regexec() ويجب ألا يُفسر بداية السلسلة كنهاية سطر.
REG_NOTEOL
يفشل عامل نهاية السطر دائمًا في المطابقة (ولكن انظر علامة التصنيف REG_NEWLINE أعلاه).
REG_STARTEND
مطابقة [string + pmatch[0].rm_so, string + pmatch[0].rm_eo) بدلاً من [string, string + strlen(string)). يسمح هذا بمطابقة البايتات NUL المضمنة وتجنب strlen(3) على السلاسل ذات الطول المعروف. إذا تم إرجاع أي مطابقات (لم يتم تمرير REG_NOSUB إلى regcomp()، ونجحت المطابقة، و n > 0)، فإنها تستبدل pmatch كالمعتاد، وتظل إزاحات المطابقة نسبية إلى string (وليس string + pmatch[0].rm_so). هذه العلامة هي امتداد BSD، غير موجودة في POSIX.

إزاحات المطابقة

ما لم يتم تمرير REG_NOSUB إلى regcomp()، فمن الممكن الحصول على مواقع المطابقات داخل string: تملأ regexec() n عناصر من pmatch بالنتائج: pmatch[0] يتوافق مع المطابقة الكاملة، pmatch[1] يتوافق مع التعبير الفرعي الأول، إلخ. إذا كان عدد المطابقات أكبر من n، فسيتم تجاهلها؛ إذا كان أقل، فسيتم ملء العناصر غير المستخدمة من pmatch بـ -1.

كل مطابقة صالحة (غير -1) تم إرجاعها تتوافق مع النطاق [string + rm_so, string + rm_eo).

regoff_t هو نوع عدد صحيح موقع قادر على تخزين أكبر قيمة يمكن تخزينها في أحد النوعين ptrdiff_t أو ssize_t.

الإبلاغ عن الأخطاء

تُستخدم regerror() لتحويل رموز الخطأ التي يمكن إرجاعها من كل من regcomp() و regexec() إلى سلاسل رسائل خطأ.

إذا لم يكن preg مؤشر null، فيجب أن يكون errcode هو أحدث خطأ تم إرجاعه من عملية على preg.

إذا لم يكن errbuf_size يساوي 0، يتم نسخ ما يصل إلى errbuf_size بايت إلى errbuf؛ دائمًا ما تنتهي سلسلة الخطأ بحرف null، ويتم اقتصاصها لتناسب.

التحرير

تقوم regfree() بإلغاء تهيئة مخزن الأنماط المؤقت في *preg، وتحرير أي ذاكرة مرتبطة به؛ يجب أن يكون *preg قد تم تهيئته عبر regcomp().

قيمة الإرجاع

تُرجع regcomp() صفرًا للتصنيف الناجح أو رمز خطأ للفشل.

تُرجع regexec() صفرًا للمطابقة الناجحة أو REG_NOMATCH للفشل.

تُرجع regerror() حجم المخزن المؤقت المطلوب للاحتفاظ بالسلسلة.

الأخطاء

يمكن إرجاع الأخطاء التالية بواسطة regcomp():

REG_BADBR
استخدام غير صالح لمشغل الإشارة المرجعية.
REG_BADPAT
استخدام غير صالح لمشغلات الأنماط مثل المجموعة أو القائمة.
REG_BADRPT
استخدام غير صالح لمشغلات التكرار مثل استخدام '*' كالحرف الأول.
REG_EBRACE
مشغلات فترات الأقواس المتعرجة غير المتطابقة.
REG_EBRACK
مشغلات قوائم الأقواس غير المتطابقة.
REG_ECOLLATE
عنصر تجميع غير صالح.
REG_ECTYPE
اسم فئة الأحرف غير المعروف.
REG_EEND
خطأ غير محدد. هذا غير معرف بواسطة POSIX.
REG_EESCAPE
شرطة مائلة لاحقة.
REG_EPAREN
مشغلات مجموعات الأقواس غير المتطابقة.
REG_ERANGE
استخدام غير صالح لمشغل النطاق؛ على سبيل المثال، نقطة نهاية النطاق تحدث قبل نقطة البداية.

ERRORS

The following values may be returned by regcomp():

REG_ASSERT
An internal error occurred when compiling the regular expression.
REG_BADPAT
The regular expression string contained a faultyly constructed pattern.
REG_BADRPT
A repeated subexpression with no preceding expression.
REG_BUG
A defect in the regular expression library.
REG_ECOLLATE
The collation symbols were invalid.
REG_ECTYPE
The character class was invalid.
REG_EEND
The regular expression terminated unexpectedly.
REG_EESCAPE
The backslash character was invalid.
REG_ESIZE
Compiled regular expression requires a pattern buffer larger than 64 kB. This is not defined by POSIX.
REG_ESPACE
The regex routines ran out of memory.
REG_ESUBREG
Invalid back reference to a subexpression.

STANDARDS

POSIX.1-2008.

HISTORY

POSIX.1-2001.

Prior to POSIX.1-2008, regoff_t was required to be capable of storing the largest value that can be stored in either an off_t type or a ssize_t type.

CAVEATS

re_nsub is only required to be initialized if REG_NOSUB wasn't specified, but all known implementations initialize it regardless.

Both regex_t and regmatch_t may (and do) have more members, in any order. Always reference them by name.

EXAMPLES

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <regex.h>
#define NITEMS(arr)  (sizeof((arr)) / sizeof((arr)[0]))
static const char *const str =
        "1) John Driverhacker;\n2) John Doe;\n3) John Foo;\n";
static const char *const re = "John.*o";
int main(void)
{
    static const char *s = str;
    regex_t     regex;
    regmatch_t  pmatch[1];
    regoff_t    off, len;
    if (regcomp(&regex, re, REG_NEWLINE))
        exit(EXIT_FAILURE);
    printf("String = \"%s\"\n", str);
    printf("Matches:\n");
    for (unsigned int i = 0; ; i++) {
        if (regexec(&regex, s, NITEMS(pmatch), pmatch, 0))
            break;
        off = pmatch[0].rm_so + (s - str);
        len = pmatch[0].rm_eo - pmatch[0].rm_so;
        printf("#%u:\n", i);
        printf("offset = %jd; length = %jd\n", (intmax_t) off,
                (intmax_t) len);
        printf("substring = \"%.*s\"\n", len, s + pmatch[0].rm_so);
        s += pmatch[0].rm_eo;
    }
    exit(EXIT_SUCCESS);
}
