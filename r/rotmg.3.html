subroutine drotmg (double precision dd1, double precision dd2, double precision dx1, double precision dy1, double precision, dimension(5) dparam)

DROTMG

الغرض:

!>
!>    بناء مصفوفة تحويل جيفنز المعدلة H التي تجعل المكون الثاني للمتجه الثنائي (DSQRT(DD1)*DX1,DSQRT(DD2)*>    DY2)**T يساوي صفراً.
!>    مع DPARAM(1)=DFLAG، تمتلك H أحد الأشكال التالية..
!>
!>    DFLAG=-1.D0     DFLAG=0.D0        DFLAG=1.D0     DFLAG=-2.D0
!>
!>      (DH11  DH12)    (1.D0  DH12)    (DH11  1.D0)    (1.D0  0.D0)
!>    H=(          )    (          )    (          )    (          )
!>      (DH21  DH22),   (DH21  1.D0),   (-1.D0 DH22),   (0.D0  1.D0).
!>    المواقع 2-4 من DPARAM تحتوي على DH11, DH21, DH12, و DH22
!>    على التوالي. (القيم 1.D0، -1.D0، أو 0.D0 التي يستلزمها
!>    الخيار DPARAM(1) لا يتم تخزينها في DPARAM.)
!>
!>    قد تكون قيم GAMSQ و RGAMSQ المعينة في عبارة DATA غير دقيقة.
!>    هذا لا بأس به حيث أنها تستخدم فقط لاختبار حجم DD1 و DD2.
!>    يتم إجراء جميع القياسات الفعلية للبيانات باستخدام GAM.
!>
!>
