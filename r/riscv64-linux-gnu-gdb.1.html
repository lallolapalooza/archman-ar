الحزمة: riscv64-linux-gnu-gdb

التراخيص: GPL3

GDB(1) أدوات تطوير GNU GDB(1)

الاسم

gdb - مصحح أخطاء GNU

الملخص

gdb [خيارات] [برنامج|برنامج معرف_العملية|برنامج ملف_النواة]

الوصف

الغرض من مصحح أخطاء مثل GDB هو السماح لك برؤية ما يحدث "داخل" برنامج آخر أثناء تنفيذه -- أو ما كان يفعله برنامج آخر في لحظة انهياره.

يمكن لـ GDB القيام بأربعة أنواع رئيسية من الأشياء (بالإضافة إلى أشياء أخرى لدعم هذه) لمساعدتك في اكتشاف الأخطاء أثناء وقوعها:

  • بدء برنامجك، مع تحديد أي شيء قد يؤثر على سلوكه.
  • جعل برنامجك يتوقف عند ظروف محددة.
  • فحص ما حدث، عندما يتوقف برنامجك.
  • تغيير الأشياء في برنامجك، حتى تتمكن من التجربة لتصحيح آثار خطأ ما والمضي قدمًا لمعرفة خطأ آخر.

يمكنك استخدام GDB لتصحيح أخطاء البرامج المكتوبة بلغات C، C++، Fortran، و Modula-2.

يتم استدعاء GDB باستخدام أمر shell "gdb". بمجرد البدء، يقرأ الأوامر من الطرفية حتى تخبره بالخروج باستخدام أمر GDB "quit" أو "exit". يمكنك الحصول على مساعدة عبر الإنترنت من GDB نفسه باستخدام الأمر "help".

يمكنك تشغيل "gdb" بدون وسائط أو خيارات؛ ولكن الطريقة الأكثر شيوعًا لبدء GDB هي باستخدام وسيط واحد أو وسيطين، يحددان ملفًا تنفيذيًا كوسيط:

gdb program

يمكنك أيضًا البدء بتحديد ملف تنفيذي وملف نواة:

gdb program core

يمكنك، بدلاً من ذلك، تحديد معرف عملية كوسيط ثانٍ أو استخدام الخيار "-p"، إذا كنت ترغب في تصحيح أخطاء عملية قيد التشغيل:

gdb program 1234
gdb -p 1234

سيؤدي ذلك إلى ربط GDB بالعملية 1234. باستخدام الخيار -p يمكنك حذف اسم ملف البرنامج.

فيما يلي بعض أوامر GDB الأكثر شيوعًا:

break [ملف:][وظيفة|سطر]
تعيين نقطة توقف عند الوظيفة أو السطر (في الملف).
run [قائمة_وسائط]
بدء برنامجك (مع قائمة_وسائط، إذا تم تحديدها).
bt
تتبع الخلفية: عرض مكدس البرنامج.
print تعبير
عرض قيمة تعبير.
c
متابعة تشغيل برنامجك (بعد التوقف، على سبيل المثال عند نقطة توقف).
next
تنفيذ سطر البرنامج التالي (بعد التوقف)؛ تجاوز أي استدعاءات وظائف في السطر.
edit [ملف:]وظيفة
انظر إلى سطر البرنامج حيث توقف حاليًا.
list [ملف:]وظيفة
اكتب نص البرنامج في محيط المكان الذي توقف فيه حاليًا.
step
تنفيذ سطر البرنامج التالي (بعد التوقف)؛ الدخول إلى أي استدعاءات وظائف في السطر.
help [اسم]
عرض معلومات حول أمر GDB الاسم، أو معلومات عامة حول استخدام GDB.
quit
exit
الخروج من GDB.

للحصول على التفاصيل الكاملة حول GDB، راجع استخدام GDB: دليل مصحح أخطاء مستوى المصدر GNU، بقلم Richard M. Stallman و Roland H. Pesch. نفس النص متاح عبر الإنترنت كإدخال "gdb" في برنامج "info".

الخيارات

أي وسائط بخلاف الخيارات تحدد ملفًا تنفيذيًا وملف نواة (أو معرف عملية)؛ أي أن الوسيط الأول الذي يتم العثور عليه بدون علامة خيار مرتبطة به يعادل خيار --se، والثاني، إن وجد، يعادل خيار -c إذا كان اسم ملف. العديد من الخيارات لها أشكال طويلة ومختصرة؛ كلاهما معروض هنا. الأشكال الطويلة يتم التعرف عليها أيضًا إذا قمت باختصارها، طالما أن ما يكفي من الخيار موجود ليكون غير مبهم.

تظهر الأشكال المختصرة هنا مع - وتظهر الأشكال الطويلة مع -- لتعكس كيفية ظهورها في --help. ومع ذلك، يتعرف GDB على جميع اتفاقيات التنسيق التالية لمعظم الخيارات:

"--option=value"
"--option value"
"-option=value"
"-option value"
"--o=value"
"--o value"
"-o=value"
"-o value"

يتم معالجة جميع الخيارات ووسائط سطر الأوامر التي تقدمها بترتيب تسلسلي. الترتيب مهم عند استخدام الخيار -x.

--help
-h
قائمة بجميع الخيارات، مع شروحات موجزة.
--symbols=file
-s file
قراءة جدول الرموز من الملف.
--write
تمكين الكتابة في الملفات التنفيذية وملفات النواة.
--exec=file
-e file
استخدام الملف كملف تنفيذي للتنفيذ عند الاقتضاء، ول فحص البيانات الخالصة بالاقتران مع تفريغ النواة.
--se=file
قراءة جدول الرموز من الملف واستخدامه كملف تنفيذي.
--core=file
-c file
استخدام الملف كتفريغ نواة للفحص.
--command=file
-x file
تنفيذ أوامر GDB من الملف.
--eval-command=command
-ex command
تنفيذ أمر GDB المحدد command.
--init-eval-command=command
-iex
تنفيذ أمر GDB command قبل تحميل البرنامج الفرعي.
--directory=directory
-d directory
إضافة الدليل إلى المسار للبحث عن ملفات المصدر.
--nh
عدم تنفيذ الأوامر من ~/.config/gdb/gdbinit، ~/.gdbinit، ~/.config/gdb/gdbearlyinit، أو ~/.gdbearlyinit
--nx
-n
عدم تنفيذ الأوامر من أي ملفات تهيئة .gdbinit أو .gdbearlyinit.
--quiet
--silent
-q
"هادئ". لا تطبع رسائل المقدمة وحقوق النشر. يتم أيضًا قمع هذه الرسائل في الوضع الدفعي.
--batch
تشغيل في الوضع الدفعي. الخروج بحالة 0 بعد معالجة جميع ملفات الأوامر المحددة بواسطة -x (و .gdbinit، إذا لم يتم تثبيطها). الخروج بحالة غير صفرية إذا حدث خطأ في تنفيذ أوامر GDB في ملفات الأوامر.

قد يكون الوضع الدفعي مفيدًا لتشغيل GDB كمرشح
