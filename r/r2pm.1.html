r2pm(1)

الحزمة: radare2

التراخيص: GPL-3.0-only, LGPL-3.0-only

R2PM(1) دليل الأوامر العامة R2PM(1)

الاسم

r2pm — مدير حزم radare2

الملخص

r2pm [[adhHIipuUglsv]] [[pkg ...]]

الوصف

يسمح بتثبيت وتحديث وإلغاء تثبيت واكتشاف الإضافات والأدوات التي يمكن استخدامها مع radare2.

-a, repo
يضيف مستودع r2pm خارجي، لا توجد وسائط لـ -a ستدرج جميع المستودعات المسجلة، استخدم '-a - repo' لإلغاء تسجيل / إزالة تلك المستودعات.
-I
عرض معلومات حول المستودع والحزم المثبتة
-i اسم_الحزمة
تثبيت حزمة
-e اسم_الحزمة
فتح سكربت الحزمة باستخدام محرركم المفضل
-d اسم_الحزمة
عرض الكود المصدري لحزمة r2pm
-gi اسم_الحزمة
تثبيت حزمة في دليل النظام
-u اسم_الحزمة
إلغاء تثبيت حزمة
-uu اسم_الحزمة
فرض إلغاء تثبيت حزمة
-U
تهيئة أو تحديث قاعدة بيانات الحزم
-UU
مثل -U، ولكن بعد ذلك قم بترقية جميع الحزم المثبتة
-gu اسم_الحزمة
إلغاء تثبيت حزمة من دليل النظام
-l
عرض قائمة بالحزم المثبتة
-s كلمة_مفتاحية
البحث في قاعدة البيانات عن حزم تطابق الكلمة المفتاحية
-t YYYY-MM-DD
تعيين متغير البيئة R2PM_TIME لتحديد وقت أخذ الكود المصدري للحزمة من git
-r الأمر ...args
تشغيل الأمر مع R2PM_BINDIR في PATH
-p
يتطلب -c لتنظيف R2PM_PLUGDIR
-v
عرض معلومات الإصدار
-h
عرض رسالة المساعدة للاستخدام
-H
عرض جميع متغيرات البيئة الخاصة المعرفة بواسطة r2pm داخليًا
-H اسم_متغير_البيئة
عرض قيمة متغير البيئة الداخلي المحدد
-c
تنظيف ذاكرة التخزين المؤقت للكود المصدري

أمثلة

يتم تهيئة قاعدة البيانات وسحبها تلقائيًا، تم إيقاف جميع الإجراءات المسمّاة، استخدم العلامات فقط

تثبيت حزمة


$ r2pm -i yara3

تثبيت حزمة اختبار (لا تقم بسحب git على $R2PM_GITDIR/yara3)


$ R2PM_GITSKIP=1 r2pm -ci yara3

تجنب استدعاءات التهيئة/التحديث (لا تقم بسحب git على $R2PM_DBDIR)


$ R2PM_OFFLINE=1 r2pm -i yara

إلغاء تثبيت حزمة


$ r2pm -u yara3

البحث عن حزمة


$ r2pm -s yara

عرض قائمة الحزم المثبتة


$ r2pm -l

البيئة


SUDO=sudo
R2PM_PLUGDIR=~/.local/share/radare2/plugins
R2PM_BINDIR=~/.local/share/radare2/prefix/bin
R2PM_OFFLINE=0
R2PM_DBDIR=~/.local/share/radare2/r2pm/db
R2PM_GITDIR=~/.local/share/radare2/r2pm/git
R2PM_GITSKIP=
R2PM_TIME=
R2_LOG_LEVEL
R2PM_INCDIR
R2PM_LIBDIR
R2PM_PREFIX
R2PM_LEGACY
