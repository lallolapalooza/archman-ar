recordmydesktop(1)

الحزمة: recordmydesktop

التراخيص: GPL

Name

recordmydesktop - record your desktop session to a video file

Synopsis

recordmydesktop [OPTIONS] [OUTPUTFILE]

Description

recordmydesktop is a program that records your desktop session to a video file. It records directly to Theora–Vorbis compressed files (Ogg Theora/Ogg Vorbis). recordmydesktop is designed to be as small as possible and depends only on the following libraries: Gtk+-2.0, GStreamer-0.10 and LAME. It does not depend on gnome-vfs(1), so it is possible to use it without installing it.

recordmydesktop can capture windows, areas, or the entire desktop. It can also record audio from any GStreamer-compatible device.

It also can choose to record the mouse cursor or not. In addition, it offers the possibility of applying a zoom factor on the recorded area.

Options

All options are written to standard error. If OUTPUTFILE is not specified, the default file name will be recorded to date.ogv.

-h, --help
Prints a help message.
-V, --version
Prints version information.
-v, --verbose
Prints debugging messages to stderr.
-d, --device DEVICE
Use DEVICE as the audio input device. Check your GStreamer documentation for a list of available devices.
-n, --no-sound
Do not record any sound.
-x, --windowid XID
Record only the window with XID XID.
-W, --window
Record a window. This option will prompt the user to select a window.
-a, --area
Record an area. This option will prompt the user to select an area.
-f, --fullscreen
Record the entire screen.
-r, --fps FPS
Set the frame rate to FPS frames per second.
-s, --seconds SECONDS
Record for SECONDS seconds.
-b, --beep
Beep when finished.
-m, --mouse
Draw the mouse cursor.
--no-mouse
Do not draw the mouse cursor.
-z, --zoom FACTOR
Set the zoom factor to FACTOR.
-q, --quality PERCENT
Set the video quality to PERCENT (0–9).
--overwrite
Overwrite output file if it exists.
--delay SECONDS
Delay recording for SECONDS seconds.
--pause-shortkey KEY
Set the keyboard shortcut for pausing/unpausing the recording to KEY.
--stop-shortkey KEY
Set the keyboard shortcut for stopping the recording to KEY.
--quit-shortkey KEY
Set the keyboard shortcut for quitting recordmydesktop to KEY.
--help-shortkeys
Show help on the keyboard shortcuts.
--
End of options.

Exit Status

On success, zero is returned. Otherwise, non-zero is returned.

Environment

There are no special environment variables that affect the operation of recordmydesktop.

Files

~/.config/recordmydesktop/recordmydesktoprc
Configuration file.

Notes

recordmydesktop is capable of using vlc, ffmpeg, and ffmpeg2theora to convert the recorded file to other formats.

$ vlc in.ogv --sout '#transcode{vcodec=mp4v,acodec=mp4a,vb=800,ab=128}:std{ access = file, mux=mp4, dst = \"out_512x384.mp4\" }'

This command converts the in.ogv file to an MP4 file named out_512x384.mp4. The video resolution is set to 512x384, and the audio bitrate is set to 128kbps.

$ ffmpeg -i in.ogv -acodec libmp3lame -ab 128 -vcodec mpeg4 -b 800 -s 512x384 out.mp4

This command performs the same conversion as the vlc example.

gst-launch -q --gst-debug-level=1 videotestsrc ! video/x-raw- yuv,width=512,height=384 ! ffenc_theora ! oggmux name=mux ! filesink location=out_512x384.ogv audiotestsrc ! wavenc ! audioconvert ! vorbisenc ! mux.

This command generates a 512x384 video file with Theora and Vorbis codecs, suitable for web publishing.

Another option is ffmpeg2theora(1), which—despite its name—is also a Theora-to-Theora converter. Changing the quality of a recordng with it can be as simple as:

$ ffmpeg2theora infile.ogv -v 3 -a 4 -o outfile.ogv

It can even perform resizing on the geometry of the recording, or change the overall duration.

Bugs

  • Does not record 3D windows if --full-shots isn't specified.
  • Saving 65536 files with the same name will result in unpredictable behavior, which might manifest as an endless loop or a segmentation fault.
