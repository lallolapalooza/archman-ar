runc-start(8)

الحزمة: runc

التراخيص: Apache

runc-start(8) دليل مدير النظام runc-start(8)

الاسم

runc start - بدء حاوية تم إنشاؤها مسبقًا

ملخص

runc start معرّف-الحاوية

الوصف

يقوم الأمر start بتنفيذ العملية المعرفة في config.json داخل حاوية تم إنشاؤها مسبقًا بواسطة runc-create(8).

انظر أيضًا

runc-create(8)، runc(8).
