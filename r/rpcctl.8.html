rpcctl(8)

الحزمة: nfs-utils

التراخيص: GPL-2.0-or-later

rpcctl(8) دليل مدير النظام rpcctl(8)

الاسم

rpcctl - يعرض معلومات اتصال SunRPC

المُلَخَّص

rpcctl [ -h | --help ] { client | switch | xprt }
rpcctl client [ -h | --help ] { show }
rpcctl client show [ -h  --help ] [ XPRT ]
rpcctl switch [ -h | --help ] { set | show }
rpcctl switch add-xprt [ -h | --help ] [ SWITCH ]
rpcctl switch set [ -h | --help ] SWITCH dstaddr NEWADDR
rpcctl switch show [ -h | --help ] [ SWITCH ]
rpcctl xprt [ -h | --help ] { remove | set | show }
rpcctl xprt remove [ -h | --help ] XPRT
rpcctl xprt set [ -h | --help ] XPRT { dstaddr NEWADDR | offline | online }
rpcctl xprt show [ -h | --help ] [ XPRT ]

الوصف

يقوم الأمر rpcctl بعرض المعلومات التي تم جمعها في ملفات SunRPC sysfs حول كائنات SunRPC في النظام.

rpcctl client - أوامر تعمل على عملاء RPC

show [ CLIENT ] (افتراضي)
عرض معلومات مفصلة حول عملاء RPC في هذا النظام. إذا تم توفير CLIENT، فاعرض فقط المعلومات حول عميل RPC واحد.

rpcctl switch - أوامر تعمل على مجموعات من الناقلات

add-xprt SWITCH
إضافة ناقل إضافي إلى SWITCH. لاحظ أن الناقل الجديد سيأخذ قيمه من الناقل "الرئيسي".
set SWITCH dstaddr NEWADDR
تغيير عنوان الوجهة لجميع الناقلات في SWITCH إلى NEWADDR. يمكن أن يكون NEWADDR عنوان IP، اسم DNS، أو أي شيء آخر يمكن حله بواسطة gethostbyname(3).
show [ SWITCH ] (افتراضي)
عرض معلومات مفصلة حول مجموعات الناقلات في هذا النظام. إذا تم توفير SWITCH، فاعرض فقط المعلومات حول مجموعة ناقلات واحدة.

rpcctl xprt - أوامر تعمل على ناقلات فردية

remove XPRT
يزيل XPRT المحدد من النظام. لاحظ أنه لا يمكن إزالة الناقلات "الرئيسية".
set XPRT dstaddr NEWADDR
تغيير عنوان الوجهة لـ XPRT المحدد إلى NEWADDR. يمكن أن يكون NEWADDR عنوان IP، اسم DNS، أو أي شيء آخر يمكن حله بواسطة gethostbyname(3).
set XPRT offline
تعيين حالة XPRT المحدد إلى غير متصل.
set XPRT online
تعيين حالة XPRT المحدد إلى متصل.
show [ XPRT ] (افتراضي)
عرض معلومات مفصلة حول ناقلات هذا النظام. إذا تم توفير XPRT، فاعرض فقط المعلومات حول ناقل واحد.

أمثلة

rpcctl switch show switch-2
عرض التفاصيل حول مفتاح RPC المسمى "switch-2".
rpcctl xprt remove xprt-4
إزالة xprt المسمى "xprt-4" من النظام.
rpcctl xprt set xprt-3 dstaddr https://linux-nfs.org
تغيير عنوان الوجهة لـ xprt المسمى "xprt-3" ليشير إلى linux-nfs.org
