RDMA_POST_WRITE(3) دليل مبرمج Librdmacm RDMA_POST_WRITE(3)

الاسم

rdma_post_write - نشر طلب عمل كتابة RDMA.

الصيغة

#include <rdma/rdma_verbs.h>

int rdma_post_write (struct rdma_cm_id *id, void *context, void *addr, size_t length, struct *mr, int flags, uint64_t remote_addr, uint32_t rkey);

الوسائط

id
مرجع لمعرف الاتصال حيث سيتم نشر الطلب.
context
سياق محدد من قبل المستخدم مرتبط بالطلب.
addr
العنوان المحلي لمصدر طلب الكتابة.
length
طول عملية الكتابة.
mr
منطقة ذاكرة اختيارية مرتبطة بالمخزن المؤقت المحلي.
flags
علامات اختيارية تستخدم للتحكم في عملية الكتابة.
remote_addr
عنوان الذاكرة المسجلة عن بعد للكتابة فيها.
rkey
مفتاح الذاكرة المسجلة المرتبط بالعنوان البعيد.

الوصف

ينشر طلب عمل على طابور الإرسال لزوج الطابور المرتبط بـ rdma_cm_id. سيتم كتابة محتويات المخزن المؤقت للبيانات المحلي في منطقة الذاكرة البعيدة.

قيمة الإرجاع

يعيد 0 عند النجاح، أو -1 عند حدوث خطأ. إذا حدث خطأ، فسيتم تعيين errno للإشارة إلى سبب الفشل.

ملاحظات

للحصول على قائمة بالعلامات المدعومة، راجع ibv_post_send. ما لم يتم تحديد بيانات مضمنة، يجب أن تكون منطقة البيانات المحلية قد تم تسجيلها قبل إصدار الكتابة، ويجب أن تظل المنطقة المسجلة حتى تكتمل الكتابة. يجب دائمًا تسجيل المنطقة البعيدة.

قد لا يتم نشر عمليات الكتابة على rdma_cm_id أو زوج الطابور المقابل حتى يتم توصيله.

سيتم إرجاع السياق المحدد من قبل المستخدم المرتبط بطلب الكتابة إلى المستخدم من خلال حقل wr_id، معرف طلب العمل، في إكمال العمل.
