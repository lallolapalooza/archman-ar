الحزمة: riscv64-linux-gnu-binutils

التراخيص: GPL-2.0-or-later

ADDR2LINE(1) أدوات تطوير GNU ADDR2LINE(1)

الاسم

addr2line - تحويل العناوين أو الرموز+الإزاحات إلى أسماء ملفات وأرقام أسطر

ملخص

addr2line [-a|--addresses]
[-b اسم_ملف_مترجم|--target=اسم_ملف_مترجم]
[-C|--demangle[=نمط]]
[-r|--no-recurse-limit]
[-R|--recurse-limit]
[-e اسم_الملف|--exe=اسم_الملف]
[-f|--functions] [-s|--basename]
[-i|--inlines]
[-p|--pretty-print]
[-j|--section=الاسم]
[-H|--help] [-V|--version]
addr addr ...

الوصف

يقوم addr2line بترجمة العناوين أو الرموز+الإزاحات إلى أسماء ملفات وأرقام أسطر. بالنظر إلى عنوان أو رمز+إزاحة في ملف قابل للتنفيذ أو إزاحة في قسم من كائن قابل للإعادة، فإنه يستخدم معلومات التصحيح لتحديد اسم الملف ورقم السطر المرتبطين به.

يتم تحديد الملف القابل للتنفيذ أو الكائن القابل للإعادة للاستخدام باستخدام الخيار -e. الافتراضي هو الملف a.out. يتم تحديد القسم في الكائن القابل للإعادة للاستخدام باستخدام الخيار -j.

يحتوي addr2line على وضعي تشغيل.

في الوضع الأول، يتم تحديد العناوين الست عشرية أو الرمز+الإزاحة في سطر الأوامر، ويقوم addr2line بعرض اسم الملف ورقم السطر لكل عنوان.

في الوضع الثاني، يقرأ addr2line العناوين الست عشرية أو الرمز+الإزاحة من الإدخال القياسي، ويطبع اسم الملف ورقم السطر لكل عنوان على الإخراج القياسي. في هذا الوضع، يمكن استخدام addr2line في أنبوب لتحويل العناوين المختارة ديناميكيًا.

تنسيق الإخراج هو اسم_الملف:رقم_السطر. افتراضيًا، يولد كل عنوان إدخال سطرًا واحدًا من الإخراج.

يمكن لخيارين إنشاء أسطر إضافية قبل كل سطر اسم_الملف:رقم_السطر (بهذا الترتيب).

إذا تم استخدام الخيار -a، فسيتم عرض سطر مع عنوان الإدخال.

إذا تم استخدام الخيار -f، فسيتم عرض سطر مع اسم_الدالة. هذا هو اسم الدالة التي تحتوي على العنوان.

يمكن لخيار واحد إنشاء أسطر إضافية بعد سطر اسم_الملف:رقم_السطر.

إذا تم استخدام الخيار -i وكان الكود في العنوان المحدد موجودًا بسبب التضمين بواسطة المترجم، فسيتم عرض أسطر إضافية لاحقًا. سيتم عرض سطر أو سطرين إضافيين (إذا تم استخدام الخيار -f) لكل دالة مضمنة.

بدلاً من ذلك، إذا تم استخدام الخيار -p، فإن كل عنوان إدخال ينشئ سطر إخراج واحدًا طويلًا يحتوي على العنوان واسم الدالة واسم الملف ورقم السطر. إذا تم استخدام الخيار -i أيضًا، فسيتم عرض الدوال المضمنة بنفس الطريقة، ولكن على أسطر منفصلة، مسبوقة بنص (مضمن بواسطة).

إذا تعذر تحديد اسم الملف أو اسم الدالة، فسيقوم addr2line بطباعة علامتي استفهام في مكانهما. إذا تعذر تحديد رقم السطر، فسيقوم addr2line بطباعة 0.

عند استخدام الرمز+الإزاحة، فإن +الإزاحة اختيارية، إلا عندما يكون الرمز غامضًا مع رقم سداسي عشري. يمكن أن تكون الرموز المحلولة مرمزة أو غير مرمزة، إلا أن الرموز غير المرمزة مع + غير مسموح بها.

خيارات

الأشكال الطويلة والقصيرة للخيارات، المعروضة هنا كبدائل، متكافئة.

-a
--addresses
يعرض العنوان قبل اسم الدالة، اسم الملف، ومعلومات رقم السطر. تتم طباعة العنوان مسبوقًا بـ 0x لتسهيل التعرف عليه.
-b اسم_ملف_مترجم
--target=اسم_ملف_مترجم
يحدد أن تنسيق الكود الكائن للملفات الكائن هو اسم_ملف_مترجم.
-C
--demangle[=نمط]
فك (demangle) أسماء الرموز ذات المستوى المنخفض إلى أسماء على مستوى المستخدم. بالإضافة إلى إزالة أي شرطة سفلية بادئة يضيفها النظام، هذا يجعل أسماء دوال C++ قابلة للقراءة. تستخدم المترجمات المختلفة أنماط ترميز مختلفة. يمكن استخدام وسيطة نمط فك الترميز الاختيارية لاختيار نمط فك ترميز مناسب لمترجمك.
-e اسم_الملف
--exe=اسم_الملف
يحدد اسم الملف القابل للتنفيذ الذي سيتم ترجمة العناوين له. الملف الافتراضي هو a.out.
-f
--functions
يعرض أسماء الدوال بالإضافة إلى اسم الملف ومعلومات رقم السطر.
-s
--basenames
يعرض فقط الجزء الأساسي من كل اسم ملف.
-i
--inlines
إذا كان العنوان ينتمي إلى دالة تم تضمينها، فسيتم أيضًا طباعة معلومات المصدر لجميع النطاقات المحيطة بالدالة الأصلية غير المضمنة. على سبيل المثال، إذا قامت "main" بتضمين "callee1" التي قامت بتضمين "callee2"، وكان العنوان من "callee2"، فسيتم أيضًا طباعة معلومات المصدر لـ "callee1" و "main".
-j
--section
يقرأ الإزاحات بالنسبة للقسم المحدد بدلاً من العناوين المطلقة.
-p
--pretty-print
يجعل الإخراج أكثر سهولة للقراءة البشرية: تتم طباعة كل موقع على سطر واحد. إذا تم تحديد الخيار -i، فسيتم مسبوقة الأسطر لجميع النطاقات المحيطة بنص (مضمن بواسطة).
-r
-R
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
يمكّن أو يعطّل حدًا لمقدار التكرار الذي يتم تنفيذه أثناء فك ترميز السلاسل. نظرًا لأن تنسيقات ترميز الأسماء تسمح بمستوى لا نهائي من التكرار، فمن الممكن إنشاء سلاسل قد يؤدي فك ترميزها إلى استنفاد مساحة المكدس المتاحة على الجهاز المضيف، مما يؤدي إلى حدوث خطأ في الذاكرة. يحاول الحد منع حدوث ذلك عن طريق تقييد التكرار إلى 2048 مستوى من التداخل.

الافتراضي هو تمكين هذا الحد، ولكن قد يكون تعطيله ضروريًا لفك ترميز الأسماء المعقدة حقًا. لاحظ مع ذلك أنه إذا تم تعطيل حد التكرار، فقد يحدث استنفاد للمكدس وسيتم رفض أي تقارير أخطاء حول مثل هذا الحدث.

الخيار -r هو مرادف للخيار --no-recurse-limit. الخيار -R هو مرادف للخيار --recurse-limit.

لاحظ أن هذا الخيار فعال فقط إذا تم تمكين الخيار -C أو --demangle.

@ملف
يقرأ خيارات سطر الأوامر من ملف. يتم إدراج الخيارات المقروءة في مكان خيار @ملف الأصلي. إذا لم يكن ملف موجودًا، أو لا يمكن قراءته، فسيتم التعامل مع الخيار حرفيًا، ولن تتم إزالته.

يتم فصل الخيارات في ملف بواسطة المسافات البيضاء. يمكن تضمين حرف مسافة بيضاء في خيار عن طريق إحاطة الخيار بالكامل إما بعلامات اقتباس مفردة أو مزدوجة. يمكن تضمين أي حرف (بما في ذلك الخط المائل العكسي) عن طريق وضع البادئة بالحرف الذي سيتم تضمينه. قد يحتوي ملف نفسه على خيارات @ملف إضافية؛ سيتم معالجة أي خيارات من هذا القبيل.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

riscv64-linux-gnu-addr2line(1)

NAME

riscv64-linux-gnu-addr2line - convert addresses to file names and line numbers.

SYNOPSIS

addr2line [-a] [-b obj] [-e progname] [-f] [-i] [-j] [-p] [-R] [-s] [-S] [-t] [--] [<address>...]

DESCRIPTION

The addr2line utility translates addresses into file names and line numbers. It is part of the GNU Binutils package.

It can also be used to find out which functions contain a given address.

When no addresses are specified on the command line, addr2line reads them from the standard input.

OPTIONS

-a
Print the address before each result.
-b obj
Use the object code format specified in obj. This option is only relevant if the linker supports multiple object code formats.
-e progname
Specify the name of the program for which to debug. If this option is not specified, addr2line will use the file specified by the environment variable GMAPS, or if that is not set, the executable specified by the command line argument will be used.
-f
Print the name of the function to which each address belongs.
-i
Print the invocation of the function.
-j
Print the results in a format suitable for use with the gprof profiler. This option is deprecated and will be removed in a future release. Use objdump instead.
-p
Print the results in a human-readable format. This is the default.
-R
Print the results in a reversed format. This option is deprecated and will be removed in a future release. Use objdump instead.
-s
Print only the file name and line number. This option is deprecated and will be removed in a future release. Use objdump instead.
-S
Print the name of the section to which each address belongs.
-t
Print the offset of the address within its section.
--
Signals the end of options, so that addresses that begin with a hyphen can be distinguished from options.
