الاسم

rtcSetGeometryBuildQuality - يحدد جودة البناء للهندسة

ملخص

#include <embree4/rtcore.h>
void rtcSetGeometryBuildQuality(
  RTCGeometry geometry,
  enum RTCBuildQuality quality
);

الوصف

تقوم الدالة rtcSetGeometryBuildQuality بتعيين جودة البناء (المعامل quality) للهندسة المحددة (المعامل geometry). جودة البناء لكل هندسة هي مجرد تلميح وقد يتم تجاهلها. تستخدم Embree حاليًا جودة البناء لكل هندسة عندما يتم تعيين جودة بناء المشهد إلى RTC_BUILD_QUALITY_LOW. في هذا الوضع، يتم بناء هيكل تسلسلي ذي مستويين، وتقوم الهندسات ببناء هيكل تسلسلي منفصل باستخدام جودة بناء الهندسة. يمكن أن تكون جودة البناء لكل هندسة أحد الخيارات التالية:

•
RTC_BUILD_QUALITY_LOW: ينشئ هياكل بيانات ذات جودة أقل، على سبيل المثال للمشاهد الديناميكية.
•
RTC_BUILD_QUALITY_MEDIUM: جودة البناء الافتراضية لمعظم الاستخدامات. توفر حلاً وسطًا جيدًا بين أداء البناء وعرضه.
•
RTC_BUILD_QUALITY_HIGH: ينشئ هياكل بيانات ذات جودة أعلى للعرض النهائي. يمكّن أداة تقسيم مكاني لأنواع بدائية معينة.
•
RTC_BUILD_QUALITY_REFIT: يستخدم نهج إعادة تركيب BVH عند تغيير مخزن الرؤوس فقط.

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.
