Regexp__Common__URI__file(3pm)

الحزمة: perl-regexp-common

التراخيص: PerlArtistic, Artistic2.0, BSD, MIT

Regexp::Common::URI::file(3) توثيق Perl مقدم من المستخدم Regexp::Common::URI::file(3)

الاسم

Regexp::Common::URI::file -- يعيد نمطًا لمعرفات URI للملفات.

الملخص

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{file}/       and  print "يحتوي على معرف URI للملف.\n";
}

الوصف

$RE{URI}{file}

يعيد نمطًا يطابق معرفات URI للملفات، كما هو محدد في RFC 1738. معرفات URI للملفات لها الشكل:

"file:" "//" [ host | "localhost" ] "/" fpath

تحت "{-keep}"، يتم إرجاع ما يلي:

$1
معرف URI الكامل.
$2
المخطط.
$3
الجزء من معرف URI الذي يلي "file://".
$4
اسم المضيف.
$5
اسم المسار، بما في ذلك الشرطة المائلة البادئة.
$6
اسم المسار، بدون الشرطة المائلة البادئة.

المراجع

[RFC 1738]
Berners-Lee, Tim, Masinter, L., McCahill, M.: Uniform Resource Locators (URL). December 1994.

انظر أيضًا

Regexp::Common::URI لمعرفات URI المدعومة الأخرى.
