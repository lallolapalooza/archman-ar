الحزمة: iproute2

RDMA-RESOURCE(8) Linux RDMA-RESOURCE(8)

اسم

rdma-resource - تكوين موارد rdma

الملخص


rdma [ خيارات ] مورد { أمر | مساعدة }

مورد := { cm_id | cq | mr | pd | qp | ctx | srq }

خيارات := { -j[son] | -d[etails] }

rdma resource show [ DEV/PORT_INDEX ]

rdma resource help

الوصف

rdma resource show - عرض معلومات تتبع موارد rdma

DEV/PORT_INDEX - يحدد رابط RDMA المطلوب عرضه. إذا تم تجاوز هذه الوسيطة، فسيتم سرد جميع الروابط.

أمثلة

rdma resource show

يعرض ملخصًا لجميع الأجهزة على النظام.

rdma resource show mlx5_2

يعرض حالة جهاز rdma المحدد.

rdma res show qp link mlx5_4

الحصول على جميع QPs للجهاز المحدد.

rdma res show qp link mlx5_4/1

الحصول على QPs لمنفذ معين.

rdma res show qp link mlx5_4/0

تقديم رقم منفذ غير صالح (0 غير صالح).

rdma res show qp link mlx5_4/-

الحصول على QPs التي لم يتم تخصيص منفذ لها بعد.

rdma res show qp link mlx5_4/- -d

عرض تفصيلي.

rdma res show qp link mlx5_4/- -dd

عرض تفصيلي بما في ذلك التفاصيل الخاصة بالبرنامج التشغيل.

rdma res show qp link mlx5_4/1 lqpn 0-6

الحد إلى QPNs محلية محددة.

rdma res show qp link mlx5_4/1 lqpn 6 -r

تفاصيل خاصة بالبرنامج التشغيل بتنسيق خام.

rdma resource show cm_id dst-port 7174

عرض CM_IDs مع منفذ ip وجهة 7174.

rdma resource show cm_id src-addr 172.16.0.100

عرض CM_IDs المرتبطة بعنوان ip محلي 172.16.0.100

rdma resource show cq pid 30489

عرض CQs التي تنتمي إلى pid 30489

rdma resource show ctx ctxn 1

عرض السياقات التي يكون فهرسها مساويًا لـ 1.

rdma resource show srq lqpn 5-7

عرض SRQs التي ترتبط بها QPs ذات lqpn 5-7.

انظر أيضًا

rdma(8)، rdma-dev(8)، rdma-link(8)، rdma-statistic(8)،
