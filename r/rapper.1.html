rapper(1)

NAME

rapper - Raptor RDF parser and serializer

SYNOPSIS

rapper [OPTION...] [URI...]

EXAMPLE

rapper http://example.com/foo.rdf

DESCRIPTION

rapper is a command line tool that parses RDF serialisations from a given URI or multiple URIs and serialises the result using a given serializer, to a given output destination.

rapper is part of the raptor RDF syntax library.

OPTIONS

rapper supports the following options:

-h, --help

Show help message and exit.

-v, --version

Show version information and exit.

-i, --input FORMAT

Parse input in FORMAT. If not specified, raptor will try to guess the input format from the URI.

-o, --output FORMAT

Serialize output in FORMAT. If not specified, raptor will default to N-Triples.

-f, --input-encoding ENCODING

Specify the character encoding of the input.

-u, --output-encoding ENCODING

Specify the character encoding of the output.

-t, --output-type TYPE

Specify the MIME type of the output. This is useful if the serializer can produce multiple MIME types.

-s, --output-as-string

Output the serialized RDF as a string.

--output-is-uri

Treat the output destination as a URI.

--base-uri URI

Set the base URI for the input URIs.

--syntax-error-term TYPE

Set the type of term to use for syntax errors. Valid types are: blank, literal, nodeid, uri.

--syntax-error-term-value VALUE

Set the value of the term to use for syntax errors.

--syntax-error-term-language LANGUAGE

Set the language of the literal term to use for syntax errors.

--syntax-error-term-datatype DATATYPE

Set the datatype of the literal term to use for syntax errors.

--dereference-scheme SCHEME

Specify the URI scheme to dereference. This option can be specified multiple times.

--no-dereference-scheme SCHEME

Do not dereference URI scheme. This option can be specified multiple times.

--ignore-base

Do not use the base URI specified in the input document.

--no-network

Do not use the network.

--query SPARQL

Run a SPARQL query on the parsed RDF.

--query-language LANGUAGE

Specify the language of the SPARQL query. Defaults to SPARQL.

--query-output FORMAT

Serialize the SPARQL query results in FORMAT.

--query-base-uri URI

Set the base URI for the SPARQL query.

EXAMPLES

rapper http://example.com/foo.rdf -o turtle
rapper http://example.com/foo.rdf -o rdfxml-abbrev > foo.rdf
rapper -i turtle -o html < foo.turtle

CONFORMING TO

rapper conforms to the Raptor RDF Syntax Library API.
