rtcSetGeometryTransformQuaternion.3embree3

الحزمة: embree3

التراخيص: Apache

rtcSetGeometryTransformQuaternion(3) Embree Ray Tracing Kernels 3 rtcSetGeometryTransformQuaternion(3)

الاسم

rtcSetGeometryTransformQuaternion - تعيين التحويل لخطوة زمنية معينة لهندسة نسخة، مع تحليل مصفوفة التحويل باستخدام الكواتيرنيونات لتمثيل الدوران.

الملخص

#include <embree3/rtcore.h>
void rtcSetGeometryTransformQuaternion(
  RTCGeometry geometry,
  unsigned int timeStep,
  const struct RTCQuaternionDecomposition* qd
);

الوصف

تقوم الدالة rtcSetGeometryTransformQuaternion بتعيين التحويل الأفيني من المحلي إلى العالمي (المعلمة qd) لهندسة نسخة (المعلمة geometry) لخطوة زمنية معينة (المعلمة timeStep). يتم تحديد التحويل كـ [RTCQuaternionDecomposition]، وهو تحليل للتحويل الأفيني يمثل المكون الدوراني للتحويل الأفيني ككواتيرنيون. هذا يسمح بالاستيفاء بين التحويلات الدورانية بدقة باستخدام الاستيفاء الخطي الكروي (مثل عجلة دوارة).

لمزيد من المعلومات حول التحليل، راجع [RTCQuaternionDecomposition]. سيتم تطبيع الكواتيرنيون الموجود في بنية RTCQuaternionDecomposition داخليًا.

للحصول على نتائج صحيحة، يجب تعيين مصفوفات التحويل لجميع الخطوات الزمنية إما باستخدام rtcSetGeometryTransform أو rtcSetGeometryTransformQuaternion. لا يُسمح بخلط التمثيلين. سيتم استخدام الاستيفاء الخطي الكروي إذا تم تعيين مصفوفات التحويل باستخدام rtcSetGeometryTransformQuaternion.

كمثال على هذه الميزة، راجع البرنامج التعليمي [Quaternion Motion Blur].

حالة الخروج

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.

راجع أيضاً

[rtcInitQuaternionDecomposition]، [rtcSetGeometryTransform]
