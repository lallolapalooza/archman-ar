الاسم

Regexp::Common::number -- توفير تعبيرات نمطية للأرقام

الملخص

use Regexp::Common qw /number/;
while (<>) {
    /^$RE{num}{int}$/                and  print "عدد صحيح\n";
    /^$RE{num}{real}$/               and  print "عدد حقيقي\n";
    /^$RE{num}{real}{-base => 16}$/  and  print "عدد حقيقي سداسي عشري\n";
}

الوصف

انظر وثائق man الخاصة بـ Regexp::Common للحصول على نظرة عامة على وظائف هذا الواجهة.

لا تستخدم هذه الوحدة مباشرة، ولكن قم بتحميلها عبر Regexp::Common.

"$RE{num}{int}{-base}{-sep}{-group}{-places}{-sign}"

يعيد نمطًا يتطابق مع عدد صحيح.

إذا تم تحديد "-base => B"، فإن العدد الصحيح يكون بالأساس B، حيث "2 <= B <= 36". بالنسبة للأسس الأكبر من 10، يتم استخدام الأحرف الكبيرة. القيمة الافتراضية لـ B هي 10.

إذا تم تحديد "-sep => P"، فإن النمط P مطلوب كعلامة فاصلة داخل الرقم. إذا لم يتم تحديد هذا الخيار، فلن يتم استخدام أي علامة فاصلة.

إذا تم تحديد "-group => N"، فيجب تجميع الأرقام بين علامات الفاصلة في تسلسلات تتكون من N أرقام بالضبط. القيمة الافتراضية لـ N هي 3. إذا تم تحديد "-group => N,M"، فيجب تجميع الأرقام بين علامات الفاصلة في تسلسلات لا تقل عن N أرقام ولا تزيد عن M أرقام. يتم تجاهل هذا الخيار إذا تم استخدام الخيار "-sep".

إذا تم تحديد "-places => N"، فيجب أن يتكون الرقم المطابق من N أرقام بالضبط. إذا تم تحديد "-places => N,M"، فيجب أن يتكون الرقم من N أرقام على الأقل و M أرقام على الأكثر. لا توجد قيمة افتراضية، مما يعني أن الأرقام غير محدودة الطول. يتم تجاهل هذا الخيار إذا تم استخدام الخيار "-sep".

إذا تم تحديد "-sign => P"، فهذا نمط يجب أن يتطابق مع علامة الرقم البادئة. يتم تعيين هذا افتراضيًا على "[-+]?"، مما يعني أن الرقم قد يسبقه علامة ناقص أو علامة زائد اختياريًا. إذا كنت ترغب في مطابقة الأعداد الصحيحة غير الموقعة، فاستخدم "$RE{num}{int}{-sign => ''}".

على سبيل المثال:

$RE{num}{int}                          # يتطابق مع 1234567
$RE{num}{int}{-sep=>','}               # يتطابق مع 1,234,567
$RE{num}{int}{-sep=>',?'}              # يتطابق مع 1234567 أو 1,234,567
$RE{num}{int}{-sep=>'.'}{-group=>4}    # يتطابق مع 1.2345.6789

"$RE{num}{real}{-base}{-radix}{-places}{-sep}{-group}{-expon}"

يعيد نمطًا يتطابق مع عدد عشري.

إذا تم تحديد "-base=N"، يُفترض أن العدد بهذا الأساس (مع تمثيل A..Z للأرقام من 11..36). افتراضيًا، الأساس هو 10.

إذا تم تحديد "-radix=P"، يتم استخدام النمط P كنقطة جذرية للعدد (أي نقطة عشرية في الأساس 10). القيمة الافتراضية هي "qr/[.]/".

إذا تم تحديد "-places=N"، يُفترض أن العدد يحتوي على N منازل بالضبط بعد نقطة الجذرية. إذا تم تحديد "-places=M,N"، يُفترض أن العدد يحتوي على ما بين M و N منازل بعد نقطة الجذرية. افتراضيًا، عدد المنازل غير محدود.

إذا تم تحديد "-sep=P"، فإن النمط P مطلوب كعلامة فاصلة ضمن كتلة نقطة الجذرية للعدد. افتراضيًا، لا يُسمح بأي فاصل.

إذا تم تحديد "-group=N"، فيجب تجميع الأرقام بين علامات الفاصلة في تسلسلات تتكون من N حرفًا بالضبط. القيمة الافتراضية لـ N هي 3.

إذا تم تحديد "-expon=P"، يتم استخدام النمط P كعلامة أس. القيمة الافتراضية لـ P هي "qr/[Ee]/".

إذا تم تحديد "-sign=P"، يتم استخدام النمط P لمطابقة العلامة البادئة (وعلامة الأس). يتم تعيين هذا افتراضيًا على "[-+]?"، مما يعني أنه يمكن استخدام علامة زائد أو ناقص اختيارية.

على سبيل المثال:

$RE{num}{real}                  # يتطابق مع 123.456 أو -0.1234567
$RE{num}{real}{-places=>2}      # يتطابق مع 123.45 أو -0.12
$RE{num}{real}{-places=>'0,3'}  # يتطابق مع 123.456 أو 0 أو 9.8
$RE{num}{real}{-sep=>'[,.]?'}   # يتطابق مع 123,456 أو 123.456
$RE{num}{real}{-base=>3'}       # يتطابق مع 121.102

NAME

Regexp::Common::number - Regexp::Common regular expressions for numbers

SYNOPSIS

$RE{num}{decimal} # matches 123.456 or -0.1234567
$RE{num}{decimal}{-places=>2} # matches 123.45 or -0.12
$RE{num}{decimal}{-places=>'0,3'} # matches 123.456 or 0 or 9.8
$RE{num}{decimal}{-sep=>'[,.]?'} # matches 123,456 or 123.456
$RE{num}{decimal}{-base=>3} # matches 121.102
$RE{num}{square} # matches 1, 4, 9, 16, etc.
$RE{num}{roman} # matches I, II, III, IV, V, VI, etc.

DESCRIPTION

This module provides regular expressions for matching various kinds of numbers.

"$RE{num}{decimal}"

This returns a regular expression that matches a valid decimal number, possibly with a leading sign and possibly with a fractional part. It may also match numbers in other bases, or have specific requirements on the number of decimal places, or on the presence/format of group separators.

See the following options, which are identical to the options for $RE{num}{real}, except that an exponent is not allowed:

  • -base=N
  • -radix=P
  • -places=N
  • -sep=P
  • -group=N

If "-base=N" is specified, the number is assumed to be in that base (with A..Z representing the digits for 11..36). By default, the base is 10.

If "-radix=P" is specified, the pattern P is used as the radix point for the number (i.e. the "decimal point" in base 10). The default is "qr/[.]/".

If "-places=N" is specified, the number is assumed to have exactly N places after the radix point. If "-places=M,N" is specified, the number is assumed to have between M and N places after the radix point. By default, the number of places is unrestricted.

If "-sep=P" specified, the pattern P is required as a grouping marker within the pre-radix section of the number. By default, no separator is allowed.

If "-group=N" is specified, digits between grouping separators must be grouped in sequences of exactly N characters. The default value of N is 3.

For example:

$RE{num}{decimal}                  # matches 123.456 or -0.1234567
$RE{num}{decimal}{-places=>2}      # matches 123.45 or -0.12
$RE{num}{decimal}{-places=>'0,3'}  # matches 123.456 or 0 or 9.8
$RE{num}{decimal}{-sep=>'[,.]?'}   # matches 123,456 or 123.456
$RE{num}{decimal}{-base=>3}       # matches 121.102

Under "-keep":

$1
captures the entire match
$2
captures the optional sign of the number
$3
captures the complete mantissa
$4
captures the whole number portion of the mantissa
$5
captures the radix point
$6
captures the fractional portion of the mantissa

"$RE{num}{square}"

Returns a pattern that matches a (decimal) square. Because Perl's arithmetic is lossy when using integers over about 53 bits, this pattern only recognizes numbers less than 9000000000000000, if one uses a Perl that is configured to use 64 bit integers. Otherwise, the limit is 2147483647. These restrictions were introduced in versions 2.116 and 2.117 of Regexp::Common. Regardless whether "-keep" was set, the matched number will be returned in $1.

"$RE{num}{roman}"

Returns a pattern that matches an integer written in Roman numbers. Case doesn't matter. There is no unique way of writing Roman numerals, but we will not match anything. We require the Roman numerals to list the symbols in order (largest first). The symbols for thousand ("M"), hundred ("C"), ten ("X"), and one ("I") can not be repeated more than four times. The symbols for five hundred ("D"), fifty ("L"), and five ("V") may not appear more than once. A sequence of four repeated characters may also be written as a subtraction: by using the repeated character just once, and have it followed by the symbol which is 5 or 10 as large. So, four can be written as "IIII", or as "IV", and nine may be written as "VIIII" or "IX". This corresponds to most modern uses of Roman numerals.

The largest number which will be matched is 4999, or "MMMMDCCCCLXXXXVIIII", or "MMMMCMXCIX".

Under "-keep", the number will be captured in $1.
