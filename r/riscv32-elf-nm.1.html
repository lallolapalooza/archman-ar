الوصف

يعرض GNU nm الرموز من الملفات الكائنة objfile.... إذا لم يتم إدراج أي ملفات كائنة كوسائط، يفترض nm الملف a.out.

لكل رمز، يعرض nm:

  • قيمة الرمز، بالأساس المحدد بالخيارات (انظر أدناه)، أو بالنظام الست عشري افتراضياً.
  • نوع الرمز. على الأقل، تُستخدم الأنواع التالية؛ توجد أنواع أخرى أيضاً، اعتماداً على تنسيق الملف الكائني. إذا كان الحرف صغيراً، فالرمز عادة ما يكون محلياً؛ إذا كان حرفاً كبيراً، فالرمز عالمي (خارجي). ومع ذلك، هناك عدد قليل من الرموز الصغيرة التي تُعرض للرموز العالمية الخاصة ("u"، "v"، و "w").
"A"
قيمة الرمز مطلقة، ولن تتغير بفعل الربط الإضافي.
"B"
"b"
الرمز موجود في قسم بيانات BSS. هذا القسم عادة ما يحتوي على بيانات مهيأة بالصفر أو غير مهيأة، على الرغم من أن السلوك الدقيق يعتمد على النظام.
"C"
"c"
الرمز شائع. الرموز الشائعة هي بيانات غير مهيأة. عند الربط، قد تظهر رموز شائعة متعددة بنفس الاسم. إذا تم تعريف الرمز في أي مكان، تُعامل الرموز الشائعة على أنها مراجع غير محددة. يُستخدم الحرف الصغير c عندما يكون الرمز في قسم خاص للرموز الشائعة الصغيرة.
"D"
"d"
الرمز موجود في قسم البيانات المهيأة.
"G"
"g"
الرمز موجود في قسم بيانات مهيأ للكائنات الصغيرة. تسمح بعض تنسيقات الملفات الكائنة بالوصول بشكل أكثر كفاءة إلى كائنات البيانات الصغيرة، مثل متغير صحيح عالمي بدلاً من مصفوفة عالمية كبيرة.
"i"
بالنسبة لملفات تنسيق PE، يشير هذا إلى أن الرمز موجود في قسم خاص بتنفيذ DLLs.

بالنسبة لملفات تنسيق ELF، يشير هذا إلى أن الرمز هو دالة غير مباشرة. هذا امتداد لـ GNU لمجموعة أنواع رموز ELF القياسية. يشير إلى رمز، إذا تم الإشارة إليه بواسطة إعادة تموضع، فلن يؤدي إلى عنوانه، بل يجب استدعاؤه في وقت التشغيل. سيقوم التنفيذ وقت التشغيل بإرجاع القيمة التي سيتم استخدامها في إعادة التموضع.

ملاحظة - يتم التحكم في عرض الرموز الفعلية لرموز GNU غير المباشرة بواسطة خيار سطر الأوامر --ifunc-chars. إذا تم توفير هذا الخيار، فإن الحرف الأول في السلسلة سيتم استخدامه لرموز الدوال غير المباشرة العالمية. إذا احتوت السلسلة على حرف ثانٍ، فسيتم استخدامه لرموز الدوال غير المباشرة المحلية.

"I"
الرمز هو مرجع غير مباشر لرمز آخر.
"N"
الرمز هو رمز تصحيح.
"n"
الرمز موجود في قسم غير بيانات، غير كود، غير تصحيح للقراءة فقط.
"p"
الرمز موجود في قسم إلغاء تكديس المكدس.
"R"
"r"
الرمز موجود في قسم بيانات للقراءة فقط.
"S"
"s"
الرمز موجود في قسم بيانات غير مهيأ أو مهيأ بالصفر للكائنات الصغيرة.
"T"
"t"
الرمز موجود في قسم النص (الكود).
"U"
الرمز غير محدد.
"u"
الرمز هو رمز عالمي فريد. هذا امتداد لـ GNU لمجموعة ربط رموز ELF القياسية. لمثل هذا الرمز، سيضمن رابط الديناميكي أنه في العملية بأكملها يوجد رمز واحد فقط بهذا الاسم والنوع قيد الاستخدام.
"V"
"v"
الرمز هو كائن ضعيف. عند ربط رمز معرف ضعيف برمز معرف عادي، يتم استخدام الرمز العادي المعرف دون خطأ. عند ربط رمز غير معرف ضعيف وعدم تعريف الرمز، تصبح قيمة الرمز الضعيف صفراً دون خطأ. في بعض الأنظمة، تشير الأحرف الكبيرة إلى أنه تم تحديد قيمة افتراضية.
"W"
"w"
الرمز هو رمز ضعيف لم يتم تحديده صراحة كرمز كائن ضعيف. عند ربط رمز معرف ضعيف برمز معرف عادي، يتم استخدام الرمز العادي المعرف دون خطأ. عند ربط رمز غير معرف ضعيف وعدم تعريف الرمز، يتم تحديد قيمة الرمز بطريقة خاصة بالنظام دون خطأ. في بعض الأنظمة، تشير الأحرف الكبيرة إلى أنه تم تحديد قيمة افتراضية.
"-"
الرمز هو رمز stabs في ملف كائني a.out. في هذه الحالة، القيم التالية المعروضة هي حقل stabs الآخر، وحقل desc stabs، ونوع stab. تُستخدم رموز stabs للاحتفاظ بمعلومات التصحيح.
"?"
نوع الرمز غير معروف، أو خاص بتنسيق الملف الكائني.
•
اسم الرمز. إذا كان هناك معلومات إصدار مرتبطة بالرمز، فسيتم عرض معلومات الإصدار أيضاً. إذا كان الرمز ذو الإصدار غير محدد أو مخفياً عن الرابط، فسيتم عرض سلسلة الإصدار كلاحقة لاسم الرمز، مسبوقة بحرف @. على سبيل المثال foo@VER_1. إذا كان الإصدار هو الإصدار الافتراضي الذي سيتم استخدامه عند حل المراجع غير ذات الإصدار للرمز، فسيتم عرضه كلاحقة مسبوقة بحرفي @. على سبيل المثال foo@@VER_2.

الخيارات

الأشكال الطويلة والقصيرة للخيارات، المعروضة هنا كبدائل، متكافئة.

-A
-o
--print-file-name
سبق كل رمز باسم الملف المدخل (أو عضو الأرشيف) الذي تم العثور عليه فيه، بدلاً من تحديد الملف المدخل مرة واحدة فقط، قبل جميع رموزه.
-a
--debug-syms
عرض جميع الرموز، بما في ذلك رموز المصحح فقط؛ عادة ما لا يتم سرد هذه.
-B
نفس --format=bsd (للتوافق مع nm الخاص بـ MIPS).
-C
--demangle[=style]
فك تشفير (demangle) أسماء الرموز منخفضة المستوى إلى أسماء على مستوى المستخدم. بالإضافة إلى إزالة أي شرطة سفلية بادئة يضيفها النظام، هذا يجعل أسماء دوال C++ قابلة للقراءة. تختلف المترجمات في أنماط التشفير المختلفة. يمكن استخدام وسيطة نمط فك التشفير الاختيارية لاختيار نمط فك التشفير المناسب للمترجم الخاص بك.
--no-demangle
لا تقم بفك تشفير أسماء الرموز منخفضة المستوى. هذا هو الإعداد الافتراضي.
--recurse-limit
--no-recurse-limit
--recurse-limit
--no-recurse-limit
--recursion-limit
--no-recursion-limit
تُمكّن أو تُعطّل حدًا لمقدار الاستدعاء الذاتي الذي يتم إجراؤه أثناء فك ترميز السلاسل النصية. نظرًا لأن تنسيقات ترميز الأسماء تسمح بمستوى لا نهائي من الاستدعاء الذاتي، فمن الممكن إنشاء سلاسل نصية قد يؤدي فك تشفيرها إلى استنفاد مساحة المكدس المتاحة على الجهاز المضيف، مما يؤدي إلى حدوث خطأ في الذاكرة. يحاول الحد منع حدوث ذلك عن طريق تقييد الاستدعاء الذاتي إلى 2048 مستوى من التداخل.

الافتراضي هو تمكين هذا الحد، ولكن قد يكون تعطيله ضروريًا لفك ترميز الأسماء المعقدة حقًا. لاحظ مع ذلك أنه إذا تم تعطيل حد الاستدعاء الذاتي، فقد يحدث استنفاد للمكدس وسيتم رفض أي تقارير أخطاء حول هذا الحدث.

-D
--dynamic
لعرض الرموز الديناميكية بدلاً من الرموز العادية. هذا له معنى فقط للكائنات الديناميكية، مثل أنواع معينة من المكتبات المشتركة.
-f format
--format=format
استخدم تنسيق الإخراج format، والذي يمكن أن يكون "bsd"، "sysv"، "posix" أو "just-symbols". الافتراضي هو "bsd". الحرف الأول فقط من format له أهمية؛ يمكن أن يكون إما حرفًا كبيرًا أو صغيرًا.
-g
--extern-only
لعرض الرموز الخارجية فقط.
-h
--help
لعرض ملخص للخيارات المتاحة لـ nm والخروج.
--ifunc-chars=CHARS
عند عرض رموز دوال GNU غير المباشرة، ستستخدم nm افتراضيًا الحرف "i" لكل من الدوال غير المباشرة المحلية والدوال غير المباشرة العامة. يتيح الخيار --ifunc-chars للمستخدم تحديد سلسلة تحتوي على حرف أو حرفين. سيتم استخدام الحرف الأول لرموز الدوال غير المباشرة العامة، وسيتم استخدام الحرف الثاني، إذا كان موجودًا، لرموز الدوال غير المباشرة المحلية.
j
نفس الأمر --format=just-symbols.
-l
--line-numbers
لكل رمز، استخدم معلومات التصحيح للعثور على اسم ملف ورقم سطر. بالنسبة للرمز المحدد، ابحث عن رقم سطر عنوان الرمز. بالنسبة للرمز غير المحدد، ابحث عن رقم سطر إدخال إعادة التعيين الذي يشير إلى الرمز. إذا تم العثور على معلومات رقم السطر، فقم بطباعتها بعد معلومات الرمز الأخرى.
--inlines
عندما يكون الخيار -l نشطًا، إذا كان العنوان ينتمي إلى دالة تم تضمينها (inlined)، فإن هذا الخيار يتسبب في طباعة معلومات المصدر لجميع النطاقات المغلفة وصولاً إلى أول دالة غير مضمنة أيضًا. على سبيل المثال، إذا قامت "main" بتضمين "callee1" التي بدورها قامت بتضمين "callee2"، وكان العنوان من "callee2"، فسيتم أيضًا طباعة معلومات المصدر لـ "callee1" و "main".
-n
-v
--numeric-sort
لفرز الرموز رقميًا حسب عناوينها، بدلاً من فرزها أبجديًا حسب أسمائها.
-p
--no-sort
لا تهتم بفرز الرموز بأي ترتيب؛ اطبعها بالترتيب الذي تم العثور عليها به.
-P
--portability
استخدم تنسيق الإخراج القياسي POSIX.2 بدلاً من التنسيق الافتراضي. يعادل -f posix.
-r
--reverse-sort
لعكس ترتيب الفرز (سواء كان رقميًا أو أبجديًا)؛ اجعل الأخير يأتي أولاً.
-S
--print-size
لطباعة كل من قيمة وحجم الرموز المحددة لنمط الإخراج "bsd". هذا الخيار ليس له تأثير على تنسيقات الكائنات التي لا تسجل أحجام الرموز، إلا إذا تم استخدام --size-sort أيضًا، وفي هذه الحالة يتم عرض حجم محسوب.

ملاحظة - هذا الخيار لا يعمل إذا تم تمكين --undefined-only لأن الرموز غير المحددة ليس لها حجم.

-s
--print-armap
عند سرد الرموز من أعضاء الأرشيف، قم بتضمين الفهرس: خريطة (مخزنة في الأرشيف بواسطة ar أو ranlib) توضح أي الوحدات تحتوي على تعريفات لأي أسماء.
-t radix
--radix=radix
استخدم radix كأساس لطباعة قيم الرموز. يجب أن يكون d للعشرية، o للثمانية، أو x للسداسي عشري.
-u
--undefined-only
لعرض الرموز غير المحددة فقط (تلك الخارجية لكل ملف كائن). افتراضيًا، يتم عرض كل من الرموز المحددة وغير المحددة.
-U
--defined-only
لعرض الرموز المحددة فقط لكل ملف كائن. افتراضيًا، يتم عرض كل من الرموز المحددة وغير المحددة.
-V
--version
لعرض رقم إصدار nm والخروج.
-X
يتم تجاهل هذا الخيار للتوافق مع إصدار AIX من nm. يأخذ معاملًا واحدًا يجب أن يكون السلسلة النصية 32_64. يتوافق الوضع الافتراضي لـ AIX nm مع -X 32، والذي لا تدعمه GNU nm.
--plugin name
لتحميل المكون الإضافي المسمى name لدعم أنواع مستهدفة إضافية. هذا الخيار متاح فقط إذا تم بناء مجموعة الأدوات مع تمكين دعم المكونات الإضافية.

إذا لم يتم توفير --plugin، ولكن تم تمكين دعم المكونات الإضافية، فإن nm يتكرر عبر الملفات في ${libdir}/bfd-plugins بترتيب أبجدي، ويتم استخدام أول مكون إضافي يدعي الكائن المعني.

يرجى ملاحظة أن دليل البحث عن المكونات الإضافية هذا *ليس* هو نفسه المستخدم بواسطة خيار -plugin الخاص بـ ld. لكي يستخدم nm المكون الإضافي للرابط، يجب نسخه إلى دليل ${libdir}/bfd-plugins. لعمليات التصريف المستندة إلى GCC، يسمى المكون الإضافي للرابط liblto_plugin.so.0.0.0. لعمليات التصريف المستندة إلى Clang، يسمى LLVMgold.so. المكون الإضافي GCC متوافق دائمًا مع الإصدارات السابقة، لذا يكفي مجرد نسخ أحدث واحد.

--size-sort
لفرز الرموز حسب الحجم. بالنسبة لكائنات ELF، يتم قراءة أحجام الرموز من ELF، بالنسبة لأنواع الكائنات الأخرى، يتم حساب أحجام الرموز كفرق بين قيمة الرمز وقيمة الرمز ذي القيمة الأعلى التالية. إذا تم استخدام تنسيق الإخراج "bsd"، فسيتم طباعة حجم الرمز، بدلاً من القيمة، ويجب استخدام -S لطباعة كل من الحجم والقيمة.

ملاحظة - هذا الخيار لا يعمل إذا تم تمكين --undefined-only لأن الرموز غير المحددة ليس لها حجم.

--special-syms
لعرض الرموز التي لها معنى خاص خاص بالهدف. تُستخدم هذه الرموز عادةً بواسطة الهدف لمعالجة خاصة ولا تكون مفيدة بشكل طبيعي عند تضمينها في قوائم الرموز العادية. على سبيل المثال، بالنسبة لأهداف ARM، سيتخطى هذا الخيار رموز التعيين المستخدمة لتحديد الانتقالات بين شفرة ARM، وشفرة THUMB، والبيانات.
--synthetic
لتضمين الرموز الاصطناعية في الإخراج. هذه رموز خاصة ينشئها الرابط لأغراض مختلفة. لا يتم عرضها افتراضيًا لأنها ليست جزءًا من شفرة المصدر الأصلية للملف الثنائي.
--unicode=[default|invalid|locale|escape|hex|highlight]
للتحكم في عرض الأحرف متعددة البايتات المشفرة بـ UTF-8 في السلاسل النصية. الافتراضي (--unicode=default) هو عدم إعطائها أي معاملة خاصة. الخيار --unicode=locale يعرض التسلسل في الإعداد المحلي الحالي، والذي قد يدعمه أو لا يدعمه. الخيارات --unicode=hex و --unicode=invalid تعرضها كسلاسل بايت ست عشري محاطة إما بأقواس زاوية أو أقواس متعرجة.

الخيار --unicode=escape يعرضها كسلاسل هروب (\uxxxx) والخيار --unicode=highlight يعرضها كسلاسل هروب مميزة باللون الأحمر (إذا كان الجهاز الطرفي يدعم ذلك). الغرض من التلوين هو لفت الانتباه إلى وجود تسلسلات يونيكود حيث قد لا تكون متوقعة.

-W
--no-weak
لعدم عرض الرموز الضعيفة.
--with-symbol-versions
--without-symbol-versions
لتُمكّن أو تُعطّل عرض معلومات إصدار الرمز. يتم عرض سلسلة الإصدار كلاحقة لاسم الرمز، مسبوقة بحرف @. على سبيل المثال
nm(1) - Arch Linux

NAME

nm - list symbols from object files

SYNOPSIS

nm [-a|--debug-syms] [-g|--external-only] [-l|--line-numbers] [-p|--no-sort] [-P|--portability] [-r|--reverse-sort] [-S|--print-size] [-t radix|--radix=radix] [-u|--undefined-only] [-x|--demangle[=style]] [--dynamic] [--extern-only] [--help] [--imported-symbols] [--no-demangle] [--no-recurse-directories] [--no-sort] [--print-file-names] [--size-sort] [--sort=key] [--undefined-only] [--version] [-B] [-o] [-X linker] [--target=bfdname] [-dynamic-linker] [-emulation] [objfile...]

DESCRIPTION

The nm utility displays the symbols from object files. By default, it lists the symbols for each object file in the specified order. If multiple object files are specified, the symbols are sorted together.

The symbol information is output in the following format:

The address of the symbol.
The symbol type, in uppercase (except for undefined symbols, which are in lowercase).
The symbol name.

The symbol types are:

a
The symbol is in the absolute symbol table. This is usually used for constants.
A
The symbol is in the absolute symbol table. This is usually used for constants.
b
The symbol is in the uninitialized data section. This section is usually called the BSS section.
B
The symbol is in the uninitialized data section. This section is usually called the BSS section.
c
The symbol is in the common symbol table. Common symbols are uninitialized variables like variables declared in C.
C
The symbol is in the common symbol table. Common symbols are uninitialized variables like variables declared in C.
d
The symbol is in the initialized data section. This section is usually called the data section.
D
The symbol is in the initialized data section. This section is usually called the data section.
i

OPTIONS

-a
--debug-syms
Do not display any symbols other than those in the debug symbol table.
-g
--external-only
Only display external symbols.
-l
--line-numbers
For each symbol, print its entry in the symbol table and the corresponding line number, if any, in the source file. If the object file was not stripped, the symbols are the addresses of the function names and the static variables. If the object file was stripped, the symbols are the addresses of the public functions.
-p
--no-sort
Do not sort the symbols. The symbols are listed in the order they appear in the object file.
-P
--portability
Print the name of each symbol, followed by its symbol type, followed by its value. This is intended to be compatible with the output of the version of nm found in POSIX.1.
-r
--reverse-sort
Sort the symbols in reverse order.
-S
--print-size
Print the size of each symbol.
-t
--radix=radix
Use radix for displaying the addresses. The default radix is hexadecimal.
-u
--undefined-only
Only display undefined symbols.
-x
--demangle[=style]
Demangle C++ symbol names. The optional style argument specifies the demangling style to use. If no style is specified, the default style is used.
--dynamic
Display symbols from the dynamic symbol table.
--imported-symbols
Display imported symbols.
--no-demangle
Do not demangle C++ symbol names.
--no-recurse-directories
Do not recurse into directories.
--print-file-names
Print the name of each object file before its symbols.
--size-sort
Sort the symbols by size.
--sort=key
Sort the symbols by key. The possible values for key are:
address
Sort by symbol address.
name
Sort by symbol name.
size
Sort by symbol size.
type
Sort by symbol type.
--help
Display a help message and exit.
--version
Display version information and exit.
-B
This option is the same as --format=default.
-o
Prepend the name of each output file with the string objfile.
-X linker
Specify an object code format other than your system's default format.
--target=bfdname
Specify an object code format other than your system's default format.
@file
Read command-line options from file. The options read are inserted in place of the original @file option. If file does not exist, or cannot be read, then the option will be treated literally, and not removed.

Options in file are separated by whitespace. A whitespace character may be included in an option by surrounding the entire option in either single or double quotes. Any character (including a backslash) may be included by prefixing the character to be included with a backslash. The file may itself contain additional @file options; any such options will be processed recursively.
