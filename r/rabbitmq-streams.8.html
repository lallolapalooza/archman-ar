الاسم

rabbitmq-streams — أدوات إدارة تدفقات RabbitMQ

الملخص

rabbitmq-streams [-q] [-s] [-l] [-n العقدة] [-t مهلة] الأمر [خيارات_الأمر]

الوصف

rabbitmq-streams هي أداة سطر أوامر توفر أوامر تُستخدم لإدارة التدفقات، على سبيل المثال، إضافة أو حذف نسخ تدفق. انظر نظرة عامة على تدفقات RabbitMQ.

الخيارات

-n العقدة
العقدة الافتراضية هي "rabbit@اسم_المضيف_الهدف"، حيث اسم_المضيف_الهدف هو المضيف المحلي. في مضيف يُسمى "myserver.example.com"، عادةً ما يكون اسم العقدة "rabbit@myserver" (ما لم يتم تجاوز RABBITMQ_NODENAME). عادةً ما يكون ناتج "hostname -s" هو اللاحقة الصحيحة لاستخدامها بعد علامة "@". انظر rabbitmq-server(8) للحصول على تفاصيل حول تكوين عقدة RabbitMQ.
-q, --quiet
تم اختيار وضع الإخراج الهادئ. يتم تقليل رسائل المعلومات عندما يكون الوضع الهادئ فعالاً.
-s, --silent
تم اختيار وضع الإخراج الصامت. يتم تقليل رسائل المعلومات ويتم قمع رؤوس الجداول عندما يكون الوضع الصامت فعالاً.
-t مهلة, --timeout مهلة
مهلة العملية بالثواني. ليست كل الأوامر تدعم المهلات. الافتراضي هو infinity.
-l, --longnames
يجب تحديده عند تكوين الكتلة لاستخدام أسماء عقد طويلة (FQDN). لمعرفة المزيد، انظر دليل تجميع RabbitMQ
--erlang-cookie ملف تعريف الارتباط
سر مشترك لاستخدامه للمصادقة على العقدة المستهدفة. فضل استخدام ملف محلي أو متغير البيئة RABBITMQ_ERLANG_COOKIE بدلاً من تحديد هذا الخيار في سطر الأوامر. لمعرفة المزيد، انظر دليل أدوات سطر أوامر RabbitMQ

الأوامر

help

يعرض المساعدة العامة والأوامر التي تدعمها rabbitmq-streams.

النسخ المتماثل

add_replica قائمة الانتظار العقدة --vhost المضيف الافتراضي

يضيف نسخة متماثلة للتدفق على العقدة المحددة.

مثال:

rabbitmq-streams add_replica --vhost "a-vhost" "a-queue" "rabbit@new-node"
delete_replica قائمة الانتظار العقدة --vhost المضيف الافتراضي

يزيل نسخة متماثلة للتدفق على العقدة المحددة.

مثال:

rabbitmq-streams delete_replica --vhost "a-vhost" "a-queue" "rabbit@decomissioned-node"

المراقبة، الرصد، والفحوصات الصحية

stream_status التدفق --vhost المضيف الافتراضي

يعرض حالة التدفق.

مثال:

rabbitmq-streams stream_status --vhost "a-vhost" "a-stream"
restart_stream التدفق --vhost المضيف الافتراضي ---preferred-leader-node العقدة

يعيد تشغيل تدفق بما في ذلك جميع نسخه المتماثلة. يشير علم العقدة المفضلة الاختياري إلى الأمر بمحاولة وضع القائد على عقدة محددة أثناء إعادة التشغيل.

مثال:

rabbitmq-streams restart_stream --vhost "a-vhost" "a-stream" --preferred-leader-node "node"

ملحق التدفق

activate_stream_consumer --stream التدفق --reference المرجع [--vhost المضيف الافتراضي]

يشغل إعادة توازن لتنشيط مستهلك في مجموعة مستهلكين نشطة واحدة.

مثال:

rabbitmq-streams activate_stream_consumer --stream stream --reference app-1
list_stream_connections [عنصر_معلومات_الاتصال ...]

يعيد إحصائيات اتصال بروتوكول التدفق.

يُستخدم المعامل عنصر_معلومات_الاتصال لتحديد معلومات الاتصال التي سيتم تضمينها في النتائج. سيتطابق ترتيب الأعمدة في النتائج مع ترتيب المعاملات. يمكن لـ عنصر_معلومات_الاتصال أن يأخذ أي قيمة من القائمة التي تتبع:

auth_mechanism
آلية مصادقة SASL المستخدمة، مثل "PLAIN".
client_properties
خصائص معلوماتية نقلها العميل أثناء إنشاء الاتصال.
conn_name
اسم قابل للقراءة للاتصال.
connected_at
تاريخ ووقت إنشاء هذا الاتصال، كطابع زمني.
connection_state
حالة الاتصال؛ واحدة مما يلي:
  • running
  • blocked
frame_max
الحد الأقصى لحجم الإطار (بايت).
heartbeat
فاصل نبضات القلب المتفاوض عليه، بالثواني.
host
اسم المضيف للخادم الذي تم الحصول عليه عبر البحث العكسي لنظام أسماء النطاقات، أو عنوان IP الخاص به إذا فشل البحث العكسي لنظام أسماء النطاقات أو تم تعطيله.

NAME

rabbitmq-streams - RabbitMQ Streams Management Tool

SYNOPSIS

rabbitmq-streams COMMAND [options]

DESCRIPTION

This tool is used to manage RabbitMQ Streams resources.

OPTIONS

The following options are available globally:

--help
Show help message and exit.
--host host
Host name of the RabbitMQ node.
--port port
Port of the RabbitMQ node.
--user user
User name for authentication.
--password password
Password for authentication.
--ssl-cert path
Path to SSL certificate.
--ssl-key path
Path to SSL key.
--ssl-ca-cert path
Path to CA certificate.
--ssl-versions versions
List of allowed SSL/TLS versions.
--log-level level
Set log level.

COMMANDS

create_topic --name name [--partitions partitions] [--replication replication] [--vhost vhost]

Creates a topic.

name
The name of the topic.
partitions
The number of partitions for the topic. Defaults to 1.
replication
The replication factor for the topic. Defaults to 1.
vhost
The virtual host of the topic.
delete_topic --name name [--vhost vhost]

Deletes a topic.

name
The name of the topic.
vhost
The virtual host of the topic.
list_topics [--vhost vhost]

Lists topics.

vhost
The virtual host of the topics.
create_stream --name name [--partitions partitions] [--replication replication] [--vhost vhost]

Creates a stream.

name
The name of the stream.
partitions
The number of partitions for the stream. Defaults to 1.
replication
The replication factor for the stream. Defaults to 1.
vhost
The virtual host of the stream.
delete_stream --name name [--vhost vhost]

Deletes a stream.

name
The name of the stream.
vhost
The virtual host of the stream.
list_streams [--vhost vhost]

Lists streams.

vhost
The virtual host of the streams.
create_consumer_group --stream stream --reference reference [--vhost vhost]

Creates a consumer group for a stream.

stream
The stream the consumer group is associated with.
reference
The reference (name) of the consumer group.
vhost
The virtual host of the stream.
delete_consumer_group --stream stream --reference reference [--vhost vhost]

Deletes a consumer group for a stream.

stream
The stream the consumer group is associated with.
reference
The reference (name) of the consumer group.
vhost
The virtual host of the stream.
list_stream_group_consumers --stream stream --reference reference [--vhost vhost] [consumerinfoitem ...]

Lists consumers of a stream consumer group in a vhost.

stream
The stream the consumers are attached to.
reference
The group reference (name).
vhost
The virtual host of the stream.

The consumerinfoitem parameter is used to indicate which consumer information items to include in the results. The column order in the results will match the order of the parameters. consumerinfoitem can take any value from the list that follows:

connection_name
Readable name of the consumer connection.
state
Consumer state; one of:
  • active
  • inactive
subscription_id
The connection-scoped ID of the consumer.

If no consumerinfoitem are specified then subscription_id, connection_name, and state are displayed.

For example, this command displays the connection name and state for each consumer attached to the stream-1 stream and belonging to the stream-1 group:

rabbitmq-streams list_stream_group_consumers --stream stream-1 --reference stream-1 connection_name state
list_stream_tracking stream [--all | --offset | --writer] [--vhost vhost]

Lists tracking information for a stream.

stream
The name of the stream.

Tracking information can be filtered by their type using one of the following mutually exclusive options:

--all
List offset tracking and writer deduplication information.
--offset
List only offset tracking information.
--writer
List only writer deduplication tracking information.

Example:

rabbitmq-streams list_stream_tracking stream-1 --offset
reset_offset --stream stream --reference reference [--vhost vhost]

Reset the stored offset for a consumer name on a stream.

Example:

rabbitmq-streams reset_offset --stream stream --reference app-1
