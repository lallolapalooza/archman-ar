rc_aaa_ctx_server(3) مكتبة عميل Radius rc_aaa_ctx_server(3)

الاسم

rc_aaa_ctx_server -

الملخص

#include <radcli/radcli.h>

int rc_aaa_ctx_server(
    rc_handle        *rh,
    RC_AAA_CTX      **ctx,
    SERVER           *aaaserver,
    rc_type           type,
    uint32_t          client_port,
    VALUE_PAIR       *send,
    VALUE_PAIR      **received,
    char             *msg,
    int               add_nas_port,
    rc_standard_codes request_type
);

الوصف

يبني طلب مصادقة/محاسبة لمنفذ id nas_port باستخدام value_pairs send ويرسله إلى خادم محدد. تحتفظ هذه الدالة بحالتها في ctx بعد عملية ناجحة. يمكن إلغاء تخصيصها باستخدام rc_aaa_ctx_free().

المعاملات

rh
مقبض للإعدادات المحللة.
ctx
إذا لم يكن NULL، فسيحتوي على سياق الطلب؛ يجب أن تكون قيمته الأولية NULL ويجب تحريرها باستخدام rc_aaa_ctx_free().
aaaserver
SERVER غير NULL لإرسال الرسالة إليه.
type
client_port
send
مصفوفة VALUE_PAIR من القيم (على سبيل المثال، PW_USER_NAME).
received
مصفوفة مخصصة للقيم المستلمة.
msg
يجب أن تكون مصفوفة بحجم PW_MAX_MSG_SIZE أو NULL؛ ستحتوي على تسلسل أي PW_REPLY_MESSAGE تم استلامه.
add_nas_port
يجب أن يكون هذا صفراً؛ إذا كان غير صفري، فسيشمل PW_NAS_PORT في الأزواج المرسلة.
request_type
أحد رموز RADIUS القياسية (على سبيل المثال، PW_ACCESS_REQUEST).

قيمة الإرجاع

قيمة value_pairs المستلمة في received، الرسائل من الخادم في msg و OK_RC (0) عند النجاح، CHALLENGE_RC (3) عند استلام Access-Challenge، قيمة سالبة عند الفشل كقيمة إرجاع.

rc_aaa_ctx_server(3) – RADIUS client library

NAME

rc_aaa_ctx_server - RADIUS client library

SYNOPSIS

#include <radclient.h>

struct rad_aaa_ctx_server * rc_aaa_ctx_server_new( const rad_config *config, const rad_err *err );

void rc_aaa_ctx_server_free( struct rad_aaa_ctx_server *ctx );

rad_server * rc_aaa_ctx_server_get( struct rad_aaa_ctx_server *ctx, const char *name, const rad_err *err );

void rc_aaa_ctx_server_add( struct rad_aaa_ctx_server *ctx, rad_server *server );

void rc_aaa_ctx_server_del( struct rad_aaa_ctx_server *ctx, const char *name );

DESCRIPTION

The RADIUS client library implements a client-side interface to the RADIUS protocol. It allows applications to perform authentication and accounting requests to RADIUS servers.

The rc_aaa_ctx_server structure manages the configuration and state of RADIUS servers used for AAA (Authentication, Authorization, and Accounting) operations.

rc_aaa_ctx_server_new: Creates a new context for managing RADIUS servers. It takes a configuration object and an error object as input. The configuration object should contain details about the RADIUS servers, such as their IP addresses, ports, and shared secrets. The error object is used for reporting errors.

rc_aaa_ctx_server_free: Frees the memory associated with the RADIUS server context.

rc_aaa_ctx_server_get: Retrieves a specific RADIUS server from the context based on its name. If found, it returns a pointer to the rad_server object; otherwise, it returns NULL.

rc_aaa_ctx_server_add: Adds a new RADIUS server to the context. The rad_server object should be created and configured beforehand.

rc_aaa_ctx_server_del: Removes a RADIUS server from the context by its name.

PARAMETERS

config
A pointer to a rad_config object containing the RADIUS server configuration.
err
A pointer to a rad_err object for error reporting.
ctx
A pointer to a struct rad_aaa_ctx_server.
name
The name of the RADIUS server to retrieve or delete.
server
A pointer to the rad_server object to add to the context.

STRUCTURES

struct rad_aaa_ctx_server
Represents the context for managing RADIUS AAA servers. It contains internal data structures for storing and accessing configured servers.

RETURN VALUE

rc_aaa_ctx_server_new returns a pointer to the newly created struct rad_aaa_ctx_server on success, or NULL on failure.

rc_aaa_ctx_server_get returns a pointer to the requested rad_server object if found, otherwise NULL.

The other functions do not return any value.
