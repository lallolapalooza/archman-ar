DESCRIPTION

These macros implement splay trees and red-black trees. Splay trees are a type of self-adjusting binary search tree. Red-black trees are another type of binary search tree that maintains a balance to guarantee logarithmic time complexity for operations.

The implementation is generic and can be used with any data type. You must define a structure to hold the tree nodes, and a comparison function to order the elements.

SPLAY TREE MACROS

SPLAY_PROTOTYPE
Declares the tree functions and head structure for a specific tree type. NOMBRE is the name of the tree type, TIPO is the type of the elements in the tree, CAMPO is the name of the field within TIPO that holds the tree node, and CMP is the name of the comparison function.
SPLAY_GENERATE
Generates the tree functions and head structure. This macro should be invoked in one source file to avoid multiple definition errors.
SPLAY_ENTRY
Defines the structure for a tree node. TIPO is the type of the element.
SPLAY_HEAD
Defines the structure for the tree head. NOMBRE is the name of the tree type, and TIPO is the type of the elements.
SPLAY_INITIALIZER
Initializes a tree head structure. This macro is used to initialize a tree head variable.
SPLAY_ROOT
Returns the root node of the tree.
SPLAY_EMPTY
Returns true if the tree is empty, false otherwise.
SPLAY_NEXT
Returns the next element in the tree in in-order traversal.
SPLAY_MIN
Returns the smallest element in the tree.
SPLAY_MAX
Returns the largest element in the tree.
SPLAY_FIND
Finds an element in the tree. The comparison function should be used to determine equality.
SPLAY_LEFT
Returns the left child of a node.
SPLAY_RIGHT
Returns the right child of a node.
SPLAY_FOREACH
Iterates over all elements in the tree in in-order traversal.
SPLAY_INIT
Initializes an empty tree.
SPLAY_INSERT
Inserts an element into the tree.
SPLAY_REMOVE
Removes an element from the tree.

RED-BLACK TREE MACROS

RB_PROTOTYPE
Declares the tree functions and head structure for a specific tree type. NOMBRE is the name of the tree type, TIPO is the type of the elements in the tree, CAMPO is the name of the field within TIPO that holds the tree node, and CMP is the name of the comparison function.
RB_PROTOTYPE_STATIC
Same as RB_PROTOTYPE but generates static functions.
RB_GENERATE
Generates the tree functions and head structure. This macro should be invoked in one source file to avoid multiple definition errors.
RB_GENERATE_STATIC
Same as RB_GENERATE but generates static functions.
RB_ENTRY
Defines the structure for a tree node. TIPO is the type of the element.
RB_HEAD
Defines the structure for the tree head. NOMBRE is the name of the tree type, and TIPO is the type of the elements.
RB_INITIALIZER
Initializes a tree head structure. This macro is used to initialize a tree head variable.
RB_ROOT
Returns the root node of the tree.
RB_EMPTY
Returns true if the tree is empty, false otherwise.
RB_NEXT
Returns the next element in the tree in in-order traversal.
RB_PREV
Returns the previous element in the tree in in-order traversal.
RB_MIN
Returns the smallest element in the tree.
RB_MAX
Returns the largest element in the tree.
RB_FIND
Finds an element in the tree. The comparison function should be used to determine equality.
RB_NFIND
Finds the nearest element to a given element. Useful for finding elements that are greater than or equal to a given key.
RB_LEFT
Returns the left child of a node.
RB_RIGHT
Returns the right child of a node.
RB_PARENT
Returns the parent of a node.
RB_FOREACH
Iterates over all elements in the tree in in-order traversal.
RB_FOREACH_SAFE
Same as RB_FOREACH but safe for removal of elements during iteration.
RB_FOREACH_REVERSE
Iterates over all elements in the tree in reverse in-order traversal.
RB_FOREACH_REVERSE_SAFE
Same as RB_FOREACH_REVERSE but safe for removal of elements during iteration.
RB_INIT
Initializes an empty tree.
RB_INSERT
Inserts an element into the tree.
RB_REMOVE
Removes an element from the tree.

EXAMPLE

Here is an example of how to use the red-black tree macros to store integers:

#include <stdio.h>
#include <stdlib.h>
#include <sys/tree.h>

struct node {
    int key;
    RB_ENTRY(node) entries; /* Must be named entries */
};

/* Define the comparison function */
int compare_nodes(struct node *a, struct node *b) {
    return a->key - b->key;
}

/* Declare and generate the tree functions */
RB_PROTOTYPE(IntTree, node, entries, compare_nodes)
RB_GENERATE(IntTree, node, entries, compare_nodes)

int main() {
    RB_HEAD(IntTree, node) head = RB_INITIALIZER(head);
    struct node *node1, *node2, *node3, *current;
    struct node query;

    /* Allocate nodes */
    node1 = malloc(sizeof(struct node));
    node2 = malloc(sizeof(struct node));
    node3 = malloc(sizeof(struct node));

    /* Initialize nodes */
    node1->key = 10;
    node2->key = 5;
    node3->key = 15;

    /* Insert nodes into the tree */
    RB_INSERT(IntTree, &head, node1);
    RB_INSERT(IntTree, &head, node2);
    RB_INSERT(IntTree, &head, node3);

    /* Traverse the tree */
    printf("In-order traversal:\n");
    RB_FOREACH(current, IntTree, &head) {
        printf("%d ", current->key);
    }
    printf("\n");

    /* Find a node */
    query.key = 5;
    current = RB_FIND(IntTree, &head, &query);
    if (current) {
        printf("Found node with key %d\n", current->key);
    } else {
        printf("Node with key 5 not found\n");
    }

    /* Remove a node */
    query.key = 10;
    current = RB_FIND(IntTree, &head, &query);
    if (current) {
        RB_REMOVE(IntTree, &head, current);
        free(current);
        printf("Removed node with key 10\n");
    }

    /* Traverse again */
    printf("In-order traversal after removal:\n");
    RB_FOREACH(current, IntTree, &head) {
        printf("%d ", current->key);
    }
    printf("\n");

    /* Clean up remaining nodes */
    RB_FOREACH_SAFE(current, IntTree, &head) {
        RB_REMOVE(IntTree, &head, current);
        free(current);
    }

    return 0;
}

الوصف

تعرّف هذه الماكرو هياكل بيانات لأنواع مختلفة من الأشجار: أشجار الانضغاط وأشجار الأحمر والأسود.

في تعريفات الماكرو، TYPE هو تسمية الهيكل الذي يعرفه المستخدم والذي يجب أن يحتوي على حقل يسمى FIELD من النوع SPLAY_ENTRY أو RB_ENTRY. الوسيط HEADNAME هو تسمية هيكل يعرفه المستخدم ويجب تعريفه باستخدام الماكرو SPLAY_HEAD() أو RB_HEAD(). يجب أن يكون الوسيط NAME اسم بادئة فريد لكل شجرة معرفة.

يتم إنشاء إعلانات نماذج الدوال باستخدام SPLAY_PROTOTYPE أو RB_PROTOTYPE أو RB_PROTOTYPE_STATIC. يتم إنشاء أجسام الدوال باستخدام SPLAY_GENERATE أو RB_GENERATE أو RB_GENERATE_STATIC. انظر الأمثلة التالية لشرح أكثر تفصيلاً لكيفية استخدام هذه الماكرو.

أشجار الانضغاط

شجرة الانضغاط هي بنية بيانات ذاتية التنظيم. كل عملية على الشجرة تسبب انضغاطًا. يقوم الانضغاط بنقل العقدة المطلوبة إلى جذر الشجرة وإعادة توازن الشجرة جزئيًا.

تنشأ هذه الفائدة من حقيقة أن تحديد العقد المطلوبة يؤدي إلى استعلامات أسرع، حيث يتم نقل العقد المطلوبة إلى قمة الشجرة. من ناحية أخرى، تتسبب كل استعلام في عمليات كتابة في الذاكرة.

يحد نظرية التوازن من وقت الوصول الإجمالي لـ m عملية وإدراج n في شجرة فارغة مبدئيًا بـ O((m + n) log n). التكلفة المستهلكة لتسلسل m استعلام في شجرة انضغاط هي O(log n).

تدار شجرة الانضغاط بواسطة هيكل معرف بالماكرو SPLAY_HEAD(). يتم الإعلان عن هيكل SPLAY_HEAD على النحو التالي:

SPLAY_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم الهيكل المراد تعريفه، و TYPE هو نوع العناصر المراد إدراجها في الشجرة.

تعلن الماكرو SPLAY_ENTRY عن هيكل يسمح بربط العناصر في الشجرة.

لاستخدام الدوال التي تعالج بنية الشجرة، يجب الإعلان عن نماذجها باستخدام الماكرو SPLAY_PROTOTYPE، حيث NAME هو معرف فريد لهذه الشجرة المحددة. الوسيط TYPE هو نوع الهيكل الذي تديره الشجرة. الوسيط FIELD هو اسم العنصر المعرف بواسطة SPLAY_ENTRY().

يتم إنشاء أجسام الدوال باستخدام الماكرو SPLAY_GENERATE. لديها نفس وسائط الماكرو SPLAY_PROTOTYPE()، ولكن يجب استخدامها مرة واحدة فقط.

أخيرًا، الوسيط CMP هو اسم دالة تستخدم لمقارنة العقد في الشجرة ببعضها البعض. تأخذ الدالة وسيطين من النوع struct TYPE *. إذا كان الوسيط الأول أصغر من الثاني، فإن الدالة تعيد قيمة أقل من الصفر. إذا كانا متساويين، فإنها تعيد صفرًا. خلاف ذلك، فإنها تعيد قيمة أكبر من الصفر. تحدد دالة المقارنة ترتيب عناصر الشجرة.

تقوم الماكرو SPLAY_INIT بتهيئة الشجرة المشار إليها بواسطة head.

يمكن أيضًا تهيئة شجرة الانضغاط بشكل ثابت باستخدام الماكرو SPLAY_INITIALIZER على النحو التالي:

SPLAY_HEAD(HEADNAME, TYPE) head = SPLAY_INITIALIZER(&head);

تقوم الماكرو SPLAY_INSERT بإدراج العنصر الجديد elm في الشجرة. عند النجاح، يتم إرجاع NULL. إذا كان هناك بالفعل عنصر بنفس القيمة في الشجرة، تتوقف عملية الإدراج ويتم إرجاع مؤشر إلى العنصر الموجود.

تقوم الماكرو SPLAY_REMOVE بإزالة العنصر elm من الشجرة المشار إليها بواسطة head. عند النجاح، يتم إرجاع مؤشر إلى العنصر المحذوف. يتم إرجاع NULL إذا لم يكن elm موجودًا في الشجرة.

يمكن استخدام الماكرو SPLAY_FIND للعثور على عنصر معين في الشجرة.

struct TYPE find, *res;
find.key = 30;
res = SPLAY_FIND(NAME, &head, &find);

يمكن استخدام الماكرو SPLAY_ROOT و SPLAY_MIN و SPLAY_MAX و SPLAY_NEXT للتنقل في الشجرة:

for (np = SPLAY_MIN(NAME, &head); np != NULL; np = SPLAY_NEXT(NAME, &head, np))

أو، للتبسيط، يمكن استخدام الماكرو SPLAY_FOREACH:

SPLAY_FOREACH(np, NAME, &head)

يجب استخدام الماكرو SPLAY_EMPTY للتحقق مما إذا كانت شجرة الانضغاط فارغة.

أشجار الأحمر والأسود

شجرة الأحمر والأسود هي شجرة بحث ثنائية ذات خاصية إضافية وهي لون العقدة. تلتزم بسلسلة من الشروط:

  1. كل مسار من الجذر إلى عقدة ورقة يحتوي على نفس العدد من العقد السوداء.
  2. كل عقدة حمراء (باستثناء الجذر) لها أب أسود.
  3. كل عقدة ورقة سوداء.

كل عملية في شجرة الأحمر والأسود محدودة بـ O(log n). الحد الأقصى لارتفاع شجرة الأحمر والأسود هو 2 log (n + 1).

تدار شجرة الأحمر والأسود بواسطة هيكل معرف بالماكرو RB_HEAD. يتم الإعلان عن هيكل RB_HEAD على النحو التالي:

RB_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم الهيكل المراد تعريفه، و TYPE هو نوع العناصر المراد إدراجها في الشجرة.

تعلن الماكرو RB_ENTRY عن هيكل يسمح بربط العناصر في الشجرة.

لاستخدام الدوال التي تعالج بنية الشجرة، يجب الإعلان عن نماذجها باستخدام الماكرو RB_PROTOTYPE أو RB_PROTOTYPE_STATIC، حيث NAME هو معرف فريد لهذه الشجرة المحددة. الوسيط TYPE هو نوع الهيكل الذي تديره الشجرة. الوسيط FIELD هو اسم العنصر المعرف بواسطة RB_ENTRY().

يتم إنشاء أجسام الدوال باستخدام الماكرو RB_GENERATE أو RB_GENERATE_STATIC. تأخذ هذه الماكرو نفس وسائط الماكرو RB_PROTOTYPE() و RB_GENERATE().
