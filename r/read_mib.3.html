وصف

تقع الوظائف التي تتعامل مع وحدات MIB في أربع مجموعات - تلك التي تتعامل مع التهيئة والإغلاق، وقراءة وتحليل ملفات MIB، والبحث في شجرة MIB، ووظائف الإخراج.

التهيئة والإغلاق

تُستخدم add_mibdir لإضافة الدليل المحدد إلى مسار المواقع التي يتم البحث فيها عن الملفات التي تحتوي على وحدات MIB. لاحظ أن هذا لا يقوم فعليًا بتحميل وحدات MIB الموجودة في هذا الدليل، ولكنه ببساطة خطوة تهيئة لجعلها متاحة لـ netsnmp_read_module. تُرجع هذه الوظيفة عدد الملفات الموجودة في الدليل، أو -1 إذا حدث خطأ. يجب استدعاؤها قبل استدعاء netsnmp_init_mib.

يقوم netsnmp_init_mib بتكوين مسار بحث دليل MIB (باستخدام add_mibdir)، ويهيئ إطار عمل MIB الداخلي، ثم يقوم بتحميل وحدات MIB المناسبة (باستخدام netsnmp_read_module و read_mib). انظر قسم متغيرات البيئة لمعرفة التفاصيل.
يجب استدعاؤها قبل أي إجراء آخر يقوم بمعالجة أو الوصول إلى شجرة MIB (ولكن بعد أي استدعاءات إضافية لـ add_mibdir).

سيقوم shutdown_mib بمسح المعلومات التي تم جمعها بواسطة netsnmp_read_module و add_mibdir و add_module_replacement. يوصى بشدة بعدم استدعاء shutdown_mib أثناء إدارة جلسات SNMP بشكل نشط.

قراءة وتحليل ملفات MIB

تأخذ netsnmp_read_module اسم وحدة MIB (والتي لا يلزم أن تكون هي نفسها اسم الملف الذي يحتوي على الوحدة)، وتحدد موقعها ضمن القائمة المكونة من أدلة MIB، وتقوم بتحميل التعريفات من الوحدة إلى شجرة MIB النشطة. كما تقوم بتحميل أي وحدات MIB مدرجة في عبارة IMPORTS لهذه الوحدة.

read_mib مشابهة، ولكنها تأخذ اسم الملف الذي يحتوي على وحدة MIB. لاحظ أن هذا الملف لا يلزم أن يكون موجودًا ضمن قائمة بحث دليل MIB (على الرغم من أن أي وحدات مدرجة في عبارة IMPORTS يجب أن تكون كذلك).

سيقوم read_all_mibs بقراءة جميع وحدات MIB الموجودة في قائمة بحث دليل MIB.

بشكل عام، يكون المحلل صامتًا بشأن الغرائب التي يراها في ملفات MIB. للحصول على تقارير التحذيرات، قم باستدعاء snmp_set_mib_warnings بمستوى 1 (أو 2 لمزيد من التحذيرات).

يمكن استخدام add_module_replacement للسماح لوحدات MIB الجديدة بإلغاء الوحدات القديمة، دون الحاجة إلى تعديل عبارات IMPORTS للوحدات الأخرى. تأخذ أسماء الوحدات القديمة والجديدة، مع مؤشر على الأجزاء من الوحدة القديمة التي تتأثر.

tag len تحميل الوحدة الجديدة عندما:
NULL 0 دائمًا (الوحدة القديمة هي مجموعة فرعية صارمة من
الجديدة)
name 0 فقط للعلامة المحددة
name غير 0 لأي معرف بهذا البادئة
يمكن استخدامه أيضًا للتعامل مع الأخطاء في معرفات الوحدات المستخدمة في عبارات IMPORTS الخاصة بـ MIB (مثل الإشارة إلى RFC1213 بدلاً من RFC1213-MIB).

البحث في شجرة MIB

تأخذ read_objid سلسلة نصية تحتوي على نسخة نصية من معرف كائن (بشكل رقمي أو وصفي)، وتقوم بتحويلها إلى القائمة المقابلة من المعرفات الفرعية. يتم إرجاع هذه القائمة في المعلمة output، ويتم إرجاع عدد المعرفات الفرعية عبر out_len. عند الاستدعاء، يجب أن تحتوي out_len على الحد الأقصى لطول المصفوفة output. إذا كان يتم معالجة معرفات كائنات متعددة، فيجب إعادة تعيين هذا الطول قبل كل استدعاء. تُرجع هذه الوظيفة قيمة 1 إذا نجحت في تحليل السلسلة و 0 بخلاف ذلك.

snmp_parse_oid مشابهة، ولكنها تُرجع مؤشرًا إلى مخزن مؤقت لـ OID المحلل (أو NULL).

تأخذ get_module_node وصفًا واسم وحدة، وتُرجع قائمة OID المقابلة، بنفس الطريقة التي تعمل بها read_objid أعلاه.
إذا تم تحديد اسم الوحدة على أنه "ANY"، فستفترض هذه الروتين أن الوصف المقدم فريد داخل الشجرة، وستُرجع الإدخال المطابق. إذا كان هذا الافتراض غير صحيح، فإن السلوك المتعلق بالمتغير الذي يتم إرجاعه يعتمد على التنفيذ.

الإخراج

سيقوم print_mib بطباعة تمثيل لشجرة MIB النشطة حاليًا إلى مؤشر الملف (FILE pointer) المحدد.

سيأخذ print_objid معرف كائن (كما تم إرجاعه بواسطة read_objid أو snmp_parse_oid أو get_module_node)، ويطبع الشكل النصي لهذا OID إلى المخرج القياسي.

يقوم fprint_objid بنفس الشيء، ولكنه يطبع إلى مؤشر الملف (FILE pointer) المحدد بواسطة المعلمة الأولية.

يقوم snprint_objid بطباعة نفس المعلومات في المخزن المؤقت (buffer) الذي يشير إليه buf والذي يبلغ طوله len. تُرجع عدد الأحرف المطبوعة، أو -1 إذا لم يكن المخزن المؤقت كبيرًا بما يكفي. في الحالة الأخيرة، سيحتوي buf عادةً على نسخة مقتطعة من المعلومات (ولكن هذا السلوك غير مضمون).

تأخذ print_description و fprint_description و snprint_description معرف كائن مشابهًا وتطبع نسخة من تعريف MIB لهذا الكائن، جنبًا إلى جنب مع OID الكامل. يتحكم المعلم width في كيفية تخطيط OID.

افتراضيًا، لا يقوم المحلل بحفظ الأوصاف لأنها قد تكون ضخمة. لكي تكون قادرًا على طباعتها، من الضروري استدعاء

man 3 read_mib

NAME

read_mib, init_mib, read_all_mibs, netsnmp_read_mib, netsnmp_init_mib, netsnmp_read_all_mibs - read MIB files

SYNOPSIS

#include <net-snmp/mib_api.h>

int init_mib(void);
int read_mib(const char *filename);
int read_all_mibs(void);

int netsnmp_init_mib(void);
int netsnmp_read_mib(const char *filename);
int netsnmp_read_all_mibs(void);

DESCRIPTION

These functions are used to load MIB modules into the netsnmp library's internal database.

The init_mib() function should be called before any MIB files are read. It initialises the internal database, clearing any previously loaded information.

The read_mib() function reads the specified MIB file. The file is parsed, and any definitions contained within it are added to the internal database.

The read_all_mibs() function reads all MIB files that can be found in the MIB directories (see MIBDIRS below).

The netsnmp_prefixed versions of these functions are identical in functionality.

It is recommended to call snmp_set_save_descriptions(1) before calling init_mib (or similar).

ENVIRONMENT VARIABLES

The main use of environmental variables with respect to these API calls is to configure which MIB modules should be loaded, and where they are located.

MIBDIRS
A colon separated list of directories to search for MIB modules.
Default: /usr/share/snmp/mibs
Used by init_mib, netsnmp_read_module, read_all_mibs and (implicitly) by read_mib.
MIBS
A colon separated list of MIB modules to load.
The default list of modules will depend on how the Net-SNMP software was originally compiled, but is typically:
IP-MIB:IF-MIB:TCP-MIB:UDP-MIB:SNMPv2-MIB:RFC1213-MIB:UCD-SNMP-MIB:HOST-RESOURCES-MIB
If the value of the MIBS environmental variable starts with a '+' character, then these MIB modules will be added to the default list. Otherwise these modules (plus any that they IMPORT from) will be loaded instead of the default list.
If the MIBS environmental variable has the value ALL then read_all_mibs will be called to load the full collection of all available MIB modules.
Used by init_mib only.
MIBFILES
A colon separated list of files to load.
Default: (none)
Used by init_mib only.

الوصف

تُستخدم هذه الدوال لتحميل وحدات MIB في قاعدة البيانات الداخلية لمكتبة netsnmp.

يجب استدعاء الدالة init_mib() قبل قراءة أي ملفات MIB. تقوم بتهيئة قاعدة البيانات الداخلية، مما يؤدي إلى مسح أي معلومات تم تحميلها سابقًا.

تقوم الدالة read_mib() بقراءة ملف MIB المحدد. يتم تحليل الملف، وتضاف أي تعريفات موجودة فيه إلى قاعدة البيانات الداخلية.

تقوم الدالة read_all_mibs() بقراءة جميع ملفات MIB التي يمكن العثور عليها في أدلة MIB (انظر MIBDIRS أدناه).

تتطابق الدوال ذات البادئة netsnmp_ مع الدوال المذكورة أعلاه في وظائفها.

يوصى باستدعاء snmp_set_save_descriptions(1) قبل استدعاء init_mib (أو ما شابه).

متغيرات البيئة

الاستخدام الرئيسي لمتغيرات البيئة فيما يتعلق باستدعاءات واجهة برمجة التطبيقات هذه هو تكوين وحدات MIB التي يجب تحميلها، ومواقعها.

MIBDIRS
قائمة مفصولة بنقطتين فوق بعض للمجلدات للبحث عن وحدات MIB.
الافتراضي: /usr/share/snmp/mibs
تستخدم بواسطة init_mib، netsnmp_read_module، read_all_mibs (وبشكل ضمني) بواسطة read_mib.
MIBS
قائمة مفصولة بنقطتين فوق بعض لوحدات MIB المراد تحميلها.
تعتمد القائمة الافتراضية للوحدات على كيفية تجميع برنامج Net-SNMP في الأصل، ولكنها عادةً ما تكون:
IP-MIB:IF-MIB:TCP-MIB:UDP-MIB:SNMPv2-MIB:RFC1213-MIB:UCD-SNMP-MIB:HOST-RESOURCES-MIB
إذا بدأت قيمة متغير البيئة MIBS بحرف '+'، فسيتم إضافة وحدات MIB هذه إلى القائمة الافتراضية. بخلاف ذلك، سيتم تحميل وحدات MIB هذه (بالإضافة إلى أي وحدات تستورد منها) بدلاً من القائمة الافتراضية.
إذا كانت قيمة متغير البيئة MIBS هي ALL، فسيتم استدعاء read_all_mibs لتحميل المجموعة الكاملة لجميع وحدات MIB المتاحة.
تستخدم بواسطة init_mib فقط.
MIBFILES
قائمة مفصولة بنقطتين فوق بعض للملفات المراد تحميلها.
الافتراضي: (لا شيء)
تستخدم بواسطة init_mib فقط.
