razor-admin - The Razor Management tool

DESCRIPTION

The Razor Management tool is a collection of programs designed to manage and administer the Razor anti-spam system. It allows users to update the Razor databases, query the Razor servers, and configure Razor client settings.

USAGE

razor-admin [options] <command>

The razor-admin command is used to perform various administrative tasks on the Razor system. The following commands are supported:

  • discover: Discover Razor servers.
  • learn: Train the Razor system with known spam or ham (not spam).
  • unlearn: Remove previously learned examples from the Razor system.
  • record: Record a message for later analysis or submission.
  • process: Process recorded messages.
  • deregister: Deregister your Razor client.
  • revoke: Revoke a previously registered Razor client.
  • whitelist: Add or remove email addresses from the whitelist.
  • blacklist: Add or remove email addresses from the blacklist.
  • stats: Display statistics about the Razor system.
  • dryrun: Perform a dry run of the Razor system without making changes.
  • version: Display the Razor version.
  • help: Display help information for a specific command.

OPTIONS

The following options can be used with razor-admin:

  • -d, --debug: Enable debugging output.
  • -h, --help: Display help information.
  • -v, --version: Display the Razor version.
  • -p, --config <file>: Specify an alternative configuration file.
  • -P, --trust-proxy: Trust the proxy server for Razor queries.
  • -r, --register: Register a new Razor client.
  • -u, --username <name>: Specify the username for registration.
  • -e, --email <address>: Specify the email address for registration.
  • -c, --country <code>: Specify the country code for registration.
  • -o, --organization <name>: Specify the organization name for registration.
  • -a, --autoupdate: Automatically update Razor databases.
  • -i, --input <file>: Specify the input file for learning or processing.
  • -t, --type <type>: Specify the type of message (spam or ham) for learning.
  • -s, --server <host>[:port]: Specify the Razor server to connect to.
  • -f, --force: Force an operation, even if it seems unnecessary.

EXAMPLES

Learn a message as spam:

razor-admin learn --message "This is a spam message." --type spam

Discover Razor servers:

razor-admin discover

Register a new Razor client:

razor-admin register --username myuser --email myemail@example.com --country US --organization MyCompany

Update Razor databases:

razor-admin update
