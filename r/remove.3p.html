REMOVE(3P) دليل مبرمج POSIX REMOVE(3P)

مقدمة

هذه الصفحة الدليلية جزء من دليل مبرمج POSIX. قد يختلف تطبيق هذه الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة في لينكس.

الاسم

remove — إزالة ملف

الملخص

#include <stdio.h>
int remove(const char *path);

الوصف

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1‐2017 يحيل إلى معيار ISO C.

ستؤدي الدالة remove() إلى جعل الملف المسمى بواسطة مسار المسار المشار إليه بواسطة path غير متاح بهذا الاسم. سيؤدي محاولة فتح هذا الملف لاحقًا باستخدام هذا الاسم إلى الفشل، ما لم يتم إنشاؤه من جديد.

إذا لم يكن path يسمي دليلًا، فإن remove(path) ستكون مكافئة لـ unlink(path).

إذا كان path يسمي دليلًا، فإن remove(path) ستكون مكافئة لـ rmdir(path).

قيمة الإرجاع

راجع rmdir() أو unlink().

الأخطاء

راجع rmdir() أو unlink().

الأقسام التالية معلوماتية.

أمثلة

إزالة الوصول إلى ملف

يوضح المثال التالي كيفية إزالة الوصول إلى ملف يسمى /home/cnd/old_mods.

#include <stdio.h>
int status;
...
status = remove("/home/cnd/old_mods");
