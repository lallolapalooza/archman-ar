DESCRIPTION

The rtmpdump utility is a small, cross-platform RTMP dump tool. It is able to connect to an RTMP server and download the stream or play it back.

The tool supports the RTMP protocol, including Flash Player authentication, RTMP tunneling, and encrypted streams (via Action Message Format encrypted with AES).

It can also be used to connect to servers using the RTMPT (RTMP tunneling over HTTP) protocol.

OPTIONS

--rtmp host:port/app -r rtmp://...
RTMP URL. If host is not specified, it defaults to 127.0.0.1. If port is not specified, it defaults to 1935. If app is not specified, it defaults to /. The URL can be in the form “rtmp://host/app”, “rtmpt://host/app”, or “rtmps://host/app”.
--playpath playpath -y playpath
Play path. This is the stream name or file name to be played.
--streamname streamname -Y streamname
Stream name. This is an alternative to playpath and is used for live streams.
--app app -a app
Application name. This is the application on the server to connect to.
--flashver version -f flashver
Flash Player version. The default is “Shockwave%20Flash%2010.0.0%20r45”.
--swfurl url -u swfurl
SWF verification URL. This is the URL of the SWF player that will be used to play the stream. This is used for Flash Player authentication.
--swfhash hash -t swfhash
SWF verification hash. This is the MD5 hash of the SWF player file.
--swfsize size -s swfsize
SWF verification size. This is the size of the SWF player file in bytes.
--swfurl url -G swfurl
SWF verification URL. This is the URL of the SWF player that will be used to play the stream. This is used for Flash Player authentication.
--swfage age -d swfage
SWF verification age. This is the age of the SWF player file in seconds.
--swfsha1 hash -k swfsha1
SWF verification SHA1 hash. This is the SHA1 hash of the SWF player file.
--pageurl url -p pageurl
Page URL. This is the URL of the web page where the stream is being played.
--protocol protocol -w protocol
Protocol. This is the protocol to use for the connection. Can be “rtmp”, “rtmpt”, or “rtmps”.
--swfurl url -W swfurl
SWF verification URL. This is the URL of the SWF player that will be used to play the stream. This is used for Flash Player authentication.
--key key -K key
Encryption key. This is the key used to decrypt the stream.
--chunksize size -C chunksize
Chunk size. This is the size of the chunks to be downloaded. The default is 4096.
--live -L
Live stream. This option indicates that the stream is a live stream.
--live -R
Live stream. This option indicates that the stream is a live stream.
--rtmpver version -v rtmpver
RTMP version. The default is 3.0.
--socks host:port -S socks
SOCKS proxy. Connect to the specified SOCKS proxy.
--proxyauth user:password -A proxyauth
Proxy authentication. Specify username and password for proxy authentication.
--httpproxy host:port -H httpproxy
HTTP proxy. Connect to the specified HTTP proxy.
--timeout seconds -T timeout
Timeout. Set the connection timeout in seconds.
--proxytype type -x proxytype
Proxy type. Can be “http”, “socks4”, or “socks5”.
--bufferlen length -B bufferlen
Buffer length. Set the buffer length in bytes.
--rtmpver version -F rtmpver
RTMP version. The default is 3.0.
--certfile file -c certfile
Certificate file. Specify the path to the client certificate file for SSL/TLS connections.
--keyfile file -e keyfile
Key file. Specify the path to the client private key file for SSL/TLS connections.
--capath path -m capath
CA path. Specify the path to the directory containing CA certificates for SSL/TLS connections.
--location file -l location
Output file. Specify the location where the downloaded stream should be saved. If not specified, the stream is sent to standard output.
--overwrite
Overwrite existing files. If a file with the same name already exists, it will be overwritten.
--quiet -q
Suppress all command output.
--verbose -V
Verbose command output.
--debug -z
Debug level output. Extremely verbose, including hex dumps of all packet data.
--help -h
Print a summary of command options.

SWF verification options

The following options are used for SWF verification, which is required by some RTMP servers:

--swfurl url
The URL of the SWF file used by the Flash player.
--swfhash hash
The MD5 hash of the SWF file.
--swfsize size
The size of the SWF file in bytes.
--swfurl url
The URL of the SWF file used by the Flash player. This is an alias for --swfurl.
--swfage age
The age of the SWF file in seconds.
--swfsha1 hash
The SHA1 hash of the SWF file.

If the check shows that the SWF file has the same modification timestamp as before, it will not be retrieved again.

Miscellaneous

--device -D address
Listener IP address. The default is 0.0.0.0, i.e., any IP address.
--sport -g port
Listener port. The default is 80.
--quiet -q
Suppress all command output.
--verbose -V
Verbose command output.
--debug -z
Debug level output. Extremely verbose, including hex dumps of all packet data.
--help -h
Print a summary of command options.

EXAMPLES

The HTTP request

GET /?r=rtmp:%2f%2fserver%2fmyapp&y=somefile HTTP/1.0

is equivalent to the rtrmpdump(1) invocation

rtmpdump -r rtmp://server/myapp -y somefile

Note that only the shortform (single letter) options are supported.

ENVIRONMENT

The value of $HOME is used as the location for the .swfinfo file.
