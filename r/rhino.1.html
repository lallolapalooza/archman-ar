RHINO(1) General Commands Manual RHINO(1)

NAME

rhino - invokes the JavaScript shell for running scripts in batch mode or interactive

SYNOPSIS

rhino [options] script_filename_or_url [script_arguments]

DESCRIPTION

This manual page documents briefly the rhino command.

rhino is a start script for the rhino JavaScript shell which provides a simple way to run scripts in batch mode or an interactive environment for exploratory programming.

OPTIONS

-debug
Generate debug information. This will set the optimization level to zero.
-e script_source
Executes script_source as a JavaScript script.
-encoding characterEncoding
Set the character encoding to apply in case it could not be detected.
-f script_filename_or_url
Reads script_filename_or_url content and execute it as a JavaScript script.
-fatal-warnings
Set warnings as errors.
-help, -?
Display help.
-modules module
Add a module to the path.
-opt, -O optLevel
Optimizes at level optLevel, which must be an integer between 0 and 9.
-require
Use require().
-sandbox
The created require() instances will be sandboxed.
-sealedlib
Use a sealed standard library.
-strict
Set strict mode.
-version versionNumber
Specifies the language version to compile with. It must be one of 100, 110, 120, 130, 140, 150, 160, 170, 180 or 200.
-w
Report warnings.

PREDEFINED PROPERTIES

Scripts executing in the shell have access to some additional properties of the top-level object.

arguments
The arguments object is an array containing the strings of all the arguments given at the command line when the shell was invoked.
help()
Executing the help function will print usage and help messages.
defineClass(className)
Define an extension using the Java class named with the string argument className. Uses ScriptableObject.defineClass() to define the extension.
deserialize(filename)
Restore from the specified file an object previously written by a call to serialize.
load([filename,...])
Load JavaScript source files named by string arguments. If multiple arguments are given, each file is read in and executed in turn.
loadClass(className)
Load and execute the class named by the string argument className. The class must be a class that implements the Script interface, as will any script compiled by jsc.
print([expr...])
Evaluate and print expressions. Evaluates each expression, converts the result to a string, and prints it.
readFile(path[,characterCoding])
Read given file and convert its bytes to a string using the specified character coding or default character coding if explicit coding argument is not given.
readUrl(url[,characterCoding])
Open an input connection to the given string url, read all its bytes and convert them to a string using the specified character coding or default character coding if explicit coding argument is not given.
runCommand(commandName,[arg,...][options])
Execute the specified command with the given argument and options as a separate process and return the exit status of the process. For details, see JavaDoc for org.mozilla.javascript.tools.shell.Global#runCommand.
setTimeout(function[,delay,arg,...])
Execute "function" after "delay" milliseconds. (If "delay" is not set, then it is set to 0.) Pass any trailing parameters as arguments. Timeouts run after the current function is done executing, and in the interactive shell, only after the shell is exited. Return an ID that may be passed to "clearTimeout".
clearTimeout(id)
Cancel a timeout set using "setTimeout".
serialize(object,filename)
Serialize the given object to the specified file.
spawn(functionOrScript)
Run the given function or script in a different thread.
sync(function)
creates a synchronized function (in the sense of a Java synchronized method) from an existing function. The new function synchronizes on the this object of its invocation.
quit()
Quit shell. The shell will also quit in interactive mode if an end-of-file character is typed at the prompt.
version([number])
Get or set JavaScript version number. If no argument is supplied, the current version number is returned. If an argument is supplied, it is expected to be one of 100, 110, 120, 130, 150, 160, 170, 180 or 200 to indicate JavaScript version 1.0, 1.1, 1.2, 1.3, 1.4, 1.5, 1.6, 1.7, 1.8 or ECMAScript 6 respectively.
write([expr...])
Evaluate and print expressions like in "print", but without the trailing newline.
console
The console object provides a simple debugging console similar to the console object provided by web browsers.
console.log(format[arg,...])
For general output of logging information. String substitution and additional arguments are supported. Prints formatted text according to the format and args supplied with "INFO" prefix. This function is identical to console.info(format[arg,...]).
console.trace(format[arg,...])
This function is identical to console.log(format[arg,...]) except it prints "TRACE" prefix instead of "INFO".
console.debug(format[arg,...])
This function is identical to console.log(format[arg,...]) except it prints "DEBUG" prefix instead of "INFO".
console.info(format[arg,...])
This function is identical to console.log(format[arg,...]).
console.warn(format[arg,...])
This function is identical to console.log(format[arg,...]) except it prints "WARN" prefix instead of "INFO".
console.error(format[arg,...])
This function is identical to console.log(format[arg,...]) except it prints "ERROR" prefix instead of "INFO".

الاسم

rhino - يستدعي واجهة JavaScript لتشغيل النصوص البرمجية في وضع الدُفعات أو وضع التفاعل

الملخص

rhino [خيارات] اسم_ملف_النص_البرمجي_أو_عنوان_الويب [وسائط_النص_البرمجي]

الوصف

توثق صفحة الدليل هذه بإيجاز الأمر rhino.

rhino هو نص برمجي بدء لواجهة JavaScript rhino التي توفر طريقة بسيطة لتشغيل النصوص البرمجية في وضع الدُفعات أو بيئة تفاعلية للبرمجة الاستكشافية.

الخيارات

-debug
إنشاء معلومات التصحيح. سيؤدي هذا إلى تعيين مستوى التحسين إلى صفر.
-e مصدر_النص_البرمجي
ينفذ مصدر_النص_البرمجي كنص برمجي JavaScript.
-encoding ترميز_الأحرف
تعيين ترميز الأحرف الذي يجب تطبيقه في حالة عدم اكتشافه.
-f اسم_ملف_النص_البرمجي_أو_عنوان_الويب
يقرأ محتوى اسم_ملف_النص_البرمجي_أو_عنوان_الويب وينفذه كنص برمجي JavaScript.
-fatal-warnings
تعيين التحذيرات كأخطاء.
-help, -?
عرض المساعدة.
-modules وحدة
إضافة وحدة إلى المسار.
-opt, -O مستوى_التحسين
يقوم بالتحسين عند المستوى optLevel، والذي يجب أن يكون عددًا صحيحًا بين 0 و 9.
-require
استخدام require().
-sandbox
ستكون مثيلات require() التي تم إنشاؤها معزولة.
-sealedlib
استخدام مكتبة قياسية مختومة.
-strict
تعيين الوضع الصارم.
-version رقم_الإصدار
يحدد إصدار اللغة المراد التجميع به. يجب أن يكون أحد الأرقام التالية: 100، 110، 120، 130، 140، 150، 160، 170، 180 أو 200.
-w
الإبلاغ عن التحذيرات.

خصائص معرفة مسبقًا

يمكن للنصوص البرمجية التي يتم تنفيذها في الواجهة الوصول إلى بعض الخصائص الإضافية للكائن الأعلى.

arguments
كائن الوسائط هو مصفوفة تحتوي على سلاسل نصية لجميع الوسائط المقدمة في سطر الأوامر عند استدعاء الواجهة.
help()
سيؤدي تنفيذ الدالة help إلى طباعة رسائل الاستخدام والمساعدة.
defineClass(اسم_الفئة)
تعريف امتداد باستخدام فئة Java المسماة باسم السلسلة النصية className. يستخدم ScriptableObject.defineClass() لتعريف الامتداد.
deserialize(اسم_الملف)
استعادة كائن تم كتابته سابقًا بواسطة استدعاء serialize من الملف المحدد.
load([اسم_الملف,...])
تحميل ملفات مصدر JavaScript المسماة بواسطة وسائط السلاسل النصية. إذا تم تقديم وسائط متعددة، يتم قراءة كل ملف وتنفيذه بالترتيب.
loadClass(اسم_الفئة)
تحميل وتنفيذ الفئة المسماة بواسطة السلسلة النصية className. يجب أن تكون الفئة هي فئة تطبق الواجهة Script، كما هو الحال مع أي نص برمجي تم تجميعه بواسطة jsc.
print([تعبير...])
تقييم وطباعة التعابير. يقوم بتقييم كل تعبير، وتحويل النتيجة إلى سلسلة نصية، وطباعتها.
readFile(المسار[, ترميز_الأحرف])
قراءة الملف المحدد وتحويل بايتاته إلى سلسلة نصية باستخدام ترميز الأحرف المحدد أو الترميز الافتراضي إذا لم يتم تقديم وسيط الترميز الصريح.
readUrl(عنوان_الويب[, ترميز_الأحرف])
فتح اتصال إدخال بعنوان الويب المحدد، وقراءة جميع بايتاته وتحويلها إلى سلسلة نصية باستخدام ترميز الأحرف المحدد أو الترميز الافتراضي إذا لم يتم تقديم وسيط الترميز الصريح.
runCommand(اسم_الأمر[, وسيط,...][خيارات])
تنفيذ الأمر المحدد مع الوسيط والخيارات المعطاة كعملية منفصلة وإرجاع حالة خروج العملية. للحصول على التفاصيل، راجع JavaDoc لـ org.mozilla.javascript.tools.shell.Global#runCommand.
setTimeout(دالة[, تأخير, وسيط,...])
تنفيذ "الدالة" بعد "تأخير" مللي ثانية. (إذا لم يتم تعيين "تأخير"، فسيتم تعيينه على 0.) تمرير أي معلمات لاحقة كوسائط. يتم تشغيل المهلات بعد انتهاء الدالة الحالية من التنفيذ، وفي الواجهة التفاعلية، فقط بعد الخروج من الواجهة. إرجاع معرف يمكن تمريره إلى "clearTimeout".
clearTimeout(معرف)
إلغاء مهلة تم تعيينها باستخدام "setTimeout".
serialize(كائن, اسم_الملف)
تسلسل الكائن المحدد إلى الملف المحدد.
spawn(دالة_أو_نص_برمجي)
تشغيل الدالة أو النص البرمجي المحدد في خيط مختلف.
sync(دالة)
ينشئ دالة متزامنة (بمعنى طريقة Java المتزامنة) من دالة موجودة. تقوم الدالة الجديدة بالمزامنة مع الكائن this الخاص باستدعائها.
quit()
إنهاء الواجهة. ستنتهي الواجهة أيضًا في الوضع التفاعلي إذا تم كتابة حرف نهاية الملف عند الموجه.
version([رقم])
الحصول على رقم إصدار JavaScript أو تعيينه. إذا لم يتم تقديم وسيط، يتم إرجاع رقم الإصدار الحالي. إذا تم تقديم وسيط، فيتوقع أن يكون أحد الأرقام التالية: 100، 110، 120، 130، 150، 160، 170، 180 أو 200 للإشارة إلى إصدار JavaScript 1.0، 1.1، 1.2، 1.3، 1.4، 1.5، 1.6، 1.7، 1.8 أو ECMAScript 6 على التوالي.
write([تعبير...])
تقييم وطباعة التعابير كما في "print"، ولكن بدون سطر جديد في النهاية.
console
يوفر كائن console واجهة تصحيح بسيطة مشابهة لكائن console الذي توفره متصفحات الويب.
console.log(التنسيق[وسيط,...])
للإخراج العام لمعلومات التسجيل. يتم دعم استبدال السلاسل النصية والوسائط الإضافية. يطبع نصًا منسقًا وفقًا للتنسيق والوسائط المقدمة مع بادئة "INFO". هذه الدالة متطابقة مع console.info(التنسيق[وسيط,...]).
console.trace(التنسيق[وسيط,...])
هذه الدالة متطابقة مع console.log(التنسيق[وسيط,...]) باستثناء أنها تطبع بادئة "TRACE" بدلاً من "INFO".
console.debug(التنسيق[وسيط,...])
هذه الدالة متطابقة مع console.log(التنسيق[وسيط,...]) باستثناء أنها تطبع بادئة "DEBUG" بدلاً من "INFO".
console.info(التنسيق[وسيط,...])
هذه الدالة متطابقة مع console.log(التنسيق[وسيط,...]).
console.warn(التنسيق[وسيط,...])
هذه الدالة متطابقة مع console.log(التنسيق[وسيط,...]) باستثناء أنها تطبع بادئة "WARN" بدلاً من "INFO".
console.error(التنسيق[وسيط,...])
هذه الدالة متطابقة مع console.log(التنسيق[وسيط,...]) باستثناء أنها تطبع بادئة "ERROR" بدلاً من "INFO".
