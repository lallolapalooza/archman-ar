Regexp__Common__URI__ftp(3pm)

الحزمة: perl-regexp-common

التراخيص: PerlArtistic, Artistic2.0, BSD, MIT

Regexp::Common::URI::ftp(3) وثائق Perl المساهمة من المستخدم Regexp::Common::URI::ftp(3)

الاسم

Regexp::Common::URI::ftp -- يُرجع نمطًا لمعرفات FTP.

الملخص

use Regexp::Common qw /URI/;
while (<>) {
    /$RE{URI}{FTP}/       and  print "يحتوي على معرف FTP.\n";
}

الوصف

$RE{URI}{FTP}{-type}{-password};

يُرجع تعبيرًا عاديًا لمعرفات FTP. ملاحظة: معرفات FTP ليست معرفة رسميًا. يُعرّف RFC 1738 عناوين URL لـ FTP، ولكن تم إبطال أجزاء من هذا RFC بواسطة RFC 2396. ومع ذلك، فإن الاختلافات بين RFC 1738 و RFC 2396 هي من النوع الذي لا يمكن تطبيقه بشكل مباشر على معرفات FTP.

هناك مشكلتان رئيسيتان:

كلمات المرور.
سمح RFC 1738 باسم مستخدم اختياري وكلمة مرور اختيارية (مفصولة بنقطتين) في عنوان URL لـ FTP. وبالتالي، لم يُسمح بالنقاط في اسم المستخدم أو كلمة المرور. يوصي RFC 2396 بشدة بعدم استخدام كلمات المرور في معرفات URI. يسمح بـ معلومات المستخدم بدلاً من ذلك. قد تحتوي هذه المعلومات للمستخدم على نقاط، وبالتالي تحتوي على أكثر من نقطة واحدة. التعبير العادي المُرجع يتبع مواصفات RFC 2396، ما لم يتم استخدام الخيار {-password}؛ عندها يسمح التعبير العادي باسم مستخدم اختياري وكلمة مرور، مفصولة بنقطتين.
محدد النوع ;type
لا يسمح RFC 1738 بفواصل منقوطة في أسماء مسارات FTP، لأن الفاصلة المنقوطة حرف محجوز لمعرفات FTP. تُستخدم الفاصلة المنقوطة لفصل المسار عن محدد النوع الاختياري. ومع ذلك، في RFC 2396، تتكون المسارات من مقاطع مفصولة بشرطة مائلة، وكل مقطع هو مجموعة من المعلمات مفصولة بفواصل منقوطة. التطبيق المباشر لـ RFC 2396 يعني أنه لا يمكن تمييز محدد النوع اللاحق عن المقطع الأخير من المسار الذي يحتوي على معلمتين، الأخيرة تبدأ بـ type=. لذلك، اخترنا منع الفاصلة المنقوطة في جزء المسار من معرف FTP.

علاوة على ذلك، يسمح RFC 1738 بثلاث قيم لمحدد النوع، A و I و D (سواء كانت بأحرف كبيرة أو صغيرة). ومع ذلك، فإن مسودة الإنترنت حول معرفات FTP [DRAFT-FTP-URL] (التي انتهت صلاحيتها في مايو 1997) تلاحظ عدم وجود تنفيذ متسق للمعلمة D وتتخلى عن D من مجموعة القيم الممكنة. نتبع هذه الممارسة؛ ومع ذلك، يمكن تحقيق سلوك RFC 1738 باستخدام المعلمة -type = "[ADIadi]">.

لمعرفات FTP الصيغة التالية:

"ftp:" "//" [ userinfo "@" ] host [ ":" port ]
            [ "/" path [ ";type=" value ]]

عند استخدام {-password}، لدينا الصيغة:

"ftp:" "//" [ user [ ":" password ] "@" ] host [ ":" port ]
            [ "/" path [ ";type=" value ]]

ضمن "{-keep}"، يتم إرجاع ما يلي:
