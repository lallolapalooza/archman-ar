rtcRetainBuffer(3) Embree Ray Tracing Kernels 3 rtcRetainBuffer(3)

NAME

rtcRetainBuffer - يزيد عداد مراجع المخزن المؤقت

SYNOPSIS

#include <embree3/rtcore.h>
void rtcRetainBuffer(RTCBuffer buffer);

DESCRIPTION

تتم إدارة كائنات المخزن المؤقت بواسطة عدادات المراجع. تقوم الدالة `rtcRetainBuffer` بزيادة عداد مراجع كائن المخزن المؤقت الممرر (وسيط المخزن المؤقت). تسمح هذه الدالة، جنبًا إلى جنب مع `rtcReleaseBuffer`، باستخدام إدارة المراجع الداخلية في فئة غلاف C++ للتعامل مع ملكية الكائن.

EXIT STATUS

في حالة الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام `rtcGetDeviceError`.

[rtcNewBuffer]، [rtcReleaseBuffer]
