readdir(2) دليل استدعاءات النظام readdir(2)

اسم

readdir - قراءة إدخال دليل

المكتبة

مكتبة C القياسية (libc, -lc)

ملخص

#include <sys/syscall.h>      /* تعريف الثوابت SYS_* */
#include <unistd.h>
int syscall(SYS_readdir, unsigned int fd,
            struct old_linux_dirent *dirp, unsigned int count);

ملاحظة: لا يوجد تعريف لـ struct old_linux_dirent؛ انظر VERSIONS.

الوصف

هذه ليست الدالة التي تهتم بها. انظر readdir(3) لواجهة مكتبة C المتوافقة مع POSIX. هذه الصفحة توثق واجهة استدعاء النظام الأساسية للنواة، والتي تم استبدالها بواسطة getdents(2).

تقوم readdir() بقراءة بنية old_linux_dirent واحدة من الدليل المشار إليه بواسطة واصف الملف fd إلى المخزن المؤقت الذي يشير إليه dirp. يتم تجاهل الوسيط count؛ يتم قراءة بنية old_linux_dirent واحدة على الأكثر.

يتم تعريف بنية old_linux_dirent (خاصة في ملف نواة Linux fs/readdir.c) على النحو التالي:


struct old_linux_dirent {
    unsigned long d_ino;     /* رقم العقدة */
    unsigned long d_offset;  /* الإزاحة إلى old_linux_dirent هذا */
    unsigned short d_namlen; /* طول d_name هذا */
    char  d_name[1];         /* اسم الملف (منتهي بصفر) */
}

d_ino هو رقم العقدة. d_offset هو المسافة من بداية الدليل إلى old_linux_dirent هذا. d_reclen هو حجم d_name، دون حساب الصفر الختامي ('\0'). d_name هو اسم ملف منتهي بصفر.

قيمة الإرجاع

عند النجاح، يتم إرجاع 1. عند نهاية الدليل، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EBADF
واصف ملف fd غير صالح.
EFAULT
يشير الوسيط خارج مساحة عنوان العملية المتصلة.
EINVAL
المخزن المؤقت للنتيجة صغير جدًا.
ENOENT
لا يوجد دليل بهذا الاسم.
ENOTDIR
واصف الملف لا يشير إلى دليل.

الإصدارات

ستحتاج إلى تعريف بنية old_linux_dirent بنفسك. ومع ذلك، ربما يجب عليك استخدام readdir(3) بدلاً من ذلك.

استدعاء النظام هذا غير موجود على x86-64.
