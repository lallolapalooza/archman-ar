Random(3o)

Random number generation

NAME

Random — Pseudo-random number generation.

Module

Random

Documentation

This module provides functions for generating pseudo-random numbers. The functions use a default generator that is initialized automatically. For more control, you can create your own generator using Random.State.make_self_init and pass it to the functions that accept a generator as an argument.
