rtcNewBuffer.3embree3

الحزمة: embree3

التراخيص: Apache

rtcNewBuffer(3) أنوية تتبع الأشعة Embree 3 rtcNewBuffer(3)

الاسم

rtcNewBuffer - إنشاء مخزن بيانات جديد

الملخص

#include <embree3/rtcore.h>
RTCBuffer rtcNewBuffer(
  RTCDevice device,
  size_t byteSize
);

الوصف

تقوم الدالة rtcNewBuffer بإنشاء كائن مخزن بيانات جديد بالحجم المحدد بالبايت (وسيطة byteSize) والذي يتم ربطه بالجهاز المحدد (وسيطة device). كائن المخزن مرجعي العد مع عدد مرجع أولي قدره 1. يمكن تحرير كائن المخزن المُرجع باستخدام استدعاء API rtcReleaseBuffer. يتم تخصيص عدد البايتات المحدد عند إنشاء المخزن وسيتم إلغاء تخصيصه عند تدمير المخزن.

حالة الخروج

عند الفشل، يتم إرجاع NULL ويتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.

راجع أيضًا

[rtcRetainBuffer]، [rtcReleaseBuffer]
