NAME

resize-part-image - تغيير حجم صورة قسم

SYNOPSIS

resize-part-image [ خيارات ] IMAGE SIZE [OUTPUT]

OPTIONS

-v | --verbose
إظهار مخرجات أوامر resize و fsck
IMAGE
الملف المستهدف لتغيير الحجم
SIZE
يتم تحديد الحجم الجديد لكل resize2fs(8)، على سبيل المثال "1G" لـ 1 جيجابايت
[OUTPUT]
إذا تم إعطاء اسم ملف OUTPUT، فلا تقم بتعديل 'IMAGE'، ولكن قم بإنشاء ملف جديد 'OUTPUT'

DESCRIPTION

تغيير حجم صورة قسم إلى حجم جديد.

SEE ALSO

resize2fs(8)

AUTHOR

تمت كتابة صفحة الدليل هذه بواسطة Dustin Kirkland <kirkland@canonical.com> لأنظمة Ubuntu (ولكن يمكن استخدامها من قبل آخرين). يُمنح الإذن بنسخ وتوزيع و/أو تعديل هذا المستند بموجب شروط رخصة جنو العمومية العامة، الإصدار 3 الصادرة عن مؤسسة البرمجيات الحرة.

في أنظمة Debian، يمكن العثور على النص الكامل لرخصة جنو العمومية العامة في /usr/share/common-licenses/GPL.
