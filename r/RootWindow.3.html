الوصف

تعيد وحدة الماكرو AllPlanes قيمة بجميع البتات مضبوطة على 1 مناسبة للاستخدام في معامل مستوى (plane) لإجراء.

تعيد وحدة الماكرو BlackPixel قيمة البكسل الأسود للشاشة المحددة.

تعيد وحدة الماكرو WhitePixel قيمة البكسل الأبيض للشاشة المحددة.

تعيد وحدة الماكرو ConnectionNumber رقم اتصال للشاشة المحددة.

تعيد وحدة الماكرو DefaultColormap معرف خريطة الألوان الافتراضية للتخصيص على الشاشة المحددة.

تعيد وحدة الماكرو DefaultDepth عمق (عدد المستويات) النافذة الجذرية الافتراضية للشاشة المحددة.

تعيد الدالة XListDepths مصفوفة الأعماق المتاحة على الشاشة المحددة. إذا كان رقم الشاشة المحدد صالحًا وتم تخصيص ذاكرة كافية للمصفوفة، فإن XListDepths تضبط count_return على عدد الأعماق المتاحة. خلاف ذلك، فإنها لا تضبط count_return وتعيد NULL. لتحرير الذاكرة المخصصة لمصفوفة الأعماق، استخدم XFree.

تعيد وحدة الماكرو DefaultGC وحدة الرسم البياني الافتراضية للنافذة الجذرية للشاشة المحددة.

تعيد وحدة الماكرو DefaultRootWindow النافذة الجذرية للشاشة الافتراضية.

تعيد وحدة الماكرو DefaultScreenOfDisplay الشاشة الافتراضية للشاشة المحددة.

تعيد وحدة الماكرو DefaultScreen رقم الشاشة الافتراضي المشار إليه في الإجراء XOpenDisplay.

تعيد وحدة الماكرو DefaultVisual نوع العرض الافتراضي للشاشة المحددة.

تعيد وحدة الماكرو DisplayCells عدد الإدخالات في خريطة الألوان الافتراضية.

تعيد وحدة الماكرو DisplayPlanes عمق النافذة الجذرية للشاشة المحددة.

تعيد وحدة الماكرو DisplayString السلسلة التي تم تمريرها إلى XOpenDisplay عند فتح الشاشة الحالية.

تعيد الدالة XMaxRequestSize الحد الأقصى لحجم الطلب (بوحدات 4 بايت) التي يدعمها الخادم دون استخدام ترميز بروتوكول بطول ممتد. لا يمكن أن تتجاوز طلبات البروتوكول الفردية إلى الخادم هذا الحجم ما لم يدعم الخادم ترميز بروتوكول بطول ممتد. يضمن البروتوكول ألا يقل الحجم عن 4096 وحدة (16384 بايت). يقوم Xlib تلقائيًا بتقسيم البيانات إلى طلبات بروتوكول متعددة حسب الحاجة للدوال التالية: XDrawPoints، XDrawRectangles، XDrawSegments، XFillArcs، XFillRectangles، و XPutImage.

تعيد الدالة XExtendedMaxRequestSize صفرًا إذا كانت الشاشة المحددة لا تدعم ترميز بروتوكول بطول ممتد؛ بخلاف ذلك، فإنها تعيد الحد الأقصى لحجم الطلب (بوحدات 4 بايت) الذي يدعمه الخادم باستخدام الترميز بطول ممتد. ستستخدم دوال Xlib XDrawLines، XDrawArcs، XFillPolygon، XChangeProperty، XSetClipRectangles، و XSetRegion الترميز بطول ممتد حسب الضرورة، إذا كان الخادم يدعمه. يُسمح باستخدام الترميز بطول ممتد في دوال Xlib الأخرى (على سبيل المثال، XDrawPoints، XDrawRectangles، XDrawSegments، XFillArcs، XFillRectangles، XPutImage) ولكن ليس مطلوبًا؛ قد يختار تطبيق Xlib تقسيم البيانات عبر طلبات أصغر متعددة بدلاً من ذلك.

تستخرج وحدة الماكرو LastKnownRequestProcessed الرقم المسلسل الكامل لآخر طلب تم معالجته بواسطة خادم X والذي يعرفه Xlib.

تستخرج وحدة الماكرو NextRequest الرقم المسلسل الكامل الذي سيتم استخدامه للطلب التالي.

تعيد وحدة الماكرو ProtocolVersion رقم الإصدار الرئيسي (11) لبروتوكول X المرتبط بالشاشة المتصلة.

تعيد وحدة الماكرو ProtocolRevision رقم مراجعة بروتوكول الخادم X الفرعي.

تعيد وحدة الماكرو QLength طول طابور الأحداث للشاشة المتصلة.

تعيد وحدة الماكرو RootWindow النافذة الجذرية.

تعيد وحدة الماكرو ScreenCount عدد الشاشات المتاحة.

تعيد وحدة الماكرو ScreenOfDisplay مؤشرًا إلى الشاشة المحددة للشاشة.

تعيد وحدة الماكرو ServerVendor مؤشرًا إلى سلسلة نصية منتهية بصفر توفر تعريفًا لمالك تطبيق خادم X.

تعيد وحدة الماكرو VendorRelease رقمًا يتعلق بإصدار البائع لخادم X.

NAME

RootWindow — Root window information

SYNTAX

int XRootWindow(Display *display, int screen_num);

ARGUMENTS

display
Specifies the connection to the X server.
screen_num
Specifies the screen number.

DESCRIPTION

The XRootWindow function returns the Window ID for the root window of the specified screen.
