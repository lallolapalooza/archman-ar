rtcGetGeometryTransform.3embree3

الحزمة: embree3

التراخيص: Apache

rtcGetGeometryTransform(3) أنوية تتبع الأشعة Embree 3 rtcGetGeometryTransform(3)

الاسم

rtcGetGeometryTransform - يعيد التحويل المثالي للمثيل
  للأبعاد الزمنية المحددة

الملخص

#include <embree3/rtcore.h>
void rtcGetGeometryTransform(
  RTCGeometry geometry,
  float time,
  enum RTCFormat format,
  void* xfm
);

الوصف

تقوم الدالة rtcGetGeometryTransform بإعادة التحويل المحلي إلى العالمي (xfm) للهندسة المثالية (geometry) لوقت معين (time في النطاق [0, 1]) بالصيغة المحددة (format).

الصيغ المحتملة للمصفوفة المعادة هي:

•
RTC_FORMAT_FLOAT3X4_ROW_MAJOR: مصفوفة الأعداد العائمة 3×4 موضوعة بترتيب الصفوف.
•
RTC_FORMAT_FLOAT3X4_COLUMN_MAJOR: مصفوفة الأعداد العائمة 3×4 موضوعة بترتيب الأعمدة.
•
RTC_FORMAT_FLOAT4X4_COLUMN_MAJOR: مصفوفة الأعداد العائمة 3×4 موضوعة بترتيب الأعمدة كمصفوفة متجانسة 4×4 مع صف أخير مساوٍ لـ (0, 0, 0, 1).

حالة الخروج

عند الفشل، يتم تعيين رمز خطأ يمكن الاستعلام عنه باستخدام rtcGetDeviceError.

انظر أيضاً

[RTC_GEOMETRY_TYPE_INSTANCE]، [rtcSetGeometryTransform]
