الاسم

runc-list - يسرد الحاويات

الملخص

runc list [خيار ...]

الوصف

يقوم الأمر list بسرد الحاويات. لاحظ أنه يمكن تحديد خيار عام --root لتغيير الجذر الافتراضي. لوصف --root، انظر runc(8).

الخيارات

--format|-f table|json
تحديد التنسيق. الافتراضي هو table. تنسيق json يوفر المزيد من التفاصيل.
--quiet|-q
عرض معرفات الحاويات فقط.

أمثلة

لسرد الحاويات التي تم إنشاؤها باستخدام الجذر الافتراضي:

# runc list

لسرد الحاويات بتنسيق JSON قابل للقراءة (بمساعدة أداة jq(1)):

# runc list -f json | jq

لسرد الحاويات التي تم إنشاؤها باستخدام الجذر /tmp/myroot:

# runc --root /tmp/myroot
