الحزمة: radare2

التراخيص: GPL-3.0-only, LGPL-3.0-only

RABIN2(1) دليل الأوامر العامة RABIN2(1)

الاسم

rabin2 — مستخرج معلومات البرامج الثنائية

الملخص

rabin2 [-AceghHiIsSMzlpRrLxvhqQTuUwV] [-a arch] [-b bits] [-B addr] [-C fmt:C:[D]] [-D lang sym|-] [-f subbin] [-k query] [-K algo] [-O binop] [-o str] [-m addr] [-@ addr] [-n str] [-X fmt file ...] file

الوصف

يسمح لك هذا البرنامج بالحصول على معلومات حول ملفات ELF/PE/MZ و CLASS بطريقة بسيطة.

كل هذه العلامات سطر الأوامر متاحة أيضًا تحت الأمر i في radare2. اكتب i? للمساعدة.

-@ addr
عرض معلومات (رمز، قسم، استيراد) للعنوان المحدد
-A
قائمة البرامج الثنائية الفرعية والأزواج المعمارية/البتات المرتبطة بها
-a arch
تعيين المعمارية (x86، arm، .. يقبل الشرطة السفلية للبتات x86_32)
-b bits
تعيين البتات (32، 64، ...)
-B addr
تجاوز baddr
-c
قائمة الفئات
-cc
قائمة الفئات بتنسيق رأس
-C [fmt:C[:D]]
إنشاء [elf,mach0,pe] للبرامج الثنائية الصغيرة arm و x86-32/64 حيث 'C' هي قائمة سداسية عشرية لبايتات الكود و ':D' هي إضافة اختيارية لوصف البايتات لقسم البيانات.
-d
عرض معلومات التصحيح/dwarf
-D lang symbolname|-
إلغاء تشفير اسم الرمز (أو - للقراءة من stdin) للغة (cxx، swift، java، cxx، ..)
-e
عرض نقاط الدخول للملف الموجود على القرص وفي الذاكرة
-ee
عرض المنشئات/الهادمات (نقاط الدخول الموسعة)
-f subbin
تحديد بنية البرنامج الثنائي الفرعي. مفيد للبرامج الثنائية fat-mach0
-F binfmt
فرض استخدام هذا المكون الإضافي للبرنامج الثنائي (تجاهل فحص الرأس)
-g
عرض جميع المعلومات الممكنة
-G addr
تحميل عنوان . الإزاحة إلى الرأس
-h
عرض رسالة المساعدة للاستخدام.
-H
عرض حقول الرأس (انظر الأمر ih في r2)
-I
عرض معلومات البرنامج الثنائي (انظر الأمر iI في r2)
-i
عرض الواردات (الرموز المستوردة من المكتبات) (انظر الأمر ii في r2)
-j
إخراج بتنسيق json
-k query
تنفيذ استعلام SDB على الملف المحمل
-K algo
اختيار خوارزمية تدقيق rahash2 ليتم تنفيذها على قوائم الأقسام (وربما غيرها في المستقبل) أي 'rabin2 -K md5 -S /bin/ls'
-l
قائمة المكتبات المرتبطة بالبرنامج الثنائي
-L
قائمة المكونات الإضافية المدعومة للبرامج الثنائية
-M
عرض عنوان الرمز 'main'
-m addr
عرض مرجع سطر المصدر من عنوان معين
-N minlen:maxlen
فرض الحد الأدنى والأقصى لعدد الأحرف لكل سلسلة (انظر -z و -zz). إذا (strlen>minlen && (!maxlen || strlen<=maxlen))
-n str
عرض معلومات (رمز، قسم، استيراد) عند إزاحة السلسلة
-o str
ملف/مجلد الإخراج لعمليات الكتابة (out افتراضيًا)
-O binop
تنفيذ عملية ثنائية على البرنامج الثنائي المستهدف (تفريغ، تغيير الحجم، تغيير الأقسام، ...) انظر '-O help' لمزيد من المعلومات
-p
تعطيل VA. عرض دائمًا العناوين الفعلية (ليس هو نفسه -B0)
-P
عرض معلومات التصحيح/pdb
-PP
تنزيل ملف pdb للبرنامج الثنائي
-q
كن هادئًا، اعرض القليل من البيانات فقط
-qq
عرض معلومات أقل (لا يوجد إزاحة/حجم لـ -z على سبيل المثال.)
-Q
عرض عنوان التحميل المستخدم بواسطة dlopen (مكتبات غير ASLR)
-r
عرض الإخراج بتنسيق radare
-R
عرض عمليات النقل
-s
عرض الرموز المصدرة
-S
عرض الأقسام
-SS
عرض المقاطع
-t
عرض تجزئات الملف
-T
عرض الشهادات
-u
غير مفلتر (لا تعيد تسمية الرموز/الأقسام المكررة)
-U
عرض الموارد
-v
عرض معلومات الإصدار.
-V
عرض معلومات الإصدار الثنائي.
-w
عرض كتل try/catch
-x
استخراج جميع البرامج الثنائية الفرعية من برنامج ثنائي مدمج (على سبيل المثال: fatmach0)
-X format file ...
تجميع ملف مدمج أو سحاب يحتوي على جميع الملفات المقدمة (fat, zip)
-z
عرض السلاسل داخل قسم .data (مثل ما يفعله gnu strings)
-Z
تقدير حجم البرنامج الثنائي
-zz
يعرض السلاسل من البرامج الثنائية الخام
-zzz
تفريغ السلاسل الخام إلى المخرج القياسي
