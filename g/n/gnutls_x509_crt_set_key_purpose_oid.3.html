gnutls_x509_crt_set_key_purpose_oid(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crt_set_key_purpose_oid(3) gnutls gnutls_x509_crt_set_key_purpose_oid(3)

الاسم

gnutls_x509_crt_set_key_purpose_oid - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crt_set_key_purpose_oid(gnutls_x509_crt_t cert, const void * oid, unsigned int critical);

الوسائط

gnutls_x509_crt_t cert
شهادة من النوع gnutls_x509_crt_t
const void * oid
مؤشر إلى سلسلة نصية منتهية بصفر تحمل معرف OID
unsigned int critical
ما إذا كان هذا الامتداد سيكون حرجًا أم لا

الوصف

ستقوم هذه الوظيفة بتعيين معرفات OID لغرض المفتاح للشهادة. يتم تخزين هذه في امتداد استخدام المفتاح الموسع (2.5.29.37) انظر تعريفات GNUTLS_KP_* للأسماء القابلة للقراءة البشرية.

ستقوم الاستدعاءات اللاحقة لهذه الوظيفة بإلحاق معرفات OID بقائمة معرفات OID.

القيمة المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
