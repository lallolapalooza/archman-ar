gnutls_cipher_decrypt3(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_cipher_decrypt3(3) gnutls gnutls_cipher_decrypt3(3)

اسم

gnutls_cipher_decrypt3 - API function

الملخص

#include <gnutls/crypto.h>

int gnutls_cipher_decrypt3(gnutls_cipher_hd_t handle, const void * ctext, size_t ctext_len, void * ptext, size_t * ptext_len, unsigned flags);

المعاملات

gnutls_cipher_hd_t handle
is a gnutls_cipher_hd_t type
const void * ctext
the data to decrypt
size_t ctext_len
the length of data to decrypt
void * ptext
the decrypted data
size_t * ptext_len
the available length for decrypted data
unsigned flags
flags for padding

الوصف

This function will decrypt the given data using the algorithm specified by the context. If flags is specified, padding for the decrypted data will be removed accordingly and ptext_len will be updated.

القيم المعادة

Zero or a negative error code on error.

منذ

3.7.7
