gnutls_hkdf_expand(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_hkdf_expand(3) gnutls gnutls_hkdf_expand(3)

الاسم

gnutls_hkdf_expand - وظيفة API

الملخص

#include <gnutls/crypto.h>

int gnutls_hkdf_expand(gnutls_mac_algorithm_t mac, const gnutls_datum_t * key, const gnutls_datum_t * info, void * output, size_t length);

المعاملات

gnutls_mac_algorithm_t mac
خوارزمية التجزئة المستخدمة داخليًا
const gnutls_datum_t * key
المفتاح شبه العشوائي الذي تم إنشاؤه باستخدام HKDF-Extract
const gnutls_datum_t * info
بيانات المعلومات الاختيارية
void * output
القيمة الناتجة لعملية التوسع
size_t length
الطول المطلوب لمفتاح الإخراج

الوصف

ستقوم هذه الوظيفة باشتقاق مواد مفاتيح ذات طول متغير من المفتاح شبه العشوائي باستخدام وظيفة HKDF-Expand كما هو محدد في RFC 5869.

الإرجاع

صفر أو رمز خطأ سالب عند حدوث خطأ.
