gnutls_register_custom_url(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_register_custom_url(3) gnutls gnutls_register_custom_url(3)

الاسم

gnutls_register_custom_url - دالة API

الملخص

#include <gnutls/urls.h>

int gnutls_register_custom_url(const gnutls_custom_url_st * st);

الوسائط

const gnutls_custom_url_st * st
هيكل gnutls_custom_url_st

الوصف

تسجيل عنوان URL مخصص. سيؤثر هذا على الدوال التالية: gnutls_url_is_supported()، gnutls_privkey_import_url()، gnutls_pubkey_import_url، gnutls_x509_crt_import_url() وجميع الدوال التي تعتمد عليها، على سبيل المثال gnutls_certificate_set_x509_key_file2().

يجب أن يكون الهيكل ودوال الاستدعاء المقدمة صالحة طوال عمر العملية. سيفشل تسجيل نوع عنوان URL موجود بـ GNUTLS_E_INVALID_REQUEST. منذ GnuTLS 3.5.0 يمكن استخدام هذه الدالة لتجاوز عناوين URL المدمجة.

هذه الدالة ليست آمنة للاستخدام المتزامن.

القيمة المرجعة

ترجع صفرًا إذا تم استيراد الهيكل المقدم أو قيمة سالبة بخلاف ذلك.
