الاسم

gnutls_x509_privkey_export_ecc_raw - وظيفة API

ملخص

#include <gnutls/x509.h>

int gnutls_x509_privkey_export_ecc_raw(gnutls_x509_privkey_t key, gnutls_ecc_curve_t * curve, gnutls_datum_t * x, gnutls_datum_t * y, gnutls_datum_t * k);

سيمثل المفتاح الخاص

الوصف

ستقوم هذه الوظيفة بتصدير معلمات المفتاح الخاص ECC الموجودة في البنية المعطاة. سيتم تخصيص المعلمات الجديدة باستخدام gnutls_malloc() وسيتم تخزينها في بيانات مناسبة.

في منحنيات EdDSA، ستكون المعلمة y هي NULL وستكون المعلمات الأخرى بالتنسيق الأصلي للمنحنى.

الإرجاع

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.

3.0
