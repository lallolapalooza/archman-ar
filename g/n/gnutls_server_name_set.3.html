gnutls_server_name_set(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_server_name_set(3) gnutls gnutls_server_name_set(3)

الاسم

gnutls_server_name_set - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_server_name_set(gnutls_session_t session, gnutls_server_name_type_t type, const void * name, size_t name_length);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
gnutls_server_name_type_t type
يحدد نوع المؤشر
const void * name
هو سلسلة نصية تحتوي على اسم الخادم.
size_t name_length
يحمل طول الاسم باستثناء حرف النهاية الفارغ

الوصف

يجب استخدام هذه الوظيفة من قبل العملاء الذين يرغبون في إبلاغ (عبر آلية امتداد TLS) الخادم بالاسم الذي اتصلوا به. يجب استخدام هذا من قبل العملاء الذين يتصلون بالخوادم التي تقوم باستضافة افتراضية.

تعتمد قيمة name على نوع type. في حالة GNUTLS_NAME_DNS، يُتوقع سلسلة اسم مجال UTF-8 منتهية بفارغ، بدون النقطة اللاحقة.

لا يُسمح بتعيين عناوين IPv4 أو IPv6 بواسطة هذه الوظيفة. إذا تم استدعاء الوظيفة باسم بطول name_length صفر، فسيتم مسح جميع أسماء الخوادم المعينة.

القيم المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
