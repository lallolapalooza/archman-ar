gnutls_auth_get_type(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_auth_get_type(3) gnutls gnutls_auth_get_type(3)

الاسم

gnutls_auth_get_type - دالة API

الملخص

#include <gnutls/gnutls.h>

gnutls_credentials_type_t gnutls_auth_get_type(gnutls_session_t session);

الوسائط

gnutls_session_t session
هو نوع gnutls_session_t.

الوصف

يعيد نوع بيانات الاعتماد لمخطط المصادقة الحالي. يجب استخدام المعلومات المُعادة لتمييز الدالة المستخدمة للوصول إلى بيانات الاعتماد.

على سبيل المثال، لحالات التشفير المتعلقة بالشهادات (خوارزميات تبادل المفاتيح: GNUTLS_KX_RSA، GNUTLS_KX_DHE_RSA)، يجب استخدام نفس الدالة للوصول إلى بيانات الاعتماد.

لاحظ أنه في الجلسات المستأنفة، تعيد هذه الدالة المخطط المستخدم في مصادقة الجلسة الأصلية.

القيم المُعادة

نوع بيانات الاعتماد لمخطط المصادقة الحالي، وهو نوع gnutls_credentials_type_t.
