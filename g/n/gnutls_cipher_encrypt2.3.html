gnutls_cipher_encrypt2(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_cipher_encrypt2(3) gnutls gnutls_cipher_encrypt2(3)

الاسم

gnutls_cipher_encrypt2 - دالة API

ملخص

#include <gnutls/crypto.h>

int gnutls_cipher_encrypt2(gnutls_cipher_hd_t handle, const void * ptext, size_t ptext_len, void * ctext, size_t ctext_len);

المعاملات

gnutls_cipher_hd_t handle
هو نوع gnutls_cipher_hd_t
const void * ptext
البيانات المراد تشفيرها
size_t ptext_len
طول البيانات المراد تشفيرها
void * ctext
البيانات المشفرة
size_t ctext_len
الطول المتاح للبيانات المشفرة

الوصف

ستقوم هذه الدالة بتشفير البيانات المعطاة باستخدام الخوارزمية المحددة بواسطة السياق. بالنسبة لمشفرات الكتل، يجب أن يكون ptext_len مضاعفًا لحجم الكتلة. بالنسبة للمشفرات المدعومة، سيكون طول البيانات المشفرة مساويًا لطول النص العادي.
