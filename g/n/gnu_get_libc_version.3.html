gnu_get_libc_version(3) دليل وظائف المكتبة gnu_get_libc_version(3)

الاسم

gnu_get_libc_version, gnu_get_libc_release - الحصول على إصدار glibc وإصداره

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <gnu/libc-version.h>
const char *gnu_get_libc_version(void);
const char *gnu_get_libc_release(void);

الوصف

تقوم الوظيفة gnu_get_libc_version() بإرجاع سلسلة نصية تحدد إصدار glibc المتاح على النظام.

تقوم الوظيفة gnu_get_libc_release() بإرجاع سلسلة نصية تشير إلى حالة إصدار glibc المتاح على النظام. ستكون هذه سلسلة نصية مثل stable.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
gnu_get_libc_version (), gnu_get_libc_release () أمان الخيوط MT-Safe

المعايير

GNU.

التاريخ

glibc 2.1.

أمثلة

عند التشغيل، سيظهر البرنامج أدناه مخرجات مثل التالية:


$ ./a.out
GNU libc version: 2.8
GNU libc release: stable

مصدر البرنامج

#include <stdio.h>
#include <stdlib.h>
#include <gnu/libc-version.h>
int
main(void)
{
    printf("GNU libc version: %s\n", gnu_get_libc_version());
    printf("GNU libc release: %s\n", gnu_get_libc_release());
    exit(EXIT_SUCCESS);
}
