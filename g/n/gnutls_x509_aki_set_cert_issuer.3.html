gnutls_x509_aki_set_cert_issuer(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_aki_set_cert_issuer(3) gnutls gnutls_x509_aki_set_cert_issuer(3)

الاسم

gnutls_x509_aki_set_cert_issuer - وظيفة API

الملخص

#include <gnutls/x509-ext.h>

int gnutls_x509_aki_set_cert_issuer(gnutls_x509_aki_t aki, unsigned int san_type, const gnutls_datum_t * san, const char * othername_oid, const gnutls_datum_t * serial);

المعاملات

gnutls_x509_aki_t aki
معرف مفتاح السلطة
unsigned int san_type
نوع الاسم (من gnutls_subject_alt_names_t)، يمكن أن يكون فارغاً
const gnutls_datum_t * san
بيانات الاسم البديل
const char * othername_oid
معرف الكائن إذا كان san_type هو GNUTLS_SAN_OTHERNAME
const gnutls_datum_t * serial
رقم authorityCertSerialNumber (يمكن أن يكون فارغاً)

الوصف

ستقوم هذه الوظيفة بتعيين اسم authorityCertIssuer ورقم authorityCertSerialNumber ليتم تخزينهما في نوع aki. عند تخزين أسماء متعددة، يجب تعيين الرقم التسلسلي في الاستدعاء الأول، ويجب استخدام NULL في الاستدعاءات اللاحقة.

منذ الإصدار 3.5.7، يتم تحويل GNUTLS_SAN_RFC822NAME و GNUTLS_SAN_DNSNAME و GNUTLS_SAN_OTHERNAME_XMPP إلى تنسيق ACE عند الضرورة.

القيمة المُعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.

منذ

3.3.0
