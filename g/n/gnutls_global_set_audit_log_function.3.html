gnutls_global_set_audit_log_function(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_global_set_audit_log_function(3) gnutls gnutls_global_set_audit_log_function(3)

الاسم

gnutls_global_set_audit_log_function - استدعاء API

الملخص

#include <gnutls/gnutls.h>

void gnutls_global_set_audit_log_function(gnutls_audit_log_func log_func);

المعاملات

gnutls_audit_log_func log_func
هي دالة تسجيل التدقيق

الوصف

هذه هي الدالة لتعيين دالة تسجيل التدقيق. هذه دالة للإبلاغ عن مشاكل هامة، مثل الهجمات المحتملة في البروتوكول. هذا يختلف عن gnutls_global_set_log_function() لأنه سيبلغ أيضًا عن الأحداث الخاصة بالجلسة. سيكون معامل الجلسة فارغًا إذا لم تكن هناك جلسة TLS مقابلة.


gnutls_audit_log_func هو من النوع، void (*gnutls_audit_log_func)( gnutls_session_t, const char*);

منذ

3.0
