gnutls_idna_map(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_idna_map(3) gnutls gnutls_idna_map(3)

الاسم

gnutls_idna_map - دالة API

ملخص

#include <gnutls/gnutls.h>

int gnutls_idna_map(const char * input, unsigned ilen, gnutls_datum_t * out, unsigned flags);

المعاملات

const char * input
يحتوي على اسم النطاق بتنسيق UTF-8
unsigned ilen
طول السلسلة المقدمة
gnutls_datum_t * out
النتيجة في سلسلة مخصصة منهية بـ null
unsigned flags
يجب أن يكون صفراً

الوصف

ستقوم هذه الدالة بتحويل اسم النطاق المحدد بتنسيق UTF-8، إلى تعيين IDNA الخاص به في متغير مخصص. لاحظ أنه اعتمادًا على العلامات التي تم تجميع مكتبة gnutls المستخدمة بها، قد يختلف ناتج هذه الدالة (أي، قد يكون IDNA2008، أو IDNA2003).

لإجبار IDNA2008، حدد العلامة GNUTLS_IDNA_FORCE_2008. في حال لم يتم تجميع GnuTLS بالتبعيات الضرورية، سيتم إرجاع GNUTLS_E_UNIMPLEMENTED_FEATURE للإشارة إلى أن gnutls غير قادر على إجراء التحويل المطلوب.

لاحظ أيضًا أن هذه الدالة سترجع سلسلة فارغة إذا تم توفير سلسلة فارغة كمدخل.

الإرجاع

GNUTLS_E_INVALID_UTF8_STRING عند وجود بيانات UTF-8 غير صالحة، أو 0 عند النجاح.

منذ

3.5.8
