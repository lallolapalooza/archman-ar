gnutls_heartbeat_ping(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_heartbeat_ping(3) gnutls gnutls_heartbeat_ping(3)

الاسم

gnutls_heartbeat_ping - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_heartbeat_ping(gnutls_session_t session, size_t data_size, unsigned int max_tries, unsigned int flags);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
size_t data_size
هو طول حمولة الاختبار.
unsigned int max_tries
إذا كانت الأعلام GNUTLS_HEARTBEAT_WAIT فهذا يحدد عدد إعادة الإرسال. استخدم الصفر لعدد غير محدود (حتى نفاد الوقت).
unsigned int flags
إذا كانت GNUTLS_HEARTBEAT_WAIT فانتظر استجابة أو انتهاء الوقت بدلاً من العودة فورًا.

الوصف

تقوم هذه الوظيفة بإرسال اختبار إلى الطرف المقابل. إذا تم تعيين flags إلى GNUTLS_HEARTBEAT_WAIT فإنها تنتظر استجابة من الطرف المقابل.

لاحظ أنه يوصى بشدة باستخدام هذه الوظيفة مع العلم GNUTLS_HEARTBEAT_WAIT، أو ستحتاج إلى التعامل مع إعادة الإرسال وانتهاء الوقت يدويًا.

إجمالي بيانات TLS المنقولة كجزء من رسالة الاختبار تُعطى بالصيغة التالية: MAX(16, data_size )+gnutls_record_overhead_size()+3.

القيم المعادة

GNUTLS_E_SUCCESS عند النجاح، وإلا فإن رمز خطأ سالب.

منذ

3.1.2
