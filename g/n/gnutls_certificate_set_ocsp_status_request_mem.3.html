الاسم

gnutls_certificate_set_ocsp_status_request_mem - وظيفة API

ملخص

#include <gnutls/gnutls.h>

int gnutls_certificate_set_ocsp_status_request_mem(gnutls_certificate_credentials_t sc, const gnutls_datum_t * resp_data, unsigned idx, gnutls_x509_crt_fmt_t fmt);

المعاملات

gnutls_certificate_credentials_t sc
هو هيكل بيانات الاعتماد.
const gnutls_datum_t * resp_data
مخزن مؤقت للذاكرة يحمل استجابة OCSP
unsigned idx
هو فهرس الشهادة كما تم إرجاعه بواسطة gnutls_certificate_set_key() والوظائف المماثلة.
gnutls_x509_crt_fmt_t fmt
هو PEM أو DER

الوصف

تقوم هذه الوظيفة بتعيين استجابات OCSP ليتم إرسالها إلى النظير لسلسلة الشهادات المحددة بواسطة idx. عندما يتم تعيين fmt إلى PEM، يمكن تحميل استجابات متعددة.

ملاحظة

تمت إضافة القدرة على تعيين استجابات OCSP متعددة لكل هيكل بيانات اعتماد عبر الفهرس idx في الإصدار 3.5.6. للحفاظ على التوافق الرجعي، يتطلب استخدام gnutls_certificate_set_flags() مع العلم GNUTLS_CERTIFICATE_API_V2 لجعل وظائف الشهادة المعينة ترجع فهرسًا يمكن استخدامه بواسطة هذه الوظيفة.

يجب استدعاء هذه الوظيفة بعد تعيين أي شهادات، ولا يمكن استخدامها للشهادات التي يتم توفيرها عبر رد اتصال - أي عند استخدام gnutls_certificate_set_retrieve_function().

يمكن استدعاء هذه الوظيفة عدة مرات عندما تكون هناك استجابات متعددة تنطبق على سلسلة الشهادات. إذا كانت الاستجابة المقدمة لا تتطابق مع أي شهادات موجودة في السلسلة، يتم إرجاع الرمز GNUTLS_E_OCSP_MISMATCH_WITH_CERTS. إذا انتهت صلاحية الاستجابة بالفعل عند تحميلها، يتم إرجاع الرمز GNUTLS_E_EXPIRED.

يعيد

عند النجاح، يتم إرجاع عدد الاستجابات المحملة، وإلا يتم إرجاع رمز خطأ سالب.
