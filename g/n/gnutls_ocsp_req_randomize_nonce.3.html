gnutls_ocsp_req_randomize_nonce(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_ocsp_req_randomize_nonce(3) gnutls gnutls_ocsp_req_randomize_nonce(3)

الاسم

gnutls_ocsp_req_randomize_nonce - دالة API

الملخص

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_randomize_nonce(gnutls_ocsp_req_t req);

الوسائط

gnutls_ocsp_req_t req
يجب أن تحتوي على نوع gnutls_ocsp_req_t

الوصف

تقوم هذه الدالة بإضافة أو تحديث امتداد nonce لطلب OCSP بقيمة عشوائية تم إنشاؤها حديثًا.

القيمة المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
