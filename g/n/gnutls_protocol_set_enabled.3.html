gnutls_protocol_set_enabled(3) gnutls gnutls_protocol_set_enabled(3)

الاسم

gnutls_protocol_set_enabled - وظيفة API

التركيب

#include <gnutls/gnutls.h>

int gnutls_protocol_set_enabled(gnutls_protocol_t version, unsigned int enabled);

الوسائط

gnutls_protocol_t version
هو رقم إصدار (gnutls)
unsigned int enabled
ما إذا كان سيتم تمكين البروتوكول

الوصف

التحكم في الإعداد العام السابق الذي حدد version كـ ممكّن أو معطّل. يُسمح باستدعاء هذه الوظيفة فقط إذا تم تعيين وضع السماح في ملف التكوين، وفقط إذا لم يتم تهيئة سلسلة أولوية TLS العامة بعد. الاستخدام المقصود هو تزويد التطبيقات بطريقة للانحراف صراحةً عن الافتراضيات الخاصة بالتوزيع أو الموقع الموروثة من ملف التكوين. التعديل قابل للتركيب مع تعديلات إضافية يتم إجراؤها من خلال آلية سلسلة الأولوية.

هذه الوظيفة ليست آمنة للخيوط (thread-safe) وهي مخصصة ليتم استدعاؤها في الخيط الرئيسي في بداية تنفيذ العملية.
