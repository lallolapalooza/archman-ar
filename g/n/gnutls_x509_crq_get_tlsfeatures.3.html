gnutls_x509_crq_get_tlsfeatures(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crq_get_tlsfeatures(3) gnutls gnutls_x509_crq_get_tlsfeatures(3)

الاسم

gnutls_x509_crq_get_tlsfeatures - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crq_get_tlsfeatures(gnutls_x509_crq_t crq, gnutls_x509_tlsfeatures_t features, unsigned int flags, unsigned int * critical);

المعاملات

gnutls_x509_crq_t crq
طلب شهادة X.509
gnutls_x509_tlsfeatures_t features
إذا نجحت الدالة، سيتم تخزين الميزات في هذا المتغير.
unsigned int flags
صفر أو GNUTLS_EXT_FLAG_APPEND
unsigned int * critical
حالة الامتداد

الوصف

ستقوم هذه الدالة بالحصول على بنية امتداد ميزات TLS لشهادة X.509 من طلب الشهادة. يجب تحرير البنية المُرجعة باستخدام gnutls_x509_tlsfeatures_deinit().

عندما يتم تعيين flags إلى GNUTLS_EXT_FLAG_APPEND، فإذا كانت بنية features فارغة، ستتصرف الدالة بشكل متطابق كما لو لم يتم تعيين العلم. بخلاف ذلك، إذا كانت هناك عناصر في بنية features، فسيتم دمجها.

لاحظ أنه يجب تهيئة features قبل استدعاء هذه الدالة.

القيمة المُرجعة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، بخلاف ذلك يتم إرجاع قيمة خطأ سالبة.

منذ

3.5.1
