gnutls_encode_rs_value(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_encode_rs_value(3) gnutls gnutls_encode_rs_value(3)

الاسم

gnutls_encode_rs_value - وظيفة API

الملخص

#include <gnutls/crypto.h>

int gnutls_encode_rs_value(gnutls_datum_t * sig_value, const gnutls_datum_t * r, const gnutls_datum_t * s);

المعاملات

gnutls_datum_t * sig_value
سيحتوي على بنية Dss-Sig-Value مرمزة بصيغة DER
const gnutls_datum_t * r
يجب أن يحتوي على القيمة r
const gnutls_datum_t * s
يجب أن يحتوي على القيمة s

الوصف

ستقوم هذه الوظيفة بترميز القيم r و s المقدمة، إلى بنية Dss-Sig-Value، المستخدمة لتوقيعات DSA و ECDSA.

يجب إلغاء تخصيص القيمة الناتجة باستخدام gnutls_free().

القيم المعادة

عند النجاح، تتم إعادة GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ.

منذ

3.6.0
