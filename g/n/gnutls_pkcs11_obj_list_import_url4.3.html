gnutls_pkcs11_obj_list_import_url4(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs11_obj_list_import_url4(3) gnutls gnutls_pkcs11_obj_list_import_url4(3)

الاسم

gnutls_pkcs11_obj_list_import_url4 - وظيفة API

الملخص

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_list_import_url4(gnutls_pkcs11_obj_t ** p_list, unsigned int * n_list, const char * url, unsigned int flags);

الحجج

gnutls_pkcs11_obj_t ** p_list
قائمة كائنات غير مهيأة (قد تكون NULL)
unsigned int * n_list
سيحتوي على حجم القائمة.
const char * url
عنوان URL لـ PKCS 11 يحدد مجموعة من الكائنات
unsigned int flags
أو تسلسل من علامات GNUTLS_PKCS11_OBJ_*

الوصف

ستقوم هذه الوظيفة بتعداد كافة الكائنات المحددة بواسطة عنوان URL لـ PKCS11 المقدم. ستقوم بتهيئة وتعيين قيم لقائمة مؤشرات الكائنات ( p_list ) المقدمة. للحصول على قائمة بجميع الكائنات المتاحة، استخدم url 'pkcs11:'.

يجب إلغاء تهيئة جميع الكائنات التي تم إرجاعها باستخدام gnutls_pkcs11_obj_deinit()، ويجب إلغاء تهيئة p_list باستخدام gnutls_free().

العلامات المدعومة في هذه الوظيفة هي GNUTLS_PKCS11_OBJ_FLAG_LOGIN، GNUTLS_PKCS11_OBJ_FLAG_LOGIN_SO، GNUTLS_PKCS11_OBJ_FLAG_PRESENT_IN_TRUSTED_MODULE، GNUTLS_PKCS11_OBJ_FLAG_CRT، GNUTLS_PKCS11_OBJ_FLAG_PUBKEY، GNUTLS_PKCS11_OBJ_FLAG_PRIVKEY، GNUTLS_PKCS11_OBJ_FLAG_WITH_PRIVKEY، GNUTLS_PKCS11_OBJ_FLAG_MARK_CA، GNUTLS_PKCS11_OBJ_FLAG_MARK_TRUSTED، ومنذ 3.5.1 GNUTLS_PKCS11_OBJ_FLAG_OVERWRITE_TRUSTMOD_EXT.

في إصدارات GnuTLS السابقة للإصدار 3.4.0، كانت الوظيفة المكافئة هي gnutls_pkcs11_obj_list_import_url2(). هذه متاحة أيضًا في هذا الإصدار كـ macro (ماكرو) الذي يقوم بالتحويل إلى هذه الوظيفة.

يعيد

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.

منذ

3.4.0
