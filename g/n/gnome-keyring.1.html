GNOME-KEYRING(1) أوامر المستخدم GNOME-KEYRING(1)

الاسم

gnome-keyring - أداة سطر الأوامر لـ gnome-keyring

الملخص

gnome-keyring import FILE

gnome-keyring certificate-exception

gnome-keyring version

الوصف

يمكن استخدام الأداة gnome-keyring للتفاعل مع gnome-keyring-daemon.

الأوامر

يمكن استخدام الأوامر التالية:

import FILE

استيراد المفاتيح أو الشهادات من ملف PKCS.

certificate-exception

لم يتم التنفيذ.

version

طباعة رقم الإصدار والخروج.

الأخطاء

يرجى إرسال تقارير الأخطاء إما إلى متعقب الأخطاء الخاص بالتوزيع أو متعقب الأخطاء الأصلي على https://gitlab.gnome.org/GNOME/gnome-keyring/-/issues/

انظر أيضًا

secret-tool(1)، seahorse(1)، gnome-keyring-daemon(1)
