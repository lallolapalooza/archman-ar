gnutls_srtp_get_profile_id(3) gnutls gnutls_srtp_get_profile_id(3)

الاسم

gnutls_srtp_get_profile_id - استدعاء API

الملخص

#include <gnutls/gnutls.h>

int gnutls_srtp_get_profile_id(const char * name, gnutls_srtp_profile_t * profile);

المعاملات

const char * name
اسم الملف الشخصي للبحث عنه
gnutls_srtp_profile_t * profile
سيحتوي على معرف الملف الشخصي

الوصف

تسمح لك هذه الوظيفة بالبحث عن ملف شخصي بناءً على سلسلة نصية.

يعيد

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
