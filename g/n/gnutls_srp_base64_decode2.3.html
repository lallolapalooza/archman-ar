الاسم

gnutls_srp_base64_decode2 - دالة API

ملخص

#include <gnutls/gnutls.h>

int gnutls_srp_base64_decode2(const gnutls_datum_t * b64_data, gnutls_datum_t * result);

الحجج

const gnutls_datum_t * b64_data
يحتوي على البيانات المشفرة
gnutls_datum_t * result
المكان الذي توجد فيه البيانات المفككة

الوصف

ستقوم هذه الدالة بفك تشفير البيانات المشفرة المعطاة. سيتم تخصيص البيانات المفككة وتخزينها في result. ستقوم بفك التشفير باستخدام خوارزمية base64 كما هو مستخدم في libsrp.

يجب استخدام gnutls_free() لتحرير البيانات المُرجعة.

تحذير! هذا التشفير base64 ليس التشفير "القياسي"، لذلك لا تستخدمه لأغراض غير SRP.
