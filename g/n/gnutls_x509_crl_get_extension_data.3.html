gnutls_x509_crl_get_extension_data(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crl_get_extension_data(3) gnutls gnutls_x509_crl_get_extension_data(3)

الاسم

gnutls_x509_crl_get_extension_data - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crl_get_extension_data(gnutls_x509_crl_t crl, unsigned indx, void * data, size_t * sizeof_data);

المعاملات

gnutls_x509_crl_t crl
يجب أن يحتوي على نوع gnutls_x509_crl_t
unsigned indx
يحدد معرف OID للتمديد المراد إرساله. استخدم (0) للحصول على الأول.
void * data
مؤشر إلى بنية لتخزين البيانات (قد يكون فارغًا)
size_t * sizeof_data
يحمل مبدئيًا حجم oid

الوصف

ستقوم هذه الوظيفة بإرجاع بيانات التمديد المطلوبة في قائمة إبطال الشهادات (CRL). سيتم تخزين بيانات التمديد كسلسلة نصية في المخزن المؤقت المقدم.

استخدم gnutls_x509_crl_get_extension_info() لاستخراج معرف OID وعلامة الأهمية. استخدم gnutls_x509_crl_get_extension_info() بدلاً من ذلك، إذا كنت تريد الحصول على بيانات مفهرسة حسب معرف OID للتمديد بدلاً من التسلسل.

القيمة المرجعة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب في حالة حدوث خطأ. إذا وصلت إلى آخر تمديد متاح، فسيتم إرجاع GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
