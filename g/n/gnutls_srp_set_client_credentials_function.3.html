الوصف

يمكن استخدام هذه الوظيفة لتعيين وظيفة استدعاء لاسترداد اسم المستخدم وكلمة المرور لمصادقة عميل SRP. شكل وظيفة الاستدعاء هو:

int (*callback)(gnutls_session_t, char** username, char**password);

يجب تخصيص username و password باستخدام gnutls_malloc().

يجب أن يكون username سلسلة نصية ASCII أو سلسلة نصية UTF-8. في حالة سلسلة نصية UTF-8، يوصى باتباع إطار عمل PRECIS لأسماء المستخدمين (rfc8265). يمكن أن تكون كلمة المرور بتنسيق ASCII، أو يتم تسويتها باستخدام gnutls_utf8_password_normalize().

سيتم استدعاء وظيفة الاستدعاء مرة واحدة لكل مصافحة قبل إرسال رسالة الترحيب الأولية.

لا يجب أن تعيد وظيفة الاستدعاء رمز خطأ سالب في المرة الثانية التي يتم استدعاؤها فيها، حيث سيتم إلغاء إجراء المصافحة.

يجب أن تعيد وظيفة الاستدعاء 0 عند النجاح. -1 يشير إلى وجود خطأ.
