gnutls_x509_crt_list_import_url(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crt_list_import_url(3) gnutls gnutls_x509_crt_list_import_url(3)

الاسم

gnutls_x509_crt_list_import_url - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crt_list_import_url(gnutls_x509_crt_t ** certs, unsigned int * size, const char * url, gnutls_pin_callback_t pin_fn, void * pin_fn_userdata, unsigned int flags);

المعاملات

gnutls_x509_crt_t ** certs
سيحتوي على قائمة الشهادات المخصصة.
unsigned int * size
سيحتوي على حجم القائمة.
const char * url
عنوان URL لـ PKCS 11
gnutls_pin_callback_t pin_fn
دالة رد اتصال PIN إذا لم يتم تعيينها عالميًا
void * pin_fn_userdata
معامل لدالة رد اتصال PIN
unsigned int flags
أحد علامات GNUTLS_PKCS11_OBJ_* لعناوين URL لـ PKCS11 أو صفر خلاف ذلك

الوصف

ستقوم هذه الوظيفة باستيراد سلسلة شهادات موجودة في رمز PKCS11 أو أي نوع من أنواع الواجهات الخلفية التي تدعم عناوين URL. يجب إنهاء الشهادات لاحقًا باستخدام gnutls_x509_crt_deinit() ويجب تحرير المؤشر المُرجع باستخدام gnutls_free().

يجب أن يكون عنوان URI المقدم هو الشهادة الأولى في السلسلة؛ سيتم استرداد الشهادات اللاحقة باستخدام gnutls_pkcs11_get_raw_issuer() أو وظائف مماثلة لعنوان URL المدعوم.

يعيد

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا فسيتم إرجاع قيمة خطأ سالبة.

منذ

3.6.3
