gnutls_supplemental_register(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_supplemental_register(3) gnutls gnutls_supplemental_register(3)

الاسم

gnutls_supplemental_register - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_supplemental_register(const char * name, gnutls_supplemental_data_format_type_t type, gnutls_supp_recv_func recv_func, gnutls_supp_send_func send_func);

المعاملات

const char * name
اسم البيانات الإضافية المراد تسجيلها
gnutls_supplemental_data_format_type_t type
نوع تنسيق البيانات الإضافية
gnutls_supp_recv_func recv_func
وظيفة استقبال البيانات
gnutls_supp_send_func send_func
وظيفة إرسال البيانات

الوصف

ستقوم هذه الوظيفة بتسجيل نوع بيانات إضافية جديدة (rfc4680). ستظل البيانات المسجلة حتى يتم استدعاء gnutls_global_deinit(). يجب أن يكون type المحدد نوعًا غير مخصص في gnutls_supplemental_data_format_type_t. إذا كان النوع مسجلاً بالفعل أو تمت معالجته بواسطة GnuTLS داخليًا، فسيتم إرجاع GNUTLS_E_ALREADY_REGISTERED.

هذه الوظيفة ليست آمنة للاستخدام المتزامن (thread-safe). نظرًا لأن البيانات الإضافية غير محددة في TLS 1.3، فإن هذه الوظيفة ستعطل دعم TLS 1.3 عالميًا.

الإرجاع

GNUTLS_E_SUCCESS عند النجاح، وإلا رمز خطأ سالب.

منذ

3.4.0
