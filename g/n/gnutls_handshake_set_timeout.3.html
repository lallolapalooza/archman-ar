gnutls_handshake_set_timeout(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_handshake_set_timeout(3) gnutls gnutls_handshake_set_timeout(3)

الاسم

gnutls_handshake_set_timeout - وظيفة API

الملخص

#include <gnutls/gnutls.h>

void gnutls_handshake_set_timeout(gnutls_session_t session, unsigned int ms);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
unsigned int ms
هي قيمة مهلة بالمللي ثانية

الوصف

تقوم هذه الوظيفة بتعيين مهلة لعملية مصافحة TLS إلى القيمة المقدمة. استخدم قيمة ms صفر لتعطيل المهلة، أو GNUTLS_DEFAULT_HANDSHAKE_TIMEOUT لقيمة افتراضية معقولة. بالنسبة لبروتوكول DTLS، يتم توفير gnutls_dtls_set_timeouts() الأكثر تفصيلاً.

تتطلب هذه الوظيفة تعيين دالة رد اتصال لمهلة السحب. انظر gnutls_transport_set_pull_timeout_function().

منذ

3.1.0
