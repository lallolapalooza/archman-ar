الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_cipher_tag(3) gnutls gnutls_cipher_tag(3)

الاسم

gnutls_cipher_tag - وظيفة API

الاستخدام

#include <gnutls/crypto.h>

int gnutls_cipher_tag(gnutls_cipher_hd_t handle, void * tag, size_t tag_size);

المعاملات

gnutls_cipher_hd_t handle
هو نوع gnutls_cipher_hd_t
void * tag
سيحتوي على الوسم
size_t tag_size
طول الوسم المراد إرجاعه

الوصف

تعمل هذه الوظيفة على خوارزميات التشفير المصادق عليه مع البيانات المرتبطة (AEAD) وسترجع الوسم الناتج.
