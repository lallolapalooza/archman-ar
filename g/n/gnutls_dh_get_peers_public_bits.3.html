الاسم

gnutls_dh_get_peers_public_bits - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_dh_get_peers_public_bits(gnutls_session_t session);

الوسائط

gnutls_session_t session
هي جلسة gnutls

الوصف

الحصول على حجم بت مفتاح Diffie-Hellman العام. يمكن استخدامه لكل من Diffie-Hellman المجهول والمؤقت.

القيم المعادة

حجم بت المفتاح العام المستخدم في آخر تبادل مفاتيح Diffie-Hellman مع النظير، أو رمز خطأ سالب في حالة حدوث خطأ.
