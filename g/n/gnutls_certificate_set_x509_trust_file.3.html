gnutls_certificate_set_x509_trust_file(3)

gnutls_certificate_set_x509_trust_file(3) gnutls gnutls_certificate_set_x509_trust_file(3)

الاسم

gnutls_certificate_set_x509_trust_file - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_trust_file(gnutls_certificate_credentials_t cred, const char * cafile, gnutls_x509_crt_fmt_t type);

الوسائط

gnutls_certificate_credentials_t cred
هو نوع gnutls_certificate_credentials_t.
const char * cafile
هو ملف يحتوي على قائمة المراجع الموثوق بها (قائمة DER أو PEM)
gnutls_x509_crt_fmt_t type
هو PEM أو DER

الوصف

تضيف هذه الوظيفة المراجع الموثوق بها من أجل التحقق من شهادات العميل أو الخادم. في حالة العميل، ليس من الضروري استدعاء هذه الوظيفة إذا لم يتم التحقق من الشهادات باستخدام gnutls_certificate_verify_peers2(). يمكن استدعاء هذه الوظيفة عدة مرات.

في حالة الخادم، سيتم إرسال أسماء المراجع الموثوق بها المعينة هنا إلى العميل إذا تم إرسال طلب شهادة. يمكن تعطيل ذلك باستخدام gnutls_certificate_send_x509_rdn_sequence().

يمكن لهذه الوظيفة أيضًا قبول عناوين URL. في هذه الحالة، ستقوم باستيراد جميع الشهادات التي تم تمييزها على أنها موثوق بها. لاحظ أن عناوين URL المدعومة هي تلك المشار إليها بواسطة gnutls_url_is_supported().
