gnutls_ocsp_status_request_enable_client(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_ocsp_status_request_enable_client(3) gnutls gnutls_ocsp_status_request_enable_client(3)

الاسم

gnutls_ocsp_status_request_enable_client - دالة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_ocsp_status_request_enable_client(gnutls_session_t session, gnutls_datum_t * responder_id, size_t responder_id_size, gnutls_datum_t * extensions);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
gnutls_datum_t * responder_id
يتم تجاهله، ويجب أن يكون NULL
size_t responder_id_size
يتم تجاهله، ويجب أن يكون صفرًا
gnutls_datum_t * extensions
يتم تجاهله، ويجب أن يكون NULL

الوصف

تُستخدم هذه الدالة من قبل العملاء لطلب استجابة OCSP من الخادم، باستخدام امتداد TLS "status_request". يُدعم فقط نوع حالة OCSP.

الإصدارات السابقة من GnuTLS دعمت تعيين حقول responder_id و
extensions، ولكن بسبب الدلالات الصعبة لاستخدام المعاملات، ومشاكل أخرى، تم إزالة هذا الدعم منذ الإصدار 3.6.0 ويجب تعيين هذه المعاملات إلى NULL.

القيمة المُعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.

منذ

3.1.3
