gnutls_pcert_import_x509_list(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pcert_import_x509_list(3) gnutls gnutls_pcert_import_x509_list(3)

الاسم

gnutls_pcert_import_x509_list - وظيفة API

الخلاصة

#include <gnutls/abstract.h>

int gnutls_pcert_import_x509_list(gnutls_pcert_st * pcert_list, gnutls_x509_crt_t * crt, unsigned * ncrt, unsigned int flags);

الحجج

gnutls_pcert_st * pcert_list
الهياكل لتخزين الشهادات؛ يجب ألا تحتوي على هياكل gnutls_pcert_st مهيأة.
gnutls_x509_crt_t * crt
الشهادات المراد استيرادها
unsigned * ncrt
عدد الشهادات في crt؛ سيتم تحديثه إذا لزم الأمر
unsigned int flags
صفر أو GNUTLS_X509_CRT_LIST_SORT

الوصف

ستقوم هذه الوظيفة المساعدة باستيراد الشهادات المعطاة إلى مجموعة من هياكل gnutls_pcert_st مخصصة مسبقًا. يجب إلغاء تهيئة الهياكل لاحقًا باستخدام gnutls_pcert_deinit(). يجب أن يحتوي pcert_list على مساحة لـ ncrt عناصر على الأقل.

في حالة تحديد GNUTLS_X509_CRT_LIST_SORT وعدم تمكن هذه الوظيفة من فرز القائمة، سيتم إرجاع GNUTLS_E_CERTIFICATE_LIST_UNSORTED. حاليًا، قد يفشل الفرز إذا تجاوز حجم القائمة حدًا داخليًا (16).

المرتجعات

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.

3.4.0
