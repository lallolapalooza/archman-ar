gnutls_decode_gost_rs_value(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_decode_gost_rs_value(3) gnutls gnutls_decode_gost_rs_value(3)

الاسم

gnutls_decode_gost_rs_value - وظيفة API

المتطلبات

#include <gnutls/crypto.h>

int gnutls_decode_gost_rs_value(const gnutls_datum_t * sig_value, gnutls_datum_t * r, gnutls_datum_t * s);

الوسائط

const gnutls_datum_t * sig_value
سيحتوي على توقيع GOST وفقًا للقسم 2.2.2 من RFC 4491
gnutls_datum_t * r
سيحتوي على قيمة r
gnutls_datum_t * s
سيحتوي على قيمة s

الوصف

ستقوم هذه الوظيفة بفك تشفير sig_value المقدمة، إلى عناصر r و s. انظر القسم 2.2.2 من RFC 4491 لمعرفة تنسيق قيمة التوقيع.

قد تكون القيم الناتجة مبطنة ببايت صفري لمنع تفسيرها كقيم سالبة. يجب إلغاء تخصيص القيمة باستخدام gnutls_free().

القيم المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ.

منذ

3.6.0
