gnutls_x509_trust_list_verify_named_crt(3)

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_trust_list_verify_named_crt(3) gnutls gnutls_x509_trust_list_verify_named_crt(3)

الاسم

gnutls_x509_trust_list_verify_named_crt - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_trust_list_verify_named_crt(gnutls_x509_trust_list_t list, gnutls_x509_crt_t cert, const void * name, size_t name_size, unsigned int flags, unsigned int * voutput, gnutls_verify_output_function func);

المعاملات

gnutls_x509_trust_list_t list
القائمة
gnutls_x509_crt_t cert
الشهادة المراد التحقق منها
const void * name
اسم الشهادة
size_t name_size
حجم اسم الشهادة
unsigned int flags
علامات يمكن استخدامها لتغيير خوارزمية التحقق. استخدم OR من تعدادات gnutls_certificate_verify_flags.
unsigned int * voutput
سيحتوي على مخرجات التحقق من الشهادة.
gnutls_verify_output_function func
إذا لم تكن فارغة، فسيتم استدعاؤها عند التحقق من كل عنصر في السلسلة مع المخرجات.

الوصف

ستحاول هذه الوظيفة العثور على شهادة مرتبطة بالاسم المقدم - راجع gnutls_x509_trust_list_add_named_crt(). إذا تم العثور على تطابق، تعتبر الشهادة صالحة. بالإضافة إلى ذلك، ستتحقق هذه الوظيفة أيضًا من قوائم إلغاء الشهادات (CRLs). سيحتوي المعامل voutput على تسلسل ORed من علامات gnutls_certificate_status_t.

بالإضافة إلى ذلك، يمكن تحديد ملف تعريف التحقق من الشهادات من بين تلك الموجودة في gnutls_certificate_verification_profiles_t عن طريق استخدام OR لنتيجة GNUTLS_PROFILE_TO_VFLAGS() مع علامات التحقق.

الإرجاع

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.
