gnutls_pkcs11_obj_get_info(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs11_obj_get_info(3) gnutls gnutls_pkcs11_obj_get_info(3)

الاسم

gnutls_pkcs11_obj_get_info - وظيفة API

الشكل

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_get_info(gnutls_pkcs11_obj_t obj, gnutls_pkcs11_obj_info_t itype, void * output, size_t * output_size);

المعاملات

gnutls_pkcs11_obj_t obj
يجب أن يحتوي على نوع gnutls_pkcs11_obj_t
gnutls_pkcs11_obj_info_t itype
يشير إلى نوع المعلومات المطلوبة
void * output
حيث سيتم تخزين الناتج
size_t * output_size
يحتوي على الحد الأقصى لحجم المخزن المؤقت للإخراج وسيتم استبداله بالحجم الفعلي.

الوصف

ستقوم هذه الوظيفة بإرجاع معلومات حول شهادة PKCS11 مثل التسمية والمعرف بالإضافة إلى معلومات الرمز المميز حيث يتم تخزين المفتاح.

عندما يكون الناتج نصًا، يتم كتابة سلسلة نصية منتهية بصفر إلى output ويتم كتابة طولها إلى output_size (بدون المنتهي الصفري). إذا كان المخزن المؤقت صغيرًا جدًا، فسيحتوي output_size على حجم المخزن المؤقت المتوقع (مع المنتهي الصفري للنص) ويعيد GNUTLS_E_SHORT_MEMORY_BUFFER.

في الإصدارات السابقة لـ 3.6.0، تضمنت هذه الوظيفة المنتهي الصفري إلى output_size. بعد 3.6.0، لا يشمل حجم الإخراج حرف المنتهي.

يعيد

GNUTLS_E_SUCCESS (0) عند النجاح أو رمز خطأ سالب عند حدوث خطأ.

منذ

2.12.0
