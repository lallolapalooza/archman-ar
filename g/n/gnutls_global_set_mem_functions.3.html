gnutls_global_set_mem_functions(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_global_set_mem_functions(3) gnutls gnutls_global_set_mem_functions(3)

الاسم

gnutls_global_set_mem_functions - دالة API

الملخص

#include <gnutls/compat.h>

void gnutls_global_set_mem_functions(gnutls_alloc_function alloc_func, gnutls_alloc_function secure_alloc_func, gnutls_is_secure_function is_secure_func, gnutls_realloc_function realloc_func, gnutls_free_function free_func);

المعاملات

gnutls_alloc_function alloc_func
إنها دالة تخصيص الذاكرة الافتراضية. مثل malloc().
gnutls_alloc_function secure_alloc_func
هذه هي دالة تخصيص الذاكرة التي سيتم استخدامها للبيانات الحساسة.
gnutls_is_secure_function is_secure_func
دالة تعيد 0 إذا كانت الذاكرة المعطاة غير آمنة. قد تكون NULL.
gnutls_realloc_function realloc_func
دالة إعادة تخصيص
gnutls_free_function free_func
الدالة التي تحرر البيانات المخصصة. يجب أن تقبل مؤشر NULL.

مهمل

منذ الإصدار 3.3.0، لم يعد من الممكن استبدال وظائف تخصيص الذاكرة المستخدمة داخليًا

هذه هي الدالة التي تحدد فيها دوال تخصيص الذاكرة التي سيتم استخدامها بواسطة gnutls. افتراضيًا، تستخدم gnutls دوال التخصيص الخاصة بمكتبة C (malloc()، free()) لتخصيص كل من البيانات الحساسة وغير الحساسة. تم توفير هذه الدالة لتعيين دوال تخصيص الذاكرة إلى شيء آخر غير الافتراضيات.

يجب استدعاء هذه الدالة قبل استدعاء gnutls_global_init(). هذه الدالة ليست آمنة للخيوط (thread-safe).
