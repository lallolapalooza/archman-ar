gnutls_pkcs7_delete_crl(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs7_delete_crl(3) gnutls gnutls_pkcs7_delete_crl(3)

الاسم

gnutls_pkcs7_delete_crl - وظيفة API

الملخص

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_delete_crl(gnutls_pkcs7_t pkcs7, int indx);

المعاملات

gnutls_pkcs7_t pkcs7
نوع pkcs7
int indx
فهرس crl المراد حذفه

الوصف

ستقوم هذه الوظيفة بحذف crl من مجموعة crl PKCS7 أو RFC2630. يبدأ الفهرس من 0. تعيد 0 عند النجاح.

القيمة المعادة

عند النجاح، تعاد القيمة GNUTLS_E_SUCCESS (0)، وإلا فتعاد قيمة خطأ سالبة.
