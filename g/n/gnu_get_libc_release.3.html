gnu_get_libc_version(3) دليل الوظائف المكتبية gnu_get_libc_version(3)

الاسم

gnu_get_libc_version, gnu_get_libc_release - الحصول على إصدار glibc وتاريخ إصداره

المكتبة

مكتبة C القياسية (libc، -lc)

النبذة

#include <gnu/libc-version.h>
const char *gnu_get_libc_version(void);
const char *gnu_get_libc_release(void);

الوصف

تعيد الوظيفة gnu_get_libc_version() سلسلة نصية تحدد إصدار glibc المتوفر في النظام.

تعيد الوظيفة gnu_get_libc_release() سلسلة نصية تشير إلى حالة إصدار glibc المتوفر في النظام. ستكون هذه سلسلة نصية مثل stable.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
gnu_get_libc_version (), gnu_get_libc_release () سلامة الترابط MT-Safe

المعايير

GNU.

التاريخ

glibc 2.1.

أمثلة

عند تشغيل البرنامج أدناه، سينتج مخرجًا مثل التالي:


$ ./a.out
GNU libc version: 2.8
GNU libc release: stable

مصدر البرنامج

#include <stdio.h>
#include <stdlib.h>
#include <gnu/libc-version.h>
int
main(void)
{
    printf("GNU libc version: %s\n", gnu_get_libc_version());
    printf("GNU libc release: %s\n", gnu_get_libc_release());
    exit(EXIT_SUCCESS);
}
