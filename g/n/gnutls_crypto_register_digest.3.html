gnutls_crypto_register_digest(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_crypto_register_digest(3) gnutls gnutls_crypto_register_digest(3)

الاسم

gnutls_crypto_register_digest - دالة API

الملخص

#include <gnutls/crypto.h>

int gnutls_crypto_register_digest(gnutls_digest_algorithm_t algorithm, int priority, gnutls_digest_init_func init, gnutls_digest_hash_func hash, gnutls_digest_output_func output, gnutls_digest_deinit_func deinit, gnutls_digest_fast_func hash_fast);

المعاملات

gnutls_digest_algorithm_t algorithm
هو معرف التجزئة لـ gnutls
int priority
هي أولوية الخوارزمية
gnutls_digest_init_func init
دالة تقوم بتهيئة التجزئة
gnutls_digest_hash_func hash
تنفيذ عملية التجزئة
gnutls_digest_output_func output
تقديم مخرجات التجزئة
gnutls_digest_deinit_func deinit
دالة تقوم بإلغاء تهيئة التجزئة
gnutls_digest_fast_func hash_fast
تنفيذ عملية التجزئة دفعة واحدة

الوصف

ستقوم هذه الدالة بتسجيل خوارزمية تجزئة لاستخدامها بواسطة gnutls. أي خوارزمية مسجلة ستحل محل الخوارزميات المضمنة، وبحسب العرف، فإن الخوارزميات المنفذة في النواة لها أولوية 90، والمدعومة بالمعالج لها أولوية 80. سيتم استخدام الخوارزمية ذات الأولوية الأدنى بواسطة gnutls.

مهمل

منذ الإصدار 3.7.0، لم يعد من الممكن تجاوز تنفيذ التشفير.

يعيد

GNUTLS_E_SUCCESS عند النجاح، وإلا رمز خطأ سالب.

منذ

3.4.0
