gnutls_base64_encode2(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_base64_encode2(3) gnutls gnutls_base64_encode2(3)

الاسم

gnutls_base64_encode2 - دالة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_base64_encode2(const gnutls_datum_t * data, gnutls_datum_t * result);

المعاملات

const gnutls_datum_t * data
يحتوي على البيانات الخام
gnutls_datum_t * result
سيحمل البيانات المشفرة المخصصة حديثًا

الوصف

ستقوم هذه الدالة بتحويل البيانات المعطاة إلى بيانات قابلة للطباعة، باستخدام تشفير base64. ستقوم هذه الدالة بتخصيص الذاكرة المطلوبة للاحتفاظ بالبيانات المشفرة.

يجب عليك استخدام gnutls_free() لتحرير البيانات المُرجعة.

يعيد

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ.

منذ

3.6.0
