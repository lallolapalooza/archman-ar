الاسم

gnutls_privkey_generate2 - استدعاء API

الاختصار

#include <gnutls/abstract.h>

int gnutls_privkey_generate2(gnutls_privkey_t pkey, gnutls_pk_algorithm_t algo, unsigned int bits, unsigned int flags, const gnutls_keygen_data_st * data, unsigned data_size);

المعاملات

gnutls_privkey_t pkey
المفتاح الخاص
gnutls_pk_algorithm_t algo
هو أحد الخوارزميات الموجودة في gnutls_pk_algorithm_t.
unsigned int bits
حجم المعامل
unsigned int flags
يجب أن يكون صفرًا أو علامات من gnutls_privkey_flags_t.

يسمح بتحديد أنواع gnutls_keygen_data_st مثل البذرة المستخدمة.
unsigned data_size
عدد data المتاح.

الوصف

ستقوم هذه الدالة بإنشاء مفتاح خاص عشوائي. لاحظ أنه يجب استدعاء هذه الدالة على مفتاح خاص تم تهيئته.

العلامة GNUTLS_PRIVKEY_FLAG_PROVABLE توجه عملية إنشاء المفتاح لاستخدام خوارزميات مثل Shawe-Taylor (من FIPS PUB186-4) التي تنشئ معلمات قابلة للإثبات من بذرة لمفاتيح RSA و DSA. على مفاتيح DSA، يتم إنشاء معلمات PQG باستخدام البذرة، بينما على RSA، يتم إنشاء القاسمين الأوليين. لتحديد بذرة صريحة (يتم استخدام بذرة عشوائية افتراضيًا)، استخدم data مع نوع GNUTLS_KEYGEN_SEED.

لاحظ أنه عند إنشاء مفتاح منحنى قطعي، يمكن استبدال المنحنى بدلاً من معامل البتات باستخدام الماكرو GNUTLS_CURVE_TO_BITS().

لتصدير المفاتيح التي تم إنشاؤها في الذاكرة أو في الملفات، يوصى باستخدام تنسيق PKCS8 لأنه يمكنه التعامل مع جميع أنواع المفاتيح، ويمكنه تخزين معلمات إضافية مثل البذرة، في حالة مفاتيح RSA أو DSA القابلة للإثبات. يمكن تصدير المفاتيح التي تم إنشاؤها في الذاكرة باستخدام gnutls_privkey_export_x509()، ثم باستخدام gnutls_x509_privkey_export2_pkcs8().

إذا كان إنشاء المفاتيح جزءًا من تطبيقك، فتجنب تعيين عدد البتات مباشرة، وبدلاً من ذلك استخدم gnutls_sec_param_to_pk_bits(). بهذه الطريقة، ستتكيف المفاتيح التي تم إنشاؤها مع مستويات الأمان لمكتبة GnuTLS الأساسية.

القيمة المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.
