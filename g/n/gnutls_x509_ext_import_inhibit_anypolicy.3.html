gnutls_x509_ext_import_inhibit_anypolicy(3) gnutls gnutls_x509_ext_import_inhibit_anypolicy(3)

الاسم

gnutls_x509_ext_import_inhibit_anypolicy - دالة API

الملخص

#include <gnutls/x509-ext.h>

int gnutls_x509_ext_import_inhibit_anypolicy(const gnutls_datum_t * ext, unsigned int * skipcerts);

الوسائط

const gnutls_datum_t * ext
بيانات الامتداد المشفرة بصيغة DER
unsigned int * skipcerts
سيحتوي على عدد الشهادات التي بعد انقضائها لم يعد مقبولاً استخدام anypolicy.

الوصف

ستقوم هذه الدالة بإرجاع قيمة SkipCerts للشهادة، عن طريق قراءة بيانات DER لـ Inhibit anyPolicy X.509 extension (2.5.29.54).

قيمة skipcerts هي عدد الشهادات الإضافية التي قد تظهر في المسار قبل أن يصبح أي سياسة (GNUTLS_X509_OID_POLICY_ANY) غير مقبولة.

المرتجعات

صفر، أو رمز خطأ سالب في حالة وجود خطأ في التحليل. إذا كانت الشهادة لا تحتوي على امتداد Inhibit anyPolicy، فسيتم إرجاع GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

منذ

3.6.0
