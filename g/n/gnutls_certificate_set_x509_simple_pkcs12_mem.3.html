الاسم

gnutls_certificate_set_x509_simple_pkcs12_mem - دالة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_simple_pkcs12_mem(gnutls_certificate_credentials_t res, const gnutls_datum_t * p12blob, gnutls_x509_crt_fmt_t type, const char * password);

المعاملات

gnutls_certificate_credentials_t res
هو نوع gnutls_certificate_credentials_t.
const gnutls_datum_t * p12blob
كتلة PKCS12.
gnutls_x509_crt_fmt_t type
هو PEM أو DER لـ pkcs12file.
const char * password
كلمة مرور اختيارية تستخدم لفك تشفير ملف PKCS12، الأكياس والمفاتيح.

الوصف

تقوم هذه الدالة بتعيين زوج شهادة/مفتاح خاص و/أو CRL في نوع gnutls_certificate_credentials_t. يمكن استدعاء هذه الدالة أكثر من مرة (في حالة وجود مفاتيح/شهادات متعددة للخادم).

يتم دعم أكياس PKCS12 المشفرة ومفاتيح PKCS8 الخاصة. ومع ذلك، يتم دعم المصادقة المستندة إلى كلمة المرور فقط، ونفس كلمة المرور لجميع العمليات.

قد يحتوي ملف PKCS12 على العديد من المفاتيح و/أو الشهادات، وستحاول هذه الدالة الكشف التلقائي بناءً على معرف المفتاح الشهادة وزوج المفاتيح المراد استخدامه. إذا كان ملف PKCS12 يحتوي على مُصدر الشهادة المختارة، فسيتم إلحاقه بالشهادة لتشكيل سلسلة.

إذا تم تخزين أكثر من مفتاح خاص واحد في ملف PKCS12، فسيتم قراءة مفتاح واحد فقط (ومن غير المحدد أي مفتاح).

يُعتقد أن قيود هذه الدالة مقبولة لمعظم الاستخدامات، وأن أي مرونة إضافية ستؤدي إلى تعقيد يجعل استخدام هذه الوظيفة أصعب.

لاحظ أن هذه الدالة تعيد افتراضيًا صفرًا عند النجاح وقيمة سالبة عند الخطأ. منذ الإصدار 3.5.6، عندما يتم تعيين العلامة GNUTLS_CERTIFICATE_API_V2 باستخدام gnutls_certificate_set_flags()، فإنها تعيد فهرسًا (أكبر من أو يساوي صفرًا). يمكن استخدام هذا الفهرس لدوال أخرى للإشارة إلى زوج المفاتيح المضاف.

يعيد

عند النجاح، تعيد هذه الدالة صفرًا، وبخلاف ذلك تعيد قيمة سالبة عند الخطأ (انظر أعلاه لتعديل هذا السلوك).
