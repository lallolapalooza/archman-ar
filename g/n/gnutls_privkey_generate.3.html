gnutls_privkey_generate(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_privkey_generate(3) gnutls gnutls_privkey_generate(3)

الاسم

gnutls_privkey_generate - وظيفة API

الملخص

#include <gnutls/abstract.h>

int gnutls_privkey_generate(gnutls_privkey_t pkey, gnutls_pk_algorithm_t algo, unsigned int bits, unsigned int flags);

الوسائط

gnutls_privkey_t pkey
مفتاح خاص مهيأ
gnutls_pk_algorithm_t algo
هو أحد الخوارزميات في gnutls_pk_algorithm_t.
unsigned int bits
حجم المعلمات المراد إنشاؤها
unsigned int flags
يجب أن يكون صفرًا أو علامات من gnutls_privkey_flags_t.

الوصف

ستقوم هذه الوظيفة بإنشاء مفتاح خاص عشوائي. لاحظ أنه يجب استدعاء هذه الوظيفة على مفتاح خاص مهيأ.

العلامة GNUTLS_PRIVKEY_FLAG_PROVABLE توجه عملية إنشاء المفتاح لاستخدام خوارزميات مثل Shawe-Taylor (من FIPS PUB186-4) التي تنشئ معلمات قابلة للإثبات من بذرة لمفاتيح RSA و DSA. انظر gnutls_privkey_generate2() لمزيد من المعلومات.

لاحظ أنه عند إنشاء مفتاح منحنى إهليلجي، يمكن استبدال المنحنى مكان المعلمة bits باستخدام الماكرو GNUTLS_CURVE_TO_BITS(). المدخلات إلى الماكرو هي أي منحنى من gnutls_ecc_curve_t.

بالنسبة لمفاتيح DSA، إذا كان حجم المجموعة الفرعية يحتاج إلى تحديد، تحقق من الماكرو GNUTLS_SUBGROUP_TO_BITS().

يوصى بعدم تعيين عدد bits مباشرة، استخدم gnutls_sec_param_to_pk_bits() بدلاً من ذلك.

انظر أيضًا gnutls_privkey_generate2().

القيمة المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا فإن قيمة خطأ سالبة.
