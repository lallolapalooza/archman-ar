الاسم

gnutls_x509_crt_get_subject_alt_name2 - وظيفة API

المُلَخَّص

#include <gnutls/x509.h>

int gnutls_x509_crt_get_subject_alt_name2(gnutls_x509_crt_t cert, unsigned int seq, void * san, size_t * san_size, unsigned int * san_type, unsigned int * critical);

المُعاملات

gnutls_x509_crt_t cert
يجب أن يحتوي على نوع gnutls_x509_crt_t
unsigned int seq
يحدد رقم تسلسل الاسم البديل (0 للاسم الأول، 1 للثاني، إلخ.)
void * san
هو المكان الذي سيتم نسخ الاسم البديل إليه
size_t * san_size
يحتوي على حجم ret.
unsigned int * san_type
يحتوي على نوع الاسم البديل (أحد gnutls_x509_subject_alt_name_t).
unsigned int * critical
سيكون غير صفري إذا تم تمييز الامتداد على أنه حرج (قد يكون فارغًا)

الوصف

ستقوم هذه الوظيفة بإرجاع الأسماء البديلة الموجودة في الشهادة المعطاة. إنها نفس وظيفة gnutls_x509_crt_get_subject_alt_name() باستثناء حقيقة أنها ستعيد نوع الاسم البديل في san_type حتى لو فشلت الوظيفة لسبب ما (أي أن المخزن المؤقت المقدم غير كافٍ).

القيمة المُعادة

نوع الاسم البديل للذات عند النجاح، أحد تعداد gnutls_x509_subject_alt_name_t. ستعيد GNUTLS_E_SHORT_MEMORY_BUFFER إذا لم يكن san_size كبيرًا بما يكفي لاستيعاب القيمة. في هذه الحالة، سيتم تحديث san_size بالحجم المطلوب. إذا لم يكن للشهادة اسم بديل بالرقم التسلسلي المحدد، فسيتم إرجاع GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.
