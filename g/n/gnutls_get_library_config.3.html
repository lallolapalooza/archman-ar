gnutls_get_library_config(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_get_library_config(3) gnutls gnutls_get_library_config(3)

الاسم

gnutls_get_library_config - وظيفة API

الملخص

#include <gnutls/gnutls.h>

const gnutls_library_config_st * gnutls_get_library_config( void);

المعاملات

void

الوصف

يعيد تكوين المكتبة كأزواج مفتاح-قيمة. المفاتيح المعرفة حاليًا هي:

- fips-module-name: اسم وحدة FIPS140

- fips-module-version: إصدار وحدة FIPS140

- libgnutls-soname: اسم SONAME للمكتبة نفسها

- libnettle-soname: اسم SONAME للمكتبة المرتبطة libnettle

- libhogweed-soname: اسم SONAME للمكتبة المرتبطة libhogweed

- libgmp-soname: اسم SONAME للمكتبة المرتبطة libgmp

- hardware-features: ميزات دعم الأجهزة المفعلة

- tls-features: ميزات بروتوكول TLS المفعلة

يعيد

مصفوفة gnutls_library_config_st منتهية بـ NUL

منذ

3.7.3
