gnutls_x509_crt_get_proxy(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crt_get_proxy(3) gnutls gnutls_x509_crt_get_proxy(3)

الاسم

gnutls_x509_crt_get_proxy - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crt_get_proxy(gnutls_x509_crt_t cert, unsigned int * critical, int * pathlen, char ** policyLanguage, char ** policy, size_t * sizeof_policy);

المعلمات

gnutls_x509_crt_t cert
يجب أن يحتوي على نوع gnutls_x509_crt_t
unsigned int * critical
سيكون غير صفري إذا تم تمييز الامتداد على أنه حرج
int * pathlen
مؤشر إلى عدد صحيح للإخراج يشير إلى طول المسار (قد يكون NULL)، رموز الخطأ غير السالبة تشير إلى حقل pCPathLenConstraint موجود والقيمة الفعلية، -1 تشير إلى أن الحقل غير موجود.
char ** policyLanguage
متغير إخراج بمعرف OID للغة السياسة
char ** policy
متغير إخراج ببيانات السياسة
size_t * sizeof_policy
حجم متغير الإخراج لبيانات السياسة

الوصف

ستقوم هذه الوظيفة بالحصول على معلومات من شهادة وكيل. تقرأ امتداد ProxyCertInfo X.509 (1.3.6.1.5.5.7.1.14).

الإرجاع

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
