gnutls_cipher_decrypt(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_cipher_decrypt(3) gnutls gnutls_cipher_decrypt(3)

الاسم

gnutls_cipher_decrypt - وظيفة API

الملخص

#include <gnutls/crypto.h>

int gnutls_cipher_decrypt(gnutls_cipher_hd_t handle, void * ctext, size_t ctext_len);

الحجج

gnutls_cipher_hd_t handle
هو نوع gnutls_cipher_hd_t
void * ctext
البيانات المراد فك تشفيرها
size_t ctext_len
طول البيانات المراد فك تشفيرها

الوصف

ستقوم هذه الوظيفة بفك تشفير البيانات المعطاة باستخدام الخوارزمية المحددة بواسطة السياق.

لاحظ أنه في تشفيرات AEAD، لن يتم التحقق من العلامة. ستحتاج إلى مقارنة العلامة المرسلة مع القيمة المعادة من gnutls_cipher_tag().

يعود

صفر أو رمز خطأ سالب عند حدوث خطأ.

منذ

2.10.0
