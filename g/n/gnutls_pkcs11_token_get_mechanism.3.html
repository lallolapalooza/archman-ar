gnutls_pkcs11_token_get_mechanism(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs11_token_get_mechanism(3) gnutls gnutls_pkcs11_token_get_mechanism(3)

الاسم

gnutls_pkcs11_token_get_mechanism - دالة API

الملخص

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_token_get_mechanism(const char * url, unsigned int idx, unsigned long * mechanism);

الوسائط

const char * url
يجب أن يحتوي على عنوان URL لـ PKCS 11
unsigned int idx
فهرس الآلية
unsigned long * mechanism
معرف آلية PKCS 11

الوصف

ستعيد هذه الدالة أسماء الآليات المدعومة من قبل الرمز المميز. يجب استدعاؤها بفهرس متزايد حتى تعود بـ GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

القيم المعادة

GNUTLS_E_SUCCESS (0) عند النجاح أو رمز خطأ سالب عند حدوث خطأ.

منذ

2.12.0
