الاسم

gnutls_ocsp_status_request_get2 - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_ocsp_status_request_get2(gnutls_session_t session, unsigned idx, gnutls_datum_t * response);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
unsigned idx
فهرس شهادة الطرف المقابل
gnutls_datum_t * response
gnutls_datum_t مع استجابة OCSP مرمزة بصيغة DER

الوصف

تعيد هذه الوظيفة استجابة حالة OCSP التي تم تلقيها من خادم TLS لفهرس الشهادة المقدم. يتوافق الفهرس مع الشهادات كما تم إرجاعها بواسطة gnutls_certificate_get_peers. عندما يكون الفهرس صفرًا، تعمل هذه الوظيفة بشكل مطابق لـ gnutls_ocsp_status_request_get().

يجب التعامل مع response المُعاد كقيمة ثابتة. إذا لم تكن هناك استجابة OCSP متاحة للفهرس المحدد، يتم إرجاع GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

القيم المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.

منذ

3.6.3
