gnutls_credentials_set(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_credentials_set(3) gnutls gnutls_credentials_set(3)

اسم

gnutls_credentials_set - دالة API

ملخص

#include <gnutls/gnutls.h>

int gnutls_credentials_set(gnutls_session_t session, gnutls_credentials_type_t type, void * cred);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
gnutls_credentials_type_t type
هو نوع بيانات الاعتماد.
void * cred
بيانات الاعتماد المراد تعيينها.

وصف

يقوم بتعيين بيانات الاعتماد المطلوبة للنوع المحدد. على سبيل المثال، اسم المستخدم، كلمة المرور - أو المفاتيح العامة والخاصة وما إلى ذلك. المعامل cred هو بنية تعتمد على type المحدد وعلى الجلسة الحالية (عميل أو خادم). يمكن تعيين cred واحد فقط لكل type مختلف، وستحل الاستدعاءات اللاحقة بنفس type محل بيانات الاعتماد التي تم تعيينها سابقًا.

لتقليل استخدام الذاكرة، ومشاركة بيانات الاعتماد بين عدة خيوط، يحتفظ gnutls بمؤشر إلى cred، وليس بنية cred بأكملها. وبالتالي، سيتعين عليك الاحتفاظ بالبنية مخصصة حتى تقوم باستدعاء gnutls_deinit()، أو استدعاء مستقبلي لـ gnutls_credentials_set() بنفس type سيستبدل بنية cred.

بالنسبة لـ GNUTLS_CRD_ANON، يجب أن يكون cred gnutls_anon_client_credentials_t في حالة العميل. في حالة الخادم، يجب أن يكون gnutls_anon_server_credentials_t.

بالنسبة لـ GNUTLS_CRD_SRP، يجب أن يكون cred gnutls_srp_client_credentials_t في حالة العميل، و gnutls_srp_server_credentials_t، في حالة الخادم.

بالنسبة لـ GNUTLS_CRD_CERTIFICATE، يجب أن يكون cred gnutls_certificate_credentials_t.

المُرجعات

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
