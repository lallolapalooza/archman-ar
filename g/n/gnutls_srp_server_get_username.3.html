اسم

gnutls_srp_server_get_username - دالة API

الملخص

#include <gnutls/gnutls.h>

const char * gnutls_srp_server_get_username(gnutls_session_t session);

المعاملات

gnutls_session_t session
هو جلسة gnutls

الوصف

هذه الدالة ستعيد اسم المستخدم للطرف المقابل. يجب استدعاء هذه الدالة فقط في حالة مصادقة SRP وفي حالة الخادم. تعيد NULL في حالة حدوث خطأ.

الإرجاع

اسم مستخدم SRP للطرف المقابل، أو NULL في حالة حدوث خطأ.
