gnutls_certificate_get_ocsp_expiration(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_certificate_get_ocsp_expiration(3) gnutls gnutls_certificate_get_ocsp_expiration(3)

الاسم

gnutls_certificate_get_ocsp_expiration - وظيفة API

ملخص

#include <gnutls/gnutls.h>

time_t gnutls_certificate_get_ocsp_expiration(gnutls_certificate_credentials_t sc, unsigned idx, int oidx, unsigned flags);

الوسائط

gnutls_certificate_credentials_t sc
هو هيكل بيانات بيانات الاعتماد.
unsigned idx
هو فهرس سلسلة الشهادات كما تم إرجاعه بواسطة gnutls_certificate_set_key() وما شابهها
int oidx
هو فهرس استجابة OCSP
unsigned flags
يجب أن تكون صفر

الوصف

تقوم هذه الوظيفة بإرجاع صلاحية استجابات OCSP المحملة، لتوفير معلومات حول وقت إعادة تحميل/تحديثها.

لاحظ أن هيكل بيانات بيانات الاعتماد يجب أن يكون للقراءة فقط عند استخدامه، وبالتالي، عند إعادة التحميل، يجب ألا يتم استخدام هيكل بيانات بيانات الاعتماد بواسطة أي جلسات، أو يجب تخصيص هيكل بيانات بيانات اعتماد جديد للجلسات الجديدة.

عندما تكون oidx (-1) فيتم إرجاع الحد الأدنى لوقت التحديث لجميع الاستجابات. خلاف ذلك، يحدد الفهرس الاستجابة المقابلة للشهادة odix في سلسلة الشهادات.

يعيد

عند النجاح، وقت انتهاء صلاحية استجابة OCSP. بخلاف ذلك (time_t)(-1) عند حدوث خطأ، أو (time_t)-2 عند الخروج عن الحدود.

منذ

3.6.3
