GnuPG__Handles(3pm)

الحزمة: perl-gnupg-interface

التراخيص: PerlArtistic, GPL

GnuPG::Handles(3) توثيق Perl المساهم به GnuPG::Handles(3)

الاسم

GnuPG::Handles - حزمة معالجات GnuPG

الملخص

use IO::Handle;
my ( $stdin, $stdout, $stderr,
     $status_fh, $logger_fh, $passphrase_fh,
   )
  = ( IO::Handle->new(), IO::Handle->new(), IO::Handle->new(),
      IO::Handle->new(), IO::Handle->new(), IO::Handle->new(),
    );
my $handles = GnuPG::Handles->new
  ( stdin      => $stdin,
    stdout     => $stdout,
    stderr     => $stderr,
    status     => $status_fh,
    logger     => $logger_fh,
    passphrase => $passphrase_fh,
  );

الوصف

عادةً ما يتم إنشاء كائنات GnuPG::Handles لاستخدامها مع طرق الكائنات من الفئة GnuPG::Interface. تمثل كائنات GnuPG::Handles مجموعة من المعالجات التي تُستخدم للتواصل مع GnuPG.

طرق الكائنات

طرق التهيئة

new( %initialization_args )
تقوم هذه الطريقة بإنشاء كائن جديد. الوسائط الاختيارية هي تهيئة أعضاء البيانات.
hash_init( %args ).

أعضاء بيانات الكائن

stdin
هذا المعالج متصل بالدخل القياسي لعملية GnuPG.
stdout
هذا المعالج متصل بالخرج القياسي لعملية GnuPG.
stderr
هذا المعالج متصل بالخطأ القياسي لعملية GnuPG.
status
هذا المعالج متصل بمعالج خرج الحالة لعملية GnuPG.
logger
هذا المعالج متصل بمعالج خرج المسجل لعملية GnuPG.
passphrase
هذا المعالج متصل بمعالج إدخال عبارة المرور لعملية GnuPG.
command
هذا المعالج متصل بمعالج إدخال الأوامر لعملية GnuPG.
options
هذه تجزئة من تجزئات الإعدادات المتعلقة بالمعالجات في هذا الكائن. التجزئة الخارجية مفهرسة بأسماء المعالجات التي ينطبق عليها الإعداد، بينما التجزئة الداخلية مفهرسة بالإعداد المرجعي. على سبيل المثال، لتعيين الإعداد "direct" إلى صحيح لمعالج الملف "stdin"، سيؤدي الكود التالي إلى ذلك: 
# بافتراض أن $handles هو كائن GnuPG::Handles تم إنشاؤه بالفعل
# يقوم هذا بتعيين جميع
# الإعدادات لمعالج الملف stdin دفعة واحدة،
# مع مسح جميع الإعدادات الأخرى
$handles->options( 'stdin', { direct => 1 } );
# هذا مفيد لإجراء تغيير واحد فقط
# على مجموعة الإعدادات لمعالج
$handles->options( 'stdin' )->{direct} = 1;
# وللحصول على الإعداد...
$setting = $handles->options( 'stdin' )->{direct};
# ولإزالة الإعدادات لـ stdin
$handles->options( 'stdin', {} );

الإعدادات المستخدمة حاليًا هي كما يلي:

direct
إذا كان الإعداد "direct" صحيحًا لمعالج، فإن عملية GnuPG التي يتم إنشاؤها ستصل مباشرة إلى المعالج. هذا مفيد لجعل عملية GnuPG تقرأ أو تكتب مباشرة من أو إلى ملف تم فتحه بالفعل.
