gnutls_transport_set_fastopen(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

الاسم

gnutls_transport_set_fastopen - وظيفة API

الملخص

#include <gnutls/socket.h>

void gnutls_transport_set_fastopen(gnutls_session_t session, int fd, struct sockaddr * connect_addr, socklen_t connect_addrlen, unsigned int flags);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
int fd
هو واصف المقبس للجلسة
struct sockaddr * connect_addr
هو العنوان الذي نريد الاتصال به
socklen_t connect_addrlen
هو طول connect_addr
unsigned int flags
يجب أن تكون صفر

الوصف

يتيح TCP Fast Open (TFO) لجلسة عميل TLS المحددة. هذا يعني أن إنشاء اتصال TCP وإرسال أول حزمة TLS client hello يتم دمجهما. يجب تحديد عنوان النظير في connect_addr و connect_addrlen ، ويجب ألا يكون المقبس المحدد بواسطة fd متصلاً.

يعمل TFO فقط مع مقابس TCP من النوع AF_INET و AF_INET6. إذا لم يكن نظام التشغيل يدعم TCP Fast Open، فستؤدي هذه الوظيفة إلى استخدام gnutls للدالة connect() بشفافية أثناء أول كتابة.

ملاحظة

تتجاوز هذه الوظيفة جميع وظائف معاودة الاتصال بالنقل. إذا كان هذا غير مرغوب فيه، فيجب تنفيذ TCP Fast Open في وظائف معاودة الاتصال للمستخدم دون استدعاء هذه الوظيفة. عند استخدام هذه الوظيفة، يجب عدم تعيين معاودات اتصال النقل، ويجب عدم استدعاء gnutls_transport_set_ptr() أو gnutls_transport_set_int().

على GNU/Linux، يجب تمكين TFO على مستوى النظام، أي في /proc/sys/net/ipv4/tcp_fastopen، ويجب تعيين البت 0.

ليس لهذه الوظيفة أي تأثير على جلسات الخادم.
