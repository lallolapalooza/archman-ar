gnutls_transport_get_int2(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_transport_get_int2(3) gnutls gnutls_transport_get_int2(3)

الاسم

gnutls_transport_get_int2 - وظيفة API

ملخص

#include <gnutls/gnutls.h>

void gnutls_transport_get_int2(gnutls_session_t session, int * recv_int, int * send_int);

الوسائط

gnutls_session_t session
هو نوع gnutls_session_t.
int * recv_int
سيحتوي على القيمة لوظيفة السحب
int * send_int
سيحتوي على القيمة لوظيفة الإرسال

الوصف

تستخدم للحصول على وسائط وظائف النقل (مثل PUSH و PULL). يجب أن تكون قد تم تعيينها باستخدام gnutls_transport_set_int2().

منذ

3.1.9
