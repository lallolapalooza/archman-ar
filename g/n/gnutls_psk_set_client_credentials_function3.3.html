gnutls_psk_set_client_credentials_function3(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_psk_set_client_credentials_function3(3) gnutls gnutls_psk_set_client_credentials_function3(3)

الاسم

gnutls_psk_set_client_credentials_function3 - وظيفة API

ملخص

#include <gnutls/gnutls.h>

void gnutls_psk_set_client_credentials_function3(gnutls_psk_client_credentials_t cred, gnutls_psk_client_credentials_function3 * func);

المعاملات

gnutls_psk_client_credentials_t cred
هو نوع gnutls_psk_server_credentials_t.
gnutls_psk_client_credentials_function3 * func
هي دالة الاستدعاء (callback function)

الوصف

يمكن استخدام هذه الوظيفة لتعيين دالة استدعاء لاسترداد اسم المستخدم وكلمة المرور لمصادقة PSK الخاصة بالعميل. شكل دالة الاستدعاء هو: int (*callback)(gnutls_session_t, gnutls_datum_t* username, gnutls_datum_t* key, gnutls_datum_t* context, gnutls_psk_key_flags *flags);

تتمتع دالة الاستدعاء هذه بنفس الدلالات الخاصة بـ gnutls_psk_set_client_credentials_function2()، ولكنها تُرجع الأعلام (flags) المرتبطة بالمفتاح. يمكن لدالة الاستدعاء استيراد PSK خارجي باستخدام الطريقة الموضحة في RFC 9258 عن طريق استخدام gnutls_psk_format_imported_identity().

يجب تخصيص الحقل data الخاص بـ username و key و context باستخدام gnutls_malloc(). يجب أن يكون username سلسلة نصية ASCII أو سلسلة UTF-8. في حالة سلسلة UTF-8، يُنصح باتباع إطار عمل PRECIS لأسماء المستخدمين (rfc8265).

سيتم استدعاء دالة الاستدعاء مرة واحدة لكل مصافحة.

يجب أن تُرجع دالة الاستدعاء 0 عند النجاح. -1 يشير إلى خطأ.
