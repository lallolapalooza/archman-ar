gnutls_x509_privkey_import_pkcs8(3)

gnutls_x509_privkey_import_pkcs8(3) gnutls gnutls_x509_privkey_import_pkcs8(3)

الاسم

gnutls_x509_privkey_import_pkcs8 - وظيفة API

الخلاصة

#include <gnutls/x509.h>

int gnutls_x509_privkey_import_pkcs8(gnutls_x509_privkey_t key, const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, const char * password, unsigned int flags);

الوسائط

gnutls_x509_privkey_t key
البيانات لتخزين المفتاح المحلل
const gnutls_datum_t * data
المفتاح المشفر بصيغة DER أو PEM.
gnutls_x509_crt_fmt_t format
إما DER أو PEM
const char * password
كلمة المرور لفك تشفير المفتاح (إذا كان مشفرًا).
unsigned int flags
0 إذا كان مشفرًا أو GNUTLS_PKCS_PLAIN إذا لم يكن مشفرًا.

الوصف

ستقوم هذه الوظيفة بتحويل مفتاح PKCS8 2.0 المشفر بصيغة DER أو PEM إلى صيغة gnutls_x509_privkey_t الأصلية. سيتم تخزين المخرجات في key. يمكن استيراد مفاتيح RSA و DSA، ويمكن استخدام العلامات فقط للإشارة إلى مفتاح غير مشفر.

يمكن أن تكون كلمة المرور password إما بصيغة ASCII أو UTF-8 في مخططات التشفير PBES2 الافتراضية، أو بصيغة ASCII لمخططات PKCS12.

إذا كان الشهادة مشفرة بصيغة PEM فيجب أن تحتوي على رأس "ENCRYPTED PRIVATE KEY"، أو "PRIVATE KEY". تحتاج فقط إلى تحديد العلامات إذا كان المفتاح مشفرًا بصيغة DER، لأنه في هذه الحالة لا يمكن اكتشاف حالة التشفير تلقائيًا.

إذا تم تحديد العلامة GNUTLS_PKCS_PLAIN وكانت البيانات المقدمة مشفرة، فسيتم إرجاع GNUTLS_E_DECRYPTION_FAILED.

القيمة المُرجعة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.
