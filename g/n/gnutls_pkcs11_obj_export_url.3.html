gnutls_pkcs11_obj_export_url(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs11_obj_export_url(3) gnutls gnutls_pkcs11_obj_export_url(3)

الاسم

gnutls_pkcs11_obj_export_url - دالة API

الملخص

#include <gnutls/pkcs11.h>

int gnutls_pkcs11_obj_export_url(gnutls_pkcs11_obj_t obj, gnutls_pkcs11_url_type_t detailed, char ** url);

الحجج

gnutls_pkcs11_obj_t obj
تحتوي على شهادة PKCS 11
gnutls_pkcs11_url_type_t detailed
غير صفر إذا كانت هناك حاجة لعنوان URL مفصل
char ** url
سيحتوي على عنوان URL مخصص

الوصف

ستقوم هذه الدالة بتصدير عنوان URL يحدد الكائن المعطى.

القيمة المرجعة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا فسيتم إرجاع قيمة خطأ سالبة.

منذ

2.12.0
