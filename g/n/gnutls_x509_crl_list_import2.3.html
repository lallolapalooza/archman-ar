gnutls_x509_crl_list_import2(3)

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crl_list_import2(3) gnutls gnutls_x509_crl_list_import2(3)

الاسم

gnutls_x509_crl_list_import2 - وظيفة API

الخلاصة

#include <gnutls/x509.h>

int gnutls_x509_crl_list_import2(gnutls_x509_crl_t ** crls, unsigned int * size, const gnutls_datum_t * data, gnutls_x509_crt_fmt_t format, unsigned int flags);

الحجج

gnutls_x509_crl_t ** crls
سيحتوي على قائمة شهادات إلغاء التوقيع (CRL) المحللة.
unsigned int * size
سيحتوي على حجم القائمة.
const gnutls_datum_t * data
بيانات شهادة إلغاء التوقيع (CRL).
gnutls_x509_crt_fmt_t format
إما DER أو PEM.
unsigned int flags
يجب أن يكون (0) أو تسلسل OR'd من gnutls_certificate_import_flags.

الوصف

ستقوم هذه الوظيفة بتحويل قائمة شهادات إلغاء التوقيع (CRL) المعطاة إلى صيغة gnutls_x509_crl_t الأصلية. سيتم تخزين المخرجات في crls . سيتم تهيئتها تلقائيًا.

إذا كانت الشهادة مشفرة بصيغة PEM، فيجب أن تحتوي على رأس "X509 CRL".

يعيد

عدد الشهادات التي تمت قراءتها أو قيمة خطأ سالبة.

منذ

3.0
