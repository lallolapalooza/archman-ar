gnutls_ocsp_req_get_nonce(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_ocsp_req_get_nonce(3) gnutls gnutls_ocsp_req_get_nonce(3)

الاسم

gnutls_ocsp_req_get_nonce - وظيفة API

الملخص

#include <gnutls/ocsp.h>

int gnutls_ocsp_req_get_nonce(gnutls_ocsp_req_const_t req, unsigned int * critical, gnutls_datum_t * nonce);

الوسائط

gnutls_ocsp_req_const_t req
يجب أن تحتوي على نوع gnutls_ocsp_req_t
unsigned int * critical
ما إذا كان امتداد nonce مميزًا بأنه حرج، أو NULL
gnutls_datum_t * nonce
سيحتوي على مخزن مؤقت تم تخصيصه حديثًا ببيانات nonce

الوصف

ستقوم هذه الوظيفة بإرجاع بيانات امتداد nonce لطلب OCSP.

يحتاج المتصل إلى إلغاء تخصيص الذاكرة عن طريق استدعاء gnutls_free() على
nonce ->data.

القيم المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع رمز خطأ سالب.
