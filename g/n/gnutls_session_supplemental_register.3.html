gnutls_session_supplemental_register(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_session_supplemental_register(3) gnutls gnutls_session_supplemental_register(3)

الاسم

gnutls_session_supplemental_register - دالة API

ملخص

#include <gnutls/gnutls.h>

int gnutls_session_supplemental_register(gnutls_session_t session, const char * name, gnutls_supplemental_data_format_type_t type, gnutls_supp_recv_func recv_func, gnutls_supp_send_func send_func, unsigned flags);

الوسائط

gnutls_session_t session
الجلسة التي سيتم التسجيل لها
const char * name
اسم البيانات الإضافية المراد تسجيلها
gnutls_supplemental_data_format_type_t type
نوع تنسيق البيانات الإضافية
gnutls_supp_recv_func recv_func
الدالة لاستقبال البيانات
gnutls_supp_send_func send_func
الدالة لإرسال البيانات
unsigned flags
يجب أن تكون صفرًا

الوصف

ستقوم هذه الدالة بتسجيل نوع بيانات إضافي جديد (rfc4680). سيتم استخدام الدوال الإضافية المسجلة لهذه الجلسة المحددة. يجب أن يكون النوع المقدم نوعًا غير مخصص في gnutls_supplemental_data_format_type_t.

إذا كان النوع مسجلاً بالفعل أو تم التعامل معه داخليًا بواسطة GnuTLS، فسيتم إرجاع GNUTLS_E_ALREADY_REGISTERED.

نظرًا لأن البيانات الإضافية غير معرفة ضمن TLS 1.3، فإن هذه الدالة ستقوم بتعطيل دعم TLS 1.3 للجلسة المحددة.

القيم المعادة

GNUTLS_E_SUCCESS عند النجاح، وإلا فإن رمز خطأ سالب.

منذ

3.5.5
