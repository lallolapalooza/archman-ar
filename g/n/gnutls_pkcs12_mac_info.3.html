gnutls_pkcs12_mac_info(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs12_mac_info(3) gnutls gnutls_pkcs12_mac_info(3)

الاسم

gnutls_pkcs12_mac_info - وظيفة API

ملخص

#include <gnutls/pkcs12.h>

int gnutls_pkcs12_mac_info(gnutls_pkcs12_t pkcs12, unsigned int * mac, void * salt, unsigned int * salt_size, unsigned int * iter_count, char ** oid);

الوسائط

gnutls_pkcs12_t pkcs12
نوع pkcs12
unsigned int * mac
خوارزمية MAC المستخدمة كـ gnutls_mac_algorithm_t
void * salt
الملح المستخدم من سلسلة المفاتيح (إذا لم يكن NULL، فإن salt_size يمثل حجمه مبدئيًا)
unsigned int * salt_size
حجم ملح السلسلة إلى المفتاح
unsigned int * iter_count
عدد تكرارات السلسلة إلى المفتاح
char ** oid
إذا لم يكن NULL، فسوف يحتوي على متغير مخصص منتهي بسلسلة فارغة مع OID

الوصف

ستوفر هذه الوظيفة معلومات حول خوارزمية MAC المستخدمة في بنية PKCS 12. إذا كانت خوارزميات البنية غير معروفة، فسيتم إرجاع الرمز GNUTLS_E_UNKNOWN_HASH_ALGORITHM، وسيتم تعيين oid فقط. أي، سيتم تعيين oid على الهياكل التي تحتوي على MAC سواء تم دعمها أم لا. يجب إلغاء تهيئته باستخدام gnutls_free(). يتم تعيين المتغيرات الأخرى فقط على الهياكل المدعومة.

الإرجاع

GNUTLS_E_INVALID_REQUEST إذا كانت البنية المقدمة لا تحتوي على MAC، GNUTLS_E_UNKNOWN_HASH_ALGORITHM إذا لم يتم دعم MAC الخاص بالبنية، أو رمز خطأ سالب آخر في حالة الفشل. صفر عند النجاح.
