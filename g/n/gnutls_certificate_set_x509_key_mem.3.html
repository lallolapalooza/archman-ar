gnutls_certificate_set_x509_key_mem(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_certificate_set_x509_key_mem(3) gnutls gnutls_certificate_set_x509_key_mem(3)

الاسم

gnutls_certificate_set_x509_key_mem - وظيفة API

الاختصار

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_key_mem(gnutls_certificate_credentials_t res, const gnutls_datum_t * cert, const gnutls_datum_t * key, gnutls_x509_crt_fmt_t type);

الوسائط

gnutls_certificate_credentials_t res
هو نوع gnutls_certificate_credentials_t.
const gnutls_datum_t * cert
يحتوي على قائمة شهادات (مسار) للمفتاح الخاص المحدد
const gnutls_datum_t * key
هو المفتاح الخاص، أو NULL
gnutls_x509_crt_fmt_t type
هو PEM أو DER

الوصف

تقوم هذه الوظيفة بتعيين زوج شهادة/مفتاح خاص في نوع gnutls_certificate_credentials_t. قد يتم استدعاء هذه الوظيفة أكثر من مرة، في حالة وجود مفاتيح/شهادات متعددة للخادم.

لاحظ أن استخدام المفتاح (2.5.29.15) امتداد PKIX في شهادات X.509 مدعوم. هذا يعني أن الشهادات المخصصة للتوقيع لا يمكن استخدامها لمجموعات التشفير التي تتطلب التشفير.

إذا تم تقديم الشهادة والمفتاح الخاص بتشفير PEM، فيجب أن تكون السلاسل التي تحتوي على قيمهما خالية من الأصفار.

قد يكون key NULL إذا كنت تستخدم وظيفة استدعاء التوقيع، راجع gnutls_sign_callback_set().

لاحظ أن هذه الوظيفة، افتراضيًا، تُرجع صفرًا عند النجاح وقيمة سالبة عند الخطأ. منذ 3.5.6، عند تعيين العلامة GNUTLS_CERTIFICATE_API_V2 باستخدام gnutls_certificate_set_flags()، فإنها تُرجع فهرسًا (أكبر من أو يساوي صفر). يمكن استخدام هذا الفهرس لوظائف أخرى للإشارة إلى زوج المفتاح المضاف.

الإرجاع

عند النجاح، تُرجع هذه الوظيفة صفرًا، وبخلاف ذلك، قيمة سالبة عند الخطأ (انظر أعلاه لتعديل هذا السلوك).
