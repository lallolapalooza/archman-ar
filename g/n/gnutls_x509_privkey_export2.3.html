gnutls_x509_privkey_export2(3)

gnutls_x509_privkey_export2(3) gnutls gnutls_x509_privkey_export2(3)

الاسم

gnutls_x509_privkey_export2 - وظيفة API

التركيب

#include <gnutls/x509.h>

int gnutls_x509_privkey_export2(gnutls_x509_privkey_t key, gnutls_x509_crt_fmt_t format, gnutls_datum_t * out);

الوسائط

gnutls_x509_privkey_t key
تحتوي على المفتاح
gnutls_x509_crt_fmt_t format
صيغة المخرجات. أحد PEM أو DER.
gnutls_datum_t * out
سيحتوي على مفتاح خاص مرمّز بصيغة PEM أو DER

الوصف

ستقوم هذه الوظيفة بتصدير المفتاح الخاص إلى هيكل PKCS1 لمفاتيح RSA أو RSA-PSS، وتسلسل أعداد صحيحة لمفاتيح DSA. سيتم تصدير أنواع المفاتيح الأخرى بصيغة PKCS8.

يتم تخصيص مخزن الإخراج المؤقت باستخدام gnutls_malloc().

يوصى باستخدام gnutls_x509_privkey_export2_pkcs8() بدلاً من هذه الوظيفة، عندما تكون صيغة إخراج متسقة مطلوبة.

القيمة المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، بخلاف ذلك قيمة خطأ سالبة.
