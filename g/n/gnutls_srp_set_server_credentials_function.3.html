الوصف

يمكن استخدام هذه الوظيفة لتعيين دالة استدعاء لاسترداد بيانات اعتماد SRP للمستخدم. شكل دالة الاستدعاء هو:

int (*callback)(gnutls_session_t, const char* username, gnutls_datum_t *salt, gnutls_datum_t *verifier, gnutls_datum_t *generator, gnutls_datum_t *prime);


username يحتوي على اسم المستخدم الفعلي. يجب ملء salt و verifier و generator و prime باستخدام gnutls_malloc(). للسهولة، قد يكون prime و generator أيضًا أحد المعلمات الثابتة المعرفة في gnutls.h.

في البداية، يكون الحقل data هو NULL في كل بنية gnutls_datum_t التي يتعين على دالة الاستدعاء ملؤها. عند انتهاء دالة الاستدعاء، ستقوم GnuTLS بإلغاء تخصيص جميع هذه المخازن المؤقتة غير NULL، بغض النظر عن قيمة الإرجاع.

لمنع المهاجمين من تخمين أسماء المستخدمين الصالحة، إذا كان المستخدم غير موجود، يجب ملء قيم g و n باستخدام معلمات مستخدم عشوائي. في هذه الحالة، يجب أن ترجع دالة الاستدعاء القيمة الخاصة (1). انظر أيضًا gnutls_srp_set_server_fake_salt_seed. إذا لم يكن هذا مطلوبًا لتطبيقك، فارجع قيمة سالبة من دالة الاستدعاء لإلغاء المصافحة.

سيتم استدعاء دالة الاستدعاء مرة واحدة فقط لكل مصافحة. يجب أن ترجع دالة الاستدعاء 0 عند النجاح، بينما يشير -1 إلى خطأ.
