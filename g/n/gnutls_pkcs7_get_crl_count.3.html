gnutls_pkcs7_get_crl_count(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs7_get_crl_count(3) gnutls gnutls_pkcs7_get_crl_count(3)

الاسم

gnutls_pkcs7_get_crl_count - وظيفة API

ملخص

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_get_crl_count(gnutls_pkcs7_t pkcs7);

الوسائط

gnutls_pkcs7_t pkcs7
نوع pkcs7

الوصف

تقوم هذه الوظيفة بإرجاع عدد الشهادات في مجموعة PKCS7 أو RFC2630 crl.

القيمة المرجعة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا فسيتم إرجاع قيمة خطأ سالبة.
