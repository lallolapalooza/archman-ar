gnutls_x509_crq_get_extension_data2(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crq_get_extension_data2(3) gnutls gnutls_x509_crq_get_extension_data2(3)

الاسم

gnutls_x509_crq_get_extension_data2 - دالة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crq_get_extension_data2(gnutls_x509_crq_t crq, unsigned indx, gnutls_datum_t * data);

المعاملات

gnutls_x509_crq_t crq
يجب أن يحتوي على نوع gnutls_x509_crq_t
unsigned indx
يحدد معرف الامتداد المطلوب قراءته. استخدم (0) للحصول على الأول.
gnutls_datum_t * data
سيحتوي على بيانات الامتداد المشفرة بصيغة DER

الوصف

ستقوم هذه الدالة بإرجاع بيانات الامتداد المطلوبة في طلب الشهادة. سيتم تخصيص بيانات الامتداد باستخدام gnutls_malloc().

استخدم gnutls_x509_crq_get_extension_info() لاستخراج معرف الامتداد.

المُرجع

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وبخلاف ذلك يتم إرجاع رمز خطأ سالب. إذا وصلت إلى آخر امتداد متاح، فسيتم إرجاع GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE.

منذ

3.3.0
