gnutls_certificate_set_x509_key_file2(3)

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

الاسم

gnutls_certificate_set_x509_key_file2 - وظيفة API

الملخص

#include <gnutls/gnutls.h>

int gnutls_certificate_set_x509_key_file2(gnutls_certificate_credentials_t res, const char * certfile, const char * keyfile, gnutls_x509_crt_fmt_t type, const char * pass, unsigned int flags);

المعاملات

gnutls_certificate_credentials_t res
هو نوع gnutls_certificate_credentials_t.
const char * certfile
هو ملف يحتوي على قائمة الشهادات (مسار) للمفتاح الخاص المحدد، بتنسيق PKCS7، أو قائمة شهادات.
const char * keyfile
هو ملف يحتوي على المفتاح الخاص.
gnutls_x509_crt_fmt_t type
هو PEM أو DER.
const char * pass
هي كلمة مرور المفتاح.
unsigned int flags
تسلسل ORed من gnutls_pkcs_encrypt_flags_t.

الوصف

تقوم هذه الوظيفة بتعيين زوج من الشهادات/المفتاح الخاص في النوع gnutls_certificate_credentials_t. قد يتم استدعاء هذه الوظيفة أكثر من مرة، في حالة وجود مفاتيح/شهادات متعددة للخادم. بالنسبة للعملاء الذين يحتاجون إلى إرسال أكثر من شهادة الكيان الطرفي الخاصة بهم، على سبيل المثال، شهادة CA وسيطة أيضًا، فيجب أن يحتوي ملف certfile على سلسلة الشهادات المرتبة.

لاحظ أنه سيتم النظر في الأسماء الموجودة في الشهادة المقدمة عند اختيار الشهادة المناسبة للاستخدام (في حالة وجود أزواج متعددة من الشهادات/المفاتيح).

يمكن لهذه الوظيفة أيضًا قبول عناوين URL في keyfile و certfile. في هذه الحالة، ستستخدم المفتاح الخاص والشهادة المشار إليها بواسطة عناوين URL. لاحظ أن عناوين URL المدعومة هي تلك التي تشير إليها gnutls_url_is_supported(). قبل GnuTLS 3.4.0، عندما تم تحديد عنوان URL، تم تجاهل جزء pass وكان يجب تسجيل رد اتصال PIN، وهذا ليس هو الحال في الإصدارات الحالية.

في حالة تقديم certfile كعنوان URL لـ PKCS 11، فإن الشهادة، والمصدرين الحاليين لها في الرمز المميز، يتم استيرادها (أي، تشكيل سلسلة الثقة المطلوبة).

إذا فشلت هذه الوظيفة في تحميل بنية res، فهي في حالة غير معرفة، ويجب عدم استخدامها مرة أخرى لتحميل مفاتيح أو شهادات أخرى.

لاحظ أن هذه الوظيفة بشكل افتراضي تُرجع صفرًا عند النجاح وقيمة سالبة عند الخطأ. منذ الإصدار 3.5.6، عند تعيين علامة GNUTLS_CERTIFICATE_API_V2 باستخدام gnutls_certificate_set_flags()، فإنها تُرجع فهرسًا (أكبر من أو يساوي صفرًا). يمكن استخدام هذا الفهرس في وظائف أخرى للإشارة إلى زوج المفتاح المضاف.

يعيد

عند النجاح، تُرجع هذه الوظائف صفرًا، وبخلاف ذلك قيمة سالبة عند الخطأ (انظر أعلاه لتعديل هذا السلوك).
