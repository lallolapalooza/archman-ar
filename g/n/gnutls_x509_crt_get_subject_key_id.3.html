gnutls_x509_crt_get_subject_key_id(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_x509_crt_get_subject_key_id(3) gnutls gnutls_x509_crt_get_subject_key_id(3)

الاسم

gnutls_x509_crt_get_subject_key_id - وظيفة API

الملخص

#include <gnutls/x509.h>

int gnutls_x509_crt_get_subject_key_id(gnutls_x509_crt_t cert, void * ret, size_t * ret_size, unsigned int * critical);

الوسائط

gnutls_x509_crt_t cert
يجب أن تحتوي على نوع gnutls_x509_crt_t
void * ret
المكان الذي سيتم فيه نسخ المعرف
size_t * ret_size
تحتوي على حجم حقل النتيجة.
unsigned int * critical
ستكون غير صفرية إذا تم تمييز الامتداد على أنه حرج (قد تكون فارغة)

الوصف

ستعيد هذه الوظيفة معرف مفتاح الموضوع لشهادة X.509v3. يتم الحصول على هذا من حقل امتداد معرف مفتاح الموضوع X.509 (2.5.29.14).

الإرجاع

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، GNUTLS_E_REQUESTED_DATA_NOT_AVAILABLE إذا لم يكن الامتداد موجودًا، وإلا فإن قيمة خطأ سالبة.
