gnutls_certificate_server_set_request(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_certificate_server_set_request(3) gnutls gnutls_certificate_server_set_request(3)

الاسم

gnutls_certificate_server_set_request - دالة واجهة برمجة التطبيقات

الملخص

#include <gnutls/gnutls.h>

void gnutls_certificate_server_set_request(gnutls_session_t session, gnutls_certificate_request_t req);

المعاملات

gnutls_session_t session
هو نوع gnutls_session_t.
gnutls_certificate_request_t req
هو أحد الخيارات: GNUTLS_CERT_REQUEST، GNUTLS_CERT_REQUIRE، GNUTLS_CERT_IGNORE

الوصف

تحدد هذه الدالة ما إذا كنا (في حالة الخادم) سنرسل رسالة طلب شهادة إلى العميل. إذا كان req هو GNUTLS_CERT_REQUIRE، فسيعيد الخادم الخطأ GNUTLS_E_NO_CERTIFICATE_FOUND إذا لم يوفر الطرف الآخر شهادة. إذا لم تقم باستدعاء هذه الدالة، فلن يُطلب من العميل إرسال شهادة. استدعاء الدالة مع req GNUTLS_CERT_IGNORE له نفس التأثير.
