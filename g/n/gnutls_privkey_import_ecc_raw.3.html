الاسم

gnutls_privkey_import_ecc_raw - دالة API

الملخص

#include <gnutls/abstract.h>

int gnutls_privkey_import_ecc_raw(gnutls_privkey_t key, gnutls_ecc_curve_t curve, const gnutls_datum_t * x, const gnutls_datum_t * y, const gnutls_datum_t * k);

الحجج

gnutls_privkey_t key
المفتاح
gnutls_ecc_curve_t curve
يحتوي على المنحنى
const gnutls_datum_t * x
يحتوي على الإحداثي x
const gnutls_datum_t * y
يحتوي على الإحداثي y
const gnutls_datum_t * k
يحتوي على k (المفتاح الخاص)

الوصف

ستقوم هذه الدالة بتحويل معلمات المنحنى الإهليلجي المعطاة إلى تنسيق gnutls_privkey_t الأصلي. سيتم تخزين الناتج في key.

في منحنيات EdDSA، يجب أن يكون المعامل y هو NULL ويجب أن تكون المعاملات x و k بالتنسيق الأصلي للمنحنى.

القيمة المعادة

عند النجاح، يتم إرجاع GNUTLS_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.
