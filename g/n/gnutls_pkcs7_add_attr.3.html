gnutls_pkcs7_add_attr(3)

الحزمة: gnutls

التراخيص: GPL-3.0-or-later AND LGPL-2.1-or-later

gnutls_pkcs7_add_attr(3) gnutls gnutls_pkcs7_add_attr(3)

الاسم

gnutls_pkcs7_add_attr - وظيفة API

الملخص

#include <gnutls/pkcs7.h>

int gnutls_pkcs7_add_attr(gnutls_pkcs7_attrs_t * list, const char * oid, gnutls_datum_t * data, unsigned flags);

الوسائط

gnutls_pkcs7_attrs_t * list
قائمة بالسمات الموجودة أو مؤشر إلى NULL للعنصر الأول
const char * oid
معرف الكائن (OID) للسمة المراد تعيينها
gnutls_datum_t * data
البيانات الخام (مشفرة بـ DER) للسمة المراد تعيينها
unsigned flags
صفر أو GNUTLS_PKCS7_ATTR_ENCODE_OCTET_STRING

الوصف

تقوم هذه الوظيفة بتعيين سمة PKCS 7 في القائمة المقدمة. في حال فشلت هذه الوظيفة، سيتم إلغاء تخصيص القائمة السابقة.

لاحظ أن أي سمات تم تعيينها باستخدام هذه الوظيفة يجب أن تكون مشفرة بـ DER أو BER، ما لم يكن هناك علامة خاصة.

الإرجاع

عند النجاح، رأس القائمة الجديد، وإلا NULL.

منذ

3.4.2
