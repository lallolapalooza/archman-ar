الاسم

gnutls_x509_trust_list_set_getissuer_function - دالة API

ملخص

#include <gnutls/x509.h>

void gnutls_x509_trust_list_set_getissuer_function(gnutls_x509_trust_list_t tlist, gnutls_x509_trust_list_getissuer_function * func);

المعاملات

gnutls_x509_trust_list_t tlist
هو نوع gnutls_x509_trust_list_t.
gnutls_x509_trust_list_getissuer_function * func
هي الدالة الاستدعائية (callback).

الوصف

تقوم هذه الدالة بتعيين دالة استدعائية ليتم استدعاؤها عندما تكون سلسلة شهادات الطرف المقابل غير مكتملة بسبب شهادة وسيطة مفقودة. قد توفر الدالة الاستدعائية الشهادة المفقودة لاستخدامها أثناء التحقق.

يتم تعريف نموذج الدالة الاستدعائية في gnutls/x509.h على النحو التالي:

int (*callback)(gnutls_x509_trust_list_t list, const gnutls_x509_crt_t cert, gnutls_x509_crt_t **issuers, unsigned int *issuers_size);

إذا تم توفير الدالة الاستدعائية، فستقوم gnutls باستدعائها أثناء إجراء التحقق من الشهادة. قد ترغب الدالة الاستدعائية في استخدام gnutls_x509_crt_get_authority_info_access() للحصول على URI الذي يمكن من خلاله محاولة تنزيل شهادة المصدر المفقودة، إذا كانت متاحة.

عند نجاح الاستدعاء، يجب على الدالة الاستدعائية تعيين '*issuers' و '*issuers_size' حتى لو كانت النتيجة فارغة؛ في هذه الحالة، سيشير '*issuers' إلى NULL وسيتم تخصيص الذاكرة باستخدام gnutls_x509_crt_list_import2(). يتم نقل ملكية كل من المصفوفة والعناصر إلى المتصل، وبالتالي لا يحتاج التطبيق إلى الاحتفاظ بالذاكرة بعد الاستدعاء.

يجب أن تُرجع الدالة الاستدعائية 0 إذا نجحت محاولة استرداد شهادات المصدر لـ 'crt'، أو قيمة غير صفرية للإشارة إلى حدوث أي خطأ أثناء المحاولة. في الحالة الأخيرة، لا يتم تعيين '*issuers' و '*issuers_size'.
