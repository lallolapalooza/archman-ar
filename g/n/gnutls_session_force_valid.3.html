الاسم

gnutls_session_force_valid - دالة API

الاختصار

#include <gnutls/gnutls.h>

void gnutls_session_force_valid(gnutls_session_t session);

الوصف

يمسح علامة غير صالح في الجلسة. هذا يعني أنه يمكن إعادة استخدام الجلسات التي كانت تالفة أو تم تلقي بيانات غير صالحة بها. استخدم فقط عند تصحيح الأخطاء أو التجريب ببروتوكول TLS. لا ينبغي استخدامه في التطبيقات العادية.
