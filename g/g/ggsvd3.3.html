NAME

zgsvd3 - ZGGSVD3 computes the generalized Schur decomposition of two complex matrices A and B.

SYNOPSIS

  SUBROUTINE ZGGSVD3( JOBS, JOBU, JOBV, M, N, P, A, LDA, B, LDB, EPSA,
                      EPSB, S, U, LDU, V, LDV, WORK, LWORK, IWORK,
                      INFO )
    INTEGER            INFO
    INTEGER            IWORK( * )
    INTEGER            LDA, LDB, LDU, LDV, LWORK, M, N, P
    COMPLEX*16         A( LDA, * ), B( LDB, * ), U( LDU, * ), V( LDV, * )
    DOUBLE PRECISION   EPSA, EPSB
    DOUBLE PRECISION   S( * )
    COMPLEX*16         WORK( * )

Detailed Description

ZGGSVD3 computes the generalized Schur decomposition of two complex upper trapezoidal matrices A and B:

  A = U * S * ( R**H )
  B = V * T * ( R**H )

where U and V are unitary matrices, R is a nonsingular upper triangular matrix, and S and T are real and upper triangular matrices. The diagonal elements of S and T are nonnegative.

The generalized Schur decomposition is computed by first reducing A and B to upper triangular and upper trapezoidal form respectively, and then applying a generalized Schur iteration to compute the generalized Schur decomposition of the resulting matrices.

Further Details

This routine is the solution to the generalized singular value decomposition problem.

See "Generalizing the Singular Value Decomposition", Computer Physics Communications 164:217-222, 2004 (doi: 10.1016/j.cpc.2004.06.030).

This routine replaces the deprecated subroutine ZGGSVD.

Parameters

JOBS
CHARACTER*1.

Indicates what is to be computed:

  = 'N':  none
  = 'S':  S and T are computed.

JOBS = 'S' is not supported.

JOBU
CHARACTER*1.

Indicates whether to compute the matrix U:

  = 'N':  U is not computed.
  = 'U':  U is computed.
JOBV
CHARACTER*1.

Indicates whether to compute the matrix V:

  = 'N':  V is not computed.
  = 'V':  V is computed.
M
INTEGER.

The number of rows of A and B.

N
INTEGER.

The number of columns of A and B. M and N must be equal.

P
INTEGER.

The number of rows of B. P and N must be equal.

A
COMPLEX*16 array, dimension (LDA, N).

On entry, the M-by-N matrix A.

LDA
INTEGER.

The leading dimension of the array A. LDA >= max(1, M).

B
COMPLEX*16 array, dimension (LDB, N).

On entry, the P-by-N matrix B.

LDB
INTEGER.

The leading dimension of the array B. LDB >= max(1, P).

EPSA
DOUBLE PRECISION.

The threshold to determine the effective rank of A.

EPSA is set to MAX(M,N)*norm(A)*MACHEPS.

The size of EPSA may affect the size of backward errors of the decomposition.

EPSB
DOUBLE PRECISION.

The threshold to determine the effective rank of B.

EPSB is set to MAX(P,N)*norm(B)*MACHEPS.

The size of EPSB may affect the size of backward errors of the decomposition.

S
DOUBLE PRECISION array, dimension (N).

On exit, the diagonal elements of the upper triangular matrix S.

The diagonal elements of S are nonnegative.

U
COMPLEX*16 array, dimension (LDU, N).

On exit, U is a unitary matrix which contains the left singular vectors of the generalized singular value decomposition.

If JOB = 'N', U is not returned.

LDU
INTEGER.

The leading dimension of the array U. LDU >= max(1, M) if JOBU = 'U', and LDU >= 1 otherwise.

V
COMPLEX*16 array, dimension (LDV, N).

On exit, V is a unitary matrix which contains the right singular vectors of the generalized singular value decomposition.

If JOBV = 'N', V is not returned.

LDV
INTEGER.

The leading dimension of the array V. LDV >= max(1, P) if JOBV = 'V', and LDV >= 1 otherwise.

WORK
COMPLEX*16 array, dimension (LWORK).

On exit, WORK(1) contains the optimal value of LWORK.

LWORK
INTEGER.

The dimension of the array WORK. LWORK >= max(1, 2*M, 2*P).

For optimal efficiency, LWORK >= max(1, 2*M, 2*P) + 2*M*N + 2*P*N + max(M*M, P*P) + max(M*P, N*N).

If LWORK = -1, then the optimal dimension is calculated and stored in WORK(1), and no computation is performed.

IWORK
INTEGER array, dimension (N).

Workspace for the subroutine.

INFO
INTEGER.

= 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = 1, the Jacobi-type procedure failed to converge. For further details, see subroutine ZTGSJA.

Internal Parameters:

TOLA    DOUBLE PRECISION
TOLB    DOUBLE PRECISION
        TOLA and TOLB are the thresholds to determine the effective
        rank of (A**H,B**H)**H. Generally, they are set to
                 TOLA = MAX(M,N)*norm(A)*MACHEPS,
                 TOLB = MAX(P,N)*norm(B)*MACHEPS.
        The size of TOLA and TOLB may affect the size of backward
        errors of the decomposition.

zgsvd3 - ZGGSVD3 يحسب تحليل Schur المعمم لمصفوفتين معقدتين A و B.

الوصف التفصيلي

ZGGSVD3 يحسب تحليل Schur المعمم لمصفوفتين شبه مثلثة علوية معقدتين A و B:

  A = U * S * ( R**H )
  B = V * T * ( R**H )

حيث U و V مصفوفتان وحدويتان، R مصفوفة علوية غير مفردة، و S و T مصفوفتان مثلثيتان حقيقيتان وعلويتان. عناصر القطر للمصفوفتين S و T غير سالبة.

يتم حساب تحليل Schur المعمم عن طريق تقليل A و B أولاً إلى شكل مثلثي علوي وشبه مثلثي علوي على التوالي، ثم تطبيق تكرار Schur المعمم لحساب تحليل Schur المعمم للمصفوفتين الناتجتين.
