gtk4-builder-tool(1)

الحزمة: gtk4

التراخيص: LGPL-2.1-or-later

gtk4-builder-tool(1) أوامر GTK gtk4-builder-tool(1)

الاسم

gtk4-builder-tool - أداة ملف GtkBuilder

الملخص

gtk4-builder-tool <COMMAND> [OPTIONS...] <FILE>
gtk4-builder-tool validate [OPTIONS...] <FILE>
gtk4-builder-tool enumerate [OPTIONS...] <FILE>
gtk4-builder-tool simplify [OPTIONS...] <FILE>
gtk4-builder-tool preview [OPTIONS...] <FILE>
gtk4-builder-tool render [OPTIONS...] <FILE>
gtk4-builder-tool screenshot [OPTIONS...] <FILE>

الوصف

يمكن لـ gtk4-builder-tool إجراء عمليات مختلفة على ملفات تعريف واجهة المستخدم الخاصة بـ GtkBuilder.

الأوامر

التحقق

يقوم الأمر validate بالتحقق من صحة ملف تعريف واجهة المستخدم المحدد والإبلاغ عن الأخطاء إلى stderr.

لاحظ أن هناك قيودًا على التحقق الذي يمكن إجراؤه للقوالب، نظرًا لأنها مرتبطة ارتباطًا وثيقًا بدالة class_init التي يتم استخدامها فيها. إذا كان ملف واجهة المستخدم الخاص بك يستخدم أنواعًا من مكتبات الطرف الثالث، فقد يكون من المفيد إضافة هذه المكتبات إلى متغير البيئة LD_PRELOAD.

--deprecations

تحذير بشأن استخدام الأنواع المهملة في ملف تعريف واجهة المستخدم.

التعداد

يطبع الأمر enumerate جميع الكائنات المسماة الموجودة في ملف تعريف واجهة المستخدم.

--callbacks

طباعة أسماء الوظائف الاستدعائية أيضًا.

معاينة

يعرض الأمر preview ملف تعريف واجهة المستخدم.

يقبل هذا الأمر خيارات لتحديد معرف الكائن العلوي وملف CSS للاستخدام.

--id=ID

معرف الكائن المراد معاينته. إذا لم يتم تحديده، سيختار gtk4-builder-tool كائنًا مناسبًا بنفسه.

--css=FILE

تحميل معلومات النمط من ملف CSS المحدد.

العرض

يقوم الأمر render بحفظ عرض لملف تعريف واجهة المستخدم كصورة png أو ملف عقدة. يمكن تحديد اسم الملف للكتابة كملف FILE ثانٍ.

يقبل هذا الأمر خيارات لتحديد معرف الكائن العلوي وملف CSS للاستخدام.

--id=ID

معرف الكائن المراد معاينته. إذا لم يتم تحديده، سيختار gtk4-builder-tool كائنًا مناسبًا بنفسه.

--css=FILE

تحميل معلومات النمط من ملف CSS المحدد.

--node

كتابة ملف عقدة متسلسل بدلاً من صورة png.

--force

الكتابة فوق ملف موجود.

لقطة الشاشة

الأمر screenshot هو اسم مستعار لـ render.

التبسيط

يقوم الأمر simplify بتبسيط ملف تعريف واجهة المستخدم عن طريق إزالة الخصائص التي تم تعيينها إلى قيمها الافتراضية ويكتب XML الناتج إلى المخرج القياسي، أو يعود إلى الملف الأصلي.

عند تحديد الخيار --3to4، يفسر الأمر simplify المدخلات كملف تعريف واجهة المستخدم GTK 3 ويحاول تحويله إلى ما يعادله في GTK 4. يقوم بإجراء تحويلات مختلفة، مثل إعادة تسمية الخصائص، وترجمة خصائص الأطفال إلى خصائص تخطيط، وإعادة كتابة إعداد GtkNotebook أو GtkStack أو GtkAssistant أو تغيير أشرطة الأدوات إلى صناديق.

يجب عليك دائمًا اختبار ملفات تعريف واجهة المستخدم المعدلة التي تنتجها gtk4-builder-tool قبل استخدامها في الإنتاج.

لاحظ على وجه الخصوص أن التحويل الذي يتم إجراؤه باستخدام --3to4 يعد نقطة انطلاق للترحيل من GTK 3 إلى GTK 4. من المتوقع أن تحتاج إلى إجراء إصلاحات يدوية بعد التحويل الأولي.

--replace

الكتابة فوق المحتوى مرة أخرى في ملف تعريف واجهة المستخدم بدلاً من استخدام المخرج القياسي.

--3to4

تحويل ملف تعريف واجهة المستخدم GTK 3 إلى ما يعادله في GTK 4.
