gtlsshd(8) — gtlsshd

gtlsshd — OpenSSH server using TLS authentication

SYNOPSIS

gtlsshd [options]

DESCRIPTION

gtlsshd is an OpenSSH server that uses TLS certificates for client authentication. It is designed to provide a secure way to access a system using certificate-based authentication instead of traditional passwords or public key authentication.

The server listens for incoming TLS connections, verifies the client's certificate against a configured trust store, and then proceeds with the standard SSH authentication and session setup.

OPTIONS

The following options are supported:

  • -f <configfile>: Specify a configuration file.
  • -p <port>: Specify the port to listen on.
  • -d <directory>: Specify the chroot directory.
  • -c <certificate>: Specify the server certificate.
  • -k <key>: Specify the server private key.
  • -C <ca_bundle>: Specify the CA bundle for client certificate verification.
  • -V <version>: Specify the TLS protocol version.
  • -h: Display help message.

TWO-FACTOR AUTHENTICATION

gtlsshd supports two-factor authentication by requiring both a valid TLS certificate and a second factor, such as a password or a one-time code, for user login. This enhances security by adding an extra layer of protection.

gtlsshd(8) — gtlsshd

gtlsshd — خادم OpenSSH يستخدم مصادقة TLS

ملخص

gtlsshd [خيارات]

الوصف

gtlsshd هو خادم OpenSSH يستخدم شهادات TLS لمصادقة العميل. تم تصميمه لتوفير طريقة آمنة للوصول إلى نظام باستخدام المصادقة القائمة على الشهادات بدلاً من كلمات المرور التقليدية أو مصادقة المفتاح العام.

يستمع الخادم للاتصالات الواردة عبر TLS، ويتحقق من شهادة العميل مقابل مخزن الثقة المحدد، ثم يبدأ في إعداد المصادقة وجلسة SSH القياسية.

الخيارات

الخيارات التالية مدعومة:

  • -f <ملف_الإعداد>: تحديد ملف الإعدادات.
  • -p <منفذ>: تحديد المنفذ للاستماع عليه.
  • -d <دليل>: تحديد دليل chroot.
  • -c <شهادة>: تحديد شهادة الخادم.
  • -k <مفتاح>: تحديد المفتاح الخاص للخادم.
  • -C <حزمة_CA>: تحديد حزمة CA للتحقق من شهادة العميل.
  • -V <إصدار>: تحديد إصدار بروتوكول TLS.
  • -h: عرض رسالة المساعدة.

المصادقة الثنائية

يدعم gtlsshd المصادقة الثنائية عن طريق طلب شهادة TLS صالحة وعامل ثانٍ، مثل كلمة مرور أو رمز لمرة واحدة، لتسجيل دخول المستخدم. هذا يعزز الأمان عن طريق إضافة طبقة إضافية من الحماية.
