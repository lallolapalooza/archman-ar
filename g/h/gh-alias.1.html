gh-alias(1)

الحزمة: github-cli

التراخيص: MIT

GH-ALIAS(1) دليل GitHub CLI GH-ALIAS(1)

الاسم

gh-alias - إنشاء اختصارات للأوامر

موجز

gh alias <command> [flags]

الوصف

يمكن استخدام الأسماء المستعارة لإنشاء اختصارات لأوامر gh أو لتجميع أوامر متعددة.

قم بتشغيل gh help alias set لمعرفة المزيد.

الأوامر المتاحة

gh-alias-delete(1)
حذف الأسماء المستعارة المعينة
gh-alias-import(1)
استيراد الأسماء المستعارة من ملف YAML
gh-alias-list(1)
عرض الأسماء المستعارة الخاصة بك
gh-alias-set(1)
إنشاء اختصار لأمر gh

1: خطأ

2: تم إلغاء الأمر

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.
