gh-release-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-RELEASE-LIST(1) دليل GitHub CLI GH-RELEASE-LIST(1)

الاسم

gh-release-list - سرد الإصدارات في مستودع

ملخص

gh release list [flags]

خيارات

--exclude-drafts
استبعاد الإصدارات المسودة
--exclude-pre-releases
استبعاد الإصدارات الأولية
-q, --jq <expression>
تصفية خرج JSON باستخدام تعبير jq
--json <fields>
إخراج JSON مع الحقول المحددة
-L, --limit <int> (افتراضي 30)
الحد الأقصى لعدد العناصر المراد جلبها
-O, --order <string> (افتراضي "desc")
ترتيب الإصدارات المعادة: {asc|desc}
-t, --template <string>
تنسيق خرج JSON باستخدام قالب Go؛ راجع "gh help formatting"

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO

أسماء مستعارة

gh release ls

حقول JSON

createdAt، isDraft، isImmutable، isLatest، isPrerelease، name، publishedAt، tagName

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.
