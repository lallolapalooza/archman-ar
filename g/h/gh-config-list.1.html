gh-config-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-CONFIG-LIST(1) دليل سطر أوامر GitHub GH-CONFIG-LIST(1)

الاسم

gh-config-list - طباعة قائمة بمفاتيح وقيم التكوين

الملخص

gh config list [flags]

الخيارات

-h, --host <string>
الحصول على تكوين لكل مضيف

أسماء مختصرة

gh config ls

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.
