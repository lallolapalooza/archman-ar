gh-release-download(1)

الحزمة: github-cli

التراخيص: MIT

GH-RELEASE-DOWNLOAD(1) دليل GitHub CLI GH-RELEASE-DOWNLOAD(1)

الاسم

gh-release-download - تنزيل أصول الإصدار

الملخص

gh release download [<tag>] [flags]

الوصف

تنزيل أصول إصدار GitHub.

بدون اسم وسم صريح كوسيط، يتم تنزيل الأصول من أحدث إصدار في المشروع. في هذه الحالة، يكون --pattern أو --archive مطلوبًا.

خيارات

-A, --archive <format>
تنزيل أرشيف شفرة المصدر بالتنسيق المحدد (zip أو tar.gz)
--clobber
الكتابة فوق الملفات الموجودة بنفس الاسم
-D, --dir <directory> (الافتراضي ".")
الدليل الذي سيتم تنزيل الملفات إليه
-O, --output <file>
الملف الذي سيتم كتابة أصل واحد إليه (استخدم "-" للكتابة إلى الإخراج القياسي)
-p, --pattern <stringArray>
تنزيل الأصول التي تطابق نمط glob فقط
--skip-existing
تخطي التنزيل عند وجود ملفات بنفس الاسم

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
اختر مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب مصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى تعليمات الأمر لمزيد من المعلومات.

مثال

# تنزيل جميع أصول إصدار معين
$ gh release download v1.2.3
# تنزيل حزم Debian فقط للإصدار الأخير
$ gh release download --pattern '*.deb'
# تحديد أنماط ملفات متعددة
$ gh release download -p '*.deb' -p '*.rpm'
# تنزيل أرشيف شفرة المصدر لإصدار
$ gh release download v1.2.3 --archive=zip
