gh(1)

الحزمة: github-cli

التراخيص: MIT

GH(1) دليل GitHub CLI GH(1)

الاسم

gh - GitHub CLI

الملخص

gh <command> <subcommand> [flags]

الوصف

تعامل بسلاسة مع GitHub من سطر الأوامر.

الأوامر الأساسية

gh-auth(1)
مصادقة gh و git مع GitHub
gh-browse(1)
افتح المستودعات، والمشاكل، وطلبات السحب، والمزيد في المتصفح
gh-codespace(1)
الاتصال وإدارة الـ codespaces
gh-gist(1)
إدارة الـ gists
gh-issue(1)
إدارة المشاكل
gh-org(1)
إدارة المنظمات
gh-pr(1)
إدارة طلبات السحب
gh-project(1)
العمل مع مشاريع GitHub.
gh-release(1)
إدارة الإصدارات
gh-repo(1)
إدارة المستودعات

أوامر GitHub Actions

gh-cache(1)
إدارة ذاكرة التخزين المؤقت لـ GitHub Actions
gh-run(1)
عرض تفاصيل حول تشغيلات سير العمل
gh-workflow(1)
عرض تفاصيل حول سير عمل GitHub Actions

أوامر إضافية

gh-agent-task(1)
العمل مع مهام الوكيل (معاينة)
gh-alias(1)
إنشاء اختصارات للأوامر
gh-api(1)
إجراء طلب مصادق عليه لواجهة برمجة تطبيقات GitHub
gh-attestation(1)
العمل مع شهادات القطع الأثرية
gh-completion(1)
إنشاء نصوص إكمال shell
gh-config(1)
إدارة إعدادات gh
gh-extension(1)
إدارة ملحقات gh
gh-gpg-key(1)
إدارة مفاتيح GPG
gh-label(1)
إدارة التصنيفات
gh-preview(1)
تنفيذ معاينات لميزات gh
gh-ruleset(1)
عرض معلومات حول قواعد المستودع
gh-search(1)
البحث عن المستودعات والمشاكل وطلبات السحب
gh-secret(1)
إدارة أسرار GitHub
gh-ssh-key(1)
إدارة مفاتيح SSH
gh-status(1)
طباعة معلومات حول المشاكل وطلبات السحب والإشعارات ذات الصلة عبر المستودعات
gh-variable(1)
إدارة متغيرات GitHub Actions

خيارات

--version
عرض إصدار gh

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

$ gh issue create
$ gh repo clone cli/cli
$ gh pr checkout 321
