gh-cache(1)

الحزمة: github-cli

التراخيص: MIT

GH-CACHE(1) دليل GitHub CLI GH-CACHE(1)

الاسم

gh-cache - إدارة ذاكرات التخزين المؤقت لـ GitHub Actions

الملخص

gh cache <command> [flags]

الوصف

العمل مع ذاكرات التخزين المؤقت لـ GitHub Actions.

الأوامر المتاحة

gh-cache-delete(1)
حذف ذاكرات التخزين المؤقت لـ GitHub Actions
gh-cache-list(1)
قائمة ذاكرات التخزين المؤقت لـ GitHub Actions

الخيارات

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

$ gh cache list
$ gh cache delete --all
