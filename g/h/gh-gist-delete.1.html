gh-gist-delete(1)

الحزمة: github-cli

التراخيص: MIT

GH-GIST-DELETE(1) دليل سطر أوامر GitHub GH-GIST-DELETE(1)

الاسم

gh-gist-delete - حذف Gist

الملخص

gh gist delete {<id> | <url>} [flags]

الوصف

حذف GitHub gist.

لحذف Gist بشكل تفاعلي، استخدم gh gist delete بدون أي وسيطات.

لحذف Gist بشكل غير تفاعلي، قم بتوفير معرف Gist أو عنوان URL الخاص به.

خيارات

--yes
تأكيد الحذف دون طلب

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

مثال

# حذف Gist بشكل تفاعلي
$ gh gist delete
# حذف Gist بشكل غير تفاعلي
$ gh gist delete 1234
