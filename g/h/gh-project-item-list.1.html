gh-project-item-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-PROJECT-ITEM-LIST(1) دليل GitHub CLI GH-PROJECT-ITEM-LIST(1)

الاسم

gh-project-item-list - سرد العناصر في مشروع

الملخص

gh project item-list [<رقم>] [flags]

الخيارات

--format <string>
تنسيق الإخراج: {json}
-q, --jq <expression>
تصفية إخراج JSON باستخدام تعبير jq
-L, --limit <int> (الافتراضي 30)
الحد الأقصى لعدد العناصر المراد جلبها
--owner <string>
اسم تسجيل الدخول للمالك. استخدم "@me" للمستخدم الحالي.
-t, --template <string>
تنسيق إخراج JSON باستخدام قالب Go؛ انظر "gh help formatting"

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون لأوامر محددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# سرد العناصر في مشروع المستخدم الحالي "1"
$ gh project item-list 1 --owner "@me"
