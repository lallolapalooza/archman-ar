gh-issue(1)

الحزمة: github-cli

التراخيص: MIT

GH-ISSUE(1) دليل GitHub CLI GH-ISSUE(1)

الاسم

gh-issue - إدارة المشكلات

الملخص

gh issue <command> [flags]

الوصف

العمل مع مشكلات GitHub.

أوامر عامة

gh-issue-create(1)
إنشاء مشكلة جديدة
gh-issue-list(1)
قائمة المشكلات في مستودع
gh-issue-status(1)
عرض حالة المشكلات ذات الصلة

أوامر مستهدفة

gh-issue-close(1)
إغلاق المشكلة
gh-issue-comment(1)
إضافة تعليق إلى مشكلة
gh-issue-delete(1)
حذف المشكلة
gh-issue-develop(1)
إدارة الفروع المرتبطة بالمشكلة
gh-issue-edit(1)
تعديل المشكلات
gh-issue-lock(1)
قفل محادثة المشكلة
gh-issue-pin(1)
تثبيت مشكلة
gh-issue-reopen(1)
إعادة فتح المشكلة
gh-issue-transfer(1)
نقل المشكلة إلى مستودع آخر
gh-issue-unlock(1)
فتح قفل محادثة المشكلة
gh-issue-unpin(1)
إلغاء تثبيت مشكلة
gh-issue-view(1)
عرض مشكلة

خيارات

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: التنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. ارجع إلى تعليمات الأمر لمزيد من المعلومات.

مثال

$ gh issue list
$ gh issue create --label bug
$ gh issue view 123 --web
