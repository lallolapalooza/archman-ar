gh-run(1)

الحزمة: github-cli

التراخيص: MIT

GH-RUN(1) دليل واجهة سطر أوامر GitHub GH-RUN(1)

الاسم

gh-run - عرض تفاصيل حول تشغيلات سير العمل

الموجز

gh run <command> [flags]

الوصف

قائمة، وعرض، ومراقبة تشغيلات سير العمل الأخيرة من GitHub Actions.

الأوامر المتاحة

gh-run-cancel(1)
إلغاء تشغيل سير العمل
gh-run-delete(1)
حذف تشغيل سير العمل
gh-run-download(1)
تنزيل القطع الأثرية الناتجة عن تشغيل سير العمل
gh-run-list(1)
قائمة تشغيلات سير العمل الأخيرة
gh-run-rerun(1)
إعادة تشغيل تشغيل
gh-run-view(1)
عرض ملخص لتشغيل سير العمل
gh-run-watch(1)
مراقبة تشغيل حتى اكتماله، وعرض تقدمه

خيارات

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.
