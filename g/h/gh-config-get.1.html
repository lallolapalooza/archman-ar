gh-config-get(1)

الحزمة: github-cli

التراخيص: MIT

GH-CONFIG-GET(1) دليل GitHub CLI GH-CONFIG-GET(1)

الاسم

gh-config-get - طباعة قيمة مفتاح تكوين معين

الملخص

gh config get <key> [flags]

الخيارات

-h, --host <string>
الحصول على إعداد خاص بالمضيف

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

مثال

$ gh config get git_protocol
