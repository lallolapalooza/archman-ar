gh-codespace-ports(1)

الحزمة: github-cli

التراخيص: MIT

GH-CODESPACE-PORTS(1) دليل سطر أوامر GitHub GH-CODESPACE-PORTS(1)

الاسم

gh-codespace-ports - سرد المنافذ في مساحة التعليمات البرمجية

ملخص

gh codespace ports [علامات]

الأوامر المتاحة

gh-codespace-ports-forward(1)
إعادة توجيه المنافذ
gh-codespace-ports-visibility(1)
تغيير رؤية المنفذ المعاد توجيهه

خيارات

-c, --codespace <سلسلة>
اسم مساحة التعليمات البرمجية
-q, --jq <تعبير>
تصفية مخرجات JSON باستخدام تعبير jq
--json <حقول>
إخراج JSON بالحقول المحددة
-R, --repo <سلسلة>
تصفية اختيار مساحة التعليمات البرمجية حسب اسم المستودع (مستخدم/مستودع)
--repo-owner <سلسلة>
تصفية اختيار مساحة التعليمات البرمجية حسب مالك المستودع (اسم مستخدم أو مؤسسة)
-t, --template <سلسلة>
تنسيق مخرجات JSON باستخدام قالب Go؛ راجع "gh help formatting"

حقول JSON

browseUrl، label، sourcePort، visibility

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى تعليمات الأمر للحصول على مزيد من المعلومات.
