gh-auth-switch(1)

الحزمة: github-cli

التراخيص: MIT

GH-AUTH-SWITCH(1) دليل GitHub CLI GH-AUTH-SWITCH(1)

الاسم

gh-auth-switch - تبديل الحساب النشط في GitHub

الملخص

gh auth switch [flags]

الوصف

تبديل الحساب النشط لمضيف GitHub.

يقوم هذا الأمر بتغيير إعدادات المصادقة التي سيتم استخدامها عند تشغيل الأوامر التي تستهدف مضيف GitHub المحدد.

إذا كان المضيف المحدد لديه حسابان، فسيتم تبديل الحساب النشط تلقائيًا. إذا كان هناك أكثر من حسابين، فستكون هناك حاجة إلى توضيح إما عبر الراية --user أو مطالبة تفاعلية.

للحصول على قائمة بالحسابات المصادق عليها، يمكنك تشغيل gh auth status.

خيارات

-h, --hostname <string>
اسم المضيف لمثيل GitHub لتبديل الحساب له
-u, --user <string>
الحساب للتبديل إليه

رموز الخروج

0: التنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# تحديد المضيف والحساب للتبديل إليهما عبر مطالبة
$ gh auth switch
# تبديل الحساب النشط على مضيف معين إلى مستخدم معين
$ gh auth switch --hostname enterprise.internal --user monalisa
