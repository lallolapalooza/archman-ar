gh-variable-set(1)

الحزمة: github-cli

التراخيص: MIT

GH-VARIABLE-SET(1) دليل سطر أوامر GitHub GH-VARIABLE-SET(1)

الاسم

gh-variable-set - إنشاء أو تحديث المتغيرات

الملخص

gh variable set <اسم-المتغير> [علامات]

الوصف

تعيين قيمة لمتغير على أحد المستويات التالية: - المستودع (الافتراضي): متاح لتشغيلات GitHub Actions أو Dependabot في مستودع - البيئة: متاح لتشغيلات GitHub Actions لبيئة نشر في مستودع - المؤسسة: متاح لتشغيلات GitHub Actions أو Dependabot داخل مؤسسة

يمكن تقييد متغير المؤسسة اختياريًا ليكون متاحًا فقط لمستودعات محددة.

الخيارات

-b, --body <سلسلة>
قيمة المتغير (يتم القراءة من المدخل القياسي إذا لم يتم تحديدها)
-e, --env <بيئة>
تعيين متغير بيئة النشر
-f, --env-file <ملف>
تحميل أسماء المتغيرات وقيمها من ملف بتنسيق dotenv
-o, --org <مؤسسة>
تعيين متغير المؤسسة
-r, --repos <مستودعات>
قائمة المستودعات التي يمكنها الوصول إلى متغير مؤسسة
-v, --visibility <سلسلة> (الافتراضي "private")
تعيين رؤية لمتغير مؤسسة: {all|private|selected}

الخيارات الموروثة من أوامر الأب

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# إضافة قيمة متغير للمستودع الحالي في مطالبة تفاعلية
$ gh variable set MYVARIABLE
# قراءة قيمة المتغير من متغير بيئة
$ gh variable set MYVARIABLE --body "$ENV_VALUE"
# قراءة قيمة المتغير من ملف
$ gh variable set MYVARIABLE < myfile.txt
# تعيين متغير لبيئة نشر في المستودع الحالي
$ gh variable set MYVARIABLE --env myenvironment
# تعيين متغير على مستوى المؤسسة مرئي لكل من المستودعات العامة والخاصة
$ gh variable set MYVARIABLE --org myOrg --visibility all
# تعيين متغير على مستوى المؤسسة مرئي لمستودعات محددة
$ gh variable set MYVARIABLE --org myOrg --repos repo1,repo2,repo3
# تعيين متغيرات متعددة مستوردة من ملف ".env"
$ gh variable set -f .env
