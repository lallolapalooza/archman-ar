gh-agent-task-view(1)

الحزمة: github-cli

التراخيص: MIT

GH-AGENT-TASK-VIEW(1) دليل واجهة سطر الأوامر لـ GitHub GH-AGENT-TASK-VIEW(1)

الاسم

gh-agent-task-view - عرض جلسة مهمة الوكيل (معاينة)

الملخص

gh agent-task view [<معرف-الجلسة> | <رقم-طلب-السحب> | <عنوان-URL-طلب-السحب> | <فرع-طلب-السحب>] [علامات]

الوصف

عرض جلسة مهمة الوكيل.

خيارات

--follow
متابعة سجلات جلسة الوكيل
--log
إظهار سجلات جلسة الوكيل
-R, --repo <[المضيف/]المالك/المستودع>
تحديد مستودع آخر باستخدام تنسيق [المضيف/]المالك/المستودع
-w, --web
فتح المهمة في المتصفح

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# عرض مهمة وكيل حسب معرف الجلسة
$ gh agent-task view e2fa49d2-f164-4a56-ab99-498090b8fcdf
# عرض مهمة وكيل حسب رقم طلب السحب في المستودع الحالي
$ gh agent-task view 12345
# عرض مهمة وكيل حسب رقم طلب السحب
$ gh agent-task view --repo OWNER/REPO 12345
# عرض مهمة وكيل حسب مرجع طلب السحب
$ gh agent-task view OWNER/REPO#12345
# عرض مهام وكيل لطلب سحب في المتصفح
$ gh agent-task view 12345 --web
