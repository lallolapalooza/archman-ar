gh-search-commits(1)

الحزمة: github-cli

التراخيص: MIT

GH-SEARCH-COMMITS(1) دليل واجهة سطر الأوامر GitHub GH-SEARCH-COMMITS(1)

الاسم

gh-search-commits - البحث عن التزامات (commits)

الملخص

gh search commits [<query>] [flags]

الوصف

البحث عن التزامات (commits) على GitHub.

تدعم الأوامر بناء استعلامات باستخدام صيغة بحث GitHub، باستخدام المعلمات وعلامات المؤهلات، أو مزيج من الاثنين.

صيغة بحث GitHub موثقة على:

⟨https://docs.github.com/search-github/searching-on-github/searching-commits⟩

لمزيد من المعلومات حول معالجة استعلامات البحث التي تحتوي على شرطة، قم بتشغيل gh search --help.

الخيارات

--author <string>
التصفية حسب المؤلف
--author-date <date>
التصفية بناءً على تاريخ التأليف
--author-email <string>
التصفية حسب البريد الإلكتروني للمؤلف
--author-name <string>
التصفية حسب اسم المؤلف
--committer <string>
التصفية حسب المُنفِّذ (committer)
--committer-date <date>
التصفية بناءً على تاريخ التنفيذ
--committer-email <string>
التصفية حسب البريد الإلكتروني للمُنفِّذ
--committer-name <string>
التصفية حسب اسم المُنفِّذ
--hash <string>
التصفية حسب هاش الالتزام (commit hash)
-q, --jq <expression>
تصفية مخرجات JSON باستخدام تعبير jq
--json <fields>
إخراج JSON بالحقول المحددة
-L, --limit <int> (الافتراضي 30)
الحد الأقصى لعدد الالتزامات (commits) التي سيتم جلبها
--merge
التصفية حسب التزامات الدمج (merge commits)
--order <string> (الافتراضي "desc")
ترتيب الالتزامات (commits) التي تم إرجاعها، يتم تجاهلها ما لم يتم تحديد علامة '--sort': {asc|desc}
--owner <strings>
التصفية حسب مالك المستودع
--parent <string>
التصفية حسب هاش الأب (parent hash)
-R, --repo <strings>
التصفية حسب المستودع
--sort <string> (الافتراضي "best-match")
فرز الالتزامات (commits) التي تم جلبها: {author-date|committer-date}
-t, --template <string>
تنسيق مخرجات JSON باستخدام قالب Go؛ انظر "gh help formatting"
--tree <string>
التصفية حسب هاش الشجرة (tree hash)
--visibility <strings>
التصفية بناءً على رؤية المستودع: {public|private|internal}
-w, --web
فتح استعلام البحث في المتصفح

حقول JSON

author, commit, committer, id, parents, repository, sha, url

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# البحث عن التزامات (commits) تطابق مجموعة الكلمات المفتاحية "readme" و "typo"
$ gh search commits readme typo
# البحث عن التزامات (commits) تطابق عبارة "bug fix"
$ gh search commits "bug fix"
# البحث عن التزامات (commits) تم تنفيذها بواسطة المستخدم "monalisa"
$ gh search commits --committer=monalisa
# البحث عن التزامات (commits) تم تأليفها بواسطة مستخدمين باسم "Jane Doe"
$ gh search commits --author-name="Jane Doe"
# البحث عن التزامات (commits) تطابق الهاش "8dd03144ffdc6c0d486d6b705f9c7fba871ee7c3"
$ gh search commits --hash=8dd03144ffdc6c0d486d6b705f9c7fba871ee7c3
# البحث عن التزامات (commits) تم تأليفها قبل 1 فبراير 2022
$ gh search commits --author-date="<2022-02-01"
