gh-auth-status(1)

الحزمة: github-cli

التراخيص: MIT

GH-AUTH-STATUS(1) دليل سطر أوامر GitHub GH-AUTH-STATUS(1)

الاسم

gh-auth-status - عرض الحساب النشط وحالة المصادقة على كل مضيف GitHub معروف

الملخص

gh auth status [علامات]

الوصف

عرض الحساب النشط وحالة المصادقة على كل مضيف GitHub معروف.

لكل مضيف، يتم اختبار حالة المصادقة لكل حساب معروف ويتم تضمين أي مشاكل في الإخراج. سيشير كل قسم مضيف إلى الحساب النشط، والذي سيتم استخدامه عند استهداف هذا المضيف.

إذا كان لدى حساب على أي مضيف (أو فقط المضاف عبر --hostname) مشاكل في المصادقة، فسوف يخرج الأمر برمز 1 ويخرج إلى stderr. لاحظ أنه عند استخدام خيار --json، سيخرج الأمر دائمًا بصفر بغض النظر عن أي مشاكل في المصادقة، ما لم يكن هناك خطأ فادح.

لتغيير الحساب النشط لمضيف، راجع gh auth switch.

خيارات

-a, --active
عرض الحساب النشط فقط
-h, --hostname <string>
التحقق فقط من حالة المصادقة لمضيف محدد
--jq <expression>
تصفية إخراج JSON باستخدام تعبير jq
--json <fields>
إخراج JSON مع الحقول المحددة
-t, --show-token
عرض رمز المصادقة
--template <string>
تنسيق إخراج JSON باستخدام قالب Go؛ انظر "gh help formatting"

حقول JSON

hosts

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# عرض حالة المصادقة لجميع الحسابات على جميع المضيفين
$ gh auth status
# عرض حالة المصادقة للحساب النشط على مضيف محدد
$ gh auth status --active --hostname github.example.com
# عرض الرموز بنص عادي
$ gh auth status --show-token
# تنسيق حالة المصادقة كـ JSON
$ gh auth status --json hosts
# تضمين رمز نصي عادي في إخراج JSON
$ gh auth status --json hosts --show-token
# تنسيق المضيفين كمصفوفة JSON مسطحة
$ gh auth status --json hosts --jq '.hosts | add'
