gh-project-edit(1)

الحزمة: github-cli

التراخيص: MIT

GH-PROJECT-EDIT(1) دليل سطر أوامر GitHub GH-PROJECT-EDIT(1)

الاسم

gh-project-edit - تعديل مشروع

الملخص

gh project edit [<رقم>] [علامات]

الخيارات

-d, --description <نص>
وصف جديد للمشروع
--format <نص>
تنسيق الإخراج: {json}
-q, --jq <تعبير>
تصفية إخراج JSON باستخدام تعبير jq
--owner <نص>
تسجيل الدخول للمالك. استخدم "@me" للمستخدم الحالي.
--readme <نص>
ملف README جديد للمشروع
-t, --template <نص>
تنسيق إخراج JSON باستخدام قالب Go؛ انظر "gh help formatting"
--title <نص>
عنوان جديد للمشروع
--visibility <نص>
تغيير رؤية المشروع: {PUBLIC|PRIVATE}

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# تعديل عنوان مشروع monalisa "1"
$ gh project edit 1 --owner monalisa --title "عنوان جديد"
