gh-pr-checkout(1)

الحزمة: github-cli

التراخيص: MIT

GH-PR-CHECKOUT(1) دليل GitHub CLI GH-PR-CHECKOUT(1)

الاسم

gh-pr-checkout - سحب طلب سحب في git

الملخص

gh pr checkout [<رقم> | <عنوان URL> | <فرع>] [أعلام]

خيارات

-b, --branch <نص>
اسم الفرع المحلي المراد استخدامه (الافتراضي: [اسم فرع الرأس])
--detach
سحب طلب السحب مع رأس منفصل
-f, --force
إعادة تعيين الفرع المحلي الحالي إلى أحدث حالة لطلب السحب
--recurse-submodules
تحديث جميع الوحدات الفرعية بعد السحب

خيارات موروثة من الأوامر الأصل

-R, --repo <[المضيف/]المالك/المستودع>
تحديد مستودع آخر باستخدام تنسيق [المضيف/]المالك/المستودع

أسماء مستعارة

gh pr co

رموز الخروج

0: التنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# اختر طلب سحب بشكل تفاعلي من بين آخر 10 لتم إغلاقها
$ gh pr checkout
# اسحب طلب سحب محدد
$ gh pr checkout 32
$ gh pr checkout https://github.com/OWNER/REPO/pull/32
$ gh pr checkout feature
