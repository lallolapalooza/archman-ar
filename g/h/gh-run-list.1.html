gh-run-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-RUN-LIST(1) دليل سطر أوامر GitHub GH-RUN-LIST(1)

الاسم

gh-run-list - سرد عمليات سير العمل الحديثة

الملخص

gh run list [علامات]

الوصف

سرد عمليات سير العمل الحديثة.

لاحظ أن توفير اسم سير العمل إلى العلامة -w لن يجلب سير العمل المعطل. قم أيضًا بتمرير العلامة -a لجلب عمليات سير العمل المعطلة باستخدام اسم سير العمل والعلامة -w.

لن تعرض العمليات التي تم إنشاؤها بواسطة سير عمل قواعد المؤسسة والمنظمة اسم سير عمل بسبب قيود واجهة برمجة تطبيقات GitHub.

لرؤية العمليات المرتبطة بطلب سحب، يجب على المستخدمين تشغيل gh pr checks.

الخيارات

-a, --all
تضمين سير العمل المعطل
-b, --branch <string>
تصفية العمليات حسب الفرع
-c, --commit <SHA>
تصفية العمليات حسب SHA الالتزام
--created <date>
تصفية العمليات حسب تاريخ إنشائها
-e, --event <event>
تصفية العمليات حسب الحدث الذي أطلق العملية
-q, --jq <expression>
تصفية مخرجات JSON باستخدام تعبير jq
--json <fields>
إخراج JSON مع الحقول المحددة
-L, --limit <int> (الافتراضي 20)
الحد الأقصى لعدد العمليات المراد جلبها
-s, --status <string>
تصفية العمليات حسب الحالة: {queued|completed|in_progress|requested|waiting|pending|action_required|cancelled|failure|neutral|skipped|stale|startup_failure|success|timed_out}
-t, --template <string>
تنسيق مخرجات JSON باستخدام قالب Go؛ انظر "gh help formatting"
-u, --user <string>
تصفية العمليات حسب المستخدم الذي أطلق العملية
-w, --workflow <string>
تصفية العمليات حسب سير العمل

الخيارات الموروثة من الأوامر الأصلية

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

أسماء مستعارة

gh run ls

حقول JSON

attempt, conclusion, createdAt, databaseId, displayTitle, event, headBranch, headSha, name, number, startedAt, status, updatedAt, url, workflowDatabaseId, workflowName

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.
