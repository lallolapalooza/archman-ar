gh-run-watch(1)

الحزمة: github-cli

التراخيص: MIT

GH-RUN-WATCH(1) دليل سطر أوامر GitHub GH-RUN-WATCH(1)

الاسم

gh-run watch - مراقبة تشغيل حتى يكتمل، وعرض تقدمه

موجز

gh run watch <run-id> [flags]

الوصف

مراقبة تشغيل حتى يكتمل، وعرض تقدمه.

افتراضيًا، يتم عرض جميع الخطوات. يمكن استخدام الخيار --compact لعرض الخطوات ذات الصلة / الفاشلة فقط.

هذا الأمر لا يدعم المصادقة عبر PATs دقيقة الحجم نظرًا لأنه لا يمكن حاليًا إنشاء PAT بإذن checks:read.

خيارات

--compact
عرض الخطوات ذات الصلة / الفاشلة فقط
--exit-status
الخروج بحالة غير صفرية إذا فشل التشغيل
-i, --interval <int> (الافتراضي 3)
فاصل التحديث بالثواني

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# مراقبة التشغيل حتى ينتهي
$ gh run watch
# مراقبة التشغيل في وضع مدمج
$ gh run watch --compact
# تشغيل أمر آخر عند انتهاء التشغيل
$ gh run watch && notify-send 'run is done!'
