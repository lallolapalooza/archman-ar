الحزمة: github-cli

GH-PREVIEW-PROMPTER(1) دليل واجهة سطر أوامر GitHub GH-PREVIEW-PROMPTER(1)

الاسم

gh-preview-prompter - تنفيذ برنامج اختبار لمعاينة الموجه

ملخص

gh preview prompter [نوع الموجه] [خيارات]

الوصف

تنفيذ برنامج اختبار لمعاينة الموجه. بدون وسيط، سيتم تشغيل جميع الموجهات.

أنواع الموجهات المتاحة: - select - multi-select - input - password - confirm - auth-token - confirm-deletion - input-hostname - markdown-editor

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. راجع مساعدة الأمر للحصول على مزيد من المعلومات.
