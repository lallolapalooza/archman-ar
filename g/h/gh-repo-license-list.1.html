gh-repo-license-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-REPO-LICENSE-LIST(1) دليل GitHub CLI GH-REPO-LICENSE-LIST(1)

الاسم

gh-repo-license-list - سرد تراخيص المستودعات الشائعة

الملخص

gh repo license list [flags]

الوصف

سرد تراخيص المستودعات الشائعة.

لمزيد من التراخيص، قم بزيارة ⟨https://choosealicense.com/appendix⟩

أسماء مستعارة

gh repo license ls

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.
