gh-cache-delete(1)

الحزمة: github-cli

التراخيص: MIT

GH-CACHE-DELETE(1) دليل واجهة سطر أوامر GitHub GH-CACHE-DELETE(1)

الاسم

gh-cache-delete - حذف ذاكرة التخزين المؤقت لـ GitHub Actions

الملخص

gh cache delete [<cache-id> | <cache-key> | --all] [flags]

الوصف

حذف ذاكرة التخزين المؤقت لـ GitHub Actions.

يتطلب الحذف التفويض بنطاق repo.

الخيارات

-a, --all
حذف كل ذاكرات التخزين المؤقت
-r, --ref <string>
الحذف حسب مفتاح ذاكرة التخزين المؤقت والمرجع، بتنسيق refs/heads/ أو refs/pull//merge
--succeed-on-no-caches <--all>
إرجاع رمز الخروج 0 إذا لم يتم العثور على ذاكرات تخزين مؤقت. يجب استخدامه بالاقتران مع --all

الخيارات الموروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب مصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

مثال

# حذف ذاكرة تخزين مؤقت بواسطة المعرف
$ gh cache delete 1234
# حذف ذاكرة تخزين مؤقت بواسطة المفتاح
$ gh cache delete cache-key
# حذف ذاكرة تخزين مؤقت بواسطة المعرف في مستودع معين
$ gh cache delete 1234 --repo cli/cli
# حذف ذاكرة تخزين مؤقت بواسطة المفتاح وفرع المرجع
$ gh cache delete cache-key --ref refs/heads/feature-branch
# حذف ذاكرة تخزين مؤقت بواسطة المفتاح ومرجع PR
$ gh cache delete cache-key --ref refs/pull/<PR-number>/merge
# حذف كل ذاكرات التخزين المؤقت (رمز الخروج 1 عند عدم وجود ذاكرات تخزين مؤقت)
$ gh cache delete --all
# حذف كل ذاكرات التخزين المؤقت (رمز الخروج 0 عند عدم وجود ذاكرات تخزين مؤقت)
$ gh cache delete --all --succeed-on-no-caches
