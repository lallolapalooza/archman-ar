gh-pr-view(1)

الحزمة: github-cli

التراخيص: MIT

GH-PR-VIEW(1) دليل سطر أوامر GitHub GH-PR-VIEW(1)

الاسم

gh-pr-view - عرض طلب سحب

الملخص

gh pr view [<رقم> | <رابط> | <فرع>] [علامات]

الوصف

عرض العنوان، الجسم، ومعلومات أخرى حول طلب سحب.

بدون وسيط، يتم عرض طلب السحب الذي ينتمي إلى الفرع الحالي.

مع العلامة --web، يتم فتح طلب السحب في متصفح الويب بدلاً من ذلك.

الخيارات

-c, --comments
عرض تعليقات طلب السحب
-q, --jq <تعبير>
تصفية مخرجات JSON باستخدام تعبير jq
--json <حقول>
إخراج JSON بالحقول المحددة
-t, --template <سلسلة>
تنسيق مخرجات JSON باستخدام قالب Go؛ راجع "gh help formatting"
-w, --web
فتح طلب سحب في المتصفح

الخيارات الموروثة من الأوامر الأصلية

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

حقول JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, state, statusCheckRollup, title, updatedAt, url

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.
