GH-RUN-CANCEL(1) دليل GitHub CLI GH-RUN-CANCEL(1)

الاسم

gh-run-cancel - إلغاء تشغيل سير عمل

نظرة عامة

gh run cancel [<run-id>] [flags]

خيارات

--force
فرض إلغاء تشغيل سير عمل

خيارات موروثة من الأوامر الأب

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.
