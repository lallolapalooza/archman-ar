gh-pr-comment(1)

الحزمة: github-cli

التراخيص: MIT

GH-PR-COMMENT(1) دليل سطر أوامر GitHub GH-PR-COMMENT(1)

الاسم

gh-pr-comment - إضافة تعليق إلى طلب سحب

الملخص

gh pr comment [<number> | <url> | <branch>] [flags]

الوصف

أضف تعليقًا إلى طلب سحب GitHub.

بدون نص الجسم المقدم عبر العلامات، سيطالب الأمر بشكل تفاعلي بنص التعليق.

الخيارات

-b, --body <text>
نص جسم التعليق
-F, --body-file <file>
قراءة نص الجسم من ملف (استخدم "-" للقراءة من الإدخال القياسي)
--create-if-none
إنشاء تعليق جديد إذا لم يتم العثور على أي تعليقات. يمكن استخدامه مع --edit-last فقط
--delete-last
حذف آخر تعليق للمستخدم الحالي
--edit-last
تعديل آخر تعليق للمستخدم الحالي
-e, --editor
تخطي المطالبات وفتح محرر النصوص لكتابة الجسم فيه
-w, --web
فتح متصفح الويب لكتابة التعليق
--yes
تخطي موجه تأكيد الحذف عند توفير --delete-last

الخيارات الموروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

$ gh pr comment 13 --body "Hi from GitHub CLI"
