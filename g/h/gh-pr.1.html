gh-pr(1)

الحزمة: github-cli

التراخيص: MIT

GH-PR(1) دليل GitHub CLI GH-PR(1)

الاسم

gh-pr - إدارة طلبات السحب (pull requests)

الاستخدام

gh pr <command> [flags]

الوصف

العمل مع طلبات السحب (pull requests) على GitHub.

الأوامر العامة

gh-pr-create(1)
إنشاء طلب سحب
gh-pr-list(1)
قائمة طلبات السحب في المستودع
gh-pr-status(1)
عرض حالة طلبات السحب ذات الصلة

الأوامر المستهدفة

gh-pr-checkout(1)
استخراج طلب سحب في git
gh-pr-checks(1)
عرض حالة CI لطلب سحب واحد
gh-pr-close(1)
إغلاق طلب سحب
gh-pr-comment(1)
إضافة تعليق إلى طلب سحب
gh-pr-diff(1)
عرض التغييرات في طلب سحب
gh-pr-edit(1)
تعديل طلب سحب
gh-pr-lock(1)
قفل محادثة طلب السحب
gh-pr-merge(1)
دمج طلب سحب
gh-pr-ready(1)
تحديد طلب سحب كجاهز للمراجعة
gh-pr-reopen(1)
إعادة فتح طلب سحب
gh-pr-revert(1)
التراجع عن طلب سحب
gh-pr-review(1)
إضافة مراجعة لطلب سحب
gh-pr-unlock(1)
فتح قفل محادثة طلب السحب
gh-pr-update-branch(1)
تحديث فرع طلب السحب
gh-pr-view(1)
عرض طلب سحب

الخيارات

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى تعليمات الأمر للحصول على مزيد من المعلومات.

مثال

$ gh pr checkout 353
$ gh pr create --fill
$ gh pr view --web
