gh-project-field-create(1)

الحزمة: github-cli

التراخيص: MIT

GH-PROJECT-FIELD-CREATE(1) دليل سطر أوامر GitHub GH-PROJECT-FIELD-CREATE(1)

الاسم

gh-project-field-create - إنشاء حقل في مشروع

ملخص

gh project field-create [<number>] [flags]

خيارات

--data-type <string>
نوع بيانات الحقل الجديد.: {TEXT|SINGLE_SELECT|DATE|NUMBER}
--format <string>
تنسيق الإخراج: {json}
-q, --jq <expression>
تصفية إخراج JSON باستخدام تعبير jq
--name <string>
اسم الحقل الجديد
--owner <string>
اسم المستخدم للمالك. استخدم "@me" للمستخدم الحالي.
--single-select-options <strings>
خيارات لنوع بيانات SINGLE_SELECT
-t, --template <string>
تنسيق إخراج JSON باستخدام قالب Go؛ انظر "gh help formatting"

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# إنشاء حقل في المشروع "1" للمستخدم الحالي
$ gh project field-create 1 --owner "@me" --name "new field" --data-type "text"
# إنشاء حقل بثلاثة خيارات للاختيار منها للمالك monalisa
$ gh project field-create 1 --owner monalisa --name "new field" --data-type "SINGLE_SELECT" --single-select-options "one,two,three"
