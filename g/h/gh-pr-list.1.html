gh-pr-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-PR-LIST(1) دليل GitHub CLI GH-PR-LIST(1)

الاسم

gh-pr-list - سرد طلبات السحب في مستودع

الملخص

gh pr list [flags]

الوصف

سرد طلبات السحب في مستودع GitHub. افتراضيًا، يسرد هذا طلبات السحب المفتوحة فقط.

بناء جملة استعلام البحث موثق هنا:

⟨https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests⟩

على مضيفات GitHub المدعومة، يمكن استخدام بناء جملة البحث المتقدم عن المشكلات في استعلام --search. لمزيد من المعلومات حول البحث المتقدم عن المشكلات، انظر:

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues⟩

الخيارات

--app <string>
التصفية حسب مؤلف تطبيق GitHub
-a, --assignee <string>
التصفية حسب المسؤول
-A, --author <string>
التصفية حسب المؤلف
-B, --base <string>
التصفية حسب الفرع الأساسي
-d, --draft
التصفية حسب حالة المسودة
-H, --head <string>
التصفية حسب الفرع الرأس (صيغة ":" غير مدعومة)
-q, --jq <expression>
تصفية مخرجات JSON باستخدام تعبير jq
--json <fields>
إخراج JSON بالحقول المحددة
-l, --label <strings>
التصفية حسب العلامة
-L, --limit <int> (الافتراضي 30)
الحد الأقصى لعدد العناصر التي سيتم جلبها
-S, --search <query>
البحث عن طلبات السحب باستخدام استعلام
-s, --state <string> (الافتراضي "open")
التصفية حسب الحالة: {open|closed|merged|all}
-t, --template <string>
تنسيق مخرجات JSON باستخدام قالب Go؛ انظر "gh help formatting"
-w, --web
سرد طلبات السحب في متصفح الويب

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام صيغة [HOST/]OWNER/REPO

أسماء مستعارة

gh pr ls

حقول JSON

additions, assignees, author, autoMergeRequest, baseRefName, baseRefOid, body, changedFiles, closed, closedAt, closingIssuesReferences, comments, commits, createdAt, deletions, files, fullDatabaseId, headRefName, headRefOid, headRepository, headRepositoryOwner, id, isCrossRepository, isDraft, labels, latestReviews, maintainerCanModify, mergeCommit, mergeStateStatus, mergeable, mergedAt, mergedBy, milestone, number, potentialMergeCommit, projectCards, projectItems, reactionGroups, reviewDecision, reviewRequests, reviews, state, statusCheckRollup, title, updatedAt, url

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# سرد طلبات السحب التي كتبتها
$ gh pr list --author "@me"
# سرد طلبات السحب ذات اسم فرع رأس محدد
$ gh pr list --head "typo"
# سرد طلبات السحب التي تحمل جميع العلامات المعطاة فقط
$ gh pr list --label bug --label "priority 1"
# تصفية طلبات السحب باستخدام بناء الجملة للبحث
$ gh pr list --search "status:success review:required"
# البحث عن طلب سحب قدم التزامًا معينًا
$ gh pr list --search "<SHA>" --state merged
