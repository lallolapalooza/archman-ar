gh-alias-set(1)

الحزمة: github-cli

التراخيص: MIT

GH-ALIAS-SET(1) دليل GitHub CLI GH-ALIAS-SET(1)

الاسم

gh-alias-set - إنشاء اختصار لأمر gh

الملخص

gh alias set <alias> <expansion> [flags]

الوصف

تعريف كلمة سيتم توسيعها إلى أمر gh كامل عند استدعائها.

قد يحدد التوسيع وسيطات وعلامات إضافية. إذا كان التوسيع يتضمن عناصر نائبة للمواضع مثل $1، فسيتم إدراج الوسيطات الإضافية التي تتبع الاسم المستعار في مكانها المناسب. بخلاف ذلك، سيتم إلحاق الوسيطات الإضافية بالأمر الموسع.

استخدم - كوسيط للتوسيع لقراءة سلسلة التوسيع من المدخلات القياسية. هذا مفيد لتجنب مشاكل الاقتباس عند تعريف التوسيعات.

إذا بدأ التوسيع بـ ! أو إذا تم تقديم --shell، فإن التوسيع هو تعبير شل سيتم تقييمه من خلال مترجم sh عند استدعاء الاسم المستعار. هذا يسمح بربط أوامر متعددة عبر الأنابيب وإعادة التوجيه.

خيارات

--clobber
الكتابة فوق الأسماء المستعارة الموجودة بنفس الاسم
-s, --shell
الإعلان عن اسم مستعار سيتم تمريره عبر مترجم شل

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

مثال

# ملاحظة: يتطلب موجه الأوامر على Windows استخدام علامات اقتباس مزدوجة للوسيطات
$ gh alias set pv 'pr view'
$ gh pv -w 123  #=> gh pr view -w 123
$ gh alias set bugs 'issue list --label=bugs'
$ gh bugs
$ gh alias set homework 'issue list --assignee @me'
$ gh homework
$ gh alias set 'issue mine' 'issue list --mention @me'
$ gh issue mine
$ gh alias set epicsBy 'issue list --author="$1" --label="epic"'
$ gh epicsBy vilmibm  #=> gh issue list --author="vilmibm" --label="epic"
$ gh alias set --shell igrep 'gh issue list --label="$1" | grep "$2"'
$ gh igrep epic foo  #=> gh issue list --label="epic" | grep "foo"
