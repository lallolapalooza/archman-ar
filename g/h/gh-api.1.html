الحزمة: github-cli

التراخيص: MIT

NAME

gh api - Send a request to the GitHub API

SYNOPSIS

gh api <request> [<request>...]

DESCRIPTION

Send a request to the GitHub API. The request consists of an HTTP method, a path, and optional request parameters.

The first argument is the HTTP method (GET, POST, PATCH, PUT, DELETE).

The second argument is the API path. It can be a REST API path (e.g. /repos/OWNER/REPO/issues) or a GraphQL query. When using GraphQL, the request can be provided as a string or a file path prefixed with @.

Optional arguments can be used to provide request parameters. Parameters can be specified as key=value pairs or as JSON. When specified as JSON, the value must be a file path prefixed with @.

See also gh(1) for global options available to all commands.

OPTIONS

The following options are available:

-X, --method <METHOD>
HTTP method to use. For example: GET, POST, PATCH, PUT, DELETE.
-H, --header <String>
Pass HTTP headers. For example: -H 'Accept: application/vnd.github.v3+json'
-f, --field <String>
Pass request parameters as key=value pairs. For example: -f title='My Issue Title' -f body='My issue body'
-F, --fields <String>
Pass request parameters as JSON. The value must be a file path prefixed with @. For example: -F data=@data.json
-q, --jq <filter>
Process the API response using jq filter. For example: --jq '.[] | select(.isFork) | .name'
-R, --repo <String>
Switch repository on the fly. OWNER/REPO or REPO

EXIT CODES

Exits with 0 if the API request was successful, and non-zero otherwise.

EXAMPLE

# List all repositories for the authenticated user
gh api user/repos

# Get information about a specific repository
gh api repos/OWNER/REPO

# Create a new issue for a repository
gh api -X POST OWNER/REPO/issues -f title='My new issue' -f body='This is the body of the issue.'

# List all forks of a repository and process the response using jq
gh api repos/OWNER/REPO/forks --jq '.[] | select(.isFork) | .name'

# Example using GraphQL to get the number of forks for a repository
gh api graphql -f query='
  query($owner: String!, $repo: String!) {
    repository(owner: $owner, name: $repo) {
      forks(first: 1) {
        totalCount
      }
    }
  }
' -f owner=OWNER -f repo=REPO --jq '.data.repository.forks.totalCount'

# Using a GraphQL query from a file
gh api graphql -f query='@query.graphql'

# Get the content of a file in a repository
gh api repos/OWNER/REPO/contents/README.md

# Post JSON data to the API
echo '{"name": "new-repo", "description": "A new repository"}' > repo.json
gh api -X POST /user/repos -f repo.json

# Calculate the percentage of forks for a repository
gh api repos/OWNER/REPO/forks --jq 'length' | xargs -I {} echo {}
gh api repos/OWNER/REPO/forks --jq '.[] | select($r[].isFork)/count($r[])'
