gh-ssh-key-add(1)

الحزمة: github-cli

التراخيص: MIT

GH-SSH-KEY-ADD(1) دليل GitHub CLI GH-SSH-KEY-ADD(1)

الاسم

gh-ssh-key-add - إضافة مفتاح SSH إلى حساب GitHub الخاص بك

الملخص

gh ssh-key add [<key-file>] [flags]

الخيارات

-t, --title <string>
عنوان للمفتاح الجديد
--type <string> (الافتراضي "authentication")
نوع مفتاح SSH: {authentication|signing}

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.
