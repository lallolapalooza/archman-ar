gh-repo-autolink(1)

الحزمة: github-cli

التراخيص: MIT

GH-REPO-AUTOLINK(1) دليل سطر أوامر GitHub GH-REPO-AUTOLINK(1)

الاسم

gh-repo-autolink - إدارة روابط الارتباط التلقائي

ملخص

gh repo autolink <command> [flags]

الوصف

تربط روابط الارتباط التلقائي المشكلات، طلبات السحب، رسائل الالتزام، ووصف الإصدارات بخدمات خارجية تابعة لجهات خارجية.

تتطلب روابط الارتباط التلقائي دور المسؤول لعرضها أو إدارتها.

لمزيد من المعلومات، راجع ⟨https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/managing-repository-settings/configuring-autolinks-to-reference-external-resources⟩

الأوامر المتاحة

gh-repo-autolink-create(1)
إنشاء مرجع ارتباط تلقائي جديد
gh-repo-autolink-delete(1)
حذف مرجع ارتباط تلقائي
gh-repo-autolink-list(1)
قائمة مراجع الارتباط التلقائي لمستودع GitHub
gh-repo-autolink-view(1)
عرض مرجع ارتباط تلقائي

خيارات

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.
