الحزمة: github-cli

التراخيص: MIT

GH-ISSUE-EDIT(1) دليل GitHub CLI GH-ISSUE-EDIT(1)

الاسم

gh-issue-edit - تعديل المشكلات

الملخص

gh issue edit {<أرقام> | <عناوين URL>} [علامات]

الوصف

تعديل مشكلة واحدة أو أكثر داخل نفس المستودع.

يتطلب تعديل مشروعات المشكلات تفويضًا بنطاق project. للتفويض، قم بتشغيل gh auth refresh -s project.

تدعم العلامات --add-assignee و --remove-assignee كلاهما القيم الخاصة التالية: - @me: تعيين أو إلغاء تعيين نفسك - @copilot: تعيين أو إلغاء تعيين Copilot (غير مدعوم على GitHub Enterprise Server)

خيارات

--add-assignee <login>
إضافة مستخدمين معينين عن طريق تسجيل الدخول الخاص بهم. استخدم "@me" لتعيين نفسك، أو "@copilot" لتعيين Copilot.
--add-label <name>
إضافة علامات بالاسم.
--add-project <title>
إضافة المشكلة إلى المشروعات بالاسم.
-b, --body <string>
تعيين نص جديد.
-F, --body-file <file>
قراءة نص النص من ملف (استخدم "-" للقراءة من الإدخال القياسي).
-m, --milestone <name>
تعديل المعلم الذي تنتمي إليه المشكلة بالاسم.
--remove-assignee <login>
إزالة المستخدمين المعينين عن طريق تسجيل الدخول الخاص بهم. استخدم "@me" لإلغاء تعيين نفسك، أو "@copilot" لإلغاء تعيين Copilot.
--remove-label <name>
إزالة علامات بالاسم.
--remove-milestone
إزالة الارتباط بالمعلم من المشكلة.
--remove-project <title>
إزالة المشكلة من المشروعات بالاسم.
-t, --title <string>
تعيين عنوان جديد.

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO.

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

$ gh issue edit 23 --title "I found a bug" --body "Nothing works"
$ gh issue edit 23 --add-label "bug,help wanted" --remove-label "core"
$ gh issue edit 23 --add-assignee "@me" --remove-assignee monalisa,hubot
$ gh issue edit 23 --add-assignee "@copilot"
$ gh issue edit 23 --add-project "Roadmap" --remove-project v1,v2
$ gh issue edit 23 --milestone "Version 1"
$ gh issue edit 23 --remove-milestone
$ gh issue edit 23 --body-file body.txt
$ gh issue edit 23 34 --add-label "help wanted"
