gh-repo-deploy-key(1)

الحزمة: github-cli

التراخيص: MIT

GH-REPO-DEPLOY-KEY(1) دليل GitHub CLI GH-REPO-DEPLOY-KEY(1)

الاسم

gh-repo-deploy-key - إدارة مفاتيح النشر في مستودع

الملخص

gh repo deploy-key <command> [flags]

الأوامر المتاحة

gh-repo-deploy-key-add(1)
إضافة مفتاح نشر إلى مستودع GitHub
gh-repo-deploy-key-delete(1)
حذف مفتاح نشر من مستودع GitHub
gh-repo-deploy-key-list(1)
قائمة مفاتيح النشر في مستودع GitHub

خيارات

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: التنفيذ الناجح

1: خطأ

2: تم إلغاء الأمر

4: يتطلب المصادقة

ملاحظة: قد تحتوي الأوامر المحددة على رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.
