gh-auth-setup-git(1)

الحزمة: github-cli

التراخيص: MIT

GH-AUTH-SETUP-GIT(1) دليل GitHub CLI GH-AUTH-SETUP-GIT(1)

الاسم

gh-auth-setup-git - إعداد git مع GitHub CLI

الملخص

gh auth setup-git [علامات]

الوصف

يقوم هذا الأمر بتكوين git لاستخدام GitHub CLI كمساعد للمصادقة. لمزيد من المعلومات حول مساعدي المصادقة في git، يرجى الرجوع إلى:

⟨https://git-scm.com/docs/gitcredentials⟩.

افتراضيًا، سيتم تعيين GitHub CLI كمساعد للمصادقة لجميع المضيفين المصادق عليهم. إذا لم يكن هناك مضيفون مصادق عليهم، يفشل الأمر بخطأ.

بدلاً من ذلك، استخدم علامة --hostname لتحديد مضيف واحد ليتم تكوينه. إذا لم يتم المصادقة على المضيف، يفشل الأمر بخطأ.

خيارات

-f, --force <--hostname>
فرض الإعداد حتى لو كان المضيف غير معروف. يجب استخدامه بالاقتران مع --hostname
-h, --hostname <string>
اسم المضيف لتكوين git له

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# تكوين git لاستخدام GitHub CLI كمساعد للمصادقة لجميع المضيفين المصادق عليهم
$ gh auth setup-git
# تكوين git لاستخدام GitHub CLI كمساعد للمصادقة لمضيف enterprise.internal
$ gh auth setup-git --hostname enterprise.internal
