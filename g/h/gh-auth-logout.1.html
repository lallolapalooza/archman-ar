gh-auth-logout(1)

الحزمة: github-cli

التراخيص: MIT

GH-AUTH-LOGOUT(1) دليل GitHub CLI GH-AUTH-LOGOUT(1)

الاسم

gh-auth-logout - تسجيل الخروج من حساب GitHub

الملخص

gh auth logout [flags]

الوصف

إزالة المصادقة لحساب GitHub.

يقوم هذا الأمر بإزالة تكوين المصادقة المخزن لحساب. يتم إزالة تكوين المصادقة محليًا فقط.

هذا الأمر لا يقوم بإلغاء رموز المصادقة.

لإلغاء جميع رموز المصادقة التي تم إنشاؤها بواسطة GitHub CLI:

1.
قم بزيارة ⟨https://github.com/settings/applications⟩
2.
حدد تطبيق "GitHub CLI"
3.
حدد "Revoke Access"
4.
حدد "I understand, revoke access"

ملاحظة: سيقوم هذا الإجراء بإلغاء جميع رموز المصادقة التي تم إنشاؤها على الإطلاق بواسطة GitHub CLI عبر جميع أجهزتك.

لمزيد من المعلومات حول إلغاء رموز تطبيقات OAuth، انظر:

⟨https://docs.github.com/en/apps/oauth-apps/using-oauth-apps/reviewing-your-authorized-oauth-apps⟩

الخيارات

-h, --hostname <string>
اسم المضيف لمثيل GitHub لتسجيل الخروج منه
-u, --user <string>
الحساب المراد تسجيل الخروج منه

رموز الخروج

0: التنفيذ الناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# حدد المضيف والحساب المراد تسجيل الخروج منهما عبر موجه
$ gh auth logout
# تسجيل الخروج من مضيف محدد وحساب محدد
$ gh auth logout --hostname enterprise.internal --user monalisa
