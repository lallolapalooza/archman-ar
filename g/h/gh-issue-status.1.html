gh-issue-status(1)

الحزمة: github-cli

التراخيص: MIT

GH-ISSUE-STATUS(1) دليل سطر أوامر GitHub GH-ISSUE-STATUS(1)

الاسم

gh-issue-status - عرض حالة المشكلات ذات الصلة

الملخص

gh issue status [علامات]

خيارات

-q, --jq <تعبير>
تصفية إخراج JSON باستخدام تعبير jq
--json <حقول>
إخراج JSON بالحقول المحددة
-t, --template <سلسلة>
تنسيق إخراج JSON باستخدام قالب Go؛ انظر "gh help formatting"

خيارات موروثة من الأوامر الأصل

-R, --repo <[المضيف/]المالك/المستودع>
تحديد مستودع آخر باستخدام تنسيق [المضيف/]المالك/المستودع

حقول JSON

assignees، author، body، closed، closedAt، closedByPullRequestsReferences، comments، createdAt، id، isPinned، labels، milestone، number، projectCards، projectItems، reactionGroups، state، stateReason، title، updatedAt، url

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

انظر أيضاً
