gh-repo-license-view(1)

الحزمة: github-cli

التراخيص: MIT

GH-REPO-LICENSE-VIEW(1) دليل GitHub CLI GH-REPO-LICENSE-VIEW(1)

الاسم

gh-repo-license-view - عرض ترخيص مستودع معين

ملخص

gh repo license view {<مفتاح-الترخيص> | <معرف-spdx>} [علامات]

الوصف

عرض ترخيص مستودع معين بواسطة مفتاح الترخيص أو معرف SPDX.

قم بتشغيل gh repo license list لرؤية التراخيص الشائعة المتاحة. لمزيد من التراخيص، قم بزيارة ⟨https://choosealicense.com/appendix⟩.

خيارات

-w, --web
فتح https://choosealicense.com/ في المتصفح

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# عرض ترخيص MIT من معرف SPDX
$ gh repo license view MIT
# عرض ترخيص MIT من مفتاح الترخيص
$ gh repo license view mit
# عرض ترخيص GNU AGPL-3.0 من معرف SPDX
$ gh repo license view AGPL-3.0
# عرض ترخيص GNU AGPL-3.0 من مفتاح الترخيص
$ gh repo license view agpl-3.0
# إنشاء LICENSE.md بترخيص MIT
$ gh repo license view MIT > LICENSE.md
