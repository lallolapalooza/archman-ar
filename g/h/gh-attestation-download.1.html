gh-attestation-download(1)

الحزمة: github-cli

التراخيص: MIT

GH-ATTESTATION-DOWNLOAD(1) دليل سطر أوامر GitHub GH-ATTESTATION-DOWNLOAD(1)

الاسم

gh-attestation-download - تنزيل شهادات المصنفات لاستخدامها في وضع عدم الاتصال

الملخص

gh attestation download [<مسار-الملف> | oci://<عنوان-الصورة>] [--owner | --repo] [flags]

الوصف

ملاحظة: هذه الميزة حاليًا في معاينة عامة، وهي عرضة للتغيير.

تنزيل الشهادات المرتبطة بمصنف للاستخدام في وضع عدم الاتصال.

يتطلب الأمر إما: * مسار ملف لمصنف، أو * عنوان URI لصورة حاوية (مثل oci://<عنوان-الصورة>)
* (لاحظ أنه إذا قدمت عنوان OCI، يجب أن تكون مصادقًا بالفعل مع سجل الحاوية الخاص بها)

بالإضافة إلى ذلك، يتطلب الأمر إما: * العلم --repo (مثل --repo github/example). * العلم --owner (مثل --owner github)، أو

يجب أن تتطابق قيمة العلم --repo مع اسم مستودع GitHub الذي يرتبط به المصنف.

يجب أن تتطابق قيمة العلم --owner مع اسم مؤسسة GitHub التي ينتمي إليها المستودع المرتبط بالمصنف.

سيتم كتابة أي حزم مجمعة مرتبطة إلى ملف في الدليل الحالي يحمل اسم هضم المصنف. على سبيل المثال، إذا كان الهضم هو "sha256:1234"، فسيكون اسم الملف "sha256:1234.jsonl".

الأقواس هي أحرف خاصة في نظام Windows ولا يمكن استخدامها في أسماء الملفات. لاستيعاب ذلك، سيتم استخدام شرطة للفصل بين الخوارزمية والهضم في اسم ملف الشهادات. على سبيل المثال، إذا كان الهضم هو "sha256:1234"، فسيكون اسم الملف "sha256-1234.jsonl".

الخيارات

-d, --digest-alg <string> (الافتراضي "sha256")
الخوارزمية المستخدمة لحساب هضم المصنف: {sha256|sha512}
--hostname <string>
تكوين المضيف للاستخدام
-L, --limit <int> (الافتراضي 30)
الحد الأقصى لعدد الشهادات التي سيتم جلبها
-o, --owner <string>
مؤسسة GitHub لتحديد نطاق البحث عن الشهادات حسب
--predicate-type <string>
تصفية الشهادات حسب نوع المتنبئ المقدم
-R, --repo <string>
اسم المستودع بالتنسيق /

رموز الخروج

0: التنفيذ الناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر للحصول على مزيد من المعلومات.

مثال

# تنزيل الشهادات لمصنف محلي مرتبط بمؤسسة
$ gh attestation download example.bin -o github
# تنزيل الشهادات لمصنف محلي مرتبط بمستودع
$ gh attestation download example.bin -R github/example
# تنزيل الشهادات لصورة OCI مرتبطة بمؤسسة
$ gh attestation download oci://example.com/foo/bar:latest -o github
