gh-cache-list(1)

الحزمة: github-cli

التراخيص: MIT

GH-CACHE-LIST(1) دليل سطر أوامر GitHub GH-CACHE-LIST(1)

الاسم

gh-cache-list - سرد ذاكرة التخزين المؤقت لإجراءات GitHub

الملخص

gh cache list [flags]

خيارات

-q, --jq <expression>
تصفية مخرجات JSON باستخدام تعبير jq
--json <fields>
إخراج JSON مع الحقول المحددة
-k, --key <string>
التصفية حسب بادئة مفتاح ذاكرة التخزين المؤقت
-L, --limit <int> (الافتراضي 30)
الحد الأقصى لعدد ذاكرات التخزين المؤقت المراد جلبها
-O, --order <string> (الافتراضي "desc")
ترتيب ذاكرات التخزين المؤقت التي تم إرجاعها: {asc|desc}
-r, --ref <string>
التصفية حسب المرجع، بصيغة refs/heads/ أو refs/pull//merge
-S, --sort <string> (الافتراضي "last_accessed_at")
فرز ذاكرات التخزين المؤقت التي تم جلبها: {created_at|last_accessed_at|size_in_bytes}
-t, --template <string>
تنسيق مخرجات JSON باستخدام قالب Go؛ راجع "gh help formatting"

خيارات موروثة من الأوامر الأصلية

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام صيغة [HOST/]OWNER/REPO

أسماء مستعارة

gh cache ls

حقول JSON

createdAt، id، key، lastAccessedAt، ref، sizeInBytes، version

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# سرد ذاكرات التخزين المؤقت للمستودع الحالي
$ gh cache list
# سرد ذاكرات التخزين المؤقت لمستودع محدد
$ gh cache list --repo cli/cli
# سرد ذاكرات التخزين المؤقت مرتبة حسب الأقل وصولاً إليها مؤخرًا
$ gh cache list --sort last_accessed_at --order asc
# سرد ذاكرات التخزين المؤقت التي تتطابق مفاتيحها مع بادئة (أو تتطابق تمامًا)
$ gh cache list --key key-prefix
# سرد ذاكرات التخزين المؤقت لفرع محدد، استبدل <branch-name> باسم الفرع الفعلي
$ gh cache list --ref refs/heads/<branch-name>
# سرد ذاكرات التخزين المؤقت لطلب سحب محدد، استبدل <pr-number> برقم طلب السحب الفعلي
$ gh cache list --ref refs/pull/<pr-number>/merge
