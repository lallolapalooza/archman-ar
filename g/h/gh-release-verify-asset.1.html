gh-release-verify-asset(1)

الحزمة: github-cli

التراخيص: MIT

GH-RELEASE-VERIFY-ASSET(1) دليل GitHub CLI GH-RELEASE-VERIFY-ASSET(1)

الاسم

gh-release-verify-asset - التحقق من أن أصل معين نشأ من إصدار

الملخص

gh release verify-asset [<tag>] <file-path> [flags]

الوصف

التحقق من أن ملف الأصل المعطى نشأ من إصدار GitHub محدد باستخدام الإفادات الموقعة بشكل تشفيري.

الإفادة هي ادعاء تقدمه GitHub بخصوص إصدار وأصوله.

يقوم هذا الأمر بالتحقق من أن الأصل الذي تقدمه يتطابق مع إفادة صالحة للإصدار المحدد (أو أحدث إصدار، إذا لم يتم إعطاء علامة).

يضمن سلامة الأصل عن طريق التحقق من أن تجزئة الأصل تتطابق مع الموضوع في الإفادة وأن الإفادة مرتبطة بالإصدار.

الخيارات

--format <string>
صيغة الإخراج: {json}
-q, --jq <expression>
تصفية إخراج JSON باستخدام تعبير jq
-t, --template <string>
صيغة إخراج JSON باستخدام قالب Go؛ انظر "gh help formatting"

الخيارات الموروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام صيغة [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# التحقق من أصل من أحدث إصدار
$ gh release verify-asset ./dist/my-asset.zip
# التحقق من أصل من علامة إصدار محددة
$ gh release verify-asset v1.2.3 ./dist/my-asset.zip
# التحقق من أصل من علامة إصدار محددة وإخراج الإفادة بصيغة JSON
$ gh release verify-asset v1.2.3 ./dist/my-asset.zip --format json
