الاسم

gh-repo-gitignore-view - عرض قالب .gitignore مستودع متاح

الموجز

gh repo gitignore view <template> [flags]

الوصف

عرض قالب .gitignore مستودع متاح.

<template> هو اسم قالب .gitignore حساس لحالة الأحرف.

لقائمة القوالب المتاحة، قم بتشغيل gh repo gitignore list.

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب المصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

مثال

# عرض قالب Go gitignore
$ gh repo gitignore view Go
# عرض قالب Python gitignore
$ gh repo gitignore view Python
# إنشاء ملف .gitignore جديد باستخدام قالب Go
$ gh repo gitignore view Go > .gitignore
# إنشاء ملف .gitignore جديد باستخدام قالب Python
$ gh repo gitignore view Python > .gitignore
