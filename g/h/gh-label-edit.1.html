gh-label-edit(1)

الحزمة: github-cli

التراخيص: MIT

GH-LABEL-EDIT(1) دليل GitHub CLI GH-LABEL-EDIT(1)

الاسم

gh-label-edit - تعديل تسمية

الملخص

gh label edit <name> [flags]

الوصف

تحديث تسمية على GitHub.

يمكن إعادة تسمية التسمية باستخدام العلم --name.

يحتاج لون التسمية أن يكون قيمة ستة أحرف ستة عشرية.

الخيارات

-c, --color <string>
لون التسمية
-d, --description <string>
وصف التسمية
-n, --name <string>
الاسم الجديد للتسمية

الخيارات الموروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب مصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. راجع مساعدة الأمر لمزيد من المعلومات.

مثال

# تحديث لون تسمية bug
$ gh label edit bug --color FF0000
# إعادة تسمية وتعديل وصف تسمية bug
$ gh label edit bug --name big-bug --description "Bigger than normal bug"
