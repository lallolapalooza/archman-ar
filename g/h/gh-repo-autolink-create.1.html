gh-repo-autolink-create(1)

الحزمة: github-cli

التراخيص: MIT

GH-REPO-AUTOLINK-CREATE(1) دليل سطر أوامر GitHub GH-REPO-AUTOLINK-CREATE(1)

الاسم

gh-repo-autolink-create - إنشاء مرجع ارتباط تلقائي جديد

ملخص

gh repo autolink create <keyPrefix> <urlTemplate> [flags]

الوصف

إنشاء مرجع ارتباط تلقائي جديد لمستودع.

يحدد الوسيط <keyPrefix> البادئة التي ستنشئ رابطًا عند إلحاق أحرف معينة بها.

يحدد الوسيط <urlTemplate> عنوان URL المستهدف الذي سيتم إنشاؤه عند العثور على keyPrefix، ويجب أن يحتوي على المتغير <num> لرقم المرجع.

افتراضيًا، تكون الروابط التلقائية أبجدية رقمية مع استخدام العلامة --numeric لإنشاء رابط تلقائي رقمي.

يختلف سلوك المتغير <num> اعتمادًا على ما إذا كان الارتباط التلقائي أبجديًا رقميًا أم رقميًا:

  • أبجدي رقمي: يطابق A-Z (غير حساس لحالة الأحرف)، 0-9، و -
  • رقمي: يطابق 0-9

إذا كان القالب يحتوي على مثيلات متعددة لـ <num>، فسيتم استبدال الأول فقط.

خيارات

-n, --numeric
تمييز الارتباط التلقائي كرقمي

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
تحديد مستودع آخر باستخدام تنسيق [HOST/]OWNER/REPO

أسماء مستعارة

gh repo autolink new

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# إنشاء ارتباط تلقائي أبجدي رقمي إلى example.com للبادئة "TICKET-".
# ينشئ https://example.com/TICKET?query=123abc من "TICKET-123abc".
$ gh repo autolink create TICKET- "https://example.com/TICKET?query=<num>"
# إنشاء ارتباط تلقائي رقمي إلى example.com للبادئة "STORY-".
# ينشئ https://example.com/STORY?id=123 من "STORY-123".
$ gh repo autolink create STORY- "https://example.com/STORY?id=<num>" --numeric
