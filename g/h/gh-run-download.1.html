gh-run-download(1)

الحزمة: github-cli

التراخيص: MIT

GH-RUN-DOWNLOAD(1) دليل GitHub CLI GH-RUN-DOWNLOAD(1)

الاسم

gh-run-download - تنزيل القطع الأثرية التي تم إنشاؤها بواسطة تشغيل سير عمل

الملخص

gh run download [<run-id>] [flags]

الوصف

تنزيل القطع الأثرية التي تم إنشاؤها بواسطة تشغيل سير عمل GitHub Actions.

سيتم استخراج محتويات كل قطعة أثرية تحت مجلدات منفصلة بناءً على اسم القطعة الأثرية. إذا تم تحديد قطعة أثرية واحدة فقط، فسيتم استخراجها في الدليل الحالي.

بشكل افتراضي، يقوم هذا الأمر بتنزيل أحدث قطعة أثرية تم إنشاؤها وتحميلها من خلال GitHub Actions. نظرًا لأنه يمكن لسير العمل حذف القطع الأثرية أو الكتابة فوقها، يجب استخدام <run-id> لتحديد قطعة أثرية من تشغيل سير عمل معين.

خيارات

-D, --dir <string> (الافتراضي ".")
الدليل الذي سيتم تنزيل القطع الأثرية إليه
-n, --name <stringArray>
تنزيل القطع الأثرية التي تطابق أيًا من الأسماء المعطاة
-p, --pattern <stringArray>
تنزيل القطع الأثرية التي تطابق نمط glob

خيارات موروثة من الأوامر الأصل

-R, --repo <[HOST/]OWNER/REPO>
حدد مستودعًا آخر باستخدام تنسيق [HOST/]OWNER/REPO

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: مطلوب مصادقة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

# تنزيل جميع القطع الأثرية التي تم إنشاؤها بواسطة تشغيل سير عمل
$ gh run download <run-id>
# تنزيل قطعة أثرية معينة ضمن تشغيل
$ gh run download <run-id> -n <name>
# تنزيل قطع أثرية معينة عبر جميع التشغيل في مستودع
$ gh run download -n <name1> -n <name2>
# تحديد القطع الأثرية للتنزيل بشكل تفاعلي
$ gh run download
