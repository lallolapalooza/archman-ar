الحزمة: github-cli

التراخيص: MIT

GH-ISSUE-LIST(1) دليل GitHub CLI GH-ISSUE-LIST(1)

الاسم

gh-issue-list - سرد المشكلات في مستودع

الملخص

gh issue list [علامات]

الوصف

يسرد المشكلات في مستودع GitHub. افتراضيًا، يسرد هذا المشكلات المفتوحة فقط.

صيغة استعلام البحث موثقة هنا:

⟨https://docs.github.com/en/search-github/searching-on-github/searching-issues-and-pull-requests⟩

على مضيفات GitHub المدعومة، يمكن استخدام صيغة بحث المشكلات المتقدمة في استعلام --search. لمزيد من المعلومات حول بحث المشكلات المتقدم، انظر:

⟨https://docs.github.com/en/issues/tracking-your-work-with-issues/using-issues/filtering-and-searching-issues-and-pull-requests#building-advanced-filters-for-issues⟩

الخيارات

--app <سلسلة>
التصفية حسب مؤلف تطبيق GitHub
-a, --assignee <سلسلة>
التصفية حسب المسؤول
-A, --author <سلسلة>
التصفية حسب المؤلف
-q, --jq <تعبير>
تصفية مخرجات JSON باستخدام تعبير jq
--json <حقول>
إخراج JSON بالحقول المحددة
-l, --label <سلاسل>
التصفية حسب التسمية
-L, --limit <عدد صحيح> (الافتراضي 30)
الحد الأقصى لعدد المشكلات التي سيتم جلبها
--mention <سلسلة>
التصفية حسب الإشارة
-m, --milestone <سلسلة>
التصفية حسب رقم أو عنوان المعلم
-S, --search <استعلام>
البحث عن المشكلات باستخدام استعلام
-s, --state <سلسلة> (الافتراضي "مفتوح")
التصفية حسب الحالة: {مفتوح|مغلق|الكل}
-t, --template <سلسلة>
تنسيق مخرجات JSON باستخدام قالب Go؛ انظر "gh help formatting"
-w, --web
سرد المشكلات في متصفح الويب

خيارات موروثة من الأوامر الأصل

-R, --repo <[المضيف/]المالك/المستودع>
حدد مستودعًا آخر باستخدام صيغة [المضيف/]المالك/المستودع

الأسماء المستعارة

gh issue ls

حقول JSON

assignees, author, body, closed, closedAt, closedByPullRequestsReferences, comments, createdAt, id, isPinned, labels, milestone, number, projectCards, projectItems, reactionGroups, state, stateReason, title, updatedAt, url

رموز الخروج

0: تنفيذ ناجح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى مساعدة الأمر لمزيد من المعلومات.

مثال

$ gh issue list --label "bug" --label "help wanted"
$ gh issue list --author monalisa
$ gh issue list --assignee "@me"
$ gh issue list --milestone "The big 1.0"
$ gh issue list --search "error no:assignee sort:created-asc"
$ gh issue list --state all
