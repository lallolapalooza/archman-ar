gh-agent-task(1)

الحزمة: github-cli

التراخيص: MIT

GH-AGENT-TASK(1) دليل سطر أوامر GitHub GH-AGENT-TASK(1)

الاسم

gh-agent-task - العمل مع مهام الوكيل (معاينة)

ملخص

gh agent-task <command> [flags]

الوصف

العمل مع مهام الوكيل في سطر أوامر GitHub في مرحلة المعاينة وهو عرضة للتغيير دون إشعار.

الأوامر المتاحة

gh-agent-task-create(1)
إنشاء مهمة وكيل (معاينة)
gh-agent-task-list(1)
سرد مهام الوكيل (معاينة)
gh-agent-task-view(1)
عرض جلسة مهمة وكيل (معاينة)

أسماء مستعارة

gh agent-tasks, gh agent, gh agents

رموز الخروج

0: تم التنفيذ بنجاح

1: خطأ

2: تم إلغاء الأمر

4: المصادقة مطلوبة

ملاحظة: قد يكون للأوامر المحددة رموز خروج إضافية. ارجع إلى تعليمات الأمر لمزيد من المعلومات.

مثال

# سرد أحدث مهام الوكيل الخاصة بك
$ gh agent-task list
# إنشاء مهمة وكيل جديدة في المستودع الحالي
$ gh agent-task create "تحسين أداء خط أنابيب معالجة البيانات"
# عرض التفاصيل حول مهام الوكيل المرتبطة بطلب سحب
$ gh agent-task view 123
# عرض التفاصيل حول مهمة وكيل محددة
$ gh agent-task view 12345abc-12345-12345-12345-12345abc
