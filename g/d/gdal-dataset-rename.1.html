الاسم

gdal-dataset-rename - إعادة تسمية ملفات مجموعة بيانات

تمت الإضافة في الإصدار 3.12.

gdal dataset rename يعيد تسمية ملفات مجموعة البيانات، بما في ذلك الملفات المصاحبة/الجانبية المحتملة.

الملخص

الاستخدام: gdal dataset rename [خيارات] <المصدر> <الوجهة>
إعادة تسمية ملفات مجموعة البيانات.
الوسائط الموضعية:
  --source <المصدر>            اسم مجموعة البيانات المصدر [مطلوب]
  --destination <الوجهة>  اسم مجموعة البيانات الوجهة [مطلوب]
الخيارات الشائعة:
  -h, --help                   عرض رسالة المساعدة والخروج
  --json-usage                 عرض الاستخدام كوثيقة JSON والخروج
  --config <المفتاح>=<القيمة>       خيار التكوين [يمكن تكراره]
الخيارات:
  --overwrite                  ما إذا كان سيسمح بالكتابة فوق الإخراج الموجود
الخيارات المتقدمة:
  -f, --format <التنسيق>        تنسيق مجموعة البيانات

الخيارات

--source <اسم الملف>
اسم الملف المصدر أو اسم الدليل. مطلوب.
--destination <اسم الملف>
اسم الملف الوجهة أو اسم الدليل. مطلوب.
-f, --format <التنسيق>
تنسيق مجموعة البيانات. يتجاوز الكشف التلقائي للتنسيق.
--overwrite
السماح للبرنامج بالكتابة فوق الملف أو مجموعة البيانات الهدف الموجودة. خلاف ذلك، بشكل افتراضي، يخرج gdal بخطأ إذا كان الملف أو مجموعة البيانات الهدف موجودة بالفعل.

أمثلة

مثال 1: إعادة تسمية مجموعة بيانات

$ gdal dataset rename old_name.tif new_name.tif
