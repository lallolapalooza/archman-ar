GD__Graph__colour(3pm)

الحزمة: perl-gdgraph

التراخيص: GPL, PerlArtistic

Graph::colour(3) وثائق Perl من مساهمات المستخدم Graph::colour(3)

الاسم

GD::Graph::colour - إجراءات معالجة الألوان للاستخدام مع GD::Graph

الملخص

use GD::Graph::colour qw(:colours :lists :files :convert);

الوصف

توفر الحزمة GD::Graph::colour عددًا قليلاً من الإجراءات للعمل مع الألوان. يتم تعريف وظائف هذه الحزمة بشكل أساسي من خلال ما هو مطلوب، حاليًا وتاريخيًا، من قبل وحدات GD::Graph.

الوظائف

colour_list( عدد الألوان )

يعيد قائمة بـ عدد الألوان من أسماء الألوان المعروفة للحزمة. يتم تصديره بعلامة :lists.

sorted_colour_list( عدد الألوان )

يعيد قائمة بـ عدد الألوان من أسماء الألوان المعروفة للحزمة، مرتبة حسب السطوع أو الصبغة. ** ملاحظة. ** في الوقت الحالي، يتم دائمًا الترتيب حسب السطوع. سيتم إضافة خيار في مرحلة لاحقة لتحديد طريقة الترتيب في وقت التشغيل. يتم تصديره بعلامة :lists.

_rgb( اسم اللون )

يعيد قائمة بقيم RGB لـ اسم اللون. إذا كان اسم اللون سلسلة نصية بالشكل المقبول لـ hex2rgb، فسيتم إضافة اللون ديناميكيًا إلى القائمة. يتم تصديره بعلامة :colours.

_hue( R,G,B )

يعيد صبغة اللون بالقيم RGB المحددة. يتم تصديره بعلامة :colours.

_luminance( R,G,B )

يعيد سطوع اللون بالقيم RGB المحددة. يتم تصديره بعلامة :colours.

add_colour(اسم_اللون => [$r, $g, $b]) أو add_colour('#7fe310')

واضحة بذاتها. يتم تصديرها بعلامة :colours.

rgb2hex($red, $green, $blue)

hex2rgb('#7fe310')

تقوم هذه الوظائف بتحويل قائمة قيم RGB إلى سلسلة ست عشرية، كما هو شائع الاستخدام في HTML وواجهة برمجة تطبيقات Image::Magick، والعكس صحيح. يتم تصديرها بعلامة :convert.

read_rgb( اسم الملف )

تقرأ الألوان من ملف rgb كما يستخدمه نظام X11.

القيام بشيء مثل:

use GD::Graph::bars;
use GD::Graph::colour;
GD::Graph::colour::read_rgb("rgb.txt") or die "cannot read colours";

سيسمح لك باستخدام أي ألوان محددة في rgb.txt في الرسم البياني الخاص بك. يتم تصديرها بعلامة :files.

أسماء الألوان المعرفة مسبقًا

white, lgray, gray, dgray, black, lblue, blue, dblue, gold, lyellow, yellow, dyellow, lgreen, green, dgreen, lred, red, dred, lpurple, purple, dpurple, lorange, orange, pink, dpink, marine, cyan, lbrown, dbrown.
