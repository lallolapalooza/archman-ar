gdnsd-plugin-null(8)

الحزمة: gdnsd

التراخيص: GPL3

GDNSD-PLUGIN-NULL(8) gdnsd GDNSD-PLUGIN-NULL(8)

اسم

gdnsd-plugin-null - إضافة null لـ gdnsd

ملخص

مثال على تكوين service_types لـ null:

service_types => {
  my_null_mon => {
    plugin => null,
    # ... معلمات service_type عامة أخرى
  }
}

سجلات منطقة تستخدم حل null

foo 300 DYNA null
bar 300 DYNC null!whatever

الوصف

gdnsd-plugin-null موجود في الغالب كمثال على الحد الأدنى الممكن من الإضافات لكل من النوعين. وهو في نفس الوقت إضافة مراقبة وإضافة حل.

عند استخدامه كإضافة حل في سجلات "DNYA" أو "DYNC"، فإنه يتجاهل أي اسم مورد يتم توفيره. يعيد دائمًا عنوان IPv4 0.0.0.0 وعنوان IPv6 "::".

عند استخدامه كإضافة مراقبة عن طريق تعريف service_type كما هو موضح في المثال أعلاه، فإنه يحاكي سلوك إضافة مراقبة حقيقية (التحديث على فترات صحيحة، وما إلى ذلك) ولكنه يرسل نتيجة "DOWN" في كل فترة تحقق مراقبة دون التحقق من أي شيء فعليًا.
