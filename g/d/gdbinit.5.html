gdbinit(5)

الحزمة: gdb

التراخيص: GPL-3.0-or-later, LGPL-3.0-or-later

GDBINIT(5) أدوات تطوير GNU GDBINIT(5)

الاسم

gdbinit - نصوص تهيئة GDB

الملخص

~/.config/gdb/gdbinit

~/.gdbinit

./.gdbinit

الوصف

تحتوي هذه الملفات على أوامر GDB لتنفيذها تلقائيًا أثناء بدء تشغيل GDB. أسطر المحتويات هي تسلسلات مخزنة من الأوامر، موصوفة في دليل GDB تحت العقدة "Sequences" -- أمر shell "info -f gdb -n Sequences".

يرجى القراءة المزيد في دليل GDB تحت العقدة "Startup" -- أمر shell "info -f gdb -n Startup".

(غير مفعل مع "--with-system-gdbinit" أثناء الترجمة)
ملف التهيئة على مستوى النظام. يتم تنفيذه ما لم يحدد المستخدم خيار GDB "-nx" أو "-n". انظر المزيد في دليل GDB تحت العقدة "System-wide configuration" -- أمر shell "info -f gdb -n 'System-wide configuration'".
(غير مفعل مع "--with-system-gdbinit-dir" أثناء الترجمة)
دليل التهيئة على مستوى النظام. يتم تنفيذ جميع الملفات في هذا الدليل عند بدء التشغيل ما لم يحدد المستخدم خيار GDB "-nx" أو "-n"، طالما أن لها امتداد ملف معروف. انظر المزيد في دليل GDB تحت العقدة "System-wide configuration" -- أمر shell "info -f gdb -n 'System-wide configuration'".
~/.config/gdb/gdbinit أو ~/.gdbinit
ملف تهيئة المستخدم. يتم تنفيذه ما لم يحدد المستخدم خيارات GDB "-nx"، "-n" أو "-nh".
.gdbinit
ملف التهيئة للدليل الحالي. قد يحتاج إلى التمكين باستخدام أمر أمان GDB "set auto-load local-gdbinit". انظر المزيد في دليل GDB تحت العقدة "Init File in the Current Directory" -- أمر shell "info -f gdb -n 'Init File in the Current Directory'".

خيارات

بيئة

انظر أيضًا

gdb(1)، "info -f gdb -n Startup"

تمت صيانة التوثيق الكامل لـ GDB كدليل Texinfo. إذا كانت برامج "info" و "gdb" وتوثيق Texinfo الخاص بـ GDB مثبتة بشكل صحيح في موقعك، فإن الأمر

info gdb

يجب أن يمنحك الوصول إلى الدليل الكامل.

Using GDB: A Guide to the GNU Source-Level Debugger، ريتشارد إم ستالمان ورولاند إتش بيش، يوليو 1991.
