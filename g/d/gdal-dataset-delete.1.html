الاسم

gdal-dataset-delete - حذف مجموعة بيانات (مجموعات بيانات)

تمت الإضافة في الإصدار 3.12.

gdal dataset delete يحذف مجموعة بيانات (مجموعات بيانات)، بما في ذلك الملفات المرتبطة/المساعدة المحتملة.

الملخص

الاستخدام: gdal dataset delete [خيارات] <اسم الملف>
حذف مجموعة بيانات (مجموعات بيانات).
الوسائط الموضعية:
  --filename <اسم الملف>   اسم الملف أو الدليل [يمكن تكراره] [مطلوب]
الخيارات الشائعة:
  -h, --help              عرض رسالة المساعدة والخروج
  --json-usage            عرض الاستخدام كمستند JSON والخروج
  --config <المفتاح>=<القيمة>  خيار التهيئة [يمكن تكراره]
الخيارات المتقدمة:
  -f, --format <الصيغة>   صيغة مجموعة البيانات

الخيارات

--filename <اسم الملف>
أي اسم ملف أو اسم دليل. مطلوب. يمكن تكراره
-f, --format <الصيغة>
صيغة مجموعة البيانات. يساعد إذا كان الكشف التلقائي لا يعمل.

أمثلة

المثال 1: حذف مجموعة بيانات

$ gdal dataset delete NE1_50M_SR_W.tif
