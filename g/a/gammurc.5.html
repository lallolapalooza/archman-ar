NAME
gammurc - configuration file for Gammu
SYNOPSIS
/etc/gammurc
DESCRIPTION

The gammurc file is the main configuration file for Gammu. It contains various settings that control the behavior of Gammu, including connection parameters, phone settings, and service configurations.

The configuration file is divided into sections, each denoted by a name in square brackets (e.g., [gammu], [smsd]). Within each section, settings are specified as key-value pairs.

Some common sections and their settings include:

[gammu]

General Gammu settings:

device
The serial port or device Gammu should use to communicate with the phone.
connection
The connection type (e.g., at, fbus).
synchronizetime
Whether to synchronize the phone's clock with the computer's clock.
[smsd]

SMS daemon settings:

service
The SMS service to use (e.g., gammu-smsd).
logfile
Path to the log file for the SMS daemon.
debuglevel
The level of debugging information to log.
InboxPath
Directory to store received SMS messages.
OutboxPath
Directory to store outgoing SMS messages.
SentSMSPath
Directory to store successfully sent SMS messages.
ErrorSMSPath
Directory to store SMS messages that failed to send.

Refer to the Gammu documentation for a complete list of sections and options.

EXAMPLES

A minimal gammurc file might look like this:

[gammu]
device = /dev/ttyACM0
connection = at
synchronizetime = yes

[smsd]
service = gammu-smsd
logfile = /var/log/gammu-smsd.log
debuglevel = 2
InboxPath = /var/spool/gammu/inbox/
OutboxPath = /var/spool/gammu/outbox/
SentSMSPath = /var/spool/gammu/sent/
ErrorSMSPath = /var/spool/gammu/error/
