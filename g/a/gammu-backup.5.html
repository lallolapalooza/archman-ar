gammu-backup(5)

الحزمة: gammu

التراخيص: GPL-2.0-or-later

GAMMU-BACKUP(5) Gammu GAMMU-BACKUP(5)

الاسم

gammu-backup - تنسيق ملف النسخ الاحتياطي لـ gammu(1).

تنسيق النسخ الاحتياطي هو ملف نصي مشفر إما بتشفير ASCII أو UCS-2-BE.

يستخدم هذا الملف صيغة ملف ini، انظر ini.

أمثلة

إذا قمت بعمل نسخة احتياطية من الإعدادات إلى ملف نصي لـ Gammu، فسيكون من الممكن تحريره. إنه سهل: سيتم كتابة العديد من الأشياء في هذا الملف مرتين - مرة باليونيكود، ومرة بـ ASCII. عندما تقوم بإزالة إصدار اليونيكود، سيستخدم Gammu ASCII عند الاستعادة (ويمكنك بسهولة تحرير نص ASCII) وسيقوم بتحويله وفقًا لإعدادات نظام التشغيل المحلي الخاص بك. عندما يكون إصدار اليونيكود للنص متاحًا، فسيتم استخدامه بدلاً من ASCII (مفيد مع هواتف اليونيكود - ليس مهمًا ما هو الإعداد المحلي المحدد في الكمبيوتر ولا يتم إجراء أي تحويل Unicode -> ASCII و ASCII -> Unicode).

يمكنك استخدام أي محرر بوظيفة التعبيرات العادية لتحرير ملف النسخ الاحتياطي النصي. تشمل أمثلة هذه المحررات vim أو TextPad وكلاهما يدعم التعبيرات العادية.

إزالة معلومات علامات الصوت

البحث عن:

^Entry\([0-9][0-9]\)VoiceTag = \(.*\)\n

الاستبدال ب:

<blank>

تغيير جميع الأرقام التي تبدأ بـ +3620، +3630، +3660، +3670 إلى +3620

البحث عن:

Type = NumberGeneral\nEntry\([0-9][0-9]\)Text = "\+36\(20\|30\|60\|70\)\n

الاستبدال ب:

Type = NumberMobile\nEntry\1Text = "\+3620

تغيير نوع أرقام الهواتف إلى محمول للأرقام التي تبدأ بـ +3620، +3630، ... وإزالة سطر TextUnicode المقابل

البحث عن:

Type = NumberGeneral\nEntry\([0-9][0-9]\)Text = "\+36\([2367]0\)\([^\"]*\)"\nEntry\([0-9][0-9]\)TextUnicode = \([^\n]*\)\n

الاستبدال ب:

Type = NumberMobile\nEntry\1Text = "\+36\2\3"\n

انظر أيضا:

converting-formats
