GAMMU-DETECT(1) Gammu GAMMU-DETECT(1)

الاسم

gammu-detect - كشف أجهزة Gammu

جديد منذ الإصدار 1.28.95.

الملخص

gammu-detect [OPTIONS]

الوصف

سكريبت لكشف الأجهزة المتاحة، والتي قد تكون مناسبة لـ gammu.

ملاحظة:

هذا البرنامج يسرد جميع الأجهزة التي قد تكون مناسبة، ولا يقوم بأي فحص للأجهزة نفسها.

حاليًا يدعم الأجهزة التالية:

  • أجهزة USB باستخدام udev
  • منافذ تسلسلية باستخدام udev
  • منافذ تسلسلية على ويندوز
  • أجهزة بلوتوث باستخدام Bluez

ملاحظة:

الأجهزة المدعومة تعتمد على النظام الأساسي الذي تستخدمه والميزات المترجمة. يمكنك معرفة ما تم ترجمته بالفعل عن طريق تشغيل gammu-detect -v.

يتبع هذا البرنامج صيغة سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (--). يتم تضمين ملخص للخيارات أدناه.

-h, --help
عرض ملخص للخيارات.
-d, --debug
عرض مخرجات التصحيح لكشف الأجهزة.
-v, --version
عرض معلومات الإصدار والميزات المترجمة.
-u, --no-udev
تعطيل فحص udev.
-b, --no-bluez
تعطيل الفحص باستخدام Bluez.
-w, --no-win32-serial
تعطيل فحص منافذ ويندوز التسلسلية.

المخرجات

مخرجات gammu-detect هي ملف تكوين لـ Gammu (انظر gammurc) مع قسم تكوين لكل جهاز قد يتم استخدامه مع gammu.

ملاحظة:

يمكنك اختيار القسم الذي ستستخدمه في gammu عن طريق gammu -s.

عند استدعائه كـ gammu-detect -d، يتم أيضًا سرد جميع الأجهزة التي تم فحصها كتعليقات في المخرجات.

مثال

; ملف تكوين تم إنشاؤه بواسطة gammu-detect.
; يرجى التحقق من دليل Gammu للحصول على مزيد من المعلومات.
[gammu]
device = /dev/ttyACM0
name = Nokia E52
connection = at
[gammu1]
device = /dev/ttyACM1
name = Nokia E52
connection = at
[gammu2]
device = /dev/ttyS0
name = Phone on serial port 0
connection = at
[gammu3]
device = /dev/ttyS1
name = Phone on serial port 1
connection = at
[gammu4]
device = /dev/ttyS2
name = Phone on serial port 2
connection = at
[gammu5]
device = /dev/ttyS3
name = Phone on serial port 3
connection = at
[gammu6]
device = 5C:57:C8:BB:BB:BB
name = Nokia E52
connection = bluephonet
