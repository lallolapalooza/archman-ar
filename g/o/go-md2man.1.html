go-md2man(1) دليل المستخدم go-md2man(1)

الاسم

go-md2man - تحويل ملفات markdown إلى صفحات دليل

ملخص

go-md2man [-in=/path/to/md/file] [-out=/path/to/output]

الوصف

يقوم go-md2man بتحويل مستندات markdown القياسية إلى صفحات دليل. تم كتابته بالكامل بلغة Go لتقليل الاعتماد على المكتبات الخارجية.

بشكل افتراضي، يكون الإدخال هو stdin والإخراج هو stdout.

خيارات

-in=ملف
مسار ملف markdown المراد معالجته.

الافتراضي هو stdin.

-out=ملف
مسار ملف الإخراج المعالج.

الافتراضي هو stdout.

أمثلة

تحويل ملف markdown go-md2man.1.md إلى صفحة دليل:

go-md2man < go-md2man.1.md > go-md2man.1

نفس الشيء، ولكن باستخدام وسائط سطر الأوامر بدلاً من إعادة توجيه shell:

go-md2man -in=go-md2man.1.md -out=go-md2man.1
