NAME

godot-mono - Godot Engine editor and command-line tool

SYNOPSIS

godot [OPTIONS...] [PATH]

DESCRIPTION

The Godot Engine is a free and open-source, cross-platform, integrated game development environment. The editor can export games to Android, BSD, iOS, Linux, macOS, SteamOS, Windows, and also the Web.

This manual page documents the command-line interface of the Godot Engine.

--advanced-debug
Enable advanced debugging features in the editor.
--build-source
This is an undocumented argument.
--check-only
Check the project's validity and exit.
--debug
Run the project in debug mode.
--dump-extension-api
Generate JSON dump of the Godot API for GDExtension bindings named 'extension_api.json' in the current folder. This file is the base file required to implement a GDExtension.
--dump-extension-api
Generate JSON dump of the Godot API for GDExtension bindings named 'extension_api.json' in the current folder.
--test <test>
Run a unit test ('string', 'math', 'physics', 'physics_2d', 'render', 'oa_hash_map', 'gui', 'shaderlang', 'gd_tokenizer', 'gd_parser', 'gd_compiler', 'gd_bytecode', 'ordered_hash_map', 'astar').

FILES

XDG_DATA_CONFIG/godot/ or ~/.config/godot/

User-specific configuration folder, contains persistent editor settings, script and text editor templates and projects metadata.
XDG_DATA_HOME/godot/ or ~/.local/share/godot/
Contains the default configuration and user data folders for Godot-made games (user:// path), as well as export templates.
XDG_DATA_CACHE/godot/ or ~/.cache/godot/
Cache folder for generated thumbnails and scene previews, as well as temporary location for downloads.
/usr/share/doc/godot/
Additional documentation files.
/usr/share/licenses/godot/
Detailed licensing information.
