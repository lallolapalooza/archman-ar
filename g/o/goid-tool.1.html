goid-tool(1)

الحزمة: opensc

التراخيص: LGPL

GOID-TOOL(1) أدوات OpenSC GOID-TOOL(1)

الاسم

goid-tool - أداة بطاقة ذكية لبطاقة بصمة GoID

الملخص

goid-tool [خيارات] [وضع]

الوصف

يمكن استخدام الأداة المساعدة goid-tool من سطر الأوامر لقراءة وكتابة بيانات **بطاقة بصمة GoID**[1].

الخيارات

--help, -h

طباعة رسالة المساعدة على الشاشة.

--version, -V

طباعة إصدار إصدار حزمة OpenSC.

--reader string, -r string

تحديد رقم القارئ المراد استخدامه. افتراضيًا، يتم استخدام القارئ الأول مع بطاقة موجودة. إذا كان الوسيط عبارة عن ATR، فسيتم اختيار القارئ ببطاقة مطابقة.

--verbose, -v

جعل goid-tool أكثر تفصيلاً. استخدمها عدة مرات لتكون أكثر تفصيلاً.

--verify-pin, -p

التحقق من رقم التعريف الشخصي.

--verify-bio, -b

التحقق من بصمة الإصبع.

--verify-pin-or-bio

التحقق من رقم التعريف الشخصي أو بصمة الإصبع (اختيار المستخدم).

خيارات لتطبيق SOCMANAGER

--new-pin

تغيير رقم التعريف الشخصي

--new-bio

استخدم (عدة مرات) لتغيير قالب واحد أو أكثر من قوالب القياسات الحيوية

--info

عرض معلومات حول تكوين SoCManager

خيارات لتطبيق PACCESS

--certificate filename, -c filename

استخدم (عدة مرات) لتمرير شهادات CV

--key, -k,

المفتاح الخاص لشهادة CV

--print-cardid

طباعة معرف البطاقة

--write-cardid data

كتابة معرف البطاقة المحدد

--print-paccessid

طباعة معرف PAccess

--write-paccessid data

كتابة معرف PAccess المحدد

--read-dg id

قراءة مجموعة البيانات المحددة؛ استخدم عدة مرات لقراءة ملفات متعددة

--out-file filename

كتابة المخرجات إلى ملف بدلاً من طباعتها؛ استخدم مرة واحدة لكل استخدام لـ --read-dg

--write-dg id

كتابة مجموعة البيانات المحددة؛ استخدم عدة مرات لكتابة ملفات متعددة

--in-file filename

قراءة المدخلات من ملف؛ استخدم مرة واحدة لكل استخدام لـ --write-dg

--delete-dg id

حذف مجموعة البيانات المحددة؛ استخدم عدة مرات لحذف ملفات متعددة

--create-dg id

إنشاء مجموعة البيانات المحددة؛ استخدم عدة مرات لإنشاء ملفات متعددة

--new-size size

حجم ملف مجموعات البيانات التي تم إنشاؤها حديثًا

--new-read-ac condition

شرط الوصول لقراءة مجموعات البيانات التي تم إنشاؤها حديثًا

--new-read-ac condition

شرط الوصول لقراءة مجموعات البيانات التي تم إنشاؤها حديثًا

--new-read-ac-chatbit index

بت الوصول المطلوب في شهادة CHAT لقراءة مجموعات البيانات التي تم إنشاؤها حديثًا

--new-write-ac condition

شرط الوصول لكتابة مجموعات البيانات التي تم إنشاؤها حديثًا

--new-write-ac-chatbit index

بت الوصول المطلوب في شهادة CHAT لكتابة مجموعات البيانات التي تم إنشاؤها حديثًا
