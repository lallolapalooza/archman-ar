gprofng(1)

SYNOPSIS

gprofng [OPTION]... [--filename]...

DESCRIPTION

The GNU profiler, gprofng, is a tool for analyzing the performance of programs. It collects execution time and call graph information, allowing developers to identify performance bottlenecks and optimize their code.

OPTIONS

This program follows the usual GNU command line syntax, with long options starting with two dashes (-). A summary of options is included below. The full description of options is available in the detailed documentation.

-h, --help
Show a summary of options.
-V, --version
Show version information.
-c, --compute-flat-profile
Compute flat profile information.
-e, --exclude-symbol SYMBOL
Exclude SYMBOL from the analysis.
-f, --function-graph
Compute function call graph information.
-l, --locate
Print the location of functions.
-o, --output FILENAME
Write the output to FILENAME.
-p, --print-flat-profile
Print flat profile information.
-q, --quiet
Do not print any messages.
-s, --brief
Print brief output.
-t, --print-call-graph
Print call graph information.
-v, --verbose
Print verbose output.
-w, --write-call-graph
Write call graph information.

ENVIRONMENT

No specific environment variables are required for basic operation, but certain variables might influence compiler or linker behavior related to profiling instrumentation.

NOTES

To use gprofng effectively, your program needs to be compiled and linked with specific options that enable profiling. Typically, this involves using the -pg flag with GCC or Clang. After execution, a gmon.out (or similar) file is generated, which gprofng then analyzes.

SEE ALSO

gprof(1), perf(1), valgrind(1)

الملخص

gprofng [خيار]... [اسم_الملف]...

الوصف

أداة GNU Profiler، gprofng، هي أداة لتحليل أداء البرامج. تقوم بجمع معلومات عن وقت التنفيذ ورسم بياني لاستدعاءات الدوال، مما يسمح للمطورين بتحديد نقاط ضعف الأداء وتحسين الكود الخاص بهم.

خيارات

يتبع هذا البرنامج قواعد سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (--). يتم تضمين ملخص للخيارات أدناه. الوصف الكامل للخيارات متاح في الوثائق التفصيلية.

-h, --help
عرض ملخص للخيارات.
-V, --version
عرض معلومات الإصدار.
-c, --compute-flat-profile
حساب معلومات الملف المسطح.
-e, --exclude-symbol رمز
استبعاد رمز من التحليل.
-f, --function-graph
حساب معلومات الرسم البياني لاستدعاءات الدوال.
-l, --locate
طباعة موقع الدوال.
-o, --output اسم_الملف
كتابة المخرجات إلى اسم_الملف.
-p, --print-flat-profile
طباعة معلومات الملف المسطح.
-q, --quiet
عدم طباعة أي رسائل.
-s, --brief
طباعة مخرجات موجزة.
-t, --print-call-graph
طباعة معلومات الرسم البياني لاستدعاءات الدوال.
-v, --verbose
طباعة مخرجات مفصلة.
-w, --write-call-graph
كتابة معلومات الرسم البياني لاستدعاءات الدوال.

البيئة

لا توجد متغيرات بيئة محددة مطلوبة للتشغيل الأساسي، ولكن قد تؤثر بعض المتغيرات على سلوك المترجم أو الرابط المتعلق بأدوات قياس الأداء.

ملاحظات

لاستخدام gprofng بفعالية، يجب ترجمة البرنامج وربطه بخيارات محددة تمكّن قياس الأداء. عادةً، يتضمن ذلك استخدام العلامة -pg مع GCC أو Clang. بعد التنفيذ، يتم إنشاء ملف gmon.out (أو ما شابه)، والذي يقوم gprofng بتحليله بعد ذلك.

gprof(1)، perf(1)، valgrind(1)
