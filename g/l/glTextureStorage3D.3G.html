glTextureStorage3D(3G)

الحزمة: opengl-man-pages

التراخيص: SGI-B-2.0, OPL-1.0

NAME

glTextureStorage3D, glTexStorage3D - specify the memory layout and format of a 3D texture or texture array

C SPECIFICATION

void glTextureStorage3D(GLuint texture, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth);

void glTexStorage3D(GLenum target, GLsizei levels, GLenum internalformat, GLsizei width, GLsizei height, GLsizei depth);

PARAMETERS

texture
Specifies the name of the texture object. For glTextureStorage3D, this parameter is the name of the texture object being modified.
target
Specifies the target texture. For glTexStorage3D, it must be GL_TEXTURE_3D, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP_ARRAY, or GL_PROXY_TEXTURE_3D, GL_PROXY_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_CUBE_MAP_ARRAY.
levels
Specifies the number of texture levels for the texture object. This value must be 1 or greater, and it must be less than or equal to the logarithm base 2 of the maximum dimension of the texture, plus one. If levels is 1, then the texture has only one level. If levels is greater than 1, then the texture has levels levels in its image pyramid.
internalformat
Specifies the internal format of the texture. The legal values for internalformat are the sized internal formats of several texture types. For example, GL_R8, GL_R16, GL_RG8, GL_RG16, GL_RGB8, GL_RGB16, GL_RGBA8, GL_RGBA16, GL_SRGB8_ALPHA8, GL_RGB10_A2, GL_RGB10_A2UI, GL_RGBA12, GL_RGBA16, GL_RGB4, GL_RGB5, GL_RGB8, GL_RGB10, GL_RGB12, GL_RGB16, GL_RGBA2, GL_RGBA4, GL_RGBA8, GL_RGBA12, GL_RGBA16, GL_DEPTH_COMPONENT16, GL_DEPTH_COMPONENT24, GL_DEPTH_COMPONENT32, GL_DEPTH_COMPONENT32F, GL_DEPTH32F_STENCIL8, GL_STENCIL_INDEX8, GL_RGB9_E5, GL_R11F_G11F_B10F, GL_RGB5_A1, GL_RGB8I, GL_RGB8UI, GL_RGB16I, GL_RGB16UI, GL_RGB32I, GL_RGB32UI, GL_RGBA8I, GL_RGBA8UI, GL_RGBA16I, GL_RGBA16UI, GL_RGBA32I, GL_RGBA32UI, GL_RGB5_COMPRESSED_RGB8_ETC2, GL_RGBA8_ETC2_EAC, GL_RGBA_ASTC_4x4_KHR, GL_RGBA_ASTC_5x4_KHR, GL_RGBA_ASTC_5x5_KHR, GL_RGBA_ASTC_6x5_KHR, GL_RGBA_ASTC_6x6_KHR, GL_RGBA_ASTC_8x5_KHR, GL_RGBA_ASTC_8x6_KHR, GL_RGBA_ASTC_8x8_KHR, GL_RGBA_ASTC_10x5_KHR, GL_RGBA_ASTC_10x6_KHR, GL_RGBA_ASTC_10x8_KHR, GL_RGBA_ASTC_10x10_KHR, GL_RGBA_ASTC_12x10_KHR, GL_RGBA_ASTC_12x12_KHR.
width
Specifies the width of the texture, in texels. This value must be non-negative.
height
Specifies the height of the texture, in texels. This value must be non-negative.
depth
Specifies the depth of the texture, in texels. This value must be non-negative.

DESCRIPTION

glTextureStorage3D and glTexStorage3D specify the complete dimensions and memory layout of a new 3D texture object, or one of the textures in a texture array.

If the texture object specified by texture (for glTextureStorage3D) or the texture object currently bound to the effective target (for glTexStorage3D) has the same texture format, dimensions and number of texture levels, then the texture will be re-initialized.

If the texture object is immutable, then it cannot be re-initialized in this way.

The texture object is initialized with a single set of texture images defined by width, height, depth, levels, and internalformat. The texture object is made immutable.

levels must be 1 or greater and less than or equal to log 2(max dimension) + 1.

The dimensions of each texture level are computed by:

    width_i = max(1, width / 2^i)
    height_i = max(1, height / 2^i)
    depth_i = max(1, depth / 2^i)

where i is the level index.

The memory allocated for the texture is determined by the internalformat, width, height, depth and levels. No further texture data may be loaded into the texture object until it has been deleted and reallocated.

NOTES

GL_STENCIL_INDEX8
is accepted for internalformat only if the GL version is 4.4 or higher.

ERRORS

GL_INVALID_OPERATION is generated by glTexStorage3D if zero is bound to target.

GL_INVALID_OPERATION is generated by glTextureStorage3D if texture is not the name of an existing texture object.

GL_INVALID_ENUM is generated if internalformat is not a valid sized internal format.

GL_INVALID_ENUM is generated if target or the effective target of texture is not one of the accepted targets described above.

GL_INVALID_VALUE is generated if width, height, depth or levels are less than 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_3D or GL_PROXY_TEXTURE_3D and levels is greater than log 2 max width ,   height ,   depth + 1.

GL_INVALID_OPERATION is generated if target is GL_TEXTURE_2D_ARRAY, GL_PROXY_TEXTURE_2D_ARRAY, GL_TEXURE_CUBE_MAP_ARRAY, or GL_PROXY_TEXTURE_CUBE_MAP_ARRAY and levels is greater than log 2 max width ,   height + 1.
