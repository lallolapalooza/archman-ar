الاسم

glGetUniformLocation - تُرجع موقع متغير Uniform

مواصفات C

GLint glGetUniformLocation(GLuint program, const GLchar *name);

المعلمات

program

يحدد كائن البرنامج المطلوب الاستعلام عنه.

name

يشير إلى سلسلة نصية منتهية بصفر تحتوي على اسم متغير Uniform الذي يجب الاستعلام عن موقعه.

الوصف

glGetUniformLocation تُرجع عددًا صحيحًا يمثل موقع متغير Uniform محدد داخل كائن برنامج. يجب أن يكون name سلسلة نصية منتهية بصفر ولا تحتوي على مسافات بيضاء. يجب أن يكون name اسم متغير Uniform نشط في program وليس بنية، أو مصفوفة من البنى، أو مكون فرعي لمتجه أو مصفوفة. تُرجع هذه الدالة -1 إذا لم يتطابق name مع متغير Uniform نشط في program، أو إذا بدأ name بالبادئة المحجوزة "gl_"، أو إذا كان name مرتبطًا بعداد ذري أو كتلة Uniform مسماة.

يمكن الاستعلام عن متغيرات Uniform التي هي بنى أو مصفوفات من البنى عن طريق استدعاء glGetUniformLocation لكل حقل داخل البنية. يمكن استخدام عامل عنصر المصفوفة "[]" وعامل حقل البنية "." في name لتحديد العناصر داخل مصفوفة أو الحقول داخل بنية. لا يُسمح بأن تكون نتيجة استخدام هذه العوامل بنية أخرى، أو مصفوفة من البنى، أو مكون فرعي لمتجه أو مصفوفة. باستثناء إذا كان الجزء الأخير من name يشير إلى مصفوفة متغير Uniform، يمكن استرداد موقع العنصر الأول للمصفوفة عن طريق استخدام اسم المصفوفة، أو عن طريق استخدام الاسم الملحق بـ "[0]".

المواقع الفعلية المعينة لمتغيرات Uniform غير معروفة حتى يتم ربط كائن البرنامج بنجاح. بعد حدوث الربط، يمكن استخدام الأمر glGetUniformLocation للحصول على موقع متغير Uniform. يمكن بعد ذلك تمرير قيمة الموقع هذه إلى glUniform() لتعيين قيمة متغير Uniform أو إلى glGetUniform() للاستعلام عن القيمة الحالية لمتغير Uniform. بعد ربط كائن برنامج بنجاح، تظل مؤشرات متغيرات Uniform ثابتة حتى يحدث أمر الربط التالي. يمكن الاستعلام عن مواقع وقيم متغيرات Uniform فقط بعد الربط إذا كان الربط ناجحًا.

الأخطاء

يتم إنشاء GL_INVALID_VALUE إذا لم يكن program قيمة تم إنشاؤها بواسطة OpenGL.

يتم إنشاء GL_INVALID_OPERATION إذا لم يكن program كائن برنامج.

يتم إنشاء GL_INVALID_OPERATION إذا لم يتم ربط program بنجاح.
