الاسم

glScissor - تحديد صندوق المقص

مواصفات C

void glScissor(GLint x, GLint y, GLsizei width, GLsizei height);

المعلمات

x, y

تحديد الزاوية السفلية اليسرى لصندوق المقص. مبدئياً (0, 0).

width, height

تحديد عرض وارتفاع صندوق المقص. عند ربط سياق GL بنافذة لأول مرة، يتم تعيين width و height إلى أبعاد تلك النافذة.

الوصف

glScissor يحدد مستطيلاً، يسمى صندوق المقص، بإحداثيات النافذة. تحدد المعلمتان الأوليان، x و y، الزاوية السفلية اليسرى للمربع. يحدد width و height عرض وارتفاع المربع.

لتمكين وتعطيل اختبار المقص، قم باستدعاء glEnable() و

glDisable مع الوسيط GL_SCISSOR_TEST. يتم تعطيل الاختبار مبدئياً. بينما يكون الاختبار ممكناً، لا يمكن تعديل إلا البكسلات الموجودة داخل صندوق المقص بواسطة أوامر الرسم. إحداثيات النافذة لها قيم صحيحة عند الزوايا المشتركة لبكسلات المخزن المؤقت للإطار. glScissor(0,0,1,1) يسمح بتعديل البكسل السفلي الأيسر فقط في النافذة، و glScissor(0,0,0,0) لا يسمح بتعديل أي بكسلات في النافذة.

عند تعطيل اختبار المقص، يبدو الأمر كما لو كان صندوق المقص يشمل النافذة بأكملها.

الأخطاء

يتم توليد GL_INVALID_VALUE إذا كان width أو height سالبًا.

عمليات GET المرتبطة

glGet() مع الوسيط GL_SCISSOR_BOX

glIsEnabled() مع الوسيط GL_SCISSOR_TEST
