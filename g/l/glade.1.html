glade(1)

الحزمة: glade

التراخيص: GPL, LGPL

GLADE(1) أوامر المستخدم GLADE(1)

الاسم

glade - إنشاء واجهات مستخدم GTK+

ملخص

glade [خيارات...] [ملف...]

الوصف

glade هو أداة لإنشاء أو تعديل واجهات المستخدم لتطبيقات GTK+ أو GNOME. يقوم بحفظ أوصاف واجهة المستخدم في ملفات xml يمكن قراءتها بواسطة واجهة GtkBuilder API التي تعد جزءًا من GTK+.

الخيارات

يمكن تحديد الخيارات التالية:

-h, --help

عرض خيارات المساعدة.

--help-all

عرض جميع خيارات المساعدة.

--help-debug

عرض خيارات تصحيح Glade.

--help-gtk

عرض خيارات GTK+.

--version

إخراج معلومات الإصدار والخروج.

--without-devhelp

تعطيل تكامل devhelp.

--display=DISPLAY

شاشة X للاستخدام.

انظر أيضًا

devhelp(1)
