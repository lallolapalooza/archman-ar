glutPostOverlayRedisplay(3)

الحزمة: freeglut

التراخيص: X11

glutPostOverlayRedisplay(3) freeglut glutPostOverlayRedisplay(3)

الاسم

glutPostOverlayRedisplay, glutPostWindowOverlayRedisplay - تحدد أن الطبقة العلوية لنافذة حالية أو محددة تحتاج إلى إعادة عرض.

تحذير

لم يتم التنفيذ بعد في freeglut.

الصيغة

void glutPostOverlayRedisplay(void);
void glutPostWindowOverlayRedisplay(int win);

الوصف

تحدد أن الطبقة العلوية للنافذة الحالية تحتاج إلى إعادة عرض. في التكرار التالي لدورة glutMainLoop، سيتم استدعاء دالة رد الاتصال الخاصة بعرض الطبقة العلوية للنافذة (أو ببساطة دالة رد الاتصال للعرض إذا لم يتم تسجيل دالة رد اتصال عرض طبقة علوية) لإعادة عرض مستوى الطبقة العلوية للنافذة. تؤدي استدعاءات متعددة لـ glutPostOverlayRedisplay قبل فرصة العرض التالية (أو فرصة عرض الطبقة العلوية إذا تم تسجيل واحدة) إلى حدوث عرض واحد فقط. يمكن استدعاء glutPostOverlayRedisplay ضمن دالة رد اتصال العرض أو عرض الطبقة العلوية للنافذة لإعادة تحديد هذه النافذة للعرض.

منطقياً، يتم التعامل مع إشعار تلف الطبقة العلوية للنافذة على أنه استدعاء glutPostOverlayRedisplay للنافذة المتضررة. على عكس التلف الذي تبلغ عنه نافذة النظام، لن يقوم glutPostOverlayRedisplay بتعيين حالة الطبقة العلوية المتضررة (التي يتم إرجاعها بواسطة glutLayerGet(GLUT_OVERLAY_DAMAGED)) إلى صحيح.

إذا لم تكن النافذة التي تريد نشر إعادة عرض الطبقة العلوية لها حالية (ولا تحتاج إلى جعلها حالية فورًا)، فإن استخدام glutPostWindowOverlayRedisplay أكثر كفاءة من استدعاء glutSetWindow إلى النافذة المطلوبة ثم استدعاء glutPostOverlayRedisplay.

مثال

إذا كنت تقوم بتأثير تفاعلي مثل السحب في الطبقة العلوية، فمن الجيد هيكلة عملية العرض الخاصة بك لتقليل الوميض (معظم الطبقات العلوية أحادية المخزن المؤقت). قم بمسح الطبقة العلوية فقط إذا كنت تعرف أن النافذة قد تضررت. بخلاف ذلك، حاول ببساطة مسح ما رسمته آخر مرة وأعد رسمه في موضع محدث. فيما يلي مثال لدالة رد اتصال عرض الطبقة العلوية المستخدمة لتنفيذ السحب في الطبقة العلوية:

  void
  redrawOverlay(void)
  {
    static int prevStretchX, prevStretchY;
    if (glutLayerGet(GLUT_OVERLAY_DAMAGED)) {
      /* الضرر يعني أننا بحاجة إلى مسح كامل. */
      glClear(GL_COLOR_BUFFER_BIT);
    } else {
      /* إلغاء رسم آخر سحب. */
      glIndexi(transparent);
      glBegin(GL_LINE_LOOP);
      glVertex2i(anchorX, anchorY);
      glVertex2i(anchorX, prevStretchY);
      glVertex2i(prevStretchX, prevStretchY);
      glVertex2i(prevStretchX, anchorY);
      glEnd();
    }
    glIndexi(red);
    glBegin(GL_LINE_LOOP);
    glVertex2i(anchorX, anchorY);
    glVertex2i(anchorX, stretchY);
    glVertex2i(stretchX, stretchY);
    glVertex2i(stretchX, anchorY);
    glEnd();
    prevStretchX = stretchX;
    prevStretchY = stretchY;
  }

لاحظ كيف يتم استخدام glutLayerGet(GLUT_OVERLAY_DAMAGED) لتحديد ما إذا كان المسح ضروريًا بسبب الضرر؛ إذا كان المسح غير ضروري، فمن الأسرع فقط رسم السحب الأخير باستخدام البكسل الشفاف.

عندما ينتهي التطبيق من تأثير السحب، فإن أفضل طريقة للتخلص من السحب هي ببساطة إخفاء الطبقة العلوية عن طريق استدعاء glutHideOverlay.
