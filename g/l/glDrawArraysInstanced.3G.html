glDrawArraysInstanced(3G)

الحزمة: opengl-man-pages

التراخيص: SGI-B-2.0, OPL-1.0

GLDRAWARRAYSINSTANCE(3G) [FIXME: manual] GLDRAWARRAYSINSTANCE(3G)

الاسم

glDrawArraysInstanced - رسم مثيلات متعددة لنطاق من العناصر

مواصفات C

void glDrawArraysInstanced(GLenum mode, GLint first, GLsizei count, GLsizei instancecount);

المعلمات

mode

يحدد نوع الأشكال الأولية المراد تصويرها. الثوابت الرمزية GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY و GL_PATCHES مقبولة.

first

يحدد الفهرس البدئي في المصفوفات الممكّنة.

count

يحدد عدد الفهارس المراد تصويرها.

instancecount

يحدد عدد المثيلات لنطاق الفهارس المحدد المراد تصويرها.

الوصف

glDrawArraysInstanced تتصرف بشكل مطابق لـ glDrawArrays() باستثناء أنه يتم تنفيذ instancecount مثيلًا لنطاق العناصر ويتقدم قيمة العداد الداخلي instanceID لكل تكرار. instanceID هو عداد داخلي بـ 32 بت يمكن قراءته بواسطة مُظلل الرأس كـ gl_InstanceID.

glDrawArraysInstanced لها نفس تأثير:

    if ( mode or count is invalid )
        generate appropriate error
    else {
        for (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawArrays(mode, first, count);
        }
        instanceID = 0;
    }

الأخطاء

يتم إنشاء GL_INVALID_ENUM إذا لم يكن mode أحد القيم المقبولة.

يتم إنشاء GL_INVALID_OPERATION إذا كان مُظلل الهندسة نشطًا وكان mode غير متوافق مع نوع المدخلات الأولي لمُظلل الهندسة في كائن البرنامج المثبت حاليًا.

يتم إنشاء GL_INVALID_VALUE إذا كان count أو instancecount سالبًا.

يتم إنشاء GL_INVALID_OPERATION إذا تم ربط كائن مخزن مؤقت غير صفري بمصفوفة ممكّنة وكان مخزن بيانات كائن المخزن المؤقت مُعينًا حاليًا.
