glClearBufferSubData(3G)

الاسم

glClearBufferSubData, glClearNamedBufferSubData - ملء كل أو جزء من مخزن بيانات الكائن المخزن بقيمة ثابتة

المواصفات C

void glClearBufferSubData(GLenum target, GLenum internalformat, GLintptr offset, GLsizeiptr size, GLenum format, GLenum type, const void * data);

void glClearNamedBufferSubData(GLuint buffer, GLenum internalformat, GLintptr offset, GLsizeiptr size, GLenum format, GLenum type, const void *data);

المعاملات

buffer

يحدد اسم الكائن المخزن لـ glClearNamedBufferSubData.

internalformat

التنسيق الداخلي الذي سيتم تخزين البيانات به في الكائن المخزن.

offset

الإزاحة بوحدات الآلة الأساسية في مخزن بيانات الكائن المخزن لبدء الملء.

size

الحجم بوحدات الآلة الأساسية لمنطقة مخزن البيانات المراد ملؤها.

format

تنسيق البيانات في الذاكرة التي يشير إليها data.

type

نوع البيانات في الذاكرة التي يشير إليها data.

data

عنوان موقع في الذاكرة يخزن البيانات المراد تكرارها في مخزن بيانات المخزن.

الوصف

glClearBufferSubData و glClearNamedBufferSubData تقومان بملء منطقة محددة من مخزن بيانات الكائن المخزن بالبيانات من ذاكرة العميل.

offset و size يحددان نطاق المنطقة داخل مخزن بيانات الكائن المخزن المراد ملؤه بالبيانات. يتم قراءة البيانات، والتي يتم توفيرها مبدئيًا بتنسيق محدد بواسطة format بنوع البيانات type، من عنوان الذاكرة المحدد بواسطة data ويتم تحويلها إلى التمثيل الداخلي المحدد بواسطة internalformat، والذي يجب أن يكون أحد التنسيقات الداخلية المحددة التالية:

The format and type parameters specify the format and data type of the data in the memory addressed by data. They must be compatible with the internalformat.

If data is NULL, the contents of the buffer are not affected by the call.

The internalformat can also be a sized internal format for depth, stencil, or depth-stencil components. These are:

           
Sized Internal Format Base Type Components Depth Stencil Depth/Stencil
GL_DEPTH_COMPONENT16 ushort 1 YES NO NO
GL_DEPTH_COMPONENT24 uint 1 YES NO NO
GL_DEPTH_COMPONENT32 uint 1 YES NO NO
GL_DEPTH_COMPONENT32F float 1 YES NO NO
GL_STENCIL_INDEX8 ubyte 1 NO YES NO
GL_DEPTH24_STENCIL8 2 YES YES YES
GL_DEPTH32F_STENCIL8 2 YES YES YES

For these formats, format and type must be GL_DEPTH_COMPONENT, GL_STENCIL_INDEX, or GL_DEPTH_STENCIL.

If format is GL_DEPTH_COMPONENT, the single component is written to the depth component of the buffer.

If format is GL_STENCIL_INDEX, the single component is written to the stencil index of the buffer.

If format is GL_DEPTH_STENCIL, the two components are written to the depth and stencil components of the buffer.

If size is zero, nothing is written.

The behavior of glClearBufferSubData is undefined if the specified range is not compatible with the buffer's usage target. For example, calling glClearBufferSubData with target GL_PIXEL_UNPACK_BUFFER is an error.

The behavior of glClearNamedBufferSubData is undefined if the buffer object is not mutable.

الأخطاء

GL_INVALID_ENUM is generated if target is not one of the buffer binding targets recognised by glClearBufferSubData.

GL_INVALID_OPERATION is generated if the buffer object bound to target is not mutable.

GL_INVALID_VALUE is generated if offset or size are negative, or if offset + size is greater than the size of the buffer object's data store.

GL_INVALID_OPERATION is generated if buffer is not the name of an existing buffer object.

GL_INVALID_OPERATION is generated if buffer is the name of a buffer object that is not mutable.

GL_INVALID_ENUM is generated if internalformat, format, or type are not legal values.

GL_INVALID_OPERATION is generated if the combination of internalformat, format, and type is not supported by the implementation.

GL_INVALID_OPERATION is generated if the buffer object currently has buffer mapping(s) other than the null mapping.
