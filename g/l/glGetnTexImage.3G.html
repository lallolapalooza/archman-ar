glGetnTexImage(3G)

NAME

glGetnTexImage - return a texture image in memory

C SPECIFICATION

void glGetnTexImage(GLenum target, GLint level, GLenum format, GLenum type, GLsizei bufSize, void *pixels);

PARAMETERS

target
Specifies the texture target. Must be one of GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_CUBE_MAP_POSITIVE_X, GL_TEXTURE_CUBE_MAP_NEGATIVE_X, GL_TEXTURE_CUBE_MAP_POSITIVE_Y, GL_TEXTURE_CUBE_MAP_NEGATIVE_Y, GL_TEXTURE_CUBE_MAP_POSITIVE_Z, GL_TEXTURE_CUBE_MAP_NEGATIVE_Z, or GL_TEXTURE_CUBE_MAP_ARRAY.
level
Specifies the texture level of the texture image to return.
format
Specifies the format of the pixel data. See the Table of formats and sizes section of the glDrawPixels man page.
type
Specifies the data type of the pixel data.
bufSize
Specifies the byte size of the buffer pointed to by pixels.
pixels
Returns the width of the specified texture image.

DESCRIPTION

glGetnTexImage returns a texture image in memory. target specifies a texture object, level specifies the texture level, format specifies the format of the texture data to be returned, and type specifies the data type of the texture data.

The texture data is returned in the order specified by glGet with argument GL_PACK_ORDER, and the pixel locations are determined by glGet with argument GL_PACK_SKIP_ROWS and GL_PACK_SKIP_PIXELS.

The bufSize parameter indicates the size of the buffer pointed to by pixels. If the actual size required to store the texture image is greater than bufSize, then glGetnTexImage generates a GL_INVALID_OPERATION error.

A non-zero buffer object name may be bound to the GL_PIXEL_PACK_BUFFER target. If a buffer object is bound to the GL_PIXEL_PACK_BUFFER target, then pixels is treated as an offset into the buffer object's memory. In this case, the buffer object is used as the destination for the texture data.

glGetnTexImage is functionally equivalent to glGetTexImage, except that it provides more robust behavior in some situations. In particular, glGetnTexImage provides a bufSize parameter which guards against buffer overflows.

NOTES

If a buffer object is bound to the GL_PIXEL_PACK_BUFFER target, the texture data are copied into the buffer object. Otherwise, the texture data are copied into the buffer pointed to by pixels.

The base internal format of the texture image is specified by glTexImage1D, glTexImage2D, glTexImage3D, glCopyTexImage1D, glCopyTexImage2D, glCopyTexImage3D, glCompressedTexImage1D, glCompressedTexImage2D, glCompressedTexImage3D, glCompressedTexSubImage1D, glCompressedTexSubImage2D, or glCompressedTexSubImage3D.

ERRORS

GL_INVALID_OPERATION is generated by glGetnTexImage if target is not one of the accepted texture targets, or if target is one of the cube map faces, but the texture object it refers to is not a cube map texture.

GL_INVALID_OPERATION is generated by glGetnTexImage if level is less than 0.

GL_INVALID_VALUE is generated if level is greater than log 2 ⁡ max, where max is the returned value of GL_MAX_TEXTURE_SIZE.

GL_INVALID_VALUE is generated if level is non-zero and the effective target is GL_TEXTURE_RECTANGLE.

GL_INVALID_ENUM is generated if format or type is not an accepted value.

GL_INVALID_OPERATION is generated if type is one of GL_UNSIGNED_BYTE_3_3_2, GL_UNSIGNED_BYTE_2_3_3_REV, GL_UNSIGNED_SHORT_5_6_5, GL_UNSIGNED_SHORT_5_6_5_REV, or GL_UNSIGNED_INT_10F_11F_11F_REV and format is not GL_RGB.

GL_INVALID_OPERATION is generated if type is one of GL_UNSIGNED_SHORT_4_4_4_4, GL_UNSIGNED_SHORT_4_4_4_4_REV, GL_UNSIGNED_SHORT_5_5_5_1, GL_UNSIGNED_SHORT_1_5_5_5_REV, GL_UNSIGNED_INT_8_8_8_8, GL_UNSIGNED_INT_8_8_8_8_REV, GL_UNSIGNED_INT_10_10_10_2, GL_UNSIGNED_INT_2_10_10_10_REV, or GL_UNSIGNED_INT_5_9_9_9_REV and format is neither GL_RGBA or GL_BGRA.

GL_INVALID_OPERATION is generated if format is GL_STENCIL_INDEX and the base internal format is not GL_STENCIL_INDEX or GL_DEPTH_STENCIL.

GL_INVALID_OPERATION is generated if a non-zero buffer object name is bound to the GL_PIXEL_PACK_BUFFER target and the buffer object's data store is currently mapped.

GL_INVALID_OPERATION is generated if a non-zero buffer object name is bound to the GL_PIXEL_PACK_BUFFER target and the data would be packed to the buffer object such that the memory writes required would exceed the data store size.

GL_INVALID_OPERATION is generated if a non-zero buffer object name is bound to the GL_PIXEL_PACK_BUFFER target and pixels is not evenly divisible into the number of bytes needed to store in memory a datum indicated by type.

GL_INVALID_OPERATION is generated by glGetTextureImage and glGetnTexImage if the buffer size required to store the requested data is greater than bufSize.
