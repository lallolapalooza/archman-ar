الاسم

glProgramParameter - تحديد معامل لكائن البرنامج

مواصفات C

void glProgramParameteri(GLuint program, GLenum pname, GLint value);

المعاملات

program

يحدد اسم كائن البرنامج الذي سيتم تعديل معامل له.

pname

يحدد اسم المعامل الذي سيتم تعديله.

value

يحدد القيمة الجديدة للمعامل المحدد بواسطة pname لـ program.

الوصف

glProgramParameter يحدد قيمة جديدة للمعامل المسمى pname لكائن البرنامج program.

إذا كان pname هو GL_PROGRAM_BINARY_RETRIEVABLE_HINT، يجب أن تكون value إما GL_FALSE أو GL_TRUE للإشارة إلى التنفيذ بنية التطبيق في استرداد التمثيل الثنائي للبرنامج باستخدام glGetProgramBinary(). قد يستخدم التنفيذ هذه المعلومات لتخزين المعلومات التي قد تكون مفيدة للاستعلام المستقبلي عن البرنامج الثنائي. يوصى بتعيين GL_PROGRAM_BINARY_RETRIEVABLE_HINT للبرنامج إلى GL_TRUE قبل استدعاء glLinkProgram()، واستخدام البرنامج في وقت التشغيل إذا كان سيتم استرداد الثنائي لاحقًا.

إذا كان pname هو GL_PROGRAM_SEPARABLE، يجب أن تكون value إما GL_TRUE أو GL_FALSE وتشير إلى ما إذا كان يمكن ربط program بمراحل خط أنابيب فردية عبر glUseProgramStages(). يجب تعيين معامل GL_PROGRAM_SEPARABLE للبرنامج إلى GL_TRUE قبل استدعاء glLinkProgram() لكي يمكن استخدامه مع كائن خط أنابيب البرنامج. الحالة الأولية لـ GL_PROGRAM_SEPARABLE هي GL_FALSE.

الأخطاء

يتم إنشاء GL_INVALID_OPERATION إذا لم يكن program اسمًا لكائن برنامج موجود.

يتم إنشاء GL_INVALID_ENUM إذا لم يكن pname أحد القيم المقبولة.

يتم إنشاء GL_INVALID_VALUE إذا لم تكن value قيمة صالحة للمعامل المسمى بواسطة pname.
