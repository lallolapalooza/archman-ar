glab-config-edit(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-config-edit - يفتح ملف إعدادات glab.

ملخص

glab config edit [علامات]

الوصف

يفتح ملف إعدادات glab. يستخدم الأمر الترتيب التالي عند اختيار المحرر المراد استخدامه:

1.
الحقل 'glab_editor' في ملف الإعدادات
2.
متغير البيئة 'VISUAL'
3.
متغير البيئة 'EDITOR'

خيارات

-l, --local[=false] افتح ملف '.git/glab-cli/config.yml' بدلاً من ملف الإعدادات العام '~/.config/glab-cli/config.yml'.

خيارات موروثة من الأوامر الأصل

-h, --help[=false] عرض المساعدة لهذا الأمر.

مثال

افتح ملف الإعدادات بالمحرر الافتراضي
- glab config edit
افتح ملف الإعدادات باستخدام vim
- EDITOR=vim glab config edit
قم بتعيين vim ليتم استخدامه لجميع استدعاءات 'glab config edit' المستقبلية
- glab config set editor vim
- glab config edit
افتح ملف الإعدادات المحلي بالمحرر الافتراضي
- glab config edit -l
