glUniformMatrix2x3fv

OpenGL GLSL Functions

NAME

glUniformMatrix2x3fv

set the value of a uniform variable

C SPECIFICATION

void glUniformMatrix2x3fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);

PARAMETERS

location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of uniform variables to be modified.
transpose
Specifies whether to transpose the matrix or matrices. Must be GL_FALSE.
value
Specifies a pointer to an array of count matrices to be downloaded to the specified uniform variable.

DESCRIPTION

glUniformMatrix2x3fv sets the value of a single row-major array of 2-column, 3-row matrices specified by the uniform variable in active program associated with loc. The transformation from OpenGL’s fixed-function pipeline matrix components to the uniform variable’s components is determined by transpose.

If transpose is GL_TRUE, then each matrix in value is transposed.

If transpose is GL_FALSE, then each matrix in value is not transposed.

The matrices are taken from the array value. Each matrix is treated as a column-major array of 2x3 matrices. count matrices are passed.

If location is not valid, or if the uniform variable indicated by location is not of type `mat2x3` or `mat2x3[]`, then GL_INVALID_OPERATION is generated.

If transpose is not GL_FALSE, then GL_INVALID_VALUE is generated.

If an error is generated, the uniform variable specified by location will not be modified.

NOTES

If the currently active program object is not zero, and if the uniform variable specified by location is not able to be modified, then GL_INVALID_OPERATION is generated.

In order for the command to execute, location must be a uniform variable location that was previously returned by glGetUniformLocation for the active program object.

The uniform variable can be either a single matrix or an array of matrices. If it is an array, then count indicates how many matrices in the array are to be modified. count can be greater than 1 only if the uniform variable is an array of matrices.

The matrices are specified in column-major order. The transpose parameter, when GL_TRUE, indicates that the matrices are to be transposed before they are loaded into the uniform variable. However, for glUniformMatrix2x3fv, transpose must be GL_FALSE.

ERRORS

GL_INVALID_OPERATION is generated if location is not a valid uniform location for the active program object, or if the uniform variable cannot be modified. GL_INVALID_VALUE is generated if transpose is not GL_FALSE.

ASSOCIATED GETS

glGetActiveUniform(), glGetUniformLocation(), glGetUniformfv()
