glab-issue-view(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-issue-view - عرض العنوان والمحتوى ومعلومات أخرى حول مشكلة.

الملخص

glab issue view [علامات]

الوصف

عرض العنوان والمحتوى ومعلومات أخرى حول مشكلة.

خيارات

-c, --comments[=false] عرض تعليقات وأنشطة المشكلة.

-F, --output="text" تنسيق الإخراج كـ: text, json.

-p, --page=1 رقم الصفحة.

-P, --per-page=20 عدد العناصر المدرجة في كل صفحة.

-s, --system-logs[=false] عرض أنشطة وسجلات النظام.

-w, --web[=false] فتح المشكلة في المتصفح. يستخدم المتصفح الافتراضي، أو المتصفح المحدد في متغير $BROWSER.

خيارات موروثة من أوامر رئيسية

-h, --help[=false] عرض المساعدة لهذا الأمر.

-R, --repo="" تحديد مستودع آخر. يمكن استخدام تنسيق OWNER/REPO أو GROUP/NAMESPACE/REPO. يقبل أيضًا عنوان URL كامل أو عنوان URL لـ Git.

مثال

$ glab issue view 123
$ glab issue show 123
$ glab issue view --web 123
$ glab issue view --comments 123
$ glab issue view https://gitlab.com/NAMESPACE/REPO/-/issues/123
