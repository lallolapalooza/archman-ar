يجب أن تكون max_lines إما رقمًا موجبًا **>= 0**، مما يحدد حدًا أعلى لعدد الأسطر في المخزن المؤقت، أو **-1** لإلغاء أي حد تم تحديده مسبقًا. عند تطبيق حد، يتم الاحتفاظ فقط بأحدث **max_lines** سطرًا تم إلحاقها في المخزن المؤقت. يتم تجاهل الأسطر الأقدم.

لتجاهل الأسطر من مخزن سجلات الوصول، استخدم الدالة **gl_clear_history()**. 

  void gl_clear_history(GetLine *gl, int all_groups);

يخبر الوسيط **all_groups** الدالة ما إذا كان سيتم حذف الأسطر المرتبطة بمجموعة السجلات الحالية فقط (راجع **gl_group_history()**)، أو جميع أسطر السجلات في المخزن المؤقت.

تسمح الدالة **gl_toggle_history()** بتبديل سجلات الوصول وتشغيلها وإيقافها دون فقدان المحتويات الحالية لقائمة سجلات الوصول.

  void gl_toggle_history(GetLine *gl, int enable);

يؤدي تعيين الوسيط **enable** إلى 0 إلى إيقاف آلية سجلات الوصول، وتعيينه إلى 1 يعيد تشغيلها. عند إيقاف تشغيل سجلات الوصول، لن تتم إضافة أسطر جديدة إلى قائمة سجلات الوصول، وستعمل روابط المفاتيح الخاصة بالبحث في السجلات كما لو لم يكن هناك شيء في مخزن سجلات الوصول.

الاستعلام عن معلومات السجلات

يمكن الاستعلام عن الحالة المهيأة لقائمة سجلات الوصول باستخدام الدالة **gl_history_state()**. 

  typedef struct {
    int enabled;     /* True if history is enabled */
    unsigned group;  /* The current history group */
    int max_lines;   /* The current upper limit on the */
                     /*  number of lines in the history */
                     /*  list, or -1 if unlimited. */
  } GlHistoryState;
  void gl_state_of_history(GetLine *gl,
                           GlHistoryState *state);

عند العودة، يتم تسجيل معلومات الحالة في المتغير المشار إليه بواسطة الوسيط **state**.

تُرجع الدالة **gl_range_of_history()** عدد ونطاق الأسطر في قائمة سجلات الوصول.

typedef struct {
  unsigned long oldest;  /* The sequential entry number */
                         /*  of the oldest line in the */
                         /*  history list. */
  unsigned long newest;  /* The sequential entry number */
                         /*  of the newest line in the */
                         /*  history list. */
  int nlines;            /* The number of lines in the */
                         /*  history list. */
} GlHistoryRange;
void gl_range_of_history(GetLine *gl, GlHistoryRange *range);

يتم تسجيل قيم الإرجاع في المتغير المشار إليه بواسطة الوسيط **range**. إذا كان عضو **nlines** في هذا الهيكل أكبر من الصفر، فإن الأعضاء **oldest** و **newest** يبلغان عن نطاق الأسطر في القائمة، و **newest=oldest+nlines-1**. بخلاف ذلك، يكون كلاهما صفرًا.

تُرجع الدالة **gl_size_of_history()** الحجم الإجمالي لمخزن سجلات الوصول والمقدار الذي يشغله المخزن حاليًا.

  typedef struct {
    size_t size;      /* The size of the history buffer */
                      /*  (bytes). */
    size_t used;      /* The number of bytes of the */
                      /*  history buffer that are */
                      /*  currently occupied. */
  } GlHistorySize;
  void gl_size_of_history(GetLine *gl, GlHistorySize *size);

عند العودة، يتم تسجيل معلومات الحجم في المتغير المشار إليه بواسطة الوسيط **size**.

تغيير الطرفيات

تفترض دالة البناء **new_GetLine()** أن الإدخال سيتم قراءته من **stdin**، والإخراج سيتم كتابته إلى **stdout**. تسمح الدالة التالية بالتبديل إلى تدفقات إدخال وإخراج مختلفة.

  int gl_change_terminal(GetLine *gl, FILE *input_fp,
                         FILE *output_fp, const char *term);

الوسيط **gl** هو الكائن الذي تم إرجاعه بواسطة **new_GetLine()**. يحدد الوسيط **input_fp** التدفق الذي سيتم القراءة منه، ويحدد الوسيط **output_fp** التدفق الذي سيتم الكتابة إليه. فقط إذا كان كلاهما يشير إلى طرفية، سيتم تمكين إدخال الطرفية التفاعلي. بخلاف ذلك، ستستدعي **gl_get_line()** ببساطة **fgets()** لقراءة إدخال الأمر. إذا كان كلا التدفقين يشيران إلى طرفية، فيجب أن يشيروا إلى نفس الطرفية، ويجب تحديد نوع هذه الطرفية عبر الوسيط **term**. يتم البحث عن قيمة الوسيط **term** في قاعدة بيانات معلومات الطرفية (terminfo أو termcap)، لتحديد تسلسلات التحكم الخاصة التي ستكون مطلوبة للتحكم في جوانب مختلفة من الطرفية. على سبيل المثال، تمرر **new_GetLine()** قيمة إرجاع **getenv("TERM")** في هذا الوسيط. لاحظ أنه إذا كان تدفق واحد أو كلا تدفقات **input_fp** و **output_fp** لا يشيران إلى طرفية، فمن القانوني تمرير **NULL** بدلاً من نوع الطرفية.

لاحظ أنه إذا كنت تريد تمرير واصفات الملفات إلى **gl_change_terminal()**، فيمكنك القيام بذلك عن طريق إنشاء أغلفة تدفق stdio باستخدام دالة POSIX **fdopen()**.

معالجة الأحداث الخارجية

بشكل افتراضي، لا تُرجع **gl_get_line()** حتى يتم إدخال سطر إدخال كامل بواسطة المستخدم، أو يحدث خطأ. في البرامج التي تحتاج إلى مراقبة الإدخال / الإخراج من مصادر أخرى غير الطرفية، هناك خياران.

  1. استخدام الدوال الموضحة في صفحة الدليل
     gl_io_mode(3) لتبديل
     **gl_get_line()** إلى وضع الخادم غير الحاجب. في هذا الوضع،
     تصبح **gl_get_line()** دالة تحرير سطر تدريجية غير حاجبة يمكن استدعاؤها بأمان من
     حلقة أحداث خارجية. على الرغم من أن هذه طريقة متعددة الاستخدامات للغاية، إلا أنها تتضمن تولي بعض
     المسؤوليات التي تؤديها **gl_get_line()** عادةً خلف الكواليس.
  2. بينما تنتظر **gl_get_line()** إدخال لوحة المفاتيح من المستخدم، يمكنك أن تطلب منها أيضًا مراقبة النشاط على واصفات ملفات اعتباطية، مثل
     مقابس الشبكة، الأنابيب، إلخ، وجعلها تستدعي دوال من اختيارك عند رؤية النشاط. يعمل هذا على أي نظام لديه استدعاء النظام
     **select()**، وهو معظم، إن لم يكن كل، نكهات يونكس.

يتضمن تسجيل واصف ملف لمراقبته بواسطة **gl_get_line()** استدعاء الدالة **gl_watch_fd()**. 

  int gl_watch_fd(GetLine *gl, int fd, GlFdEvent event,
                  GlFdEventFn *callback, void *data);

إذا أعادت هذه القيمة قيمة غير صفرية، فهذا يعني إما أن وسائطك غير صالحة، أو أن هذه الميزة غير مدعومة على النظام المضيف.

الوسيط **fd** هو واصف الملف المراد مراقبته. يحدد الوسيط **event** نوع النشاط الذي يهم، ويتم اختياره من القيم المحصورة التالية:

  GLFD_READ   -  مراقبة وصول البيانات للقراءة.
  GLFD_WRITE  -  مراقبة القدرة على الكتابة إلى واصف الملف
                 بدون حجب.
  GLFD_URGENT -  مراقبة وصول البيانات العاجلة
                 خارج النطاق على واصف الملف.

الوسيط **callback** هو الدالة التي سيتم استدعاؤها عند رؤية النشاط المحدد. يجب تعريفها باستخدام الماكرو التالي، المحدد في libtecla.h.

  #define GL_FD_EVENT_FN(fn) GlFdStatus (fn)(GetLine *gl, \
                                      void *data, int fd, \
                                      GlFdEvent event)

يتم تمرير الوسيط **data** لدالة **gl_watch_fd()** إلى دالة الاستدعاء لاستخدامها الخاص، ويمكن أن يشير إلى أي شيء تريده، بما في ذلك **NULL**. يتم أيضًا تمرير واصف الملف ووسيط الحدث إلى دالة الاستدعاء، وهذا يسمح نظريًا بتسجيل نفس دالة الاستدعاء لأكثر من نوع حدث واحد و/أو أكثر من واصف ملف واحد. يجب أن تكون قيمة الإرجاع لدالة الاستدعاء واحدة من القيم التالية.

  GLFD_ABORT    -  إخبار gl_get_line() بالإجهاض. عندما يحدث هذا،
                   تُرجع **gl_get_line()**
                   **NULL**، واستدعاء لاحق لـ
                   **gl_return_status()** سيعيد
                   **GLR_FDABORT**. لاحظ أنه إذا كان التطبيق يحتاج
                   **errno** دائمًا إلى قيمة ذات معنى عندما
                   تُرجع **gl_get_line()** **NULL**،
                   فيجب على دالة الاستدعاء تعيين
                   **errno** بشكل مناسب.
  GLFD_REFRESH  -  إعادة رسم سطر الإدخال ثم الاستمرار في
                   انتظار الإدخال. أرجع هذا إذا
                   قامت دالة الاستدعاء بالكتابة إلى الطرفية.
  GLFD_CONTINUE -  الاستمرار في انتظار الإدخال، دون
                   إعادة رسم السطر.

لاحظ أنه قبل استدعاء دالة الاستدعاء، تقوم **gl_get_line()** بحجب معظم الإشارات، وتترك معالجات الإشارات الخاصة بها مثبتة، لذا إذا كنت بحاجة إلى التقاط إشارة معينة، فستحتاج إلى تثبيت معالج إشارة خاص بك مؤقتًا، وإلغاء حظر الإشارة. تأكد من إعادة حظر الإشارة (إذا كانت محظورة في الأصل) واستعادة معالج الإشارة الأصلي، إن وجد، قبل العودة.

إذا احتاجت دالة الاستدعاء إلى القراءة أو الكتابة إلى الطرفية، فيجب عليها بشكل مثالي استدعاء **gl_normal_io(gl)** أولاً لتعليق تحرير السطر مؤقتًا. سيؤدي هذا إلى استعادة الطرفية إلى وضع الإدخال / الإخراج القانوني الحاجب، وتحريك المؤشر إلى بداية سطر طرفية جديد. لاحقًا، عند عودة دالة الاستدعاء، ستلاحظ **gl_get_line()** أنه تم استدعاء **gl_normal_io()**، وستعيد عرض سطر الإدخال وتستأنف التحرير. لاحظ أنه في هذه الحالة، تكون قيم الإرجاع **GLFD_REFRESH** و **GLFD_CONTINUE** متكافئة.

لدعم الحالات التي تستدعي فيها دالة الاستدعاء دالة طرف ثالث تكتب أحيانًا وبشكل غير متوقع إلى الطرفية، يتم إعادة تمكين التحويل التلقائي لـ **"0** إلى **"0** قبل استدعاء دالة الاستدعاء. إذا علمت دالة الاستدعاء أن دالة الطرف الثالث كتبت إلى الطرفية، فيجب عليها بعد ذلك إرجاع قيمة الإرجاع **GLFD_REFRESH**، لإخبار **gl_get_line()** بإعادة عرض سطر الإدخال.

لإزالة دالة استدعاء قمت بتسجيلها سابقًا لواصف ملف وحدث معينين، قم ببساطة باستدعاء **gl_watch_fd()** بنفس واصف الملف ووسيط **event**، ولكن مع وسيط **callback** بقيمة **0**. يتم تجاهل الوسيط **data** في هذه الحالة.
