الاسم

glGetBufferParameteriv, glGetBufferParameteri64v, glGetNamedBufferParameteriv, glGetNamedBufferParameteri64v - إرجاع معلمات كائن المخزن المؤقت

المواصفات C

void glGetBufferParameteriv(GLenum target, GLenum value, GLint * data);

void glGetBufferParameteri64v(GLenum target, GLenum value, GLint64 * data);

void glGetNamedBufferParameteriv(GLuint buffer, GLenum pname, GLint *params);

void glGetNamedBufferParameteri64v(GLuint buffer, GLenum pname, GLint64 *params);

المعلمات

target

يحدد الهدف الذي تم ربط كائن المخزن المؤقت به لـ glGetBufferParameteriv و glGetBufferParameteri64v. يجب أن يكون أحد أهداف ربط المخزن المؤقت في الجدول التالي:
هدف ربط المخزن المؤقت الغرض
GL_ARRAY_BUFFER سمات الرأس
GL_ATOMIC_COUNTER_BUFFER تخزين عدادات ذرية
GL_COPY_READ_BUFFER مصدر نسخ المخزن المؤقت
GL_COPY_WRITE_BUFFER وجهة نسخ المخزن المؤقت
GL_DISPATCH_INDIRECT_BUFFER أوامر إرسال غير مباشرة للحساب
GL_DRAW_INDIRECT_BUFFER معلمات أمر الرسم غير المباشر
GL_ELEMENT_ARRAY_BUFFER فهارس مصفوفة الرأس
GL_PIXEL_PACK_BUFFER هدف قراءة البكسل
GL_PIXEL_UNPACK_BUFFER مصدر بيانات النسيج
GL_QUERY_BUFFER مخزن مؤقت لنتائج الاستعلام
GL_SHADER_STORAGE_BUFFER تخزين للقراءة والكتابة للمظللات
GL_TEXTURE_BUFFER مخزن مؤقت لبيانات النسيج
GL_TRANSFORM_FEEDBACK_BUFFER مخزن مؤقت لتغذية التحويل
GL_UNIFORM_BUFFER تخزين كتل الموحدة

buffer

يحدد اسم كائن المخزن المؤقت لـ glGetNamedBufferParameteriv و glGetNamedBufferParameteri64v.

value

يحدد اسم معلمة كائن المخزن المؤقت للاستعلام عنها.

data

يُرجع المعلمة المطلوبة.

الوصف

ترجع هذه الدوال في data معلمة محددة لكائن المخزن المؤقت المحدد.

pname يحدد معلمة كائن مخزن مؤقت محددة، على النحو التالي:

GL_BUFFER_ACCESS

params تُرجع سياسة الوصول التي تم تعيينها أثناء تعيين كائن المخزن المؤقت (قيمة معلمة التعداد access التي تم تمريرها إلى glMapBuffer). إذا تم تعيين المخزن المؤقت باستخدام glMapBufferRange، يتم تحديد سياسة الوصول عن طريق ترجمة البتات في معلمة access تلك إلى أحد التعدادات المدعومة لـ glMapBuffer كما هو موضح في مواصفات OpenGL.

GL_BUFFER_ACCESS_FLAGS

params تُرجع سياسة الوصول التي تم تعيينها أثناء تعيين كائن المخزن المؤقت (قيمة حقل بت المعلمة access الذي تم تمريره إلى glMapBufferRange). إذا تم تعيين المخزن المؤقت باستخدام glMapBuffer، يتم تحديد سياسة الوصول عن طريق ترجمة التعدادات في معلمة access تلك إلى البتات المقابلة لـ glMapBufferRange كما هو موضح في مواصفات OpenGL. القيمة الابتدائية هي صفر.

GL_BUFFER_IMMUTABLE_STORAGE

params تُرجع علامة منطقية تشير إلى ما إذا كان كائن المخزن المؤقت غير قابل للتغيير. القيمة الابتدائية هي GL_FALSE.

GL_BUFFER_MAPPED

params تُرجع علامة تشير إلى ما إذا كان كائن المخزن المؤقت معينًا حاليًا. القيمة الابتدائية هي GL_FALSE.

GL_BUFFER_MAP_LENGTH

params تُرجع طول التعيين في كائن المخزن المؤقت الذي تم إنشاؤه باستخدام glMapBuffer*. يجب استخدام الإصدارات i64v لهذه الاستعلامات لهذه المعلمة. القيمة الابتدائية هي صفر.

GL_BUFFER_MAP_OFFSET

params تُرجع إزاحة التعيين في كائن المخزن المؤقت الذي تم إنشاؤه باستخدام glMapBuffer*. يجب استخدام الإصدارات i64v لهذه الاستعلامات لهذه المعلمة. القيمة الابتدائية هي صفر.

GL_BUFFER_SIZE

params تُرجع حجم كائن المخزن المؤقت، مقاسًا بالبايت. القيمة الابتدائية هي 0.

GL_BUFFER_STORAGE_FLAGS

params تُرجع حقل بت يشير إلى علامات التخزين لكائن المخزن المؤقت. إذا كان كائن المخزن المؤقت غير قابل للتغيير، فإن القيمة المرتجعة ستكون تلك المحددة عند إنشاء مخزن البيانات باستخدام glBufferStorage. إذا تم إنشاء مخزن البيانات باستخدام glBufferData، فستكون القيمة GL_MAP_READ_BIT | GL_MAP_WRITE_BIT | GL_DYNAMIC_STORAGE_BIT | GL_MAP_WRITE_BIT. القيمة الابتدائية هي صفر.

GL_BUFFER_USAGE

params تُرجع نمط استخدام كائن المخزن المؤقت. القيمة الابتدائية هي GL_STATIC_DRAW.

ملاحظات

إذا تم إنشاء خطأ، فلن يتم إجراء أي تغيير على محتويات data.

هدف GL_ATOMIC_COUNTER_BUFFER متاح فقط إذا كان إصدار GL 4.2 أو أعلى.

هدفا GL_DISPATCH_INDIRECT_BUFFER و GL_SHADER_STORAGE_BUFFER متاحان فقط إذا كان إصدار GL 4.3 أو أعلى.

هدف GL_QUERY_BUFFER متاح فقط إذا كان إصدار GL 4.4 أو أعلى.

الأخطاء

يتم إنشاء GL_INVALID_ENUM بواسطة glGetBufferParameter* إذا لم يكن target أحد أهداف المخزن المؤقت المقبولة.

يتم إنشاء GL_INVALID_OPERATION بواسطة glGetBufferParameter* إذا تم ربط الصفر بالهدف target.

يتم إنشاء GL_INVALID_OPERATION بواسطة glGetNamedBufferParameter* إذا لم يكن buffer اسم كائن مخزن مؤقت موجود.

يتم إنشاء GL_INVALID_ENUM إذا لم يكن pname أحد أسماء معلمات كائن المخزن المؤقت الموضحة أعلاه.

NAME

glGetBufferParameteri64v - return parameters of a buffer object

C SPECIFICATION

void glGetBufferParameteri64v(GLenum target, GLenum pname, GLint64 *data);

PARAMETERS

target

Specifies the target buffer object. The symbolic constant must be one of GL_ARRAY_BUFFER, GL_ATOMIC_COUNTER_BUFFER, GL_COPY_READ_BUFFER, GL_COPY_WRITE_BUFFER, GL_DRAW_INDIRECT_BUFFER, GL_ELEMENT_ARRAY_BUFFER, GL_PIXEL_PACK_BUFFER, GL_PIXEL_UNPACK_BUFFER, GL_QUERY_BUFFER, GL_SHADER_STORAGE_BUFFER, GL_TEXTURE_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, or GL_UNIFORM_BUFFER.

pname

Specifies the symbolic name of the buffer parameter to be returned. The symbolic constant must be one of:
GL_BUFFER_ACCESS_FLAGS
Returns a bitwise OR of GL_MAP_READ_BIT, GL_MAP_WRITE_BIT, and/or GL_MAP_FLUSH_EXPLICIT_BIT, indicating the access possibilities for the buffer object's mapped region.
GL_BUFFER_ACCESS
Returns the current access modes for the buffer object's mapped region. This is a bitwise OR of GL_MAP_READ_BIT, GL_MAP_WRITE_BIT, and/or GL_MAP_PERSISTENT_BIT.
GL_BUFFER_BINDING
Returns the buffer object bound to the specified target.
GL_BUFFER_DATA_SIZE
Returns the size, in basic memory units, of the buffer object's currently bound buffer data.
GL_BUFFER_MAP_LENGTH
Returns the length of the currently mapped region of the buffer object.
GL_BUFFER_MAP_OFFSET
Returns the offset of the currently mapped region of the buffer object.
GL_BUFFER_SIZE
Returns the size, in basic memory units, of the buffer object's currently bound buffer data.
GL_DYNAMIC_STORAGE_BIT
Returns a boolean value indicating if the buffer was created with the GL_DYNAMIC_STORAGE_BIT flag.
GL_MAP_COHERENT_BIT
Returns a boolean value indicating if the buffer was created with the GL_MAP_COHERENT_BIT flag.
GL_MAP_FLUSH_EXPLICIT_BIT
Returns a boolean value indicating if the buffer was created with the GL_MAP_FLUSH_EXPLICIT_BIT flag.
GL_MAP_READ_BIT
Returns a boolean value indicating if the buffer was created with the GL_MAP_READ_BIT flag.
GL_MAP_WRITE_BIT
Returns a boolean value indicating if the buffer was created with the GL_MAP_WRITE_BIT flag.
GL_NEVER_FREE_MEMORY_BIT
Returns a boolean value indicating if the buffer was created with the GL_NEVER_FREE_MEMORY_BIT flag.
GL_QUERY_BUFFER_BARRIER_BIT
Returns a boolean value indicating if the buffer was created with the GL_QUERY_BUFFER_BARRIER_BIT flag.
GL_RELEASE_ARRAY_INDEX
Returns a boolean value indicating if the buffer was created with the GL_RELEASE_ARRAY_INDEX flag.
GL_CLIENT_STORAGE_BIT
Returns a boolean value indicating if the buffer was created with the GL_CLIENT_STORAGE_BIT flag.
GL_CLEAR_BUFFER_BIT
Returns a boolean value indicating if the buffer was created with the GL_CLEAR_BUFFER_BIT flag.

data

Specifies the address of a 64-bit integer, or array of 64-bit integers, in which the requested data is written.

DESCRIPTION

glGetBufferParameteri64v returns information about the specified buffer object. target specifies the target buffer object. pname specifies the particular buffer object parameter to be returned. If the buffer object corresponding to target is not a valid buffer object, an GL_INVALID_OPERATION is generated.

If pname is GL_BUFFER_SIZE or GL_BUFFER_DATA_SIZE, then data is a pointer to a 64-bit integer that receives the size, in basic memory units, of the buffer object's currently bound buffer data.

If pname is GL_BUFFER_ACCESS_FLAGS, then data is a pointer to a 64-bit integer that receives a bitwise OR of GL_MAP_READ_BIT, GL_MAP_WRITE_BIT, and/or GL_MAP_FLUSH_EXPLICIT_BIT, indicating the access possibilities for the buffer object's mapped region.

If pname is GL_BUFFER_ACCESS, then data is a pointer to a 64-bit integer that receives the current access modes for the buffer object's mapped region. This is a bitwise OR of GL_MAP_READ_BIT, GL_MAP_WRITE_BIT, and/or GL_MAP_PERSISTENT_BIT.

If pname is GL_BUFFER_MAP_LENGTH, then data is a pointer to a 64-bit integer that receives the length of the currently mapped region of the buffer object.

If pname is GL_BUFFER_MAP_OFFSET, then data is a pointer to a 64-bit integer that receives the offset of the currently mapped region of the buffer object.

If pname is one of the other buffer creation flags (e.g. GL_DYNAMIC_STORAGE_BIT, GL_CLIENT_STORAGE_BIT, etc.), then data is a pointer to a 64-bit integer that receives a boolean value indicating if the buffer was created with that flag.

A buffer object is created using glGenBuffers and glBindBuffer. Then, buffer data are created and initialized using glBufferData, glBufferSubData, or glBufferStorage.

The parameter queries are available in OpenGL 4.5 and later.

NOTES

The symbolic constants for pname are defined in <GL/gl.h>.

The 64-bit types are only supported on systems where `long long` is 64 bits wide.

If a buffer object has not been defined using glBufferData or glBufferStorage, then glGetBufferParameteriv and glGetBufferParameteri64v will return 0 for GL_BUFFER_SIZE and GL_BUFFER_DATA_SIZE.

If the buffer object is not mapped, then glGetBufferParameteriv and glGetBufferParameteri64v will return 0 for GL_BUFFER_MAP_LENGTH and GL_BUFFER_MAP_OFFSET.

ERRORS

GL_INVALID_OPERATION is generated if glGetError is called when no buffer object is associated with target.

GL_INVALID_ENUM is generated if target or pname is not an accepted value.
