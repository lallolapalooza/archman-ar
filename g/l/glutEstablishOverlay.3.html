glutEstablishOverlay(3)

الحزمة: freeglut

التراخيص: X11

glutEstablishOverlay(3) freeglut glutEstablishOverlay(3)

الاسم

glutEstablishOverlay - تنشئ تراكبًا (إذا أمكن) للنافذة الحالية.

تحذير

لم يتم تنفيذه بعد في freeglut.

الصيغة

void glutEstablishOverlay(void);

الوصف

تقوم glutEstablishOverlay بإنشاء تراكب (إذا كان ممكنًا) للنافذة الحالية. يتم تحديد وضع العرض المطلوب للتراكب بواسطة وضع العرض الأولي. يمكن استدعاء glutLayerGet(GLUT_OVERLAY_POSSIBLE) لتحديد ما إذا كان التراكب ممكنًا للنافذة الحالية مع وضع العرض الأولي الحالي. لا تحاول إنشاء تراكب عندما لا يكون ذلك ممكنًا؛ سيقوم GLUT بإنهاء البرنامج.

إذا تم استدعاء glutEstablishOverlay عندما يكون هناك تراكب موجود بالفعل، فسيتم أولاً إزالة التراكب الحالي، ثم يتم إنشاء تراكب جديد. يتم تجاهل حالة سياق OpenGL للتراكب القديم.

يتم عرض حالة العرض الأولية للتراكب، ومع ذلك لا يتم عرض التراكب فعليًا إلا إذا كانت نافذة التراكب معروضة.

بشكل ضمني، تتغير طبقة النافذة قيد الاستخدام إلى التراكب مباشرة بعد إنشاء التراكب.

مثال

إن إنشاء تراكب يتطلب بعض الجهد، ولكنه سهل بمجرد التعود عليه. إليك مثال:

  int overlaySupport;
  int transparent, red, white;
  glutInitDisplayMode(GLUT_SINGLE | GLUT_INDEX);
  overlaySupport = glutLayerGet(GLUT_OVERLAY_POSSIBLE);
  if (overlaySupport) {
    glutEstablishOverlay();
    glutHideOverlay();
    transparent = glutLayerGet(GLUT_TRANSPARENT_INDEX);
    glClearIndex(transparent);
    red = (transparent + 1) % glutGet(GLUT_WINDOW_COLORMAP_SIZE);
    white = (transparent + 2) % glutGet(GLUT_WINDOW_COLORMAP_SIZE);
    glutSetColor(red, 1.0, 0.0, 0.0);  /* أحمر. */
    glutSetColor(white, 1.0, 1.0, 1.0);  /* أبيض. */
    glutOverlayDisplayFunc(redrawOverlay);
    glutReshapeFunc(reshape);
  } else {
    printf("آسف، لا يوجد تراكب رائع (جرب محطة عمل SGI)!0);
  }

إذا قمت بإعداد تراكب وقمت بتثبيت دالة استدعاء إعادة التشكيل، فأنت بحاجة إلى تحديث منافذ العرض وربما مصفوفات الإسقاط لكل من المستوى العادي والتراكب. على سبيل المثال، قد تبدو دالة استدعاء إعادة التشكيل الخاصة بك كالتالي:

  void
  reshape(int w, int h)
  {
    if (overlaySupport) {
      glutUseLayer(GLUT_OVERLAY);
      /* إعداد التراكب ليكون له نظام إحداثيات بأسلوب X. */
      glViewport(0, 0, w, h);
      glMatrixMode(GL_PROJECTION);
      glLoadIdentity();
      gluOrtho2D(0, w, 0, h);
      glScalef(1, -1, 1);
      glTranslatef(0, -h, 0);
      glMatrixMode(GL_MODELVIEW);
      glutUseLayer(GLUT_NORMAL);
    }
    glViewport(0, 0, w, h);
  }

راجع صفحة دليل glutOverlayDisplayFunc للحصول على مثال يوضح طريقة لكتابة دالة استدعاء عرض التراكب الخاصة بك.

ملاحظات التنفيذ X

يستخدم GLUT لـ X اصطلاح SERVER_OVERLAY_VISUALS لتحديد ما إذا كانت مرئيات التراكب متاحة. بينما يسمح الاصطلاح بتراكبات غير شفافة (بدون شفافية) وتراكبات مع تحديد الشفافية كقناع بت، فإن إدارة التراكب في GLUT توفر فقط الوصول إلى تراكبات البكسل الشفافة.

حتى يتم فهم تراكبات RGBA بشكل أفضل، يدعم GLUT فقط تراكبات فهرس الألوان.
