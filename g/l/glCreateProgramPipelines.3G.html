الاسم

glCreateProgramPipelines - إنشاء كائنات خطوط أنابيب البرامج

مواصفات C

void glCreateProgramPipelines(GLsizei n, GLuint *pipelines);

المعلمات

n

عدد كائنات خطوط أنابيب البرامج المراد إنشاؤها.

pipelines

يحدد مصفوفة يتم فيها تخزين أسماء كائنات خطوط أنابيب البرامج الجديدة.

الوصف

glCreateProgramPipelines تُرجع n أسماء خطوط أنابيب برامج غير مستخدمة سابقًا في pipelines، ويمثل كل منها كائن خط أنابيب برنامج جديد تم تهيئته إلى الحالة الافتراضية.

الأخطاء

يتم إنشاء GL_INVALID_VALUE إذا كانت n سالبة.
