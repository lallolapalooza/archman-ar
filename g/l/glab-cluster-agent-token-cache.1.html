الاسم

glab-cluster-agent-token-cache - إدارة رموز GitLab Agent المخزنة مؤقتًا.

ملخص

glab cluster agent token-cache [علامات]

الوصف

إدارة رموز GitLab Agent المخزنة مؤقتًا التي تم إنشاؤها بواسطة "glab cluster agent get-token".

تسمح لك مجموعة الأوامر هذه بإدراج رموز العميل المخزنة مؤقتًا محليًا في مخزن المفاتيح وذاكرة التخزين المؤقت لنظام الملفات ومسحها.

تخزين ذاكرة التخزين المؤقت

يقوم GitLab CLI بتخزين رموز العميل مؤقتًا في موقعين:

1.
مخزن المفاتيح - يستخدم مخزن المفاتيح للنظام (مدير بيانات اعتماد Windows، حافظة مفاتيح macOS، خدمة الأسرار في Linux)
2.
نظام الملفات - يخزن الرموز في دليل ذاكرة التخزين المؤقت للمستخدم كملفات مشفرة

تعمل ذاكرة التخزين المؤقت على تحسين الأداء عن طريق تجنب الحاجة إلى إنشاء رموز جديدة لكل عملية kubectl عند استخدام "glab cluster agent update-kubeconfig".

تنسيق مفتاح ذاكرة التخزين المؤقت

يتم تخزين الرموز المخزنة مؤقتًا باستخدام تنسيق مفتاح يتضمن:

  • عنوان URL لمثيل GitLab المشفر بـ Base64
  • معرف العميل

يضمن هذا عزل الرموز بشكل صحيح حسب مثيل GitLab والعميل.

الخيارات الموروثة من الأوامر الأصل

-h, --help[=false] عرض المساعدة لهذا الأمر.

-R, --repo="" حدد مستودعًا آخر. يمكن استخدام تنسيق OWNER/REPO أو GROUP/NAMESPACE/REPO. يقبل أيضًا عنوان URL كامل أو عنوان URL لـ Git.
