الاسم

glClipControl - التحكم في سلوك إحداثيات القص إلى إحداثيات النافذة

مواصفات C

void glClipControl(GLenum origin, GLenum depth);

المعلمات

origin

يحدد أصل التحكم في القص. يجب أن يكون أحد الخيارات التالية: GL_LOWER_LEFT أو GL_UPPER_LEFT.

depth

يحدد وضع عمق التحكم في القص. يجب أن يكون أحد الخيارات التالية: GL_NEGATIVE_ONE_TO_ONE أو GL_ZERO_TO_ONE.

الوصف

glClipControl يتحكم في سلوك حجم القص وسلوك تحويل إحداثيات القص إلى إحداثيات النافذة.

يتم تعريف حجم العرض بواسطة $$z_{min} \leq z_c \leq w_c$$ حيث $z_{min} = -w_c$ عندما يكون depth هو GL_NEGATIVE_ONE_TO_ONE، و $z_{min} = 0$ عندما يكون depth هو GL_ZERO_TO_ONE.

يتم إعطاء إحداثيات الجهاز المعيارية $y_d$ بواسطة $$y_d = { { f \times y_c } \over w_c }$$ حيث $f = 1$ عندما يكون origin هو GL_LOWER_LEFT، و $f = -1$ عندما يكون origin هو GL_UPPER_LEFT.

يتم إعطاء إحداثيات النافذة $z_w$ بواسطة $$z_w = s \times z_d + b$$ حيث $s = { { f - n } \over 2 }$ و $b = { {n + f} \over 2 }$ عندما يكون depth هو GL_NEGATIVE_ONE_TO_ONE، و $s = f - n$ و $b = n$ عندما يكون depth هو GL_ZERO_TO_ONE. $n$ و $f$ هما قيم نطاق العمق الأمامي والخلفي المحددة باستخدام glDepthRange().

أخيرًا، يتم عكس إشارة حساب مساحة المضلع المعرفة بواسطة gl_FrontFacing() لتحديد ما إذا كان المضلع أماميًا أو خلفيًا عند تحديد origin على GL_UPPER_LEFT.

ملاحظات

التعريف الافتراضي لحجم قص GL هو لـ origin بقيمة GL_LOWER_LEFT و depth بقيمة GL_NEGATIVE_ONE_TO_ONE.

origin بقيمة GL_UPPER_LEFT و depth بقيمة GL_ZERO_TO_ONE يتوافق مع تعريف حجم قص Direct3D.

origin بقيمة GL_UPPER_LEFT و depth بقيمة GL_NEGATIVE_ONE_TO_ONE يتوافق مع أصل الزاوية العلوية اليسرى لنظام إحداثيات النافذة في Microsoft Windows ونظام X Window.

هناك مناقشة مستفيضة حول استخدامات وعواقب إضافية لإعدادات حجم القص المختلفة في مواصفات امتداد GL_ARB_clip_control في سجل OpenGL على الرابط: http://www.opengl.org/registry/.

الأخطاء

يتم إنشاء خطأ GL_INVALID_ENUM إذا لم يكن origin GL_LOWER_LEFT أو GL_UPPER_LEFT.

يتم إنشاء خطأ GL_INVALID_ENUM إذا لم يكن depth GL_NEGATIVE_ONE_TO_ONE أو GL_ZERO_TO_ONE.
