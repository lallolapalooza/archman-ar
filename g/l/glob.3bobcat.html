glob.3bobcat

الحزمة: libbobcat

التراخيص: GPL

FBB::Glob(3bobcat) ملفات تطابق نمطًا FBB::Glob(3bobcat)

الاسم

FBB::Glob - غلاف حول glob(3) للعثور على ملفات تطابق نمطًا

الملخص

#include <bobcat/glob>
خيار الربط: -lbobcat

الوصف

الفئة FBB::Glob هي غلاف حول الدالة C glob(3). تُرجع قائمة بالملفات التي تطابق نمطًا معينًا تم تقديمه إلى مُنشئات FBB::Glob أو أعضائها.

اسم النطاق

FBB
جميع المُنشئات، الأعضاء، المعاملات، والمُعدِّلات المذكورة في صفحة الدليل هذه مُعرَّفة في نطاق الأسماء FBB.

التعدادات

Glob::Type:
هذا التعداد، وهو مطابق لتعداد Type الخاص بـ stat(3bobcat)، يُعرّف القيم التالية:

o
BLOCK_DEVICE (0060000): الكائن هو جهاز كتلة؛
o
CHARACTER_DEVICE (0020000): الكائن هو جهاز حرفي؛
o
DIRECTORY (0040000): الكائن هو دليل؛
o
FIFO (0010000): الكائن هو أنبوب مُسمى (قائمة انتظار)؛
o
REGULAR_FILE (0100000): الكائن هو ملف عادي؛
o
SOCKET (0140000): الكائن هو مقبس؛
o
SYMBOLIC_LINK (0120000): الكائن هو رابط رمزي؛
o
ANY: أي من الأنواع المذكورة أعلاه.

هذه القيم تُستخدم أيضًا بواسطة stat(2) و lstat(2). على الرغم من أنه يمكن دمجها باستخدام المعامل bitor، إلا أنها ليست قابلة للتمييز بشكل فريد عند دمجها. على سبيل المثال، قيمة CHARACTER_DEVICE | DIRECTORY تساوي قيمة BLOCK_DEVICE. من الممكن أيضًا دمج قيم Type في std::unordered_set، مما يتجنب الارتباك الذي قد ينجم عن استخدام المعامل bitor.

Glob::Flags:

o
NO_FLAG: تساوي 0، ويمكن استخدامها لتجنب الحاجة إلى تحديد 0. ليس لها استخدام آخر.
o
ERR: العودة عند أخطاء القراءة؛
o
MARK: إضافة شرطة مائلة إلى كل اسم.
o
NOSORT: لا تقم بفرز الأسماء.
o
NOESCAPE: الشرطات المائلة العكسية لا تُقتبس من رموز التعريف (metacharacters).
o
PERIOD: يمكن لرموز . الرائدة أن تتطابق مع رموز التعريف (أي، * و ?).
o
NOMATCH: عند تحديدها، لن تُطلق المُنشئات استثناءات عندما لا يتم العثور على ملفات تطابق أنماط glob الخاصة بها. بدلاً من ذلك، ستعود بشكل طبيعي، وسيعيد عضو Glob’s size() (انظر أدناه) القيمة 0.

Glob::Dots:

o
FIRST: سيتم إدراج أسماء الملفات التي تبدأ بنقطة أولاً. ضمن هذه المجموعة وفي المجموعة المتبقية، يتم الحفاظ على الترتيب النسبي.
o
DEFAULT: إرجاع أسماء الملفات كما تظهر في عملية globbing.

المُنشئات

o
Glob(std::string const &pattern = "*", int flags = PERIOD, Dots dots = FIRST):
هذا المُنشئ (الذي يمكن استخدامه أيضًا كمُنشئ افتراضي) يحدد جميع العناصر التي تطابق pattern.
يتم إطلاق استثناء Exception إذا لم يتمكن المُنشئ من إكمال مهامه بشكل صحيح.
يمكن تحديد عدة أعلام، مفصولة بمعامل bitor.
يكمل هذا المُنشئ مهمته بشكل صحيح إذا تم تحديد قيم Flag معروفة فقط وإذا عادت دالة glob(3) بدون أخطاء؛
o
Glob(Type type, std::string const &pattern = "*", int flags = PERIOD, Dots dots = FIRST):
يحدد هذا المُنشئ جميع العناصر لـ pattern عندما تكون أنواعها `elementType’ متساوية مع قيمة elementType & type. قد تتكون قيمة type المحددة من أي تركيبة مُدمجة باستخدام bitor من قيم التعداد المُعرفة بواسطة تعداد Type. لاحظ أن هذا قد ينتج عنه نتائج مربكة. على سبيل المثال، عند تحديد DIRECTORY، يتم أيضًا قبول العناصر التي هي BLOCK_DEVICEs أو SOCKETs. يمكن استخدام المُنشئ التالي لتجنب هذا الارتباك؛
o
Glob(std::unordered_set<Type> const &typeSet, std::string const &pattern = "*", int flags = PERIOD, Dots dots = FIRST):
يحدد هذا المُنشئ جميع العناصر لـ pattern عندما تكون أنواعها موجودة في typeSet. على عكس المُنشئ السابق، لكي يتم قبول عنصر، يجب أن تتطابق أنواعه تمامًا مع قيمة نوع في مجموعة typeSet.

تتوفر مُنشئات النسخ والتحريك (وأدوات التعيين).

المعاملات المُعاد تعريفها

o
char const *operator[](size_t idx) const:
يتم إرجاع العنصر في موضع الفهرس idx كسلسلة C. تُرجع سلسلة فارغة إذا كان idx يساوي أو يتجاوز size().

الدوال الأعضاء

o
size_t size() const:
يُرجع عدد العناصر التي تم اكتشافها؛
o
char const *const *begin() const:
يُرجع مؤشرًا إلى أول عنصر تم اكتشافه. يمكن استخدام هذا المؤشر في الخوارزميات العامة كمُكرر إخراج يدعم حساب المؤشرات؛
o
char const *const *end() const:
يُرجع مؤشرًا يتجاوز آخر عنصر تم اكتشافه. يمكن استخدام هذا المؤشر في الخوارزميات العامة كمُكرر إخراج يدعم حساب المؤشرات؛
o
void swap(Glob &other):
يُبدل محتويات الكائن الآخر مع الكائن الحالي.

أمثلة

    int main(int argc, char **argv)
    {
        if (argc == 1)
        {
            cout << "Provide glob-expression as 1st arg\n";
            return 1;
        }
        cout << "General:\n";
        Glob general;
        for (size_t idx = 0; idx < general.size(); idx++)
            cout << idx << ": " << general[idx] << endl;
        cout << "Pattern: " << argv[1] << "\n";
        Glob pattern(argv[1], Glob::PERIOD, Glob::DEFAULT);
        for (size_t idx = 0; idx < pattern.size(); idx++)
            cout << idx << ": " << pattern[idx] << endl;
    }
