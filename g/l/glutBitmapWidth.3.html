glutBitmapWidth(3)

الحزمة: freeglut

التراخيص: X11

glutBitmapWidth(3) freeglut glutBitmapWidth(3)

الاسم

glutBitmapWidth - يرجع عرض حرف خط نقطي.
glutBitmapLength يرجع طول سلسلة خط نقطي.

الصيغة

int glutBitmapWidth(void *font, int character)
int glutBitmapLength(void *font, const unsigned char *string)

المعاملات

font
خط نقطي للاستخدام. للقيم الصالحة، انظر وصف glutBitmapCharacter.
character
الحرف لإرجاع عرضه (غير مقيد بـ 8 بت).
string
سلسلة نصية (أحرف 8 بت)، تنتهي بـ nul.

الوصف

تُرجع glutBitmapWidth العرض بالبكسل لحرف نقطي في خط نقطي مدعوم. بينما قد يختلف عرض الأحرف في الخط (على الرغم من أن خطوط العرض الثابتة لا تختلف)، فإن خصائص الارتفاع القصوى لخط معين ثابتة.

تُرجع glutBitmapLength الطول بالبكسل لسلسلة (أحرف 8 بت). هذا الطول يعادل مجموع جميع العروض التي تم إرجاعها بواسطة glutBitmapWidth لكل حرف في السلسلة.

انظر أيضًا

glutBitmapCharacter, glutStrokeWidth
