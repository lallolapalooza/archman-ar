NAME

glUniformMatrix4x3fv

load a 4-by-3 matrix into a uniform variable

C SPECIFICATION

void glUniformMatrix4x3fv(GLint location,
                          GLsizei count,
                          GLboolean transpose,
                          const GLfloat *value);

PARAMETERS

location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of matrices to be downloaded and passed to the uniform variable.
transpose
Specifies whether to transpose the matrix or not. Must be GL_FALSE.
value
Specifies a pointer to the first element of an array of values to be loaded.

DESCRIPTION

glUniformMatrix4x3fv loads a matrix or an array of matrices into a uniform variable in one or more shader programs.

The uniform variables are identified by their location, and specified by the location parameter.

The count parameter specifies the number of matrices to be passed. This can be greater than 1 only if the uniform variable is an array of matrices.

The transpose parameter indicates whether the matrix or matrices should be transposed. It must be GL_FALSE for glUniformMatrix4x3fv.

The value parameter points to the first element of the matrix or array of matrices to be loaded. The matrices are stored in column-major order.

NOTES

If the specified uniform variable is not active, or if it is not a matrix or an array of matrices, the command is ignored.

The GL_FALSE value for the transpose parameter means that the matrices are loaded in their specified order. If GL_TRUE were permitted, the matrices would be transposed before being loaded.

The matrices are loaded into the uniform variable starting from the location specified.

ERRORS

A GL_INVALID_OPERATION is generated if the specified location could not be determined.

A GL_INVALID_VALUE is generated if transpose is not GL_FALSE.

ASSOCIATED GETS

glGetUniformiv(), glGetUniformfv()
