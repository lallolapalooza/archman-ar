glGetQueryBufferObject(3G)

الحزمة: opengl-man-pages

التراخيص: SGI-B-2.0, OPL-1.0

NAME

glGetQueryBufferObjectuiv - query the parameters of a query object

C SPECIFICATION

void glGetQueryBufferObjectuiv( GLuint queryId,
                                                        GLintptr buffer,
                                                        GLenum pname );

PARAMETERS

queryId
Specifies the name of a query object.
buffer
Specifies the offset in the buffer object into which the results of `pname` should be written.
pname
Specifies the symbolic constant representing the query parameter to be returned.

DESCRIPTION

glGetQueryBufferObjectuiv retrieves the value of a parameter from a query object and stores it in a buffer object. queryId names the query object, and pname specifies the parameter to retrieve. The result is written into the currently bound buffer object at the offset specified by buffer.

The valid values for pname are:

  • GL_QUERY_RESULT: Returns the result of the query. This will be an unsigned integer.
  • GL_QUERY_RESULT_AVAILABLE: Returns a boolean indicating whether a query result is available.

The results are written into the buffer object associated with the target specified when the buffer was created. The buffer parameter specifies the offset, in basic memory units, into the buffer object where the result should be placed.

The values returned in the buffer are of type GLuint. If pname is GL_QUERY_RESULT_AVAILABLE, the value written is 1 if the result is available, and 0 otherwise.

If the query object is still active (i.e., glBeginQuery has been called but glEndQuery has not yet been called), the behavior is undefined.

If queryId is not the name of a valid query object, an GL_INVALID_OPERATION error is generated.

If the buffer object is not currently bound to the target associated with the query object, an GL_INVALID_OPERATION error is generated.

If the offset specified by buffer is outside the bounds of the buffer object, an GL_INVALID_OPERATION error is generated.

If pname is not one of the accepted symbolic constants, an GL_INVALID_ENUM error is generated.

NOTES

This function is available only if the GL_EXT_disjoint_timer_query extension is supported.

The buffer object must be created with the target GL_QUERY_BUFFER.

The offset buffer must be a multiple of the alignment requirement for the data type being written.

ERRORS

GL_INVALID_OPERATION

  • If queryId is not the name of a valid query object.
  • If the buffer object is not currently bound to the target GL_QUERY_BUFFER.
  • If the offset specified by buffer is outside the bounds of the buffer object.

GL_INVALID_ENUM

  • If pname is not GL_QUERY_RESULT or GL_QUERY_RESULT_AVAILABLE.
