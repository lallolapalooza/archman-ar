glab-ci-run(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-ci-run - إنشاء أو تشغيل خط أنابيب CI/CD جديد.

الملخص

glab ci run [علامات]

الوصف

الخيار --branch متاح لجميع أنواع خطوط الأنابيب.

خيارات المتغيرات غير متوافقة مع خطوط أنابيب طلبات الدمج. إذا تم استخدامها مع خطوط أنابيب طلبات الدمج، تفشل الأوامر برسالة مثل ERROR: if any flags in the group [output output-format] are set none of the others can be

حدد مدخلًا واحدًا أو أكثر لخط الأنابيب باستخدام العلامة -i أو --input لكل مدخل. تستخدم كل علامة مدخل صيغة key:value.

يتم تحديد أنواع القيم وستكون افتراضية إلى string ما لم يتم تحديد نوع بشكل صريح. لتحديد نوع، استخدم صيغة type(value). على سبيل المثال، key:string(value) سيمرر القيمة النصية value كمدخل.

الأنواع الصالحة هي:

  • string: قيمة نصية. هذا هو النوع الافتراضي. على سبيل المثال، key:string(value).
  • int: قيمة عدد صحيح. على سبيل المثال، key:int(42).
  • float: قيمة عدد عشري. على سبيل المثال، key:float(3.14).
  • bool: قيمة منطقية. على سبيل المثال، key:bool(true).
  • array: مصفوفة من النصوص. على سبيل المثال، key:array(foo,bar).

يمكن تحديد مصفوفة من النصوص بفاصلة لاحقة. على سبيل المثال، key:array(foo,bar,) سيمرر المصفوفة [foo, bar]. array() يحدد مصفوفة فارغة. لتمرير مصفوفة مع نص فارغ، استخدم array(,).

يجب الهروب من وسائط القيم التي تحتوي على أقواس من الصدفة باستخدام علامات الاقتباس. على سبيل المثال، يجب كتابة --input key:array(foo,bar) على النحو التالي --input 'key:array(foo,bar)'.

الخيارات

-b, --branch="" إنشاء خط أنابيب على الفرع/المرجع.

-i, --input=[] تمرير المدخلات إلى خط الأنابيب بالصيغة ':'. لا يمكن استخدامه لخطوط أنابيب طلبات الدمج. راجع التوثيق للحصول على أمثلة.

--mr[=false] تشغيل خط أنابيب طلب الدمج بدلاً من خط أنابيب الفرع.

--variables=[] تمرير المتغيرات إلى خط الأنابيب بالصيغة :. لا يمكن استخدامه لخطوط أنابيب طلبات الدمج.

--variables-env=[] تمرير المتغيرات إلى خط الأنابيب بالصيغة :. لا يمكن استخدامه لخطوط أنابيب طلبات الدمج.

--variables-file=[] تمرير محتويات الملف كمتغير ملف إلى خط الأنابيب بالصيغة :. لا يمكن استخدامه لخطوط أنابيب طلبات الدمج.

-f, --variables-from="" ملف JSON مع متغيرات لتنفيذ خط الأنابيب. يتوقع مصفوفة من التجزئات، كل منها يحتوي على 'key' و 'value' على الأقل. لا يمكن استخدامه لخطوط أنابيب طلبات الدمج.

-w, --web[=false] فتح خط الأنابيب في المتصفح. يستخدم المتصفح الافتراضي، أو المتصفح المحدد في متغير البيئة BROWSER.

خيارات موروثة من الأوامر الأصل

-h, --help[=false] إظهار المساعدة لهذا الأمر.

-R, --repo="" تحديد مستودع آخر. يمكن استخدام صيغة OWNER/REPO أو GROUP/NAMESPACE/REPO. يقبل أيضًا عنوان URL كامل أو عنوان URL لمستودع Git.

مثال

$ glab ci run
$ glab ci run --variables \"key1:value,with,comma\"
$ glab ci run -b main
$ glab ci run --web
$ glab ci run --mr
# تحديد متغيرات CI
$ glab ci run -b main --variables-env key1:val1
$ glab ci run -b main --variables-env key1:val1,key2:val2
$ glab ci run -b main --variables-env key1:val1 --variables-env key2:val2
$ glab ci run -b main --variables-file MYKEY:file1 --variables KEY2:some_value
# تحديد مدخلات CI
$ glab ci run -b main --input key1:val1 --input key2:val2
$ glab ci run -b main --input "replicas:int(3)" --input "debug:bool(false)" --input "regions:array(us-east,eu-west)"
// للحصول على مثال لـ 'glab ci run -f' مع ملف متغيرات، انظر
// [Run a CI/CD pipeline with variables from a file](https://docs.gitlab.com/editor_extensions/gitlab_cli/#run-a-cicd-pipeline-with-variables-from-a-file)
// في توثيق GitLab.
