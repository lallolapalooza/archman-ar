الاسم

glDeleteTextures - حذف نسيج مسمى

مواصفات C

void glDeleteTextures(GLsizei n, const GLuint * textures);

المعلمات

n

تحدد عدد الأنسجة المراد حذفها.

textures

تحدد مصفوفة من الأنسجة المراد حذفها.

الوصف

glDeleteTextures يحذف n نسيجًا مسمى بالعناصر الموجودة في المصفوفة textures. بعد حذف نسيج، فإنه لا يحتوي على محتويات أو أبعاد، واسمه متاح لإعادة الاستخدام (على سبيل المثال بواسطة glGenTextures()). إذا تم حذف نسيج تم ربطه حاليًا، فإن الربط يعود إلى 0 (النسيج الافتراضي).

glDeleteTextures يتجاهل بصمت القيم 0 والأسماء التي لا تتوافق مع الأنسجة الموجودة.

الأخطاء

يتم توليد GL_INVALID_VALUE إذا كانت n سالبة.
