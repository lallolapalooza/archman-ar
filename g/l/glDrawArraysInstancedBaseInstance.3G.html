glDrawArraysInstancedBaseInstance(3G)

الحزمة: opengl-man-pages

التراخيص: SGI-B-2.0, OPL-1.0

GLDRAWARRAYSINSTANCE(3G) [FIXME: دليل] GLDRAWARRAYSINSTANCE(3G)

الاسم

glDrawArraysInstancedBaseInstance - رسم مثيلات متعددة لنطاق من العناصر مع تطبيق إزاحة على سمات المثيلات

مواصفات C

void glDrawArraysInstancedBaseInstance(GLenum mode, GLint first, GLsizei count, GLsizei instancecount, GLuint baseinstance);

المعاملات

mode

يحدد نوع الأشكال الهندسية المراد رسمها. يتم قبول الثوابت الرمزية GL_POINTS, GL_LINE_STRIP, GL_LINE_LOOP, GL_LINES, GL_TRIANGLE_STRIP, GL_TRIANGLE_FAN, GL_TRIANGLES GL_LINES_ADJACENCY, GL_LINE_STRIP_ADJACENCY, GL_TRIANGLES_ADJACENCY, GL_TRIANGLE_STRIP_ADJACENCY و GL_PATCHES.

first

يحدد فهرس البداية في المصفوفات الممكّنة.

count

يحدد عدد الفهارس المراد رسمها.

instancecount

يحدد عدد مثيلات النطاق المحدد من الفهارس المراد رسمها.

baseinstance

يحدد المثيل الأساسي لاستخدامه في جلب سمات رؤوس المثيلات.

الوصف

glDrawArraysInstancedBaseInstance تعمل بنفس طريقة glDrawArrays() باستثناء أنه يتم تنفيذ instancecount مثيل من نطاق العناصر، ويزداد عداد instanceID الداخلي مع كل تكرار. instanceID هو عداد داخلي بـ 32 بت يمكن للشادر الرأسي قراءته كـ gl_InstanceID.

glDrawArraysInstancedBaseInstance لها نفس تأثير:

    if ( mode or count is invalid )
        generate appropriate error
    else {
        for (int i = 0; i < instancecount ; i++) {
            instanceID = i;
            glDrawArrays(mode, first, count);
        }
        instanceID = 0;
    }

يمكن تصنيف سمات رؤوس معينة كـ مثيلات من خلال استخدام glVertexAttribDivisor(). توفر سمات رؤوس المثيلات بيانات رؤوس لكل مثيل للشادر الرأسي. يتم حساب فهرس الرأس الذي تم جلبه من مصفوفات سمات رؤوس المثيلات الممكّنة على النحو التالي: gl _ InstanceID divisor + baseInstance. لاحظ أن baseinstance لا تؤثر على القيمة المرئية في الشادر لـ gl_InstanceID.

الأخطاء

يتم إنشاء GL_INVALID_ENUM إذا لم يكن mode إحدى القيم المقبولة.

يتم إنشاء GL_INVALID_OPERATION إذا كان هناك شادر هندسي نشط وكان mode غير متوافق مع نوع الشكل الهندسي المدخل للشادر الهندسي في كائن البرنامج المثبت حاليًا.

يتم إنشاء GL_INVALID_VALUE إذا كان count أو instancecount سالبًا.

يتم إنشاء GL_INVALID_OPERATION إذا كان اسم كائن المخزن المؤقت غير صفري مرتبطًا بمصفوفة ممكّنة وكان مخزن بيانات كائن المخزن المؤقت معينًا حالياً.
