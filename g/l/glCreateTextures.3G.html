الاسم

glCreateTextures - إنشاء كائنات النسيج

مواصفات C

void glCreateTextures(GLenum target, GLsizei n, GLuint *textures);

المعلمات

target

يحدد هدف النسيج الفعال لكل نسيج تم إنشاؤه.

n

عدد كائنات النسيج المراد إنشاؤها.

textures

يحدد مصفوفة يتم فيها تخزين أسماء كائنات النسيج الجديدة.

الوصف

glCreateTextures تُرجع n أسماء نسيج غير مستخدمة سابقًا في textures، يمثل كل منها كائن نسيج جديد بالبُعد والنوع المحددين بواسطة target وتم تهيئته إلى القيم الافتراضية لنوع النسيج هذا.

يجب أن يكون target أحد القيم التالية: GL_TEXTURE_1D, GL_TEXTURE_2D, GL_TEXTURE_3D, GL_TEXTURE_1D_ARRAY, GL_TEXTURE_2D_ARRAY, GL_TEXTURE_RECTANGLE, GL_TEXTURE_CUBE_MAP, GL_TEXTURE_CUBE_MAP_ARRAY, GL_TEXTURE_BUFFER, GL_TEXTURE_2D_MULTISAMPLE أو GL_TEXTURE_2D_MULTISAMPLE_ARRAY.

الأخطاء

يتم إنشاء GL_INVALID_ENUM إذا لم يكن target أحد القيم المسموح بها.

يتم إنشاء GL_INVALID_VALUE إذا كانت n سالبة.
