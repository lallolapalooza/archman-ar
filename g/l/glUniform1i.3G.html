glUniform1i(3G)

الحزمة: opengl-man-pages

التراخيص: SGI-B-2.0, OPL-1.0

الاسم

glUniformMatrix - تعيين قيم مصفوفات إلى الـ uniforms.

تحديد C

void glUniformMatrix2fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix2x3fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix2x4fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix3fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix3x2fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix3x4fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix4fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix4x2fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);
void glUniformMatrix4x3fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);

المعلمات

location
يحدد الـ uniform المطلوب تعديله.
count
يحدد عدد المصفوفات التي سيتم تحديثها.
transpose
يحدد ما إذا كان يجب تبديل المصفوفات قبل تعيينها. يجب أن تكون القيمGL_FALSE أوGL_TRUE.
value
يشير إلى مؤشر إلى مصفوفة القيم الأولى المراد تعيينها للـ uniform المحدد.

الوصف

تُستخدم وظائف glUniformMatrix...fv لتعيين قيم مصفوفات لمواقع uniform محددة في البرنامج الحالي.

تسمح وظائف glUniformMatrix2fv و glUniformMatrix3fv و glUniformMatrix4fv بتعيين مصفوفات 2x2 و 3x3 و 4x4 على التوالي.

تسمح وظائف glUniformMatrix2x3fv و glUniformMatrix2x4fv و glUniformMatrix3x2fv و glUniformMatrix3x4fv و glUniformMatrix4x2fv و glUniformMatrix4x3fv بتعيين مصفوفات بأبعاد مختلطة.

إذا كانت قيمة transpose هي GL_TRUE، فيجب أن يتم تبديل كل مصفوفة في value قبل تعيينها إلى الـ uniform.

سيتم تعيين القيم مباشرة إلى الـ uniform بغض النظر عن قيم الـ uniform الأخرى.

ملاحظات

يجب أن تكون location قيمة صالحة تم الحصول عليها من خلال استدعاء glGetUniformLocation.

إذا لم يتم استخدام الـ uniform المحدد، فلن يتم استدعاء الوظيفة.

الأخطاء

يتم إنشاء GL_INVALID_OPERATION إذا لم يتم تفعيل برنامج Shader.

يتم إنشاء GL_INVALID_VALUE إذا كانت count سالبة.
