global(n)

الحزمة: tcl

التراخيص: TCL

global(n) أوامر Tcl المدمجة global(n)

الاسم

global - الوصول إلى المتغيرات العامة

الملخص

global ?اسم_متغير ...?

الوصف

لا يكون لهذا الأمر أي تأثير ما لم يتم تنفيذه في سياق جسم إجراء (proc body). إذا تم تنفيذ أمر global في سياق جسم إجراء، فإنه ينشئ متغيرات محلية مرتبطة بالمتغيرات العامة المقابلة (على الرغم من أن هذه المتغيرات المرتبطة، مثل تلك التي تم إنشاؤها بواسطة upvar، لا يتم تضمينها في القائمة التي تعيدها info locals).

إذا كان اسم_متغير يحتوي على مؤهلات مساحة اسم، فإن اسم المتغير المحلي هو الاسم غير المؤهل للمتغير العام، كما يتم تحديده بواسطة أمر namespace tail.

يتم دائمًا التعامل مع اسم_متغير على أنه اسم متغير، وليس عنصر مصفوفة. يتم إرجاع خطأ إذا كان الاسم يبدو كعنصر مصفوفة، مثل a(b).

أمثلة

يقوم هذا الإجراء بتعيين متغير مساحة الاسم ::a::x

proc reset {} {
    global a::x
    set x 0
}

يقوم هذا الإجراء بتجميع السلاسل النصية التي تم تمريرها إليه في مخزن مؤقت عام، مفصولة بسطور جديدة. إنه مفيد للمواقف التي تريد فيها بناء رسالة جزءًا بجزء (كما لو كان باستخدام puts) ولكن إرسال تلك الرسالة الكاملة في جزء واحد (على سبيل المثال، عبر اتصال تم فتحه باستخدام socket أو كجزء من استجابة HTTP محسوبة).

proc accum {string} {
    global accumulator
    append accumulator $string \n
}
