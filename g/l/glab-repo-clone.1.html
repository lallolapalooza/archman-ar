glab-repo-clone(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-repo-clone - استنساخ مستودع أو مشروع GitLab.

الملخص

glab repo clone [خيارات] [] [-- ...] glab repo clone -g [خيارات] [] [-- ...]

الوصف

الاستنساخ يدعم هذه المراجع المختصرة:

  • مستودع
  • اسم_النطاق/مستودع
  • منظمة/مجموعة/مستودع
  • معرف المشروع

الخيارات

-g, --group="" تحديد المجموعة لاستنساخ المستودعات منها.

-p, --preserve-namespace[=false] استنساخ المستودع في دليل فرعي بناءً على اسم النطاق.

-a, --archived[=false] الحد حسب حالة الأرشفة. استخدم مع '-a=false' لاستبعاد المستودعات المؤرشفة. يستخدم مع العلم --group.

-G, --include-subgroups[=true] تضمين المشاريع في المجموعات الفرعية لهذه المجموعة. الافتراضي هو true. يستخدم مع العلم --group.

-m, --mine[=false] الحد بالمشاريع في المجموعة المملوكة للمستخدم الحالي المصادق عليه. يستخدم مع العلم --group.

-v, --visibility="" الحد حسب الرؤية: عام، داخلي، خاص. يستخدم مع العلم --group.

-I, --with-issues-enabled[=false] الحد بالمشاريع مع تمكين ميزة المشكلات. الافتراضي هو false. يستخدم مع العلم --group.

-M, --with-mr-enabled[=false] الحد بالمشاريع مع تمكين ميزة طلبات الدمج. الافتراضي هو false. يستخدم مع العلم --group.

-S, --with-shared[=true] تضمين المشاريع المشتركة في هذه المجموعة. الافتراضي هو true. يستخدم مع العلم --group.

--paginate[=false] إجراء طلبات HTTP إضافية لجلب جميع صفحات المشاريع قبل الاستنساخ. يحترم --per-page.

--page=1 رقم الصفحة.

--per-page=30 عدد العناصر المراد إدراجها في كل صفحة.

خيارات موروثة من أوامر أصلية

-h, --help[=false] عرض المساعدة لهذا الأمر.

مثال

# يستنسخ المستودع في الدليل الحالي
$ glab repo clone gitlab-org/cli
$ glab repo clone https://gitlab.com/gitlab-org/cli
# يستنسخ المستودع في 'mydirectory'
$ glab repo clone gitlab-org/cli mydirectory
# يستنسخ المستودع 'glab' للمستخدم الحالي
$ glab repo clone glab
# يبحث عن المشروع باستخدام المعرف المقدم ويستنسخه
$ glab repo clone 4356677
# يستنسخ جميع المستودعات في مجموعة
$ glab repo clone -g everyonecancontribute --paginate
# يستنسخ جميع المستودعات غير المؤرشفة في مجموعة
$ glab repo clone -g everyonecancontribute --archived=false --paginate
# يستنسخ من مثيل GitLab مدار ذاتيًا أو GitLab المخصص
$ GITLAB_HOST=salsa.debian.org glab repo clone myrepo
