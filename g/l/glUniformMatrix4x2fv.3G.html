glUniformMatrix4x2fv(3G)

الحزمة: opengl-man-pages

التراخيص: SGI-B-2.0, OPL-1.0

NAME

glUniformMatrix4x2fv - set the value of a uniform variable

C SPECIFICATION

void glUniformMatrix4x2fv(GLint location, GLsizei count, GLboolean transpose, const GLfloat *value);

PARAMETERS

location
Specifies the location of the uniform variable to be modified.
count
Specifies the number of matrices to be downloaded by the function.
transpose
Specifies whether to transpose the matrix or matrices. Must be GL_FALSE .
value
Specifies a pointer to the first element of an array of values that will be used to update the specified uniform variable.

DESCRIPTION

glUniformMatrix4x2fv sets the value of a uniform variable of type mat4x2 (4 columns, 2 rows) or array of mat4x2s from an array of floating-point values.

location is the integer location of a uniform variable in the calling program object.

count is the number of individual matrices to be modified. If count is 1, a single matrix will be downloaded. If count is greater than 1, then count individual matrices will be downloaded.

transpose must be GL_FALSE as matrices are expected in column-major order.

value points to the first element of an array of 4 * 2 * count floating-point values. These values are loaded into the specified uniform variable, in the order they are specified.

NOTES

If the uniform variable specified by location is not of type mat4x2 or an array of mat4x2s, a GL error is generated.

If the uniform variable is not active in the calling program object, or if it is not accessible, the commands have no effect.

If location is -1, the command is ignored.

glUniformMatrix4x2fv is available for setting uniform variables within the core profile, in version 4.0 and later, and in compatibility profile, in version 2.0 and later.

ERRORS

GL_INVALID_OPERATION is generated if location does not correspond to a valid uniform variable location, or if the uniform variable location is not active or belongs to the active program object.

GL_INVALID_VALUE is generated if count is negative.

ASSOCIATED GETS

glGetUniformfv , glGetUniformiv , glGetActiveUniform , glGetUniformLocation

VERSION SUPPORT


Version 4.0
Core Profile Version 4.0
Compatibility Profile Version 2.0
