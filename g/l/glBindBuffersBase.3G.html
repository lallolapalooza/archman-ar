glBindBuffersBase(3G)

glBindBuffersBase(3G) [FIXME: manual] glBindBuffersBase(3G)

الاسم

glBindBuffersBase - ربط كائن أو أكثر من الكائنات المخزنة مؤقتًا بتسلسل من أهداف المخازن المؤقتة المفهرسة

المواصفات بلغة C

void glBindBuffersBase(GLenum target, GLuint first, GLsizei count, const GLuint *buffers);

المعلمات

target

يحدد هدف عملية الربط. يجب أن يكون target أحد الخيارات التالية: GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER أو GL_SHADER_STORAGE_BUFFER.

first

يحدد فهرس نقطة الربط الأولى ضمن المصفوفة المحددة بواسطة target.

count

يحدد عدد نقاط الربط المتجاورة لربط الكائنات المخزنة مؤقتًا.

buffers

مؤشر إلى مصفوفة من أسماء الكائنات المخزنة مؤقتًا لربطها بالأهداف عند نقطة الربط المحددة، أو NULL.

الوصف

تقوم glBindBuffersBase بربط مجموعة من count كائنات مخزنة مؤقتًا تحمل الأسماء الموجودة في المصفوفة buffers إلى count نقاط ربط متتالية بدءًا من الفهرس first للمصفوفة المحددة بواسطة target. إذا كانت buffers تساوي NULL، فإن glBindBuffersBase تفصل أي كائنات مخزنة مؤقتًا مرتبطة حاليًا بنقاط الربط المشار إليها. بافتراض عدم حدوث أخطاء، فإنها تعادل الشيفرة الزائفة التالية، والتي تستدعي glBindBufferBase()، باستثناء أن target غير المفهرس لا يتم تغييره بواسطة glBindBuffersBase:

    for (i = 0; i < count; i++) {
        if (buffers != NULL) {
            glBindBufferBase(target, first + i, buffers[i]);
        } else {
            glBindBufferBase(target, first + i, 0);
        }
    }

سيتم فحص كل إدخال في buffers بشكل فردي، وإذا تم العثور على قيمة غير صالحة، فلن يتم تغيير حالة ربط هذا الكائن المخزن مؤقتًا وسيتم إنشاء خطأ. ومع ذلك، سيتم تحديث الحالة لمؤشرات ربط الكائنات المخزنة مؤقتًا الأخرى التي تشير إليها الأمر.

ملاحظات

glBindBuffersBase متاحة فقط إذا كان إصدار GL هو 4.4 أو أعلى.

الأخطاء

يتم إنشاء GL_INVALID_ENUM إذا لم يكن target هو GL_ATOMIC_COUNTER_BUFFER, GL_TRANSFORM_FEEDBACK_BUFFER, GL_UNIFORM_BUFFER أو GL_SHADER_STORAGE_BUFFER.

يتم إنشاء GL_INVALID_OPERATION إذا كان first + count أكبر من عدد نقاط الربط المفهرسة الخاصة بالهدف.

يتم إنشاء GL_INVALID_OPERATION إذا كانت أي قيمة في buffers ليست صفرًا أو اسم كائن مخزن مؤقت موجود.
