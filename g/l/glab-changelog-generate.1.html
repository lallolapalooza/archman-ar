glab-changelog-generate(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-changelog-generate - إنشاء سجل تغييرات للمستودع أو المشروع.

الملخص

glab changelog generate [flags]

الوصف

إنشاء سجل تغييرات للمستودع أو المشروع.

خيارات

--config-file="" مسار ملف إعداد سجل التغييرات في مستودع Git الخاص بالمشروع. الافتراضي هو '.gitlab/changelog_config.yml'.

--date="" تاريخ ووقت الإصدار. يستخدم صيغة ISO 8601 (2016-03-11T03:45:40Z). الافتراضي هو الوقت الحالي.

--from="" بداية نطاق التغييرات (كرقم SHA) لاستخدامه عند إنشاء سجل التغييرات. هذا التغيير نفسه لا يتم تضمينه في القائمة.

--to="" نهاية نطاق التغييرات (كرقم SHA) لاستخدامه عند إنشاء سجل التغييرات. يتم تضمين هذا التغيير في القائمة. الافتراضي هو HEAD للفرع الافتراضي للمشروع.

--trailer="" الذيل (trailer) الخاص بـ Git لاستخدامه لتضمين التغييرات. الافتراضي هو 'Changelog'.

-v, --version="" الإصدار الذي سيتم إنشاء سجل التغييرات له. يجب أن يتبع ترقيم الإصدارات الدلالية. الافتراضي هو إصدار النسخة المحلية، مثل استخدام 'git describe'.

خيارات موروثة من أوامر أب

-h, --help[=false] عرض المساعدة لهذا الأمر.

مثال

# إنشاء سجل تغييرات
$ glab changelog generate
