NAME

glProgramUniform4uiv — set the value of a uniform variable in an active program object

C SPECIFICATION

    void glProgramUniform4uiv( GLuint program,
                               GLint location,
                               GLsizei count,
                               const GLuint *value );

PARAMETERS

program

Specifies the program object containing the uniform variable to be modified.

location

Specifies the location of the uniform variable to be modified.

count

Specifies the number of elements to be updated. Should be 1 if the uniform variable is not an array.

value

Specifies a pointer to the new values to be stored in the uniform variable.

DESCRIPTION

Calls to glProgramUniform{4}uiv set the value of a uniform variable within a program object. This function is similar to glUniform(), but it allows the uniform variable to be set without making the program object current. It also supports setting uniforms of types that are not directly supported by glUniform (e.g. unsigned integer types).

If the uniform variable specified by location is not an array, count must be 1. If the uniform variable is an array, count specifies the number of elements to update, and the values are taken from the array pointed to by value.

If location is not valid, then the generic `uniform' parameter is ignored.

If program is not a value generated by creating a program object, or if it is the name of an object for which compilation or linking failed, the command is ignored.

If program has been linked, and location is not equal to the location of any uniform variable in program, and location is not -1, then the command is ignored.

If the specified uniform variable is not of type GL_UNSIGNED_INT_VEC4, then the command is ignored.

The values specified by value are interpreted as unsigned integers.

NOTES

The behavior of glProgramUniform* calls is undefined if the program object specified by program is not the name of a program object for which compilation and linking have completed successfully.

The behavior of glProgramUniform* calls is undefined if the uniform variable specified by location is not a valid uniform variable location in the program object specified by program.

When a program object is no longer active, the uniform locations obtained from it become invalid.

ERRORS

A GL error may be generated by the following.

GL_INVALID_OPERATION is generated if program is not zero and is not the name of an active program object.

GL_INVALID_OPERATION is generated if location is not -1 and is not a valid uniform location for the active program object program.

GL_INVALID_OPERATION is generated if the uniform variable specified by location is not of type GL_UNSIGNED_INT_VEC4.

GL_INVALID_VALUE is generated if count is less than zero.
