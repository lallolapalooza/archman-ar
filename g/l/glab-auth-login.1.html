glab-auth-login(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-auth-login - المصادقة مع مثيل GitLab.

ملخص

glab auth login [علامات]

الوصف

المصادقة مع مثيل GitLab. يمكنك تمرير رمز مميز عبر الإدخال القياسي باستخدام --stdin. النطاقات المطلوبة للرمز المميز هي: api، write_repository. يتم تخزين التكوين وبيانات الاعتماد في ملف التكوين العام (الافتراضي ~/.config/glab-cli/config.yml).

عند التشغيل في وضع تفاعلي داخل مستودع Git، سيقوم glab تلقائيًا باكتشاف مثيلات GitLab من روابط Git الخاصة بك وتقديمها كخيارات، مما يوفر عليك كتابة اسم المضيف يدويًا.

خيارات

-a، --api-host="" عنوان URL لمضيف API.

-p، --api-protocol="" بروتوكول API: https، http

-g، --git-protocol="" بروتوكول Git: ssh، https، http

--hostname="" اسم المضيف لمثيل GitLab للمصادقة معه.

-j، --job-token="" رمز مهمة CI.

--stdin[=false] قراءة الرمز المميز من الإدخال القياسي.

-t، --token="" رمز وصول GitLab الخاص بك.

--use-keyring[=false] تخزين الرمز المميز في سلسلة مفاتيح نظام التشغيل الخاص بك.

خيارات موروثة من أوامر أب

-h، --help[=false] عرض المساعدة لهذا الأمر.

مثال

# بدء الإعداد التفاعلي
# (إذا كنت في مستودع Git، سيقوم glab باكتشاف واقتراح مثيلات GitLab من الروابط)
$ glab auth login
# المصادقة ضد `gitlab.com` عن طريق قراءة الرمز المميز من ملف
$ glab auth login --stdin < myaccesstoken.txt
# المصادقة مع GitLab Self-Managed أو GitLab Dedicated
$ glab auth login --hostname salsa.debian.org
# إعداد غير تفاعلي
$ glab auth login --hostname gitlab.example.org --token glpat-xxx --api-host gitlab.example.org:3443 --api-protocol https --git-protocol ssh
# إعداد غير تفاعلي قراءة الرمز المميز من ملف
$ glab auth login --hostname gitlab.example.org --api-host gitlab.example.org:3443 --api-protocol https --git-protocol ssh  --stdin < myaccesstoken.txt
# إعداد CI/CD غير تفاعلي
$ glab auth login --hostname $CI_SERVER_HOST --job-token $CI_JOB_TOKEN
