glab-milestone-create(1)

الحزمة: glab

التراخيص: MIT

glab(1) glab(1)

الاسم

glab-milestone-create - إنشاء علامة فارقة للمجموعة أو المشروع.

الملخص

glab milestone create [علامات]

الوصف

إنشاء علامة فارقة للمجموعة أو المشروع.

خيارات

--description="" وصف العلامة الفارقة.

--due-date="" تاريخ الاستحقاق للعلامة الفارقة. متوقع بتنسيق ISO 8601 (2025-04-15T08:00:00Z).

--group="" معرف أو مسار المجموعة المشفرة في عنوان URL.

--project="" معرف أو مسار المشروع المشفر في عنوان URL.

--start-date="" تاريخ البدء للعلامة الفارقة. متوقع بتنسيق ISO 8601 (2025-04-15T08:00:00Z).

--title="" عنوان العلامة الفارقة.

خيارات مستمدة من الأوامر الأصل

-h, --help[=false] عرض المساعدة لهذا الأمر.

-R, --repo="" تحديد مستودع آخر. يمكن استخدام صيغة OWNER/REPO أو GROUP/NAMESPACE/REPO. يقبل أيضًا عنوان URL كاملاً أو عنوان URL لـ Git.

مثال

 # إنشاء علامة فارقة للمشروع الحالي
$ glab milestone create --title='مثال على العنوان' --due-date='2025-12-16'
# إنشاء علامة فارقة للمشروع المحدد
$ glab milestone create --title='مثال على علامة فارقة للمجموعة' --due-date='2025-12-16' --project 123
# إنشاء علامة فارقة للمجموعة المحددة
$ glab milestone create --title='مثال على علامة فارقة للمجموعة' --due-date='2025-12-16' --group 456
