الاسم

glab-duo-ask - إنشاء أوامر Git من اللغة الطبيعية.

ملخص

glab duo ask [علامات]

الوصف

إنشاء أوامر Git من اللغة الطبيعية بمساعدة الذكاء الاصطناعي.

صف ما تريد القيام به بلغة بسيطة، وسيقترح GitLab Duo أوامر Git المناسبة. يقدم الذكاء الاصطناعي كلاً من الأوامر والشرح.

بعد تلقي الأوامر المقترحة، يمكنك تنفيذها مباشرة من سطر الأوامر. يجب عليك تأكيد كل أمر قبل تنفيذه.

استخدم هذا الأمر لـ:

  • استرداد أوامر Git المنسية.
  • تعلم كيفية إنجاز عمليات Git محددة.
  • الحصول على إرشادات حول سير عمل Git المعقد.
  • تقليل تبديل السياق أثناء التطوير.

خيارات

--git[=true] طرح سؤال حول Git.

خيارات موروثة من الأوامر الأصل

-h, --help[=false] إظهار المساعدة لهذا الأمر.

مثال

$ glab duo ask list last 10 commit titles
> قائمة بأوامر Git لعرض عناوين آخر 10 عمليات تثبيت مع شرح وخيار لتنفيذ الأوامر.
$ glab duo ask how do I undo my last commit
> اقتراحات للتراجع عن آخر عملية تثبيت مع شرح لأساليب مختلفة.
$ glab duo ask show me files changed in the last commit
> أوامر لعرض الملفات التي تم تعديلها في آخر عملية تثبيت.
