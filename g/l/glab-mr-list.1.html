الاسم

glab-mr-list - سرد طلبات الدمج.

الملخص

glab mr list [علامات]

الوصف

سرد طلبات الدمج.

الخيارات

-A, --all[=false] الحصول على جميع طلبات الدمج.

-a, --assignee=[] الحصول فقط على طلبات الدمج المعينة للمستخدمين. يمكن فصل المستخدمين المتعددين بفاصلة أو تحديدهم بتكرار العلامة.

--author="" تصفية طلبات الدمج حسب المؤلف.

-c, --closed[=false] الحصول فقط على طلبات الدمج المغلقة.

-d, --draft[=false] التصفية حسب طلبات الدمج المسودة.

-g, --group="" اختيار مجموعة/مجموعة فرعية. يتم تجاهل هذا الخيار إذا تم تعيين وسيط مستودع.

-l, --label=[] تصفية طلبات الدمج حسب العلامة. يمكن فصل العلامات المتعددة بفاصلة أو تحديدها بتكرار العلامة.

-M, --merged[=false] الحصول فقط على طلبات الدمج المدمجة.

-m, --milestone="" تصفية طلبات الدمج حسب المعلم.

--not-draft[=false] التصفية حسب طلبات الدمج غير المسودة.

--not-label=[] تصفية طلبات الدمج التي لا تحتوي على علامة. يمكن فصل العلامات المتعددة بفاصلة أو تحديدها بتكرار العلامة.

-o, --order="" ترتيب طلبات الدمج حسب. خيارات الترتيب: created_at, title, merged_at أو updated_at.

-F, --output="text" تنسيق الإخراج كـ: text, json.

-p, --page=1 رقم الصفحة.

-P, --per-page=30 عدد العناصر لسردها لكل صفحة.

-R, --repo="" اختيار مستودع آخر. يمكن استخدام تنسيق OWNER/REPO أو GROUP/NAMESPACE/REPO. يقبل أيضًا عنوان URL كامل أو عنوان URL لـ Git.

-r, --reviewer=[] الحصول فقط على طلبات الدمج مع مستخدمين كمراجعين. يمكن فصل المستخدمين المتعددين بفاصلة أو تحديدهم بتكرار العلامة.

--search="" التصفية حسب العنوان والوصف.

-S, --sort="" فرز طلبات الدمج حسب. خيارات الفرز: asc, desc.

-s, --source-branch="" التصفية حسب فرع المصدر.

-t, --target-branch="" التصفية حسب الفرع الهدف.

الخيارات الموروثة من الأوامر الأصل

-h, --help[=false] عرض المساعدة لهذا الأمر.

مثال

$ glab mr list --all
$ glab mr ls -a
$ glab mr list --assignee=@me
$ glab mr list --reviewer=@me
$ glab mr list --source-branch=new-feature
$ glab mr list --target-branch=main
$ glab mr list --search "this adds feature X"
$ glab mr list --label needs-review
$ glab mr list --not-label waiting-maintainer-feedback,subsystem-x
$ glab mr list -M --per-page 10
$ glab mr list --draft
$ glab mr list --not-draft
