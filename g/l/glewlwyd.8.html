GLEWLWYD(8) أدوات إدارة النظام GLEWLWYD(8)

اسم

glewlwyd - خادم تسجيل الدخول الأحادي (SSO) مع مصادقة متعددة العوامل

الوصف

خادم تسجيل الدخول الأحادي (SSO) Glewlwyd مع مصادقة متعددة العوامل

الإصدار 2.6.0

خيارات سطر الأوامر:

-c --config-file PATH

مسار ملف التكوين

-e --env-variables

استخدام متغيرات البيئة لتكوين Glewlwyd

-p --port PORT

المنفذ للاستماع إليه

-u --url-prefix PREFIX

بادئة عنوان URL لواجهة برمجة التطبيقات (API)

-m --log-mode MODE

أوضاع التسجيل المتاحة: console، syslog أو file. إذا كنت تريد أوضاعًا متعددة، فافصل بينها بفاصلة "،" الافتراضي: console

-l --log-level LEVEL

مستويات التسجيل المتاحة: NONE، ERROR، WARNING، INFO، DEBUG الافتراضي: INFO

-f --log-file PATH

مسار ملف السجل إذا تم تحديد وضع السجل file

-v --version

طباعة الإصدار الحالي لـ Glewlwyd

-h --help

طباعة هذه الرسالة

انظر أيضًا

يتم الاحتفاظ بالتوثيق الكامل لـ glewlwyd كدليل Texinfo. إذا كانت البرنامجان info و glewlwyd مثبتين بشكل صحيح في موقعك، فإن الأمر

info glewlwyd

يجب أن يمنحك الوصول إلى الدليل الكامل.
