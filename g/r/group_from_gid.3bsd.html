group_from_gid(3bsd)

الحزمة: libbsd

التراخيص: custom

user_from_uid(3) دليل وظائف المكتبة user_from_uid(3)

الاسم

user_from_uid، uid_from_user، group_from_gid، gid_from_group — تخزين إدخالات كلمة المرور والمجموعة مؤقتًا

المكتبة

المكتبة "libbsd"

الملخص

#include <pwd.h> (انظر libbsd(7) لاستخدام التضمين.)
int
uid_from_user(const char *name, uid_t *uid);

const char *
user_from_uid(uid_t uid, int nouser);

#include <grp.h>

int
gid_from_group(const char *name, gid_t *gid);

const char *
group_from_gid(gid_t gid, int nogroup);

الوصف

تقوم الدالة user_from_uid() بإرجاع اسم المستخدم المرتبط بالوسيط uid. يتم تخزين اسم المستخدم مؤقتًا بحيث لا تتطلب الاستدعاءات المتعددة بنفس uid استدعاءات إضافية لـ getpwuid(3). إذا لم يكن هناك مستخدم مرتبط بـ uid، يتم إرجاع مؤشر إلى تمثيل نصي لـ uid، ما لم تكن الوسيطة nouser غير صفرية، وفي هذه الحالة يتم إرجاع مؤشر فارغ.

تقوم الدالة uid_from_user() بإرجاع معرف المستخدم المرتبط بالوسيط name. يتم تخزين معرف المستخدم مؤقتًا بحيث لا تتطلب الاستدعاءات المتعددة بنفس name استدعاءات إضافية لـ getpwnam(3). إذا لم يكن هناك معرف مستخدم مرتبط بـ name، فإن الدالة uid_from_user() ترجع -1؛ بخلاف ذلك، فإنها تخزن معرف المستخدم في الموقع الذي يشير إليه uid وترجع 0.

تقوم الدالة group_from_gid() بإرجاع اسم المجموعة المرتبط بالوسيط gid. يتم تخزين اسم المجموعة مؤقتًا بحيث لا تتطلب الاستدعاءات المتعددة بنفس gid استدعاءات إضافية لـ getgrgid(3). إذا لم تكن هناك مجموعة مرتبطة بـ gid، يتم إرجاع مؤشر إلى تمثيل نصي لـ gid، ما لم تكن الوسيطة nogroup غير صفرية، وفي هذه الحالة يتم إرجاع مؤشر فارغ.

تقوم الدالة gid_from_group() بإرجاع معرف المجموعة المرتبط بالوسيط name. يتم تخزين معرف المجموعة مؤقتًا بحيث لا تتطلب الاستدعاءات المتعددة بنفس name استدعاءات إضافية لـ getgrnam(3). إذا لم يكن هناك معرف مجموعة مرتبط بـ name، فإن الدالة gid_from_group() ترجع -1؛ بخلاف ذلك، فإنها تخزن معرف المجموعة في الموقع الذي يشير إليه gid وترجع 0.

انظر أيضًا

getgrgid(3)، getpwuid(3)
