GraphViz__XML(3pm)

الحزمة: perl-graphviz

التراخيص: GPL, PerlArtistic

GraphViz::XML(3) وثائق Perl من مساهمة المستخدم GraphViz::XML(3)

الاسم

GraphViz::XML - تصور XML كشجرة

الملخص

use GraphViz::XML;
my $graph = GraphViz::XML->new($xml);
print $g->as_png;

الوصف

تجعل هذه الوحدة من السهل تصور XML كشجرة. XML صعب على البشر فهمه، خاصة إذا كان XML مولدًا بواسطة الكمبيوتر. تهدف هذه الوحدة إلى تصور XML كرسم بياني لجعل بنية XML واضحة والمساعدة في فهم XML.

تمثل عناصر XML كعقد ماسية، مع روابط للعناصر الموجودة بداخلها. البيانات النصية ممثلة في عقد دائرية.

لاحظ أنه يجب تثبيت وحدة XML::Twig.

الأساليب

جديد

هذا هو المنشئ. يأخذ وسيطًا واحدًا إلزاميًا، وهو XML المراد تصوره. يتم إرجاع كائن GraphViz.

my $graph = GraphViz::XML->new($xml);

بصيغة_*

يمكن تصور XML بعدة تنسيقات رسومية مختلفة. تشمل الأساليب as_ps، as_hpgl، as_pcl، as_mif، as_pic، as_gd، as_gd2، as_gif، as_jpeg، as_png، as_wbmp، as_ismap، as_imap، as_vrml، as_vtx، as_mp، as_fig، as_svg. راجع وثائق GraphViz لمزيد من المعلومات. الأسلوبان الأكثر شيوعًا هما:

# طباعة ملف بتنسيق PNG
print $g->as_png;
# طباعة ملف بتنسيق PostScript
print $g->as_ps;

الأخطاء

يميل GraphViz إلى إعادة ترتيب العقد. آمل في إيجاد حل قريبًا (ربما باستخدام المنافذ).
