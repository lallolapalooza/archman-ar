الحزمة: sway-contrib

التراخيص: MIT

grimshot(1) دليل الأوامر العامة grimshot(1)

الاسم

grimshot - مساعد لقطات الشاشة داخل sway

الملخص

grimshot [--notify] [--cursor] [--wait N] (copy|save) [TARGET] [FILE]
grimshot check
grimshot usage

الخيارات

--notify

عرض إشعارات للمستخدم بأنه تم التقاط لقطة شاشة.

--cursor

تضمين مؤشرات في لقطة الشاشة.

--wait N

الانتظار لمدة N ثوانٍ قبل التقاط لقطة شاشة. ينتظر بعد إجراء أي تحديد يدوي. يوصى بالجمع مع --notify لمعرفة وقت التقاط لقطة الشاشة.

save

حفظ لقطة الشاشة في ملف عادي. سيكتب Grimshot ملفات الصور إلى XDG_SCREENSHOTS_DIR إذا تم تعيينها (أو تم تعريفها في user-dirs.dir)، أو سيعود إلى XDG_PICTURES_DIR. قم بتعيين FILE إلى '-' لتوجيه الإخراج إلى STDOUT. قم بتعيين متغير البيئة GRIMSHOT_FILENAME_FORMAT لتجاوز اسم الملف الافتراضي.

copy

نسخ بيانات لقطة الشاشة (كـ image/png) إلى الحافظة.

savecopy

حفظ لقطة الشاشة في ملف عادي (انظر وثائق save) ونسخ بيانات لقطة الشاشة إلى الحافظة (انظر وثائق copy).

الوصف

Grimshot هو أداة سهلة الاستخدام لقطات الشاشة لـ sway. يوفر واجهة مريحة فوق grim و slurp و jq، ويدعم تخزين لقطة الشاشة إما مباشرة إلى الحافظة باستخدام wl-copy أو إلى ملف.

أمثلة

نمط الاستخدام النموذجي هو إضافة هذه الروابط إلى إعدادات sway الخاصة بك:

# لقطات الشاشة:
# Super+P: النافذة الحالية
# Super+Shift+p: تحديد المنطقة
# Super+Alt+p: الإخراج الحالي
# Super+Ctrl+p: تحديد نافذة
bindsym Mod4+p       exec grimshot save active
bindsym Mod4+Shift+p exec grimshot save area
bindsym Mod4+Mod1+p  exec grimshot save output
bindsym Mod4+Ctrl+p  exec grimshot save window

و/أو أضف متغيرات البيئة هذه إلى تكوين shell الخاص بك:

export GRIMSHOT_FILENAME_FORMAT="$(date --iso-8601=ns | tr ':' -)"

الأهداف

يمكن لـ grimshot التقاط الأهداف المسماة التالية:

active

يلتقط النافذة النشطة حاليًا.

screen

يلتقط الشاشة بأكملها. يشمل هذا جميع المخرجات المرئية.

area

يسمح بتحديد منطقة مستطيلة يدويًا، ويلتقطها.

window

يسمح بتحديد نافذة واحدة يدويًا (بالنقر عليها)، ويلتقطها.

output

يلتقط الإخراج النشط حاليًا.

anything

يسمح بتحديد نافذة واحدة يدويًا (بالنقر عليها)، أو إخراج (بالنقر خارج جميع النوافذ، على سبيل المثال، على شريط الحالة)، أو منطقة (باستخدام النقر والسحب).

الإخراج

سيقوم Grimshot بطباعة اسم ملف لقطة الشاشة الملتقطة إلى stdout إذا تم استدعاؤه بالأوامر الفرعية save أو savecopy.
