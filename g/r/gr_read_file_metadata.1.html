GR_READ_FILE_METADATA(1) أوامر المستخدم GR_READ_FILE_METADATA(1)

الاسم

gr_read_file_metadata - أداة Gnu Radio

الوصف

يقرأ ملف Gnu Radio مع بيانات وصفية، ويستخرج الرأس ويطبعه.

مصادر ومصارف الملفات مع البيانات الوصفية (Tom Rondeau)

ينفذ مصدّران جديدان مصادر ومصارف ملفات محسّنة تتضمن بيانات وصفية يتم تمريرها باستخدام ميزة علامات التدفق في Gnu Radio. أصبح من الممكن الآن تخزين أشياء مثل التردد ومعدل العينات في ملفات الالتقاط، أو أي أزواج مفتاح/قيمة أخرى تقوم بوضع علامات عليها لتدفقات البيانات داخل مخطط التدفق.
