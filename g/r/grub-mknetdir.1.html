grub-mknetdir(1)

الحزمة: grub

التراخيص: GPL-3.0-or-later

GRUB-MKNETDIR(1) أوامر المستخدم GRUB-MKNETDIR(1)

الاسم

grub-mknetdir - إعداد دليل شبكة GRUB للتمهيد.

ملخص

grub-mknetdir [خيار...]

الوصف

?يُعد صور التمهيد عبر الشبكة لـ GRUB في net_directory/subdir بافتراض أن net_directory هو جذر TFTP.

--appended-signature-size=حجم
أضف قسم ملاحظة يحجز SIZE بايت لتوقيع ملحق.
--compress=لا|xz|gz|lzo
ضغط ملفات GRUB [اختياري].
--disable-cli
تعطيل الوصول إلى واجهة سطر الأوامر.
--disable-shim-lock
تعطيل مدقق shim_lock.
--dtb=ملف
تضمين DTB محدد.
-d, --directory=دليل
استخدام الصور والوحدات تحت DIR [الافتراضي=/usr/lib/grub/<platform>].
--fonts=خطوط
تثبيت FONTS [الافتراضي=unicode].
--install-modules=وحدات
تثبيت MODULES وتبعياتها فقط [الافتراضي=كل].
-k, --pubkey=ملف
تضمين FILE كمفتاح عام لفحص التوقيع.
--locale-directory=دليل استخدام الترجمات تحت DIR
[الافتراضي=/usr/share/locale].
--locales=لغات
تثبيت LOCALES فقط [الافتراضي=كل].
--modules=وحدات
تحميل الوحدات المحددة MODULES مسبقًا.
--sbat=ملف
بيانات وصفية لـ SBAT.
--themes=سمات
تثبيت THEMES [الافتراضي=starfield].
-v, --verbose
طباعة رسائل تفصيلية.
-x, --x509key=ملف
تضمين FILE كشهادة x509 لفحص التوقيع الملحق.
--core-compress=xz|none|auto
اختر الضغط المستخدم لصورة النواة.
--net-directory=دليل
الدليل الجذر لخادم TFTP.
--subdir=دليل
الدليل الفرعي النسبي على خادم الشبكة.
-؟, --help
عرض قائمة المساعدة هذه.
--usage
عرض رسالة استخدام قصيرة.
-V, --version
طباعة إصدار البرنامج.

الوسائط الإلزامية أو الاختيارية للخيارات الطويلة هي أيضًا إلزامية أو اختيارية لأي خيارات قصيرة مقابلة.

يُعد صور التمهيد عبر الشبكة لـ GRUB في net_directory/subdir بافتراض أن net_directory هو جذر TFTP.

الإبلاغ عن الأخطاء

أبلغ عن الأخطاء إلى <bug-grub@gnu.org>.
