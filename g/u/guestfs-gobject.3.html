guestfs-gobject(3)

الحزمة: libguestfs

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later

guestfs-gobject(3) دعم المحاكاة الافتراضية guestfs-gobject(3)

الاسم

guestfs-gobject - كيفية استخدام libguestfs مع ربطات GObject

مهمل

هذه الربطات مهملة وستتم إزالتها في libguestfs 1.58.

الملخص

من Javascript باستخدام gjs:

const Guestfs = imports.gi.Guestfs;
var g = new Guestfs.Session();
g.add_drive('disk.img', null);
g.launch();
g.close();

الوصف

توثق صفحة الدليل هذه كيفية استدعاء libguestfs باستخدام ربطات GObject، خاصة من Javascript.

لاحظ أن ربطات GObject تواجه مشاكل في التعامل مع القيم 64 بت. يجب ألا تستخدم ربطات GObject إذا كانت هناك ربطات أصلية للغتك. على سبيل المثال، لاستخدام libguestfs من Python، يُنصح بشدة باستخدام ربطات Python الأصلية بدلاً من ذلك (انظر guestfs-python(3)).

هذه الصفحة توثق فقط الاختلافات عن واجهة برمجة التطبيقات C وتعطي بعض الأمثلة. إذا لم تكن على دراية باستخدام libguestfs، فستحتاج أيضًا إلى قراءة guestfs(3).

جافاسكربت

باستخدام gjs، يمكنك كتابة ملف ".js" يحتوي على:

const Guestfs = imports.gi.Guestfs;
var g = new Guestfs.Session();
g.add_drive('disk.img', null);
g.launch();
g.close();

ثم تشغيله باستخدام:

gjs program.js

عند الإبلاغ عن خطأ، يرجى تقديم:
