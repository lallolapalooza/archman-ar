genl-ctrl-list(8) دليل مدير النظام genl-ctrl-list(8)

الاسم

genl-ctrl-list - يسرد العائلات المسجلة من Generic Netlink على جانب النواة

الملخص

genl-ctrl-list [-d]

الوصف

يستعلم من وحدة تحكم Generic Netlink في النواة ويطبع قائمة بجميع عائلات Generic Netlink المسجلة بما في ذلك إصدار الواجهة التي تم تسجيلها.

الخيارات

-h أو --help
يطبع نص المساعدة إلى وحدة التحكم ويخرج.
-v أو --version
يطبع معلومات الإصدار إلى وحدة التحكم ويخرج.
-d أو --details
يشمل معلومات تفصيلية إضافية لكل عائلة Generic Netlink يتم طباعتها.

تشمل المعلومات:

hdrsize N
حجم الرأس الخاص بالمستخدم.
maxattr N
أقصى معرف سمة Netlink تتوقعه الواجهة.
op NAME (ID) <FLAGS>
قائمة بالعمليات المتاحة بما في ذلك اسمها، معرفها الرقمي، والأعلام التي تشير إلى قدرات العملية.

الأعلام المتاحة:

admin-perm
يتطلب صلاحيات إدارية
has-doit
يمكن للعملية التعامل مع الطلب
has-dump
يمكن للعملية التعامل مع طلب تفريغ
has-policy
تطبق العملية سياسة التحقق من السمات
grp NAME (ID)
قائمة بالمجموعات المتعددة البث المسجلة بما في ذلك الاسم (إن وجد) والمعرف.
مثال:
0x0010 nlctrl version 2

hdrsize 0 maxattr 7

op GETFAMILY (0x03) <has-doit,has-dump,has-policy>

grp notify (0x10)

مثال

$ genl-ctrl-list
0x0010 nlctrl version 2
0x0011 NLBL_MGMT version 3
0x0012 NLBL_CIPSOv4 version 3
0x0013 NLBL_UNLBL version 3
0x0014 acpi_event version 1
0x0015 thermal_event version 1
0x0016 VFS_DQUOT version 1
0x0017 TASKSTATS version 1
0x0018 NET_DM version 2
