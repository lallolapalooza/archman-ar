getservent(3) دليل وظائف المكتبة getservent(3)

الاسم

getservent, getservbyname, getservbyport, setservent, endservent - الحصول على إدخال الخدمة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <netdb.h>
struct servent *getservent(void);
struct servent *getservbyname(const char *name, const char *proto);
struct servent *getservbyport(int port, const char *proto);
void setservent(int stayopen);
void endservent(void);

الوصف

تقوم الوظيفة getservent() بقراءة الإدخال التالي من قاعدة بيانات الخدمات (انظر services(5)) وتعيد بنية servent تحتوي على الحقول المفككة من الإدخال. يتم فتح اتصال بقاعدة البيانات إذا لزم الأمر.

تعيد الوظيفة getservbyname() بنية servent للإدخال من قاعدة البيانات الذي يطابق اسم الخدمة name باستخدام البروتوكول proto. إذا كان proto هو NULL، فسيتم مطابقة أي بروتوكول. يتم فتح اتصال بقاعدة البيانات إذا لزم الأمر.

تعيد الوظيفة getservbyport() بنية servent للإدخال من قاعدة البيانات الذي يطابق المنفذ port (المعطى بترتيب البايت الشبكي) باستخدام البروتوكول proto. إذا كان proto هو NULL، فسيتم مطابقة أي بروتوكول. يتم فتح اتصال بقاعدة البيانات إذا لزم الأمر.

تقوم الوظيفة setservent() بفتح اتصال بقاعدة البيانات، وتعيين الإدخال التالي إلى الإدخال الأول. إذا كان stayopen غير صفري، فلن يتم إغلاق الاتصال بقاعدة البيانات بين استدعاءات إحدى وظائف getserv*().

تقوم الوظيفة endservent() بإغلاق الاتصال بقاعدة البيانات.

يتم تعريف البنية servent في <netdb.h> على النحو التالي:


struct servent {
    char  *s_name;       /* الاسم الرسمي للخدمة */
    char **s_aliases;    /* قائمة الأسماء المستعارة */
    int    s_port;       /* رقم المنفذ */
    char  *s_proto;      /* البروتوكول المراد استخدامه */
}

أعضاء البنية servent هم:

s_name
الاسم الرسمي للخدمة.
s_aliases
قائمة بأسماء بديلة للخدمة، تنتهي بـ NULL.
s_port
رقم المنفذ للخدمة بالترتيب الشبكي للبايت.
s_proto
اسم البروتوكول المراد استخدامه مع هذه الخدمة.

قيمة الإرجاع

تعيد الوظائف getservent() و getservbyname() و getservbyport() مؤشرًا إلى بنية servent مخصصة بشكل ثابت، أو NULL إذا حدث خطأ أو تم الوصول إلى نهاية الملف.

الملفات

/etc/services
ملف قاعدة بيانات الخدمات

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
getservent () سلامة الخيط MT-Unsafe race:servent race:serventbuf locale
getservbyname () سلامة الخيط MT-Unsafe race:servbyname locale
getservbyport () سلامة الخيط MT-Unsafe race:servbyport locale
setservent (), endservent () سلامة الخيط MT-Unsafe race:servent locale

في الجدول أعلاه، يشير servent في race:servent إلى أنه إذا تم استخدام أي من الوظائف setservent() أو getservent() أو endservent() بشكل متوازٍ في خيوط مختلفة من البرنامج، فقد تحدث سباقات بيانات.
