getopt(1)

GETOPT - parse command line options

SYNOPSIS

getopt program-options -- your-options -- arg1 arg2 ...

DESCRIPTION

The getopt utility is a shell-compatible wrapper around the C library function getopt(). It is used to parse command-line arguments.

The getopt command reorders the operands of the specified command such that all options are together at the beginning of the operand list, followed by all non-option operands.

PROGRAM OPTIONS

The getopt command itself accepts the following options:

-o short-options
Specifies the short options that are recognized. If an option requires an argument, it is followed by a colon (:).
--
Separates the getopt program options from the command's options.

YOUR OPTIONS

These are the options for the command that you are parsing.

EXIT STATUS

getopt returns an exit status of 0 if the parsing is successful, a non-zero value otherwise.

EXAMPLES

                        $ getopt -o "a:b" -- -a foo -b arg1 arg2
                        -a foo -b -- arg1 arg2
