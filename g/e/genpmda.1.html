GENPMDA(1) دليل الأوامر العام GENPMDA(1)

الاسم

genpmda - مولد وكيل نطاق مقاييس الأداء

الملخص

genpmda [-dv] [-D النطاق] [-n pmns] [-o دليل] [-s stdpmid] [-t topdir] -c ملف_التكوين -i IAM

الوصف

genpmda هو أداة تطوير تطبيقات سريعة لإنشاء وكلاء نطاقات مقاييس أداء جديدة، انظر PMDA(3). يوفر طريقة سهلة وفعالة للغاية لتوسيع Performance Co-pilot (PCP) بمقاييس أداء جديدة دون الحاجة إلى فهم التفاصيل منخفضة المستوى لكيفية بناء وكلاء PMDAs.

genpmda يقرأ ملف تكوين يحتوي على مساحة اسم مقاييس أداء (PMNS) معززة، انظر PMNS(5)، ويقوم تلقائيًا بإنشاء جميع الكود المصدري تقريبًا لتنفيذ وكيل PMDA كامل وظيفي، بما في ذلك Makefile، ومساحة الاسم، وبرامج الدعم النصية لتكوين وكيل PMDA الجديد، ونص المساعدة للمقاييس. يمكن إنشاء وكلاء PMDA بسيطة نسبيًا تلقائيًا من ملف التكوين دون كتابة أي كود إضافي. وكلاء PMDA الأكثر تعقيدًا، على سبيل المثال، التي تحتوي على مجالات مثيل متعددة، تتطلب فقط كتابة طرق التحديث لمجالات المثيل يدويًا.

مثال على صيغة ملف التكوين التي يقبلها genpmda مقدم أدناه.

الخيارات

الخيارات المطلوبة:
-c ملف_التكوين
ملف ملف_التكوين المدخل، انظر المثال أدناه
-i IAM
اسم وكيل PMDA IAM، يجب أن يظهر في stdpmid أو يجب استخدام الخيار -D لتحديد النطاق.
خيارات أخرى:
-d
إنشاء نص Install لوكيل PMDA كخادم (الافتراضي هو DSO)
-D النطاق
استخدم رقم النطاق في pmns و domain.h التي تم إنشاؤها (إذا لم يتم تحديد -s)
-n pmns
استخدم pmns كجذر لمساحة الاسم (الافتراضي يطابق العلم -i)
-o دليل
استخدم دليل للكود المصدري الذي تم إنشاؤه، الافتراضي ./generated
-s stdpmid
المسار إلى stdpmid (الافتراضي ../../pmns/stdpmid)
-t topdir
استخدم topdir في GNUmakefile الذي تم إنشاؤه، الافتراضي ../../..
-v
طباعة رسائل مفصلة حول ما يقوم به genpmda.

مثال:
إنشاء وكيل "example" PMDA باستخدام النطاق 99:


genpmda -D 99 -v -i EXAMPLE -c example.conf

هنا ملف التكوين example.conf (للخيار المطلوب -c): 

example {
    metric
}
example.metric {
    ##  metric            string
    ##  pmid              EXAMPLE:CLUSTER:0
    ##  indom             PM_INDOM_NULL
    ##  type              PM_TYPE_STRING
    ##  units             PMDA_PMUNITS(0,0,0,0,0,0)
    ##  semantics         PM_SEM_DISCRETE
    ##  briefhelptext     one line help text for example.metric.string
    ##  helptext          long help text for example.metric.string
    ##  helptext          This is the second line of the long help text
    ##  helptext          and this is the third line.
    ##  fetch             function example_string_fetch_callback
    ##  code              atom->cp = "hello world";
    ##  code              return 1;
    ##  endmetric
}

بيئة PCP

تُستخدم متغيرات البيئة التي تبدأ بالبادئة PCP_ لتحديد أسماء الملفات والأدلة المستخدمة بواسطة PCP. في كل تثبيت، يحتوي الملف /etc/pcp.conf على القيم المحلية لهذه المتغيرات. يمكن استخدام المتغير $PCP_CONF لتحديد ملف تكوين بديل، كما هو موضح في pcp.conf(5).

انظر أيضاً

pmcd(1), PMDA(3), pcp.conf(5), pcp.env(5) و PMNS(5).
