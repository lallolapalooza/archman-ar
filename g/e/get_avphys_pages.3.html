get_phys_pages(3) دليل وظائف المكتبة get_phys_pages(3)

الاسم

get_phys_pages, get_avphys_pages - الحصول على إجمالي عدد الصفحات المادية المتاحة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/sysinfo.h>
long get_phys_pages(void);
long get_avphys_pages(void);

الوصف

تعيد الدالة get_phys_pages() العدد الإجمالي للصفحات المادية للذاكرة المتوفرة على النظام.

تعيد الدالة get_avphys_pages() عدد الصفحات المادية للذاكرة المتاحة حاليًا على النظام.

قيمة الإرجاع

عند النجاح، تعيد هذه الدوال قيمة غير سالبة كما هو موضح في الوصف. عند الفشل، تعيد -1 وتضبط errno للإشارة إلى الخطأ.

الأخطاء

ENOSYS
لم يتمكن النظام من توفير المعلومات المطلوبة (ربما لأن نظام الملفات /proc لم يكن مثبتًا).

المعايير

GNU.

التاريخ

قبل glibc 2.23، كانت هذه الدوال تحصل على المعلومات المطلوبة عن طريق مسح الحقول MemTotal و MemFree في /proc/meminfo. منذ glibc 2.23، تحصل هذه الدوال على المعلومات المطلوبة عن طريق استدعاء sysinfo(2).

ملاحظات

توفر استدعاءات sysconf(3) التالية وسيلة محمولة للحصول على نفس المعلومات التي توفرها الدوال الموصوفة في هذه الصفحة.


total_pages = sysconf(_SC_PHYS_PAGES);    /* إجمالي الصفحات */
avl_pages = sysconf(_SC_AVPHYS_PAGES);    /* الصفحات المتاحة */

أمثلة

يوضح المثال التالي كيفية استخدام get_phys_pages() و get_avphys_pages().

#include <stdio.h>
#include <stdlib.h>
#include <sys/sysinfo.h>
int
main(void)
{
    printf("This system has %ld pages of physical memory and "
            "%ld pages of physical memory available.\n",
            get_phys_pages(), get_avphys_pages());
    exit(EXIT_SUCCESS);
}
