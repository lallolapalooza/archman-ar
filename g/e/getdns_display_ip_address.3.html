getdns_display_ip_address(3)

الحزمة: getdns

التراخيص: BSD

getdns_display_ip_address(3) getdns getdns_display_ip_address(3)

الاسم

getdns_display_ip_address -- تحويل عنوان IP لـ getdns إلى سلسلة نصية

المكتبة

مكتبة محلل DNS (libgetdns, -lgetdns)

الملخص

#include <getdns.h>

char *
getdns_display_ip_address (const getdns_bindata *ipv4_or_ipv6_addr)

الوصف

تقوم هذه الدالة المساعدة بإرجاع تمثيل سلسلة نصية منسقة بشكل جيد لعنوان IPv4 أو IPv6. يتم استخدام طول bindata لتحديد ما إذا كان العنوان IPv4 أو IPv6.

ipv4_or_ipv6_addr بيانات مرتبطة بالعنوان المراد عرضه

قيم الإرجاع

ترجع تمثيل سلسلة نصية لعنوان IP (تم تخصيصه باستخدام مخصص النظام - malloc)، ويكون المستدعي مسؤولاً عن تحرير مساحة التخزين باستخدام free().
