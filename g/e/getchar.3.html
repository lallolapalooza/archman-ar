fgetc(3) دليل وظائف المكتبة fgetc(3)

الاسم

fgetc, fgets, getchar, ungetc - إدخال الأحرف والسلاسل النصية

المكتبة

مكتبة C القياسية (libc, -lc)

نبذة

#include <stdio.h>
int fgetc(FILE *stream);
int getchar(void);
char *fgets(int size;
            char s[restrict size], int size, FILE *restrict stream);
int ungetc(int c, FILE *stream);

الوصف

تقوم الدالة fgetc() بقراءة الحرف التالي من stream وإرجاعه كـ unsigned char تم تحويله إلى int، أو EOF عند نهاية الملف أو حدوث خطأ.

الدالة getchar() مكافئة لـ fgetc(stdin).

تقوم الدالة fgets() بقراءة ما لا يزيد عن حرف واحد أقل من size من stream وتخزينه في المخزن المؤقت المشار إليه بواسطة s. يتوقف القراءة عند نهاية الملف (EOF) أو عند حرف السطر الجديد. إذا تمت قراءة حرف سطر جديد، فسيتم تخزينه في المخزن المؤقت. سيتم تخزين بايت صفري (null byte) ('\0') بعد الحرف الأخير في المخزن المؤقت.

تقوم الدالة ungetc() بإعادة c إلى stream، بعد تحويلها إلى unsigned char، حيث تكون متاحة لعمليات القراءة اللاحقة. سيتم إرجاع الأحرف المعاد إدخالها بترتيب عكسي؛ يتم ضمان عملية واحدة فقط لإعادة الإدخال.

يمكن خلط استدعاءات الدوال الموصوفة هنا مع بعضها البعض ومع استدعاءات دوال الإدخال الأخرى من مكتبة stdio لنفس مجرى الإدخال.

للحصول على النظائر غير المقفلة، انظر unlocked_stdio(3).

قيمة الإرجاع

تقوم الدالتان fgetc() و getchar() بإرجاع الحرف المقروء كـ unsigned char تم تحويله إلى int أو EOF عند نهاية الملف أو حدوث خطأ.

تقوم الدالة fgets() بإرجاع s عند النجاح، و NULL عند حدوث خطأ أو عند الوصول إلى نهاية الملف ولم يتم قراءة أي أحرف.

تقوم الدالة ungetc() بإرجاع c عند النجاح، أو EOF عند حدوث خطأ.
