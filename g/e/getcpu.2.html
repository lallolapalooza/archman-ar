getcpu(2) دليل استدعاءات النظام getcpu(2)

الاسم

getcpu - تحديد وحدة المعالجة المركزية (CPU) وعقدة NUMA التي تعمل عليها الخيط (thread) المستدعي

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#define _GNU_SOURCE             /* انظر feature_test_macros(7) */
#include <sched.h>
int getcpu(unsigned int *_Nullable cpu, unsigned int *_Nullable node);

الوصف

يقوم استدعاء النظام getcpu() بتحديد المعالج والعقدة التي يعمل عليهما الخيط أو العملية المستعية ويكتبهما في الأعداد الصحيحة التي تشير إليها وسائط cpu و node. المعالج هو عدد صحيح صغير فريد يحدد وحدة معالجة مركزية. العقدة هي معرف صغير فريد يحدد عقدة NUMA. عندما يكون أي من cpu أو node فارغاً (NULL)، لا يتم كتابة شيء في المؤشر المقابل.

المعلومات الموضوعة في cpu مضمون أن تكون حالية فقط في وقت الاستدعاء: ما لم يتم تثبيت الارتباط بوحدة المعالجة المركزية باستخدام sched_setaffinity(2)، يمكن للنواة تغيير وحدة المعالجة المركزية في أي وقت. (لا يحدث هذا عادةً لأن المجدول يحاول تقليل الانتقالات بين وحدات المعالجة المركزية للحفاظ على ذاكرة التخزين المؤقت ساخنة، ولكنه ممكن.) يجب أن يسمح المستدعي بإمكانية أن تكون المعلومات المرجعة في cpu و node لم تعد حالية بحلول وقت عودة الاستدعاء.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EFAULT
تشير الوسائط إلى خارج مساحة عنوان العملية المستعية.

المعايير

Linux.

التاريخ

Linux 2.6.19 (x86-64 و i386)، glibc 2.29.

اختلافات مكتبة C/النواة

استدعاء النظام للنواة له وسيط ثالث:


int getcpu(unsigned int *cpu, unsigned int *node,
           struct getcpu_cache *tcache);

الوسيط tcache غير مستخدم منذ Linux 2.6.24، ويجب تحديده (عند استدعاء استدعاء النظام مباشرة) كـ NULL، ما لم تكن هناك حاجة للتوافق مع Linux 2.6.23 أو الإصدارات الأقدم.

في Linux 2.6.23 والإصدارات الأقدم، إذا كان الوسيط tcache غير فارغ (non-NULL)، فقد أشار إلى مؤشر إلى مخزن مؤقت مخصص من قبل المستدعي في مساحة التخزين المحلية للخيط (thread-local storage) والذي تم استخدامه لتوفير آلية تخزين مؤقت لـ getcpu(). يمكن أن يؤدي استخدام ذاكرة التخزين المؤقت إلى تسريع استدعاءات getcpu()، مقابل وجود فرصة ضئيلة جداً لأن تكون المعلومات المرجعة قديمة. اعتُبرت آلية التخزين المؤقت مسببة للمشاكل عند ترحيل الخيوط بين وحدات المعالجة المركزية، ولذلك تم تجاهل الوسيط الآن.

ملاحظات

تبذل Linux قصارى جهدها لجعل هذا الاستدعاء سريعاً قدر الإمكان. (على بعض البنى، يتم ذلك عبر تنفيذ في vdso(7).) الهدف من getcpu() هو السماح للبرامج بإجراء تحسينات باستخدام بيانات لكل وحدة معالجة مركزية أو لتحسين NUMA.
