الحزمة: gearmand

التراخيص: BSD-3-Clause

NAME

gearman_failed - This page describes return values for the libgearman library.

SYNOPSIS

#include <libgearman/error.h>

DESCRIPTION

The following constants are used for returning error or status information from the various libgearman functions. They are of type gearman_return_t.

CLIENT TO WORKER

type GEARMAN_SUCCESS
The function call was successful.
type GEARMAN_FAILURE
The function call failed. A detailed error message can be obtained via gearman_client_error().
type GEARMAN_HOST_LOOKUP_ERROR
Could not resolve hostname.
type GEARMAN_CONNECTION_ERROR
Could not connect to Gearman server.
type GEARMAN_CONNECTION_LOST
Connection to Gearman server was lost.
type GEARMAN_NETWORK_MEM_IO_ERROR
Memory allocation error.
type GEARMAN_INVALID_ARGUMENT
An invalid argument was passed to the function.
type GEARMAN_BUFFER_TOO_SMALL
A buffer provided was too small.
type GEARMAN_MAX_BUFFER_SIZE
The requested buffer size was too large.
type GEARMAN_LOST_COMMAND
A command was lost between client and server.
type GEARMAN_COMMAND_DELIVERY_TEMPORARY_FAILURE
The command failed to be delivered to a worker, but can be retried.
type GEARMAN_COMMAND_DELIVERY_PERMANENT_FAILURE
The command failed to be delivered to a worker, and can not be retried.
type GEARMAN_COMMAND_INVALID
The command sent to the server was invalid.
type GEARMAN_BAD_CHARACTER
A character in the job name or payload was invalid.
type GEARMAN_WORK_DEQUEUE
Cannot dequeue the job, it may be in use or already completed.
type GEARMAN_WORK_GETNAMED
Worker wanted a named job.
type GEARMAN_WORK_INTEGRITY_BRIBE
Worker requested a bribe, but did not complete the job.
type GEARMAN_WORK_TOO_MANY_REQUESTS
Worker has requested too many jobs.
type GEARMAN_WORK_UNKNOWN_STATE
Worker has encountered an unknown job state.
type GEARMAN_WORK_OUT_OF_MEMORY
Worker ran out of memory.
type GEARMAN_WORK_LOST_CONNECTION
Worker lost connection to gearmand.
type GEARMAN_WORK_SHUTDOWN
Worker has been shut down.
type GEARMAN_WORK_STARVED
No jobs available for worker.
type GEARMAN_CANNOT_DO
Worker does not know how to do this job.
type GEARMAN_UNJOBBER
Worker attempted to use an invalid job handle.
type GEARMAN_TEXT_TOO_LONG
The data sent was too long.
type GEARMAN_NO_JOBS
No jobs were available.
type GEARMAN_EOM
End Of Message

WORKER TO CLIENT

Client which have registed a custom gearman_actions_t may use these value as return values to the calling client.

type GEARMAN_WORK_DATA
Worker has sent a chunked piece of data to the client via gearman_job_send_data()
type GEARMAN_WORK_WARNING
Worker has issued a warning to the client via gearman_job_send_warning()
type GEARMAN_WORK_STATUS
Status has been updated by the worker via gearman_job_send_status()
type GEARMAN_WORK_EXCEPTION
Worker has sent an exception the client via gearman_job_send_exception()
type GEARMAN_WORK_ERROR
A task has had an error and will be retried.
type GEARMAN_PAUSE
Used only in custom application for client return based on GEARMAN_WORK_DATA, GEARMAN_WORK_WARNING, GEARMAN_WORK_EXCEPTION, GEARMAN_WORK_FAIL, or GEARMAN_WORK_STATUS. gearman_continue() can be used to check for this value.

WORKER TO CLIENT

Any function defined by gearman_worker_define_function() may, and can only, return the following gearman_return_t values.

type GEARMAN_FATAL
type GEARMAN_FAIL
The function failed to complete the job. GEARMAN_FATAL is the deprecated name for GEARMAN_FAIL
type GEARMAN_ERROR
A task has had an error and will be retried.
type GEARMAN_SHUTDOWN
GEARMAN_SHUTDOWN is a special case. If it is returned the client will be sent GEARMAN_SUCCESS, but gearman_worker_work() will exit with GEARMAN_SHUTDOWN.

TASK ONLY

type GEARMAN_NOT_FLUSHING
gearman_task_send_workload() failed, it was not in the correct state.
type GEARMAN_DATA_TOO_LARGE
gearman_task_send_workload() failed, the data was too large to be sent.
type GEARMAN_UNKNOWN_OPTION
Default state of task return value.

PROTOCOL

If any of these errors occurred the connection will be dropped/reset.

type GEARMAN_INVALID_MAGIC
type GEARMAN_INVALID_COMMAND
type GEARMAN_INVALID_PACKET
type GEARMAN_UNEXPECTED_PACKET
type GEARMAN_TOO_MANY_ARGS

DEPRECATED

type GEARMAN_IGNORE_PACKET
type GEARMAN_MAX_RETURN

SEE ALSO

gearmand(8) libgearman(3) gearman_client_error() or gearman_worker_error()

الاسم

gearman_failed - تصف هذه الصفحة قيم الإرجاع لمكتبة libgearman.

الملخص

#include <libgearman/error.h>

الوصف

تُستخدم الثوابت التالية لإرجاع معلومات الخطأ أو الحالة من دوال libgearman المختلفة. وهي من نوع gearman_return_t.

العميل إلى العامل

type GEARMAN_SUCCESS
كان استدعاء الدالة ناجحًا.
type GEARMAN_FAILURE
فشل استدعاء الدالة. يمكن الحصول على رسالة خطأ مفصلة عبر gearman_client_error().
type GEARMAN_HOST_LOOKUP_ERROR
تعذر حل اسم المضيف.
type GEARMAN_CONNECTION_ERROR
تعذر الاتصال بخادم Gearman.
type GEARMAN_CONNECTION_LOST
فُقد الاتصال بخادم Gearman.
type GEARMAN_NETWORK_MEM_IO_ERROR
خطأ في تخصيص الذاكرة.
type GEARMAN_INVALID_ARGUMENT
تم تمرير وسيط غير صالح إلى الدالة.
type GEARMAN_BUFFER_TOO_SMALL
كان المخزن المؤقت المقدم صغيرًا جدًا.
type GEARMAN_MAX_BUFFER_SIZE
كان حجم المخزن المؤقت المطلوب كبيرًا جدًا.
type GEARMAN_LOST_COMMAND
فُقد أمر بين العميل والخادم.
type GEARMAN_COMMAND_DELIVERY_TEMPORARY_FAILURE
فشل تسليم الأمر إلى عامل، ولكن يمكن إعادة محاولة ذلك.
type GEARMAN_COMMAND_DELIVERY_PERMANENT_FAILURE
فشل تسليم الأمر إلى عامل، ولا يمكن إعادة محاولة ذلك.
type GEARMAN_COMMAND_INVALID
كان الأمر المرسل إلى الخادم غير صالح.
type GEARMAN_BAD_CHARACTER
كانت حرف في اسم المهمة أو حمولتها غير صالح.
type GEARMAN_WORK_DEQUEUE
تعذر إلغاء قائمة انتظار المهمة، قد تكون قيد الاستخدام أو مكتملة بالفعل.
type GEARMAN_WORK_GETNAMED
رغب العامل في مهمة مسماة.
type GEARMAN_WORK_INTEGRITY_BRIBE
طلب العامل رشوة، لكنه لم يكمل المهمة.
type GEARMAN_WORK_TOO_MANY_REQUESTS
طلب العامل عددًا كبيرًا جدًا من المهام.
type GEARMAN_WORK_UNKNOWN_STATE
واجه العامل حالة مهمة غير معروفة.
type GEARMAN_WORK_OUT_OF_MEMORY
نفدت ذاكرة العامل.
type GEARMAN_WORK_LOST_CONNECTION
فقد العامل الاتصال بـ gearmand.
type GEARMAN_WORK_SHUTDOWN
تم إيقاف تشغيل العامل.
type GEARMAN_WORK_STARVED
لا توجد مهام متاحة للعامل.
type GEARMAN_CANNOT_DO
العامل لا يعرف كيفية القيام بهذه المهمة.
type GEARMAN_UNJOBBER
حاول العامل استخدام مقبض مهمة غير صالح.
type GEARMAN_TEXT_TOO_LONG
كانت البيانات المرسلة طويلة جدًا.
type GEARMAN_NO_JOBS
لم تكن هناك مهام متاحة.
type GEARMAN_EOM
نهاية الرسالة

العامل إلى العميل

يمكن للعملاء الذين قاموا بتسجيل gearman_actions_t مخصص استخدام هذه القيم كقيم إرجاع للعميل المستدعي.

type GEARMAN_WORK_DATA
أرسل العامل جزءًا مقطعًا من البيانات إلى العميل عبر gearman_job_send_data()
type GEARMAN_WORK_WARNING
أصدر العامل تحذيرًا للعميل عبر gearman_job_send_warning()
type GEARMAN_WORK_STATUS
تم تحديث الحالة بواسطة العامل عبر gearman_job_send_status()
type GEARMAN_WORK_EXCEPTION
أرسل العامل استثناءً إلى العميل عبر gearman_job_send_exception()
type GEARMAN_WORK_ERROR
حدث خطأ في مهمة وسيتم إعادة محاولة ذلك.
type GEARMAN_PAUSE
يُستخدم فقط في التطبيق المخصص لإرجاع العميل بناءً على GEARMAN_WORK_DATA، GEARMAN_WORK_WARNING، GEARMAN_WORK_EXCEPTION، GEARMAN_WORK_FAIL، أو GEARMAN_WORK_STATUS. يمكن استخدام gearman_continue() للتحقق من هذه القيمة.

العامل إلى العميل

أي دالة معرفة بواسطة gearman_worker_define_function() قد، ولا يمكنها، إرجاع قيم gearman_return_t التالية فقط.

type GEARMAN_FATAL
type GEARMAN_FAIL
فشلت الدالة في إكمال المهمة. GEARMAN_FATAL هو الاسم المهمل لـ GEARMAN_FAIL
type GEARMAN_ERROR
حدث خطأ في مهمة وسيتم إعادة محاولة ذلك.
type GEARMAN_SHUTDOWN
GEARMAN_SHUTDOWN هو حالة خاصة. إذا تم إرجاعه، سيتم إرسال GEARMAN_SUCCESS إلى العميل، ولكن gearman_worker_work() ستخرج مع GEARMAN_SHUTDOWN.

المهمة فقط

type GEARMAN_NOT_FLUSHING
فشل gearman_task_send_workload()، لم يكن في الحالة الصحيحة.
type GEARMAN_DATA_TOO_LARGE
فشل gearman_task_send_workload()، كانت البيانات كبيرة جدًا بحيث لا يمكن إرسالها.
type GEARMAN_UNKNOWN_OPTION
الحالة الافتراضية لقيمة إرجاع المهمة.
