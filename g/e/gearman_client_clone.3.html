gearman_client_clone(3)

الحزمة: gearmand

التراخيص: BSD-3-Clause

GEARMAN_CLIENT_CLONE(3) Gearmand GEARMAN_CLIENT_CLONE(3)

NAME

gearman_client_clone - توثيق Gearmand، https://gearman.org/gearmand/

SYNOPSIS

#include <libgearman/gearman.h>

gearman_client_st *gearman_client_create(gearman_client_st *client)
gearman_client_st *gearman_client_clone(gearman_client_st *client, const gearman_client_st *from)
void gearman_client_free(gearman_client_st *client)

Link with -lgearman

DESCRIPTION

gearman_client_create() يستخدم لإنشاء بنية c:type:gearman_client_st التي ستستخدم بعد ذلك بواسطة وظائف عميل libgearman الأخرى للتواصل مع الخادم. يجب عليك إما تمرير بنية gearman_client_st معلنة بشكل ثابت إلى gearman_client_create() أو NULL. إذا تم تمرير NULL، فسيتم تخصيص بنية لك.

gearman_client_clone() مشابه لـ gearman_client_create() ولكنه ينسخ الافتراضيات وقائمة الخوادم من بنية gearman_client_st المصدر. إذا مررت NULL كوسيط للمصدر المراد استنساخه، فهو نفس استدعاء gearman_client_create. إذا كان الوسيط الوجهة NULL، فسيتم تخصيص gearman_client_st لك.

لتنظيف الذاكرة المرتبطة ببنية gearman_client_st، يجب تمريرها إلى gearman_client_free عند الانتهاء من استخدامها. gearman_client_free() هي الطريقة الوحيدة للتأكد من إلغاء تخصيص كل الذاكرة عند الانتهاء من استخدام البنية.

تحذير:

قد ترغب في تجنب استخدام gearman_client_create() أو gearman_client_clone() مع تخصيص يعتمد على المكدس، أي الوسيط الأول. معظم المشاكل المتعلقة بسلامة ABI تتعلق بالهياكل المخصصة على المكدس.

RETURN VALUE

gearman_client_create ترجع مؤشرًا إلى gearman_client_st التي تم إنشاؤها (أو تهيئتها). عند فشل التخصيص، ترجع NULL.

gearman_client_clone ترجع مؤشرًا إلى gearman_client_st التي تم إنشاؤها (أو تهيئتها). عند فشل التخصيص، ترجع NULL.
