git-annex-renameremote(1)

git-annex-renameremote(1) دليل الأوامر العامة git-annex-renameremote(1)

الاسم

git-annex-renameremote - يغير اسم جهاز تخزين خاص

الملخص

git annex renameremote name|uuid|desc newname

الوصف

يغير الاسم المستخدم لتمكين جهاز تخزين خاص.

عادةً ما يُستخدم الاسم الحالي لتحديد جهاز التخزين الخاص المراد إعادة تسميته، ولكن يمكن أيضًا استخدام معرّفه الفريد (uuid) أو وصفه.

هذا مفيد بشكل خاص عندما كان جهاز تخزين خاص قديم يستخدم اسمًا، والآن تريد استخدام هذا الاسم لجهاز تخزين خاص جديد. git annex initremote لا يسمح لك بإنشاء جهاز تخزين بنفس الاسم، لذا قم بإعادة تسمية الجهاز القديم أولاً.


git annex renameremote phone lost-phone
git annex initremote phone ...

يقوم هذا فقط بتحديث الاسم الذي يخزنه git-annex للاستخدام بواسطة git annex enableremote. لا يقوم بتحديث قسم تكوين git لجهاز التخزين الخاص لاستخدام الاسم الجديد، ولكن بالطبع يمكنك تعديل تكوين git إذا كنت ترغب في إعادة تسميته هناك.

الخيارات

يمكن استخدام الخيارات العامة لـ git-annex (git-annex-common-options(1)).
