الاسم

git-var - عرض متغير منطقي في Git

الملخص

git var (-l | <variable>)

الوصف

يطبع متغير منطقي في Git. يخرج برمز 1 إذا لم يكن للمتغير قيمة.

خيارات

-l

يعرض المتغيرات المنطقية. بالإضافة إلى ذلك، يتم إدراج جميع متغيرات ملف تكوين Git .git/config أيضًا. (ومع ذلك، فإن وظيفة إدراج متغيرات التكوين مهملة لصالح git config -l.)

أمثلة

$ git var GIT_AUTHOR_IDENT
Eric W. Biederman <ebiederm@lnxi.com> 1121223278 -0600

المتغيرات

GIT_AUTHOR_IDENT

مؤلف قطعة من الكود.

GIT_COMMITTER_IDENT

الشخص الذي أدخل قطعة من الكود في Git.

GIT_EDITOR

محرر نصوص لاستخدامه بواسطة أوامر Git. القيمة مخصصة ليتم تفسيرها بواسطة الصدفة عند استخدامها. أمثلة: ~/bin/vi، $SOME_ENVIRONMENT_VARIABLE، "C:\Program Files\Vim\gvim.exe" --nofork. ترتيب الأفضلية هو $GIT_EDITOR، ثم قيمة تكوين core.editor، ثم $VISUAL، ثم $EDITOR، ثم الافتراضي الذي تم اختياره وقت التجميع، وهو عادةً vi.

GIT_SEQUENCE_EDITOR

محرر نصوص يستخدم لتحرير ملف todo أثناء تشغيل git rebase -i. مثل GIT_EDITOR، القيمة مخصصة ليتم تفسيرها بواسطة الصدفة عند استخدامها. ترتيب الأفضلية هو $GIT_SEQUENCE_EDITOR، ثم قيمة تكوين sequence.editor، ثم قيمة git var GIT_EDITOR.

GIT_PAGER

عارض نصوص لاستخدامه بواسطة أوامر Git (مثل less). القيمة مخصصة ليتم تفسيرها بواسطة الصدفة. ترتيب الأفضلية هو $GIT_PAGER، ثم قيمة تكوين core.pager، ثم $PAGER، ثم الافتراضي الذي تم اختياره وقت التجميع (عادةً less).

GIT_DEFAULT_BRANCH

اسم الفرع الأول الذي تم إنشاؤه في المستودعات المهيأة حديثًا.

GIT_SHELL_PATH

مسار الثنائي الذي يوفر صدفة POSIX للأوامر التي تستخدم الصدفة.

GIT_ATTR_SYSTEM

مسار ملف gitattributes(5) للنظام، إذا تم تمكين واحد.

GIT_ATTR_GLOBAL

مسار ملف gitattributes(5) العام (لكل مستخدم).

GIT_CONFIG_SYSTEM

مسار ملف التكوين للنظام، إذا تم تمكين واحد.

GIT_CONFIG_GLOBAL

مسار ملفات التكوين العامة (لكل مستخدم)، إذا وجدت.

تحتوي معظم قيم المسارات على قيمة واحدة فقط. ومع ذلك، يمكن أن تحتوي بعضها على قيم متعددة، مفصولة بأسطر جديدة، ويتم سردها بترتيب من الأولوية الأعلى إلى الأدنى. يجب أن يكون المتصلون مستعدين لأي قيمة مسار من هذا القبيل تحتوي على عناصر متعددة.

لاحظ أنه يتم طباعة المسارات حتى لو لم تكن موجودة، ولكن ليس إذا تم تعطيلها بواسطة متغيرات بيئة أخرى.
