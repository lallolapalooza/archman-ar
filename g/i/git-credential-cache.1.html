git-credential-cache(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-CREDENTIAL-CACHE(1) دليل Git GIT-CREDENTIAL-CACHE(1)

الاسم

git-credential-cache - مساعد لتخزين كلمات المرور مؤقتًا في الذاكرة

الملخص

git config credential.helper 'cache [<options>]'

الوصف

يقوم هذا الأمر بتخزين بيانات الاعتماد مؤقتًا للاستخدام بواسطة برامج Git المستقبلية. يتم الاحتفاظ ببيانات الاعتماد المخزنة في ذاكرة عملية cache-daemon (بدلاً من كتابتها في ملف) ويتم نسيانها بعد انتهاء مهلة قابلة للتكوين. يتم نسيان بيانات الاعتماد بشكل أسرع إذا ماتت عملية cache-daemon، على سبيل المثال إذا أعيد تشغيل النظام. يمكن الوصول إلى ذاكرة التخزين المؤقت عبر مقبس مجال Unix، مقيدة بالمستخدم الحالي بواسطة أذونات نظام الملفات.

من غير المرجح أن ترغب في استدعاء هذا الأمر مباشرة؛ فهو مخصص للاستخدام كمساعد بيانات اعتماد بواسطة أجزاء أخرى من Git. انظر gitcredentials(7) أو أمثلة أدناه.

خيارات

--timeout <seconds>

عدد الثواني لتخزين بيانات الاعتماد مؤقتًا (الافتراضي: 900).

--socket <path>

استخدم <path> للاتصال بعملية cache daemon قيد التشغيل (أو بدء عملية cache daemon جديدة إذا لم تكن قيد التشغيل). الافتراضي هو $XDG_CACHE_HOME/git/credential/socket ما لم يكن ~/.git-credential-cache/ موجودًا، وفي هذه الحالة يتم استخدام ~/.git-credential-cache/socket بدلاً من ذلك. إذا كان دليل منزلك موجودًا على نظام ملفات مثبت على الشبكة، فقد تحتاج إلى تغيير هذا إلى نظام ملفات محلي. يجب عليك تحديد مسار مطلق.

التحكم في عملية الخادم

إذا كنت ترغب في أن تخرج عملية الخادم مبكرًا، وتنسى جميع بيانات الاعتماد المخزنة مؤقتًا قبل انتهاء مهلتها، يمكنك إصدار إجراء exit:

git credential-cache exit

أمثلة

الهدف من هذا المساعد هو تقليل عدد المرات التي يجب عليك فيها كتابة اسم المستخدم أو كلمة المرور. على سبيل المثال:

$ git config credential.helper cache
$ git push http://example.com/repo.git
Username: <اكتب اسم المستخدم الخاص بك>
Password: <اكتب كلمة المرور الخاصة بك>
[يعمل لمدة 5 دقائق إضافية]
$ git push http://example.com/repo.git
[يتم استخدام بيانات الاعتماد الخاصة بك تلقائيًا]

يمكنك توفير خيارات عبر متغير تكوين credential.helper (هذا المثال يزيد وقت التخزين المؤقت لمدة ساعة واحدة):

$ git config credential.helper 'cache --timeout=3600'

رموز الوصول الشخصية

تقبل بعض المستودعات البعيدة رموز الوصول الشخصية، والتي يتم إنشاؤها عشوائيًا ويصعب حفظها. عادة ما تكون لها فترة صلاحية تمتد لأسابيع أو أشهر.

يعتبر git-credential-cache غير مناسب بطبيعته للتخزين الدائم لرموز الوصول الشخصية. سيتم نسيان بيانات الاعتماد بعد انتهاء مهلة ذاكرة التخزين المؤقت. حتى إذا قمت بتكوين مهلة طويلة، فسيتم نسيان بيانات الاعتماد إذا ماتت عملية الخادم.

لتجنب إعادة إنشاء رموز الوصول الشخصية بشكل متكرر، قم بتكوين مساعد بيانات اعتماد مع تخزين دائم. بدلاً من ذلك، قم بتكوين مساعد بيانات اعتماد OAuth لإنشاء بيانات الاعتماد تلقائيًا. انظر gitcredentials(7)، الأقسام "Available helpers" و "OAuth".
