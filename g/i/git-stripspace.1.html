git-stripspace(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-STRIPSPACE(1) دليل Git GIT-STRIPSPACE(1)

الاسم

git-stripspace - إزالة المسافات البيضاء غير الضرورية

الملخص

git stripspace [-s | --strip-comments]
git stripspace [-c | --comment-lines]

الوصف

اقرأ النص، مثل رسائل الالتزام، الملاحظات، العلامات، وأوصاف الفروع، من المدخل القياسي وقم بتنظيفها بالطريقة التي يستخدمها Git.

بدون وسائط، سيتم القيام بما يلي:

•إزالة المسافات البيضاء اللاحقة من جميع الأسطر
•ضغط الأسطر الفارغة المتتالية المتعددة إلى سطر فارغ واحد
•إزالة الأسطر الفارغة من بداية ونهاية المدخل
•إضافة حرف سطر جديد (\n) مفقود إلى السطر الأخير إذا لزم الأمر.

في حالة أن المدخل يتكون بالكامل من أحرف مسافات بيضاء، فلن يتم إنتاج أي مخرجات.

ملاحظة: هذا مخصص لتنظيف البيانات الوصفية. فضل استخدام وضع --whitespace=fix الخاص بـ git-apply(1) لتصحيح المسافات البيضاء في الرقع (patches) أو الملفات في المستودع.

الخيارات

-s, --strip-comments

تجاهل وإزالة جميع الأسطر التي تبدأ بحرف تعليق (core.commentChar، الافتراضي هو #).

-c, --comment-lines

أضف حرف التعليق ومسافة فارغة قبل كل سطر. سيتم إنهاء الأسطر تلقائيًا بحرف سطر جديد. في الأسطر الفارغة، سيتم إضافة حرف التعليق فقط.

أمثلة

بالنظر إلى المدخل المزعج التالي مع $ للإشارة إلى نهاية السطر:

|مقدمة موجزة   $
|   $
|$
|فقرة جديدة$
|# مع سطر معلّق   $
|يشرح الكثير من الأشياء.$
|$
|# فقرة قديمة، معلّقة أيضًا. $
|      $
|النهاية.$
|  $

استخدم git stripspace بدون وسائط للحصول على:

|مقدمة موجزة$
|$
|فقرة جديدة$
|# مع سطر معلّق$
|يشرح الكثير من الأشياء.$
|$
|# فقرة قديمة، معلّقة أيضًا.$
|$
|النهاية.$

استخدم git stripspace --strip-comments للحصول على:

|مقدمة موجزة$
|$
|فقرة جديدة$
|يشرح الكثير من الأشياء.$
|$
|النهاية.$
