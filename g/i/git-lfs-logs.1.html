git-lfs-logs(1)

الحزمة: git-lfs

التراخيص: MIT

GIT-LFS-LOGS(1)   GIT-LFS-LOGS(1)

الاسم

git-lfs-logs - عرض الأخطاء من أمر git-lfs

الملخص

git lfs logs
git lfs logs <ملف>
git lfs logs clear
git lfs logs boomtown

الوصف

عرض الأخطاء من أمر git-lfs. في كل مرة يتعطل فيها، يتم حفظ التفاصيل في ".git/lfs/logs".

الأوامر

clear

يمسح جميع سجلات الأخطاء الموجودة.

boomtown

يُنشئ استثناءً وهميًا.

خيارات

بدون أي خيارات، تعرض git lfs logs ببساطة قائمة بسجلات الأخطاء.

•<file>: يعرض سجل الخطأ المحدد. استخدم "last" لعرض أحدث خطأ.

انظر أيضًا

جزء من حزمة git-lfs(1).
