الحزمة: git

GIT-PACK-REDUNDANT(1) Git Manual GIT-PACK-REDUNDANT(1)

اسم

git-pack-redundant - البحث عن ملفات الحزم الزائدة

ملخص

git pack-redundant [--verbose] [--alt-odb] (--all | <pack-filename>...)

تحذير

تم إهمال git pack-redundant وهو مجدول للإزالة في إصدار مستقبلي من Git. نظرًا لأنه يمكنه فقط إزالة حزم مكررة كاملة وليس كائنات فردية مكررة، فإنه بشكل عام ليس أداة مفيدة لتقليل حجم المستودع. من الأفضل استخدام git gc للقيام بذلك، والذي سيضع الكائنات في حزمة جديدة، وإزالة التكرارات.

سيؤدي تشغيل pack-redundant بدون العلامة --i-still-use-this إلى الفشل في هذا الإصدار. إذا كنت تعتقد أن لديك حالة استخدام تكون فيها pack-redundant مناسبة أكثر وتعترض على هذه الإزالة، فيرجى الاتصال بقائمة بريد Git على git@vger.kernel.org[1]. تتوفر مزيد من المعلومات حول القائمة على https://git-scm.com/community.

الوصف

يحسب هذا البرنامج الحزم الزائدة في المستودع الخاص بك. الناتج مناسب للتوجيه إلى xargs rm إذا كنت في جذر المستودع.

يقبل git pack-redundant قائمة بالكائنات على الإدخال القياسي. سيتم تجاهل أي كائنات معطاة عند التحقق من الحزم المطلوبة. هذا يجعل الأمر التالي مفيدًا عند الرغبة في إزالة الحزم التي تحتوي على كائنات غير قابلة للوصول.

git fsck --full --unreachable | cut -d ' ' -f3 | \ git pack-redundant --all | xargs rm

الخيارات

--all

يعالج جميع الحزم. يتم تجاهل أي أسماء ملفات في سطر الأوامر.

--alt-odb

لا تتطلب الكائنات الموجودة في الحزم من قواعد بيانات الكائنات البديلة (odb) أن تكون موجودة في الحزم المحلية.

--verbose

يخرج بعض الإحصائيات إلى stderr. له عقوبة أداء صغيرة.
