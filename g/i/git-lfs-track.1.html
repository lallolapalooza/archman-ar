الاسم

git-lfs-track - عرض أو إضافة مسارات Git LFS إلى سمات Git

الموجز

git lfs track [خيارات] [<نمط>...]

الوصف

بدء تتبع الأنماط المحددة من خلال Git LFS. تتم كتابة الوسيطة إلى .gitattributes. إذا لم يتم توفير مسارات، فقم ببساطة بسرد المسارات التي يتم تتبعها حاليًا.

تنص وثائق gitattributes https://git-scm.com/docs/gitattributes على أن الأنماط تستخدم قواعد نمط gitignore https://git-scm.com/docs/gitignore لمطابقة المسارات. هذا يعني أن الأنماط التي تحتوي على النجمة (*) أو علامة الاستفهام (?) أو أقواس الأحرف ([ و ]) يتم التعامل معها بشكل خاص؛ لتعطيل هذا السلوك والتعامل معها حرفيًا بدلاً من ذلك، استخدم --filename أو قم بتهريب الحرف بشرطة مائلة للخلف.

خيارات

--verbose, -v

إذا تم تمكينه، اجعل git lfs track يسجل الملفات التي سيقوم بلمسها. معطل افتراضيًا.

--dry-run, -d

إذا تم تمكينه، اجعل git lfs track يسجل جميع الإجراءات التي سيتخذها عادةً (إضافة إدخالات إلى .gitattributes، لمس الملفات على القرص، إلخ) دون إجراء أي عمليات تعديل على القرص.

git lfs track --dry-run [ملفات] يحاكي أيضًا بشكل ضمني سلوك تمرير --verbose، وسيقوم بتسجيل تفاصيل أكبر حول ما يفعله.

معطل افتراضيًا.

--filename

عامل الوسيطات كأسماء ملفات حرفية، وليس كأنماط. سيتم تهريب أي أحرف حرفية في اسم الملف عند كتابة ملف .gitattributes.

--lockable, -l

اجعل المسارات "قابلة للقفل"، مما يعني أنه يجب قفلها لتعديلها، وستصبح للقراءة فقط في نسخة العمل عندما لا تكون مقفلة.

--not-lockable

قم بإزالة علامة القابلة للقفل من المسارات بحيث لم تعد للقراءة فقط ما لم يتم قفلها.

--no-excluded


لا تسرد الأنماط المستبعدة في الإخراج؛ قم فقط بسرد الأنماط التي يتم تتبعها. --no-modify-attrs: يجعل الإدخالات المطابقة "متسخة" بحيث يمكن لـ Git إعادة فهرسة الملفات التي ترغب في تحويلها إلى LFS. لا يعدل أي ملف .gitattributes.

أمثلة

•سرد الأنماط التي يتتبعها Git LFS حاليًا:

git lfs track

•تكوين Git LFS لتتبع ملفات GIF:

git lfs track "*.gif"

•تكوين Git LFS لتتبع ملفات PSD وجعلها للقراءة فقط ما لم يتم قفلها:

git lfs track --lockable "*.psd"

•تكوين Git LFS لتتبع الملف المسمى project [1].psd:

git lfs track --filename "project [1].psd"

انظر أيضًا

git-lfs-untrack(1), git-lfs-install(1), gitattributes(5), gitignore(5).
