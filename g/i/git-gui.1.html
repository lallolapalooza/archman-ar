git-gui(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-GUI(1) دليل Git GIT-GUI(1)

الاسم

git-gui - واجهة رسومية محمولة لـ Git

الملخص

git gui [<command>] [<arguments>]

الوصف

واجهة مستخدم رسومية تعتمد على Tcl/Tk لـ Git. تركز git gui على تمكين المستخدمين من إجراء تغييرات على مستودعاتهم عن طريق إنشاء التزامات (commits) جديدة، تعديل الالتزامات الحالية، إنشاء فروع (branches)، إجراء عمليات دمج (merges) محلية، وجلب (fetching) ودفع (pushing) إلى مستودعات بعيدة.

بخلاف gitk، تركز git gui على إنشاء الالتزامات وتوصيف الملف الواحد ولا تعرض تاريخ المشروع. ومع ذلك، فإنها توفر إجراءات في القائمة لبدء جلسة gitk من داخل git gui.

git gui معروفة بالعمل على جميع أنظمة UNIX الشائعة، Mac OS X، وWindows (تحت كل من Cygwin وMSYS). قدر الإمكان، يتم اتباع إرشادات واجهة المستخدم الخاصة بنظام التشغيل، مما يجعل git gui واجهة أصلية إلى حد ما للمستخدمين.

الأوامر

blame

ابدأ عارض blame على الملف المحدد في الإصدار المعطى (أو دليل العمل إذا لم يتم تحديده).

browser

ابدأ متصفح شجرة يعرض جميع الملفات في الالتزام المحدد. الملفات المختارة من خلال المتصفح تفتح في عارض blame.

citool

ابدأ git gui ورتب لإجراء التزام واحد بالضبط قبل الخروج والعودة إلى الصدفة (shell). الواجهة مقصورة على إجراءات الالتزام فقط، مما يقلل من وقت بدء تشغيل التطبيق قليلاً ويبسط شريط القوائم.

version

عرض الإصدار الحالي من git gui.

أمثلة

git gui blame Makefile

اعرض محتويات الملف Makefile في دليل العمل الحالي، وقدم تعليقات توضيحية لكل من المؤلف الأصلي لكل سطر، ومن نقل السطر إلى موقعه الحالي. يتم تعليق الملف غير الملتزم، ويتم تعيين التغييرات غير الملتزم (إن وجدت) صراحة إلى Not Yet Committed.

git gui blame v0.99.8 Makefile

اعرض محتويات Makefile في المراجعة v0.99.8 وقدم تعليقات توضيحية لكل سطر. بخلاف المثال أعلاه، يتم قراءة الملف من قاعدة بيانات الكائنات وليس من دليل العمل.

git gui blame --line=100 Makefile

قم بتحميل التعليقات التوضيحية كما هو موضح أعلاه وقم بالتمرير التلقائي للعرض ليتمركز حول السطر 100.

git gui citool

قم بإجراء التزام واحد وعد إلى الصدفة عند اكتماله. يعيد هذا الأمر رمز خروج غير صفري إذا تم إغلاق النافذة بأي طريقة أخرى غير إجراء التزام.

git gui citool --amend

ادخل تلقائيًا إلى وضع Amend Last Commit (تعديل آخر التزام) في الواجهة.

git gui citool --nocommit

تصرف مثل citool العادي، ولكن بدلاً من إجراء التزام، قم ببساطة بالإنهاء برمز خروج صفري. لا يزال يتحقق من أن الفهرس لا يحتوي على أي إدخالات غير مدمجة، لذلك يمكنك استخدامه كإصدار واجهة رسومية لـ git-mergetool(1)

git citool

نفس الأمر git gui citool (أعلاه).

git gui browser maint

اعرض متصفحًا لشجرة الفرع maint. يمكن عرض الملفات المختارة في المتصفح باستخدام عارض blame الداخلي.

انظر أيضاً

gitk(1)

متصفح مستودع Git. يعرض الفروع، سجل الالتزامات، واختلافات الملفات. gitk هو الأداة التي تبدأها إجراءات Repository Visualize في git gui.

أخرى

git gui تتم صيانتها فعليًا كمشروع مستقل، ولكن الإصدارات المستقرة يتم توزيعها كجزء من مجموعة Git لتسهيل المستخدمين النهائيين.

يمكن العثور على المستودع الرسمي لمشروع git gui في:

https://github.com/j6t/git-gui
