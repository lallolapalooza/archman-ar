git-commit-tree(1)

git-commit-tree - Write a new commit object

الاسم

git-commit-tree - Write a new commit object

الملخص

git commit-tree <tree> [<parent>...]

الوصف

This command is used to create a new commit object. It takes the tree and parent commit(s) as arguments, and reads the commit log message from standard input. It then creates a new commit object and prints its 7-bit ASCII object name to standard output.

خيارات

-m <message>
Use the given <message> as the commit log message. If this option is given, the command will not read from standard input.
-F <file>
Use the given file as the commit log message. If this option is given, the command will not read from standard input.
-p <parent>
Use the given <parent> as a parent commit. This option can be given multiple times to specify multiple parents. If no parent commits are specified, the new commit will be a root commit.
-s
Use the signature of the author as the committer. This option is useful when creating commits on behalf of someone else.
-S
Sign the new commit object with GPG.

معلومات الالتزام

A commit object contains the following information:

  • The tree object name of the root of the tree.
  • The parent commit object names.
  • The author's name and email address.
  • The committer's name and email address.
  • The commit date and time.
  • The commit log message.

صيغ التاريخ

The commit date and time are stored in a human-readable format. The following formats are supported:

  • %a %b %d %H:%M:%S %Y %z (e.g., Mon Aug 15 10:30:00 2016 -0700)
  • %a %b %d %H:%M:%S %Y %Z (e.g., Mon Aug 15 10:30:00 2016 PDT)

مناقشة

This command is usually not used directly by end-users. It is typically used by other Git commands, such as git commit, to create new commit objects.

الملفات

.git/COMMIT_EDITMSG
When a commit message is being edited, the previous message is written to this file.
