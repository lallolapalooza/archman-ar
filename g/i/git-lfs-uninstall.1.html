الحزمة: git-lfs

GIT-LFS-UNINSTALL(1)   GIT-LFS-UNINSTALL(1)

الاسم

git-lfs-uninstall - إزالة إعداد Git LFS

الملخص

git lfs uninstall

الوصف

قم بتنفيذ الإجراءات التالية لإزالة إعداد Git LFS:

•إزالة مرشحات التنظيف والمسح "lfs" من إعداد Git العام.
•إلغاء تثبيت خطاف الدفع المسبق لـ Git LFS إذا تم تشغيله من داخل مستودع Git.

خيارات

--local

يزيل مرشحات المسح والتنظيف "lfs" من إعداد Git الخاص بالمستودع المحلي، بدلاً من إعداد Git العام (~/.gitconfig).

--worktree

يزيل مرشحات المسح والتنظيف "lfs" من إعداد Git لشجرة العمل الحالية، بدلاً من إعداد Git العام (~/.gitconfig) أو إعداد Git الخاص بالمستودع المحلي ($GIT_DIR/config). إذا كانت هناك أشجار عمل متعددة قيد الاستخدام، فيجب تمكين امتداد إعداد Git worktreeConfig لاستخدام هذا الخيار. إذا كانت شجرة عمل واحدة فقط قيد الاستخدام، فإن --worktree له نفس تأثير --local. هذا الخيار متاح فقط إذا كان إصدار Git المثبت هو 2.20.0 أو أحدث ويدعم بالتالي امتداد "worktreeConfig".

--system

يزيل مرشحات المسح والتنظيف "lfs" من إعداد Git للنظام، بدلاً من إعداد Git العام (~/.gitconfig).

--skip-repo

يتجاوز تنظيف المستودع المحلي؛ استخدمه إذا كنت ترغب في إلغاء تثبيت مرشحات lfs العامة ولكن لا ترغب في إجراء تغييرات على المستودع الحالي.

انظر أيضاً

git-lfs-install(1), git-worktree(1).
