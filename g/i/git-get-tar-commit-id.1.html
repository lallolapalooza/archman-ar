git-get-tar-commit-id(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-GET-TAR-COMMIT-ID(1) دليل Git GIT-GET-TAR-COMMIT-ID(1)

اسم

git-get-tar-commit-id - استخراج معرف الالتزام من أرشيف تم إنشاؤه باستخدام git-archive

نظرة عامة

git get-tar-commit-id

الوصف

اقرأ أرشيف tar تم إنشاؤه بواسطة git archive من المدخل القياسي واستخرج معرف الالتزام المخزن فيه. يقرأ فقط أول 1024 بايت من المدخلات، وبالتالي لا يتأثر وقت تشغيله بحجم أرشيف tar بشكل كبير.

إذا لم يتم العثور على معرف التزام، فإن git get-tar-commit-id يخرج بهدوء برمز إرجاع 1. يمكن أن يحدث هذا إذا لم يتم إنشاء الأرشيف باستخدام git archive أو إذا كان المعامل الأول لـ git archive هو معرف شجرة بدلاً من معرف التزام أو علامة.
