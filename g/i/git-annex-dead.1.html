git-annex-dead(1)

الحزمة: git-annex

التراخيص: AGPL-3.0-only

git-annex-dead(1) دليل الأوامر العامة git-annex-dead(1)

الاسم

git-annex-dead - إخفاء مستودع مفقود أو مفتاح

الملخص

git annex dead [مستودع ...] [--مفتاح مفتاح_ما ...]

الوصف

هذا الأمر موجود للتعامل مع المواقف التي فقدت فيها البيانات، وأنت تعرف ذلك، وتريد التوقف عن التذكير بتلك الحقيقة.

عند تحديد مستودع، فإنه يشير إلى أن المستودع قد فُقد بشكل لا يمكن استرداده، لذلك لن يتم إدراجه في، على سبيل المثال، git annex whereis. يمكن تحديد المستودعات باستخدام اسمها البعيد، أو وصفها، أو UUID الخاص بها. (للتراجع، استخدم git annex semitrust.)

عند تحديد مفتاح، فإنه يشير إلى أن محتوى هذا المفتاح قد فُقد بشكل لا يمكن استرداده. هذا يجعل المفتاح يتم تخطيه عند العمل على جميع المفاتيح باستخدام، على سبيل المثال، --all. (للتراجع، أعد محتوى المفتاح إلى المستودع، باستخدام، على سبيل المثال، git annex reinject.)

خيارات

--key=somekey
استخدم لتحديد مفتاح ميت.
--json
تمكين إخراج JSON. هذا مخصص للتحليل بواسطة البرامج التي تستخدم git-annex. كل سطر من الإخراج هو كائن JSON.
--json-error-messages
الرسائل التي يتم إخراجها عادةً إلى الخطأ القياسي مدرجة في JSON بدلاً من ذلك.
أيضًا يمكن استخدام git-annex-common-options(1).
