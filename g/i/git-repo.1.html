الحزمة: git

GIT-REPO(1) Git Manual GIT-REPO(1)

اسم

git-repo - استرداد معلومات حول المستودع

الملخص

git repo info [--format=(keyvalue|nul)] [-z] [<key>...]
git repo structure [--format=(table|keyvalue|nul)]

الوصف

استرداد معلومات حول المستودع.

هذا الأمر تجريبي. قد يتغير السلوك.

الأوامر

info [--format=(keyvalue|nul)] [-z] [<key>...]

استرداد معلومات متعلقة بالبيانات الوصفية للمستودع الحالي. سيتم إرجاع البيانات المطلوبة فقط بناءً على مفاتيحها (انظر قسم "مفاتيح المعلومات" أدناه).

سيتم إرجاع القيم بنفس الترتيب الذي تم به طلب المفاتيح الخاصة بها.

يمكن اختيار تنسيق الإخراج من خلال العلامة --format. يتم دعم تنسيقين:

keyvalue

إخراج أزواج المفتاح والقيمة سطرًا بسطر باستخدام الحرف = كفاصل بين المفتاح والقيمة. القيم التي تحتوي على أحرف "غير عادية" يتم اقتباسها كما هو موضح لمتغير التكوين core.quotePath (انظر git-config(1)). هذا هو الافتراضي.

nul

مشابه لـ keyvalue، ولكن باستخدام حرف سطر جديد كفاصل بين المفتاح والقيمة واستخدام حرف NUL بعد كل قيمة. هذا التنسيق مناسب بشكل أفضل ليتم تحليله بواسطة تطبيق آخر من keyvalue. بخلاف تنسيق keyvalue، لا يتم اقتباس القيم أبدًا.

-z هو اسم مستعار لـ --format=nul.

structure [--format=(table|keyvalue|nul)]

استرداد إحصائيات حول بنية المستودع الحالي. يتم الإبلاغ عن أنواع المعلومات التالية:
•عدد المراجع مصنفة حسب النوع
•عدد الكائنات التي يمكن الوصول إليها مصنفة حسب النوع

يمكن اختيار تنسيق الإخراج من خلال العلامة --format. يتم دعم ثلاثة تنسيقات:

table

إخراج إحصائيات المستودع في جدول سهل القراءة. قد يتغير هذا التنسيق وهو غير مخصص للتحليل الآلي. هذا هو التنسيق الافتراضي.

keyvalue

يحتوي كل سطر من الإخراج على زوج مفتاح-قيمة لإحصائية المستودع. يتم استخدام الحرف = للفصل بين المفتاح والقيمة. القيم التي تحتوي على أحرف "غير عادية" يتم اقتباسها كما هو موضح لمتغير التكوين core.quotePath (انظر git-config(1)).

nul

مشابه لـ keyvalue، ولكنه يستخدم حرف NUL للفصل بين أزواج المفتاح والقيمة بدلاً من سطر جديد. كما أنه يستخدم حرف سطر جديد كفاصل بين المفتاح والقيمة بدلاً من =. بخلاف تنسيق keyvalue، لا يتم اقتباس القيم التي تحتوي على أحرف "غير عادية" أبدًا.

مفاتيح المعلومات

للحصول على مجموعة من القيم من git repo info، يجب عليك تقديم المفاتيح التي تحددها. إليك قائمة بالمفاتيح المتاحة والقيم التي ترجعها:

layout.bare

true إذا كان هذا مستودعًا فارغًا، وإلا false.

layout.shallow

true إذا كان هذا مستودعًا ضحلًا، وإلا false.

object.format

تنسيق الكائن (خوارزمية التجزئة) المستخدم في المستودع.

references.format

تنسيق تخزين المرجع. القيم الصالحة هي:
•files للملفات غير المعبأة مع ملفات packed-refs. هذا هو الافتراضي.
•reftable لتنسيق reftable. هذا التنسيق تجريبي وداخلياته قابلة للتغيير.

أمثلة

•استرداد تنسيق المرجع للمستودع الحالي: 
git repo info references.format
•استرداد ما إذا كان المستودع الحالي فارغًا وما إذا كان ضحلًا باستخدام تنسيق nul: 
git repo info --format=nul layout.bare layout.shallow
