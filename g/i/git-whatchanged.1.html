git-whatchanged(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-WHATCHANGED(1) دليل Git GIT-WHATCHANGED(1)

الاسم

git-whatchanged - عرض السجلات مع الاختلافات التي تقدمها كل تلتزمة

الخلاصة

git whatchanged <option>...

تحذير

git whatchanged تم إهماله وهو مجدول للإزالة في إصدار مستقبلي من Git، حيث أنه مجرد git log مع افتراضات مختلفة.

الوصف

يعرض سجلات الالتزام ومخرجات الفرق التي تقدمها كل التزام.

يتم تشجيع المستخدمين الجدد على استخدام git-log(1) بدلاً من ذلك. الأمر whatchanged هو في الأساس نفس الأمر git-log(1) ولكنه يعرض افتراضيًا تنسيق الفرق الخام ويخطيء عمليات الدمج:

git log --raw --no-merges

تم الاحتفاظ بالأمر بشكل أساسي لأسباب تاريخية؛ أصابع العديد من الأشخاص الذين تعلموا Git قبل وقت طويل من اختراع git log من خلال قراءة قائمة بريد نواة Linux مدربة على كتابته.

أمثلة

git whatchanged -p v2.6.12.. include/scsi drivers/scsi

يعرض كتصحيحات الالتزامات منذ الإصدار v2.6.12 التي غيرت أي ملف في الدلائل الفرعية include/scsi أو drivers/scsi

git whatchanged --since="2 weeks ago" -- gitk

يعرض التغييرات خلال الأسبوعين الماضيين على الملف gitk. "--" ضروري لتجنب الالتباس مع الفرع المسمى gitk
