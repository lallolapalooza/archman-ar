git-patch-id(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-PATCH-ID(1) Git Manual GIT-PATCH-ID(1)

الاسم

git-patch-id - حساب معرف فريد لرقعة

ملخص

git patch-id [--stable | --unstable | --verbatim]

الوصف

اقرأ رقعة من الإدخال القياسي واحسب معرف الرقعة لها.

لا يعد "معرف الرقعة" سوى مجموع SHA-1 لتغييرات الملفات المرتبطة بالرقعة، مع تجاهل أرقام الأسطر. على هذا النحو، فإنه "مستقر بشكل معقول"، ولكنه في نفس الوقت فريد بشكل معقول، أي أن رقعتين لهما نفس "معرف الرقعة" مضمونان تقريبًا بنفس الشيء.

الاستخدام الرئيسي لهذا الأمر هو البحث عن التزامات مكررة محتملة.

عند التعامل مع إخراج git diff-tree، فإنه يستفيد من حقيقة أن الرقعة مسبوقة باسم الكائن للالتزام، ويخرج سلسلتين سداسي عشريتين بطول 40 بايت. السلسلة الأولى هي معرف الرقعة، والسلسلة الثانية هي معرف الالتزام. يمكن استخدام هذا لإنشاء ربط من معرف الرقعة إلى معرف الالتزام.

الخيارات

--verbatim

حساب معرف الرقعة للمدخلات كما تم تقديمه، لا تقم بتجريد أي مسافات بيضاء.

هذا هو الافتراضي إذا كان patchid.verbatim هو true.

--stable

استخدام مجموع "مستقر" من الهاشات كمعرف للرقعة. مع هذا الخيار:
•إعادة ترتيب تغييرات الملفات التي تشكل الرقعة لا يؤثر على المعرف. على وجه الخصوص، تنتج رقعتان تنتجان عن مقارنة نفس الشجرتين بإعدادين مختلفين لـ -O<orderfile> نفس توقيع معرف الرقعة، مما يسمح باستخدام النتيجة المحسوبة كمفتاح لفهرسة بعض المعلومات الوصفية حول التغيير بين الشجرتين؛
•النتيجة مختلفة عن القيمة التي ينتجها git 1.9 والإصدارات الأقدم أو التي تنتج عند تكوين هاش "غير مستقر" (انظر --unstable أدناه) - حتى عند استخدامها على إخراج التغيير المأخوذ بدون أي استخدام لـ -O<orderfile>، مما يجعل قواعد البيانات الموجودة التي تخزن مثل هذه المعرفات "غير المستقرة" أو التاريخية غير قابلة للاستخدام.
•يتم تجاهل جميع المسافات البيضاء داخل الرقعة ولا تؤثر على المعرف.

هذا هو الافتراضي إذا تم تعيين patchid.stable إلى true.

--unstable

استخدام هاش "غير مستقر" كمعرف للرقعة. مع هذا الخيار، النتيجة المنتجة متوافقة مع قيمة معرف الرقعة التي ينتجها git 1.9 والإصدارات الأقدم ويتم تجاهل المسافات البيضاء. قد يرغب المستخدمون الذين لديهم قواعد بيانات موجودة تخزن معرفات الرقعة التي أنتجها git 1.9 والإصدارات الأقدم (الذين لا يتعاملون مع رقع معاد ترتيبها) في استخدام هذا الخيار.

هذا هو الافتراضي.
