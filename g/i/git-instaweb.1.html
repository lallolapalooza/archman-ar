git-instaweb(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-INSTAWEB(1) دليل Git GIT-INSTAWEB(1)

الاسم

git-instaweb (1) — تصفح مستودعك العامل في gitweb على الفور

الملخص

git instaweb [--local] [--httpd=<httpd>] [--port=<port>]
               [--browser=<browser>]
git instaweb [--start] [--stop] [--restart]

الوصف

برنامج نصي بسيط لإعداد gitweb وخادم ويب لتصفح المستودع المحلي.

الخيارات

-l, --local

ربط خادم الويب فقط بعنوان IP المحلي (127.0.0.1).

-d, --httpd

سطر أوامر خادم HTTP الذي سيتم تنفيذه. يمكن تحديد خيارات سطر الأوامر هنا، وسيتم إضافة ملف التكوين في نهاية سطر الأوامر. حاليًا، يتم دعم apache2، lighttpd، mongoose، plackup، python، و webrick. (الافتراضي: lighttpd)

-m, --module-path

مسار الوحدة (مطلوب فقط إذا كان httpd هو Apache). (الافتراضي: /usr/lib/apache2/modules)

-p, --port

رقم المنفذ لربط خادم httpd به. (الافتراضي: 1234)

-b, --browser

متصفح الويب الذي يجب استخدامه لعرض صفحة gitweb. سيتم تمريره إلى البرنامج النصي المساعد git web--browse مع عنوان URL الخاص بتثبيت gitweb. راجع git-web--browse(1) لمزيد من المعلومات حول هذا. إذا فشل البرنامج النصي، فسيتم طباعة عنوان URL إلى المخرج القياسي.

start, --start

بدء تشغيل مثيل httpd والخروج. إعادة إنشاء ملفات التكوين حسب الضرورة لتشغيل مثيل جديد.

stop, --stop

إيقاف تشغيل مثيل httpd والخروج. هذا لا ينشئ أي ملفات تكوين لتشغيل مثيل جديد، ولا يغلق المتصفح.

restart, --restart

إعادة تشغيل مثيل httpd والخروج. إعادة إنشاء ملفات التكوين حسب الضرورة لتشغيل مثيل جديد.

التكوين

يمكنك تحديد التكوين في ملف .git/config الخاص بك

[instaweb]
        local = true
        httpd = apache2 -f
        port = 4321
        browser = konqueror
        modulePath = /usr/lib/apache2/modules

إذا لم يتم تعيين متغير التكوين instaweb.browser، فسيتم استخدام web.browser بدلاً منه إذا تم تعريفه. راجع git-web--browse(1) لمزيد من المعلومات حول هذا.
