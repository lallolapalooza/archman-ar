git-annex-watch(1) دليل الأوامر العامة git-annex-watch(1)

الاسم

git-annex-watch - خادم لمراقبة التغييرات

الملخص

git annex watch

الوصف

يراقب التغييرات في الملفات في الدليل الحالي وأدلته الفرعية، ويتولى إضافة الملفات الجديدة تلقائيًا، وكذلك التعامل مع الملفات المحذوفة والمُنسوخة والمُنتقلة. مع تشغيل هذا كخادم في الخلفية، لن تحتاج بعد الآن إلى تشغيل أوامر git يدويًا عند التعامل مع ملفاتك.

بشكل افتراضي، ستتم إضافة جميع الملفات الجديدة في الدليل إلى المستودع. (بما في ذلك الملفات المخفية.) لمنع إضافة بعض الملفات، استخدم ملفات .gitignore.

بشكل افتراضي، تتم إضافة جميع الملفات التي تتم إضافتها إلى الـ annex، بنفس طريقة تشغيل git annex add. إذا قمت بضبط annex.largefiles، فسيتم إضافة الملفات التي لا تطابقها باستخدام git add.

خيارات

--foreground
تجنب الانقسام إلى الخلفية.
--stop
إيقاف خادم يعمل في المستودع الحالي.
يمكن أيضًا استخدام git-annex-common-options(1).
