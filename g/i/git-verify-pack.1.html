git-verify-pack(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-VERIFY-PACK(1) دليل Git GIT-VERIFY-PACK(1)

الاسم

git-verify-pack - التحقق من صحة ملفات أرشيف Git المعبأة

الملخص

git verify-pack [-v | --verbose] [-s | --stat-only] [--] <pack>.idx...

الوصف

اقرأ كل ملف idx لملفات أرشيف Git المعبأة المعطاة في سطر الأوامر، وتحقق من صحة ملف idx وملف الحزمة المقابل.

خيارات

-v, --verbose

بعد التحقق من صحة الحزمة، اعرض قائمة الكائنات الموجودة في الحزمة ورسم بياني لطول سلسلة التفاوت (delta chain).

-s, --stat-only

لا تحقق من محتويات الحزمة؛ فقط اعرض الرسم البياني لطول سلسلة التفاوت. مع --verbose، يتم أيضًا عرض قائمة الكائنات.

--

لا تفسر أي وسائط إضافية كخيارات.

تنسيق الإخراج

عند تحديد الخيار -v، يكون التنسيق المستخدم هو:

اسم-الكائن نوع حجم حجم-في-الحزمة إزاحة-في-الحزمة

للكائنات التي لم يتم تفريقها (deltified) في الحزمة، و

اسم-الكائن نوع حجم حجم-في-الحزمة إزاحة-في-الحزمة عمق اسم-الكائن-الأساسي

للكائنات التي تم تفريقها.
