git-verify-tag(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-VERIFY-TAG(1) دليل Git GIT-VERIFY-TAG(1)

الاسم

git-verify-tag - التحقق من توقيع GPG للعلامات

ملخص

git verify-tag [-v | --verbose] [--format=<format>] [--raw] <tag>...

الوصف

التحقق من صحة توقيع gpg الذي تم إنشاؤه بواسطة git tag في كائنات العلامات المدرجة في سطر الأوامر.

الخيارات

--raw

اطبع مخرجات حالة gpg الخام إلى الخطأ القياسي بدلاً من المخرجات العادية القابلة للقراءة البشرية.

-v, --verbose

اطبع محتويات كائن العلامة قبل التحقق منها.
