الاسم

git-bug-commands - عرض الأوامر المتاحة.

الملخص

git-bug commands [flags]

الوصف

عرض الأوامر المتاحة.

الخيارات

-p, --pretty[=false] إخراج وصف الأمر بالإضافة إلى تعليق متوافق مع Markdown

-h, --help[=false] تعليمات للأوامر
