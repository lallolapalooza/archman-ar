الحزمة: git-bug

التراخيص: GPL-3.0-only

GIT-BUG(1) GIT-BUG(1)

الاسم

git-bug-user-user - عرض هوية مستخدم

ملخص

git-bug user user show [USER_ID] [flags]

الوصف

عرض هوية مستخدم

خيارات

-f, --field="" تحديد الحقل المراد عرضه. القيم الصالحة هي [email,humanId,id,lastModification,lastModificationLamports,login,metadata,name]

-h, --help[=false] مساعدة للمستخدم
