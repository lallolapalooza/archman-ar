git-annex-diffdriver(1)

الحزمة: git-annex

التراخيص: AGPL-3.0-only

git-annex-diffdriver(1) دليل الأوامر العامة git-annex-diffdriver(1)

الاسم

git-annex-diffdriver - مشغل diff الخاص بـ git

الملخص

git annex diffdriver [--get,--text] [-- --diffopts --]

git annex diffdriver -- cmd --cmdopts --

الوصف

عادةً، يعرض الأمر git diff عند تشغيله على الملفات الملحقة التغييرات المكتنزة في git، على سبيل المثال روابط الرموز الخاصة بـ annex والملفات المؤشر. يسمح هذا الأمر لـ git diff بالقيام بـ diff لمحتويات الملفات الملحقة بدلاً من ذلك.

يمكن استخدام هذا الأمر إما كمقارن نصوص بسيط، أو كغلاف لتشغيل مشغل diff خارجي لـ git.

إذا كانت بعض ملفاتك الملحقة نصية بطبيعتها، ويمكن مقارنتها بشكل مفيد باستخدام diff(1)، يمكنك تهيئة git لاستخدام هذا الأمر لمقارنتها، عن طريق تهيئة .gitattributes ليحتوي على سبيل المثال *.txt diff=annextextdiff وتهيئة git config diff.annextextdiff.command "git annex diffdriver --text".

إذا لم تكن ملفاتك الملحقة نصية بطبيعتها، فستحتاج إلى برنامج مشغل diff خارجي قادر على مقارنة تنسيق (تنسيقات) الملفات التي تستخدمها. راجع وثائق git الخاصة بـ GIT_EXTERNAL_DIFF ووثائق gitattributes(5) الخاصة بمشغلات diff الخارجية.

عادةً، عند استخدام git diff مع مشغل diff خارجي، فلن يرى محتويات الملفات الملحقة، لأن git يمرر لها روابط الرموز الخاصة بـ git-annex أو الملفات المؤشر. يعمل هذا الأمر على معالجة المشكلة، عن طريق تشغيل مشغل diff الخارجي الفعلي، وتمرير مسارات المحتوى الملحق إليه. قم بتهيئة git لاستخدام "git-annex diffdriver -- cmd params --" كمشغل diff خارجي، حيث cmd هو مشغل diff الخارجي الذي تريد تشغيله، و params هي أي معلمات إضافية لتمريرها إليه. لاحظ "--" اللاحقة، وهي مطلوبة.

على سبيل المثال، لاستخدام برنامج j-c-diff كمشغل diff خارجي، قم بتعيين GIT_EXTERNAL_DIFF="git-annex diffdriver -- j-c-diff --"

الخيارات

للحصول على محتويات الملفات الملحقة من المستودعات البعيدة عندما لا تكون موجودة بالفعل، استخدم الخيار --get. ستبقى محتويات الملف في المستودع للاستخدام لاحقًا حتى يتم إسقاطها بالطرق المعتادة.

لمقارنة الملفات النصية باستخدام diff(1)، استخدم الخيار --text. لتمرير خيارات إضافية إلى diff(1)، استخدم على سبيل المثال "--text -- --color --"

لاستخدام مشغل diff خارجي، يجب أن تبدأ الخيارات بـ "--" يليه أمر مشغل diff، وخياراته، و "--" آخر

يمكن أيضًا استخدام خيارات git-annex-common-options(1) العامة.
