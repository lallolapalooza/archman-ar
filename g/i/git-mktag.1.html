git-mktag(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-MKTAG(1) دليل Git GIT-MKTAG(1)

الاسم

git-mktag - ينشئ كائن علامة مع تحقق إضافي

الملخص

git mktag

الوصف

يقرأ محتويات علامة من الإدخال القياسي وينشئ كائن علامة. الإخراج هو معرف <object> للعلامة الجديدة.

هذا الأمر يعادل إلى حد كبير git-hash-object(1) الذي تم استدعاؤه مع -t tag -w --stdin. أي أن كلاهما سينشئ ويكتب علامة موجودة في my-tag:

git mktag <my-tag
git hash-object -t tag -w --stdin <my-tag

الاختلاف هو أن mktag سيموت قبل كتابة العلامة إذا لم تجتاز العلامة فحص git-fsck(1).

فحص "fsck" الذي يقوم به mktag أكثر صرامة مما سيقوم به git-fsck(1) افتراضيًا، حيث تتم ترقية جميع رسائل fsck.<msg-id> من تحذيرات إلى أخطاء (لذا فإن سطر "tagger" المفقود، على سبيل المثال، هو خطأ).

تعتبر الرؤوس الإضافية في الكائن أيضًا خطأ تحت mktag، ولكن يتم تجاهلها بواسطة git-fsck(1). يمكن تعطيل هذا الفحص الإضافي عن طريق تعيين متغير fsck.<msg-id> المناسب:

git -c fsck.extraHeaderEntry=ignore mktag <my-tag-with-headers

خيارات

--strict

افتراضيًا، يقوم mktag بتشغيل وضع git-fsck(1) --strict المكافئ. استخدم --no-strict لتعطيله.

تنسيق العلامة

ملف توقيع العلامة، الذي سيتم تغذيته إلى الإدخال القياسي لهذا الأمر، له تنسيق ثابت بسيط للغاية: أربعة أسطر من

object <hash>
type <typename>
tag <tagname>
tagger <tagger>

تليها بعض الرسائل الاختيارية ذات التنسيق الحر (بعض العلامات التي أنشأتها Git الأقدم قد لا تحتوي على سطر tagger). الرسالة، عندما تكون موجودة، يتم فصلها بسطر فارغ عن الرأس. قد تحتوي الرسالة على توقيع لا تهتم به Git نفسها، ولكن يمكن التحقق منه باستخدام gpg.
