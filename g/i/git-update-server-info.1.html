git-update-server-info(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-UPDATE-SERVER-INFO(1) دليل Git GIT-UPDATE-SERVER-INFO(1)

الاسم

git-update-server-info - تحديث ملف معلومات مساعد لمساعدة الخوادم البسيطة

الملخص

git update-server-info [-f | --force]

الوصف

يحتاج الخادم البسيط الذي لا يقوم بتوليد حزم في الوقت الفعلي إلى بعض ملفات المعلومات المساعدة في دليل $GIT_DIR/info و $GIT_OBJECT_DIRECTORY/info لمساعدة العملاء في اكتشاف المراجع والحزم التي يمتلكها الخادم. يقوم هذا الأمر بإنشاء هذه الملفات المساعدة.

الخيارات

-f, --force

تحديث ملفات المعلومات من الصفر.

الناتج

يقوم الأمر حاليًا بتحديث الملفات التالية. يرجى الاطلاع على gitrepository-layout(5) لوصف الغرض منها:

•objects/info/packs
•info/refs
