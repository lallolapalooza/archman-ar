git-diff-files(1)

الحزمة: git

التراخيص: GPL-2.0-only

/p>
اجعل البرنامج يخرج بأكواد مشابهة لـ diff(1). أي، يخرج بالرقم 1 في حالة وجود اختلافات، و 0 يعني عدم وجود اختلافات.

--quiet

تعطيل جميع مخرجات البرنامج. يتضمن --exit-code. يعطل تنفيذ أدوات diff الخارجية التي لا يُوثق على كود الخروج الخاص بها، أي أن خيار التكوين الخاص بها diff.trustExitCode أو diff.<driver>.trustExitCode أو متغير البيئة GIT_EXTERNAL_DIFF_TRUST_EXIT_CODE هو false.

--ext-diff

السماح بتنفيذ أداة diff خارجية. إذا قمت بتعيين برنامج diff خارجي باستخدام gitattributes(5)، فأنت بحاجة إلى استخدام هذا الخيار مع git-log(1) والأوامر المشابهة.

--no-ext-diff

رفض برامج diff الخارجية.

--textconv, --no-textconv

السماح (أو رفض) تشغيل مرشحات التحويل النصي الخارجية عند مقارنة الملفات الثنائية. انظر gitattributes(5) للتفاصيل. نظرًا لأن مرشحات textconv هي تحويلات أحادية الاتجاه عادةً، فإن diff الناتج مناسب للاستهلاك البشري، ولكن لا يمكن تطبيقه. لهذا السبب، يتم تمكين مرشحات textconv افتراضيًا فقط لـ git-diff(1) و git-log(1)، ولكن ليس لـ git-format-patch(1) أو أوامر diff الأساسية.

--ignore-submodules[=(none|untracked|dirty|all)]

تجاهل التغييرات في الوحدات الفرعية عند إنشاء diff. all هو الافتراضي. سيؤدي استخدام none إلى اعتبار الوحدة الفرعية معدلة إذا كانت تحتوي على ملفات غير متتبعة أو معدلة أو إذا كان HEAD الخاص بها يختلف عن الالتزام المسجل في المشروع الرئيسي ويمكن استخدامه لتجاوز أي إعدادات للخيار ignore في git-config(1) أو gitmodules(5). عند استخدام untracked، لا تعتبر الوحدات الفرعية متسخة عندما تحتوي فقط على محتوى غير متتبع (ولكن يتم مسحها بحثًا عن محتوى معدل). استخدام dirty يتجاهل جميع التغييرات في شجرة العمل للوحدات الفرعية، ويتم عرض التغييرات فقط في الالتزامات المخزنة في المشروع الرئيسي (كان هذا هو السلوك حتى 1.7.0). استخدام all يخفي جميع التغييرات في الوحدات الفرعية.

--src-prefix=<prefix>

عرض الـ <prefix> المصدر المحدد بدلاً من "a/".

--dst-prefix=<prefix>

عرض الـ <prefix> الوجهة المحدد بدلاً من "b/".

--no-prefix

عدم عرض أي بادئة مصدر أو وجهة.

--default-prefix

استخدام بادئات المصدر والوجهة الافتراضية ("a/" و "b/"). هذا يتجاوز متغيرات التكوين مثل diff.noprefix، diff.srcPrefix، diff.dstPrefix، و diff.mnemonicPrefix (انظر git-config(1)).

--line-prefix=<prefix>

إضافة <prefix> إضافي إلى كل سطر من المخرجات.

--ita-invisible-in-index

بشكل افتراضي، تظهر الإدخالات التي أضافها git add -N كملف فارغ موجود في git diff وملف جديد في git diff --cached. يجعل هذا الخيار الإدخال يظهر كملف جديد في git diff وغير موجود في git diff --cached. يمكن التراجع عن هذا الخيار باستخدام --ita-visible-in-index. كلا الخيارين تجريبيين ويمكن إزالتهما في المستقبل.

--max-depth=<depth>

لكل مواصفات مسار معطاة في سطر الأوامر، انزل إلى عمق لا يزيد عن <depth> مستويات من الأدلة. قيمة -1 تعني لا يوجد حد. لا يمكن دمجها مع رموز الاستبدال في مواصفات المسار. بالنظر إلى شجرة تحتوي على foo/bar/baz، تعرض القائمة التالية المطابقات التي تم إنشاؤها بواسطة كل مجموعة من الخيارات:
•--max-depth=0 -- foo: foo
•--max-depth=1 -- foo: foo/bar
•--max-depth=1 -- foo/bar: foo/bar/baz
•--max-depth=1 -- foo foo/bar: foo/bar/baz
•--max-depth=2 -- foo: foo/bar/baz

إذا لم يتم توفير مواصفات مسار، يتم قياس العمق كما لو تم تحديد جميع الإدخالات على المستوى الأعلى. لاحظ أن هذا يختلف عن القياس من الجذر، حيث أن --max-depth=0 سيظل يعيد foo. هذا يسمح لك بتقييد العمق مع طلب مجموعة فرعية من إدخالات المستوى الأعلى.

لاحظ أن هذا الخيار مدعوم فقط لـ diffs بين كائنات الشجرة، وليس ضد الفهرس أو شجرة العمل.

لمزيد من الشرح التفصيلي لهذه الخيارات الشائعة، انظر أيضًا gitdiffcore(7).

-1 --base, -2 --ours, -3 --theirs, -0

diff مقابل إصدار "الأساس"، أو فرع "لدينا"، أو فرع "الآخر". باستخدام هذه الخيارات، لا يتم عرض diffs للإدخالات المدمجة.

الافتراضي هو diff مقابل فرعنا (-2) والمسارات التي تم حلها بشكل نظيف. يمكن إعطاء الخيار -0 لتجاهل مخرجات diff للإدخالات غير المدمجة وعرض "Unmerged" فقط.

-c, --cc

يقارن هذا المرحلة 2 (فرعنا)، المرحلة 3 (فرع الآخر)، وملف شجرة العمل وينتج diff مدمج، مشابه للطريقة التي يعرض بها diff-tree التزام دمج بهذه العلامات.

-q

ابق صامتًا حتى للملفات غير الموجودة

صيغة المخرجات الخام

صيغة المخرجات الخام من git-diff-index، git-diff-tree، git-diff-files و git diff --raw متشابهة جدًا.

تقارن هذه الأوامر مجموعتين من الأشياء؛ ما يتم مقارنته يختلف:

git-diff-index <tree-ish>

يقارن <tree-ish> والملفات الموجودة على نظام الملفات.

git-diff-index --cached <tree-ish>

يقارن <tree-ish> والفهرس.

git-diff-tree [-r] <tree-ish-1> <tree-ish-2> [<pattern>...]

يقارن الأشجار المسماة بالحجتين.

git-diff-files [<pattern>...]

يقارن الفهرس والملفات الموجودة على نظام الملفات.

تبدأ الأداة git-diff-tree مخرجاتها بطباعة تجزئة (hash) ما يتم مقارنته. بعد ذلك، تطبع جميع الأوامر سطر مخرجات لكل ملف متغير.

يتم تنسيق سطر المخرجات بهذه الطريقة:

:100644 100644 bcd1234 0123456 M file0
copy-edit      :100644 100644 abcd123 1234567 C68 file1 file2
rename-edit    :100644 100644 abcd123 1234567 R86 file1 file3
create         :000000 100644 0000000 1234567 A file4
delete         :100644 000000 1234567 0000000 D file5
unmerged       :000000 000000 0000000 0000000 U file6

أي، من اليسار إلى اليمين:

1.نقطتين رأسيتين.
2.الوضع لـ "المصدر"؛ 000000 إذا كان إنشاء أو غير مدمج.
3.مسافة.
4.الوضع لـ "الوجهة"؛ 000000 إذا كان حذف أو غير مدمج.
5.مسافة.
6.sha1 لـ "المصدر"؛ 0{40} إذا كان إنشاء أو غير مدمج.
7.مسافة.
8.sha1 لـ "الوجهة"؛ 0{40} إذا كان حذف، أو غير مدمج أو "شجرة العمل خارج المزامنة مع الفهرس".
9.مسافة.
10.الحالة، متبوعة برقم "درجة" اختياري.
11.علامة جدولة (tab) أو NUL عند استخدام الخيار -z.
12.المسار لـ "المصدر"
13.علامة جدولة (tab) أو NUL عند استخدام الخيار -z؛ موجود فقط لـ C أو R.
14.المسار لـ "الوجهة"؛ موجود فقط لـ C أو R.
15.حرف سطر جديد (LF) أو NUL عند استخدام الخيار -z، لإنهاء السجل.

حروف الحالة المحتملة هي:

•A: إضافة ملف
•C: نسخة من ملف إلى ملف جديد
•D: حذف ملف
•M: تعديل محتويات أو وضع ملف
•R: إعادة تسمية ملف
•T: تغيير في نوع الملف (ملف عادي، رابط رمزي، أو وحدة فرعية)
•U: الملف غير مدمج (يجب عليك إكمال الدمج قبل أن يمكن الالتزام به)
•X: نوع تغيير "غير معروف" (على الأرجح خطأ، يرجى الإبلاغ عنه)

حروف الحالة C و R تتبع دائمًا بدرجة (تمثل النسبة المئوية للتشابه بين مصدر ووجهة النقل أو النسخ). قد يتبع حرف الحالة M بدرجة (تمثل النسبة المئوية للاختلاف) لإعادة كتابة الملفات.

يتم عرض sha1 لـ "الوجهة" على أنه 0's إذا كان ملف على نظام الملفات خارج المزامنة مع الفهرس.

مثال:

:100644 100644 5be4a4a 0000000 M file.c

بدون الخيار -z، يتم اقتباس أسماء المسارات التي تحتوي على أحرف "غير عادية" كما هو موضح لمتغير التكوين core.quotePath (انظر git-config(1)). باستخدام -z يتم إخراج اسم الملف حرفيًا ويتم إنهاء السطر ببايت NUL.

صيغة diff لعمليات الدمج

git-diff-tree، git-diff-files و git-diff --raw يمكنها أخذ الخيار -c أو --cc لإنشاء مخرجات diff أيضًا لالتزامات الدمج. تختلف المخرجات عن الصيغة الموضحة أعلاه بالطريقة التالية:

1.يوجد نقطتان رأسيتان لكل والد.
2.هناك المزيد من الأوضاع "المصدر" و sha1 "المصدر".
3.الحالة هي أحرف حالة متسلسلة لكل والد.
4.لا توجد "درجة" اختيارية.
5.أسماء ملفات مفصولة بـ tab.

بالنسبة لـ -c و --cc، يتم عرض الوجهة فقط أو المسار النهائي حتى إذا تم إعادة تسمية الملف في أي جانب من جوانب السجل. مع --combined-all-paths، يتم عرض اسم المسار في كل والد
