git-mktree(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-MKTREE(1) دليل Git GIT-MKTREE(1)

الاسم

git-mktree - بناء كائن شجرة من نص بتنسيق ls-tree

الملخص

git mktree [-z] [--missing] [--batch]

الوصف

يقرأ الإدخال القياسي بتنسيق إخراج ls-tree غير المتكرر، وينشئ كائن شجرة. يتم تطبيع ترتيب إدخالات الشجرة بواسطة mktree لذلك لا يلزم فرز الإدخال مسبقًا. يتم كتابة اسم كائن الشجرة المبني إلى الإخراج القياسي.

الخيارات

-z

اقرأ إخراج ls-tree -z المنتهي بحرف NUL بدلاً من ذلك.

--missing

السماح بالكائنات المفقودة. السلوك الافتراضي (بدون هذا الخيار) هو التحقق من أن تجزئة كل إدخال شجرة تحدد كائنًا موجودًا. ليس لهذا الخيار أي تأثير على معاملة إدخالات gitlink (المعروفة أيضًا باسم "submodules") والتي يُسمح دائمًا بأن تكون مفقودة.

--batch

السماح ببناء أكثر من كائن شجرة واحد قبل الخروج. يتم فصل كل شجرة بسطر فارغ واحد. السطر الجديد الأخير اختياري. ملاحظة - إذا تم استخدام الخيار -z، يتم إنهاء الأسطر بحرف NUL.
