git-merge-index(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-MERGE-INDEX(1) دليل Git GIT-MERGE-INDEX(1)

الاسم

git-merge-index - تشغيل دمج للملفات التي تحتاج إلى دمج

الملخص

git merge-index [-o] [-q] <merge-program> (-a | ( [--] <file>...) )

الوصف

يبحث هذا الأمر في الفهرس عن الملف <file>(s)، وإذا كانت هناك إدخالات دمج، فإنه يمرر قيمة SHA-1 لتلك الملفات كوسائط 1، 2، 3 (وسيط فارغ إذا لم يكن هناك ملف)، و <file> كوسيط 4. تمرر أوضاع الملفات للملفات الثلاثة كوسائط 5، 6 و 7.

الخيارات

--

لا تفسر المزيد من الوسائط كخيارات.

-a

قم بتشغيل الدمج لجميع الملفات في الفهرس التي تحتاج إلى دمج.

-o

بدلاً من التوقف عند أول دمج فاشل، قم بجميع عمليات الدمج دفعة واحدة - استمر في الدمج حتى عندما تعيد عمليات الدمج السابقة أخطاء، ولا تُرجع رمز الخطأ إلا بعد اكتمال جميع عمليات الدمج.

-q

لا تشتكِ من فشل برنامج الدمج (عادةً ما يشير فشل برنامج الدمج إلى تعارضات أثناء الدمج). هذا للأدوات التي قد ترغب في إصدار رسائل مخصصة.

إذا تم استدعاء git merge-index مع عدة <file>(s) (أو -a) فإنه يعالجها بالتتابع ويتوقف فقط إذا أعاد الدمج رمز خروج غير صفري.

عادةً ما يتم تشغيل هذا الأمر مع نص برمجي يستدعي محاكاة Git لأمر merge من حزمة RCS.

يتم تضمين نص برمجي نموذجي يسمى git merge-one-file في التوزيع.

تنبيه تنبيه تنبيه! ترتيب كائنات الدمج في Git يختلف عن ترتيب كائنات الدمج في برنامج merge الخاص بـ RCS. في الترتيب أعلاه، النسخة الأصلية هي الأولى. لكن ترتيب الوسائط لبرنامج الدمج ثلاثي الاتجاهات merge هو وضع النسخة الأصلية في الوسط. لا تسألني لماذا.

أمثلة:

torvalds@ppc970:~/merge-test> git merge-index cat MM
This is MM from the original tree.              # original
This is modified MM in the branch A.            # merge1
This is modified MM in the branch B.            # merge2
This is modified MM in the branch B.            # current contents

أو

torvalds@ppc970:~/merge-test> git merge-index cat AA MM
cat: : No such file or directory
This is added AA in the branch A.
This is added AA in the branch B.
This is added AA in the branch B.
fatal: merge program failed

حيث يوضح المثال الأخير كيف سيتوقف git merge-index عن محاولة الدمج بمجرد أن يعيد أي شيء خطأ (أي، أعاد cat خطأ للملف AA، لأنه لم يكن موجودًا في النسخة الأصلية، وبالتالي لم يحاول git merge-index حتى دمج الشيء MM).
