GIT-MERGE-ONE-FILE(1) دليل Git GIT-MERGE-ONE-FILE(1)

الاسم

git-merge-one-file - البرنامج المساعد القياسي للاستخدام مع git-merge-index

ملخص

git merge-one-file

الوصف

هذا هو البرنامج المساعد القياسي للاستخدام مع git merge-index لحل الدمج بعد الدمج البسيط الذي تم باستخدام git read-tree -m.
