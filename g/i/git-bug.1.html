GIT-BUG(1) GIT-BUG(1)

الاسم

git-bug - متعقب أخطاء مدمج في Git

الملخص

git-bug [flags]

الوصف

git-bug هو متعقب أخطاء مدمج في Git.

يستخدم git-bug كائنات Git لتخزين تتبع الأخطاء بشكل منفصل عن سجل الملفات. نظرًا لأن الأخطاء هي كائنات Git عادية، يمكن دفعها وسحبها من/إلى نفس المستودع البعيد الذي تستخدمه بالفعل للتعاون مع الآخرين.

الخيارات

-h, --help[=false] مساعدة لـ git-bug
