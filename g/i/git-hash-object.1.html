git-hash-object(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-HASH-OBJECT(1) دليل Git GIT-HASH-OBJECT(1)

الاسم

git-hash-object - حساب قيمة معرف الكائن وإنشاء كائن من ملف اختياريًا

الملخص

git hash-object [-t <type>] [-w] [--path=<file> | --no-filters]
                [--stdin [--literally]] [--] <file>...
git hash-object [-t <type>] [-w] --stdin-paths [--no-filters]

الوصف

يحسب قيمة معرف الكائن لنوع كائن محدد مع محتويات الملف المسمى (الذي يمكن أن يكون خارج شجرة العمل)، ويكتب اختياريًا الكائن الناتج في قاعدة بيانات الكائنات. يبلغ عن معرف الكائن الخاص به إلى مخرجاته القياسية. عند عدم تحديد <type>، فإنه يكون افتراضيًا "blob".

الخيارات

-t <type>

حدد نوع الكائن المراد إنشاؤه (الافتراضي: "blob"). القيم الممكنة هي commit، tree، blob، و tag.

-w

اكتب الكائن فعليًا في قاعدة بيانات الكائنات.

--stdin

اقرأ الكائن من المدخل القياسي بدلاً من ملف.

--stdin-paths

اقرأ أسماء الملفات من المدخل القياسي، اسم ملف واحد في كل سطر، بدلاً من سطر الأوامر.

--path

قم بتجزئة الكائن كما لو كان موجودًا في المسار المحدد. لا يؤثر موقع الملف بشكل مباشر على قيمة التجزئة، ولكن المسار يستخدم لتحديد مرشحات Git التي يجب تطبيقها على الكائن قبل وضعه في قاعدة بيانات الكائنات. نتيجة لتطبيق المرشحات، قد يختلف البيانات الثنائية الفعلية التي تم وضعها في قاعدة بيانات الكائنات عن الملف المحدد. هذا الخيار مفيد بشكل أساسي لتجزئة الملفات المؤقتة الموجودة خارج دليل العمل أو الملفات المقروءة من المدخل القياسي.

--no-filters

قم بتجزئة المحتويات كما هي، متجاهلاً أي مرشح إدخال كان سيتم اختياره بواسطة آلية السمات، بما في ذلك تحويل نهاية السطر. إذا تمت قراءة الملف من المدخل القياسي، فهذا ضمني دائمًا، ما لم يتم تحديد الخيار --path.

--literally

اسمح لـ --stdin بتجزئة أي بيانات غير مفيدة إلى كائن غير ثابت قد لا يجتاز فحص الكائنات القياسي أو فحوصات git-fsck. مفيد للاختبار المكثف لـ Git نفسه أو لتكرار خصائص الكائنات التالفة أو الخاطئة التي تم العثور عليها.
