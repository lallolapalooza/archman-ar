git-annex-filter-process(1)

الحزمة: git-annex

التراخيص: AGPL-3.0-only

git-annex-filter-process(1) دليل الأوامر العام git-annex-filter-process(1)

الاسم

git-annex-filter-process - عملية فلترة طويلة الأمد لـ git-annex

الملخص

git annex filter-process

الوصف

عندما لا يكون هذا ممكّنًا، تتضمن كل ملف يتم فلترته بواسطة git بدء عملية git-annex smudge جديدة. قد يكون بدء العديد من هذه العمليات للعديد من الملفات بطيئًا، ويمكن أن يجعل الأوامر مثل git checkout و git add بطيئة عند تشغيلها على العديد من الملفات. (العديد من الملفات الملحقة المقفلة لا تجعل git checkout بطيئًا، ولكن الملفات غير المقفلة والملفات غير الملحقة تبطئها.)

من ناحية أخرى، عندما يكون هذا ممكّنًا، يقوم git add للملفات الكبيرة بقراءة إضافية غير ضرورية للملف، ويوجه محتوياته إلى git-annex. لذلك، عندما يكون هذا ممكّنًا، سيكون من الأسرع استخدام git-annex add لإضافة الملفات الكبيرة إلى الملحق، بدلاً من git add. تتأثر الأوامر الأخرى التي تضيف ملفات، مثل git commit -a، بهذا أيضًا.

يتم استخدام هذا افتراضيًا في مستودعات git-annex v9 والإصدارات الأحدث، بينما تستخدم مستودعات v8 git-annex smudge للتوافق مع الإصدارات الأقدم من git-annex.

لتمكين هذا في مستودع v8، قم بتشغيل:


git config filter.annex.process 'git-annex filter-process'

لتعطيله، يمكنك ببساطة إلغاء تعيين الإعداد:


git config --unset filter.annex.process

لن يكون هناك فرق مرئي في السلوك بين تمكين هذا وعدم تمكينه، بخلاف التغييرات في السرعة واستخدام الذاكرة عند استخدام git.

خيارات

يمكن استخدام خيارات git-annex-common (1).
