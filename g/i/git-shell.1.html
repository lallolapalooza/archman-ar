git-shell(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-SHELL(1) دليل Git GIT-SHELL(1)

الاسم

git-shell - Shell تسجيل مقيد للوصول فقط عبر SSH إلى Git

الملخص

chsh -s $(command -v git-shell) <user>
git clone <user>@localhost:/path/to/repo.git
ssh <user>@localhost

الوصف

هذا هو shell تسجيل لحسابات SSH لتوفير وصول محدود إلى Git. يسمح بتنفيذ أوامر Git فقط من جانب الخادم التي تنفذ وظائف السحب/الدفع، بالإضافة إلى الأوامر المخصصة الموجودة في دليل فرعي يسمى git-shell-commands في الدليل الرئيسي للمستخدم.

الأوامر

يقبل git shell الأوامر التالية مع الخيار -c:

git receive-pack <argument>, git upload-pack <argument>, git upload-archive <argument>

استدعاء أمر الخادم المقابل لدعم طلب العميل git push أو git fetch أو git archive --remote.

cvs server

محاكاة خادم CVS. انظر git-cvsserver(1).

إذا كان هناك دليل ~/git-shell-commands موجودًا، فسيتعامل git shell أيضًا مع الأوامر المخصصة الأخرى عن طريق تشغيل "git-shell-commands/<command> <arguments>" من الدليل الرئيسي للمستخدم.

الاستخدام التفاعلي

افتراضيًا، يمكن تنفيذ الأوامر المذكورة أعلاه فقط باستخدام الخيار -c؛ shell ليس تفاعليًا.

إذا كان هناك دليل ~/git-shell-commands موجودًا، يمكن أيضًا تشغيل git shell بشكل تفاعلي (بدون وسيطات). إذا كان هناك أمر help موجود في دليل git-shell-commands، فسيتم تشغيله لتزويد المستخدم بنظرة عامة على الإجراءات المسموح بها. ثم يتم عرض موجه "git> " حيث يمكن للمستخدم إدخال أي من الأوامر من دليل git-shell-commands، أو exit لإغلاق الاتصال.

بشكل عام، يستخدم هذا الوضع كواجهة إدارية للسماح للمستخدمين بإدراج المستودعات التي لديهم حق الوصول إليها، أو إنشاء، حذف، أو إعادة تسمية المستودعات، أو تغيير أوصاف المستودعات والأذونات.

إذا كان هناك أمر no-interactive-login موجودًا، فسيتم تشغيله وإلغاء shell التفاعلي.

أمثلة

لتعطيل تسجيلات الدخول التفاعلية، وعرض تحية بدلاً من ذلك:

$ chsh -s /usr/bin/git-shell
$ mkdir $HOME/git-shell-commands
$ cat >$HOME/git-shell-commands/no-interactive-login <<\EOF
#!/bin/sh
printf '%s\n' "Hi $USER! You've successfully authenticated, but I do not"
printf '%s\n' "provide interactive shell access."
exit 128
EOF
$ chmod +x $HOME/git-shell-commands/no-interactive-login

لتمكين الوصول إلى git-cvsserver (والذي يجب عمومًا أن يكون له مثال no-interactive-login أعلاه كشرط مسبق، حيث أن إنشاء دليل git-shell-commands يسمح بتسجيلات الدخول التفاعلية):

$ cat >$HOME/git-shell-commands/cvs <<\EOF
if ! test $# = 1 && test "$1" = "server"
then
        echo >&2 "git-cvsserver only handles \"server\""
        exit 1
fi
exec git cvsserver server
EOF
$ chmod +x $HOME/git-shell-commands/cvs
