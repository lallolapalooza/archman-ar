git-lfs-fsck(1)

الحزمة: git-lfs

التراخيص: MIT

GIT-LFS-FSCK(1)   GIT-LFS-FSCK(1)

الاسم

git-lfs-fsck - فحص ملفات Git LFS للتأكد من سلامتها

الملخص

git lfs fsck [خيارات] [مراجعات]

الوصف

يفحص جميع ملفات Git LFS في HEAD الحالي للتأكد من سلامتها.

يتم نقل الملفات التالفة إلى ".git/lfs/bad".

يمكن تحديد المراجعات إما كـ committish واحد، في هذه الحالة يتم فحص هذا الالتزام فقط؛ أو كـ نطاق بالشكل A..B (وهذا الشكل فقط)، في هذه الحالة يتم فحص هذا النطاق؛ أو يتم تجاهله تمامًا، في هذه الحالة يتم فحص HEAD (ولـ --objects، الفهرس).

الوضع الافتراضي هو إجراء جميع الفحوصات.

في تهيئة Git الخاصة بك أو في ملف .lfsconfig، يمكنك تعيين lfs.fetchexclude إلى قائمة مسارات مفصولة بفواصل. إذا تم تعريف lfs.fetchexclude، فلن يتم فحص أي ملفات Git LFS التي تتطابق مساراتها مع أحد هذه المسارات للتأكد من سلامتها. تتم مطابقة المسارات باستخدام المطابقة العامة وفقًا لـ gitignore(5).

الخيارات

--objects

تحقق من أن كل كائن في HEAD يتطابق مع تجزئته المتوقعة وأن كل كائن موجود على القرص.

--pointers

تحقق من أن كل مؤشر قياسي وأن كل ملف يجب تخزينه كملف Git LFS مخزن كذلك.

انظر أيضًا

git-lfs-ls-files(1)، git-lfs-status(1)، gitignore(5).

جزء من مجموعة أدوات git-lfs(1).
