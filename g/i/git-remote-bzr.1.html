git-remote-bzr(1)

الحزمة: breezy

التراخيص: GPL-2.0-or-later

GIT-REMOTE-BZR(1) دليل Git GIT-REMOTE-BZR(1)

الاسم

git-remote-bzr - دعم Git عن بعد لمستودعات Bazaar

الملخص

git clone bzr::<source-repo> [<destination>]
git fetch bzr::<source-repo> [<destination>]

الوصف

يقدم هذا الأمر الدعم لاستخدام مستودعات bzr كعنصر بعيد لـ Git، من خلال المكون الإضافي breezy-git. في الوقت الحالي، يدعم الاستنساخ من، وجلب من، ودفع إلى مستودعات Bazaar. دعم الجلب لا يزال تجريبيًا، وقد يكون بطيئًا.

الأخطاء

يرجى الإبلاغ عن الأخطاء على https://launchpad.net/brz/+filebug

الترخيص

breezy-git و git-remote-bzr مرخصان تحت رخصة GNU GPL، الإصدار 2 أو أحدث.

انظر أيضًا

git-remote-helpers(1)، breezy(1)
