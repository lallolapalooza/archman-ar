git-for-each-repo(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-FOR-EACH-REPO(1) دليل Git GIT-FOR-EACH-REPO(1)

الاسم

git-for-each-repo - تشغيل أمر Git على قائمة مستودعات

ملخص

git for-each-repo --config=<config> [--] <arguments>

الوصف

تشغيل أمر Git على قائمة مستودعات. تُستخدم الوسائط بعد الخيارات المعروفة أو مؤشر -- كوسائط لعملية Git الفرعية.

هذا الأمر تجريبي. قد يتغير سلوكه.

على سبيل المثال، يمكننا تشغيل الصيانة على كل مستودع من قائمة المستودعات المخزنة في متغير الإعداد maintenance.repo باستخدام

git for-each-repo --config=maintenance.repo maintenance run

سيقوم هذا بتشغيل git -C <repo> maintenance run لكل قيمة <repo> في متغير الإعداد متعدد القيم maintenance.repo.

خيارات

--config=<config>

استخدم متغير الإعداد المعطى كقائمة متعددة القيم تخزن أسماء مسارات مطلقة. كرر على قائمة المسارات هذه لتشغيل الوسائط المعطاة.

يتم تحميل قيم الإعداد هذه من إعدادات Git النظامية والعالمية والمحلية، حسب توفرها. إذا تم تشغيل git for-each-repo في دليل ليس مستودع Git، فسيتم استخدام إعدادات النظام والعالمية فقط.

--keep-going

استمر مع المستودعات المتبقية إذا فشل الأمر على مستودع. سيشير رمز الخروج على أي حال إلى أن العملية الإجمالية لم تكن ناجحة.

لاحظ أن رمز الخروج الدقيق للأمر الفاشل لا يتم تمريره كرمز خروج لأمر for-each-repo: إذا فشل الأمر في أي من المستودعات المحددة، فسيكون رمز الخروج الإجمالي هو 1.

سلوك العملية الفرعية

إذا أعادت أي عملية فرعية git -C <repo> <arguments> رمز خروج غير صفري، فإن عملية git for-each-repo تعيد رمز الخروج هذا دون تشغيل المزيد من العمليات الفرعية.

تستعير كل عملية فرعية git -C <repo> <arguments> واصفات الملفات القياسية stdin و stdout و stderr.
