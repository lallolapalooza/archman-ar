git-http-fetch(1)

الحزمة: git

التراخيص: GPL-2.0-only

GIT-HTTP-FETCH(1) دليل Git GIT-HTTP-FETCH(1)

الاسم

git-http-fetch - تنزيل من مستودع Git بعيد عبر HTTP

الملخص

git http-fetch [-c] [-t] [-a] [-d] [-v] [-w <filename>] [--recover] [--stdin | --packfile=<hash> | <commit>] <URL>

الوصف

يقوم بتنزيل مستودع Git بعيد عبر HTTP.

يقوم هذا الأمر دائمًا بالحصول على جميع الكائنات. تاريخيًا، كانت هناك ثلاثة خيارات -a و -c و -t لاختيار الكائنات التي سيتم تنزيلها. يتم تجاهل هذه الخيارات بصمت الآن.

الخيارات

commit-id

إما الهاش أو اسم الملف تحت [URL]/refs/ للسحب منه.

-a, -c, -t

يتم تجاهل هذه الخيارات لأسباب تاريخية.

-v

الإبلاغ عما يتم تنزيله.

-w <filename>

يكتب معرف الالتزام (commit-id) في الملف المحدد تحت $GIT_DIR/refs/<filename> على الطرف المحلي بعد اكتمال النقل.

--stdin

بدلاً من معرف الالتزام في سطر الأوامر (والذي لا يُتوقع في هذه الحالة)، يتوقع git http-fetch سطورًا على الإدخال القياسي بالتنسيق 
<commit-id>['\t'<filename-as-in--w>]

--packfile=<hash>

للاستخدام الداخلي فقط. بدلاً من معرف الالتزام في سطر الأوامر (والذي لا يُتوقع في هذه الحالة)، يقوم git http-fetch بجلب ملف الحزمة (packfile) مباشرة من عنوان URL المحدد ويستخدم index-pack لإنشاء ملفات .idx و .keep المقابلة. يستخدم الهاش لتحديد اسم الملف المؤقت وهو اعتباطي. تتم طباعة مخرجات index-pack إلى الإخراج القياسي. يتطلب --index-pack-args.

--index-pack-args=<args>

للاستخدام الداخلي فقط. الأمر الذي سيتم تشغيله على محتويات الحزمة التي تم تنزيلها. يتم ترميز الوسائط بـ URL مفصولة بمسافات.

--recover

التحقق من أن كل ما يمكن الوصول إليه من الهدف قد تم جلبه. يستخدم بعد مقاطعة عملية جلب سابقة.
