git-warp-time(1)

الحزمة: git-warp-time

التراخيص: GPL-3.0-only

git-warp-time(1) دليل الأوامر العامة git-warp-time(1)

الاسم

git-warp-time - أداة سطر أوامر تعيد تعيين الطوابع الزمنية للملفات في دليل العمل الخاص بمستودع Git إلى الطابع الزمني الدقيق لآخر تثبيت قام بتعديل كل ملف

الملخص

git-warp-time [-d|--dirty] [-i|--ignored] [-o|--ignore-older] [-q|--quiet] [-h|--help] [PATHS]

الوصف

أداة سطر أوامر تعيد تعيين الطوابع الزمنية للملفات في دليل العمل الخاص بمستودع Git إلى الطابع الزمني الدقيق لآخر تثبيت قام بتعديل كل ملف

الخيارات

-d, --dirty
تضمين الملفات التي يتعقبها Git ولكن مع تعديلات في الفرع العامل
-i, --ignored
تضمين الملفات التي يتعقبها Git ولكن أيضًا الملفات المتجاهلة
-o, --ignore-older
لمس الملفات الأحدث من تاريخها فقط، وتجاهل الملفات الأقدم
-q, --quiet
لا تطبع أي مخرجات حول الملفات التي تم لمسها أو تخطيها
-h, --help
طباعة المساعدة
[PATHS]
قائمة اختيارية من المسارات للعمل عليها بدلاً من الافتراضي وهو جميع الملفات التي يتعقبها Git
