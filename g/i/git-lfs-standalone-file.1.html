الاسم

git-lfs-standalone-file - محول نقل مستقل لروابط الملفات

الملخص

git lfs standalone-file

الوصف

يوفر محول نقل مستقل لروابط الملفات (المسارات المحلية).

بشكل افتراضي، يتطلب Git LFS دعم خادم HTTP لتنفيذ بروتوكول Git LFS. ومع ذلك، تتيح هذه الأداة استخدام عناوين URL التي تبدأ بـ <file:///> (أي، تلك التي تمثل المسارات المحلية) بالإضافة إلى ذلك. لا يلزم إعداد؛ يتعامل Git LFS مع هذا داخليًا.

عند استدعائها، تتحدث هذه الأداة بصيغة JSON على المدخلات والمخرجات كمحول نقل مستقل. لا يُقصد استخدامها من قبل المستخدمين النهائيين.

انظر أيضًا

جزء من مجموعة git-lfs(1).
