GIT-LFS-POST-COMMIT(1)   GIT-LFS-POST-COMMIT(1)

الاسم

git-lfs-post-commit - تنفيذ خطاف post-commit لـ Git LFS

الملخص

git lfs post-commit

الوصف

يستجيب لأحداث ما بعد الالتزام (post-commit) في Git. يتأكد من أن أي ملفات تم تمييزها كقابلة للقفل بواسطة git lfs track تكون للقراءة فقط في نسخة العمل، إذا لم تكن مقفلة حاليًا بواسطة المستخدم المحلي.

بينما يحتاج الأمر git lfs post-merge، والذي له غرض مماثل، إلى فحص جميع الملفات في نسخة العمل، يمكن لـ git lfs post-commit الاقتصار على فحص الملفات التي تغيرت فقط في HEAD. يتعامل بشكل أساسي مع الملفات القابلة للقفل المضافة حديثًا والتي لم يتم جعلها للقراءة فقط بعد.

انظر أيضًا

git-lfs-post-merge(1)، git-lfs-track(1)

جزء من مجموعة git-lfs(1).
