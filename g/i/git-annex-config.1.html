git-annex-config(1)

الحزمة: git-annex

التراخيص: AGPL-3.0-only

<article class="man-page"> <section class="Sh"> <h1 class="Sh" id="NAME"><a class="permalink" href="#NAME">NAME</a></h1> <p class="Pp">git-annex-config - get and set git-annex configuration options</p> </section> <section class="Sh"> <h1 class="Sh" id="SYNOPSIS"><a class="permalink" href="#SYNOPSIS">SYNOPSIS</a></h1> <p class="Pp"><code>git annex config [<a href="#options">OPTIONS</a>] [<key> <value>]</code></p> <p class="Pp"><code>git annex config --get <key></code></p> <p class="Pp"><code>git annex config --unset <key></code></p> </section> <section class="Sh"> <h1 class="Sh" id="DESCRIPTION"><a class="permalink" href="#DESCRIPTION">DESCRIPTION</a></h1> <p class="Pp">This subcommand is used to get and set git-annex configuration options. It works like git config, but for git-annex specific options.</p> <p class="Pp">The configuration options can be set in several places, including the git configuration, and per-repository configuration files. This command lets you interact with these settings.</p> </section> <section class="Sh"> <h1 class="Sh" id="SUPPORTED_SETTINGS"><a class="permalink" href="#SUPPORTED_SETTINGS">SUPPORTED SETTINGS</a></h1> <p class="Pp">See git-annex-OPTIONS(1) for a list of supported configuration settings.</p> </section> <section class="Sh"> <h1 class="Sh" id="OPTIONS"><a class="permalink" href="#OPTIONS">OPTIONS</a></h1> <dl class="Bl"> <dt id="file"><a class="permalink" href="#file"><code>--file file</code></a></dt> <dd>Specifies a configuration file to use, instead of the default ones.</dd> <dt id="get"><a class="permalink" href="#get"><code>--get key</code></a></dt> <dd>Get the value of a configuration option.</dd> <dt id="bool"><a class="permalink" href="#bool"><code>--bool key</code></a></dt> <dd>Get the boolean value of a configuration option.</dd> <dt id="bools"><a class="permalink" href="#bools"><code>--bools key</code></a></dt> <dd>Get all boolean values of a configuration option.</dd> <dt id="int"><a class="permalink" href="#int"><code>--int key</code></a></dt> <dd>Get the integer value of a configuration option.</dd> <dt id="ints"><a class="permalink" href="#ints"><code>--ints key</code></a></dt> <dd>Get all integer values of a configuration option.</dd> <dt id="string"><a class="permalink" href="#string"><code>--string key</code></a></dt> <dd>Get the string value of a configuration option.</dd> <dt id="strings"><a class="permalink" href="#strings"><code>--strings key</code></a></dt> <dd>Get all string values of a configuration option.</dd> <dt id="local"><a class="permalink" href="#local"><code>--local</code></a></dt> <dd>Set the configuration option only for the current repository.</dd> <dt id="global"><a class="permalink" href="#global"><code>--global</code></a></dt> <dd>Set the configuration option globally for the current user.</dd> <dt id="system"><a class="permalink" href="#system"><code>--system</code></a></dt> <dd>Set the configuration option system-wide.</dd> <dt id="unset"><a class="permalink" href="#unset"><code>--unset key</code></a></dt> <dd>Unset a configuration option.</dd> <dt id="add"><a class="permalink" href="#add"><code>--add key value</code></a></dt> <dd>Add a configuration option. This is used for options that can have multiple values.</dd> <dt id="show-origin"><a class="permalink" href="#show-origin"><code>--show-origin</code></a></dt> <dd>Show the origin of the configuration option. This can be useful for debugging. For example, <code>annex.backend</code> cannot be set in the git-annex branch, but it can be set in <b>.gitattributes</b> or <b>git config</b> and this option can explain which setting will be used for it.</dd> <dt id="for"><a class="permalink" href="#for"><code>--for-file file</code></a></dt> <dd>Can be used in combination with <code>--show-origin</code> to specify what filename to check for in <b>.gitattributes</b>.</dd> <dt id="Also"><a class="permalink" href="#Also">Also the git-annex-common-options(1) can be used.</a></dt> <dd></dd> </dl> </section> <section class="Sh"> <h1 class="Sh" id="EXAMPLE"><a class="permalink" href="#EXAMPLE">EXAMPLE</a></h1> <p class="Pp">Suppose you want to prevent git annex sync from committing changes to files, so a manual git commit workflow is used in all clones of the repository. Then run:</p> <p class="Pp"><br/> <code>git annex config --set annex.autocommit false</code></p> <p class="Pp">If you want to override that in a partiticular clone, just use git config in the clone:</p> <p class="Pp"><br/> <code>git config annex.autocommit true</code></p> <p class="Pp">And to get back to the default behavior:</p> <p class="Pp"><br/> <code>git annex config --unset annex.autocommit</code></p> </section> <section class="Sh"> <h1 class="Sh" id="SEE_ALSO"><a class="permalink" href="#SEE_ALSO">SEE ALSO</a></h1> <p class="Pp"><a class="Xr"
