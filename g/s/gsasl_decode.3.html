gsasl_decode(3)

الحزمة: gsasl

التراخيص: LGPL-2.1-or-later AND GPL-3.0-or-later AND GFDL-1.3-or-later

gsasl_decode(3) gsasl gsasl_decode(3)

الاسم

gsasl_decode - دالة API

الملخص

#include <gsasl.h>

int gsasl_decode(Gsasl_session * sctx, const char * input, size_t input_len, char ** output, size_t * output_len);

المعاملات

Gsasl_session * sctx
مقبض جلسة libgsasl.
const char * input
مصفوفة بايت المدخلات.
size_t input_len
حجم مصفوفة بايت المدخلات.
char ** output
مصفوفة بايت المخرجات مخصصة حديثًا.
size_t * output_len
مؤشر إلى متغير المخرجات بحجم مصفوفة بايت المخرجات.

الوصف

فك تشفير البيانات وفقًا لآلية SASL المتفق عليها. قد يعني هذا أن البيانات محمية من حيث السلامة أو الخصوصية.

يتم تخصيص المخزن المؤقت output بواسطة هذه الدالة، ويقع على عاتق المتصل إلغاء تخصيصه عن طريق استدعاء gsasl_free( output ).

القيمة المرجعة: تُرجع GSASL_OK إذا نجح الترميز، وإلا فإنها تُرجع رمز خطأ.
