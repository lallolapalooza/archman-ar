GSSAPI__Status(3pm)

الحزمة: perl-gssapi

التراخيص: GPL, PerlArtistic

GSSAPI::Status(3) وثائق Perl التي ساهم بها المستخدم GSSAPI::Status(3)

الاسم

GSSAPI::Status - طرق لمعالجة حالات GSSAPI

الملخص

use GSSAPI;

$status = GSSAPI::Status->new(GSS_S_COMPLETE, 0);
if (GSS_ERROR($status->major)) {
  die "موت رهيب";
}
if (! $status) {                      # طريقة أخرى لكتابة ما سبق
  die "موت رهيب";
}
$status = $some_GSSAPI->someop($args1, etc);
if ($status) {
  foreach ($status->generic_message, $status->specific_message) {
    print "خطأ GSSAPI: $_\n";
  }
  die "ساعدني";
}

الوصف

تُعاد كائنات "GSSAPI::Status" بواسطة معظم عمليات GSSAPI الأخرى. تتكون هذه الحالات من رمز GSSAPI عام، ولعمليات معظمها، رمز خاص بالآلية. يمكن الوصول إلى هذه الرموز الرقمية عبر طريقتي "major" و "minor". يمكن الحصول على الرسائل النصية القياسية التي تتوافق مع الحالة الحالية عبر طريقتي "generic_message" و "specific_message". يعيد كل منها قائمة نصوص يجب عرضها على الأرجح بالترتيب.

يتكون الجزء العام من رمز حالة GSSAPI::Status من ثلاثة حقول فرعية يمكن الوصول إليها باستخدام وظيفتي "GSS_CALLING_ERROR" و "GSS_ROUTINE_ERROR" و "GSS_SUPPLEMENTARY_INFO". يمكن مقارنة القيم المعادّة مع الثوابت التي تبدأ أسماؤها بـ "GSS_S_" إذا أراد الكود الخاص بك التعامل مع أخطاء معينة بنفسه. تعيد الدالة "GSS_ERROR" قيمة صحيحة إذا وفقط إذا لم يتضمن الرمز العام المعطى خطأ في الاستدعاء أو خطأ في الروتين.

عند تقييم كائن "GSSAPI::Status" في سياق منطقي، سيكون صحيحًا إذا وفقط إذا كان رمز الحالة الرئيسي هو "GSS_S_COMPLETE".

عند تقييم كائن "GSSAPI::Status" في سياق نصي، سيعيد الرسائل العامة والخاصة مجمعة مع أسطر جديدة. قد يؤدي هذا إلى عمل "die $status" بشكل مفيد أو لا.

أخطاء

الكائنات الأساسية منفذة حاليًا كهيكل C تم تمييزه يحتوي على رموز الحالة الرئيسية والثانوية. ربما يجب أن يكون بدلاً من ذلك مصفوفة مميزة أو تجزئة، مما يقلل من كمية الكود C المتضمن ويجعله أكثر مرونة.
