gsettings(1)

الحزمة: glib2

التراخيص: LGPL-2.1-or-later

gsettings() gsettings()

الاسم

gsettings - أداة تهيئة GSettings

الملخص

gsettings get SCHEMA*[:*PATH] KEY
gsettings monitor SCHEMA*[:*PATH] KEY
gsettings writable SCHEMA*[:*PATH] KEY
gsettings range SCHEMA*[:*PATH] KEY
gsettings describe SCHEMA*[:*PATH] KEY
gsettings set SCHEMA*[:*PATH] KEY VALUE
gsettings reset SCHEMA*[:*PATH] KEY
gsettings reset-recursively SCHEMA*[:*PATH]
gsettings list-schemas [--print-paths]
gsettings list-relocatable-schemas
gsettings list-keys SCHEMA*[:*PATH]
gsettings list-children SCHEMA*[:*PATH]
gsettings list-recursively [SCHEMA*[:*PATH]]
gsettings help [COMMAND]

الوصف

يوفر gsettings واجهة سطر أوامر بسيطة لـ GSettings. تتيح لك الحصول على، تعيين، أو مراقبة مفتاح فردي للتغييرات.

يلزم الوسيطان SCHEMA و KEY لمعظم الأوامر لتحديد معرف المخطط واسم المفتاح المطلوب التعامل معه. قد يحتوي معرف المخطط اختياريًا على لاحقة :PATH. تحديد المسار مطلوب فقط إذا كان المخطط لا يحتوي على مسار ثابت.

عند تعيين مفتاح، تحتاج أيضًا إلى تحديد VALUE. تنسيق القيمة هو تنسيق GVariant المتسلسل، لذا يجب أن تتضمن السلاسل النصية اقتباسات صريحة: 'foo'. يتم استخدام هذا التنسيق أيضًا عند طباعة القيم.

لاحظ أن gsettings يحتاج إلى اتصال ناقل D-Bus للجلسة لكتابة التغييرات إلى قاعدة بيانات dconf.

الأوامر

get

يحصل على قيمة KEY. تتم طباعة القيمة بتنسيق GVariant متسلسل.

monitor

يراقب KEY للتغييرات ويطبع القيم المتغيرة. إذا لم يتم تحديد KEY، تتم مراقبة جميع المفاتيح في المخطط. تستمر المراقبة حتى تنتهي العملية.

writable

يكتشف ما إذا كان KEY قابلاً للكتابة.

range

يستعلم عن نطاق القيم الصالحة لـ KEY.

describe

يستعلم عن وصف القيم الصالحة لـ KEY.

set

يعين قيمة KEY إلى VALUE. يتم تحديد القيمة بتنسيق GVariant متسلسل.

reset

يعيد تعيين KEY إلى قيمته الافتراضية.

reset-recursively

يعيد تعيين جميع المفاتيح ضمن SCHEMA المحدد.

list-schemas

يسرد المخططات المثبتة غير القابلة لإعادة التوطين. انظر list-relocatable-schemas إذا كنت مهتمًا بالمخططات القابلة لإعادة التوطين. إذا تم توفير --print-paths، تتم أيضًا طباعة المسار الذي يتم تعيين كل مخطط له.

list-relocatable-schemas

يسرد المخططات المثبتة القابلة لإعادة التوطين. انظر list-schemas إذا كنت مهتمًا بالمخططات غير القابلة لإعادة التوطين.

list-keys

يسرد المفاتيح في SCHEMA.

list-children

يسرد العناصر الفرعية لـ SCHEMA.

list-recursively

يسرد المفاتيح والقيم، بشكل متكرر. إذا لم يتم توفير SCHEMA، يسرد المفاتيح في جميع المخططات.

help

يطبع المساعدة ويخرج.
