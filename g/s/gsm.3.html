gsm(3)

الحزمة: gsm

التراخيص: custom

GSM(3) دليل وظائف المكتبة GSM(3)

الاسم

gsm_create, gsm_destroy, gsm_encode, gsm_decode — ضغط صوتي بفقدان GSM 06.10

الملخص

#include "gsm.h"

gsm gsm_create();

void gsm_encode(handle, src, dst)
gsm handle;
gsm_signal src[160];
gsm_frame dst;

int gsm_decode(handle, src, dst)
gsm handle;
gsm_frame src;
gsm_signal dst[160];

void gsm_destroy(handle)
gsm handle;

الوصف

Gsm هو تنفيذ للمعيار النهائي لمسودة GSM 06.10 لترميز الكلام بمعدل كامل.

تقوم gsm_create() بتهيئة تمريرة gsm وتعيد كائن 'gsm' يمكن استخدامه كمقبض في استدعاءات لاحقة لـ gsm_decode() أو gsm_encode() أو gsm_destroy().

تقوم gsm_encode() بترميز مصفوفة من 160 عينة 13 بت (معطاة كـ gsm_signal's، قيم عددية صحيحة موقعة لا تقل عن 16 بت) إلى gsm_frame بحجم 33 بايت. (gsm_frame هو نوع معرف كمصفوفة من 33 gsm_bytes في gsm.h.)

تقوم gsm_decode() بفك ترميز gsm_frame إلى مصفوفة من 160 عينة 13 بت (معطاة كـ gsm_signals)، والتي تبدو إلى حد ما مثل ما قدمته لـ gsm_encode() على الجانب الآخر من الشبكة.

تقوم gsm_destroy() بإنهاء تمريرة gsm وتحرير جميع المساحات المرتبطة بها.

صيغة العينة

يفترض التحجيم التالي للمدخلات إلى الخوارزمية:


   0  1                             11 12
   S..v..v..v..v..v..v..v..v..v..v..v..v..*..*..*
فقط أعلى 13 بت تستخدم كقيمة مدخلة موقعة.
ناتج gsm_decode() لديه أقل ثلاث بتات مضبوطة على الصفر.

قيمة الإرجاع

تعيد gsm_create() كائن مقبض غير شفاف من نوع gsm، أو 0 عند حدوث خطأ. تعيد gsm_decode() -1 إذا كان الإطار المقدم غير صالح، وإلا 0.

مثال

#include "gsm.h"
gsm handle;
gsm_frame buf;
gsm_signal sample[160];
int cc, soundfd;
play() {	/* قراءة البيانات المضغوطة من الإدخال القياسي، الكتابة إلى soundfd */
	if (!(handle = gsm_create())) error...
	while (cc = read(0, (char *)buf, sizeof buf)) {
		if (cc != sizeof buf) error...
		if (gsm_decode(handle, buf, sample) < 0) error... 
		if (write(soundfd, sample, sizeof sample) != sizeof sample)
			error...
	}
	gsm_destroy(handle);
}
record() {	/* قراءة من soundfd، كتابة البيانات المضغوطة إلى الإخراج القياسي */
	if (!(handle = gsm_create())) error...
	while (cc = read(soundfd, sample, sizeof sample)) {
		if (cc != sizeof sample) error...
		gsm_encode(handle, sample, buf);
		if (write(1, (char *)buf, sizeof buf) != sizeof sample) 
			error...
	}
	gsm_destroy(handle);
}
