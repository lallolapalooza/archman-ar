gsasl_property_set_raw(3)

الحزمة: gsasl

التراخيص: LGPL-2.1-or-later AND GPL-3.0-or-later AND GFDL-1.3-or-later

gsasl_property_set_raw(3) gsasl gsasl_property_set_raw(3)

الاسم

gsasl_property_set_raw - وظيفة API

الملخص

#include <gsasl.h>

int gsasl_property_set_raw(Gsasl_session * sctx, Gsasl_property prop, const char * data, size_t len);

المعاملات

Gsasl_session * sctx
مقبض الجلسة.
Gsasl_property prop
قيمة تعدادية من نوع Gsasl_property، تشير إلى نوع البيانات في data.
const char * data
السلسلة الحرفية المراد تخزينها.
size_t len
طول السلسلة الحرفية المراد تخزينها.

الوصف

يقوم بعمل نسخة من data بطول len وتخزين نسخة منه منتهية بصفر في مقبض الجلسة للخاصية prop المحددة.

يمكنك إلغاء تخصيص data فورًا بعد استدعاء هذه الوظيفة، دون التأثير على البيانات المخزنة في مقبض الجلسة.

باستثناء مؤشر الطول، هذه الوظيفة متطابقة مع gsasl_property_set.

قيمة الإرجاع: GSASL_OK في حالة النجاح، وإلا GSASL_MALLOC_ERROR.

0.2.0
