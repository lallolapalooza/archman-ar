gsasl_encode(3)

الحزمة: gsasl

التراخيص: LGPL-2.1-or-later AND GPL-3.0-or-later AND GFDL-1.3-or-later

gsasl_encode(3) gsasl gsasl_encode(3)

الاسم

gsasl_encode - دالة API

الملخص

#include <gsasl.h>

int gsasl_encode(Gsasl_session * sctx, const char * input, size_t input_len, char ** output, size_t * output_len);

الوسائط

Gsasl_session * sctx
مقبض جلسة libgsasl.
const char * input
مصفوفة بايتات المدخلات.
size_t input_len
حجم مصفوفة بايتات المدخلات.
char ** output
مصفوفة بايتات مخرجات مخصصة حديثًا.
size_t * output_len
مؤشر إلى متغير المخرجات بحجم مصفوفة بايتات المخرجات.

الوصف

ترميز البيانات وفقًا لآلية SASL المتفاوض عليها. قد يعني هذا حماية البيانات بالسلامة أو الخصوصية.

يتم تخصيص مخزن output المؤقت بواسطة هذه الدالة، وتقع على عاتق المتصل مسؤولية إلغاء تخصيصه عن طريق استدعاء gsasl_free( output ).

قيمة الإرجاع: ترجع GSASL_OK إذا نجح الترميز، وإلا رمز خطأ.
