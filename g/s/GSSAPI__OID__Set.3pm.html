GSSAPI__OID__Set(3pm)

الحزمة: perl-gssapi

التراخيص: GPL, PerlArtistic

GSSAPI::OID::Set(3) وثائق Perl المساهمة من المستخدم GSSAPI::OID::Set(3)

الاسم

GSSAPI::OID::Set - طرق للتعامل مع مجموعات GSSAPI OIDs، وبعض مجموعات OID الثابتة.

الملخص

use GSSAPI;
$oidset = GSSAPI::OID::Set->new;
$status = $oidset->insert($oid);
$status = $oidset->contains($oid, $isthere);
if ($status && $isthere) {
  # إلخ إلخ إلخ
}

الوصف

كائنات "GSSAPI::OID::Set" هي ببساطة مجموعات من GSSAPI:OIDs (بالطبع).

الأخطاء

لا توجد طريقة لسرد OIDs في مجموعة؛ يمكنك فقط التحقق مما إذا كان OID معين موجودًا. هذا في الواقع خطأ في واجهة برمجة تطبيقات C، لذا سيكون أي إصلاح محددًا للتنفيذ.
