اسم

gsasl_done - دالة API

الملخص

#include <gsasl.h>

void gsasl_done(Gsasl * ctx);

المعاملات

Gsasl * ctx
مقبض libgsasl.

الوصف

تقوم هذه الدالة بتدمير مقبض libgsasl. يجب عدم استخدام المقبض مع دوال libgsasl الأخرى بعد هذا الاستدعاء.
