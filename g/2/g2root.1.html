g2root(1)

الحزمة: root

التراخيص: LGPL-2.1-or-later, BSD-2-Clause, BSD-3-Clause-LBNL, NCSA

G2ROOT(1) دليل الأوامر العامة G2ROOT(1)

الاسم

g2root - تحويل ملفات هندسة GEANT إلى ملفات ROOT

الموجز

g2rootd [-f اسم_الخريطة] اسم_geant اسم_الماكرو

الوصف

يمكنك تحويل هندسة GEANT (انظر http://geant.cern.ch/ لمزيد من المعلومات حول GEANT) إلى هندسة ROOT باتباع الخطوات التالية

1
قم بتشغيل النسخة التفاعلية من GEANT وإنتاج ملف Zebra RZ detector.geom، بكتابة الأمر:
Geant > rz/file 21 detector.geom on
2
قم بتشغيل برنامج g2root لتحويل ملف Zebra RZ إلى ماكرو ROOT detector.C:
g2root detector.geom detector.C
3
قم بتشغيل جلسة ROOT التالية؛
root [1] .x detector.C
root [2] detector.Draw()
root [3] c1.x3d()   // (هذا يستدعي عارض Root ثلاثي الأبعاد)
root [4] TFile f("detector.root","NEW") //فتح ملف root جديد
root [5] detector.Write() //كتابة هيكل الهندسة
root [6] f.Write()

لاحظ أن هيكل TNode الموجود حاليًا في ROOT لم يتم تصميمه كبديل لحزمة هندسية حقيقية. كانت الفكرة بشكل أساسي هي رسم هندسات بسيطة في برامج عرض الأحداث. نحن حاليًا نقوم بدراسة عدة بدائل لحزمة هندسية حقيقية وفعالة تدعم:

-
قاعدة بيانات قرص تخزن إصدارات هندسية متعددة
-
محرر عارض تفاعلي
-
مع عروض ثلاثية الأبعاد
-
ولكن أيضًا عروض مقطوعة ثنائية الأبعاد
-
مع واجهات لـ MC الحالية أو المستقبلية مثل GEANT3 أو GEANT4

برنامج ثانٍ يسمى gh2root (انظر http://root.cern/root/gh2root.html) يقوم بإنشاء كود C++ تلقائيًا يتوافق مع هياكل GEANT3 Zebra JSET، JVERTX، JKINE، JHITS و JDIGI.
