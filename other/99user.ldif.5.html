99USER.LDIF(5) دليل تنسيقات الملفات 99USER.LDIF(5)

الاسم

/etc/dirsrv/schema/99user.ldif - ملف LDIF يحتوي على مخطط LDAP مخصص لخادم الدليل 389.

الملخص

/etc/dirsrv/schema/99user.ldif

الوصف

99user.ldif

يحتوي هذا الملف على تعريفات مخطط LDAP التي يعرفها المستخدم أو المخصصة (السمات وفئات الكائنات) التي يستخدمها خادم الدليل.

الصيغة

attributeTypes: VALUE
objectClasses: VALUE

مثال

dn: cn=schema
attributeTypes: ( 1.1.1.1.1.1.1 NAME 'myNewAttribute' DESC 'Custom defined attribute type' SYNTAX 1.3.6.1.4.1.1466.115.121.1.15 SINGLE-VALUE X-ORIGIN
objectClasses: ( 1.1.1.1.1.1.1.2 NAME 'myNewObjectcass' DESC 'Custom defined objectclass' SUP top MUST ( myNewAttribute ) MAY ( uid $ cn ) X-ORIGIN 'user-defined' )

المؤلف

تمت كتابة 99user.ldif بواسطة مشروع 389.

الإبلاغ عن الأخطاء

أبلغ عن الأخطاء إلى https://github.com/389ds/389-ds-base/issues/new
