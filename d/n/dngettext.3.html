dngettext(3)

الحزمة: gettext

التراخيص: GFDL-1.2-only, GPL-2.0-only, GPL-2.0-or-later, LGPL-2.0-only

NGETTEXT(3) دليل وظائف المكتبة NGETTEXT(3)

الاسم

ngettext, dngettext, dcngettext — ترجمة رسالة واختيار صيغة الجمع

الملخص

#include <libintl.h>

char * ngettext (const char * msgid, const char * msgid_plural,
                 unsigned long int n);
char * dngettext (const char * domainname,
                  const char * msgid, const char * msgid_plural,
                  unsigned long int n);
char * dcngettext (const char * domainname,
                   const char * msgid, const char * msgid_plural,
                   unsigned long int n, int category);

الوصف

تحاول وظائف ngettext و dngettext و dcngettext ترجمة سلسلة نصية إلى لغة المستخدم الأصلية، وذلك بالبحث عن صيغة الجمع المناسبة للترجمة في كتالوج رسائل.

صيغ الجمع هي أشكال نحوية تعتمد على رقم. بعض اللغات لديها شكلين، يُطلق عليهما المفرد والجمع. لغات أخرى لديها ثلاثة أشكال، تُسمى المفرد والمثنى والجمع. هناك أيضًا لغات لديها أربعة أشكال.

تعمل وظائف ngettext و dngettext و dcngettext مثل وظائف gettext و dgettext و dcgettext على التوالي. بالإضافة إلى ذلك، فإنها تختار صيغة الجمع المناسبة، والتي تعتمد على الرقم n ولغة كتالوج الرسائل الذي تم العثور فيه على الترجمة.

في الإعداد المحلي "C"، أو إذا لم تحتوي أي من الكتالوجات المستخدمة على ترجمة لـ msgid، فإن وظائف ngettext و dngettext و dcngettext تُرجع msgid إذا كان n == 1، أو msgid_plural إذا كان n != 1.

قيمة الإرجاع

إذا تم العثور على ترجمة في أحد الكتالوجات المحددة، فسيتم تحويل صيغة الجمع المناسبة إلى مجموعة رموز الإعداد المحلي وإرجاعها. السلسلة الناتجة مخصصة ثابتة ولا يجب تعديلها أو تحريرها. بخلاف ذلك، يتم إرجاع msgid أو msgid_plural، كما هو موضح أعلاه.

الأخطاء

لا يتم تعديل errno.

الأخطاء

كان يجب أن يكون نوع الإرجاع const char *، ولكنه char * لتجنب التحذيرات في كود C الذي يسبق ANSI C.
