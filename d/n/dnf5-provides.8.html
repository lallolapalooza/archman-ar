dnf5-provides(8)

الحزمة: dnf5

التراخيص: GPL-2.0-or-later

DNF5-PROVIDES(8) dnf5 DNF5-PROVIDES(8)

الاسم

dnf5-provides - أمر يوفر

الملخص

dnf5 provides [global options] <package-spec-PFB>...

الوصف

يقوم أمر provides في DNF5 بالعثور على الحزم التي توفر <package-spec-PFB> المحدد.

أمثلة

dnf5 provides tito
يخرج الحزم التي توفر الأمر tito.
dnf5 provides /usr/bin/tito
يخرج الحزمة التي توفر الملف /usr/bin/tito
dnf5 provides zless
لا يوجد Provides لـ zless ولكن توجد حزمة تحتوي على zless.
يخرج الحزمة التي توفر الملف /usr/bin/zless

ملاحظة:

سلوك جديد: إذا لم يتم العثور على حزمة واحدة أو أكثر بواسطة يوفر، فسيعيد DNF5 الآن رمز خروج 1 ويسرد جميع التوفيرات التي لا تتطابق في نهاية الإخراج.
dnf5 provides rpm nonexistent_package
يخرج التوفيرات لـ rpm ويبلغ في stderr بأن nonexistent_package
لم يتطابق مع أي نتيجة.
