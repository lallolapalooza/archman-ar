NAME

dnf5-do - Do Command

SYNOPSIS

dnf5 do [options] [arguments]

DESCRIPTION

الأمر do هو أمر عالمي لإدارة الحزم في DNF5. يسمح للمستخدم بتعريف عمليات متعددة (install، remove، upgrade، downgrade، and reinstall).

بخلاف سلسلة من الأوامر المحددة (install، remove، upgrade، downgrade، and reinstall)، يتعامل الأمر do مع جميع الإجراءات المطلوبة معًا ويقوم بتنفيذها في معاملة واحدة. هذا يبسط العمليات المعقدة ويجعلها أكثر كفاءة.

فرق آخر هو أن الأمر do يسمح بالتحديد الصريح لأنواع الكائنات في المعاملة: package، group، أو auto. بالنسبة لنوع group، من الممكن تحديد ما إذا كان معرف المجموعة (group ID) أو اسم المجموعة (group name) هو المستخدم. افتراضيًا، النوع auto نشط. في هذا الوضع، يتصرف الأمر do مثل الأوامر الأخرى، ويستنتج نوع الكائن من تحديده. على سبيل المثال، إذا بدأ التحديد بالحرف @، فإنه يُعامل كمعرف مجموعة (group ID) أو وحدة (module).

يتم تحديد الإجراءات الفردية وأنواع الكائنات بواسطة الخيارات ويمكن دمجها.

الخيارات الأخرى لها نفس المعنى والاستخدام كما هو الحال مع الأوامر (install، remove، upgrade، downgrade، and reinstall). الاستثناءات هي الخيارات --installed-from-repo و --from-repo. بينما لها نفس المعنى، فإنها تنطبق فقط على الحزم التي تتبعها في سطر الأوامر. بالإضافة إلى ذلك، يمكن تكرارها بقيم مختلفة.

OPTIONS

--action
Action to be done on the following items.

هذا خيار إلزامي يجب أن يسبق عناصر المعاملة (الكائنات). يحتاج الأمر do إلى هذه المعلومات لمعرفة الإجراء الذي يجب اتخاذه على العناصر المحددة. يدعم: install، remove، upgrade، downgrade، reinstall.

--type
Type of the following items.

يدعم: auto، package، group. auto هو الافتراضي حتى يتم استخدام الخيار type.

--allowerasing
Allow removing of installed packages to resolve any potential dependency problems.

السماح بإزالة الحزم المثبتة لحل أي مشاكل تبعية محتملة.

--skip-broken
Resolve any dependency problems by removing packages that are causing problems from the transaction.

حل أي مشاكل تبعية عن طريق إزالة الحزم التي تسبب المشاكل من المعاملة.

--skip-unavailable
Allow skipping packages that are not available in repositories. All available packages will be installed.

السماح بتخطي الحزم غير المتوفرة في المستودعات. سيتم تثبيت جميع الحزم المتاحة.

--allow-downgrade
Enable downgrade of dependencies when resolving the requested operation.

تمكين تخفيض إصدار التبعيات عند حل العملية المطلوبة.

--no-allow-downgrade
Disable downgrade of dependencies when resolving the requested operation.

تعطيل تخفيض إصدار التبعيات عند حل العملية المطلوبة.

--installed-from-repo=REPO_ID,...
Filters installed packages by the ID of the repository they were installed from.

تصفية الحزم المثبتة حسب معرف المستودع الذي تم التثبيت منه.

--from-repo=REPO_ID,...
Packages (or their provides) explicitly specified on the command line will only be looked up in the specified repositories.
These repositories are automatically enabled.
Repository enabling and disabling still applies. Dependencies of these packages will be resolved from any enabled repository.

سيتم البحث عن الحزم (أو ما توفره) المحددة صراحة في سطر الأوامر فقط في المستودعات المحددة. سيتم تمكين هذه المستودعات تلقائيًا. لا يزال تمكين وتعطيل المستودعات ساري المفعول. سيتم حل تبعيات هذه الحزم من أي مستودع ممكّن.

--downloadonly
Download the resolved package set without executing an RPM transaction.

تنزيل مجموعة الحزم التي تم حلها دون تنفيذ معاملة RPM.

--offline
Store the transaction to be performed offline. See dnf5-offline(8), Offline command <#offline-command-ref-label>.

تخزين المعاملة ليتم تنفيذها دون اتصال بالإنترنت. انظر dnf5-offline(8)، الأمر Offline <#offline-command-ref-label>.

--advisories=ADVISORY_NAME,...
Include content contained in advisories with specified name.
This is a list option.
Expected values are advisory IDs, e.g. FEDORA-2201-123.
Any transaction command (install, upgrade) will fail with an error if there is no existing advisory in the list; this can be bypassed by using the --skip-unavailable switch.

تضمين المحتوى الموجود في الإشعارات بالاسم المحدد. هذا خيار قائمة. القيم المتوقعة هي معرفات الإشعارات، مثل FEDORA-2201-123. أي أمر معاملة (تثبيت، ترقية) سيفشل بخطأ إذا لم يكن هناك إشعار موجود في القائمة؛ يمكن تجاوز ذلك باستخدام خيار --skip-unavailable.

--advisory-severities=ADVISORY_SEVERITY,...
Include content contained in advisories with specified severity.
This is a list option.
Accepted values are: critical, important, moderate, low, none.

تضمين المحتوى الموجود في الإشعارات بالشدة المحددة. هذا خيار قائمة. القيم المقبولة هي: critical، important، moderate، low، none.

--bzs=BUGZILLA_ID,...
Include content contained in advisories that fix a ticket of the given Bugzilla ID.
This is a list option.
Expected values are numeric IDs, e.g. 123123.
Any transaction command (install, upgrade) will fail with an error if there is no advisory fixing the given ticket; this can be bypassed by using the --skip-unavailable switch.

تضمين المحتوى الموجود في الإشعارات التي تصلح تذكرة معرف Bugzilla المحدد. هذا خيار قائمة. القيم المتوقعة هي معرفات رقمية، مثل 123123. أي أمر معاملة (تثبيت، ترقية) سيفشل بخطأ إذا لم يكن هناك إشعار يصلح التذكرة المحددة؛ يمكن تجاوز ذلك باستخدام خيار --skip-unavailable.

--cves=CVE_ID,...
Include content contained in advisories that fix a ticket of the given CVE (Common Vulnerabilities and Exposures) ID.
This is a list option.
Expected values are string IDs in CVE format, e.g. CVE-2201-0123.
Any transaction command (install, upgrade) will fail with an error if there is no advisory fixing the given ticket; this can be bypassed by using the --skip-unavailable switch.

تضمين المحتوى الموجود في الإشعارات التي تصلح تذكرة معرف CVE (Common Vulnerabilities and Exposures) المحدد. هذا خيار قائمة. القيم المتوقعة هي معرفات نصية بتنسيق CVE، مثل CVE-2201-0123. أي أمر معاملة (تثبيت، ترقية) سيفشل بخطأ إذا لم يكن هناك إشعار يصلح التذكرة المحددة؛ يمكن تجاوز ذلك باستخدام خيار --skip-unavailable.

--security
Include content contained in security advisories.

تضمين المحتوى الموجود في إشعارات الأمان.

--bugfix
Include content contained in bugfix advisories.

تضمين المحتوى الموجود في إشعارات إصلاح الأخطاء.

--enhancement
Include content contained in enhancement advisories.

تضمين المحتوى الموجود في إشعارات التحسينات.

--newpackage
Include content contained in newpackage advisories.

تضمين المحتوى الموجود في إشعارات الحزم الجديدة.

EXAMPLES

dnf5 do --action=install tito
تثبيت حزمة tito.
dnf5 do --action=remove sddm-wayland-plasma --action=install sddm-x11
استبدال حزمة sddm-wayland-plasma بـ sddm-x11.
dnf5 do --action=install --type=group id=office 'name=Games and Entertainment' --type=package iftop --action=remove atop
تثبيت مجموعة office (بالمعرف)، ومجموعة Games and Entertainment (بالاسم)، وحزمة iftop، وإزالة حزمة atop.
dnf5 do --action=install pkg --from-repo=myrepo1 pkg1 --from-repo=myrepo2 pkg2 --action=remove --installed-from-repo=compromised_repo '*'
تثبيت حزمة pkg من أي مستودع ممكّن، بالإضافة إلى حزمة pkg1 من المستودع myrepo1 وحزمة pkg2 من المستودع myrepo2. التبعيات
