DNF5-CHANGELOG(8) dnf5 DNF5-CHANGELOG(8)

الاسم

dnf5-changelog - أمر سجل التغييرات

ملخص

dnf5 changelog [خيارات] [<حزمة-مواصفات-NI>...]

الوصف

عرض سجلات تغيير الحزم.

خيارات

--since=DATE
عرض إدخالات سجل التغييرات فقط منذ DATE.
توقع تنسيق التاريخ YYYY-MM-DD.
--count=VALUE
تحديد عدد إدخالات سجل التغييرات المعروضة لكل حزمة إلى VALUE.
--upgrades
عرض إدخالات سجل التغييرات الجديدة فقط للحزم التي توفر ترقيات للحزم المثبتة بالفعل.

أمثلة

dnf5 changelog --since=2023-04-01
عرض إدخالات سجل التغييرات منذ 1 أبريل 2023 لجميع الحزم.
dnf5 changelog --count=5 bash
عرض آخر 3 سجلات تغيير لحزمة bash.
