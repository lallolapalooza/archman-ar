real(wp) function dnrm2 (integer n, real(wp), dimension(*) x, integer incx)

DNRM2

الغرض:

!>
!> DNRM2 تعيد المعيار الإقليدي للمتجه من خلال اسم الدالة، بحيث
!>
!>    DNRM2 := sqrt( x'*x )
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>         عدد العناصر في المتجه (المتجهات) المدخلة
!>

X

!>          X هو مصفوفة من نوع DOUBLE PRECISION، بحجم ( 1 + ( N - 1 )*abs( INCX ) )
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)، المسافة التخزينية بين عناصر X
!>          إذا كان INCX > 0، فإن X(1+(i-1)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX < 0، فإن X(1-(n-i)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX = 0، فإن x ليس متجهًا، لذلك لا داعي لاستدعاء
!>          هذا الروتين الفرعي. إذا قمت باستدعائه على أي حال، فسيتم عد x(1)
!>          في معيار المتجه N مرة.
!>
