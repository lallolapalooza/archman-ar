real(wp) function dznrm2 (integer n, complex(wp), dimension(*) x, integer incx)

DZNRM2

الغرض:

!>
!> DZNRM2 تُرجع المعيار الإقليدي لمتجه عبر اسم الوظيفة، بحيث
!>
!>    DZNRM2 := sqrt( x**H*x )
!>

المعلمات

N 
!>          N هو عدد صحيح (INTEGER)
!>         عدد العناصر في المتجه (المتجهات) المدخلة
!>

X

!>          X هو مصفوفة مركبة (COMPLEX*16)، ذات أبعاد (N)
!>         متجه مركّب به N عناصر
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)، المسافة المخزنة بين عناصر X
!>          إذا كان INCX > 0، فإن X(1+(i-1)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX < 0، فإن X(1-(n-i)*INCX) = x(i) لـ 1 <= i <= n
!>          إذا كان INCX = 0، فإن X ليس متجهًا، لذلك لا حاجة لاستدعاء
!>          هذا الإجراء الفرعي. إذا قمت باستدعائه على أي حال، فسيتم احتساب x(1)
!>          في معيار المتجه N مرة.
!>
