subroutine dptt01 (integer n, double precision, dimension( * ) d, double precision, dimension( * ) e, double precision, dimension( * ) df, double precision, dimension( * ) ef, double precision, dimension( * ) work, double precision resid)

DPTT01

الغرض:

!>
!> DPTT01 يعيد بناء مصفوفة ثلاثية قطرية A من تحليلها L*D*L'
!> ويحسب الباقي
!>    norm(L*D*L' - A) / ( n * norm(A) * EPS ),
!> حيث EPS هو الجزء الكسري من الآلة.
!>

المعلمات

N 
!>          N هو عدد صحيح
!>          مرتبة المصفوفة A.
!>

D

!>          D هو مصفوفة ذات دقة مزدوجة، بُعدها (N)
!>          عناصر القطرية الـ n للمصفوفة الثلاثية القطرية A.
!>

E

!>          E هو مصفوفة ذات دقة مزدوجة، بُعدها (N-1)
!>          العناصر تحت القطرية الـ (n-1) للمصفوفة الثلاثية القطرية A.
!>

DF

!>          DF هو مصفوفة ذات دقة مزدوجة، بُعدها (N)
!>          عناصر القطرية الـ n للعامل L من تحليل L*D*L'
!>          للمصفوفة A.
!>

EF

!>          EF هو مصفوفة ذات دقة مزدوجة، بُعدها (N-1)
!>          العناصر تحت القطرية الـ (n-1) للعامل L من
!>          تحليل L*D*L' للمصفوفة A.
!>

WORK

!>          WORK هو مصفوفة ذات دقة مزدوجة، بُعدها (2*N)
!>

RESID

!>          RESID هو دقة مزدوجة
!>          norm(L*D*L' - A) / (n * norm(A) * EPS)
!>
