DPMSGetTimeouts(3)

الحزمة: libxext

التراخيص: LicenseRef-libxext

DPMSGetTimeouts(3) X FUNCTIONS DPMSGetTimeouts(3)

الاسم

DPMSGetTimeouts - استرداد قيم المهلة الزمنية المستخدمة بواسطة خادم X لتوقيتات DPMS

الملخص

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/dpms.h>
Bool DPMSGetTimeouts
(
      Display *display,
      CARD16 *standby,
      CARD16 *suspend,
      CARD16 *off
);

الوسائط

display
يحدد الاتصال بخادم X
standby
يحدد مهلة الاستعداد الحالية بالثواني
suspend
يحدد مهلة التعليق الحالية بالثواني
off
يحدد مهلة الإيقاف الحالية بالثواني

الوصف

تقوم الدالة DPMSGetTimeouts باسترداد قيم المهلة الزمنية المستخدمة بواسطة خادم X لتوقيتات DPMS.

القيمة standby هي مقدار الوقت الذي لم يتم فيه أي نشاط بالثواني قبل استدعاء وضع الاستعداد. قيمة صفر تشير إلى تعطيل هذا الوضع.

القيمة suspend هي مقدار الوقت الذي لم يتم فيه أي نشاط بالثواني قبل استدعاء المستوى الثاني من توفير الطاقة. قيمة صفر تشير إلى تعطيل هذا الوضع.

القيمة off هي مقدار الوقت الذي لم يتم فيه أي نشاط بالثواني قبل استدعاء المستوى الثالث والأخير لتوفير الطاقة. قيمة صفر تشير إلى تعطيل هذا الوضع.

قيم الإرجاع

TRUE
تعيد الدالة DPMSGetTimeouts القيمة TRUE عندما يتم إرجاع القيم.
FALSE
تعيد الدالة DPMSGetTimeouts القيمة FALSE عندما لا يتم إرجاع أي قيم.
