DPMSGetVersion(3)

الحزمة: libxext

التراخيص: LicenseRef-libxext

DPMSGetVersion(3) وظائف X DPMSGetVersion(3)

الاسم

DPMSGetVersion - يعيد إصدار امتداد DPMS الذي ينفذه خادم X

الملخص

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/dpms.h>
Status DPMSGetVersion
(
      Display *display,
      int *major_version,
      int *minor_version
);

الوسائط

display
يحدد الاتصال بخادم X
major_version
يحدد موقع الإرجاع للإصدار الرئيسي للامتداد
minor_version
يحدد موقع الإرجاع للإصدار الفرعي للامتداد

الوصف

تقوم الدالة DPMSGetVersion بإرجاع إصدار إشارة إدارة طاقة العرض (DPMS) الذي ينفذه خادم X. تعيد رقم إصدار رئيسي وفرعي. سيتم زيادة رقم الإصدار الرئيسي للتغييرات غير المتوافقة مع البروتوكول، وسيتم زيادة رقم الإصدار الفرعي للتغييرات الصغيرة والمتوافقة مع الإصدارات السابقة.

قيم الإرجاع

TRUE
تقوم الدالة DPMSGetVersion بإرجاع TRUE عندما يكون الامتداد مدعومًا ويتم إرجاع القيم.
FALSE
تقوم الدالة DPMSGetVersion بإرجاع FALSE عندما لا يكون الامتداد مدعومًا.

انظر أيضًا

DPMSCapable(3)، DPMSQueryExtension(3)
