DPMSEnable(3)

الحزمة: libxext

التراخيص: LicenseRef-libxext

DPMSEnable(3) وظائف X DPMSEnable(3)

الاسم

DPMSEnable - تمكين DPMS على الشاشة المحددة

الملخص

cc [ flag ... ] file ... -lXext [ library ... ]
#include <X11/extensions/dpms.h>
Status DPMSEnable ( Display *display );

الوسائط

display
يحدد الاتصال بخادم X

الوصف

تقوم الدالة DPMSEnable بتمكين إشارات إدارة طاقة العرض (DPMS) على الشاشة المحددة. عند تمكين DPMS، سيستخدم DPMS قيم المهلة المحفوظة حاليًا. سيؤدي ذلك إلى تشغيل مستوى طاقة DPMS المناسب بناءً على قيم المهلة. راجع DPMSSetTimeouts. تتأثر جميع الشاشات المادية بـ DPMSEnable في نفس الوقت.

إذا تم استدعاء DPMSEnable على شاشة تم تمكين DPMS عليها بالفعل، أو على شاشة لا تدعم DPMS، فلن يتم إجراء أي تغيير ولن يتم إرجاع خطأ.

قيم الإرجاع

TRUE
تعود الدالة DPMSEnable دائمًا بالقيمة TRUE.

انظر أيضًا

DPMSCapable(3)، DPMSDisable(3)، DPMSGetTimeouts(3)، DPMSSetTimeouts(3)

libXext 1.3.6 إصدار X 11
