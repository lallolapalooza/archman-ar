subroutine dppequ (character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) s, double precision scond, double precision amax, integer info)

DPPEQU

الغرض:

!>
!> DPPEQU تحسب مقاييس الصف والعمود المقصود بها موازنة مصفوفة متماثلة موجبة محددة A
!> مخزنة بشكل مكدس وتقليل رقم حالتها (بالنسبة إلى المعيار الثنائي). S تحتوي على
!> عوامل القياس، S(i)=1/sqrt(A(i,i))، مختارة بحيث تكون المصفوفة المقاسة
!> B بعناصر B(i,j)=S(i)*A(i,j)*S(j) لها واحدات على القطر.
!> هذا الاختيار لـ S يضع رقم حالة B ضمن عامل N
!> من أصغر رقم حالة ممكن عبر جميع مقاييس الأقطار الممكنة.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  المثلث العلوي لـ A مخزن؛
!>          = 'L':  المثلث السفلي لـ A مخزن.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A. N >= 0.
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          المثلث العلوي أو السفلي للمصفوفة المتماثلة A، مكدس
!>          عمودياً في مصفوفة خطية. يتم تخزين العمود j للمصفوفة A
!>          في المصفوفة AP كالتالي:
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.
!>

S

!>          S is DOUBLE PRECISION array, dimension (N)
!>          If INFO = 0, S contains the scale factors for A.
!>

SCOND

!>          SCOND is DOUBLE PRECISION
!>          If INFO = 0, S contains the ratio of the smallest S(i) to
!>          the largest S(i).  If SCOND >= 0.1 and AMAX is neither too
!>          large nor too small, it is not worth scaling by S.
!>

AMAX

!>          AMAX is DOUBLE PRECISION
!>          القيمة المطلقة لأكبر عنصر في المصفوفة. إذا كانت AMAX قريبة جداً
!>          من الفائض أو قريبة جداً من النقص، يجب قياس المصفوفة.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element is nonpositive.
!>
