dblink_send_query(3)

الحزمة: postgresql

التراخيص: PostgreSQL

DBLINK_SEND_QUERY(3) وثائق PostgreSQL 18.1 DBLINK_SEND_QUERY(3)

الاسم

dblink_send_query - يرسل استعلامًا غير متزامن إلى قاعدة بيانات بعيدة

الملخص

dblink_send_query(text connname, text sql) returns int

الوصف

dblink_send_query يرسل استعلامًا ليتم تنفيذه بشكل غير متزامن، أي، دون انتظار فوري للنتيجة. يجب ألا يكون هناك استعلام غير متزامن قيد التقدم بالفعل على الاتصال.

بعد الإرسال الناجح لاستعلام غير متزامن، يمكن التحقق من حالة الإنجاز باستخدام dblink_is_busy، ويتم جمع النتائج في النهاية باستخدام dblink_get_result. من الممكن أيضًا محاولة إلغاء استعلام غير متزامن نشط باستخدام dblink_cancel_query.

الوسائط

connname

اسم الاتصال المراد استخدامه.

sql

عبارة SQL التي ترغب في تنفيذها في قاعدة البيانات البعيدة، على سبيل المثال select * from pg_class.

قيمة الإرجاع

يعيد 1 إذا تم إرسال الاستعلام بنجاح، و 0 بخلاف ذلك.

أمثلة

SELECT dblink_send_query('dtest1', 'SELECT * FROM foo WHERE f1 < 3');
