dblink_exec(3)

الحزمة: postgresql

التراخيص: PostgreSQL

DBLINK_EXEC(3) توثيق PostgreSQL 18.1 DBLINK_EXEC(3)

الاسم

dblink_exec - يقوم بتنفيذ أمر في قاعدة بيانات بعيدة

الملخص

dblink_exec(text connname, text sql [, bool fail_on_error]) returns text
dblink_exec(text connstr, text sql [, bool fail_on_error]) returns text
dblink_exec(text sql [, bool fail_on_error]) returns text

الوصف

dblink_exec يقوم بتنفيذ أمر (أي، أي عبارة SQL لا تُرجع صفوفًا) في قاعدة بيانات بعيدة.

عند إعطاء وسيطين نصيين، يتم البحث أولاً عن الأول كاسم اتصال دائم؛ إذا تم العثور عليه، يتم تنفيذ الأمر على هذا الاتصال. إذا لم يتم العثور عليه، يتم التعامل مع الوسيط الأول كسلسلة معلومات اتصال كما هو الحال مع dblink_connect، ويتم إنشاء الاتصال المحدد فقط طوال مدة هذا الأمر.

الوسائط

connname

اسم الاتصال المراد استخدامه؛ احذف هذه المعلمة لاستخدام الاتصال غير المسمى.

connstr

سلسلة معلومات اتصال، كما تم وصفها سابقًا لـ dblink_connect.

sql

الأمر SQL الذي ترغب في تنفيذه في قاعدة البيانات البعيدة، على سبيل المثال insert into foo values(0, 'a', '{"a0","b0","c0"}').

fail_on_error

إذا كانت صحيحة (القيمة الافتراضية عند حذفها)، فإن خطأ يتم إلقاؤه على الجانب البعيد للاتصال يتسبب في إلقاء خطأ محليًا أيضًا. إذا كانت خاطئة، يتم الإبلاغ عن الخطأ البعيد محليًا كـ NOTICE، ويتم تعيين قيمة إرجاع الدالة إلى ERROR.

قيمة الإرجاع

تُرجع الحالة، إما سلسلة حالة الأمر أو ERROR.

أمثلة

SELECT dblink_connect('dbname=dblink_test_standby');
 dblink_connect
----------------
 OK
(1 row)
SELECT dblink_exec('insert into foo values(21, ''z'', ''{"a0","b0","c0"}'');');
   dblink_exec
-----------------
 INSERT 943366 1
(1 row)
SELECT dblink_connect('myconn', 'dbname=regression');
 dblink_connect
----------------
 OK
(1 row)
SELECT dblink_exec('myconn', 'insert into foo values(21, ''z'', ''{"a0","b0","c0"}'');');
   dblink_exec
------------------
 INSERT 6432584 1
(1 row)
SELECT dblink_exec('myconn', 'insert into pg_class values (''foo'')',false);
NOTICE:  sql error
DETAIL:  ERROR:  null value in column "relnamespace" violates not-null constraint
 dblink_exec
-------------
 ERROR
(1 row)
