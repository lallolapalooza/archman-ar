DBD__Sponge(3pm)

الحزمة: perl-dbi

التراخيص: GPL, PerlArtistic

DBD::Sponge(3) وثائق Perl المساهمة من المستخدم DBD::Sponge(3)

الاسم

DBD::Sponge - إنشاء مقبض بيان DBI من بيانات Perl

الملخص

my $sponge = DBI->connect("dbi:Sponge:","","",{ RaiseError => 1 });
my $sth = $sponge->prepare($statement, {
        rows => $data,
        NAME => $names,
        %attr
    }
);

الوصف

DBD::Sponge مفيد لجعل بنية بيانات Perl متاحة من خلال مقبض بيان DBI قياسي. قد يكون هذا مفيدًا لمؤلفي وحدات DBD الذين يحتاجون إلى تحويل البيانات بهذه الطريقة.

الطرق

connect()

my $sponge = DBI->connect("dbi:Sponge:","","",{ RaiseError => 1 });

هنا صيغة نموذجية لإنشاء مقبض قاعدة بيانات لبرنامج تشغيل Sponge. لا توجد حاجة لاسم مستخدم أو كلمة مرور.

prepare()

my $sth = $sponge->prepare($statement, {
        rows => $data,
        NAME => $names,
        %attr
    }
);
  • $statement هنا هو بيان تعسفي أو اسم تريد تقديمه كهوية لبياناتك. إذا كنت تستخدم DBI::Profile، فسيظهر في بيانات ملف التعريف.

    بشكل عام، من المتوقع أن تقوم بإعداد مقبض بيان كما لو حدث بيان "select".

  • $data هو مرجع للبيانات التي تقدمها، معطاة كمصفوفة من المصفوفات.
  • $names هو مرجع لمصفوفة من أسماء الأعمدة لـ $data التي تقدمها. يجب أن يتطابق العدد والترتيب مع عدد وترتيب أعمدة $data.
  • %attr هو تجزئة من سمات DBI القياسية الأخرى التي قد تمررها إلى بيان prepare.

    حاليًا، يتم دعم NAME و TYPE و PRECISION فقط.

الأخطاء

استخدام هذه الوحدة لإعداد بيانات تشبه INSERT غير موثق حاليًا.
