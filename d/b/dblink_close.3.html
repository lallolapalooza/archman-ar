dblink_close(3)

الحزمة: postgresql

التراخيص: PostgreSQL

DBLINK_CLOSE(3) توثيق PostgreSQL 18.1 DBLINK_CLOSE(3)

الاسم

dblink_close - يغلق مؤشرًا في قاعدة بيانات بعيدة

الملخص

dblink_close(text cursorname [, bool fail_on_error]) returns text
dblink_close(text connname, text cursorname [, bool fail_on_error]) returns text

الوصف

dblink_close يغلق مؤشرًا تم فتحه سابقًا باستخدام dblink_open.

المعاملات

connname

اسم الاتصال المراد استخدامه؛ احذف هذا المعامل لاستخدام الاتصال غير المسمى.

cursorname

اسم المؤشر المراد إغلاقه.

fail_on_error

إذا كانت القيمة صحيحة (افتراضي عند حذفه) فعندئذٍ يتسبب الخطأ الذي يظهر على الجانب البعيد للاتصال في ظهور خطأ محليًا أيضًا. إذا كانت القيمة خاطئة، يتم الإبلاغ عن الخطأ البعيد محليًا كـ NOTICE، ويتم تعيين قيمة إرجاع الدالة إلى ERROR.

قيمة الإرجاع

تعيد الحالة، إما OK أو ERROR.

ملاحظات

إذا بدأت dblink_open كتلة معامل صريحة، وكان هذا هو المؤشر المفتوح الوحيد المتبقي في هذا الاتصال، فستقوم dblink_close بتنفيذ COMMIT المطابق.

أمثلة

SELECT dblink_connect('dbname=postgres options=-csearch_path=');
 dblink_connect
----------------
 OK
(1 row)
SELECT dblink_open('foo', 'select proname, prosrc from pg_proc');
 dblink_open
-------------
 OK
(1 row)
SELECT dblink_close('foo');
 dblink_close
--------------
 OK
(1 row)
