توثيق الوظيفة/الروتين الفرعي

subroutine dgehd2 (integer n, integer ilo, integer ihi, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) tau, double precision, dimension( * ) work, integer info)

DGEHD2 تختزل مصفوفة مربعة عامة إلى شكل هسنبرغ العلوي باستخدام خوارزمية غير محظورة.

الغرض:

!>
!> DGEHD2 تختزل مصفوفة عامة حقيقية A إلى شكل هسنبرغ العلوي H عن طريق
!> تحويل تشابه متعامد:  Q**T * A * Q = H .
!>

المعلمات

N 
!>          N هو عدد صحيح
!>          رتبة المصفوفة A.  N >= 0.
!>

ILO

!>          ILO هو عدد صحيح
!>

IHI

!>          IHI هو عدد صحيح
!>
!>          يفترض أن A هي بالفعل مصفوفة مثلثة عليا في الصفوف
!>          والأعمدة 1:ILO-1 و IHI+1:N. عادة ما يتم تعيين ILO و IHI
!>          بواسطة استدعاء سابق لـ DGEBAL؛ بخلاف ذلك، يجب تعيينها
!>          إلى 1 و N على التوالي. انظر التفاصيل الإضافية.
!>          1 <= ILO <= IHI <= max(1,N).
!>

A

!>          A هي مصفوفة DOUBLE PRECISION، البعد (LDA,N)
!>          عند الدخول، المصفوفة العامة n × n المطلوب اختزالها.
!>          عند الخروج، يتم الكتابة فوق الجزء المثلثي العلوي والقطر السفلي الأول من A
!>          بمصفوفة هسنبرغ العلوية H، والعناصر أسفل القطر السفلي الأول، مع المصفوفة TAU،
!>          تمثل المصفوفة المتعامدة Q كناتج لمُحولات أولية. انظر التفاصيل الإضافية.
!>

LDA

!>          LDA هو عدد صحيح
!>          البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

TAU

!>          TAU هي مصفوفة DOUBLE PRECISION، البعد (N-1)
!>          العوامل القياسية للمُحولات الأولية (انظر التفاصيل الإضافية).
!>

WORK

!>          WORK هي مصفوفة DOUBLE PRECISION، البعد (N)
!>

INFO

!>          INFO هو عدد صحيح
!>          = 0:  خروج ناجح.
!>          < 0:  إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية.
!>

تفاصيل إضافية:

!>
!>  المصفوفة Q ممثلة كناتج لـ (ihi-ilo) مُحول أولي
!>  مُحولات
!>
!>     Q = H(ilo) H(ilo+1) . . . H(ihi-1).
!>
!>  كل H(i) لها الشكل
!>
!>     H(i) = I - tau * v * v**T
!>
!>  حيث tau هو عدد حقيقي، و v هو متجه حقيقي مع
!>  v(1:i) = 0، v(i+1) = 1، و v(ihi+1:n) = 0؛ v(i+2:ihi) مخزنة عند
!>  الخروج في A(i+2:ihi,i)، و tau في TAU(i).
!>
!>  محتويات A موضحة بالمثال التالي، مع
!>  n = 7، ilo = 2، و ihi = 6:
!>
!>  عند الدخول،                        عند الخروج،
!>
!>  ( a   a   a   a   a   a   a )    (  a   a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      a   h   h   h   h   a )
!>  (     a   a   a   a   a   a )    (      h   h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  h   h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  h   h   h   h )
!>  (     a   a   a   a   a   a )    (      v2  v3  v4  h   h   h )
!>  (                         a )    (                          a )
!>
!>  حيث a يمثل عنصراً من المصفوفة الأصلية A، h يمثل عنصراً معدلاً
!>  من مصفوفة هسنبرغ العلوية H، و vi يمثل عنصراً
!>  من المتجه الذي يحدد H(i).
!>
