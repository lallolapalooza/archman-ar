subroutine dgbsvxx (character fact, character trans, integer n, integer kl, integer ku, integer nrhs, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( ldafb, * ) afb, integer ldafb, integer, dimension( * ) ipiv, character equed, double precision, dimension( * ) r, double precision, dimension( * ) c, double precision, dimension( ldb, * ) b, integer ldb, double precision, dimension( ldx , * ) x, integer ldx, double precision rcond, double precision rpvgrw, double precision, dimension( * ) berr, integer n_err_bnds, double precision, dimension( nrhs, * ) err_bnds_norm, double precision, dimension( nrhs, * ) err_bnds_comp, integer nparams, double precision, dimension( * ) params, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGBSVXX computes the solution to system of linear equations A * X = B for GB matrices

Purpose:

!>
!>    DGBSVXX uses the LU factorization to compute the solution to a
!>    double precision system of linear equations  A * X = B,  where A is an
!>    N-by-N matrix and B and X are N-by-NRHS matrices.
!>
!>    If requested, both normwise and maximum componentwise error bounds
!>    are returned. DGBSVXX will return a solution with a tiny
!>    guaranteed error (O(eps) where eps is the working machine
!>    precision) unless the matrix is very ill-conditioned, in which
!>    case a warning is returned. Relevant condition numbers also are
!>    calculated and returned.
!>
!>    DGBSVXX accepts user-provided factorizations and equilibration
!>    factors; see the definitions of the FACT and EQUED options.
!>    Solving with refinement and using a factorization from a previous
!>    DGBSVXX call will also produce a solution with either O(eps)
!>    errors or warnings, but we cannot make that claim for general
!>    user-provided factorizations and equilibration factors if they
!>    differ from what DGBSVXX would itself produce.
!>

Description:

!>
!>    The following steps are performed:
!>
!>    1. If FACT = 'E', double precision scaling factors are computed to equilibrate
!>    the system:
!>
!>      TRANS = 'N':  diag(R)*A*diag(C)     *inv(diag(C))*X = diag(R)*B
!>      TRANS = 'T': (diag(R)*A*diag(C))**T *inv(diag(R))*X = diag(C)*B
!>      TRANS = 'C': (diag(R)*A*diag(C))**H *inv(diag(R))*X = diag(C)*B
!>
!>    Whether or not the system will be equilibrated depends on the
!>    scaling of the matrix A, but if equilibration is used, A is
!>    overwritten by diag(R)*A*diag(C) and B by diag(R)*B (if TRANS='N')
!>    or diag(C)*B (if TRANS = 'T' or 'C').
!>
!>    2. If FACT = 'N' or 'E', the LU decomposition is used to factor
!>    the matrix A (after equilibration if FACT = 'E') as
!>
!>      A = P * L * U,
!>
!>    where P is a permutation matrix, L is a unit lower triangular
!>    matrix, and U is upper triangular.
!>
!>    3. If some U(i,i)=0, so that U is exactly singular, then the
!>    routine returns with INFO = i. Otherwise, the factored form of A
!>    is used to estimate the condition number of the matrix A (see
!>    argument RCOND). If the reciprocal of the condition number is less
!>    than machine precision, the routine still goes on to solve for X
!>    and compute error bounds as described below.
!>
!>    4. The system of equations is solved for X using the factored form
!>    of A.
!>
!>    5. By default (unless PARAMS(LA_LINRX_ITREF_I) is set to zero),
!>    the routine will use iterative refinement to try to get a small
!>    error and error bounds.  Refinement calculates the residual to at
!>    least twice the working precision.
!>
!>    6. If equilibration was used, the matrix X is premultiplied by
!!>    diag(C) (if TRANS = 'N') or diag(R) (if TRANS = 'T' or 'C') so
!>    that it solves the original system before equilibration.
!> 
!>     Some optional parameters are bundled in the PARAMS array.  These
!>     settings determine how refinement is performed, but often the
!>     defaults are acceptable.  If the defaults are acceptable, users
!>     can pass NPARAMS = 0 which prevents the source code from accessing
!>     the PARAMS argument.
!>

Parameters

FACT 
!>          FACT is CHARACTER*1
!>     Specifies whether or not the factored form of the matrix A is
!>     supplied on entry, and if not, whether the matrix A should be
!>     equilibrated before it is factored.
!>       = 'F':  On entry, AF and IPIV contain the factored form of A.
!>               If EQUED is not 'N', the matrix A has been
!>               equilibrated with scaling factors given by R and C.
!>               A, AF, and IPIV are not modified.
!>       = 'N':  The matrix A will be copied to AF and factored.
!>       = 'E':  The matrix A will be equilibrated if necessary, then
!>               copied to AF and factored.
!>

TRANS

!>          TRANS is CHARACTER*1
!>     Specifies the form of the system of equations:
!>       = 'N':  A * X = B     (No transpose)
!>       = 'T':  A**T * X = B  (Transpose)
!>       = 'C':  A**H * X = B  (Conjugate Transpose = Transpose)
!>

N

!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!>

KL

!>          KL is INTEGER
!>     The number of subdiagonals within the band of A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>     The number of superdiagonals within the band of A.  KU >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>     The number of right hand sides, i.e., the number of columns
!>     of the matrices B and X.  NRHS >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>     On entry, the matrix A in band storage, in rows 1 to KL+KU+1.
!>     The j-th column of A is stored in the j-th column of the
!>     array AB as follows:
!>     AB(KU+1+i-j,j) = A(i,j) for max(1,j-KU)<=i<=min(N,j+kl)
!>
!>     If FACT = 'F' and EQUED is not 'N', then AB must have been
!>     equilibrated by the scaling factors in R and/or C.  AB is not
!>     modified if FACT = 'F' or 'N', or if FACT = 'E' and
!>     EQUED = 'N' on exit.
!>
!>     On exit, if EQUED .ne. 'N', A is scaled as follows:
!>     EQUED = 'R':  A := diag(R) * A
!>     EQUED = 'C':  A := A * diag(C)
!>     EQUED = 'B':  A := diag(R) * A * diag(C).
!>

LDAB

!>          LDAB is INTEGER
!>     The leading dimension of the array AB.  LDAB >= KL+KU+1.
!>

AFB

!>          AFB is DOUBLE PRECISION array, dimension (LDAFB,N)
!>     On entry, if FACT = 'F', AFB contains the factored form of the
!>     matrix A.  AFB is not modified.
!>
!>     On exit, if FACT = 'E', AFB contains the factored form of the
!>     equilibrated or unbalanced matrix A.
!>     The factorization is in the same format as is returned by DGBTRF.
!>

LDAFB

!>          LDAFB is INTEGER
!>     The leading dimension of the array AFB.
!>     LDAFB >= 2*KL+KU+1.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>     On entry, if FACT = 'F', IPIV contains the pivot indices from
!>     the factorization. IPIV is not modified.
!>
!>     On exit, if FACT = 'E', IPIV contains the pivot indices from
!>     the factorization of the current matrix A.
!>     The pivot indices are given in the array as returned by DGBTRF.
!>

EQUED

!>          EQUED is CHARACTER*1
!>     Describes the scaling that was done in EQUILIBRATE matrix A.
!>       = 'N': No equilibration was done, Equilibrate was not called.
!>       = 'R': Row equilibration was done, i.e., A was replaced by
!>              diag(R)*A, which in the call was diag(R)*A*I.
!>       = 'C': Column equilibration and mixing was done, i.e., A was
!>              replaced by A*diag(C).
!>       = 'B': Both row and column equilibration and mixing was done,
!>              i.e., A was replaced by diag(R)*A*diag(C).
!>     On entry, if FACT = 'F', EQUED specifies the form of equilibration
!>     done.
!>

R

!>          R is DOUBLE PRECISION array, dimension (N)
!>     On entry, if FACT = 'F' and EQUED is 'R' or 'B', R contains the
!>     row scaling factors for the matrix A.
!>
!>     On exit, if EQUED = 'R' or 'B', R contains the row scaling
!>     factors that were applied to matrix A.
!>

C

!>          C is DOUBLE PRECISION array, dimension (N)
!>     On entry, if FACT = 'F' and EQUED is 'C' or 'B', C contains the
!>     column scaling factors for the matrix A.
!>
!>     On exit, if EQUED = 'C' or 'B', C contains the column scaling
!>     factors that were applied to matrix A.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>     On entry, the N-by-NRHS matrix of right hand side vectors, B.
!>
!>     If FACT = 'E' and TRANS = 'N', B is overwritten by
!>     diag(R)*B.
!>     If FACT = 'E' and TRANS = 'T' or 'C', B is overwritten by
!>     diag(C)*B.
!>
!>     On exit, B is overwritten by the solution vectors, X.
!>

LDB

!>          LDB is INTEGER
!>     The leading dimension of the array B. LDB >= max(1,N).
!>

X

!>          X is DOUBLE PRECISION array, dimension (LDX,NRHS)
!>     On exit, X contains the N-by-NRHS solution matrix X to the
!>     original system. Note that B is not restored on exit.
!>

LDX

!>          LDX is INTEGER
!>     The leading dimension of the array X. LDX >= max(1,N).
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>     On exit, RCOND is the reciprocal condition number of the matrix A
!>     after equilibration. If RCOND is near zero, the matrix is singular
!>     or very ill-conditioned.
!>

RPVGRW

!>          RPVGRW is DOUBLE PRECISION
!>     The relative forward error, RPVGRW = U(1)/U(N), computed during
!>     iterative refinement. This is returned only when EQUED = 'N'
!>     and no iterative refinement is performed.
!>

BERR

!>          BERR is DOUBLE PRECISION array, dimension (NRHS)
!>     On exit, BERR(j) contains the componentwise relative backward
!>     error computed for the solution X(:,j) using RPVGRW, and the
!>     residual vector.
!>

N_ERR_BNDS

!>          N_ERR_BNDS is INTEGER
!>     The number of error bounds computed for each right hand side.
!>     If PARAMS(LA_LINRX_ERROR_I) = 0, then N_ERR_BNDS = 1.
!>     If PARAMS(LA_LINRX_ERROR_I) = 1, then N_ERR_BNDS = 2.
!>

ERR_BNDS_NORM

!>          ERR_BNDS_NORM is DOUBLE PRECISION array, dimension
!>          (NRHS, *), where the second dimension is N_ERR_BNDS.
!>     On exit, ERR_BNDS_NORM(j,k) contains an upper bound for the
!>     normwise relative error in the solution vectors X(j).
!>     ERR_BNDS_NORM(j,1) is the normwise relative error bound, and
!>     ERR_BNDS_NORM(j,2) is the normwise relative error of the
!>     solution computed by iterative refinement.
!>

ERR_BNDS_COMP

!>          ERR_BNDS_COMP is DOUBLE PRECISION array, dimension
!>          (NRHS, *), where the second dimension is N_ERR_BNDS.
!>     On exit, ERR_BNDS_COMP(j,k) contains an upper bound for the
!>     componentwise relative error in the solution vectors X(j).
!>     ERR_BNDS_COMP(j,1) is the componentwise relative error bound, and
!>     ERR_BNDS_COMP(j,2) is the componentwise relative error of the
!>     solution computed by iterative refinement.
!>

NPARAMS

!>          NPARAMS is INTEGER
!>     The number of parameters in the PARAMS array. If NPARAMS = 0,
!>     the PARAMS array is not used.
!>

PARAMS

!>          PARAMS is DOUBLE PRECISION array, dimension (NPARAMS)
!>     Optional parameters. If NPARAMS > 0, the following parameters
!>     can be set:
!>
!>     PARAMS(LA_LINRX_ITREF_I) : INTEGER
!>       = 0: iterative refinement is disabled.
!>       = 1: iterative refinement is enabled (default).
!>
!>     PARAMS(LA_LINRX_ERROR_I) : INTEGER
!>       = 0: error bounds are not computed.
!>       = 1: error bounds are computed (default).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(N,NRHS,2))
!>     Workspace array. On exit, WORK(1) contains the minimum value of
!>     R and C(j) and WORK(2) contains the maximum value of R and C(j)
!>     if equilibration is performed.
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>     Workspace array.
!>

INFO

!>          INFO is INTEGER
!>     = 0: successful exit
!>     < 0: if INFO = -i, the i-th argument had an illegal value.
!>     > 0: if INFO = i, and i <= N, then U(i,i) is exactly zero.  The
!>          factorization has been completed, but the matrix is
!>          singular.
!>        if INFO = i, and i > N, then the routine was unable to
!>          recover from running into a zero diagonal element,
!>          and may have failed to converge or produced inaccurate
!>          results.
!>
