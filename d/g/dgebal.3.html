وثائق الوظيفة/الإجراء الفرعي

subroutine dgebal (character job, integer n, double precision, dimension( lda, * ) a, integer lda, integer ilo, integer ihi, double precision, dimension( * ) scale, integer info)

DGEBAL

الغرض:

!>
!> DGEBAL توازن مصفوفة عامة حقيقية A. يتضمن ذلك، أولاً،
!> إعادة ترتيب A عبر تحويل تشابه لعزل القيم الذاتية
!> في العناصر من 1 إلى ILO-1 والأخيرة من IHI+1 إلى N على
!> القطر؛ وثانياً، تطبيق تحويل تشابه قطري
!> للصفوف والأعمدة ILO إلى IHI لجعل الصفوف والأعمدة
!> متقاربة في المعيار قدر الإمكان. كلا الخطوتين اختياريتان.
!>
!> قد يقلل التوازن من معيار 1 للمصفوفة، ويحسن
!> دقة القيم الذاتية و/أو المتجهات الذاتية المحسوبة.
!>

المعلمات

JOB 
!>          JOB is CHARACTER*1
!>          تحدد العمليات التي سيتم إجراؤها على A:
!>          = 'N':  لا شيء: ببساطة قم بتعيين ILO = 1، IHI = N، SCALE(I) = 1.0
!>                  لـ i = 1,...,N؛
!>          = 'P':  إعادة ترتيب فقط؛
!>          = 'S':  تحجيم فقط؛
!>          = 'B':  كلاهما، إعادة ترتيب وتحجيم.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          عند الإدخال، المصفوفة المدخلة A.
!>          عند الخروج، يتم استبدال A بالمصفوفة المتوازنة.
!>          إذا كان JOB = 'N'، لا يتم الرجوع إلى A.
!>          انظر التفاصيل الإضافية.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

ILO

!>          ILO is INTEGER
!>

IHI

!>          IHI is INTEGER
!>          يتم تعيين ILO و IHI إلى أعداد صحيحة بحيث عند الخروج
!>          A(i,j) = 0 إذا كان i > j وكان j = 1,...,ILO-1 أو i = IHI+1,...,N.
!>          إذا كان JOB = 'N' أو 'S'، فإن ILO = 1 و IHI = N.
!>

SCALE

!>          SCALE is DOUBLE PRECISION array, dimension (N)
!>          تفاصيل عمليات إعادة الترتيب وعوامل التحجيم المطبقة على
!>          A.  إذا كان P(j) هو فهرس الصف والعمود المتبادلة
!>          مع الصف والعمود j وكان D(j) هو عامل التحجيم
!>          المطبق على الصف والعمود j، فإن
!>          SCALE(j) = P(j)    لـ j = 1,...,ILO-1
!>                   = D(j)    لـ j = ILO,...,IHI
!>                   = P(j)    لـ j = IHI+1,...,N.
!>          ترتيب حدوث المبادلات هو N إلى IHI+1،
!>          ثم 1 إلى ILO-1.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  انتهاء ناجح.
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية.
!>

التفاصيل الإضافية:

!>
!>  تتكون عمليات إعادة الترتيب من مبادلات الصفوف والأعمدة التي تضع
!>  المصفوفة في الشكل
!>
!>             ( T1   X   Y  )
!>     P A P = (  0   B   Z  )
!>             (  0   0   T2 )
!>
!>  حيث T1 و T2 مصفوفتان مثلثيتان علويتان تقع قيمهما الذاتية
!>  على القطر.  علامات مؤشرات الأعمدة ILO و IHI بداية
!>  ونهاية الأعمدة للمصفوفة الفرعية B. يتكون التوازن من تطبيق
!>  تحويل تشابه قطري inv(D) * B * D لجعل
!>  معايير 1 لكل صف من B وعموده المقابل متساوية تقريبًا.
!>  المصفوفة الناتجة هي
!>
!>     ( T1     X*D          Y    )
!>     (  0  inv(D)*B*D  inv(D)*Z ).
!>     (  0      0           T2   )
!>
!>  يتم إرجاع معلومات حول عمليات إعادة الترتيب P والمصفوفة القطرية D
!>  في المتجه SCALE.
!>
!>  هذا الإجراء الفرعي يعتمد على إجراء EISPACK BALANC.
!>
!>  تم تعديله بواسطة Tzu-Yi Chen، قسم علوم الحاسوب، جامعة
!>    كاليفورنيا في بيركلي، الولايات المتحدة الأمريكية
!>
!>  تمت إعادة هيكلته بواسطة Evert Provoost، قسم علوم الحاسوب،
!>    KU Leuven، بلجيكا
!>
