توثيق الوظيفة/الإجراء الفرعي

subroutine dgecon (character norm, integer n, double precision, dimension( lda, * ) a, integer lda, double precision anorm, double precision rcond, double precision, dimension( * ) work, integer, dimension( * ) iwork, integer info)

DGECON

الغرض:

!>
!> DGECON تقدر مقلوب رقم الشرط لمصفوفة حقيقية عامة A، سواء في المعيار 1-norm أو
!> المعيار اللانهائي infinity-norm، باستخدام التحلل LU الذي تم حسابه بواسطة DGETRF.
!>
!> يتم الحصول على تقدير لـ norm(inv(A))، ويتم حساب مقلوب رقم الشرط على أنه
!>    RCOND = 1 / ( norm(A) * norm(inv(A)) ).
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد ما إذا كان رقم الشرط 1-norm أو infinity-norm مطلوبًا:
!>          = '1' or 'O':  1-norm;
!>          = 'I':         Infinity-norm.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          العوامل L و U من التحلل A = P*L*U
!>          كما تم حسابها بواسطة DGETRF.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(1,N).
!>

ANORM

!>          ANORM is DOUBLE PRECISION
!>          إذا كان NORM = '1' أو 'O'، فإن المعيار 1-norm للمصفوفة الأصلية A.
!>          إذا كان NORM = 'I'، فإن المعيار اللانهائي infinity-norm للمصفوفة الأصلية A.
!>

RCOND

!>          RCOND is DOUBLE PRECISION
!>          مقلوب رقم شرط المصفوفة A،
!>          يتم حسابه على النحو التالي RCOND = 1/(norm(A) * norm(inv(A))).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (4*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  نجاح الخروج
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت قيمة غير قانونية.
!>                الأرقام غير العددية (NaNs) هي قيم غير قانونية لـ ANORM، وهي تنتشر إلى
!>                المعلمة المخرجة RCOND.
!>                اللانهاية (Infinity) غير قانونية لـ ANORM، وهي تنتشر إلى المخرجات
!>                المعلمة RCOND كـ 0.
!>          = 1:  إذا كان RCOND = NaN، أو
!>                   RCOND = Inf، أو
!>                   المعيار المحسوب لمقلوب A هو 0.
!>                في الحالة الأخيرة، يتم إرجاع RCOND = 0.
!>
