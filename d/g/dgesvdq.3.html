NAME

dgesvdq - computes the singular value decomposition (SVD) of a real general m-by-n matrix A

SYNOPSIS

SUBROUTINE DGESVDQ(JOBA, JOBV, JOBP, JOBR, M, N, A, LDA, S, U, LDU, V, LDV,
                   IWORK, LIWORK, WORK, LWORK, RWORK, LRWORK, INFO)

Where:

CHARACTER(1) JOBA, JOBV, JOBP, JOBR
INTEGER M, N, LDA, LDU, LDV, LIWORK, LWORK, LRWORK, INFO
REAL(8) A(LDA,*), S(*), U(LDU,*), V(LDV,*), WORK(*)
REAL(8) RWORK(*)

Function/Subroutine Documentation

This subroutine computes the singular value decomposition (SVD) of a real m-by-n matrix A, A = U * S * V^T. The routine uses a QR factorization with column pivoting to determine the effective rank of A, and then applies a QR SVD algorithm to compute the SVD accurately.

Arguments:

JOBA

CHARACTER*1. Specifies the computation of the scaled condition estimate. See Details.

  • 'E': Estimate the condition number of the column scaled matrix.

  • 'N': No scaled condition estimate.

Default: 'N'.

JOBV

CHARACTER*1. Specifies the computation of V.

  • 'A': The full m-by-n matrix V is computed.

  • 'N': The array V is not used.

  • 'S': The first min(m,n) columns of V, containing the right singular vectors, are computed.

  • 'U': The first min(m,n) columns of V, containing the right singular vectors, are computed.

Default: 'V'.

JOBP

CHARACTER*1. Specifies whether to use column pivoting.

  • 'N': No column pivoting is performed.

  • 'P': Column pivoting is performed. The rank revealing QR factorization is used.

Default: 'P'.

JOBR

CHARACTER*1. Specifies the computation of the full SVD.

  • 'N': No further computations are performed after computing the SVD of the upper trapezoidal factor R.

  • 'T': The full SVD is computed.

Default: 'N'.

M

INTEGER. Number of rows of the matrix A.

N

INTEGER. Number of columns of the matrix A.

A

DOUBLE PRECISION array, dimension (LDA,N). On entry, the m-by-n matrix A.

LDA

INTEGER. Leading dimension of the array A.

S

DOUBLE PRECISION array, dimension (min(M,N)). On exit, the singular values of A, sorted in descending order.

U

DOUBLE PRECISION array, dimension (LDU,K). K = M if JOBU = 'A'; K = min(M,N) if JOBU = 'S', 'U', or 'R'. On exit, U contains the left singular vectors.

LDU

INTEGER. Leading dimension of the array U.

V

DOUBLE PRECISION array, dimension (LDV,K). K = N if JOBV = 'A'; K = min(M,N) if JOBV = 'S', 'U', or 'R'. On exit, V contains the right singular vectors.

LDV

INTEGER. Leading dimension of the array V.

NUMRANK

INTEGER. NUMRANK is the numerical rank first determined after the rank revealing QR factorization, following the strategy specified by the value of JOBA. If JOBV = 'R' and JOBU = 'R', only NUMRANK leading singular values and vectors are then requested in the call of DGESVD. The final value of NUMRANK might be further reduced if some singular values are computed as zeros.

IWORK

INTEGER array, dimension (max(1, LIWORK)). On exit, IWORK(1:N) contains column pivoting permutation of the rank revealing QR factorization. If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence of row swaps used in row pivoting. These can be used to restore the left singular vectors in the case JOBU = 'F'. If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0, IWORK(1) returns the minimal LIWORK.

LIWORK

INTEGER. The dimension of the array IWORK. LIWORK >= N + M - 1, if JOBP = 'P' and JOBA .NE. 'E'; LIWORK >= N if JOBP = 'N' and JOBA .NE. 'E'; LIWORK >= N + M - 1 + N, if JOBP = 'P' and JOBA = 'E'; LIWORK >= N + N if JOBP = 'N' and JOBA = 'E'. If LIWORK = -1, then a workspace query is assumed; the routine only calculates and returns the optimal and minimal sizes for the WORK, IWORK, and RWORK arrays, and no error message related to LWORK is issued by XERBLA.

WORK

DOUBLE PRECISION array, dimension (max(2, LWORK)), used as a workspace. On exit, if, on entry, LWORK.NE.-1, WORK(1:N) contains parameters needed to recover the Q factor from the QR factorization computed by DGEQP3. If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0, WORK(1) returns the optimal LWORK, and WORK(2) returns the minimal LWORK.

LWORK

INTEGER. The dimension of the array WORK. It is determined as follows: Let LWQP3 = 3*N+1, LWCON = 3*N, and let LWORQ = { MAX( N, 1 ), if JOBU = 'R', 'S', or 'U' { MAX( M, 1 ), if JOBU = 'A' LWSVD = MAX( 5*N, 1 ) LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 5*(N/2), 1 ), LWORLQ = MAX( N, 1 ), LWQRF = MAX( N/2, 1 ), LWORQ2 = MAX( N, 1 ) Then the minimal value of LWORK is: = MAX( N + LWQP3, LWSVD ) if only the singular values are needed; = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed, and a scaled condition estimate requested; = N + MAX( LWQP3, LWSVD, LWORQ ) if the singular values and the left singular vectors are requested; = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the singular values and the left singular vectors are requested, and also a scaled condition estimate requested; = N + MAX( LWQP3, LWSVD ) if the singular values and the right singular vectors are requested; = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right singular vectors are requested, and also a scaled condition etimate requested; = N + MAX( LWQP3, LWSVD, LWORQ ) if the full SVD is requested with JOBV = 'R'; independent of JOBR; = N + MAX( LWQP3, LWCON, LWSVD, LWORQ ) if the full SVD is requested, JOBV = 'R' and, also a scaled condition estimate requested; independent of JOBR; = MAX( N + MAX( LWQP3, LWSVD, LWORQ ), N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ) ) if the full SVD is requested with JOBV = 'A' or 'V', and JOBR ='N' = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ), N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWORLQ, LWORQ ) ) if the full SVD is requested with JOBV = 'A' or 'V', and JOBR ='N', and also a scaled condition number estimate requested. = MAX( N + MAX( LWQP3, LWSVD, LWORQ ), N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the full SVD is requested with JOBV = 'A', 'V', and JOBR ='T' = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWORQ ), N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWORQ2, LWORQ ) ) if the full SVD is requested with JOBV = 'A' or 'V', and JOBR ='T', and also a scaled condition number estimate requested. Finally, LWORK must be at least two: LWORK = MAX( 2, LWORK ). If LWORK = -1, then a workspace query is assumed; the routine only calculates and returns the optimal and minimal sizes for the WORK, IWORK, and RWORK arrays, and no error message related to LWORK is issued by XERBLA.

RWORK

DOUBLE PRECISION array, dimension (max(1, LRWORK)). On exit, 1. If JOBA = 'E', RWORK(1) contains an estimate of the condition number of the column scaled A. If A = C * D where D is diagonal and C has unit columns in the Euclidean norm, then, assuming full column rank, N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1). Otherwise, RWORK(1) = -1. 2. RWORK(2) contains the number of singular values computed as exact zeros in DGESVD applied to the upper triangular or trapezoidal R (from the initial QR factorization). In case of early exit (no call to DGESVD, such as in the case of zero matrix) RWORK(2) = -1. If LIWORK, LWORK, or LRWORK = -1, then on exit, if INFO = 0, RWORK(1) returns the minimal LRWORK.

LRWORK

INTEGER. The dimension of the array RWORK. If JOBP ='P', then LRWORK >= MAX(2, M). Otherwise, LRWORK >= 2 If LRWORK = -1, then a workspace query is assumed; the routine only calculates and returns the optimal and minimal sizes for the WORK, IWORK, and RWORK arrays, and no error message related to LWORK is issued by XERBLA.

INFO

INTEGER. = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if DBDSQR did not converge, INFO specifies how many superdiagonals of an intermediate bidiagonal form B (computed in DGESVD) did not converge to zero.

Further Details:

1. The data movement (matrix transpose) is coded using simple nested
DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
Those DO-loops are easily identified in this source code - by the CONTINUE
statements labeled with 11**. In an optimized version of this code, the
nested DO loops should be replaced with calls to an optimized subroutine.
2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
column norm overflow. This is the minial precaution and it is left to the
SVD routine (CGESVD) to do its own preemptive scaling if potential over-
or underflows are detected. To avoid repeated scanning of the array A,
an optimal implementation would do all necessary scaling before calling
CGESVD and the scaling in CGESVD can be switched off.
3. Other comments related to code optimization are given in comments in the
code, enclosed in [[double brackets]].
