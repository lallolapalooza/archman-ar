dcb-dcbx(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

DCB-DCBX(8) Linux DCB-DCBX(8)

الاسم

dcb-dcbx - عرض / معالجة DCBX (بروتوكول تبادل جسور مراكز البيانات)

الموجز


dcb [ خيارات ] dcbx { أمر | مساعدة }

dcb dcbx show dev DEV

dcb dcbx set dev DEV [ host ] [ lld-managed ] [ cee ] [ ieee ] [ static ]

الوصف

بروتوكول تبادل جسور مراكز البيانات (DCBX) هو بروتوكول تستخدمه أجهزة DCB لتبادل معلومات التكوين مع الأجهزة المتصلة مباشرة. كائن DCBX في Linux هو حقل بت مكون من بايت واحد من العلامات التي تقوم بتكوين ما إذا كان DCBX مطبقًا في الجهاز أو في المضيف، وأي إصدار من البروتوكول يجب استخدامه. يستخدم dcb dcbx للوصول إلى كائن DCBX الخاص بالمنفذ في Linux.

هناك وضعان رئيسيان للتشغيل: في وضع host، يتم تطبيق بروتوكول DCBX بواسطة وكيل LLDP المضيف، وتستخدم واجهات DCB لنشر المعلمات المتفاوض عليها للأجهزة القادرة. في وضع lld-managed، تتم معالجة التكوين بواسطة الجهاز، وتستخدم واجهات DCB لفحص المعلمات المتفاوض عليها، ويمكن أيضًا استخدامها لتعيين المعلمات الأولية.

المعلمات

عند استخدامه مع dcb dcbx set، فإن الكلمات الرئيسية التالية تمكن التكوين المقابل. تعتبر الكلمات الرئيسية التي لم يتم ذكرها في سطر الأوامر معطلة. عند استخدامه مع show، يتم عرض كل ميزة ممكّنة بواسطة الكلمة الرئيسية المقابلة.

host
lld-managed
يكون الجهاز في وضع تشغيل المضيف، وعلى التوالي، وضع تشغيل lld-managed، كما هو موضح أعلاه. من حيث المبدأ، هاتان الكلمتان الرئيسيتان متعارضتان، ولكن dcb dcbx يسمح بتعيين كليهما ويترك المشغل يتعامل معه حسب الاقتضاء.
cee
ieee
يدعم الجهاز CEE (Converged Enhanced Ethernet) وعلى التوالي، إصدار IEEE من مواصفات DCB. عادةً ما يتم تعيين واحدة فقط من هذه، ولكن dcb dcbx لا يفرض ذلك.
static
يشير إلى أن المحرك يدعم التكوين الثابت. لا يتم إجراء أي تفاوض فعلي، والمعلمات المتفاوض عليها هي دائمًا التكوين الأولي.

مثال والاستخدام

وضع محرك DCB في وضع التشغيل "host"، واستخدام واجهات DCB القياسية IEEE:

# dcb dcbx set dev eth0 host ieee

عرض ما تم تعيينه:

# dcb dcbx show dev eth0
host ieee
