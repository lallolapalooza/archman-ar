توثيق الوظيفة/الروتين الفرعي

subroutine dtptrs (character uplo, character trans, character diag, integer n, integer nrhs, double precision, dimension( * ) ap, double precision, dimension( ldb, * ) b, integer ldb, integer info)

DTPTRS

الغرض:

!>
!> DTPTRS يحل نظامًا مثلثيًا بالشكل:
!>
!>    A * X = B  أو  A**T * X = B،
!>
!> حيث A هي مصفوفة مثلثية من الرتبة N مخزنة بتنسيق مضغوط، و B هي مصفوفة N-by-NRHS.
!>
!> هذا الروتين الفرعي يتحقق من أن A غير مفردة، ولكن يجب على المستدعين ملاحظة أن التفرد التام فقط هو الذي يتم اكتشافه. من الممكن أن تكون عناصر قطرية واحدة أو أكثر من A أرقامًا صغيرة جدًا دون أن يشير هذا الروتين الفرعي إلى خطأ.
!>
!> إذا كان فقدان الدقة العددية بسبب المصفوفات القريبة من التفرد يمثل مصدر قلق، فيجب على المستدعي التحقق من أن A غير مفردة ضمن بعض التفاوت قبل استدعاء هذا الروتين الفرعي.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  A is upper triangular; (A مثلثية علوية)
!>          = 'L':  A is lower triangular. (A مثلثية سفلية)
!>

TRANS

!>          TRANS is CHARACTER*1
!>          Specifies the form of the system of equations: (يحدد شكل نظام المعادلات)
!>          = 'N':  A * X = B  (No transpose) (بدون تبديل)
!>          = 'T':  A**T * X = B  (Transpose) (تبديل)
!>          = 'C':  A**H * X = B  (Conjugate transpose = Transpose) (تبديل مرافق = تبديل)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          = 'N':  A is non-unit triangular; (A مثلثية غير أحادية)
!>          = 'U':  A is unit triangular. (A مثلثية أحادية)
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0. (رتبة المصفوفة A. N >= 0.)
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrix B.  NRHS >= 0. (عدد الأطراف اليمنى، أي عدد أعمدة المصفوفة B. NRHS >= 0.)
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          The upper or lower triangular matrix A, packed columnwise in
!>          a linear array.  The j-th column of A is stored in the array
!>          AP as follows: (المصفوفة A المثلثية العلوية أو السفلية، مضغوطة عمودياً في
!>          مصفوفة خطية. يتم تخزين العمود j من A في المصفوفة
!>          AP على النحو التالي:)
!>          if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;
!>          if UPLO = 'L', AP(i + (j-1)*(2*n-j)/2) = A(i,j) for j<=i<=n.
!>

B

!>          B is DOUBLE PRECISION array, dimension (LDB,NRHS)
!>          On entry, the right hand side matrix B. (عند الدخول، مصفوفة الطرف الأيمن B.)
!>          On exit, if INFO = 0, the solution matrix X. (عند الخروج، إذا كانت INFO = 0، مصفوفة الحل X.)
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,N). (البعد الرائد للمصفوفة B. LDB >= max(1,N).)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit (خروج ناجح)
!>          < 0:  if INFO = -i, the i-th argument had an illegal value (إذا كانت INFO = -i، فإن المعامل i كان له قيمة غير قانونية)
!>          > 0:  if INFO = i, the i-th diagonal element of A is exactly zero,
!>                indicating that the matrix is singular and the
!>                solutions X have not been computed. (إذا كانت INFO = i، فإن العنصر القطري i للمصفوفة A يساوي صفرًا بالضبط،
!>                مما يشير إلى أن المصفوفة مفردة وأن
!>                حلول X لم يتم حسابها.)
!>
