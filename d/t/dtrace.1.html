dtrace(1)

الحزمة: systemtap

التراخيص: GPL-2.0-or-later

DTRACE(1) دليل الأوامر العام DTRACE(1)

الاسم

dtrace - أداة إنشاء مسبار ثابت لتطبيق المستخدم متوافق مع Dtrace.

الملخص

dtrace -s ملف [خيارات]

الوصف

يقوم الأمر dtrace بتحويل وصف المسبار المحدد في file.d إلى ملف رأس مسبار عبر الخيار -h أو ملف وصف مسبار عبر الخيار -G.

الخيارات

-h
إنشاء ملف رأس systemtap.
-G
إنشاء ملف كائن وصف مسبار systemtap. يستدعي هذا مترجم C بمجموعة معقولة من خيارات المترجم. إذا كنت بحاجة إلى إضافة المزيد، فسيتم نسخ الخيارات الموجودة في متغير البيئة CFLAGS إلى المترجم. إذا لم يكن هذا كافيًا، استخدم الخيار -k لالتقاط ملف C الذي تم إنشاؤه وقم بالترجمة حسب الحاجة.
-o ملف
هو اسم ملف الإخراج. إذا تم إعطاء الخيار -G فسيكون اسم ملف الإخراج file.o؛ إذا تم إعطاء الخيار -h فسيكون اسم ملف الإخراج file.h.
-C
تشغيل معالج C المسبق (cpp) على ملف الإدخال عند إعطاء الخيار -h.
-I ملف
إعطاء مسار التضمين هذا لـ cpp عند إعطاء الخيار -C.
-k
الاحتفاظ بالملفات المؤقتة، على سبيل المثال مصدر لغة C للخيار -G.

أمثلة

systemtap متوافق مع المصدر مع دعم مسبار تطبيق المستخدم الثابت لـ dtrace. نظرًا لملف test.d الذي يحتوي على:

provider sdt_probes 
{
  probe test_0 (int type);
  probe test_1 (struct astruct node);
};
struct astruct {int a; int b;};

ثم الأمر "dtrace -s test.d -G" سينشئ ملف وصف المسبار test.o والأمر "dtrace -stest.d -h" سينشئ ملف رأس المسبار test.h بعد ذلك يمكن للتطبيق استخدام وحدات الماكرو التي تم إنشاؤها بهذه الطريقة:

#include "test.h"
 ...
struct astruct s;
 ...
SDT_PROBES_TEST_0(value);
 ...
if (SDT_PROBES_TEST_1_ENABLED())
    SDT_PROBES_TEST_1(expensive_function(s));

سيمافورات

السيمافورات هي متغيرات علامة تستخدمها المسابير كوسيلة لتجاوز المعالجة المكلفة المحتملة لإعداد الوسيطات للمسابير التي قد لا تكون نشطة. يتم تعيينها / مسحها تلقائيًا بواسطة systemtap عند تشغيل نص برمجي ذي صلة، لذلك يتم دفع تكلفة إعداد الوسيطات فقط عند الضرورة. يتم تعريف متغيرات السيمافور هذه داخل ملف الكائن "test.o"، والذي يجب بعد ذلك ربطه بتطبيق.

في بعض الأحيان، لا تكون متغيرات السيمافور ضرورية ولا مفيدة. تخطيها يمكن أن يبسط عملية البناء، عن طريق تخطي ملف "test.o" الإضافي. لتخطي الاعتماد على متغيرات السيمافور، قم بتضمين "<sys/sdt.h>" داخل التطبيق قبل "test.h":

#include <sys/sdt.h>
#include "test.h"
 ...
struct astruct s;
 ...
SDT_PROBES_TEST_0(value);
 ...
if (SDT_PROBES_TEST_1_ENABLED())
   SDT_PROBES_TEST_1(cheap_function(s));

في هذا الوضع، يكون اختبار ENABLED() ثابتًا عند 1.
