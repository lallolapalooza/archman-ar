الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-container-top - عرض العمليات قيد التشغيل لحاوية

ملخص

docker container top CONTAINER [ps OPTIONS]

الوصف

عرض العمليات قيد التشغيل للحاوية. يمكن أن يكون ps-OPTION أيًا من الخيارات التي تمررها إلى أمر ps في Linux.

جميع المعلومات المعروضة هي من وجهة نظر المضيف.

أمثلة

تشغيل docker container top مع خيار ps الخاص بـ -x:

$ docker container top 8601afda2b -x
PID      TTY       STAT       TIME         COMMAND
16623    ?         Ss         0:00         sleep 99999
