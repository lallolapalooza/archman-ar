docker-start(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-start - بدء حاوية واحدة أو أكثر متوقفة

الموجز

docker start [OPTIONS] CONTAINER [CONTAINER...]

الوصف

اختصار لـ docker container start.

خيارات

-a, --attach[=false] ربط STDOUT/STDERR وتمرير الإشارات

--checkpoint="" الاستعادة من نقطة التحقق هذه

--checkpoint-dir="" استخدام دليل تخزين مخصص لنقطة التحقق

--detach-keys="" تجاوز تسلسل المفاتيح لفصل حاوية

-i, --interactive[=false] ربط STDIN للحاوية
