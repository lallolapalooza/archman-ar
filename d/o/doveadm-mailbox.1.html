NAME

doveadm-mailbox - mailbox management

SYNOPSIS

doveadm [GLOBAL OPTIONS] mailbox

doveadm [GLOBAL OPTIONS] mailbox delete [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [--expunge] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox destroy [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox create [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox rename [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] old-mailbox new-mailbox

doveadm [GLOBAL OPTIONS] mailbox copy [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] source-mailbox dest-mailbox

doveadm [GLOBAL OPTIONS] mailbox move [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] source-mailbox dest-mailbox

doveadm [GLOBAL OPTIONS] mailbox search [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-T] [-q] [-n] [--] search query

doveadm [GLOBAL OPTIONS] mailbox list [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-q] [-s] [-B] [-E] [-F format] [pattern] ...

doveadm [GLOBAL OPTIONS] mailbox status [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [-q] [-B] [-E] [-F format] field ...

doveadm [GLOBAL OPTIONS] mailbox subscribe [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox unsubscribe [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox set [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [--uid-validity uid] [--next-uid uid] [--min-next-uid uid] [--min-first-recent-uid uid] [--min-highest-modseq seq] [--min-highest-pvt-modseq seq] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox cache purge [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox cache decision [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] [--all] [--fields list of fields] [--last-used unix timestamp] [--decision no|temp|yes] mailbox ...

doveadm [GLOBAL OPTIONS] mailbox cache remove [-A | -u user | -F file | --no-userdb-lookup] [-S socket_path] search query

DESCRIPTION

The doveadm mailbox command is used to manage mailboxes. It can perform operations like creating, deleting, renaming, copying, moving, listing, and displaying status information about mailboxes.

mailbox delete

Delete the specified mailbox(es). Mailbox is first renamed to a temporary name, then deleted. If the mailbox contains any mail, it will be moved to the trash folder (if configured) before deletion.

If --expunge is used, all messages in the mailbox are expunged before the mailbox is deleted. This is useful if you want to free up disk space.

mailbox destroy

Destroy the specified mailbox(es). This command permanently removes the mailbox and all its contents. Use with extreme caution.

mailbox create

Create the specified mailbox(es).

mailbox rename

Rename the specified mailbox from old-mailbox to new-mailbox.

mailbox copy

Copy the contents of source-mailbox to dest-mailbox.

mailbox move

Move the contents of source-mailbox to dest-mailbox.

mailbox search

Search for messages in the specified mailbox(es) using the given search query. See doveadm-search-query(7) for the search query syntax.

-T: Print the UIDs of the matching messages.

-q: Print the raw message data.

-n: Use numeric IDs instead of names.

mailbox list

List mailboxes matching the given pattern(s). The pattern is a standard shell glob pattern.

-q: Print only the mailbox names.

-s: List subscribed mailboxes only.

-B: List all mailboxes, including non-subscribed ones.

-E: List only empty mailboxes.

-F format: Use the specified format string for output. See doveadm-format(7) for supported fields.

mailbox status

Display status information for the specified mailbox(es). The available fields are:

messages: Number of messages in the mailbox.

bytes: Total size of messages in the mailbox (in bytes).

uidvalidity: The UIDVALIDITY value of the mailbox.

uidnext: The next UID to be assigned to a new message.

uidhighestmodseq: The highest modification sequence value assigned to any message in the mailbox.

junk: Number of messages marked as junk.

unread: Number of unread messages.

recent: Number of recent messages.

firstrecentuid: The UID of the first recent message.

firstunseenuid: The UID of the first unseen message.

highestmodseq: The highest modification sequence value assigned to any message in the mailbox (including private metadata).

highestpvtmodseq: The highest private modification sequence value assigned to any message in the mailbox.

virtualsize: The total size of messages in the mailbox, including headers and attachments (in bytes).

deleted: Number of deleted messages.

seen: Number of seen messages.

all: All available fields.

-q: Print only the specified fields.

-B: Print status for all mailboxes.

-E: Print status for empty mailboxes only.

-F format: Use the specified format string for output. See doveadm-format(7) for supported fields.

mailbox subscribe

Subscribe the specified mailbox(es).

mailbox unsubscribe

Unsubscribe the specified mailbox(es).

mailbox set

This command is used to set UID validity, next UID, first recent UID and modification sequence values.

Usually this is only ever to be used during migration, or restoring mailbox after disaster. Settings these values is highly discouraged, and is not supported for all mail backends.

mailbox cache purge

Purge the dovecot.index.cache file. Most importantly this frees up disk space from mails that were already deleted. Normally there i no need to run this command manually, because the compression is also run automatically.

mailbox cache decision

This command is used to list or change caching decisions for field(s) in mailbox(es). You can list decisions by leaving out decision and last-used parameters.

--all

List or change all fields.

--fields

List or change these comma/space separated fields.

--decision

Set field caching decision. Yes means it's always cached. Temp means it's provisionally cached. No means the field is not cached.

--last-used

Set field's last used timestamp.

NOTE: This command cannot be used to add new fields to cache! You need to first add them to configuration. Setting caching to no will not immediately drop field from cache, it will stop adding the field to cache.

mailbox cache remove

Remove any matching mail(s) from cache.

WARNING! This command can erase ALL cached data, causing system slowness.

See doveadm-search-query(7) for the search query syntax.

EXAMPLE

List subscribed mailboxes, beginning with 'dovecot', of user bob:

doveadm mailbox list -s -u bob dovecot\*
dovecot
dovecot/pigeonhole
dovecot/pigeonhole/2.0

Now have a look at the status of user bob's dovecot mailboxes:

doveadm -f table mailbox status -u bob "messages vsize" dovecot\*
mailbox                                    messages vsize
dovecot                                    20501    93968492
dovecot/pigeonhole                         0        0
dovecot/pigeonhole/2.0                     47       323474

Converting an internationalized mailbox name from mUTF-7 to UTF-8 and vice versa:

doveadm mailbox mutf7 -7 "~peter/mail/&U,BTFw-/&ZeVnLIqe-"
~peter/mail/台北/日本語
doveadm mailbox mutf7 ~peter/mail/台北/日本語
~peter/mail/&U,BTFw-/&ZeVnLIqe-
