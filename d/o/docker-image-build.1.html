docker-image-build(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم دوكر DOCKER(1)

الاسم

docker-image-build - بناء صورة من Dockerfile

الملخص

docker image build [خيارات] PATH | URL | -

الوصف

اسم مستعار لـ docker build.

الخيارات

--add-host= إضافة تعيين مخصص من مضيف إلى IP ("مضيف:ip")

--build-arg= تعيين متغيرات وقت البناء

--cache-from=[] صور يجب اعتبارها مصادر للذاكرة المؤقتة

--cgroup-parent="" تعيين cgroup الأب لتعليمات "RUN" أثناء البناء

--compress[=false] ضغط سياق البناء باستخدام gzip

--cpu-period=0 تحديد فترة جدولة CPU CFS (Completely Fair Scheduler)

--cpu-quota=0 تحديد حصة جدولة CPU CFS (Completely Fair Scheduler)

-c, --cpu-shares=0 مشاركات CPU (وزن نسبي)

--cpuset-cpus="" وحدات المعالجة المركزية التي يُسمح بالتنفيذ فيها (0-3، 0،1)

--cpuset-mems="" وحدات الذاكرة التي يُسمح بالتنفيذ فيها (0-3، 0،1)

-f, --file="" اسم Dockerfile (الافتراضي هو "PATH/Dockerfile")

--force-rm[=false] إزالة الحاويات الوسيطة دائمًا

--iidfile="" كتابة معرف الصورة إلى الملف

--isolation="" تقنية عزل الحاويات

--label= تعيين بيانات وصفية للصورة

-m, --memory=0 حد الذاكرة

--memory-swap=0 حد مبادلة الذاكرة يساوي الذاكرة والمبادلة: -1 لتمكين المبادلة غير المحدودة

--network="default" تعيين وضع الشبكة لتعليمات RUN أثناء البناء

--no-cache[=false] عدم استخدام الذاكرة المؤقتة عند بناء الصورة

--platform="" تعيين المنصة إذا كان الخادم قادرًا على العمل مع منصات متعددة

--pull[=false] محاولة سحب إصدار أحدث من الصورة دائمًا

-q, --quiet[=false] كبت مخرجات البناء وطباعة معرف الصورة عند النجاح

--rm[=true] إزالة الحاويات الوسيطة بعد بناء ناجح

--security-opt=[] خيارات الأمان

--shm-size=0 حجم "/dev/shm"

--squash[=false] ضغط الطبقات المبنية حديثًا في طبقة واحدة جديدة

-t, --tag= الاسم وعلامة اختيارية بتنسيق "name:tag"

--target="" تعيين مرحلة البناء المستهدفة المراد بنائها.

--ulimit=[] خيارات ulimit
