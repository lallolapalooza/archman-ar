docker-machine-inspect(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-machine-inspect(1) دليل الأوامر العامة podman-machine-inspect(1)

الاسم

podman-machine-inspect - فحص آلة افتراضية واحدة أو أكثر

الملخص

podman machine inspect [خيارات] [اسم] ...

الوصف

فحص آلة افتراضية واحدة أو أكثر

الحصول على تفاصيل أكبر حول الآلات الافتراضية لـ Podman. يمكن فحص أكثر من آلة افتراضية واحدة في نفس الوقت.

اسم الجهاز الافتراضي الافتراضي هو podman-machine-default. إذا لم يتم تحديد اسم الجهاز الافتراضي كوسيط، فسيتم فحص podman-machine-default.

للمستخدمين غير الجذر فقط.

الخيارات

--format

طباعة النتائج باستخدام قالب Go.

العنصر النائب الوصف
.ConfigDir ... موقع دليل تكوين الجهاز الافتراضي
.ConnectionInfo ... معلومات اتصال الجهاز الافتراضي
.Created ... وقت إنشاء الجهاز الافتراضي (سلسلة، ISO3601)
.LastUp ... وقت تشغيل الجهاز الافتراضي آخر مرة
.Name اسم الجهاز الافتراضي
.Resources ... الموارد المستخدمة بواسطة الجهاز الافتراضي
.Rootful ما إذا كان الجهاز الافتراضي يفضل تشغيل الحاويات الجذرية أو غير الجذرية
.Rosetta ما إذا كان هذا الجهاز الافتراضي يستخدم Rosetta
.SSHConfig ... معلومات تكوين SSH للتواصل مع الجهاز الافتراضي
.State حالة الجهاز الافتراضي
.UserModeNetworking ما إذا كان هذا الجهاز الافتراضي يستخدم شبكات وضع المستخدم

--help

طباعة بيان الاستخدام.

أمثلة

فحص جهاز Podman المحدد.

$ podman machine inspect podman-machine-default
[
     {
          "ConfigDir": {
               "Path": "/Users/jacksparrow/.config/containers/podman/machine/applehv"
          },
          "ConnectionInfo": {
               "PodmanSocket": {
                    "Path": "/var/folders/9r/n3056v597wv2cq8s2j80bdnw0000gn/T/podman/podman-machine-default-api.sock"
               },
               "PodmanPipe": null
          },
          "Created": "2025-02-11T14:12:48.231836+05:30",
          "LastUp": "2025-08-12T19:31:19.391294+05:30",
          "Name": "podman-machine-default",
          "Resources": {
               "CPUs": 6,
               "DiskSize": 100,
               "Memory": 6144,
               "USBs": []
          },
          "SSHConfig": {
               "IdentityPath": "/Users/jacksparrow/.local/share/containers/podman/machine/machine",
               "Port": 53298,
               "RemoteUsername": "core"
          },
          "State": "running",
          "UserModeNetworking": true,
          "Rootful": false,
          "Rosetta": true
     }
]

عرض اسم الجهاز الافتراضي وحالته:

$ podman machine inspect --format "{{.Name}}\t{{.State}}"
podman-machine-default running

عرض معلومات موارد الجهاز الافتراضي:

$ podman machine inspect --format "Machine: {{.Name}}\nCPUs: {{.Resources.CPUs}}\nMemory: {{.Resources.Memory}} bytes\nDisk: {{.Resources.DiskSize}} bytes"
Machine: podman-machine-default
CPUs: 6
Memory: 6144 bytes
Disk: 100 bytes

عرض تفاصيل تكوين الجهاز الافتراضي:

$ podman machine inspect --format "{{.Name}}: {{.State}} (Rootful: {{.Rootful}}, User Networking: {{.UserModeNetworking}})"
podman-machine-default: running (Rootful: false, User Networking: true)

عرض معلومات وقت تشغيل الجهاز الافتراضي:

$ podman machine inspect --format "Created: {{.Created}}\nLast Up: {{.LastUp}}\nState: {{.State}}"
Created: 2025-02-11 14:12:48.231836 +0000 UTC
Last Up: 2025-08-12 19:31:19.391294 +0000 UTC
State: running

عرض معلومات الاتصال:

$ podman machine inspect --format "Socket: {{.ConnectionInfo.PodmanSocket}}\nConfig Dir: {{.ConfigDir}}"
Socket: {/var/folders/9r/n3056v597wv2cq8s2j80bdnw0000gn/T/podman/podman-machine-default-api.sock <nil>}
Config Dir: {/Users/jacksparrow/.config/containers/podman/machine/applehv <nil>}
