NAME

\n

docker-volume-ls - List volumes

\n
\n
\n

SYNOPSIS

\n

docker volume ls [OPTIONS]

\n
\n
\n

DESCRIPTION

\n

Lists all the volumes Docker manages. You can filter using the\n -f or --filter flag. The filtering format is a\n key=value pair. To specify more than one filter, pass multiple flags\n (for example, --filter "foo=bar" --filter\n "bif=baz")

\n

The currently supported filters are:

\n
    \n
  • dangling (boolean - true or false, 1 or\n 0)
    • \n
  • driver (a volume driver's name)
    • \n
  • label (label=<key> or\n label=<key>=<value>)
    • \n
  • name (a volume's name)\n
    • \n
\n
\n
\n

OPTIONS

\n

--cluster[=false] \tDisplay only cluster volumes, and use\n cluster volume list formatting

\n

-f, --filter= \tProvide filter values (e.g.\n "dangling=true")

\n

--format="" \tFormat output using a custom\n template: 'table': Print output in table format with column headers\n (default) 'table TEMPLATE': Print output in table format using the given Go\n template 'json': Print in JSON format 'TEMPLATE': Print output using the\n given Go template. Refer to https://docs.docker.com/go/formatting/ for more\n information about formatting output with templates

\n

-q, --quiet[=false] \tOnly display volume names

\n
\n
\n

SEE ALSO

\n

docker-volume(1)

الاسم

\n

docker-volume-ls - سرد وحدات التخزين

\n
\n
\n

الملخص

\n

docker volume ls [OPTIONS]

\n
\n
\n

الوصف

\n

يسرد جميع وحدات التخزين التي يديرها Docker. يمكنك التصفية باستخدام\n العلم -f أو --filter. تنسيق التصفية هو زوج من المفتاح=القيمة.\n لتحديد أكثر من عامل تصفية، قم بتمرير أعلام متعددة (على سبيل المثال، --filter "foo=bar" --filter\n "bif=baz")

\n

عوامل التصفية المدعومة حاليًا هي:

\n
    \n
  • dangling (قيمة منطقية - true أو false، 1 أو\n 0)
    • \n
  • driver (اسم مشغل وحدة تخزين)
    • \n
  • label (label=<key> أو\n label=<key>=<value>)
    • \n
  • name (اسم وحدة تخزين)\n
    • \n
\n
\n
\n

خيارات

\n

--cluster[=false] \tعرض وحدات تخزين الكتلة فقط، واستخدام تنسيق سرد وحدات تخزين الكتلة

\n

-f, --filter= \tتوفير قيم التصفية (على سبيل المثال،\n "dangling=true")

\n

--format="" \tتنسيق الإخراج باستخدام قالب مخصص: 'table': طباعة الإخراج بتنسيق جدول مع رؤوس الأعمدة\n (افتراضي) 'table TEMPLATE': طباعة الإخراج بتنسيق جدول باستخدام قالب Go المحدد 'json': طباعة بتنسيق JSON 'TEMPLATE': طباعة الإخراج باستخدام قالب Go المحدد. ارجع إلى https://docs.docker.com/go/formatting/ لمزيد من المعلومات حول تنسيق الإخراج باستخدام القوالب

\n

-q, --quiet[=false] \tعرض أسماء وحدات التخزين فقط

\n
