docker-pod-stats(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-pod-stats(1) دليل الأوامر العامة podman-pod-stats(1)

الاسم

podman-pod-stats - عرض تدفق مباشر لاستخدام موارد الحاويات في بود أو أكثر

الملخص

podman pod stats [خيارات] [بود]

الوصف

عرض تدفق مباشر لإحصائيات استخدام موارد الحاويات في بود أو أكثر. التشغيل بدون صلاحيات الجذر (rootless) مدعوم فقط على cgroups v2.

الخيارات

--all, -a

إظهار جميع الحاويات. يتم عرض الحاويات قيد التشغيل فقط بشكل افتراضي.

--format=قالب

طباعة إحصائيات الحاويات بشكل جميل إلى JSON أو باستخدام قالب Go.

الرموز النائبة الصالحة لقالب Go مدرجة أدناه:

الرمز النائب الوصف
.BlockIO إدخال/إخراج الكتل (Block IO)
.CID معرف الحاوية (Container ID)
.CPU نسبة استخدام وحدة المعالجة المركزية (CPU percentage)
.Mem نسبة استخدام الذاكرة (Memory percentage)
.MemUsage استخدام الذاكرة (Memory usage)
.MemUsageBytes استخدام الذاكرة بالبايت (Memory usage in Bytes - IEC)
.Name اسم الحاوية (Container Name)
.NetIO إدخال/إخراج الشبكة (Network IO)
.PIDS عدد العمليات (Number of PIDs)
.Pod معرف البود (Pod ID)

عند استخدام قالب Go، قم بتسبق التنسيق بـ table لطباعة الرؤوس.

--latest, -l

بدلاً من تقديم اسم البود أو معرفه، استخدم آخر بود تم إنشاؤه. ملاحظة: قد يكون آخر بود تم تشغيله من مستخدمين آخرين لـ Podman على الجهاز المضيف. (هذا الخيار غير متاح مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2)).

--no-reset

لا تقم بمسح الشاشة/طرفية بين فترات الإبلاغ.

--no-stream

تعطيل بث إحصائيات البود وسحب النتيجة الأولى فقط. الإعداد الافتراضي هو false.

أمثلة

عرض إحصائيات حول جميع البودات بدون بث:

# podman pod stats -a --no-stream
ID             NAME              CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin    --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2
3b33001239ee   sleepy_stallman   --      -- / --             --      -- / --   -- / --    --

عرض إحصائيات حول بود محدد بدون بث:

# podman pod stats --no-stream a9f80
ID             NAME             CPU %   MEM USAGE / LIMIT   MEM %   NET IO    BLOCK IO   PIDS
a9f807ffaacd   frosty_hodgkin   --      3.092MB / 16.7GB    0.02%   -- / --   -- / --    2

عرض إحصائيات حول بود محدد بتنسيق JSON بدون بث:

# podman pod stats --no-stream --format=json a9f80
[
    {
        "id": "a9f807ffaacd",
        "name": "frosty_hodgkin",
        "cpu_percent": "--",
        "mem_usage": "3.092MB / 16.7GB",
        "mem_percent": "0.02%",
        "netio": "-- / --",
        "blocki": "-- / --",
        "pids": "2"
    }
]

عرض إحصائيات محددة بتنسيق جدول حول بود محدد:

# podman pod stats --no-stream --format "table {{.ID}} {{.Name}} {{.MemUsage}}" 6eae
ID             NAME           MEM USAGE / LIMIT
6eae9e25a564   clever_bassi   3.031MB / 16.7GB
