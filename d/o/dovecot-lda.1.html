الاسم

dovecot-lda - dovecot local delivery agent

الملخص

dovecot-lda [-d mailbox] [-m mailbox] [-f from_address] [-a alternate_address] [-r rcpt_address] [-s size_limit] [-u uid] [-g gid] [-k keep_alive] [-S shutdown_timeout] [-p pidfile] [-L] [-U] [-V] [--]

الوصف

The dovecot-lda is a local delivery agent that can deliver mail to a user's mailbox. It supports various delivery methods, including Maildir and mbox formats, and can integrate with Dovecot's authentication and user database mechanisms.

الخيارات

-d mailbox
Deliver to the specified mailbox.
-m mailbox
Same as -d.
-f from_address
The sender's email address.
-a alternate_address
An alternate recipient address.
-r rcpt_address
The recipient's email address.
-s size_limit
The maximum size of the message in bytes.
-u uid
The user ID of the recipient.
-g gid
The group ID of the recipient.
-k keep_alive
Keep the connection alive for the specified duration.
-S shutdown_timeout
The timeout for shutting down the agent.
-p pidfile
Specify a PID file.
-L
Log messages to syslog.
-U
Do not log messages.
-V
Verbose output.
--
End of options. Any subsequent arguments are treated as part of the mail.

أمثلة

# Deliver mail to user's INBOX
dovecot-lda -d INBOX

# Deliver mail with sender and recipient information
dovecot-lda -f sender@example.com -a user@example.com -r user@example.com

الملفات

There are no specific files mentioned in this section, but typical mail directories like Maildir or mbox are used.
