podman-machine-list(1) دليل الأوامر العامة podman-machine-list(1)

الاسم

podman-machine-list - سرد الآلات الافتراضية

الملخص

podman machine list [خيارات]

podman machine ls [خيارات]

الوصف

سرد الآلات الافتراضية التي تديرها Podman.

يتطلب Podman على MacOS و Windows آلة افتراضية. هذا لأن الحاويات هي Linux - لا تعمل الحاويات على أي نظام تشغيل آخر لأن الوظائف الأساسية للحاويات مرتبطة بنواة Linux. يجب استخدام podman machine لإدارة أجهزة MacOS و Windows، ولكن يمكن استخدامها اختياريًا على Linux.

بدون صلاحيات الجذر فقط.

ملاحظة: يتم إدارة ملف تكوين podman-machine تحت الدليل $XDG_CONFIG_HOME/containers/podman/machine/. قد يؤدي تغيير متغير البيئة $XDG_CONFIG_HOME أثناء تشغيل الآلات إلى سلوك غير متوقع. (انظر podman(1))

الخيارات

--all-providers

عرض الآلات من جميع المزودين

--format=format

تغيير تنسيق الإخراج الافتراضي. يمكن أن يكون هذا من نوع مدعوم مثل 'json' أو قالب Go. العناصر النائبة الصالحة لقالب Go مدرجة أدناه:

العنصر النائب الوصف
.CPUs عدد وحدات المعالجة المركزية
.Created الوقت منذ إنشاء الآلة الافتراضية
.Default هل هي الآلة الافتراضية الافتراضية
.DiskSize حجم القرص للآلة الافتراضية
.IdentityPath المسار إلى ملف الهوية ssh
.LastUp الوقت منذ آخر تشغيل للآلة الافتراضية
.Memory الذاكرة المخصصة للآلة الافتراضية
.Name اسم الآلة الافتراضية
.Port منفذ SSH للاستخدام للاتصال بالآلة الافتراضية
.RemoteUsername اسم مستخدم الآلة الافتراضية لـ Podman بدون صلاحيات الجذر
.Running هل الآلة الافتراضية قيد التشغيل
.Stream اسم التدفق
.Swap المبادلة المخصصة للآلة الافتراضية
.UserModeNetworking ما إذا كانت الآلة الافتراضية تستخدم شبكات وضع المستخدم
.VMType نوع الآلة الافتراضية

--help

طباعة بيان الاستخدام.

--noheading, -n

تخطي عناوين الجدول من القائمة.

--quiet, -q

طباعة اسم الآلة الافتراضية فقط. هذا يعني أيضًا عدم طباعة عنوان الجدول.

أمثلة

سرد جميع آلات Podman.

$ podman machine list
NAME                    VM TYPE     CREATED      LAST UP      CPUS        MEMORY      DISK SIZE
podman-machine-default  qemu        2 weeks ago  2 weeks ago  1           2.147GB     10.74GB

سرد جميع آلات Podman باستخدام تنسيق الجدول المحدد.

$ podman machine ls --format "table {{.Name}}\t{{.VMType}}\t{{.Created}}\t{{.LastUp}}"
NAME                    VM TYPE     CREATED      LAST UP
podman-machine-default  qemu        2 weeks ago  2 weeks ago

سرد جميع آلات Podman بتنسيق json.

$ podman machine ls --format json
[
    {
        "Name": "podman-machine-default",
        "Default": false,
        "Created": "2021-12-27T10:36:14.373347492-05:00",
        "Running": false,
        "LastUp": "2021-12-27T11:22:50.17333371-05:00",
        "Stream": "default",
        "VMType": "qemu",
        "CPUs": 1,
        "Memory": "2147483648",
        "DiskSize": "10737418240"
    }
]
