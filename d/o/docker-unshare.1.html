docker-unshare(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-unshare(1) دليل الأوامر العام podman-unshare(1)

الاسم

podman-unshare - تشغيل أمر داخل مساحة اسم مستخدم معدلة

الملخص

podman unshare [خيارات] [أمر]

الوصف

يطلق عملية (افتراضيًا، $SHELL) في مساحة اسم مستخدم جديدة. يتم تكوين مساحة اسم المستخدم بحيث يبدو أن معرف المستخدم (UID) ومعرف المجموعة الأساسي (GID) للمستخدم المستدعي هما المعرف 0، على التوالي. أي نطاقات تتطابق مع هذا المستخدم والمجموعة في /etc/subuid و /etc/subgid يتم تعيينها أيضًا على أنها خاصة بها بمساعدة أدوات المساعدة newuidmap(1) و newgidmap(1).

podman unshare مفيد لاستكشاف أخطاء العمليات غير المتميزة وإصلاحها ولإزالة تخزين البيانات والبيانات الأخرى المتعلقة بالصور والحاويات يدويًا.

إنه مفيد أيضًا لاستخدام أمر podman mount. إذا أراد مستخدم غير متميز تحميل حاوية والعمل معها، فإنه يحتاج إلى تنفيذ podman unshare. يفشل تنفيذ podman mount للمستخدمين غير المتميزين ما لم يكن المستخدم يعمل داخل جلسة podman unshare.

تحدد جلسة unshare متغيرين بيئيين:

  • CONTAINERS_GRAPHROOT: المسار إلى بيانات الحاوية الثابتة.
  • CONTAINERS_RUNROOT: المسار إلى بيانات الحاوية المتطايرة.

هام: هذا الأمر غير متوفر مع عميل Podman البعيد.

الخيارات

--help, -h

طباعة بيان الاستخدام

--rootless-netns

الانضمام إلى مساحة اسم الشبكة غير المتميزة المستخدمة لشبكات netavark. يمكن استخدامها للاتصال بحاوية غير متميزة عبر عنوان IP (شبكات الجسر). هذا غير ممكن بخلاف ذلك من مساحة اسم شبكة المضيف.

رموز الخروج

يقدم رمز الخروج من podman unshare معلومات حول سبب فشل تشغيل الحاوية أو سبب خروجها. عندما تخرج أوامر podman unshare برمز غير صفري، تتبع رموز الخروج معيار chroot، انظر أدناه:

125 الخطأ يتعلق بـ podman نفسه

$ podman unshare --foo; echo $?
Error: unknown flag: --foo
125

126 تنفيذ أمر محتوى و الأمر لا يمكن استدعاؤه

$ podman unshare /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 تنفيذ أمر محتوى و الأمر لا يمكن العثور عليه

$ podman unshare foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

رمز الخروج رمز خروج الأمر المحتوى

$ podman unshare /bin/sh -c 'exit 3'; echo $?
3

مثال

تنفيذ الأمر المحدد في مساحة اسم المستخدم غير المتميزة:

$ podman unshare id
uid=0(root) gid=0(root) groups=0(root),65534(nobody)

إظهار تعيينات مساحة اسم المستخدم للحاويات غير المتميزة:

$ podman unshare cat /proc/self/uid_map /proc/self/gid_map
         0       1000          1
         1      10000      65536
         0       1000          1
         1      10000      65536

إظهار معلومات شبكة المسار غير المتميزة في مساحة اسم المستخدم للحاويات غير المتميزة:

$ podman unshare --rootless-netns ip addr

       valid_lft forever preferred_lft forever
