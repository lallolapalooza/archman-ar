docker-machine-cp(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-machine-cp(1) دليل الأوامر العامة podman-machine-cp(1)

الاسم

podman-machine-cp - نسخ المحتويات بشكل آمن بين المضيف والجهاز الافتراضي

الملخص

podman machine cp [خيارات] مسار_المصدر مسار_الوجهة

الوصف

استخدم النسخ الآمن (scp) لنسخ الملفات أو الدلائل بين الجهاز الافتراضي وجهاز المضيف الخاص بك.

podman machine cp لا يدعم النسخ بين جهازين افتراضيين، مما يتطلب تشغيل جهازين في وقت واحد.

بالإضافة إلى ذلك، podman machine cp سيقوم تلقائيًا بنسخ الملفات والدلائل بشكل متكرر.

الخيارات

--help

طباعة بيان الاستخدام.

--quiet, -q

كبت إخراج حالة النسخ.

أمثلة

نسخ ملف من المضيف الخاص بك إلى جهاز Podman Machine قيد التشغيل.

$ podman machine cp ~/configuration.txt podman-machine-default:~/configuration.txt
...
Copy Successful

نسخ ملف من جهاز Podman Machine قيد التشغيل إلى المضيف الخاص بك.

$ podman machine cp podman-machine-default:~/logs/log.txt ~/logs/podman-machine-default.txt
...
Copy Successful

نسخ دليل من المضيف الخاص بك إلى جهاز Podman Machine قيد التشغيل.

$ podman machine cp ~/.config podman-machine-default:~/.config
...
Copy Successful

نسخ دليل من جهاز Podman Machine قيد التشغيل إلى المضيف الخاص بك.

$ podman machine cp podman-machine-default:~/.config ~/podman-machine-default.config
...
Copy Successful
