podman-farm-create(1) دليل الأوامر العامة podman-farm-create(1)

الاسم

podman farm create - إنشاء مزرعة جديدة

موجز

podman farm create name [connections]

الوصف

إنشاء مزرعة جديدة مع اتصالات يعرفها Podman والتي تمت إضافتها عبر الأمر podman system connection add.

يمكن إنشاء مزرعة فارغة دون إضافة أي اتصالات إليها. إضافة أو إزالة الاتصالات من مزرعة عبر الأمر podman farm update.

أمثلة

إنشاء المزرعة المحددة بدون اتصالات:

$ podman farm create farm2

إنشاء مزرعة مع اتصالات:

$ podman farm create farm1 f37 f38

انظر أيضًا

podman(1), podman-farm(1), podman-system-connection(1), podman-system-connection-add(1)
