docker-network-exists(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-network-exists(1) دليل الأوامر العامة podman-network-exists(1)

الاسم

podman network exists - التحقق من وجود الشبكة المعطاة

الملخص

podman network exists network

الوصف

podman network exists تتحقق مما إذا كانت الشبكة موجودة. يمكن استخدام الاسم أو المعرف (ID) للشبكة كمدخل. يعيد Podman رمز خروج 0 عند العثور على الشبكة. يتم إرجاع 1 بخلاف ذلك. رمز خروج 125 يشير إلى وجود مشكلة أخرى.

الخيارات

--help, -h

طباعة بيان الاستخدام

مثال

التحقق من وجود شبكة محددة (الشبكة موجودة بالفعل):

$ podman network exists net1
$ echo $?
0

التحقق من وجود شبكة غير موجودة:

$ podman network exists webbackend
$ echo $?
1

انظر أيضًا

podman(1), podman-network(1)
