الاسم

podman-machine-list - سرد الأجهزة الافتراضية

الخلاصة

podman machine list [خيارات]

podman machine ls [خيارات]

الوصف

سرد الأجهزة الافتراضية التي تديرها Podman.

تتطلب Podman على MacOS و Windows جهازًا افتراضيًا. هذا لأنه ليست الحاويات لينكس - الحاويات لا تعمل على أي نظام تشغيل آخر لأن الوظائف الأساسية للحاويات مرتبطة بنواة لينكس. يجب استخدام podman machine لإدارة أجهزة MacOS و Windows، ولكن يمكن استخدامها اختياريًا على لينكس.

الجذر فقط.

ملاحظة: يتم إدارة ملف تكوين podman-machine تحت الدليل $XDG_CONFIG_HOME/containers/podman/machine/. قد يؤدي تغيير متغير البيئة $XDG_CONFIG_HOME أثناء تشغيل الأجهزة إلى سلوك غير متوقع. (انظر podman(1))

الخيارات

--all-providers

عرض الأجهزة من جميع المزودين

--format=format

تغيير تنسيق الإخراج الافتراضي. يمكن أن يكون هذا من نوع مدعوم مثل 'json' أو قالب Go. العناصر النائبة الصالحة لقالب Go مدرجة أدناه:

العنصر النائب الوصف
.CPUs عدد وحدات المعالجة المركزية
.Created الوقت منذ إنشاء الجهاز الافتراضي
.Default هل هو الجهاز الافتراضي الافتراضي
.DiskSize حجم القرص للجهاز الافتراضي
.IdentityPath المسار إلى ملف هوية ssh
.LastUp الوقت منذ آخر تشغيل للجهاز الافتراضي
.Memory الذاكرة المخصصة للجهاز الافتراضي
.Name اسم الجهاز الافتراضي
.Port منفذ SSH للاستخدام للاتصال بالجهاز الافتراضي
.RemoteUsername اسم مستخدم الجهاز الافتراضي لـ Podman بدون جذر
.Running هل الجهاز الافتراضي قيد التشغيل
.Stream اسم البث
.Swap المقايضة المخصصة للجهاز الافتراضي
.UserModeNetworking ما إذا كان الجهاز الافتراضي يستخدم شبكة وضع المستخدم
.VMType نوع الجهاز الافتراضي

--help

طباعة بيان الاستخدام.

--noheading, -n

حذف عناوين الجدول من القائمة.

--quiet, -q

طباعة اسم الجهاز الافتراضي فقط. يشير هذا أيضًا إلى عدم طباعة أي عنوان جدول.

أمثلة

سرد جميع أجهزة Podman الافتراضية.

$ podman machine list
NAME                    VM TYPE     CREATED      LAST UP      CPUS        MEMORY      DISK SIZE
podman-machine-default  qemu        2 weeks ago  2 weeks ago  1           2.147GB     10.74GB

سرد جميع أجهزة Podman الافتراضية باستخدام تنسيق الجدول المحدد.

$ podman machine ls --format "table {{.Name}}\t{{.VMType}}\t{{.Created}}\t{{.LastUp}}"
NAME                    VM TYPE     CREATED      LAST UP
podman-machine-default  qemu        2 weeks ago  2 weeks ago

سرد جميع أجهزة Podman الافتراضية بتنسيق json.

$ podman machine ls --format json
[
    {
        "Name": "podman-machine-default",
        "Default": false,
        "Created": "2021-12-27T10:36:14.373347492-05:00",
        "Running": false,
        "LastUp": "2021-12-27T11:22:50.17333371-05:00",
        "Stream": "default",
        "VMType": "qemu",
        "CPUs": 1,
        "Memory": "2147483648",
        "DiskSize": "10737418240"
    }
]
