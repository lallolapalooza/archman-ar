docker-network-reload(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-network-reload(1) دليل الأوامر العامة podman-network-reload(1)

الاسم

podman-network-reload - إعادة تحميل تكوين الشبكة للحاويات

الملخص

podman network reload [خيارات] [حاوية...]

الوصف

إعادة تحميل تكوين شبكة حاوية واحدة أو أكثر.

يعتمد Podman الأصيل (Rootful Podman) على قواعد iptables لتوفير الاتصال بالشبكة. إذا تم حذف قواعد iptables، وهو ما يحدث على سبيل المثال مع firewall-cmd --reload، تفقد الحاوية الاتصال بالشبكة. هذا الأمر يعيد الاتصال بالشبكة.

الخيارات

--all, -a

إعادة تحميل تكوين الشبكة لجميع الحاويات.

--latest, -l

بدلاً من توفير اسم الحاوية أو معرفها، استخدم آخر حاوية تم إنشاؤها. ملاحظة: قد تكون آخر حاوية تم تشغيلها من مستخدمين آخرين لـ Podman على الجهاز المضيف. (هذا الخيار غير متاح مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

مثال

إعادة تحميل تكوين الشبكة بعد إعادة تحميل جدار الحماية:

# podman run -p 80:80 -d nginx
b1b538e8bc4078fc3ee1c95b666ebc7449b9a97bacd15bcbe464a29e1be59c1c
# curl 127.0.0.1
works
# sudo firewall-cmd --reload
success
# curl 127.0.0.1
hangs
# podman network reload b1b538e8bc40
b1b538e8bc4078fc3ee1c95b666ebc7449b9a97bacd15bcbe464a29e1be59c1c
# curl 127.0.0.1
works

إعادة تحميل تكوين الشبكة لجميع الحاويات:

# podman network reload --all
b1b538e8bc4078fc3ee1c95b666ebc7449b9a97bacd15bcbe464a29e1be59c1c
fe7e8eca56f844ec33af10f0aa3b31b44a172776e3277b9550a623ed5d96e72b
