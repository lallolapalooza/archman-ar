docker-machine-stop(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-machine-stop(1) دليل الأوامر العامة podman-machine-stop(1)

الاسم

podman-machine-stop - إيقاف آلة افتراضية

الملخص

podman machine stop [الاسم]

الوصف

يقوم بإيقاف آلة افتراضية.

اسم الآلة الافتراضية الافتراضي هو podman-machine-default. إذا لم يتم تحديد اسم الآلة كمعامل، فسيتم إيقاف podman-machine-default.

للمستخدمين غير الجذر فقط.

يتطلب Podman على MacOS و Windows آلة افتراضية. هذا لأن الحاويات هي Linux - الحاويات لا تعمل على أي نظام تشغيل آخر لأن الوظائف الأساسية للحاويات مرتبطة بنواة Linux. يجب استخدام آلة Podman لإدارة أجهزة MacOS و Windows، ولكن يمكن استخدامها اختياريًا على Linux.

podman machine stop يقوم بإيقاف آلة Linux افتراضية يتم تشغيل الحاويات فيها.

الخيارات

--help

طباعة بيان الاستخدام.

أمثلة

إيقاف آلة podman تسمى myvm.

$ podman machine stop myvm
