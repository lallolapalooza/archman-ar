podman-system-connection-rename(1) دليل الأوامر العامة podman-system-connection-rename(1)

الاسم

podman-system-connection-rename - إعادة تسمية وجهة خدمة Podman

الملخص

podman system connection rename old new

الوصف

إعادة تسمية وجهة SSH من old إلى new.

مثال

إعادة تسمية الاتصال المحدد:

$ podman system connection rename laptop devel

انظر أيضًا

podman(1), podman-system(1), podman-system-connection(1)
