الحزمة: podman-docker

podman-system-connection(1) دليل الأوامر العامة podman-system-connection(1)

الاسم

podman-system-connection - إدارة الوجهة (الوجهات) لخدمات Podman

النبذة

podman system connection subcommand

الوصف

إدارة الوجهة (الوجهات) لخدمات Podman.

يُطالب المستخدم بإدخال كلمة مرور تسجيل الدخول ssh أو عبارة مرور ملف المفتاح حسب الحاجة. يتم دعم ssh-agent إذا كان قيد التشغيل.

يدير Podman اتصال النظام عن طريق الكتابة والقراءة من ملف podman-connections.json الموجود تحت $XDG_CONFIG_HOME/containers أو إذا لم يتم تعيين البيئة، فإنه يعود إلى $HOME/.config/containers. أو يمكن تعيين المتغير البيئي PODMAN_CONNECTIONS_CONF إلى مسار ملف كامل سيستخدمه Podman بدلاً من ذلك. تتم إدارة هذا الملف بواسطة أوامر Podman ويجب ألا يقوم المستخدمون بتحريره مباشرة. لتكوين الاتصالات يدويًا، استخدم service_destinations في containers.conf.

إذا تم تعيين عمود ReadWrite في ناتج podman system connection list إلى true، فسيتم تخزين الاتصال في ملف podman-connections.json وإلا فسيتم تخزينه في containers.conf وبالتالي لا يمكن تعديله باستخدام أوامر podman system connection.

الأوامر

الأمر صفحة الدليل الوصف
add podman-system-connection-add(1) تسجيل وجهة لخدمة Podman
default podman-system-connection-default(1) تعيين وجهة مسماة كافتراضية لخدمة Podman
list podman-system-connection-list(1) عرض قائمة بالوجهات لخدمة (خدمات) Podman
remove podman-system-connection-remove(1) حذف وجهة مسماة
rename podman-system-connection-rename(1) إعادة تسمية وجهة خدمة Podman

مثال

عرض قائمة اتصالات النظام:

$ podman system connection list
Name URI                                           Identity	      Default  ReadWrite
devl ssh://root@example.com/run/podman/podman.sock ~/.ssh/id_rsa  true     true
