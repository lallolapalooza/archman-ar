doveadm-dump(1)

الحزمة: dovecot

التراخيص: MIT, LGPL-2.1-only

DOVEADM-DUMP(1) Dovecot DOVEADM-DUMP(1)

الاسم

doveadm-dump - تفريغ محتوى فهرس/سجل بريد Dovecot الثنائي

ملخص

doveadm [خيارات عامة] dump [-t النوع] المسار [وسيطات خاصة بالنوع]

الوصف

يستخدم Dovecot عدة ملفات فهرس وسجل ثنائية من أجل تحسين أداء الوصول إلى رسائل البريد. بالنسبة لبعض تنسيقات صندوق البريد، مثل sdbox و mdbox، تكون ملفات الفهرس جزءًا من التنسيق نفسه. لمعرفة التفاصيل حول ملفات الفهرس، راجع [[link,design_index_format_main].

يُستخدم doveadm dump لعرض محتويات ملفات الفهرس/السجل الخاصة بصندوق البريد، بتنسيق قابل للقراءة البشرية. هذا مفيد بشكل أساسي لمطوري Dovecot عند تصحيح مشكلة ما.

الخيارات العامة

doveadm(1) العام

-D

يُمكّن التفصيل ورسائل التصحيح.

-O

لا تقرأ أي ملف تكوين، استخدم الافتراضيات فقط. يتم تعيين dovecot_storage_version افتراضيًا إلى أحدث إصدار، ولكن يمكن تجاوزه باستخدام

-k

احتفظ بالبيئة الكاملة لـ doveadm، وليس فقط إعداد import_environment.

-v

يُمكّن التفصيل، بما في ذلك عداد التقدم.

-i اسم_التثبيت

إذا كنت تستخدم تثبيتات Dovecot متعددة، فاختر ملف التكوين بناءً على اسم التثبيت هذا.

راجع إعداد instance_name لمزيد من المعلومات.

-c ملف_التكوين

اقرأ التكوين من ملف_التكوين المحدد. بشكل افتراضي، يقرأ أولاً مقبس التكوين، ثم يعود إلى /etc/dovecot/dovecot.conf. يمكنك أيضًا توجيه هذا إلى مقبس تكوين لتثبيت متوافق.

-o الإعداد=القيمة

يتجاوز إعداد التكوين الإعداد من /etc/dovecot/dovecot.conf ومن قاعدة بيانات المستخدم مع القيمة المحددة. لتجاوز إعدادات متعددة، يمكن تحديد الخيار -o عدة مرات.

الخيارات

-t النوع


تم حذفه، يحاول doveadm(1) اكتشاف نوع

النوع يمكن أن يكون:

dbox : => m.n (ملف صندوق بريد sdbox أو mdbox)

fts-expunge-log : تفريغ قائمة رسائل البريد المحذوفة في dovecot-expunges.log.

fts-flatcurve : تفريغ الكلمات المفتاحية المفهرسة في دليل فهارس fts-flatcurve وتكراراتها.

imap-compress : فك ضغط سجل حركة مرور IMAP، والذي يحتوي على بيانات مضغوطة باستخدام امتداد ضغط IMAP.

dcrypt-file : تفريغ البيانات الوصفية لملف مشفر بـ dcrypt.

وسيطات خاصة بالنوع

private_key=/path : لفك تشفير محتويات الملف.

password=secret : لفك تشفير المفتاح الخاص.

dcrypt-key : تفريغ البيانات الوصفية لمفتاح dcrypt.

وسيطات خاصة بالنوع

private_key=/path

لفك تشفير محتويات الملف.

password=secret

لفك تشفير المفتاح الخاص.

dump=pem|dovecot|jwk

لتحديد تنسيق التفريغ.

index : => dovecot.index, dovecot.map.index

وسيطات خاصة بالنوع

uid=number : تفريغ الرسالة ذات المعرف الفريد فقط

log : => dovecot.index.log, dovecot.map.index.log

mailboxlog : => dovecot.mailbox.log

thread : => dovecot.index.thread

الوسيطات

المسار

المسار إلى تخزين dbox المقابل، أو ملف الفهرس أو السجل. إذا تم تحديد دليل فقط، يحاول doveadm اكتشاف نوع الملفات الموجودة تحته وتفريغها.

مثال

عرض محتويات فهرس صندوق بريد:

doveadm dump ~/Maildir/.work/

الإبلاغ عن الأخطاء

قم بالإبلاغ عن الأخطاء، بما في ذلك مخرجات doveconf -n، إلى قائمة بريد Dovecot ⟨dovecot@dovecot.org⟩. تتوفر معلومات حول الإبلاغ عن الأخطاء على: https://dovecot.org/bugreport.html
