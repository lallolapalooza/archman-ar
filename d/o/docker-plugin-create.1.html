docker-plugin-create(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-plugin-create - إنشاء مكون إضافي من نظام ملفات جذر وتكوين. يجب أن يحتوي دليل بيانات المكون الإضافي على ملف config.json ودليل rootfs.

الملخص

docker plugin create [OPTIONS] PLUGIN PLUGIN-DATA-DIR

الوصف

إنشاء مكون إضافي من نظام ملفات جذر وتكوين. يجب أن يحتوي دليل بيانات المكون الإضافي على ملف config.json ودليل rootfs.

خيارات

--compress[=false] ضغط السياق باستخدام gzip
