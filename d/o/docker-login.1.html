docker-login(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-login - المصادقة على سجل

الملخص

docker login [OPTIONS] [SERVER]

الوصف

تسجيل الدخول إلى سجل Docker موجود على SERVER المحدد. يمكنك تحديد عنوان URL أو اسم مضيف لقيمة SERVER. إذا لم تحدد SERVER، فإن الأمر يستخدم سجل Docker العام الموجود على https://registry-1.docker.io/ افتراضيًا. للحصول على اسم مستخدم/كلمة مرور لسجل Docker العام، قم بإنشاء حساب على Docker Hub.

يتطلب docker login من المستخدم استخدام sudo أو أن يكون root، باستثناء:

1.
الاتصال بخادم بعيد، مثل docker engine تم توفيره بواسطة docker-machine.
2.
تمت إضافة المستخدم إلى مجموعة docker. سيؤثر هذا على أمان نظامك؛ مجموعة docker تعادل root. انظر سطح هجوم Docker Daemon ⟨https://docs.docker.com/engine/security/#docker-daemon-attack-surface⟩ للتفاصيل.

يمكنك تسجيل الدخول إلى أي مستودع عام أو خاص لديك بيانات اعتماد له. عند تسجيل الدخول، يقوم الأمر بتخزين بيانات الاعتماد المشفرة في $HOME/.docker/config.json على Linux أو %USERPROFILE%/.docker/config.json على Windows.

أمثلة

تسجيل الدخول إلى سجل على جهازك المحلي

# docker login localhost:8080

انظر أيضًا

docker-logout(1) لتسجيل الخروج من سجل.

خيارات

-p, --password="" كلمة المرور أو رمز الوصول الشخصي (PAT)

--password-stdin[=false] خذ كلمة المرور أو رمز الوصول الشخصي (PAT) من stdin

-u, --username="" اسم المستخدم
