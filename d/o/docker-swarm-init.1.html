docker-swarm-init(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم دوكر DOCKER(1)

اسم

docker-swarm-init - تهيئة swarm

الموجز

docker swarm init [خيارات]

الوصف

تهيئة swarm

الخيارات

--advertise-addr="" عنوان الإعلان (التنسيق: "[:port]")

--autolock[=false] تمكين قفل المديرين تلقائيًا (يتطلب مفتاح إلغاء قفل لبدء مدير متوقف)

--availability="active" توفر العقدة ("active", "pause", "drain")

--cert-expiry=2160h0m0s فترة صلاحية شهادات العقدة (ns|us|ms|s|m|h)

--data-path-addr="" العنوان أو الواجهة المستخدمة لحركة مرور مسار البيانات (التنسيق: "")

--data-path-port=0 رقم المنفذ المستخدم لحركة مرور مسار البيانات (1024 - 49151). إذا لم يتم تعيين قيمة أو تم تعيينها إلى 0، فسيتم استخدام المنفذ الافتراضي (4789).

--default-addr-pool=[] مجمع العناوين الافتراضي بتنسيق CIDR

--default-addr-pool-mask-length=24 طول قناع شبكة مجمع العناوين الافتراضي

--dispatcher-heartbeat=5s فترة نبضات المرسل (ns|us|ms|s|m|h)

--external-ca= مواصفات نقطة (نقاط) توقيع الشهادة الخارجية

--force-new-cluster[=false] فرض إنشاء مجموعة جديدة من الحالة الحالية

--listen-addr=0.0.0.0:2377 عنوان الاستماع (التنسيق: "[:port]")

--max-snapshots=0 عدد لقطات Raft الإضافية للاحتفاظ بها

--snapshot-interval=10000 عدد إدخالات السجل بين لقطات Raft

--task-history-limit=5 حد الاحتفاظ بسجل المهام
