docker-quadlet-print(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-quadlet-print(1) دليل الأوامر العامة podman-quadlet-print(1)

الاسم

podman quadlet print - عرض محتويات quadlet

الملخص

podman quadlet print quadlet

podman quadlet cat quadlet

الوصف

طباعة محتويات Quadlet، وعرض الملف بما في ذلك جميع التعليقات.

أمثلة

استخدام podman quadlet print لعرض محتويات quadlet باسم myquadlet.container:

$ podman quadlet print myquadlet.container
[Container]
Image=alpine
Exec=sh -c "echo LIFECYCLE TEST STARTED; trap 'exit' SIGTERM; while :; do echo running; sleep 1; done"
LogDriver=passthrough
