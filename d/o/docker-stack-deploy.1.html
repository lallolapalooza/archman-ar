docker-stack-deploy(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-stack-deploy - نشر مكدس جديد أو تحديث مكدس موجود

ملخص

docker stack deploy [OPTIONS] STACK

الوصف

نشر مكدس جديد أو تحديث مكدس موجود

خيارات

-c, --compose-file=[] مسار ملف Compose، أو "-" للقراءة من stdin

-d, --detach[=true] الخروج فورًا بدلاً من انتظار تقارب خدمات المكدس

--prune[=false] تنظيف الخدمات التي لم تعد مشار إليها

-q, --quiet[=false] كتم إخراج التقدم

--resolve-image="always" الاستعلام عن السجل لحل معرف الصورة والمنصات المدعومة ("always", "changed", "never")

--with-registry-auth[=false] إرسال تفاصيل مصادقة السجل إلى وكلاء Swarm
