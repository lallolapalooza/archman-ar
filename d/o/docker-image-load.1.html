docker-image-load(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-image-load - تحميل صورة من أرشيف tar أو STDIN

الملخص

docker image load [OPTIONS]

الوصف

يقوم بتحميل مستودع مضغوط بصيغة tar من ملف أو تدفق الإدخال القياسي. يقوم باستعادة الصور والعلامات. يكتب أسماء الصور أو معرفاتها المستوردة إلى تدفق الإخراج القياسي.

أمثلة

$ docker images
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
busybox             latest              769b9341d937        7 weeks ago         2.489 MB
$ docker load --input fedora.tar
# […]
Loaded image: fedora:rawhide
# […]
Loaded image: fedora:20
# […]
$ docker images
REPOSITORY          TAG                 IMAGE ID            CREATED             SIZE
busybox             latest              769b9341d937        7 weeks ago         2.489 MB
fedora              rawhide             0d20aec6529d        7 weeks ago         387 MB
fedora              20                  58394af37342        7 weeks ago         385.5 MB
fedora              heisenbug           58394af37342        7 weeks ago         385.5 MB
fedora              latest              58394af37342        7 weeks ago         385.5 MB

انظر أيضا

docker-image-save(1) لحفظ صورة واحدة أو أكثر في أرشيف tar (يتم تدفقها إلى STDOUT افتراضيًا).

خيارات

-i, --input="" اقرأ من ملف أرشيف tar، بدلاً من STDIN

--platform=[] قم بتحميل المنصة (المنصات) المحددة فقط. يتم تنسيقها كقائمة مفصولة بفواصل من "os[/arch[/variant]]" (على سبيل المثال، "linux/amd64,linux/arm64/v8").

-q, --quiet[=false] قم بكتم إخراج التحميل
