podman-quadlet-list(1) دليل الأوامر العامة podman-quadlet-list(1)

الاسم

podman-quadlet-list - قائمة بـ Quadlets المثبتة

الملخص

podman quadlet list [خيارات]

الوصف

يسرد جميع Quadlets المهيأة للمستخدم الحالي.

الخيارات

--filter, -f=مرشح

تصفية الإخراج بناءً على الشروط المعطاة.

صيغة الوسيط مرشحات هي مفتاح=قيمة. إذا كان هناك أكثر من مرشح واحد، فقم بتمرير خيارات متعددة: --filter foo=bar --filter bif=baz.

المرشحات المدعومة:

المرشح الوصف
name التصفية حسب اسم quadlet.

--format=صيغة

طباعة الإخراج بتنسيق JSON أو باستخدام قالب Go (الافتراضي "{{range .}}{{.Name}}\t{{.UnitName}}\t{{.Path}}\t{{.Status}}\n{{end -}}")

طباعة النتائج باستخدام قالب Go.

العنصر النائب الوصف
.App اسم التطبيق إذا كان Quadlet جزءًا من تطبيق
.Name اسم ملف Quadlet
.Path مسار ملف Quadlet على القرص
.Status حالة Quadlet المقابلة لوحدة systemd
.UnitName اسم وحدة systemd المقابلة لـ quadlet

أمثلة

أمر قائمة بسيط

$ podman quadlet list
NAME                            UNIT NAME                     PATH ON DISK                                                          STATUS      APPLICATION
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  Not loaded
sample-quadlet.container        sample-quadlet.service        /home/user/.config/containers/systemd/sample-quadlet.container        Not loaded

تصفية القائمة حسب الاسم.

$ podman quadlet list --filter 'name=test*'
NAME                            UNIT NAME                     PATH ON DISK                                                          STATUS      APPLICATION
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  Not loaded

تنسيق ناتج القائمة لحقل معين.

$ podman quadlet list --format '{{ .UnitName }}'
UNIT NAME
test-service-quadlet.service
sample-quadlet.service
