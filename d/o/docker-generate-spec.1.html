docker-generate-spec(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-generate-spec(1) دليل الأوامر العامة podman-generate-spec(1)

الاسم

podman generate spec - إنشاء JSON Specgen بناءً على الحاويات أو المجموعات (pods)

الملخص

podman generate spec [خيارات] *حاوية | مجموعة

الوصف

يقوم الأمر podman generate spec بإنشاء JSON Specgen من حاويات ومجموعات Podman. يمكن طباعة هذا JSON إلى ملف، أو مباشرة إلى سطر الأوامر، أو كلاهما.

يمكن استخدام هذا JSON كمدخل لواجهة برمجة تطبيقات Podman (Podman API)، وبشكل خاص لإنشاء حاويات ومجموعات Podman. Specgen هو الهيكل الداخلي لـ Podman لتشكيل كيانات جديدة متعلقة بالحاويات.

الخيارات

--compact, -c

طباعة الإخراج بتنسيق مدمج، بسطر واحد. هذا مفيد عند توجيه البيانات إلى واجهة برمجة تطبيقات Podman.

--filename, -f=اسم-الملف

إخراج إلى الملف المحدد.

--name, -n

إعادة تسمية المجموعة أو الحاوية، بحيث لا تتعارض مع الكيان الموجود. هذا مفيد عندما يراد استخدام JSON قبل حذف مجموعة أو حاوية المصدر.

{"name":"container1-clone","command":["/bin/sh"],...
