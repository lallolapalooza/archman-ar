docker-image-import(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم دوكر DOCKER(1)

الاسم

docker-image-import - استيراد محتويات من أرشيف tar لإنشاء صورة نظام ملفات

الملخص

docker image import [خيارات] ملف|URL|- [اسم_المستودع[:العلامة]]

الوصف

إنشاء صورة نظام ملفات جديدة من محتويات أرشيف tar (.tar, .tar.gz, .tgz, .bzip, .tar.xz, .txz) بداخلها، ثم وضع علامة عليها اختياريًا.

أمثلة

الاستيراد من موقع بعيد

# docker image import http://example.com/exampleimage.tgz example/imagerepo

الاستيراد من ملف محلي

الاستيراد إلى دوكر عبر الأنابيب والمدخل القياسي:

# cat exampleimage.tgz | docker image import - example/imagelocal

الاستيراد مع رسالة التثبيت.

# cat exampleimage.tgz | docker image import --message "صورة جديدة مستوردة من أرشيف tar" - exampleimagelocal:new

الاستيراد إلى صورة دوكر من ملف محلي.

# docker image import /path/to/exampleimage.tgz

الاستيراد من ملف محلي ووضع علامة

الاستيراد إلى دوكر عبر الأنابيب والمدخل القياسي:

# cat exampleimageV2.tgz | docker image import - example/imagelocal:V-2.0

الاستيراد من دليل محلي

# tar -c . | docker image import - exampleimagedir

تطبيق تعليمات Dockerfile المحددة أثناء استيراد الصورة

يقوم هذا المثال بتعيين متغير البيئة ENV في صورة دوكر DEBUG إلى true افتراضيًا.

# tar -c . | docker image import -c="ENV DEBUG=true" - exampleimagedir

عندما يدعم الخادم أنظمة تشغيل متعددة

إذا كان الخادم يدعم أنظمة تشغيل متعددة، ولم تتطابق الصورة التي يتم استيرادها مع نظام التشغيل الافتراضي، فقد يكون من الضروري إضافة --platform. سيكون هذا ضروريًا عند استيراد صورة Linux إلى خادم Windows.

# docker image import --platform=linux .\linuximage.tar

انظر أيضاً

docker-export(1) لتصدير محتويات نظام ملفات كأرشيف tar إلى STDOUT.

خيارات

-c, --change= تطبيق تعليمات Dockerfile على الصورة التي تم إنشاؤها

-m, --message="" تعيين رسالة التثبيت للصورة المستوردة

--platform="" تعيين المنصة إذا كان الخادم قادرًا على دعم منصات متعددة
