docker-kube-apply(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-kube-apply(1) دليل الأوامر العامة podman-kube-apply(1)

الاسم

podman kube apply - تطبيق YAML Kubernetes بناءً على حاويات أو وحدات أو وحدات تخزين على مجموعة Kubernetes

الاستخدام

podman kube apply [خيارات] [حاوية... | وحدة... | وحدة تخزين...]

الوصف

podman kube apply تنشر حاوية Podman أو وحدة أو وحدة تخزين على مجموعة Kubernetes. استخدم الخيار --file لنشر ملف YAML (مواصفات v1) الخاص بـ Kubernetes على مجموعة Kubernetes أيضًا.

لاحظ أن ملف YAML الخاص بـ Kubernetes يمكن استخدامه لتشغيل النشر في Podman عبر podman-play-kube(1).

الخيارات

--ca-cert-file=ملف شهادة CA المسار | غير آمن

المسار إلى ملف شهادة CA الخاص بمجموعة Kubernetes. عادةً ما تحتوي ملفات kubeconfig على بيانات ملف شهادة CA، ويقوم generate kube تلقائيًا باستردادها إذا كانت متاحة في kubeconfig. إذا لم تكن بيانات ملف شهادة CA متاحة، فاضبط هذا الخيار على insecure لتجاوز التحقق من الشهادة.

--file, -f=مسار ملف yaml kube

المسار إلى ملف yaml الخاص بـ kubernetes لنشره على مجموعة kubernetes. يمكن أن يكون هذا الملف ناتجًا عن أمر podman kube generate. قد يكون الإدخال بصيغة ملف yaml، أو stdin. لاستخدام stdin، استخدم --file=-.

--kubeconfig, -k=مسار ملف kubeconfig

المسار إلى ملف kubeconfig المراد استخدامه عند نشر ملف kube yaml الذي تم إنشاؤه إلى مجموعة Kubernetes. يمكن استخدام متغير البيئة KUBECONFIG لتعيين المسار لملف kubeconfig أيضًا. ملاحظة: يمكن أن يحتوي ملف kubeconfig على تكوينات متعددة للمجموعات، لكن kube generate يختار دائمًا تكوين المجموعة الأول في ملف kubeconfig المحدد.

--ns=namespace

المساحة الاسمية أو المشروع لنشر أعباء العمل الخاصة بملف kube yaml الذي تم إنشاؤه إليه في مجموعة Kubernetes.

--service, -s

يُستخدم لإنشاء خدمة للحاوية أو الوحدة المقابلة التي يتم نشرها إلى المجموعة. على وجه الخصوص، إذا كانت الحاوية أو الوحدة تحتوي على ربط لمنافذ، فإن مواصفات الخدمة تتضمن إعلان NodePort لكشف الخدمة. يتم تعيين منفذ عشوائي بواسطة Podman في مواصفات الخدمة التي يتم نشرها إلى المجموعة.

أمثلة

تطبيق وحدة تخزين Podman وحاوية إلى مساحة الأسماء "default" في مجموعة Kubernetes.

$ podman kube apply --kubeconfig /tmp/kubeconfig myvol vol-test-1
Deploying to cluster...
Successfully deployed workloads to cluster!
$ kubectl get pods
NAME             READY   STATUS    RESTARTS   AGE
vol-test-1-pod   1/1     Running   0          9m

تطبيق ملف YAML الخاص بـ Kubernetes إلى مساحة الأسماء "default" في مجموعة Kubernetes.

$ podman kube apply --kubeconfig /tmp/kubeconfig -f vol.yaml
Deploying to cluster...
Successfully deployed workloads to cluster!
$ kubectl get pods
NAME             READY   STATUS    RESTARTS   AGE
vol-test-2-pod   1/1     Running   0          9m

تطبيق ملف YAML الخاص بـ Kubernetes إلى مساحة الأسماء "test1" في مجموعة Kubernetes.

$ podman kube apply --kubeconfig /tmp/kubeconfig --ns test1 vol-test-3
Deploying to cluster...
Successfully deployed workloads to cluster!
$ kubectl get pods --namespace test1
NAME             READY   STATUS    RESTARTS   AGE
vol-test-3-pod   1/1     Running   0          9m
