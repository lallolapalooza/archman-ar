docker-artifact-add(1)

الحزمة: podman-docker

التراخيص: Apache-2.0

podman-artifact-add(1) دليل الأوامر العامة podman-artifact-add(1)

الاسم

podman artifact add - إضافة قطعة أثرية OCI إلى مخزن القطع الأثرية المحلي

ملخص

podman artifact add [خيارات] اسم-القطعة-الأثرية ملف [ملف ...]

الوصف

إضافة قطعة أثرية OCI إلى المخزن المحلي من نظام الملفات المحلي. يجب عليك توفير ملف واحد على الأقل لإنشاء القطعة الأثرية، ولكن يمكن أيضًا إضافة عدة ملفات.

تتضمن القطع الأثرية تلقائيًا طابعًا زمنيًا للإنشاء في التعليق **org.opencontainers.image.created** بتنسيق RFC3339Nano. عند استخدام الخيار **--append**، يتم الحفاظ على الطابع الزمني الأصلي للإنشاء.

الخيارات

--annotation=تعليق=قيمة

تعيين تعليق على الإدخال للصورة أو القطعة الأثرية المحددة.

ملاحظة: قم بتعيين التعليقات لكل ملف يتم إضافته. يُستخدم التعليق "org.opencontainers.image.title" لتسمية الطبقة عند تحميلها في حاوية، يجب أن يكون هذا العنوان فريدًا لكل طبقة قطعة أثرية.

--append, -a

إلحاق ملفات بقطعة أثرية موجودة. لا يمكن استخدام هذا الخيار مع الخيار **--type**.

--file-type

تعيين نوع وسائط ملف القطعة الأثرية بدلاً من السماح للاكتشاف بتحديد النوع

--help

طباعة بيان الاستخدام.

--replace

إذا كانت هناك قطعة أثرية بنفس الاسم موجودة بالفعل، فاستبدلها وأزلها. القيمة الافتراضية هي **false**. لا يمكن استخدام هذا الخيار مع الخيار **--append**.

--type

تعيين نوع للقطعة الأثرية التي يتم إضافتها.

أمثلة

إضافة ملف واحد إلى قطعة أثرية

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar.ml
0fe1488ecdef8cc4093e11a55bc048d9fc3e13a4ba846efd24b5a715006c95b3

إضافة قطعة أثرية OCI إلى المخزن مع نوع:

$ podman artifact add --artifact-type application/com.example.ai --file-type application/vnd.gguf quay.io/myimage/myartifact:latest /home/user/model.gguf

استبدال قطعة أثرية موجودة بنفس الاسم

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar.ml
0fe1488ecdef8cc4093e11a55bc048d9fc3e13a4ba846efd24b5a715006c95b3

إضافة ملفات متعددة إلى قطعة أثرية

$ podman artifact add quay.io/myartifact/myml:latest /tmp/foobar1.ml /tmp/foobar2.ml
1487acae11b5a30948c50762882036b41ac91a7b9514be8012d98015c95ddb78

إضافة ملفات إلى قطعة أثرية OCI موجودة

$ podman artifact add --append quay.io/myimage/myartifact:latest /home/user/config.yaml

إنشاء قطعة أثرية مع استبدال اسم طبقة القطعة الأثرية، ثم تحميلها في حاوية.

podman artifact add --annotation org.opencontainers.image.title=smollm2 quay.io/myreg/smollm2:latest blobs/sha256-4d2396b16114669389d7555c15a1592aad584750310f648edad5ca8c4eccda17
podman run --mount type=artifact,source=quay.io/myreg/smollm2:latest,destination=/mnt fedora ls -l /mnt
smollm2
