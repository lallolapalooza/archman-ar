docker-node-update(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم دوكر DOCKER(1)

الاسم

docker-node-update - تحديث عقدة

الاستخدام

docker node update [خيارات] العقدة

الوصف

تحديث عقدة

الخيارات

--availability="" توفر العقدة ("نشط"، "إيقاف مؤقت"، "تصريف")

--label-add= إضافة أو تحديث تسمية العقدة ("مفتاح=قيمة")

--label-rm= إزالة تسمية العقدة إذا كانت موجودة

--role="" دور العقدة ("عامل"، "مدير")
