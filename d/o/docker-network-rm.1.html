docker-network-rm(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-network-rm - إزالة شبكة أو أكثر

الملخص

docker network rm NETWORK [NETWORK...]

الوصف

يزيل شبكة أو أكثر بالاسم أو المعرّف. لإزالة شبكة، يجب عليك أولاً فصل أي حاويات متصلة بها. لإزالة الشبكة المسماة 'my-network':

$ docker network rm my-network

لحذف شبكات متعددة في أمر docker network rm واحد، قم بتوفير أسماء أو معرفات شبكات متعددة. يحاول المثال التالي حذف شبكة بالمعرف 3695c422697f وشبكة مسماة my-network:

$ docker network rm 3695c422697f my-network

عند تحديد شبكات متعددة، يحاول الأمر حذف كل منها بالتتابع. إذا فشل حذف شبكة واحدة، يستمر الأمر في الشبكة التالية في القائمة ويحاول حذفها. يبلغ الأمر عن النجاح أو الفشل لكل عملية حذف.

خيارات

-f, --force[=false] لا تعطي خطأ إذا لم تكن الشبكة موجودة
