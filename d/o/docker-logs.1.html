docker-logs(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-logs - جلب سجلات حاوية

المُلَخَّص

docker logs [OPTIONS] CONTAINER

الوصف

اسم مستعار لـ docker container logs.

الخيارات

--details[=false] عرض تفاصيل إضافية مقدمة للسجلات

-f, --follow[=false] متابعة مخرجات السجل

--since="" عرض السجلات منذ الطابع الزمني (مثل "2013-01-02T13:23:37Z") أو نسبي (مثل "42m" لمدة 42 دقيقة)

-n, --tail="all" عدد الأسطر المراد عرضها من نهاية السجلات

-t, --timestamps[=false] عرض الطوابع الزمنية

--until="" عرض السجلات قبل طابع زمني (مثل "2013-01-02T13:23:37Z") أو نسبي (مثل "42m" لمدة 42 دقيقة)
