podman-machine-reset(1) دليل الأوامر العامة podman-machine-reset(1)

الاسم

podman-machine-reset - إعادة تعيين آلات Podman والبيئة

الملخص

podman machine reset [خيارات]

الوصف

إعادة تعيين بيئة آلة Podman الخاصة بك. يقوم هذا الأمر بإيقاف أي آلات قيد التشغيل ثم إزالتها. بعد ذلك، تتم إزالة ملفات التكوين والبيانات. ستشمل ملفات البيانات صور أقراص الآلات وأي صور مخبأة تم سحبها سابقًا. عند تشغيل هذا الأمر، سيتم حذف جميع آلات Podman الخاصة بك.

الخيارات

--force, -f

إعادة تعيين بدون تأكيد.

--help

طباعة بيان الاستخدام.

أمثلة

$ podman machine reset
Warning: this command will delete all existing podman machines
and all of the configuration and data directories for Podman machines
The following machine(s) will be deleted:
dev
podman-machine-default
Are you sure you want to continue? [y/N] y
$

إعادة تعيين قسرية بدون تأكيد.

$ podman machine reset --force
$
