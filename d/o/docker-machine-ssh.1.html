podman-machine-ssh(1) دليل الأوامر العامة podman-machine-ssh(1)

الاسم

podman-machine-ssh - SSH إلى آلة افتراضية

ملخص

podman machine ssh [خيارات] [اسم] [أمر [وسيط ...]]

الوصف

SSH إلى آلة افتراضية مدارة بواسطة Podman وتنفيذ أمر اختياري على الآلة الافتراضية. ما لم تستخدم الآلة الافتراضية الافتراضية، يجب أن يكون الوسيط الأول هو اسم الآلة الافتراضية. يمكن أن يتبع الأمر الاختياري بعد ذلك. إذا لم يتم توفير أمر، فسيتم إنشاء جلسة تفاعلية مع الآلة الافتراضية.

يتم تمرير رمز الخروج من أمر ssh إلى مستدعي podman machine ssh، انظر رموز الخروج ⟨#Exit-Codes⟩.

اسم الآلة الافتراضية الافتراضي هو podman-machine-default. إذا لم يتم تحديد اسم آلة كوسط، فسيتم SSH إلى podman-machine-default.

للمستخدمين الذين لا يستخدمون صلاحيات الجذر فقط.

خيارات

--help

طباعة بيان الاستخدام.

--username=اسم

اسم المستخدم المراد استخدامه عند SSH إلى الآلة الافتراضية.

رموز الخروج

يعطي رمز الخروج من podman machine ssh معلومات حول سبب فشل الأمر. عندما تخرج أوامر podman machine ssh برمز غير صفري، فإن رموز الخروج تتبع معيار chroot، انظر أدناه:

125 الخطأ مع podman نفسه

$ podman machine ssh --foo; echo $?
Error: unknown flag: --foo
125

126 تنفيذ أمر محتوى و الأمر لا يمكن استدعاؤه

$ podman machine ssh /etc; echo $?
Error: fork/exec /etc: permission denied
126

127 تنفيذ أمر محتوى و الأمر لا يمكن العثور عليه

$ podman machine ssh foo; echo $?
Error: fork/exec /usr/bin/bogus: no such file or directory
127

رمز الخروج رمز خروج الأمر المحتوى

$ podman machine ssh /bin/sh -c 'exit 3'; echo $?
3

أمثلة

للحصول على جلسة تفاعلية مع آلة Podman الافتراضية:

SSH إلى آلة Podman الافتراضية.

$ podman machine ssh

تشغيل أمر داخل آلة Podman الافتراضية عبر ssh.

$ podman machine ssh myvm

تشغيل أمر داخل آلة Podman المحددة عبر ssh.

$ podman machine ssh myvm rpm -q podman

podman(1), podman-machine(1)
