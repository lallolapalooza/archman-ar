docker-attach(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-attach - ربط الإدخال القياسي، الإخراج، وتدفقات الخطأ المحلية ب حاوية قيد التشغيل

ملخص

docker attach [خيارات] CONTAINER

الوصف

اسم مستعار لـ docker container attach.

الخيارات

--detach-keys="" تجاوز تسلسل المفاتيح لفصل حاوية

--no-stdin[=false] لا تقم بربط STDIN

--sig-proxy[=true] تمرير جميع الإشارات المستلمة إلى العملية
