DORCSD

الغرض:

!>
!> DORCSD يحسب تفكيك CS للمصفوفة المتعامدة المقسمة X بحجم M*M:
!>
!>                                 [  I  0  0 |  0  0  0 ]
!>                                 [  0  C  0 |  0 -S  0 ]
!>     [ X11 | X12 ]   [ U1 |    ] [  0  0  0 |  0  0 -I ] [ V1 |    ]**T
!> X = [-----------] = [---------] [---------------------] [---------]   .
!>     [ X21 | X22 ]   [    | U2 ] [  0  0  0 |  I  0  0 ] [    | V2 ]
!>                                 [  0  S  0 |  0  C  0 ]
!>                                 [  0  0  I |  0  0  0 ]
!>
!> X11 هي مصفوفة بحجم P*Q. المصفوفات المتعامدة U1، U2، V1، و V2 هي بحجم P*P،
!> (M-P)*(M-P)، Q*Q، و (M-Q)*(M-Q) على التوالي. C و S هما مصفوفتان قطريتان غير سالبين بحجم R*R تحققان C^2 + S^2 = I، حيث R = MIN(P,M-P,Q,M-Q).
!>
