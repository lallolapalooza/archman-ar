docker-info(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-info - عرض معلومات على مستوى النظام

الملخص

docker info [OPTIONS]

الوصف

اسم بديل لـ docker system info.

خيارات

-f, --format="" تنسيق الإخراج باستخدام قالب مخصص: 'json': طباعة بتنسيق JSON 'TEMPLATE': طباعة الإخراج باستخدام قالب Go المحدد. راجع https://docs.docker.com/go/formatting/ لمزيد من المعلومات حول تنسيق الإخراج باستخدام القوالب
