التراخيص: GPL

doctext(1) doctext(1)

الاسم

doctext - إنشاء صفحات توثيق من ملفات المصدر

الملخص

doctext [ -mpath path ] [ -ext n ] [ -I filename ] [ -latex ]
[ -html ] [ -index filename ] [ -indexdir filename ]
[ -jumpfile filename ] [ -outfile filename ]
[ -mapref filename ] [ -nolocation ] [ -location ]
[ -defn defnfile ] [ -dosnl ] [ -skipprefix name ]
[ -ignore string ] [ -oldargstyle ]
[ -heading string ] [ -basedir dirname ] filenames
[ -Wargdesc ] [ -Wnone ]

معلمات الإدخال

-mpath path
- يحدد المسار حيث سيتم كتابة صفحات الدليل
-ext n
- يحدد الامتداد (1-9، l، إلخ)
-nolocation
- لا يعطي اسم الملف الذي تم فيه معلومات صفحة الدليل
-I filename
- يحتوي اسم الملف على تضمينات عامة مطلوبة لهذه الروتينات
-latex
- إنشاء مخرجات LaTeX بدلاً من ملفات بتنسيق الدليل
-html
- إنشاء مخرجات HTML (WWW) بدلاً من ملفات بتنسيق الدليل
-man
- إنشاء مخرجات man (nroff) (الافتراضي)
-index filename
- إنشاء ملف فهرس مناسب لـ tohtml (لإنشاء ملفات WWW)
-defn defnfilename
- قراءة الأوامر من هذا الملف بعد تحميل الأوامر الافتراضية
-mapref filename
- قراءة قاعدة بيانات الارتباط التشعبي وتطبيقها على المخرجات
-indexdir dirname
- يحدد الدليل الجذر لإدخالات ملف الفهرس. على سبيل المثال
-index foo.cit -indexdir \"http://www.mcs.anl.gov/foo/man\"
-outfile filename
- وضع صفحات الدليل في الملف المحدد
-heading name
- اسم للعنوان (وسط السطر العلوي)
-quotefmt
- دعم '\\tt' و `\\em`
-oldargstyle
- السماح بـ '. ' متعددة لقائمة وسيطات، بدلاً من استخدام '+ .... -' لقوائم الوسيطات ذات الإدخالات المتعددة.
-skipprefix name
- تخطي 'name' في بداية كل سطر. يمكن استخدام هذا لمصادر Fortran أو Shell
-ignore string
- تخطي 'name' في ملخص دالة. يمكن استخدام هذا لإزالة الكلمات الرئيسية الخاصة المطلوبة لبناء الروتين ولكن غير مطلوبة للمستخدم (على سبيل المثال، كلمات رئيسية تصدير خاصة عند بناء DLLs)
-keyword filename
- وضع إدخالات الكلمات الرئيسية في نهاية الملف المحدد
-locdir directory
- يستخدم الدليل في حقل الموقع (Location:)
-dosnl
- إنشاء ملفات بنمط DOS (رجوع-سطر جديد بدلاً من سطر جديد)
filenames
- أسماء الملفات التي سيتم استخراج المستندات منها
-Wargdesc
- تحذير بشأن الوسيطات التي لا تحتوي على وصف
-Wnone
- إيقاف التحذيرات
