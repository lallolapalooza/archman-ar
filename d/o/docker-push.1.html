docker-push(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) أدلة مستخدم Docker DOCKER(1)

الاسم

docker-push - تحميل صورة إلى مسجل

ملخص

docker push [خيارات] NAME[:TAG]

الوصف

اسم مستعار لـ docker image push.

الخيارات

-a, --all-tags[=false] تحميل جميع العلامات للصورة إلى المستودع

--platform="" تحميل بيان خاص بمنصة كصورة أحادية المنصة إلى المسجل. لن يتم تحميل فهرس الصورة، مما يعني أن البيانات الأخرى، بما في ذلك الإقرارات، لن يتم الحفاظ عليها. 'os[/arch[/variant]]: منصة صريحة (على سبيل المثال، linux/amd64)

-q, --quiet[=false] كتم الإخراج المطول
