docker-history(1)

الحزمة: docker

التراخيص: Apache-2.0

DOCKER(1) Docker User Manuals DOCKER(1)

الاسم

docker-history - عرض تاريخ صورة

الملخص

docker history [OPTIONS] IMAGE

الوصف

اختصار للأمر docker image history.

الخيارات

--format="" تنسيق الإخراج باستخدام قالب مخصص: 'table': طباعة الإخراج بتنسيق جدول مع رؤوس الأعمدة (افتراضي) 'table TEMPLATE': طباعة الإخراج بتنسيق جدول باستخدام قالب Go المحدد 'json': طباعة بتنسيق JSON 'TEMPLATE': طباعة الإخراج باستخدام قالب Go المحدد. راجع https://docs.docker.com/go/formatting/ لمزيد من المعلومات حول تنسيق الإخراج باستخدام القوالب

-H, --human[=true] طباعة الأحجام والتواريخ بتنسيق يمكن قراءته بسهولة

--no-trunc[=false] عدم اقتطاع الإخراج

--platform="" عرض التاريخ للمنصة المحددة. بتنسيق "os[/arch[/variant]]" (على سبيل المثال، "linux/amd64")

-q, --quiet[=false] عرض معرفات الصور فقط
