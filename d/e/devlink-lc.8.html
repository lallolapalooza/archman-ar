الاسم

devlink-lc - تكوين بطاقة الخط devlink

الملخص


devlink [ خيارات ] lc { أمر | help }

خيارات := { -V[ersion] }

devlink lc set DEV lc LC_INDEX [ type { LC_TYPE | notype } ]

devlink lc show [ DEV [ lc LC_INDEX ] ]

devlink lc help

الوصف

devlink lc set - تغيير سمات بطاقة الخط

DEV
يحدد جهاز devlink المراد العمل عليه.


التنسيق هو:


BUS_NAME/BUS_ADDRESS

lc LC_INDEX
يحدد فهرس فتحة بطاقة الخط المراد تعيينها.
type {
LC_TYPE | notype } نوع بطاقة الخط المراد توفيرها. يوفر كل برنامج تشغيل قائمة بأنواع بطاقات الخط المدعومة والتي تظهر في مخرجات الأمر devlink lc show .

devlink lc show - عرض سمات بطاقة الخط

DEV
يحدد جهاز devlink المراد العمل عليه. إذا تم حذف وسيطتي lc و DEV، فسيتم سرد جميع بطاقات الخط لجميع الأجهزة.
lc LC_INDEX
يحدد فهرس فتحة بطاقة الخط المراد عرضها.

أمثلة

devlink lc show

يعرض حالة جميع بطاقات الخط في النظام.

devlink lc show pci/0000:01:00.0 lc 1

يعرض حالة بطاقة الخط ذات الفهرس 1.

devlink lc set pci/0000:01:00.0 lc 1 type 16x100G

يعين نوع بطاقة الخط المحددة إلى النوع 16x100G.

devlink lc set pci/0000:01:00.0 lc 1 notype

يمسح التزويد على بطاقة الخط.
