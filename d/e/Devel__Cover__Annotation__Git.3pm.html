Devel::Cover::Annotation::Git(3) توثيق مساهمات المستخدمين في Perl Devel::Cover::Annotation::Git(3)

الاسم

Devel::Cover::Annotation::Git - إضافة تعليقات بمعلومات git

الإصدار

الإصدار 1.51

ملخص

cover -report text -annotation git  # أو أي نوع تقرير آخر

الوصف

إضافة معلومات تعليقات git إلى تقارير التغطية. تم تصميم هذه الوحدة ليتم استدعاؤها من برنامج "cover".
