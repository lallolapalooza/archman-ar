devlink-dpipe(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

DEVLINK-DPIPE(8) Linux DEVLINK-DPIPE(8)

الاسم

devlink-dpipe - تصور مسار بيانات devlink

الموجز


devlink [ خيارات ] dpipe { table | header } { الأمر | help }

خيارات := { -V[ersion] }

devlink dpipe table show DEV [ name اسم_الجدول ]

devlink dpipe table set DEV name اسم_الجدول

devlink dpipe table dump DEV name اسم_الجدول

devlink dpipe header show DEV

devlink dpipe help

الوصف

devlink dpipe table show - عرض سمات جدول devlink dpipe

name اسم_الجدول
يحدد الجدول المراد العمل عليه.

devlink dpipe table set - تعيين سمات جدول devlink dpipe

name اسم_الجدول
يحدد الجدول المراد العمل عليه.

devlink dpipe table dump - تفريغ مدخلات جدول devlink dpipe

name اسم_الجدول
يحدد الجدول المراد العمل عليه.

devlink dpipe header show - عرض سمات رأس devlink dpipe

name اسم_الجدول
يحدد الجدول المراد العمل عليه.

أمثلة

devlink dpipe table show pci/0000:01:00.0

يعرض جميع جداول dpipe على جهاز devlink المحدد.

devlink dpipe table show pci/0000:01:00.0 name mlxsw_erif

يعرض جدول mlxsw_erif dpipe على جهاز devlink المحدد.

devlink dpipe table set pci/0000:01:00.0 name mlxsw_erif counters_enabled true

يقوم بتشغيل العدادات على جدول mlxsw_erif.

devlink dpipe table dump pci/0000:01:00.0 name mlxsw_erif

يقوم بتفريغ محتويات جدول mlxsw_erif.

devlink dpipe header show pci/0000:01:00.0

يعرض جميع رؤوس dpipe على جهاز devlink المحدد.
