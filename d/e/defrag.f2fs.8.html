defrag.f2fs(8)

الحزمة: f2fs-tools

التراخيص: GPL

DEFRAG.F2FS(8) دليل مدير النظام DEFRAG.F2FS(8)

الاسم

defrag.f2fs - إعادة تحديد موقع الكتل في منطقة معينة إلى المنطقة المحددة

الملخص

defrag.f2fs [ -s عنوان كتلة البدء ] [ -l عدد الكتل ] [ -t عنوان كتلة الهدف ] [ -i الاتجاه ] [ -d مستوى التصحيح ] جهاز

الوصف

defrag.f2fs يستخدم لنقل عدد محدد من الكتل بدءًا من عنوان كتلة معطى إلى عنوان الكتلة الهدف مع اتجاه. جهاز هو الملف الخاص المقابل للجهاز (مثل /dev/sdXX).

على سبيل المثال، # defrag.f2fs -s 0x4000 -l 0x100 -t 0x10000 -i /dev/sdb1

هذا ينقل الكتل بين 0x4000 و 0x4100 إلى المنطقة اليسرى من 0x10000.

رمز الخروج الذي يعيده defrag.f2fs هو 0 عند النجاح و -1 عند الفشل.

الخيارات

-s عنوان كتلة البدء
تحديد عنوان كتلة البدء.
-l عدد الكتل
تحديد عدد الكتل المراد نقلها.
-t عنوان كتلة الهدف
تحديد عنوان كتلة الوجهة.
-i الاتجاه
تعيين الاتجاه إلى اليسار. إذا لم يتم تعيينه، يصبح الاتجاه الافتراضي هو اليمين.
-d مستوى التصحيح
تحديد مستوى خيارات التصحيح. الرقم الافتراضي هو 0، والذي يعرض رسائل تصحيح أساسية.
