الاسم

deadline_test - برنامج اختبار عالي الدقة

الوصف

يستخدم هذا البرنامج لاختبار مجدول المهام deadline (مهام SCHED_DEADLINE)

الملخص

deadline_test [ -hb ] [ -c CPUSET ] [ -i INTV ] [ -p PERCENT ] [ -P PERCENT ] [ -r PRIO ] [ -s STEP ] [ -t NUM ]

الخيارات

-b
ربط على آخر معالج. (اختصار لـ -c <lastcpu>)
-c CPUSET
قائمة مفصولة بفاصلات أو شرطات من المعالجات لتشغيل مهام deadline عليها
-h
عرض قائمة المساعدة هذه
-i INTV
أقصر موعد نهائي للمهام
-p PERCENT
النسبة المئوية لعرض النطاق الترددي للاستخدام (1-90%)
-P PERCENT
النسبة المئوية لوقت التشغيل لإكمال التنفيذ (الافتراضي 100%)
-r PRIO
إضافة مهمة RT ذات أولوية معينة لإجهاد النظام
-s STEP
المقدار المطلوب لزيادة الموعد النهائي لكل مهمة بالميكروثانية (الافتراضي 500 ميكروثانية)
-t NUM
عدد الخيوط التي سيتم تشغيلها كـ deadline (الافتراضي 1)
