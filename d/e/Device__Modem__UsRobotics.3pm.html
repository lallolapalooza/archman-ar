Device__Modem__UsRobotics(3pm)

الحزمة: perl-device-modem

التراخيص: GPL, PerlArtistic

Device::Modem::UsRobotics(3) توثيق مقدم من مستخدمي Perl Device::Modem::UsRobotics(3)

الاسم

Device::Modem::UsRobotics - امتدادات لمودم USR للتحكم في وضع الذات

الملخص

use Device::Modem::UsRobotics;
my $modem = Device::Modem::UsRobotics->new( port => '/dev/ttyS1' );
$modem->connect( baudrate => 9600 );
my %info = $modem->messages_info();
print "There are $info{unreleased_voice_msg} unread voice messages on $info{stored_voice_msg} total\n";
print "There are $info{unreleased_fax_msg} unread fax messages on $info{stored_fax_msg} total\n";
# Get details about message n. X
my %msg = $modem->message_info(1);
      index type information attributes status day hour minute
      callerid page addresshigh addresslow checksum
print 'This is a ', ($msg{type} == 2 ? 'voice' : 'fax'), 'message', "\n";
print 'It came from no. ', $msg{callerid}, "\n";
# ...
# Now clear all messages
$modem->clear_memory();

تحذير

لم يتم توثيق هذه الوحدة بعد، وهي قيد التطوير الأولي. حتى الآن، تقرأ معلومات رسائل الصوت/الفاكس بشكل صحيح، ولكن عند حفظ رسائل الصوت على القرص، قد يتم فك تشفيرها بشكل غير صحيح أحيانًا.

لذلك، إذا كنت بحاجة إلى برنامج يعمل، تحقق من TkUsr القديم الجيد بواسطة Ludovic Drolez، ما لم تكن ترغب في المساعدة في تطوير Device::Modem::UsRobotics.

التوثيق ليتم إكماله من الآن فصاعدًا.....

الأساليب

clear_memory()

يستخدم لمسح مساحة ذاكرة المودم بشكل دائم. توجد مساحات ذاكرة منفصلة، واحدة لرسائل الصوت/الفاكس وواحدة لإعدادات المستخدم. أمثلة:

    $modem->clear_memory('user');     # أو $modem->clear_memory(1)
$modem->clear_memory('messages'); # أو $modem->clear_memory(2)

لمسح كليهما، يمكنك استخدام:

$modem->clear_memory('all');      # أو $modem->clear_memory(0);

المعلمات:

$memtype
سلسلة نصية أو عدد صحيح يحدد نوع الذاكرة المراد مسحها، حيث 0 تعني "الكل"، 1 تعني ذاكرة "المستخدم"، 2 تعني ذاكرة "الرسائل".
