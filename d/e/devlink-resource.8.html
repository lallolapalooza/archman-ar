devlink-resource(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

DEVLINK-RESOURCE(8) Linux DEVLINK-RESOURCE(8)

الاسم

devlink-resource - تكوين موارد جهاز devlink

الملخص


devlink [ خيارات ] resource { أمر | help }

خيارات := { -v[erbose] }

devlink resource show DEV

devlink resource help

devlink resource set DEV path RESOURCE_PATH size RESOURCE_SIZE

الوصف

devlink resource show - عرض موارد جهاز devlink

DEV - يحدد جهاز devlink للعرض.


التنسيق هو:
اسم_الناقل/عنوان_الناقل

devlink resource set - تعيين حجم المورد لمورد محدد

DEV - يحدد جهاز devlink.

path RESOURCE_PATH
مسار المورد.
size RESOURCE_SIZE
حجم المورد الجديد.

أمثلة

devlink resource show pci/0000:01:00.0

يعرض موارد جهاز devlink المحدد.

devlink resource set pci/0000:01:00.0 path /kvd/linear size 98304

يعين حجم المورد المحدد لجهاز devlink المحدد.
