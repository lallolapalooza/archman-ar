Devel__Cover__Web(3pm)

الحزمة: perl-devel-cover

التراخيص: PerlArtistic, GPL

Devel::Cover::Web(3) وثائق مساهمة المستخدم لـ Perl Devel::Cover::Web(3)

الاسم

Devel::Cover::Web - ملفات لجافاسكريبت أو CSS

الإصدار

الإصدار 1.51

الملخص

use Devel::Cover::Web "write_file";
write_file $directory, $file;
write_file $directory, "all";
write_file $directory, "js";
write_file $directory, "css";

الوصف

تسمح هذه الوحدة بكتابة ملفات جافاسكريبت و CSS إلى دليل محدد.

الإجراءات الفرعية

write_file($directory, $file)

إخراج الملف المحدد إلى الدليل المحدد.

انظر أيضًا

Devel::Cover::Report::Html_basic
cpancover
