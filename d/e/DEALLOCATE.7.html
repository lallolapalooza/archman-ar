DEALLOCATE(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DEALLOCATE(7) وثائق PostgreSQL 18.1 DEALLOCATE(7)

الاسم

DEALLOCATE - إلغاء تخصيص عبارة مُعدّة مسبقًا

الملخص

DEALLOCATE [ PREPARE ] { name | ALL }

الوصف

يُستخدم الأمر DEALLOCATE لإلغاء تخصيص عبارة SQL مُعدّة مسبقًا. إذا لم تقم بإلغاء تخصيص عبارة مُعدّة مسبقًا بشكل صريح، فسيتم إلغاء تخصيصها عند انتهاء الجلسة.

لمزيد من المعلومات حول العبارات المُعدة مسبقًا، راجع PREPARE(7).

المعلمات

PREPARE

يتم تجاهل هذه الكلمة المفتاحية.

name

اسم العبارة المُعدة مسبقًا لإلغاء تخصيصها.

ALL

إلغاء تخصيص جميع العبارات المُعدة مسبقًا.

التوافق

يتضمن معيار SQL عبارة DEALLOCATE، ولكنه مخصص فقط للاستخدام في SQL المضمن.

انظر أيضًا

EXECUTE(7), PREPARE(7)
