depdiagram-generate(1)

الحزمة: kapidox

التراخيص: LGPL

depdiagram-generate(1) دليل الأوامر العام depdiagram-generate(1)

الاسم

depdiagram-generate - أدوات إنشاء وثائق واجهة برمجة تطبيقات KDE

الإصدار

5.13.0

الاستخدام

الاستخدام: depdiagram-generate [-h] [-o FILE] [--qt] [--detailed]
[--framework FRAMEWORK]
dot_files [dot_files ...]

الوسائط الموضعية:
dot_files

الوسائط الاختيارية:
-h, --help عرض رسالة المساعدة هذه والخروج
-o FILE, --output FILE
الإخراج إلى FILE
--qt إظهار مكتبات Qt
--detailed إظهار الأهداف داخل الأطر
--framework FRAMEWORK
إظهار تبعيات الإطار FRAMEWORK فقط
