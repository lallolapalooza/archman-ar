destroy(n)

الحزمة: tk

destroy(n) أوامر Tk المضمنة destroy(n)

الاسم

destroy - تدمير نافذة أو أكثر

الملخص

destroy ?window window ...?

الوصف

يقوم هذا الأمر بحذف النوافذ المحددة بواسطة الوسيطات window، بالإضافة إلى جميع النوافذ المنحدرة منها. إذا تم حذف النافذة “.”، فسيتم تدمير جميع النوافذ وسيخرج التطبيق (عادةً). يتم تدمير النوافذ بالترتيب، وإذا حدث خطأ أثناء تدمير نافذة، يتوقف الأمر دون تدمير النوافذ المتبقية. لا يتم إرجاع خطأ إذا كانت window غير موجودة.

مثال

تدمير جميع مربعات الاختيار التي هي أطفال مباشرون للودجت المحدد:

proc killCheckbuttonChildren {parent} {
   foreach w [winfo children $parent] {
      if {[winfo class $w] eq "Checkbutton"} {
         destroy $w
      }
   }
}
