dawson(3)

الحزمة: libcerf

التراخيص: MIT

build::libcerf::src::libcerf::man::dawson(3) دليل libcerf build::libcerf::src::libcerf::man::dawson(3)

الاسم

cdawson, dawson - تكامل داسون

الملخص

#include <cerf.h>

double _Complex cdawson ( double _Complex z );

double dawson ( double x );

الوصف

الدالة cdawson تُرجع تكامل داسون D(z) = exp(-z^2) integral from 0 to z exp(t^2) dt = sqrt(pi)/2 * exp(-z^2) * erfi(z).

الدالة dawson تأخذ وسيطًا حقيقيًا x، وتُرجع النتيجة الحقيقية D(x).

انظر أيضًا

يعتمد حساب D(z) على دالة فادييفا w_of_z(3)؛ لحساب D(x)، يتم استخدام الجزء التخيلي im_w_of_x(3).

دوال الخطأ المركبة الأخرى: w_of_z(3)، voigt(3)، cerf(3)، erfcx(3)، erfi(3).
