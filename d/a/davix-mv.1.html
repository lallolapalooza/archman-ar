davix-mv(1)

الحزمة: davix

التراخيص: LGPL-2.1-or-later

DAVIX-MV(1) أداة سرد DAVIX-MV(1)

الاسم

davix-mv - أداة إعادة تسمية تستند إلى libdavix

الملخص


davix-mv [خيارات]... الرابط-الأصلي الرابط-الجديد

الوصف

davix-mv هي أداة لإعادة تسمية/نقل الموارد باستخدام خدمات متوافقة مع HTTP، Webdav أو REST.
يمكن للأوامر إعادة تسمية/نقل الموارد وحاويات الموارد.

يتم تشغيل davix-mv بواسطة libdavix. راجع libdavix(3) للحصول على التفاصيل.

الخيارات

خيارات مشتركة:

--debug
وضع التصحيح
--header, -H
إضافة حقل رأس إلى الطلب (مثال: -H "Depth: 1" )
--help, -h
عرض رسالة المساعدة هذه
--metalink OPT
دعم Metalink. (OPT=failover[الافتراضي]|no)
--module, -P PLUGIN_NAME
تحميل مكون إضافي أو ملف تعريف بالاسم
--redirection OPT
دعم إعادة التوجيه الشفاف. (OPT=yes[الافتراضي]|no)
--proxy, -x URL
عنوان URL لخادم وكيل SOCKS5. (مثال: socks5://login:pass@socks.example.org)
--trace
تتبع نطاقات محددة، تشمل الخيارات:
file - واجهة ملفات Davix
posix - واجهة Davix POSIX
xml - إخراج محلل XML
ssl - تفاصيل SSL والشهادات
header - رؤوس استعلامات HTTP
body - جسم HTTP
chain - معلومات سلاسل الإدخال/الإخراج
core - معلومات التكوين وغيرها
grid - معلومات أخرى من جهات خارجية
socket - معلومات المقبس
locks - معلومات قفل WebDAV
all - يتتبع كل شيء
--version
عرض الإصدار

خيارات الأمان:

--capath CA_path
إضافة دليل سلطة شهادات إضافي
--cert, -E cred_path
شهادة العميل بتنسيق PEM
--key priv_path
مفتاح خاص بتنسيق PEM
--insecure, -k
تعطيل فحوصات مصادقة SSL
--userlogin
تسجيل دخول المستخدم لمصادقة اسم المستخدم/كلمة المرور
--userpass
كلمة مرور المستخدم لمصادقة اسم المستخدم/كلمة المرور
--s3secretkey
مصادقة AWS S3: المفتاح السري
--s3accesskey
مصادقة AWS S3: مفتاح الوصول
--s3region
مصادقة AWS S3: المنطقة
--s3token
رمز الأمان AWS S3 - يستخدم مع بيانات اعتماد STS المؤقتة
--s3alternate
حدد هذا العلم إذا كنت بحاجة إلى استخدام عنوان URL S3 المستند إلى المسار
--azurekey
مفتاح مصادقة Azure

أمثلة

إعادة تسمية مورد عبر HTTP
davix-mv http://example.org/rename_me.txt http://example.org/thanks.txt

نقل مورد على شبكة تخزين Grid مع مصادقة VOMS
davix-mv -P grid davs://grid-storage.example.org/dir1/dir2/move_me.txt davs://grid-storage.example.org/dir1/move_me.txt
