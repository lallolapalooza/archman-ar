dane_query_tlsa(3) gnutls dane_query_tlsa(3)

الاسم

dane_query_tlsa - واجهة برمجة التطبيقات (API)

ملخص

#include <gnutls/dane.h>

int dane_query_tlsa(dane_state_t s, dane_query_t * r, const char * host, const char * proto, unsigned int port);

الوسائط

dane_state_t s
هيكل حالة DANE
dane_query_t * r
هيكل لوضع النتيجة
const char * host
اسم المضيف للبحث عنه.
const char * proto
نوع البروتوكول (tcp، udp، إلخ)
unsigned int port
رقم منفذ الخدمة (مثل 443).

الوصف

ستقوم هذه الدالة بالاستعلام من خادم DNS عن بيانات TLSA (DANE) للمضيف المحدد.

يعيد

عند النجاح، يتم إرجاع DANE_E_SUCCESS (0)، وإلا يتم إرجاع قيمة خطأ سالبة.
