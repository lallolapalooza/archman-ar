davix-http(1)

الحزمة: davix

التراخيص: LGPL-2.1-or-later

DAVIX-HTTP(1) أداة طلب HTTP DAVIX-HTTP(1)

الاسم

davix-http - أداة استعلام HTTP تعتمد على libdavix

الملخص

davix-http [خيارات]... عنوان_url

الوصف

davix-http هي أداة تستخدم libdavix لتنفيذ استعلامات HTTP.
يمكن استخدامها للتفاعل مع خدمات الويب RESTful.

انظر libdavix(3) للتفاصيل.

الخيارات

خيارات الطلب:

--data
محتوى الطلب
--request, -X
طريقة الطلب المستخدمة (مثال: GET، PUT، PROPFIND، إلخ.)

الخيارات الشائعة:

--debug
وضع التصحيح
--header, -H
إضافة حقل رأس إلى الطلب (مثال: -H "Depth: 1")
--help, -h
عرض رسالة المساعدة هذه
--metalink OPT
دعم Metalink. (OPT=failover[افتراضي]|no)
--module, -P PLUGIN_NAME
تحميل إضافة أو ملف تعريف بالاسم
--redirection OPT
دعم إعادة التوجيه الشفاف. (OPT=yes[افتراضي]|no)
--proxy, -x URL
خادم وكيل SOCKS5. (مثال: socks5://login:pass@socks.example.org)
--trace
تتبع نطاقات محددة، الخيارات تشمل:
file - واجهة ملف Davix
posix - واجهة POSIX Davix
xml - خرج محلل XML
ssl - تفاصيل SSL والشهادات
header - رؤوس استعلامات HTTP
body - نصوص HTTP
chain - معلومات سلاسل الإدخال/الإخراج
core - معلومات التكوين وغيرها
grid - معلومات أخرى من أطراف ثالثة
socket - معلومات المقبس
locks - معلومات قفل WebDAV
all - تتبع كل شيء
--version
عرض الإصدار

خيارات الأمان:

--capath CA_path
إضافة سلطة شهادات إضافية
--cert, -E cred_path
شهادة العميل بصيغة PEM
--key priv_path
المفتاح الخاص بصيغة PEM
--insecure, -k
تعطيل فحوصات شهادات SSL
--userlogin
اسم المستخدم للمصادقة بالاسم/كلمة المرور
--userpass
كلمة مرور المستخدم للمصادقة بالاسم/كلمة المرور
--s3secretkey
المصادقة AWS S3: مفتاح سري
--s3accesskey
المصادقة AWS S3: مفتاح وصول
--s3region
المصادقة AWS S3: المنطقة
--s3token
رمز الأمان AWS S3 - يستخدم مع بيانات اعتماد STS المؤقتة
--s3alternate
حدد هذا العلم إذا كنت بحاجة إلى استخدام عنوان URL S3 المستند إلى المسار
--azurekey
مفتاح المصادقة Azure

أمثلة

تنفيذ طلب GET عبر HTTP
davix-http http://example.org/

تنفيذ طلب HEAD عبر HTTP + TLS مع مصادقة المستخدم
davix-http -X HEAD https://login:password@example.org

تنفيذ طلب PUT عبر S3 عبر HTTPS ومحتوى أساسي
davix-http -X PUT s3s://bucket.example.org/mifile -d "Hello World"
