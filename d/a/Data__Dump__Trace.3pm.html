Data__Dump__Trace(3pm)

الحزمة: perl-data-dump

التراخيص: PerlArtistic, GPL

Data::Dump::Trace(3) وثائق مساهمة المستخدم من بيرل Data::Dump::Trace(3)

الاسم

Data::Dump::Trace - مساعدات لتتبع استدعاءات الدوال والأساليب

الملخص

use Data::Dump::Trace qw(autowrap mcall);
autowrap("LWP::UserAgent" => "ua", "HTTP::Response" => "res");
use LWP::UserAgent;
$ua = mcall(LWP::UserAgent => "new");      # بدلاً من LWP::UserAgent->new;
$ua->get("http://www.example.com")->dump;

الوصف

الوظائف التالية متوفرة:

autowrap( $class )
autowrap( $class => $prefix )
autowrap( $class1 => $prefix1, $class2 => $prefix2, ... )
autowrap( $class1 => \%info1, $class2 => \%info2, ... )
تسجيل الفئات التي يتم تغليف كائناتها تلقائيًا عند إرجاعها بواسطة إحدى وظائف الاستدعاء التالية. إذا تم توفير $prefix فسيتم استخدامه لتسمية الكائنات.

البديل هو تمرير تجزئة %info لكل فئة. المفاتيح المعترف بها هي:

prefix => $string
سلسلة البادئة المستخدمة لتسمية كائنات هذا النوع.
proto => \%hash
تجزئة نماذج أولية لاستخدامها للأساليب عند تغليف كائن.
wrap( name => $str, func => \&func, proto => $proto )
wrap( name => $str, obj => $obj, proto => \%hash )
ترجع دالة أو كائن مغلف. عند استدعاء دالة مغلفة، يتم طباعة تتبع بعد عودة الدالة الأساسية. عند استدعاء أسلوب على كائن مغلف، يتم طباعة تتبع بعد عودة الأساليب على الكائنات الأساسية.

انظر "النماذج الأولية" لوصف الوسيط "proto".

call( $name, \&func, $proto, @ARGS )
يستدعي الدالة المعطاة بالوسائط المعطاة. سيستخدم التتبع $name كاسم للدالة.

انظر "النماذج الأولية" لوصف الوسيط $proto.

mcall( $class, $method, $proto, @ARGS )
mcall( $object, $method, $proto, @ARGS )
يستدعي الأسلوب المعطى بالوسائط المعطاة.

انظر "النماذج الأولية" لوصف الوسيط $proto.

trace( $symbol, $prototype )
يستبدل الدالة المعطاة بواسطة $symbol بدالة مغلفة.

النماذج الأولية

ملاحظة: صيغة سلسلة النموذج الأولي الموصوفة هنا تجريبية ومن المحتمل أن تتغير في الإصدارات اللاحقة من هذه الواجهة.

يمكن للوسيط $proto إلى call() و mcall() اختياريًا توفير نموذج أولي لاستدعاء الدالة. هذا يعطي المتتبع تلميحات حول كيفية تنسيق قوائم الوسائط بشكل أفضل وما إذا كانت هناك وسائط داخلية/خارجية أو خارجية. الشكل العام لسلسلة النموذج الأولي هو:

<arguments> = <return_value>

النموذج الأولي الافتراضي هو "@ = @"؛ قائمة قيم كمدخلات وقائمة قيم كمخرجات.

يمكن استخدام القيمة '%' لكل من الوسائط والقيمة المرجعة للقول بأن قوائم نمط المفتاح/القيمة مستخدمة.

بدلاً من ذلك، يمكن إدراج وسائط موضعية فردية، يمثل كل منها بحرف:

"i"
وسيط إدخال
"o"
وسيط إخراج
"O"
وسيط إدخال وإخراج

إذا كان نموذج القيمة المرجعة يحتوي على "!" مضافًا، فإنه يشير إلى أن هذه الدالة تضبط errno ($!) عندما ترجع قيمة خاطئة. سيعرض التتبع القيمة الحالية لـ errno في هذه الحالة.

إذا كانت صيغة القيمة المرجعة تبدو كاسم متغير (مع بادئة "$")، وكانت الدالة ترجع كائنًا مباركًا، فسيتم استخدام اسم المتغير كبادئة وسيتم تتبع الكائن المرجع تلقائيًا.
