davix-mkdir(1)

الحزمة: davix

التراخيص: LGPL-2.1-or-later

DAVIX-MKDIR(1) أداة سرد DAVIX-MKDIR(1)

الاسم

davix-mkdir - أداة إنشاء مجلدات تعتمد على libdavix.

ملخص

davix-mkdir [خيارات]... عنوان_URL

الوصف

davix-mkdir هي أداة لإنشاء مجلدات أو مجموعات مع خدمات متوافقة مع HTTP، Webdav أو REST.
يدعم الأمر بروتوكولات Http (http(s)://)، WebDav (dav(s)://) و S3 (s3(s)://).

يتم تشغيل davix-mkdir بواسطة libdavix. انظر libdavix(3) للحصول على التفاصيل.

خيارات

خيارات عامة:

--debug
وضع التصحيح
--header, -H
أضف حقل رأس إلى الطلب (مثال: -H "Depth: 1" )
--help, -h
عرض رسالة المساعدة هذه
--metalink OPT
دعم Metalink. (OPT=failover[افتراضي]|no)
--module, -P PLUGIN_NAME
تحميل مكون إضافي أو ملف تعريف بالاسم
--redirection OPT
دعم إعادة التوجيه الشفاف. (OPT=yes[افتراضي]|no)
--proxy, -x URL
خادم وكيل SOCKS5 بعنوان URL. (مثال: socks5://login:pass@socks.example.org)
--trace
تتبع نطاقات محددة، تشمل الخيارات:
file - واجهة ملف Davix
posix - واجهة POSIX Davix
xml - مخرجات محلل XML
ssl - تفاصيل SSL و الشهادات
header - رؤوس استعلامات HTTP
body - أجسام HTTP
chain - معلومات سلاسل الإدخال/الإخراج
core - معلومات التكوين ومعلومات متنوعة
grid - معلومات متنوعة من أطراف ثالثة
socket - معلومات المقبس
locks - معلومات قفل WebDAV
all - يتتبع كل شيء
--version
عرض الإصدار

خيارات الأمان:

--capath CA_path
إضافة سلطة شهادات إضافية
--cert, -E cred_path
شهادة العميل بتنسيق PEM
--key priv_path
المفتاح الخاص بتنسيق PEM
--insecure, -k
تعطيل فحوصات صلاحية SSL
--userlogin
اسم مستخدم لمصادقة اسم المستخدم/كلمة المرور
--userpass
كلمة مرور المستخدم لمصادقة اسم المستخدم/كلمة المرور
--s3secretkey
مصادقة AWS S3: المفتاح السري
--s3accesskey
مصادقة AWS S3: مفتاح الوصول
--s3region
مصادقة AWS S3: المنطقة
--s3token
رمز أمان AWS S3 - يستخدم مع بيانات اعتماد STS المؤقتة
--s3alternate
حدد هذا العلم إذا كنت بحاجة إلى استخدام عنوان URL S3 المستند إلى المسار
--azurekey
مفتاح مصادقة Azure

أمثلة

إنشاء مجلد عبر WebDav
davix-mkdir dav://webdav.example.org/dir/directory_to_create

إنشاء مجلد على تخزين شبكي بمصادقة VOMS
davix-mkdir -P grid davs://grid-storage.example.org/dir1/directory_to_create
