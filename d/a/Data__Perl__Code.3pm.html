Data__Perl__Code(3pm)

الحزمة: perl-data-perl

التراخيص: PerlArtistic, GPL

Data::Perl::Code(3) وثائق Perl المقدمة من المستخدم Data::Perl::Code(3)

الاسم

Data::Perl::Code - فئة تغليف لـ Perl coderefs.

الإصدار

version 0.002011

الملخص

use Data::Perl qw/code/;
my $code = code(sub { 'Foo'} );
$code->execute(); # returns 'Foo';

الوصف

هذه الفئة هي مجرد مستهلك لدور Data::Perl::Role::Code، والذي يوفر كل الوظائف. من المحتمل أن ترغب في النظر إليه بدلاً من ذلك.
