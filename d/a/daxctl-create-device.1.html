daxctl-create-device(1)

الحزمة: ndctl

التراخيص: LGPL

DAXCTL-CREATE-DEVICE(1) دليل daxctl DAXCTL-CREATE-DEVICE(1)

الاسم

daxctl create-device - إنشاء جهاز devdax

ملخص

daxctl create-device [<خيارات>]

أمثلة

•إنشاء dax0.1 بحجم 4 جيجابايت
# daxctl create-device -s 4G
[
  {
    "chardev":"dax0.1",
    "size":4294967296,
    "target_node":0,
    "mode":"devdax"
  }
]
•إنشاء أجهزة بحجم كامل متاح على جميع المناطق
# daxctl create-device -u
[
  {
    "chardev":"dax0.1",
    "size":"15.63 GiB (16.78 GB)",
    "target_node":0,
    "mode":"devdax"
  },
  {
    "chardev":"dax1.1",
    "size":"15.63 GiB (16.78 GB)",
    "target_node":1,
    "mode":"devdax"
  }
]
•إنشاء dax0.1 بحجم كامل متاح على المنطقة 0
# daxctl create-device -r 0 -u
{
  "chardev":"dax0.1",
  "size":"15.63 GiB (16.78 GB)",
  "target_node":0,
  "mode":"devdax"
}

وصف

ينشئ جهاز dax في وضع devdax في المناطق الديناميكية. يمكن أيضًا تحويل النتيجة إلى وضع system-ram الذي يرتب لربط نطاق dax بالنظام كذاكرة عادية.

daxctl create-device يتوقع أن يقوم BIOS أو النواة بتعريف نطاق في خريطة ذاكرة EFI مع EFI_MEMORY_SP. النطاقات الناتجة تعني أن سعتها البالغة 100٪ محجوزة للتطبيقات.

خيارات

-r, --region=

تقييد العملية على الأجهزة التي تنتمي إلى المنطقة (المناطق) المحددة. منطقة devdax هي نطاق متجاور من الذاكرة يستضيف جهازًا واحدًا أو أكثر /dev/daxX.Y، حيث X هو معرف المنطقة و Y هو معرف مثيل الجهاز.

-s, --size=

بالنسبة للمناطق التي تدعم إنشاء أجهزة dax، قم بتعيين حجم الجهاز بالبايت. بخلاف ذلك، يتم افتراضياً إلى الحد الأقصى للحجم الذي تحدده المنطقة. يدعم هذا الخيار اللاحقات "k" أو "K" لـ KiB، و "m" أو "M" لـ MiB، و "g" أو "G" لـ GiB، و "t" أو "T" لـ TiB. 
يجب أن يكون الحجم مضاعفًا لمحاذاة المنطقة.

-a, --align

التطبيقات التي ترغب في إنشاء تعيينات ذاكرة dax مع إدخالات جدول الصفحات أكبر من حجم صفحة النظام الأساسي (4K على x86) تحتاج إلى جهاز محاذٍ بشكل كافٍ. يتم افتراضياً إلى 2M. لاحظ أن وضع "devdax" يفرض محاذاة جميع التعيينات إلى هذه القيمة، أي أنه يفشل في محاولات التعيين غير المحاذاة.

--input

التطبيقات التي ترغب في تحديد النطاقات المخصصة لمثيل device-dax، أو ترغب في إنشاء أجهزة تم إنشاؤها مسبقًا، يمكنها تمرير ملف إدخال JSON. يتيح خيار الملف للمستخدم تمرير كائن JSON مشابه لتلك المدرجة مع "daxctl list". 
لا يتم إعادة إنشاء اسم الجهاز، ولكن إذا تم تمرير "chardev" في
ملف JSON، فسيتم استخدامه للحصول على معرف المنطقة.
لاحظ أن محتوى JSON في الملف لا يمكن أن يكون مصفوفة من كائنات
JSON ولكن بالأحرى كائن JSON واحد، أي بدون أقواس المصفوفة.

-u, --human

افتراضياً، ستخرج الأوامر بيانات خام عددية سهلة القراءة للحواسيب. بدلاً من ذلك، مع هذا العلم، سيتم تنسيق الأرقام التي تمثل حجم التخزين كسلاسل نصية قابلة للقراءة البشرية مع وحدات، وسيتم تحويل الحقول الأخرى إلى سلاسل سداسية عشرية.

-v, --verbose

إخراج المزيد من رسائل التصحيح
