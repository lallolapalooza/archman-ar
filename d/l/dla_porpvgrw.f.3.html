الوظائف/الروتينات الفرعية


double precision function dla_porpvgrw (uplo, ncols, a, lda, af, ldaf, work)


DLA_PORPVGRW يحسب عامل نمو المحور العكسي norm(A)/norm(U) لمصفوفة متماثلة أو هرمية موجبة محددة.

توثيق الوظيفة/الروتين الفرعي

double precision function dla_porpvgrw (character*1 uplo, integer ncols, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, double precision, dimension( * ) work)

DLA_PORPVGRW يحسب عامل نمو المحور العكسي norm(A)/norm(U) لمصفوفة متماثلة أو هرمية موجبة محددة.

الغرض:

!>
!>
!> DLA_PORPVGRW يحسب عامل نمو المحور العكسي
!> norm(A)/norm(U). يتم استخدام المعيار. إذا كان هذا
!> أقل بكثير من 1، فقد يكون استقرار تحليل LU للمصفوفة
!> (الموازنة) A ضعيفًا. هذا يعني أيضًا أن
!> الحل X، وتقديرات أرقام الشرط، وحدود الخطأ قد تكون
!> غير موثوقة.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>       = 'U':  المثلث العلوي لـ A مخزن؛
!>       = 'L':  المثلث السفلي لـ A مخزن.
!>

NCOLS

!>          NCOLS هو INTEGER
!>     عدد أعمدة المصفوفة A. NCOLS >= 0.
!>

A

!>          A هو مصفوفة DOUBLE PRECISION، البعد (LDA,N)
!>     عند الإدخال، المصفوفة N-by-N A.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A. LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة DOUBLE PRECISION، البعد (LDAF,N)
!>     العامل المثلثي U أو L من تحليل Cholesky
!>     A = U**T*U أو A = L*L**T، كما تم حسابه بواسطة DPOTRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF. LDAF >= max(1,N).
!>

WORK

!>          WORK هو مصفوفة DOUBLE PRECISION، البعد (2*N)
!>
