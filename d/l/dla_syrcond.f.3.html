double precision function dla_syrcond (uplo, n, a, lda, af, ldaf, ipiv, cmode, c, info, work, iwork)
DLA_SYRCOND تقدر عدد شرط Skeel لمصفوفة غير محددة متماثلة.

وثائق الوظيفة/الإجراء الفرعي

double precision function dla_syrcond (character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, integer cmode, double precision, dimension( * ) c, integer info, double precision, dimension( * ) work, integer, dimension( * ) iwork)

DLA_SYRCOND تقدر عدد شرط Skeel لمصفوفة غير محددة متماثلة.

الغرض:

!>
!>    DLA_SYRCOND تقدر عدد شرط Skeel للمصفوفة op(A) * op2(C)
!>    حيث يتم تحديد op2 بواسطة CMODE كما يلي
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    يتم حساب عدد شرط Skeel cond(A) = norminf( |inv(A)||A| )
!>    عن طريق حساب عوامل القياس R بحيث تكون
!>    diag(R)*A*op2(C) متوازنة الصفوف ويتم حساب عدد شرط المعيار اللانهائي القياسي.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>       = 'U':  المثلث العلوي للمصفوفة A مخزن؛
!>       = 'L':  المثلث السفلي للمصفوفة A مخزن.
!>

N

!>          N هو INTEGER
!>     عدد المعادلات الخطية، أي رتبة
!>     المصفوفة A.  N >= 0.
!>

A

!>          A هو مصفوفة DOUBLE PRECISION، البعد (LDA,N)
!>     عند الدخول، المصفوفة N-by-N A.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة DOUBLE PRECISION، البعد (LDAF,N)
!>     المصفوفة القطرية الجزئية D والعوامل المستخدمة
!>     للحصول على العامل U أو L كما تم حسابه بواسطة DSYTRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV هو مصفوفة INTEGER، البعد (N)
!>     تفاصيل التبادلات والبنية الجزئية لـ D
!>     كما تم تحديده بواسطة DSYTRF.
!>

CMODE

!>          CMODE هو INTEGER
!>     يحدد op2(C) في الصيغة op(A) * op2(C) كما يلي:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C هو مصفوفة DOUBLE PRECISION، البعد (N)
!>     المتجه C في الصيغة op(A) * op2(C).
!>

INFO

!>          INFO هو INTEGER
!>       = 0:  الخروج الناجح.
!>     i > 0:  المعلمة i غير صالحة.
!>

WORK

!>          WORK هو مصفوفة DOUBLE PRECISION، البعد (3*N).
!>     مساحة عمل.
!>

IWORK

!>          IWORK هو مصفوفة INTEGER، البعد (N).
!>     مساحة عمل.
!>
