الوظائف/الروتينات الفرعية


double precision function dlantb (norm, uplo, diag, n, k, ab, ldab, work)
DLANTB ترجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة مثلثة شريطية.

وثائق الوظيفة/الروتين الفرعي

double precision function dlantb (character norm, character uplo, character diag, integer n, integer k, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

DLANTB ترجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة مثلثة شريطية.

الغرض:

!>
!> DLANTB  ترجع قيمة المعيار واحد،  أو معيار فروبنيوس،  أو
!> المعيار اللانهائي،  أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> مثلثة شريطية A،  ذات ( k + 1 ) أقطار.
!>

النتائج

DLANTB 
!>
!>    DLANTB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تمثل  المعيار واحد لمصفوفة (أكبر مجموع أعمدة)،
!> normI  تمثل  المعيار اللانهائي  لمصفوفة  (أكبر مجموع صفوف) و
!> normF  تمثل  معيار فروبنيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في DLANTB كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثة علوية أم سفلية.
!>          = 'U':  مثلثة علوية
!>          = 'L':  مثلثة سفلية
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثة أحادية أم لا.
!>          = 'N':  غير أحادية مثلثة
!>          = 'U':  أحادية مثلثة
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين DLANTB
!>          إلى الصفر.
!>

K

!>          K is INTEGER
!>          عدد الأقطار فوق القطر الرئيسي للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار تحت القطر الرئيسي للمصفوفة A إذا كان UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>          المصفوفة الشريطية المثلثية العلوية أو السفلية A، مخزنة في
!>          الصفوف k+1 الأولى من AB.  يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(k+1+i-j,j) = A(i,j) حيث max(1,j-k)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)   = A(i,j) حيث j<=i<=min(n,j+k).
!>          لاحظ أنه عندما يكون DIAG = 'U'، فإن عناصر المصفوفة AB
!>          المقابلة للعناصر القطرية للمصفوفة A لا يتم الإشارة إليها، ولكن يفترض أنها واحد.
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= K+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I'. خلاف ذلك، لا يتم
!>          الإشارة إلى WORK.
!>
