DLAHQR تحسب القيم الذاتية والتحليل لشفرتريكس هسنبرغ علوي، باستخدام خوارزمية QR للتحويلات المزدوجة/المفردة.

الغرض:

!>
!>    DLAHQR هو إجراء فرعي مساعد يتم استدعاؤه بواسطة DHSEQR لتحديث
!>    القيم الذاتية والتحليل لشفرتريكس الموجود بالفعل، من خلال
!>    التعامل مع الشفرتريكس الفرعي لهسنبرغ في الصفوف والأعمدة ILO إلى
!>    IHI.
!>

المعلمات

WANTT 
!>          WANTT هو LOGICAL
!>          = .TRUE. : مطلوب الشكل شفرتريكسي الكامل T؛
!>          = .FALSE.: القيم الذاتية فقط مطلوبة.
!>

WANTZ

!>          WANTZ هو LOGICAL
!>          = .TRUE. : مصفوفة متجهات شفرتريكس Z مطلوبة؛
!>          = .FALSE.: متجهات شفرتريكس غير مطلوبة.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة H. N >= 0.
!>

ILO

!>          ILO هو INTEGER
!>

IHI

!>          IHI هو INTEGER
!>          من المفترض أن H بالفعل شبه ثلاثي علوي في
!>          الصفوف والأعمدة IHI+1:N، وأن H(ILO,ILO-1) = 0 (ما لم
!>          يكن ILO = 1). يعمل DLAHQR بشكل أساسي مع الشفرتريكس
!>          الفرعي لهسنبرغ في الصفوف والأعمدة ILO إلى IHI، ولكنه يطبق
!>          تحويلات على H بالكامل إذا كان WANTT هو .TRUE..
!>          1 <= ILO <= max(1,IHI)؛ IHI <= N.
!>

H

!>          H هو مصفوفة DOUBLE PRECISION، حجم (LDH,N)
!>          عند الدخول، مصفوفة هسنبرغ العلوية H.
!>          عند الخروج، إذا كان INFO صفراً وإذا كان WANTT هو .TRUE.، فإن H
!>          شبه ثلاثي علوي في الصفوف والأعمدة ILO:IHI، مع أي
!>          كتل قطرية 2x2 في الشكل القياسي. إذا كان INFO صفراً
!>          و WANTT هو .FALSE.، فإن محتويات H غير محددة عند الخروج.
!>          حالة الخروج من H إذا كان INFO غير صفري معطاة أدناه تحت وصف INFO.
!>

LDH

!>          LDH هو INTEGER
!>          البعد الرائد للمصفوفة H. LDH >= max(1,N).
!>

WR

!>          WR هي مصفوفة DOUBLE PRECISION، حجم (N)
!>

WI

!>          WI هي مصفوفة DOUBLE PRECISION، حجم (N)
!>          يتم تخزين الأجزاء الحقيقية والتخيلية، على التوالي، للقيم
!>          الذاتية المحسوبة ILO إلى IHI في العناصر المقابلة
!>          من WR و WI. إذا تم حساب قيمتين ذاتيتين كزوج مترافق مركب،
!>          يتم تخزينهما في عناصر متتالية من WR و WI، وليكن i-th و
!>          (i+1)th، مع WI(i) > 0 و WI(i+1) < 0. إذا كان WANTT هو .TRUE.،
!>          يتم تخزين القيم الذاتية بنفس ترتيب الأقطار
!>          للشفرتريكس العائدة في H، مع WR(i) = H(i,i)، و، إذا
!>          كان H(i:i+1,i:i+1) كتلة قطرية 2x2،
!>          WI(i) = sqrt(H(i+1,i)*H(i,i+1)) و WI(i+1) = -WI(i).
!>

ILOZ

!>          ILOZ هو INTEGER
!>

IHIZ

!>          IHIZ هو INTEGER
!>          حدد الصفوف من Z التي يجب تطبيق التحويلات عليها إذا كان WANTZ
!>          هو .TRUE..
!>          1 <= ILOZ <= ILO؛ IHI <= IHIZ <= N.
!>

Z

!>          Z هي مصفوفة DOUBLE PRECISION، حجم (LDZ,N)
!>          إذا كان WANTZ هو .TRUE.، عند الدخول، يجب أن تحتوي Z على
!>          المصفوفة الحالية Z للتحويلات التي تم تجميعها بواسطة DHSEQR،
!>          وعند الخروج تم تحديث Z؛ يتم تطبيق التحويلات فقط على
!>          الشفرتريكس الفرعي Z(ILOZ:IHIZ,ILO:IHI).
!>          إذا كان WANTZ هو .FALSE.، لا يتم الرجوع إلى Z.
!>

LDZ

!>          LDZ هو INTEGER
!>          البعد الرائد للمصفوفة Z. LDZ >= max(1,N).
!>

INFO

!>          INFO هو INTEGER
!>           = 0:  خروج ناجح
!>           > 0:  إذا كان INFO = i، فشل DLAHQR في حساب جميع
!>                  القيم الذاتية ILO إلى IHI في إجمالي 30 تكرارًا
!>                  لكل قيمة ذاتية؛ العناصر i+1:ihi من WR و WI
!>                  تحتوي على تلك القيم الذاتية التي تم
!>                  حسابها بنجاح.
!>
!>                  إذا كان INFO > 0 وكان WANTT هو .FALSE.، فعند الخروج،
!>                  القيم الذاتية المتبقية غير المتقاربة هي
!>                  القيم الذاتية للشفرتريكس هسنبرغ العلوي
!>                  للصفوف والأعمدة ILO خلال INFO من القيمة النهائية
!>                  للمصفوفة H.
!>
!>                  إذا كان INFO > 0 وكان WANTT هو .TRUE.، فعند الخروج
!>          (*)       (المصفوفة H الأولية)*U  = U*(المصفوفة H النهائية)
!>                  حيث U هي مصفوفة متعامدة. المصفوفة H النهائية
!>                  شبه هسنبرغ وثلاثية في الصفوف والأعمدة INFO+1 إلى IHI.
!>
!>                  إذا كان INFO > 0 وكان WANTZ هو .TRUE.، فعند الخروج
!>                      (المصفوفة Z النهائية)  = (المصفوفة Z الأولية)*U
!>                  حيث U هي المصفوفة المتعامدة في (*)
!>                  (بغض النظر عن قيمة WANTT.)
!>

dlahqr(3) - LAPACK routine

NAME

dlahqr - an N×N upper Hessenberg matrix that is reduced to upper triangular form by means of orthogonal similarity transformations.

SYNOPSIS

  SUBROUTINE dlahqr(WANTT, WANTZ, N, ILO, IHI, A, LDA, B, LDB, WR, WI, Z, LDZ, WORK, LWORK, INFO)
    LOGICAL            WANTT, WANTZ
    INTEGER            N, ILO, IHI, LDA, LDB, LDZ, LWORK, INFO
    DOUBLE PRECISION   A(LDA,*)
    DOUBLE PRECISION   B(LDB,*)
    DOUBLE PRECISION   WR(*)
    DOUBLE PRECISION   WI(*)
    DOUBLE PRECISION   Z(LDZ,*)
    DOUBLE PRECISION   WORK(LWORK)

DESCRIPTION

dlahqr is a subroutine that reduces a real upper Hessenberg matrix to upper triangular form by means of orthogonal similarity transformations.

PARAMETERS

  • WANTT : LOGICAL

    Indicates whether or not the transformations are to be recorded in B.

  • WANTZ : LOGICAL

    Indicates whether or not the transformations are to be recorded in Z.

  • N : INTEGER

    The order of the matrix A. 0 ≤ N.

  • ILO : INTEGER

    The starting row and column index of the reduction range. 1 ≤ ILO ≤ IHI ≤ N.

  • IHI : INTEGER

    The ending row and column index of the reduction range. 1 ≤ ILO ≤ IHI ≤ N.

  • A : DOUBLE PRECISION array, dimension (LDA, *)

    On entry, the upper Hessenberg matrix A. On exit, the upper triangular matrix, and if WANTT is true, the orthogonal matrix Q such that A = Q B QT.

  • LDA : INTEGER

    The leading dimension of the array A. LDA ≥ max(1, N).

  • B : DOUBLE PRECISION array, dimension (LDB, *)

    On exit, if WANTT is true, B contains the upper triangular matrix; otherwise, B is used for workspace.

  • LDB : INTEGER

    The leading dimension of the array B. LDB ≥ max(1, N).

  • WR : DOUBLE PRECISION array, dimension (*)

    On exit, the real parts of the eigenvalues of A.

  • WI : DOUBLE PRECISION array, dimension (*)

    On exit, the imaginary parts of the eigenvalues of A. If WI(i) = 0, then A(i,i) is a real eigenvalue.

  • Z : DOUBLE PRECISION array, dimension (LDZ, *)

    On exit, if WANTZ is true, Z contains the orthogonal matrix Q which reduces A to upper triangular form. Z is initialized to the identity matrix.

  • LDZ : INTEGER

    The leading dimension of the array Z. LDZ ≥ max(1, N).

  • WORK : DOUBLE PRECISION array, dimension (LWORK)

    Workspace array.

  • LWORK : INTEGER

    The dimension of the array WORK. LWORK ≥ max(1, N).

  • INFO : INTEGER

    INFO = 0: successful exit.

    INFO < 0: if INFO = -i, the i-th argument had an illegal value.

    INFO > 0: if INFO = i, the QR algorithm failed to compute all the eigenvalues. I eigenvalues failed to converge.

DIAGNOSTICS

See the description of the INFO parameter.
