توثيق الدالة/الدُرجان

subroutine dlarfgp (integer n, double precision alpha, double precision, dimension( * ) x, integer incx, double precision tau)

DLARFGP تنشئ مصفوفة انعكاس أولية (مصفوفة هاوسهولدر) ذات معامل بيتا غير سالب.

الغرض:

!>
!> DLARFGP تنشئ مصفوفة انعكاس أولية حقيقية H من الرتبة n، بحيث
!>
!>       H * ( alpha ) = ( beta ),   H**T * H = I.
!>           (   x   )   (   0  )
!>
!> حيث alpha و beta قيمتان عدديتان، beta غير سالب، و x متجه حقيقي
!> يتكون من (n-1) عنصر. تُمثَّل H بالشكل
!>
!>       H = I - tau * ( 1 ) * ( 1 v**T ) ,
!>                     ( v )
!>
!> حيث tau قيمة عددية حقيقية و v متجه حقيقي يتكون من (n-1) عنصر.
!>
!> إذا كانت جميع عناصر x صفرية، فإن tau = 0 وتُعتبر H مصفوفة الوحدة.
!>

المعلمات

N 
!>          N هو عدد صحيح (INTEGER)
!>          رتبة مصفوفة الانعكاس الأولية.
!>

ALPHA

!>          ALPHA هو دقة مزدوجة (DOUBLE PRECISION)
!>          عند الإدخال: القيمة alpha.
!>          عند الخروج: يتم استبدالها بالقيمة beta.
!>

X

!>          X هو مصفوفة دقة مزدوجة (DOUBLE PRECISION)، أبعادها
!>                         (1+(N-2)*abs(INCX))
!>          عند الإدخال: المتجه x.
!>          عند الخروج: يتم استبداله بالمتجه v.
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)
!>          الزيادة بين عناصر X. INCX > 0.
!>

TAU

!>          TAU هو دقة مزدوجة (DOUBLE PRECISION)
!>          القيمة tau.
!>
