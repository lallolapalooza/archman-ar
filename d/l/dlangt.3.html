الدوال/الإجراءات الفرعية


double precision function dlangt (norm, n, dl, d, du)
DLANGT تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة ثلاثية عامة.

توثيق الدالة/الإجراء الفرعي

double precision function dlangt (character norm, integer n, double precision, dimension( * ) dl, double precision, dimension( * ) d, double precision, dimension( * ) du)

DLANGT تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة ثلاثية عامة.

الغرض:

!>
!> DLANGT  تُرجع قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة
!> ثلاثية حقيقية A.
!>

تُرجع

DLANGT 
!>
!>    DLANGT = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى المعيار واحد للمصفوفة (الحد الأقصى لمجموع الأعمدة)،
!> normI  يشير إلى المعيار اللانهائي للمصفوفة (الحد الأقصى لمجموع الصفوف) و
!> normF  يشير إلى معيار فروبينيوس للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسقًا.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في DLANGT كما هو موضح
!>          أعلاه.
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم
!>          تعيين DLANGT إلى الصفر.
!>

DL

!>          DL is DOUBLE PRECISION array, dimension (N-1)
!>          العناصر الفرعية تحت القطر للمصفوفة A (عددها N-1).
!>

D

!>          D is DOUBLE PRECISION array, dimension (N)
!>          عناصر القطر الرئيسي للمصفوفة A (عددها N).
!>

DU

!>          DU is DOUBLE PRECISION array, dimension (N-1)
!>          العناصر الفرعية فوق القطر للمصفوفة A (عددها N-1).
!>
