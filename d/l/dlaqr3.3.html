Function/Subroutine Documentation

  Purpose
  =======
  
  DLAQR3 is a subroutine to find the desired range of Eigenvalues of a
  given matrix A.
  
  Arguments
  =========
  
  WANTT   (input) CHARACTER*1
          Specifies whether to compute the eigenvectors of the
          underlying upper Hessenberg matrix T.
          = 'N': Compute Eigenvalues only.
          = 'V': Compute Eigenvectors of T.
  
  WANTZ   (input) CHARACTER*1
          Specifies whether to compute the Eigenvectors of the
          underlying upper Hessenberg matrix A.
          = 'N': Compute Eigenvalues only.
          = 'V': Compute Eigenvectors of A.
  
  N       (input) INTEGER
          The order of the matrix A.  0 <= N.
  
  KTOP    (input) INTEGER
          The top row index of the submatrix for which Eigenvalues are
          desired.  1 <= KTOP.
  
  KBOT    (input) INTEGER
          The bottom row index of the submatrix for which Eigenvalues are
          desired. KTOP <= KBOT <= N.
  
  NB      (input) INTEGER
          The blocking size for the splitting of the algorithm.
  
  ROWS    (input) INTEGER
          The number of rows of the blocking window.
  
  NHI     (input) INTEGER
          The number of Eigenvalues desired.  0 <= NHI <= KBOT - KTOP + 1.
  
  ILO     (input) INTEGER
          The row and column index of the first row/column of the
           deflation-stable submatrix.
  
  LWORK   (input) INTEGER
          The dimension of the array WORK. LWORK >= 1.
          On exit, WORK(1) contains the minimum required dimension of WORK.
  
  A       (input/output) REAL array, dimension (LDA,*)
          On entry, A contains the upper Hessenberg matrix.
          On exit, the Eigenvalues are in the diagonal elements of A.
  
  LDA     (input) INTEGER
          The leading dimension of the array A.  LDA >= max(1, N).
  
  B       (input/output) REAL array, dimension (LDB,*)
          On entry, B contains the subdiagonal elements of the upper
          Hessenberg matrix.
          On exit, B may be of arbitrary size.
  
  LDB     (input) INTEGER
          The leading dimension of the array B.  LDB >= max(1, N).
  
  RWORK   (workspace) REAL array, dimension (N)
  
  Q       (input/output) REAL array, dimension (LDQ,*)
          On entry, Q is an orthogonal matrix which reduces A to
          upper Hessenberg form.
          On exit, Q is the orthogonal matrix which reduces A to Schur form
          diag(S) or diag(H) if WANTT = 'N'.
  
  LDQ     (input) INTEGER
          The leading dimension of the array Q. LDQ >= max(1, N).
  
  Z       (input/output) REAL array, dimension (LDZ,*)
          On entry, Z is an orthogonal matrix.
          On exit, Z is the orthogonal matrix that transforms A to the
          triangular form U*D*U**H, if WANTZ = 'V'.
  
  LDZ     (input) INTEGER
          The leading dimension of the array Z. LDZ >= max(1, N).
  
  WORK    (workspace) REAL array, dimension (LWORK)
          On exit, WORK(1) contains the minimum required dimension of WORK.
  
  INFO    (output) INTEGER
          = 0:  successful exit
          < 0:  if INFO = -i, the i-th argument had an illegal value.
          > 0:  Algorithm did not converge.
  
  Detailed Description
  ====================
  
  This routine is internally called by DGEBAL and DGEEV to compute the
  Eigenvalues and Eigenvectors of a general matrix A.
  
  The algorithm uses an inverse iteration combined with deflation.
  The Eigenvalues are computed in the diagonal elements of A.
  The Eigenvectors are computed in the columns of Z.
  The routine expects A to be in upper Hessenberg form.
  
  The Eigenvalues are computed in the diagonal elements of A. The Eigenvectors
  are computed in the columns of Z. The routine expects A to be in
  upper Hessenberg form.
  
  The workspace size is determined by the Eigenvalue computation, the
  Eigenvector computation and the Givens rotation updates. The minimum
  workspace size is returned in WORK(1).
  
  The subroutine computes the required workspace size for the given
  values of N, NW, KTOP and KBOT. The estimate is returned
  in WORK(1). No error message related to LWORK is issued
  by XERBLA. Neither H nor Z are accessed.
