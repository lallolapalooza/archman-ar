NAME

dlatme - Checks that a subroutine that generates a general band matrix satisfies its specifications.

SYNOPSIS

SUBROUTINE DLATME(
     N, DIST, MODE, SEED, SYM, GROUP, KL, KU, ANORM, A, LDA, WORK, INFO )

  INTEGER :: N
  CHARACTER*1 :: DIST, MODE, SEED, SYM, GROUP
  INTEGER :: KL, KU
  DOUBLE PRECISION :: ANORM
  DOUBLE PRECISION :: A( LDA, * )
  INTEGER :: LDA
  DOUBLE PRECISION :: WORK( * )
  INTEGER :: INFO

Function/Subroutine Documentation

DLATME is a subroutine that checks that a subroutine that generates a general band matrix satisfies its specifications. It is a driver routine for testing DLATME, which generates test matrices for the LAPACK routines.

The matrix A is generated in the form

A = U * S * V

where U and V are random unitary matrices and S is a diagonal matrix of singular values specified by DS, MODES, and CONDS.

Arguments:

N

INTEGER

The order of the matrix A. N must be at least 1.

Not modified.

DIST

CHARACTER*1

Specifies the distribution of eigenvalues or singular values.

'U' - Uniform distribution

'S' - Sine distribution

'N' - Normal distribution

'L' - Log-uniform distribution

'C' - Cauchy distribution

'E' - Exponential distribution

'Q' - Random orthogonal matrix

'R' - Random unitary matrix

'G' - Random general matrix

'B' - Random band matrix

'H' - Random Hessenberg matrix

'T' - Random triangular matrix

'O' - Random orthogonal matrix

'P' - Random permutation matrix

'D' - Random diagonal matrix

Not modified.

MODE

INTEGER

Specifies how the singular values are set.

-2: Singular values are chosen in [0,1].

-1: Singular values are chosen in [1,10].

0: Singular values are given by DS.

1: Singular values are chosen in [1,10].

2: Singular values are chosen in [0,1].

3: Singular values are chosen in [1,10*conds].

4: Singular values are chosen in [1/conds,1].

5: Singular values are chosen in [1/conds,10/conds].

6: Singular values are chosen in [1,conds].

Modified if MODE is nonzero.

SEED

DOUBLE PRECISION array, dimension (4)

The seed for generating random numbers. Not modified.

SYM

CHARACTER*1

'U' - Upper triangular

'L' - Lower triangular

'U' - Upper triangular

'S' - Symmetric

'H' - Skew-symmetric

'B' - Non-symmetric

Not modified.

GROUP

CHARACTER*1

'G' - General matrix

'T' - Triangular matrix

'H' - Hessenberg matrix

'B' - Band matrix

Not modified.

DS

DOUBLE PRECISION array, dimension ( N )

This array is used to specify the singular values of X, in the same way that D specifies the eigenvalues of A.

If MODE=0, the DS contains the singular values, which may not be zero.

Modified if MODE is nonzero.

MODES

INTEGER

CONDS

DOUBLE PRECISION

Same as MODE and COND, but for specifying the diagonal of S. MODES=-6 and +6 are not allowed (since they would result in randomly ill-conditioned eigenvalues.)

KL

INTEGER

This specifies the lower bandwidth of the matrix. KL=1 specifies upper Hessenberg form. If KL is at least N-1, then A will have full lower bandwidth. KL must be at least 1.

Not modified.

KU

INTEGER

This specifies the upper bandwidth of the matrix. KU=1 specifies lower Hessenberg form. If KU is at least N-1, then A will have full upper bandwidth; if KU and KL are both at least N-1, then A will be dense. Only one of KU and KL may be less than N-1. KU must be at least 1.

Not modified.

ANORM

DOUBLE PRECISION

If ANORM is not negative, then A will be scaled by a non-negative real number to make the maximum-element-norm of A to be ANORM.

Not modified.

A

DOUBLE PRECISION array, dimension ( LDA, N )

On exit A is the desired test matrix.

Modified.

LDA

INTEGER

LDA specifies the first dimension of A as declared in the calling program. LDA must be at least N.

Not modified.

WORK

DOUBLE PRECISION array, dimension ( 3*N )

Workspace.

Modified.

INFO

INTEGER

Error code. On exit, INFO will be set to one of the following values:

0 => normal return

-1 => N negative

-2 => DIST illegal string

-5 => MODE not in range -6 to 6

-6 => COND less than 1.0, and MODE neither -6, 0 nor 6

-8 => EI(1) is not ' ' or 'R', EI(j) is not 'R' or 'I', or two adjacent elements of EI are 'I'.

-9 => RSIGN is not 'T' or 'F'

-10 => UPPER is not 'T' or 'F'

-11 => SIM is not 'T' or 'F'

-12 => MODES=0 and DS has a zero singular value.

-13 => MODES is not in the range -5 to 5.

-14 => MODES is nonzero and CONDS is less than 1.

-15 => KL is less than 1.

-16 => KU is less than 1, or KL and KU are both less than N-1.

-19 => LDA is less than N.

1 => Error return from DLATM1 (computing D)

2 => Cannot scale to DMAX (max. eigenvalue is 0)

3 => Error return from DLATM1 (computing DS)

4 => Error return from DLARGE

5 => Zero singular value from DLATM1.
