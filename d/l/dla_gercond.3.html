double precision function dla_gercond (trans, n, a, lda, af, ldaf, ipiv, cmode, c, info, work, iwork)
DLA_GERCOND تقدّر رقم حالة Skeel لمصفوفة عامة.

توثيق الوظيفة/الإجراء الفرعي

double precision function dla_gercond (character trans, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, integer cmode, double precision, dimension( * ) c, integer info, double precision, dimension( * ) work, integer, dimension( * ) iwork)

DLA_GERCOND تقدّر رقم حالة Skeel لمصفوفة عامة.

الغرض:

!>
!>    DLA_GERCOND تقدّر رقم حالة Skeel لـ op(A) * op2(C)
!>    حيث يتم تحديد op2 بواسطة CMODE على النحو التالي
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    يتم حساب رقم حالة Skeel cond(A) = norminf( |inv(A)||A| )
!>    عن طريق حساب عوامل القياس R بحيث
!>    diag(R)*A*op2(C) تكون مكافئة للصفوف ويتم حساب رقم حالة المعيار لانهائي القياسي.
!>

المعاملات

TRANS 
!>          TRANS هو CHARACTER*1
!>     يحدد شكل نظام المعادلات:
!>       = 'N':  A * X = B     (بدون تبديل)
!>       = 'T':  A**T * X = B  (تبديل)
!>       = 'C':  A**H * X = B  (تبديل مرافق = تبديل)
!>

N

!>          N هو INTEGER
!>     عدد المعادلات الخطية، أي ترتيب
!>     المصفوفة A.  N >= 0.
!>

A

!>          A هو مصفوفة DOUBLE PRECISION، البعد (LDA,N)
!>     عند الإدخال، المصفوفة N*N A.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة DOUBLE PRECISION، البعد (LDAF,N)
!>     العوامل L و U من التحليل
!>     A = P*L*U كما تم حسابه بواسطة DGETRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV هو مصفوفة INTEGER، البعد (N)
!>     فهارس المحور من التحليل A = P*L*U
!>     كما تم حسابه بواسطة DGETRF؛ تم تبديل الصف i من المصفوفة
!>     مع الصف IPIV(i).
!>

CMODE

!>          CMODE هو INTEGER
!>     يحدد op2(C) في الصيغة op(A) * op2(C) على النحو التالي:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!>

C

!>          C هو مصفوفة DOUBLE PRECISION، البعد (N)
!>     المتجه C في الصيغة op(A) * op2(C).
!>

INFO

!>          INFO هو INTEGER
!>       = 0:  انتهاء ناجح.
!>     i > 0:  المعامل i غير صالح.
!>

WORK

!>          WORK هو مصفوفة DOUBLE PRECISION، البعد (3*N).
!>     مساحة عمل.
!>

IWORK

!>          IWORK هو مصفوفة INTEGER، البعد (N).
!>     مساحة عمل.
!>
