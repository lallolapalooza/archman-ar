subroutine dlaic1 (integer job, integer j, double precision, dimension( j ) x, double precision sest, double precision, dimension( j ) w, double precision gamma, double precision sestpr, double precision s, double precision c)

DLAIC1 يطبق خطوة واحدة من تقدير الشرط التدريجي.

الغرض:

!>
!> DLAIC1 يطبق خطوة واحدة من تقدير الشرط التدريجي
!> في أبسط صوره:
!>
!> لتكن x، twonorm(x) = 1، متجهًا منفردًا تقريبيًا لمصفوفة ثلاثية سفلية بحجم j*j
!> L، بحيث
!>          twonorm(L*x) = sest
!> ثم تحسب DLAIC1 sestpr، s، c بحيث
!> المتجه
!>                 [ s*x ]
!>          xhat = [  c  ]
!> هو متجه منفرد تقريبي للمصفوفة
!>                 [ L       0  ]
!>          Lhat = [ w**T gamma ]
!> بمعنى أن
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> اعتمادًا على JOB، يتم حساب تقدير لأكبر أو أصغر قيمة فردية.
!>
!> لاحظ أن [s c]**T و sestpr**2 هي زوج قيمة/متجه ذاتي للنظام
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ alpha ]
!>                                           [ gamma ]
!>
!> حيث  alpha =  x**T*w.
!>

المعلمات

!>          = 1: يتم حساب تقدير لأكبر قيمة فردية.
!>          = 2: يتم حساب تقدير لأصغر قيمة فردية.

J

!>          J هو عدد صحيح (INTEGER)
!>          طول X و W
!>

X

!>          X هو مصفوفة من النوع DOUBLE PRECISION، بأبعاد (J)

!>          SEST هو النوع DOUBLE PRECISION
!>          القيمة الفردية المقدرة للمصفوفة L بحجم j*j
!>

W

!>          W هو مصفوفة من النوع DOUBLE PRECISION، بأبعاد (J)
!>          المتجه j، w.
!>

!>          GAMMA هو النوع DOUBLE PRECISION
!>          العنصر القطري gamma.
!>

!>          SESTPR هو النوع DOUBLE PRECISION
