توثيق الوظيفة/الإجراء الفرعي

subroutine dlar2v (integer n, double precision, dimension( * ) x, double precision, dimension( * ) y, double precision, dimension( * ) z, integer incx, double precision, dimension( * ) c, double precision, dimension( * ) s, integer incc)

DLAR2V يطبق متجه دوران مستوي بجيب تمام حقيقي وجيب حقيقي من كلا الجانبين على تسلسل من المصفوفات المتماثلة/الهيرميتية 2x2.

الغرض:

!>
!> DLAR2V يطبق متجه دوران مستوي حقيقي من كلا الجانبين على
!> تسلسل من المصفوفات المتماثلة الحقيقية 2x2، المعرفة بعناصر
!> المتجهات x، y، و z. لكل i = 1,2,...,n
!>
!>    ( x(i)  z(i) ) := (  c(i)  s(i) ) ( x(i)  z(i) ) ( c(i) -s(i) )
!>    ( z(i)  y(i) )    ( -s(i)  c(i) ) ( z(i)  y(i) ) ( s(i)  c(i) )
!>
