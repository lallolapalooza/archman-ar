توثيق الوظيفة/الروتين الفرعي

subroutine dlags2 (logical upper, double precision a1, double precision a2, double precision a3, double precision b1, double precision b2, double precision b3, double precision csu, double precision snu, double precision csv, double precision snv, double precision csq, double precision snq)

DLAGS2 يحسب مصفوفتين متعامدتين 2 × 2 هما U، V، و Q، ويطبقهما على المصفوفتين A و B بحيث تكون صفوف A و B المحولة متوازية.

الغرض:

!>
!> DLAGS2 يحسب مصفوفتين متعامدتين 2 × 2 هما U، V و Q، بحيث إذا كان ( UPPER ) فإن:
!>
!>           U**T *A*Q = U**T *( A1 A2 )*Q = ( x  0  )
!>                             ( 0  A3 )     ( x  x  )
!> و
!>           V**T*B*Q = V**T *( B1 B2 )*Q = ( x  0  )
!>                            ( 0  B3 )     ( x  x  )
!>
!> أو إذا كان ( .NOT.UPPER ) فإن:
!>
!>           U**T *A*Q = U**T *( A1 0  )*Q = ( x  x  )
!>                             ( A2 A3 )     ( 0  x  )
!> و
!>           V**T*B*Q = V**T*( B1 0  )*Q = ( x  x  )
!>                           ( B2 B3 )     ( 0  x  )
!>
!> صفوف A و B المحولة متوازية، حيث:
!>
!>   U = (  CSU  SNU ), V = (  CSV SNV ), Q = (  CSQ   SNQ )
!>       ( -SNU  CSU )      ( -SNV CSV )      ( -SNQ   CSQ )
!>
!> Z**T يمثل منقول Z.
!>
!>
