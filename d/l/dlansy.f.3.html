double precision function dlansy (norm, uplo, n, a, lda, work)

DLANSY ترجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية.

توثيق الوظيفة/الإجراء الفرعي

double precision function dlansy (character norm, character uplo, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

DLANSY ترجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة حقيقية.

الغرض:

!>
!> DLANSY  ترجع قيمة المعيار واحد،  أو معيار فروبينيوس، أو
!> معيار اللانهاية،  أو  العنصر ذي القيمة المطلقة الأكبر  لمصفوفة
!> متماثلة حقيقية A.
!>

ترجع

DLANSY 
!>
!>    DLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تدل على  المعيار واحد لمصفوفة (أكبر مجموع أعمدة)،
!> normI  تدل على  معيار اللانهاية  لمصفوفة  (أكبر مجموع صفوف) و
!> normF  تدل على  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في DLANSY كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان سيتم الرجوع إلى الجزء المثلثي العلوي أو السفلي
!>          للمصفوفة المتماثلة A.
!>          = 'U':  يتم الرجوع إلى الجزء المثلثي العلوي
!>          = 'L':  يتم الرجوع إلى الجزء المثلثي السفلي
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين DLANSY
!>          إلى صفر.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          المصفوفة المتماثلة A.  إذا كان UPLO = 'U'، فإن الجزء المثلثي
!>          العلوي الرئيسي n x n من A يحتوي على الجزء المثلثي العلوي
!>          للمصفوفة A، ولا يتم الرجوع إلى الجزء المثلثي السفلي الصارم من A.
!>          إذا كان UPLO = 'L'، فإن الجزء المثلثي السفلي الرئيسي n x n
!>          من A يحتوي على الجزء المثلثي السفلي
!>          للمصفوفة A، ولا يتم الرجوع إلى الجزء المثلثي العلوي الصارم من A.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I' أو '1' أو 'O'.
!>          بخلاف ذلك، لا يتم الرجوع إلى WORK.
!>
