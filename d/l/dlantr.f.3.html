الدوال/الإجراءات الفرعية


double precision function dlantr (norm, uplo, diag, m, n, a, lda, work)
DLANTR تعيد قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة شبه منحرفة أو مثلثية.

وثائق الدالة/الإجراء الفرعي

double precision function dlantr (character norm, character uplo, character diag, integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

DLANTR تعيد قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة شبه منحرفة أو مثلثية.

الغرض:

!>
!> DLANTR  تعيد قيمة المعيار الواحد،  أو معيار فروبينيوس،  أو
!> معيار اللانهاية،  أو  العنصر ذي  القيمة المطلقة الأكبر  لمصفوفة
!> شبه منحرفة أو مثلثية A.
!>

تعيد

DLANTR 
!>
!>    DLANTR = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تشير إلى  المعيار الواحد لمصفوفة (أكبر مجموع عمودي)،
!> normI  تشير إلى  معيار اللانهاية  لمصفوفة (أكبر مجموع صفي) و
!> normF  تشير إلى  معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابت.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إعادتها في DLANTR كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A شبه منحرفة علوية أو سفلية.
!>          = 'U':  شبه منحرفة علوية
!>          = 'L':  شبه منحرفة سفلية
!>          لاحظ أن A مثلثية بدلاً من شبه منحرفة إذا كان M = N.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A لها قطر موحد أم لا.
!>          = 'N':  قطر غير موحد
!>          = 'U':  قطر موحد
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A.  M >= 0، وإذا كان
!>          UPLO = 'U'، فإن M <= N.  عندما يكون M = 0، يتم تعيين DLANTR إلى صفر.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة A.  N >= 0، وإذا كان
!>          UPLO = 'L'، فإن N <= M.  عندما يكون N = 0، يتم تعيين DLANTR إلى صفر.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          المصفوفة شبه المنحرفة A (A مثلثية إذا كان M = N).
!>          إذا كان UPLO = 'U'، فإن الجزء العلوي العلوي من المصفوفة شبه المنحرفة
!>          بحجم m × n في المصفوفة A يحتوي على المصفوفة شبه المنحرفة العلوية،
!>          والجزء المثلثي السفلي السفلي من A لا يتم الاستشهاد به.
!>          إذا كان UPLO = 'L'، فإن الجزء السفلي السفلي من المصفوفة شبه المنحرفة
!>          بحجم m × n في المصفوفة A يحتوي على المصفوفة شبه المنحرفة السفلية،
!>          والجزء المثلثي العلوي العلوي من A لا يتم الاستشهاد به.  لاحظ
!>          أنه عندما يكون DIAG = 'U'، لا يتم الاستشهاد بعناصر القطر في A
!>          ويفترض أنها واحد.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(M,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= M عندما يكون NORM = 'I'.  بخلاف ذلك، لا يتم
!>          الاستشهاد بـ WORK.
!>
