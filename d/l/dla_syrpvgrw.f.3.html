الوظائف/الإجراءات الفرعية


double precision function dla_syrpvgrw (uplo, n, info, a, lda, af, ldaf, ipiv, work)
DLA_SYRPVGRW تحسب مقلوب معامل نمو المحور (pivot growth factor) norm(A)/norm(U) لمصفوفة غير محددة متماثلة.

وثائق الوظيفة/الإجراء الفرعي

double precision function dla_syrpvgrw (character*1 uplo, integer n, integer info, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) work)

DLA_SYRPVGRW تحسب مقلوب معامل نمو المحور norm(A)/norm(U) لمصفوفة غير محددة متماثلة.

الغرض:

!>
!>
!> DLA_SYRPVGRW تحسب مقلوب معامل نمو المحور
!> norm(A)/norm(U). يتم استخدام المعيار . إذا كان هذا
!> أقل بكثير من 1، فقد يكون استقرار التحلل LU للمصفوفة (المتوازنة)
!> A ضعيفًا. هذا يعني أيضًا أن الحل X، وتقديرات أعداد الشرط، وحدود الخطأ قد تكون
!> غير موثوقة.
!>

المعاملات

UPLO 
!>          UPLO هو CHARACTER*1
!>       = 'U':  المثلث العلوي من A مخزن؛
!>       = 'L':  المثلث السفلي من A مخزن.
!>

N

!>          N هو INTEGER
!>     عدد معادلات الخطية، أي ترتيب المصفوفة A. N >= 0.
!>

INFO

!>          INFO هو INTEGER
!>     القيمة INFO التي تم إرجاعها من DSYTRF، أي، المحور في
!>     العمود INFO هو 0 تمامًا.
!>

A

!>          A هو مصفوفة DOUBLE PRECISION، البعد (LDA,N)
!>     عند الدخول، المصفوفة A بحجم N-by-N.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرئيسي للمصفوفة A. LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة DOUBLE PRECISION، البعد (LDAF,N)
!>     المصفوفة القطرية الفرعية D والمضاعفات المستخدمة للحصول على
!>     المعامل U أو L كما تم حسابه بواسطة DSYTRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرئيسي للمصفوفة AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV هو مصفوفة INTEGER، البعد (N)
!>     تفاصيل التبادلات والبنية الفرعية لـ D
!>     كما تم تحديده بواسطة DSYTRF.
!>

WORK

!>          WORK هو مصفوفة DOUBLE PRECISION، البعد (2*N)
!>
