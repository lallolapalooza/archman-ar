double precision function dlangb (norm, n, kl, ku, ab, ldab, work)


DLANGB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة عامة ذات نطاق.

توثيق الوظيفة/الإجراء الفرعي

double precision function dlangb (character norm, integer n, integer kl, integer ku, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

DLANGB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة عامة ذات نطاق.

الغرض:

!>
!> DLANGB  تُرجع قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> معيار اللانهاية، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة
!> بحجم n × n ذات نطاق، مع kl قطرات فرعية و ku قطرات فائقة.
!>

العودة

DLANGB 
!>
!>    DLANGB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يمثل المعيار واحد للمصفوفة (أقصى مجموع أعمدة)،
!> normI  يمثل معيار اللانهاية  للمصفوفة (أقصى مجموع صفوف) و
!> normF  يمثل معيار فروبينيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في DLANGB كما هو موضح
!>          أعلاه.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين DLANGB
!>          إلى الصفر.
!>

KL

!>          KL is INTEGER
!>          عدد القطرات الفرعية للمصفوفة A.  KL >= 0.
!>

KU

!>          KU is INTEGER
!>          عدد القطرات الفائقة للمصفوفة A.  KU >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>          المصفوفة ذات النطاق A، مخزنة في الصفوف من 1 إلى KL+KU+1.  العمود j
!>          من A مخزن في العمود j من المصفوفة AB كما يلي:
!>          AB(ku+1+i-j,j) = A(i,j) for max(1,j-ku)<=i<=min(n,j+kl).
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= KL+KU+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما NORM = 'I'؛ بخلاف ذلك، لا يتم الرجوع إلى
!>          WORK.
!>
