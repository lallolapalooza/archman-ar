DLATM2

توثيق الوظيفة/الروتين الفرعي

double precision function dlatm2 (integer m, integer n, integer i, integer j, integer kl, integer ku, integer idist, integer, dimension( 4 ) iseed, double precision, dimension( * ) d, integer igrade, double precision, dimension( * ) dl, double precision, dimension( * ) dr, integer ipvtng, integer, dimension( * ) iwork, double precision sparse)

DLATM2

الغرض:

!>
!>    DLATM2 تُرجع الإدخال (I,J) لمصفوفة عشوائية ذات أبعاد
!>    (M, N) موصوفة بالمعلمات الأخرى. يتم استدعاؤها بواسطة
!>    الروتين DLATMR لبناء مصفوفات اختبار عشوائية. لا يتم فحص الأخطاء
!>    على المعلمات، لأن هذه الروتين يتم استدعاؤه في
!>    حلقة ضيقة بواسطة DLATMR الذي قد قام بالفعل بفحص المعلمات.
!>
!>    يختلف استخدام DLATM2 عن SLATM3 في ترتيب مولد الأرقام العشوائية
!>    المستدعى لملء إدخالات المصفوفة العشوائية.
!>    مع DLATM2، يتم استدعاء المولد لملء المصفوفة
!>    عمودياً. مع DLATM3، يتم استدعاء المولد لملء
!>    المصفوفة عمودياً، وبعد ذلك يتم تبديلها. وبالتالي، يمكن استخدام DLATM3
!>    لبناء مصفوفات عشوائية تختلف فقط في ترتيب
!>    صفوفها و/أو أعمدتها. تُستخدم DLATM2 لبناء
!>    مصفوفات نطاق مع تجنب استدعاء مولد الأرقام العشوائية
!>    للإدخالات خارج النطاق (وبالتالي توليد أرقام عشوائية
!>
!>    المصفوفة التي تمثل إدخالها (I,J) يتم إنشاؤها كالتالي
!>    (هذا الروتين يحسب إدخالًا واحدًا فقط):
!>
!>      إذا كان I خارج (1..M) أو J خارج (1..N)، أرجع صفرًا
!>         (هذا مناسب لتوليد مصفوفات بصيغة نطاق).
!>
!>      قم بتوليد مصفوفة A بإدخالات عشوائية من التوزيع IDIST.
!>
!>      قم بتعيين القطر إلى D.
!>
!>      قم بترتيب المصفوفة، إذا رغبت، من اليسار (بواسطة DL) و/أو
!>         من اليمين (بواسطة DR أو DL) كما هو محدد بواسطة IGRADE.
!>
!>      قم بتبديل الصفوف و/أو الأعمدة، إذا رغبت، كما هو محدد بواسطة
!>         IPVTNG و IWORK.
!>
!>      قم بتحويل المصفوفة إلى نطاق بحيث يكون لديها عرض نطاق سفلي KL
!>         وعرض نطاق علوي KU.
!>
!>      قم بتعيين إدخالات عشوائية إلى صفر كما هو محدد بواسطة SPARSE.
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>           عدد صفوف المصفوفة. لا يتم تعديله.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>           عدد أعمدة المصفوفة. لا يتم تعديله.
!>

I

!>          I هو عدد صحيح (INTEGER)
!>           صف الإدخال المراد إرجاعه. لا يتم تعديله.
!>

J

!>          J هو عدد صحيح (INTEGER)
!>           عمود الإدخال المراد إرجاعه. لا يتم تعديله.
!>

KL

!>          KL هو عدد صحيح (INTEGER)
!>           عرض النطاق السفلي. لا يتم تعديله.
!>

KU

!>          KU هو عدد صحيح (INTEGER)
!>           عرض النطاق العلوي. لا يتم تعديله.
!>

IDIST

!>          IDIST هو عدد صحيح (INTEGER)
!>           عند الإدخال، يحدد IDIST نوع التوزيع المراد
!>           استخدامه لتوليد مصفوفة عشوائية.
!>           1 => موحد (UNIFORM) (0, 1)
!>           2 => موحد (UNIFORM) (-1, 1)
!>           3 => طبيعي (NORMAL) (0, 1)
!>           لا يتم تعديله.
!>

ISEED

!>          ISEED هو مصفوفة عدد صحيح (INTEGER) ذات أبعاد ( 4 )
!>           بذرة لمولد الأرقام العشوائية.
!>           تتغير عند الخروج.
!>

D

!>          D هي مصفوفة double precision ذات أبعاد ( MIN( I , J ) )
!>           عناصر القطر للمصفوفة. لا يتم تعديلها.
!>

IGRADE

!>          IGRADE هو عدد صحيح (INTEGER)
!>           يحدد ترتيب المصفوفة على النحو التالي:
!>           0  => لا ترتيب
!>           1  => يتم ضرب المصفوفة مسبقًا بالقطر (diag( DL ))
!>           2  => يتم ضرب المصفوفة لاحقًا بالقطر (diag( DR ))
!>           3  => يتم ضرب المصفوفة مسبقًا بالقطر (diag( DL )) و
!>                         لاحقًا بالقطر (diag( DR ))
!>           4  => يتم ضرب المصفوفة مسبقًا بالقطر (diag( DL )) و
!>                         لاحقًا بمقلوب القطر (inv( diag( DL ) ))
!>           5  => يتم ضرب المصفوفة مسبقًا بالقطر (diag( DL )) و
!>                         لاحقًا بالقطر (diag( DL ))
!>           لا يتم تعديله.
!>

DL

!>          DL هي مصفوفة double precision ( I أو J، حسب الاقتضاء )
!>           عوامل المقياس الأيسر لترتيب المصفوفة. لا يتم تعديلها.
!>

DR

!>          DR هي مصفوفة double precision ( I أو J، حسب الاقتضاء )
!>           عوامل المقياس الأيمن لترتيب المصفوفة. لا يتم تعديلها.
!>

IPVTNG

!>          IPVTNG هو عدد صحيح (INTEGER)
!>           عند الإدخال يحدد تباديل الصفوف على النحو التالي:
!>           0 => لا شيء.
!>           1 => تبديل الصفوف.
!>           2 => تبديل الأعمدة.
!>           3 => تبديل كامل، أي على كلا الجانبين.
!>           لا يتم تعديله.
!>

IWORK

!>          IWORK هي مصفوفة عدد صحيح (INTEGER) ( I أو J، حسب الاقتضاء )
!>           تحدد هذه المصفوفة التبديل المستخدم.
!>           الصف (أو العمود) في الموضع K كان أصلاً في
!>           الموضع IWORK( K ).
!>           يختلف هذا عن IWORK لـ DLATM3. لا يتم تعديله.
!>

SPARSE

!>          SPARSE هي double precision بين 0. و 1.
!>           عند الإدخال يحدد ندرة المصفوفة
!>           إذا كان سيتم توليد مصفوفة نادرة.
!>           يجب أن تكون SPARSE بين 0 و 1.
!>           يتم توليد رقم عشوائي موحد ( 0، 1 ) x
!>           ويتم مقارنته بـ SPARSE؛ إذا كان x أكبر، يظل إدخال المصفوفة
!>           دون تغيير، وإذا كان x أصغر، يتم تعيين الإدخال
!>           إلى صفر. وبالتالي، في المتوسط، سيتم تعيين نسبة fracción من
!>           الإدخالات إلى الصفر.
!>           لا يتم تعديله.
!>
