subroutine dlasv2 (double precision f, double precision g, double precision h, double precision ssmin, double precision ssmax, double precision snr, double precision csr, double precision snl, double precision csl)

DLASV2 تحسب التحلل القيمي المفرد لمصفوفة مثلثة بحجم 2x2.

الغرض:

!>
!> DLASV2 تحسب التحلل القيمي المفرد لمصفوفة مثلثة بحجم 2x2
!>    [  F   G  ]
!>    [  0   H  ].
!> عند العودة، abs(SSMAX) هو القيمة المفردة الأكبر، abs(SSMIN) هي
!> القيمة المفردة الأصغر، و (CSL,SNL) و (CSR,SNR) هما المتجهان المفردان الأيسر
!> والأيمن للقيمة abs(SSMAX)، مما يعطي التحلل
!>
!>    [ CSL  SNL ] [  F   G  ] [ CSR -SNR ]  =  [ SSMAX   0   ]
!>    [-SNL  CSL ] [  0   H  ] [ SNR  CSR ]     [  0    SSMIN ].
!>

المعلمات

F 
!>          F is DOUBLE PRECISION
!>          العنصر (1,1) للمصفوفة 2x2.
!>

G

!>          G is DOUBLE PRECISION
!>          العنصر (1,2) للمصفوفة 2x2.
!>

H

!>          H is DOUBLE PRECISION
!>          العنصر (2,2) للمصفوفة 2x2.
!>

SSMIN

!>          SSMIN is DOUBLE PRECISION
!>          abs(SSMIN) هي القيمة المفردة الأصغر.
!>

SSMAX

!>          SSMAX is DOUBLE PRECISION
!>          abs(SSMAX) هي القيمة المفردة الأكبر.
!>

SNL

!>          SNL is DOUBLE PRECISION
!>

CSL

!>          CSL is DOUBLE PRECISION
!>          المتجه (CSL, SNL) هو متجه مفرد أيسر للوحدة للقيمة المفردة
!>          abs(SSMAX).
!>

SNR

!>          SNR is DOUBLE PRECISION
!>

CSR

!>          CSR is DOUBLE PRECISION
!>          المتجه (CSR, SNR) هو متجه مفرد أيمن للوحدة للقيمة المفردة
!>          abs(SSMAX).
!>
