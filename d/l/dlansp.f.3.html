double precision function dlansp (norm, uplo, n, ap, work)
DLANSP تُرجع قيمة المعيار 1، أو معيار Frobenius، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة متماثلة مقدمة في شكل مضغوط.

توثيق الدالة/الإجراء الفرعي

double precision function dlansp (character norm, character uplo, integer n, double precision, dimension( * ) ap, double precision, dimension( * ) work)

DLANSP تُرجع قيمة المعيار 1، أو معيار Frobenius، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة متماثلة مقدمة في شكل مضغوط.

الغرض:

!>
!> DLANSP  تُرجع قيمة المعيار واحد،  أو معيار Frobenius،  أو
!> المعيار اللانهائي،  أو  العنصر ذو القيمة المطلقة الأكبر لمصفوفة
!> متماثلة حقيقية A،  مقدمة في شكل مضغوط.
!>

ترجع

DLANSP 
!>
!>    DLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يمثل  المعيار واحد لمصفوفة (مجموع أعمدة الأقصى)،
!> normI  يمثل  المعيار اللانهائي  لمصفوفة  (مجموع صفوف الأقصى) و
!> normF  يمثل  معيار Frobenius  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في DLANSP كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي المثلثي للمصفوفة
!>          المتماثلة A مقدمًا.
!>          = 'U':  الجزء العلوي المثلثي من A مقدم
!>          = 'L':  الجزء السفلي المثلثي من A مقدم
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين DLANSP
!>          إلى صفر.
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          الجزء العلوي أو السفلي المثلثي للمصفوفة المتماثلة A، مضغوط
!>          حسب العمود في مصفوفة خطية.  يتم تخزين العمود j من A
!>          في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'؛ بخلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
