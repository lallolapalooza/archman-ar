توثيق الوظيفة/الوحدة الفرعية

subroutine dlanv2 (double precision a, double precision b, double precision c, double precision d, double precision rt1r, double precision rt1i, double precision rt2r, double precision rt2i, double precision cs, double precision sn)

DLANV2 تحسب التحلل Schur لمصفوفة حقيقية 2x2 غير متماثلة في شكل قياسي:

الغرض:

!>
!> DLANV2 تحسب التحلل Schur لمصفوفة حقيقية 2x2 غير متماثلة في شكل قياسي:
!>
!>      [ A  B ] = [ CS -SN ] [ AA  BB ] [ CS  SN ]
!>      [ C  D ]   [ SN  CS ] [ CC  DD ] [-SN  CS ]
!>
!> حيث إما
!> 1) CC = 0 بحيث تكون AA و DD قيمًا ذاتية حقيقية للمصفوفة، أو
!> 2) AA = DD و BB*CC < 0، بحيث تكون AA + أو - sqrt(BB*CC) قيمًا ذاتية مترافقة مركبة.
!>
