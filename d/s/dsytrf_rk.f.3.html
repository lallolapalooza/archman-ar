NAME

dsytrf_rk - dsytrf_rk

SYNOPSIS

SUBROUTINE DSYTRF_RK(
   UPLO, N, A, LDA,
   IPIV, WORK, LWORK, INFO
)
INTEGER :: INFO
INTEGER :: LDA, LWORK, N
REAL(8) :: A( * ), WORK( * )
INTEGER :: IPIV( * )
CHARACTER( LEN = 1 ) :: UPLO

Function/Subroutine Documentation

!>
!>  Purpose
!>  =======
!>
!>  DSYTRF_RK computes the factorization of a real symmetric matrix
!>  A = P * D * P**T * U**T * U if UPLO = 'U', or
!>  A = P * D * P**T * L**T * L if UPLO = 'L',
!>  where D is a block diagonal matrix of order n consisting of
!>  1-by-1 and 2-by-2 diagonal blocks.
!>  P is a sparse permutation matrix, U is an upper triangular matrix
!>  with unit diagonal elements and L is a lower triangular matrix with
!>  unit diagonal elements. U**T*U is and L**T*L are the U or L factors
!>  from a block UDU or LDL factorization, respectively.
!>
!>  Arguments
!>  =========
!>
!>  UPLO    (input) CHARACTER(LEN=1)
!>          Specifies whether the factors U and L are upper or lower
!>          triangular matrices:
!>          = 'U': U**T*U factors are computed for the upper triangle;
!>          = 'L': L**T*L factors are computed for the lower triangle.
!>
!>  N       (input) INTEGER
!>          The order of the matrix A.  N >= 0.
!>
!>  A       (input/output) REAL(8) array, dimension (LDA,N)
!>          On entry, the symmetric matrix A.
!>          On exit, the factors U and L and the block diagonal matrix D.
!>          The elements of D may be stored in the diagonal elements of A.
!>          See Further Details for the structure of A on exit.
!>
!>  LDA     (input) INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>
!>  IPIV    (output) INTEGER array, dimension (N)
!>          Details of the block factorization and the block
!>          diagonal structure are needed for the block LDL factorization.
!>          For 1 < k <= N, IPIV(k) specifies the type of block:
!>          If IPIV(k) > 0, then D(k,k) is a 1-by-1 block IPIV(k) and
!>          no exchange was made.
!>          If IPIV(k) < 0, then D(k,k) is a 2-by-2 block,
!>          and the permutation sends row k+1 to row k.
!>
!>  WORK    (workspace) REAL(8) array, dimension (LWORK)
!>
!>  LWORK   (input) INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,N).
!>          For optimal efficiency if LWORK is large enough, the block
!>          size k where the algorithm switches to block factorization
!>          can be used.
!>
!>  INFO    (output) INTEGER
!>          = 0:  successful exit
!>          > 0:  if INFO = k, D(k,k) is a 2-by-2 block and is exactly
!>                singular. D is thus singular. The factorization has been
!>                completed but it is not useful for solving equations.
!>
!>  Details
!>  =======
!>
!>  The factorization is a block version of the factorization
!>  with rook pivoting. The factorization is formed in the following steps:
!>
!>  1.  Obtain the factorization A = P * D * P**T * U**T * U by
!>      calling DSYTRF.
!>  2.  Further factorize the block diagonal matrix D into block UDU or LDL
!>      factorization.
!>
!>  The factorization is not unique. For example, if D(k,k) is a 2-by-2
!>  block D = diag( ..., D(k,k), ... ), where
!>
!>        D(k,k) = ( d11 d12 )
!>                 ( d21 d22 )
!>
!>  Then D(k,k) can be written as D(k,k) = U1**T * D1 * U1, where
!>
!>        D1 = ( d11   0  )
!>             (  0  d22' )
!>
!>  or D(k,k) can be written as D(k,k) = L1 * D1 * L1**T, where
!>
!>        D1 = ( d11'  0  )
!>             (  0   d22 )
!>
!>  The factorization can be completed by calling DSYTRF to obtain
!>  the U and L factors and the diagonal matrix D.
!>
!>  The factorization also involves pivoting. The diagonal elements of
!>  the block matrix D are stored in the diagonal elements of A.
!>  The elements of the U and L factors are stored in the upper and lower
!>  triangular parts of A respectively.
!>
!>  The permutation information is stored in the array IPIV.
!>
!>  NOTE: INFO only stores the first occurrence of
!>  a singularity, any subsequent occurrence of singularity
!>  is not stored in INFO even though the factorization
!>  always completes.
!>
