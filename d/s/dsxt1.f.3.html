وثائق الوظيفة/الإجراء الفرعي

double precision function dsxt1 (integer ijob, double precision, dimension( * ) d1, integer n1, double precision, dimension( * ) d2, integer n2, double precision abstol, double precision ulp, double precision unfl)

DSXT1

الغرض:

!>
!> DSXT1  يحسب الفرق بين مجموعة من القيم الذاتية.
!> يتم إرجاع النتيجة كقيمة للدالة.
!>
!> IJOB = 1:   يحسب   max { min | D1(i)-D2(j) | }
!>                         i     j
!>
!> IJOB = 2:   يحسب   max { min | D1(i)-D2(j) | /
!>                         i     j
!>                              ( ABSTOL + |D1(i)|*ULP ) }
!>

المعلمات

IJOB 
!>          IJOB هو عدد صحيح (INTEGER)
!>          يحدد نوع الاختبارات التي سيتم إجراؤها.  (انظر أعلاه.)
!>

D1

!>          D1 هو مصفوفة من الدقة المزدوجة (DOUBLE PRECISION)، البعد (N1)
!>          المصفوفة الأولى.  يجب أن تكون D1 بترتيب متزايد، أي،
!>          D1(j) <= D1(j+1).
!>

N1

!>          N1 هو عدد صحيح (INTEGER)
!>          طول D1.
!>

D2

!>          D2 هو مصفوفة من الدقة المزدوجة (DOUBLE PRECISION)، البعد (N2)
!>          المصفوفة الثانية.  يجب أن تكون D2 بترتيب متزايد، أي،
!>          D2(j) <= D2(j+1).
!>

N2

!>          N2 هو عدد صحيح (INTEGER)
!>          طول D2.
!>

ABSTOL

!>          ABSTOL هو دقة مزدوجة (DOUBLE PRECISION)
!>          التفاوت المطلق، يستخدم كمقياس للخطأ.
!>

ULP

!>          ULP هو دقة مزدوجة (DOUBLE PRECISION)
!>          دقة الآلة.
!>

UNFL

!>          UNFL هو دقة مزدوجة (DOUBLE PRECISION)
!>          أصغر رقم موجب لا يتجاوز معكوسه عن طريق الخطأ.
!>
