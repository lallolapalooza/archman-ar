توثيق الوظيفة/الإجراء الفرعي

subroutine dsptri (character uplo, integer n, double precision, dimension( * ) ap, integer, dimension( * ) ipiv, double precision, dimension( * ) work, integer info)

DSPTRI

الغرض:

!>
!> DSPTRI يحسب معكوس مصفوفة متماثلة غير محددة حقيقية
!> A في تخزين مضغوط باستخدام التحليل A = U*D*U**T أو
!> A = L*D*L**T الذي تم حسابه بواسطة DSPTRF.
!>

المعاملات

UPLO 
!>          UPLO is CHARACTER*1
!>          تحدد ما إذا كانت تفاصيل التحليل مخزنة
!>          كمصفوفة مثلثية عليا أو سفلى.
!>          = 'U':  مثلثية عليا، الشكل هو A = U*D*U**T؛
!>          = 'L':  مثلثية سفلى، الشكل هو A = L*D*L**T.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)
!>          عند الإدخال، المصفوفة القطرية الفرعية D والمعاملات
!>          المستخدمة للحصول على العامل U أو L كما تم حسابه بواسطة DSPTRF،
!>          مخزنة كمصفوفة مثلثية مضغوطة.
!>
!>          عند الخروج، إذا كان INFO = 0، معكوس (متماثل) للمصفوفة الأصلية،
!>          مخزن كمصفوفة مثلثية مضغوطة. العمود j من inv(A)
!>          مخزن في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = inv(A)(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'،
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) لـ j<=i<=n.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          تفاصيل التبادلات والبنية الفرعية لـ D
!>          كما تم تحديدها بواسطة DSPTRF.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية
!>          > 0: إذا كان INFO = i، فإن D(i,i) = 0؛ المصفوفة مفردة ولا يمكن حساب معكوسها.
!>
