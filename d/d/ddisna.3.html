subroutine ddisna (character job, integer m, integer n, double precision, dimension( * ) d, double precision, dimension( * ) sep, integer info)

DDISNA

الغرض:

!>
!> DDISNA يحسب الأرقام الشرطية المعكوسة للمتجهات الذاتية لمصفوفة حقيقية متناظرة أو معقدة هرميتية أو للمتجهات المنفردة اليسرى أو اليمنى لمصفوفة عامة m-by-n. الرقم الشرطي المعكوس هو 'الفجوة' بين القيمة الذاتية أو القيمة المنفردة المقابلة وأقرب قيمة أخرى.
!>
!> الحد الأقصى للخطأ، المقاس بالزاوية بالراديان، في المتجه المحسوب I معطى بواسطة
!>
!>        DLAMCH( 'E' ) * ( ANORM / SEP( I ) )
!>
!> حيث ANORM = 2-norm(A) = max( abs( D(j) ) ). لا يُسمح لـ SEP(I) بأن تكون أصغر من DLAMCH( 'E' )*ANORM للحد من حجم حد الخطأ.
!>
!> قد تُستخدم DDISNA أيضًا لحساب حدود الخطأ للمتجهات الذاتية لمشكلة القيم الذاتية المتناظرة المحددة المعممة.
!>

المعلمات

JOB 
!>          JOB is CHARACTER*1
!>          يحدد للمشكلة التي سيتم حساب الأرقام الشرطية المعكوسة لها:
!>          = 'E':  المتجهات الذاتية لمصفوفة متناظرة/هرميتية؛
!>          = 'L':  المتجهات المنفردة اليسرى لمصفوفة عامة؛
!>          = 'R':  المتجهات المنفردة اليمنى لمصفوفة عامة.
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة. M >= 0.
!>

N

!>          N is INTEGER
!>          إذا كان JOB = 'L' أو 'R'، فإن عدد أعمدة المصفوفة،
!>          وفي هذه الحالة N >= 0. يتم تجاهلها إذا كان JOB = 'E'.
!>

D

!>          D is DOUBLE PRECISION array, dimension (M) if JOB = 'E'
!>                              dimension (min(M,N)) if JOB = 'L' or 'R'
!>          القيم الذاتية (إذا كان JOB = 'E') أو القيم المنفردة (إذا كان JOB =
!>          'L' أو 'R') للمصفوفة، بترتيب متزايد أو متناقص. إذا كانت قيمًا منفردة، فيجب أن تكون غير سالبة.
!>

SEP

!>          SEP is DOUBLE PRECISION array, dimension (M) if JOB = 'E'
!>                               dimension (min(M,N)) if JOB = 'L' or 'R'
!>          الأرقام الشرطية المعكوسة للمتجهات.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  الخروج بنجاح.
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية.
!>
