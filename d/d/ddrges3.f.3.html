subroutine ddrges3 (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( lda, * ) b, double precision, dimension( lda, * ) s, double precision, dimension( lda, * ) t, double precision, dimension( ldq, * ) q, integer ldq, double precision, dimension( ldq, * ) z, double precision, dimension( * ) alphar, double precision, dimension( * ) alphai, double precision, dimension( * ) beta, double precision, dimension( * ) work, integer lwork, double precision, dimension( 13 ) result, logical, dimension( * ) bwork, integer info)

DDRGES3

الغرض:

!>
!> DDRGES3 يتحقق من مشغل مشكلة القيم الذاتية المعممة غير المتناظرة (شكل شور)
!> DGGES3.
!>
!> يقوم DGGES3 بتفكيك A و B إلى Q S Z' و Q T Z' ، حيث ' تعني
!> تبديل، T مثلثة عليا، S في شكل شور المعمم
!> (كتلة مثلثية عليا، مع كتل 1x1 و 2x2 على القطر،
!> الكتل 2x2 المقابلة لأزواج مترافقة معقدة من
!> القيم الذاتية المعممة)، و Q و Z متعامدتان. كما أنها
!> تحسب القيم الذاتية المعممة (alpha(j),beta(j))، j=1,...,n،
!> وبالتالي، w(j) = alpha(j)/beta(j) هو جذر المعادلة المميزة
!> det( A - w(j) B ) = 0
!> اختياريًا، تعيد ترتيب القيم الذاتية لوضع
!> مجموعة مختارة من القيم الذاتية في الكتلة القطرية الأمامية لـ
!> أشكال شور.
!>
!> عند استدعاء DDRGES3، سيتم تحديد عدد من المصفوفات () و
!> عدد من المصفوفات (). لكل حجم ()
!> ولكل نوع من المصفوفات، سيتم إنشاء زوج من المصفوفات (A, B)
!> واستخدامه للاختبار. لكل زوج مصفوفات، سيتم إجراء الاختبارات الـ 13 التالية
!> ومقارنتها بالحدTHRESH باستثناء الاختبارات (5)، (11)، و (13).
!>
!>
!> (1) | A - Q S Z' | / ( |A| n ulp ) (بدون فرز للقيم الذاتية)
!>
!>
!> (2) | B - Q T Z' | / ( |B| n ulp ) (بدون فرز للقيم الذاتية)
!>
!>
!> (3) | I - QQ' | / ( n ulp ) (بدون فرز للقيم الذاتية)
!>
!>
!> (4) | I - ZZ' | / ( n ulp ) (بدون فرز للقيم الذاتية)
!>
!> (5) إذا كانت A في شكل شور (أي، شكل شبه مثلثي)
!> (بدون فرز للقيم الذاتية)
!>
!> (6) إذا كانت القيم الذاتية = كتل قطرية لشكل شور (S, T)،
!> أي، اختبار الحد الأقصى فوق j لـ D(j) حيث:
!>
!> إذا كان alpha(j) حقيقيًا:
!> |alpha(j) - S(j,j)| |beta(j) - T(j,j)|
!> D(j) = ------------------------ + -----------------------
!> max(|alpha(j)|,|S(j,j)|) max(|beta(j)|,|T(j,j)|)
!>
!> إذا كان alpha(j) معقدًا:
!> | det( s S - w T ) |
!> D(j) = ---------------------------------------------------
!> ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!> و S و T هنا هما الكتل القطرية 2 × 2 من S و T
!> المقابلة للقيم الذاتية j و j+1.
!> (بدون فرز للقيم الذاتية)
!>
!> (7) | (A,B) - Q (S,T) Z' | / ( | (A,B) | n ulp )
!> (مع فرز القيم الذاتية).
!>
!> (8) | I - QQ' | / ( n ulp ) (مع فرز القيم الذاتية).
!>
!> (9) | I - ZZ' | / ( n ulp ) (مع فرز القيم الذاتية).
!>
!> (10) إذا كانت A في شكل شور (أي، شكل شبه مثلثي)
!> (مع فرز القيم الذاتية).
!>
!> (11) إذا كانت القيم الذاتية = كتل قطرية لشكل شور (S, T)،
!> أي، اختبار الحد الأقصى فوق j لـ D(j) حيث:
!>
!> إذا كان alpha(j) حقيقيًا:
!> |alpha(j) - S(j,j)| |beta(j) - T(j,j)|
!> D(j) = ------------------------ + -----------------------
!> max(|alpha(j)|,|S(j,j)|) max(|beta(j)|,|T(j,j)|)
!>
!> إذا كان alpha(j) معقدًا:
!> | det( s S - w T ) |
!> D(j) = ---------------------------------------------------
!> ulp max( s norm(S), |w| norm(T) )*norm( s S - w T )
!>
!> و S و T هنا هما الكتل القطرية 2 × 2 من S و T
!> المقابلة للقيم الذاتية j و j+1.
!> (مع فرز القيم الذاتية).
!>
!> (12) إذا نجح الفرز و SDIM هو عدد القيم الذاتية
!> التي تم تحديدها.
!>
!> مصفوفات الاختبار
!> =============
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد الأنواع بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كانت DOTYPE(j) تساوي .TRUE.، فسيتم إنشاء مصفوفة النوع j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1) ( 0, 0 ) (زوج من المصفوفات الصفرية)
!>
!> (2) ( I, 0 ) (مصفوفة الهوية ومصفوفة صفرية)
!>
!> (3) ( 0, I ) (مصفوفة صفرية ومصفوفة هوية)
!>
!> (4) ( I, I ) (زوج من مصفوفات الهوية)
!>
!> t t
!> (5) ( J , J ) (زوج من كتل جوردان المبدلة)
!>
!> ( I 0 )
!> (6) ( X, Y ) حيث X = ( J 0 ) و Y = ( t )
!> ( 0 I ) ( 0 J )
!> و I مصفوفة هوية k x k و J كتلة جوردان (k+1)x(k+1)
!> k = (N-1)/2
!>
!> (7) ( D, I ) حيث D هي diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!> بتلك الإدخالات القطرية.)
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) حيث big قريب من الفائض و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!> D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!> t t
!> (16) Q ( J , J ) Z حيث Q و Z مصفوفتان متعامدتان عشوائيتان.
!>
!> (17) Q ( T1, T2 ) Z حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!> بإدخالات عشوائية O(1) فوق القطر
!> وإدخالات قطرية diag(T1) =
!> ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!> ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!> diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!> s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!> N-5
!> (20) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, 1, a, ..., a =s, 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!> حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, 0, ..., 0 )
!>
