double precision function dqrt12 (m, n, a, lda, s, work, lwork)
DQRT12

وثائق الوظيفة/الإجراء الفرعي

double precision function dqrt12 (integer m, integer n, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( * ) s, double precision, dimension( lwork ) work, integer lwork)

DQRT12

الغرض:

!>
!> DQRT12 يحسب القيم المفردة `svlues' للشبه المنحرف العلوي
!> لـ A(1:M,1:N) ويعيد النسبة
!>
!>      || svlues - s ||/(||s||*eps*max(M,N))
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>          عدد صفوف المصفوفة A.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>          عدد أعمدة المصفوفة A.
!>

A

!>          A هي مصفوفة من نوع double precision، بأبعاد (LDA,N)
!>          المصفوفة M-by-N المسماة A. يتم الإشارة فقط إلى شبه المنحرف العلوي.
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البعد الرائد للمصفوفة A.
!>

S

!>          S هي مصفوفة من نوع double precision، بأبعاد (min(M,N))
!>          القيم المفردة للمصفوفة A.
!>

WORK

!>          WORK هي مصفوفة من نوع double precision، بأبعاد (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح (INTEGER)
!>          طول المصفوفة WORK. LWORK >= max(M*N + 4*min(M,N) +
!>          max(M,N), M*N+2*MIN( M, N )+4*N).
!>
