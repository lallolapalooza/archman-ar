توثيق الوظيفة/الإجراء الفرعي

double precision function dqrt14 (character trans, integer m, integer n, integer nrhs, double precision, dimension( lda, * ) a, integer lda, double precision, dimension( ldx, * ) x, integer ldx, double precision, dimension( lwork ) work, integer lwork)

DQRT14

الغرض:

!>
!> DQRT14 يتحقق مما إذا كانت X في الفضاء الصفّي لـ A أو A'. يتم ذلك
!> عن طريق تحجيم كل من X و A بحيث تكون معاييرهما في النطاق
!> [sqrt(eps), 1/sqrt(eps)]، ثم حساب تحليل QR لـ [A,X]
!> (إذا كان TRANS = 'T') أو تحليل LQ لـ [A',X]' (إذا كان TRANS = 'N')،
!> وإرجاع معيار المثلث اللاحق، مقاسًا بـ
!> MAX(M,N,NRHS)*eps.
!>

المعلمات

TRANS 
!>          TRANS is CHARACTER*1
!>          = 'N':  لا يوجد تبديل، تحقق من X في الفضاء الصفّي لـ A
!>          = 'T':  تبديل، تحقق من X في الفضاء الصفّي لـ A'.
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة A.
!>

NRHS

!>          NRHS is INTEGER
!>          عدد الأطراف اليمنى، أي عدد أعمدة
!>          X.
!>

A

!>          A is DOUBLE PRECISION array, dimension (LDA,N)
!>          المصفوفة A بحجم M × N.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.
!>

X

!>          X is DOUBLE PRECISION array, dimension (LDX,NRHS)
!>          إذا كان TRANS = 'N'، فإن المصفوفة X بحجم N × NRHS.
!>          إذا كان TRANS = 'T'، فإن المصفوفة X بحجم M × NRHS.
!>

LDX

!>          LDX is INTEGER
!>          البعد الرائد للمصفوفة X.
!>

WORK

!>          WORK is DOUBLE PRECISION array dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          طول مساحة العمل المطلوبة
!>          إذا كان TRANS = 'N'، فإن LWORK >= (M+NRHS)*(N+2)؛
!>          إذا كان TRANS = 'T'، فإن LWORK >= (N+NRHS)*(M+2).
!>
