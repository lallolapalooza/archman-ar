الترجمات ليست متكررة، لذلك تتجنب dwarfdump إجراء الترجمة أكثر من مرة على أي سلسلة نصية. انظر الخيار --format-suppress-sanitize أدناه لإزالة تحويل الإخراج.

--print-all (-a)

dwarfdump - dump the DWARF debugging information from an executable file.

NAME

dwarfdump - dump the DWARF debugging information from an executable file

SYNOPSIS

dwarfdump [-a] [-c] [-d] [-f] [-g] [-h] [-i] [-l] [-o] [-p] [-r] [-s] [-u] [-v] [-x] [-w] [--help] [--version] [-o output_format] [-n name] [-m compilation_unit] [-t tag] [-F format] [-I input_format] [-S input_format] [-U input_format] [-B base_address] [--] [file...]

DESCRIPTION

The dwarfdump utility reads DWARF debugging information from the specified executable files and prints it to standard output in a human-readable format. If no files are specified, dwarfdump reads from standard input.

DWARF is a debugging data format used by many compilers and debuggers to store information about the structure of a program, such as variables, functions, types, and source code locations.

OPTIONS

The following options are available:

-a
Dump all DWARF information. This is the default behavior.
-c
Dump compilation unit information.
-d
Dump DIE (Debug Information Entry) information.
-f
Dump function information.
-g
Dump global variable information.
-h
Dump header information.
-i
Dump inline function information.
-l
Dump line number information.
-o
Dump offset information.
-p
Dump producer information.
-r
Dump reference information.
-s
Dump string information.
-u
Dump unique identifier information.
-v
Dump variable information.
-x
Dump attribute information.
-w
Dump type information.
--help
Display a help message and exit.
--version
Display version information and exit.
-o output_format
Specify the output format. Supported formats are: txt, json, xml.
-n name
Dump information for the specified name (e.g., function name, variable name).
-m compilation_unit
Dump information for the specified compilation unit.
-t tag
Dump information for the specified tag (e.g., DW_TAG_variable, DW_TAG_function).
-F format
Specify the input format. Supported formats are: dwarf, gimli.
-I input_format
Specify the input format. This is an alias for -F.
-S input_format
Specify the input format. This is an alias for -F.
-U input_format
Specify the input format. This is an alias for -F.
-B base_address
Specify the base address for relocatable object files.
--
Treat all subsequent arguments as filenames, even if they start with a hyphen.

LIMITING OUTPUT

The following options can be used to limit the output to specific types of information:

-n name
Only dump information for entries with the specified name.
-m compilation_unit
Only dump information for the specified compilation unit.
-t tag
Only dump information for entries with the specified DWARF tag.

OTHER OPTIONS

The following options control the input and output formats:

-o output_format
Specify the output format. Supported formats are: txt, json, xml.
-F format, -I input_format, -S input_format, -U input_format
Specify the input format. Supported formats are: dwarf, gimli.
-B base_address
Specify the base address for relocatable object files.

SPLIT DWARF

If DWARF debugging information is split into separate files (e.g., using -gsplit-dwarf compiler option), dwarfdump can read this information by specifying the path to the .dwo or .dwi file.

FILES

file...
One or more executable files, object files, or archives to be processed. If no files are specified, standard input is used.

NOTES

dwarfdump relies on the libdwarf library for parsing DWARF information.

The output format can vary depending on the DWARF information present in the file and the options used.
