DROP_TRIGGER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP TRIGGER(7) توثيق PostgreSQL 18.1 DROP TRIGGER(7)

الاسم

DROP_TRIGGER - إزالة مشغل

الملخص

DROP TRIGGER [ IF EXISTS ] name ON table_name [ CASCADE | RESTRICT ]

الوصف

DROP TRIGGER يزيل تعريف مشغل موجود. لتنفيذ هذا الأمر، يجب أن يكون المستخدم الحالي هو مالك الجدول الذي تم تعريف المشغل له.

المعلمات

IF EXISTS

لا تصدر خطأ إذا لم يكن المشغل موجودًا. سيتم إصدار إشعار في هذه الحالة.

name

اسم المشغل المراد إزالته.

table_name

اسم الجدول (مع مؤهل المخطط اختياريًا) الذي تم تعريف المشغل له.

CASCADE

قم بإزالة الكائنات التي تعتمد على المشغل تلقائيًا، وبالدور جميع الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

ارفض إزالة المشغل إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الافتراضي.

أمثلة

تدمير المشغل if_dist_exists على الجدول films:

DROP TRIGGER if_dist_exists ON films;

التوافق

عبارة DROP TRIGGER في PostgreSQL غير متوافقة مع معيار SQL. في معيار SQL، أسماء المشغلات ليست محلية للجداول، لذا فإن الأمر هو ببساطة DROP TRIGGER name.
