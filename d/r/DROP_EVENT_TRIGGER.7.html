DROP_EVENT_TRIGGER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP EVENT TRIGGER(7) وثائق PostgreSQL 18.1 DROP EVENT TRIGGER(7)

الاسم

DROP_EVENT_TRIGGER - إزالة مشغل حدث

الملخص

DROP EVENT TRIGGER [ IF EXISTS ] name [ CASCADE | RESTRICT ]

الوصف

DROP EVENT TRIGGER يزيل مشغل حدث موجود. لتنفيذ هذا الأمر، يجب أن يكون المستخدم الحالي هو مالك مشغل الحدث.

المعلمات

IF EXISTS

لا تُصدر خطأ إذا لم يكن مشغل الحدث موجودًا. يتم إصدار إشعار في هذه الحالة.

name

اسم مشغل الحدث المراد إزالته.

CASCADE

إزالة تلقائيًا الكائنات التي تعتمد على المشغل، وبدورها جميع الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

رفض إزالة المشغل إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الافتراضي.

أمثلة

تدمير المشغل snitch:

DROP EVENT TRIGGER snitch;

التوافق

لا يوجد أمر DROP EVENT TRIGGER في معيار SQL.

انظر أيضاً

CREATE EVENT TRIGGER (CREATE_EVENT_TRIGGER(7)), ALTER EVENT TRIGGER (ALTER_EVENT_TRIGGER(7))
