remainder(3) دليل وظائف المكتبة remainder(3)

الاسم

drem، dremf، dreml، remainder، remainderf، remainderl - دالة الباقي ذات الفاصلة العائمة

المكتبة

مكتبة الرياضيات (libm، -lm)

الملخص

#include <math.h>
double remainder(double x, double y);
float remainderf(float x, float y);
long double remainderl(long double x, long double y);
/* مترادفات مهملة */
[[deprecated]] double drem(double x, double y);
[[deprecated]] float dremf(float x, float y);
[[deprecated]] long double dreml(long double x, long double y);
متطلبات ميزة الاختبار Macro لـ glibc (انظر feature_test_macros(7)):

remainder():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

remainderf()، remainderl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

drem()، dremf()، dreml():

    /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

الوصف

تقوم هذه الدوال بحساب باقي قسمة x على y. القيمة المرجعة هي x-n*y، حيث n هي القيمة x / y، مقربة إلى أقرب عدد صحيح. إذا كانت القيمة المطلقة لـ x-n*y تساوي 0.5، يتم اختيار n ليكون زوجيًا.

هذه الدوال لا تتأثر بوضع التقريب الحالي (انظر fenv(3)).

دالة drem() تقوم بنفس الشيء تمامًا.

قيمة الإرجاع

عند النجاح، تعيد هذه الدوال الباقي ذو الفاصلة العائمة، x-n*y. إذا كانت القيمة المرجعة 0، فإنها تحمل علامة x.

إذا كان x أو y عبارة عن NaN، يتم إرجاع NaN.

إذا كان x لا نهائيًا، و y ليس NaN، تحدث خطأ في النطاق (domain error)، ويتم إرجاع NaN.

إذا كان y صفرًا، و x ليس NaN، تحدث خطأ في النطاق (domain error)، ويتم إرجاع NaN.

الأخطاء

انظر math_error(7) لمعرفة كيفية تحديد ما إذا كان قد حدث خطأ عند استدعاء هذه الدوال.

يمكن أن تحدث الأخطاء التالية:

خطأ في النطاق: x لا نهائي و y ليس NaN
errno يتم تعيينه إلى EDOM (ولكن انظر BUGS). يتم رفع استثناء غير صالح للفاصلة العائمة (FE_INVALID).
هذه الدوال لا تقوم بتعيين errno لهذه الحالة.
خطأ في النطاق: y صفر
errno يتم تعيينه إلى EDOM. يتم رفع استثناء غير صالح للـ فاصلة العائمة (FE_INVALID).

الأخطاء

قبل glibc 2.15، الاستدعاء


remainder(nan(""), 0);

أرجعت NaN، كما هو متوقع، ولكنها تسببت بشكل خاطئ في خطأ في النطاق. منذ glibc 2.15، يتم إرجاع NaN صامت (أي، لا يوجد خطأ في النطاق).

قبل glibc 2.15، لم يتم تعيين errno إلى EDOM لخطأ النطاق الذي يحدث عندما يكون x لا نهائيًا و y ليس NaN.

أمثلة

الاستدعاء "remainder(29.0, 3.0)" يرجع -1.
