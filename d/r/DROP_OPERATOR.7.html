DROP_OPERATOR(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP OPERATOR(7) وثائق PostgreSQL 18.1 DROP OPERATOR(7)

الاسم

DROP_OPERATOR - إزالة عامل

الاختصار

DROP OPERATOR [ IF EXISTS ] name ( { left_type | NONE } , right_type ) [, ...] [ CASCADE | RESTRICT ]

الوصف

DROP OPERATOR تزيل عاملاً موجودًا من نظام قاعدة البيانات. لتنفيذ هذا الأمر، يجب أن تكون مالك العامل.

المعلمات

IF EXISTS

لا تطرح خطأ إذا لم يكن العامل موجودًا. يتم إصدار إشعار في هذه الحالة.

name

اسم عامل موجود (يمكن إضافة اسم المخطط إليه).

left_type

نوع بيانات المعامل الأيسر للعامل؛ اكتب NONE إذا لم يكن للعامل معامل أيسر.

right_type

نوع بيانات المعامل الأيمن للعامل.

CASCADE

إزالة الكائنات التي تعتمد على العامل تلقائيًا (مثل طرق العرض التي تستخدمه)، وبدورها جميع الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

رفض إزالة العامل إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الوضع الافتراضي.

أمثلة

إزالة عامل الرفع a^b للنوع الصحيح:

DROP OPERATOR ^ (integer, integer);

إزالة عامل المكمل الثنائي البادئ ~b للنوع bit:

DROP OPERATOR ~ (none, bit);

إزالة عوامل متعددة في أمر واحد:

DROP OPERATOR ~ (none, bit), ^ (integer, integer);

التوافق

لا يوجد عبارة DROP OPERATOR في معيار SQL.

انظر أيضًا
