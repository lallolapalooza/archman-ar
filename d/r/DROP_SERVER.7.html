DROP_SERVER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP SERVER(7) وثائق PostgreSQL 18.1 DROP SERVER(7)

اسم

DROP_SERVER - إزالة وصف الخادم الخارجي

ملخص

DROP SERVER [ IF EXISTS ] name [, ...] [ CASCADE | RESTRICT ]

الوصف

DROP SERVER تزيل وصف خادم خارجي موجود. لتنفيذ هذا الأمر، يجب أن يكون المستخدم الحالي هو مالك الخادم.

المعلمات

IF EXISTS

لا تطرح خطأ إذا لم يكن الخادم موجودًا. يتم إصدار إشعار في هذه الحالة.

name

اسم خادم موجود.

CASCADE

أسقِ تلقائيًا الكائنات التي تعتمد على الخادم (مثل تعيينات المستخدم)، وبدورها كل الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

ارفض إسقاط الخادم إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الافتراضي.

أمثلة

أسقِ الخادم foo إذا كان موجودًا:

DROP SERVER IF EXISTS foo;

التوافق

DROP SERVER يتوافق مع ISO/IEC 9075-9 (SQL/MED). بند IF EXISTS هو امتداد لـ PostgreSQL.

انظر أيضًا

CREATE SERVER (/man/CREATE_SERVER.7.en)، ALTER SERVER (/man/ALTER_SERVER.7.en)
