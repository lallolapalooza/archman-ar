dropbearkey(1)

الحزمة: dropbear

التراخيص: MIT

dropbearkey(1) دليل الأوامر العامة dropbearkey(1)

الاسم

dropbearkey - إنشاء مفاتيح خاصة للاستخدام مع dropbear(8) أو dbclient(1)

ملخص

dropbearkey -t type -f file [-s bits] [-y]

الوصف

يقوم dropbearkey بإنشاء مفتاح خاص بتنسيق SSH RSA أو DSS أو ECDSA أو Ed25519، ويحفظه في ملف للاستخدام مع عميل أو خادم Dropbear. لاحظ أن بعض تطبيقات SSH تستخدم المصطلح "DSA" بدلاً من "DSS"، وهما يعنيان نفس الشيء.

خيارات

-t type
نوع المفتاح المراد إنشاؤه. يجب أن يكون أحد الخيارات: rsa أو ecdsa أو ed25519 أو dss.
-f file
اكتب المفتاح السري إلى الملف file. للمصادقة من جانب العميل، يتم تحميل ~/.ssh/id_dropbear افتراضيًا.
-s bits
اضبط حجم المفتاح إلى bits بت، يجب أن يكون من مضاعفات العدد 8 (اختياري).
-y
فقط اطبع المفتاح العام والبصمة للمفتاح الخاص الموجود في file.

ملاحظات

يمكن استخدام البرنامج dropbearconvert(1) للتحويل بين تنسيقات مفاتيح Dropbear و OpenSSH.

Dropbear لا يدعم المفاتيح المشفرة.

مثال

إنشاء مفتاح مضيف:
# dropbearkey -t rsa -f /etc/dropbear/dropbear_rsa_host_key

استخراج مفتاح عام مناسب لـ authorized_keys من مفتاح خاص:
# dropbearkey -y -f id_rsa | grep "^ssh-rsa " >> authorized_keys
