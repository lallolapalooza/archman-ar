DROP_USER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP USER(7) توثيق PostgreSQL 18.1 DROP USER(7)

الاسم

DROP_USER - إزالة دور قاعدة بيانات

الملخص

DROP USER [ IF EXISTS ] name [, ...]

الوصف

DROP USER هو ببساطة تهجئة بديلة لـ DROP ROLE.

التوافق

عبارة DROP USER هي امتداد لـ PostgreSQL. يترك معيار SQL تعريف المستخدمين للتطبيق.

انظر أيضًا

DROP ROLE (DROP_ROLE(7))
