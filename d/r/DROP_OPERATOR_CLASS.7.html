DROP_OPERATOR_CLASS(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP OPERATOR CLASS(7) وثائق PostgreSQL 18.1 DROP OPERATOR CLASS(7)

الاسم

DROP_OPERATOR_CLASS - إزالة فئة عامل.

ملخص

DROP OPERATOR CLASS [ IF EXISTS ] name USING index_method [ CASCADE | RESTRICT ]

الوصف

DROP OPERATOR CLASS تزيل فئة عامل موجودة. لتنفيذ هذا الأمر، يجب أن تكون مالك فئة العامل.

DROP OPERATOR CLASS لا تزيل أي عوامل أو دوال تشير إليها الفئة. إذا كانت هناك أي فهارس تعتمد على فئة العامل، فستحتاج إلى تحديد CASCADE لإكمال الإزالة.

المعلمات

IF EXISTS

لا تعرض خطأ إذا كانت فئة العامل غير موجودة. يتم إصدار إشعار في هذه الحالة.

name

اسم (اختياري مع مؤهل المخطط) فئة عامل موجودة.

index_method

اسم طريقة الوصول للفهرس التي تم إنشاؤها فئة العامل لها.

CASCADE

قم بإزالة الكائنات التي تعتمد على فئة العامل تلقائيًا (مثل الفهارس)، وبدورها كل الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

رفض إزالة فئة العامل إذا كانت هناك أي كائنات تعتمد عليها. هذا هو الوضع الافتراضي.

ملاحظات

DROP OPERATOR CLASS لن تزيل عائلة العوامل التي تحتوي على الفئة، حتى لو لم يبق شيء آخر في العائلة (على وجه الخصوص، في حالة تم إنشاء العائلة ضمنيًا بواسطة CREATE OPERATOR CLASS). عائلة عوامل فارغة غير ضارة، ولكن من أجل التنظيم قد ترغب في إزالة العائلة باستخدام DROP OPERATOR FAMILY؛ أو ربما يكون من الأفضل استخدام DROP OPERATOR FAMILY في المقام الأول.

أمثلة

إزالة فئة العوامل B-tree widget_ops:

DROP OPERATOR CLASS widget_ops USING btree;

لن ينجح هذا الأمر إذا كانت هناك أي فهارس موجودة تستخدم فئة العامل. أضف CASCADE لإزالة مثل هذه الفهارس مع فئة العامل.

التوافق

لا يوجد بيان DROP OPERATOR CLASS في معيار SQL.

انظر أيضا
