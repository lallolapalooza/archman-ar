DROP_MATERIALIZED_VIEW(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP MATERIALIZED VIEW(7) توثيق PostgreSQL 18.1 DROP MATERIALIZED VIEW(7)

الاسم

DROP MATERIALIZED VIEW - إزالة عرض مجسم

موجز

DROP MATERIALIZED VIEW [ IF EXISTS ] name [, ...] [ CASCADE | RESTRICT ]

الوصف

DROP MATERIALIZED VIEW يقوم بإسقاط عرض مجسم موجود. لتنفيذ هذا الأمر، يجب أن تكون مالك العرض المجسم.

المعاملات

IF EXISTS

لا تُطلق خطأ إذا كان العرض المجسم غير موجود. يتم إصدار إشعار في هذه الحالة.

name

اسم العرض المجسم المراد إزالته (يمكن تحديده بالمخطط).

CASCADE

قم تلقائيًا بإسقاط الكائنات التي تعتمد على العرض المجسم (مثل العروض المجسمة الأخرى، أو العروض العادية)، وبدورها جميع الكائنات التي تعتمد على تلك الكائنات (راجع القسم 5.15).

RESTRICT

رفض إسقاط العرض المجسم إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الوضع الافتراضي.

أمثلة

سيقوم هذا الأمر بإزالة العرض المجسم المسمى order_summary:

DROP MATERIALIZED VIEW order_summary;

التوافق

DROP MATERIALIZED VIEW هو امتداد لـ PostgreSQL.
