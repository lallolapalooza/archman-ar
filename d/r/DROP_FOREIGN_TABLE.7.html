DROP_FOREIGN_TABLE(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP FOREIGN TABLE(7) توثيق PostgreSQL 18.1 DROP FOREIGN TABLE(7)

الاسم

DROP_FOREIGN_TABLE - إزالة جدول خارجي

الملخص

DROP FOREIGN TABLE [ IF EXISTS ] name [, ...] [ CASCADE | RESTRICT ]

الوصف

DROP FOREIGN TABLE تزيل جدولاً خارجياً. يمكن فقط لمالك الجدول الخارجي إزالته.

المعلمات

IF EXISTS

لا ترمي خطأ إذا كان الجدول الخارجي غير موجود. يتم إصدار إشعار في هذه الحالة.

name

اسم الجدول الخارجي المراد إسقاطه (يمكن تأهيله بالمخطط).

CASCADE

إسقاط الكائنات التي تعتمد على الجدول الخارجي تلقائيًا (مثل العروض)، وبالتالي جميع الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

رفض إسقاط الجدول الخارجي إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الافتراضي.

أمثلة

لتدمير جدولين خارجيين، الأفلام والموزعين:

DROP FOREIGN TABLE films, distributors;

التوافق

يتوافق هذا الأمر مع ISO/IEC 9075-9 (SQL/MED)، باستثناء أن المعيار يسمح فقط بإسقاط جدول خارجي واحد لكل أمر، وبصرف النظر عن خيار IF EXISTS، وهو امتداد لـ PostgreSQL.

انظر أيضاً

ALTER FOREIGN TABLE (ALTER_FOREIGN_TABLE(7)), CREATE FOREIGN TABLE (CREATE_FOREIGN_TABLE(7))
