DROP_TABLE(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP TABLE(7) وثائق PostgreSQL 18.1 DROP TABLE(7)

الاسم

DROP_TABLE - إزالة جدول

الملخص

DROP TABLE [ IF EXISTS ] name [, ...] [ CASCADE | RESTRICT ]

الوصف

DROP TABLE تزيل الجداول من قاعدة البيانات. يمكن فقط لمالك الجدول، ومالك المخطط، والمستخدم الخارق إسقاط جدول. لإفراغ جدول من الصفوف دون تدمير الجدول، استخدم DELETE أو TRUNCATE.

DROP TABLE تزيل دائمًا أي فهارس، قواعد، مشغلات، وقيود موجودة للجدول الهدف. ومع ذلك، لإسقاط جدول تتم الإشارة إليه بواسطة عرض أو قيد مفتاح خارجي لجدول آخر، يجب تحديد CASCADE. (CASCADE ستزيل عرضًا تابعًا بالكامل، ولكن في حالة المفتاح الخارجي ستزيل فقط قيد المفتاح الخارجي، وليس الجدول الآخر بالكامل).

المعلمات

IF EXISTS

لا ترمي خطأ إذا لم يكن الجدول موجودًا. يتم إصدار إشعار في هذه الحالة.

name

اسم الجدول المطلوب إسقاطه (يمكن تحديد المخطط اختياريًا).

CASCADE

إسقاط تلقائي للكائنات التي تعتمد على الجدول (مثل العروض)، وبالتبعية جميع الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

رفض إسقاط الجدول إذا كانت هناك أي كائنات تعتمد عليه. هذا هو الافتراضي.

أمثلة

لتدمير جدولين، films و distributors:

DROP TABLE films, distributors;

التوافق

يتوافق هذا الأمر مع معيار SQL، باستثناء أن المعيار يسمح بإسقاط جدول واحد فقط في كل أمر، وبصرف النظر عن خيار IF EXISTS، وهو امتداد PostgreSQL.

انظر أيضًا

ALTER TABLE (ALTER_TABLE(7))، CREATE TABLE (CREATE_TABLE(7))
