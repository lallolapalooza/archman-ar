DROP_LANGUAGE(7)

الحزمة: postgresql

DROP LANGUAGE(7) وثائق PostgreSQL 18.1 DROP LANGUAGE(7)

الاسم

DROP LANGUAGE - إزالة لغة إجرائية

الملخص

DROP [ PROCEDURAL ] LANGUAGE [ IF EXISTS ] name [ CASCADE | RESTRICT ]

الوصف

DROP LANGUAGE تزيل تعريف لغة إجرائية مسجلة مسبقًا. يجب أن تكون مستخدمًا خارقًا أو مالك اللغة لاستخدام DROP LANGUAGE.


ملاحظة

اعتبارًا من PostgreSQL 9.1، تم جعل معظم اللغات الإجرائية "ملحقات" (extensions)، ويجب بالتالي إزالتها باستخدام DROP EXTENSION بدلاً من DROP LANGUAGE.

المعلمات

IF EXISTS

لا ترمي خطأ إذا كانت اللغة غير موجودة. يتم إصدار إشعار في هذه الحالة.

name

اسم لغة إجرائية موجودة.

CASCADE

إزالة تلقائيًا الكائنات التي تعتمد على اللغة (مثل الدوال في اللغة)، وبالتتابع جميع الكائنات التي تعتمد على تلك الكائنات (انظر القسم 5.15).

RESTRICT

رفض إزالة اللغة إذا كانت هناك أي كائنات تعتمد عليها. هذا هو الوضع الافتراضي.

أمثلة

يقوم هذا الأمر بإزالة اللغة الإجرائية plsample:

DROP LANGUAGE plsample;

التوافق

لا يوجد بيان DROP LANGUAGE في معيار SQL.

انظر أيضاً

ALTER LANGUAGE (ALTER_LANGUAGE(7)), CREATE LANGUAGE (CREATE_LANGUAGE(7))
