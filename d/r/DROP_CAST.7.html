DROP_CAST(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP CAST(7) توثيق PostgreSQL 18.1 DROP CAST(7)

الاسم

DROP CAST - إزالة تحويل

ملخص

DROP CAST [ IF EXISTS ] (source_type AS target_type) [ CASCADE | RESTRICT ]

الوصف

DROP CAST يزيل تحويلاً معرفاً مسبقاً.

لكي تكون قادراً على إسقاط تحويل، يجب أن تمتلك نوع البيانات المصدر أو الهدف. هذه هي نفس الامتيازات المطلوبة لإنشاء تحويل.

المعلمات

IF EXISTS

لا ترمي خطأ إذا كان التحويل غير موجود. يتم إصدار إشعار في هذه الحالة.

source_type

اسم نوع البيانات المصدر للتحويل.

target_type

اسم نوع البيانات الهدف للتحويل.

CASCADE
RESTRICT

هذه الكلمات المفتاحية ليس لها أي تأثير، حيث لا توجد تبعيات على التحويلات.

أمثلة

لإسقاط التحويل من النوع text إلى النوع int:

DROP CAST (text AS int);

التوافق

الأمر DROP CAST يتوافق مع معيار SQL.

انظر أيضًا

CREATE CAST (CREATE_CAST(7))
