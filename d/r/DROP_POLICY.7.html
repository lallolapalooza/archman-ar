DROP_POLICY(7)

الحزمة: postgresql

التراخيص: PostgreSQL

DROP POLICY(7) توثيق PostgreSQL 18.1 DROP POLICY(7)

الاسم

DROP_POLICY - إزالة سياسة مستوى الصف من جدول

الملخص

DROP POLICY [ IF EXISTS ] name ON table_name [ CASCADE | RESTRICT ]

الوصف

DROP POLICY تزيل السياسة المحددة من الجدول. لاحظ أنه إذا تمت إزالة السياسة الأخيرة لجدول ولا يزال الجدول يمتلك سياسة مستوى الصف مفعلة عبر ALTER TABLE، فسيتم استخدام السياسة الافتراضية الرافضة. يمكن استخدام ALTER TABLE ... DISABLE ROW LEVEL SECURITY لتعطيل سياسة مستوى الصف لجدول، سواء كانت سياسات الجدول موجودة أم لا.

المعلمات

IF EXISTS

لا تقم بإلقاء خطأ إذا لم تكن السياسة موجودة. سيتم إصدار إشعار في هذه الحالة.

name

اسم السياسة المراد إسقاطها.

table_name

اسم الجدول (مؤهل بالمخطط اختياريًا) الذي تقع عليه السياسة.

CASCADE
RESTRICT

هذه الكلمات المفتاحية ليس لها أي تأثير، حيث لا توجد تبعيات على السياسات.

أمثلة

لإسقاط السياسة المسماة p1 على الجدول المسمى my_table:

DROP POLICY p1 ON my_table;

التوافق

DROP POLICY هي إضافة خاصة بـ PostgreSQL.

انظر أيضًا

CREATE POLICY (CREATE_POLICY(7))، ALTER POLICY (ALTER_POLICY(7))
