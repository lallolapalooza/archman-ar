subroutine drotg (real(wp) a, real(wp) b, real(wp) c, real(wp) s)

DROTG

الهدف:

!>
!> DROTG تنشئ دوران مستوى
!>    [  c  s ] [ a ] = [ r ]
!>    [ -s  c ] [ b ]   [ 0 ]
!> بحيث يتحقق c**2 + s**2 = 1.
!>
!> تستخدم الحسابات الصيغ التالية
!>    sigma = sgn(a)    if |a| >  |b|
!>          = sgn(b)    if |b| >= |a|
!>    r = sigma*sqrt( a**2 + b**2 )
!>    c = 1; s = 0      if r = 0
!>    c = a/r; s = b/r  if r != 0
!> كما تحسب الروتين الفرعي أيضًا
!>    z = s    if |a| > |b|,
!>      = 1/c  if |b| >= |a| and c != 0
!>      = 1    if c = 0
!> هذا يسمح بإعادة بناء c و s من z كما يلي:
!>    إذا كان z = 1، يتم تعيين c = 0، s = 1.
!>    إذا كان |z| < 1، يتم تعيين c = sqrt(1 - z**2) و s = z.
!>    إذا كان |z| > 1، يتم تعيين c = 1/z و s = sqrt( 1 - c**2).
!>
!>
