double precision function drzt01 (m, n, a, af, lda, tau, work, lwork)
DRZT01

توثيق الدالة/الإجراء الفرعي

double precision function drzt01 (integer m, integer n, double precision, dimension( lda, * ) a, double precision, dimension( lda, * ) af, integer lda, double precision, dimension( * ) tau, double precision, dimension( lwork ) work, integer lwork)

DRZT01

الغرض:

!>
!> DRZT01 تُرجع
!>      || A - R*Q || / ( M * eps * ||A|| )
!> للمصفوفة A شبه المنحرفة العلوية التي تم تحليلها باستخدام DTZRZF.
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>          عدد الصفوف للمصفوفتين A و AF.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>          عدد الأعمدة للمصفوفتين A و AF.
!>

A

!>          A هي مصفوفة ذات دقة مزدوجة (DOUBLE PRECISION array)، البعد (LDA,N)
!>          المصفوفة الأصلية شبه المنحرفة العلوية A ذات الأبعاد M × N.
!>

AF

!>          AF هي مصفوفة ذات دقة مزدوجة (DOUBLE PRECISION array)، البعد (LDA,N)
!>          الناتج من DTZRZF للمدخل A.
!>          المثلث السفلي غير مستخدم.
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البعد الرئيسي للمصفوفتين A و AF.
!>

TAU

!>          TAU هي مصفوفة ذات دقة مزدوجة (DOUBLE PRECISION array)، البعد (M)
!>          تفاصيل تحويلات هاوسهولدر كما تم إرجاعها بواسطة
!>          DTZRZF.
!>

WORK

!>          WORK هي مصفوفة ذات دقة مزدوجة (DOUBLE PRECISION array)، البعد (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح (INTEGER)
!>          طول المصفوفة WORK.  LWORK >= m*n + m*nb.
!>
