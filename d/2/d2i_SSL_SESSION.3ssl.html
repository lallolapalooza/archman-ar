d2i_SSL_SESSION(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

D2I_SSL_SESSION(3ssl) OpenSSL D2I_SSL_SESSION(3ssl)

الاسم

d2i_SSL_SESSION, d2i_SSL_SESSION_ex, i2d_SSL_SESSION - تحويل كائن SSL_SESSION من/إلى تمثيل ASN1

الملخص

#include <openssl/ssl.h>
SSL_SESSION *d2i_SSL_SESSION(SSL_SESSION **a, const unsigned char **pp,
                             long length);
SSL_SESSION *d2i_SSL_SESSION_ex(SSL_SESSION **a, const unsigned char **pp,
                                long length, OSSL_LIB_CTX *libctx,
                                const char *propq);
int i2d_SSL_SESSION(SSL_SESSION *in, unsigned char **pp);

الوصف

تقوم هذه الدوال بفك وترميز كائن SSL_SESSION. للحصول على تفاصيل الترميز، انظر d2i_X509(3).

تحتفظ كائنات SSL_SESSION بمعلومات الارتباط الداخلية لقائمة ذاكرة التخزين المؤقت للجلسة، عند إدراجها في ذاكرة التخزين المؤقت لجلسة SSL_CTX واحدة. لذلك، يجب استخدام كائن SSL_SESSION واحد فقط، بغض النظر عن عدد مرات الإشارة إليه، مع كائن SSL_CTX واحد فقط (وكائنات SSL المنشأة من كائن SSL_CTX هذا).

قيم الإرجاع

d2i_SSL_SESSION() و d2i_SSL_SESSION_ex() ترجع مؤشرًا إلى كائن SSL_SESSION المخصص حديثًا. في حالة الفشل، يتم إرجاع المؤشر NULL ويمكن استرداد رسالة الخطأ من مكدس الأخطاء.

i2d_SSL_SESSION() ترجع حجم تمثيل ASN1 بالبايت. عندما لا تكون الجلسة صالحة، يتم إرجاع 0 ولا يتم إجراء أي عملية.

انظر أيضًا

ssl(7)، SSL_SESSION_free(3)، SSL_CTX_sess_set_get_cb(3)، d2i_X509(3)

تاريخ

تمت إضافة الدالة d2i_SSL_SESSION_ex() في OpenSSL 3.2.
