DisplayHeightMM(3)

الحزمة: libx11

التراخيص: MIT AND X11

ImageByteOrder(3) وظائف XLIB ImageByteOrder(3)

الاسم

ImageByteOrder, BitmapBitOrder, BitmapPad, BitmapUnit, DisplayHeight, DisplayHeightMM, DisplayWidth, DisplayWidthMM, XListPixmapFormats, XPixmapFormatValues - وظائف ووحدات ماكرو لتنسيق الصور

الصيغة

XPixmapFormatValues *XListPixmapFormats(Display *display, int *count_return);

int ImageByteOrder(Display *display);

int BitmapBitOrder(Display *display);

int BitmapPad(Display *display);

int BitmapUnit(Display *display);

int DisplayHeight(Display *display, int screen_number);

int DisplayHeightMM(Display *display, int screen_number);

int DisplayWidth(Display *display, int screen_number);

int DisplayWidthMM(Display *display, int screen_number);

المعاملات

display
يحدد الاتصال بخادم X.
count_return
يعيد عدد تنسيقات البكسماپ المدعومة بواسطة العرض.
screen_number
يحدد رقم الشاشة المناسب على الخادم المضيف.

الوصف

تقوم الدالة XListPixmapFormats بإعادة مصفوفة من هياكل XPixmapFormatValues تصف أنواع الصور بتنسيق Z المدعومة بواسطة العرض المحدد. إذا كانت الذاكرة غير كافية، فإن XListPixmapFormats تعيد NULL. لتحرير التخزين المخصص لهياكل XPixmapFormatValues، استخدم XFree.

تحدد وحدة الماكرو ImageByteOrder ترتيب البايت المطلوب للصور لكل وحدة مسح ضوئي بتنسيق XY (خريطة نقطية) أو لكل قيمة بكسل بتنسيق Z.

تعيد وحدة الماكرو BitmapBitOrder إما LSBFirst أو MSBFirst للإشارة إلى ما إذا كانت البتة اليسرى في الخريطة النقطية كما تظهر على الشاشة هي البتة الأقل أو الأكثر أهمية في الوحدة.

تعيد وحدة الماكرو BitmapPad عدد البتات التي يجب أن تكون كل مسح ضوئي محسوبة.

تعيد وحدة الماكرو BitmapUnit حجم وحدة المسح الضوئي للخريطة النقطية بالبتات.

تعيد وحدة الماكرو DisplayHeight ارتفاع الشاشة المحددة بالبكسل.

تعيد وحدة الماكرو DisplayHeightMM ارتفاع الشاشة المحددة بالمليمتر.

تعيد وحدة الماكرو DisplayWidth عرض الشاشة بالبكسل.

تعيد وحدة الماكرو DisplayWidthMM عرض الشاشة المحددة بالمليمتر.

الهياكل

يوفر هيكل XPixmapFormatValues واجهة لمعلومات تنسيق البكسماپ التي يتم إرجاعها في وقت إعداد الاتصال. يحتوي على:

typedef struct {
        int depth;
        int bits_per_pixel;
        int scanline_pad;
} XPixmapFormatValues;
