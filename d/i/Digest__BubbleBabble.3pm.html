Digest__BubbleBabble(3pm)

الحزمة: perl-digest-bubblebabble

التراخيص: PerlArtistic, GPL

Digest::BubbleBabble(3) وثائق مساهمة من المستخدم في Perl Digest::BubbleBabble(3)

الاسم

Digest::BubbleBabble - إنشاء بصمات فقاعية

الملخص

# إنشاء بصمة لسلسلة نصية بسيطة.
use Digest::BubbleBabble qw( bubblebabble );
my $fingerprint = bubblebabble( Digest => "Pineapple" );
# إنشاء بصمة لتجزئة SHA-1.
use Digest::SHA1 qw( sha1 );
$fingerprint = bubblebabble( Digest => sha1("hello") );

الوصف

Digest::BubbleBabble يأخذ تجزئة رسالة (عادة ما يتم إنشاؤها بواسطة إحدى خوارزميات تجزئة الرسائل MD5 أو SHA-1) وينشئ بصمة لهذه التجزئة بتنسيق "الفقاعة الفقاعية". الفقاعة الفقاعية هي طريقة لتمثيل تجزئة الرسالة كسلسلة من الكلمات "حقيقية"، لجعل البصمة أسهل في التذكر. "الكلمات" ليست بالضرورة كلمات حقيقية، ولكنها تبدو أكثر مثل الكلمات من سلسلة من الأحرف السداسية عشرية.

يتم استخدام تجزئة الفقاعة الفقاعية بواسطة مجموعة SSH2 (وبالتالي، بواسطة Net::SSH::Perl، تطبيق Perl لـ SSH) لعرض بصمات مفاتيح سهلة التذكر. يتم تحويل المفتاح (مفتاح DSA أو RSA) إلى شكل نصي، ويتم تجزئته باستخدام Digest::SHA1، ويتم تشغيله عبر bubblebabble لإنشاء بصمة المفتاح.

الاستخدام

Digest::BubbleBabble يقوم بتصدير دالة واحدة بشكل مشروط تسمى bubblebabble؛ لاستيراد الدالة يجب عليك اختيار استيرادها، هكذا:

use Digest::BubbleBabble qw( bubblebabble );

bubblebabble( Digest => $digest )

حاليًا يأخذ زوجًا واحدًا فقط من الوسائط، ويجب أن يكون المفتاح هو Digest، والقيمة هي تجزئة الرسالة الفعلية $digest. يجب عليك إنشاء تجزئة الرسالة هذه بنفسك باستخدام إما Digest::MD5 أو Digest::SHA1.

يعيد شكل الفقاعة الفقاعية للتجزئة.
