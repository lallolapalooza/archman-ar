عند مقارنة قوائم حيث يكون لكل عنصر مفتاح مميز، يمكننا تحسين تصحيح المقارنة بإدخال حركتين تحريريتين مركبتين: تبديلات ونقل.

التبديل s يتبادل موضع عنصرين. تكلفة التبديل تساوي 2 * تغيير - إبسيلون. النقل s يغير موضع عنصر واحد. تكلفة النقل تساوي حذف + إضافة - إبسيلون.

عندما تكون تكلفة الحذف + الإضافة أكبر من التغيير ومع هذه الأوزان المحددة، يمكن حساب التصحيح الأمثل مع التبديلات و النقل مباشرة وبتكلفة منخفضة من التصحيح الأمثل الأصلي.

النوع 'a with_pos = {
pos : int ;
data : 'a ;
}

القيمة with_pos : 'a list -> 'a with_pos list

النوع ('l, 'r, 'diff) mismatch =
| Name of {
pos : int ;
got : string ;
expected : string ;
types_match : bool ;
}
| Type of {
pos : int ;
got : 'l ;
expected : 'r ;
reason : 'diff ;
}

النوع ('l, 'r, 'diff) change =
| Change of ('l, 'r, 'diff) mismatch
| Swap of {
pos : int * int ;
first : string ;
last : string ;
}
| Move of {
name : string ;
got : int ;
expected : int ;
}
| Insert of {
pos : int ;
insert : 'r ;
}
| Delete of {
pos : int ;
delete : 'l ;
}

هذا الإصدار المتخصص من التغييرات يقدم تغييرين مركبين: نقل و تبديل
