DirHandle(3perl) دليل مبرمجي بيرل DirHandle(3perl)

الاسم

DirHandle - (مهمل) توفير دوال كائن لمقابض الدليل

الملخص

# النهج الموصى به منذ Perl 5.6: لا تستخدم DirHandle
if (opendir my $d, '.') {
    while (readdir $d) { something($_); }
    rewind $d;
    while (readdir $d) { something_else($_); }
}
# كيف ستستخدم هذه الوحدة إذا كنت ستستخدمها
use DirHandle;
if (my $d = DirHandle->new(".")) {
    while (defined($_ = $d->read)) { something($_); }
    $d->rewind;
    while (defined($_ = $d->read)) { something_else($_); }
}

الوصف

لا يوجد سبب لاستخدام هذه الوحدة في الوقت الحاضر.

توفر دالة "DirHandle" واجهة بديلة للدوال opendir() و closedir() و readdir() و rewinddir().

حتى الإصدار Perl 5.5، لم يكن بإمكان opendir() إنشاء مقبض دليل تلقائيًا من "undef"، لذلك كان استخدام مقبض موضعي يتطلب استخدام دالة من Symbol لإنشاء glob مجهول، وهو ما تطلب خطوة منفصلة. تقوم "DirHandle" بتغليف هذا، مما سمح بكود أنظف من opendir(). منذ Perl 5.6، أصبحت opendir() وحدها هي كل ما تحتاجه للمقابض الموضعية.
