الاسم

Digest.S - توقيع لدالة تجزئة تنتج ملخصات بطول hash_length من سلاسل الأحرف، ومصفوفات البايت، والملفات.

نوع الوحدة

Module type Digest.S

التوثيق

Module type S
= sig end

توقيع لدالة تجزئة تنتج ملخصات بطول hash_length من سلاسل الأحرف، ومصفوفات البايت، والملفات.

منذ 5.2

type t = string

نوع الملخصات.

val hash_length : int

طول الملخصات، بالبايت.

val compare : t -> t -> int

قارن بين ملخصين، بنفس مواصفات compare.

val equal : t -> t -> bool

اختبر تساوي ملخصين.

val string : string -> t

أرجع ملخص السلسلة النصية المعطاة.

val bytes : bytes -> t

أرجع ملخص تسلسل البايت المعطى.

val substring : string -> int -> int -> t

substring s ofs len يرجع ملخص السلسلة الفرعية لـ s بدءًا من الفهرس ofs ويحتوي على len حرف.

val subbytes : bytes -> int -> int -> t

subbytes s ofs len يرجع ملخص التسلسل الفرعي لـ s بدءًا من الفهرس ofs ويحتوي على len بايت.

val channel : in_channel -> int -> t

اقرأ الأحرف من القناة وأرجع ملخصها. انظر Digest.channel للمواصفات الكاملة.

val file : string -> t

أرجع ملخص الملف الذي يحمل الاسم المعطى.

val output : out_channel -> t -> unit

اكتب ملخصًا على قناة الإخراج المعطاة.

val input : in_channel -> t

اقرأ ملخصًا من قناة الإدخال المعطاة.

val to_hex : t -> string

أرجع التمثيل السداسي عشري القابل للطباعة للملخص المعطى.

يثير Invalid_argument إذا كان طول الوسيط ليس hash_length،

val of_hex : string -> t

حول تمثيل سداسي عشري مرة أخرى إلى الملخص المقابل.

يثير Invalid_argument إذا كان طول الوسيط ليس 2 * hash_length، أو إذا احتوت الوسائط على أحرف غير سداسية عشرية.
