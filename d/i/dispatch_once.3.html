dispatch_once(3)

الحزمة: libdispatch

التراخيص: Apache-2.0

dispatch_once(3) دليل وظائف المكتبة dispatch_once(3)

الاسم

dispatch_once — تنفيذ كتلة مرة واحدة فقط

ملخص

#include <dispatch/dispatch.h>

void
dispatch_once(dispatch_once_t *predicate, void (^block)(void));

void
dispatch_once_f(dispatch_once_t *predicate, void *context, void (*function)(void *));

الوصف

توفر الدالة dispatch_once() آلية بسيطة وفعالة لتشغيل مُهيئ مرة واحدة بالضبط، مشابهة لـ pthread_once(3). الكود المصمم جيدًا يخفي استخدام التهيئة الكسولة. على سبيل المثال:

FILE *getlogfile(void)
{
	static dispatch_once_t pred;
	static FILE *logfile;

	dispatch_once(&pred, ^{
		logfile = fopen(MY_LOG_FILE, "a");
	});

	return logfile;
}

الأساسيات

الدالة dispatch_once() هي غلاف للدالة dispatch_once_f().
