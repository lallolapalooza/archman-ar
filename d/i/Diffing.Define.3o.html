الاسم

Diffing.Define - Define(Defs) ينشئ أنواع المقارنة من الأنواع المعرفة في Defs والدوال (functors) التي تحتاج إلى تهيئة بمعلمات خوارزمية المقارنة

وحدة نمطية

الوحدة النمطية Diffing.Define

التوثيق

الوحدة النمطية Define
: (D : Defs) -> sig end

Define(Defs) ينشئ أنواع المقارنة من الأنواع المعرفة في Defs والدوال (functors) التي تحتاج إلى تهيئة بمعلمات خوارزمية المقارنة

المعلمات:

"D"

Diffing.Defs

type change = (D.left, D.right, D.eq, D.diff) Diffing.change

نوع التغييرات المحتملة على قائمة.

type patch = change list

الرقعة (patch) هي قائمة مرتبة من التغييرات.

module type Parameters = sig end

module type S = sig end

module Simple : sig end -> S

المقارنة المتغيرة تسمح بتوسيع القوائم التي يتم مقارنتها أثناء المقارنة. في اتجاه واحد محدد.

module Right_variadic : sig end -> S
