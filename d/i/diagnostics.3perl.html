diagnostics(3perl)

NAME

diagnostics — Enable warnings and diagnostics

DESCRIPTION

This module is a convenient way to enable warnings and diagnostics. When you use this module, it automatically enables all standard Perl warnings. It also provides a mechanism for enabling specific diagnostic messages that are normally disabled by default.

SYNOPSIS 

    use diagnostics;
    
    # Code that might generate warnings or diagnostics
    my $x = "hello" + 5;

DIAGNOSTICS

When the diagnostics module is used, it enables the following warnings by default:

  • all: Enables all standard Perl warnings.
  • portable: Issues warnings about constructs that might not be portable to other Perl implementations.
  • utf8: Issues warnings about potential UTF-8 issues.

You can also enable specific diagnostic messages that are normally disabled by default. For example, to enable the deprecated diagnostic: 

    use diagnostics -warnings => 'deprecated';
    
    # Code that uses deprecated features

You can specify multiple warnings in a comma-separated list: 

    use diagnostics -warnings => 'deprecated, experimental';

INTERNALS

The diagnostics module works by setting the $^W variable and by using the warnings pragma. It also provides a mechanism to enable specific diagnostic messages by setting the $^DIAGNOSTIC_LIMIT variable.

BUGS

There are no known bugs in this module.
