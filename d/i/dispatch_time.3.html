dispatch_time(3)

الحزمة: libdispatch

التراخيص: Apache-2.0

dispatch_time(3) دليل وظائف المكتبة dispatch_time(3)

الاسم

dispatch_time، dispatch_walltime — حساب المعالم الزمنية

المُلَخَّص

#include <dispatch/dispatch.h>

static const dispatch_time_t DISPATCH_TIME_NOW = 0ull;
static const dispatch_time_t DISPATCH_WALLTIME_NOW = ~1ull;
static const dispatch_time_t DISPATCH_TIME_FOREVER = ~0ull;

dispatch_time_t
dispatch_time(dispatch_time_t base, int64_t offset);

dispatch_time_t
dispatch_walltime(struct timespec *base, int64_t offset);

الوصف

توفر الدالتان dispatch_time() و dispatch_walltime() آلية بسيطة للتعبير عن المعالم الزمنية للاستخدام مع وظائف dispatch التي تحتاج إلى مهلات زمنية أو تعمل بجدول زمني.

النوع dispatch_time_t هو عدد صحيح شبه شفاف، مع القيم الخاصة فقط DISPATCH_TIME_NOW، DISPATCH_WALLTIME_NOW و DISPATCH_TIME_FOREVER معرفة خارجيًا. يتم تمثيل جميع القيم الأخرى بتنسيق داخلي غير آمن للحسابات أو المقارنات الصحيحة. التنسيق الداخلي عرضة للتغيير.

تقوم الدالة dispatch_time() بإرجاع معلم زمني نسبيًا إلى معلم زمني موجود بعد إضافة offset نانوثانية. إذا كانت المعلمة base تقابل داخليًا ساعة الحائط أو كانت DISPATCH_WALLTIME_NOW، فإن القيمة المرجعة تكون نسبية لساعة الحائط. بخلاف ذلك، إذا كانت base هي DISPATCH_TIME_NOW، فسيتم استخدام الوقت الحالي للساعة المضيفة الافتراضية. في منصات Apple، يتم الحصول على قيمة الساعة المضيفة الافتراضية من mach_absolute_time().

تفيد الدالة dispatch_walltime() في إنشاء معلم زمني نسبيًا إلى نقطة زمنية ثابتة باستخدام ساعة الحائط، كما هو محدد بواسطة المعلمة الاختيارية base. إذا كانت base فارغة (NULL)، فسيتم استخدام الوقت الحالي لساعة الحائط. dispatch_walltime(NULL, offset) يعادل dispatch_time(DISPATCH_WALLTIME_NOW, offset).

حالات الحافة

تكتشف الدالتان dispatch_time() و dispatch_walltime() ظروف تجاوز السعة (overflow) وانخفاض السعة (underflow) عند تطبيق المعلمة offset.

يتسبب تجاوز السعة في إرجاع DISPATCH_TIME_FOREVER. عندما تكون base هي DISPATCH_TIME_FOREVER، يتم تجاهل المعلمة offset.

يتسبب انخفاض السعة في إرجاع أصغر قيمة يمكن تمثيلها لساعة معينة.

أمثلة

إنشاء معلم زمني بعد ثانيتين في المستقبل، نسبيًا إلى الساعة الافتراضية:

milestone = dispatch_time(DISPATCH_TIME_NOW, 2 * NSEC_PER_SEC);

إنشاء معلم زمني بعد ثانيتين في المستقبل، بتوقيت ساعة الحائط:

milestone = dispatch_time(DISPATCH_WALLTIME_NOW, 2 * NSEC_PER_SEC);

إنشاء معلم زمني لاستخدامه كمهلة زمنية لا نهائية:

milestone = DISPATCH_TIME_FOREVER;

إنشاء معلم زمني يوم الثلاثاء، 19 يناير 2038:

struct timespec ts;
ts.tv_sec = 0x7FFFFFFF;
ts.tv_nsec = 0;
milestone = dispatch_walltime(&ts, 0);

استخدام دلتا سالبة لإنشاء معلم زمني قبل ساعة واحدة من المعلم أعلاه:

milestone = dispatch_walltime(&ts, -60 * 60 * NSEC_PER_SEC);

قيمة الإرجاع

ترجع هذه الدوال قيمة مجردة للاستخدام مع dispatch_after()، dispatch_group_wait()، dispatch_semaphore_wait()، أو dispatch_source_set_timer().
