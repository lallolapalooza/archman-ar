الاسم

diffman-git - مقارنة التغييرات في صفحات الدليل سطراً بسطر

الملخص

diffman-git [خيارات-diff ...] [[التزام-أساسي] التزام]

الوصف

يقوم الأمر diffman-git بتنسيق صفحة دليل في اثنين من git(1) commits، ثم يقوم بتشغيل diff(1) على المخرجات المنسقة.

إذا لم يتم تحديد commit، فإنه يفرق دليل العمل مقابل HEAD.

إذا لم يتم تحديد base-commit، تتم المقارنة مقابل الالتزام السابق.

الخيارات

-s
الإبلاغ عند تساوي ملفين.
-Un
إخراج n (افتراضي 3) أسطر من السياق الموحد.
-w
تجاهل كل المسافات البيضاء.

البيئة

انظر man(1).

أمثلة

$ MAN_KEEP_FORMATTING= diffman-git 437e4afec6ca | less -R;
--- 437e4afec6ca^:man/man3/sem_open.3
+++ 437e4afec6ca:man/man3/sem_open.3
@@ -14,3 +14,2 @@
-     sem_t *sem_open(const char *name, int oflag);
-     sem_t *sem_open(const char *name, int oflag,
-                     mode_t mode, unsigned int value);
+     sem_t *sem_open(const char *name, int oflag, ...
+                     /* mode_t mode, unsigned int value */ );
