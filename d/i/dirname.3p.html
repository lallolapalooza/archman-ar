DIRNAME(3P) دليل مبرمج POSIX DIRNAME(3P)

المقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

dirname — الإبلاغ عن اسم الدليل الأصل لمسار ملف

الملخص

#include <libgen.h>
char *dirname(char *path);

الوصف

تأخذ الدالة dirname() مؤشرًا إلى سلسلة أحرف تحتوي على مسار، وتعيد مؤشرًا إلى سلسلة أحرف هو مسار الدليل الأصل للملف. لا تقوم الدالة dirname() بحل المسارات؛ ولن يتأثر النتيجة بما إذا كان path موجودًا أم لا أو بنوع ملفه. لن يتم احتساب أحرف '/' اللاحقة في المسار التي ليست أيضًا أحرف '/' رائدة كجزء من المسار.

إذا كان path لا يحتوي على '/'، فإن dirname() ستعيد مؤشرًا إلى السلسلة ".". إذا كان path مؤشرًا فارغًا أو يشير إلى سلسلة فارغة، فإن dirname() ستعيد مؤشرًا إلى السلسلة ".".

يجوز للدالة dirname() تعديل السلسلة التي يشير إليها path، ويجوز لها إعادة مؤشر إلى مساحة تخزين ثابتة قد يتم الكتابة فوقها لاحقًا بواسطة استدعاء لاحق لـ dirname().

لا يُشترط أن تكون الدالة dirname() آمنة للسلاسل.

قيمة الإرجاع

ستعيد الدالة dirname() مؤشرًا إلى سلسلة كما هو موضح أعلاه.

يجوز للدالة dirname() تعديل السلسلة التي يشير إليها path، ويجوز لها إعادة مؤشر إلى مساحة تخزين داخلية. قد يصبح المؤشر المُعاد غير صالح أو قد يتم الكتابة فوق المساحة بواسطة استدعاء لاحق لـ dirname(). قد يصبح المؤشر المُعاد أيضًا غير صالح إذا تم إنهاء الخيط المستدعي.

الأخطاء

لم يتم تعريف أي أخطاء.

الأقسام التالية معلوماتية.

أمثلة

يقرأ المقطع البرمجي التالي مسارًا، ويغير الدليل الحالي إلى الدليل الأصل، ويفتح الملف.

char *path = NULL, *pathcopy;
size_t buflen = 0;
ssize_t linelen = 0;
int fd;
linelen = getline(&path, &buflen, stdin);
path[linelen-1] = 0;
pathcopy = strdup(path);
if (chdir(dirname(pathcopy)) < 0) {
    ...
}
if ((fd = open(basename(path), O_RDONLY)) >= 0) {
    ...
    close (fd);
}
...
free (pathcopy);
free (path);

يتضمن قسم الأمثلة في صفحة الدليل الخاصة بـ basename() (انظر basename()) جدولًا يوضح نتائج معالجة العديد من المسارات العينة بواسطة الدوال basename() و dirname() وأدوات basename و dirname.

استخدام التطبيق

تنتج الدوال dirname() و basename() معًا مسارًا كاملاً. يعبر التعبير dirname(path) عن مسار الدليل حيث يتم العثور على basename(path).

نظرًا لأن معنى "//" الرائد هو تعريف ضمني للتنفيذ، فإن dirname("//foo) قد تعيد إما "//" أو '/' (ولكن لا شيء آخر).
