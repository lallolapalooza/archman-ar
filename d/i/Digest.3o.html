الوحدة Digest
: sig end

هضم الرسالة.

توفر هذه الوحدة وظائف لحساب 'الهضم'، المعروف أيضًا باسم 'التجزئة' (hashes)، لسلاسل نصية أو ملفات ذات طول عشوائي. خوارزميات التجزئة المدعومة هي BLAKE2 و MD5.

الوظائف الأساسية

تستخدم الوظائف في هذا القسم خوارزمية التجزئة MD5 لإنتاج هضمات بحجم 128 بت (16 بايت). MD5 ليست آمنة من الناحية التشفيرية. لذلك، لا ينبغي استخدام هذه الوظائف للتطبيقات الحساسة للأمن. وظائف BLAKE2 أدناه آمنة من الناحية التشفيرية.

type t = string

نوع الهضمات: سلاسل نصية بحجم 16 بايت.

val compare : t -> t -> int

وظيفة المقارنة للهضمات بحجم 16 بايت، بنفس المواصفات مثل compare وتشارك التنفيذ مع String.compare. جنبًا إلى جنب مع النوع t، تسمح هذه الوظيفة compare بتمرير الوحدة Digest كوسيطة للمرفقات Set.Make و Map.Make.

منذ 4.03

val string : string -> t

إرجاع هضم السلسلة النصية المعطاة.

val bytes : bytes -> t

إرجاع هضم تسلسل البايتات المعطى.

منذ 4.02

val substring : string -> int -> int -> t

Digest.substring s ofs len تُرجع هضم السلسلة النصية الفرعية s بدءًا من الفهرس ofs وتحتوي على len حرفًا.

val subbytes : bytes -> int -> int -> t

Digest.subbytes s ofs len تُرجع هضم التسلسل الفرعي للبايتات s بدءًا من الفهرس ofs وتحتوي على len بايت.

منذ 4.02

val channel : in_channel -> int -> t

إذا كان len غير سالب، فإن Digest.channel ic len يقرأ len حرفًا من القناة ic ويُرجع هضمها، أو يرفع End_of_file إذا تم الوصول إلى نهاية الملف قبل قراءة len حرفًا. إذا كان len سالبًا، فإن Digest.channel ic len يقرأ جميع الأحرف من ic حتى الوصول إلى نهاية الملف ويُرجع هضمها.

val file : string -> t

إرجاع هضم الملف الذي يحمل الاسم المحدد.

val output : out_channel -> t -> unit

اكتب هضمًا على قناة الإخراج المحددة.

val input : in_channel -> t

اقرأ هضمًا من قناة الإدخال المحددة.

val to_hex : t -> string

إرجاع التمثيل السداسي عشري القابل للطباعة للهضم المحدد.

يرفع Invalid_argument إذا لم يكن الوسيط 16 بايت بالضبط.

val of_hex : string -> t

حوّل تمثيلًا سداسي عشري مرة أخرى إلى الهضم المقابل.

منذ 4.00

الواجهة العامة

module type S = sig end

التوقيع لوظيفة تجزئة تنتج هضمات بطول hash_length من سلاسل الأحرف، ومصفوفات البايتات، والملفات.

منذ 5.2

وظائف التجزئة المحددة

module BLAKE128 : S

BLAKE128 هي وظيفة تجزئة BLAKE2b التي تنتج هضمات بحجم 128 بت (16 بايت). إنها آمنة من الناحية التشفيرية. ومع ذلك، فإن الحجم الصغير للهضمات يسمح بهجمات القوة الغاشمة في 2{^64} محاولة.

منذ 5.2

module BLAKE256 : S

BLAKE256 هي وظيفة تجزئة BLAKE2b التي تنتج هضمات بحجم 256 بت (32 بايت). إنها آمنة من الناحية التشفيرية، وهضماتها كبيرة بما يكفي لإحباط هجمات القوة الغاشمة.

منذ 5.2

module BLAKE512 : S

BLAKE512 هي وظيفة تجزئة BLAKE2b التي تنتج هضمات بحجم 512 بت (64 بايت). إنها آمنة من الناحية التشفيرية، وهضماتها كبيرة بما يكفي لإحباط هجمات القوة الغاشمة.

منذ 5.2

module MD5 : S

MD5 هي وظيفة تجزئة MD5. تنتج هضمات بحجم 128 بت (16 بايت) وهي ليست آمنة من الناحية التشفيرية على الإطلاق. يجب استخدامها فقط للتوافق مع التصاميم السابقة التي تتطلب استخدام MD5.
