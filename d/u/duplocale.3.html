duplocale(3) دليل وظائف المكتبة duplocale(3)

الاسم

duplocale - مضاعفة كائن locale

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <locale.h>
locale_t duplocale(locale_t locobj);
متطلبات ماكرو اختبار الميزة لـ glibc (انظر feature_test_macros(7)):

duplocale():

    منذ glibc 2.10:
        _XOPEN_SOURCE >= 700
    قبل glibc 2.10:
        _GNU_SOURCE

الوصف

تقوم وظيفة duplocale() بإنشاء نسخة مكررة من كائن locale الذي يشير إليه locobj.

إذا كان locobj هو LC_GLOBAL_LOCALE، فإن duplocale() يقوم بإنشاء كائن locale يحتوي على نسخة من locale العام الذي تم تحديده بواسطة setlocale(3).

قيمة الإرجاع

عند النجاح، تعيد duplocale() مقبضًا لكائن locale الجديد. عند حدوث خطأ، فإنها تعيد (locale_t) 0، وتعين errno للإشارة إلى الخطأ.

الأخطاء

ENOMEM
ذاكرة غير كافية لإنشاء كائن locale المكرر.

المعايير

POSIX.1-2008.

التاريخ

glibc 2.3.

ملاحظات

يمكن أن تخدم مضاعفة locale الأغراض التالية:

•
لإنشاء نسخة من كائن locale سيتم تعديل فئة واحدة أو أكثر فيه (باستخدام newlocale(3)).
•
للحصول على مقبض للـ locale الحالي الذي يمكن استخدامه في وظائف أخرى تستخدم مقبض locale، مثل toupper_l(3). يتم ذلك عن طريق تطبيق duplocale() على القيمة التي تم إرجاعها بواسطة الاستدعاء التالي:

loc = uselocale((locale_t) 0);

هذه التقنية ضرورية، لأن استدعاء uselocale(3) أعلاه قد يعيد القيمة LC_GLOBAL_LOCALE، والتي تؤدي إلى سلوك غير محدد إذا تم تمريرها إلى وظائف مثل toupper_l(3). يمكن استخدام استدعاء duplocale() للتأكد من تحويل القيمة LC_GLOBAL_LOCALE إلى كائن locale قابل للاستخدام. انظر الأمثلة، أدناه.

يجب إلغاء تخصيص كل كائن locale تم إنشاؤه بواسطة duplocale() باستخدام freelocale(3).

أمثلة

يستخدم البرنامج التالي uselocale(3) و duplocale() للحصول على مقبض للـ locale الحالي الذي يتم تمريره بعد ذلك إلى toupper_l(3). يأخذ البرنامج وسيطة واحدة في سطر الأوامر، وهي سلسلة من الأحرف يتم تحويلها إلى أحرف كبيرة وعرضها على الإخراج القياسي. مثال على استخدامه هو كالتالي:


$ ./a.out abc;
ABC

مصدر البرنامج

#define _XOPEN_SOURCE 700
#include <ctype.h>
#include <err.h>
#include <locale.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    locale_t loc, nloc;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s string\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    /* This sequence is necessary, because uselocale() might return
       the value LC_GLOBAL_LOCALE, which can't be passed as an
       argument to toupper_l().  */
    loc = uselocale((locale_t) 0);
    if (loc == (locale_t) 0)
        err(EXIT_FAILURE, "uselocale");
    nloc = duplocale(loc);
    if (nloc == (locale_t) 0)
        err(EXIT_FAILURE, "duplocale");
    for (char *p = argv[1]; *p; p++)
        putchar(toupper_l(*p, nloc));
    printf("\n");
    freelocale(nloc);
    exit(EXIT_SUCCESS);
}
