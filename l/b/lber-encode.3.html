الوصف

توفر هذه الروتينات واجهة روتينية لتطبيق مبسط لقواعد التشفير الأساسية (BER) لـ ASN.1. إصدار BER الذي تدعمه هذه الروتينات هو الإصدار المحدد لبروتوكول LDAP. قواعد التشفير هي نفسها قواعد BER، باستثناء أنه يتم استخدام أطوال الشكل المحدد فقط، ويتم تشفير سلاسل البتات وسلاسل البايتات دائمًا في شكل بدائي. توثق صفحة الدليل هذه روتينات التشفير في مكتبة lber. راجع lber-decode(3) للحصول على تفاصيل حول روتينات فك التشفير المقابلة. استشر lber-types(3) للحصول على معلومات حول الأنواع والمخصصات ومزيلات التخصيص.

عادةً، الروتينات الوحيدة التي تحتاج إلى استدعائها بواسطة تطبيق هي ber_alloc_t() لتخصيص عنصر BER للتشفير، و ber_printf() للتشفير الفعلي، و ber_flush2() لكتابة العنصر فعليًا. يتم توفير الروتينات الأخرى للتطبيقات التي تحتاج إلى مزيد من التحكم مما توفره ber_printf(). بشكل عام، تعيد هذه الروتينات طول العنصر المشفر، أو -1 إذا حدث خطأ.

يستخدم الروتين ber_alloc_t() لتخصيص عنصر BER جديد. يجب استدعاؤه بمعامل LBER_USE_DER.

يستخدم الروتين ber_flush2() لكتابة العنصر فعليًا إلى مقبس (أو واصف ملف)، بمجرد تشفيره بالكامل (باستخدام ber_printf() وما شابه). راجع lber-sockbuf(3) لمزيد من التفاصيل حول تنفيذ Sockbuf للمعامل sb. إذا كان المعامل freeit غير صفري، فسيتم تحرير ber المقدم. إذا تم استخدام LBER_FLUSH_FREE_ON_SUCCESS، فسيتم تحرير ber فقط عند التصفية بنجاح، وإلا فسيظل سليمًا؛ إذا تم استخدام LBER_FLUSH_FREE_ON_ERROR، فسيتم تحرير ber فقط عند حدوث خطأ، وإلا فسيظل سليمًا؛ إذا تم استخدام LBER_FLUSH_FREE_ALWAYS، فسيتم تحرير ber على أي حال. يختلف هذا الدالة عن الدالة الأصلية ber_flush(3) ، والتي يتوافق سلوكها مع ما هو مشار إليه لـ LBER_FLUSH_FREE_ON_SUCCESS. لاحظ أنه في المستقبل، قد يتغير سلوك ber_flush(3) مع قيمة freeit غير صفرية إلى سلوك ber_flush2(3) مع تعيين freeit على LBER_FLUSH_FREE_ALWAYS.

يستخدم الروتين ber_printf() لتشفير عنصر BER بنفس الطريقة التي يعمل بها sprintf(3). أحد الاختلافات الهامة، على الرغم من ذلك، هو أنه يتم الاحتفاظ ببعض معلومات الحالة مع المعامل ber بحيث يمكن إجراء استدعاءات متعددة لـ ber_printf() لإلحاق أشياء بنهاية عنصر BER. تكتب Ber_printf() إلى ber، وهو مؤشر إلى BerElement مثل الذي تم إرجاعه بواسطة ber_alloc_t(). تقوم بتفسير وتنسيق معاملاتها وفقًا لسلسلة التنسيق fmt. يمكن أن تحتوي سلسلة التنسيق على الأحرف التالية:

b
قيمة منطقية. يجب توفير معامل ber_int_t. يتم إخراج عنصر منطقي.
e
تعداد. يجب توفير معامل ber_int_t. يتم إخراج عنصر تعداد.
i
عدد صحيح. يجب توفير معامل ber_int_t. يتم إخراج عنصر عدد صحيح.
B
سلسلة بتات. يتم توفير مؤشر char * إلى بداية سلسلة البتات، متبوعًا بعدد البتات في سلسلة البتات. يتم إخراج عنصر سلسلة بتات.
n
فارغ. لا يلزم توفير معامل. يتم إخراج عنصر فارغ.
o
سلسلة بايت. يتم توفير char *، متبوعًا بطول السلسلة التي يشير إليها. يتم إخراج عنصر سلسلة بايت.
O
سلسلة بايت. يتم توفير بنية berval *. يتم إخراج عنصر سلسلة بايت.
s
سلسلة بايت. يتم توفير سلسلة منتهية بـ NULL. يتم إخراج عنصر سلسلة بايت، باستثناء البايت NULL الختامي.
t
علامة. يتم توفير علامة ber_tag_t تحدد العلامة التي سيتم إعطاؤها للعنصر التالي. يعمل هذا عبر الاستدعاءات.
v
عدة سلاسل بايت. يتم توفير مصفوفة منتهية بـ NULL من مؤشرات char *. لاحظ أنه يلزم وجود بنية مثل '{v}' للحصول على تسلسل فعلي من سلاسل البايتات.
V
عدة سلاسل بايت. يتم توفير مصفوفة منتهية بـ NULL من مؤشرات struct berval *. لاحظ أنه يلزم وجود بنية مثل '{V}' للحصول على تسلسل فعلي من سلاسل البايتات.
W
عدة سلاسل بايت. يتم توفير مصفوفة من structs berval. تنتهي المصفوفة بـ struct berval مع bv_val يكون NULL. لاحظ أنه يلزم وجود بنية مثل '{W}' للحصول على تسلسل فعلي من سلاسل البايتات.
{
بدء التسلسل. لا يلزم توفير معامل.
}
إنهاء التسلسل. لا يلزم توفير معامل.
[
بدء المجموعة. لا يلزم توفير معامل.
]
إنهاء المجموعة. لا يلزم توفير معامل.

يكتب الروتين ber_put_int() عنصر العدد الصحيح num إلى عنصر BER ber.

يكتب الروتين ber_put_enum() عنصر التعداد num إلى عنصر BER ber.

يكتب الروتين ber_put_boolean() القيمة المنطقية التي يقدمها bool إلى عنصر BER.

يكتب الروتين ber_put_bitstring() blen بتات بدءًا من str كسلسلة بتات إلى عنصر BER المحدد. لاحظ أن blen هو الطول بالبتات لسلسلة البتات.

يكتب الروتين ber_put_ostring() len بايتات بدءًا من str إلى عنصر BER كسلسلة بايت.

يكتب الروتين ber_put_string() السلسلة المنتهية بـ NULL (ناقص الحرف NULL الختامي) إلى عنصر BER كسلسلة بايت.

يكتب الروتين ber_put_null() عنصر NULL إلى عنصر BER.

يستخدم الروتين ber_start_seq() لبدء تسلسل في عنصر BER. يعمل الروتين ber_start_set() بشكل مشابه. يتم تحديد نهاية التسلسل أو المجموعة عن طريق استدعاء مطابق قريب لـ ber_put_

أمثلة

بافتراض الإعلانات المتغيرة التالية، وأن المتغيرات قد تم تعيينها بشكل مناسب، فإن ترميز lber لكائن ASN.1 التالي:

      AlmostASearchRequest := SEQUENCE {
          baseObject      DistinguishedName,
          scope           ENUMERATED {
              baseObject    (0),
              singleLevel   (1),
              wholeSubtree  (2)
          },
          derefAliases    ENUMERATED {
              neverDerefaliases   (0),
              derefInSearching    (1),
              derefFindingBaseObj (2),
              alwaysDerefAliases  (3)
          },
          sizelimit       INTEGER (0 .. 65535),
          timelimit       INTEGER (0 .. 65535),
          attrsOnly       BOOLEAN,
          attributes      SEQUENCE OF AttributeType
      }

يمكن تحقيق ذلك على النحو التالي:

      int rc;
      ber_int_t    scope, ali, size, time, attrsonly;
      char   *dn, **attrs;
      BerElement *ber;
      /* ... fill in values ... */
      ber = ber_alloc_t( LBER_USE_DER );
      if ( ber == NULL ) {
              /* error */
      }
      rc = ber_printf( ber, "{siiiib{v}}", dn, scope, ali,
          size, time, attrsonly, attrs );
      if( rc == -1 ) {
              /* error */
      } else {
              /* success */
      }
