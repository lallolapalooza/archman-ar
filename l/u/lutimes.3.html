futimes(3) دليل وظائف المكتبة futimes(3)

الاسم

futimes, lutimes - تغيير طوابع ملف الوقت

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/time.h>
int futimes(int fd, const struct timeval tv[2]);
int lutimes(const char *path, const struct timeval tv[2]);
متطلبات ميزة الاختبار (Feature Test Macro) لـ glibc (راجع feature_test_macros(7)):

futimes(), lutimes():

    منذ glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 وما قبله:
        _BSD_SOURCE

الوصف

تقوم futimes() بتغيير أوقات الوصول والتعديل لملف بنفس طريقة utimes(2)، مع اختلاف أن الملف الذي يتم تغيير طوابع وقته يتم تحديده عبر واصف ملف، fd، بدلاً من اسم مسار.

تقوم lutimes() بتغيير أوقات الوصول والتعديل لملف بنفس طريقة utimes(2)، مع اختلاف أنه إذا كان path يشير إلى رابط رمزي، فلن يتم إلغاء الإشارة إليه: بدلاً من ذلك، يتم تغيير طوابع الوقت للرابط الرمزي.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

الأخطاء كما في utimes(2)، مع الإضافات التالية لـ futimes():

EBADF
fd ليس واصف ملف صالح.
ENOSYS
لم يتمكن من الوصول إلى نظام الملفات /proc.

قد يحدث الخطأ الإضافي التالي لـ lutimes():

ENOSYS
النواة لا تدعم هذا الاستدعاء؛ مطلوب Linux 2.6.22 أو أحدث.

الخصائص

لشرح المصطلحات المستخدمة في هذا القسم، راجع attributes(7).
