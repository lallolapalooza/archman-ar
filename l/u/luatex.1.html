luatex(1)

الحزمة: texlive-bin

التراخيص: GPL-2.0-or-later

LUATEX(1) دليل الأوامر العام LUATEX(1)

الاسم

luatex, dviluatex, luahbtex, luajittex, texlua, texluac - نسخة موسعة من TeX تستخدم Lua كلغة برمجة نصية مضمنة

الملخص

luatex [--lua=FILE] [OPTION]... [TEXNAME[.tex]] [COMMANDS]
luatex [--lua=FILE] [OPTION]... \FIRST-LINE
luatex [--lua=FILE] [OPTION]... &FMT [ARGS]

الوصف

يشغل آلية الطباعة luaTeX على TEXNAME، مما ينشئ عادةً TEXNAME.pdf. تتم معالجة أي COMMANDS متبقية كمدخلات luatex، بعد قراءة TEXNAME.

بدلاً من ذلك، إذا بدأ أول وسيط غير اختياري بشرطة مائلة للخلف (\)، ففسر جميع الوسائط غير الاختيارية كسطر إدخال luatex.

بدلاً من ذلك، إذا بدأ أول وسيط غير اختياري بـ &، يتم أخذ الكلمة التالية كـ FMT للقراءة، مما يلغي كل شيء آخر. تتم معالجة الوسائط المتبقية كما هو موضح أعلاه.

إذا لم يتم تحديد أي وسائط أو خيارات، يطلب الإدخال.

إذا تم استدعاؤه باسم texlua فإنه يعمل كمفسر Lua. إذا تم استدعاؤه باسم texluac فإنه يعمل كمترجم لـ Lua bytecode.

بدأ LuaTeX كنسخة موسعة من pdfTeX مع دعم Unicode و OpenType للخطوط، ولغة البرمجة النصية المضمنة Lua، وامتدادات e-TeX و Omega، بالإضافة إلى محرك MetaPost متكامل، والذي يمكنه إنشاء ملفات PDF بالإضافة إلى ملفات DVI. لمزيد من المعلومات حول luatex، راجع http://www.luatex.org؛ ويمكنك قراءة دليل LuaTeX باستخدام أداة texdoc (texdoc luatex).

يعتبر جميع مدخلات ومخرجات نصوص LuaTeX نصوص Unicode، على الرغم من أن المرشحات المختلفة تجعل من الممكن دعم أي ترميز.

في وضع DVI، يمكن استخدام LuaTeX كبديل كامل لمحرك TeX.

في وضع PDF، يمكن لـ LuaTeX التعامل أصليًا مع تنسيقات الرسومات PDF و JPG و JBIG2 و PNG. لا يمكن لـ LuaTeX تضمين ملفات رسومات PostScript أو Encapsulated PostScript (EPS)؛ قم بتحويلها أولاً إلى PDF باستخدام epstopdf (1).

يشتمل المتغير luajittex على مترجم Lua just-in-time.

يمكن للمتغير luahbtex استخدام محرك HarfBuzz لتشكيل الأحرف، بدلاً من مشكل الأحرف المضمن في LuaTeX.

خيارات

عند بدء تشغيل الملف التنفيذي LuaTeX، يبحث عن الخيار --lua في سطر الأوامر. إذا لم يكن هناك خيار --lua، يتم تفسير سطر الأوامر بطريقة مشابهة لطريقة pdfTeX و Aleph التقليدية. ولكن إذا كان الخيار موجودًا، سيدخل LuaTeX وضعًا بديلاً لتحليل سطر الأوامر مقارنة ببرامج web2c القياسية. وجود --lua يجعل معظم الخيارات الأخرى غير موثوق بها، لأن ملف تهيئة lua يمكنه تعطيل kpathsea و/أو ربط الدوال بمختلف ردود النداء.

--lua=FILE
ملف تهيئة lua.

الخيارين التاليين يغيران سلوك التنفيذ:

--luaonly
بدء LuaTeX كمفسر Lua. في هذا الوضع، سيقوم بتعيين arg[0] الخاص بـ Lua إلى اسم البرنامج النصي الذي تم العثور عليه، ودفع الخيارات السابقة بقيم سالبة وبقية سطر الأوامر في القيم الإيجابية، تمامًا مثل مفسر Lua. سيخرج LuaTeX فورًا بعد تنفيذ البرنامج النصي Lua المحدد.
--luaconly
بدء LuaTeX كمترجم Lua bytecode. في هذا الوضع، LuaTeX مطابق تمامًا لـ luac من توزيعة Lua المستقلة، باستثناء أنه لا يحتوي على المفتاح -l، وأنه يقبل (لكنه يتجاهل) المفتاح --luaconly.

ثم خيارات web2c العادية:

--debug-format

تصحيح تحميل التنسيق.
--draftmode
يضبط \pdfdraftmode بحيث لا يكتب luaTeX ملف PDF ولا يقرأ أي صور مضمنة، مما يؤدي إلى تسريع التنفيذ.
--enable-write18

مرادف لـ --shell-escape.
--disable-write18

مرادف لـ --no-shell-escape.
--shell-escape

تمكين البناء \write18{command}، ودوال Lua os.execute() و os.exec() و os.spawn() و io.popen(). يمكن أن يكون command أي أمر shell. هذا البناء غير مسموح به عادة لأسباب أمنية.
--no-shell-escape

تعطيل البناء \write18{command} ودوال Lua الأخرى، حتى لو تم تمكينها في ملف texmf.cnf.
--shell-restricted
تمكين نسخة مقيدة من \write18 و os.execute() و os.exec() و os.spawn() و io.popen()، فقط الأوامر المدرجة في ملف texmf.cnf مسموح بها.
--file-line-error
طباعة رسائل الخطأ بالشكل file:line:error وهو مشابه لطريقة تنسيق العديد من المترجمات لها.
--no-file-line-error
تعطيل طباعة رسائل الخطأ بأسلوب file:line:error.
--fmt=FORMAT
استخدم FORMAT كاسم للتنسيق المراد استخدامه، بدلاً من الاسم الذي تم استدعاء luaTeX به أو سطر %&.
--help
طباعة رسالة المساعدة والخروج.
--ini
ابدأ في وضع INI، والذي يستخدم لتفريغ التنسيقات. يمكن استخدام وضع INI للطباعة، ولكن لا يتم تحميل أي تنسيق مسبقًا، وقد تكون التهيئة الأساسية مثل تعيين فئات الأحرف مطلوبة.
--interaction=MODE
يضبط وضع التفاعل. يمكن أن يكون MODE إما batchmode أو nonstopmode أو scrollmode أو errorstopmode. معنى هذه الأوضاع هو نفس معنى الأوامر \ المقابلة.
--jobname=NAME
استخدم NAME لاسم المهمة، بدلاً من استخراجه من اسم ملف الإدخال.
--kpathsea-debug=BITMASK
يضبط علامات تصحيح البحث عن المسار وفقًا لـ BITMASK. راجع دليل Kpathsea للحصول على التفاصيل.
--mktex=FMT
تمكين إنشاء mktexFMT، حيث يجب أن يكون FMT إما tex أو tfm.
--nosocket
تعطيل مكتبة luasocket (الشبكة).
--output-comment=STRING
في وضع DVI، استخدم STRING لتعليق ملف DVI بدلاً من التاريخ. يتم تجاهل هذا الخيار في وضع PDF.
--output-directory=DIRECTORY
اكتب ملفات الإخراج في DIRECTORY بدلاً من الدليل الحالي. ابحث عن ملفات الإدخال في DIRECTORY أولاً، ثم على طول مسار البحث العادي.
--output-format=FORMAT
اضبط وضع تنسيق الإخراج، حيث يجب أن يكون FORMAT إما pdf أو dvi. يؤثر هذا أيضًا على مجموعة تنسيقات الرسومات التي يفهمها luaTeX.
--progname=NAME
تصرف وكأنك البرنامج NAME (فقط لـ kpathsea).
--recorder
تمكين مسجل الملفات. يترك هذا سجلاً للملفات التي تم فتحها للإدخال والإخراج في ملف بامتداد .fls.
--safer
تعطيل بعض أوامر Lua التي يمكن إساءة استخدامها بسهولة من قبل مستند ضار.
--syncte

NAME

luatex — Lua enhanced TeX

SYNOPSIS

luatex [options] {<tex-file> [<file-arguments>…]}

luatex [options] {&formatname [<file-arguments>…]}

DESCRIPTION

LuaTeX is a typesetting system which combines the power of TeX with the flexibility of the Lua programming language. It is a direct descendant of pdfTeX, and inherits most of its features, including the ability to directly produce PDF output. In addition, LuaTeX offers a clean and powerful API for extending and controlling the typesetting process.

The primary goal of LuaTeX is to make TeX extensible, in a way that allows for modern typographic features and advanced typesetting capabilities to be integrated into the TeX engine.

This manual page only describes a subset of the options available in LuaTeX. For a complete list and more detailed explanations, please refer to the official LuaTeX documentation.

OPTIONS

--interaction=mode
Set the interaction mode. mode can be one of `batchmode', `nonstopmode', `scrollmode', `shortdisplaymode', `normalmode' (default).
-output-directory=dir
Set the output directory. All output files (PDF, log, aux, etc.) will be written to dir instead of the current directory.
-jobname=name
Set the job name. This determines the base name for the output files.
--fmt=name
Use the format file name instead of the default.
--ini
Run in INI mode, for use in building formats.
--engine=name
Use a specific engine. This is primarily for compatibility and typically not needed when running LuaTeX directly.
-version
Print version information and exit.
-help
Print a help message and exit.
--addons=addons
Load specified Lua addons. addons is a comma-separated list of addon names.
--synctex=NUMBER
Enable/disable SyncTeX extension.
--version
Print version information and exit.
--credits
Print credits and version details.
The following options are ignored:
--8bit, --etex, --parse-first-line, --no-parse-first-line
These are always on.
--default-translate-file=TCXNAME, --translate-file=TCXNAME
These are always off.

SEE ALSO

pdftex(1), etex(1), aleph(1), lua(1).

AUTHORS

The primary authors of LuaTeX are Taco Hoekwater, Hartmut Henkel, Hans Hagen, and Luigi Scarso, with help from Martin Schröder, Karel Skoupy, and Han The Thanh.

TeX was designed by Donald E. Knuth, who implemented it using his Web system for Pascal programs. It was ported to Unix at Stanford by Howard Trickey, and at Cornell by Pavel Curtis. The version now offered with the Unix TeX distribution is that generated by the Web to C system (web2c), originally written by Tomas Rokicki and Tim Morgan.

The LuaTeX home page is http://luatex.org.
