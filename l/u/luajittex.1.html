NAME

luajittex - LuaJITTeX engine for LuaTeX

SYNOPSIS

luajittex [OPTION]... [TEXINPUTS]

DESCRIPTION

LuaJITTeX is a variant of LuaTeX that uses the LuaJIT compiler instead of the standard Lua interpreter. This can lead to significant speed improvements for Lua scripts executed within LuaTeX.

LuaJITTeX offers all the features of LuaTeX, including:

- Direct access to Unicode characters.
- Extended support for OpenType fonts.
- A powerful embedded Lua scripting interface.
- Full support for the TeX, LaTeX, and ConTeXt macro packages.

The command-line options are largely compatible with those of pdftex and luatex.

OPTIONS

-c
Purge the format file cache.
--engine-version
Print the engine version information and exit.
--help
Print a help message and exit.
-interaction=MODE
Set interaction mode. MODE can be one of batchmode, nonstopmode, scrollmode, and nonstopmode.
-job-name=NAME
Use NAME for the job name.
-kpathsea-debug=BITMASK
Enable Kpathsea debugging. See kpathsea(3) for details.
---lua=FILE
Execute the Lua script in FILE before processing the input file.
--etex
Enable e-TeX extensions. This is the default.
--disable-etex
Disable e-TeX extensions.
--etex-mode=MODE
Set e-TeX mode. MODE can be etex, etex-pdf, or etex-tex.
--parse-first-line
Parse the first line of the input file for TeX directives (e.g., format). This is the default.
--no-parse-first-line
Do not parse the first line of the input file.
-fmt=NAME
Use the format file NAME. The default is luajittex.
-output-directory=DIR
Write output files in directory DIR.
-program-name=NAME
Set the program name (used for finding formats).
--recorder
Enable file change logging.
--shell-escape
Enable running external commands (dangerous).
--no-shell-escape
Disable running external commands.
--shell-safe-escape
Enable running external commands that are considered safe.
--synctex=NUMBER
Enable/disable SyncTeX extension.
--version
Print version information and exit.
--credits
Print credits and version details.
The following options are ignored:
--8bit, --etex, --parse-first-line, --no-parse-first-line
These are always on.
--default-translate-file=TCXNAME, --translate-file=TCXNAME
These are always off.

AUTHORS

LuaJITTeX is a derivative of LuaTeX. The primary authors of LuaTeX are Taco Hoekwater, Hartmut Henkel, Hans Hagen, and Luigi Scarso, with help from Martin Schröder, Karel Skoupy, and Han The Thanh.

The LuaJIT compiler itself is authored by Mike Pall.

TeX was designed by Donald E. Knuth, who implemented it using his Web system for Pascal programs. It was ported to Unix at Stanford by Howard Trickey, and at Cornell by Pavel Curtis. The version now offered with the Unix TeX distribution is that generated by the Web to C system (web2c), originally written by Tomas Rokicki and Tim Morgan.

The LuaTeX home page is http://luatex.org.

The LuaJIT home page is http://luajit.org.
