mtxrun(1) أداة تشغيل ConTeXt TDS mtxrun(1)

الاسم


mtxrun - أداة تشغيل ConTeXt TDS

الملخص

mtxrun [ خيارات ... ] [ أسماء الملفات ]

الوصف

أداة تشغيل ConTeXt TDS

خيارات

--script
تشغيل سكريبت mtx (lua هي الطريقة المفضلة) (--noquotes)، لا يوجد سكريبت يعطي قائمة
--evaluate
تشغيل الكود المقدم في سطر الأوامر (بين علامتي اقتباس) (=loop) (exit|quit للإيقاف)
--execute
تشغيل سكريبت أو برنامج (طريقة texmfstart) (--noquotes)
--resolve
حل الوسيطات ذات البادئات
--ctxlua
التشغيل داخليًا (باستخدام المكتبات المحملة مسبقًا)
--internal
تشغيل السكريبت باستخدام المكتبات المضمنة (نفس --ctxlua)
--locate
تحديد موقع اسم الملف المعطى في قاعدة البيانات (افتراضي) أو النظام (--first --all --detail)
--tree=pathtotree
استخدام شجرة texmf المعطاة (الملف الافتراضي: setuptex.tmf)
--path=runpath
الانتقال إلى المسار المعطى قبل التنفيذ
--ifchanged=filename
التنفيذ فقط عند تغيير الملف المعطى (تدقيق md)
--iftouched=old,new
التنفيذ فقط عند تغيير الملف المعطى (ختم زمني)
--makestubs
إنشاء stubs (مؤشرات) للسكريبتات (المتعلقة بـ context)
--removestubs
إزالة stubs (مؤشرات) للسكريبتات (المتعلقة بـ context)
--stubpath=binpath
المسارات التي سيتم كتابة stubs فيها
--windows
إنشاء stubs لنظام ويندوز (mswin)
--unix
إنشاء stubs لنظام يونكس (لينكس)
--addbinarypath
إضافة binarypath (الموجود) إلى بداية المسارات للمشغلات
--verbose
تقديم المزيد من المعلومات
--trackers=list
تمكين المتعقبات المعطاة
--progname=str
تنسيق أو الواجهة الخلفية
--systeminfo=str
عرض نظام التشغيل الحالي، المعالج، إلخ
--edit
تشغيل المحرر مع الملف الذي تم العثور عليه
--launch
تشغيل الملفات مثل الأدلة، يفترض دعم نظام التشغيل (--all,--list)
--timedrun
تشغيل سكريبت وتوقيت تشغيله
--autogenerate
إعادة إنشاء قواعد البيانات إذا لزم الأمر (مفيد عند استخدامه لتشغيل context في محرر)
--usekpse
استخدام kpse كبديل (عند عدم وجود mkiv و cache مثبت، غالبًا أبطأ)
--forcekpse
فرض استخدام kpse (مفيد عند عدم وجود mkiv و cache مثبت ولكن بوظائف أقل)
--prefixes
عرض البادئات المدعومة
--generate
إنشاء قاعدة بيانات الملفات
--variables
عرض متغيرات التكوين
--configurations
عرض ترتيب التكوين
--directives
عرض التوجيهات (المعروفة)
--trackers
عرض المتعقبات (المعروفة)
--experiments
عرض التجارب (المعروفة)
--expand-braces
توسيع المتغير المعقد
--resolve-path
توسيع المتغير (حل المسارات بالكامل)
--expand-path
توسيع المتغير (حل المسارات)
--expand-var
توسيع المتغير (حل المراجع)
--show-path
عرض توسيع المسار لـ ...
--var-value
الإبلاغ عن قيمة المتغير
--find-file
الإبلاغ عن موقع الملف
--find-path
الإبلاغ عن مسار الملف
--pattern=string
تصفية المتغيرات
