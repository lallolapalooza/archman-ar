LUAOTFLOAD-TOOL(1) معالجة النص LUAOTFLOAD-TOOL(1)

الاسم

luaotfload-tool - إنشاء والاستعلام عن قاعدة بيانات أسماء الخطوط Luaotfload

الملخص

luaotfload-tool [ -bcDfFiIlLnpqRSuvVhw ]

luaotfload-tool --update [ --force ] [ --quiet ] [ --verbose ]
[ --prefer-texmf ] [ --dry-run ] [ --formats=[+|-]EXTENSIONS ] [ --no-compress ] [ --no-strip ] [ --local ] [ --max-fonts=N ]
luaotfload-tool --find=FONTNAME [ --fuzzy ] [ --info ] [ --inspect ]
[ --no-reload ]

luaotfload-tool --flush-lookups

luaotfload-tool --cache=DIRECTIVE

luaotfload-tool --list=CRITERION[:VALUE] [ --fields=F1,F2,...,Fn ]

luaotfload-tool --bisect=DIRECTIVE

luaotfload-tool --help

luaotfload-tool --version

luaotfload-tool --show-blacklist

luaotfload-tool --diagnose=CHECK

luaotfload-tool --conf=FILE --dumpconf

الوصف

يتيح أداة luaotfload-tool الوصول إلى قاعدة بيانات أسماء الخطوط المطلوبة بواسطة حزمة Luaotfload. هناك وضعان عامان: update (تحديث) و query (استعلام).

  • update: تحديث قاعدة البيانات أو إعادة بنائها بالكامل؛
  • query: حل اسم خط أو عرض مطابقات قريبة.

الخيارات

وضع التحديث (update mode)

--update, -u
تحديث قاعدة البيانات؛ فهرسة خطوط جديدة.
--force, -f
فرض إعادة بناء قاعدة البيانات؛ إعادة فهرسة جميع الخطوط.
--local, -L
تضمين ملفات الخطوط في $PWD. سيؤدي هذا الخيار إلى إعادة بناء أجزاء كبيرة من قاعدة البيانات. وبالتالي فهو غير فعال للغاية. بالإضافة إلى ذلك، إذا تم العثور على ملفات خطوط محلية، يتم منع حفظ قاعدة البيانات على القرص، لذا يجب تحليل الخطوط المحلية مع كل استدعاء لـ luaotfload-tool.
--no-reload, -n
منع التحديثات التلقائية لقاعدة البيانات (على سبيل المثال، عند تمرير --find إلى اسم غير معروف).
--no-compress, -c
لا تقم بضغط النسخة النصية العادية لفهرس الخطوط عبر gzip. مفيد لتصحيح الأخطاء إذا كان محرر النصوص الخاص بك مبنيًا بدون zlib.
--prefer-texmf, -p
تنظيم قاعدة بيانات أسماء الملفات بطريقة تفضل الخطوط الموجودة في شجرة TEXMF على خطوط النظام إذا كانت مثبتة في كليهما.
--formats=EXTENSIONS
امتدادات ملفات الخطوط المراد فهرستها. حيث EXTENSIONS هي قائمة مفصولة بفواصل للامتدادات المدعومة (otf, ttf, ttc). إذا كانت القائمة مسبوقة بعلامة +، تتم إضافة القائمة المعطاة إلى القائمة النشطة حاليًا؛ - تطرح. الافتراضي: otf,ttf,ttc. أمثلة:
1.
--formats=-ttc,ttf سيؤدي إلى تخطي خطوط TrueType ومجموعات الخطوط؛
2.
--formats=otf سيقوم بفحص ملفات OpenType فقط؛
3.
--formats=+afm يتضمن ملفات Postscript الثنائية مصحوبة بملف AFM.

وضع الاستعلام (query mode)

--find=NAME
حل اسم خط؛ يبحث عن <name> في قاعدة البيانات ويطبع اسم الملف الذي تم ربطه به. --find يفهم أيضًا بناء جملة الطلب، أي --find=file:foo.otf يتحقق مما إذا كان foo.otf مفهرسًا.
--fuzzy, -F
عرض مطابقات تقريبية لاسم الملف إذا فشل البحث (يتطلب --find).
--info, -i
عرض معلومات أساسية عن ملف خط تم حله (يتطلب --find).
--inspect, -I
عرض معلومات مفصلة عن طريق تحميل الخط وتحليل جدول الخطوط؛ بطيء جدًا! لمعرفة معنى الحقول المرجعة، راجع وثائق LuaTeX. (يتطلب --find).
--list=CRITERION
عرض الإدخالات، حيث CRITERION هو أحد الخيارات التالية:
1.
الحرف *، لاختيار جميع الإدخالات؛
2.
حقل في إدخال قاعدة البيانات، على سبيل المثال version أو format*، سيتم فرز المخرجات بناءً عليه. المعلومات في قاعدة بيانات غير مضغوطة (انظر الخيار --no-strip أعلاه) متداخلة: يمكن الوصول إلى الحقول الفرعية للسجل باستخدام الفاصل ->، على سبيل المثال، file->location، style->units_per_em، أو names->sanitized->english->prefmodifiers. ملاحظة: بناء جملة shell يتطلب أن تكون الوسائط التي تحتوي على -> مقتبسة بشكل صحيح!
3.
تعبير بالشكل field:value لتحديد المخرجات للإدخالات التي يتطابق فيها field مع value. يمكن أن تحتوي value على * لمطابقة عدد عشوائي من الأحرف.

على سبيل المثال، لإخراج أسماء الملفات والإصدارات المقابلة، مرتبة حسب تنسيق الخط:

./luaotfload-tool.lua --list="format" --fields="file->base,version"

هذا يطبع:

otf latinmodern-math.otf  Version 1.958
otf lmromancaps10-oblique.otf 2.004
otf lmmono8-regular.otf 2.004
otf lmmonoproplt10-bold.otf 2.004
otf lmsans10-oblique.otf  2.004
otf lmromanslant8-regular.otf 2.004
otf lmroman12-italic.otf  2.004
otf lmsansdemicond10-oblique.otf  2.004
...
--fields=FIELDS
قائمة مفصولة بفواصل للحقول التي يجب طباعتها. المعلومات في قاعدة بيانات غير مضغوطة (انظر الخيار --no-strip أعلاه) متداخلة: يمكن الوصول إلى الحقول الفرعية للسجل باستخدام الفاصل ->، على سبيل المثال، file->location، style->units_per_em، أو names->sanitized->english->subfamily. الافتراضي هو plainname,version*. (له معنى فقط مع --list.)

ذاكرة التخزين المؤقت للخطوط والبحث

--flush-lookups
مسح ذاكرة التخزين المؤقت للبحث عن أسماء الخطوط (تجريبي).
--cache=DIRECTIVE
التحكم في ذاكرة التخزين المؤقت، حيث DIRECTIVE هو أحد الخيارات التالية:
1.
purge -> حذف ملفات Lua من ذاكرة التخزين المؤقت؛
2.
erase -> حذف ملفات Lua و Luc من ذاكرة التخزين المؤقت؛
3.
show -> طباعة الإحصائيات.

طرق تصحيح الأخطاء

--show-blacklist, -b
عرض الملفات المدرجة في القائمة السوداء (وليس المجلدات).
--dry-run, -D
لا تقم بتحميل الخطوط عند تحديث قاعدة البيانات؛ قم بفحص المجلدات فقط. (لتصحيح الأخطاء المتعلقة بنظام الملفات.)
--no-strip
لا تقم بإزالة المعلومات الزائدة بعد بناء قاعدة البيانات. تحذير: سيؤدي هذا إلى تضخيم الفهرس إلى حوالي ضعف إلى ثلاثة أضعاف الحجم الطبيعي.
--max-fonts=N
الحد الأقصى لعدد الخطوط التي يتم فهرستها (مفيد عند اختبار.

--verbose, -v: زيادة تفاصيل المخرجات.

--quiet, -q: تقليل تفاصيل المخرجات.

--force-run-script, -R: لتشغيل آلية التحديث.

--version, -V: عرض الإصدار.

--help, -h: عرض المساعدة.

--diagnose=CHECK: تشغيل فحوصات معينة (على سبيل المثال، missing-files).

--conf=FILE: استخدم ملف إعدادات معين.

--dumpconf: اطبع ملف الإعدادات الافتراضي.

أمثلة

لتحديث قاعدة البيانات:

$ luaotfload-tool --update

لإعادة بناء قاعدة البيانات بالكامل، مع تفضيل خطوط TEXMF:

$ luaotfload-tool --update --force --prefer-texmf

للبحث عن الخط الذي يسمى "MyFont" وعرض مساره:

$ luaotfload-tool --find=MyFont

لعرض جميع الخطوط التي يبدأ اسمها بـ "Times" (بشكل تقريبي):

$ luaotfload-tool --find=Times --fuzzy

لعرض معلومات مفصلة عن خط معين:

$ luaotfload-tool --find=SourceSansPro --inspect

لعرض جميع ملفات الخطوط من النوع OTF:

$ luaotfload-tool --list=format:otf

لعرض أسماء الخطوط وإصداراتها، مرتبة حسب اسم عائلة الخط:

$ luaotfload-tool --list=family --fields=plainname,version

لمسح ذاكرة التخزين المؤقت للبحث:

$ luaotfload-tool --flush-lookups
