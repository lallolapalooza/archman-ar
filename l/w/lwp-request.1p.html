lwp-request(1p)

الحزمة: perl-libwww

التراخيص: GPL-1.0-or-later OR Artistic-1.0-Perl

LWP-REQUEST(1) وثائق Perl مساهمة من المستخدم LWP-REQUEST(1)

الاسم

lwp-request - وكيل مستخدم بسيط عبر سطر الأوامر

الاستخدام

lwp-request [-afPuUsSedvhx] [-m الطريقة] [-b عنوان URL أساسي] [-t مهلة]
[-i آخر تعديل منذ] [-c نوع المحتوى]
[-C بيانات الاعتماد] [-p عنوان URL للبروكسي] [-o تنسيق] عنوان URL...

الوصف

يمكن استخدام هذا البرنامج لإرسال طلبات إلى خوادم WWW ونظام الملفات المحلي. يتم قراءة محتوى الطلب لطرق POST و PUT و PATCH من الإدخال القياسي. يتم طباعة محتوى الاستجابة على الإخراج القياسي. يتم طباعة رسائل الخطأ على الإخراج القياسي للخطأ. يعيد البرنامج قيمة حالة تشير إلى عدد عناوين URL التي فشلت.

الخيارات هي:

-m <method>
تعيين الطريقة المستخدمة للطلب. إذا لم يتم استخدام هذا الخيار، يتم اشتقاق الطريقة من اسم البرنامج.
-f
فرض الطلب، حتى لو كان البرنامج يعتقد أن الطريقة غير قانونية. قد يرفض الخادم الطلب في النهاية.
-b <uri>
سيتم استخدام عنوان URI هذا كعنوان URI أساسي لحل جميع عناوين URI النسبية المعطاة كحجة.
-t <timeout>
تعيين قيمة المهلة للطلبات. المهلة هي مقدار الوقت الذي سينتظره البرنامج للحصول على استجابة من الخادم البعيد قبل فشله. الوحدة الافتراضية لقيمة المهلة هي الثواني. قد تلحق "m" أو "h" بقيمة المهلة لجعلها دقائق أو ساعات، على التوالي. المهلة الافتراضية هي '3m'، أي 3 دقائق.
-i <time>
تعيين رأس If-Modified-Since في الطلب. إذا كان الوقت هو اسم ملف، فاستخدم طابع وقت التعديل لهذا الملف. إذا لم يكن الوقت ملفًا، فسيتم تحليله كتاريخ حرفي. ألق نظرة على HTTP::Date للتنسيقات المعترف بها.
-c <content-type>
تعيين نوع المحتوى للطلب. هذا الخيار مسموح به فقط للطلبات التي تأخذ محتوى، أي POST و PUT و PATCH. يمكنك فرض الطرق على أخذ محتوى باستخدام الخيار "-f" مع "-c". نوع المحتوى الافتراضي لـ POST هو "application/x-www-form-urlencoded". نوع المحتوى الافتراضي للآخرين هو "text/plain".
-p <proxy-url>
تعيين البروكسي المراد استخدامه للطلبات. يقوم البرنامج أيضًا بتحميل إعدادات البروكسي من البيئة. يمكنك تعطيل ذلك باستخدام الخيار "-P".
-P
لا تقم بتحميل إعدادات البروكسي من البيئة.
-H <header>
إرسال هذا الرأس HTTP مع كل طلب. يمكنك تحديد عدة رؤوس، على سبيل المثال: 
lwp-request \
    -H 'Referer: http://other.url/' \
    -H 'Host: somehost' \
    http://this.url/

إذا كان اسم الرأس مسبوقًا بنقطتين، فلن يتم توحيده (انظر "أسماء الحقول غير القياسية" في HTTP::Headers).

-C <username>:<password>
تقديم بيانات اعتماد للمستندات المحمية بالمصادقة الأساسية. إذا كان المستند محميًا ولم تقم بتحديد اسم المستخدم وكلمة المرور باستخدام هذا الخيار، فسيُطلب منك توفير هذه القيم.

الخيارات التالية تتحكم فيما يعرضه البرنامج:

-u
طباعة طريقة الطلب وعنوان URL المطلق عند إجراء الطلبات.
-U
طباعة رؤوس الطلب بالإضافة إلى طريقة الطلب وعنوان URL المطلق.
-s
طباعة رمز حالة الاستجابة. هذا الخيار قيد التشغيل دائمًا لطلبات HEAD.
-S
طباعة سلسلة حالة الاستجابة. يعرض هذا طلبات إعادة التوجيه والمصادقة التي تتعامل معها المكتبة.
-e
طباعة رؤوس الاستجابة. هذا الخيار قيد التشغيل دائمًا لطلبات HEAD.
-E
طباعة سلسلة حالة الاستجابة مع رؤوس الاستجابة الكاملة.
-d
لا تقم بطباعة محتوى الاستجابة.
-o <format>
معالجة محتوى HTML بطرق مختلفة قبل طباعته. إذا كان نوع المحتوى للاستجابة ليس HTML، فإن هذا الخيار ليس له تأثير. القيم القانونية للتنسيق هي؛ "text"، "ps"، "links"، "html" و "dump".

إذا حددت تنسيق "text"، فسيتم تنسيق HTML كنص عادي "latin1". إذا حددت تنسيق "ps"، فسيتم تنسيقه كـ Postscript.

سيقوم تنسيق "links" بإخراج جميع الروابط الموجودة في مستند HTML. سيتم توسيع الروابط النسبية إلى روابط مطلقة.

سيقوم تنسيق "html" بإعادة تنسيق كود HTML وسيقوم تنسيق "dump" ببساطة بعرض شجرة بناء جملة HTML.

لاحظ أن توزيع "HTML-Tree" يجب تثبيته حتى يعمل هذا الخيار. بالإضافة إلى ذلك، يجب تثبيت توزيع "HTML-Format" حتى يعمل "-o text" أو "-o ps".

-v
طباعة رقم إصدار البرنامج وإنهاء.
-h
طباعة رسالة الاستخدام وإنهاء.
-a
تعيين وضع النص (ascii) لإدخال وإخراج المحتوى. إذا لم يتم استخدام هذا الخيار، يتم إدخال وإخراج المحتوى في الوضع الثنائي.

نظرًا لأن هذا البرنامج منفذ باستخدام مكتبة LWP، فإنه سيدعم فقط البروتوكولات التي تدعمها LWP.

lwp-request(1p) - صفحة الدليل

الاسم

lwp-request - طلب URI

مقدمة

يستخدم lwp-request (المعروف سابقًا باسم GET) لطلب URI. يمكن استخدامه للحصول على محتوى صفحة ويب، أو إرسال بيانات إلى خادم ويب.

الاستخدام

lwp-request [خيارات] URI

الخيارات

  • -h، --help: عرض رسالة المساعدة والخروج.
  • -V، --version: عرض معلومات الإصدار والخروج.
  • -m، --method <METHOD>: تعيين طريقة HTTP (مثل GET، POST، PUT، DELETE، إلخ). الافتراضي هو GET.
  • -a، --agent <AGENT>: تعيين سلسلة وكيل المستخدم HTTP.
  • -H، --header <HEADER>: تعيين رأس HTTP. يمكن استخدام هذا الخيار عدة مرات.
  • -C، --credentials <USER:PASS>: تعيين بيانات الاعتماد للمصادقة الأساسية.
  • -f، --force: تجاهل التحقق من نوع المحتوى.
  • -v، --verbose: زيادة الإسهاب.
  • -d، --data <DATA>: إرسال بيانات في جسم الطلب (مفيد لطرق POST و PUT).
  • -F، --file <FILE>: إرسال ملف في جسم الطلب (مفيد لطرق POST).

أمثلة

# جلب صفحة ويب
lwp-request http://www.example.com

# إرسال بيانات POST
lwp-request -m POST -d 'key=value&anotherkey=anothervalue' http://www.example.com/submit

# إرسال ملف عبر POST
lwp-request -m POST -F 'upload_file=@/path/to/your/file.txt' http://www.example.com/upload
