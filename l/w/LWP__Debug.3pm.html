LWP__Debug(3pm)

الحزمة: perl-libwww

التراخيص: GPL-1.0-or-later OR Artistic-1.0-Perl

LWP::Debug(3) توثيق بيرل من مساهمة المستخدم LWP::Debug(3)

الاسم

LWP::Debug - تم إيقافه

الوصف

تم إيقاف هذه الوحدة. يرجى الرجوع إلى LWP::ConsoleLogger لاحتياجات التصحيح الخاصة بك.

تُستخدم LWP::Debug لتوفير مرافق التتبع، ولكنها لم تعد مستخدمة بواسطة LWP. يتم الاحتفاظ بالكود الموجود في هذه الوحدة (دون توثيق) حتى تستمر التعليمات البرمجية الخارجية التي تستخدم الواجهات القديمة في العمل.

إحدى الميزات المفيدة التي وفرتها LWP::Debug (بطريقة غير دقيقة ومزعجة) كانت مراقبة حركة مرور الشبكة. يوفر القسم التالي بعض التلميحات حول البدائل الموصى بها.

مراقبة حركة مرور الشبكة

أفضل طريقة لمراقبة حركة مرور الشبكة التي تنشئها LWP هي استخدام برنامج مراقبة TCP خارجي. يوصى بشدة ببرنامج WireShark http://www.wireshark.org/ لهذا الغرض.

نهج آخر هو استخدام خادم وكيل HTTP للتصحيح وجعل LWP توجه كل حركة مرورها عبر هذا الخادم. قم باستدعاء "$ua->proxy" لإعداده ثم استخدم LWP كما هو الحال من قبل.

للاحتياجات الأقل دقة للمراقبة، قد يكون مجرد إعداد بعض المعالجات البسيطة كافيًا. يقوم المثال التالي بإعداد معالجات لتفريغ كائنات الطلب والاستجابة التي تمر عبر LWP:

use LWP::UserAgent;
$ua = LWP::UserAgent->new;
$ua->default_header('Accept-Encoding' => scalar HTTP::Message::decodable());
$ua->add_handler("request_send",  sub { shift->dump; return });
$ua->add_handler("response_done", sub { shift->dump; return });
$ua->get("http://www.example.com");
