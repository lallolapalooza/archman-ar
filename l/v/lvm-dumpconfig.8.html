الاسم

lvmconfig — عرض ومعالجة معلومات التكوين

الملخص

lvmconfig
[ option_args ]
[ position_args ]

الوصف

يقوم lvmconfig، lvm config، lvm dumpconfig (لأسباب التوافق، سيتم إزالته لاحقًا) بإنتاج مخرجات مهيكلة من شجرة تكوين LVM. تشمل مصادر بيانات التكوين lvm.conf(5) والإعدادات من سطر الأوامر عبر --config.

الخيارات

--atversion String
تحديد إصدار LVM بتنسيق x.y.z حيث x هو الإصدار الرئيسي، y هو الإصدار الفرعي، و z هو مستوى التصحيح (مثل 2.2.106). عند عرض التكوين، سيتم فقط أخذ إعدادات التكوين المعترف بها في إصدار LVM هذا في الاعتبار. يمكن استخدام هذا لعرض تكوين يفهمه إصدار LVM معين ولا يحتوي على إعدادات أحدث قد يصدر LVM رسالة تحذير عند التحقق من التكوين.
--commandprofile String
ملف تعريف الأمر المراد استخدامه لتكوين الأمر. انظر lvm.conf(5) لمزيد من المعلومات حول ملفات التعريف.
--config String
إعدادات التكوين للأمر. هذه تتجاوز إعدادات lvm.conf(5). يستخدم وسيط String نفس تنسيق lvm.conf(5)، أو قد يستخدم صيغة القسم/الحقل. انظر lvm.conf(5) لمزيد من المعلومات حول التكوين.
-d|--debug ...
تحديد مستوى التصحيح. كرر من 1 إلى 6 مرات لزيادة تفاصيل الرسائل المرسلة إلى ملف السجل و/أو syslog (إذا تم تكوينه).
--devices PV
تقييد الأجهزة التي تكون مرئية ويمكن الوصول إليها للأمر. الأجهزة غير المدرجة ستظهر على أنها مفقودة. يمكن تكرار هذا الخيار، أو قبول قائمة أجهزة مفصولة بفواصل. هذا يتجاوز ملف الأجهزة.
--devicesfile String
ملف يسرد الأجهزة التي يجب أن يستخدمها LVM. يجب أن يكون الملف موجودًا في /etc/lvm/devices/ ويتم إدارته باستخدام الأمر lvmdevices(8). هذا يتجاوز إعدادات devices/devicesfile و devices/use_devicesfile في lvm.conf(5).
--driverloaded y|n
إذا تم ضبطه على لا، فلن يحاول الأمر استخدام device-mapper. للاختبار والتصحيح.
-f|--file String
اكتب المخرجات إلى الملف المسمى.
-h|--help
عرض نص المساعدة.
--ignoreadvanced
استبعاد إعدادات التكوين المتقدمة من المخرجات.
--ignorelocal
تجاهل القسم المحلي. يجب تعريف القسم المحلي في ملف lvmlocal.conf، ويجب أن يحتوي على إعدادات تكوين خاصة بالمضيف المحلي لا يجب نسخها إلى مضيفين آخرين.
--ignoreunsupported
استبعاد إعدادات التكوين غير المدعومة من المخرجات. هذه الإعدادات إما تستخدم لأغراض التصحيح والتطوير فقط أو أن دعمها غير مكتمل بعد وليست مخصصة للاستخدام في بيئة الإنتاج. types current و diff تشمل الإعدادات غير المدعومة في مخرجاتها افتراضيًا، بينما تتجاهل جميع الأنواع الأخرى الإعدادات غير المدعومة.
--journal String
تسجيل المعلومات في سجل systemd. هذه المعلومات هي بالإضافة إلى المعلومات التي تم تمكينها بواسطة إعداد lvm.conf log/journal. command: تسجيل معلومات حول الأمر. output: تسجيل مخرجات الأمر الافتراضية. debug: تسجيل تصحيح كامل للأمر.
-l|--list
اطبع قائمة بإعدادات التكوين بدلاً من شجرة إعدادات التكوين المنظمة. إذا تم استخدامه بدون خيارات أخرى، فهذا يماثل --typeconfig list --withsummary.
--lockopt String
يستخدم لتمرير خيارات لحالات خاصة إلى lvmlockd. انظر lvmlockd(8) لمزيد من المعلومات.
--longhelp
عرض نص المساعدة الطويل.
--mergedconfig
عند تشغيل الأمر باستخدام --config و/أو --commandprofile (أو استخدام متغير البيئة LVM_COMMAND_PROFILE)، --profile، أو --metadataprofile، قم بدمج كل محتويات "متتالية التكوين" قبل عرضها. بدون الدمج، يتم عرض التكوين الموجود في مقدمة المتتالية فقط. انظر lvm.conf(5) لمزيد من المعلومات حول التكوين.
--metadataprofile String
ملف تعريف البيانات الوصفية المراد استخدامه لتكوين الأمر. انظر lvm.conf(5) لمزيد من المعلومات حول ملفات التعريف.
--nohints
لا تستخدم ملف التلميحات لتحديد مواقع الأجهزة لـ PVs. قد يقرأ الأمر المزيد من الأجهزة للعثور على PVs عندما لا يتم استخدام التلميحات. سيظل الأمر يقوم بتنفيذ إلغاء صلاحية ملف التلميحات القياسي حيثما كان ذلك مناسبًا.
--nolocking
تعطيل القفل. استخدم بحذر، قد تؤدي الأوامر المتزامنة إلى نتائج غير صحيحة.
--profile String
اسم مستعار لـ --commandprofile أو --metadataprofile، اعتمادًا على الأمر.
-q|--quiet ...
كبت المخرجات ورسائل السجل. يتجاوز --debug و --verbose. كرر مرة واحدة لكبت أي مطالبات بالإجابة "لا".
--showdeprecated
تضمين إعدادات التكوين المهملة في المخرجات. هذه الإعدادات

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

OPTIONS

--deprecated
Include deprecated configuration settings in the output. Deprecated settings are deprecated after a certain version. If a concrete version is specified with --atversion, deprecated settings are automatically included if the specified version is lower than the version in which the settings were deprecated. The current and diff types include deprecated settings in their output by default, all the other types ignore deprecated settings.
--showunsupported
Include unsupported configuration settings in the output. These settings are either used for debugging or development purposes only, or their support is not yet complete and they are not meant to be used in production. The current and diff types include unsupported settings in their output by default, all the other types ignore unsupported settings.
--sinceversion String
Specify an LVM version in x.y.z format where x is the major version, the y is the minor version and z is the patchlevel (e.g. 2.2.106). This option is currently applicable only with --typeconfig new to display all configuration settings introduced since given version.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
--typeconfig current|default|diff|full|list|missing|new|profilable|profilable-command|profilable-metadata
current prints the config settings that would be applied to an lvm command (assuming the command does not override them on the command line.) This includes: settings that have been modified in lvm config files, settings that get their default values from config files, and default settings that have been uncommented in config files. default prints all settings with their default values. Changes made in lvm config files are not reflected in the output. Some settings get their default values internally, and these settings are printed as comments. Other settings get their default values from config files, and these settings are not printed as comments. diff prints only config settings that have been modified from their default values in config files (the difference between current and default.) full prints every setting uncommented and set to the current value, i.e. how it would be used by an lvm command. This includes settings modified in config files, settings that usually get defaults internally, and settings that get defaults from config files. list prints all config names without values. missing prints settings that are missing from the lvm config files. A missing setting that usually gets its default from config files is printed uncommented and set to the internal default. Settings that get their default internally and are not set in config files are printed commented with the internal default. new prints config settings that have been added since the lvm version specified by --sinceversion. They are printed with their default values. profilable prints settings with their default values that can be set from a profile. profilable-command prints settings with their default values that can be set from a command profile. profilable-metadata prints settings with their default values that can be set from a metadata profile. Also see lvm.conf(5).
--unconfigured
Internal option used for generating config file during build.
--validate
Validate current configuration used and exit with appropriate return code. The validation is done only for the configuration at the front of the "config cascade". To validate the whole merged configuration tree, also use --mergedconfig. The validation is done even if lvm.conf(5) config/checks is disabled.
--valuesonly
When printing config settings, print only values without keys.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
--withcomments
Display a full comment for each configuration node. For deprecated settings, also display comments about deprecation.
--withgeneralpreamble
Include general config file preamble.
--withlocalpreamble
Include local config file preamble.
--withspaces
Where appropriate, add more spaces in output for better readability.
--withsummary
Display a one line comment for each configuration node.
--withversions
Also display a comment containing the version of introduction for each configuration node. If the setting is deprecated, also display the version since which it is deprecated.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)

VARIABLES

String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

NAME

lvm-dumpconfig - Display LVM configuration

SYNOPSIS

lvm-dumpconfig [-a|--all] [-l|--long] [-p|--profile] [-t|--type <type1>[,<type2>...] ] [-n|--noheadings] [-o|--ordered] [-j|--uuid] [-v|--verbose] [-M|--metadatatype <type>] [-r|--reported] [-f|--force] [-h|--help] [-m|--masked]

DESCRIPTION

lvm-dumpconfig is a command-line tool that displays the configuration of LVM (Logical Volume Manager) devices and settings. It allows users to view various aspects of the LVM configuration, including device information, volume group details, logical volume settings, and global LVM parameters.

USAGE

The basic usage of lvm-dumpconfig involves running the command with optional arguments to filter and format the output. Without any options, it displays a summary of the LVM configuration.

OPTIONS

-a, --all
Display all configuration parameters, including those not typically shown.
-l, --long
Display the configuration in a long, detailed format.
-p, --profile
Display the LVM profile configuration.
-t, --type <type1>[,<type2>...]
Specify the type(s) of configuration to display. For example, vg, lv, pv, global.
-n, --noheadings
Suppress the output of column headings.
-o, --ordered
Display the configuration in a specific order.
-j, --uuid
Display UUIDs for LVM devices.
-v, --verbose
Enable verbose output, showing more detailed information during execution.
-M, --metadatatype <type>
Specify the metadata type (e.g., lvm1, lvm2).
-r, --reported
Display reported configuration values.
-f, --force
Force the operation, potentially overriding safety checks.
-h, --help
Display a help message and exit.
-m, --masked
Display masked configuration values.

VARIABLES

This command does not directly manipulate variables but displays configuration settings that can be considered variables within the LVM system.

ENVIRONMENT VARIABLES

This command does not rely on specific environment variables for its core functionality, but standard LVM environment variables might influence its behavior indirectly.
