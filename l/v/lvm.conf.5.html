NAME

lvm.conf — ملف تكوين LVM2

SYNOPSIS

/etc/lvm/lvm.conf

DESCRIPTION

يتم تحميل lvm.conf أثناء مرحلة التهيئة لـ lvm(8). يمكن لهذا الملف بدوره تحميل ملفات أخرى - الإعدادات التي يتم قراءتها لاحقًا تتجاوز الإعدادات السابقة. يتم التحقق من الطوابع الزمنية للملفات بين الأوامر، وإذا تغير أي منها، فسيتم إعادة تحميل جميع الملفات.

لوصف كل إعداد من إعدادات lvm.conf(5)، قم بتشغيل:

lvmconfig --typeconfig default --withcomments --withspaces

يمكن تجاوز الإعدادات المعرفة في lvm.conf بأي من طرق التكوين الموسعة التالية:

تجاوز التكوين المباشر على سطر الأوامر
يأخذ خيار سطر الأوامر --config ConfigurationString السلسلة ConfigurationString كسلسلة تكوين تمثيلية مباشرة لتجاوز التكوين الحالي. ConfigurationString له نفس تنسيق ملف تكوين LVM.
ملف تعريف التكوين (profile config)

ملف التعريف هو مجموعة من إعدادات التكوين القابلة للتخصيص المختارة التي تهدف إلى تحقيق خصائص معينة في بيئات أو استخدامات مختلفة. يستخدم لتجاوز التكوين الحالي. عادة، يجب أن يعكس اسم ملف التعريف تلك البيئة أو الاستخدام.

هناك مجموعتان من ملفات التعريف المعترف بها: ملفات تعريف الأوامر و ملفات تعريف البيانات الوصفية (metadata profiles).

يستخدم ملف تعريف الأوامر لتجاوز إعدادات تكوين محددة على مستوى أمر LVM العام - يتم تطبيقه في بداية تنفيذ أمر LVM ويستخدم طوال وقت تنفيذ أمر LVM. يتم تطبيق ملف تعريف الأوامر باستخدام خيار سطر الأوامر --commandprofile ProfileName الذي تتعرف عليه جميع أوامر LVM2.

يستخدم ملف تعريف البيانات الوصفية لتجاوز إعدادات تكوين محددة على مستوى مجموعة وحدات التخزين / وحدة التخزين المنطقية - يتم تطبيقه بشكل مستقل لكل مجموعة وحدات تخزين / وحدة تخزين منطقية تتم معالجتها. على هذا النحو، يمكن لكل مجموعة وحدات تخزين / وحدة تخزين منطقية تخزين اسم ملف التعريف المستخدم في بياناتها الوصفية، بحيث يتم تطبيق ملف التعريف في المرة التالية التي تتم فيها معالجة مجموعة وحدات التخزين / وحدة التخزين المنطقية. إذا كانت مجموعة وحدات التخزين وأي من وحدات التخزين المنطقية الخاصة بها تحتوي على ملفات تعريف مختلفة محددة، فسيتم تفضيل ملف التعريف المحدد لوحدة التخزين المنطقية. يمكن ربط/فك ربط ملف تعريف البيانات الوصفية باستخدام أوامر lvchange و vgchange وخياراتهما --metadataprofile ProfileName و --detachprofile أو خيار --metadataprofile أثناء الإنشاء عند استخدام أوامر vgcreate أو lvcreate. توفر أوامر الإبلاغ vgs و lvs خيارات الإخراج -o vg_profile و -o lv_profile لعرض ملف تعريف البيانات الوصفية المرتبط حاليًا بمجموعة وحدات تخزين أو وحدة تخزين منطقية.

مجموعة الخيارات المسموح بها لملفات تعريف الأوامر تكون متبادلة الاستبعاد عند مقارنتها بمجموعة الخيارات المسموح بها لملفات تعريف البيانات الوصفية. لا يمكن خلط الإعدادات التي تنتمي إلى أي من هاتين المجموعتين معًا، وستقوم أدوات LVM برفض مثل هذه الملفات التعريفية.

يوفر LVM نفسه بضعة ملفات تعريف تكوين معرفة مسبقًا. يُسمح للمستخدمين بإضافة المزيد من ملفات التعريف بقيم مختلفة إذا لزم الأمر. لهذا الغرض، يوجد command_profile_template.profile (لملفات تعريف الأوامر) و metadata_profile_template.profile (لملفات تعريف البيانات الوصفية) التي تحتوي على جميع الإعدادات القابلة للتخصيص بواسطة ملفات التعريف من النوع المحدد. يتم تشجيع المستخدمين على نسخ هذه الملفات التعريفية النموذجية وتعديلها حسب الحاجة. بدلاً من ذلك، يمكن استخدام lvmconfig --file <ProfileName.profile> --type profilable-command <section> أو lvmconfig --file <ProfileName.profile> --type profilable-metadata <section> لإنشاء تكوين بإعدادات قابلة للتخصيص من أي من النوعين لقسم معين وحفظه في ملف ProfileName.profile جديد (إذا لم يتم تحديد القسم، فسيتم الإبلاغ عن جميع الإعدادات القابلة للتخصيص).

يتم تخزين ملفات التعريف في دليل /etc/lvm/profile افتراضيًا. يمكن تغيير هذا الموقع باستخدام إعداد config/profile_dir. يتم تخزين كل تكوين ملف تعريف في ملف ProfileName.profile في دليل ملف التعريف. عند الإشارة إلى ملف التعريف، يتم حذف اللاحقة .profile.

ملف تعريف العلامة (tag config)

انظر وصف إعداد التكوين tags أدناه.

عند استخدام عدة طرق تكوين في نفس الوقت وعندما يبحث LVM عن قيمة لإعداد معين، فإنه يتنقل عبر تسلسل التكوين هذا من اليسار إلى اليمين:

تجاوز التكوين المباشر على سطر الأوامر → تكوين ملف تعريف الأوامر → تكوين ملف تعريف البيانات الوصفية → تكوين العلامة → lvmlocal.conf → lvm.conf

لا يوجد جزء من هذا التسلسل إلزامي. إذا لم يتم العثور على قيمة للإعداد في نهاية التسلسل، فسيتم استخدام قيمة افتراضية لذلك الإعداد. استخدم lvmconfig للتحقق من الإعدادات المستخدمة والقيم الافتراضية.

SYNTAX

يصف هذا القسم صيغة ملف التكوين.

المسافات البيضاء ليست ذات أهمية إلا إذا كانت ضمن علامات اقتباس. يوفر هذا خيارات واسعة لأنماط المسافات البادئة المقبولة. تبدأ التعليقات بالرمز # وتستمر حتى نهاية السطر. يتم التعامل معها كمسافات بيضاء.

إليك قواعد نحوية غير رسمية:

file = value*
يتكون ملف التكوين من مجموعة من القيم.
value = section | assignment
يمكن أن تكون القيمة إما قسمًا جديدًا، أو تعيينًا.
section = identifier '{' value* '}'
يجمع القسم القيم المرتبطة معًا. إذا تمت مواجهة نفس القسم عدة مرات، يتم دمج محتويات جميع النسخ معًا بترتيب ظهورها.
يتم تمييزه باسم ويحدد بأقواس معقوفة. مثال:
backup {
...
}
assignment = identifier '=' ( array | type )

يقوم التعيين بربط نوع بمعرف. إذا كان المعرف يحتوي على شرطات مائلة، فإنها تفسر كفواصل مسار. العبارة section/key = value تعادل section { key = value }. إذا تمت مواجهة عدة نسخ من نفس المفتاح، فقط القيمة الأخيرة هي المستخدمة (ويتم إصدار تحذير).
مثال: level = 7
array = '[' ( type ',')* type ']' | '[' ']'
تدعم المصفوفات غير المتجانسة.
يجب فصل العناصر بفواصل.
مصفوفة فارغة مقبولة.
سيتم تفسير مصفوفة بعنصر واحد بشكل صحيح إذا كانت أقواس المصفوفة مفقودة.
type =
integer|float|string integer = [0-9]*
float = [0-9]*'.'[0-9]*
string = '"' .* '"'
يجب أن تكون السلاسل التي تحتوي على مسافات محاطة بعلامات اقتباس مزدوجة، يمكن ترك الكلمات المفردة التي تبدأ بحرف غير مقتبسة.

SETTINGS

يقوم الأمر lvmconfig بطباعة إعدادات تكوين LVM بطرق مختلفة. راجع صفحة man lvmconfig(8).

أمر لطباعة قائمة بجميع إعدادات التكوين الممكنة، مع قيمها الافتراضية:
lvmconfig --type default

أمر لطباعة قائمة بجميع إعدادات التكوين الممكنة، مع قيمها الافتراضية، ووصف كامل لكل منها كتعليق:
lvmconfig --type default --withcomments

أمر لطباعة قائمة بجميع إعدادات التكوين الممكنة، مع قيمها الحالية (يتم عرض القيم المهيأة وغير الافتراضية):
lvmconfig --type current
