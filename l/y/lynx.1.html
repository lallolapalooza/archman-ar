\n
\n
\n

NAME

\n

lynx - a general purpose distributed information browser for the\n World Wide Web

\n
\n
\n

SYNOPSIS

\n

lynx [options] [optional paths or URLs]

\n

lynx [options] [path or URL] -get_data\n
\n data\n
\n --

\n

lynx [options] [path or URL] -post_data\n
\n data\n
\n --

\n

Use “lynx -help” to display a complete list of\n current options.

\n
\n
\n

DESCRIPTION

\n

Lynx is a fully-featured World Wide Web (WWW) client for\n users running cursor-addressable, character-cell display devices (e.g.,\n vt100 terminals, vt100 emulators running on Windows or any POSIX platform, or any other “curses-oriented” display). It will display\n hypertext markup language (HTML) documents containing links to files\n residing on the local system, as well as files residing on remote systems\n running Gopher, HTTP, FTP, WAIS, and NNTP servers.

\n

Lynx has been ported to many systems, including all\n variants of Unix, Windows (since Windows 95), DOS DJGPP and OS/2, as well as\n VMS and OS/390.

\n

Lynx can be used to access information on the World Wide\n Web, or to build information systems intended primarily for local access.\n For example, Lynx has been used to build several Campus Wide\n Information Systems (CWIS). In addition, Lynx can be used to build\n systems isolated within a single LAN.

\n
\n
\n

OPTIONS

\n

At start up, Lynx will load any local file or remote URL\n specified at the command line. For help with URLs, press\n “?” or “H” while running\n Lynx. Then follow the link titled, “Help on URLs.”

\n

If more than one local file or remote URL is listed on the command\n line, Lynx will open only the last interactively. All of the names\n (local files and remote URLs) are added to the G)oto history.

\n

Lynx uses only long option names. Option names can begin\n with double dash “--” as well, underscores and dashes can be\n intermixed in option names (in the reference below, options are shown with\n one dash “-” before them, and with underscores\n “_”).

\n

Lynx provides many command-line options. Some options\n require a value (string, number or keyword). These are noted in the\n reference below. The other options set boolean values in the program. There\n are three types of boolean options: set, unset and toggle. If no option\n value is given, these have the obvious meaning: set (to true), unset (to\n false), or toggle (between true/false). For any of these, an explicit value\n can be given in different forms to allow for operating system constraints, e.g.,

\n

\n
\n

\n
-center:off\n-center=off\n-center-
\n

Lynx recognizes “1”, “+”,\n “on” and “true” for true values, and\n “0”, “-”, “off” and\n “false” for false values. Other option-values are ignored.

\n

The default boolean, number and string option values that are\n compiled into Lynx are displayed in the help-message provided by\n lynx -help. Some of those may differ according to how Lynx was\n built; see the help message itself for these values. The -help option\n is processed in the third pass of options-processing, so any option which\n sets a value, as well as runtime configuration values are reflected in the\n help-message.

LYNX(1) Lynx – متصفح الويب النصي LYNX(1)

الاسم

lynx - متصفح معلومات موزع للأغراض العامة لشبكة الويب العالمية

الملخص

lynx [خيارات] [مسارات أو عناوين URL اختيارية]

lynx [خيارات] [مسار أو عنوان URL] -get_data
بيانات
--

lynx [خيارات] [مسار أو عنوان URL] -post_data
بيانات
--

استخدم "lynx -help" لعرض قائمة كاملة بالخيارات الحالية.

الوصف

Lynx هو عميل شبكة الويب العالمية (WWW) كامل الميزات للمستخدمين الذين يشغلون أجهزة عرض قابلة للتحكم بالمؤشر، تعتمد على خلايا النص (مثل، أجهزة طرفية vt100، محاكيات vt100 تعمل على Windows أو أي منصة POSIX، أو أي عرض آخر "موجه نحو curses"). سيعرض مستندات لغة ترميز النص التشعبي (HTML) التي تحتوي على روابط لملفات موجودة على النظام المحلي، بالإضافة إلى الملفات الموجودة على الأنظمة البعيدة التي تشغل خوادم Gopher و HTTP و FTP و WAIS و NNTP.

تم نقل Lynx إلى العديد من الأنظمة، بما في ذلك جميع متغيرات Unix و Windows (منذ Windows 95) و DOS DJGPP و OS/2، بالإضافة إلى VMS و OS/390.

يمكن استخدام Lynx للوصول إلى المعلومات على شبكة الويب العالمية، أو لبناء أنظمة معلومات مخصصة بشكل أساسي للوصول المحلي. على سبيل المثال، تم استخدام Lynx لبناء العديد من أنظمة المعلومات على مستوى الحرم الجامعي (CWIS). بالإضافة إلى ذلك، يمكن استخدام Lynx لبناء أنظمة معزولة داخل شبكة محلية واحدة.

خيارات

عند بدء التشغيل، سيقوم Lynx بتحميل أي ملف محلي أو عنوان URL عن بعد تم تحديده في سطر الأوامر. للحصول على المساعدة بشأن عناوين URL، اضغط على "?" أو "H" أثناء تشغيل Lynx. ثم اتبع الرابط بعنوان "Help on URLs" (المساعدة بشأن عناوين URL).

إذا تم إدراج أكثر من ملف محلي أو عنوان URL عن بعد واحد في سطر الأوامر، فسيقوم Lynx بفتح الأخير فقط بشكل تفاعلي. تتم إضافة جميع الأسماء (الملفات المحلية وعناوين URL عن بعد) إلى سجل G)oto.

يستخدم Lynx أسماء خيارات طويلة فقط. يمكن أن تبدأ أسماء الخيارات بشرطة مزدوجة "--" أيضًا، ويمكن خلط الشرطات السفلية والشرطات في أسماء الخيارات (في المرجع أدناه، يتم عرض الخيارات بشرطة واحدة "-" قبلها، و بشرطات سفلية "_" ).

يوفر Lynx العديد من خيارات سطر الأوامر. تتطلب بعض الخيارات قيمة (سلسلة نصية، رقم، أو كلمة مفتاحية). يتم ملاحظة هذه في المرجع أدناه. الخيارات الأخرى تقوم بتعيين قيم منطقية في البرنامج. هناك ثلاثة أنواع من الخيارات المنطقية: تعيين، إلغاء تعيين، تبديل. إذا لم يتم تقديم قيمة خيار، فإن هذه لها المعنى الواضح: تعيين (إلى صحيح)، إلغاء تعيين (إلى خاطئ)، أو تبديل (بين صحيح/خاطئ). لأي من هذه، يمكن تقديم قيمة صريحة بأشكال مختلفة للسماح بقيود نظام التشغيل، على سبيل المثال:


-center:off
-center=off
-center-

يتعرف Lynx على "1"، "+"، "on"، و "true" للقيم الصحيحة، و "0"، "-"، "off"، و "false" للقيم الخاطئة. يتم تجاهل القيم الأخرى للخيارات.

يتم عرض القيم الافتراضية للخيارات المنطقية والأرقام والسلاسل النصية المترجمة في Lynx في رسالة المساعدة التي يوفرها lynx -help. قد تختلف بعض هذه القيم وفقًا لكيفية بناء Lynx؛ راجع رسالة المساعدة نفسها لهذه القيم. يتم معالجة الخيار -help في الدورة الثالثة لمعالجة الخيارات، لذلك تنعكس أي خيار يقوم بتعيين قيمة، بالإضافة إلى قيم التكوين وقت التشغيل، في رسالة المساعدة.

ENVIRONMENT

ADDR_NO_REDIRECT
This variable, if set, causes Lynx to skip the check for local redirection. This is useful on systems that may not be able to perform local redirection reliably.
BOOKMARK_ICONS
If set to a valid path, Lynx will look for the icons for the bookmarks in that path. It is otherwise relative to the home directory.
CHARSET_DEFAULT
This variable, if set, specifies the default character set to be used for displaying documents. It overrides the compiled-in default character set.
COLOR_MAP
This variable, if set, specifies the color map to be used for displaying documents. It must be a file that contains the color map information.
DEF_COLOR_SCHEME
This variable, if set, specifies the default color scheme to be used for displaying documents. It must be one of the color schemes defined in the `color_scheme.h' file.
DUMB_TERMINAL
If set, causes Lynx to use a very basic terminal emulation, which may be useful on systems that do not properly report their terminal type.
GOPHER_HOST
If set, this variable specifies the default Gopher host to connect to. It is used when no host is specified on the command line.
GOPHER_PORT
If set, this variable specifies the default Gopher port to connect to. It is used when no port is specified on the command line.
HISTORY_FILE
If set, this variable specifies the file to be used for storing the history of visited URLs. If not set, the history is not saved.
HTTP_ACCEPT
This variable, if set, specifies the value of the Accept header sent to HTTP servers. It can be used to control the types of documents that the server will send.
HTTP_ACCEPT_ENCODING
This variable, if set, specifies the value of the Accept-Encoding header sent to HTTP servers. It can be used to control the content encodings that the server will send.
HTTP_CHARSET
This variable, if set, specifies the value of the Accept-Charset header sent to HTTP servers. It can be used to control the character sets that the server will send.
HTTP_LANGUAGE
This variable, if set, specifies the value of the Accept-Language header sent to HTTP servers. It can be used to control the languages that the server will send.
HTTP_PROXY
This variable, if set, specifies the proxy server to be used for HTTP connections. It overrides the compiled-in default proxy server.
HTTPS_PROXY
This variable, if set, specifies the proxy server to be used for HTTPS connections. It overrides the compiled-in default proxy server.
INLINE_IMAGES
If set to `0', causes Lynx to not display inline images. This is useful on slow connections or systems with limited graphics capabilities.
LD_LIBRARY_PATH
If set, this variable is used by Lynx to locate shared libraries. This is typically used on systems that do not have a standard library path.
LINK_BASE
If set, this variable specifies the base URL to be used for resolving relative links. This is useful when working with local copies of web pages.
LOCALE_PATH
This variable, if set, specifies the path to the locale data files. This is used by Lynx to determine the appropriate language and formatting for messages and dates.
LYNX_CFG
If set, this variable specifies the configuration file to be used by Lynx. If not set, Lynx will use the compiled-in default configuration file.
LYNX_COOKIE_JAR
If set, this variable specifies the file to be used for storing cookies. If not set, cookies are not saved.
LYNX_DUMP_FILE
If set, this variable specifies the file to be used for dumping the current document. This is useful for saving the content of a web page.
LYNX_EXTERNAL_JOB
If set, this variable specifies the external program to be used for handling external jobs, such as downloading files. The variable's value is the command to execute.
LYNX_HELPFILE
If set, this variable specifies the help file to be used by Lynx. If not set, Lynx will use the compiled-in default help file.
LYNX_KEYMAP
If set, this variable specifies the keymap file to be used by Lynx. This file defines the key bindings for various commands.
LYNX_LIBSSH2_SSH_PROG
If set, this variable specifies the path to the SSH client program that Lynx will use when accessing SSH URLs. This is typically used when the system's default SSH client is not in the PATH.
LYNX_LNP_MODE
This variable, if set, controls the behavior of the Lynx NotePad. A value of `0' disables the NotePad.
LYNX_LNP_PATH
This variable, if set, specifies the directory in which the Lynx NotePad files are stored. If not set, the files are stored in the user's home directory.
LYNX_LNP_SAVEDIR
If set, this variable specifies the directory in which to save NotePad entries. If not set, the entries are saved in the current directory.
LYNX_OPTIONSFILE
If set, this variable specifies the options file to be used by Lynx. This file contains user-configurable options that override the compiled-in defaults.
LYNX_PRINT_COMMAND
If set, this variable specifies the command to be used for printing documents. This command is executed when the user selects the "print" option from the menu.
LYNX_PRINT_DISPLAY_METHOD
This variable controls how printing is handled. If set to `0', printing is disabled. If set to `1', printing is done via the LYNX_PRINT_COMMAND environment variable. If set to `2', printing is done via a printer dialog.
LYNX_PRINT_FILENAME
If set, this variable specifies the default filename for printing. This is used when the user selects the "print" option from the menu.
LYNX_PRINT_HELPER
This variable specifies the external program that Lynx uses to print documents. If not set, Lynx uses the system's default printer.
LYNX_PRINT_OUT_FILE
If set, this variable specifies the output file for printing. This is used when printing to a file instead of a printer.
LYNX_PRINT_PAGE_NUMBERS
If set to `0', page numbers are not printed. If set to `1', page numbers are printed.
LYNX_PRINT_PAGE_SIZE
If set, this variable specifies the page size for printing. This is used when printing to a file or a printer.
LYNX_PRINT_TOP_MARGIN
If set, this variable specifies the top margin for printing. This is used when printing to a file or a printer.
LYNX_PRINT_TYPE
This variable controls the type of output for printing. If set to `ascii', the output is plain ASCII text. If set to `postscript', the output is PostScript.
LYNX_USERAGENT
This variable, if set, specifies the User-Agent string that Lynx sends to HTTP servers. This can be used to identify Lynx to web servers.
LYNX_VERSION_FILE
This variable specifies the file that contains the version information of Lynx. This file is created for use by an external program, as defined in a lynx.cfg PRINTER: definition statement. If the field does not exist for the document, the variable is set to a null string under UNIX, or “No URL” under VMS.
LYNX_TRACE
If set, causes Lynx to write a trace file as if the -trace option were supplied.
LYNX_TRACE_FILE
If set, overrides the compiled-in name of the trace file, which is either Lynx.trace or LY-TRACE.LOG (the latter on the DOS/Windows platforms). The trace file is in either case relative to the home directory.
LYNX_VERSION
This variable is always set by Lynx, and may be used by an external program to determine if it was invoked by Lynx.
See also the comments in the distribution's sample mailcap file, for notes on usage in such a file.
TERM
Normally, this variable is used by Lynx to determine the terminal type being used to invoke Lynx. If, however, it is unset at startup time (or has the value “unknown”), or if the -term command-line option is used (see OPTIONS section above), Lynx will set or modify its value to the user specified terminal type (for the Lynx execution environment). Note: If set/modified by Lynx, the values of the LINES and/or COLUMNS environment variables may also be changed.

Simulated CGI Support

If built with the cgi-links option enabled, Lynx allows access to a cgi script directly without the need for an http daemon.

When executing such “lynxcgi scripts” (if enabled), the following variables may be set for simulating a CGI environment:

CONTENT_LENGTH

CONTENT_TYPE

DOCUMENT_ROOT

HTTP_ACCEPT_CHARSET

HTTP_ACCEPT_LANGUAGE

HTTP_USER_AGENT

PATH_INFO

PATH_TRANSLATED

QUERY_STRING

REMOTE_ADDR

REMOTE_HOST

REQUEST_METHOD

SERVER_SOFTWARE

Other environment variables are not inherited by the script, unless they are provided via a LYNXCGI_ENVIRONMENT statement in the configuration file. See the lynx.cfg file, and the (draft) CGI 1.1 Specification http://Web.Golux.Com/coar/cgi/draft-coar-cgi-v11-00.txt for the definition and usage of these variables.

The CGI Specification, and other associated documentation, should be consulted for general information on CGI script programming.

Native Language Support

If configured and installed with Native Language Support, Lynx will display status and other messages in your local language. See the file ABOUT_NLS in the source distribution, or at your local GNU site, for more information about internationalization.

The following environment variables may be used to alter default settings:

LANG
This variable, if set, will override the default message language. It is an ISO 639 two-letter code identifying the language. Language codes are NOT the same as the country codes given in ISO 3166.
LANGUAGE
This variable, if set, will override the default message language. This is a GNU extension that has higher priority for setting the message catalog than LANG or LC_ALL.
LC_ALL
and
LC_MESSAGES
These variables, if set, specify the notion of native language formatting style. They are POSIXly correct.
LINGUAS
This variable, if set prior to configuration, limits the installed languages to specific values. It is a space-separated list of two-letter codes. Currently, it is hard-coded to a wish list.
NLSPATH
This variable, if set, is used as the path prefix for message catalogs.
