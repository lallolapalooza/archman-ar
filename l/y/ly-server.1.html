ly-server(1)

الحزمة: python-ly

التراخيص: GPL-2.0-or-later

LY-SERVER(1) python-ly LY-SERVER(1)

الاسم

ly-server - معالجة ملفات مصدر LilyPond عبر HTTP

الاستخدام:

ly-server [خيارات]

خادم HTTP لمعالجة كود إدخال LilyPond

خيارات الخادم

-v, --version
عرض رقم الإصدار والخروج
-h, --help
عرض نص المساعدة هذا والخروج
-p,--port PORT
المنفذ الذي يستمع إليه الخادم (الافتراضي 5432)
-t,--timeout TIME
إذا تم التعيين، سيتم إيقاف الخادم تلقائيًا بعد -t ثوانٍ من عدم النشاط، لم يتم تنفيذه بعد!

خيارات الأوامر

-e,--encoding ENC
ترميز الإدخال (الافتراضي UTF-8)
--output-encoding ENC
ترميز الإخراج (الافتراضي هو ترميز الإدخال)
-l,--language NAME
لغة أسماء النغمات الافتراضية (الافتراضي هو "nederlands")
-d <variable=value>
تعيين متغير (انظر أدناه)

تحدد خيارات الأوامر القيم الافتراضية لتنفيذ الأوامر التي يتم تشغيلها عبر طلبات HTTP. يمكن تجاوز هذه الخيارات بواسطة طلب HTTP الفردي.

طلبات HTTP

طلبات GET

سيتم تنفيذ بعض طلبات GET لاحقًا لاسترداد القيم أو تغيير بعض إعدادات الخادم بناءً على مسار URL.

طلبات POST

يقبل الخادم طلبات POST دون استخدام مسار URL (حالياً). كجسم للطلب، يتوقع سلسلة JSON واحدة تحتوي على العناصر التالية:

commands (إلزامي)
مصفوفة تحتوي على أمر واحد أو أكثر ليتم تنفيذها بشكل متسلسل. كل إدخال يحتوي على:
command (إلزامي):
اسم للأمر. يجب أن يكون واحدًا من قائمة الأوامر المتاحة أدناه.
args (اختياري):
إذا كان الأمر يتطلب وسيطات (مثل أمر transpose)، يتم توفيرها كسلسلة نصية واحدة.
variables (اختياري):
قاموس لتعيين المتغيرات. يجب أن تكون المفاتيح من القائمة أدناه، ويتم التحقق من أنواع القيم الصحيحة. إذا تم توفير متغير واحد أو أكثر، فسيتم تعيينها قبل تنفيذ الأمر. قد يتم تعديل المتغير مرة أخرى قبل تنفيذ الأمر التالي، ولكنه لا يتم إعادة تعيينه تلقائيًا. يؤدي توفير متغير بقيمة '' إلى إلغاء تعيين المتغير.
options (اختياري)
قاموس لتعيين الخيارات. يجب أن تكون المفاتيح من قائمة خيارات الأوامر المذكورة أعلاه، مع استخدام الاسم الطويل بدون الواصلات البادئة، على سبيل المثال { "encoding": "UTF-16" }. إذا تم توفير خيار هنا، فإنه يتجاوز الخيار الافتراضي المقدم في سطر الأوامر، ولكن فقط للأمر الحالي.
data (إلزامي)
سلسلة واحدة تحتوي على مستند LilyPond المدخل.

سيحاول الخادم إنشاء سلسلة من الأوامر من الطلب، وإذا كان هناك خطأ في أي شيء، فسيرسل رسالة "طلب سيء" برمز استجابة HTTP 400.

كائن الاستجابة

إذا تم تنفيذ الأوامر بنجاح، سيحتوي جسم الاستجابة على كائن JSON متسلسل يحتوي على العناصر التالية:

info
مصفوفة من الإدخالات مع نتيجة أوامر "info" (انظر أدناه). كل إدخال له حقل command وحقل info.
doc
كائن له حقلان:
content
سلسلة تحتوي على محتوى المستند مع تطبيق جميع أوامر "edit" بشكل متتالٍ. (إذا لم يتم تحديد أي أوامر تحرير، فإن هذا يحتوي على الإدخال الأصلي).
commands
مصفوفة بأسماء الأوامر التي تم تطبيقها.
exports
مصفوفة تحتوي على إدخالات لكل أمر "export" تم تطبيقه. كل إدخال له الحقول التالية:
doc
سلسلة تحتوي على محتوى المستند المحول/المصدر.
command
اسم الأمر الذي تم تطبيقه.

الأوامر

هناك ثلاثة أنواع من الأوامر التي يتم التعامل مع نتائجها بشكل مستقل:

  • أوامر "info" تسترد البيانات الوصفية من مستند الإدخال
  • أوامر "edit" تعدل المستند، أوامر التحرير اللاحقة تؤثر على التعديلات
  • أوامر "export" التي تحول الإدخال إلى تنسيق آخر. لا تتأثر الأوامر اللاحقة بنتيجة أوامر التصدير.

الأوامر المعلوماتية التي تعيد معلومات ولا تغير الملف:

mode
طباعة وضع (تخمين إذا لم يتم تقديمه) للمستند.
version
طباعة إصدار LilyPond، إذا تم تعيينه في المستند.
language
طباعة لغة أسماء النغمات، إذا تم تعيينها في المستند.

الأوامر التي تعدل الإدخال:

indent
إعادة تنسيق الملف.
reformat
إعادة تنسيق الملف.
translate <language>
ترجمة أسماء النغمات إلى اللغة.
transpose <from> <to>
نقل الملف بشكل مشابه لما يفعله LilyPond، يتم تقديم النغمات بلغة 'nederlands'.
abs2rel
تحويل الموسيقى المطلقة إلى نسبية.
rel2abs
تحويل الموسيقى النسبية إلى مطلقة.

الأوامر التي تحول الإدخال إلى تنسيق آخر:

musicxml
التحويل إلى MusicXML (قيد التطوير، بعيد عن الاكتمال).
