ltx2crossrefxml(1)

الحزمة: texlive-doc

التراخيص: GPL

ltx2crossrefxml(1) CROSSREFWARE LATEX ltx2crossrefxml(1)

الاسم

ltx2crossrefxml.pl - إنشاء ملفات XML لتقديمها إلى crossref.org

الملخص

ltx2crossrefxml [-c ملف_التكوين] [-o ملف_الإخراج] [-input-is-xml]
ملف_لاتك1 ملف_لاتك2 ...

الخيارات

-c ملف_التكوين
ملف التكوين. إذا كان هذا الملف غائبًا، يتم استخدام القيم الافتراضية. انظر أدناه لمعرفة تنسيقه.
-o ملف_الإخراج
ملف الإخراج. إذا لم يتم استخدام هذا الخيار، يتم إخراج XML إلى الإخراج القياسي.
-rpi-is-xml
لا تقم بتحويل سلاسل المؤلف والعنوان المدخلة، افترض أنها XML صالحة.

يتم دعم الخيارات المعتادة "--help" و "--version" أيضًا. يمكن أن تبدأ الخيارات بـ "-" أو "--"، ويتم ترتيبها بشكل عشوائي.

الوصف

لكل ملف_لاتك معين، يقرأ هذا البرنامج النصي ملفات ".rpi" (إذا كانت موجودة) و (إذا كانت موجودة) ملفات ".bbl" ويخرج XML مطابقًا يمكن تحميله إلى Crossref (https://crossref.org). يتم تجاهل أي امتداد لـ ملف_لاتك، ولا يتم قراءة ملف_لاتك نفسه (ولا يلزم وجوده حتى).

يحدد كل ملف ".rpi" البيانات الوصفية لمقالة واحدة لتقديمها إلى Crossref (عنصر "journal_article" في مخططهم)؛ مثال على ذلك أدناه. يتم إخراج هذه الملفات بواسطة الحزمة "resphilosophica" (https://ctan.org/pkg/resphilosophica) وإجراءات النشر TUGboat (https://tug.org/TUGboat/repository.html)، ولكن (كالعادة) يمكن إنشاؤها يدويًا أو بأي طريقة أخرى تنفذها.

تُستخدم أي ملفات ".bbl" موجودة لمعلومات الاقتباس في XML الناتج. انظر قسم الاقتباسات أدناه.

ما لم يتم تحديد "--rpi-is-xml"، لجميع النصوص (المؤلفون، العنوان، الاقتباسات)، يتم استبدال تسلسلات تحكم TeX القياسية بنص عادي أو UTF-8 أو إزالتها، حسب الاقتضاء. يتم استخدام الروتين "LaTeX::ToUnicode::convert" لهذا الغرض (https://ctan.org/pkg/bibtexperllibs). من شبه المؤكد أن تسلسلات تحكم TeX الصعبة لن تتم معالجتها بشكل صحيح.

إذا تم تقديم "--rpi-is-xml"، يتم إخراج سلاسل المؤلف والعنوان من ملفات rpi كما هي، مع افتراض أنها XML صالحة؛ لا يتم إجراء أي فحص.

يتم دائمًا تحويل نص الاقتباس من ملفات ".bbl" من LaTeX إلى نص عادي.

هذا البرنامج النصي يكتب ملف XML فقط. الأمر متروك لك للقيام بالتحميل إلى Crossref؛ على سبيل المثال، يمكنك استخدام أداة Java الخاصة بهم "crossref-upload-tool.jar" (https://www.crossref.org/education/member-setup/direct-deposit-xml/https-post).

لتعريف مخطط Crossref الذي يتم إخراجه حاليًا بواسطة هذا البرنامج النصي، راجع https://data.crossref.org/reports/help/schema_doc/5.3.1/index.html مع روابط ومعلومات إضافية في https://www.crossref.org/documentation/schema-library/metadata-deposit-schema-5-3-1/.

تنسيق ملف التكوين

يتم قراءة ملف التكوين ككود Perl. وبالتالي، يتم تجاهل أسطر التعليقات التي تبدأ بـ "#" والأسطر الفارغة. الأسطر الأخرى هي عادةً تعيينات بالشكل (المسافات اختيارية):

$variable = value ;

عادةً ما تكون القيمة عبارة عن "سلسلة" محاطة بعلامات اقتباس مزدوجة أو مفردة ASCII، وفقًا لصيغة Perl. الفكرة هي تحديد القيم الخاصة بالمستخدم والخاصة بالمجلة المطلوبة لتحميل Crossref. المتغيرات المستخدمة هي:

$depositorName = "اسم المودع";
$depositorEmail = 'moder@example.org';
$registrant = 'المسجل';  # اسم المنظمة
$fullTitle = "العنوان الكامل";   # اسم المجلة
$issn = "1234-5678";         # مطلوب
$abbrevTitle = "عنوان مختصر."; # اختياري
$coden = "CODEN";            # اختياري

لكل تشغيل، يُفترض أن تنتمي جميع بيانات ".rpi" المقروءة إلى المجلة المحددة في ملف التكوين. بشكل أكثر تحديدًا، يتم كتابة بيانات التكوين كعنصر "journal_metadata"، مع "full_title" و "issn" وما إلى ذلك، ثم يتم كتابة كل ".rpi" كـ "journal_issue" بالإضافة إلى عناصر "journal_article".

يمكن لملف التكوين أيضًا تعريف دالة Perl واحدة: "LaTeX_ToUnicode_convert_hook". إذا تم تعريفها، يتم استدعاؤها في بداية إجراء تحويل نص LaTeX إلى Unicode، والذي يتم باستخدام الوحدة LaTeX::ToUnicode، من الحزمة "bibtexperllibs" (https://ctan.org/pkg/bibtexperllibs). يجب أن تقبل الدالة سلسلة واحدة (نص LaTeX)، وتعيد سلسلة واحدة (ربما السلسلة المحولة). ثم يتم تطبيق التحويلات القياسية على السلسلة المعادة، لذا تحتاج الدالة المكونة فقط إلى معالجة الحالات الخاصة، مثل تسلسلات التحكم الخاصة بالمجلة المعنية.

تنسيق ملف RPI

هذا هو (الجزء ذو الصلة من) ملف ".rpi" المقابل للمثال "rpsample.tex" في حزمة "resphilosophica" (https://ctan.org/pkg/resphilosophica):

%authors=Boris Veytsman\and A. U. Th{\o }r\and C. O. R\"espondent
%title=A Sample Paper:\\ \emph  {A Template}
%year=2012
%volume=90
%issue=1--2
%startpage=1
%endpage=1
%doi=10.11612/resphil.A31245
%paperUrl=http://borisv.lk.net/paper12
%publicationType=full_text

يتم تجاهل الأسطر الأخرى، وبعضها لا يبدأ بـ % (ولا تظهر). لمزيد من التفاصيل حول المعالجة، انظر الكود.

القيمة %paperUrl هي ما سيتم ربطه بالـ %doi المحدد (يتم إخراجه كعنصر "resource"). توصي Crossref بشدة بأن يكون عنوان URL لصفحة هبوط تسمى، وليس مباشرة لملف pdf (https://www.crossref.org/education/member-setup/creating-a-landing-page/). حالة خاصة: إذا لم يتم تحديد عنوان URL، وكانت المجلة Res Philosophica، فسيتم إرجاع عنوان URL مخصص للبحث باستخدام pdcnet.org. يجب على أي مجلة أخرى تحديد هذا دائمًا.

يتم تقسيم حقل %authors عند "\and" (مع تجاهل المسافات قبلها وبعدها)، ويتم إخراجه كعنصر "contributors"، باستخدام "sequence="first"" للمدرج الأول، و "sequence="additional"" للباقي. يتم تحليل المؤلفين باستخدام "BibTeX::Parser::Author" (https://ctan.org/pkg/bibtexperllibs).

إذا لم يتم تحديد %publicationType، فسيتم تعيين قيمته الافتراضية إلى "full_text"، نظرًا لأنه كان هذا هو الحال تاريخيًا؛ يمكن أيضًا تقديم "full_text" بشكل صريح. القيم الأخرى المسموح بها بواسطة مخطط Crossref هي "abstract_only" و "bibliographic_record". أخيرًا، إذا كانت القيمة "omit"، فإن العنصر "publication_type".

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
