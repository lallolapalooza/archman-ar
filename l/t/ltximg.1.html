ltximg(1) دليل الأوامر العامة ltximg(1)

الاسم

ltximg - بيئات LaTeX إلى ملفات صور وملفات مستقلة

الملخص

ltximg [<خيارات>] [--] <اسم_الملف>.<tex|ltx>

الوصف

ltximg يقوم بأتمتة عملية استخراج وتحويل البيئات من ملف LaTeX إلى تنسيقات صور وملفات مستقلة باستخدام ghostscript و poppler-utils. يقوم بإنشاء ملف واحد يحتوي فقط على البيئات المستخرجة وملف آخر يحتوي على جميع البيئات المستخرجة المحولة إلى "\includegraphics".

افتراضيًا، البيئات المستخرجة هي:

preview pspicture tikzpicture pgfpicture psgraph postscript PSTexample

الخيارات

الخيارات التي تقبل قيمة تتطلب إما مسافة فارغة أو "=" بين الخيار والقيمة. يمكن تجميع خيارات مختصرة متعددة، وإذا كان الخيار الأخير يأخذ قائمة مفصولة بفواصل، فأنت بحاجة إلى "--" في النهاية. المسارات النسبية أو المطلقة للمجلدات والملفات غير مدعومة.

إذا تم استخدامه بدون [<خيارات>]، يتم تحويل البيئات المستخرجة إلى تنسيق صور pdf وحفظها في دليل "./images" باستخدام "pdflatex" وحزمة preview للمعالجة.

خيارات البرنامج النصي العامة:

-h, --help
عرض مساعدة سطر الأوامر والخروج.
-v, --version
عرض الإصدار الحالي والخروج.
-V, --verbose
طباعة معلومات مفصلة.
-l, --log
كتابة ملف ".log" بمعلومات تصحيح الأخطاء.
-t, --tif
إنشاء ملفات ".tif" باستخدام ghostscript.
-b, --bmp
إنشاء ملفات ".bmp" باستخدام ghostscript.
-j, --jpg
إنشاء ملفات ".jpg" باستخدام ghostscript.
-p, --png
إنشاء ملفات ".png" باستخدام ghostscript.
-e, --eps
إنشاء ملفات ".eps" باستخدام pdftops.
-s, --svg
إنشاء ملفات ".svg" باستخدام pdftocairo.
-P, --ppm
إنشاء ملفات ".ppm" باستخدام pdftoppm.
-g, --gray
تدرج رمادي للصور باستخدام ghostscript.
-f, --force
التقاط "\psset" و "\tikzset" للاستخراج.
-n, --noprew
إنشاء ملفات صور بدون حزمة preview.
-r عدد_صحيح, --runs=عدد_صحيح
تعيين عدد المرات التي سيتم فيها تشغيل المترجم على ملف الإدخال لاستخراج البيئات (الافتراضي: 1).
-d عدد_صحيح, --dpi=عدد_صحيح
دقة النقاط في البوصة للصور (الافتراضي: 150).
-m عدد_صحيح, --margins=عدد_صحيح
تعيين الهوامش بالـ bp لـ pdfcrop (الافتراضي: 0).
-o اسم_الملف, --output=اسم_الملف
إنشاء ملف إخراج.
--imgdir=اسم_المجلد
تعيين اسم المجلد لحفظ الصور والملفات (الافتراضي: images).
--prefix=سلسلة
تعيين بادئة لإلحاقها بكل ملف تم إنشاؤه (الافتراضي: fig).
--myverb=اسم_الماكرو
إضافة "\macroname" للبحث المضمن بالنص الحرفي (الافتراضي: myverb).
--clean=doc|pst|tkz|all|off
يزيل نص كتلة معين في ملف الإخراج (الافتراضي: doc).
--zip
ضغط الملفات التي تم إنشاؤها بتنسيق ".zip".
--tar
ضغط الملفات التي تم إنشاؤها بتنسيق ".tar.gz".
--srcenv
إنشاء ملفات تحتوي فقط على كود البيئات.
--subenv
إنشاء ملفات مستقلة للبيئات.
--shell
تمكين "\write18{SHELL COMMAND}".
--latex
استخدام "latex>dvips>ps2pdf" لـ مدخلات المترجم و "pdflatex" لـ مخرجات المترجم.
--dvips
استخدام "latex>dvips>ps2pdf" لـ مدخلات المترجم و "latex>dvips>ps2pdf" لـ مخرجات المترجم.
--dvilua
استخدام "dvilualatex>dvips>ps2pdf" لـ مدخلات المترجم و "lualatex" لـ مخرجات المترجم.
--dvipdf
استخدام "latex>dvipdfmx" لـ مدخلات المترجم و "latex>dvipdfmx" لـ مخرجات المترجم.
--xetex
استخدام "xelatex" لـ مدخلات و مخرجات المترجم.
--luatex
استخدام "lualatex" لـ مدخلات و مخرجات المترجم.
--arara
استخدام "arara" لـ مدخلات و مخرجات المترجم.
--latexmk
استخدام "latexmk" لملف مخرجات المترجم.
--norun
تشغيل البرنامج النصي، ولكن لا يتم إنشاء ملفات الصور.
--nopdf
لا تقم بإنشاء ملفات صور ".pdf".
--nocrop
لا تقم بتشغيل pdfcrop.
--extrenv=env1,env2,...
إضافة بيئات جديدة للاستخراج.
--skipenv=env1,env2,...
تخطي بعض البيئات الافتراضية للاستخراج.
--verbenv=env1,env2,...
إضافة بيئات جديدة بالنص الحرفي.
--writenv=env1,env2,...
إضافة بيئات كتابة جديدة بالنص الحرفي.
--deltenv=env1,env2,...
حذف البيئات في ملف الإخراج.

مثال

ltximg --latex -e -p --subenv -o test-out.ltx test-in.ltx

قم بإنشاء دليل "./images" (إذا لم يكن موجودًا) مع تحويل جميع البيئات المستخرجة إلى ".pdf"،

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

EXAMPLE

The following example latex code:

test-in.ltx
\documentclass[preview]{standalone}
\usepackage{ltximg}
\ltximginput{example.eps}
\ltximginput{example.png}
\begin{document}
Hello world!
\end{document}

will produce the files ".eps", ".png" and standalone files, a file test-in-fig-all.ltx with all extracted environments and the file test-out.ltx with all environments converted to "\includegraphics" using "latex>dvips>ps2pdf" and preview package for test-in.ltx and "pdflatex" for test-out.ltx.
