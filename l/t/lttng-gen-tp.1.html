lttng-gen-tp(1)

الحزمة: lttng-ust

التراخيص: LGPL2.1, GPL2, MIT

LTTNG-GEN-TP(1) دليل LTTng LTTNG-GEN-TP(1)

الاسم

lttng-gen-tp - إنشاء كود مزود نقاط التتبع LTTng-UST

الملخص

lttng-gen-tp [--verbose] [--output=FILE.c]
             [--output=FILE.h] [--output=FILE.o] TEMPLATE

الوصف

تقوم الأداة lttng-gen-tp بتبسيط إنشاء ملفات مزود نقاط التتبع LTTng-UST. تأخذ ملف قالب بسيط، TEMPLATE، وتقوم بإنشاء كود C اللازم لاستخدام نقاط التتبع المحددة في تطبيقك. انظر قسم صيغة ملف القالب أدناه لمزيد من المعلومات حول صيغة TEMPLATE.

حالياً، يمكن لـ lttng-gen-tp إنشاء ملفات .h و .c و .o المرتبطة بمزود نقاط التتبع الخاص بك. يمكن تضمين الملف .h الذي تم إنشاؤه مباشرة في تطبيقك. يمكنك السماح لـ lttng-gen-tp بإنشاء الملف .o أو تجميع الملف .c بنفسك. انظر lttng-ust(3) لمزيد من المعلومات حول تجميع مزودي نقاط التتبع LTTng-UST.

بشكل افتراضي، تقوم lttng-gen-tp بإنشاء ملفات .h و .c و .o، مع كون اسم الملف الأساسي هو اسم الملف الأساسي لـ TEMPLATE. يمكنك إنشاء نوع ملف واحد أو أكثر محدد باستخدام الخيار --output، مع تكراره حسب الحاجة.

صيغة ملف القالب

ملف القالب، الذي عادة ما يكون له امتداد .tp، يحتوي على قائمة بتعريفات LTTNG_UST_TRACEPOINT_EVENT() وإدخالات تعريف اختيارية أخرى، مثل LTTNG_UST_TRACEPOINT_LOGLEVEL(). انظر lttng-ust(3) للحصول على القائمة الكاملة للتعريفات المتاحة.

تتم كتابة تعريفات LTTNG_UST_TRACEPOINT_EVENT() كما كنت تكتبها في ملف رأس مزود قالب LTTng-UST. التعليقات C مدعومة (/* */ و //)، بالإضافة إلى الأسطر التي تبدأ بـ #.


ملاحظة

يجب أن يكون اسم المزود (الحجة الأولى لـ LTTNG_UST_TRACEPOINT_EVENT()) هو نفسه في جميع وحدات الماكرو LTTNG_UST_TRACEPOINT_EVENT() في TEMPLATE.

إليك مثال:

LTTNG_UST_TRACEPOINT_EVENT(
    // اسم مزود نقطة التتبع
    my_provider,
    // اسم نقطة التتبع/الحدث
    my_event,
    // وسائط نقطة التتبع (إدخال)
    LTTNG_UST_TP_ARGS(char *, text),
    // حقول نقطة التتبع/الحدث (إخراج)
    LTTNG_UST_TP_FIELDS(
        lttng_ust_field_string(message, text)
    )
)

الخيارات

-o, --output=FILE

لا تنشئ ملفات افتراضية: أنشئ FILE.

امتداد FILE يحدد ما يتم إنشاؤه، من بين .h و .c و .o. يمكن استخدام هذا الخيار أكثر من مرة لإنشاء أنواع ملفات مختلفة.

-v, --verbose

زيادة تفصيل المخرجات.

-h, --help

عرض مساعدة الأمر.

متغيرات البيئة

CC

مترجم C للاستخدام. الافتراضي: cc، ثم gcc إذا لم يتم العثور على cc. هذا الخيار ذو صلة فقط عند إنشاء الملف .o.

CFLAGS

الأعلام والخيارات التي يتم تمريرها مباشرة إلى المترجم ($CC). هذا الخيار ذو صلة فقط عند إنشاء الملف .o.
