lttng_ust_tracelog(3)

الحزمة: lttng-ust

التراخيص: LGPL2.1, GPL2, MIT

NAME

lttng_ust_tracelog, lttng_ust_vtracelog — emit trace messages with LTTng-UST

SYNOPSIS

#include <lttng/tracef.h>

void lttng_ust_tracelog(const char *format, ...);
void lttng_ust_vtracelog(const char *format, va_list ap);

DESCRIPTION

The lttng_ust_tracelog and lttng_ust_vtracelog macros emit a trace message to the current context. The format of the message is controlled by the format string, which can contain any combination of literal characters and format specifiers for various C data types.

The available format specifiers are: printf(3)-style.

The lttng_ust_tracelog macro takes a variable number of arguments, similar to the standard C library function printf(3). It is variadic.

The lttng_ust_vtracelog macro takes a va_list argument, and is thus suitable for implementing functions that are themselves variadic.

The trace message is written to the LTTng context. If no tracing session is active, these macros do nothing.

EXAMPLE

The following code snippet shows how to use these macros:

#include <lttng/tracef.h>

void my_function(int value, const char *name)
{
    lttng_ust_tracelog("Entering my_function with value: %d and name: %s",
                       value, name);

    // ... function logic ...

    lttng_ust_tracelog("Exiting my_function");
}

void my_variadic_function(const char *fmt, ...)
{
    va_list ap;

    va_start(ap, fmt);
    lttng_ust_vtracelog(fmt, ap);
    va_end(ap);
}

LIMITATIONS

The lttng_ust_tracelog() does not have a STAP_PROBEV() call, because STAP_PROBEV() does not support va_list. If you need it, you should emit this call yourself.

See lttng-ust(3) to learn more about custom tracepoint providers.
