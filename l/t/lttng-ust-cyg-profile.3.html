الحزمة: lttng-ust

التراخيص: LGPL2.1, GPL2, MIT

LTTNG-UST-CYG-PRO(3) دليل LTTng LTTNG-UST-CYG-PRO(3)

الاسم

lttng-ust-cyg-profile - تتبع الدوال (مساعد LTTng-UST)

الملخص

قم بتجميع تطبيقك بخيار المترجم -finstrument-functions.

قم بتشغيل تطبيقك عن طريق التحميل المسبق liblttng-ust-cyg-profile-fast.so لتتبع الدوال السريع:

$ LD_PRELOAD=liblttng-ust-cyg-profile-fast.so my-app

قم بتشغيل تطبيقك عن طريق التحميل المسبق liblttng-ust-cyg-profile.so لتتبع الدوال الأبطأ والأكثر تفصيلاً:

$ LD_PRELOAD=liblttng-ust-cyg-profile.so my-app

الوصف

عندما يتم تحميل مكتبة liblttng-ust-cyg-profile.so أو liblttng-ust-cyg-profile-fast.so مسبقًا قبل بدء تشغيل تطبيق معين، يتم تتبع جميع نقاط دخول وخروج الدوال بواسطة LTTng-UST (انظر lttng-ust(3))، بشرط أن يكون التطبيق المذكور قد تم تجميعه باستخدام خيار المترجم -finstrument-functions.

انظر lttng(1) لمعرفة المزيد حول كيفية التحكم في جلسات تتبع LTTng.

يأتي تتبع الدوال باستخدام LTTng-UST في نكهتين، كل منهما يوفر مقايضة مختلفة بين الأداء والمتانة:

liblttng-ust-cyg-profile-fast.so

هذا هو إصدار خفيف الوزن يجب استخدامه فقط حيث يمكن ضمان تسجيل تيار الأحداث بالكامل دون أي أحداث مفقودة. يتم استبعاد أي نوع من المعلومات المكررة.

عند كل دخول للدالة، يتم تسجيل عنوان الدالة المسماة في حدث LTTng-UST. يتم تسجيل مخارج الدوال كحدث LTTng-UST فارغ آخر.

انظر قسم تتبع الدوال السريع أدناه للحصول على القائمة الكاملة للأحداث المنبعثة وحقولها.

liblttng-ust-cyg-profile.so

هذا إصدار أكثر متانة يعمل أيضًا لحالات الاستخدام التي قد يتم فيها تجاهل الأحداث، أو عدم تسجيلها منذ بدء تشغيل التطبيق. في هذه الحالات، يحتاج محلل التتبع إلى معلومات إضافية لإعادة بناء تدفق البرنامج.

عند كل دخول وخروج للدالة، يتم تسجيل عنوان الدالة المسماة وعنوان موقع الاستدعاء في حدث LTTng-UST.

انظر قسم تتبع الدوال المطول أدناه للحصول على القائمة الكاملة للأحداث المنبعثة وحقولها.

الاستخدام

لاستخدام تتبع الدوال LTTng-UST، تحتاج إلى التأكد من أن مصادر تطبيقك مجمعة باستخدام خيار المترجم -finstrument-functions.

قد يكون من الضروري الحد من عدد ملفات المصدر التي يتم استخدام هذا الخيار فيها لمنع توليد كمية مفرطة من بيانات التتبع وقت التشغيل. عادةً، هناك علامات مترجم إضافية تسمح لك بتحديد اختيار أكثر دقة لتأثير الدوال.

لكل دالة مؤثرة، سيحتوي الملف التنفيذي على استدعاءات لخطافات الدوال المراقبة (بعد دخول الدالة، تسمى __cyg_profile_func_enter()، وقبل خروج الدالة مباشرة، تسمى __cyg_profile_func_exit()).

عن طريق التحميل المسبق (باستخدام متغير البيئة LD_PRELOAD) لإحدى المكتبات المشتركة المقدمة، يتم تعريف خطافات المراقبة هذه لإصدار أحداث LTTng (كما هو موضح أدناه).


ملاحظة

قد يؤدي استخدام هذه الميزة إلى توليد كمية هائلة من بيانات التتبع بواسطة التطبيق المؤثر. يتأثر وقت تشغيل التطبيق أيضًا بشكل كبير. كن حذرًا على الأنظمة ذات الموارد المحدودة.

تتبع الدوال السريع

تتوفر أحداث LTTng-UST التالية عند استخدام liblttng-ust-cyg-profile-fast.so. تم ضبط مستوى تسجيلها على LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_FUNCTION.

lttng_ust_cyg_profile_fast:func_entry

يتم إصدارها عند دخول دالة تطبيق، أو بشكل أكثر تحديدًا، عند استدعاء __cyg_profile_func_enter().

الحقول:

اسم الحقل الوصف
func_addr عنوان الدالة.

lttng_ust_cyg_profile_fast:func_exit

يتم إصدارها عند خروج دالة تطبيق، أو بشكل أكثر تحديدًا، عند استدعاء __cyg_profile_func_exit().

لا يحتوي هذا الحدث على حقول. نظرًا لأنه يجب استخدام مكتبة liblttng-ust-cyg-profile-fast.so فقط عندما يمكن ضمان تسجيل تيار الأحداث بالكامل دون أي أحداث مفقودة، يمكن استخدام نهج قائم على المكدس لكل خيط على جانب محلل التتبع لمطابقة أحداث دخول وخروج الدالة.

تتبع الدوال المطول

تتوفر أحداث LTTng-UST التالية عند استخدام liblttng-ust-cyg-profile.so. تم ضبط مستوى تسجيلها على LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_FUNCTION.

lttng_ust_cyg_profile:func_entry

يتم إصدارها عند دخول دالة تطبيق، أو بشكل أكثر تحديدًا، عند استدعاء __cyg_profile_func_enter().

الحقول:

اسم الحقل الوصف
func_addr عنوان الدالة.
call_site العنوان الذي تم استدعاء هذه الدالة منه.

lttng_ust_cyg_profile:func_exit

يتم إصدارها عند خروج دالة تطبيق، أو بشكل أكثر تحديدًا، عند استدعاء __cyg_profile_func_exit().

الحقول:

اسم الحقل الوصف
func_addr عنوان الدالة.
call_site العنوان الذي تم استدعاء هذه الدالة منه.

NAME

lttng-ust-cyg-profile - LTTng-UST user space dynamic tracing

SYNOPSIS

This is a Perl module that provides bindings to the LTTng-UST (Linux Trace Toolkit Next - User Space Tracing) library. It allows you to instrument your Perl code with tracepoints to record events and measure performance. The module utilizes the LTTng-UST C library for the actual tracing functionality.

The specific functions and usage will depend on the LTTng-UST C library's capabilities and how this Perl module exposes them. You would typically use this module to:

  • Define and enable tracepoints in your Perl scripts.
  • Associate data with tracepoints (context).
  • Control trace sessions (start, stop, etc.) via Perl.

Note: This is a high-level description based on the module name. Refer to the module's specific documentation for exact API details.

DESCRIPTION

The lttng-ust-cyg-profile Perl module acts as a bridge between Perl scripts and the LTTng-UST dynamic tracing infrastructure. It allows Perl developers to leverage the power of LTTng for understanding the runtime behavior of their applications, diagnosing issues, and optimizing performance.

By enabling developers to easily add tracepoints within their Perl code, lttng-ust-cyg-profile facilitates detailed event logging and profiling. This can be invaluable for debugging complex applications, identifying bottlenecks, and gaining insights into application flow.

The underlying LTTng-UST library is a powerful tracing framework for Linux, and this module aims to make its capabilities accessible from the Perl environment. This can be particularly useful for system utilities or applications written in a mix of languages.
