lttng_ust_vtracelog(3)

الحزمة: lttng-ust

التراخيص: LGPL2.1, GPL2, MIT

LTTNG_UST_TRACELOG(3) دليل LTTng LTTNG_UST_TRACELOG(3)

الاسم

lttng_ust_tracelog, lttng_ust_vtracelog - واجهة LTTng-UST شبيهة بـ printf(3) مع مستوى تسجيل

ملخص

#include <lttng/tracelog.h>
#define lttng_ust_tracelog(level, fmt, ...)
#define lttng_ust_vtracelog(level, fmt, ap)

الربط مع:

•-llttng-ust
•إذا قمت بتعريف _LGPL_SOURCE قبل تضمين <lttng/tracelog.h> (مباشرة أو بشكل غير مباشر): -llttng-ust-common

الوصف

تسمح واجهة LTTng-UST lttng_ust_tracelog() و lttng_ust_vtracelog() لك بتتبع تطبيقك بمساعدة وحدات ماكرو بسيطة شبيهة بـ printf(3) و vprintf(3)، مع معلمة إضافية لمستوى التسجيل المطلوب.

يتم تمرير المعلمة fmt مباشرة كالمعلمة fmt الخاصة بـ vasprintf(3)، بالإضافة إلى:

بالنسبة لـ lttng_ust_tracelog()

المعلمات الاختيارية التي تلي fmt.

بالنسبة لـ lttng_ust_vtracelog()

المعلمة ap كالمعلمة ap الخاصة بـ vasprintf(3) (نوع va_list).

الغرض من lttng_ust_tracelog() و lttng_ust_vtracelog() هو تسهيل الانتقال من التسجيل إلى التتبع.

القيم المتاحة للمعلمة level هي:

LTTNG_UST_TRACEPOINT_LOGLEVEL_EMERG

النظام غير قابل للاستخدام.

LTTNG_UST_TRACEPOINT_LOGLEVEL_ALERT

يجب اتخاذ إجراء على الفور.

LTTNG_UST_TRACEPOINT_LOGLEVEL_CRIT

الشروط الحرجة.

LTTNG_UST_TRACEPOINT_LOGLEVEL_ERR

حالات الخطأ.

LTTNG_UST_TRACEPOINT_LOGLEVEL_WARNING

شروط التحذير.

LTTNG_UST_TRACEPOINT_LOGLEVEL_NOTICE

شرط طبيعي، ولكنه مهم.

LTTNG_UST_TRACEPOINT_LOGLEVEL_INFO

رسالة معلوماتية.

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_SYSTEM

معلومات تصحيح الأخطاء ذات نطاق على مستوى النظام (مجموعة من البرامج).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_PROGRAM

معلومات تصحيح الأخطاء ذات نطاق على مستوى البرنامج (مجموعة من العمليات).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_PROCESS

معلومات تصحيح الأخطاء ذات نطاق على مستوى العملية (مجموعة من الوحدات).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_MODULE

معلومات تصحيح الأخطاء ذات نطاق على مستوى الوحدة (ملف تنفيذي/مكتبة) (مجموعة من الوحدات).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_UNIT

معلومات تصحيح الأخطاء ذات نطاق وحدة التجميع (مجموعة من الدوال).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_FUNCTION

معلومات تصحيح الأخطاء ذات نطاق على مستوى الدالة.

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG_LINE

معلومات تصحيح الأخطاء ذات نطاق على مستوى السطر (مستوى التسجيل الافتراضي).

LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG

رسالة على مستوى تصحيح الأخطاء.

لاستخدام lttng_ust_tracelog() أو lttng_ust_vtracelog()، قم بتضمين <lttng/tracelog.h> حيثما تحتاجه، واربط تطبيقك بـ liblttng-ust و liblttng-ust-common. انظر قسم مثال أدناه للحصول على مثال استخدام كامل.

بمجرد أن يكون تطبيقك مجهزًا بـ lttng_ust_tracelog() و/أو استدعاءات lttng_ust_vtracelog() وجاهزًا للتشغيل، استخدم lttng-enable-event(1) لتمكين الحدث lttng_ust_tracelog:*. يمكنك عزل مستويات تسجيل محددة باستخدام خيارات --loglevel و --loglevel-only لهذا الأمر.

تحتوي أحداث lttng_ust_tracelog() و lttng_ust_vtracelog() على الحقول التالية:

اسم الحقل الوصف
line السطر في الملف المصدر حيث تم استدعاء lttng_ust_tracelog().
file الملف المصدر الذي تم استدعاء lttng_ust_tracelog() منه.
func اسم الدالة التي تم استدعاء lttng_ust_tracelog() منها.
msg مخرجات السلسلة المهيأة.

إذا لم تكن بحاجة إلى ربط مستوى تسجيل محدد بـ lttng_ust_tracelog()/lttng_ust_vtracelog()، استخدم lttng_ust_tracef(3) بدلاً من ذلك.

انظر أيضًا قسم القيود أدناه للحصول على قيود مهمة يجب مراعاتها عند استخدام lttng_ust_tracelog() أو lttng_ust_vtracelog().

مثال

هذا مثال على استخدام lttng_ust_tracelog():

#include <stdlib.h>
#include <lttng/tracelog.h>
int main(int argc, char *argv[])
{
    int i;
    if (argc < 2) {
        lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_CRIT,
                           "ليس هناك حجج كافية: %d", argc);
        return EXIT_FAILURE;
    }
    lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_INFO,
                       "بدء التطبيق مع %d حجج", argc);
    for (i = 0; i < argc; i++) {
        lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_DEBUG,
                           "الحجة %d: %s", i, argv[i]);
    }
    lttng_ust_tracelog(LTTNG_UST_TRACEPOINT_LOGLEVEL_INFO,
                       "إنهاء التطبيق");
    return EXIT_SUCCESS;
}

يمكن تجميع ملف المصدر C هذا، المحفوظ باسم app.c، في برنامج على هذا النحو:

$ cc -o app app.c -llttng-ust -llttng-ust-common

يمكنك إنشاء جلسة تتبع LTTng، وتمكين جميع أحداث lttng_ust_tracelog()، وبدء جلسة التتبع المنشأة على هذا النحو:

$ lttng create my-session
$ lttng enable-event --userspace 'lttng_ust_tracelog:*'
$ lttng start

أو يمكنك تمكين أحداث lttng_ust_tracelog() التي تطابق مستوى تسجيل أكثر صرامة على الأقل من مستوى تسجيل معين:

$ lttng enable-event --userspace 'lttng_ust_tracelog:*' \
                     --loglevel=INFO

بعد ذلك، قم بتشغيل البرنامج المراد تتبعه:

$ ./app a few arguments passed to this application

أخيرًا، أوقف جلسة التتبع، وافحص الأحداث المسجلة:

$ lttng stop
$ lttng view

القيود

تم تطوير وحدات الماكرو المساعدة lttng_ust_tracelog() و lttng_ust_vtracelog() لجعل تتبع مساحة المستخدم بسيطًا للغاية، على الرغم من العيوب الملحوظة مقارنة بمقدمي نقاط التتبع المخصصة والكاملة:

•جميع الأحداث التي تم إنشاؤها لها نفس أسماء مقدم الخدمة/الحدث.
•لا يوجد فحص ثابت للأنواع.
•حقل الحدث الوحيد مع بيانات المستخدم الذي تحصل عليه فعليًا، والذي يسمى msg، هو سلسلة نصية قد تحتوي على القيم التي مررتها إلى الماكرو باستخدام التنسيق الخاص بك. هذا يعني أيضًا أنه لا يمكنك استخدام التصفية باستخدام تعبير مخصص في وقت التشغيل لأنه لا توجد حقول معزولة.
•نظرًا لأن lttng_ust_tracelog() و lttng_ust_vtracelog() تستخدم وظيفة vasprintf(3) الخاصة بمكتبة C القياسية في الخلفية لتنسيق السلاسل النصية في وقت التشغيل، فإن أدائها المتوقع أقل من استخدام مقدمي نقاط تتبع مخصصين مع حقول ذات أنواع محددة، والتي لا تتطلب تحويلاً إلى سلسلة نصية.
•بشكل عام، لا تكون السلسلة النصية التي تحتوي على التمثيل النصي لحقول بيانات المستخدم مدمجة مثل الحقول الثنائية في التتبع الناتج.

لذلك، تعد lttng_ust_tracelog()/lttng_ust_vtracelog() مفيدة للنماذج الأولية السريعة وتصحيح الأخطاء، ولكن لا ينبغي اعتبارها لأي تطبيق دائم/جدي تم تجهيزه

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

lttng_ust_vtracelog(3)

NAME

lttng_ust_vtracelog - Trace an event with a variable argument list

SYNOPSIS

#include <lttng/tracef.h>

int lttng_ust_vtracelog(const char *format, va_list ap);

DESCRIPTION

The lttng_ust_vtracelog() function is used to trace a message using a variable argument list. The format string format follows the same rules as the printf(3) format string.

This function is useful when the arguments to be traced are already formatted into a va_list structure, like when writing wrappers for existing tracing functions.

EXAMPLE

This example shows how to wrap the lttng_ust_tracef(3) function:

    #include <lttng/tracef.h>
    #include <stdarg.h>

    void my_custom_tracer(const char *format, ...)
    {
        va_list ap;
        va_start(ap, format);
        if (lttng_ust_vtracelog(format, ap) == 0) {
            /* Trace successful */
        } else {
            /* Trace failed */
        }
        va_end(ap);
    }

    int main(void)
    {
        my_custom_tracer("Hello, %s!", "world");
        return 0;
    }

LIMITATIONS

lttng_ust_vtracelog() does not have a STAP_PROBEV() call, because STAP_PROBEV() does not support va_list. If you need it, you should emit this call yourself.

See lttng-ust(3) to learn more about custom tracepoint providers.
