روتين فرعي clarfgp (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFGP ينشئ عاكسًا أوليًا (مصفوفة هاوسهولدر) مع بيتا غير سالب.

الغرض:

!>
!> CLARFGP ينشئ عاكسًا أوليًا معقدًا H من الرتبة n، بحيث
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> حيث alpha و beta قيمتان عدديتان، beta حقيقية وغير سالبة، و
!> x هو متجه معقد ذو n-1 عنصر. يُمثَّل H بالشكل
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> حيث tau قيمة عددية معقدة و v متجه معقد ذو n-1 عنصر. لاحظ أن H ليس هيرميتيًا.
!>
!> إذا كانت عناصر x كلها صفرية و alpha حقيقية، فإن tau = 0
!> وتُعتبر H مصفوفة الوحدة.
!>

larfgp(3)

NAME

larfgp - constructs a general real elementary reflector

SYNOPSIS

  SUBROUTINE LARFGP( N, ALPHA, X, INCX, TAU )
      INTEGER        INCX, N
      DOUBLECOMPLEX  ALPHA, TAU
      COMPLEX*16     X( * )

Detailed Description

LARFGP constructs a general elementary reflector H of order N, such that

H * x = [ beta ]

[ 0 ]

where x is an n-element vector in the first element of the array X, and beta is a scalar with beta <= scale*x[1], where scale is the scaling factor computed for x.

H is defined as H = I - tau * v * v^H, where tau is a scalar and v is the first column of the matrix V.

The vector v is returned in the slice X(1:N, 1), except that the element v(1) is returned in ALPHA, and

ALPHA

  ALPHA is COMPLEX*16
  On entry, the value alpha.
  On exit, it is overwritten with the value beta.

LARFGP(3) LAPACK LARFGP(3)

X 

  X is COMPLEX*16 array, dimension
                 (1+(N-2)*abs(INCX))
  On entry, the vector x.
  On exit, it is overwritten with the vector v.

INCX 

  INCX is INTEGER
  The increment between elements of X. INCX > 0.

TAU 

  TAU is COMPLEX*16
  The value tau.
