subroutine dlasv2 (double precision f, double precision g, double precision h, double precision ssmin, double precision ssmax, double precision snr, double precision csr, double precision snl, double precision csl)

DLASV2 تحسب تحليل القيم المنفردة لمصفوفة مثلثية 2x2.

الغرض:

!>
!> DLASV2 تحسب تحليل القيم المنفردة لمصفوفة مثلثية 2x2
!>    [  F   G  ]
!>    [  0   H  ].
!> عند العودة، abs(SSMAX) هي القيمة المنفردة الأكبر، abs(SSMIN) هي
!> القيمة المنفردة الأصغر، و(CSL,SNL) و(CSR,SNR) هي المتجهات المنفردة اليسرى
!> واليمنى للقيمة abs(SSMAX)، مما يعطي التحليل
!>
!>    [ CSL  SNL ] [  F   G  ] [ CSR -SNR ]  =  [ SSMAX   0   ]
!>    [-SNL  CSL ] [  0   H  ] [ SNR  CSR ]     [  0    SSMIN ].
!>

    الاسم

    lasv2.3 - شرح الأوامر (man page)

    الملخص

    lasv2.3 [OPTIONS] [FILE...]

    الوصف

    lasv2.3 هو أداة سطر أوامر تسمح لك بإدارة وإظهار المعلومات المتعلقة بالأجهزة الافتراضية.

    الخيارات

    -h, --help
    عرض رسالة المساعدة والخروج.
    -v, --version
    عرض معلومات الإصدار والخروج.
    -l, --list
    عرض قائمة بجميع الأجهزة الافتراضية.
    -a, --add
    إضافة جهاز افتراضي جديد بناءً على ملف التكوين المحدد.
    -r, --remove
    إزالة الجهاز الافتراضي المحدد.
    -s, --start
    بدء تشغيل الجهاز الافتراضي المحدد.
    -p, --stop
    إيقاف الجهاز الافتراضي المحدد.
    -c, --console
    الاتصال بوحدة تحكم الجهاز الافتراضي المحدد.

    أمثلة

    لعرض قائمة بجميع الأجهزة الافتراضية:

    lasv2.3 --list

    لإضافة جهاز افتراضي جديد باستخدام ملف التكوين my_vm.conf:

    lasv2.3 --add my_vm.conf

    لبدء تشغيل جهاز افتراضي يسمى webserver:

    lasv2.3 --start webserver
