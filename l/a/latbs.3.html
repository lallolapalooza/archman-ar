روتين فرعي clatbs (uplo حرفي، trans حرفي، diag حرفي، normin حرفي، n صحيح، kd صحيح، معقد، dimension(ldab, *) ab، ldab صحيح، معقد، dimension(*) x، scale حقيقي، cnorm حقيقي، dimension(*)، info صحيح)

CLATBS يحل نظام معادلات مثلثي نطاقي.

الغرض:

!>
!> CLATBS يحل أحد الأنظمة المثلثية
!>
!>    A * x = s*b,  A**T * x = s*b,  أو  A**H * x = s*b,
!>
!> مع قياس لمنع الفائض، حيث A هي مصفوفة نطاقية مثلثية علوية أو سفلية. هنا A**T
!> تمثل منقول المصفوفة A، و x و b هما متجهان يحتويان على n عنصر، و s هو عامل
!> قياس، عادة ما يكون أقل من أو يساوي 1، يتم اختياره بحيث تكون مكونات x
!> أقل من عتبة الفائض. إذا لم يتسبب النظام غير المقاس في حدوث فائض، يتم استدعاء
!> روتين BLAS من المستوى 2 CTBSV. إذا كانت المصفوفة A منفردة (A(j,j) = 0 لبعض j)،
!> فسيتم تعيين s إلى 0 ويتم إرجاع حل غير تافه لـ A*x = 0.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية علوية أم سفلية.
!>          = 'U':  مثلثية علوية
!>          = 'L':  مثلثية سفلية
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد العملية المطبقة على A.
!>          = 'N':  حل A * x = s*b     (بدون منقول)
!>          = 'T':  حل A**T * x = s*b  (منقول)
!>          = 'C':  حل A**H * x = s*b  (منقول مقترن)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية أحادية أم لا.
!>          = 'N':  غير مثلثية أحادية
!>          = 'U':  مثلثية أحادية
!>

NORMIN

!>          NORMIN هو CHARACTER*1
!>          يحدد ما إذا كان CNORM قد تم تعيينه أم لا.
!>          = 'Y':  يحتوي CNORM على معايير الأعمدة عند الإدخال
!>          = 'N':  لم يتم تعيين CNORM عند الإدخال. عند الخروج، سيتم
!>                  حساب المعايير وتخزينها في CNORM.
!>

N

!>          N هو صحيح (INTEGER)
!>          رتبة المصفوفة A.  N >= 0.
!>

KD

!>          KD هو صحيح (INTEGER)
!>          عدد الأقطار الفرعية أو فوق الأقطار في المصفوفة المثلثية A.  KD >= 0.
!>

AB

!>          AB هو مصفوفة معقدة (COMPLEX array)، dimension (LDAB,N)
!>          المصفوفة المثلثية العلوية أو السفلية النطاقية A، مخزنة في
!>          أول KD+1 صفوف من المصفوفة. يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كالتالي:
!>          إذا كان UPLO = 'U'، فإن AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j) = A(i,j) لـ j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB هو صحيح (INTEGER)
!>          البعد الرئيسي للمصفوفة AB.  LDAB >= KD+1.
!>

X

!>          X هي مصفوفة معقدة (COMPLEX array)، dimension (N)
!>          عند الإدخال، الجانب الأيمن b من النظام المثلثي.
!>          عند الخروج، يتم استبدال X بمتجه الحل x.
!>

SCALE

!>          SCALE هو حقيقي (REAL)
!>          عامل القياس s للنظام المثلثي
!>             A * x = s*b,  A**T * x = s*b,  أو  A**H * x = s*b.
!>          إذا كان SCALE = 0، فإن المصفوفة A منفردة أو سيئة القياس،
!>          والمتجه x هو حل دقيق أو تقريبي لـ A*x = 0.
!>

CNORM

!>          CNORM هي مصفوفة حقيقية (REAL array)، dimension (N)
!>
!>          إذا كان NORMIN = 'Y'، فإن CNORM هو وسيط إدخال و CNORM(j)
!>          يحتوي على معيار الجزء غير القطري من العمود j
!>          للمصفوفة A. إذا كان TRANS = 'N'، يجب أن يكون CNORM(j) أكبر من أو
!>          يساوي المعيار اللانهائي، وإذا كان TRANS = 'T' أو 'C'، يجب أن يكون CNORM(j)
!>          أكبر من أو يساوي المعيار 1.
!>
!>          إذا كان NORMIN = 'N'، فإن CNORM هو وسيط إخراج و CNORM(j)
!>          يعيد المعيار 1 للجزء غير القطري من العمود j
!>          للمصفوفة A.
!>

INFO

!>          INFO هو صحيح (INTEGER)
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -k، فإن الوسيط k كان له قيمة غير قانونية
!>

تفاصيل إضافية:

!>
!> يتم حساب حد تقريبي لـ x؛ إذا كان هذا الحد أقل من الفائض، يتم استدعاء CTBSV،
!> وإلا، يتم استخدام كود محدد يتحقق من احتمالية الفائض أو القسمة على صفر
!> عند كل عملية.
!>
!> يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!> إذا كانت A مثلثية سفلية هي:
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> نحدد الحدود على مكونات x بعد j تكرار للحلقة:
!>     M(j) = حد لـ x[1:j]
!>     G(j) = حد لـ x[j+1:n]
!> مبدئياً، لنكن M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!> ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> حيث CNORM(j+1) أكبر من أو يساوي المعيار اللانهائي
!> للعمود j+1 من A، باستثناء القطر. وبالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> بما أن |x(j)| <= M(j)، فإننا نستخدم روتين BLAS من المستوى 2 CTBSV إذا كان
!> معكوس أكبر M(j)، j=1,..,n، أكبر من
!> max(underflow, 1/overflow).
!>
!> يستخدم الحد على x(j) أيضًا لتحديد متى يمكن إجراء خطوة في
!> المخطط العمودي دون خوف من الفائض. إذا كان
!> الحد المحسوب أكبر من ثابت كبير، يتم قياس x لمنع الفائض،
!> ولكن إذا فاض الحد، يتم تعيين x إلى 0، و x(j) إلى
!> 1، و scale إلى 0، ويتم العثور على حل غير تافه لـ A*x = 0.
!>
!> وبالمثل، يستخدم مخطط صفي لحل A**T *x = b أو
!> A**H *x = b. الخوارزمية الأساسية لـ A المثلثية العلوية هي:
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end
!>
!> نقوم بحساب حدين بشكل متزامن
!>       G(j) = حد لـ ( b(i) - A[1:i-1,i]' * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد لـ x(i)، 1<=i<=j
!>
!> القيم الأولية هي G(0) = 0، M(0) = max{b(i)، i=1,..,n}، ونقوم
!> بإضافة الشرط G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!> ثم حد x(j) هو:
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> ويمكننا استدعاء CTBSV بأمان إذا كان 1/M(n) و 1/G(n) كلاهما أكبر
!> من max(underflow, 1/overflow).
!>

!> وإلا، يتم استخدام كود محدد يتحقق من احتمالية الفائض أو القسمة على صفر

!> يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!> إذا كانت A مثلثية سفلية هي:
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> نحدد الحدود على مكونات x بعد j تكرار للحلقة:
!>     M(j) = حد لـ x[1:j]
!>     G(j) = حد لـ x[j+1:n]
!> مبدئياً، لنكن M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!> ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> حيث CNORM(j+1) أكبر من أو يساوي المعيار اللانهائي
!> للعمود j+1 من A، باستثناء القطر. وبالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> بما أن |x(j)| <= M(j)، فإننا نستخدم روتين BLAS من المستوى 2 STBSV إذا كان
!> معكوس أكبر M(j)، j=1,..,n، أكبر من
!> max(underflow, 1/overflow).
!>
!> يستخدم الحد على x(j) أيضًا لتحديد متى يمكن إجراء خطوة في
!> المخطط العمودي دون خوف من الفائض. إذا كان
!> الحد المحسوب أكبر من ثابت كبير، يتم قياس x لمنع الفائض،

!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end

!>       G(j) = حد لـ ( b(i) - A[1:i-1,i]' * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد لـ x(i)، 1<=i<=j
!>
!> القيم الأولية هي G(0) = 0، M(0) = max{b(i)، i=1,..,n}، ونقوم
!> بإضافة الشرط G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!> ثم حد x(j) هو:
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
