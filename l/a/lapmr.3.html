NAME

lapmr - lapmr

SYNOPSIS

SUBROUTINE ZLAPMR(
  M, N, X, LDX, K, INFO
)
  INTEGER M, N, LDX, INFO
  COMPLEX*16 X( LDX, * )
  INTEGER K( * )

Description

ZLAPMR applies a block permutation to a complex matrix.

This subroutine is intended to be used on the matrix X and the permutation vector K to form the matrix X*P or X P, where P is a block permutation matrix.

The permutation is specified by the array K.

Parameters

M

M is INTEGER

The number of rows of the matrix X. M >= 0.

N

N is INTEGER

The number of columns of the matrix X. N >= 0.

X

X is COMPLEX*16 array, dimension (LDX,N)

On entry, the M by N matrix X.

On exit, X contains the permuted matrix X.

LDX

LDX is INTEGER

The leading dimension of the array X, LDX >= MAX(1,M).

K

K is INTEGER array, dimension (M)

On entry, K contains the permutation vector. K is used as internal workspace, but reset to its original value on output.

INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value.

الوصف

تطبق ZLAPMR تبديلًا كتليًا على مصفوفة معقدة.

تم تخصيص هذه الإجراءات الفرعية للاستخدام على المصفوفة X ومتجه التبديل K لتكوين المصفوفة X*P أو X P، حيث P هي مصفوفة تبديل كتلي.

يتم تحديد التبديل بواسطة المصفوفة K.

عند الإدخال، المصفوفة X ذات الأبعاد M × N.
