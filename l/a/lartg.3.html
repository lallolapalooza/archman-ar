subroutine clartg (complex(wp) f, complex(wp) g, real(wp) c, complex(wp) s, complex(wp) r)

CLARTG توليد دوران مستوي مع جيب تمام حقيقي وجيب مركب.

الغرض:

!>
!> CLARTG توليد دوران مستوي بحيث
!>
!>    [  C         S  ] . [ F ]  =  [ R ]
!>    [ -conjg(S)  C  ]   [ G ]     [ 0 ]
!>
!> حيث C حقيقي و C**2 + |S|**2 = 1.
!>
!> الصيغ الرياضية المستخدمة لـ C و S هي
!>
!>    sgn(x) = {  x / |x|,   x != 0
!>             {  1,         x  = 0
!>
!>    R = sgn(F) * sqrt(|F|**2 + |G|**2)
!>
!>    C = |F| / sqrt(|F|**2 + |G|**2)
!>
!>    S = sgn(F) * conjg(G) / sqrt(|F|**2 + |G|**2)
!>
!> شروط خاصة:
!>    إذا كان G=0، فإن C=1 و S=0.
!>    إذا كان F=0، فإن C=0 و S يتم اختياره بحيث يكون R حقيقيًا.
!>
!> عندما تكون F و G حقيقية، تبسط الصيغ إلى C = F/R و
!> S = G/R، ويجب أن تكون القيم المعادة لـ C، S، و R متطابقة
!> مع تلك التي تعيدها SLARTG.
!>
!> تتضمن الخوارزمية المستخدمة لحساب هذه الكميات قياسًا
!> لتجنب التدفق الزائد أو الناقص في حساب الجذر التربيعي
!> لمجموع المربعات.
!>
!> هذه هي نفس روتين CROTG من BLAS1، باستثناء أن
!> F و G لا تتغير عند العودة.
!>
!> أدناه، wp=>sp تشير إلى الدقة الأحادية من وحدة LA_CONSTANTS.
!>

subroutine dlartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

DLARTG توليد دوران مستوي مع جيب تمام حقيقي وجيب حقيقي.

الغرض:

!>
!> DLARTG توليد دوران مستوي بحيث
!>
!>    [  C  S  ]  .  [ F ]  =  [ R ]
!>    [ -S  C  ]     [ G ]     [ 0 ]
!>
!> حيث C**2 + S**2 = 1.
!>
!> الصيغ الرياضية المستخدمة لـ C و S هي
!>    R = sign(F) * sqrt(F**2 + G**2)
!>    C = F / R
!>    S = G / R
!> وبالتالي C >= 0. الخوارزمية المستخدمة لحساب هذه الكميات
!> تتضمن قياسًا لتجنب التدفق الزائد أو الناقص في حساب
!> الجذر التربيعي لمجموع المربعات.
!>
!> هذه النسخة متقطعة في R عند F = 0 ولكنها تعيد نفس
!> C و S مثل ZLARTG للمدخلات المركبة (F,0) و (G,0).
!>
!> هذه نسخة أكثر دقة من روتين BLAS1 DROTG،
!> مع الاختلافات الأخرى التالية:
!>    F و G لا تتغير عند العودة.
!>    إذا كان G=0، فإن C=1 و S=0.
!>    إذا كان F=0 و (G .ne. 0)، فإن C=0 و S=sign(1,G) بدون إجراء أي
!>       عمليات حسابية نقطة عائمة (يوفر العمل في DBDSQR عندما
!>       تكون هناك أصفار على القطر).
!>
!> أدناه، wp=>dp تشير إلى الدقة المزدوجة من وحدة LA_CONSTANTS.
!>

subroutine slartg (real(wp) f, real(wp) g, real(wp) c, real(wp) s, real(wp) r)

SLARTG generates a plane rotation with real cosine and sine.

Purpose:

!>
        !> SLARTG generates a plane rotation so that
        !>
        !>    [  C    S  ] . [ F ]  =  [ R ]
        !>    [ -S    C  ]   [ G ]     [ 0 ]
        !>
        !> where C and S are real and C**2 + S**2 = 1.
        !>
        !> The mathematical formulas used for C and S are
        !>
        !>    R = sgn(F)*sqrt(F**2 + G**2)
        !>    C = F/R
        !>    S = G/R
        !>
        !> Special conditions:
        !>    If G=0, then C=1 and S=0.
        !>    If F=0, then C=0 and S=1.
        !>
        !> The algorithm used to compute these quantities incorporates scaling
        !> to avoid overflow or underflow in computing the square root of the
        !> sum of squares.
        !>
        !> This is the same routine SROTG fom BLAS1, except that
        !> F and G are unchanged on return.
        !>
        !> Below, wp=>dp stands for double precision from LA_CONSTANTS module.
        !>

Parameters

F 
!>          F is REAL(wp)
        !>          The first component of vector to be rotated.
        !>

G

!>          G is REAL(wp)
        !>          The second component of vector to be rotated.
        !>

C

!>          C is REAL(wp)
        !>          The cosine of the rotation.
        !>

S

!>          S is REAL(wp)
        !>          The sine of the rotation.
        !>

R

!>          R is REAL(wp)
        !>          The nonzero component of the rotated vector.
        !>

Author

Weslley Pereira, University of Colorado Denver, USA

Date

December 2021

Further Details:

!>
        !> Based on the algorithm from
        !>
        !>  Anderson E. (2017)
        !>  Algorithm 978: Safe Scaling in the Level 1 BLAS
        !>  ACM Trans Math Softw 44:1--28
        !>  https://doi.org/10.1145/3061665
