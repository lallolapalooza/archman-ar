توثيق الوظيفة

subroutine clar2v (integer n, complex, dimension( * ) x, complex, dimension( * ) y, complex, dimension( * ) z, integer incx, real, dimension( * ) c, complex, dimension( * ) s, integer incc)

CLAR2V يطبق متجهًا من دورانات المستوى مع جيب تمام حقيقي وجيب مركب من كلا الجانبين على تسلسل من مصفوفات 2x2 المتماثلة/الهرمية.

الغرض:

!>
!> CLAR2V يطبق متجهًا من دورانات المستوى المركبة مع جيب تمام حقيقي من كلا الجانبين
!> على تسلسل من مصفوفات 2x2 الهرمية المركبة، المعرفة بعناصر المتجهات x، y و z.
!> لكل i = 1,2,...,n
!>
!>    (       x(i)  z(i) ) :=
!>    ( conjg(z(i)) y(i) )
!>
!>      (  c(i) conjg(s(i)) ) (       x(i)  z(i) ) ( c(i) -conjg(s(i)) )
!>      ( -s(i)       c(i)  ) ( conjg(z(i)) y(i) ) ( s(i)        c(i)  )
!>

!>          المتجه x؛ يفترض أن عناصر x حقيقية.
!>

Y

!>          Y هو مصفوفة مركبة (COMPLEX)، البعد (1+(N-1)*INCX)
!>          المتجه y؛ يفترض أن عناصر y حقيقية.
!>

Z

!>          Z هو مصفوفة مركبة (COMPLEX)، البعد (1+(N-1)*INCX)
!>          المتجه z.
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)
!>          الزيادة بين عناصر X، Y و Z. INCX > 0.
!>

C

!>          C هو مصفوفة حقيقية (REAL)، البعد (1+(N-1)*INCC)
!>          جيب تمام دورانات المستوى.
!>
