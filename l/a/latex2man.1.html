النص الشرطي

يقوم latex2man بمعالجة مدخلات LaTeX مسبقًا للسماح باستخدام النص بشكل شرطي. يستخدم نوع خاص من تعليقات LaTeX لهذا الغرض.

*
%@% IF condition %@%
*
%@% ELSE %@%
*
%@% END-IF %@%

يجب أن يحتوي السطر على مثل هذا التعليق فقط ولا شيء آخر. condition هو تعبير منطقي يحتوي على "أسماء" وعوامل تشغيل. الأسماء المعطاة مع الخيار -Cname لها القيمة "صحيح" (true)، بينما يُفترض أن جميع الأسماء الأخرى التي تظهر في التعبير قيمتها "خطأ" (false). إذا أدت تقييم التعبير المنطقي إلى القيمة "صحيح"، فسيتم استخدام النص الموجود في جزء "then" وسيتم تخطي النص في جزء "else" الاختياري (والعكس صحيح). يمكن تداخل IF / ELSE / END-IF. كعوامل تشغيل منطقية، يُسمح بما يلي:

||T}&T{ أو منطقي
&&T}&T{ و منطقي
! نفي

( و ) للتجميع مسموح بها.

على سبيل المثال:
%@% IF abc %@%
abc تم التعيين
%@% IF xyz %@%
xyz تم التعيين
%@% ELSE %@%
xyz لم يتم التعيين
%@% END-IF %@%
%@% ELSE %@%
abc لم يتم التعيين
%@% IF xyz || !XYZ %@%
xyz أو !XYZ تم التعيين
%@% ELSE %@%
xyz أو !XYZ لم يتم التعيين
%@% END-IF %@%
%@% END-IF %@%

قم بتشغيل صفحة الدليل هذه عبر latex2man مع، على سبيل المثال، -C'abc XYZ' وانظر إلى المخرجات التي تم إنشاؤها. (إذا قمت ببساطة بتشغيل المستند LaTeX عبر LaTeX، فسيتم عرض جميع الأسطر في ملف .dvi).
abc لم يتم التعيين
xyz أو !XYZ تم التعيين

للتحقق من ميزة النص الشرطي، عندما يتم استدعاء latex2man مع

2b. لم يتم تعيين شرط TEXI.

ترجمة وحدات المستخدم المعرفة

يحتوي ملف ترجمة وحدات المستخدم (المعطى بواسطة [-ttransfile]) على أوامر Perl تحدد ترجمة وحدات LaTeX التي عرفها المستخدم. قد تحتوي هذه الوحدات على صفر أو واحد أو حجتين. الكود المتوقع هو:

*
تبدأ التعليقات برمز # حتى نهاية السطر.
*
بالنسبة لوحدة \foo بدون حجج، يجب تحديد الكود التالي:
الترجمة إلى صفحات الدليل (Man-Pages)
$manMacro{'foo'} = '...';
الترجمة إلى HTML
$htmlMacro{'foo'} = '...';
الترجمة إلى TexInfo
$texiMacro{'foo'} = '...';

حيث ... هي الترجمة.

*
بالنسبة لوحدة \foo{..} بحجة واحدة، يجب تحديد الكود التالي:
الترجمة إلى صفحات الدليل (Man-Pages)
$manMacro1a{'foo'} = '...';
$manMacro1b{'foo'} = '...';
الترجمة إلى HTML
$htmlMacro1a{'foo'} = '...';
$htmlMacro1b{'foo'} = '...';
الترجمة إلى TexInfo
$texiMacro1a{'foo'} = '...';
$texiMacro1b{'foo'} = '...';

حيث ... هي الترجمة. يتم استخدام الكود 1a قبل الحجة، بينما تتم طباعة 1b بعد تعيين الحجة.

*
بالنسبة لوحدة \foo{..}{..} بحجتين، يجب تحديد الكود التالي:
الترجمة إلى صفحات الدليل (Man-Pages)
$manMacro2a{'foo'} = '...';
$manMacro2b{'foo'} = '...';
$manMacro2c{'foo'} = '...';
الترجمة إلى HTML
$htmlMacro2a{'foo'} = '...';
$htmlMacro2b{'foo'} = '...';
$htmlMacro2c{'foo'} = '...';
الترجمة إلى TexInfo
$texiMacro2a{'foo'} = '...';
$texiMacro2b{'foo'} = '...';
$texiMacro2c{'foo'} = '...';

حيث ... هي الترجمة. يتم استخدام الكود 2a قبل الحجة الأولى، 2b بين الحجتين، وتتم طباعة 2c بعد تعيين الحجة الثانية.

*
يحتوي الملف latex2man.trans على بعض أمثلة الأكواد.

ملاحظات عامة

1.
الأسطر الفارغة تتم طباعتها كفواصل فقرات.
2.
لا يجب تقسيم حجج أوامر LaTeX عبر عدة أسطر.
3.
لا تقم بتداخل استدعاءات الوحدات (macros).
4.
باستثناء البيئات والوحدات المذكورة، لا تتم ترجمة استخدام بيئات أو وحدات LaTeX الأخرى. استخدامها سيؤدي إلى نتائج غير صحيحة (garbage) في المخرجات.
5.
يتطلب latex2man إصدار Perl >= 5.0004_03.
6.
إذا كنت ترغب في تثبيت النظام باستخدام Makefile الموزع، فستحتاج إلى GNU-make. إذا لم يكن لديك، يجب عليك تنفيذ الخطوات الموضحة في Makefile يدويًا.

أسماء فئات CSS

يوضح الجدول التالي أسماء فئات CSS التي سيتم تضمينها في وسوم HTML كسمات. يمكنك تحديد خصائص نمط CSS في CSSfile لهذه الفئات:

وسم HTML فئة (Class) التطبيق على النمط
body جسم صفحة HTML
h1 titlehead العنوان في أعلى صفحة HTML المحدد كوسيط للبيئة Name
h4 authorhead المؤلف في أعلى صفحة HTML المحدد كوسيط للبيئة Name
h4 datehead التاريخ في أعلى صفحة HTML
h4 versionhead إصدار صفحة الدليل في أعلى صفحة HTML المحدد كوسيط للوحدة setVersion
h2 sectionname عنوان قسم محدد كوسيط للوحدة section
h4 subsectionname عنوان قسم فرعي محدد كوسيط للوحدة subsection
h5 subsubsectionname عنوان قسم فرعي أصغر محدد كوسيط للوحدة subsubsection
font progname اسم برنامج محدد كوسيط للوحدة Prog
font filename اسم ملف محدد كوسيط للوحدة File
font commandname اسم أمر محدد كوسيط للوحدة Cmd
font textstyle كل نص ليس وسيطًا لوحدة LaTeX أو latex2man
font optstyle اسم خيار محدد كوسيط للوحدات Opt، oOpt، OptArg، oOptArg أو oOptoArg
font argstyle اسم وسيط محدد كوسيط للوحدات Arg، oArg، OptArg، oOptArg أو oOptoArg
a, font urlstyle عنوان URL محدد كوسيط للوحدة URL
a, font urlstyle.link فئة فرعية من فئة urlstyle
a, font urlstyle.visited فئة فرعية

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
