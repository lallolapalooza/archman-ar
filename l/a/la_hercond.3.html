دالة حقيقية cla_syrcond_c (حرف uplo، صحيح n، مركب، بعد (_lda، * ) a، صحيح lda، مركب، بعد (_ldaf، * ) af، صحيح ldaf، صحيح، بعد ( * ) ipiv، حقيقي، بعد ( * ) c، منطقي capply، صحيح info، مركب، بعد ( * ) work، حقيقي، بعد ( * ) rwork)

CLA_SYRCOND_C تحسب عدد شرط القاعدة اللانهائية لـ op(A)*inv(diag(c)) للمصفوفات المتناظرة غير المحددة.

!>    op(A) * inv(diag(C)) حيث C متجه حقيقي.
!>

دالة دقة مزدوجة dla_syrcond (حرف uplo، صحيح n، دقة مزدوجة، بعد (_lda، * ) a، صحيح lda، دقة مزدوجة، بعد (_ldaf، * ) af، صحيح ldaf، صحيح، بعد ( * ) ipiv، صحيح cmode، دقة مزدوجة، بعد ( * ) c، صحيح info، دقة مزدوجة، بعد ( * ) work، صحيح، بعد ( * ) iwork)

DLA_SYRCOND تقدر عدد شرط Skell للمصفوفة المتناظرة غير المحددة.

الغرض:

!>
!>    DLA_SYRCOND تقدر عدد شرط Skell لـ op(A) * op2(C)
!>    حيث يتم تحديد op2 بواسطة CMODE كما يلي
!>    CMODE =  1    op2(C) = C
!>    CMODE =  0    op2(C) = I
!>    CMODE = -1    op2(C) = inv(C)
!>    يتم حساب عدد شرط Skell cond(A) = norminf( |inv(A)||A| )
!>    عن طريق حساب عوامل القياس R بحيث
!>    diag(R)*A*op2(C) تكون متوازنة الصفوف ويتم حساب عدد الشرط القياسي
!>    للقاعدة اللانهائية.
!>
