الغرض:

!>
!> CLATRS يحل أحد الأنظمة المثلثية
!>
!>    A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b,
!>
!> مع التحجيم لمنع التدفق الزائد. حيث A هي مصفوفة مثلثية علوية أو سفلية،
!> A**T تشير إلى منقول A، A**H تشير إلى المرافق المنقول لـ A، x و b هما متجهان
!> مكونان من n عنصر، و s هو عامل التحجيم، عادة ما يكون أقل من أو يساوي 1،
!> يتم اختياره بحيث تكون مكونات x أقل من حد التدفق الزائد. إذا لم يسبب
!> النظام غير المحجّم تدفقًا زائدًا، يتم استدعاء روتين المستوى 2 BLAS
!> CTRSV. إذا كانت المصفوفة A منفردة (A(j,j) = 0 لبعض j)، يتم تعيين s إلى
!> 0 ويتم إرجاع حل غير بديهي لـ A*x = 0.
!>

NAME

ZLATRS — solves a triangular system of the form A*x = b or A**T *x = b

SYNOPSIS

 SUBROUTINE ZLATRS( UPLO, TRANS, DIAG, NORMEQ, N, A, LDA, X, LDX, B, LDB, INFO )

      CHARACTER * 1        UPLO
      CHARACTER * 1        TRANS
      CHARACTER * 1        DIAG
      CHARACTER * 1        NORMEQ
      INTEGER              N
      COMPLEX*16           A( LDA, * )
      INTEGER              LDA
      COMPLEX*16           X( LDX, * )
      INTEGER              LDX
      COMPLEX*16           B( LDB, * )
      INTEGER              LDB
      INTEGER              INFO

Detailed Description

ZLATRS solves a triangular system of the form A*x = b or A**T *x = b, where A is a quasi-triangular matrix and there is no need to fully factorize A. It is generated by ZTRNA.

A is an N x N matrix. X and B are N x NRHS matrices. For the triangular solver, A is represented as a sequence of 2x2 blocks. The diagonal blocks are either 1x1 or 2x2. If A(j,j) is a 1x1 block, then A(j,j) = A(j,j).

If A(j,j) is a 2x2 block, then

          A(j,j) = [ A(j,j)  A(j+1,j)  ]
                   [ A(j,j+1)  A(j+1,j+1)]

where j = 1, 3, ..., N-1 or N. A(j,j) is used for the 1x1 case and A(j,j), A(j+1,j), A(j,j+1), A(j+1,j+1) are used for the 2x2 case.

This routine is called by ZTRNA to solve the triangular system

          op(A) * x = b

where op(A) is either A or A**T. The matrix A is quasi-triangular.

The algorithm takes advantage of the fact that the triangular matrix A is generated by ZTRNA. The entries of A are such that we can bound the entries of the solution x. We can then scale the problem to avoid overflow and underflow.

The bounds are computed using the following scheme.

We compute the bounds on the solution x

          M(j) = bound on max( |x(i)| ) for 1<=i<=j

and the bound on the numerator term

          G(j) = bound on max( |b(i) - A(i,1:i-1)*x(1:i-1)| ) for 1<=i<=j

The initial values are G(0) = 0 and M(0) = max( |b(i)| ) for 1<=i<=n.

The diagonal elements are checked to prevent overflow and underflow. If the diagonal element A(j,j) is zero, the routine returns an error.

The bound M(j) is updated as follows:

          M(j) = max( M(j-1) * ( 1 + CNORM(j) ) / |A(j,j)| , G(j) )

where CNORM(j) is the bound on the norm of the j-th column of A.

The routine continues the computation as long as the bounds are within the representable range of floating point numbers. If an overflow is detected, the matrix is scaled to prevent it. If the bound overflows, x is set to 0, x(j) to 1, and scale to 0, and a non-trivial solution to A*x = 0 is found.

Similarly, a row-wise scheme is used to solve A**T *x = b or A**H *x = b. The basic algorithm for A upper triangular is

               for j = 1, ..., n
                    x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
               end

We simultaneously compute two bounds

               G(j) = bound on ( b(i) - A[1:i-1,i]' * x[1:i-1] ), 1<=i<=j
               M(j) = bound on x(i), 1<=i<=j

The initial values are G(0) = 0, M(0) = max{b(i), i=1,..,n}, and we add the constraint G(j) >= G(j-1) and M(j) >= M(j-1) for j >= 1.

Then the bound on x(j) is

               M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |

                    <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
                              1<=i<=j

and we can safely call ZTRSV if 1/M(n) and 1/G(n) are both greater than max(underflow, 1/overflow).
