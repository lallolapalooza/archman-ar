CLARFT تشكل العامل المثلثي T للمنعكس القطاعي H = I - vtvH

الغرض:

!>
!> CLARFT تشكل العامل المثلثي T لمنعكس قطاعي مركب H من الدرجة n، والذي يتم تعريفه كناتج لـ k منعكسات أساسية.
!>
!> إذا كان DIRECT = 'F'، فإن H = H(1) H(2) . . . H(k) و T مثلثية عليا؛
!>
!> إذا كان DIRECT = 'B'، فإن H = H(k) . . . H(2) H(1) و T مثلثية سفلى.
!>
!> إذا كان STOREV = 'C'، يتم تخزين المتجه الذي يعرف المنعكس الأساسي H(i) في العمود i للمصفوفة V، و
!>
!>    H  =  I - V * T * V**H
!>
!> إذا كان STOREV = 'R'، يتم تخزين المتجه الذي يعرف المنعكس الأساسي H(i) في الصف i للمصفوفة V، و
!>
!>    H  =  I - V**H * T * V
!>

المعلمات

DIRECT 
!>          DIRECT هو CHARACTER*1
!>          يحدد ترتيب ضرب المنعكسات الأساسية لتشكيل المنعكس القطاعي:
!>          = 'F': H = H(1) H(2) . . . H(k) (أمامي)
!>          = 'B': H = H(k) . . . H(2) H(1) (خلفي)
!>

STOREV

!>          STOREV هو CHARACTER*1
!>          يحدد كيفية تخزين المتجهات التي تعرف المنعكسات الأساسية (انظر أيضًا تفاصيل إضافية):
!>          = 'C': حسب الأعمدة
!>          = 'R': حسب الصفوف
!>

N

!>          N هو INTEGER
!>          درجة المنعكس القطاعي H. N >= 0.
!>

K

!>          K هو INTEGER
!>          درجة العامل المثلثي T (= عدد المنعكسات الأساسية). K >= 1.
!>

V

!>          V هي مصفوفة COMPLEX، أبعادها
!>                               (LDV,K) إذا كان STOREV = 'C'
!>                               (LDV,N) إذا كان STOREV = 'R'
!>          المصفوفة V. انظر التفاصيل الإضافية.
!>

LDV

!>          LDV هو INTEGER
!>          البعد الرائد للمصفوفة V.
!>          إذا كان STOREV = 'C'، فإن LDV >= max(1,N)؛ إذا كان STOREV = 'R'، فإن LDV >= K.
!>

TAU

!>          TAU هي مصفوفة COMPLEX، أبعادها (K)
!>          يجب أن تحتوي TAU(i) على العامل القياسي للمنعكس الأساسي H(i).
!>

T

!>          T هي مصفوفة COMPLEX، أبعادها (LDT,K)
!>          العامل المثلثي T بحجم k × k للمنعكس القطاعي.
!>          إذا كان DIRECT = 'F'، فإن T مثلثية عليا؛ إذا كان DIRECT = 'B'، فإن T مثلثية
!>          سفلى. بقية المصفوفة لا تستخدم.
!>

LDT

!>          LDT هو INTEGER
!>          البعد الرائد للمصفوفة T. LDT >= K.
!>

Name


dlarft — forms the triangular factor T of a block reflector
    H = I - vtvᵀ




recursive   subroutine dlarft (character direct, character storev, integer n, integer k,   real, dimension( ldv, * ) v, integer ldv, real, dimension( * ) tau, real,   dimension( ldt, * ) t, integer ldt)


Purpose:




!>
!> DLARFT forms the triangular factor T of a real block reflector H
!> of order n, which is defined as a product of k elementary reflectors.
!>
!> If DIRECT = 'F', H = H(1) H(2) . . . H(k) and T is upper triangular;
!>
!> If DIRECT = 'B', H = H(k) . . . H(2) H(1) and T is lower triangular.
!>
!> If STOREV = 'C', the vector which defines the elementary reflector
!> H(i) is stored in the i-th column of the array V, and
!>
!>    H  =  I - V * T * V**T
!>
!> If STOREV = 'R', the vector which defines the elementary reflector
!> H(i) is stored in the i-th row of the array V, and
!>
!>    H  =  I - V**T * T * V
!> 




Parameters


DIRECT

!>          DIRECT is CHARACTER*1
!>          Specifies the order in which the elementary reflectors are
!>          multiplied to form the block reflector:
!>          = 'F': H = H(1) H(2) . . . H(k) (Forward)
!>          = 'B': H = H(k) . . . H(2) H(1) (Backward)
!> 


STOREV


!>          STOREV is CHARACTER*1
!>          Specifies how the vectors which define the elementary
!>          reflectors are stored (see also Further Details):
!>          = 'C': columnwise
!>          = 'R': rowwise
!> 


N


!>          N is INTEGER
!>          The order of the block reflector H. N >= 0.
!> 


K


!>          K is INTEGER
!>          The order of the triangular factor T (= the number of
!>          elementary reflectors). K >= 1.
!> 


V


!>          V is REAL array, dimension
!>                               (LDV,K) if STOREV = 'C'
!>                               (LDV,N) if STOREV = 'R'
!>          The matrix V. See further details.
!> 


LDV


!>          LDV is INTEGER
!>          The leading dimension of the array V.
!>          If STOREV = 'C', LDV >= max(1,N); if STOREV = 'R', LDV >= K.
!> 


TAU


!>          TAU is REAL array, dimension (K)
!>          TAU(i) must contain the scalar factor of the elementary
!>          reflector H(i).
!> 


T


!>          T is REAL array, dimension (LDT,K)
!>          The k by k triangular factor T of the block reflector.
!>          If DIRECT = 'F', T is upper triangular; if DIRECT = 'B', T is
!>          lower triangular. The rest of the array is not used.
!> 


LDT


!>          LDT is INTEGER
!>          The leading dimension of the array T. LDT >= K.
!>

NAME

    
LARFT — constructs a matrix of Householder vectors.






    
SYNOPSIS

    
SUBROUTINE LARFT(
   JOBC, N, K, X, LDX, TAU, Y, LDY )

   CHARACTER          *1      JOBC
   INTEGER            N, K, LDX, LDY
   REAL               X( LDX, * ), TAU( * ), Y( LDY, * )







    
Detailed Description

    
LARFT constructs a matrix Z of Householder vectors that performs a
    rank-k update of a matrix A. Specifically, it returns the

    
    Matrix Z  such that  A*Z = A - U*V^T


    
where U and V are matrices of rank k.

    
The relationship between the vectors returned in Y and the Householder
    vectors is specified by JOBC.






    
Function Documentation

    
The matrix of Householder vectors is constructed from the Householder
    vectors returned by a preliminary call to sgeqrf.s or p?geqrf.

    
The relationship between the Householder vectors and the matrix Y is
    as follows:

    
If JOBC = 'X', then Y is the matrix U (or V) in the expression
    A*Z = A - U*V^T.

    
If JOBC = 'N', then Y is the upper triangular matrix R in the
    expression A = Q*R.

    
Otherwise, an error is reported.

    
The matrix X contains the Householder vectors returned by sgeqrf.s or
    p?geqrf.

    
The vector TAU contains the scalar factors of the elementary reflectors.
