NAME

latin1 — ISO/IEC 8859-1 character set

DESCRIPTION

This manual page describes the ISO/IEC 8859-1 character set, commonly known as Latin-1.

It is an 8-bit character set that defines characters for most Western European languages. The first 128 characters (0-127) are identical to the ASCII character set.
