NAME

laln2

solving AX = B for a 1x1, 2x2, or 1x2/2x1 (general) matrix A

SYNOPSIS

 SUBROUTINE LALN2( LTRANS, NA, NW, SMIN, CA, A, LDA, D1, D2, B, LDB, WR, WI, X, LDX, SCALE, XNORM, INFO )
           LOGICAL :: LTRANS
           INTEGER :: NA, NW, LDA, LDB, LDX, INFO
           REAL :: SMIN, CA, D1, D2, WR, WI, SCALE, XNORM
           REAL :: A( LDA, NA ), B( LDB, NW ), X( LDX, NW )

Detailed Description

This routine is called by SLAEX2 and SLAEX3. It computes the solution X to the equation

       (ca A - w D) X = B
 

where

       A is an NA x NA real matrix,
       ca is a real scalar,
       D is an NA x NA real diagonal matrix,
       w is a real or complex value,
       X and B are NA x NW matrices, and NW is 1 or 2.

It is assumed that

       norm(ca A - w D) is roughly the same order of magnitude as B.

The routine scales B so that (ca A - w D) X is computed without overflow.

The routine is not symmetric with respect to the input arguments A and B. If LTRANS is true, then (ca AT - w D) X = B is solved instead.

INFO>0 means that (ca A - w D) had to be perturbed to make its smallest (or only) singular value greater than SMIN. In the interests of speed, this routine does not check the inputs for errors.

This routine calls SLALN2 to perform the actual computation. SLALN2 computes the solution X to the equation

       (ca A - w D) X = B

where A is an NA x NA real matrix, ca is a real scalar, D is an NA x NA real diagonal matrix, w is a real or complex value, and X and B are NA x NW matrices. NW is 1 or 2.

It is assumed that norm(ca A - w D) is roughly the same order of magnitude as B. The routine scales B so that (ca A - w D) X is computed without overflow. The routine is not symmetric with respect to the input arguments A and B. If LTRANS is true, then (ca AT - w D) X = B is solved instead.

If w is complex, X and B are represented as NA x 2 matrices, the first column of each being the real part and the second being the imaginary part.

SCALE is a scaling factor (<= 1), computed by SLALN2, which is so chosen that X can be computed without overflow. X is further scaled if necessary to assure that norm(ca A - w D)*norm(X) is less than overflow.

If both singular values of (ca A - w D) are less than SMIN, SMIN*identity will be used instead of (ca A - w D). If only one singular value is less than SMIN, one element of (ca A - w D) will be perturbed enough to make the smallest singular value roughly SMIN. If both singular values are at least SMIN, (ca A - w D) will not be perturbed. In any case, the perturbation will be at most some small multiple of max( SMIN, ulp*norm(ca A - w D) ). The singular values are computed by infinity-norm approximations, and thus will only be correct to a factor of 2 or so.

Note: all input quantities are assumed to be smaller than overflow by a reasonable factor. (See BIGNUM.)
