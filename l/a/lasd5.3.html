الوظائف


روتين فرعي dlasd5 (i, d, z, delta, rho, dsigma, work)
DLASD5 تحسب الجذر التربيعي للقيمة الذاتية i-th للتعديل المتماثل الإيجابي من الرتبة الأولى لمصفوفة قطرية 2x2. تستخدم بواسطة sbdsdc. روتين فرعي slasd5 (i, d, z, delta, rho, dsigma, work)
SLASD5 تحسب الجذر التربيعي للقيمة الذاتية i-th للتعديل المتماثل الإيجابي من الرتبة الأولى لمصفوفة قطرية 2x2. تستخدم بواسطة sbdsdc.

الوصف التفصيلي

توثيق الوظيفة

روتين فرعي dlasd5 (integer i, double precision, dimension( 2 ) d, double precision, dimension( 2 ) z, double precision, dimension( 2 ) delta, double precision rho, double precision dsigma, double precision, dimension( 2 ) work)

DLASD5 تحسب الجذر التربيعي للقيمة الذاتية i-th للتعديل المتماثل الإيجابي من الرتبة الأولى لمصفوفة قطرية 2x2. تستخدم بواسطة sbdsdc.

الغرض:

!>
!> يقوم هذا الروتين الفرعي بحساب الجذر التربيعي للقيمة الذاتية I-th
!> لتعديل متماثل إيجابي من الرتبة الأولى لمصفوفة قطرية 2x2
!>
!>            diag( D ) * diag( D ) +  RHO * Z * transpose(Z) .
!>
!> يفترض أن تكون المدخلات القطرية في المصفوفة D تحقق
!>
!>            0 <= D(i) < D(j)  لـ  i < j .
!>
!> نفترض أيضًا أن RHO > 0 وأن المعيار الإقليدي للمتجه
!> Z هو واحد.
!>

المعاملات

I 
!>          I هو عدد صحيح
!>         فهرس القيمة الذاتية المطلوب حسابها.  I = 1 أو I = 2.
!>

D

!>          D هي مصفوفة double precision، بعد ( 2 )
!>         القيم الذاتية الأصلية. نفترض 0 <= D(1) < D(2).
!>

Z

!>          Z هي مصفوفة double precision، بعد ( 2 )
!>         مكونات المتجه المحدث.
!>

DELTA

!>          DELTA هي مصفوفة double precision، بعد ( 2 )
!>         تحتوي على (D(j) - sigma_I) في مكونها j.
!>         المتجه DELTA يحتوي على المعلومات اللازمة
!>         لبناء المتجهات الذاتية.
!>

RHO

!>          RHO هو double precision
!>         المقياس في صيغة التحديث المتماثل.
!>

DSIGMA

!>          DSIGMA هو double precision
!>         القيمة المحسوبة sigma_I، القيمة الذاتية المحدثة I-th.
!>

WORK

!>          WORK هي مصفوفة double precision، بعد ( 2 )
!>         تحتوي WORK على (D(j) + sigma_I) في مكونها j.
!>
