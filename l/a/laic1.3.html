laic1(3) دليل وظائف المكتبة laic1(3)

الاسم

laic1 - laic1: تقدير الشرط، خطوة في gelsy

الملخص

الوظائف


إجراء فرعي claic1 (job, j, x, sest, w, gamma, sestpr, s, c)
CLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي. إجراء فرعي dlaic1 (job, j, x, sest, w, gamma, sestpr, s, c)
DLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي. إجراء فرعي slaic1 (job, j, x, sest, w, gamma, sestpr, s, c)
SLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي. إجراء فرعي zlaic1 (job, j, x, sest, w, gamma, sestpr, s, c)
ZLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي.

الوصف التفصيلي

وثائق الوظائف

إجراء فرعي claic1 (job صحيح، j صحيح، مركب، بعد (j) x، صحيح sest، مركب، بعد (j) w، مركب gamma، صحيح sestpr، مركب s، مركب c)

CLAIC1 يطبق خطوة واحدة لتقدير الشرط.

الغرض:

!>
!> CLAIC1 يطبق خطوة واحدة لتقدير الشرط التزايدي في
!> أبسط نسخة له:
!>
!> ليكن x، twonorm(x) = 1، متجهًا منفردًا تقريبيًا لمصفوفة مثلثية سفلية L بحجم j*j، بحيث
!>          twonorm(L*x) = sest
!> ثم تحسب CLAIC1 sestpr، s، c بحيث
!> المتجه
!>                 [ s*x ]
!>          xhat = [  c  ]
!> هو متجه منفرد تقريبي للمصفوفة
!>                 [ L      0  ]
!>          Lhat = [ w**H gamma ]
!> بمعنى أن
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> اعتمادًا على JOB، يتم حساب تقدير للقيمة المنفردة الأكبر أو الأصغر.
!>
!> لاحظ أن [s c]**H و sestpr**2 هما زوج قيمي خاص للنظام
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> حيث alpha =  x**H*w.
!>
