!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي المثلثي للمصفوفة
!>          الهرميتية A مخزنًا.
!>          = 'U':  مثلث علوي
!>          = 'L':  مثلث سفلي
!>

N

!>          N هو صحيح INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

AP

!>          AP هو مصفوفة COMPLEX، البعد (N*(N+1)/2)
!>          عند الدخول، المثلث العلوي أو السفلي للمصفوفة الهرميتية
!>          A، مضغوطة عموديًا في مصفوفة خطية. العمود j من A
!>          مخزن في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>
!>          عند الخروج، المصفوفة المعادلة:  diag(S) * A * diag(S)، بنفس
!>          تنسيق التخزين مثل A.
!>

S

!>          S هي مصفوفة REAL، البعد (N)
!>          عوامل القياس للمصفوفة A.
!>

SCOND

!>          SCOND هو REAL
!>          نسبة أصغر S(i) إلى أكبر S(i).
!>

AMAX

!>          AMAX هو REAL
!>          القيمة المطلقة لأكبر عنصر في المصفوفة.
!>

EQUED

!>          EQUED هو CHARACTER*1
!>          يحدد ما إذا تم إجراء المعادلة أم لا.
!>          = 'N':  لم يتم إجراء المعادلة.
!>          = 'Y':  تم إجراء المعادلة، أي تم استبدال A بـ
!>                  diag(S) * A * diag(S).
!>

المعلمات الداخلية:

!>  THRESH هي قيمة حد تستخدم لتحديد ما إذا كان يجب إجراء القياس
!>  بناءً على نسبة عوامل القياس. إذا كان SCOND < THRESH،
!>  يتم إجراء القياس.
!>
!>  LARGE و SMALL هي قيم حدود تستخدم لتحديد ما إذا كان يجب إجراء القياس
!>  بناءً على الحجم المطلق لأكبر عنصر في المصفوفة.
!>  إذا كان AMAX > LARGE أو AMAX < SMALL، يتم إجراء القياس.
!>

NAME


laqhp


LAPACK routine






SYNOPSIS


 SUBROUTINE LAQHP( UPLO, EQUED, N, H, LDH, S, ROWCND, AMAX, EQUED2 )



In modern Fortran:


 SUBROUTINE LAQHP( UPLO, EQUED, N, H, LDH, S, ROWCND, AMAX, EQUED2 )







Detailed Description


This routine is part of the LAPACK routines for computing the
    Schur factorization of a general matrix. It is used in conjunction with
    routines like `SCHKFA` and `ZCHKFA`.


The routine is intended to be used to check the accuracy of the
    Schur factorization of a general matrix. It is called by the LAPACK
    routines `LAQHP` and `LAQP`. It is also called by `LAQSP` and `LAQGP`.


The routine is designed to provide an estimate of the condition
    number of the triangular factor of the Schur factorization. This condition
    number is used to determine whether the factorization is accurate.


The routine takes as input the upper or lower triangular factor
    of the Schur factorization, denoted by H, and the scaling factors,
    denoted by S. It also takes as input the row condition number, denoted by
    ROWCND, and the maximum absolute value of the elements in H, denoted by
    AMAX.


The routine returns the scaled triangular factor, denoted by
    EQUED2, which is used to compute the condition number of the triangular
    factor.






Function Documentation


  SUBROUTINE LAQHP( UPLO, EQUED, N, H, LDH, S, ROWCND, AMAX, EQUED2 )



Purpose:


To compute the scaled Schur factorization of a general matrix H,
    and to estimate the condition number of the triangular factor.


Arguments:




UPLO


CHARACTER*1.
    
Specifies whether the matrix H is upper or lower triangular.

    
UPLO = 'U' or 'u': H is upper triangular.

    
UPLO = 'L' or 'l': H is lower triangular.




EQUED


CHARACTER*1.
    
Specifies whether the matrix H has been scaled.

    
EQUED = 'Y' or 'y': H has been scaled.

    
EQUED = 'N' or 'n': H has not been scaled.




N


INTEGER.
    
The order of the matrix H. N >= 0.




H


DOUBLE PRECISION array, dimension (LDH, N).


LDH


INTEGER.
    
The leading dimension of the array H. LDH >= max(1, N).




S


DOUBLE PRECISION array, dimension (N).


ROWCND


DOUBLE PRECISION.


AMAX


DOUBLE PRECISION.


EQUED2


CHARACTER*1.
    
Specifies whether the matrix H has been scaled.

    
EQUED2 = 'Y' or 'y': H has been scaled.

    
EQUED2 = 'N' or 'n': H has not been scaled.
