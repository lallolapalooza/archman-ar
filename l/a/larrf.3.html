NAME

larrf

LAPACK routine to find eigenvalues and eigenvectors of a symmetric tridiagonal matrix

SYNOPSIS

 SUBROUTINE LARRF(N, D, L, LD, CLSTRT, CLEND, W, WGAP, WERR, SPDIAM,
                 CLGAPL, CLGAPR, PIVMIN, SIGMA, DPLUS, LPLUS, WORK, INFO)

Parameters

N
INTEGER

The number of rows and columns of the matrix A.

D
REAL array, dimension (N)

The diagonal elements of the tridiagonal matrix A.

L
REAL array, dimension (N-1)

The subdiagonal elements of the tridiagonal matrix A.

LD
REAL array, dimension (N-1)

The (N-1) elements L(i)*D(i).

CLSTRT
INTEGER

The index of the first eigenvalue in the cluster.

CLEND
INTEGER

The index of the last eigenvalue in the cluster.

W
REAL array, dimension

dimension is >= (CLEND-CLSTRT+1)

The eigenvalue APPROXIMATIONS of L D L^T in ascending order.

W( CLSTRT ) through W( CLEND ) form the cluster of relatively close eigenalues.

WGAP
REAL array, dimension

dimension is >= (CLEND-CLSTRT+1)

The separation from the right neighbor eigenvalue in W.

WERR
REAL array, dimension

dimension is >= (CLEND-CLSTRT+1)

WERR contain the semiwidth of the uncertainty interval of the corresponding eigenvalue APPROXIMATION in W

SPDIAM
REAL

estimate of the spectral diameter obtained from the Gerschgorin intervals

CLGAPL
REAL
CLGAPR
REAL

absolute gap on each end of the cluster.

Set by the calling routine to protect against shifts too close to eigenvalues outside the cluster.

PIVMIN
REAL

The minimum pivot allowed in the Sturm sequence.

SIGMA
REAL

The shift used to form L(+) D(+) L(+)^T.

DPLUS
REAL array, dimension (N)

The N diagonal elements of the diagonal matrix D(+).

LPLUS
REAL array, dimension (N-1)

The first (N-1) elements of LPLUS contain the subdiagonal elements of the unit bidiagonal matrix L(+).

WORK
REAL array, dimension (2*N)

Workspace.

INFO
INTEGER

Signals processing OK (=0) or failure (=1)

Detailed Description

This routine is part of the LAPACK routine DLARRF, which is used to find eigenvalues of a symmetric tridiagonal matrix. Specifically, this routine is responsible for computing the information about a cluster of relatively close eigenvalues.

The matrix A is implicitly defined by its diagonal elements D and subdiagonal elements L.

The routine works with a shifted and possibly down- or up-dated matrix A-sigma*I = L(+) D(+) L(+)^T, where sigma is a shift. The information about the eigenvalues and their approximate locations is provided in the arrays W, WGAP, and WERR.

The parameters CLGAPL and CLGAPR are used to control the shifts to avoid numerical issues with eigenvalues outside the cluster.

The parameter PIVMIN is the minimum pivot allowed in the Sturm sequence calculation, which is crucial for the stability of the eigenvalue computation.

SPDIAM is an estimate of the spectral diameter, which gives an idea of the spread of the eigenvalues.

The routine returns INFO=0 if the computation is successful, and INFO=1 otherwise.
