NAME

lanhp — calculates the norm of a general band matrix

SYNOPSIS

       SUBROUTINE LANHP( NORM, UPLO, N, AP, WORK, INFO )

           CHARACTER          NORM, UPLO
           INTEGER            N, INFO
           DOUBLE PRECISION   AP( * ), WORK( * )

Detailed Description

LANHP calculates one of the norms of an upper or lower triangular band matrix.

Input Parameters

NORM

NORM is CHARACTER*1

Specifies the value to be computed:

'E'

Computes the Euclidean norm: ||A||2 = sqrt(sum(abs(Aij)**2)).

'1'

Computes the 1-norm: ||A||1 = maxj(sumi(abs(Aij))).

'I'

Computes the infinity-norm: ||A||inf = maxi(sumj(abs(Aij))).

'M'

Computes the maximum absolute value of the elements of A. This is not a true norm.

UPLO

UPLO is CHARACTER*1

Specifies whether the matrix A is upper or lower triangular:

'U'

Upper triangular band matrix.

'L'

Lower triangular band matrix.

N

N is INTEGER

The order of the matrix A. N >= 0. When N = 0, LANHP is set to zero.

AP

AP is DOUBLE PRECISION array, dimension (N*(N+1)/2)

The upper or lower triangle of the symmetric matrix A, packed columnwise in a linear array. The j-th column of A is stored in the array AP as follows:

if UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) for 1<=i<=j;

if UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) for j<=i<=n.

WORK

WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)), where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise, WORK is not referenced.

الوصف المفصل

LANHP يحسب أحد معايير المصفوفة المثلثية العليا أو السفلى المستطيلة.

معلمات الإدخال

NORM

NORM هو CHARACTER*1

يحدد القيمة المراد حسابها:

'E'

يحسب المعيار الإقليدي: ||A||2 = sqrt(sum(abs(Aij)**2)).

'1'

يحسب المعيار 1: ||A||1 = maxj(sumi(abs(Aij))).

'I'

يحسب المعيار اللانهائي: ||A||inf = maxi(sumj(abs(Aij))).

'M'

يحسب أقصى قيمة مطلقة لعناصر A. هذا ليس معيارًا حقيقيًا.

UPLO

UPLO هو CHARACTER*1

يحدد ما إذا كانت المصفوفة A مثلثية عليا أم سفلى:

'U'

مصفوفة مثلثية عليا مستطيلة.

'L'

مصفوفة مثلثية سفلى مستطيلة.

N

N هو INTEGER

رتبة المصفوفة A. N >= 0. عندما N = 0، يتم تعيين LANHP إلى الصفر.

AP

AP هو مصفوفة DOUBLE PRECISION، حجمها (N*(N+1)/2)

المثلث العلوي أو السفلي للمصفوفة المتماثلة A، مجمعة عمودياً في مصفوفة خطية. يتم تخزين العمود j للمصفوفة A في المصفوفة AP كما يلي:

إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j;

إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.

WORK

WORK هو مصفوفة DOUBLE PRECISION، حجمها (MAX(1,LWORK)), حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'. بخلاف ذلك، لا يتم الرجوع إلى WORK.
