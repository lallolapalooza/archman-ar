--floattype=markstyle\n or -f markstyle
\n
Add code to preamble for selected style which replace standard marking and\n markup commands within floats (e.g., marginal remarks cause an error\n within floats so marginal marking can be disabled thus). This option\n defines all "\\DIF...FL" commands.\n Available styles: "FLOATSAFE TRADITIONALSAFE\n IDENTICAL"\n

--encoding=enc\n or -e enc
\n
Specify encoding of old.tex and new.tex. Typical encodings are\n "ascii",\n "utf8",\n "latin1",\n "latin9". A list of available encodings\n can be obtained by executing\n

"perl -MEncode -e 'print join\n ("\\n",Encode-"encodings( ":all" )) ;' >

\n

If this option is used, then old.tex, new.tex are only opened\n once. [Default encoding is utf8 unless the first few lines of the\n preamble contain an invocation\n "\\usepackage[..]{inputenc}" in which\n case the encoding chosen by this command is asssumed. Note that ASCII\n (standard latex) is a subset of utf8]

\n
\n
--preamble=file\n or -p file
\n
Insert file at end of preamble instead of generating preamble. The\n preamble must define the following commands\n "\\DIFaddbegin, \\DIFaddend, \\DIFadd{..},\n \\DIFdelbegin,\\DIFdelend,\\DIFdel{..}," and\n varieties for use within floats "\\DIFaddbeginFL,\n \\DIFaddendFL, \\DIFaddFL{..},\n \\DIFdelbeginFL, \\DIFdelendFL, \\DIFdelFL{..}" (If this option is set -t,\n -s, and -f options are ignored.)
\n
--packages=pkg1,pkg2,..
\n
Tell latexdiff that .tex file is processed with the packages in list\n loaded. This is normally not necessary if the .tex file includes the\n preamble, as the preamble is automatically scanned for\n "\\usepackage" commands. Use of the\n --packages option disables automatic scanning, so if for any reason\n package specific parsing needs to be switched off, use\n --packages=none. The following packages trigger special\n behavior:

"endfloat"
\n
Ensure that "\\begin{figure}" and\n "\\end{figure}" always appear by\n themselves on a line.

"hyperref"
\n
Change name of "\\DIFadd" and\n "\\DIFdel" commands to\n "\\DIFaddtex" and\n "\\DIFdeltex" and define new\n "\\DIFadd" and\n "\\DIFdel" commands, which provide a\n wrapper for these commands, using them for the text but not for the link\n defining command (where any markup would cause errors).

"apacite", "biblatex"

"siunitx"

\n

"glossaries"
\n
Define most of the glossaries commands as safe, protecting them with\n \\mbox'es where needed
\n
"mhchem"

\n
"chemformula" or "chemmacros"

--append-safecmd=append-file\n or -a append-file or\n --append-safecmd="cmd1,cmd2,..."
\n
Exclude from, replace or append to the list of regular expressions (RegEx)\n matching commands which are safe to use within the scope of a\n "\\DIFadd" or\n "\\DIFdel" command. The file must contain\n one Perl-RegEx per line (Comment lines beginning with # or % are ignored).\n Note that the RegEx needs to match the whole of the token, i.e., /^regex$/\n is implied and that the initial "\\" of the command is not\n included. The --exclude-safecmd and --append-safecmd options\n can be combined with the ---replace-safecmd option and can be used\n repeatedly to add cumulatively to the lists.\n
\n --exclude-safecmd and --append-safecmd can also take a comma\n separated list as input. If a comma for one of the regex is required, \n escape it thus "\\,". In most cases it will be necessary to\n protect the comma-separated list from the shell by putting it in quotation\n marks.

Other configuration options:

\n
\n
--allow-spaces
\n
\n Allow spaces between bracketed or braced arguments to commands. Note that\n this option might have undesirable side effects (unrelated scope might get\n lumpeded with preceding commands) so should only be used if the default\n produces erroneous results. (Default requires arguments to directly follow\n each other without intervening spaces).\n
\n
--math-markup=level
\n
\n Determine granularity of markup in displayed math environments: Possible\n values for level are (both numerical and text labels are acceptable):\n

"off" or\n 0: suppress markup for math environments.\n Deleted equations will not appear in diff file. This mode can be used if\n all the other modes cause invalid latex code.

\n

"whole" or\n 1: Differencing on the level of whole equations.\n Even trivial changes to equations cause the whole equation to be marked\n changed. This mode can be used if processing in coarse or fine mode\n results in invalid latex code.

\n

"coarse" or\n 2: Detect changes within equations marked up\n with a coarse granularity; changes in equation type (e.g.displaymath to\n equation) appear as a change to the complete equation. This mode is\n recommended for situations where the content and order of some equations\n are still being changed. [Default]

\n

"fine" or\n 3: Detect small change in equations and mark up\n at fine granularity. This mode is most suitable, if only minor changes\n to equations are expected, e.g. correction of typos.

\n
\n
--graphics-markup=level
\n
\n 
Change highlight style for graphics embedded with C<\\includegraphics> commands.\n
\n

Possible values for level:

\n

"none",\n "off" or 0: no\n highlighting for figures

\n

"new-only" or\n 1: surround newly added or changed figures with\n a blue frame [Default if graphicx package loaded]

\n

"both" or\n 2: highlight new figures with a blue frame and\n show deleted figures at reduced scale, and crossed out with a red\n diagonal cross. Use configuration variable SCALEDELGRAPHICS to set size\n of deleted figures.

\n

Note that changes to the optional parameters will make the\n figure appear as changed to latexdiff, and this figure will thus be\n highlighted.

\n

In some circumstances \"Misplaced \\noalign\" error can\n occur if there are certain types of changes in tables. In this case\n please use "--graphics-markup=none" as\n a work-around.

\n
\n
--no-del
\n
\n Suppress deleted text from the diff. It is similar in effect to the BOLD\n style, but the deleted text ist not just invisible in the output, it is\n also not included in the diff text file. This can be more robust than just\n making it invisible.\n
\n
--disable-citation-markup\n or --disable-auto-mbox
\n
Suppress citation markup and markup of other vulnerable commands in styles\n using ulem (UNDERLINE,FONTSTRIKE, CULINECHBAR) (the two options are\n identical and are simply aliases)
\n

إعادة تعريف الأنماط

الأنواع الرئيسية

يحدد النوع الرئيسي ترميز النص العادي وبعض أوامر لاتكس المختارة خارج العوامات عن طريق تعريف أوامر الترميز "\DIFadd{...}" و "\DIFdel{...}".

"UNDERLINE"
النص المضاف يكون بخط سفلي متموج وأزرق، والنص المحذوف يكون مشطوبًا وأحمر (يتطلب حزمتي color و ulem). لا تعمل الكتابة فوق النص في معادلات الرياضيات المعروضة بحيث يتم وضع خط سفلي تحت الأجزاء المحذوفة من المعادلة، وليس خطًا مشطوبًا (هذا قيد متأصل في حزمة ulem).
"LUAUNDERLINE"
النص المضاف يكون بخط سفلي وأزرق، والنص المحذوف يكون مشطوبًا وأحمر (يتطلب حزمة lua-ul + LuaLaTeX).
"CTRADITIONAL"
النص المضاف يكون أزرق وفي خط sans-serif، ويتم إنشاء ملاحظة سفلية حمراء لكل جزء نصي محذوف. (يتطلب حزمة color)
"TRADITIONAL"
مثل "CTRADITIONAL" ولكن بدون استخدام الألوان.
"CFONT"
النص المضاف يكون أزرق وفي خط sans-serif، والنص المحذوف يكون أحمر وبحجم صغير جدًا.
"FONTSTRIKE"
النص المضاف يكون في خط sans-serif، والنص المحذوف صغير ومشطوب.
"CCHANGEBAR"
النص المضاف يكون أزرق، والنص المحذوف يكون أحمر. بالإضافة إلى ذلك، يتم تمييز النص المتغير بشريط في الهامش (يتطلب حزمتي color و changebar).
"CFONTCHBAR"
مثل "CFONT" ولكن مع أشرطة تغيير إضافية (يتطلب حزمتي color و changebar).
"CULINECHBAR"
مثل "UNDERLINE" ولكن مع أشرطة تغيير إضافية (يتطلب حزم color و ulem و changebar).
"CHANGEBAR"
لا يتم ترميز النص، ولكن يتم تمييز الهوامش بأشرطة تغيير (يتطلب حزمة changebar).
"INVISIBLE"
لا يوجد ترميز مرئي (ولكن سيتم إدراج أوامر الترميز العامة).
"BOLD"
النص المضاف يكون بخط عريض، والنص المحذوف لا يظهر. (انظر أيضًا خيار --no-del لإمكانية أخرى لإخفاء النص المحذوف)
"PDFCOMMENT"
تستخدم حزمة pdfcomment لوضع خط سفلي للنص الجديد، وتمييز الحذفات بتعليق PDF. لاحظ أن هذا الترميز قد يظهر بشكل مختلف أو لا يظهر على الإطلاق اعتمادًا على عارض PDF المستخدم. من المحتمل أن يكون عارض acroread هو الأفضل دعمًا لترميز PDF. يوصى بهذا النمط فقط إذا كان عدد الاختلافات صغيرًا.

الأنواع الفرعية

يحدد النوع الفرعي الأوامر التي يتم إدراجها في بداية ونهاية الكتل المضافة أو المحذوفة، بغض النظر عما إذا كانت هذه الكتل تحتوي على نص أو أوامر (الأوامر المحددة: "\DIFaddbegin, \DIFaddend, \DIFdelbegin, \DIFdelend").

"SAFE"
لا يوجد ترميز إضافي (الخيار الموصى به)
"MARGIN"
وضع علامات على بداية ونهاية الكتل المتغيرة برموز في الهامش المجاور (باستخدام الأمر القياسي "\marginpar" - ملاحظة أن هذا أحيانًا يتحرك قليلاً عن الموضع المقصود).
"COLOR"
طريقة بديلة لوضع علامات على المقاطع المضافة باللون الأزرق، والمقاطع المحذوفة باللون الأحمر. (يوصى باستخدام الأنواع الرئيسية بدلاً من ذلك لإحداث ترميز لوني، على الرغم من أنه في بعض الحالات يمكن أن يكون التلوين باستخدام dvipscol أكثر اكتمالاً، على سبيل المثال مع أوامر الاقتباس).
"DVIPSCOL"
طريقة بديلة لوضع علامات على المقاطع المضافة باللون الأزرق، والمقاطع المحذوفة باللون الأحمر. لاحظ أن "DVIPSCOL" يعمل فقط مع محول dvips، على سبيل المثال لا يعمل مع pdflatex. (يوصى باستخدام الأنواع الرئيسية بدلاً من ذلك لإحداث ترميز لوني، على الرغم من أنه في بعض الحالات يمكن أن يكون التلوين باستخدام dvipscol أكثر اكتمالاً).
"ZLABEL"
يمكن استخدامه لتمييز الصفحات المتغيرة فقط، ولكنه يتطلب معالجة لاحقة. يوصى بعدم استدعاء هذا الخيار يدويًا ولكن استخدام "latexdiff-vc" مع الخيار "--only-changes". بدلاً من ذلك، استخدم البرنامج النصي الموجود داخل مقدمة ملفات diff التي تم إنشاؤها باستخدام هذا النمط.
"ONLYCHANGEDPAGE"
يميز أيضًا الصفحات المتغيرة، دون الحاجة إلى معالجة لاحقة، ولكنه قد لا يعمل بشكل موثوق إذا كانت هناك مواد عائمة (صور، جداول).
"LABEL"
مشابه لـ "ZLABEL"، ولكنه لا يحتاج إلى حزمة zref ويعمل بشكل أقل موثوقية (مهمل).

أنواع العوامات

قد تسبب بعض الترميزات المستخدمة في النص الرئيسي مشاكل عند استخدامها داخل العوامات (مثل الصور أو الجداول). لهذا السبب، يتم استخدام إصدارات بديلة لجميع أوامر الترميز داخل العوامات. يحدد نوع العوامة هذه الأوامر البديلة.

"FLOATSAFE"
استخدم ترميزًا مطابقًا للنص كما في النص الرئيسي، ولكن اجعل جميع الأوامر التي تميز بداية ونهاية الكتل المتغيرة أوامر فارغة. يجب عليك اختيار نوع العوامة هذا إذا كان نوعك الفرعي هو "MARGIN" لأن "\marginpar" لا يعمل بشكل صحيح داخل العوامات.
"TRADITIONALSAFE"
تمييز الإضافات بنفس طريقة النص الرئيسي. يتم تمييز البيئات المحذوفة بأقواس زاوية \[ و \] ويتم ضبط النص المحذوف بحجم scriptscript. يجب استخدام نوع العوامة هذا دائمًا مع أنواع الترميز "TRADITIONAL" و "CTRADITIONAL" لأن الأمر \footnote لا يعمل بشكل صحيح في البيئات العائمة.
"IDENTICAL"
لا يوجد فرق بين النص الرئيسي والعوامات.

مشاكل شائعة ودليل أسئلة متكررة

تغيير الاقتباسات يؤدي إلى صناديق مفرطة
يوجد عدم توافق بين حزمة "ulem"، التي تستخدمها "latexdiff" للتسطير والشطب في نمط UNDERLINE، النمط الافتراضي، وطريقة إنشاء الاقتباسات. لكي نتمكن من تمييز الاقتباسات بشكل صحيح، يتم تغليفها بأمر "\mbox". نظرًا لأنه لا يمكن تقسيم mboxes عبر الأسطر، فإن هذه الإجراءات غالبًا ما تؤدي إلى صناديق مفرطة، مما قد يحجب المحتوى لأنه يتجاوز الهامش الأيمن. يحدث الشيء نفسه مع بعض الحزم الأخرى (مثل siunitx). إذا كان هذا يمثل مشكلة، فلديك عدة خيارات.

1. استخدم علامة "CFONT" (الخيار "-t CFONT"): إذا تم اختيار علامة التمييز هذه، فلن يتم تمييز الاقتباسات المتغيرة بعد الآن بالخط المتعرج (الإضافات) أو الشطب (الحذف)، ولكن لا تزال مميزة بالألوان المناسبة، ويتم عرض النص المحذوف بخط مختلف. ستعمل الأنماط الأخرى التي لا تستخدم حزمة "ulem" أيضًا.

2. اختر الخيار "--disable-citation-markup" الذي يقوم بإيقاف تمييز الاقتباسات: لن يتم عرض الاقتباسات المحذوفة بعد الآن، وسيتم عرض الاقتباسات المضافة بدون علامات تمييز. (كان هذا هو السلوك الافتراضي لـ latexdiff في الإصدارات 0.6 والأقدم). بالنسبة للحزم المخصصة، يمكنك تحديد الأوامر التي تحتاج إلى حمايتها بواسطة "\mbox" باستخدام خيارات "--append-mboxsafecmd" و "--excludemboxsafecmd" (قدم قوائم الأوامر الخاصة بك كطلب ميزة على صفحة github لتعيين السلوك الافتراضي للإصدارات المستقبلية، انظر القسم 6)

3. إذا كنت تستخدم luatex >= 1.12.0، يمكنك استخدام الخيار LUAUNDERLINE الذي يستخدم lua-ul بدلاً من ulem للتسطير، والذي لا يحتوي على هذه المشكلة (ميزة تجريبية).

التغييرات في المعادلات الرياضية المعقدة تؤدي إلى أخطاء في معالجة لاتيك.
جرب الخيار "--math-markup=whole". إذا فشل ذلك أيضًا، يمكنك إيقاف تمييز المعادلات باستخدام "--math-markup=off".
الأجزاء المحذوفة في المعادلات لا يتم شطبها بل تسطيرها.
هذا قيد لحزمة ulem التي تنفذ الشطب. إذا كنت تستخدم حزمة amsmath، فسيتم إعادة تعريف أمر الشطب بطريقة يتم فيها تغليف المقاطع المحذوفة بأمر "\text"؛ إضافة "\usepackage{amsmath}" إلى مقدمتك سيؤدي إلى تشغيل هذا السلوك. (إذا لم يتم تضمين amsmath مباشرة، ولكن تم استيرادها بواسطة حزمة أخرى، فلن يتمكن latexdiff من اكتشاف توفرها؛ في هذه الحالة، يمكنك إعطاء latexdiff تلميحًا باستخدام الخيار "--packages=amsmath".
كيف يمكنني فقط عرض الصفحات التي حدثت فيها تغييرات؟
استخدم الخيارين "--s ZLABEL" (يتطلب بعض المعالجة اللاحقة) أو "-s ONLYCHANGEDPAGE". يتولى "latexdiff-vc --ps|--pdf" مع الخيار "--only-changes" المعالجة اللاحقة لك (يتطلب تثبيت حزمة zref).
ترميز الأحرف يتعطل عند تشغيل latexdiff من powershell.
هذه المشكلة لا تقتصر على "latexdiff" وتتعلق بالإعدادات الافتراضية لـ "powershell" في Windows. يوصى باستخدام "cmd" بدلاً من ذلك.

الأخطاء

الخيار allow-spaces غير مطبق بشكل كامل ومتسق. إنه يكسر القواعد التي لا تهتم فيها الأرقام وأنواع المسافات البيضاء، حيث يتم التعامل مع أعداد مختلفة من المسافات بين الوسيطات على أنها مهمة.

يرجى الإبلاغ عن الأخطاء باستخدام متعقب المشكلات على صفحة مستودع github https://github.com/ftilmann/latexdiff.git، أو إرسالها إلى tilmann -- AT -- gfz-potsdam.de. قم بتضمين رقم إصدار latexdiff (من التعليقات في أعلى المصدر أو استخدم --version). إذا صادفت ملفات latex خالية من الأخطاء وتتوافق مع المواصفات الموضحة أعلاه، ولا يزال تفريقها لا ينتج عنه latex خالٍ من الأخطاء، فيرجى إرسال تلك الملفات إلي، ويفضل أن تكون معدلة لتشمل فقط المقطع المخالف طالما أنه لا يزال يعيد إنتاج المشكلة. إذا كان ملفك يعتمد على ملفات فئات غير قياسية، فيجب عليك تضمينها. لن أنظر في الأمثلة التي أواجه فيها صعوبة في تشغيل الملفات الأصلية.

قابلية النقل

latexdiff لا تستخدم أوامر خارجية وبالتالي يجب أن تعمل على أي منصة تدعم Perl 5.6 أو أعلى. إذا تمت معالجة ملفات بترميزات أخرى غير ASCII أو UTF-8، فيجب أن يكون Perl 5.8 أو أعلى مطلوبًا.

يتطلب الإصدار القياسي من latexdiff تثبيت حزمة Perl "Algorithm::Diff" (متاحة من www.cpan.org - http://search.cpan.org/~nedkonz/Algorithm-Diff-1.15) ولكن هناك أيضًا إصدار مستقل، latexdiff-so، الذي يحتوي على هذه الحزمة مضمنة. يتطلب latexdiff-fast وجود الأمر diff.
