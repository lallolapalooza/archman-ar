CLAQPS تحسب خطوة من تحليل QR مع تثبيت الأعمدة لمصفوفة حقيقية m-by-n A باستخدام BLAS المستوى 3.

الغرض:

!>
!> CLAQPS تحسب خطوة من تحليل QR مع تثبيت الأعمدة
!> لمصفوفة A حقيقية m-by-n باستخدام BLAS-3. تحاول تحليل
!> NB عمودًا من A بدءًا من الصف OFFSET+1، وتحدث جميع
!> المصفوفة باستخدام BLAS-3 xGEMM.
!>
!> في بعض الحالات، بسبب إلغاءات كارثية، لا يمكنها
!> تحليل NB عمودًا. لذلك، يتم إرجاع العدد الفعلي للأعمدة المحللة
!> في KB.
!>
!> الكتلة A(1:OFFSET,1:N) يتم تثبيتها بشكل مناسب، ولكن لا يتم تحليلها.
!>

subroutine slaqps (integer m, integer n, integer offset, integer nb, integer kb, real, dimension( lda, * ) a, integer lda, integer, dimension( * ) jpvt, real, dimension( * ) tau, real, dimension( * ) vn1, real, dimension( * ) vn2, real, dimension( * ) auxv, real, dimension( ldf, * ) f, integer ldf)

SLAQPS computes a step of QR factorization with column pivoting of a real m-by-n matrix A by using BLAS level 3.

Purpose:

!>
!> SLAQPS computes a step of QR factorization with column pivoting
!> of a real M-by-N matrix A by using Blas-3.  It tries to factorize
!> NB columns from A starting from the row OFFSET+1, and updates all
!> of the matrix with Blas-3 xGEMM.
!>
!> In some cases, due to catastrophic cancellations, it cannot
!> factorize NB columns.  Hence, the actual number of factorized
!> columns is returned in KB.
!>
!> Block A(1:OFFSET,1:N) is accordingly pivoted, but not factorized.
!>

Parameters

M 
!>          M is INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A. N >= 0
!>

OFFSET

!>          OFFSET is INTEGER
!>          The number of rows of A that have been factorized in
!>          previous steps.
!>

NB

!>          NB is INTEGER
!>          The number of columns to factorize.
!>

KB

!>          KB is INTEGER
!>          The number of columns actually factorized.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the M-by-N matrix A.
!>          On exit, block A(OFFSET+1:M,1:KB) is the triangular
!>          factor obtained and block A(1:OFFSET,1:N) has been
!>          accordingly pivoted, but no factorized.
!>          The rest of the matrix, block A(OFFSET+1:M,KB+1:N) has
!>          been updated.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

JPVT

!>          JPVT is INTEGER array, dimension (N)
!>          JPVT(I) = K <==> Column K of the full matrix A has been
!>          permuted into position I in AP.
!>

TAU

!>          TAU is REAL array, dimension (KB)
!>          The scalar factors of the elementary reflectors.
!>

VN1

!>          VN1 is REAL array, dimension (N)
!>          The vector with the partial column norms.
!>

VN2

!>          VN2 is REAL array, dimension (N)
!>          The vector with the exact column norms.
!>

AUXV

!>          AUXV is REAL array, dimension (NB)
!>          Auxiliary vector.
!>

F

!>

LDF

NAME

laqps - solves a general band matrix problem

SYNOPSIS

SUBROUTINE LAQPS(M, N, NB, A, LDA, D, E, U, LDU, V, LDV, INFO)
INTEGER M, N, NB, LDA, LDU, LDV, INFO
REAL A(LDA,*)
REAL D(N), E(N)
REAL U(LDU,*)
REAL V(LDV,*)

Detailed Description

The routine LAQPS is designed to solve the linear system of equations Ax = B, where A is a general band matrix. It uses a block cyclic reduction algorithm. The matrix A is decomposed into submatrices, and the solution is computed recursively. This routine is part of the LAPACK library, which provides routines for solving various linear algebra problems.

The parameters are as follows:

  • M: The number of rows of the matrix A.
  • N: The number of columns of the matrix A.
  • NB: The block size for the algorithm.
  • A: The band matrix A.
  • LDA: The leading dimension of the array A.
  • D: The diagonal elements of the matrix.
  • E: The subdiagonal elements of the matrix.
  • U: A work array for storing intermediate results.
  • LDU: The leading dimension of the array U.
  • V: A work array for storing intermediate results.
  • LDV: The leading dimension of the array V.
  • INFO: An integer output parameter indicating the status of the computation. 0 indicates success, a negative value indicates an error.

The routine modifies the input array A in-place and returns the solution in the array B (not explicitly shown in the synopsis but implied by the problem it solves). The arrays U and V are used for internal computations and are overwritten.

Refer to the LAPACK documentation for a more in-depth explanation of the algorithm and its mathematical underpinnings.

Function Documentation

The LAPACK routine `laqps` is part of the library's extensive collection of routines for dense and banded linear systems. It is specifically designed to handle the solution of band matrix problems, offering an efficient approach for such systems. The implementation details, including the exact numerical methods and error handling strategies, are documented within the official LAPACK user's guide. For precise usage and return value descriptions, consulting the LAPACK documentation is recommended.

This function is part of the LAPACK's banded solvers module. It leverages block cyclic reduction to solve the system efficiently. The algorithm's complexity and performance characteristics are dependent on the band width and the dimensions of the matrix.
