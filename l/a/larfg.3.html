وثائق الوظائف

subroutine clarfg (integer n, complex alpha, complex, dimension( * ) x, integer incx, complex tau)

CLARFG تولد عاكسًا أوليًا معقدًا (مصفوفة Householder).

الغرض:

!>
!> CLARFG تولد عاكسًا أوليًا معقدًا H من الرتبة n، بحيث
!>
!>       H**H * ( alpha ) = ( beta )،   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> حيث alpha و beta عددان، و beta حقيقي، و x متجه معقد مكون من (n-1) عنصر. يتم تمثيل H بالشكل
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ،
!>                     ( v )
!>
!> حيث tau عدد معقد و v متجه معقد مكون من (n-1) عنصر. لاحظ أن H ليس هيرميتيًا.
!>
!> إذا كانت جميع عناصر x صفرية و alpha حقيقية، فإن tau = 0 وتعتبر H مصفوفة الوحدة.
!>
!> بخلاف ذلك  1 <= real(tau) <= 2  و  abs(tau-1) <= 1 .
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>          رتبة العاكس الأولي.
!>

ALPHA

!>          ALPHA هو عدد مركب (COMPLEX)
!>          عند الإدخال، القيمة alpha.
!>          عند الخروج، يتم الكتابة فوقها بالقيمة beta.
!>

X

!>          X هو مصفوفة مركبة (COMPLEX array)، البعد
!>                         (1+(N-2)*abs(INCX))
!>          عند الإدخال، المتجه x.
!>          عند الخروج، يتم الكتابة فوقه بالمتجه v.
!>

INCX

!>          INCX هو عدد صحيح (INTEGER)
!>          الزيادة بين عناصر X. INCX > 0.
!>

TAU

!>          TAU هو عدد مركب (COMPLEX)
!>          القيمة tau.
!>
