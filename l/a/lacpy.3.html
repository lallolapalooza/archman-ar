NAME

lacpy - copies a matrix to another matrix

SYNOPSIS

    SUBROUTINE LACPY( UPLO, M, N, A, LDA, B, LDB )


    CHARACTER * 1           UPLO
    INTEGER                 M, N, LDA, LDB
    COMPLEX*16              A( LDA, N ), B( LDB, N )

Function Documentation

LACPY copies all or part of an m-by-n matrix A to an m-by-n matrix B.

Arguments

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies the part of the matrix A to be copied and               where
!>          on the matrix B.
!>
!>          = 'U':  Upper triangle of A is copied to the upper triangle of B.
!>          = 'L':  Lower triangle of A is copied to the lower triangle of B.
!>          Otherwise:  The entire matrix A is copied to the entire matrix B.
!>

M

!>          M is INTEGER
!>          The number of rows of the matrix A.  M >= 0.
!>

N

!>          N is INTEGER
!>          The number of columns of the matrix A.  N >= 0.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          The m by n matrix A.  If UPLO = 'U', only the upper trapezium
!>          is accessed; if UPLO = 'L', only the lower trapezium is
!>          accessed.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,M).
!>

B

!>          B is COMPLEX*16 array, dimension (LDB,N)
!>          On exit, B = A in the locations specified by UPLO.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(1,M).
!>
