NAME

latin2(7)

Latin-2 character set

DESCRIPTION

The ISO/IEC 8859-2 character set, often called Latin-2, is an eight-bit character set designed for the languages of Central and Eastern Europe. It extends the basic ASCII character set (0-127) with additional characters in the range 160-255 (0xA0-0xFF).
