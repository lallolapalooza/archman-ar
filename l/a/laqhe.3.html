NAME

ZLAQSY - The routine scales a symmetric matrix A.

SYNOPSIS

    SUBROUTINE ZLAQSY( UPLO, N, A, LDA, S, SCOND, AMAX, EQUED )

      CHARACTER * 1 UPLO
      INTEGER N
      COMPLEX*16 A( LDA, * )
      INTEGER LDA
      DOUBLE PRECISION S( * )
      DOUBLE PRECISION SCOND
      DOUBLE PRECISION AMAX
      CHARACTER * 1 EQUED

Function Documentation

ZLAQSY scales a symmetric matrix A by diagonal matrices D1, D2. The task is to compute a diagonal matrix D so that diag(S)*A*diag(S) = B is equilibrated, i.e. the largest element in each row and column of B has absolute value at most one. Then A is replaced by B, S(i) is the i-th diagonal element of D, and SCOND is the ratio of the smallest diagonal element of D to the largest. If S(i) = 0 then the i-th diagonal element of D is taken to be 1. In this case, the row and column i of A are not scaled, and SCOND is set to 0.

If the scaling operation would cause the matrix to overflow or underflow, it is performed by means of logarithms.

A symmetric matrix A may be replaced by diag(S)*A*diag(S) to improve the condition of A.

Arguments

UPLO

      CHARACTER*1 UPLO
      Specifies whether the upper or lower triangular part of the matrix A
      is supplied.

      UPLO = 'U': Upper triangular part
      UPLO = 'L': Lower triangular part

N

      INTEGER N
      The order of the matrix A.  N >= 0.

A

      COMPLEX*16 A( LDA, * )
      On entry, the n by n symmetric matrix A.  Only the UPLO part of A
      is referenced.

LDA

      INTEGER LDA
      The leading dimension of the array A.  LDA >= max(N,1).

S

      DOUBLE PRECISION S( * )
      The array S contains the diagonal elements of the desired diagonal
      scaling matrix D.

SCOND

      DOUBLE PRECISION SCOND
      On exit, if EQUED = 'Y', SCOND contains the ratio of the smallest
      element of S to the largest element of S.  If SCOND >= 1, then
      the matrix S is well-conditioned.

AMAX

      DOUBLE PRECISION AMAX
      On exit, AMAX is the absolute value of the largest matrix entry.

EQUED

      CHARACTER*1 EQUED
      On exit, EQUED specifies whether or not the equilibration was done.
      'EQUED' = 'N': No equilibration was done. A was not scaled.
      'EQUED' = 'Y': Equilibration was done. A has been replaced by
                  diag(S)*A*diag(S).

Internal Parameters:

!>  THRESH is a threshold value used to decide if scaling should be done
!>  based on the ratio of the scaling factors.  If SCOND < THRESH,
!>  scaling is done.
!>
!>  LARGE and SMALL are threshold values used to decide if scaling should
!>  be done based on the absolute size of the largest matrix element.
!>  If AMAX > LARGE or AMAX < SMALL, scaling is done.
