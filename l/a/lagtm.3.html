CLAGTM تقوم بإجراء ناتج ضرب مصفوفة-مصفوفة بالشكل C = αAB+βC، حيث A مصفوفة ثلاثية الأقطار، B و C مصفوفتان مستطيليتان، و α و β عددان قياسيان، قد يكونان 0، 1، أو -1.

الغرض:

!>
!> CLAGTM تقوم بإجراء ناتج ضرب مصفوفة-مصفوفة بالشكل
!>
!>    B := alpha * A * X + beta * B
!>
!> حيث A مصفوفة ثلاثية الأقطار من الرتبة N، B و X مصفوفتان من النوع N × NRHS
!> و alpha و beta عددان قياسيان حقيقيان، يمكن لكل منهما أن يكون
!> 0.، 1.، أو -1.
!>

المعاملات

TRANS 
!>          TRANS هو CHARACTER*1
!>          يحدد العملية المطبقة على A.
!>          = 'N':  بدون تبديل، B := alpha * A * X + beta * B
!>          = 'T':  تبديل،    B := alpha * A**T * X + beta * B
!>          = 'C':  تبديل مرافق، B := alpha * A**H * X + beta * B
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

NRHS

!>          NRHS هو INTEGER
!>          عدد الأطراف اليمنى، أي عدد أعمدة
!>          المصفوفتين X و B.
!>

ALPHA

!>          ALPHA هو REAL
!>          العدد القياسي alpha.  يجب أن يكون ALPHA 0.، 1.، أو -1.؛ خلاف ذلك،
!>          يفترض أنه 0.
!>

DL

!>          DL هو مصفوفة COMPLEX، البعد (N-1)
!>          عناصر القطر الفرعي (n-1) للمصفوفة T.
!>

D

!>          D هو مصفوفة COMPLEX، البعد (N)
!>          العناصر القطرية لـ T.
!>

DU

!>          DU هو مصفوفة COMPLEX، البعد (N-1)
!>          عناصر القطر الرئيسي الفرعي (n-1) لـ T.
!>

X

!>          X هي مصفوفة COMPLEX، البعد (LDX,NRHS)
!>          المصفوفة X من النوع N × NRHS.
!>

LDX

!>          LDX هو INTEGER
!>          البعد الرائد للمصفوفة X.  LDX >= max(N,1).
!>

BETA

!>          BETA هو REAL
!>          العدد القياسي beta.  يجب أن يكون BETA 0.، 1.، أو -1.؛ خلاف ذلك،
!>          يفترض أنه 1.
!>

B

!>          B هي مصفوفة COMPLEX، البعد (LDB,NRHS)
!>          عند الإدخال، المصفوفة B من النوع N × NRHS.
!>          عند الخروج، يتم استبدال B بالتعبير المصفوفي
!>          B := alpha * A * X + beta * B.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرائد للمصفوفة B.  LDB >= max(N,1).
!>

NAME

lagtm - performs a matrix-matrix product for a tridiagonal matrix

SYNOPSIS

  subroutine clagtm(character trans, integer n, integer nrhs, real alpha,

                   double precision beta, complex*16, dimension(ldb, *) b,
                   integer ldb)

Detailed Description

This subroutine generates the matrix product AB or A'B, depending on the value of the character parameter TRANS.

A tridiagonal matrix is a matrix where the only non-zero elements are on the main diagonal and on the first sub-diagonal and first super-diagonal.

Purpose:

!>
!> LAGTM performs a matrix-matrix product of the form
!>
!>    B := alpha * A * X + beta * B
!>
!> where A is a tridiagonal matrix of order N, B and X are N by NRHS
!> matrices, and alpha and beta are scalars.
!>

Function Documentation

subroutine clagtm (character trans, integer n, integer nrhs, real alpha, complex, dimension( * ) dl, complex, dimension( * ) d, complex, dimension( * ) du, complex, dimension( ldx, * ) x, integer ldx, real beta, complex, dimension( ldb, * ) b, integer ldb)

CLAGTM performs a matrix-matrix product of the form C = αAB+βC, where A is a tridiagonal matrix, B and C are rectangular matrices, and α and β are scalars, which may be 0, 1, or -1.

Purpose:

!>
!> CLAGTM performs a matrix-matrix product of the form
!>
!>    B := alpha * A * X + beta * B
!>
!> where A is a tridiagonal matrix of order N, B and X are N by NRHS
!> matrices, and alpha and beta are real scalars, each of which may be
!> 0., 1., or -1.
!>

Parameters

TRANS 
!>          TRANS is CHARACTER*1
!>          Specifies the operation applied to A.
!>          = 'N':  No transpose, B := alpha * A * X + beta * B
!>          = 'T':  Transpose,    B := alpha * A'* X + beta * B
!>          = 'C':  Conjugate transpose = Transpose
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices X and B.
!>

ALPHA

!>          ALPHA is REAL
!>          The scalar alpha.  ALPHA must be 0., 1., or -1.; otherwise,
!>          it is assumed to be 0.
!>

DL

!>          DL is COMPLEX array, dimension (N-1)
!>          The (n-1) sub-diagonal elements of T.
!>

D

!>          D is COMPLEX array, dimension (N)
!>          The diagonal elements of T.
!>

DU

!>          DU is COMPLEX array, dimension (N-1)
!>          The (n-1) super-diagonal elements of T.
!>

X

!>          X is COMPLEX array, dimension (LDX,NRHS)
!>          The N by NRHS matrix X.
!>

LDX

!>          LDX is INTEGER
!>          The leading dimension of the array X.  LDX >= max(N,1).
!>

BETA

!>          BETA is REAL
!>          The scalar beta.  BETA must be 0., 1., or -1.; otherwise,
!>          it is assumed to be 1.
!>

B

!>          B is COMPLEX array, dimension (LDB,NRHS)
!>          On entry, the N by NRHS matrix B.
!>          On exit, B is overwritten by the matrix expression
!>          B := alpha * A * X + beta * B.
!>

LDB

!>          LDB is INTEGER
!>          The leading dimension of the array B.  LDB >= max(N,1).
!>
