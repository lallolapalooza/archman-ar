Description:
larrk - LAPACK routine for singular value decomposition
Synopsis:
SUBROUTINE LARRK(RWORK, N, K, NB, RWORK, LDWRK, T, LDT, Z, LDZ, RESID, WORK, INFO)
Arguments:
  • RWORK: REAL for workspace array
  • N: INTEGER, order of the matrix
  • K: INTEGER, the number of columns of A
  • NB: INTEGER, the block size
  • RWORK: REAL for workspace array
  • LDWRK: INTEGER, leading dimension of the array RWORK
  • T: REAL for workspace array
  • LDT: INTEGER, leading dimension of the array T
  • Z: REAL for workspace array
  • LDZ: INTEGER, leading dimension of the array Z
  • RESID: REAL, residual norm
  • WORK: REAL for workspace array
  • INFO: INTEGER, error exit flag
