وثائق الوظائف

دالة حقيقية clanhb (norm character، uplo character، n integer، k integer، complex، dimension(ldab, *) ab، ldab integer، real، dimension(*) work)

CLANHB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة هيرميتية شريطية.

الغرض:

!>
!> CLANHB  تُرجع قيمة المعيار واحد،  أو معيار فروبينيوس، أو
!> المعيار اللانهائي،  أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة هيرميتية
!> شريطية A بحجم n × n، مع k فوق-قطر.
!>

تُرجع

CLANHB 
!>
!>    CLANHB = ( max(abs(A(i,j)))، NORM = 'M' أو 'm'
!>             (
!>             ( norm1(A)،         NORM = '1', 'O' أو 'o'
!>             (
!>             ( normI(A)،         NORM = 'I' أو 'i'
!>             (
!>             ( normF(A)،         NORM = 'F', 'f', 'E' أو 'e'
!>
!> حيث  norm1  تعني المعيار واحد للمصفوفة (أقصى مجموع عمود)،
!> normI  تعني المعيار اللانهائي  للمصفوفة  (أقصى مجموع صف) و
!> normF  تعني  معيار فروبينيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسقًا.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANHB كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي من المثلث لمصفوفة
!>          الشريط A مُقدمًا.
!>          = 'U':  الجزء العلوي من المثلث
!>          = 'L':  الجزء السفلي من المثلث
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANHB
!>          إلى الصفر.
!>

K

!>          K هو INTEGER
!>          عدد فوق-الأقطار أو تحت-الأقطار لمصفوفة الشريط A.  K >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX، حجمها (LDAB,N)
!>          الجزء العلوي أو السفلي من المثلث لمصفوفة الشريط الهيرميتية A،
!>          مخزنة في أول K+1 صفوف من AB.  يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB على النحو التالي:
!>          إذا كان UPLO = 'U'، فإن AB(k+1+i-j,j) = A(i,j) لـ max(1,j-k)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)   = A(i,j) لـ j<=i<=min(n,j+k).
!>          لاحظ أن الأجزاء التخيلية للعناصر القطرية ليست ضرورية
!>          لتعيينها وتُفترض أنها صفر.
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= K+1.
!>

WORK

!>          WORK هي مصفوفة REAL، حجمها (MAX(1,LWORK))،
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'. خلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>

double precision function dlansb (character norm, character uplo, integer n, integer k, double precision, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

DLANSB returns the value of the 1-norm, or the Frobenius norm, or the infinity norm, or the element of largest absolute value of a symmetric band matrix.

Purpose:

!>
!> DLANSB  returns the value of the one norm,  or the Frobenius norm, or
!> the  infinity norm,  or the element of  largest absolute value  of an
!> n by n symmetric band matrix A,  with k super-diagonals.
!>

Returns

DLANSB 
!>
!>    DLANSB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in DLANSB as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          band matrix A is supplied.
!>          = 'U':  Upper triangular part is supplied
!>          = 'L':  Lower triangular part is supplied
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, DLANSB is
!>          set to zero.
!>

K

!>          K is INTEGER
!>          The number of super-diagonals or sub-diagonals of the
!>          band matrix A.  K >= 0.
!>

AB

!>          AB is DOUBLE PRECISION array, dimension (LDAB,N)
!>          The upper or lower triangle of the symmetric band matrix A,
!>          stored in the first K+1 rows of AB.  The j-th column of A is
!>          stored in the j-th column of the array AB as follows:
!>          if UPLO = 'U', AB(k+1+i-j,j) = A(i,j) for max(1,j-k)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)   = A(i,j) for j<=i<=min(n,j+k).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= K+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          where LWORK >= N when NORM = 'I' or '1' or 'O'; otherwise,
!>          WORK is not referenced.
!>

Author

!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'

!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
