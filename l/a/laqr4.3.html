الغرض:

!>
!>    CLAQR4 تنفذ مستوى واحد من التكرار لـ CLAQR0.
!>    إنها تنفيذ كامل لخوارزمية QR متعددة الإزاحات ذات الفقاعات الصغيرة. قد يتم استدعاؤها بواسطة CLAQR0، ولأحجام نوافذ التفريغ الكبيرة بما فيه الكفاية، قد يتم استدعاؤها بواسطة CLAQR3. هذا الروتين مطابق لـ CLAQR0 ما عدا أنه يستدعي CLAQR2 بدلاً من CLAQR3.
!>
!>    CLAQR4 تحسب القيم الذاتية لمصفوفة هسنبرغ H، وبشكل اختياري، المصفوفتين T و Z من تحليل Schur H = Z T Z**H، حيث T هي مصفوفة مثلثة عليا (شكل Schur)، و Z هي مصفوفة الوحدة للمتجهات الذاتية.
!>
!>    بشكل اختياري، يمكن ضرب Z في مصفوفة الوحدة المدخلة Q بحيث يمكن لهذا الروتين إعطاء التحليل التام لمصفوفة A التي تم تقليلها إلى شكل هسنبرغ H بواسطة مصفوفة الوحدة Q: A = Q*H*Q**H = (QZ)*H*(QZ)**H.
!>

NAME

ZLAQR4 - ZLAQR4 computes the Schur decomposition of a complex upper Hessenberg matrix H: H = Q*T, where T is upper triangular. The Schur factor Q is unitary and is returned in the lower triangular part of H. The Schur factor T is returned in the upper triangular part of H.

SYNOPSIS

SUBROUTINE ZLAQR4( WANTT, WANTZ, N, ILO, IHI, H, LDH, W, ILOZ, IHIZ, Z, LDZ,
                   WORK, LWORK, INFO )

   LOGICAL           WANTT
   LOGICAL           WANTZ
   INTEGER           N
   INTEGER           ILO, IHI
   COMPLEX*16        H( LDH,*)
   INTEGER           LDH
   COMPLEX*16        W(*)
   INTEGER           ILOZ, IHIZ
   COMPLEX*16        Z(LDZ,*)
   INTEGER           LDZ
   COMPLEX*16        WORK(*)
   INTEGER           LWORK
   INTEGER           INFO

Detailed Description

This routine implements the QR algorithm for computing the Schur decomposition of an upper Hessenberg matrix. This routine is typically called by ZLAQR0, which is the main driver for the QR iteration.

Arguments

WANTT

LOGICAL

If WANTT is .TRUE., then the Schur factor T is returned in the upper triangular part of H.

WANTZ

LOGICAL

If WANTZ is .TRUE., then the unitary matrix Z is returned in Z.

N

INTEGER

The order of the matrix H. 0 <= N.

ILO

INTEGER

ILO and IHI specify the diagonal blocks of H that are to be reduced to triangular form. Usually, H will be ILO:IHI block upper Hessenberg and other subdiagonal entries outside this block will be zero. The range ILO:IHI requires the QR algorithm to be executed.

ILO and IHI should be set as follows:

  • If the matrix input to ZLAQR4 is already upper triangular, then ILO = 1 and IHI = 0.
  • If the matrix input to ZLAQR4 is upper Hessenberg, then ILO and IHI should be set to the first and last indices of the principal submatrix that has not yet been reduced to upper triangular form.
  • Normally, ILO and IHI are the outputs from subroutine ZGEBAL.

If N > 0, then 1 <= ILO <= MAX(1,IHI); set IHI = MAX(ILO,IHI).

If N = 0, then ILO = 1 and IHI = 0.

IHI

INTEGER

H

COMPLEX*16 array, dimension (LDH,N)

On entry, the N-by-N upper Hessenberg matrix H.

On exit, if INFO = 0 and WANTT is .TRUE., then H contains the upper triangular matrix T from the Schur decomposition (the Schur form). If INFO = 0 and WANT is .FALSE., then the contents of H are unspecified on exit.

This subroutine may explicitly set H(i,j) = 0 for i > j and j = 1, 2, ... ILO-1 or j = IHI+1, IHI+2, ... N.

LDH

INTEGER

The leading dimension of the array H. LDH >= max(1,N).

W

COMPLEX*16 array, dimension (N)

The computed eigenvalues of H(ILO:IHI,ILO:IHI) are stored in W(ILO:IHI). If WANTT is .TRUE., then the eigenvalues are stored in the same order as on the diagonal of the Schur form returned in H, with W(i) = H(i,i).

ILOZ

INTEGER

IHIZ

INTEGER

Specify the rows of Z to which transformations must be applied if WANTZ is .TRUE..

1 <= ILOZ <= ILO; IHI <= IHIZ <= N.

Z

COMPLEX*16 array, dimension (LDZ,IHIZ)

If WANTZ is .FALSE., then Z is not referenced.

If WANTZ is .TRUE., then Z(ILO:IHI,ILOZ:IHIZ) is replaced by Z(ILO:IHI,ILOZ:IHIZ)*U where U is the orthogonal Schur factor of H(ILO:IHI,ILO:IHI).

(The output value of Z when INFO > 0 is given under the description of INFO below.)

LDZ

INTEGER

The leading dimension of the array Z. If WANTZ is .TRUE. then LDZ >= MAX(1,IHIZ). Otherwise, LDZ >= 1.

WORK

COMPLEX*16 array, dimension LWORK

On exit, if LWORK = -1, WORK(1) returns an estimate of the optimal value for LWORK.

LWORK

INTEGER

The dimension of the array WORK. LWORK >= max(1,N) is sufficient, but LWORK typically as large as 6*N may be required for optimal performance. A workspace query to determine the optimal workspace size is recommended.

If LWORK = -1, then ZLAQR4 does a workspace query. In this case, ZLAQR4 checks the input parameters and estimates the optimal workspace size for the given values of N, ILO and IHI. The estimate is returned in WORK(1). No error message related to LWORK is issued by XERBLA. Neither H nor Z are accessed.

INFO

INTEGER

  • = 0: successful exit
  • > 0: if INFO = i, ZLAQR4 failed to compute all of the eigenvalues. Elements 1:ilo-1 and i+1:n of WR and WI contain those eigenvalues which have been successfully computed. (Failures are rare.)

If INFO > 0 and WANT is .FALSE., then on exit, the remaining unconverged eigenvalues are the eigen- values of the upper Hessenberg matrix rows and columns ILO through INFO of the final, output value of H.

If INFO > 0 and WANTT is .TRUE., then on exit

(*) (initial value of H)*U = U*(final value of H)

where U is a unitary matrix. The final value of H is upper Hessenberg and triangular in rows and columns INFO+1 through IHI.

If INFO > 0 and WANTZ is .TRUE., then on exit

(final value of Z(ILO:IHI,ILOZ:IHIZ) = (initial value of Z(ILO:IHI,ILOZ:IHIZ)*U

where U is the unitary matrix in (*) (regard- less of the value of WANTT.)

If INFO > 0 and WANTZ is .FALSE., then Z is not accessed.
