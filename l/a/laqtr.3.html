الغرض:

!>
!> DLAQTR يحل النظام الحقيقي شبه القطري التقريبي
!>
!>              op(T)*p = scale*c,               if LREAL = .TRUE.
!>
!> أو الأنظمة المركبة شبه القطرية التقريبية
!>
!>            op(T + iB)*(p+iq) = scale*(c+id),  if LREAL = .FALSE.
!>
!> بالحساب الحقيقي، حيث T شبه قطري علوي.
!> إذا كان LREAL = .FALSE.، فيجب أن تكون الكتلة القطرية الأولى من T
!> 1 × 1، و B هي المصفوفة ذات الهيكل الخاص
!>
!>                B = [ b(1) b(2) ... b(n) ]
!>                    [       w            ]
!>                    [           w        ]
!>                    [              .     ]
!>                    [                 w  ]
!>
!> op(A) = A أو A**T، A**T يمثل منقول المصفوفة
!> A.
!>
!> عند الإدخال، X = [ c ]. عند الخروج، X = [ p ].
!>               [ d ]                  [ q ]
!>
!> تم تصميم هذا الروتين الفرعي لتقدير رقم الشرط
!> في الروتين DTRSNA.
!>

!>          عند الخروج، SCALE هو عامل القياس.

X

!>          عند الإدخال، تحتوي X على الطرف الأيمن للنظام.
!>          عند الخروج، يتم الكتابة فوق X بالحل.

!>                بالتحقق من المدخلات للأخطاء.

Detailed Description


This routine solves the generalized eigenvalue problem:




A Z = lambda B Z




where A and B are upper triangular matrices. The solution is obtained
    by solving a sequence of 1-by-1 or 2-by-2 generalized eigenvalue
    problems.


The routine computes the solution of the generalized eigenvalue
    problem




A*Z = lambda*B*Z




where A and B are upper triangular matrices. It does so by solving a
    sequence of 1-by-1 or 2-by-2 generalized eigenvalue problems.


The function assumes that A and B are upper triangular matrices.
    The solution Z is computed such that




A*Z = B*Z*D




where D is a diagonal matrix, and Z is a nonsingular matrix. The
    diagonal elements of D are the generalized eigenvalues.


The routine is designed to handle cases where the matrices may be
    singular or ill-conditioned. It uses a technique that perturbs the diagonal
    blocks to maintain nonsingularity.
