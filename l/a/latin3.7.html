ISO_8859-3(7) دليل المعلومات المتنوعة ISO_8859-3(7)

الاسم

iso_8859-3 - مجموعة أحرف ISO/IEC 8859-3 مرمزة بالأرقام الثمانية والعشرية والسداسية العشرية

الوصف

يتضمن معيار ISO/IEC 8859 عدة امتدادات 8 بت لمجموعة أحرف ASCII (المعروفة أيضًا باسم ISO/IEC 646-IRV). تقوم ISO/IEC 8859-3 بترميز الأحرف المستخدمة في بعض لغات جنوب شرق أوروبا.

أبجديات ISO/IEC 8859

تتضمن المجموعة الكاملة من أبجديات ISO/IEC 8859:

ISO/IEC 8859-1 لغات غرب أوروبا (Latin-1)
ISO/IEC 8859-2 لغات وسط وشرق أوروبا (Latin-2)
ISO/IEC 8859-3 لغات جنوب شرق أوروبا ولغات متنوعة (Latin-3)
ISO/IEC 8859-4 لغات الدول الاسكندنافية / البلطيق (Latin-4)
ISO/IEC 8859-5 لاتيني/سيريلي
ISO/IEC 8859-6 لاتيني/عربي
ISO/IEC 8859-7 لاتيني/يوناني
ISO/IEC 8859-8 لاتيني/عبري
ISO/IEC 8859-9 تعديل Latin-1 للغة التركية (Latin-5)
ISO/IEC 8859-10 لغات Lappish/Nordic/Eskimo (Latin-6)
ISO/IEC 8859-11 لاتيني/تايلاندي
ISO/IEC 8859-13 لغات حوض البلطيق (Latin-7)
ISO/IEC 8859-14 سلتيك (Latin-8)
ISO/IEC 8859-15 لغات غرب أوروبا (Latin-9)
ISO/IEC 8859-16 روماني (Latin-10)

NAME

latin3 - ISO/IEC 8859-3 character set

DESCRIPTION

ISO/IEC 8859-3 is an 8-bit character set. The first 256 characters of the Unicode standard are compatible with the ISO 8859 series of character sets. Specifically, the characters in the range U+0000 to U+00FF are the same as ISO 8859-1, except that the characters in the range U+00A0 to U+00FF are defined differently for each of the ISO 8859 character sets.

This document describes the ISO 8859-3 character set, also known as Latin-3.

The characters available in ISO 8859-3 are:
