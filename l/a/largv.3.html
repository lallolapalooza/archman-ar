الاسم

largv - largv: توليد متجه من دوران المستوى

الملخص

الوظائف


روتين فرعي clargv (n, x, incx, y, incy, c, incc)
CLARGV يولد متجه من دوران المستوى مع جيب التمام الحقيقي وجيوب مركبة. روتين فرعي dlargv (n, x, incx, y, incy, c, incc)
DLARGV يولد متجه من دوران المستوى مع جيب التمام الحقيقي وجيوب حقيقية. روتين فرعي slargv (n, x, incx, y, incy, c, incc)
SLARGV يولد متجه من دوران المستوى مع جيب التمام الحقيقي وجيوب حقيقية. روتين فرعي zlargv (n, x, incx, y, incy, c, incc)
ZLARGV يولد متجه من دوران المستوى مع جيب التمام الحقيقي وجيوب مركبة.

وصف تفصيلي

توثيق الوظيفة

روتين فرعي clargv (عدد صحيح n, مركب, البعد(* ) x, عدد صحيح incx, مركب, البعد(* ) y, عدد صحيح incy, حقيقي, البعد(* ) c, عدد صحيح incc)

CLARGV يولد متجه من دوران المستوى مع جيب التمام الحقيقي وجيوب مركبة.

الغرض:

!>
!> CLARGV يولد متجه من دوران المستوى المركب مع جيب التمام الحقيقي،
!> التي يتم تحديدها بواسطة عناصر المتجهات المركبة x و y.
!> لكل i = 1,2,...,n
!>
!>    (        c(i)   s(i) ) ( x(i) ) = ( r(i) )
!>    ( -conjg(s(i))  c(i) ) ( y(i) ) = (   0  )
!>
!>    حيث c(i)**2 + ABS(s(i))**2 = 1
!>
!> يتم استخدام الاتفاقيات التالية (وهي نفس تلك الموجودة في CLARTG،
!> ولكنها تختلف عن روتين BLAS1 CROTG):
!>    إذا كانت y(i)=0، فإن c(i)=1 و s(i)=0.
!>    إذا كانت x(i)=0، فإن c(i)=0 ويتم اختيار s(i) بحيث يكون r(i) حقيقيًا.
!>

المعلمات

N 
!>          N هو عدد صحيح
!>          عدد دورانات المستوى التي سيتم توليدها.
!>

X

!>          X هو مصفوفة مركبة، البعد (1+(N-1)*INCX)
!>          عند الدخول، المتجه x.
!>          عند الخروج، يتم استبدال x(i) بـ r(i)، لكل i = 1,...,n.
!>

INCX

!>          INCX هو عدد صحيح
!>          الزيادة بين عناصر X. INCX > 0.
!>

Y

!>          Y هو مصفوفة مركبة، البعد (1+(N-1)*INCY)
!>          عند الدخول، المتجه y.
!>          عند الخروج، جيوب دورانات المستوى.
!>

INCY

!>          INCY هو عدد صحيح
!>          الزيادة بين عناصر Y. INCY > 0.
!>

C

!>          C هو مصفوفة حقيقية، البعد (1+(N-1)*INCC)
!>          جيب التمام لدورانات المستوى.
!>

INCC

!>          INCC هو عدد صحيح
!>          الزيادة بين عناصر C. INCC > 0.
!>
