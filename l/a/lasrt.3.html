توثيق الدالة

روتين فرعي dlasrt (المعرف النصي id، العدد الصحيح n، الدقة المزدوجة، البعد (*) d، العدد الصحيح info)

DLASRT يفرز الأرقام بترتيب تصاعدي أو تنازلي.

الغرض:

!>
!> قم بفرز الأرقام في D بترتيب تصاعدي (إذا كان ID = 'I') أو
!> بترتيب تنازلي (إذا كان ID = 'D').
!>
!> استخدم الفرز السريع (Quick Sort)، مع العودة إلى فرز الإدراج (Insertion sort) على المصفوفات
!> ذات الحجم <= 20. بعد المكدس (STACK) يحد N بحوالي 2**32.
!>

المعلمات

ID 
!>          ID هو CHARACTER*1
!>          = 'I': فرز D بترتيب تصاعدي؛
!>          = 'D': فرز D بترتيب تنازلي.
!>

N

!>          N هو INTEGER
!>          طول المصفوفة D.
!>

D

!>          D هي مصفوفة DOUBLE PRECISION، البعد (N)
!>          عند الدخول، المصفوفة المطلوب فرزها.
!>          عند الخروج، تم فرز D بترتيب تصاعدي
!>          (D(1) <= ... <= D(N) ) أو بترتيب تنازلي
!>          (D(1) >= ... >= D(N) )، اعتمادًا على ID.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  الخروج بنجاح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i لها قيمة غير قانونية
!>
