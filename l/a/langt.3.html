وصف مفصل

توثيق الوظائف

دالة حقيقية clangt (المعيار حرفي، n صحيح، معقد، البعد (*) dl، معقد، البعد (*) d، معقد، البعد (*) du)

CLANGT تُرجع قيمة المعيار 1، أو المعيار الفروbenius، أو معيار اللانهاية، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة ثلاثية الأقطار عامة.

الغرض:

!>
!> CLANGT  تُرجع قيمة المعيار واحد، أو المعيار فروbenius، أو
!> معيار اللانهاية، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> معقدة ثلاثية الأقطار A.
!>

القيم المُرجعة

CLANGT 
!>
!>    CLANGT = ( max(abs(A(i,j)))، NORM = 'M' أو 'm'
!>             (
!>             ( norm1(A)،         NORM = '1', 'O' أو 'o'
!>             (
!>             ( normI(A)،         NORM = 'I' أو 'i'
!>             (
!>             ( normF(A)،         NORM = 'F', 'f', 'E' أو 'e'
!>
!> حيث  norm1  يشير إلى معيار المصفوفة الواحد (أقصى مجموع أعمدة)،
!> normI  يشير إلى معيار المصفوفة للانهاية  (أقصى مجموع صفوف) و
!> normF  يشير إلى المعيار الفروbenius للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANGT كما هو موضح
!>          أعلاه.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم
!>          تعيين CLANGT إلى صفر.
!>

DL

!>          DL هو مصفوفة COMPLEX، البعد (N-1)
!>          عناصر القطر السفلي (n-1) للمصفوفة A.
!>

D

!>          D هو مصفوفة COMPLEX، البعد (N)
!>          عناصر القطر الرئيسي للمصفوفة A.
!>

DU

!>          DU هو مصفوفة COMPLEX، البعد (N-1)
!>          عناصر القطر العلوي (n-1) للمصفوفة A.
!>
