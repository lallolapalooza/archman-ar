NAME

larzt - constructs the triangular factor T of a block reflector H of rank K.

SYNOPSIS

 SUBROUTINE LARZT( DIRECT, STOREV, N, K, V, LDV, TAU, T, LDT )

 CHARACTER(LEN=1) CHARACTER(LEN=1)
 INTEGER N, K, LDV, LDT
 COMPLEX*16 V( LDV, * ), TAU( * ), T( LDT, * )

Detailed Description

LARZT constructs the triangular factor T of a block reflector H of rank K. The block reflector H is defined as

 H = H(k) * H(k-1) * ... * H(1)

where each H(i) is a general reflection of the form

 H(i) = I - tau(i) * v(i) * v(i)^H

and v(i) is a vector, which is stored in the columns of V. If STOREV = 'C', V is a N-by-K matrix and the vectors v(i) are stored in the columns of V and H(i) is implicitly given by tau(i) and the i-th column of V.

If STOREV = 'R', V is a K-by-N matrix and the vectors v(i) are stored in the rows of V and H(i) is implicitly given by tau(i) and the i-th row of V.

The algorithm used is described by Petitet, Daniels, and Quintana-Osorio in "An efficient QR decomposition with look-ahead" (1998).

Arguments:

DIRECT
CHARACTER(LEN=1).

DIRECT determines the block reflector structure:

  • 'F' (Forward recurrence) means H is.
  • 'B' (Backward recurrence) means H is.
    STOREV
    CHARACTER(LEN=1).

    STOREV determines the storage format of the vectors which define the H(i) which form the block reflector:

    • 'C' => Columnwise storage, V is N-by-K.
  • 'R' => Rowwise storage, V is K-by-N.
    N
    INTEGER.

    The number of rows of the matrix V.

    K
    INTEGER.

    The number of columns of the matrix V.

    V
    COMPLEX*16 array, dimension (LDV,K) or (LDV,N) if STOREV='R'.

    On entry, V contains the vectors v(i) that define the elementary reflectors H(i) in the columns (if STOREV = 'C') or rows (if STOREV = 'R') of V. See further details.

    LDV
    INTEGER.

    The leading dimension of the array V.

    • If STOREV = 'C', LDV >= max(1,N); if STOREV = 'R', LDV >= K.
    TAU
    COMPLEX*16 array, dimension (K).

    TAU(i) must contain the scalar factor of the elementary reflector H(i).

    T
    COMPLEX*16 array, dimension (LDT,K).

    The k by k triangular factor T of the block reflector. If DIRECT = 'F', T is upper triangular; if DIRECT = 'B', T is lower triangular. The rest of the array is not used.

    LDT
    INTEGER.

    The leading dimension of the array T. LDT >= K.

     The shape of the matrix V and the storage of the vectors which define

         ( v1 v2 v3 )
