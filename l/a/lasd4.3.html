توثيق الوظيفة

subroutine dlasd4 (integer n, integer i, double precision, dimension( * ) d, double precision, dimension( * ) z, double precision, dimension( * ) delta, double precision rho, double precision sigma, double precision, dimension( * ) work, integer info)

DLASD4 تحسب الجذر التربيعي للقيمة الذاتية المحدثة i لمصفوفة قطرية موجبة ذات رتبة واحدة معدلة موجبة. تستخدم بواسطة dbdsdc.

الغرض:

!>
!> هذه الروتين الفرعي يحسب الجذر التربيعي للقيمة الذاتية المحدثة I
!> لمصفوفة قطرية موجبة ذات رتبة واحدة معدلة موجبة
!> التي تُعطى مدخلاتها كمربعات
!> للمدخلات المقابلة في المصفوفة d، وأن
!>
!>        0 <= D(i) < D(j)  for  i < j
!>
!> وأن RHO > 0. يتم ترتيب ذلك بواسطة الروتين المستدعي، وهو
!> ليس خسارة في التعميم. النظام المعدل ذو الرتبة الواحدة هو بالتالي
!>
!>        diag( D ) * diag( D ) +  RHO * Z * Z_transpose.
!>
!> حيث نفترض أن المعيار الإقليدي لـ Z هو 1.
!>
!> تتكون الطريقة من تقريب الدوال الكسرية في المعادلة العلمانية
!> بواسطة دوال كسرية استيفانية أبسط.
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>         طول جميع المصفوفات.
!>

I

!>          I هو عدد صحيح (INTEGER)
!>         فهرس القيمة الذاتية المراد حسابها.  1 <= I <= N.
!>

D

!>          D هي مصفوفة دقة مزدوجة (DOUBLE PRECISION)، حجمها ( N )
!>         القيم الذاتية الأصلية. يُفترض أنها مرتبة
!>         بترتيب، 0 <= D(I) < D(J)  for I < J.
!>

Z

!>          Z هي مصفوفة دقة مزدوجة (DOUBLE PRECISION)، حجمها ( N )
!>         مكونات متجه التحديث.
!>

DELTA

!>          DELTA هي مصفوفة دقة مزدوجة (DOUBLE PRECISION)، حجمها ( N )
!>         إذا كان N .ne. 1، تحتوي DELTA على (D(j) - sigma_I) في مكونها j.
!>         إذا كان N = 1، فإن DELTA(1) = 1. يحتوي المتجه DELTA
!>         على المعلومات الضرورية لبناء المتجهات الذاتية (المنفردة).
!>

RHO

!>          RHO هو دقة مزدوجة (DOUBLE PRECISION)
!>         العدد الثابت في صيغة التحديث المتماثل.
!>

SIGMA

!>          SIGMA هو دقة مزدوجة (DOUBLE PRECISION)
!>         سيجما_I المحسوبة، القيمة الذاتية المحدثة I.
!>

WORK

!>          WORK هي مصفوفة دقة مزدوجة (DOUBLE PRECISION)، حجمها ( N )
!>         إذا كان N .ne. 1، تحتوي WORK على (D(j) + sigma_I) في مكونها j.
!>         إذا كان N = 1، فإن WORK( 1 ) = 1.
!>

INFO

!>          INFO هو عدد صحيح (INTEGER)
!>         = 0:  انتهاء ناجح
!>         > 0:  إذا كان INFO = 1، فشلت عملية التحديث.
!>

المعاملات الداخلية:

!>  المتغير المنطقي ORGATI (origin-at-i؟) يستخدم للتمييز
!>  ما إذا كانت D(i) أو D(i+1) تُعامل كنقطة الأصل.
!>
!>            ORGATI = .true.    نقطة الأصل عند i
!>            ORGATI = .false.   نقطة الأصل عند i+1
!>
!>  المتغير المنطقي SWTCH3 (switch-for-3-poles؟) هو لملاحظة
!>  ما إذا كنا نعمل مع ثلاثة أقطاب!
!>
!>  MAXIT هو الحد الأقصى لعدد التكرارات المسموح بها لكل
!>  قيمة ذاتية.
!>
