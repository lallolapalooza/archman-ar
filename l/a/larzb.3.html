روتين فرعي clarzb (character side, character trans, character direct, character storev, integer m, integer n, integer k, integer l, complex, dimension( ldv, * ) v, integer ldv, complex, dimension( ldt, * ) t, integer ldt, complex, dimension( ldc, * ) c, integer ldc, complex, dimension( ldwork, * ) work, integer ldwork)

CLARZB يطبق عاكس كتلة أو مرافقته المتعامدة على مصفوفة عامة.

الغرض:

!>
!> CLARZB يطبق عاكس كتلة مركب H أو مرافقته المتعامدة H**H
!> على مصفوفة عامة مركبة موزعة M-by-N C من اليسار أو اليمين.
!>
!> حاليًا، يتم دعم STOREV = 'R' و DIRECT = 'B' فقط.
!>

المعلمات

SIDE 
!>          SIDE هي CHARACTER*1
!>          = 'L': تطبيق H أو H**H من اليسار
!>          = 'R': تطبيق H أو H**H من اليمين
!>

TRANS

!>          TRANS هي CHARACTER*1
!>          = 'N': تطبيق H (بدون مرافق)
!>          = 'C': تطبيق H**H (مرافق متعامد)
!>

DIRECT

!>          DIRECT هي CHARACTER*1
!>          تحدد كيفية تشكيل H من ناتج عواكس أولية
!>          = 'F': H = H(1) H(2) . . . H(k) (أمامي، غير مدعوم بعد)
!>          = 'B': H = H(k) . . . H(2) H(1) (خلفي)
!>

STOREV

!>          STOREV هي CHARACTER*1
!>          تحدد كيفية تخزين المتجهات التي تحدد العواكس الأولية:
!>          = 'C': عموديًا (غير مدعوم بعد)
!>          = 'R': أفقيًا
!>

M

!>          M هو INTEGER
!>          عدد صفوف المصفوفة C.
!>

N

!>          N هو INTEGER
!>          عدد أعمدة المصفوفة C.
!>

K

!>          K هو INTEGER
!>          ترتيب المصفوفة T (= عدد العواكس الأولية التي يشكل ناتجها
!>          عاكس الكتلة).
!>

L

!>          L هو INTEGER
!>          عدد الأعمدة في المصفوفة V التي تحتوي على الجزء الهادف
!>          من عواكس هاوسهولدر.
!>          إذا كان SIDE = 'L'، فإن M >= L >= 0، وإذا كان SIDE = 'R'، فإن N >= L >= 0.
!>

V

!>          V هي مصفوفة COMPLEX، بأبعاد (LDV,NV).
!>          إذا كان STOREV = 'C'، فإن NV = K؛ وإذا كان STOREV = 'R'، فإن NV = L.
!>

LDV

!>          LDV هو INTEGER
!>          البعد الرئيسي للمصفوفة V.
!>          إذا كان STOREV = 'C'، فإن LDV >= L؛ وإذا كان STOREV = 'R'، فإن LDV >= K.
!>

T

!>          T هي مصفوفة COMPLEX، بأبعاد (LDT,K)
!>          المصفوفة المثلثية K-by-K T في تمثيل عاكس الكتلة.
!>

LDT

!>          LDT هو INTEGER
!>          البعد الرئيسي للمصفوفة T. LDT >= K.
!>

C

!>          C هي مصفوفة COMPLEX، بأبعاد (LDC,N)
!>          عند الإدخال، المصفوفة C ذات الأبعاد M-by-N.
!>          عند الخروج، يتم الكتابة فوق C بواسطة H*C أو H**H*C أو C*H أو C*H**H.
!>

LDC

!>          LDC هو INTEGER
!>          البعد الرئيسي للمصفوفة C. LDC >= max(1,M).
!>

WORK

!>          WORK هي مصفوفة COMPLEX، بأبعاد (LDWORK,K)
!>

LDWORK

!>          LDWORK هو INTEGER
!>          البعد الرئيسي للمصفوفة WORK.
!>          إذا كان SIDE = 'L'، فإن LDWORK >= max(1,N)؛
!>          إذا كان SIDE = 'R'، فإن LDWORK >= max(1,M).
!>

LARZB(3) - LAPACK

NAME

LARZB ― builds a dense matrix from an orthonormal factor of a general rectangular matrix.

SYNOPSIS

 SUBROUTINE LARZB( SIDE, TRANS, DIRECT, STORE, M, N, K, L,
&                   V, LDV, TAU, C, LDC, WORK, INFO )

Parameters

CHARACTER SIDE
Specifies whether the orthogonal transformation is applied to A or B.
SIDE = 'L': expects left orthogonal factor of A
SIDE = 'R': expects right orthogonal factor of A
CHARACTER TRANS
Specifies whether the orthogonal transformation is triangular or trapezoidal.
TRANS = 'N': V is n x k
TRANS = 'T': V is k x n
CHARACTER DIRECT
Specifies the direction of the block Householder transformations.
DIRECT = 'F': Front-ending
DIRECT = 'B': Back-ending
CHARACTER STORE
Specifies whether the vectors are stored one below the other or one next to the other.
STORE = 'R': one vector per row
STORE = 'C': one vector per column
INTEGER M
The number of rows of the matrix C.
INTEGER N
The number of columns of the matrix C.
INTEGER K
The number of columns of the matrix V.
INTEGER L
The number of entries in the vectors U and W.
REAL V( LDV, * )

The matrix V with dimension LDV*K.

If STORE = 'R', V is (k x l) or (l x k).

If STORE = 'C', V is (n x k) or (k x n).

INTEGER LDV
The leading dimension of the array V.
REAL TAU( * )

The scalar factors of the elementary Householder transformations.

The dimension of TAU is K.

REAL C( LDC, * )

On entry, the matrix C.

On exit, C is overwritten by the result of applying the transformations to C.

dimension (LDC, N)
INTEGER LDC
The leading dimension of the array C.
REAL WORK( * )

Workspace array.

The dimension of WORK is max(M,N).

INTEGER INFO

<0: if INFO = -i, then the i-th argument had an illegal value.

>0: failure

INFO = 0: successful exit

>0: if INFO = i, then the i-th argument had an illegal value.

>0: a dimension parameter is invalid

  if (SIDE = 'L') then M <= 0
  if (SIDE = 'R') then N <= 0
  if (TRANS = 'N') then
    if (DIRECT = 'F') then
      if (STORE = 'R') then K <= 0 or L <= 0
      if (STORE = 'C') then K <= 0 or L <= 0
    else if (DIRECT = 'B') then
      if (STORE = 'R') then K <= 0 or L <= 0
      if (STORE = 'C') then K <= 0 or L <= 0
    endif
  else if (TRANS = 'T') then
    if (DIRECT = 'F') then
      if (STORE = 'R') then K <= 0 or L <= 0
      if (STORE = 'C') then K <= 0 or L <= 0
    else if (DIRECT = 'B') then
      if (STORE = 'R') then K <= 0 or L <= 0
      if (STORE = 'C') then K <= 0 or L <= 0
    endif
  endif

It is assumed that:

  1 <= M, N <= max(M,N)
  1 <= K <= max(M,N)
  1 <= L <= max(M,N)
  1 <= LDV
  1 <= LDC

The dimensions of V and TAU depend on the values of SIDE, TRANS, DIRECT and STORE.

  if (SIDE = 'L') then
    if (TRANS = 'N') then
      if (DIRECT = 'F') then
        if (STORE = 'R') then M >= K, L >= L
        if (STORE = 'C') then M >= K, L >= L
      else if (DIRECT = 'B') then
        if (STORE = 'R') then M >= K, L >= L
        if (STORE = 'C') then M >= K, L >= L
      endif
    else if (TRANS = 'T') then
      if (DIRECT = 'F') then
        if (STORE = 'R') then K >= K, L >= L
        if (STORE = 'C') then K >= K, L >= L
      else if (DIRECT = 'B') then
        if (STORE = 'R') then K >= K, L >= L
        if (STORE = 'C') then K >= K, L >= L
      endif
    endif
  else if (SIDE = 'R') then
    if (TRANS = 'N') then
      if (DIRECT = 'F') then
        if (STORE = 'R') then N >= K, L >= L
        if (STORE = 'C') then N >= K, L >= L
      else if (DIRECT = 'B') then
        if (STORE = 'R') then N >= K, L >= L
        if (STORE = 'C') then N >= K, L >= L
      endif
    else if (TRANS = 'T') then
      if (DIRECT = 'F') then
        if (STORE = 'R') then K >= K, L >= L
        if (STORE = 'C') then K >= K, L >= L
      else if (DIRECT = 'B') then
        if (STORE = 'R') then K >= K, L >= L
        if (STORE = 'C') then K >= K, L >= L
      endif
    endif
  endif

  The dimension of WORK is max(M,N)
  The dimension of TAU is K

Description

LARZB applies a real orthogonal factor of a general rectangular matrix to a real rectangular matrix.

Let

    Q = ( V Q1 )

or

    Q = ( V )
        ( V1 )

be the orthogonal matrix, where V is an m x k or k x n matrix with Householder reflections defined by the entries in V and TAU. LARZB applies Q or QT to C.

The dimensions of V, TAU and WORK depend on SIDE, TRANS, DIRECT and STORE.

The matrix C is modified as follows:

    if SIDE = 'L', C is replaced by Q * C.
    if SIDE = 'R', C is replaced by C * Q.

The transformations are applied in the order defined by DIRECT.

The matrix V contains the vectors U and W which define the Householder transformations.

The dimensions of V, C and WORK depend on SIDE, TRANS, DIRECT and STORE.
