CLANSY تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متناظرة معقدة. دالة دقيقة مزدوجة dlansy (norm, uplo, n, a, lda, work)
DLANSY تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متناظرة حقيقية. دالة حقيقية slansy (norm, uplo, n, a, lda, work)
SLANSY تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متناظرة حقيقية. دالة حقيقية zlanhe (norm, uplo, n, a, lda, work)
ZLANHE تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هيرميتية معقدة. دالة دقيقة مزدوجة zlansy (norm, uplo, n, a, lda, work)
ZLANSY تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متناظرة معقدة.

وصف تفصيلي

توثيق الوظيفة

دالة حقيقية clanhe (الحرف norm, الحرف uplo, الصحيح n, معقد, البعد( lda, * ) a, الصحيح lda, حقيقي, البعد( * ) work)

CLANHE تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هيرميتية معقدة.

الغرض:

!>
!> CLANHE  تُرجع قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هيرميتية معقدة A.
!>

النتائج

CLANHE 
!>
!>    CLANHE = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على المعيار واحد للمصفوفة (أكبر مجموع عمود)،
!> normI  يدل على المعيار اللانهائي للمصفوفة (أكبر مجموع صف) و
!> normF  يدل على معيار فروبينيوس للمصفوفة (الجذر التربيعي لمجموع المربعات).
!> لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANHE كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كان سيتم الرجوع إلى الجزء العلوي أو السفلي المثلثي
!>          للمصفوفة الهيرميتية A.
!>          = 'U':  يتم الرجوع إلى الجزء العلوي المثلثي من A
!>          = 'L':  يتم الرجوع إلى الجزء السفلي المثلثي من A
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANHE
!>          إلى صفر.
!>

A

!>          A هي مصفوفة COMPLEX، البعد (LDA,N)
!>          المصفوفة الهيرميتية A.  إذا كان UPLO = 'U'، فإن الجزء العلوي
!>          المثلثي الرئيسي N × N من A يحتوي على الجزء العلوي
!>          المثلثي للمصفوفة A، ولا يتم الرجوع إلى الجزء السفلي
!>          المثلثي الصارم من A.  إذا كان UPLO = 'L'، فإن الجزء السفلي
!>          المثلثي الرئيسي N × N من A يحتوي على الجزء السفلي
!>          المثلثي للمصفوفة A، ولا يتم الرجوع إلى الجزء العلوي
!>          المثلثي الصارم من A.  لاحظ أن الأجزاء التخيلية للعناصر
!>          القطرية لا تحتاج إلى تعيين ويُفترض أنها صفر.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK هي مصفوفة REAL، البعد (MAX(1,LWORK))،
!>          حيث LWORK >= N عندما NORM = 'I' أو '1' أو 'O'. بخلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>

ZLANSY 
!>
!>    ZLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> where  norm1  denotes the  one norm of a matrix (maximum column sum),
!> normI  denotes the  infinity norm  of a matrix  (maximum row sum) and
!> normF  denotes the  Frobenius norm of a matrix (square root of sum of
!> squares).  Note that  max(abs(A(i,j)))  is not a consistent matrix norm.
!>

Parameters

NORM 
!>          NORM is CHARACTER*1
!>          Specifies the value to be returned in ZLANSY as described
!>          above.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          Specifies whether the upper or lower triangular part of the
!>          symmetric matrix A is to be referenced.
!>          = 'U':  Upper triangular part of A is referenced
!>          = 'L':  Lower triangular part of A is referenced
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.  When N = 0, ZLANSY is
!>          set to zero.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          The symmetric matrix A.  If UPLO = 'U', the leading n by n
!>          upper triangular part of A contains the upper triangular part
!>          of the matrix A, and the strictly lower triangular part of A
!>          is not referenced.  If UPLO = 'L', the leading n by n lower
!>          triangular part of A contains the lower triangular part of
!>          the matrix A, and the strictly upper triangular part of A is
!>          not referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(N,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
