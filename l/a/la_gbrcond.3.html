DESCRIPTION


The routines estimate the Skeel condition number for a general band
    matrix A, and optionally for op(A)*op2(C) where op2 is determined by
    CMODE.


The Skeel condition number for a matrix A is defined as


    cond(A) = norm(A) * norm(inv(A))



where the norm is the infinity-norm.


The routines compute the condition number using the formula


    cond(A) = norminf( |inv(A)| * |A| )



This is done by computing scaling factors R such that diag(R)*A is row
    equilibrated, computing the LU factorization of diag(R)*A, and then
    computing the infinity-norm condition number of the scaled matrix.


The complex routines use the following.


cla_gbrcond_x computes the condition number for A*C, where C
    is a diagonal matrix represented by the vector c.


zla_gbrcond_c computes the condition number for A*C, where C
    is a diagonal matrix represented by the vector c.


dla_gbrcond computes the condition number for A*C, where C
    is a diagonal matrix represented by the vector c.


sla_gbrcond computes the condition number for A*C, where C
    is a diagonal matrix represented by the vector c.


The purpose of zla_gbrcond_c is to compute an estimate of the
    reciprocal of the condition number of a general band matrix.


The purpose of cla_gbrcond_x is to compute an estimate of the
    reciprocal of the condition number of a general band matrix.


The purpose of dla_gbrcond is to compute an estimate of the
    reciprocal of the condition number of a general band matrix.


The purpose of sla_gbrcond is to compute an estimate of the
    reciprocal of the condition number of a general band matrix.




cla_gbrcond_x


Estimates the Skeel condition number for op(A) * C, where C is
    a diagonal matrix.


Purpose:




!>
!>    CLA_GBRCOND_X estimates the Skeel condition number of op(A)*C
!>    where op(A) is the transpose of A or conjugate transpose of A
!>    and C is a diagonal matrix represented by the vector C.
!>    The Skeel condition number cond(A) = norminf( |inv(A)||A| )
!>    is computed by computing scaling factors R such that
!>    diag(R)*A is row equilibrated and computing the standard
!>    infinity-norm condition number.
!> 




Parameters


TRANS

!>          TRANS is CHARACTER*1
!>     Specifies the form of the system of equations:
!>       = 'N':  A * C      (No transpose)
!>       = 'T':  A**T * C   (Transpose)
!>       = 'C':  A**H * C   (Conjugate Transpose)
!> 


N


!>          N is INTEGER
!>     The number of linear equations, i.e., the order of the
!>     matrix A.  N >= 0.
!> 


KL


!>          KL is INTEGER
!>     The number of subdiagonals within the band of A.  KL >= 0.
!> 


KU


!>          KU is INTEGER
!>     The number of superdiagonals within the band of A.  KU >= 0.
!> 


AFB


!>          AFB is COMPLEX array, dimension (LDAFB,N)
!>     Details of the LU factorization of the band matrix A, as
!>     computed by CGBTRF.  U is stored as an upper triangular
!>     band matrix with KL+KU superdiagonals in rows 1 to KL+KU+1,
!>     and the multipliers used during the factorization are stored
!>     in rows KL+KU+2 to 2*KL+KU+1.
!> 


LDAFB


!>          LDAFB is INTEGER
!>     The leading dimension of the array AFB.  LDAFB >= 2*KL+KU+1.
!> 


IPIV


!>          IPIV is INTEGER array, dimension (N)
!>     The pivot indices from the factorization A = P*L*U
!>     as computed by CGBTRF; row i of the matrix was interchanged
!>     with row IPIV(i).
!> 


CMODE


!>          CMODE is INTEGER
!>     Determines op2(C) in the formula op(A) * op2(C) as follows:
!>     CMODE =  1    op2(C) = C
!>     CMODE =  0    op2(C) = I
!>     CMODE = -1    op2(C) = inv(C)
!> 


C


!>          C is COMPLEX array, dimension (N)
!>     The vector C in the formula op(A) * op2(C).
!> 


INFO


!>          INFO is INTEGER
!>       = 0:  Successful exit.
!>     i > 0:  The ith argument is invalid.
!> 


WORK


!>          WORK is COMPLEX array, dimension (2*N).
!>     Workspace.
!> 


RWORK


!>          RWORK is REAL array, dimension (N).
!>     Workspace.
!>
