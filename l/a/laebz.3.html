Purpose:

SLAEBZ computes the number of eigenvalues of a real symmetric tridiagonal matrix which are less than or equal to a given value, and performs other tasks required by the routine sstebz.

Purpose:

!>
!> SLAEBZ contains the iteration loops which compute and use the
!> function N(w), which is the count of eigenvalues of a symmetric
!> tridiagonal matrix T less than or equal to its argument  w.  It
!> performs a choice of two types of loops:
!>
!> IJOB=1, followed by
!> IJOB=2: It takes as input a list of intervals and returns a list of
!>         sufficiently small intervals whose union contains the same
!>         eigenvalues as the union of the original intervals.
!>         The input intervals are (AB(j,1),AB(j,2)], j=1,...,MINP.
!>         The output interval (AB(j,1),AB(j,2)] will contain
!>         eigenvalues NAB(j,1)+1,...,NAB(j,2), where 1 <= j <= MOUT.
!>
!> IJOB=3: It performs a binary search in each input interval
!>         (AB(j,1),AB(j,2)] for a point  w(j)  such that
!>         N(w(j))=NVAL(j), and uses  C(j)  as the starting point of
!>         the search.  If such a w(j) is found, then on output
!>         AB(j,1)=AB(j,2)=w.  If no such w(j) is found, then on output
!>         (AB(j,1),AB(j,2)] will be a small interval containing the
!>         point where N(w) jumps through NVAL(j), unless that point
!>         lies outside the initial interval.
!>
!> Note that the intervals are in all cases half-open intervals,
!> i.e., of the form  (a,b] , which includes  b  but not  a .
!>
!> To avoid underflow, the matrix should be scaled so that its largest
!> element is no greater than  overflow**(1/2) * underflow**(1/4)
!> in absolute value.  To assure the most accurate computation
!> of small eigenvalues, the matrix should be scaled to be
!> not much smaller than that, either.
!>
!> See W. Kahan , Report CS41, Computer Science Dept., Stanford
!> University, July 21, 1966
!>
!> Note: the arguments are, in general, *not* checked for unreasonable
!> values.
!>

!>          to the number of non-converged intervals.

N

!>          N is INTEGER

!>          least 1.
!>

MMAX

!>          MMAX is INTEGER
!>          The maximum number of intervals.  If more than MMAX intervals

NBMIN

Detailed Description

This routine is part of the LAPACK routines for finding the eigenvalues and eigenvectors of a symmetric tridiagonal matrix. Specifically, SLAEBZ is used to count the number of eigenvalues within specified intervals or to find intervals containing a specific range of eigenvalues.

The function of SLAEBZ depends on the input parameter IJOB:

IJOB=1:

Counts the number of eigenvalues in the intervals defined by AB. The diagonal elements of the matrix T are passed in U, the subdiagonal elements in V, and the superdiagonal elements in T. NMAX is the total number of eigenvalues. MINP is the minimum number of intervals needed. ABSTOL and RELTOL are tolerances for convergence. The output parameter MOUT will contain the number of eigenvalues in the intervals. NAB will be updated to store the counts of eigenvalues at the interval endpoints.

IJOB=2:

Finds approximations to eigenvalues within the intervals defined by AB. The input NAB specifies the range of eigenvalues to find within each interval. The output AB will contain the approximate eigenvalues, and NAB will be updated accordingly.

IJOB=3:

Searches for intervals containing a specified range of eigenvalues. NVAL specifies the desired range of eigenvalues. AB defines the search intervals. C provides initial search points. The output AB will contain the refined intervals, and NVAL will be updated to reflect the number of eigenvalues found in each interval.

The routine also takes workspace arrays U, V, T, NVAL, AB, C, NAB, WORK, and IWORK, and returns an INFO flag indicating the success of the operation.

Note that the input arrays AB and NVAL may be modified by the routine, and their contents on output may not correspond directly to their input values due to reordering and splitting of intervals.
