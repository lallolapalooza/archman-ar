subroutine clapmt (logical forwrd, integer m, integer n, complex, dimension( ldx, * ) x, integer ldx, integer, dimension( * ) k)

CLAPMT تقوم بإعادة ترتيب الأعمدة لمصفوفة M × N بشكل أمامي أو عكسي.

الغرض:

!>
!> CLAPMT تعيد ترتيب أعمدة المصفوفة M × N المسماة X كما هو محدد
!> بواسطة التبديل K(1),K(2),...,K(N) للأعداد الصحيحة 1,...,N.
!> إذا كانت FORWRD = .TRUE.، تبديل أمامي:
!>
!>      يتم نقل X(*,K(J)) إلى X(*,J) لـ J = 1,2,...,N.
!>
!> إذا كانت FORWRD = .FALSE.، تبديل عكسي:
!>
!>      يتم نقل X(*,J) إلى X(*,K(J)) لـ J = 1,2,...,N.
!>

المعلمات

FORWRD 
!>          FORWRD هو LOGICAL
!>          = .TRUE.، تبديل أمامي
!>          = .FALSE.، تبديل عكسي
!>

M

!>          M هو INTEGER
!>          عدد صفوف المصفوفة X. M >= 0.
!>

N

!>          N هو INTEGER
!>          عدد أعمدة المصفوفة X. N >= 0.
!>

X

!>          X هو مصفوفة COMPLEX، ذات بعد (LDX,N)
!>          عند الإدخال، المصفوفة M × N المسماة X.
!>          عند الخروج، تحتوي X على المصفوفة المعاد ترتيبها X.
!>

LDX

!>          LDX هو INTEGER
!>          البعد الرئيسي للمصفوفة X، LDX >= MAX(1,M).
!>

K

!>          K هي مصفوفة INTEGER، ذات بعد (N)
!>          عند الإدخال، تحتوي K على متجه التبديل. يتم استخدام K
!>          كمساحة عمل داخلية، ولكن يتم إعادة تعيينها إلى قيمتها الأصلية عند
!>          الخروج.
!>

NAME

lapmt - LAPACK routine

SYNOPSIS

SUBROUTINE LAPMT(
   M, N, X, LDX, K )

INTEGER M, N, LDX
COMPLEX*16 X( LDX, * )
INTEGER K( * )

Detailed Description

LAPMT is a subroutine in LAPACK.

Description:
  LAPMT performs a permutation on a matrix X.
  It is intended to be used in order to satisfy the conditions of
  certain algorithms.

Arguments:
  M: M is INTEGER
     The number of rows of the matrix X. M >= 0.

  N: N is INTEGER
     The number of columns of the matrix X. N >= 0.

  X: X is COMPLEX*16 array, dimension (LDX,N)
     On entry, the M by N matrix X.
     On exit, X contains the permuted matrix X.

  LDX: LDX is INTEGER
     The leading dimension of the array X, LDX >= MAX(1,M).

  K: K is INTEGER array, dimension (N)
     On entry, K contains the permutation vector. K(i) specifies the
     i-th column of X to be moved to the K(i)-th position. The values
     K(i) must be a permutation of the integers from 1 to N.
     On exit, K contains the original permutation vector.
