lanht(3) دليل وظائف المكتبة lanht(3)

الاسم

lanht - lan{ht,st}: مصفوفة هيرميتية/متناظرة، ثلاثية الأقطار

الملخص

الوظائف


وظيفة حقيقية clanht (norm، n، d، e)

CLANHT تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هيرميتية ثلاثية الأقطار معقدة.

وظيفة دقيقة مزدوجة dlanst (norm، n، d، e)

DLANST تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متناظرة ثلاثية الأقطار حقيقية.

وظيفة حقيقية slanst (norm، n، d، e)

SLANST تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متناظرة ثلاثية الأقطار حقيقية.

وظيفة دقيقة مزدوجة zlanht (norm، n، d، e)

ZLANHT تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هيرميتية ثلاثية الأقطار معقدة.

وصف تفصيلي

توثيق الوظيفة

وظيفة حقيقية clanht (نورم حرفي، عدد صحيح n، حقيقي، بُعد(*) d، معقد، بُعد(*) e)

CLANHT تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة هيرميتية ثلاثية الأقطار معقدة.

الغرض:

!>
!> CLANHT  تُرجع قيمة المعيار واحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لـ
!> مصفوفة هيرميتية ثلاثية الأقطار معقدة A.
!>

تُرجع

CLANHT 
!>
!>    CLANHT = ( max(abs(A(i,j)))، NORM = 'M' or 'm'
!>             (
!>             ( norm1(A)،         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A)،         NORM = 'I' or 'i'
!>             (
!>             ( normF(A)،         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تشير إلى  معيار المصفوفة واحد (أقصى مجموع أعمدة)،
!> normI  تشير إلى  المعيار اللانهائي  للمصفوفة  (أقصى مجموع صفوف) و
!> normF  تشير إلى  معيار فروبينيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متناسق.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في CLANHT كما هو موضح
!>          أعلاه.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين CLANHT
!>          إلى الصفر.
!>

D

!>          D هو مصفوفة REAL، بُعد (N)
!>          العناصر القطرية لـ A.
!>

E

!>          E هو مصفوفة COMPLEX، بُعد (N-1)
!>          العناصر تحت القطرية أو فوق القطرية (n-1) لـ A.
!>
