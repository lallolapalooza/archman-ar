NAME

launhr_col_getrfnp2 - performs a LU factorization of a general M x N matrix A, using partial pivoting with sequential blocking.

SYNOPSIS

 SUBROUTINE LAUNHR_COL_GETRFN_P2( M, N, A, LDA, IPIV, INFO )

     INTEGER           M, N, LDA, INFO

     INTEGER,        DIMENSION( * )   :: IPIV
     COMPLEX*16      A( * )

Detailed Description

LAUNHR_COL_GETRFN_P2 performs a LU factorization of a general M x N matrix A, using partial pivoting with sequential blocking.

This is a blocked version of GETRF, where the matrix is divided into blocks and factorization is performed on these blocks.

Arguments:

M

!>          (input) INTEGER
!>          The number of rows of the matrix A. M >= 0.
!>

N

!>          (input) INTEGER
!>          The number of columns of the matrix A. N >= 0.
!>

A

!>          (input/output) COMPLEX*16 array, dimension (LDA,N)
!>          On entry, the M x N matrix to be factorized.
!>          On exit, the factors L and U from the factorization
!>          A = P*L*U; the lower triangle of A contains the
!>          lower triangular matrix L, and the upper triangle of A
!>          contains the upper triangular matrix U.
!>

LDA

!>          (input) INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

IPIV

!>          (output) INTEGER array, dimension (min(M,N))
!>          The pivot indices of size K = min(M,N).
!>          Row i of the factorization is exchanged with row IPIV(i).
!>

INFO

!>          (output) INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
