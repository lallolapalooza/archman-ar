labelframe(n)

الحزمة: tk

التراخيص: TCL

labelframe(n) أوامر Tk المضمنة labelframe(n)

اسم

labelframe - إنشاء ومعالجة أدوات حاوية موسومة 'labelframe'

الموجز

labelframe pathName ?options?

الخيارات القياسية

-borderwidth	-highlightbackground	-pady
-cursor	-highlightcolor	-relief
-font	-highlightthickness	-takefocus
-foreground	-padx	-text

راجع صفحة دليل options للحصول على تفاصيل حول الخيارات القياسية.

خيارات خاصة بالأداة

اسم سطر الأوامر:	-background
اسم قاعدة البيانات:	background
فئة قاعدة البيانات:	Background
هذا الخيار هو نفس الخيار القياسي -background باستثناء أن قيمته يمكن تحديدها أيضًا كسلسلة فارغة. في هذه الحالة، لن تعرض الأداة خلفية أو إطارًا، ولن يتم استهلاك ألوان من خريطة ألوانها لخلفيتها وإطارها.
اسم سطر الأوامر:	-class
اسم قاعدة البيانات:	class
فئة قاعدة البيانات:	Class
يحدد فئة للنافذة. ستستخدم هذه الفئة عند الاستعلام عن قاعدة بيانات الخيارات لخيارات النافذة الأخرى، وسيتم استخدامها أيضًا لاحقًا لأغراض أخرى مثل الربط. لا يمكن تغيير الخيار -class باستخدام أمر الأداة configure.
اسم سطر الأوامر:	-colormap
اسم قاعدة البيانات:	colormap
فئة قاعدة البيانات:	Colormap
يحدد خريطة ألوان لاستخدامها للنافذة. يمكن أن تكون القيمة إما new، في هذه الحالة يتم إنشاء خريطة ألوان جديدة للنافذة ولفروعها، أو اسم نافذة أخرى (يجب أن تكون على نفس الشاشة ولها نفس المرئيات مثل pathName)، في هذه الحالة ستستخدم النافذة الجديدة خريطة الألوان من النافذة المحددة. إذا لم يتم تحديد الخيار -colormap، فستستخدم النافذة الجديدة نفس خريطة الألوان مثل والدتها. لا يمكن تغيير هذا الخيار باستخدام أمر الأداة configure.
اسم سطر الأوامر:	-height
اسم قاعدة البيانات:	height
فئة قاعدة البيانات:	Height
يحدد الارتفاع المطلوب للنافذة بأي من الأشكال المقبولة بواسطة Tk_GetPixels. إذا كان هذا الخيار أقل من أو يساوي صفرًا، فلن تطلب النافذة أي حجم على الإطلاق.
اسم سطر الأوامر:	-labelanchor
اسم قاعدة البيانات:	labelAnchor
فئة قاعدة البيانات:	LabelAnchor
يحدد مكان وضع التسمية. يتم عرض التسمية فقط إذا كان الخيار -text ليس سلسلة فارغة. القيم الصالحة لهذا الخيار هي (ترتيبها في اتجاه عقارب الساعة) nw، n، ne، en، e، es، se، s،sw، ws، w و wn. القيمة الافتراضية هي nw.
اسم سطر الأوامر:	-labelwidget
اسم قاعدة البيانات:	labelWidget
فئة قاعدة البيانات:	LabelWidget
يحدد أداة لاستخدامها كتسمية. هذا يتجاوز أي خيار -text. يجب أن توجد الأداة قبل استخدامها كـ -labelwidget وإذا لم تكن فرعًا لهذه النافذة، فسيتم رفعها فوقها في ترتيب التكديس.
اسم سطر الأوامر:	-visual
اسم قاعدة البيانات:	visual
فئة قاعدة البيانات:	Visual
يحدد معلومات المرئيات للنافذة الجديدة بأي من الأشكال التي تقبلها Tk_GetVisual. إذا لم يتم تحديد هذا الخيار، فستستخدم النافذة الجديدة نفس المرئيات مثل والدتها. لا يمكن تعديل الخيار -visual باستخدام أمر الأداة configure.
اسم سطر الأوامر:	-width
اسم قاعدة البيانات:	width
فئة قاعدة البيانات:	Width
يحدد العرض المطلوب للنافذة بأي من الأشكال المقبولة بواسطة Tk_GetPixels. إذا كان هذا الخيار أقل من أو يساوي صفرًا، فلن تطلب النافذة أي حجم على الإطلاق.

الوصف

ينشئ الأمر labelframe نافذة جديدة (محددة بالوسيط pathName) ويجعلها أداة labelframe. يمكن تحديد خيارات إضافية، موضحة أعلاه، في سطر الأوامر أو في قاعدة بيانات الخيارات لتكوين جوانب labelframe مثل لون الخلفية والتخفيف. يعيد الأمر labelframe اسم المسار للنافذة الجديدة.

Labelframe هي أداة بسيطة. هدفها الأساسي هو العمل كفاصل أو حاوية لتخطيطات النوافذ المعقدة. لديها ميزات frame بالإضافة إلى القدرة على عرض تسمية.

أمر الأداة

ينشئ الأمر labelframe أمر Tcl جديد اسمه مطابق لاسم مسار نافذة labelframe. يمكن استخدام هذا الأمر لاستدعاء عمليات مختلفة على الأداة. له الشكل العام التالي:

pathName option ?arg arg ...?
PathName هو اسم الأمر، وهو مطابق لاسم أداة labelframe. Option و args تحدد السلوك الدقيق للأمر. الأوامر التالية ممكنة لأدوات الإطارات:
pathName cget option
يعيد القيمة الحالية لخيار التكوين المحدد بواسطة option. يمكن لـ option أن تأخذ أي من القيم التي يقبلها الأمر labelframe.
pathName configure ?option? ?value option value ...?
الاستعلام عن خيارات التكوين للأداة أو تعديلها. إذا لم يتم تحديد أي option، يعيد قائمة تصف جميع الخيارات المتاحة لـ pathName (راجع Tk_ConfigureInfo للحصول على معلومات حول تنسيق هذه القائمة). إذا تم تحديد option بدون value، فإن الأمر يعيد قائمة تصف الخيار المسمى الواحد (ستكون هذه القائمة مطابقة للقائمة الفرعية المقابلة للقيمة التي تم إرجاعها إذا لم يتم تحديد option). إذا تم تحديد زوج أو أكثر من option-value، يقوم الأمر بتعديل خيارات الأداة المسماة إلى القيم المحددة؛ في هذه الحالة، يعيد الأمر سلسلة فارغة. يمكن لـ option أن تأخذ أي من القيم التي يقبلها الأمر labelframe.

الربط

عند إنشاء labelframe جديدة، ليس لديها أي ربط أحداث افتراضي: labelframes ليست مخصصة للتفاعل.

مثال

يوضح هذا كيفية بناء جزء من واجهة مستخدم لمورد هامبرغر. يتم استخدام أدوات labelframe لتنظيم الخيارات المتاحة حسب أنواع الأشياء التي يتم اتخاذ الخيارات عليها.

grid [labelframe .burger -text "Burger"] \
     [labelframe .bun    -text "Bun"] -sticky news
grid [labelframe .cheese -text "Cheese Option"] \
     [labelframe .pickle -text "Pickle Option"] -sticky news
foreach {type name val} {
    burger Beef    beef
    burger Lamb    lamb
    burger Vegetarian beans
    bun    Plain   white
    bun    Sesame  seeds
    bun    Wholemeal brown
    cheese None    none
    cheese Cheddar cheddar
    cheese Edam    edam
    cheese Brie    brie
    cheese Gruy\u00e8re gruyere
    cheese "Monterey Jack" jack
    pickle None    none
    pickle Gherkins gherkins
    pickle Onions  onion
    pickle Chili   chili
} {
    set w [radiobutton .$type.$val -text $name -anchor w \
            -variable $type -value $val]
    pack $w -side top -fill x
}
set burger beef
set bun    white
set cheese none
set pickle none
