lxc-update-config(1)

الحزمة: lxc

التراخيص: LGPL

lxc-update-config(1) lxc-update-config(1)

الاسم

lxc-update-config - تحديث ملف تهيئة قديم قبل LXC 2.1

الملخص


lxc-update-config
{-c config}

الوصف

يقوم lxc-update-config بالكشف عن أي مفاتيح تهيئة قديمة في ملف config المحدد وسيستبدلها بمفاتيح التهيئة الجديدة المناسبة.

سيقوم lxc-update-config أولاً بإنشاء نسخة احتياطية من ملف config القديم في نفس الدليل وتسميته config.backup ثم سيقوم بتحديث ملف config الأصلي في مكانه. في حالة فشل التحديث في التطبيق أو أدى إلى ملف config غير صالح لا يمكن استخدامه لبدء حاوية، يمكن للمستخدمين إما مقارنة config مع config.backup ومحاولة إصلاح أي مفاتيح تهيئة غير صالحة يدويًا أو ببساطة العودة إلى ملف التهيئة القديم عن طريق نسخ config.backup إلى config.

أي فشل لـ lxc-update-config في إنشاء ملف config قابل للاستخدام يعتبر خطأ ويجب الإبلاغ عنه للجهة المطورة.

الخيارات

-c, --config
مسار ملف التهيئة المطلوب تحديثه.
-h, --help
