lxc-create(1)

lxc-create — create a new LXC container

SYNOPSIS

lxc-create [OPTIONS] -n <container-name> -t <template> [-- <template-options>]

DESCRIPTION

lxc-create is used to create a new LXC container. It uses a template to populate the container's root filesystem.

The template is specified using the -t option. The most common template is <<none>>, which creates an empty container. Other templates can be used to create containers with pre-installed operating systems or to provide specific configurations.

The container name is specified using the -n option.

Any arguments following -- are passed directly to the template.

OPTIONS

-n NAME
Specify the name for the new container. This name must be unique.
-t TEMPLATE
Specify the template to use for creating the container. Common templates include:
  • <<none>>: Creates an empty container.
  • debian: Creates a Debian container.
  • ubuntu: Creates an Ubuntu container.
  • fedora: Creates a Fedora container.
  • alpine: Creates an Alpine Linux container.
The available templates may vary depending on your LXC installation.
-- TEMPLATE-OPTIONS
Arguments to be passed to the template script.
-f CONFIGURATION_FILE
Specify the configuration file for the container. If not specified, a default configuration file will be created.
-P ROOTFS_DIR
Specify the directory where the container's root filesystem will be created. If not specified, the default location (usually /var/lib/lxc/<container-name>/rootfs) will be used.
-p TEMPLATE_PATH
Specify a path to search for templates. This option can be used multiple times.
-L LOGFILE
Specify a file for logging.
-l LEVEL
Set the logging level. Possible values are: TRACE, DEBUG, INFO, WARNING, ERROR, FATAL, PANIC.
-d
Enable debug output.
-h
Show help information.

COMMON OPTIONS

The following options are common to most LXC commands:

-C CONFIG
Specify the configuration file for the command.
-q
Quiet mode. Suppress informational output.
-v
Verbose mode. Increase the amount of output.
-N NETWORKING
Specify the networking configuration.
-F FORCE
Force operation.

DIAGNOSTIC

The exit status is 0 on success, or a non-zero value in case of an error.

SEE ALSO

lxc-start(1), lxc-stop(1), lxc-destroy(1), lxc.conf(5)

lxc-create(1)

lxc-create — إنشاء حاوية LXC جديدة

ملخص

lxc-create [خيارات] -n <اسم-الحاوية> -t <قالب> [-- <خيارات-القالب>]

الوصف

يُستخدم lxc-create لإنشاء حاوية LXC جديدة. يستخدم قالبًا لتعبئة نظام ملفات الجذر الخاص بالحاوية.

يتم تحديد القالب باستخدام الخيار -t. القالب الأكثر شيوعًا هو <<لا شيء>>، والذي ينشئ حاوية فارغة. يمكن استخدام قوالب أخرى لإنشاء حاويات تحتوي على أنظمة تشغيل مثبتة مسبقًا أو لتوفير تكوينات محددة.

يتم تحديد اسم الحاوية باستخدام الخيار -n.

سيتم تمرير أي وسائط بعد -- مباشرة إلى القالب.

خيارات

-n الاسم
تحديد اسم الحاوية الجديدة. يجب أن يكون هذا الاسم فريدًا.
-t القالب
تحديد القالب المراد استخدامه لإنشاء الحاوية. تشمل القوالب الشائعة:
  • <<لا شيء>>: ينشئ حاوية فارغة.
  • debian: ينشئ حاوية Debian.
  • ubuntu: ينشئ حاوية Ubuntu.
  • fedora: ينشئ حاوية Fedora.
  • alpine: ينشئ حاوية Alpine Linux.
قد تختلف القوالب المتاحة اعتمادًا على تثبيت LXC الخاص بك.
-- خيارات-القالب
الوسائط التي سيتم تمريرها إلى نص القالب.
-f ملف-التكوين
تحديد ملف التكوين للحاوية. إذا لم يتم تحديده، سيتم إنشاء ملف تكوين افتراضي.
-P دليل-نظام-ملفات-الجذر
تحديد الدليل الذي سيتم إنشاء نظام ملفات الجذر الخاص بالحاوية فيه. إذا لم يتم تحديده، سيتم استخدام الموقع الافتراضي (عادةً /var/lib/lxc/<اسم-الحاوية>/rootfs).
-p مسار-القالب
تحديد مسار للبحث عن القوالب. يمكن استخدام هذا الخيار عدة مرات.
-L ملف-السجل
تحديد ملف للتسجيل.
-l المستوى
تعيين مستوى التسجيل. القيم الممكنة هي: TRACE، DEBUG، INFO، WARNING، ERROR، FATAL، PANIC.
-d
تمكين إخراج التصحيح.
-h
عرض معلومات المساعدة.

خيارات شائعة

الخيارات التالية شائعة في معظم أوامر LXC:

-C التكوين
تحديد ملف التكوين للأمر.
-q
وضع هادئ. قم بقمع إخراج المعلومات.
-v
وضع مفصل. زيادة كمية المخرجات.
-N الشبكات
تحديد تكوين الشبكات.
-F فرض
فرض العملية.

التشخيص

حالة الخروج هي 0 عند النجاح، أو قيمة غير صفرية في حالة حدوث خطأ.
