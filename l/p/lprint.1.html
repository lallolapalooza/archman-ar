lprint(1) Michael R Sweet lprint(1)

الاسم

lprint - تطبيق طابعة الملصقات

الموجز

lprint [ الأمر الفرعي ] [ الخيارات ] [ الملفات ]

الوصف

lprint هو تطبيق طابعة الملصقات يمكن تشغيله بشكل مستقل أو كخدمة شبكة IPP Everywhere مخصصة. يدعم lprint طباعة صور PNG وملفات رسوم Apple/PWG وملفات الملصقات الخاصة بالطابعة إلى طابعات الملصقات USB وشبكة. إذا لم يتم تحديد أمر فرعي، فسيتم افتراض "submit".

الأوامر الفرعية

يتم التعرف على الأوامر الفرعية التالية بواسطة lprint:

add
إضافة طابور طابعة.
cancel
إلغاء مهمة طباعة واحدة أو أكثر.
default
تعيين طابور الطابعة الافتراضي.
delete
حذف طابور طابعة.
devices
قائمة الطابعات المتصلة.
drivers
قائمة برامج التشغيل المدعومة.
jobs
قائمة مهام الطباعة المعلقة.
modify
تعديل طابور طابعة.
options
قائمة الخيارات المدعومة.
printers
قائمة طوابير الطابعات.
server
بدء تشغيل خادم.
shutdown
إيقاف تشغيل خادم قيد التشغيل.
status
عرض حالة طابعة أو جميع الطابعات.
submit
تقديم ملف للطباعة.
