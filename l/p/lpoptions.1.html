lpoptions(1)

الحزمة: cups

التراخيص: Apache-2.0 WITH LLVM-exception AND BSD-3-Clause AND Zlib AND BSD-2-Clause

lpoptions(1) OpenPrinting lpoptions(1)

اسم

lpoptions - عرض أو تعيين خيارات الطابعة والإعدادات الافتراضية

ملخص

lpoptions [ -h خادم[:منفذ] ] [ -E ] -d وجهة[/مثيل] [ -l ]
lpoptions [ -h خادم[:منفذ] ] [ -E ] [ -p وجهة[/مثيل] ] -o خيار[=قيمة] ...
lpoptions [ -h خادم[:منفذ] ] [ -E ] [ -p وجهة[/مثيل] ] -r خيار
lpoptions [ -h خادم[:منفذ] ] [ -E ] -x وجهة[/مثيل]

الوصف

lpoptions يعرض أو يعين خيارات الطابعة والإعدادات الافتراضية. إذا لم يتم تحديد طابعة باستخدام الخيار -p، يتم استخدام الطابعة الافتراضية كما هو موضح في lp(1).

إذا لم يتم تحديد أي خيار من الخيارات -l أو -o أو -r، يتم الإبلاغ عن الخيارات الحالية على المخرج القياسي.

تُستخدم الخيارات المعينة بأمر lpoptions بواسطة الأوامر lp(1) و lpr(1) عند إرسال المهام.

عند التشغيل بواسطة المستخدم الجذر (root)، يحصل lpoptions على ويعين الإعدادات الافتراضية والنسخ الافتراضية لجميع المستخدمين في ملف /etc/cups/lpoptions. بخلاف ذلك، تتم إدارة الإعدادات الافتراضية لكل مستخدم في ملف ~/.cups/lpoptions.

الخيارات

يدعم lpoptions الخيارات التالية:

-E
يمكّن التشفير عند الاتصال بخادم CUPS.
-d وجهة[/مثيل]
يعيّن الطابعة الافتراضية للمستخدم إلى وجهة. إذا تم توفير مثيل، فسيتم استخدام هذا المثيل المحدد. يتجاوز هذا الخيار الطابعة الافتراضية للنظام للمستخدم الحالي.
-h خادم[:منفذ]
يستخدم خادمًا بديلاً. ملاحظة: يجب أن يأتي هذا الخيار قبل جميع الخيارات الأخرى.
-l
يسرد الخيارات الخاصة بالطابعة وإعداداتها الحالية.
-o خيار[=قيمة]
يحدد خيارًا جديدًا للوجهة المسماة.
-p وجهة[/مثيل]
يعيّن الوجهة والمثيل، إذا تم تحديدهما، لأي خيارات تتبع. إذا لم يكن المثيل المسمى موجودًا، فسيتم إنشاؤه. يمكن إنشاء الوجهات فقط باستخدام برنامج lpadmin(8).
-r خيار
يزيل الخيار المحدد من الوجهة المسماة.
-x وجهة[/مثيل]
يزيل خيارات الوجهة والمثيل المسميين، إذا تم تحديدهما. إذا لم يكن المثيل المسمى موجودًا، فلن يتم القيام بشيء. يمكن إزالة الوجهات فقط باستخدام الأمر lpadmin(8).

الملفات

~/.cups/lpoptions - الإعدادات الافتراضية والنسخ الخاصة بالمستخدم التي أنشأها المستخدمون غير الجذر.
/etc/cups/lpoptions - الإعدادات الافتراضية والنسخ على مستوى النظام التي أنشأها المستخدم الجذر.

متوافق مع

أمر lpoptions فريد من نوعه لـ CUPS.

راجع أيضًا
