lpstat(1)

الحزمة: cups

التراخيص: Apache-2.0 WITH LLVM-exception AND BSD-3-Clause AND Zlib AND BSD-2-Clause

lpstat(1) OpenPrinting lpstat(1)

الاسم

lpstat - طباعة معلومات حالة CUPS

المُلَخَّص

lpstat [ -h اسم_المضيف[:المنفذ] ] [ -E ] [ -H ] [ -U اسم_المستخدم ] [ -l ] [ -W وظائف_معينة ] [ -a [ وجهة(وجهات) ] ] [ -c [ فئة(فئات) ] ] [ -d ] [ -e ] [ -o [ وجهة(وجهات) ] ] [ -p [ طابعة(طابعات) ] ] [ -r ] [ -R ] [ -s ] [ -t ] [ -u [ مستخدم(مستخدمين) ] ] [ -v [ طابعة(طابعات) ] ]

الوصف

lpstat يعرض معلومات الحالة حول الفئات والوظائف والطابعات الحالية. عند تشغيله بدون وسائط، سيقوم lpstat بسرد الوظائف النشطة التي تم وضعها في قائمة الانتظار بواسطة المستخدم الحالي.

الخيارات

يدعم الأمر lpstat الخيارات التالية:

-E
يجبر التشفير عند الاتصال بالخادم.
-H
يعرض اسم مضيف الخادم والمنفذ.
-R
يعرض ترتيب وظائف الطباعة.
-U اسم_المستخدم
يحدد اسم مستخدم بديل.
-W وظائف_معينة
يحدد الوظائف التي يجب عرضها، "all" (الكل)، "successful" (ناجحة)، "completed" (مكتملة) أو "not-completed" (غير مكتملة) (الافتراضي). يجب أن يظهر هذا الخيار قبل الخيار -o و/أو أي أسماء طابعات، وإلا فسيتم استخدام القيمة الافتراضية ("not-completed") في الطلب إلى المجدول.
-a [وجهة(وجهات)]
يعرض حالة قبول قوائم انتظار الطابعة. إذا لم يتم تحديد أي طابعات، فسيتم سرد جميع الطابعات.
-c [فئة(فئات)]
يعرض فئات الطابعات والطابعات التي تنتمي إليها. إذا لم يتم تحديد أي فئات، فسيتم سرد جميع الفئات.
-d
يعرض الوجهة الافتراضية الحالية.
-e
يعرض جميع الوجهات المتاحة على الشبكة المحلية.
-h اسم_المضيف[:المنفذ]
يحدد خادمًا بديلاً. ملاحظة: يجب أن يأتي هذا الخيار قبل جميع الخيارات الأخرى.
-l
يعرض قائمة طويلة للطابعات أو الفئات أو الوظائف.
-o [وجهة(وجهات)]
يعرض الوظائف الموضوعة في قائمة الانتظار على الوجهات المحددة. إذا لم يتم تحديد أي وجهات، فسيتم عرض جميع الوظائف.
-p [طابعة(طابعات)]
يعرض الطابعات وما إذا كانت ممكّنة للطباعة. إذا لم يتم تحديد أي طابعات، فسيتم سرد جميع الطابعات.
-r
يعرض ما إذا كان خادم CUPS قيد التشغيل.
-s
يعرض ملخصًا للحالة، بما في ذلك الوجهة الافتراضية، وقائمة بالفئات والطابعات الأعضاء فيها، وقائمة بالطابعات وأجهزتها المرتبطة بها. هذا يعادل استخدام الخيارات -d و -c و -v.
-t
يعرض جميع معلومات الحالة. هذا يعادل استخدام الخيارات -r و -d و -c و -v و -a و -p و -o.
-u [مستخدم(مستخدمين)]
يعرض قائمة بوظائف الطباعة التي وضعها المستخدمون المحددة في قائمة الانتظار. إذا لم يتم تحديد مستخدمين، فإنه يسرد الوظائف التي وضعها المستخدم الحالي في قائمة الانتظار.
-v [طابعة(طابعات)]
يعرض الطابعات والجهاز الذي ترتبط به. إذا لم يتم تحديد أي طابعات، فسيتم سرد جميع الطابعات.

متوافق مع

على عكس نظام طباعة System V، يسمح CUPS لأسماء الطابعات بأن تحتوي على أي حرف قابل للطباعة باستثناء المسافة (SPACE) وعلامة الجدولة (TAB) و "/" و "#". أيضًا، أسماء الطابعات والفئات ليست حساسة لحالة الأحرف.

الخيارات -h و -e و -E و -U و -W فريدة لـ CUPS.

يتم تجاهل خيارات Solaris -f و -P و -S بصمت.
