ldns_pkt_authority(3)

NAME

ldns_pkt_authority - retrieve the authority section of a packet

SYNOPSIS


#include <ldns/packet.h>

ldns_rr_list *
ldns_pkt_authority(const ldns_pkt *pkt);

DESCRIPTION

This function retrieves the authority section of a packet. The authority section contains the authoritative name servers for the zone.

AUTHOR

Written by the ldns team.

REPORTING BUGS

Please report bugs to ldns-devel@lists.nlnetlabs.nl

COPYRIGHT

Copyright (c) 2004-2019 NLnet Labs. This is a free software package. The distribution and use of this software are permitted under the terms of the BSD license.

SEE ALSO

ldns_pkt_question(3), ldns_pkt_answer(3), ldns_pkt_add(3), ldns_pkt_set_authority(3)

REMARKS

The returned ldns_rr_list should be freed using ldns_rr_list_free().
