الحزمة: ldns

التراخيص: custom:BSD

NAME

ldns_pkt_qr - Query/Response flag

LIBRARY

ldns

SYNOPSIS

#include <stdint.h>
#include <stdbool.h>
#include <ldns/ldns.h>

uint16_t ldns_pkt_qr(const ldns_pkt *pkt);

DESCRIPTION

The ldns_pkt_qr function returns the Query/Response (QR) flag from the given DNS packet.

The QR flag is a single bit in the DNS header that indicates whether the message is a query (0) or a response (1).

الاسم

ldns_pkt_qr - علامة الاستعلام/الاستجابة

المكتبة

ldns

ملخص

#include <stdint.h>
#include <stdbool.h>

الوصف

تقوم الدالة ldns_pkt_qr بإرجاع علامة الاستعلام/الاستجابة (QR) من حزمة DNS المعطاة.

علامة QR هي بت واحد في رأس DNS يشير إلى ما إذا كانت الرسالة استعلامًا (0) أم استجابة (1).
