NAME

ldns_rdf2buffer_str_aaaa - convert a DNS resource record to a string

SYNOPSIS

#include <ldns/ldns.h>
ssize_t ldns_rdf2buffer_str_aaaa(ldns_buffer *buffer, const ldns_rdf *rdf);

DESCRIPTION

ldns_rdf2buffer_str_aaaa converts a DNS resource record (rdf) into a human readable string and appends it to the given buffer.

The given rdf must be a presentation format representation of an AAAA record.
