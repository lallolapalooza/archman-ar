ldns_pkt_get_section_clone() إرجاع كافة قوائم السجلات (rr_list) في الحزمة. يقوم بعمل نسخة من القوائم بدلاً من إرجاع مؤشرات.
p: الحزمة المراد البحث فيها
s: أي أقسام سيتم إرجاعها
إرجاع ldns_rr_list مع السجلات أو NULL إذا لم يتم العثور على أي منها

ldns_pkt_rr_list_by_name() إرجاع كافة السجلات (rr) التي تحمل اسمًا معينًا من حزمة. يمكن تحديد القسم الاختياري من الحزمة
p: الحزمة
r: الاسم
s: قسم الحزمة
إرجاع قائمة بالسجلات أو NULL إذا لم يتم العثور على أي منها

ldns_pkt_rr_list_by_type() إرجاع كافة السجلات (rr) التي تحمل نوعًا معينًا من حزمة. يمكن تحديد القسم الاختياري من الحزمة
p: الحزمة
t: النوع
s: قسم الحزمة
إرجاع قائمة بالسجلات أو NULL إذا لم يتم العثور على أي منها

ldns_pkt_rr_list_by_name_and_type() إرجاع كافة السجلات (rr) التي تحمل نوعًا واسمًا محددين من حزمة. يمكن تحديد القسم الاختياري من الحزمة
packet: الحزمة
ownername: الاسم
type: النوع
sec: قسم الحزمة
إرجاع قائمة بالسجلات أو NULL إذا لم يتم العثور على أي منها

    ldns_pkt_ancount — get number of answer resource records

    NAME

    ldns_pkt_ancount – get number of answer resource records

    SYNOPSIS

    #include <ldns/pkt.h>

    uint16_t ldns_pkt_ancount(const ldns_pkt *pkt);

    DESCRIPTION

    ldns_pkt_ancount retrieves the answer record count from the header of a ldns packet.
