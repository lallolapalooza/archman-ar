التراخيص: custom:BSD

NAME

ldns_pkt_cd - Packet Flags

SYNOPSIS

#include <ldns/pkt.h>

uint16_t ldns_pkt_cd(ldns_pkt *pkt);

DESCRIPTION

The ldns_pkt_cd function returns the value of the CD (Checking Disabled) flag from the given packet.

AUTHOR

ldns was developed by NLnet Labs.

REPORTING BUGS

Please report bugs to the ldns mailing list <ldns-users@nlnetlabs.nl>.

COPYRIGHT

SEE ALSO

ldns_pkt_aa, ldns_pkt_qr, ldns_pkt_tc, ldns_pkt_rd, ldns_pkt_ra, ldns_pkt_ad, ldns_pkt_do

REMARKS

The Checking Disabled (CD) flag is a bit in the DNS header. When set, it indicates that the checking of DNSSEC signatures is disabled.
