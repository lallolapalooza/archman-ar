ldap_extended_operation(3)

الحزمة: libldap

التراخيص: custom

LDAP_EXTENDED_OPERATION(3) دليل وظائف المكتبة LDAP_EXTENDED_OPERATION(3)

الاسم

ldap_extended_operation, ldap_extended_operation_s — توسيع عمليات LDAP إلى خادم LDAP.

المكتبة

OpenLDAP LDAP (libldap, -lldap)

الملخص

#include <ldap.h>
int ldap_extended_operation(
LDAP *ld,
const char *requestoid,
const struct berval *requestdata,
LDAPControl **sctrls,
LDAPControl **cctrls,
int *msgidp );
int ldap_extended_operation_s(
LDAP *ld,
const char *requestoid,
const struct berval *requestdata,
LDAPControl **sctrls,
LDAPControl **cctrls,
char **retoidp,
struct berval **retdatap );

الوصف

يُستخدم الإجراء ldap_extended_operation_s() لتنفيذ عملية LDAP ممتدة بشكل متزامن. يأخذ requestoid، الذي يشير إلى سلسلة OID بنظام الأرقام العشرية المعكوسة التي تحدد العملية الممتدة المراد تنفيذها. requestdata هي البيانات المطلوبة للطلب، sctrls هي مصفوفة من هياكل LDAPControl لاستخدامها مع هذه العملية الممتدة، cctrls هي مصفوفة من هياكل LDAPControl التي تسرد عناصر التحكم الخاصة بالعميل لاستخدامها مع هذه العملية الممتدة.

يشير معامل الإخراج retoidp إلى سلسلة OID بنظام الأرقام العشرية المعكوسة التي يعيدها خادم LDAP. يجب تحرير الذاكرة المستخدمة بواسطة السلسلة باستخدام وظيفة ldap_memfree(3). يشير معامل الإخراج retdatap إلى مؤشر إلى بنية berval تحتوي على البيانات المعادة. إذا لم يتم إرجاع أي بيانات بواسطة الخادم، يتم تعيين المؤشر إلى NULL. يجب تحرير الذاكرة المستخدمة بواسطة هذه البنية باستخدام وظيفة ber_bvfree(3).

تعمل وظيفة ldap_extended_operation() تمامًا مثل ldap_extended_operation_s()، ولكن العملية غير متزامنة. توفر معرف الرسالة للطلب الذي بدأته في المتغير الصحيح المشار إليه بواسطة msgidp. يمكن الحصول على نتيجة هذه العملية عن طريق استدعاء ldap_result(3).

انظر أيضًا

ber_bvfree(3)، ldap_memfree(3)، ldap_parse_extended_result(3)، ldap_result(3)
