p: الحزمة

ldns_pkt_get_section_clone() يعيد قائمة بجميع السجلات (rr_list) في الحزمة. يقوم بنسخ القوائم بدلاً من إرجاع مؤشرات.
p: الحزمة التي سيتم البحث فيها
s: أي الأقسام سيتم إرجاعها
يعيد ldns_rr_list مع السجلات أو NULL إذا لم يتم العثور على أي منها

ldns_pkt_rr_list_by_name() يعيد جميع السجلات (rr) باسم محدد من حزمة. يمكن تحديد القسم الاختياري من الحزمة
p: الحزمة
r: الاسم
s: قسم الحزمة
يعيد قائمة بالسجلات أو NULL إذا لم يتم العثور على أي منها

ldns_pkt_rr_list_by_type() يعيد جميع السجلات (rr) بنوع محدد من حزمة. يمكن تحديد القسم الاختياري من الحزمة
p: الحزمة
t: النوع
s: قسم الحزمة
يعيد قائمة بالسجلات أو NULL إذا لم يتم العثور على أي منها

ldns_pkt_rr_list_by_name_and_type() يعيد جميع السجلات (rr) بنوع واسم محددين من حزمة. يمكن تحديد القسم الاختياري من الحزمة
packet: الحزمة
ownername: الاسم
type: النوع
sec: قسم الحزمة
يعيد قائمة بالسجلات أو NULL إذا لم يتم العثور على أي منها

    NAME

    ldns_pkt_nscount - count the number of name server records in a packet

    LIBRARY

    ldns

    SYNOPSIS

    
#include <ldns/pkt.h>

size_t
ldns_pkt_nscount(const ldns_pkt *pkt);

    DESCRIPTION

    The ldns_pkt_nscount function iterates through all the resource records in the given packet pkt and counts the number of records of type NS.

    AUTHOR
