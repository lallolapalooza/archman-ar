ldns_rr_list_push_rr(3)

الحزمة: ldns

التراخيص: custom:BSD

ldns(3) دليل وظائف المكتبة ldns(3)

الاسم

ldns_rr_list_cat, ldns_rr_list_push_rr, ldns_rr_list_pop_rr - معالجة ldns_rr_list

الملخص

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_rr_list_cat(ldns_rr_list *left, const ldns_rr_list *right);

bool ldns_rr_list_push_rr(ldns_rr_list *rr_list, const ldns_rr *rr);

ldns_rr* ldns_rr_list_pop_rr(ldns_rr_list *rr_list);

الوصف

تقوم ldns_rr_list_cat() بدمج قائمتين من ldns_rr_list معًا. هذا يعدل *left (لتوسيعه وإضافة المؤشرات من *right).
left: الجانب الأيسر
right: الجانب الأيمن
يعيد القائمة اليسرى مع دمج القائمة اليمنى بها

تقوم ldns_rr_list_push_rr() بإضافة سجل RR إلى قائمة سجلات RR.
rr_list: قائمة سجلات RR المراد الإضافة إليها
rr: سجل RR المراد إضافته
يعيد false عند حدوث خطأ، وإلا فإنه يعيد true

تقوم ldns_rr_list_pop_rr() بإزالة آخر سجل RR من قائمة سجلات RR.
rr_list: قائمة سجلات RR المراد الإزالة منها
يعيد NULL إذا لم يكن هناك شيء لإزالته. وإلا فإنه يعيد سجل RR الذي تم إزالته
