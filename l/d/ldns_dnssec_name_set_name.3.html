ldns_dnssec_name_set_name(3)

التراخيص: custom:BSD

الوصف

ldns_dnssec_name_new() إنشاء بنية بيانات جديدة لاسم dnssec
تعيد البنية المخصصة

ldns_dnssec_name_new_frm_rr() إنشاء بنية بيانات جديدة لاسم dnssec من RR المحدد

rr: RR الذي سيتم استخلاص الخصائص منه، وإضافته إلى الاسم

ldns_dnssec_name_free() تحرير بنية الاسم و RRs و rrsets الخاصة بها. لا يتم تحرير سجلات ldns_rr الفردية الموجودة فيها

name: البنية التي سيتم تحريرها

ldns_dnssec_name_name() تعيد اسم النطاق لبنية dnssec_name المعطاة

name: اسم dnssec للحصول على اسم النطاق منه
تعيد اسم النطاق

ldns_dnssec_name_set_name() تعيين اسم النطاق لبنية dnssec_name المعطاة

name: اسم dnssec لتعيين اسم النطاق الخاص به
dname: اسم النطاق لتعيينه. هذه البيانات *لا* يتم نسخها.

ldns_dnssec_name_set_nsec() تعيين NSEC(3) RR لبنية dnssec_name المعطاة

name: اسم dnssec لتعيين اسم النطاق الخاص به
nsec: nsec rr لتعيينه. هذه البيانات *لا* يتم نسخها.

ldns_dnssec_name_cmp() تقارن أسماء النطاقات للحجج المعطاة بترتيبها القياسي.

a: أول dnssec_name للمقارنة
b: ثاني dnssec_name للمقارنة
تعيد -1 إذا كان اسم النطاق لـ a يأتي قبل اسم النطاق لـ b في الترتيب القياسي، 1 إذا كان العكس، و 0 إذا كانا متساويين

ldns_dnssec_name_add_rr() تُدرج RR المحدد في المكان الصحيح في dnssec_name الحالي. لا يتم إجراء أي فحص ما إذا كان الاسم متطابقًا

name: ldns_dnssec_name لإضافة RR إليه
rr: RR المراد إضافته
تعيد LDNS_STATUS_OK عند النجاح، رمز خطأ بخلاف ذلك

ldns_dnssec_name_find_rrset() البحث عن RRset بالنوع المحدد ضمن بنية الاسم هذه

name: الاسم للبحث فيه عن RRset
type: نوع RRset المراد البحث عنه
تعيد RRset، أو NULL إذا لم يكن موجودًا

ldns_dnssec_name_print() تطبع RRs في بنية اسم dnssec إلى واصف الملف المحدد

out: واصف الملف الذي سيتم الطباعة إليه
name: بنية الاسم لطباعة محتوياتها
