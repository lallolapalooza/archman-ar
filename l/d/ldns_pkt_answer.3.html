ldns_pkt_answer(3)

الحزمة: ldns

التراخيص: custom:BSD

NAME

ldns_pkt_answer

retrieves the answer section of a DNS packet

LIBRARY

libldns, -lldns

SYNOPSIS

                
                #include <ldns/dns.h>
                
                
                
                ldns_rr_list *
                ldns_pkt_answer(const ldns_pkt *pkt);

DESCRIPTION

The ldns_pkt_answer() function retrieves the answer section from the given DNS packet.

It returns a pointer to an ldns_rr_list containing the answer resource records.

If the answer section is empty, a NULL pointer is returned.

AUTHOR

REPORTING BUGS

REMARKS

The returned ldns_rr_list is owned by the packet and should not be freed by the caller. It is valid as long as the packet is valid.
