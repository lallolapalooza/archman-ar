    DESCRIPTION

    The ldns_pkt_ra function creates a new packet. The packet is initialized with a query for the given name and type. The packet is then written into the buffer. The current position in the buffer is updated accordingly. The function returns the total number of bytes written to the buffer.

The current position in the buffer is updated accordingly. The function returns the total number of bytes written to the buffer.
