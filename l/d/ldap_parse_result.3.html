ldap_parse_result(3)

الحزمة: libldap

LDAP_PARSE_RESULT(3) دليل وظائف المكتبة LDAP_PARSE_RESULT(3)

الاسم

ldap_parse_result - تحليل النتائج

المكتبة

OpenLDAP LDAP (libldap, -lldap)

الملخص

#include <ldap.h>
int ldap_parse_result( LDAP *ld, LDAPMessage *result,
	int *errcodep, char **matcheddnp, char **errmsgp,
	char ***referralsp, LDAPControl ***serverctrlsp,
	int freeit )
int ldap_parse_sasl_bind_result( LDAP *ld, LDAPMessage *result,
	struct berval **servercredp, int freeit )
int ldap_parse_extended_result( LDAP *ld, LDAPMessage *result,
	char **retoidp, struct berval **retdatap, int freeit )
int ldap_parse_intermediate( LDAP *ld, LDAPMessage *result,
	char **retoidp, struct berval **retdatap,
	LDAPControl ***serverctrlsp, int freeit )

الوصف

تُستخدم هذه الروتينات لاستخراج المعلومات من رسالة نتيجة. ستعمل على رسالة النتيجة الأولى في سلسلة من نتائج البحث (تتجاوز أنواع الرسائل الأخرى). تأخذ result كما تم إرجاعها بواسطة استدعاء إلى ldap_result(3) أو ldap_search_s(3) أو ldap_search_st(3). بالإضافة إلى ldap_parse_result()، تُستخدم الروتينات ldap_parse_sasl_bind_result() و ldap_parse_extended_result() للحصول على جميع معلومات النتيجة من عمليات ربط SASL والعمليات الموسعة. لاستخراج المعلومات من الاستجابات الوسيطة، يمكن استخدام ldap_parse_intermediate().

سيتم ملء المعلمة errcodep برمز النتيجة من رسالة النتيجة.

قد يقوم الخادم بتوفير سلسلة DN مطابقة في الرسالة تشير إلى مدى التعرف على اسم في الطلب. سيتم ملء المعلمة matcheddnp بهذه السلسلة إذا تم توفيرها، وإلا فستكون NULL. إذا تم إرجاع سلسلة، يجب تحريرها باستخدام ldap_memfree(3).

سيتم ملء المعلمة errmsgp بحقل رسالة الخطأ من الرسالة المحللة. يجب تحرير هذه السلسلة باستخدام ldap_memfree(3).

سيتم ملء المعلمة referralsp بمصفوفة مخصصة لسلاسل الإحالة من الرسالة المحللة. يجب تحرير هذه المصفوفة باستخدام ldap_memvfree(3). إذا لم يتم إرجاع أي إحالات، فسيتم تعيين *referralsp إلى NULL.

سيتم ملء المعلمة serverctrlsp بمصفوفة مخصصة لوحدات التحكم المنسوخة من الرسالة المحللة. يجب تحرير المصفوفة باستخدام ldap_controls_free(3). إذا لم يتم إرجاع أي وحدات تحكم، فسيتم تعيين *serverctrlsp إلى NULL.

تحدد المعلمة freeit ما إذا كانت الرسالة المحللة ستُحرر أم لا بعد الاستخراج. أي قيمة غير صفرية ستجعلها تحرر الرسالة. يمكن أيضًا استخدام الروتين ldap_msgfree(3) لتحرير الرسالة لاحقًا.

بالنسبة لنتائج ربط SASL، سيتم ملء المعلمة servercredp ببنية berval مخصصة تحتوي على بيانات الاعتماد من الخادم إذا كانت موجودة. يجب تحرير البنية باستخدام ber_bvfree(3).

بالنسبة للنتائج الموسعة والاستجابات الوسيطة، سيتم ملء المعلمة retoidp بتمثيل النص بنمط OID المتقطع لاسم استجابة العملية الموسعة. يجب تحرير السلسلة باستخدام ldap_memfree(3). إذا لم يتم إرجاع أي OID، فسيتم تعيين *retoidp إلى NULL.

بالنسبة للنتائج الموسعة والاستجابات الوسيطة، سيتم ملء المعلمة retdatap بمؤشر إلى بنية berval تحتوي على البيانات من استجابة العملية الموسعة. يجب تحرير البنية باستخدام ber_bvfree(3). إذا لم يتم إرجاع أي بيانات، فسيتم تعيين *retdatap إلى NULL.

بالنسبة لجميع معلمات النتائج المذكورة أعلاه، يمكن استخدام قيم NULL في الاستدعاءات لتجاهل حقول معينة.

الأخطاء

عند النجاح، يتم إرجاع LDAP_SUCCESS. بخلاف ذلك، تكون قيم معلمات النتائج غير محددة.
