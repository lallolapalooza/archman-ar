LDATTACH(8) إدارة النظام LDATTACH(8)

الاسم

ldattach - ربط بروتوكول خط بمنفذ تسلسلي

ملخص

ldattach [-1278denoVh] [-i iflag] [-s speed] ldisc device

الوصف

يقوم البرنامج الخفي ldattach بفتح ملف device المحدد (الذي يجب أن يشير إلى جهاز تسلسلي) ويربط بروتوكول الخط ldisc به لمعالجة البيانات المرسلة و/أو المستلمة. ثم ينتقل إلى الخلفية مع إبقاء الجهاز مفتوحًا حتى يظل بروتوكول الخط محملًا.

يمكن تحديد بروتوكول الخط ldisc إما بالاسم أو بالرقم.

لإلغاء ربط بروتوكول الخط، قم بتنفيذ kill(1) للعملية ldattach.

بدون وسائط، يعرض ldattach معلومات الاستخدام.

بروتوكولات الخطوط

اعتمادًا على إصدار النواة، يتم دعم بروتوكولات الخطوط التالية:

TTY(0)

بروتوكول الخط الافتراضي، يوفر تشغيلًا شفافًا (وضع خام) بالإضافة إلى إمكانيات تحرير أسطر الطرفية المعتادة (وضع مطبوخ).

SLIP(1)

معالج بروتوكول IP لخط التسلسلي (SLIP) لنقل حزم TCP/IP عبر الخطوط التسلسلية.

MOUSE(2)

مشغل جهاز لأجهزة التأشير المتصلة بـ RS232 (فئران تسلسلية).

PPP(3)

معالج بروتوكول النقطة إلى النقطة (PPP) لنقل حزم الشبكة عبر الخطوط التسلسلية.

STRIP(4); AX25(5); X25(6)

مشغل خط لنقل حزم X.25 عبر خطوط تسلسلية غير متزامنة.

6PACK(7); R3964(9)

مشغل لوحدة Simatic R3964.

IRDA(11)

مشغل Linux IrDa (نقل البيانات بالأشعة تحت الحمراء) - انظر http://irda.sourceforge.net/

HDLC(13)

مشغل HDLC المتزامن.

SYNC_PPP(14)

مشغل PPP المتزامن.

HCI(15)

مشغل Bluetooth HCI UART.

GIGASET_M101(16)

مشغل لمحول Siemens Gigaset M101 التسلسلي DECT.

PPS(18)

مشغل لمصدر نبضة في الثانية (PPS) لخط تسلسلي.

GSM0710(21)

مشغل لبروتوكول التجميع المتعدد GSM 07.10 للمودم (CMUX).

خيارات

-1, --onestopbit

تحديد عدد بتات التوقف للخط التسلسلي إلى واحد.

-2, --twostopbits

تحديد عدد بتات التوقف للخط التسلسلي إلى اثنين.

-7, --sevenbits

تحديد حجم الحرف للخط التسلسلي إلى 7 بتات.

-8, --eightbits

تحديد حجم الحرف للخط التسلسلي إلى 8 بتات.

-d, --debug

إبقاء ldattach في المقدمة بحيث يمكن مقاطعته أو تصحيحه، ولطباعة رسائل مفصلة حول تقدمه إلى المخرج القياسي للأخطاء.

-e, --evenparity

تحديد التكافؤ للخط التسلسلي ليكون زوجيًا.

-i, --iflag value...

تعيين البتات المحددة في كلمة c_iflag للخط التسلسلي. قد تكون القيمة value المعطاة رقمًا أو اسمًا رمزيًا. إذا كانت value مسبوقة بعلامة الطرح، فسيتم مسح البتات المحددة بدلاً من ذلك. يمكن إعطاء عدة قيم مفصولة بفواصل لتعيين ومسح بتات متعددة.

-n, --noparity

تحديد التكافؤ للخط التسلسلي ليكون بدون.

-o, --oddparity

تحديد التكافؤ للخط التسلسلي ليكون فرديًا.

-s, --speed value

تعيين سرعة (معدل الباود) الخط التسلسلي إلى القيمة value المحددة.

-c, --intro-command string

تحديد أمر مقدمة يتم إرساله عبر الخط التسلسلي قبل استدعاء ldattach. على سبيل المثال، بالاقتران مع بروتوكول الخط GSM0710، يكون الأمر "AT+CMUX=0\r" مناسبًا بشكل شائع للتبديل بين المودم إلى وضع CMUX.

-p, --pause value

النوم لمدة value ثانية قبل استدعاء ldattach. الافتراضي هو ثانية واحدة.

-h, --help

عرض نص المساعدة والخروج.

-V, --version

عرض الإصدار والخروج.
