    NAME

    ldns_buffer_read_at - reads data from a buffer at a given position

    LIBRARY

    ldns library

    SYNOPSIS

    #include <ldns/buffer.h>
    ssize_t ldns_buffer_read_at(ldns_buffer* buffer, size_t position, void* data, size_t size);

    DESCRIPTION

    The ldns_buffer_read_at() function reads size bytes from the given buffer, starting at the specified position, and copies them into the memory area pointed to by data. The position is an offset from the beginning of the buffer.

    The function will read at most size bytes. If the specified position plus size exceeds the current size of the buffer, the function will read only up to the end of the buffer.

    RETURN_VALUE

    On success, ldns_buffer_read_at() returns the number of bytes actually read. This value will be less than or equal to size.

    If the buffer is NULL or data is NULL, it returns -1.

    EXAMPLE

    
ldns_buffer* buffer = ldns_buffer_new(1024);
// ... populate buffer ...
char my_data[50];
ssize_t bytes_read = ldns_buffer_read_at(buffer, 10, my_data, sizeof(my_data));
if (bytes_read > 0) {
    // Successfully read 'bytes_read' bytes into my_data
}
ldns_buffer_free(buffer);

    SEE_ALSO

    ldns_buffer_new(3), ldns_buffer_push(3), ldns_buffer_read(3)

    REMARKS

    This function is useful for reading data from specific locations within a buffer without advancing the buffer's current read position.

    الاسم

    ldns_buffer_read_at - يقرأ البيانات من المخزن المؤقت في موضع معين

    المكتبة

    مكتبة ldns

    الملخص

    #include <ldns/buffer.h>
    ssize_t ldns_buffer_read_at(ldns_buffer* buffer, size_t position, void* data, size_t size);

    الوصف

    تقوم الدالة ldns_buffer_read_at() بقراءة size بايت من buffer المحدد، بدءًا من position المحدد، ونسخها إلى منطقة الذاكرة التي يشير إليها data. position هو إزاحة من بداية المخزن المؤقت.

    ستقرأ الدالة بحد أقصى size بايت. إذا كان position المحدد بالإضافة إلى size يتجاوز الحجم الحالي للمخزن المؤقت، فستقرأ الدالة فقط حتى نهاية المخزن المؤقت.

    قيمة الإرجاع

    عند النجاح، ترجع ldns_buffer_read_at() عدد البايتات التي تم قراءتها فعليًا. ستكون هذه القيمة أقل من أو تساوي size.

    إذا كان buffer هو NULL أو data هو NULL، فإنها ترجع -1.

    مثال

    
ldns_buffer* buffer = ldns_buffer_new(1024);
// ... ملء المخزن المؤقت ...
char my_data[50];
ssize_t bytes_read = ldns_buffer_read_at(buffer, 10, my_data, sizeof(my_data));
if (bytes_read > 0) {
    // تم قراءة 'bytes_read' بايت بنجاح في my_data
}
ldns_buffer_free(buffer);
