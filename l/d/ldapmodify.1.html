ldapmodify(1)

الحزمة: openldap

التراخيص: custom

NAME

ldapmodify, ldapadd, ldapdelete — تعديل، إضافة، وحذف إدخالات LDAP

SYNOPSIS

ldapmodify [-] [-a] [-c] [-C cacertfile] [-e] [-E exopchanism] [-f file] [-F sslpeerfile] [-G realm] [-h host] [-H URI] [-j authzid] [-k] [-K keyfile] [-l] [-L] [-m] [-M] [-n] [-N] [-p port] [-P promptfile] [-q] [-Q] [-r] [-R] [-s] [-S credaccess] [-t] [-T saslmech] [-U authcid] [-v] [-V] [-w passwd] [-W] [-x] [-X authzid] [-y file] [--] [host[:port] ...]

ldapadd [-a] [-c] [-C cacertfile] [-e] [-E exopchanism] [-f file] [-F sslpeerfile] [-G realm] [-h host] [-H URI] [-j authzid] [-k] [-K keyfile] [-l] [-L] [-m] [-M] [-n] [-N] [-p port] [-P promptfile] [-q] [-Q] [-r] [-R] [-s] [-S credaccess] [-t] [-T saslmech] [-U authcid] [-v] [-V] [-w passwd] [-W] [-x] [-X authzid] [-y file] [--] [host[:port] ...]

ldapdelete [-c] [-C cacertfile] [-e] [-E exopchanism] [-f file] [-F sslpeerfile] [-G realm] [-h host] [-H URI] [-j authzid] [-k] [-K keyfile] [-l] [-L] [-m] [-M] [-n] [-N] [-p port] [-P promptfile] [-q] [-Q] [-r] [-R] [-s] [-S credaccess] [-t] [-T saslmech] [-U authcid] [-v] [-V] [-w passwd] [-W] [-x] [-X authzid] [-y file] [--] [host[:port] ...]

DESCRIPTION

تُستخدم أدوات سطر الأوامر ldapadd و ldapdelete و ldapmodify لإضافة إدخالات LDAP أو حذفها أو تعديلها. يتم تحديد التغييرات المطلوب إجراؤها في ملف بتنسيق LDIF (LDAP Data Interchange Format).

ldapadd يضيف إدخالات جديدة إلى دليل LDAP.

ldapdelete يحذف إدخالات من دليل LDAP.

ldapmodify يعدل إدخالات موجودة في دليل LDAP.

يمكن لـ ldapmodify إجراء عمليات إضافة أو استبدال أو حذف لسمات محددة داخل إدخال. عندما يتم استخدام -a مع ldapmodify، فإنه يضيف إدخالات جديدة، أي أنه يقوم بعمل ldapadd. عندما يتم استخدام -d مع ldapmodify، فإنه يحذف إدخالات، أي أنه يقوم بعمل ldapdelete. لذلك، فإن ldapadd و ldapdelete هما مجرد اختصارات لـ ldapmodify مع خيارات محددة.

OPTIONS

-a أضف الإدخالات. هذا الخيار له نفس تأثير تشغيل ldapadd.

-c وضع الاستمرارية. يواصل تشغيل الأداة حتى لو حدثت أخطاء. بدون هذا الخيار، تتوقف الأداة عند أول خطأ.

-C cacertfile اسم الملف الذي يحتوي على شهادة CA الموثوقة.

-e يطبع رسالة الخطأ في حالة فشل عملية الـ LDAP.

-E exopchanism آلية التوسع (Extended Operation).

-f file اسم الملف الذي يحتوي على التغييرات المراد إجراؤها. إذا لم يتم تحديد هذا الخيار، فسيتم قراءة الإدخال من الإدخال القياسي.

-F sslpeerfile اسم الملف الذي يحتوي على شهادة CA الموثوقة.

-G realm نطاق SASL.

-h host اسم مضيف خادم LDAP.

-H URI عنوان URI لخادم LDAP.

-j authzid تصريح المصادقة.

-k تخطي التحقق من خادم LDAP.

-K keyfile اسم الملف الذي يحتوي على مفتاح العميل الخاص.

-l تعطيل التحقق من إرث السمات.

-L تعطيل التحقق من القيود.

-m تعطيل التحقق من مخطط الدليل.

-M تمكين وضع تعديل الدليل.

-n لا تقم بتنفيذ العملية. فقط قم بطباعة التغييرات التي سيتم إجراؤها.

-N لا تطلب كلمة المرور.

-p port رقم منفذ خادم LDAP.

-P promptfile اسم الملف الذي يحتوي على المطالبات.

-q طلب كلمة المرور.

-Q لا تطلب كلمة المرور.

-r تخطي التحقق من وجود الإدخال.

-R تخطي إعادة توجيه HTTP.

-s نمط سمة.

-S credaccess وصول بيانات الاعتماد.

-t نمط تعديل.

-T saslmech آلية SASL.

-U authcid معرف المصادقة.

-v وضع مطول.

-V طباعة رقم إصدار الأدوات.

-w passwd كلمة المرور.

-W طلب كلمة المرور.

-x استخدام المصادقة البسيطة.

-X authzid تصريح المصادقة.

-y file اسم الملف الذي يحتوي على بيانات الاعتماد.

INPUT FORMAT

يجب أن يتوافق محتوى file (أو الإدخال القياسي إذا لم يتم إعطاء علامة -f في سطر الأوامر) مع التنسيق المحدد في ldif(5) (LDIF كما هو محدد في RFC 2849).

EXAMPLES

بافتراض أن الملف /tmp/entrymods موجود ويحتوي على:

    dn: cn=Modify Me,dc=example,dc=com
    changetype: modify
    replace: mail
    mail: modme@example.com
    -
    add: title
    title: Grand Poobah
    -
    add: jpegPhoto
    jpegPhoto:< file:///tmp/modme.jpeg
    -
    delete: description
    -

الأمر:

    ldapmodify -f /tmp/entrymods

سيستبدل محتويات السمة mail للإدخال "Modify Me" بالقيمة "modme@example.com"، ويضيف title بقيمة "Grand Poobah"، ومحتويات الملف "/tmp/modme.jpeg" كـ jpegPhoto، ويزيل السمة description بالكامل.

بافتراض أن الملف /tmp/newentry موجود ويحتوي على:

    dn: cn=Barbara Jensen,dc=example,dc=com
    objectClass: person
    cn: Barbara Jensen
    cn: Babs Jensen
    sn: Jensen
    title: the world's most famous mythical manager
    mail: bjensen@example.com
    uid: bjensen

الأمر:

    ldapadd -f /tmp/newentry

سيضيف إدخالًا جديدًا لـ Babs Jensen، باستخدام القيم من الملف /tmp/newentry.

بافتراض أن الملف /tmp/entrymods موجود ويحتوي على:

    dn: cn=Barbara Jensen,dc=example,dc=com
    changetype: delete

الأمر:

    ldapmodify -f /tmp/entrymods

سيقوم بحذف إدخال Babs Jensen.
