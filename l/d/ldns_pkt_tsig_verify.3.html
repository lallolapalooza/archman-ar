ldns_pkt_tsig_verify(3)

الحزمة: ldns

التراخيص: custom:BSD

ldns(3) دليل وظائف المكتبة ldns(3)

الاسم

ldns_pkt_tsig_verify, ldns_pkt_tsig_sign - توقيع TSIG والتحقق منه

الملخص

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_pkt_tsig_verify(ldns_pkt *pkt, const uint8_t *wire, size_t wire_size, const char *key_name, const char *key_data, const ldns_rdf *mac);

ldns_status ldns_pkt_tsig_sign(ldns_pkt *pkt, const char *key_name, const char *key_data, uint16_t fudge, const char *algorithm_name, const ldns_rdf *query_mac);

الوصف

تقوم ldns_pkt_tsig_verify() بالتحقق من سجل TSIG للحزمة والمفتاح المعطيين. يجب توفير السلك أيضًا لأن TSIG لا يوقع الحزم المعيارية.
pkt: الحزمة المراد التحقق منها
wire: مطلوب للتحقق من MAC
wire_size: حجم السلك
key_name: اسم المفتاح المشترك
key_data: المفتاح بتنسيق base64
mac: MAC الأصلي
تُرجع true إذا كان TSIG صحيحًا، و false إذا لم يكن كذلك، أو إذا لم يتم تعيين TSIG

تقوم ldns_pkt_tsig_sign() بإنشاء سجل TSIG للحزمة والمفتاح المعطيين.
pkt: الحزمة المراد توقيعها
key_name: اسم المفتاح المشترك
key_data: المفتاح بتنسيق base64
fudge: عدد الثواني المسموح به من الخطأ في وقت التوقيع
algorithm_name: اسم الخوارزمية المستخدمة
query_mac: يُضاف إلى الملخص إذا لم يكن NULL (لذا NULL هو لتوقيع الاستعلامات، وغير NULL هو لتوقيع الردود)
تُرجع الحالة (OK في حالة النجاح)
