ldap_rename(3)

الحزمة: libldap

التراخيص: custom

LDAP_RENAME(3) دليل وظائف المكتبة LDAP_RENAME(3)

الاسم

ldap_rename, ldap_rename_s - إعادة تسمية الإدخال المحدد.

المكتبة

OpenLDAP LDAP (libldap, -lldap)

الملخص

#include <ldap.h>
int ldap_rename( ld, dn, newrdn, newparent, deleteoldrdn, sctrls[], cctrls[], msgidp );
LDAP *ld;
const char *dn, *newrdn, *newparent;
int deleteoldrdn;
LDAPControl *sctrls[], *cctrls[];
int *msgidp);
int ldap_rename_s( ld, dn, newrdn, newparent, deleteoldrdn, sctrls[], cctrls[] );
LDAP *ld;
const char *dn, *newrdn, *newparent;
int deleteoldrdn;
LDAPControl *sctrls[], *cctrls[];

الوصف

تُستخدم هذه الروتينات لتنفيذ عملية إعادة تسمية LDAP. تقوم الوظيفة بتغيير المكون الورقي للاسم المميز للإدخال وربما نقل الإدخال إلى حاوية أب جديدة. تقوم ldap_rename_s بتنفيذ عملية إعادة تسمية بشكل متزامن. تأخذ الطريقة dn، التي تشير إلى الاسم المميز للإدخال الذي يتم مقارنة سمته، newparent، الاسم المميز للأب الجديد للإدخال. إذا كانت هذه المعلمة NULL، يتم تغيير RDN فقط. يتم تحديد DN الجذر بتمرير سلسلة فارغة، "". تحدد deleteoldrdn ما إذا كان يجب الاحتفاظ بـ RDN القديم أو حذفه. يشير الصفر إلى أنه يجب الاحتفاظ بـ RDN القديم. إذا اخترت هذا الخيار، فسيحتوي السمة على كلا الاسمين (القديم والجديد). يشير أي قيمة غير صفرية إلى أنه يجب حذف RDN القديم. تشير serverctrls إلى مصفوفة من هياكل LDAPControl التي تسرد عناصر التحكم العميل المراد استخدامها مع هذه العملية الموسعة. استخدم NULL لتحديد عدم وجود عناصر تحكم للعميل. تشير clientctrls إلى مصفوفة من هياكل LDAPControl التي تسرد عناصر التحكم العميل المراد استخدامها مع البحث.

تعمل ldap_rename بنفس طريقة عمل ldap_rename_s، ولكن العملية غير متزامنة. تُرجع معرف الرسالة للطلب الذي بدأت فيه. يمكن الحصول على نتيجة هذه العملية عن طريق استدعاء ldap_result(3).

الأخطاء

تُرجع ldap_rename() القيمة -1 في حالة حدوث خطأ في بدء الطلب، وستقوم بتعيين حقل ld_errno في المعلمة ld للإشارة إلى الخطأ. تُرجع ldap_rename_s() رمز خطأ LDAP الناتج عن عملية إعادة التسمية.
