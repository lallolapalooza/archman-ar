ldap_result(3)

الحزمة: libldap

التراخيص: custom

LDAP_RESULT(3) دليل وظائف المكتبة LDAP_RESULT(3)

الاسم

ldap_result - انتظار نتيجة عملية LDAP

المكتبة

OpenLDAP LDAP (libldap, -lldap)

ملخص

#include <ldap.h>
int ldap_result( LDAP *ld, int msgid, int all,
	struct timeval *timeout, LDAPMessage **result );
int ldap_msgfree( LDAPMessage *msg );
int ldap_msgtype( LDAPMessage *msg );
int ldap_msgid( LDAPMessage *msg );

الوصف

يُستخدم الروتين ldap_result() للانتظار واسترجاع نتيجة عملية تم بدؤها مسبقًا بواسطة أحد روتينات عمليات LDAP غير المتزامنة (على سبيل المثال، ldap_search_ext(3)، ldap_modify_ext(3)، إلخ). تُعيد هذه الروتينات -1 في حالة حدوث خطأ، ومعرّف استدعاء عند بدء العملية بنجاح. يتم اختيار معرّف الاستدعاء بواسطة المكتبة ويُضمن أن يكون فريدًا عبر جلسة LDAP. يمكن استخدامه لطلب نتيجة عملية معينة من ldap_result() عبر المعلمة msgid.

سيتم حظر الروتين ldap_result() أم لا، اعتمادًا على إعداد المعلمة timeout. إذا كانت timeout ليست مؤشرًا فارغًا (NULL)، فإنها تحدد أقصى فترة انتظار لاكتمال الاختيار. إذا كانت timeout مؤشرًا فارغًا (NULL)، فسيتم استخدام قيمة LDAP_OPT_TIMEOUT التي تم تعيينها بواسطة ldap_set_option(3). مع الإعداد الافتراضي، يتم حظر الاختيار إلى أجل غير مسمى. لتنفيذ استطلاع، يجب أن تكون المعلمة timeout مؤشرًا غير فارغ (non-NULL)، يشير إلى بنية timeval ذات قيمة صفرية. للحصول على سلوك الإعداد الافتراضي، مع تجاوز أي قيمة تم تعيينها بواسطة ldap_set_option(3)، قم بتعيين الحقل tv_sec للمعلمة timeout إلى -1. راجع select(2) لمزيد من التفاصيل.

إذا كانت نتيجة عملية معينة مطلوبة، فيجب تعيين msgid إلى معرّف الاستدعاء الذي تم إرجاعه عند بدء العملية، وإلا يجب توفير LDAP_RES_ANY أو LDAP_RES_UNSOLICITED للانتظار لأي استجابة أو استجابة غير مرغوب فيها.

المعلمة all، إذا كانت غير صفرية، تتسبب في أن يُعيد ldap_result() جميع الاستجابات مع msgid، وإلا يتم إرجاع الاستجابة التالية فقط. يُستخدم هذا عادةً للحصول على جميع استجابات عملية البحث.

تتكون استجابة البحث من صفر أو أكثر من إدخالات البحث، وصفر أو أكثر من مراجع البحث، وصفر أو أكثر من الاستجابات الجزئية الموسعة تليها نتيجة البحث. إذا تم تعيين all إلى 0، فسيتم إرجاع إدخالات البحث واحدًا تلو الآخر فور وصولها، عبر استدعاءات منفصلة لـ ldap_result(). إذا تم تعيينها إلى 1، فسيتم إرجاع استجابة البحث بالكامل فقط، أي بعد استلام جميع الإدخالات، وجميع المراجع، وجميع الاستجابات الجزئية الموسعة، ونتيجة البحث النهائية.

قيمة الإرجاع

عند النجاح، يتم إرجاع نوع النتيجة المستلمة وستحتوي المعلمة result على نتيجة العملية؛ وإلا، فإن المعلمة result غير محددة. يجب تمرير هذه النتيجة إلى روتينات تحليل LDAP، ldap_first_message(3) وما يتبعها، للتفسير.

أنواع النتائج المحتملة التي تم إرجاعها هي:

LDAP_RES_BIND (0x61)
LDAP_RES_SEARCH_ENTRY (0x64)
LDAP_RES_SEARCH_REFERENCE (0x73)
LDAP_RES_SEARCH_RESULT (0x65)
LDAP_RES_MODIFY (0x67)
LDAP_RES_ADD (0x69)
LDAP_RES_DELETE (0x6b)
LDAP_RES_MODDN (0x6d)
LDAP_RES_COMPARE (0x6f)
LDAP_RES_EXTENDED (0x78)
LDAP_RES_INTERMEDIATE (0x79)

يُستخدم الروتين ldap_msgfree() لتحرير الذاكرة المخصصة للنتائج بواسطة ldap_result() أو ldap_search_ext_s(3) وما يتبعها. يأخذ مؤشرًا إلى النتيجة أو سلسلة النتائج المراد تحريرها ويُعيد نوع الرسالة الأخيرة في السلسلة. إذا كان المؤشر فارغًا (NULL)، فإن الدالة لا تفعل شيئًا وتُعيد صفرًا.

يُعيد الروتين ldap_msgtype() نوع الرسالة.

يُعيد الروتين ldap_msgid() معرّف الرسالة لرسالة.

الأخطاء

يُعيد ldap_result() -1 إذا حدث خطأ ما، وصفر إذا تم تجاوز المهلة المحددة. يُعيد ldap_msgtype() و ldap_msgid() -1 عند حدوث خطأ.
