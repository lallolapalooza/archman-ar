NAME

ldns_pkt_get_opcode - get the opcode from a DNS packet

LIBRARY

libldns

SYNOPSIS

#include <ldns/ldns.h>

ldns_lookup_type ldns_pkt_get_opcode(ldns_pkt *pkt);

DESCRIPTION

The function ldns_pkt_get_opcode retrieves the opcode of the DNS packet pointed to by pkt.
