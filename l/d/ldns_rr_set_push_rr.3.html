ldns_rr_set_push_rr(3)

الحزمة: ldns

التراخيص: custom:BSD

ldns(3) دليل وظائف المكتبة ldns(3)

الاسم

ldns_rr_set_push_rr, ldns_rr_set_pop_rr - دفع وسحب سجلات RR على مجموعة سجلات RR (rrset)

الملخص

#include <stdint.h>
#include <stdbool.h>

#include <ldns/ldns.h>

bool ldns_rr_set_push_rr(ldns_rr_list *rr_list, ldns_rr *rr);

ldns_rr* ldns_rr_set_pop_rr(ldns_rr_list *rr_list);

الوصف

تقوم الدالة ldns_rr_set_push_rr() بدفع سجل RR إلى مجموعة سجلات RR (والتي هي في الواقع قوائم سجلات RR - rr_list).
*rr_list: مجموعة سجلات RR التي سيتم دفع سجل RR إليها.
*rr: سجل RR الذي سيتم دفعه.
تُرجع القيمة true إذا نجحت عملية الدفع، وإلا تُرجع false.

تقوم الدالة ldns_rr_set_pop_rr() بسحب آخر سجل RR من مجموعة سجلات RR. هذه الدالة موجودة فقط من أجل التناظر.
rr_list: قائمة سجلات RR التي سيتم السحب منها.
تُرجع NULL إذا لم يكن هناك شيء للسحب. وإلا تُرجع سجل RR الذي تم سحبه.
