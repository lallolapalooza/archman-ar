ldns_rdf2buffer_str_nsec(3)

الحزمة: ldns

التراخيص: custom:BSD

NAME

ldns_rdf2buffer_str_nsec, ldns_rdf2buffer_str_nsec_owner - convert NSEC resource record data into a string

SYNOPSIS

In <ldns/util.h>:

int ldns_rdf2buffer_str_nsec(char **str, size_t *len, ldns_rdf *rdf);
int ldns_rdf2buffer_str_nsec_owner(char **str, size_t *len, ldns_rdf *rdf,
    ldns_rdf *owner);

DESCRIPTION

The function ldns_rdf2buffer_str_nsec converts an NSEC resource record data into a string. The string is stored in the buffer pointed to by str, and its size is stored in len. The caller is responsible for freeing the allocated memory for str.

The function ldns_rdf2buffer_str_nsec_owner does the same, but also takes the owner name of the record, which is needed to convert the owner name to the canonical presentation form.

الاسم

ldns_rdf2buffer_str_nsec, ldns_rdf2buffer_str_nsec_owner - تحويل بيانات سجل مورد NSEC إلى سلسلة نصية

الملخص

في <ldns/util.h>:

int ldns_rdf2buffer_str_nsec(char **str, size_t *len, ldns_rdf *rdf);
int ldns_rdf2buffer_str_nsec_owner(char **str, size_t *len, ldns_rdf *rdf,

الوصف

تقوم الدالة ldns_rdf2buffer_str_nsec بتحويل بيانات سجل مورد NSEC إلى سلسلة نصية. يتم تخزين السلسلة النصية في المخزن المؤقت الذي يشير إليه str، ويتم تخزين حجمها في len. يكون المستدعي مسؤولاً عن تحرير الذاكرة المخصصة لـ str.

تقوم الدالة ldns_rdf2buffer_str_nsec_owner بالمثل، ولكنها تأخذ أيضًا اسم المالك للسجل، والذي يلزم لتحويل اسم المالك إلى شكله التقديمي القياسي.
