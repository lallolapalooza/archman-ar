ldns_rdf2buffer_str_a(3)

الحزمة: ldns

التراخيص: custom:BSD

NAME

ldns_rdf2buffer_str_a, ldns_rdf2buffer_str_str, ldns_rdf2buffer_str_ipv4, ldns_rdf2buffer_str_ipv6 - convert a data structure to string representation

SYNOPSIS

#include <ldns/util.h>
#include <ldns/types.h>

    ssize_t
    ldns_rdf2buffer_str_a(char *buffer, size_t len, const ldns_rdf *rdf);
    ssize_t
    ldns_rdf2buffer_str_str(char *buffer, size_t len, const ldns_rdf *rdf);
    ssize_t
    ldns_rdf2buffer_str_ipv4(char *buffer, size_t len, const ldns_rdf *rdf);
    ssize_t
    ldns_rdf2buffer_str_ipv6(char *buffer, size_t len, const ldns_rdf *rdf);

DESCRIPTION

The ldns library provides functions for manipulating DNS records. These functions can be used to convert ldns_rdf objects into string representations. The functions are specific to the type of data the ldns_rdf object contains.

The ldns_rdf2buffer_str_a function converts an ldns_rdf object containing an A record (IPv4 address) into a string representation. It writes the string to the provided buffer of the given length.

The ldns_rdf2buffer_str_str function converts an ldns_rdf object containing a string into a string representation. It writes the string to the provided buffer of the given length.

The ldns_rdf2buffer_str_ipv4 function converts an ldns_rdf object containing an IPv4 address into a string representation. It writes the string to the provided buffer of the given length.

The ldns_rdf2buffer_str_ipv6 function converts an ldns_rdf object containing an IPv6 address into a string representation. It writes the string to the provided buffer of the given length.

All functions return the number of bytes written to the buffer, or -1 if an error occurred (e.g., the buffer is too small).
