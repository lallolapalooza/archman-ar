    ldns_pkt_id(3) - get the packet identifier

    NAME

    ldns_pkt_id - get the packet identifier

    LIBRARY

    ldns (libldns, -lldns)

    SYNOPSIS

    #include <ldns/dns.h>

    uint16_t ldns_pkt_id(const ldns_pkt *pkt);

    DESCRIPTION

    The ldns_pkt_id() function retrieves the 16-bit identifier from the given DNS packet.
