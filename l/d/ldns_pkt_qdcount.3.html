NAME

ldns_pkt_qdcount — return the question count of a DNS packet

LIBRARY

ldns

SYNOPSIS

#include <ldns/ldns.h>

uint16_t
ldns_pkt_qdcount(const ldns_pkt *pkt);

DESCRIPTION

The ldns_pkt_qdcount function returns the question count of the DNS packet pkt.
