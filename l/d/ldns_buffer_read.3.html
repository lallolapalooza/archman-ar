ldns_buffer_read(3)

ldns_buffer_read

read from a buffer

SYNOPIS

#include <ldns/buffer.h>

uint8_t *
ldns_buffer_read(ldns_buffer *buffer, size_t len);

DESCRIPTION

Reads len bytes from the current position of buffer. The current position is advanced by len bytes. If the buffer does not contain len bytes, NULL is returned.

ARGUMENTS

buffer
The buffer to read from.
len
The number of bytes to read.

RETURN VALUE

A pointer to the data read from the buffer, or NULL if the buffer does not contain len bytes.
