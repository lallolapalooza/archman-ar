};

DESCRIPTION

The ldns_rr_type enumeration contains all known DNS resource record types as defined by IANA and some experimental types. The values of these constants correspond to the numeric type codes used in DNS.

The ldns_rr_compress enumeration is used to specify whether DNS name compression is allowed when writing DNS messages.

The ldns_rr_list structure represents a list or set of resource records (RR). It is a dynamic array of pointers to ldns_rr structures. The _rr_count field stores the current number of RRs in the list, and _rr_capacity stores the allocated capacity of the underlying array. The _rrs field is a pointer to the array of RR pointers.
