lkbib(1) دليل الأوامر العامة lkbib(1)

الاسم

lkbib - البحث في قواعد البيانات الببليوغرافية

الملخص

lkbib [-n] [-i الحقول] [-p الملف] ... [-t n] الكلمة_المفتاحية ...
lkbib --help
lkbib -v
lkbib --version

الوصف

يقوم lkbib بالبحث في قواعد البيانات الببليوغرافية عن مراجع تحتوي على الكلمات المفتاحية key ويكتب أي مراجع تم العثور عليها إلى دفق الإخراج القياسي. يقرأ قواعد البيانات المعطاة بخيارات -p ثم (إلا إذا تم إعطاء -n) قاعدة بيانات افتراضية. يتم أخذ قاعدة البيانات الافتراضية من متغير البيئة REFER إذا تم تعيينه، وإلا فإنه يكون /usr/dict/papers/Ind. لكل قاعدة بيانات file للبحث فيها، إذا كان هناك ملف فهرس .i تم إنشاؤه بواسطة indxbib(1) موجودًا، فسيتم البحث فيه بدلاً من ذلك؛ يمكن لكل فهرس تغطية قواعد بيانات متعددة.

الخيارات

يعرض --help رسالة استخدام، بينما يعرض -v و --version معلومات الإصدار؛ كلها تخرج بعد ذلك.

-i سلسلة
عند البحث في الملفات التي لا يوجد لها فهرس، تجاهل محتويات الحقول التي تقع أسماؤها في string.
-n
قم بقمع البحث في قاعدة البيانات الافتراضية.
-p ملف
ابحث في file. يمكن استخدام خيارات -p متعددة.
-t n
تطلب فقط الأحرف الأولى n من الكلمات المفتاحية. الافتراضي هو 6.

البيئة

REFER
قاعدة البيانات الافتراضية.

الملفات

/usr/dict/papers/Ind
قاعدة البيانات الافتراضية التي سيتم استخدامها إذا لم يتم تعيين متغير البيئة REFER.
file.i
ملفات الفهرس.
