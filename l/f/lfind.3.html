lsearch(3) دليل وظائف المكتبة lsearch(3)

الاسم

lfind، lsearch - بحث خطي في مصفوفة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <search.h>
void *lfind(size_t *n, const void *key, const void *base, size_t size,
            typeof(int (const void *, const void *)) compar);
void *lsearch(size_t *n, const void *key, void *base, size_t size,
            typeof(int (const void *, const void *)) compar);

الوصف

تقوم lfind() و lsearch() بإجراء بحث خطي عن key في المصفوفة base التي تحتوي على *n عنصر بحجم size بايت لكل منها. يتوقع من دالة المقارنة المشار إليها بواسطة compar أن تأخذ وسيطين يشيران إلى كائن key وعضو في المصفوفة، بهذا الترتيب، وأن تعيد صفرًا إذا تطابق كائن key مع عضو المصفوفة، وتعيد قيمة غير صفرية بخلاف ذلك.

إذا لم تعثر lsearch() على عنصر مطابق، فسيتم إدراج كائن key في نهاية الجدول، وسيتم زيادة *n. على وجه الخصوص، يجب أن تعرف أن عنصرًا مطابقًا موجود، أو أن هناك مساحة إضافية متاحة.

قيمة الإرجاع

تعيد lfind() مؤشرًا إلى عضو مطابق في المصفوفة، أو NULL إذا لم يتم العثور على تطابق. تعيد lsearch() مؤشرًا إلى عضو مطابق في المصفوفة، أو إلى العضو المضاف حديثًا إذا لم يتم العثور على تطابق.
