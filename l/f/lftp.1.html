lftp(1)

الحزمة: lftp

التراخيص: GPL-3.0-or-later

-l, --long استخدام تنسيق قائمة مفصل
-q, --quiet عدم إظهار الحالة
-s, --size طباعة حجم كل ملف
--filesize إذا كنت تقوم بطباعة الحجم، اطبع حجم الملفات فقط
-i, --nocase مطابقة الأنماط غير حساسة لحالة الأحرف
-I, --sortnocase فرز الأسماء غير حساسة لحالة الأحرف
-D, --dirsfirst قائمة الدلائل أولاً
--sort=OPT "name", "size", "date"
-S فرز حسب حجم الملف
--user, --group,
--perms, --date,
--linkcount, --links إظهار الحقول الفردية

command cmd args...

تنفيذ الأمر المحدد مع تجاهل الأسماء المستعارة.

debug [OPTS] level|off

تبديل التصحيح إلى level أو إيقافه. الخيارات:

-T اقتطاع ملف الإخراج
-o <file> إعادة توجيه إخراج التصحيح إلى الملف
-c إظهار سياق الرسالة
-p إظهار PID
-t إظهار الطوابع الزمنية

du [OPTS] path...

تلخيص استخدام القرص. الخيارات:

-a, --all كتابة الأعداد لجميع الملفات، وليس الدلائل فقط
--block-size=SIZ استخدام كتل بحجم SIZ بايت
-b, --bytes طباعة الحجم بالبايت
-c, --total إنتاج إجمالي
-d, --max-depth=N طباعة الإجمالي لدليل (أو ملف، مع --all) فقط إذا كان N أو أقل مستويات تحت وسيط سطر الأوامر؛ --max-depth=0 هو نفس --summarize
-F, --files طباعة عدد الملفات بدلاً من الأحجام
-h, --human-readable طباعة الأحجام بتنسيق سهل القراءة (مثل 1K 234M 2G)
-H, --si وبالمثل، ولكن استخدم قوى 1000 وليس 1024
-k, --kilobytes مثل --block-size=1024
-m, --megabytes مثل --block-size=1048576
-S, --separate-dirs عدم تضمين حجم الدلائل الفرعية
-s, --summarize عرض ملخص فقط لكل وسيط
--exclude=PAT استبعاد الملفات التي تطابق PAT

echo [-n] string

يطبع (يكرر) السلسلة المحددة إلى الشاشة.

edit [OPTS] file

استرداد الملف البعيد إلى موقع مؤقت، وتشغيل محرر محلي عليه، وتحميل الملف مرة أخرى إذا تم تغييره. الخيارات:

-k الاحتفاظ بالملف المؤقت
-o <temp> موقع ملف مؤقت صريح

eval [-f format ] args...

بدون -f، يقوم بتنفيذ الوسائط المحددة كأمر. مع -f، يتم تحويل الوسائط إلى أمر جديد. يمكن أن يحتوي التنسيق على نص عادي وعناصر نائبة $0...$9 و $@، المقابلة للوسائط.

exit [bg] [top] [parent] [kill] [code]

سيؤدي الخروج إلى الخروج من lftp أو الانتقال إلى الخلفية إذا كانت هناك مهام نشطة. إذا لم تكن هناك مهمة نشطة، يتم تمرير code إلى نظام التشغيل كحالة إنهاء lftp. إذا تم حذف code، يتم استخدام رمز خروج آخر أمر.

``exit bg'' يجبر الانتقال إلى الخلفية عندما يكون cmd:move-background خطأ. ``exit top'' يجعل المنفذ الداخلي للأوامر `shell' (منفذ أوامر lftp الداخلية) ينهي. ``exit parent'' ينهي shell الأب عند تشغيل برنامج نصي متداخل. ``exit kill'' يقتل جميع المهام المرقمة قبل الخروج. يمكن دمج الخيارات، على سبيل المثال، ``at 08:00 -- exit top kill &'' يقتل جميع المهام ويجعل lftp يخرج في الوقت المحدد.

fg

اسم مستعار لـ `wait'.

find [OPTS] directory...

سرد الملفات في الدليل (الدليل الحالي افتراضيًا) بشكل متكرر. يمكن أن يساعد هذا الخوادم التي تفتقر إلى دعم ls -R. يمكنك إعادة توجيه إخراج هذا الأمر. الخيارات:

-d MD, --max-depth=MD تحديد أقصى عمق للمسح
-l, --ls استخدام تنسيق قائمة مفصل

ftpcopy

مهمل. استخدم أحد الخيارات التالية بدلاً من ذلك:

get ftp://... -o ftp://...
get -O ftp://... file1 file2...
put ftp://...
mput ftp://.../*
mget -O ftp://... ftp://.../*
أو تركيبات أخرى للحصول على نقل FXP (مباشرة بين خادمين FTP). سيعود lftp إلى النسخ العادي (عبر العميل) إذا لم يتمكن من بدء نقل FXP أو إذا كان ftp:use-fxp خطأ.

get [-E] [-a] [-c] [-e] [-P N] [-O base] rfile [-o lfile] ...

استرداد الملف البعيد rfile وتخزينه كملف محلي lfile. إذا تم حذف -o، يتم تخزين الملف في ملف محلي بنفس اسم الأساس لـ rfile. يمكنك الحصول على ملفات متعددة عن طريق تحديد مثيلات متعددة من rfile (و -o lfile). لا يقوم بتوسيع أحرف البدل، استخدم mget لذلك.

-c متابعة، إعادة الحصول
-E حذف ملفات المصدر بعد النقل الناجح
-e حذف ملف الوجهة قبل النقل
-a استخدام وضع ASCII (ثنائي هو الافتراضي)
-P N تنزيل N ملفات بالتوازي
-O <base> تحديد الدليل الأساسي أو عنوان URL حيث يجب وضع الملفات

أمثلة:

get README
get README -o debian.README
get README README.mirrors
get README -o debian.README README.mirrors -o debian.mirrors
get README -o ftp://some.host.org/debian.README
get README -o ftp://some.host.org/debian-dir/   (النهاية / مهمة)

get1 [OPTS] rfile

نقل ملف واحد. الخيارات:

-o <lfile> اسم الملف الوجهة (الافتراضي - اسم الأساس لـ rfile)
-c متابعة، إعادة الحصول
-E حذف ملفات المصدر بعد النقل الناجح
-a استخدام وضع ASCII (ثنائي هو الافتراضي)
-d إنشاء دليل الملف الوجهة
--source-region=<from-to> نقل منطقة محددة من ملف المصدر
--target-position=<pos> موضع في الملف الوجهة للكتابة فيه

glob [OPTS] [command] patterns

توسيع الأنماط المحددة التي تحتوي على أحرف خاصة وتمرير النتيجة إلى الأمر المحدد أو إرجاع رمز الخروج المناسب.

-f ملفات عادية (افتراضي)
-d دلائل
-a جميع الأنواع
--exist إرجاع رمز خروج صفر عندما تتوسع الأنماط إلى قائمة غير فارغة
--not-exist إرجاع رمز خروج صفر عندما تتوسع الأنماط إلى قائمة فارغة

أمثلة:

glob echo *
glob --exist *.csv && echo "There are *.csv files"

help [cmd]

طباعة المساعدة لـ cmd أو إذا لم يتم تحديد cmd، طباعة قائمة بالأوامر المتاحة.

history [OPTS] [cnt]

عرض أو تعديل سجل الأوامر. الوسيط الاختياري cnt يحدد عدد سطور السجل التي سيتم سردها، أو "all" لسرد جميع الإدخالات. الخيارات:

-w <file> كتابة السجل إلى ملف.
-r <file> قراءة السجل من ملف؛ يلحق بالسجل الحالي.
-c مسح السجل.
-l سرد السجل (افتراضي).

jobs [OPTS] [job_no...]

سرد المهام قيد التشغيل. إذا تم تحديد job_no، قم بسرد مهمة واحدة بهذا الرقم فقط. الخيارات:

-v مطول، عدة -v تزيد المطول
-r سرد مهمة واحدة محددة فقط دون تكرار

kill all|job_no

حذف المهمة المحددة برقم job_no أو جميع المهام. (لـ job_no انظر jobs)

lcd ldir

تغيير الدليل المحلي الحالي ldir. يتم تخزين الدليل المحلي السابق كـ '-'. يمكنك القيام بـ `lcd -' للعودة إلى الدليل السابق.

ln [-s] existing-file new-link

إنشاء رابط ثابت/رمزي لملف موجود. الخيار -s يختار إنشاء رابط رمزي.

local command

تشغيل الأمر المحدد باستخدام جلسة ملف محلية file:// بدلاً من جلسة بعيدة. أمثلة:

local pwd
local ls
local mirror /dir1 /dir2

lpwd

طباعة دليل العمل الحالي على الجهاز المحلي.

ls params

سرد الملفات البعيدة. يمكنك إعادة توجيه إخراج هذا الأمر إلى ملف أو عبر أنبوب إلى أمر خارجي. افتراضيًا، يتم تخزين إخراج ls مؤقتًا، لرؤية قائمة جديدة استخدم rels أو cache flush.

mget [-c] [-d] [-a] [-E] [-e] [-P N] [-O base] files

الحصول على الملفات المحددة مع أحرف البدل الموسعة.

cmd:queue-parallel (number)
عدد المهام التي تعمل بالتوازي في قائمة انتظار.
cmd:remote-completion (boolean)
قيمة منطقية للتحكم في ما إذا كان lftp يستخدم الإكمال عن بعد أم لا. عند القيمة true، يخمن المفتاح Tab ما إذا كانت الكلمة التي يتم إكمالها اسم ملف عن بعد. يقوم Meta-Tab دائمًا بالإكمال عن بعد. لذلك، يمكنك فرض الإكمال عن بعد باستخدام Meta-Tab عندما تكون cmd:remote-completion false أو عندما يكون التخمين خاطئًا.
cmd:save-cwd-history (boolean)
عند القيمة true، يقوم lftp بحفظ آخر دليل عمل حالي (CWD) لكل موقع في ~/.local/share/lftp/cwd_history أو ~/.lftp/cwd_history، مما يسمح بتنفيذ ``cd -'' بعد إعادة تشغيل lftp. القيمة الافتراضية هي true.
cmd:save-rl-history (boolean)
عند القيمة true، يقوم lftp بحفظ سجل الأوامر (readline history) في ~/.local/share/lftp/rl_history أو ~/.lftp/rl_history عند الخروج. القيمة الافتراضية هي true.
cmd:show-status (boolean)
عند القيمة false، لا يعرض lftp سطر الحالة على الطرفية. القيمة الافتراضية هي true.
cmd:set-term-status (boolean)
عند القيمة true، يقوم lftp بتحديث حالة الطرفية إذا كانت مدعومة (مثل xterm). يعتمد هذا الإعداد على نوع الطرفية من متغير البيئة TERM.
cmd:status-interval (timeinterval)
الفترة الزمنية بين تحديثات الحالة.
cmd:stifle-rl-history (number)
عدد الأسطر التي يتم الاحتفاظ بها في سجل الأوامر (readline history).
cmd:term-status (string)
سلسلة التنسيق المستخدمة لعرض حالة الطرفية. يعتمد هذا الإعداد على نوع الطرفية من متغير البيئة TERM. القيمة الافتراضية تستخدم قيم termcap ``tsl'' و ``fsl''.

الهروب (escapes) التالية مدعومة:

\a جرس
\e هروب
\n سطر جديد
\s "lftp"
\v إصدار lftp
\T سلسلة الحالة
cmd:time-style (string)
هذا الإعداد هو القيمة الافتراضية لخيار cls --time-style.
cmd:trace (boolean)
عند القيمة true، يقوم lftp بطباعة الأوامر التي ينفذها (مثل sh -x).
cmd:verify-host (boolean)
إذا كانت القيمة true، يقوم lftp بحل اسم المضيف فورًا في أمر `open'. من الممكن أيضًا تخطي التحقق لأمر `open' واحد إذا تم توفير `&'، أو إذا تم الضغط على ^Z أثناء التحقق.
cmd:verify-path (boolean)
إذا كانت القيمة true، يقوم lftp بالتحقق من المسار المقدم في أمر `cd'. من الممكن أيضًا تخطي التحقق لأمر `cd' واحد إذا تم توفير `&'، أو إذا تم الضغط على ^Z أثناء التحقق. أمثلة: 
set cmd:verify-path/hftp://* false
cd directory &
cmd:verify-path-cached (boolean)
عند القيمة false، ينجح أمر `cd` إلى دليل معروف من ذاكرة التخزين المؤقت بأنه موجود فورًا. خلاف ذلك، سيعتمد التحقق على إعداد cmd:verify-path.
color:use-color (tri-boolean)
عند القيمة true، يقوم أمر cls وإخراج الإكمال بإدراج الملفات الملونة وفقًا لإعداد color:dir-colors. عند تعيينه إلى auto، يتم استخدام الألوان عندما يكون الإخراج طرفية.
color:dir-colors (string)
وصف لون قائمة الملفات. افتراضيًا، يتم استخدام قيمة متغير البيئة LS_COLORS. انظر dircolors(1).
dns:SRV-query (boolean)
استعلام عن سجلات SRV واستخدامها قبل gethostbyname. تستخدم سجلات SRV فقط إذا لم يتم تحديد المنفذ بشكل صريح. انظر RFC2052 للحصول على التفاصيل.
dns:cache-enable (boolean)
تمكين ذاكرة التخزين المؤقت لنظام أسماء النطاقات (DNS). إذا كانت مغلقة، يقوم lftp بحل اسم المضيف في كل مرة يعيد فيها الاتصال.
dns:cache-expire (time interval)
وقت صلاحية إدخالات ذاكرة التخزين المؤقت لنظام أسماء النطاقات. لديها تنسيق <number><unit>+، على سبيل المثال 1d12h30m5s أو فقط 36h. لتعطيل انتهاء الصلاحية، قم بتعيينها إلى `inf` أو `never`.
dns:cache-size (number)
الحد الأقصى لعدد إدخالات ذاكرة التخزين المؤقت لنظام أسماء النطاقات.
dns:fatal-timeout (time interval)
تحديد الوقت لاستعلامات نظام أسماء النطاقات. إذا كان خادم DNS غير متاح لفترة طويلة جدًا، سيفشل lftp في حل اسم المضيف المحدد. قم بتعيينه إلى `never` لتعطيله.
dns:order (list of protocol names)
يحدد ترتيب استعلامات نظام أسماء النطاقات. الافتراضي هو ``inet6 inet'' مما يعني البحث أولاً عن العنوان في عائلة inet6، ثم inet واستخدامها بهذا الترتيب. لتعطيل البحث عن inet6 (AAAA)، قم بتعيين هذا المتغير إلى ``inet''.
dns:use-fork (boolean)
إذا كانت القيمة true، سيقوم lftp بعمل fork قبل حل عنوان المضيف. القيمة الافتراضية هي true.
dns:max-retries (number)
إذا كان صفرًا، فلا يوجد حد لعدد المرات التي سيحاول فيها lftp البحث عن عنوان. إذا كان > 0، سيحاول lftp فقط هذا العدد من المرات للبحث عن عنوان لكل عائلة عناوين في dns:order.
dns:name (string)
يمكن استخدام هذا الإعداد لاستبدال اسم مستعار للمضيف باسم آخر أو عنوان IP. يتم استخدام اسم المضيف المستعار كإغلاق للإعداد، والاسم المستبدل أو عنوان IP موجود في القيمة. يمكن فصل أسماء متعددة أو عناوين IP بفواصل.
file:charset (string)
مجموعة الأحرف المحلية. يتم تعيينها من اللغة الحالية مبدئيًا.
file:use-lock (boolean)
عند القيمة true، يستخدم lftp تأمينًا استشاريًا على الملفات المحلية عند فتحها.
file:use-fallocate (boolean)
عند القيمة true، يستخدم lftp fallocate(2) أو posix_fallocate(3) لتخصيص مساحة تخزين مسبقًا وتقليل تجزئة الملفات في أوامر pget و torrent.
fish:auto-confirm (boolean)
عند القيمة true، يجيب lftp بـ "yes" على جميع أسئلة ssh، وخاصة على السؤال حول مفتاح المضيف الجديد. خلاف ذلك، يجيب بـ "no".
fish:charset (string)
مجموعة الأحرف المستخدمة بواسطة خادم fish في الطلبات والردود وقوائم الملفات. الافتراضي هو فارغ مما يعني نفس الشيء مثل المحلي.
fish:connect-program (string)
البرنامج المستخدم للاتصال بالخادم البعيد. يجب أن يدعم الخيار `-l` لاسم المستخدم، `-p` لرقم المنفذ. الافتراضي هو `ssh -a -x`. يمكنك تعيينه إلى `rsh`، على سبيل المثال. للمصادقة بالمفتاح الخاص، أضف الخيار `-i` مع ملف المفتاح.
fish:shell (string)
استخدم قذيفة محددة على جانب الخادم. الافتراضي هو /bin/sh. في بعض الأنظمة، يخرج /bin/sh عند الانتقال إلى دليل غير موجود. يمكن لـ lftp التعامل مع ذلك ولكنه يحتاج إلى إعادة الاتصال. قم بتعيينه إلى /bin/bash لهذه الأنظمة إذا كان bash مثبتًا.
ftp:acct (string)
أرسل هذه السلسلة في أمر ACCT بعد تسجيل الدخول. يتم تجاهل النتيجة. إغلاق هذا الإعداد له تنسيق user@host.
ftp:anon-pass (string)
يضبط كلمة المرور المستخدمة للمصادقة على وصول FTP المجهول. الافتراضي هو "lftp@".
ftp:anon-user (string)
يضبط اسم المستخدم المستخدم للمصادقة على وصول FTP المجهول. الافتراضي هو "anonymous".
ftp:auto-sync-mode (regex)
إذا كانت الرسالة الأولى من الخادم تتطابق مع هذا التعبير النمطي، فقم بتشغيل وضع المزامنة لهذا المضيف.
ftp:catch-size (boolean)
عندما لا يكون هناك دعم لأمر SIZE، حاول التقاط حجم الملف من الرد "150 Opening data connection".
ftp:charset (string)
مجموعة الأحرف المستخدمة بواسطة خادم FTP في الطلبات والردود وقوائم الملفات. الافتراضي هو فارغ مما يعني نفس الشيء مثل المحلي. يستخدم هذا الإعداد فقط عندما لا يدعم الخادم UTF8.
ftp:client (string)
اسم عميل FTP الذي سيتم إرساله مع أمر CLNT، إذا كان مدعومًا من قبل الخادم. إذا كان فارغًا، فلن يتم إرسال أمر CLNT.
ftp:compressed-re (regex)
سيتم اعتبار الملفات ذات الاسم المطابق مضغوطة ولن يتم استخدام "MODE Z" لها.
ftp:bind-data-socket (boolean)
ربط مقبس البيانات بواجهة اتصال التحكم (في الوضع السلبي). الافتراضي هو true، الاستثناء هو واجهة loopback.

الملفات

/etc/lftp.conf
ملف تكوين النظام لـ lftp.
~/.config/lftp/rc أو ~/.lftp/rc
هذه الملفات يتم تنفيذها عند بدء تشغيل lftp بعد /etc/lftp.conf.
~/.local/share/lftp/log أو ~/.lftp/log
الملف الذي يتم تسجيل الأشياء فيه عندما ينتقل lftp إلى الخلفية في وضع nohop.
~/.local/share/lftp/transfer_log أو ~/.lftp/transfer_log
الملف الذي يتم تسجيل عمليات النقل فيه عندما يتم تعيين الإعداد log:enabled/xfer إلى `yes'. يمكن تغيير الموقع عن طريق الإعداد log:file/xfer.
~/.local/share/lftp/bookmarks أو ~/.lftp/bookmarks
يستخدم هذا الملف لتخزين إشارات lftp المرجعية. راجع أمر bookmark.
~/.local/share/lftp/cwd_history أو ~/.lftp/cwd_history
يستخدم هذا الملف لتخزين آخر الدلائل العاملة لكل موقع تمت زيارته.
~/.local/share/lftp/bg/ أو ~/.lftp/bg/
يستخدم هذا الدليل لتخزين المقابس المسماة لعمليات lftp الخلفية.
~/.cache/lftp/DHT/ أو ~/.lftp/DHT/
يستخدم هذا الدليل لتخزين ذاكرة التخزين المؤقت لمعرف DHT والعقد لـ IPv4 و IPv6. لاحقة اسم الملف هي اسم المضيف.
~/.cache/lftp/edit/ أو ~/.lftp/edit/
يستخدم هذا الدليل لتخزين الملفات المؤقتة لأمر edit.
~/.local/share/lftp/torrent/md/ أو ~/.lftp/torrent/md/
يستخدم هذا الدليل لتخزين البيانات الوصفية لـ torrent. إنه مفيد بشكل خاص لروابط magnet، يمكن تحميل البيانات الوصفية المخزنة مؤقتًا من الدليل. يمكن أن يعمل أيضًا كسجل لـ torrent، أسماء الملفات هي info_hash لـ torrents.
~/.netrc
يتم استشارة هذا الملف للحصول على اسم تسجيل الدخول وكلمة المرور الافتراضية للخادم عند تحديده بدون بروتوكول لأمر `open'. يتم البحث عن كلمات المرور هنا أيضًا إذا تم استخدام عنوان URL باسم مستخدم ولكن بدون كلمة مرور.
