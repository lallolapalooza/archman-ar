lreplace(n)

الحزمة: tcl

التراخيص: TCL

lreplace(n) أوامر Tcl المضمنة lreplace(n)

اسم

lreplace - استبدال عناصر في قائمة بعناصر جديدة

ملخص

lreplace list first last ?element element ...?

الوصف

lreplace تُرجع قائمة جديدة تتكون من استبدال صفر أو أكثر من عناصر list بالعناصر element. first و last هما قيم مؤشر تحدد العنصر الأول والأخير من النطاق المراد استبداله. قيم المؤشرات first و last تُفسر بنفس طريقة تفسير قيم المؤشرات للأمر string index، وتدعم العمليات الحسابية البسيطة للمؤشرات والمؤشرات النسبية لنهاية القائمة. 0 يشير إلى العنصر الأول من القائمة، و end يشير إلى العنصر الأخير من القائمة.

إذا كان أي من first أو last أقل من الصفر، فيُعتبر أنه يشير إلى قبل العنصر الأول من القائمة. هذا يسمح لـ lreplace بإضافة عناصر في بداية list. إذا كان أي من first أو last يشير إلى موقع أكبر من مؤشر آخر عنصر في القائمة، فيُعامل كما لو كان مؤشرًا أكبر بواحد من العنصر الأخير. هذا يسمح لـ lreplace بإضافة عناصر في نهاية list.

إذا كان last أقل من first، فسيتم إدراج أي عناصر محددة في القائمة قبل العنصر المحدد بواسطة first دون حذف أي عناصر.

العناصر element تحدد صفرًا أو أكثر من العناصر الجديدة التي ستضاف إلى القائمة بدلًا من تلك التي تم حذفها. كل عنصر element سيصبح عنصرًا منفصلًا في القائمة. إذا لم يتم تحديد أي عناصر element، فسيتم ببساطة حذف العناصر بين first و last.

أمثلة

استبدال عنصر في قائمة بعنصر آخر:

% lreplace {a b c d e} 1 1 foo
a foo c d e

استبدال عنصرين في قائمة بثلاثة:

% lreplace {a b c d e} 1 2 three more elements
a three more elements d e

حذف العنصر الأخير من قائمة في متغير:

% set var {a b c d e}
a b c d e
% set var [lreplace $var end end]
a b c d

إجراء لحذف عنصر معين من قائمة:

proc lremove {listVariable value} {
    upvar 1 $listVariable var
    set idx [lsearch -exact $var $value]
    set var [lreplace $var $idx $idx]
}

إضافة عناصر إلى القائمة؛ لاحظ أن end+2 ستُعامل في البداية كما لو كانت 6، لكن كلاهما، وهذا الرقم و 12345، أكبر من مؤشر العنصر الأخير لذا فهما يعملان بشكل متطابق:

% set var {a b c d e}
a b c d e
% set var [lreplace $var 12345 end+2 f g h i]
a b c d e f g h i
