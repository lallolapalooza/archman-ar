lr_run(1)

الحزمة: lire

التراخيص: GPL-2.0-only

LR_RUN.IN(1) وثائق Lire لـ LogReport LR_RUN.IN(1)

الاسم

lr_run - تشغيل برنامج Lire والتعامل مع مخرجات التسجيل

الملخص

lr_run program arguments

الوصف

يقوم lr_run بتشغيل program، ويعيد توجيه مخرجات stderr الخاصة بـ program إلى logger(1). يقوم بتحليل مخرجات التسجيل لـ programs، ويضبط أعلام logger(1) وفقًا لذلك.

يحصل lr_run على التكوين من sysconfdir/lire/defaults. في حالة تعيين 'lr_logging_method' إلى 'stderr'، لا يتم إشراك logger(1): يتم إعادة توجيه مخرجات التسجيل إلى stderr. في حالة تعيين 'lr_debug' إلى سلسلة فارغة، يتم كبت الرسائل ذات مستويات التسجيل debug و info. يتم استخدام متغير التكوين 'lr_logging_facility' للعثور على مرفق logger(1).

ملاحظات

يجب أن تكون مخرجات program على stderr بالتنسيق superservice service id programname level message. يجب أن يكون level أحد هذه: emerg (النظام غير قابل للاستخدام)، alert (يجب اتخاذ إجراء فورًا)، crit (ظروف حرجة)، err (ظروف خطأ)، warning (ظروف تحذير)، notice (ظرف طبيعي، ولكنه مهم)، info (رسالة إعلامية)، debug (رسالة على مستوى التصحيح). انظر syslog(3).

يمكن استخدام id لتمييز كل مهمة Lire، بحيث يمكن تتبعها. يجب أن يكون programname اسم البرنامج الذي أنشأ سطر السجل.

أمثلة

لمعالجة سجل Postfix وعرض التقرير كنص، استخدم

$ lr_run lr_log2report postfix < /var/log/mail.log

لمعالجة سجل Postfix وإنشاء التقرير بتنسيق HTML (معبأ في أرشيف tar)، استخدم:

$ lr_run lr_log2report -o html postfix < /var/log/mail.log > postfix.tar
