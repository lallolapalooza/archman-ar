libressl-EVP_MD_CTX_ctrl(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

EVP_MD_CTX_CTRL(3) دليل المكتبة EVP_MD_CTX_CTRL(3)

الاسم

EVP_MD_CTX_ctrl، EVP_MD_CTX_set_flags، EVP_MD_CTX_clear_flags، EVP_MD_CTX_test_flags، EVP_MD_CTX_pkey_ctx، EVP_MD_CTX_set_pkey_ctx، EVP_MD_CTX_md_data — تكوين سياقات التجزئة التشفيرية EVP

الملخص

المكتبة “libcrypto”
#include <openssl/evp.h>

int
EVP_MD_CTX_ctrl(EVP_MD_CTX *ctx, int command, int p1, void* p2);

void
EVP_MD_CTX_set_flags(EVP_MD_CTX *ctx, int flags);

void
EVP_MD_CTX_clear_flags(EVP_MD_CTX *ctx, int flags);

int
EVP_MD_CTX_test_flags(const EVP_MD_CTX *ctx, int flags);

EVP_PKEY_CTX *
EVP_MD_CTX_pkey_ctx(const EVP_MD_CTX *ctx);

void
EVP_MD_CTX_set_pkey_ctx(EVP_MD_CTX *ctx, EVP_PKEY_CTX *pctx);

void *
EVP_MD_CTX_md_data(const EVP_MD_CTX *ctx);

الوصف

EVP_MD_CTX_ctrl() تنفيذ الأمر المحدد للتجزئة command مع الوسائط المحددة للأمر p1 و p2 على ctx، والذي يحتاج إلى إعداده بالفعل باستخدام EVP_DigestInit_ex(3) قبل استدعاء هذه الدالة. قد تنطبق قيود أخرى اعتمادًا على الأمر المحدد وتنفيذ التجزئة.

إذا كان command هو EVP_MD_CTRL_MICALG، يتم تجاهل p1 ويكون p2 وسيطة إخراج من النوع char **p2. يتم تخصيص سلسلة نصية تحدد خوارزمية التحقق من سلامة رسالة التجزئة ويتم إرجاع مؤشر إلى هذه السلسلة النصية في *p2. تقع على عاتق المتصل مسؤولية free(3) *p2 عندما لم تعد هناك حاجة إليها. يتم استخدام هذا command بواسطة SMIME_write_CMS(3) و SMIME_write_PKCS7(3) عند إنشاء رسائل S/MIME متعددة الأجزاء / موقعة كما هو محدد في RFC 3851.

EVP_MD_CTX_set_flags() تقوم بتعيين و EVP_MD_CTX_clear_flags() تقوم بمسح جميع بتات الأعلام في ctx التي تم تعيينها في الوسيط flags. EVP_MD_CTX_test_flags() تختبر أي من بتات الأعلام التي تم تعيينها في الوسيط flags والتي تم تعيينها أيضًا في ctx. بتات الأعلام المحتملة هي:

EVP_MD_CTX_FLAG_NO_INIT
توجيه EVP_DigestInit_ex(3) والوظائف التي تستدعيها بعدم تهيئة البيانات الداخلية الخاصة بطريقة التجزئة وتنفيذها.
EVP_MD_CTX_FLAG_ONESHOT
توجيه التجزئة لتحسين تحديث واحد فقط، إن أمكن. بالنسبة لخوارزميات التجزئة المدمجة في المكتبة، عادة ما لا يكون لهذا العلم أي تأثير.

EVP_MD_CTX_pkey_ctx() ترجع EVP_PKEY_CTX المعين لـ ctx. يجب ألا يقوم المتصل بتحرير المؤشر المرجع.

EVP_MD_CTX_set_pkey_ctx() يعين pctx لـ ctx. يستخدم هذا عادةً لتوفير EVP_PKEY_CTX مخصص لـ EVP_DigestSignInit(3) أو EVP_DigestVerifyInit(3). يحتفظ المتصل بملكية pctx الذي تم تمريره إلى هذه الدالة وهو مسؤول عن تحريره عندما لم يعد هناك حاجة إليه.

إذا كان ctx يحتوي بالفعل على EVP_PKEY_CTX عند استدعاء هذه الدالة، فإنه يتم تحرير EVP_PKEY_CTX القديم إذا تم إنشاؤه داخليًا، ولكن إذا تم تثبيته أيضًا باستخدام EVP_MD_CTX_set_pkey_ctx()، فإن المؤشر إلى EVP_PKEY_CTX القديم يتم استبداله ببساطة بالمؤشر الجديد وتظل ملكية EVP_PKEY_CTX القديم مع المتصل السابق.

يُسمح أيضًا بتمرير مؤشر NULL للوسيط pctx. في هذه الحالة، يتم فصل أي EVP_PKEY_CTX تم تعيينه بالفعل لـ ctx عنه كما هو موضح أعلاه، ولكن لا يتم تعيين EVP_PKEY_CTX جديد.

EVP_MD_CTX_md_data() ترجع بيانات التجزئة الخاصة بـ ctx. يتم تخصيص المساحة بحجم يتم تحديده وقت الترجمة. لم يتم كشف الحجم بواسطة واجهة برمجة تطبيقات.

قيم الإرجاع

EVP_MD_CTX_ctrl() ترجع 1 للنجاح أو 0 للفشل.

EVP_MD_CTX_test_flags() ترجع OR البتي للوسيط flags والأعلام المعينة في ctx.

EVP_MD_CTX_pkey_ctx() و EVP_MD_CTX_md_data() ترجع مؤشرات إلى تخزين مملوك لـ ctx.

انظر أيضًا

evp(3), EVP_DigestInit(3), EVP_MD_nid(3)

التاريخ

EVP_MD_CTX_set_flags(), EVP_MD_CTX_clear_flags(), و EVP_MD_CTX_test_flags() ظهرت لأول مرة في OpenSSL 0.9.7 وكانت متاحة منذ OpenBSD 3.2.

EVP_MD_CTX_ctrl() ظهرت لأول مرة في OpenSSL 1.1.0 وكانت متاحة منذ OpenBSD 5.7.

EVP_MD_CTX_pkey_ctx() و EVP_MD_CTX_md_data() ظهرت لأول مرة في OpenSSL 1.1.0 و EVP_MD_CTX_set_pkey_ctx() في OpenSSL 1.1.1. كانت هذه الوظائف متاحة منذ OpenBSD 7.1.
