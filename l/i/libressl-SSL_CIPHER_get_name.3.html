libressl-SSL_CIPHER_get_name(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

NAME

SSL_CIPHER_get_name, SSL_CIPHER_get_bits, SSL_CIPHER_get_version, SSL_CIPHER_get_id, SSL_CIPHER_get_cipher_nid, SSL_CIPHER_get_digest_nid, SSL_CIPHER_get_kx_nid, SSL_CIPHER_get_auth_nid, SSL_CIPHER_get_handshake_digest, SSL_CIPHER_is_aead, SSL_CIPHER_find, SSL_CIPHER_description - إدارة تشفير SSL/TLS

SYNOPSIS

#include <openssl/ssl.h>

const char *
SSL_CIPHER_get_name(const SSL_CIPHER *cipher);

int
SSL_CIPHER_get_bits(const SSL_CIPHER *cipher);

const char *
SSL_CIPHER_get_version(const SSL_CIPHER *cipher);

uint32_t
SSL_CIPHER_get_id(const SSL_CIPHER *cipher);

int
SSL_CIPHER_get_cipher_nid(const SSL_CIPHER *cipher);

int
SSL_CIPHER_get_digest_nid(const SSL_CIPHER *cipher);

int
SSL_CIPHER_get_kx_nid(const SSL_CIPHER *cipher);

int
SSL_CIPHER_get_auth_nid(const SSL_CIPHER *cipher);

const EVP_MD *
SSL_CIPHER_get_handshake_digest(const SSL_CIPHER *cipher);

int
SSL_CIPHER_is_aead(const SSL_CIPHER *cipher);

SSL_CIPHER *
SSL_CIPHER_find(const char *cipher_name);

char *
SSL_CIPHER_description(const SSL_CIPHER *cipher, char *buf, int len);

DESCRIPTION

يتم استخدام هذه الوظائف للاستعلام عن خصائص التشفير.
SSL_CIPHER_get_name() و SSL_CIPHER_get_version() ترجعان اسم التشفير ونسخته على التوالي. SSL_CIPHER_get_bits() ترجع عدد البتات السرية.

Protocol version:
إصدار البروتوكول: SSLv3, TLSv1.2, أو TLSv1.3. تمييز تشفيرات TLSv1.0 بـ SSLv3. لم تتم إضافة تشفيرات جديدة بواسطة TLSv1.1.
Kx=⟨تبادل المفاتيح⟩
طريقة تبادل المفاتيح: DH, ECDH, GOST, RSA, أو TLSv1.3.
Au=⟨مصادقة⟩
طريقة المصادقة: ECDSA, GOST01, RSA, TLSv1.3, أو None. None تمثل التشفيرات المجهولة.
Enc=⟨طريقة التشفير المتماثل⟩
طريقة التشفير مع عدد البتات السرية: 3DES(168), RC4(128), AES(128), AES(256), AESGCM(128), AESGCM(256), Camellia(128), Camellia(256), ChaCha20-Poly1305, GOST-28178-89-CNT, أو None.
Mac=⟨رمز مصادقة الرسالة⟩
ملخص الرسالة: MD5, SHA1, SHA256, SHA384, AEAD, GOST94, GOST89IMIT, أو STREEBOG256.

RETURN VALUES

SSL_CIPHER_get_name() ترجع مؤشرًا داخليًا لسلسلة نصية تنتهي بـ NUL.
SSL_CIPHER_get_version() ترجع مؤشرًا لسلسلة نصية ثابتة تنتهي بـ NUL. إذا كان cipher مؤشرًا NULL، فإن كلا الدالتين ترجعان مؤشرًا للسلسلة الثابتة "(NONE)".

SSL_CIPHER_get_bits() ترجع عددًا صحيحًا موجبًا يمثل عدد البتات السرية أو 0 إذا كان cipher مؤشرًا NULL.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid(), و SSL_CIPHER_get_auth_nid() ترجع ثابت NID أو NID_undef في حالة حدوث خطأ.
SSL_CIPHER_get_handshake_digest() ترجع كائن EVP_MD صالحًا أو NULL في حالة حدوث خطأ.

SSL_CIPHER_is_aead() ترجع 1 إذا كان cipher هو AEAD أو 0 خلاف ذلك.

SSL_CIPHER_find() ترجع مؤشرًا لهيكل SSL_CIPHER صالحًا أو NULL في حالة حدوث خطأ.

SSL_CIPHER_get_id() ترجع عددًا صحيحًا غير موقع بحجم 32 بت.

SSL_CIPHER_description() ترجع buf أو سلسلة جديدة مخصصة عند النجاح أو مؤشرًا لسلسلة ثابتة عند حدوث خطأ.

EXAMPLES

مثال على ناتج SSL_CIPHER_description():

ECDHE-RSA-AES256-GCM-SHA256 TLSv1.2 Kx=ECDH Au=RSA Enc=AESGCM(256) Mac=AEAD

يمكن استرداد قائمة كاملة عن طريق استدعاء الأمر التالي:

$ openssl ciphers -v ALL:COMPLEMENTOFALL

SEE ALSO

openssl(1), ssl(3), SSL_get_ciphers(3), SSL_get_current_cipher(3)

HISTORY

SSL_CIPHER_description() ظهرت لأول مرة في SSLeay 0.8.0. SSL_CIPHER_get_name(), SSL_CIPHER_get_bits(), و SSL_CIPHER_get_version() ظهرت لأول مرة في SSLeay 0.8.1. هذه الوظائف متاحة منذ OpenBSD 2.4.

SSL_CIPHER_get_id() ظهرت لأول مرة في OpenSSL 1.0.1 وهي متاحة منذ OpenBSD 5.3.

SSL_CIPHER_get_cipher_nid(), SSL_CIPHER_get_digest_nid(), SSL_CIPHER_get_kx_nid(), SSL_CIPHER_get_auth_nid(), و SSL_CIPHER_is_aead() ظهرت لأول مرة في OpenSSL 1.1.0 وهي متاحة منذ OpenBSD 6.3.
SSL_CIPHER_find() ظهرت لأول مرة في OpenSSL 1.1.0 وهي متاحة منذ OpenBSD 7.0.
SSL_CIPHER_get_handshake_digest() ظهرت لأول مرة في OpenSSL 1.1.1 وهي متاحة منذ OpenBSD 7.6.

BUGS

إذا لم تتمكن SSL_CIPHER_description() من معالجة تشفير مدمج، فإن وصف خاصية التشفير المعنية هو "unknown". لا ينبغي أن تحدث هذه الحالة.
