Lire__Param(3pm)

الحزمة: lire

التراخيص: GPL-2.0-only

Param(3pm) وثائق LogReport's Lire Param(3pm)

الاسم

Lire::Param - كائن يمثل معاملًا في مواصفات XML.

الوصف

Lire::Param هي كائنات تمثل المعاملات في مواصفات XML. يُستخدم الكائن لتمثيل مواصفات المعامل بالإضافة إلى قيمته الحالية.

new( 'name' => $name, 'type' => $type, [ 'default' => $default ] )

ينشئ كائن Lire::Param جديد.

name()

يعيد اسم هذا المعامل.

type()

يعيد نوع هذا المعامل.

value( [ $new_value ] )

يعيد (ويعدل اختياريًا) القيمة الحالية لهذا المعامل. إذا لم يتم تعيين قيمة، ولكن هناك قيمة افتراضية متاحة، فسيتم إرجاع القيمة الافتراضية.

default( [ $new_default ] )

يعيد (ويغير اختياريًا) القيمة الافتراضية للمعامل.

description( [ $new_description ] )

يعيد (ويغير اختياريًا) وصف المعامل الحالي.

as_type_spec()

يعيد كائن Lire::Config::TypeSpec يمثل المعامل الحالي بشكل مناسب.

انظر أيضًا

Lire::Config::TypeSpec(3pm), Lire::XMLSpecContainer(3pm)
