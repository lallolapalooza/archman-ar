libressl-EVP_CIPHER_do_all(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

EVP_CIPHER_DO_ALL(3) دليل وظائف المكتبة EVP_CIPHER_DO_ALL(3)

الاسم

EVP_CIPHER_do_all، EVP_CIPHER_do_all_sorted، EVP_MD_do_all، EVP_MD_do_all_sorted، OBJ_NAME_do_all، OBJ_NAME_do_all_sorted — التكرار فوق جداول البحث للتشفيرات والهضم

الملخص

المكتبة «libcrypto»
#include <openssl/evp.h>

void
EVP_CIPHER_do_all(void (*fn)(const EVP_CIPHER *cipher, const char *from, const char *to, void *arg), void *arg);

void
EVP_CIPHER_do_all_sorted(void (*fn)(const EVP_CIPHER *cipher, const char *from, const char *to, void *arg), void *arg);

void
EVP_MD_do_all(void (*fn)(const EVP_MD *md, const char *from, const char *to, void *arg), void *arg);

void
EVP_MD_do_all_sorted(void (*fn)(const EVP_MD *md, const char *from, const char *to, void *arg), void *arg);

typedef struct {
        int	    type;
        int	    alias;
        const char *name;
        const char *data;
} OBJ_NAME;


void
OBJ_NAME_do_all(int type, void (*fn)(const OBJ_NAME *obj_name, void *arg), void *arg);

void
OBJ_NAME_do_all_sorted(int type, void (*fn)(const OBJ_NAME *obj_name, void *arg), void *arg);

الوصف

EVP_CIPHER_do_all() تستدعي fn على كل إدخال في الجدول العام لأسماء التشفير والأسماء المستعارة. بالنسبة لإدخال اسم تشفير، يتم استدعاء fn باستخدام cipher غير خالية، واسم التشفير غير الخالي الخاص بها from، و to خالية، ومؤشر arg. بالنسبة لإدخال اسم مستعار، يتم استدعاء fncipher خالي، واسمها المستعار from، واسم التشفير الذي يشير إليه الاسم المستعار to، ومؤشر arg.

EVP_CIPHER_do_all_sorted() مشابهة، باستثناء أنها تعالج أسماء التشفير والأسماء المستعارة بترتيب أبجدي لأسمائها from كما تم تحديده بواسطة strcmp(3).

EVP_MD_do_all() تستدعي fn على كل إدخال في الجدول العام لأسماء الهضم والأسماء المستعارة. بالنسبة لإدخال اسم هضم، يتم استدعاء fnmd غير خالي، واسم الهضم غير الخالي الخاص بها from، و to خالية، ومؤشر arg. بالنسبة لإدخال اسم مستعار، يتم استدعاء fnmd خالي، واسمها المستعار from، واسم الهضم الذي يشير إليه الاسم المستعار to، ومؤشر arg.

EVP_MD_do_all_sorted() مشابهة، باستثناء أنها تعالج أسماء الهضم والأسماء المستعارة بترتيب أبجدي لأسمائها from كما تم تحديده بواسطة strcmp(3).

OBJ_NAME هو تجريد للأنواع الأساسية لجداول البحث للتشفيرات وأسمائها المستعارة، والهضم وأسمائها المستعارة، على التوالي. بالنسبة للتشفير، type هو OBJ_NAME_TYPE_CIPHER_METH، alias هو 0، name هو اسمه الذي يتم البحث عنه، و data هو كائن EVP_CIPHER الذي يمثله، محولاً إلى const char *. بالنسبة لاسم مستعار للتشفير، type هو OBJ_NAME_TYPE_CIPHER_METH، alias هو OBJ_NAME_ALIAS، name هو اسمه الذي يتم البحث عنه، و data هو الاسم الذي يشير إليه. الهضم الذي يمثل كائن EVP_MD وأسمائه المستعارة يتم تمثيلها بشكل مشابه، باستثناء أن نوعها هو OBJ_NAME_TYPE_MD_METH.

OBJ_NAME_do_all() تستدعي fn على كل obj_name في الجدول الذي له type المعطى (إما OBJ_NAME_TYPE_CIPHER_METH أو OBJ_NAME_TYPE_MD_METH)، وتمرر أيضًا مؤشر arg. OBJ_NAME_do_all_sorted() مشابهة باستثناء أنها تعالج obj_name بترتيب أبجدي لأسمائها كما تم تحديده بواسطة strcmp(3).

التاريخ

ظهرت هذه الوظائف لأول مرة في OpenSSL 1.0.0 وكانت متاحة منذ OpenBSD 4.9.

تحذيرات

EVP_CIPHER_do_all_sorted()، EVP_MD_do_all_sorted()، و OBJ_NAME_do_all_sorted() لا يمكنها الإبلاغ عن الأخطاء. في بعض التطبيقات، تحتاج إلى تخصيص ذاكرة داخليًا، وإذا فشل تخصيص الذاكرة، فإنها لا تفعل شيئًا على الإطلاق، دون إبلاغ المستدعي بالمشكلة.
