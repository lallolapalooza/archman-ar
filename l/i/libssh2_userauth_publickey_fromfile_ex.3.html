libssh2_userauth_publickey_fromfile_ex(3)

الحزمة: libssh2

التراخيص: BSD

libssh2_userauth_publickey_fromfile_ex(3) libssh2 libssh2_userauth_publickey_fromfile_ex(3)

الاسم

libssh2_userauth_publickey_fromfile_ex - مصادقة جلسة بمفتاح عام، قراءة من ملف

الملخص

#include <libssh2.h>
int
libssh2_userauth_publickey_fromfile_ex(LIBSSH2_SESSION *session,
                                       const char *username,
                                       unsigned int username_len,
                                       const char *publickey,
                                       const char *privatekey,
                                       const char *passphrase);

الوصف

session - مثيل الجلسة كما تم إرجاعه بواسطة libssh2_session_init_ex(3)

username - مؤشر إلى اسم المستخدم للمصادقة عليه.

username_len - طول username.

publickey - اسم المسار لملف المفتاح العام. (مثال: /etc/ssh/hostkey.pub). إذا تم بناء libssh2 مقابل OpenSSL، يمكن تعيين هذا الخيار إلى NULL.

privatekey - اسم المسار لملف المفتاح الخاص. (مثال: /etc/ssh/hostkey)

passphrase - عبارة المرور المستخدمة عند فك تشفير privatekey.

محاولة المصادقة بمفتاح عام باستخدام إما ملف مفتاح عام أو ملف مفتاح خاص مشفر بصيغة PEM مخزن على القرص. عند توفير مفتاح خاص، يتم استخراج المفتاح العام منه تلقائيًا. عند توفير كليهما، يكون للمفتاح العام المقدم الأسبقية.

قيمة الإرجاع

إرجاع 0 عند النجاح أو قيمة سالبة عند الفشل. ترجع LIBSSH2_ERROR_EAGAIN عندما تتسبب في حظر. بينما LIBSSH2_ERROR_EAGAIN هو رقم سالب، فإنه ليس فشلاً بحد ذاته.

الأخطاء

LIBSSH2_ERROR_FILE - مشكلة في فتح ملف القرص أو قراءته أو تحليله.

LIBSSH2_ERROR_ALLOC - فشل استدعاء داخلي لتخصيص الذاكرة.

LIBSSH2_ERROR_SOCKET_SEND - عدم القدرة على إرسال بيانات على المقبس.

LIBSSH2_ERROR_SOCKET_TIMEOUT -

LIBSSH2_ERROR_PUBLICKEY_UNVERIFIED - كان تركيبة اسم المستخدم/المفتاح العام غير صالحة.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - لم يتم قبول المصادقة باستخدام المفتاح العام المقدم.
