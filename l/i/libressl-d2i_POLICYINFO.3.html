d2i_POLICYINFO, i2d_POLICYINFO, d2i_CERTIFICATEPOLICIES, i2d_CERTIFICATEPOLICIES, d2i_POLICYQUALINFO, i2d_POLICYQUALINFO, d2i_USERNOTICE, i2d_USERNOTICE, d2i_NOTICEREF, i2d_NOTICEREF — decode and encode X.509 certificate policies

DESCRIPTION

\n

These functions decode and encode X.509 certificate policies. For details about the semantics, examples, caveats, and bugs, see ASN1_item_d2i(3).

\n

d2i_POLICYINFO() and i2d_POLICYINFO() decode and encode an ASN.1 PolicyInformation structure defined in RFC 5280 section 4.2.1.4.

\n

d2i_CERTIFICATEPOLICIES() and i2d_CERTIFICATEPOLICIES() decode and encode an ASN.1 CertificatePolicies structure defined in RFC 5280 section 4.2.1.4.

\n

d2i_POLICYQUALINFO() and i2d_POLICYQUALINFO() decode and encode an ASN.1 PolicyQualifierInfo structure defined in RFC 5280 section 4.2.1.4.

\n

d2i_USERNOTICE() and i2d_USERNOTICE() decode and encode an ASN.1 UserNotice structure defined in RFC 5280 section 4.2.1.4.

\n

d2i_NOTICEREF() and i2d_NOTICEREF() decode and encode an ASN.1 NoticeReference structure defined in RFC 5280 section 4.2.1.4.

\n
\n
\n

RETURN VALUES

\n

d2i_POLICYINFO(), d2i_CERTIFICATEPOLICIES(), d2i_POLICYQUALINFO(), d2i_USERNOTICE(), and d2i_NOTICEREF() return a POLICYINFO, CERTIFICATEPOLICIES, POLICYQUALINFO, USERNOTICE, or NOTICEREF object, respectively, or NULL if an error occurs.

\n

i2d_POLICYINFO(), i2d_CERTIFICATEPOLICIES(), i2d_POLICYQUALINFO(), i2d_USERNOTICE(), and i2d_NOTICEREF() return the number of bytes successfully encoded or a negative value if an error occurs.

الوصف

\n

تقوم هذه الوظائف بفك ترميز وتشفير سياسات شهادة X.509. للتفاصيل حول المعاني والأمثلة والتحذيرات والأخطاء، راجع ASN1_item_d2i(3).

\n

d2i_POLICYINFO() و i2d_POLICYINFO() تقوم بفك ترميز وتشفير بنية PolicyInformation ASN.1 المحددة في RFC 5280 القسم 4.2.1.4.

\n

d2i_CERTIFICATEPOLICIES() و i2d_CERTIFICATEPOLICIES() تقوم بفك ترميز وتشفير بنية CertificatePolicies ASN.1 المحددة في RFC 5280 القسم 4.2.1.4.

\n

d2i_POLICYQUALINFO() و i2d_POLICYQUALINFO() تقوم بفك ترميز وتشفير بنية PolicyQualifierInfo ASN.1 المحددة في RFC 5280 القسم 4.2.1.4.

\n

d2i_USERNOTICE() و i2d_USERNOTICE() تقوم بفك ترميز وتشفير بنية UserNotice ASN.1 المحددة في RFC 5280 القسم 4.2.1.4.

\n

d2i_NOTICEREF() و i2d_NOTICEREF() تقوم بفك ترميز وتشفير بنية NoticeReference ASN.1 المحددة في RFC 5280 القسم 4.2.1.4.

\n
\n
\n

قيم الإرجاع

\n

d2i_POLICYINFO()، d2i_CERTIFICATEPOLICIES()، d2i_POLICYQUALINFO()، d2i_USERNOTICE()، و d2i_NOTICEREF() ترجع كائن POLICYINFO، CERTIFICATEPOLICIES، POLICYQUALINFO، USERNOTICE، أو NOTICEREF، على التوالي، أو NULL في حالة حدوث خطأ.

\n

i2d_POLICYINFO()، i2d_CERTIFICATEPOLICIES()، i2d_POLICYQUALINFO()، i2d_USERNOTICE()، و i2d_NOTICEREF() ترجع عدد البايتات التي تم تشفيرها بنجاح أو قيمة سالبة في حالة حدوث خطأ.

\n
