libressl-BUF_MEM_new(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

BUF_MEM_NEW(3) دليل وظائف المكتبة BUF_MEM_NEW(3)

الاسم

BUF_MEM_new، BUF_MEM_free، BUF_MEM_grow، BUF_MEM_grow_clean — بنية مصفوفات الأحرف البسيطة

الملخص

مكتبة "libcrypto"
#include <openssl/buffer.h>

BUF_MEM *
BUF_MEM_new(void);

void
BUF_MEM_free(BUF_MEM *a);

int
BUF_MEM_grow(BUF_MEM *str، size_t len);

int
BUF_MEM_grow_clean(BUF_MEM *str، size_t len);

الوصف

تتعامل مكتبة المخزن المؤقت مع مصفوفات الأحرف البسيطة. تُستخدم المخازن المؤقتة لأغراض مختلفة في المكتبة، وأكثرها بروزًا هي وحدات الإدخال/الإخراج (BIOs) المستندة إلى الذاكرة.

تستخدم المكتبة بنية BUF_MEM المعرفة في buffer.h:

typedef struct buf_mem_st {
	size_t length;	/* عدد البايتات الحالي */
	char *data;
	size_t max;	/* حجم المخزن المؤقت */
} BUF_MEM;

length هو الحجم الحالي للمخزن المؤقت بالبايت؛ max هو مقدار الذاكرة المخصصة للمخزن المؤقت. توجد ثلاث وظائف تتعامل مع هذه الأمور ووظيفة واحدة متفرقة.

BUF_MEM_new() تخصص مخزنًا مؤقتًا جديدًا بحجم صفر.

BUF_MEM_free() تحرر مخزنًا مؤقتًا موجودًا بالفعل. يتم تعيين البيانات إلى الصفر قبل تحريرها في حالة احتواء المخزن المؤقت على بيانات حساسة. إذا كان a مؤشرًا فارغًا (NULL)، فلن يحدث أي إجراء.

BUF_MEM_grow() تغير حجم مخزن مؤقت موجود بالفعل إلى len. يتم الحفاظ على أي بيانات موجودة بالفعل في المخزن المؤقت إذا زاد حجمه.

BUF_MEM_grow_clean() مشابهة لـ BUF_MEM_grow()، ولكنها تعين أي ذاكرة تم تحريرها أو تخصيصها إضافيًا إلى الصفر.

قيم الإرجاع

BUF_MEM_new() تُرجع المخزن المؤقت أو NULL عند حدوث خطأ.

BUF_MEM_grow() و BUF_MEM_grow_clean() تُرجعان صفرًا عند حدوث خطأ أو الحجم الجديد (أي len).

انظر أيضًا

BIO_new(3)، BIO_s_mem(3)

التاريخ

BUF_MEM_new()، BUF_MEM_free()، و BUF_MEM_grow() ظهرت لأول مرة في SSLeay 0.6.0. كانت جميع هذه الوظائف متاحة منذ OpenBSD 2.4.

BUF_MEM_grow_clean() ظهرت لأول مرة في OpenSSL 0.9.7 وكانت متاحة منذ OpenBSD 3.2.
