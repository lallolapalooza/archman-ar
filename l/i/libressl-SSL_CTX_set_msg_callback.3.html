libressl-SSL_CTX_set_msg_callback(3)

الحزمة: libressl

التراخيص: ISC، مخصص:OpenSSL

SSL_CTX_SET_MSG_CALLBACK(3) دليل الوظائف المكتبية SSL_CTX_SET_MSG_CALLBACK(3)

الاسم

SSL_CTX_set_msg_callback، SSL_CTX_set_msg_callback_arg، SSL_set_msg_callback، SSL_set_msg_callback_arg — تثبيت دالة استدعاء لمراقبة رسائل البروتوكول

الملخص

المكتبة “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_msg_callback(SSL_CTX *ctx, void (*cb)(int write_p, int version, int content_type, const void *buf, size_t len, SSL *ssl, void *arg));

void
SSL_CTX_set_msg_callback_arg(SSL_CTX *ctx, void *arg);

void
SSL_set_msg_callback(SSL *ssl, void (*cb)(int write_p, int version, int content_type, const void *buf, size_t len, SSL *ssl, void *arg));

void
SSL_set_msg_callback_arg(SSL *ssl, void *arg);

الوصف

SSL_CTX_set_msg_callback() أو SSL_set_msg_callback() يمكن استخدامها لتعريف دالة استدعاء للرسائل cb لمراقبة جميع رسائل بروتوكول SSL/TLS (مثل رسائل المصافحة) التي يتم استقبالها أو إرسالها. SSL_CTX_set_msg_callback_arg() و SSL_set_msg_callback_arg() يمكن استخدامها لضبط الوسيط arg لدالة الاستدعاء، وهو متاح للاستخدام العشوائي للتطبيق.

SSL_CTX_set_msg_callback() و SSL_CTX_set_msg_callback_arg() تحدد الإعدادات الافتراضية التي سيتم نسخها إلى كائنات SSL جديدة بواسطة SSL_new(3). SSL_set_msg_callback() و SSL_set_msg_callback_arg() تعدل الإعدادات الفعلية لكائن SSL. استخدام مؤشر NULL لـ cb يعطل دالة استدعاء الرسائل.

عندما يتم استدعاء cb بواسطة مكتبة SSL/TLS لرسالة بروتوكول، فإن وسائط الدالة لها المعاني التالية:

write_p
هذا العلم هو 0 عند استقبال رسالة بروتوكول و 1 عند إرسال رسالة بروتوكول.
version
إصدار البروتوكول الذي يتم تفسير رسالة البروتوكول بموجبه بواسطة المكتبة، مثل TLS1_VERSION، TLS1_1_VERSION، TLS1_2_VERSION، DTLS1_VERSION، أو DTLS1_2_VERSION.
content_type
هذه واحدة من قيم ContentType المحددة في مواصفات البروتوكول (SSL3_RT_CHANGE_CIPHER_SPEC، SSL3_RT_ALERT، SSL3_RT_HANDSHAKE، ولكن أبداً SSL3_RT_APPLICATION_DATA لأن دالة الاستدعاء سيتم استدعاؤها فقط لرسائل البروتوكول.)
buf, len
buf يشير إلى مخزن مؤقت يحتوي على رسالة البروتوكول، والتي تتكون من len بايت. المخزن المؤقت لم يعد صالحًا بعد عودة دالة الاستدعاء.
ssl
كائن SSL الذي استقبل أو أرسل الرسالة.
arg
الوسيط المحدد من قبل المستخدم الذي تم تحديده اختياريًا بواسطة SSL_CTX_set_msg_callback_arg() أو SSL_set_msg_callback_arg().

يتم تمرير رسائل البروتوكول إلى دالة الاستدعاء بعد فك التشفير وتجميع الأجزاء حيثما ينطبق ذلك. (وبالتالي فإن حدود السجلات غير مرئية.)

إذا أدى معالجة رسالة بروتوكول مستلمة إلى خطأ، فقد لا يتم استدعاء دالة الاستدعاء. على سبيل المثال، لن ترى دالة الاستدعاء أبداً رسائل تعتبر كبيرة جدًا لمعالجتها.

بسبب التفاوض التلقائي على إصدار البروتوكول، version ليس بالضرورة إصدار البروتوكول الذي يستخدمه مرسل الرسالة: إذا تم استقبال رسالة TLS 1.0 ClientHello بواسطة خادم يدعم SSL 3.0 فقط، فإن version سيكون SSL3_VERSION.
