NAME

libalpm_cb - callback function type

SYNOPSIS

#include <alpm_callback.h>

typedef int (*alpm_callback_t)(
    int code,
    void *data
);

DESCRIPTION

This callback function type is used by libalpm to notify the user about the progress of certain operations, like downloading packages.

CALLBACK FUNCTIONS

The callback function is called with a code indicating the event type and a pointer to data structure containing event-specific information.

The callback function should return 0 on success or a non-zero value to abort the operation.

code

An integer representing the event type. The following codes are defined:

  • ALPM_CB_NULL: No specific event, data is NULL.
  • ALPM_CB_LOG: Log message, data points to an alpm_log_event_t structure.
  • ALPM_CB_DL_PROGRESS: Download progress, data points to an alpm_download_event_progress_t structure.
  • ALPM_CB_DL_RETRY: Download retry, data points to an alpm_download_event_retry_t structure.
  • ALPM_CB_DL_COMPLETED: Download completed, data points to an alpm_download_event_completed_t structure.

data

A pointer to a structure containing event-specific information. The type of the structure depends on the value of the code parameter.

struct alpm_download_event_progress_t

Contains information about download progress.

typedef struct {
    const char *pkgname;
    const char *url;
    const char *localpath;
    long long size;
    long long dlspeed;
    long long dlnow;
} alpm_download_event_progress_t;
  • pkgname: Name of the package being downloaded.
  • url: URL of the package being downloaded.
  • localpath: Path to the local file being downloaded.
  • size: Total size of the file in bytes.
  • dlspeed: Current download speed in bytes per second.
  • dlnow: Number of bytes downloaded so far.
