الاسم

iconv_open - تخصيص واصف لتحويل مجموعات الأحرف

ملخص

#include <iconv.h>

iconv_t iconv_open (const char* tocode, const char* fromcode);

الوصف

تقوم وظيفة iconv_open بتخصيص واصف تحويل مناسب لتحويل تسلسلات البايتات من ترميز الأحرف fromcode إلى ترميز الأحرف tocode.

القيم المسموح بها لـ fromcode و tocode والمجموعات المدعومة تعتمد على النظام. بالنسبة لمكتبة libiconv، يتم دعم الترميزات التالية، في جميع المجموعات.

اسم الترميز الفارغ "" يعادل "char": يشير إلى ترميز الأحرف المحلي المعتمد.

عندما يتم إلحاق السلسلة "//TRANSLIT" بـ tocode، يتم تنشيط الترجمة. هذا يعني أنه عندما لا يمكن تمثيل حرف في مجموعة الأحرف الهدف، يمكن تقريبه من خلال حرف واحد أو أكثر يبدو مشابهًا للحرف الأصلي.

عندما يتم إلحاق السلسلة "//IGNORE" بـ tocode، سيتم تجاهل تسلسلات البايتات المتعددة غير الصالحة في الإدخال والأحرف التي لا يمكن تمثيلها في مجموعة الأحرف الهدف بصمت.

عندما يتم إلحاق السلسلة "//NON_IDENTICAL_DISCARD" بـ tocode، سيتم تجاهل الأحرف التي لا يمكن تمثيلها في مجموعة الأحرف الهدف بصمت.

يمكن استخدام واصف التحويل الناتج مع iconv أي عدد من المرات. يظل صالحًا حتى يتم إلغاء تخصيصه باستخدام iconv_close.

يحتوي واصف التحويل على حالة تحويل. بعد الإنشاء باستخدام iconv_open، تكون الحالة في الحالة الأولية. يؤدي استخدام iconv إلى تعديل حالة تحويل الواصف. (هذا يعني أنه لا يمكن استخدام واصف التحويل في خيوط متعددة في وقت واحد.) لإعادة الحالة إلى الحالة الأولية، استخدم iconv مع NULL كوسيط inbuf.

قيمة الإرجاع

تقوم وظيفة iconv_open بإرجاع واصف تحويل تم تخصيصه حديثًا. في حالة حدوث خطأ، تقوم بتعيين errno وإرجاع (iconv_t)(-1).

الأخطاء

يمكن أن يحدث الخطأ التالي، من بين أمور أخرى:

EINVAL
التحويل من fromcode إلى tocode غير مدعوم من قبل التنفيذ.

iconv_open(3) - Arch Linux

iconv_open(3)

الوصف

iconv_open - فتح محول أحرف.

الصيغة 
#include <iconv.h>

iconv_t iconv_open(const char *tocode, const char *fromcode);
الوصف

الدالة iconv_open() تفتح واصفًا لمحول أحرف جديد. يحدد tocode الترميز الوجهة، و fromcode يحدد الترميز المصدر. إذا نجحت، تعيد الدالة واصفًا لمحول الأحرف، والذي يمكن استخدامه في استدعاءات لاحقة لـ iconv(). إذا فشلت، تعيد الدالة (iconv_t) -1 وتعين المتغير العام errno للإشارة إلى الخطأ.

الرموز المميزة المتاحة لـ tocode و fromcode تعتمد على نظام التشغيل. يمكنك استخدام iconvlist() للحصول على قائمة بالترميزات المتاحة.

القيمة المعادة

عند النجاح، تعيد iconv_open() واصفًا لمحول الأحرف. عند الفشل، تعيد (iconv_t) -1 ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء
  • EINVAL: ترميز غير صالح تم تحديده في tocode أو fromcode.
  • ENOMEM: ذاكرة غير كافية متاحة.
مثال 
#include <stdio.h>
#include <stdlib.h>
#include <iconv.h>
#include <errno.h>

int main() {
    iconv_t cd;
    const char *fromcode = "UTF-8";
    const char *tocode = "ISO-8859-1";

    cd = iconv_open(tocode, fromcode);
    if (cd == (iconv_t) -1) {
        perror("iconv_open");
        exit(EXIT_FAILURE);
    }

    printf("Successfully opened iconv descriptor for %s to %s\n", fromcode, tocode);

    if (iconv_close(cd) == -1) {
        perror("iconv_close");
        exit(EXIT_FAILURE);
    }

    printf("Successfully closed iconv descriptor\n");

    return 0;
}
