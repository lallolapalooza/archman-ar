إرشادات عامة

قاعدة إبهام آمنة جدًا: انظر إلى ما تم فعله بالفعل وحاول فعل الشيء نفسه.

  • يجب تجنب علامات التبويب واستبدالها بـ ثماني مسافات.
  • المسافة البادئة عادة ما تكون 4 مسافات.
  • يجب أن تلتف الأسطر بحد أقصى عند 79 حرفًا.
  • لا تترك مسافات بيضاء في نهاية الأسطر.
  • لا تستخدم مسافات متعددة لأي شيء آخر غير المسافة البادئة.
  • الكود الذي يظهر تحذيرات == كود خنزير == ضربتان على وجهك

أسلوب ترميز C

حاول استخدام أسماء قصيرة كلما أمكن ذلك (i للفهارس، w للعرض، cv للوحة الرسم...). وحدات الماكرو دائمًا بأحرف كبيرة، وأسماء المتغيرات والدوال دائمًا بأحرف صغيرة. استخدم الشرطة السفلية لفصل الكلمات داخل الأسماء:

#define BROKEN 0
#define MAX(x, y) ((x > y) ? (x) : (y))
unsigned int x, y, w, h;
char *font_name;
void frobulate_every_three_seconds(void);

const هي لاحقة. إنها char const *foo، وليس const char *foo.

استخدم المسافات بعد الفواصل وبين المعاملات. لا تستخدم المسافات بعد قوس فتح أو قبله قوس إغلاق:

a += 2;
b = (a * (c + d));
x = min(x1, x2, x3);

لا تضع مسافة بين الدوال والقوس الافتتاحي المقابل:

int function(int);

يمكن إدراج مسافة بعد الكلمات المفتاحية مثل for، while أو if، ولكن الاتساق مع بقية الصفحة أمر مشجع:

if(a == b)
    return;
if (p == NULL)

لا تضع أقواسًا حول قيم الإرجاع:

return a + (b & x) + d[10];

يجب أن تكون الأقواس المعقوفة الافتتاحية في سطر خاص بها، محاذية للكتلة الحالية. الأقواس المعقوفة اختيارية للأسطر المفردة:

int function(int a)
{
    if(a & 0x84)
        return a;
    if(a < 0)
    {
        return -a;
    }
    else
    {
        a /= 2;
        switch(a)
        {
            case 0:
            case 1:
                return -1;
                break;
            default:
                return a;
        }
    }
}
