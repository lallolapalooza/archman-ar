الوصف

يمكن لكائن ASN1_STRING تمثيل مجموعة متنوعة من أنواع ASN.1 المضمنة. يمكنه تخزين نوع وقيمة.

تقوم جميع دوال *_new() بتخصيص وتهيئة كائن ASN1_STRING فارغ. يوضح الجدول التالي النوع المعين للكائن الجديد، ونوع ASN.1 الذي يمثله.

DESCRIPTION

These functions provide mechanisms for creating and freeing ASN1 data types. Most of them are simple wrappers around the more generic ASN1_STRING_new() and ASN1_STRING_type_new() functions, or specific constructors for known ASN1 types.

The *_new() functions allocate and initialize an ASN1_STRING structure of the specified type. The contents are initialized to sensible defaults, typically empty or zeroed values. The specific meaning of these defaults depends on the ASN1 type.

The *_free() functions release the memory allocated for the ASN1 structure a. Any data contained within the structure is also freed.

The mapping between the specific *_new() functions and the underlying ASN1 type is as follows:

        Object Type          Function

The following table lists the specific *_new() functions and the ASN1 types they create:

ASN1_STRING_new() V_ASN1_OCTET_STRING
ASN1_STRING_type_new() type argument
ASN1_OCTET_STRING_new() V_ASN1_OCTET_STRING OCTET STRING
ASN1_BIT_STRING_new() V_ASN1_BIT_STRING BIT STRING
ASN1_INTEGER_new() V_ASN1_INTEGER INTEGER
ASN1_ENUMERATED_new() V_ASN1_ENUMERATED ENUMERATED
ASN1_UTF8STRING_new() V_ASN1_UTF8STRING UTF8String
ASN1_IA5STRING_new() V_ASN1_IA5STRING IA5String
ASN1_UNIVERSALSTRING_new() V_ASN1_UNIVERSALSTRING UniversalString
ASN1_BMPSTRING_new() V_ASN1_BMPSTRING BMPString
ASN1_GENERALSTRING_new() V_ASN1_GENERALSTRING GeneralString
ASN1_T61STRING_new() V_ASN1_T61STRING T61String
ASN1_VISIBLESTRING_new() V_ASN1_VISIBLESTRING VisibleString
ASN1_PRINTABLESTRING_new() V_ASN1_PRINTABLESTRING PrintableString
ASN1_PRINTABLE_new() V_ASN1_UNDEF
DIRECTORYSTRING_new() V_ASN1_UNDEF
DISPLAYTEXT_new() V_ASN1_UNDEF
ASN1_GENERALIZEDTIME_new() V_ASN1_GENERALIZEDTIME GeneralizedTime
ASN1_UTCTIME_new() V_ASN1_UTCTIME UTCTime
ASN1_TIME_new() V_ASN1_UNDEF TIME

All the *_free() functions free a including any data contained in it. If a is a NULL pointer, no action occurs.

RETURN VALUES

All the *_new() functions return the new ASN1_STRING object if successful; otherwise NULL is returned and an error code can be retrieved with ERR_get_error(3).

BUGS

ASN1_OCTET_STRING, ASN1_BIT_STRING, ASN1_INTEGER, ASN1_ENUMERATED, ASN1_UTF8STRING, ASN1_IA5STRING, ASN1_UNIVERSALSTRING, ASN1_BMPSTRING, ASN1_GENERALSTRING, ASN1_T61STRING, ASN1_VISIBLESTRING, ASN1_PRINTABLESTRING, ASN1_GENERALIZEDTIME, ASN1_UTCTIME, and ASN1_TIME are all structures with a common ASN1 structure. In particular, they all contain a pointer to the ASN1 tag value, the length, and a pointer to the data. The ASN1_STRING_new() function creates a generic ASN1_STRING object which can be used for any of these types. The ASN1_STRING_type_new() function creates an ASN1_STRING object of a specified type. The specific *_new() functions are convenient wrappers that call the appropriate ASN1_STRING_type_new() function.

All the *_free() functions are wrappers around ASN1_STRING_free().
