libressl-X509_ATTRIBUTE_get0_object(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

X509_ATTRIBUTE_GET0_OBJECT(3) دليل وظائف المكتبة X509_ATTRIBUTE_GET0_OBJECT(3)

الاسم

X509_ATTRIBUTE_get0_object، X509_ATTRIBUTE_count، X509_ATTRIBUTE_get0_type، X509_ATTRIBUTE_get0_data — وصول قراءة سمة X.501

ملخص

المكتبة «libcrypto»
#include <openssl/x509.h>

ASN1_OBJECT *
X509_ATTRIBUTE_get0_object(X509_ATTRIBUTE *attr);

int
X509_ATTRIBUTE_count(const X509_ATTRIBUTE *attr);

ASN1_TYPE *
X509_ATTRIBUTE_get0_type(X509_ATTRIBUTE *attr, int index);

void *
X509_ATTRIBUTE_get0_data(X509_ATTRIBUTE *attr, int index, int type, void *data);

الوصف

توفر هذه الوظائف وصول القراءة لكائن السمة X.501 attr.

بالنسبة لـ X509_ATTRIBUTE_get0_data، عادةً ما يكون الوسيط type أحد الثوابت V_ASN1_* المعرفة في <openssl/asn1.h>. على سبيل المثال، إذا كان من المتوقع أن تكون القيمة المرجعة من النوع ASN1_OCTET_STRING، قم بتمرير V_ASN1_OCTET_STRING كوسيط type. يتم تجاهل الوسيط data؛ يوصى بتمرير NULL.

قيم الإرجاع

X509_ATTRIBUTE_get0_object() تُرجع مؤشرًا داخليًا لنوع attr أو NULL إذا كان attr هو NULL أو إذا لم يتم تعيين نوعه.

X509_ATTRIBUTE_count() تُرجع عدد القيم المخزنة في attr أو 0 إذا لم يتم تعيين أي قيمة أو قيم.

X509_ATTRIBUTE_get0_type() تُرجع مؤشرًا داخليًا لكائن ANY بتنسيق ASN.1 يمثل القيمة ذات index الصفري المحدد أو NULL إذا كان attr هو NULL، أو إذا كان index أكبر من أو يساوي عدد القيم المخزنة في attr، أو إذا لم يتم تعيين أي قيمة أو قيم.

X509_ATTRIBUTE_get0_data() تُرجع مؤشرًا داخليًا للبيانات الموجودة في القيمة ذات index الصفري المحدد أو NULL إذا كان attr هو NULL، أو إذا كان index أكبر من أو يساوي عدد القيم المخزنة في attr، أو إذا لم يتم تعيين أي قيمة أو قيم، أو إذا كان كائن ANY بتنسيق ASN.1 الذي يمثل القيمة ذات index المحدد ليس من النوع المطلوب type.

انظر أيضًا

ASN1_OBJECT_new(3)، ASN1_TYPE_new(3)، OPENSSL_sk_new(3)، X509_ATTRIBUTE_new(3)، X509_ATTRIBUTE_set1_object(3)
