libkeccak_hmac_create(3)

الحزمة: libkeccak

التراخيص: custom:ISC

LIBKECCAK_HMAC_CREATE(3) دليل وظائف المكتبة LIBKECCAK_HMAC_CREATE(3)

الاسم

libkeccak_hmac_create - تخصيص وتهيئة حالة HMAC-hashing

الملخص

#include <libkeccak.h>
struct libkeccak_hmac_state *libkeccak_hmac_create(const struct libkeccak_spec *spec, const void *key, size_t key_length);

اربط مع -lkeccak.

الوصف

تقوم الدالة libkeccak_hmac_create() بتخصيص مؤشر struct libkeccak_hmac_state * جديد بعنصر واحد مهيأ، وتعيين معلمات ضبط الخوارزمية إلى تلك المحددة بواسطة *spec، والمفتاح إلى key بطول key_length.

قيم الإرجاع

ترجع الدالة libkeccak_hmac_create() مؤشرًا مخصصًا حديثًا struct libkeccak_hmac_state * (بعنصر واحد مهيأ) عند اكتمالها بنجاح. عند حدوث خطأ، يتم إرجاع NULL ويتم تعيين errno لوصف الخطأ.

الأخطاء

قد تفشل الدالة libkeccak_hmac_create() لأي سبب محدد للدوال malloc(3) و realloc(3).

انظر أيضًا

libkeccak_hmac_initialise(3), libkeccak_hmac_free(3), libkeccak_hmac_fast_free(3), libkeccak_hmac_duplicate(3)
