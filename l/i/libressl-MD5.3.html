libressl-MD5(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

MD5(3) دليل وظائف المكتبة MD5(3)

الاسم

MD4، MD5، MD4_Init، MD4_Update، MD4_Final، MD5_Init، MD5_Update، MD5_Final — وظائف تجزئة MD4 و MD5

الملخص

المكتبة «libcrypto»
#include <openssl/md4.h>

unsigned char *
MD4(const unsigned char *d، unsigned long n، unsigned char *md);

int
MD4_Init(MD4_CTX *c);

int
MD4_Update(MD4_CTX *c، const void *data، unsigned long len);

int
MD4_Final(unsigned char *md، MD4_CTX *c);

#include <openssl/md5.h>

unsigned char *
MD5(const unsigned char *d، unsigned long n، unsigned char *md);

int
MD5_Init(MD5_CTX *c);

int
MD5_Update(MD5_CTX *c، const void *data، unsigned long len);

int
MD5_Final(unsigned char *md، MD5_CTX *c);

الوصف

MD4 و MD5 هما وظيفتان تجزئة تشفيرتان بإخراج 128 بت.

MD4() و MD5() تحسبان تجزئة رسالة MD4 و MD5 للبايتات n الموجودة في d وتضعها في md، والذي يجب أن يحتوي على مساحة لـ MD4_DIGEST_LENGTH == MD5_DIGEST_LENGTH == 16 بايت للإخراج.

يمكن استخدام الوظائف التالية إذا لم تكن الرسالة مخزنة بالكامل في الذاكرة:

MD5_Init() تهيئ بنية MD5_CTX.

MD5_Update() يمكن استدعاؤها بشكل متكرر مع أجزاء من الرسالة المراد تجزئتها (len بايتات في data).

MD5_Final() تضع تجزئة الرسالة في md، والذي يجب أن يحتوي على مساحة لـ MD5_DIGEST_LENGTH == 16 بايت للإخراج، وتمحو MD5_CTX.

MD4_Init()، MD4_Update()، و MD4_Final() متشابهة باستخدام بنية MD4_CTX.

يجب على التطبيقات استخدام الوظائف عالية المستوى EVP_DigestInit(3) إلخ. بدلاً من استدعاء وظائف التجزئة هذه مباشرة.

قيم الإرجاع

MD4() و MD5() ترجع مؤشرات إلى قيمة التجزئة.

MD4_Init()، MD4_Update()، MD4_Final()، MD5_Init()، MD5_Update()، و MD5_Final() ترجع 1 للنجاح أو 0 بخلاف ذلك.

انظر أيضاً

EVP_DigestInit(3)

المعايير

RFC 1320، RFC 1321

التاريخ

MD5()، MD5_Init()، MD5_Update()، و MD5_Final() ظهرت في SSLeay 0.4 أو أقدم وكانت متاحة منذ OpenBSD 2.4.

MD4()، MD4_Init()، MD4_Update()، و MD4_Final() ظهرت لأول مرة في OpenSSL 0.9.6 وكانت متاحة منذ OpenBSD 2.9.

تحذيرات

تسمح التطبيقات الأخرى لـ md في MD4() و MD5() بأن تكون NULL وترجع مصفوفة ثابتة، وهي ليست آمنة للاستخدام المتزامن.
