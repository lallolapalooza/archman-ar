libpipewire-module-example-sink(7)

libpipewire-module-example-sink(7) دليل المعلومات المتنوعة libpipewire-module-example-sink(7)

الاسم

libpipewire-module-example-sink - مثال لإخراج الصوت

الوصف

مثال إخراج الصوت هو نقطة بداية جيدة لكتابة إخراج صوت مخصص.

نحن نشير إلى الكود المصدري لمزيد من المعلومات.

اسم الوحدة

libpipewire-module-example-sink

خيارات الوحدة

  • node.name: اسم فريد للبث
  • node.description: اسم مقروء للبث
  • stream.props = {}: خصائص سيتم تمريرها إلى البث

خيارات عامة

خيارات ذات سلوك معروف جيدًا.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

مثال التكوين

# ~/.config/pipewire/pipewire.conf.d/my-example-sink.conf
context.modules = [
{   name = libpipewire-module-example-sink
    args = {
        node.name = "example_sink"
        node.description = "My Example Sink"
        stream.props = {
            audio.position = [ FL FR ]
        }
    }
}
]
