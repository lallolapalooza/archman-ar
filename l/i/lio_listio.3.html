lio_listio(3) دليل وظائف المكتبة lio_listio(3)

الاسم

lio_listio - بدء قائمة طلبات الإدخال/الإخراج

المكتبة

مكتبة الوقت الفعلي (librt، -lrt)

الملخص

#include <aio.h>
int lio_listio(int n;
               int mode,
               struct aiocb *restrict const aiocb_list[restrict n],
               int n, struct sigevent *restrict sevp);

الوصف

تبدأ الوظيفة lio_listio() قائمة عمليات الإدخال/الإخراج الموصوفة بواسطة المصفوفة aiocb_list.

له العملية mode إحدى القيم التالية:

LIO_WAIT
تتوقف الاستدعاء حتى تكتمل جميع العمليات. يتم تجاهل الوسيط sevp.
LIO_NOWAIT
يتم وضع عمليات الإدخال/الإخراج في قائمة الانتظار للمعالجة وتعود الاستدعاء على الفور. عند اكتمال جميع عمليات الإدخال/الإخراج، يحدث إشعار غير متزامن، كما هو محدد بواسطة الوسيط sevp؛ انظر sigevent(3type) للتفاصيل. إذا كان sevp فارغًا، فلا يحدث أي إشعار غير متزامن.

الوسيط aiocb_list هو مصفوفة من المؤشرات إلى هياكل aiocb التي تصف عمليات الإدخال/الإخراج. يتم تنفيذ هذه العمليات بترتيب غير محدد. يحدد الوسيط n حجم المصفوفة aiocb_list. يتم تجاهل المؤشرات الفارغة في aiocb_list.

في كل كتلة تحكم في aiocb_list، يحدد حقل aio_lio_opcode عملية الإدخال/الإخراج التي سيتم بدءها، على النحو التالي:

LIO_READ
بدء عملية قراءة. يتم وضع العملية في قائمة الانتظار كما لو تم استدعاء aio_read(3) مع تحديد كتلة التحكم هذه.
LIO_WRITE
بدء عملية كتابة. يتم وضع العملية في قائمة الانتظار كما لو تم استدعاء aio_write(3) مع تحديد كتلة التحكم هذه.
LIO_NOP
تجاهل كتلة التحكم هذه.

الحقول المتبقية في كل كتلة تحكم لها نفس المعاني كما هو الحال بالنسبة لـ aio_read(3) و aio_write(3). يمكن استخدام حقول aio_sigevent لكل كتلة تحكم لتحديد الإشعارات لعمليات الإدخال/الإخراج الفردية (انظر sigevent(7)).

قيمة الإرجاع

إذا كان mode هو LIO_NOWAIT، فإن lio_listio() تعود بـ 0 إذا تم وضع جميع عمليات الإدخال/الإخراج بنجاح في قائمة الانتظار. وإلا، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

إذا كان mode هو LIO_WAIT، فإن lio_listio() تعود بـ 0 عند اكتمال جميع عمليات الإدخال/الإخراج بنجاح. وإلا، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

يوفر حالة الإرجاع من lio_listio() معلومات فقط حول الاستدعاء نفسه، وليس حول عمليات الإدخال/الإخراج الفردية. قد تفشل عملية إدخال/إخراج واحدة أو أكثر، ولكن هذا لا يمنع العمليات الأخرى من الإكمال. يمكن تحديد حالة عمليات الإدخال/الإخراج الفردية في aiocb_list باستخدام aio_error(3). عند اكتمال عملية ما، يمكن الحصول على حالة إرجاعها باستخدام aio_return(3). قد تفشل عمليات الإدخال/الإخراج الفردية للأسباب الموضحة في aio_read(3) و aio_write(3).

الأخطاء

قد تفشل الوظيفة lio_listio() للأسباب التالية:

EAGAIN
نفاد الموارد.
EAGAIN
عدد عمليات الإدخال/الإخراج المحدد بواسطة n سيؤدي إلى تجاوز الحد AIO_MAX.
EINTR
كان mode هو LIO_WAIT وتم التقاط إشارة قبل اكتمال جميع عمليات الإدخال/الإخراج؛ انظر signal(7). (قد تكون هذه حتى إحدى الإشارات المستخدمة للإشعار بإكمال الإدخال/الإخراج غير المتزامن.)
EINVAL
mode غير صالح، أو أن n يتجاوز الحد AIO_LISTIO_MAX.
EIO
فشلت عملية واحدة أو أكثر محددة بواسطة aiocb_list. يمكن للتطبيق التحقق من حالة كل عملية باستخدام aio_return(3).

إذا فشلت lio_listio() بالخطأ EAGAIN أو EINTR أو EIO، فقد تكون بعض العمليات في aiocb_list قد تم بدؤها. إذا فشلت lio_listio() لأي سبب آخر، فلم يتم بدء أي من عمليات الإدخال/الإخراج.

ملاحظات

من الجيد مسح كتل التحكم بالصفر قبل استخدامها. يجب عدم تغيير كتل التحكم أثناء عمليات الإدخال/الإخراج قيد التقدم. يجب عدم الوصول إلى مناطق المخزن المؤقت التي يتم القراءة منها أو الكتابة إليها أثناء العمليات أو قد تحدث نتائج غير محددة. يجب أن تظل مناطق الذاكرة المعنية صالحة.

تؤدي عمليات الإدخال/الإخراج المتزامنة التي تحدد نفس هيكل aiocb إلى نتائج غير محددة.

lio_listio(3)

NAME

lio_listio - Asynchronous I/O operation submission

SYNOPSIS

#include <aio.h>

int lio_listio(int mode, struct aiocb *restrict list[], int nent, struct sigevent *restrict sig);

DESCRIPTION

The lio_listio() function is used to submit a list of asynchronous I/O control blocks for processing. The mode parameter determines how the operations in the list are processed.

If mode is LIO_READ, all operations in the list must be read operations.

If mode is LIO_WRITE, all operations in the list must be write operations.

If mode is LIO_READWRITE, the list can contain a mix of read and write operations.

The list parameter is an array of pointers to aiocb structures. Each aiocb structure describes an asynchronous I/O operation to be performed. The nent parameter specifies the number of aiocb structures in the list.

The sig parameter specifies how the completion of the entire list of operations should be signaled. If sig is NULL, no notification is sent upon completion.

RETURN VALUE

On success, lio_listio() returns 0. On failure, it returns -1 and sets errno to indicate the error.

ERRORS

  • EINVAL: An invalid value was specified for mode, or list is NULL, or nent is less than or equal to 0.
  • EAGAIN: The system limit on the number of asynchronous I/O operations has been reached.
  • ENOMEM: Not enough memory could be allocated to fulfill the request.

ATTRIBUTES

For an explanation of the attributes of these interfaces, see attributes(7).

STANDARDS

The lio_listio() function conforms to POSIX.1-2008.

HISTORY

The lio_listio() function first appeared in FreeBSD 3.0.

NOTES

Each aiocb structure in the list must be properly initialized before being passed to lio_listio().

The aio_error() function can be used to retrieve the error status of individual operations in the list.

The aio_return() function can be used to retrieve the return status of individual operations in the list.
