الوصف

X509_EXTENSION_new() تخصص وتهيئ كائن X509_EXTENSION فارغ، يمثل بنية Extension ASN.1 المحددة في RFC 5280 القسم 4.1. إنه كائن تغليف حول كائنات امتداد محددة من أنواع مختلفة ويخزن معرف نوع الامتداد وعلامة الحرجية بالإضافة إلى الشكل المشفر DER للكائن المغلف. يمكن استخدام كائنات X509_EXTENSION لشهادات X.509 v3 داخل كائنات X509_CINF ولقوائم إلغاء الشهادات X.509 v2 داخل كائنات X509_CRL_INFO وX509_REVOKED.

X509_EXTENSION_dup() ينشئ نسخة عميقة من ex باستخدام ASN1_item_dup(3).

X509_EXTENSION_free() تحرر ex

X509_EXTENSION_create_by_NID() تنشئ امتدادًا من النوع nid والحرجية crit باستخدام البيانات data. يتم إرجاع الامتداد المنشأ وكتابته إلى *ex بإعادة استخدام أو تخصيص امتداد جديد إذا لزم الأمر، لذلك يجب أن يكون *ex إما NULL أو بنية X509_EXTENSION صالحة. يجب ألا يكون مؤشرًا غير مهيأ.

X509_EXTENSION_create_by_OBJ() مطابق لـ X509_EXTENSION_create_by_NID() باستثناء أنه ينشئ امتدادًا باستخدام obj بدلاً من NID.

X509_EXTENSION_set_object() يضبط نوع الامتداد لـ ex إلى obj. يتم تكرار المؤشر obj داخليًا لذلك يجب تحرير obj بعد الاستخدام.

X509_EXTENSION_set_critical() يضبط حرجية ex إلى crit. إذا كانت crit صفرًا، فإن الامتداد غير حرج، وإلا فإنه حرج.

X509_EXTENSION_set_data() يضبط البيانات في الامتداد ex إلى data. يتم تكرار المؤشر data داخليًا.

X509_EXTENSION_get_object() يرجع نوع الامتداد لـ exASN1_OBJECT. المؤشر المرجع هو قيمة داخلية يجب عدم تحريرها.

X509_EXTENSION_get_critical() يختبر ما إذا كان ex

X509_EXTENSION_get_data() يرجع بيانات الامتداد ex. المؤشر المرجع هو قيمة داخلية يجب عدم تحريرها.

X509_supported_extension() يتحقق مما إذا كان ex

تتعامل هذه الوظائف مع محتويات الامتداد مباشرة. معظم التطبيقات ترغب في تحليل أو ترميز وإضافة امتداد: يجب عليها استخدام وظائف ترميز وفك ترميز الامتداد بدلاً من ذلك مثل X509_add1_ext_i2d(3) و X509_get_ext_d2i(3).

البيانات data المرتبطة بامتداد هي ترميز الامتداد في بنية ASN1_OCTET_STRING.

قيم الإرجاع

X509_EXTENSION_new()، X509_EXTENSION_dup()، X509_EXTENSION_create_by_NID()، و X509_EXTENSION_create_by_OBJ() ترجع مؤشر X509_EXTENSION أو NULL إذا حدث خطأ.

X509_EXTENSION_set_object()، X509_EXTENSION_set_critical()، و X509_EXTENSION_set_data() ترجع 1 للنجاح أو 0 للإخفاق.

X509_EXTENSION_get_object() ترجع مؤشر ASN1_OBJECT.

X509_EXTENSION_get_critical() ترجع 0 لغير الحرج أو 1 للحرج.

X509_EXTENSION_get_data() ترجع مؤشر ASN1_OCTET_STRING.

DESCRIPTION

These functions are used to create, manipulate, and query X.509 extensions.

X509_EXTENSION_new() allocates and returns an empty X509_EXTENSION structure. It returns NULL on failure.

X509_EXTENSION_free() frees the X509_EXTENSION structure ex.

X509_EXTENSION_dup() duplicates the X509_EXTENSION structure ex.

X509_EXTENSION_create_by_NID() creates a new X509_EXTENSION structure representing the extension identified by the numerical identifier nid. The extension is marked as critical if crit is non-zero. The extension value is specified by the string value, which is interpreted according to the NID. If ex is not NULL, it is reused to store the new extension.

X509_EXTENSION_create_by_OBJ() is similar to X509_EXTENSION_create_by_NID() but uses an ASN1_OBJECT pointer obj instead of a NID.

X509_EXTENSION_set_object() sets the object identifier of the extension ex to obj.

X509_EXTENSION_set_critical() sets the criticality flag of the extension ex to crit. If crit is non-zero, the extension is marked critical.

X509_EXTENSION_set_data() sets the extension data of ex to data with length len.

X509_EXTENSION_get_object() returns the ASN1_OBJECT pointer for the extension ex. The returned pointer should not be freed.

X509_EXTENSION_get_critical() returns the criticality flag of the extension ex. It returns 1 if the extension is critical, and 0 otherwise.

X509_EXTENSION_get_data() returns the extension data as an ASN1_OCTET_STRING pointer. The returned pointer should not be freed.

X509_supported_extension() returns 1 if the type of ex is supported by the verifier or 0 otherwise.
