الوصف

BIO_f_ssl() تُرجع طريقة SSL BIO. هذه طريقة BIO مرشحة وهي غلاف حول روتينات SSL الخاصة بـ OpenSSL، مضيفةً "نكهة" BIO لمدخلات ومخرجات SSL.

الاتصالات التي تتم على SSL BIO تتواصل باستخدام بروتوكول SSL مع BIOs القراءة والكتابة الخاصة بـ SSL. إذا لم يتم إنشاء اتصال SSL، فسيتم محاولة إنشائه عند أول استدعاء لعملية إدخال/إخراج.

إذا تم إلحاق BIO بـ SSL BIO باستخدام BIO_push(3)، فسيتم استخدامه تلقائيًا كـ BIOs القراءة والكتابة الخاصة بـ SSL BIO.

استدعاء BIO_reset(3) على SSL BIO يقوم بإغلاق أي اتصال SSL حالي عن طريق استدعاء SSL_shutdown(3). ثم يتم إرسال BIO_reset(3) إلى BIO التالي في السلسلة؛ هذا عادةً ما يقطع اتصال النقل الأساسي. ثم تتم إعادة تعيين SSL BIO إلى حالة القبول أو الاتصال الأولية.

إذا تم تعيين علامة الإغلاق عند تحرير SSL BIO، فسيتم أيضًا تحرير بنية SSL الداخلية باستخدام SSL_free(3).

BIO_set_ssl() تضبط مؤشر SSL الداخلي لـ BIO b إلى ssl باستخدام علامة الإغلاق c.

BIO_get_ssl() تسترجع مؤشر SSL الخاص بـ BIO b؛ يمكن بعد ذلك معالجته باستخدام وظائف مكتبة SSL القياسية.

BIO_set_ssl_mode() تضبط وضع SSL BIO إلى client. إذا كان client يساوي 1، يتم تعيين وضع العميل. إذا كان client يساوي 0، يتم تعيين وضع الخادم.

BIO_set_ssl_renegotiate_bytes() تضبط عدد بايتات إعادة التفاوض على num. عند التعيين، بعد كل num بايت من الإدخال/الإخراج (القراءة والكتابة)، يتم إعادة التفاوض على جلسة SSL تلقائيًا. يجب أن يكون num على الأقل 512 بايت.

BIO_set_ssl_renegotiate_timeout() تضبط مهلة إعادة التفاوض على seconds. عند انتهاء مهلة إعادة التفاوض، يتم إعادة التفاوض على الجلسة تلقائيًا.

BIO_get_num_renegotiates() تُرجع العدد الإجمالي لإعادة التفاوض على الجلسة بسبب الإدخال/الإخراج أو المهلة.

BIO_new_ssl() تخصص SSL BIO باستخدام SSL_CTX ctx وتستخدم وضع العميل إذا كان client غير صفري.

BIO_new_ssl_connect() تنشئ سلسلة BIO جديدة تتكون من SSL BIO (باستخدام ctx) متبوعة بـ BIO اتصال.

BIO_new_buffer_ssl_connect() تنشئ سلسلة BIO جديدة تتكون من BIO تخزين مؤقت، و SSL BIO (باستخدام ctx) و BIO اتصال.

BIO_ssl_copy_session_id() تنسخ معرف جلسة SSL بين سلاسل BIO from و to. يتم ذلك عن طريق تحديد مواقع SSL BIOs في كل سلسلة واستدعاء SSL_copy_session_id(3) على مؤشر SSL الداخلي.

BIO_ssl_shutdown() تغلق اتصال SSL على سلسلة BIO bio. يتم ذلك عن طريق تحديد موقع SSL BIO في السلسلة واستدعاء SSL_shutdown(3) على مؤشر SSL الداخلي الخاص بها.

BIO_do_handshake() تحاول إكمال مصافحة SSL على BIO المقدم وإنشاء اتصال SSL. تُرجع 1 إذا تم إنشاء الاتصال بنجاح. تُرجع قيمة صفرية أو سالبة إذا لم يكن بالإمكان إنشاء الاتصال؛ الاستدعاء BIO_do_handshake(3)

DESCRIPTION

The BIO_f_ssl() function returns a BIO_METHOD that supports the SSL BIO filter.

The BIO_new_ssl() function creates a new SSL BIO. The ctx is an SSL_CTX(3) structure. If client is non-zero, the SSL BIO is configured as a client, otherwise it is configured as a server.

The BIO_new_ssl_connect() and BIO_new_buffer_ssl_connect() functions create a new SSL BIO chain, with an underlying connect BIO. This simplifies the process of creating an SSL client connection. BIO_new_buffer_ssl_connect() also adds a buffering BIO to the chain. The ctx is an SSL_CTX(3) structure.

The BIO_ssl_op_set() function sets SSL operations on the SSL BIO. The op parameter is a bit mask of operations to be set. The currently supported operation is SSL_OP_NO_SESSION_RESUMPTION_ON_RENEGOTIATION.

The BIO_ssl_op_get() function retrieves the SSL operations set on the SSL BIO.

The BIO_ssl_set_mode() function sets SSL mode options on the SSL BIO. The mode parameter is a bit mask of modes to be set. The currently supported mode is SSL_MODE_AUTO_RETRY which retries BIO operations if they fail due to non-blocking transport and an SSL error.

The BIO_ssl_get_mode() function retrieves the SSL mode options set on the SSL BIO.

The BIO_ssl_renegotiate_bytes() function sets the number of bytes that can be read or written after which a renegotiation will be triggered.

The BIO_ssl_get_num_renegotiates() returns the number of renegotiations that have occurred on the BIO.

The BIO_ssl_renegotiate_timeout() function sets a timeout for renegotiation.

The BIO_ssl_get_ssl() function returns the SSL(3) structure associated with the SSL BIO.

The BIO_set_ssl() function associates an existing SSL(3) structure with the given BIO. If close_flag is non-zero, the SSL(3) structure will be freed when the BIO is freed.

The BIO_ssl_connect() and BIO_ssl_accept() functions perform the SSL connect and accept operations respectively. They should be called after the underlying transport has been established.

The BIO_ssl_shutdown() function performs an SSL shutdown operation.

The BIO_ssl_session_id() function retrieves the session ID of the current SSL connection.

The BIO_ssl_copy_session_id() function copies the SSL session ID from one BIO to another. This is useful for resuming SSL sessions.

The BIO_do_handshake() function performs the SSL handshake. This can be called explicitly to separate the handshake process from other I/O operations.

BIO_should_retry(3) should be used for non blocking BIOs to determine if the call should be retried. If an SSL connection has already been established, this call has no effect.

When a chain containing an SSL BIO is copied with BIO_dup_chain(3), SSL_dup(3) is called internally to copy the SSL object from the existing BIO object to the new BIO object, and the internal data related to BIO_set_ssl_renegotiate_bytes() and BIO_set_ssl_renegotiate_timeout() is also copied.

SSL BIOs are exceptional in that if the underlying transport is non-blocking they can still request a retry in exceptional circumstances. Specifically this will happen if a session renegotiation takes place during a BIO_read(3) operation. One case where this happens is when step up occurs.

In OpenSSL 0.9.6 and later the SSL flag SSL_AUTO_RETRY can be set to disable this behaviour. In other words, when this flag is set an SSL BIO using a blocking transport will never request a retry.

Since unknown BIO_ctrl(3) operations are sent through filter BIOs, the server name and port can be set using BIO_set_conn_hostname(3) and BIO_set_conn_port(3) on the BIO returned by BIO_new_ssl_connect() without having to locate the connect BIO first.

Applications do not have to call BIO_do_handshake() but may wish to do so to separate the handshake process from other I/O processing.

BIO_set_ssl(), BIO_get_ssl(), BIO_set_ssl_mode(), BIO_set_ssl_renegotiate_bytes(), BIO_set_ssl_renegotiate_timeout(), BIO_get_num_renegotiates(), and BIO_do_handshake() are implemented as macros.

RETURN VALUES

BIO_f_ssl() returns a pointer to a static BIO_METHOD structure.

When called on an SSL BIO object, BIO_method_type(3) returns the constant BIO_TYPE_SSL and BIO_method_name(3) returns a pointer to the static string "ssl".

BIO_set_ssl(), BIO_get_ssl(), BIO_set_ssl_mode(), BIO_set_ssl_renegotiate_bytes(), BIO_set_ssl_renegotiate_timeout(), and BIO_get_num_renegotiates() return 1 on success or a value less than or equal to 0 if an error occurred.

BIO_new_ssl(), BIO_new_ssl_connect(), and BIO_new_buffer_ssl_connect() returns a pointer to a newly allocated BIO chain or NULL if an error occurred.

BIO_ssl_copy_session_id() returns 1 on success or 0 on error.

BIO_do_handshake() returns 1 if the connection was established successfully or a value less than or equal to 0 otherwise.

EXAMPLES

This SSL/TLS client example attempts to retrieve a page from an SSL/TLS web server. The I/O routines are identical to those of the unencrypted example in BIO_s_connect(3).

BIO *sbio, *out;
int len;
char tmpbuf[1024];
SSL_CTX *ctx;
SSL *ssl;

ERR_load_crypto_strings();
ERR_load_SSL_strings();
OpenSSL_add_all_algorithms();

/*
 * We would seed the PRNG here if the platform didn't do it automatically
 */

ctx = SSL_CTX_new(SSLv23_client_method());

/*
 * We'd normally set some stuff like the verify paths and mode here because
 * as things stand this will connect to any server whose certificate is
 * signed by any CA.
 */

sbio = BIO_new_ssl_connect(ctx);

BIO_get_ssl(sbio, &ssl);

if (!ssl) {
	fprintf(stderr, "Can't locate SSL pointer\n");
	/* whatever ... */
}

/* Don't want any retries */
SSL_set_mode(ssl, SSL_MODE_AUTO_RETRY);

/* We might want to do other things with ssl here */

BIO_set_conn_hostname(sbio, "localhost:https");

out = BIO_new_fp(stdout, BIO_NOCLOSE);
if (BIO_do_connect(sbio) <= 0) {
	fprintf(stderr, "Error connecting to server\n");
	ERR_print_errors_fp(stderr);
	/* whatever ... */
}

if (BIO_do_handshake(sbio) <= 0) {
	fprintf(stderr, "Error establishing SSL connection\n");
	ERR_print_errors_fp(stderr);
	/* whatever ... */
}

/* Could examine ssl here to get connection info */

BIO_puts(sbio, "GET / HTTP/1.0\n\n");
for (;;) {
	len = BIO_read(sbio, tmpbuf, 1024);
	if(len <= 0) break;
	BIO_write(out, tmpbuf, len);
}
BIO_free_all(sbio);
BIO_free(out);

Here is a simple server example. It makes use of a buffering BIO to allow lines to be read from the SSL BIO using BIO_gets(3). It creates a pseudo web page containing the actual request from a client and also echoes the request to standard output.

BIO *sbio, *bbio, *acpt, *out;
int len;
char tmpbuf[1024];
SSL_CTX *ctx;
SSL *ssl;

ctx = SSL_CTX_new(SSLv23_server_method());

if (!SSL_CTX_use_certificate_file(ctx,"server.pem",SSL_FILETYPE_PEM)
    || !SSL_CTX_use_PrivateKey_file(ctx,"server.pem",SSL_FILETYPE_PEM)
    || !SSL_CTX_check_private_key(ctx)) {
	fprintf(stderr, "Error setting up SSL_CTX\n");
	ERR_print_errors_fp(stderr);
	return 0;
}

/*
 * Might do other things here like setting verify locations and DH and/or
 * RSA temporary key callbacks
 */

/* New SSL BIO setup as server */
sbio = BIO_new_ssl(ctx,0);

BIO_get_ssl(sbio, &ssl);

if (!ssl) {
	fprintf(stderr, "Can't locate SSL pointer\n");
	/* whatever ... */
}

/* Don't want any retries */
SSL_set_mode(ssl, SSL_MODE_AUTO_RETRY);

/* Create the buffering BIO */

bbio = BIO_new(BIO_f_buffer());

/* Add to chain */
sbio = BIO_push(bbio, sbio);

acpt = BIO_new_accept("4433");

/*
 * By doing this when a new connection is established we automatically
 * have sbio inserted into it. The BIO chain is now 'swallowed' by the
 * accept BIO and will be freed when the accept BIO is freed.
 */

BIO_set_accept_bios(acpt,sbio);

out = BIO_new_fp(stdout, BIO_NOCLOSE);

/* Wait for incoming connection */
if (BIO_do_accept(acpt) <= 0) {
	fprintf(stderr, "Error setting up accept BIO\n");
	ERR_print_errors_fp(stderr);
	return 0;
}

/* We only want one connection so remove and free accept BIO */

sbio = BIO_pop(acpt);

BIO_free_all(acpt);

if (BIO_do_handshake(sbio) <= 0) {
	fprintf(stderr, "Error in SSL handshake\n");
	ERR_print_errors_fp(stderr);
	return 0;
}

BIO_puts(sbio, "HTTP/1.0 200 OK\r\nContent-type: text/plain\r\n\r\n");
BIO_puts(sbio, "\r\nConnection Established\r\nRequest headers:\r\n");
BIO_puts(sbio, "--------------------------------------------------\r\n");

for (;;) {
	len = BIO_gets(sbio, tmpbuf, 1024);
	if (len <= 0)
		break;
	BIO_write(sbio, tmpbuf, len);
	BIO_write(out, tmpbuf, len);
	/* Look for blank line signifying end of headers */
	if ((tmpbuf[0] == '\r') || (tmpbuf[0] == '\n'))
		break;
}

BIO_puts(sbio, "--------------------------------------------------\r\n");
BIO_puts(sbio, "\r\n");

/* Since there is a buffering BIO present we had better flush it */
BIO_flush(sbio);

BIO_free_all(sbio);

HISTORY

BIO_f_ssl(), BIO_set_ssl(), and BIO_get_ssl() first appeared in SSLeay 0.6.0. BIO_set_ssl_mode(), BIO_new_ssl(), and BIO_ssl_copy_session_id() first appeared in SSLeay 0.8.0. BIO_ssl_shutdown() and BIO_do_handshake() first appeared in SSLeay 0.8.1. BIO_set_ssl_renegotiate_bytes(), BIO_get_num_renegotiates(), BIO_set_ssl_renegotiate_timeout(), BIO_new_ssl_connect(), and BIO_new_buffer_ssl_connect() first appeared in SSLeay 0.9.0. All these functions have been available since OpenBSD 2.4.
