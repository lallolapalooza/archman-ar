NAME

libdmtx — Data Matrix barcode library

SYNOPSIS

#include <dmtx.h>

dmtxMatrixRegion *dmtxDecodeMatrixRegion(dmtxDecode *dec, dmtxRegion *reg, int options);
void dmtxRegionDestroy(dmtxMatrixRegion **reg);
void dmtxMessageDestroy(dmtxMessage **msg);
void dmtxDecodeDestroy(dmtxDecode **dec);
void dmtxImageDestroy(dmtxImage **img);

DESCRIPTION

The libdmtx library decodes Data Matrix barcodes from images. It can also encode and create Data Matrix barcodes.

This manual page describes the functions that are used to decode Data Matrix barcodes. See dmtxencode(3) for details on encoding functions.

ENCODING - Generating Data Matrix Barcodes

Use dmtxEncodeCreate to create an encoder. Use dmtxEncodeMatrixRegion to encode a region and dmtxEncodeDestroy to destroy the encoder.

DECODING - Reading Data Matrix Barcodes

Use dmtxDecodeCreate to create a decoder. Use dmtxDecodeImage to decode an image, or dmtxDecodeMatrixRegion to decode a specific region of an image. Use dmtxDecodeDestroy to destroy the decoder.

EXAMPLE PROGRAM

The following is a simplified example of how to decode a Data Matrix barcode from an image file.

#include <dmtx.h>
#include <stdio.h>
#include <stdlib.h>

int main(int argc, char *argv[]) {
    dmtxImage *img;
    dmtxDecode *dec;
    dmtxRegion *reg;
    dmtxMessage *msg;
    FILE *fp;

    if(argc != 2) {
        fprintf(stderr, "Usage: %s <image file>\n", argv[0]);
        exit(1);
    }

    fp = fopen(argv[1], "rb");
    if(!fp) {
        perror("fopen");
        exit(1);
    }

    /* Load image from file */
    img = dmtxImageLoad(argv[1], DmtxPack24);
    if(!img) {
        fprintf(stderr, "Could not load image file: %s\n", argv[1]);
        fclose(fp);
        exit(1);
    }
    fclose(fp);

    /* Create decoder */
    dec = dmtxDecodeCreate(img, DmtxRegionPossiblyTiny);
    if(!dec) {
        fprintf(stderr, "Could not create decoder.\n");
        dmtxImageDestroy(&img);
        exit(1);
    }

    /* Find and decode barcode region */
    reg = dmtxScanFindNext(dec, NULL);
    if(reg != NULL) {
        msg = dmtxDecodeMatrixRegion(dec, reg, DmtxUndefined);
        if(msg != NULL) {
            fputs("output: \"", stdout);
            fwrite(msg->output, sizeof(unsigned char), msg->outputIdx, stdout);
            fputs("\"\n", stdout);
            dmtxMessageDestroy(&msg);
        }
        dmtxRegionDestroy(&reg);
    }

    dmtxDecodeDestroy(&dec);
    dmtxImageDestroy(&img);
    exit(0);
}

The dmtxDecodeMatrixRegion function attempts to decode a Data Matrix barcode from the specified region. If successful, it returns a pointer to a dmtxMessage structure containing the decoded data. If no barcode is found or an error occurs, it returns NULL.

The dmtxMessage structure contains the following fields:

  • output: A pointer to the decoded data.
  • outputIdx: The length of the decoded data.

Remember to free the allocated memory for the message and region using dmtxMessageDestroy and dmtxRegionDestroy respectively when you are done with them.
