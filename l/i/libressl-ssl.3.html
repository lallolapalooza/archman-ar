libressl-ssl(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL(3) دليل وظائف المكتبة SSL(3)

الاسم

ssl — مكتبة OpenSSL TLS

الوصف

تنفذ مكتبة ssl بروتوكول Transport Layer Security (TLS)، وهو الخليفة لبروتوكول Secure Sockets Layer (SSL).

يتم إنشاء كائن SSL_CTX كإطار عمل لإنشاء اتصالات مدعومة بـ TLS/SSL (انظر SSL_CTX_new(3)). يمكن تعيين خيارات مختلفة تتعلق بالشهادات والخوارزميات وما إلى ذلك في هذا الكائن.

عند إنشاء اتصال شبكة، يمكن تعيينه لكائن SSL. بعد إنشاء كائن SSL باستخدام SSL_new(3)، يمكن استخدام SSL_set_fd(3) أو SSL_set_bio(3) لربط اتصال الشبكة بالكائن.

ثم يتم تنفيذ مصافحة TLS/SSL باستخدام SSL_accept(3) أو SSL_connect(3) على التوالي. تستخدم SSL_read(3) و SSL_write(3) لقراءة وكتابة البيانات على اتصال TLS/SSL. يمكن استخدام SSL_shutdown(3) لإغلاق اتصال TLS/SSL.

هياكل البيانات

في الوقت الحالي، تتعامل وظائف مكتبة ssl مع هياكل البيانات التالية:

SSL_METHOD (طريقة SSL)
هذا هيكل إرسال يصف طرق/وظائف مكتبة ssl الداخلية التي تنفذ إصدارات البروتوكول المختلفة. يلزم لإنشاء SSL_CTX. انظر TLS_method(3) للمنشئات.
SSL_CIPHER (تشفير SSL)
يحتوي هذا الهيكل على معلومات الخوارزمية لتشفير معين وهو جزء أساسي من بروتوكول SSL/TLS. يتم تكوين التشفيرات المتاحة على أساس SSL_CTX وتصبح التشفيرات المستخدمة فعليًا جزءًا من SSL_SESSION.
SSL_CTX (سياق SSL)
هذا هو هيكل السياق العام الذي يتم إنشاؤه بواسطة خادم أو عميل مرة واحدة طوال عمر البرنامج ويحتوي بشكل أساسي على قيم افتراضية لهياكل SSL التي يتم إنشاؤها لاحقًا للاتصالات.
SSL_SESSION (جلسة SSL)
هذا هيكل يحتوي على تفاصيل جلسة TLS/SSL الحالية لاتصال: تشفيرات SSL_CIPHER، وشهادات العميل والخادم، والمفاتيح، وما إلى ذلك.
SSL (اتصال SSL)
هذا هو هيكل SSL/TLS الرئيسي الذي يتم إنشاؤه بواسطة خادم أو عميل لكل اتصال تم إنشاؤه. هذا هو في الواقع الهيكل الأساسي في واجهة برمجة تطبيقات SSL. في وقت التشغيل، يتعامل التطبيق عادةً مع هذا الهيكل الذي يحتوي على روابط لمعظم الهياكل الأخرى.

ملفات الرأس

في الوقت الحالي، توفر مكتبة ssl ملفات رأس C التالية التي تحتوي على نماذج أولية لهياكل البيانات والوظائف:

ssl.h
هذا هو ملف الرأس المشترك لواجهة برمجة تطبيقات SSL/TLS. قم بتضمينه في برنامجك لجعل واجهة برمجة تطبيقات مكتبة ssl متاحة. يقوم بتضمين رؤوس SSL أكثر خصوصية ورؤوس من مكتبة crypto داخليًا. كلما احتجت إلى تفاصيل معمقة حول الأجزاء الداخلية لواجهة برمجة تطبيقات SSL، انظر داخل ملف الرأس هذا.
ssl3.h
هذا هو ملف الرأس الفرعي الذي يتعامل مع بروتوكول SSLv3 فقط.
عادةً لا تحتاج إلى تضمينه صراحةً لأنه مضمن بالفعل بواسطة ssl.h.
tls1.h
هذا هو ملف الرأس الفرعي الذي يتعامل مع بروتوكول TLSv1 فقط.
عادةً لا تحتاج إلى تضمينه صراحةً لأنه مضمن بالفعل بواسطة ssl.h.

وظائف الواجهة البرمجية

التشفيرات

تصف الصفحات التالية الوظائف التي تعمل على كائنات SSL_CIPHER: SSL_get_ciphers(3)، SSL_get_current_cipher(3)، SSL_CIPHER_get_name(3)

سياقات البروتوكول

تصف الصفحات التالية الوظائف التي تعمل على كائنات SSL_CTX.

المنشئات والمزيلات: SSL_CTX_new(3)، SSL_CTX_set_ssl_version(3)، SSL_CTX_free(3)

تكوين الشهادات: SSL_CTX_add_extra_chain_cert(3)، SSL_CTX_get0_certificate(3)، SSL_CTX_load_verify_locations(3)، SSL_CTX_set_cert_store(3)، SSL_CTX_set_cert_verify_callback(3)، SSL_CTX_set_client_cert_cb(3)، SSL_CTX_set_default_passwd_cb(3)، SSL_CTX_set_tlsext_status_cb(3)

تكوين الجلسات: SSL_CTX_add_session(3)، SSL_CTX_flush_sessions(3)، SSL_CTX_sess_number(3)، SSL_CTX_sess_set_cache_size(3)، SSL_CTX_sess_set_get_cb(3)، SSL_CTX_sessions(3)، SSL_CTX_set_session_cache_mode(3)، SSL_CTX_set_timeout(3)، SSL_CTX_set_tlsext_ticket_key_cb(3)

تكوينات متنوعة: SSL_CTX_get_ex_new_index(3)، SSL_CTX_set_tlsext_servername_callback(3)

التكوين المشترك للسياقات والاتصالات

تأتي الوظائف الموجودة في الصفحات التالية كل منها في شكلين: أحدهما لتكوين اتصال SSL واحد مباشرة، والآخر ليتم استدعاؤه على كائن SSL_CTX، لتعيين افتراضيات لجميع اتصالات SSL المستقبلية التي تم إنشاؤها من هذا السياق.

تكوين البروتوكول والخوارزميات: SSL_CTX_set_alpn_select_cb(3)، SSL_CTX_set_cipher_list(3)، SSL_CTX_set_min_proto_version(3)، SSL_CTX_set_options(3)، SSL_CTX_set_security_level(3)، SSL_CTX_set_tlsext_use_srtp(3)، SSL_CTX_set_tmp_dh_callback(3)، SSL_CTX_set1_groups(3)

تكوين الشهادات: SSL_CTX_add1_chain_cert(3)، SSL_CTX_get_verify_mode(3)، libressl-ssl(3) — LibreSSL 4.2.1

NAME

ssl — API for Transport Layer Security (TLS) and Secure Sockets Layer (SSL)

DESCRIPTION

The libssl library provides an API for implementing Transport Layer Security (TLS) and Secure Sockets Layer (SSL) protocols. This manual page provides a high-level overview of the API functions, categorized by their purpose.

SSL_CTX Configuration

These functions are used to configure an SSL_CTX object, which is used to create SSL objects.

Certificate and key configuration: SSL_CTX_check_private_key(3), SSL_CTX_load_verify_locations(3), SSL_CTX_set_cert_cb(3), SSL_CTX_set_default_passwd_cb(3), SSL_CTX_set_key(3), SSL_CTX_use_certificate_chain_file(3), SSL_CTX_use_file(3), SSL_CTX_use_pkcs12(3)

Verification configuration: SSL_CTX_set_client_CA_list(3), SSL_CTX_set_max_cert_list(3), SSL_CTX_set_verify(3), SSL_CTX_use_certificate(3), SSL_get_client_CA_list(3) SSL_set1_param(3)

Session configuration: SSL_CTX_set_generate_session_id(3), SSL_CTX_set_session_id_context(3)

Various configuration: SSL_CTX_ctrl(3), SSL_CTX_set_info_callback(3), SSL_CTX_set_mode(3), SSL_CTX_set_msg_callback(3), SSL_CTX_set_quiet_shutdown(3), SSL_CTX_set_read_ahead(3), SSL_set_max_send_fragment(3)

Sessions

The following pages describe functions acting on SSL_SESSION objects.

Constructors and destructors: SSL_SESSION_new(3), SSL_SESSION_free(3)

Accessors: SSL_SESSION_get_compress_id(3), SSL_SESSION_get_ex_new_index(3), SSL_SESSION_get_id(3), SSL_SESSION_get_protocol_version(3), SSL_SESSION_get_time(3), SSL_SESSION_get0_peer(3), SSL_SESSION_has_ticket(3), SSL_SESSION_set1_id_context(3)

Encoding and decoding: d2i_SSL_SESSION(3), PEM_read_SSL_SESSION(3), SSL_SESSION_print(3)

Connections

The following pages describe functions acting on SSL connection objects:

Constructors and destructors: SSL_new(3), SSL_dup(3), SSL_free(3), BIO_f_ssl(3)

To change the configuration: SSL_clear(3), SSL_set_SSL_CTX(3), SSL_copy_session_id(3), SSL_set_bio(3), SSL_set_connect_state(3), SSL_set_fd(3), SSL_set_session(3), SSL_set1_host(3), SSL_set_verify_result(3)

To inspect the configuration: SSL_get_certificate(3), SSL_get_default_timeout(3), SSL_get_ex_new_index(3), SSL_get_fd(3), SSL_get_rbio(3), SSL_get_SSL_CTX(3)

To transmit data: DTLSv1_listen(3), SSL_accept(3), SSL_connect(3), SSL_do_handshake(3), SSL_read(3), SSL_read_early_data(3), SSL_renegotiate(3), SSL_shutdown(3), SSL_write(3)

To inspect the state after a connection is established: SSL_export_keying_material(3), SSL_get_client_random(3), SSL_get_ex_data_X509_STORE_CTX_idx(3), SSL_get_peer_cert_chain(3), SSL_get_peer_certificate(3), SSL_get_server_tmp_key(3), SSL_get_servername(3), SSL_get_session(3), SSL_get_shared_ciphers(3), SSL_get_verify_result(3), SSL_get_version(3), SSL_session_reused(3)

To inspect the state during ongoing communication: SSL_get_error(3), SSL_get_shutdown(3), SSL_get_state(3), SSL_num_renegotiations(3), SSL_pending(3), SSL_rstate_string(3), SSL_state_string(3), SSL_want(3)

Utility functions

SSL_alert_type_string(3), SSL_dup_CA_list(3), SSL_load_client_CA_file(3)

Obsolete functions

OPENSSL_init_ssl(3), SSL_COMP_get_compression_methods(3), SSL_CTX_set_tmp_rsa_callback(3), SSL_library_init(3), SSL_set_tmp_ecdh(3)

openssl(1), crypto(3), tls_init(3)
