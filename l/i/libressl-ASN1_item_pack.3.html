libressl-ASN1_item_pack(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

ASN1_ITEM_PACK(3) دليل وظائف المكتبة ASN1_ITEM_PACK(3)

الاسم

ASN1_item_pack، ASN1_item_unpack — تعبئة كائن ASN.1 في ASN1_STRING

الملخص

مكتبة «libcrypto»؛
#include <openssl/asn1.h>

ASN1_STRING *
ASN1_item_pack(void *val_in، const ASN1_ITEM *it، ASN1_STRING **string_out);

void *
ASN1_item_unpack(const ASN1_STRING *string_in، const ASN1_ITEM *it);

الوصف

ASN1_item_pack() تقوم بتشفير الكائن الذي يشير إليه val_in إلى تنسيق DER باستخدام ASN1_item_i2d(3) وتخزين الشكل المشفر في **string_out. إذا كان string_out أو *string_out هو مؤشر NULL، يتم تخصيص كائن ASN1_STRING جديد وإعادته.

ASN1_item_unpack() تقوم بتفسير البيانات في string_in كمصفوفة بايت مشفرة بتنسيق DER- أو BER- وفك تشفير قيمة واحدة من النوع it إلى كائن مخصص حديثًا باستخدام ASN1_item_d2i(3).

قيم الإرجاع

ASN1_item_pack() تعيد الكائن المعدل أو الجديد أو NULL إذا فشل تخصيص الذاكرة أو التشفير.

ASN1_item_unpack() تعيد الكائن الجديد أو NULL إذا فشل تخصيص الذاكرة أو فك التشفير.

انظر أيضًا

ASN1_item_d2i(3)، ASN1_item_new(3)، ASN1_STRING_new(3)

التاريخ

ASN1_item_pack() و ASN1_item_unpack() ظهرتا لأول مرة في OpenSSL 0.9.7 وكانتا متاحتين منذ OpenBSD 3.2.

الأخطاء

انظر قسم الأخطاء في ASN1_item_i2d(3).
