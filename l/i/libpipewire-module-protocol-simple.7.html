الاسم

libpipewire-module-protocol-simple - بروتوكول بسيط

الوصف

يوفر البروتوكول البسيط دفق صوت ثنائي الاتجاه عبر مقبس شبكة.

الغرض منه هو استخدامه مع تطبيق مشغل البروتوكول البسيط، المتاح على Android لتشغيل وتسجيل دفق.

كل عميل يتصل سيقوم بإنشاء دفق التقاط و/أو تشغيل، اعتمادًا على خيارات التكوين.

يمكنك أيضًا استخدامه لتغذية بيانات الصوت إلى عملاء آخرين مثل خادم snapcast.

اسم الوحدة

libpipewire-module-protocol-simple

خيارات الوحدة

  • capture: قيمة منطقية إذا تم تمكين الالتقاط. سيؤدي هذا إلى إنشاء دفق التقاط أو مغسلة لكل عميل متصل.
  • playback: قيمة منطقية إذا تم تمكين التشغيل. سيؤدي هذا إلى إنشاء دفق تشغيل أو مصدر لكل عميل متصل.
  • local.ifname = <str>: اسم الواجهة للاستخدام
  • local.ifaddress = <str>: عنوان الواجهة للاستخدام
  • server.address = []: مصفوفة من عناوين الخادم للاستماع عليها كـ tcp:(<ip>:)<port>.
  • capture.props: خصائص اختيارية لدفق الالتقاط
  • playback.props: خصائص اختيارية لدفق التشغيل

خيارات عامة

خيارات ذات سلوك معروف.

  • remote.name
  • audio.rate
  • audio.format
  • audio.channels
  • audio.position
  • node.latency
  • node.rate
  • stream.capture.sink
  • node.name
  • target.object

بشكل افتراضي، سيعمل الخادم مع عينات ستيريو 16 بت بتردد 44.1 كيلو هرتز.

مثال تكوين

# ~/.config/pipewire/pipewire.conf.d/my-protocol-simple.conf
context.modules = [
{   name = libpipewire-module-protocol-simple
    args = {
        # توفير دفق التقاط، يمكن للعملاء التقاط البيانات من PipeWire
        capture = true
        #
        # توفير دفق تشغيل، يمكن للعميل إرسال البيانات إلى PipeWire للتشغيل
        playback = true
        #
        #audio.rate = 44100
        #audio.format = S16
        #audio.channels = 2
        #audio.position = [ FL FR ]
        #
        # العناوين التي يستمع عليها هذا الخادم للاتصالات الجديدة
        # للعملاء
        server.address = [
            "tcp:4711"
        ]
        capture.props = {
            # اسم العقدة أو معرفها لاستخدامه في الالتقاط.
            #target.object = null
            #
            # لجعل دفق الالتقاط يلتقط منافذ المراقبة
            #stream.capture.sink = false
            #
            # جعله مغسلة بدلاً من دفق التقاط
            #media.class = Audio/Sink
        }
        playback.props = {
            # اسم العقدة أو معرفها لاستخدامه في التشغيل.
            #target.object = null
            #
            # جعله مصدرًا بدلاً من دفق تشغيل
            #media.class = Audio/Source
        }
    }
}
]

مثال تكوين لخادم SNAPCAST

 context.modules = [
 {   name = libpipewire-module-protocol-simple
     args = {
         # توفير مغسلة
         capture = true
         audio.rate = 48000
         audio.format = S16
         audio.channels = 2
         audio.position = [ FL FR ]
         # العناوين التي يستمع عليها هذا الخادم للاتصالات الجديدة
         # للعملاء
         server.address = [
             "tcp:4711"
         ]
         capture.props = {
             # جعله مغسلة بدلاً من دفق التقاط
             media.class = Audio/Sink
         }
     }
 }
 ]
 على خادم snapcast، أضف ما يلي إلى ملف `snapserver.conf`:
\code{.unparsed}
 [stream]
 sampleformat =  48000:16:2
 source = tcp://127.0.0.1:4711?name=PipeWireSnapcast&mode=client

سيحاول Snapcast الاتصال بخادم البروتوكول البسيط والحصول على العينات منه. يحاول Snapcast إعادة الاتصال عندما يتم قطع الاتصال بطريقة ما.
