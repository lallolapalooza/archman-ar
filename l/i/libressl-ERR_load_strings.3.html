libressl-ERR_load_strings(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

ERR_LOAD_STRINGS(3) دليل وظائف المكتبة ERR_LOAD_STRINGS(3)

الاسم

ERR_load_strings، ERR_PACK، ERR_get_next_error_library — تحميل سلاسل أخطاء OpenSSL عشوائية

الملخص

المكتبة «libcrypto»
#include <openssl/err.h>

void
ERR_load_strings(int lib، ERR_STRING_DATA str[]);

unsigned long
ERR_PACK(int lib، int func، int reason);

int
ERR_get_next_error_library(void);

الوصف

ERR_load_strings() تسجل سلاسل الأخطاء لرقم المكتبة lib.

str عبارة عن مصفوفة من بيانات سلاسل الأخطاء:

typedef struct ERR_string_data_st {
        unsigned long error;
        char *string;
} ERR_STRING_DATA;

يتم إنشاء رمز الخطأ من رقم المكتبة ودالة ورمز سبب:

error = ERR_PACK(lib, func, reason)

ERR_PACK() هو ماكرو.

الإدخال الأخير في المصفوفة هو {0، NULL}.

ERR_get_next_error_library() يمكن استخدامه لتعيين أرقام المكتبات للمكتبات المستخدمة في وقت التشغيل.

قيم الإرجاع

ERR_PACK() تعيد رمز الخطأ. ERR_get_next_error_library() تعيد رقم مكتبة جديد.

انظر أيضاً

ERR(3)

التاريخ

ERR_load_strings() و ERR_PACK() ظهرت لأول مرة في SSLeay 0.4.4. ERR_get_next_error_library() ظهرت لأول مرة في SSLeay 0.9.0. هذه الوظائف متاحة منذ OpenBSD 2.4.
