libressl-d2i_DHparams(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

D2I_DHPARAMS(3) دليل وظائف المكتبة D2I_DHPARAMS(3)

الاسم

d2i_DHparams، i2d_DHparams — وظائف PKCS#3 DH parameter

الخلاصة

المكتبة "libcrypto"
#include <openssl/dh.h>

DH *
d2i_DHparams(DH **a، unsigned char **pp، long length);

int
i2d_DHparams(DH *a، unsigned char **pp);

الوصف

تقوم هذه الوظائف بفك ترميز (decode) وترميز (encode) معلمات PKCS#3 DH باستخدام بنية DHparameter الموصوفة في PKCS#3. وتتصرف بطريقة مشابهة لوظيفتي d2i_X509(3) و i2d_X509(3).

قيم الإرجاع

d2i_DHparams() تُرجع كائن DH أو NULL في حالة حدوث خطأ.

i2d_DHparams() تُرجع عدد البايتات التي تم ترميزها بنجاح أو قيمة أقل من أو تساوي 0 في حالة حدوث خطأ.

انظر أيضا

d2i_X509(3)، DH_new(3)

التاريخ

ظهرت وظيفتي d2i_DHparams() و i2d_DHparams() لأول مرة في SSLeay 0.5.1 وكانت متاحة منذ OpenBSD 2.4.
