libressl-EVP_OpenInit(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

EVP_OPENINIT(3) دليل وظائف المكتبة EVP_OPENINIT(3)

الاسم

EVP_OpenInit، EVP_OpenUpdate، EVP_OpenFinal — فك تشفير مظروف EVP

الملخص

المكتبة «libcrypto»
#include <openssl/evp.h>

int
EVP_OpenInit(EVP_CIPHER_CTX *ctx، EVP_CIPHER *type، unsigned char *ek، int ekl، unsigned char *iv، EVP_PKEY *priv);

int
EVP_OpenUpdate(EVP_CIPHER_CTX *ctx، unsigned char *out، int *outl، unsigned char *in، int inl);

int
EVP_OpenFinal(EVP_CIPHER_CTX *ctx، unsigned char *out، int *outl);

الوصف

تعد وظائف مظروف EVP واجهة عالية المستوى لفك تشفير المظروف. تقوم بفك تشفير مفتاح تشفير متماثل مشفر بمفتاح عام ثم فك تشفير البيانات باستخدامه.

EVP_OpenInit() تقوم بتهيئة سياق تشفير ctx لفك التشفير باستخدام نوع التشفير type. تقوم بفك تشفير المفتاح المتماثل المشفر بطول ekl بايت المقدمة في المعامل ek باستخدام المفتاح الخاص priv. يتم توفير متجه التهيئة (IV) في المعامل iv.

EVP_OpenUpdate() و EVP_OpenFinal() لها نفس خصائص وظائف EVP_DecryptUpdate(3) و EVP_DecryptFinal(3) بالضبط.

من الممكن استدعاء EVP_OpenInit() مرتين بنفس الطريقة التي يتم بها استدعاء EVP_DecryptInit(3). يجب أن يتم تعيين priv إلى NULL في الاستدعاء الأول، وبعد تعيين أي معاملات تشفير، يجب استدعاؤه مرة أخرى مع تعيين type إلى NULL.

إذا كان نوع التشفير المقدم في المعامل type هو تشفير متغير الطول، فسيتم تعيين طول المفتاح إلى قيمة طول المفتاح المستعاد. إذا كان التشفير تشفيرًا ثابت الطول، فيجب أن يتطابق طول المفتاح المستعاد مع طول التشفير الثابت.

EVP_OpenUpdate() مُطبقة كمُعامل.

قيم الإرجاع

EVP_OpenInit() تُرجع 0 عند حدوث خطأ أو عددًا صحيحًا غير صفري (في الواقع حجم المفتاح السري المستعاد) عند النجاح.

EVP_OpenUpdate() تُرجع 1 للنجاح أو 0 للفشل.

EVP_OpenFinal() تُرجع 0 إذا فشل فك التشفير أو 1 للنجاح.

انظر أيضًا

evp(3)، EVP_EncryptInit(3)، EVP_SealInit(3)

التاريخ

EVP_OpenInit()، EVP_OpenUpdate()، و EVP_OpenFinal() ظهرت لأول مرة في SSLeay 0.5.1 وكانت متاحة منذ OpenBSD 2.4.
