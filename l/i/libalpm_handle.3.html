الوصف التفصيلي

وظائف لتهيئة وإطلاق libalpm

توثيق تعاريف الأنواع

typedef struct _alpm_handle_t alpm_handle_t

معالج سياق libalpm. يمثل هذا الهيكل نسخة من libalpm.

توثيق الوظائف

alpm_handle_t * alpm_initialize (const char * root, const char * dbpath, alpm_errno_t * err)

يهيئ المكتبة. ينشئ معالجًا، يتصل بقاعدة البيانات وينشئ ملف قفل. يجب استدعاء هذا قبل استدعاء أي وظائف أخرى.

المعلمات

root مسار الجذر لجميع عمليات نظام الملفات
dbpath المسار المطلق لقاعدة بيانات libalpm
err متغير اختياري للاحتفاظ بأي رموز خطأ مرتجعة

يعيد

معالج سياق عند النجاح، NULL عند الخطأ، سيتم تعيين err إذا تم توفيره

int alpm_release (alpm_handle_t * handle)

يطلق المكتبة. يفصل عن قاعدة البيانات، ويزيل المعالج وملف القفل. يجب أن يكون هذا آخر استدعاء لـ alpm تقوم به. بعد إرجاع هذا، يجب اعتبار المعالج غير صالح ولا يمكن استخدامه بأي شكل من الأشكال.

المعلمات

handle المعالج السياقي

يعيد

0 عند النجاح، -1 عند الخطأ
