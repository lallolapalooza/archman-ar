libressl-OCSP_sendreq_new(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

NAME

OCSP_sendreq_new, OCSP_req_add1_nonce, OCSP_sendreq_create, OCSP_sendreq_http, OCSP_sendreq_push, OCSP_sendreq_verify, OCSP_sendreq_free - Send an OCSP request

SYNOPSIS

OCSP_REQ_CTX *OCSP_sendreq_new(BIO *vb, const char *host, const char *path, OCSP_URL *path, BIO *req, OCSP_REQ_CTX * rctx);

int OCSP_req_add1_nonce(OCSP_REQ_CTX *rctx);

int OCSP_sendreq_create(OCSP_REQ_CTX *rctx);

int OCSP_sendreq_http(OCSP_REQ_CTX *rctx);

int OCSP_sendreq_push(OCSP_REQ_CTX *rctx);

int OCSP_sendreq_verify(OCSP_REQ_CTX *rctx);

void OCSP_sendreq_free(OCSP_REQ_CTX *rctx);

DESCRIPTION

These functions implement the sending of OCSP requests.

OCSP_sendreq_new() creates a new OCSP request context.

OCSP_req_add1_nonce() adds a nonce to the request.

OCSP_sendreq_create() creates the OCSP request.

OCSP_sendreq_http() sends the OCSP request over HTTP.

OCSP_sendreq_push() pushes the request.

OCSP_sendreq_verify() verifies the response.

OCSP_sendreq_free() frees the OCSP request context.

If an application wishes to support more advanced features, it should use an alternative, more complete, HTTP library.

Currently only HTTP POST queries to responders are supported.
