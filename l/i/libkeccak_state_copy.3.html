libkeccak_state_copy(3)

الحزمة: libkeccak

التراخيص: custom:ISC

LIBKECCAK_STATE_COPY(3) دليل وظائف المكتبة LIBKECCAK_STATE_COPY(3)

الاسم

libkeccak_state_copy - نسخ حالة التجزئة

الملخص

#include <libkeccak.h>
int libkeccak_state_copy(struct libkeccak_state *dest, const struct libkeccak_state *src);

الربط مع -lkeccak.

الوصف

تقوم الدالة libkeccak_state_copy() بتهيئة *dest لتكون مطابقة لـ *src. يشمل ذلك جميع أعضاء البنية struct libkeccak_state، بما في ذلك حالة الإسفنج ومخزن مؤقت لدفعة الرسالة.

قيم الإرجاع

ترجع الدالة libkeccak_state_copy() القيمة 0 عند اكتمالها بنجاح. عند حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno لوصف الخطأ.

الأخطاء

قد تفشل الدالة libkeccak_state_copy() لأي سبب محدد للدالة malloc(3).

انظر أيضًا

libkeccak_state_duplicate(3)، libkeccak_state_initialise(3)
