Lire__Config__Parser(3pm)

الحزمة: lire

التراخيص: GPL-2.0-only

Parser(3pm) وثائق Lire لتسجيل التقارير Parser(3pm)

الاسم

Lire::Config::Parser - ينشئ كائن Lire::Config::ConfigFile من XML

الملخص

use Lire::Config;
use Lire::Config::Parser;
my $parser = new Lire::Config::Parser( 'spec' => Lire::Config->config_spec());
my $conf = $parser->parsefile( 'config.xml' );

الوصف

محلل XML بسيط إلى حد ما يتبع مواصفات التكوين لتحليل ملف XML.

new( 'spec' => $spec )

ينشئ كائن محلل سيقوم بتحليل ملف التكوين الذي يتحقق مقابل مواصفات Lire::Config::ConfigSpec $spec.

load_config_file( $file )

يقوم بتحليل ملف XML $file ويعيد كائن Lire::Config::ConfigFile الذي يمثله.

انظر أيضًا

Lire::Config::ConfigFile(3pm), Lire::Config::SpecParser(3pm),
Lire::Config::ConfigSpec(3pm)
