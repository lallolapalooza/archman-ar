libressl-SSL_get_current_cipher(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_GET_CURRENT_CIPHER(3) دليل الوظائف المكتبية SSL_GET_CURRENT_CIPHER(3)

الاسم

SSL_get_current_cipher، SSL_get_cipher، SSL_get_cipher_name، SSL_get_cipher_bits، SSL_get_cipher_version — الحصول على SSL_CIPHER للاتصال

الملخص

المكتبة “libssl” libcrypto
#include <openssl/ssl.h>

const SSL_CIPHER *
SSL_get_current_cipher(const SSL *ssl);

const char *
SSL_get_cipher(const SSL *ssl);

const char *
SSL_get_cipher_name(const SSL *ssl);

int
SSL_get_cipher_bits(const SSL *ssl, int *np);

char *
SSL_get_cipher_version(const SSL *ssl);

الوصف

SSL_get_current_cipher() تعيد مؤشرًا إلى كائن SSL_CIPHER يحتوي على وصف للخوارزمية المشفرة المستخدمة فعليًا لاتصال تم إنشاؤه باستخدام الكائن ssl. انظر SSL_CIPHER_get_name(3) لمزيد من التفاصيل.

SSL_get_cipher_name() تحصل على اسم الخوارزمية المشفرة المستخدمة حاليًا. SSL_get_cipher() مماثل لـ SSL_get_cipher_name().

SSL_get_cipher_bits() تحصل على عدد البتات السرية/الخوارزمية المستخدمة و SSL_get_cipher_version() تعيد اسم البروتوكول.

SSL_get_cipher()، SSL_get_cipher_name()، SSL_get_cipher_bits()، و SSL_get_cipher_version() منفذة كـ وحدات ماكرو.

قيم الإرجاع

SSL_get_current_cipher() تعيد الخوارزمية المشفرة المستخدمة فعليًا، أو NULL إذا لم يتم إنشاء جلسة.

انظر أيضًا

ssl(3)، SSL_CIPHER_get_name(3)

التاريخ

SSL_get_cipher() ظهرت في SSLeay 0.4 أو أقدم. SSL_get_cipher_bits() ظهرت لأول مرة في SSLeay 0.6.4. SSL_get_cipher_name() و SSL_get_cipher_version() ظهرتا لأول مرة في SSLeay 0.8.0. SSL_get_current_cipher() ظهرت لأول مرة في SSLeay 0.8.1. هذه الوظائف متاحة منذ OpenBSD 2.4.
