libkeccak_behex_upper(3)

الحزمة: libkeccak

التراخيص: custom:ISC

LIBKECCAK_BEHEX_UPPER(3) دليل وظائف المكتبة LIBKECCAK_BEHEX_UPPER(3)

الاسم

libkeccak_behex_upper - يحول ملخص ثنائي إلى سداسي عشري بأحرف كبيرة

الملخص

#include <libkeccak.h>
void libkeccak_behex_upper(char *restrict output, const void *restrict hashsum, size_t n);

الربط مع -lkeccak.

الوصف

تقوم الوظيفة libkeccak_behex_upper() بتحويل ملخص ثنائي، مخزن في hashsum، إلى سداسي عشري بأحرف كبيرة، وتخزن التمثيل السداسي العشري في output.

سيتم إنهاء output بحرف NUL.

تحدد المعلمة n عدد البايتات التي يتكون منها الملخص الثنائي. يحتاج output إلى حجم تخصيص (2 * n + 1).

قيم الإرجاع

الوظيفة libkeccak_behex_upper() لا ترجع أي قيمة.

الأخطاء

لا يمكن أن تفشل الوظيفة libkeccak_behex_upper().

انظر أيضا

libkeccak_behex_lower(3), libkeccak_unhex(3)
