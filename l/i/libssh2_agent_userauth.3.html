libssh2_agent_userauth(3)

الحزمة: libssh2

التراخيص: BSD

libssh2_agent_userauth(3) libssh2 libssh2_agent_userauth(3)

الاسم

libssh2_agent_userauth - المصادقة على جلسة باستخدام مفتاح عام، بمساعدة ssh-agent

الملخص

#include <libssh2.h>
int
libssh2_agent_userauth(LIBSSH2_AGENT *agent,
                       const char *username,
                       struct libssh2_agent_publickey *identity);

الوصف

agent - مقبض ssh-agent كما تم إرجاعه بواسطة libssh2_agent_init(3)

username - اسم المستخدم البعيد للمصادقة به.

identity - المفتاح العام للمصادقة به، كما تم إرجاعه بواسطة libssh2_agent_get_identity(3)

محاولة المصادقة بمفتاح عام بمساعدة ssh-agent.

قيمة الإرجاع

إرجاع 0 في حالة النجاح، أو قيمة سالبة في حالة حدوث خطأ.

التوفر

تمت الإضافة في libssh2 1.2
