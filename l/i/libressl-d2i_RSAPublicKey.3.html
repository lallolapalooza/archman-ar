الوصف

تقوم هذه الوظائف بفك ترميز وتشفير مفاتيح RSA الخاصة والعامة. للتفاصيل حول الدلالات والأمثلة والتحذيرات والأخطاء، راجع ASN1_item_d2i(3).

d2i_RSAPublicKey() و i2d_RSAPublicKey() تقومان بفك ترميز وتشفير بنية RSAPublicKey الخاصة بـ PKCS#1 المعرفة في الملحق A.1.1 من RFC 8017. d2i_RSAPublicKey_bio()، d2i_RSAPublicKey_fp()، i2d_RSAPublicKey_bio()، و i2d_RSAPublicKey_fp() مشابهة باستثناء أنها تقوم بفك الترميز أو التشفير باستخدام مؤشر BIO أو FILE.

d2i_RSAPrivateKey() و i2d_RSAPrivateKey() تقومان بفك ترميز وتشفير بنية RSAPrivateKey الخاصة بـ PKCS#1 المعرفة في الملحق A.1.2 من RFC 8017. يجب أن تحتوي البنية RSA الممررة إلى وظائف تشفير المفاتيح الخاصة على جميع مكونات المفتاح الخاص PKCS#1. البيانات التي يتم تشفيرها بواسطة وظائف المفتاح الخاص غير مشفرة وبالتالي لا توفر أمانًا للمفتاح الخاص. d2i_RSAPrivateKey_bio()، d2i_RSAPrivateKey_fp()، i2d_RSAPrivateKey_bio()، و i2d_RSAPrivateKey_fp() مشابهة باستثناء أنها تقوم بفك الترميز أو التشفير باستخدام مؤشر BIO أو FILE.

d2i_Netscape_RSA() و i2d_Netscape_RSA() تقومان بفك ترميز وتشفير مفتاح RSA الخاص بتنسيق NET. هذه الوظائف موجودة لتوفير التوافق مع بعض البرامج القديمة جدًا. يحتوي تنسيق NET على بعض نقاط الضعف الأمنية الخطيرة ويجب تجنبه قدر الإمكان.

d2i_RSA_PSS_PARAMS() و i2d_RSA_PSS_PARAMS() تقومان بفك ترميز وتشفير بنية RSASSA-PSS-params الخاصة بـ PKCS#1 المعرفة في الملحق A.2.3 من RFC 8017 والموثقة في RSA_PSS_PARAMS_new(3).

d2i_RSA_PUBKEY() و i2d_RSA_PUBKEY() تقومان بفك ترميز وتشفير مفتاح RSA العام u

NAME

d2i_RSAPublicKey, d2i_RSAPublicKey_bio, d2i_RSAPublicKey_fp, d2i_RSA_PUBKEY, d2i_RSA_PUBKEY_bio, d2i_RSA_PUBKEY_fp, i2d_RSAPublicKey, i2d_RSAPublicKey_bio, i2d_RSAPublicKey_fp, i2d_RSA_PUBKEY, i2d_RSA_PUBKEY_bio, i2d_RSA_PUBKEY_fp - RSA public key (and SubjectPublicKeyInfo) decoding and encoding

SYNOPSIS

#include <openssl/rsa.h>

RSA *d2i_RSAPublicKey_bio(BIO *bp, RSA **rp);

RSA *d2i_RSA_PUBKEY(RSA **rp, const unsigned char **in, long len);
RSA *d2i_RSA_PUBKEY_bio(BIO *bp, RSA **rp);
RSA *d2i_RSA_PUBKEY_fp(FILE *fp, RSA **rp);

int i2d_RSAPublicKey(const RSA *r, unsigned char **out);
int i2d_RSAPublicKey_bio(BIO *bp, const RSA *r);
int i2d_RSAPublicKey_fp(FILE *fp, const RSA *r);

int i2d_RSA_PUBKEY(const RSA *r, unsigned char **out);
int i2d_RSA_PUBKEY_bio(BIO *bp, const RSA *r);
int i2d_RSA_PUBKEY_fp(FILE *fp, const RSA *r);

DESCRIPTION

The RSA public key encoding routines encode the RSA public key contained in the structure pointed to by r into DER format. The result is written to the memory location pointed to by out. If out is NULL, then space is allocated for the output. The caller is responsible for freeing this memory.

The RSA public key decoding routines decode an RSA public key from DER format. If rp is not NULL, the decoded RSA structure is stored in *rp. If rp is NULL, then a new RSA structure is allocated.

The encoded public key can be in one of two formats:

  • An RSA public key, encoded as specified in PKCS#1, RFC 8017.
  • A SubjectPublicKeyInfo structure defined in RFC 5280 section 4.1 and documented in X509_PUBKEY_new(3).

The functions d2i_RSAPublicKey(), d2i_RSA_PUBKEY(), i2d_RSAPublicKey(), and i2d_RSA_PUBKEY() operate on memory buffers.

d2i_RSAPublicKey_bio(), d2i_RSA_PUBKEY_bio(), i2d_RSAPublicKey_bio(), and i2d_RSA_PUBKEY_bio() operate on a BIO object.

d2i_RSAPublicKey_fp(), d2i_RSA_PUBKEY_fp(), i2d_RSAPublicKey_fp(), and i2d_RSA_PUBKEY_fp() operate on a FILE pointer.

d2i_RSA_PUBKEY(), d2i_RSA_PUBKEY_bio(), and d2i_RSA_PUBKEY_fp() are more general than d2i_RSAPublicKey(), etc. They decode the SubjectPublicKeyInfo structure defined in RFC 5280 section 4.1 and documented in X509_PUBKEY_new(3). d2i_RSA_PUBKEY(), d2i_RSA_PUBKEY_bio(), d2i_RSA_PUBKEY_fp(), i2d_RSA_PUBKEY(), i2d_RSA_PUBKEY_bio(), and i2d_RSA_PUBKEY_fp() are similar except that they decode or encode using a BIO or FILE pointer.

RETURN VALUES

d2i_RSAPublicKey(), d2i_RSAPublicKey_bio(), d2i_RSAPublicKey_fp(), d2i_RSAPrivateKey(), d2i_RSAPrivateKey_bio(), d2i_RSAPrivateKey_fp(), d2i_Netscape_RSA(), d2i_RSA_PUBKEY(), d2i_RSA_PUBKEY_bio(), and d2i_RSA_PUBKEY_fp() return a valid RSA object or NULL if an error occurs.

d2i_RSA_PSS_PARAMS() returns a valid RSA_PSS_PARAMS object or NULL if an error occurs.

i2d_RSAPublicKey(), i2d_RSAPrivateKey(), i2d_Netscape_RSA(), i2d_RSA_PSS_PARAMS(), and i2d_RSA_PUBKEY() return the number of bytes successfully encoded or a negative value if an error occurs.

i2d_RSAPublicKey_bio(), i2d_RSAPublicKey_fp(), i2d_RSAPrivateKey_bio(), i2d_RSAPrivateKey_fp(), i2d_RSA_PUBKEY_bio(), and i2d_RSA_PUBKEY_fp() return 1 for success or 0 if an error occurs.
