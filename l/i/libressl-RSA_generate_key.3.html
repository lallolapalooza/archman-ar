libressl-RSA_generate_key(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

RSA_GENERATE_KEY(3) دليل وظائف المكتبة RSA_GENERATE_KEY(3)

الاسم

RSA_generate_key_ex, RSA_generate_key — إنشاء زوج مفاتيح RSA

الملخص

المكتبة «libcrypto»
#include <openssl/rsa.h>

int
RSA_generate_key_ex(RSA *rsa, int bits, BIGNUM *e, BN_GENCB *cb);

مهمل:


RSA *
RSA_generate_key(int num, unsigned long e, void (*callback)(int, int, void *), void *cb_arg);

الوصف

RSA_generate_key_ex() تقوم بإنشاء زوج مفاتيح وتخزينه في rsa.

سيكون حجم المعامل هو bits، وسيكون الأس العام هو e. يجب اعتبار أحجام المفاتيح التي يكون فيها num < 1024 غير آمنة. الأس هو عدد فردي، عادةً 3 أو 17 أو 65537.

يمكن استخدام دالة رد اتصال لتوفير ملاحظات حول تقدم عملية إنشاء المفتاح. إذا لم يكن cb NULL، فسيتم استدعاؤها باستخدام دالة BN_GENCB_call(3):

  • أثناء إنشاء عدد أولي عشوائي، يتم استدعاؤها كما هو موضح في BN_generate_prime(3).
  • عندما يتم رفض العدد الأولي العشوائي n لأنه غير مناسب للمفتاح، يتم استدعاء BN_GENCB_call(cb, 2, n).
  • عندما يتم العثور على عدد أولي عشوائي p حيث p-1 أولي نسبيًا مع e، يتم استدعاؤها كـ BN_GENCB_call(cb, 3, 0).

تتكرر العملية بعد ذلك للعدد الأولي q مع BN_GENCB_call(cb, 3, 1).

RSA_generate_key() مهملة. يجب على التطبيقات الجديدة استخدام RSA_generate_key_ex() بدلاً من ذلك. تعمل RSA_generate_key() بنفس طريقة RSA_generate_key_ex() باستثناء أنها تستخدم ردود اتصال «النمط القديم». انظر BN_generate_prime(3) لمزيد من التفاصيل.

قيم الإرجاع

RSA_generate_key_ex() ترجع 1 عند النجاح أو 0 عند الخطأ. RSA_generate_key() ترجع المفتاح عند النجاح أو NULL عند الخطأ.

يمكن الحصول على رموز الأخطاء عن طريق ERR_get_error(3).

انظر أيضًا

BN_generate_prime(3), RSA_get0_key(3), RSA_meth_set_keygen(3), RSA_new(3)

التاريخ

ظهرت RSA_generate_key() في SSLeay 0.4 أو أقدم وتمت إضافة وسيطة cb_arg إليها في SSLeay 0.9.0. كانت متاحة منذ OpenBSD 2.4.

ظهرت RSA_generate_key_ex() لأول مرة في OpenSSL 0.9.8 وكانت متاحة منذ OpenBSD 4.5.

أخطاء

BN_GENCB_call(cb, 2, x) تستخدم بمعنيين مختلفين.

تدخل RSA_generate_key() في حلقة لا نهائية لقيم الإدخال غير الصالحة.
