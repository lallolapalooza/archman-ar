libressl-SSL_get_state(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_GET_STATE(3) دليل الوظائف المكتبية SSL_GET_STATE(3)

الاسم

SSL_get_state، SSL_state، SSL_in_accept_init، SSL_in_before، SSL_in_connect_init، SSL_in_init، SSL_is_init_finished — تفحص حالة آلة حالات SSL

الملخص

مكتبة “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_get_state(const SSL *ssl);

int
SSL_state(const SSL *ssl);

int
SSL_in_accept_init(const SSL *ssl);

int
SSL_in_before(const SSL *ssl);

int
SSL_in_connect_init(const SSL *ssl);

int
SSL_in_init(const SSL *ssl);

int
SSL_is_init_finished(const SSL *ssl);

الوصف

SSL_get_state() تُرجع تمثيلاً مشفراً للحالة الحالية لآلة حالات SSL. SSL_state() هو اسم مستعار مهمل لـ SSL_get_state().

قد يتم تعيين البتات التالية:

SSL_ST_ACCEPT
يتم تعيين هذا البت بواسطة SSL_accept(3) و بواسطة SSL_set_accept_state(3). يشير إلى أن ssl مُهيأ لوضع الخادم ولم يبدأ العميل بعد مصافحة TLS. تُرجع الوظيفة SSL_in_accept_init() قيمة غير صفرية إذا تم تعيين هذا البت أو 0 بخلاف ذلك.
SSL_ST_BEFORE
يتم تعيين هذا البت بواسطة وظائف SSL_accept(3)، SSL_connect(3)، SSL_set_accept_state(3)، و SSL_set_connect_state(3). يشير إلى أن مصافحة TLS لم تبدأ بعد. تُرجع الوظيفة SSL_in_before() قيمة غير صفرية إذا تم تعيين هذا البت أو 0 بخلاف ذلك.
SSL_ST_CONNECT
يتم تعيين هذا البت بواسطة SSL_connect(3) و بواسطة SSL_set_connect_state(3). يشير إلى أن ssl مُهيأ لوضع العميل ولم تبدأ مصافحة TLS بعد. تُرجع الوظيفة SSL_in_connect_init() قيمة غير صفرية إذا تم تعيين هذا البت أو 0 بخلاف ذلك.

يمكن استخدام الأقنعة التالية:

SSL_ST_INIT
تم التعيين إذا تم تعيين SSL_ST_ACCEPT أو SSL_ST_CONNECT. تُرجع الوظيفة SSL_in_init() قيمة غير صفرية إذا تم تعيين أحد هذه أو 0 بخلاف ذلك.
SSL_ST_MASK
يشمل هذا القناع جميع البتات باستثناء SSL_ST_ACCEPT، SSL_ST_BEFORE، و SSL_ST_CONNECT.
SSL_ST_OK
تم تعيين الحالة إلى هذه القيمة عند إنشاء الاتصال. تُرجع الوظيفة SSL_is_init_finished() قيمة غير صفرية إذا كانت الحالة تساوي هذا الثابت، أو 0 بخلاف ذلك.
SSL_ST_RENEGOTIATE
البرنامج على وشك إعادة التفاوض، على سبيل المثال عند الدخول إلى SSL_read(3) أو SSL_write(3) مباشرة بعد استدعاء SSL_renegotiate(3).

معنى البتات الأخرى يعتمد على البروتوكول. عادةً لا تحتاج تطبيقات البرامج إلى فحص أي من هذه البتات الأخرى.

قد يتم تنفيذ جميع هذه الوظائف كـ macros.

انظر أيضا

ssl(3)، SSL_renegotiate(3)، SSL_set_connect_state(3)

التاريخ

SSL_is_init_finished() ظهرت لأول مرة في SSLeay 0.4.5b. SSL_state() ظهرت لأول مرة في SSLeay 0.5.2. SSL_in_accept_init()، SSL_in_connect_init()، و SSL_in_init() ظهرت لأول مرة في SSLeay 0.6.0. SSL_in_before() ظهرت لأول مرة في SSLeay 0.8.0. SSL_get_state() ظهرت لأول مرة في SSLeay 0.9.0. جميع هذه الوظائف متاحة منذ OpenBSD 2.4.
