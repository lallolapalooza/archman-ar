libressl-EC_KEY_METHOD_new(3)

DESCRIPTION

The EC key methods provide a way to implement the elliptic curve cryptographic operations using different algorithms or libraries. The main EC key method structure is EC_KEY_METHOD. This structure is intended to be used by applications to provide their own implementations of the EC operations.

The EC_KEY_METHOD_new() function allocates and initializes a new EC_KEY_METHOD structure. If meth is not NULL, then the new structure is initialized as a copy of the provided structure. Otherwise, a default structure is used. The function EC_KEY_METHOD_free() frees the memory associated with the EC_KEY_METHOD structure.

The functions EC_KEY_METHOD_set_ecc_key_meth() and EC_KEY_METHOD_get_ecc_key_meth() set and retrieve the underlying EC key method that will be used for the actual cryptographic operations. This is useful for creating composite methods, for example, one method that does some preprocessing and then calls another method.

The functions EC_KEY_METHOD_set_sign() and EC_KEY_METHOD_get_sign() set and retrieve the functions implementing ECDSA_sign(3) and ECDSA_do_sign(3). The sign_setup function pointer is optional and can be NULL.

The functions EC_KEY_METHOD_set_verify() and EC_KEY_METHOD_get_verify() set and retrieve the functions implementing ECDSA_verify(3) and ECDSA_do_verify(3). The verify_setup function pointer is optional and can be NULL.

The functions EC_KEY_METHOD_set_keygen() and EC_KEY_METHOD_get_keygen() set and retrieve the function implementing EC_KEY_generate_key(3).

The functions EC_KEY_METHOD_set_compute_key() and EC_KEY_METHOD_get_compute_key() set and retrieve the function implementing ECDH_compute_key(3).

The function EC_KEY_set_default_method() chooses the method meth to be used for the creation of new EC_KEY objects by future invocations of EC_KEY_new_method(), or reverts to the default implementation if meth is NULL.

The function EC_KEY_get_default_method() returns the method that EC_KEY_new_method() will use for the creation of new EC_KEY objects in the future.

The function EC_KEY_new_method() creates and initializes a new EC_KEY object using the EC_KEY_METHOD set with EC_KEY_set_default_method(). The ENGINE *engine argument is always ignored and passing NULL is recommended.

The function EC_KEY_set_method() dissociates the key from the ENGINE it is using, if any, and causes it to use meth in the future.

The function EC_KEY_get_method() returns the EC_KEY_METHOD currently used by the given key.

RETURN VALUES

EC_KEY_METHOD_new() returns the newly allocated EC_KEY_METHOD object or NULL if an error occurs.

EC_KEY_METHOD_inits() returns the initialized EC_KEY_METHOD object or NULL if an error occurs.

EC_KEY_METHOD_set_ecc_key_meth() and EC_KEY_METHOD_set_sign(), EC_KEY_METHOD_set_verify(), EC_KEY_METHOD_set_keygen(), EC_KEY_METHOD_set_compute_key() return 1 on success or 0 on failure.

EC_KEY_METHOD_get_ecc_key_meth() returns the associated EC key method. EC_KEY_METHOD_get_sign() returns the sign and sign setup functions. EC_KEY_METHOD_get_verify() returns the verify and verify setup functions. EC_KEY_METHOD_get_keygen() returns the key gen function. EC_KEY_METHOD_get_compute_key() returns the compute key function.

EC_KEY_set_default_method() returns 1 on success or 0 on failure.

EC_KEY_get_default_method() returns the default method.

EC_KEY_new_method() returns the newly allocated EC_KEY object or NULL if an error occurs.

EC_KEY_set_method() returns 1 on success or 0 on failure.

EC_KEY_get_method() returns the method used by the key.
