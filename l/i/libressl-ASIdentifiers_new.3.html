الحزمة: libressl

ASIDENTIFIERS_NEW(3) دليل وظائف المكتبة ASIDENTIFIERS_NEW(3)

الاسم

ASIdentifiers_new، ASIdentifiers_free، d2i_ASIdentifiers، i2d_ASIdentifiers — امتدادات تفويض معرفات النظام المستقل (AS) RFC 3779

الملخص

المكتبة «libcrypto»
#include <openssl/x509v3.h>

ASIdentifiers *
ASIdentifiers_new(void);

void
ASIdentifiers_free(ASIdentifiers *asid);

ASIdentifiers *
d2i_ASIdentifiers(ASIdentifiers **asid, const unsigned char **in, long len);

int
i2d_ASIdentifiers(ASIdentifiers *asid, unsigned char **out);

الوصف

تحدد RFC 3779 امتدادين لشهادة X.509v3 يسمحان بتفويض عناوين IP ومعرفات النظام المستقل (AS) من المُصدر إلى موضوع الشهادة. يحتوي كائن ASIdentifiers على مجموعات من أرقام AS الفردية ونطاقات أرقام AS المطلوب تفويضها.

ASIdentifiers_new() تخصص وتهيئ كائن ASIdentifiers جديدًا وفارغًا يمكن ملؤه باستخدام X509v3_asid_add_id_or_range(3). راجع ASRange_new(3) للحصول على تفاصيل التنفيذ.

ASIdentifiers_free() تُحرر asid بما في ذلك أي بيانات تحتوي عليها. إذا كان asidNULL، فلن يتم اتخاذ أي إجراء.

d2i_ASIdentifiers() و i2d_ASIdentifiers() تقوم بفك ترميز وترميز كائنات ASN.1 ASIdentifiers كما هو محدد في RFC 3779، القسم 3.2.3.1. للحصول على تفاصيل حول الدلالات والأمثلة والمحاذير والأخطاء، انظر ASN1_item_d2i(3). لكي يتوافق الترميز الناتج عن i2d_ASIdentifiers() مع RFC 3779، يجب أن يكون asidX509v3_asid_canonize(3).

قيم الإرجاع

ASIdentifiers_new() تُرجع كائن ASIdentifiers جديدًا أو NULL إذا حدث خطأ.

d2i_ASIdentifiers() تُرجع كائن ASIdentifiers أو NULL إذا حدث خطأ في فك الترميز أو تخصيص الذاكرة.

i2d_ASIdentifiers() تُرجع عدد البايتات التي تم ترميزها بنجاح أو قيمة <= 0 إذا حدث خطأ.

التاريخ

ظهرت هذه الوظائف لأول مرة في OpenSSL 0.9.8e وكانت متاحة منذ OpenBSD 7.1.

الأخطاء

لا توجد وظائف مقابلة لامتداد تفويض عنوان IP الخاص بـ RFC 3779 الممثل بـ IPAddrBlocks.
