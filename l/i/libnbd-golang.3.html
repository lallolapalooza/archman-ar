اسم

libnbd-golang - كيفية استخدام libnbd من Go

ملخص

import "libguestfs.org/libnbd"
h, err := libnbd.Create()
if err != nil {
    panic(err)
}
defer h.Close()
uri := "nbd://localhost"
err = h.ConnectUri(uri)
if err != nil {
    panic(err)
}
size, err := h.GetSize()
if err != nil {
    panic(err)
}
fmt.Printf("size of %s = %d\n", uri, size)

الوصف

توثق صفحة الدليل هذه كيفية استخدام libnbd للوصول إلى خوادم NBD (Network Block Device) من لغة البرمجة Go. تعمل روابط Go بشكل مشابه جدًا للروابط C، لذا يجب أن تبدأ بقراءة libnbd(3).

المقابض

أنشئ مقبض libnbd من النوع "Libnbd" عن طريق استدعاء Create().

يمكنك إما إغلاق المقبض بشكل صريح عن طريق استدعاء مؤجل لـ "h.Close()" أو سيتم إغلاقه تلقائيًا عند جمعه بواسطة جامع القمامة.

الأخطاء

تقوم معظم الاستدعاءات بإرجاع إما "LibnbdError" واحد أو زوج "(ret, LibnbdError)".

أمثلة

يحتوي هذا الدليل على أمثلة مكتوبة بلغة Go:

https://gitlab.com/nbdkit/libnbd/tree/master/golang/examples
