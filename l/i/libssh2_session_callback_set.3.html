libssh2_session_callback_set(3)

الحزمة: libssh2

التراخيص: BSD

libssh2_session_callback_set(3) libssh2 libssh2_session_callback_set(3)

الاسم

libssh2_session_callback_set - تعيين دالة رد اتصال

الملخص

#include <libssh2.h>
void *
libssh2_session_callback_set(LIBSSH2_SESSION *session,
                             int cbtype, void *callback);

الوصف

هذا التنفيذ **مهمل** في 1.11.1. استخدم الدالة libssh2_session_callback_set2(3) بدلاً من ذلك!

هذا التنفيذ يتوقع ويعيد مؤشر بيانات لدوال رد الاتصال.

للتفاصيل حول الدالة البديلة، انظر libssh2_session_callback_set2(3) التي تتوقع وتعيد مؤشر دالة.

قيمة الإرجاع

مؤشر إلى معالج رد اتصال سابق. يعيد NULL إذا لم يتم تعيين معالج رد اتصال سابق أو كان نوع رد الاتصال غير معروف.
