libressl-SSL_CTX_get_verify_mode(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_CTX_GET_VERIFY_MODE(3) دليل المكتبة SSL_CTX_GET_VERIFY_MODE(3)

الاسم

SSL_CTX_get_verify_mode، SSL_get_verify_mode، SSL_CTX_get_verify_depth، SSL_get_verify_depth، SSL_get_verify_callback، SSL_CTX_get_verify_callback — الحصول على معلمات التحقق المعينة حاليًا

الشكل العام

المكتبة “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_CTX_get_verify_mode(const SSL_CTX *ctx);

int
SSL_get_verify_mode(const SSL *ssl);

int
SSL_CTX_get_verify_depth(const SSL_CTX *ctx);

int
SSL_get_verify_depth(const SSL *ssl);

int
(*SSL_CTX_get_verify_callback(const SSL_CTX *ctx))(int, X509_STORE_CTX *);

int
(*SSL_get_verify_callback(const SSL *ssl))(int, X509_STORE_CTX *);

الوصف

SSL_CTX_get_verify_mode() ترجع وضع التحقق المعين حاليًا في ctx.

SSL_get_verify_mode() ترجع وضع التحقق المعين حاليًا في ssl.

SSL_CTX_get_verify_depth() ترجع حد عمق التحقق المعين حاليًا في ctx. إذا لم يتم تعيين حد صراحةً، فسيتم إرجاع −1 وسيتم استخدام القيمة الافتراضية.

SSL_get_verify_depth() ترجع حد عمق التحقق المعين حاليًا في ssl. إذا لم يتم تعيين حد صراحةً، فسيتم إرجاع −1 وسيتم استخدام القيمة الافتراضية.

SSL_CTX_get_verify_callback() ترجع مؤشر دالة إلى دالة الاستدعاء للتحقق المعينة حاليًا في ctx. إذا لم يتم تعيين دالة استدعاء صراحةً، فسيتم إرجاع مؤشر NULL وسيتم استخدام دالة الاستدعاء الافتراضية.

SSL_get_verify_callback() ترجع مؤشر دالة إلى دالة الاستدعاء للتحقق المعينة حاليًا في ssl. إذا لم يتم تعيين دالة استدعاء صراحةً، فسيتم إرجاع مؤشر NULL وسيتم استخدام دالة الاستدعاء الافتراضية.

التاريخ

SSL_CTX_get_verify_mode()، SSL_get_verify_mode()، SSL_get_verify_callback()، و SSL_CTX_get_verify_callback() ظهرت لأول مرة في SSLeay 0.8.0 وكانت متاحة منذ OpenBSD 2.4.

SSL_CTX_get_verify_depth() و SSL_get_verify_depth() ظهرت لأول مرة في OpenSSL 0.9.3 وكانت متاحة منذ OpenBSD 2.6.
