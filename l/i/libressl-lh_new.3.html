NAME

lh_new - create a new hash lookup table

SYNOPSIS

#include <openssl/lh.h>

LHASH_OF(type) *lh_new(unsigned long init_size, unsigned long init_max);

LHASH_OF(type) *lh_insert(LHASH_OF(type) *table, const void *data);

void *lh_retrieve(LHASH_OF(type) *table, const void *data);

void *lh_delete(LHASH_OF(type) *table, const void *data);

void lh_free(LHASH_OF(type) *table);

unsigned long lh_num(const LHASH_OF(type) *table);

DESCRIPTION

The lh_new function creates a new hash lookup table. The init_size parameter specifies the initial number of buckets in the table, and init_max specifies the maximum number of entries before the table is resized.

The lh_insert function inserts an element into the hash table. The data parameter is a pointer to the element to be inserted. The element must have a hash function and an equality function associated with it.

The lh_retrieve function retrieves an element from the hash table. The data parameter is a pointer to the element to be searched for. The function returns a pointer to the element if found, or NULL otherwise.

The lh_delete function deletes an element from the hash table. The data parameter is a pointer to the element to be deleted. The function returns a pointer to the deleted element if found, or NULL otherwise.

The lh_free function frees the hash table and all its elements.

The lh_num function returns the number of elements in the hash table.

RETURN VALUES

lh_new returns a pointer to the newly created hash table, or NULL on failure.

lh_insert returns a pointer to the inserted element, or NULL on failure.

lh_retrieve returns a pointer to the retrieved element, or NULL if not found.

lh_delete returns a pointer to the deleted element, or NULL if not found.

lh_num returns the number of elements in the hash table.

NOTES

The elements stored in the hash table are not copied. The caller is responsible for managing the memory of the elements.

INTERNALS

The hash table implementation uses open addressing with linear probing. The hash function and equality function for the elements are determined by the type of the elements stored in the table.

SEE ALSO

lh_insert(3), lh_retrieve(3), lh_delete(3), lh_free(3), lh_num(3)

HISTORY

The lh_* functions were first introduced in OpenSSL 0.9.1.

BUGS

None reported.
