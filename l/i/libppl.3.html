التراخيص: GPL-3.0-or-later

الاسم

libppl - واجهة C++ لمكتبة بارما متعددة السطوح

ملخص

#include <ppl.hh>

c++ file.cc -lppl

الوصف

هذا هو ملخص قصير حول كيفية استخدام مكتبة بارما متعددة السطوح (PPL) في برامج C++ الخاصة بك على أنظمة التشغيل الشبيهة بـ Unix. لاحظ أن PPL لديها واجهات أيضًا لـ C و Java و OCaml وعدد من أنظمة Prolog: ابحث في مكان آخر عن وثائق حول هذه الواجهات. لاحظ أيضًا أن هذه الوثيقة لا تصف وظائف المكتبة أو فئاتها أو طرقها ووظائفها: راجع دليل مستخدم مكتبة بارما متعددة السطوح (الإصدار 1.2) للحصول على هذا النوع من المعلومات.

تضمين ملف الرأس

واجهة C++ الخاصة بـ PPL لديها ملف رأس واحد فقط، يسمى ppl.hh. لذلك يجب أن يحتوي برنامجك على توجيه بالشكل

#include <ppl.hh>

بالطبع، يجب عليك التأكد من أنك قمت بتثبيت PPL في مكان يمكن للمترجم العثور عليه، إما بنفسه أو بمساعدة خيار سطر الأوامر المناسب -Idir (راجع الملف INSTALL للحصول على معلومات حول كيفية تكوين المكتبة بحيث يتم تثبيتها في المكان الذي تختاره).

تهيئة وإنهاء المكتبة

مجرد تضمين ppl.hh في ملف واحد على الأقل من مشروعك سيؤدي إلى التهيئة والإنهاء التلقائي للمكتبة. ومع ذلك، هناك مواقف قد تكون فيها التهيئة والإنهاء التلقائي غير مرغوب فيهما (على سبيل المثال، إذا كان التطبيق يتعامل مع وظائف تخصيص الذاكرة لـ GMP). في تلك الحالات، يجب أن يكون كل تضمين لـ ppl.hh بالشكل

#define PPL_NO_AUTOMATIC_INITIALIZATION
#include <ppl.hh>

عند تعطيل التهيئة والإنهاء التلقائي، يجب عليك بالتأكيد استدعاء الدالة

void Parma_Polyhedra_Library::initialize()

قبل استخدام المكتبة. من الجيد أيضًا استدعاء الدالة

void Parma_Polyhedra_Library::finalize()

عند الانتهاء من استخدام المكتبة.

استخدام المكتبة

مع الأخذ في الاعتبار أنه لا غنى عن القراءة المتأنية لـ دليل مستخدم مكتبة بارما متعددة السطوح (الإصدار 1.2)، يمكنك العثور على العديد من الأمثلة للاستخدام في الدلائل tests (انظر README في هذا الدليل) و demos/ppl_lcdd لتوزيع المصدر.

الربط مع المكتبة

من الأفضل الربط مع واجهة C++ لمكتبة بارما متعددة السطوح باستخدام مترجم C++ نفسه: عادةً ما يكون تحديد خيار سطر الأوامر -lppl كافيًا. في الواقع، إذا كنت تستخدم إصدارًا مشتركًا من المكتبة، فإن هذا يسجل تلقائيًا الاعتمادية من مكتبة GMP، وهو أمر يجب أن يتعامل معه الرابط برشاقة. وإلا فسيتعين عليك إضافة -lgmpxx -lgmp إلى سطر الأوامر. الأمور أكثر تعقيدًا إذا قمت بتثبيت PPL في مكان غير قياسي. في هذه الحالة، ستحتاج إلى استخدام خيار -Ldir، وإذا كنت تستخدم إصدارًا مشتركًا من المكتبة، فقد تتخذ خطوات إضافية: راجع وثائق نظامك للحصول على مزيد من المعلومات حول هذا الموضوع (Program Library HOWTO مفيد بشكل خاص لمستخدمي GNU/Linux).

تنفيذ العمليات المحمية بالذاكرة

إحدى الميزات المثيرة للاهتمام في مكتبة بارما متعددة السطوح هي إمكانية تنفيذ العمليات المحمية بالذاكرة. الفكرة هي أنه يمكنك تحديد كمية الذاكرة الافتراضية المتاحة للعملية، وتشغيل عملية PPL، والاستعداد لالتقاط استثناء std::bad_alloc. نظرًا لأن المكتبة آمنة للاستثناءات، يمكنك اتخاذ الإجراءات التصحيحية المناسبة (على سبيل المثال، تبسيط الأشكال المتعددة و/أو اختيار خوارزميات أقل دقة ولكن أقل تعقيدًا)، وإعادة تشغيل العملية. للقيام بذلك، يجب عليك تحديد وظائف تخصيص الذاكرة البديلة لـ GMP التي تلقي std::bad_alloc عند استنفاد الذاكرة. على سبيل المثال:

#include <new>
#include <cstdlib>
extern "C" void*
cxx_malloc(size_t size) {
  void* p = malloc(size);
  if (p != 0 || size == 0)
    return p;
  throw std::bad_alloc();
}
extern "C" void*
cxx_realloc(void* q, size_t, size_t new_size) {
  void* p = realloc(q, new_size);
  if (p != 0 || new_size == 0)
    return p;
  throw std::bad_alloc();
}
extern "C" void
cxx_free(void* p, size_t) {
  free(p);
}

ثم يجب عليك تثبيت هذه الوظائف، ويمكن القيام بذلك بطريقتين مختلفتين:

(1)
إذا كان مترجم C++ الخاص بك يدعم __attribute__ ((weak)) ولا توجد لديك أي احتياجات خاصة أخرى، فيمكنك ببساطة الربط مع تطبيقك دالة C ppl_set_GMP_memory_allocation_functions(void) مثل 
extern "C" void
ppl_set_GMP_memory_allocation_functions(void) {
  mp_set_memory_functions(cxx_malloc, cxx_realloc, cxx_free);
}

هذا كل ما عليك فعله، سواء كنت تستخدم ميزة التهيئة التلقائية للمكتبة أم لا (انظر أعلاه): في كلتا الحالتين، ستقوم إجراءات التهيئة تلقائيًا باستدعاء ppl_set_GMP_memory_allocation_functions(void).

(2)
إذا كان مترجم C++ الخاص بك لا يدعم __attribute__ ((weak))، فلن تتمكن من استخدام ميزة التهيئة التلقائية للمكتبة (انظر أعلاه) ويجب عليك كتابة برنامج رئيسي بالشكل 
int main() {
  // ترتيب استدعاءات الدوال التالية مهم.
  mp_set_memory_functions(cxx_malloc, cxx_realloc, cxx_free);
  Parma_Polyhedra_Library::initialize();
  ...

استخدام الأرقام العشرية الأصلية

عند التهيئة، تقوم مكتبة بارما متعددة السطوح بتعيين وضع تقريب FPU بطريقة تسمح لعملياتها المستندة إلى الأرقام العشرية بأن تكون متحفظة (أي، قد تكون تقريبية ولكنها صحيحة) وفعالة بشكل معقول. في حالة كان تطبيقك يستخدم الأرقام العشرية الأصلية ويعتمد على وضع تقريب معين (إذا كنت في شك، افترض أنه يعتمد على التقريب إلى أقرب عدد صحيح ليكون ساريًا)، يجب عليك استخدام الدالة

void Parma_Polyhedra_Library::restore_pre_PPL_rounding()

بعد تهيئة PPL وقبل استخدام الأرقام العشرية الأصلية في التطبيق. إذا لم يكن تطبيقك يستخدم أي تجريد يعتمد على الأرقام العشرية لـ PPL، فلا يلزم اتخاذ أي إجراءات أخرى. بخلاف ذلك، من الضروري استدعاء الدالة

void Parma_Polyhedra_Library::set_rounding_for_PPL()

قبل استدعاء أي واجهة PPL تتعلق بتلك التجريدات.

NAME

libppl - Parma Polyhedra Library

SYNOPSIS

#include <ppl.hh>

// ...

DESCRIPTION

The Parma Polyhedra Library (PPL) is a free software library, written in C++, for the analysis of polyhedral reduced products. It is designed to provide programmers with a set of tools for static analysis and verification of computer programs.

PPL can be used to represent and manipulate polyhedra, which are geometric shapes that arise in many areas of computer science, including program analysis, optimization, and formal verification.

INCLUDING THE HEADER FILE

To use the PPL library in your C++ programs, you must include the main header file: 

#include <ppl.hh>

INITIALIZING AND FINALIZING THE LIBRARY

The PPL library does not require any explicit initialization or finalization. You can start using its functionalities as soon as you include the header file.

USING THE LIBRARY

The PPL library provides a rich set of classes and functions for working with polyhedra. You can create polyhedra, perform operations such as intersection, union, and projection, and query their properties.

For example, to create a polyhedron representing the set of points (x, y) such that x ≥ 0 and y ≥ 0, you can use the following code: 

#include <ppl.hh>

int main() {
    // Create a space of dimension 2
    ppl::Space_polka space(2);

    // Create a new polyhedron
    ppl::Polyhedron P(space);

    // Add constraints: x >= 0 and y >= 0
    P.add_constraint(ppl::new_Constraint(space, 1, 0, 0)); // x >= 0
    P.add_constraint(ppl::new_Constraint(space, 0, 1, 0)); // y >= 0

    // Now P represents the first quadrant
    // ...
    return 0;
}

LINKING WITH THE LIBRARY

When compiling your C++ program that uses PPL, you need to link against the PPL library. Use the following command: 

g++ your_program.cpp -o your_program -lppl

If you have installed PPL in a non-standard location, you might need to specify the library path using the -L option and the include path using the -I option.

IMPLEMENTING MEMORY-GUARDED COMPUTATIONS

PPL provides mechanisms for handling potential memory exhaustion during complex computations. You can set resource bounds or use exception handling to manage these situations gracefully.

USING NATIVE FLOATING POINT NUMBERS

PPL supports the use of native floating-point numbers (like double) for representing coefficients in constraints and polyhedra. This can be useful for interfacing with existing code or when dealing with approximate computations.

AVAILABILITY

The Parma Polyhedra Library is available on most Unix-like systems. It can be installed using your system's package manager or by compiling from source.
