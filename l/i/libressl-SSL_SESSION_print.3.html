libressl-SSL_SESSION_print(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_SESSION_PRINT(3) دليل وظائف المكتبة SSL_SESSION_PRINT(3)

الاسم

SSL_SESSION_print, SSL_SESSION_print_fp — طباعة بعض خصائص كائن SSL_SESSION

موجز

مكتبة “libssl” libcrypto
#include <openssl/ssl.h>

int
SSL_SESSION_print(BIO *bp, const SSL_SESSION *session);

int
SSL_SESSION_print_fp(FILE *fp, const SSL_SESSION *session);

الوصف

SSL_SESSION_print() تطبع بعض خصائص session بتنسيق قابل للقراءة الآدمية إلى BIO *bp، بما في ذلك إصدار البروتوكول، اسم التشفير، معرف الجلسة، سياق معرف الجلسة، المفتاح الرئيسي، تلميح عمر تذكرة الجلسة، تذكرة الجلسة، وقت البدء، المهلة، ورمز نتيجة التحقق.

SSL_SESSION_print_fp() تفعل نفس الشيء مثل SSL_SESSION_print() باستثناء أنها تطبع إلى FILE *fp.

قيم الإرجاع

SSL_SESSION_print() و SSL_SESSION_print_fp() ترجع 1 للنجاح أو 0 للفشل.

في بعض الحالات، يمكن تحديد سبب الفشل باستخدام ERR_get_error(3).

انظر أيضا

d2i_SSL_SESSION(3), PEM_read_SSL_SESSION(3), ssl(3), SSL_get_session(3), SSL_SESSION_free(3), SSL_SESSION_get_ex_new_index(3), SSL_SESSION_get_time(3), SSL_SESSION_new(3)

التاريخ

SSL_SESSION_print() ظهرت لأول مرة في SSLeay 0.5.2. SSL_SESSION_print_fp() ظهرت لأول مرة في SSLeay 0.6.0. كلا الوظيفتين متاحتان منذ OpenBSD 2.4.
