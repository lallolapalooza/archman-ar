DESCRIPTION

\n

The function BN_generate_prime() generates a prime number of bits bits and stores it in ret. The prime number is generated by first picking a random number, and then checking if it is prime. If it is not prime, another random number is picked, and so on, until a prime is found.

\n

safe is a boolean value. If it is 1, a prime number p such that 2p+1 is also prime is generated. Such primes are called safe primes.

\n

add and rem are optional BIGNUMs. If specified, the generated prime p will satisfy p = add (mod rem). This can be used to enforce certain properties on the generated prime.

\n

The callback parameter is a callback function, which is called during the prime generation process. The callback function is of type int (*callback)(int, int, void *). The first argument is the step, and the second argument is the progress within that step. The third argument is a pointer to the argument passed to BN_GENCB_set(). The callback function is expected to return 1 on success and 0 on failure. If the callback returns 0, the prime generation process is aborted.

\n

BN_generate_prime_ex() is the more modern version of BN_generate_prime(). It is identical except that it takes a BN_GENCB * argument for the callback function. This allows for more complex state to be maintained by the callback.

\n

BN_is_prime() performs a probabilistic primality test on the number a. The number of iterations is determined by checks. A return value of 1 means that a is definitely prime. A return value of 0 means that a is definitely composite.

\n

The cb argument is a callback function that is called during the primality test. The first argument to the callback is the current iteration number, and the second argument is the total number of iterations. The callback function is expected to return 1 on success and 0 on failure. If the callback returns 0, the primality test is aborted.

\n

BN_is_prime_ex() is the more modern version of BN_is_prime(). It is identical except that it takes a BN_CTX * argument for the context, which is used to store temporary values.

\n

BN_is_prime_fasttest() and BN_is_prime_fasttest_ex() are variants of BN_is_prime() and BN_is_prime_ex() that use a faster algorithm for testing primality. This algorithm is less accurate than the one used by BN_is_prime() and BN_is_prime_ex(), but it is much faster.

\n

BN_GENCB_new() allocates and initializes a new BN_GENCB structure.

\n

BN_GENCB_free() frees a BN_GENCB structure previously allocated by BN_GENCB_new().

\n

BN_GENCB_set_old() sets the callback function pointer callback in the BN_GENCB object pointed to by cb. This function is provided for backward compatibility with older versions of OpenSSL.

\n

BN_GENCB_set() sets the callback function pointer callback and the user data pointer arg in the BN_GENCB object pointed to by cb.

\n

BN_GENCB_get_arg() returns the cb_arg pointer that was previously stored in cb using BN_GENCB_set() or BN_GENCB_set_old().

\n

BN_GENCB_call() calls the callback function stored in cb with the specified step and progress values. It returns 1 if the callback returns 1, and 0 otherwise.

\n
\n\n
\n

RETURN VALUES

\n

BN_generate_prime(), BN_generate_prime_ex(), BN_is_prime(), BN_is_prime_ex(), BN_is_prime_fasttest(), and BN_is_prime_fasttest_ex() return 1 on success, or 0 on failure. In some cases, error codes can be obtained by ERR_get_error(3).

\n

BN_GENCB_new() returns a pointer to the newly allocated BN_GENCB object or NULL if memory allocation fails.

\n

The callback functions pointed to by the cb_fp arguments are supposed to return 1 on success or 0 on error.

\n

BN_GENCB_get_arg() returns the cb_arg pointer that was previously stored in cb using BN_GENCB_set() or BN_GENCB_set_old().

\n

In some cases, error codes can be obtained by ERR_get_error(3).
