libkeccak_state_duplicate(3)

الحزمة: libkeccak

التراخيص: custom:ISC

LIBKECCAK_STATE_DUPLICATE(3) دليل الوظائف المكتبية LIBKECCAK_STATE_DUPLICATE(3)

اسم

libkeccak_state_duplicate - تخصيص حالة تجزئة مكررة

الملخص

#include <libkeccak.h>
struct libkeccak_state *libkeccak_state_duplicate(const struct libkeccak_state *src);

اربط مع -lkeccakP.

الوصف

تقوم وظيفة libkeccak_state_duplicate() بتخصيص حالة تجزئة جديدة وتهيئتها لتكون مطابقة لـ *src. يتضمن ذلك جميع أعضاء بنية struct libkeccak_state، بما في ذلك حالة الإسفنج ومخزن مؤقت لجزء الرسالة.

قيم الإرجاع

تُرجع وظيفة libkeccak_state_duplicate() مؤشرًا جديدًا مخصصًا struct libkeccak_state* (لعنصر واحد مهيأ) عند اكتمال التنفيذ بنجاح. عند حدوث خطأ، يتم إرجاع NULL وتعيين errno لوصف الخطأ.

الأخطاء

قد تفشل وظيفة libkeccak_state_duplicate() لأي سبب محدد لوظيفة malloc(3).

راجع أيضاً

libkeccak_state_copy(3)، libkeccak_state_create(3)
