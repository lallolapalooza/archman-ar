الاسم

libpipewire-module-jack-tunnel - نفق JACK

الوصف

توفر وحدة jack-tunnel مصدرًا أو بالوعة تقوم بنقل كل الصوت إلى خادم JACK.

عادةً ما تُستخدم هذه الوحدة مع JACK DBus detect الذي سيقوم بتحميل النفق تلقائيًا بالمعلمات الصحيحة بناءً على معلومات dbus.

اسم الوحدة

libpipewire-module-jack-tunnel

خيارات الوحدة

  • jack.library: المكتبة libjack التي سيتم تحميلها، افتراضيًا يتم البحث عن libjack.so.0 في أدلة JACK_PATH ثم في بعض مسارات المكتبات القياسية. يمكن أن تكون مسارًا مطلقًا.
  • jack.server: اسم خادم JACK الذي سيتم النفق إليه.
  • jack.client-name: اسم عميل JACK.
  • jack.connect: إذا كان يجب توصيل منافذ jack تلقائيًا. يمكن أيضًا وضعه لكل تيار.
  • tunnel.mode: وضع النفق، sink|source|duplex، افتراضي duplex
  • midi.ports: عدد منافذ midi. يمكن إضافتها أيضًا إلى خصائص التيار.
  • source.props: خصائص إضافية لمرشح المصدر.
  • sink.props: خصائص إضافية لمرشح البالوعة.

خيارات عامة

خيارات ذات سلوك معروف.

  • remote.name
  • audio.channels
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object لتحديد اسم العقدة البعيدة أو معرّفها التسلسلي للربط به

مثال على تكوين بالوعة/مصدر مزدوج

# ~/.config/pipewire/pipewire.conf.d/my-jack-tunnel.conf
context.modules = [
{   name = libpipewire-module-jack-tunnel
    args = {
        #jack.library     = libjack.so.0
        #jack.server      = null
        #jack.client-name = PipeWire
        #jack.connect     = true
        #tunnel.mode      = duplex
        #midi.ports       = 0
        #audio.channels   = 2
        #audio.position   = [ FL FR ]
        source.props = {
            # خصائص بالوعة إضافية
        }
        sink.props = {
            # خصائص بالوعة إضافية
        }
    }
}
]
