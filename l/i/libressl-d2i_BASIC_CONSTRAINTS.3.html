libressl-d2i_BASIC_CONSTRAINTS(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

D2I_BASIC_CONSTRAINTS(3) دليل وظائف المكتبة D2I_BASIC_CONSTRAINTS(3)

الاسم

d2i_BASIC_CONSTRAINTS، i2d_BASIC_CONSTRAINTS، d2i_EXTENDED_KEY_USAGE، i2d_EXTENDED_KEY_USAGE — فك تشفير وترميز استخدامات مفتاح X.509

الملخص

المكتبة «libcrypto»
#include <openssl/x509v3.h>

BASIC_CONSTRAINTS *
d2i_BASIC_CONSTRAINTS(BASIC_CONSTRAINTS **val_out, const unsigned char **der_in, long length);

int
i2d_BASIC_CONSTRAINTS(BASIC_CONSTRAINTS *val_in, unsigned char **der_out);

EXTENDED_KEY_USAGE *
d2i_EXTENDED_KEY_USAGE(EXTENDED_KEY_USAGE **val_out, const unsigned char **der_in, long length);

int
i2d_EXTENDED_KEY_USAGE(EXTENDED_KEY_USAGE *val_in, unsigned char **der_out);

الوصف

تقوم هذه الوظائف بفك تشفير وترميز هياكل البيانات التي تصف الأغراض المقصودة لاستخدام المفتاح الموجود في شهادة X.509. للحصول على تفاصيل حول الدلالات والأمثلة والمحاذير والأخطاء، راجع ASN1_item_d2i(3).

d2i_BASIC_CONSTRAINTS() و i2d_BASIC_CONSTRAINTS() يقومان بفك تشفير وترميز بنية ASN.1 BasicConstraints كما هو محدد في RFC 5280 القسم 4.2.1.9.

d2i_EXTENDED_KEY_USAGE() و i2d_EXTENDED_KEY_USAGE() يقومان بفك تشفير وترميز بنية ASN.1 ExtKeyUsageSyntax كما هو محدد في RFC 5280 القسم 4.2.1.12.

قيم الإرجاع

d2i_BASIC_CONSTRAINTS() و d2i_EXTENDED_KEY_USAGE() ترجعان كائن BASIC_CONSTRAINTS أو EXTENDED_KEY_USAGE على التوالي، أو NULL في حالة حدوث خطأ.

i2d_BASIC_CONSTRAINTS() و i2d_EXTENDED_KEY_USAGE() ترجعان عدد البايتات التي تم ترميزها بنجاح أو قيمة سالبة في حالة حدوث خطأ.

انظر أيضًا

ASN1_item_d2i(3)، BASIC_CONSTRAINTS_new(3)، EXTENDED_KEY_USAGE_new(3)، X509_EXTENSION_new(3)

المعايير

RFC 5280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile

التاريخ

d2i_BASIC_CONSTRAINTS() و i2d_BASIC_CONSTRAINTS() ظهرتا لأول مرة في OpenSSL 0.9.2b وكانتا متاحتين منذ OpenBSD 2.6.

d2i_EXTENDED_KEY_USAGE() و i2d_EXTENDED_KEY_USAGE() ظهرتا لأول مرة في OpenSSL 0.9.7 وكانتا متاحتين منذ OpenBSD 3.2.
