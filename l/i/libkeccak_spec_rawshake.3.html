libkeccak_spec_rawshake(3)

الحزمة: libkeccak

التراخيص: custom:ISC

LIBKECCAK_SPEC_RAWSHAKE(3) دليل وظائف المكتبة LIBKECCAK_SPEC_RAWSHAKE(3)

الاسم

libkeccak_spec_rawshake - تهيئة معلمات تجزئة RawSHAKE

ملخص

#include <libkeccak.h>
void libkeccak_spec_rawshake(struct libkeccak_spec *spec, long int x, long int d);

اربط مع -lkeccak.

الوصف

تقوم الدالة libkeccak_spec_rawshake() بتعيين *spec لتحديد معلمات Keccak المستخدمة لتجزئة RawSHAKE مع السعة النصفية المحددة، بالبت، عبر المعامل x، وحجم الإخراج المحدد، بالبت، عبر المعامل d.

قيم الإرجاع

الدالة libkeccak_spec_rawshake() لا ترجع أي قيمة.

الأخطاء

لا يمكن أن تفشل الدالة libkeccak_spec_rawshake().

مثال

يقوم هذا المثال بتهيئة struct libkeccak_spec لتحديد معلمات Keccak المستخدمة لـ RawSHAKE256(, 512):

struct libkeccak_spec spec;
libkeccak_spec_rawshake(&spec, 256, 512);
