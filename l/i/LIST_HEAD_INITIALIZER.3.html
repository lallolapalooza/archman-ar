LIST_HEAD_INITIALIZER(3bsd)

NAME

LIST_HEAD_INITIALIZER — macro for initializing a list head

SYNOPSIS

#include <sys/queue.h>

LIST_HEAD(name, type)

LIST_HEAD_INITIALIZER(name)

DESCRIPTION

The LIST_HEAD macro declares a structure named name which represents a doubly linked list head. The second argument, type, is the name of the structure that will be used for the list entries.

The LIST_HEAD_INITIALIZER macro is used to initialize a list head structure. It should be used when declaring a global or static list head variable.

RETURN VALUE

N/A

ERRORS

N/A

HISTORY

The LIST_HEAD and LIST_HEAD_INITIALIZER macros first appeared in FreeBSD 2.2.

BUGS

N/A

EXAMPLES

To declare and initialize a list of integers:

#include <sys/queue.h>

struct intlist {
    int value;
    LIST_ENTRY(intlist) next;
};

LIST_HEAD(intlist_head, intlist) my_list = LIST_HEAD_INITIALIZER(my_list);

int main() {
    struct intlist *element;

    element = malloc(sizeof(struct intlist));
    element->value = 10;
    LIST_INSERT_HEAD(&my_list, element, next);

    // ... process the list ...

    return 0;
}
