libtool(1)

الحزمة: libtool

التراخيص: LGPL-2.0-or-later WITH Libtool-exception

LIBTOOL(1) أوامر المستخدم LIBTOOL(1)

الاسم

libtool - توفير خدمات عامة لبناء المكتبات

الملخص

libtool [خيار]... [وسيط_الوضع]...

الوصف

توفير خدمات عامة لبناء المكتبات.

الخيارات

--config
عرض جميع متغيرات التكوين
--debug
تمكين تتبع shell المطول
-n, --dry-run
عرض الأوامر دون تعديل أي ملفات
--features
عرض معلومات التكوين الأساسية
--finish
استخدام العملية '--mode=finish'
--mode=الوضع
استخدام وضع العملية الوضع
--no-finish
عدم تحديث ذاكرة التخزين المؤقت لمكتبات المشاركة
--no-quiet, --no-silent
طباعة رسائل المعلومات الافتراضية
--no-warnings
مكافئ لـ '-Wnone'
--preserve-dup-deps
عدم إزالة المكتبات التابعة المكررة
--quiet, --silent
عدم طباعة رسائل المعلومات
--reorder-cache=مسارات
إعادة ترتيب ذاكرة التخزين المؤقت لمكتبات المشاركة للمسارات المفضلة
--tag=علامة
استخدام متغيرات التكوين من علامة العلامة
-v, --verbose
طباعة رسائل معلومات أكثر من الافتراضي
--version
طباعة معلومات الإصدار
-W, --warnings=فئة
الإبلاغ عن التحذيرات التي تقع ضمن الفئة [الكل]
-h, --help, --help-all
طباعة رسالة مساعدة قصيرة، طويلة، أو مفصلة

تشمل فئات التحذير:

'all'
عرض جميع التحذيرات
'none'
إيقاف جميع التحذيرات
'error'
تُعامل التحذيرات كأخطاء قاتلة

إذا تم توفير علامة، فيجب أن تستخدم إحدى أسماء العلامات التالية:

اسم العلامة
اسم اللغة
CC
C
CXX
C++
OBJC
Objective-C
OBJCXX
Objective-C++
GCJ
Java
F77
Fortran 77
FC
Fortran
GO
Go
RC
موارد Windows

إذا لم ترَ اسم علامة مرتبطًا بلغة البرمجة الخاصة بك، فهذا يعني أنك تستخدم مترجمًا لا يدعمه libtool.

يجب أن يكون الوضع أحد الخيارات التالية:

clean
إزالة الملفات من دليل البناء
compile
تجميع ملف مصدر في كائن libtool
execute
تعيين مسار المكتبة تلقائيًا، ثم تشغيل برنامج
finish
إكمال تثبيت مكتبات libtool
install
تثبيت المكتبات أو الملفات التنفيذية
link
إنشاء مكتبة أو ملف تنفيذي
uninstall
إزالة المكتبات من دليل مثبت

تختلف وسائط الوضع بناءً على الوضع. عند تمريرها كخيار أول، يمكن اختصار '--mode=MODE' باسم 'MODE' أو اختصار فريد له.

الصفحة الرئيسية لـ GNU libtool: https://www.gnu.org/s/libtool/.
