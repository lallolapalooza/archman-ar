libressl-SSL_set_tmp_ecdh(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_SET_TMP_ECDH(3) دليل وظائف المكتبة SSL_SET_TMP_ECDH(3)

الاسم

SSL_set_tmp_ecdh، SSL_CTX_set_tmp_ecdh، SSL_set_ecdh_auto، SSL_CTX_set_ecdh_auto، SSL_set_tmp_ecdh_callback، SSL_CTX_set_tmp_ecdh_callback — اختيار منحنى لتبادل مفاتيح ECDH المؤقتة

الملخص

مكتبة "libssl" libcrypto
#include <openssl/ssl.h>

long
SSL_set_tmp_ecdh(SSL *ssl، EC_KEY *ecdh);

long
SSL_CTX_set_tmp_ecdh(SSL_CTX *ctx، EC_KEY *ecdh);

long
SSL_set_ecdh_auto(SSL *ssl، int state);

long
SSL_CTX_set_ecdh_auto(SSL_CTX *ctx، int state);

void
SSL_set_tmp_ecdh_callback(SSL *ssl، EC_KEY *(*ecdh)(SSL *ssl, int is_export, int keylength));

void
SSL_CTX_set_tmp_ecdh_callback(SSL_CTX *ctx، EC_KEY *(*ecdh)(SSL *ssl, int is_export, int keylength));

الوصف

يتم تمكين اختيار منحنيات EC وإنشائها تلقائيًا دائمًا في LibreSSL، ولا يمكن للتطبيقات توفير مفاتيح EC يدويًا للاستخدام مع تبادل مفاتيح ECDH.

التأثير الوحيد المتبقي لـ SSL_set_tmp_ecdh() هو أن منحنى مفتاح ecdh المحدد يصبح المنحنى الوحيد الممكّن لاتصال ssl، لذا فهو يعادل استدعاء SSL_set1_groups_list(3) مع اسم المنحنى المفرد نفسه.

SSL_CTX_set_tmp_ecdh() له نفس التأثير على جميع الاتصالات التي سيتم إنشاؤها من ctx في المستقبل.

الوظائف SSL_set_ecdh_auto()، SSL_CTX_set_ecdh_auto()، SSL_set_tmp_ecdh_callback()، و SSL_CTX_set_tmp_ecdh_callback() مهملة وليس لها تأثير.

قيم الإرجاع

SSL_set_tmp_ecdh() و SSL_CTX_set_tmp_ecdh() تعيد 1 عند النجاح أو 0 عند الفشل.

SSL_set_ecdh_auto()، SSL_CTX_set_ecdh_auto()، SSL_set_tmp_ecdh_callback()، و SSL_CTX_set_tmp_ecdh_callback() تعيد دائمًا 1.

انظر أيضًا

ssl(3)، SSL_CTX_set1_groups(3)، SSL_CTX_set_cipher_list(3)، SSL_CTX_set_options(3)، SSL_CTX_set_tmp_dh_callback(3)، SSL_new(3)

التاريخ

SSL_set_tmp_ecdh()، SSL_CTX_set_tmp_ecdh()، SSL_set_tmp_ecdh_callback()، و SSL_CTX_set_tmp_ecdh_callback() ظهرت لأول مرة في OpenSSL 0.9.8 وكانت متاحة منذ OpenBSD 4.5.

SSL_CTX_set_ecdh_auto() و SSL_set_ecdh_auto() ظهرت لأول مرة في OpenSSL 1.0.2 وكانت متاحة منذ OpenBSD 5.7.
