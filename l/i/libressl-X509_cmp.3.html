libressl-X509_cmp(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

X509_CMP(3) دليل وظائف المكتبة X509_CMP(3)

الاسم

X509_cmp، X509_NAME_cmp، X509_issuer_and_serial_cmp، X509_issuer_name_cmp، X509_subject_name_cmp، X509_CRL_cmp، X509_CRL_match — مقارنة شهادات X.509 والقيم ذات الصلة

الملخص

مكتبة “libcrypto”
#include <openssl/x509.h>

int
X509_cmp(const X509 *a، const X509 *b);

int
X509_NAME_cmp(const X509_NAME *a، const X509_NAME *b);

int
X509_issuer_and_serial_cmp(const X509 *a، const X509 *b);

int
X509_issuer_name_cmp(const X509 *a، const X509 *b);

int
X509_subject_name_cmp(const X509 *a، const X509 *b);

int
X509_CRL_cmp(const X509_CRL *a، const X509_CRL *b);

int
X509_CRL_match(const X509_CRL *a، const X509_CRL *b);

الوصف

X509_cmp() تقارن شهادتي X.509 باستخدام memcmp(3) على تجزئات تمثيلاتها القياسية (DER) كما تم إنشاؤها باستخدام X509_digest(3). وظيفة التجزئة خاصة بالتنفيذ: LibreSSL تستخدم SHA-512، وتستخدم التطبيقات الأخرى SHA-1.

X509_NAME_cmp() تقارن كائنين من نوع Name وفقًا لـ X.501 باستخدام تمثيلاتهما القياسية (DER) التي تم إنشاؤها باستخدام i2d_X509_NAME(3).

X509_issuer_and_serial_cmp() تقارن حقلي issuer و serialNumber لهيكلي TBSCertificate، باستخدام X509_NAME_cmp() للحقول issuer.

X509_issuer_name_cmp() تقارن الحقول issuer لهيكلي TBSCertificate باستخدام X509_NAME_cmp().

X509_subject_name_cmp() تقارن الحقول subject لهيكلي TBSCertificate باستخدام X509_NAME_cmp().

X509_CRL_cmp() اسمها مضلل؛ فهي تقارن فقط الحقول issuer لهيكلي TBSCertList باستخدام X509_NAME_cmp().

X509_CRL_match() تقارن قائمتي إبطال شهادة باستخدام memcmp(3) على تجزئات تمثيلاتهما القياسية (DER) كما تم إنشاؤها باستخدام X509_CRL_digest(3). وظيفة التجزئة خاصة بالتنفيذ: LibreSSL تستخدم SHA-512، وتستخدم التطبيقات الأخرى SHA-1.

قيم الإرجاع

جميع هذه الوظائف ترجع 0 للإشارة إلى تطابق أو قيمة غير صفرية للإشارة إلى عدم تطابق.

X509_NAME_cmp()، X509_issuer_and_serial_cmp()، X509_issuer_name_cmp()، X509_subject_name_cmp() و X509_CRL_cmp() قد ترجع -2 للإشارة إلى خطأ.

انظر أيضًا

i2d_X509_NAME(3)، X509_CRL_new(3)، X509_digest(3)، X509_NAME_new(3)، X509_new(3)

التاريخ

X509_issuer_and_serial_cmp()، X509_issuer_name_cmp()، و X509_subject_name_cmp() ظهرت لأول مرة في SSLeay 0.5.1، و X509_NAME_cmp() و X509_CRL_cmp() في SSLeay 0.8.0. كانت هذه الوظائف متاحة منذ OpenBSD 2.4.

X509_cmp() ظهرت لأول مرة في OpenSSL 0.9.5 وكانت متاحة منذ OpenBSD 2.7.

X509_CRL_match() ظهرت لأول مرة في OpenSSL 1.0.0 وكانت متاحة منذ OpenBSD 4.9.

أخطاء

بالنسبة لـ X509_NAME_cmp()، X509_issuer_and_serial_cmp()، X509_issuer_name_cmp()، X509_subject_name_cmp() و X509_CRL_cmp()، القيمة المرجعة -2 تشير أحيانًا إلى عدم تطابق وأحيانًا إلى خطأ.
