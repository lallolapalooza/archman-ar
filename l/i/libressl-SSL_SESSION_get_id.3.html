libressl-SSL_SESSION_get_id(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_SESSION_GET_ID(3) دليل الوظائف المكتبية SSL_SESSION_GET_ID(3)

الاسم

SSL_SESSION_get_id، SSL_SESSION_set1_id — الحصول على معرف جلسة SSL وتعيينه

المُلخَّص

المكتبة “libssl” libcrypto
#include <openssl/ssl.h>

const unsigned char *
SSL_SESSION_get_id(const SSL_SESSION *s, unsigned int *len);

int
SSL_SESSION_set1_id(SSL_SESSION *s, const unsigned char *sid, unsigned int sid_len);

الوصف

SSL_SESSION_get_id() تُرجع مؤشرًا إلى قيمة معرف الجلسة الداخلية للجلسة s. يتم تخزين طول المعرف بالبايت في *len. قد يكون الطول 0. لا ينبغي للمستدعي تحرير المؤشر المُرجع مباشرة.

SSL_SESSION_set1_id() تعيّن معرف الجلسة للجلسة s إلى نسخة من sid بطول sid_len.

قيم الإرجاع

SSL_SESSION_get_id() تُرجع مؤشرًا إلى قيمة معرف الجلسة.

SSL_SESSION_set1_id() تُرجع 1 للنجاح و 0 للفشل، على سبيل المثال إذا تجاوز طول معرف الجلسة المُقدم SSL_MAX_SSL_SESSION_ID_LENGTH.

انظر أيضًا

ssl(3)، SSL_copy_session_id(3)، SSL_get_session(3)، SSL_SESSION_get_compress_id(3)، SSL_SESSION_get_protocol_version(3)، SSL_SESSION_has_ticket(3)، SSL_SESSION_new(3)

التاريخ

SSL_SESSION_get_id() ظهرت لأول مرة في OpenSSL 0.9.8 وكانت متاحة منذ OpenBSD 4.5.

SSL_SESSION_set1_id() ظهرت لأول مرة في OpenSSL 1.1.0 وكانت متاحة منذ OpenBSD 6.3.
