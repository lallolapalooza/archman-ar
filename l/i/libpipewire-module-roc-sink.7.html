الاسم

libpipewire-module-roc-sink - ROC sink

الوصف

وحدة roc-sink تنشئ PipeWire sink ترسل العينات إلى عنوان مستقبل مُعد مسبقًا.

يمكن بعد ذلك توصيل تيار صوتي من أي تطبيق قيد التشغيل إلى هذا الـ sink أو جعله الـ sink الافتراضي.

اسم الوحدة

libpipewire-module-roc-sink

خيارات الوحدة

خيارات خاصة بسلوك هذه الوحدة

  • sink.props = {}: خصائص سيتم تمريرها إلى تيار الـ sink
  • sink.name = <str>: node.name الخاص بالـ sink
  • remote.ip = <str>: عنوان IP الخاص بالمستقبل البعيد
  • remote.source.port = <str>: منفذ TCP/UDP الخاص بالمستقبل البعيد لحزم المصدر
  • remote.repair.port = <str>: منفذ TCP/UDP الخاص بالمستقبل البعيد لحزم المستقبل
  • remote.control.port = <str>: منفذ TCP/UDP الخاص بالمستقبل البعيد لحزم التحكم
  • fec.code = <str>: القيم الممكنة: disable, rs8m, ldpc

خيارات عامة

خيارات ذات سلوك معروف:

  • node.name
  • node.description
  • media.name

مثال على التهيئة

 # ~/.config/pipewire/pipewire.conf.d/my-roc-sink.conf
 context.modules = [
  {   name = libpipewire-module-roc-sink
      args = {
          fec.code = disable
          remote.ip = 192.168.0.244
          remote.source.port = 10001
          remote.repair.port = 10002
          remote.control.port = 10003
          sink.name = "ROC Sink"
          sink.props = {
             node.name = "roc-sink"
          }
      }
  }
]
