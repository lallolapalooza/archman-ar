ref="#only_proxies">-only-proxies <0>/<1>
"1" يجعل الروابط لا تبدأ أي اتصال غير مباشر. وهو مفيد لإخفاء الهوية باستخدام Tor أو شبكات مماثلة.
-ssl.certificates <0>/<1>/<2>
(الافتراضي 1) 0 - تجاهل الشهادة غير الصالحة. 1 - تحذير بشأن شهادة غير صالحة. 2 - رفض شهادة غير صالحة.
-ssl.builtin-certificates <0>/<1>
(الافتراضي 0؛ على DOS و OpenVMS الافتراضي 1) استخدام الشهادات المضمنة بدلاً من شهادات النظام.
-ssl.client-cert-key <filename>
اسم الملف المشفر بصيغة PEM مع المفتاح الخاص للمستخدم لمصادقة شهادة العميل.
-ssl.client-cert-crt <filename>
اسم الملف المشفر بصيغة PEM مع شهادة المستخدم لمصادقة شهادة العميل.
-ssl.client-cert-password <text>
كلمة المرور للمفتاح الخاص للمستخدم.
-async-dns <0>/<1>
محلل DNS غير متزامن تشغيل (1) / إيقاف (0).
-dns-over-https <url>
عنوان URL لنظام أسماء النطاقات عبر HTTPS.
-http-bugs.http10 <0>/<1>
(الافتراضي 0) "1" يجبر على استخدام بروتوكول HTTP/1.0 فقط. (مفيد للخوادم المعيبة التي تدعي أنها متوافقة مع HTTP/1.1 ولكنها ليست كذلك) "0" يتيح استخدام كل من HTTP/1.0 و HTTP/1.1.
-http-bugs.allow-blacklist <0>/<1>
(الافتراضي 1) "1" يستخدم افتراضيًا قائمة بالخوادم التي لديها دعم معيب لـ HTTP/1.1. عندما يجد الروابط مثل هذا الخادم، سيعيد المحاولة للطلب باستخدام HTTP/1.0.
-http-bugs.bug-no-accept-charset <0>/<1>
(الافتراضي 0) لا ترسل حقل Accept-Charset من رأس HTTP. نظرًا لأنه طويل جدًا، فإن بعض الخوادم سترفض الطلب. ستقوم خوادم أخرى بتحويل المحتوى إلى نص عادي ASCII عند فقدان Accept-Charset.
-http-bugs.no-compression <0>/<1>
(الافتراضي 0) "1" يجعل الروابط لا تعلن عن دعم ضغط HTTP (لكنه سيظل يقبل البيانات المضغوطة). استخدمه عند التواصل مع خادم لديه دعم ضغط معيب.
-http-bugs.retry-internal-errors <0>/<1>
(الافتراضي 0) إعادة المحاولة عند أخطاء الخادم الداخلية (50x).
-http.fake-firefox <0>/<1>
(الافتراضي 0) تظاهر بأن المتصفح هو Firefox في رأس HTTP.
-http.do-not-track <0>/<1>
(الافتراضي 0) إرسال طلب "عدم التتبع" في رأس HTTP.
-http.referer <0>/<1>/<2>/<3>/<4>
(الافتراضي 0) 0 - لا ترسل المرجع. 1 - أرسل عنوان URL المطلوب كـ مرجع. 2 - أرسل مرجعًا مزيفًا. 3 - أرسل مرجعًا حقيقيًا. 4 - أرسل مرجعًا حقيقيًا فقط إلى نفس الخادم.
-http.fake-referer <string>
قيمة المرجع المزيف.
-http.fake-user-agent <string>
قيمة وكيل المستخدم المزيف.
-http.extra-header <string>
سلسلة إضافية مضافة إلى رأس HTTP.
-ftp.anonymous-password <string>
كلمة المرور للوصول المجهول عبر FTP.
-ftp.use-passive <0>/<1>
استخدام أمر FTP PASV لتجاوز جدران الحماية.
-ftp.use-erpt-epsv <0>/<1>
استخدام أوامر EPRT و EPSV بدلاً من PORT و PASV.
-ftp.set-iptos <0>/<1>
تعيين نوع الخدمة IP لتحقيق إنتاجية عالية في اتصالات FTP.
-smb.allow-hyperlinks-to-smb <0>/<1>
السماح بالروابط التشعبية لبروتوكول SMB. تعطيل هذا يحسن الأمان، لأن مواقع الإنترنت لا يمكنها استغلال الأخطاء المحتملة في عميل SMB.

links(1) - Manual page

NAME

links - a text-mode web browser

SYNOPSIS

links [options] [URL]

DESCRIPTION

links is a text-mode web browser. It supports HTML, HTTP/1.1, CSS, JavaScript, and SSL. It can be operated in a graphical environment (like X11) or in a text terminal.

OPTIONS

-h, --help
Display help message and exit.
-v, --version
Display version information and exit.
-g, --graphics
Enable graphics mode (if supported by terminal).
-n, --no-graphics
Disable graphics mode.
-c, --cookie-file=FILE
Use specified file for cookies.
-e, --encoding=ENCODING
Set default character encoding.
-f, --force-html
Force rendering of HTML even for non-HTML files.
-j, --disable-javascript
Disable JavaScript execution.
-s, --save-session=FILE
Save current session to FILE.
-l, --load-session=FILE
Load session from FILE.
-o, --output-file=FILE
Output the current page to FILE.
-t, --timeout=SECONDS
Set connection timeout to SECONDS.
-u, --user-agent=AGENT
Set user agent string.

NAVIGATION KEYS

Up/Down Arrows
Scroll up/down.
Left/Right Arrows
Go back/forward in history.
Page Up/Page Down
Scroll page by page.
Home/End
Go to the top/bottom of the page.
g
Go to URL.
u
Go to parent directory.
b
Go back.
f
Go forward.
r
Reload current page.
q
Quit.

EDITING KEYS

Tab
Move to the next link.
Shift+Tab
Move to the previous link.
Enter
Follow the selected link.
Space
Scroll down.
Backspace
Scroll up.

FILES

~/.links/cookies
Default cookie file.
~/.links/history
Session history.
~/.links/settings
User settings.

PLATFORMS

links is available for Linux, macOS, and other Unix-like systems.

BUGS

Report bugs to links-users@twibright.com.
