NAME

BIO_s_file(3) — file BIO methods

SYNOPSIS

#include <openssl/bio.h>

const BIO_METHOD *
BIO_s_file(void);

BIO *
BIO_new_file(const char *filename, const char *mode);

BIO *
BIO_new_fp(FILE *fp, int flags);

int
BIO_set_fp(BIO *bio, FILE *fp, int flags);

FILE *
BIO_get_fp(BIO *bio);

int
BIO_seek(BIO *bio, long offset);

long
BIO_tell(BIO *bio);

int
BIO_read_filename(BIO *bio, const char *filename);

int
BIO_write_filename(BIO *bio, const char *filename);

int
BIO_append_filename(BIO *bio, const char *filename);

int
BIO_rw_filename(BIO *bio, const char *filename);

DESCRIPTION

The file BIOs are used to perform I/O operations on standard C FILE pointers or directly on files using their filenames. They use the underlying C standard I/O library functions for all operations.

The BIO_s_file() function returns a pointer to the file BIO method structure.

The BIO_new_file() function creates a new file BIO object. It opens the file specified by filename in the mode specified by mode. The mode string must be a valid mode string for fopen(3). If successful, it returns a pointer to the new BIO object, otherwise NULL is returned.

The BIO_new_fp() function creates a new file BIO object associated with the already open standard I/O stream fp. The flags are a bitmask of BIO_CLOSE and BIO_NOCLOSE. If BIO_CLOSE is set, the underlying FILE pointer will be closed when the BIO is freed. If BIO_NOCLOSE is set, the FILE pointer will not be closed.

The BIO_set_fp() function associates the file BIO object bio with the standard I/O stream fp. The flags are the same as for BIO_new_fp().

The BIO_get_fp() function returns the underlying standard I/O stream associated with the BIO.

The BIO_seek() function seeks to the position specified by offset in the BIO. This is equivalent to calling fseek(3).

The BIO_tell() function returns the current file position. This is equivalent to calling ftell(3).

The functions BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), and BIO_rw_filename() are convenience functions that create a new file BIO object, open the specified file with the appropriate mode, and set it up for reading, writing, appending, or read/write access, respectively. They return 1 on success or 0 on failure.

The following table shows the modes and flags used by these functions:

BIO_FP_READ Open for reading.
BIO_FP_WRITE Open for writing.
BIO_FP_APPEND Open for appending.
BIO_FP_READ|BIO_FP_WRITE Open for reading and writing.
BIO_CLOSE Close the file pointer when the BIO is freed.
BIO_NOCLOSE Do not close the file pointer when the BIO is freed.

The BIO_read_filename() function is equivalent to calling BIO_new_file() with mode "r" and setting the BIO_CLOSE flag.

The BIO_write_filename() function is equivalent to calling BIO_new_file() with mode "w" and setting the BIO_CLOSE flag.

The BIO_append_filename() function is equivalent to calling BIO_new_file() with mode "a" and setting the BIO_CLOSE flag.

The BIO_rw_filename() function is equivalent to calling BIO_new_file() with mode "r+" and setting the BIO_CLOSE flag.

The modes and flags can be combined using the bitwise OR operator.

The following table shows the combinations of flags and the corresponding functions:

Flags Function
BIO_CLOSE | BIO_FP_READ BIO_read_filename()
BIO_CLOSE | BIO_FP_WRITE BIO_write_filename()
BIO_CLOSE | BIO_FP_APPEND BIO_append_filename()
BIO_CLOSE | BIO_FP_READ | BIO_FP_WRITE BIO_rw_filename()

RETURN VALUES

BIO_s_file() returns the file BIO method.

BIO_new_file() and BIO_new_fp() return a file BIO or NULL if an error occurred.

When called on a file BIO object, BIO_method_type(3) returns the constant BIO_TYPE_FILE and BIO_method_name(3) returns a pointer to the static string "FILE pointer".

BIO_set_fp() and BIO_get_fp() return 1 for success or 0 for failure (although the current implementation never returns 0).

BIO_seek(3) returns the same value as the underlying fseek(3) function: 0 for success or -1 for failure.

BIO_tell(3) returns the current file position.

BIO_read_filename(), BIO_write_filename(), BIO_append_filename(), and BIO_rw_filename() return 1 for success or 0 for failure.

EXAMPLES

File BIO "hello world":

BIO *bio_out;
bio_out = BIO_new_fp(stdout, BIO_NOCLOSE);
BIO_printf(bio_out, "Hello World\n");

Alternative technique:

BIO *bio_out;
bio_out = BIO_new(BIO_s_file());
if(bio_out == NULL) /* Error ... */
if(!BIO_set_fp(bio_out, stdout, BIO_NOCLOSE)) /* Error ... */
BIO_printf(bio_out, "Hello World\n");

Write to a file:

BIO *out;
out = BIO_new_file("filename.txt", "w");
if(!out) /* Error occurred */
BIO_printf(out, "Hello World\n");
BIO_free(out);

Alternative technique:

BIO *out;
out = BIO_new(BIO_s_file());
if(out == NULL) /* Error ... */
if(!BIO_write_filename(out, "filename.txt")) /* Error ... */
BIO_printf(out, "Hello World\n");
BIO_free(out);

SEE ALSO

BIO_new(3), BIO_read(3), BIO_seek(3)

HISTORY

BIO_s_file(), BIO_set_fp(), BIO_get_fp(), BIO_read_filename(), BIO_write_filename(), and BIO_append_filename() first appeared in SSLeay 0.6.0. BIO_new_file() and BIO_new_fp() first appeared in SSLeay 0.8.0. All these functions have been available since OpenBSD 2.4.

BIO_rw_filename() first appeared in SSLeay 0.9.1 and has been available since OpenBSD 2.6.

BUGS

BIO_reset(3) and BIO_seek(3) are implemented using fseek(3) on the underlying stream. The return value for fseek(3) is 0 for success or -1 if an error occurred. This differs from other types of BIO which will typically return 1 for success and a non-positive value if an error occurred.
