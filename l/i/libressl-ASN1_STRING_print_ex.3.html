الاسم

ASN1_STRING_print_ex، ASN1_STRING_print_ex_fp، ASN1_STRING_print، ASN1_tag2str — روتينات إخراج ASN1_STRING

الملخص

مكتبة «libcrypto»
#include <openssl/asn1.h>

int
ASN1_STRING_print_ex(BIO *out، const ASN1_STRING *str، unsigned long flags);

int
ASN1_STRING_print_ex_fp(FILE *fp، const ASN1_STRING *str، unsigned long flags);

int
ASN1_STRING_print(BIO *out، const ASN1_STRING *str);

const char *
ASN1_tag2str(int tag);

الوصف

تقوم هذه الدوال بإخراج بنية ASN1_STRING. تستخدم ASN1_STRING لتمثيل جميع أنواع سلاسل ASN.1.

ASN1_STRING_print_ex() تقوم بإخراج str إلى out، ويتم تحديد التنسيق بواسطة الخيارات flags. ASN1_STRING_PRINT_EX_FP() متطابقة باستثناء أنها تخرج إلى fp بدلاً من ذلك.

ASN1_STRING_PRINT() تطبع str إلى out ولكن باستخدام تنسيق مختلف عن ASN1_STRING_PRINT_EX(). تستبدل الأحرف غير القابلة للطباعة (باستثناء CR، LF) بـ ‘.’.

ASN1_tag2str() ترجع اسمًا يمكن قراءته بواسطة الإنسان لـ ASN.1 tag المحدد.

ASN1_STRING_PRINT() هي دالة مهملة يجب تجنبها؛ استخدم ASN1_STRING_PRINT_EX() بدلاً من ذلك.

على الرغم من وجود عدد كبير من الخيارات، فإن ASN1_STRFLGS_RFC2253 غالبًا ما يكون مناسبًا، أو على أطراف UTF-8 ASN1_STRFLGS_RFC2253 و ~ASN1_STRFLGS_ESC_MSB.

مجموعة الخيارات الكاملة المدعومة لـ flags مدرجة أدناه.

يمكن الهروب من أحرف مختلفة. إذا تم تعيين ASN1_STRFLGS_ESC_2253، فسيتم الهروب من الأحرف التي تحددها RFC 2253. إذا تم تعيين ASN1_STRFLGS_ESC_CTRL، فسيتم الهروب من أحرف التحكم. إذا تم تعيين ASN1_STRFLGS_ESC_MSB، فسيتم الهروب من الأحرف ذات MSB المحدد: لا ينبغي استخدام هذا الخيار إذا كانت المحطة الطرفية تفسر تسلسلات UTF-8 بشكل صحيح.

يأخذ الهروب عدة أشكال. إذا كان الحرف الذي يتم الهروب منه حرفًا بحجم 16 بت، فسيتم استخدام النموذج ""\UXXXX"" باستخدام أربعة أحرف بالضبط للتمثيل الست عشري. إذا كان 32 بت، فسيتم استخدام ""\WXXXXXXXX"" باستخدام ثمانية أحرف من تمثيله الست عشري. لن يتم استخدام هذه النماذج إلا إذا لم يتم تعيين تحويل UTF-8 (انظر أدناه).

عادةً ما يتم الهروب من الأحرف القابلة للطباعة باستخدام الشرطة المائلة العكسية (‘\’) حرف. إذا تم تعيين ASN1_STRFLGS_ESC_QUOTE، فسيتم إحاطة السلسلة بأكملها بدلاً من ذلك بعلامات اقتباس مزدوجة: هذا ربما يكون أكثر قابلية للقراءة من ترميز الشرطة المائلة العكسية. تستخدم الأحرف الأخرى ""\XX"" باستخدام حرفين بالضبط من التمثيل الست عشري.

إذا تم تعيين ASN1_STRFLGS_UTF8_CONVERT، فسيتم تحويل الأحرف إلى تنسيق UTF-8 أولاً. إذا كانت المحطة الطرفية تدعم عرض تسلسلات UTF-8، فسيقوم هذا الخيار بعرض الأحرف متعددة البايت بشكل صحيح.

إذا تم تعيين ASN1_STRFLGS_IGNORE_TYPE، فلن يتم تفسير نوع السلسلة على الإطلاق: يفترض أن كل شيء هو بايت واحد لكل حرف. هذا لأغراض التصحيح بشكل أساسي ويمكن أن يؤدي إلى إخراج مربك في السلاسل متعددة الأحرف.

إذا تم تعيين ASN1_STRFLGS_SHOW_TYPE، فسيتم طباعة نوع السلسلة نفسه قبل قيمته (على سبيل المثال "BMPSTRING")، باستخدام ASN1_tag2str().

بدلاً من تفسير محتويات السلسلة، يمكن "تفريغها": وهذا ببساطة يخرج قيمة السلسلة باستخدام النموذج #XXXX باستخدام التنسيق الست عشري لكل ثماني.

إذا تم تعيين ASN1_STRFLGS_DUMP_ALL، فسيتم تفريغ أي نوع.

عادةً ما تفترض أنواع السلاسل غير الحرفية (مثل OCTET STRING) بايت واحد لكل حرف؛ إذا تم تعيين ASN1_STRFLGS_DUMP_UNKNOWN، فسيتم تفريغها بدلاً من ذلك.

عند تفريغ نوع ما بشكل طبيعي، تتم طباعة البايتات المحتوى فقط؛ إذا تم تعيين ASN1_STRFLGS_DUMP_DER، فسيتم تفريغ الترميز الكامل بدلاً من ذلك (بما في ذلك البايتات الخاصة بالعلامة والطول).

ASN1_STRFLGS_RFC2253 تتضمن جميع العلامات المطلوبة بواسطة RFC 2253. وهي تعادل ASN1_STRFLGS_ESC_2253 | ASN1_STRFLGS_ESC_CTRL | ASN1_STRFLGS_ESC_MSB | ASN1_STRFLGS_UTF8_CONVERT | ASN1_STRFLGS_DUMP_UNKNOWN | ASN1_STRFLGS_DUMP_DER.

قيم الإرجاع

ASN1_STRING_print_ex() و ASN1_STRING_print_ex_fp() ترجع عدد الأحرف المكتوبة أو -1 في حالة حدوث خطأ.

ASN1_STRING_print() ترجع 1 عند النجاح أو 0 عند حدوث خطأ.

ASN1_tag2str() ترجع سلسلة ثابتة.

انظر أيضًا

ASN1_parse_dump(3)، ASN1_STRING_new(3)، X509_NAME_print_ex(3)، X509_signature_dump(3)

التاريخ

ASN1_STRING_print() ظهرت لأول مرة في SSLeay 0.6.5 وكانت متاحة منذ OpenBSD 2.4.

ASN1_tag2str() ظهرت لأول مرة في OpenSSL 0.9.5 وكانت متاحة منذ OpenBSD 2.7.

ASN1_STRING_print_ex() و ASN1_STRING_print_ex_fp() ظهرتا لأول مرة في OpenSSL 0.9.6 وكانتا متاحتين منذ OpenBSD 2.9.

    NAME

    ASN1_STRING_print_ex - ASN.1 string print function

    SYNOPSIS

    #include <openssl/asn1.h>

int ASN1_STRING_print_ex(BIO *out, ASN1_STRING *str, unsigned long flags);
int ASN1_STRING_print_ex_fp(FILE *fp, ASN1_STRING *str, unsigned long flags);

    DESCRIPTION

    The ASN1_STRING_print_ex() function prints the contents of the ASN1_STRING structure pointed to by str to the BIO out. The flags parameter controls the output format.

    The ASN1_STRING_print_ex_fp() function is similar, but prints to the FILE pointer fp.

    The following flags can be used:

    ASN1_STRFLGS_UTF8_CONVERT
    If set, attempts to convert the string to UTF8 before printing. If the conversion fails, the original string is printed.
    ASN1_STRFLGS_DUMP_UNKNOWN
    If set, unknown string types are dumped in a hex format.
    ASN1_STRFLGS_SHOW_TYPE
    If set, the type of the string is printed before the string content.
    ASN1_STRFLGS_PRINTABLE
    If set, only printable characters are printed. Non-printable characters are replaced by their hex representation.
    ASN1_STRFLGS_ESCVERBATIM
    If set, escape characters are printed as is, rather than being interpreted.

    It is recommended to use the flag combination ASN1_STRFLGS_UTF8_CONVERT | ASN1_STRFLGS_DUMP_UNKNOWN for general use.

    RETURN VALUES

    ASN1_STRING_print_ex() and ASN1_STRING_print_ex_fp() return 1 on success, and 0 on failure.

    SEE ALSO

    BIO_new(3), ASN1_STRING_new(3)

    HISTORY

    The ASN1_STRING_print_ex() function was added in OpenSSL 0.9.7.

    الاسم

    ASN1_STRING_print_ex - وظيفة طباعة سلسلة ASN.1

    الملخص

    #include <openssl/asn1.h>

int ASN1_STRING_print_ex(BIO *out, ASN1_STRING *str, unsigned long flags);
int ASN1_STRING_print_ex_fp(FILE *fp, ASN1_STRING *str, unsigned long flags);

    الوصف

    تقوم وظيفة ASN1_STRING_print_ex() بطباعة محتويات بنية ASN1_STRING المشار إليها بواسطة str إلى BIO out. يتحكم المعامل flags في تنسيق الإخراج.

    وظيفة ASN1_STRING_print_ex_fp() مشابهة، ولكنها تطبع إلى مؤشر الملف fp.

    يمكن استخدام الأعلام التالية:

    ASN1_STRFLGS_UTF8_CONVERT
    إذا تم تعيينه، يحاول تحويل السلسلة إلى UTF8 قبل الطباعة. إذا فشل التحويل، يتم طباعة السلسلة الأصلية.
    ASN1_STRFLGS_DUMP_UNKNOWN
    إذا تم تعيينه، يتم تفريغ أنواع السلاسل غير المعروفة بتنسيق سداسي عشري.
    ASN1_STRFLGS_SHOW_TYPE
    إذا تم تعيينه، يتم طباعة نوع السلسلة قبل محتوى السلسلة.
    ASN1_STRFLGS_PRINTABLE
    إذا تم تعيينه، يتم طباعة الأحرف القابلة للطباعة فقط. يتم استبدال الأحرف غير القابلة للطباعة بتمثيلها السداسي عشري.
    ASN1_STRFLGS_ESCVERBATIM
    إذا تم تعيينه، يتم طباعة أحرف الهروب كما هي، بدلاً من تفسيرها.

    يوصى باستخدام مجموعة الأعلام ASN1_STRFLGS_UTF8_CONVERT | ASN1_STRFLGS_DUMP_UNKNOWN للاستخدام العام.

    قيم الإرجاع

    تعيد ASN1_STRING_print_ex() و ASN1_STRING_print_ex_fp() القيمة 1 عند النجاح، و 0 عند الفشل.

    انظر أيضًا

    BIO_new(3), ASN1_STRING_new(3)
