libressl-tls_connect(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

TLS_CONNECT(3) دليل وظائف المكتبة TLS_CONNECT(3)

الاسم

tls_connect، tls_connect_fds، tls_connect_servername، tls_connect_socket، tls_connect_cbs — إصدار تعليمات لعميل TLS لإنشاء اتصال

الملخص

المكتبة “libtls” libssl libcrypto
#include <tls.h>

int
tls_connect(struct tls *ctx، const char *host، const char *port)؛

int
tls_connect_fds(struct tls *ctx، int fd_read، int fd_write، const char *servername)؛

int
tls_connect_servername(struct tls *ctx، const char *host، const char *port، const char *servername)؛

int
tls_connect_socket(struct tls *ctx، int s، const char *servername)؛

int
tls_connect_cbs(struct tls *ctx، ssize_t (*tls_read_cb)(struct tls *ctx, void *buf, size_t buflen, void *cb_arg)، ssize_t (*tls_write_cb)(struct tls *ctx, const void *buf, size_t buflen, void *cb_arg)، void *cb_arg، const char *servername)؛

الوصف

بعد إنشاء سياق عميل TLS باستخدام tls_client(3) وتكوينه باستخدام tls_configure(3)، يتم بدء اتصال العميل عن طريق استدعاء tls_connect(). ستقوم هذه الوظيفة بإنشاء مقبس جديد، والاتصال بالمحدد host و port، ثم إنشاء اتصال آمن. قد يكون port رقميًا أو اسم خدمة. إذا كان NULL، فسيتم السماح بـ hosthost.

الدالة tls_connect_servername() لها نفس السلوك، ومع ذلك يتم توفير الاسم المراد استخدامه للتحقق من صحته صراحةً، في حالة اختلاف اسم خادم TLS عن اسم DNS.

يمكن ترقية مقبس موجود بالفعل إلى اتصال آمن عن طريق استدعاء tls_connect_socket().

بدلاً من ذلك، يمكن إنشاء اتصال آمن عبر زوج من واصفات الملفات الموجودة عن طريق استدعاء tls_connect_fds().

استدعاء tls_connect_cbs() يسمح لوظائف رد الاتصال للقراءة والكتابة بمعالجة نقل البيانات. يتم تمرير المعلمة cb_arg المحددة مرة أخرى إلى الوظائف، ويمكن أن تحتوي على مؤشر لأي بيانات يحددها المتصل.

قيم الإرجاع

تعيد هذه الوظائف 0 عند النجاح أو -1 عند حدوث خطأ.

التاريخ

tls_connect() و tls_connect_socket() ظهرت في OpenBSD 5.6 وحصلت على أسمائها النهائية في OpenBSD 5.7.

tls_connect_fds() و tls_connect_servername() ظهرت في OpenBSD 5.7 و tls_connect_cbs() في OpenBSD 6.1.
