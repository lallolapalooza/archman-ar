Detailed Description

Functions to manipulate libalpm packages

Typedef Documentation

typedef struct _alpm_pkg_t alpm_pkg_t

A package. A package can be loaded from disk via alpm_pkg_load or retrieved from a database. Packages from databases are automatically freed when the database is unregistered. Packages loaded from a file must be freed manually.

Packages can then be queried for metadata or added to a transaction to be added or removed from the system.

ALPM_PKG_REASON_DEPEND
Installed as a dependency for another package.
ALPM_PKG_REASON_UNKNOWN

enum alpm_pkgvalidation_t

Method used to validate a package.

Enumerator

ALPM_PKG_VALIDATION_UNKNOWN
The package's validation type is unknown.
ALPM_PKG_VALIDATION_NONE
The package does not have any validation.
ALPM_PKG_VALIDATION_MD5SUM
The package is validated with md5.
ALPM_PKG_VALIDATION_SHA256SUM
The package is validated with sha256.
ALPM_PKG_VALIDATION_SIGNATURE
The package is validated with a PGP signature.

int alpm_pkg_vercmp (const char * a, const char * b)

قارن سلسلتين نصيتين للإصدار وحدد أيهما "أحدث". تُرجع قيمة قابلة للمقارنة مع الطريقة التي يعمل بها strcmp. تُرجع 1 إذا كان a أحدث من b، و 0 إذا كان a و b لهما نفس الإصدار، أو -1 إذا كان b أحدث من a.

ستتجاوز قيم الحقبة المختلفة لسلاسل الإصدارات أي مقارنة أخرى. إذا لم يتم توفير حقبة، فسيتم افتراض 0.

ضع في اعتبارك أن pkgrel تتم مقارنته فقط إذا كان متاحًا على كلا الإصدارين المقدمين لهذه الوظيفة. على سبيل المثال، مقارنة 1.5-1 و 1.5 ستؤدي إلى 0؛ مقارنة 1.5-1 و 1.5-2 ستؤدي إلى -1 كما هو متوقع. هذا هو أساسًا لدعم تبعيات الإصدارات التي لا تتضمن pkgrel.

    DESCRIPTION

    The libalpm package management library provides an interface to query package information and manipulate packages. The functions detailed in this man page allow you to retrieve lists of packages, access individual package details, and query dependency information.

    alpm_get_packages() fetches all installed and available packages from all configured repositories.

    alpm_get_local_packages() fetches only installed packages.

    alpm_get_foreign_packages() fetches only packages that are installed but not available in any configured repository (e.g., manually installed packages).

    alpm_get_pkg() retrieves a specific package from a given package list by its name.

    alpm_get_pkg_local() retrieves a specific installed package by its name.

    alpm_get_pkg_remote() retrieves a specific package from a specified repository by its name.

    The following functions retrieve specific attributes of a package:

    alpm_pkg_get_name(), alpm_pkg_get_version(), alpm_pkg_get_base(), alpm_pkg_get_desc(), alpm_pkg_get_url(), alpm_pkg_get_build_date(), alpm_pkg_get_packager(), alpm_pkg_get_arch(), alpm_pkg_get_license(), alpm_pkg_get_groups(), alpm_pkg_get_depends(), alpm_pkg_get_optdepends(), alpm_pkg_get_makepends(), alpm_pkg_get_checkdepends(), alpm_pkg_get_provides(), alpm_pkg_get_conflicts(), alpm_pkg_get_replaces(), alpm_pkg_get_size(), alpm_pkg_get_isize(), alpm_pkg_get_md5sum(), alpm_pkg_get_sha256sum(), alpm_pkg_get_filename(), alpm_pkg_get_path(), alpm_pkg_get_reason().

    alpm_pkg_get_flag() checks if a specific flag is set for the package. Possible flags are defined in alpm_flags_t (see alpm.h).

    The following functions retrieve lists of dependencies for a package:

    alpm_pkg_get_deps(), alpm_pkg_get_opt_deps(), alpm_pkg_get_make_deps(), alpm_pkg_get_check_deps(), alpm_pkg_get_provides_list(), alpm_pkg_get_conflicts_list(), alpm_pkg_get_replaces_list().

    The returned lists are of type alpm_list_t, where each element is a pointer to the respective structure (alpm_depend_t, alpm_target_t, etc.).

    The following functions are used to access information about dependencies:

    alpm_get_depend() retrieves a specific dependency from a list by its name.

    alpm_depend_get_name(), alpm_depend_get_version(), alpm_depend_get_condition(), alpm_depend_get_dependency(), alpm_depend_get_reason(), alpm_depend_get_dependency_reason().

    These functions retrieve attributes of a dependency object.

    RETURN VALUE

    On success, these functions return pointers to the requested data or lists. On failure, they return NULL or an empty list.
