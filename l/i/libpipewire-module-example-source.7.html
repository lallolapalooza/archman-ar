libpipewire-module-example-source(7) دليل معلومات متنوعة libpipewire-module-example-source(7)

الاسم

libpipewire-module-example-source - مصدر مثال

الوصف

مصدر المثال هو نقطة انطلاق جيدة لكتابة مصدر مخصص.

نشير إلى الكود المصدري لمزيد من المعلومات.

اسم الوحدة

libpipewire-module-example-source

خيارات الوحدة

  • node.name: اسم فريد للبث
  • node.description: اسم مقروء للبث
  • stream.props = {}: خصائص يتم تمريرها إلى البث

خيارات عامة

خيارات ذات سلوك معروف جيدًا.

  • remote.name
  • audio.format
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class

مثال للتكوين

# ~/.config/pipewire/pipewire.conf.d/my-example-source.conf
context.modules = [
{   name = libpipewire-module-example-source
    args = {
        node.name = "example_source"
        node.description = "My Example Source"
        stream.props = {
            audio.position = [ FL FR ]
        }
    }
}
]
