libressl-SSL_get_ciphers(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_GET_CIPHERS(3) دليل وظائف المكتبة SSL_GET_CIPHERS(3)

الاسم

SSL_get_ciphers، SSL_CTX_get_ciphers، SSL_get1_supported_ciphers، SSL_get_client_ciphers، SSL_get_cipher_list — الحصول على قوائم SSL_CIPHERs المتاحة

الملخص

المكتبة “libssl” libcrypto
#include <openssl/ssl.h>

STACK_OF(SSL_CIPHER) *
SSL_get_ciphers(const SSL *ssl);

STACK_OF(SSL_CIPHER) *
SSL_CTX_get_ciphers(const SSL_CTX *ctx);

STACK_OF(SSL_CIPHER) *
SSL_get1_supported_ciphers(SSL *ssl);

STACK_OF(SSL_CIPHER) *
SSL_get_client_ciphers(const SSL *ssl);

const char *
SSL_get_cipher_list(const SSL *ssl, int priority);

الوصف

SSL_get_ciphers() تعيد المكدس المتاح لـ SSL_CIPHERs لـ ssl، مرتبة حسب الأفضلية.

SSL_CTX_get_ciphers() تعيد المكدس المتاح لـ SSL_CIPHERs لـ ctx.

SSL_get1_supported_ciphers() تعيد مكدسًا لـ SSL_CIPHERs الممكّنة لـ ssl كما سيتم إرسالها في ClientHello، مرتبة حسب الأفضلية. تعتمد القائمة على إعدادات مثل قائمة التشفير، وإصدارات البروتوكول المدعومة، ومستوى الأمان، وخوارزميات التوقيع الممكّنة. قد تختلف قائمة التشفيرات التي سيتم إرسالها في ClientHello عن قائمة التشفيرات التي ستكون مقبولة عند العمل كخادم. على سبيل المثال، قد تكون التشفيرات الإضافية قابلة للاستخدام من قبل خادم إذا كانت هناك فجوة في قائمة البروتوكولات المدعومة، وقد لا تكون بعض التشفيرات قابلة للاستخدام من قبل خادم إذا لم يتم تكوين شهادة مناسبة.

SSL_get_client_ciphers() تعيد المكدس المتاح لـ SSL_CIPHERs التي تطابق القائمة المستلمة من العميل على ssl.

يمكن الحصول على تفاصيل التشفيرات التي تم الحصول عليها بواسطة SSL_get_ciphers()، SSL_CTX_get_ciphers()، SSL_get1_supported_ciphers()، و SSL_get_client_ciphers() باستخدام عائلة وظائف SSL_CIPHER_get_name(3).

SSL_get_cipher_list() تم إيقافه — استخدم SSL_get_ciphers() بدلاً من ذلك — وتم تسميته بشكل خاطئ؛ فهو لا يعيد قائمة بل اسم عنصر واحد من القيمة المرجعة لـ SSL_get_ciphers()، مع الفهرس المعطى بواسطة المعامل priority. تمرير 0 يحدد التشفير ذو الأولوية الأعلى. للتكرار عبر جميع التشفيرات المتاحة بترتيب تنازلي للأولوية، قم بزيادة المعامل بشكل متكرر بمقدار 1 حتى يتم إرجاع NULL.

قيم الإرجاع

SSL_get_ciphers() تعيد مؤشرًا داخليًا إلى قائمة تشفيرات أو NULL إذا كان ssl هو NULL أو إذا لم تكن التشفيرات متاحة. قد يصبح المؤشر المرجع غير صالح ليس فقط عندما يتم تدمير ssl أو عند استدعاء SSL_set_cipher_list(3) عليه، ولكن أيضًا عندما يتم تحرير كائن SSL_CTX المستخدم بواسطة ssl في وقت الاستدعاء أو عند استدعاء SSL_CTX_set_cipher_list(3) على كائن السياق هذا.

SSL_CTX_get_ciphers() تعيد مؤشرًا داخليًا إلى قائمة تشفيرات أو NULL إذا كان ctx هو NULL أو إذا لم تكن التشفيرات متاحة. يصبح المؤشر المرجع غير صالح عندما يتم تدمير ctx أو عند استدعاء SSL_CTX_set_cipher_list(3) عليه.

SSL_get1_supported_ciphers() تعيد قائمة مشكلة حديثًا من التشفيرات أو NULL إذا كان ssl هو NULL، أو إذا لم تكن التشفيرات متاحة، أو إذا حدث خطأ. عندما لم يعد المؤشر المرجع مطلوبًا، يكون المتصل مسؤولاً عن تحريره باستخدام sk_SSL_CIPHER_free().

SSL_get_client_ciphers() تعيد مؤشرًا داخليًا إلى قائمة تشفيرات أو NULL إذا كان ssl هو NULL، أو لا يمتلك جلسة نشطة، أو لا يعمل في وضع الخادم. يصبح المؤشر المرجع غير صالح عندما يتم تدمير كائن SSL_SESSION، حتى لو ظل كائن ssl صالحًا. قد يصبح أيضًا غير صالح في ظروف أخرى، على سبيل المثال عند معالجة ClientHello جديد.

SSL_get_cipher_list() تعيد مؤشرًا داخليًا إلى سلسلة نصية أو NULL إذا كان ssl هو NULL، أو إذا لم تكن التشفيرات متاحة، أو إذا كان priority أكبر من أو يساوي عدد التشفيرات المتاحة.

انظر أيضًا

ssl(3)، SSL_CIPHER_get_name(3)، SSL_CTX_set_cipher_list(3)

التاريخ

SSL_get_cipher_list() ظهرت لأول مرة في SSLeay 0.5.2. SSL_get_ciphers() ظهرت لأول مرة في SSLeay 0.8.0. كانت كلتا الوظيفتين متاحتين منذ OpenBSD 2.4.

SSL_CTX_get_ciphers() ظهرت لأول مرة في OpenSSL 1.1.0 وكانت متاحة منذ OpenBSD 6.3.

SSL_get1_supported_ciphers() و SSL_get_client_ciphers() ظهرتا لأول مرة في OpenSSL 1.1.0 وكانتا متاحتين منذ OpenBSD 6.5.

NAME

SSL_get_ciphers, SSL_set_ciphers, SSL_get_client_ciphers, SSL_set_client_ciphers, SSL_get_server_ciphers, SSL_set_server_ciphers, SSL_get_cipher_list, SSL_set_cipher_list, SSL_get_client_CA_list, SSL_add_client_CA, SSL_CTX_get_client_CA_list, SSL_CTX_add_client_CA, SSL_get_shared_ciphers, SSL_CIPHER_get_name, SSL_CIPHER_get_id, SSL_CIPHER_get_bits, SSL_CIPHER_get_version, SSL_CIPHER_description, SSL_CIPHER_number, SSL_CIPHER_find

DESCRIPTION

The function SSL_get_ciphers returns a STACK_OF(SSL_CIPHER) containing the list of ciphers that the SSL/TLS library will negotiate for the given SSL object.

The function SSL_set_ciphers sets the cipher list for the given SSL object. The caller must ensure that the provided STACK_OF(SSL_CIPHER) is correctly managed (e.g., using sk_SSL_CIPHER_new and sk_SSL_CIPHER_push).

SSL_get_client_ciphers and SSL_set_client_ciphers retrieve and set the client's cipher list, respectively.

SSL_get_server_ciphers and SSL_set_server_ciphers retrieve and set the server's cipher list, respectively.

SSL_get_cipher_list retrieves the cipher at index n from the SSL object's cipher list.

SSL_set_cipher_list sets the cipher list using a string format. The string is a comma-separated list of cipher suites, potentially with modifiers (e.g., "HIGH:!aNULL:!MD5").

SSL_get_client_CA_list returns a STACK_OF(X509_NAME) containing the list of distinguished names of Certificate Authorities that the SSL object will present to the client during the handshake.

SSL_add_client_CA adds a client CA distinguished name to the list for the given SSL object.

SSL_CTX_get_client_CA_list and SSL_CTX_add_client_CA work similarly but operate on the SSL_CTX object, affecting all SSL objects created from that context.

SSL_get_shared_ciphers is used to determine the set of ciphers that are mutually supported by both the client and the server. It takes the client's cipher list and returns the server's cipher list. The intersection of these two lists is the set of shared ciphers. The result is stored in shared_ciphers and server_ciphers.

SSL_CIPHER_get_name returns the name of the cipher suite.

SSL_CIPHER_get_id returns the unique identifier of the cipher suite.

SSL_CIPHER_get_bits returns the number of non-keying bits of the cipher. If alg_bits is not NULL, it will be set to the number of keying bits.

SSL_CIPHER_get_version returns the protocol version associated with the cipher suite.

SSL_CIPHER_description returns a human-readable description of the cipher suite. The description is written into the buffer buf of size len.

SSL_CIPHER_number returns the numerical identifier of the cipher suite.

SSL_CIPHER_find finds an SSL_CIPHER object corresponding to the given cipher name.

RETURN VALUES

SSL_get_ciphers, SSL_get_client_ciphers, SSL_get_server_ciphers, SSL_get_client_CA_list, SSL_CTX_get_client_CA_list, and SSL_get_shared_ciphers return a pointer to a STACK_OF(SSL_CIPHER) or STACK_OF(X509_NAME), or NULL on error.

SSL_set_ciphers, SSL_set_client_ciphers, SSL_set_server_ciphers, SSL_set_cipher_list, and SSL_CTX_add_client_CA return 1 on success, and 0 or -1 on error.

SSL_CIPHER_get_name, SSL_CIPHER_get_version, and SSL_CIPHER_description return a pointer to a string, or NULL on error.

SSL_CIPHER_get_id, SSL_CIPHER_get_bits, SSL_CIPHER_number return integer values.

SSL_CIPHER_find returns a pointer to an SSL_CIPHER object, or NULL if the cipher is not found.

DIAGNOSTICS

Errors can occur due to invalid cipher lists, memory allocation failures, or issues during the SSL/TLS handshake. Specific error details can be obtained using the OpenSSL error handling functions (e.g., ERR_get_error).

EXAMPLE

Setting a cipher list: 

SSL_CTX *ctx;
// ... initialize ctx ...
if (SSL_CTX_set_cipher_list(ctx, "DEFAULT:!aNULL:!eNULL") != 1) {
    // handle error
}

Getting the cipher list: 

SSL *ssl;
// ... initialize ssl ...
const STACK_OF(SSL_CIPHER) *ciphers = SSL_get_ciphers(ssl);
for (int i = 0; i < sk_SSL_CIPHER_num(ciphers); i++) {
    const SSL_CIPHER *cipher = sk_SSL_CIPHER_value(ciphers, i);
    printf("Cipher: %s\n", SSL_CIPHER_get_name(cipher));
}
