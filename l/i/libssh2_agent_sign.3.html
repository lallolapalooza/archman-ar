libssh2_agent_sign(3)

الحزمة: libssh2

التراخيص: BSD

libssh2_agent_sign(3) libssh2 libssh2_agent_sign(3)

الاسم

libssh2_agent_sign - توقيع البيانات، بمساعدة ssh-agent

التركيب

#include <libssh2.h>
int
libssh2_agent_sign(LIBSSH2_AGENT *agent,
                   struct libssh2_agent_publickey *identity,
                   unsigned char **sig,
                   size_t *s_len,
                   const unsigned char *data,
                   size_t d_len,
                   const char *method,
                   unsigned int method_len);

الوصف

agent - مقبض ssh-agent كما تم إرجاعه بواسطة libssh2_agent_init(3)

identity - المفتاح العام للمصادقة به، كما تم إرجاعه بواسطة libssh2_agent_get_identity(3)

sig - مؤشر إلى مخزن مؤقت لوضع التوقيع فيه. المسؤولية عن تحرير التوقيع تقع على المتصل باستخدام LIBSSH2_FREE.

s_len - مؤشر إلى طول المعلمة sig.

data - البيانات المراد توقيعها.

d_len - طول المعلمة data.

method - مخزن مؤقت يشير إلى طريقة التوقيع. يجب أن يتطابق هذا مع السلسلة النصية في بداية identity->blob.

method_len - طول المعلمة method.

قم بتوقيع البيانات باستخدام ssh-agent. يمكن استخدام هذه الدالة في رد اتصال مسجل باستخدام libssh2_session_callback_set2(3) باستخدام LIBSSH2_CALLBACK_AUTHAGENT_SIGN لتوقيع تحدي مصادقة من الخادم. ومع ذلك، فإن العميل مسؤول عن تنفيذ الكود الذي يستدعي رد الاتصال هذا استجابة لرسالة SSH2_AGENTC_SIGN_REQUEST.

قيمة الإرجاع

تُرجع 0 في حالة النجاح، أو قيمة سالبة في حالة الخطأ.

التوفر
