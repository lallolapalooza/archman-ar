List::Util(3perl) دليل مبرمج Perl List::Util(3perl)

NAME

List::Util - مجموعة من دوال القوائم المساعدة العامة

SYNOPSIS

use List::Util qw(
  reduce any all none notall first reductions
  max maxstr min minstr product sum sum0
  pairs unpairs pairkeys pairvalues pairfirst pairgrep pairmap
  shuffle uniq uniqint uniqnum uniqstr head tail zip mesh
);

DESCRIPTION

"List::Util" يحتوي على مجموعة مختارة من الدوال التي يجد المستخدمون أنها مرغوبة لتضمينها في نواة Perl، ولكن استخدامها لن يكون مرتفعًا بما يكفي لتبرير استخدام كلمة رئيسية، وحجمها صغير جدًا بحيث يكون الامتدادات الفردية غير فعال.

بشكل افتراضي، "List::Util" لا يقوم بتصدير أي من هذه الدوال.

دوال اختزال القائمة

تطبق الدوال التالية كتلة كود على قائمة من القيم.

reduce

$result = reduce { BLOCK } @list

يختزل @list عن طريق استدعاء "BLOCK" في سياق قياسي عدة مرات، وتعيين $a و $b في كل مرة. سيكون الاستدعاء الأول له $a و $b معينين لأول عنصرين في القائمة، بينما سيتم إجراء الاستدعاءات اللاحقة عن طريق تعيين $a إلى نتيجة الاستدعاء السابق و $b إلى العنصر التالي في القائمة.

يعيد نتيجة آخر استدعاء لـ "BLOCK". إذا كانت @list فارغة، يتم إرجاع "undef". إذا كانت @list تحتوي على عنصر واحد فقط، يتم إرجاع هذا العنصر ولا يتم تنفيذ "BLOCK".

توضح الأمثلة التالية كيف يمكن استخدام "reduce" لتنفيذ دوال اختزال القائمة في هذه الوحدة. (لا يتم تنفيذها بهذه الطريقة، ولكن بطريقة أكثر كفاءة في دوال C فردية).

$foo = reduce { defined($a)            ? $a :
                $code->(local $_ = $b) ? $b :
                                         undef } undef, @list # first
$foo = reduce { $a > $b ? $a : $b } 1..10       # max
$foo = reduce { $a gt $b ? $a : $b } 'A'..'Z'   # maxstr
$foo = reduce { $a < $b ? $a : $b } 1..10       # min
$foo = reduce { $a lt $b ? $a : $b } 'aa'..'zz' # minstr
$foo = reduce { $a + $b } 1 .. 10               # sum
$foo = reduce { $a . $b } @bar                  # concatenate
$foo = reduce { $a || $code->(local $_ = $b) } 0, @bar   # any
$foo = reduce { $a && $code->(local $_ = $b) } 1, @bar   # all
$foo = reduce { $a && !$code->(local $_ = $b) } 1, @bar  # none
$foo = reduce { $a || !$code->(local $_ = $b) } 0, @bar  # notall
   # لاحظ أن هذه التنفيذات لا تتوقف تمامًا

إذا كان الخوارزم الخاص بك يتطلب أن ينتج "reduce" قيمة هوية، فتأكد دائمًا من تمرير هذه القيمة كوسيط أول لتجنب إرجاع "undef".

$foo = reduce { $a + $b } 0, @values;             # sum مع قيمة الهوية 0

تقترح كتل الكود أعلاه أيضًا كيفية استخدام "reduce" لإنشاء نسخة مجمعة أكثر كفاءة من إحدى هذه الدوال الأساسية وكتلة "map". على سبيل المثال، لحساب الطول الإجمالي لجميع السلاسل في قائمة، يمكننا استخدام

$total = sum map { length } @strings;

ومع ذلك، تنتج هذه الطريقة قيمًا مؤقتة من نوع العدد الصحيح للطول كالأصل من قوائم السلاسل، فقط لاختزالها مرة أخرى إلى قيمة واحدة. يمكننا حساب نفس النتيجة بكفاءة أكبر باستخدام "reduce" مع كتلة كود تتراكم الأطوال بكتابة هذا بدلاً من:

$total = reduce { $a + length $b } 0, @strings

الدوال الأخرى لاختزال القائمة التي تعيد قيمًا قياسية هي تخصصات لهذه الفكرة العامة.

reductions

@results = reductions { BLOCK } @list

من الإصدار 1.54.

على غرار "reduce"، ولكنه يعيد أيضًا القيم الوسيطة جنبًا إلى جنب مع النتيجة النهائية. كما هو الحال من قبل، يتم تعيين $a إلى العنصر الأول في القائمة المعطاة، ويتم استدعاء كتلة "BLOCK" مرة واحدة لكل عنصر متبقٍ في القائمة، مع التقاط النتيجة لإرجاعها بالإضافة إلى القيمة الجديدة لـ $a.

ستبدأ القائمة المرجعة بقيمة $a الأولية، متبوعة بكل قيمة يعيدها الكتلة بالترتيب. ستكون القيمة النهائية للنتيجة مطابقة لما كانت ستعيده الدالة "reduce" بالنظر إلى نفس الكتلة والقائمة.

reduce     { "$a-$b" }  "a".."d"    # "a-b-c-d"
reductions { "$a-$b" }  "a".."d"    # "a", "a-b", "a-b-c", "a-b-c-d"

any

my $bool = any { BLOCK } @list;

من الإصدار 1.33.

على غرار "grep"، يقوم بتقييم "BLOCK" عن طريق تعيين $_ لكل عنصر في @list بالترتيب. يعيد "any" قيمة صحيحة إذا جعل أي عنصر "BLOCK" يعيد قيمة صحيحة. إذا لم يعد "BLOCK" أبدًا قيمة صحيحة أو كانت @list فارغة، فإنه يعيد قيمة خاطئة.

يمكن كتابة العديد من حالات استخدام "grep" في الشروط الشرطية باستخدام "any"، حيث يمكن أن يتوقف عن العمل بعد النتيجة الصحيحة الأولى.

if( any { length > 10 } @strings ) {
    # على الأقل سلسلة واحدة أطول من 10 أحرف
}

ملاحظة: بسبب مشكلات XS، يمكن للكتلة الممررة الوصول مباشرة إلى @_ الخارجي. هذا ليس مقصودًا وقد يتعطل تحت المصحح.

all

my $bool = all { BLOCK } @list;

من الإصدار 1.33.

على غرار "any"، ولكنه يتطلب أن تجعل جميع العناصر في @list "BLOCK" يعيد قيمة صحيحة. إذا أعاد أي عنصر قيمة خاطئة، فإنه يعيد قيمة خاطئة. إذا لم يعد "BLOCK" أبدًا قيمة خاطئة أو كانت @list فارغة، فإنه يعيد قيمة صحيحة.

ملاحظة: بسبب مشكلات XS، يمكن للكتلة الممررة الوصول مباشرة إلى @_ الخارجي. هذا ليس مقصودًا وقد يتعطل تحت المصحح.

none

notall

my $bool = none { BLOCK } @list;
my $bool = notall { BLOCK } @list;

من الإصدار 1.33.

على غرار "any" و "all"، ولكن مع عكس معنى الإرجاع. يعيد "none" قيمة صحيحة فقط إذا لم يجعل أي قيمة في @list "BLOCK" يعيد قيمة صحيحة، ويعيد "notall" قيمة صحيحة فقط إذا لم تفعل جميع القيم ذلك.

ملاحظة: بسبب مشكلات XS، يمكن للكتلة الممررة الوصول مباشرة إلى @_ الخارجي. هذا ليس مقصودًا وقد يتعطل تحت المصحح.

first

my $val = first { BLOCK } @list;

على غرار "grep"، يقوم بتقييم "BLOCK" عن طريق تعيين $_ لكل عنصر في @list بالترتيب. يعيد "first" العنصر الأول حيث تكون نتيجة "BLOCK" قيمة صحيحة. إذا لم يعد "BLOCK" أبدًا قيمة صحيحة أو كانت @list فارغة، فإنه يعيد "undef".

ملاحظة: بسبب مشكلات XS، يمكن للكتلة الممررة الوصول مباشرة إلى @_ الخارجي. هذا ليس مقصودًا وقد يتعطل تحت المصحح.
