libressl-des_read_pw(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

DES_READ_PW(3) دليل وظائف المكتبة DES_READ_PW(3)

الاسم

EVP_read_pw_string، EVP_read_pw_string_min، EVP_set_pw_prompt، EVP_get_pw_prompt — وظائف واجهة مستخدم توافقية

الملخص

المكتبة “libcrypto”
#include <openssl/evp.h>

int
EVP_read_pw_string(char *buf، int length، const char *prompt، int verify);

int
EVP_read_pw_string_min(char *buf، int min_length، int length، const char *prompt، int verify);

void
EVP_set_pw_prompt(const char *default_prompt);

char *
EVP_get_pw_prompt(void);

الوصف

EVP_read_pw_string() تكتب prompt إلى /dev/tty، أو، إذا تعذر فتحها، إلى الإخراج القياسي، وتقوم بإيقاف عرض الأحرف، وتقرأ سلسلة إدخال من /dev/tty، أو، إذا تعذر فتحها، من الإدخال القياسي. يتم إرجاع السلسلة في buf، والذي يجب أن يحتوي على مساحة لـ length بايت على الأقل. إذا تجاوزت الوسيطة length BUFSIZ، يتم استخدام BUFSIZ بدلاً من ذلك. إذا تم تعيين verify، يُطلب من المستخدم كلمة المرور مرتين وما لم يتطابق النسختان، يتم إرجاع خطأ.

EVP_read_pw_string_min() تتحقق بالإضافة إلى ذلك من أن كلمة المرور لا تقل عن min_length بايت.

EVP_set_pw_prompt() تقوم بتعيين مطالبة افتراضية لنسخة من default_prompt، أو تمسح المطالبة الافتراضية إذا كانت الوسيطة default_prompt هي NULL أو سلسلة فارغة. إذا كانت الوسيطة default_prompt أطول من 79 بايت، يتم اقتطاع النسخة بصمت إلى طول سلسلة يبلغ 79 بايت.

طالما تم تعيين مطالبة افتراضية، يمكن استدعاء EVP_read_pw_string() و EVP_read_pw_string_min() مع وسيطة prompt تبلغ NULL، وفي هذه الحالة يتم استخدام المطالبة الافتراضية بدلاً من ذلك.

قيم الإرجاع

EVP_read_pw_string() و EVP_read_pw_string_min() ترجع 0 عند النجاح أو قيمة سالبة عند الفشل.

تُرجع -1 إذا كانت length أقل من أو تساوي صفرًا أو عند فشل تخصيص الذاكرة. تُرجع -1 أو -2 إذا فشل الاستدعاء الداخلي لـ UI_process(3).

بالإضافة إلى ذلك، تُرجع EVP_read_pw_string_min -1 إذا كانت min_length سالبة، أو إذا كانت length أقل من أو تساوي min_length، أو إذا أدخل المستخدم كلمة مرور أقصر من min_length.

EVP_get_pw_prompt() تُرجع مؤشرًا داخليًا إلى ذاكرة ثابتة تحتوي على المطالبة الافتراضية، أو NULL إذا لم يتم تعيين مطالبة افتراضية.

انظر أيضًا

التاريخ

EVP_read_pw_string() ظهرت لأول مرة في SSLeay 0.5.1 و EVP_set_pw_prompt() و EVP_get_pw_prompt() في SSLeay 0.6.0. كانت هذه الوظائف متاحة منذ OpenBSD 2.4.

EVP_read_pw_string_min() ظهرت لأول مرة في OpenSSL 1.0.0 وكانت متاحة منذ OpenBSD 4.9.
