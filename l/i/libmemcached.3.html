الاسم

libmemcached - مكتبة عميل C/C++ لخادم memcached

الملخص

#include <libmemcached/memcached.h>
قم بالترجمة والربط مع -lmemcached


----



تم تصميم libmemcached لتوفير أكبر عدد من الخيارات لاستخدام Memcached. بعض الميزات المتوفرة:

1.
دعم النقل المتزامن وغير المتزامن.
2.
التجزئة المتسقة والتوزيع.
3.
خوارزمية تجزئة قابلة للتعديل لمطابقة المفاتيح.
4.
الوصول إلى دعم الكائنات الكبيرة.
5.
النسخ المتماثل المحلي.
6.
دليل مرجعي كامل وتوثيق لواجهة برمجة التطبيقات (API).
7.
أدوات لإدارة شبكات Memcached الخاصة بك.

الوصف

libmemcached هي مكتبة عميل صغيرة وآمنة في الاستخدام المتزامن (thread-safe) لبروتوكول memcached. تمت كتابة جميع التعليمات البرمجية للسماح بالاستخدام عبر الويب والاستخدام المضمن. تتعامل مع العمل خلف الكواليس لتوجيه المفاتيح الفردية إلى خوادم محددة يحددها المطور (وتتم مطابقة القيم بناءً على ترتيب الخوادم كما يقدمها المستخدم). إنها تنفذ طريقة معيارية ومتسقة لتوزيع الكائنات.

هناك طرق متعددة للتوجيه والتجزئة مطبقة. راجع صفحة الدليل memcached_behavior_set() لمزيد من المعلومات.

يتم إجراء جميع العمليات مقابل بنية memcached_st. يمكن تخصيص هذه البنى ديناميكيًا أو تخصيصها ثابتًا ثم تهيئتها بواسطة memcached_create(). تمت كتابة وظائف لتغليف memcached_st. لا يُنصح بالعمل مباشرة على البنية.

تعيد جميع الوظائف تقريبًا قيمة من نوع memcached_return_t. يمكن ترجمة هذه القيمة إلى سلسلة نصية قابلة للطباعة باستخدام memcached_strerror().

يتم تخزين الكائنات على الخوادم عن طريق تجزئة المفاتيح. ترتبط قيمة التجزئة بمفتاح معين بخادم معين. تفهم جميع العملاء كيفية عمل هذه التجزئة، لذا من الممكن بشكل موثوق إرسال البيانات إلى خادم واسترداد البيانات من خادم.

يمكن استخدام مفاتيح المجموعات اختياريًا لتجميع مجموعات من الكائنات مع الخوادم.

يتم دعم مساحات الأسماء، ويمكن استخدامها لتقسيم ذاكرة التخزين المؤقت بحيث يمكن لتطبيقات متعددة استخدام نفس خوادم memcached.

يجب تمكين بعض ميزات المكتبة من خلال memcached_behavior_set().

الخيوط والعمليات

لا يتم استخدام متغيرات عامة في هذه المكتبة.

بنى memcached_st آمنة في الاستخدام المتزامن (thread-safe)، ولكن عند استخدام الخيوط أو العمليات المتفرعة، من المهم الاحتفاظ بنسخة واحدة من memcached_st لكل عملية أو خيط. بدون إنشاء هياكل قفل خاصة بك، لا يمكنك مشاركة memcached_st واحدة. ومع ذلك، يمكنك استدعاء memcached_quit() على memcached_st ثم استخدام البنية المستنسخة الناتجة.

SYNOPSIS

#include <libmemcached/memcached.h>

DESCRIPTION

The libmemcached library provides a client API for the memcached distributed memory caching system. It allows applications to interact with one or more memcached servers to store and retrieve data efficiently.

This library offers a robust and high-performance interface for implementing caching strategies in applications. It handles connection management, key hashing, data serialization, and error handling, simplifying the development process.

THREADS AND PROCESSES

libmemcached is generally thread-safe. However, you should ensure that memcached client objects are not shared between multiple threads without proper synchronization if you are performing operations that modify the state of the client object (like adding or removing servers).

SYSTEMTAP

Kernel-level instrumentation for libmemcached can be achieved using SystemTap. This allows for advanced performance monitoring and debugging without modifying the application code.

CLIENT PROGRAMS

Several command-line client programs are available that utilize the libmemcached library, allowing for manual interaction with memcached servers for testing and administration.

UTILITY LIBRARIES

The libmemcached library is composed of various utility functions and structures that facilitate the interaction with the memcached protocol. These include functions for connection handling, data retrieval and storage, server management, and error reporting.
