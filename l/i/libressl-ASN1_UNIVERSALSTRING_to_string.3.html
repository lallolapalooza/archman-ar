libressl-ASN1_UNIVERSALSTRING_to_string(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

ASN1_UNIVERSALSTRING_TO_STRING(3) دليل وظائف المكتبة ASN1_UNIVERSALSTRING_TO_STRING(3)

الاسم

ASN1_UNIVERSALSTRING_to_string — إعادة ترميز UTF-32 إلى ISO Latin-1

ملخص

مكتبة “libcrypto”
#include <openssl/asn1.h>

int
ASN1_UNIVERSALSTRING_to_string(ASN1_UNIVERSALSTRING *string);

الوصف

ASN1_UNIVERSALSTRING_to_string() تفترض أن string المعطاة مرمزة بصيغة UTF-32، وتعيد ترميزها في مكانها إلى ISO Latin-1، وتغير النوع وفقًا لـ ASN1_PRINTABLE_type(3).

ASN1_UNIVERSALSTRING_to_string() تفشل وتترك string دون تغيير إذا كان نوعها ASN1_STRING_type(3) ليس V_ASN1_UNIVERSALSTRING، إذا كان طولها ASN1_STRING_length(3) ليس مضاعفًا لأربعة بايتات، أو إذا كانت أي من أحرفها لا يمكن تمثيلها في ISO Latin-1.

في حالة النجاح، يتم تقليل طول ASN1_STRING_length(3) للـ string بمعامل أربعة.

قيم الإرجاع

ASN1_UNIVERSALSTRING_to_string() ترجع 1 عند النجاح أو 0 عند الفشل.

انظر أيضًا

ASN1_mbstring_copy(3)، ASN1_STRING_new(3)، ASN1_STRING_to_UTF8(3)

التاريخ

ASN1_UNIVERSALSTRING_to_string() ظهرت لأول مرة في SSLeay 0.8.0 وكانت متاحة منذ OpenBSD 2.4.
