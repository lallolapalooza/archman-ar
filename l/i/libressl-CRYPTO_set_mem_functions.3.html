libressl-CRYPTO_set_mem_functions(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

CRYPTO_SET_MEM_FUNCTIONS(3) دليل وظائف المكتبة CRYPTO_SET_MEM_FUNCTIONS(3)

الاسم

CRYPTO_set_mem_functions، CRYPTO_mem_ctrl، CRYPTO_mem_leaks، CRYPTO_mem_leaks_fp، CRYPTO_mem_leaks_cb — التحكم في تخصيص الذاكرة القديم في OpenSSL

الملخص

مكتبة “libcrypto”
#include <openssl/crypto.h>

int
CRYPTO_set_mem_functions(void *(*m)(size_t, const char *, int), void *(*r)(void *, size_t, const char *, int), void (*f)(void *, const char *, int));

int
CRYPTO_mem_ctrl(int mode);

int
CRYPTO_mem_leaks(BIO *b);

int
CRYPTO_mem_leaks_fp(FILE *fp);

typedef int *
CRYPTO_MEM_LEAK_CB(unsigned long, const char *, int, int, void *);

int
CRYPTO_mem_leaks_cb(CRYPTO_MEM_LEAK_CB *cb);

الوصف

لا تستخدم أيًا من الواجهات الموثقة هنا. يتم توفيرها فقط للتوافق مع تعليمات التطبيق القديمة.

CRYPTO_set_mem_functions()، CRYPTO_mem_ctrl()، CRYPTO_mem_leaks()، CRYPTO_mem_leaks_fp()، و CRYPTO_mem_leaks_cb() ليس لها أي تأثير.

قيم الإرجاع

CRYPTO_set_mem_functions() تعود دائمًا بـ 0.

CRYPTO_mem_ctrl() تعود دائمًا بـ CRYPTO_MEM_CHECK_OFF.

CRYPTO_mem_leaks()، CRYPTO_mem_leaks_fp()، و CRYPTO_mem_leaks_cb() تعود دائمًا بـ -1.

انظر أيضًا

crypto(3)

التاريخ

CRYPTO_mem_ctrl()، CRYPTO_mem_leaks()، و CRYPTO_mem_leaks_fp() ظهرت لأول مرة في SSLeay 0.6.4. CRYPTO_set_mem_functions() ظهرت لأول مرة في SSLeay 0.6.5. CRYPTO_mem_leaks_cb() ظهرت لأول مرة في SSLeay 0.6.6. كل هذه الوظائف كانت متاحة دائمًا منذ OpenBSD 2.4.
