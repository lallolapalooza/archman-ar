الوصف

كائن ASN1_TIME هو غلاف سطحي حول سلسلة تحتوي على قيمة وقت ASN.1 Time بالتنسيق المقيد الصالح في شهادات X.509. كائن ASN1_TIME هو إما كائن ASN1_UTCTIME يحتوي على سلسلة بالتنسيق YYMMDDHHMMSSZ والتي تكون صالحة للسنوات من 1950 إلى 2049، أو كائن ASN1_GENERALIZEDTIME يحتوي على سلسلة بالتنسيق YYYYMMDDHHMMSSZ والتي تكون صالحة للسنوات من 0000 إلى 1949 ومن 2050 إلى 9999. في كلتا الحالتين، يمثل اللاحقة الإلزامية ‘Z’ المنطقة الزمنية GMT. LibreSSL لا يدعم التصميم الكامل لبنية أوقات ASN.1. على وجه الخصوص، لا يدعم الثواني الكسرية ولا أي منطقة زمنية أخرى.

الوظائف ASN1_TIME_set()، ASN1_UTCTIME_set()، و ASN1_GENERALIZEDTIME_set() تضبط كائن الوقت s إلى الوقت الممثل بقيمة time_t t. إذا كان s يساوي NULL، يتم تخصيص كائن وقت جديد وإعادته.

الوظائف ASN1_TIME_adj()، ASN1_UTCTIME_adj()، و ASN1_GENERALIZEDTIME_adj() تضبط كائن الوقت s إلى الوقت الممثل بالوقت offset_day و offset_sec بعد قيمة time_t t. يمكن أن تكون قيم offset_day أو offset_sec سالبة لضبط وقت قبل t. قيمة offset_sec يمكن أن تتجاوز أيضًا عدد الثواني في اليوم. إذا كان s يساوي N

DESCRIPTION

The ASN1_TIME, ASN1_GENERALIZEDTIME, and ASN1_UTCTIME types represent ASN.1 Time values. ASN1_TIME is a generic type which can represent either ASN1_UTCTIME or ASN1_GENERALIZEDTIME.

ASN1_TIME_set(), ASN1_GENERALIZEDTIME_set(), and ASN1_UTCTIME_set() set the ASN.1 time object s to the value of the POSIX time_t value t. If s is NULL, then a new ASN1_TIME, ASN1_GENERALIZEDTIME, or ASN1_UTCTIME object is allocated. Otherwise the supplied object is used.

The functions ASN1_TIME_set_string(), ASN1_GENERALIZEDTIME_set_string(), and ASN1_UTCTIME_set_string() set the ASN.1 time object s to the value represented by the string str. The string must be in one of the formats specified by the ASN.1 Time definitions, see ASN1_TIME_print(3) for details.

The functions ASN1_TIME_adj(), ASN1_GENERALIZEDTIME_adj(), and ASN1_UTCTIME_adj() add offset_day days and offset_sec seconds to the time value t. If s is NULL, a new object is allocated. Otherwise the supplied object s is used.

The functions ASN1_TIME_check(), ASN1_GENERALIZEDTIME_check(), and ASN1_UTCTIME_check() validate the ASN.1 time object s. ASN1_GENERALIZEDTIME_check() only accepts time values in the GeneralizedTime format (i.e. with a 4-digit year). ASN1_UTCTIME_check() only accepts time values in the UTCTime format (i.e. with a 2-digit year). ASN1_TIME_check() accepts both formats.

ASN1_TIME_normalize() converts the ASN.1 time object s to a normalized form. This means that any fractional seconds are removed, and the timezone is set to UTC if present, or set to UTC if absent.

The functions ASN1_TIME_to_tm(), ASN1_UTCTIME_to_tm(), and ASN1_GENERALIZEDTIME_to_tm() convert the ASN.1 time object s to a POSIX struct tm format, storing the result in tm. If tm is NULL, a new struct tm is allocated and returned.

The functions OPENSSL_gmtime(), OPENSSL_timegm(), and OPENSSL_posix_to_tm() are wrappers around the POSIX gmtime(), timegm(), and localtime() functions. They perform the same functionality but do not set the tm_isdst field in the returned struct tm.

OPENSSL_tm_to_posix() converts a struct tm to a POSIX time_t value. The time must be in UTC.

The functions ASN1_TIME_print(), ASN1_GENERALIZEDTIME_print(), and ASN1_UTCTIME_print() print the ASN.1 time object a to the BIO bp. The output format is standard YYYYMMDDHHMMSSZ or YYYYMMDDHHMMSS+HH'MM' or YYYYMMDDHHMMSS-HH'MM'.

The function ASN1_TIME_cmp_time_t() compares the ASN.1 time object s to the POSIX time_t value t. It returns 1 if s is after t, -1 if s is before t, and 0 if they are equal.

The function ASN1_TIME_compare() compares two ASN.1 time objects a and b. It returns 1 if a is after b, -1 if a is before b, and 0 if they are equal.

The function ASN1_TIME_diff() calculates the difference in days and seconds between two ASN.1 time objects a and b. The result is stored in days and seconds. The result represents a - b.

RETURN VALUES

ASN1_TIME_set(), ASN1_GENERALIZEDTIME_set(), ASN1_UTCTIME_set(), ASN1_TIME_set_string(), ASN1_GENERALIZEDTIME_set_string(), ASN1_UTCTIME_set_string(), ASN1_TIME_adj(), ASN1_GENERALIZEDTIME_adj(), ASN1_UTCTIME_adj(), ASN1_TIME_check(), ASN1_GENERALIZEDTIME_check(), ASN1_UTCTIME_check(), ASN1_TIME_normalize(), ASN1_TIME_print(), ASN1_GENERALIZEDTIME_print(), ASN1_UTCTIME_print(), ASN1_TIME_cmp_time_t(), ASN1_UTCTIME_cmp_time_t(), ASN1_TIME_compare(), and ASN1_TIME_diff() return 1 on success or 0 on failure. It is a failure if the year is less than 0 or more than 9999.

ASN1_TIME_to_tm(), ASN1_UTCTIME_to_tm(), ASN1_GENERALIZEDTIME_to_tm(), OPENSSL_gmtime(), OPENSSL_timegm(), and OPENSSL_posix_to_tm() return a pointer to a struct tm on success, or NULL on failure. It is a failure if the year is less than 0 or more than 9999.

OPENSSL_tm_to_posix() return 1 for success or 0 on failure. It is a failure if the year is less than 0 or more than 9999.

EXAMPLES

Set a time object to one hour after the current time and print it out:

#include <time.h>
#include <openssl/asn1.h>

ASN1_TIME *asn1_time;
time_t t;
BIO *b;

t = time(NULL);
asn1_time = ASN1_TIME_adj(NULL, t, 0, 60 * 60);
b = BIO_new_fp(stdout, BIO_NOCLOSE);
if (asn1_time != NULL) {
	ASN1_TIME_print(b, asn1_time);
	BIO_printf(b, "\n");
} else {
	BIO_printf(b, "Time out of range or un-representable\n");
}
ASN1_STRING_free(asn1_time);
BIO_free(b);

STANDARDS

The usage of the ASN.1 Time, UTCTime, and GeneralizedTime data types in X.509 certificates is specified in RFC 5280, Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile, section 4.1.2.5 (TBS Certificate Validity).

HISTORY

ASN1_UTCTIME_check() and ASN1_UTCTIME_print() first appeared in SSLeay 0.5.1. ASN1_UTCTIME_set() first appeared in SSLeay 0.6.0. ASN1_UTCTIME_set_string() first appeared in SSLeay 0.9.0. All these functions have been available since OpenBSD 2.4.

ASN1_TIME_set(), ASN1_GENERALIZEDTIME_set(), ASN1_GENERALIZEDTIME_set_string(), ASN1_GENERALIZEDTIME_check(), ASN1_TIME_print(), and ASN1_GENERALIZEDTIME_print() first appeared in OpenSSL 0.9.2b and have been available since OpenBSD 2.6.

ASN1_UTCTIME_cmp_time_t() first appeared in OpenSSL 0.9.6 and has been available since OpenBSD 2.9.

ASN1_TIME_check() and ASN1_TIME_to_generalizedtime() first appeared in OpenSSL 0.9.7 and have been available since OpenBSD 3.2.

ASN1_TIME_adj(), ASN1_UTCTIME_adj(), ASN1_GENERALIZEDTIME_adj(), and ASN1_TIME_set_string() first appeared in OpenSSL 1.0.0 and have been available since OpenBSD 4.9.

ASN1_TIME_diff() first appeared in OpenSSL 1.0.2 and have been available since OpenBSD 7.1.

ASN1_TIME_set_string_X509(), ASN1_TIME_normalize(), ASN1_TIME_to_tm(), ASN1_TIME_cmp_time_t(), and ASN1_TIME_compare() first appeared in OpenSSL 1.1.1 and have been available since OpenBSD 7.2.

OPENSSL_gmtime() first appeared in OpenSSL 0.9.7. OPENSSL_timegm(), OPENSSL_posix_to_tm(), and OPENSSL_tm_to_posix() first appeared in BoringSSL; all these functions have been available since OpenBSD 7.5.

CAVEATS

Some applications add offset times directly to a time_t value and pass the results to ASN1_TIME_set() (or equivalent). This can cause problems as the time_t value can overflow on some systems resulting in unexpected results. New applications should use ASN1_TIME_adj() instead and pass the offset value in the offset_sec and offset_day parameters instead of directly manipulating a time_t value.
