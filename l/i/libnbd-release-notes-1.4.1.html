NAME

libnbd-release-notes - libnbd release notes

DESCRIPTION

This document contains the release notes for libnbd.

Release Notes 1.4.1

This is a bugfix release.

New features
None.
Bug fixes
  • Fixed a bug where libnbd could crash if the remote server sent a malformed reply. (Issue #127)
  • Fixed a bug where libnbd could leak file descriptors if the connection to the remote server was interrupted. (Issue #128)
  • Fixed a bug where libnbd could return incorrect error messages in some cases. (Issue #129)

Release Notes 1.4.0

This release adds support for new features and improves performance.

New features
  • Added support for asynchronous I/O operations. This allows applications to perform I/O operations in the background without blocking the main thread.
  • Added support for multiple concurrent connections to the same server.
  • Added support for TLS/SSL encryption of connections.
Bug fixes
  • Fixed a bug where libnbd could crash if the remote server sent a malformed reply. (Issue #127)
  • Fixed a bug where libnbd could leak file descriptors if the connection to the remote server was interrupted. (Issue #128)
  • Fixed a bug where libnbd could return incorrect error messages in some cases. (Issue #129)
Performance improvements
  • Improved the performance of read and write operations by using asynchronous I/O.
  • Reduced the memory usage of libnbd by optimizing data structures.
