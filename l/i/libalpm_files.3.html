وظائف لملفات الحزم

توثيق هياكل البيانات

struct alpm_file_t

ملف في حزمة.

حقول البيانات:

mode_t mode أذونات الملف.

char * name اسم الملف.

off_t size حجم الملف.

struct alpm_filelist_t

حاوية قائمة ملفات الحزمة.

حقول البيانات:

size_t count عدد الملفات في المصفوفة.

alpm_file_t * files مصفوفة من الملفات.

struct alpm_backup_t

إدخال نسخة احتياطية محلية للحزمة أو ملف الحزمة.

حقول البيانات:

char * hash تجزئة اسم الملف (تستخدم داخليًا)

char * name اسم الملف (بدون لاحقة .pacsave)

توثيق الوظائف

alpm_file_t * alpm_filelist_contains (const alpm_filelist_t * filelist, const char * path)

يحدد ما إذا كانت قائمة ملفات الحزمة تحتوي على مسار معين. يجب أن يكون المسار المقدم نسبيًا إلى جذر التثبيت بدون شرطات مائلة بادئة، على سبيل المثال "etc/localtime". عند البحث عن الدلائل، يجب أن يحتوي المسار على شرطة مائلة لاحقة.

المعلمات

filelist مؤشر إلى قائمة ملفات الحزمة
path المسار المراد البحث عنه في الحزمة

الإرجاع

مؤشر إلى الملف المطابق أو NULL إذا لم يتم العثور عليه
