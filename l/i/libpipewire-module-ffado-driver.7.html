الاسم

libpipewire-module-ffado-driver - برنامج تشغيل الصوت FFADO firewire

الوصف

توفر وحدة ffado-driver مصدرًا أو مصرفًا باستخدام مكتبة libffado للقراءة والكتابة إلى أجهزة الصوت firewire.

اسم الوحدة

libpipewire-module-ffado-driver

خيارات الوحدة

  • driver.mode: وضع برنامج التشغيل، sink|source|duplex، الافتراضي duplex
  • ffado.devices: مصفوفة من الأجهزة لفتحها، الافتراضي "hw:0"
  • ffado.period-size: حجم الفترة، الافتراضي 1024. قيمة 0 ستستخدم مدة الرسم البياني.
  • ffado.period-num: عدد الفترات، الافتراضي 3
  • ffado.sample-rate: معدل العينة، الافتراضي 48000. قيمة 0 ستستخدم معدل الرسم البياني.
  • ffado.slave-mode: وضع العبد
  • ffado.snoop-mode: وضع التنصت
  • ffado.verbose: مستوى تفصيل ffado
  • ffado.rtprio: أولوية الوقت الحقيقي لـ ffado، هذا افتراضيًا هو أولوية خادم PipeWire + 5
  • ffado.realtime: وضع الوقت الحقيقي لـ ffado. هذا يتطلب تكوين rlimits بشكل صحيح للحصول على جدولة FIFO بالأولوية ffado.rtprio
  • latency.internal.input: زمن استجابة إضافي للإدخال بالإطارات
  • latency.internal.output: زمن استجابة إضافي للإخراج بالإطارات
  • source.props: خصائص إضافية لمرشح المصدر
  • sink.props: خصائص إضافية لمرشح المصرف

خيارات عامة

خيارات ذات سلوك معروف.

  • remote.name
  • audio.position
  • node.name
  • node.description
  • node.group
  • node.virtual
  • media.class
  • target.object لتحديد اسم العقدة البعيدة أو معرفها التسلسلي للربط بها

مثال على تكوين مصرف/مصدر مزدوج

# ~/.config/pipewire/pipewire.conf.d/my-ffado-driver.conf
context.modules = [
{   name = libpipewire-module-ffado-driver
    args = {
        #driver.mode       = duplex
        #ffado.devices     = [ "hw:0" ]
        #ffado.period-size = 1024
        #ffado.period-num  = 3
        #ffado.sample-rate = 48000
        #ffado.slave-mode  = false
        #ffado.snoop-mode  = false
        #ffado.verbose     = 0
        #ffado.rtprio      = 65
        #ffado.realtime    = true
        #latency.internal.input  = 0
        #latency.internal.output = 0
        #audio.position    = [ FL FR ]
        source.props = {
            # خصائص مصرف إضافية
        }
        sink.props = {
            # خصائص مصرف إضافية
        }
    }
}
]
