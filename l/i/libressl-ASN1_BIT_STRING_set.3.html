libressl-ASN1_BIT_STRING_set(3)

الحزمة: libressl

التراخيص: ISC، custom:OpenSSL

ASN1_BIT_STRING_SET(3) دليل وظائف المكتبة ASN1_BIT_STRING_SET(3)

الاسم

ASN1_BIT_STRING_set، ASN1_BIT_STRING_set_bit، ASN1_BIT_STRING_get_bit — مُحَدِّدات سلسلة بتات ASN.1

الملخص

المكتبة «libcrypto»
#include <openssl/asn1.h>

int
ASN1_BIT_STRING_set(ASN1_BIT_STRING *bitstr, unsigned char *data, int len);

int
ASN1_BIT_STRING_set_bit(ASN1_BIT_STRING *bitstr, int bitnumber, int set);

int
ASN1_BIT_STRING_get_bit(ASN1_BIT_STRING *bitstr, int bitnumber);

الوصف

ASN1_BIT_STRING_set() تضبط السمة len لطول bitstr وتنسخ هذا العدد من البايتات من data إلى bitstr، متجاوزةً أي بيانات سابقة، وذلك بمجرد استدعاء ASN1_STRING_set(3). لا تقوم هذه الوظيفة بأي تحقق على الإطلاق. على وجه الخصوص، لا تتحقق مما إذا كان bitstr هو بالفعل من النوع V_ASN1_BIT_STRING ولا، حتى لو كان كذلك، ما إذا كانت وسائط data و len ذات مغزى لسلسلة البتات المحددة هذه.

إذا كانت الوسيطة set غير صفرية، فإن ASN1_BIT_STRING_set_bit() تضبط البت المحدد بالـ bitnumber المعطى في bitstr؛ وإلا، فإنها تمسح ذلك البت. الـ bitnumber الذي قيمته 0 يعالج البت الأكثر أهمية في أول بايت بيانات لـ bitstr، والـ 7 يعالج البت الأقل أهمية في نفس البايت، والـ 8 يعالج البت الأكثر أهمية في ثاني بايت بيانات، وهكذا.

إذا تم طلب ضبط بت يتجاوز آخر بايت بيانات موجود، تتم إضافة بايتات إضافية إلى bitstrbitstr.

ASN1_BIT_STRING_get_bit() يتحقق مما إذا كان البت المحدد بالـ bitnumber معينًا في bitstr.

قيم الإرجاع

ASN1_BIT_STRING_set() ترجع 1 عند النجاح أو 0 إذا فشل تخصيص الذاكرة أو إذا كان data هو NULL وكان len هو -1 في نفس الاستدعاء.

ASN1_BIT_STRING_set_bit() ترجع 1 عند النجاح أو 0 إذا كان bitstr هو NULL أو إذا فشل تخصيص الذاكرة.

ASN1_BIT_STRING_get_bit() ترجع 1 إذا كان البت المحدد بالـ bitnumber معينًا في bitstr أو 0 إذا كان bitstr هو NULL، أو إذا كان bitnumber يشير إلى ما بعد آخر بايت بيانات في bitstr، أو إذا كان البت المطلوب غير معين.

انظر أيضًا

ASN1_BIT_STRING_new(3), ASN1_STRING_set(3), d2i_ASN1_BIT_STRING(3), v2i_ASN1_BIT_STRING(3)

التاريخ

ASN1_BIT_STRING_set() ظهرت لأول مرة في SSLeay 0.6.5. ASN1_BIT_STRING_set_bit() و ASN1_BIT_STRING_get_bit() ظهرتا لأول مرة في SSLeay 0.9.0. هذه الوظائف متاحة منذ OpenBSD 2.4.
