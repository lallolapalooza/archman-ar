الوصف

ASN1_mbstring_copy() تفسر inbytes بايت بدءًا من inout، مع تغيير الترميز اختياريًا. إذا كان الوسيط inbytesstrlen(3) لـ in

يحدد الوسيط inform ترميز الأحرف لـ in:

inform الترميز
MBSTRING_ASC ISO-Latin-1
MBSTRING_BMP UTF-16
MBSTRING_UNIV UTF-32
MBSTRING_UTF8 UTF-8

يحدد القناع mask مجموعة من أنواع سلاسل ASN.1 التي يرغب المستخدم في قبولها:

بت في mask نوع الإخراج المقبول الافتراضي
B_ASN1_PRINTABLESTRING ASN1_PRINTABLESTRING نعم
B_ASN1_IA5STRING ASN1_IA5STRING لا
B_ASN1_T61STRING ASN1_T61STRING نعم
B_ASN1_BMPSTRING ASN1_BMPSTRING نعم
B_ASN1_UNIVERSALSTRING ASN1_UNIVERSALSTRING لا
أي بت آخر ASN1_UTF8STRING نعم

يتم استخدام النوع الأول من الجدول أعلاه الذي يتم تضمينه في الوسيط mask والذي يمكنه تمثيل inmask

تتضمن ثوابت قناع البت التالية كل منها عدة بتات مدرجة أعلاه:

قناع ثابت PRI IA5 T61 BMP UNI UTF8
B_ASN1_DIRECTORYSTRING نعم لا نعم نعم نعم نعم
DIRSTRING_TYPE نعم لا نعم نعم لا نعم
PKCS9STRING_TYPE نعم نعم نعم نعم لا نعم

إذا كان out هو NULL، فسيتم التحقق من صحة inform و inbytes و in

بخلاف ذلك، إذا كان *out هو NULL، فسيتم تخصيص كائن إخراج جديد من نوع الإخراج وسيتم تخزين مؤشر إليه في *out.

بخلاف ذلك، سيتم استخدام **out ككائن إخراج. سيتم تحرير أي بيانات مخزنة فيه بالفعل وتغيير نوعه إلى نوع الإخراج.

أخيرًا، يتم نسخ in إلى كائن الإخراج، مع تغيير ترميز الأحرف إذا لم يتطابق inform مع الترميز المستخدم بواسطة نوع الإخراج.

ASN1_mbstring_ncopy() مشابه باستثناء أن عدد الأحرف في inminchars إلى maxchars، شاملة. إذا كان maxchars يساوي 0، فلن يتم فرض حد أعلى على عدد الأحرف.

ASN1_STRING_set_by_NID() مشابه مع الاختلافات التالية:

  • إذا كان out هو NULL، فسيتم تخصيص كائن إخراج جديد وإعادته بدلاً من تخطي النسخ.
  • إذا كان nid لديه إدخال جدول سلاسل عام يمكن استرداده باستخدام ASN1_STRING_TABLE_get(3)، فسيتم أخذ mask و minchars و maxchars من إدخال جدول السلاسل هذا. بالنسبة لبعض قيم nid، سيتم تطبيق قناع عام إضافي على القناع قبل استخدامه. القيمة الافتراضية للقناع العام هي B_ASN1_UTF8STRING.
  • إذا لم يكن لـ nid إدخال جدول سلاسل عام، فسيتم استخدام B_ASN1_PRINTABLESTRING | B_ASN1_T61STRING | B_ASN1_BMPSTRING | B_ASN1_UTF8STRING بدلاً من القناع المأخوذ من الجدول، وسيتم أيضًا تطبيق القناع العام عليه.
  • حتى لو حدث النجاح والفشل في نفس المواقف، فإن القيمة المرتجعة مختلفة.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

ASN1_STRING_type(3) can be used to determine the type of the return value.

ASN1_STRING_set_default_mask() sets the global mask used by ASN1_STRING_set_by_NID() to the mask argument.

ASN1_STRING_set_default_mask_asc() sets the global mask as follows:

maskname mask
"default" anything
"nombstr" anything except B_ASN1_BMPSTRING | B_ASN1_UTF8STRING
"pkix" anything except B_ASN1_T61STRING
"utf8only" B_ASN1_UTF8STRING

If the maskname argument starts with the substring "MASK:", the rest of it is interpreted as an unsigned long value using strtoul(3).

In typical usage, the calling code calculates the bitwise AND of the return value and a mask describing data types that the calling code is willing to use. If the result of the AND operation is non-zero, the data type is adequate; otherwise, the calling code may need to raise an error.

RETURN VALUES

ASN1_mbstring_copy() and ASN1_mbstring_ncopy() return the V_ASN1_* constant representing the output type or -1 if inform is invalid, if inbytes or in is invalid for the inform encoding, if in contains an UTF-16 surrogate, which is unsupported even for input using the UTF-16 encoding, or if memory allocation fails.

ASN1_mbstring_ncopy() also returns -1 if in contains fewer than minchars or more than maxchars characters.

ASN1_STRING_set_by_NID() returns the new or changed ASN.1 string object or NULL on failure.

ASN1_STRING_set_default_mask_asc() returns 1 if successful or 0 if "MASK:" is not followed by a number, if the number is followed by a non-numeric character, or if the maskname is invalid.

ASN1_STRING_get_default_mask() returns the global mask.

ASN1_tag2bit() returns a B_ASN1_* constant or 0.
