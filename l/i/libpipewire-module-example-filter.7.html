libpipewire-module-example-filter(7) دليل المعلومات المتنوعة libpipewire-module-example-filter(7)

الاسم

libpipewire-module-example-filter - مرشح مثال

الوصف

مرشح المثال هو نقطة انطلاق جيدة لكتابة مرشح مخصص.

نحن نشير إلى الكود المصدري لمزيد من المعلومات.

اسم الوحدة

libpipewire-module-example-filter

خيارات الوحدة

  • node.description: اسم قابل للقراءة للبشر لتيارات المرشح
  • capture.props = {}: خصائص سيتم تمريرها إلى تيار الإدخال
  • playback.props = {}: خصائص سيتم تمريرها إلى تيار الإخراج

خيارات عامة

خيارات ذات سلوك معروف. يمكن إضافة معظم الخيارات إلى التكوين العام أو التيارات الفردية:

  • remote.name
  • audio.rate
  • audio.channels
  • audio.position
  • media.name
  • node.latency
  • node.description
  • node.group
  • node.link.group
  • node.virtual
  • node.name : انظر الملاحظات أدناه. إذا لم يتم تحديده، الافتراضي هو 'filter-PID-MODULEID'.

خصائص التيار فقط:

  • media.class
  • node.name : إذا لم يتم تقديمه لكل تيار، فسيتم إضافة بادئة global node.name بـ 'input.' و 'output.' لإنشاء اسم عقدة لتيار الالتقاط والإخراج على التوالي.

مثال تكوين لمصدر افتراضي

# ~/.config/pipewire/pipewire.conf.d/my-example-filter.conf
context.modules = [
{   name = libpipewire-module-example-filter
    args = {
      node.description = "مثال مرشح"
      capture.props = {
          audio.position = [ FL FR ]
          node.passive = true
      }
      playback.props = {
          node.name = "مثال مرشح"
          media.class = "Audio/Source"
          audio.position = [ FL FR ]
      }
    }
}
]
pw-cli -m lm libpipewire-module-example-filter '{ audio.position=[FL FR] }'
