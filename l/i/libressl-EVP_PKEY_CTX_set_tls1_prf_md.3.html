libressl-EVP_PKEY_CTX_set_tls1_prf_md(3)

الحزمة: libressl

التراخيص: ISC، مخصص:OpenSSL

EVP_PKEY_CTX_SET_TLS1_PRF_MD(3) دليل الوظائف المكتبية EVP_PKEY_CTX_SET_TLS1_PRF_MD(3)

الاسم

EVP_PKEY_CTX_set_tls1_prf_md، EVP_PKEY_CTX_set1_tls1_prf_secret، EVP_PKEY_CTX_add1_tls1_prf_seed — خوارزمية اشتقاق مفتاح TLS PRF

الملخص

مكتبة “libcrypto”
#include <openssl/evp.h>
#include <openssl/kdf.h>

int
EVP_PKEY_CTX_set_tls1_prf_md(EVP_PKEY_CTX *pctx, const EVP_MD *md);

int
EVP_PKEY_CTX_set1_tls1_prf_secret(EVP_PKEY_CTX *pctx, unsigned char *sec, int seclen);

int
EVP_PKEY_CTX_add1_tls1_prf_seed(EVP_PKEY_CTX *pctx, unsigned char *seed, int seedlen);

الوصف

تنفذ خوارزمية EVP_PKEY_TLS1_PRF وظيفة اشتقاق المفتاح PRF لـ TLS. لا ترتبط بأي مفتاح خاص ولا تنفذ سوى اشتقاق المفاتيح باستخدام EVP_PKEY_derive(3).

EVP_PKEY_set_tls1_prf_md() تضبط خوارزمية التجزئة (digest) المرتبطة بـ TLS PRF. EVP_md5_sha1(3) تُعامل كحالة خاصة تستخدم خوارزمية PRF باستخدام كل من MD5 و SHA-1 كما هو مستخدم في TLS 1.0 و 1.1.

EVP_PKEY_CTX_set1_tls1_prf_secret() تضبط قيمة السر لـ TLS PRF إلى seclen بايت من المخزن المؤقت sec. يتم استبدال أي قيمة سر موجودة وإعادة تعيين أي بذرة (seed).

EVP_PKEY_CTX_add1_tls1_prf_seed() تضبط البذرة إلى seedlen بايت من seed. إذا تم تعيين بذرة بالفعل، فإنها تضاف إلى القيمة الحالية.

عمليات التحكم بالسلاسل النصية

تدعم TLS PRF أيضًا عمليات التحكم المستندة إلى السلاسل النصية باستخدام EVP_PKEY_CTX_ctrl_str(3). المعلمة type "md" تستخدم القيمة value المقدمة كاسم لخوارزمية التجزئة المراد استخدامها. المعلمات type "secret" و "seed" تستخدم المعلمة value المقدمة كقيمة سر أو بذرة. الأسماء "hexsecret" و "hexseed" مشابهة باستثناء أنها تأخذ سلسلة سداسية عشرية يتم تحويلها إلى ثنائية.

ملاحظات

جميع هذه الدوال منفذة كـ macros.

يمكن الحصول على سياق لـ TLS PRF عن طريق استدعاء:

EVP_PKEY_CTX *pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_TLS1_PRF, NULL);

يجب تعيين خوارزمية التجزئة، القيمة السرية، والبذرة قبل اشتقاق مفتاح، وإلا سيحدث خطأ.

لا يمكن أن يتجاوز الطول الإجمالي لجميع البذور 1024 بايت: يجب أن يكون هذا أكثر من كافٍ لأي استخدام طبيعي لـ TLS PRF.

يتم تحديد طول الإخراج لـ PRF بواسطة معلمة الطول في EVP_PKEY_derive(3). نظرًا لأن طول الإخراج متغير، فإن تعيين المخزن المؤقت على NULL ليس ذا معنى لـ TLS PRF.

قيم الإرجاع

جميع هذه الدوال ترجع 1 للنجاح و 0 أو قيمة سالبة للفشل. على وجه الخصوص، تشير القيمة المرجعة -2 إلى أن العملية غير مدعومة من قبل خوارزمية المفتاح العام.

أمثلة

هذا المثال يشتق 10 بايت باستخدام SHA-256 مع المفتاح السري "secret" وقيمة البذرة "seed":

EVP_PKEY_CTX *pctx;
unsigned char out[10];
size_t outlen = sizeof(out);

pctx = EVP_PKEY_CTX_new_id(EVP_PKEY_TLS1_PRF, NULL);
if (EVP_PKEY_derive_init(pctx) <= 0)
    /* خطأ */
if (EVP_PKEY_CTX_set_tls1_prf_md(pctx, EVP_sha256()) <= 0)
    /* خطأ */
if (EVP_PKEY_CTX_set1_tls1_prf_secret(pctx, "secret", 6) <= 0)
    /* خطأ */
if (EVP_PKEY_CTX_add1_tls1_prf_seed(pctx, "seed", 4) <= 0)
    /* خطأ */
if (EVP_PKEY_derive(pctx, out, &outlen) <= 0)
    /* خطأ */
