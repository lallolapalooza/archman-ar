الوصف

BIO_ctrl()، BIO_callback_ctrl()، BIO_ptr_ctrl()، و BIO_int_ctrl() هي عمليات "تحكم" في BIO تأخذ وسائط من أنواع مختلفة. هذه الوظائف لا يتم استدعاؤها عادةً بشكل مباشر - يتم استخدام وحدات ماكرو مختلفة بدلاً من ذلك. يتم وصف وحدات الماكرو القياسية أدناه. يتم وصف وحدات الماكرو الخاصة بنوع معين من BIO في صفحة دليل BIO المحدد بالإضافة إلى أي ميزات خاصة للاستدعاءات القياسية.

اعتمادًا على cmd وعلى نوع b، قد يكون لـ BIO_ctrl() تأثير للقراءة فقط على b أو تغيير بيانات في b أو في هياكله الفرعية. قد يكون له أيضًا تأثير جانبي لتغيير الذاكرة التي يشير إليها parg.

BIO_callback_ctrl() لا تستدعي BIO_ctrl() بل تتطلب أن يوفر نوع BIO لـ b مؤشر وظيفة callback_ctrl مخصص، وهو مدمج في المكتبة لبعض أنواع BIO القياسية ويمكن توفيره باستخدام BIO_meth_set_callback_ctrl(3) لأنواع BIO المعرفة من قبل التطبيق. الأمر الوحيد cmd المدعوم بواسطة BIO_callback_ctrl() هو BIO_CTRL_SET_CALLBACK.

BIO_ptr_ctrl() تستدعي BIO_ctrl() مع parg يشير إلى موقع متغير مؤشر مؤقت تم تهيئته إلى NULL.

BIO_int_ctrl() تستدعي BIO_ctrl() مع parg يشير إلى موقع متغير int مؤقت تم تهيئته إلى iarg. إذا غيرت BIO_ctrl() القيمة المخزنة في *parg، يتم تجاهل القيمة الجديدة.

BIO_reset() تعيد تعيين BIO عادةً إلى حالة أولية. في حالة BIOs المتعلقة بالملفات، على سبيل المثال، فإنها تعيد مؤشر الملف إلى بداية الملف.

BIO_seek() تعيد تعيين مؤشر موضع الملف لـ BIOs المتعلقة بالملفات (وهي واجهات ملفات وصفية وملفات FILE) إلى ofs بايت من بداية الملف.

BIO_tell() تعيد موضع الملف الحالي لـ BIO متعلق بالملف.

BIO_flush() عادةً ما تكتب أي بيانات مخزنة داخليًا. في بعض الحالات، يتم استخدامها للإشارة إلى نهاية الملف (EOF) وأنه لن يتم كتابة المزيد من البيانات.

BIO_eof() تعيد 1 إذا قرأت BIO نهاية الملف (EOF). المعنى الدقيق لـ "EOF" يختلف حسب نوع BIO.

BIO_set_close() تحدد علامة إغلاق BIO b إلى flag. يمكن أن تأخذ flag القيمة BIO_CLOSE أو BIO_NOCLOSE. عادةً ما يتم استخدام BIO_CLOSE في BIO مصدر/مستقبل للإشارة إلى أنه يجب إغلاق تدفق الإدخال/الإخراج الأساسي عند تحرير BIO.

BIO_get_close() تعيد علامة إغلاق BIO.

BIO_pending()، BIO_ctrl_pending()، BIO_wpending()، و BIO_ctrl_wpending() تعيد عدد الأحرف المعلقة في مخازن BIO للقراءة والكتابة. لا تدعم جميع BIOs هذه الاستدعاءات. تعيد BIO_ctrl_pending() و BIO_ctrl_wpending() نوع size_t وهي وظائف.

BIO_set_info_callback() تقوم بتثبيت مؤشر الوظيفة cb كإرجاع معلومات في b عن طريق استدعاء BIO_callback_ctrl() مع أمر BIO_CTRL_SET_CALLBACK. من بين أنواع BIO المبنية في المكتبة، فقط BIO_s_c

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

BIO_get_callback() retrieves the callback function pointer previously set with BIO_set_callback(). The callback is stored in cb and the user data pointer is stored in data.

BIO_get_cipher_status() returns the cipher status of a cipher BIO. See BIO_set_cipher(3) for details.

BIO_get_data() retrieves the user data pointer previously set with BIO_set_data().

BIO_get_info_callback() retrieves the info callback function pointer previously set with BIO_set_info_callback() or BIO_callback_ctrl(). The callback is stored in cbp.

The function type name bio_info_cb is a deprecated synonym for BIO_info_cb provided for backward compatibility with some existing application software.

The BIO_ctrl() function may be used to call other control functions. Some control functions take additional arguments, while others do not. The specific arguments depend on the command used.

  • BIO_C_FILE_SEEK and BIO_C_FILE_TELL: These commands take no additional arguments. They are used to seek and tell the current position in a file BIO, respectively. The result is returned as the return value of BIO_ctrl().
  • BIO_C_GET_FD and BIO_C_SET_FD: These commands take a pointer to an int as the argument. For BIO_C_GET_FD, the file descriptor is stored in the integer. For BIO_C_SET_FD, the file descriptor is set from the integer.
  • BIO_C_GET_FILE_PTR and BIO_C_SET_FILE_PTR: These commands take a pointer to a FILE structure as the argument. For BIO_C_GET_FILE_PTR, the FILE pointer is stored in the structure. For BIO_C_SET_FILE_PTR, the FILE pointer is set from the structure.
  • BIO_C_GET_SSL and BIO_C_SET_SSL: These commands take a pointer to an SSL structure as the argument. For BIO_C_GET_SSL, the SSL pointer is stored in the structure. For BIO_C_SET_SSL, the SSL pointer is set from the structure.
  • BIO_C_GET_BUF_MEM_PTR and BIO_C_SET_BUF_MEM: These commands take a pointer to a BIO_ADDR structure as the argument. For BIO_C_GET_BUF_MEM_PTR, the buffer memory pointer is stored in the structure. For BIO_C_SET_BUF_MEM, the buffer memory is set from the structure.
  • BIO_C_GET_INFO_CALLBACK and BIO_C_SET_INFO_CALLBACK: These commands take a pointer to a BIO_info_cb function pointer as the argument. For BIO_C_GET_INFO_CALLBACK, the info callback pointer is stored in the function pointer. For BIO_C_SET_INFO_CALLBACK, the info callback pointer is set from the function pointer.
  • BIO_C_GET_CALLBACK and BIO_C_SET_CALLBACK: These commands take a pointer to a bio_callback function pointer and a pointer to a void pointer for user data as the argument. For BIO_C_GET_CALLBACK, the callback pointer and user data pointer are stored in the provided pointers. For BIO_C_SET_CALLBACK, the callback pointer and user data pointer are set from the provided pointers.
  • BIO_C_GET_CALLBACK_ARG and BIO_C_SET_DATA: These commands take a pointer to a void pointer for user data as the argument. For BIO_C_GET_CALLBACK_ARG, the user data pointer is stored in the provided pointer. For BIO_C_SET_DATA, the user data pointer is set from the provided pointer.
  • BIO_C_GET_WRITE_BUF_SIZE and BIO_C_SET_WRITE_BUF_SIZE: These commands take a pointer to an int as the argument. For BIO_C_GET_WRITE_BUF_SIZE, the buffer size is stored in the integer. For BIO_C_SET_WRITE_BUF_SIZE, the buffer size is set from the integer.
  • BIO_C_GET_READ_REQUEST and BIO_C_SET_READ_REQUEST: These commands take a pointer to an int as the argument. For BIO_C_GET_READ_REQUEST, the read request value is stored in the integer. For BIO_C_SET_READ_REQUEST, the read request value is set from the integer.
  • BIO_C_GET_WRITE_GUARANTEE and BIO_C_SET_WRITE_GUARANTEE: These commands take a pointer to an size_t as the argument. For BIO_C_GET_WRITE_GUARANTEE, the write guarantee value is stored in the size_t. For BIO_C_SET_WRITE_GUARANTEE, the write guarantee value is set from the size_t.
  • BIO_C_MAKE_BIO_PAIR and BIO_C_DESTROY_BIO_PAIR: These commands take a pointer to a BIO_PAIR structure as the argument. For BIO_C_MAKE_BIO_PAIR, a new BIO pair is created and the pointers to the pair are stored in the structure. For BIO_C_DESTROY_BIO_PAIR, the BIO pair pointed to by the structure is destroyed.
  • BIO_C_DO_STATE_MACHINE: This command takes no additional arguments. It is used to trigger the state machine in certain BIOs, such as SSL BIOs.
  • BIO_C_GET_BUFF_NUM_LINES and BIO_C_SET_BUFF_READ_DATA: These commands take a pointer to an int as the argument. For BIO_C_GET_BUFF_NUM_LINES, the number of lines in the buffer is stored in the integer. For BIO_C_SET_BUFF_READ_DATA, the data to be read from the buffer is set from the integer.
  • BIO_C_GET_CIPHER_CTX and BIO_C_SET_CIPHER_CTX: These commands take a pointer to a EVP_CIPHER_CTX structure as the argument. For BIO_C_GET_CIPHER_CTX, the cipher context is stored in the structure. For BIO_C_SET_CIPHER_CTX, the cipher context is set from the structure.
  • BIO_C_GET_MD and BIO_C_SET_MD: These commands take a pointer to an EVP_MD structure as the argument. For BIO_C_GET_MD, the message digest is stored in the structure. For BIO_C_SET_MD, the message digest is set from the structure.
  • BIO_C_GET_MD_CTX and BIO_C_SET_MD_CTX: These commands take a pointer to an EVP_MD_CTX structure as the argument. For BIO_C_GET_MD_CTX, the message digest context is stored in the structure. For BIO_C_SET_MD_CTX, the message digest context is set from the structure.
  • BIO_C_GET_CIPHER_STATUS: This command takes no additional arguments. It returns the cipher status of a cipher BIO.
  • BIO_C_GET_BIND_MODE and BIO_C_SET_BIND_MODE: These commands take a pointer to an int as the argument. For BIO_C_GET_BIND_MODE, the bind mode is stored in the integer. For BIO_C_SET_BIND_MODE, the bind mode is set from the integer.
  • BIO_C_GET_ACCEPT: This command takes a pointer to an int as the argument. The port number is stored in the integer.
  • BIO_C_GET_SSL_NUM_RENEGOTIATES: This command takes a pointer to an unsigned int as the argument. The number of renegotiations is stored in the unsigned int.
  • BIO_C_SET_BUF_MEM_EOF_RETURN: This command takes an int as the argument. It sets the return value for EOF when reading from a memory BIO.
  • BIO_C_SET_SSL_RENEGOTIATE_BYTES and BIO_C_SET_SSL_RENEGOTIATE_TIMEOUT: These commands take an unsigned int as the argument. They set the number of bytes before renegotiation and the timeout for renegotiation, respectively.
  • BIO_C_SHUTDOWN_WR: This command takes no additional arguments. It shuts down the write side of a BIO.
  • BIO_C_SSL_MODE: This command takes an int as the argument. It sets the SSL mode for an SSL BIO.
  • BIO_CTRL_DGRAM_CONNECT, BIO_CTRL_DGRAM_GET_PEER, BIO_CTRL_DGRAM_GET_RECV_TIMER_EXP, BIO_CTRL_DGRAM_GET_SEND_TIMER_EXP, BIO_CTRL_DGRAM_SET_CONNECTED, BIO_CTRL_DGRAM_SET_PEER: These commands relate to datagram BIOs and take specific arguments depending on the command. See the relevant documentation for details.
  • BIO_CTRL_DUP: This command takes a pointer to a BIO structure as the argument. It duplicates the state of the source BIO into the destination BIO.
  • BIO_CTRL_EOF: This command takes no additional arguments. It returns 1 if the end of the file has been reached, and 0 otherwise.
  • BIO_CTRL_FLUSH: This command takes no additional arguments. It flushes any buffered data in the BIO.
  • BIO_CTRL_GET_DIR: This command takes no additional arguments. It returns the direction of the BIO (read or write).
  • BIO_CTRL_GET_LEN: This command takes no additional arguments. It returns the length of the data in the BIO.
  • BIO_CTRL_GET_OFFSET: This command takes no additional arguments. It returns the current offset in the BIO.
  • BIO_CTRL_GET_PEEK_AROUND and BIO_CTRL_SET_PEEK_SOCKET: These commands relate to peek socket BIOs and take specific arguments. See the relevant documentation for details.
  • BIO_CTRL_GET_PORT: This command takes a pointer to an int as the argument. The port number is stored in the integer.
  • BIO_CTRL_GET_RUN_FWD_FUNCTION and BIO_CTRL_SET_RUN_FWD_FUNCTION: These commands relate to forward functions and take specific arguments. See the relevant documentation for details.
  • BIO_CTRL_GET_SIGNING_PKEY and BIO_CTRL_SET_SIGNING_PKEY: These commands relate to signing keys and take specific arguments. See the relevant documentation for details.
  • BIO_CTRL_GET_SSL_ACTION: This command takes no additional arguments. It returns the current SSL action.
  • BIO_CTRL_LISTENER_REUSEADDR: This command takes a pointer to an int as the argument. It sets or gets the listener reuse address option.
  • BIO_CTRL_PENDING: This command takes no additional arguments. It returns the number of pending bytes in the BIO.
  • BIO_CTRL_PUSH_FINALTERIZER and BIO_CTRL_SET_PUSH_FINALTERIZER: These commands relate to finalizer functions and take specific arguments. See the relevant documentation for details.
  • BIO_CTRL_RESET: This command takes no additional arguments. It resets the BIO.
  • BIO_CTRL_UP_REF: This command takes no additional arguments. It increments the reference count of the BIO.
  • BIO_TEST_NOCALLBACKS: This command takes no additional arguments. It is used for testing purposes to disable callbacks.

BIO_ctrl_pending(3), BIO_ctrl_reset(3), BIO_ctrl_set_close(3), and BIO_set_callback(3) support this functionality. Some filter BIO types forward this control call to the next BIO in the chain instead of processing it themselves.

قيم الإرجاع

يعتمد معنى قيم الإرجاع من BIO_ctrl() و BIO_callback_ctrl() و BIO_int_ctrl() على كل من نوع b و cmd. إذا كان b مؤشرًا NULL، فلن يتم تنفيذ أي إجراء وسيتم إرجاع 0. عادةً ما يشير الإرجاع -2 إلى خطأ فادح. على وجه الخصوص، يتم إرجاعه إذا كان cmd غير مدعوم من قبل نوع b.

BIO_callback_ctrl() و BIO_set_info_callback() ترجع 1 عند النجاح، و 0 إذا كان b هو NULL أو للإشارة إلى فشل cmd صالح، أو -2 إذا كان cmd غير مدعوم من قبل b.

BIO_ptr_ctrl() ترجع NULL إذا كانت استدعاء BIO_ctrl() يرجع قيمة سالبة أو لا يغير *parg، أو المؤشر الذي يضعه في *parg خلاف ذلك.

BIO_int_ctrl() ترجع قيمة الإرجاع من BIO_ctrl().

BIO_reset() عادةً ما ترجع 1 للنجاح و 0 أو -1 للفشل. استثناءات BIOs للملفات، حيث ترجع 0 للنجاح و -1 للفشل.

BIO_seek() و BIO_tell() كلاهما يرجعان موضع الملف الحالي عند النجاح و -1 للفشل، باستثناء BIOs للملفات حيث بالنسبة BIO_seek() ترجع دائمًا 0 للنجاح و -1 للفشل.

BIO_flush() ترجع 1 للنجاح و 0 أو -1 للفشل.

BIO_eof() ترجع 1 إذا تم الوصول إلى نهاية الملف (EOF) أو 0 بخلاف ذلك.

BIO_set_close() ترجع دائمًا 1.

BIO_get_close() ترجع قيمة علامة الإغلاق BIO_CLOSE أو BIO_NOCLOSE.

BIO_pending() و BIO_ctrl_pending() و BIO_wpending() و BIO_ctrl_wpending() ترجع كمية البيانات المعلقة.

BIO_get_info_callback() ترجع 1 عند النجاح، بما في ذلك عندما يدعم نوع b رد اتصال معلوماتي ولكن لم يتم تثبيت أي شيء، و 0 إذا كان b هو NULL أو -2 إذا كان نوع b لا يدعم رد اتصال معلوماتي.

إذا تم تثبيت رد اتصال في b باستخدام BIO_set_callback_ex(3) أو BIO_set_callback(3)، فيمكنه تعديل قيم الإرجاع لجميع هذه الدوال.

ملاحظات

نظرًا لأنه يمكنه كتابة البيانات، BIO_flush() قد يرجع 0 أو -1 مشيرًا إلى أنه يجب إعادة محاولة الاستدعاء لاحقًا بطريقة مشابهة لـ BIO_write(3). يجب استخدام استدعاء BIO_should_retry(3) واتخاذ الإجراء المناسب إذا فشل الاستدعاء.

قد لا تحدد قيم الإرجاع لـ BIO_pending() و BIO_wpending() بشكل موثوق كمية البيانات المعلقة في جميع الحالات. على سبيل المثال، في حالة BIO للملفات، قد تكون بعض البيانات متاحة في المخازن المؤقتة الداخلية لمبنى FILE ولكن لا يمكن تحديد ذلك بطريقة محمولة. بالنسبة لأنواع أخرى من BIOs، قد لا تكون مدعومة.

إذا لم تتعامل BIOs المفلترة داخليًا مع عملية BIO_ctrl() معينة، فإنها عادةً ما تمرر العملية إلى BIO التالي في السلسلة. هذا يعني غالبًا أنه لا حاجة لتحديد BIO المطلوب لعملية معينة: يمكن استدعاؤها على سلسلة وسيتم تمريرها تلقائيًا إلى BIO المناسب. ومع ذلك، يمكن أن يؤدي هذا إلى نتائج غير متوقعة. على سبيل المثال، لا تنفذ BIOs المفلترة الحالية BIO_seek()، ولكن قد ينجح هذا إذا انتهت السلسلة بـ BIO للملف أو واصف الملف.

ترجع BIOs المصدر/المصرف 0 إذا لم تتعرف على عملية BIO_ctrl().
