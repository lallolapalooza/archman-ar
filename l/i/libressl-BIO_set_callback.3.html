libressl-BIO_set_callback(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

NAME

BIO_set_callback, BIO_get_callback, BIO_set_callback_arg, BIO_get_callback_arg, BIO_callback_fn, BIO_callback_fn_ex, BIO_callback_ctrl, BIO_set_callback_ex, BIO_get_callback_ex, BIO_debug_callback - set and get BIO callback functions

SYNOPSIS

#include <openssl/bio.h>

BIO_set_callback(BIO *b, BIO_callback_cb *cb);
BIO_callback_cb *BIO_get_callback(BIO *b);
BIO_set_callback_arg(BIO *b, void *pointer);
void *BIO_get_callback_arg(BIO *b);
longBIO_debug_callback(BIO *b, int cmd, const char *arg, int arglen, long ret);

BIO_set_callback_ex(BIO *b, BIO_callback_fn_ex *callback);
BIO_callback_fn_ex *BIO_get_callback_ex(BIO *b);
BIO_callback_ctrl(BIO *b, int cmd, BIO_info_cb *fp);
BIO_callback_ctrl(BIO *b, int cmd, long larg, void *parg);
BIO_callback_ctrl(BIO *b, int cmd, long larg, void *parg);
BIO_callback_ctrl(BIO *b, int cmd, long larg, void *parg);

DESCRIPTION

The BIO routines provide a framework for reading and writing data. They can be extended by the use of callback functions.

There are two sets of callback functions: the older style BIO_callback_cb() callback (referred to as cb below) and the newer style BIO_callback_fn_ex() callback (referred to as cb_ex below).

The BIO_set_callback() function installs a callback function cb for the BIO b. The callback function cb is invoked before and after various operations on the BIO.

The BIO_set_callback_arg() function installs an arbitrary pointer pointer for the BIO b. This pointer can be retrieved later using BIO_get_callback_arg() and can be used to pass context information to the callback function.

The BIO_set_callback_ex() function installs a callback function callback for the BIO b. This is the newer style callback function. It is invoked before and after various operations on the BIO.

BIO_callback_ctrl() is a generic function to perform control operations on a BIO. It can be used to set or retrieve the callback function and callback argument.

The callback function cb has the following signature:

long cb(BIO *b, int oper, const char *arg, int arglen, long ret, long user_data);

The callback function cb_ex has the following signature:

long cb_ex(BIO *b, int event, const char *arg, int arglen, long ret, void *user_data);

The parameter b is the BIO that the operation is being performed on. The parameter event (or oper for cb) is a bitmask indicating the operation being performed. The lower 31 bits are the operation type, and the highest bit indicates if the callback is being invoked after the operation has completed (e.g. BIO_CB_RETURN). The parameter arg is a pointer to the data being processed, or data associated with the operation. The parameter arglen is the length of the data pointed to by arg. The parameter ret is the return value of the underlying BIO operation. The parameter user_data is the pointer set using BIO_set_callback_arg() or BIO_set_callback_ex().

The return value of the callback function is typically ignored, except in the case of BIO_debug_callback().

The following table shows the values of event (and oper) for different BIO operations:

Before the read operation:
cb_ex(b, BIO_CB_GETS, out, outl, 0, 0, 1, NULL)
or cb(b, BIO_CB_GETS, out, outl,    0, 1)
After the read operation:
cb_ex(b, BIO_CB_GETS|BIO_CB_RETURN, out, outl, 0, 0, ret, &bytes)
or cb(b, BIO_CB_GETS|BIO_CB_RETURN, out, outl,    0, ret)
In BIO_puts(BIO *b, const char *in):
before the write operation:
cb_ex(b, BIO_CB_PUTS, in, 0, 0, 0, 1, NULL)
or cb(b, BIO_CB_PUTS, in,    0, 0, 1)

after the write operation:
cb_ex(b, BIO_CB_PUTS|BIO_CB_RETURN, in, 0, 0, 0, ret, &bytes)
or cb(b, BIO_CB_PUTS|BIO_CB_RETURN, in,    0, 0, ret)
In BIO_ctrl(BIO *b, int cmd, long larg, void *parg):
before the control operation:
cb_ex(b, BIO_CB_CTRL, parg, 0, cmd, larg, 1, NULL)
or cb(b, BIO_CB_CTRL, parg,    cmd, larg, 1)

after the control operation:
cb_ex(b, BIO_CB_CTRL|BIO_CB_RETURN, parg, 0, cmd, larg, ret, NULL)
or cb(b, BIO_CB_CTRL|BIO_CB_RETURN, parg,    cmd, larg, ret)
In BIO_callback_ctrl(BIO *b, int cmd, BIO_info_cb *fp):
before the control operation:
cb_ex(b, BIO_CB_CTRL, fp, 0, cmd, 0, 1, NULL)
or cb(b, BIO_CB_CTRL, fp,    cmd, 0, 1)

after the control operation:
cb_ex(b, BIO_CB_CTRL|BIO_CB_RETURN, fp, 0, cmd, 0, ret, NULL)
or cb(b, BIO_CB_CTRL|BIO_CB_RETURN, fp,    cmd, 0, ret)

RETURN VALUES

BIO_get_callback_ex() returns a pointer to the function cb_ex previously installed with BIO_set_callback_cb(), or NULL if no such callback was installed.

BIO_get_callback() returns a pointer to the function cb previously installed with BIO_set_callback(), or NULL if no such callback was installed.

BIO_get_callback_arg() returns the pointer previously set with BIO_set_callback_arg(), or NULL if no such pointer was set.

BIO_debug_callback() returns ret if the bit BIO_CB_RETURN is set in cmd, or 1 otherwise.

EXAMPLES

The BIO_debug_callback() function is a good example. Its source is in the file crypto/bio/bio_cb.c.

HISTORY

BIO_set_callback(), BIO_get_callback(), BIO_set_callback_arg(), and BIO_debug_callback() first appeared in SSLeay 0.6.0. BIO_get_callback_arg() first appeared in SSLeay 0.8.0. These functions have been available since OpenBSD 2.4.

BIO_callback_fn() first appeared in OpenSSL 1.1.0. BIO_callback_fn_ex(), BIO_set_callback_ex(), and BIO_get_callback_ex() first appeared in OpenSSL 1.1.1. These functions have been available since OpenBSD 7.1.
