الوصف

PKCS7_add_attribute() يضيف سمة جديدة من النوع nid إلى قائمة unauthenticatedAttributes الخاصة بـ si، ويضيف كائن ASN.1 ANY جديد من النوع attrtype بالقيمة value المعطاة إلى السمة الجديدة. يتم نقل ملكية value إلى كائن السمة الجديد، لذلك يجب على الكود الذي يستدعيها عدم استدعاء free(3) لـ value. إذا كانت القائمة تحتوي بالفعل على سمة غير موثقة من النوع nid قبل الاستدعاء، فسيتم استبدال السمة الجديدة بالقديمة بدلاً من إلحاقها بنهاية القائمة.

PKCS7_set_attributes() يحرر قائمة unauthenticatedAttributes الخاصة بـ si وجميع السمات الموجودة فيها ويستبدلها بنسخة عميقة من sk.

PKCS7_get_attribute() يسترجع أول عضو ASN.1 ANY من السمة من النوع nid من قائمة unauthenticatedAttributes الخاصة بـ si.

سلوك PKCS7_add_signed_attribute()، PKCS7_set_signed_attributes()، و PKCS7_get_signed_attribute() متطابق ما عدا أنها تعمل على قائمة authenticatedAttributes.

الطريقة العادية لاستخدام PKCS7_add_signed_attribute() هي إنشاء كائن SignedInfo أولاً باستخدام PKCS7_sign(3) باستخدام العلم PKCS7_PARTIAL أو PKCS7_STREAM، استرداد كائن PKCS7_SIGNER_INFO باستخدام PKCS7_get_signer_info(3) أو إضافة كائن إضافي باستخدام PKCS7_sign_add_signer(3)، استدعاء PKCS7_add_signed_attribute() لكل سمة إضافية مرغوبة، ثم إجراء التوقيع باستخدام PKCS7_final(3) أو باستخدام وظيفة إنهاء أخرى.

الوظائف الأربعة المتبقية هي وظائف التفاف حول PKCS7_add_signed_attribute().

PKCS7_add_attrib_content_type() تحدد السمة NID_pkcs9_contentType إلى coid، والتي تحدد نوع المحتوى لقيمة ContentInfo المراد توقيعها. هذه السمة إلزامية ويتم إضافتها تلقائيًا بواسطة PKCS7_sign(3) و PKCS7_sign_add_signer(3) ما لم يكن العلم PKCS7_NOATTR موجودًا. يمكن الحصول على كائنات مناسبة كوسائط لـ coid على سبيل المثال باستخدام OBJ_nid2obj(3). إذا كان coid هو NULL، فإن نوع المحتوى يكون افتراضيًا NID_pkcs7_data.

PKCS7_add1_attrib_digest() يحدد أو يستبدل السمة NID_pkcs9_messageDigest، وهي الخلاصة الرسالة لمحتويات بايتات ترميز DER لحقل المحتوى لقيمة ContentInfo التي يتم توقيعها، بنسخة من md، والتي يُفترض أنها بطول mdlen بايت. إذا كان mdlen هو -1، فإنه يتم استخدام strlen(md) بدلاً من mdlen. هذه السمة إلزامية ويتم إضافتها تلقائيًا بواسطة PKCS7_dataFinal(3) و PKCS7_final(3).

PKCS7_add0_attrib_signing_time() يحدد أو يستبدل السمة الاختيارية NID_pkcs9_signingTime بـ t، مما يحدد الوقت الذي قام فيه الموقّع بعملية التوقيع. يتم نقل ملكية t إلى كائن السمة الجديد، لذلك يجب على الكود الذي يستدعيها عدم استدعاء free(3) لـ t. إذا كان t هو NULL، يتم تخصيص بنية ASN1_TIME جديدة. يتم إضافة هذه السمة تلقائيًا بواسطة PKCS7_dataFinal(3) و PKCS7_final(3).

PKCS7_add_attrib_smimecap() يحدد أو يستبدل السمة الاختيارية NID_SMIMECapabilities، مما يشير إلى الخوارزميات التي يكون المرسل مستعدًا للتعامل معها. لا يتم تخزين المؤشر cap في كائن السمة الجديد ويمكن تمريره إلى sk_X509_ALGOR_pop_free().

PKCS7_add_attribute(3) — LibreSSL — The absurdly simple, secure, and fast crypto library

NAME

PKCS7_add_attribute, PKCS7_set_attributes, PKCS7_get_attribute, PKCS7_add_signed_attribute, PKCS7_set_signed_attributes, PKCS7_get_signed_attribute, PKCS7_add_attrib_content_type, PKCS7_add1_attrib_digest, PKCS7_add0_attrib_signing_time, PKCS7_add_attrib_smimecap — PKCS#7 attributes

SYNOPSIS

#include <openssl/pkcs7.h>

int PKCS7_add_attribute(PKCS7_SIGNER_INFO *si, int nid, int type, void *value);
int PKCS7_set_attributes(PKCS7_SIGNER_INFO *si, STACK_OF(X509_ATTRIBUTE) *sk);
X509_ATTRIBUTE *PKCS7_get_attribute(PKCS7_SIGNER_INFO *si, int nid);
int PKCS7_add_signed_attribute(PKCS7_SIGNER_INFO *si, int nid, int type, void *value);
int PKCS7_set_signed_attributes(PKCS7_SIGNER_INFO *si, STACK_OF(X509_ATTRIBUTE) *sk);
X509_ATTRIBUTE *PKCS7_get_signed_attribute(PKCS7_SIGNER_INFO *si, int nid);
int PKCS7_add_attrib_content_type(PKCS7_SIGNER_INFO *si, ASN1_OBJECT *oid);
int PKCS7_add1_attrib_digest(PKCS7_SIGNER_INFO *si, const unsigned char *md, int len);
int PKCS7_add0_attrib_signing_time(PKCS7_SIGNER_INFO *si, ASN1_TIME *t);
int PKCS7_add_attrib_smimecap(PKCS7_SIGNER_INFO *si, STACK_OF(X509_ALGOR) *cap);

DESCRIPTION

PKCS7_add_attribute() and PKCS7_set_attributes() add or set attributes in the “attributes” field of the PKCS7_SIGNER_INFO structure pointed to by si. The attributes field is only present if the PKCS#7 structure is signed data, not otherwise.

PKCS7_add_attribute() adds a single attribute of type type and value value to the attributes of si. The attribute is identified by nid. The caller is responsible for freeing the value if it was allocated, except when type is V_ASN1_OBJECT, V_ASN1_NULL, V_ASN1_BOOLEAN, or V_ASN1_INTEGER. This function returns 1 on success and 0 on failure.

PKCS7_set_attributes() replaces the entire attributes list of si with the stack sk. The caller should no longer free sk after this call. This function returns 1 on success and 0 on failure.

PKCS7_get_attribute() returns a pointer to the attribute with the given nid from the attributes list of si, or NULL on failure.

PKCS7_add_signed_attribute() and PKCS7_set_signed_attributes() add or set attributes in the “signed attributes” field of the PKCS7_SIGNER_INFO structure pointed to by si. The signed attributes field is always present, and is always present in S/MIME messages.

PKCS7_add_signed_attribute() adds a single attribute of type type and value value to the signed attributes of si. The attribute is identified by nid. The caller is responsible for freeing the value if it was allocated, except when type is V_ASN1_OBJECT, V_ASN1_NULL, V_ASN1_BOOLEAN, or V_ASN1_INTEGER. This function returns 1 on success and 0 on failure.

PKCS7_set_signed_attributes() replaces the entire signed attributes list of si with the stack sk. The caller should no longer free sk after this call. This function returns 1 on success and 0 on failure.

PKCS7_get_signed_attribute() returns a pointer to the signed attribute with the given nid from the signed attributes list of si, or NULL on failure.

PKCS7_add_attrib_content_type() adds the PKCS#9 content type attribute to the signed attributes of si. The content type is specified by oid.

PKCS7_add1_attrib_digest() adds the PKCS#9 message digest attribute to the signed attributes of si. The digest is specified by md with length len.

PKCS7_add0_attrib_signing_time() adds the PKCS#9 signing time attribute to the signed attributes of si. The signing time is specified by t. Note that the last digit of the time string is dropped if it is present.

PKCS7_add_attrib_smimecap() adds the S/MIME capabilities attribute to the signed attributes of si. The capabilities are specified by the stack cap.

The attribute of type NID_pkcs9_messageDigest is added automatically by PKCS7_final(3) unless the PKCS7_NOATTR flag is present.

The attribute of type NID_pkcs9_signingTime is added automatically by PKCS7_final(3) unless the PKCS7_NOATTR flag is present.

The attribute of type NID_pkcs9_contentType is added automatically by PKCS7_final(3) unless the PKCS7_NOATTR flag is present.

The attribute of type NID_smimeEncryptionKeyUsage is added automatically by PKCS7_final(3) unless the PKCS7_NOATTR flag is present.

The attribute of type NID_smimeCapabilities is added automatically by PKCS7_final(3) unless the PKCS7_NOATTR or PKCS7_NOSMIMECAP flag is present.

Note that the functions that add attributes consume the value argument. If the caller wishes to free the value after the call, they must first duplicate it. For example: content = ASN1_OCTET_STRING_new(); ... PKCS7_add_attribute(si, NID_pkcs9_challengePassword, V_ASN1_OCTET_STRING, content); /* content is now owned by the PKCS7 structure */

PKCS7_add0_attrib_signing_time() does not take ownership of t. The caller is still responsible for freeing it after the call using PKCS7_final(3). The caller should ensure that t is not freed until after the PKCS7_final() call, and that the PKCS7 structure itself is not freed until after t has been freed. This means that in the common case, the caller should free t after calling PKCS7_final(). However, if PKCS7_final() fails, the caller should free t immediately.

The caller is responsible for freeing the returned X509_ALGOR structure using sk_X509_ALGOR_pop_free(3)() after the call. This attribute is automatically added by PKCS7_sign(3) and PKCS7_sign_add_signer(3) unless the PKCS7_NOATTR or PKCS7_NOSMIMECAP flag is present.

RETURN VALUES

PKCS7_add_attribute(), PKCS7_set_attributes(), PKCS7_add_signed_attribute(), PKCS7_set_signed_attributes(), PKCS7_add_attrib_content_type(), PKCS7_add1_attrib_digest(), PKCS7_add0_attrib_signing_time(), and PKCS7_add_attrib_smimecap() return 1 on success or 0 on failure. The most common reason for failure is lack of memory. PKCS7_add_attribute() and PKCS7_add_signed_attribute() also fail if nid is invalid, and PKCS7_add_attrib_content_type() if si already contains an authenticated attribute of type NID_pkcs9_contentType.

PKCS7_get_attribute() and PKCS7_get_signed_attribute() return an internal pointer to an ASN.1 ANY object or NULL on failure. They fail if nid is invalid, if the respective list in si contains no attribute of the requested type, or if an invalid element is found in the list before finding the attribute of the requested type.

STANDARDS

RFC 2315: PKCS #7: Cryptographic Message Syntax Version 1.5, section 9.2: SignerInfo type

RFC 2985: PKCS #9: Selected Object Classes and Attribute Types Version 2.0, section 5.3: Attribute types for use in PKCS #7 data and section 5.6: Attributes defined in S/MIME

RFC 5652: Cryptographic Message Syntax (CMS), section 5.3: SignerInfo Type and section 11: Useful Attributes

RFC 8551: Secure/Multipurpose Internet Mail Extensions (S/MIME) Version 4.0 Message Specification, section 2.5.2: SMIMECapabilities Attribute

HISTORY

PKCS7_add_attribute(), PKCS7_set_attributes(), PKCS7_get_attribute(), PKCS7_add_signed_attribute(), PKCS7_set_signed_attributes(), and PKCS7_get_signed_attribute() first appeared in OpenSSL 0.9.1 and have been available since OpenBSD 2.6.

PKCS7_add_attrib_smimecap() first appeared in OpenSSL 0.9.5 and has been available since OpenBSD 2.7.

PKCS7_add_attrib_content_type(), PKCS7_add1_attrib_digest(), and PKCS7_add0_attrib_signing_time() first appeared in OpenSSL 1.0.0 and have been available since OpenBSD 4.9.

CAVEATS

PKCS7_set_signed_attributes() does not validate that sk contains the PKCS #9 content type and message digest attributes required by RFC 2315. It succeeds even when sk is empty, leaving si in a state that violates the standard.

PKCS7_add0_attrib_signing_time() does not validate t beyond checking that it is well-formed per RFC 5652, section 11.3. In particular, it may set the signing time to the future or to the remote past.

BUGS

A function to remove individual attributes from these lists does not appear to exist. A program desiring to do that might have to manually iterate the fields auth_attr and unauth_attr of si, which are both of type STACK_OF(X509_ATTRIBUTE), using the facilities described in STACK_OF(3) and OPENSSL_sk_new(3).
