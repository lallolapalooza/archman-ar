الوصف

هذه واجهات مستقلة عن الخوارزمية لفك ترميز وإنشاء المفاتيح الخاصة والعامة. للحصول على تفاصيل حول الدلالات والأمثلة والتحذيرات والأخطاء، راجع ASN1_item_d2i(3).

d2i_PrivateKey() يقوم بفك ترميز مفتاح خاص باستخدام الخوارزمية type. يحاول استخدام أي تنسيق خاص بالخوارزمية أو تنسيق PrivateKeyInfo غير المشفر PKCS#8 المحدد في RFC 5208 القسم 5. يجب أن يكون المعلم type ثابت خوارزمية مفتاح عام مثل EVP_PKEY_RSA. يحدث خطأ إذا لم يتطابق المفتاح الذي تم فك ترميزه مع type.

d2i_AutoPrivateKey() مشابه لـ d2i_PrivateKey() باستثناء أنه يحاول اكتشاف الخوارزمية تلقائيًا.

d2i_PrivateKey_bio() و d2i_PrivateKey_fp() مشابهة لـ d2i_PrivateKey() باستثناء أنها تقرأ من مؤشر BIO أو FILE.

i2d_PrivateKey() يقوم بإنشاء (ترميز) val_in. يستخدم تنسيقًا خاصًا بالخوارزمية أو، إذا لم يتم تعريف تنسيق لهذا النوع من المفاتيح، تنسيق PrivateKeyInfo غير المشفر PKCS#8.

i2d_PrivateKey_bio() و i2d_PrivateKey_fp() مشابهة لـ i2d_PrivateKey() باستثناء أنها تكتب إلى مؤشر BIO أو FILE وتستخدم اصطلاحًا مختلفًا لقيم الإرجاع الخاصة بها.

i2d_PKCS8PrivateKeyInfo_bio() و i2d_PKCS8PrivateKeyInfo_fp() تقوم بإنشاء (ترميز) val_in بتنسيق PrivateKeyInfo غير المشفر PKCS#8. وهي مشابهة لـ i2d_PrivateKey() باستثناء أنها لا تستخدم أي تنسيقات خاصة بالخوارزمية وأنها تكتب إلى مؤشر BIO أو FILE بدلاً من المخزن المؤقت.

تستخدم جميع هذه الوظائف تنسيق DER والمفاتيح غير المشفرة. التطبيقات التي ترغب في تشفير أو فك تشفير المفاتيح الخاصة يجب أن تستخدم وظائف أخرى مثل d2i_PKCS8PrivateKey_bio(3) بدلاً من ذلك.

إذا كان *val_out ليس NULL عند استدعاء d2i_PrivateKey() أو d2i_AutoPrivateKey() (أي، يتم إعادة استخدام بنية موجودة) وكان تنسيق المفتاح هو PKCS#8، فسيتم تحرير *val_out واستبداله عند نجاح الاستدعاء.

d2i_PublicKey() يستدعي d2i_DSAPublicKey(3)، o2i_ECPublicKey(3)، أو d2i_RSAPublicKey(3) اعتمادًا على type ويخزن النتيجة في كائن EVP_PKEY الذي تم إرجاعه.

i2d_PublicKey() يستدعي i2d_DSAPublicKey(3)، i2o_ECPublicKey(3)، أو i2d_RSAPublicKey(3) اعتمادًا على الخوارزمية المستخدمة بواسطة val_in.

قيم الإرجاع

d2i_PrivateKey()، d2i_AutoPrivateKey()، d2i_PrivateKey_bio()، d2i_PrivateKey_fp()، و d2i_PublicKey() ترجع بنية EVP_PKEY صالحة أو NULL في حالة حدوث خطأ.

i2d_PrivateKey() و i2d_PublicKey() ترجع عدد البايتات التي تم إنشاؤها (ترميزها) بنجاح أو قيمة سالبة في حالة حدوث خطأ.

i2d_PrivateKey_bio()، i2d_PrivateKey_fp()، i2d_PKCS8PrivateKeyInfo_bio()، و i2d_PKCS8PrivateKeyInfo_fp() ترجع 1 للنجاح أو 0 في حالة حدوث خطأ.

لجميع الوظائف، يمكن الحصول على رمز الخطأ عن طريق استدعاء ERR_get_error(3).

NAME

d2i_PrivateKey, i2d_PrivateKey, d2i_PublicKey, i2d_PublicKey, d2i_AutoPrivateKey, d2i_PrivateKey_bio, d2i_PrivateKey_fp, i2d_PrivateKey_bio, i2d_PrivateKey_fp, i2d_PKCS8PrivateKeyInfo_bio, i2d_PKCS8PrivateKeyInfo_fp - DER de/serialization of private and public keys

SYNOPSIS

#include <openssl/evp.h>
#include <openssl/pem.h>

Functions for DER format:

EVP_PKEY *d2i_PrivateKey(EVP_PKEY **x, const unsigned char **in, long len);
int i2d_PrivateKey(const EVP_PKEY *x, unsigned char **out);
EVP_PKEY *d2i_PublicKey(EVP_PKEY **x, const unsigned char **in, long len);
int i2d_PublicKey(const EVP_PKEY *x, unsigned char **out);
EVP_PKEY *d2i_AutoPrivateKey(EVP_PKEY **x, const unsigned char **in, long len);

Functions for BIO objects:

EVP_PKEY *d2i_PrivateKey_bio(BIO *bp, EVP_PKEY **x);
int i2d_PrivateKey_bio(BIO *bp, EVP_PKEY *x);
int i2d_PKCS8PrivateKeyInfo_bio(BIO *bp, PKCS8_PRIV_INFO *p8inf);

Functions for FILE pointers:

EVP_PKEY *d2i_PrivateKey_fp(FILE *fp, EVP_PKEY **x);
int i2d_PrivateKey_fp(FILE *fp, EVP_PKEY *x);
int i2d_PKCS8PrivateKeyInfo_fp(FILE *fp, PKCS8_PRIV_INFO *p8inf);

DESCRIPTION

These functions convert between the DER-encoded representation of private and public keys and the EVP_PKEY structure.

d2i_PrivateKey and d2i_PublicKey attempt to decode a DER-encoded private key and public key, respectively, from the memory location pointed to by in. The decoded key is stored in the EVP_PKEY structure pointed to by x. If x is NULL, a new EVP_PKEY structure is allocated. The in pointer is advanced to point to the data immediately following the decoded key. The len argument is the total number of bytes available at in.

i2d_PrivateKey and i2d_PublicKey attempt to encode the private key x and public key x, respectively, into DER format. If out is NULL, a buffer is allocated to hold the DER encoding. The allocated buffer will be freed by the caller. If out is not NULL, the DER encoding is written to the buffer pointed to by out. The return value is the number of bytes written. The caller is responsible for freeing the allocated buffer if out was NULL.

d2i_AutoPrivateKey is a convenience function that attempts to decode a private key from the DER-encoded input data. It tries to determine the key type and then calls the appropriate specific decode function.

d2i_PrivateKey_bio and d2i_PrivateKey_fp attempt to decode a DER-encoded private key from a BIO object and a FILE pointer, respectively. They are equivalent to calling d2i_PrivateKey after reading the appropriate amount of data from the BIO or FILE pointer.

i2d_PrivateKey_bio and i2d_PrivateKey_fp attempt to encode the private key x into DER format and write it to a BIO object and a FILE pointer, respectively.

i2d_PKCS8PrivateKeyInfo_bio and i2d_PKCS8PrivateKeyInfo_fp encode a PKCS#8 private key information structure into DER format and write it to a BIO object and a FILE pointer, respectively.

RETURN VALUES

d2i_PrivateKey, d2i_PublicKey, and d2i_AutoPrivateKey return a pointer to the newly created EVP_PKEY structure on success, or NULL on failure.

i2d_PrivateKey and i2d_PublicKey return the number of bytes in the encoded output on success, or a non-positive value on failure.

d2i_PrivateKey_bio and d2i_PrivateKey_fp return a pointer to the newly created EVP_PKEY structure on success, or NULL on failure.

i2d_PrivateKey_bio, i2d_PrivateKey_fp, i2d_PKCS8PrivateKeyInfo_bio, and i2d_PKCS8PrivateKeyInfo_fp return 1 on success, and 0 or a non-positive value on failure.

HISTORY

d2i_PrivateKey(), i2d_PrivateKey(), d2i_PublicKey(), and i2d_PublicKey() first appeared in SSLeay 0.6.0 and have been available since OpenBSD 2.4.

d2i_AutoPrivateKey(), d2i_PrivateKey_bio(), d2i_PrivateKey_fp(), i2d_PrivateKey_bio(), i2d_PrivateKey_fp(), i2d_PKCS8PrivateKeyInfo_bio(), and i2d_PKCS8PrivateKeyInfo_fp() first appeared in OpenSSL 0.9.5 and have been available since OpenBSD 2.7.
