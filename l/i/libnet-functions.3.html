وظائف بناء الحزمة

جوهر libnet هي وظائف بناء الحزم المستقلة عن النظام الأساسي. تتيح هذه الوظائف لمبرمج التطبيق بناء ترويسات البروتوكول (والبيانات) بطريقة بسيطة ومتسقة دون الحاجة إلى القلق (بشكل مفرط) بشأن التفاصيل الشبكية منخفضة المستوى. كل دالة libnet_build() تبني جزءًا من الحزمة (عادةً ترويسة بروتوكول). في حين أنه من الممكن تمامًا بناء حزمة كاملة جاهزة للإرسال باستدعاء واحد لدالة libnet_build()، إلا أنه يتطلب بشكل عام أكثر من استدعاء واحد لدالة من فئة البناء لإنشاء حزمة كاملة. تتكون الحزمة الكاملة الجاهزة للإرسال عادةً من أكثر من جزء واحد. كل دالة تبني ترويسة بروتوكول تأخذ سلسلة من الوسائط المقابلة تقريبًا لقيم الترويسة كما تظهر على السلك. هذه العملية بديهية ولكنها غالبًا ما تؤدي إلى دوال ذات نماذج أولية ضخمة وإطارات مكدس كبيرة. أحد الأشياء المهمة التي يجب ملاحظتها هو أنه يجب عليك استدعاء هذه الدوال بالترتيب، المقابل لكيفية ظهورها على السلك (من أعلى طبقة بروتوكول لأسفل). هذه العملية البناء بديهية؛ إنها تقارب ما يحدث في نواة نظام التشغيل. بمعنى آخر، لبناء حزمة بروتوكول وقت الشبكة (NTP) باستخدام واجهة طبقة الربط، سيستدعي مبرمج التطبيق دوال libnet_build() بالترتيب التالي:

1.
libnet_build_ntp()
2.
libnet_build_udp()
3.
libnet_build_ipv4()
4.
libnet_build_ethernet() هذا الترتيب ضروري لـ libnet 1.1.x لربط الحزمة داخليًا بشكل صحيح (الإصدارات السابقة من libnet لم يكن لديها هذا المتطلب).

واجهة الحمولة

تحدد واجهة الحمولة طريقة اختيارية لتضمين البيانات مباشرة بعد ترويسة البروتوكول المعنية. يمكنك استخدام هذه الدالة لمجموعة متنوعة من الأغراض، بما في ذلك ما يلي:

  • تضمين معلومات ترويسة بروتوكول إضافية أو عشوائية غير متوفرة من واجهة libnet
  • تضمين حمولة حزمة (قطاع بيانات)
  • بناء ترويسة بروتوكول أخرى غير متوفرة من واجهة libnet لاستخدام الواجهة، يجب على مبرمج التطبيق إنشاء بيانات حمولة i وتمرير const uint8_t * إلى هذه البيانات وحجمها إلى دالة libnet_build() المطلوبة. libnet يعالج الباقي.

من المهم ملاحظة أن بعض الدوال (خاصة بناة IPv6) تستخدم واجهة الحمولة لتحديد بيانات متغيرة الطول ولكنها ظاهريًا غير اختيارية. راجع دوال libnet_build_ipv6*() الفردية لمزيد من المعلومات.

ينشئ بيئة libnet. يقوم بتهيئة المكتبة ويعيد سياق libnet. إذا كان نوع الحقن هو LIBNET_LINK أو LIBNET_LINK_ADV، تقوم الدالة بتهيئة أولويات الحقن لواجهة طبقة الارتباط، مما يمكّن مبرمج التطبيق من بناء حزم بدءًا من طبقة ربط البيانات (مما يوفر أيضًا تحكمًا أكثر تفصيلاً في طبقة IP). إذا استخدم libnet طبقة ربط البيانات وكان الوسيط device غير NULL، تحاول الدالة استخدام جهاز الشبكة المحدد لحقن الحزم. هذا هو إما سلسلة نصية معيارية تشير إلى الجهاز (مثل 'eth0' لبطاقة Ethernet بسرعة 100 ميجابت على Linux أو 'fxp0' لبطاقة Ethernet بسرعة 100 ميجابت على OpenBSD) أو تمثيل النقاط والعشري لعنوان IP للجهاز (192.168.0.1). إذا كان device NULL، يحاول libnet العثور على جهاز مناسب للاستخدام. إذا كان نوع الحقن هو LIBNET_RAW4 أو LIBNET_RAW4_ADV، تقوم الدالة بتهيئة أولويات الحقن لواجهة مقبس IPv4 الخام. يجب أن يكون الوسيط الأخير، err_buf، مخزنًا مؤقتًا بحجم LIBNET_ERRBUF_SIZE ويحتوي على رسالة خطأ إذا فشلت الدالة. تتطلب هذه الدالة امتيازات الجذر للتنفيذ بنجاح. عند النجاح، تعيد الدالة سياق libnet صالحًا للاستخدام في استدعاءات الدوال اللاحقة؛ عند الفشل، تعيد الدالة NULL.

المعلمات

injection_type نوع حقن الحزم (LIBNET_LINK، LIBNET_LINK_ADV، LIBNET_RAW4، LIBNET_RAW4_ADV، LIBNET_RAW6، LIBNET_RAW6_ADV)
device الواجهة المراد استخدامها (NULL وسيقوم libnet بالاختيار)
err_buf ستحتوي على رسالة خطأ عند الفشل

الإرجاع

سياق libnet جاهز للاستخدام أو NULL عند حدوث خطأ.

LIBNET_API void libnet_toggle_checksum (libnet_t * l, int ptag, int mode)

With the checksum field set to '0', by default libnet will calculate the header checksum prior to injection. If the header is set to any other value, by default libnet will not calculate the header checksum. To over-ride this behavior, use libnet_toggle_checksum(). Switches auto-checksumming on or off for the specified ptag. If mode is set to LIBNET_ON, libnet will mark the specified ptag to calculate a checksum for the ptag prior to injection. This assumes that the ptag refers to a protocol that has a checksum field. If mode is set to LIBNET_OFF, libnet will clear the checksum flag and no checksum will be computed prior to injection. This assumes that the programmer will assign a value (zero or otherwise) to the checksum field. Often times this is useful if a precomputed checksum or some other predefined value is going to be used. Note that when libnet is initialized with LIBNET_RAW4, the IPv4 header checksum will always be computed by the kernel prior to injection, regardless of what the programmer sets.

Parameters

l pointer to a libnet context
ptag the ptag reference number
mode LIBNET_ON or LIBNET_OFF

Return values

1 on success
-1 on failure

LIBNET_API int libnet_write (libnet_t * l)

Writes a prebuilt packet to the network. The function assumes that l was previously initialized (via a call to libnet_init()) and that a previously constructed packet has been built inside this context (via one or more calls to the libnet_build* family of functions) and is ready to go. Depending on how libnet was initialized, the function will write the packet to the wire either via the raw or link layer interface. The function will also bump up the internal libnet stat counters which are retrievable via libnet_stats().

Parameters

l pointer to a libnet context

Returns

the number of bytes written

Return values

-1 on error
