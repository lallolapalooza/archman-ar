BIO_FIND_TYPE(3) دليل الوظائف المكتبية BIO_FIND_TYPE(3)

الاسم

BIO_find_type، BIO_next، BIO_method_type، BIO_method_name — استعراض سلسلة BIO

الملخص

مكتبة «libcrypto»
#include <openssl/bio.h>

BIO *
BIO_find_type(BIO *bio، int type);

BIO *
BIO_next(BIO *bio);

int
BIO_method_type(const BIO *bio);

const char *
BIO_method_name(const BIO *bio);

#define BIO_TYPE_NONE 0
#define BIO_TYPE_START 128

الوصف

BIO_find_type() تبحث عن BIO مطابق للنوع المحدد type في السلسلة التي تبدأ من bio. إذا كان البايت الأقل أهمية من الوسيط type غير صفري، يتم قبول المطابقات الدقيقة للنوع type فقط. خلاف ذلك، يتطلب التطابق فقط أن يتم تعيين أي من البتات الموجودة في الوسيط type في BIO المرشح.

الأنواع التي يكون فيها البايت الأقل أهمية في النطاق من 0 إلى BIO_TYPE_START، شاملة، محجوزة لأنواع BIO المدمجة في المكتبة. الأنواع التي يكون فيها البايت الأقل أهمية أكبر من BIO_TYPE_START متاحة لأنواع BIO المعرفة من قبل المستخدم؛ راجع BIO_get_new_index(3) للتفاصيل.

BIO_next() ترجع BIO التالي في السلسلة بعد bio. يمكن استخدام هذه الوظيفة لاستعراض جميع BIOs في سلسلة أو بالاقتران مع BIO_find_type() للعثور على جميع BIOs من نوع معين.

BIO_method_type() ترجع نوع bio المحدد.

BIO_method_name() ترجع سلسلة ASCII تمثل نوع bio.

فيما يلي أنواع BIO المصدر/المصرف المدمجة التي تعمل على واصفات الملفات. كلها تحتوي على كل من البتات BIO_TYPE_SOURCE_SINK و BIO_TYPE_DESCRIPTOR ولكن ليس البت BIO_TYPE_FILTER المحدد في ثابت النوع الخاص بها.

ثابت النوع سلسلة الاسم BIO_METHOD
BIO_TYPE_ACCEPT قبول مقبس BIO_s_accept(3)
BIO_TYPE_CONNECT اتصال مقبس BIO_s_connect(3)
BIO_TYPE_DGRAM مقبس بيانات BIO_s_datagram(3)
BIO_TYPE_FD واصف ملف BIO_s_fd(3)
BIO_TYPE_SOCKET مقبس BIO_s_socket(3)

فيما يلي أنواع BIO المصدر/المصرف المدمجة التي لا تعمل مباشرة على واصفات الملفات. كلها تحتوي على البت BIO_TYPE_SOURCE_SINK ولكن ليس البتات BIO_TYPE_DESCRIPTOR و BIO_TYPE_FILTER المحددة في ثابت النوع الخاص بها.

ثابت النوع سلسلة الاسم BIO_METHOD
BIO_TYPE_BIO زوج BIO BIO_s_bio(3)
BIO_TYPE_FILE مؤشر ملف BIO_s_file(3)
BIO_TYPE_MEM مخزن مؤقت للذاكرة BIO_s_mem(3)
BIO_TYPE_NULL فارغ BIO_s_null(3)

فيما يلي أنواع BIO المفلترة المدمجة. كلها تحتوي على البت BIO_TYPE_FILTER ولكن ليس البتات BIO_TYPE_SOURCE_SINK و BIO_TYPE_DESCRIPTOR المحددة في ثابت النوع الخاص بها.

ثابت النوع سلسلة الاسم BIO_METHOD
BIO_TYPE_BASE64 ترميز base64 BIO_f_base64(3)
BIO_TYPE_BUFFER مخزن مؤقت BIO_f_buffer(3)
BIO_TYPE_CIPHER تشفير BIO_f_cipher(3)
BIO_TYPE_MD تجزئة رسالة BIO_f_md(3)
BIO_TYPE_NULL_FILTER مرشح فارغ BIO_f_null(3)
BIO_TYPE_SSL ssl BIO_f_ssl(3)

الثوابت BIO_TYPE_BER، BIO_TYPE_PROXY_CLIENT، و BIO_TYPE_PROXY_SERVER لا تتوافق مع أي أنواع BIO تنفذها المكتبة ولا يُقصد استخدامها لأنواع معرفة من التطبيق أيضًا. الثوابت BIO_TYPE_COMP، BIO_TYPE_LINEBUFFER، و BIO_TYPE_NBIO_TEST تتوافق مع أنواع BIO مهملة وغير موثقة عمدًا.

إذا كان متغير في برنامج تطبيق مخصص لتخزين نوع BIO ولكنه لا يشير مؤقتًا إلى أي BIO أو يشير إلى BIO من نوع غير معروف، يوصى بتعيين المتغير إلى BIO_TYPE_NONE.

قيم الإرجاع

BIO_find_type() ترجع BIO المطابق التالي أو NULL إذا كان bio مؤشر NULL أو إذا لم يتم العثور على BIO مطابق.

BIO_next() ترجع BIO التالي أو NULL إذا كان bio مؤشر NULL أو يشير

DESCRIPTION

The BIO library provides a mechanism for writing and reading data. It is often used in the form of a chain, where data passes through a sequence of BIOs, each performing some transformation or action on the data. For example, a common chain might consist of a connection BIO, followed by an SSL BIO, followed by a BIO for compressing data.

BIO_find_type() searches the BIO chain starting at bio for a BIO of the specified type. The type should be one of the BIO_TYPE_* constants, for example BIO_TYPE_MD for a digest BIO.

BIO_next() returns the next BIO in the chain after bio. It returns NULL if bio is the last BIO in the chain.

BIO_method_type() returns the type of the BIO method associated with bio.

BIO_method_name() returns the name of the BIO method associated with bio.

BIO_sock_error() returns the last socket error that occurred on a socket-based BIO.

BIO_fd_nonblock() returns non-zero if the file descriptor underlying the BIO is in non-blocking mode.

BIO_set_callback() and BIO_get_callback() set and get the user-defined callback function for the BIO.

BIO_set_callback_arg() and BIO_get_callback_arg() set and get the user-defined argument for the BIO callback.

BIO_get_host_address() returns the host address associated with a connection BIO. The return value is an internal pointer and should not be freed.

RETURN VALUES

BIO_find_type() returns a pointer to the first BIO of the specified type found in the chain, or NULL if no such BIO is found. Note that BIO_find_type() will search the entire chain, potentially wrapping around.

BIO_next() returns the next BIO in the chain, or NULL if called on the last BIO in a chain.

BIO_method_type() returns one of the BIO_TYPE_* constants.

BIO_method_name() returns an internal pointer to a string.

EXAMPLES

Traverse a chain looking for digest BIOs:

BIO *btmp;

btmp = in_bio;	/* in_bio is the chain to search through */
while (btmp != NULL) {
	btmp = BIO_find_type(btmp, BIO_TYPE_MD);
	if (btmp == NULL)
		break;	/* Not found */

	/* btmp is a digest BIO, do something with it ... */
	...

	btmp = BIO_next(btmp);
}

HISTORY

BIO_method_type() and BIO_method_name() first appeared in SSLeay 0.6.0. BIO_find_type() first appeared in SSLeay 0.6.6. These functions have been available since OpenBSD 2.4.

BIO_next() first appeared in OpenSSL 0.9.6 and has been available since OpenBSD 2.9.
