الوصف

الوظيفة EVP_PKEY_keygen_init() تهيء سياق خوارزمية المفتاح العام باستخدام ctx->pkey لعملية إنشاء مفتاح.

الوظيفة EVP_PKEY_keygen() تقوم بعملية إنشاء مفتاح. يتم كتابة المفتاح المنشأ في ppkey.

الوظائف EVP_PKEY_paramgen_init() و EVP_PKEY_paramgen() مشابهة ما عدا أنه يتم إنشاء المعلمات.

الوظائف EVP_PKEY_CTX_set_cb() و EVP_PKEY_CTX_get_cb() تقومان بتعيين واسترداد دالة الاستدعاء لإنشاء المفتاح أو المعلمات على التوالي.

الوظيفة EVP_PKEY_CTX_set0_keygen_info() تعين المعلمات المرتبطة بعملية الإنشاء إلى المصفوفة dat التي تحتوي على datlen معلمة عدد صحيح. يحتفظ المتصل بملكية المصفوفة dat؛ ولن يتم تحريرها مطلقًا بواسطة المكتبة.

الوظيفة EVP_PKEY_CTX_get_keygen_info() ترجع المعلمات المرتبطة بعملية الإنشاء. إذا كان idx يساوي -1، يتم إرجاع العدد الإجمالي للمعلمات المتاحة. أي قيمة غير سالبة ترجع قيمة تلك المعلمة. يجب استدعاء EVP_PKEY_CTX_get_keygen_info() بقيمة غير سالبة لـ idx فقط داخل دالة الاستدعاء.

إذا أعادت دالة الاستدعاء قيمة 0، فسيتم إلغاء عملية إنشاء المفتاح وتحدث خطأ. قد يحدث هذا أثناء عملية تستغرق وقتًا طويلاً حيث ينقر المستخدم على زر "إلغاء".

الوظائف EVP_PKEY_CTX_set_app_data() و EVP_PKEY_CTX_get_app_data() تقومان بتعيين واسترداد مؤشر غامض. يمكن استخدام هذا لتعيين قيمة معينة للتطبيق يمكن استردادها في دالة الاستدعاء: على سبيل المثال، مقبض يستخدم لتحديث "مربع حوار التقدم".

الوظائف التي تم إيقاف استخدامها EVP_PKEY_CTX_set_data() و EVP_PKEY_CTX_get_data() تقومان بتعيين واسترداد مؤشر غامض مختلف يتم تجاهله بواسطة المكتبة.

بعد استدعاء EVP_PKEY_keygen_init() أو EVP_PKEY_paramgen_init()، يمكن إجراء عمليات تحكم خاصة بالخوارزمية لتعيين أي معلمات مناسبة للعملية.

يمكن استدعاء الوظائف EVP_PKEY_keygen() و EVP_PKEY_paramgen() أكثر من مرة على نفس السياق إذا تم إجراء عدة عمليات باستخدام نفس المعلمات.

يعتمد معنى المعلمات التي تم تمريرها إلى دالة الاستدعاء على الخوارزمية والتنفيذ المحدد للخوارزمية. قد لا يقدم البعض أي معلومات مفيدة على الإطلاق أثناء إنشاء المفتاح أو المعلمات. قد لا يستدعي البعض الآخر دالة الاستدعاء.

العملية التي تنفذها عملية إنشاء المفتاح أو المعلمات تعتمد على الخوارزمية المستخدمة. في بعض الحالات (على سبيل المثال، EC مع منحنى مسمى تم تقديمه) فإن خيار "الإنشاء" يقوم ببساطة بتعيين الحقول المناسبة في بنية EVP_PKEY.

في OpenSSL، تحتوي بنية EVP_PKEY التي تحتوي على مفتاح خاص أيضًا على مكونات المفتاح العام والمعلمات (إن وجدت). المفتاح الخاص في OpenSSL يعادل ما تسميه بعض المكتبات "زوج مفاتيح". يمكن استخدام المفتاح الخاص في الوظائف التي تتطلب استخدام مفتاح عام أو معلمات.

قيم الإرجاع

EVP_PKEY_keygen_init(), EVP_PKEY_paramgen_init(), EVP_PKEY_keygen(), و EVP_PKEY_paramgen() ترجع 1 للنجاح و 0 أو قيمة سالبة للفشل. على وجه الخصوص، يشير رمز الإرجاع -2 إلى أن العملية غير مدعومة من قبل خوارزمية المفتاح العام.

من المفترض أن ترجع دوال الاستدعاء من النوع EVP_PKEY_gen_cb() قيمة 1 عند النجاح أو 0 عند حدوث خطأ.

EVP_PKEY_CTX_get_cb() ترجع مؤشر وظيفة إلى دالة الاستدعاء المثبتة حاليًا أو NULL إذا لم تكن هناك دالة استدعاء مثبتة.

EVP_PKEY_CTX_get_keygen_info() ترجع عدد المعلمات المتاحة إذا كان idx يساوي -1، إحدى هذه المعلمات إذا كان idx أكبر من أو يساوي

NAME

EVP_PKEY_keygen, EVP_PKEY_keygen_init, EVP_PKEY_CTX_set_keygen_info, EVP_PKEY_CTX_get_keygen_info, EVP_PKEY_CTX_set_app_data, EVP_PKEY_CTX_get_app_data, EVP_PKEY_CTX_get_data — public key generation functions

SYNOPSIS

#include <openssl/evp.h>

int
EVP_PKEY_keygen_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_keygen(EVP_PKEY_CTX *ctx, EVP_PKEY **ppkey);

int
EVP_PKEY_CTX_set_keygen_info(EVP_PKEY_CTX *ctx, int request, int value);

int
EVP_PKEY_CTX_get_keygen_info(EVP_PKEY_CTX *ctx, int request);

void
EVP_PKEY_CTX_set_app_data(EVP_PKEY_CTX *ctx, void *data);

void *
EVP_PKEY_CTX_get_app_data(EVP_PKEY_CTX *ctx);

void *
EVP_PKEY_CTX_get_data(EVP_PKEY_CTX *ctx);

DESCRIPTION

The EVP_PKEY API provides a generic interface to public key algorithms. EVP_PKEY_keygen_init() and EVP_PKEY_keygen() are used to generate a public/private key pair.

A key generation context is created using EVP_PKEY_CTX_new() or EVP_PKEY_CTX_new_id(). EVP_PKEY_keygen_init() must be called before EVP_PKEY_keygen(). EVP_PKEY_keygen_init() initializes the key generation operation within the context ctx.

EVP_PKEY_keygen() performs the key generation. The generated public/private key pair is returned in ppkey. The caller is responsible for freeing the returned EVP_PKEY structure using EVP_PKEY_free(3).

Some key generation operations may need specific parameters to be set, for example, the number of bits for an RSA key. These can be set using EVP_PKEY_CTX_ctrl() or EVP_PKEY_CTX_ctrl_str(). Alternatively, some common parameters may be available through specific functions like EVP_PKEY_CTX_set_rsa_keygen_bits().

The generation process can be monitored by setting a callback function using EVP_PKEY_CTX_set_callback(). The callback function is invoked at various stages of the generation process. The callback is passed the EVP_PKEY_CTX pointer.

The application can pass arbitrary data to the callback function using EVP_PKEY_CTX_set_app_data(). This data can be retrieved within the callback using EVP_PKEY_CTX_get_app_data().

The callback function can request information about the generation process using EVP_PKEY_CTX_get_keygen_info(). The request parameter specifies what information is requested. Currently, the following requests are supported:

0
Returns the current stage of the key generation. The return value is a bitmask of flags describing the current stage. Possible flags are:
0
No progress.
1
A parameter has been generated.
2
A sub-problem has been generated.
3
A key has been generated.

The callback function should return 1 on success and 0 or a negative value on error.

Information can also be set for the callback using EVP_PKEY_CTX_set_keygen_info(). The request parameter specifies what information is being set. The value parameter is the value to set. Currently, the following requests are supported:

0
Set the number of bits for the key being generated. This is equivalent to calling EVP_PKEY_CTX_set_rsa_keygen_bits().

EVP_PKEY_CTX_get_data() returns the pointer that was last passed to EVP_PKEY_CTX_ctrl() with the EVP_PKEY_CTRL_SET_DATA command.

The return value of EVP_PKEY_CTX_get_keygen_info() is the number of available parameters, or less than the number of available parameters, or 0 otherwise.

EVP_PKEY_CTX_get_app_data() and EVP_PKEY_CTX_get_data() return the pointer that was last passed to the corresponding set function, or NULL if the corresponding set function was never called on ctx.

EXAMPLES

Generate a 2048-bit RSA key:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL;

ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA, NULL);
if (!ctx)
	/* Error occurred */
if (EVP_PKEY_keygen_init(ctx) <= 0)
	/* Error */
if (EVP_PKEY_CTX_set_rsa_keygen_bits(ctx, 2048) <= 0)
	/* Error */

/* Generate key */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* Error */

Generate a key from a set of parameters:

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
EVP_PKEY *pkey = NULL, *param;

/* Assumes that param is already set up. */
ctx = EVP_PKEY_CTX_new(param, NULL);
if (!ctx)
	/* Error occurred */
if (EVP_PKEY_keygen_init(ctx) <= 0)
	/* Error */

/* Generate key */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* Error */

Example of generation callback for OpenSSL public key implementations:

/* Application data is a BIO to output status to */

EVP_PKEY_CTX_set_app_data(ctx, status_bio);

static int
genpkey_cb(EVP_PKEY_CTX *ctx)
{
	char c = '*';
	BIO *b = EVP_PKEY_CTX_get_app_data(ctx);
	int p;

	p = EVP_PKEY_CTX_get_keygen_info(ctx, 0);
	if (p == 0)
		c = '.';
	if (p == 1)
		c = '+';
	if (p == 2)
		c = '*';
	if (p == 3)
		c = '\n';
	BIO_write(b, &c, 1);
	(void)BIO_flush(b);
	return 1;
}

الوصف

توفر واجهة EVP_PKEY واجهة عامة لخوارزميات المفاتيح العامة. تُستخدم EVP_PKEY_keygen_init() و EVP_PKEY_keygen() لإنشاء زوج مفاتيح عام/خاص.

يتم إنشاء سياق لإنشاء المفاتيح باستخدام EVP_PKEY_CTX_new() أو EVP_PKEY_CTX_new_id(). يجب استدعاء EVP_PKEY_keygen_init() قبل EVP_PKEY_keygen(). تقوم EVP_PKEY_keygen_init() بتهيئة عملية إنشاء المفتاح ضمن السياق ctx.

EVP_PKEY_keygen() تنفذ عملية إنشاء المفتاح. يتم إرجاع زوج المفاتيح العام/الخاص المنشأ في ppkey. المسؤولية عن تحرير بنية EVP_PKEY المرتجعة تقع على عاتق المستدعي باستخدام EVP_PKEY_free(3).

قد تحتاج بعض عمليات إنشاء المفاتيح إلى تعيين معلمات محددة، على سبيل المثال، عدد البتات لمفتاح RSA. يمكن تعيين هذه باستخدام EVP_PKEY_CTX_ctrl() أو EVP_PKEY_CTX_ctrl_str(). بدلاً من ذلك، قد تكون بعض المعلمات الشائعة متاحة من خلال دوال محددة مثل EVP_PKEY_CTX_set_rsa_keygen_bits().

يمكن مراقبة عملية الإنشاء عن طريق تعيين دالة استدعاء باستخدام EVP_PKEY_CTX_set_callback(). يتم استدعاء دالة الاستدعاء في مراحل مختلفة من عملية الإنشاء. يتم تمرير مؤشر EVP_PKEY_CTX إلى دالة الاستدعاء.

يمكن للتطبيق تمرير بيانات اعتباطية إلى دالة الاستدعاء باستخدام EVP_PKEY_CTX_set_app_data(). يمكن استرداد هذه البيانات داخل دالة الاستدعاء باستخدام EVP_PKEY_CTX_get_app_data().

يمكن لدالة الاستدعاء طلب معلومات حول عملية الإنشاء باستخدام EVP_PKEY_CTX_get_keygen_info(). يحدد المعامل request ما هي المعلومات المطلوبة. حالياً، يتم دعم الطلبات التالية:

0
يعيد المرحلة الحالية لإنشاء المفتاح. القيمة المرتجعة هي قناع بت من الأعلام التي تصف المرحلة الحالية. الأعلام الممكنة هي:
0
لا يوجد تقدم.
1
تم إنشاء معلمة.
2
تم إنشاء مشكلة فرعية.
3
تم إنشاء مفتاح.

يجب أن ترجع دالة الاستدعاء 1 عند النجاح و 0 أو قيمة سالبة عند حدوث خطأ.

يمكن أيضاً تعيين المعلومات لدالة الاستدعاء باستخدام EVP_PKEY_CTX_set_keygen_info(). يحدد المعامل request ما هي المعلومات التي يتم تعيينها. المعامل value هو القيمة المراد تعيينها. حالياً، يتم دعم الطلبات التالية:

0
تعيين عدد البتات للمفتاح الذي يتم إنشاؤه. هذا يعادل استدعاء EVP_PKEY_CTX_set_rsa_keygen_bits().

EVP_PKEY_CTX_get_data() ترجع المؤشر الذي تم تمريره آخر مرة إلى الأمر EVP_PKEY_CTRL_SET_DATA باستخدام EVP_PKEY_CTX_ctrl().

قيمة الإرجاع لـ EVP_PKEY_CTX_get_keygen_info() هي عدد المعلمات المتاحة، أو أقل من عدد المعلمات المتاحة، أو 0 خلاف ذلك.

EVP_PKEY_CTX_get_app_data() و EVP_PKEY_CTX_get_data() ترجع المؤشر الذي تم تمريره آخر مرة إلى الدالة المقابلة، أو NULL إذا لم يتم استدعاء الدالة المقابلة مطلقًا على ctx.

#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;

ctx = EVP_PKEY_CTX_new_id(EVP_PKEY_RSA, NULL);

	/* حدث خطأ */

	/* خطأ */

	/* خطأ */

/* إنشاء المفتاح */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* خطأ */

	/* خطأ */

/* إنشاء المفتاح */
if (EVP_PKEY_keygen(ctx, &pkey) <= 0)
	/* خطأ */
