الاسم

libpipewire-module-vban-recv - مستقبل VBAN

الوصف

يقوم وحدة vban-recv بإنشاء مصدر PipeWire يستقبل حزم VBAN الصوتية و MIDI.

سيستمع المستقبل على منفذ محدد (6980) وينشئ دفقًا لكل دفق VBAN مستلم على المنفذ.

اسم الوحدة

libpipewire-module-vban-recv

خيارات الوحدة

خيارات خاصة بسلوك هذه الوحدة

  • local.ifname = <str>: اسم الواجهة المراد استخدامها
  • source.ip = <str>: عنوان IP المصدر للاستماع عليه، الافتراضي هو 127.0.0.1
  • source.port = <int>: منفذ المصدر للاستماع عليه، الافتراضي هو 6980
  • node.always-process = <bool>: صحيح للاستقبال حتى عند عدم التشغيل
  • sess.latency.msec = <str>: زمن الاستجابة المستهدف للشبكة بالمللي ثانية، الافتراضي 100
  • stream.props = {}: خصائص سيتم تمريرها إلى جميع التدفقات
  • stream.rules = <rules>: قواعد المطابقة، استخدم إجراءات إنشاء دفق.

مطابقات قواعد التدفق stream.rules

  • vban.ip: عنوان IP الخاص بمرسل VBAN
  • vban.port: منفذ مرسل VBAN
  • sess.name: اسم دفق VBAN

إنشاء دفق stream.rules create-stream

بالإضافة إلى جميع الخصائص التي يمكن تمريرها إلى دفق، يمكنك أيضًا تعيين:

•
sess.latency.msec = <str>: زمن الاستجابة المستهدف للشبكة بالمللي ثانية، الافتراضي 100

خيارات عامة

خيارات ذات سلوك معروف:

  • remote.name
  • audio.position
  • media.name
  • media.class
  • node.name
  • node.description
  • node.group
  • node.latency
  • node.virtual

مثال تهيئة

# ~/.config/pipewire/pipewire.conf.d/my-vban-recv.conf
context.modules = [
{   name = libpipewire-module-vban-recv
    args = {
        #local.ifname = eth0
        #source.ip = 127.0.0.1
        #source.port = 6980
        sess.latency.msec = 100
        #node.always-process = false
        #audio.position = [ FL FR ]
        stream.props = {
           #media.class = "Audio/Source"
           #node.name = "vban-receiver"
        }
        stream.rules = [
            {   matches = [
                    {    sess.name = "~.*"
                         #sess.media = "audio" | "midi"
                         #vban.ip = ""
                         #vban.port = 1000
                         #audio.channels = 2
                         #audio.format = "U8" | "S16LE" | "S24LE" | "S32LE" | "F32LE" | "F64LE"
                         #audio.rate = 44100
                    }
                ]
                actions = {
                    create-stream = {
                        stream.props = {
                            #sess.latency.msec = 100
                            #target.object = ""
                            #audio.position = [ FL FR ]
                            #media.class = "Audio/Source"
                            #node.name = "vban-receiver"
                        }
                    }
                }
            }
        ]
    }
}
]
