libressl-ASN1_get_object(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

ASN1_GET_OBJECT(3) دليل المكتبة ASN1_GET_OBJECT(3)

الاسم

ASN1_get_object — تحليل ثمانيات المعرف والطول

ملخص

مكتبة "libcrypto"
#include <openssl/asn1.h>

int
ASN1_get_object(const unsigned char **ber_in, long *plength, int *ptag, int *pclass, long omax);

الوصف

ASN1_get_object() يحلل ثمانيات المعرف والطول لقيمة مرمزة بصيغة BER. عند مدخل الدالة، يُتوقع أن يشير *ber_in إلى أول ثماني للمعرف. إذا كانت ثمانيات المعرف والطول صالحة، تقوم الدالة بتقديم *ber_in إلى أول ثماني للمحتوى قبل العودة.

إذا كانت ثمانيات المعرف صالحة، فإن ASN1_get_object() تخزن رقم العلامة في *ptag وفئة العلامة في *pclass. الفئة هي إما V_ASN1_UNIVERSAL أو V_ASN1_APPLICATION أو V_ASN1_CONTEXT_SPECIFIC أو V_ASN1_PRIVATE.

إذا كانت ثمانيات الطول صالحة أيضًا، فإن ASN1_get_object() تخزن الرقم المشفر في ثمانيات الطول في *plength. إذا أشارت ثماني الطول إلى الشكل غير المحدد، يتم تعيين *plength إلى 0.

ASN1_get_object() تفحص على الأكثر omax بايت. إذا ظل تحليل ثمانيات الطول غير مكتمل بعد فحص هذا العدد من البايتات، يفشل التحليل مع ASN1_R_HEADER_TOO_LONG.

قيم الإرجاع

البتات المحددة في قيمة الإرجاع لـ ASN1_get_object() لها المعاني التالية:

0x80
حدث خطأ. تم تعيين أحد الأخطاء الموصوفة أدناه.
0x20 = V_ASN1_CONSTRUCTED
الترميز مُركب بدلاً من أولي، و ثمانيات المعرف والطول صالحة.
0x01
تشير ثماني الطول إلى الشكل غير المحدد. يمكن أن يحدث هذا البت فقط إذا تم تعيين V_ASN1_CONSTRUCTED أيضًا.

وبالتالي، يمكن أن تحدث التركيبات التالية:

0x00
ترميز أولي صالح.
0x20
ترميز مركب صالح، شكل محدد.
0x21
ترميز مركب صالح، شكل غير محدد.
0x80
إما ترميز أولي بعلامة محددة وطول محدد، ولكن محتويات المحتوى لا تتناسب مع omax، أو فشل التحليل. استخدم ERR_GET_REASON(3) للتمييز بين الحالتين.
0xa0
ترميز مركب بعلامة محددة وطول محدد، ولكن محتويات المحتوى لا تتناسب مع omax.

تركيبات البت 0x01، 0x81، و 0xa1 لا يمكن أن تحدث كقيم إرجاع.

الأخطاء

إذا تم تعيين البت 0x80 في قيمة الإرجاع، يمكن استرداد التشخيصات باستخدام ERR_get_error(3)، ERR_GET_REASON(3)، و ERR_reason_error_string(3):

ASN1_R_HEADER_TOO_LONG "الرأس طويل جدًا"
فحص omax بايت لم يكن كافياً لإنهاء التحليل، رقم العلامة المشفر في ثمانيات المعرف يتجاوز INT_MAX، الرقم المشفر في ثمانيات الطول يتجاوز LONG_MAX، أو محاولة استخدام الشكل غير المحدد لثمانيات الطول على الرغم من أن الترميز أولي.

في هذه الحالة، قيمة الإرجاع هي بالضبط 0x80؛ لا يتم تعيين بتات أخرى.

إذا حدثت المشكلة أثناء تحليل ثمانيات المعرف، تظل *ptag و *pclass دون تغيير. إذا حدثت المشكلة أثناء تحليل ثمانيات الطول، يتم تعيين *ptag و *pclass وفقًا لثمانيات المعرف. في كلتا الحالتين، تظل *ber_in و *plength دون تغيير.

صياغة رسالة الخطأ مربكة. من ناحية، قد يكون الرأس على ما يرام، وقد يكون السبب الجذري للمشكلة هو أن الوسيط omax المختار كان صغيرًا جدًا. من ناحية أخرى، يتم الإبلاغ عن أخطاء بناء جملة BER الصريحة أيضًا باسم ASN1_R_HEADER_TOO_LONG.

ASN1_R_TOO_LONG "طويل جدًا"
ثمانيات المعرف والطول صالحة، ولكن ثمانيات المحتوى لا تتناسب مع omax. تم تعيين ما يلي حسب الاقتضاء ويمكن فحصه بأمان: *pclass، *ptag، *plength، والبتات V_ASN1_CONSTRUCTED و 0x01 في قيمة الإرجاع. تم تقديم مؤشر التحليل *ber_in إلى أول ثماني للمحتوى.

مرة أخرى، قد تبدو رسالة الخطأ مربكة في بعض الأحيان. قد يكون طول المحتوى معقولاً، وقد يكون السبب الجذري للمشكلة هو أن الوسيط omax المختار كان صغيرًا جدًا.

انظر أيضًا

ASN1_item_d2i(3)، ASN1_item_new(3)، ASN1_parse_dump(3)

NAME

ASN1_get_object - extract an ASN.1 object from a buffer

SYNOPSIS

#include <openssl/asn1.h>

int ASN1_get_object(const unsigned char **pp, int *plength, int *ptag, const unsigned char *end);

DESCRIPTION

ASN1_get_object() extracts an ASN.1 object from the buffer pointed to by pp. The buffer is expected to contain a valid ASN.1 structure. On successful completion, the object's tag is written to *ptag, its length to *plength, and pp is advanced to point to the start of the object's content. The parameter end points to the end of the buffer. If the object extends beyond end, the function returns 0. If the object is successfully parsed, it returns 1. Otherwise, it returns 0.

The object is not decoded, only the tag and length are extracted. The content is still in the buffer, starting at the updated pp.

The tag is returned in *ptag. If the tag is constructed, the highest bit is set. The ASN.1 class is encoded in the two bits following the highest bit. The remaining 5 bits encode the tag number.

The length is returned in *plength. If the length is indefinite (0xFF), *plength is set to -1. The caller is responsible for finding the end of the indefinite length structure (typically by finding the two consecutive zero bytes).

The buffer is described by the pointers pp and end. pp points to the start of the buffer, and end points to one byte past the end of the buffer. On successful return, pp is updated to point to the start of the object's content.

RETURN VALUES

ASN1_get_object() returns 1 on success, and 0 on failure. Failure can occur if the buffer is too short, or if the ASN.1 structure is malformed.

SEE ALSO

ASN1_put_object(3), ASN1_STRING_new(3)

HISTORY

The ASN1_get_object function first appeared in OpenSSL 0.9.3.

الاسم

ASN1_get_object - استخراج كائن ASN.1 من مخزن مؤقت

الملخص

#include <openssl/asn1.h>

int ASN1_get_object(const unsigned char **pp, int *plength, int *ptag, const unsigned char *end);

الوصف

تقوم ASN1_get_object() باستخراج كائن ASN.1 من المخزن المؤقت الذي يشير إليه pp. من المتوقع أن يحتوي المخزن المؤقت على بنية ASN.1 صالحة. عند اكتمال العملية بنجاح، تتم كتابة علامة الكائن في *ptag، وطوله في *plength، ويتم تقديم pp للإشارة إلى بداية محتوى الكائن. تشير المعلمة end إلى نهاية المخزن المؤقت. إذا امتد الكائن إلى ما بعد end، فإن الدالة ترجع 0. إذا تم تحليل الكائن بنجاح، فإنها ترجع 1. وإلا، فإنها ترجع 0.

لا يتم فك تشفير الكائن، بل يتم فقط استخراج العلامة والطول. لا يزال المحتوى موجودًا في المخزن المؤقت، بدءًا من pp المحدث.

يتم إرجاع العلامة في *ptag. إذا كانت العلامة مركبة، فسيتم تعيين البت الأعلى. يتم ترميز فئة ASN.1 في البتات الاثنين التاليين للبت الأعلى. وتقوم الـ 5 بتات المتبقية بترميز رقم العلامة.

يتم إرجاع الطول في *plength. إذا كان الطول غير محدد (0xFF)، فإن *plength يتم تعيينه إلى -1. يتحمل المتصل مسؤولية العثور على نهاية الهيكل ذي الطول غير المحدد (عادةً عن طريق العثور على البايتين المتتاليين الصفرين).

يتم وصف المخزن المؤقت بواسطة المؤشرين pp و end. يشير pp إلى بداية المخزن المؤقت، ويشير end إلى بايت واحد بعد نهاية المخزن المؤقت. عند العودة بنجاح، يتم تحديث pp للإشارة إلى بداية محتوى الكائن.

قيم الإرجاع

ترجع ASN1_get_object() القيمة 1 عند النجاح، و 0 عند الفشل. قد يحدث الفشل إذا كان المخزن المؤقت قصيرًا جدًا، أو إذا كانت بنية ASN.1 غير صحيحة.
