الوصف

tls_ocsp_process_response() تعالج استجابة OCSP خام في response بالحجم size للتحقق من حالة إبطال الشهادة النظيرة من ctx. يشير رمز النجاح 0 إلى أن الشهادة لم يتم إلغاؤها.

tls_peer_ocsp_url() تعيد عنوان URL للتحقق من صحة OCSP لشهادة النظير من ctx.

الدوال التالية تعيد معلومات حول شهادة النظير من ctx التي تم الحصول عليها عن طريق التحقق من صحة استجابة OCSP الملصقة أثناء المصافحة، أو عبر استدعاء سابق لـ tls_ocsp_process_response().

tls_peer_ocsp_response_status() تعيد حالة استجابة OCSP وفقًا لـ RFC 6960 القسم 2.3.

tls_peer_ocsp_cert_status() تعيد رمز حالة شهادة OCSP وفقًا لـ RFC 6960 القسم 2.2.

tls_peer_ocsp_crl_reason() تعيد رمز حالة سبب إبطال شهادة OCSP وفقًا لـ RFC 5280 القسم 5.3.1.

tls_peer_ocsp_result() تعيد تمثيلًا نصيًا لرمز حالة OCSP الذي أعادته إحدى الدوال الثلاث السابقة. إذا كانت استجابة OCSP صالحة ولم يتم إلغاء الشهادة، فإن السلسلة النصية تشير إلى حالة شهادة OCSP. بخلاف ذلك، تشير السلسلة النصية إلى سبب إبطال شهادة OCSP أو خطأ OCSP.

tls_peer_ocsp_revocation_time() تعيد وقت إبطال OCSP.

tls_peer_ocsp_this_update() تعيد وقت التحديث الحالي لـ OCSP.

tls_peer_ocsp_next_update() تعيد وقت التحديث التالي لـ OCSP.

قيم الإرجاع

tls_ocsp_process_response() تعيد 0 عند النجاح أو -1 عند الخطأ.

tls_peer_ocsp_url() و tls_peer_ocsp_result() تعيدان NULL عند الخطأ أو حالة نقص الذاكرة.

الدالة tls_peer_ocsp_response_status() تعيد أحد القيم التالية: TLS_OCSP_RESPONSE_SUCCESSFUL, TLS_OCSP_RESPONSE_MALFORMED, TLS_OCSP_RESPONSE_INTERNALERROR, TLS_OCSP_RESPONSE_TRYLATER, TLS_OCSP_RESPONSE_SIGREQUIRED, أو TLS_OCSP_RESPONSE_UNAUTHORIZED عند النجاح أو -1 عند الخطأ.

الدالة tls_peer_ocsp_cert_status() تعيد أحد القيم التالية: TLS_OCSP_CERT_GOOD, TLS_OCSP_CERT_REVOKED, أو TLS_OCSP_CERT_UNKNOWN عند النجاح، و -1 عند الخطأ.

الدالة tls_peer_ocsp_crl_reason() تعيد أحد القيم التالية: TLS_CRL_REASON_UNSPECIFIED, TLS_CRL_REASON_KEY_COMPROMISE, TLS_CRL_REASON_CA_COMPROMISE, TLS_CRL_REASON_AFFILIATION_CHANGED, TLS_CRL_REASON_SUPERSEDED, TLS_CRL_REASON_CESSATION_OF_OPERATION, TLS_CRL_REASON_CERTIFICATE_HOLD, TLS_CRL_REASON_REMOVE_FROM_CRL, TLS_CRL_REASON_PRIVILEGE_WITHDRAWN, أو TLS_CRL_REASON_AA_COMPROMISE عند النجاح أو -1 عند الخطأ.

tls_peer_ocsp_revocation_time(), tls_peer_ocsp_this_update(), و tls_peer_ocsp_next_update() تعيد وقتًا بالثواني منذ العصر (epoch) عند النجاح أو -1 عند الخطأ.
