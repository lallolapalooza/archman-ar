Lire__Config__Index(3pm)

الحزمة: lire

التراخيص: GPL-2.0-only

Index(3pm) وثائق Lire الخاصة بـ LogReport Index(3pm)

الاسم

Lire::Config::Index - سجل الفهرس والواجهة

الملخص

use base qw/Lire::Config::Index/;
sub has_entry { my ($self, $name) = @_; ... }
sub entries { my $self = $_[0]; ... }
sub get_ref { my ($self, $name) = @_; ... }

الوصف

تُستخدم واجهة Lire::Config::Index بواسطة Lire::Config::ReferenceSpec(3pm) للتحقق من صحة والحصول على الكائن المشار إليه.

سجل الفهرس

هذه هي طرق الفئة المستخدمة لتسجيل والحصول على كائنات الفهرس.

has_index( $name )

يعيد القيمة true إذا تم تسجيل فهرس تحت الاسم $name.

get_index( $name )

يعيد الفهرس المسمى $name. يصرخ إذا لم يتم تسجيل مثل هذا الفهرس.

set_index( $name, $index )

يسجل $index تحت الاسم $name. يستبدل أي فهرس سابق تم تسجيله تحت نفس الاسم.

واجهة الفهرس

has_entry( $name )

يجب أن يعيد القيمة true إذا كان $name معرفًا في هذا الفهرس.

entries()

يجب أن يعيد جميع الإدخالات المعرفة في الفهرس.

get_ref( $name )

يجب أن يعيد الكائن المفهرس تحت $name. يجب إطلاق خطأ إذا لم يكن هناك مثل هذا الإدخال.;.
