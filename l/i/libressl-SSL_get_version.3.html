libressl-SSL_get_version(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_GET_VERSION(3) دليل وظائف المكتبة SSL_GET_VERSION(3)

الاسم

SSL_get_version، SSL_is_dtls، SSL_version — الحصول على معلومات البروتوكول للاتصال

ملخص

المكتبة “libssl” libcrypto
#include <openssl/ssl.h>

const char *
SSL_get_version(const SSL *ssl);

int
SSL_is_dtls(const SSL *ssl);

int
SSL_version(const SSL *ssl);

الوصف

SSL_get_version() ترجع اسم البروتوكول المستخدم للاتصال ssl.

SSL_is_dtls() ترجع 1 إذا كان الاتصال يستخدم DTLS، و 0 إذا لم يكن كذلك.

SSL_version() ترجع ثابتًا رقميًا يمثل هذا البروتوكول.

هذه الوظائف ترجع نتائج موثوقة فقط بعد اكتمال المصافحة الأولية.

قيم الإرجاع

يمكن أن ترجع السلاسل النصية أو الأرقام التالية بواسطة SSL_get_version() و SSL_version():

"TLSv1" أو TLS1_VERSION
يستخدم الاتصال بروتوكول TLSv1.0.
"TLSv1.1" أو TLS1_1_VERSION
يستخدم الاتصال بروتوكول TLSv1.1.
"TLSv1.2" أو TLS1_2_VERSION
يستخدم الاتصال بروتوكول TLSv1.2.
"TLSv1.3" أو TLS1_3_VERSION
يستخدم الاتصال بروتوكول TLSv1.3.
"DTLSv1" أو DTLS1_VERSION
يستخدم الاتصال بروتوكول Datagram Transport Layer Security 1.0.
"DTLSv1.2" أو DTLS1_2_VERSION
يستخدم الاتصال بروتوكول Datagram Transport Layer Security 1.2.
"unknown"
يشير هذا إلى إصدار بروتوكول غير معروف؛ لا يمكن أن يحدث حاليًا مع LibreSSL.

SSL_is_dtls() ترجع 1 إذا كان الاتصال يستخدم DTLS، و 0 إذا لم يكن كذلك.

التاريخ

SSL_get_version() و SSL_version() ظهرت لأول مرة في SSLeay 0.8.0 وكانت متاحة منذ OpenBSD 2.4.

SSL_is_dtls() ظهرت لأول مرة في OpenSSL 1.1.0 وكانت متاحة منذ OpenBSD 6.9.
