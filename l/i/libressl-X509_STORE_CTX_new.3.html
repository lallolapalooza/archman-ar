libressl-X509_STORE_CTX_new(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

NAME

X509_STORE_CTX_new, X509_STORE_CTX_init, X509_STORE_CTX_cleanup, X509_STORE_CTX_free, X509_STORE_CTX_set_cert, X509_STORE_CTX_set_chain, X509_STORE_CTX_trusted_stack, X509_STORE_CTX_set0_trusted_stack, X509_STORE_CTX_get0_store, X509_STORE_CTX_get0_cert, X509_STORE_CTX_set0_untrusted, X509_STORE_CTX_get0_untrusted – إنشاء وإدارة سياق التحقق من الشهادة

DESCRIPTION

تُستخدم هذه الدوال لإنشاء وإدارة سياق التحقق من شهادة X.509. سياق التحقق هو بنية تحتوي على جميع المعلومات المطلوبة للتحقق من سلسلة شهادات.

يجب ألا يتم استخدام:

X509_STORE_CTX ctx;
X509_STORE_CTX_init(&ctx, store, cert, chain);

هذا غير موصى به في التطبيقات الجديدة. يجب عليهم بدلاً من ذلك القيام بما يلي:

X509_STORE_CTX *ctx;
ctx = X509_STORE_CTX_new();
if (ctx == NULL)
	/* خطأ فادح */
X509_STORE_CTX_init(ctx, store, cert, chain);

RETURN VALUES

X509_STORE_CTX_new() تُرجع سياقًا مخصصًا حديثًا أو NULL إذا حدث خطأ.

X509_STORE_CTX_init() تُرجع 1 للنجاح أو 0 إذا حدث خطأ.

X509_STORE_CTX_get0_store() تُرجع مؤشرًا داخليًا إلى مخزن الشهادات الموثوق به أو NULL إذا لم يتم تعيين أي مخزن.

X509_STORE_CTX_get0_cert() تُرجع مؤشرًا داخليًا إلى الشهادة المراد التحقق منها أو NULL إذا لم يتم تعيين أي شهادة.

X509_STORE_CTX_get0_untrusted() تُرجع مؤشرًا داخليًا إلى مجموعة الشهادات الإضافية غير الموثوق بها أو NULL إذا لم يتم توفير مجموعة شهادات إضافية.

HISTORY

X509_STORE_CTX_init(), X509_STORE_CTX_cleanup(), X509_STORE_CTX_set_cert(), و X509_STORE_CTX_set_chain() ظهرت لأول مرة في SSLeay 0.8.0 وكانت متاحة منذ OpenBSD 2.4.

X509_STORE_CTX_new() و X509_STORE_CTX_free() ظهرت لأول مرة في OpenSSL 0.9.5 وكانت متاحة منذ OpenBSD 2.7.

X509_STORE_CTX_trusted_stack() ظهرت لأول مرة في OpenSSL 0.9.6 وكانت متاحة منذ OpenBSD 2.9.

X509_STORE_CTX_get0_store() ظهرت لأول مرة في OpenSSL 1.0.2. X509_STORE_CTX_set0_trusted_stack(), X509_STORE_CTX_get0_cert(), X509_STORE_CTX_set0_untrusted(), و X509_STORE_CTX_get0_untrusted() ظهرت لأول مرة في OpenSSL 1.1.0. كانت هذه الدوال متاحة منذ OpenBSD 6.3.
