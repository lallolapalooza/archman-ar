libressl-X509_keyid_set1(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

X509_KEYID_SET1(3) دليل الوظائف المكتبية X509_KEYID_SET1(3)

الاسم

X509_keyid_set1, X509_keyid_get0, X509_alias_set1, X509_alias_get0 — بيانات شهادة مساعدة لـ PKCS#12

ملخص

مكتبة “libcrypto”
#include <openssl/x509.h>

int
X509_keyid_set1(X509 *x, const unsigned char *data, int len);

unsigned char *
X509_keyid_get0(X509 *x, int *plen);

int
X509_alias_set1(X509 *x, const unsigned char *data, int len);

unsigned char *
X509_alias_get0(X509 *x, int *plen);

الوصف

تقوم هذه الدوال بتخزين بيانات مساعدة غير قياسية في x واسترجاعها.

سيتم كتابة len بايت من data المخزنة باستخدام X509_keyid_set1() إلى سمة localKeyID لهيكل PKCS#12 إذا تم استدعاء PKCS12_create(3) لاحقًا على x، وسيتم كتابة data المخزنة باستخدام X509_alias_set1() إلى سمة friendlyName. إذا تم تمرير مؤشر NULL كـ data، فسيتم إزالة البيانات المساعدة المخزنة المقابلة في x، إن وجدت، وتحريرها. إذا كان data يشير إلى سلسلة منتهية بـ NUL، يمكن تمرير -1 كـ len للسماح بحساب lenstrlen(3).

على العكس، يقوم PKCS12_parse(3) باسترجاع هذه السمات من هيكل PKCS#12 بحيث يمكن الوصول إليها لاحقًا باستخدام X509_keyid_get0() و X509_alias_get0(). ما لم يتم تمرير NULL لـ plen، فإن هذه الدوال تخزن حجم المخزن المؤقت المُعاد بالبايتات في *plen. بعد الاستدعاء، لا يلزم أن يكون المخزن المؤقت المُعاد منتهيًا بـ NUL، ولكنه قد يحتوي على بايتات NUL داخلية.

تصميم واجهة برمجة التطبيقات غير مكتمل للغاية؛ نظرًا لتعقيد PKCS#12، ربما يكون هذا رصيدًا بدلاً من عيب. يحدد معيار PKCS#12 العديد من السمات التي لا يمكن تخزينها في كائنات X509.

لربط الشهادات بالأسماء البديلة ومعرفات المفاتيح، تُستخدم امتدادات شهادات X.509 بشكل شائع أكثر من سمات PKCS#12، على سبيل المثال باستخدام X509_EXTENSION_CREATE_BY_NID(3) مع NID_subject_alt_name أو NID_subject_key_identifier.

قيم الإرجاع

X509_keyid_set1() و X509_alias_set1() تعيد 1 إذا كان data هو NULL أو إذا تم نسخ data المدخل بنجاح إلى x، أو 0 إذا كان data ليس NULL ولكن لم يمكن نسخه بسبب أن xNULL أو فشل تخصيص الذاكرة.

X509_keyid_get0() و X509_alias_get0() تعيد مؤشرًا داخليًا إلى مصفوفة من البايتات أو NULL إذا لم يكن x يحتوي على بيانات مساعدة من النوع المطلوب.

انظر أيضًا

ASN1_STRING_set(3), X509_CERT_AUX_new(3), X509_EXTENSION_new(3), X509_new(3), X509V3_get_d2i(3)

التاريخ

X509_alias_set1() و X509_alias_get0() ظهرت لأول مرة في OpenSSL 0.9.5 وكانت متاحة منذ OpenBSD 2.7.

X509_keyid_set1() ظهرت لأول مرة في OpenSSL 0.9.6 وكانت متاحة منذ OpenBSD 2.9.

X509_keyid_get0() ظهرت لأول مرة في OpenSSL 0.9.8 وكانت متاحة منذ OpenBSD 4.5.
