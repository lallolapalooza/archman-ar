libressl-X509_STORE_CTX_set_verify_cb(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

CAVEATS

In general a verification callback should NOT return a changed value of ok because this can allow the verification to appear to succeed in an unpredictable way. This can effectively remove all security from the application because untrusted or invalid certificates may be accepted. Doing this can possibly make X509_verify_cert(3) return what appears to be a validated chain of certificates that has not been validated or even had the signatures checked.
