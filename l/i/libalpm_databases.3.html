وظائف للاستعلام عن قاعدة بيانات libalpm والتلاعب بها.

توثيق النوع المعرف

typedef struct _alpm_db_t alpm_db_t

قاعدة بيانات. قاعدة البيانات هي حاوية تخزن البيانات الوصفية حول الحزم.

يمكن أن تكون قاعدة البيانات موجودة على نظام الملفات المحلي أو على خادم بعيد.

لاستخدام قاعدة بيانات، يجب تسجيلها أولاً عبر alpm_register_syncdb. إذا كانت قاعدة البيانات موجودة بالفعل في dbpath فسيتمكن من استخدامها. بخلاف ذلك، تحتاج قاعدة البيانات إلى التنزيل باستخدام alpm_db_update. حتى لو كان مصدر قاعدة البيانات هو نظام الملفات المحلي.

بعد ذلك، يمكن استخدام قاعدة البيانات للاستعلام عن الحزم والمجموعات. ستظل أي حزم أو مجموعات من قاعدة البيانات مملوكة لقاعدة البيانات ولا يلزم على المستخدم تحريرها. سيتم تحريرها عند إلغاء تسجيل قاعدة البيانات.

يتم إلغاء تسجيل قواعد البيانات تلقائيًا عند تحرير alpm_handle_t.

توثيق نوع التعداد

enum alpm_db_usage_t

مستوى استخدام قاعدة البيانات.

المُعَدِّدات

ALPM_DB_USAGE_SYNC
تمكين التحديثات لقاعدة البيانات هذه.
ALPM_DB_USAGE_SEARCH
تمكين البحث في قاعدة البيانات هذه.
ALPM_DB_USAGE_INSTALL
تمكين تثبيت الحزم من قاعدة البيانات هذه.
ALPM_DB_USAGE_UPGRADE
تمكين الترقيات النظامية باستخدام قاعدة البيانات هذه.
ALPM_DB_USAGE_ALL
تمكين جميع مستويات الاستخدام.

NAME

alpm_databases - Database synchronization functions

SYNOPSIS

#include <alpm.h>
#include <alpm_database.h>

alpm_list_t *
alpm_get_syncdbs (alpm_handle_t *handle);

alpm_db_t *
alpm_register_syncdb (alpm_handle_t *handle, const char *treename,
    int level);

int
alpm_unregister_all_syncdbs (alpm_handle_t *handle);

Detailed Description

alpm_get_syncdbs

Get the list of sync databases. Returns a list of alpm_db_t structures, one for each registered sync database.

Parameters

handle the context handle

Returns

a reference to an internal list of alpm_db_t structures

alpm_register_syncdb

Register a sync database of packages. Databases can not be registered when there is an active transaction.

Parameters

handle the context handle
treename the name of the sync repository
level what level of signature checking to perform on the database; note that this must be a '.sig' file type verification

Returns

an alpm_db_t* on success (the value), NULL on error

alpm_unregister_all_syncdbs

Unregister all package databases. Databases can not be unregistered while there is an active transaction.

Parameters

handle the context handle

Returns

0 on success, -1 on error (pm_errno is set accordingly)
