Lire__ReportParser__HTMLDocBookFormatter(3pm)

الحزمة: lire

التراخيص: GPL-2.0-only

HTMLDocBookFormatter(3pm) وثائق LogReport's Lire HTMLDocBookFormatter(3pm)

الاسم

Lire::ReportParser::HTMLDocBookFormatter - فئة فرعية من Lire::ReportParser تقوم بتنسيق الوصف.

الملخص

لتنسيق DocBook:

use Lire::ReportParser::HTMLDocBookFormatter qw/dbk2html/;
my $txt = dbk2html( "<para>Test</para>" );

في معالجات تقارير XML:

package MyParser;
use base qw/ Lire::ReportParser::HTMLDocBookFormatter Lire::ReportParser /;
sub new {
    my $self = shift->SUPER::new( @_ );
    $self->init_docbook_formatter( @_ );
    return $self;
}
sub handle_description {
    my ( $self, $desc ) = @_;
    print $desc;
    return;
}

الوصف

Lire::ReportParser::HTMLDocBookFormatter هي النظير لـ Lire::ReportParser::AsciiDocBookFormatter لتنسيق الإخراج HTML. يرجى قراءة وثائقه لمعرفة كيفية استخدام هذه الفئة. استخدامهما متطابق تمامًا.

dbk2html( $docbook_str, [$columns], [$xhtml] )

يعيد إصدار HTML لشظية DocBook XML $docbook_str. المعلمة "columns" تحدد عدد الأعمدة التي يجب تنسيق نص DocBook HTML فيها. المعلمة "xhtml" تحدد ما إذا كان الكود المنشأ سيكون متوافقًا مع XHTML؛ القيمة الافتراضية هي نعم.

ستقوم هذه الدالة **die()** في حالة حدوث خطأ.

انظر أيضًا
