NAME

libalpm_errors — libalpm error codes

SYNOPSIS

#include <alpm_errno.h>

DESCRIPTION

This document lists all of the error codes that can be returned by libalpm's functions.

Detailed Description

ALPM_ERR_NONE
No error.
ALPM_ERR_NO_SPACE
Not enough space.
ALPM_ERR_LOW_LEVEL
A low-level error occurred.
ALPM_ERR_NOT_IMPLEMENTED
Not implemented.
ALPM_ERR_INVALID_HANDLE
Invalid handle.
ALPM_ERR_DB_INVALID
Database is invalid.
ALPM_ERR_DB_INIT
Failed to initialize database.
ALPM_ERR_DB_OPEN
Failed to open database.
ALPM_ERR_DB_CORRUPT
Database is corrupt.
ALPM_ERR_DB_LOAD
Failed to load database.
ALPM_ERR_DB_SAVE
Failed to save database.
ALPM_ERR_DB_UNLINK
Failed to unlink database.
ALPM_ERR_DB_REMOVE
Failed to remove database.
ALPM_ERR_DIR_CREATE
Failed to create directory.
ALPM_ERR_DIR_REMOVE
Failed to remove directory.
ALPM_ERR_FILE_READ
Failed to read file.
ALPM_ERR_FILE_WRITE
Failed to write file.
ALPM_ERR_FILE_REMOVE
Failed to remove file.
ALPM_ERR_FILE_STAT
Failed to stat file.
ALPM_ERR_FILE_RENAME
Failed to rename file.
ALPM_ERR_FILE_OPEN
Failed to open file.
ALPM_ERR_PKGS_NOT_SORTED
Packages are not sorted.
ALPM_ERR_PKG_INVALID_SIG

ALPM_ERR_PKG_MISSING_SIG
Package does not have a signature.
ALPM_ERR_PKG_OPEN

ALPM_ERR_PKG_CANT_REMOVE
Failed to remove package files.
ALPM_ERR_PKG_INVALID_NAME

ALPM_ERR_SIG_MISSING
