التحويل

apply BLOCK LIST

تطبق الكتلة على كل عنصر في القائمة وتعيد قائمة بالقيم بعد تطبيق الكتلة. في السياق العددي، يتم إرجاع العنصر الأخير. هذه الدالة مشابهة لـ "map" ولكنها لا تعدل عناصر القائمة الأصلية:

my @list = (1 .. 4);
my @mult = apply { $_ *= 2 } @list;
print "\@list = @list\n";
print "\@mult = @mult\n";
__END__
@list = 1 2 3 4
@mult = 2 4 6 8

يمكن اعتبارها اختصارًا لـ

for (my @mult = @list) { $_ *= 2 }

insert_after BLOCK VALUE LIST

تدرج القيمة بعد أول عنصر في القائمة يكون شرطه في الكتلة صحيحًا. تقوم بتعيين $_ لكل عنصر في القائمة بالترتيب:

my @list = qw/This is a list/;
insert_after { $_ eq "a" } "longer" => @list;
print "@list";
__END__
This is a longer list

insert_after_string STRING VALUE LIST

تدرج القيمة بعد أول عنصر في القائمة يساوي STRING.

my @list = qw/This is a list/;
insert_after_string "a", "longer" => @list;
print "@list";
__END__
This is a longer list

pairwise BLOCK ARRAY1 ARRAY2

تقيّم الكتلة لكل زوج من العناصر في ARRAY1 و ARRAY2 وتعيد قائمة جديدة تتكون من القيم التي أعادتها الكتلة. يتم تعيين العنصرين لـ $a و $b. ملاحظة: هذان متغيراً يشيران إلى القيم الأصلية، لذا فإن تعديلهما سيعدل القوائم الأصلية.

@a = (1 .. 5);
@b = (11 .. 15);
@x = pairwise { $a + $b } @a, @b;     # يعيد 12, 14, 16, 18, 20
# تشبيك مع pairwise
@a = qw/a b c/;
@b = qw/1 2 3/;
@x = pairwise { ($a, $b) } @a, @b;    # يعيد a, 1, b, 2, c, 3

mesh ARRAY1 ARRAY2 [ ARRAY3 ... ]

zip ARRAY1 ARRAY2 [ ARRAY3 ... ]

تعيد قائمة بالعناصر الأولى من كل قائمة، يليها العناصر الثانية، وهكذا، حتى تنفد جميع القوائم.

أمثلة:

@x = qw/a b c d/;
@y = qw/1 2 3 4/;
@z = mesh @x, @y;         # يعيد a, 1, b, 2, c, 3, d, 4
@a = ('x');
@b = ('1', '2');
@c = qw/zip zap zot/;
@d = mesh @a, @b, @c;   # x, 1, zip, undef, 2, zap, undef, undef, zot

"zip" هو اسم مستعار لـ "mesh".

zip6

zip_unflatten

تعيد قائمة قوائم تتكون من العناصر الأولى لكل قائمة، يليها العناصر الثانية، وهكذا، حتى تنفد جميع القوائم.

@x = qw/a b c d/;
@y = qw/1 2 3 4/;
@z = zip6 @x, @y;         # يعيد [a, 1], [b, 2], [c, 3], [d, 4]
@a = ('x');
@b = ('1', '2');
@c = qw/zip zap zot/;
@d = zip6 @a, @b, @c;     # [x, 1, zip], [undef, 2, zap], [undef, undef, zot]

"zip_unflatten" هو اسم مستعار لـ "zip6".

listcmp ARRAY0 ARRAY1 [ ARRAY2 ... ]

تعيد قائمة ارتباطية للعناصر ومعرف القائمة التي تم العثور عليها فيها. تسمح بالتنفيذ السهل لـ @a & @b، @a | @b، @a ^ @b وما إلى ذلك. يتم تجاهل العناصر غير المحددة في أي قائمة.

my @a = qw(one two three four five six seven eight nine ten eleven twelve thirteen);
my @b = qw(two three five seven eleven thirteen seventeen);
my @c = qw(one one two three five eight thirteen twentyone);
my %cmp = listcmp @a, @b, @c; # يعيد (one => [0, 2], two => [0, 1, 2], three => [0, 1, 2], four => [0], ...)
my @seq = (1, 2, 3);
my @prim = (undef, 2, 3, 5);
my @fib = (1, 1, 2);
my %cmp = listcmp @seq, @prim, @fib;
# يعيد ( 1 => [0, 2], 2 => [0, 1, 2], 3 => [0, 1], 5 => [1] )

arrayify LIST[,LIST[,LIST...]]

تعيد قائمة بكل عنصر من القوائم المعطاة. سيتم أيضًا توسيع القوائم المتداخلة.

@a = (1, [[2], 3], 4, [5], 6, [7], 8, 9);
@l = arrayify @a;         # يعيد 1, 2, 3, 4, 5, 6, 7, 8, 9

uniq LIST

distinct LIST

تعيد قائمة جديدة بإزالة القيم المكررة من LIST عن طريق مقارنة القيم كمفاتيح تجزئة، باستثناء أن undefined تعتبر مختلفة عن ''. ترتيب العناصر في القائمة الناتجة هو نفسه في LIST. في السياق العددي، يعيد عدد العناصر الفريدة في LIST.

my @x = uniq 1, 1, 2, 2, 3, 5, 3, 4; # يعيد 1 2 3 5 4
my $x = uniq 1, 1, 2, 2, 3, 5, 3, 4; # يعيد 5
# يعيد "Mike", "Michael", "Richard", "Rick"
my @n = distinct "Mike", "Michael", "Richard", "Rick", "Michael", "Rick"
# يعيد "A8", "", undef, "A5", "S1"
my @s = distinct "A8", "", undef, "A5", "S1", "A5", "A8"
# يعيد "Giulia", "Giulietta", undef, "", 156, "GTA", "GTV", 159, "Brera", "4C"
my @w = uniq "Giulia", "Giulietta", undef, "", 156, "GTA", "GTV", 159, "Brera", "4C", "Giulietta", "Giulia"

"distinct" هو اسم مستعار لـ "uniq".

RT#49800 يمكن استخدامه لتقديم ملاحظات حول هذا السلوك.

singleton LIST

تعيد قائمة جديدة بإزالة القيم من LIST التي تتكرر أكثر من مرة واحدة عن طريق مقارنة القيم كمفاتيح تجزئة، باستثناء أن undefined تعتبر مختلفة عن ''. ترتيب العناصر في القائمة الناتجة هو نفسه في LIST. في السياق العددي، يعيد عدد العناصر التي تتكرر مرة واحدة بالضبط في LIST.

my @x = singleton 1,1,2,2,3,4,5 # يعيد 3 4 5

duplicates LIST

تعيد قائمة جديدة بإزالة القيم من LIST التي تتكرر أقل من مرتين عن طريق مقارنة القيم كمفاتيح تجزئة، باستثناء أن undefined تعتبر مختلفة عن ''. ترتيب العناصر في القائمة الناتجة هو نفسه في LIST. في السياق العددي، يعيد عدد العناصر التي تتكرر أكثر من مرة واحدة في LIST.

my @y = duplicates 1,1,2,4,7,2,3,4,6,9; # يعيد 1,2,4

frequency LIST

تعيد قائمة ارتباطية للقيم الفريدة وتكرارها.

my @f = frequency values %radio_nrw; # يعيد (
#  'Deutschlandfunk (DLF)' => 9, 'WDR 3' => 10,
#  'WDR 4' => 11, 'WDR 5' => 14, 'WDR Eins Live' => 14,
#  'Deutschlandradio Kultur' => 8,...)

occurrences LIST

تعيد قائمة جديدة للتكرارات والقيم المقابلة من LIST.

my @o = occurrences ((1) x 3, (2) x 4, (3) x 2, (4) x 7, (5) x 2, (6) x 4);
#  @o = (undef, undef, [3, 5], [1], [2, 6], undef, undef, [4]);

mode LIST

يعيد القيمة المنوالية لـ LIST. في السياق العددي، يعيد فقط القيمة المنوالية. في سياق القائمة، تعيد جميع العناصر التي تحدث بشكل منوال.

my @m = mode ((1) x 3, (2) x 4, (3) x 2, (4) x 7, (5) x 2, (6) x 4, (7) x 3, (8) x 7);
#  @m = (7, 4, 8) - قائمة ثنائية المنوال

slide BLOCK LIST

تعمل الدالة "slide" مع أزواج من عناصر القائمة مثل:

my @s = slide { "$a and $b" } (0..3);
# @s = ("0 and 1", "1 and 2", "2 and 3")

المفهوم وراء هذه الدالة هو نوع من العدسة التي تنزلق عبر قائمة وتستدعي "BLOCK" كلما تم الوصول إلى العنصر التالي في القائمة.

التقسيم

after BLOCK LIST

تعيد قائمة بالقيم من LIST بعد (باستثناء) النقطة التي تعيد فيها BLOCK قيمة صحيحة. تقوم بتعيين $_ لكل عنصر في القائمة بالترتيب:

@x = after { $_ % 5 == 0 } (1..9);    # يعيد 6, 7, 8, 9

after_incl BLOCK LIST

نفس "after" ولكنها تشمل أيضًا العنصر الذي تكون فيه BLOCK صحيحة.

before BLOCK LIST

تعيد قائمة بالقيم من LIST حتى (باستثناء) النقطة التي تعيد فيها BLOCK قيمة صحيحة. تقوم بتعيين $_ لكل عنصر في القائمة بالترتيب:

before_incl BLOCK LIST

نفس "before" ولكنها تشمل أيضًا العنصر الذي تكون فيه BLOCK صحيحة.

part BLOCK LIST

تقسم LIST وفقًا للقيمة التي أعادتها BLOCK، والتي تشير إلى القسم الذي يوجد فيه القيمة الحالية. تعيد قائمة بالأقسام التي تم إنشاؤها. كل قسم تم إنشاؤه هو مرجع لقائمة.

my $i = 0;
my @part = part { $i++ % 2 } 1 .. 8;   # يعيد [1, 3, 5, 7], [2, 4, 6, 8]

يمكنك الحصول على قائمة أقسام مبعثرة حيث تكون الأقسام غير المحددة undefined:

my @part = part { 2 } 1 .. 10;            # يعيد undef, undef, [ 1 .. 10 ]

يجب أن تكون حذرًا مع القيم السالبة، على الرغم من ذلك:

my @part = part { -1 } 1 .. 10;
__END__
محاولة تعديل قيمة مصفوفة غير قابلة للإنشاء، فهرس -1 ...

القيم السالبة صالحة فقط عند الإشارة إلى قسم تم إنشاؤه مسبقًا:

my @idx  = ( 0, 1, -1 );
my $i    = 0;
my @part = part { $idx[$i++ % 3] } 1 .. 8; # [1, 4, 7], [2, 3, 5, 6, 8]

@r  = samples 10, 1..10; # نفس shuffle

شكرا

Tassilo von Parseval

تُوجّه الشكر إلى عدد من الأشخاص: ستيف بوركيس لتقديم المشورة لي بشأن اسم مساحة الأسماء، وجيمس كينان وتيرينس برانو لجهودهما في الحفاظ على CPAN أنظف عن طريق إهمال إصدار List::Utils.

اقترح برايان مكولي تضمين apply() وقدم التنفيذ الخالص لـ Perl.

طلب مني إريك جي. رود إضافة جميع وظائف وحدته "List::MoreUtil" إلى هذه الوحدة. مع تعديلات طفيفة، فإن التنفيذات الخالصة لتلك الوظائف تعود له.

الأشخاص الذين أشاروا فورًا تقريبًا إلى العديد من المشكلات في الإصدار 0.07 (سلافين ريزيك، رون سافاج، مختبرو CPAN).

اكتشف توماس إيه. لوري تسربًا معينًا للذاكرة.

حذرني لارس ثيجلر من مشكلات في إصدارات Perl القديمة.

تخلى أنو سيجل عن مسؤولية each_arrayref().

حذرني ديفيد فيلمر من مشكلة في each_arrayref() والتي قد تتسبب في تجاوز سعة المكدس.

اقترح ريكاردو سينييس تضمين part() وقدم التنفيذ لـ Perl.

أصلح روبن هوستون خطأ في واجهة برمجة تطبيقات MULTICALL الخاصة بـ perl لجعل تنفيذ XS الخاص بـ part() يعمل.

Jens Rehsack

تُوجّه الشكر إلى جميع المشاركين الذين قدموا ملاحظات أثناء تطوير الإصدار 0.400.

شكر خاص لديفيد جولدين الذي كرس الكثير من الوقت لتطوير تصميم يدعم الحالة الحالية لـ CPAN والبرامج القديمة بظلام. كما قدم العديد من الإصلاحات لتحسين واجهة برمجة التطبيقات بحيث يستفيد منها أي مستخدم لـ List::MoreUtils، من الماضي القديم إلى الأحدث الذي تم استخدامه مؤخرًا.

قدم توبي إنكستر الكثير من الملاحظات المفيدة حول كود المستورد الصحي وقدم توجيهًا جيدًا لمناقشات واجهة برمجة التطبيقات.

قدم بيتر رابيتسون مستودع git صحي مع كل تاريخ الحزمة.
