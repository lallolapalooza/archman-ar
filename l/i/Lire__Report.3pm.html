Lire__Report(3pm)

الحزمة: lire

التراخيص: GPL-2.0-only

Report(3pm) وثائق Lire::Report Report(3pm)

الاسم

Lire::Report - واجهة لتقرير Lire.

ملخص

use Lire::ReportParser::ReportBuilder;
my $parser = new Lire::ReportParser::ReportBuilder;
my $report = $parser->parse( "report.xml" );
print $report->superservice(), " report\n";
print "Generated on ", scalar( localtime( $report->date() ) ), "\n";
print "Timespan starts on ", scalar( localtime( $report->timespan_start() ) ), "\n";
print "Timespan ends on ", scalar( localtime( $report->timespan_start() ) ), "\n";
foreach my $s ( $report->sections() ) {
    print "Section: '", $s->title(), "' has ", scalar $s->subreports(),
        " subreports in it\n";
}

الوصف

توفر هذه الوحدة واجهة برمجة تطبيقات (API) لتقرير تم إنشاؤه بواسطة Lire. يمكن استخدام Lire::ReportParser::ReportBuilder(3pm) لإنشاء كائن Lire::Report من ملف XML يلتزم بـ DTD لغة ترميز تقرير Lire.

المُنشئ

يمكن بناء كائن Lire::Report من ملف تقرير XML، من الدالة new() أو من كائن Lire::ReportConfig.

new( [ $timespan_period ], [ $timespan_start ], [ $timespan_end ] )

ينشئ تقرير Lire جديد. تهيئة المعلمات $timespan_period و $timespan_start و $timespan_end تهيئ السمات بنفس الاسم.

أساليب الكائن

version()

ترجع رقم إصدار تنسيق التقرير الذي تم استخدامه في التمثيل الخارجي لهذا التقرير. الإصدار الحالي هو 2.1.

generator([$generator)

ترجع سلسلة المُنشئ التي سيتم إخراجها في التعليقات عند استخدام الدالة write_report(). يمكن تغيير هذه القيمة عن طريق تمرير قيمة جديدة عبر المعلمة $generator.

date( [ $new_date ] )

ترجع (وتغير اختياريًا) التاريخ بالثواني منذ الحقبة الذي تم فيه إنشاء هذا التقرير.

timespan_period( [ $new_period ] )

ترجع (وتغير اختياريًا) فترة التقرير. يمكن أن تكون الفترة 'hourly' (ساعية)، 'daily' (يومية)، 'weekly' (أسبوعية)، 'monthly' (شهرية) أو 'yearly' (سنوية). عندما تكون الفترة غير محددة (undef)، فإنها تكون فترة عشوائية.

timespan_start( [ $new_start ] )

ترجع (وتغير اختياريًا) بداية الفترة الزمنية التي يغطيها هذا التقرير بالثواني منذ الحقبة.

timespan_end( [ $new_end ] )

ترجع (وتغير اختياريًا) نهاية الفترة الزمنية التي يغطيها هذا التقرير بالثواني منذ الحقبة.

title( [$title] )

ترجع عنوان التقرير، إذا كان له عنوان.

إذا تم تعيين المعلمة $title، فسيتم تعيين عنوان التقرير إلى هذه القيمة الجديدة.

description( [$new_desc] )

ترجع وصف التقرير. هذا الوصف مشفر بتنسيق DocBook XML.

إذا تم تعيين المعلمة $description، فإن هذه الدالة ستضبط الوصف على هذه القيمة الجديدة. إذا كانت المعلمة $description غير محددة (undef)، فسيتم إزالة الوصف.

sections( )

ترجع أقسام التقرير كمصفوفة. ستكون هذه مصفوفة من كائنات Lire::Report::Section.

add_section( $section )

تضيف قسمًا إلى هذا التقرير. يجب أن تكون المعلمة $section كائن Lire::Report::Section.

subreport_by_id( $id )

ترجع كائن Lire::Report::Subreport بالمعرف $id. ترجع قيمة غير محددة (undef) عندما لا يوجد تقرير فرعي بهذا المعرف.

schemas()

ترجع مرجع مصفوفة يحتوي على جميع المخططات التي يستخدمها هذا التقرير.

write_report( [FH] );

تكتب التقرير بتنسيق XML على مقبض الملف FH أو إلى الإخراج القياسي (STDOUT) إذا لم يتم تحديده.

تتولى هذه الدالة إضافة عناصر مثل رأس XML "<?xml version=[...]". تقوم بتشفير تقرير XML بتنسيق UTF-8، باستخدام Lire::I18N::set_fh_encoding().

delete( )

يزيل جميع المراجع الدائرية حتى يمكن تحرير الكائن.
