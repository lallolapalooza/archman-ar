libressl-PKCS8_pkey_set0(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

PKCS8_PKEY_SET0(3) دليل وظائف المكتبة PKCS8_PKEY_SET0(3)

الاسم

PKCS8_pkey_set0، PKCS8_pkey_get0، PKCS8_pkey_add1_attr_by_NID، PKCS8_pkey_get0_attrs — تغيير وفحص كائنات PKCS#8 PrivateKeyInfo

المُلَخَّص

مكتبة “libcrypto”
#include <openssl/x509.h>

int
PKCS8_pkey_set0(PKCS8_PRIV_KEY_INFO *keyinfo, ASN1_OBJECT *aobj, int version, int ptype, void *pval, unsigned char *data, int len);

int
PKCS8_pkey_get0(const ASN1_OBJECT **paobj, const unsigned char **pdata, int *plen, const X509_ALGOR **palgor, const PKCS8_PRIV_KEY_INFO *keyinfo);

int
PKCS8_pkey_add1_attr_by_NID(PKCS8_PRIV_KEY_INFO *keyinfo, int nid, int type, const unsigned char *data, int len);

const STACK_OF(X509_ATTRIBUTE) *
PKCS8_pkey_get0_attrs(const PKCS8_PRIV_KEY_INFO *keyinfo);

الوصف

PKCS8_pkey_set0() تهيئة الكائن keyinfo. يتم تعيين الخوارزمية إلى aobj مع نوع المعلمة المرتبط به ptype وقيمة المعلمة pval باستخدام X509_ALGOR_set0(3)، مما يستبدل أي معلومات سابقة حول الخوارزمية. ما لم يكن data هو NULL، يتم تعيين المفتاح الخاص المشفر إلى len بايت بدءًا من data باستخدام ASN1_STRING_set0(3)، دون إجراء أي تحقق. إذا كان data هو NULL، تظل بيانات المفتاح دون تغيير. إذا كان version أكبر من أو يساوي 0، فإنه يستبدل أي إصدار موجود؛ بخلاف ذلك، يظل الإصدار دون تغيير. إذا كان keyinfo يحتوي على أي سمات، فإنها تظل دون تغيير.

PKCS8_pkey_get0() تسترجع بعض المعلومات من الكائن keyinfo. يتم تخزين المؤشرات الداخلية لمعرف كائن الخوارزمية (OID)، AlgorithmIdentifier، والمفتاح الخاص المشفر في *paobj، و*palgor، و*pdata، على التوالي. يمكن تمرير مؤشرات NULL لأي من هذه الوسائط الثلاثة إذا لم تكن المعلومات المعنية مطلوبة. ما لم يكن pdata هو NULL، يتم تعيين *plen إلى عدد البايتات في *pdata.

PKCS8_pkey_add1_attr_by_NID() ينشئ كائن سمة X.501 جديدًا باستخدام X509_ATTRIBUTE_create_by_NID(3) ويضيفه إلى سمات keyinfo.

قيم الإرجاع

PKCS8_pkey_set0() و PKCS8_pkey_add1_attr_by_NID() ترجع 1 للنجاح أو 0 للفشل.

PKCS8_pkey_get0() ترجع دائمًا 1.

PKCS8_pkey_get0_attrs() ترجع مؤشرًا داخليًا لمصفوفة السمات المرتبطة بـ keyinfo أو NULL إذا لم يتم تعيين أي سمات.

انظر أيضًا

ASN1_STRING_set0(3)، EVP_PKCS82PKEY(3)، OBJ_nid2obj(3)، PKCS8_PRIV_KEY_INFO_new(3)، STACK_OF(3)، X509_ALGOR_new(3)، X509_ATTRIBUTE_create_by_NID(3)، X509_ATTRIBUTE_new(3)

التاريخ

PKCS8_pkey_set0() و PKCS8_pkey_get0() ظهرت لأول مرة في OpenSSL 1.0.0 وكانت متاحة منذ OpenBSD 4.9.

PKCS8_pkey_add1_attr_by_NID() و PKCS8_pkey_get0_attrs() ظهرت لأول مرة في OpenSSL 1.1.0 وكانت متاحة منذ OpenBSD 6.4.
