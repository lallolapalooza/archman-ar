libressl-EVP_PKEY_decrypt(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

EVP_PKEY_DECRYPT(3) دليل المكتبة EVP_PKEY_DECRYPT(3)

الاسم

EVP_PKEY_decrypt_init، EVP_PKEY_decrypt — فك تشفير باستخدام خوارزمية المفتاح العام

الملخص

المكتبة «libcrypto»
#include <openssl/evp.h>

int
EVP_PKEY_decrypt_init(EVP_PKEY_CTX *ctx);

int
EVP_PKEY_decrypt(EVP_PKEY_CTX *ctx, unsigned char *out, size_t *outlen, const unsigned char *in, size_t inlen);

الوصف

تقوم الدالة EVP_PKEY_decrypt_init() بتهيئة سياق خوارزمية المفتاح العام باستخدام المفتاح ctx->pkey لعملية فك التشفير.

تقوم الدالة EVP_PKEY_decrypt() بتنفيذ عملية فك تشفير بمفتاح عام باستخدام ctx. يتم تحديد البيانات المراد فك تشفيرها باستخدام المعلمات in و inlen. إذا كان out يساوي NULL، فسيتم كتابة الحد الأقصى لحجم المخزن المؤقت للإخراج في المعلمة outlen. إذا لم يكن out يساوي NULL، فيجب أن يحتوي المعلمة outlen قبل الاستدعاء على طول المخزن المؤقت out. إذا كان الاستدعاء ناجحًا، فسيتم كتابة البيانات المفكوكة إلى out وحجم البيانات المكتوبة إلى outlen.

بعد الاستدعاء إلى EVP_PKEY_decrypt_init()، يمكن إجراء عمليات تحكم خاصة بالخوارزمية لتعيين أي معلمات مناسبة للعملية.

يمكن استدعاء الدالة EVP_PKEY_decrypt() أكثر من مرة على نفس السياق إذا تم إجراء عدة عمليات باستخدام نفس المعلمات.

قيم الإرجاع

EVP_PKEY_decrypt_init() و EVP_PKEY_decrypt() ترجع 1 للنجاح و 0 أو قيمة سلبية للفشل. على وجه الخصوص، يشير رمز الإرجاع -2 إلى أن العملية غير مدعومة من قبل خوارزمية المفتاح العام.

أمثلة

فك تشفير البيانات باستخدام OAEP (لمفاتيح RSA):

#include <openssl/evp.h>
#include <openssl/rsa.h>

EVP_PKEY_CTX *ctx;
unsigned char *out, *in;
size_t outlen, inlen;
EVP_PKEY *key;

/*
 * يفترض أن key و in و inlen تم إعدادهما بالفعل
 * وأن key هو مفتاح RSA خاص.
 */
ctx = EVP_PKEY_CTX_new(key, NULL);
if (!ctx)
	/* حدث خطأ */
if (EVP_PKEY_decrypt_init(ctx) <= 0)
	/* خطأ */
if (EVP_PKEY_CTX_set_rsa_padding(ctx, RSA_PKCS1_OAEP_PADDING) <= 0)
	/* خطأ */

/* تحديد طول المخزن المؤقت */
if (EVP_PKEY_decrypt(ctx, NULL, &outlen, in, inlen) <= 0)
	/* خطأ */

out = malloc(outlen);

if (!out)
	/* فشل malloc */

if (EVP_PKEY_decrypt(ctx, out, &outlen, in, inlen) <= 0)
	/* خطأ */

/* البيانات المفكوكة هي outlen بايت مكتوبة إلى المخزن المؤقت out */
