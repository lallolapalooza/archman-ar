اسم

\n

libtar_hash_new، libtar_hash_free، libtar_hash_next، libtar_hash_prev، libtar_hash_getkey، libtar_hash_search، libtar_hash_add، libtar_hash_del - إجراءات جدول التجزئة

\n
\n
\n

الملخص

\n

#include <libtar.h>

\n

libtar_hash_t *libtar_hash_new(int num, int (*hashfunc)());
\nvoid libtar_hash_free(libtar_hash_t *h, void (*freefunc)());
\nint libtar_hash_next(libtar_hash_t *h, libtar_hashptr_t *hp);
\nint libtar_hash_prev(libtar_hash_t *h, libtar_hashptr_t *hp);
\nint libtar_hash_search(libtar_hash_t *h, libtar_hashptr_t *hp, void *data, int (*matchfunc)());
\nint libtar_hash_getkey(libtar_hash_t *h, libtar_hashptr_t *hp, void *data, int (*matchfunc)());
\nint libtar_hash_add(libtar_hash_t *h, void *data);
\nint libtar_hash_del(libtar_hash_t *h, libtar_hashptr_t *hp);

\n
\n
\n

الوصف

\n

تقوم الدالة libtar_hash_new() بإنشاء جدول تجزئة جديد بـ num دلو واستخدام دالة التجزئة المشار إليها بواسطة hashfunc. إذا كانت hashfunc هي NULL، يتم استخدام دالة تجزئة افتراضية مصممة للسلاسل النصية ASCII ذات 7 بت.

\n

تقوم الدالة libtar_hash_free() بتحرير جميع الذاكرة المرتبطة بهيكل التجزئة h. إذا لم تكن freefunc هي NULL، فسيتم استدعاؤها لتحرير الذاكرة المرتبطة بكل عقدة في جدول التجزئة.

\n

تُستخدم الدالتان libtar_hash_next() و libtar_hash_prev() للتكرار عبر جدول التجزئة. يحتوي هيكل libtar_hashptr_t على حقلي bucket، الذي يشير إلى الدلو الحالي في جدول التجزئة، و node، وهو مؤشر إلى العقدة الحالية في الدلو الحالي. لبدء التكرار من بداية أو نهاية جدول التجزئة، يجب على المستدعي تهيئة hp.bucket إلى -1 و hp.node إلى NULL.

\n

تقوم الدالة libtar_hash_search() بالبحث بشكل تكراري عبر جدول التجزئة h حتى تجد عقدة تتطابق محتوياتها مع data باستخدام دالة المطابقة matchfunc. يبدأ البحث من الموقع المشار إليه بواسطة hp.

\n

تستخدم الدالة libtar_hash_getkey() دالة التجزئة المرتبطة بـ h لتحديد الدلو الذي يجب أن يكون فيه data، وتبحث فقط في ذلك الدلو عن عقدة مطابقة باستخدام matchfunc. يبدأ البحث من الموقع المشار إليه بواسطة hp.

\n

تضيف الدالة libtar_hash_add() data إلى جدول التجزئة h.

\n

تزيل الدالة libtar_hash_del() العقدة المشار إليها بواسطة hp.

\n
\n
\n

قيمة الإرجاع

\n

تُرجع الدالة libtar_hash_new() مؤشرًا إلى هيكل التجزئة الجديد، أو NULL في حالة حدوث خطأ.

\n

تُرجع الدالتان libtar_hash_next() و libtar_hash_prev() القيمة 1 عند إرجاع بيانات صالحة، و 0 عند نهاية جدول التجزئة.

\n

تُرجع الدالتان libtar_hash_getkey() و libtar_hash_search() القيمة 1 عند العثور على تطابق، أو 0 بخلاف ذلك.

\n

تُرجع الدالة libtar_hash_add() القيمة 0 عند النجاح، أو -1 عند حدوث خطأ (وتقوم بتعيين errno).

\n

تُرجع الدالة libtar_hash_del() القيمة 0 عند النجاح، أو -1 عند حدوث خطأ (وتقوم بتعيين errno).
