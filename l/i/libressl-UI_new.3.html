DESCRIPTION

The user interface functions provide a generic framework for handling user interactions, such as asking for passwords or other sensitive information. They allow different user interface methods to be plugged in, with the OpenSSL default method being one example.

UI_new() creates a new user interface object. UI_install_method() installs a user interface method globally. UI_get_method() retrieves the currently installed user interface method for a given UI object. UI_method_name() returns the name of a user interface method. UI_new_fp() creates a new UI object associated with a given file pointer. UI_set_result() sets the result for a specific prompt index. UI_get_result() retrieves the result for a specific prompt index. UI_free() frees a user interface object. UI_add_error() adds an error message to the UI object. UI_get_error() retrieves an error message by index. UI_set_input_flags() sets input flags for the UI object. UI_get_input_flags() retrieves the current input flags. UI_add_input_flags() adds flags to the existing input flags. UI_load_ex() loads a user interface method by name. UI_method_set_opener(), UI_method_set_writer(), UI_method_set_reader(), UI_method_set_prompt(), and UI_method_set_closer() are used to define the callback functions for a user interface method.

UI_OpenSSL is a pointer to the default OpenSSL user interface method. UI_OpenSSL_method() returns a pointer to the default OpenSSL UI method. UI_OpenSSL_print_errors(), UI_OpenSSL_write_errors(), UI_OpenSSL_read_errors(), and UI_OpenSSL_prompt_errors() are specific functions for handling errors within the OpenSSL UI method. UI_OpenSSL_cleanup() cleans up resources used by the OpenSSL UI method.

RETURN VALUES

These functions typically return 1 on success and 0 or -1 on failure, depending on the function.
