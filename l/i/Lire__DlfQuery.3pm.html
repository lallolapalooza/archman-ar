NAME

Lire::DlfQuery - Object for querying Dlf records

SYNOPSIS

 use Lire::DlfQuery;

 my $query = Lire::DlfQuery->new( database => $dlf_database );
 my @records = $query->all_records;
 my $record = $query->find_record( timestamp_begin => 1234567890,
                                   timestamp_end   => 1234567900 );
 my @records = $query->find_records_by_id( id => 123 );

 # $query->{database} is the Dlf::Database object
 # $query->{last_error}
 # $query->{last_error_message}

DESCRIPTION

This module provides a query object for Dlf records. It allows you to fetch all records from a Dlf database, or fetch specific records by timestamp range or ID.

SEE ALSO

Dlf(3pm), Dlf::Database(3pm).
