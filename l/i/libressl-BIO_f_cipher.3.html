NAME

BIO_f_cipher, BIO_push_cipher, BIO_set_cipher, BIO_get_cipher_ctx - cipher BIO filter

SYNOPSIS

#include <openssl/bio.h>

BIO_METHOD *BIO_f_cipher(void);
int BIO_push_cipher(BIO *out, const EVP_CIPHER *cipher, unsigned char *key, unsigned char *iv, int enc);
BIO *BIO_set_cipher(BIO *bio, const EVP_CIPHER *cipher, unsigned char *key, unsigned char *iv, int enc);
EVP_CIPHER_CTX *BIO_get_cipher_ctx(BIO *bio);

DESCRIPTION

The cipher BIO filter allows the use of an EVP cipher as a BIO filter. It can be pushed onto a BIO chain using the BIO_push() function.

The cipher BIO filter performs encryption or decryption of data passing through it.

When the cipher BIO is pushed onto a chain, it must be configured with a cipher, a key, and an initialization vector (IV).

The BIO_f_cipher() function returns a BIO method for cipher BIOs.

The BIO_push_cipher() function pushes a cipher BIO filter onto the BIO chain represented by out. The cipher used is specified by cipher. The key and iv are used for encryption/decryption. If enc is 1, encryption is performed. If enc is 0, decryption is performed.

The BIO_set_cipher() function sets the cipher BIO filter for the BIO bio. The cipher, key, and IV are set similarly to BIO_push_cipher().

The BIO_get_cipher_ctx() function retrieves the EVP_CIPHER_CTX from the cipher BIO filter.

The cipher BIO filter handles the padding of data automatically. If the data being written is not a multiple of the cipher's block size, padding will be added. When reading, the padding will be removed.

The cipher BIO filter is a stateful filter. It maintains the cipher context and updates it as data is processed.

When decrypting, the IV is typically prepended to the ciphertext. The cipher BIO filter expects to read the IV first, then the ciphertext. The IV is used to initialize the cipher context for decryption.

When encrypting, the IV is typically appended to the ciphertext. The cipher BIO filter writes the IV after the ciphertext. The IV is then used to initialize the cipher context for decryption.

The cipher BIO filter is a stream cipher filter. It is not suitable for block ciphers that require exact block sizes for input and output without proper handling of padding.

The cipher BIO filter can be used with various BIO types, including file BIOs, memory BIOs, and network BIOs.

The cipher BIO filter handles the key schedule and initialization vector automatically. The key and IV are set when the cipher BIO is pushed onto the chain or set using BIO_set_cipher().

The cipher BIO filter is a thread-safe filter. However, the underlying BIO and the cipher context must also be thread-safe.

The cipher BIO filter can be used in conjunction with other BIO filters, such as compression BIOs or hash BIOs.

When using the cipher BIO filter for encryption, it is recommended to use a random IV and to prepend it to the ciphertext. When decrypting, the IV must be provided to initialize the cipher context.
