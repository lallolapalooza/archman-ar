libressl-d2i_PKEY_USAGE_PERIOD(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

D2I_PKEY_USAGE_PERIOD(3) دليل وظائف المكتبة D2I_PKEY_USAGE_PERIOD(3)

الاسم

d2i_PKEY_USAGE_PERIOD، i2d_PKEY_USAGE_PERIOD — فك تشفير وتشفير امتدادات فترة استخدام المفتاح X.509

ملخص

المكتبة «libcrypto»
#include <openssl/x509v3.h>

PKEY_USAGE_PERIOD *
d2i_PKEY_USAGE_PERIOD(PKEY_USAGE_PERIOD **val_out, const unsigned char **der_in, long length);

int
i2d_PKEY_USAGE_PERIOD(PKEY_USAGE_PERIOD *val_in, unsigned char **der_out);

الوصف

d2i_PKEY_USAGE_PERIOD() و i2d_PKEY_USAGE_PERIOD() تقومان بفك تشفير وتشفير بنية PrivateKeyUsagePeriod بتنسيق ASN.1 المحدد في RFC 3280 القسم 4.2.1.4. للحصول على تفاصيل حول الدلالات، الأمثلة، التحذيرات، والأخطاء، راجع ASN1_item_d2i(3).

قيم الإرجاع

d2i_PKEY_USAGE_PERIOD() ترجع كائن PKEY_USAGE_PERIOD أو NULL في حالة حدوث خطأ.

i2d_PKEY_USAGE_PERIOD() ترجع عدد البايتات التي تم تشفيرها بنجاح أو قيمة سالبة في حالة حدوث خطأ.

انظر أيضًا

ASN1_item_d2i(3)، PKEY_USAGE_PERIOD_new(3)، X509_EXTENSION_new(3)

المعايير

RFC 3280: Internet X.509 Public Key Infrastructure Certificate and Certificate Revocation List (CRL) Profile, section 4.2.1.4: Private Key Usage Period

تم إبطال RFC 3280 بواسطة RFC 5280؛ راجع PKEY_USAGE_PERIOD_new(3) لمزيد من التفاصيل.

التاريخ

d2i_PKEY_USAGE_PERIOD() و i2d_PKEY_USAGE_PERIOD() ظهرتا لأول مرة في OpenSSL 0.9.2b وكانتا متاحتين منذ OpenBSD 2.6.
