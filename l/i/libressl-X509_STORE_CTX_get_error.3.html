الوصف

عادةً ما يتم استدعاء معظم هذه الوظائف بعد X509_verify_cert(3) للتدقيق في معلومات الحالة المتعلقة بالتحقق من الشهادة. قد يتم استدعاء البعض الآخر أيضًا في دالة رد اتصال التحقق لتحديد طبيعة الخطأ.

X509_STORE_CTX_get_error() تُرجع رمز الخطأ الخاص بـ ctx. انظر قسم رموز الأخطاء للحصول على وصف كامل لجميع رموز الأخطاء.

X509_STORE_CTX_set_error() تقوم بتعيين رمز الخطأ الخاص بـ ctx إلى s. على سبيل المثال، يمكن استخدامها في دالة رد اتصال التحقق لتعيين خطأ بناءً على فحوصات إضافية.

X509_STORE_CTX_get_error_depth() تُرجع عمق الخطأ. هذا عدد صحيح غير سالب يمثل مكان حدوث الخطأ في سلسلة الشهادات. إذا كان صفرًا، فقد حدث في شهادة الكيان النهائي، واحد إذا كانت الشهادة التي وقعت على شهادة الكيان النهائي، وهكذا.

X509_STORE_CTX_set_error_depth() تقوم بتعيين عمق الخطأ. يمكن استخدام هذا بالاشتراك مع X509_STORE_CTX_set_error() لتعيين العمق الذي تم عنده اكتشاف حالة الخطأ.

X509_STORE_CTX_get_current_cert() تُرجع الشهادة في ctx التي تسببت في الخطأ أو NULL إذا لم تكن هناك شهادة ذات صلة.

X509_STORE_CTX_set_current_cert() تقوم بتعيين الشهادة التي تسببت في الخطأ في ctx إلى cert المعطاة. هذه القيمة ليست مخصصة للبقاء صالحة لفترة طويلة جدًا، وتبقى مملوكة للمستدعي. يمكن فحصها بواسطة دالة رد اتصال التحقق التي يتم استدعاؤها لمعالجة كل خطأ يتم مواجهته أثناء التحقق من السلسلة، ولم تعد مطلوبة بعد عودة مثل هذه الدالة. إذا رغبت دالة رد الاتصال في حفظ الشهادة لاستخدامها بعد عودتها، فيجب عليها زيادة عدد المراجع الخاص بها عبر X509_up_ref(3). بمجرد عدم الحاجة إلى شهادة محفوظة بهذا الشكل، يمكن تحريرها باستخدام X509_free(3).

X509_STORE_CTX_get0_current_issuer() تُرجع الشهادة التي تسببت في فشل التحقق من الجهة المصدرة أو NULL إذا لم تكن هناك شهادة CA ذات صلة.

X509_STORE_CTX_get0_current_crl() تُرجع قائمة إلغاء الشهادات التي تسببت في فشل التحقق من CRL أو NULL إذا لم تكن هناك CRL ذات صلة.

عندما تنشأ الحاجة، أثناء التحقق من مسار الشهادات، للتحقق من صحة مسار الشهادات لشهادة جهة إصدار CRL، تقوم المكتبة بإنشاء كائن X509_STORE_CTX جديد ومؤقت. إذا تم استدعاء X509_STORE_CTX_get0_parent_ctx() على هذا الكائن المؤقت، يتم إرجاع مؤشر إلى سياق التحقق الأصلي لمسار الشهادات. قد يكون هذا مفيدًا في دوال رد الاتصال التي يتم استدعاؤها من X509_verify_cert(3) أو من روتيناتاتها لمعرفة ما إذا كانت دالة رد الاتصال تُستدعى من التحقق من مسار الشهادة المستهدفة أو من التحقق من مسار شهادة جهة إصدار CRL ذات صلة، وإذا كانت الحالة الأخيرة، فما هي الشهادة المستهدفة.

X509_STORE_CTX_get0_chain() تُرجع مؤشرًا داخليًا لسلسلة تحقق كاملة إذا كان استدعاء سابق لـ X509_verify_cert(3) ناجحًا. إذا لم يكن استدعاء X509_verify_cert(3) ناجحًا، فقد تكون السلسلة المُرجعة غير مكتملة أو غير صالحة. X509_STORE_CTX_get_chain() هو اسم مستعار مهمل لـ X509_STORE_CTX_get0_chain(). X509_STORE_CTX_get1_chain() تُرجع نسخة عميقة من نفس السلسلة التي تستمر حتى بعد تحرير بنية ctx. عندما لا تكون مطلوبة بعد الآن، يجب تحريرها باستخدام

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

sk_X509_pop_free(chain, X509_free).

X509_STORE_CTX_set0_verified_chain() يقوم بتحرير سلسلة التحقق التي تم إنشاؤها بواسطة استدعاء سابق لـ X509_verify_cert(3)، إذا كان هناك، ويستبدلها بـ chain المحدد. يتم نقل ملكية chain إلى ctx، لذا يجب ألا يقوم المتصل بتحريرها.

X509_verify_cert_error_string() يعيد سلسلة نصية قابلة للقراءة لخطأ التحقق n.

يجب استخدام الدوال المذكورة أعلاه بدلاً من الإشارة مباشرة إلى الحقول في بنية X509_VERIFY_CTX.

في إصدارات OpenSSL قبل 1.0، لم تكن الشهادة الحالية التي أعادتها X509_STORE_CTX_get_current_cert() تكون أبدًا NULL. يجب على التطبيقات التحقق من قيمة الإرجاع قبل طباعة أي معلومات تصحيح متعلقة بالشهادة الحالية.

إذا تم تمرير رمز خطأ غير معروف إلى X509_verify_cert_error_string()، يتم إرجاع "خطأ غير معروف في التحقق من الشهادة". لا ينبغي أن يحدث هذا أبدًا إلا إذا تم تمرير رمز غير صالح.

قيم الإرجاع

X509_STORE_CTX_get_error() يعيد X509_V_OK أو رمز خطأ.

X509_STORE_CTX_get_error_depth() يعيد عمق خطأ غير سالب.

X509_STORE_CTX_get_current_cert()، X509_STORE_CTX_get0_current_issuer()، و X509_STORE_CTX_get0_current_crl() تعيد الكائن الذي سبب الخطأ أو NULL إذا لم يكن هناك كائن من النوع المطلوب ذي صلة بالخطأ.

X509_STORE_CTX_get0_parent_ctx() يعيد السياق الأب أو NULL إذا كان ctx ليس سياق ابن مؤقت يستخدم للتحقق من المسار لشهادة جهة إصدار CRL.

X509_STORE_CTX_get_num_untrusted() يعيد عدد الشهادات غير الموثوقة التي تم استخدامها في بناء السلسلة أثناء استدعاء X509_verify_cert(3).

X509_STORE_CTX_get0_chain()، X509_STORE_CTX_get_chain()، و X509_STORE_CTX_get1_chain() تعيد مؤشرًا إلى مكدس شهادات أو NULL إذا حدث خطأ.

X509_verify_cert_error_string() يعيد سلسلة نصية قابلة للقراءة لخطأ التحقق n.

رموز الخطأ

يتم عرض قائمة برموز الخطأ ورسائله أدناه. تم تعريف بعض رموز الخطأ ولكن لم يتم إرجاعها حاليًا: يتم وصفها بأنها "غير مستخدمة".

libressl - X509_STORE_CTX_get_error(3)

NAME

X509_STORE_CTX_get_error, X509_STORE_CTX_set_error, X509_STORE_CTX_get_current_cert, X509_STORE_CTX_get_num_untrusted, X509_STORE_CTX_set0_verified_chain - manage verification context

SYNOPSIS

int X509_STORE_CTX_get_error(X509_STORE_CTX *ctx);
void X509_STORE_CTX_set_error(X509_STORE_CTX *ctx, int error);
X509 *X509_STORE_CTX_get_current_cert(X509_STORE_CTX *ctx);
int X509_STORE_CTX_get_num_untrusted(X509_STORE_CTX *ctx);
int X509_STORE_CTX_set0_verified_chain(X509_STORE_CTX *ctx, STACK_OF(X509) *chain);

DESCRIPTION

X509_STORE_CTX_get_error() returns the current error code stored in the verification context ctx.

X509_STORE_CTX_set_error() sets the error code in the verification context ctx to error.

X509_STORE_CTX_get_current_cert() returns a pointer to the certificate currently being processed by the verification context ctx.

X509_STORE_CTX_get_num_untrusted() returns the number of untrusted certificates in the verification context ctx.

X509_STORE_CTX_set0_verified_chain() sets the verified chain of certificates in the verification context ctx to chain. The ownership of chain is transferred to ctx. If chain is NULL, any existing chain is freed.

RETURN VALUES

X509_STORE_CTX_get_error() returns the current error code. Possible values are defined in X509_STORE_CTX_get_error(3).

X509_STORE_CTX_get_current_cert() returns a pointer to the current certificate or NULL if none is set.

X509_STORE_CTX_get_num_untrusted() returns the number of untrusted certificates.

X509_STORE_CTX_set0_verified_chain() returns 1 on success, and 0 on failure.

ERROR CODES

The error codes returned by X509_STORE_CTX_get_error() are documented in X509_STORE_CTX_get_error(3).
