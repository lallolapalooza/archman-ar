link(1)

الحزمة: coreutils

التراخيص: GPL-3.0-or-later, GFDL-1.3-or-later

LINK(1) أوامر المستخدم LINK(1)

الاسم

link - استدعاء الدالة link لإنشاء رابط لملف

الملخص

link FILE1 FILE2
link OPTION

الوصف

استدعاء الدالة link لإنشاء رابط يسمى FILE2 لملف موجود FILE1.

--help
عرض هذه المساعدة والخروج
--version
إخراج معلومات الإصدار والخروج

المؤلف

مكتوب بواسطة Michael Stone.
