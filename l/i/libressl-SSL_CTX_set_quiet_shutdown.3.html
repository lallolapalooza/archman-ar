libressl-SSL_CTX_set_quiet_shutdown(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

SSL_CTX_SET_QUIET_SHUTDOWN(3) دليل الدوال المكتبية SSL_CTX_SET_QUIET_SHUTDOWN(3)

الاسم

SSL_CTX_set_quiet_shutdown, SSL_CTX_get_quiet_shutdown, SSL_set_quiet_shutdown, SSL_get_quiet_shutdown — تعديل سلوك إنهاء الاتصال

الملخص

مكتبة “libssl” libcrypto
#include <openssl/ssl.h>

void
SSL_CTX_set_quiet_shutdown(SSL_CTX *ctx, int mode);

int
SSL_CTX_get_quiet_shutdown(const SSL_CTX *ctx);

void
SSL_set_quiet_shutdown(SSL *ssl, int mode);

int
SSL_get_quiet_shutdown(const SSL *ssl);

الوصف

SSL_CTX_set_quiet_shutdown() تضبط علامة "إنهاء الاتصال الهادئ" للكائن ctx لتكون mode. الكائنات SSL التي تم إنشاؤها من ctx ترث القيمة mode الصحيحة في الوقت الذي يتم فيه استدعاء SSL_new(3). قد تكون القيمة mode 0 أو 1.

SSL_CTX_get_quiet_shutdown() تعيد إعداد "إنهاء الاتصال الهادئ" للكائن ctx.

SSL_set_quiet_shutdown() تضبط علامة "إنهاء الاتصال الهادئ" للكائن ssl لتكون mode. يظل الإعداد صالحًا حتى تتم إزالة ssl باستخدام SSL_free(3) أو حتى يتم استدعاء SSL_set_quiet_shutdown() مرة أخرى. لا يتغير عند استدعاء SSL_clear(3). قد تكون القيمة mode 0 أو 1.

SSL_get_quiet_shutdown() تعيد إعداد "إنهاء الاتصال الهادئ" للكائن ssl.

عادةً، عند الانتهاء من اتصال SSL، يجب على الأطراف إرسال رسائل تنبيه "إشعار الإغلاق" باستخدام SSL_shutdown(3) لإنهاء اتصال نظيف.

عند ضبط علامة "إنهاء الاتصال الهادئ" على 1، ستقوم SSL_shutdown(3) بضبط العلامات الداخلية على SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN (ثم تتصرف SSL_shutdown(3) مثل استدعاء SSL_set_shutdown(3) مع SSL_SENT_SHUTDOWN|SSL_RECEIVED_SHUTDOWN). وبالتالي يعتبر الجلسة قد انتهت، ولكن لا يتم إرسال أي تنبيه "إشعار الإغلاق" إلى الطرف المقابل. هذا السلوك ينتهك معيار TLS.

الإعداد الافتراضي هو سلوك الإنهاء العادي كما هو موصوف في معيار TLS.

قيم الإرجاع

SSL_CTX_get_quiet_shutdown() و SSL_get_quiet_shutdown() تعيد الإعداد الحالي.
