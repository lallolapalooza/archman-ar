libressl-X509_NAME_ENTRY_get_object(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

NAME

X509_NAME_ENTRY_get_object, X509_NAME_ENTRY_get_data, X509_NAME_ENTRY_set, X509_NAME_ENTRY_new, X509_NAME_ENTRY_free, X509_NAME_ENTRY_set_object, X509_NAME_ENTRY_set_data, X509_NAME_ENTRY_create_by_txt, X509_NAME_ENTRY_create_by_NID, X509_NAME_ENTRY_create_by_OBJ — manipulate X509_NAME entries

SYNOPSIS

#include <openssl/x509.h>

X509_NAME_ENTRY *X509_NAME_ENTRY_new(void);
ASN1_OBJECT *X509_NAME_ENTRY_get_object(const X509_NAME_ENTRY *ne);
ASN1_STRING *X509_NAME_ENTRY_get_data(const X509_NAME_ENTRY *ne);
int X509_NAME_ENTRY_set(X509_NAME_ENTRY *ne, int n);
int X509_NAME_ENTRY_set_object(X509_NAME_ENTRY *ne, const ASN1_OBJECT *obj);
int X509_NAME_ENTRY_set_data(X509_NAME_ENTRY *ne, const ASN1_STRING *data);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_txt(X509_NAME_ENTRY **ret, const char *field, int type, const unsigned char *bytes, int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_NID(X509_NAME_ENTRY **ret, int nid, int type, const unsigned char *bytes, int len);
X509_NAME_ENTRY *X509_NAME_ENTRY_create_by_OBJ(X509_NAME_ENTRY **ret, const ASN1_OBJECT *obj, int type, const unsigned char *bytes, int len);
void X509_NAME_ENTRY_free(X509_NAME_ENTRY *ne);

DESCRIPTION

An X509_NAME object represents a distinguished name (DN) such as the issuer or subject name in an X.509 certificate. A DN is a sequence of one or more relative distinguished names (RDNs). Each RDN is a set of one or more attribute-value pairs. An attribute-value pair is represented by an X509_NAME_ENTRY structure.

An X509_NAME_ENTRY consists of an attribute type (the object identifier, or OID) and the attribute value (the string data).

X509_NAME_ENTRY_new() allocates and returns a new, empty X509_NAME_ENTRY structure.

X509_NAME_ENTRY_get_object() returns the attribute type OID of the entry ne.

X509_NAME_ENTRY_get_data() returns the attribute value string of the entry ne.

X509_NAME_ENTRY_set() is a deprecated function. It is intended to set the RDN index within an X509_NAME object, but it does not actually perform this operation.

X509_NAME_ENTRY_set_object() sets the attribute type OID of the entry ne to obj.

X509_NAME_ENTRY_set_data() sets the attribute value string of the entry ne to data.

X509_NAME_ENTRY_create_by_txt() creates a new X509_NAME_ENTRY. The attribute type is specified by the text string field, which will be looked up internally. The type parameter specifies the ASN1 type of the data (e.g. V_ASN1_UTF8STRING). The attribute value is given by bytes and len.

X509_NAME_ENTRY_create_by_NID() is similar to X509_NAME_ENTRY_create_by_txt(), but the attribute type is specified by the integer nid (a numeric identifier for the OID).

X509_NAME_ENTRY_create_by_OBJ() is similar to X509_NAME_ENTRY_create_by_NID(), but the attribute type is specified by the ASN1_OBJECT structure obj.

The X509_NAME_ENTRY_free() function frees the X509_NAME_ENTRY structure ne. If ne is NULL, nothing is done.

The created entry is returned. If ret is not NULL, the created entry is also stored in ret. If ret is not NULL and the entry is successfully created, ret will point to the created entry. If ret is not NULL and an error occurs, ret will be NULL.

Note that the bytes and len parameters for the create functions are treated as raw bytes and are not interpreted or converted. The type parameter determines how these bytes are interpreted by ASN1 functions.

The relevant field information can be looked up internally.

RETURN VALUES

The X509_NAME_ENTRY_new() function returns a valid X509_NAME_ENTRY structure if successful; otherwise NULL is returned and an error code can be retrieved with ERR_get_error(3).

X509_NAME_ENTRY_get_object() returns a valid ASN1_OBJECT structure if it is set or NULL if an error occurred.

X509_NAME_ENTRY_get_data() returns a valid ASN1_STRING structure if it is set or NULL if an error occurred.

X509_NAME_ENTRY_set() returns the zero-based index of the RDN ne is used in, or 0 if ne is not yet used by any X509_NAME object.

The X509_NAME_ENTRY_set_object() function returns 1 if successful; otherwise 0 is returned and an error code can be retrieved with ERR_get_error(3).

X509_NAME_ENTRY_set_data() returns 1 on success or 0 on error. In some cases of failure, the reason can be determined with ERR_get_error(3).

X509_NAME_ENTRY_create_by_txt(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() return a valid X509_NAME_ENTRY structure on success or NULL if an error occurred. In some cases of failure, the reason can be determined with ERR_get_error(3).

STANDARDS

HISTORY

X509_NAME_ENTRY_new() and X509_NAME_ENTRY_free() first appeared in SSLeay 0.5.1. X509_NAME_ENTRY_get_object(), X509_NAME_ENTRY_get_data(), X509_NAME_ENTRY_set_object(), X509_NAME_ENTRY_set_data(), X509_NAME_ENTRY_create_by_NID(), and X509_NAME_ENTRY_create_by_OBJ() first appeared in SSLeay 0.8.0. These functions have been available since OpenBSD 2.4.

X509_NAME_ENTRY_create_by_txt() first appeared in OpenSSL 0.9.5 and has been available since OpenBSD 2.7.

X509_NAME_ENTRY_set() first appeared in OpenSSL 1.1.0 and has been available since OpenBSD 6.3.

CAVEATS

Despite its name, X509_NAME_ENTRY_set() does not set anything. Something like “X509_NAME_ENTRY_get_set” would have been a better name.
