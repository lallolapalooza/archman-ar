libressl-BN_cmp(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

BN_CMP(3) دليل الوظائف المكتبية BN_CMP(3)

الاسم

BN_cmp، BN_ucmp، BN_is_zero، BN_is_one، BN_is_word، BN_abs_is_word، BN_is_odd — وظائف مقارنة واختبار BIGNUM

الملخص

المكتبة “libcrypto”
#include <openssl/bn.h>

int
BN_cmp(const BIGNUM *a, const BIGNUM *b);

int
BN_ucmp(const BIGNUM *a, const BIGNUM *b);

int
BN_is_zero(const BIGNUM *a);

int
BN_is_one(const BIGNUM *a);

int
BN_is_word(const BIGNUM *a, const BN_ULONG w);

int
BN_abs_is_word(const BIGNUM *a, const BN_ULONG w);

int
BN_is_odd(const BIGNUM *a);

الوصف

BN_cmp() تقارن الأرقام a و b. BN_ucmp() تقارن القيم المطلقة لها.

BN_is_zero() و BN_is_one() و BN_is_word() تختبر ما إذا كانت a تساوي 0، 1، أو w على التوالي. BN_abs_is_word() تختبر ما إذا كانت القيمة المطلقة لـ a تساوي w. BN_is_odd() تختبر ما إذا كانت a فردية.

BN_ULONG هو ماكرو يتوسع إلى unsigned long (= uint64_t) على منصات _LP64 و unsigned int (= uint32_t) في أماكن أخرى.

قيم الإرجاع

BN_cmp() ترجع -1 إذا a<b، 0 إذا a==b، و 1 إذا a>b. BN_ucmp() نفس الشيء باستخدام القيم المطلقة لـ a و b.

BN_is_zero()، BN_is_one()، BN_is_word()، BN_abs_is_word()، و BN_is_odd() ترجع 1 إذا كان الشرط صحيحًا، 0 بخلاف ذلك.

انظر أيضًا

BN_new(3)

التاريخ

BN_cmp()، BN_ucmp()، BN_is_zero()، BN_is_one()، و BN_is_word() ظهرت لأول مرة في SSLeay 0.5.1. BN_is_odd() ظهرت لأول مرة في SSLeay 0.8.0. هذه الوظائف متاحة منذ OpenBSD 2.4.

BN_abs_is_word() ظهرت لأول مرة في OpenSSL 0.9.7 وكانت متاحة منذ OpenBSD 3.2.
