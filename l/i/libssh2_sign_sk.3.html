libssh2_sign_sk(3)

الحزمة: libssh2

التراخيص: BSD

libssh2_sign_sk(3) libssh2 libssh2_sign_sk(3)

الاسم

libssh2_sign_sk - إنشاء توقيع من مصادق FIDO2.

الملخص

#include <libssh2.h>
int
libssh2_sign_sk(LIBSSH2_SESSION *session,
                unsigned char **sig,
                size_t *sig_len,
                const unsigned char *data,
                size_t data_len,
                void **abstract);
typedef struct _LIBSSH2_PRIVKEY_SK {
    int algorithm;
    uint8_t flags;
    const char *application;
    const unsigned char *key_handle;
    size_t handle_len;
    LIBSSH2_USERAUTH_SK_SIGN_FUNC((*sign_callback));
    void **orig_abstract;
} LIBSSH2_PRIVKEY_SK;

الوصف

session - مثيل الجلسة كما تم إرجاعه بواسطة libssh2_session_init_ex(3)

sig - مؤشر إلى مخزن مؤقت لوضع التوقيع فيه. المتصل مسؤول عن تحرير التوقيع باستخدام LIBSSH2_FREE.

sig_len - مؤشر إلى طول المعلمة sig.

data - البيانات المراد توقيعها.

data_len - طول المعلمة data.

abstract - مؤشر إلى مؤشر إلى LIBSSH2_PRIVKEY_SK. انظر الوصف أدناه.

إنشاء توقيع من مصادق FIDO2، باستخدام خوارزميات تبادل المفاتيح sk-ssh-ed25519@openssh.com أو sk-ecdsa-sha2-nistp256@openssh.com.

المعلمة abstract هي مؤشر إلى مؤشر بسبب العمليات الداخلية لـ libssh2. يجب ملء LIBSSH2_PRIVKEY_SK بالكامل، ويكون المتصل مسؤولاً عن جميع عمليات إدارة الذاكرة لحقولها.

algorithm - خوارزمية التوقيع المراد استخدامها. القيم الممكنة هي LIBSSH2_HOSTKEY_TYPE_ED25519 و LIBSSH2_HOSTKEY_TYPE_ECDSA_256.

flags - قناع بت يحدد خيارات المصادق. عندما يتم تعيين LIBSSH2_SK_PRESENCE_REQUIRED، يتطلب المصادق لمسة. عندما يتم تعيين LIBSSH2_SK_VERIFICATION_REQUIRED، يتطلب المصادق رقم تعريف شخصي. العديد من الخوادم والمصادقات لا تعمل بشكل صحيح عندما لا يتم تعيين LIBSSH2_SK_PRESENCE_REQUIRED.

application - سلسلة محددة من قبل المستخدم لاستخدامها كاسم RP للمصادق. عادةً "ssh:".

key_handle - مقبض المفتاح المراد استخدامه لقائمة السماح للمصادق.

handle_len - طول المعلمة key_handle.

abstract - بيانات محددة من قبل المستخدم. عندما يكون رقم التعريف الشخصي مطلوبًا، استخدم هذا لتمرير رقم التعريف الشخصي، أو مؤشر دالة لاسترداد رقم التعريف الشخصي.

key_handle مقبض المفتاح المفكوك من ملف المفتاح الخاص.

handle_len طول المعلمة key_handle.

sign_callback - مسؤول عن التواصل مع المصادق المادي لإنشاء توقيع. عند النجاح، يجب وضع معلومات التوقيع في المعلمة `sig_info sig_info ويجب أن ترجع الدالة 0. عند الفشل، يجب أن ترجع رقمًا سالبًا. انظر libssh2_userauth_publickey_sk(3)
لمزيد من المعلومات.

orig_abstract - بيانات محددة من قبل المستخدم. عندما يكون رقم التعريف الشخصي مطلوبًا، استخدم هذا لتمرير رقم التعريف الشخصي، أو مؤشر دالة لاسترداد رقم التعريف الشخصي.

قيمة الإرجاع

إرجاع 0 عند النجاح أو سالب عند الفشل.
