libressl-EVP_PKEY_print_private(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

EVP_PKEY_PRINT_PRIVATE(3) دليل الوظائف المكتبية EVP_PKEY_PRINT_PRIVATE(3)

الاسم

EVP_PKEY_print_public، EVP_PKEY_print_private، EVP_PKEY_print_params — وظائف طباعة خوارزميات المفاتيح العامة

ملخص

المكتبة “libcrypto”
#include <openssl/evp.h>

int
EVP_PKEY_print_public(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

int
EVP_PKEY_print_private(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

int
EVP_PKEY_print_params(BIO *out, const EVP_PKEY *pkey, int indent, ASN1_PCTX *pctx);

الوصف

تقوم الوظائف EVP_PKEY_print_public()، EVP_PKEY_print_private()، و EVP_PKEY_print_params() بطباعة المكونات العامة أو الخاصة أو المعلمات للمفتاح pkey، على التوالي. يتم إرسال المفتاح إلى BIO out بشكل قابل للقراءة البشرية. تشير المعلمة indent إلى مدى المسافة البادئة للطباعة.

تسمح المعلمة pctx بتخصيص خرج الطباعة بشكل دقيق باستخدام خيارات طباعة ASN.1. إذا تم تعيين pctx إلى NULL، فسيتم استخدام القيم الافتراضية. حاليًا، لا تتضمن أي خوارزميات مفاتيح عامة أي خيارات في المعلمة pctx.

إذا كان المفتاح لا يتضمن جميع المكونات التي تشير إليها الوظيفة، فسيتم طباعة المكونات الموجودة في المفتاح فقط. على سبيل المثال، تمرير مفتاح عام إلى EVP_PKEY_print_private() سيقوم بطباعة المكونات العامة فقط.

قيم الإرجاع

تعيد كل من هذه الوظائف 1 للنجاح وصفر أو قيمة سالبة للفشل. على وجه الخصوص، تشير القيمة المرجعة -2 إلى أن العملية غير مدعومة من قبل خوارزمية المفتاح العام.

انظر أيضًا

EVP_PKEY_CTX_new(3)، EVP_PKEY_keygen(3)، EVP_PKEY_new(3)
