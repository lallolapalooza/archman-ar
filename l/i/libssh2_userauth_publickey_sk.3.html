libssh2_userauth_publickey_sk(3)

الحزمة: libssh2

التراخيص: BSD

libssh2_userauth_publickey_sk(3) libssh2 libssh2_userauth_publickey_sk(3)

الاسم

libssh2_userauth_publickey_sk - المصادقة على جلسة باستخدام مصادق FIDO2

الملخص

#include <libssh2.h>
int
libssh2_userauth_publickey_sk(LIBSSH2_SESSION *session,
                              const char *username,
                              size_t username_len,
                              const unsigned char *publickeydata,
                              size_t publickeydata_len,
                              const char *privatekeydata,
                              size_t privatekeydata_len,
                              const char *passphrase,
                              LIBSSH2_USERAUTH_SK_SIGN_FUNC((*sign_callback)),
                              void **abstract);

استدعاء

#define LIBSSH2_SK_PRESENCE_REQUIRED     0x01
#define LIBSSH2_SK_VERIFICATION_REQUIRED 0x04
typedef struct _LIBSSH2_SK_SIG_INFO {
    uint8_t flags;
    uint32_t counter;
    unsigned char *sig_r;
    size_t sig_r_len;
    unsigned char *sig_s;
    size_t sig_s_len;
} LIBSSH2_SK_SIG_INFO;
int name(LIBSSH2_SESSION *session, LIBSSH2_SK_SIG_INFO *sig_info,
         const unsigned char *data, size_t data_len, int algorithm,
         uint8_t flags, const char *application,
         const unsigned char *key_handle, size_t handle_len,
         void **abstract);

الوصف

session - مثيل الجلسة كما تم إرجاعه بواسطة libssh2_session_init_ex(3)

username - اسم المستخدم لمحاولة المصادقة له.

username_len - طول المعلمة username.

publickeydata - المخزن المؤقت الذي يحتوي على محتويات ملف المفتاح العام. إذا كان NULL، فسيتم استخراج المفتاح العام من privatekeydata. عند استخدام مصادقة الشهادات، يجب أن يحتوي هذا المخزن المؤقت على بيانات الشهادة العامة.

publickeydata_len - طول بيانات المفتاح العام.

privatekeydata - المخزن المؤقت الذي يحتوي على محتويات ملف المفتاح الخاص.

privatekeydata_len - طول بيانات المفتاح الخاص.

passphrase - عبارة المرور المستخدمة عند فك تشفير ملف المفتاح الخاص.

sign_callback - استدعاء للتواصل مع مصادق FIDO2.

abstract - بيانات مقدمة من المستخدم لتمريرها إلى الاستدعاء.

محاولة مصادقة FIDO2. باستخدام خوارزميات تبادل المفاتيح sk-ssh-ed25519@openssh.com أو sk-ecdsa-sha2-nistp256@openssh.com.

هذه الوظيفة مدعومة فقط عندما تعتمد libssh2 على OpenSSL.

وصف الاستدعاء

session - مثيل الجلسة كما تم إرجاعه بواسطة libssh2_session_init_ex(3)

sig_info - يتم ملؤه بواسطة الاستدعاء مع التوقيع والمعلومات المصاحبة من المصادق.

data - البيانات المراد توقيعها.

data_len - طول المعلمة data.

algorithm - خوارزمية التوقيع المراد استخدامها. القيم الممكنة هي LIBSSH2_HOSTKEY_TYPE_ED25519 و LIBSSH2_HOSTKEY_TYPE_ECDSA_256.

flags - قناع بت يحدد خيارات المصادق. عند تعيين LIBSSH2_SK_PRESENCE_REQUIRED، يتطلب المصادق لمسة. عند تعيين LIBSSH2_SK_VERIFICATION_REQUIRED، يتطلب المصادق رقم PIN. العديد من الخوادم والمصادقات لا تعمل بشكل صحيح عندما لا يتم تعيين LIBSSH2_SK_PRESENCE_REQUIRED.

application - سلسلة نصية يحددها المستخدم لاستخدامها كاسم RP للمصادق. عادةً "ssh:".

key_handle - مقبض المفتاح المراد استخدامه لقائمة السماح الخاصة بالمصادق.

handle_len - طول المعلمة key_handle.

abstract - بيانات محددة من قبل المستخدم. عند الحاجة إلى رقم PIN، استخدم هذا لتمرير رقم PIN، أو مؤشر دالة لاسترداد رقم PIN.

استدعاء sign_callback مسؤول عن التواصل مع المصادق الفعلي لإنشاء توقيع. عند النجاح، يجب وضع معلومات التوقيع في المعلمة `sig_info sig_info ويجب أن يعيد الاستدعاء 0. عند الفشل، يجب أن يعيد عددًا سالبًا.

حقول LIBSSH2_SK_SIG_INFO هي كما يلي.

flags - قناع بت يحدد خيارات المصادق. يجب قراءة هذا من المصادق ولا يجب نسخه ببساطة من المعلمة flags إلى الاستدعاء.

counter - قيمة تم إرجاعها من المصادق.

sig_r - لتوقيعات Ed25519، يحتوي هذا على التوقيع بأكمله، كما تم إرجاعه مباشرة من المصادق. لتوقيعات ECDSA، يحتوي هذا على المكون r للتوقيع في تمثيل ثنائي كبير النهاية. لكلتا الخوارزميتين، استخدم LIBSSH2_ALLOC لتخصيص الذاكرة. سيتم تحريرها بواسطة المتصل.

sig_r_len - طول المعلمة sig_r.

sig_s - لتوقيعات ECDSA، يحتوي هذا على المكون s للتوقيع في تمثيل ثنائي كبير النهاية. استخدم LIBSSH2_ALLOC لتخصيص الذاكرة. سيتم تحريرها بواسطة المتصل. لتوقيعات Ed25519، قم بتعيين هذا إلى NULL.

sig_s_len - طول المعلمة sig_s.

قيمة الإرجاع

إعادة 0 عند النجاح أو قيمة سالبة عند الفشل. يعيد LIBSSH2_ERROR_EAGAIN عندما كان سيحظر بخلاف ذلك. بينما LIBSSH2_ERROR_EAGAIN هو رقم سالب، فإنه ليس فشلاً بحد ذاته.

الأخطاء

بعض الأخطاء التي قد تعيدها هذه الوظيفة تشمل:

LIBSSH2_ERROR_ALLOC - فشل استدعاء تخصيص ذاكرة داخلي.

LIBSSH2_ERROR_SOCKET_SEND - غير قادر على إرسال بيانات عبر المقبس.

LIBSSH2_ERROR_AUTHENTICATION_FAILED - فشل، اسم مستخدم/مفتاح غير صحيح.
