libressl-PEM_write_bio_PKCS7_stream(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

PEM_WRITE_BIO_PKCS7_STREAM(3) دليل وظائف المكتبة PEM_WRITE_BIO_PKCS7_STREAM(3)

الاسم

PEM_write_bio_PKCS7_stream — إخراج بنية PKCS7 بتنسيق PEM

ملخص

المكتبة «libcrypto»
#include <openssl/pkcs7.h>

int
PEM_write_bio_PKCS7_stream(BIO *out, PKCS7 *p7, BIO *data, int flags);

الوصف

PEM_write_bio_PKCS7_stream() تخرج بنية PKCS7 بتنسيق PEM.

هي بخلاف ذلك مطابقة للدالة SMIME_write_PKCS7(3).

هذه الدالة هي فعليًا نسخة من PEM_write_bio_PKCS7(3) تدعم التدفق.

قيم الإرجاع

عند اكتمال التنفيذ بنجاح، يتم إرجاع 1؛ وإلا يتم إرجاع 0 ويمكن استرداد رمز خطأ باستخدام ERR_get_error(3).

انظر أيضًا

BIO_new(3), i2d_PKCS7_bio_stream(3), PEM_write_PKCS7(3), PKCS7_final(3), PKCS7_new(3), SMIME_write_PKCS7(3)

التاريخ

PEM_write_bio_PKCS7_stream() ظهرت لأول مرة في OpenSSL 1.0.0 وكانت متاحة منذ OpenBSD 4.9.
