الوصف

X509v3_get_ext_count() تسترجع عدد الإضافات في x.

X509v3_get_ext() تسترجع الإضافة loc من x. يمكن أن يأخذ المؤشر loc أي قيمة من 0 إلى X509_get_ext_count(x) - 1. الإضافة المُرجعة هي مؤشر داخلي لا يجب تحريره بواسطة التطبيق.

X509v3_get_ext_by_NID() و X509v3_get_ext_by_OBJ() تبحث عن إضافة باستخدام nid أو obj من مكدس الإضافات x. يبدأ البحث من الإضافة التي تلي lastpos أو من البداية إذا كانت lastpos تساوي -1. إذا تم العثور على الإضافة، يتم إرجاع مؤشرها؛ بخلاف ذلك، يتم إرجاع قيمة سالبة.

X509v3_get_ext_by_critical() مشابهة لـ X509v3_get_ext_by_NID() باستثناء أنها تبحث عن إضافة ذات أهمية crit. القيمة صفر لـ crit تبحث عن إضافة غير هامة؛ القيمة غير الصفرية تبحث عن إضافة هامة.

X509v3_delete_ext() تحذف الإضافة ذات المؤشر loc من x. يتم إرجاع الإضافة المحذوفة ويجب تحريرها بواسطة المتصل. إذا كانت loc

These functions are used to manipulate the extensions of X509, X509_CRL and X509_REVOKED objects. The argument x is the object whose extensions are being manipulated.

The functions with the X509v3_ prefix operate on a stack of extensions directly. The functions with the X509_ prefix operate on the extensions embedded within an X509 certificate structure. The functions with the X509_CRL_ prefix operate on the extensions embedded within an X509_CRL structure. The functions with the X509_REVOKED_ prefix operate on the extensions embedded within an X509_REVOKED entry.

The functions X509v3_get_ext_count(), X509_get_ext_count(), X509_CRL_get_ext_count() and X509_REVOKED_get_ext_count() return the number of extensions present.

The functions X509v3_get_ext(), X509_get_ext(), X509_CRL_get_ext() and X509_REVOKED_get_ext() return the extension at position loc. Positions start from 0. If loc is out of range, then NULL is returned.

The functions X509v3_get_ext_by_NID(), X509_get_ext_by_NID(), X509_CRL_get_ext_by_NID() and X509_REVOKED_get_ext_by_NID() search for an extension with the given nid (numeric ID). The search starts from the extension after the position specified by the crit parameter. If crit is -1, the search starts from the beginning. If crit is set to a valid extension index, the search starts from the extension following it. If the extension is found, its index is returned. Otherwise -1 is returned. A value of -2 is returned if OBJ_nid2obj(3) fails.

The functions X509v3_get_ext_by_OBJ(), X509_get_ext_by_OBJ(), X509_CRL_get_ext_by_OBJ() and X509_REVOKED_get_ext_by_OBJ() are similar to the ..._get_ext_by_NID functions, but they take an ASN1_OBJECT pointer obj instead of a nid.

The functions X509v3_get_ext_by_critical(), X509_get_ext_by_critical(), X509_CRL_get_ext_by_critical() and X509_REVOKED_get_ext_by_critical() search for an extension with the specified critical flag value crit. The search starts from the extension after the position specified by the crit parameter. If crit is -1, the search starts from the beginning. If crit is set to a valid extension index, the search starts from the extension following it. If the extension is found, its index is returned. Otherwise -1 is returned.

The functions X509v3_delete_ext(), X509_delete_ext(), X509_CRL_delete_ext() and X509_REVOKED_delete_ext() delete the extension at position loc. If loc is an invalid index value, NULL is returned.

X509v3_add_ext() adds the extension ex to the stack *x at position loc. If loc is -1, the new extension is added to the end. If *x is NULL, a new stack will be allocated. The passed extension ex is duplicated internally so it must be freed after use.

X509_get_ext_count(), X509_get_ext(), X509_get_ext_by_NID(), X509_get_ext_by_OBJ(), X509_get_ext_by_critical(), X509_delete_ext(), and X509_add_ext() operate on the extensions of certificate x. They are otherwise identical to the X509v3 functions.

X509_CRL_get_ext_count(), X509_CRL_get_ext(), X509_CRL_get_ext_by_NID(), X509_CRL_get_ext_by_OBJ(), X509_CRL_get_ext_by_critical(), X509_CRL_delete_ext(), and X509_CRL_add_ext() operate on the extensions of the CRL x. They are otherwise identical to the X509v3 functions.

X509_REVOKED_get_ext_count(), X509_REVOKED_get_ext(), X509_REVOKED_get_ext_by_NID(), X509_REVOKED_get_ext_by_OBJ(), X509_REVOKED_get_ext_by_critical(), X509_REVOKED_delete_ext(), and X509_REVOKED_add_ext() operate on the extensions of the CRL entry x. They are otherwise identical to the X509v3 functions.

These functions are used to examine stacks of extensions directly. Many applications will want to parse or encode and add an extension: they should use the extension encode and decode functions instead such as X509_get_ext_d2i(3).

Extension indices start from zero, so a zero index return value is not an error. These search functions start from the extension after the lastpos parameter, so it should initially be set to -1. If it is set to 0, the initial extension will not be checked.

RETURN VALUES

X509v3_get_ext_count() returns the extension count.

X509v3_get_ext(), X509v3_delete_ext(), and X509_delete_ext() return an X509_EXTENSION pointer or NULL if an error occurs.

X509v3_get_ext_by_NID(), X509v3_get_ext_by_OBJ(), and X509v3_get_ext_by_critical() return the extension index or -1 if an error occurs. In addition, X509v3_get_ext_by_NID() returns -2 if OBJ_nid2obj(3) fails on the requested nid.

X509v3_add_ext() returns a stack of extensions or NULL on error.

X509_add_ext() returns 1 on success or 0 on error.
