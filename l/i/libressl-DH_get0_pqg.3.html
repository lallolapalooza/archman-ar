libressl-DH_get0_pqg(3)

الحزمة: libressl

التراخيص: ISC, custom:OpenSSL

NAME

DH_get0_pqg, DH_set0_pqg, DH_get0_key, DH_set0_key, DH_clear_flags, DH_test_flags, DH_set_flags, DH_get0_engine, DH_set_length, DH_get0_p, DH_get0_q, DH_get0_g, DH_get0_pub_key, DH_get0_priv_key - Diffie-Hellman parameter and key manipulation

DESCRIPTION

These functions provide access to the components of a DH structure, and to manipulate its flags and associated engine.

DH_get0_pqg() retrieves the Diffie-Hellman prime p, generator g, and the prime factor q, if available. The values are stored in the memory locations pointed to by p, q, and g.

DH_set0_pqg() sets the Diffie-Hellman prime p, generator g, and the prime factor q. The function takes ownership of the provided BIGNUM objects. If p, q, or g is NULL, the corresponding component is not set.

DH_get0_key() retrieves the public key pub_key and private key priv_key, if available. The values are stored in the memory locations pointed to by pub_key and priv_key.

DH_set0_key() sets the public key pub_key and private key priv_key. The function takes ownership of the provided BIGNUM objects. If pub_key or priv_key is NULL, the corresponding component is not set.

DH_get_flags() returns the flags associated with the DH structure.

DH_set_flags() sets the specified flags in the DH structure.

DH_clear_flags() clears the specified flags in the DH structure.

DH_test_flags() tests if the specified flags are set in the DH structure.

DH_get0_engine() returns the ENGINE associated with the DH structure.

DH_set_engine() sets the specified ENGINE for the DH structure. Note that this is deprecated and should not be used.

DH_set_length() sets the length of the private key in the DH structure.

DH_get0_p(), DH_get0_q(), DH_get0_g(), DH_get0_pub_key(), and DH_get0_priv_key() are convenience functions that retrieve the individual components p, q, g, public key, and private key, respectively.

RETURN VALUES

DH_get0_pqg(), DH_get0_key(), DH_get0_p(), DH_get0_q(), DH_get0_g(), DH_get0_pub_key(), and DH_get0_priv_key() return 1 on success, and 0 on failure.

DH_set0_pqg() and DH_set0_key() return 1 on success, and 0 on failure.

DH_get_flags() returns the current flags.

DH_set_flags(), DH_clear_flags(), DH_test_flags(), DH_set_engine(), and DH_set_length() return 1 on success and 0 on failure.

DH_get0_engine() returns the engine or NULL if no engine is set.

HISTORY

DH_get0_pqg(), DH_set0_pqg(), DH_get0_key(), DH_set0_key(), DH_clear_flags(), DH_test_flags(), DH_set_flags(), DH_get0_engine(), and DH_set_length() first appeared in OpenSSL 1.1.0 and have been available since OpenBSD 6.3.

DH_get0_p(), DH_get0_q(), DH_get0_g(), DH_get0_pub_key(), and DH_get0_priv_key() first appeared in OpenSSL 1.1.1 and have been available since OpenBSD 7.1.
