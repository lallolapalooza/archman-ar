الاسم

libpipewire-module-snapcast-discover - اكتشاف Snapcast

الوصف

يقوم تلقائيًا بإنشاء جهاز استقبال Snapcast استنادًا إلى معلومات zeroconf.

سيقوم هذا الوحدة بتحميل وحدة `module-protocol-simple` لكل دفق معلن يطابق القاعدة مع إجراء `create-stream` ويمرر الخصائص إلى الوحدة.

إذا لم يتم تقديم أي `stream.rules`، فسيقوم بإنشاء جهاز استقبال لجميع خوادم snapcast المعلنة.

سيتم إنشاء دفق جديد على خادم snapcast بالاسم المحدد `snapcast.stream-name` أو `PipeWire-<hostname>`. ستحتاج إلى توجيه هذا الدفق الجديد إلى العملاء باستخدام تطبيق تحكم snapcast.

اسم الوحدة

libpipewire-module-snapcast-discover

خيارات الوحدة

خيارات خاصة بسلوك هذه الوحدة

  • `snapcast.discover-local` = السماح باكتشاف الخدمات المحلية أيضًا. افتراضي: `false`.
  • `stream.rules` = <القواعد>: قواعد المطابقة، استخدام إجراءات `create-stream`. انظر Protocol Simple لخصائص الوحدة.

تطابقات `stream.rules`

  • `snapcast.ip`: عنوان IP لخادم snapcast.
  • `snapcast.port`: منفذ خادم snapcast.
  • `snapcast.ifindex`: فهرس الواجهة التي تم استلام إعلان snapcast عليها.
  • `snapcast.ifname`: اسم الواجهة التي تم استلام إعلان snapcast عليها.
  • `snapcast.name`: اسم خادم snapcast.
  • `snapcast.hostname`: اسم المضيف لخادم snapcast.
  • `snapcast.domain`: نطاق خادم snapcast.

إنشاء دفق `stream.rules`

بالإضافة إلى جميع الخصائص التي يمكن تمريرها إلى Protocol Simple، يمكنك أيضًا تعيين:

  • `snapcast.stream-name`: اسم الدفق على خادم snapcast.
  • `node.name`: اسم جهاز الاستقبال الذي يتم إنشاؤه على المرسل.

مثال على التهيئة

# ~/.config/pipewire/pipewire.conf.d/my-snapcast-discover.conf
context.modules = [
{   name = libpipewire-module-snapcast-discover
    args = {
        stream.rules = [
            {   matches = [
                    {    snapcast.ip = "~.*"
                         #snapcast.port = 1000
                         #snapcast.ifindex = 1
                         #snapcast.ifname = eth0
                         #snapcast.name = ""
                         #snapcast.hostname = ""
                         #snapcast.domain = ""
                    }
                ]
                actions = {
                    create-stream = {
                        #audio.rate = 44100
                        #audio.format = S16LE   # S16LE, S24_32LE, S32LE
                        #audio.channels = 2
                        #audio.position = [ FL FR ]
                        #
                        # اسم الدفق كما يظهر على خادم snapcast:
                        #snapcast.stream-name = "PipeWire"
                        #
                        # اسم جهاز الاستقبال على المرسل:
                        #node.name = "Snapcast Sink"
                        #
                        #capture = true
                        #server.address = [ "tcp:4711" ]
                        #capture.props = {
                            #target.object = ""
                            #node.latency = 2048/48000
                            #media.class = "Audio/Sink"
                        #}
                    }
                }
            }
        ]
    }
}
]
