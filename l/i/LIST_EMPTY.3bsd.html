قوائم الذيل TAIL QUEUES

قائمة الذيل يرأسها هيكل معرف بواسطة الماكرو TAILQ_HEAD. يحتوي هذا الهيكل على زوج من المؤشرات، أحدهما يشير إلى العنصر الأول في قائمة الذيل والآخر إلى العنصر الأخير في قائمة الذيل. العناصر مرتبطة بشكل مزدوج بحيث يمكن إزالة عنصر عشوائي دون تتبع قائمة الذيل. يمكن إضافة عناصر جديدة إلى قائمة الذيل بعد عنصر موجود، قبل عنصر موجود، في رأس قائمة الذيل، أو في نهاية قائمة الذيل. يتم تعريف هيكل TAILQ_HEAD على النحو التالي:

TAILQ_HEAD(HEADNAME, TYPE) head;

حيث HEADNAME هو اسم الهيكل الذي سيتم تعريفه، و TYPE هو نوع العناصر التي سيتم ربطها في قائمة الذيل. يمكن بعد ذلك تعريف مؤشر إلى رأس قائمة الذيل كالتالي:

struct HEADNAME *headp;

(الأسماء head و headp قابلة للاختيار من قبل المستخدم.)

الماكرو TAILQ_HEAD_INITIALIZER يُقيّم إلى مُهيئ لقائمة الذيل head.

الماكرو TAILQ_CONCAT يقوم بدمج قائمة الذيل التي يرأسها head2 في نهاية قائمة الذيل التي يرأسها head1، مع إزالة جميع الإدخالات من القائمة الأولى.

الماكرو TAILQ_EMPTY يُقيّم إلى صحيح إذا لم تكن هناك عناصر في قائمة الذيل.

الماكرو TAILQ_ENTRY يُعرف هيكلًا يقوم بربط العناصر في قائمة الذيل.

الماكرو TAILQ_FIRST يُرجع العنصر الأول في قائمة الذيل أو NULL إذا كانت قائمة الذيل فارغة.

الماكرو TAILQ_FOREACH يتتبع قائمة الذيل المشار إليها بواسطة head في الاتجاه الأمامي، مع تعيين كل عنصر بدوره إلى var. يتم تعيين var إلى NULL إذا اكتملت الحلقة بشكل طبيعي، أو إذا لم تكن هناك عناصر.

الماكرو TAILQ_FOREACH_FROM يتصرف بشكل مطابق لـ TAILQ_FOREACH عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في TAILQ المشار إليها بواسطة head.

الماكرو TAILQ_FOREACH_REVERSE يتتبع قائمة الذيل المشار إليها بواسطة head في الاتجاه العكسي، مع تعيين كل عنصر بدوره إلى var.

الماكرو TAILQ_FOREACH_REVERSE_FROM يتصرف بشكل مطابق لـ TAILQ_FOREACH_REVERSE عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة العكسية عند var بدلاً من العنصر الأخير في TAILQ المشار إليها بواسطة head.

الماكرو TAILQ_FOREACH_SAFE و TAILQ_FOREACH_REVERSE_SAFE يتتبعان القائمة المشار إليها بواسطة head في الاتجاه الأمامي أو العكسي على التوالي، مع تعيين كل عنصر بدوره إلى var. ومع ذلك، على عكس نظيراتها غير الآمنة، TAILQ_FOREACH و TAILQ_FOREACH_REVERSE تجعل من الممكن إزالة var وكذلك تحريره من داخل الحلقة بأمان دون التأثير على التتبع.

الماكرو TAILQ_FOREACH_FROM_SAFE يتصرف بشكل مطابق لـ TAILQ_FOREACH_SAFE عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة عند var بدلاً من العنصر الأول في TAILQ المشار إليها بواسطة head.

الماكرو TAILQ_FOREACH_REVERSE_FROM_SAFE يتصرف بشكل مطابق لـ TAILQ_FOREACH_REVERSE_SAFE عندما يكون var هو NULL، وإلا فإنه يعامل var كعنصر TAILQ تم العثور عليه سابقًا ويبدأ الحلقة العكسية عند var بدلاً من العنصر الأخير في TAILQ المشار إليها بواسطة head.

الماكرو TAILQ_INIT يقوم بتهيئة قائمة الذيل المشار إليها بواسطة head.

الماكرو TAILQ_INSERT_HEAD يُدرج العنصر الجديد elm في رأس قائمة الذيل.

الماكرو TAILQ_INSERT_TAIL يُدرج العنصر الجديد elm في نهاية قائمة الذيل.

الماكرو TAILQ_INSERT_AFTER يُدرج العنصر الجديد elm بعد العنصر listelm.

الماكرو TAILQ_INSERT_BEFORE يُدرج العنصر الجديد elm قبل العنصر listelm.

الماكرو TAILQ_LAST يُرجع العنصر الأخير في قائمة الذيل. إذا كانت قائمة الذيل فارغة، فإن القيمة المرجعة هي NULL.

الماكرو TAILQ_NEXT يُرجع العنصر التالي في قائمة الذيل، أو NULL إذا كان هذا العنصر هو الأخير.

الماكرو TAILQ_PREV يُرجع العنصر السابق في قائمة الذيل، أو NULL إذا كان هذا العنصر هو الأول.

الماكرو TAILQ_REMOVE يزيل العنصر elm من قائمة الذيل.

الماكرو TAILQ_SWAP يبادل محتويات head1 و head2.

NAME


queue, TAILQ,
    LIST, SLIST, INSQ,
    REMQ, REMQUE — macros for
    manipulating singly and doubly linked lists and queues






LIBRARY


Support library libbsd






SYNOPSIS


#include <sys/queue.h>

typedef struct entry { ... entry_t; } entry_t;
typedef struct tailq_entry { ... tailq_entry_t; } tailq_entry_t;

/* Singly-linked lists */
typedef struct slist { ... slist_t; } slist_t;
typedef struct slist_entry { ... slist_entry_t; } slist_entry_t;

/* Doubly-linked lists */
typedef struct list { ... list_t; } list_t;
typedef struct list_entry { ... list_entry_t; } list_entry_t;

/* Doubly-linked tail queues */
typedef struct tailq { ... tailq_t; } tailq_t;
typedef struct tailq_entry { ... tailq_entry_t; } tailq_entry_t;

void
some_function(entry_t *n1, entry_t *n2)
{
	LIST_ENTRY(entry) n1_list;
	TAILQ_ENTRY(entry) n1_tailq;
	entry_t *temp;

	LIST_INIT(&head);
	LIST_INSERT_HEAD(&head, n1, n1_list);
	LIST_INSERT_AFTER(n1, n2, n1_list);
	LIST_REMOVE(n1, n1_list);
	temp = LIST_FIRST(&head);
	temp = LIST_NEXT(n1, n1_list);

	TAILQ_INIT(&head);
	TAILQ_INSERT_HEAD(&head, n1, n1_tailq);
	TAILQ_INSERT_TAIL(&head, n2, n1_tailq);
	TAILQ_INSERT_AFTER(&head, n1, n2, n1_tailq);
	TAILQ_INSERT_BEFORE(n1, n2, n1_tailq);
	TAILQ_REMOVE(&head, n1, n1_tailq);
	temp = TAILQ_FIRST(&head);
	temp = TAILQ_NEXT(n1, n1_tailq);
	temp = TAILQ_PREV(n1, tailq, n1_tailq);
	temp = TAILQ_LAST(&head, tailq);
	temp = TAILQ_PREV(n1, tailq, n1_tailq);
	temp = TAILQ_NEXT(n1, n1_tailq);
	TAILQ_FOREACH(temp, &head, n1_tailq) {
		...
	}
	TAILQ_FOREACH_REVERSE(temp, &head, tailq, n1_tailq) {
		...
	}
	TAILQ_FOREACH_SAFE(temp, &head, n1_tailq, n1) {
		...
	}
	TAILQ_FOREACH_REVERSE_SAFE(temp, &head, tailq, n1_tailq, n1) {
		...
	}
	n1 = n2;
}

DIAGNOSTICS


When debugging queue(3), it can be useful
    to trace queue changes. To enable tracing, define the macro
    QUEUE_MACRO_DEBUG_TRACE at compile time.


It can also be useful to trash pointers that have been unlinked
    from a queue, to detect use after removal. To enable pointer trashing,
    define the macro QUEUE_MACRO_DEBUG_TRASH at compile
    time. The macro QMD_IS_TRASHED(void
    *ptr) returns true if ptr has been trashed by
    the QUEUE_MACRO_DEBUG_TRASH option.

التشخيص

عند تصحيح أخطاء queue(3)، قد يكون من المفيد تتبع تغييرات الطابور. لتمكين التتبع، قم بتعريف الماكرو QUEUE_MACRO_DEBUG_TRACE في وقت الترجمة.
