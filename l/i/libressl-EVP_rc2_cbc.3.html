NAME

EVP_rc2_cbc, EVP_rc2_cfb, EVP_rc2_ofb, EVP_rc2_ecb - RC2 encryption/decryption

SYNOPSIS

#include <openssl/evp.h>

int EVP_rc2_cbc(const EVP_CIPHER *cipher);
int EVP_rc2_cfb(const EVP_CIPHER *cipher);
int EVP_rc2_ofb(const EVP_CIPHER *cipher);
int EVP_rc2_ecb(const EVP_CIPHER *cipher);

DESCRIPTION

These functions return an EVP_CIPHER object implementing the RC2 cipher in different modes. These functions are deprecated and should not be used. Instead, the more general functions like EVP_aes_128_cbc() should be used.

RC2 is a variable-key-size block cipher. Historically, RC2 supported key sizes from 1 to 128 bits. However, due to security concerns, the use of RC2 with key sizes smaller than 40 bits is no longer recommended. It is also not recommended to use RC2 at all.

The key length of the returned cipher is set to 128 bits.

The following modes are supported:

EVP_rc2_cbc()
Cipher Feedback (CFB) mode.
EVP_rc2_cfb()
Output Feedback (OFB) mode.
EVP_rc2_ofb()
Electronic Codebook (ECB) mode.
EVP_rc2_ecb()
Cipher Block Chaining (CBC) mode.

The actual cipher object must be passed to these functions. For example:

const EVP_CIPHER *cipher = EVP_get_cipherbyname("rc2-40-cbc");
if (cipher) {
    EVP_CIPHER_CTX *ctx = EVP_CIPHER_CTX_new();
    if (ctx) {
        if (EVP_EncryptInit_ex(ctx, cipher, NULL, key, iv) == 1) {
            // ... encryption ...
        }
        EVP_CIPHER_CTX_free(ctx);
    }
}

It is recommended to use RC2 with a key length of at least 40 bits.

See also EVP_CIPHER_meth_new(3), EVP_CIPHER_CTX_new(3).

RETURN VALUES

These functions return a pointer to a static EVP_CIPHER object. The pointer should not be freed. If an error occurs, NULL is returned.

SEE ALSO

EVP_CIPHER_meth_new(3), EVP_CIPHER_CTX_new(3), EVP_EncryptInit_ex(3)

HISTORY

The functions EVP_rc2_cbc(), EVP_rc2_cfb(), EVP_rc2_ofb(), and EVP_rc2_ecb() were deprecated in OpenSSL 3.0.0.
