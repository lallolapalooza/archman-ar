LIBBLKID(3) دليل المبرمجين LIBBLKID(3)

الاسم

libblkid - مكتبة تحديد أجهزة الكتل

الملخص

#include <blkid.h>

cc file.c -lblkid

الوصف

تُستخدم مكتبة libblkid لتحديد أجهزة الكتل (الأقراص) من حيث محتواها (مثل نوع نظام الملفات) وكذلك لاستخراج معلومات إضافية مثل تسميات نظام الملفات/أسماء وحدات التخزين، ومعرفات فريدة/أرقام تسلسلية. الاستخدام الشائع هو السماح باستخدام علامات LABEL= و UUID= بدلاً من ترميز أسماء أجهزة الكتل المحددة في ملفات التكوين. انظر قائمة بجميع العلامات المتاحة في قسم TAGS.

يسمح الجزء المنخفض المستوى من المكتبة أيضًا باستخراج معلومات حول الأقسام وطوبولوجيا جهاز الكتلة.

يحتفظ الجزء عالي المستوى من المكتبة بمعلومات حول أجهزة الكتل في ملف ذاكرة تخزين مؤقت ويتم التحقق من صحته قبل إعادته للمستخدم (إذا كان للمستخدم إذن قراءة على جهاز الكتلة الخام، وإلا فلا). تسمح ذاكرة التخزين المؤقت أيضًا للمستخدمين غير المتميزين (عادةً أي شخص غير الجذر، أو أولئك الذين ليسوا في مجموعة "disk") بتحديد الأجهزة حسب التسمية/المعرف. يمكن تجاوز الموقع القياسي لملف ذاكرة التخزين المؤقت بواسطة متغير البيئة BLKID_FILE.

في الحالات التي يتم فيها الحصول على معلومات حول جهاز معروف واحد، فإن ذلك لا يؤثر على الأداء سواء تم استخدام ذاكرة التخزين المؤقت أم لا (ما لم تكن غير قادر على قراءة جهاز الكتلة مباشرة).

يدعم الجزء عالي المستوى من المكتبة طريقتين لتحديد LABEL/UUID. يقرأ المعلومات مباشرة من جهاز كتلة أو يقرأ المعلومات من الروابط الرمزية udev /dev/disk/by-*. يُفضل udev كطريقة افتراضية.

إذا كنت تتعامل مع أجهزة متعددة، يوصى بشدة باستخدام ذاكرة التخزين المؤقت (حتى لو كانت فارغة) حيث سيتم مسح الأجهزة مرة واحدة على الأكثر وسيتم تحديث ذاكرة التخزين المؤقت على القرص إذا أمكن.

في بعض الحالات (النوى المعيارية)، لا تكون أجهزة الكتل مرئية إلا بعد الوصول إليها للمرة الأولى، لذلك من الضروري أن تكون هناك طريقة لتحديد هذه الأجهزة دون تعداد الأجهزة المرئية فقط، لذا فإن استخدام ملف ذاكرة التخزين المؤقت مطلوب في هذا الموقف.

ملف الإعداد

يمكن تجاوز الموقع القياسي لملف الإعداد /etc/blkid.conf بواسطة متغير البيئة BLKID_CONF. لمزيد من التفاصيل حول ملف الإعداد، راجع صفحة الدليل blkid(8).

العلامات

تم إدراج جميع العلامات المتاحة أدناه. لا يتم دعم جميع العلامات لجميع أنظمة الملفات. لتمكين علامة، قم بتعيين أحد الأعلام التالية باستخدام blkid_probe_set_superblocks_flags():

BLKID_SUBLKS_TYPE

•TYPE - نوع نظام الملفات

BLKID_SUBLKS_SECTYPE

•SEC_TYPE - نوع نظام الملفات الثانوي

BLKID_SUBLKS_LABEL

•LABEL - تسمية نظام الملفات

BLKID_SUBLKS_LABELRAW

•LABEL_RAW - التسمية الخام من رأس نظام الملفات

BLKID_SUBLKS_UUID

•UUID - معرف فريد لنظام الملفات (حروف صغيرة)
•UUID_SUB - معرف فريد لعضو المجموعة أو معرف عنصر الجهاز، إلخ (مثل zfs، btrfs، ...)
•LOGUUID - معرف سجل خارجي (مثل xfs)

BLKID_SUBLKS_UUIDRAW

•UUID_RAW - المعرف الفريد الخام من رأس نظام الملفات

BLKID_SUBLKS_USAGE

•USAGE - سلسلة الاستخدام: "raid"، "filesystem"، إلخ.

BLKID_SUBLKS_VERSION

•VERSION - إصدار نظام الملفات

BLKID_SUBLKS_MAGIC

•SBMAGIC - سلسلة السحر لرأس الكتلة
•SBMAGIC_OFFSET - إزاحة SBMAGIC

BLKID_SUBLKS_FSINFO

•FSSIZE - حجم نظام الملفات. لاحظ أنه بالنسبة لـ XFS سيعيد نفس القيمة التي تعيدها lsblk (بدون بيانات XFS الوصفية)، ولكن بالنسبة لـ ext4 سيعيد الحجم مع بيانات التعريف الوصفية وبالنسبة لـ BTRFS لن يحسب العبء الزائد لتكوين RAID (بيانات مكررة).
•FSLASTBLOCK - آخر كتلة لنظام الملفات/إجمالي عدد كتل نظام الملفات
•FSBLOCKSIZE - حجم كتلة نظام الملفات

العلامات التالية ممكّنة دائمًا

•BLOCK_SIZE - الحد الأدنى لحجم الكتلة الذي يمكن الوصول إليه بواسطة نظام الملفات
•MOUNT - اسم تجميع التثبيت (ocfs فقط)
•EXT_JOURNAL - معرف سجل خارجي
•SYSTEM_ID - معرف نظام ISO9660
•VOLUME_SET_ID - معرف مجموعة وحدات تخزين ISO9660
•DATA_PREPARER_ID - معرف بيانات ISO9660
•PUBLISHER_ID - معرف الناشر ISO9660
•APPLICATION_ID - معرف التطبيق ISO9660
•BOOT_SYSTEM_ID - معرف نظام الإقلاع ISO9660

libblkid

retrieve block device attributes - library for block device identification

NAME

libblkid - retrieve block device attributes - library for block device identification

SYNOPSIS

#include <blkid.h>
...

DESCRIPTION

The libblkid library provides functions for identifying and retrieving attributes of block devices. It can be used to get information such as the filesystem type, label, UUID, and other metadata associated with a block device.

FUNCTIONS

The library provides a set of functions, including:

  • blkid_get_all(): Get all attributes for a block device.
  • blkid_get_tag(): Get a specific tag (attribute) from a block device.
  • blkid_probe_devices(): Probe block devices for attributes.
  • blkid_free_probe(): Free the resources associated with a probe.
  • And others...

CONFIGURATION FILE

The library may use configuration files to determine how to interpret certain device attributes or to define custom probing logic. The exact location and format of these files can vary depending on the system configuration.

TAGS

Libblkid uses the concept of "tags" to represent attributes of block devices. Common tags include:

  • UUID: Universally Unique Identifier of the filesystem.
  • LABEL: Human-readable label of the filesystem.
  • TYPE: Filesystem type (e.g., ext4, xfs, vfat).
  • PARTLABEL: Partition label.
  • PARTUUID: Partition UUID.
  • And others...
