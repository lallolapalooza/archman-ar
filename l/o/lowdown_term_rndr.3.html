lowdown_term_rndr(3)

الحزمة: lowdown

التراخيص: ISC

LOWDOWN_TERM_RNDR(3) دليل وظائف المكتبة LOWDOWN_TERM_RNDR(3)

الاسم

lowdown_term_rndr — عرض Markdown في مخرجات الطرفية

المكتبة

المكتبة "liblowdown"

ملخص

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_term_rndr(struct lowdown_buf *out, void *arg, const struct lowdown_node *n);

الوصف

يقوم بعرض شجرة عقد n التي تم إنشاؤها بواسطة lowdown_doc_parse(3) أو lowdown_diff(3) باستخدام عارض الطرفية arg كما تم إرجاعه بواسطة lowdown_term_new(3). تتم كتابة المخرجات في out، والتي يجب تهيئتها وتحريرها بواسطة المستدعي.

تتكون المخرجات من أحرف مرمزة بـ UTF-8 وتسلسلات هروب ANSI (في الواقع ISO/IEC 6429).

يتوقع من المستدعي أن يكون قد استدعى setlocale(3) إلى ترميز أحرف "UTF-8" قبل استخدام هذه الوظيفة، وإلا فلن يتم التعرف على تسلسلات UTF-8 بشكل صحيح.

قيم الإرجاع

يعيد صفر عند فشل تخصيص الذاكرة، وقيمة غير صفرية عند النجاح.

أمثلة

يقوم ما يلي بتحليل bi بطول bsz ويخرج بتنسيق طرفية ANSI.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if (setlocale(LC_CTYPE, "en_US.UTF-8") == NULL)
	err(1, NULL);

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_term_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_term_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_term_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

انظر أيضًا

lowdown(3), lowdown_term_free(3), lowdown_term_new(3)

المعايير

تم وصف رموز هروب ANSI في ISO/IEC 6429، سابقًا ECMA-48.
