NAME

Locale::RecodeData::CP10007 - Cyrillic (CP10007) character data

SYNOPSIS

    use Locale::RecodeData qw( :cp10007 );
    # ...

DESCRIPTION

This module provides the character data for the CP10007 character set (also known as KOI8-R). It is used by the Locale::Recode family of modules.

The character data is organized as a hash where the keys are the original character codes and the values are the Unicode equivalents.

The module defines the following constants, which are the hash tables:

  • $CP10007_TO_UNI: Converts CP10007 to Unicode.
  • $UNI_TO_CP10007: Converts Unicode to CP10007.

COMMENTS

The CP10007 character set is a superset of the KOI8-R character set. Some characters in CP10007 may not be present in KOI8-R.
