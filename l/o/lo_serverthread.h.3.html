القيمة المعادة

مثيل جديد لـ lo_server_thread.

lo_server_thread lo_server_thread_new_from_url (const char * url, lo_err_handler err_h)

إنشاء خيط خادم جديد، يأخذ المنفذ وعنوان IP لمجموعة البث المتعدد الاختياري من سلسلة URL.

المعلمات

url عنوان URL لتحديد معلمات الخادم.
err_h دالة رد اتصال خطأ سيتم استدعاؤها في حالة حدوث خطأ في استقبال الرسالة أو إنشاء الخادم. قم بتمرير NULL إذا كنت لا تريد معالجة الأخطاء.

القيمة المعادة

مثيل جديد لـ lo_server_thread.

lo_server_thread lo_server_thread_new_multicast (const char * group, const char * port, lo_err_handler err_h)

إنشاء خيط خادم جديد لمعالجة رسائل OSC الواردة، والانضمام إلى مجموعة بث متعدد UDP. تتولى خيوط الخادم استقبال الرسائل وإرسالها عن طريق إنشاء خيط نظام بشكل شفاف لمعالجة الرسائل الواردة. استخدم هذا إذا كنت لا تريد التعامل مع الخيوط بنفسك.

المعلمات

group مجموعة البث المتعدد للانضمام إليها. انظر التوثيق حول بث متعدد IP للنطاقات المقبولة للعناوين؛ على سبيل المثال، http://tldp.org/HOWTO/Multicast-HOWTO-2.html
port إذا تم تمرير NULL، فسيختار النظام منفذًا غير مستخدم، ويمكن استرداد رقمه باستخدام lo_server_thread_get_port() بحيث يمكن تمريره إلى العملاء. بخلاف ذلك، يمكن تمرير رقم منفذ عشري أو اسم خدمة أو مسار مقبس نطاق UNIX.
err_h دالة سيتم استدعاؤها في حالة حدوث خطأ. يتم تعريف نموذج الدالة في lo_types.h

lo_server_thread lo_server_thread_new_multicast_iface (const char * group, const char * port, const char * iface, const char * ip, lo_err_handler err_h)

إنشاء مثيل خيط خادم جديد، والانضمام إلى مجموعة بث متعدد UDP، وتحديد الواجهة الشبكية المراد استخدامها اختياريًا. لاحظ أنه عادةً ما يتم تحديد إما iface أو ip فقط.

المعلمات

group مجموعة البث المتعدد للانضمام إليها. انظر التوثيق حول بث متعدد IP للنطاقات المقبولة للعناوين؛ على سبيل المثال، http://tldp.org/HOWTO/Multicast-HOWTO-2.html
port إذا كنت تستخدم UDP، فيمكن تمرير NULL للعثور على منفذ غير مستخدم. بخلاف ذلك، يمكن تمرير رقم منفذ عشري أو اسم خدمة. إذا كنت تستخدم مقابس نطاق UNIX، فيجب تمرير مسار المقبس هنا.
iface سلسلة تحدد اسم واجهة شبكة للاستخدام، أو صفر إذا لم يتم تحديدها.
ip سلسلة تحدد عنوان IP لواجهة شبكة للاستخدام، أو صفر إذا لم يتم تحديدها.
err_h دالة رد اتصال خطأ سيتم استدعاؤها في حالة حدوث خطأ في استقبال الرسالة أو إنشاء الخادم. قم بتمرير NULL إذا كنت لا تريد معالجة الأخطاء.

lo_server_thread lo_server_thread_new_with_proto (const char * port, int proto, lo_err_handler err_h)

إنشاء خيط خادم جديد لمعالجة رسائل OSC الواردة، وتحديد البروتوكول. تتولى خيوط الخادم استقبال الرسائل وإرسالها عن طريق إنشاء خيط نظام بشكل شفاف لمعالجة الرسائل الواردة. استخدم هذا إذا كنت لا تريد التعامل مع الخيوط بنفسك.

المعلمات

port إذا تم تمرير NULL، فسيختار النظام منفذًا غير مستخدم، ويمكن استرداد رقمه باستخدام lo_server_thread_get_port() بحيث يمكن تمريره إلى العملاء. بخلاف ذلك، يمكن تمرير رقم منفذ عشري أو اسم خدمة أو مسار مقبس نطاق UNIX.
proto البروتوكول المراد استخدامه، يجب أن يكون أحد LO_UDP أو LO_TCP أو LO_UNIX.
err_h دالة سيتم استدعاؤها في حالة حدوث خطأ. يتم تعريف نموذج الدالة في lo_types.h

void lo_server_thread_pp (lo_server_thread st)

طباعة جميلة لكائن lo_server_thread.

void lo_server_thread_set_callbacks (lo_server_thread st, lo_server_thread_init_callback init, lo_server_thread_cleanup_callback cleanup, void * user_data)

تعيين دالة تهيئة و/أو دالة تنظيف لخيط الخادم المحدد. لكي يكون لها أي تأثير، يجب استدعاؤها قبل بدء تشغيل خيط الخادم.

المعلمات

st خيط الخادم الذي سيتم إضافة الطريقة إليه.
init دالة التهيئة التي سيتم استدعاؤها فور بدء تشغيل الخيط. يمكن أن تكون NULL.
cleanup دالة التنظيف التي سيتم استدعاؤها قبل خروج الخيط. يمكن أن تكون NULL.
user_data قيمة سيتم تمريرها إلى دوال رد الاتصال.

int lo_server_thread_start (lo_server_thread st)

بدء تشغيل خيط الخادم.

المعلمات

st خيط الخادم المراد بدء تشغيله.

القيمة المعادة

أقل من 0 عند الفشل، 0 عند النجاح.

المعلمات

st خيط الخادم المراد بدء تشغيله.

القيمة المعادة

أقل من 0 عند الفشل، 0 عند النجاح.
