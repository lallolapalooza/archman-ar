الاسم

Locale::RecodeData::MACTURKISH - إجراءات التحويل لـ MACTURKISH

الملخص

هذه الوحدة داخلية لـ libintl. لا تستخدمها مباشرة!

الوصف

تم إنشاء هذه الوحدة وتحتوي على جداول وروتينات التحويل لـ MACTURKISH.

NAME

Locale::RecodeData::MACTURKISH - MacTurkish encoding

\n
\n
\n

SYNOPSIS

\n
    use Locale::RecodeData::MACTURKISH;\n\n    # As a Perl module\n    Locale::RecodeData::MACTURKISH->new();\n\n    # As a Locale::Recode backend\n    # locale_recode -e MACTURKISH -f UTF8\n    # locale_recode -e MACTURKISH -f LATIN1\n

\n
\n

DESCRIPTION

\n

This module provides the MacTurkish encoding, which is a variant of\n the Turkish TIS-620 encoding, and is used by Apple Macintosh computers\n for the Turkish language.

\n
\n
\n

COMMENTS

\n

This encoding is obsolete and deprecated. It should not be used for new\n applications. It is only provided for backward compatibility.
