lowdown_nroff_rndr(3)

الحزمة: lowdown

التراخيص: ISC

LOWDOWN_NROFF_RNDR(3) دليل وظائف المكتبة LOWDOWN_NROFF_RNDR(3)

الاسم

lowdown_nroff_rndr — تصيير Markdown إلى roff

المكتبة

المكتبة «liblowdown»

الملخص

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_nroff_rndr(struct lowdown_buf *out, void *arg, const struct lowdown_node *n);

الوصف

يقوم بتصيير شجرة العقد n التي تم إنشاؤها بواسطة lowdown_doc_parse(3) أو lowdown_diff(3) باستخدام مصيّر roff arg كما تم إرجاعه بواسطة lowdown_nroff_new(3). تتم كتابة المخرجات في out، والتي يجب تهيئتها وتحريرها بواسطة المستدعي.

تتكون المخرجات من مخرجات roff باستخدام حزم الماكرو ms أو man.

قيم الإرجاع

يعيد صفرًا في حالة فشل تخصيص الذاكرة، وغير صفر في حالة النجاح.

أمثلة

يقوم ما يلي بتحليل b بطول bsz وإخراجها بتنسيق groff_ms(7).

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_nroff_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_nroff_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_nroff_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

راجع أيضًا

lowdown(3), lowdown_nroff_free(3), lowdown_nroff_new(3)

يستخدم هذا كل من ماكرو troff الأصلي man لـ الإصدار 7 AT&T UNIX، المحدد في man(7)، وامتدادات groff man-ext. كلاهما يتم تنفيذهما في mandoc.

تم تعريف ماكرو troff ms في groff_ms(7)، مع امتدادات groff mspdf الموصوفة في "Portable Document Format Publishing with GNU Troff" بواسطة Keith Marshall. لا يتم تنفيذ أي منهما في mandoc.
