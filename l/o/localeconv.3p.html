NAME

localeconv — get localeconv numeric formatting information

SYNOPSIS

#include <locale.h>

struct lconv *localeconv(void);

DESCRIPTION

The localeconv() function retrieves implementation-defined information concerning the current locale's numeric formatting conventions. This information is stored in a structure of type struct lconv. The members of this structure are described below.

The structure struct lconv contains the following members:

char *decimal_point
The string used as the decimal point for non-monetary quantities.
char *thousands_sep
The string used as a thousands separator for non-monetary quantities.
char *grouping
A string whose contents describe the grouping of digits to the left of the decimal point for non-monetary quantities. The first element of the string specifies the number of digits in the group immediately to the left of the decimal point. The second element specifies the number of digits in the next group to the left. The third element specifies the number of digits in the next group, and so on. If the second element is equal to CHAR_MAX, then the remaining groups have the same size as the first group. If the second element is equal to 0, then the grouping is not repeated. If the string is empty, then no grouping is performed.
char *int_curr_symbol
The international currency symbol, as defined by ISO 4217.
char *currency_symbol
The local currency symbol.
char *mon_decimal_point
The string used as the decimal point for monetary quantities.
char *mon_thousands_sep
The string used as a thousands separator for monetary quantities.
char *mon_grouping
A string whose contents describe the grouping of digits for monetary quantities. The format is the same as for the grouping member.
char *positive_sign
The string used to indicate a positive sign for monetary quantities.
char *negative_sign
The string used to indicate a negative sign for monetary quantities.
char *int_frac_digits
The number of digits used to represent the fractional part of the international currency symbol. INT_MAX is used if the number of digits is not specified.
char *frac_digits
The number of digits used to represent the fractional part of the local currency symbol.
char *p_cs_precedes
Whether the currency symbol precedes the value for positive quantities. '1' if it precedes, '0' if it follows.
char *p_sep_by_space
Whether a space separates the currency symbol from the value for positive quantities. '1' if there is a space, '0' if there is not.
char *n_cs_precedes
Whether the currency symbol precedes the value for negative quantities. '1' if it precedes, '0' if it follows.
char *n_sep_by_space
Whether a space separates the currency symbol from the value for negative quantities. '1' if there is a space, '0' if there is not.
char *p_sign_posn
The positioning of the positive sign for monetary quantities. Values are: 0: Parentheses surround the quantity. 1: A space precedes the quantity. 2: A space follows the quantity. 3: A space precedes the currency symbol. 4: A space follows the currency symbol. INT_MAX if the sign position is not specified.
char *n_sign_posn
The positioning of the negative sign for monetary quantities. Values are: 0: Parentheses surround the quantity. 1: A space precedes the quantity. 2: A space follows the quantity. 3: A space precedes the currency symbol. 4: A space follows the currency symbol. INT_MAX if the sign position is not specified.

All members of the struct lconv are pointers to character strings. The strings pointed to by the grouping and mon_grouping members may be modified by the calling program. All other string pointers point to strings that should not be modified by the calling program.

The localeconv() function returns a pointer to a statically allocated structure of type struct lconv, which may be overwritten by a subsequent call to localeconv() or by calls to setlocale() that modify the LC_NUMERIC category.

RETURN VALUE

The localeconv() function returns a pointer to the structure describing the current locale's numeric formatting conventions.

ERRORS

No errors are defined.

EXAMPLES

None.

APPLICATION USAGE

The members of the struct lconv are implementation-defined. Applications should not rely on specific values for these members, but rather on the symbolic constants defined in <locale.h>, such as CHAR_MAX and INT_MAX.

The pointers returned by localeconv() point to static storage that may be overwritten by subsequent calls to localeconv() or setlocale(). If the application needs to preserve the values, it must copy the contents of the structure.

The strings for grouping and mon_grouping are treated specially. They are the only members whose contents may be modified by the calling program. It is implementation-defined whether these strings are static or dynamically allocated. To avoid potential issues, applications should copy these strings if they need to be preserved across calls to localeconv() or setlocale().
