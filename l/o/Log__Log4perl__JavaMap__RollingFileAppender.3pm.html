Log__Log4perl__JavaMap__RollingFileAppender(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

JavaMap::RollingFileAppender(3) وثائق Perl المساهمة من المستخدم JavaMap::RollingFileAppender(3)

الاسم

Log::Log4perl::JavaMap::RollingFileAppender - يغلف Log::Dispatch::FileRotate

ملخص

الوصف

هذا يربط Log4j's RollingFileAppender بـ Log::Dispatch::FileRotate بواسطة Mark Pfeiffer، <markpf@mlp-consulting.com.au>.

الخصائص الممكنة للإعداد لـ log4j ConsoleAppender هي:

File
Append      "true|false|1|0" افتراضي=true
BufferedIO  "true|false|1|0" افتراضي=false (أي أن autoflush مفعل)
MaxFileSize افتراضي 10_000_000
MaxBackupIndex افتراضي هو 1

الخصائص الممكنة للإعداد لـ Log::Dispatch::FileRotate هي:

filename
mode  "write|append"
autoflush 0|1
size
max
