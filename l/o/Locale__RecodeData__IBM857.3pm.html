NAME

Locale::RecodeData::IBM857 - character set constants for IBM Code Page 857 (Turkish)

SYNOPSIS

use Locale::RecodeData::IBM857;

DESCRIPTION

This module defines constants for the character set IBM Code Page 857 (Turkish).

See also the other Locale::RecodeData(3) modules.
