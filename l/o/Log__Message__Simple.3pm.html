الاسم

Log::Message::Simple - واجهة مبسطة لـ Log::Message

الملخص

use Log::Message::Simple qw[msg error debug
                            carp croak cluck confess];
use Log::Message::Simple qw[:STD :CARP];
### standard reporting functionality
msg(    "Connecting to database",           $verbose );
error(  "Database connection failed: $@",   $verbose );
debug(  "Connection arguments were: $args", $debug );
### standard carp functionality
carp(   "Wrong arguments passed: @_" );
croak(  "Fatal: wrong arguments passed: @_" );
cluck(  "Wrong arguments passed -- including stacktrace: @_" );
confess("Fatal: wrong arguments passed -- including stacktrace: @_" );
### retrieve individual message
my @stack = Log::Message::Simple->stack;
my @stack = Log::Message::Simple->flush;
### retrieve the entire stack in printable form
my $msgs  = Log::Message::Simple->stack_as_string;
my $trace = Log::Message::Simple->stack_as_string(1);
### redirect output
local $Log::Message::Simple::MSG_FH     = \*STDERR;
local $Log::Message::Simple::ERROR_FH   = \*STDERR;
local $Log::Message::Simple::DEBUG_FH   = \*STDERR;
### force a stacktrace on error
local $Log::Message::Simple::STACKTRACE_ON_ERROR = 1

الوصف

توفر هذه الوحدة تسهيلات تسجيل موحدة باستخدام وحدة "Log::Message".

الوظائف

msg("سلسلة_الرسالة" [,VERBOSE])

تسجل رسالة في المكدس، وتطبعها إلى "STDOUT" (أو فعليًا $MSG_FH، انظر قسم "المتغيرات العامة" أدناه)، إذا كان خيار "VERBOSE" صحيحًا. الخيار "VERBOSE" قيمته الافتراضية خاطئة.

يتم تصديرها افتراضيًا، أو باستخدام الوسم ":STD".

debug("سلسلة_الرسالة" [,VERBOSE])

تسجل رسالة تصحيح أخطاء في المكدس، وتطبعها إلى "STDOUT" (أو فعليًا $DEBUG_FH، انظر قسم "المتغيرات العامة" أدناه)، إذا كان خيار "VERBOSE" صحيحًا. الخيار "VERBOSE" قيمته الافتراضية خاطئة.

يتم تصديرها افتراضيًا، أو باستخدام الوسم ":STD".

error("سلسلة_الخطأ" [,VERBOSE])

تسجل خطأ في المكدس، وتطبعه إلى "STDERR" (أو فعليًا $ERROR_FH، انظر أقسام "المتغيرات العامة" أدناه)، إذا كان خيار "VERBOSE" صحيحًا. الخيار "VERBOSE" قيمته الافتراضية صحيحة.

يتم تصديرها افتراضيًا، أو باستخدام الوسم ":STD".

carp();

توفر وظائف مساوية لـ Carp::carp() مع الاستمرار في التسجيل في المكدس.

يتم تصديرها باستخدام الوسم ":CARP".

croak();

توفر وظائف مساوية لـ Carp::croak() مع الاستمرار في التسجيل في المكدس.

يتم تصديرها باستخدام الوسم ":CARP".

confess();

توفر وظائف مساوية لـ Carp::confess() مع الاستمرار في التسجيل في المكدس.

يتم تصديرها باستخدام الوسم ":CARP".

cluck();

توفر وظائف مساوية لـ Carp::cluck() مع الاستمرار في التسجيل في المكدس.

يتم تصديرها باستخدام الوسم ":CARP".

طرق الفئة

Log::Message::Simple->stack()

يسترجع جميع العناصر في المكدس. نظرًا لأن "Log::Message::Simple" يتم تنفيذه باستخدام "Log::Message"، استشر صفحة الرجل الخاصة به للوظيفة "retrieve" لمعرفة ما يتم إرجاعه وكيفية استخدام العناصر.

Log::Message::Simple->stack_as_string([TRACE])

تُرجع المكدس بأكمله كسلسلة نصية قابلة للطباعة. إذا كان خيار "TRACE" صحيحًا، فسيتم إرجاع جميع العناصر باستخدام إخراج "Carp::longmess"، بدلاً من الرسالة فقط. قيمة "TRACE" الافتراضية خاطئة.

Log::Message::Simple->flush()

يزيل جميع العناصر من المكدس ويعيدها. نظرًا لأن "Log::Message::Simple" يتم تنفيذه باستخدام "Log::Message"، استشر صفحة الرجل الخاصة به للوظيفة "retrieve" لمعرفة ما يتم إرجاعه وكيفية استخدام العناصر.

المتغيرات العامة

$ERROR_FH
هذا هو مقبض الملف الذي تتم طباعة جميع الرسائل المرسلة إلى error() عليه. قيمته الافتراضية هي *STDERR.
$MSG_FH
هذا هو مقبض الملف الذي تتم طباعة جميع الرسائل المرسلة إلى msg() عليه. قيمته الافتراضية هي *STDOUT.
$DEBUG_FH
هذا هو مقبض الملف الذي تتم طباعة جميع الرسائل المرسلة إلى debug() عليه. قيمته الافتراضية هي *STDOUT.
$STACKTRACE_ON_ERROR
إذا تم تعيين هذا الخيار على "true"، فإن كل استدعاء لـ error() سيقوم بإنشاء تتبع للمكدس باستخدام Carp::shortmess(). القيمة الافتراضية هي "false".

Log::Message::Simple(3pm)

Log::Message::Simple - A simple implementation of Log::Message

NAME

Log::Message::Simple - A simple implementation of Log::Message

DESCRIPTION

This module is a basic implementation of the Log::Message API. It provides a straightforward way to log messages without the complexity of other logging modules.

SYNOPSIS

use Log::Message::Simple;

my $log = Log::Message::Simple->new( 'MyApp' );
$log->info( 'This is an informational message.' );
$log->warn( 'This is a warning message.' );
$log->error( 'This is an error message.' );

CONSTRUCTOR

new( appname )

Creates a new Log::Message::Simple object. The appname parameter is a string that will be prepended to all log messages.

METHODS

info( message )

Logs an informational message.

warn( message )

Logs a warning message.

error( message )

Logs an error message.

debug( message )

Logs a debug message.

EXAMPLE

A simple example demonstrating the usage of Log::Message::Simple:

use Log::Message::Simple;

my $log = Log::Message::Simple->new( 'MyScript' );

$log->info( 'Starting script execution.' );
# Output: MyApp [INFO]: Starting script execution.

# Simulate an operation
my $result = perform_operation();

if ( $result ) {
    $log->info( 'Operation successful.' );
    # Output: MyApp [INFO]: Operation successful.
} else {
    $log->error( 'Operation failed!' );
    # Output: MyApp [ERROR]: Operation failed!
}

$log->warn( 'Script is about to finish.' );
# Output: MyApp [WARN]: Script is about to finish.

exit 0;

sub perform_operation {
    # Dummy operation
    return int(rand(2));
}
