NAME

Locale::RecodeData::EBCDIC_PT - EBCDIC (Portugal) encoding definition

SYNOPSIS

use Locale::RecodeData::EBCDIC_PT;

DESCRIPTION

This module provides the definition for the EBCDIC encoding used in Portugal. It is used by the recode utility and the Locale::Recode module.

No further documentation is available for this module.
