Log__Log4perl__Appender__Socket(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Appender::Socket(3) وثائق Perl المساهمة من المستخدم Appender::Socket(3)

الاسم

Log::Log4perl::Appender::Socket - تسجيل الأحداث في مقبس

الملخص

use Log::Log4perl::Appender::Socket;
my $appender = Log::Log4perl::Appender::Socket->new(
  PeerAddr => "server.foo.com",
  PeerPort => 1234,
);
$appender->log(message => "Log me\n");

الوصف

هذا هو مُلحق بسيط للكتابة في مقبس. يعتمد على IO::Socket::INET ويقدم جميع المعلمات التي يقدمها هذا المودول.

عند تدمير الكائن، سيتم إفراغ الرسائل المعلقة وإغلاق المقبس.

إذا لم يتمكن الملحق من الاتصال بالخادم أثناء مرحلة التهيئة (أثناء تشغيل الدالة البانية "new")، فسوف يموت (die()).

إذا فشل الملحق في تسجيل رسالة لأن طريقة send() الخاصة بالمقبس فشلت (على الأرجح لأن الخادم تعطل)، فسيحاول إعادة الاتصال مرة واحدة. إذا نجح، فسيتم إرسال الرسالة. إذا فشلت إعادة الاتصال، يتم إرسال تحذير إلى STDERR، وتعيد طريقة log() وتتجاهل الرسالة.

إذا تم تقديم الخيار "silent_recovery" إلى الدالة البانية وتم تعيينه على قيمة حقيقية، فإن السلوك مختلف: إذا لم يكن بالإمكان إنشاء اتصال المقبس وقت التهيئة، يتم إصدار تحذير واحد. ستحاول كل محاولة تسجيل بعد ذلك إنشاء الاتصال وتجاهل الرسالة بصمت إذا فشلت. إذا لم تكن تريد حتى التحذير، فقم بتعيين الخيار "no_warning" على قيمة حقيقية.

قد لا يكون الاتصال وقت التهيئة خيارًا جيدًا عند التشغيل تحت Apache1 Apache2/prefork، لأن العملية الأصلية تنشئ المقبس وتتم مشاركة الاتصالات بين الأطفال المتفرعين - يمكن لجميع الأطفال الذين يكتبون إلى نفس المقبس أن يخلطوا الرسائل. لذلك، بدلاً من ذلك، يمكنك استخدام "defer_connection" والذي سيؤجل إنشاء الاتصال حتى يتم إرسال رسالة السجل الأولى.

مثال

اكتب خادمًا بسرعة باستخدام المودول IO::Socket::INET:

use IO::Socket::INET;
my $sock = IO::Socket::INET->new(
    Listen    => 5,
    LocalAddr => 'localhost',
    LocalPort => 12345,
    Proto     => 'tcp');
while(my $client = $sock->accept()) {
    print "Client connected\n";
    while(<$client>) {
        print "$_\n";
    }
}

قم بتشغيله ثم قم بتشغيل البرنامج النصي التالي كعميل:

use Log::Log4perl qw(:easy);
my $conf = q{
    log4perl.category                  = WARN, Socket
    log4perl.appender.Socket           = Log::Log4perl::Appender::Socket
    log4perl.appender.Socket.PeerAddr  = localhost
    log4perl.appender.Socket.PeerPort  = 12345
    log4perl.appender.Socket.layout    = SimpleLayout
};
Log::Log4perl->init(\$conf);
sleep(2);
for(1..10) {
    ERROR("Quack!");
    sleep(5);
}
