LOCALTIME(3P) الدليل البرمجي لـ POSIX LOCALTIME(3P)

مقدمة

هذه الصفحة الدليلية هي جزء من الدليل البرمجي لـ POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة الدليل المقابلة لـ Linux لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

localtime, localtime_r — تحويل قيمة زمن إلى وقت محلي مفصل

الملخص

#include <time.h>
struct tm *localtime(const time_t *timer);
struct tm *localtime_r(const time_t *restrict timer,
    struct tm *restrict result);

الوصف

بالنسبة لـ localtime(): تتماشى الوظائف الموصوفة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموصوفة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1‐2017 يحيل إلى معيار ISO C.

تقوم الدالة localtime() بتحويل الوقت بالثواني منذ الحقبة التي يشير إليها timer إلى وقت مفصل، معبراً عنه كوقت محلي. تقوم الدالة بالتصحيح للمنطقة الزمنية وأي تعديلات زمنية موسمية. تُستخدم معلومات المنطقة الزمنية المحلية كما لو أن localtime() تستدعي tzset().

العلاقة بين الوقت بالثواني منذ الحقبة المستخدم كوسيط للدالة localtime() وهيكل tm (المعرف في ترويسة <time.h>) هي أن النتيجة يجب أن تكون كما هو محدد في التعبير المعطى في تعريف الثواني منذ الحقبة (انظر مجلد التعريفات الأساسية لـ POSIX.1‐2017، القسم 4.16، الثواني منذ الحقبة) المصحح للمنطقة الزمنية وأي تعديلات زمنية موسمية، حيث تتوافق الأسماء في الهيكل وفي التعبير.

تنطبق نفس العلاقة على localtime_r().

قد لا تكون الدالة localtime() آمنة للخيوط.

تقوم الدوال asctime() و ctime() و gmtime() و localtime() بإرجاع قيم في أحد كائنين ثابتين: هيكل وقت مفصل ومصفوفة من نوع char. قد يؤدي تنفيذ أي من الدوال إلى الكتابة فوق المعلومات المعادة في أي من هذين الكائنين بواسطة أي من الدوال الأخرى.

تقوم الدالة localtime_r() بتحويل الوقت بالثواني منذ الحقبة التي يشير إليها timer إلى وقت مفصل مخزن في الهيكل الذي يشير إليه result. تقوم الدالة localtime_r() أيضاً بإرجاع مؤشر إلى نفس الهيكل.

على عكس localtime()، لا يُشترط على الدالة localtime_r() تعيين tzname. إذا قامت localtime_r() بتعيين tzname، فيجب عليها أيضاً تعيين daylight و timezone. إذا لم تقم localtime_r() بتعيين tzname، فلا يجب عليها تعيين daylight ولا يجب عليها تعيين timezone.

قيمة الإرجاع

عند الانتهاء بنجاح، تُرجع الدالة localtime() مؤشراً إلى هيكل الوقت المفصل. إذا تم اكتشاف خطأ، تُرجع localtime() مؤشراً فارغاً وتُعيّن errno للإشارة إلى الخطأ.

عند الانتهاء بنجاح، تُرجع localtime_r() مؤشراً إلى الهيكل الذي يشير إليه الوسيط result. إذا تم اكتشاف خطأ، تُرجع localtime_r() مؤشراً فارغاً وتُعيّن errno للإشارة إلى الخطأ.

الأخطاء

تفشل الدوال localtime() و localtime_r() في الحالات التالية:

EOVERFLOW
لا يمكن تمثيل النتيجة.

الأقسام التالية إعلامية.

أمثلة

الحصول على التاريخ والوقت المحليين

يستخدم المثال التالي الدالة time() لحساب الوقت المنقضي، بالثواني، منذ 1 يناير 1970، 0:00 بالتوقيت العالمي المنسق (الحقبة)، localtime() لتحويل هذه القيمة إلى وقت مفصل، و asctime() لتحويل قيم الوقت المفصل إلى سلسلة نصية قابلة للطباعة.

#include <stdio.h>
#include <time.h>
int main(void)
{
    time_t result;
    result = time(NULL);
    printf("%s%ju secs since the Epoch\n",
        asctime(localtime(&result)),
            (uintmax_t)result);
    return(0);
}

يكتب هذا المثال الوقت الحالي إلى stdout بالشكل التالي:

Wed Jun 26 10:32:15 1996
835810335 secs since the Epoch

الحصول على وقت التعديل لملف

يطبع المثال التالي طابع وقت آخر تعديل للبيانات في المنطقة الزمنية المحلية لملف معين.

#include <stdio.h>
#include <time.h>
#include <sys/stat.h>
int
print_file_time(const char *pathname)
{
    struct stat statbuf;
    struct tm *tm;
    char timestr[BUFSIZ];
    if(stat(pathname, &statbuf) == -1)
        return -1;
    if((tm = localtime(&statbuf.st_mtime)) == NULL)
        return -1;
    if(strftime(timestr, sizeof(timestr), "%Y-%m-%d %H:%M:%S", tm) == 0)
        return -1;
    printf("%s: %s.%09ld\n", pathname, timestr, statbuf.st_mtim.tv_nsec);
    return 0;
}

توقيت حدث

يحصل المثال التالي على الوقت الحالي، ويحوله إلى سلسلة نصية باستخدام localtime() و asctime()، ويطبعه إلى المخرج القياسي باستخدام fputs(). ثم يطبع عدد الدقائق المتبقية لحدث يتم توقيته.

#include <time.h>
#include <stdio.h>
...

int minutes_to_event;
...

printf("The time is ");
fputs(asctime(localtime(&now)), stdout);
printf("There are still %d minutes to the event.\n",
    minutes_to_event);
...

LOCALTIME(3) Library Functions Manual LOCALTIME(3)

NAME

localtime, localtime_r, localtime_rz, gmtime, gmtime_r, gmtime_rz - convert broken-down time into a time expressed as a local or Coordinated Universal Time (UTC) broken-down time

SYNOPSIS

#include <time.h>

struct tm *localtime(const time_t *timep);

struct tm *localtime_r(const time_t *timep, struct tm *result);

struct tm *localtime_rz(const time_t *timep, struct tm *result);

struct tm *gmtime(const time_t *timep);

struct tm *gmtime_r(const time_t *timep, struct tm *result);

struct tm *gmtime_rz(const time_t *timep, struct tm *result);

DESCRIPTION

The localtime() function converts the given time, expressed as seconds since the Epoch (1970-01-01 00:00:00 UTC), in the argument `timep` into a broken-down time representation (`struct tm`) that is expressed as the local time according to the current time zone.

The gmtime() function does the same, but converts the time into a broken-down time representation that is expressed as Coordinated Universal Time (UTC).

The functions `localtime_r()`, `gmtime_r()`, `localtime_rz()`, and `gmtime_rz()` are reentrant versions of `localtime()` and `gmtime()`. They store the broken-down time representation in the `struct tm` buffer pointed to by `result`, and return a pointer to this buffer.

The `_rz` variants are similar to the `_r` variants, but they also store the time zone abbreviation in the `tm_zone` field of the `struct tm` structure. This field is a `char *` pointing to a string that is the time zone abbreviation (e.g. "EST", "EDT"). This field is not part of the POSIX standard. This feature is specific to glibc.

The `struct tm` structure is defined in <time.h> as follows:

              struct tm {
                  int tm_sec;   /* seconds after the minute, 0-60 */
                  int tm_min;   /* minutes after the hour, 0-59 */
                  int tm_hour;  /* hours since midnight, 0-23 */
                  int tm_mday;  /* day of the month, 1-31 */
                  int tm_mon;   /* months since January, 0-11 */
                  int tm_year;  /* years since 1900 */
                  int tm_wday;  /* days since Sunday, 0-6 */
                  int tm_yday;  /* days since January 1, 0-365 */
                  int tm_isdst; /* Daylight Saving Time flag */
                  char *tm_zone;/* abbreviation of timezone name (not standard) */
                  long tm_gmtoff;/* offset from UTC in seconds (not standard) */
              };

The value of `tm_isdst` is positive if DST is in effect, zero if it is not, and negative if the information is not available.

The `tm_zone` and `tm_gmtoff` fields are not part of the POSIX standard. They are GNU extensions. `tm_zone` is set by `localtime_rz` and `gmtime_rz`. `tm_gmtoff` is the offset from UTC in seconds. This is also set by `localtime_rz` and `gmtime_rz`.

The `localtime()` and `gmtime()` functions usually return a pointer to a statically allocated `struct tm` object. It is potentially shared between all calls to `localtime()` and `gmtime()` within a thread. It is also potentially shared between calls to `localtime()` and `gmtime()`. Therefore, the value returned by `localtime()` or `gmtime()` should be copied before calling `localtime()` or `gmtime()` again.

The `localtime_r()` and `gmtime_r()` functions store the result in the user-supplied buffer `result`. This makes them thread-safe.

The `localtime_rz()` and `gmtime_rz()` functions are similar to the `_r` versions, but they also fill in the `tm_zone` and `tm_gmtoff` fields.

RETURN VALUE

On success, `localtime()` and `gmtime()` return a pointer to the broken-down time structure. On error, they return NULL. (However, these functions are unlikely to fail.)

The reentrant functions `localtime_r()`, `gmtime_r()`, `localtime_rz()`, and `gmtime_rz()` return a pointer to the `result` structure on success. They do not return an error indication.

ERRORS

The `localtime()` and `gmtime()` functions may set `errno` to `EOVERFLOW` if the given time `timep` is out of the range representable by `struct tm`.

APPLICATION USAGE

The `localtime()` and `gmtime()` functions are not thread-safe, because they may return a pointer to a static buffer. Use `localtime_r()` and `gmtime_r()` instead in multithreaded applications.

RATIONALE

The POSIX standard defines `localtime()` and `gmtime()`. The `_r` variants are also widely available. The `_rz` variants are GNU extensions.
