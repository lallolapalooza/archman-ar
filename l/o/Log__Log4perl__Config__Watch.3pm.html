Log__Log4perl__Config__Watch(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Config::Watch(3) وثائق Perl المساهمة من المستخدم Config::Watch(3)

الاسم

Log::Log4perl::Config::Watch - اكتشاف تغييرات الملفات

الملخص

use Log::Log4perl::Config::Watch;
my $watcher = Log::Log4perl::Config::Watch->new(
                      file            => "/data/my.conf",
                      check_interval  => 30,
              );
while(1) {
    if($watcher->change_detected()) {
        print "Change detected!\n";
    }
    sleep(1);
}

الوصف

تساعد هذه الوحدة في اكتشاف التغييرات في الملفات. على الرغم من أنها تأتي مع توزيعة "Log::Log4perl"، إلا أنه يمكن استخدامها بشكل مستقل.

يقوم الباني بتحديد الملف المراد مراقبته وفاصل التحقق بالثواني. سيؤدي استدعاء change_detected() لاحقًا إلى:

  • إرجاع قيمة خاطئة على الفور دون إجراء فحوصات مادية للملف إذا لم ينتهِ "check_interval".
  • إجراء اختبار مادي للملف المحدد إذا انقضت عدد الثواني المحددة في "check_interval" منذ آخر فحص مادي. إذا تغير تاريخ تعديل الملف منذ آخر فحص مادي، فسوف يعيد قيمة صحيحة، وإلا فسيتم إرجاع قيمة خاطئة.

خلاصة القول: يسمح لك "check_interval" باستدعاء الدالة change_detected() كلما شئت، دون تكبد عقوبة أداء كبيرة بسبب إجراء عمليات نظام الملفات (ومع ذلك، فإنك تدفع ثمن عدم معرفة تغييرات الملفات حتى انقضاء "check_interval" ثانية).

التمييز بوضوح بين وقت النظام ووقت نظام الملفات. إذا كانت نظام الملفات الخاص بك (مثل نظام ملفات NFS) متأخرًا بمقدار ثابت مقارنة بساعة الكمبيوتر التنفيذي، فسيعمل بشكل جيد.

لتعطيل ميزة التأخير في توفير الموارد، قم ببساطة بتعيين "check_interval" إلى 0 وستقوم change_detected() بإجراء فحص مادي للملف في كل مرة يتم استدعائها.

إذا كان لديك بالفعل الوقت الحالي متاحًا، يمكنك تمريره إلى change_detected() كمعامل اختياري، كما في

change_detected($time)

والذي لن يؤدي بعد ذلك إلى استدعاء time()، بل سيستخدم القيمة المقدمة.

وضع الإشارة

بدلاً من استقصاء الوقت وتغييرات الملفات، يمكن توجيه new() لإعداد معالج إشارة. إذا قمت باستدعاء الباني على النحو التالي:

my $watcher = Log::Log4perl::Config::Watch->new(
                      file    => "/data/my.conf",
                      signal  => 'HUP'
              );

فسيتم تثبيت معالج إشارة، يقوم بتعيين متغير الكائن "$self->{signal_caught}" إلى قيمة صحيحة عند وصول الإشارة. يأتي مع جميع المشاكل التي تصاحب معالجات الإشارات.

تشغيل الفحوصات

لتشغيل فحص مادي للملف في المرة التالية التي يتم فيها استدعاء change_detected() بغض النظر عما إذا كان "check_interval" قد انتهت صلاحيته أم لا، قم باستدعاء:

$watcher->force_next_check();

على كائن المراقبة.

اكتشاف الملفات المنقولة

يمكن أيضًا استخدام المراقب لاكتشاف الملفات التي تم نقلها. لن يكتشف فقط إذا اختفى ملف مراقب، ولكنه سيكتشف أيضًا إذا تم استبداله بملف جديد في هذه الأثناء.

my $watcher = Log::Log4perl::Config::Watch->new(
    file           => "/data/my.conf",
    check_interval => 30,
);
while(1) {
    if($watcher->file_has_moved()) {
        print "File has moved!\n";
    }
    sleep(1);
}

تحد المعلمتان "check_interval" و "signal" عدد فحوصات نظام الملفات المادية، بنفس الطريقة كما هو الحال مع change_detected().
