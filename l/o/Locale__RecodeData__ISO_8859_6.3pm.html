الاسم

Locale::RecodeData::ISO_8859-6 - إجراءات تحويل لـ ISO-8859-6

الملخص

هذه الوحدة داخلية لـ libintl. لا تستخدمها مباشرة!

الوصف

هذه الوحدة مولدة وتحتوي على جداول التحويل والإجراءات لـ ISO-8859-6.

تعليقات

الملاحظات التالية مقتطفة من charmap الأصلي:

الإصدار: 1.0
 المصدر: سجل ECMA
 اسم مستعار ISO-IR-127
 اسم مستعار ISO_8859-6:1987
 اسم مستعار ISO_8859-6
 اسم مستعار ECMA-114
 اسم مستعار ASMO-708
 اسم مستعار ARABIC

ملاحظة: الأسماء المستعارة المذكورة أعلاه قد لا تكون صالحة بالضرورة!

جدول الأحرف

يتم ترتيب الجدول التالي بنفس ترتيب charmap الأصلي. جميع رموز الأحرف بالنظام السداسي عشري. يرجى قراءة 'ISO-10646' على أنها 'ISO-10646-UCS4'.

NAME

Locale::RecodeData::ISO_8859_6 - ISO-8859-6 to/from UTF-8.

SYNOPSIS

    use Locale::RecodeData 'ISO-8859-6';

DESCRIPTION

This module provides the necessary data for Locale::Recode to convert between ISO-8859-6 and UTF-8.

This module should never be used directly. It is used by Locale::Recode.

COMMENTS

This module is an encoding module for Locale::Recode.

The encoding ISO-8859-6 represents the Arabic alphabet. It is a 8-bit encoding.

The mapping to UTF-8 is defined in the associated Unicode::Map file.
