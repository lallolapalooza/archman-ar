-thtml, -tlatex, -tman, -tms, and -ttree.

ما يلي هو خيارات طويلة خاصة بالمخرجات. بالنسبة لـ HTML باستخدام -thtml، تكون كما يلي:

--html-callout-mdn, --html-callout-gfm
إخراج بناء جملة استدعاء MDN أو GFM أو كليهما.
--html-hardwrap
التفاف الفقرات بقوة عن طريق إخراج فواصل الأسطر عند الاقتضاء.
--html-no-escapehtml
إذا تم تحديد --html-no-skiphtml، فإن هذا يتسبب في عدم هروب HTML المضمن، وبدلاً من ذلك يتم إخراجه كما هو. ليس لهذا أي تأثير إذا لم يتم تحديد --html-no-skiphtml.
--html-no-head-ids
لا تقم بإخراج سمات id للعناوين.
--html-no-num-ent
لا تقم بتطبيع كيانات HTML (عند الإمكان) ككيانات رقمية وبدلاً من ذلك استخدم الكيانات كما تم إدخالها.
--html-no-owasp
لا تتبع توصيات OWASP لهروب النصوص، وقم فقط بالهروب الأدنى لضمان عدم تفسير المحتوى العادي كـ HTML.
--html-no-skiphtml
إخراج HTML المضمن. بشكل افتراضي، لا يتم إخراج HTML المضمن على الإطلاق. انظر --html-no-escapehtml.
--html-titleblock
إذا تم تحليل أي معلومات عنوان (العنوان، المؤلف، التاريخ)، فقم بتنسيقها كعنصر رأس يظهر أولاً في المستند.

لكلا تنسيقي roff -tman و -tms (ما لم يُذكر خلاف ذلك)، تنطبق ما يلي:

--roff-code-font=fonts
تجاوز الخطوط الافتراضية ذات العرض الثابت بمجموعة من الأشكال العادية، والعريضة، والمائلة، والمائلة والعريضة بترتيبها. على سبيل المثال، B,B,BI,BI تستخدم الخط العريض (“B”) بدلاً من عرض ثابت. عدم تحديد خط سيستخدم الافتراضي، وكذلك تحديد اسم خط طوله صفر. الأسماء المستعارة none، bold، و code لا تحدد خطوطًا خاصة، أو خطًا عريضًا، أو العرض الثابت الافتراضي.
--roff-endnotes
تأخير طباعة الحواشي السفلية حتى نهاية المستند. ينطبق فقط على -tms، حيث أن -tman يدعم فقط الحواشي الختامية.
--roff-no-numbered
لا تقم بإخراج العناوين المرقمة (.NH NN). ينطبق فقط على -tms.
--roff-no-skiphtml
إخراج HTML المضمن. هذا عادة لا معنى له لأن HTML لن يتم تفسيره بواسطة قارئ الإخراج. بشكل افتراضي، يتم حذف HTML.
--roff-no-links
لا تعرض عناوين URL للصور والروابط (لا تزال الروابط التلقائية تُعرض). (لا يزال محتوى الرابط يُعرض.) يتجاوز --roff-short-links للصور والروابط. ينطبق فقط عند تحديد --roff-traditional.
--roff-short-links
تقصير عناوين URL للصور والروابط والروابط التلقائية إلى اسم النطاق والمسار النهائي فقط. ينطبق فقط عند تحديد --roff-traditional.
--roff-traditional
لا تستخدم وحدات الماكرو للارتباطات التشعبية (.pdfhref، .UR، .MT)، والجداول متعددة الصفحات (.TS H، .TH)، وصيغة تسلسل Unicode (\[uNNNN])، ووحدات الماكرو لكتل الأمثلة (.EX)، وعناوين الأقسام الحديثة (.NH NN، .SH NN، .pdfhref O NN)، أو الروابط الداخلية للمستند (.pdfhref L). الإخراج متوافق مع troff(1) التقليدي.

البادئة الوسيطة --nroff، كما في --nroff-traditional، تم إهمالها لصالح --roff.

إخراج -tterm له ما يلي:

--term-all-metadata
إذا تم تحديد -s، فقم بإخراج جميع البيانات الوصفية بدلاً من العنوان والمؤلف والتاريخ فقط.
--term-columns=columns
عدد الأعمدة في الطرفية. مفيد عند التشغيل في خط أنابيب. الافتراضي هو ما تُبلغ عنه الطرفية أو 72 إذا لم تكن في طرفية.
--term-hmargin=margin
عدد أحرف الهامش الأيسر. الافتراضي هو صفر. يمكن أن يكون أيضًا auto لتعيين الهامش الأيسر إلى نصف --term-columns المتبقية بعد طرح --term-width.
--term-hpadding=padding
عدد أحرف الحشو الأيسر. الافتراضي هو أربعة. الحشو يستهلك من --term-width.
--term-no-ansi
لا تعرض أنماط ANSI على الإطلاق. هذا يعني ضمنيًا --term-no-colour.
--term-no-colour
لا تعرض ألوان ANSI. سيظل هذا يزين النص بخطوط تحتها، وخطوط عريضة، ومائلة، ولكن لا يصدر أي رموز ألوان.
--term-no-links
لا تعرض عناوين URL للصور والروابط (لا تزال الروابط التلقائية تُعرض). (لا يزال محتوى الرابط يُعرض.) يتجاوز --term-short-links و --term-no-rellinks.
--term-no-rellinks
لا تعرض عناوين URL للروابط النسبية. (لا يزال محتوى الرابط يُعرض.) يتجاوز --term-short-links.
--term-short-links
تقصير عناوين URL للصور والروابط والروابط التلقائية إلى اسم النطاق والمسار النهائي فقط.
--term-vmargin=margin
عدد فواصل الأسطر الجديدة في الهامش العلوي والسفلي. الافتراضي هو صفر.
--term-width=width
حد ناعم لعدد الأحرف في كل سطر بما في ذلك (--term-hpadding). قد يتم تجاوز هذا بالنص الحرفي. إذا كان صفرًا أو غير معين، فسيتم الافتراضي إلى --term-columns أو 80 كحد أقصى. سيتم اقتطاعه إلى --term-columns.

إخراج -tgemini له العديد من العلامات التي تتحكم في موضع الروابط. بشكل افتراضي، يتم وضع الروابط (الصور، الروابط التلقائية، والروابط) في قائمة انتظار عند تحديدها في سطر ثم إصدارها في تسلسل كتلة بعد أقرب عنصر كتلة.

--gemini-link-end
إخراج قائمة الروابط في نهاية المستند بدلاً من بعد أقرب عنصر كتلة.
--gemini-link-inline
عرض جميع الروابط ضمن تدفق النص. سيؤدي هذا إلى حدوث أخطاء عند تداخل الروابط، مثل الصور داخل الروابط، والروابط في اقتباسات الكتل، وما إلى ذلك. لا ينبغي استخدامه إلا في المستندات المصممة بعناية.
--gemini-link-noref
لا تقم بتنسيق تسميات الروابط. له الأسبقية على --gemini-link-roman.
--gemini-link-roman
عند تنسيق تسميات الروابط، استخدم الأرقام الرومانية الصغيرة بدلاً من النظام الستة عشري الافتراضي (أي “a”، “b”، ...، “aa”، “ab”، ...).
--gemini-metadata
طباعة البيانات الوصفية كمفتاح موحد متبوعًا بنقطتين فوق بعضهما ثم القيمة، كل منها في سطر واحد (يتم استبدال فواصل الأسطر بمسافات). تنتهي كتلة البيانات الوصفية بسطرين جديدين. إذا لم تكن هناك بيانات وصفية، فلن يحدث شيء.

--latex-no-numbered

--latex-no-skiphtml
إخراج HTML المضمن. هذا عادة لا معنى له لأن HTML لن يتم تفسيره بواسطة قارئ الإخراج. بشكل افتراضي، يتم حذف HTML.

الحزمة: lowdown

التراخيص: ISC

OPTIONS

--help
Print help message and exit.
--version
Print version information and exit.
-ifile, --inputfile
Read input from file. If omitted, read from standard input. A value of - for file explicitly uses standard input.
-ofile, --outputfile
Write output to file. If omitted, write to standard output. A value of - for file explicitly uses standard output.
-ttype, --templatetype
Use template type. Valid values are fodt, fohtml, html, latex, man, ms, odt, term, and xml. Defaults to term.
-f, --fragment
Do not emit a full document, only the content fragment. This is equivalent to -tfohtml when -t is not specified.
-m, --meta
Render only the metadata. This option is useful only when -t is html or fohtml. See also METADATA.
--html-style
Use the default CSS stylesheet. Requires -thtml or -tfohtml.
-s, --standalone
Emit a standalone document, not just a fragment. Default when -t is not term or xml.
--no-xml-decl
Do not emit an XML declaration for XML or HTML output.
--no-xml-doctype
Do not emit an XML doctype for HTML or XML output.
--table-of-contents
Generate a table of contents. Requires -thtml or -tfohtml.
--template-filefile
Use file as a template. The template may be overridden by the -ttype option.
--odt-stylefile
Use file as the ODT styles template. This may be overridden by the -todt option.
--xml-stylefile
Use file as the XML stylesheet. This may be overridden by the -txml option.
-v, --verbose
Increase verbosity.
-V, --version
Print version and exit.
-h, --help
Print help and exit.

METADATA

The lowdown utility supports metadata in YAML, JSON, or INI format. This metadata is parsed from the start of the document or from a separate file if specified with the -m option. Metadata keys are case-insensitive.

The following keys are recognised:

author
The author of the document.
date
The date of the document.
title
The title of the document.

The metadata is rendered only when -t is html or fohtml. The -m option extracts and prints the metadata.

When using -X, the following metadata keys are also recognised:

uppercase
Uppercase all list items.

ENVIRONMENT

NO_COLOR
Do not emit colours when in -tterm mode. Synonym for NO_COLOUR. Same as --term-nocolour.

FILES

share/html/default.html
The default template used if --template is not provided to -thtml.
share/latex/default.latex
The default template used if --template is not provided to -tlatex.
share/man/default.man
The default template used if --template is not provided to -tman.
share/man/default.ms
The default template used if --template is not provided to -tms.
share/odt/styles.xml
Default styles used when generating standalone -tfodt documents. Template for --odt-style styles.

EXIT STATUS

The lowdown utility exits 0 on success, and >0 if an error occurs.

If the -X flag is used, lowdown exits with an error if the given keyword is not found.

EXAMPLES

To view a Markdown file on an ANSI-compatible, UTF-8 terminal:

lowdown -tterm foo.md | less -R

The terminal may also be used with groff(1) or mandoc(1) rendering:

lowdown -stms foo.md | groff -itk -mspdf -Tutf8 | less -R
lowdown -stman foo.md | groff -itk -man -Tutf8 | less -R
lowdown -stman foo.md | mandoc | less

To emit a standalone HTML5 document:

lowdown -s foo.md > foo.html

To use groff(1) or mandoc(1) to format as a PS file:

lowdown -stms foo.md | groff -itk -mspdf > foo.ps
lowdown -stman foo.md | mandoc -Tps > foo.ps

Or with LaTeX:

lowdown -stlatex foo.md > foo.latex
pslatex foo.latex

PDF generation follows similar logic:

lowdown -stms foo.md | pdfroff -itk -mspdf > foo.pdf
lowdown -stman foo.md | mandoc -Tpdf > foo.pdf
lowdown -stlatex foo.md > foo.latex
pdflatex foo.latex

UTF-8 support for groff(1) PDF or PS output requires appropriate fonts, such as the Unicode Times font. This and other Unicode fonts are not always installed by default. They may be found, for PDF output, in the devpdf set of the groff(1) font directory and are prefixed with ‘U’.

lowdown -stms foo.md | pdfroff -itk -mspdf -FU-T > foo.pdf

To list all metadata keys, then to extract the “title” metadata value from foo.md:

lowdown -L foo.md
lowdown -X title foo.md
