الوصف

LibreOffice (LO اختصاراً) هو حزمة برامج مكتبية متعددة المنصات. تم اشتقاقها من OpenOffice.org 3.3 Beta في 28 سبتمبر 2010.

libreoffice هو نص برمجي (script) يقوم بإعداد البيئة وتمرير وسائط سطر الأوامر إلى البرنامج الثنائي soffice.bin.

بدلاً من ذلك، تقوم النصوص البرمجية المساعدة التالية بتشغيل الوحدة المعنية:

sbase, scalc, sdraw, simpress, smath, sofficerc, swriter

الخيارات

--accept=سلسلة_قبول
يحدد سلسلة ربط UNO-URL لإنشاء قابل UNO يمكن من خلاله للبرامج الأخرى الاتصال للوصول إلى واجهة برمجة التطبيقات (API). لاحظ أن الوصول إلى واجهة برمجة التطبيقات يسمح بتنفيذ أوامر عشوائية. صيغة سلسلة ربط UNO-URL هي: uno:نوع_الاتصال،معلمات؛اسم_البروتوكول،معلمات؛اسم_الكائن
--base
يبدأ المعالج لملف Base جديد.
--calc
يبدأ بملف Calc جديد.
--convert-to امتداد_ملف_الإخراج[:اسم_مرشح_الإخراج] [--outdir دليل_الإخراج ملف...
تحويل الملفات دفعة واحدة. إذا لم يتم تحديد --outdir، فسيتم استخدام دليل العمل الحالي كدليل إخراج للملفات المحولة. يتضمن هذا الخيار --headless.

أمثلة:

--convert-to pdf *.doc

يحول جميع ملفات .doc إلى ملفات PDF.

--convert-to pdf:writer_pdf_Export --outdir /home/user *.doc

يحول جميع ملفات .doc إلى ملفات PDF باستخدام الإعدادات الموجودة في مربع حوار تصدير PDF في Writer وحفظها في /home/user.

--display شاشة
يحدد هذا الخيار خادم X المراد استخدامه؛ انظر X(7).
--draw
يبدأ بملف Draw جديد.
--global
يبدأ بملف Global جديد.
--headless
يبدأ في وضع "الوضع بدون واجهة"، والذي يسمح باستخدام التطبيق بدون واجهة مستخدم.

يمكن استخدام هذا الوضع الخاص عندما يتم التحكم في التطبيق بواسطة عملاء خارجيين عبر واجهة برمجة التطبيقات.

يتضمن هذا الخيار --invisible ويتجاهل بيئة واجهة المستخدم الرسومية تمامًا. لا يعمل --quickstart مع هذا المعامل.

--help|-h|-?
يسرد معلمات سطر أوامر LibreOffice.
--impress
يبدأ بملف Impress جديد.
--invisible
يبدأ في الوضع غير المرئي.

لن يكون شعار بدء التشغيل أو نافذة البرنامج الأولية مرئيين. يمكن التحكم في LO وفتح المستندات وصناديق الحوار عبر واجهة برمجة التطبيقات.

عند البدء بهذا المعامل، لا يمكن الخروج منه إلا باستخدام مدير المهام (Windows) أو أمر kill (أنظمة شبيهة بـ UNIX).

لا يعمل --quickstart مع هذا المعامل.

--infilter="<مرشح>"
يفرض نوع مرشح إدخال إذا كان ذلك ممكناً. على سبيل المثال --infilter="Calc Office Open XML" فقط.
--math
يبدأ بملف Math جديد.
--minimized
يحافظ على شاشة البداية مصغرة.
-n قالب...
ينشئ مستنداً جديداً من القوالب المحددة.
--nodefault
يبدأ LO دون إنشاء مستند جديد. في المرة التالية التي تبدأ فيها LO، تظهر شاشة الترحيب.

يتم استخدامه مع --nologo من قبل مشغلات سريعة. لاحظ أن --quickstart لم يعد مدعوماً منذ OpenOffice.org 2.0.0.

--nolockcheck
يعطل التحقق من المثيلات عن بعد التي تستخدم التثبيت.
--nologo
يعطل شاشة البداية عند بدء تشغيل البرنامج.
--norestore
يعطل الاستعادة واستعادة الملفات بعد انهيار النظام. من الممكن أن يحاول LO استعادة ملف يتعطل عليه باستمرار، إذا حدث ذلك، فإن --norestore هو الطريقة الوحيدة لبدء LO.
--nosplash
يعطل شاشة البداية عند بدء تشغيل البرنامج.
-o ملف...
يفتح الملفات المحددة للتحرير، حتى القوالب.

بدون -o، سيقوم ملف القالب بإنشاء مستند جديد مشتق من ذلك القالب.

-p ملف...
يطبع الملفات المحددة إلى الطابعة الافتراضية وينتهي. لا تظهر شاشة البداية.

إذا كان اسم الملف يحتوي على مسافات، فيجب وضعه بين علامتي اقتباس.

--print-to-file [--printer-name اسم_الطابعة] [--outdir دليل_الإخراج] ملف...
طباعة الملفات دفعة واحدة إلى ملف. إذا لم يتم تحديد --printer-name، فسيتم استخدام الطابعة الافتراضية. إذا لم يتم تحديد --outdir، فسيتم استخدام دليل العمل الحالي كدليل إخراج للملفات المحولة.

أمثلة:

--print-to-file *.doc

يطبع جميع ملفات .doc إلى دليل العمل الحالي باستخدام الطابعة الافتراضية.

--print-to-file --printer-name nasty_lowres_printer --outdir /home/user *.doc

يطبع جميع ملفات .doc إلى دليل /home/user باستخدام nasty_lowres_printer.

--pt اسم_الطابعة ملف...
يطبع الملفات المحددة إلى الطابعة اسم_الطابعة وينتهي. لا تظهر شاشة البداية.

إذا كان اسم الملف يحتوي على مسافات، فيجب وضعه بين علامتي اقتباس.

--quickstart --quickstart=no
يبدأ LO مع مشغله السريع. --quickstart=no يعطل المشغل السريع.

لا يعمل مع --invisible أو --headless.

--show ملف_Impress...
يفتح ملفات Impress المحددة، ويبدأ العرض التقديمي وينتهي بعد انتهائه.
--unaccept=سلسلة_قبول
يغلق قابلاً تم إنشاؤه باستخدام الخيار --accept.

استخدم --unaccept=all لإغلاق جميع القوابل المفتوحة.

--terminate_after_init
يخرج من التطبيق بعد تهيئة جميع الوحدات.

يتم استخدامه مع --headless لتحويل الملفات.

--version
عرض معلومات الإصدار.
--view ملف...
يفتح الملفات المحددة للقراءة فقط.
--web
يبدأ بصفحة ويب جديدة.
--writer
يبدأ بملف Writer جديد.

loimpress(1) — LibreOffice

NAME

loimpress — LibreOffice Impress

SYNOPSIS

loimpress [OPTIONS] [file...]

DESCRIPTION

LibreOffice is a free and open-source office-suite, a successor of OpenOffice.org.

Impress is a presentation application, let you create, edit and display presentations.

This program is part of the LibreOffice suite.

OPTIONS

These options are available:

--accept =url
Accepts incoming connections on the given socket.
--calc
Starts with a new Calc spreadsheet.
--draw
Starts with a new Draw drawing.
--extend
Starts LO and connects to an already running instance.
--impress
Starts with a new Impress presentation.
--mail
Starts with a new document for the mail merge.
--math
Starts with a new Math formula.
--minimized
Starts LO minimized.
--norestore
Disables the recovery of the last session.
--nologo
Don't show the splash screen.
--norun
Don't start a new instance.
--osdevmode
Activates some debug options.
--readme file
Displays the README file.
--show file
Starts the slideshow for the given presentation.
--splash-page
Shows the splash screen.
--terminate_after_init
Starts LO and terminates after it registers some UNO services. Doesn't show the splash during startup.
--view file...
Opens the given files read-only creating a temporary copy of them at $TMPDIR.
--web
Starts with a new HTML document.
--writer
Starts with a new Writer document.

TROUBLESHOOTING PROBLEMS

See http://wiki.documentfoundation.org/BugReport for more details on how to report bugs in LibreOffice.
