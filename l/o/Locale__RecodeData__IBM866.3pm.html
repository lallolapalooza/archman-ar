الاسم

Locale::RecodeData::IBM866 - روتينات التحويل لـ IBM866

الملخص

هذه الوحدة هي جزء داخلي من libintl. لا تستخدمها مباشرة!

الوصف

هذه الوحدة تم إنشاؤها وتحتوي على جداول التحويل والروتينات الخاصة بـ IBM866.

تعليقات

تم استخراج التعليقات التالية من خريطة الأحرف الأصلية:

automatically generated from the charDB
alias CP866
alias 866

يرجى ملاحظة أن الأسماء البديلة المذكورة أعلاه ليست بالضرورة صالحة!

NAME

Locale::RecodeData::IBM866 - codeset `IBM866’

SYNOPSIS

use Locale::RecodeData::IBM866;

DESCRIPTION

The codeset IBM866 is a character set used for Cyrillic characters on IBM systems.

COMMENTS

This codeset has been contributed by Guido Flohr.
