NAME

Locale::RecodeData::MACHEBREW - Hebrew letters, with specific mapping for MACHEBREW.

SYNOPSIS

  use Locale::RecodeData::MACHEBREW;

DESCRIPTION

This module provides the mapping of Hebrew letters for the MACHEBREW encoding. It is used by the Locale::Recode module.

The encoding is defined by the following set of character mappings:

  0x00-0x7f   ASCII
  0x80-0xff   Hebrew letters

COMMENTS

None.
