Locale::Util(3) توثيق Perl مساهمة من المستخدم Locale::Util(3)

الاسم

Locale::Util - وظائف l10n و i10n محمولة

الملخص

use Locale::Util;
my @linguas = parse_http_accept_language $ENV{HTTP_ACCEPT_LANGUAGE};
my @charsets = parse_http_accept_charset $ENV{HTTP_ACCEPT_CHARSET};
# حاول تعيين اللغة إلى البرتغالية البرازيلية بترميز UTF-8.
my $set_locale = set_locale LC_ALL, 'pt', 'BR', 'utf-8';
set_locale_cache $last_cache;

my $cache = get_locale_cache;
web_set_locale ($ENV{HTTP_ACCEPT_LANGUAGE}, $ENV_ACCEPT_CHARSET);
web_set_locale (['fr-BE', 'fr', 'it'], ['cp1252', 'utf-8']);

الوصف

توفر هذه الوحدة وظائف محمولة تتعامل مع التوطين (l10n) والعولمة (i10n). لا تصدر شيئًا افتراضيًا، يجب عليك تحديد كل وظيفة تحتاجها في قائمة الاستيراد، أو استخدام الاسم المؤهل بالكامل.

تركز الوظائف هنا على تطوير الويب، على الرغم من أنها عامة بما يكفي لوضعها في مساحة اسم Locale::.

تعتبر هذه الوحدة كودًا تجريبيًا. الواجهة ليست مستقرة. يرجى الاتصال بالمؤلف إذا كنت ترغب في استخدامها في كود الإنتاج.

تم تقديم هذه الوحدة في libintl-perl 1.17.

الوظائف

parse_http_accept_language STRING
تحلل سلسلة نصية كما تم تمريرها في رأس HTTP "Accept-Language". تعيد قائمة من الرموز مرتبة حسب قيمة الجودة، انظر RFC 2616 للتفاصيل.

مثال:

parse_http_accept ("fr-fr, fr; q=0.7, de; q=0.3");

هذا يعني: أعطني الفرنسية لفرنسا بقيمة جودة 1.0 (الحد الأقصى). وإلا سآخذ أي نسخة فرنسية أخرى (جودة 0.7)، الألمانية لها جودة 0.3 بالنسبة لي.

ستعيد الوظيفة قائمة بالرموز بالترتيب لقيم الجودة الخاصة بها، في هذه الحالة "fr-fr"، "fr" و "de".

الوظيفة أكثر تساهلاً من RFC 2616. تقبل قيم جودة أكبر من 1.0 وبأكثر من 3 منازل عشرية. كما أنها تقبل لغات وأسماء بلدان بأكثر من 8 أحرف. تتم ترجمة اللغة "*" إلى "C".

parse_http_accept_charset STRING
تحلل سلسلة نصية كما تم تمريرها في رأس HTTP "Accept-Charset". تعيد قائمة من الرموز مرتبة حسب قيمة الجودة، انظر RFC 2616 للتفاصيل.

سيتم ترجمة مجموعة الأحرف الخاصة "*" (تعني جميع مجموعات الأحرف) إلى قيمة غير محددة.

set_locale CATEGORY, LANGUAGE[, COUNTRY, CHARSET]
تحاول تعيين اللغة المحلية للمستخدم عن طريق POSIX::setlocale(). الوظيفة الأخيرة لها عيب، وهو أن وسيطها الثاني (سلسلة وصف اللغة) غير قياسي تمامًا ويعتمد على النظام. تحاول هذه الوظيفة بذل قصارى جهدها لتخمين مفهوم النظام لمعرف اللغة، باستخدام الوسائط المقدمة:
CATEGORY
وسيط عددي لفئة لغة صالحة. هذه هي ثوابت LC_* (LC_ALL، LC_CTIME، LC_COLLATE، ...) المعرفة في كل من Locale::Messages(3pm) و POSIX(3pm).
LANGUAGE
معرف لغة مكون من حرفين وفقًا لـ ISO 639. لا يهم حالة الأحرف، ولكن سيتم دائمًا محاولة نسخة غير متغيرة (أي ليست بأحرف صغيرة) من اللغة التي قدمتها.
COUNTRY
معرف لغة مكون من حرفين وفقًا لـ ISO 639. لا يهم حالة الأحرف، ولكن سيتم دائمًا محاولة نسخة غير متغيرة (أي ليست بأحرف صغيرة) من اللغة التي قدمتها.

هذا الوسيط اختياري. إذا لم يتم تحديده، ستحاول الوظيفة تخمين بلد مناسب، وإلا فستتركه لنظام التشغيل.

CHARSET
اسم مجموعة أحرف صالحة. صالح يعني صالح! مجموعة الأحرف "utf8" ليست صالحة (إنها "utf-8"). مجموعات الأحرف المقبولة من قبل خوارزميات التخمين في Encode(3pm) ليست بالضرورة صالحة.

إذا كانت الوسيط غير محددة، فسيتم تجاهلها. يتم تجاهلها دائمًا على نظام Windows.

تحاول الوظيفة الاقتراب من اللغة المطلوبة في حلقات، وتحسينها عند كل نجاح. ستحاول أولاً تعيين اللغة (لأي بلد)، ثم تحاول تحديد اللغة الصحيحة، وأخيرًا تحاول تحديد مجموعة الأحرف الصحيحة.

قيمة الإرجاع هي خطأ في حالة الفشل، أو قيمة الإرجاع من استدعاء POSIX::setlocale() الأساسي في حالة النجاح.

في سياق المصفوفة، تعيد الوظيفة اسم البلد الذي تم تمريره في المكالمة الناجحة إلى POSIX::setlocale(). إذا كانت هذه السلسلة مساوية لاسم البلد الذي مررته كوسيط، يمكنك أن تكون متأكدًا بشكل معقول من أن الإعدادات لهذا البلد تُستخدم بالفعل. إذا لم تكن متساوية، فقد اتخذت الوظيفة تخمينًا للبلد (لديها قائمة بالبلدان "الافتراضية" لكل لغة). يبدو أنه على نظام Windows، تنجح POSIX::setlocale() أيضًا، إذا مررت اسم بلد غير مدعوم بالفعل. لذلك، المعلومات ليست موثوقة تمامًا.

يرجى ملاحظة أن هذه الوظيفة مخصصة لعمليات الخادم (خاصة تطبيقات الويب) التي تحتاج إلى التبديل بطريقة محمولة إلى لغة معينة. إنها **ليست** الطريقة الموصى بها لتعيين لغة البرنامج لتطبيق عادي. في تطبيق عادي يجب عليك القيام بما يلي:

use POSIX qw (setlocale LC_ALL);
setlocale LC_ALL, '';

السلسلة الفارغة كوسيط ثانٍ تعني أنه يجب على النظام التبديل إلى اللغة الافتراضية للمستخدم.

get_locale_cache
الوظيفة set_locale() قد تكون مكلفة، خاصة عندما تفشل، لأنها يمكن أن تحاول الكثير من التركيبات المختلفة، وقد يحتاج النظام إلى تحميل الكثير من تعريفات اللغة من قاعدة بياناته الداخلية.

لتسريع الأمور، يتم تخزين النتائج مؤقتًا داخليًا في تجزئة، المفاتيح هي اللغات، المفاتيح الفرعية البلدان، المفاتيح الفرعية الفرعية مجموعات الأحرف. يمكنك الحصول على مرجع لهذه التجزئة باستخدام get_locale_cache().

لا يمكن أن تفشل الوظيفة.

set_locale_cache HASH
تعيين ذاكرة التخزين المؤقت الداخلية. يمكنك تمرير تجزئة أو مرجع تجزئة. ستستخدم الوظيفة هذا كذاكرة تخزين مؤقت لها، متجاهلة ذاكرة التخزين المؤقت القديمة. هذا يسمح لك بالاحتفاظ بالتجزئة بشكل دائم.

لا يمكن أن تفشل الوظيفة.

web_set_locale (ACCEPT_LANGUAGE, ACCEPT_CHARSET, CATEGORY, AVAILABLE)
حاول تغيير اللغة إلى الإعدادات الموصوفة بواسطة ACCEPT_LANGUAGE و ACCEPT_CHARSET. لكل وسيط يمكنك تمرير سلسلة نصية كما في رأس http المقابل، أو مرجع لمصفوفة من معرفات اللغة أو مجموعة الأحرف على التوالي.

حاليًا، يتم استخدام مجموعة الأحرف الأولى التي تم تمريرها فقط كوسيط. يتم تشجيعك بشدة على تمرير قيمة ثابتة هنا، حتى يكون لديك تحكم في إخراجك.

يحدد الوسيط CATEGORY الفئة (واحدة من ثوابت LC_* كما هي معرفة في Locale::Messages(3pm) أو في POSIX(3pm)). الفئة الافتراضية هي LC_ALL.

يمكنك تمرير مرجع اختياري لقائمة باللغات بتنسيق XPG4 المتاحة في تطبيقك. هذا مفيد إذا كنت تعرف اللغات التي يدعمها تطبيقك. في الواقع، يتم أخذ جزء اللغة فقط من القيم الموجودة في القائمة في الاعتبار (على سبيل المثال، لـ "en_US"، يتم استخدام "en" فقط). يتم تجاهل البلد أو الأجزاء الأخرى.

تعيد الوظيفة القيمة المعادة من استدعاء set_locale() الأساسي، أو خطأ عند الفشل.

تعيد الوظيفة خطأ عند الفشل. عند النجاح، تعيد القيمة المعادة من استدعاء set_locale() الأساسي. يمكن استخدام هذه القيمة مباشرة في استدعاءات لاحقة لـ POSIX::setlocale(). في سياق المصفوفة، تعيد إضافيًا معرفات الـ

Locale::Util(3pm) — Arch Linux

NAME

Locale::Util — Perl module for locale-related utilities.

SYNOPSIS

use Locale::Util;

my $locale = current_locale;
my $encoding = current_encoding;

set_locale( 'en_US.UTF-8' );
set_encoding( 'UTF-8' );

my $ret = setlocale( LC_ALL, '' );
my $ret = setlocale( LC_COLLATE, 'fr_FR.ISO-8859-1' );
my $ret = setlocale( LC_MESSAGES, '' );

if ( defined $ret ) {
  print "Locale was successfully set to: $ret\n";
} else {
  warn "Failed to set locale.\n";
}

my $set = set_locale( LC_ALL, "en_GB.ISO-8859-1" );
my $country = locale_country( LC_ALL );
my $language = locale_language( LC_ALL );
my $charset = locale_charset( LC_ALL );

print "Country: $country, Language: $language, Charset: $charset\n";
print "Full locale: ", full_locale( 'en_US.UTF-8' ), "\n";
print "Locale: ", locale_string('en_US.UTF-8'), "\n";

my $val = current_locale ( LC_MESSAGES );
my $val = current_encoding ( LC_MESSAGES );

if ( valid_locale( 'en_US.UTF-8' ) ) {
    print "Locale en_US.UTF-8 is valid.\n";
}
if ( valid_charset( 'UTF-8' ) ) {
    print "Charset UTF-8 is valid.\n";
}

my $ret = set_locale_to_default();
my $ret = set_locale_to_default( LC_TIME );
my $ret = set_locale_to_default( LC_TIME, "de_DE.ISO-8859-1" );

my $ret = set_encoding_to_default();
my $ret = set_encoding_to_default( 'UTF-8' );
my $ret = set_encoding_to_default( 'UTF-8', 'en_US.UTF-8' );

my $ret = set_locale_and_encoding( 'en_US.UTF-8' );
my $ret = set_locale_and_encoding( 'en_US.UTF-8', 'UTF-8' );

my $ret = set_locale_if_valid( 'en_US.UTF-8' );
my $ret = set_locale_if_valid( 'en_US.UTF-8', 'UTF-8' );
my $ret = set_locale_if_valid( 'en_US.UTF-8', 'UTF-8', LC_COLLATE );

my $locale_string = locale_info( LC_ALL );
my $country = locale_info( LC_ALL, 'country' );
my $language = locale_info( LC_ALL, 'lang' );
my $charset = locale_info( LC_ALL, 'charset' );

my $locale_string = locale_info( 'en_US.UTF-8' );
my $country = locale_info( 'en_US.UTF-8', 'country' );
my $language = locale_info( 'en_US.UTF-8', 'lang' );
my $charset = locale_info( 'en_US.UTF-8', 'charset' );

DESCRIPTION

This module provides routines to query and set the current locale and character set.

It is intended to be used as a Perl interface to the standard C library function setlocale(3). Note that setlocale may be called with different category constants like LC_ALL, LC_COLLATE, LC_CTYPE, LC_MESSAGES, LC_MONETARY, LC_NUMERIC, and LC_TIME.

The constants LC_ALL, etc. are exported by this module.

A locale string typically consists of the language code, an underscore, the country code, and an optional character set specification (e.g. en_US.UTF-8). The character set specification is optional and depends on the operating system.

This module tries to determine the current locale and character set used by the Perl interpreter. It may not be successful on all systems.

FUNCTIONS

current_locale [CATEGORY]
Returns the current locale setting for the given CATEGORY (defaults to LC_ALL). If the locale can not be determined, it returns undef.
current_encoding [CATEGORY]
Returns the character set encoding used for the given CATEGORY (defaults to LC_ALL). If the encoding can not be determined, it returns undef.
set_locale CATEGORY, LOCALE
Sets the locale for the given CATEGORY to LOCALE. Returns the actual locale string that was set, or undef on failure. If LOCALE is empty or undef, the default locale of the system is used.
set_encoding ENCODING
Sets the character set encoding to ENCODING. Returns the actual encoding string that was set, or undef on failure. This function is a convenience wrapper around setlocale(LC_CTYPE, ...) and setlocale(LC_ALL, ...).
setlocale CATEGORY, LOCALE
This is the Perl interface to the C library function. It takes the category constant and the locale string as arguments. Returns the actual locale string that was set, or undef on failure.
locale_country LOCALE
Extracts the country code from the given LOCALE string. Returns the country code or undef if it cannot be determined.
locale_language LOCALE
Extracts the language code from the given LOCALE string. Returns the language code or undef if it cannot be determined.
locale_charset LOCALE
Extracts the character set from the given LOCALE string. Returns the character set or undef if it cannot be determined.
full_locale LOCALE
Returns the full locale string, including language, country, and charset. The input LOCALE can be a string or a category constant.
locale_string LOCALE
Returns the locale string for the given LOCALE. The input LOCALE can be a string or a category constant.
valid_locale LOCALE
Checks if the given LOCALE string is valid on the current system. Returns true or false.
valid_charset CHARSET
Checks if the given CHARSET string is valid on the current system. Returns true or false.
set_locale_to_default [CATEGORY, LOCALE]
Sets the locale for the given CATEGORY (defaults to LC_ALL) to the system's default locale. If LOCALE is specified, it is used as the default locale. Returns the actual locale string that was set, or undef on failure.
set_encoding_to_default [ENCODING, LOCALE]
Sets the encoding to the system's default encoding. If ENCODING is specified, it is used as the default encoding. If LOCALE is also specified, the encoding is set for that specific locale. Returns the actual encoding string that was set, or undef on failure.
set_locale_and_encoding LOCALE, [ENCODING]
Sets both the locale and the encoding. If ENCODING is not specified, it is derived from the LOCALE string. Returns true on success, false otherwise.
set_locale_if_valid LOCALE, [ENCODING, CATEGORY]
Sets the locale to LOCALE if it is valid on the system. If ENCODING is provided, it is also checked for validity. If CATEGORY is provided, the locale is set only for that category. Returns true on success, false otherwise.
locale_info LOCALE, [KEY]
Returns information about the given LOCALE. If KEY is specified, it returns the value for that key (e.g., 'country', 'lang', 'charset'). If KEY is not specified, it returns the full locale string. The input LOCALE can be a string or a category constant.

BUGS

The function set_locale() probably fails to guess the correct locale identifier on a lot of systems. If you have found such a case, please submit it as a bug report.

The bug tracking system for this packags is at http://rt.cpan.org/NoAuth/Bugs.html?libintl-perl

Please note that this module is considered alpha code, and the interface is not stable. Please contact the author, if you want to use it in production code.
