NAME

Locale::RecodeData::CP1252 - an encoding of code page 1252

SYNOPSIS

use Locale::RecodeData "CP1252";

DESCRIPTION

This module defines the mapping of code page 1252 (also known as Windows-1252) to and from Unicode.

This module is part of the Locale::Recode distribution. See the documentation for Locale::Recode(3) for more details on how to use it.

COMMENTS

Code page 1252 is an extension of ISO 8859-1. The characters in the range U+0080 to U+009F, which are C1 control codes in ISO 8859-1, are assigned printable characters in code page 1252.
