lowdown_gemini_new(3)

الحزمة: lowdown

التراخيص: ISC

LOWDOWN_GEMINI_NEW(3) دليل وظائف المكتبة LOWDOWN_GEMINI_NEW(3)

الاسم

lowdown_gemini_new — تخصيص عارض Gemini لـ Markdown

المكتبة

المكتبة “liblowdown”

ملخص

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void *
lowdown_gemini_new(const struct lowdown_opts *opts);

الوصف

يقوم بتخصيص عارض Gemini باستخدام opts->oflags، أو صفر إذا كان opts هو NULL. يمكن استخدام المؤشر المُعاد مع استدعاءات متعددة لـ lowdown_gemini_rndr(3) ويجب تحريره باستخدام lowdown_gemini_free(3).

البِتات التي يتم التعرف عليها في opts->oflags هي LOWDOWN_GEMINI_LINK_IN، LOWDOWN_GEMINI_LINK_END، LOWDOWN_GEMINI_LINK_NOREF، LOWDOWN_GEMINI_LINK_ROMAN، LOWDOWN_GEMINI_METADATA، و LOWDOWN_STANDALONE. تم توثيق هذه في lowdown(3).

قيم الإرجاع

يعيد مؤشرًا إلى العارض أو NULL في حالة فشل الذاكرة. يجب تحرير المؤشر المُعاد باستخدام lowdown_gemini_free(3).

أمثلة

يقوم الكود التالي بتحليل b بطول bsz ويخرج بتنسيق Gemini.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if (setlocale(LC_CTYPE, "en_US.UTF-8") == NULL)
	err(1, NULL);
if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_gemini_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_gemini_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_gemini_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

انظر أيضًا

lowdown(3)، lowdown_gemini_free(3)، lowdown_gemini_rndr(3)

تم توثيق تنسيق gemini “gemtext” في مشروع Gemini. الإصدار وقت كتابة هذا المستند هو 0.24.1.
