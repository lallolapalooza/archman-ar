FBB::LogBuf(3bobcat) تدفق رسائل السجل FBB::LogBuf(3bobcat)

الاسم

FBB::LogBuf - معالجة رسائل السجل باستخدام std::streambuf

الملخص

#include <bobcat/logbuf>
خيار الربط: -lbobcat

الوصف

FBB::LogBuf هو فئة مشتقة من std::streambuf لمعالجة رسائل السجل. يمكن تكوين التدفق لتسجيل الرسائل، والطوابع الزمنية، ومستويات السجل في وقت الإنشاء وبعده. يمكن استخدام FBB::LogBuf لتهيئة std::ostream.

FBB

ترث من

std::streambuf

تعدادات

تم تعريف التعداد TimeStamps في مساحة الاسم FBB لاستخدامه عند تهيئة كائنات FBB::LogBuf. له القيم التالية:

o
NOTIMESTAMPS:
لن يتم إضافة طوابع زمنية إلى رسائل السجل.
o
TIMESTAMPS:
سيتم إضافة طوابع زمنية إلى رسائل السجل.
o
UTCTIMESTAMPS:
سيتم إضافة طوابع زمنية تعرض وقت التوقيت العالمي المنسق (UTC) إلى رسائل السجل.

يتم استخدام التعداد Active للتمييز بين تعليق إدخال الرسائل عندما لا يتجاوز مستوى الرسالة الحد الأدنى، وتعليق جميع عمليات إدخال الرسائل (على سبيل المثال، عند تعليق إدخال الرسائل في كائنات FBB::Log بعد استدعاء العضو off الخاص بها):

o
OFF:
تم تعليق جميع عمليات الإدخال في كائن LogBuf؛
o
NOT_ACTIVE:
تم تعليق إدخال الرسائل في كائن LogBuf إذا كانت مستوياتها أقل من الحد الأدنى المحدد (كما هو محدد بواسطة، على سبيل المثال، Log::setLevel).
o
ACTIVE:
يتم إدخال الرسائل.

المنشئات

o
LogBuf(TimeStamps timestamps = TIMESTAMPS, bool active = true, char const *delim = " "):
يقوم هذا المنشئ بإنشاء كائن FBB::LogBuf يقوم بكتابة رسائل السجل الخاصة به إلى std::cerr. إذا تم تهيئة المعامل active إلى false، فلن يتم تسجيل أي رسائل حتى يتم تشغيل نشاط المخزن المؤقت (انظر setActive() أدناه). المعامل delim يتم إدراجه مباشرة بعد الطابع الزمني. إذا كان المحدد غير مناسب، يمكن تحديد سلسلة فارغة أو مؤشر 0. عندما يكون stamps == FBB::NOTIMESTAMPS، يتم تجاهل delim. يتكون الطابع الزمني من الشهر، ورقم اليوم من الشهر، والوقت (المحلي) للرسالة الحالية، كما يظهر عادةً في الرسائل في ملفات /var/log. على سبيل المثال، Aug 5 13:52:23؛
o
LogBuf(std::ostream &stream, TimeStamps timestamps = TIMESTAMPS, bool active = true, char const *delim = " "):
يقوم هذا المنشئ بإنشاء كائن FBB::LogBuf يقوم بكتابة رسائل السجل الخاصة به إلى التدفق المستخدم لتهيئة المعامل stream الخاص به. إذا تم تهيئة المعامل active إلى false، فلن يتم تسجيل أي رسائل حتى يتم تشغيل نشاط المخزن المؤقت (انظر setActive() أدناه). المعامل delim يتم إدراجه مباشرة بعد الطابع الزمني. إذا كان المحدد غير مناسب، يمكن تحديد سلسلة فارغة أو مؤشر 0. عندما يكون stamps == FBB::NOTIMESTAMPS، يتم تجاهل delim. يتكون الطابع الزمني من الشهر، ورقم اليوم من الشهر، والوقت (المحلي) للرسالة الحالية، كما يظهر عادةً في الرسائل في ملفات /var/log. على سبيل المثال، Aug 5 13:52:23.

وظائف الأعضاء العامة

جميع أعضاء std::streambuf متاحة، حيث ترث FBB::LogBuf من هذه الفئة.

o
bool active() const:
تعيد true إذا كانت رسائل السجل قيد المعالجة حاليًا؛
o
bool empty() const:
تعيد true إذا كان المخزن المؤقت للكائن فارغًا حاليًا (في البداية أو بعد إدراج حرف سطر جديد)؛
o
void setStream(std::ostream &stream):
يمكن استخدام هذا العضو للتبديل إلى التدفق المراد تسجيل الرسائل إليه. تقع على عاتق المبرمج مسؤولية ضمان بقاء التدفق الخارجي متاحًا طالما يتم إدخال رسائل السجل إليه؛
o
void settimestamp(FBB::TimeStamps timestamps, char const *delim = " "):
تقوم دالة العضو بتفعيل/إلغاء تفعيل إضافة الطوابع الزمنية. استخدم القيمة FBB::TIMESTAMPS لإضافة الطوابع الزمنية، و FBB::NOTIMESTAMPS لحذف الطوابع الزمنية. يتكون الطابع الزمني من الشهر، ورقم اليوم من الشهر، والوقت (المحلي) للرسالة الحالية، كما يظهر عادةً في الرسائل في ملفات /var/log. على سبيل المثال، Aug 5 13:52:23. يتم إدراج المعامل delim مباشرة بعد الطابع الزمني. إذا كان المحدد غير مناسب، يمكن تحديد سلسلة فارغة أو مؤشر 0. عندما يكون stamps == FBB::NOTIMESTAMPS، يتم تجاهل delim؛
o
void setActive(bool active):
ما لم تكن حالة Active للكائن الحالي OFF، يمكن استخدام هذا العضو لتفعيل/إلغاء تفعيل التسجيل. الوسيط true يفعل التسجيل، والوسيط false يلغيه. إذا كانت حالة Active الحالية OFF، فإن هذا العضو لا يغير حالة نشاط الكائن. يتم استدعاء هذا العضو عادةً بواسطة أعضاء FBB::Log::level؛
o
void setActive(Active active):
تقوم دالة العضو بتفعيل/إلغاء تفعيل التسجيل. الوسيط ACTIVE يفعل التسجيل، والوسيط OFF يلغي التسجيل تمامًا، والوسيط NOT_ACTIVE يلغي التسجيل أيضًا، ولكن هنا يمكن أيضًا استخدام setActive(true) لإعادة تفعيل التسجيل؛
o
void setEmpty(bool empty):
يمكن استدعاء هذا العضو لضمان إدراج طابع زمني قبل الإدخال التالي. يتم استدعاؤه كـ setEmpty(true) عند إدراج حرف سطر جديد (\n)، مما يضمن إضافة طابع زمني آخر قبل الإدخال التالي.

مثال

#include <iostream>
#include <iomanip>
#include <bobcat/log>
#include <bobcat/level>
using namespace std;
using namespace FBB;
int main()
{
    LogBuf buffer(cout, FBB::TIMESTAMPS);
    ostream log(&buffer);
    log << "This message is written to cout" << nl <<
           setw(16) << ’ ’ << "occupying multiple lines\n";
    buffer.setActive(false);
    log << "one line\n";
    log << "more lines ";
    log << fnl;
    log << "another\n";
    buffer.setActive(true);
    log << "and active again\n";
    log << "another log msg\n";
}
