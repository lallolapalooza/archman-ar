القوالب

تقبل بعض وسائط الإخراج قالبًا (--template) لتخصيص الإخراج المستقل (-s). يتم ملء المحتوى المدخل المفسر في القوالب من خلال عبارات التحكم التي تدعم الشروط والحلقات وتسلسلات تحويل المتغيرات.

عبارات التحكم محددة كـ $statement$ أو ${statement}. قد توجد مسافات بيضاء عشوائية حول العبارة غير الحساسة لحالة الأحرف بين المحددات المتطابقة. تعتبر العبارات التي لا تحتوي على محدد إغلاق نصًا معتمًا.

العبارات التالية متاحة:

$$، ${}
إخراج حرف $ حرفيًا. يمكن أن تحتوي هذه على مسافات بيضاء عشوائية.
$ifdef(expression)$
عبارة شرطية. قد لا توجد مسافات بيضاء بين ifdef والقوس الافتتاحي. تبدأ كتلة تنتهي بـ else، endif، أو نهاية الملف. يتم إخراج محتوياتها فقط إذا كانت expression تقيم إلى سلسلة غير فارغة.
$else$
تبدأ كتلة تنتهي بـ endif أو نهاية الملف. يتم إخراج محتوياتها فقط إذا كانت شرط عبارة ifdef السابقة تقيم إلى سلسلة فارغة. else بدون ifdef سابقة لا يتم إخراجها.
$endif$
تغلق كتلة بدأت بـ ifdef أو else. إذا لم تسبقها إحدى هذه العبارات، يتم تجاهلها بصمت.
$for(expression)$
عبارة حلقية. قد لا توجد مسافات بيضاء بين for والقوس الافتتاحي. تبدأ كتلة تنتهي بـ endfor أو نهاية الملف. يتم إخراج محتويات الكتلة بشكل متكرر لكل عنصر قائمة يتم تقييمه من expression. يمكن استخدام الكلمة المفتاحية الأنافورية this للوصول إلى تعبير الحلقة الحالي داخل الكتلة.
$expression$
يتم استبداله بنتيجة تقييم تعبير القالب.

إذا انتهت عبارة تحكم بشرطتين متتاليتين قبل محدد الإغلاق، يتم استهلاك الإدخال حتى السطر التالي وشامله أو حتى نهاية الملف. هذا يسمح لوسائط الإخراج الحساسة للأسطر باستخدام عبارات التحكم دون أسطر فارغة غير ضرورية.

تتكون التعبيرات من

initial[([arg]*)]?[.transform[([arg]*)]?]*
،

أو قيمة أولية تقبل وسائط اختيارية تليها سلسلة اختيارية من التحويلات التي تقبل وسائط اختيارية. إذا كانت قائمة الوسائط فارغة أو لم يتم توفيرها، فإنها تقيم إلى قائمة فارغة.

القيمة initial هي واحدة مما يلي:

and(expression[,expression]*)
قائمة غير فارغة تحتوي على القيمة true إذا كانت جميع التعبيرات تقيم إلى قوائم غير فارغة، وإلا قائمة فارغة. تعبير فارغ يقيم إلى قائمة فارغة.
"literal string"
تقيم إلى قائمة وحيدة تحتوي على السلسلة. سلسلة فارغة تقيم إلى قائمة فارغة. يمكن الهروب من علامة الاقتباس المزدوجة، مثل "foo\"bar".
body
جسم المستند المدخل المفسر.
مفتاح البيانات الوصفية المقنن
القيمة للمفتاح البيانات الوصفية المعطى، إذا تم العثور عليها، وإلا قائمة فارغة.
body
جسم المستند المدخل المفسر.
meta(key)
إنتاج قيمة البيانات الوصفية للمفتاح البيانات الوصفية المقنن key. يسمح للمفاتيح التي هي أيضًا كلمات مفتاحية مثل body أو endif.
not(expression)
قائمة غير فارغة تحتوي على القيمة true إذا كان التعبير يقيم كقائمة فارغة، وإلا قائمة فارغة.
or(expression[,expression]*)
قائمة غير فارغة تحتوي على القيمة true إذا كان تعبير واحد يقيم إلى قوائم غير فارغة، وإلا قائمة فارغة. تعبير فارغ يقيم إلى قائمة فارغة.
this
قيمة سياق حلقة حالي أو قائمة فارغة.

إذا لم يتم تحديد مفتاح بيانات وصفية في الإدخال، أو إذا لم يتم تهيئة this الأنافوري بواسطة سياق حلقي، فإن القيمة الأولية تقيم إلى قائمة فارغة. خلاف ذلك، القيمة هي قائمة وحيدة.

إذا كانت التحويلات غير صالحة، فإنها تتحول إلى قائمة فارغة.

escapegemini، escapegeminiline

هروب عناصر القائمة لمحتوى جسم HTML (-thtml)، السمات، وسمات URL، على التوالي.

هروب عناصر القائمة لمحتوى جسم LaTeX (-tlatex).

[-o file] [-F file

DESCRIPTION

The lowdown-diff utility compares two Markdown files, old.md and new.md, and outputs the differences between them. The output format is determined by the -t flag.

The following output types are supported:

-tterm
Output differences suitable for display on an ANSI-compatible, UTF-8 terminal. It uses colours to highlight additions and deletions. If -Cchar is specified, that character is used for deletions. The default deletion character is ‘-’. If -Schar is specified, that character is used for additions. The default addition character is ‘+’. If -ppath is specified, that path is used to determine a diff context. If -ddir is specified, that directory is used to determine a diff context.
-thtml
Output differences as an HTML5 document. This type supports using a template file specified with the -T flag. If no template is given, share/html/default.html is used.
-tlatex
Output differences as a LaTeX document. This type supports using a template file specified with the -T flag. If no template is given, share/latex/default.latex is used.
-tman
Output differences suitable for rendering as a man page. This type supports using a template file specified with the -T flag. If no template is given, share/man/default.man is used.
-tms
Output differences suitable for rendering with groff -ms. This type supports using a template file specified with the -T flag. If no template is given, share/man/default.ms is used.
-tfodt
Output differences as a Flat OpenDocument Text (ODF) file. This type supports using a template file specified with the -T flag. If no template is given, share/odt/styles.xml is used as the basis for the styles.
-tgemini
Output differences in Gemini format.

The following options are also supported:

escape
Escape the special characters in Markdown and roff delimiters. This is useful when generating output for formats that may misinterpret these characters. It can be used with any output type (e.g., -thtml, -tlatex, -tman), either for multiple lines or compressed to a single line. escaperoff also escapes initial roff delimiters and those after newlines.
join
Join a list into a singleton list using two spaces as a join delimiter.
lowercase
Lowercase all list items.
split
Split list items on sequences of two or more white-space tokens (space, newline, tab). This is usually invoked on a singleton, but may be repeatedly invoked on a pre-split list. Invokes trim prior to the first split. The resulting list has no items that are only white-space.
trim
Trim white-space from the beginning and end of all list items. If an item has no non-white-space, it is discarded.
uppercase
Uppercase all list items.

ENVIRONMENT

NO_COLOR
Do not emit colours when in -tterm mode. Synonym for NO_COLOUR. Same as --term-nocolour.

FILES

share/html/default.html
The default template used if --template is not provided to -thtml.
share/latex/default.latex
The default template used if --template is not provided to -tlatex.
share/man/default.man
The default template used if --template is not provided to -tman.
share/man/default.ms
The default template used if --template is not provided to -tms.
share/odt/styles.xml
Default styles used when generating standalone -tfodt documents. Template for --odt-style styles.

EXIT STATUS

The lowdown-diff utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

To view Markdown differences on an ANSI-compatible, UTF-8 terminal:

lowdown-diff -tterm old.md new.md | less -R

The terminal may also be used with groff(1) rendering:

lowdown-diff -stms old.md new.md | \
  groff -itk -mspdf -Tutf8 | less -R
lowdown-diff -stman old.md new.md | \
  groff -itk -man -Tutf8 | less -R

To emit a standalone HTML5 document:

lowdown-diff -s old.md new.md > foo.html

To use groff(1) to format as a PS file:

lowdown-diff -stms old.md new.md | \
  groff -itk -mspdf > foo.ps

Or with LaTeX:

lowdown-diff -stlatex old.md new.md > foo.latex
pslatex foo.latex

PDF generation follows similar logic:

lowdown-diff -stms old.md new.md | \
  pdfroff -itk -mspdf > foo.pdf
lowdown-diff -stlatex old.md new.md > foo.latex
pdflatex foo.latex

UTF-8 support for groff(1) PDF or PS output requires appropriate fonts, such as the Unicode Times font. This and other Unicode fonts are not always installed by default. They may be found, for PDF output, in the devpdf set of the groff(1) font directory and are prefixed with ‘U’.

lowdown-diff -stms old.md new.md | \
  pdfroff -itk -mspdf -FU-T > foo.pdf
