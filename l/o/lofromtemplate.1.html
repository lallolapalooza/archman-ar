NAME

lofromtemplate — Create a document from a template

SYNOPSIS

lofromtemplate [Options] [Template]

DESCRIPTION

This command uses LibreOffice to create a document based on a template. If no template is specified, a default template is used.

It is a wrapper script for LibreOffice which allows to create documents from templates without needing to start the full LibreOffice suite.

OPTIONS

--back
Starts LO in the background.
--calc
Starts with a new Calc document.
--draw
Starts with a new Draw document.
--export file
Exports the document to the specified file and exits. The format is determined by the file extension.
--export-to-dir dir
Exports the document to the specified directory and exits. The format is determined by the template's default export format.
--help
Shows help message.
--impress
Starts with a new Impress document.
--lang language
Uses the specified language for the document.
--minimized
Starts LO minimized.
--norestore
Disables the restoring of the last used document.
--nologo
Does not show the splash screen.
--origdir dir
Sets the original directory to dir.
--print
Prints the document and exits.
--print-to-file file
Prints the document to the specified file and exits. The format is determined by the file extension.
--show file
Opens the given file read-only.
--template-dir dir
Specifies the directory to search for templates.
--terminate_after_init
Starts LO and terminates after it registers some UNO services. Doesn't show the splash during startup.
--view file...
Opens the given files read-only creating a temporary copy of them at $TMPDIR.
--web
Starts with a new HTML document.
--writer
Starts with a new Writer document.
