NAME

Locale::RecodeData::KOI8_U - KOI8-U character set

SYNOPSIS

    use Locale::RecodeData qw( :KOI8_U );

    my $string = "\x8f\x85\x92\x81\x84\x91\x94\x90\x8c\x88\x8d\x95\x9a\x9b\x9d\x9c\x87\x83\x9f\x9e\x96\x93\x97\x8a\x8b\x99\x80\x86\x8e\x8f\x98\x92";
    my $recode = Locale::RecodeData->new( 'KOI8_U' );

    $recode->map_char( ... );
    $recode->map_text( ... );
    $recode->unmap_char( ... );
    $recode->unmap_text( ... );

    print $recode->head();
    print $recode->text();
    print $recode->tail();

DESCRIPTION

This module provides the KOI8-U character set (also known as Unicode U+0430-U+044f KOI8-U, Cyrillic KOI8-U) for the Locale::Recode module.

KOI8-U is an 8-bit character encoding for the Cyrillic alphabet, primarily used for Russian.

The module exports no subroutines. It is intended to be used by the Locale::Recode module.

COMMENTS

This file has been generated from the character mapping file koi8-u.conf of the recode library.

The character set name KOI8-U has been registered at IETF and has an official name.
