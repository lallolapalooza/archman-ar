NAME

Locale::RecodeData::IBM1026 - Character set information for IBM Code Page 1026

SYNOPSIS

 use Locale::RecodeData 'IBM1026';
 my $data = Locale::RecodeData->new('IBM1026');

DESCRIPTION

This module provides character set mapping data for the IBM1026 character set.

COMMENTS

This character set is also known as cp1026, EUC-TW, or windows-1252.

This character set is a superset of ISO 8859-1.
