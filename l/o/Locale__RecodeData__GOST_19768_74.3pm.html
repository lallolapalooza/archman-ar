تعليقات

تم استخراج التعليقات التالية من ترميز الأحرف الأصلي:

الإصدار: 1.0
 المصدر: سجل ECMA
 اسم بديل ST_SEV_358-88
 اسم بديل ISO-IR-153

ملاحظة: الأسماء البديلة المذكورة أعلاه ليست بالضرورة صالحة!

NAME

Locale::RecodeData::GOST_19768_74 — GOST 19768-74 (Cyrillic) encoding

SYNOPSIS

    use Locale::RecodeData::GOST_19768_74;
    # ...
    my $recode_data = Locale::RecodeData::GOST_19768_74->new();
    # ...

DESCRIPTION

This module provides access to the GOST 19768-74 (Cyrillic) character set mapping table.

The GOST 19768-74 standard is an old Soviet and Russian standard for encoding Cyrillic characters. It is a 8-bit encoding.

This module is intended to be used with the Locale::Recode(3) module.

COMMENTS

    The GOST 19768-74 standard is used for Cyrillic characters.
    It is a 8-bit encoding.
    For the mapping table, please see the GOST 19768-74 definition.
