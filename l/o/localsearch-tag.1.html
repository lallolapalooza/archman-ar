localsearch-tag(1)

الحزمة: localsearch

التراخيص: GPL-2.0-or-later

LOCALSEARCH-TAG(1) دليل LocalSearch LOCALSEARCH-TAG(1)

الاسم

localsearch-tag - إضافة، إزالة، وسرد العلامات.

الملخص

localsearch tag FILE [-l <limit>] [-o <offset>] [-r]
localsearch tag -t [-s] [-r] FILE
localsearch tag -a <TAG> [-e <description>]
localsearch tag -d <TAG>

الوصف

سرد العلامات للملفات المحلية أو بواسطة تسميات العلامات نفسها إذا تم استخدام -t.

من الممكن أيضًا إدارة العلامات باستخدام الخيارات -a و -d.

يمكن أن يكون الوسيط FILE مسارًا محليًا أو URI. كما أنه ليس بالضرورة مسارًا مطلقًا.

الخيارات

-t, --list

سرد جميع العلامات. تتضمن النتائج عدد الملفات المرتبطة بتلك العلامة ومعرف العلامة الفريد. يمكنك عرض الملفات المرتبطة بكل علامة باستخدام --show-files.

-s, --show-files

عرض الملفات المرتبطة بكل علامة. هذا الخيار متاح فقط مع الخيار --list.

-a, --add=TAG

إضافة علامة بالاسم TAG. إذا لم يتم تحديد الوسيط FILE، يتم إنشاء العلامة ببساطة (إذا لم تكن موجودة بالفعل) ولا يتم ربط أي ملفات بها.

-d, --delete=TAG

حذف علامة بالاسم TAG. إذا لم يتم تحديد الوسيط FILE، يتم حذف العلامة لجميع الملفات.

-e, --description=STRING

ينطبق هذا الخيار فقط عند استخدام --add ويوفر وصفًا يتوافق مع تسمية العلامة وفقًا لـ STRING.

-l, --limit=N

تحديد عدد النتائج. الافتراضي هو 512.

-o, --offset=N

إزاحة نتائج البحث بمقدار N. على سبيل المثال، ابدأ من العنصر رقم 10 في النتائج. الافتراضي هو 0.
$ localsearch tag -s -t banana

يجب أن يعرض الملفات في قاعدة البيانات التي تحتوي على العلامة banana.

راجع أيضًا

localsearch search(1), localsearch info(1).
