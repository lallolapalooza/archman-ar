NAME

Locale::RecodeData::IBM863 — Character set description for IBM Code Page 863 (Canadian French).

SYNOPSIS

  use Locale::Recode::IBM863;

  # Convert from IBM863 to UTF-8
  my $recode_to_utf8 = Locale::Recode::IBM863->new('UTF-8');
  my $string_utf8 = $recode_to_utf8->string_to_utf8($string_ibm863);

  # Convert from UTF-8 to IBM863
  my $recode_from_utf8 = Locale::Recode::IBM863->new('UTF-8', 'IBM863');
  my $string_ibm863 = $recode_from_utf8->string_from_utf8($string_utf8);

DESCRIPTION

This module provides the character set description for IBM Code Page 863 (Canadian French) for use with the Locale::Recode module.

It defines the mapping between this character set and other character sets, allowing for transparent data conversion.

COMMENTS

This character set is mainly used on older IBM PC systems for Canadian French.
