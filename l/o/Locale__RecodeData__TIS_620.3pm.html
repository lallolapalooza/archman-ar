Locale::RecodeData::TIS_620 - روتينات التحويل لـ TIS-620

الملخص

هذه الوحدة داخلية لـ libintl. يجب عدم استخدامها مباشرة!

الوصف

تحتوي هذه الوحدة على جداول التحويل والروتينات الخاصة بـ TIS-620.

تعليقات

تم استخلاص التعليقات التالية من جدول الأحرف الأصلي:

NAME

Locale::RecodeData::TIS_620 - TIS 620 encoding and TIS 620 data.

SYNOPSIS

    use Locale::Recode;
    use Locale::RecodeData::TIS_620;

    # Convert from TIS 620 to UTF-8
    my $recode = Locale::Recode->new('TIS_620', 'UTF-8');
    $recode->translate($string);

    # Convert from UTF-8 to TIS 620
    my $recode = Locale::Recode->new('UTF-8', 'TIS_620');
    $recode->translate($string);

DESCRIPTION

This module provides functions for encoding and decoding Thai characters using the TIS 620 character set.

COMMENTS

TIS 620 is the Thai Industrial Standard 620-1990. It is a 7-bit encoding, that is used for Thai characters.

This module is part of the Locale::Recode distribution.
