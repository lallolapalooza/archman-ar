NAME

Locale::RecodeData::KOI8_RU - KOI8-R encoding for Locale::Recode

SYNOPSIS

 use Locale::RecodeData::KOI8_RU;

 my $recode = Locale::Recode->new("KOI8-RU");
 $recode->filter( ... );

DESCRIPTION

This module provides the KOI8-R character encoding for the Locale::Recode package.

KOI8-R is a character encoding for Cyrillic alphabets. It is widely used in Russia and other Slavic countries.

This module implements the mapping between KOI8-R and the Unicode character set.

COMMENTS

 The following data is derived from the KOI8-R specification.
 The order corresponds to the byte values from 0x80 to 0xFF.
 Some entries are not assigned, or are not used in this specific
 encoding.
