الوحدة Load_path
: sig end

إدارة مجلدات التضمين.

تقدم هذه الوحدة واجهة عالية المستوى لتحديد مواقع الملفات في مسار التحميل، والذي يتم بناؤه من خيارات سطر الأوامر -I و -H وعدد قليل من المعلمات الأخرى.

تفترض أن محتويات مجلدات التضمين لا تتغير أثناء تنفيذ المترجم.

val add_dir : hidden:bool -> string -> unit

أضف مجلدًا إلى نهاية مسار التحميل (أي بأدنى أولوية).

val remove_dir : string -> unit

إزالة مجلد من مسار التحميل

val reset : unit -> unit

إزالة جميع المجلدات

module Dir : sig end

type auto_include_callback = (Dir.t -> string -> string option) -> string -> string

نوع دوال الاستدعاء الخاصة بـ init ~auto_include

val no_auto_include : auto_include_callback

لا يوجد تضمين تلقائي للمجلدات: يؤدي فقدان المسارات إلى رفع Not_found كالمعتاد.

val init : auto_include:auto_include_callback -> visible:string list -> hidden:string list -> unit

init ~visible ~hidden هو نفس reset ();
List.iter add_dir (List.rev hidden);
List.iter add_dir (List.rev visible)

val auto_include_otherlibs : (string -> unit) -> auto_include_callback

auto_include_otherlibs alert هي دالة استدعاء يتم تمريرها إلى Load_path.init وتضيف تلقائيًا -I +lib إلى مسار التحميل بعد استدعاء alert lib.

val get_path_list : unit -> string list

إرجاع قائمة المجلدات التي تم تمريرها إلى add_dir حتى الآن.

type paths = {
visible : string list ;
hidden : string list ;
}

val get_paths : unit -> paths

إرجاع المجلدات التي تم تمريرها إلى add_dir حتى الآن.

val find : string -> string

تحديد موقع ملف في مسار التحميل. يرفع Not_found إذا لم يتم العثور على الملف. هذه الدالة محسّنة للحالة التي يكون فيها اسم الملف اسمًا أساسيًا، أي لا يحتوي على فاصل للمجلدات.

val find_normalized : string -> string

نفس find ، ولكن البحث أيضًا عن اسم وحدة قياسي (انظر Misc.normalized_unit_filename )، أي إذا كان الاسم Foo.ml ، يسمح لمطابقة /path/Foo.ml و /path/foo.ml.

type visibility =
| Visible
| Hidden

val find_normalized_with_visibility : string -> string * visibility

نفس find_normalized ، ولكنه يبلغ أيضًا عما إذا تم العثور على cmi في مجلد -I (Visible) أو مجلد -H (Hidden)

val add : Dir.t -> unit

مهمل.

الاسم القديم لـ Load_path.append_dir

val append_dir : Dir.t -> unit

append_dir d يضيف d إلى نهاية مسار التحميل (أي بأدنى أولوية.

val prepend_dir : Dir.t -> unit

prepend_dir d يضيف d إلى بداية مسار التحميل (أي بأعلى أولوية.

val get_visible : unit -> Dir.t list

نفس get_paths () ، باستثناء أنه يُرجع Dir.t list ، ولا يتضمن مسارات -H.
