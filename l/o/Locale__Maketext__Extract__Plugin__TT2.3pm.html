Locale::Maketext::Extract::Plugin::TT2(3) توثيق Perl مساهم من المستخدم Locale::Maketext::Extract::Plugin::TT2(3)

الاسم

Locale::Maketext::Extract::Plugin::TT2 - محلل تنسيق Template Toolkit

الإصدار

الإصدار 1.00

الملخص

$plugin = Locale::Maketext::Extract::Plugin::TT2->new(
    $lexicon            # كائن Locale::Maketext::Extract
    @file_types         # اختياريًا تحديد قائمة بأنواع الملفات المعترف بها
)
$plugin->extract($filename,$filecontents);

الوصف

يستخرج السلاسل النصية لتوطينها من قوالب Template Toolkit.

اسم المكون الإضافي المختصر

tt2

التنسيقات الصالحة

التنسيقات الصالحة هي:

[% |l(args) %]string[% END %]
[% 'string' | l(args) %]
[% l('string',args) %]
[% c.l('string') %]
أيضًا، جميع التركيبات المذكورة أعلاه مع "c." بادئة يجب أن تعمل بشكل صحيح. هذا هو بناء الجملة الافتراضي عند استخدام قوالب TT مع Mojolicious.

l و loc قابلان للتبديل.

| و FILTER قابلان للتبديل.

أنواع الملفات المعروفة

.tt
.tt2
.html
.tt.*
.tt2.*

يتطلب

Template

ملاحظات

  • احذر استخدام صيغة "loc" يمكن أن يعطي نتائج إيجابية خاطئة إذا كنت تستخدم مكون الإضافة Perl الإضافي على ملفات TT. إذا كنت ترغب في استخدام صيغة "loc"، فيجب عليك تحديد أنواع الملفات التي تريد أن يقوم مكون الإضافة Perl الإضافي بتحليلها، أو تمكين أنواع الملفات الافتراضية، على سبيل المثال: 
    xgettext.pl -P perl ....        # أنواع الملفات الافتراضية
xgettext.pl -P perl=pl,pm  ... # أنواع الملفات المحددة
  • يجب أن تكون السلسلة النصية المراد توطينها سلسلة نصية، وليست متغيرًا. نحاول عدم استخراج استدعاءات لدالة التوطين الخاصة بك التي تحتوي على متغيرات، على سبيل المثال: 
    l('string',arg)  # تم استخراجه
l(var,arg)       # لم يتم استخراجه

    هذا لا يعمل مع مرشحات الكتل، لذا لا تفعل ذلك. على سبيل المثال:

    [%  FILTER l %]
   string [% var %]      # سيئ!
[% END %]
  • الحصول على رقم السطر الصحيح صعب في TT. غالبًا ما سيكون نطاقًا من الأسطر، أو قد يتم تجاهله بسبب استخدام PRE_CHOMP أو POST_CHOMP. سيكون دائمًا ضمن بضعة أسطر من الموقع الصحيح.
  • إذا كان لديك PRE/POST_CHOMP ممكّنًا بشكل افتراضي في قوالبك، فيجب عليك استخراج السلاسل النصية باستخدام نفس القيم. لضبطها، يمكنك استخدام البرنامج النصي المساعد التالي: 
    #!/usr/bin/perl
use Locale::Maketext::Extract::Run qw(xgettext);
use Locale::Maketext::Extract::Plugin::TT2();
%Locale::Maketext::Extract::Plugin::TT2::PARSER_OPTIONS = (
     PRE_CHOMP  => 1, # أو 2
     POST_CHOMP => 1, # أو 2
     # أيضًا START/END_TAG, ANYCASE, INTERPOLATE, V1DOLLAR, EVAL_PERL
);
xgettext(@ARGV);
