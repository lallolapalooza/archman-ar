الاسم

Locale::RecodeData::ISO_8859_13 - روتينات التحويل لـ ISO-8859-13

الملخص

هذه الوحدة هي جزء داخلي من libintl. لا تستخدمها مباشرة!

الوصف

هذه الوحدة تم إنشاؤها وتحتوي على جداول وروتينات التحويل لـ ISO-8859-13.

تعليقات

تم استخراج التعليقات التالية من خريطة الأحرف الأصلية:

تم إنشاؤها تلقائيًا من charDB
اسم مستعار ISO-IR-179
اسم مستعار LATIN7
اسم مستعار L7

يرجى ملاحظة أن الأسماء المستعارة المذكورة أعلاه ليست بالضرورة صالحة!

جدول الأحرف

الجدول التالي مرتب بنفس ترتيب خريطة الأحرف الأصلية. جميع رموز الأحرف بالترميز السداسي عشري. يرجى قراءة 'ISO-10646' كـ 'ISO-10646-UCS4'.

Locale::RecodeData::ISO_8859_13(3pm)

NAME

Locale::RecodeData::ISO_8859_13 - character mappings for ISO 8859-13

SYNOPSIS

  use Locale::RecodeData::ISO_8859_13;

DESCRIPTION

This module provides the character mapping tables required for Locale::Recode(3) to translate between ISO 8859-13 (Latin-7) and other character sets.

The mappings are loaded automatically by Locale::Recode(3) when needed.

You should not need to use this module directly.
