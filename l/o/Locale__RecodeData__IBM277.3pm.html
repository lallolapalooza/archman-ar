Locale::RecodeData::IBM277(3) وثائق مساهمة من مستخدم Perl Locale::RecodeData::IBM277(3)

الاسم

Locale::RecodeData::IBM277 - روتينات تحويل لـ IBM277

الملخص

هذه الوحدة داخلية في libintl. لا تستخدمها مباشرة!

الوصف

تحتوي هذه الوحدة على جداول التحويل والروتينات الخاصة بـ IBM277.

تعليقات

الملاحظات التالية مأخوذة من ملف charmap الأصلي:

 الإصدار: 1.0
 المصدر: IBM NLS RM Vol2 SE09-8002-01, مارس 1990
 اسم مستعار EBCDIC-CP-DK
 اسم مستعار EBCDIC-CP-NO

ملاحظة: الأسماء المستعارة المذكورة أعلاه قد لا تكون صالحة بالضرورة!

جدول الأحرف

الجدول التالي مرتب بنفس ترتيب ملف charmap الأصلي. جميع رموز الأحرف بالترميز السداسي عشري. يرجى قراءة 'ISO-10646' على أنها 'ISO-10646-UCS4'.

NAME

Locale::RecodeData::IBM277 — Japanese character set definition.

SYNOPSIS

 use Locale::RecodeData::IBM277;

DESCRIPTION

This module defines the character set IBM-277 (also known as '850' or 'cp850').
