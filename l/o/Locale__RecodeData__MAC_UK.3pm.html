الاسم

Locale::RecodeData::MAC_UK - وظائف التحويل لـ MAC-UK

ملخص

هذه الوحدة داخلية في libintl. لا تستخدمها مباشرة!

الوصف

هذه الوحدة تم إنشاؤها وتحتوي على جداول التحويل وروتينات لـ MAC-UK.

تعليقات

تم استخلاص الملاحظات التالية من charmap الأصلي:

تم إنشاؤه تلقائيًا من charDB

ملاحظة: الأسماء المستعارة المذكورة أعلاه ليست بالضرورة صالحة!

NAME

Locale::RecodeData::MAC_UK — MacRoman (United Kingdom) character set

SYNOPSIS

use Locale::RecodeData::MAC_UK;

DESCRIPTION

This module provides the character set data for the MacRoman (United Kingdom) character encoding.

COMMENTS

This character set is a variant of MacRoman that is used in the United Kingdom.
