NAME

Locale::RecodeData::ISO_8859_9 - Perl module for ISO 8859-9 (Turkish) encoding.

SYNOPSIS

 use Locale::RecodeData::ISO_8859_9;

DESCRIPTION

This module provides the ISO 8859-9 encoding information to the Locale::Recode package.

ISO 8859-9 is the Latin-9 character encoding, also known as ISO 8859-9:1999. It is a 8-bit encoding which is a superset of ASCII and ISO 8859-1. It adds the Turkish letters Ğ, ğ, İ, ı, Ö, ö, Ş, ş.

COMMENTS

This module doesn't export any subroutines. It is only loaded by Locale::Recode when needed.
