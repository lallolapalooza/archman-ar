loc_database_lookup(3)

الحزمة: libloc

التراخيص: LGPL-2.1-or-later

LOC_DATABASE_LOOKUP(3)   LOC_DATABASE_LOOKUP(3)

الاسم

loc_database_lookup - البحث عن شبكة في قاعدة البيانات

الملخص

#include <libloc/database.h>

int loc_database_lookup(struct loc_database* db, const struct in6_addr* address, struct loc_network** network);

int loc_database_lookup_from_string(struct loc_database* db, const char* string, struct loc_network** network);

الوصف

تحاول وظائف البحث العثور على شبكة في قاعدة البيانات.

تأخذ loc_database_lookup عنوان IP بتنسيق struct in6_addr والذي يمكن أن يكون إما عنوان IPv6 عادي أو عنوان IPv4 مدمج.

تأخذ loc_database_lookup_string عنوان IP كنص وستقوم بتحليله تلقائيًا.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. وإلا، يتم إرجاع قيمة غير صفرية ويتم تعيين errno وفقًا لذلك.
