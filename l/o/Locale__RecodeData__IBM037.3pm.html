NAME

Locale::RecodeData::IBM037 - Character set definition for IBM Code Page 037

SYNOPSIS

    use Locale::RecodeData;

DESCRIPTION

Locale::RecodeData::IBM037 is a Perl module that provides definitions for the IBM Code Page 037 character set. It is intended for use with the Locale::Recode module.

Code page 037 is a character encoding that was originally developed by IBM for their mainframe operating systems. It is a superset of ASCII that includes additional characters for national languages, such as those used in Australia, Canada, and the United States.

The module defines the mapping between the IBM Code Page 037 character set and Unicode. This allows for the conversion of text data between different character encodings.

COMMENTS

This module is part of the libintl-perl package, which provides internationalization and localization support for Perl programs.
