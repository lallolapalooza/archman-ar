Locale__Maketext__Lexicon__Msgcat(3pm)

الحزمة: perl-locale-maketext-lexicon

التراخيص: GPL, PerlArtistic

Locale::Maketext::Lexicon::Msgcat(3) وثائق بيرل المساهم بها من قبل المستخدم Locale::Maketext::Lexicon::Msgcat(3)

الاسم

Locale::Maketext::Lexicon::Msgcat - محلل فهرس Msgcat لـ Maketext

الإصدار

الإصدار 1.00

الملخص

package Hello::I18N;
use base 'Locale::Maketext';
use Locale::Maketext::Lexicon {
    en => ['Msgcat', 'en_US/hello.pl.m'],
};
package main;
my $lh = Hello::I18N->get_handle('en');
print $lh->maketext(1,2);   # تعيين 1، رسالة 2
print $lh->maketext("1,2"); # نفس الشيء

الوصف

تقوم هذه الوحدة بتحليل فهرس Msgcat واحد أو أكثر بتنسيق النص العادي، وتعيد هاش Lexicon، والذي يمكن البحث فيه إما باستخدام شكل ذي وسيطين ("$set_id, $msg_id") أو كسلسلة واحدة ("$set_id,$msg_id").

ملاحظات

سيتم إخفاء جميع الأحرف الخاصة ("["، "]"، و "~") في الفهارس بحيث تفقد معانيها السحرية. هذا يعني أن استدعاءات "->maketext" لهذا الفهرس لن تأخذ أي وسائط إضافية.

انظر أيضًا

Locale::Maketext, Locale::Maketext::Lexicon
