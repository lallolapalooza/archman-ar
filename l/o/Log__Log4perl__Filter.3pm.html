Log__Log4perl__Filter(3pm)

NOMBRE

Log::Log4perl::Filter::MyFilter - Un filtro de ejemplo simple

SINOPSIS

  use Log::Log4perl::Filter::MyFilter;

  my $filter = Log::Log4perl::Filter::MyFilter->new(
      name  => "MyFilter",
      color => "red",
  );
  $filter->set_level( $DEBUG );

  # ... si el nivel del mensaje es DEBUG y el color es 'red'
  #     entonces ok() devolverá true
  if ( $filter->ok( $event ) ) {
      # ... registrar el mensaje ...
  }

DESCRIPCIÓN

Este es un filtro de ejemplo simple que muestra cómo implementar un filtro personalizado. Se basa en un atributo llamado color, que debe ser establecido al inicializar el filtro.

Cuando Log::Log4perl procesa la configuración y encuentra una entrada como esta:

log4perl.filter.MyFilter       = Log::Log4perl::Filter::MyFilter
log4perl.filter.MyFilter.color = red

esto causará la invocación de:

Log::Log4perl::Filter::MyFilter->new( name  => "MyFilter",
                                      color => "red" );

La clase de filtro personalizada debe utilizar esto para establecer los atributos del objeto, para que estén disponibles más tarde para tomar decisiones sobre registrar/no registrar según ellos.

ok() es el método del filtro para indicar si el mensaje debe registrarse o no. Será llamado por Log::Log4perl cuando necesite que el filtro tome la decisión. Un valor falso devuelto por ok() bloqueará los mensajes, un valor verdadero permitirá que pasen.
