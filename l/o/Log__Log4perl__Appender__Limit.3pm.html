Log__Log4perl__Appender__Limit(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Appender::Limit(3) توثيق مساهمات مستخدمي Perl Appender::Limit(3)

الاسم

Log::Log4perl::Appender::Limit - تحديد تسليم الرسائل عبر فترة حظر

الملخص

use Log::Log4perl qw(:easy);
my $conf = qq(
  log4perl.category = WARN, Limiter

      # ملحق البريد الإلكتروني
  log4perl.appender.Mailer          = Log::Dispatch::Email::MailSend
  log4perl.appender.Mailer.to       = drone\@pageme.com
  log4perl.appender.Mailer.subject  = Something's broken!
  log4perl.appender.Mailer.buffered = 0
  log4perl.appender.Mailer.layout   = PatternLayout
  log4perl.appender.Mailer.layout.ConversionPattern=%d %m %n
      # ملحق الحد، باستخدام ملحق البريد الإلكتروني أعلاه
  log4perl.appender.Limiter              = Log::Log4perl::Appender::Limit
  log4perl.appender.Limiter.appender     = Mailer
  log4perl.appender.Limiter.block_period = 3600
);
Log::Log4perl->init(\$conf);
WARN("This message will be sent immediately.");
WARN("This message will be delayed by one hour.");
sleep(3601);
WARN("This message plus the last one will be sent now, seperately.");

الوصف

"appender"
يحدد اسم الملحق المستخدم بواسطة المحدد. يجب تعريف الملحق المحدد في مكان ما في ملف التكوين، وليس بالضرورة قبل تعريف "Log::Log4perl::Appender::Limit".
"block_period"
فترة بالثواني بين تسليم الرسائل. إذا وصلت رسائل في تلك الأثناء، فسيتم حفظها (إذا تم تعيين "accumulate" إلى قيمة صحيحة) أو تجاهلها (إذا لم يتم تعيين "accumulate").
"persistent"
اسم الملف الذي يقوم فيه "Log::Log4perl::Appender::Limit" بتخزين أوقات التسليم بشكل دائم. إذا تم حذفه، فلن يتذكر الملحق ما حدث عند إعادة تشغيل البرنامج.
"max_until_flushed"
الحد الأقصى لعدد الرسائل المتراكمة. إذا تجاوز ذلك، سيقوم الملحق بإخراج جميع الرسائل، بغض النظر عما إذا كانت الفترة المحددة في "block_period" قد مرت أم لا. لا تخلط مع "max_until_discarded".
"max_until_discarded"
الحد الأقصى لعدد الرسائل المتراكمة. إذا تجاوز ذلك، سيقوم الملحق ببساطة بتجاهل الرسائل الإضافية، في انتظار انتهاء "block_period" لإخراج جميع الرسائل المتراكمة. لا تخلط مع "max_until_flushed".
"appender_method_on_flush"
اسم طريقة اختياري يتم استدعاؤها على الملحق المتصل بالمحدد عند إخراج الرسائل. على سبيل المثال، لجعل التعليمات البرمجية النموذجية في قسم الملخص تجمع رسائل البريد الإلكتروني المخزنة مؤقتًا في رسالة واحدة، قم بتغيير معلمة الملحق "buffered" إلى 1 وقم بتعيين قيمة المحدد "appender_method_on_flush" إلى السلسلة "flush": 
log4perl.category = WARN, Limiter

    # ملحق البريد الإلكتروني
log4perl.appender.Mailer          = Log::Dispatch::Email::MailSend
log4perl.appender.Mailer.to       = drone\@pageme.com
log4perl.appender.Mailer.subject  = Something's broken!
log4perl.appender.Mailer.buffered = 1
log4perl.appender.Mailer.layout   = PatternLayout
log4perl.appender.Mailer.layout.ConversionPattern=%d %m %n
    # ملحق الحد، باستخدام ملحق البريد الإلكتروني أعلاه
log4perl.appender.Limiter              = Log::Log4perl::Appender::Limit
log4perl.appender.Limiter.appender     = Mailer
log4perl.appender.Limiter.block_period = 3600
log4perl.appender.Limiter.appender_method_on_flush = flush

سيؤدي هذا إلى قيام المرسل بتخزين الرسائل مؤقتًا والانتظار حتى تقوم flush() بإرسال المجموعة بأكملها. سيقوم المحدد بعد ذلك باستدعاء طريقة flush() الخاصة بالملحق عند إخراج مخزنه المؤقت.

إذا كان الملحق المتصل بـ "Limit" يستخدم "PatternLayout" مع محدد طابع زمني، فستلاحظ أن طوابع الرسائل الزمنية تعكس حدث التسجيل الأصلي، وليس وقت عرض الرسالة في الملحق المتصل. تم تطبيق حيل كبيرة لتحقيق ذلك (سعال!).

ملاحظات التطوير

"Log::Log4perl::Appender::Limit" هو ملحق *مركب*. على عكس الملحقات الأخرى، لا يقوم بتسجيل أي رسائل، بل يمررها ببساطة إلى الملحق الفرعي المرفق به. لهذا السبب، لا يحتاج إلى تخطيط (على عكس الملحقات العادية). إذا لم يحدد أيًا منها، يتم تمرير الرسائل دون تغيير.

تُطبق المرشحات المخصصة أيضًا على الملحق المركب فقط. لا يتم تطبيقها على الملحق الفرعي. ينطبق الشيء نفسه على عتبات الملحق. قد يتغير هذا السلوك في المستقبل.
