NAME

Locale::RecodeData::MACGREEK - MAC Greek encoding

SYNOPSIS

use Locale::RecodeData ::MACGREEK;

DESCRIPTION

This module provides the MAC Greek encoding as a Perl Locale::Recode data file.

MAC Greek is a character set developed by Apple for their Macintosh computers.
