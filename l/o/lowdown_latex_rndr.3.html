lowdown_latex_rndr(3)

الحزمة: lowdown

التراخيص: ISC

LOWDOWN_LATEX_RNDR(3) دليل الوظائف المكتبية LOWDOWN_LATEX_RNDR(3)

الاسم

lowdown_latex_rndr — تصيير Markdown إلى LaTeX

المكتبة

المكتبة "liblowdown"

ملخص

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_latex_rndr(struct lowdown_buf *out, void *arg, const struct lowdown_node *n);

الوصف

يقوم بتصيير شجرة عقد n التي تم إنشاؤها بواسطة lowdown_doc_parse(3) أو lowdown_diff(3) باستخدام مصيّر LaTeX arg كما تم إرجاعه بواسطة lowdown_latex_new(3). يتم كتابة الخرج في out، والذي يجب أن يتم تهيئته وتحريره بواسطة المتصل.

قيم الإرجاع

يعيد صفرًا عند الفشل في تخصيص الذاكرة، ويعيد قيمة غير صفرية عند النجاح.

أمثلة

يقوم المثال التالي بتحليل b بطول bsz ويخرج بتنسيق LaTeX.

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_latex_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_latex_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_latex_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);
