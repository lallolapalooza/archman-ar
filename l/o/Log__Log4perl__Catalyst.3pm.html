Log__Log4perl__Catalyst(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Catalyst(3) وثائق مساهمة من المستخدمين بلغة Perl Catalyst(3)

الاسم

Log::Log4perl::Catalyst - وحدة Log4perl لـ Catalyst

ملخص

في وحدة تطبيق Catalyst الرئيسية لديك:

use Log::Log4perl::Catalyst;
  # إما اجعل Log4perl يتصرف مثل مسجل Catalyst الافتراضي:
__PACKAGE__->log(Log::Log4perl::Catalyst->new());
  # أو استخدم ملف تكوين Log4perl، مع الاستفادة الكاملة
  # من وظائف Log4perl
__PACKAGE__->log(Log::Log4perl::Catalyst->new('l4p.conf'));

... ثم قم بنثر عبارات التسجيل في جميع أنحاء أي كود يتم تنفيذه بواسطة Catalyst:

$c->log->debug("هذا يستخدم log4perl!");

الوصف

توفر هذه الوحدة وظائف Log4perl لتطبيقات Catalyst. تم استلهامها من Catalyst::Log::Log4perl على CPAN، ولكن تمت إعادة كتابتها بالكامل وتستخدم نهجًا مختلفًا لتوحيد Catalyst و Log4perl.

يوفر Log4perl مسجلات، مرتبطة عادةً بالحزمة الحالية، والتي يمكن بعد ذلك التحكم فيها عن بعد بواسطة تكوين مركزي. هذا يعني أنه إذا كان لديك دالة تحكم مثل

package MyApp::Controller::User;
sub add : Chained('base'): PathPart('add'): Args(0) {
    my ( $self, $c ) = @_;
    $c->log->info("إضافة مستخدم");
    # ...
}

يتوفر التحكم المستند إلى المستوى عبر الطرق التالية:

$c->log->debug("قراءة التكوين");
$c->log->info("إضافة مستخدم");
$c->log->warn("تعذر قراءة التكوين ($!)");
$c->log->error("تعذر إضافة المستخدم ", $user);
$c->log->fatal("قاعدة البيانات معطلة، إلغاء الطلب");

ولكن هذا ليس كل شيء، Log4perl أكثر قوة بكثير.

يمكن إخفاء عبارة التسجيل أو تنشيطها بناءً على ملف Log4perl يبدو كالتالي

  # جميع مسجلات MyApp مفتوحة لـ DEBUG وما فوق
log4perl.logger.MyApp = DEBUG, Screen
# ...

أو

  # جميع المسجلات تحظر الرسائل الأقل من INFO
log4perl.logger=INFO, Screen
# ...

على التوالي. راجع صفحة دليل Log4perl لمعرفة كيفية إجراء تصفية دقيقة لمستوى التسجيل والموقع، وكيفية إعادة توجيه الرسائل ليس فقط إلى الشاشة أو إلى ملفات السجل، ولكن أيضًا إلى قواعد البيانات، ومرسلات البريد الإلكتروني، وغير ذلك الكثير.

أيضًا، يمكنك تغيير تنسيق الرسالة. على سبيل المثال إذا كنت تريد معرفة مكان تسجيل عبارة معينة، قم بتشغيل أسماء الملفات وأرقام الأسطر:

# ملف تكوين Log4perl
# ...
log4perl.appender.Screen.layout.ConversionPattern = \
      %F{1}-%L: %p %m%n

ستبدو الرسائل بعد ذلك كالتالي

MyApp.pm-1869: INFO حفظ ملف تعريف المستخدم للمستخدم "wonko"

أو هل تريد تسجيل عنوان IP للطلب مع كل عبارة تسجيل؟ لا مشكلة مع Log4perl، فقط قم باستدعاء

Log::Log4perl::MDC->put( "ip", $c->req->address() );

في بداية دورة الطلب واستخدم

# ملف تكوين Log4perl
# ...
log4perl.appender.Screen.layout.ConversionPattern = \
      [%d]-%X{ip} %F{1}-%L: %p %m%n

كتنسيق Log4perl. ستبدو الرسائل كالتالي

[2010/02/22 23:25:55]-123.122.108.10 MyApp.pm-1953: INFO قراءة ملف تعريف للمستخدم "wonko"

مرة أخرى، تحقق من صفحة دليل Log4perl، هناك وفرة من خيارات التكوين.

طرق

new($config, [%options])
إذا تم استدعاؤها بدون معلمات، يقوم new() بتهيئة Log4perl بطريقة تجعل الرسائل تسجل بشكل مشابه لآلية التسجيل الافتراضية لـ Catalyst. إذا قمت بتوفير تكوين، سواء كان اسم ملف تكوين أو مرجعًا لسلسلة نصية تحتوي على التكوين، فسيقوم باستدعاء Log4perl بهذه المعلمات.

المعلمة الثانية (الاختيارية) هي قائمة من أزواج المفتاح/القيمة:

'autoflush'   =>  1   # سجل بدون تخزين مؤقت (لا يدعم 'abort')
'watch_delay' => 30   # إذا تم تعيينه، استخدم L<Log::Log4perl>'s init_and_watch
_flush()
يقوم بتفريغ ذاكرة التخزين المؤقت للنظام.
abort($abort)
يمسح المخازن المؤقتة الداخلية لنظام التسجيل دون تسجيل أي شيء.

استخدام وحدات الماكرو :easy مع Catalyst

إذا كنت قد سئمت من كتابة

$c->log->debug("...");

وتفضل استخدام أوضاع وحدات الماكرو المريحة لـ Log4perl مثل

DEBUG "...";

فقط قم بسحب هذه الوحدات عبر وضع :easy في Log::Log4perl وابدأ في العمل:

use Log::Log4perl qw(:easy);
  # ... استخدم وحدات الماكرو لاحقًا
sub base :Chained('/') :PathPart('apples') :CaptureArgs(0) {
    my ( $self, $c ) = @_;
    DEBUG "معالجة التفاح";
}

لاحظ الفرق بين تهيئة Log4perl في Catalyst، والتي تستخدم وحدة Log::Log4perl::Catalyst الخاصة بـ Catalyst (في أعلى هذه الصفحة)، واستخدام مسجلات Log4perl مع مسجلات ووحدات الماكرو القياسية لـ Log::Log4perl. بينما تتطلب التهيئة قيام Log4perl بأداء سحر مظلم للتوافق مع استراتيجية التسجيل المختلفة لـ Catalyst، فإن الحصول على كائنات المسجل الخاصة بـ Log4perl أو استدعاء وحدات الماكرو الخاصة بها لم يتغير.

بدلاً من استخدام طريقة Catalyst للإشارة إلى كائن "السياق" $c للحصول على مراجع المسجل عبر طريقة log() الخاصة به، يمكنك بنفس القدر استخدام get_logger() الخاص بـ Log4perl أو وحدات الماكرو للوصول إلى مسجلات Log4perl الفردية. النتيجة هي نفسها.
