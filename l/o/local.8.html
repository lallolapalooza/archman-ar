NAME

local — delivery agent for local delivery

SYNOPSIS

    postdrop -r "user@example.com"
    /usr/sbin/postfix local [generic-options]

DESCRIPTION

The local delivery agent handles mail delivery for local recipients. It is responsible for handling Postfix-specific delivery features such as virtual domains, aliasing, mail forwarding, and mailbox delivery.

The local agent is typically invoked by the smtpd process or by the qmgr process.

CASE FOLDING

Except for the local delivery agent, all other Postfix commands and daemons fold case for domain names in internet addresses. The local delivery agent preserves case for domain names.

SYSTEM-WIDE AND USER-LEVEL ALIASING

The local agent can expand system-wide aliases (specified in ~/.forward file).

When local processes an address like user+tag@example.com, it can optionally send mail to ~/.forward-tag, or to a file named ~/.forward with the contents of the tag appended.

MAIL FORWARDING

When local finds a ~/.forward file in a recipient's home directory, it will try to forward the mail to the destination(s) specified in that file. The ~/.forward file can contain a list of addresses, filenames, or command specifications.

If the ~/.forward file contains a list of addresses, each address is delivered to.

If the ~/.forward file contains a filename, the mail is appended to that file.

If the ~/.forward file contains a command, the mail is piped to that command.

MAILBOX DELIVERY

If no ~/.forward file is found, and the recipient is not an alias, local will attempt to deliver the mail to the recipient's mailbox. By default, this is the file /var/spool/mail/user.

EXTERNAL COMMAND DELIVERY

When local is configured to use an external command for delivery (e.g., via .forward or an alias definition), it executes the command with the mail content piped to its standard input.

EXTERNAL FILE DELIVERY

When local is configured to deliver mail to an external file (e.g., via .forward or an alias definition), it appends the mail content to the specified file.

ADDRESS EXTENSION

The local agent supports address extensions, which are parts of an email address that follow a + or other delimiter character. These extensions can be used to route mail to specific sub-addresses or files.

DELIVERY RIGHTS

The local agent checks if the recipient's home directory exists and is accessible before attempting delivery. It also checks if it has the necessary permissions to write to the mailbox or append to the forward file.

STANDARDS

The local agent aims to comply with relevant RFC standards for mail delivery and aliasing.

DIAGNOSTICS

Diagnostic messages are logged to syslogd(8) with the facility mail. Errors typically indicate permission problems, non-existent directories, or invalid configuration settings.

SECURITY

The local agent runs with the privileges of the recipient user when performing actions like reading ~/.forward or delivering to a user's mailbox. This helps prevent privilege escalation.

The local agent does not execute arbitrary commands specified in alias files or ~/.forward files unless explicitly configured to do so and with appropriate security considerations.

BUGS

The local agent's behavior with complex alias and forwarding configurations can sometimes be intricate. Refer to the Postfix documentation for detailed explanations and examples.
