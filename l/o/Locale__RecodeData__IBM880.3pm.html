Locale__RecodeData__IBM880(3pm)

الحزمة: perl-libintl-perl

التراخيص: LGPL

الاسم

Locale::RecodeData::IBM880 - وحدة لتشفير IBM Code Page 00880.

ملخص

    require Locale::RecodeData::IBM880;
    1;

الوصف

تُقدم هذه الوحدة ملفات بيانات التشفير لـ IBM Code Page 00880. تم إنشاؤها بواسطة recode-config.

تُستخدم هذه الوحدة داخليًا بواسطة Locale::Recode عند الحاجة إلى تحويلات تتضمن IBM-880.

تعليقات

هذا هو وصف مختصر لـ IBM Code Page 00880.
