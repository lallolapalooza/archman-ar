local(n)

الحزمة: tcl

التراخيص: TCL

local(n) [incr Tcl] local(n)

الاسم

itcl::local - إنشاء كائن محلي للإجراء

الملخص

itcl::local اسم_الفئة اسم_الكائن ?وسيط وسيط ...?

الوصف

يقوم الأمر local بإنشاء كائن [incr Tcl] يكون محليًا لإطار الاستدعاء الحالي. عندما يختفي إطار الاستدعاء، يتم حذف الكائن تلقائيًا. هذا الأمر مفيد لإنشاء كائنات محلية للإجراء.

كنتيجة جانبية، ينشئ هذا الأمر متغيرًا اسمه "itcl-local-xxx"، حيث xxx هو اسم الكائن الذي يتم إنشاؤه. هذا المتغير يكتشف متى يتم تدمير إطار الاستدعاء ويقوم تلقائيًا بحذف الكائن المرتبط به.

مثال

في المثال التالي، يتم استخدام كائن "عداد" بسيط داخل الإجراء "test". يتم إنشاء العداد ككائن محلي، لذا يتم حذفه تلقائيًا في كل مرة يخرج فيها الإجراء. عبارات puts المضمنة في المنشئ/الهادم تظهر الكائن يأتي ويذهب مع استدعاء الإجراء.

itcl::class counter {
    private variable count 0
    constructor {} {
        puts "تم الإنشاء: $this"
    }
    destructor {
        puts "تم الحذف: $this"
    }
    method bump {{by 1}} {
        incr count $by
    }
    method get {} {
        return $count
    }
}
proc test {val} {
    local counter x
    for {set i 0} {$i < $val} {incr i} {
        x bump
    }
    return [x get]
}
set result [test 5]
puts "test: $result"
set result [test 10]
puts "test: $result"
puts "الكائنات: [itcl::find objects *]"
