NAME

Locale::RecodeData::ISO_8859_15 - ISO 8859-15 (Latin-9) encoding

SYNOPSIS

 use Locale::RecodeData::ISO_8859_15;
 my $recode_data = Locale::RecodeData::ISO_8859_15->new();

DESCRIPTION

This module provides the ISO 8859-15 character set information for the Locale::Recode module.

ISO 8859-15 is a 8-bit character encoding that is a modified version of ISO 8859-14. It includes the Euro sign (€) and some characters that are frequently used in Western European languages.

COMMENTS

The Euro sign (U+20AC) is located at code 0xA4 in ISO 8859-15, replacing the general currency sign (¤) found at the same position in ISO 8859-1.
