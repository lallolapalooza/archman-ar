lowdown_file_diff(3)

الحزمة: lowdown

التراخيص: ISC

LOWDOWN_FILE_DIFF(3) دليل الوظائف المكتبية LOWDOWN_FILE_DIFF(3)

الاسم

lowdown_file_diff — تحليل ومقارنة ملفات Markdown إلى مخرجات منسقة

المكتبة

المكتبة “liblowdown”

الملخص

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

int
lowdown_file_diff(const struct lowdown_opts *opts, FILE *fnew, FILE *fold, char **ret, size_t *retsz);

الوصف

يقوم بتحليل تدفقات الملفات lowdown(5) fnew و fold وينتج نص برمجي للتعديل في ret بحجم retsz وفقًا للتكوينات opts. يتم تحديد تنسيق الإخراج بواسطة opts->type.

عند النجاح، يكون المستدعي مسؤولاً عن تحرير ret.

قيم الإرجاع

يعيد صفرًا عند الفشل، وغير صفر عند النجاح. يحدث الفشل عند فشل قراءة الملف أو عند استنفاد الذاكرة. عند الفشل، تكون محتويات ret و retsz غير محددة.
