Locale::Maketext::Simple(3perl) دليل مبرمجي Perl Locale::Maketext::Simple(3perl)

الاسم

Locale::Maketext::Simple - واجهة بسيطة لـ Locale::Maketext::Lexicon

الإصدار

توثق هذه الوثيقة الإصدار 0.18 من Locale::Maketext::Simple، الذي صدر في 8 سبتمبر 2006.

ملخص

إعداد بسيط (يبحث عن auto/Foo/*.po و auto/Foo/*.mo):

package Foo;
use Locale::Maketext::Simple;       # يستورد 'loc'
loc_lang('fr');                     # تعيين اللغة إلى الفرنسية
sub hello {
    print loc("Hello, [_1]!", "World");
}

مثال أكثر تعقيدًا:

package Foo::Bar;
use Locale::Maketext::Simple (
    Class       => 'Foo',       # البحث في auto/Foo/
    Style       => 'gettext',   # %1 بدلاً من [_1]
    Export      => 'maketext',  # maketext() بدلاً من loc()
    Subclass    => 'L10N',      # Foo::L10N بدلاً من Foo::I18N
    Decode      => 1,           # فك تشفير الإدخالات إلى سلاسل unicode
    Encoding    => 'locale',    # ولكن تشفير القواميس باللغة المحلية الحالية
                                # (يتطلب Locale::Maketext::Lexicon 0.36)
);
sub japh {
    print maketext("Just another %1 hacker", "Perl");
}

الوصف

هذه الوحدة هي غلاف بسيط حول Locale::Maketext::Lexicon، مصممة لتخفيف الحاجة إلى إنشاء فئات اللغات لمؤلفي الوحدات.

يتم اختيار اللغة المستخدمة من استدعاء loc_lang. إذا لم يكن البحث ممكنًا، فسيتم استخدام اللغة الافتراضية (i-default). إذا لم يكن البحث باللغة الافتراضية، فسيتم إرجاع المفتاح.

إذا لم تكن Locale::Maketext::Lexicon موجودة، فإنها تنفذ وظيفة ترجمة بسيطة عن طريق استيفاء "[_1]" بالوسيط الأول، "[_2]" بالوسيط الثاني، وهكذا. يتم التعامل مع الوظائف المستوفاة مثل "[quant,_1]" على أنها "[_1]"، مع الاستثناء الوحيد لـ "[tense,_1,X]"، والتي ستلحق "ing" بـ "_1" عندما تكون X "present"، أو تلحق "ed" بـ <_1> بخلاف ذلك.

خيارات

يتم تمرير جميع الخيارات إما عبر عبارة "use"، أو عبر "import" صريح.

Class

بشكل افتراضي، تستمد Locale::Maketext::Simple مصدرها من الدليل auto/ للحزمة التي تم استدعاؤها؛ يمكنك تجاوز هذا السلوك عن طريق تحديد حزمة أخرى بشكل صريح كـ "Class".

Path

إذا كانت ملفات PO و MO الخاصة بك موجودة في مسار آخر غير "auto/"، يمكنك تحديدها باستخدام خيار "Path".

Style

بشكل افتراضي، تستخدم هذه الوحدة نمط "maketext" من "[_1]" و "[quant,_1]" للاستيفاء. بدلاً من ذلك، يمكنك تحديد نمط "gettext"، الذي يستخدم %1 و %quant(%1) للاستيفاء.

هذا الخيار غير حساس لحالة الأحرف.

Export

بشكل افتراضي، تقوم هذه الوحدة بتصدير وظيفة واحدة، "loc"، إلى مساحة اسم المستدعي. يمكنك تعيينها إلى اسم آخر، أو تعيينها إلى سلسلة فارغة لتعطيل التصدير.

Subclass

بشكل افتراضي، تنشئ هذه الوحدة فئة فرعية "::I18N" تحت حزمة المستدعي (أو الحزمة المحددة بواسطة "Class")، وتخزن بيانات القاموس في فئاتها الفرعية. يمكنك تعيين اسم آخر غير "I18N" عبر هذا الخيار.

Decode

إذا تم تعيينه إلى قيمة صحيحة، فسيتم تحويل الإدخالات المصدر إلى سلاسل utf8 (متاحة في Perl 5.6.1 أو أحدث). تتطلب هذه الميزة وحدة Encode أو Encode::compat.

Encoding

يحدد ترميزًا لتخزين إدخالات القاموس، بدلاً من سلاسل utf8. إذا تم تعيينه إلى "locale"، يتم استخدام الترميز من إعداد اللغة المحلية الحالي. يتضمن قيمة صحيحة لـ "Decode".
