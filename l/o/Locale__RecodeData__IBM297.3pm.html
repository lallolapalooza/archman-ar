NAME

Locale::RecodeData::IBM297 - Recode from code page 297 (CP297) to Unicode.

SYNOPSIS

    use Locale::RecodeData::IBM297;

    # The following are typical uses:
    # Locale::RecodeData::IBM297->new('IBM297');
    # Locale::Recode->new('IBM297');
    # Locale::Recode->new('297');
    # Locale::Recode->new(297);

DESCRIPTION

This module provides the recode data for code page 297 (also known as CP297, 297, or IBM-297). Code page 297 is used for French Canadian.

This module is used by the Locale::Recode(3) module. You usually do not need to use it directly.

COMMENTS

This module is supposed to map to the ISO 8859-1 (Latin-1) character set.
