NAME

Locale::RecodeData::CP1251 - Cyrillic encoding (Windows-1251)

SYNOPSIS

    use Locale::RecodeData::CP1251;

    # Encode a string
    my $encoded = Locale::Recode->new('cp1251')->string_to_codepoint($string);

    # Decode a string
    my $decoded = Locale::Recode->new('cp1251')->codepoint_to_string($codepoint_string);

DESCRIPTION

This module provides the mapping between the Unicode codepoints and the Windows-1251 character encoding (also known as CP1251, Cyrillic). This module is intended to be used by the Locale::Recode module and should not be used directly.

The mapping is based on the data provided by the Recode project.

The following tables show the mapping between Unicode codepoints and Windows-1251 characters.
