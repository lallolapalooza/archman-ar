التراخيص: BSD-2-Clause, BSD-3-Clause, BSD-4-Clause-UC, GPL-2.0-only, GPL-2.0-or-later, GPL-3.0-or-later, ISC, LGPL-2.1-or-later, LicenseRef-PublicDomain

LOSETUP(8) إدارة النظام LOSETUP(8)

الاسم

losetup - إعداد أجهزة الحلقة والتحكم بها

التركيب

الحصول على المعلومات:

losetup [loopdev]

losetup -l [-a]

losetup -j file [-o offset]

فصل جهاز حلقة:

losetup -d loopdev ...

فصل جميع أجهزة الحلقة المرتبطة:

losetup -D

إعداد جهاز حلقة:

losetup [-o offset] [--sizelimit size] [--sector-size size] [--loop-ref name] [-Pr] [--show] -f|loopdev file

تغيير حجم جهاز حلقة:

losetup -c loopdev

الوصف

يُستخدم losetup لربط أجهزة الحلقة بملفات عادية أو أجهزة كتل، ولفصل أجهزة الحلقة، والاستعلام عن حالة جهاز حلقة. إذا تم إعطاء الوسيطة loopdev فقط، فسيتم عرض حالة جهاز الحلقة المقابل. إذا لم يتم إعطاء أي خيار، فسيتم عرض جميع أجهزة الحلقة.

لاحظ أن تنسيق الإخراج القديم (أي losetup -a) مع السلاسل المفصولة بفواصل أصبح مهجورًا لصالح تنسيق الإخراج --list.

من الممكن إنشاء المزيد من أجهزة الحلقة المستقلة لنفس الملف الخلفي. قد يكون هذا الإعداد خطيرًا، ويمكن أن يتسبب في فقدان البيانات والتلف والكتابة فوقها. استخدم --nooverlap مع --find أثناء الإعداد لتجنب هذه المشكلة.

إعداد جهاز الحلقة ليس عملية ذرية عند استخدامه مع --find، ولا يحمي losetup هذه العملية بأي قفل. عدد المحاولات مقيد داخليًا بحد أقصى 16. يُوصى باستخدام flock(1) على سبيل المثال لتجنب التصادم في حالات الاستخدام المتوازية بكثافة.

الخيارات

قد تتبع الوسيطتين size وoffset لواحق مضاعفة KiB (=1024)، MiB (=1024*1024)، وهكذا لـ GiB وTiB وPiB وEiB وZiB وYiB (اللاحقة "iB" اختيارية، على سبيل المثال، "K" لها نفس معنى "KiB") أو اللواحق KB (=1000)، MB (=1000*1000)، وهكذا لـ GB وTB وPB وEB وZB وYB.

-a، --all

عرض حالة جميع أجهزة الحلقة. لاحظ أنه ليست كل المعلومات متاحة للمستخدمين غير الجذر. انظر أيضًا --list. تنسيق الإخراج القديم (كما يُطبع بدون --list) أصبح مهجورًا.

-d، --detach loopdev...

فصل الملف أو الجهاز المرتبط بجهاز (أجهزة) الحلقة المحددة. لاحظ أنه منذ Linux v3.7 تستخدم نواة النظام "تدمير الجهاز الكسول". لم تعد عملية الفصل تُرجع خطأ EBUSY إذا كان الجهاز مستخدمًا بنشاط من قبل النظام، ولكن يتم وضع علامة عليه بعلم المسح التلقائي ويتم تدميره لاحقًا. حتى إذا لم يكن الجهاز قيد الاستخدام، يمكن تدمير جهاز الحلقة لاحقًا. إذا كنت بحاجة إلى الانتظار حتى الإزالة الكاملة لجهاز الحلقة، فاستدعِ udevadm settle بعد losetup.

-D، --detach-all

فصل جميع أجهزة الحلقة المرتبطة.

-f، --find [file]

العثور على أول جهاز حلقة غير مستخدم. إذا كانت الوسيطة file موجودة، فاستخدم الجهاز الذي تم العثور عليه كجهاز حلقة. وإلا، فاطبع اسمه فقط.

--show

عرض اسم جهاز الحلقة المعين إذا كان الخيار -f والوسيطة file موجودين.

-L، --nooverlap

التحقق من التعارضات بين أجهزة الحلقة لتجنب الحالة التي يتم فيها مشاركة نفس الملف الخلفي بين المزيد من أجهزة الحلقة. إذا كان الملف مستخدمًا بالفعل بواسطة جهاز آخر، فأعد استخدام الجهاز بدلاً من جهاز جديد. لا يكون الخيار منطقيًا إلا مع --find.

-j، --associated file [-o offset]

عرض حالة جميع أجهزة الحلقة المرتبطة بـ file المحدد.

-o، --offset offset

يتم نقل بداية البيانات بمقدار offset بايت داخل الملف أو الجهاز المحدد. قد تتبع offset اللواحق المضاعفة؛ انظر أعلاه.

--loop-ref string

تعيين سلسلة مرجعية. الافتراضي المتوافق مع الإصدارات السابقة هو استخدام اسم الملف الخلفي كمرجع في ioctl إعداد الحلقة (المعروف أيضًا باسم lo_file_name). يمكن لهذا الخيار تجاوز هذا السلوك الافتراضي وتعيين المرجع إلى string. قد يُستخدم المرجع بواسطة udevd في /dev/loop/by-ref. لا تستخدم نواة Linux المرجع على الإطلاق، ولكن قد تستخدمه بعض الأدوات القديمة التي لا يمكنها قراءة الملف الخلفي من sysfs. المرجع قابل للقراءة فقط للمستخدم الجذر (انظر --output +REF) وهو مقيد بـ 64 بايت.

--sizelimit size

يتم تعيين نهاية البيانات إلى ما لا يزيد عن size بايت بعد بداية البيانات. قد تتبع size اللواحق المضاعفة؛ انظر أعلاه.

-b، --sector-size size

تعيين حجم القطاع المنطقي لجهاز الحلقة بالبايت (منذ Linux 4.14). يمكن استخدام الخيار عند إنشاء جهاز حلقة جديد بالإضافة إلى كونه أمرًا مستقلًا لتعديل حجم القطاع لجهاز الحلقة الموجود بالفعل.

-c، --set-capacity loopdev

إجبار برنامج تشغيل الحلقة على إعادة قراءة حجم الملف المرتبط بجهاز الحلقة المحدد.

-P، --partscan

إجبار النواة على فحص جدول الأقسام على جهاز حلقة تم إنشاؤه حديثًا. لاحظ أن تحليل جدول الأقسام يعتمد على أحجام القطاعات. الافتراضي هو حجم القطاع 512 بايت، وإلا فستحتاج إلى استخدام الخيار --sector-size مع --partscan.

-r، --read-only

إعداد جهاز حلقة للقراءة فقط.

--direct-io[=on|off]

تمكين أو تعطيل الإدخال/الإخراج المباشر للملف الخلفي. الافتراضي هو off. تحديد --direct-io أو --direct-io=on سيؤدي إلى تمكينه. ولكن، يمكن توفير --direct-io=off لإيقافه صراحةً.

-v، --verbose

الوضع المطوّل.

-l، --list

إذا تم تحديد جهاز حلقة أو الخيار -a، فاطبع الأعمدة الافتراضية إما لجهاز الحلقة المحدد أو لجميع أجهزة الحلقة؛ الافتراضي هو طباعة معلومات حول جميع الأجهزة. انظر أيضًا --output و--noheadings و--raw و--json.

-O، --output column[,column]...

تحديد الأعمدة التي سيتم طباعتها لإخراج --list. استخدم --help للحصول على قائمة بجميع الأعمدة المدعومة.

--output-all

إخراج جميع الأعمدة المتاحة.

-n، --noheadings

عدم طباعة العناوين لتنسيق إخراج --list.

--raw

استخدام تنسيق إخراج --list الخام.

-J، --json

استخدام تنسيق JSON لإخراج --list.

التشفير

لم يعد Cryptoloop مدعومًا لصالح dm-crypt. لمزيد من التفاصيل انظر cryptsetup(8).

حالة الخروج

يُرجع losetup القيمة 0 عند النجاح، وقيمة غير صفرية عند الفشل. عندما يعرض losetup حالة جهاز حلقة، فإنه يُرجع 1 إذا لم يكن الجهاز مُهيأ و2 إذا حدث خطأ منع تحديد حالة الجهاز.

ملاحظات

منذ الإصدار 2.37 يستخدم losetup ioctl LOOP_CONFIGURE لإعداد جهاز حلقة جديد باستدعاء ioctl واحد. تستخدم الإصدارات القديمة ioctl LOOP_SET_FD وLOOP_SET_STATUS64 للقيام بنفس الشيء.

الاسم

losetup - إعداد والتحكم في أجهزة الحلقة

الملخص

losetup [-o offset] [--sizelimit size] [-Pr] [--show] [-v] [-f loopdev] file

losetup -d [-v] loopdev ...

losetup -D [-v]

losetup -a [-v] [-O output_fields]

losetup -c [-v] [-O output_fields] device

losetup -c [-v] [-O output_fields] file

losetup -j file [-o offset] [-O output_fields] [--sizelimit size]

losetup -J [-o offset] [-O output_fields] [--sizelimit size]

losetup -l [-v] [-O output_fields]

losetup -t [-v] [-O output_fields]

losetup -V

losetup -h

الوصف

losetup يُستخدم لربط ملفات عادية أو أجهزة كتلة بأجهزة الحلقة. جهاز الحلقة يجعل الملف قابلاً للوصول كجهاز كتلة.

إذا لم يتم إعطاء أي وسيطات، سيعرض losetup حالة جميع أجهزة الحلقة.

الخيارات

يقبل losetup الوسيطات التالية:

-a, --all

إظهار حالة جميع أجهزة الحلقة.

-c, --set-capacity loopdev

إعادة قراءة حجم الملف المرتبط بجهاز الحلقة المحدد. يعيد هذا الخيار تعيين سعة جهاز الحلقة لتعكس الحجم الحالي للملف الأساسي. هذا مفيد عندما يتغير حجم الملف المرتبط.

-d, --detach loopdev ...

فصل جهاز الحلقة المحدد. يجب أن يكون جهاز الحلقة غير مستخدم. يمكن تحديد عدة أجهزة.

-D, --detach-all

فصل جميع أجهزة الحلقة المستخدمة.

-f, --find [loopdev]

البحث عن أول جهاز حلقة غير مستخدم. إذا تم تحديد loopdev، فسيتم استخدامه كجهاز حلقة بدلاً من البحث عن جهاز حر.

-h, --help

طباعة معلومات المساعدة والخروج.

-j, --associated file

إظهار حالة جميع أجهزة الحلقة المرتبطة بالملف file.

-J, --json

استخدام تنسيق JSON للإخراج.

-l, --list

إظهار معلومات حول جهاز حلقة واحد أو أكثر. إذا لم يتم تحديد جهاز، فسيتم إظهار حالة جميع أجهزة الحلقة.

-O, --output output_fields

تحديد حقول الإخراج لخيارات --list و--find و--associated. استخدم --help للحصول على قائمة بجميع الحقول المدعومة.

-o, --offset offset

بدء البيانات عند offset بايت في الملف.

-P, --partscan

فرض فحص جدول التقسيمات على جهاز الحلقة.

-r, --read-only

إعداد جهاز الحلقة للقراءة فقط.

--sizelimit size

تحديد حد الحجم بالبايت.

--show

عرض اسم جهاز الحلقة إذا تم إنشاء جهاز حلقة بنجاح.

-t, --terse

استخدام تنسيق الإخراج المختصر.

-v, --verbose

وضع مطوّل.

-V, --version

عرض معلومات الإصدار والخروج.

التشفير

لا يدعم losetup التشفير. استخدم cryptsetup(8) لتشفير أجهزة الحلقة.

حالة الخروج

يعيد losetup القيمة 0 عند النجاح، وقيمة غير صفرية عند الفشل.

ملاحظات

يجب أن يكون جهاز الحلقة غير مستخدم قبل ربطه بملف. يمكن استخدام الخيار --find للعثور على جهاز حلقة حر تلقائياً.

البيئة

LOOPDEV_DEBUG=all

تمكين إخراج التصحيح.

الملفات

/dev/loop[0..N]

أجهزة كتلة الحلقة

/dev/loop-control

جهاز التحكم بالحلقة

مثال

يمكن استخدام الأوامر التالية كمثال على استخدام جهاز الحلقة.

# dd if=/dev/zero of=~/file.img bs=1024k count=10
# losetup --find --show ~/file.img
/dev/loop0
# mkfs -t ext2 /dev/loop0
# mount /dev/loop0 /mnt
...
# umount /dev/loop0
# losetup --detach /dev/loop0
