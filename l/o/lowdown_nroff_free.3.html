lowdown_nroff_free(3)

الحزمة: lowdown

التراخيص: ISC

LOWDOWN_NROFF_FREE(3) دليل وظائف المكتبة LOWDOWN_NROFF_FREE(3)

الاسم

lowdown_nroff_free — تحرير مُصيِّر Markdown roff

المكتبة

المكتبة «liblowdown»

الملخص

#include <sys/queue.h>
#include <stdio.h>
#include <lowdown.h>

void
lowdown_nroff_free(void *arg);

الوصف

تحرر مُصيِّر roff الذي تم إنشاؤه باستخدام lowdown_nroff_new(3). إذا كان arg هو NULL، فلن تقوم الدالة بأي شيء.

أمثلة

يقوم المثال التالي بتحليل b بطول bsz ويخرج بتنسيق groff_ms(7).

struct lowdown_buf *out;
struct lowdown_doc *doc;
struct lowdown_node *n;
void *rndr;

if ((doc = lowdown_doc_new(NULL)) == NULL)
	err(1, NULL);
if ((n = lowdown_doc_parse(doc, NULL, b, bsz, NULL)) == NULL)
	err(1, NULL);
if ((out = lowdown_buf_new(256)) == NULL)
	err(1, NULL);
if ((rndr = lowdown_nroff_new(NULL)) == NULL)
	err(1, NULL);
if (!lowdown_nroff_rndr(out, rndr, n))
	err(1, NULL);

fwrite(out->data, 1, out->size, stdout);

lowdown_nroff_free(rndr);
lowdown_buf_free(out);
lowdown_node_free(n);
lowdown_doc_free(doc);

انظر أيضًا

lowdown(3)، lowdown_nroff_new(3)

يستخدم هذا كلاً من وحدات man الأصلية لـ الإصدار 7 من UNIX AT&T، المعرفة في man(7)، وملحقات groff man-ext. كلاهما مُطبَّق في mandoc.

وحدات ms الخاصة بـ troff معرفة في groff_ms(7)، مع ملحقات groff mspdf الموصوفة في "Portable Document Format Publishing with GNU Troff" بواسطة Keith Marshall. لا يوجد منهما مُطبق في mandoc.
