loadkeys(1)

الحزمة: kbd

التراخيص: GPL-2.0-or-later

LOADKEYS(1) دليل الأوامر العامة LOADKEYS(1)

الاسم

loadkeys - تحميل جداول ترجمة لوحة المفاتيح

الموجز

loadkeys [خيار]... اسم_الملف...
loadkeys --default
loadkeys --mktable
loadkeys --bkeymap
loadkeys --tkeymap[=shape]
loadkeys --parse

الوصف

البرنامج loadkeys يقرأ الملف أو الملفات المحددة بواسطة اسم_الملف.... هدفه الرئيسي هو تحميل خريطة مفاتيح النواة (kernel keymap) للترف (console). يمكنك تحديد جهاز الترف باستخدام الخيار -C (أو --console ).

إعادة الضبط إلى الافتراضي

إذا تم إعطاء الخيار -d (أو --default )، فإن loadkeys يقوم بتحميل خريطة مفاتيح افتراضية، ربما الملف defkeymap.map إما في /usr/share/kbd/keymaps أو في /usr/src/linux/drivers/tty/vt. (ربما تم تعريف الأول بواسطة المستخدم، بينما الأخير هو خريطة مفاتيح QWERTY لأجهزة الكمبيوتر الشخصية - ربما ليس ما كان مرغوبًا فيه.) في بعض الأحيان، مع تحميل خريطة مفاتيح غريبة (مع علامة الطرح في تركيبة معدلة غامضة غير معروفة) يكون من الأسهل كتابة `loadkeys defkeymap.map'.

تحميل خريطة مفاتيح النواة

الوظيفة الرئيسية لـ loadkeys هي تحميل أو تعديل جداول الترجمة لمشغل لوحة المفاتيح. عند تحديد أسماء الملفات، يمكن الإشارة إلى الإدخال القياسي باستخدام الشرطة (-). إذا لم يتم تحديد أي ملف، يتم قراءة البيانات من الإدخال القياسي.

بالنسبة للعديد من البلدان وأنواع لوحات المفاتيح، تتوفر خرائط مفاتيح مناسبة بالفعل، وقد يقوم أمر مثل `loadkeys uk' بما تريده. من ناحية أخرى، من السهل إنشاء خريطة مفاتيح خاصة بك. يجب على المستخدم إخبار ما هي الرموز التي تنتمي لكل مفتاح. يمكنه العثور على رمز المفتاح (keycode) لمفتاح باستخدام showkey(1)، بينما يتم تقديم تنسيق خريطة المفاتيح في keymaps(5) ويمكن أيضًا رؤيته من إخراج dumpkeys(1).

تحميل جدول التنغيم للنواة

إذا لم يحتوِ ملف الإدخال على أي تعريفات لمفتاح التجميع (compose key)، فإن جدول التنغيم للنواة يبقى دون تغيير، ما لم يتم إعطاء الخيار -c (أو --clearcompose )، وفي هذه الحالة يتم إفراغ جدول التنغيم للنواة. إذا كان ملف الإدخال يحتوي على تعريفات لمفتاح التجميع، فسيتم إزالة جميع التعريفات القديمة، واستبدالها بالإدخالات الجديدة المحددة. جدول التنغيم للنواة هو تسلسل من (68 افتراضيًا) إدخالات تصف كيف تعمل علامات التشكيل الميتة (dead diacritical signs) ومفاتيح التجميع. على سبيل المثال، سطر

compose ',' 'c' to ccedilla

يعني أن <ComposeKey><,><c> يجب أن يتم دمجها إلى <ccedilla>. يمكن رؤية المحتوى الحالي لهذا الجدول باستخدام `dumpkeys --compose-only'.

تحميل جدول السلاسل النصية للنواة

الخيار -s (أو --clearstrings ) يقوم بمسح جدول السلاسل النصية للنواة. إذا لم يتم إعطاء هذا الخيار، سيقوم loadkeys فقط بإضافة أو استبدال السلاسل النصية، وليس إزالتها. (وبالتالي، فإن الخيار -s مطلوب للوصول إلى حالة محددة بشكل جيد.) جدول السلاسل النصية للنواة هو تسلسل من السلاسل النصية بأسماء مثل F31. يمكنك جعل مفتاح الوظيفة F5 (على لوحة مفاتيح كمبيوتر شخصي عادية) ينتج النص `Hello!'، و Shift+F5 `Goodbye!' باستخدام أسطر

keycode 63 = F70 F71
string F70 = "Hello!"
string F71 = "Goodbye!"

في خريطة المفاتيح. الروابط الافتراضية لمفاتيح الوظائف هي تسلسلات هروب مستوحاة بشكل أساسي من محطة VT100.

إنشاء جدول مصدر النواة

إذا تم إعطاء الخيار -m (أو --mktable )، فإن loadkeys يطبع إلى الإخراج القياسي ملفًا يمكن استخدامه كـ /usr/src/linux/drivers/tty/vt/defkeymap.c، يحدد روابط المفاتيح الافتراضية للنواة (ولا يعدل خريطة المفاتيح الحالية).

إنشاء خريطة مفاتيح ثنائية

إذا تم إعطاء الخيار -b (أو --bkeymap )، فإن loadkeys يطبع إلى الإخراج القياسي ملفًا يمكن استخدامه كخريطة مفاتيح ثنائية كما هو متوقع من أمر loadkmap الخاص بـ Busybox (ولا يعدل خريطة المفاتيح الحالية).

إنشاء خريطة مفاتيح نصية

إذا تم إعطاء الخيار -t (أو --tkeymap )، فإن loadkeys يطبع إلى الإخراج القياسي ملفًا يمكن استخدامه كخريطة مفاتيح نصية كما هو متوقع من أمر loadkeys (ولا يعدل خريطة المفاتيح الحالية). يمكن استخدام وسيط اختياري لتحديد شكل تنسيق الإخراج: -tshape (أو --tkeymap=shape ).

الأشكال المتاحة:

2 الإخراج الافتراضي.
4 سطر واحد لكل رمز مفتاح (keycode).
8 سطر واحد لكل زوج (معدل، رمز مفتاح).
16 سطر واحد لكل رمز مفتاح حتى أول فجوة.

وضع Unicode

loadkeys يكتشف تلقائيًا ما إذا كان الترف في وضع Unicode أو ASCII (XLATE). عند تحميل خريطة مفاتيح، يتم حل رموز المفاتيح الحرفية (keysyms) (مثل section) وفقًا لذلك؛ يتم تحويل رموز المفاتيح الرقمية لتناسب وضع الترف الحالي، بغض النظر عن الطريقة التي يتم بها تحديدها (عشري، ثماني، سداسي عشري، أو Unicode).

المفتاح -u (أو --unicode) يجبر loadkeys على تحويل جميع خرائط المفاتيح إلى Unicode. إذا كان لوحة المفاتيح في وضع غير Unicode، مثل XLATE، فسيقوم loadkeys بتغييره إلى Unicode لوقت تنفيذه. ستتم طباعة رسالة تحذير في هذه الحالة.

يُنصح بتشغيل kbd_mode(1) قبل loadkeys بدلاً من استخدام الخيار -u.

خيارات أخرى

-a --ascii
فرض التحويل إلى ASCII.
-h --help
يطبع loadkeys رقم الإصدار ورسالة استخدام قصيرة إلى مخرج الخطأ القياسي للبرنامج ويخرج.
-p --parse
يبحث loadkeys ويقوم بتحليل خريطة المفاتيح دون اتخاذ أي إجراء.
-q --quiet
يقمع loadkeys جميع المخرجات العادية.
-V --version
يطبع loadkeys رقم الإصدار ويخرج.

تحذير

لاحظ أن أي شخص لديه إذن قراءة لـ /dev/console يمكنه تشغيل loadkeys وبالتالي تغيير تخطيط لوحة المفاتيح، مما قد يجعله غير قابل للاستخدام. لاحظ أن جدول ترجمة لوحة المفاتيح مشترك لجميع وحدات الترف الافتراضية، لذا فإن أي تغييرات في روابط المفاتيح تؤثر على جميع وحدات الترف الافتراضية في وقت واحد.

لاحظ أنه نظرًا لأن التغييرات تؤثر على جميع وحدات الترف الافتراضية، فإنها تستمر أيضًا بعد جلستك. هذا يعني أنه حتى عند مطالبة تسجيل الدخول، قد لا تكون روابط المفاتيح كما يتوقعها المستخدم.

loadkeys(1)

NAME

loadkeys - load a keyboard translation table

SYNOPSIS

loadkeys [-b] [-c] [-d] [-n] [-o file] [-s] [-v] [-m mode] [-k kernel_map] [-t keymap] [keymap]

DESCRIPTION

The loadkeys command loads a new keyboard translation table into the kernel. This table defines how keystrokes are translated into keysyms. The default keymap file is usually found in /usr/share/kbd/keymaps/.

RESET TO DEFAULT

When called without arguments, loadkeys restores the default keymap. The default keymap is determined by the kernel's /proc/sys/kernel/ctrl_alt_del setting, or by a default keymap if that is not set.

loadkeys --default resets the keymap to the system default, as determined by the configuration in /etc/vconsole.conf. This is the most common way to reset the keymap.

LOAD KERNEL KEYMAP

loadkeys keymap loads the specified keymap file. The keymap file can be specified by its name (e.g., us for /usr/share/kbd/keymaps/i386/qwerty/us.map.gz) or by its full path.

LOAD KERNEL ACCENT TABLE

loadkeys -a accent_table loads the specified accent table. Accent tables are used for composing characters.

LOAD KERNEL STRING TABLE

loadkeys -S string_table loads the specified string table. String tables are used for defining macro keys.

CREATE KERNEL SOURCE TABLE

loadkeys -r keymap creates a kernel source table from the specified keymap file. This is a text-based representation of the keymap that can be edited and then compiled into a binary keymap using loadkeys -c.

CREATE BINARY KEYMAP

loadkeys -c keymap compiles a text-based keymap file into a binary keymap suitable for loading into the kernel. The output is written to stdout and can be redirected to a file.

CREATE TEXT KEYMAP

loadkeys -x keymap converts a binary keymap file into a text-based representation. The output is written to stdout and can be redirected to a file.

UNICODE MODE

loadkeys -u enables Unicode mode, where keystrokes are translated into Unicode code points. This is useful for internationalization and for handling input from non-standard keyboards.

loadkeys -U disables Unicode mode.

OTHER OPTIONS

-b
Don't clear the screen after loading the keymap.
-d
Use the default keymap file (usually /usr/share/kbd/keymaps/i386/qwerty/us.map.gz).
-n
Don't load the keymap, just print the name of the keymap that would be loaded.
-o file
Write the output of -c or -x to the specified file instead of stdout.
-s
Suppress output.
-v
Verbose mode. Print information about the keymap being loaded.
-m mode
Set the console mode. Possible values are 8bit, 14bit, 16bit, unsupported.
-k kernel_map
Load the specified kernel map. This is used for special keymaps like the Ctrl+Alt+Del key.
-t keymap
Load the specified keymap for the text console.

WARNING

Loading an incorrect keymap can make your keyboard unusable. Always ensure you have a way to restore the default keymap, for example, by having a bootable USB drive with a working system.

FILES

/usr/share/kbd/keymaps/
Default directory for keymap files.
/etc/vconsole.conf
Configuration file for the virtual console, including the default keymap.
