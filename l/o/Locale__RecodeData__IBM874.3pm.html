NAME

Locale::RecodeData::IBM874 - Recode data from IBM’s Thai CCSID 874

SYNOPSIS

use Locale::Recode;

# Read Thai text from a file, convert it to UTF-8
my $str_utf8 = Locale::Recode::decode('IBM874', $str_ibm874);

# Write Thai text to a file, convert it from UTF-8
my $str_ibm874 = Locale::Recode::encode('IBM874', $str_utf8);

DESCRIPTION

This module provides the character mapping for IBM’s Thai CCSID 874 encoding.

CCSID 874 is a superset of the Thai TIS 620 standard. CCSID 874 includes the characters of the ISO 8859-1 (Latin-1) character set in the range 0x80 to 0xFF.

COMMENTS

This module is part of the libintl-perl distribution.
