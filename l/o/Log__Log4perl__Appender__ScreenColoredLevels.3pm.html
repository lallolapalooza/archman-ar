Log__Log4perl__Appender__ScreenColoredLevels(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Appender::ScreenColoredLevels(3) توثيق Perl المساهم به من قبل المستخدم Appender::ScreenColoredLevels(3)

الاسم

Log::Log4perl::Appender::ScreenColoredLevels - تلوين الرسائل وفقًا للمستوى

الملخص

use Log::Log4perl qw(:easy);
Log::Log4perl->init(\ <<'EOT');
  log4perl.category = DEBUG, Screen
  log4perl.appender.Screen = \
      Log::Log4perl::Appender::ScreenColoredLevels
  log4perl.appender.Screen.layout = \
      Log::Log4perl::Layout::PatternLayout
  log4perl.appender.Screen.layout.ConversionPattern = \
      %d %F{1} %L> %m %n
EOT
  # تظهر باللون الأسود
DEBUG "رسالة تصحيح";
  # تظهر باللون الأخضر
INFO  "رسالة معلومات";
  # تظهر باللون الأزرق
WARN  "رسالة تحذير";
  # تظهر باللون الأرجواني
ERROR "رسالة خطأ";
  # تظهر باللون الأحمر
FATAL "رسالة فادحة";

الوصف

يعمل هذا الملحق مثل Log::Log4perl::Appender::Screen، باستثناء أنه يلون خرجه، بناءً على أولوية الرسالة المرسلة.

يمكنك تكوين الألوان والسمات المستخدمة للمستويات المختلفة، عن طريق تحديدها في التكوين الخاص بك:

log4perl.appender.Screen.color.TRACE=cyan
log4perl.appender.Screen.color.DEBUG=bold blue

يمكنك أيضًا تحديد لا شيء، للإشارة إلى أن هذا المستوى يجب ألا يطبق عليه التلوين، مما يعني أن النص سيكون أيًا كان اللون الافتراضي لمحطتك الطرفية. هذا هو الافتراضي لرسائل التصحيح.

log4perl.appender.Screen.color.DEBUG=

يمكنك استخدام أي سمة مدعومة من Term::ANSIColor كخيار تكوين.

log4perl.appender.Screen.color.FATAL=\
    bold underline blink red on_white

الألوان والسمات الشائعة الاستخدام هي:

سمات
BOLD, DARK, UNDERLINE, UNDERSCORE, BLINK
ألوان
BLACK, RED, GREEN, YELLOW, BLUE, MAGENTA, CYAN, WHITE
ألوان الخلفية
ON_BLACK, ON_RED, ON_GREEN, ON_YELLOW, ON_BLUE, ON_MAGENTA, ON_CYAN, ON_WHITE

راجع Term::ANSIColor للحصول على قائمة كاملة، ومعلومات حول أي منها مدعوم من قبل محاكيات الطرفية الشائعة المختلفة.

القيم الافتراضية لهذه الخيارات هي:

Trace
أصفر
Debug
لا شيء (أيًا كان الإعداد الافتراضي للطرفية)
Info
أخضر
Warn
أزرق
Error
أرجواني
Fatal
أحمر

يقبل المنشئ new() معلمة اختيارية "stderr"، إذا تم تعيينها على قيمة حقيقية، فسيقوم الملحق بتسجيل جميع المستويات إلى STDERR. إذا تم تعيين "stderr" على قيمة خاطئة، فسيسجل جميع المستويات إلى STDOUT. بخلاف ذلك، يمكن تعيين "stderr" على تجزئة، مع مفتاح لكل "log4p_level" وقيمة حقيقية لاستخدام stderr ديناميكيًا. الإعداد الافتراضي لـ "stderr" هو 1، لذا سيتم تسجيل جميع الرسائل إلى STDERR افتراضيًا.

# جميع الرسائل/المستويات إلى STDERR
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => 1,
);
# فقط ERROR و FATAL إلى STDERR (حساس لحالة الأحرف)
my $app = Log::Log4perl::Appender::Screen->new(
    stderr  => { ERROR => 1, FATAL => 1},
);

يمكن للمنشئ أيضًا أن يأخذ معلمة اختيارية "color"، وهي قيمة تجزئة لخيارات تكوين الألوان، وسيتم تعيين أي مستويات غير مدرجة في التجزئة إلى قيمها الافتراضية.

استخدام ScreenColoredLevels على نظام التشغيل Windows

لاحظ أنه إذا كنت تستخدم هذا الملحق على نظام التشغيل Windows، فستحتاج إلى جلب Win32::Console::ANSI من CPAN وإضافة

use Win32::Console::ANSI;

إلى النص البرمجي الخاص بك.
