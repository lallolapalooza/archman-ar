NAME


Locale::RecodeData::IBM865 — Locale::Recode encoding definition






SYNOPSIS


    use Locale::Recode;
    use Locale::RecodeData::IBM865;







DESCRIPTION


This module provides the encoding definition for IBM865 to be used
    by the Locale::Recode module.


Locale::Recode is a module for automatic character encoding detection and
    conversion. Locale::RecodeData::* modules provide the character mappings for
    different encodings.






COMMENTS


This encoding is known as CP865 or DOS Latin 1 for Nordic.
