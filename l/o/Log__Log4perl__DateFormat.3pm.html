Log::Log4perl::DateFormat(3pm)

Log4perl is a robust, fast, and flexible logging framework for Perl, inspired by log4j from Java. This module, Log::Log4perl::DateFormat, provides the functionality to format log messages according to specified patterns, similar to how `SimpleDateFormat` works in Java.

Description

The Log::Log4perl::DateFormat class is used internally by Log4perl to handle date and time formatting within log messages. It allows developers to specify a pattern string that defines how the timestamp should be represented.

Synopsis

use Log::Log4perl::DateFormat;

my $formatter = Log::Log4perl::DateFormat->new("yyyy-MM-dd HH:mm:ss");
my $formatted_time = $formatter->format(time);
print $formatted_time;

Methods

new(PATTERN)
Creates a new DateFormat object with the specified PATTERN. The pattern string uses various placeholders (e.g., yyyy for year, MM for month, dd for day, HH for hour, mm for minute, ss for second).
format(TIMESTAMP)
Formats the given TIMESTAMP (which should be a Unix epoch time) according to the pattern defined for this DateFormat object.

Pattern Letters

The following pattern letters are supported:

  • yyyy: Year (e.g., 2023)
  • MM: Month in year (01-12)
  • dd: Day in month (01-31)
  • HH: Hour in day (00-23)
  • mm: Minute in hour (00-59)
  • ss: Second in minute (00-59)

Log::Log4perl::DateFormat(3pm)

Log4perl هو إطار عمل تسجيل قوي وسريع ومرن للغة Perl، مستوحى من log4j الخاص بلغة Java. توفر هذه الوحدة، Log::Log4perl::DateFormat، الوظائف اللازمة لتنسيق رسائل السجل وفقًا لأنماط محددة، على غرار كيفية عمل SimpleDateFormat في Java.

الوصف

يتم استخدام الفئة Log::Log4perl::DateFormat داخليًا بواسطة Log4perl للتعامل مع تنسيق التاريخ والوقت داخل رسائل السجل. يسمح للمطورين بتحديد سلسلة نمط تحدد كيفية تمثيل الطابع الزمني.

الملخص

use Log::Log4perl::DateFormat;

my $formatter = Log::Log4perl::DateFormat->new("yyyy-MM-dd HH:mm:ss");
my $formatted_time = $formatter->format(time);
print $formatted_time;

الطرق

new(PATTERN)
ينشئ كائن DateFormat جديدًا باستخدام PATTERN المحدد. تستخدم سلسلة النمط أحرفًا بديلة مختلفة (مثل yyyy للسنة، MM للشهر، dd لليوم، HH للساعة، mm للدقيقة، ss للثانية).
format(TIMESTAMP)
يقوم بتنسيق TIMESTAMP المعطى (والذي يجب أن يكون وقت Unix epoch) وفقًا للنمط المحدد لكائن DateFormat هذا.

أحرف النمط

الأحرف النمطية التالية مدعومة:

  • yyyy: السنة (مثل 2023)
  • MM: الشهر في السنة (01-12)
  • dd: اليوم في الشهر (01-31)
  • HH: الساعة في اليوم (00-23)
  • mm: الدقيقة في الساعة (00-59)
  • ss: الثانية في الدقيقة (00-59)
