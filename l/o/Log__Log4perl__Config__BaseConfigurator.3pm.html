Log__Log4perl__Config__BaseConfigurator(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Config::BaseConfigurator(3) وثائق مساهمة المستخدم من Perl Config::BaseConfigurator(3)

الاسم

Log::Log4perl::Config::BaseConfigurator - فئة أساسية للمكوّنات

الملخص

هذه فئة أساسية افتراضية، يجب أن تشتق جميع المكوّنات منها.

الوصف

الأساليب

"new"
المُنشئ، يتم استدعاؤه عادةً مثل: 
my $config_parser = SomeConfigParser->new(
    file => $file,
);
my $data = $config_parser->parse();

بدلاً من "file"، قد تحدد الفئة المشتقة "SomeConfigParser" أي نوع من وسائط إدخال التكوين (مثل "url => 'http://foobar'"). عليها فقط التأكد من أن أسلوبها parse() سيجلب لاحقًا بيانات الإدخال من الوسيط المحدد.

تقبل الفئة الأساسية اسم ملف أو مرجعًا لمصفوفة من أسطر النص:

"file"
يحدد ملفًا يقوم أسلوب parse() بتحليله لاحقًا.
"text"
يحدد مرجعًا لمصفوفة من المقاييس، تمثل سجلات التكوين (عادةً أسطر ملف). يقبل أيضًا مقياسًا بسيطًا، والذي يقسمه عند أسطر جديدة ويحوله إلى مصفوفة: 
my $config_parser = MyYAMLParser->new(
    text => ['foo: bar',
             'baz: bam',
            ],
);
my $data = $config_parser->parse();

إذا تم تحديد أي من معلمات "file" أو "text" في استدعاء المُنشئ، فإن الاستدعاء اللاحق لأسلوب المُكوّن text() سيعيد مرجعًا لمصفوفة من أسطر نص التكوين. سيتم استخدام هذا عادةً بواسطة أسلوب parse() لمعالجة الإدخال.

"parse"
أسلوب افتراضي، يجب أن تحدده الفئة المشتقة.

متطلبات المحلل

  • إذا كان المحلل يوفر وظائف استبدال المتغيرات، فيجب عليه تنفيذها.
  • يعيد أسلوب parse() الخاص بالمحلل مرجعًا لهشاشات داخل هشاشات (HoH). تحتوي الهشاشات العليا على الكلمات الرئيسية العليا (مثل "category"، "appender") كمفاتيح، مرتبطة بقيم هي مراجع لهشاشات متداخلة بشكل أعمق.
  • يتم تجريد البادئة "log4perl." (مثل تلك المستخدمة في فئة PropertyConfigurator)، فهي ليست جزءًا من بنية HoH.
  • يتم الإشارة إلى كل قيمة Log4perl بواسطة المفتاح "value"، كما في: 
    $data->{category}->{Bar}->{Twix}->{value} = "WARN, Logfile"

أمثلة

تكوين Log::Log4perl التالي:

log4perl.category.Bar.Twix        = WARN, Screen
log4perl.appender.Screen          = Log::Log4perl::Appender::File
log4perl.appender.Screen.filename = test.log
log4perl.appender.Screen.layout   = Log::Log4perl::Layout::SimpleLayout

يحتاج إلى تحويله بواسطة أسلوب parse() الخاص بالمحلل إلى بنية البيانات هذه:

{ appender => {
    Screen  => {
      layout => {
        value  => "Log::Log4perl::Layout::SimpleLayout" },
        value  => "Log::Log4perl::Appender::Screen",
    },
  },
  category => {
    Bar => {
      Twix => {
        value => "WARN, Screen" }
    } }
}

للحصول على مثال كامل، تحقق من تطبيق محلل YAML النموذجي في "eg/yamlparser". يستخدم صيغة YAML بسيطة لتحديد تكوين Log4perl لتوضيح المفهوم.
