Log__Log4perl__Appender(3pm)

الحزمة: perl-log-log4perl

التراخيص: PerlArtistic, GPL

Log::Log4perl::Appender - Abstract base class for appenders

الاسم

Log::Log4perl::Appender - فئة أساسية مجردة للملحقات

الملخص

use Log::Log4perl::Appender;

# Inherit from Log::Log4perl::Appender
package My::Appender;
@ISA = qw(Log::Log4perl::Appender);

# Implement the log() method
sub log {
    my ($self, $logData) = @_;
    # ... process $logData ...
}

# Implement the close() method (optional)
sub close {
    my ($self) = @_;
    # ... cleanup ...
}

# Create and configure an instance
my $appender = My::Appender->new( name => 'my_appender' );
$appender->level( 'DEBUG' );

الوصف

هذه الفئة هي فئة أساسية مجردة لجميع الملحقات في Log4perl. الملحقات هي المسؤولة عن توجيه رسائل السجل إلى وجهات مختلفة، مثل وحدة التحكم، أو ملف، أو قاعدة بيانات، أو شبكة، وما إلى ذلك.

لتنفيذ ملحق جديد، تحتاج إلى وراثة هذه الفئة وتنفيذ طريقة log().

يجب أن تكون طرق الملحق القياسية (مثل new، level، name، layout، close) متاحة من الفئة الأساسية. إذا كنت بحاجة إلى تعديل سلوكها، يمكنك تجاوزها في فئتك الفرعية.

new()

يقوم بإنشاء مثيل جديد للملحق. يأخذ الوسيطات التالية:

  • name: اسم فريد للملحق.

level()

يضبط أو يعيد مستوى التسجيل للملحق. يتم تجاهل رسائل السجل ذات المستوى الأقل من مستوى الملحق.

name()

يعيد اسم الملحق.

layout()

يضبط أو يعيد مخطط الملحق. يستخدم المخطط لتنسيق رسالة السجل قبل إرسالها إلى الوجهة.

log()

هذه هي الطريقة الأساسية التي يجب تنفيذها بواسطة جميع الملحقات. تأخذ وسيطة واحدة:

  • $logData: يحتوي على جميع المعلومات المتعلقة برسالة السجل، بما في ذلك الرسالة نفسها، ومستوى السجل، والوقت، واسم الثريد، واسم الملف، ورقم السطر، وما إلى ذلك.

يجب على تنفيذك لهذه الطريقة معالجة $logData وإرسال السجل إلى الوجهة المحددة للملحق.

close()

هذه الطريقة اختيارية. يجب تنفيذها إذا كان الملحق بحاجة إلى إجراء أي عمليات تنظيف عند إغلاق المسجل (على سبيل المثال، إغلاق ملف). يتم استدعاء هذه الطريقة تلقائيًا بواسطة Log4perl عند إيقاف تشغيل المسجل.

المعلمات التي تم تمريرها إلى طريقة log() للملحق

الطريقة log() للملحق تتلقى كائن Log::Log4perl::LogEvent يحتوي على جميع المعلومات حول حدث التسجيل.

يحتوي كائن LogEvent على السمات التالية:

  • message: رسالة السجل الفعلية.
  • level: مستوى السجل (على سبيل المثال، 'DEBUG'، 'INFO'، 'ERROR').
  • timestamp: طابع زمني لوقت حدوث حدث السجل.
  • thread: اسم الثريد الذي قام بإنشاء حدث السجل.
  • file: اسم الملف الذي حدث فيه حدث السجل.
  • line: رقم السطر في الملف حيث حدث حدث السجل.
  • logger: كائن المسجل الذي أنشأ حدث السجل.
  • throwable: استثناء (إن وجد) مرتبط بحدث السجل.

المزالق

  • إذا لم تقم بتنفيذ طريقة log()، فسوف تتلقى خطأ.
  • تذكر التحقق من مستوى السجل قبل القيام بعمل مكلف في طريقة log().

الملحقات التي تتوقع أجزاء الرسالة

بعض الملحقات، وخاصة تلك التي تكتب إلى تدفقات، قد تتوقع أن يتم تمريرها على أجزاء من رسالة السجل بدلاً من سلسلة واحدة كاملة. هذا يحدث عندما يقوم المسجل بتسجيل رسائل متعددة متتالية باستخدام نفس الثريد. في مثل هذه الحالات، قد تحتاج إلى معالجة خاصية $logData->{message} بشكل مختلف.
