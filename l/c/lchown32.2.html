الوصف

تُغيّر دالة chown() مالك الملف المحدد بواسطة pathname إلى owner. يجب أن يكون المعرّف owner إما معرف مستخدم رقمي أو اسم مستخدم، والذي يتم تحويله إلى معرف مستخدم رقمي باستخدام getpwnam(3). إذا كان owner هو -1، فلن يتم تغيير مالك الملف.

إذا كان group ليس -1، فسيتم تغيير مجموعة الملف المحدد بواسطة pathname إلى group. يجب أن يكون group إما معرف مجموعة رقمي أو اسم مجموعة، والذي يتم تحويله إلى معرف مجموعة رقمي باستخدام getgrnam(3). إذا كان group هو -1، فلن يتم تغيير مجموعة الملف.

عادةً ما يكون chown() متاحًا فقط للمستخدم الخارق (root). يمكن للمستخدمين غير الخارقين تغيير ملكية ملف فقط إذا كان الملف يقع على نظام ملفات تم تحميله مع خيار -o all_squash (انظر mount(8)) وكان المستخدم الذي يقوم بالاستدعاء هو مالك الملف.

لتغيير المالك والمجموعة في استدعاء واحد، استخدم fchown(2). إذا كان pathname يشير إلى رابط رمزي، فسيتم تغيير مالك الملف الذي يشير إليه الرابط، وليس الرابط نفسه. استخدم lchown(2) لتغيير مالك الرابط الرمزي نفسه.

عند إنشاء ملف (على سبيل المثال، بواسطة open(2) أو mkdir(2))، يصبح مالكه هو نفسه معرف المستخدم لنظام الملفات للعملية المنشئة. تعتمد مجموعة الملف على مجموعة من العوامل، بما في ذلك نوع نظام الملفات، والخيارات المستخدمة لتحميل نظام الملفات، وما إذا كانت بت وضع set-group-ID ممكّنة على الدليل الأصل أم لا. إذا كان نظام الملفات يدعم خيارات تحميل -o grpid (أو، بشكل مرادف -o bsdgroups) و -o nogrpid (أو، بشكل مرادف -o sysvgroups) (mount(8))، فإن القواعد تكون كما يلي:

•
إذا تم تحميل نظام الملفات باستخدام -o grpid، فإن مجموعة الملف الجديد تصبح هي نفسها مجموعة الدليل الأصل.
•
إذا تم تحميل نظام الملفات باستخدام -o nogrpid وكانت بت set-group-ID معطلة على الدليل الأصل، فإن مجموعة الملف الجديد تصبح هي نفسها معرف مجموعة نظام الملفات للعملية.
•
إذا تم تحميل نظام الملفات باستخدام -o nogrpid وكانت بت set-group-ID ممكّنة على الدليل الأصل، فإن مجموعة الملف الجديد تصبح هي نفسها مجموعة الدليل الأصل.

حتى Linux 4.12، تدعم ext2، ext3، ext4، و XFS خيارات تحميل -o grpid و -o nogrpid. أنظمة الملفات التي لا تدعم خيارات التحميل هذه تتبع قواعد -o nogrpid.

ملاحظات glibc

في الأنوية الأقدم حيث fchownat() غير متاح، تتراجع وظيفة التغليف glibc إلى استخدام chown() و lchown(). عندما يكون path نسبيًا، تقوم glibc بإنشاء اسم مسار بناءً على الرابط الرمزي في /proc/self/fd الذي يتوافق مع الوسيط dirfd.

NFS

يتم انتهاك دلالات chown() عمدًا في أنظمة الملفات NFS التي تم تمكين تعيين UID لها. بالإضافة إلى ذلك، يتم انتهاك دلالات جميع استدعاءات النظام التي تصل إلى محتويات الملف، لأن chown() قد يتسبب في إلغاء الوصول الفوري للملفات المفتوحة بالفعل. قد يؤدي التخزين المؤقت من جانب العميل إلى تأخير بين الوقت الذي تم فيه تغيير الملكية للسماح بالوصول لمستخدم ووقت يمكن فيه الوصول إلى الملف فعليًا بواسطة المستخدم على عملاء آخرين.

تفاصيل تاريخية

دعوات النظام الأصلية لـ Linux chown()، fchown()، و lchown() دعمت فقط معرفات المستخدم والمجموعة ذات 16 بت. لاحقًا، أضاف Linux 2.4 chown32()، fchown32()، و lchown32()، ودعمت معرفات 32 بت. تتعامل وظائف التغليف glibc chown()، fchown()، و lchown() بشفافية مع الاختلافات عبر إصدارات النواة.

قبل Linux 2.1.81 (باستثناء 2.1.46)، لم يتبع chown() الروابط الرمزية. منذ Linux 2.1.81، يتبع chown() الروابط الرمزية، وهناك استدعاء نظام جديد lchown() لا يتبع الروابط الرمزية. منذ Linux 2.1.86، حصل هذا الاستدعاء الجديد (الذي له نفس الدلالات مثل chown() القديم) على نفس رقم استدعاء النظام، وحصل chown() على الرقم الذي تم تقديمه حديثًا.

أمثلة

يغير البرنامج التالي ملكية الملف المسمى في وسيط سطر الأوامر الثاني إلى القيمة المحددة في وسيط سطر الأوامر الأول. يمكن تحديد المالك الجديد إما كمعرف مستخدم رقمي، أو كاسم مستخدم (يتم تحويله إلى معرف مستخدم باستخدام getpwnam(3) لإجراء بحث في ملف كلمات المرور للنظام).

مصدر البرنامج

#include <pwd.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    char           *endptr;
    uid_t          uid;
    struct passwd  *pwd;
    if (argc != 3 || argv[1][0] == '\0') {
        fprintf(stderr, "%s <owner> <file>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    uid = strtol(argv[1], &endptr, 10);  /* Allow a numeric string */
    if (*endptr != '\0') {         /* Was not pure numeric string */
        pwd = getpwnam(argv[1]);   /* Try getting UID for username */
        if (pwd == NULL) {
            perror("getpwnam");
            exit(EXIT_FAILURE);
        }
        uid = pwd->pw_uid;
    }
    if (chown(argv[2], uid, -1) == -1) {
        perror("chown");
        exit(EXIT_FAILURE);
    }
    exit(EXIT_SUCCESS);
}
