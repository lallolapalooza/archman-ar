التاريخ

كان حقل st_mode في بنية stat في الأصل غير معرف بشكل جيد.

يوفر POSIX.1-2008 مواصفات أكثر صرامة، مما يفرض على lstat() إرجاع معلومات صالحة في جميع الحقول باستثناء بتات الوضع في st_mode.

قد يكون استخدام الحقلين st_blocks و st_blksize أقل قابلية للنقل. (تم تقديمهما في BSD. يختلف تفسيرهما بين الأنظمة، وربما على نظام واحد عند مشاركة وحدات NFS.)

اختلافات مكتبة C / النواة

بمرور الوقت، أدت الزيادات في حجم بنية stat إلى ثلاثة إصدارات متتالية من stat(): sys_stat() (موضع __NR_oldstat) و sys_newstat() (موضع __NR_stat) و sys_stat64() (موضع __NR_stat64) على الأنظمة 32 بت مثل i386. كان الإصداران الأولان موجودين بالفعل في Linux 1.0 (وإن كانا بأسماء مختلفة)؛ تمت إضافة الأخير في Linux 2.4. تنطبق ملاحظات مماثلة على fstat() و lstat().

إصدارات النواة الداخلية لبنية stat التي تتعامل معها الإصدارات المختلفة هي على التوالي:

__old_kernel_stat
البنية الأصلية، مع حقول ضيقة نسبيًا، ولا توجد مساحة بادئة.
stat
حقل st_ino أكبر ومساحة بادئة مضافة إلى أجزاء مختلفة من البنية للسماح بالتوسع المستقبلي.
stat64
حقل st_ino أكبر، وحقول st_uid و st_gid أكبر لاستيعاب توسيع Linux 2.4 لمعرفات المستخدمين (UIDs) ومعرفات المجموعات (GIDs) إلى 32 بت، وحقول أخرى مختلفة موسعة ومساحات بادئة إضافية في البنية. (تم استهلاك بعض بايتات المساحة البادئة في النهاية في Linux 2.6، مع ظهور معرفات الأجهزة 32 بت ومكونات النانو ثانية لحقول الطوابع الزمنية.)

تخفي دالة الغلاف stat() في glibc هذه التفاصيل عن التطبيقات، حيث تستدعي أحدث إصدار من استدعاء النظام الذي توفره النواة، وتعيد تجميع المعلومات المرتجعة إذا لزم الأمر للبرامج القديمة.

على الأنظمة الحديثة 64 بت، الحياة أبسط: هناك استدعاء نظام واحد stat() وتتعامل النواة مع بنية stat تحتوي على حقول بالحجم الكافي.

استدعاء النظام الأساسي الذي تستخدمه دالة الغلاف fstatat() في glibc يسمى فعليًا fstatat64() أو، في بعض البنيات، newfstatat().

أمثلة

يستدعي البرنامج التالي lstat() ويعرض الحقول المحددة في بنية stat المرتجعة.

#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/stat.h>
#include <sys/sysmacros.h>
#include <time.h>
int
main(int argc, char *argv[])
{
    struct stat sb;
    if (argc != 2) {
        fprintf(stderr, "Usage: %s <path>\n", argv[0]);
        exit(EXIT_FAILURE);
    }
    if (lstat(argv[1], &sb) == -1) {
        perror("lstat");
        exit(EXIT_FAILURE);
    }
    printf("ID of containing device:  [%x,%x]\n",
           major(sb.st_dev),
           minor(sb.st_dev));
    printf("File type:                ");
    switch (sb.st_mode & S_IFMT) {
    case S_IFBLK:  printf("block device\n");            break;
    case S_IFCHR:  printf("character device\n");        break;
    case S_IFDIR:  printf("directory\n");               break;
    case S_IFIFO:  printf("FIFO/pipe\n");               break;
    case S_IFLNK:  printf("symlink\n");                 break;
    case S_IFREG:  printf("regular file\n");            break;
    case S_IFSOCK: printf("socket\n");                  break;
    default:       printf("unknown?\n");                break;
    }
    printf("I-node number:            %ju\n", (uintmax_t) sb.st_ino);
    printf("Mode:                     %jo (octal)\n",
           (uintmax_t) sb.st_mode);
    printf("Link count:               %ju\n", (uintmax_t) sb.st_nlink);
    printf("Ownership:                UID=%ju   GID=%ju\n",
           (uintmax_t) sb.st_uid, (uintmax_t) sb.st_gid);
    printf("Preferred I/O block size: %jd bytes\n",
           (intmax_t) sb.st_blksize);
    printf("File size:                %jd bytes\n",
           (intmax_t) sb.st_size);
    printf("Blocks allocated:         %jd\n",
           (intmax_t) sb.st_blocks);
    printf("Last status change:       %s", ctime(&sb.st_ctime));
    printf("Last file access:         %s", ctime(&sb.st_atime));
    printf("Last file modification:   %s", ctime(&sb.st_mtime));
    exit(EXIT_SUCCESS);
}
