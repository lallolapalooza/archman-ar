الاسم

lsfd - سرد واصفات الملفات

الاستخدام

lsfd [خيار]

الوصف

lsfd مخصص ليكون بديلاً حديثًا لـ lsof(8) على أنظمة لينكس. على عكس lsof، يتخصص lsfd في نواة لينكس؛ فهو يدعم ميزات لينكس الخاصة مثل مساحات الأسماء (namespaces) بكود أبسط. lsfd ليس بديلاً مباشرًا لـ lsof؛ فهما مختلفان في واجهة سطر الأوامر وتنسيقات الإخراج.

الإخراج الافتراضي عرضة للتغيير. لذلك، كلما أمكن، يجب عليك تجنب استخدام الإخراج الافتراضي في البرامج النصية الخاصة بك. قم دائمًا بتعريف الأعمدة المتوقعة بشكل صريح باستخدام --output قائمة-الأعمدة في البيئات التي تتطلب إخراجًا ثابتًا.

يستخدم lsfd Libsmartcols لتنسيق الإخراج والتصفية. راجع وصف خيار --output لتخصيص تنسيق الإخراج، وخيار --filter للتصفية. استخدم lsfd --list-columns للحصول على قائمة بجميع الأعمدة المتاحة.

الخيارات

-l, --threads

يسرد على مستوى الخيوط (threads).

-J, --json

استخدم تنسيق الإخراج JSON.

-n, --noheadings

لا تطبع العناوين.

-o, --output list

حدد أعمدة الإخراج التي سيتم طباعتها. راجع قسم أعمدة الإخراج للحصول على تفاصيل الأعمدة المتاحة.

قد يتم توسيع قائمة الأعمدة الافتراضية إذا تم تحديد list بالتنسيق +list (على سبيل المثال، lsfd -o +DELETED).

-r, --raw

استخدم تنسيق الإخراج الخام.

--notruncate

لا تقم بقص النص في الأعمدة.

-p, --pid pids

اجمع المعلومات فقط للعمليات المحددة. pids هي قائمة بمعرفات العمليات (pids). يمكن استخدام فاصلة أو مسافات كفواصل. يمكنك استخدام هذا الخيار مع pidof(1). راجع أمثلة التصفية.

كل من الخيار -Q مع تعبير يتضمن PID، على سبيل المثال -Q (PID == 1)، والخيار -p، على سبيل المثال -p 1، قد يطبعان نفس الإخراج ولكن استخدام الخيار -p أكثر كفاءة بكثير لأن الخيار -p يعمل في مرحلة مبكرة جدًا من المعالجة مقارنة بالخيار -Q.

-i[4|6], --inet[=4|=6]

سرد مقابس IPv4 فقط و/أو مقابس IPv6 فقط.

-Q, --filter expr

اطبع الملفات التي تطابق الشرط الذي يمثله expr فقط. راجع أيضًا scols-filter(5) و أمثلة التصفية.

-C, --counter label:filter_expr

حدد عدادًا مخصصًا يستخدم في إخراج --summary. يقوم lsfd بإنشاء عداد باسم label. أثناء جمع المعلومات، يقوم lsfd بعد الملفات التي تطابق filter_expr، ويخزن العدد المحسوب في العداد المسمى label. يقوم lsfd بتطبيق عوامل التصفية المحددة بخيارات --filter قبل العد؛ الملفات المستبعدة بواسطة عوامل التصفية لا يتم عدها.

راجع scols-filter(5) حول filter_expr. يجب أن لا يحتوي label على { ولا :. يمكنك تحديد عدادات متعددة بتحديد هذا الخيار عدة مرات.

راجع أيضًا أمثلة العدادات.

--summary[=when]

يتحكم هذا الخيار في إخراج أسطر الملخص. يمكن أن تكون الوسيطة الاختيارية when هي only (فقط)، append (إلحاق)، أو never (أبدًا). إذا تم حذف الوسيطة when، فإنها تكون افتراضية only.

تقارير الملخص تحتوي على عدادات. يتكون العداد من تسمية وقيمة عدد صحيح. --counter هو الخيار لتحديد العداد. إذا لم يحدد المستخدم أي عداد، يستخدم lsfd تعريفات العدادات المضمنة المحددة مسبقًا (العدادات الافتراضية) لإنشاء إخراج الملخص.

تحذير: قد يؤدي استخدام --summary و --json إلى كسر الإخراج. فقط الجمع بين --summary=only و --json صالح.

--debug-filter

افحص بنية البيانات الداخلية للتصفية واخرج. هذا مفيد فقط لمطوري lsfd.

--dump-counters

افحص تعريف العدادات المستخدمة في إخراج --summary.

--hyperlink[=mode]

اطبع المسارات كروابط طرفية (terminal hyperlinks). يمكن تعيين mode إلى "always" (دائمًا)، "never" (أبدًا)، أو "auto" (تلقائي). يمكن تعيين الوسيطة الاختيارية when إلى "auto"، "never"، أو "always". إذا تم حذف الوسيطة when، فإنها ستكون افتراضية "auto". تعني إعداد "auto" أن الروابط الطرفية ستستخدم فقط إذا كان الإخراج على طرفية.

-H, --list-columns

سرد الأعمدة المتاحة التي يمكنك تحديدها في خيار --output.

-h, --help

عرض نص المساعدة والخروج.

-V, --version

عرض الإصدار والخروج.

اقتباس من kernel/fork.c في شجرة مصدر Linux:

إذا كانت مساحات أسماء pid مدعومة، فستقوم هذه الوظيفة أيضًا بطباعة معرف العملية الذي تشير إليه pidfd لجميع مساحات أسماء pid التابعة بدءًا من مساحة أسماء pid الحالية للمثيل، أي أن حقل Pid والحق entry الأول في حقل NSpid سيكونان متطابقين.

لاحظ أن هذا يختلف عن حقلي Pid و NSpid في /proc/<pid>/status حيث يتم دائمًا عرض Pid و NSpid بالنسبة إلى مساحة أسماء pid لمثيل procfs.

FILTER EXAMPLES

lsfd has few options for filtering. In most of cases, what you should know is -Q (or --filter) option. Combined with -o (or --output) option, you can customize the output as you want.

List files associated with PID 1 and PID 2 processes:

# lsfd -Q '(PID == 1) or (PID == 2)'

Do the same in an alternative way:

# lsfd -Q '(PID == 1) || (PID == 2)'

Do the same in a more efficient way:

# lsfd --pid 1,2

Whitespaces can be used instead of a comma:

# lsfd --pid '1 2'

Utilize pidof(1) for list the files associated with "firefox":

# lsfd --pid "$(pidof firefox)"

List the 1st file descriptor opened by PID 1 process:

# lsfd -Q '(PID == 1) and (FD == 1)'

Do the same in an alternative way:

# lsfd -Q '(PID == 1) && (FD == 1)'

List all running executables:

# lsfd -Q 'ASSOC == "exe"'

Do the same in an alternative way:

# lsfd -Q 'ASSOC eq "exe"'

Do the same but print only file names:

# lsfd -o NAME -Q 'ASSOC eq "exe"' | sort -u

List deleted files associated to processes:

# lsfd -Q 'DELETED'

List non-regular files:

# lsfd -Q 'TYPE != "REG"'

List block devices:

# lsfd -Q 'DEVTYPE == "blk"'

Do the same with TYPE column:

# lsfd -Q 'TYPE == "BLK"'

List files including "dconf" directory in their names:

# lsfd -Q 'NAME =~ ".\*/dconf/.*"'

List files opened in a QEMU virtual machine:

# lsfd -Q '(COMMAND =~ ".\*qemu.*") and (FD >= 0)'

List timerfd files expired within 0.5 seconds:

# lsfd -Q '(TIMERFD.remaining < 0.5) and (TIMERFD.remaining > 0.0)'

List processes communicating via unix stream sockets:

# lsfd  -Q 'TYPE == "UNIX-STREAM" && UNIX.PATH =~ ".+"' -oUNIX.PATH,PID,COMMAND,FD,SOCK.STATE,ENDPOINTS

List processes communicating via a specified unix stream socket:

# lsfd  -Q 'TYPE == "UNIX-STREAM" && UNIX.PATH == "@/tmp/.X11-unix/X0"' -oUNIX.PATH,PID,COMMAND,FD,SOCK.STATE,ENDPOINTS
