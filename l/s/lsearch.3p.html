LSEARCH(3P) دليل مبرمج POSIX LSEARCH(3P)

مقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة في لينكس.

الاسم

lsearch, lfind — بحث خطي وتحديث

الملخص

#include <search.h>
void *lsearch(const void *key, void *base, size_t *nelp, size_t width,
    int (*compar)(const void *, const void *));
void *lfind(const void *key, const void *base, size_t *nelp,
    size_t width, int (*compar)(const void *, const void *));

الوصف

تقوم الدالة lsearch() بالبحث الخطي في الجدول وإرجاع مؤشر داخل الجدول للعنصر المطابق. إذا لم يوجد العنصر، فسيتم إضافته في نهاية الجدول. يشير الوسيط key إلى العنصر المراد البحث عنه في الجدول. يشير الوسيط base إلى العنصر الأول في الجدول. الوسيط width هو حجم العنصر بالبايت. يشير الوسيط nelp إلى عدد صحيح يحتوي على العدد الحالي للعناصر في الجدول. سيتم زيادة العدد الصحيح الذي يشير إليه nelp إذا تمت إضافة العنصر إلى الجدول. يشير الوسيط compar إلى دالة مقارنة يجب على التطبيق توفيرها (على سبيل المثال، strcmp()). يتم استدعاؤها مع وسيطين يشيران إلى العناصر التي يتم مقارنتها. يجب أن يضمن التطبيق أن ترجع الدالة 0 إذا كانت العناصر متساوية، وغير ذلك بخلاف ذلك.

تكون الدالة lfind() مكافئة للدالة lsearch()، باستثناء أنه إذا لم يتم العثور على العنصر، فلن يتم إضافته إلى الجدول. بدلاً من ذلك، يتم إرجاع مؤشر فارغ (null pointer).

قيمة الإرجاع

إذا تم العثور على العنصر المراد البحث عنه، فإن كلتا الدالتين lsearch() و lfind() ترجعان مؤشرًا إليه. بخلاف ذلك، ترجع lfind() مؤشرًا فارغًا وترجع lsearch() مؤشرًا إلى العنصر المضاف حديثًا.

ترجع كلتا الدالتين مؤشرًا فارغًا في حالة حدوث خطأ.

الأخطاء

لا توجد أخطاء محددة.

الأقسام التالية إعلامية.

أمثلة

تخزين السلاسل النصية في جدول

هذا المقتطف يقرأ أقل من أو يساوي TABSIZE سلسلة نصية بحجم أقل من أو يساوي ELSIZE ويخزنها في جدول، مع إزالة التكرارات.

#include <stdio.h>
#include <string.h>
#include <search.h>
#define TABSIZE 50
#define ELSIZE 120
...
    char line[ELSIZE], tab[TABSIZE][ELSIZE];
    size_t nel = 0;
    ...
    while (fgets(line, ELSIZE, stdin) != NULL && nel < TABSIZE)
        (void) lsearch(line, tab, &nel,
            ELSIZE, (int (*)(const void *, const void *)) strcmp);
    ...

البحث عن عنصر مطابق

يبحث المثال التالي عن أي سطر يقرأ "Thisisatest.".

#include <search.h>
#include <string.h>
...
char line[ELSIZE], tab[TABSIZE][ELSIZE];
size_t nel = 0;
char *findline;
void *entry;
findline = "This is a test.\n";
entry = lfind(findline, tab, &nel, ELSIZE, (
    int (*)(const void *, const void *)) strcmp);

استخدام التطبيق

لا تحتاج دالة المقارنة إلى مقارنة كل بايت، لذا يمكن أن تحتوي العناصر على بيانات عشوائية بالإضافة إلى القيم التي تتم مقارنتها.

يمكن أن تحدث نتائج غير معرفة إذا لم تكن هناك مساحة كافية في الجدول لإضافة عنصر جديد.
