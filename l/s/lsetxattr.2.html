setxattr(2) دليل استدعاءات النظام setxattr(2)

الاسم

setxattr, lsetxattr, fsetxattr - تعيين قيمة سمة موسعة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/xattr.h>
int setxattr(size_t size;
              const char *path, const char *name,
              const void value[size], size_t size, int flags);
int lsetxattr(size_t size;
              const char *path, const char *name,
              const void value[size], size_t size, int flags);
int fsetxattr(size_t size;
              int fd, const char *name,
              const void value[size], size_t size, int flags);

الوصف

السمات الموسعة هي أزواج اسم:قيمة مرتبطة بـ inodes (ملفات، أدلة، روابط رمزية، إلخ). وهي امتدادات للسمات العادية المرتبطة بجميع inodes في النظام (أي بيانات stat(2)). يمكن العثور على نظرة عامة كاملة لمفاهيم السمات الموسعة في xattr(7).

تقوم setxattr() بتعيين قيمة السمة الموسعة التي تم تحديدها بواسطة name والمرتبطة بالمسار path المحدد في نظام الملفات. تحدد الوسيطة size حجم value (بالبايت)؛ يُسمح بقيمة بطول صفر.

lsetxattr() مطابقة لـ setxattr()، باستثناء حالة الرابط الرمزي، حيث يتم تعيين السمة الموسعة على الرابط نفسه، وليس الملف الذي يشير إليه.

fsetxattr() مطابقة لـ setxattr()، حيث يتم تعيين السمة الموسعة فقط على الملف المفتوح المشار إليه بواسطة fd (كما تم إرجاعه بواسطة open(2)) بدلاً من path.

اسم السمة الموسعة هو سلسلة نصية منتهية بحرف فارغ. يتضمن name بادئة مساحة اسم؛ قد يكون هناك العديد من مساحات الأسماء المنفصلة المرتبطة بـ inode فردي. value للسمة الموسعة هو قطعة من البيانات النصية أو الثنائية العشوائية ذات الطول المحدد.

افتراضيًا (أي، flags صفر)، سيتم إنشاء السمة الموسعة إذا لم تكن موجودة، أو سيتم استبدال القيمة إذا كانت السمة موجودة بالفعل. لتعديل هذه الدلالات، يمكن تحديد إحدى القيم التالية في flags:

XATTR_CREATE
إجراء إنشاء خالص، يفشل إذا كانت السمة المسماة موجودة بالفعل.
XATTR_REPLACE
إجراء عملية استبدال خالصة، تفشل إذا كانت السمة المسماة غير موجودة بالفعل.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. عند الفشل، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EDQUOT
حدود حصة القرص كانت تعني أنه لا توجد مساحة كافية متبقية لتخزين السمة الموسعة.
EEXIST
تم تحديد XATTR_CREATE، والسمة موجودة بالفعل.
ENODATA
تم تحديد XATTR_REPLACE، والسمة غير موجودة.
ENOSPC
لا توجد مساحة كافية متبقية لتخزين السمة الموسعة.
ENOTSUP
بادئة مساحة اسم name غير صالحة.
ENOTSUP
السمات الموسعة غير مدعومة من قبل نظام الملفات، أو معطلة،
EPERM
الملف مميز على أنه غير قابل للتغيير أو للكتابة فقط. (انظر FS_IOC_SETFLAGS(2const).)

بالإضافة إلى ذلك، قد تحدث الأخطاء الموثقة في stat(2).

ERANGE
يتجاوز حجم name أو value حدًا خاصًا بنظام الملفات.
