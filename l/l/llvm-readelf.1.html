llvm-readelf(1)

الحزمة: llvm

التراخيص: Apache-2.0 WITH LLVM-exception

LLVM-READELF(1) LLVM LLVM-READELF(1)

الاسم

llvm-readelf - قارئ LLVM للكائنات بأسلوب GNU

ملخص

llvm-readelf [خيارات] [ملف إدخال...]

الوصف

أداة llvm-readelf تعرض معلومات منخفضة المستوى خاصة بالتنسيق حول ملف كائن واحد أو أكثر.

إذا كان ملف الإدخال هو "-"، تقرأ llvm-readelf من الإدخال القياسي. وإلا، فإنها ستقرأ من أسماء الملفات المحددة.

الخيارات

--all, -a
تعادل تحديد جميع خيارات العرض الرئيسية ذات الصلة بتنسيق الملف.
--addrsig
عرض جدول أهمية العناوين.
--arch-specific, -A
عرض معلومات خاصة بالمعمارية، على سبيل المثال قسم سمات ARM على ARM.
--bb-addr-map
عرض محتويات قسم (أقسام) خريطة عناوين الكتل الأساسية، والتي تحتوي على عنوان كل دالة، بالإضافة إلى الإزاحة النسبية لكل كتلة أساسية.
--decompress, -z
عرض محتوى القسم غير المضغوط عند استخدامه مع -x أو -p. إذا لم تكن الأقسام مضغوطة، يتم عرضها كما هي.
--demangle, -C
عرض أسماء الرموز غير المشفرة في الإخراج.
--dependent-libraries
عرض قسم المكتبات التابعة.
--dyn-relocations
عرض إدخالات الإزاحة الديناميكية.
--dyn-symbols, --dyn-syms
عرض جدول الرموز الديناميكي.
--dynamic-table, --dynamic, -d
عرض الجدول الديناميكي.
--cg-profile
عرض قسم ملف تعريف الرسم البياني للاستدعاء.
--histogram, -I
عرض مخطط توزيع لأشجار تجزئة الرموز الديناميكية.
--elf-linker-options
عرض قسم خيارات الرابط.
--elf-output-style=<قيمة>
تنسيق معلومات ELF بالنمط المحدد. الخيارات الصالحة هي LLVM، GNU، و JSON. إخراج LLVM هو تنسيق موسع ومنظم. إخراج GNU (الافتراضي) يحاكي إخراج readelf المكافئ من GNU. JSON هو إخراج بتنسيق JSON مخصص للاستهلاك الآلي.
--extra-sym-info
عرض معلومات إضافية (اسم القسم) عند عرض الرموز.
--section-groups, -g
عرض مجموعات الأقسام.
--expand-relocs
عند استخدامه مع --relocations، عرض كل إزاحة بتنسيق موسع متعدد الأسطر.
--file-header, -h
عرض رؤوس الملفات.
--gnu-hash-table
عرض جدول تجزئة GNU للرموز الديناميكية.
--hash-symbols
عرض جدول التجزئة الموسع مع بيانات الرموز الديناميكية.
--hash-table
عرض جدول التجزئة للرموز الديناميكية.
--headers, -e
يعادل تعيين: --file-header، --program-headers، و --sections.
--help
عرض ملخص لخيارات سطر الأوامر.
--hex-dump=<قسم[,قسم,...]>, -x
عرض الأقسام المحددة كبايت سداسي عشري. يمكن أن يكون قسم فهرس قسم أو اسم قسم.
--memtag
عرض معلومات حول وضع علامات الذاكرة الموجودة في الملف الثنائي. هذا يشمل إدخالات ديناميكية متنوعة خاصة بوضع العلامات، أقسام واصفات عامة مفككة، وملاحظات ELF خاصة بنظام Android مفككة.
--needed-libs
عرض المكتبات المطلوبة.
--no-demangle
عدم عرض أسماء الرموز غير المشفرة في الإخراج. مفعل افتراضيًا.
--notes, -n
عرض جميع الملاحظات.
--pretty-print
عند استخدامه مع --elf-output-style، سيتم تنسيق إخراج JSON بتنسيق أكثر قابلية للقراءة.
--program-headers, --segments, -l
عرض رؤوس البرامج.
--relocations, --relocs, -r
عرض إدخالات الإزاحة في الملف.
--sections, --section-headers, -S
عرض جميع الأقسام.
--section-data
عند استخدامه مع --sections، عرض بيانات القسم لكل قسم معروض. ليس لهذا الخيار تأثير على إخراج أسلوب GNU.
--section-details, -t
عرض جميع تفاصيل الأقسام. يستخدم كبديل لـ --sections.
--section-mapping
عرض تعيين القسم إلى المقطع.
--section-relocations
عند استخدامه مع --sections، عرض الإزاحات لكل قسم معروض. ليس لهذا الخيار تأثير على إخراج أسلوب GNU.
--section-symbols
عند استخدامه مع --sections، عرض الرموز لكل قسم معروض. ليس لهذا الخيار تأثير على إخراج أسلوب GNU.
--stackmap
عرض محتويات خريطة المكدس
--statistics, -X
عرض إحصائيات حول محتويات الملف.
--symbol-groups
عرض مجموعات الرموز.
--symbol-table, --syms, -s
عرض جدول الرموز.
--unwind
عرض جدول إلغاء التحميل.
--version
عرض إصدار الأداة.
--vma-to-section
عرض قسم إلى تعيينات عنوان الذاكرة الافتراضية.

OPTIONS

The following options are available:

--arch-truncate
Truncate output for the arch symbol.
--archive-member=<member>
Process contents of the specified archive member only.
--aranges
Dump the .ARM.attribute section.
--attributes
Dump the .attributes section.
--brand, -I
Display the binary identification.
--chdr
Display the section header table.
--cl<section_name>
Dump the specified section.
--common, -C
Display the common symbol list.
--debug-ranges
Dump the .debug_ranges section.
--dependencies, -D
Display the shared object dependencies.
--dependents, -U
Display the shared object dependents.
--dynamic, -d
Display the dynamic section.
--dwo-name
Display the DWo name section.
--ehdr
Display the ELF header.
--exports, -x
Display the exported symbol list.
--filehdr
Display the ELF file header.
--fixup, -F
Display the fixup section.
--gnu-style
Use GNU readelf output style. This is the default.
--hash-table
Display the hash table.
--headers, -h
Display the section header table.
--histogram, -t
Print histogram of symbol values.
--i386-unwind
Display unwind information for the i386 architecture.
--ident
Display the .ident section.
--imports, -i
Display the imported symbol list.
--init-array
Display the array of constructors.
--jump-relocs
Display the jump relocations.
--link_group, -L
Display the link group section.
--notes, -n
Display the note sections.
--opcodes
Decode and display the opcode information.
--plt, -P
Display the procedure linkage table.
--relocs, -r
Display the relocation entries.
--section-details
Display detailed section information.
--section-index
Display section index information.
--section-sort-by-name
Sort section output by name.
--section-sort-by-size
Sort section output by size.
--sections, -S
Display the section header table.
--static-libgcc
Display the static libgcc section.
--stack-sizes
Display the contents of the stack sizes section(s), i.e. pairs of function names and the size of their stack frames. Currently only implemented for GNU style output.
--string-dump=<section[,section,...]>, -p
Display the specified section(s) as a list of strings. section may be a section index or section name.
--symbols, --syms, -s
Display the symbol table. Also display the dynamic symbol table when using GNU output style for ELF.
--unwind, -u
Display unwind information.
--version
Display the version of the llvm-readelf executable.
--version-info, -V
Display version sections.
--wide, -W
Ignored for GNU readelf compatibility. The output is already similar to when using -W with GNU readelf.
@<FILE>
Read command-line options from response file <FILE>.

EXIT STATUS

llvm-readelf returns 0 under normal operation. It returns a non-zero exit code if there were any errors.
