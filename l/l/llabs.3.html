llabs(3) دليل الدوال المكتبية llabs(3)

الاسم

abs, labs, llabs, imaxabs, uabs, ulabs, ullabs, umaxabs - حساب القيمة المطلقة لعدد صحيح

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <stdlib.h>
int abs(int j);
long labs(long j);
long long llabs(long long j);
unsigned int uabs(int j);
unsigned long ulabs(long j);
unsigned long long ullabs(long long j);
#include <inttypes.h>
intmax_t imaxabs(intmax_t j);
uintmax_t umaxabs(intmax_t j);
متطلبات ميزة الاختبار (Feature Test Macro Requirements) لـ glibc (انظر feature_test_macros(7)):

llabs():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L

uabs()، ulabs()، ullabs()، umaxabs():

    _ISOC2Y_SOURCE

الوصف

تقوم هذه الدوال بحساب القيمة المطلقة للمعامل j من نوع العدد الصحيح المناسب للدالة.

قيمة الإرجاع

ترجع القيمة المطلقة لمعامل العدد الصحيح، من نوع العدد الصحيح المناسب للدالة.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
abs ()، labs ()، llabs ()، imaxabs ()، uabs ()، ulabs ()، ullabs ()، umaxabs () أمان الخيوط (Thread safety) MT-Safe

الأخطاء

بالنسبة لـ abs()، labs()، llabs()، و imaxabs()، فإن محاولة أخذ القيمة المطلقة لأصغر عدد سالب معرف ليس له تعريف.
