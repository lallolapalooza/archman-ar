LL2_IMPORT_LASTLOG(3) دليل المبرمج LL2_IMPORT_LASTLOG(3)

الاسم

ll2_import_lastlog - يستورد ملف lastlog القديم.

الملخص

#include <lastlog2.h>

int ll2_import_lastlog (struct ll2_context *context, const char *lastlog_file, char **error);

الوصف

يستورد جميع الإدخالات من ملف lastlog_file (lastlog(8)) إلى قاعدة بيانات lastlog2 المعرفة باستخدام context. إذا كان context هو NULL، فسيتم أخذ قاعدة البيانات الافتراضية، المعرفة في LL2_DEFAULT_DATABASE.

char    *error = NULL;
const   char *lastlog_path = "/var/log/lastlog";
int ret = ll2_import_lastlog (NULL, lastlog_path, &error);

قيمة الإرجاع

تعيد 0 عند النجاح، -ENOMEM أو -1 عند الفشل الآخر. يحتوي error على سلسلة خطأ إذا كانت قيمة الإرجاع -1. error غير مضمونة لاحتواء سلسلة خطأ، يمكن أن تكون NULL أيضًا. يجب تحرير error بواسطة المستدعي.
