llvm-ifs(1)

الحزمة: llvm

التراخيص: Apache-2.0 WITH LLVM-exception

LLVM-IFS(1) LLVM LLVM-IFS(1)

الاسم

llvm-ifs - أداة لتكوين كائنات مشتركة وهمية

الملخص

llvm-ifs [خيارات] مدخلات

الوصف

llvm-ifs هي أداة تنتج بشكل مشترك ملفات وهمية نصية قابلة للقراءة البشرية (.ifs) للكائنات المشتركة والملفات الوهمية للكائنات المشتركة القابلة للربط (.so) من كائنات ELF المشتركة أو الملفات الوهمية النصية. الملفات الوهمية النصية مفيدة لمراقبة تغييرات ABI للكائن المشترك. يمكن استخدام الملفات الوهمية للكائنات المشتركة القابلة للربط لتجنب إعادة الربط غير الضروري عندما لا يتغير ABI للمكتبات المشتركة.

تنسيقات IFS

هنا مثال على التمثيل النصي (IFS) لكائن مشترك تم إنتاجه بواسطة llvm-ifs:

--- !ifs-v1
IFSVersion: 3.0
SoName: libtest.so /* اختياري */
Target: x86_64-unknown-linux-gnu   /* اختياري، التنسيق 1، نفس تنسيق ثلاثي LLVM الهدف */
Target: { Arch: x86_64, Endianness: little, Bitwidth: 64 } /* اختياري، التنسيق 2 */
NeededLibs:
  - libc.so.6
Symbols:
  - { Name: sym0, Type: Notype }
  - { Name: sym1, Type: Object, Size: 0 }
  - { Name: sym2, Type: Func, Weak: false }
  - { Name: sym3, Type: TLS }
  - { Name: sym4, Type: Unknown, Warning: foo }
...
  • IFSVersion: إصدار ملف IFS لتوافق القارئ.
  • SoName (اختياري): اسم ملف الكائن المشترك الذي يتم تكوينه كملف وهمي.
  • Target (اختياري): معلومات المعمارية، ترتيب البايتات (endianness)، وعرض البت لهذا الكائن المشترك. يمكن أن يكون بالتنسيق الصريح أو بتنسيق ثلاثي LLVM الضمني. يمكن أن يكون اختياريًا ويمكن تجاوزه من خيارات سطر الأوامر.
  • NeededLibs: قائمة الكائنات المشتركة الخارجية التي تعتمد عليها هذه المكتبة.
  • Symbols: مجموعة من جميع البيانات المطلوبة لربط الكائنات لكل رمز، مرتبة حسب الاسم بترتيب تصاعدي.
  • Name: اسم الرمز.
  • Type: ما إذا كان الرمز كائنًا، وظيفة، لا نوع، تخزين مؤقت محلي (thread local storage)، أو غير معروف. يتم تعيين أنواع الرموز غير المدعومة صراحةً على أنها غير معروفة لتحسين نسبة الإشارة إلى الضوضاء.
  • Size: حجم الرمز المعني، لا ينطبق على الدوال، وهو اختياري لرموز NoType.
  • Undefined: ما إذا كان الرمز معرفًا في ملف الكائن المشترك هذا أم لا.
  • Weak: ما إذا كان يجب التعامل مع الرمز على أنه ضعيف (weak) أم لا.
  • Warning (اختياري): نص تحذير للإخراج عند ربط هذا الرمز.

يحتوي تنسيق النص هذا المستند إلى YAML على كل ما هو مطلوب لإنشاء كائن مشترك ELF قابل للربط وكذلك ملف TAPI بتنسيق Apple. ترتيب الرموز مرتب، لذلك يمكن مقارنة هذه الملفات بسهولة باستخدام أدوات diff. إذا تغير محتوى الملف، فهذا يشير إلى تغيير قد يكسر ABI.

تنسيق الوهم ELF

يجب أن يحتوي الحد الأدنى من ملف ELF الذي يمكن أن يستخدمه الرابط على الأقسام التالية المعبأة بشكل صحيح:

  • رأس ELF.
  • رؤوس الأقسام.
  • جدول رموز الديناميكية (قسم .dynsym).
  • جدول سلاسل الديناميكية (قسم .dynstr).
  • جدول الديناميكية (قسم .dynamic).
  • إدخال DT_SYMTAB.
  • إدخال DT_STRTAB.
  • إدخال DT_STRSZ.
  • إدخالات DT_NEEDED. (اختياري)
  • إدخال DT_SONAME. (اختياري)
•
جدول سلاسل رؤوس الأقسام (قسم .shstrtab)

قد يعاني ملف ELF هذا من مشكلات توافق مع أدوات تحليل ELF التي تعتمد على رؤوس البرنامج. الروابط مثل LLD تعمل بشكل جيد مع ملف ELF الأدنى هذا دون أخطاء.

الخيارات

--input-format=[IFS|ELF|OtherObjectFileFormats]
تحديد تنسيق ملف الإدخال. حاليًا، يتم دعم ملفات IFS النصية وملفات ELF المشتركة فقط. هذا العلم اختياري حيث يمكن استنتاج تنسيق الإدخال.
--output-elf=<اسم-ملف-الإخراج>
تحديد ملف الإخراج للوهم ELF المشترك.
--output-ifs=<اسم-ملف-الإخراج>
تحديد ملف الإخراج لـ IFS النصي.
--output-tbd=<اسم-ملف-الإخراج>
تحديد ملف الإخراج لـ TAPI tbd الخاص بـ Apple.
--arch=[x86_64|AArch64|...]
هذا العلم اختياري ويجب استخدامه فقط عند قراءة ملف IFS الذي لا يحدد Arch (المعمارية). يحدد هذا العلم معمارية ملف الإخراج، ويمكن أن يكون أي سلسلة مدعومة بواسطة حقل 'e_machine' في ELF. إذا كانت القيمة تتعارض مع ملف IFS، فسيتم الإبلاغ عن خطأ وسيتوقف البرنامج.
--endianness=[little|big]
هذا العلم اختياري ويجب استخدامه فقط عند قراءة ملف IFS الذي لا يحدد Endianness (ترتيب البايتات). يحدد هذا العلم ترتيب البايتات لملف الإخراج. إذا كانت القيمة تتعارض مع ملف IFS، فسيتم الإبلاغ عن خطأ وسيتوقف البرنامج.
--bitwidth=[32|64]
هذا العلم اختياري ويجب استخدامه فقط عند قراءة ملف IFS الذي لا يحدد BitWidth (عرض البت). يحدد هذا العلم عرض البت لملف الإخراج. إذا كانت القيمة تتعارض مع ملف IFS المدخل، فسيتم الإبلاغ عن خطأ وسيتوقف البرنامج.
--target=<ثلاثي الهدف>
هذا العلم اختياري ويجب استخدامه فقط عند قراءة ملف IFS الذي لا يحدد أي معلومات هدف. يحدد هذا العلم المعمارية، ترتيب البايتات، وعرض البت لملف الإخراج باستخدام ثلاثي هدف LLVM. لا يمكن استخدام هذا العلم في نفس الوقت مع أعلام الهدف الأخرى.
--hint-ifs-target=<ثلاثي الهدف>
هذا العلم اختياري ويجب استخدامه فقط عند قراءة كائن مشترك ELF وإنشاء ملف IFS. افتراضيًا، سيستخدم llvm-ifs حقلي 'Arch، Endianness و BitWidth' لعكس معلومات الهدف من ملف الإدخال. استخدام هذا العلم سيخبر llvm-ifs بثلاثي الهدف المتوقع في ملف IFS الناتج. إذا تطابقت القيمة مع معلومات الهدف من ملف الكائن، فسيتم استخدام هذه القيمة في حقل 'Target:' في IFS الذي تم إنشاؤه. إذا تعارضت مع ملف الإدخال، فسيتم الإبلاغ عن خطأ وسيتوقف البرنامج.
--strip-ifs-arch
هذا العلم اختياري ويجب استخدامه فقط عند إخراج ملف IFS. يقوم هذا العلم بإزالة حقل Arch من ملف IFS حتى يمكن تجاوزه لاحقًا.
--strip-ifs-endianness
هذا العلم اختياري ويجب استخدامه فقط عند إخراج ملف IFS. يقوم هذا العلم بإزالة حقل Endianness من ملف IFS حتى يمكن تجاوزه لاحقًا.
--strip-ifs-bitwidth
هذا العلم اختياري ويجب استخدامه فقط عند إخراج ملف IFS. يقوم هذا العلم بإزالة حقل BitWidth من ملف IFS حتى يمكن تجاوزه لاحقًا.
--strip-ifs-target
هذا العلم اختياري ويجب استخدامه فقط عند إخراج ملف IFS. يقوم هذا العلم بإزالة حقل Target من ملف IFS حتى يمكن تجاوزه لاحقًا.
--no-warn
لا تعرض تحذيرات حول الرموز غير المدعومة.
--verbose
قم بتشغيل الوضع المطول.
--help
عرض رسالة المساعدة.
--version
عرض معلومات الإصدار.
