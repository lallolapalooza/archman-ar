NAME

lli ― Interpreter for LLVM bitcode

SYNOPSIS

lli [ -a | --asm-syntax=syntax ]
    [ -b | --bounds-checking ]
    [ -c | --interpret ]
    [ -disable-lazy ]
    [ -dce ]
    [ -disable-prealloc ]
    [ -disable-vectorize ]
    [ -enable-lazy ]
    [ -frame-pointer=type ]
    [ -help ]
    [ -internalize-public-functions ]
    [ -load=plugin ]
    [ -loop-maximize-unroll ]
    [ -loop-unroll ]
    [ -march=target-triple ]
    [ -m-llvm-bc-dir=dir ]
    [ -no-color ]
    [ -Olevel ]
    [ -pass-remarks-output=file ]
    [ -print-after=pass ]
    [ -print-after-all ]
    [ -print-before=pass ]
    [ -print-before-all ]
    [ -print-module-before=pass ]
    [ -print-module-after=pass ]
    [ -stats ]
    [ -S ]
    [ -time-passes ]
    [ -verify-each ]
    [ -x86-asm-syntax=syntax ]
    [ -version ]
    [ -v ]
    [ -- ]
    input.bc
    [ arg1 ... ]

DESCRIPTION

The lli utility is the LLVM interpreter. It takes an LLVM bitcode file as input and executes it directly.

It can also be used to JIT compile and execute the bitcode. This is the default behavior unless the -c option is specified.

GENERAL OPTIONS

Many of the general options are standard LLVM options. See llvm-config(1) for more details.

-help
Print a summary of command-line options.
-version
Print the version number of this program and exit.
-load=plugin
Load the specified plugin.
-disable-lazy
Disable lazy JIT loading for functions.
-enable-lazy
Enable lazy JIT loading for functions (default).
-stats
Print statistics to standard error, including timing and counting information about passes executed.
-time-passes
Time each pass, printing the time to standard error.
-verify-each
Run verifier after each pass (for debugging).
-debug
Enable debug message output.
-help-list
List all command line options supported by the tool.

TARGET OPTIONS

-march=target-triple
Generate code for the specified target triple. For example, x86_64-unknown-linux-gnu.

FLOATING POINT OPTIONS

-frame-pointer=type

Control the emission of frame pointers. Valid type values are:

0
None (never emit frame pointers).
1
All (always emit frame pointers).
2
0 or 1 depending on call stack information.

CODE GENERATION OPTIONS

-a
-asm-syntax=syntax
Specify the assembly syntax to use. Valid syntax values are:
=simple: simple spiller
=local: local spiller

-x86-asm-syntax=syntax

Choose style of code to emit from X86 backend:
=att: Emit AT&T-style assembly
=intel: Emit Intel-style assembly

EXIT STATUS

If lli fails to load the program, it will exit with an exit code of 1. Otherwise, it will return the exit code of the program it executes.
