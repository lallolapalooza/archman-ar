LL2_UPDATE_LOGIN_TIME(3) دليل المبرمجين LL2_UPDATE_LOGIN_TIME(3)

الاسم

ll2_update_login_time - يكتب إدخالًا *جديدًا* بوقت تسجيل دخول محدث.

نظرة عامة

#include <lastlog2.h>

int ll2_update_login_time (struct ll2_context *context, const char *user, int64_t ll_time, char **error);

الوصف

يكتب إدخالًا جديدًا إلى قاعدة البيانات، المحدد في context، للمستخدم user. يتم تعيين الوقت بواسطة ll_time بينما تؤخذ القيم الأخرى من إدخال موجود بالفعل. إذا كان context فارغًا (NULL)، فسيتم استخدام قاعدة البيانات الافتراضية، المحددة في LL2_DEFAULT_DATABASE.

char    *error = NULL;
const   char *user = "root";
int64_t login_time = time(0); // الحصول على وقت النظام؛
int ret = ll2_update_login_time (NULL, user, login_time, &error);

قيمة الإرجاع

تُرجع 0 عند النجاح، و -ENOMEM أو -1 عند فشل آخر. يحتوي error على سلسلة نصية للخطأ إذا كانت قيمة الإرجاع -1. لا يُضمن أن يحتوي error على سلسلة نصية للخطأ، وقد يكون فارغًا (NULL) أيضًا. يجب تحرير error بواسطة المستدعي.
