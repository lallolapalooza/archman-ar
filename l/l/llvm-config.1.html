llvm-config(1)

الحزمة: llvm

التراخيص: Apache-2.0 WITH LLVM-exception

LLVM-CONFIG(1) LLVM LLVM-CONFIG(1)

الاسم

llvm-config - طباعة خيارات تجميع LLVM

الملخص

llvm-config خيار [مكونات...]

الوصف

llvm-config يسهل بناء التطبيقات التي تستخدم LLVM. يمكنه طباعة علامات المترجم، علامات الرابط، ومكتبات الكائنات المطلوبة للربط مع LLVM.

أمثلة

للربط مع JIT:

g++ `llvm-config --cxxflags` -o HowToUseJIT.o -c HowToUseJIT.cpp
g++ `llvm-config --ldflags` -o HowToUseJIT HowToUseJIT.o \
    `llvm-config --libs engine bcreader scalaropts`

الخيارات

--assertion-mode

طباعة وضع التأكيد المستخدم عند بناء LLVM (ON أو OFF).

--bindir

طباعة دليل التثبيت لملفات LLVM الثنائية.

--build-mode

طباعة وضع البناء المستخدم عند بناء LLVM (مثل Debug أو Release).

--build-system

طباعة نظام البناء المستخدم لبناء LLVM (مثل cmake أو gn).

--cflags

طباعة علامات مترجم C المطلوبة لاستخدام رؤوس LLVM.

--cmakedir

طباعة دليل تثبيت وحدات CMake الخاصة بـ LLVM.

--components

طباعة جميع أسماء المكونات الصالحة.

--cppflags

طباعة علامات معالج C المسبق المطلوبة لاستخدام رؤوس LLVM.

--cxxflags

طباعة علامات مترجم C++ المطلوبة لاستخدام رؤوس LLVM.

--has-rtti

طباعة ما إذا كان LLVM مبنيًا مع RTTI (YES أو NO).

--help

طباعة ملخص لحجج llvm-config.

--host-target

طباعة ثلاثي الهدف الذي تم استخدامه لتكوين LLVM.

--ignore-libllvm

تجاهل libLLVM والربط بمكتبات المكونات بدلاً من ذلك.

--includedir

طباعة دليل التثبيت لرؤوس LLVM.

--ldflags

طباعة العلامات المطلوبة للربط مع مكتبات LLVM.

--libdir

طباعة دليل التثبيت لمكتبات LLVM.

--libfiles

مشابه لـ --libs، ولكن طباعة المسار الكامل لكل ملف مكتبة. هذا مفيد عند إنشاء تبعيات makefile، لضمان إعادة ربط أداة ما إذا تغيرت أي مكتبة تستخدمها.

--libnames

مشابه لـ --libs، ولكن طباعة أسماء الملفات العارية للمكتبات بدون -l أو مسارات. مفيد للربط بنسخة غير مثبتة من LLVM.

--libs

طباعة جميع المكتبات المطلوبة للربط مع مكونات LLVM المحددة، بما في ذلك أي تبعيات.

--link-shared

ربط المكونات كمكتبات مشتركة.

--link-static

ربط مكتبات المكونات بشكل ثابت.

--obj-root

طباعة جذر الكائن المستخدم لبناء LLVM.

--prefix

طباعة بادئة التثبيت لـ LLVM.

--shared-mode

طباعة كيف يمكن ربط المكونات المقدمة بشكل جماعي (مشترك أو ثابت).

--system-libs

طباعة جميع مكتبات النظام المطلوبة للربط مع مكونات LLVM المحددة، بما في ذلك أي تبعيات.

--targets-built

طباعة أسماء المكونات لجميع الأهداف التي تدعمها هذه النسخة من LLVM.

--version

طباعة رقم إصدار LLVM.

المكونات

لطباعة قائمة بجميع المكونات المتاحة، قم بتشغيل llvm-config --components. في معظم الحالات، تتوافق المكونات مباشرة مع مكتبات LLVM. تشمل "المكونات الافتراضية" المفيدة:

all

تتضمن جميع مكتبات LLVM. الافتراضي إذا لم يتم تحديد مكونات.

backend

تتضمن إما الواجهة الخلفية الأصلية أو الواجهة الخلفية C.

engine

تتضمن إما JIT الأصلية أو مترجم الكود الثنائي.

حالة الخروج

إذا نجح llvm-config، فسوف يخرج برمز 0. بخلاف ذلك، إذا حدث خطأ، فسوف يخرج بقيمة غير صفرية.

المؤلف

تم صيانته بواسطة فريق LLVM (https://llvm.org/).
