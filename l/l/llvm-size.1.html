llvm-size(1)

الحزمة: llvm

التراخيص: Apache-2.0 WITH LLVM-exception

LLVM-SIZE(1) LLVM LLVM-SIZE(1)

الاسم

llvm-size - طباعة معلومات الحجم

الملخص

llvm-size [خيارات] [إدخال...]

الوصف

llvm-size هي أداة تقوم بطباعة معلومات الحجم للملفات الثنائية. تهدف إلى أن تكون بديلاً مباشرًا لـ size الخاص بـ GNU.

تقوم الأداة بطباعة معلومات الحجم لكل إدخال محدد. إذا لم يتم تحديد أي إدخال، فإن البرنامج يطبع معلومات الحجم لـ a.out. إذا تم تحديد "-" كملف إدخال، يقرأ llvm-size ملفًا من تدفق الإدخال القياسي. إذا كان الإدخال عبارة عن أرشيف، فسيتم عرض معلومات الحجم لجميع أعضائه.

الخيارات

-A
يعادل --format مع القيمة sysv.
--arch=<arch>
بنى (معماريات) الثنائيات العالمية Mach-O لعرض المعلومات لها.
-B
يعادل --format مع القيمة berkeley.
--common
تضمين أحجام رموز ELF المشتركة في حجم bss لتنسيق الإخراج berkeley، أو كإدخال قسم منفصل لتنسيق الإخراج sysv. إذا لم يتم تحديده، يتم تجاهل هذه الرموز.
-d
يعادل --radix مع القيمة 10.
-l
عرض معلومات مفصلة للعناوين والإزاحات للمقاطع والأقسام في ملفات Mach-O بتنسيق darwin.
--format=<format>
تعيين تنسيق الإخراج إلى <format> المحدد. التنسيقات المتوفرة هي berkeley (الافتراضي)، sysv، و darwin.

يلخص إخراج Berkeley أحجام text و data و bss في كل ملف، كما هو موضح أدناه لمجموعة نموذجية من ملفات ELF:

$ llvm-size --format=berkeley test.o test2.o
   text    data     bss     dec     hex filename
    182      16       5     203      cb test.elf
     82       8       1      91      5b test2.o

بالنسبة لملفات Mach-O، يختلف تنسيق الإخراج قليلاً:

$ llvm-size --format=berkeley macho.obj macho2.obj
__TEXT  __DATA  __OBJC  others  dec     hex
4       8       0       0       12      c       macho.obj
16      32      0       0       48      30      macho2.obj

يعرض إخراج Sysv الحجم ومعلومات العنوان لمعظم الأقسام، مع إدراج كل ملف بشكل منفصل:

$ llvm-size --format=sysv test.elf test2.o
   test.elf  :
   section       size      addr
   .eh_frame       92   2097496
   .text           90   2101248
   .data           16   2105344
   .bss             5   2105360
   .comment       209         0
   Total          412
   test2.o  :
   section             size   addr
   .text                 26      0
   .data                  8      0
   .bss                   1      0
   .comment             106      0
   .note.GNU-stack        0      0
   .eh_frame             56      0
   .llvm_addrsig          2      0
   Total                199

يؤثر تنسيق darwin فقط على ملفات الإدخال Mach-O. إذا تم تحديد إدخال بتنسيق ملف مختلف، يعود llvm-size إلى تنسيق berkeley. عند إنتاج تنسيق darwin، تعرض الأداة معلومات حول المقاطع والأقسام:

$ llvm-size --format=darwin macho.obj macho2.obj
   macho.obj:
   Segment : 12
           Section (__TEXT, __text): 4
           Section (__DATA, __data): 8
           total 12
   total 12
   macho2.obj:
   Segment : 48
           Section (__TEXT, __text): 16
           Section (__DATA, __data): 32
           total 48
   total 48
--help, -h
عرض ملخص لخيارات سطر الأوامر.
-m
يعادل --format مع القيمة darwin.
-o
يعادل --radix مع القيمة 8.
--radix=<value>
عرض معلومات الحجم بالأساس المحدد. القيم المسموح بها هي 8 و 10 (الافتراضي) و 16 للإخراج الثماني والعشري والسداسي عشري على التوالي.

مثال:

$ llvm-size --radix=8 test.o
   text    data     bss     oct     hex filename
   0152      04      04     162      72 test.o
$ llvm-size --radix=10 test.o
   text    data     bss     dec     hex filename
   106       4       4     114      72 test.o
$ llvm-size --radix=16 test.o
   text    data     bss     dec     hex filename
   0x6a     0x4     0x4     114      72 test.o
--totals, -t
ينطبق فقط على تنسيق الإخراج berkeley. عرض الإجماليات لجميع الحقول المدرجة، بالإضافة إلى إدخالات الملفات الفردية.

مثال:

$ llvm-size --totals test.elf test2.o
   text    data     bss     dec     hex filename
    182      16       5     203      cb test.elf
     82       8       1      91      5b test2.o
    264      24       6     294     126 (TOTALS)
--version
عرض إصدار الملف التنفيذي llvm-size.
-x
يعادل --radix مع القيمة 16.
@<FILE>
قراءة خيارات سطر الأوامر من ملف الاستجابة <FILE>.

حالة الخروج

ينتهي llvm-size برمز خروج غير صفري في حالة حدوث خطأ. وإلا، فإنه ينتهي بالرمز 0.

الأخطاء

للإبلاغ عن الأخطاء، يرجى زيارة <https://github.com/llvm/llvm-project/labels/tools:llvm-size/>.

تمت صيانته بواسطة فريق LLVM (https://llvm.org/).

    NAME

    llvm-size — display information about the size of object files

    SYNOPSIS

    llvm-size [OPTION...] [FILE...]

    DESCRIPTION

    The llvm-size utility displays the size of each section and the total size of each input object file. If no files are specified, the standard input is used. If multiple files are specified, the sizes are displayed for each file individually, and then a summary of the total sizes for all files is displayed.

    The output format is similar to the GNU size utility.

    OPTIONS

    --help

    Display a help message and exit.

    --version

    Display the version of llvm-size and exit.

    --format=<format>

    Specify the output format. Supported formats are:

    sysv

    System V Release 4 format.

    berkeley

    BSD Berkeley format.

    --radix=<radix>

    Specify the radix (number base) for sizes. Supported radixes are 8, 10, and 16.

    --common

    Display sizes of common symbols.

    --mtime

    Display the last modification time of each file.

    --totals

    Display the total sizes for all files.

    EXIT STATUS

    The exit status is 0 if the operation was successful, and non-zero otherwise.
