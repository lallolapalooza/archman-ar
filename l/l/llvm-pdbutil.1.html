الملخص

llvm-pdbutil [أمر فرعي] [خيارات]

الوصف

يعرض الأنواع والرموز وسجلات CodeView ومعلومات أخرى من ملف PDB، بالإضافة إلى معالجة وإنشاء ملفات PDB. يستخدم llvm-pdbutil عادةً في الاختبارات المستندة إلى FileCheck لاختبار وظائف قراءة وكتابة LLVM لملفات PDB، ولكنه يمكن استخدامه أيضًا للتحقيق العام في ملفات PDB والتحقيقات الجنائية، أو كبديل لـ cvdump.

الأوامر الفرعية

ينقسم llvm-pdbutil إلى عدة أوامر فرعية، كل منها مصمم لغرض مختلف. يتبع ملخص موجز لكل أمر، مع مزيد من التفاصيل في الأقسام التالية.

  • pretty - عرض معلومات الرمز والنوع بتنسيق يحاول أن يبدو مثل الكود المصدري الأصلي قدر الإمكان.
  • dump - عرض الأنواع والهياكل منخفضة المستوى من ملف PDB، بما في ذلك سجلات CodeView وجداول التجزئة وتدفقات PDB وما إلى ذلك.
  • bytes - عرض البيانات من تدفقات ملف PDB، السجلات، الأنواع، الرموز، إلخ كبايت خام.
  • yaml2pdb - بالنظر إلى وصف yaml لملف PDB، قم بإنشاء ملف PDB صالح يطابق هذا الوصف.
  • pdb2yaml - لملف PDB معين، قم بإنشاء وصف YAML لجزء من الملف أو كله بطريقة يمكن إعادة بناء PDB.
  • merge - بالنظر إلى ملفي PDB، قم بإنشاء ملف PDB ثالث يكون نتيجة دمج ملفي PDB المدخلين.

pretty

هام:

تم بناء الأمر الفرعي pretty على Windows DIA SDK، وبالتالي فهو غير مدعوم على المنصات غير التابعة لنظام Windows.

الاستخدام: llvm-pdbutil pretty [خيارات] <ملف PDB المدخل>

الملخص

يعرض الأمر الفرعي pretty تمثيلاً عالي المستوى للغاية لمعلومات التصحيح في برنامجك. نظرًا لأنه مبني على Windows DIA SDK، وهو واجهة برمجة التطبيقات القياسية التي تستعلم عنها أدوات ومصححات أخطاء Windows معلومات التصحيح، فإنه يقدم عرضًا أكثر مصداقية لكيفية تفسير مصحح الأخطاء لمعلومات التصحيح الخاصة بك مقارنةً بوضع يعرض سجلات CodeView منخفضة المستوى.

الخيارات

خيارات التصفية والفرز

ملاحظة:

تكون أولوية مرشحات exclude على مرشحات include. لذلك، إذا تطابق المرشح مع قاعدة include وقاعدة exclude، فسيتم استبعاده.
-exclude-compilands=<string>
عند عرض الوحدات المترجمة، مساهمات ملفات المصدر للوحدات المترجمة، أو الرموز لكل وحدة مترجمة، يوجه هذا الخيار llvm-pdbutil إلى استبعاد أي وحدات مترجمة تتطابق مع التعبير العادي المحدد.
-exclude-symbols=<string>
عند عرض الرموز العامة، العامة، أو لكل وحدة مترجمة، يوجه هذا الخيار llvm-pdbutil إلى استبعاد أي رموز تتطابق مع التعبير العادي المحدد.
-exclude-types=<string>
عند عرض الأنواع، يوجه هذا الخيار llvm-pdbutil إلى استبعاد أي أنواع تتطابق مع التعبير العادي المحدد.
-include-compilands=<string>
عند عرض الوحدات المترجمة، مساهمات ملفات المصدر للوحدات المترجمة، أو الرموز لكل وحدة مترجمة، قصر البحث الأولي على الوحدات المترجمة التي تتطابق مع التعبير العادي المحدد فقط.
-include-symbols=<string>
عند عرض الرموز العامة، العامة، أو لكل وحدة مترجمة، قصر البحث الأولي على الرموز التي تتطابق مع التعبير العادي المحدد فقط.
-include-types=<string>
عند عرض الأنواع، قصر البحث الأولي على الأنواع التي تتطابق مع التعبير العادي المحدد فقط.
-min-class-padding=<uint>
عرض الأنواع فقط التي تحتوي على قدر معين من حشو المحاذاة، مع مراعاة الحشو في الفئات الأساسية وأعضاء الحقول المجمعة.
-min-class-padding-imm=<uint>
عرض الأنواع فقط التي تحتوي على قدر معين من حشو المحاذاة، مع تجاهل الحشو في الفئات الأساسية وأعضاء الحقول المجمعة.
-min-type-size=<uint>
عرض الأنواع T فقط حيث يكون sizeof(T) أكبر من أو يساوي المقدار المحدد.
-no-compiler-generated
لا تعرض الأنواع والرموز التي تم إنشاؤها بواسطة المترجم.
-no-enum-definitions
عند عرض تعداد (enum)، لا تعرض التعداد الكامل (على سبيل المثال، قيم المُعدِّد الفردية).
-no-system-libs
لا تعرض الرموز من المكتبات النظامية.

NAME

llvm-pdbutil — PDB file utility

SYNOPSIS

llvm-pdbutil subcommand [options]

DESCRIPTION

The llvm-pdbutil is a tool for inspecting and manipulating PDB (Program Database) files.

The following subcommands are supported:

SUBCOMMANDS

dump

USAGE: llvm-pdbutil dump [options] <input PDB file>

Summary

The dump subcommand provides a general-purpose way to inspect the contents of a PDB file. It allows dumping various structures and streams within the PDB file in a human-readable format.

Options

-section-contribs
Dump section contributions.
-section-headers
Dump image section headers.
-section-map
Dump section map.
-string-table
Dump PDB string table.

bytes

USAGE: llvm-pdbutil bytes [options] <input PDB file>

Summary

Like the dump subcommand, the bytes subcommand displays low level information about the structure of a PDB file, but it is used for even deeper forensics. The bytes subcommand finds various structures in a PDB file based on the command line options specified, and dumps them in hex. Someone working on support for emitting PDBs would use this heavily, for example, to compare one PDB against another PDB to ensure byte-for-byte compatibility. It is not enough to simply compare the bytes of an entire file, or an entire stream because it's perfectly fine for the same structure to exist at different locations in two different PDBs, and "finding" the structure is half the battle.

Options

MSF File Options

-block-range=<start[-end]>
Dump binary data from specified range of MSF file blocks.
-byte-range=<start[-end]>
Dump binary data from specified range of bytes in the file.
-fpm
Dump the MSF free page map.
-stream-data=<string>
Dump binary data from the specified streams. Format is SN[:Start][@Size]. For example, -stream-data=7:3@12 dumps 12 bytes from stream 7, starting at offset 3 in the stream.

PDB Stream Options

-name-map
Dump bytes of PDB Name Map

DBI Stream Options

-ec
Dump the edit and continue map substream of the DBI stream.
-files
Dump the file info substream of the DBI stream.
-modi
Dump the modi substream of the DBI stream.
-sc
Dump section contributions substream of the DBI stream.
-sm
Dump the section map from the DBI stream.
-type-server
Dump the type server map from the DBI stream.

Module Options

-mod=<uint>
Limit all options in this category to the specified module index. By default, options in this category will dump bytes from all modules.
-chunks
Dump the bytes of each module's C13 debug subsection.
-split-chunks
When specified with -chunks, split the C13 debug subsection into a separate chunk for each subsection type, and dump them separately.
-syms
Dump the symbol record substream from each module.

Type Record Options

-id=<uint>
Dump the record from the IPI stream with the given type index.
-type=<uint>
Dump the record from the TPI stream with the given type index.

pdb2yaml

USAGE: llvm-pdbutil pdb2yaml [options] <input PDB file>

Summary

Options

yaml2pdb

USAGE: llvm-pdbutil yaml2pdb [options] <input YAML file>

Summary

Generate a PDB file from a YAML description. The YAML syntax is not described here. Instead, use llvm-pdbutil pdb2yaml and examine the output for an example starting point.

Options

-pdb=<file-name>

Write the resulting PDB to the specified file.

merge

USAGE: llvm-pdbutil merge [options] <input PDB file 1> <input PDB file 2>

Summary

Merge two PDB files into a single file.

Options

-pdb=<file-name>

Write the resulting PDB to the specified file.
