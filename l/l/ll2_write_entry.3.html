LL2_WRITE_ENTRY(3) دليل المبرمجين LL2_WRITE_ENTRY(3)

الاسم

ll2_write_entry - يكتب إدخالاً جديداً في قاعدة البيانات.

النبذة

#include <lastlog2.h>

int ll2_write_entry (struct ll2_context *context, const char *user, int64_t ll_time, const char *tty, const char *rhost, const char *pam_service, char **error);

الوصف

يكتب إدخالاً جديداً في قاعدة البيانات، والتي يتم تعريفها في context. إذا كانت context فارغة (NULL)، فسيتم استخدام قاعدة البيانات الافتراضية، المعرفة في LL2_DEFAULT_DATABASE.

time_t login_time = time(0); // الحصول على وقت النظام
char   *error = NULL;
const  char *user = "root";
int ret = ll2_write_entry (NULL, user, login_time, "pts/0",
                            "192.168.122.1", NULL, &error);

pam_service هو اسم الخدمة أو المثيل الذي أنشأ الإدخال (اختياري).

قيمة الإرجاع

يعيد 0 عند النجاح، -ENOMEM أو -1 عند فشل آخر. يحتوي error على سلسلة نصية للخطأ إذا كانت قيمة الإرجاع -1. لا يُضمن أن يحتوي error على سلسلة نصية للخطأ، وقد يكون فارغاً (NULL) أيضاً. يجب على المستدعي تحرير error.
