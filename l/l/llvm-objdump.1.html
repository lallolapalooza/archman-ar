llvm-objdump(1)

الحزمة: llvm

التراخيص: Apache-2.0 WITH LLVM-exception

LLVM-OBJDUMP(1) LLVM LLVM-OBJDUMP(1)

الاسم

llvm-objdump - أداة LLVM لعرض محتويات الملفات الكائنية

الملخص

llvm-objdump [الأوامر] [الخيارات] [أسماء الملفات...]

الوصف

تقوم الأداة llvm-objdump بطباعة محتويات الملفات الكائنية والصور النهائية المربوطة المسماة في سطر الأوامر. إذا لم يتم تحديد اسم ملف، ستحاول llvm-objdump القراءة من a.out. إذا تم استخدام - كاسم ملف، ستعالج llvm-objdump ملفًا من تدفق الإدخال القياسي الخاص بها.

الأوامر

يجب تحديد واحد على الأقل من الأوامر التالية، ويمكن دمج بعض الأوامر مع أوامر أخرى:

-a, --archive-headers
عرض المعلومات الموجودة داخل رؤوس الأرشيف.
-d, --disassemble
تفكيك جميع الأقسام التنفيذية الموجودة في ملفات الإدخال. على بعض المعماريات (AArch64، PowerPC، x86)، يتم تفكيك جميع التعليمات المعروفة افتراضيًا. على المعماريات الأخرى، يلزم استخدام --mcpu أو --mattr لتمكين مجموعات تعليمات معينة. يتم عرض التعليمات المعطلة على أنها <unknown>.
-D, --disassemble-all
تفكيك جميع الأقسام الموجودة في ملفات الإدخال.
--disassemble-symbols=<symbol1[,symbol2,...]>
تفكيك الرموز المحددة فقط. يأخذ أسماء الرموز التي تم فك تشفيرها عند تحديد --demangle، وإلا فإنه يأخذ أسماء الرموز المشفرة. يتضمن --disassemble.
--dwarf=<value>
عرض أقسام DWARF لتصحيح الأخطاء المحددة. القيم المدعومة هي:

frames - .debug_frame

-f, --file-headers
عرض محتويات رأس الملف الإجمالي.
--fault-map-section
عرض محتويات قسم خريطة الأخطاء.
-h, --headers, --section-headers
عرض ملخصات رؤوس كل قسم.
--help
عرض معلومات الاستخدام والخروج. لا يتداخل مع الأوامر الأخرى.
-p, --private-headers
عرض رؤوس الملفات الخاصة بالتنسيق.
-r, --reloc
عرض إدخالات إعادة التوطين في الملف.
-R, --dynamic-reloc
عرض إدخالات إعادة التوطين الديناميكية في الملف.
--raw-clang-ast
عرض المحتويات الثنائية الخام لقسم clang AST.
-s, --full-contents
عرض محتويات كل قسم.
-t, --syms
عرض جدول الرموز.
-T, --dynamic-syms
عرض محتويات جدول الرموز الديناميكي.
-u, --unwind-info
عرض معلومات فك التعبئة للمدخلات.

هذه العملية مدعومة حاليًا فقط لملفات COFF و Mach-O الكائنية.

-v, --version
عرض إصدار الملف التنفيذي llvm-objdump. لا يتداخل مع الأوامر الأخرى.
-x, --all-headers
عرض جميع معلومات الرأس المتاحة. يعادل تحديد --archive-headers، --file-headers، --private-headers، --reloc، --section-headers، و --syms.

الخيارات

تدعم llvm-objdump الخيارات التالية:

--adjust-vma=<offset>
زيادة العنوان المعروض في تفكيك أو طباعة رؤوس الأقسام بواسطة الإزاحة المحددة.
--arch-name=<string>
تحديد بنية المعالج المستهدفة عند تفكيك الشفرة. استخدم --version للحصول على قائمة بالأهداف المتاحة.
--build-id=<string>
البحث عن الكائن باستخدام معرف البناء المعطى، المحدد كسلسلة ست عشرية. يتم التعامل مع الكائن الذي تم العثور عليه كما لو كان اسم ملف إدخال.
-C, --demangle
فك تشفير أسماء الرموز في المخرجات.
--debug-file-directory <path>
توفير مسار إلى دليل يحتوي على دليل فرعي .build-id للبحث عن معلومات تصحيح الأخطاء للملفات الثنائية المجردة. يتم البحث في مثيلات متعددة لهذه الوسيطة بالترتيب المعطى.
--debuginfod, --no-debuginfod
ما إذا كان سيتم محاولة البحث في debuginfod عن الملفات الثنائية لتصحيح الأخطاء أم لا. ما لم يتم تحديده، يتم تمكين debuginfod فقط إذا تم تجميع libcurl (LLVM_ENABLE_CURL) وتم توفير عنوان URL للخادم واحد على الأقل بواسطة متغير البيئة DEBUGINFOD_URLS.
--debug-vars=<format>
طباعة مواقع (في السجلات أو الذاكرة) للمتغيرات على مستوى المصدر بجانب تفكيك الشفرة. قد تكون format هي unicode أو ascii، الافتراضي هو unicode إذا تم حذفه.
--debug-vars-indent=<width>
المسافة البادئة لعرض المتغيرات على مستوى المصدر، بالنسبة لبداية تفكيك الشفرة. الافتراضي هو 52 حرفًا.
-j, --section=<section1[,section2,...]>
تنفيذ الأوامر على الأقسام المحددة فقط. بالنسبة لـ Mach-O استخدم segment,section لتحديد اسم القسم.
-l, --line-numbers
عند تفكيك الشفرة، عرض أرقام أسطر المصدر. يتضمن --disassemble.
-M, --disassembler-options=<opt1[,opt2,...]>
تمرير خيارات تفكيك الشفرة الخاصة بالهدف. الخيارات المتاحة:
  • reg-names-std: ARM فقط (افتراضي). الطباعة في وثائق تعليمات ARM 's'، مع استبدال r13/r14/r15 بـ sp/lr/pc.
  • reg-names-raw: ARM فقط. استخدام r متبوعة برقم السجل.
  • no-aliases: AArch64 و RISC-V فقط. طباعة الاسم الرمزي الخام للتعليمات بدلاً من الاسم الرمزي الزائف.
  • numeric: RISC-V فقط. طباعة أسماء السجلات الخام بدلاً من الاسم الرمزي لـ ABI. (على سبيل المثال، طباعة x1 بدلاً من ra)
  • att

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

: x86 فقط (الافتراضي). الطباعة بلغة AT&T .
  • intel: x86 فقط. الطباعة بلغة intel .
    • --disassembler-color=<mode>
    تمكين أو تعطيل إخراج ملون للمفكك.
    • off: تعطيل إخراج ملون للمفكك.
    • on: تمكين إخراج ملون للمفكك.
    • terminal: تمكين إخراج ملون للمفكك إذا كان الجهاز الطرفي يدعم ذلك (الافتراضي).
    --mcpu=<cpu-name>
    استهداف نوع معالج محدد لفك التجميع. قم بتحديد --mcpu=help لعرض المعالجات المتاحة.
    --mattr=<a1,+a2,-a3,...>
    تمكين/تعطيل سمات خاصة بالهدف. قم بتحديد --mattr=help لعرض السمات المتاحة.
    -mllvm <arg>
    تحديد وسيطة لتمريرها إلى مكتبة CommandLine الخاصة بـ LLVM.
    --no-leading-addr, --no-addresses
    عند فك التجميع، لا تطبع العناوين البادئة للتعليمات أو الانتقالات المضمنة.
    --no-print-imm-hex
    لا تستخدم تنسيق سداسي عشري للقيم الفورية في إخراج فك التجميع.
    --no-show-raw-insn
    عند فك التجميع، لا تطبع البايتات الأولية لكل تعليمة.
    --offloading
    عرض محتويات أقسام تفريغ LLVM وحزم تفريغ HIP.
    --prefix=<prefix>
    عند فك التجميع باستخدام الخيار --source، قم بإضافة البادئة prefix إلى المسارات المطلقة.
    --prefix-strip=<level>
    عند فك التجميع باستخدام الخيار --source، قم بإزالة level من الدلائل الأولية في المسارات المطلقة. هذا الخيار ليس له تأثير بدون --prefix.
    --print-imm-hex
    استخدم تنسيق سداسي عشري عند طباعة القيم الفورية في إخراج فك التجميع (الافتراضي).
    -S, --source
    عند فك التجميع، اعرض المصدر متداخلاً مع فك التجميع. تتضمن ضمنياً --disassemble.
    --show-all-symbols
    اعرض جميع الرموز أثناء فك التجميع، حتى لو تم تعريف رموز متعددة في نفس الموقع.
    --show-lma
    اعرض عمود LMA عند تفريغ رؤوس أقسام ELF. الافتراضي هو الإيقاف إلا إذا كان لدى أي قسم VMA و LMA مختلفين.
    --start-address=<address>
    عند فك التجميع، قم بفك التجميع فقط من العنوان المحدد.

    عند طباعة الانتقالات، قم بطباعة الانتقالات التي تصحح الإزاحات من address فما فوق.

    عند طباعة الرموز، قم بطباعة الرموز بقيمة لا تقل عن address.

    --stop-address=<address>
    عند فك التجميع، قم بفك التجميع فقط حتى العنوان المحدد، ولكن لا يشمله.

    عند طباعة الانتقالات، قم بطباعة الانتقالات التي تصحح الإزاحات حتى address.

    عند طباعة الرموز، قم بطباعة الرموز بقيمة تصل إلى address.

    --symbolize-operands
    عند فك التجميع، قم بترميز معامل الهدف الفرعي لطباعة تسمية بدلاً من عنوان حقيقي.

    عند طباعة مرجع رمز عام نسبي إلى PC، قم بطباعته كإزاحة من الرمز الرائد.

    عند وجود قسم bb-address-map (أي، تم بناء ملف الكائن باستخدام -fbasic-block-address-map)، يتم استرداد التسميات من هذا القسم بدلاً من ذلك. إذا كان هناك pgo-analysis-map موجودًا بجانب bb-address-map، فسيتم طباعة أي تحليلات متاحة بعد تسمية الكتلة ذات الصلة. افتراضيًا، يتم طباعة أي تحليل بتنسيق خاص (أي، BlockFrequency، BranchProbability، إلخ) كقيم سداسية عشرية خام.

    مدعوم فقط لـ AArch64 و BPF و PowerPC و X86.

    Example:
    تعليمة فرعية غير مرمزة مع هدف محلي ووصول إلى الذاكرة نسبي إلى PC مثل
    cmp eax, dword ptr [rip + 4112]
jge 0x20117e <_start+0x25>

    قد تصبح

    <L0>:
  cmp eax, dword ptr <g>
  jge      <L0>
    --pretty-pgo-analysis-map
    عند استخدام --symbolize-operands مع bb-address-map و pgo-analysis-map، قم بطباعة التحليلات باستخدام نفس تنسيق تمريرات التحليل الخاصة بها. مثال على التنسيق الجذاب سيكون طباعة ترددات الكتل بالنسبة لكتلة الدخول، بنفس طريقة BFI.

    يعمل فقط عندما يتم تمكين --symbolize-operands.

    --triple=<string>
    الهدف الثلاثي لفك التجميع، راجع --version للأهداف المتاحة.
    -w, --wide
    تم التجاهل للتوافق مع GNU objdump.
    --x86-asm-syntax=<style>
    تم إهماله. عند استخدامه مع --disassemble، اختر نمط التعليمات البرمجية لإخراجها من الواجهة الخلفية X86. القيم المدعومة هي:
    att
    تجميع بأسلوب AT&T
    intel
    تجميع بأسلوب Intel

    نمط فك التجميع الافتراضي هو att.

    -z, --disassemble-zeroes
    لا تتخطى الكتل الصفرية عند فك التجميع.
    @<FILE>
    اقرأ خيارات وأوامر سطر الأوامر من ملف الاستجابة <FILE>.

    --archive-member-offsets

    --chained-fixups
    اطبع معلومات إصلاحات الربط المتسلسلة.
    --dyld-info
    اعرض معلومات الربط وإعادة التعيين التي يستخدمها dyld لحل المراجع الخارجية في ثنائي مرتبط نهائي.
    --dylibs-used

    --dsym=<string>
    استخدم ملف .dSYM لمعلومات التصحيح.
    --dylib-id
    اعرض معرف المكتبة المشتركة لملفات dylib.
    --exports-trie
    اعرض الرموز المصدرة.
    --function-starts [=<addrs|names|both>]

    اطبع معلومات الخط من معلومات التصحيح إذا كانت متوفرة.

    NAME

    llvm-objdump — display information about object files

    SYNOPSIS

    llvm-objdump [-option...] [--] [file...]

    DESCRIPTION

    The llvm-objdump utility displays information from object files. It is intended to be a more portable and feature-rich replacement for the traditional objdump utility. It supports a variety of file formats, including ELF, COFF, Mach-O, and Wasm.

    This document describes the options available for llvm-objdump.

    COMMANDS

    The following options select which information to display. If no information selecting options are specified, llvm-objdump displays the symbol table.

    -a
    Dump all information in the archive.
    -A
    Dump all information in the archive. This is an alias for -a.
    -d, --disassemble
    Disassemble all code sections.
    -D, --disassemble-all
    Disassemble all symbols.
    -f, --file-headers
    Dump the file headers.
    -h, --headers-only
    Dump the file headers.
    -r, --relocations
    Dump the relocation bits.
    -s, --full-contents
    Dump the full contents of all readable sections, not just the symbol table.
    -t, --syms
    Dump the symbol table.
    -T, --dynamic-syms
    Dump the dynamic symbol table.
    -V, --version-info
    Dump the version info.
    -u, --needed-entries
    Dump the undefined needed libraries.
    -x, --all-header
    Dump all header information.
    --archive-member
    Only display information for the specified archive members.
    --bind-start
    Dump the binding info starting from the specified offset.
    --code
    Dump code sections.
    --data
    Dump data sections.
    --disassemble-symbols
    Only disassemble symbols that match the given regular expression.
    --exports-table
    Dump the export table.
    --external-is-und
    Treat external symbols as undefined.
    --flags
    Dump the flags.
    --indirect-symbols
    Dump the indirect symbol table.
    --info-plist
    Dump the info plist section as strings.
    --lazy-bind
    Dump lazy binding info.
    --link-opt-hints
    Dump the linker optimization hints.
    --objc-meta-data
    Dump the Objective-C runtime meta data.
    --private-header
    Dump only the first format specific file header.
    --rebasing
    Dump rebasing information.
    --rpaths
    Dump runtime search paths for the binary.
    --section-headers
    Dump section headers.
    --symbol-description
    Add symbol description to disassembly output.
    --text
    Dump text sections.
    --thread-local-storage
    Dump the thread-local storage information.
    --traceback-table
    Decode traceback table in disassembly output. Implies --disassemble.
    --universal-headers
    Dump universal headers.
    --unwind-table
    Dump the unwind table.
    -v, --verbose
    Increase verbosity.
    --weak-bind
    Dump weak binding information.

    OPTIONS

    The following options can be used to modify the output or behavior of llvm-objdump:

    -arch
    Select the architecture to display. This option is only applicable to Mach-O files that contain multiple architectures.
    -arch_name
    Select the specified architecture. This is a shorthand for -arch name.
    --demangle[=style]
    Decode C++ symbol names. The optional style argument specifies the demangling style. If not specified, the default style is used.
    --disasm-armor
    Attempt to display disassembled code in a more human-readable format.
    --disassemble-fn=regex
    Only disassemble functions matching the regular expression regex.
    --dylib-install-name
    Display the dylib install name.
    --exports-trie
    Display the export trie.
    --exports-trie-details
    Display the export trie with details.
    --headers-count
    Print the number of headers.
    --indirect-symbols
    Display the indirect symbol table.
    --info-plist
    Display the info plist section as strings.
    --lazy-bind
    Display lazy binding info.
    --link-opt-hints
    Display the linker optimization hints.
    -m, --macho
    Use Mach-O specific object file parser. Commands and other options may behave differently when used with --macho.
    --no-leading-headers
    Do not print any leading headers.
    --no-symbolic-operands
    Do not print symbolic operands when disassembling.
    --non-verbose
    Display the information for Mach-O objects in non-verbose or numeric form.
    --objc-meta-data
    Display the Objective-C runtime meta data.
    --private-header
    Display only the first format specific file header.
    --rebase
    Display rebasing information.
    --rpaths
    Display runtime search paths for the binary.
    --universal-headers
    Display universal headers.
    --weak-bind
    Display weak binding information.
