llength(n)

الحزمة: tcl

التراخيص: TCL

llength(n) أوامر Tcl المضمنة llength(n)

الاسم

llength - عد عدد العناصر في قائمة

الملخص

llength list

الوصف

يعامل list كقائمة ويعيد سلسلة عشرية تعطي عدد العناصر فيها.

أمثلة

النتيجة هي عدد العناصر:

% llength {a b c d e}
5
% llength {a b c}
3
% llength {}
0

بالطبع، لا يُضمن أن تكون العناصر بالضرورة كلمات بالمعنى الحرفي للكلمة، خاصة عند استخدام علامات الاقتباس:

% llength {a b {c d} e}
4
% llength {a b { } c d e}
6

القائمة الفارغة ليست بالضرورة سلسلة فارغة:

% set var { }; puts "[string length $var],[llength $var]"
1,0
