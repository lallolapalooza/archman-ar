less(3perl) دليل مبرمجي بيرل less(3perl)

الاسم

less - صيغة بيرل لطلب القليل من شيء ما

الملخص

use less 'CPU';

الوصف

هذه صيغة مستخدم. إذا كنت محظوظًا جدًا، فإن بعض الأكواد التي تستخدمها ستعلم أنك طلبت استخدامًا أقل لوحدة المعالجة المركزية أو الذاكرة أو الدهون أو ... لا يمكننا معرفة ذلك. استشر وثائقك حول كل شيء تستخدمه حاليًا.

للحصول على اقتراحات عامة، جرب طلب "CPU" أو "memory".

use less 'memory';
use less 'CPU';
use less 'fat';

إذا طلبت لا شيء على وجه الخصوص، فسوف تطلب less 'please'.

use less 'please';

لمؤلفي الوحدات

كانت `less` موجودة في الأساس كوحدة "مزحة" منذ فترة طويلة، ولم يكن لديها أي طريقة حقيقية لتوصيل أي معلومات إلى أي شيء. بفضل Nicholas Clark، لدينا صيغ المستخدم (انظر perlpragma) والآن يمكن لـ "less" أن تفعل شيئًا.

يمكنك على الأرجح توقع أن يتمكن المستخدمون من تخمين أنه يمكنهم طلب استخدام أقل لوحدة المعالجة المركزية أو الذاكرة أو فقط "أقل" بشكل عام.

إذا لم يحدد المستخدم أي شيء، يتم تفسيره على أنه استخدم علامة "please". الأمر متروك لك لجعل هذا مفيدًا.

# مكافئ
use less;
use less 'please';

"BOOLEAN = less->of( FEATURE )"

الطريقة القياسية "less->of( NAME )" تُرجع قيمة منطقية لتخبرك ما إذا كان المستخدم قد طلب تقليل شيء ما.

if ( less->of( 'CPU' ) ) {
    ...
}
elsif ( less->of( 'memory' ) ) {
}

"FEATURES = less->of()"

إذا لم تطلب أي ميزة، فستحصل على قائمة الميزات التي طلب المستخدم منك أن تكون لطيفًا بشأنها. هذا له تأثير جانبي لطيف وهو أنه إذا لم تحترم أي شيء على وجه الخصوص، فيمكنك فقط طلبه واستخدامه كقيمة منطقية.

if ( less->of ) {
    ...
}
else {
    ...
}

محاذير

هذا غالبًا لا يفعل شيئًا.
يعمل هذا فقط على الإصدار 5.10+
على الأقل هو متوافق مع الإصدارات السابقة في عدم القيام بالكثير.
