lm32-elf-gcov-tool(1)

الحزمة: lm32-elf-gcc

التراخيص: GPL-3.0-with-GCC-exception AND GFDL-1.3-or-later

GCOV-TOOL(1) GNU GCOV-TOOL(1)

الاسم

gcov-tool - أداة معالجة ملفات gcda غير متصلة

الملخص

gcov-tool [-v|--version] [-h|--help]

gcov-tool merge [merge-options] directory1 directory2
[-o|--output directory]
[-v|--verbose]
[-w|--weight w1,w2]

gcov-tool merge-stream [merge-stream-options] [file]
[-v|--verbose]
[-w|--weight w1,w2]

gcov-tool rewrite [rewrite-options] directory
[-n|--normalize long_long_value]
[-o|--output directory]
[-s|--scale float_or_simple-frac_value]
[-v|--verbose]

gcov-tool overlap [overlap-options] directory1 directory2
[-f|--function]
[-F|--fullname]
[-h|--hotonly]
[-o|--object]
[-t|--hot_threshold] float
[-v|--verbose]

الوصف

gcov-tool هي أداة غير متصلة لمعالجة ملفات gcda الخاصة بـ gcc.

تدعم gcov-tool الحالية الوظائف التالية:

  • دمج مجموعتين من الملفات التعريفية بأوزان.
  • قراءة تيار من الملفات التعريفية مع أسماء الملفات المرتبطة ودمجها مع مجموعة من الملفات التعريفية بأوزان.
  • قراءة مجموعة واحدة من الملفات التعريفية وإعادة كتابة محتويات الملف التعريفي. يمكن للمرء تغيير حجم أو تطبيع قيم العدادات.

تشمل الأمثلة على حالات استخدام هذه الأداة ما يلي:

  • جمع الملفات التعريفية لمجموعات مختلفة من المدخلات، واستخدام هذه الأداة لدمجها. يمكن للمرء تحديد الوزن لدمج الأهمية النسبية لكل مدخل.
  • جمع الملفات التعريفية من الأنظمة المستهدفة بدون نظام ملفات (بيئات قائمة بذاتها). دمج الملفات التعريفية المجمعة مع الملفات التعريفية المرتبطة الموجودة على النظام المضيف. يمكن للمرء تحديد الوزن لدمج الأهمية النسبية لكل مدخل.
  • إعادة كتابة الملف التعريفي بعد إزالة مجموعة فرعية من ملفات gcda، مع الحفاظ على اتساق الملخص والرسم البياني.
  • يمكن استخدامها أيضًا لتصحيح أخطاء كود libgcov أو استخدامه، حيث تشترك الأداة في الجزء الأكبر من الكود مع المكتبة التشغيلية.

لاحظ أنه لعملية الدمج، قد يحتوي هذا الملف التعريفي الذي تم إنشاؤه بشكل غير متصل على قيم مختلفة قليلاً عن الملف التعريفي المدمج عبر الإنترنت. فيما يلي قائمة بالاختلافات النموذجية:

  • اختلاف الرسم البياني: تعيد هذه الأداة غير المتصلة حساب الرسم البياني بعد دمج العدادات. وبالتالي، فإن الرسم البياني الناتج دقيق. لا تمتلك عملية الدمج عبر الإنترنت هذه القدرة - يتم دمج الرسم البياني من رسمين بيانيين والنتيجة هي تقريب.
  • اختلاف مجموع الملخص: يستخدم مجموع الملخص عملية CRC32. تعتمد القيمة على ترتيب قائمة الارتباط لكائنات gcov-info. يختلف هذا الترتيب في gcov-tool عنه في الدمج عبر الإنترنت. من المتوقع وجود مجموعات ملخص مختلفة. هذا لا يهم حقًا حيث أن المترجم لا يستخدم هذا المجموع في أي مكان.
  • اختلاف قيم عدادات الملف التعريفي للقيمة: بعض قيم العدادات للملف التعريفي للقيمة تعتمد على وقت التشغيل، مثل عناوين الكومة. من الطبيعي رؤية بعض الاختلاف في هذه الأنواع من العدادات.

الخيارات

-h
--help
عرض المساعدة حول استخدام gcov-tool (على المخرج القياسي)، والخروج دون إجراء أي معالجة إضافية.
-v
--version
عرض رقم إصدار gcov-tool (على المخرج القياسي)، والخروج دون إجراء أي معالجة إضافية.
merge
دمج دليلين للملفات التعريفية.
-o directory
--output directory
تعيين دليل الملف التعريفي الناتج. اسم دليل الإخراج الافتراضي هو merged_profile.
-v
--verbose
تعيين وضع المسهب.
-w w1,w2
--weight w1,w2
تعيين أوزان الدمج للمجلدين directory1 و directory2، على التوالي. الأوزان الافتراضية هي 1 لكليهما.
merge-stream
جمع الملفات التعريفية مع أسماء الملفات المرتبطة من تيار بيانات gcfn و gcda. قراءة التيار من الملف المحدد بواسطة file أو من stdin. دمج الملفات التعريفية مع الملفات التعريفية المرتبطة في نظام الملفات المضيف. تطبيق الأوزان الاختيارية أثناء دمج الملفات التعريفية.

لإنشاء تيار بيانات gcfn و gcda على النظام المستهدف، يرجى الاطلاع على الدوال "__gcov_filename_to_gcfn()" و "__gcov_info_to_gcda()" المعلنة في "#include <gcov.h>".

-v
--verbose
تعيين وضع المسهب.
-w w1,w2
--weight w1,w2
تعيين أوزان الدمج للملفات التعريفية من تيار بيانات gcfn و gcda والملفات التعريفية المرتبطة في نظام الملفات المضيف، على التوالي. الأوزان الافتراضية هي 1 لكليهما.
rewrite
قراءة دليل الملف التعريفي المحدد وإعادة الكتابة إلى دليل جديد.
-n long_long_value
--normalize <long_long_value>
تطبيع الملف التعريفي. القيمة المحددة هي أقصى قيمة عداد في الملف التعريفي الجديد.
-o directory
--output directory
تعيين دليل الملف التعريفي الناتج. اسم الإخراج الافتراضي هو rewrite_profile.
-s float_or_simple-frac_value
--scale float_or_simple-frac_value
تغيير حجم عدادات الملف التعريفي. يمكن أن تكون القيمة المحددة في شكل قيمة فاصلة عائمة، أو قيمة كسرية بسيطة، مثل 1، 2، 2/3، و 5/3.
-v
--verbose
تعيين وضع المسهب.
overlap
حساب درجة التداخل بين دليلي الملفات التعريفية المحددين. يتم حساب درجة التداخل بناءً على الملفات التعريفية للأقواس. يتم تعريفها على أنها مجموع min (p1_counter[i] / p1_sum_all, p2_counter[i] / p2_sum_all)، لجميع عدادات الأقواس i، حيث p1_counter[i] و p2_counter[i] هما عدادان متطابقان و p1_sum_all و p2_sum_all هما مجموع قيم العدادات في الملف التعريفي 1 و 2، على التوالي.
-f
--function
طباعة درجة تداخل الدالة.
-F
--fullname
طباعة اسم ملف gcda بالكامل.
-h
--hotonly
طباعة المعلومات الخاصة بـ

lm32-elf-gcov-tool(1) — Arch Linux

NAME

lm32-elf-gcov-tool(1) — tool to manipulate gcov data

SYNOPSIS

lm32-elf-gcov-tool [-b|--branch] [-c|--counts] [-d|--dump] [-f|--functions] [-o|--object] [-t float|--hot_threshold float] [-v|--verbose]

DESCRIPTION

The gcov-tool utility is used to manipulate gcov data. This is a work in progress and has limited functionality at the moment.

OPTIONS

-b, --branch
Print branch coverage information.
-c, --counts
Print execution counts for each line.
-d, --dump
Dump gcov data to standard output.
-f, --functions
Print function execution counts.
-o, --object
Print object level overlap score.
-t float, --hot_threshold float
Set the threshold for hot counter value.
-v, --verbose
Set the verbose mode.

SEE ALSO

gpl(7), gfdl(7), fsf-funding(7), gcc(1), gcov(1) and the Info entry for gcc.
