lm.3bobcat

الحزمة: libbobcat

التراخيص: GPL

lm(3bobcat) مُعالج OFoldStream lm(3bobcat)

الاسم

FBB::lm - مُعالج يضبط الهوامش اليسرى لكائنات OFoldStream

الملخص

#include <bobcat/ofoldstream> أو
#include <bobcat/ofoldbuf>
خيار الربط: -lbobcat

الوصف

تنفذ الفئة lm مُعالجًا يمكن إدراجه في كائنات OFoldStream لضبط الهامش الأيسر للكائن إلى القيمة المطلوبة.

اعتمادًا على إعدادات علامة التبويب الخاصة بـ OFoldStream، تمثل القيمة المدرجة عدد أحرف المسافة الفارغة أو عدد أحرف علامة التبويب التي سيتم استخدامها للهامش الأيسر.

سيتم معالجة الطلب عند حرف السطر التالي أو مُعالج std::flush أو std::endl الذي يتم إدراجه في التدفق. إذا كان السطر لا يزال يستخدم كائن lm ومُعالج flush تم إدراجهما في التدفق، فسيصبح الهامش الأيسر الجديد فعالاً عند إدراج الكلمة التالية في هذا السطر (انظر قسم المثال أدناه).

يتم طرح استثناء bad_cast عند إدراج المُعالج في ostream لا يستخدم مخزنًا مؤقتًا OFoldBuf.

النطاق

FBB
تم تعريف جميع المنشئات والأعضاء والمُعاملات والمعالجات المذكورة في صفحة الدليل هذه في النطاق FBB.

ترث من

-

المنشئ

o
lm(size_t newValue):

منشئات النسخ والنقل (وعوامل التعيين) متاحة.

دوال العضو

o
std::ostream &modify(std::ostream &out) const:
عادةً لا يتم استدعاء هذا العضو مباشرة من برامج المستخدم. بدلاً من ذلك، يتم استدعاؤه بواسطة عامل الإدراج عند إدراج المُعالج lm.

مثال

    #include <iostream>
    #include <bobcat/ofoldstream>
    using namespace std;
    using namespace FBB;
    int main()
    {
        OFoldStream out(cout, 0, 80);
        out << "hello world (left margin is 0)" << lm(4) << "\n"
               "this uses a 4 character wide left margin\n" <<
               lm(0) << flush << "at column 0 again\n";
    }
