kubectl-auth-can-i(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl auth can-i - التحقق مما إذا كان الإجراء مسموحًا به

الملخص

kubectl auth can-i [خيارات]

الوصف

التحقق مما إذا كان الإجراء مسموحًا به.

VERB هو فعل منطقي لواجهة برمجة تطبيقات Kubernetes مثل 'get'، 'list'، 'watch'، 'delete'، إلخ. TYPE هو مورد Kubernetes. سيتم حل الاختصارات والمجموعات. NONRESOURCEURL هو عنوان URL جزئي يبدأ بـ "/". NAME هو اسم مورد Kubernetes معين. يتناسب هذا الأمر بشكل جيد مع الانتحال. انظر العلامة العامة --as.

الخيارات

-A, --all-namespaces=false إذا كانت صحيحة، تحقق من الإجراء المحدد في جميع مساحات الأسماء.

--list=false إذا كانت صحيحة، تطبع جميع الإجراءات المسموح بها.

--no-headers=false إذا كانت صحيحة، تطبع الإجراءات المسموح بها بدون رؤوس

-q, --quiet=false إذا كانت صحيحة، قم بقمع الإخراج وقم فقط بإرجاع رمز الخروج.

--subresource="" مورد فرعي مثل pod/log أو deployment/scale

الخيارات الموروثة من الأوامر الأصل

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة أسماء.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذه العلامة لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--certificate-authority="" مسار إلى ملف شهادة السلطة

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كانت صحيحة، استبعاد ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كانت صحيحة، فلن يتم التحقق من صحة شهادة الخادم. سيؤدي هذا إلى جعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" مسار إلى ملف kubeconfig للاستخدام في طلبات CLI.

--kuberc="" مسار إلى ملف kuberc للاستخدام في التفضيلات. يمكن تعطيل هذا عن طريق تصدير KUBECTL_KUBERC=false بوابة الميزة أو إيقاف الميزة KUBERC=off.

--match-server-version=false طلب مطابقة إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كانت موجودة، نطاق مساحة الأسماء لطلب CLI هذا

--password="" كلمة المرور للمصادقة الأساسية إلى خادم API

--profile="none" اسم الملف التعريفي لالتقاطه. أحد (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف لكتابة الملف التعريفي إليه

--request-timeout="0" طول الوقت للانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة وقت مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء مهلة الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم للاستخدام في التحقق من صحة شهادة الخادم. إذا لم يتم توفيره، فسيتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز حامل للمصادقة إلى خادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية إلى خادم API

--version=false --version، --version=raw تطبع معلومات الإصدار وتخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false معاملة التحذيرات الواردة من الخادم كأخطاء والخروج برمز خروج غير صفري

مثال

  # تحقق مما إذا كان بإمكاني إنشاء pods في أي مساحة أسماء
  kubectl auth can-i create pods --all-namespaces
  # تحقق مما إذا كان بإمكاني سرد deployments في مساحة الأسماء الحالية
  kubectl auth can-i list deployments.apps
  # تحقق مما إذا كان حساب الخدمة "foo" في مساحة الأسماء "dev" يمكنه سرد pods في مساحة الأسماء "prod"
  # يجب أن يُسمح لك باستخدام الانتحال للعلامة العامة "--as"
  kubectl auth can-i list pods --as=system:serviceaccount:dev:foo -n prod
  # تحقق مما إذا كان بإمكاني فعل كل شيء في مساحة الأسماء الحالية ("*" تعني الكل)
  kubectl auth can-i '*' '*'
  # تحقق مما إذا كان بإمكاني الحصول على الوظيفة المسماة "bar" في مساحة الأسماء "foo"
  kubectl auth can-i list jobs.batch/bar -n foo
  # تحقق مما إذا كان بإمكاني قراءة سجلات pods
  kubectl auth can-i get pods --subresource=log
  # تحقق مما إذا كان بإمكاني الوصول إلى عنوان URL /logs/
  kubectl auth can-i get /logs/
  # تحقق مما إذا كان بإمكاني الموافقة على certificates.k8s.io
  kubectl auth can-i approve certificates.k8s.io
  # سرد جميع الإجراءات المسموح بها في مساحة الأسماء "foo"
  kubectl auth can-i --list --namespace=foo
