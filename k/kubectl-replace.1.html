NAME

kubectl-replace - Replace a resource by filename or stdin

SYNOPSIS

kubectl replace -f FILENAME [options]

kubectl replace -f - [options]

DESCRIPTION

Replace a resource by filename or stdin. This command is deprecated and will be removed in a later version. Use 'kubectl apply' instead.

A resource is replaced if it is not found, and created otherwise.

To create a resource by filename or stdin, use 'kubectl create'.

To update a resource by filename or stdin, use 'kubectl apply'.

To update a resource's live configuration by editing the resource's configuration, use 'kubectl edit'.

OPTIONS

The options below are inherited from the parent command:

--all-namespaces
If present, the namespaces on the client side are ignored. The server is used to determine the target namespaces. Therefore, the object will be found in the namespace specified on the server side.
--allow-missing-template-keys=true
If true, ignore any errors in templates when a field or map key is missing in the data provided. By default, this is false.
--append-hash-to-image-defaults=false
Append a hash to the image name by default.
--atomic=false
If true, the server will try to perform a resource update that is atomic.
--cascade=[background|orphan|foreground]
Must be "background", "orphan", or "foreground". When deleting a collection of objects, the behavior of this flag determines the cascade deletion. This is currently only supported when deleting a Deployment or a ReplicaSet.
--context
The name of the kubeconfig context to use. If not specified, the current-context is used.
--dry-run=false
If true, only print the object that would be sent, without sending it.
--field-manager=kubectl-replace
Name of the manager used for New resource conflict resolution.
--force=false
If true, immediately remove resources from API and bypass graceful deletion. Note that this means finalizers are not respected; use with caution.
--grace-period=-1
Period of time in seconds given to the resource to terminate gracefully. Ignored if negative. Set to 1 for immediate shutdown. Can only be used with --force.
--ignore-not-found=false
If true, ignore the error when the resource is not found.
--kustomize=""
Customize the resource before applying. Accepts a path to a kustomize directory.
--kubeconfig=""
kubeconfig file location.
--modify-annotation=[]
The annotations to add to the resource. Annotations with the same key will be overwritten.
--modify-label=[]
The labels to add to the resource. Labels with the same key will be overwritten.
--namespace=""
If present, the namespace scope for this CLI request.
--no-headers=false
When using the default or custom-columns output format, don't print headers (default print headers).
--record=false
Record current kubectl command in the resource annotation. If true, mark this command as disabling the annotation of the following commands.
--selector=""
Selector (label query) to filter on, supports '=', '==', and '!='.
--server-side=false
If true, use the server-side apply patch.
--template=""
Template string or path to template file rendered with gotpl.
--validate=true
If true, use prevent conflicts between string slices, between slices and strings, and between specific types. Otherwise, only send updates if the object already exists and the operation to update it works.

EXAMPLE

Replace a deployment named 'my-deployment' from a local file 'my-deployment.yaml' and set the image to 'myrepo/myimage:latest':

kubectl replace -f my-deployment.yaml --image=myrepo/myimage:latest

Replace a pod named 'my-pod' from stdin:

cat my-pod.yaml | kubectl replace -f -
