الاسم

kitten-desktop-ui-run-server - تشغيل الخوادم المختلفة المستخدمة للتكامل مع سطح مكتب لينكس

الاستخدام

kitten desktop-ui run-server

الوصف

يجب تشغيل هذا الأمر في وقت مبكر جدًا من تسلسل بدء تشغيل مدير النوافذ الخاص بك، قبل تشغيل أي برامج أخرى.

خيارات

--override, -o
تجاوز خيارات التكوين الفردية، يمكن تحديده عدة مرات. الصيغة: name=value. مثال: -o color_scheme=dark
--config, -c
تحديد مسار لملف (ملفات) التكوين لاستخدامه. يتم دمج جميع ملفات التكوين مع الملف المضمن desktop-ui-portal.conf، متجاوزة القيم المضمنة. يمكن تحديد هذا الخيار عدة مرات لقراءة ملفات تكوين متعددة بالتسلسل، والتي يتم دمجها. استخدم القيمة الخاصة NONE لعدم تحميل أي ملف تكوين.

إذا لم يتم تحديد هذا الخيار، يتم البحث عن ملفات التكوين بالترتيب التالي: $XDG_CONFIG_HOME/kitty/desktop-ui-portal.conf، ~/.config/kitty/desktop-ui-portal.conf، $XDG_CONFIG_DIRS/kitty/desktop-ui-portal.conf. أول ملف يوجد هو الذي يستخدم كملف تكوين.

إذا تم تحديد متغير البيئة KITTY_CONFIG_DIRECTORY، يتم استخدام هذا الدليل دائمًا ولا يحدث البحث المذكور أعلاه.

إذا كان الملف /etc/xdg/kitty/desktop-ui-portal.conf موجودًا، يتم دمجه قبل (أي بأولوية أقل) أي ملفات تكوين المستخدم. يمكن استخدامه لتحديد القيم الافتراضية على مستوى النظام لجميع المستخدمين. يمكنك استخدام إما - أو /dev/stdin لقراءة التكوين من STDIN.
