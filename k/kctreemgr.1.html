kctreemgr(1)

الحزمة: kyotocabinet

التراخيص: GPL-3.0-or-later

KCTREEMGR(1) كيوتو كابينت KCTREEMGR(1)

الاسم

kctreemgr - واجهة سطر الأوامر لإدارة قاعدة بيانات شجرة الملفات

الوصف

الأمر `kctreemgr' هو أداة لاختبار وتصحيح قاعدة بيانات شجرة الملفات وتطبيقاتها. `path' يحدد مسار ملف قاعدة البيانات. `key' يحدد مفتاح سجل. `value' يحدد قيمة سجل. `file' يحدد ملف الإدخال/الإخراج.


kctreemgr create [-otr] [-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-psiz num] [-rcd|-rcld|-rcdd] path
ينشئ ملف قاعدة بيانات.
kctreemgr inform [-onl|-otl|-onr] [-st] path
يطبع معلومات الحالة.
kctreemgr set [-onl|-otl|-onr] [-add|-app|-rep|-inci|-incd] [-sx] path key value
يخزن سجلاً.
kctreemgr remove [-onl|-otl|-onr] [-sx] path key
يزيل سجلاً.
kctreemgr get [-onl|-otl|-onr] [-rm] [-sx] [-px] [-pz] path key
يطبع قيمة سجل.
kctreemgr list [-onl|-otl|-onr] [-des] [-max num] [-rm] [-sx] [-pv] [-px] path [key]
يطبع مفاتيح جميع السجلات، مفصولة بأسطر جديدة.
kctreemgr clear [-onl|-otl|-onr] path
يزيل جميع سجلات قاعدة البيانات.
kctreemgr import [-onl|-otl|-onr] [-sx] path [file]
يستورد سجلات من ملف TSV.
kctreemgr copy [-onl|-otl|-onr] path file
ينسخ قاعدة البيانات بأكملها.
kctreemgr dump [-onl|-otl|-onr] path [file]
يقوم بتفريغ السجلات في ملف لقطة.
kctreemgr load [-otr] [-onl|-otl|-onr] path [file]
يقوم بتحميل السجلات من ملف لقطة.
kctreemgr defrag [-onl|-otl|-onr] path
يجري إزالة التجزئة.
kctreemgr setbulk [-onl|-otl|-onr] path key value ...
يخزن السجلات دفعة واحدة.
kctreemgr removebulk [-onl|-otl|-onr] [-sx] path key ...
يزيل السجلات دفعة واحدة.
kctreemgr getbulk [-onl|-otl|-onr] [-sx] [-px] path key ...
يسترجع السجلات دفعة واحدة.
kctreemgr check [-onl|-otl|-onr] path
يتحقق من الاتساق.

الخيارات تتميز بما يلي.

-otr : يفتح قاعدة البيانات مع خيار الاقتطاع.
-onl : يفتح قاعدة البيانات مع خيار عدم القفل.
-otl : يفتح قاعدة البيانات مع خيار محاولة القفل.
-onr : يفتح قاعدة البيانات مع خيار عدم الإصلاح التلقائي.
-apow num : يحدد قوة محاذاة حجم السجل.
-fpow num : يحدد قوة سعة مجمع الكتل الحرة.
-ts : يقوم بضبط قاعدة البيانات مع الخيار الصغير.
-tl : يقوم بضبط قاعدة البيانات مع الخيار الخطي.
-tc : يقوم بضبط قاعدة البيانات مع خيار الضغط.
-bnum num : يحدد عدد الدلاء في جدول التجزئة.
-psiz num : يحدد حجم كل صفحة.
-rcd : يستخدم مقارنة الأرقام العشرية بدلاً من المقارنة النصية.
-rcld : يستخدم مقارنة النص التنازلية بدلاً من التصاعدية.
-rcdd : يستخدم مقارنة الأرقام العشرية التنازلية بدلاً من المقارنة النصية.
-st : يطبع معلومات متنوعة.
-add : يؤدي عملية إضافة.
-app : يؤدي عملية إلحاق.
-rep : يؤدي عملية استبدال.
-inci : يؤدي عملية زيادة عدد صحيح.
-incd : يؤدي عملية زيادة أعداد حقيقية.
-sx : يتم تقييم بيانات الإدخال كسلسلة بيانات سداسية عشرية.
-rm : يزيل السجل.
-px : يتم تحويل بيانات الإخراج إلى سلسلة بيانات سداسية عشرية.
-pz : لا يضيف سطر جديد في نهاية الإخراج.
-des : يزور السجلات بترتيب تنازلي.
-max num : يحدد الحد الأقصى لعدد السجلات المعروضة.
-pv : يطبع قيم السجلات أيضًا.

يعيد هذا الأمر القيمة 0 عند النجاح، وقيمة أخرى عند الفشل.
