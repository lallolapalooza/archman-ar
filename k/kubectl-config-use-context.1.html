kubectl-config-use-context(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl config use-context - تعيين السياق الحالي في ملف kubeconfig

الاستخدام

kubectl config use-context [خيارات]

الوصف

تعيين السياق الحالي في ملف kubeconfig.

خيارات موروثة من الأوامر الأصل

--as=""      اسم المستخدم الذي سيتم انتحاله للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[]      المجموعة التي سيتم انتحالها للعملية، يمكن تكرار هذا الخيار لتحديد مجموعات متعددة.

--as-uid=""      معرف المستخدم (UID) الذي سيتم انتحاله للعملية.

--cache-dir="/home/username/.kube/cache"      دليل التخزين المؤقت الافتراضي

--certificate-authority=""      المسار إلى ملف شهادة للسلطة المصدقة

--client-certificate=""      المسار إلى ملف شهادة العميل لـ TLS

--client-key=""      المسار إلى ملف مفتاح العميل لـ TLS

--cluster=""      اسم مجموعة kubeconfig المراد استخدامها

--context=""      اسم سياق kubeconfig المراد استخدامه

--disable-compression=false      إذا كان صحيحًا، لا يتم ضغط الاستجابات لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false      إذا كان صحيحًا، لن يتم التحقق من صلاحية شهادة الخادم. سيجعل هذا اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig=""      استخدام ملف kubeconfig معين

--kuberc=""      المسار إلى ملف kuberc المراد استخدامه للتفضيلات. يمكن تعطيل ذلك عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف الميزة KUBERC=off.

--match-server-version=false      مطالبة إصدار الخادم بمطابقة إصدار العميل

-n, --namespace=""      إذا كان موجودًا، نطاق مساحة الاسم لطلب CLI هذا

--password=""      كلمة المرور للمصادقة الأساسية مع خادم API

--profile="none"      اسم الملف الشخصي المراد التقاطه. أحد الخيارات (none | cpu | heap | goroutine | threadcreate | block | mutex)

--profile-output="profile.pprof"      اسم الملف الذي سيتم كتابة الملف الشخصي إليه

--request-timeout="0"      المدة الزمنية للانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). قيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server=""      عنوان ومنفذ خادم Kubernetes API

--tls-server-name=""      اسم الخادم المراد استخدامه للتحقق من شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token=""      رمز حامل (Bearer token) للمصادقة مع خادم API

--user=""      اسم مستخدم kubeconfig المراد استخدامه

--username=""      اسم المستخدم للمصادقة الأساسية مع خادم API

--version=false      --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يعين الإصدار المبلغ عنه

--warnings-as-errors=false      معاملة التحذيرات المستلمة من الخادم كأخطاء والخروج برمز خروج غير صفري

مثال

  # استخدم السياق لمجموعة minikube
  kubectl config use-context minikube
