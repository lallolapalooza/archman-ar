NAME

kubectl-delete - Delete resources by filenames, stdin, selectors, labels, and tags

SYNOPSIS

kubectl delete [--all] [-A, --all-namespaces] [--cascade=[background|foreground|orphan] | --cascade-dependents] [-f, --filename FILENAME] [-k, --kustomize KUSTOMIZATION] [-l, --selector LABEL_SELECTOR] [--local] [--no-headers] [--ignore-not-found] [--force-conflicts] [--now] [--grace-period GRAVE_PERIOD] [-o, --output output] [-p, --providers PROVIDERS] [--resource-version string] [-R, --recursive] [-a, --all] [-n, --namespace NAMESPACE] [--all] [-w, --watch] [--wait] [--force] [--timeout TIMEOUT] [--confirm] [--interactive] [TYPE/NAME ...] [TYPE… ( NAME_PREFIX_OR_LABEL ...)]

DESCRIPTION

Delete resources by filenames, stdin, selectors, labels, and tags.

Note that label selectors and namespace flags are not supported for deleting multiple types. For example, you cannot run `kubectl delete pods,services -l foo=bar`.

Use --all to delete all resources specified by TYPE.

Use --cascade to control the deletion cascading behavior. Valid options are: background, foreground, orphan.

background: Delete the dependent objects immediately and delete the owner object after the dependent objects are deleted. foreground: Delete the owner object immediately and delete the dependent objects after the owner object is deleted. orphan: Owner object is deleted immediately, and dependent objects are not deleted.

Use --grace-period to specify the duration in seconds (non-negative integer) to wait for graceful termination. Set to 0 to force deletion immediately. Defaults to 30 seconds.

Use --force to skip the graceful shutdown period. Note that this requires the --grace-period=0 flag.

Use --now to delete resources immediately. This flag is a shortcut for --grace-period=0.

Use --interactive to prompt before deleting resources. This flag is a shortcut for --confirm.

Use --ignore-not-found to ignore not found errors when deleting resources. This will prevent the command from exiting with a non-zero exit code when one or more specified resources are not found.

Use --force-conflicts to immediately delete resources even if there are conflicts.

OPTIONS

--all - do not wait for deletion of resources that have the ServerSideApply field manager set. --all-namespaces, -A - If present, allow deleting resources from all namespaces. --cascade - Determines whether and how dependent objects should be deleted (default "background"). Possible values: background, foreground, orphan. --cascade-dependents - If present, immediately delete dependent objects and the owner object after the dependent objects are deleted. -f, --filename [] - Filename, directory, or URL to files identifying the resource to be deleted. -k, --kustomize - Process the kustomization directory. This flag runs kustomize build and then deletes the rendered manifest. -l, --selector - Selector (label query) to filter on, not including names. --local - If true, will won't run abstration, just print the resources that will be deleted. --no-headers - When using the default output format, don't print headers (default true). --ignore-not-found - Return 0 if the specified resources do not exist. --force-conflicts - Immediately delete resources, even if there are conflicts. --now - If true, call delete options with a timeout of 0. --grace-period int - Period of time in seconds to wait for processes to terminate. -o, --output string - Output format. One of: json|yaml|wide|name|custom-columns=...|custom-columns-file=...|go-template=...|go-template-file=...|jsonpath=...|jsonpath-file=.... -p, --providers string - Provider to use for the resource. --resource-version string - Only delete resources with the matching resource version. -R, --recursive - Process the directory used in -f, --filename recursively. -w, --watch - After the deletion request is sent, watch for changes to the deleted object until all specified objects are deleted. --wait - If true, wait until all deletions are final. --force - Force delete resources. This option is deprecated. Use --grace-period=0 and --now instead. --timeout string - The length of time to be waiting. Must be a non-negative number, followed by a unit: "ns", "us" (or "µs"), "ms", "s", "m", "h". If unit is omitted, the default unit is seconds. Invalid time units go against the help text. --confirm - If true, prompt user for confirmation. --interactive - If true, prompt user for confirmation. (default true)

EXAMPLE

  # Delete a pod using the type and name specified in pod.json
  kubectl delete -f ./pod.json
  # Delete resources from a directory containing kustomization.yaml - e.g. dir/kustomization.yaml
  kubectl delete -k dir
  # Delete resources from all files that end with '.json'
  kubectl delete -f '*.json'
  # Delete a pod based on the type and name in the JSON passed into stdin
  cat pod.json | kubectl delete -f -
  # Delete pods and services with same names "baz" and "foo"
  kubectl delete pod,service baz foo
  # Delete pods and services with label name=myLabel
  kubectl delete pods,services -l name=myLabel
  # Delete a pod with minimal delay
  kubectl delete pod foo --now
  # Force delete a pod on a dead node
  kubectl delete pod foo --force
  # Delete all pods
  kubectl delete pods --all
  # Delete all pods only if the user confirms the deletion
  kubectl delete pods --all --interactive
