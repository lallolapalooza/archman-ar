kubectl-auth-whoami(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl auth whoami - تجريبي: تحقق من سمات الموضوع الذاتي

الملخص

kubectl auth whoami [خيارات]

الوصف

تجريبي: تحقق من هويتك وسماتك (المجموعات، إضافات).

    هذا الأمر مفيد للتعرف على سمات المستخدم الحالية،
    خاصة عند تمكين المصادقة الديناميكية، على سبيل المثال، webhook للرموز، أو وكيل المصادقة، أو موفر OIDC،
    في مجموعة Kubernetes.

الخيارات

--allow-missing-template-keys=true إذا كان صحيحًا، فتجاهل أي أخطاء في القوالب عند فقدان حقل أو مفتاح خريطة في القالب. ينطبق فقط على تنسيقات الإخراج go-template و jsonpath.

-o, --output="" تنسيق الإخراج. أحد: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--show-managed-fields=false إذا كان صحيحًا، احتفظ بالحقول المُدارة عند طباعة الكائنات بتنسيق JSON أو YAML.

--template="" سلسلة القالب أو المسار إلى ملف القالب لاستخدامه عند -o=go-template, -o=go-template-file. تنسيق القالب هو قوالب golang [http://golang.org/pkg/text/template/#pkg-overview].

خيارات موروثة من الأوامر الأصل

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذا العلم لتحديد مجموعات متعددة.

--as-uid="" المعرف الفريد (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--certificate-authority="" المسار إلى ملف شهادة للسلطة المصدقة

--client-certificate="" المسار إلى ملف شهادة العميل لـ TLS

--client-key="" المسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كان صحيحًا، فتجاوز ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، فلن يتم التحقق من صحة شهادة الخادم. هذا سيجعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" المسار إلى ملف kubeconfig للاستخدام في طلبات CLI.

--kuberc="" المسار إلى ملف kuberc للاستخدام للتفضيلات. يمكن تعطيل هذا عن طريق تصدير KUBECTL_KUBERC=false بوابة ميزات أو إيقاف تشغيل الميزة KUBERC=off.

--match-server-version=false مطالبة إصدار الخادم بمطابقة إصدار العميل

-n, --namespace="" إذا كان موجودًا، نطاق مساحة الاسم لطلب CLI هذا

--password="" كلمة المرور للمصادقة الأساسية إلى خادم API

--profile="none" اسم الملف الشخصي لالتقاطه. أحد (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي سيتم كتابة الملف الشخصي إليه

--request-timeout="0" الوقت الذي يجب الانتظار قبل الاستسلام لطلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s, 2m, 3h). القيمة صفر تعني عدم انتهاء مهلة الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم لاستخدامه للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز حامل للمصادقة إلى خادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية إلى خادم API

--version=false --version, --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يضبط الإصدار المُبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # احصل على سمات الموضوع الخاص بك
  kubectl auth whoami
  # احصل على سمات الموضوع الخاص بك بتنسيق JSON
  kubectl auth whoami -o json
