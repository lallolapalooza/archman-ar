kubectl-patch(1)

الحزمة: kubectl

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl patch - تحديث حقول مورد

الملخص

kubectl patch [خيارات]

الوصف

تحديث حقول مورد باستخدام ترقيع الدمج الاستراتيجي (strategic merge patch)، أو ترقيع دمج JSON (JSON merge patch)، أو ترقيع JSON (JSON patch).

يتم قبول تنسيقات JSON و YAML.

ملاحظة: ترقيع الدمج الاستراتيجي غير مدعوم للموارد المخصصة.

خيارات

--allow-missing-template-keys=true إذا كانت صحيحة، تجاهل أي أخطاء في القوالب عند فقدان حقل أو مفتاح خريطة في القالب. ينطبق فقط على تنسيقات الإخراج golang و jsonpath.

--dry-run="none" يجب أن يكون "none" أو "server" أو "client". إذا كانت استراتيجية العميل، اطبع فقط الكائن الذي سيتم إرساله، دون إرساله. إذا كانت استراتيجية الخادم، قم بإرسال طلب من جانب الخادم دون تثبيت المورد.

--field-manager="kubectl-patch" اسم المدير المستخدم لتتبع ملكية الحقل.

-f, --filename=[] اسم ملف، دليل، أو عنوان URL للملفات التي تحدد المورد المراد تحديثه

-k, --kustomize="" معالجة دليل kustomization. لا يمكن استخدام هذا العلم مع -f أو -R.

--local=false إذا كانت صحيحة، سيعمل الترقيع على محتوى الملف، وليس المورد الموجود على جانب الخادم.

-o, --output="" تنسيق الإخراج. واحد من: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

-p, --patch="" الترقيع الذي سيتم تطبيقه على ملف JSON للمورد.

--patch-file="" ملف يحتوي على ترقيع سيتم تطبيقه على المورد.

--record=false تسجيل أمر kubectl الحالي في تعليق المورد. إذا تم تعيينه على false، لا تقم بتسجيل الأمر. إذا تم تعيينه على true، قم بتسجيل الأمر. إذا لم يتم تعيينه، الافتراضي هو تحديث قيمة التعليق التوضيحي الموجود فقط إذا كان موجودًا بالفعل.

-R, --recursive=false معالجة الدليل المستخدم في -f، --filename بشكل متكرر. مفيد عندما تريد إدارة البيانات الوصفية ذات الصلة المنظمة داخل نفس الدليل.

--show-managed-fields=false إذا كانت صحيحة، احتفظ بالحقول المُدارة عند طباعة الكائنات بتنسيق JSON أو YAML.

--subresource="" إذا تم تحديده، سيعمل الترقيع على المورد الفرعي للكائن المطلوب.

--template="" سلسلة قالب أو مسار لملف قالب لاستخدامه عند -o=go-template، -o=go-template-file. تنسيق القالب هو قوالب golang [http://golang.org/pkg/text/template/#pkg-overview].

--type="strategic" نوع الترقيع المقدم؛ واحد من [json merge strategic]

خيارات موروثة من أوامر الأصل

--as="" اسم المستخدم الذي سيتم انتحاله للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة التي سيتم انتحالها للعملية، يمكن تكرار هذا العلم لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) الذي سيتم انتحاله للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--certificate-authority="" مسار ملف شهادة السلطة

--client-certificate="" مسار ملف شهادة العميل لـ TLS

--client-key="" مسار ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كانت صحيحة، قم بتعطيل ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كانت صحيحة، فلن يتم التحقق من صحة شهادة الخادم. سيؤدي هذا إلى جعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" مسار ملف kubeconfig للاستخدام في طلبات CLI.

--kuberc="" مسار ملف kuberc للاستخدام في التفضيلات. يمكن تعطيل ذلك عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف بوابة الميزات KUBERC=off.

--match-server-version=false طلب مطابقة إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كانت موجودة، نطاق مساحة الاسم لطلب CLI هذا

--password="" كلمة مرور للمصادقة الأساسية لخادم API

--profile="none" اسم الملف التعريفي المراد التقاطه. واحد من (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي سيتم كتابة الملف التعريفي إليه

--request-timeout="0" مدة الانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم API الخاص بـ Kubernetes

--tls-server-name="" اسم الخادم الذي سيتم استخدامه للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز التوثيق المميز للمصادقة لخادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية لخادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # تحديث جزئي لعقدة باستخدام ترقيع دمج استراتيجي، مع تحديد الترقيع كـ JSON
  kubectl patch node k8s-node-1 -p '{"spec":{"unschedulable":true}}'
  # تحديث جزئي لعقدة باستخدام ترقيع دمج استراتيجي، مع تحديد الترقيع كـ YAML
  kubectl patch node k8s-node-1 -p $'spec:\n unschedulable: true'
  # تحديث جزئي لعقدة محددة بواسطة النوع والاسم المحددين في "node.json" باستخدام ترقيع دمج استراتيجي
  kubectl patch -f node.json -p '{"spec":{"unschedulable":true}}'
  # تحديث صورة حاوية؛ يتطلب spec.containers[*].name لأنه مفتاح دمج
  kubectl patch pod valid-pod -p '{"spec":{"containers":[{"name":"kubernetes-serve-hostname","image":"new image"}]}}'
  # تحديث صورة حاوية باستخدام ترقيع JSON مع مصفوفات موضعية
  kubectl patch pod valid-pod --type='json' -p='[{"op": "replace", "path": "/spec/containers/0/image", "value":"new image"}]'
  # تحديث عدد النسخ المتماثلة لتوزيع باستخدام المورد الفرعي 'scale' باستخدام ترقيع دمج
  kubectl patch deployment nginx-deployment --subresource='scale' --type='merge' -p '{"spec":{"replicas":2}}'
