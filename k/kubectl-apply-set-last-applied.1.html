kubectl-apply-set-last-applied(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl apply set-last-applied - تعيين تعليق last-applied-configuration على كائن مباشر لمطابقة محتويات ملف

الملخص

kubectl apply set-last-applied [خيارات]

الوصف

يعيّن أحدث تعليقات last-applied-configuration عن طريق تعيينها لمطابقة محتويات ملف. يؤدي هذا إلى تحديث last-applied-configuration كما لو تم تشغيل 'kubectl apply -f'، دون تحديث أي أجزاء أخرى من الكائن.

الخيارات

--allow-missing-template-keys=true إذا كان صحيحًا، تجاهل أي أخطاء في القوالب عند فقدان حقل أو مفتاح خريطة في القالب. ينطبق فقط على تنسيقات الإخراج golang و jsonpath.

--create-annotation=false سيقوم بإنشاء تعليقات 'last-applied-configuration' إذا كان الكائن الحالي لا يمتلك واحدًا

--dry-run="none" يجب أن تكون "none"، "server"، أو "client". إذا كانت استراتيجية العميل، قم فقط بطباعة الكائن الذي سيتم إرساله، دون إرساله. إذا كانت استراتيجية الخادم، فقم بإرسال طلب من جانب الخادم دون حفظ المورد.

-f, --filename=[] اسم الملف، الدليل، أو عنوان URL للملفات التي تحتوي على تعليقات last-applied-configuration

-o, --output="" تنسيق الإخراج. أحد الخيارات: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--show-managed-fields=false إذا كان صحيحًا، احتفظ بـ managedFields عند طباعة الكائنات بتنسيق JSON أو YAML.

--template="" سلسلة قالب أو مسار إلى ملف قالب لاستخدامه عند -o=go-template، -o=go-template-file. تنسيق القالب هو قوالب golang [http://golang.org/pkg/text/template/#pkg-overview].

خيارات موروثة من الأوامر الأصل

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في نطاق.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذه العلامة لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--certificate-authority="" مسار إلى ملف شهادة للسلطة المصدقة

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig المراد استخدامها

--context="" اسم سياق kubeconfig المراد استخدامه

--disable-compression=false إذا كان صحيحًا، قم بالتراجع عن ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، لن يتم التحقق من صحة شهادة الخادم. سيجعل هذا اتصالات HTTPS غير آمنة

--kubeconfig="" مسار إلى ملف kubeconfig المستخدم لطلبات CLI.

--kuberc="" مسار إلى ملف kuberc المستخدم للتفضيلات. يمكن تعطيل ذلك عن طريق تصدير KUBECTL_KUBERC=false بوابة ميزة أو إيقاف تشغيل الميزة KUBERC=off.

--match-server-version=false يتطلب تطابق إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كانت موجودة، نطاق المساحة الاسمية لطلب CLI هذا

--password="" كلمة المرور للمصادقة الأساسية على خادم API

--profile="none" اسم الملف الشخصي المراد التقاطه. أحد الخيارات (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف المراد كتابة الملف الشخصي إليه

--request-timeout="0" المدة الزمنية للانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم المراد استخدامه للتحقق من شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز حامل (Bearer token) للمصادقة على خادم API

--user="" اسم مستخدم kubeconfig المراد استخدامه

--username="" اسم المستخدم للمصادقة الأساسية على خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات الواردة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # تعيين last-applied-configuration لمورد لمطابقة محتويات ملف
  kubectl apply set-last-applied -f deploy.yaml
  # تنفيذ set-last-applied على كل ملف تكوين في دليل
  kubectl apply set-last-applied -f path/
  # تعيين last-applied-configuration لمورد لمطابقة محتويات ملف؛ سيقوم بإنشاء التعليق إذا لم يكن موجودًا بالفعل
  kubectl apply set-last-applied -f deploy.yaml --create-annotation=true
