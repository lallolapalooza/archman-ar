NAME

khard.conf - configuration file for khard

SUMMARY

ملف الإعداد لـ khard هو ملف نصي عادي بصيغة تشبه ini. العديد من الخيارات لها خيار سطر أوامر مقابل. القسم الوحيد الإلزامي في ملف الإعداد هو تعريف دفاتر العناوين المتاحة.

LOCATION

يتم البحث عن الملف في $XDG_CONFIG_HOME/khard/khard.conf. إذا كانت متغير البيئة $XDG_CONFIG_HOME غير معين، فسيتم استخدام ~/.config/ بدلاً منه.

يمكن تغيير الموقع باستخدام متغير البيئة $KHARD_CONFIG أو خيار سطر الأوامر -c (وهو ما له الأسبقية).

SYNTAX

يدعم الأقسام المميزة بأقواس مربعة والأقسام المتداخلة بأقواس مربعة إضافية. يحتوي كل قسم على مفاتيح متعددة مع قيم محددة بعلامات التساوي. القيم مكتوبة ويتم التحقق من نوعها.

OPTIONS

يتكون ملف الإعداد من هذه الأقسام الأربعة:

addressbooks
يحتوي هذا القسم على أقسام فرعية متعددة، ولكن قسم واحد على الأقل. يمكن أن يكون لكل قسم فرعي اسم عشوائي سيكون اسم دفتر عناوين معروف لـ khard. يجب أن يحتوي كل من هذه الأقسام الفرعية على مفتاح path مع مسار المجلد الذي يحتوي على ملفات vCard لدفتر العناوين هذا. اختياريًا، يمكنك تعيين قيمة type إما إلى discover أو vdir، وهو الافتراضي. قيمة path تدعم متغيرات البيئة وبادئات tilde. عند استخدام النوع discover، فإنه يدعم أيضًا مطابقة الأنماط. يتوقع khard أن تحتوي ملفات vCard على سجل VCARD واحد فقط لكل ملف وتنتهي بامتداد .vcf.
general
يسمح هذا القسم بتكوين بعض الميزات العامة لـ khard. المفاتيح التالية متاحة في هذا القسم:
  • debug: مؤشر منطقي يحدد ما إذا كان يجب تعيين مستوى التسجيل على debug افتراضيًا (نفس تأثير الخيار --debug على سطر الأوامر)
  • default_action: الإجراء/الأمر الفرعي الافتراضي للاستخدام إذا لم يتطابق الوسيط غير الخيار الأول مع أي من الأوامر الفرعية المتاحة
  • editor: محرر النصوص المستخدم لتحرير إدخالات دفتر العناوين، إذا لم يتم توفير $EDITOR فسيتم استخدامه
  • merge_editor: أمر يستخدم لدمج بطاقتين بشكل تفاعلي، إذا لم يتم توفيره، فسيتم استخدام $MERGE_EDITOR
contact table
يستخدم هذا القسم لتكوين سلوك قوائم الإخراج المختلفة لـ khard. المفاتيح التالية متاحة:
  • display: أي جزء من الاسم سيتم استخدامه في القوائم؛ يمكن أن يكون هذا أحد first_name أو last_name أو formatted_name
  • group_by_addressbook: ما إذا كان سيتم تجميع جهات الاتصال حسب دفتر العناوين في القوائم أم لا
  • localize_dates: ما إذا كان سيتم ترجمة التواريخ أم استخدام تنسيقات التواريخ ISO
  • preferred_email_address_type: تسميات عناوين البريد الإلكتروني المفضلة
  • preferred_phone_number_type: تسميات أرقام الهواتف المفضلة
  • reverse: ما إذا كان سيتم عكس ترتيب قوائم جهات الاتصال أم لا
  • show_nicknames: ما إذا كان سيتم عرض الأسماء المستعارة
  • show_uids: ما إذا كان سيتم عرض المعرفات الفريدة
  • show_kinds: ما إذا كان سيتم عرض الأنواع
  • sort: الحقل الذي سيتم فرز قوائم جهات الاتصال حسبه
vcard
  • private_objects: قائمة بالسلاسل النصية، هذه هي أسماء حقول vCard الخاصة (التي تبدأ بـ X-) التي سيتم تحميلها وعرضها بواسطة khard
  • search_in_source_files: ما إذا كان سيتم البحث في ملفات vCard المصدر قبل تحليلها لتسريع عمليات البحث
  • skip_unparsable: ما إذا كان سيتم تخطي ملفات vCard غير القابلة للتحليل، وإلا فسيخرج khard عند أول بطاقة غير قابلة للتحليل يواجهها
  • preferred_version: إصدار vCard المفضل لاستخدامه في البطاقات الجديدة

EXAMPLE

هذا هو ملف الإعداد المثال:

# example configuration file for khard version > 0.14.0
# place it under ~/.config/khard/khard.conf
# This file is parsed by the configobj library.  The syntax is described at
# https://configobj.readthedocs.io/en/latest/configobj.html#the-config-file-format
[addressbooks]
[[family]]
path = ~/.contacts/family/
[[friends]]
path = ~/.contacts/friends/
[[work]]
path = ~/.work/**/client-*-contacts/
type = discover
[general]
debug = no
default_action = list
# These are either strings or comma seperated lists
editor = vim, -i, NONE
merge_editor = vimdiff
[contact table]
# display names by first or last name: first_name / last_name / formatted_name
display = first_name
# group by address book: yes / no
group_by_addressbook = no
# reverse table ordering: yes / no
reverse = no
# append nicknames to name column: yes / no
show_nicknames = no
# show uid table column: yes / no
show_uids = yes
# show kind table column: yes / no
show_kinds = no
# sort by first or last name: first_name / last_name / formatted_name
sort = last_name
# localize dates: yes / no
localize_dates = yes
# set a comma separated list of preferred phone number types in descending priority
# or nothing for non-filtered alphabetical order
preferred_phone_number_type = pref, cell, home
# set a comma separated list of preferred email address types in descending priority
# or nothing for non-filtered alphabetical order
preferred_email_address_type = pref, work, home
[vcard]
# extend contacts with your own private objects
# these objects are stored with a leading "X-" before the object name in the vcard files
# every object label may only contain letters, digits and the - character
# example:
#   private_objects = Jabber, Skype, Twitter
# default: ,  (the empty list)
private_objects = Jabber, Skype, Twitter
# preferred vcard version: 3.0 / 4.0
preferred_version = 3.0
# Look into source vcf files to speed up search queries: yes / no
search_in_source_files = no
# skip unparsable vcard files: yes / no
skip_unparsable = no
