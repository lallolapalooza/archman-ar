الحزمة: knot

NAME

kxdpgun – DNS query load generator

SYNOPSIS

kxdpgun [-i input file] [-t threads] [-Q queries] [-p port] [-b batch size] [-T] [-V] [-h] [address]...

DESCRIPTION

The kxdpgun utility generates DNS query load against specified addresses. It reads queries from a file or generates random queries if no file is specified. It supports both UDP and TCP transports.

The primary use case is to stress DNS servers and measure their performance.

OPTIONS

The options are explained in the following sections.

-i input file
Read DNS queries from the specified input file. Each line should contain a query in the format: <name> <type> [<class>]. If not specified, random queries are generated.
-t threads
Number of worker threads to use for generating queries. Default is 1.
-Q queries
Total number of queries to send. If set to 0, kxdpgun will run indefinitely until interrupted.
-p port
Port number to use for sending queries. Default is 53.
-b batch size
Number of queries to send in a single batch (for UDP). Default is 1.
-T
Use TCP transport instead of UDP.
-V
Print version information and exit.
-h
Print help message and exit.

ARGUMENTS

address ...

List of IP addresses (IPv4 or IPv6) of the DNS servers to query.

NOTES

The statistics printed by kxdpgun are collected for any given thread. The statistics printouts ignore this and are thus ever-so-slightly inaccurate. The error margin decreases proportionally to the volume of data & timespan over which they are collected.

EXIT VALUES

Exit status of 0 means successful operation. Any other exit status indicates an error.

EXAMPLES

Manually created queries file:

abc6.example.com. AAAA
nxdomain.example.com. A
notzone. A
a.example.com. NS E
ab.example.com. A D
abcd.example.com. DS D

Queries file generated from a zone file (Knot DNS format):

cat ZONE_FILE | awk "{print \$1,\$3}" | grep -E "(NS|DS|A|AAAA|PTR|MX|SOA)$" | sort -u -R > queries.txt

Basic usage:

# kxdpgun -i ~/queries.txt 2001:DB8::1

Using UDP with increased batch size:

# kxdpgun -t 20 -Q 1000000 -i ~/queries.txt -b 20 -p 8853 192.0.2.1

Using TCP:

# kxdpgun -t 20 -Q 100000 -i ~/queries.txt -T -p 8853 192.0.2.1
