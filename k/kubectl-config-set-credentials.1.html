kubectl-config-set-credentials(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
إريك باريس يناير 2015

الاسم

kubectl config set-credentials - تعيين إدخال مستخدم في kubeconfig

الملخص

kubectl config set-credentials [خيارات]

الوصف

تعيين إدخال مستخدم في kubeconfig.

تحديد اسم موجود بالفعل سيؤدي إلى دمج حقول جديدة فوق القيم الموجودة.

    خيارات شهادة العميل:
    --client-certificate=certfile --client-key=keyfile
    خيارات رمز الحامل:
    --token=bearer_token
    خيارات المصادقة الأساسية:
    --username=basic_user --password=basic_password

رمز الحامل والمصادقة الأساسية متعارضان.

الخيارات

--auth-provider="" مزود المصادقة لإدخال المستخدم في kubeconfig

--auth-provider-arg=[] وسائط 'key=value' لمزود المصادقة

--client-certificate="" مسار ملف شهادة العميل لإدخال المستخدم في kubeconfig

--client-key="" مسار ملف مفتاح العميل لإدخال المستخدم في kubeconfig

--embed-certs=false تضمين شهادة / مفتاح العميل لإدخال المستخدم في kubeconfig

--exec-api-version="" إصدار API لمكون المكون الإضافي لبيانات اعتماد التنفيذ لإدخال المستخدم في kubeconfig

--exec-arg=[] وسائط جديدة لأمر المكون الإضافي لبيانات اعتماد التنفيذ لإدخال المستخدم في kubeconfig

--exec-command="" الأمر للمكون الإضافي لبيانات اعتماد التنفيذ لإدخال المستخدم في kubeconfig

--exec-env=[] قيم بيئة 'key=value' للمكون الإضافي لبيانات اعتماد التنفيذ

--exec-interactive-mode="" وضع التفاعل لمكون بيانات اعتماد التنفيذ لإدخال المستخدم في kubeconfig

--exec-provide-cluster-info=false ProvideClusterInfo لمكون بيانات اعتماد التنفيذ لإدخال المستخدم في kubeconfig

--password="" كلمة المرور لإدخال المستخدم في kubeconfig

--token="" الرمز المميز لإدخال المستخدم في kubeconfig

--username="" اسم المستخدم لإدخال المستخدم في kubeconfig

الخيارات الموروثة من أوامر الأب

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذا العلم لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل التخزين المؤقت الافتراضي

--certificate-authority="" مسار ملف شهادة السلطة الموثوقة

--cluster="" اسم كتلة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كان صحيحًا، سيتم الامتناع عن ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، لن يتم فحص شهادة الخادم للتحقق من صحتها. سيؤدي هذا إلى جعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" استخدام ملف kubeconfig معين

--kuberc="" مسار ملف kuberc للاستخدام في التفضيلات. يمكن تعطيل ذلك عن طريق تصدير KUBECTL_KUBERC=false بوابة الميزة أو إيقاف تشغيل الميزة KUBERC=off.

--match-server-version=false مطالبة إصدار الخادم بإصدار العميل

-n, --namespace="" إذا كان موجودًا، نطاق مساحة الاسم لطلب CLI هذا

--profile="none" اسم الملف الشخصي لالتقاطه. أحد (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف لكتابة الملف الشخصي إليه

--request-timeout="0" الوقت الذي يجب الانتظار فيه قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة وقت مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء مهلة الطلبات.

-s, --server="" عنوان ومنفذ خادم واجهة برمجة تطبيقات Kubernetes

--tls-server-name="" اسم الخادم المستخدم للتحقق من شهادة الخادم. إذا لم يتم توفيره، يتم استخدام الاسم المضيف المستخدم للاتصال بالخادم

--user="" اسم مستخدم kubeconfig للاستخدام

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false معاملة التحذيرات المستلمة من الخادم كأخطاء والخروج برمز خروج غير صفري

مثال

  # تعيين حقل "client-key" فقط على إدخال "cluster-admin"
  # دون لمس القيم الأخرى
  kubectl config set-credentials cluster-admin --client-key=~/.kube/admin.key
  # تعيين المصادقة الأساسية لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --username=admin --password=uXFGweU9l35qcif
  # تضمين بيانات شهادة العميل في إدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --client-certificate=~/.kube/admin.crt --embed-certs=true
  # تمكين مزود مصادقة Google Compute Platform لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --auth-provider=gcp
  # تمكين مزود مصادقة OpenID Connect لإدخال "cluster-admin" مع وسائط إضافية
  kubectl config set-credentials cluster-admin --auth-provider=oidc --auth-provider-arg=client-id=foo --auth-provider-arg=client-secret=bar
  # إزالة قيمة تكوين "client-secret" لموفر مصادقة OpenID Connect لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --auth-provider=oidc --auth-provider-arg=client-secret-
  # تمكين مكون إضافي جديد للمصادقة عبر التنفيذ لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-command=/path/to/the/executable --exec-api-version=client.authentication.k8s.io/v1beta1
  # تمكين مكون إضافي جديد للمصادقة عبر التنفيذ لإدخال "cluster-admin" مع وضع تفاعلي
  kubectl config set-credentials cluster-admin --exec-command=/path/to/the/executable --exec-api-version=client.authentication.k8s.io/v1beta1 --exec-interactive-mode=Never
  # تحديد وسائط مكون إضافي جديد للمصادقة عبر التنفيذ لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-arg=arg1 --exec-arg=arg2
  # إنشاء أو تحديث متغيرات بيئة المكون الإضافي للمصادقة عبر التنفيذ لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-env=key1=val1 --exec-env=key2=val2
  # إزالة متغيرات بيئة المكون الإضافي للمصادقة عبر التنفيذ لإدخال "cluster-admin"
  kubectl config set-credentials cluster-admin --exec-env=var-to-remove-
