key_setsecret(3) دليل دوال المكتبة key_setsecret(3)

الاسم

key_decryptsession, key_encryptsession, key_setsecret, key_gendes, key_secretkey_is_set - واجهات لاستدعاء خدمة المفاتيح rpc

المكتبة

مكتبة C القياسية (libc، -lc)

الاختصار

#include <rpc/rpc.h>
int key_decryptsession(char *remotename, des_block *deskey);
int key_encryptsession(char *remotename, des_block *deskey);
int key_gendes(des_block *deskey);
int key_setsecret(char *key);
int key_secretkey_is_set(void);

الوصف

تُستخدم الدوال هنا ضمن آلية المصادقة الآمنة لـ RPC (AUTH_DES). لا ينبغي أن تكون هناك حاجة لبرامج المستخدم لاستخدام هذه الدوال.

تستخدم الدالة key_decryptsession() اسم شبكة الخادم (البعيد) وتأخذ مفتاح DES لفك التشفير. تستخدم المفتاح العام للخادم والمفتاح السري المرتبط بمعرف المستخدم الفعال للعملية المتصلة.

الدالة key_encryptsession() هي عكس الدالة key_decryptsession(). تقوم بتشفير مفاتيح DES باستخدام المفتاح العام للخادم والمفتاح السري المرتبط بمعرف المستخدم الفعال للعملية المتصلة.

تُستخدم الدالة key_gendes() لطلب مفتاح محادثة آمن من خادم المفاتيح.

تُستخدم الدالة key_setsecret() لتعيين المفتاح لمعرف المستخدم الفعال للعملية المتصلة.

يمكن استخدام الدالة key_secretkey_is_set() لتحديد ما إذا كان قد تم تعيين مفتاح لمعرف المستخدم الفعال للعملية المتصلة.

قيمة الإرجاع

تعيد هذه الدوال القيمة 1 عند النجاح و 0 عند الفشل.
