الاسم

kanshi - ملف التكوين

الوصف

ملف تكوين kanshi هو قائمة من الملفات الشخصية. يحتوي كل ملف شخصي على اسم اختياري ويتضمن توجيهات ملف شخصي مفصولة بأقواس ({ و }).

مثال:

include /etc/kanshi/config.d/*
profile {
	output LVDS-1 disable
	output "Some Company ASDF 4242" {
		mode 1600x900
		position 0,0
	}
}
profile nomad {
	output LVDS-1 enable scale 2
}

التوجيهات

profile [<name>] { <profile directives...> }

يعرف ملفًا شخصيًا جديدًا باستخدام توجيهات الملف الشخصي المحددة والمفصولة بأقواس. يمكن تحديد اسم ولكنه اختياري.

output <criteria> <output-directive...>

يعرف الإعدادات الافتراضية لتوجيهات الإخراج داخل تعريفات الملفات الشخصية.

تنطبق هذه الإعدادات الافتراضية فقط عند ذكر الإخراج المعني في ملف شخصي محدد. على سبيل المثال، الملفان الشخصيان التاليان متكافئان:

output eDP-1 scale 2
profile manual {
	output eDP-1 scale 2
}
profile uses-defaults {
	output eDP-1
}

يمكن تحديد توجيهات الإخراج في كتلة مفصولة بأقواس أيضًا.

include <path>

ضمّن ملفًا آخر من path. يقوم بتوسيع صيغة shell (راجع wordexp(3) للتفاصيل).

توجيهات الملفات الشخصية

يتبع توجيهات الملفات الشخصية حجج مفصولة بمسافات. يمكن اقتباس الحجج (باستخدام ") إذا كانت تحتوي على مسافات.

output <criteria> <output-directive...>

يضيف توجيه الإخراج إخراجًا إلى الملف الشخصي.

يمكن أن يكون المعيار واحدًا مما يلي:

  • اسم إخراج (على سبيل المثال "DP-1"). لاحظ أن أسماء الإخراج قد لا تكون مستقرة: قد تتغير عبر عمليات إعادة التشغيل (اعتمادًا على ترتيب فحص برنامج تشغيل النواة) أو ترتيب الإنشاء (عادةً لأرصفة USB-C).
  • سلسلة نصية مفصولة بمسافات تحتوي على الشركة المصنعة للإخراج، الطراز، والرقم التسلسلي (على سبيل المثال "Foocorp ASDF 1234"). يمكن استخدام نمط حرف بدل (على سبيل المثال "Foocorp ASDF *")، راجع glob(7). إذا كان أحد هذه الحقول مفقودًا، فيجب ملؤه بالسلسلة النصية "Unknown" (على سبيل المثال "Foocorp ASDF Unknown").
  • اسم مستعار للإخراج (على سبيل المثال "$work-desk3") تم تعريفه بواسطة توجيه اسم مستعار للإخراج. لا يمكن استخدام الأسماء المستعارة للإخراج إلا في نطاق الملف الشخصي.
  • حرف بدل "*" لمطابقة أي إخراج. لا يمكن استخدام أحرف البدل إلا في نطاق الملف الشخصي ولن تطابق إلا إخراجًا واحدًا.

يمكن تحديد توجيهات الإخراج في كتلة مفصولة بأقواس أيضًا.

على sway(1)، يمكن الحصول على أسماء ومعرفات الإخراج عبر "swaymsg -t get_outputs".

exec <command>

ينفذ توجيه exec أمرًا عند تطبيق الملف الشخصي بنجاح. يمكن استخدام هذا لتحديث حالة المترجم إلى الملف الشخصي عندما لا يتم ذلك تلقائيًا.

يتم تنفيذ الأوامر بشكل غير متزامن وقد لا يتم الحفاظ على ترتيبها. إذا كنت بحاجة إلى تنفيذ أوامر متسلسلة، فيجب عليك تجميعها في عبارة exec واحدة أو في برنامج نصي منفصل.

على sway(1) على سبيل المثال، يمكن استخدام exec لنقل مساحات العمل إلى الإخراج الصحيح:

profile multihead {
	output eDP-1 enable
	output DP-1 enable transform 270
	exec swaymsg workspace 1, move workspace to eDP-1
}

لاحظ أنه يجب توخي الحذر الإضافي مع الإخراجات التي تم تعريفها بوصف إخراج حيث قد يتغير الاسم الحقيقي:

profile complex {
	output "Some Other Company GTBZ 2525" mode 1920x1200
	exec swaymsg workspace 1, move workspace to output '"Some Other Company GTBZ 2525"'
}

توجيهات الإخراج

enable|disable

يمكّن أو يعطّل الإخراج المحدد.

mode [--custom] <width>x<height>[@<rate>[Hz]]

يقوم بتكوين الإخراج المحدد لاستخدام الوضع المحدد. الأوضاع هي مزيج من العرض والارتفاع (بالبكسل) ومعدل التحديث (بالهرتز) الذي يمكن تكوين شاشتك لاستخدامه.

أمثلة:

output HDMI-A-1 mode 1920x1080
output HDMI-A-1 mode 1920x1080@60Hz
output HDMI-A-1 mode --custom 1280x720@60Hz

position <x>,<y>

يضع الإخراج في الموضع المحدد في مساحة الإحداثيات العامة.

مثال:

output HDMI-A-1 position 1600,0

scale <factor>

يقوم بقياس الإخراج بالمعامل القياس المحدد.

transform <transform>

يضبط تحويل الإخراج. يمكن أن يكون أحد "90"، "180"، "270" للدوران؛ أو "flipped"، "flipped-90"، "flipped-180"، "flipped-270" للدوران و قلب؛ أو "normal" لعدم وجود تحويل.

adaptive_sync on|off

يمكّن أو يعطّل المزامنة التكيفية (المعروفة أيضًا باسم معدل التحديث المتغير).

alias $<name>

يعرف اسمًا مستعارًا لهذا الإخراج. لا يمكن تعريف الأسماء المستعارة للإخراج إلا في النطاق العام.
