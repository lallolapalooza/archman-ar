kubeadm-init-phase-certs-all(1)

الحزمة: kubeadm

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
إريك باريس يناير 2015

الاسم

kubeadm init phase certs all - إنشاء جميع الشهادات

الملخص

kubeadm init phase certs all [خيارات]

الوصف

إنشاء جميع الشهادات

الخيارات

--apiserver-advertise-address="" عنوان IP الذي سيُعلن خادم API أنه يستمع عليه. إذا لم يتم تعيينه، فسيتم استخدام واجهة الشبكة الافتراضية.

--apiserver-cert-extra-sans=[] أسماء بديلة إضافية (SANs) اختيارية لاستخدامها لشهادة خدمة خادم API. يمكن أن تكون عناوين IP وأسماء DNS.

--cert-dir="/etc/kubernetes/pki" المسار الذي سيتم حفظ الشهادات وتخزينها فيه.

--config="" المسار إلى ملف تكوين kubeadm.

--control-plane-endpoint="" تحديد عنوان IP ثابت أو اسم DNS لمستوى التحكم.

--dry-run=false لا تقم بتطبيق أي تغييرات؛ فقط أخرج ما سيتم القيام به.

--kubernetes-version="stable-1" اختر إصدار Kubernetes محدد لمستوى التحكم.

--service-cidr="10.96.0.0/12" استخدام نطاق بديل لعناوين IP لخدمات VIP.

--service-dns-domain="cluster.local" استخدام نطاق بديل للخدمات، على سبيل المثال "myorg.internal".

الخيارات الموروثة من الأوامر الأصلية

--rootfs="" المسار إلى نظام ملفات الجذر 'الحقيقي' للمضيف. سيؤدي هذا إلى جعل kubeadm يقوم بتغيير الدليل إلى المسار المقدم.

--version=false --version، --version=raw تطبع معلومات الإصدار وتخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه
