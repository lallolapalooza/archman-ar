الاسم

kubectl config - تعديل ملفات kubeconfig

الملخص

kubectl config [خيارات]

الوصف

تعديل ملفات kubeconfig باستخدام أوامر فرعية مثل "kubectl config set current-context my-context".

يتبع ترتيب التحميل هذه القواعد:

1.
إذا تم تعيين علامة --kubeconfig، فسيتم تحميل هذا الملف فقط. يمكن تعيين العلامة مرة واحدة فقط ولا يتم دمجها.
2.
إذا تم تعيين متغير البيئة $KUBECONFIG، فسيتم استخدامه كقائمة مسارات (قواعد تقسيم المسار العادية لنظامك). يتم دمج هذه المسارات. عند تعديل قيمة، يتم تعديلها في الملف الذي يحدد المقطع. عند إنشاء قيمة، يتم إنشاؤها في أول ملف موجود. إذا لم تكن هناك ملفات في السلسلة موجودة، فسيتم إنشاء الملف الأخير في القائمة.
3.
بخلاف ذلك، يتم استخدام ${HOME}/.kube/config ولا يتم دمجها.

خيارات

--kubeconfig="" استخدام ملف kubeconfig معين

خيارات موروثة من الأوامر الأصلية

--as="" اسم المستخدم لانتحال الشخصية للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة لانتحال الشخصية للعملية، يمكن تكرار هذه العلامة لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) لانتحال الشخصية للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--certificate-authority="" مسار ملف شهادة للسلطة المصدقة

--client-certificate="" مسار ملف شهادة عميل لـ TLS

--client-key="" مسار ملف مفتاح عميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كان صحيحًا، تخطي ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، فلن يتم التحقق من صحة شهادة الخادم. هذا سيجعل اتصالات HTTPS الخاصة بك غير آمنة

--kuberc="" مسار ملف kuberc للاستخدام في التفضيلات. يمكن تعطيل ذلك عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف بوابة الميزات KUBERC=off.

--match-server-version=false تتطلب مطابقة إصدار الخادم لإصدار العميل

-n, --namespace="" إذا كانت موجودة، نطاق مساحة الاسم لهذا الطلب CLI

--password="" كلمة المرور للمصادقة الأساسية مع خادم API

--profile="none" اسم الملف الشخصي المراد التقاطه. أحد الخيارات (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي سيتم كتابة الملف الشخصي إليه

--request-timeout="0" طول الوقت للانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم المراد استخدامه للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز حامل للمصادقة مع خادم API

--user="" اسم المستخدم في kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية مع خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري
