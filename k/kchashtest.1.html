KCHASHTEST(1) Kyoto Cabinet KCHASHTEST(1)

اسم

kchashtest - واجهة سطر أوامر لاختبار قاعدة بيانات التجزئة للملفات

الوصف

الأمر `kchashtest' هو أداة لاختبار المرافق واختبار الأداء لقاعدة بيانات تجزئة الملفات. يستخدم هذا الأمر بالتنسيق التالي. `path' تحدد مسار ملف قاعدة البيانات. `rnum' تحدد عدد التكرارات.


kchashtest order [-th num] [-rnd] [-set|-get|-getw|-rem|-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
يؤدي الاختبارات بالترتيب.
kchashtest queue [-th num] [-it num] [-rnd] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
يؤدي عمليات التخزين المؤقت.
kchashtest wicked [-th num] [-it num] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
يؤدي عمليات مختلطة مختارة عشوائيًا.
kchashtest tran [-th num] [-it num] [-hard] [-oat|-onl|-onl|-otl|-onr] [-apow num] [-fpow num] [-ts] [-tl] [-tc] [-bnum num] [-msiz num] [-dfunit num] [-lv] path rnum
يؤدي اختبار المعاملات.

الخيارات تتضمن ما يلي.

-th num : يحدد عدد خيوط العامل.
-rnd : يؤدي الاختبار العشوائي.
-set : يؤدي عملية التعيين فقط.
-get : يؤدي عملية الحصول فقط.
-getw : يؤدي عملية الحصول مع المخزن المؤقت فقط.
-rem : يؤدي عملية الإزالة فقط.
-etc : يؤدي عمليات متنوعة.
-tran : يؤدي المعاملات.
-oat : يفتح قاعدة البيانات مع خيار المعاملة التلقائية.
-oas : يفتح قاعدة البيانات مع خيار المزامنة التلقائية.
-onl : يفتح قاعدة البيانات مع خيار عدم القفل.
-otl : يفتح قاعدة البيانات مع خيار محاولة القفل.
-onr : يفتح قاعدة البيانات مع خيار عدم الإصلاح التلقائي.
-apow num : يحدد قوة محاذاة حجم السجل.
-fpow num : يحدد قوة سعة مجمع الكتل الحرة.
-ts : يقوم بضبط قاعدة البيانات مع الخيار الصغير.
-tl : يقوم بضبط قاعدة البيانات مع الخيار الخطي.
-tc : يقوم بضبط قاعدة البيانات مع خيار الضغط.
-bnum num : يحدد عدد مجموعات جدول التجزئة.
-msiz num : يحدد حجم منطقة الذاكرة المخططة.
-dfunit num : يحدد خطوة الوحدة الرقمية لإلغاء التجزئة التلقائي.
-lv : يبلغ عن جميع الأخطاء.
-it num : يحدد عدد التكرار.
-hard : يؤدي المزامنة المادية.

يعيد هذا الأمر 0 عند النجاح، وغير ذلك عند الفشل.
