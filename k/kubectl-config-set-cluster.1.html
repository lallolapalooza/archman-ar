kubectl-config-set-cluster(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl config set-cluster - تعيين إدخال مجموعة في kubeconfig

الملخص

kubectl config set-cluster [خيارات]

الوصف

تعيين إدخال مجموعة في kubeconfig.

تحديد اسم موجود بالفعل سيؤدي إلى دمج الحقول الجديدة فوق القيم الحالية لتلك الحقول.

خيارات

--certificate-authority="" مسار إلى ملف certificate-authority لإدخال المجموعة في kubeconfig

--embed-certs=false تضمين الشهادات لإدخال المجموعة في kubeconfig

--insecure-skip-tls-verify=false تخطي التحقق من صحة TLS بشكل غير آمن لإدخال المجموعة في kubeconfig

--proxy-url="" عنوان URL للوكيل لإدخال المجموعة في kubeconfig

--server="" الخادم لإدخال المجموعة في kubeconfig

--tls-server-name="" اسم خادم TLS لإدخال المجموعة في kubeconfig

خيارات موروثة من الأوامر الأصل

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذا العلامة لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كانت صحيحة، فسيتم إلغاء ضغط الاستجابة لجميع الطلبات إلى الخادم

--kubeconfig="" استخدام ملف kubeconfig معين

--kuberc="" مسار ملف kuberc للاستخدام للتفضيلات. يمكن تعطيل هذا عن طريق تصدير بوابة الميزة KUBECTL_KUBERC=false أو إيقاف الميزة KUBERC=off.

--match-server-version=false طلب مطابقة إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كان موجودًا، نطاق مساحة الاسم لطلب CLI هذا

--password="" كلمة المرور للمصادقة الأساسية لخادم API

--profile="none" اسم الملف الشخصي الذي سيتم التقاطه. أحد الخيارات (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي سيتم كتابة الملف الشخصي إليه

--request-timeout="0" طول الوقت للانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). تعني القيمة صفر عدم انتهاء صلاحية الطلبات.

--token="" رمز مميز للمصادقة لخادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية لخادم API

--version=false --version، --version=raw تطبع معلومات الإصدار وتخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # تعيين حقل الخادم فقط على إدخال المجموعة e2e دون المساس بالقيم الأخرى
  kubectl config set-cluster e2e --server=https://1.2.3.4
  # تضمين بيانات سلطة الشهادات لإدخال المجموعة e2e
  kubectl config set-cluster e2e --embed-certs --certificate-authority=~/.kube/e2e/kubernetes.ca.crt
  # تعطيل التحقق من الشهادات لإدخال المجموعة e2e
  kubectl config set-cluster e2e --insecure-skip-tls-verify=true
  # تعيين اسم خادم TLS مخصص للاستخدام للتحقق من إدخال المجموعة e2e
  kubectl config set-cluster e2e --tls-server-name=my-cluster-name
  # تعيين عنوان URL للوكيل لإدخال المجموعة e2e
  kubectl config set-cluster e2e --proxy-url=https://1.2.3.4
