NAME

KEYCTL_DH_COMPUTE - Compute a Diffie-Hellman shared secret

LIBRARY

Keyctl (libkeyutils), part of libkeyutils

SYNOPSIS

#include <keyctl.h>

long keyctl_dh_compute(key_serial_t keyid, const char *value, size_t value_len, const char *prime, size_t prime_len, const char *base, size_t base_len, char *result, size_t result_len);

DESCRIPTION

keyctl_dh_compute() is used to compute a Diffie-Hellman shared secret. It takes the key ID of a key of type user: 

    user:dh_params:

This key should contain the Diffie-Hellman prime (p) and base (g) as described in dh_params(5).

The caller provides the other party's public key component (y) in value.

The function computes (y^x mod p) where x is the private key component loaded into the keyctl system.

The prime (p) and base (g) are read from the specified key. If they are not present in the key, they are read from the provided prime and base arguments.

The result is written to the buffer pointed to by result, which must be large enough to hold result_len bytes. The actual length of the computed shared secret is returned on success.

RETURN VALUE

On success, keyctl_dh_compute() returns the length of the computed shared secret.

On failure, it returns a negative value indicating an error code.

ERRORS

EACCES:: The key specified by keyid is not accessible.

EFAULT:: The value, result, prime, or base pointers are invalid.

EINVAL:: An invalid argument was provided. For example, value_len, prime_len, or base_len are too large, or result_len is too small.

ENOMEM:: Not enough memory to perform the operation.

ENOENT:: The key specified by keyid does not exist.

ENOSPC:: The keyring has insufficient space.

EPERM:: The key specified by keyid does not have the correct type.

ERANGE:: The result buffer is too small.

STANDARDS

Linux keyctl system calls.

HISTORY

The keyctl functionality was introduced in Linux kernel 2.6.
