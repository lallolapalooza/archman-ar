الاسم

key_decryptsession, key_encryptsession, key_setsecret, key_gendes, key_secretkey_is_set - واجهات لبرنامج خادم مفاتيح rpc

المكتبة

مكتبة C القياسية (libc، -lc)

المُلَخَّص

#include <rpc/rpc.h>
int key_decryptsession(char *remotename, des_block *deskey);
int key_encryptsession(char *remotename, des_block *deskey);
int key_gendes(des_block *deskey);
int key_setsecret(char *key);
int key_secretkey_is_set(void);

الوصف

تُستخدم الوظائف هنا ضمن آلية المصادقة الآمنة في RPC (AUTH_DES). لا ينبغي أن تكون هناك حاجة لبرامج المستخدم لاستخدام هذه الوظائف.

تستخدم الوظيفة key_decryptsession() اسم شبكة الخادم (البعيد) وتأخذ مفتاح DES لفك التشفير. تستخدم المفتاح العام للخادم والمفتاح السري المرتبط بمعرف المستخدم الفعلي للعملية المستدعية.

الوظيفة key_encryptsession() هي عكس الوظيفة key_decryptsession(). تقوم بتشفير مفاتيح DES باستخدام المفتاح العام للخادم والمفتاح السري المرتبط بمعرف المستخدم الفعلي للعملية المستدعية.

تُستخدم الوظيفة key_gendes() لطلب مفتاح محادثة آمن من خادم المفاتيح.

تُستخدم الوظيفة key_setsecret() لتعيين المفتاح لمعرف المستخدم الفعلي للعملية المستدعية.

يمكن استخدام الوظيفة key_secretkey_is_set() لتحديد ما إذا كان قد تم تعيين مفتاح لمعرف المستخدم الفعلي للعملية المستدعية.

قيمة الإرجاع

تُرجع هذه الوظائف 1 عند النجاح و 0 عند الفشل.

السمات
