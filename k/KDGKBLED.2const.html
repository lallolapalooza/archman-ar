\n

NAME

kdgkbled, kdsled — keyboard input and control

\n\n
\n

SYNOPSIS

#include <linux/kd.h>

int ioctl(int fd, int request, ...);

\n\n
\n

DESCRIPTION

The following ioctl requests control various aspects of the console keyboard driver.

\n
PIO_UNISCRNMAP
\n
Loads the "user definable" (fourth) table in the kernel which\n maps bytes into Unicodes, which are then translated into screen symbols\n according to the currently loaded Unicode-to-font map. Special Unicodes\n starting at U+F000 can be used to map directly to the font symbols. (Since\n Linux 1.3.1.)
\n
GIO_UNIMAP
\n
Get Unicode-to-font mapping from kernel. argp points to a
\n
\n
\n
\n
\n
\n 
struct unimapdesc {\n    unsigned short  entry_ct;\n    struct unipair *entries;\n};\n
\n
\n
\n
\n
where entries points to an array of
\n
\n
\n
\n 
struct unipair {\n    unsigned short unicode;\n    unsigned short fontpos;\n};\n
\n
\n
\n
\n
(Since Linux 1.1.92.)
\n
\n
\n
PIO_UNIMAP
\n
Put unicode-to-font mapping in kernel. argp points to a struct\n unimapdesc. (Since Linux 1.1.92)
\n
PIO_UNIMAPCLR
\n
Clear table, possibly advise hash algorithm. argp points to a
\n
\n
\n
\n
\n
\n 
struct unimapinit {\n    unsigned short advised_hashsize;  /* 0 if no opinion */\n    unsigned short advised_hashstep;  /* 0 if no opinion */\n    unsigned short advised_hashlevel; /* 0 if no opinion */\n};\n
\n
\n
\n
\n
(Since Linux 1.1.92.)
\n
\n
\n
KDGKBMODE
\n
Gets current keyboard mode. argp points to a long which is\n set to one of these:\n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n \n
K_RAW0x00 /* Raw (scancode) mode */
K_XLATE0x01 /* Translate keycodes using keymap */
K_MEDIUMRAW0x02 /* Medium raw (scancode) mode */
K_UNICODE0x03 /* Unicode mode */
K_OFF0x04 /* Disabled mode (since Linux 2.6.39) */
\n
\n
KDSKBMODE
\n
Sets current keyboard mode. argp is a long equal to one of\n the values shown for KDGKBMODE.
\n
KDGKBMETA
\n
Gets meta key handling mode. argp points to a long which is\n set to one of these:\n \n \n \n \n \n \n \n \n \n \n \n
K_METABIT0x03set high order bit
K_ESCPREFIX0x04escape prefix
\n
\n
KDSKBMETA
\n
Sets meta key handling mode. argp is a long equal to one of\n the values shown above for KDGKBMETA.
\n
KDGKBENT
\n
Gets one entry in key translation table (keycode to action code).\n argp points to a
\n
\n
\n
\n
\n
\n 
struct kbentry {\n    unsigned char  kb_table;\n    unsigned char  kb_index;\n    unsigned short kb_value;\n};\n
\n
\n
\n
\n
with the first two members filled in: kb_table selects the key\n table (0 <= kb_table < MAX_NR_KEYMAPS), and kb_index\n is the keycode (0 <= kb_index < NR_KEYS). kb_value is\n set to the corresponding action code, or K_HOLE if there is no such key,\n or K_NOSUCHMAP if kb_table is invalid.
\n
\n
\n
KDSKBENT
\n
Sets one entry in translation table. argp points to a struct\n kbentry.
\n
KDGKBSENT
\n
Gets one function key string. argp points to a
\n
\n
\n
\n
\n
\n 
struct kbsentry {\n    unsigned char kb_func;\n    unsigned char kb_string[512];\n};\n
\n
\n
\n
\n
kb_string is set to the (null-terminated) string corresponding to\n the kb_functh function key action code.
\n
\n
\n
KDSKBSENT
\n
Sets one function key string entry. argp points to a struct\n kbsentry.
\n
KDGKBDIACR
\n
Read kernel accent table. argp points to a
\n
\n
\n
\n
\n
\n 
struct kbdiacrs {\n    unsigned int   kb_cnt;\n    struct kbdiacr kbdiacr[256];\n};\n
\n
\n
\n
\n
where kb_cnt is the number of entries in the array, each of which\n is a
\n
\n
\n
\n 
struct kbdiacr {\n    unsigned char diacr;\n    unsigned char base;\n    unsigned char result;\n};\n
\n
\n
\n
\n
\n
KDGETKEYCODE
\n
Read kernel keycode table entry (scan code to keycode). argp points\n to a
\n
\n
\n
\n
\n
\n 
struct kbkeycode {\n    unsigned int scancode;\n    unsigned int keycode;\n};\n
\n
\n
\n
\n
keycode is set to correspond to the given scancode. (89\n <= scancode <= 255 only. For 1 <= scancode <\n 88, keycode==scancode.) (Since Linux 1.1.63.)
\n
\n
\n
KDSETKEYCODE
\n
Write kernel keycode table entry. argp points to a struct\n kbkeycode. (Since Linux 1.1.63.)
\n
KDSIGACCEPT
\n
The calling process indicates its willingness to accept the signal\n argp when it is generated by pressing an appropriate key\n combination. (1 <= argp <= NSIG). (See spawn_console()\n in linux/drivers/char/keyboard.c.)
\n
\n
\n\n
\n

RETURN VALUE

\n

On success, 0 is returned (except where indicated). On failure, -1\n is returned, and errno is set to indicate the error.

\n
\n\n
\n

ERRORS

\n
\n
EINVAL
\n
argp is invalid.
\n
\n
\n\n
\n

STANDARDS

Linux.
