kubectl-config-set(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl config set - تعيين قيمة فردية في ملف kubeconfig

ملخص

kubectl config set [OPTIONS]

الوصف

تعيين قيمة فردية في ملف kubeconfig.

PROPERTY_NAME هو اسم مفصول بنقاط حيث تمثل كل علامة رمزية إما اسم سمة أو مفتاح خريطة. لا يجوز لمفاتيح الخرائط أن تحتوي على نقاط.

PROPERTY_VALUE هي القيمة الجديدة التي تريد تعيينها. تتوقع الحقول الثنائية مثل 'certificate-authority-data' سلسلة مرمزة base64 إلا إذا تم استخدام العلامة --set-raw-bytes.

سيؤدي تحديد اسم سمة موجود بالفعل إلى دمج الحقول الجديدة فوق القيم الموجودة.

الخيارات

--set-raw-bytes=false عند كتابة قيمة خاصية []byte، اكتب السلسلة المقدمة مباشرة بدون فك ترميز base64.

خيارات موروثة من أوامر أب

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذه العلامة لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل التخزين المؤقت الافتراضي

--certificate-authority="" مسار إلى ملف شهادة للسلطة الموثوقة

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم الكتلة kubeconfig للاستخدام

--context="" اسم السياق kubeconfig للاستخدام

--disable-compression=false إذا كانت صحيحة، اختر عدم المشاركة في ضغط الاستجابات لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كانت صحيحة، فلن يتم التحقق من صحة شهادة الخادم. هذا سيجعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" استخدام ملف kubeconfig معين

--kuberc="" مسار ملف kuberc للاستخدام للتفضيلات. يمكن تعطيل هذا عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف الميزة KUBERC=off.

--match-server-version=false طلب تطابق إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كانت موجودة، نطاق مساحة الاسم لهذا الطلب CLI

--password="" كلمة المرور للمصادقة الأساسية لخادم API

--profile="none" اسم الملف الشخصي المراد التقاطه. واحد من (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف لكتابة الملف الشخصي إليه

--request-timeout="0" طول الوقت للانتظار قبل الاستسلام لطلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (على سبيل المثال، 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم للاستخدام للتحقق من شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز التضمين للمصادقة لخادم API

--user="" اسم المستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية لخادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات الواردة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # تعيين الحقل server على الكتلة my-cluster إلى https://1.2.3.4
  kubectl config set clusters.my-cluster.server https://1.2.3.4
  # تعيين الحقل certificate-authority-data على الكتلة my-cluster
  kubectl config set clusters.my-cluster.certificate-authority-data $(echo "cert_data_here" | base64 -i -)
  # تعيين الحقل cluster في السياق my-context إلى my-cluster
  kubectl config set contexts.my-context.cluster my-cluster
  # تعيين الحقل client-key-data للمستخدم cluster-admin باستخدام خيار --set-raw-bytes
  kubectl config set users.cluster-admin.client-key-data cert_data_here --set-raw-bytes=true
