kubectl-config-unset(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl config unset - إلغاء تعيين قيمة فردية في ملف kubeconfig

الملخص

kubectl config unset [خيارات]

الوصف

إلغاء تعيين قيمة فردية في ملف kubeconfig.

اسم الخاصية (PROPERTY_NAME) هو اسم مفصول بنقاط حيث يمثل كل رمز إما اسم سمة أو مفتاح خريطة. قد لا تحتوي مفاتيح الخرائط على نقاط.

خيارات موروثة من الأوامر الأصل

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذا العلم لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل التخزين المؤقت الافتراضي

--certificate-authority="" مسار إلى ملف شهادة للسلطة الموثقة

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كان صحيحًا، يتم إلغاء الاشتراك في ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، لن يتم التحقق من صحة شهادة الخادم. سيؤدي هذا إلى جعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" استخدام ملف kubeconfig معين

--kuberc="" مسار إلى ملف kuberc للاستخدام للتفضيلات. يمكن تعطيل هذا عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف بوابة الميزات KUBERC=off.

--match-server-version=false تطلب مطابقة إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كان موجودًا، نطاق مساحة الاسم لطلب CLI هذا

--password="" كلمة المرور للمصادقة الأساسية إلى خادم API

--profile="none" اسم الملف الشخصي المراد التقاطه. واحد من (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي سيتم كتابة الملف الشخصي إليه

--request-timeout="0" مدة الانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). تعني القيمة صفر عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم المراد استخدامه للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز Bearer للمصادقة إلى خادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية إلى خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه

--warnings-as-errors=false يعامل التحذيرات المستلمة من الخادم كأخطاء ويخرج برمز خروج غير صفري

مثال

  # إلغاء تعيين السياق الحالي
  kubectl config unset current-context
  # إلغاء تعيين مساحة الاسم في السياق foo
  kubectl config unset contexts.foo.namespace
