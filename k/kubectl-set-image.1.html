kubectl-set-image(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl set image - تحديث صورة قالب الـ pod

الملخص

kubectl set image [خيارات]

الوصف

تحديث صور الحاويات الموجودة للموارد.

الموارد الممكنة تشمل (غير حساس لحالة الأحرف):

    pod (po), replicationcontroller (rc), deployment (deploy), daemonset (ds), statefulset (sts), cronjob (cj), replicaset (rs)

الخيارات

--all=false تحديد جميع الموارد، في مساحة اسم أنواع الموارد المحددة

--allow-missing-template-keys=true إذا كانت صحيحة، تجاهل أي أخطاء في القوالب عند فقدان حقل أو مفتاح خريطة في القالب. ينطبق فقط على تنسيقات الإخراج golang و jsonpath.

--dry-run="none" يجب أن تكون "none"، "server"، أو "client". إذا كانت استراتيجية العميل، فقط اطبع الكائن الذي سيتم إرساله، دون إرساله. إذا كانت استراتيجية الخادم، قم بإرسال طلب من جانب الخادم دون حفظ المورد.

--field-manager="kubectl-set" اسم المدير المستخدم لتتبع ملكية الحقول.

-f, --filename=[] اسم الملف، دليل، أو عنوان URL للملفات التي تحدد المورد للحصول عليه من خادم.

-k, --kustomize="" معالجة دليل kustomization. لا يمكن استخدام هذا الخيار مع -f أو -R.

--local=false إذا كانت صحيحة، فلن يتصل set image بـ api-server ولكنه سيعمل محليًا.

-o, --output="" تنسيق الإخراج. أحد الخيارات التالية: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--record=false تسجيل أمر kubectl الحالي في التعليق التوضيحي للمورد. إذا تم تعيينه إلى false، فلا تسجل الأمر. إذا تم تعيينه إلى true، فقم بتسجيل الأمر. إذا لم يتم تعيينه، فقم بتحديث قيمة التعليق التوضيحي الحالي فقط إذا كانت موجودة بالفعل.

-R, --recursive=false معالجة الدليل المستخدم في -f، --filename بشكل متكرر. مفيد عندما تريد إدارة البيانات التعريفية ذات الصلة المنظمة داخل نفس الدليل.

-l, --selector="" محدد (استعلام التسمية) للتصفية، يدعم '=', '==', '!=', 'in', 'notin'. (على سبيل المثال: -l key1=value1,key2=value2,key3 in (value3)). يجب أن تفي الكائنات المتطابقة بجميع قيود التسمية المحددة.

--show-managed-fields=false إذا كانت صحيحة، احتفظ بـ managedFields عند طباعة الكائنات بتنسيق JSON أو YAML.

--template="" سلسلة القالب أو المسار إلى ملف القالب لاستخدامه عند -o=go-template, -o=go-template-file. تنسيق القالب هو قوالب golang [http://golang.org/pkg/text/template/#pkg-overview].

خيارات موروثة من الأوامر الأبوية

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذا الخيار لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل التخزين المؤقت الافتراضي

--certificate-authority="" المسار إلى ملف شهادة للسلطة المصدقة

--client-certificate="" المسار إلى ملف شهادة عميل للـ TLS

--client-key="" المسار إلى ملف مفتاح عميل للـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كانت صحيحة، فتجنب ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كانت صحيحة، فلن يتم التحقق من صحة شهادة الخادم. سيؤدي هذا إلى جعل اتصالات HTTPS غير آمنة.

--kubeconfig="" المسار إلى ملف kubeconfig للاستخدام في طلبات CLI.

--kuberc="" المسار إلى ملف kuberc لاستخدام التفضيلات. يمكن تعطيل ذلك عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف الميزة KUBERC=off.

--match-server-version=false تطلب تطابق إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كانت موجودة، نطاق مساحة الاسم لهذا الطلب CLI

--password="" كلمة المرور للمصادقة الأساسية إلى خادم API

--profile="none" اسم الملف التعريفي المراد التقاطه. أحد الخيارات التالية (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف لكتابة الملف التعريفي إليه

--request-timeout="0" مدة الانتظار قبل الاستسلام لطلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل: 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم لاستخدامه في التحقق من شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم.

--token="" رمز الحامل للمصادقة إلى خادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية إلى خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # تعيين صورة حاوية nginx الخاصة بتوزيع nginx إلى 'nginx:1.9.1'، وصورة حاوية busybox إلى 'busybox'
  kubectl set image deployment/nginx busybox=busybox nginx=nginx:1.9.1
  # تحديث صورة حاوية nginx لجميع عمليات التوزيع ووحدات التحكم في النسخ المتماثل إلى 'nginx:1.9.1'
  kubectl set image deployments,rc nginx=nginx:1.9.1 --all
  # تحديث صورة جميع حاويات daemonset abc إلى 'nginx:1.9.1'
  kubectl set image daemonset abc *=nginx:1.9.1
  # طباعة النتيجة (بتنسيق yaml) لتحديث صورة حاوية nginx من ملف محلي، دون الاتصال بالخادم
  kubectl set image -f path/to/file.yaml nginx=nginx:1.9.1 --local -o yaml
