الاسم

kclangctest - واجهة سطر الأوامر لاختبار ربط لغة C

الوصف

الأمر `kclangctest' هو أداة لاختبار مرفق وللأداء ربط لغة C. يُستخدم هذا الأمر بالصيغة التالية. `path' تحدد مسار ملف قاعدة البيانات. `rnum' تحدد عدد التكرارات.


kclangctest order [-rnd] [-etc] [-tran] [-oat|-onl|-onl|-otl|-onr] path rnum
يجري اختبارات بالترتيب.
kclangctest index [-rnd] [-etc] [-oat|-onl|-onl|-otl|-onr] path rnum
يجري عمليات الفهرسة.
kclangctest map [-rnd] [-etc] [-bnum num] rnum
يجري اختبار لخريطة الهاش التي توفر الذاكرة.
kclangctest list [-rnd] [-etc] rnum
يجري اختبار لقائمة المصفوفات التي توفر الذاكرة.

تتميز الخيارات بما يلي.

-rnd : يجري اختبارًا عشوائيًا.
-etc : يجري عمليات متنوعة.
-tran : يجري معاملة.
-oat : يفتح قاعدة البيانات بخيار المعاملة التلقائية.
-oas : يفتح قاعدة البيانات بخيار المزامنة التلقائية.
-onl : يفتح قاعدة البيانات بخيار عدم القفل.
-otl : يفتح قاعدة البيانات بخيار محاولة القفل.
-onr : يفتح قاعدة البيانات بخيار عدم الإصلاح التلقائي.
-bnum num : يحدد عدد الدلاء لجدول الهاش.

يعيد هذا الأمر 0 عند النجاح، وآخر عند الفشل.
