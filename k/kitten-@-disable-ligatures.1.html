Name

kitty - a fast, feature rich, cross-platform, GPU accelerated terminal emulator

Usage

kitty @ [options] ...

Description

kitty is a popular, free and open-source, cross-platform, GPU-accelerated terminal emulator built with performance and features in mind. It supports tiling window management, image and video rendering, emojis, and more. kitty is highly configurable through its configuration file.

Options

Various options can be passed to kitty @ to control its behavior. These include options for managing windows, tabs, and other aspects of the terminal environment. For a comprehensive list, refer to the official documentation or use the help command within kitty.

Global options

Global options affect the overall behavior of kitty and can often be set in the configuration file (~/.config/kitty/kitty.conf). Some common global options include settings for font, color scheme, key bindings, and window layout.
