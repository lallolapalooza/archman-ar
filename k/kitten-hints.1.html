\n

Command line interface

\n
\n
\n
--program <PROGRAM>
\n
The program to run. The special value kitten can be used to run\n another kitten. Default: kitten hints --prev-next-spaces\n Choices: kitten
\n
\n
\n
\n
\n
--regex
\n
Interpret the argument for --map-object as a regular\n expression. Default: no
\n
\n
\n
\n
\n
--map-object <MAP_OBJECT>
\n
Map the specified object to the specified action. For example, to map\n all URLs to the open-url kitten. The default action is to run the program\n specified by --program. The default object is text matching the\n specified regex. The regex is a POSIX ERE. It is possible to capture\n groups in the regex, which can be used in the replacement string using\n backreferences (\\1, \\2, etc.). The format for the\n replacement is a string with named groups of the form key=value.\n Default: (?m)^\\s*(.+?)\\s*$
\n
\n
\n
\n
\n
--linenum-action\n <LINENUM_ACTION>
\n
Where to perform the action on matched errors. self means the\n current window, window a new kitty window, tab a new tab, os_window a new OS window and background run in the\n background. remote-control is like background but the program can\n use kitty remote control without needing to turn on remote control\n globally. The actual action is whatever arguments are provided to the\n kitten, for example: kitten hints --type=linenum --linenum-action=tab\n vim +{line} {path} will open the matched path at the matched line\n number in vim in a new kitty tab. Note that in order to use\n --program to copy or paste the provided arguments, you need to use\n the special value self. Default: self Choices:\n background, os_window, remote-control, self,\n tab, window
\n
\n
\n
\n
\n
--url-prefixes\n <URL_PREFIXES>
\n
Comma separated list of recognized URL prefixes. Defaults to the list of\n prefixes defined by the url_prefixes\n <#opt-kitty.url_prefixes> option in kitty.conf. Default:\n default
\n
\n
\n
\n
\n
--url-excluded-characters\n <URL_EXCLUDED_CHARACTERS>
\n
Characters to exclude when matching URLs. Defaults to the list of\n characters defined by the url_excluded_characters\n <#opt-kitty.url_excluded_characters> option in kitty.conf.\n The syntax for this option is the same as for\n url_excluded_characters <#opt-kitty.url_excluded_characters>.\n Default: default
\n
\n
\n
\n
\n
--word-characters\n <WORD_CHARACTERS>
\n
Characters to consider as part of a word. In addition, all characters\n marked as alphanumeric in the Unicode database will be considered as word\n characters. Defaults to the select_by_word_characters\n <#opt-kitty.select_by_word_characters> option from\n kitty.conf.
\n
\n
\n
\n
\n
--minimum-match-length\n <MINIMUM_MATCH_LENGTH>
\n
The minimum number of characters to consider a match. Default:\n 3
\n
\n
\n
\n
\n
--multiple\n [=no]
\n
Select multiple matches and perform the action on all of them together at\n the end. In this mode, press Esc to finish selecting.
\n
\n
\n
\n
\n
--multiple-joiner\n <MULTIPLE_JOINER>
\n
String for joining multiple selections when copying to the clipboard or\n inserting into the terminal. The special values are: space - a\n space character, newline - a newline, empty - an empty\n joiner, json - a JSON serialized list, auto - an automatic\n choice, based on the type of text being selected. In addition, integers\n are interpreted as zero-based indices into the list of selections. You can\n use 0 for the first selection and -1 for the last. Default:\n auto
\n
\n
\n
\n
\n
--add-trailing-space\n <ADD_TRAILING_SPACE>
\n
Add trailing space after matched text. Defaults to auto, which adds\n the space when used together with --multiple. Default: auto\n Choices: always, auto, never
\n
\n
\n
\n
\n
--hints-offset\n <HINTS_OFFSET>
\n
The offset (from zero) at which to start hint numbering. Note that only\n numbers greater than or equal to zero are respected. Default:\n 1
\n
\n
\n
\n
\n
--alphabet\n <ALPHABET>
\n
The list of characters to use for hints. The default is to use numbers and\n lowercase English alphabets. Specify your preference as a string of\n characters. Note that you need to specify the --hints-offset as\n zero to use the first character to highlight the first match, otherwise it\n will start with the second character by default.
\n
\n
\n
\n
\n
--ascending\n [=no]
\n
Make the hints increase from top to bottom, instead of decreasing from top\n to bottom.
\n
\n
\n
\n
\n
--hints-foreground-color\n <HINTS_FOREGROUND_COLOR>
\n
The foreground color for hints. You can use color names or hex values. For\n the eight basic named terminal colors you can also use the bright-\n prefix to get the bright variant of the color. Default: black
\n
\n
\n
\n
\n
--hints-background-color\n <HINTS_BACKGROUND_COLOR>
\n
The background color for hints. You can use color names or hex values. For\n the eight basic named terminal colors you can also use the bright-\n prefix to get the bright variant of the color. Default: green
\n
\n
\n
\n
\n
--hints-text-color\n <HINTS_TEXT_COLOR>
\n
The foreground color for text pointed to by the hints. You can use color\n names or hex values. For the eight basic named terminal colors you can\n also use the bright- prefix to get the bright variant of the color.\n The default is to pick a suitable color automatically. Default:\n auto
\n
\n
\n
\n
\n
--customize-processing\n <CUSTOMIZE_PROCESSING>
\n
Name of a python file in the kitty config directory which will be imported\n to provide custom implementations for pattern finding and performing\n actions on selected matches. You can also specify absolute paths to load\n the script from elsewhere. See\n https://sw.kovidgoyal.net/kitty/kittens/hints/ for details.
\n
\n
\n
\n
\n
--window-title\n <WINDOW_TITLE>
\n
The title for the hints window, default title is based on the type of text\n being hinted.
\n
\n
\n

Note:

\n
\n
\n

To avoid having to specify the same command line options\n on every invocation, you can use the action_alias\n <#opt-kitty.action_alias> option in kitty.conf, creating aliases\n that have common sets of options. For example:

\n
\n
\n
action_alias myhints kitten hints --alphabet qfjdkslaureitywovmcxzpq1234567890\nmap f1 myhints --customize-processing custom-hints.py
