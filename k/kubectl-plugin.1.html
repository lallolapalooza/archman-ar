kubectl-plugin(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
إريك باريس يناير 2015

الاسم

kubectl plugin - يوفر أدوات مساعدة للتفاعل مع الإضافات

الملخص

kubectl plugin [خيارات]

الوصف

يوفر أدوات مساعدة للتفاعل مع الإضافات.

توفر الإضافات وظائف موسعة ليست جزءًا من التوزيع الرئيسي لسطر الأوامر. يرجى الرجوع إلى الوثائق والأمثلة لمزيد من المعلومات حول كيفية كتابة الإضافات الخاصة بك.

أسهل طريقة لاكتشاف وتثبيت الإضافات هي من خلال المشروع الفرعي لـ Kubernetes krew: [krew.sigs.k8s.io]. لتثبيت krew، تفضل بزيارة https://krew.sigs.k8s.io/docs/user-guide/setup/install

خيارات موروثة من الأوامر الأبوية

--as="" اسم المستخدم لانتحاله للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة لانتحالها للعملية، يمكن تكرار هذا العلم لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) لانتحاله للعملية.

--cache-dir="/home/username/.kube/cache" دليل ذاكرة التخزين المؤقت الافتراضي

--certificate-authority="" مسار إلى ملف شهادة لمرجع الشهادات

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم السياق kubeconfig للاستخدام

--disable-compression=false إذا كان صحيحًا، قم بالانسحاب من ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، فلن يتم التحقق من صحة شهادة الخادم. هذا سيجعل اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" مسار ملف kubeconfig للاستخدام في طلبات CLI.

--kuberc="" مسار ملف kuberc للاستخدام في التفضيلات. يمكن تعطيل هذا عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف تشغيل الميزة KUBERC=off.

--match-server-version=false طلب مطابقة إصدار الخادم لإصدار العميل

-n, --namespace="" إذا كان موجودًا، فإن نطاق مساحة الاسم لهذا الطلب CLI

--password="" كلمة المرور للمصادقة الأساسية على خادم API

--profile="none" اسم الملف التعريفي المراد التقاطه. أحد (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف لكتابة الملف التعريفي إليه

--request-timeout="0" مدة الانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء مهلة الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم المستخدم للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، فسيتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز حامل للمصادقة على خادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية على خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # قائمة بجميع الإضافات المتاحة
  kubectl plugin list
  # قائمة بأسماء الثنائيات فقط للإضافات المتاحة بدون مسارات
  kubectl plugin list --name-only
