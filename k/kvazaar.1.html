NAME

kvazaar - KVAZAR video encoder

SYNOPSIS

kvazaar [options] [input file]

DESCRIPTION

This manual page describes the kvazaar command. Kvazaar is a high-performance, open-source video encoder that implements the Versatile Video Coding (VVC) standard (also known as ISO/IEC 23008-2 or ITU-T H.266).

The encoder aims to provide significant compression improvements over previous standards like HEVC (H.265), while maintaining compatibility with a wide range of hardware and software.

The following options are supported:

--input <string>
Input file name [stdin]
--output <string>
Output file name [stdout]
--recon <string>
Reconstructed file name
--threads <integer>
Number of threads to use [0 = number of cores]
--preset <string>
Preset encoding configuration [medium]
--cqp <integer>
Constant QP mode
--crf <integer>
Constant Rate Factor mode
--bitrate <integer>
Target bitrate in bits/s
--qp <integer>
Constant QP value
--intra-period <integer>
Intra period length
--intra-qp-offset <integer>
Intra QP offset
--decode-into-one-frame
Decodes into one frame
--vui-parameters
Enable VUI parameters
--level <string>
Specify encoding level [undef]
- undef, 1, 1.1, 1.2, 1.3, 2, 2.1, 2.2, 3, 3.1, 3.2, 4, 4.1, 4.2, 5, 5.1, 5.2, 6, 6.1, 6.2
--profile <string>
Specify encoding profile [main]
--bit-depth <integer>
Specify bit depth [0 = auto]
--chroma-format <string>
Specify chroma format [undef]
- undef, bt709, bt470m, bt470bg,
smpte170m, smpte240m, film, bt2020
--transfer <string>
Specify transfer characteristics [undef]
- undef, bt709, bt470m, bt470bg,
smpte170m, smpte240m, linear, log100,
log316, iec61966-2-4, bt1361e,
iec61966-2-1, bt2020-10, bt2020-12
--colormatrix <string>
Specify color matrix setting [undef]
- undef, bt709, fcc, bt470bg, smpte170m,
smpte240m, GBR, YCgCo, bt2020nc, bt2020c
--chromaloc <integer>
Specify chroma sample location (0 to 5) [0]
