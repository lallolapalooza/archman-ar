kubectl-set-selector(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl set selector - تعيين المحدد على مورد

ملخص

kubectl set selector [خيارات]

الوصف

تعيين المحدد على مورد. لاحظ أن المحدد الجديد سيحل محل المحدد القديم إذا كان للمورد واحد قبل استدعاء 'set selector'.

يجب أن يبدأ المحدد بحرف أو رقم، وقد يحتوي على أحرف وأرقام وشرطات ونقاط وشرطات سفلية، بحد أقصى 63 حرفًا. إذا تم تحديد --resource-version، فستستخدم التحديثات هذا الإصدار من المورد، وإلا فسيتم استخدام الإصدار الحالي للمورد. ملاحظة: حاليًا يمكن تعيين المحددات على كائنات الخدمة فقط.

الخيارات

--all=false تحديد جميع الموارد في نطاق أنواع الموارد المحددة

--allow-missing-template-keys=true إذا كان صحيحًا، فتجاهل أي أخطاء في القوالب عند فقدان حقل أو مفتاح خريطة في القالب. ينطبق فقط على تنسيقات الإخراج go-template و jsonpath.

--dry-run="none" يجب أن يكون "none" أو "server" أو "client". إذا كانت استراتيجية العميل، فقم فقط بطباعة الكائن الذي سيتم إرساله، دون إرساله. إذا كانت استراتيجية الخادم، فقم بإرسال طلب من جانب الخادم دون حفظ المورد.

--field-manager="kubectl-set" اسم المدير المستخدم لتتبع ملكية الحقول.

-f, --filename=[] تحديد المورد.

--local=false إذا كان صحيحًا، فلن يتصل التعليق التوضيحي بخادم واجهة برمجة التطبيقات ولكنه سيعمل محليًا.

-o, --output="" تنسيق الإخراج. أحد الخيارات: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

--record=false تسجيل أمر kubectl الحالي في التعليق التوضيحي للمورد. إذا تم تعيينه على false، فلا تسجل الأمر. إذا تم تعيينه على true، فقم بتسجيل الأمر. إذا لم يتم تعيينه، فقم بتحديث قيمة التعليق التوضيحي الحالية فقط إذا كانت موجودة بالفعل.

-R, --recursive=true معالجة الدليل المستخدم في -f، --filename بشكل متكرر. مفيد عندما تريد إدارة ملفات تعريف مرتبطة منظمة داخل نفس الدليل.

--resource-version="" إذا كان غير فارغ، فستنجح تحديثات المحددات فقط إذا كان هذا هو الإصدار الحالي للمورد للكائن. صالح فقط عند تحديد مورد واحد.

--show-managed-fields=false إذا كان صحيحًا، احتفظ بـ managedFields عند طباعة الكائنات بتنسيق JSON أو YAML.

--template="" سلسلة قالب أو مسار لملف قالب لاستخدامه عند -o=go-template، -o=go-template-file. تنسيق القالب هو قوالب golang [http://golang.org/pkg/text/template/#pkg-overview].

خيارات موروثة من الأوامر الأصلية

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في نطاق.

--as-group=[] مجموعة للانتحال للعملية، يمكن تكرار هذه العلامة لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل التخزين المؤقت الافتراضي

--certificate-authority="" مسار إلى ملف شهادة للسلطة المصدقة

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig المراد استخدامها

--context="" اسم سياق kubeconfig المراد استخدامه

--disable-compression=false إذا كان صحيحًا، فتجاوز ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، فلن يتم التحقق من صحة شهادة الخادم. سيؤدي ذلك إلى جعل اتصالات HTTPS غير آمنة

--kubeconfig="" مسار إلى ملف kubeconfig المراد استخدامه لطلبات CLI.

--kuberc="" مسار إلى ملف kuberc المراد استخدامه للتفضيلات. يمكن تعطيل ذلك عن طريق تصدير KUBECTL_KUBERC=false أو إيقاف تشغيل ميزة KUBERC=off.

--match-server-version=false مطالبة إصدار الخادم بمطابقة إصدار العميل

-n, --namespace="" إذا كان موجودًا، نطاق المجال لهذه الطلب CLI

--password="" كلمة المرور للمصادقة الأساسية إلى خادم API

--profile="none" اسم الملف الشخصي لالتقاطه. أحد الخيارات (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي ستتم كتابة الملف الشخصي إليه

--request-timeout="0" مدة الانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). تعني القيمة صفر عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم API Kubernetes

--tls-server-name="" اسم الخادم المراد استخدامه للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، فسيتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز مميز للمصادقة إلى خادم API

--user="" اسم مستخدم kubeconfig المراد استخدامه

--username="" اسم المستخدم للمصادقة الأساسية إلى خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # تعيين التسميات والمحدد قبل إنشاء زوج نشر/خدمة
  kubectl create service clusterip my-svc --clusterip="None" -o yaml --dry-run=client | kubectl set selector --local -f - 'environment=qa' -o yaml | kubectl create -f -
  kubectl create deployment my-dep -o yaml --dry-run=client | kubectl label --local -f - environment=qa -o yaml | kubectl create -f -
