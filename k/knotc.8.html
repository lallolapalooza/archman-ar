NAME

knotc — Knot DNS control utility

SYNOPSIS

knotc [-c config_file] command [arguments]

DESCRIPTION

The knotc utility is used to control the Knot DNS resolver/server. It allows querying and modifying the server configuration, as well as performing other administrative tasks.

EXIT VALUES

The exit status of knotc is 0 on success, and non-zero otherwise.

EXAMPLES

Get the primary servers for the example.com zone

$ knotc conf-read 'zone[example.com].master'

Add example.org zone with a zonefile location

$ knotc conf-begin
$ knotc conf-set 'zone[example.org]'
$ knotc conf-set 'zone[example.org].file' '/var/zones/example.org.zone'
$ knotc conf-commit

Get the SOA record for each configured zone

$ knotc zone-read -- @ SOA

SEE ALSO

knotd(8), knot.conf(5), editrc(5).
