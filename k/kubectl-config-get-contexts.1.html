kubectl-config-get-contexts(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
Eric Paris Jan 2015

الاسم

kubectl config get-contexts - وصف سياق واحد أو أكثر

الملخص

kubectl config get-contexts [خيارات]

الوصف

عرض سياق واحد أو أكثر من ملف kubeconfig.

خيارات

--no-headers=false عند استخدام تنسيق الإخراج الافتراضي أو تنسيق الأعمدة المخصصة، لا تطبع الرؤوس (افتراضي طباعة الرؤوس).

-o, --output="" تنسيق الإخراج. واحد من: (name).

خيارات موروثة من الأوامر الأبوية

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] مجموعة للانتحال للعملية، يمكن تكرار هذا العلم لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل التخزين المؤقت الافتراضي

--certificate-authority="" مسار ملف شهادة السلطة

--client-certificate="" مسار ملف شهادة العميل لـ TLS

--client-key="" مسار ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig للاستخدام

--context="" اسم سياق kubeconfig للاستخدام

--disable-compression=false إذا كان صحيحًا، يتم إلغاء ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، فلن يتم التحقق من صحة شهادة الخادم. سيجعل هذا اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" استخدام ملف kubeconfig معين

--kuberc="" مسار ملف kuberc للاستخدام للتفضيلات. يمكن تعطيل هذا عن طريق تصدير بوابة الميزات KUBECTL_KUBERC=false أو إيقاف بوابة الميزات KUBERC=off.

--match-server-version=false تطلب تطابق إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كان موجودًا، نطاق مساحة الاسم لهذا الطلب من واجهة سطر الأوامر

--password="" كلمة المرور للمصادقة الأساسية مع خادم API

--profile="none" اسم الملف التعريفي المراد التقاطه. واحد من (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف الذي ستتم كتابة الملف التعريفي إليه

--request-timeout="0" طول الوقت للانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (مثل 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم للاستخدام للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز المصادقة الحامل (Bearer token) للمصادقة مع خادم API

--user="" اسم مستخدم kubeconfig للاستخدام

--username="" اسم المستخدم للمصادقة الأساسية مع خادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يضبط الإصدار المبلغ عنه

--warnings-as-errors=false تعامل مع التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # سرد جميع السياقات في ملف kubeconfig الخاص بك
  kubectl config get-contexts
  # وصف سياق واحد في ملف kubeconfig الخاص بك
  kubectl config get-contexts my-context
