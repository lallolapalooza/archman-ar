killall(1)

NAME

killall - kill processes by name

SYNOPSIS

killall [-Z] [-u user] [-P pid] [-t tty] [-i] [-q] [-s signal] [-v] name...

DESCRIPTION

killall sends a specified signal, or SIGTERM if none is specified, to all processes running any of the specified command names. Unless prevented by a -o or -O option, the command also examines the command line arguments of processes to see if they match any of the specified names. A process is killed if its command name matches any of the specified names.

killall can be used to kill processes owned by other users, but unless killall is run as the super-user, it only kills processes owned by the user running killall.

The -o and -O options control whether the command line arguments of processes are checked.

OPTIONS

-Z, --all Kill all processes that match the specified name, even if they are running from a different path. -u, --user user Only kill processes owned by user. -P, --pid pid Only kill processes with the specified pid. -t, --tty tty Only kill processes attached to the specified tty. -i, --interactive Ask the user for confirmation before killing each process. -q, --quiet Do not report if a process could not be killed. -s, --signal signal Send signal instead of SIGTERM. The signal can be specified by name (e.g., HUP, INT, KILL, TERM) or by number. -v, --verbose Report whether the signal was successfully sent.

FILES

/proc (process information filesystem)

KNOWN BUGS

None reported.

SEE ALSO

kill(1), pkill(1), pgrep(1)

killall(1)

الاسم

killall - قتل العمليات بالاسم

الملخص

killall [-Z] [-u user] [-P pid] [-t tty] [-i] [-q] [-s signal] [-v] name...

الوصف

killall يرسل إشارة محددة، أو SIGTERM إذا لم يتم تحديد أي إشارة، إلى جميع العمليات التي تقوم بتشغيل أي من أسماء الأوامر المحددة. ما لم يتم منع ذلك بواسطة خيار -o أو -O، يقوم الأمر أيضًا بفحص وسائط سطر الأوامر للعمليات لمعرفة ما إذا كانت تتطابق مع أي من الأسماء المحددة. يتم قتل عملية إذا كان اسم أمرها يتطابق مع أي من الأسماء المحددة.

يمكن استخدام killall لقتل العمليات التي يمتلكها مستخدمون آخرون، ولكن ما لم يتم تشغيل killall بصلاحيات المستخدم الخارق، فإنه يقتل فقط العمليات التي يملكها المستخدم الذي يقوم بتشغيل killall.

تتحكم الخيارات -o و -O فيما إذا كانت وسائط سطر الأوامر للعمليات سيتم فحصها.

الخيارات

-Z, --all قتل جميع العمليات التي تتطابق مع الاسم المحدد، حتى لو كانت تعمل من مسار مختلف. -u, --user user قتل العمليات التي يملكها user فقط. -P, --pid pid قتل العمليات ذات pid المحدد فقط. -t, --tty tty قتل العمليات المتصلة بـ tty المحدد فقط. -i, --interactive طلب تأكيد من المستخدم قبل قتل كل عملية. -q, --quiet عدم الإبلاغ إذا لم يكن من الممكن قتل عملية. -s, --signal signal إرسال signal بدلاً من SIGTERM. يمكن تحديد الإشارة بالاسم (مثل HUP, INT, KILL, TERM) أو بالرقم. -v, --verbose الإبلاغ عما إذا تم إرسال الإشارة بنجاح.

الملفات

/proc (نظام ملفات معلومات العمليات)

الأخطاء المعروفة

لم يتم الإبلاغ عن أي شيء.

انظر أيضًا

kill(1), pkill(1), pgrep(1)
