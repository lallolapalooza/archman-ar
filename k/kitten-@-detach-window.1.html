kitten(1)

Name

kitten - controls kitty, the fast, featureful, GPU accelerated terminal emulator

Usage

kitten [-o ] [-c ] [-w ] [-h ] [-d] [-s ] [-t ] [-T ] [-V] [--} [args...]

Description

The kitten utility is used to control kitty, the fast, featureful, GPU accelerated terminal emulator. It can be used to send commands to an existing kitty instance, or to launch new kitty windows or tabs.

Options

-o
Use the specified key binding file instead of the default.
-c
Use the specified configuration file instead of the default.
-w
Set the width of the new window to columns.
-h
Set the height of the new window to rows.
-d
Detach the new window from the controlling terminal.
-s
Start the new window in the specified session.
-t
Set the terminal type to .
-T
Run the specified display program instead of the shell.
-V
Print version information and exit.
--
End of options. Any remaining arguments are treated as the command to run.

Global options

The following options are available for controlling the behavior of the kitten command:

--allow-non-local-shell
Allow launching a non-local shell. This is a security risk and should only be used if you know what you are doing.
--config-dir-is-pwd
Treat the current directory as the config directory.
--debug
Enable debugging output.
--debug-window
Enable debugging output for the specified window.
--end-signal
Send the specified signal to the process when the window is closed.
--env
Set the environment variable to .
--feature-flags
Enable or disable feature flags. Supported flags: if-available, always, never
