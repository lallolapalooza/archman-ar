الاسم

kubeadm-join - انضمام عقدة إلى مجموعة Kubernetes

الملخص

kubeadm join [API_SERVER_URL] --token [TOKEN] [flags]

الوصف

يستخدم الأمر kubeadm join لإضافة عقدة عاملة (worker node) إلى مجموعة Kubernetes موجودة. يتطلب هذا الأمر عنوان خادم API للمجموعة، ورقم تعريف الرمز المميز (token) الذي تم إنشاؤه بواسطة kubeadm init، وإذا لزم الأمر، بصمة المفتاح (key fingerprint) للتحقق من شهادة CA.

الخيارات

--token string

الرمز المميز للانضمام إلى المجموعة.

--discovery-file string

ملف يحتوي على معلومات اكتشاف المجموعة (عادةً ما يتم إنشاؤه بواسطة kubeadm init --discovery-file).

--discovery-token-ca-cert-hash string

تجزئة شهادة CA للمجموعة (على سبيل المثال، sha256:.....). يتم استخدامها للتحقق من شهادة CA للمجموعة.

--node-ip string

عنوان IP الذي ستستخدمه هذه العقدة للاتصال بخادم API.

--cri-socket string

مسار مقبس CRI (Container Runtime Interface) المراد استخدامه. الافتراضي هو unix:///var/run/cri-dockerd.sock.

خيارات موروثة من أوامر الأب

لا توجد خيارات موروثة مباشرة من الأمر الأب.
