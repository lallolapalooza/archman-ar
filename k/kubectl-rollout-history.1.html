kubectl-rollout-history(1)

الحزمة: kubectl

التراخيص: Apache-2.0

KUBERNETES(1)(kubernetes) KUBERNETES(1)(kubernetes)
إريك باريس يناير 2015

الاسم

kubectl rollout history - عرض سجل التراجع

الملخص

kubectl rollout history [خيارات]

الوصف

عرض الإصدارات والتكوينات السابقة للتراجع.

الخيارات

--allow-missing-template-keys=true إذا كان صحيحًا، تجاهل أي أخطاء في القوالب عندما يكون الحقل أو مفتاح الخريطة مفقودًا في القالب. ينطبق فقط على تنسيقات الإخراج golang و jsonpath.

-f, --filename=[] اسم الملف أو الدليل أو عنوان URL للملفات التي تحدد المورد المطلوب الحصول عليه من الخادم.

-k, --kustomize="" معالجة دليل kustomization. لا يمكن استخدام هذا الخيار مع -f أو -R.

-o, --output="" تنسيق الإخراج. أحد الخيارات: (json, yaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file).

-R, --recursive=false معالجة الدليل المستخدم في -f، --filename بشكل متكرر. مفيد عندما تريد إدارة الملفات التصريحية ذات الصلة المنظمة داخل نفس الدليل.

--revision=0 عرض التفاصيل، بما في ذلك podTemplate للإصدار المحدد

-l, --selector="" محدد (استعلام الملصق) للتصفية، يدعم '=', '==', '!=', 'in', 'notin'. (على سبيل المثال، -l key1=value1,key2=value2,key3 in (value3)). يجب أن تتطابق الكائنات المطابقة مع جميع قيود الملصقات المحددة.

--show-managed-fields=false إذا كان صحيحًا، احتفظ بالحقول التي تتم إدارتها عند طباعة الكائنات بتنسيق JSON أو YAML.

--template="" سلسلة القالب أو المسار إلى ملف القالب لاستخدامه عند -o=go-template، -o=go-template-file. تنسيق القالب هو قوالب golang [http://golang.org/pkg/text/template/#pkg-overview].

خيارات موروثة من الأوامر الأصل

--as="" اسم المستخدم للانتحال للعملية. يمكن أن يكون المستخدم مستخدمًا عاديًا أو حساب خدمة في مساحة اسم.

--as-group=[] المجموعة للانتحال للعملية، يمكن تكرار هذا الخيار لتحديد مجموعات متعددة.

--as-uid="" معرف المستخدم (UID) للانتحال للعملية.

--cache-dir="/home/username/.kube/cache" دليل الذاكرة المؤقتة الافتراضي

--certificate-authority="" مسار إلى ملف شهادة للسلطة المصدقة

--client-certificate="" مسار إلى ملف شهادة العميل لـ TLS

--client-key="" مسار إلى ملف مفتاح العميل لـ TLS

--cluster="" اسم مجموعة kubeconfig المراد استخدامها

--context="" اسم سياق kubeconfig المراد استخدامه

--disable-compression=false إذا كان صحيحًا، استبعاد ضغط الاستجابة لجميع الطلبات إلى الخادم

--insecure-skip-tls-verify=false إذا كان صحيحًا، لن يتم التحقق من صحة شهادة الخادم. سيجعل هذا اتصالات HTTPS الخاصة بك غير آمنة

--kubeconfig="" مسار إلى ملف kubeconfig للاستخدام في طلبات سطر الأوامر.

--kuberc="" مسار إلى ملف kuberc للاستخدام في التفضيلات. يمكن تعطيل هذا عن طريق تصدير بوابة الميزة KUBECTL_KUBERC=false أو إيقاف تشغيل الميزة KUBERC=off.

--match-server-version=false طلب تطابق إصدار الخادم مع إصدار العميل

-n, --namespace="" إذا كان موجودًا، فإن نطاق مساحة الاسم لطلب سطر الأوامر هذا

--password="" كلمة المرور للمصادقة الأساسية لخادم API

--profile="none" اسم الملف الشخصي المراد التقاطه. أحد الخيارات: (none|cpu|heap|goroutine|threadcreate|block|mutex)

--profile-output="profile.pprof" اسم الملف المراد كتابة الملف الشخصي إليه

--request-timeout="0" مدة الانتظار قبل التخلي عن طلب خادم واحد. يجب أن تحتوي القيم غير الصفرية على وحدة زمنية مقابلة (على سبيل المثال، 1s، 2m، 3h). القيمة صفر تعني عدم انتهاء صلاحية الطلبات.

-s, --server="" عنوان ومنفذ خادم Kubernetes API

--tls-server-name="" اسم الخادم المراد استخدامه للتحقق من صحة شهادة الخادم. إذا لم يتم توفيره، يتم استخدام اسم المضيف المستخدم للاتصال بالخادم

--token="" رمز المميز للمصادقة لخادم API

--user="" اسم مستخدم kubeconfig المراد استخدامه

--username="" اسم المستخدم للمصادقة الأساسية لخادم API

--version=false --version، --version=raw يطبع معلومات الإصدار ويخرج؛ --version=vX.Y.Z... يحدد الإصدار المبلغ عنه

--warnings-as-errors=false عامل التحذيرات المستلمة من الخادم كأخطاء واخرج برمز خروج غير صفري

مثال

  # عرض سجل تراجع للنشر
  kubectl rollout history deployment/abc
  # عرض تفاصيل الإصدار 3 لـ daemonset
  kubectl rollout history daemonset/abc --revision=3
