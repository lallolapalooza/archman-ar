rename_principal

rename_principal [-force] old_principal new_principal

يعيد تسمية old_principal المحدد إلى new_principal. يطالب هذا الأمر بتأكيد، ما لم يتم توفير الخيار -force.

يتطلب هذا الأمر امتيازات add و delete.

اسم مستعار: renprinc

delete_principal

delete_principal [-force] principal

يحذف principal المحدد من قاعدة البيانات. يطالب هذا الأمر بالحذف، ما لم يتم توفير الخيار -force.

يتطلب هذا الأمر امتياز delete.

اسم مستعار: delprinc

change_password

change_password [options] principal

يغير كلمة مرور principal. يطالب بكلمة مرور جديدة إذا لم يتم تحديد -randkey أو -pw.

يتطلب هذا الأمر امتياز changepw، أو أن يكون principal الذي يقوم بتشغيل البرنامج هو نفسه principal الذي يتم تغييره.

اسم مستعار: cpw

الخيارات التالية متاحة:

-randkey
يعين مفتاح principal إلى قيمة عشوائية.
-pw password
يعين كلمة المرور إلى السلسلة المحددة. قد يؤدي استخدام هذا الخيار في البرنامج النصي إلى كشف كلمة المرور لمستخدمين آخرين على النظام عبر قائمة العمليات.
-e enc:salt,...
يستخدم قائمة keysalt المحددة لتعيين مفاتيح principal. انظر Keysalt_lists في kdc.conf(5) للحصول على قائمة بالقيم الممكنة.
-keepold
يحتفظ بالمفاتيح الحالية في قاعدة البيانات. هذا العلم عادة غير ضروري إلا ربما لمفاتيح krbtgt principals.

مثال:

kadmin: cpw systest
Enter password for principal systest@BLEEP.COM:
Re-enter password for principal systest@BLEEP.COM:
Password for systest@BLEEP.COM changed.
kadmin:

purgekeys

purgekeys [-all|-keepkvno oldest_kvno_to_keep] principal

يحذف المفاتيح القديمة المحفوظة سابقًا (مثل، من change_password -keepold) من principal. إذا تم تحديد -keepkvno، فإنه يحذف فقط المفاتيح ذات kvnos الأقل من oldest_kvno_to_keep. إذا تم تحديد -all، فإنه يحذف جميع المفاتيح. الخيار -all جديد في الإصدار 1.12.

يتطلب هذا الأمر امتياز modify.

list_principals

list_principals [expression]

يسترجع جميع أسماء principal أو بعضها. expression هو تعبير نمط shell يمكن أن يحتوي على أحرف البدل ?، *، و []. يتم طباعة جميع أسماء principal التي تطابق التعبير. إذا لم يتم توفير تعبير، يتم طباعة جميع أسماء principal. إذا كان التعبير لا يحتوي على حرف @، يتم إلحاق حرف @ متبوعًا بالنطاق المحلي بالتعبير.

يتطلب هذا الأمر امتياز list.

مثال:

kadmin:  listprincs test*

test2@SECURE-TEST.OV.COM
test1@SECURE-TEST.OV.COM
testuser@SECURE-TEST.OV.COM

set_string

set_string principal name value

يعين سمة سلسلة على principal. تُستخدم سمات السلسلة لتوفير تكوين لكل principal لوحدة KDC وبعض وحدات KDC المساعدة. أسماء سمات السلسلة التالية معترف بها بواسطة KDC:

require_auth
يحدد مؤشر مصادقة مطلوب للمصادقة على principal كخدمة. يمكن تحديد مؤشرات متعددة، مفصولة بمسافات؛ في هذه الحالة، سيتم قبول أي من المؤشرات المحددة. (جديد في الإصدار 1.14.)
session_enctypes
يحدد أنواع التشفير المدعومة لمفاتيح الجلسة عندما تتم المصادقة على principal كخادم. انظر Encryption_types في kdc.conf(5) للحصول على قائمة بالقيم المقبولة.
otp
يمكّن كلمات المرور لمرة واحدة (OTP) المصادقة المسبقة لـ principal عميل. value هو سلسلة JSON تمثل مصفوفة من الكائنات، كل منها يحتوي على حقول type و username اختيارية.
pkinit_cert_match
يحدد تعبير مطابقة يحدد سمات الشهادة المطلوبة لشهادة العميل المستخدمة بواسطة principal أثناء المصادقة PKINIT. تعبير المطابقة بنفس تنسيق تلك المستخدمة بواسطة خيار pkinit_cert_match في krb5.conf(5). (جديد في الإصدار 1.16.)
pac_privsvr_enctype
يجبر نوع تشفير مخازن PAC KDC checksum على نوع التشفير المحدد للتذاكر الصادرة لهذا الخادم، عن طريق اشتقاق مفتاح من مفتاح krbtgt المحلي إذا كان من نوع تشفير مختلف. قد يكون من الضروري تعيين هذه القيمة إلى "aes256-sha1" على إدخال krbtgt عبر النطاقات لنطاق Active Directory عند استخدام مفاتيح aes-sha2 على إدخال krbtgt المحلي.

يتطلب هذا الأمر امتياز modify.

اسم مستعار: setstr

مثال:

set_string host/foo.mit.edu session_enctypes aes128-cts
set_string user@FOO.COM otp "[{""type"":""hotp"",""username"":""al""}]"

add_policy [options] policy

يضيف سياسة كلمة مرور تسمى policy إلى قاعدة البيانات.

يتطلب هذا الأمر امتياز add.

اسم مستعار: addpol

الخيارات التالية متاحة:

-maxlife time
(مدة زمنية أو سلسلة getdate) يحدد الحد الأقصى لعمر كلمة المرور.
-minlife time
(مدة زمنية أو سلسلة getdate) يحدد الحد الأدنى لعمر كلمة المرور.
-minlength length
يحدد الحد الأدنى لطول كلمة المرور.
-minclasses number
يحدد الحد الأدنى لعدد فئات الأحرف المطلوبة في كلمة المرور. فئات الأحرف الخمس هي الأحرف الصغيرة، والأحرف الكبيرة، والأرقام، وعلامات الترقيم، والمسافات البيضاء/الأحرف غير القابلة للطباعة.
-history number
يحدد عدد المفاتيح القديمة المحفوظة لـ principal. هذا الخيار غير مدعوم مع وحدة قاعدة بيانات LDAP KDC.
-maxfailure maxnumber
يحدد عدد فشل المصادقة قبل قفل principal. يتم تتبع فشل المصادقة فقط للمفاتيح التي تتطلب المصادقة المسبقة. يتم إعادة تعيين عداد المحاولات الفاشلة إلى 0 بعد محاولة مصادقة ناجحة. قيمة maxnumber 0 (الافتراضي) يعطل القفل.

NAME

kadmin, kadmin/local - Kerberos 5 administration program

SYNOPSIS

kadmin [-p principal] [-k] [-n] [-r realm]
    [-m] [-w password] [-Q query_expr]
    [-T ticket_cache] [-q] [-d] [-l] [-t] [-f]
    [-F] [-P port] [-S service] [-H host]
    [-i] [-V] [-v] [-e] [-x extra_options] [-conf
    file] [-kdc kdc_host] [-dn dn] [-U user]
    [-R realm] [-P password]

or

kadmin [-help | -?]

kadmin/local is a symbolic link to kadmin, used to allow local administration without Kerberos authentication.

DESCRIPTION

The kadmin program provides an interactive interface for administering the Kerberos 5 database.

The administration program can be used to create, delete, and modify principals, policies, keytabs, and realms. It also allows for dumping and loading of the Kerberos database.

The kadmin/local link allows administration by the local root user without requiring a Kerberos ticket. This is typically used for initial setup of the Kerberos database.

Note that some options are only available for specific database modules. For example, the lock/unlock commands only work with the DB2 database module.

OPTIONS

The options are as follows:

-p principal
The principal name to log in as. If not specified, kadmin will prompt for it.
-k
Use a keytab file to authenticate instead of a password.
-n
No password prompt. Use this if the principal is already authenticated.
-r realm
The realm to use. If not specified, the default realm is used.
-m
Use the default principal name and realm.
-w password
The password for the principal. If not specified, kadmin will prompt for it.
-Q query_expr
Specify a query expression for list_principals.
-T ticket_cache
Use the specified ticket cache.
-q
Quiet mode. Suppresses some informational messages.
-d
Enable debugging output.
-l
Enable logging.
-t
Print the KDC timestamp.
-f
Print the KDC flags.
-F
Print the KDC policy information.
-P port
The port to connect to the KDC administration daemon on. Defaults to 749.
-S service
The service principal to use for administration. Defaults to kadmin/admin.
-H host
The KDC host to connect to. Defaults to the KDC listed in krb5.conf.
-i
Interactive mode. Prompts for commands.
-V
Verbose mode. Prints more detailed information.
-v
Print version information and exit.
-e
Print the list of supported encryption types.
-x extra_options
Pass extra options to the KDC administration daemon. See kadmind(8) for details.
-conf file
Use the specified Kerberos configuration file.
-kdc kdc_host
Use the specified KDC host.
-dn dn
Use the specified DN for LDAP authentication.
-U user
Use the specified user for LDAP authentication.
-R realm
Use the specified realm.
-P password
Use the specified password for authentication.
-help | -?
Display a help message and exit.

DATABASE OPTIONS

These options are used for interacting with the Kerberos database.

-db2logdir directory
Sets the directory for DB2 transaction logs.
-db2sockdir directory
Sets the directory for DB2 socket files.
-db2lockdir directory
Sets the directory for DB2 lock files.
-db2dbldir directory
Sets the directory for DB2 database files.

COMMANDS

The following commands are available:

add_policy

add_policy [options] policy

Creates a new password policy named policy. The following options are available:

-maxlife maximum_life
(duration or getdate string) Sets the maximum lifetime for a password.
-minlife minimum_life
(duration or getdate string) Sets the minimum lifetime for a password.
-minlength length
(integer) Sets the minimum length for a password.
-minclasses number
(integer) Sets the minimum number of character classes required in a password.
-maxകെptkeys count
(integer) Sets the number of old passwords to keep track of.
-failurecountinterval failuretime
(duration or getdate string) Sets the allowable time between authentication failures. If an authentication failure happens after failuretime has elapsed since the previous failure, the number of authentication failures is reset to 1. A failuretime value of 0 (the default) means forever.
-lockoutduration lockouttime
(duration or getdate string) Sets the duration for which the principal is locked from authenticating if too many authentication failures occur without the specified failure count interval elapsing. A duration of 0 (the default) means the principal remains locked out until it is administratively unlocked with modprinc -unlock.
-allowedkeysalts
Specifies the key/salt tuples supported for long-term keys when setting or changing a principal's password/keys. See Keysalt_lists in kdc.conf(5) for a list of the accepted values, but note that key/salt tuples must be separated with commas (',') only. To clear the allowed key/salt policy use a value of '-'.

Example:

kadmin: add_policy -maxlife "2 days" -minlength 5 guests
kadmin:

modify_policy

modify_policy [options] policy

Modifies the password policy named policy. Options are as described for add_policy.

This command requires the modify privilege.

Alias: modpol

delete_policy

delete_policy [-force] policy

Deletes the password policy named policy. Prompts for confirmation before deletion. The command will fail if the policy is in use by any principals.

This command requires the delete privilege.

Alias: delpol

Example:

kadmin: del_policy guests
Are you sure you want to delete the policy "guests"?
(yes/no): yes
kadmin:

get_policy

get_policy [ -terse ] policy

Displays the values of the password policy named policy. With the -terse flag, outputs the fields as quoted strings separated by tabs.

This command requires the inquire privilege.

Alias: getpol

Examples:

kadmin: get_policy admin
Policy: admin
Maximum password life: 180 days 00:00:00
Minimum password life: 00:00:00
Minimum password length: 6
Minimum number of password character classes: 2
Number of old keys kept: 5
Reference count: 17
kadmin: get_policy -terse admin
admin     15552000  0    6    2    5    17
kadmin:

The "Reference count" is the number of principals using that policy. With the LDAP KDC database module, the reference count field is not meaningful.

list_policies

list_policies [expression]

Retrieves all or some policy names. expression is a shell-style glob expression that can contain the wild-card characters ?, *, and []. All policy names matching the expression are printed. If no expression is provided, all existing policy names are printed.

This command requires the list privilege.

Aliases: listpols, get_policies, getpols.

Examples:

kadmin:  listpols
test-pol
dict-only
once-a-min
test-pol-nopw
kadmin:  listpols t*
test-pol
test-pol-nopw
kadmin:

ktadd

ktadd [options] principal
ktadd [options] -glob princ-exp

Adds a principal, or all principals matching princ-exp, to a keytab file. Each principal's keys are randomized in the process. The rules for princ-exp are described in the list_principals command.

This command requires the inquire and changepw privileges. With the -glob form, it also requires the list privilege.

The options are:

-k[eytab] keytab
Use keytab as the keytab file. Otherwise, the default keytab is used.
-e enc:salt,...
Uses the specified keysalt list for setting the new keys of the principal. See Keysalt_lists in kdc.conf(5) for a list of possible values.
-q
Display less verbose information.
-norandkey
Do not randomize the keys. The keys and their version numbers stay unchanged. This option cannot be specified in combination with the -e option.

An entry for each of the principal's unique encryption types is added, ignoring multiple keys with the same encryption type but different salt types.

Alias: xst

Example:

kadmin: ktadd -k /tmp/foo-new-keytab host/foo.mit.edu
Entry for principal host/foo.mit.edu@ATHENA.MIT.EDU with kvno 3,
     encryption type aes256-cts-hmac-sha1-96 added to keytab
     FILE:/tmp/foo-new-keytab
kadmin:

ktremove

ktremove [options] principal [kvno | all | old]

Removes entries for the specified principal from a keytab. Requires no permissions, since this does not require database access.

If the string "all" is specified, all entries for that principal are removed; if the string "old" is specified, all entries for that principal except those with the highest kvno are removed. Otherwise, the value specified is parsed as an integer, and all entries whose kvno match that integer are removed.

The options are:

-k[eytab] keytab
Use keytab as the keytab file. Otherwise, the default keytab is used.
-q
Display less verbose information.

Alias: ktrem

Example:

kadmin: ktremove kadmin/admin all
Entry for principal kadmin/admin with kvno 3 removed from keytab
     FILE:/etc/krb5.keytab
kadmin:

lock

Lock database exclusively. Use with extreme caution! This command only works with the DB2 KDC database module.

unlock

Release the exclusive database lock.

list_requests

Lists available for kadmin requests.

Aliases: lr, ?

quit

Exit program. If the database was locked, the lock is released.

Aliases: exit, q
