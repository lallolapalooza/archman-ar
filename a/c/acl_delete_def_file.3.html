acl_delete_def_file(3)

الحزمة: acl

التراخيص: LGPL

ACL_DELETE_DEF_FILE(3) دليل وظائف المكتبة ACL_DELETE_DEF_FILE(3)

الاسم

acl_delete_def_file — حذف ACL افتراضي بواسطة اسم ملف

المكتبة

مكتبة قوائم التحكم بالوصول لنظام لينكس (libacl, -lacl).

الاختصار

#include <sys/types.h>
#include <sys/acl.h>

int
acl_delete_def_file(const char *path_p);

الوصف

تقوم وظيفة acl_delete_def_file() بحذف ACL افتراضي من الدليل الذي يشير إليه المسار المحدد بواسطة المتغير path_p.

يجب أن يتطابق معرف المستخدم الفعلي للعملية مع مالك الملف أو الدليل، أو يجب أن تمتلك العملية القدرة CAP_FOWNER لنجاح الطلب.

إذا لم يكن المتغير path_p دليلاً، تفشل الوظيفة. لا يعتبر خطأ إذا كان الدليل الذي يشير إليه المسار path_p لا يحتوي على ACL افتراضي.

قيمة الإرجاع

تعيد الوظيفة acl_delete_def_file() القيمة 0 في حالة النجاح؛ وإلا، يتم إرجاع القيمة -1 ويتم تعيين المتغير العام errno لبيان الخطأ.

الأخطاء

إذا حدث أي من الظروف التالية، تعيد الوظيفة acl_delete_def_file() القيمة -1 وتعين errno إلى القيمة المقابلة:

[EINVAL]
الملف المشار إليه بواسطة path_p ليس دليلاً.
[ENOTSUP]
نظام الملفات الذي يقع عليه الملف المحدد بواسطة path_p لا يدعم قوائم التحكم بالوصول (ACLs)، أو أن قوائم التحكم بالوصول معطلة.
[EPERM]
العملية لا تمتلك الصلاحية المناسبة لأداء عملية حذف ACL الافتراضي.
[EROFS]
تتطلب هذه الوظيفة تعديل نظام ملفات للقراءة فقط حاليًا.

المعايير

IEEE Std 1003.1e draft 17 (“POSIX.1e”, مهجورة)
