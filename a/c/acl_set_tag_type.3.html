acl_set_tag_type(3)

الحزمة: acl

التراخيص: LGPL

ACL_SET_TAG_TYPE(3) دليل وظائف المكتبة ACL_SET_TAG_TYPE(3)

الاسم

acl_set_tag_type — تعيين نوع العلامة لإدخال ACL

المكتبة

مكتبة قوائم التحكم في الوصول لنظام Linux (libacl, -lacl).

ملخص

#include <sys/types.h>
#include <sys/acl.h>

int
acl_set_tag_type(acl_entry_t entry_d, acl_tag_t tag_type);

الوصف

الدالة acl_set_tag_type() تقوم بتعيين نوع العلامة لإدخال ACL المشار إليه بواسطة الوسيط entry_d إلى قيمة الوسيط tag_type.

تستمر أي واصفات إدخال ACL التي تشير إلى الإدخال المشار إليه بواسطة entry_d في الإشارة إلى هذا الإدخال.

قيمة الإرجاع

تُرجع الدالة acl_set_tag_type() القيمة 0 عند النجاح؛ وإلا، تُرجع القيمة -1 ويتم تعيين المتغير العام errno للإشارة إلى الخطأ.

الأخطاء

إذا حدث أي من الشروط التالية، تُرجع الدالة acl_set_tag_type() -1 وتُعين errno إلى القيمة المقابلة:

[EINVAL]
الوسيط entry_d ليس واصفًا صالحًا لإدخال ACL.

الوسيط tag_type ليس نوع علامة صالحًا.

المعايير

مسودة IEEE Std 1003.1e 17 (“POSIX.1e”، تم التخلي عنها)
