audit_add_watch(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_ADD_WATCH(3) واجهة برمجة تطبيقات تدقيق Linux AUDIT_ADD_WATCH(3)

الاسم

audit_add_watch - إنشاء تخطيط قاعدة لمراقبة

الملخص

#include <libaudit.h>
int audit_add_watch(struct audit_rule_data **rulep, const char *path);"

الوصف

ستقوم audit_add_watch بإنشاء قاعدة مراقبة في المؤشر إلى مؤشر rulep. كل ما تحتاج إلى تمريره هو path الكامل لملف وسيقوم بتهيئة بنية audit_rule_data للمراقبة.

قيمة الإرجاع

يعيد -1 في حالة حدوث خطأ؛ وإلا، 0 للنجاح.

انظر أيضًا

audit_add_rule_data(3)، audit_delete_rule_data(3).
