audit_set_enabled(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_SET_ENABLED(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_SET_ENABLED(3)

الاسم

audit_set_enabled - تمكين أو تعطيل التدقيق

ملخص

#include <libaudit.h>

int audit_set_enabled(intfd,uint32_t"enabled);"

الوصف

يُستخدم audit_set_enabled للتحكم في ما إذا كان نظام التدقيق نشطًا أم لا. عندما يتم تمكين نظام التدقيق (تم تعيين enabled إلى 1)، سيمر كل استدعاء نظام عبر نظام التدقيق لجمع المعلومات وربما تشغيل حدث.

إذا تم تعطيل نظام التدقيق (تم تعيين enabled إلى 0)، لا تدخل استدعاءات النظام في نظام التدقيق ولا يتم جمع أي بيانات. قد يتم إنشاء بعض الأحداث بواسطة أنظمة فرعية MAC مثل SE Linux حتى لو كان نظام التدقيق معطلاً. من الممكن قمع هذه الأحداث أيضًا، عن طريق إضافة قاعدة تدقيق مع تعيين الأعلام إلى AUDIT_FILTER_EXCLUDE

قيمة الإرجاع

قيمة الإرجاع تكون <= 0 عند حدوث خطأ، وإلا فهي رقم معرف تسلسل netlink. يمكن أن تواجه هذه الدالة أي خطأ يمكن أن تواجهه sendto.

انظر أيضًا

audit_add_rule_data(3), auditd(8).
