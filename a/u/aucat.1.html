aucat(1)

الحزمة: sndio

التراخيص: ISC

NAME

aucat - a generic audio device mixer and player

SYNOPSIS

aucat [-n] [-h] [-v] [-e enc] [-r rate] [-b bits] [-F file] [-L file] [-P file] [-c chn] [-m map] [-i file] [-o file] [-d dev] [-f file] [-q dev] [-s dev] [-t dev] [-p dev] [-R dev] [-O dev] [-M dev] [-S dev] [-Q dev]

DESCRIPTION

aucat is a command-line utility that plays and records audio data between files and audio devices. It supports mixing multiple audio streams, resampling, and various audio file formats. The command can also be used for audio device control and routing.

The aucat command can be used to:

  • Play audio files to an audio device.
  • Record audio from an audio device into a file.
  • Mix multiple audio files and/or devices.
  • Route audio streams between different channels and devices.
  • Control audio playback using MIDI Machine Control (MMC) and MIDI Time Code (MTC).

MIDI CONTROL

The aucat command can synchronize with external MIDI devices for playback control and timecode synchronization. This is particularly useful in professional audio and video production environments.

To enable MIDI control, you need to specify the MIDI ports that aucat will use. The -q option specifies the MIDI output port for MMC commands, and the -i option specifies the MIDI input port for receiving MMC commands and MTC.

For example, to use midithru/0 as the MIDI output port for MMC commands and file.wav as the audio file to play:

$ aucat -f snd/mmc -q midithru/0 -i file.wav

In this scenario, aucat will start, stop, and seek automatically, mirroring all user actions in the MIDI sequencer. This assumes the MIDI sequencer is configured to transmit MMC on midithru/0 and to use snd/mmc as the MIDI port. Additionally, the MIDI sequencer can be configured to use the snd/mmc port as an MTC clock source, ensuring synchronization with the playback of file.wav.

EXAMPLES

Mix and play two files while recording a third file:

$ aucat -i file1.wav -i file2.wav -o file3.wav

Record channels 2 and 3 into one stereo file and channels 6 and 7 into another stereo file using a 44.1kHz sampling rate for both:

$ aucat -r 44100 -m 2:3/0:1 -o file1.wav -m 6:7/0:1 -o file2.wav

Split a stereo file into two mono files:

$ aucat -n -i stereo.wav -c 1 -m 0:0/0:0 -o left.wav \
	-m 1:1/0:0 -o right.wav

BUGS

Resampling is low quality.

There are limitations inherent to the wav, aiff, and au file formats: not all encodings are supported, file sizes are limited to 2GB, and the files must support the lseek(2) operation (e.g. pipes do not support it).
