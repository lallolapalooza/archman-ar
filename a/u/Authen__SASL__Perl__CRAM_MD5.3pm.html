Authen__SASL__Perl__CRAM_MD5(3pm)

الحزمة: perl-authen-sasl

التراخيص: GPL, PerlArtistic

Authen::SASL::Perl::CRAM_MD5(3) وثائق Perl المساهمة من المستخدم Authen::SASL::Perl::CRAM_MD5(3)

الاسم

Authen::SASL::Perl::CRAM_MD5 - (مهمل) فئة مصادقة CRAM MD5

الإصدار

الإصدار 2.1900

الملخص

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'CRAM-MD5',
  callback  => {
    user => $user,
    pass => $pass
  },
);

الوصف

تنفذ هذه الطريقة الجزء الخاص بالعميل من خوارزمية CRAM-MD5 SASL، كما هو موضح في RFC 2195 أو في مسودة IETF draft-ietf-sasl-crammd5-XX.txt.

يرجى ملاحظة أنه تم نقل هذه الآلية إلى قسم "الاستخدام المحدود" لسجل الآليات https://www.iana.org/assignments/sasl-mechanisms/sasl-mechanisms.xhtml وهي مهملة فعليًا وفقًا لـ RFC8314 https://www.rfc-editor.org/rfc/rfc8314.html (انظر القسم 5؛ اعتبارات الأمان).
