audit_name_to_errno(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_NAME_TO_ERRNO(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_NAME_TO_ERRNO(3)

الاسم

audit_name_to_errno، audit_errno_to_name - تحويل اسم الخطأ (errno) وقيمة الخطأ الرقمية إلى بعضهما البعض

الملخص

#include <libaudit.h>
int audit_name_to_errno(const char *error);
const char *audit_errno_to_name(int error);

الوصف

تقوم الدالة audit_name_to_errno() بتحويل اسم الخطأ (errno) ("EPERM"، "ENOENT"، "ESRCH"، إلخ) إلى قيمة الخطأ الرقمية (EPERM، ENOENT، ESRCH، إلخ). error هو اسم الخطأ.

تقوم الدالة audit_errno_to_name() بتحويل قيمة الخطأ الرقمية (EPERM، ENOENT، ESRCH، إلخ) إلى اسم الخطأ ("EPERM"، "ENOENT"، "ESRCH"، إلخ). error هي قيمة الخطأ الرقمية.

قيمة الإرجاع

تعيد الدالة audit_name_to_errno() القيمة 0 في حالة حدوث خطأ؛ بخلاف ذلك، تكون قيمة الإرجاع هي قيمة الخطأ الرقمية.

تعيد الدالة audit_errno_to_name() القيمة NULL في حالة حدوث خطأ؛ بخلاف ذلك، تكون قيمة الإرجاع هي اسم الخطأ.
