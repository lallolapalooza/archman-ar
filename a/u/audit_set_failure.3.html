audit_set_failure(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_SET_FAILURE(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_SET_FAILURE(3)

الاسم

audit_set_failure - تعيين علامة فشل التدقيق

الملخص

#include <libaudit.h>

int audit_set_failure(intfd,uint32_t"failure);"

الوصف

تقوم audit_set_failure بتعيين الإجراء الذي سيقوم به النواة عند الوصول إلى حد قائمة الانتظار الخلفية أو عند مواجهة خطأ وعدم القدرة على المتابعة. القيم الممكنة هي:

0 - AUDIT_FAIL_SILENT
لا تفعل شيئًا، لا تبلغ عن شيء، تخطى تسجيل السجل واستمر.
1 - AUDIT_FAIL_PRINTK [افتراضي]
تسجيل سجل التدقيق باستخدام printk مما سيؤدي إلى كتابة الأحداث اللاحقة إلى syslog.
2 - AUDIT_FAIL_PANIC
استدعاء وظيفة panic. سيتم استخدام هذا لمنع استخدام الجهاز عند فقدان أحداث التدقيق.

قيمة الإرجاع

القيمة المرجعة هي <= 0 عند حدوث خطأ، وإلا فهي رقم معرف تسلسل netlink. يمكن أن يكون لهذه الدالة أي خطأ يمكن أن تواجهه sendto.

انظر أيضاً

audit_set_backlog_limit(3)، audit_open(3)، auditd(8)، auditctl(8).
