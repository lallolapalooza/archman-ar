NAME

auto-multiple-choice-analyse - Analyse a survey.

SYNOPSIS

auto-multiple-choice-analyse [options] survey.tex

DESCRIPTION

This command analyses the survey and creates a set of files:
  • A directory survey-data containing the answers.
  • A directory survey-img containing the images of the answers.
  • A directory survey-pdf containing the PDF files for the answers.
  • A directory survey-correction containing the correction files for the answers.
The options are applied in the same order as they appear in the command line.

--try-three | --no-try-three

If the three-valued mark recognition does not succeed, it tries to process it anyway.

--debug file.log

Specify the file for debug information.

الاسم

auto-multiple-choice-analyse - تحليل مسح.

الملخص

auto-multiple-choice-analyse [خيارات] survey.tex

الوصف

يقوم هذا الأمر بتحليل المسح وإنشاء مجموعة من الملفات:
  • دليل survey-data يحتوي على الإجابات.
  • دليل survey-img يحتوي على صور الإجابات.
  • دليل survey-pdf يحتوي على ملفات PDF للإجابات.
  • دليل survey-correction يحتوي على ملفات التصحيح للإجابات.
يتم تطبيق الخيارات بنفس الترتيب الذي تظهر به في سطر الأوامر.

--try-three | --no-try-three

إذا لم ينجح التعرف على العلامة ثلاثية القيم، فإنه يحاول معالجتها على أي حال.

--debug file.log

تحديد الملف لمعلومات التصحيح.
