audit_log_acct_message(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_LOG_ACCT_MESSAGE(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_LOG_ACCT_MESSAGE(3)

الاسم

audit_log_acct_message - تسجيل رسالة حساب مستخدم

الملخص

#include <libaudit.h>

int audit_log_acct_message(intaudit_fd,int"type,constchar*"pgname,constchar*"op,constchar*"name,unsignedint"id,constchar*"host,constchar*"addr,constchar*"tty,int"result);"

الوصف

تقوم هذه الوظيفة بتسجيل رسالة إلى نظام التدقيق باستخدام تنسيق رسالة محدد مسبقًا. يجب استخدامها لجميع عمليات معالجة الحسابات. معلمات الوظيفة هي كما يلي:

audit_fd - الواصف الملفي الذي تم إرجاعه بواسطة audit_open
type - نوع الرسالة: AUDIT_USER_CHAUTHTOK لتغيير أي سمات حساب.
pgname - اسم البرنامج، إذا كان NULL فسيحاول اكتشافه
op - العملية. مثال: "adding-user"، "changing-finger-info"، "deleting-group". يجب أن تحتوي هذه القيمة على شرطة أو شرطة سفلية بين الكلمات حتى تقوم محللات التقارير بتجميعها معًا.
name - اسم حساب المستخدم أو المجموعة. إذا لم يكن متاحًا استخدم NULL.
id - معرف المستخدم أو معرف المجموعة الذي يتم إجراء العملية عليه. إذا كان المستخدم غير معروف، قم بتمرير -1 واملأ معلمة الاسم. يستخدم هذا فقط عندما يكون المستخدم NULL.
host - اسم المضيف إذا كان معروفًا. إذا لم يكن متاحًا قم بتمرير NULL.
addr - عنوان الشبكة للمستخدم. إذا لم يكن متاحًا قم بتمرير NULL.
tty - جهاز tty للمستخدم، إذا كان NULL فسيحاول اكتشافه
result - 1 يعني "نجاح" و 0 يعني "فشل"

قيمة الإرجاع

تعيد رقم التسلسل الذي يكون > 0 عند النجاح أو <= 0 عند حدوث خطأ.

الأخطاء

تعيد هذه الوظيفة -1 عند الفشل. افحص errno لمزيد من المعلومات.

انظر أيضًا

audit_log_user_message(3)، audit_log_user_comm_message(3)، audit_log_user_avc_message(3)، audit_log_semanage_message(3).
