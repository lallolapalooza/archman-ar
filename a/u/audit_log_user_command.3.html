audit_log_user_command(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_LOG_USER_COMMAND(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_LOG_USER_COMMAND(3)

الاسم

audit_log_user_command - تسجيل أمر مستخدم

الملخص

#include <libaudit.h>

int audit_log_user_command(intaudit_fd,int"type,constchar*"command,constchar*"tty,int"result);"

الوصف

تقوم هذه الدالة بتسجيل أمر في نظام التدقيق باستخدام تنسيق رسالة محدد مسبقًا. تقوم بترميز الأمر كما يتوقعه نظام التدقيق للسلاسل النصية غير الموثوق بها. يجب أن تستخدم جميع التطبيقات التي تحتاج إلى تسجيل الأوامر هذه الدالة. معلمات الدالة هي كما يلي:

audit_fd - الـ fd الذي تم إرجاعه بواسطة audit_open
type - نوع الرسالة، مثال: AUDIT_USYS_CONFIG, AUDIT_USER_LOGIN
command - الأمر الذي يتم تسجيله
tty - الـ tty الخاص بالمستخدم، إذا كان NULL فستحاول الدالة اكتشافه
result - 1 يعني "نجاح" و 0 يعني "فشل"

قيمة الإرجاع

ترجع رقم التسلسل الذي يكون > 0 عند النجاح أو <= 0 عند الخطأ.

الأخطاء

ترجع هذه الدالة -1 عند الفشل. افحص errno لمزيد من المعلومات.
