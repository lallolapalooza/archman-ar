AUDIT_DELETE_RULE_DATA(3) واجهة برمجة تطبيقات تدقيق Linux AUDIT_DELETE_RULE_DATA(3)

الاسم

audit_delete_rule_data - حذف قاعدة تدقيق

ملخص

#include <libaudit.h>
int audit_delete_rule_data(int fd, struct audit_rule_data *rule, int flags, int action);"

الوصف

يُستخدم audit_delete_rule_data لحذف القواعد المحملة حاليًا في النواة. يتم توفير واصف الملف في fd ووصف القاعدة في rule. لحذف قاعدة، يجب عليك إعداد القواعد بشكل مطابق للقاعدة التي يتم حذفها. انظر audit_add_rule_data لتعريفات flags و action.

قيمة الإرجاع

القيمة المرجعة هي <= 0 عند حدوث خطأ، وإلا فإنها تكون رقم معرف تسلسل netlink. يمكن أن تواجه هذه الدالة أي خطأ قد تواجهه sendto.

انظر أيضًا

audit_add_rule_data(3)، auditctl(8).
