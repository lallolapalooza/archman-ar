Authen__SASL__Perl__EXTERNAL(3pm)

الحزمة: perl-authen-sasl

التراخيص: GPL, PerlArtistic

Authen::SASL::Perl::EXTERNAL(3) وثائق Perl التي ساهم بها المستخدم Authen::SASL::Perl::EXTERNAL(3)

الاسم

Authen::SASL::Perl::EXTERNAL - فئة المصادقة الخارجية

الإصدار

الإصدار 2.1900

ملخص

use Authen::SASL qw(Perl);
$sasl = Authen::SASL->new(
  mechanism => 'EXTERNAL',
  callback  => {
    user => $user
  },
);

الوصف

تقوم هذه الطريقة بتنفيذ الجزء الخاص بالعميل من خوارزمية SASL الخارجية، كما هو موضح في RFC 2222.
