الحزمة: aubio

التراخيص: GPL-3.0-or-later

NAME

aubioonset - detect onsets in audio signal

SYNOPSIS

aubioonset [-h] [-v] [-i] [-b] [-s] [-n] [-e] [-m method] [-t threshold] [-f output_format] [-o output_file] [--buf-size size] [--onset rate rate] [--no-fftw] [--float-bis] [--verbose] input_file...

DESCRIPTION

This command line tool can be used to detect onsets in an audio file. It uses the aubio library for the detection process.

The detected onsets are printed to the standard output, or to the specified output file.

The format of the output can be specified using the -f option. Supported formats are:

  • text: onset times in seconds, one per line.
  • midi: MIDI note on events, for use with e.g. ubiocut(1).
  • disc: onset detection function (ODF) values for debugging.

OPTIONS

-h, --help
Print a help message and exit.
-v, --version
Print version information and exit.
-i, --input input_file
Input audio file. Can be specified multiple times for multiple input files.
-o, --output output_file
Write output to output_file instead of stdout.
-f, --output-format output_format
Specify the output format. Supported values are: text, midi, disc. Default is text.
-m, --onset-method method
Choose the onset detection method. Available methods depend on the aubio library, but common ones include: complex, phase, hfc, energy, spectral, mkl.
-t, --onset-threshold threshold
Set the threshold for onset detection. This value is dependent on the chosen method and the input signal.
-s, --onset-silence silence
Set the silence threshold. Onsets are not detected in silence.
-n, --onset-delay delay
Set the delay for onset detection. This can be used to fine-tune the detection.
-e, --onset-min-duration duration
Set the minimum duration between two detected onsets.
--buf-size size
Set the buffer size for processing. Default is 1024.
--onset-rate rate
Set the expected onset rate (onsets per second). Default is 200.
--no-fftw
Disable the use of FFTW for faster Fourier transforms.
--float-bis
Use floating point representation for the Bis-onsets algorithm.
--verbose
Enable verbose output for debugging.

ONSET METHODS

The available onset detection methods are determined by the aubio library. Some common methods include:

complex
Onset detection based on the complex spectral domain.
phase
Onset detection based on phase variations.
hfc
Onset detection based on High Frequency Content.
energy
Onset detection based on energy changes.
spectral
Onset detection based on spectral flux.
mkl
Onset detection using the Multikernel Learning algorithm.

The effectiveness of each method can vary depending on the type of audio signal. Experimentation is recommended.
