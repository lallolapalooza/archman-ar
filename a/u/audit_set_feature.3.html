audit_set_feature(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_GET_FEATURES(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_GET_FEATURES(3)

الاسم

audit_get_features, audit_set_feature - الاستعلام أو تغيير ميزات تدقيق النواة

الملخص

#include <libaudit.h>

uint32_t audit_get_features(void);
int audit_set_feature(int fd, unsigned feature, unsigned value, unsigned lock);"

الوصف

audit_get_features() تعيد خريطة بت تصف ميزات تدقيق النواة المدعومة. يتم تخزين خريطة البت داخليًا ويتم استردادها من النواة عند أول استدعاء.

audit_set_feature() يغير بت ميزة للنواة باستخدام الواصف fd الذي يجب أن يكون مقبس شبكة تدقيق مفتوح. feature يحدد البت المراد تعديله. إذا كانت value غير صفرية، يتم تمكين الميزة، وإلا يتم تعطيلها. إذا كانت lock غير صفرية، يتم قفل إعداد الميزة حتى إعادة التشغيل.

بتات الميزات المعرفة حاليًا هي:

AUDIT_FEATURE_BITMAP_BACKLOG_LIMIT
النواة تدعم تغيير عمق قائمة الانتظار.
AUDIT_FEATURE_BITMAP_BACKLOG_WAIT_TIME
النواة تدعم تأخير استدعاءات النظام عندما تكون القائمة ممتلئة.
AUDIT_FEATURE_BITMAP_EXECUTABLE_PATH
ستتضمن النواة مسار الملف التنفيذي في سجلات EXECVE.
AUDIT_FEATURE_BITMAP_EXCLUDE_EXTEND
يمكن استخدام قواعد الاستثناء مع حقول أكثر من مجرد نوع الرسالة.
AUDIT_FEATURE_BITMAP_SESSIONID_FILTER
التصفية حسب معرف الجلسة مدعومة.
AUDIT_FEATURE_BITMAP_LOST_RESET
يسمح بإعادة تعيين عداد الأحداث المفقودة.
AUDIT_FEATURE_BITMAP_FILTER_FS
النواة تدعم تصفية حقل نظام الملفات.

قيمة الإرجاع

audit_get_features() تعيد خريطة الميزات أو 0 إذا كانت استعلامات الميزات غير مدعومة. audit_set_feature() تعيد <= 0 عند حدوث خطأ، وإلا فإنها تعيد رقم معرف تسلسل الشبكة.

انظر أيضاً

audit_request_features(3)، audit_reset_lost(3)، audit_open(3).
