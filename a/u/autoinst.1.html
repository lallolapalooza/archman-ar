NAME

autoinst - automate the installation of OpenType fonts for use with TeX

SYNOPSIS

autoinst [options] fontfile ...

DESCRIPTION

The autoinst script automates the process of preparing and installing OpenType fonts for use with TeX. It takes one or more OpenType font files (usually ending in .otf) as input and generates the necessary TeX font metric (.tfm), virtual font (.vf), map (.map), and LaTeX style files. It aims to make it as easy as possible to use OpenType fonts within a TeX document.

The generated files are placed in a subdirectory "./autoinst_output/" of the current directory. The user is responsible for moving these files to the appropriate locations in their TeX installation and updating the TeX filename database (e.g., by running texhash and updmap).

WARNINGS AND CAVEATS

  • autoinst relies on external tools such as otfinstgram, otfinfo, makeotfmerals, otftotfm, ps2pk, and potentially others. Ensure these are installed and accessible in your system's PATH.
  • The process of generating TeX support files for OpenType fonts can be complex. While autoinst automates much of this, some fonts may require manual adjustments or specific options.
  • Always back up your TeX installation before running any installation scripts that modify system files.
  • The default behavior assumes a standard TeX Live or MiKTeX installation. Users with custom configurations might need to adjust paths or use specific options.
  • Font name handling can be tricky. autoinst tries to follow standard conventions, but inconsistencies in font metadata might lead to unexpected results.

COMMAND-LINE OPTIONS

-verbose
Enable verbose output, showing the commands being executed.
-quiet
Suppress non-error messages.
-force
Overwrite existing generated files without prompting.
-target=TARGET
Specifies the type of TeX engine the generated files are intended for. Possible values include:
tex
(default) Generates files for traditional TeX engines (e.g., pdftex, dvips).
luatex
Generates files optimized for LuaTeX.
xetex
Generates files optimized for XeTeX.
-encoding=ENCODING
Specify the TeX encoding to use. If not provided, autoinst attempts to detect the best encoding from the font's metadata. Common encodings include T1, LY1, and OT1.
-t1suffix
Append a suffix to the generated T1 font filenames. This can be useful to avoid conflicts with existing T1 font files.
-vendor=VENDOR
Sets the vendor name used in the directory structure of the TEXMF tree. Defaults to "lcdftools".
-typeface=TYPEFACE
Sets the typeface name used in the directory structure of the TEXMF tree. Defaults to the font's family name.
-logfile=filename
Write log data to the specified filename instead of the default <fontfamily>.log. If the file exists, output is appended.
-manual
Manual mode. Instead of executing commands immediately, autoinst writes them to a script file (autoinst.bat by default). It also instructs otftotfm to generate human-readable pl/vpl files instead of tfm/vf files, and places all output in "./autoinst_output/". This mode is for users who want to inspect or modify the generated files and commands before installation. When using this option, you need to manually perform the following steps after autoinst finishes:
  1. Run pltotf and vptovf on the generated pl and vf files to convert them to tfm/vf format.
  2. Move all generated files to a proper TEXMF tree and update the filename database (e.g., run texhash).
  3. Tell TeX about the new map file (e.g., run updmap).
Note that some options (like -target, -vendor, and -typeface) are ignored in manual mode. Font name modification also does not occur in manual mode.
-defaultlining/-defaultoldstyle
Specifies the default figure style (lining or oldstyle) for the font. Use these only if the font doesn't provide OpenType features for its default figure style, and you need to override autoinst's default assumptions (which are usually correct).
-defaulttabular/-defaultproportional
Similar to the above, but specifies the default figure spacing (tabular or proportional).
-nfssweight=code=weight
Maps an NFSS weight code (e.g., 'm' for medium) to a specific font weight name (e.g., 'Regular'). Can be used multiple times. To disable a code, use an empty weight (e.g., "-nfssweight=ul=").
-nfsswidth=code=width
Maps an NFSS width code (e.g., 'm' for medium) to a specific font width name (e.g., 'Normal'). Can be used multiple times. To disable a code, use an empty width (e.g., "-nfsswidth=mc=").
-extra=extra options
Passes extra options directly to the underlying otftotfm command. Quote these options to prevent them from being interpreted by autoinst.
-nofigurekern
Suppresses kerning pairs for figures, which can interfere with alignment in tables. This option adds many --ligkern options to the otftotfm command and may cause issues on some systems, hence it is not enabled by default.

SEE ALSO

otfinstgram(1), otfinfo(1), otftotfm(1), makeotfmerals(1), texhash(1), updmap(1).

Eddie Kohler's TypeTools and T1Utils (http://www.lcdf.org/type).

Perl can be obtained from http://www.perl.org.

LuaTeX (http://www.luatex.org) and XeTeX (http://www.tug.org/xetex) are Unicode-aware TeX engines that can use OpenType fonts directly.

The FontPro project (https://github.com/sebschub/FontPro) offers LaTeX support for Adobe's Minion Pro, Myriad Pro and Cronos Pro font families.

RECENT CHANGES

(See the source code for a complete history.)

2025-01-07
Fixed a font metadata parsing issue affecting Libertinus Serif Display and potentially others, by applying a specific fix only for Source Serif 4.
2024-01-04
Improved font metadata parsing for better handling of unusual weight/width names. Added a warning if 'Regular' weight or width cannot be found.
2023-12-30
Bugfix: Font info parsing now works correctly for Junicode 2.
2023-09-14
Added "\up..." and "\it..." commands to the style file.
2023-06-28
Adapted font metadata parsing for Adobe Source Serif 4.
2023-02-01
Added support for T4, T5, CS, L7X, and QX encodings.
2023-01-31
If superior/inferior figures are present, the generated style file now redefines "\textsuperscript" and "\textsubscript", and patches LaTeX's footnote mechanism accordingly (inspired by the realscripts package). Fixed several bugs in metadata parsing, style file generation, and the "-t1suffix" option to ensure it works for dvips and dvipdfmx.
