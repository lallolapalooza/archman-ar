<\/dt>

SVCXPRT *svctcp_create(int sock, unsigned int send_buf_size,
                       unsigned int recv_buf_size);<\/pre>


  
<\/dt>
  
هذا الإجراء ينشئ نقل خدمة RPC مستند إلى TCP/IP، والذي يعيد مؤشرًا إليه. يرتبط النقل بالمقبس sock، والذي قد يكون RPC_ANYSOCK، وفي هذه الحالة يتم إنشاء مقبس جديد. إذا لم يكن المقبس مرتبطًا بمنفذ TCP محلي، فإن هذا الإجراء يرتبط به بمنفذ عشوائي. عند الانتهاء، xprt->xp_sock هو واصف مقبس النقل، و xprt->xp_port هو رقم منفذ النقل. يعيد هذا الإجراء NULL إذا فشل. نظرًا لأن RPC المستند إلى TCP يستخدم I/O المخزن مؤقتًا، يمكن للمستخدمين تحديد حجم المخازن المؤقتة؛ القيم الصفرية تختار قيمًا افتراضية مناسبة.<\/dd>
