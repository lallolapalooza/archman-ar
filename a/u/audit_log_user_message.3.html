audit_log_user_message(3)

الحزمة: audit

التراخيص: GPL-2.0-or-later, LGPL-2.0-or-later

AUDIT_LOG_USER_MESSAGE(3) واجهة برمجة تطبيقات تدقيق لينكس AUDIT_LOG_USER_MESSAGE(3)

الاسم

audit_log_user_message - تسجيل رسالة مستخدم عامة

ملخص

#include <libaudit.h>
int audit_log_user_message(int audit_fd, int type, const char *message, const char *hostname, const char *addr, const char *tty, int result)"

الوصف

تقوم هذه الدالة بتسجيل رسالة إلى نظام التدقيق باستخدام تنسيق رسالة محدد مسبقًا. يجب على جميع تطبيقات وحدة التحكم ELF التي لا تتعامل مع الحسابات أو المجموعات استخدام هذه الدالة. إذا كان التطبيق مكتوبًا بلغة بايثون أو مترجم آخر، فاستخدم الدالة audit_log_user_comm_message بدلاً من ذلك. تكون معاملات الدالة كما يلي:

audit_fd - الـ fd الذي تم إرجاعه بواسطة audit_open
type - نوع الرسالة، مثال: AUDIT_USYS_CONFIG, AUDIT_USER_LOGIN
message - نص الرسالة التي يتم إرسالها
hostname - اسم المضيف إذا كان معروفًا، NULL إذا كان غير معروف
addr - عنوان الشبكة للمستخدم، NULL إذا كان غير معروف
tty - الـ tty للمستخدم، إذا كان NULL ستحاول معرفته
result - 1 يعني "نجاح" و 0 يعني "فشل"

قيمة الإرجاع

تُرجع رقم التسلسل الذي يكون > 0 عند النجاح أو <= 0 عند الخطأ.

الأخطاء

تُرجع هذه الدالة -1 عند الفشل. افحص errno لمزيد من المعلومات.

انظر أيضًا

audit_log_user_comm_message(3), audit_log_acct_message(3), audit_log_user_avc_message(3), audit_log_semanage_message(3).
