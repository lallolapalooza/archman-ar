ALTER_AGGREGATE(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER AGGREGATE(7) توثيق PostgreSQL 18.1 ALTER AGGREGATE(7)

الاسم

ALTER AGGREGATE - تغيير تعريف دالة تجميعية

الملخص

ALTER AGGREGATE name ( aggregate_signature ) RENAME TO new_name
ALTER AGGREGATE name ( aggregate_signature )
                OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER AGGREGATE name ( aggregate_signature ) SET SCHEMA new_schema
where aggregate_signature is:
* |
[ argmode ] [ argname ] argtype [ , ... ] |
[ [ argmode ] [ argname ] argtype [ , ... ] ] ORDER BY [ argmode ] [ argname ] argtype [ , ... ]

الوصف

ALTER AGGREGATE يغير تعريف دالة تجميعية.

يجب أن تمتلك الدالة التجميعية لاستخدام ALTER AGGREGATE. لتغيير مخطط الدالة التجميعية، يجب أن يكون لديك أيضًا إذن CREATE في المخطط الجديد. لتغيير المالك، يجب أن تكون قادرًا على SET ROLE إلى الدور الجديد المالك، ويجب أن يمتلك هذا الدور إذن CREATE في مخطط الدالة التجميعية. (تفرض هذه القيود أن تغيير المالك لا يقوم بأي شيء لا يمكنك القيام به عن طريق إسقاط وإعادة إنشاء الدالة التجميعية. ومع ذلك، يمكن للمستخدم الخارق تغيير ملكية أي دالة تجميعية على أي حال.)

المعلمات

name

اسم (مؤهل اختياريًا بمخطط) لدالة تجميعية موجودة.

argmode

وضع الوسيط: IN أو VARIADIC. إذا تم حذفه، الافتراضي هو IN.

argname

اسم وسيط. لاحظ أن ALTER AGGREGATE لا يولى أي اهتمام فعلي لأسماء الوسائط، حيث أن أنواع بيانات الوسائط فقط هي المطلوبة لتحديد هوية الدالة التجميعية.

argtype

نوع بيانات مدخل تعمل عليه الدالة التجميعية. للإشارة إلى دالة تجميعية بدون وسائط، اكتب * بدلاً من قائمة مواصفات الوسائط. للإشارة إلى دالة تجميعية لمجموعة مرتبة، اكتب ORDER BY بين مواصفات الوسائط المباشرة والتجميعية.

new_name

الاسم الجديد للدالة التجميعية.

new_owner

المالك الجديد للدالة التجميعية.

new_schema

المخطط الجديد للدالة التجميعية.

ملاحظات

الصيغة الموصى بها للإشارة إلى دالة تجميعية لمجموعة مرتبة هي كتابة ORDER BY بين مواصفات الوسائط المباشرة والتجميعية، بنفس الأسلوب كما في CREATE AGGREGATE. ومع ذلك، سيعمل أيضًا حذف ORDER BY ودمج مواصفات الوسائط المباشرة والتجميعية في قائمة واحدة. في هذا الشكل المختصر، إذا تم استخدام VARIADIC "any" في كل من قوائم الوسائط المباشرة والتجميعية، فاكتب VARIADIC "any" مرة واحدة فقط.

أمثلة

لإعادة تسمية الدالة التجميعية myavg لنوع integer إلى my_average:

ALTER AGGREGATE myavg(integer) RENAME TO my_average;

لتغيير مالك الدالة التجميعية myavg لنوع integer إلى joe:

ALTER AGGREGATE myavg(integer) OWNER TO joe;

لنقل الدالة التجميعية لمجموعة مرتبة mypercentile مع وسيط مباشر من نوع float8 ووسيط مجمع من نوع integer إلى المخطط myschema:

ALTER AGGREGATE mypercentile(float8 ORDER BY integer) SET SCHEMA myschema;

سيعمل هذا أيضًا:

ALTER AGGREGATE mypercentile(float8, integer) SET SCHEMA myschema;

التوافق

لا توجد عبارة ALTER AGGREGATE في معيار SQL.

انظر أيضًا

CREATE AGGREGATE (CREATE_AGGREGATE(7)), DROP AGGREGATE (DROP_AGGREGATE(7))
