ALTER_STATISTICS(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER STATISTICS(7) توثيق PostgreSQL 18.1 ALTER STATISTICS(7)

الاسم

ALTER_STATISTICS - تغيير تعريف كائن الإحصائيات الموسعة

الملخص

ALTER STATISTICS name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER STATISTICS name RENAME TO new_name
ALTER STATISTICS name SET SCHEMA new_schema
ALTER STATISTICS name SET STATISTICS { new_target | DEFAULT }

الوصف

ALTER STATISTICS يغير معلمات كائن الإحصائيات الموسعة الموجود. أي معلمات لا يتم تعيينها بشكل خاص في أمر ALTER STATISTICS تحتفظ بإعداداتها السابقة.

يجب أن تكون مالك كائن الإحصائيات لاستخدام ALTER STATISTICS. لتغيير مخطط كائن الإحصائيات، يجب أن يكون لديك أيضًا إذن CREATE في المخطط الجديد. لتغيير المالك، يجب أن تكون قادرًا على SET ROLE إلى الدور المالك الجديد، ويجب أن يكون لهذا الدور إذن CREATE في مخطط كائن الإحصائيات. (تفرض هذه القيود أن تغيير المالك لا يفعل شيئًا لا يمكنك فعله عن طريق إسقاط وإعادة إنشاء كائن الإحصائيات. ومع ذلك، يمكن لمستخدم خارق تغيير ملكية أي كائن إحصائيات على أي حال.)

المعلمات

name

الاسم (اختياريًا مؤهل بالمخطط) لكائن الإحصائيات المراد تغييره.

new_owner

اسم المستخدم للمالك الجديد لكائن الإحصائيات.

new_name

الاسم الجديد لكائن الإحصائيات.

new_schema

المخطط الجديد لكائن الإحصائيات.

new_target

هدف جمع الإحصائيات لهذا الكائن الإحصائي لعمليات ANALYZE اللاحقة. يمكن تعيين الهدف في النطاق من 0 إلى 10000. قم بتعيينه إلى DEFAULT للعودة إلى استخدام هدف الإحصائيات الافتراضي للنظام (default_statistics_target). (تعيين قيمة -1 هو طريقة قديمة لكتابة لتحقيق نفس النتيجة.) لمزيد من المعلومات حول استخدام الإحصائيات بواسطة مخطط استعلام PostgreSQL، ارجع إلى القسم 14.2.

التوافق

لا يوجد أمر ALTER STATISTICS في معيار SQL.

انظر أيضا

CREATE STATISTICS (CREATE_STATISTICS(7))، DROP STATISTICS (DROP_STATISTICS(7))
