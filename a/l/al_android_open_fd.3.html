الاسم

al_android_open_fd - واجهة برمجة تطبيقات Allegro 5

الملخص

#include <allegro5/allegro_android.h>
int al_android_open_fd(const char *uri, const char *mode)

الوصف

يفتح واصف ملف للوصول إلى البيانات تحت معرف مورد موحد (URI). تقبل هذه الدالة مخططات URI content:// و file://. أنت مسؤول عن إغلاق واصف الملف المُعاد.

يمكن أن يكون mode للملف "r"، "w"، "rw"، "wt"، "wa" أو "rwt". يختلف التنفيذ الدقيق لهذه الأوضاع اعتمادًا على مزود المحتوى الأساسي. على سبيل المثال، قد يؤدي "w" إلى اقتطاع الملف أو قد لا يؤدي.

يعيد واصف ملف عند النجاح أو قيمة سالبة عند حدوث خطأ. عند حدوث خطأ، يتم تعيين errno الخاص بـ Allegro.

ملاحظة: تذكر إضافة الأذونات ذات الصلة بتطبيقك إلى ملف البيان.

مثال:

const char *content_uri = "content://...";
int fd = al_android_open_fd(content_uri, "r");
if (fd >= 0) {
    ALLEGRO_FILE *f = al_fopen_fd(fd, "r");
    if (f != NULL) {
        do_something_with(f);
        al_fclose(f);
    }
    else {
        handle_error(al_get_errno());
        close(fd);
    }
}
else {
    handle_error(al_get_errno());
}
