al_draw_indexed_buffer(3)

al_draw_indexed_buffer(3) دليل وظائف المكتبة al_draw_indexed_buffer(3)

الاسم

al_draw_indexed_buffer - واجهة برمجة تطبيقات Allegro 5

الملخص

#include <allegro5/allegro_primitives.h>
int al_draw_indexed_buffer(ALLEGRO_VERTEX_BUFFER* vertex_buffer,
   ALLEGRO_BITMAP* texture, ALLEGRO_INDEX_BUFFER* index_buffer,
   int start, int end, int type)

الوصف

يرسم مجموعة فرعية من مخزن الرؤوس الممرر. تستخدم هذه الدالة مخزن فهارس لتحديد الرؤوس التي سيتم استخدامها. يجب ألا يكون كلا المخزنين مقفلين. بالإضافة إلى ذلك، للرسم على صور نقطية في الذاكرة أو باستخدام صور نقطية في الذاكرة كنسيج، يجب أن يدعم كلا المخزنين القراءة (أي أنه يجب إنشاؤهما باستخدام ALLEGRO_PRIM_BUFFER_READWRITE).

المعاملات:

•
vertex_buffer - مخزن الرؤوس للرسم
•
texture - النسيج المراد استخدامه، قم بتمرير NULL لاستخدام الأشكال الأولية المظللة بالألوان فقط
•
index_buffer - مخزن الفهارس المراد استخدامه
•
start - فهرس البداية لمجموعة الفهارس في مخزن الفهارس المراد رسمها
•
end - الفهرس الذي يلي آخر فهرس للمجموعة الفرعية من مخزن الفهارس المراد رسمها
•
type - عضو في تعداد ALLEGRO_PRIM_TYPE(3)، يحدد نوع الشكل الأولي المراد رسمه. لاحظ أن ALLEGRO_PRIM_LINE_LOOP و ALLEGRO_PRIM_POINT_LIST غير مدعومين.

الإرجاع: عدد الأشكال الأولية المرسومة
