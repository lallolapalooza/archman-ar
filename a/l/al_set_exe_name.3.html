الاسم

al_set_exe_name - Allegro 5 API

ملخص

#include <allegro5/allegro.h>
void al_set_exe_name(char const *path)

الوصف

هذه الدالة تتجاوز اسم الملف التنفيذي المستخدم بواسطة al_get_standard_path(3) لـ ALLEGRO_EXENAME_PATH و ALLEGRO_RESOURCES_PATH.

أحد الاحتمالات التي يمكن أن يكون فيها تغيير هذا مفيدًا هو إذا كنت تستخدم الواجهة التغليفية لـ Python. سيعتقد Allegro افتراضيًا أن الملف التنفيذي لـ Python في النظام هو الملف التنفيذي الحالي - ولكن يمكنك تعيينه إلى ملف .py الذي يتم تنفيذه بدلاً من ذلك.

منذ

5.0.6, 5.1.0
