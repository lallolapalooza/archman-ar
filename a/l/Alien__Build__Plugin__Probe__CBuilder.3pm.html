Alien__Build__Plugin__Probe__CBuilder(3pm)

الحزمة: perl-alien-build

التراخيص: PerlArtistic

Alien::Build::Plugin::Probe::CBuilder(3) وثائق Perl المساهمة من المستخدم Alien::Build::Plugin::Probe::CBuilder(3)

الاسم

Alien::Build::Plugin::Probe::CBuilder - يتحسس المكتبات النظامية عن طريق التخمين باستخدام ExtUtils::CBuilder

الإصدار

الإصدار 2.84

الملخص

use alienfile;
plugin 'Probe::CBuilder' => (
  cflags => '-I/opt/libfoo/include',
  libs   => '-L/opt/libfoo/lib -lfoo',
);

بدلاً من ذلك:

ues alienfile;
plugin 'Probe::CBuilder' => (
  aliens => [ 'Alien::libfoo', 'Alien::libbar' ],
);

الوصف

يقوم هذا المكون الإضافي بالتحسس لعلامات المترجم والربط باستخدام ExtUtils::CBuilder. هذا بديل مفيد لـ Alien::Build::Plugin::PkgConfig::Negotiate للحزم التي لا توفر ملف ".pc" لـ pkg-config، أو للحالات التي قد لا تكون فيها ملفات ".pc" هذه متاحة. (على سبيل المثال، في FreeBSD، libarchive جزء أساسي من نظام التشغيل، ولكنه لا يتضمن ملف ".pc" الذي يتم توفيره عادةً عند تثبيت حزمة libarchive على Linux).

الخصائص

options

أي خيارات إضافية تريد تمريرها إلى المنشئ لـ ExtUtils::CBuilder.

cflags

علامات المترجم.

libs

علامات الربط

program

البرنامج المراد استخدامه في الاختبار.

version

هذا تعبير عادي لتحليل الإصدار من خرج برنامج الاختبار.

atleast_version

الحد الأدنى للإصدار المطلوب كما يقدمه النظام.

aliens

قائمة الكائنات الفضائية (aliens) للاستعلام عن علامات المترجم والربط.

lang

لغة البرمجة المستخدمة. إما "C" أو "C++".
