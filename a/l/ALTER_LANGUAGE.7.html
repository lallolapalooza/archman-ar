ALTER_LANGUAGE(7)

الحزمة: postgresql

ALTER LANGUAGE(7) توثيق PostgreSQL 18.1 ALTER LANGUAGE(7)

الاسم

ALTER_LANGUAGE - تغيير تعريف لغة إجرائية

ملخص

ALTER [ PROCEDURAL ] LANGUAGE name RENAME TO new_name
ALTER [ PROCEDURAL ] LANGUAGE name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

الوصف

ALTER LANGUAGE يغير تعريف لغة إجرائية. الوظيفة الوحيدة هي إعادة تسمية اللغة أو تعيين مالك جديد. يجب أن تكون مستخدمًا خارقًا أو مالكًا للغة لاستخدام ALTER LANGUAGE.

المعلمات

name

اسم لغة

new_name

الاسم الجديد للغة

new_owner

المالك الجديد للغة

التوافق

لا يوجد أمر ALTER LANGUAGE في معيار SQL.

انظر أيضًا

CREATE LANGUAGE (CREATE_LANGUAGE(7))، DROP LANGUAGE (DROP_LANGUAGE(7))
