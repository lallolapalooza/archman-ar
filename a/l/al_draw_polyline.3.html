al_draw_polyline(3)

الحزمة: allegro

التراخيص: Zlib, BSD-3-Clause, OFL-1.1, LicenseRef-Custom

al_draw_polyline(3) دليل وظائف المكتبة al_draw_polyline(3)

الاسم

al_draw_polyline - واجهة برمجة تطبيقات Allegro 5

الملخص

#include <allegro5/allegro_primitives.h>
void al_draw_polyline(const float* vertices, int vertex_stride,
   int vertex_count, int join_style, int cap_style,
   ALLEGRO_COLOR color, float thickness, float miter_limit)

الوصف

ارسم سلسلة من مقاطع الخطوط.

•
vertices - مصفوفة متداخلة لإحداثيات رؤوس (x, y)
•
vertex_stride - عدد البايتات بين أزواج الرؤوس (الخطوة)
•
vertex_count - عدد الرؤوس في المصفوفة
•
join_style - عضو في ALLEGRO_LINE_JOIN(3) يحدد كيفية عرض الوصلات بين مقاطع الخطوط
•
cap_style - عضو في ALLEGRO_LINE_CAP(3) يحدد كيفية عرض نهايات الخطوط
•
color - لون الخط
•
thickness - سماكة الخط، مرر <= 0 لرسم خطوط رفيعة
•
miter_limit - معامل لنمط الوصلات المتينة

عادة ما تكون الخطوة 2 * sizeof(float) ولكن قد تكون أكثر إذا كانت إحداثيات الرؤوس في مصفوفة من نوع هيكل معين، على سبيل المثال:

struct VertexInfo {
   float x;
   float y;
   int id;
};
void my_draw(struct VertexInfo verts[], int vertex_count, ALLEGRO_COLOR c)
{
   al_draw_polyline((float *)verts, sizeof(VertexInfo), vertex_count,
      ALLEGRO_LINE_JOIN_NONE, ALLEGRO_LINE_CAP_NONE, c, 1.0, 1.0);
}

قد تكون الخطوة أيضًا سالبة إذا كانت الرؤوس مخزنة بترتيب عكسي.
