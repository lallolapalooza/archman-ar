ALTER_LARGE_OBJECT(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER LARGE OBJECT(7) توثيق PostgreSQL 18.1 ALTER LARGE OBJECT(7)

الاسم

ALTER_LARGE_OBJECT - تغيير تعريف كائن كبير

الملخص

ALTER LARGE OBJECT large_object_oid OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }

الوصف

ALTER LARGE OBJECT يغير تعريف كائن كبير.

يجب أن تمتلك الكائن الكبير لاستخدام ALTER LARGE OBJECT. لتغيير المالك، يجب عليك أيضًا أن تكون قادرًا على SET ROLE للدور المالك الجديد. (ومع ذلك، يمكن لمستخدم خارق تغيير أي كائن كبير على أي حال.) حاليًا، الوظيفة الوحيدة هي تعيين مالك جديد، لذا فإن كلا القيدين ينطبقان دائمًا.

المعلمات

large_object_oid

معرف الكائن الكبير المراد تغييره

new_owner

المالك الجديد للكائن الكبير

التوافق

لا يوجد بيان ALTER LARGE OBJECT في معيار SQL.
