ALTER_TEXT_SEARCH_DICTIONARY(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER TEXT SEARCH DICTIONARY(7) توثيق PostgreSQL 18.1 ALTER TEXT SEARCH DICTIONARY(7)

الاسم

ALTER_TEXT_SEARCH_DICTIONARY - تغيير تعريف قاموس البحث النصي

الملخص

ALTER TEXT SEARCH DICTIONARY name (
    option [ = value ] [, ... ]
)
ALTER TEXT SEARCH DICTIONARY name RENAME TO new_name
ALTER TEXT SEARCH DICTIONARY name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER TEXT SEARCH DICTIONARY name SET SCHEMA new_schema

الوصف

ALTER TEXT SEARCH DICTIONARY يغير تعريف قاموس البحث النصي. يمكنك تغيير خيارات القاموس الخاصة بالقالب، أو تغيير اسم القاموس أو مالكه.

يجب أن تكون مالك القاموس لاستخدام ALTER TEXT SEARCH DICTIONARY.

المعاملات

name

الاسم (يمكن أن يسبقه اسم مخطط) لقاموس بحث نصي موجود.

option

اسم خيار خاص بالقالب ليتم تعيينه لهذا القاموس.

value

القيمة الجديدة للاستخدام لخيار خاص بالقالب. إذا تم حذف علامة المساواة والقيمة، فسيتم إزالة أي إعداد سابق للخيار من القاموس، مما يسمح باستخدام القيمة الافتراضية.

new_name

الاسم الجديد لقاموس البحث النصي.

new_owner

المالك الجديد لقاموس البحث النصي.

new_schema

المخطط الجديد لقاموس البحث النصي.

يمكن ظهور الخيارات الخاصة بالقالب بأي ترتيب.

أمثلة

يقوم الأمر التالي بتغيير قائمة الكلمات المتوقفة لقاموس يعتمد على Snowball. تظل المعاملات الأخرى دون تغيير.

ALTER TEXT SEARCH DICTIONARY my_dict ( StopWords = newrussian );

يقوم الأمر التالي بتغيير الخيار إلى اللغة الهولندية، ويزيل خيار الكلمات المتوقفة بالكامل.

ALTER TEXT SEARCH DICTIONARY my_dict ( language = dutch, StopWords );

يقوم الأمر التالي "بتحديث" تعريف القاموس دون تغيير أي شيء فعليًا.

ALTER TEXT SEARCH DICTIONARY my_dict ( dummy );

(السبب في أن هذا يعمل هو أن كود إزالة الخيار لا يشتكي إذا لم يكن هناك مثل هذا الخيار.) هذه الحيلة مفيدة عند تغيير ملفات التكوين للقاموس: سيجبر الأمر ALTER جلسات قاعدة البيانات الحالية على إعادة قراءة ملفات التكوين، وهو ما لن تفعله أبدًا بخلاف ذلك إذا كانت قد قرأتها سابقًا.

التوافق

لا يوجد بيان ALTER TEXT SEARCH DICTIONARY في معيار SQL.

انظر أيضًا

CREATE TEXT SEARCH DICTIONARY (CREATE_TEXT_SEARCH_DICTIONARY(7))، DROP TEXT SEARCH DICTIONARY (DROP_TEXT_SEARCH_DICTIONARY(7))
