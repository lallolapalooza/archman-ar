ALTER_EVENT_TRIGGER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER EVENT TRIGGER(7) وثائق PostgreSQL 18.1 ALTER EVENT TRIGGER(7)

الاسم

ALTER_EVENT_TRIGGER - تغيير تعريف مشغل حدث

الملخص

ALTER EVENT TRIGGER name DISABLE
ALTER EVENT TRIGGER name ENABLE [ REPLICA | ALWAYS ]
ALTER EVENT TRIGGER name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER EVENT TRIGGER name RENAME TO new_name

الوصف

ALTER EVENT TRIGGER يغير خصائص مشغل حدث موجود.

يجب أن تكون مستخدمًا خارقًا لتغيير مشغل حدث.

المعلمات

name

اسم المشغل الحالي المراد تغييره.

new_owner

اسم المستخدم للمالك الجديد لمشغل الحدث.

new_name

الاسم الجديد لمشغل الحدث.

DISABLE/ENABLE [ REPLICA | ALWAYS ]

تُشكل هذه الصيغ تشغيل مشغلات الأحداث. المشغل المعطل لا يزال معروفًا للنظام، ولكنه لا يُنفذ عند حدوث الحدث الذي يشغله. انظر أيضًا session_replication_role.

التوافق

لا يوجد بيان ALTER EVENT TRIGGER في معيار SQL.

انظر أيضًا

CREATE EVENT TRIGGER (CREATE_EVENT_TRIGGER(7)), DROP EVENT TRIGGER (DROP_EVENT_TRIGGER(7))
