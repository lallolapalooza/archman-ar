alpm-buildinfo-create-v1(1)

الحزمة: alpm-buildinfo

التراخيص: Apache-2.0 OR MIT, CC-BY-SA-4.0

alpm-buildinfo-create-v1(1) دليل الأوامر العامة alpm-buildinfo-create-v1(1)

الاسم

alpm-buildinfo-create-v1 - إنشاء ملف BUILDINFO الإصدار 1

الموجز

alpm-buildinfo create v1 <--builddate> <--builddir> [--buildenv] [--installed] [--options] <--packager> <--pkgarch> <--pkgbase> <--pkgbuild-sha256sum> <--pkgname> <--pkgver> [-h|--help] [FILE]

الوصف

إنشاء ملف BUILDINFO الإصدار 1

خيارات

--builddate <BUILDDATE>
توفير تاريخ بناء
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_BUILDDATE.
--builddir <BUILDDIR>
توفير دليل بناء
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_BUILDDIR.
--buildenv <BUILDENV>
توفير بيئة بناء واحدة أو أكثر
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_BUILDENV.
--installed <INSTALLED>
توفير مكون مثبت واحد أو أكثر
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_INSTALLED.
--options <OPTIONS>
توفير خيار واحد أو أكثر
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_OPTIONS.
--packager <PACKAGER>
توفير جهة التعبئة
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_PACKAGER.
--pkgarch <PKGARCH>
توفير بنية الحزمة
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_PKGARCH.
--pkgbase <PKGBASE>
توفير اسم أساس الحزمة
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_PKGBASE.
--pkgbuild-sha256sum <PKGBUILD_SHA256SUM>
توفير مجموع checksum SHA256 لملف PKGBUILD
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_PKGBUILD_SHA256SUM.
--pkgname <PKGNAME>
توفير اسم الحزمة
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_PKGNAME.
--pkgver <PKGVER>
توفير إصدار الحزمة
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_PKGVER.
-h, --help
طباعة المساعدة
[FILE] [افتراضي: .BUILDINFO]
توفير ملف للكتابة إليه
يمكن تحديده أيضًا باستخدام متغير البيئة BUILDINFO_OUTPUT_FILE.
