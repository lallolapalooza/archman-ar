Alien__Build__Plugin__Prefer__BadVersion(3pm)

الحزمة: perl-alien-build

التراخيص: PerlArtistic

Alien::Build::Plugin::Prefer::BadVersion(3) توثيق Perl مساهمة من المستخدم Alien::Build::Plugin::Prefer::BadVersion(3)

الاسم

Alien::Build::Plugin::Prefer::BadVersion - مكون إضافي لتصفية الإصدارات المعروفة السيئة

الإصدار

الإصدار 2.84

الملخص

use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3';

الوصف

يسمح لك هذا المكون الإضافي بتصفية الإصدارات المعروفة السيئة للمكتبات في التثبيت المشترك بسهولة. لا يؤثر على تثبيت النظام على الإطلاق. تحتاج إلى مكون إضافي Prefer يقوم بتصفية وفرز الملفات أولاً. يمكنك تحديد الفلتر بإحدى الطرق الثلاث:

كسلسلة نصية
تصفية أي ملفات تطابق الإصدار المحدد. 
use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3';
كمصفوفة
تصفية جميع الملفات التي تطابق أيًا من الإصدارات المحددة. 
use alienfile;
plugin 'Prefer::BadVersion' => [ '1.2.3', '1.2.4' ];
كمرجع دالة (code reference)
تصفية أي ملفات تعيد قيمة صحيحة. 
use alienfile;
plugin 'Prefer::BadVersion' => sub {
  my($file) = @_;
  $file->{version} eq '1.2.3'; # نفس الإصدار النصي أعلاه
};

يمكن أيضًا استخدام هذا المكون الإضافي لتصفية الإصدارات السيئة المعروفة لمكتبة معينة على منصة واحدة فقط. على سبيل المثال، إذا كنت تعلم أن الإصدار 1.2.3 سيء على نظام ويندوز، ولكنه مقبول على المنصات الأخرى:

use alienfile;
plugin 'Prefer::BadVersion' => '1.2.3' if $^O eq 'MSWin32';

الخصائص

filter

تصفية الإدخالات التي تطابق المرشح.

تنبيهات

إذا كنت تستخدم وضع السلسلة النصية أو المصفوفة، فأنت بحاجة إلى مكون إضافي Prefer موجود يحدد رقم الإصدار لكل مرشح ملف، مثل Alien::Build::Plugin::Prefer::SortVersions.

ما لم تكن تريد استبعاد أحدث إصدار من تثبيت مشترك، فإن هذا المكون الإضافي ليس مفيدًا حقًا. ليس له أي تأثير على تثبيتات النظام، وهو ما قد لا يكون واضحًا في البداية.
