الاسم

alsatplg - مترجم طوبولوجيا ALSA

ملخص

alsatplg <خيارات> [أمر]

الوصف

alsatplg (مترجم طوبولوجيا ALSA) هو برنامج لترجمة ملف تكوين الطوبولوجيا إلى ملف ثنائي لبرامج تشغيل النواة.

تقوم برامج تشغيل الصوت الحالية عادةً بتضمين معلومات الطوبولوجيا في مصادر برنامج التشغيل: وهذا يربط برنامج تشغيل الصوت بإحكام بلوحة التطوير، مما يجعل تعديل برنامج التشغيل للعمل على أجهزة مختلفة يستغرق وقتًا طويلاً. يرتبط برنامج التشغيل أيضًا ارتباطًا وثيقًا بإصدار البرنامج الثابت DSP، مما يعني أن الأمر يتطلب عناية إضافية للحفاظ على تزامن إصدار برنامج التشغيل والبرنامج الثابت. تتطلب ميزات البرنامج الثابت الجديدة أيضًا تحديثات لبرنامج التشغيل.

مشروع طوبولوجيا ALSA يلغي الحاجة إلى إعادة كتابة أو نقل برامج تشغيل الصوت إلى أجهزة مختلفة أو برامج ثابتة مختلفة: لا تحتوي برامج التشغيل على بيانات طوبولوجيا مضمنة، مما يعني أنه يمكن استخدام برنامج تشغيل واحد على أجهزة مختلفة عن طريق تحديث بيانات الطوبولوجيا من نظام الملفات. يمكن دفع تحديثات البرنامج الثابت دون الحاجة إلى تحديث برامج التشغيل. يحتاج البرنامج الثابت الجديد فقط إلى تضمين ملف طوبولوجيا محدث يصف التحديث.

خيارات

الخيارات المتاحة:

-h, --help
هذه المساعدة
-V, --version
عرض إصدار الأداة وإصدارات المكتبات المستخدمة
-c, --compile FILE
ملف تكوين المصدر للترجمة
-d, --decode FILE
ملف طوبولوجيا ثنائي المصدر لفك الترميز
-n, --normalize FILE
تحليل وحفظ ملف التكوين بالتنسيق المعياري
-u, --dump FILE
تحليل وحفظ ملف التكوين بالتنسيق المحدد
-o, --output FILE
ملف الإخراج
-v, --verbose LEVEL
تعيين مستوى التفصيل
-s, --sort
فرز معرفات التكوين (مجموعة للتطبيع)
-x, --nocheck
حفظ التكوين بدون فحص تكامل إضافي
-z, --dapm-nosort
لا تفرز عناصر رسم بياني DAPM (كما في الإصدار 1.2.1-)

الملفات

ملفات الطوبولوجيا الرئيسية لكل بطاقة صوت مدعومة موجودة في /usr/share/alsa/topology.

على سبيل المثال، ملف حالة الاستخدام الرئيسي لبطاقة broadwell موجود في /usr/share/alsa/topology/broadwell/broadwell.conf، هذا الملف يصف أجهزة الصوت لبرنامج التشغيل.

لمزيد من التفاصيل حول بناء جملة ملفات UCM، راجع الكود المصدري لـ alsa-lib:
http://git.alsa-project.org/?p=alsa-lib.git;a=blob;f=src/topology/parser.c
