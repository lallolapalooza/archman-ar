ALTER_SERVER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER SERVER(7) توثيق PostgreSQL 18.1 ALTER SERVER(7)

الاسم

ALTER SERVER - تغيير تعريف خادم خارجي

الملخص

ALTER SERVER name [ VERSION 'new_version' ]
    [ OPTIONS ( [ ADD | SET | DROP ] option ['value'] [, ... ] ) ]
ALTER SERVER name OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER SERVER name RENAME TO new_name

الوصف

يقوم الأمر ALTER SERVER بتغيير تعريف خادم خارجي. الشكل الأول يغير سلسلة إصدار الخادم أو الخيارات العامة للخادم (يجب تحديد عبارة واحدة على الأقل). الشكل الثاني يغير مالك الخادم.

لتغيير الخادم، يجب أن تكون مالك الخادم. بالإضافة إلى تغيير المالك، يجب أن تكون قادرًا على تعيين الدور (SET ROLE) إلى الدور الجديد المالك، ويجب أن يكون لديك امتياز الاستخدام (USAGE privilege) على مغلف البيانات الخارجية للخادم. (لاحظ أن المستخدمين الخارقين يلبون جميع هذه المعايير تلقائيًا).

المعلمات

name

اسم الخادم الموجود.

new_version

إصدار الخادم الجديد.

OPTIONS ( [ ADD | SET | DROP ] option ['value'] [, ... ] )

تغيير خيارات الخادم. تحدد ADD و SET و DROP الإجراء المراد تنفيذه. يُفترض ADD إذا لم يتم تحديد عملية بشكل صريح. يجب أن تكون أسماء الخيارات فريدة؛ كما يتم التحقق من الأسماء والقيم باستخدام مكتبة مغلف البيانات الخارجية للخادم.

new_owner

اسم المستخدم للمالك الجديد للخادم الخارجي.

new_name

الاسم الجديد للخادم الخارجي.

أمثلة

تغيير الخادم foo، إضافة خيارات الاتصال:

ALTER SERVER foo OPTIONS (host 'foo', dbname 'foodb');

تغيير الخادم foo، تغيير الإصدار، تغيير خيار المضيف:

ALTER SERVER foo VERSION '8.4' OPTIONS (SET host 'baz');

التوافق

يتوافق الأمر ALTER SERVER مع ISO/IEC 9075-9 (SQL/MED). الأوامر OWNER TO و RENAME هي امتدادات PostgreSQL.

انظر أيضًا

CREATE SERVER (CREATE_SERVER(7)), DROP SERVER (DROP_SERVER(7))
