Alien__Build__Plugin__Download__GitLab(3pm)

التراخيص: PerlArtistic

Alien::Build::Plugin::Download::GitLab(3) وثائق مساهمات المستخدم في Perl Alien::Build::Plugin::Download::GitLab(3)

الاسم

Alien::Build::Plugin::Download::GitLab - إضافة Alien::Build لتنزيل من GitLab

الإصدار

الإصدار 0.01

الملخص

use alienfile;

plugin 'Download::GitLab' => (
  gitlab_user    => 'plicease',
  gitlab_project => 'dontpanic',
);

الوصف

تم تصميم هذه الإضافة لتنزيل الأصول من مثيل GitLab.

الخصائص

gitlab_host

المضيف الذي سيتم جلبه منه، وهو https://gitlab.com افتراضيًا.

gitlab_user

المستخدم الذي سيتم جلبه منه.

gitlab_project

المشروع الذي سيتم جلبه منه.

type

نوع الأصل المطلوب جلبه. يجب أن يكون أحد الخيارات التالية: "source" أو "link".

format

التنسيق المتوقع للأصل. يجب أن يكون تنسيقًا يفهمه Alien::Build::Plugin::Extract::Negotiate. الافتراضي هو "tar.gz".

version_from

من أين يتم حساب الإصدار. يجب أن يكون أحد الخيارات التالية: "tag_name" أو "name". الافتراضي هو "tag_name".

convert_version

هذا مرجع برمجي اختياري، يمكن استخدامه لتعديل الإصدار. على سبيل المثال، إذا كانت العلامات تحتوي على بادئة "v"، يمكنك إزالتها كما يلي:

plugin 'Download::GitLab' => (
  gitlab_user     => 'plicease',
  gitlab_project  => 'dontpanic',
  convert_version => sub {
    my $version = shift;
    $version =~ s/^v//;
    return $version;
  },
);

link_name

بالنسبة لأنواع "link"، هذا هو تعبير عادي يقوم بتصفية أسماء ملفات الأصول. على سبيل المثال، إذا كانت هناك تنسيقات أرشيف متعددة متاحة، يمكنك الحصول على ملف tarball المضغوط فقط عن طريق تعيين هذا إلى "qr/\.tar\.gz$/".
