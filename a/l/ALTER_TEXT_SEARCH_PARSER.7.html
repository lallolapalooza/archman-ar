ALTER_TEXT_SEARCH_PARSER(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER TEXT SEARCH PARSER(7) وثائق PostgreSQL 18.1 ALTER TEXT SEARCH PARSER(7)

الاسم

ALTER_TEXT_SEARCH_PARSER — تغيير تعريف محلل البحث النصي

الملخص

ALTER TEXT SEARCH PARSER name RENAME TO new_name
ALTER TEXT SEARCH PARSER name SET SCHEMA new_schema

الوصف

ALTER TEXT SEARCH PARSER يغير تعريف محلل البحث النصي. حالياً، الوظيفة الوحيدة المدعومة هي تغيير اسم المحلل.

يجب أن تكون مستخدمًا فائقًا لاستخدام ALTER TEXT SEARCH PARSER.

المعلمات

name

اسم (يمكن تحديد المخطط له اختياريًا) محلل بحث نصي موجود.

new_name

الاسم الجديد لمحلل البحث النصي.

new_schema

المخطط الجديد لمحلل البحث النصي.

التوافق

لا توجد عبارة ALTER TEXT SEARCH PARSER في معيار SQL.

انظر أيضاً

CREATE TEXT SEARCH PARSER (CREATE_TEXT_SEARCH_PARSER(7)), DROP TEXT SEARCH PARSER (DROP_TEXT_SEARCH_PARSER(7))
