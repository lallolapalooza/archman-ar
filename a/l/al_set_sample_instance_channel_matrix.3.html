al_set_sample_instance_channel_matrix(3)

الحزمة: allegro

التراخيص: Zlib, BSD-3-Clause, OFL-1.1, LicenseRef-Custom

al_set_sample_instance_channel_matrix(3) Library Functions Manual al_set_sample_instance_channel_matrix(3)

الاسم

al_set_sample_instance_channel_matrix - واجهة برمجة تطبيقات Allegro 5

ملخص

#include <allegro5/allegro_audio.h>
bool al_set_sample_instance_channel_matrix(ALLEGRO_SAMPLE_INSTANCE *spl, const float *matrix)

الوصف

اضبط المصفوفة المستخدمة لخلط القنوات القادمة من هذا المثيل في الخلاط المرفق به. عادةً ما يستنتج Allegro قيم هذه المصفوفة من إعدادات الكسب والتحريك، بالإضافة إلى تكوينات القنوات لهذا المثيل والخلاط المرفق به، لكن هذا يسمح لك بتجاوز تلك القيمة الافتراضية. لاحظ أنه إذا قمت بتعيين الكسب أو التحريك لهذا المثيل أو الخلاط المرفق به، فستحتاج إلى استدعاء هذه الدالة مرة أخرى.

تحتوي المصفوفة على صفوف قنوات الخلاط وأعمدة قنوات العينة، وهي بترتيب الصفوف. على سبيل المثال، إذا كان لديك مثيل عينة ستيريو وتريد خلطه في خلاط 5.1 يمكنك استخدام هذا الكود:

float matrix[] = {
    0.5, 0.0, /* نصف اليسار إلى الأمام الأيسر */
    0.0, 0.5, /* نصف اليمين إلى الأمام الأيمن */
    0.5, 0.0, /* نصف اليسار إلى الخلف الأيسر */
    0.0, 0.5, /* نصف اليمين إلى الخلف الأيمن */
    0.1, 0.1, /* خلط اليسار واليمين للمركز */
    0.1, 0.1, /* خلط اليسار واليمين للمركز */
};
al_set_sample_instance_channel_matrix(instance, matrix);

تُرجع true عند النجاح، وfalse عند الفشل (مثل إذا لم يكن هذا مرفقًا بخلاط).
