alpm-install-scriptlet(5)

الحزمة: alpm-docs

التراخيص: CC-BY-SA-4.0

(5) دليل تنسيقات الملفات (5)

الاسم

alpm-install-scriptlet – نص برمجي مخصص للتثبيت للحزم المستندة إلى ALPM.

الوصف

نص برمجي اختياري للصدفة يحدد الإجراءات المخصصة التي سيتم تنفيذها أثناء تثبيت حزمة أو ترقيتها أو إزالتها.

يتم تنفيذ الدوال الصدفية في الجذر (/) للنظام، لذلك يجب أن تكون جميع المسارات بداخله مطلقة.

توجد هذه الملفات في جذر حزم ALPM وتسمى .INSTALL.

التنسيق العام

قد يحتوي alpm-install-scriptlet على صفر أو أكثر من دوال الصدفة المحددة التي تحدد الإجراءات لأحداث دورة حياة مختلفة للحزمة. جميع الدوال اختيارية ويمكن تضمين فقط تلك الضرورية لحزمة معينة.

يمكن كتابة النص البرمجي بلغة صدفة تدعم خيار سطر الأوامر -c واستدعاء دوال مسماة مع وسيطات إضافية من واجهة سطر أوامر المفسر.

لاحظ أن مفسر الصدفة المستخدم بواسطة برنامج إدارة الحزم لتشغيل النص البرمجي يتم تعريفه عالميًا (على سبيل المثال، لكل توزيع). لا يتم استخدام shebang في النص البرمجي ولا يعتمد قرار أي صدفة سيتم استخدامه لتشغيله على بيانات وصفية للحزمة، بل يتم تحديده عادةً على مستوى التوزيع أو النظام. هذا يعني أنه لا يمكن تغيير مفسر الصدفة على أساس كل حزمة.

الدوال

الدوال المتاحة مدرجة أدناه. تقبل وسيطة واحدة أو اثنتين وهي إصدارات الحزمة، مقدمة كـ alpm-package-version.

pre_install

يتم تنفيذه قبل تثبيت الحزمة، مع إصدار الحزمة الجديد كوسيطة له.

post_install

يتم تنفيذه بعد تثبيت الحزمة، مع إصدار الحزمة الجديد كوسيطة له.

pre_upgrade

يتم تنفيذه قبل ترقية الحزمة، مع الوسيطات التالية:

1.
إصدار الحزمة الجديد
2.
إصدار الحزمة القديم
post_upgrade

يتم تنفيذه بعد ترقية الحزمة، مع الوسيطات التالية:

1.
إصدار الحزمة الجديد
2.
إصدار الحزمة القديم
pre_remove

يتم تنفيذه قبل إزالة الحزمة، مع إصدار الحزمة القديم كوسيطة له.

post_remove

يتم تنفيذه بعد إزالة الحزمة، مع إصدار الحزمة القديم كوسيطة له.

أمثلة

مثال على تحديد نص برمجي للتثبيت في ملف PKGBUILD:

install=example.install

مثال على نص برمجي أساسي لـ example.install:

pre_install() {
    echo "Preparing to install package version $1"
}
post_install() {
    echo "Package version $1 installed"
}
pre_upgrade() {
    echo "Preparing to upgrade from version $2 to $1"
}
post_upgrade() {
    echo "Upgraded from version $2 to $1"
}
pre_remove() {
    echo "Preparing to remove package version $1"
}
post_remove() {
    echo "Package version $1 removed"
}
