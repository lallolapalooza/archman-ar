al_draw_filled_polygon_with_holes(3)

الحزمة: allegro

التراخيص: Zlib, BSD-3-Clause, OFL-1.1, LicenseRef-Custom

al_draw_filled_polygon_with_holes(3) دليل وظائف المكتبة al_draw_filled_polygon_with_holes(3)

الاسم

al_draw_filled_polygon_with_holes - واجهة برمجة تطبيقات Allegro 5

الملخص

#include <allegro5/allegro_primitives.h>
void al_draw_filled_polygon_with_holes(const float *vertices,
   const int *vertex_counts, ALLEGRO_COLOR color)

الوصف

ترسم مضلعًا بسيطًا مملوءًا مع طرح صفر أو أكثر من المضلعات البسيطة الأخرى - الثقوب. لا يمكن للثقوب لمس أو تقاطع خطوط المضلع المملوء.

•
vertices - مصفوفة متداخلة من إحداثيات رؤوس (x, y) لكل مضلع، بما في ذلك الثقوب.
•
vertex_counts - عدد الرؤوس لكل مضلع. يُعطى عدد الرؤوس في المضلع المملوء بواسطة vertex_counts[0] ويجب أن يكون ثلاثة على الأقل. تشير العناصر اللاحقة إلى عدد الرؤوس في كل ثقب. يجب إنهاء المصفوفة بعنصر بقيمة صفر.
•
color - لون المضلع المملوء

عندما يكون المحور y متجهًا للأسفل (الحالة المعتادة) ، يجب ترتيب إحداثيات المضلع المملوء عكس اتجاه عقارب الساعة. يجب أن تستخدم جميع رؤوس الثقوب الترتيب المعاكس (مع اتجاه عقارب الساعة والمحور y للأسفل). يجب أن تكون جميع رؤوس الثقوب داخل المضلع الرئيسي ويجب ألا يتداخل أي ثقب مع المضلع الرئيسي.

على سبيل المثال:

float vertices[] = {
      0,   0, // المضلع المملوء، الزاوية العلوية اليسرى
      0, 100, // المضلع المملوء، الزاوية السفلية اليسرى
    100, 100, // المضلع المملوء، الزاوية السفلية اليمنى
    100,   0, // المضلع المملوء، الزاوية العلوية اليمنى
     10,  10, // ثقب، أعلى اليسار
     90,  10, // ثقب، أعلى اليمين
     90,  90  // ثقب، أسفل اليمين
};
int vertex_counts[] = {
   4, // عدد الرؤوس للمضلع المملوء
   3, // عدد الرؤوس للثقب
   0  // فاصل
};

هناك 7 رؤوس: أربعة لمربع خارجي من (0، 0) إلى (100، 100) بترتيب عكس اتجاه عقارب الساعة، وثلاثة رؤوس إضافية لمثلث داخلي بترتيب اتجاه عقارب الساعة. يستخدم المضلع الرئيسي الخارجي الرؤوس من 0 إلى 3 (شاملة) ويستخدم الثقب الرؤوس من 4 إلى 6 (شاملة).
