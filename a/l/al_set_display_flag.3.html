الاسم

al_set_display_flag - واجهة برمجة تطبيقات Allegro 5

الملخص

#include <allegro5/allegro.h>
bool al_set_display_flag(ALLEGRO_DISPLAY *display, int flag, bool onoff)

الوصف

تمكين أو تعطيل أحد أعلام العرض. الأعلام هي نفسها كما في al_set_new_display_flags(3). الأعلام الوحيدة التي يمكن تغييرها بعد الإنشاء هي:

•
ALLEGRO_FULLSCREEN_WINDOW
•
ALLEGRO_FRAMELESS
•
ALLEGRO_MAXIMIZED

تُرجع true إذا كان المشغل يدعم تبديل العلم المحدد، وإلا تُرجع false. يمكنك استخدام al_get_display_flags(3) للاستعلام عما إذا كانت خاصية العرض المعطاة قد تغيرت بالفعل.

منذ

5.0.7, 5.1.2
