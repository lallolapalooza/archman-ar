Alien__Build__Plugin__Probe__CommandLine(3pm)

الحزمة: perl-alien-build

التراخيص: PerlArtistic

Alien::Build::Plugin::Probe::CommandLine(3) وثائق مقدمة من المستخدم لـ Perl Alien::Build::Plugin::Probe::CommandLine(3)

الاسم

Alien::Build::Plugin::Probe::CommandLine - التحقق من الأدوات أو الأوامر المتاحة بالفعل

الإصدار

إصدار 2.84

ملخص

use alienfile;
plugin 'Probe::CommandLine' => (
  command => 'gzip',
  args    => [ '--version' ],
  match   => qr/gzip/,
  version => qr/gzip ([0-9\.]+)/,
);

الوصف

هذا المكون يتحقق من وجود برنامج سطر الأوامر المحدد.

الخصائص

command

اسم الأمر.

args

الوسائط التي سيتم تمريرها إلى الأمر.

secondary

إذا كنت تستخدم مكون تحقق آخر (مثل Alien::Build::Plugin::Probe::CBuilder أو Alien::Build::Plugin::PkgConfig::Negotiate) للكشف عن وجود مكتبة، ولكنك تحتاج أيضًا إلى وجود برنامج، فيجب عليك تعيين secondary إلى قيمة حقيقية. على سبيل المثال عندما تحتاج إلى كليهما:

use alienfile;
# يتطلب كلاً من مكتبة liblzma وبرنامج xz
plugin 'PkgConfig' => 'liblzma';
plugin 'Probe::CommandLine' => (
  command   => 'xz',
  secondary => 1,
);

عندما لا تفعل:

use alienfile;
plugin 'Probe::CommandLine' => (
  command   => 'gzip',
  secondary => 0, # الافتراضي
);

match

تعبير نمطي يجب أن يتطابق مع ناتج البرنامج.

match_stderr

تعبير نمطي يجب أن يتطابق مع الخطأ القياسي للبرنامج.

version

تعبير نمطي لاستخراج الإصدار من ناتج البرنامج. يجب أن يخزن التعبير النمطي رقم الإصدار في $1.

version_stderr

تعبير نمطي لاستخراج الإصدار من الخطأ القياسي للبرنامج. يجب أن يخزن التعبير النمطي رقم الإصدار في $1.

atleast_version

الحد الأدنى للإصدار المطلوب كما هو متوفر في النظام.
