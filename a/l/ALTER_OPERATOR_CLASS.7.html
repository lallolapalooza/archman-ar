ALTER_OPERATOR_CLASS(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER OPERATOR CLASS(7) PostgreSQL 18.1 Documentation ALTER OPERATOR CLASS(7)

الاسم

ALTER_OPERATOR_CLASS - تغيير تعريف فئة عامل التشغيل

الموجز

ALTER OPERATOR CLASS name USING index_method
    RENAME TO new_name
ALTER OPERATOR CLASS name USING index_method
    OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER OPERATOR CLASS name USING index_method
    SET SCHEMA new_schema

الوصف

ALTER OPERATOR CLASS يغير تعريف فئة عامل التشغيل.

يجب أن تمتلك فئة عامل التشغيل لاستخدام ALTER OPERATOR CLASS. لتغيير المالك، يجب أن تكون قادرًا على تعيين دور (SET ROLE) للدور الجديد المالك، ويجب أن يمتلك هذا الدور امتياز الإنشاء (CREATE) على مخطط فئة عامل التشغيل. (هذه القيود تضمن أن تغيير المالك لا يقوم بأي شيء لا يمكنك القيام به عن طريق إسقاط فئة عامل التشغيل وإعادة إنشائها. ومع ذلك، يمكن للمستخدم الخارق (superuser) تغيير ملكية أي فئة عامل تشغيل على أي حال.)

المعلمات

name

اسم فئة عامل التشغيل الموجودة (يمكن تحديد المخطط اختياريًا).

index_method

اسم طريقة الفهرسة التي تم إنشاء فئة عامل التشغيل هذه لأجلها.

new_name

الاسم الجديد لفئة عامل التشغيل.

new_owner

المالك الجديد لفئة عامل التشغيل.

new_schema

المخطط الجديد لفئة عامل التشغيل.

التوافق

لا توجد عبارة ALTER OPERATOR CLASS في معيار SQL.

انظر أيضاً

CREATE OPERATOR CLASS (CREATE_OPERATOR_CLASS(7))، DROP OPERATOR CLASS (DROP_OPERATOR_CLASS(7))، ALTER OPERATOR FAMILY (ALTER_OPERATOR_FAMILY(7))
