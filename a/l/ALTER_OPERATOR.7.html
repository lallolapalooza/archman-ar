ALTER_OPERATOR(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER OPERATOR(7) توثيق PostgreSQL 18.1 ALTER OPERATOR(7)

الاسم

ALTER_OPERATOR - تغيير تعريف معامل

الملخص

ALTER OPERATOR name ( { left_type | NONE } , right_type )
    OWNER TO { new_owner | CURRENT_ROLE | CURRENT_USER | SESSION_USER }
ALTER OPERATOR name ( { left_type | NONE } , right_type )
    SET SCHEMA new_schema
ALTER OPERATOR name ( { left_type | NONE } , right_type )
    SET ( {  RESTRICT = { res_proc | NONE }
           | JOIN = { join_proc | NONE }
           | COMMUTATOR = com_op
           | NEGATOR = neg_op
           | HASHES
           | MERGES
          } [, ... ] )

الوصف

يقوم أمر ALTER OPERATOR بتغيير تعريف معامل.

يجب أن تمتلك المعامل لاستخدام ALTER OPERATOR. لتغيير المالك، يجب أن تكون قادرًا على تعيين دور (SET ROLE) إلى الدور المالك الجديد، ويجب أن يمتلك هذا الدور امتياز الإنشاء (CREATE) على مخطط المعامل. (تضمن هذه القيود أن تغيير المالك لا يؤدي إلى أي شيء لا يمكنك القيام به عن طريق إسقاط المعامل وإعادة إنشائه. ومع ذلك، يمكن للمستخدم الخارق (superuser) تغيير ملكية أي معامل على أي حال.)

المعلمات

name

اسم معامل موجود (يمكن إضافة اسم المخطط إليه).

left_type

نوع البيانات للمعامل الأيسر للمعامل؛ اكتب NONE إذا لم يكن للمعامل معامل أيسر.

right_type

نوع البيانات للمعامل الأيمن للمعامل.

new_owner

المالك الجديد للمعامل.

new_schema

المخطط الجديد للمعامل.

res_proc

وظيفة تقدير انتقائية القيود (restriction selectivity estimator) لهذا المعامل؛ اكتب NONE لإزالة مقدر الانتقائية الموجود.

join_proc

وظيفة تقدير انتقائية الربط (join selectivity estimator) لهذا المعامل؛ اكتب NONE لإزالة مقدر الانتقائية الموجود.

com_op

المعامل التبادلي (commutator) لهذا المعامل. يمكن تغييره فقط إذا لم يكن للمعامل معامل تبادلي موجود.

neg_op

المعامل المعاكس (negator) لهذا المعامل. يمكن تغييره فقط إذا لم يكن للمعامل معامل معاكس موجود.

HASHES

يشير إلى أن هذا المعامل يمكن أن يدعم ربط التجزئة (hash join). يمكن تمكينه فقط وليس تعطيله.

MERGES

يشير إلى أن هذا المعامل يمكن أن يدعم ربط الدمج (merge join). يمكن تمكينه فقط وليس تعطيله.

ملاحظات

راجع القسم 36.14 والقسم 36.15 لمزيد من المعلومات.

نظرًا لأن المعاملات التبادلية تأتي في أزواج تكون تبادلية لبعضها البعض، فإن الأمر ALTER OPERATOR SET COMMUTATOR سيقوم أيضًا بتعيين المعامل التبادلي للمعامل com_op ليكون المعامل المستهدف. وبالمثل، سيقوم الأمر ALTER OPERATOR SET NEGATOR أيضًا بتعيين المعامل المعاكس للمعامل neg_op ليكون المعامل المستهدف. لذلك، يجب أن تمتلك المعامل التبادلي أو المعاكس بالإضافة إلى المعامل المستهدف.

أمثلة

تغيير مالك معامل مخصص a @@ b للنوع text:

ALTER OPERATOR @@ (text, text) OWNER TO joe;

تغيير وظائف تقدير انتقائية القيود والربط للمعامل المخصص a && b للنوع int[]:

ALTER OPERATOR && (int[], int[]) SET (RESTRICT = _int_contsel, JOIN = _int_contjoinsel);

تمييز المعامل && على أنه تبادلي لنفسه:

ALTER OPERATOR && (int[], int[]) SET (COMMUTATOR = &&);

التوافق

لا يوجد بيان ALTER OPERATOR في معيار SQL.
