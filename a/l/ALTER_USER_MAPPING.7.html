ALTER_USER_MAPPING(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ALTER USER MAPPING(7) توثيق PostgreSQL 18.1 ALTER USER MAPPING(7)

الاسم

ALTER_USER_MAPPING - تغيير تعريف تعيين مستخدم

الملخص

ALTER USER MAPPING FOR { user_name | USER | CURRENT_ROLE | CURRENT_USER | SESSION_USER | PUBLIC }
    SERVER server_name
    OPTIONS ( [ ADD | SET | DROP ] option ['value'] [, ... ] )

الوصف

ALTER USER MAPPING يغير تعريف تعيين مستخدم.

يمكن لمالك خادم خارجي تغيير تعيينات المستخدمين لهذا الخادم لأي مستخدم. بالإضافة إلى ذلك، يمكن للمستخدم تغيير تعيين مستخدم لاسم المستخدم الخاص به إذا تم منح امتياز USAGE على الخادم للمستخدم.

المعلمات

user_name

اسم المستخدم للتعيين. CURRENT_ROLE، CURRENT_USER، و USER تطابق اسم المستخدم الحالي. PUBLIC يستخدم للمطابقة مع جميع أسماء المستخدمين الحالية والمستقبلية في النظام.

server_name

اسم الخادم لتعيين المستخدم.

OPTIONS ( [ ADD | SET | DROP ] option ['value'] [, ... ] )

تغيير الخيارات لتعيين المستخدم. الخيارات الجديدة تطغى على أي خيارات محددة سابقًا. ADD، SET، و DROP تحدد الإجراء الذي سيتم تنفيذه. يُفترض ADD إذا لم يتم تحديد عملية صراحةً. يجب أن تكون أسماء الخيارات فريدة؛ يتم التحقق من صحة الخيارات أيضًا بواسطة برنامج تشغيل البيانات الأجنبية الخاص بالخادم.

أمثلة

تغيير كلمة المرور لتعيين المستخدم bob، الخادم foo:

ALTER USER MAPPING FOR bob SERVER foo OPTIONS (SET password 'public');

التوافق

ALTER USER MAPPING يتوافق مع ISO/IEC 9075-9 (SQL/MED). هناك مشكلة دقيقة في بناء الجملة: يتجاهل المعيار الكلمة المفتاحية FOR. بما أن CREATE USER MAPPING و DROP USER MAPPING تستخدمان FOR في مواضع مماثلة، و IBM DB2 (كونها التنفيذ الرئيسي الآخر لـ SQL/MED) تتطلبها أيضًا لـ ALTER USER MAPPING، فإن PostgreSQL تنحرف عن المعيار هنا لصالح الاتساق وقابلية التشغيل البيني.

راجع أيضًا

CREATE USER MAPPING (CREATE_USER_MAPPING(7))، DROP USER MAPPING (DROP_USER_MAPPING(7))
