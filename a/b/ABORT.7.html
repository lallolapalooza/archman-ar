ABORT(7)

الحزمة: postgresql

التراخيص: PostgreSQL

ABORT(7) توثيق PostgreSQL 18.1 ABORT(7)

الاسم

ABORT - إلغاء المعاملة الحالية

ملخص

ABORT [ WORK | TRANSACTION ] [ AND [ NO ] CHAIN ]

الوصف

يقوم الأمر ABORT بالتراجع عن المعاملة الحالية ويتسبب في التخلي عن جميع التحديثات التي تمت بواسطة المعاملة. هذا الأمر مطابق تمامًا في السلوك للأمر القياسي SQL ROLLBACK، وهو موجود فقط لأسباب تاريخية.

المعاملات

WORK
TRANSACTION

كلمات مفتاحية اختيارية. ليس لها تأثير.

AND CHAIN

إذا تم تحديد AND CHAIN، فسيتم بدء معاملة جديدة على الفور بنفس خصائص المعاملة (راجع SET TRANSACTION) مثل تلك التي تم الانتهاء منها لل تو. وإلا، فلن تبدأ معاملة جديدة.

ملاحظات

استخدم COMMIT لإنهاء المعاملة بنجاح.

إصدار الأمر ABORT خارج كتلة المعاملة يصدر تحذيرًا ولا يكون له أي تأثير بخلاف ذلك.

أمثلة

لإلغاء جميع التغييرات:

ABORT;

التوافق

هذا الأمر هو امتداد PostgreSQL موجود لأسباب تاريخية. ROLLBACK هو الأمر القياسي SQL المكافئ.

راجع أيضًا
