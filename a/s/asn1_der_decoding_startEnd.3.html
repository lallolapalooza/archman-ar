asn1_der_decoding_startEnd(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_der_decoding_startEnd(3) libtasn1 asn1_der_decoding_startEnd(3)

الاسم

asn1_der_decoding_startEnd - وظيفة API

الملخص

#include <libtasn1.h>

int asn1_der_decoding_startEnd(asn1_node element, const void * ider, int ider_len, const char * name_element, int * start, int * end);

المعاملات

asn1_node element
مؤشر إلى عنصر ASN1
const void * ider
المصفوفة التي تحتوي على ترميز DER.
int ider_len
عدد البايتات في * ider : ider [0].. ider [len-1]
const char * name_element
عنصر من هيكل NAME.
int * start
موضع البايت الأول لفك ترميز NAME_ELEMENT ( ider [*start])
int * end
موضع البايت الأخير لفك ترميز NAME_ELEMENT ( ider [*end])

الوصف

البحث عن نقطة البداية والنهاية لعنصر في سلسلة ترميز DER. أعني أنه إذا كان لديك ترميز DER وقد استخدمت بالفعل الدالة asn1_der_decoding() لملء بنية، فقد يحدث أنك تريد العثور على جزء السلسلة المتعلق بعنصر من البنية.

أحد الأمثلة هو التسلسل "tbsCertificate" داخل شهادة X509.

لاحظ أنه منذ libtasn1 3.7، يمكن حذف المعاملين ider و ider_len، إذا تم فك ترميز العنصر بالفعل باستخدام asn1_der_decoding().

الإرجاع

ASN1_SUCCESS إذا كان ترميز DER صحيحًا، ASN1_ELEMENT_NOT_FOUND إذا كان ELEMENT هو asn1_node فارغًا أو name_element ليس عنصرًا صالحًا، ASN1_TAG_ERROR أو ASN1_DER_ERROR إذا كان ترميز DER لا يتطابق مع البنية ELEMENT.
