asn1_delete_element(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_delete_element(3) libtasn1 asn1_delete_element(3)

الاسم

asn1_delete_element - وظيفة API

الاختصار

#include <libtasn1.h>

int asn1_delete_element(asn1_node structure, const char * element_name);

المعاملات

asn1_node structure
مؤشر إلى الهيكل الذي يحتوي على العنصر الذي تريد حذفه.
const char * element_name
اسم العنصر الذي تريد حذفه.

الوصف

يحذف العنصر المسمى * element_name داخل * structure.

القيمة المعادة

ASN1_SUCCESS في حالة النجاح، ASN1_ELEMENT_NOT_FOUND إذا لم يتم العثور على element_name.
