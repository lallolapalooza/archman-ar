asn1_der_decoding(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_der_decoding(3) libtasn1 asn1_der_decoding(3)

الاسم

asn1_der_decoding - وظيفة API

الملخص

#include <libtasn1.h>

int asn1_der_decoding(asn1_node * element, const void * ider, int ider_len, char * errorDescription);

المعاملات

asn1_node * element
مؤشر إلى هيكل ASN1.
const void * ider
المتجه الذي يحتوي على ترميز DER.
int ider_len
عدد البايتات من * ider : ider [0].. ider [len-1].
char * errorDescription
سلسلة منتهية بـ NULL تحتوي على تفاصيل عند حدوث خطأ.

الوصف

ملء الهيكل * element بقيم سلسلة ترميز DER. يجب أن يكون الهيكل قد تم إنشاؤه للتو باستخدام الوظيفة asn1_create_element().

لاحظ أن المتغير * element يتم توفيره كمؤشر لأسباب تاريخية.

الإرجاع

ASN1_SUCCESS إذا كان ترميز DER صحيحًا، ASN1_ELEMENT_NOT_FOUND إذا كان ELEMENT هو NULL، و ASN1_TAG_ERROR أو ASN1_DER_ERROR إذا كان ترميز der لا يتطابق مع اسم الهيكل (* ELEMENT تم حذفه).
