asn1_copy_node(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_copy_node(3) libtasn1 asn1_copy_node(3)

الاسم

asn1_copy_node - وظيفة API

الملخص

#include <libtasn1.h>

int asn1_copy_node(asn1_node dst, const char * dst_name, asn1_node_const src, const char * src_name);

المعاملات

asn1_node dst
عقدة الوجهة asn1.
const char * dst_name
اسم الحقل في عقدة الوجهة.
asn1_node_const src
عقدة المصدر asn1.
const char * src_name
اسم الحقل في عقدة المصدر.

الوصف

إنشاء نسخة عميقة من متغير asn1_node. تتطلب هذه الوظيفة أن تكون dst موسعة باستخدام asn1_create_element().

القيم المعادة

إرجاع ASN1_SUCCESS عند النجاح.
