asn1_print_structure(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_print_structure(3) libtasn1 asn1_print_structure(3)

الاسم

asn1_print_structure - وظيفة API

الاختصار

#include <libtasn1.h>

void asn1_print_structure(FILE * out, asn1_node_const structure, const char * name, int mode);

المعاملات

FILE * out
مؤشر إلى ملف الإخراج (مثل stdout).
asn1_node_const structure
مؤشر إلى البنية التي تريد زيارتها.
const char * name
عنصر من البنية.
int mode
تحديد مقدار البنية المراد طباعتها، يمكن أن يكون ASN1_PRINT_NAME، ASN1_PRINT_NAME_TYPE، ASN1_PRINT_NAME_TYPE_VALUE، أو ASN1_PRINT_ALL.

الوصف

تطبع على واصف الملف out شجرة البنية بدءًا من العنصر name داخل البنية structure.
