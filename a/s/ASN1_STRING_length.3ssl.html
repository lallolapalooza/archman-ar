ASN1_STRING_length(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

ASN1_STRING_LENGTH(3ssl) OpenSSL ASN1_STRING_LENGTH(3ssl)

الاسم

ASN1_STRING_dup, ASN1_STRING_cmp, ASN1_STRING_set, ASN1_STRING_length, ASN1_STRING_type, ASN1_STRING_get0_data, ASN1_STRING_data, ASN1_STRING_to_UTF8 - وظائف مساعدة لـ ASN1_STRING

الملخص

#include <openssl/asn1.h>
int ASN1_STRING_length(ASN1_STRING *x);
const unsigned char *ASN1_STRING_get0_data(const ASN1_STRING *x);
unsigned char *ASN1_STRING_data(ASN1_STRING *x);
ASN1_STRING *ASN1_STRING_dup(const ASN1_STRING *a);
int ASN1_STRING_cmp(ASN1_STRING *a, ASN1_STRING *b);
int ASN1_STRING_set(ASN1_STRING *str, const void *data, int len);
int ASN1_STRING_type(const ASN1_STRING *x);
int ASN1_STRING_to_UTF8(unsigned char **out, const ASN1_STRING *in);

الوصف

تسمح هذه الوظائف بمعالجة بنية ASN1_STRING.

ASN1_STRING_length() تُرجع طول محتوى x. يجب ألا يكون x فارغًا (NULL).

ASN1_STRING_get0_data() تُرجع مؤشرًا داخليًا لبيانات x. نظرًا لأن هذا مؤشر داخلي، فيجب عدم تحريره أو تعديله بأي شكل من الأشكال. يجب ألا يكون x فارغًا (NULL).

ASN1_STRING_data() مشابهة لـ ASN1_STRING_get0_data() باستثناء أن القيمة المُرجعة ليست ثابتة. هذه الوظيفة مهملة: يجب على التطبيقات استخدام ASN1_STRING_get0_data() بدلاً منها.

ASN1_STRING_dup() تُرجع نسخة من البنية a.

ASN1_STRING_cmp() تقارن a و b، وتعيد 0 إذا كان الاثنان متطابقين. يتم مقارنة أنواع السلسلة ومحتواها.

ASN1_STRING_set() تعين بيانات السلسلة str إلى المخزن المؤقت data بطول len. يتم نسخ البيانات المقدمة. إذا كان len يساوي -1، فسيتم تحديد الطول بواسطة strlen(data).

ASN1_STRING_type() تُرجع نوع x، باستخدام ثوابت قياسية مثل V_ASN1_OCTET_STRING.

ASN1_STRING_to_UTF8() تحول السلسلة in إلى تنسيق UTF8، ويتم تخصيص البيانات المحولة في مخزن مؤقت في *out. يتم إرجاع طول out أو رمز خطأ سالب. يجب تحرير المخزن المؤقت *out باستخدام OPENSSL_free().

ملاحظات

يتم تمثيل معظم أنواع ASN1 في OpenSSL كهيكل ASN1_STRING. الأنواع الأخرى مثل ASN1_OCTET_STRING هي مجرد typedef إلى ASN1_STRING وتستدعي الوظائف مكافئات ASN1_STRING. يستخدم ASN1_STRING أيضًا لبعض أنواع CHOICE التي تتكون بالكامل من أنواع سلاسل بدائية مثل DirectoryString و Time.

لا ينبغي استخدام هذه الوظائف لفحص أو تعديل أنواع ASN1_INTEGER أو ASN1_ENUMERATED: يجب استخدام وظائف مساعدة INTEGER أو ENUMERATED ذات الصلة بدلاً من ذلك.

بشكل عام، لا يمكن افتراض أن البيانات التي تم إرجاعها بواسطة ASN1_STRING_data() لا تنتهي بـ null أو لا تحتوي على null مضمنة. سيعتمد التنسيق الفعلي للبيانات على نوع السلسلة الفعلي نفسه: على سبيل المثال، بالنسبة لـ IA5String، ستكون البيانات بتنسيق ASCII، وبالنسبة لـ BMPString، ستكون بايتين لكل حرف بتنسيق big endian، وبالنسبة لـ UTF8String، ستكون بتنسيق UTF8.

يجب توخي الحذر المماثل لضمان أن البيانات بالتنسيق الصحيح عند استدعاء ASN1_STRING_set().

قيم الإرجاع

ASN1_STRING_length() تُرجع طول محتوى x.

ASN1_STRING_get0_data() و ASN1_STRING_data() تُرجعان مؤشرًا داخليًا لبيانات x.

ASN1_STRING_dup() تُرجع بنية ASN1_STRING صالحة أو NULL إذا حدث خطأ.

ASN1_STRING_cmp() تُرجع عددًا صحيحًا أكبر من أو يساوي أو أقل من 0، وفقًا لما إذا كان a أكبر من أو يساوي أو أقل من b.

ASN1_STRING_set() تُرجع 1 عند النجاح أو 0 عند الخطأ.

ASN1_STRING_type() تُرجع نوع x.

ASN1_STRING_to_UTF8() تُرجع عدد البايتات في السلسلة الخارجية out أو قيمة سالبة إذا حدث خطأ.
