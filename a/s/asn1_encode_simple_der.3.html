asn1_encode_simple_der(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_encode_simple_der(3) libtasn1 asn1_encode_simple_der(3)

الاسم

asn1_encode_simple_der - دالة API

الملخص

#include <libtasn1.h>

int asn1_encode_simple_der(unsigned int etype, const unsigned char * str, unsigned int str_len, unsigned char * tl, unsigned int * tl_len);

المعاملات

unsigned int etype
نوع السلسلة المراد ترميزها (ASN1_ETYPE_)
const unsigned char * str
بيانات السلسلة.
unsigned int str_len
طول السلسلة
unsigned char * tl
العلامة والطول المشفرين
unsigned int * tl_len
بايتات حقل tl

الوصف

ينشئ ترميز DER لأنواع ASN.1 البسيطة المختلفة مثل السلاسل وما إلى ذلك. يقوم بتخزين العلامة والطول في tl ، والتي يجب أن تحتوي على مساحة لـ ASN1_MAX_TL_SIZE بايت على الأقل. مبدئيًا، يجب أن يحتوي tl_len على حجم tl.

يجب أن يتكون ترميز DER الكامل من القيمة الموجودة في tl مضافًا إليها السلسلة str المقدمة.

القيمة المعادة

ASN1_SUCCESS عند النجاح أو قيمة خطأ.
