ASN1_ITEM_lookup(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

ASN1_ITEM_LOOKUP(3ssl) OpenSSL ASN1_ITEM_LOOKUP(3ssl)

اسم

ASN1_ITEM_lookup, ASN1_ITEM_get - البحث عن هياكل ASN.1

المُلخص

#include <openssl/asn1.h>
const ASN1_ITEM *ASN1_ITEM_lookup(const char *name);
const ASN1_ITEM *ASN1_ITEM_get(size_t i);

الوصف

ASN1_ITEM_lookup() تُرجع ASN1_ITEM المسماة name.

ASN1_ITEM_get() تُرجع ASN1_ITEM ذات الفهرس i. تُرجع هذه الدالة NULL إذا كان الفهرس i خارج النطاق.

قيم الإرجاع

ASN1_ITEM_lookup() و ASN1_ITEM_get() تُرجعان بنية ASN1_ITEM صالحة أو NULL إذا حدث خطأ.
