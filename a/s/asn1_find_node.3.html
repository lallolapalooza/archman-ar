asn1_find_node(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_find_node(3) libtasn1 asn1_find_node(3)

الاسم

asn1_find_node - وظيفة API

ملخص

#include <libtasn1.h>

asn1_node asn1_find_node(asn1_node_const pointer, const char * name);

الوسائط

asn1_node_const pointer
مؤشر عنصر NODE_ASN.
const char * name
سلسلة نصية منتهية بـ NULL مع اسم العنصر المراد البحث عنه.

الوصف

يبحث عن عنصر باسم name بدءًا من pointer. الاسم يتكون من معرفات مختلفة مفصولة بنقاط. عندما يكون اسم * pointer موجودًا، يجب أن يكون المعرف الأول هو اسم * pointer ، وإلا يجب أن يكون اسم أحد أبناء * pointer.

النتائج

نتيجة البحث، أو NULL إذا لم يتم العثور عليه.
