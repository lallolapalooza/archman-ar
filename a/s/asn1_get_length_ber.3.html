asn1_get_length_ber(3)

الحزمة: libtasn1

التراخيص: GPL-3.0-or-later, LGPL-2.1-or-later, GFDL-1.3-or-later

asn1_get_length_ber(3) libtasn1 asn1_get_length_ber(3)

الاسم

asn1_get_length_ber - دالة API

الملخص

#include <libtasn1.h>

long asn1_get_length_ber(const unsigned char * ber, int ber_len, int * len);

المعاملات

const unsigned char * ber
بيانات BER المراد فك تشفيرها.
int ber_len
طول بيانات BER المراد فك تشفيرها.
int * len
متغير الخرج الذي يحتوي على طول حقل طول BER.

الوصف

استخراج حقل طول من بيانات BER. الفرق بينها وبين asn1_get_length_der() هو أن هذه الدالة ستعيد طولًا حتى لو كانت القيمة ذات ترميز غير محدد.

الإرجاع

إرجاع قيمة الطول المفكوك، أو قيمة سالبة عندما تكون القيمة كبيرة جدًا.
