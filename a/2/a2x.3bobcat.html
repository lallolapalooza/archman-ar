a2x.3bobcat

الحزمة: libbobcat

التراخيص: GPL

FBB::A2x(3bobcat) محول النص إلى X FBB::A2x(3bobcat)

الاسم

FBB::A2x - كائنات تؤدي تحويلات من ASCII إلى X (أي شيء)

الملخص

#include <bobcat/a2x>
خيار الربط: -lbobcat

الوصف

تقدم كائنات FBB::A2x المكافئ لـ C++ لوظائف التحويل القياسية للسلاسل النصية في C++ مثل stol, stoul, stod إلخ. هذه الوظائف القياسية للسلاسل النصية في C++ مفيدة للغاية ويجب تفضيلها على استخدام أعضاء كائنات A2x، ولكن A2x تقدم فوائد إضافية حيث أنها تعمم هذه الوظائف على أي نوع يمكن استخراجه من كائنات istream.

FBB

المنشئات

o
A2x():
يقوم هذا المنشئ بإنشاء كائن A2x فارغ. لا يمكن تحويل أي معلومات من كائن A2x تم إنشاؤه بهذه الطريقة.
o
A2x(char const *text):
يخزن هذا المنشئ text. إذا كان text يمثل قيمة نصية من نوع ما، فيمكن استخدام كائن A2x لتهيئة أو تعيين هذه القيمة لمتغير من هذا النوع المحدد. ومع ذلك، لا يزال الاستخراج ممكنًا أيضًا.
o
A2x(std::string const &str):
يخزن هذا المنشئ النص الموجود في str. إذا كان هذا النص يمثل قيمة نصية من نوع ما، فيمكن استخدام كائن A2x لتهيئة أو تعيين هذه القيمة لمتغير من هذا النوع المحدد. الاستخراج ممكن أيضًا.

منشئات النسخ والنقل متاحة.

دالة عضو ثابتة

o
bool lastFail():
تُرجع هذه الدالة true إذا فشل التحويل الأخير (أي، أرجعت الدالة fail() للكائن true، وتُرجع false بخلاف ذلك). تسمح هذه الدالة بالتحقق من نجاح الاستخراج/التحويل باستخدام كائنات A2x المجهولة. تُرجع الدالة أيضًا true عندما لم يتم إجراء أي تحويلات حتى الآن.
لاحظ أن هذه الدالة تُرجع قيمة عضو ثابت thread_local: لا يمكن للخيوط المختلفة فحص حالة lastFail للخيوط الأخرى.

دالة عضو

جميع أعضاء فئة istringstream متاحة.

o
Type to():
تُرجع هذه الدالة أي نوع Type يدعم الاستخراج من i[string]streams. إذا فشل الاستخراج، تُرجع الدالة good() لكائن A2x القيمة false، وتُرجع القيمة الافتراضية للنوع Type. تم تطبيق عامل التشغيل هذا كدالة عضو قالب. يوجد أيضًا عامل تشغيل تحويل النوع متاح (انظر أدناه)، ولكن يمكن تفضيل شكل الدالة العضو على عامل تشغيل التحويل في المواقف التي تتطلب تمييزًا صريحًا (على سبيل المثال، في الحالات التي لا يكون فيها للتحويل حل نوع واضح مثل الإدراجات المباشرة). تم تقديم مثال في قسم مثال أدناه.

عوامل التشغيل المحملة بشكل زائد

o
operator Type():
التحويل إلى أي نوع Type يدعم الاستخراج من istreams. إذا فشل الاستخراج، ستُرجع الدالة good() لكائن A2x القيمة false، وتُرجع القيمة الافتراضية للنوع Type. تم تطبيق عامل التشغيل هذا كقالب عضو.
o
istream &operator>>(istream &, Type &):
الاستخراج إلى أي نوع Type يدعم الاستخراج من istreams. إذا فشل الاستخراج، تُرجع الدالة good() لكائن A2x القيمة false، وتُرجع القيمة الافتراضية للنوع Type (يتم تضمين هذه الإمكانية بحقيقة أن هذه الفئة ترث من istringstream، ولكن من المفيد التأكيد على أن عملية الاستخراج لا تزال متاحة).
o
A2x &operator=(char const *):
يقوم بتخزين نص جديد في كائن A2x، ويعيد تعيين علامات الحالة إلى ios::good. إذا تم تمرير مؤشر 0، يتم تخزين سلسلة فارغة.
o
A2x &operator=(std::string const &):
يخزن النص المخزن في وسيط std::string في كائن A2x، ويعيد تعيين علامات الحالة إلى ios::good.

عامل التشغيل المعين المحمل بشكل زائد متاح

مثال

    int x = A2x("12");
    A2x a2x("12.50");
    double d;
    d = a2x;
    a2x = "err";
    d = a2x;        // d الآن 0
    a2x = " a";
    char c = a2x;   // c الآن 'a'
                    // تحويل صريح إلى `double'
    cout << A2x("12.4").to<double>() << endl;
