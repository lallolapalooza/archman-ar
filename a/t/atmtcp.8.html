الاسم

atmtcp - توجيه حركة مرور ATM عبر TCP

الملخص

atmtcp [ OPTIONS ] [ COMMAND ]

الوصف

يقوم atmtcp بتوجيه حركة مرور ATM عبر اتصال TCP. يمكن استخدامه لإنشاء جسر بين شبكة ATM وشبكة IP، أو لإنشاء نفق ATM عبر شبكة IP.

الخيارات

  • -i, --interface INTERFACE: واجهة ATM المراد استخدامها.
  • -r, --remote ADDRESS: عنوان IP للجهاز البعيد.
  • -p, --port PORT: منفذ TCP المراد استخدامه.
  • -d, --debug: تفعيل وضع التصحيح.
  • -h, --help: عرض رسالة المساعدة والخروج.

الأوامر

  • bridge: إنشاء جسر بين شبكة ATM وشبكة TCP.
  • tunnel: إنشاء نفق ATM عبر شبكة TCP.

القيود

يتطلب تشغيل atmtcp صلاحيات الجذر.

أمثلة

لإنشاء جسر بين واجهة ATM atm0 وجهاز بعيد بعنوان IP 192.168.1.100 ومنفذ 1234:

sudo atmtcp -i atm0 -r 192.168.1.100 -p 1234 bridge

لإنشاء نفق ATM عبر شبكة TCP:

sudo atmtcp -i atm0 -r 192.168.1.100 -p 1234 tunnel
