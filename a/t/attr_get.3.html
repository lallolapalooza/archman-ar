attr_get(3)

الحزمة: attr

التراخيص: LGPL

ATTR_GET(3) واجهة برمجة تطبيقات توافق XFS ATTR_GET(3)

الاسم

attr_get, attr_getf - الحصول على قيمة سمة مستخدم لكائن نظام الملفات

C الملخص

#include <attr/attributes.h>

int attr_get (const char *path, const char *attrname, 
              char *attrvalue, int *valuelength, int flags);
int attr_getf (int fd, const char *attrname, 
               char *attrvalue, int *valuelength, int flags);

الوصف

توفر الدالتان attr_get و attr_getf طريقة لاسترداد قيمة سمة.

Path يشير إلى اسم مسار لكائن نظام ملفات، و fd يشير إلى واصف الملف المرتبط بملف. إذا كانت السمة attrname موجودة، سيتم نسخ القيمة المرتبطة بها إلى المخزن المؤقت attrvalue. الوسيط valuelength هو وسيط إدخال/إخراج، والذي يجب أن يحتوي عند استدعاء attr_get على الحجم الأقصى لقيمة السمة التي يقبلها العملية. عند العودة، سيتم تعديل valuelength لإظهار الحجم الفعلي لقيمة السمة التي تم إرجاعها. يمكن أن يحتوي الوسيط flags على الرموز التالية مدمجة باستخدام OR الثنائية:

ATTR_ROOT
البحث عن attrname في مساحة عنوان الجذر، وليس في مساحة عنوان المستخدم. (محدود للاستخدام من قبل المستخدم الخارق فقط)
ATTR_DONTFOLLOW
لا تتبع الروابط الرمزية عند حل path في استدعاء دالة attr_get. الافتراضي هو تتبع الروابط الرمزية.

ستفشل attr_get إذا كان واحد أو أكثر مما يلي صحيحًا:

[ENOATTR]
اسم السمة المعطى غير مرتبط بكائن نظام الملفات المشار إليه.
[E2BIG]
قيمة السمة المعطاة كبيرة جدًا بحيث لا تتناسب مع المخزن المؤقت. تم تعديل العدد الصحيح الذي يشير إليه الوسيط valuelength لإظهار العدد الفعلي للبايتات المطلوبة لتخزين قيمة تلك السمة.
[ENOENT]
الملف المسمى غير موجود.
[EPERM]
معرف المستخدم الفعال لا يتطابق مع مالك الملف ومعرف المستخدم الفعال ليس مستخدمًا خارقًا.
[ENOTDIR]
أحد مكونات مسار البادئة ليس دليلًا.
[EACCES]
يُمنع إذن البحث في مكون من مسار البادئة.
[EINVAL]
تم تعيين بت في الوسيط flag غير معرف لنظام الاستدعاء هذا.
[EFAULT]
Path، attrname، attrvalue، أو valuelength يشير خارج مساحة العنوان المخصصة للعملية.
[ELOOP]
بحث اسم المسار تضمن الكثير من الروابط الرمزية.
[ENAMETOOLONG]
طول path يتجاوز {MAXPATHLEN}، أو مكون اسم المسار أطول من {MAXNAMELEN}.

ستفشل attr_getf إذا:

[ENOATTR]
اسم السمة المعطى غير مرتبط بكائن نظام الملفات المشار إليه.
[E2BIG]
قيمة السمة المعطاة كبيرة جدًا بحيث لا تتناسب مع المخزن المؤقت. تم تعديل العدد الصحيح الذي يشير إليه الوسيط valuelength لإظهار العدد الفعلي للبايتات المطلوبة لتخزين قيمة تلك السمة.
[EINVAL]
تم تعيين بت في الوسيط flag غير معرف لنظام الاستدعاء هذا، أو fd يشير إلى مقبس، وليس ملفًا.
[EFAULT]
Attrname، attrvalue، أو valuelength يشير خارج مساحة العنوان المخصصة للعملية.
[EBADF]
Fd لا يشير إلى واصف صالح.

التشخيص

عند النجاح، يتم إرجاع الصفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno بشكل مناسب.
