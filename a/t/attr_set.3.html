attr_set(3)

الحزمة: attr

التراخيص: LGPL

ATTR_SET(3) واجهة برمجة تطبيقات التوافق XFS ATTR_SET(3)

الاسم

attr_set, attr_setf - تعيين قيمة سمة مستخدم لكائن نظام الملفات

ملخص C

#include <attr/attributes.h>

int attr_set (const char *path, const char *attrname, 
              const char *attrvalue, const int valuelength,
              int flags);
int attr_setf (int fd, const char *attrname, 
               const char *attrvalue, const int valuelength,
               int flags);

الوصف

توفر الدالتان attr_set و attr_setf طريقة لإنشاء السمات وتعيين/تغيير قيمها.

Path يشير إلى اسم مسار لكائن نظام الملفات، و fd يشير إلى واصف الملف المرتبط بملف. إذا لم تكن السمة attrname موجودة، فسيتم إنشاء سمة بالاسم والقيمة المعطاة وربطها بكائن نظام الملفات المشار إليه. إذا كانت هناك سمة بهذا الاسم موجودة بالفعل على كائن نظام الملفات هذا، فسيتم استبدال القيمة الحالية بالقيمة الجديدة المعطاة في هذا الاستدعاء. يتم نسخ قيمة السمة الجديدة من المخزن المؤقت attrvalue لإجمالي valuelength بايت. يمكن أن تحتوي الوسيطة flags على الرموز التالية مفصولة بمؤشر OR:

ATTR_ROOT
ابحث عن attrname في مساحة عنوان **الجذر**، وليس في مساحة عنوان **المستخدم**. (محدود للاستخدام من قبل المستخدم الخارق فقط)
ATTR_DONTFOLLOW
لا تتبع الروابط الرمزية عند حل path في استدعاء دالة attr_set. الافتراضي هو تتبع الروابط الرمزية.
ATTR_CREATE
إرجاع خطأ (EEXIST) إذا كانت سمة بالاسم المعطى موجودة بالفعل على كائن نظام الملفات المشار إليه، وإلا فقم بإنشاء سمة بالاسم والقيمة المعطاة. تُستخدم هذه العلامة لتنفيذ عملية إنشاء بحتة، بدون هذه العلامة، ستقوم attr_set بإنشاء السمة إذا لم تكن موجودة بالفعل. سيتم إرجاع خطأ (EINVAL) إذا تم تعيين كل من ATTR_CREATE و ATTR_REPLACE في نفس الاستدعاء.
ATTR_REPLACE
إرجاع خطأ (ENOATTR) إذا لم تكن سمة بالاسم المعطى موجودة بالفعل على كائن نظام الملفات المشار إليه، وإلا فقم باستبدال قيمة السمة الموجودة بالقيمة المعطاة. تُستخدم هذه العلامة لتنفيذ عملية استبدال بحتة، بدون هذه العلامة، ستقوم attr_set بإنشاء السمة إذا لم تكن موجودة بالفعل. سيتم إرجاع خطأ (EINVAL) إذا تم تعيين كل من ATTR_CREATE و ATTR_REPLACE في نفس الاستدعاء.

ستفشل attr_set إذا كان أي مما يلي صحيحًا:

[ENOATTR]
اسم السمة المعطى غير مرتبط بكائن نظام الملفات المشار إليه وتم تعيين بت علامة ATTR_REPLACE.
[E2BIG]
قيمة السمة المعطاة كبيرة جدًا، وتتجاوز الحد الأقصى المسموح به لقيمة السمة.
[EEXIST]
اسم السمة المعطى مرتبط بالفعل بكائن نظام الملفات المشار إليه وتم تعيين بت علامة ATTR_CREATE.
[ENOENT]
الملف المسمى غير موجود.
[EPERM]
معرف المستخدم الفعال لا يتطابق مع مالك الملف ومعرف المستخدم الفعال ليس المستخدم الخارق.
[ENOTDIR]
أحد مكونات بادئة المسار ليس دليلًا.
[EACCES]
تم رفض إذن البحث في مكون من مكونات بادئة المسار.
[EINVAL]
تم تعيين بت في الوسيطة flag غير معرفة لهذه المكالمة النظامية، أو تم تعيين كل من بت علامة ATTR_CREATE و ATTR_REPLACE.
[EFAULT]
Path أو attrname أو attrvalue يشير إلى خارج مساحة العنوان المخصصة للعملية.
[ELOOP]
تضمن البحث عن اسم المسار عددًا كبيرًا جدًا من الروابط الرمزية.
[ENAMETOOLONG]
طول path يتجاوز {MAXPATHLEN}، أو مكون اسم المسار أطول من {MAXNAMELEN}.

ستفشل attr_setf إذا:

[ENOATTR]
اسم السمة المعطى غير مرتبط بكائن نظام الملفات المشار إليه وتم تعيين بت علامة ATTR_REPLACE.
[E2BIG]
قيمة السمة المعطاة كبيرة جدًا، وتتجاوز الحد الأقصى المسموح به لقيمة السمة.
[EEXIST]
اسم السمة المعطى مرتبط بالفعل بكائن نظام الملفات المشار إليه وتم تعيين بت علامة ATTR_CREATE.
[EINVAL]
تم تعيين بت في الوسيطة flag غير معرفة لهذه المكالمة النظامية، أو تم تعيين كل من بت علامة ATTR_CREATE و ATTR_REPLACE، أو fd يشير إلى مقبس، وليس ملفًا.
[EFAULT]
Attrname أو attrvalue يشير إلى خارج مساحة العنوان المخصصة للعملية.
[EBADF]
Fd لا يشير إلى واصف صالح.

التشخيص

عند النجاح، يتم إرجاع صفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno بشكل مناسب.
