attr_list(3)

الحزمة: attr

التراخيص: LGPL

ATTR_LIST(3) واجهة برمجة تطبيقات التوافق مع XFS ATTR_LIST(3)

الاسم

attr_list, attr_listf - سرد أسماء السمات المستخدمة لكائن نظام الملفات

C ملخص

#include <attr/attributes.h>

int attr_list (const char ∗path, char ∗buffer, 
               const int buffersize, int flags,
               attrlist_cursor_t ∗cursor);
int attr_listf (int fd, char ∗buffer, 
                const int buffersize, int flags,
                attrlist_cursor_t ∗cursor);

الوصف

توفر الدوال attr_list و attr_listf طريقة لسرد السمات الموجودة لكائن نظام الملفات.

Path يشير إلى اسم مسار لكائن نظام ملفات، و fd يشير إلى واصف الملف المرتبط بملف. سيتم ملء buffer بهيكل يصف على الأقل جزءًا من السمات المرتبطة بكائن نظام الملفات المحدد. سيتم الكتابة فوق buffer بهيكل attrlist_t يحتوي على قائمة بالسمات المرتبطة بكائن نظام الملفات هذا، بحد أقصى buffersize بايت. يجب أن يكون buffer كبيرًا بما يكفي لاستيعاب هياكل البيانات المناسبة بالإضافة إلى اسم سمة واحد على الأقل بحجم أقصى، ولكن لا يمكن أن يكون طوله أكثر من ATTR_MAX_VALUELEN (حالياً 64 كيلوبايت) بايت.

تشمل محتويات هيكل attrlist_t الأعضاء التالية:

int32_t al_count; /∗ عدد الإدخالات في attrlist ∗/
int32_t al_more; /∗ T/F: المزيد من السمات (قم باستدعاء النظام مرة أخرى) ∗/
int32_t al_offset[1]; /∗ إزاحات البايت للسمات [متغير الحجم] ∗/

يعرض الحقل al_count عدد السمات الممثلة في هذا المخزن المؤقت، وهو أيضًا عدد العناصر في مصفوفة al_offset. سيكون الحقل al_more غير صفري إذا أدى استدعاء attr_list آخر إلى المزيد من السمات. تحتوي مصفوفة al_offset على إزاحة البايت داخل buffer للهيكل الذي يصف كل سمة، وهو هيكل attrlist_ent_t. سيساعد الماكرو ATTR_ENTRY(buffer, index) في فك تشفير القائمة. يأخذ مؤشرًا إلى buffer و index إلى مصفوفة al_offset ويعيد مؤشرًا إلى هيكل attrlist_ent_t المقابل.

تشمل محتويات هيكل attrlist_ent_t الأعضاء التالية:

uint32_t a_valuelen; /∗ عدد البايتات في قيمة السمة ∗/
char a_name[]; /∗ اسم السمة (ينتهي بـ NULL) ∗/

يُظهر الحقل a_valuelen حجم قيمة السمة المرتبطة بالاسم المخزن في الحقل a_name بالبايت. الاسم هو سلسلة نصية تنتهي بـ NULL.

لاحظ أنه لا يمكن الحصول على قيمة السمة من خلال هذه الواجهة، ويجب استخدام استدعاء attr_get للحصول على القيمة. تخبر واجهة attr_list العملية المستدعية حجم المخزن المؤقت الذي يجب أن تمتلكه للحصول على قيمة السمة.

يمكن أن يحتوي الوسيط flags على الرموز التالية مدمجة ببعضها باستخدام OR:

ATTR_ROOT
سرد السمات الموجودة في مساحة عنوان الجذر، وليس في مساحة عنوان المستخدم. (محدود للاستخدام من قبل المستخدم الخارق فقط)
ATTR_DONTFOLLOW
لا تتبع الروابط الرمزية عند حل path في استدعاء دالة attr_list. الافتراضي هو تتبع الروابط الرمزية.

الوسيط cursor هو مؤشر إلى هيكل بيانات غير شفاف يستخدمه النواة لتتبع موضع العملية المستدعية في قائمة السمات. العمليات الوحيدة الصالحة على cursor هي تمريره إلى استدعاء دالة attr_list أو تعيين قيمته إلى صفر. يجب تعيينه إلى صفر قبل استدعاء attr_list الأول. لاحظ أن التطبيقات متعددة الخيوط قد تحتفظ بأكثر من cursor واحد لخدمة سياقات متعددة، أي أن استدعاء attr_list "آمن للخيوط" (thread-safe).

ستفشل attr_list إذا كان واحد أو أكثر مما يلي صحيحًا:

[ENOENT]
الملف المسمى غير موجود.
[EPERM]
معرف المستخدم الفعال لا يتطابق مع مالك الملف ومعرف المستخدم الفعال ليس مستخدمًا خارقًا.
[ENOTDIR]
أحد مكونات بادئة المسار ليس دليلاً.
[EACCES]
تم رفض إذن البحث في مكون من بادئة المسار.
[EINVAL]
تم تعيين بت في الوسيط flag غير معرف لهذا الاستدعاء النظامي، أو كان المخزن المؤقت صغيرًا جدًا أو كبيرًا جدًا.
[EFAULT]
يشير Path أو buffer خارج مساحة العنوان المخصصة للعملية، أو buffer أو bufsize ليسا متوائمين 32 بت.
[ELOOP]
تضمن بحث اسم المسار الكثير من الروابط الرمزية.
[ENAMETOOLONG]
طول path يتجاوز {MAXPATHLEN}، أو مكون اسم المسار أطول من {MAXNAMELEN}.
[ENOATTR]
السمة attribute غير موجودة لهذا الملف.

ستفشل attr_listf إذا:

[EINVAL]
تم تعيين بت في الوسيط flag غير معرف لهذا الاستدعاء النظامي، أو يشير fd إلى مقبس، وليس ملفًا، أو كان المخزن المؤقت صغيرًا جدًا أو كبيرًا جدًا.
[EFAULT]
يشير Path أو buffer خارج مساحة العنوان المخصصة للعملية، أو buffer أو bufsize ليسا متوائمين 32 بت.
[EBADF]
Fd لا يشير إلى واصف صالح.

التشخيص

عند الانتهاء بنجاح، يتم إرجاع القيمة 0. بخلاف ذلك، يتم إرجاع القيمة -1 ويتم تعيين errno للإشارة إلى الخطأ.
