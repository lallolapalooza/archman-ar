attr_multi(3)

Name

attr_multi - Extended attributes (multiple values)

Description

The attr_multi utility is used to get, set, or remove extended attributes on files or directories. Unlike the standard attr command, attr_multi can handle multiple values for a single attribute name.

Usage

attr_multi [options] <command> <attribute_name> <file>

attr_multi [options] <command> <attribute_name> <value> ... <file>

Commands

  • get: Retrieve the values of an attribute.
  • set: Set the values of an attribute.
  • remove: Remove an attribute and all its values.

Options

  • -n, --namespace <namespace>: Specify the attribute namespace (e.g., user, system, security).
  • -h, --help: Display help message.
  • -v, --version: Display version information.

Examples

To set multiple user-defined attributes for a file:

attr_multi set user.myattr value1 value2 value3 my_file

To get all values of a user-defined attribute:

attr_multi get user.myattr my_file

To remove a user-defined attribute and all its values:

attr_multi remove user.myattr my_file
