aa_puts(3)

الحزمة: aalib

التراخيص: LGPL-2.0-or-later

aa_puts(3) دليل وظائف المكتبة aa_puts(3)

الاسم

aa_puts - إخراج سلسلة نصية إلى مخازن الإخراج الخاصة بـ AA-lib.

الملخص

#include <aalib.h>

void aa_puts
(
aa_context *c,
int x,
int y,
enum aa_attribute attr,
const char *s
);

المعلمات

aa_context *c
يحدد سياق AA-lib للعمل عليه.
int x
إحداثي X للحرف الأول.
int y
إحداثي Y للحرف الأول.
enum aa_attribute attr
السمة المراد استخدامها.

القيم الممكنة لـ enum aa_attribute هي كما يلي:

AA_NORMAL
أحرف عادية.
AA_DIM
أحرف داكنة.
AA_BOLD
أحرف ساطعة.
AA_BOLDFONT
أحرف مرسومة بخط عريض.
AA_REVERSE
أحرف معكوسة (أسود على أبيض).
AA_SPECIAL
ارسم الأحرف بطريقة مرئية بسهولة على الشاشة. يعتمد الرسم الدقيق على برنامج التشغيل، ولكن يجب استخدام هذه الوضعية لإخراج نصوص تريد جعلها مرئية بسهولة في الصورة.
const char *s
السلسلة النصية المراد إخراجها.

الوصف

إخراج السلسلة النصية المعطاة إلى مخازن الإخراج الخاصة بـ AA-lib. لرؤية التأثير، تحتاج أيضًا إلى استدعاء aa_flush.
