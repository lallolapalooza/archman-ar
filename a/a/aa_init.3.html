aa_init(3)

الحزمة: aalib

التراخيص: LGPL-2.0-or-later

aa_init(3) دليل وظائف المكتبة aa_init(3)

الاسم

aa_init - فتح شاشة الإخراج لمكتبة AA-lib.

الملخص

#include <aalib.h>

aa_context *aa_init
(
const struct aa_driver *driver,
const struct aa_hardware_params *defparams,
const void *driverdata
);

المعاملات

const struct aa_driver *driver
المشغل الذي تريد استخدامه. تتوفر المشغلات في المصفوفة aa_drivers المنتهية بـ NULL.
const struct aa_hardware_params *defparams
معلمات الجهاز التي تريدها. استخدم aa_defparams للقيم الافتراضية.
const void *driverdata
يتم تمرير هذا المؤشر مباشرة إلى المشغل لتحديد معلمات إضافية تعتمد على المشغل.

الوصف

هذه هي الدالة الأساسية لتهيئة AA-lib. تسمح بتحكم أفضل في العملية مقارنة بالدالة aa_autoinit الأسهل في الاستخدام.

يجب على كل برنامج AA-lib أن يستدعي aa_parseoptions قبل أول استدعاء لـ aa_init.

المُرجعات

مؤشر إلى سياق AA-lib جديد أو NULL إذا فشلت العملية.
