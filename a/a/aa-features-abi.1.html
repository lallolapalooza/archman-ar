الحزمة: apparmor

التراخيص: GPL-2.0-only, LGPL-2.0-only, LGPL-2.1-only

AA-FEATURES-ABI(1) AppArmor AA-FEATURES-ABI(1)

الاسم

aa-features-abi - استخراج، التحقق من صحة، والتلاعب بـ ABIs لميزات AppArmor

ملخص

aa-features-abi [خيارات] <المصدر> [خيارات الإخراج]

الوصف

يُستخدم aa-features-abi لاستخراج features abi وإخراجه إما إلى stdout أو إلى ملف محدد. يجب تحديد خيار SOURCE. إذا لم يتم تحديد خيار إخراج، يتم كتابة features abi إلى stdout.

الخيارات

aa-features-abi يقبل الوسائط التالية:

-h, --help
عرض دليل استخدام موجز.
-d, --debug
عرض الرسائل مع معلومات التصحيح
-v, --verbose
عرض الرسائل مع الإحصائيات

المصدر

-x, --extract
استخراج features abi للنواة
-f FILE, --file=FILE
تحميل features abi من FILE وإرساله إلى خيارات الإخراج.

خيارات الإخراج

--stdout
كتابة features abi إلى stdout، هذا هو الخيار الافتراضي إذا لم يتم تحديد خيار إخراج.
-w FILE, --write FILE
كتابة features abi إلى FILE.

الأخطاء

إذا وجدت أي أخطاء، فيرجى الإبلاغ عنها على https://gitlab.com/apparmor/apparmor/-/issues.

انظر أيضاً

apparmor(7)، apparmor.d(5)، aa_features(3)، و https://wiki.apparmor.net.
