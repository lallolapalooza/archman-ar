aa_query_label(2)

الحزمة: apparmor

التراخيص: GPL-2.0-only, LGPL-2.0-only, LGPL-2.1-only

AA_QUERY_LABEL(2) AppArmor AA_QUERY_LABEL(2)

الاسم

aa_query_label - الاستعلام عن إذن الوصول المرتبط بتسمية

aa_query_file_path, aa_query_file_path_len - الاستعلام عن أذونات الوصول لمسار ملف

aa_query_link_path, aa_query_link_path_len - الاستعلام عن أذونات الوصول لمسار رابط

ملخص

#include <sys/apparmor.h>

int aa_query_label(uint32_t mask, char *query, size_t size, int *allowed, int *audited);

int aa_query_file_path(uint32_t mask, const char *label, size_t label_len, const char *path, int *allowed, int *audited);

int aa_query_file_path_len(uint32_t mask, const char *label, size_t label_len, const char *path, size_t path_len, int *allowed, int *audited);

int aa_query_link_path(const char *label, const char *target, const char *link, int *allowed, int *audited);

int aa_query_link_path_len(const char *label, size_t label_len, const char *target, size_t target_len, const char *link, size_t link_len, int *allowed, int *audited);

اربط مع -lapparmor عند التصريف.

الوصف

تقوم الدالة aa_query_label بجلب الأذونات الحالية الممنوحة بواسطة التسمية المحددة في سلسلة الاستعلام.

الاستعلام هو استعلام بتنسيق ثنائي خام، يحتوي على التسمية واستعلام الإذن. يتم تفسير القيمتين allowed و audited المُرجعتين كقيم منطقية، تشير ببساطة إلى ما إذا كان الاستعلام مسموحًا به وما إذا كان يتم تدقيقه.

قناع سلسلة الاستعلام هو قناع بت للأذونات المراد الاستعلام عنها وهو يعتمد على نوع الفئة (انظر إدخالات AA_CLASS_xxx في sys/apparmor.h).

تنسيق سلسلة الاستعلام يعتمد أيضًا على AA_CLASS ولذلك ينبغي عادةً استخدام دوال المساعدة aa_query_xxx بدلاً من استخدام aa_query_label مباشرة. إذا تم استخدام الواجهة مباشرة، يجب أن تحتوي سلسلة الاستعلام على رأس AA_QUERY_CMD_LABEL_SIZE والذي ستستخدمه aa_query_label.

دوال aa_query_file_path و aa_query_file_path_len هي دوال مساعدة تقوم بتجميع استعلام مسار ملف مُنسق بشكل صحيح للدالة aa_query_label. التسمية هي تسمية apparmor صالحة كما يتم إرجاعها بواسطة aa_splitcon مع كون label_len هو طول التسمية. المسار هو أي مسار نظام ملفات صالح للاستعلام عن الأذونات له. بالنسبة لمتغير aa_query_file_path_len، تحدد المعلمة path_len عدد البايتات في المسار لاستخدامها كجزء من الاستعلام.

دوال aa_query_link_path و aa_query_link_path_len هي دوال مساعدة تقوم بتجميع استعلام مسار رابط مُنسق بشكل صحيح للدالة aa_query_label. تحدد المعلمات link_len و target_len عدد البايتات في الرابط و الهدف لاستخدامها كجزء من الاستعلام.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0، وتحتوي المعلمتان allowed و audited على قيمة منطقية 0 غير مسموح بها/مدققة أو 1 مسموح بها/مدققة. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno(3) بشكل مناسب.

الأخطاء

EINVAL
القناع mask المطلوب فارغ.

حجم size الاستعلام أقل من حجم الاستعلام AA_QUERY_CMD_LABEL_SIZE

وحدة نواة apparmor ليست محملة أو واجهة الوصول إلى واجهة النواة غير متاحة

ENOMEM
كانت الذاكرة غير كافية.
EACCES
تم رفض الوصول إلى التسمية المحددة أو واجهة الاستعلام.
ENOENT
التسمية المحددة غير موجودة أو غير مرئية.
ERANGE
بيانات التقييد كبيرة جدًا بحيث لا تتناسب مع المخزن المؤقت المقدم.

ملاحظات

أذونات التسمية المُرجعة صالحة فقط وقت الاستعلام ويمكن أن تتغير في أي وقت في المستقبل.
