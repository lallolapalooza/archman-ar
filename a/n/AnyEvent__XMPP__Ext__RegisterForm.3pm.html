AnyEvent__XMPP__Ext__RegisterForm(3pm)

الحزمة: perl-anyevent-xmpp

التراخيص: GPL, PerlArtistic

AnyEvent::XMPP::Ext::RegisterForm(3) وثائق Perl من مساهمي المستخدم AnyEvent::XMPP::Ext::RegisterForm(3)

الاسم

AnyEvent::XMPP::Ext::RegisterForm - معالج نموذج التسجيل داخل النطاق

الملخص

my $con = AnyEvent::XMPP::Connection->new (...);
...
$con->do_in_band_register (sub {
   my ($form, $error) = @_;
   if ($error) { print "ERROR: ".$error->string."\n" }
   else {
      if ($form->type eq 'simple') {
         if ($form->has_field ('username') && $form->has_field ('password')) {
            $form->set_field (
               username => 'test',
               password => 'qwerty',
            );
            $form->submit (sub {
               my ($form, $error) = @_;
               if ($error) { print "SUBMIT ERROR: ".$error->string."\n" }
               else {
                  print "Successfully registered as ".$form->field ('username')."\n"
               }
            });
         } else {
            print "Couldn't fill out the form: " . $form->field ('instructions') ."\n";
         }
      } elsif ($form->type eq 'data_form' {
         my $dform = $form->data_form;
         ... fill out the form $dform (of type AnyEvent::XMPP::DataForm) ...
         $form->submit_data_form ($dform, sub {
            my ($form, $error) = @_;
            if ($error) { print "DATA FORM SUBMIT ERROR: ".$error->string."\n" }
            else {
               print "Successfully registered as ".$form->field ('username')."\n"
            }
         })
      }
   }
});

الوصف

تمثل هذه الوحدة نموذج تسجيل داخل النطاق يمكن ملؤه وتقديمه.

يمكنك الحصول على نسخة من هذه الفئة فقط عن طريق طلبها من اتصال AnyEvent::XMPP::Connection عن طريق استدعاء طريقة "request_inband_register_form".

new (%args)
عادةً ما يأخذ المُنشئ وسيطات لا شيء باستثناء عندما تريد إنشاء نموذج إجابة، حينها تستدعي المُنشئ هكذا:

إذا كان لديك حقول نموذج قديمة كمرجع تجزئة في $filled_legacy_form:

AnyEvent::XMPP::Ext::RegisterForm (
   legacy_form => $filled_legacy_form,
   answered => 1
);

إذا كان لديك نموذج بيانات في $answer_data_form:

AnyEvent::XMPP::Ext::RegisterForm (
   legacy_form => $answer_data_form,
   answered => 1
);
try_fillout_registration ($username, $password)
تحاول هذه الطريقة ملء نموذج تم استلامه من الطرف الآخر. تقوم بإدخال اسم المستخدم وكلمة المرور وتعيد كائن AnyEvent::XMPP::Ext::RegisterForm جديدًا وهو نموذج الإجابة.

ملاحظة: هذه الوظيفة مجرد تخمين لملء نموذج للتسجيل التلقائي، ولكنها قد تفشل إذا كانت النماذج أكثر تعقيدًا ولديها حقول مطلوبة لا نعرفها.

التسجيل بدون تفاعل المستخدم غير ممكن نظريًا لأن النماذج يمكن أن تكون مختلفة من خادم لآخر وتتطلب معلومات مختلفة. يرجى أيضًا إلقاء نظرة على XEP-0077.

لاحظ أنه إذا كان النموذج أكثر تعقيدًا، فلن تعمل هذه الطريقة ولا يضمن أن يكون التسجيل ناجحًا.

استدعاء هذه الطريقة على نموذج إجابة (حيث تُرجع "is_answer_form" قيمة صحيحة) ستكون نتيجتها غير محددة.

is_answer_form
ستعيد هذه الطريقة قيمة صحيحة إذا تم إرجاع هذا النموذج بواسطة، على سبيل المثال، "try_fillout_registration" أو يمثل بشكل عام نموذج إجابة.
is_already_registered
تُرجع هذه الطريقة قيمة صحيحة إذا كانت النماذج المستلمة هي فقط بيانات التسجيل الحالية. أساسًا، تُرجع هذه الطريقة قيمة صحيحة عندما تكون مسجلاً بالفعل في الخادم.
get_legacy_form_fields
تُرجع هذه الطريقة تجزئة حيث تكون المفاتيح هي حقول النموذج القديم كما هو موصوف في مخطط XML لـ XEP-0077.

إذا احتوى النموذج على عقد فقط، فستكون المفاتيح لها قيمة undef.

إذا احتوى النموذج أيضًا على معلومات التسجيل، في حالة ما إذا كانت "is_already_registered" تُرجع قيمة صحيحة، فستحتوي القيم على سلاسل نصية للحقول.

get_data_form
تُرجع هذه الطريقة نموذج AnyEvent::XMPP::Ext::DataForm الذي جاء مع استجابة التسجيل. إذا لم يتم توفير أي نموذج بيانات بواسطة الخادم، تُرجع هذه الطريقة undef.
get_oob
تُرجع هذه الطريقة تجزئة مشابهة لتلك التي تم إرجاعها من الوظيفة "url_from_node" في AnyEvent::XMPP::Ext::OOB. تحتوي على بيانات خارج النطاق لهذا النموذج التسجيل.
answer_form_to_simxml
تُرجع هذه الطريقة قائمة بعقد "simxml".
