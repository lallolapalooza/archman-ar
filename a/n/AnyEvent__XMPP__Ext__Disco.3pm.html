AnyEvent__XMPP__Ext__Disco(3pm)

الحزمة: perl-anyevent-xmpp

التراخيص: GPL, PerlArtistic

AnyEvent::XMPP::Ext::Disco(3) توثيق مساهم من مستخدمي Perl AnyEvent::XMPP::Ext::Disco(3)

الاسم

AnyEvent::XMPP::Ext::Disco - فئة مدير اكتشاف الخدمات لـ XEP-0030

الملخص

use AnyEvent::XMPP::Ext::Disco;
my $con = AnyEvent::XMPP::IM::Connection->new (...);
$con->add_extension (my $disco = AnyEvent::XMPP::Ext::Disco->new);
$disco->request_items ($con, 'romeo@montague.net', undef,
   sub {
      my ($disco, $items, $error) = @_;
      if ($error) { print "ERROR:" . $error->string . "\n" }
      else {
         ... do something with the $items ...
      }
   }
);

الوصف

تمثل هذه الوحدة النمطية فئة مدير اكتشاف الخدمات. تقوم بإنشاء مثيلات لهذه الفئة والحصول على معالج لإرسال طلبات الاكتشاف كما هو موضح في XEP-0030.

كما تسمح لك بإعداد شجرة disco-info/items يمكن للآخرين التنقل فيها وتسمح لك أيضًا بنشر معلومات disco.

هذه الفئة مشتقة من AnyEvent::XMPP::Ext ويمكن إضافتها كامتداد الكائنات التي تنفذ واجهة AnyEvent::XMPP::Extendable أو تشتق منها.

الأساليب

new (%args)
ينشئ معالج disco جديد.
set_identity ($category, $type, $name)
هذا يحدد هوية عقدة المعلومات العليا.

$name اختياري ويمكن أن يكون غير معرف. يرجى ملاحظة أن $name سيتجاوز جميع الأسماء التي تم تعيينها سابقًا! إذا كان $name غير معرف، فلن يتم تجاوز أي اسم تم تعيينه سابقًا.

لقائمة الهويات الصالحة انظر:

http://www.xmpp.org/registrar/disco-categories.html

تقوم هذه الدالة بإزالة الهوية $category و $type.

disable_feature ($uri)
هذه الطريقة تمكن الميزة $uri، حيث يجب أن تكون $uri إحدى القيم من عمود الاسم في: http://www.xmpp.org/registrar/disco-features.html

يمكنك أيضًا تمرير قائمة بالميزات التي تريد تعطيلها إلى "disable_feature"!

request_items ($con, $dest, $node, $cb)
هذه الطريقة ترسل طلب عناصر إلى كيان JID $from. $node هو العقدة الاختيارية لإرسال الطلب إليها، والتي يمكن أن تكون غير معرفة.

$con يجب أن يكون مثيلاً لـ AnyEvent::XMPP::Connection أو فئة مشتقة منه. سيتم استدعاء رد الاتصال $cb عند عودة الطلب مع 3 وسائط: معالج disco، كائن AnyEvent::XMPP::Ext::Disco::Items (أو غير معرف)، وكائن AnyEvent::XMPP::Error::IQ عند حدوث خطأ وعدم استلام أي عناصر.

مهلة الطلب هي مهلة IQ للاتصال $con.

$disco->request_items ($con, 'a@b.com', undef, sub {
   my ($disco, $items, $error) = @_;
   die $error->string if $error;
   # do something with the items here ;_)
});
request_info ($con, $dest, $node, $cb)
هذه الطريقة ترسل طلب معلومات إلى كيان JID $from. $node هو العقدة الاختيارية لإرسال الطلب إليها، والتي يمكن أن تكون غير معرفة.

$con يجب أن يكون مثيلاً لـ AnyEvent::XMPP::Connection أو فئة مشتقة منه. سيتم استدعاء رد الاتصال $cb عند عودة الطلب مع 3 وسائط: معالج disco، كائن AnyEvent::XMPP::Ext::Disco::Info (أو غير معرف)، وكائن AnyEvent::XMPP::Error::IQ عند حدوث خطأ وعدم استلام أي معلومات.

مهلة الطلب هي مهلة IQ للاتصال $con.

$disco->request_info ($con, 'a@b.com', undef, sub {
   my ($disco, $info, $error) = @_;
   die $error->string if $error;
   # do something with info here ;_)
});
