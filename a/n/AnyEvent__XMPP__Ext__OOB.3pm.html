AnyEvent__XMPP__Ext__OOB(3pm)

الحزمة: perl-anyevent-xmpp

التراخيص: GPL, PerlArtistic

AnyEvent::XMPP::Ext::OOB(3) توثيق مساهمة المستخدم من بيرل AnyEvent::XMPP::Ext::OOB(3)

الاسم

AnyEvent::XMPP::Ext::OOB - بيانات خارج النطاق XEP-0066

الملخص

my $con = AnyEvent::XMPP::Connection->new (...);
$con->add_extension (my $disco = AnyEvent::XMPP::Ext::Disco->new);
$con->add_extension (my $oob = AnyEvent::XMPP::Ext::OOB->new);
$disco->enable_feature ($oob->disco_feature);
$oob->reg_cb (oob_recv => sub {
   my ($oob, $con, $node, $url) = @_;
   if (got ($url)) {
      $oob->reply_success ($con, $node);
   } else {
      $oob->reply_failure ($con, $node, 'not-found');
   }
});
$oob->send_url (
   $con, 'someonewho@wants.an.url.com', "http://nakedgirls.com/marie_021.jpg",
   "Yaww!!! Hot like SUN!",
   sub {
      my ($error) = @_;
      if ($error) { # then error
      } else { # everything fine
      }
   }
)

الوصف

توفر هذه الوحدة واجهة مساعدة للتعامل مع بيانات خارج النطاق كما هو محدد في XEP-0066.

الكائن الذي يتم إنشاؤه يتعامل مع طلبات بيانات خارج النطاق من وإلى الآخرين.

هناك أيضًا بعض الدوال المساعدة المعرفة للحصول على معلومات OOB من عنصر XML على سبيل المثال:

الدوال

url_from_node ($node)
تستخرج هذه الدالة عنوان URL وحقلاً وصفياً اختيارياً من عنصر XML في $node (والذي يجب أن يكون AnyEvent::XMPP::Node).

$node يجب أن يكون عنصر XML الذي يحتوي على العنصر <url> والعنصر <desc> الاختياري (وهو على سبيل المثال عنصر <x xmlns='jabber:x:oob'>)!

(تبحث هذه الطريقة في كلا الفضائين الاسمين، jabber:x:oob و jabber:iq:oob، للعناصر <url> و <desc>).

تقوم بإرجاع مرجع هاش يجب أن يحتوي على البنية التالية:

{
   url  => "http://someurl.org/mycoolparty.jpg",
   desc => "That was a party!",
}

إذا لم يتم العثور على شيء، فإن هذه الطريقة لا ترجع شيئاً (undef).

الطرق

new ()
هذا هو المنشئ، لا يأخذ أي حجج إضافية.
reply_success ($con, $node)
ترد هذه الطريقة على مرسل OOB بأن عنوان URL تم استلامه بنجاح.

$con و $node هما وسيطات $con و $node لحدث "oob_recv" الذي تريد الرد عليه.

reply_failure ($con, $node, $type)
ترد هذه الطريقة على المرسل بأنه إما تم رفض النقل أو لم يتم العثور عليه.

إذا تم رفض النقل، فيجب عليك تعيين $type إلى 'reject'، وإلا يجب أن يكون $type 'not-found'.

$con و $node هما وسيطات $con و $node لحدث "oob_recv" الذي تريد الرد عليه.

send_url ($con, $jid, $url, $desc, $cb)
ترسل هذه الطريقة طلباً لنقل ملف خارج النطاق إلى $jid. $url هو عنوان URL الذي يجب على الطرف الآخر تنزيله. $desc هو سلسلة وصف اختيارية (قابلة للقراءة من قبل الإنسان) للملف المشار إليه بالعنوان ويمكن أن يكون undef إذا كنت لا ترغب في نقل أي وصف.

$cb هو رد اتصال سيتم استدعاؤه بمجرد نجاح النقل.

الوسيط الأول لرد الاتصال سيكون إما undef في حالة النجاح أو 'reject' عندما يرفض الطرف الآخر الملف أو 'not-found' إذا كان الطرف الآخر غير قادر على تنزيل الملف.

الأحداث

يمكن التسجيل لهذه الأحداث باستخدام "reg_cb":

oob_recv => $con, $node, $url
يتم إنشاء هذا الحدث كلما أراد شخص ما إرسال ملف بيانات خارج النطاق إليك. $url هو مرجع هاش مثل الذي تعيده "url_from_node".

$con هو AnyEvent::XMPP::Connection (أو AnyEvent::XMPP::IM::Connection) الذي تم استقبال البيانات منه.

$node هو AnyEvent::XMPP::Node لطلب IQ، يمكنك الحصول على JID المرسل من السمة 'from' الخاصة به.

إذا قمت بجلب الملف بنجاح، فيجب عليك استدعاء "reply_success". إذا كنت تريد رفض الملف أو لم تتمكن من الحصول عليه، فاستدعِ "reply_failure".
