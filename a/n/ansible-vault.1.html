NAME

ansible-vault

encrypt and decrypt Ansible Vault-encrypted files

SYNOPSIS

ansible-vault [OPTIONS] [SUBCOMMAND]

DESCRIPTION

The ansible-vault command provides commands to create, edit, encrypt, and decrypt variable files and inventory files.

Ansible Vault is a powerful feature of Ansible that allows you to securely store sensitive data such as passwords, keys, and certificates. It uses a symmetric encryption scheme. You can encrypt individual files or use Vault to encrypt specific values within larger files.

The following subcommands are available:

  • ansible-vault create FILE

    Creates a new encrypted file. It will prompt you for a password to encrypt the file with.

  • ansible-vault decrypt FILE

    Decrypts a previously encrypted file. It will prompt you for the password used to encrypt the file.

  • ansible-vault edit FILE

    Opens an encrypted file in your default editor. The file will be decrypted in memory, and when you save and close the file, the changes will be encrypted back into the file.

  • ansible-vault encrypt FILE

    Encrypts a previously unencrypted file. It will prompt you for a password to encrypt the file with.

  • ansible-vault rekey FILE

    Changes the password of an encrypted file. It will prompt you for the old password and then the new password.

  • ansible-vault view FILE

    Decrypts and displays the contents of an encrypted file. It will prompt you for the password used to encrypt the file.

COMMON OPTIONS

--vault-password-file FILE
The password file to use for the Vault password. This option is mutually exclusive with --ask-vault-pass.
--ask-vault-pass
Ask for the vault password.

ACTIONS

ask for vault password
