AnyEvent__Impl__UV(3pm)

الحزمة: perl-anyevent

التراخيص: PerlArtistic, GPL

AnyEvent::Impl::UV(3) وثائق مساهمة المستخدم من بيرل AnyEvent::Impl::UV(3)

الاسم

AnyEvent::Impl::UV - موصل AnyEvent لـ UV

الملخص

use AnyEvent;
use UV;

# يتم تحميل هذه الوحدة تلقائيًا حسب الحاجة

الوصف

توفر هذه الوحدة دعمًا شفافًا لـ AnyEvent. لا يتعين عليك القيام بأي شيء لجعل UV يعمل مع AnyEvent سوى تحميل UV قبل إنشاء أول مراقب AnyEvent.
