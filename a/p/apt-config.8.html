Name

apt-config - configuration settings for APT

Synopsis

apt-config [-h|--help] [-v|--version] [-c file|--config-file file] [-o option|--option option] command

Description

apt-config is a command-line tool to display APT configuration settings. It reads APT configuration files and displays the values of specified configuration options. This tool is primarily intended for debugging and understanding APT's configuration behavior.

Configuration files

APT reads its configuration from a list of files. The default locations are /etc/apt/sources.list and /etc/apt/sources.list.d/, /etc/apt/apt.conf and /etc/apt/apt.conf.d/.

APT configuration files are simple text files. Each file can contain a number of configuration directives. A directive has the form: 

                    APT::Setting::Path "value";

Comments can be introduced with a double slash (//) and extend to the end of the line.

The configuration system supports a hierarchical structure. For example, the option APT::Get::Assume-Yes can be set in a configuration file by using the directive: 

                    APT::Get::Assume-Yes "true";

The configuration system supports variables, and includes support for regular expressions. It also supports the possibility to include other configuration files or directories using the directive: 

                    #include "/etc/apt/myconfig.conf";
                    #include "/etc/apt/myconfig.d/";

The configuration system supports a special syntax for specifying parameters to APT's acquire method. This is done using a hash syntax, for example: 

                    Acquire::http::Proxy "http://proxyserver:8080";

This example sets the proxy server to be used for HTTP downloads.

Options

-h, --help
Show a help message and exit.
-v, --version
Show version information and exit.
-c file, --config-file file
Specify a configuration file to load. This option can be specified multiple times to load multiple configuration files.
-o option, --option option
Specify an arbitrary configuration option. This option can be specified multiple times to specify multiple options. The format is " APT::Setting=value ".

Commands

show section
Display all configuration options under the specified section. For example, apt-config show APT::Get will display all options under APT::Get. If no section is specified, all configuration options will be displayed.
get option
Display the value of the specified configuration option. For example, apt-config get APT::Get::Assume-Yes will display the value of APT::Get::Assume-Yes.

See also

apt.conf(5)

الاسم

apt-config - إعدادات التكوين لـ APT

الملخص

apt-config [-h|--help] [-v|--version] [-c ملف|--config-file ملف] [-o خيار|--option خيار] أمر

الوصف

apt-config هو أداة سطر أوامر لعرض إعدادات تكوين APT. تقوم بقراءة ملفات تكوين APT وعرض قيم خيارات التكوين المحددة. هذه الأداة مخصصة بشكل أساسي لتصحيح الأخطاء وفهم سلوك تكوين APT.

ملفات الإعداد

يقرأ APT تكوينه من قائمة ملفات. المواقع الافتراضية هي /etc/apt/sources.list و /etc/apt/sources.list.d/ و /etc/apt/apt.conf و /etc/apt/apt.conf.d/.

ملفات تكوين APT هي ملفات نصية بسيطة. يمكن لكل ملف أن يحتوي على عدد من تعليمات التكوين. يتخذ التوجيه الشكل: 

                    APT::Setting::Path "value";

يمكن تقديم التعليقات باستخدام شرطتين مائلتين مزدوجتين (//) وتمتد إلى نهاية السطر.

يدعم نظام التكوين بنية هرمية. على سبيل المثال، يمكن تعيين الخيار APT::Get::Assume-Yes في ملف تكوين باستخدام التوجيه: 

                    APT::Get::Assume-Yes "true";

يدعم نظام التكوين المتغيرات، ويتضمن دعمًا للتعبيرات العادية. كما يدعم إمكانية تضمين ملفات تكوين أخرى أو مجلدات باستخدام التوجيه: 

                    #include "/etc/apt/myconfig.conf";
                    #include "/etc/apt/myconfig.d/";

يدعم نظام التكوين بناء جملة خاص لتحديد معلمات طريقة الحصول الخاصة بـ APT. يتم ذلك باستخدام بناء جملة الهاش، على سبيل المثال: 

                    Acquire::http::Proxy "http://proxyserver:8080";

يقوم هذا المثال بتعيين خادم البروكسي الذي سيتم استخدامه لتنزيلات HTTP.

الخيارات

-h, --help
عرض رسالة مساعدة والخروج.
-v, --version
عرض معلومات الإصدار والخروج.
-c ملف, --config-file ملف
تحديد ملف تكوين لتحميله. يمكن تحديد هذا الخيار عدة مرات لتحميل ملفات تكوين متعددة.
-o خيار, --option خيار
تحديد خيار تكوين اختياري. يمكن تحديد هذا الخيار عدة مرات لتحديد خيارات متعددة. الصيغة هي " APT::Setting=value ".

الأوامر

show قسم
عرض جميع خيارات التكوين تحت القسم المحدد. على سبيل المثال، apt-config show APT::Get سيعرض جميع الخيارات تحت APT::Get. إذا لم يتم تحديد قسم، فسيتم عرض جميع خيارات التكوين.
get خيار
عرض قيمة خيار التكوين المحدد. على سبيل المثال، apt-config get APT::Get::Assume-Yes سيعرض قيمة APT::Get::Assume-Yes.
