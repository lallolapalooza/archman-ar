الاسم

apptainer-oci-create - إنشاء حاوية من دليل حزمة (للمستخدم الجذر فقط)

الملخص

apptainer oci create -b [خيارات الإنشاء...]

الوصف

استدعاء عملية الإنشاء لإنشاء مثيل حاوية من دليل حزمة OCI

خيارات

-b, --bundle="" تحديد مسار حزمة OCI (مطلوب)

--empty-process[=false] تشغيل الحاوية دون تنفيذ عملية الحاوية (مثل: للحاوية POD)

-h, --help[=false] المساعدة لـ create

--log-format="kubernetes" تحديد تنسيق ملف السجل. التنسيقات المتاحة هي basic، kubernetes و json

-l, --log-path="" تحديد مسار ملف السجل

--pid-file="" تحديد ملف PID

-s, --sync-socket="" تحديد مسار مقبس يونكس لمزامنة الحالة

مثال

  $ apptainer oci create -b ~/bundle mycontainer
