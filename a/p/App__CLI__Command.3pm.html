App__CLI__Command(3pm)

الحزمة: perl-app-cli

التراخيص: GPL, PerlArtistic

App::CLI::Command(3) وثائق مساهمة من مستخدمي Perl App::CLI::Command(3)

الاسم

App::CLI::Command - الفئة الأساسية لأوامر App::CLI

الملخص

package MyApp::List;
use base qw(App::CLI::Command);
use constant options => (
    'verbose'   => 'verbose',
    'n|name=s'  => 'name',
);
sub run {
    my ( $self, $arg ) = @_;
    print "verbose" if $self->{verbose};
    my $name = $self->{name}; # الحصول على الوسيط بعد الخيار الطويل --name
    # أي شيء تريد أن يفعله هذا الأمر
}
# انظر App::CLI للحصول على معلومات حول كيفية استدعاء الأوامر الفرعية (أو الأوامر).

الوصف

subcommand()

return old genre subcommand of $self;

cascading()

إرجاع مثيل للأمر الفرعي المتتالي المستدعى إذا كان مدرجًا في أوامرك الفرعية الثابتة.

cascadable()

إرجاع اسم حزمة الأمر الفرعي إذا كان الأمر الفرعي المستدعى موجودًا في أوامرك الفرعية الثابتة، وإلا، إرجاع "undef".

app

إرجاع الكائن الذي يشير إلى التطبيق الحالي.

brief_usage ($file)

عرض استخدام موجز من سطر واحد للكائن الأمر. اختياريًا، يمكن توفير ملف لاستخراج الاستخدام من POD.

usage ($want_detail)

عرض الاستخدام. إذا كان $want_detail صحيحًا، فسيتم عرض قسم "DESCRIPTION" أيضًا.

loc_text $text

ترجمة النص الأساسي (بتنسيق) في $text وإرجاع النسخة المترجمة.

filename

إرجاع اسم الملف لوحدة الأمر.
