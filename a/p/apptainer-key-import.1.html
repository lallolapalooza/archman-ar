الاسم

apptainer-key-import - استيراد مفتاح محلي إلى مجموعة المفاتيح المحلية أو العالمية

الملخص

apptainer key import [خيارات الاستيراد...]

الوصف

يسمح أمر 'key import' بإضافة مفتاح إلى مجموعة المفاتيح المحلية أو العالمية الخاصة بك
من ملف محدد.

الخيارات

-g, --global[=false] إدارة مفاتيح عامة عالمية (الاستيراد/السحب/الإزالة مقيدة للمستخدم الجذر أو التثبيت غير المميز فقط)

-h, --help[=false] مساعدة للاستيراد

-d, --keysdir="/build/.apptainer/keys" تعيين مسار دليل مجموعة المفاتيح المحلية، طريقة أخرى هي تعيين متغير البيئة 'APPTAINER_KEYSDIR'

--new-password[=false] تعيين كلمة مرور جديدة للمفتاح الخاص

مثال

  $ apptainer key import ./my-key.asc
  # الاستيراد إلى مجموعة المفاتيح العالمية (للمستخدم الجذر فقط)
  $ apptainer key import --global ./my-key.asc
