apptainer-instance-stop(1)

الحزمة: apptainer

التراخيص: BSD-3-Clause, BSD-3-Clause-LBNL

apptainer(1) apptainer(1)

الاسم

apptainer-instance-stop - إيقاف مثيل مسمى لصورة حاوية معينة

الاختصار

apptainer instance stop [خيارات الإيقاف...] [المثيل]

الوصف

يسمح لك الأمر apptainer instance stop بإيقاف وتنظيف مثيل مسمى قيد التشغيل لصورة حاوية معينة.

الخيارات

-a, --all[=false] إيقاف جميع مثيلات المستخدم

-F, --force[=false] فرض إيقاف المثيل

-h, --help[=false] مساعدة عند الإيقاف

-s, --signal="" الإشارة المرسلة إلى المثيل

-t, --timeout=10 فرض إيقاف المثيلات غير المتوقفة بعد X ثوانٍ

-u, --user="" إذا كان يعمل كـ root، أوقف المثيلات التي تنتمي إلى المستخدم

مثال

  $ apptainer instance start my-sql.sif mysql1
  $ apptainer instance start my-sql.sif mysql2
  $ apptainer instance stop mysql*
  Stopping mysql1 instance of my-sql.sif (PID=23845)
  Stopping mysql2 instance of my-sql.sif (PID=23858)
  $ apptainer instance start my-sql.sif mysql1
  Force instance to shutdown
  $ apptainer instance stop -f mysql1 (may corrupt data)
  Send SIGTERM to the instance
  $ apptainer instance stop -s SIGTERM mysql1
  $ apptainer instance stop -s TERM mysql1
  $ apptainer instance stop -s 15 mysql1
