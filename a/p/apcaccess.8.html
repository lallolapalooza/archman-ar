NAME

apcaccess — obtains status information from an APC UPS unit

SYNOPSIS

apcaccess [ -a ] [ -h ] [ -F file ] [ -I ipaddr ] [ -L ] [ -T ] [ -u ] [ VARIABLE ... ]

DESCRIPTION

apcaccess is a client program for the apcupsd daemon. It interrogates the apcupsd daemon and prints out the status information it receives.

By default, apcaccess contacts the apcupsd daemon running on the local machine. However, you can specify a remote host to query using the -I ipaddr option.

If you supply one or more VARIABLE names on the command line, apcaccess will query the daemon for just those variables, and print only the requested values.

If the -F file option is used, apcaccess will read the list of variables to query from the specified file.

The -a option will cause apcaccess to display all available variables and their values.

The -L option will cause apcaccess to display the last recorded status report, rather than querying the running apcupsd daemon.

The -T option will cause apcaccess to display the current status report, rather than querying the running apcupsd daemon.

The -u option will cause apcaccess to display the current status report in a "simple" format, rather than the default "detailed" format.

If the -h option is used, apcaccess will print a help message and exit.

STATUS REPORT FORMAT

The output of apcaccess is a series of variable name/value pairs. These are described below. Some variables may not be present, depending on the UPS model and its configuration.

EXAMPLES

To display all available status information from the local apcupsd daemon:

        $ apcaccess

To display only the battery charge percentage and estimated runtime left:

        $ apcaccess BCHARGE TIMELEFT

To display all status information from a remote apcupsd daemon running on host 192.168.0.10:

        $ apcaccess -I 192.168.0.10
