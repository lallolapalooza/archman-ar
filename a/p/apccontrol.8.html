NAME apccontrol - script for handling apcupsd events
SYNOPSIS apccontrol event
DESCRIPTION The apccontrol script is invoked by the apcupsd daemon whenever a specific event occurs. The script is used to perform actions based on these events, such as shutting down the system. The script receives the event name as its first argument. The following events are recognized: onbattery apcupsd generates this event when the UPS switches to battery power due to a utility power outage. Default action -- sends "Power Outage. Utility power has failed." to wall and then continues to run. offbattery apcupsd generates this event when utility power is restored and the UPS is no longer on battery power. Default action -- sends "Power Restored. Utility power is back." to wall and then continues to run. lowonbattery apcupsd generates this event when the battery is low while on battery power. This is determined by the TIMEOUT configuration directive. Default action -- sends "Power Outage. Utility power has failed." to wall and then continues to run. fastrate apcupsd generates this event when the battery charge rate goes above the MAXTRANSFER setting. Default action -- does nothing. slowrate apcupsd generates this event when the battery charge rate goes below the MINTRANSFER setting. Default action -- does nothing. reтиюp apcupsd generates this event when the UPS is on battery power and the time specified by the TIMEOUT configuration directive expires. This configuration directive is not normally used with smart UPSes which would instead rely on the more reliable remaining runtime (MINUTES) or the battery level (BATTERYLEVEL) configuration directives. Default action -- sends "UPS battery runtime limit exceeded. Doing shutdown." to wall and then exits. After this event, apcupsd will immediately generate a doshutdown event. startselftest apcupsd generates this event when it detects the start of a UPS self test. Default action: does nothing. endselftest apcupsd generates this event when it detects the end of a UPS self test. Default action: does nothing.
CUSTOMISING EVENT ACTIONS Do not modify apccontrol directly as it will be overwritten the next time you upgrade to a new release of apcupsd. The recommended way to customise an event action is simply to create an executable program or script file with the same name as the event and put that file in the /etc/apcupsd directory. Now, when the selected event occurs, apccontrol will execute your program or script. If you want apccontrol to also execute its default action for the selected event, your program or script should exit with an exit status of 0 (zero). If you do not want apccontrol to also execute its default action for the selected event, your program or script must exit with an exit status of 99. Be aware that if you completely override the default action, you must ensure the proper shutdown of your computer if this is necessary. Some sample scripts (changeme, commfailure, commok, offbattery and onbattery) that email messages to root instead of broadcasting messages to all logged-in users may be found in /etc/apcupsd after an installation and also in the platforms/etc directory of the apcupsd source code.
FILES /etc/apcupsd/apccontrol
