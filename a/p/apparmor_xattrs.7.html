الحزمة: apparmor

التراخيص: GPL-2.0-only, LGPL-2.0-only, LGPL-2.1-only

APPARMOR_XATTRS(7) AppArmor APPARMOR_XATTRS(7)

الاسم

apparmor_xattrs - مطابقة سمات الملفات الموسعة (xattr) لملفات AppArmor

الوصف

يمكن لملفات AppArmor مطابقة الملفات بشكل شرطي بناءً على وجود وقيمة السمات الموسعة بالإضافة إلى مسار الملف. ينطبق الملف التالي على أي ملف تحت "/usr/bin" حيث تكون السمة الموسعة "security.apparmor" لها القيمة "trusted":

profile trusted /usr/bin/* xattrs=(security.apparmor="trusted") {
        # ...
}

لاحظ أن "security.apparmor" و "trusted" اعتباطيان، ويمكن للملفات المطابقة بناءً على قيمة أي سمة.

قد تحتوي قيمة xattrs أيضًا على تعبير نمطي للمسار:

profile trusted /usr/bin/* xattrs=(user.trust="tier/*") {
        # ...
}

يمكن استخدام الأدوات getfattr(1) و setfattr(1) لعرض وإدارة قيم xattr:

$ setfattr -n 'security.apparmor' -v 'trusted' /usr/bin/example-tool
$ getfattr --absolute-names -d -m - /usr/bin/example-tool
# file: usr/bin/example-tool
security.apparmor="trusted"

تُحدد أولوية كل ملف بواسطة طول المسار، ثم عدد سمات xattrs المحددة. يُفضل المسار الأكثر تحديدًا على مطابقات سمات xattrs:

# أعلى أولوية، أطول مسار.
profile example1 /usr/bin/example-tool {
        # ...
}
# أولوية أقل من المسار الأطول، ولكنها أعلى من قاعدة
# بعدد أقل من مطابقات سمات xattrs.
profile example2 /usr/** xattrs=(
        security.apparmor="trusted"
        user.domain="**"
) {
        # ...
}
# أقل أولوية. نفس طول المسار للملف الثاني، ولكن له
# عدد أقل من مطابقات سمات xattrs.
profile example2 /usr/** {
        # ...
}

تتطلب مطابقة سمات xattrs ميزة النواة التالية:

/sys/kernel/security/apparmor/features/domain/attach_conditions/xattr

قضايا معروفة

لا يمكن لملفات AppArmor حاليًا مطابقة السمات الموسعة بشكل موثوق ذات القيم الثنائية مثل security.evm و security.ima. في المستقبل، قد يكتسب AppArmor القدرة على المطابقة بناءً على وجود سمات معينة مع تجاهل قيمها.
