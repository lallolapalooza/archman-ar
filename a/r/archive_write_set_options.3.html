archive_write_set_options(3)

ARCHIVE_WRITE_OPTIONS(3) دليل وظائف المكتبة ARCHIVE_WRITE_OPTIONS(3)

الاسم

archive_write_set_filter_option، archive_write_set_format_option، archive_write_set_option، archive_write_set_options — وظائف تتحكم في خيارات كتابة الأرشيفات

المكتبة

مكتبة الأرشيف التدفق (libarchive, -larchive)

الملخص

int
archive_write_set_filter_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_write_set_format_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_write_set_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_write_set_options(struct archive *, const char *options);

الوصف

توفر هذه الوظائف طريقة لعملاء libarchive لتكوين وحدات كتابة محددة.

archive_write_set_filter_option(), archive_write_set_format_option()
يحدد خيارًا سيتم تمريره إلى المرشحات المسجلة حاليًا (بما في ذلك مرشحات فك الضغط) أو قارئات التنسيق.

إذا كان option و value كلاهما NULL، فلن تقوم هذه الوظائف بأي شيء وسيتم إرجاع ARCHIVE_OK. إذا كان option NULL ولكن value ليس كذلك، فلن تقوم هذه الوظائف بأي شيء وسيتم إرجاع ARCHIVE_FAILED.

إذا لم يكن module NULL، فسيتم توفير option و value للمرشح أو القارئ المسمى module. ستكون القيمة المرتجعة إما ARCHIVE_OK إذا تم التعامل مع الخيار بنجاح أو ARCHIVE_WARN إذا لم يتعرف الوحدة النمطية على الخيار أو لم يكن من الممكن التعامل معه. إذا لم تكن هناك وحدة نمطية كهذه، فسيتم إرجاع ARCHIVE_FAILED.

إذا كان module NULL، فسيتم توفير option و value لكل وحدة نمطية مسجلة. إذا أعادت أي وحدة نمطية ARCHIVE_FATAL، فسيتم إرجاع هذه القيمة فورًا. بخلاف ذلك، سيتم إرجاع ARCHIVE_OK إذا قبلت أي وحدة نمطية الخيار، و ARCHIVE_FAILED في جميع الحالات الأخرى.

archive_write_set_option()
يستدعي archive_write_set_format_option()، ثم archive_write_set_filter_option(). إذا أعادت أي من الوظيفتين ARCHIVE_FATAL، فسيتم إرجاع ARCHIVE_FATAL فورًا. بخلاف ذلك، سيتم إرجاع القيمة الأكبر بين القيمتين.
archive_write_set_options()
options هي قائمة خيارات مفصولة بفواصل. إذا كان options NULL أو فارغًا، فسيتم إرجاع ARCHIVE_OK فورًا.

للخيارات الفردية أحد الأشكال التالية:

option=value
سيتم توفير زوج الخيار/القيمة لكل وحدة نمطية. الوحدات النمطية التي لا تقبل خيارًا بهذا الاسم ستتجاهله.
option
سيتم توفير الخيار لكل وحدة نمطية بقيمة "1".
!option
سيتم توفير الخيار لكل وحدة نمطية بقيمة NULL.
module:option=value, module:option, module:!option
كما هو مذكور أعلاه، ولكن سيتم توفير الخيار والقيمة المقابلة فقط للوحدات النمطية التي يتطابق اسمها مع module.

خيارات

مرشح b64encode
mode
يتم تفسير القيمة كأرقام ثمانية تحدد وضع الملف.
name
تحدد القيمة اسم الملف.
مرشح bzip2
compression-level
يتم تفسير القيمة كرقم صحيح عشري يحدد مستوى ضغط bzip2. القيم المدعومة هي من 1 إلى 9.
مرشح gzip
compression-level
يتم تفسير القيمة كرقم صحيح عشري يحدد مستوى ضغط gzip. القيم المدعومة هي من 0 إلى 9.
timestamp
تخزين الطابع الزمني. يتم تمكين هذا افتراضيًا.
مرشح lrzip
compression=type
استخدم type كطريقة ضغط. القيم المدعومة هي "bzip2"، "gzipi"، "lzo" (فائق السرعة)، و "zpaq" (الأفضل، بطيء للغاية).
compression-level
يتم تفسير القيمة كرقم صحيح عشري يحدد مستوى ضغط lrzip. القيم المدعومة هي من 1 إلى 9.
مرشح lz4
compression-level
يتم تفسير القيمة كرقم صحيح عشري يحدد مستوى ضغط lz4. القيم المدعومة هي من 0 إلى 9.
stream-checksum
تمكين تدقيق المجموع. يتم تمكين هذا افتراضيًا.
block-checksum
تمكين تدقيق الكتلة. يتم تعطيل هذا افتراضيًا.
block-size
يتم تفسير القيمة كرقم صحيح عشري يحدد حجم كتلة ضغط lz4. القيم المدعومة هي من 4 إلى 7 (افتراضي).
block-dependence
استخدم الكتلة السابقة للكتلة التي يتم ضغطها كقاموس ضغط لتحسين نسبة الضغط. يتم تعطيل هذا افتراضيًا.
مرشح lzop
compression-level
يتم تفسير القيمة كرقم صحيح عشري يحدد مستوى ضغط lzop. القيم المدعومة هي من 1 إلى 9.
