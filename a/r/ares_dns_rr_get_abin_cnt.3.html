NAME

ares_dns_rr_get_abin_cnt - Get the number of a-records in a rr

SYNOPSIS

#include <ares.h>

unsigned int ares_dns_rr_get_abin_cnt(const struct ares_dns_rr *rr);

DESCRIPTION

The ares_dns_rr_get_abin_cnt function is used to get the number of a-records within the given DNS resource record structure. It should be noted that this function is only able to count a-records within the given resource record. The function does not go through any linked lists or any other substructures that may be contained within a resource record. The function simply looks at the data within the resource record itself.

The DNS resource record structure contains various fields depending on the type of the resource record. For a-records, the data field contains a list of IPv4 addresses. This function iterates through that list and counts the number of addresses found.

If the given resource record is not an a-record, the behavior of this function is undefined. It is the responsibility of the caller to ensure that the provided resource record is indeed an a-record before calling this function.

RETURN VALUE

Returns the number of a-records found within the given resource record. If the resource record is not an a-record, the return value is undefined.
