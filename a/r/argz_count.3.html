argz_count(3)

argz_count - count the number of arguments in an argz string

SYNOPSIS

#include <argz.h>

size_t argz_count(const char *argz);

DESCRIPTION

The argz_count function returns the number of arguments in the argz string pointed to by argz.

An argz string is a possibly-empty, null-terminated string which is terminated by two null characters. The arguments are separated by null characters.

RETURN VALUE

On success, argz_count returns the number of arguments in the argz string.

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

argz_count RequiresHook glibc

STANDARDS

The argz functions are not part of any standard.
