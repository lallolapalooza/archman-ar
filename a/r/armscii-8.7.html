NAME

armscii-8 — ARMSCII-8 character set

DESCRIPTION

The ARMSCII-8 character set is a character encoding standard for the Armenian alphabet. It was developed by the Armenian National Center for Scientific Research in Informatics and Automation.

This manual page lists the characters in the ARMSCII-8 character set, along with their decimal, hexadecimal, and Unicode equivalents.
