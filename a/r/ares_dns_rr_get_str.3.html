الوصف

These functions provide functions for creating, inspecting and modifying DNS resource records (RRs) and DNS record collections.

The primary data structure for holding DNS records is ares_dns_record_t. This structure can contain multiple RRs in different sections (answer, authority, additional).

ares_dns_record_rr_add() adds a new RR to the specified section of the DNS record. It allocates memory for the new RR and its data, which must be freed later.

ares_dns_record_rr_cnt() returns the number of RRs in the specified section.

ares_dns_record_rr_get() retrieves a pointer to an RR at the given index within the specified section. This pointer should not be modified directly.

ares_dns_record_rr_get_const() retrieves a constant pointer to an RR at the given index within the specified section. This is safer for inspection.

ares_dns_record_rr_del() removes an RR from the specified section at the given index and frees its associated memory.

ares_dns_rr_get_name(), ares_dns_rr_get_type(), ares_dns_rr_get_class(), and ares_dns_rr_get_ttl() retrieve basic information about an RR.

The ares_dns_rr_set_*() functions are used to set specific fields within an RR. The key argument specifies which field to set, and the subsequent arguments provide the value. The appropriate key should be used based on the RR type and the expected data type.

The ares_dns_rr_get_*() functions are used to retrieve specific fields from an RR. The key argument specifies which field to retrieve. For binary data (_get_bin), the length is returned via the len pointer. For array-like data (like TXT or OPT records), _get_abin_cnt() returns the number of elements, and _get_abin() retrieves a specific element.

ares_dns_rr_set_opt() and related functions handle options within OPT records.

Refer to the enumerations for the available keys and section types.

قيم الإرجاع

Functions that add or modify RRs return ARES_SUCCESS on success, or an error code otherwise.

ares_dns_record_rr_cnt() returns the count of RRs, which can be 0.

ares_dns_record_rr_get() returns a pointer to the RR or NULL if the index is out of bounds.

ares_dns_record_rr_get_const() returns a constant pointer to the RR or NULL if the index is out of bounds.

ares_dns_record_rr_del() returns ARES_SUCCESS if the RR was found and deleted, otherwise it returns an error code.

ares_dns_rr_get_name(), ares_dns_rr_get_type(), ares_dns_rr_get_class(), and ares_dns_rr_get_ttl() return the corresponding values.

ares_dns_rr_set_*() functions return ARES_SUCCESS on success, or an error code indicating the type of error (e.g., invalid key, invalid data type).

ares_dns_rr_get_*() functions return the value of the requested field. For pointer-returning functions like ares_dns_rr_get_addr(), NULL is returned if the field is not found or not of the expected type. For functions returning sizes or counts, 0 is returned if the field is not found or empty.
