archive_read_set_options(3)

الحزمة: libarchive

التراخيص: BSD-2-Clause

ARCHIVE_READ_OPTIONS(3) دليل وظائف المكتبة ARCHIVE_READ_OPTIONS(3)

الاسم

archive_read_set_filter_option، archive_read_set_format_option، archive_read_set_option، archive_read_set_options — وظائف تتحكم في الخيارات لقراءة الأرشيفات

المكتبة

مكتبة الأرشيف المتدفقة (libarchive, -larchive)

الملخص

int
archive_read_set_filter_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_read_set_format_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_read_set_option(struct archive *, const char *module, const char *option, const char *value);

int
archive_read_set_options(struct archive *, const char *options);

الوصف

توفر هذه الوظائف طريقة لعملاء libarchive لتكوين وحدات قراءة معينة.

archive_read_set_filter_option(), archive_read_set_format_option()
تحدد خيارًا سيتم تمريره إلى المرشحات المسجلة حاليًا (بما في ذلك مرشحات فك الضغط) أو قارئات التنسيق.

إذا كان option و value كلاهما NULL، فلن تقوم هذه الوظائف بأي شيء وسيتم إرجاع ARCHIVE_OK. إذا كان option هو NULL ولكن value ليس كذلك، فلن تقوم هذه الوظائف بأي شيء وسيتم إرجاع ARCHIVE_FAILED.

إذا كان module ليس NULL، فسيتم توفير option و value إلى المرشح أو القارئ المسمى module. ستكون القيمة المرجعة هي قيمة الوحدة. إذا لم يكن هناك وحدة من هذا القبيل، فسيتم إرجاع ARCHIVE_FAILED.

إذا كان module هو NULL، فسيتم توفير option و value لكل وحدة مسجلة. إذا أعادت أي وحدة ARCHIVE_FATAL، فسيتم إرجاع هذه القيمة على الفور. بخلاف ذلك، سيتم إرجاع ARCHIVE_OK إذا قبلت أي وحدة الخيار، و ARCHIVE_FAILED في جميع الحالات الأخرى.

archive_read_set_option()
يستدعي archive_read_set_format_option()، ثم archive_read_set_filter_option(). إذا أعادت أي وظيفة ARCHIVE_FATAL، فسيتم إرجاع ARCHIVE_FATAL على الفور. خلاف ذلك، سيتم إرجاع الأكبر من القيمتين.
archive_read_set_options()
options هي قائمة مفصولة بفواصل من الخيارات. إذا كان options هو NULL أو فارغًا، فسيتم إرجاع ARCHIVE_OK على الفور.

يستدعي archive_read_set_option() مع كل خيار بدوره. إذا أعادت أي استدعاء archive_read_set_option() القيمة ARCHIVE_FATAL، فسيتم إرجاع ARCHIVE_FATAL على الفور.

للخيارات الفردية أحد الأشكال التالية:

option=value
سيتم توفير زوج الخيار/القيمة لكل وحدة. الوحدات التي لا تقبل خيارًا بهذا الاسم ستقوم بتجاهله.
option
سيتم توفير الخيار لكل وحدة بقيمة “1”.
!option
سيتم توفير الخيار لكل وحدة بقيمة NULL.
module:option=value, module:option, module:!option
كما هو مذكور أعلاه، ولكن سيتم توفير الخيار والقيمة المقابلة فقط للوحدات التي يتطابق اسمها مع module.
