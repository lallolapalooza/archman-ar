الحزمة: tcl

التراخيص: TCL

"permalink" href="#tcl_traceExec">tcl_traceExec
يمكن تعيين قيمة هذا المتغير للتحكم في مقدار معلومات التتبع التي يتم عرضها أثناء تنفيذ التعليمات البرمجية. افتراضيًا، tcl_traceExec يساوي صفرًا ولا يتم عرض أي معلومات. يؤدي تعيين tcl_traceExec إلى 1 إلى إنشاء تتبع في سطر واحد في stdout عند كل استدعاء لإجراء Tcl. يؤدي تعيينه إلى 2 إلى إنشاء سطر إخراج في كل مرة يتم فيها استدعاء أي أمر Tcl يحتوي على اسم الأمر ووسيطاته. يؤدي تعيينه إلى 3 إلى إنتاج تتبع مفصل يظهر نتيجة تنفيذ كل تعليمة برمجية. لاحظ أنه عند tcl_traceExec يساوي 2 أو 3، لا يتم عرض أوامر مثل set و incr التي تم استبدالها بالكامل بسلسلة من التعليمات البرمجية. يعد تعيين هذا المتغير مفيدًا في تتبع المشكلات المشتبه بها في مترجم ومفسر التعليمات البرمجية.
هذا المتغير والوظيفة موجودان فقط إذا تم تعريف TCL_COMPILE_DEBUG أثناء تجميع Tcl.
tcl_wordchars
قيمة هذا المتغير هي تعبير عادي يمكن تعيينه للتحكم في ما يعتبر أحرف "كلمة"، للأمثلة مثل تحديد كلمة بالنقر المزدوج في النص في Tk. يعتمد على النظام الأساسي. في Windows، القيمة الافتراضية هي \S، مما يعني أي شيء باستثناء حرف مسافة Unicode. بخلاف ذلك، القيمة الافتراضية هي \w، وهي أي حرف كلمة Unicode (رقم، حرف، أو شرطة سفلية).
tcl_nonwordchars
قيمة هذا المتغير هي تعبير عادي يمكن تعيينه للتحكم في ما يعتبر أحرف "غير كلمة"، للأمثلة مثل تحديد كلمة بالنقر المزدوج في النص في Tk. يعتمد على النظام الأساسي. في Windows، القيمة الافتراضية هي \s، مما يعني أي حرف مسافة Unicode. بخلاف ذلك، القيمة الافتراضية هي \W، وهي أي شيء باستثناء حرف كلمة Unicode (رقم، حرف، أو شرطة سفلية).
tcl_version
عند إنشاء مفسر، تقوم Tcl بتهيئة هذا المتغير للاحتفاظ برقم الإصدار لإصدار Tcl هذا بالشكل x.y. تمثل التغييرات في x تغييرات رئيسية مع احتمالية وجود عدم توافق، وتمثل التغييرات في y تحسينات صغيرة وإصلاحات للأخطاء التي تحتفظ بالتوافق مع الإصدارات السابقة. يتم إرجاع قيمة هذا المتغير بواسطة الأمر info tclversion.

متغيرات عامة أخرى

يُضمن وجود المتغيرات التالية فقط في ملفات tclsh التنفيذية و wish؛ لا تقوم مكتبة Tcl بتعريفها بنفسها ولكن العديد من بيئات Tcl تفعل ذلك.

argc
عدد الوسائط لـ tclsh أو wish.
argv
قائمة Tcl بالوسائط لـ tclsh أو wish.
argv0
البرنامج النصي الذي بدأ tclsh أو wish تنفيذه (إذا تم تحديده) أو بخلاف ذلك الاسم الذي تم به استدعاء tclsh أو wish.
tcl_interactive
يحتوي على 1 إذا كان tclsh أو wish قيد التشغيل تفاعليًا (لم يتم تحديد برنامج نصي وكان الإدخال القياسي جهازًا شبيهًا بالطرفية)، 0 بخلاف ذلك.

أمثلة

لإضافة دليل إلى مجموعة المواقع التي يتم البحث فيها بواسطة package require، على سبيل المثال، بسبب بعض الحزم الخاصة بالتطبيق المستخدمة، يجب تحديث المتغير auto_path:

lappend ::auto_path [file join [pwd] "theLibDir"]

طريقة بسيطة وإن لم تكن قوية جدًا للتعامل مع وسائط سطر الأوامر بالشكل "-foo 1 -bar 2" هي تحميلها في مصفوفة بعد تحميل الإعدادات الافتراضية أولاً:

array set arguments {-foo 0 -bar 0 -grill 0}
array set arguments $::argv
puts "foo is $arguments(-foo)"
puts "bar is $arguments(-bar)"
puts "grill is $arguments(-grill)"

يمكن استخدام المتغير العام argv0 (بالاقتران مع الأمر info script) لتحديد ما إذا كان البرنامج النصي الحالي يتم تنفيذه كالبرنامج النصي الرئيسي أو تم تحميله كمكتبة. هذا مفيد لأنه يسمح باستخدام برنامج نصي واحد كمكتبة وعرض توضيحي لهذه المكتبة:

if {$::argv0 eq [info script]} {
    # running as: tclsh example.tcl
} else {
    package provide Example 1.0
}
