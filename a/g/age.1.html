الحزمة: age

التراخيص: BSD-3-Clause

AGE(1) دليل الأوامر العامة AGE(1)

الاسم

age - تشفير ملفات بسيط، حديث وآمن

ملخص

age [--encrypt] (-r RECIPIENT | -R PATH)... [--armor] [-o OUTPUT] [INPUT]
age [--encrypt] --passphrase [--armor] [-o OUTPUT] [INPUT]
age --decrypt [-i PATH | -j PLUGIN]... [-o OUTPUT] [INPUT]

الوصف

يقوم age بتشفير أو فك تشفير INPUT إلى OUTPUT. الوسيط INPUT اختياري ويفترض أنه الإدخال القياسي. يمكن تحديد ملف INPUT واحد فقط. إذا لم يتم تحديد -o، يفترض OUTPUT أنه الإخراج القياسي.

إذا تم تحديد -p/--passphrase، يتم تشفير الملف بعبارة مرور يتم طلبها بشكل تفاعلي. بخلاف ذلك، يتم تشفيره لمستلم واحد أو أكثر RECIPIENTS محددين باستخدام -r/--recipient أو -R/--recipients-file. يمكن لكل مستلم فك تشفير الملف.

في وضع -d/--decrypt، يتم اكتشاف الملفات المشفرة بعبارة مرور تلقائيًا ويتم طلب عبارة المرور بشكل تفاعلي. بخلاف ذلك، يتم استخدام هوية واحدة أو أكثر IDENTITIES محددة باستخدام -i/--identity لفك تشفير الملف.

ملفات age المشفرة هي ملفات ثنائية وغير قابلة للتغيير، مع حمل إضافي يبلغ حوالي 200 بايت لكل مستلم، بالإضافة إلى 16 بايت لكل 64 كيلوبايت من النص العادي.

الخيارات

-o, --output=OUTPUT
اكتب الملف المشفر أو المفكوك تشفيره إلى OUTPUT بدلاً من الإخراج القياسي. إذا كان OUTPUT موجودًا بالفعل، فسيتم الكتابة فوقه.
إذا كنت تقوم بالتشفير بدون --armor، سيرفض age إخراج الملفات الثنائية إلى TTY. يمكن فرض ذلك عن طريق تحديد - كـ OUTPUT.
--version
اطبع الإصدار واخرج.

خيارات التشفير

-e, --encrypt
قم بتشفير INPUT إلى OUTPUT. هذا هو الوضع الافتراضي.
-r, --recipient=RECIPIENT
قم بالتشفير للمستلم المحدد صراحةً RECIPIENT. راجع قسم المستلمون والهويات للاطلاع على تنسيقات المستلمين الممكنة.
يمكن تكرار هذا الخيار ودمجه مع علامات المستلمين الأخرى، ويمكن فك تشفير الملف بواسطة جميع المستلمين المقدمين بشكل مستقل.
-R, --recipients-file=PATH
قم بالتشفير للمستلمين RECIPIENTS المدرجين في الملف الموجود في PATH، مستلم واحد في كل سطر. يتم تجاهل الأسطر الفارغة والأسطر التي تبدأ بـ # كتعليقات.
إذا كان PATH هو -، يتم قراءة المستلمين من الإدخال القياسي. في هذه الحالة، يجب تحديد الوسيط INPUT.
يمكن تكرار هذا الخيار ودمجه مع علامات المستلمين الأخرى، ويمكن فك تشفير الملف بواسطة جميع المستلمين المقدمين بشكل مستقل.
-p, --passphrase
قم بالتشفير بعبارة مرور، يتم طلبها بشكل تفاعلي من الطرفية. سيعرض age خيار توليد عبارة مرور آمنة تلقائيًا.
لا يمكن استخدام هذا الخيار مع علامات المستلمين الأخرى.
-a, --armor
التشفير في ترميز "درع" ASCII فقط.
درع age هو إصدار صارم من PEM بالنوع AGE ENCRYPTED FILE، ترميز Base64 "صارم" قياسي، بدون رؤوس، وبدون دعم للبيانات الإضافية البادئة واللاحقة.
فك التشفير يكتشف ويفك ترميز درع ASCII تلقائيًا.
-i, --identity=PATH
قم بالتشفير للمستلمين RECIPIENTS المقابلة للهويات IDENTITIES المدرجة في الملف في PATH. هذا يعادل تحويل الملف الموجود في PATH إلى ملف مستلمين باستخدام age-keygen -y ثم تمريره إلى -R/--recipients-file.
لتنسيق PATH، راجع تعريف -i/--identity في قسم خيارات فك التشفير.
يجب تحديد -e/--encrypt بشكل صريح عند استخدام -i/--identity في وضع التشفير لتجنب الالتباس.
-j PLUGIN
قم بالتشفير باستخدام المكون الإضافي الخالي من البيانات PLUGIN.
هذا يعادل استخدام -i/--identity مع ملف يحتوي على هوية مكون إضافي واحدة IDENTITY لا تشفر أي بيانات خاصة بالمكون الإضافي.
يجب تحديد -e/--encrypt بشكل صريح عند استخدام -j في وضع التشفير لتجنب الالتباس.

خيارات فك التشفير

-d, --decrypt
قم بفك تشفير INPUT إلى OUTPUT.
إذا كان INPUT مشفرًا بعبارة مرور، فسيتم اكتشافه تلقائيًا وسيتم طلب عبارة المرور بشكل تفاعلي. بخلاف ذلك، يتم استخدام الهويات IDENTITIES المحددة باستخدام -i/--identity.
يتم اكتشاف وفك ترميز درع ASCII تلقائيًا.
-i, --identity=PATH
قم بفك التشفير باستخدام الهويات IDENTITIES الموجودة في PATH.
قد يكون PATH أحد ما يلي:
أ. ملف يسرد الهويات IDENTITIES، واحدة في كل سطر. يتم تجاهل الأسطر الفارغة والأسطر التي تبدأ بـ "#" كتعليقات.
ب. ملف age مشفر بعبارة مرور، يحتوي على هويات IDENTITIES واحدة في كل سطر كما هو موضح أعلاه. يتم طلب عبارة المرور بشكل تفاعلي. لاحظ أن ملفات الهوية المحمية بكلمة مرور ليست ضرورية لمعظم حالات الاستخدام، حيث يعني الوصول إلى ملف الهوية المشفر الوصول إلى النظام بأكمله.
ج. ملف مفتاح SSH خاص، بتنسيق PKCS#1 أو PKCS#8 أو OpenSSH. إذا كان المفتاح الخاص محميًا بكلمة مرور، يتم طلب كلمة المرور بشكل تفاعلي فقط إذا تطابقت هوية SSH مع الملف. راجع قسم مفاتيح SSH لمزيد من المعلومات، بما في ذلك أنواع المفاتيح المدعومة.
د. "-"، مما يؤدي إلى قراءة أحد الخيارات المذكورة أعلاه من الإدخال القياسي. في هذه الحالة، يجب تحديد الوسيط INPUT.
يمكن تكرار هذا الخيار. يتم تجربة الهويات بالترتيب الذي يتم تقديمها به، ويتم استخدام أول هوية تتطابق مع أحد مستلمي الملف. يتم تجاهل الهويات غير المستخدمة، ولكنها خطأ إذا كان ملف INPUT مشفرًا بعبارة مرور وتم تحديد -i/--identity.
-j PLUGIN
قم بفك التشفير باستخدام المكون الإضافي الخالي من البيانات PLUGIN.
هذا يعادل استخدام -i/--identity مع ملف يحتوي على هوية مكون إضافي واحدة IDENTITY لا تشفر أي بيانات خاصة بالمكون الإضافي.

المستلمون والهويات

المستلمون (RECIPIENTS) هي قيم عامة، مثل مفتاح عام، يمكن تشفير ملف إليها. الهويات (IDENTITIES) هي قيم خاصة، مثل مفتاح خاص، تسمح بفك تشفير ملف تم تشفيره للمستلم المقابل RECIPIENT.

مفاتيح X25519 الأصلية

يتم إنشاء أزواج مفاتيح age الأصلية باستخدام age-keygen(1)، وتوفر ترميزات صغيرة وتشفيرًا قويًا يعتمد على X25519. وهي نوع المستلم الموصى به لمعظم التطبيقات.
