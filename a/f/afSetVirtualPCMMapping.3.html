afSetVirtualPCMMapping(3)

الحزمة: audiofile

التراخيص: Apache-2.0, GPL-2.0-or-later, LGPL-2.1-or-later

AFSETVIRTUALSAMPLEFO(3)   AFSETVIRTUALSAMPLEFO(3)

الاسم

afSetVirtualByteOrder, afSetVirtualChannels, afSetVirtualPCMMapping, afSetVirtualSampleFormat - ضبط تنسيق بيانات المسار الافتراضي في ملف صوتي

الملخص

#include <audiofile.h>
int afSetVirtualByteOrder (AFfilehandle file, int track, int byteOrder);
int afSetVirtualChannels (AFfilehandle file, int track, int channels);
int afSetVirtualSampleFormat (AFfilehandle file, int track,
    int sampleFormat, int sampleWidth);
int afSetVirtualPCMMapping (AFfilehandle file, int track,
    double slope, double intercept, double minclip, double maxclip);

المعاملات

• file هو مقبض ملف AF (AFfilehandle) يشير إلى ملف صوتي مفتوح وعادة ما يتم إنشاؤه بواسطة afOpenFile.
• track هو عدد صحيح يحدد مسارًا معينًا في ملف صوتي مفتوح. المسار الوحيد الصالح هو AF_DEFAULT_TRACK لجميع تنسيقات الملفات المدعومة حاليًا.
• sampleFormat هو عدد صحيح يحدد تنسيق عينة افتراضي. القيم الصالحة هي AF_SAMPFMT_TWOSCOMP, AF_SAMPFMT_UNSIGNED, AF_SAMPFMT_FLOAT, و AF_SAMPFMT_DOUBLE.
• sampleWidth هو عدد صحيح موجب يحدد عدد البتات في العينة.
• channels هو عدد صحيح موجب يحدد عدد قنوات الصوت المتداخلة في مسار الصوت المحدد.
• byteOrder هو عدد صحيح يحدد ترتيب البايت الافتراضي للعينات في مسار الصوت المحدد. يمكن أن يكون byteOrder إما AF_BYTEORDER_BIGENDIAN أو AF_BYTEORDER_LITTLEENDIAN.
• slope و intercept هما قيمتان لأرقام النقطة العائمة مزدوجة الدقة تشيران إلى ميل عينة بيانات الصوت وقيمة عبور الصفر، على التوالي، لتنسيق العينة المحدد.
• minclip و maxclip هما قيمتان لأرقام النقطة العائمة مزدوجة الدقة تشيران إلى الحد الأدنى أو الأقصى لقيم العينات التي سيتم إرجاعها. سيتم تعيين أي قيم أقل من minclip إلى minclip، وسيتم تعيين أي قيم أكبر من maxclip إلى maxclip.

قيمة الإرجاع

تعيد هذه الدوال 0 للنجاح و -1 للفشل.
