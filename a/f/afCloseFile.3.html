afCloseFile(3)

الحزمة: audiofile

التراخيص: Apache-2.0, GPL-2.0-or-later, LGPL-2.1-or-later

AFCLOSEFILE(3)   AFCLOSEFILE(3)

اسم

afCloseFile - إغلاق ملف صوتي مفتوح

الملخص

#include <audiofile.h>
int afCloseFile(AFfilehandle file);

المعاملات

file هو مقبض ملف صالح تم إنشاؤه بواسطة afOpenFile(3).

الوصف

يقوم afCloseFile بإغلاق ملف الصوت file، وتحديث الملف إذا تم فتحه للكتابة.

قيمة الإرجاع

يقوم afCloseFile بإرجاع 0 إذا تم إغلاق الملف بشكل صحيح و -1 إذا حدث خطأ أثناء إغلاق الملف.

الأخطاء

يمكن لـ afCloseFile توليد الأخطاء المحتملة التالية:

• AF_BAD_FILEHANDLE
• AF_BAD_LSEEK
• AF_BAD_WRITE

انظر أيضاً

afOpenFile(3)
