afWriteMisc(3)

الحزمة: audiofile

التراخيص: Apache-2.0, GPL-2.0-or-later, LGPL-2.1-or-later

AFREADMISC(3)   AFREADMISC(3)

الاسم

afReadMisc، afWriteMisc، afSeekMisc - الوصول إلى البيانات الوصفية المتنوعة في ملف صوتي

الملخص

#include <audiofile.h>
int afReadMisc (AFfilehandle file, int miscid, void *buffer, int nbytes);
int afWriteMisc (AFfilehandle file, int miscid, const void *buffer, int nbytes);
int afSeekMisc (AFfilehandle file, int miscid, int offbytes);

الوصف

تقوم الدالة `afReadMisc` بقراءة ما يصل إلى `nbytes` من شريحة البيانات المتنوعة التي تم تحديدها بواسطة `miscid` في `file`.

تقوم الدالة `afWriteMisc` بكتابة ما يصل إلى `nbytes` إلى شريحة البيانات المتنوعة التي تم تحديدها بواسطة `miscid` في `file`.

تقوم الدالة `afSeekMisc` بتغيير الإزاحة الحالية داخل شريحة البيانات المتنوعة التي تم تحديدها بواسطة `miscid` إلى الإزاحة `offbytes`.

قيمة الإرجاع

تقوم الدالة `afReadMisc` بإرجاع عدد البايتات التي تم قراءتها من شريحة البيانات المتنوعة المحددة إلى المخزن المؤقت المشار إليه بواسطة `buffer`.

تقوم الدالة `afWriteMisc` بإرجاع عدد البايتات التي تم كتابتها إلى شريحة البيانات المتنوعة المحددة من المخزن المؤقت المشار إليه بواسطة `buffer`.

تقوم الدالة `afSeekMisc` بإرجاع الموقع الجديد لمؤشر بيانات المنطق مقاسًا كإزاحة بالبايتات من بداية منطقة بيانات الشريحة المتنوعة.

الأخطاء

يمكن للدوال `afReadMisc` و `afWriteMisc` و `afSeekMisc` إنتاج رموز الخطأ التالية:

• AF_BAD_READ
• AF_BAD_WRITE
• AF_BAD_MISCSEEK
• AF_BAD_MISCID
• AF_BAD_TRACKID
• AF_BAD_FILEHANDLE
