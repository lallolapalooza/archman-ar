afcclient(1)

الحزمة: libimobiledevice

التراخيص: LGPL-2.1-or-later

afcclient(1) دليل الأوامر العامة afcclient(1)

الاسم

afcclient - التفاعل مع خدمة AFC/HouseArrest على جهاز متصل.

الملخص

afcclient [خيارات] [أمر ...]

الوصف

أداة مساعدة للتفاعل مع خدمة AFC/HouseArrest. هذا يسمح بالوصول إلى أجزاء من نظام الملفات على جهاز iOS.

يمكن استخدام afcclient بشكل تفاعلي مع موجه الأوامر، أو تشغيل أمر واحد والخروج.

الأوامر

devinfo
طباعة معلومات الجهاز
info PATH
طباعة سمات الملف للملف في المسار PATH
ls PATH
طباعة محتويات الدليل للمسار PATH
mv OLD NEW
إعادة تسمية الملف OLD إلى NEW
mkdir PATH
إنشاء دليل في المسار PATH
ln [-s] FILE [LINK]
إنشاء رابط (رمزي) للملف المسمى LINKNAME. ملاحظة: تم تعطيل هذه الميزة في الإصدارات الأحدث من iOS.
rm [-rf] PATH
إزالة العنصر في المسار PATH
get [-rf] PATH [LOCALPATH]
نقل الملف في المسار PATH من الجهاز إلى LOCALPATH، أو الدليل الحالي إذا تم حذفه. إذا كان LOCALPATH دليلًا، فسيتم تخزين الملف داخل الدليل.
put [-rf] LOCALPATH [PATH]
نقل الملف المحلي في LOCALPATH إلى الجهاز في المسار PATH، أو الدليل الحالي إذا تم حذفه. إذا كان PATH دليلًا، فسيتم تخزين الملف داخل الدليل.

الخيارات

-u, --udid UDID
استهداف جهاز محدد بواسطة UDID
-n, --network
الاتصال بجهاز شبكة (غير مستحسن، حيث قد يتم إنهاء الاتصال في أي وقت)
--container <appid>
الوصول إلى دليل حاوية التطبيق للتطبيق ذي معرف التطبيق appid المعطى
--documents <appid>
الوصول إلى دليل المستندات للتطبيق ذي معرف التطبيق appid المعطى
-h, --help
طباعة معلومات الاستخدام
-d, --debug
تمكين تصحيح الاتصال
-v, --version
طباعة معلومات الإصدار
