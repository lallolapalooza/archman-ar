veth(4) دليل برامج تشغيل الأجهزة veth(4)

الاسم

veth - جهاز إيثرنت افتراضي

الوصف

أجهزة veth هي أجهزة إيثرنت افتراضية. يمكنها أن تعمل كأنفاق بين مساحات الأسماء الشبكية لإنشاء جسر إلى جهاز شبكة مادي في مساحة أسماء أخرى، ولكن يمكن أيضًا استخدامها كأجهزة شبكة مستقلة.

يتم دائمًا إنشاء أزواج أجهزة veth متصلة. يمكن إنشاء زوج باستخدام الأمر:


# ip link add <p1-name> type veth peer name <p2-name>

في الأعلى، p1-name و p2-name هما الأسماء المعينة لنقطتي النهاية المتصلتين.

الحزم المرسلة على جهاز في الزوج يتم استقبالها فورًا على الجهاز الآخر. عندما يكون أي من الجهازين معطلاً، تكون حالة الاتصال للزوج معطلة.

تفيد أزواج أجهزة veth في الجمع بين مرافق الشبكة الخاصة بالنواة بطرق مثيرة للاهتمام. أحد حالات الاستخدام المثيرة للاهتمام بشكل خاص هو وضع أحد طرفي زوج veth في مساحة أسماء شبكة والطرف الآخر في مساحة أسماء شبكة أخرى، مما يسمح بالاتصال بين مساحات الأسماء الشبكية. للقيام بذلك، يمكن توفير المعلمة netns عند إنشاء الواجهات:


# ip link add <p1-name> netns <p1-ns> type veth peer <p2-name> netns <p2-ns>

أو، لزوج veth موجود، انقل أحد الجانبين إلى مساحة الأسماء الأخرى:


# ip link set <p2-name> netns <p2-ns>

يمكن استخدام ethtool(8) للعثور على الند لواجهة شبكة veth، باستخدام أوامر مثل:


# ip link add ve_A type veth peer name ve_B;   # إنشاء زوج veth
# ethtool -S ve_A;         # اكتشاف فهرس الواجهة للند
NIC statistics:
     peer_ifindex: 16
# ip link | grep '^16:';   # البحث عن الواجهة
16: ve_B@ve_A: <BROADCAST,MULTICAST,M-DOWN> mtu 1500 qdisc ...
