vfs_virusfilter(8)

الحزمة: samba

التراخيص: GPL-3.0-or-later

NAME

vfs_virusfilter - Samba VFS module to scan files for viruses

SYNOPSIS

vfs objects = virusfilter

virusfilter: virusfilter backend [ virusfilter: option ... ]

DESCRIPTION

This VFS module is a wrapper around a virus scanner. It is intended to scan files for viruses as they are written to the Samba server. When a file is closed, this module will call the specified virus scanner to scan the file. If the virus scanner reports the file as infected, the file will be deleted.

The backend may be an executable name or a Python script name. The executable should accept the filename as the first argument. It should return 0 if the file is clean, and non-zero if the file is infected. Python scripts should call the scan_file() method of the VirusScanner object.

See vfs_python(3) for more information on writing Python scripts.

The virusfilter VFS module requires the vfs_streams_depot(8) module to be loaded before it. This is because virusfilter stores information about scanned files in the alternate data stream of the file. This means that the following configuration must be used:

        vfs objects = streams_depot virusfilter

If you intend to use this module, you will need to ensure that vfs_streams_depot(8) is also loaded.

The following options are supported:

virusfilter: backend = backend
Specifies the virus scanner to use. This can be the full path to an executable or a script, or just the name if it is in the system's PATH. This option is mandatory.
virusfilter: infected = action
Specifies the action to take when a file is found to be infected. The following actions are supported:
delete
Delete the infected file. This is the default action.
report
Report the infected file but do not delete it. The file will be logged but otherwise left untouched.
virusfilter: onerror = action
Specifies the action to take when an error occurs during scanning. The following actions are supported:
abort
Abort the operation, returning an error to the client. This is the default behavior.
ignore
Ignore the error and continue as if no error occurred. The file will not be scanned.
virusfilter: logfile = logfile
Specifies the path to a file where virus scanning events will be logged. If not specified, events will be logged to the Samba log files.
virusfilter: loglevel = level
Specifies the level of detail for logging. The default is 3.

OPTIONS

The virusfilter VFS module does not support any command line options.

NOTES

This module is intended for security in depth by providing virus scanning capability on the server. It is not intended to be used in lieu of proper client based security. Other modules for security may exist and may be desirable for security in depth on the server.

Make sure that the virus scanner executable has execute permissions for the user that the Samba daemon runs as.

The virus filter should be configured to not scan files in the Samba log directory or any temporary directories used by Samba.

If using the default `delete` action, the virus scanner should be configured to not scan files in the Samba spool directory, as this can lead to infinite loops.

The virus scanner will be called with the full path to the file as its argument. The scanner should return 0 if the file is clean, and non-zero if the file is infected. If the scanner returns a non-zero value, the file will be deleted.

It is important that the `streams_depot` VFS module is loaded before the `virusfilter` module. This is because `virusfilter` stores its state in the alternate data stream of the file. If `streams_depot` is not loaded first, `virusfilter` will not be able to store its state, and may not function correctly.

Ensure that the `vfs objects` line in your `smb.conf` file correctly specifies the order of the VFS modules. For example:

        vfs objects = streams_depot virusfilter

This order ensures that `streams_depot` is initialized before `virusfilter`, allowing `virusfilter` to access the alternate data streams properly.
