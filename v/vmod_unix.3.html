vmod_unix(3)

الحزمة: varnish

التراخيص: BSD-2-Clause

VMOD_UNIX(3) دليل دوال المكتبة VMOD_UNIX(3)

الاسم

vmod_unix - أدوات لمقابسونات نطاق يونكس

ملخص

استورد unix [باسم name] [من "path"]
STRING user()
STRING group()
INT uid()
INT gid()

الوصف

توفر وحدة vmod هذه معلومات حول بيانات اعتماد العملية النظيرة (اسم المستخدم والمجموعة الخاصة بمالك العملية) المتصلة بمستمع Varnish عبر مقبس نطاق Unix، إذا كانت المنصة تدعم ذلك.

أمثلة:

استورد unix;
sub vcl_recv {
      # إرجاع "403 ممنوع" إذا كانت العملية النظيرة المتصلة
      # لا تعمل باسم المستخدم "trusteduser".
      if (unix.user() != "trusteduser") {
              return( synth(403) );
      }
      # طلب أن تعمل العملية النظيرة في المجموعة
      # "trustedgroup".
      if (unix.group() != "trustedgroup") {
              return( synth(403) );
      }
      # طلب أن تعمل العملية النظيرة تحت معرف مستخدم رقمي
      # محدد.
      if (unix.uid() != 4711) {
              return( synth(403) );
      }
      # طلب أن تعمل العملية النظيرة تحت معرف مجموعة رقمي.
      if (unix.gid() != 815) {
              return( synth(403) );
      }
}

الحصول على بيانات اعتماد النظير ممكن على منصة تدعم أحد الخيارات التالية:

  • getpeereid(3) (مثل FreeBSD وأنظمة أخرى مشتقة من BSD)
  • الخيار المقبس SO_PEERCRED لـ getsockopt(2) (Linux)
  • getpeerucred(3C) (SunOS ومنحدراتها)

على SunOS وأصدقائها، تتم إضافة مجموعة الامتيازات PRIV_PROC_INFO إلى عملية Varnish الفرعية أثناء تحميل وحدة vmod، انظر setppriv(2).

على معظم المنصات، تكون القيمة المرجعة هي المستخدم أو المجموعة الفعال الذي كان صحيحًا عند بدء العملية النظيرة للاتصال.

STRING user()

إرجاع اسم المستخدم الخاص بمالك العملية النظيرة.

مقتصر على: client، backend.

STRING group()

إرجاع اسم المجموعة الخاص بمالك العملية النظيرة.

مقتصر على: client، backend.

INT uid()

إرجاع معرف المستخدم الرقمي الخاص بمالك العملية النظيرة.

مقتصر على: client، backend.

INT gid()

إرجاع معرف المجموعة الرقمي الخاص بمالك العملية النظيرة.

مقتصر على: client، backend.

الأخطاء

تخضع جميع الدوال في وحدة vmod هذه للقيود التالية:

  • لا يجوز استدعاء أي منها في vcl_init{} أو vcl_fini{}. إذا تم استدعاء إحداها في vcl_init{}، فسيفشل تحميل برنامج VCL، مع رسالة خطأ من وحدة vmod.
  • إذا تم استدعاؤها على منصة غير مدعومة، فسيتم استدعاء فشل VCL. تتم كتابة رسالة خطأ إلى السجل (بالعلامة VCL_Error)، وبالنسبة لجميع الروتينات الفرعية لـ VCL باستثناء vcl_synth{}، يتم توجيه التحكم مباشرة إلى vcl_synth{}، مع تعيين حالة الاستجابة إلى 503 وسلسلة السبب إلى "VCL failed".

    إذا حدث الفشل أثناء vcl_synth{}، فسيتم إنهاء vcl_synth{}، وسيتم إرسال سطر الاستجابة "503 VCL failed".

  • إذا كان المستمع الحالي ليس مقبس نطاق Unix، أو إذا فشلت محاولة قراءة بيانات الاعتماد، فسيتم كتابة رسالة VCL_Error إلى السجل. تُرجع دوال السلسلة (unix.user() و unix.group()) NULL، بينما تُرجع دوال INT (unix.uid() و unix.gid()) -1.
