visudo(8)

الحزمة: sudo

التراخيص: custom

تصحيح الأخطاء وحجج إضافة sudoers

visudo الإصدارات 1.8.4 وما فوق تدعم إطار عمل تصحيح مرن يتم تكوينه عبر أسطر Debug في ملف sudo.conf(5).

بدءًا من sudo 1.8.12، سيقوم visudo أيضًا بتحليل حجج إضافة sudoers لتجاوز اسم مسار sudoers الافتراضي، ومعرف المستخدم، ومعرف المجموعة، ووضع الملف. هذه الحجج، إذا كانت موجودة، يجب أن تُدرج بعد مسار الإضافة (أي، بعد sudoers.so). يمكن تحديد حجج متعددة، مفصولة بمسافات بيضاء. على سبيل المثال:

Plugin sudoers_policy sudoers.so sudoers_mode=0400

الحجج التالية مدعومة:

sudoers_file=pathname
يمكن استخدام وسيطة sudoers_file لتجاوز المسار الافتراضي لملف sudoers.
sudoers_uid=user-ID
يمكن استخدام وسيطة sudoers_uid لتجاوز المالك الافتراضي لملف sudoers. يجب تحديده كمعرف مستخدم رقمي.
sudoers_gid=group-ID
يمكن استخدام وسيطة sudoers_gid لتجاوز المجموعة الافتراضية لملف sudoers. يجب تحديده كمعرف مجموعة رقمي (ليس اسم مجموعة).
sudoers_mode=mode
يمكن استخدام وسيطة sudoers_mode لتجاوز وضع الملف الافتراضي لملف sudoers. يجب تحديده كقيمة ثمانية.

لمزيد من المعلومات حول تكوين sudo.conf(5)، راجع دليلها.

بيئة التشغيل

قد يتم استشارة متغيرات بيئة التشغيل التالية اعتمادًا على قيمة إعدادات editor و env_editor في sudoers:

SUDO_EDITOR
يستدعيه visudo كمحرر للاستخدام
VISUAL
يستخدمه visudo إذا لم يتم تعيين SUDO_EDITOR
EDITOR
يستخدمه visudo إذا لم يتم تعيين SUDO_EDITOR ولا VISUAL

ملفات

/etc/sudo.conf
تكوين واجهة sudo الأمامية
/etc/sudoers
قائمة بمن يمكنه تشغيل ماذا
/etc/sudoers.tmp
الملف المؤقت الافتراضي الذي يستخدمه visudo

التشخيصات

بالإضافة إلى الإبلاغ عن أخطاء بناء جملة sudoers، قد ينتج visudo الرسائل التالية:

sudoers file busy, try again later.
شخص آخر يقوم حاليًا بتحرير ملف sudoers.
/etc/sudoers: Permission denied
لم تقم بتشغيل visudo كـ root.
you do not exist in the passwd database
معرف المستخدم الخاص بك لا يظهر في قاعدة بيانات نظام passwd.
Warning: {User,Runas,Host,Cmnd}_Alias referenced but not defined
إما أنك تحاول استخدام {User,Runas,Host,Cmnd}_Alias غير معلن عنه أو أن لديك اسم مستخدم أو مضيف مدرج يتكون بالكامل من أحرف كبيرة وأرقام وحرف الشرطة السفلية ( ‘_’). في الحالة الأخيرة، يمكنك تجاهل التحذيرات (لن يشتكي sudo). الرسالة مسبوقة باسم المسار لملف sudoers ورقم السطر حيث تم استخدام Alias غير المعرف. في وضع -s (صارم) تكون هذه أخطاء، وليس تحذيرات.
Warning: unused {User,Runas,Host,Cmnd}_Alias
تم تعريف {User,Runas,Host,Cmnd}_Alias المحدد ولكنه لم يستخدم قط. الرسالة مسبوقة باسم المسار لملف sudoers ورقم السطر حيث تم تعريف Alias غير المستخدم. قد ترغب في التعليق على Alias غير المستخدم أو إزالته.
Warning: cycle in {User,Runas,Host,Cmnd}_Alias
يشير {User,Runas,Host,Cmnd}_Alias المحدد إلى نفسه، إما مباشرة أو من خلال Alias يشتمل عليه. الرسالة مسبوقة باسم المسار لملف sudoers ورقم السطر حيث تم اكتشاف الدورة. هذا تحذير فقط ما لم يتم تشغيل visudo في وضع -s (صارم) حيث سيقوم sudo بتجاهل الدورات عند تحليل ملف sudoers.
ignoring editor backup file
أثناء معالجة @includedir أو #includedir، تم العثور على ملف باسم ينتهي بـ ‘~’ أو .bak. يتم تخطي هذه الملفات بواسطة sudo و visudo.
ignoring file name containing '.'
أثناء معالجة @includedir أو #includedir، تم العثور على ملف باسم يحتوي على حرف ‘.’. يتم تخطي هذه الملفات بواسطة sudo و visudo.
unknown defaults entry "name"
يحتوي ملف sudoers على إعداد Defaults غير معروف بواسطة visudo.

المؤلفون

لقد عمل العديد من الأشخاص على sudo على مر السنين؛ هذا الإصدار يتكون من كود مكتوب بشكل أساسي بواسطة:

Todd C. Miller

انظر ملف Contributors.md في توزيع sudo ( https://www.sudo.ws/about/contributors/) للحصول على قائمة شاملة بالأشخاص الذين ساهموا في sudo.

تنبيهات

لا توجد طريقة سهلة لمنع المستخدم من الحصول على shell root إذا كان المحرر المستخدم بواسطة visudo يسمح بالهروب إلى shell.

أخطاء

إذا كنت تعتقد أنك وجدت خطأ في visudo، يمكنك إما تقديم تقرير خطأ في قاعدة بيانات أخطاء sudo، https://bugzilla.sudo.ws/، أو فتح مسألة في https://github.com/sudo-project/sudo/issues. إذا كنت تفضل استخدام البريد الإلكتروني، يمكن إرسال الرسائل إلى قائمة sudo-workers البريدية، https://www.sudo.ws/mailman/listinfo/sudo-workers (عامة) أو <sudo@sudo.ws> (خاصة).

يرجى عدم الإبلاغ عن الثغرات الأمنية عبر مسائل GitHub العامة، Bugzilla، أو القوائم البريدية. بدلاً من ذلك، أبلغ عنها عبر البريد الإلكتروني إلى <Todd.Miller@sudo.ws>. يمكنك تشفير رسالتك باستخدام PGP إذا كنت ترغب في ذلك، باستخدام المفتاح الموجود في https://www.sudo.ws/dist/PGPKEYS.

الدعم

يتوفر دعم محدود مجاني عبر قائمة sudo-users البريدية، انظر https://www.sudo.ws/mailman/listinfo/sudo-users للاشتراك أو البحث في الأرشيف.

إخلاء مسؤولية

يتم توفير visudo "كما هي" ويتم إخلاء أي ضمانات صريحة أو ضمنية، بما في ذلك، على سبيل المثال لا الحصر، الضمانات الضمنية لقابلية التسويق والملاءمة لغرض معين. انظر ملف LICENSE.md الموزع مع sudo أو https://www.sudo.ws/about/license/ للحصول على التفاصيل الكاملة.
