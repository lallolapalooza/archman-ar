virt-fw-sigdb(1)

الحزمة: virt-firmware

VIRT-FW-SIGDB(1) أوامر المستخدم VIRT-FW-SIGDB(1)

الاسم

virt-fw-sigdb - صفحة دليل لـ virt-fw-sigdb 25.10

الوصف

تتيح الأداة virt-fw-sigdb إنشاء وتعديل وطباعة قواعد بيانات توقيع EFI. هذا هو التنسيق الذي تستخدمه البرامج الثابتة UEFI لتخزين قوائم الشهادات وتجزئات المصادقة للبرامج الثنائية في متغيرات EFI مثل 'PK' و 'KEK' و 'db' و 'dbx'.

عادةً ما يتم تضمين قواعد بيانات التوقيع في مخازن متغيرات EFI، لذا بالنسبة لمعظم حالات الاستخدام، يجب عليك التحقق من الأداة virt-fw-vars(1) بدلاً من هذه.

الاستثناء لهذه القاعدة هو قائمة شهادات CA الجذرية لاتصالات TLS التي يمكن تمريرها من المضيف عبر qemu إلى OVMF باستخدام ملف etc/edk2/https/cacerts fw_cfg.

الاستخدام: virt-fw-sigdb [-h] [-i FILE] [-o FILE] [--add-cert GUID FILE]

[--add-hash GUID HASH] [-p]

خيارات:

-h, --help
عرض رسالة المساعدة هذه والخروج
-i, --input FILE
قراءة ملف efi sigdb
-o, --output FILE
كتابة ملف efi sigdb.
--add-cert GUID FILE
إضافة شهادة x509 إلى قاعدة بيانات التوقيع، تم تحميلها بتنسيق pem من FILE ومع GUID المالك، يمكن تحديده عدة مرات
--add-hash GUID HASH
إضافة تجزئة sha256 إلى قاعدة بيانات التوقيع، مع GUID المالك، يمكن تحديده عدة مرات
-p, --print
طباعة قاعدة بيانات التوقيع

أمثلة

طباعة قاعدة بيانات CA الجذرية للنظام
virt-fw-sigdb --print \
--input /etc/pki/ca-trust/extracted/edk2/cacerts.bin
