NAME

vgmerge — merge two Volume Groups

SYNOPSIS

vgmerge [-A|--available {y|n}] [-f|--force] [-P|--partial] [-y|--yes] DestinationVG SourceVG [PhysicalVolumePath...]

DESCRIPTION

Merges SourceVG into DestinationVG. SourceVG must be deactivated and must not contain any Logical Volumes. If SourceVG contains more than one Physical Volume, PhysicalVolumePath must be used to specify which Physical Volume(s) to merge. If PhysicalVolumePath is not specified, all Physical Volumes from SourceVG are merged.

All Physical Volumes in SourceVG are added to DestinationVG. The metadata is copied from SourceVG to DestinationVG. The metadata in SourceVG is not changed, and the Logical Volumes are not moved or changed.

SourceVG is not removed, but it will be empty after the merge operation. It can be removed afterwards using vgremove(8).

OPTIONS

See vgchange(8) for more options.

-A, --available {y|n} Controls the allocation of Physical Volumes in SourceVG. If y (default), allocatable Physical Volumes in SourceVG are marked as not available for allocation in DestinationVG. If n, they are marked as available.

-f, --force Force the merge operation. This can be used to merge a SourceVG that contains Logical Volumes, but they will be lost. Use with extreme caution.

-P, --partial Allow merging of partial Volume Groups. This is useful when some Physical Volumes of SourceVG are unavailable.

-y, --yes Assume "yes" to all questions.

VARIABLES

None.

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables.

EXAMPLES

Merge vg02 into vg01: vgmerge vg01 vg02

Merge a specific Physical Volume from vg02 into vg01: vgmerge vg01 vg02 /dev/sdb1
