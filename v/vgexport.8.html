NAME

vgexport — Export LVM Volume Group

SYNOPSIS

vgexport [-v|--verbose] [-h|--help] [VolumeGroupName...]

DESCRIPTION

This command exports one or more volume groups, making them unavailable on the current system. The metadata for the exported volume groups is removed from the system's LVM configuration, and the underlying physical devices are made available for use on another system.

A volume group can be exported only if it contains no active logical volumes. Use lvchange -a n to deactivate all logical volumes in the volume group before exporting it.

The volume group name may be specified. If no volume group is specified, all volume groups that are not in use will be exported.

OPTIONS

-v|--verbose
Enables verbose mode. Multiple -v options increase verbosity.
-h|--help
Display usage information about this command. This will return 1 unless -q is used.
-q|--quiet
Suppress output and exit status messages. Exit status 0 means success, exit status >=1 means failure. In quiet mode, exit status 0 means success, exit status 1 means failure. In very quiet mode, exit status 0 means success, exit status 2 means error.
--force
Force the export of the volume group. This option is useful if the volume group is in an inconsistent state, but it should be used with extreme caution as it can lead to data loss.
--output OFMT
Specify the output format. The string OFMT must be one of the values lvm.conf(5) global/output_format. Defaults to `text'. The common output formats are:
text - text file
xml - XML format
-s|--selectSelect
Select the devices to export using device select criteria. See lvm(8) for syntax.
-t|--test
Perform a simulation of the command without making any actual changes. This is useful for testing and verifying commands before execution. The command will report what it would do, but will not modify the LVM configuration or data.
-u|--uuid UUID
Export the volume group with the specified UUID. This is useful when dealing with multiple volume groups that have the same name or when restoring a volume group from a backup.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution.

VARIABLES

VG
Volume Group name. See lvm(8) for valid names.
Tag
Tag name. See lvm(8) for information about tag names and using tags in place of a VG, LV or PV.
Select
Select indicates that a required positional parameter can be omitted if the --select option is used. No arg appears in this position.
UUID
The UUID of the volume group to be exported.
OFMT
Output format for the command's output. Refer to lvm.conf(5) for supported formats.

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

SEE ALSO

lvm(8), vgimport(8), vgchange(8), lvchange(8).
