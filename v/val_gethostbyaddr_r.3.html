val_gethostbyaddr_r(3)

الحزمة: dnssec-tools

التراخيص: BSD

val_gethostbyname(3) دليل المبرمج val_gethostbyname(3)

الاسم

val_gethostbyname(), val_gethostbyname2(), val_gethostbyname_r(), val_gethostbyname2_r() - الحصول على مدخل مضيف شبكة تم التحقق منه بواسطة DNSSEC

الوصف

val_gethostbyname()، val_gethostbyname2()، val_gethostbyname_r()، val_gethostbyname2_r()، val_gethostbyaddr() و val_gethostbyaddr_r() تقوم بالتحقق من صحة استعلامات DNS باستخدام DNSSEC. تقوم بإرجاع قيمة مدخل مضيف شبكة من النوع struct hostent وهي إصدارات مدركة لـ DNSSEC من وظائف gethostbyname(3)، gethostbyname2(3)، gethostbyname_r()، gethostbyname2_r()، gethostbyaddr() و gethostbyaddr_r() على التوالي. (انظر gethostbyname(3) لمزيد من المعلومات حول النوع struct hostent).

val_gethostbyname()، val_gethostbyname_r()، val_gethostbyaddr()، و val_gethostbyaddr_r() تدعم عناوين IPv4 فقط. val_gethostbyname2() و val_gethostbyname2_r() تدعم عناوين IPv4 و IPv6.

الوظائف val_gethostbyname_r()، val_gethostbyname2_r() و val_gethostbyaddr_r() هي إصدارات قابلة لإعادة الاستخدام ويمكن استخدامها بأمان في التطبيقات متعددة الخيوط.

المعلمة ctx تحدد سياق التحقق، والذي يمكن تعيينه إلى NULL للقيم الافتراضية (انظر libval(3) و dnsval.conf لمزيد من التفاصيل حول سياقات التحقق وسياسة التحقق).

val_gethostbyname()، val_gethostbyname2() و val_gethostbyaddr() تقوم بتعيين المتغير العام h_errno لإرجاع رمز خطأ المستكشف. الإصدارات القابلة لإعادة الاستخدام val_gethostbyname_r()، val_gethostbyname2_r() و val_gethostbyaddr_r() تستخدم المعلمة h_errnop لإرجاع هذه القيمة. هذا يضمن سلامة الخيوط، عن طريق تجنب المتغير العام h_errno. يجب ألا تكون h_errnop NULL. (انظر صفحة الدليل لـ gethostbyname(3) للقيم المحتملة لـ h_errno.)

المعلمات name، af، ret، buf، buflen، و result لها نفس الصيغة والدلالات للمعلمات المقابلة للوظائف الأصلية gethostbyname*() و gethostbyaddr*(). انظر صفحة الدليل لـ gethostbyname(3) لمزيد من التفاصيل حول هذه المعلمات.

تستخدم المعلمة val_status لإرجاع رمز خطأ المدقق ويجب ألا تكون NULL. يمكن استخدام val_istrusted() و val_isvalidated() لتحديد مدى موثوقية البيانات ويمكن استخدام p_val_status() لعرض قيمة الحالة للمستخدم بتنسيق ASCII (انظر libval(3) لمزيد من المعلومات).

قيم الإرجاع

الوظائف val_gethostbyname()، val_gethostbyname2()، و val_gethostbyaddr() ترجع مؤشرًا إلى بنية hostent عندما تتمكن من حل اسم المضيف المعطى (مع أو بدون التحقق من DNSSEC)، و NULL إذا لم تكن البيانات متاحة. الذاكرة للقيمة المرجعة مخصصة بشكل ثابت بواسطة هاتين الوظيفتين. لذلك، يجب على المتصل عدم تحرير الذاكرة للقيمة المرجعة.

الوظائف val_gethostbyname_r()، val_gethostbyname2_r() و val_gethostbyaddr_r() ترجع 0 عندما تتمكن من حل اسم المضيف المعطى (مع أو بدون التحقق من DNSSEC)، ورمز خطأ غير صفري عند الفشل.

الوظائف val_gethostbyaddr() و val_gethostbyaddr_r() ترجع 0 عندما تتمكن من حل اسم المضيف المعطى (مع أو بدون التحقق من DNSSEC)، ورمز خطأ غير صفري عند الفشل.

المعلمة val_status تعطي مؤشرًا على موثوقية البيانات. إذا كانت بنية hostent المرجعة NULL، فإن هذه القيمة تعطي مؤشرًا على ما إذا كان عدم وجود البيانات يمكن الوثوق به أم لا.

مثال

#include <stdio.h>
#include <stdlib.h>
#include <validator.h>

   int main(int argc, char *argv[])
   {
        int val_status;
        struct hostent *h = NULL;
        if (argc < 2) {
            printf("Usage: %s <hostname>\n", argv[0]);
            exit(1);
        }
        h = val_gethostbyname(NULL, argv[1], &val_status);
        printf("h_errno = %d [%s]\n", h_errno,
            hstrerror(h_errno));
        if (h) {
            printf("Validation Status = %d [%s]\n", val_status,
                   p_val_status(val_status));
        }
        return 0;
   }

ملاحظات

هذه الوظائف لا تقرأ حاليًا ترتيب البحث من /etc/hosts.conf. في الوقت الحالي، يتم تعيين الترتيب الافتراضي للتشاور مع ملف /etc/hosts أولاً ثم الاستعلام عن DNS.

الإصدارات الحالية لهذه الوظائف لا تدعم استعلامات NIS.
