أوامر SAM

vis يدعم صيغة تفاعلية من لغة الأوامر المستندة إلى التعبيرات العادية الهيكلية التي تم تقديمها بواسطة sam(1).

تعبيرات عادية

vis حاليًا يؤجل مطابقة التعبيرات العادية إلى مكتبة C الأساسية. يستخدم ما تشير إليه POSIX باسم "تعبيرات عادية موسعة" كما هو موضح في regex(7). المراسي ^ و $ تطابق بداية / نهاية النطاق الذي يتم تطبيقه عليها. بالإضافة إلى ذلك \n و \t يمكن استخدامها للإشارة إلى الأسطر الجديدة وعلامات الجدولة، على التوالي. الذرة . تطابق أي حرف باستثناء السطر الجديد. التعبير العادي الفارغ يمثل آخر تعبير كامل تم مواجهته.

عناوين

يشير العنوان إلى سلسلة فرعية (أو نطاق) في ملف. في ما يلي "حرف n" يعني السلسلة الفارغة بعد الحرف n-th في الملف، مع 1 الحرف الأول في الملف. "سطر n" يعني المطابقة n-th، بدءًا من بداية الملف، للتعبير العادي " .*\n?".

جميع النوافذ لديها دائمًا سلسلة حالية واحدة على الأقل وهي العنوان الافتراضي. في sam يشار إلى هذا باسم dot. في vis يمكن أن توجد "نقاط" متعددة (أو تحديدات) في نفس الوقت.

عناوين بسيطة

#n
السلسلة الفارغة بعد الحرف n; #0 هي بداية الملف.
n
السطر n.
/regexp/
 
?regexp?
السلسلة الفرعية التي تطابق التعبير العادي، تم العثور عليها بالبحث نحو نهاية (/) أو بداية (?) الملف. البحث لا يلتف حول عند الوصول إلى نهاية (بداية) الملف.

عناوين مركبة

في ما يلي، a1 و a2 هما عنوانان.

a1+a2
العنوان a2 تم تقييمه بدءًا من نهاية a1.
a1-a2
العنوان a2 تم تقييمه بالبحث في الاتجاه العكسي بدءًا من بداية a1.
a1,a2
السلسلة الفرعية من بداية a1 إلى نهاية a2. إذا كان a10. إذا كان a2$.
a1;a2
مثل a1,a2 ولكن مع a2 تم تقييمه في نهاية، ونطاق معين إلى، a1.

العوامل + و - لها أولوية عالية، بينما , و ; لها أولوية منخفضة.

في كلا صيغتي + و - ، إذا كان a2a1 مفقودًا، يتم استبدال .. إذا كان كل من a1 و a2+. قد يكون a2? الأحرف، فإن تأثير + أو - يتم عكسه. الرمز % هو اسم مستعار لـ , وبالتالي 0,$. إنه خطأ أن يمثل عنوان مركب سلسلة فرعية مشوهة.

أوامر

في ما يلي، يمثل النص المحدد بشرطات مائلة النص المحدد بأي حرف ASCII قابل للطباعة باستثناء الأحرف الأبجدية الرقمية. يمكن حذف أي عدد من المحددات اللاحقة، مع تمثيل متعدد للحذفات سلاسل فارغة، ولكن يجب أن يكون المحدد الأول موجودًا دائمًا. في أي نص محدد، لا يجوز ظهور حرف السطر الجديد حرفيًا؛ \n و \t يمكن كتابتها للسطر الجديد وعلامة الجدولة؛ \/ يقتبس المحدد، هنا /. يتم استبدال حرف العطف & و \n، حيث n هو رقم (1-9) بالسجل المقابل. يتم تفسير الشرطة المائلة بشكل حرفي بخلاف ذلك.

يمكن مسبوق معظم الأوامر بعنوان لتحديد نطاق عملها. إذا كان الأمر يتطلب عنوانًا ولم يتم توفيره، يتم استخدام عنوان افتراضي. في الوضع العادي، هذا يعادل الحرف الذي يقع عليه التحديد حاليًا. إذا كان هناك تحديد واحد فقط x و y افتراضيًا للملف بأكمله 0,$. في الوضع العادي، أوامر الكتابة w و wq تنطبق دائمًا على الملف بأكمله. يتم تنفيذ الأوامر مرة واحدة لكل تحديد. في الوضع المرئي، يتم تطبيق الأوامر على كل تحديد كما لو كان أمر x ضمني، يطابق التحديدات الموجودة، قد تم تقديمه.

في الوصف، يتم استخدام "نطاق" لتمثيل أي عنوان يتم توفيره.

العديد من الأوامر تنشئ تحديدات جديدة كأثر جانبي عند إصدارها من وضع مرئي. إذا كان الأمر كذلك، فإنه يكون دائمًا لـ "نتيجة" التغيير: النص الجديد للإدراج، السلسلة الفارغة للحذف، إخراج الأمر للتصفية، إلخ. إذا لم تتبق أي تحديدات بعد تنفيذ أمر ناجح، سيتحول المحرر إلى الوضع العادي، وإلا فإنه يبقى في الوضع المرئي. هذا يسمح بتحسينات *تفاعلية* للنطاقات.

COMMANDS

Vis supports a number of commands which are invoked by typing : (colon) to enter the command line or ? (question mark) to enter the search prompt.

:edit [file name]
edit a file
:open [file name]
open a file in the current window
:split [file name]
split window into rows (horizontally)
:vsplit [file name]
split window into columns (vertically)
:q[!] [exit code]
close currently focused window
:qall[!] [exit code]
close all windows, terminate editor with exit code (defaults to 0)

Commands taking a file name will invoke the vis-open(1) utility, if given a file pattern or directory.

Runtime key mappings

vis supports global as well as window local run time key mappings which are always evaluated recursively.

:map[!] mode lhs rhs
add a global key mapping
:map-window[!] mode lhs rhs
add a window local key mapping
:unmap mode lhs
remove a global key mapping
:unmap-window mode lhs
remove a window local key mapping

In the above mode refers to one of ‘normal’, ‘insert’, ‘replace’, ‘visual’, ‘visual-line’ or ‘operator-pending’; lhs refers to the key to map and rhs is a key action or alias. An existing mapping may be overridden by forcing the map command by specifying !.

Because key mappings are always recursive, doing something like:

:map! normal j 2j

will not work because it would enter an endless loop. Instead, vis uses pseudo keys referred to as key actions which can be used to invoke a set of available editor functions. :help lists all currently active key bindings as well as all available symbolic keys.

Keyboard Layout Specific Mappings

In order to facilitate usage of non-latin keyboard layouts, vis allows one to map locale specific keys to their latin equivalents by means of the

:langmap locale-keys latin-keys

command. As an example, the following maps the movement keys in Russian layout:

:langmap ролд hjkl

If the key sequences have not the same length, the remainder of the longer sequence will be discarded.

The defined mappings take effect in all non-input modes, i.e. everywhere except in insert and replace mode.

Undo/Redo

:earlier [count]
revert to older text state
:later [count]
revert to newer text state

If count is suffixed by either of d (days), h (hours), m (minutes) or s (seconds) it is interpreted as an offset from the current system time and the closest available text state is restored.

COMMAND and SEARCH PROMPT

MPT

أمر البحث المطالب به الذي تم فتحه بواسطة :، /، أو ? تم تنفيذه كنافذة بارتفاع سطر واحد، يعرض ملفًا عاديًا يبدأ تحريره في وضع الإدراج. <Esc> يتحول إلى الوضع العادي، و <Esc> ثانٍ يلغي المطالبة. <Up> يكبر النافذة، مما يتيح الوصول إلى سجل الأوامر. <C-v><Enter> يُدرج سطرًا جديدًا حرفيًا، وبالتالي يمكّن الأوامر متعددة الأسطر. <Enter> ينفذ التحديد المرئي إن وجد، أو غير ذلك كل شيء في المنطقة التي تتكون من موضع التحديد ورموز المطالبة الفاصلة في بداية الأسطر المجاورة.

التكوين

vis يستخدم Lua للتكوين ولأغراض البرمجة النصية. أثناء بدء التشغيل، يتم تحميل visrc.lua (انظر قسم الملفات) والتي يمكن استخدامها لتعيين خيارات التكوين الشخصية. على سبيل المثال، سيؤدي ما يلي إلى تمكين عرض أرقام الأسطر:

vis:command('set number')

البيئة

VIS_PATH
المسار الافتراضي للاستخدام لتحميل ملفات دعم Lua.
HOME
دليل المنزل المستخدم لأمر cd إذا لم يتم تقديم وسيط.
TERM
نوع الطرفية المستخدم لتهيئة واجهة الـ curses، افتراضيًا xterm إذا لم يتم تعيينها.
SHELL
صدفة الأوامر المستخدمة للأوامر المتعلقة بالإدخال / الإخراج مثل !، >، < و |.
XDG_CONFIG_HOME
دليل التكوين المستخدم، افتراضيًا $HOME/.config إذا لم يتم تعيينه.

الملفات

عند بدء التشغيل، سيقوم vis بتحميل أول ملف تكوين visrc.lua يتم العثور عليه من هذه المواقع. يمكن سرد جميع المسارات المستخدمة حاليًا في وقت التشغيل باستخدام الأمر :help.

  • $VIS_PATH
  • موقع الثنائي vis (على الأنظمة التي يتوفر فيها /proc/self/exe).
  • $XDG_CONFIG_HOME/vis حيث يشير XDG_CONFIG_HOME إلى $HOME/.config إذا لم يتم تعيينه.
  • /etc/vis للتكوين على مستوى النظام الذي يوفره المسؤول.
  • /usr/local/share/vis أو /usr/share/vis حسب تكوين البناء.

    عند إنشاء visrc.lua جديد، تأكد من نسخ الهيكل من هنا.

حالة الخروج

تخرج الأداة المساعدة vis بـ 0 عند النجاح، و >0 إذا حدث خطأ.

أمثلة

استخدم vis كمرشح تفاعلي.

$ { echo Pick your number; seq 1 10; } | vis - > choice

استخدم متصفح الملفات المستند إلى vis-open(1) لسرد جميع ملفات المصدر بلغة C:

:e *.c

قم بتشغيل عملية في الخلفية وقم بتوجيه النطاق إلى مدخلاتها القياسية:

:> { plumber <&3 3<&- & } 3<&0 1>&- 2>&-
