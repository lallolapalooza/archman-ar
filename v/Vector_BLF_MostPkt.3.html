MostPkt

Vector BLF - most recent packet in a BLF file

NAME

MostPkt - Reads the most recent packet from a BLF file.

SYNOPSIS

int MostPkt(const char *filename, struct BLF_Packet_t *packet);

Detailed Description

The MostPkt function reads the most recent packet from the specified BLF file. The packet's data is stored in the structure pointed to by packet. The function returns 0 on success and a negative value on error.
