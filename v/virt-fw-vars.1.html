NAME

virt-fw-vars — manipulate UEFI firmware variables

SYNOPSIS

virt-fw-vars [-h | --help] [-V | --version] [-i | --input FILE] [-o | --output FILE] [-p | --print] [-e | --enroll-redhat] [--secure-boot] [--boot-order ORDER] [-q | --quiet]

DESCRIPTION

The virt-fw-vars utility can be used to inspect and modify UEFI firmware variable files (OVMF).

UEFI firmware variable files are typically stored in a FAT filesystem. This utility expects the input file to be such a filesystem image.

The following actions are supported:

Print variable store.
virt-fw-vars --input ${guest}_VARS.fd \
--print --verbose
Enroll default (microsoft) secure boot certificates
virt-fw-vars --input OVMF_VARS.fd \
--output OVMF_VARS.secboot.fd \
--enroll-redhat \
--secure-boot
