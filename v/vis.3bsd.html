الوصف

تقوم الدالة vis() بنسخ سلسلة نصية تمثل الحرف c إلى dst. إذا لم يكن الحرف c بحاجة إلى ترميز، فسيتم نسخه دون تغيير. السلسلة النصية تنتهي بحرف NUL، ويتم إرجاع مؤشر إلى نهاية السلسلة. الحد الأقصى لطول أي ترميز هو أربعة بايتات (باستثناء الـ NUL اللاحق)؛ لذلك، عند ترميز مجموعة من الأحرف في مخزن مؤقت، يجب أن يكون حجم المخزن المؤقت أربعة أضعاف عدد البايتات المرمزة، بالإضافة إلى واحد للـ NUL اللاحق. يتم استخدام المعلمة flag لتعديل نطاق الأحرف الافتراضي الذي يتم النظر فيه للترميز ولتعديل التمثيل البصري. الحرف الإضافي، nextc، يستخدم فقط عند تحديد تنسيق ترميز VIS_CSTYLE (الموضح أدناه).

تقوم الدوال strvis()، stravis()، strnvis()، strvisx()، و strnvisx() بنسخ تمثيل بصري للسلسلة src إلى dst. تقوم الدوال strvis() و strnvis() بترميز الأحرف من src حتى أول حرف NUL. تقوم الدوال strvisx() و strnvisx() بترميز len من الأحرف بالضبط من src (وهذا مفيد لترميز كتلة بيانات قد تحتوي على أحرف NUL). كلا الشكلين ينهيان dst بحرف NUL. يجب أن يكون حجم dst أربعة أضعاف عدد البايتات المرمزة من src (بالإضافة إلى واحد للـ NUL). كلا الشكلين يرجعان عدد الأحرف في dst (لا يشمل الـ NUL اللاحق). الدالة stravis()

NAME

vis, strvis, strvisx, nvis, snvis, strnvis, strnvisx, strsnvis, strsnvisx - make characters visible

LIBRARY

libbsd — an implementation of BSD APIs for Linux

SYNOPSIS

#include <vis.h>


char *nvis(char *dst, const char *src, size_t dlen, int flag);
char *snvis(char *dst, const char *src, size_t dlen, int flag);
intstrnvis(char *dst, const char *src, size_t dlen, int flag);
intstrnvisx(char *dst, const char *src, size_t dlen, int flag, const char *Esc);
intstrsnvis(char *dst, const char *src, size_t dlen, int flag);
intstrsnvisx(char *dst, const char *src, size_t dlen, int flag, const char *Esc);
char *vis(char *dst, const char *src, int flag, int nextch);
char *strvis(char *dst, const char *src, int flag);
char *strvisx(char *dst, const char *src, int flag, int nextch);
char *svis(char *dst, const char *src, int flag, int nextch);
char *strsvis(char *dst, const char *src, int flag);
char *strsvisx(char *dst, const char *src, int flag, int nextch);

DESCRIPTION

The vis() family of functions convert arbitrary characters into a printable representation. This representation is suitable for displaying or storing data that may contain non-printable characters, such as control characters or characters with the high bit set.

The functions in this family fall into two groups based on the return value and buffer size handling.

vis(), strvis(), strvisx(), svis(), strsvis(), strsvisx()
These functions expect the destination buffer dst to be large enough to hold the result. It is the caller's responsibility to ensure that dst is sufficiently large. The functions return a pointer to the destination buffer dst. The maximum expansion of any input character is 4 bytes (e.g. ^A becomes \\001).
nvis(), snvis(), strnvis(), strnvisx(), strsnvis(), strsnvisx()
These functions take an additional argument dlen which specifies the maximum number of bytes that can be written to the destination buffer dst. If the conversion would exceed this size, the functions will return an error (see ERRORS). strnvis(), strnvisx(), strsnvis(), and strsnvisx() return the number of bytes written to dst, or -1 on error. nvis() and snvis() return a pointer to the destination buffer dst, or NULL on error.

The input is specified by the null-terminated string src. The converted output is stored in the buffer pointed to by dst.

The flag argument specifies how the conversion is performed. It is the bitwise OR of zero or more of the following flags:

VIS_CSTYLE
Use C-style backslash escaping. For example, newline is represented as \n, tab as \t, etc. Control characters are represented as ^C, where C is the appropriate character. Meta characters (characters with the high bit set) are represented as M-C, where C is the character with the high bit stripped.
VIS_DQFORM
Use the same encoding as VIS_CSTYLE, except that double quotes are escaped with a backslash, and the double quote character itself is escaped when it occurs at the beginning of the string or immediately after a backslash.
VIS_WHITE
Represent space characters as ␣ (unicode U+2423) instead of a space character. Other whitespace characters like tab, newline etc. are encoded using the VIS_CSTYLE method.
VIS_ALL
Encode all characters, including the space character. Space is encoded as \x20.
VIS_HTTPSTYLE
Use the percent-encoding scheme used in URLs (RFC 1738). The form is %XX where X represents a hexadecimal digit.
VIS_MIMESTYLE
Use MIME Quoted-Printable encoding as described in RFC 2045, only don't break lines and don't handle CRLF. The form is =XX where X represents an upper case hexadecimal digit.

There is one additional flag, VIS_NOSLASH, which inhibits the doubling of backslashes and the backslash before the default format (that is, control characters are represented by ^C and meta characters as M-C). With this flag set, the encoding is ambiguous and non-invertible.

MULTIBYTE CHARACTER SUPPORT

These functions support multibyte character input. The encoding conversion is influenced by the setting of the LC_CTYPE environment variable which defines the set of characters that can be copied without encoding.

If VIS_NOLOCALE is set, processing is done assuming the C locale and overriding any other environment settings.

When 8-bit data is present in the input, LC_CTYPE must be set to the correct locale or to the C locale. If the locales of the data and the conversion are mismatched, multibyte character recognition may fail and encoding will be performed byte-by-byte instead.

As noted above, dst must be four times the number of bytes processed from src. But note that each multibyte character can be up to MB_LEN_MAX bytes so in terms of multibyte characters, dst must be four times MB_LEN_MAX times the number of characters processed from src.

ENVIRONMENT

LC_CTYPE
Specify the locale of the input data. Set to C if the input data locale is unknown.

ERRORS

The functions nvis() and snvis() will return NULL and the functions strnvis(), strnvisx(), strsnvis(), and strsnvisx(), will return -1 when the dlen destination buffer size is not enough to perform the conversion while setting errno to:

[ENOSPC]
The destination buffer size is not large enough to perform the conversion.

HISTORY

The vis(), strvis(), and strvisx() functions first appeared in 4.4BSD. The svis(), strsvis(), and strsvisx() functions appeared in NetBSD 1.5. The buffer size limited versions of the functions (nvis(), strnvis(), strnvisx(), snvis(), strsnvis(), and strsnvisx()) appeared in NetBSD 6.0 and FreeBSD 9.2. Multibyte character support was added in NetBSD 7.0 and FreeBSD 9.2.
