Name

virkeycode-atset3 - Keyboard keycodes for ATset3 input device

DESCRIPTION

The ATset3 keyboard emulation sends keycodes that can be interpreted by the libvirt host. This page describes the mapping for ATset3 keyboard emulation.

The ATset3 keyboard emulation supports the following keys:

  • Keycodes: These are numerical codes representing physical keys on a keyboard. The virkeycode tool can be used to list and test keycodes.

  • Shift states: Keycodes can be modified by shift states (Shift, Ctrl, Alt, etc.) to produce different characters or actions.
