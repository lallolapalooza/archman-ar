NAME

virkeycode — Key codes for virtual machines

DESCRIPTION

This document lists the key codes that can be used with virkeycode(1) command. The key codes are represented as numerical values, optionally in hexadecimal format prefixed with "0x", and also as symbolic names.

The key codes are derived from the Linux kernel's input event codes, but some have been mapped or renamed for consistency with libvirt.

The following key codes are supported:
