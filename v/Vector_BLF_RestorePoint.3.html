وصف مفصل

نقطة استعادة

يتم الاحتفاظ بنقاط الاستعادة في قائمة هي في الأساس فهرس يشير إلى كل كائن رقم 1001. لذلك، مع تخطي الكائن 0، فإنه يعد 1000، 2001، 3002، ...

ملاحظة

يعتمد هذا الفصل على الملاحظات، حيث لا تتوفر وثائق عامة. هناك وظائف API غير موثقة للتعامل مع RestorePoint. ويبدو أن هذا هو الحال.

يعمل

غير واضح ما هي هذه المتغير.

ربما مجرد حقل محجوز للامتدادات المستقبلية.

تظهر الأمثلة:

  • File1: 0, 0x9a
  • File2: 0, 1, 2, 3, 4, 5, 6
  • File3: 0, 0xffffffff, 0x10020
  • File4: 0xb9
  • File5: 0, 0x2c9a8a00

هذه بيانات مشابهة لتلك الخاصة بـ LogContainer.unknownLogContainer.
