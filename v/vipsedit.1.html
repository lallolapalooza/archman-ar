vipsedit(1)

الحزمة: libvips

التراخيص: LGPL-2.1-or-later

VIPSEDIT(1) دليل الأوامر العامة VIPSEDIT(1)

الاسم

vipsedit - تعديل رأس ملف صورة vips

الملخص

vipsedit [خيار...] ملف_vips

الوصف

يغير vipsedit رأس ملف صورة VIPS. هذا مفيد لتعيين الدقة، على سبيل المثال.

الخيارات هي:


-x, --xsize=N تعيين Xsize إلى N
-y, --ysize=N تعيين Ysize إلى N
-b, --bands=N تعيين Bands إلى N
-f, --format=F تعيين BandFmt إلى F (مثل uchar)
-i, --interpretation=I
تعيين Interpretation إلى I (مثل xyz)
-c, --coding=C تعيين Coding إلى C (مثل labq)
-X, --xres=R تعيين Xres إلى R بكسل/مم
-Y, --yres=R تعيين Yres إلى R بكسل/مم
-u, --xoffset=N تعيين Xoffset إلى N
-v, --yoffset=N تعيين Yoffset إلى N
-e, --setext استبدال كتلة الامتداد بـ stdin

كن حذرًا جدًا عند تغيير Xsize أو Ysize أو BandFmt أو Bands. لا يقوم vipsedit بأي تحقق!

أمثلة

لتعيين Xsize إلى 512 و Bands إلى 6:


vipsedit --xsize=512 --bands=6 fred.v

أو


vipsedit -x 512 -b 6 fred.v

استخراج بيانات التعريف XML من صورة باستخدام vipsheader(1)، وتعديلها، وإعادة إرفاقها باستخدام vipsedit(1).


vipsheader -f getext fred.v | sed s/banana/pineapple/ | vipsedit -e fred.v

قيمة الإرجاع

تُرجع 0 عند النجاح وغير صفر عند حدوث خطأ.
