vde_tunctl(8)

الحزمة: vde2

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later

VDE_TUNCTL(8) دليل مدير النظام VDE_TUNCTL(8)

الاسم

vde_tunctl — إنشاء وإدارة واجهات TUN/TAP مستمرة

الملخص

vde_tunctl [-f clonedev] [-u owner] [-g group] [-n] [-t dev-name]

vde_tunctl [-f clonedev] -d dev-name

الوصف

vde_tunctl تسمح لمسؤول النظام بتكوين جهاز TUN/TAP مسبقًا لاستخدامه بواسطة مستخدم معين. يمكن لهذا المستخدم فتح الجهاز واستخدامه، ولكنه لا يمكنه تغيير أي جوانب من جانب المضيف للواجهة.

vde_tunctl هو امتداد لـ tunctl.

يقوم vde_tunctl بتعريف واجهات tap ما لم يبدأ dev-name بـ "tun" أو يظهر الخيار -n في سطر الأوامر.

الاستخدام

لإنشاء واجهة لاستخدامها بواسطة مستخدم معين، قم بتشغيل tunctl بدون الخيار -d:

# vde_tunctl -u someuser  
تعيين 'tap0' مستمر ومملوك لـ uid 500

بعد ذلك، قم بتكوين الواجهة كالمعتاد:

# ifconfig tap0 192.168.0.254 up  
# route add -host 192.168.0.253 dev tap0  
# bash -c 'echo 1 > /proc/sys/net/ipv4/conf/tap0/proxy_arp'  
# arp -Ds 192.168.0.253 eth0 pub

لحذف الواجهة، استخدم الخيار -d:

# vde_tunctl -d tap0  
تعيين 'tap0' غير مستمر

لإنشاء أو تدمير واجهة tun (بدلاً من tap):

# vde_tunctl -n -u someuser
تعيين 'tun0' مستمر ومملوك لـ uid 500
# vde_tunctl -d tun0
تعيين 'tun0' غير مستمر
