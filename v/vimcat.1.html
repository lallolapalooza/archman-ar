vimcat(1)

الحزمة: vimpager

التراخيص: custom:BSD

VIMCAT(1) VIMCAT(1)

الاسم

vimcat - مسلط الضوء النحوي المعتمد على vim

ملخص

vimcat some_file

الوصف

يُخرج محتويات ملف إلى المخرج القياسي، مع تسليط الضوء النحوي باستخدام vim كواجهة خلفية.

على GitHub: http://github.com/rkitover/vimpager

لاستخدام vimrc مختلف مع vimcat، ضع إعداداتك في ملف ~ / .vimcatrc.

لتعطيل تحميل الملحقات، ضع "set noloadplugins" في ملف ~ / .vimcatrc.

خيارات سطر الأوامر

-c cmd

تشغيل أمر vim بعد فتح الملف. يتم دعم وسيطات -c متعددة.

--cmd cmd

تشغيل أمر vim عند دخول vim قبل أي شيء آخر. يتم دعم وسيطات --cmd متعددة.

-u vimrc

استخدام .vimrc بديل أو .vimcatrc.
