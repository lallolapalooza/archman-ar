vmod_cookie(3)

الحزمة: varnish

التراخيص: BSD-2-Clause

VMOD_COOKIE(3) دليل وظائف المكتبة VMOD_COOKIE(3)

الاسم

vmod_cookie - وحدة Varnish لملفات تعريف الارتباط (Cookies)

الملخص

الوصف

التعامل مع ملفات تعريف الارتباط HTTP بسهولة أكبر في Varnish VCL.

يقوم بتحليل رأس ملف تعريف الارتباط إلى مخزن بيانات داخلي، حيث تتوفر وظائف `get`/`set`/`delete` لكل ملف تعريف ارتباط. تقوم وظيفة `keep()` بإزالة جميع ملفات تعريف الارتباط باستثناء قائمة محددة مفصولة بفواصل. تقوم وظيفة `filter()` بإزالة قائمة ملفات تعريف الارتباط المفصولة بفواصل.

يمكن استخدام التعبيرات العادية لاختيار ملفات تعريف الارتباط، أو حذف ملفات تعريف الارتباط المطابقة، أو حذف أسماء ملفات تعريف الارتباط غير المطابقة.

تم تضمين وظيفة مساعدة لتنسيق حقل تاريخ `Expires` الخاص بـ `Set-Cookie`.

عمر الحالة المحملة باستخدام `cookie.parse()` هو سياق الطلب الحالي أو سياق طلب الخلفية. لتمرير المتغيرات إلى طلب الخلفية، قم بتخزين المحتويات كرؤوس `bereq` وهمية.

مثال على التصفية:

import cookie;
sub vcl_recv {
    if (req.http.cookie) {
        cookie.parse(req.http.cookie);
        # إما حذف تلك التي تريد التخلص منها:
        cookie.delete("cookie2");
        # أو حذف الكل باستثناء القليل:
        cookie.keep("SESSIONID,PHPSESSID");
        # تخزينها مرة أخرى في req ليتم تمريرها إلى الخلفية.
        set req.http.cookie = cookie.get_string();
        # إذا كانت فارغة، قم بإلغاء تعيينها حتى تتمكن VCL المدمجة من النظر فيها للتخزين المؤقت.
        if (req.http.cookie == "") {
            unset req.http.cookie;
        }
    }
}

VOID clean()

تنظيف ملفات تعريف الارتباط التي تم تحليلها مسبقًا. لا يلزم تشغيل `clean()` في العمليات العادية.

مثال:

sub vcl_recv {
    cookie.clean();
}

VOID delete(STRING cookiename)

حذف cookiename من تخزين vmod الداخلي إذا كان موجودًا.

مثال:

sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2");
    cookie.delete("cookie2");
    # سيؤدي get_string() الآن إلى إرجاع "cookie1=value1"
}

VOID filter(STRING filterstring)

حذف جميع ملفات تعريف الارتباط من تخزين vmod الداخلي الموجودة في قائمة أسماء ملفات تعريف الارتباط المفصولة بفواصل.

مثال:

sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2; cookie3=value3");
    cookie.filter("cookie1,cookie2");
    # سيؤدي get_string() الآن إلى إرجاع "cookie3=value3"
}

VOID filter_re(REGEX expression)

حذف جميع ملفات تعريف الارتباط من تخزين vmod الداخلي التي تطابق التعبير العادي expression.

مثال:

sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2; cookie3=value3");
    cookie.filter_re("^cookie[12]$");
    # سيؤدي get_string() الآن إلى إرجاع "cookie3=value3"
}

VOID keep(STRING filterstring)

حذف جميع ملفات تعريف الارتباط من تخزين vmod الداخلي التي ليست ضمن قائمة أسماء ملفات تعريف الارتباط المفصولة بفواصل.

مثال:

sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2; cookie3=value3");
    cookie.keep("cookie1,cookie2");
    # سيؤدي get_string() الآن إلى إرجاع "cookie1=value1; cookie2=value2"
}

VOID keep_re(REGEX expression)

حذف جميع ملفات تعريف الارتباط من تخزين vmod الداخلي التي لا تتطابق مع التعبير expression.

مثال:

sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2; cookie3=value3");
    cookie.keep_re("^cookie[12]$");
    # سيؤدي get_string() الآن إلى إرجاع "cookie1=value1; cookie2=value2"
}

STRING format_date(TIME now, DURATION timedelta)

الحصول على سلسلة تاريخ منسقة بتنسيق RFC1123 مناسبة للإدراج في رأس الاستجابة `Set-Cookie`.

يجب توخي الحذر إذا كانت الاستجابة تحتوي على رؤوس `Set-Cookie` متعددة. في هذه الحالة، يجب استخدام وحدة الرأس (`header vmod`).

مثال:

sub vcl_deliver {
    # تعيين ملف تعريف ارتباط للمستخدم على العميل يستمر لمدة 5 دقائق.
    set resp.http.Set-Cookie = "userid=" + req.http.userid +
        "; Expires=" + cookie.format_date(now, 5m) + "; httpOnly";
}

STRING get(STRING cookiename)

الحصول على قيمة cookiename، كما تم تخزينها في تخزين vmod الداخلي.

مثال:

import std;
sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2");
    std.log("قيمة cookie1 هي: " + cookie.get("cookie1"));
}

إذا كان cookiename غير موجود، يتم إرجاع السلسلة NULL. لاحظ أنه يتم تحويل السلسلة NULL إلى سلسلة فارغة عند تعيينها لرأس. هذا يعني أن ما يلي صحيح:

if (req.http.Cookie) {
        cookie.parse(req.http.Cookie);
        set req.http.X-tmp = cookie.get("a_cookie");
} else {
        set req.http.X-tmp = "";
}
if (req.http.X-tmp != "") {
        # فعل شيئا مع رأس X-tmp...
} else {
        # حالة احتياطية
}

ومع ذلك، غالبًا ما يكون استخدام `cookie.isset()` طريقة أفضل للتحقق مما إذا كان ملف تعريف ارتباط معين موجودًا، كما يلي:

unset req.http.X-tmp; # غير ضروري إذا لم تكن هناك حاجة لحالة احتياطية
if (req.http.Cookie) {
        cookie.parse(req.http.Cookie);
        if (cookie.isset("a_cookie")) {
                set req.http.X-tmp = cookie.get("a_cookie");
                # فعل شيئا مع رأس X-tmp...
        }
}
# إذا لزم الأمر، افعل شيئًا عندما لا يكون a_cookie موجودًا
if (!req.http.X-tmp) {
        # حالة احتياطية
}

STRING get_re(REGEX expression)

الحصول على قيمة أول ملف تعريف ارتباط في تخزين vmod الداخلي الذي يطابق التعبير العادي expression. إذا لم يتطابق شيء، يتم إرجاع السلسلة NULL.

مثال:

import std;
sub vcl_recv {
    cookie.parse("cookie1=value1; cookie2=value2");
    std.log("قيمة cookie1 هي: " + cookie.get_re("^cookie1$"));
}

STRING get_string()

الحصول على قيمة سلسلة ملف تعريف ارتباط مع جميع ملفات تعريف الارتباط في تخزين vmod الداخلي. لا يعدل التخزين الداخلي.

مثال:

sub vcl_recv {
    cookie.parse(req.http.cookie);
    cookie.keep("SESSIONID,PHPSESSID");
    set req.http.cookie = cookie.get_string();
}

BOOL isset(STRING cookiename)

التحقق مما إذا كان cookiename موجودًا في تخزين vmod الداخلي.

مثال:

import std;
sub vcl_recv {
    cookie.parse(req.http.cookie);
    if (cookie.isset("SESSIONID")) {
        std.log("SESSIONID is set");
    }
}

VOID parse(STRING cookieheader)

تحليل رأس HTTP cookieheader وتخزين ملفات تعريف الارتباط المفردة في تخزين vmod الداخلي.

مثال:

sub vcl_recv {
    cookie.parse(req.http.cookie);
}

VOID set(STRING cookiename, STRING value)

قم بتعيين أو تحديث ملف تعريف الارتباط cookiename بالقيمة value في تخزين vmod الداخلي.

مثال:

sub vcl_recv {
    cookie.set("cookie1", "value1");
    cookie.set("cookie2", "value2");
    # get_string() سيؤدي الآن إلى إرجاع "cookie1=value1; cookie2=value2"
}
