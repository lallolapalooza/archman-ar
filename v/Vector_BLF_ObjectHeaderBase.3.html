Vector_BLF_ObjectHeaderBase

NAME

Vector_BLF_ObjectHeaderBase - Base class for BLF object headers

SYNOPSIS

#include <vector/vector_blf_types.h>

Class Vector_BLF_ObjectHeaderBase

DESCRIPTION

The Vector_BLF_ObjectHeaderBase class is the base class for all BLF object headers. It provides common fields such as object type, size, and timestamp.

PUBLIC ATTRIBUTES

uint16_t type
The type of the BLF object.
uint16_t size
The size of the BLF object in bytes.
uint64_t timestamp
The timestamp of the BLF object.
