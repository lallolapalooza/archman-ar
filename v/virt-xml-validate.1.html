virt-xml-validate(1)

الحزمة: libvirt

التراخيص: LGPL-2.1-or-later, GPL-3.0-or-later

virt-xml-validate(1) دعم المحاكاة الافتراضية virt-xml-validate(1)

الاسم

virt-xml-validate - التحقق من صحة ملفات libvirt XML مقابل مخطط

الملخص

virt-xml-validate XML-FILE [SCHEMA-NAME]

virt-xml-validate OPTION

الوصف

يتحقق من صحة ملفات libvirt XML للتوافق مع المخطط المنشور. الوسيط الإلزامي الأول هو المسار إلى ملف XML الذي سيتم التحقق منه. الوسيط الثاني الاختياري هو اسم المخطط للتحقق ضده. إذا تم حذفه، فسيتم استنتاج اسم المخطط من اسم العنصر الجذر في مستند XML.

أسماء المخططات الصالحة حاليًا تشمل:

•
cpu

مخطط التنسيق XML للمعالج.

•
domainsnapshot

مخطط تنسيق XML المستخدم لتكوين لقطة النطاق.

•
domaincheckpoint

مخطط تنسيق XML المستخدم لتكوين نقطة فحص النطاق.

•
domainbackup

مخطط تنسيق XML المستخدم لتكوين نسخة احتياطية للنطاق.

•
domaincaps

مخطط تنسيق XML لقدرات النطاق.

•
domain

مخطط تنسيق XML المستخدم لتكوين نطاقات الضيف.

•
networkport

مخطط تنسيق XML المستخدم لتكوين منفذ الشبكة.

•
network

مخطط تنسيق XML لتكوين الشبكة الافتراضية.

•
storagepoolcaps

مخطط تنسيق XML لقدرات مجمع التخزين.

•
storagepool

مخطط تنسيق XML لتكوين مجمع التخزين.

•
storagevol

مخطط تنسيق XML لوصف وحدات التخزين.

•
nodedev

مخطط تنسيق XML لوصف أجهزة العقدة.

•
capability

مخطط تنسيق XML للإعلان عن قدرات المشغل.

•
nwfilter

مخطط تنسيق XML لمرشحات حركة مرور الشبكة.

•
nwfilterbinding

مخطط تنسيق XML لربط مرشحات الشبكة.

•
secret

مخطط تنسيق XML لوصف الأسرار.

•
interface

مخطط تنسيق XML لواجهات المضيف المادية.
