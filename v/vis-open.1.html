NAME

vis-open — تحديد ملف لفتحه بشكل تفاعلي

SYNOPSIS

vis-open [-p prompt] [-f] [--] [files]

vis-open -h

DESCRIPTION

vis-open يأخذ قائمة بأسماء الملفات والمجلدات في سطر الأوامر ويعرضها في قائمة للمستخدم للاختيار. إذا اختار المستخدم مجلدًا (بما في ذلك ..)، يتم عرض محتويات المجلد كقائمة جديدة. بمجرد أن يختار المستخدم اسم ملف، يتم طباعة مساره المطلق إلى الإخراج القياسي.

vis-open يستخدم vis-menu(1) كواجهة مستخدم له، لذا راجع تلك الصفحة لمزيد من التفاصيل.

-p prompt
عرض prompt قبل قائمة العناصر. يتم تمرير هذا مباشرة إلى vis-menu(1).
-f
بشكل طبيعي، إذا تم تزويد vis-open بوسيط ملف أو مجلد واحد، فسيتم اختياره تلقائيًا (طباعة اسم الملف إلى الإخراج القياسي، أو تقديم قائمة جديدة بمحتويات المجلد). إذا تم توفير -f، فسيعرض vis-open دائمًا الوسائط التي يتلقاها، حتى لو كان هناك واحد فقط.
--
إذا تم العثور على هذا الرمز قبل أول وسيط غير خيار، فسيتم التعامل مع جميع الوسائط اللاحقة كعناصر قائمة، حتى لو كانت بخلاف ذلك خيارات صالحة لسطر الأوامر.

إذا تم العثور عليه بعد أول وسيط غير خيار، أو بعد مثيل سابق لـ --، فيتم التعامل معه كعنصر قائمة.

files
أسماء الملفات والمجلدات التي سيتم تقديمها للمستخدم. إذا لم يكن الاسم موجودًا في نظام الملفات وقام المستخدم باختياره، فسيتم التعامل معه كملف.
-h
إذا كان موجودًا، يطبع vis-open ملخصًا للاستخدام ويخرج، متجاهلاً أي علامة ووسائط أخرى.

EXIT STATUS

يخرج الأداة المساعدة vis-open عند النجاح، ويخرج بقيمة أكبر من 0 إذا حدث خطأ.

على وجه الخصوص، مثل vis-menu(1)، لا يطبع vis-open شيئًا ويضبط حالة الخروج الخاصة به على 1 إذا رفض المستخدم تحديد ملف.

EXAMPLES

CHOICE=$(vis-open -p "Select a file to stat")
if [ $? -gt 0 ]; then
	echo "No selection was made, or an error occurred"
else
	stat "$CHOICE"
fi

SEE ALSO

vis(1), vis-menu(1)

BUGS

نظرًا لأن vis-open يستخدم ls(1) للحصول على محتويات المجلد، فقد تحدث أشياء غريبة إذا كان لديك أحرف تحكم في أسماء ملفاتك.
