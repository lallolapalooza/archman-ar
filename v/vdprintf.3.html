الاسم

printf, fprintf, dprintf, sprintf, snprintf, vprintf, vfprintf, vdprintf, vsprintf, vsnprintf - تحويل المخرجات المنسقة

المكتبة

مكتبة C القياسية (libc, -lc)

int printf(const char *restrict format, ...);

الوصف

تقوم الوظائف في عائلة printf() بإنتاج مخرجات وفقًا لـ format كما هو موضح أدناه. تكتب الوظيفتان printf() و vprintf() المخرجات إلى stdout، دفق الإخراج القياسي؛ تكتب fprintf() و vfprintf() المخرجات إلى دفق الإخراج المحدد stream؛ تكتب sprintf() و snprintf() و vsprintf() و vsnprintf() إلى سلسلة الأحرف str.

الوظيفة dprintf() هي نفسها الوظيفة fprintf() باستثناء أنها تنتج المخرجات إلى واصف ملف، fd، بدلاً من دفق stdio(3).

تكتب الوظيفتان snprintf() و vsnprintf() ما لا يزيد عن size بايت (بما في ذلك البايت الصفري النهائي ('\0')) إلى str.

الوظائف vprintf() و vfprintf() و vdprintf() و vsprintf() و vsnprintf() تعادل الوظائف printf() و fprintf() و dprintf() و sprintf() و snprintf() على التوالي، باستثناء أنها تُستدعى مع va_list بدلاً من عدد متغير من الوسائط. لا تستدعي هذه الوظائف ماكرو va_end. نظرًا لأنها تستدعي ماكرو va_arg، فإن قيمة ap غير محددة بعد الاستدعاء. انظر stdarg(3).

تقوم جميع هذه الوظائف بكتابة المخرجات تحت سيطرة سلسلة format التي تحدد كيفية تحويل الوسائط اللاحقة (أو الوسائط التي يتم الوصول إليها عبر مرافق الوسائط المتغيرة الطول في stdarg(3)) للإخراج.

يحدد C99 و POSIX.1-2001 أن النتائج غير محددة إذا أدى استدعاء sprintf() أو snprintf() أو vsprintf() أو vsnprintf() إلى نسخ بين الكائنات المتداخلة (على سبيل المثال، إذا كان صفيف السلسلة الهدف وأحد الوسائط المقدمة يشير إلى نفس المخزن المؤقت). انظر التحذيرات.

تنسيق سلسلة التنسيق

سلسلة التنسيق هي سلسلة أحرف، تبدأ وتنتهي في حالة التحول الأولية الخاصة بها، إن وجدت. تتكون سلسلة التنسيق من صفر أو أكثر من التوجيهات: أحرف عادية (ليست %)، والتي يتم نسخها دون تغيير إلى دفق الإخراج؛ ومواصفات تحويل، ينتج كل منها عن جلب صفر أو أكثر من الوسائط اللاحقة. يتم تقديم كل مواصفات تحويل بالحرف %، وتنتهي بـ محدد تحويل. بينهما قد يكون (بهذا الترتيب) صفر أو أكثر من الأعلام، وعرض الحقل الأدنى الاختياري، ودقة اختيارية، ومعدل طول اختياري.

الصيغة العامة لمواصفات التحويل هي:


%[argument$][flags][width][.precision][length modifier]conversion

يجب أن تتوافق الوسائط بشكل صحيح (بعد ترقية النوع) مع محدد التحويل. افتراضيًا، يتم استخدام الوسائط بالترتيب المعطى، حيث يطلب كل '*' (انظر عرض الحقل والدقة أدناه) وكل محدد تحويل الوسيطة التالية (ويكون خطأ إذا تم تقديم عدد غير كافٍ من الوسائط). يمكن أيضًا تحديد بشكل صريح أي وسيطة يتم أخذها، في كل مكان تكون فيه وسيطة مطلوبة، عن طريق كتابة "%m$" بدلاً من '%' و "*m$" بدلاً من '*'، حيث يشير العدد الصحيح العشري m إلى موضع الوسيطة في قائمة الوسائط المطلوبة، مرقمة بدءًا من 1. لذلك،


printf("%*d", width, num);

و


printf("%2$*1$d", width, num);

متكافئان. يسمح النمط الثاني بالإشارة المتكررة إلى نفس الوسيطة. لا يتضمن معيار C99 النمط الذي يستخدم '$'، والذي يأتي من مواصفات UNIX الواحدة. إذا تم استخدام النمط الذي يستخدم '$'، فيجب استخدامه في كل مكان لجميع التحويلات التي تأخذ وسيطة وجميع وسائط العرض والدقة، ولكن يمكن مزجه مع تنسيقات "%%"، والتي لا تستهلك وسيطة. قد لا تكون هناك فجوات في أرقام الوسائط المحددة باستخدام '$'. على سبيل المثال، إذا تم تحديد الوسيطتين 1 و 3، فيجب أيضًا تحديد الوسيطة 2 في مكان ما في سلسلة التنسيق.

بالنسبة لبعض التحويلات الرقمية، يتم استخدام حرف القاعدة ("الفاصل العشري") أو حرف تجميع الآلاف. تعتمد الأحرف الفعلية المستخدمة على جزء LC_NUMERIC من الإعداد المحلي. (انظر setlocale(3).) الإعداد المحلي POSIX يستخدم '.' كحرف عشري، ولا يحتوي على حرف تجميع. لذلك،


printf("%'.2f", 1234567.89);

ينتج عنه "1234567.89" في الإعداد المحلي POSIX، و "1234567,89" في إعداد nl_NL المحلي، و "1.234.567,89" في إعداد da_DK المحلي.

NAME

vdprintf — print output to a file descriptor

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <stdio.h>
#include <stdarg.h>
int vdprintf(int fd, const char *format, va_list ap);

DESCRIPTION

The vdprintf() function is the same as dprintf() (see dprintf(3)), with the difference that the C variable, ap, which receives the list of arguments must have been initialized by va_start(3) in some compatible way with the corresponding vprintf family function.

The vdprintf() function should not be used before a call to va_start().

The C variable argument list ap is traversed by the va_arg() macro (in stdarg.h), passing all arguments to vdprintf() that were not supplied as arguments to the calling function.

The entire list of arguments is passed by value, and may not be permanently modified.

After the call to vdprintf(), the argument list ap is undefined. The calling function must then call va_end() to clean up.

The vdprintf() function writes output to the file descriptor fd.

The vdprintf() function is equivalent to calling dprintf(3) with the same arguments.

RETURN VALUE

Upon successful completion, vdprintf() returns the number of characters written. Otherwise, it returns a negative value and sets errno to indicate the error.

ERRORS

See dprintf(3).

ATTRIBUTES

For an explanation of the terms used in this section, see attributes(7).

+------------------------------------+--------------+
| Interface                          | Attribute    |
+------------------------------------+--------------+
| vdprintf(3)                        | robustness   |
+------------------------------------+--------------+

STANDARDS

vdprintf() is a non-standard extension, available since glibc 2.0.

HISTORY

vdprintf() first appeared in glibc.

CAVEATS

The vsnprintf() function is the preferred way to safely format strings into a buffer, as it doesn't require guessing the buffer size beforehand.

BUGS

The implementation of vsnprintf() in glibc versions prior to 2.0.6 did not correctly handle the case where the buffer size was not sufficient to hold the entire output string. If truncation occurred, the return value was undefined.

EXAMPLES

To print Pi to five decimal places:


#include <math.h>
#include <stdio.h>
fprintf(stdout, "pi = %.5f\n", 4 * atan(1.0));

To print a date and time in the form "Sunday, July 3, 10:02", where weekday and month are pointers to strings:


#include <stdio.h>
fprintf(stdout, "%s, %s %d, %.2d:%.2d\n",
        weekday, month, day, hour, min);

Many countries use the day-month-year order. Hence, an internationalized version must be able to print the arguments in an order specified by the format:


#include <stdio.h>
fprintf(stdout, format,
        weekday, month, day, hour, min);

where format depends on locale, and may permute the arguments. With the value:


"%1$s, %3$d. %2$s, %4$d:%5$.2d\n"

one might obtain "Sonntag, 3. Juli, 10:02".

To allocate a sufficiently large string and print into it (code correct for both glibc 2.0 and glibc 2.1):

#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
char *
make_message(const char *fmt, ...)
{
    int n = 0;
    size_t size = 0;
    char *p = NULL;
    va_list ap;
    /* Determine required size.  */
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0)
        return NULL;
    size = (size_t) n + 1;      /* One extra byte for '\0' */
    p = malloc(size);
    if (p == NULL)
        return NULL;
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0) {
        free(p);
        return NULL;
    }
    return p;
}

If truncation occurs in glibc versions prior to glibc 2.0.6, this is treated as an error instead of being handled gracefully.

``` ```arabic vdprintf(3) — صفحات دليل أرتش لينكس

الاسم

vdprintf — طباعة المخرجات إلى واصف ملف

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdio.h>
#include <stdarg.h>
int vdprintf(int fd, const char *format, va_list ap);

الوصف

الدالة vdprintf() هي نفسها الدالة dprintf() (انظر dprintf(3))، مع اختلاف أن قائمة المتغيرات C، ap، التي تستقبل قائمة الوسائط يجب أن تكون قد تم تهيئتها بواسطة va_start(3) بطريقة متوافقة مع دالة vprintf المقابلة.

لا ينبغي استخدام الدالة vdprintf() قبل استدعاء va_start().

يتم اجتياز قائمة المتغيرات C ap بواسطة الماكرو va_arg() (في stdarg.h)، وتمرير جميع الوسائط إلى vdprintf() التي لم يتم توفيرها كوسائط للدالة المستدعية.

يتم تمرير قائمة الوسائط بأكملها بالقيمة، وقد لا يتم تعديلها بشكل دائم.

بعد استدعاء vdprintf()، تكون قائمة الوسائط ap غير محددة. يجب على الدالة المستدعية بعد ذلك استدعاء va_end() للتنظيف.

تكتب الدالة vdprintf() المخرجات إلى واصف الملف fd.

الدالة vdprintf() مكافئة لاستدعاء dprintf(3) بنفس الوسائط.

قيمة الإرجاع

عند اكتمالها بنجاح، تعيد الدالة vdprintf() عدد الأحرف التي تم كتابتها. بخلاف ذلك، فإنها تعيد قيمة سالبة وتعيّن errno للإشارة إلى الخطأ.

الأخطاء

انظر dprintf(3).

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

| الواجهة                          | السمة    |

المعايير

vdprintf() هو امتداد غير قياسي، متاح منذ glibc 2.0.

التاريخ

ظهرت vdprintf() لأول مرة في glibc.

تنبيهات

الدالة vsnprintf() هي الطريقة المفضلة لتنسيق السلاسل بشكل آمن في مخزن مؤقت، لأنها لا تتطلب تخمين حجم المخزن المؤقت مسبقًا.

أخطاء

لم تتعامل آلية تنفيذ vsnprintf() في إصدارات glibc قبل 2.0.6 بشكل صحيح مع الحالة التي لم يكن فيها حجم المخزن المؤقت كافيًا لاحتواء سلسلة الإخراج بأكملها. إذا حدث اقتطاع، فإن قيمة الإرجاع لم تكن محددة.

أمثلة

لطباعة Pi بخمسة أرقام عشرية:


#include <math.h>
#include <stdio.h>
fprintf(stdout, "pi = %.5f\n", 4 * atan(1.0));

لطباعة تاريخ ووقت بالشكل "الأحد، يوليو 3، 10:02"، حيث weekday و month مؤشرات إلى سلاسل نصية:


#include <stdio.h>
fprintf(stdout, "%s, %s %d, %.2d:%.2d\n",
        weekday, month, day, hour, min);

تستخدم العديد من البلدان ترتيب اليوم-الشهر-السنة. لذلك، يجب أن يكون الإصدار المترجم قادرًا على طباعة الوسائط بترتيب محدد بواسطة التنسيق:


#include <stdio.h>
fprintf(stdout, format,
        weekday, month, day, hour, min);

حيث يعتمد format على اللغة المحلية، وقد يقوم بتبديل ترتيب الوسائط. مع القيمة:


"%1$s, %3$d. %2$s, %4$d:%5$.2d\n"

قد يتم الحصول على "Sonntag, 3. Juli, 10:02".

لتخصيص سلسلة نصية بحجم كبير وطباعة إليها (الكود صحيح لكل من glibc 2.0 و glibc 2.1):

#include <stdio.h>
#include <stdlib.h>
#include <stdarg.h>
char *
make_message(const char *fmt, ...)
{
    int n = 0;
    size_t size = 0;
    char *p = NULL;
    va_list ap;
    /* تحديد الحجم المطلوب.  */
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0)
        return NULL;
    size = (size_t) n + 1;      /* بايت إضافي واحد لـ '\0' */
    p = malloc(size);
    if (p == NULL)
        return NULL;
    va_start(ap, fmt);
    n = vsnprintf(p, size, fmt, ap);
    va_end(ap);
    if (n < 0) {
        free(p);
        return NULL;
    }
    return p;
}

إذا حدث اقتطاع في إصدارات glibc قبل glibc 2.0.6، يتم معاملة هذا كخطأ بدلاً من التعامل معه بشكل رشيق.
