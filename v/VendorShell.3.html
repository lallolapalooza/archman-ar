XmNaudibleWarning
يحدد ما إذا كان الإجراء ينشط إشارته الصوتية المرتبطة. القيم الممكنة هي XmBELL و XmNONE.
XmNbuttonFontList
يحدد قائمة الخطوط المستخدمة لأبناء الأزرار. انظر مورد XmNbuttonRenderTable.
XmNbuttonRenderTable
يحدد جدول العرض المستخدم لأبناء أزرار VendorShell. إذا كانت هذه القيمة NULL عند التهيئة وإذا كانت قيمة XmNdefaultFontList ليست NULL، فسيتم تهيئة XmNbuttonRenderTable بقيمة XmNdefaultFontList. إذا كانت قيمة XmNdefaultFontList هي NULL، فسيتم البحث في التسلسل الهرمي الأصل للأداة بحثًا عن سلف يحمل السمة XmQTspecifyRenderTable. إذا تم العثور على مثل هذا السلف، فسيتم تهيئة XmNbuttonRenderTable بقيمة XmBUTTON_RENDER_TABLE للأداة السلف. إذا لم يتم العثور على أي سلف، فإن الافتراضي يعتمد على التنفيذ. ارجع إلى XmRenderTable(3) لمزيد من المعلومات حول إنشاء وهيكل جدول العرض.
XmNdefaultFontList
يحدد قائمة خطوط افتراضية لأبناء VendorShell. هذا المورد مهمل وهو موجود للتوافق مع الإصدارات السابقة. تم استبداله بـ XmNbuttonFontList و XmNlabelFontList و XmNtextFontList.
XmNdeleteResponse
يحدد الإجراء الذي تتخذه الواجهة استجابةً لرسالة WM_DELETE_WINDOW. يمكن أن يكون الإعداد واحدًا من ثلاثة قيم: XmDESTROY و XmUNMAP و XmDO_NOTHING. يتم مسح المورد، ويتم اتخاذ الإجراء المناسب بعد استدعاء قائمة ردود الفعل WM_DELETE_WINDOW (إن وجدت) المسجلة لدى مدير البروتوكول.
XmNinputMethod
يحدد السلسلة النصية التي تضبط معدّل اللغة لطريقة الإدخال. عند استدعاء XtGetValues على هذا المورد، تكون القيمة المعادة مؤشرًا إلى قيمة المورد الفعلية ولا ينبغي تحريرها.
XmNinputPolicy
يحدد السياسة التي يجب اتباعها لإنشاء سياق إدخال (IC) لهذه الواجهة. يمكن أن يكون لهذا المورد القيم التالية:
XmPER_SHELL
يحدد أنه يتم إنشاء XIC واحد فقط لكل واجهة.
XmPER_WIDGET
يحدد أنه يتم إنشاء XIC واحد لكل أداة.

XmNkeyboardFocusPolicy
يحدد تخصيص تركيز لوحة المفاتيح ضمن التسلسل الهرمي لأدوات الواجهة الجذرية لهذه الصدفة (shell). يجب توجيه تركيز لوحة المفاتيح الخاص بنظام X إلى مكان ما في التسلسل الهرمي حتى يصبح هذا الإدارة للتركيز من جانب العميل ساري المفعول. القيم الممكنة هي XmEXPLICIT، التي تحدد سياسة "انقر للكتابة"، و XmPOINTER، التي تحدد سياسة مدفوعة بالمؤشر.
XmNlabelFontList
يحدد قائمة الخطوط المستخدمة لعناصر التسمية الفرعية. انظر مورد XmNlabelRenderTable.
XmNlabelRenderTable
يحدد قائمة الخطوط المستخدمة لعناصر التسمية الفرعية الخاصة بـ VendorShell (Labels و LabelGadgets). إذا كانت هذه القيمة NULL عند التهيئة وإذا كانت قيمة XmNdefaultFontList ليست NULL، فسيتم تهيئة XmNlabelFontList إلى قيمة XmNdefaultFontList. إذا كانت قيمة XmNdefaultFontList هي NULL، فسيتم البحث في التسلسل الهرمي للوالد للأداة عن سلف يحمل خاصية XmQTspecifyRenderTable. إذا تم العثور على سلف كهذا، فسيتم تهيئة XmNlabelRenderTable إلى XmLABEL_RENDER_TABLE للسلف. إذا لم يتم العثور على سلف كهذا، فإن الافتراضي يعتمد على التنفيذ. ارجع إلى XmRenderTable(3) لمزيد من المعلومات حول إنشاء وبنية جدول التصيير (render table).
XmNlayoutDirection
يحدد الاتجاه الذي سيتم فيه ترتيب الأدوات الفرعية، أو الأطفال، أو المكونات المرئية الأخرى. هذه السياسة ستطبق كسياسة تخطيط افتراضية لجميع الأحفاد من هذا VendorShell.
XmNmwmDecorations

XmNmwmInputMode
يحدد علامة وضع الإدخال (قيود الإدخال الخاصة بالتطبيق أو النظام) لخاصية _MOTIF_WM_HINTS. إذا لم يتم تحديد علامة وضع إدخال بواسطة خاصية _MOTIF_WM_HINTS، فلن يتم تطبيق أي قيود على الإدخال، ويدخل الإدخال إلى أي نافذة. القيمة الافتراضية لمورد XmNmwmInputMode هي عدم تحديد أي علامة وضع إدخال لخاصية _MOTIF_WM_HINTS.
التطبيق الذي يضبط قيود الإدخال على مربع حوار يستخدم عادةً مورد XmNdialogStyle الخاص بـ BulletinBoard بدلاً من مورد XmNmwmInputMode الخاص بـ DialogShell الرئيسي.
القيم الممكنة لهذا المورد، المعرفة في ملف التضمين Xm/MwmUtil.h، هي
MWM_INPUT_MODELESS
يدخل الإدخال إلى أي نافذة.
MWM_INPUT_PRIMARY_APPLICATION_MODAL
لا يدخل الإدخال إلى أسلاف هذه النافذة.
MWM_INPUT_SYSTEM_MODAL
يدخل الإدخال فقط إلى هذه النافذة.
MWM_INPUT_FULL_APPLICATION_MODAL
لا يدخل الإدخال إلى نوافذ أخرى في هذا التطبيق.

RESOURCES

XmNtextRenderTable
This resource is used to specify the text rendering table for the widget. If not set, the widget searches for an ancestor widget that has this resource set. If such an ancestor is found, XmNtextRenderTable is initialized to the XmTEXT_RENDER_TABLE value of the ancestor widget. If no such ancestor is found, the default is implementation dependent. Refer to XmRenderTable(3) for more information on the creation and structure of a render table.
XmNtoolTipEnable
Specifies whether toolTips are enabled for this shell or not.
XmNtoolTipPostDelay
Specifies the time, in milliseconds, to wait after the pointer enters a widget before posting the toolTip associated with this widget.
XmNtoolTipPostDuration
Specifies the time, in milliseconds, that the toolTip is displayed. A value of 0 will display the tip indefinitely.
XmNunitType
Provides the basic support for resolution independence. It defines the type of units a widget uses with sizing and positioning resources. The resource has a default unit type of XmPIXELS.
The unit type can also be specified in resource files, with the following format:
<floating value><unit>
where:
unit
is <" ", pixels, inches, centimeters, millimeters, points, font units>
pixels
is <pix, pixel, pixels>
inches
is <in, inch, inches>
centimeter
is <cm, centimeter, centimeters>
millimeters
is <mm, millimeter, millimeters>
points
is <pt, point, points>
font units
is <fu, font_unit, font_units>
float
is {"+"|"-"}{{<"0"-"9">*}.}<"0"-"9">*
Note that the type Dimension must always be positive.
For example,
xmfonts*XmMainWindow.height: 10.4cm
*PostIn.width: 3inches
XmNunitType can have the following values:
XmPIXELS
All values provided to the widget are treated as normal pixel values.
XmMILLIMETERS
All values provided to the widget are treated as normal millimeter values.
Xm100TH_MILLIMETERS
All values provided to the widget are treated as 1/100 of a millimeter.
XmCENTIMETERS
All values provided to the widget are treated as normal centimeter values.
XmINCHES
All values provided to the widget are treated as normal inch values.
Xm1000TH_INCHES
All values provided to the widget are treated as 1/1000 of an inch.
XmPOINTS
All values provided to the widget are treated as normal point values. A point is a unit used in text processing applications and is defined as 1/72 of an inch.
Xm100TH_POINTS
All values provided to the widget are treated as 1/100 of a point. A point is a unit used in text processing applications and is defined as 1/72 of an inch.
XmFONT_UNITS
All values provided to the widget are treated as normal font units. A font unit has horizontal and vertical components. These are the values of the XmScreen resources XmNhorizontalFontUnit and XmNverticalFontUnit.
Xm100TH_FONT_UNITS
All values provided to the widget are treated as 1/100 of a font unit. A font unit has horizontal and vertical components. These are the values of the XmScreen resources XmNhorizontalFontUnit and XmNverticalFontUnit.
For more information about units, refer to the XmConvertUnits reference page.
XmNuseAsyncGeometry
Specifies whether the geometry manager should wait for confirmation of a geometry request to the window manager. When the value of this resource is True, the geometry manager forces XmNwaitForWm to False and XmNwmTimeout to 0, and it relies on asynchronous notification. When the value of this resource is False, XmNwaitForWm and XmNwmTimeout are unaffected. The default is False.
