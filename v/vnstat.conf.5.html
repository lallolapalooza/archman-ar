resolution.
64bitInterfaceCounters
تحديد طريقة التعامل مع عدادات الواجهة. قم بتعيينها إلى 1 لتحديد أن جميع الواجهات تستخدم عدادات 64 بت في جانب النواة و 0 لتعريف عدادات 32 بت. قم بتعيينها إلى -1 لاستخدام النمط القديم الذي تم استخدامه في الإصدارات السابقة حيث يُفترض أن قيم العدادات التي تقل عن 32 بت هي 32 بت وأي شيء أكبر يُفترض أنه عداد 64 بت. قد ينتج عن هذا نتائج خاطئة إذا تمت إعادة تعيين عداد 64 بت ضمن 32 بت. قم بتعيينها إلى -2 لاستخدام الكشف التلقائي بناءً على هياكل بيانات النواة المتاحة.
AlwaysAddNewInterfaces
تمكين أو تعطيل الإنشاء التلقائي لإدخالات قاعدة بيانات جديدة للواجهات التي ليست موجودة حاليًا في قاعدة البيانات حتى لو كان ملف قاعدة البيانات موجودًا بالفعل عند بدء تشغيل الخادم. سيتم أيضًا إنشاء إدخالات قاعدة بيانات جديدة للواجهات الجديدة التي يتم رؤيتها أثناء تشغيل الخادم. يتم استبعاد الواجهات الوهمية lo و lo0 و sit0 دائمًا من الإضافة. 1 = ممكّن، 0 = معطّل.
BandwidthDetection
محاولة الكشف التلقائي عن قيمة MaxBandwidth لكل واجهة مراقبة. تدعم الواجهات الإيثرنت هذه الميزة في الغالب. سيتم استخدام MaxBandwidth كقيمة احتياطية إذا فشل الكشف. سيؤدي أي تكوين خاص بالواجهة MaxBW إلى تعطيل الكشف للواجهة المحددة. في Linux، يتم تعطيل الكشف لواجهات tun لأن نواة Linux تقوم دائمًا بالإبلاغ عن 10 ميجابت بغض النظر عن الواجهة الحقيقية المستخدمة. 1 = ممكّن، 0 = معطّل.
BandwidthDetectionInterval
كم مرة بالدقائق يتم إجراء الكشف الخاص بالواجهة عن MaxBandwidth للكشف عن التغييرات المحتملة عندما يكون BandwidthDetection ممكّنًا. يمكن تعطيله بتعيينه إلى 0. نطاق القيمة: 0..30
BootVariation
الوقت بالثواني الذي يمكن أن يختلف فيه وقت التشغيل الذي تقارنه نواة النظام بين التحديثات. نطاق القيمة: 0..300
CheckDiskSpace
تمكين أو تعطيل التحقق من توفر مساحة قرص فارغة على الأقل قبل كتابة قاعدة البيانات. 1 = ممكّن، 0 = معطّل.
CreateDirs
تمكين أو تعطيل إنشاء الدلائل عند عدم وجود المسار المحدد. يشمل ذلك دلائل DatabaseDir و LogFile و PidFile. سيتم إنشاء دليل LogFile فقط عندما يتم تعيين UseLogging إلى 1. سيتم إنشاء دليل PidFile فقط إذا تم بدء تشغيل الخادم كعملية خلفية. ستحاول عملية الخادم إنشاء الدليل باستخدام أذونات المستخدم الذي بدأ العملية.
DaemonGroup
تحديد المجموعة التي يجب أن ينتقل إليها الخادم أثناء بدء التشغيل. يمكن أن تكون المجموعة اسم المجموعة أو معرف مجموعة رقمي. اترك فارغًا لتعطيل تبديل المجموعة. يمكن استخدام هذا الخيار فقط عندما يتم بدء العملية كـ root.
DaemonUser
تحديد المستخدم الذي يجب أن ينتقل إليه الخادم أثناء بدء التشغيل. يمكن أن يكون المستخدم اسم تسجيل دخول المستخدم أو معرف مستخدم رقمي. اترك فارغًا لتعطيل تبديل المستخدم. يمكن استخدام هذا الخيار فقط عندما يتم بدء العملية كـ root.
DailyDays
مدة الاحتفاظ بالبيانات لإدخالات دقة اليوم الواحد. يحدد التكوين عدد الأيام الماضية التي سيتم تخزين الإدخالات فيها. عيّن إلى -1 لإدخالات غير محدودة أو إلى 0 لتعطيل جمع البيانات لهذه الدقة.
DatabaseSynchronous
تغيير إعداد علامة SQLite "synchronous" التي تتحكم في مقدار العناية المبذولة لضمان اكتمال كتابة القرص تمامًا عند كتابة البيانات إلى قاعدة البيانات قبل متابعة الإجراءات الأخرى. تتخذ القيم الأعلى خطوات إضافية لضمان سلامة البيانات على حساب الأداء الأبطأ. ستؤدي القيمة 0 إلى ترك كل المعالجة لنظام الملفات نفسه. عيّن إلى -1 لاختيار القيمة الافتراضية وفقًا لوضع قاعدة البيانات الذي يتم التحكم فيه بواسطة إعداد DatabaseWriteAheadLogging. راجع وثائق SQLite لمزيد من التفاصيل حول القيم من 1 إلى 3. نطاق القيمة: -1..3
DatabaseWriteAheadLogging
تمكين أو تعطيل وضع SQLite Write-Ahead Logging لقاعدة البيانات. راجع وثائق SQLite لمزيد من التفاصيل ولاحظ أن الدعم لعمليات القراءة فقط غير متوفر في إصدارات SQLite الأقدم. 1 = ممكّن، 0 = معطّل.
HourlyDays
مدة الاحتفاظ بالبيانات لإدخالات دقة الساعة الواحدة. يحدد التكوين عدد الأيام الماضية التي سيتم تخزين الإدخالات فيها. عيّن إلى -1 لإدخالات غير محدودة أو إلى 0 لتعطيل جمع البيانات لهذه الدقة.
LogFile
تحديد مسار واسم ملف السجل لاستخدامه إذا تم تعيين UseLogging إلى 1.
MaxBandwidth
الحد الأقصى لعرض النطاق الترددي لجميع الواجهات. إذا تجاوز حركة المرور الخاصة بالواجهة القيمة المحددة، فسيتم اعتبار البيانات غير صالحة ورفضها. عيّن إلى 0 لتعطيل الميزة. نطاق القيمة: 0..50000
MaxBW
نفس MaxBandwidth ولكن يمكن استخدامه لتعيين حدود فردية لواجهات محددة. يتم تحديد اسم الواجهة مباشرة بعد الكلمة الرئيسية MaxBW بدون مسافات. على سبيل المثال MaxBWeth0 لـ eth0 و MaxBWppp0 لـ ppp0. يتم تعطيل BandwidthDetection على مستوى الواجهة الفردية لكل تكوين MaxBW. نطاق القيمة: 0..50000
MonthlyMonths
مدة الاحتفاظ بالبيانات لإدخالات دقة الشهر الواحد. يحدد التكوين عدد الأشهر الماضية التي سيتم تخزين الإدخالات فيها. عيّن إلى -1 لإدخالات غير محدودة أو إلى 0 لتعطيل جمع البيانات لهذه الدقة.
MonthRotate
يوم الشهر الذي يُتوقع أن تتغير فيه الأشهر. عادة ما يتم تعيينه إلى 1 ولكن يمكن تعيينه إلى قيم بديلة على سبيل المثال لتتبع حركة المرور الشهرية المدفوعة حيث لا تبدأ فترة الفوترة في اليوم الأول. على سبيل المثال، إذا تم تعيينه إلى 7، فإن أيام فبراير حتى 6 بما في ذلك سيتم احتسابها لشهر يناير. تغيير هذا الخيار لن يؤدي إلى إعادة حساب البيانات الموجودة. نطاق القيمة: 1..28
MonthRotateAffectsYears
تمكين أو تعطيل MonthRotate للتأثير أيضًا على البيانات السنوية. ينطبق فقط عندما يكون MonthRotate بقيمة أكبر من واحد. 1 = ممكّن، 0 = معطّل.
OfflineSaveInterval
كم مرة بالدقائق يتم حفظ بيانات الواجهة المخزنة مؤقتًا في ملف عندما تكون جميع الواجهات المراقبة غير متصلة. نطاق القيمة: SaveInterval..60
PidFile
تحديد مسار واسم ملف PID لاستخدامه. يتم إنشاء الملف فقط إذا تم بدء تشغيل الخادم كعملية خلفية.
PollInterval
كم مرة بالثواني يتم التحقق من الواجهات بحثًا عن تغييرات في الحالة. نطاق القيمة: 2..60
RescanDatabaseOnSave
اكتشاف تلقائي للواجهات المضافة من قاعدة البيانات وبدء المراقبة. يتم إجراء إعادة المسح كل SaveInterval أو OfflineSaveInterval دقيقة اعتمادًا على حالة النشاط الحالية. 1 = ممكّن، 0 = معطّل.
SaveInterval
كم مرة بالدقائق يتم حفظ بيانات الواجهة المخزنة مؤقتًا في ملف. نطاق القيمة: ( UpdateInterval / 60 )..60
SaveOnStatusChange
تمكين أو تعطيل الحفظ الإضافي لبيانات الواجهة المخزنة مؤقتًا في ملف عند تغيير توفر الواجهة، أي عند انتقال الواجهة إلى وضع عدم الاتصال أو العودة إلى وضع الاتصال. 1 = ممكّن، 0 = معطّل.
TimeSyncWait
كم عدد الدقائق التي يجب الانتظار خلالها أثناء بدء تشغيل الخادم لمزامنة ساعة النظام إذا بدا أن أحدث تحديث لقاعدة البيانات يحدث في المستقبل. قد يكون هذا ضروريًا في الأنظمة التي لا تحتوي على ساعة في الوقت الفعلي (RTC) والتي تتطلب بعض الوقت بعد الإقلاع للاستعلام عن الوقت الصحيح وتعيينه. 0 = الانتظار معطّل. نطاق القيمة: 0..60
TopDayEntries
مدة الاحتفاظ بالبيانات لإدخالات أفضل يوم. يحدد التكوين عدد إدخالات أفضل يوم في الماضي التي سيتم تخزينها. عيّن إلى -1 لإدخالات غير محدودة أو إلى 0 لتعطيل جمع البيانات لهذه الدقة.
TrafficlessEntries
إنشاء إدخالات قاعدة بيانات حتى عندما لا يكون هناك حركة مرور خلال فترة الإدخال. 1 = ممكّن، 0 = معطّل.
UpdateFileOwner
تمكين أو تعطيل تحديث ملكية الملف أثناء بدء تشغيل عملية الخادم. أثناء بدء تشغيل الخادم، سيتم تعديل ملفات قاعدة البيانات والسجلات وملفات PID فقط إذا تم تمكين ميزة تغيير المستخدم أو المجموعة ( DaemonUser أو DaemonGroup ) ولا تتطابق الملفات مع المستخدم أو المجموعة المطلوبة. أثناء الإنشاء اليدوي لقاعدة البيانات، سيؤدي هذا الخيار إلى وراثة ملكية الملفات من دليل قاعدة البيانات إذا كان الدليل موجودًا بالفعل. هذا الخيار له تأثير فقط عندما يتم بدء العملية كـ root أو عبر sudo.
UpdateInterval
كم مرة بالثواني يتم تحديث بيانات الواجهة. نطاق القيمة: PollInterval..300
UseLogging
تمكين أو تعطيل التسجيل. يتم تجاهل هذا الخيار عندما يبدأ تشغيل الخادم باستخدام -n, --nodaemon مما يؤدي إلى عرض جميع مخرجات السجل في الطرفية التي تستخدمها عملية الخادم. 0 = معطّل، 1 = ملف سجل، و 2 = syslog.

NAME

vnstat.conf — configuration file for vnStat daemon and tools

SYNOPSIS

vnstatd uses the configuration file /etc/vnstat.conf by default.

DESCRIPTION

The configuration file allows customization of various aspects of vnStat operation.

AlwaysNetwork
Always use network interfaces found at startup, even if they are not present at the time the daemon is running. 1 = enabled, 0 = disabled.
AllowRoot
Allow vnStat to be run as root. 1 = enabled, 0 = disabled.
BandwidthLimit
Set a bandwidth limit for the given interface. When the limit is exceeded, the rate will be displayed in red. The value is specified in kbit/Mbit/Gbit/Tbit. Example: BandwidthLimit 1000mbit.
CalendarGrabPercent
Percentage of data to grab for calendar view. Value range: 1..100
CalendarTopPercent
Percentage of data to show at the top in calendar view. Value range: 1..100
CheckInterval
Update interval in seconds. Default is 300 seconds (5 minutes).
DaemonHost
Hostname or IP address to which the daemon should bind. Default is all interfaces (0.0.0.0).
DaemonPort
Port number to which the daemon should bind. Default is 12045.
DatabaseDir
Directory where database files are stored. Default is /var/lib/vnstat/.
DateFormat
Formatting of date. Uses the same format as date(1).
EnableHyperlinks
Enable or disable hyperlinks in output. 1 = enabled, 0 = disabled.
EnableLogging
Enable or disable logging to file. 1 = enabled, 0 = disabled.
EndTime
End time for daily graph. Uses 24-hour format HH:MM. Default is 00:00.
ExportTemplate
Template for exporting data. Allows custom output formats.
FirstWeekday
Set the first day of the week. 0 = Sunday, 1 = Monday, etc. Default is 0 (Sunday).
GraphOutputFormat
Output format for graphs. Available formats: png, svg, gif. Default is png.
GraphHeight
Height of graph in pixels. Value range: 150..2000
GraphWidth
Width of graph in pixels. Value range: 288..2000
HourlyGraphHeight
Height of hourly graph in pixels. Value range: 150..2000
HourlyGraphWidth
Width of hourly graph in pixels. Value range: 288..2000
ImageCacheSize
Maximum number of images to keep in cache. Default is 100.
InterfaceIgnoreList
List of network interfaces to ignore. Separate interfaces with commas. Example: InterfaceIgnoreList lo,virbr0.
InterfaceList
List of network interfaces to monitor. Separate interfaces with commas. If not set, all interfaces except those in InterfaceIgnoreList will be monitored.
LogFile
Path to the log file. Default is /var/log/vnstat.log.
LongTermDays
Data retention duration for the long term resolution entries. The configuration defines for how many past days entries will be stored. Set to -1 for unlimited entries or to 0 to disable the data collection of this resolution.
LongTermMonths
Data retention duration for the long term resolution entries. The configuration defines for how many past months entries will be stored. Set to -1 for unlimited entries or to 0 to disable the data collection of this resolution.
LongTermYears
Data retention duration for the long term resolution entries. The configuration defines for how many past years entries will be stored. Set to -1 for unlimited entries or to 0 to disable the data collection of this resolution.
NoColor
Disable color output. 1 = enabled, 0 = disabled.
OutputStyle
Configure the output style for tables.
0 = standard,
1 = show rates,
2 = show percentages,
3 = show rates and percentages.
PidFile
Path to the PID file. Default is /run/vnstat/vnstat.pid.
PollingInterval
Interval in seconds for polling interface statistics. Default is 5 seconds.
RateUnit
Unit for displaying data rates. Available units: K, M, G, T. Default is auto.
RotateLogs
Number of log files to keep. Default is 4.
StartTime
Start time for daily graph. Uses 24-hour format HH:MM. Default is 00:00.
Top20
Enable or disable showing top 20 days/months/years in statistics. 1 = enabled, 0 = disabled.
UpdateInterval
Update interval in seconds for database. Default is 300 seconds (5 minutes).
UseColor
Use color output. 1 = enabled, 0 = disabled.
UseNetwork
Enable or disable using network interfaces found at startup. 1 = enabled, 0 = disabled.
UseUTC
Enable or disable using UTC as timezone in the database for all entries. When enabled, all entries added to the database will use UTC regardless of the configured system timezone. When disabled, the configured system timezone will be used. Changing this setting will not result in already existing data to be modified. 1 = enabled, 0 = disabled.
VacuumOnHUPSignal
Enable or disable the execution of SQLite VACUUM command after the daemon has received a HUP signal. When enabled, the database file is rebuilt and repacked into a minimal amount of disk space. The difference in size can be notable especially if data retention durations have been reduced or previously monitored interfaces removed from the database. 1 = enabled, 0 = disabled.
VacuumOnStartup
Enable or disable the execution of SQLite VACUUM command during daemon startup. When enabled, the database file is rebuilt and repacked into a minimal amount of disk space. The difference in size can be notable especially if data retention durations have been reduced or previously monitored interfaces removed from the database. 1 = enabled, 0 = disabled.
YearlyYears
Data retention duration for the one year resolution entries. The configuration defines for how many past years entries will be stored. Set to -1 for unlimited entries or to 0 to disable the data collection of this resolution.

IMAGE OUTPUT RELATED KEYWORDS

5MinuteGraphResultCount
Number of 5 minute periods to be included in the 5 minute resolution graph. The value affects the width of the graph. Value range: 288..2000
5MinuteGraphHeight
Height of 5 minute resolution graph in pixels. Value range: 150..2000
BarColumnShowsRate
The bar column represents traffic rate in list outputs when enabled. Requires also that OutputStyle has been configured to show the traffic rate column by using the value 3. Enabling this option will automatically cause EstimateStyle to have the value 0. Visually this option affects only the color legend text and the last line on the list if that line represents the currently ongoing time period. 1 = enabled, 0 = disabled.
CBackground
Background color.
CEdge
Edge color, if visible.
CHeader
Header background color.
CHeaderTitle
Header title text color.
CHeaderDate
Header date text color.
CLine
Line color.
CLineL
Lighter version of line color. Set to '-' in order to use a calculated value based on CLine.
CPercentileLine
95th percentile line color. Used only in 95th percentile graph.
CRx
Color for received data.
CRxD
Darker version of received data color. Set to '-' in order to use a calculated value based on CRx.
CText
Common text color.
CTotal
Color for total data, sum of received and transmitted data. Used only in 95th percentile graph.
CTx
Color for transmitted data.
CTxD
Darker version of transmitted data color. Set to '-' in order to use a calculated value based on CTx.
EstimateStyle
Show a visual representation of the traffic estimation. 0 = not shown, 1 = continuation of existing bar, 2 = separate bar.
HeaderFormat
Formatting of date in header. Uses the same format as date(1).
HourlyGraphMode
Select the output mode of the hourly graph. 0 = 24 hour sliding window, 1 = graph begins from midnight.
HourlyRate
Show hours with rate instead of transferred amount. 1 = enabled, 0 = disabled.
ImageScale
Scale output to given percent. Value range: 50..500
LargeFonts
Increase the size of used fonts. 1 = enabled, 0 = disabled.
LineSpacingAdjustment
Adjust line spacing in list format outputs. Positive values increase the space between lines while negative values reduce it. Value range: -5..10
SummaryGraph
Select which graph style output is shown next to the summary data in the horizontal and vertical summary outputs. 0 = hours, 1 = 5 minutes.
SummaryRate
Show rate in summary output if available. 1 = enabled, 0 = disabled.
TransparentBg
Set background color as transparent. 1 = enabled, 0 = disabled.

FILES

/etc/vnstat.conf
Config file that will be used unless $HOME/.vnstatrc exists or alternative value is given as command line parameter.

RESTRICTIONS

Using long date output formats may cause misalignment in shown columns if the length of the date exceeds the fixed size allocation.
