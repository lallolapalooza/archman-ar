NAME

Vector_BLF_SerialEvent - A class to represent serial port events within the Vector BLF (Bus Logging File) format.

SYNOPSIS

The Vector_BLF_SerialEvent class is part of the Vector BLF library, designed for parsing and manipulating data from Vector logging files.

DESCRIPTION

The Vector_BLF_SerialEvent class encapsulates the information related to a serial port event recorded in a BLF file. This includes details such as the timestamp of the event, the channel it occurred on, and the actual data transmitted or received over the serial port.

Detailed Description

This class provides a structured way to access and interpret serial communication data logged within a BLF file. It is crucial for analyzing the low-level details of serial transmissions, such as UART data, which are often used for debugging or diagnostic purposes in embedded systems.
