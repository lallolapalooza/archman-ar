الحزمة: vcdimager

التراخيص: GPL-2.0-or-later

VCDXGEN(1) أوامر المستخدم VCDXGEN(1)

الاسم

vcdxgen - صفحة دليل لـ vcdxgen 2.0.0

الملخص

vcdxgen mpeg-track1 [mpeg-track2...]

الوصف

-o, --output-file=FILE
تحديد ملف xml للإخراج (الافتراضي: 'videocd.xml')
-t, --type=TYPE
اختيار نوع VideoCD ('vcd11', 'vcd2', 'svcd' أو 'hqvcd') (الافتراضي: 'vcd2')
-l, --iso-volume-label=LABEL
تحديد تسمية وحدة ISO لقرص الفيديو (الافتراضي: 'VIDEOCD')
--iso-application-id=LABEL
تحديد معرف تطبيق ISO لقرص الفيديو (الافتراضي: '')
--info-album-id=LABEL
تحديد معرف الألبوم لمجموعة أقراص الفيديو (الافتراضي: '')
--volume-count=NUMBER
تحديد عدد الوحدات في مجموعة الألبوم
--volume-number=NUMBER
تحديد رقم تسلسل مجموعة الألبوم (< volume-count)
--broken-svcd-mode
تمكين وضع التوافق غير المتوافق للأجهزة المعطلة
--update-scan-offsets
تحديث إزاحات بيانات المسح في تدفق فيديو mpeg2
--nopbc
عدم إنشاء PBC
--add-dirtree=DIR
إضافة محتويات الدليل بشكل متكرر إلى جذر نظام ملفات ISO
--add-dir=ISO_DIRNAME
إضافة دليل فارغ إلى نظام ملفات ISO
--add-file=FILE,ISO_FILENAME
إضافة ملف واحد إلى نظام ملفات ISO
--add-file-2336=FILE,ISO_FILENAME
إضافة ملف يحتوي على قطاعات كاملة بحجم 2336 بايت إلى نظام ملفات ISO
--filename-encoding=STRING
استخدام ترميز مجموعة أحرف معين لأسماء الملفات بدلاً من UTF8
-v, --verbose
كن مفصلاً
-q, --quiet
عرض الرسائل الحرجة فقط
-V, --version
عرض معلومات الإصدار وحقوق النشر والخروج

خيارات المساعدة:

-?, --help
عرض رسالة المساعدة هذه
--usage
عرض رسالة استخدام مختصرة
