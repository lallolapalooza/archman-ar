uint32_t Vector::BLF::CanErrorFrameExt::flags {}

علامات إطار خطأ CAN الموسعة تحدد المعلومات الإضافية الصالحة. القيم التالية ممكنة:

  • 1: SJA 1000 ECC صالح (العضو ecc)
  • 2: رمز خطأ Vector CAN Core صالح.
  • 4: موضع خطأ Vector CAN Core
  • 8: طول إطار Vector CAN Core بالنانوثانية
