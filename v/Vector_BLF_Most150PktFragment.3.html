Detailed Description

Structure to hold a MOST150 packet fragment.

This structure is used to store information about a fragment of a MOST150 packet. It includes details such as the announced and actual data length, source and destination addresses, the actual data payload, and acknowledgment and control information.

The dataLenAnnounced field indicates the expected length of the user data at the start of the transmission. In certain scenarios, such as sending to an invalid target address or when the receive buffer of the target device is full, the transmission may terminate before all data bytes are sent. In these cases, the counted number of bytes on the bus (dataLen) will be less than the announced data length. Rarely, due to very specific bit errors (like degradation of the end termination byte), dataLen can also be greater than dataLenAnnounced.

  • Bit 0: 0x00000001: dataLenAnnounced
  • Bit 1: 0x00000002: sourceAdr
  • Bit 2: 0x00000004: destAdr
  • Bit 3: 0x00000008: ackNack
  • Bit 4: 0x00000010: pAck
  • Bit 5: 0x00000020: pIndex

  • Bit 10: 0x00000400: destMacAdr
