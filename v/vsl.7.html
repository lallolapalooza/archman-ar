>EXP_When
يتم تسجيلها عندما تنقل شريحة انتهاء الصلاحية كائنًا على شجرة الأولوية (binheap).
EXP_Inspect
يتم تسجيلها عندما تفحص شريحة انتهاء الصلاحية الكائن التالي المقرر انتهاء صلاحيته.
EXP_Expired
يتم تسجيلها عندما تنتهي صلاحية شريحة انتهاء الصلاحية لكائن.
EXP_Removed
يتم تسجيلها عندما تزيل شريحة انتهاء الصلاحية كائنًا قبل انتهاء صلاحيته.
VBF_Superseded
يتم تسجيلها عندما يتفوق كائن على كائن آخر.
LRU_Cand
يتم تسجيلها عندما يتم تقييم كائن لانتهاء صلاحيته القسري (LRU).
LRU
يتم تسجيلها عندما تنتهي صلاحية كائن قسريًا بسبب LRU.
LRU_Fail
يتم تسجيلها عندما لا يتم العثور على كائن مرشح مناسب لانتهاء صلاحية LRU القسري.

التنسيق هو:

EXP_Rearm p=%p E=%f e=%f f=0x%x
EXP_Inbox p=%p e=%f f=0x%x
EXP_Kill p=%p e=%f f=0x%x
EXP_When p=%p e=%f f=0x%x
EXP_Inspect p=%p e=%f f=0x%x
EXP_Expired x=%u t=%f h=%u
EXP_Removed x=%u t=%f h=%u
VBF_Superseded x=%u n=%u
LRU_Cand p=%p f=0x%x r=%d
LRU x=%u
LRU_Fail
وسيلة إيضاح:
p=%p         مؤشر Objcore
t=%f         وقت الحياة المتبقي (ثانية)
e=%f         وقت انتهاء الصلاحية (حقبة يونكس)
E=%f         وقت انتهاء الصلاحية القديم (حقبة يونكس)
f=0x%x       علامات Objcore
r=%d         عدد مراجع Objcore
x=%u         معرف VXID للكائن
n=%u         معرف VXID للكائن الجديد
h=%u         مرات الوصول لـ Objcore

Gzip - تم تنفيذ G(un)zip على الكائن
يتم إصدار سجل Gzip لكل مثيل من عمل gzip أو gunzip الذي يتم تنفيذه. في أسوأ الحالات، سيعمل معامل ESI المخزن في الكائنات المضغوطة ولكن يتم تسليمها غير مضغوطة، على العديد من هذه السجلات.

التنسيق هو:

%c %c %c %d %d %d %d %d
|  |  |  |  |  |  |  |
|  |  |  |  |  |  |  +- طول البت للبيانات المضغوطة
|  |  |  |  |  |  +---- موقع البت لـ 'آخر' بت
|  |  |  |  |  +------- موقع البت لأول كتلة فك ضغط
|  |  |  |  +---------- البايتات المخرجة
|  |  |  +------------- البايتات المدخلة
|  |  +---------------- 'E': ESI، '-': كائن عادي
|  +------------------- 'F': جلب، 'D': تسليم
+---------------------- 'G': Gzip، 'U': Gunzip، 'u': اختبار Gunzip

أمثلة:

U F E 182 159 80 80 1392
G F E 159 173 80 1304 1314

|  |  |  |  |  |
|  |  |  |  |  +- إجمالي البايتات المرسلة
|  |  |  |  +---- بايتات النص المرسلة
|  |  |  +------- بايتات الرأس المرسلة
|  |  +---------- إجمالي البايتات المستلمة
|  +------------- بايتات النص المستلمة
+---------------- بايتات الرأس المستلمة
