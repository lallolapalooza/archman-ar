vgdb - A debugger for VGDB.

SYNOPSIS

vgdb

DESCRIPTION

vgdb is a debugger for the VGDB (Virtual Game Database) system. It allows users to interact with and debug VGDB applications.

OPTIONS

vgdb does not accept any command-line options.

USAGE

To start the VGDB debugger, simply run the command:

vgdb

Once the debugger is running, you can use its commands to inspect and control your VGDB application.

COMMANDS

The following commands are available within the vgdb debugger:

  • help: Displays a list of available commands.
  • list: Lists the source code around the current execution point.
  • break [line_number|function_name]: Sets a breakpoint at the specified line number or function.
  • continue: Continues execution until the next breakpoint or the end of the program.
  • next: Executes the next line of code, stepping over function calls.
  • step: Executes the next line of code, stepping into function calls.
  • print [variable_name]: Prints the value of the specified variable.
  • quit: Exits the debugger.

NOTES

This man page is provided as a quick reference. For more detailed information on VGDB and its debugging capabilities, please refer to the official VGDB documentation.

vgdb - مصحح أخطاء لـ VGDB.

الملخص

vgdb

الوصف

vgdb هو مصحح أخطاء لنظام VGDB (قاعدة بيانات الألعاب الافتراضية). يتيح للمستخدمين التفاعل مع تطبيقات VGDB وتصحيحها.

الخيارات

vgdb لا يقبل أي خيارات سطر الأوامر.

الاستخدام

لبدء مصحح أخطاء VGDB، قم ببساطة بتشغيل الأمر:

vgdb

بمجرد تشغيل مصحح الأخطاء، يمكنك استخدام أوامره لفحص والتحكم في تطبيق VGDB الخاص بك.

الأوامر

الأوامر التالية متاحة داخل مصحح أخطاء vgdb:

  • help: يعرض قائمة بالأوامر المتاحة.
  • list: يسرد الكود المصدري حول نقطة التنفيذ الحالية.
  • break [رقم_السطر|اسم_الدالة]: يضع نقطة توقف عند رقم السطر أو اسم الدالة المحدد.
  • continue: يواصل التنفيذ حتى نقطة التوقف التالية أو نهاية البرنامج.
  • next: ينفذ السطر التالي من الكود، ويتجاوز استدعاءات الدوال.
  • step: ينفذ السطر التالي من الكود، ويقوم بالدخول إلى استدعاءات الدوال.
  • print [اسم_المتغير]: يطبع قيمة المتغير المحدد.
  • quit: يخرج من مصحح الأخطاء.

ملاحظات

تم تقديم صفحة الدليل هذه كمرجع سريع. لمزيد من المعلومات التفصيلية حول VGDB وقدرات تصحيح الأخطاء الخاصة به، يرجى الرجوع إلى الوثائق الرسمية لـ VGDB.
