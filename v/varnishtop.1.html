varnishtop(1)

NAME

varnishtop - Top-like utility for Varnish

SYNOPSIS

varnishtop [-a] [-c] [-C] [-d] [-f] [-i] [-I] [-N] [-n ident] [-P file] [-r file] [-S sock] [-T proto] [-V] [-w file] [-X] [-x] [<delay>]

DESCRIPTION

varnishtop is a top-like utility that monitors the Varnish Cache's internal state.

It displays a live-updating list of statistics, allowing you to see which parts of Varnish are being utilized and to identify potential bottlenecks.

EXAMPLES

varnishtop

Runs varnishtop with default settings.

varnishtop -i

Runs varnishtop and shows statistics for individual requests.

varnishtop -C

Runs varnishtop in color mode.

SEE ALSO

  • varnish(1)
  • varnishlog(1)
  • varnishstat(1)

HISTORY

The varnishtop utility was first introduced in Varnish Cache version 2.0.

varnishtop(1)

الاسم

varnishtop - أداة تشبه "top" لـ Varnish

الملخص

varnishtop [-a] [-c] [-C] [-d] [-f] [-i] [-I] [-N] [-n ident] [-P file] [-r file] [-S sock] [-T proto] [-V] [-w file] [-X] [-x] [<delay>]

الوصف

varnishtop هي أداة تشبه "top" تقوم بمراقبة الحالة الداخلية لذاكرة التخزين المؤقت لـ Varnish.

تعرض قائمة إحصائيات يتم تحديثها باستمرار، مما يسمح لك برؤية الأجزاء التي يستخدمها Varnish وتحديد الاختناقات المحتملة.

أمثلة

varnishtop

تشغيل varnishtop بالإعدادات الافتراضية.

varnishtop -i

تشغيل varnishtop وعرض إحصائيات الطلبات الفردية.

varnishtop -C

تشغيل varnishtop في وضع الألوان.
