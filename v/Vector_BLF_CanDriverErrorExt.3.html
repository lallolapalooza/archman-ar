Vector_BLF_CanDriverErrorExt(3)

Vector CAN driver error extensions

The Vector_BLF_CanDriverErrorExt library provides a set of functions for handling and interpreting error codes specific to the Vector CAN driver. This library is typically used in applications that interface with Vector CAN hardware, such as CAN interfaces and logging tools.

SYNOPSIS

#include <vector/can_driver_error_ext.h>

DESCRIPTION

The Vector_BLF_CanDriverErrorExt library offers functions to retrieve human-readable descriptions of Vector CAN driver error codes. This can be invaluable for debugging and diagnostics, allowing developers to understand the nature of errors reported by the CAN hardware or driver.

The library typically includes functions like:

  • Vector_BLF_GetErrorDescription(int errorCode): This function takes an integer error code as input and returns a string containing a descriptive message for that error.
  • Potentially other helper functions for error categorization, severity level determination, or specific error code handling.

USAGE

To use the Vector_BLF_CanDriverErrorExt library, you need to:

  1. Include the header file: #include <vector/can_driver_error_ext.h>.
  2. Link against the library during compilation (e.g., using -lVector_BLF_CanDriverErrorExt).
  3. Call the provided functions to interpret error codes obtained from your Vector CAN driver interactions.

EXAMPLE

#include <iostream>
#include <vector/can_driver_error_ext.h>

int main() {
    // Assume 'driver_error_code' is obtained from a Vector CAN driver function
    int driver_error_code = 1001; // Example error code

    const char* error_description = Vector_BLF_GetErrorDescription(driver_error_code);

    if (error_description) {
        std::cerr << "CAN Driver Error: " << error_description << std::endl;
    } else {
        std::cerr << "Unknown CAN Driver Error Code: " << driver_error_code << std::endl;
    }

    return 0;
}

RETURN VALUE

The Vector_BLF_GetErrorDescription function returns a pointer to a null-terminated string describing the error. If the error code is unknown or invalid, it may return NULL.
