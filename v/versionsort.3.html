versionsort(3)

NAME

versionsort - compare strings lexicographically, using version-number semantics

LIBRARY

Comparison Functions (lib)`, man:intro(3)

SYNOPSIS

#include <string.h>

int versionsort(const char *str1, const char *str2);
int versionsort_r(const char *str1, const char *str2);

DESCRIPTION

The versionsort() function compares two strings, str1 and str2, lexicographically, using version-number semantics. This means that numbers embedded within the strings are compared numerically, rather than lexicographically. For example, "version10" comes after "version2" with versionsort(), but would come before it with standard string comparison.

The versionsort_r() function is a reentrant version of versionsort().

RETURN VALUE

The versionsort() and versionsort_r() functions return an integer less than, equal to, or greater than zero if str1 is found, respectively, to be less than, to match, or be greater than str2.

ERRORS

No errors are defined.

ATTRIBUTES

For an explanation of the terms used in this section, see man:attributes(7).

+-----------------------------+----------------------------+
| Interface                   | Attribute                  |
+-----------------------------+----------------------------+
| versionsort(), versionsort_r() | Thread safety, Not         |
|                             | all-signal                |
+-----------------------------+----------------------------+

STANDARDS

The versionsort() function is a non-standard extension, commonly found on Linux and other systems. It is not part of POSIX or the C standard.

HISTORY

The versionsort() function first appeared in glibc.

NOTES

The comparison is performed by first splitting the strings into components, where components are either sequences of digits or sequences of non-digits. Then, these components are compared. If both components are digits, they are compared numerically. Otherwise, they are compared lexicographically.

The versionsort_r() function is identical to versionsort(), but is reentrant. This means that it can be safely called from multiple threads simultaneously.

EXAMPLES

#include <stdio.h>
#include <string.h>

int main() {
    const char *v1 = "version2.10";
    const char *v2 = "version2.2";
    const char *v3 = "version10.1";

    printf("Comparing \"%s\" and \"%s\": %d\\n", v1, v2, versionsort(v1, v2));
    printf("Comparing \"%s\" and \"%s\": %d\\n", v1, v3, versionsort(v1, v3));

    return 0;
}
