virtstoraged(8) دعم المحاكاة الافتراضية virtstoraged(8)

الاسم

virtstoraged - خادم إدارة مجمعات التخزين لـ libvirt

الملخص

virtstoraged [خيار]...

الوصف

البرنامج virtstoraged هو مكون خادم يعمل كخادم في نظام إدارة المحاكاة الافتراضية libvirt.

إنه أحد مجموعة الخوادم النمطية التي تحل محل الوظائف التي كان يوفرها سابقًا الخادم المتكامل libvirtd.

يعمل هذا الخادم على مضيفات المحاكاة الافتراضية لتوفير إدارة مجمعات التخزين.

يستمع الخادم virtstoraged فقط لطلبات عبر مقبس مجال Unix محلي. يتم توفير الوصول عن بعد عبر TLS/TCP والتوافق مع الإصدارات السابقة للعملاء القدامى الذين يتوقعون libvirtd بواسطة الخادم virtproxyd.

إعادة تشغيل virtstoraged لا تقاطع الأجهزة الافتراضية قيد التشغيل. تستمر الأجهزة الافتراضية في العمل وسيتم التقاط التغييرات في حالتها تلقائيًا أثناء بدء التشغيل بشكل عام. ومع ذلك، يوصى بتجنب إعادة التشغيل مع وجود أجهزة افتراضية قيد التشغيل كلما كان ذلك عمليًا.

أوضاع بدء تشغيل الخادم

الخادم virtstoraged قادر على البدء في وضعين.

وضع تنشيط المقبس

على المضيفات التي تحتوي على systemd، يتم تشغيله في وضع تنشيط المقبس وسيعتمد على systemd لإنشاء المقابس UNIX والاستماع إليها وتمريرها كواصفات ملفات مفتوحة مسبقًا. في هذا الوضع، لن يكون لمعظم خيارات تكوين المقبس في /etc/libvirt/virtstoraged.conf أي تأثير.

وضع الخدمة التقليدي

على المضيفات التي لا تحتوي على systemd، سيقوم بإنشاء مقابس UNIX والاستماع إليها بنفسه.

الخيارات

-h, --help

عرض استخدام مساعدة سطر الأوامر ثم الخروج.

-d, --daemon

تشغيل كخادم وكتابة ملف PID.

-f, --config *FILE*

استخدام ملف التكوين هذا، متجاوزًا القيمة الافتراضية.

-p, --pid-file *FILE*

استخدام هذا الاسم لملف PID، متجاوزًا القيمة الافتراضية.

-t, --timeout *SECONDS*

الخروج بعد فترة المهلة (بالثواني)، شريطة عدم وجود اتصالات عميل.

-v, --verbose

تمكين إخراج الرسائل المفصلة.

--version

عرض معلومات الإصدار ثم الخروج.

الإشارات

عند استلام SIGHUP، سيقوم virtstoraged بإعادة تحميل تكوينه.

الملفات

عند التشغيل كـ root

•
/etc/libvirt/virtstoraged.conf

ملف التكوين الافتراضي الذي يستخدمه virtstoraged، ما لم يتم تجاوزه في سطر الأوامر باستخدام الخيار -f | --config.

  • /run/libvirt/virtstoraged-sock
  • /run/libvirt/virtstoraged-sock-ro
  • /run/libvirt/virtstoraged-admin-sock

مقابس virtstoraged التي سيستخدمها.

مفتاح الخادم الخاص TLS الذي سيستخدمه virtstoraged.

•
/run/virtstoraged.pid

ملف PID المراد استخدامه، ما لم يتم تجاوزه بواسطة الخيار -p | --pid-file.

عند التشغيل كـ مستخدم غير root

•
$XDG_CONFIG_HOME/libvirt/virtstoraged.conf

ملف التكوين الافتراضي الذي يستخدمه virtstoraged، ما لم يتم تجاوزه في سطر الأوامر باستخدام الخيار -f | --config.

  • $XDG_RUNTIME_DIR/libvirt/virtstoraged-sock
  • $XDG_RUNTIME_DIR/libvirt/virtstoraged-admin-sock

مقابس virtstoraged التي سيستخدمها.

•
$XDG_RUNTIME_DIR/libvirt/virtstoraged.pid

ملف PID المراد استخدامه، ما لم يتم تجاوزه بواسطة الخيار -p | --pid-file.

إذا لم يتم تعيين $XDG_CONFIG_HOME في بيئتك، فسيستخدم virtstoraged $HOME/.config.

إذا لم يتم تعيين $XDG_RUNTIME_DIR في بيئتك، فسيستخدم virtstoraged $HOME/.cache.

أمثلة

للحصول على إصدار virtstoraged:

# virtstoraged --version
virtstoraged (libvirt) 11.10.0

لبدء virtstoraged، مع توجيهه لإنشاء ملف PID:

# virtstoraged -d
# ls -la /run/virtstoraged.pid
-rw-r--r-- 1 root root 6 Jul  9 02:40 /run/virtstoraged.pid

virtstoraged(8)

virtstoraged(8) daemon manages virtual machine storage objects. It provides the storage management API for libvirt, exposing storage pools and volumes to applications.

This daemon is intended to be run by the root user. It is usually started automatically at boot time.

OPTIONS

-d, --daemon
Run as a daemon in the background. This is the default behavior when virtstoraged is started automatically at boot time.
-h, --help
Print a help message and exit.
-V, --version
Print version information and exit.

SEE ALSO

libvirt(3), virsh(1)
