Vector_BLF_GlobalMarker(3)

NAME

Vector_BLF_GlobalMarker - Global marker to indicate a specific position in the BLF file.

SYNOPSIS

#include <vector/blf.h> 

struct Vector_BLF_GlobalMarker {
    // fields
};

Detailed Description

This structure represents a global marker within a Vector BLF (Binary Logging Format) file. Global markers are used to denote specific points or events within the logged data, allowing for easier navigation and analysis.

Member Function Documentation

This structure does not expose any public member functions. Its members are typically accessed through accessor functions or directly if the structure definition is available.

Member Data Documentation

The specific member data fields for Vector_BLF_GlobalMarker are not detailed here but would typically include information such as:

  • Timestamp: The time at which the marker was placed.
  • Marker Type: An identifier for the type of marker.
  • Description: An optional text description of the marker.

Refer to the BLF file format specification or the library's source code for exact details.
