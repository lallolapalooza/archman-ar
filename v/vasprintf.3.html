asprintf(3) دليل وظائف المكتبة asprintf(3)

الاسم

asprintf, vasprintf - طباعة إلى سلسلة محجوزة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#define _GNU_SOURCE         /* انظر feature_test_macros(7) */
#include <stdio.h>
int asprintf(char **restrict strp, const char *restrict fmt, ...);
int vasprintf(char **restrict strp, const char *restrict fmt,
              va_list ap);

الوصف

الدالتان asprintf() و vasprintf() هما نظيرتا sprintf(3) و vsprintf(3)، باستثناء أنهما تحجزان سلسلة نصية كبيرة بما يكفي لاستيعاب الإخراج بما في ذلك البايت الصفري الختامي ('\0')، وتعيدان مؤشراً إليها عبر الوسيط الأول. يجب تمرير هذا المؤشر إلى free(3) لتحرير المساحة المحجوزة عند عدم الحاجة إليها.

قيمة الإرجاع

عند النجاح، تعيد هاتان الدالتان عدد البايتات المطبوعة، تمامًا مثل sprintf(3). عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ، وتكون محتويات strp غير محددة.

الأخطاء

انظر sprintf(3) و malloc(3).

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
asprintf (), vasprintf () سلامة الخيوط MT-Safe locale

الإصدارات

تضبط تطبيق FreeBSD strp إلى NULL عند حدوث خطأ.

المعايير

GNU، BSD.

انظر أيضًا

free(3), malloc(3), printf(3)
