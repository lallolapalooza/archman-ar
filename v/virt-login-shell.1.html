virt-login-shell(1)

الحزمة: libvirt

virt-login-shell(1) دعم المحاكاة الافتراضية virt-login-shell(1)

الاسم

virt-login-shell - أداة لتنفيذ shell داخل حاوية

الملخص

virt-login-shell [خيار]

الوصف

برنامج virt-login-shell هو shell ذو صلاحيات (setuid) يُستخدم للانضمام إلى حاوية LXC تتطابق مع اسم المستخدم. إذا لم تكن الحاوية قيد التشغيل، فسيحاول virt-login-shell بدء تشغيل الحاوية. لا يُسمح لـ virt-login-shell بالعمل بواسطة المستخدم الجذر (root). سيتم إضافة المستخدمين العاديين إلى حاوية تتطابق مع اسم المستخدم الخاص بهم، إذا كانت موجودة، وسيتم تكوينهم في /etc/libvirt/virt-login-shell.conf.

البنية الأساسية لمعظم استخدامات virt-login-shell هي:

virt-login-shell

الخيارات

-c CMD

لتوجيه الـ shell لتنفيذ CMD بدلاً من تقديم مطالبة shell تفاعلية.

-h, --help

لعرض استخدام مساعدة سطر الأوامر ثم الخروج.

-V, --version

لعرض معلومات الإصدار ثم الخروج.

الإعدادات

بشكل افتراضي، سيقوم virt-login-shell بتنفيذ برنامج /bin/sh للمستخدم. يمكنك تعديل هذا السلوك عن طريق تعريف متغير الـ shell في /etc/libvirt/virt-login-shell.conf. مثال:

shell = [ "/bin/bash" ]

إذا تم تعيين خيار الإعداد auto_shell، فسوف يحاول اكتشاف الـ shell تلقائيًا من /etc/password داخل الحاوية. يجب القيام بذلك فقط إذا كانت الحاوية تحتوي على دليل /etc منفصل عن المضيف، وإلا فسيؤدي ذلك إلى استدعاء virt-login-shell بشكل متكرر. مثال:

auto_shell = 1

بشكل افتراضي، لا يُسمح لأي مستخدمين باستخدام virt-login-shell، وإذا كنت ترغب في السماح لمستخدمين معينين باستخدام virt-login-shell، فيجب عليك تعديل المتغير allowed_users في /etc/libvirt/virt-login-shell.conf. مثال:

allowed_users = [ "tom", "dick", "harry" ]

حالة الخروج

يعيد virt-login-shell عادةً حالة خروج الأمر الذي قام بتنفيذه. إذا تم إنهاء الأمر بواسطة إشارة، ولكن هذه الإشارة ليست قاتلة لـ virt-login-shell، فإنه يعيد رقم الإشارة مضافًا إليه 128.

حالات الخروج التي يولدها virt-login-shell نفسه:

  • 0 تم استخدام خيار لمعرفة المزيد عن هذا الثنائي.
  • 125 خطأ عام قبل محاولة تنفيذ الـ shell المُكوّن؛ على سبيل المثال، إذا لم يكن libvirtd قيد التشغيل.
  • 126 الـ shell المُكوّن موجود ولكن لا يمكن تنفيذه.
  • 127 الـ shell المُكوّن لا يمكن العثور عليه.
