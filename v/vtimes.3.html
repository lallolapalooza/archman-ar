getrusage(2) دليل استدعاءات النظام getrusage(2)

الاسم

getrusage - الحصول على مقاييس استخدام الموارد

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <sys/resource.h>
int getrusage(int who, struct rusage *usage);

الوصف

getrusage() تُرجع مقاييس استخدام الموارد لـ who، والتي يمكن أن تكون أحد الخيارات التالية:

RUSAGE_SELF
إرجاع إحصائيات استخدام الموارد للعملية المستدعية، وهي مجموع الموارد التي استخدمتها جميع الخيوط في العملية.
RUSAGE_CHILDREN
إرجاع إحصائيات استخدام الموارد لجميع العمليات الفرعية للعملية المستدعية التي انتهت وتم الانتظار عليها. ستشمل هذه الإحصائيات الموارد التي استخدمتها العمليات الفرعية والمنحدرات الأبعد، إذا انتظر جميع المنحدرات الفاصلة على عملياتهم الفرعية المنتهية.
RUSAGE_THREAD (منذ Linux 2.6.26)
إرجاع إحصائيات استخدام الموارد للخيط المستدعي. يجب تعريف ماكرو اختبار الميزة _GNU_SOURCE (قبل تضمين أي ملف رأس) للحصول على تعريف هذا الثابت من <sys/resource.h>.

تُرجع استخدامات الموارد في البنية المشار إليها بواسطة usage، والتي لها الشكل التالي:


struct rusage {
    struct timeval ru_utime; /* وقت وحدة المعالجة المركزية للمستخدم المستخدم */
    struct timeval ru_stime; /* وقت وحدة المعالجة المركزية للنظام المستخدم */
    long   ru_maxrss;        /* الحد الأقصى لمجموعة الذاكرة المقيمة */
    long   ru_ixrss;         /* حجم الذاكرة المشتركة المتكامل */
    long   ru_idrss;         /* حجم البيانات غير المشتركة المتكامل */
    long   ru_isrss;         /* حجم المكدس غير المشترك المتكامل */
    long   ru_minflt;        /* إعادة تخصيص الصفحات (أخطاء الصفحات الناعمة) */
    long   ru_majflt;        /* أخطاء الصفحات (أخطاء الصفحات الصلبة) */
    long   ru_nswap;         /* عمليات التبديل */
    long   ru_inblock;       /* عمليات الإدخال للكتل */
    long   ru_oublock;       /* عمليات الإخراج للكتل */
    long   ru_msgsnd;        /* رسائل IPC المرسلة */
    long   ru_msgrcv;        /* رسائل IPC المستلمة */
    long   ru_nsignals;      /* إشارات مستلمة */
    long   ru_nvcsw;         /* تبديلات السياق الطوعية */
    long   ru_nivcsw;        /* تبديلات السياق غير الطوعية */
};

ليست كل الحقول مكتملة؛ الحقول غير المدعومة يتم تعيينها إلى صفر بواسطة النواة. (الحقول غير المدعومة مقدمة للتوافق مع أنظمة أخرى، ولأنها قد تُدعم يومًا ما على لينكس). تُفسر الحقول على النحو التالي:

ru_utime
هذا هو إجمالي الوقت الذي قضاه في وضع المستخدم، معبرًا عنه في بنية timeval (ثوانٍ زائد ميكروثانية).
ru_stime
هذا هو إجمالي الوقت الذي قضاه في وضع النواة، معبرًا عنه في بنية timeval (ثوانٍ زائد ميكروثانية).
ru_maxrss (منذ Linux 2.6.32)
هذا هو الحد الأقصى لمجموعة الذاكرة المقيمة المستخدمة (بالكيلوبايت). بالنسبة إلى RUSAGE_CHILDREN، هذا هو حجم الذاكرة المقيمة لأكبر عملية فرعية، وليس الحد الأقصى لحجم الذاكرة المقيمة لشجرة العمليات.
ru_ixrss (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_idrss (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_isrss (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_minflt
عدد أخطاء الصفحات التي تم خدمتها دون أي نشاط للإدخال/الإخراج؛ هنا، يتم تجنب نشاط الإدخال/الإخراج عن طريق "استعادة" إطار صفحة من قائمة الصفحات التي تنتظر إعادة التخصيص.
ru_majflt
عدد أخطاء الصفحات التي تم خدمتها وتتطلب نشاط إدخال/إخراج.
ru_nswap (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_inblock (منذ Linux 2.6.22)
عدد المرات التي اضطر فيها نظام الملفات إلى إجراء عملية إدخال.
ru_oublock (منذ Linux 2.6.22)
عدد المرات التي اضطر فيها نظام الملفات إلى إجراء عملية إخراج.
ru_msgsnd (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_msgrcv (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_nsignals (غير مدعوم)
هذا الحقل غير مستخدم حاليًا على لينكس.
ru_nvcsw (منذ Linux 2.6)
عدد المرات التي نتجت فيها تبديلة سياق عن تنازل العملية طوعًا عن المعالج قبل اكتمال شريحة الوقت الخاصة بها (عادةً لانتظار توفر مورد).
ru_nivcsw (منذ Linux 2.6)
عدد المرات التي نتجت فيها تبديلة سياق عن جعل عملية ذات أولوية أعلى قابلة للتشغيل أو لأن العملية الحالية تجاوزت شريحة وقتها.

قيمة الإرجاع

عند النجاح، يتم إرجاع صفر. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EFAULT
يشير usage خارج مساحة العنوان القابلة للوصول.
EINVAL
who غير صالح.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، راجع attributes(7).

المعايير

POSIX.1-2024.

يحدد POSIX.1 getrusage()، ولكنه يحدد فقط الحقول ru_utime و ru_stime.

RUSAGE_THREAD خاص بلينكس.

التاريخ

POSIX.1-2001، SVr4، 4.3BSD.

قبل Linux 2.6.9، إذا كان تصرف SIGCHLD هو SIG_IGN، فسيتم تضمين استخدامات الموارد للعمليات الفرعية تلقائيًا في القيمة التي ترجعها RUSAGE_CHILDREN، على الرغم من أن POSIX.1-2001 يحظر هذا صراحةً. تمت معالجة هذا عدم التوافق في Linux 2.6.9 والإصدارات الأحدث.

تم أخذ تعريف البنية الموضح في بداية هذه الصفحة من 4.3BSD Reno.

وفرت الأنظمة القديمة وظيفة vtimes() بغرض مشابه لـ getrusage(). للحفاظ على التوافق، يوفر glibc (حتى Linux 2.32) أيضًا vtimes(). يجب كتابة جميع التطبيقات الجديدة باستخدام getrusage(). (منذ Linux 2.33، لم يعد glibc يوفر تطبيقًا لـ vtimes().)

ملاحظات

يتم الحفاظ على مقاييس استخدام الموارد عبر execve(2).
