v4l2-ctl(1)

الحزمة: v4l-utils

التراخيص: LGPL

NAME

v4l2-ctl

control utility for Video4Linux devices

SYNOPSIS

v4l2-ctl [options]

DESCRIPTION

The v4l2-ctl utility provides an interface to control video devices that support the Video4Linux API.

It can be used to query device capabilities, set controls, and stream video.

OPTIONS

The utility supports a wide range of options. The most common ones include:

  • -d, --device <device> Specify the video device to use (e.g., /dev/video0).
  • --list-devices List available video devices.
  • --list-formats List supported pixel formats.
  • --list-controls List available controls.
  • -c, --set-ctrl <name>=<value> Set the value of a control.
  • -C, --get-ctrl <name> Get the value of a control.
  • --stream-mmap Use memory-mapped I/O for streaming.
  • --stream-to <file> Stream video to a file.
  • --stream-count <count> Number of frames to stream.
  • --stream-to-host <hostname> Stream video over the network.
  • --stream-dmabuf Use DMABUFs for streaming.
  • --export-device <device> Device to export DMABUFs from.
  • --stream-out-mmap Use memory-mapped I/O for output streaming.
  • --out-device <device> Specify the output video device.
  • --stream-out-dmabuf Use DMABUFs for output streaming.

EXIT STATUS

Returns 0 on success, or a non-zero value if an error occurred.

EXAMPLES

List all available video devices:

v4l2-ctl --list-devices

List supported pixel formats for /dev/video0:

v4l2-ctl -d /dev/video0 --list-formats

List available controls for /dev/video0:

v4l2-ctl -d /dev/video0 --list-controls

Get the value of the 'brightness' control on /dev/video0:

v4l2-ctl -d /dev/video0 --get-ctrl brightness

Set the 'brightness' control to 128 on /dev/video0:

v4l2-ctl -d /dev/video0 --set-ctrl brightness=128

Stream video from /dev/video0 and store it in a file:

v4l2-ctl --stream-mmap --stream-count=1 --stream-to=file.raw

Stream video from /dev/video0 and stream it over the network:

v4l2-ctl --stream-mmap --stream-to-host <hostname>

Use 'qvidcap -p' on the host to view the video.

Stream video from /dev/video0 using DMABUFs exported from /dev/video2:

v4l2-ctl --stream-dmabuf --export-device /dev/video2

Stream video from a memory-to-memory device:

v4l2-ctl --stream-mmap --stream-out-mmap

Stream video from a capture video device (/dev/video1) to an output video device (/dev/video2):

v4l2-ctl -d1 --stream-mmap --out-device /dev/video2 --stream-out-dmabuf
