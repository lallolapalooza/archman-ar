val_async_select_info(3)

الحزمة: dnssec-tools

التراخيص: BSD

NAME

val_async_select_info, val_async_check_wait, val_async_cancel, val_async_cancel_all — asynchronous validation API

SYNOPSIS

#include <val.h>

int val_async_select_info(int fd, int events);

int val_async_check_wait(void);

int val_async_cancel(val_request_id_t request_id);

int val_async_cancel_all(void);

DESCRIPTION

These functions are part of the DNSSEC-Tools asynchronous validation API. They allow applications to perform DNSSEC validation operations asynchronously, without blocking the main execution thread.

val_async_select_info sets up the necessary file descriptor for the asynchronous operations. The fd parameter should be a file descriptor obtained from val_async_init(). The events parameter specifies the events to monitor for. This function is typically used in conjunction with the select(2) system call.

val_async_check_wait checks if there are any pending asynchronous validation requests. It should be called after val_async_select_info indicates that an event has occurred on the monitored file descriptor.

val_async_cancel cancels a specific asynchronous validation request identified by its request_id. The request_id is returned by the function that initiated the asynchronous request.

val_async_cancel_all cancels all pending asynchronous validation requests.

RETURN VALUES

val_async_select_info() returns VAL_NO_ERROR on success and VAL_BAD_ARGUMENT if an illegal argument was passed to the function.

val_async_check_wait() returns 0 when no pending requests are found and a positive integer when requests are still pending. A value less than zero on error.

val_async_cancel() and val_async_cancel_all() return VAL_NO_ERROR on success.
