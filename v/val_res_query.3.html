val_res_query(3)

الحزمة: dnssec-tools

التراخيص: BSD

val_res_query(3) دليل المبرمج val_res_query(3)

الاسم

val_res_query(), val_res_search() - استعلامات الدقة التي تم التحقق منها بواسطة DNSSEC

الملخص

#include <validator/validator.h>
int val_res_query(const val_context_t *ctx,
                  const char *dname,
                  int class,
                  int type,
                  unsigned char *answer,
                  int anslen,
                  val_status_t *val_status);
int val_res_search(val_context_t * ctx,
          const char *dname,
          int class_h,
          int type,
          unsigned char * answer,
          int anslen,
          val_status_t * val_status);

الوصف

تقوم الدالة val_res_query() بإجراء التحقق من صحة DNSSEC لاستعلامات DNS. وهي بديل مدرك لـ DNSSEC للدالة القديمة res_query(3). تقوم الدالة val_res_search() بإجراء عملية مشابهة للدالة val_res_query(). بالإضافة إلى ذلك، تستخدم مسارات البحث المحددة في ملف /etc/resolv.conf لإنشاء اسم النطاق المؤهل بالكامل. val_res_search() هي بديل مدرك لـ DNSSEC للدالة res_search(3).

المعلمة ctx هي سياق المدقق ويمكن تعيينها إلى NULL للإعدادات الافتراضية. يمكن العثور على مزيد من المعلومات حول هذا الحقل في libval(3).

المعلمة dname تحدد اسم النطاق، class تحدد فئة DNS و type تحدد نوع DNS.

يتم إرجاع قيم حالة التحقق للدالتين val_res_query() و val_res_search() في حقول val_status الخاصة بهما. p_val_status() ترجع وصفًا نصيًا موجزًا لرمز الخطأ. val_istrusted() تحدد ما إذا كان رمز الحالة يشير إلى أنه يمكن الوثوق بالاستجابة، و val_isvalidated() تحدد ما إذا كان رمز الحالة يشير إلى أنه تم التحقق من الاستجابة. (انظر libval(3) لمزيد من المعلومات).

قيم الإرجاع

val_res_query() و val_res_search() ترجع عدد البايتات المستلمة عند النجاح و -1 عند الفشل.
