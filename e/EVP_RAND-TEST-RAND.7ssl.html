EVP_RAND-TEST-RAND(7ssl)

الحزمة: openssl

التراخيص: Apache-2.0

EVP_RAND-TEST-RAND(7ssl) OpenSSL EVP_RAND-TEST-RAND(7ssl)

اسم

EVP_RAND-TEST-RAND - تطبيق EVP_RAND للاختبار

وصف

دعم مولد اختبار من خلال واجهة برمجة التطبيقات EVP_RAND. هذا المولد مخصص لأغراض الاختبار فقط، ولا يقوم بإنشاء أرقام عشوائية.

الهوية

"TEST-RAND" هو اسم هذا التطبيق؛ يمكن استخدامه مع الدالة EVP_RAND_fetch().

المعلمات المدعومة

المعلمات المدعومة هي:

"state" (OSSL_RAND_PARAM_STATE) <عدد صحيح>
"fips-indicator" (OSSL_RAND_PARAM_FIPS_APPROVED_INDICATOR) <عدد صحيح>
تعمل هذه المعلمات كما هو موضح في "PARAMETERS" في EVP_RAND(3).
"strength" (OSSL_RAND_PARAM_STRENGTH) <عدد صحيح غير مؤشر>
"reseed_requests" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <عدد صحيح غير مؤشر>
"reseed_time_interval" (OSSL_DRBG_PARAM_RESEED_TIME_INTERVAL) <عدد صحيح>
"max_request" (OSSL_DRBG_PARAM_RESEED_REQUESTS) <عدد صحيح غير مؤشر>
"min_entropylen" (OSSL_DRBG_PARAM_MIN_ENTROPYLEN) <عدد صحيح غير مؤشر>
"max_entropylen" (OSSL_DRBG_PARAM_MAX_ENTROPYLEN) <عدد صحيح غير مؤشر>
"min_noncelen" (OSSL_DRBG_PARAM_MIN_NONCELEN) <عدد صحيح غير مؤشر>
"max_noncelen" (OSSL_DRBG_PARAM_MAX_NONCELEN) <عدد صحيح غير مؤشر>
"max_perslen" (OSSL_DRBG_PARAM_MAX_PERSLEN) <عدد صحيح غير مؤشر>
"max_adinlen" (OSSL_DRBG_PARAM_MAX_ADINLEN) <عدد صحيح غير مؤشر>
"reseed_counter" (OSSL_DRBG_PARAM_RESEED_COUNTER) <عدد صحيح غير مؤشر>
تعمل هذه المعلمات كما هو موضح في "PARAMETERS" في EVP_RAND(3)، باستثناء أنه يمكن ضبطها جميعًا وقراءتها.
"test_entropy" (OSSL_RAND_PARAM_TEST_ENTROPY) <سلسلة بايتات>
تقوم بتعيين البايتات التي يتم إرجاعها عند إرسال طلب إنتروبيا إلى مولد الاختبار. يتم تذكر الموضع الحالي عبر استدعاءات التوليد. إذا كانت البيانات المتوفرة غير كافية لتلبية طلب، يتم إرجاع خطأ.
"test_nonce" (OSSL_RAND_PARAM_TEST_NONCE) <سلسلة بايتات>
تقوم بتعيين البايتات التي يتم إرجاعها عند إرسال طلب nonce إلى مولد الاختبار. سيقوم كل طلب nonce بإرجاع جميع البايتات.
"generate" (OSSL_RAND_PARAM_GENERATE) <عدد صحيح>
إذا كانت هذه المعلمة صفرًا، فسوف تقوم فقط بإصدار بيانات nonce والإنتروبيا المقدمة عبر المعلمات المذكورة أعلاه. بخلاف ذلك، يتم إنتاج مخرجات شبه عشوائية منخفضة الجودة وغير مشفرة. هذه المعلمة تساوي صفرًا بشكل افتراضي.

ملاحظات

يمكن الحصول على سياق لمولد اختبار عن طريق استدعاء:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "TEST-RAND", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

أمثلة

EVP_RAND *rand;
EVP_RAND_CTX *rctx;
unsigned char bytes[100];
OSSL_PARAM params[4], *p = params;
unsigned char entropy[1000] = { ... };
unsigned char nonce[20] = { ... };
unsigned int strength = 48;
rand = EVP_RAND_fetch(NULL, "TEST-RAND", NULL);
rctx = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_free(rand);
*p++ = OSSL_PARAM_construct_uint(OSSL_RAND_PARAM_STRENGTH, &strength);
*p++ = OSSL_PARAM_construct_octet_string(OSSL_RAND_PARAM_TEST_ENTROPY,
                                         entropy, sizeof(entropy));
*p++ = OSSL_PARAM_construct_octet_string(OSSL_RAND_PARAM_TEST_NONCE,
                                         nonce, sizeof(nonce));
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
