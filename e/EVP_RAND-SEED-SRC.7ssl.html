EVP_RAND-SEED-SRC(7ssl)

الحزمة: openssl

التراخيص: Apache-2.0

EVP_RAND-SEED-SRC(7ssl) OpenSSL EVP_RAND-SEED-SRC(7ssl)

الاسم

EVP_RAND-SEED-SRC - تطبيق EVP_RAND لمصدر بذرة العشوائية

الوصف

دعم لتوليد الأرقام العشوائية الحتمي من خلال واجهة برمجة تطبيقات EVP_RAND.

يتم تحديد مصادر البذور المستخدمة عند تكوين OpenSSL للبناء باستخدام الخيار --with-rand-seed=. افتراضيًا، يتم استخدام مصادر العشوائية لنظام التشغيل.

الهوية

"SEED-SRC" هو اسم هذا التطبيق؛ يمكن استخدامه مع الدالة EVP_RAND_fetch().

المعلمات المدعومة

المعلمات المدعومة هي:

"state" (OSSL_RAND_PARAM_STATE) <integer>
"strength" (OSSL_RAND_PARAM_STRENGTH) <unsigned integer>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <unsigned integer>
تعمل هذه المعلمات كما هو موضح في "PARAMETERS" في EVP_RAND(3).

ملاحظات

يمكن الحصول على سياق لمصدر البذور عن طريق استدعاء:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "SEED-SRC", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

أمثلة

EVP_RAND *rand;
EVP_RAND_CTX *seed, *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
/* إنشاء وتفعيل مصدر بذرة */
rand = EVP_RAND_fetch(NULL, "SEED-SRC", NULL);
seed = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_instantiate(seed, strength, 0, NULL, 0, NULL);
EVP_RAND_free(rand);
/* تغذية هذا في DRBG */
rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, seed);
EVP_RAND_free(rand);
/* تكوين DRBG */
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_CIPHER,
                                        SN_aes_256_ctr, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
EVP_RAND_CTX_free(seed);
