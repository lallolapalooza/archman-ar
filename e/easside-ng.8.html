easside-ng(8)

الحزمة: aircrack-ng

EASSIDE-NG(8) دليل مدير النظام EASSIDE-NG(8)

الاسم

easside-ng - أداة سحرية تلقائية تسمح لك بالتواصل عبر نقطة وصول (AP) مشفرة بـ WEP دون معرفة المفتاح

الملخص

easside-ng <خيارات>

الوصف

easside-ng هي أداة سحرية تلقائية تسمح لك بالتواصل عبر نقطة وصول (AP) مشفرة بـ WEP دون معرفة مفتاح WEP. تقوم أولاً بتحديد شبكة، ثم تربط بها، وتحصل على بيانات XOR لخوارزمية التوليد العشوائي الزائف (PRGA)، وتحدد مخطط IP للشبكة، ثم تقوم بإعداد واجهة TAP حتى تتمكن من التواصل مع نقطة الوصول دون الحاجة إلى مفتاح WEP. كل هذا يتم دون تدخل منك.

الخيارات

-h
يعرض شاشة المساعدة.
-v <عنوان MAC للضحية>
عنوان MAC لنقطة الوصول المستهدفة (اختياري).
-m <عنوان MAC المصدر>
عنوان MAC المصدر المراد استخدامه (اختياري).
-i <عنوان IP>
عنوان IP المصدر المراد استخدامه على شبكة WLAN. الافتراضي هو الشبكة التي تم فك تشفيرها مضافًا إليها '.123' (اختياري).
-r <عنوان IP للموجه>
عنوان IP لموجه نقطة الوصول. يمكن أن يكون هذا عنوان IP الخارجي لنقطة الوصول أو عنوان IP لموجه فعلي اعتمادًا على الطوبولوجيا. الافتراضي هو الشبكة التي تم فك تشفيرها مضافًا إليها '.1' (اختياري).
-s <عنوان IP لخادم Buddy>
عنوان IP لخادم Buddy-ng (إلزامي)
-f <الواجهة>
واجهة الشبكة اللاسلكية المراد استخدامها (إلزامي)
-c <القناة>
تثبيت الواجهة على هذه القناة (اختياري).
-n
تحديد عنوان IP للإنترنت فقط.
