Exporter__Tiny__Manual__QuickStart(3pm)

الحزمة: perl-exporter-tiny

التراخيص: PerlArtistic, GPL

Exporter::Tiny::Manual::QuickStart(3) وثائق مساهمة المستخدم لـ Perl Exporter::Tiny::Manual::QuickStart(3)

الاسم

Exporter::Tiny::Manual::QuickStart - أسرع طريقة للبدء باستخدام Exporter::Tiny

الملخص

package MyUtils;

use Exporter::Shiny qw( frobnicate );

sub frobnicate {
   ...;   # الكود الخاص بك هنا
}

1;

الآن يمكن للناس استخدام وحدتك النمطية مثل هذا:

use MyUtils "frobnicate";

frobnicate(42);

أو مثل هذا:

use MyUtils "frobnicate" => { -as => "frob" };

frob(42);

انظر الملخص. نعم، الأمر بهذه البساطة.

الخطوات التالية

التصديرات الافتراضية

لاحظ أن الوحدة النمطية في الملخص لا تصدر أي شيء افتراضيًا. إذا قام الناس بتحميل "MyUtils" مثل هذا:

use MyUtils;

فلن يكونوا قد استوردوا أي وظائف. يمكنك تحديد مجموعة افتراضية من الوظائف لتصديرها مثل هذا:

package MyUtils;

use Exporter::Shiny qw( frobnicate );

our @EXPORT = qw( frobnicate );

sub frobnicate { ... }

1;

أو، إذا كنت تريد أن تكون نجم روك خارق:

package MyUtils;

use Exporter::Shiny our @EXPORT = qw( frobnicate );

sub frobnicate { ... }

1;

العلامات

يمكنك توفير علامات ليستخدمها الناس:

package MyUtils;

use Exporter::Shiny qw( frobnicate red green blue );

our %EXPORT_TAGS = (
   utils   => [qw/ frobnicate /],
   colours => [qw/ red green blue /],
);

sub frobnicate { ... }
sub red        { ... }
sub green      { ... }
sub blue       { ... }

1;

ويمكن للناس الآن استيراد وظائفك مثل هذا:

use MyUtils ":colours";

أو هذا:

use MyUtils "-colours";

أو الاستفادة من حقيقة أن Perl يقوم تلقائيًا بتمييز الكلمات الفارغة المسبوقة بشرطة:

use MyUtils -colours;

يتم تعريف علامتين تلقائيًا لك: "-default" (وهي مجرد نفس @EXPORT) و "-all" (وهي اتحاد @EXPORT و @EXPORT_OK). إذا كنت لا تحبها، يمكنك تجاوزها:

our %EXPORT_TAGS = (
   default => \@some_other_stuff,
   all     => \@more_stuff,
);

المولدات

يحدث التصدير عادةً عن طريق نسخ دالة فرعية من الحزمة الخاصة بك إلى الحزمة الخاصة بالمستدعي. ولكن في بعض الأحيان يكون من المفيد إنشاء دالة فرعية *مخصصة* لإدراجها في حزمة المستدعي. هذا سهل جدًا.

package MyUtils;

use Exporter::Shiny qw( frobnicate );

sub _generate_frobnicate {
   my ( $me, $name, $args, $globals ) = @_;
   my $caller = $globals->{into};

   return sub {
       ...;  # الكود الخاص بك هنا
   };
}

1;

المعلمة $me هنا هي سلسلة نصية تحتوي على اسم الحزمة التي يتم الاستيراد منها؛ $caller هي الحزمة الوجهة؛ $name هو اسم الدالة الفرعية (في هذه الحالة "frobnicate")؛ و $args هي معلمة مخصصة لهذه الوظيفة. (حسب العرف، $args عادة ما تكون خريطة.)

# الهاشف { foo => 42 } هو $args أعلاه.
#
use MyUtils "frobnicate" => { foo => 42 };

تجنب Exporter::Shiny

Exporter::Shiny هو غلاف صغير حول Exporter::Tiny. يجب أن يفعل في الغالب ما تريده، ولكن قد تفضل أحيانًا استخدام Exporter::Tiny مباشرة.

يمكن كتابة المثال في الملخص على هذا النحو:

package MyUtils;

use parent "Exporter::Tiny";
our @EXPORT_OK = qw( frobnicate );

sub frobnicate {
   ...;   # الكود الخاص بك هنا
}

1;

ما يفعله Exporter::Shiny هو في الغالب مجرد تعيين @EXPORT_OK لك وإعداد الوراثة من الفئة الأساسية (Exporter::Tiny).

يقوم Exporter::Shiny أيضًا بتعيين $INC{'MyUtils.pm'} لك، والذي لا يحدث عادة فرقًا كبيرًا، ولكنه مفيد في بعض الحالات الهامشية.
