getrpcent(3) دليل الدوال المكتبية getrpcent(3)

الاسم

getrpcent, getrpcbyname, getrpcbynumber, setrpcent, endrpcent - الحصول على مدخل RPC

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <netdb.h>
struct rpcent *getrpcent(void);
struct rpcent *getrpcbyname(const char *name);
struct rpcent *getrpcbynumber(int number);
void setrpcent(int stayopen);
void endrpcent(void);

الوصف

تقوم الدوال getrpcent() و getrpcbyname() و getrpcbynumber() بإرجاع مؤشر إلى كائن يحتوي على الحقول المفككة لمدخل في قاعدة بيانات أرقام برامج RPC.


struct rpcent {
    char  *r_name;     /* اسم الخادم لهذا برنامج RPC */
    char **r_aliases;  /* قائمة الأسماء البديلة */
    long   r_number;   /* رقم برنامج RPC */
};

الأعضاء في هذا الهيكل هم:

r_name
اسم الخادم لهذا برنامج RPC.
r_aliases
قائمة تنتهي بـ NULL بأسماء بديلة لبرنامج RPC.
r_number
رقم برنامج RPC لهذه الخدمة.

تقوم الدالة getrpcent() بقراءة المدخل التالي من قاعدة البيانات. يتم فتح اتصال بقاعدة البيانات إذا لزم الأمر.

تقوم الدالة setrpcent() بفتح اتصال بقاعدة البيانات، وتعيين المدخل التالي إلى المدخل الأول. إذا كانت stayopen غير صفرية، فلن يتم إغلاق الاتصال بقاعدة البيانات بين استدعاءات إحدى دوال getrpc*().

تقوم الدالة endrpcent() بإغلاق الاتصال بقاعدة البيانات.

تقوم الدالتان getrpcbyname() و getrpcbynumber() بالبحث بشكل متسلسل من بداية الملف حتى يتم العثور على اسم برنامج RPC أو رقم برنامج مطابق، أو حتى الوصول إلى نهاية الملف.

قيمة الإرجاع

عند النجاح، ترجع getrpcent() و getrpcbyname() و getrpcbynumber() مؤشرًا إلى هيكل rpcent مخصص في الذاكرة الثابتة. يتم إرجاع NULL عند نهاية الملف أو حدوث خطأ.

الملفات

/etc/rpc
قاعدة بيانات أرقام برامج RPC.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

getrpcent (), getrpcbyname (), getrpcbynumber () أمان الخيوط MT-Unsafe
setrpcent (), endrpcent () أمان الخيوط MT-Safe locale

التاريخ
