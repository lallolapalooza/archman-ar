expr(1)

الحزمة: coreutils

التراخيص: GPL-3.0-or-later, GFDL-1.3-or-later

EXPR(1) أوامر المستخدم EXPR(1)

الاسم

expr - تقييم التعبيرات

المُلَخَّص

expr EXPRESSION
expr OPTION

الوصف

--help
عرض هذه المساعدة والخروج
--version
إخراج معلومات الإصدار والخروج

طباعة قيمة EXPRESSION إلى المخرج القياسي. يتم فصل مجموعات الأسبقية المتزايدة بسطر فارغ. قد يكون EXPRESSION:

ARG1 | ARG2
ARG1 إذا لم يكن فارغًا أو 0، وإلا ARG2
ARG1 & ARG2
ARG1 إذا لم يكن أي من الوسيطين فارغًا أو 0، وإلا 0
ARG1 < ARG2
ARG1 أقل من ARG2
ARG1 <= ARG2
ARG1 أقل من أو يساوي ARG2
ARG1 = ARG2
ARG1 يساوي ARG2
ARG1 != ARG2
ARG1 لا يساوي ARG2
ARG1 >= ARG2
ARG1 أكبر من أو يساوي ARG2
ARG1 > ARG2
ARG1 أكبر من ARG2
ARG1 + ARG2
المجموع الحسابي لـ ARG1 و ARG2
ARG1 - ARG2
الفرق الحسابي لـ ARG1 و ARG2
ARG1 * ARG2
حاصل الضرب الحسابي لـ ARG1 و ARG2
ARG1 / ARG2
حاصل القسمة الحسابي لـ ARG1 مقسومًا على ARG2
ARG1 % ARG2
باقي القسمة الحسابي لـ ARG1 مقسومًا على ARG2
STRING : REGEXP
مطابقة نمط مثبتة لـ REGEXP في STRING
match STRING REGEXP
نفس STRING : REGEXP
substr STRING POS LENGTH
سلسلة فرعية من STRING، POS محسوبة من 1
index STRING CHARS
الفهرس في STRING حيث يتم العثور على أي من CHARS، أو 0
length STRING
طول STRING
+ TOKEN
تفسير TOKEN كسلسلة نصية، حتى لو كان كلمة مفتاحية مثل 'match' أو عامل تشغيل مثل '/'
( EXPRESSION )
قيمة EXPRESSION

احذر من أن العديد من العوامل تتطلب الهروب أو الاقتباس للأصداف. المقارنات حسابية إذا كان كلا ARG متوفرين أرقامًا، وإلا فهي معجمية. تطابقات النمط تُرجع السلسلة التي تمت مطابقتها بين \( و \) أو فارغة؛ إذا لم يتم استخدام \( و \)، فإنها تُرجع عدد الأحرف المطابقة أو 0.

حالة الخروج تكون 0 إذا كان EXPRESSION ليس فارغًا ولا 0، 1 إذا كان EXPRESSION فارغًا أو 0، 2 إذا كان EXPRESSION غير صالح نحويًا، و 3 إذا حدث خطأ.
