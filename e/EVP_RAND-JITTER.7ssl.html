EVP_RAND-JITTER(7ssl)

الحزمة: openssl

التراخيص: Apache-2.0

EVP_RAND-JITTER(7ssl) OpenSSL EVP_RAND-JITTER(7ssl)

الاسم

EVP_RAND-JITTER - مصدر تهيئة مولد الأرقام العشوائية EVP_RAND التنفيذي.

الوصف

دعم لتهيئة مولد الأرقام العشوائية الحتمية عبر واجهة برمجة تطبيقات EVP_RAND.

مصدر التهيئة البرمجية هذا ينتج عشوائية بناءً على تقلبات طفيفة في "الارتعاش" (jitter) في وحدة المعالجة المركزية.

وهو متاح عندما يتم تجميع OpenSSL مع خيار enable-jitter. عند توفره، يتم إدراجه في openssl list -random-generators و openssl info -seeds.

الهوية

"JITTER" هو اسم هذا التنفيذ؛ يمكن استخدامه مع دالة EVP_RAND_fetch().

المعلمات المدعومة

المعلمات المدعومة هي:

"state" (OSSL_RAND_PARAM_STATE) <عدد صحيح>
"strength" (OSSL_RAND_PARAM_STRENGTH) <عدد صحيح غير موقع>
"max_request" (OSSL_RAND_PARAM_MAX_REQUEST) <عدد صحيح غير موقع>
تعمل هذه المعلمات كما هو موضح في "PARAMETERS" في EVP_RAND(3).

ملاحظات

يمكن الحصول على سياق لمصدر التهيئة عن طريق استدعاء:

EVP_RAND *rand = EVP_RAND_fetch(NULL, "JITTER", NULL);
EVP_RAND_CTX *rctx = EVP_RAND_CTX_new(rand, NULL);

تمت إضافة الخيار enable-jitter في OpenSSL 3.4.

من خلال تحديد خيار التكوين enable-fips-jitter، سيستخدم موفر FIPS مصدر ارتعاش داخلي لإنتروبيا. سيؤدي تمكين هذا الخيار إلى تشغيل موفر FIPS في وضع غير متوافق ما لم يتم إجراء تقييم إنتروبيا ESV https://csrc.nist.gov/Projects/cryptographic-module-validation-program/entropy-validations وتحقق إضافي من خلال CMVP https://csrc.nist.gov/projects/cryptographic-module-validation-program. تمت إضافة هذا الخيار في OpenSSL 3.5.

أمثلة

EVP_RAND *rand;
EVP_RAND_CTX *seed, *rctx;
unsigned char bytes[100];
OSSL_PARAM params[2], *p = params;
unsigned int strength = 128;
/* إنشاء وتهيئة مصدر التهيئة */
rand = EVP_RAND_fetch(NULL, "JITTER", NULL);
seed = EVP_RAND_CTX_new(rand, NULL);
EVP_RAND_instantiate(seed, strength, 0, NULL, 0, NULL);
EVP_RAND_free(rand);
/* تغذية هذا في DRBG */
rand = EVP_RAND_fetch(NULL, "CTR-DRBG", NULL);
rctx = EVP_RAND_CTX_new(rand, seed);
EVP_RAND_free(rand);
/* تكوين DRBG */
*p++ = OSSL_PARAM_construct_utf8_string(OSSL_DRBG_PARAM_CIPHER,
                                        SN_aes_256_ctr, 0);
*p = OSSL_PARAM_construct_end();
EVP_RAND_instantiate(rctx, strength, 0, NULL, 0, params);
EVP_RAND_generate(rctx, bytes, sizeof(bytes), strength, 0, NULL, 0);
EVP_RAND_CTX_free(rctx);
EVP_RAND_CTX_free(seed);
