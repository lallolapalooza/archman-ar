EFADV_QUERY_QP_WQS(3) دليل EFA المباشر EFADV_QUERY_QP_WQS(3)

الاسم

efadv_query_qp_wqs - استعلام سمات طابور العمل الخاصة بـ EFA لوحدة طابور الزوج.

ملخص

#include <infiniband/efadv.h>
int efadv_query_qp_wqs(struct ibv_qp *ibvqp, struct efadv_wq_attr *sq_attr,
                       struct efadv_wq_attr *rq_attr, uint32_t inlen);

الوصف

تقوم efadv_query_qp_wqs() بالاستعلام عن سمات طابور العمل الخاصة بوحدة طابور الزوج للجهاز.

يتم التعامل مع التوافق باستخدام حقلي comp_mask و inlen.

struct efadv_wq_attr {
    uint64_t comp_mask;
    uint8_t *buffer;
    uint32_t entry_size;
    uint32_t num_entries;
    uint32_t *doorbell;
    uint32_t max_batch;
    uint8_t reserved[4];
};
inlen
الدخل: حجم `struct efadv_wq_attr`.
comp_mask
قناع التوافق.
buffer
مخزن طابور العمل.
entry_size
حجم كل إدخال في الطابور.
num_entries
الحد الأقصى لعدد الإدخالات في الطابور.
doorbell
جرس باب الطابور.
max_batch
الحد الأقصى لحجم الدفعة لتقديمات الطابور.

قيمة الإرجاع

تُرجع efadv_query_qp_wqs() القيمة 0 عند النجاح، أو قيمة `errno` عند الفشل (والتي تشير إلى سبب الفشل).

انظر أيضًا

efadv(7)

ملاحظات

•
قناع التوافق (comp_mask) هو حقل خرج ولا توجد له حاليًا أي قيم.
