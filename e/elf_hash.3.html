elf_hash(3)

الحزمة: libelf

التراخيص: GPL-2.0-or-later OR LGPL-3.0-or-later

ELF_HASH(3) دليل مبرمج Libelf ELF_HASH(3)

الاسم

elf_hash, elf_gnu_hash - حساب قيمة التجزئة القياسية لـ ELF أو تجزئة GNU لسلسلة نصية.

النبذة

#include <libelf.h>
unsigned long int elf_hash(const char *string);
unsigned long int elf_gnu_hash(const char *string);

الوصف

تقوم الدالة elf_hash بحساب قيمة التجزئة القياسية لـ ELF لسلسلة نصية تنتهي بـ NULL. تُستخدم قيم التجزئة عادةً في ملفات الكائنات لـ ELF لتجزئة جدول الرموز. تُستخدم دالة التجزئة في أقسام SHT_HASH لأنها تتجنب إنشاء قيم تعتمد على بنية معينة وهي مناسبة للاستخدام عبر بنيات مختلفة.

تقوم الدالة elf_gnu_hash بحساب قيمة التجزئة بنمط GNU لسلسلة نصية تنتهي بـ NULL، وتُستخدم في قسم SHT_GNU_HASH.

المعاملات

string
سلسلة نصية تنتهي بـ NULL ليتم تجزئتها.

قيمة الإرجاع

تعيد هاتان الدالتان قيمة تجزئة لـ string. تُستخدم فقط الـ 32 بت الأقل من قيمة الإرجاع.

انظر أيضًا

libelf(3), elf(5)

السمات
