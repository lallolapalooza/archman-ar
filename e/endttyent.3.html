getttyent(3) دليل وظائف المكتبة getttyent(3)

الاسم

getttyent, getttynam, setttyent, endttyent — الحصول على مدخل ملف ttys

المكتبة

مكتبة C القياسية (libc، -lc)

ملخص

#include <ttyent.h>
struct ttyent *getttyent(void);
struct ttyent *getttynam(const char *name);
int setttyent(void);
int endttyent(void);

الوصف

توفر هذه الوظائف واجهة للملف _PATH_TTYS (على سبيل المثال، /etc/ttys).

تقوم الوظيفة setttyent() بفتح الملف أو إرجاعه إلى البداية إذا كان مفتوحًا بالفعل.

تقوم الوظيفة endttyent() بإغلاق الملف.

تقوم الوظيفة getttynam() بالبحث عن اسم طرفية معين في الملف. وتعيد مؤشرًا إلى هيكل ttyent (وصف أدناه).

تقوم الوظيفة getttyent() بفتح الملف _PATH_TTYS (إذا لزم الأمر) وتعيد المدخل الأول. إذا كان الملف مفتوحًا بالفعل، فإنها تعيد المدخل التالي. هيكل ttyent له الصيغة التالية:


struct ttyent {
    char *ty_name;     /* اسم جهاز الطرفية */
    char *ty_getty;    /* الأمر المراد تنفيذه، عادةً getty */
    char *ty_type;     /* نوع الطرفية لـ termcap */
    int   ty_status;   /* أعلام الحالة */
    char *ty_window;   /* الأمر لبدء مدير النوافذ */
    char *ty_comment;  /* حقل التعليق */
};

يمكن أن تكون ty_status:


#define TTY_ON     0x01  /* تمكين تسجيل الدخول (بدء برنامج ty_getty) */
#define TTY_SECURE 0x02  /* السماح للمستخدم UID 0 بتسجيل الدخول */

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
getttyent (), setttyent (), endttyent (), getttynam () سلامة الخيط MT-Unsafe race:ttyent

المعايير

BSD.

ملاحظات

تحت Linux، الملف /etc/ttys، والوظائف الموصوفة أعلاه، غير مستخدمة.

انظر أيضًا

ttyname(3)، ttyslot(3)
