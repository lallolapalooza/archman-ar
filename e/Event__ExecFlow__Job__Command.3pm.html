Event__ExecFlow__Job__Command(3pm)

الحزمة: perl-event-execflow

التراخيص: PerlArtistic

Event::ExecFlow::Job::Command(3) وثائق مساهمات المستخدم لـ Perl Event::ExecFlow::Job::Command(3)

الاسم

Event::ExecFlow::Job::Command - أمر خارجي للتنفيذ غير المتزامن

الملخص

Event::ExecFlow::Job::Command->new (
  command              => أمر Shell ليتم تنفيذه،
  fetch_output         => قيمة منطقية إذا كان يجب جلب المخرجات،
  progress_parser      => إغلاق أو تعبير نمطي لتحليل التقدم،
  configure_callback   => إغلاق لتهيئة الأمر
                          قبل التنفيذ،
  ...
  سمات Event::ExecFlow::Job
);

الوصف

استخدم هذه الوحدة لتنفيذ أمر خارجي بشكل غير متزامن مع Event::ExecFlow.
