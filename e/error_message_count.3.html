error(3) دليل وظائف المكتبة error(3)

الاسم

error, error_at_line, error_message_count, error_one_per_line, error_print_progname - وظائف الإبلاغ عن الأخطاء في glibc

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <error.h>
void error(int status, int errnum, const char *format, ...);
void error_at_line(int status, int errnum, const char *file,
                   unsigned int line, const char *format, ...);
extern unsigned int error_message_count;
extern int error_one_per_line;
extern typeof(void (void))  *error_print_progname;

الوصف

error() هي وظيفة عامة للإبلاغ عن الأخطاء. تقوم بتفريغ stdout، ثم إخراج إلى stderr اسم البرنامج، ونقطتين ومسافة، والرسالة المحددة بواسطة سلسلة تنسيق format بأسلوب printf(3)، وإذا كانت errnum غير صفرية، فستقوم بنقطتين ومسافة إضافيتين متبوعة بالسلسلة المعطاة بواسطة strerror(errnum). يجب أن تأتي أي وسيطات مطلوبة لـ format بعد format في قائمة الوسيطات. يتم إنهاء الإخراج بحرف سطر جديد.

اسم البرنامج الذي تطبعه error() هو قيمة المتغير العام program_invocation_name(3). program_invocation_name له قيمة أولية مطابقة لـ argv[0] لـ main(). يمكن تعديل قيمة هذا المتغير لتغيير إخراج error().

إذا كانت status ذات قيمة غير صفرية، فإن error() تقوم باستدعاء exit(3) لإنهاء البرنامج باستخدام القيمة المعطاة كحالة خروج؛ وإلا فإنها تعود بعد طباعة رسالة الخطأ.

الوظيفة error_at_line() هي نفسها تمامًا مثل error()، باستثناء إضافة الوسيطات file و line. الإخراج الناتج هو كما هو الحال بالنسبة لـ error()، باستثناء أنه بعد اسم البرنامج يتم كتابة: نقطتين، وقيمة file، ونقطتين، وقيمة line. قد تكون قيم المعالج المسبق __LINE__ و __FILE__ مفيدة عند استدعاء error_at_line()، ولكن يمكن أيضًا استخدام قيم أخرى. على سبيل المثال، يمكن أن تشير هذه الوسيطات إلى موقع في ملف إدخال.

إذا تم تعيين المتغير العام error_one_per_line على قيمة غير صفرية، فإن سلسلة من استدعاءات error_at_line() بنفس قيمة file و line ستؤدي إلى إخراج رسالة واحدة فقط (الأولى).

يقوم المتغير العام error_message_count بعدد الرسائل التي تم إخراجها بواسطة error() و error_at_line().

إذا تم تعيين المتغير العام error_print_progname إلى عنوان وظيفة (أي أنه ليس NULL)، فسيتم استدعاء هذه الوظيفة بدلاً من إضافة اسم البرنامج والنقطتين إلى بداية الرسالة. يجب أن تقوم الوظيفة بطباعة سلسلة مناسبة إلى stderr.

سمات

لشرح المصطلحات المستخدمة في هذا القسم، راجع attributes(7).

الواجهة السمة القيمة
error () سلامة الخيوط MT-Safe locale
error_at_line () سلامة الخيوط MT-Unsafe race: error_at_line/error_one_per_line locale

يتم الوصول إلى المتغير الداخلي error_one_per_line (بدون أي شكل من أشكال المزامنة، ولكن نظرًا لأنه int يستخدم مرة واحدة، فيجب أن يكون آمنًا بدرجة كافية)، وإذا تم تعيين error_one_per_line على قيمة غير صفرية، فإن المتغيرات الثابتة الداخلية (غير المكشوفة للمستخدمين) المستخدمة لتخزين آخر اسم ملف ورقم سطر تم طباعتهما يتم الوصول إليهما وتعديلهما دون مزامنة؛ التحديث ليس ذريًا ويحدث قبل تعطيل الإلغاء، لذلك لا يمكن مقاطعته إلا بعد تعديل أحد المتغيرين. بعد ذلك، error_at_line() تشبه إلى حد كبير error().
