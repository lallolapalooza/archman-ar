التراخيص: PerlArtistic

Event::ExecFlow::Job::Code(3) توثيق مساهمة المستخدم في Perl Event::ExecFlow::Job::Code(3)

الاسم

Event::ExecFlow::Job::Code - تنفيذ دالة إغلاق

ملخص

Event::ExecFlow::Job::Code->new (
  code     => دالة إغلاق للتنفيذ،
  ...
  سمات Event::ExecFlow::Job
);

الوصف

استخدم هذه الوحدة لتنفيذ كود Perl عشوائي (مُمرر كدالة إغلاق) داخل Event::ExecFlow.
