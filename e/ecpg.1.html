ecpg(1)

الحزمة: postgresql-libs

التراخيص: PostgreSQL

ECPG(1) وثائق PostgreSQL 18.1 ECPG(1)

الاسم

ecpg - معالج SQL المدمج للغة C

الموجز

ecpg [خيار...] ملف...

الوصف

ecpg هو المعالج المسبق لـ SQL المدمج لبرامج C. يقوم بتحويل برامج C ذات عبارات SQL المدمجة إلى كود C عادي عن طريق استبدال استدعاءات SQL باستدعاءات وظائف خاصة. يمكن بعد ذلك معالجة ملفات الإخراج بأي سلسلة أدوات مترجم C.

سيقوم ecpg بتحويل كل ملف إدخال معطى في سطر الأوامر إلى ملف الإخراج C المقابل. إذا كان اسم ملف الإدخال لا يحتوي على أي امتداد، فسيتم افتراض .pgc. سيتم استبدال امتداد الملف بـ .c لإنشاء اسم ملف الإخراج. ولكن يمكن تجاوز اسم ملف الإخراج باستخدام الخيار -o.

إذا كان اسم ملف الإدخال هو فقط -، فسيقرأ ecpg البرنامج من الإدخال القياسي (ويكتب إلى الإخراج القياسي، ما لم يتم تجاوز ذلك باستخدام -o).

لا يصف صف المرجع هذا لغة SQL المدمجة. راجع الفصل 34 لمزيد من المعلومات حول هذا الموضوع.

الخيارات

يقبل ecpg الوسائط التالية في سطر الأوامر:

-c

توليد كود C تلقائيًا من كود SQL. حاليًا، يعمل هذا مع EXEC SQL TYPE.

-C mode

تعيين وضع التوافق. يمكن أن يكون mode INFORMIX أو INFORMIX_SE أو ORACLE.

-D symbol[=value]

تعريف رمز المعالج المسبق، بنفس طريقة توجيه EXEC SQL DEFINE. إذا لم يتم تحديد value، فسيتم تعريف الرمز بالقيمة 1.

-h

معالجة ملفات الرأس. عند تحديد هذا الخيار، يصبح امتداد ملف الإخراج .h وليس .c، والامتداد الافتراضي لملف الإدخال هو .pgh وليس .pgc. أيضًا، يتم فرض الخيار -c.

-i

قم بمعالجة ملفات تضمين النظام أيضًا.

-I directory

تحديد مسار تضمين إضافي، يستخدم للعثور على الملفات المدرجة عبر EXEC SQL INCLUDE. الافتراضيات هي . (الدليل الحالي)، /usr/local/include، دليل PostgreSQL للتضمين الذي يتم تحديده عند الترجمة (الافتراضي: /usr/local/pgsql/include)، و /usr/include، بهذا الترتيب.

-o filename

يحدد أن ecpg يجب أن يكتب كل إخراجه إلى filename المحدد. اكتب -o - لإرسال كل الإخراج إلى الإخراج القياسي.

-r option

يختار سلوك وقت التشغيل. option يمكن أن يكون أحد الخيارات التالية:

no_indicator

لا تستخدم المؤشرات ولكن بدلاً من ذلك استخدم قيمًا خاصة لتمثيل القيم الفارغة. تاريخياً، كانت هناك قواعد بيانات تستخدم هذا النهج.

prepare

قم بإعداد جميع العبارات قبل استخدامها. ستحتفظ مكتبة ecpg بذاكرة تخزين مؤقت للعبارات المعدة وتعيد استخدام عبارة إذا تم تنفيذها مرة أخرى. إذا امتلأت الذاكرة المؤقتة، ستقوم مكتبة ecpg بتحرير العبارة الأقل استخدامًا.

questionmarks

السماح بعلامة الاستفهام كعنصر نائب لأسباب التوافق. كان هذا هو الافتراضي منذ وقت طويل.

-t

تشغيل الالتزام التلقائي للمعاملات. في هذا الوضع، يتم الالتزام بكل أمر SQL تلقائيًا ما لم يكن داخل كتلة معاملة صريحة. في الوضع الافتراضي، يتم الالتزام بالأوامر فقط عند إصدار EXEC SQL COMMIT.

-v

طباعة معلومات إضافية بما في ذلك الإصدار ومسار "التضمين".

--version

طباعة إصدار ecpg والخروج.

-?
--help

عرض المساعدة حول وسائط سطر أوامر ecpg، والخروج.

ملاحظات

عند ترجمة ملفات الكود C المعالجة مسبقًا، يحتاج المترجم إلى القدرة على العثور على ملفات رأس ECPG في دليل تضمين PostgreSQL. لذلك، قد تحتاج إلى استخدام الخيار -I عند استدعاء المترجم (على سبيل المثال، -I/usr/local/pgsql/include).

يجب ربط البرامج التي تستخدم كود C مع SQL مدمج بمكتبة libecpg، على سبيل المثال باستخدام خيارات الرابط -L/usr/local/pgsql/lib -lecpg.

يمكن العثور على قيمة أي من هذين الدليلين المناسبين للتثبيت باستخدام pg_config(1).

أمثلة

إذا كان لديك ملف مصدر C SQL مدمج باسم prog1.pgc، يمكنك إنشاء برنامج قابل للتنفيذ باستخدام التسلسل التالي من الأوامر:

ecpg prog1.pgc
cc -I/usr/local/pgsql/include -c prog1.c
cc -o prog1 prog1.o -L/usr/local/pgsql/lib -lecpg
