Event__ExecFlow(3pm)

الحزمة: perl-event-execflow

التراخيص: PerlArtistic

Event::ExecFlow(3) وثائق مساهمة من مستخدمي Perl Event::ExecFlow(3)

الاسم

Event::ExecFlow - واجهة برمجة تطبيقات عالية المستوى للتحكم في تدفق التنفيذ المعتمد على الأحداث.

ملاحظة

هذا الإصدار لا يحتوي على أي وثائق تقريبًا حتى الآن. إذا كنت مهتمًا بالتفاصيل، يرجى الاتصال بالمؤلف.

ملخص

يوفر Event::ExecFlow واجهة برمجة تطبيقات عالية المستوى لتعريف تدفقات التحكم المعقدة مع التنفيذ غير المتزامن للبرامج الخارجية.

ملخص

use Event::ExecFlow;
my $job = Event::ExecFlow::Job::Group->new (
  jobs => [
    Event::ExecFlow::Job::Command->new (
      name            => "transcode",
      title           => "تحويل قرص DVD إلى OGG",
      command         => "transcode -i /dev/dvd ...",
      fetch_output    => 1,
      progress_max    => 4711, # عدد الإطارات
      progress_parser => sub {
        my ($job, $buffer) = @_;
        $job->set_progress_cnt($1) if $buffer =~ /\[\d+-(\d+)\]/;
        #-- أو ببساطة اكتب هذا:
        #--   progress_parser => qr/\[\d+-(\d+)\]/,
      },
    ),
    Event::ExecFlow::Job::Code->new (
      name          => "checks",
      title         => "إجراء بعض الفحوصات",
      depends_on    => [ "transcode" ],
      code          => sub {
        my ($job) = @_;
        my $transcode = $job->get_group->get_job_by_name("transcode");
        if ( $transcode->get_output !~ /.../ ) {
          $job->set_error_message("فشل فحص XY");
        }
        #-- يمكن القيام بذلك بسهولة أكبر كـ post_callback تم إضافته إلى
        #-- الوظيفة "transcode" أعلاه، ولكنه مع ذلك مثال جيد
        #-- لنوع الوظيفة "Code" ويظهر كيف يمكن للوظائف
        #-- أن تتداخل مع بعضها البعض.
      },
    ),
    Event::ExecFlow::Job::Command->new (
      title         => "دمج ملف OGG",
      depends_on    => [ "checks" ],
      command       => "ogmmerge ...",
      no_progress   => 1,
    ),
  ],
);
#-- هذا يرث من Event::ExecFlow::Frontend
my $frontend = Video::DVDRip::GUI::ExecFlow->new(...);
$frontend->start_job($job);

الوصف

يقدم Event::ExecFlow واجهة برمجة تطبيقات عالية المستوى لتعريف المهام، والتي تنفذ بشكل أساسي أوامر خارجية، وتحلل مخرجاتها للحصول على معلومات التقدم أو الحالة الأخرى، وتشغل إجراءات عند اكتمال الأمر وما إلى ذلك. يمكن ربط هذه المهام معًا بشكل متكرر لإنجاز مهام معقدة تتكون من العديد من المهام.

بالإضافة إلى ذلك، يحدد واجهة برمجة تطبيقات قابلة للتوسيع للتواصل مع تطبيق الواجهة الأمامية، والذي قد يتم كتابته باستخدام Gtk2 أو Tk أو Qt أو يكون برنامجًا بسيطًا من وحدة تحكم نصية.

في حالة Gtk2، يتم شحن عنصر واجهة مستخدم مخصص لعرض خطة مهام Event::ExecFlow، بما في ذلك تحديثات التقدم، مع حزمة Gtk2::Ex::FormFactory.

المتطلبات

يتطلب Event::ExecFlow وحدات Perl التالية:

AnyEvent           >= 0.04
Locale::TextDomain
Test::More
