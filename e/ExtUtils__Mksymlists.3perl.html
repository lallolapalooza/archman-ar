ExtUtils::Mksymlists(3perl) دليل مبرمجي Perl ExtUtils::Mksymlists(3perl)

الاسم

ExtUtils::Mksymlists - كتابة ملفات خيارات الرابط (linker options files) للتمديدات الديناميكية

الملخص

use ExtUtils::Mksymlists;
Mksymlists(  NAME     => $name ,
             DL_VARS  => [ $var1, $var2, $var3 ],
             DL_FUNCS => { $pkg1 => [ $func1, $func2 ],
                           $pkg2 => [ $func3 ] });

الوصف

"ExtUtils::Mksymlists" ينتج ملفات تستخدمها الرابط (linker) تحت بعض أنظمة التشغيل أثناء إنشاء مكتبات مشتركة للتمديدات الديناميكية. عادةً ما يتم استدعاؤه من Makefile تم إنشاؤه بواسطة MakeMaker عند بناء التمديد. يتم إنشاء ملف خيارات الرابط عن طريق استدعاء الدالة "Mksymlists"، والتي يتم تصديرها افتراضيًا من "ExtUtils::Mksymlists". تأخذ وسيطًا واحدًا، وهو قائمة من أزواج المفتاح-القيمة، حيث يتم التعرف على المفاتيح التالية:

DLBASE
يحدد هذا البند الاسم الذي يعرف به الرابط التمديد، والذي قد يختلف عن اسم التمديد نفسه (على سبيل المثال، يضيف بعض الروابط حرف '_' إلى اسم التمديد). إذا لم يتم تحديده، يتم اشتقاقه من سمة NAME. يتم استخدامه حاليًا فقط بواسطة OS2 و Win32.
DL_FUNCS
هذا مطابق لسمة DL_FUNCS المتاحة عبر MakeMaker، والتي تؤخذ منها عادةً. قيمتها هي مرجع إلى مصفوفة ترابطية (associative array)، حيث يكون كل مفتاح هو اسم حزمة، وكل قيمة هي مرجع إلى مصفوفة بأسماء دوال يجب تصديرها بواسطة التمديد. على سبيل المثال، يمكن للمرء أن يقول "DL_FUNCS => { Homer::Iliad => [ qw(trojans greeks) ], Homer::Odyssey => [ qw(travellers family suitors) ] }". يجب أن تكون أسماء الدوال متطابقة مع تلك الموجودة في كود XSUB؛ "Mksymlists" سيقوم بتعديل الأسماء المكتوبة في ملف خيارات الرابط لتتناسب مع التغييرات التي أجراها xsubpp. بالإضافة إلى ذلك، إذا لم تبدأ أي من الدوال في قائمة بالسلسلة boot_، فستقوم "Mksymlists" بإضافة دالة تهيئة (bootstrap function) لتلك الحزمة، تمامًا كما تفعل xsubpp. (إذا كانت دالة boot_<pkg> موجودة في القائمة، فسيتم تمريرها دون تغيير.) إذا لم يتم تحديد DL_FUNCS، فسيتم تعيينها افتراضيًا إلى دالة التهيئة للتمديد المحدد في NAME.
DL_VARS
هذا مطابق لسمة DL_VARS المتاحة عبر MakeMaker، ومثل DL_FUNCS، يتم تحديده عادةً عبر MakeMaker. قيمته هي مرجع إلى مصفوفة بأسماء متغيرات يجب تصديرها بواسطة التمديد.
FILE
يمكن استخدام هذا المفتاح لتحديد اسم ملف خيارات الرابط (باستثناء الامتداد الخاص بنظام التشغيل)، إذا لم ترغب لسبب ما في استخدام القيمة الافتراضية، وهي آخر كلمة في سمة NAME (على سبيل المثال، لـ "Tk::Canvas"، يكون FILE افتراضيًا "Canvas").
FUNCLIST
يوفر هذا وسيلة بديلة لتحديد أسماء الدوال التي سيتم تصديرها من التمديد. قيمته هي مرجع إلى مصفوفة بأسماء دوال سيتم تصديرها بواسطة التمديد. يتم تمرير هذه الأسماء دون تغيير إلى ملف خيارات الرابط. تحديد قيمة لسمة FUNCLIST يمنع الإنشاء التلقائي لدالة التهيئة للحزمة. لإنشاء اسم التهيئة لا يزال يتعين عليك تحديد اسم الحزمة في جدول hash الخاص بـ DL_FUNCS: 
Mksymlists(  NAME     => $name ,
             FUNCLIST => [ $func1, $func2 ],
             DL_FUNCS => { $pkg => [] } );
IMPORTS
تستخدم هذه السمة لتحديد الأسماء التي سيتم استيرادها إلى التمديد. يتم استخدامها حاليًا فقط بواسطة OS/2 و Win32.
NAME
يعطي هذا اسم التمديد (على سبيل المثال "Tk::Canvas") الذي سيتم إنتاج ملف خيارات الرابط له.

عند استدعاء "Mksymlists"، يجب دائمًا تحديد سمة NAME. في معظم الحالات، هذا كل ما هو ضروري. في حالة التمديدات غير العادية، ومع ذلك، يمكن استخدام السمات الأخرى لتوفير معلومات إضافية للرابط.
