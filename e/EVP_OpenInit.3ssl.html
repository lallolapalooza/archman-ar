EVP_OpenInit(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

EVP_OPENINIT(3ssl) OpenSSL EVP_OPENINIT(3ssl)

الاسم

EVP_OpenInit, EVP_OpenUpdate, EVP_OpenFinal - فك تشفير غلاف EVP

الملخص

#include <openssl/evp.h>
int EVP_OpenInit(EVP_CIPHER_CTX *ctx, EVP_CIPHER *type, unsigned char *ek,
                 int ekl, unsigned char *iv, EVP_PKEY *priv);
int EVP_OpenUpdate(EVP_CIPHER_CTX *ctx, unsigned char *out,
                   int *outl, unsigned char *in, int inl);
int EVP_OpenFinal(EVP_CIPHER_CTX *ctx, unsigned char *out, int *outl);

الوصف

تُعد روتينات غلاف EVP واجهة عالية المستوى لفك تشفير الغلاف. فهي تقوم بفك تشفير مفتاح متماثل مشفر بمفتاح عام ثم تقوم بفك تشفير البيانات باستخدامها.

يقوم EVP_OpenInit() بتهيئة سياق التشفير ctx لفك التشفير باستخدام المشفر type. يقوم بفك تشفير المفتاح المتماثل المشفر بطول ekl بايت المقدم في المعلمة ek باستخدام المفتاح الخاص priv. يتم توفير IV في المعلمة iv.

EVP_OpenUpdate() و EVP_OpenFinal() لهما نفس خصائص روتينات EVP_DecryptUpdate() و EVP_DecryptFinal() تمامًا، كما هو موضح في صفحة دليل EVP_EncryptInit(3).

ملاحظات

من الممكن استدعاء EVP_OpenInit() مرتين بنفس الطريقة التي يتم بها استدعاء EVP_DecryptInit(). يجب أن يحتوي الاستدعاء الأول على priv مضبوطًا على NULL (وبعد تعيين أي معلمات تشفير) يجب استدعاؤه مرة أخرى مع تعيين type على NULL.

إذا كان المشفر المقدم في المعلمة type مشفرًا متغير الطول، فسيتم تعيين طول المفتاح إلى قيمة طول المفتاح المسترد. إذا كان المشفر مشفرًا ثابت الطول، فيجب أن يتطابق طول المفتاح المسترد مع طول المشفر الثابت.

قيم الإرجاع

يعيد EVP_OpenInit() القيمة 0 عند حدوث خطأ أو قيمة عدد صحيح غير صفرية (في الواقع حجم المفتاح السري المسترد) عند النجاح.

يعيد EVP_OpenUpdate() القيمة 1 للنجاح أو 0 للفشل.

يعيد EVP_OpenFinal() القيمة 0 إذا فشل فك التشفير أو 1 للنجاح.
