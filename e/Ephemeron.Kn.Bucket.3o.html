الوحدة Bucket

النوع ('k, 'd) t

الدلو هو "قائمة" قابلة للتغيير من الـ ephemerons.

القيمة make : unit -> ('k, 'd) t

إنشاء دلو جديد.

القيمة add : ('k, 'd) t -> 'k array -> 'd -> unit

إضافة ephemeron إلى الدلو.

القيمة remove : ('k, 'd) t -> 'k array -> unit

remove b k تزيل من b الـ ephemeron المضاف حديثًا بمفاتيح k، أو لا تفعل شيئًا إذا لم يكن هناك مثل هذا الـ ephemeron.

القيمة find : ('k, 'd) t -> 'k array -> 'd option

تُرجع بيانات الـ ephemeron المضاف حديثًا بالمفاتيح المعطاة، أو None إذا لم يكن هناك مثل هذا الـ ephemeron.

القيمة length : ('k, 'd) t -> int

تُرجع حدًا أعلى لطول الدلو.

القيمة clear : ('k, 'd) t -> unit

إزالة جميع الـ ephemerons من الدلو.
