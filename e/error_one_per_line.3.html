error(3) دليل الوظائف المكتبية error(3)

الاسم

error, error_at_line, error_message_count, error_one_per_line, error_print_progname - وظائف تقارير الأخطاء في glibc

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <error.h>
void error(int status, int errnum, const char *format, ...);
void error_at_line(int status, int errnum, const char *file,
                   unsigned int line, const char *format, ...);
extern unsigned int error_message_count;
extern int error_one_per_line;
extern typeof(void (void))  *error_print_progname;

الوصف

error() هي وظيفة عامة للإبلاغ عن الأخطاء. تقوم بمسح stdout، ثم تطبع إلى stderr اسم البرنامج، ونقطتين ومسافة، والرسالة المحددة بواسطة سلسلة تنسيق format بأسلوب printf(3)، وإذا كان errnum غير صفري، يتم طباعة نقطتين ومسافة أخرى متبوعة بالسلسلة المقدمة بواسطة strerror(errnum). أي وسائط مطلوبة لـ format يجب أن تتبع format في قائمة الوسائط. يتم إنهاء الإخراج بحرف سطر جديد.

اسم البرنامج الذي تطبعه error() هو قيمة المتغير العام program_invocation_name(3). program_invocation_name له في البداية نفس قيمة argv[0] الخاص بـ main(). يمكن تعديل قيمة هذا المتغير لتغيير خرج error().

إذا كانت status ذات قيمة غير صفرية، فإن error() تستدعي exit(3) لإنهاء البرنامج باستخدام القيمة المعطاة كحالة خروج؛ بخلاف ذلك، تعود بعد طباعة رسالة الخطأ.

وظيفة error_at_line() هي نفسها تمامًا مثل error()، باستثناء إضافة الوسيطين file و line. الإخراج المنتج هو كما هو الحال بالنسبة لـ error()، باستثناء أنه بعد اسم البرنامج يتم كتابة: نقطتين، قيمة file، نقطتين، وقيمة line. قد تكون القيم المعالج المسبق __LINE__ و __FILE__ مفيدة عند استدعاء error_at_line()، ولكن يمكن أيضًا استخدام قيم أخرى. على سبيل المثال، يمكن أن تشير هذه الوسائط إلى موقع في ملف إدخال.

إذا تم تعيين المتغير العام error_one_per_line على قيمة غير صفرية، فإن سلسلة من استدعاءات error_at_line() بنفس قيم file و line ستؤدي إلى طباعة رسالة واحدة فقط (الأولى).

يقوم المتغير العام error_message_count بعد عدد الرسائل التي تم إخراجها بواسطة error() و error_at_line().

إذا تم تعيين المتغير العام error_print_progname على عنوان وظيفة (أي، ليس NULL)، فسيتم استدعاء هذه الوظيفة بدلاً من إضافة اسم البرنامج والنقطتين إلى بداية الرسالة. يجب أن تقوم الوظيفة بطباعة سلسلة مناسبة إلى stderr.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، راجع attributes(7).

الواجهة السمة القيمة
error () السلامة الخيطية MT-Safe locale
error_at_line () السلامة الخيطية MT-Unsafe race: error_at_line/error_one_per_line locale

يتم الوصول إلى المتغير الداخلي error_one_per_line (دون أي شكل من أشكال المزامنة، ولكن نظرًا لأنه int مستخدم مرة واحدة، فيجب أن يكون آمنًا بدرجة كافية)، وإذا تم تعيين error_one_per_line على قيمة غير صفرية، يتم الوصول إلى المتغيرات الثابتة الداخلية (غير المعروضة للمستخدمين) المستخدمة لتخزين آخر اسم ملف ورقم سطر مطبوعين وتعديلها بدون مزامنة؛ التحديث ليس ذريًا ويحدث قبل تعطيل الإلغاء، لذلك لا يمكن مقاطعته إلا بعد تعديل أحد المتغيرين. بعد ذلك، error_at_line() تشبه إلى حد كبير error().
