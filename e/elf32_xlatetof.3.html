elf32_xlatetof(3)

الحزمة: libelf

التراخيص: GPL-2.0-or-later OR LGPL-3.0-or-later

ELF32_XLATETOM(3) دليل مبرمج Libelf ELF32_XLATETOM(3)

الاسم

elf32_xlatetom, elf64_xlatetom - ترجمة بيانات ELF 32 بت أو 64 بت من تمثيل الملف إلى تمثيل الذاكرة
elf32_xlatetof, elf64_xlatetof - ترجمة بيانات ELF 32 بت أو 64 بت من تمثيل الذاكرة إلى تمثيل الملف

الملخص

#include <libelf.h>
int elf32_xlatetom(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf64_xlatetom(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf32_xlatetof(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);
int elf64_xlatetof(Elf_Data *dst, const Elf_Data *src, unsigned int encoding);

الوصف

ترجمة بيانات ELF من تمثيل الملف إلى تمثيل الذاكرة أو العكس. يمكن أن تختلف تمثيلات الملف والذاكرة لبيانات ELF فيما يتعلق بالترتيب البايتي. تأتي البيانات في تمثيل الملف عادةً من elf_rawdata بينما تأتي البيانات في تمثيل الذاكرة عادةً من elf_getdata. عندما لا يكون هناك فرق بين تمثيلات الملف والذاكرة، تقوم هذه الوظائف ببساطة بنسخ بيانات ELF من src إلى dst. وإلا، سيتم تبديل الترميز بين ELFDATA2LSB (الخطين المكملين بالترتيب البايتي الصغير) و ELFDATA2MSB (الخطين المكملين بالترتيب البايتي الكبير). يتم تحديد ترميز ملف ELF في العضو Elf32_Ehdr أو Elf64_Ehdr e_ident[EI_DATA]. لمعرفة ترميز الذاكرة لبرنامج، يمكنك استخدام #include <endian.h> والتحقق مما إذا كان BYTE_ORDER == LITTLE_ENDIAN (المقابل لـ ELFDATA2LSB) أو BYTE_ORDER == BIG_ENDIAN (المقابل لـ ELFDATA2MSB).

المعاملات

dst
الوجهة التي سيتم فيها تخزين البيانات المترجمة. يجب أن يكون d_size لـ dst على الأقل بحجم d_size لـ src.
src
بيانات المصدر. بالنسبة لوظائف xlatetom، يجب أن تكون بيانات المصدر في تمثيل الملف. بالنسبة لوظائف xlatetof، يجب أن تكون بيانات المصدر في تمثيل الذاكرة.
encoding
يحدد ترميزًا. يمكن أن يكون إما ELFDATA2LSB (الخطين المكملين بالترتيب البايتي الصغير) أو ELFDATA2MSB (الخطين المكملين بالترتيب البايتي الكبير). بالنسبة لوظائف xlatetom، يحدد هذا ترميز src. بالنسبة لوظائف xlatetof، يحدد هذا ترميز dst.

قيمة الإرجاع

عند النجاح، قم بإرجاع dst، والتي ستحتوي على البيانات المترجمة. إذا لم يكن هناك فرق بين تمثيلات الملف والذاكرة، فسيحتوي dst على نسخة من بيانات المصدر. سيتم تعيين d_type و d_size لـ dst لتكون مثل تلك الخاصة بـ src.


في حالة حدوث خطأ، قم بإرجاع NULL وتعيين رمز خطأ libelf.
