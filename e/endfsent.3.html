getfsent(3) دليل دوال المكتبة getfsent(3)

الاسم

getfsent, getfsspec, getfsfile, setfsent, endfsent - التعامل مع إدخالات fstab

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <fstab.h>
int setfsent(void);
struct fstab *getfsent(void);
void endfsent(void);
struct fstab *getfsfile(const char *mount_point);
struct fstab *getfsspec(const char *special_file);

الوصف

تقوم هذه الدوال بالقراءة من الملف /etc/fstab. يتم تعريف struct fstab بواسطة:


struct fstab {
    char       *fs_spec;       /* اسم جهاز الكتلة */
    char       *fs_file;       /* نقطة التحميل */
    char       *fs_vfstype;    /* نوع نظام الملفات */
    char       *fs_mntops;     /* خيارات التحميل */
    const char *fs_type;       /* خيار rw/rq/ro/sw/xx */
    int         fs_freq;       /* تكرار التفريغ، بالأيام */
    int         fs_passno;     /* رقم المرور في التفريغ المتوازي */
};

هنا يحتوي الحقل fs_type (في نظام *BSD) على إحدى السلاسل الخمس "rw"، "rq"، "ro"، "sw"، "xx" (للقراءة والكتابة، للقراءة والكتابة مع حصة، للقراءة فقط، تبديل، تجاهل).

تقوم الدالة setfsent() بفتح الملف عند الحاجة وتعيين المؤشر على السطر الأول.

تقوم الدالة getfsent() بتحليل السطر التالي من الملف. (بعد فتحه عند الحاجة.)

تقوم الدالة endfsent() بإغلاق الملف عند الحاجة.

تبحث الدالة getfsspec() في الملف من البداية وتعيد أول إدخال تم العثور عليه يتطابق فيه حقل fs_spec مع الوسيط special_file.

تبحث الدالة getfsfile() في الملف من البداية وتعيد أول إدخال تم العثور عليه يتطابق فيه حقل fs_file مع الوسيط mount_point.

قيمة الإرجاع

عند النجاح، تعيد الدوال getfsent() و getfsfile() و getfsspec() مؤشرًا إلى struct fstab، بينما تعيد setfsent() القيمة 1. عند الفشل أو نهاية الملف، تعيد هذه الدوال NULL و 0 على التوالي.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
endfsent (), setfsent () أمان الخيط MT-Unsafe race:fsent
getfsent (), getfsspec (), getfsfile () أمان الخيط MT-Unsafe race:fsent locale

الإصدارات

توجد هذه الدوال في العديد من أنظمة التشغيل، على سبيل المثال، *BSD، SunOS، Digital UNIX، AIX (الذي يحتوي أيضًا على getfstype()). يحتوي HP-UX على دوال بنفس الأسماء، ولكنها تستخدم struct checklist بدلاً من struct fstab، وتعتبر هذه الدوال مهملة، وقد تم استبدالها بـ getmntent(3).

المعايير

لا شيء.

التاريخ

ظهرت الدالة getfsent() في 4.0BSD؛ وظهرت الدوال الأربع الأخرى في 4.3BSD.

ملاحظات

هذه الدوال ليست آمنة للاستخدام مع الخيوط.

نظرًا لأن لينكس يسمح بتحميل جهاز متخصص للكتلة في عدة أماكن، ولأن عدة أجهزة يمكن أن يكون لها نفس نقطة التحميل، حيث يكون الجهاز الأخير الذي له نقطة تحميل معينة هو الأكثر أهمية، بينما تعيد الدالتان getfsfile() و getfsspec() أول ظهور فقط، فإن هاتين الدالتين غير مناسبتين للاستخدام تحت لينكس.
