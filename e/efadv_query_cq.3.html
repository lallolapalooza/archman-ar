EFADV_QUERY_CQ(3) دليل EFA المباشر EFADV_QUERY_CQ(3)

الاسم

efadv_query_cq - الاستعلام عن سمات طابور الإكمال الخاصة بـ EFA

ملخص

#include <infiniband/efadv.h>
int efadv_query_cq(struct ibv_cq *ibvcq, struct efadv_cq_attr *attr,
                   uint32_t inlen);

الوصف

efadv_query_cq() تستعلم عن سمات طابور الإكمال الخاصة بالجهاز.

تتم معالجة التوافق باستخدام حقلي comp_mask و inlen.

struct efadv_cq_attr {
    uint64_t comp_mask;
    uint8_t *buffer;
    uint32_t entry_size;
    uint32_t num_entries;
    uint32_t *doorbell;
};
inlen
إدخال: حجم بنية efadv_cq_attr.
comp_mask
قناع التوافق.
buffer
مخزن طابور الإكمال.
entry_size
حجم كل إدخال في طابور الإكمال.
num_entries
العدد الأقصى للإدخالات في طابور الإكمال.
doorbell
جرس الباب العكسي المستخدم لتحديث الجهاز بالإدخالات التي تم مسحها ضوئيًا وطلب الإشعارات. NULL عندما لا يكون قيد الاستخدام لطابور الإكمال هذا.

قيمة الإرجاع

efadv_query_cq() ترجع 0 عند النجاح، أو قيمة errno عند الفشل (والتي تشير إلى سبب الفشل).

انظر أيضًا

efadv(7)

ملاحظات

•
قناع التوافق (comp_mask) هو حقل إخراج ولا يحتوي حاليًا على أي قيم.
