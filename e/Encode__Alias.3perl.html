Encode::Alias(3perl) دليل مبرمجي بيرل Encode::Alias(3perl)

الاسم

Encode::Alias - تعريفات أسماء مستعارة للترميزات

الملخص

use Encode;
use Encode::Alias;
define_alias( "اسم_جديد" => ترميز);
define_alias( qr/.../ => ترميز);
define_alias( sub { return ترميز if ...; } );

الوصف

يسمح باستخدام اسم_جديد كاسم مستعار لـ ترميز. يمكن أن يكون ترميز إما اسم ترميز أو كائن ترميز (كما هو موضح في Encode).

حاليًا، يمكن تحديد الوسيط الأول للدالة define_alias() بالطرق التالية:

كسلسلة نصية بسيطة.
كتعبير عادي مجمّع qr//، على سبيل المثال:
define_alias( qr/^iso8859-(\d+)$/i => '"iso-8859-$1"' );

في هذه الحالة، إذا لم يكن ترميز مرجعًا، يتم "تقييمه" للسماح باستبدال $1 إلخ. المثال هو طريقة لتسمية الأسماء المستعارة كما تستخدم في خطوط X11 بالأسماء القياسية MIME لأسرة iso-8859-*. لاحظ علامات الاقتباس المزدوجة داخل علامات الاقتباس المفردة.

(أو، ليس عليك القيام بذلك بنفسك لأن هذا المثال معرف مسبقًا)

إذا كنت تستخدم تعبيرًا عاديًا هنا، فيجب عليك استخدام علامات الاقتباس كما هو موضح وإلا فلن يعمل. لاحظ أيضًا أن معالجة التعبيرات العادية صعبة حتى بالنسبة لذوي الخبرة. استخدم هذه الميزة بحذر.

كمرجع شفرة، على سبيل المثال:
define_alias( sub {shift =~ /^iso8859-(\d+)$/i ? "iso-8859-$1" : undef } );

نفس تأثير المثال أعلاه بطريقة مختلفة. يأخذ مرجع الشفرة الاسم المستعار كوسيط ويعيد اسمًا قياسيًا عند النجاح أو undef إذا لم يكن كذلك. لاحظ أن الوسيط الثاني يتم تجاهله إذا تم تقديمه. استخدم هذا بحذر أكبر من إصدار التعبير العادي.

تغييرات في تعريف الأسماء المستعارة بواسطة مرجع الشفرة

ابتداءً من Encode 1.87، لم يعد النموذج القديم

define_alias( sub { return  /^iso8859-(\d+)$/i ? "iso-8859-$1" : undef } );

يعمل.

Encode حتى 1.86 استخدم داخليًا "local $_" لتنفيذ هذا النموذج القديم. لكن فكر في الشفرة التالية؛

use Encode;
$_ = "eeeee" ;
while (/(e)/g) {
  my $utf = decode('aliased-encoding-name', $1);
  print "position:",pos,"\n";
}

قبل Encode 1.86 يفشل هذا بسبب "local $_".

تجاوز الأسماء المستعارة

يمكنك تجاوز الأسماء المستعارة المعرفة مسبقًا ببساطة عن طريق تطبيق define_alias(). يتم تقييم الاسم المستعار الجديد دائمًا أولاً، وعند الضرورة، تقوم define_alias() بمسح ذاكرة التخزين المؤقت الداخلية لجعل التعريف الجديد متاحًا.

# إعادة توجيه SHIFT_JIS إلى صفحة رمز MS/IBM 932، وهي مجموعة شاملة
# من SHIFT_JIS
define_alias( qr/shift.*jis$/i  => '"cp932"' );
define_alias( qr/sjis$/i        => '"cp932"' );

إذا كنت تريد إزالة جميع الأسماء المستعارة المعرفة مسبقًا، يمكنك استخدام

Encode::Alias->undef_aliases;

للقيام بذلك. و

Encode::Alias->init_aliases;

يعيد الإعدادات الافتراضية للمصنع.

لاحظ أن define_alias() لن تكون قادرة على تجاوز الاسم القياسي للترميزات. يتم البحث عن الترميزات أولاً بالاسم القياسي قبل محاولة الأسماء المستعارة المحتملة.
