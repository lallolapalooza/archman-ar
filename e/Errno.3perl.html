Errno.3perl

الحزمة: perl

التراخيص: Artistic-1.0-Perl OR GPL-1.0-or-later

Errno(3perl) دليل مبرمجي بيرل Errno(3perl)

الاسم

Errno - ثوابت خطأ النظام errno

ملخص

use Errno qw(EINTR EIO :POSIX);

الوصف

يقوم "Errno" بتعريف وتصدير بشكل شرطي جميع ثوابت الأخطاء المعرفة في ملف تضمين errno.h الخاص بنظامك. لديها علامة تصدير واحدة، ":POSIX"، والتي ستقوم بتصدير جميع أرقام الأخطاء المعرفة في POSIX.

على نظام ويندوز، يقوم "Errno" أيضًا بتعريف وتصدير بشكل شرطي لجميع ثوابت أخطاء Winsock المعرفة في ملف تضمين WinError.h الخاص بنظامك. يتم تضمين هذه في علامة تصدير ثانية، ":WINSOCK".

يجعل "Errno" أيضًا السحر "%!" بحيث يكون لكل عنصر من "%!" قيمة غير صفرية فقط إذا تم ضبط $! على هذه القيمة. على سبيل المثال:

my $fh;
unless (open($fh, "<", "/fangorn/spouse")) {
    if ($!{ENOENT}) {
        warn "Get a wife!\n";
    } else {
        warn "This path is barred: $!";
    }
}

إذا كان الثابت المحدد "EFOO" غير موجود في النظام، فإن $!{EFOO} يعيد "". يمكنك استخدام "exists $!{EFOO}" للتحقق مما إذا كان الثابت متاحًا في النظام.

يقوم Perl تلقائيًا بتحميل "Errno" في المرة الأولى التي تستخدم فيها "%!"، لذلك لا تحتاج إلى "use" صريح.

محاذير

قد يكون استيراد ثابت معين غير محمول جدًا، لأن الاستيراد سيفشل على المنصات التي لا تحتوي على هذا الثابت. طريقة أكثر قابلية للحمل لضبط $! على قيمة صالحة هي استخدام:

if (exists &Errno::EFOO) {
    $! = &Errno::EFOO;
}
