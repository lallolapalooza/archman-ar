الوصف

هذه الوظائف خاصة بـ glibc.

متجه argz هو مؤشر إلى مخزن مؤقت للأحرف مع طول، انظر argz_add(3). متجه envz هو متجه argz خاص، وهو الذي تكون فيه السلاسل بالشكل "name=value". كل شيء بعد علامة '=' الأولى يعتبر قيمة. إذا لم تكن هناك علامة '=', يتم اعتبار القيمة NULL. (بينما القيمة في حالة وجود علامة '=' في النهاية هي السلسلة الفارغة "".)

هذه الوظائف مخصصة لمعالجة متجهات envz.

envz_add() تضيف السلسلة "name=value" (في حالة أن value ليست NULL) أو "name" (في حالة أن value هي NULL) إلى متجه envz (*envz, *envz_len) وتقوم بتحديث *envz و *envz_len. إذا كان هناك إدخال بنفس الاسم name موجودًا، فسيتم إزالته.

envz_entry() تبحث عن name في متجه envz (envz, envz_len) وتعيد الإدخال إذا تم العثور عليه، أو NULL إذا لم يتم العثور عليه.

envz_get() تبحث عن name في متجه envz (envz, envz_len) وتعيد القيمة إذا تم العثور عليها، أو NULL إذا لم يتم العثور عليها. (لاحظ أن القيمة يمكن أن تكون NULL أيضًا، وذلك عندما يكون هناك إدخال لـ name بدون علامة '='.)

envz_merge() تضيف كل إدخال في envz2 إلى *envz، كما لو كانت باستخدام envz_add(). إذا كان override صحيحًا، فستحل القيم في envz2 محل تلك التي لها نفس الاسم في *envz، وإلا فلن تفعل ذلك.

envz_remove() تزيل الإدخال لـ name من (*envz, *envz_len) إذا كان موجودًا.

envz_strip() تزيل جميع الإدخالات ذات القيمة NULL.

قيمة الإرجاع

جميع وظائف envz التي تقوم بتخصيص الذاكرة لها نوع إرجاع error_t (نوع عدد صحيح)، وتعيد 0 للنجاح، و ENOMEM إذا حدث خطأ في التخصيص.

أمثلة

#include <envz.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[], char *envp[])
{
    char    *str;
    size_t  e_len = 0;
    for (size_t i = 0; envp[i] != NULL; i++)
        e_len += strlen(envp[i]) + 1;
    str = envz_entry(*envp, e_len, "HOME");
    printf("%s\n", str);
    str = envz_get(*envp, e_len, "HOME");
    printf("%s\n", str);
    exit(EXIT_SUCCESS);
}
