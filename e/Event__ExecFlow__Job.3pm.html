Event__ExecFlow__Job(3pm)

الحزمة: perl-event-execflow

التراخيص: PerlArtistic

Event::ExecFlow::Job(3) وثائق مساهمة من المستخدمين بلغة بيرل Event::ExecFlow::Job(3)

الاسم

Event::ExecFlow::Job - فئة أساسية مجردة لجميع فئات الوظائف

الملخص

Event::ExecFlow::Job->new (
  title                => وصف وصفي للوظيفة،
  name                 => اسم داخلي قصير،
  depends_on           => أسماء الوظائف التي تعتمد عليها هذه الوظيفة،
  progress_max         => أقصى قيمة متوقعة للتقدم،
  progress_ips         => نص لعرضه كـ "عنصر في الثانية"،
  no_progress          => الوظيفة ليس لها حالة تقدم على الإطلاق،
  pre_callbacks        => ردود اتصال يتم تنفيذها قبل بدء الوظيفة،
  post_callbacks       => ردود اتصال يتم تنفيذها بعد انتهاء الوظيفة،
  error_callbacks      => ردود اتصال يتم تنفيذها إذا كانت الوظيفة بها أخطاء،
  warning_callbacks    => ردود اتصال يتم تنفيذها إذا كانت الوظيفة بها تحذيرات،
  stash                => تجليد مخصص للبيانات مخزن مع الوظيفة،
);

الوصف

هذه فئة أساسية مجردة وعادة لا تستخدم مباشرة من التطبيق. للبرمجة اليومية، السمات المعرفة في هذه الفئة هي الأكثر أهمية، حيث أنها مشتركة بين جميع الوظائف في إطار عمل Event::ExecFlow.
