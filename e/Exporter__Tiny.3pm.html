Exporter__Tiny(3pm)

الحزمة: perl-exporter-tiny

التراخيص: PerlArtistic, GPL

Exporter::Tiny(3) توثيق Perl المساهم به من المستخدم Exporter::Tiny(3)

الاسم

Exporter::Tiny - مصدر يوفر ميزات Sub::Exporter ولكن مع تبعيات أساسية فقط

الموجز

package MyUtils;
use base "Exporter::Tiny";
our @EXPORT = qw(frobnicate);
sub frobnicate { ... }
1;
package MyScript;
use MyUtils "frobnicate" => { -as => "frob" };
print frob(42);
exit;

الوصف

يدعم Exporter::Tiny العديد من الميزات الخارجية لـ Sub::Exporter، بما في ذلك إعادة تسمية الوظائف المستوردة باستخدام خيارات "-as"، "-prefix" و "-suffix"؛ وجهات صريحة مع خيار "into"؛ ومثبتات بديلة مع خيار "installer". ولكنه مكتوب بحوالي 40٪ فقط من عدد أسطر الكود وبدون تبعيات غير أساسية.

واجهته الداخلية أقرب إلى Exporter.pm، حيث يتم التكوين من خلال متغيرات الحزمة @EXPORT، @EXPORT_OK و %EXPORT_TAGS.

إذا كنت تحاول **كتابة** وحدة ترث من Exporter::Tiny، فانظر إلى:

  • Exporter::Tiny::Manual::QuickStart
  • Exporter::Tiny::Manual::Exporting

إذا كنت تحاول **استخدام** وحدة ترث من Exporter::Tiny، فانظر إلى:

•
Exporter::Tiny::Manual::Importing
