NAME

enscript

convert text files to PostScript, HP-PCL, or RTF

SYNOPSIS

enscript [-123456789] [-`] [-a lines] [-B] [-C] [-d printer] [-e] [-E[rc]] [-f font] [-F name] [-g] [-h] [-i n] [-I n] [-j] [-l lines] [-L n] [-m file] [-n] [-N] [-o file] [-O dir] [-p file] [-P printer] [-q] [-r] [-R] [-s size] [-S n] [-t title] [-T] [-u] [-U n] [-v] [-V] [-w language] [-W] [--] [file ...]

DESCRIPTION

The enscript utility is a text-to-PostScript converter. It can convert text files to PostScript, HP-PCL, or RTF formats. It supports syntax highlighting for many programming languages, page numbering, fancy headers and footers, etc. Enscript is extensible by PostScript code snippets.

The output of enscript can be piped directly to a printer (e.g. `enscript foo.c | lpr').

OPTIONS

The options can be grouped together. For example, to print a file in landscape mode with two columns, you can use -2r.

-1, -2, -3, -4, -5, -6, -7, -8, -9
Print the text in 1, 2, ..., 9 columns. The default is 1 column. The number of columns can also be specified with the -W option.
-`
Print the text in the specified number of columns and rotate the output 90 degrees (landscape mode).
-a lines
Set the number of usable lines per page to lines. The default is 66 lines.
-B
Do not print page numbers.
-C
Print line numbers.
-d printer
Send the output to the specified printer. This option is obsolete, use -P instead.
-e
Highlight the keywords of the source code. This option is useful for printing source code. It recognizes many programming languages.
-E[rc]
Highlight the keywords of the source code and count the lines of code. The optional argument r tells enscript to use the keywords from the specified file. The optional argument c tells enscript to count the lines of code. If the c option is used, enscript will print the number of lines of code at the end of the file.
-f font
Select the default body font. The default font is "Courier10". The font name must be followed by its size in points. For example, to use Times-Roman 10pt font, use -fTimes-Roman10. If the font size is omitted, the default size is 10pt.
-F name
Select the font for the fancy header and footer. The default font is "Helvetica".
-g
Generate dummy PostScript output. This option is useful for testing. It prints a PostScript file that contains only the page size and a message that the dummy page is generated.
-h
Print a fancy header on each page. The header contains the filename, date and time, and the page number.
-i n
Set the vertical line spacing to n. The default value is 1.
-I n
Set the horizontal line spacing to n. The default value is 1.
-j
Join the files. This option is useful when you want to print multiple files as one document.
-l lines
Set the number of lines per page to lines. The default is 66 lines.
-L n
Set the number of columns to n. The default is 1 column.
-m file
Include the specified PostScript file in the output. This option can be used to add custom PostScript code to the output.
-n
Do not print page numbers.
-N
Do not print a fancy header on each page. This is the default behavior.
-o file
Write the PostScript output to the specified file. If this option is not used, the output is sent to the standard output.
-O dir
Specify the directory where enscript should look for its configuration files and other resources. The default is `/usr/share/enscript'.
-p file
Write the PostScript output to the specified file. This option is obsolete, use -o instead.
-P printer
Send the output to the specified printer. This option is equivalent to the PRINTER environment variable.
-q
Quiet mode. Suppress all messages, except for errors.
-r
Rotate the output 90 degrees (landscape mode). This option is equivalent to specifying 2 columns and rotating the output.
-R
Print the text in reverse order (last page first). This option is useful when printing multiple copies of a document.
-s size
Set the default font size to size points. The default is 10 points. This option can be used in combination with the -f option.
-S n
Set the paper size to n. The default is 0 (A4 size). See the `PAPERSIZE' environment variable for more information.
-t title
Set the title of the document. The title is printed in the page header. The default title is the name of the file being processed.
-T
Enable tab expansion. Tabs are expanded to spaces. The default tab stop is 8.
-u
Print the text in reverse order (last page first). This option is equivalent to -R.
-U n
Set the tab stop to n spaces. The default is 8.
-v
Print the version of enscript and exit.
-V
Verbose mode. Print messages about the progress of enscript.
-w language
Set the output language to language. Possible values are `ps' (PostScript, default), `hplj' (HP-PCL), and `rtf' (RTF).
-W
Use the specified number of columns for the output. This option is equivalent to specifying the number of columns with -1 to -9. For example, -W2 is equivalent to -2.
--
End of options. All subsequent arguments are treated as filenames.

CONFIGURATION FILES

Enscript uses configuration files to set default options. The configuration files are searched in the following order: `/etc/enscript/enscript.cfg', `/etc/enscript/enscriptsite.cfg', `~/.enscriptrc'.

The configuration files use the following syntax: `option=value'.

For example, to set the default font to Times-Roman 10pt, you can add the following line to your `~/.enscriptrc' file:

fTimes-Roman10

See `enscript(5)' for a complete list of configuration options.

FANCY HEADERS

You can customize the fancy header and footer by creating a file with the desired PostScript code and including it using the -m option. The file should contain a PostScript procedure named `psheader'.

For example, to add a custom header to your document, create a file named `myheader.ps' with the following content:

/psheader {
  /Courier selectfont
  10 setfontsize
  0 792 moveto  % Top left corner of the page
  (My Custom Header) show
} bind def

Then, use the following command to print your file:

enscript -mmyheader.ps foo.txt

SPECIAL ESCAPES

Enscript supports special escape sequences that can be used within the input files to control the output. These escapes start with the sequence `^@'. The following escapes are supported:

bnum
bold text with factor num
color colorname
set text color
font fontname
select current font
hnum
set image height to num
inum
italic text with factor num
ps code
include raw PostScript code to the output
rnum
underline text with factor num
shade gray
highlight regions of text by changing the text background color
sxnum
scale image in x direction with factor num
synum
scale image in y direction with factor num

As a default, all dimensions are given in lines (vertical) and characters (horizontal). You can also specify other units by appending an unit specifier after number. Possible unit specifiers and the corresponding units are:

c
centimeters
i
inches
l
lines or characters (default)
p
PostScript points

For example to print an image one inch high, you can specify height by following options: h1i (1 inch), h2.54c (2.54 cm), h72p (72 points).

font
select current font. The syntax of the escape is:

^@font{fontname[:encoding]}

where fontname is a standard font specification. Special font specification default can be used to select the default body font (enscript's default or the one specified by the command line option -f, --font).

The optional argument encoding specifies the encoding that should be used for the new font. Currently the encoding can only be the enscript's global input encoding or ps.

ps
include raw PostScript code to the output. The syntax of the escape is:

^@ps{code}

shade
highlight regions of text by changing the text background color. Escape's syntax is:

^@shade{gray}

where gray is the new text background gray value. The default value is 1.0 (white) which disables highlighting.

PAGE DEVICE OPTIONS

Page device is a PostScript level 2 feature that offers an uniform interface to control printer's output device. Enscript protects all page device options inside an if block so they have no effect in level 1 interpreters. Although all level 2 interpreters support page device, they do not have to support all page device options. For example some printers can print in duplex mode and some can not. Refer to the documentation of your printer for supported options.

Here are some usable page device options which can be selected with the -D, --setpagedevice option. For a complete listing, see PostScript Language Reference Manual: section 4.11 Device Setup.

Collate boolean
how output is organized when printing multiple copies
Duplex boolean
duplex (two side) printing
ManualFeed boolean
manual feed paper tray
OutputFaceUp boolean
print output `face up' or `face down'
Tumble boolean
how opposite sides are positioned in duplex printing

PRINTING EXAMPLES

Following printing examples assume that enscript uses the default configuration. If default actions have been changed from the configuration files, some examples will behave differently.

enscript foo.txt
Print file foo.txt to the default printer.
enscript -Possu foo.txt
Print file foo.txt to printer ossu.
enscript -pfoo.ps foo.txt
Print file foo.txt, but leave PostScript output to file foo.ps.
enscript -2 foo.txt
Print file foo.txt to two columns.
enscript -2r foo.txt
Print file to two columns and rotate output 90 degrees (landscape).
enscript -DDuplex:true foo.txt
Print file in duplex (two side) mode (printer dependent).
enscript -G2rE -U2 foo.c
My default code printing command: gaudy header, two columns, landscape, code highlighting, 2-up printing.
enscript -E --color -whtml --toc -pfoo.html *.h *.c
A nice HTML report of your project's C source files.

ENVIRONMENT VARIABLES

The environment variable ENSCRIPT can be used to pass default options for enscript. For example, to select the default body font to be Times-Roman 7pt, set the following value to the ENSCRIPT environment variable:

-fTimes-Roman7

The value of the ENSCRIPT variable is processed before the command line options, so command line options can be used to overwrite these defaults.

Variable ENSCRIPT_LIBRARY specifies the enscript's library directory. It can be used to overwrite the build-in default `/usr/share/enscript'.

RETURN VALUE

Enscript returns value 1 to the shell if any errors were encountered or 0 otherwise. If the option --extended-return-values was specified, the return value is constructed from the following flags:

0
no errors or warnings
2
some lines were truncated or wrapped
4
some characters were missing from the used fonts
8
some characters were unprintable
