الاسم

etwdump - توفير واجهة لقراءة تتبع الأحداث لنظام Windows (ETW)

ملخص

etwdump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --capture ] [ --fifo=<path to file or pipe> ] [ --iue=<Should undecidable events be included> ] [ --etlfile=<etl file> ] [ --params=<filter parameters> ]

الوصف

etwdump هي أداة extcap توفر الوصول إلى ملف سجل تتبع الأحداث أو جلسة تتبع أحداث مباشرة. يتم استخدامها فقط لعرض تتبع الأحداث على نظام Windows التي تتضمن رسالة نصية قابلة للقراءة وبروتوكولات مختلفة (مثل MBIM وحزم IP).

خيارات

--help

طباعة وسائط البرنامج.

--version

طباعة إصدار البرنامج.

--extcap-interfaces

قائمة الواجهات المتاحة.

--extcap-interface=<interface>

استخدام الواجهات المحددة.

--extcap-dlts

قائمة DLTs للواجهة المحددة.

--extcap-config

قائمة خيارات التكوين للواجهة المحددة.

--capture

بدء التقاط من الواجهة المحددة وحفظها في المكان المحدد بواسطة --fifo.

--fifo=<path to file or pipe>

حفظ الحزمة الملتقطة في ملف أو إرسالها عبر pipe.

--iue=<Should undecidable events be included>

اختر ما إذا كان سيتم تضمين الحدث الذي لا يمكن تحديده.

--etlfile=<Etl file>

تحديد ملف etl لعرضه في Wireshark.

--params=<filter parameters>

موفرو الإدخال، عوامل تصفية الكلمات الرئيسية والمستويات لملف etl وجلسة البث المباشر.

أمثلة

لرؤية وسائط البرنامج:

etwdump --help

لرؤية إصدار البرنامج:

etwdump --version

لرؤية الواجهات:

etwdump --extcap-interfaces

مثال للمخرجات

interface {value=etwdump}{display=ETW reader}

لرؤية DLTs للواجهة:

etwdump --extcap-interface=etwdump --extcap-dlts

مثال للمخرجات

dlt {number=1}{name=etwdump}{display=DLT_ETW}

لرؤية خيارات تكوين الواجهة:

etwdump --extcap-interface=etwdump --extcap-config

مثال للمخرجات

arg {number=0}{call=--etlfile}{display=etl file}{type=fileselect}{tooltip=Select etl file to display in Wireshark}{group=Capture}
arg {number=1}{call=--params}{display=filter parameters}{type=string}{tooltip=Input providers, keyword and level filters for the etl file and live session}{group=Capture}
arg {number=2}{call=--iue}{display=Should undecidable events be included}{type=boolflag}{default=false}{tooltip=Choose if the undecidable event is included}{group=Capture}

للالتقاط:

etwdump --extcap-interface etwdump --fifo=/tmp/etw.pcapng --capture --params "--p=Microsoft-Windows-Wmbclass-Opn --p=Microsoft-Windows-wmbclass --k=0xff --l=4"
etwdump --extcap-interface etwdump --fifo=/tmp/etw.pcapng --capture --params "--p=Microsoft-Windows-Wmbclass-Opn --p=Microsoft-Windows-NDIS-PacketCapture"

ملاحظة

لإيقاف الالتقاط اضغط CTRL+C/kill/إنهاء التطبيق.
