النوع ('k1, 'k2, 'd) t

الحاوية هي "قائمة" قابلة للتغيير من الأثيريات.

القيمة make : unit -> ('k1, 'k2, 'd) t

إنشاء حاوية جديدة.

القيمة add : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> 'd -> unit

إضافة أثيرية إلى الحاوية.

القيمة remove : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> unit

remove b k1 k2 تزيل من b الأثيرية الأكثر إضافة مؤخرًا بالمفاتيح k1 و k2 ، أو لا تفعل شيئًا إذا لم تكن هناك أثيرية كهذه.

القيمة find : ('k1, 'k2, 'd) t -> 'k1 -> 'k2 -> 'd option

تُرجع بيانات الأثيرية الأكثر إضافة مؤخرًا بالمفاتيح المعطاة، أو None إذا لم تكن هناك أثيرية كهذه.

القيمة length : ('k1, 'k2, 'd) t -> int

تُرجع حدًا أعلى لطول الحاوية.

القيمة clear : ('k1, 'k2, 'd) t -> unit

إزالة جميع الأثيريات من الحاوية.
