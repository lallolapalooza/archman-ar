YAML__PP__Schema__Tie__IxHash(3pm)

الحزمة: perl-yaml-pp

التراخيص: PerlArtistic, GPL

YAML::PP::Schema::Tie::IxHash(3) توثيق Perl المساهم به من قبل المستخدم YAML::PP::Schema::Tie::IxHash(3)

الاسم

YAML::PP::Schema::Tie::IxHash - (مهمل) مخطط لتسلسل الهاشات المرتبة

الملخص

use YAML::PP;
use Tie::IxHash;
my $yp = YAML::PP->new( schema => [qw/ + Tie::IxHash /] );
tie(my %ordered, 'Tie::IxHash');
%ordered = (
    U => 2,
    B => 52,
);
my $yaml = $yp->dump_string(\%ordered);
# الإخراج:
---
U: 2
B: 52

الوصف

هذا مهمل. راجع الخيار الجديد "preserve" في YAML::PP.

يسمح لك هذا المخطط بتفريغ الهاشات المرتبة المرتبطة بـ Tie::IxHash.

هذا الكود جديد وتجريبي إلى حد ما.

لم يتم تنفيذه بعد للتحميل، لذلك عليك ربط الهاشات بنفسك في الوقت الحالي.

أمثلة:

الترتيب
# كود
tie(my %order, 'Tie::IxHash');

الترتيب المبارك
# كود
tie(my %order, 'Tie::IxHash');
%order = (
    U => 2,
    B => 52,
    c => 64,
    19 => 84,
    Disco => 2000,
    Year => 2525,
    days_on_earth => 20_000,
);
bless \%order, 'Order';
# YAML
--- !perl/hash:Order
U: 2
B: 52
c: 64
19: 84
Disco: 2000
Year: 2525
days_on_earth: 20000
