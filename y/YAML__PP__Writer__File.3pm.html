YAML__PP__Writer__File(3pm)

الحزمة: perl-yaml-pp

التراخيص: PerlArtistic, GPL

YAML::PP::Writer::File(3) وثائق مساهمة المستخدم من Perl YAML::PP::Writer::File(3)

الاسم

YAML::PP::Writer::File - كتابة مخرجات YAML إلى ملف أو مقبض ملف

الملخص

my $writer = YAML::PP::Writer::File->new(output => $file);

الوصف

يقوم YAML::PP::Emitter بإرسال مخرجاته إلى الكاتب.

يمكنك استخدام كاتبك الخاص. إذا كنت تريد إرسال مخرجات YAML إلى مكان آخر. انظر t/44.writer.t كمثال.

الطرق

new
my $writer = YAML::PP::Writer::File->new(output => $file);
my $writer = YAML::PP::Writer::File->new(output => $filehandle);

المُنشئ.

write
$writer->write('- ');
init
$writer->init;

تهيئة

finish
$writer->finish;

يتم استدعاؤه عند انتهاء الإخراج. إذا كان الوسيط اسم ملف، فسيتم إغلاق مقبض الملف. إذا كان الوسيط مقبض ملف، فيجب على المتصل إغلاقه.

output, set_output
جالب/مُعدّل للإخراج YAML
