YAML__PP__Schema__Merge(3pm)

الحزمة: perl-yaml-pp

التراخيص: PerlArtistic, GPL

YAML::PP::Schema::Merge(3) وثائق مساهمة مستخدم Perl YAML::PP::Schema::Merge(3)

الاسم

YAML::PP::Schema::Merge - تمكين مفاتيح دمج YAML للتعيينات

الملخص

use YAML::PP;
my $yp = YAML::PP->new( schema => [qw/ + Merge /] );
my $yaml = <<'EOM';
---
- &CENTER { x: 1, y: 2 }
- &LEFT { x: 0, y: 2 }
- &BIG { r: 10 }
- &SMALL { r: 1 }
# All the following maps are equal:
- # Explicit keys
  x: 1
  y: 2
  r: 10
  label: center/big
- # Merge one map
  << : *CENTER
  r: 10
  label: center/big
- # Merge multiple maps
  << : [ *CENTER, *BIG ]
  label: center/big
- # Override
  << : [ *BIG, *LEFT, *SMALL ]
  x: 1
  label: center/big
EOM
my $data = $yp->load_string($yaml);
# $data->[4] == $data->[5] == $data->[6] == $data->[7]

الوصف

انظر https://yaml.org/type/merge.html للمواصفات.

اقتباس:

"حدد تعيينًا واحدًا أو أكثر ليتم دمجها مع التعيين الحالي.

يُستخدم مفتاح الدمج "<<" للإشارة إلى أنه يجب إدراج جميع مفاتيح الخرائط المحددة في الخريطة الحالية. إذا كانت القيمة المرتبطة بالمفتاح عقدة تعيين واحدة، يتم إدراج كل زوج من المفاتيح / القيم الخاصة بها في التعيين الحالي، ما لم يكن المفتاح موجودًا بالفعل فيه. إذا كانت القيمة المرتبطة بمفتاح الدمج تسلسلًا، فيتوقع أن يحتوي هذا التسلسل على عقد تعيين ويتم دمج كل عقدة من هذه العقد بدورها وفقًا لترتيبها في التسلسل. المفاتيح في عقد التعيين في وقت مبكر من التسلسل تتجاوز المفاتيح المحددة في عقد التعيين اللاحقة.

تنفيذ هذا بطريقة عامة ليس بالأمر السهل، لأننا يجب أيضًا التعامل مع المفاتيح المكررة، وYAML::PP يتيح لك كتابة معالجك الخاص لمعالجة التعيينات.

لذلك، فإن الواجهة الداخلية لهذا ليست مستقرة في هذه المرحلة.

لاحظ أنه إذا قمت بتمكين هذا المخطط، فسيتم اعتبار القيمة العددية البسيطة `<<` خاصة في أي مكان في المستند الخاص بك، لذا إذا كنت تريد حرفيًا `<<` ، فعليك وضعه بين علامتي اقتباس.

لاحظ أن الدمج الذي تم إجراؤه ليس "دمجًا عميقًا". يتم دمج المفاتيح على المستوى العلوي فقط.
