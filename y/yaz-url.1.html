yaz-url(1)

الحزمة: yaz

التراخيص: LicenseRef-yaz

YAZ-URL(1) أوامر YAZ-URL(1)

الاسم

yaz-url - أداة جلب عناوين URL الخاصة بـ YAZ

الملخص

yaz-url [-H name:value] [-m method] [-O fname] [-p fname] [-R num] [-u user/password] [-v] [-x proxy] [url...]

الوصف

yaz-url هي أداة لجلب محتوى الويب. إنها محدودة للغاية في وظائفها مقارنة ببرامج مثل curl و wget.

يجب أن تسبق الخيارات عنوان URL المعطى في سطر الأوامر، حتى يسري مفعولها.

يتم كتابة محتوى HTTP الذي تم جلبه إلى الإخراج القياسي، ما لم يتم تحديد الخيار -O.

الخيارات

-H name:value

يحدد محتوى رأس HTTP بالاسم والقيمة. يمكن تقديم هذا الخيار عدة مرات (لأسماء مختلفة، بالطبع).

-m method

يحدد طريقة HTTP المستخدمة لعنوان URL التالي. الافتراضي هو الطريقة "GET". ومع ذلك، فإن الخيار -p يضبطها على "POST".

-O fname

يحدد اسم ملف الإخراج لمحتوى HTTP.

-p fname

يحدد ملفًا ليتم إرساله في عنوان URL التالي.

-R num

يحدد الحد الأقصى لعدد عمليات إعادة التوجيه HTTP التي سيتم اتباعها. قيمة الصفر تعطل متابعة عمليات إعادة توجيه HTTP.

-u user/password

يحدد اسم مستخدم وكلمة مرور لاستخدامهما في المصادقة الأساسية لـ HTTP في جلب عنوان URL التالي. يجب فصل اسم المستخدم وكلمة المرور بشرطة مائلة (لذلك لا يمكن تحديد اسم مستخدم يحتوي على شرطة مائلة).

-v

يجعل yaz-url يطبع كل طلب / استجابة HTTP إلى الإخراج القياسي.

-x proxy

يحدد وكيلًا لاستخدامه في جلب عنوان URL.
