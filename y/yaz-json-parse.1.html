YAZ-JSON-PARSE(1) أوامر YAZ-JSON-PARSE(1)

الاسم

yaz-json-parse - محلل JSON الخاص بـ YAZ

الملخص

yaz-json-parse [-p]

الوصف

yaz-json-parse هو أداة توضح واجهة برمجة تطبيقات JSON الخاصة بـ YAZ. (yaz/json.h).

يحاول البرنامج تحليل JSON من الإدخال القياسي (stdin). سيعيد رمز الخروج 1 إذا فشل التحليل وسيتم طباعة رسالة خطأ التحليل إلى الخطأ القياسي (stderr). يعيد البرنامج رمز الخروج 0 إذا نجح التحليل، ولا يعيد أي مخرجات إلا إذا تم تحديد -p (انظر أدناه).

الخيارات

-p

يجعل محلل JSON يعرض سلسلة نتيجة JSON إلى المخرجات القياسية، إذا كان التحليل من stdin ناجحًا. إذا تم تحديد -p مرتين، فإن المخرجات ستكون مخرجات متعددة الأسطر مع المسافات البادئة (طباعة جميلة).
