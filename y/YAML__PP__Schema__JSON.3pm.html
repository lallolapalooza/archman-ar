YAML__PP__Schema__JSON(3pm)

الحزمة: perl-yaml-pp

التراخيص: PerlArtistic, GPL

YAML::PP::Schema::JSON(3) وثائق Perl المساهمة من المستخدم YAML::PP::Schema::JSON(3)

الاسم

YAML::PP::Schema::JSON - مخطط JSON لـ YAML 1.2

الملخص

my $yp = YAML::PP->new( schema => ['JSON'] );
my $yp = YAML::PP->new( schema => [qw/ JSON empty=str /] );
my $yp = YAML::PP->new( schema => [qw/ JSON empty=null /] );

الوصف

مع هذا المخطط، ستعمل معالجة القيم العادية كما هو الحال في JSON. كل ما يتطابق مع قيمة خاصة سيتم تحميله على هذا النحو، وسيقوم بتحميل القيم العادية الأخرى كسلاسل نصية.

لاحظ أن هذا يختلف عن مخطط JSON الرسمي لـ YAML 1.2، حيث يجب وضع علامات اقتباس لجميع السلاسل النصية.

هنا يمكنك رؤية جميع المخططات والأمثلة التي تنفذها YAML::PP: https://perlpunk.github.io/YAML-PP-p5/schemas.html

المخطط الرسمي: https://yaml.org/spec/1.2/spec.html#id2803231

التكوين

مخطط JSON الرسمي لـ YAML 1.2 يتطلب وضع علامات اقتباس لجميع السلاسل النصية. YAML::PP حاليًا لا يتطلب ذلك (قد يفعل ذلك اختياريًا في المستقبل).

هذا يعني أنه لا يُسمح بعقد فارغة في المخطط الرسمي. مثال:

---
key:

السلوك الافتراضي لـ YAML::PP::Schema::JSON هو إرجاع سلسلة فارغة، لذلك سيكون مكافئًا لـ:

---
key: ''

يمكنك تكوينه لحل هذا كـ "undef":

my $yp = YAML::PP->new( schema => [qw/ JSON empty=null /] );

بهذه الطريقة يكون مكافئًا لـ:

---
key: null

الافتراضي هو:

my $yp = YAML::PP->new( schema => [qw/ JSON empty=str /] );
