fribidi_shape_mirroring(3) دليل المبرمج fribidi_shape_mirroring(3)

الاسم

fribidi_shape_mirroring - إجراء تشكيل المرآة

الخلاصة

#include <../fribidi/lib/fribidi.h>

void fribidi_shape_mirroring
(
const FriBidiLevel *embedding_levels,
const FriBidiStrIndex len,
FriBidiChar *str
);

المعاملات

const FriBidiLevel *embedding_levels
قائمة مستويات التضمين المدخلة، كما تم إرجاعها بواسطة fribidi_get_par_embedding_levels.
const FriBidiStrIndex len
طول السلسلة المدخلة.
FriBidiChar *str
السلسلة المراد تشكيلها.

الوصف

تستبدل هذه الوظيفة أحرف المرآة في تضمينات اليمين إلى اليسار في السلسلة بما يعادلها المرآتي كما تم إرجاعه بواسطة fribidi_get_mirror_char().

تطبق هذه الوظيفة القاعدة L4 من خوارزمية Unicode ثنائية الاتجاه المتوفرة على http://www.unicode.org/reports/tr9/#L4.
