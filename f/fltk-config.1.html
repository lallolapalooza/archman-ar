fltk-config(1)

الحزمة: fltk

التراخيص: LGPL-2.0-only WITH FLTK-exception

fltk-config(1) دليل الأوامر العامة fltk-config(1)

الاسم

fltk-config - برنامج نصي للحصول على معلومات حول الإصدار المثبت من fltk.

الملخص

fltk-config [ --prefix [=DIR] ] [ --exec-prefix [=DIR] ] [ --version ] [ --api-version ] [ --use-gl ] [ --use-images ] [ --use-glut ] [ --cc ] [ --cxx ] [ --cflags ] [ --cxxflags ] [ --ldflags ] [ --ldstaticflags ] [ --libs ] [ -Dname[=value] ] [ -g ] [ --compile program.cxx ]

الوصف

fltk-config هو برنامج نصي مساعد يمكن استخدامه للحصول على معلومات حول الإصدار الحالي لـ FLTK المثبت على النظام، وما هي خيارات المترجم ورابط الربط التي يجب استخدامها عند بناء التطبيقات المستندة إلى FLTK، ولبناء تطبيقات FLTK بسيطة.

الخيارات التالية مدعومة:

--api-version

يعرض رقم إصدار FLTK API الحالي، على سبيل المثال "1.1".
--cc
--cxx

يعرض مترجم C/C++ الذي تم استخدامه لترجمة FLTK.
--cflags
--cxxflags

يعرض خيارات مترجم C/C++ التي يجب استخدامها عند ترجمة ملفات المصدر التي تستخدم FLTK.
--compile program.cxx

يقوم بترجمة ملف المصدر program.cxx إلى program. هذا الخيار يعني "--post program".
-g

يقوم بتمكين معلومات التصحيح عند الترجمة باستخدام الخيار --compile.
--ldflags

يعرض خيارات رابط الربط التي يجب استخدامها عند ربط تطبيق FLTK.
--ldstaticflags

يعرض خيارات رابط الربط التي يجب استخدامها عند ربط تطبيق FLTK بمكتبات FLTK الثابتة.
--libs

يعرض المسار الكامل لملفات مكتبة FLTK، لاستخدامها في فحص الاعتماديات.
--use-gl

يمكّن دعم OpenGL.
--use-glut

يمكّن دعم GLUT.
--use-images

يمكّن دعم ملفات الصور.
--version

يعرض رقم إصدار FLTK الحالي، على سبيل المثال "1.1.0".
