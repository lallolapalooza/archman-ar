flatpak-config(1)

الحزمة: flatpak

التراخيص: LGPL-2.1-or-later

FLATPAK CONFIG(1) flatpak config FLATPAK CONFIG(1)

الاسم

flatpak-config - إدارة الإعدادات

ملخص

flatpak config [خيار...]

flatpak config [خيار...] --set المفتاح القيمة

flatpak config [خيار...] --unset|--get المفتاح

الوصف

يعرض أمر flatpak config أو يعدل إعدادات تثبيت flatpak. المفاتيح المدعومة هي:

languages

اللغات التي يتم تضمينها عند تثبيت ملحقات Locale. القيمة عبارة عن قائمة مفصولة بفواصل منقوطة رموز لغات مكونة من حرفين، أو إحدى القيم الخاصة * أو *all*. إذا تم إلغاء تعيين هذا المفتاح، فسيقوم flatpak افتراضيًا بتضمين مفتاح extra-languages والموقع الحالي.

extra-languages

يُستخدم هذا المفتاح عندما لا يتم تعيين اللغات، وهو يحدد ملحقات locale إضافية فوق اللغات المكونة للنظام. القيمة عبارة عن قائمة مفصولة بفواصل منقوطة لمعرفات locale (اللغة، locale اختياري، رموز ترميز اختياري، معدّل اختياري) كما هو موثق بواسطة setlocale(3) (على سبيل المثال، en;en_DK;zh_HK.big5hkscs;uz_UZ.utf8@cyrillic).

لتكوين المستودعات الفردية، انظر flatpak-remote-modify(1). لتكوين التطبيقات الفردية، انظر flatpak-override(1).

خيارات

يتم فهم الخيارات التالية:

-h, --help

عرض خيارات المساعدة والخروج.

--list

طباعة جميع المفاتيح وقيمها.

--set

تعيين المفتاح KEY إلى القيمة VALUE.

--unset

إلغاء تعيين المفتاح KEY.

--get

طباعة قيمة المفتاح KEY.

-u, --user

تكوين التثبيت لكل مستخدم.

--system

تكوين التثبيت على مستوى النظام.

--installation=NAME

تكوين التثبيت على مستوى النظام المحدد بالاسم NAME من بين التثبيتات المعرفة في /etc/flatpak/installations.d/. استخدام --installation=default يعادل استخدام --system.

-v, --verbose

طباعة معلومات التصحيح أثناء معالجة الأمر.

--ostree-verbose

طباعة معلومات تصحيح OSTree أثناء معالجة الأمر.

أمثلة

$ flatpak config --set languages "sv;en;fi"
