blurdetect

\n

يحدد ضبابية الإطارات دون تغيير الإطارات المدخلة.

\n

بناءً على Marziliano، Pina، وآخرون. \"مقياس ضبابية إدراكي بدون مرجع.\" يسمح بالاختصار القائم على الكتل.

\n

يقبل الفلتر الخيارات التالية:

\n
\n
low
\n
\n
high
\n
تعيين القيم الدنيا والقصوى للعتبات المستخدمة بواسطة خوارزمية Canny للعتبات.\n

تختار العتبة القصوى وحدات البكسل ذات الحواف \"القوية\"،\n والتي يتم ربطها بعد ذلك بالاتصال الثماني مع وحدات البكسل ذات الحواف\n \"الضعيفة\" التي تحددها العتبة الدنيا.

\n

يجب اختيار قيم العتبات low و high في النطاق [0,1]، ويجب أن تكون low أقل من أو تساوي\n high.

\n

القيمة الافتراضية لـ low هي\n "20/255"، والقيمة الافتراضية لـ\n high هي "50/255".\n

\n
\n
radius
\n
تحديد نصف القطر للبحث حول بكسل الحافة عن القيم القصوى المحلية.\n

\n
block_width
\n

\n
block_height
\n
تحديد الضبابية للكتل بارتفاع block_height. إذا تم تعيينها على\n أي قيمة أقل من 1، فلن يتم استخدام الكتل وسيتم معالجة الصورة بأكملها\n كوحدة واحدة بغض النظر عن block_width.\n
\n

bm3d

\n

تنقية الإطارات باستخدام خوارزمية Block-Matching 3D.

\n

يقبل الفلتر الخيارات التالية.

\n
\n
sigma
\n
تعيين قوة التنقية. القيمة الافتراضية هي 1. النطاق المسموح به هو من 0 إلى\n 999.9. خوارزمية التنقية حساسة جدًا لـ sigma، لذا اضبطها\n وفقًا للمصدر.\n
\n
block
\n
تعيين حجم الرقعة المحلية. هذا يحدد الأبعاد في 2D.\n
\n
bstep
\n
تعيين خطوة الانزلاق لمعالجة الكتل. القيمة الافتراضية هي 4. النطاق المسموح به\n هو من 1 إلى 64. القيم الأصغر تسمح بمعالجة المزيد من الكتل المرجعية وتكون أبطأ.\n
\n
group
\n
تعيين الحد الأقصى لعدد الكتل المتشابهة للبعد الثالث. القيمة الافتراضية هي\n 1. عند التعيين على 1، لا يتم إجراء مطابقة الكتل. تسمح القيم الأكبر بمزيد من\n الكتل في مجموعة واحدة. النطاق المسموح به هو من 1 إلى 256.\n
\n
range
\n
تعيين نصف قطر مطابقة كتل البحث. الافتراضي هو 9. النطاق المسموح به هو من\n 1 إلى INT32_MAX.\n
\n
mstep
\n
تعيين الخطوة بين موقعي بحث ل مطابقة الكتل. الافتراضي هو 1.\n النطاق المسموح به هو من 1 إلى 64. الأصغر أبطأ.\n
\n
thmse
\n
تعيين عتبة متوسط مربع الخطأ لمطابقة الكتل. النطاق الصالح هو 0 إلى\n INT32_MAX.\n
\n
hdthr
\n
تعيين معامل العتبة للعتبة الصلبة في مجال التحويل ثلاثي الأبعاد.\n القيم الأكبر تؤدي إلى تصفية عتبة صلبة أقوى في مجال التردد.\n
\n
estim
\n
تعيين وضع تقدير التصفية. يمكن أن يكون\n "basic" أو\n "final". الافتراضي هو\n "basic".\n
\n
ref
\n
إذا تم تمكينه، سيستخدم الفلتر الدفق الثاني لمطابقة الكتل. الافتراضي هو\n معطل لـ "basic" لقيمة\n estim، ودائما ممكّن إذا كانت قيمة estim هي\n "final".\n
\n
planes
\n
تعيين المستويات للتصفية. الافتراضي هو كل المتاحة باستثناء ألفا.\n
\n
\n

أمثلة

\n
    \n
  • تصفية أساسية باستخدام bm3d:\n 
    bm3d=sigma=3:block=4:bstep=2:group=1:estim=basic\n
    \n
    • \n
  • نفس ما سبق، ولكن يتم تصفية الإضاءة فقط:\n 
    bm3d=sigma=3:block=4:bstep=2:group=1:estim=basic:planes=1\n
    \n
    • \n
  • نفس ما سبق، ولكن مع وضعي التقدير:\n 
    split[a][b],[a]bm3d=sigma=3:block=4:bstep=2:group=1:estim=basic[a],[b][a]bm3d=sigma=3:block=4:bstep=2:group=16:estim=final:ref=1\n
    \n
    • \n
  • نفس ما سبق، ولكن مع تصفية مسبقة باستخدام فلتر nlmeans بدلاً من ذلك:\n 
    split[a][b],[a]nlmeans=s=3:r=7:p=3[a],[b][a]bm3d=sigma=3:block=4:bstep=2:group=16:estim=final:ref=1\n
    \n

multiply

Multiply first video stream pixels values with second video stream pixels values.

The filter accepts the following options:

scale
Set the scale applied to second video stream. By default is 1. Allowed range is from 0 to 9.
offset
Set the offset applied to second video stream. By default is 0.5. Allowed range is from -1 to 1.
planes
Specify planes from input video stream that will be processed. By default all planes are processed.

Commands

This filter supports same commands as options.

negate

Negate (invert) the input video.

It accepts the following option:

components
Set components to negate.

Available values for components are:

y
u
v
a
r
g
b
negate_alpha
With value 1, it negates the alpha component, if present. Default value is 0.

Commands

This filter supports same commands as options.

nlmeans

Denoise frames using Non-Local Means algorithm.

Each pixel is adjusted by looking for other pixels with similar contexts. This context similarity is defined by comparing their surrounding patches of size pxp. Patches are searched in an area of rxr around the pixel.

Note that the research area defines centers for patches, which means some patches will be made of pixels outside that research area.

The filter accepts the following options.

s
Set denoising strength. Default is 1.0. Must be in range [1.0, 30.0].
p
Set patch size. Default is 7. Must be odd number in range [0, 99].
pc
Same as p but for chroma planes.

The default value is 0 and means automatic.

r
Set research size. Default is 15. Must be odd number in range [0, 99].
rc
Same as r but for chroma planes.

The default value is 0 and means automatic.

nnedi

Deinterlace video using neural network edge directed interpolation.

This filter accepts the following options:

weights
Mandatory option, without binary file filter can not work. Currently file can be found here: https://github.com/dubhater/vapoursynth-nnedi3/blob/master/src/nnedi3_weights.bin
deint
Set which frames to deinterlace, by default it is "all". Can be "all" or "interlaced".
field
Set mode of operation.

Can be one of the following:

af
Use frame flags, both fields.
a
Use frame flags, single field.
t
Use top field only.
b
Use bottom field only.
tf
Use both fields, top first.
bf
Use both fields, bottom first.
planes
Set which planes to process, by default filter process all frames.
nsize
Set size of local neighborhood around each pixel, used by the predictor neural network.

Can be one of the following:

s8x6
s16x6
s32x6
s48x6
s8x4
s16x4
s32x4
nns
Set the number of neurons in predictor neural network. Can be one of the following:
n16
n32
n64
n128
n256
qual
Controls the number of different neural network predictions that are blended together to compute the final output value. Can be "fast", default or "slow".
etype
Set which set of weights to use in the predictor. Can be one of the following:
a, abs
weights trained to minimize absolute error
s, mse
weights trained to minimize squared error
pscrn
Controls whether or not the prescreener neural network is used to decide which pixels should be processed by the predictor neural network and which can be handled by simple cubic interpolation. The prescreener is trained to know whether cubic interpolation will be sufficient for a pixel or whether it should be predicted by the predictor nn. The computational complexity of the prescreener nn is much less than that of the predictor nn. Since most pixels can be handled by cubic interpolation, using the prescreener generally results in much faster processing. The prescreener is pretty accurate, so the difference between using it and not using it is almost always unnoticeable.

Can be one of the following:

none
original
new
new2
new3

Default is "new".

Commands

This filter supports same commands as options, excluding weights option.

noformat

Force libavfilter not to use any of the specified pixel formats for the input to the next filter.

It accepts the following parameters:

pix_fmts
A '|'-separated list of pixel format names, such as pix_fmts=yuv420p|monow|rgb24".

Examples

  • Force libavfilter to use a format different from yuv420p for the input to the vflip filter: 
    noformat=pix_fmts=yuv420p,vflip
  • Convert the input video to any of the formats not contained in the list: 
    noformat=yuv420p|yuv444p|yuv410p

overlay

Draw one video overlay on top of the main input video.

It accepts the following options:

x
Set the expression for the x-coordinate of the overlay. Default value is "0".
y
Set the expression for the y-coordinate of the overlay. Default value is "0".
w
Set the expression for the width of the overlay. Default value is "overlay_w".
h
Set the expression for the height of the overlay. Default value is "overlay_h".
shortest
Set to 1 to stop encoding when the shortest input ends, default is 0.
eof_action
Set the action to take when EOF is reached on an input. Default is "repeat". Possible values are "repeat", "endall".
format
Set the pixel format for the overlay. Default value is "yuv420p".
repeatlast
Set the number of frames to repeat for the overlay when EOF is reached. Default value is "0".

The expressions for x, y, w, h may contain the following values: main_w, main_h, overlay_w, overlay_h, x, y, a (aspect ratio).

Also, they may contain variables specific for the overlay:

frame_num
The number of the current frame.
x
The current x coordinate of the overlay.
y
The current y coordinate of the overlay.

Example

Place the overlay image on the center of the main video:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=(main_w-overlay_w)/2:(main_h-overlay_h)/2" -f null -

Place the overlay image on the bottom right corner of the main video:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=main_w-overlay_w-10:main_h-overlay_h-10" -f null -

Place the overlay image on the top right corner of the main video:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=x=W-w-10:y=10" -f null -

Fade the overlay image from 0 to 1 in 100 frames:

ffmpeg -i main.mpg -i overlay.png -lavfi "color=c=black:s=WxH:d=10,format=rgba,fade=in:st=0:d=100,format=rgba [logo]; [logo] overlay=x=10:y=10" -f null -

Set the overlay width to half the width of the main video:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=x=(main_w-overlay_w)/2:y=(main_h-overlay_h)/2:w=main_w/2" -f null -

Set the overlay size to 100x100 pixels:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=w=100:h=100:x=(main_w-100)/2:y=(main_h-100)/2" -f null -

Place the overlay on the center of the screen, and scale it to the width of the main video:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=x=(main_w-overlay_w)/2:y=(main_h-overlay_h)/2:w=main_w" -f null -

Enable temporal dampering of overlay position. The overlay will move slowly to the specified position.

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=x='if(eq(n\,0)\,x\,min(x+3\,(main_w-overlay_w)/2))':y='if(eq(n\,0)\,y\,min(y+3\,(main_h-overlay_h)/2))'" -f null -

Averaging the overlay position over the last 5 frames:

ffmpeg -i main.mpg -i overlay.png -lavfi "overlay=x=avg(x*4+{X})+({X})/5:y=avg(y*4+{Y})+({Y})/5" -f null -

Use overlay as a black background and overlay it with the main video:

ffmpeg -i main.mpg -i black.png -lavfi "[0:v]pad=iw*2:ih*2[base]; [1:v]setpts=PTS-STARTPTS[fg]; [base][fg]overlay=x=iw/2:y=ih/2" -f null -

Show multiple overlays:

ffmpeg -i main.mpg -i overlay1.png -i overlay2.png -lavfi "overlay=x=10:y=10, overlay=x=W-w-10:y=10" -f null -

In case the overlay has an alpha channel, it will be used for blending.

If the overlay file contains multiple frames, only the first one is used.

If the overlay file has a variable frame rate, it will be treated as a constant frame rate of 25 fps.

If the overlay contains an alpha channel, then the alpha channel will be used for blending.

If the overlay has an alpha channel, then the alpha channel will be used for blending. If the overlay does not have an alpha channel, then the filter will try to use the color key.

If you want to specify the colorkey, you can use the colorkey filter.

The filter automatically detects if the overlay image has an alpha channel and uses it for blending. If the overlay image does not have an alpha channel, then the filter attempts to use the colorkey.

If you want to specify the colorkey, you can use the colorkey filter.

Commands

This filter supports same commands as options.

palettegen

Generate an optimal color palette.

This filter is useful for reducing the number of colors in a video, for example, for creating animated GIFs.

It accepts the following options:

stats_mode
Select the mode for gathering statistics. Default is "full". Possible values are "full", "diff", "full_fast", "diff_fast".
max_colors
Set the maximum number of colors in the palette. Default is 256.

Example

Generate a palette from a video and save it to a file:

ffmpeg -i input.mp4 -vf palettegen palette.png

Use the generated palette to create an animated GIF:

ffmpeg -i input.mp4 -i palette.png -lavfi "[0][1]paletteuse" output.gif

This filter outputs a single frame which is the palette.

paletteuse

Use a generated palette to replace the original colors.

This filter is useful for reducing the number of colors in a video, for example, for creating animated GIFs.

It accepts the following options:

stats_mode
Select the mode for gathering statistics. Default is "diff". Possible values are "full", "diff", "full_fast", "diff_fast".
dither
Set the dithering algorithm. Default is "sierra2". Possible values are "bayer", "sierra2", "sierra2_4a", "floyd_steinberg".
diff_mode
Set the difference mode. Default is "rectangle". Possible values are "rectangle", "average".

Example

Generate a palette from a video and save it to a file:

ffmpeg -i input.mp4 -vf palettegen palette.png

Use the generated palette to create an animated GIF:

ffmpeg -i input.mp4 -i palette.png -lavfi "[0][1]paletteuse" output.gif

pad

Pad the input video, resizing the image, while keeping the aspect ratio.

It accepts the following options:

w
Set the width of the output video. Default value is "iw*2".
h
Set the height of the output video. Default value is "ih*2".
x
Set the expression for the x-coordinate of the input video. Default value is "(ow-iw)/2".
y
Set the expression for the y-coordinate of the input video. Default value is "(oh-ih)/2".
color
Set the color of the padding. Default value is "black".
aspect_ratio
Set the aspect ratio of the output video. Default value is "sample_aspect_ratio".

The expressions for w, h, x, y may contain the following values: iw, ih, ow, oh, x, y.
