FCEUX(6) دليل الألعاب FCEUX(6)

الاسم

fceux - محاكي لجهاز نينتندو / فاميكوم الأصلي (8 بت).

الملخص

fceux [خيارات] "اسم الملف"

الوصف

FCEUX هو محاكي لجهاز نينتندو إنترتينمنت سيستم (NES) الأصلي (8 بت). يحتوي على محرك قوي لتصيير الألوان قابل للتخصيص بالكامل، إلى جانب دعم ممتاز للصوت وأجهزة التحكم، ويدعم أيضًا تسجيل وتشغيل الأفلام.

خيارات

خيارات متنوعة

--no-config {0|1}
استخدام ملف الإعدادات الافتراضي وعدم الحفظ فيه، عند التمكين.
-g {0|1}, --gamegenie {0|1}
تمكين أو تعطيل محاكاة Game Genie.
--nogui {0|1}
تمكين أو تعطيل واجهة المستخدم الرسومية GTK.
--loadlua FILE
تحميل برنامج Lua النصي من اسم الملف FILE.

خيارات المحاكاة

--pal {0|1}
تمكين أو تعطيل وضع PAL.

خيارات الإدخال

-i DEV, --inputcfg DEV
ضبط جهاز الإدخال DEV عند بدء التشغيل. الأجهزة: gamepad powerpad hypershot quizking
--input{1|2} DEV
تعيين جهاز الإدخال المراد محاكاته للإدخال 1 أو 2. الأجهزة: gamepad zapper powerpad.0 powerpad.1 arkanoid
--input{3|4} DEV
تعيين جهاز توسعة Famicom المراد محاكاته للإدخال 3 أو 4. الأجهزة: quizking hypershot mahjong toprider ftrainer familykeyboard oekakids arkanoid shadow bworld 4player
--inputdisplay {0|1}
تمكين أو تعطيل عرض المدخلات.
--fourscore {0|1}
تمكين أو تعطيل محاكاة FourScore.

خيارات الرسومات

--newppu {0|1}
تمكين أو تعطيل نواة PPU الجديدة. (تحذير: قد يؤدي إلى كسر حالات الحفظ)
--frameskip NUM
تحديد عدد الإطارات NUM لتخطيها لكل إطار محاكى.
--clipsides {0|1}
تمكين أو تعطيل قص الأعمدة الثمانية اليسرى واليمنى من ناتج الفيديو.
--slstart SCANLINE
تحديد خط المسح الأول المراد عرضه.
--slend SCANLINE
تحديد خط المسح الأخير المراد عرضه.
--nospritelim {0|1}
عند التعيين إلى 0، يعطل هذا الحد الطبيعي لـ 8 صور في كل خط مسح. عند التعيين إلى 1، يمكّن هذا الحد الطبيعي لـ 8 صور في كل خط مسح. ملاحظة: نعم، هذا الخيار "متعمد".
-x XRES, --xres XRES
تحديد الدقة الأفقية لوضع ملء الشاشة.
-y YRES, --yres YRES
تحديد الدقة الرأسية لوضع ملء الشاشة.
--doublebuf {0|1}
تمكين أو تعطيل التخزين المؤقت المزدوج.
--autoscale {0|1}
تمكين أو تعطيل التحجيم التلقائي في وضع ملء الشاشة.
--keepratio {0|1}
الحفاظ على نسبة العرض إلى الارتفاع الأصلية لجهاز NES عند التحجيم التلقائي.
--{x|y}scale VAL
ضرب العرض/الارتفاع بـ VAL. (أرقام حقيقية > 0 مع OpenGL، وإلا أعداد صحيحة > 0).
--{x|y}stretch {0|1}
تمديد لملء السطح على المحور x/y (OpenGL فقط).
-b {8|16|24|32}, --bpp {8|16|24|32}
تحديد البتات لكل بكسل.
--opengl {0|1}
تمكين أو تعطيل دعم OpenGL.
--openglip {0|1}
تمكين أو تعطيل الاستيفاء الخطي لـ OpenGL.
-f {0|1}, --fullscreen {0|1}
تمكين أو تعطيل وضع ملء الشاشة.
--noframe {0|1}
إخفاء شريط العنوان وزخارف النافذة.
--special {1-4}
استخدام مرشحات تحجيم الفيديو الخاصة. (1 = hq2x 2 = Scale2x 3 = NTSC 2x 4 = hq3x 5 = Scale3x)
-p FILE, --palette FILE
استخدام اللوحة المخصصة في FILE.
--ntsccolor {0|1}
تمكين أو تعطيل ألوان NES NTSC.
--tint VAL
ضبط درجة لون NTSC.
--hue VAL
ضبط درجة تدرج اللون NTSC.

خيارات الصوت

-s {0|1}, --sound {0|1}
تمكين أو تعطيل الصوت.
--soundrate RATE
تحديد معدل عينة تشغيل الصوت (0 == إيقاف؟).
--soundq {0|1|2}
تحديد جودة الصوت. (0 = منخفض 1 = عالي 2 = عالي جدًا)
--soundbufsize MS
تحديد حجم المخزن المؤقت للصوت بالمللي ثانية MS.
--volume {0-256}
يحدد مستوى صوت الصوت بالقيمة المعطاة، حيث 256 هو أقصى مستوى صوت.
--trianglevol {0-256}
يحدد مستوى صوت الموجة المثلثية بالقيمة المعطاة، حيث 256 هو أقصى مستوى صوت.
--square1vol {0-256}
يحدد مستوى صوت الموجة المربعة 1 بالقيمة المعطاة، حيث 256 هو أقصى مستوى صوت.
--square2vol {0-256}
يحدد مستوى صوت الموجة المربعة 2 بالقيمة المعطاة، حيث 256 هو أقصى مستوى صوت.
--noisevol {0-256}
يحدد مستوى صوت مولد الضوضاء بالقيمة المعطاة، حيث 256 هو أقصى مستوى صوت.
--lowpass {0|1}
تمكين أو تعطيل الترشيح المنخفض التمرير للصوت.
--soundrecord FILE
تسجيل الصوت في الملف FILE.

خيارات الأفلام

--playmov FILE
تشغيل فيلم FCM/FM2 مسجل من اسم الملف FILE.
--pauseframe FRAME
إيقاف تشغيل الفيلم مؤقتًا عند الإطار FRAME.
--moviemsg {0|1}
تمكين أو تعطيل رسائل الفيلم.
--fcmconvert FILE
تحويل ملف الفيلم fcm FILE إلى fm2.
--ripsubs FILE
تحويل ترجمات الفيلم إلى srt.
--subtitles {0|1}
تمكين أو تعطيل عرض الترجمات.
