NAME

footclient — control a running foot instance

SYNOPSIS

footclient [-p pid] [-s socket] [command]

DESCRIPTION

The footclient program is used to control a running foot(1) instance. It connects to the instance via a UNIX domain socket and sends it a command.

The path to the socket is determined by the FOOT_INSTANCE environment variable, or defaults to ${XDG_RUNTIME_DIR}/foot/instance_name, where instance_name is the first argument to foot(1) when it was started, or default if no such argument was given.

If the FOOT_INSTANCE environment variable is set, footclient will attempt to connect to the socket specified by that variable.

If the FOOT_INSTANCE environment variable is not set, and the -s option is not specified, footclient will look for the socket in the default location. If foot(1) was started with an instance name (e.g. foot -n myinstance), the socket will be located at ${XDG_RUNTIME_DIR}/foot/myinstance. Otherwise, it will be located at ${XDG_RUNTIME_DIR}/foot/default.

The following commands are supported:

new-window
Open a new foot(1) window. Any arguments after new-window will be passed to foot(1) as the command to execute in the new window.
search
Search for text in the foot(1) window. Any arguments after search will be used as the search query. The search is case-insensitive and uses sub-string matching.
prompt [args...]
Prompt the user for input. Any arguments after prompt are passed as arguments to the underlying prompt command (see --prompt-command option in foot(1)).
color-scheme [name]
Switch to the specified color scheme. If no name is provided, cycle through the configured color schemes. The color schemes are defined in the [colors] and [colors2] sections of the configuration file.
quit
Close the foot(1) window.
pid
Print the PID of the foot(1) process to standard output.

OPTIONS

-p, --pid pid
Connect to the foot(1) instance with the specified process ID. This option overrides -s and the FOOT_INSTANCE environment variable.
-s, --socket socket
Connect to the specified socket path. This option overrides the FOOT_INSTANCE environment variable.
-h, --help
Print a help message and exit.
-v, --version
Print version information and exit.

EXIT STATUS

The exit status is 0 if the command was sent successfully, and non-zero otherwise.

TERMINFO

This program relies on the foot(1) terminal capabilities database.

ENVIRONMENT

The following environment variables affect footclient:

FOOT_INSTANCE
Specifies the path to the UNIX domain socket used to communicate with foot(1).
XDG_RUNTIME_DIR
Used to determine the default socket path if FOOT_INSTANCE is not set and -s is not specified.

Signals

The following signals have special meaning in footclient:

  • SIGUSR1: switch to color theme 1 (i.e. use the [colors] section).
  • SIGUSR2: switch to color theme 2 (i.e. use the [colors2] section).

When sending SIGUSR1/SIGUSR2 to a footclient instance, the theme is changed in that instance only. This is different from when you send SIGUSR1/SIGUSR2 to the server process, where all instances change the theme.

Note: for obvious reasons, this is not supported when footclient is started with --no-wait.

الاسم

footclient — تحكم في مثيل foot قيد التشغيل

ملخص

footclient [-p pid] [-s socket] [command]

الوصف

يُستخدم برنامج footclient للتحكم في مثيل foot(1) قيد التشغيل. يتصل بالمثيل عبر مقبس مجال UNIX ويرسل إليه أمرًا.

يتم تحديد مسار المقبس بواسطة متغير البيئة FOOT_INSTANCE، أو افتراضيًا ${XDG_RUNTIME_DIR}/foot/instance_name، حيث instance_name هو الوسيط الأول لـ foot(1) عند تشغيله، أو default إذا لم يتم تقديم أي وسيط.

إذا تم تعيين متغير البيئة FOOT_INSTANCE، فسيحاول footclient الاتصال بالمقبس المحدد بواسطة هذا المتغير.

إذا لم يتم تعيين متغير البيئة FOOT_INSTANCE، ولم يتم تحديد الخيار -s، فسيقوم footclient بالبحث عن المقبس في الموقع الافتراضي. إذا تم تشغيل foot(1) باسم مثيل (على سبيل المثال، foot -n myinstance)، فسيتم وضع المقبس في ${XDG_RUNTIME_DIR}/foot/myinstance. بخلاف ذلك، سيتم وضعه في ${XDG_RUNTIME_DIR}/foot/default.

الأوامر التالية مدعومة:

new-window
افتح نافذة foot(1) جديدة. سيتم تمرير أي وسائط بعد new-window إلى foot(1) كأمر لتنفيذه في النافذة الجديدة.
search
ابحث عن نص في نافذة foot(1). سيتم استخدام أي وسائط بعد search كاستعلام بحث. البحث غير حساس لحالة الأحرف ويستخدم مطابقة السلاسل الفرعية.
prompt [args...]
اطلب من المستخدم الإدخال. سيتم تمرير أي وسائط بعد prompt كوسائط للأمر الأساسي للمطالبة (انظر خيار --prompt-command في foot(1)).
color-scheme [name]
التبديل إلى مخطط الألوان المحدد. إذا لم يتم توفير اسم، فقم بالتبديل عبر مخططات الألوان المعدة. يتم تعريف مخططات الألوان في الأقسام [colors] و [colors2] من ملف التكوين.
quit
أغلق نافذة foot(1).
pid
اطبع معرف العملية (PID) لعملية foot(1) إلى المخرج القياسي.

خيارات

-p, --pid pid
الاتصال بمثيل foot(1) الذي يحمل معرف العملية المحدد. يتجاوز هذا الخيار -s ومتغير البيئة FOOT_INSTANCE.
-s, --socket socket
الاتصال بمسار المقبس المحدد. يتجاوز هذا الخيار متغير البيئة FOOT_INSTANCE.
-h, --help
اطبع رسالة مساعدة واخرج.
-v, --version
اطبع معلومات الإصدار واخرج.

حالة الخروج

حالة الخروج هي 0 إذا تم إرسال الأمر بنجاح، وغير ذلك إذا فشل.

TERMINFO

يعتمد هذا البرنامج على قاعدة بيانات إمكانيات طرفية foot(1).

البيئة

تؤثر متغيرات البيئة التالية على footclient:

FOOT_INSTANCE
يحدد مسار مقبس مجال UNIX المستخدم للتواصل مع foot(1).
XDG_RUNTIME_DIR
يستخدم لتحديد مسار المقبس الافتراضي إذا لم يتم تعيين FOOT_INSTANCE ولم يتم تحديد -s.

الإشارات

الإشارات التالية لها معنى خاص في footclient:

  • SIGUSR1: التبديل إلى سمة اللون 1 (أي استخدام القسم [colors]).
  • SIGUSR2: التبديل إلى سمة اللون 2 (أي استخدام القسم [colors2]).

عند إرسال SIGUSR1/SIGUSR2 إلى مثيل footclient، يتم تغيير السمة في هذا المثيل فقط. هذا يختلف عن إرسال SIGUSR1/SIGUSR2 إلى عملية الخادم، حيث تقوم جميع المثيلات بتغيير السمة.

ملاحظة: لأسباب واضحة، هذا غير مدعوم عند تشغيل footclient مع --no-wait.
