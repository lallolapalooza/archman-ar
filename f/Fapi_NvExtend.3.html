Fapi_NvExtend(3)

Fapi_NvExtend - Extends the NV Index of the specified policy.

Detailed Description

The Fapi_NvExtend function extends the NV Index of the specified policy. This function is part of the Firmware Access API (FAPI) and is used to manage Non-Volatile (NV) memory. NV memory is used to store platform configuration data that needs to persist across reboots.

When extending an NV Index, you are essentially increasing the size of the allocated space for that index. This can be useful when the amount of data to be stored in an NV Index is expected to grow over time.

Function Documentation

TPM2_NvExtend(
    TPMI_RH_NV_AUTH authHandle,
    TPM2_HANDLE nvIndex,
    const UINT8 * data,
    UINT16 size
);
  • authHandle: The handle of the entity being used for authorization.
  • nvIndex: The index of the NV Index to be extended.
  • data: A pointer to the data to be written to the NV Index.
  • size: The size of the data to be written.

This function returns a TPM2_RC code indicating the success or failure of the operation.

Fapi_NvExtend(3)

Fapi_NvExtend - يوسع مؤشر NV للسياسة المحددة.

الوصف التفصيلي

تقوم الدالة Fapi_NvExtend بتوسيع مؤشر NV للسياسة المحددة. هذه الدالة جزء من واجهة برمجة تطبيقات الوصول إلى البرامج الثابتة (FAPI) وتستخدم لإدارة الذاكرة غير المتطايرة (NV). تُستخدم ذاكرة NV لتخزين بيانات تكوين النظام الأساسي التي تحتاج إلى الاستمرار عبر عمليات إعادة التشغيل.

عند توسيع مؤشر NV، فإنك تزيد فعليًا من حجم المساحة المخصصة لهذا المؤشر. يمكن أن يكون هذا مفيدًا عندما من المتوقع أن ينمو حجم البيانات المراد تخزينها في مؤشر NV بمرور الوقت.

توثيق الدالة

TPM2_NvExtend(
    TPMI_RH_NV_AUTH authHandle,
    TPM2_HANDLE nvIndex,
    const UINT8 * data,
    UINT16 size
);
  • authHandle: مقبض الكيان المستخدم للمصادقة.
  • nvIndex: مؤشر مؤشر NV المراد توسيعه.
  • data: مؤشر إلى البيانات المراد كتابتها في مؤشر NV.
  • size: حجم البيانات المراد كتابتها.

تعيد هذه الدالة رمز TPM2_RC يشير إلى نجاح أو فشل العملية.
