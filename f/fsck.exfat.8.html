fsck.exfat(8)

الحزمة: exfatprogs

التراخيص: GPL2

fsck.exfat(8) دليل مدير النظام fsck.exfat(8)

الاسم

fsck.exfat - فحص نظام ملفات exFAT

الملخص

fsck.exfat [ -a ] [ -n ] [ -r ] [ -v ] [ -y ] [ -b ] [ -v ] جهاز
fsck.exfat -V

الوصف

fsck.exfat يفحص نظام ملفات exFAT ويصلح نظام الملفات بناءً على الخيارات الممررة. يمكن إصلاح التلفيات التالية، وانظر الخيار '-s'.

-
قطاع الإقلاع يحتوي على معلمات غير صالحة. إذا كان قطاع الإقلاع الاحتياطي صالحًا، يتم استبدال قطاع الإقلاع به.
-
المجموعة (Cluster) معلمة كحرة ولكنها تنتمي إلى ملف، أو العكس. يتم تمييز خريطة البت (bitmap) للمجموعة بشكل صحيح.
-
حجم الملف كبير بشكل غير طبيعي مقارنة بعدد المجموعات. يتم تغيير الحجم.
-
حجم الملف صغير بشكل غير طبيعي مقارنة بعدد المجموعات. يتم حذف المجموعات المتبقية.
-
سلسلة مجموعات الملف تحتوي على رقم مجموعة غير صالح. يتم تغيير الرقم إلى EOF، ويتغير حجم الملف أيضًا.
-
سلسلة مجموعات الملف تحتوي على حلقة. يتم كسر الحلقة.
-
تتشارك الملفات نفس المجموعة. يتم كسر سلاسل المجموعات للملفات باستثناء واحد.
-
رقم المجموعة البدائية غير صالح. يتم تغيير رقم المجموعة وحجم الملف إلى 0.
-
قيمة فحص (checksum) لمجموعة إدخال الدليل غير صالحة. يتم حذف مجموعة إدخال الدليل.
-
قيمة تجزئة (hash) سيئة لاسم ملف. يتم تغيير قيمة التجزئة بشكل صحيح.
-
حقول مجموعة إدخال الدليل تحتوي على قيم غير صالحة. يتم حذف مجموعة إدخال الدليل.

الخيارات

-a
يقوم هذا الخيار بنفس وظيفة الخيار -p. تم تقديمه للتوافق مع الإصدارات السابقة فقط؛ يُقترح استخدام الخيار -p كلما أمكن ذلك.
-n
فحص نظام الملفات ولكن لا تحاول إصلاح نظام الملفات.
-p
إصلاح نظام الملفات دون تدخل المستخدم إذا كان ذلك ممكنًا بأمان.
-r
إصلاح نظام الملفات بشكل تفاعلي.
-s
إنشاء ملفات في /LOST+FOUND للمجموعات اليتيمة. هذه الملفات تحتوي على مجموعات مخصصة ولكنها لا تنتمي إلى أي ملفات عند إصلاح نظام الملفات. يتم تخصيص المجموعات غير المستخدمة والمتجاورة في خريطة البت لنفس الملف.
-v
طباعة معلومات تصحيح مفصلة أثناء فحص نظام ملفات exFAT.
-V
طباعة رقم الإصدار والخروج.
-y
إصلاح نظام الملفات بالإجابة بنعم على جميع الأسئلة.
-b
محاولة إصلاح نظام الملفات حتى لو لم يتم العثور على نظام ملفات exFAT.

أمثلة

إصلاح جهاز تالف وإنشاء ملفات في /LOST+FOUND، والتي تحتوي على مجموعات مخصصة ولكنها لا تنتمي إلى أي ملفات عند إصلاح الجهاز.

$ fsck.exfat -p -s /dev/sda1
