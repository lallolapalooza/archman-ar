FLATPAK LIST(1) flatpak list FLATPAK LIST(1)

الاسم

flatpak-list - سرد التطبيقات و/أو الأطر المثبتة

ملخص

flatpak list [خيار...]

الوصف

يسرد أسماء التطبيقات والأطر المثبتة.

بشكل افتراضي، يتم عرض كل من التطبيقات والأطر، ولكن يمكنك تغيير ذلك باستخدام خيارات --app أو --runtime.

بشكل افتراضي، يتم عرض التثبيتات لكل مستخدم وعلى مستوى النظام. استخدم خيارات --user أو --installation أو --system لتغيير ذلك.

يمكن أيضًا استخدام الأمر list للعثور على التطبيقات المثبتة التي تستخدم إطارًا معينًا، باستخدام الخيار --app-runtime.

خيارات

يتم فهم الخيارات التالية:

-h, --help

عرض خيارات المساعدة والخروج.

-u, --user

سرد التثبيتات لكل مستخدم.

--system

سرد التثبيتات الافتراضية على مستوى النظام.

--installation=NAME

سرد تثبيت على مستوى النظام محدد بالاسم بين تلك المعرفة في /etc/flatpak/installations.d/. استخدام --installation=default يعادل استخدام --system.

--arch=ARCH

سرد التطبيقات/الأطر لهذا المعمار. انظر flatpak --supported-arches للمعمار المدعومة من قبل المضيف.

-d, --show-details

عرض المصدر والأحجام والمعلومات الإضافية الأخرى. يعادل --columns=all.

--app

سرد التطبيقات.

--runtime

سرد الأطر.

--all, -a

سرد جميع الأطر المثبتة، بما في ذلك امتدادات اللغة و امتدادات التصحيح. هذه مخفية بشكل افتراضي.

--app-runtime=RUNTIME

سرد التطبيقات التي تستخدم الإطار المحدد.

-v, --verbose

طباعة معلومات التصحيح أثناء معالجة الأمر.

--ostree-verbose

طباعة معلومات تصحيح OSTree أثناء معالجة الأمر.

--columns=FIELD,...

تحديد المعلومات التي يجب عرضها لكل مرجع. يمكنك سرد حقول متعددة، أو استخدام هذا الخيار عدة مرات.

أضف :s[tart] أو :m[iddle] أو :e[nd] أو :f[ull] إلى أسماء الأعمدة لتغيير طريقة الاقتطاع.

الحقول

يتم فهم الحقول التالية بواسطة الخيار --columns:

name

عرض الاسم

description

عرض الوصف

application

عرض معرف التطبيق أو الإطار

arch

عرض المعمار

branch

عرض الفرع

runtime

عرض الإطار المستخدم

version

عرض الإصدار

ref

عرض المرجع

origin

عرض المستودع الأصلي

installation

عرض التثبيت

active

عرض الالتزام النشط

latest

عرض أحدث التزام

size

عرض الحجم المثبت

options

عرض الخيارات

all

عرض جميع الأعمدة

help

عرض قائمة الأعمدة المتاحة

لاحظ أن أسماء الحقول يمكن اختصارها إلى بادئة فريدة.

أمثلة

$ flatpak --user --columns=app list

Application
org.gnome.Builder
org.freedesktop.glxgears
org.gnome.MyApp
org.gnome.gedit
