NAME

foomatic-rip - PostScript RIP filter for CUPS

SYNOPSIS

foomatic-rip [options] [job-id]

DESCRIPTION

foomatic-rip is a PostScript RIP (Raster Image Processor) filter for CUPS.

It takes a PostScript file as input and converts it into a printer-ready format, which can be a raster image (like PCL, JPEG, PNG, etc.) or another PostScript file.

The filter uses the Foomatic database to determine the correct printer driver and settings for the conversion.

DIRECT, SPOOLER-LESS PRINTING

If you want to print directly to a printer without using the CUPS spooler, you can use foomatic-rip like this:

foomatic-rip your-ps-file > /dev/lp0

or

foomatic-rip your-ps-file > /dev/usb/lp0

For this to work, you need to have the printer driver set up in the Foomatic database for your printer.

PRINTING WITH SPOOLER

Normally, foomatic-rip is called by the CUPS spooler. CUPS passes the job-id of the print job as a command-line argument. foomatic-rip then reads the PostScript file from standard input and writes the converted data to standard output.

The CUPS spooler uses the settings in /etc/cups/printers.conf and /etc/cups/cupsd.conf to determine which filter to use for a given printer.

CONFIGURATION FILE

The configuration file for foomatic-rip is /etc/foomatic/filter.conf. This file contains options that control how foomatic-rip behaves.

FILES

/etc/cups/cupsd.conf
CUPS daemon configuration file. Contains settings related to filters and printers.
/etc/cups/printers.conf
CUPS printers configuration file. Contains definitions for currently defined printers.
/etc/cups/foomatic-rip.conf
/etc/foomatic/filter.conf

Configuration file for foomatic-rip

EXIT STATUS

foomatic-rip returns 0 unless something unexpected happens.
