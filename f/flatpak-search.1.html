الحزمة: flatpak

FLATPAK SEARCH(1) flatpak search FLATPAK SEARCH(1)

الاسم

flatpak-search - البحث عن التطبيقات والأوقات التشغيلية

الملخص

flatpak search TEXT

الوصف

يبحث عن التطبيقات والأوقات التشغيلية التي تتطابق مع النص. لاحظ أن هذا يستخدم بيانات appstream التي يمكن تحديثها باستخدام أمر flatpak update. يتم تحديث بيانات appstream تلقائيًا فقط إذا كان عمرها يومًا واحدًا على الأقل.

الخيارات

الخيارات التالية مفهومة:

-u, --user

ابحث فقط في المستودعات البعيدة في التثبيت الخاص بالمستخدم.

--system

ابحث فقط في المستودعات البعيدة في التثبيت الافتراضي على مستوى النظام.

--installation=NAME

عرض تثبيت على مستوى النظام بالاسم NAME ضمن تلك المعرفة في /etc/flatpak/installations.d/. استخدام --installation=default يعادل استخدام --system.

-h, --help

عرض خيارات المساعدة والخروج.

-v, --verbose

طباعة معلومات التصحيح أثناء معالجة الأمر.

--ostree-verbose

طباعة معلومات تصحيح OSTree أثناء معالجة الأمر.

--columns=FIELD,...

حدد المعلومات التي سيتم عرضها لكل نتيجة. يمكنك سرد حقول متعددة، أو استخدام هذا الخيار عدة مرات.

أضف :s[tart] أو :m[iddle] أو :e[nd] أو :f[ull] إلى أسماء الأعمدة لتغيير اختصار النص.

الحقول

الحقول التالية مفهومة بواسطة الخيار --columns:

name

عرض الاسم

description

عرض الوصف

application

عرض معرف التطبيق

version

عرض الإصدار

branch

عرض الفرع

remotes

عرض المستودعات البعيدة

all

عرض جميع الأعمدة

help

عرض قائمة الأعمدة المتاحة

لاحظ أن أسماء الحقول يمكن اختصارها إلى بادئة فريدة.
