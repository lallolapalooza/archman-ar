fido_dev_enable_entattest(3)

الحزمة: libfido2

التراخيص: BSD-2-Clause

FIDO_DEV_ENABLE_ENTATTEST(3) دليل وظائف المكتبة FIDO_DEV_ENABLE_ENTATTEST(3)

الاسم

fido_dev_enable_entattest، fido_dev_toggle_always_uv، fido_dev_force_pin_change، fido_dev_set_pin_minlen، fido_dev_set_pin_minlen_rpid — واجهة برمجة تطبيقات جهاز المصادقة CTAP 2.1

الملخص

#include <fido.h>
#include <fido/config.h>

int
fido_dev_enable_entattest(fido_dev_t *dev, const char *pin);

int
fido_dev_toggle_always_uv(fido_dev_t *dev, const char *pin);

int
fido_dev_force_pin_change(fido_dev_t *dev, const char *pin);

int
fido_dev_set_pin_minlen(fido_dev_t *dev, size_t len, const char *pin);

int
fido_dev_set_pin_minlen_rpid(fido_dev_t *dev, const char * const *rpid, size_t n, const char *pin);

الوصف

الوظائف الموصوفة في هذه الصفحة تسمح بتكوين جهاز مصادقة CTAP 2.1.

تقوم الوظيفة fido_dev_enable_entattest() بتمكين ميزة مصادقة المؤسسة (Enterprise Attestation) على dev. مصادقة المؤسسة تطلب من جهاز المصادقة تضمين معلومات تعريف فريدة في عبارات المصادقة اللاحقة. قد يكون المعامل pin فارغًا إذا لم يكن لـ dev رقم تعريف شخصي (PIN) معين.

تقوم الوظيفة fido_dev_toggle_always_uv() بتبديل ميزة "التحقق من المستخدم دائمًا" (user verification always) على dev. عند تعيينها، تفرض هذه الميزة التحقق من المستخدم على مستوى جهاز المصادقة لجميع بيانات الاعتماد المعروفة. إذا كان devpin فارغًا إذا لم يكن لـ dev

تقوم الوظيفة fido_dev_force_pin_change() بتوجيه dev إلى المطالبة بتغيير رقم التعريف الشخصي (PIN). ستفشل محاولات مصادقة رقم التعريف الشخصي اللاحقة ضد dev

تقوم الوظيفة fido_dev_set_pin_minlen() بتعيين الحد الأدنى لطول رقم التعريف الشخصي (PIN) لـ devlen. يمكن فقط زيادة الحد الأدنى لأطوال أرقام التعريف الشخصي.

تقوم الوظيفة fido_dev_set_pin_minlen_rpid() بتعيين قائمة بمعرفات الطرف الموثوق به (RP IDs) المسموح لها بالحصول على الحد الأدنى لطول رقم التعريف الشخصي (PIN) لـ dev من خلال امتداد CTAP 2.1 FIDO_EXT_MINPINLEN. يتم تمثيل قائمة بمعرفات الطرف الموثوق به بواسطة rpid، وهو متجه من n سلاسل UTF-8 منتهية بـ NUL. يتم إنشاء نسخة من rpid، ولا يتم الاحتفاظ بأي مرجع إليها أو لمحتوياتها. يمكن الحصول على الحد الأقصى لقيمة n التي يدعمها جهاز المصادقة باستخدام fido_cbor_info_maxrpid_minpinlen(3).

تنعكس إعدادات التكوين في الحمولة التي يعيدها جهاز المصادقة استجابةً لاستدعاء fido_dev_get_cbor_info(3).

قيم الإرجاع

تم تعريف رموز الخطأ التي تعيدها fido_dev_enable_entattest() و fido_dev_toggle_always_uv() و fido_dev_force_pin_change() و fido_dev_set_pin_minlen() و fido_dev_set_pin_minlen_rpid() في <fido/err.h>. عند النجاح، يتم إرجاع FIDO_OK.
