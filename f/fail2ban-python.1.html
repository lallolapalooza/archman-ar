fail2ban-python(1)

الحزمة: fail2ban

التراخيص: GPL-2.0-or-later

FAIL2BAN-PYTHON(1) أوامر المستخدم FAIL2BAN-PYTHON(1)

الاسم

fail2ban-python - مساعد لـ Fail2Ban لضمان استخدام نفس Python

الوصف

الاستخدام: fail2ban-python [خيار] ... [-c أمر | -m وحدة | ملف | -] [معامل] ... الخيارات (و متغيرات البيئة المقابلة): -b : إصدار تحذيرات حول str(bytes_instance)، str(bytearray_instance)

ومقارنة البايتات/bytearray مع str. (-bb: إصدار أخطاء)

-B : عدم كتابة ملفات .pyc عند الاستيراد؛ أيضًا PYTHONDONTWRITEBYTECODE=x -c أمر : برنامج تم تمريره كسلسلة نصية (ينهي قائمة الخيارات) -d : تشغيل مخرجات تصحيح الأخطاء للمحلل (للخبراء فقط، يعمل فقط على

إصدارات التصحيح)؛ أيضًا PYTHONDEBUG=x

-E : تجاهل متغيرات بيئة PYTHON* (مثل PATH) -h : طباعة رسالة المساعدة هذه والخروج (أيضًا -؟ أو --help) -i : الفحص بشكل تفاعلي بعد تشغيل البرنامج النصي؛ يجبر على ظهور موجه حتى

إذا لم يكن الإدخال القياسي طرفية؛ أيضًا PYTHONINSPECT=x

-I : عزل Python عن بيئة المستخدم (يتضمن -E و -s) -m وحدة : تشغيل وحدة مكتبة كبرنامج نصي (ينهي قائمة الخيارات) -O : إزالة التأكيدات والتعليمات البرمجية المعتمدة على __debug__؛ إضافة .opt-1 قبل

امتداد .pyc؛ أيضًا PYTHONOPTIMIZE=x

-OO : إجراء تغييرات -O وأيضًا التخلص من التعليقات التوضيحية؛ إضافة .opt-2 قبل

امتداد .pyc

-P : عدم إضافة مسار قد يكون غير آمن إلى sys.path -q : عدم طباعة رسائل الإصدار وحقوق النشر عند بدء التشغيل التفاعلي -s : عدم إضافة دليل الموقع الخاص بالمستخدم إلى sys.path؛ أيضًا PYTHONNOUSERSITE -S : عدم تضمين 'import site' عند التهيئة -u : فرض تدفقات الإخراج القياسي والإخراج القياسي للأخطاء لتكون غير مخزنة مؤقتًا؛

هذا الخيار ليس له تأثير على الإدخال القياسي؛ أيضًا PYTHONUNBUFFERED=x

-v : مطول (تتبع عبارات الاستيراد)؛ أيضًا PYTHONVERBOSE=x

يمكن تقديمه عدة مرات لزيادة الإسهاب

-V : طباعة رقم إصدار Python والخروج (أيضًا --version)

عندما يتم تقديمه مرتين، اطبع مزيدًا من المعلومات حول البناء

-W معامل : التحكم في التحذير؛ المعامل هو الإجراء:الرسالة:الفئة:الوحدة:رقم السطر

أيضًا PYTHONWARNINGS=معامل

-x : تخطي السطر الأول من المصدر، مما يسمح باستخدام أشكال غير يونكس من #!cmd -X خيار : تعيين خيار خاص بالتنفيذ --check-hash-based-pycs دائمًا|افتراضي|أبدًا:

التحكم في كيفية قيام Python بإبطال صلاحية ملفات .pyc المستندة إلى التجزئة

--help-env : طباعة المساعدة حول متغيرات بيئة Python والخروج --help-xoptions : طباعة المساعدة حول خيارات -X الخاصة بالتنفيذ والخروج --help-all : طباعة معلومات المساعدة الكاملة والخروج المعاملات: ملف : قراءة البرنامج من ملف نصي - : قراءة البرنامج من الإدخال القياسي (افتراضي؛ وضع تفاعلي إذا كان tty) معامل ...: معاملات تم تمريرها إلى البرنامج في sys.argv[1:]
