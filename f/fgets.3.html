fgetc(3) دليل وظائف المكتبة fgetc(3)

الاسم

fgetc, fgets, getchar, ungetc - إدخال الأحرف والسلاسل النصية

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdio.h>
int fgetc(FILE *stream);
int getchar(void);
char *fgets(int size;
            char s[restrict size], int size, FILE *restrict stream);
int ungetc(int c, FILE *stream);

الوصف

تقوم الدالة fgetc() بقراءة الحرف التالي من stream وإعادته كـ unsigned char محوّل إلى int، أو EOF عند نهاية الملف أو حدوث خطأ.

الدالة getchar() تعادل fgetc(stdin).

تقوم الدالة fgets() بقراءة ما لا يزيد عن size - 1 حرفًا من stream وتخزينها في المخزن المؤقت المشار إليه بواسطة s. يتوقف القراءة بعد EOF أو سطر جديد. إذا تم قراءة سطر جديد، يتم تخزينه في المخزن المؤقت. يتم تخزين بايت null ( '\0' ) فارغ بعد آخر حرف في المخزن المؤقت.

تقوم الدالة ungetc() بإعادة c إلى stream، محوّلة إلى unsigned char، حيث تصبح متاحة لعمليات القراءة اللاحقة. سيتم إرجاع الأحرف التي تم إعادتها بترتيب عكسي؛ مضمون عملية دفع واحدة فقط للخلف.

يمكن خلط استدعاءات الدوال الموصوفة هنا مع بعضها البعض ومع استدعاءات لوظائف إدخال أخرى من مكتبة stdio لنفس مجرى الإدخال.

للحصول على نظائر غير مقفلة، انظر unlocked_stdio(3).

قيمة الإرجاع

تقوم الدالتان fgetc() و getchar() بإرجاع الحرف المقروء كـ unsigned char محوّل إلى int أو EOF عند نهاية الملف أو حدوث خطأ.

تقوم الدالة fgets() بإرجاع s عند النجاح، و NULL عند الخطأ أو عندما تحدث نهاية الملف دون قراءة أي أحرف.

تقوم الدالة ungetc() بإرجاع c عند النجاح، أو EOF عند الخطأ.

السمات

ملاحظات
