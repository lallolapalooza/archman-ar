fcft_rasterize_grapheme_utf32(3)

الحزمة: fcft

التراخيص: MIT

fcft_rasterize_grapheme_utf32(3) fcft fcft_rasterize_grapheme_utf32(3)

الاسم

fcft_rasterize_grapheme_utf32 - تحويل صورة عنقود رمز مميز (grapheme cluster) إلى بكسلات

الملخص

#include <fcft/fcft.h>

const struct fcft_grapheme *fcft_rasterize_grapheme_utf32(

struct fcft_font *font, size_t len, const uint32_t grapheme_cluster[static len], enum fcft_subpixel subpixel);

الوصف

تقوم الدالة fcft_rasterize_grapheme_utf32() بتحويل عنقود الرمز المميز cluster إلى بكسلات باستخدام الخط الأساسي، أو أحد الخطوط الاحتياطية، في font.

كل عنصر في العنقود هو نقطة ترميز يونيكود مرمزة بـ UTF-32.

يتم البحث عن الخطوط لجميع نقاط الترميز في عنقود الرمز المميز، بدءًا بالخط الأساسي ثم الخطوط الاحتياطية المخصصة، وأخيرًا الخطوط الاحتياطية التي يوفرها FontConfig.

يسمح لك subpixel بتحديد وضع البكسل الفرعي المراد استخدامه. انظر fcft_rasterize_char_utf32() لمزيد من التفاصيل.

قيمة الإرجاع

في حالة حدوث خطأ، يتم إرجاع NULL.

في حالة النجاح، يتم إرجاع مؤشر إلى رمز مميز تم تحويله إلى بكسلات. يتم تخزين الرمز المميز مؤقتًا في fcft، مما يجعل الاستدعاءات اللاحقة بنفس الوسائط سريعة جدًا (أي، لا حاجة للبرامج لتخزين الرموز الرسومية مؤقتًا بنفسها).

يتم إدارة كائن الرمز المميز بواسطة font. لا حاجة لتحريره صراحةً؛ يتم تحريره عند تدمير font (باستخدام fcft_destroy()).

struct fcft_grapheme {
    int cols;
    size_t count;
    const struct fcft_glyph **glyphs;
};

cols هو عدد "الأعمدة" التي يشغلها الرمز الرسومي (فعليًا، wcswidth(cluster)).

glyphs عبارة عن مصفوفة من count رموز رسومية تم تحويلها إلى بكسلات. انظر fcft_rasterize_char_utf32() لوصف struct fcft_glyph.

انظر أيضًا
