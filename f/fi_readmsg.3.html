الاسم

fi_rma - عمليات الوصول للذاكرة عن بعد

fi_read / fi_readv / fi_readmsg
بدء قراءة من الذاكرة عن بعد

fi_write / fi_writev / fi_writemsg fi_inject_write / fi_writedata : بدء كتابة إلى الذاكرة عن بعد

    fi_addr_t src_addr, uint64_t addr, uint64_t key, void *context);

    size_t count, fi_addr_t src_addr, uint64_t addr, uint64_t key,

    uint64_t flags);

    void *desc, fi_addr_t dest_addr, uint64_t addr, uint64_t key,
    void *context);

المعلمات

ep
نقطة نهاية النسيج (fabric endpoint) لبدء عملية القراءة أو الكتابة.
buf
مخزن بيانات محلي للقراءة فيه (هدف القراءة) أو للكتابة منه (مصدر الكتابة).
len
طول البيانات المراد قراءتها أو كتابتها، بالمقدمة بالبايت. التحويلات الصالحة تكون من 0 بايت حتى أقصى حجم رسالة (max_msg_size) لنقطة النهاية.
iov
مخزن بيانات متجهة (vectored data buffer).
count
عدد إدخالات البيانات المتجهة.
addr
عنوان الذاكرة عن بعد للوصول إليها. سيكون هذا هو العنوان الظاهري (virtual address) للمنطقة البعيدة في حالة FI_MR_BASIC، أو الإزاحة (offset) من العنوان البدئي في حالة FI_MR_SCALABLE.
key
مفتاح الحماية (protection key) المرتبط بالذاكرة عن بعد.
desc
واصف (descriptor) مرتبط بمخزن البيانات المحلي. انظر fi_mr(3).
data
بيانات طابور الإكمال عن بعد (remote CQ data) ليتم نقلها مع العملية.
dest_addr
عنوان الوجهة لعمليات الكتابة غير المتصلة (connectionless write transfers). يتم تجاهله لنقاط النهاية المتصلة.
src_addr
عنوان المصدر للقراءة منه لعمليات النقل غير المتصلة. يتم تجاهله لنقاط النهاية المتصلة.
msg
واصف الرسالة لعمليات القراءة والكتابة.
flags
علامات إضافية لتطبيقها على عملية القراءة أو الكتابة.
context
مؤشر محدد من قبل المستخدم لربطه بالعملية. يتم تجاهل هذه المعلمة إذا كانت العملية لن تولد إكمالًا ناجحًا، إلا إذا حددت علامة عملية (op flag) أن المعلمة context يجب استخدامها للإدخال المطلوب.

الوصف

عمليات الوصول للذاكرة عن بعد (RMA - Remote Memory Access) تُستخدم لنقل البيانات مباشرة بين مخزن بيانات محلي ومخزن بيانات بعيد. تحدث عمليات RMA على مستوى البايت، ولا يتم الحفاظ على حدود الرسائل.

تُستخدم دوال الكتابة – fi_write, fi_writev, fi_writemsg, fi_inject_write, و fi_writedata – لإرسال البيانات إلى مخزن ذاكرة عن بعد. الاختلاف الرئيسي بين دوال الكتابة هو عدد وأنواع المعلمات التي تقبلها كمدخلات. بخلاف ذلك، فإنها تقوم بنفس الوظيفة العامة.

تُستخدم دوال القراءة – fi_read, fi_readv, و fi_readmsg – لنقل البيانات من منطقة ذاكرة عن بعد إلى مخزن (أو مخازن) بيانات محلي. على غرار عمليات الكتابة، تعمل عمليات القراءة بشكل غير متزامن. يجب على المستخدمين عدم المساس بمخزن (أو مخازن) البيانات المنشورة حتى تكتمل عملية القراءة.

يتم الإبلاغ عن عمليات RMA المكتملة للمستخدم من خلال واحد أو أكثر من طوابير الإكمال (completion queues) المرتبطة بنقطة النهاية. يقدم المستخدمون السياق (context) الذي يرتبط بكل عملية، ويتم إعادته للمستخدم كجزء من الإكمال. انظر fi_cq للحصول على تفاصيل أحداث الإكمال.

افتراضيًا، لا يقوم الطرف البعيد بإنشاء حدث أو إخطار المستخدم عند الوصول إلى منطقة ذاكرة بواسطة عملية قراءة أو كتابة RMA. ومع ذلك، يمكن ربط بيانات فورية (immediate data) بعملية كتابة RMA. ستؤدي عمليات الكتابة RMA مع البيانات الفورية إلى إنشاء إدخال إكمال في الطرف البعيد، بحيث يمكن تسليم البيانات الفورية.

fi_write

يقوم استدعاء fi_write بنقل البيانات الموجودة في مخزن البيانات المحدد من قبل المستخدم إلى منطقة ذاكرة عن بعد.

fi_writev

يضيف استدعاء fi_writev دعمًا لقائمة التجميع والتفريق (scatter-gather list) إلى fi_write. ينقل fi_writev مجموعة مخازن البيانات المشار إليها بواسطة المعلمة iov إلى منطقة الذاكرة عن بعد.

fi_writemsg

يدعم استدعاء fi_writemsg عمليات نقل البيانات عبر نقاط النهاية المتصلة وغير المتصلة، مع القدرة على التحكم في عملية الكتابة لكل استدعاء من خلال استخدام العلامات. تأخذ الدالة fi_writemsg بنية struct fi_msg_rma كمدخل.

struct fi_msg_rma {
    const struct iovec *msg_iov;     /* مصفوفة التجميع والتفريق المحلية */
    void               **desc;       /* واصف العملية */
    size_t             iov_count;    /* عدد العناصر في msg_iov */
    fi_addr_t          addr;        /* عنوان نقطة نهاية اختياري */
    const struct fi_rma_iov *rma_iov;/* قائمة التجميع والتفريق عن بعد (SGL) */
    size_t             rma_iov_count;/* عدد العناصر في rma_iov */
    void               *context;     /* سياق محدد من قبل المستخدم */
    uint64_t           data;         /* بيانات فورية اختيارية */
};
struct fi_rma_iov {
    uint64_t           addr;         /* عنوان RMA الهدف */
    size_t             len;          /* حجم المخزن الهدف */
    uint64_t           key;          /* مفتاح الوصول */
};

fi_inject_write

استدعاء حقن الكتابة (write inject call) هو نسخة محسنة من fi_write. يوفر دلالات إكمال مشابهة لـ fi_inject fi_msg(3).

fi_writedata

استدعاء بيانات الكتابة (write data call) مشابه لـ fi_write، ولكنه يسمح بإرسال بيانات طابور الإكمال عن بعد (انظر علامة FI_REMOTE_CQ_DATA) كجزء من عملية النقل.

fi_inject_writedata

استدعاء حقن بيانات الكتابة (inject write data call) مشابه لـ fi_inject_write، ولكنه يسمح بإرسال بيانات طابور الإكمال عن بعد (انظر علامة FI_REMOTE_CQ_DATA) كجزء من عملية النقل.

fi_read

يطلب استدعاء fi_read من نقطة النهاية البعيدة نقل البيانات من منطقة الذاكرة عن بعد إلى مخزن البيانات المحلي.

fi_readv

يضيف استدعاء fi_readv دعمًا لقائمة التجميع والتفريق (scatter-gather list) إلى fi_read. ينقل fi_readv البيانات من منطقة الذاكرة عن بعد إلى مجموعة مخازن البيانات المشار إليها بواسطة المعلمة iov.

fi_readmsg

يدعم استدعاء fi_readmsg عمليات نقل البيانات عبر نقاط النهاية المتصلة وغير المتصلة، مع القدرة على التحكم في عملية القراءة لكل استدعاء من خلال استخدام العلامات. تأخذ الدالة fi_readmsg بنية struct fi_msg_rma كمدخل.
