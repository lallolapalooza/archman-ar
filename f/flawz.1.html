flawz(1)

الحزمة: flawz

التراخيص: MIT, Apache-2.0

flawz(1) دليل الأوامر العامة flawz(1)

الاسم

flawz - واجهة مستخدم طرفية لتصفح ثغرات CVE

الملخص

flawz [--url] [-f|--feeds] [-d|--db] [-u|--force-update] [-o|--offline] [-q|--query] [-t|--theme] [-h|--help] [-V|--version]

الوصف

واجهة مستخدم طرفية لتصفح ثغرات CVE

الخيارات

--url=URL [افتراضي: https://nvd.nist.gov/feeds/json/cve/1.1/]
عنوان URL حيث يمكن العثور على خلاصات NIST CVE 1.1
يمكن أيضًا تحديده باستخدام متغير البيئة URL.
-f, --feeds=FEEDS [افتراضي: 2002:2024,recent,modified]
قائمة الخلاصات التي سيتم مزامنتها
يمكن أيضًا تحديدها باستخدام متغير البيئة FEEDS.
-d, --db=DB
مسار قاعدة بيانات SQLite المستخدمة لتخزين بيانات CVE المتزامنة
يمكن أيضًا تحديدها باستخدام متغير البيئة DB.
-u, --force-update
جلب الخلاصات دائمًا
-o, --offline
عدم جلب الخلاصات
-q, --query=QUERY
ابدأ بعبارة بحث
يمكن أيضًا تحديدها باستخدام متغير البيئة QUERY.
-t, --theme=THEME [افتراضي: dracula]
تعيين السمة

القيم الممكنة:

  • dracula: Dracula
  • nord: Nord
  • one-dark: One Dark
  • solarized-dark: Solarized Dark
  • gruvbox-light: Gruvbox Light
-h, --help
طباعة المساعدة (راجع الملخص باستخدام '-h')
-V, --version
