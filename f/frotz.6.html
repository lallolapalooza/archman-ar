TERM

على وحدة تحكم nux، غالبًا ما يتم تعيين $TERM على "linux". هذا سيدعم اللون. بالنسبة لوحدة تحكم NetBSD أو OpenBSD على x86 أو amd64، فإن القيمة الافتراضية لـ $TERM هي "vt100". للحصول على دعم الألوان هناك، تحتاج إلى تعيين $TERM على "pc3". وحدة تحكم FreeBSD $TERM هي "xterm" وستدعم اللون. اللون على وحدات التحكم النصية على أجهزة أخرى غير x86 أو amd64 لم يتم اختباره.

على بعض أنظمة التشغيل، لن يقوم Xterm بتغيير لون المؤشر ليتناسب مع لون النص. لحل هذه المشكلة، أضف السطر التالي إلى ملف .Xresources الخاص بك واكتب xrdb -merge $HOME/.Xresources

xterm*cursorColor: *XtDefaultForeground

يمكن أيضًا إضافة هذا إلى ملف على مستوى النظام مثل /etc/X11/Xresources/x11-common أو /etc/X11/app-defaults/XTerm. يمكن أن تختلف أسماء ومواقع الملفات على مستوى النظام من نظام تشغيل إلى آخر.

UNICODE

يدعم Frotz رموز Unicode عن طريق UTF-8 إذا كانت الوحدة الطرفية المستخدمة تدعم UTF-8. إذا كنت تفضل استخدام xterm، فابدأها كـ uxterm. هذا برنامج نصي مساعد يقوم بإعداد xterm مع إعدادات اللغة UTF-8. يمكنك أيضًا إخبار xterm يدويًا بالتبديل إلى وضع UTF-8 عن طريق الضغط على CTRL وزر الماوس الأيمن لإظهار قائمة VT FONTS. اعتمادًا على كيفية تثبيت xterm، قد ترى خيارًا لـ "UTF-8 Fonts" والذي سيسمح بعرض Unicode بشكل صحيح.

يمكن أن يختلف جعل xterm العادي يتصرف بهذه الطريقة في كل وقت من نظام إلى آخر. تحتوي محاكيات الطرفيات الأخرى على طرقها الخاصة ليتم تعيينها لاستخدام ترميز أحرف UTF-8.

الأحرف غير ASCII

يمكن عرض الرموز غير ASCII دون استخدام UTF-8 عن طريق مجموعات الأحرف ISO-8859-1 أو ISO-8859-15 (Latin-1 أو Latin-9). ISO-8859-15 متطابق تقريبًا مع ISO-8859-1 باستثناء أنه يدعم الأحرف المزدوجة OE/oe، ليحل محل الأحرف ذات الاستخدام غير المتكرر 1/2 و 1/4. انظر أيضًا luit(1) charsets(7) iso_8859-1(7) و iso_8859-15(7) لمزيد من المعلومات.

الإعدادات المحلية

وسيلة مهمة لضمان أن النظام يعرف لاستخدام UTF-8 هي التأكد من تعيين الإعدادات المحلية بشكل مناسب. هذا صالح فقط عندما يعمل Dumb Frotz تحت أنظمة شبيهة بـ Unix.

سيخبرك الأمر locale بما هو مستخدم حاليًا. سيظهر لك locale -a ما هو متاح. ثم قم بتعيين متغير البيئة LANG الخاص بك إلى شيء مناسب باستخدام أحد هذه الأوامر:

export LANG=C.UTF-8 export LANG=en_US.utf8

يمكن وضع هذا في ملف تكوين shell الخاص بك، سواء كان .profile أو .bash_profile أو .login أو .bashrc أو أي شيء آخر.

يمكن أيضًا تعيينه على مستوى النظام في الملفات المكافئة في /etc.

معايير Z-MACHINE

يتوافق Frotz مع معيار Z-Machine 1.1 الصادر في مايو 2006، والمراجع في فبراير 2014. الإصدار المعتمد موجود هنا:
http://inform-fiction.org/zmachine/standards/z1point1/index.html

اعتبارًا من 1.1، تم السماح بمعلمة prompt إضافية اختيارية على الحفظ / الاستعادة الموسعة للإصدار 5. تسمح هذه المعلمة للعبة بقراءة أو كتابة ملف مساعد (aux) دون مطالبة اللاعب. انظر القسم 15 من المعيار للحصول على التفاصيل. يقتصر Frotz على الملفات التي لها امتداد اسم ملف ".aux". عندما يكون الخيار -R (قراءة / كتابة مقيدة) نشطًا، تقتصر القراءات والكتابات عبر هذه الآلية على المسار المحدد كما هو الحال مع جميع عمليات الوصول إلى الملفات الأخرى.

البيئة

إذا تم تعريف متغير البيئة ZCODE_PATH، فسيبحث Frotz في هذا المسار عن ملفات الألعاب. إذا لم يكن هذا موجودًا، فسيبحث عن INFOCOM_PATH. يجب أن تكون أي ملفات إضافية مطلوبة، مثل الملفات المساعدة أو ملفات blorb، في نفس الدليل الذي يجد فيه Frotz ملف القصة.

لكي يتم قراءة مفتاح Alt بشكل صحيح في Xterm، يجب أن تكون الأسطر التالية في ملف .Xresources الخاص بك:

XTerm*metaSendsEscape: true
XTerm*eightBitInput: false

تنبيهات

يواجه Z Machine نفسه صعوبة في مفهوم تغيير حجم الطرفية. يفترض أنه بمجرد تعيين ارتفاع وعرض النص، فلن يتغير أبدًا؛ حتى عبر عمليات الحفظ. كان هذا منطقيًا عندما كانت الطرفيات 24x80 هي القاعدة والواجهات الرسومية كانت غير معروفة إلى حد كبير. أنا متأكد تمامًا من وجود طريقة للتغلب على هذه المشكلة، ولكن في الوقت الحالي، لا تقم بتغيير حجم xterm الذي يعمل فيه Frotz. أيضًا، يجب أن تحاول التأكد من أن الطرفية التي تستعيد عليها لعبة محفوظة لها نفس الأبعاد مثل الطرفية التي حفظت عليها اللعبة.

قد يكون تأخير الصوت طويلًا بشكل غير معقول اعتمادًا على إعدادات نظام التشغيل الخاص بك. Linux بشكل عام لديه الأمور بشكل صحيح. قد تحتاج BSDs إلى ضبط بعض إعدادات sysctl(8). انظر صفحات man sound(4) أو audio(4) لمزيد من المعلومات.

يمكنك استخدام مسار مثل /usr/local/games/zcode:$HOME/zcode مع $ZCODE_PATH أو $INFOCOM_PATH لأن shell سيقوم بتفسير متغير $HOME هذا لك قبل تعيين $ZCODE_PATH. أثناء معالجة frotz.conf و $HOME/.frotzrc، لا يتم استخدام shell. لذلك لا يمكنك استخدام متغيرات البيئة في خيار zcodepath داخل ملفات التكوين.

صفحة man هذه ليست مخصصة لإخبار المستخدمين كيفية لعب الخيال التفاعلي. ارجع إلى الملف HOW_TO_PLAY المضمن في وثائق Unix Frotz أو قم بزيارة أحد المواقع التالية:

http://www.microheaven.com/ifguide/
http://www.brasslantern.org/beginners/
http://www.musicwords.net/if/how_to_play.htm
http://ifarchive.org/

    NAME

    frotz - an interpreter for Infocom text adventure games

    SYNOPSIS

    frotz [-a] [-b] [-c] [-d] [-e] [-f] [-i] [-j] [-k] [-m] [-n] [-o] [-p] [-r] [-s savefile] [-t] [-u] [-v] [-w] [-z] [-h height] [-W width] [-L lines] [-S scrollback] [-C color] [-K keymap] [-F font] [-A codeset] [--curses] [--no-curses] [--help] [--version] [storyfile ...]

    DESCRIPTION

    frotz is an interpreter for text adventure games released by Infocom and other companies, running on the Z-machine virtual machine. It supports games from the first Infocom games (Zork I, 1980) up to the latest ones. It can also play games from other vendors that were compiled for the Z-machine.

    OPTIONS

    -a
    Use alternative interpretation, e.g. for some older games.
    -b
    Display bold text as bold.
    -c
    Create a save file named after the story file (with extension .save).
    -d
    Dump the Z-machine memory.
    -e
    Use extended Z-machine opcodes (for Z-machine version 4 and higher).
    -f
    Use fixed-width font.
    -i
    Ignore invalid opcodes.
    -j
    Use Japanese character set.
    -k
    Use keyboard input for cursor control (instead of number pad).
    -m
    Use monochrome display.
    -n
    No sound.
    -o
    Use old-style object attributes.
    -p
    Display pictures as pictures (if supported by the game).
    -r
    Reverse colors (white text on black background).
    -s savefile
    Load a saved game from savefile.
    -t
    Use TADS sound effects.
    -u
    Use Unicode characters.
    -v
    Print version information and exit.
    -w
    Wipe screen before starting.
    -z
    Use Z-machine version 3 opcodes.
    -h height
    Set screen height to height lines.
    -W width
    Set screen width to width columns.
    -L lines
    Set number of scrollback lines to lines.
    -S scrollback
    Set scrollback buffer size to scrollback lines.
    -C color
    Set text color to color.
    -K keymap
    Use the specified keymap file.
    -F font
    Use the specified font file.
    -A codeset
    Use the specified character codeset.
    --curses
    Use curses interface.
    --no-curses
    Do not use curses interface.
    --help
    Display help message and exit.
    --version
    Display version information and exit.

    FILES

    ~/.frotzrc
    User-specific configuration file.
    /etc/frotz.conf
    System-wide configuration file.

    CONFIGURATION FILES

    The configuration files contain a list of settings that are applied when frotz starts. The following options can be set:

    • alternate_interpretation
    • bold_text
    • create_save_file
    • dump_memory
    • extended_opcodes
    • fixed_width_font
    • ignore_invalid_opcodes
    • japanese_charset
    • keyboard_cursor
    • monochrome
    • no_sound
    • old_object_attributes
    • pictures
    • reverse_colors
    • save_file
    • tads_sound
    • unicode
    • wipe_screen
    • z_machine_version_3
    • height
    • width
    • scrollback
    • color
    • keymap
    • font
    • codeset
    • curses

    Each option is set as follows: option_name = value. Boolean options can be set to true or false. Numeric options can be set to integers. String options can be set to quoted strings.

    COLOR

    frotz supports color output. The color option can be used to set the text color. The following colors are supported: black, red, green, yellow, blue, magenta, cyan, white.

    UNICODE

    frotz supports Unicode characters when the unicode option is enabled or the -u flag is used. This allows for better display of international characters.

    NON ASCII CHARACTERS

    If your terminal supports UTF-8, you can use the -u option to display non-ASCII characters correctly. This is especially useful for games with internationalization.

    LOCALE

    frotz respects the user's locale settings. If the locale is set to a non-English language, frotz will attempt to use the appropriate character set and fonts.

    Z-MACHINE STANDARDS

    frotz supports games compiled for Z-machine versions 1 through 8. The -z and -e options can be used to force specific Z-machine versions if needed.

    ENVIRONMENT

    The FROTZ_CONFIG environment variable can be used to specify an alternative configuration file location.

    FURTHER INFORMATION

    For more detailed information on configuration options and advanced usage, please refer to the frotz documentation available at the official website or by running frotz with the --help option.

    CAVEATS

    Some older games may not function correctly with newer versions of frotz or with certain options enabled. Experimentation may be required to find the optimal settings for specific games.

    BUGS

    Please report any bugs or issues to the frotz bug tracker.
