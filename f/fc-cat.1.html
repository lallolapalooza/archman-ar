fc-cat(1)

الحزمة: fontconfig

التراخيص: HPND AND Unicode-DFS-2016

FC-CAT(1) FC-CAT(1)

الاسم

fc-cat - قراءة ملفات معلومات الخط المخزنة مؤقتاً

الملخص

fc-cat [ -rvVh ] [ --recurse ] [ --verbose ] [ --version ] [ --help ]
[ ملفات-الخط-المخزن-مؤقتاً-%version% | مجلدات ... ]

الوصف

fc-cat يقرأ معلومات الخط من ملفات التخزين المؤقت أو المتعلقة بمجلدات الخطوط ويصدرها بصيغة ASCII.

الخيارات

يتبع هذا البرنامج قواعد بناء جملة سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتضمن الملخص أدناه خيارات.

-r --recurse
التكرار في المجلدات الفرعية.
-v --verbose
كن مفصلاً.
-h --help
عرض ملخص الخيارات.
-V --version
عرض إصدار البرنامج والخروج.
