FEUPDATEENV(3P) دليل مبرمج POSIX FEUPDATEENV(3P)

المقدمة

هذه الصفحة من الدليل هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة في Linux.

الاسم

feupdateenv — تحديث بيئة الفاصلة العائمة

الملخص

#include <fenv.h>
int feupdateenv(const fenv_t *envp);

الوصف

تتوافق الوظيفة الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

ستحاول الدالة feupdateenv() حفظ استثناءات الفاصلة العائمة التي تم إطلاقها حاليًا في مساحتها التلقائية، ومحاولة تثبيت بيئة الفاصلة العائمة التي يمثلها الكائن الذي يشير إليه envp، ثم محاولة إطلاق استثناءات الفاصلة العائمة المحفوظة. يجب أن يشير الوسيط envp إلى كائن تم تعيينه بواسطة استدعاء لـ feholdexcept() أو fegetenv()، أو يساوي ماكرو بيئة فاصلة عائمة.

قيمة الإرجاع

سترجع الدالة feupdateenv() قيمة صفرية فقط إذا تم تنفيذ جميع الإجراءات المطلوبة بنجاح.

الأخطاء

لا توجد أخطاء معرفة.

الأقسام التالية إعلامية.

أمثلة

يوضح المثال التالي رمزًا نموذجيًا لإخفاء استثناءات الفاصلة العائمة للنقص الزائف:

#include <fenv.h>
double f(double x)
{
    #pragma STDC FENV_ACCESS ON
    double result;
    fenv_t save_env;
    feholdexcept(&save_env);
    // احسب النتيجة
    if (/* اختبر نقص زائف */)
    feclearexcept(FE_UNDERFLOW);
    feupdateenv(&save_env);
    return result;
}
