NAME

feature - compile-time feature checking and enablement

SYNOPSIS

    use feature ':5.10';
    use feature 'switch';
    use feature qw(say for);
    use feature 'unicode_strings';
    use feature ':default';
    my $enabled = feature::feature_enabled('say');
    my @enabled = feature::features_enabled();
    my $bundle = feature::feature_bundle();

DESCRIPTION

This module provides compile-time control over Perl's experimental and other features.

Historically, many features that were experimental were enabled by default only when a certain version of Perl was declared (e.g. use v5.10;). When this was done, the relevant features would be enabled for the entire scope. Since Perl 5.10, a more explicit mechanism has been available.

The feature pragma allows you to enable or disable specific features explicitly. This is particularly useful for enabling features that are not enabled by default in older Perl versions, or for disabling features that you do not want to accidentally use.

The feature pragma is also used to enable feature *bundles*. A feature bundle is a named collection of features. For example, :5.10 is a bundle that enables all features that were new in Perl 5.10. :default is a bundle that enables all features that are enabled by default in the current version of Perl.

AVAILABLE FEATURES

The following features are currently recognized by this module:

say
Enables the say function, which is like print but automatically appends a newline.
state
Enables the state variable declaration, which creates a variable that persists across function calls but is lexically scoped.
unicode_strings
Enables Unicode support for string operations. This means that string functions will operate on Unicode code points rather than bytes. This is equivalent to use utf8;.
unicode_eval
Enables Unicode support for eval. This means that eval will interpret its input as UTF-8.
evaloncode
Enables the evaloncode feature, which allows expressions to be evaluated in string contexts. This is generally considered dangerous and is discouraged.
bareword_filehandles
Enables the use of bare words as filehandles. This is generally discouraged and will be removed in a future version of Perl.
check_numeric_types
Enables runtime checks for numeric types. This is intended for use during development and testing.
switch
Enables the switch statement, which provides a more convenient way to write multi-way conditional logic.
for
Enables the for statement, which provides a more convenient way to write loops.
glob
Enables the glob operator, which performs shell wildcard expansion.
regex_context_patch
Enables a patch to the regex context that affects how backreferences are handled. This is a compatibility feature for older code.
strict_subs
Enables strict subroutine declarations. This means that all subroutines must be explicitly declared before they are called.
isa
Enables the isa operator, which checks if an object is an instance of a class.
multiline
Enables multiline regular expressions. This allows regular expressions to span multiple lines.
bitwise
Enables bitwise operators. This allows you to perform bitwise operations on numbers.
deref_perl_objects
Enables the dereferencing of Perl objects. This allows you to access the members of an object using the arrow operator.
arrow
Enables the arrow operator (->) for method calls.
autoderef
Enables automatic dereferencing of arrays and hashes in certain contexts.
array_base
Enables the use of array_base for specifying the base index of arrays.
pack
Enables the pack function, which packs data into a binary string.
unpack
Enables the unpack function, which unpacks data from a binary string.
readline
Enables the readline function, which reads a line from a filehandle.
substr
Enables the substr function, which extracts a substring from a string.
splice
Enables the splice function, which removes and/or replaces elements in an array.
threads
Enables support for multithreading.
signatures
Enables subroutine signatures, which allow you to specify parameter names and types.
attributes
Enables subroutine attributes, which allow you to add metadata to subroutines.
parentheses_only
Enables the use of parentheses only for subroutine calls. This means that you cannot call a subroutine without parentheses.
autovivification
Enables autovivification, which automatically creates nested data structures as needed.
eval_lives
Enables the eval_lives feature, which allows expressions to be evaluated in string contexts.
implicit_bare_hash_lookup
Enables implicit bare hash lookup. This means that you can access elements of a hash without specifying the hash name.
indirect
Enables indirect object invocation. This allows you to call methods on objects indirectly.
bare_newline
Enables the use of a bare newline character as a statement terminator. This is generally discouraged.
no_count
Disables the no_count feature, which is used to suppress warnings about unused variables.
print_to_stderr
Enables the print_to_stderr feature, which redirects all print output to STDERR.

FEATURE BUNDLES

A feature bundle is a named collection of features. The following feature bundles are recognized:

:5.10
Enables all features that were new in Perl 5.10. These include say, state, and unicode_strings.
:5.12
Enables all features that were new in Perl 5.12. These include switch, for, and evaloncode.
:5.14
Enables all features that were new in Perl 5.14. These include check_numeric_types and bareword_filehandles.
:5.16
Enables all features that were new in Perl 5.16. These include regex_context_patch, strict_subs, and isa.
:5.18
Enables all features that were new in Perl 5.18. These include multiline, bitwise, and deref_perl_objects.
:5.20
Enables all features that were new in Perl 5.20. These include arrow, autoderef, array_base, pack, unpack, readline, substr, splice, threads, and signatures.
:5.22
Enables all features that were new in Perl 5.22. These include attributes, parentheses_only, autovivification, and eval_lives.
:5.24
Enables all features that were new in Perl 5.24. These include implicit_bare_hash_lookup and indirect.
:5.26
Enables all features that were new in Perl 5.26. These include bare_newline and no_count.
:5.28
Enables all features that were new in Perl 5.28. These include print_to_stderr.
:default
Enables all features that are enabled by default in the current version of Perl. This is equivalent to use v5.VERSION; where VERSION is the current Perl version.
:all
Enables all currently known features. This is not recommended for general use, as it may enable experimental features that are not yet stable.

IMPLICIT LOADING

The feature pragma can be used without explicitly importing it. For example:

    use v5.10; # Imports the say, state, and unicode_strings features
    use v5.12 switch => 1; # Imports the switch feature and enables it

When used this way, the features are automatically imported into the current package.

CHECKING FEATURES

The feature module provides functions for checking whether features are enabled at compile time.

feature_enabled()
feature_enabled($depth)

Test whether a named feature is enabled at a given level in the call stack, returning a true value if it is. $depth defaults to 1, which checks the scope that called the scope calling feature::feature_enabled().

croaks for an unknown feature name.

features_enabled()
features_enabled($depth)
package ReportEnabledFeatures;
use feature "say";
sub import {
  say STDERR join " ", feature::features_enabled();
}

Returns a list of the features enabled at a given level in the call stack. $depth defaults to 1, which checks the scope that called the scope calling feature::features_enabled().

feature_bundle()
feature_bundle($depth)
Returns the feature bundle, if any, selected at a given level in the call stack. $depth defaults to 1, which checks the scope that called the scope calling feature::feature_bundle().

Returns an undefined value if no feature bundle is selected in the scope.

The bundle name returned will be for the earliest bundle matching the selected bundle, so:

use feature ();
use v5.12;
BEGIN { print feature::feature_bundle(0); }

will print 5.11.

This returns internal state, at this point "use v5.12;" sets the feature bundle, but " use feature ":5.12"; " does not set the feature bundle. This may change in a future release of perl.
