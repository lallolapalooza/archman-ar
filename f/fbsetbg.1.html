fbsetbg(1)

الحزمة: fluxbox

التراخيص: MIT

FBSETBG(1) دليل Fluxbox FBSETBG(1)

الاسم

fbsetbg - تعيين خلفية أو نمط

الملخص

fbsetbg [-uU wallpapersetter] [-fFcCtTaA] wallpaper

fbsetbg [-uU wallpapersetter] -rR path

fbsetbg -bB fbsetrootoptions...

fbsetbg [-l|h|i|p]

الوصف

fbsetbg(1) هو برنامج مساعد يحاول العثور على تطبيق مناسب لتعيين الخلفية ثم يحاول تعيين الخلفية باستخدام هذا التطبيق. لا تحتاج إلى تهيئة fbsetbg. إنه يستخدم فقط أول تطبيق يمكنه العثور عليه.

علاوة على ذلك، يدعم تذكر آخر خلفية تم تعيينها حتى لا تضطر إلى تعديل ملف النمط أو ملف التهيئة لتغيير الخلفية.

يهدف إلى تقديم رسائل خطأ واضحة في نافذة تسهل تصحيح الأخطاء.

خيارات

-f file

تعيين خلفية بملء الشاشة.

-c file

تعيين خلفية في المنتصف.

-t file

تعيين خلفية متجانبة.

-a file

تعيين خلفية مكبرة، مع الحفاظ على نسبة العرض إلى الارتفاع (إذا كان برنامج تعيين الخلفية الخاص بك لا يدعم هذا الخيار، فسيعود fbsetbg إلى -f).

-u wallpapersetter

استخدام برنامج تعيين الخلفية المحدد، وعدم استخدام أي وسيط لنسيانها.

-b fbsetrootoptions

تمرير الخيارات إلى fbsetroot(1). يمكن استخدام هذه لتعيين نسيج خلفية صلب أو نمطي أو متدرج.

-r directory

تعيين خلفية عشوائية من مجلد.

-F, -C, -T, -A, -U, -B, -R

نفس الخيارات بحروف صغيرة ولكن بدون تذكر.

-l

تعيين الخلفية السابقة. أو، إذا تم استخدام ميزة العشوائية مؤخرًا، قم بتعيين خلفية عشوائية أخرى من نفس المجلد.

-i

عرض معلومات مفيدة حول أفضل برنامج تعيين خلفية تم العثور عليه.

-p

عرض بعض النصائح المفيدة.

-h

عرض رسالة مساعدة.

الملفات

~/.fluxbox/lastwallpaper

في هذا الملف، سيتم تخزين الخلفية التي قمت بتعيينها، لخيار -l.

البيئة

wpsetters

برامج تعيين الخلفية المراد استخدامها. يمكن أن تكون هذه قائمة مفصولة بمسافات للتطبيقات المراد تجربتها، أو اسمًا واحدًا فقط.

DISPLAY

الشاشة التي تريد تعيين الخلفية عليها.

أمثلة

لاستخدام feh(1) كبرنامج لتعيين الخلفية وتعيين wallpapper.jpg من الدليل الحالي كخلفية.

$ wpsetters=feh fbsetbg wallpaper.jpg

استعادة آخر خلفية تم تعيينها على الشاشة :0.0 بالخيارات المخزنة.

$ DISPLAY=:0.0 fbsetbg -l

الأخطاء

fbsetbg(1) ليس مضمونًا.
