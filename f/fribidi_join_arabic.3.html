الاسم

fribidi_join_arabic - إجراء الربط العربي

الملخص

#include <../fribidi/lib/fribidi.h>

void fribidi_join_arabic
(
const FriBidiCharType *bidi_types,
const FriBidiStrIndex len,
const FriBidiLevel *embedding_levels,
FriBidiArabicProp *ar_props
);

المعلمات

const FriBidiCharType *bidi_types
قائمة أنواع bidi المدخلة كما تم إرجاعها بواسطة fribidi_get_bidi_types().

نظرًا لوجود 23 قيمة محتملة لـ const FriBidiCharType، لم يتم سردها كلها هنا.

const FriBidiStrIndex len
طول السلسلة المدخلة.
const FriBidiLevel *embedding_levels
قائمة مستويات التضمين المدخلة، كما تم إرجاعها بواسطة fribidi_get_par_embedding_levels.
FriBidiArabicProp *ar_props
خصائص اللغة العربية المراد تحليلها، والتي تم تهيئتها بواسطة أنواع الربط، كما تم إرجاعها بواسطة fribidi_get_joining_types.

الوصف

تقوم هذه الدالة بتنفيذ خوارزمية الربط العربية. ويعني ذلك، بالنظر إلى أنواع الربط العربية للأحرف في ar_props (لا تقلق، يمكن تحويل FriBidiJoiningType إلى FriBidiArabicProp تلقائيًا)، تقوم هذه الدالة بتعديل هذه الخصائص لاستيعاب تأثير الأحرف المجاورة. قد تحتاج إلى هذه المعلومات لاحقًا لإجراء تشكيل اللغة العربية.

تقوم هذه الدالة بتنفيذ القواعد من R1 إلى R7 شاملة (جميع القواعد) لخوارزمية الربط المتصلة باللغة العربية لمعيار Unicode كما هو متاح على http://www.unicode.org/versions/Unicode4.0.0/ch08.pdf#G7462. كما تتفاعل بشكل صحيح مع خوارزمية الاتجاهين كما هي محددة في القسم
3.5 التشكيل من خوارزمية الاتجاهين لـ Unicode المتاحة على http://www.unicode.org/reports/tr9/#Shaping.

هناك عدد قليل من وحدات الماكرو المعرفة في fribidi-joining-types.h للاستعلام عن الخصائص العربية التي تحسبها هذه الدالة.
