الحزمة: flashprog

التراخيص: GPL-2.0-or-later

FLASHPROG-CONFIG(8) 2024-11-03 FLASHPROG-CONFIG(8)

الاسم

flashprog-config - قراءة وكتابة سجلات الحالة والإعدادات للرقائق الفلاشية

الملخص

flashprog config [get] <خيارات> <إعداد>
flashprog config  set  <خيارات> [--temporary] <إعداد> <قيمة>

حيث <خيارات> العامة هي:

-p <اسم المبرمج>[:<معلمات>] [-c <اسم الشريحة>]
[-V[V[V]]] [-o <ملف السجل>] [-h]

الوصف

flashprog-config هي أداة مساعدة لقراءة وكتابة بتات سجلات الحالة والإعدادات الخاصة برقائق الفلاش. حالياً، تدعم فقط رقائق SPI NOR.

العمليات

يمكنك تحديد إحدى العمليتين get أو set، أو عدم تحديد عملية مما يعني القراءة الافتراضية لإعداد.

get <إعداد>

اقرأ واطبع قيمة الإعداد المحدد. انظر الإعدادات أدناه.

set [--temporary] <إعداد> <قيمة>

اكتب القيمة المحددة للإعداد. انظر الإعدادات و القيم أدناه.

عند توفير الخيار --temporary، ستحاول flashprog كتابة قيمة مؤقتة لا يتم تخزينها في الفلاش. هذا يتطلب دعمًا خاصًا من الشريحة الفلاشية لأمر سجل حالة كتابة متطايرة. ستُفقد القيمة الجديدة عند إعادة تعيين الشريحة الفلاشية. لذلك، يكون استخدامه عبثًا مع المبرمجين الخارجيين الذين يقومون بتشغيل وإيقاف تشغيل طاقة الشريحة الفلاشية (مثل Dediprog).

الإعدادات

qe, quad-enable

تدعم رقائق SPI NOR الفلاشية غالبًا تبديل بعض دبابيسها (عادةً /WP و /HOLD) بخطوط إدخال/إخراج إضافية. هذا يمكّنها من نقل أربعة بتات في المرة الواحدة عند تعيين بت quad-enable.

القيم

false, true

سيتم تحويل القيمتين false و true إلى 0 و 1 على التوالي.

الأرقام الطبيعية: 0, 1, ...

عند إعطاء أرقام طبيعية، سيتم كتابة أقل البتات أهمية في تمثيلها الثنائي إلى إعداد.

الخيارات

تتطلب جميع العمليات استخدام الخيار -p/--programmer (يرجى الاطلاع للحصول على مزيد من المعلومات حول دعم المبرمج والمعلمات).

-p, --programmer <الاسم>[:<المعلمة>[,<المعلمة>]...]

حدد جهاز المبرمج. هذا إلزامي لجميع العمليات. يرجى الاطلاع على الدليل للحصول على قائمة بالمبرمجين المدعومين حالياً ومعلماتهم.

-c, --chip <اسم الشريحة>

افحص فقط الشريحة الرومية الفلاشية المحددة. يأخذ هذا الخيار اسم الشريحة كما يطبع بواسطة flashprog -L بدون اسم البائع كمعلمة. يرجى ملاحظة أن اسم الشريحة حساس لحالة الأحرف.

-V, --verbose

مخرجات أكثر تفصيلاً. يمكن تقديم هذا الخيار عدة مرات (بحد أقصى 3 مرات، أي -VVV) لمزيد من مخرجات التصحيح.

-o, --output <ملف السجل>

احفظ سجل التصحيح الكامل في <ملف السجل>. إذا كان الملف موجودًا بالفعل، فسيتم استبداله. هذه هي الطريقة الموصى بها لجمع السجلات من flashprog لأنها ستكون مفصلة حتى لو كانت الرسائل على الشاشة غير مفصلة ولا تتطلب إعادة توجيه المخرجات.

-h, --help

عرض نص المساعدة والخروج.

--temporary

حاول استخدام أمر سجل حالة كتابة متطايرة. انظر set ضمن العمليات أعلاه.

أمثلة

لقراءة إعداد quad-enable للفلاش البيوس الداخلي:

flashprog config -p internal quad-enable
أو
flashprog config get -p internal quad-enable
لتعيين بت quad-enable مؤقتًا لشريحة متصلة بـ FT4222H:
flashprog config set -p ft4222_spi --temporary quad-enable 1

حالة الخروج

تنتهي flashprog بنتيجة 0 عند النجاح، و 1 عند معظم الإخفاقات، ولكن بنتيجة 3 إذا فشل استدعاء mmap().

المتطلبات

تحتاج flashprog إلى أذونات وصول مختلفة للمبرمجين المختلفين. انظر هذا القسم في الدليل للحصول على التفاصيل.
