FREE(3P) دليل مبرمج POSIX FREE(3P)

PROLOG

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

NAME

free — تحرير الذاكرة المخصصة

SYNOPSIS

#include <stdlib.h>
void free(void *ptr);

DESCRIPTION

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

تقوم الدالة free() بإلغاء تخصيص المساحة التي يشير إليها ptr؛ أي جعلها متاحة للتخصيصات المستقبلية. إذا كان ptr مؤشرًا فارغًا، فلن يحدث أي إجراء. بخلاف ذلك، إذا لم يتطابق الوسيط مع مؤشر تم إرجاعه سابقًا بواسطة دالة في POSIX.1-2008 التي تقوم بتخصيص ذاكرة كما لو كانت بواسطة malloc()، أو إذا تم إلغاء تخصيص المساحة بواسطة استدعاء لـ free() أو realloc()، فإن السلوك غير محدد.

يؤدي أي استخدام لمؤشر يشير إلى مساحة تم تحريرها إلى سلوك غير محدد.

RETURN VALUE

لا تقوم الدالة free() بإرجاع قيمة.

ERRORS

لا توجد أخطاء محددة.
