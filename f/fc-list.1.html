FC-LIST(1) FC-LIST(1)

الاسم

fc-list - قائمة بالخطوط المتاحة

المُلَخَّص

fc-list [ -vVh ] [ --verbose ] [ -f format | --format format ] [ -q | --quiet ] [ --version ] [ --help ]
[ pattern [ element ... ] ]

الوصف

fc-list يسرد الخطوط والأنماط المتاحة على النظام للتطبيقات التي تستخدم fontconfig. إذا تم تحديد أي عناصر، فسيتم طباعة تلك فقط. بخلاف ذلك، سيتم طباعة اسم العائلة والنمط، ما لم يتم طلب إخراج مفصل.

الخيارات

يتبع هذا البرنامج صيغة سطر الأوامر المعتادة لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). تتضمن القائمة أدناه ملخصًا للخيارات.

-v --verbose
طباعة إخراج مفصل للنمط الكامل للخط لكل تطابق، أو elements إذا تم توفير أي منها.
-f --format format
تنسيق الإخراج وفقًا لمحدد التنسيق format.
-q --quiet
كتم كل الإخراج العادي. يعيد 1 كرمز خطأ إذا لم تتطابق أي خطوط.
-V --version
عرض إصدار البرنامج والخروج.
-h --help
عرض ملخص الخيارات.
pattern
إذا تم تعيين هذه الحجة، فسيتم عرض الخطوط التي تطابق pattern فقط.
element
إذا تم تعيينه، فسيتم عرض خاصية element للخطوط المتطابقة.

أمثلة

fc-list
يسرد جميع وجوه الخطوط.
fc-list :lang=hi
يسرد وجوه الخطوط التي تغطي اللغة الهندية.
fc-list : family style file spacing
يسرد اسم الملف وقيمة المسافة لكل وجه خط. ``:'' هو نمط فارغ يتطابق مع جميع الخطوط.
