مستند قابل للتكوين لمحرك التنسيق Format.

تقدم هذه الوحدة نوع مستند نقي وغير قابل للتغيير يمثل تسلسلاً من تعليمات التنسيق التي سيتم طباعتها بواسطة محرك تنسيق في وقت لاحق. في الوقت نفسه ، توفر أيضًا مترجم سلسلة التنسيق الذي ينتج هذا النوع من المستندات من سلسلة التنسيق والطابعات المرتبطة بها.

تم تصميم الوحدة لتكون متوافقة مع المصدر مع الكود الذي يحدد طابعات التنسيق: استبدال `Format` بـ `Format_doc` في الكود الخاص بك سيحول طابعات `Format` إلى طابعات `Format_doc`.

module Doc : sig end

formatter rdoc ينشئ Format_doc.formatter الذي يحدث المرجع rdoc

type 'a format_printer = Format.formatter -> 'a -> unit

NAME

Format_doc - Documentation for Format module

Module

module Format_doc : sig ... end

Documentation

This module provides utilities for formatting output, particularly for printing lists and tables.

The `pp_two_columns` function formats a list of pairs into two columns separated by a delimiter.

pp_two_columns : ?sep:string -> ?max_lines:int -> Format.formatter -> (string * string) list -> unit

Formats a list of string pairs into two columns. Each pair is printed on a single line, with the two strings separated by the `sep` string (default is "|").

The `max_lines` argument can be used to specify a maximum number of lines to print. If the input has too many lines, an ellipsis (...) is inserted in the middle.

Example:

pp_two_columns ~max_lines:3 Format.std_formatter [ "abc", "hello"; "def", "zzz"; "a" , "bllbl"; "bb" , "dddddd"; ]

prints:

abc | hello ... bb | dddddd
