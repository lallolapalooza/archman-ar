ecvt_r(3) دليل وظائف المكتبة ecvt_r(3)

الاسم

ecvt_r, fcvt_r, qecvt_r, qfcvt_r - تحويل رقم نقطة عائمة إلى سلسلة نصية

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <stdlib.h>
[[deprecated]] int ecvt_r(double number, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
[[deprecated]] int fcvt_r(double number, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
[[deprecated]] int qecvt_r(long double number, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
[[deprecated]] int qfcvt_r(long double number, int ndigits,
                          int *restrict decpt, int *restrict sign,
                          char *restrict buf, size_t size);
متطلبات ماكرو اختبار الميزة لـ glibc (انظر feature_test_macros(7)):

ecvt_r(), fcvt_r(), qecvt_r(), qfcvt_r():

    /* glibc >= 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _SVID_SOURCE || _BSD_SOURCE

الوصف

الوظائف ecvt_r(), fcvt_r(), qecvt_r(), و qfcvt_r() متطابقة مع ecvt(3)، fcvt(3)، qecvt(3)، و qfcvt(3)، على التوالي، باستثناء أنها لا تُرجع نتيجتها في مخزن مؤقت ثابت، ولكنها بدلاً من ذلك تستخدم buf المزوّد بالحجم size. انظر ecvt(3) و qecvt(3).

قيمة الإرجاع

تُرجع هذه الوظائف 0 عند النجاح، و -1 عند الفشل.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
ecvt_r (), fcvt_r (), qecvt_r (), qfcvt_r () سلامة الخيط MT-Safe

المعايير

GNU.

ملاحظات

هذه الوظائف قديمة. بدلاً من ذلك، يُوصى بـ sprintf(3).
