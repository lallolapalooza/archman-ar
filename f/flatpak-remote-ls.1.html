flatpak-remote-ls(1)

الحزمة: flatpak

التراخيص: LGPL-2.1-or-later

FLATPAK REMOTE-LS(1) flatpak remote-ls FLATPAK REMOTE-LS(1)

الاسم

flatpak-remote-ls - عرض وقت التشغيل والتطبيقات المتاحة

ملخص

flatpak remote-ls [خيار...] [REMOTE]

الوصف

يعرض وقت التشغيل والتطبيقات المتاحة في المستودع البعيد بالاسم REMOTE، أو جميع المستودعات إذا لم يتم تحديد واحد. يمكنك العثور على جميع المستودعات البعيدة المهيأة باستخدام flatpak remotes.

يمكن أن يكون REMOTE عنوان URI من نوع file:// يشير إلى مستودع محلي بدلاً من اسم بعيد.

ما لم يتم تجاوزها باستخدام خيارات --system أو --user أو --installation، يستخدم هذا الأمر إما التثبيت الافتراضي على مستوى النظام أو التثبيت الخاص بالمستخدم، اعتمادًا على أي منهما يحتوي على REMOTE المحدد.

الخيارات

يتم فهم الخيارات التالية:

-h, --help

عرض خيارات المساعدة والخروج.

-u, --user

استخدام التهيئة الخاصة بالمستخدم.

--system

استخدام التهيئة الافتراضية على مستوى النظام.

--installation=NAME

استخدام تثبيت على مستوى النظام محدد بالاسم NAME من بين تلك المعرفة في /etc/flatpak/installations.d/. استخدام --installation=default يعادل استخدام --system.

--cached

تفضيل استخدام المعلومات المخزنة مؤقتًا محليًا إن أمكن، على الرغم من أنها قد تكون قديمة. هذا أسرع، ولكنه يخاطر بإرجاع معلومات قديمة.

-d, --show-details

عرض المعماريات والفروع ومعرفات الالتزام، بالإضافة إلى الأسماء. يعادل --columns=all.

--runtime

عرض وقت التشغيل فقط، استبعاد التطبيقات.

--app

عرض التطبيقات فقط، استبعاد أوقات التشغيل.

--all, -a

عرض كل شيء. افتراضيًا، يتم إخفاء امتدادات اللغة والتصحيح وكذلك المعماريات الثانوية عندما تكون المعمارية الأساسية متاحة.

--updates

عرض فقط تلك التي لديها تحديثات متاحة.

--arch=ARCH

عرض فقط تلك التي تطابق المعمارية المحددة. افتراضيًا، يتم عرض المعماريات المدعومة فقط. استخدم --arch=* لعرض جميع المعماريات. انظر flatpak --supported-arches للمعماربات المدعومة من قبل المضيف.

-v, --verbose

طباعة معلومات التصحيح أثناء معالجة الأمر.

--ostree-verbose

طباعة معلومات تصحيح OSTree أثناء معالجة الأمر.

--app-runtime=RUNTIME

عرض التطبيقات التي تستخدم وقت التشغيل المحدد

--columns=FIELD,...

تحديد المعلومات التي يجب عرضها حول كل مرجع. يمكنك سرد حقول متعددة، أو استخدام هذا الخيار عدة مرات.

أضف :s[tart] أو :m[iddle] أو :e[nd] أو :f[ull] إلى أسماء الأعمدة لتغيير الاقتطاع.

الحقول

يتم فهم الحقول التالية بواسطة الخيار --columns:

name

عرض الاسم

description

عرض وصف التطبيق

application

عرض معرف التطبيق أو وقت التشغيل

arch

عرض المعمارية

branch

عرض الفرع

version

عرض الإصدار

ref

عرض المرجع

origin

عرض المستودع الأصلي

commit

عرض الالتزام النشط

runtime

عرض وقت التشغيل المستخدم

installed-size

عرض حجم التثبيت

download-size

عرض حجم التنزيل

options

عرض الخيارات

all

عرض جميع الأعمدة

help

عرض قائمة الأعمدة المتاحة

لاحظ أن أسماء الحقول يمكن اختصارها إلى بادئة فريدة.

أمثلة

$ flatpak --user remote-ls --app testrepo

Ref
org.gnome.Builder
org.freedesktop.glxgears

$ flatpak remote-ls file:///run/media/mwleeds/d4d37026-cde2-4e5e-8bcc-d23ebbf231f9/.ostree/repo

Ref
org.kde.Khangman
