ffi(3)

الحزمة: libffi

التراخيص: MIT

FFI(3) دليل وظائف المكتبة FFI(3)

الاسم

FFI — واجهة الوظائف الخارجية

المكتبة

libffi, -lffi

المُلَخَّص

#include <ffi.h>

ffi_status
ffi_prep_cif(ffi_cif *cif, ffi_abi abi, unsigned int nargs, ffi_type *rtype, ffi_type **atypes);

void
ffi_prep_cif_var(ffi_cif *cif, ffi_abi abi, unsigned int nfixedargs, unsigned int ntotalargs, ffi_type *rtype, ffi_type **atypes);

void
ffi_call(ffi_cif *cif, void (*fn)(void), void *rvalue, void **avalue);

الوصف

توفر واجهة الوظائف الخارجية آلية يمكن من خلالها لوظيفة إنشاء استدعاء لوظيفة أخرى في وقت التشغيل دون الحاجة إلى معرفة واجهة الوظيفة المدعوة وقت التجميع.

انظر أيضًا

ffi_prep_cif(3), ffi_prep_cif_var(3), ffi_call(3)
