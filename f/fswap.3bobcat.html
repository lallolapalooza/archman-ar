الأخطاء

لا ينبغي تطبيق دوال fswap ميكانيكيًا لتبديل كائنات فئات تحتوي على أعضاء بيانات من نوع مؤشر تحدد، على سبيل المثال، قائمة مترابطة. اعتبر قائمة من أربعة كائنات مثل:

    A -> B -> C -> D

التبديل السريع لـ B و C سيؤدي إلى القائمة التالفة التالية:

               +------+
               |      |
    A -> C -+  +-> B -+   +-> D
            |             |
            +-------------+

ومع ذلك، قد تستفيد الفئات التي تنفذ هيكل بيانات مثل القائمة المترابطة من عمليات التبديل السريع: من خلال تنفيذ عضو تبديل خاص بها، يمكنها أولاً استخدام التبديل السريع لتبديل الكائنات، يليه تبديل سريع آخر لإلغاء تبديل مؤشرات `next’ الخاصة بها.

لا ينبغي أيضًا استخدام الدالة fswap للكائنات التي تحدد مؤشرات (خلفية) لبياناتها الخاصة. اعتبر الكائنات التالية التي تستخدم مؤشرات للبيانات والمؤشرات (الخلفية) للكائنات الأصلية:

    Before fswapping:
        A                                  B
       +--------+   +-----------+         +--------+   +-----------+
       |        |   |           |         |        |   |           |
     +--> *Aimp------> *A (back)--+     +--> *Bimp------> *B (back)--+
     | |        |   |           | |     | |        |   |           | |
     +--**Aimp  |   +-----------+ |     +--**Bimp  |   +-----------+ |
       +--------+ <---------------+       +--------+ <---------------+
    After fswapping:
                     +-------------------------------+
                  +--|-------------------------------|-+
    +-------------|--|-----------------+             | |
    |   A         |  v                 |   B         | v
    |  +--------+ | +-----------+      |  +--------+ | +-----------+
    |  |        | | |           |      |  |        | | |           |
  +-----> *Bimp---+ |  *A (back)--+    +---> *Aimp---+ |  *B (back)--+
  | |  |        |   |           | |       |        |   |           | |
  | +---**Bimp  |   +-----------+ |    +---**Aimp  |   +-----------+ |
  |    +--------+ <---------------+    |  +--------+ <---------------+
  +------------------------------------+
بعد التبديل، يجب أن يشير **Bimp إلى عنوان Bimp (الذي أصبح الآن في A)، ولكنه في الواقع يشير إلى عنوان Aimp (الذي أصبح الآن في B). وبالمثل، لا تزال المؤشرات الخلفية تشير إلى كائناتها الأصلية بدلاً من الكائنات المبدلة الخاصة بها.

جميع فئات stream تحدد مثل هذه المؤشرات وبالتالي لا يمكن تبديلها باستخدام fswap.

الخلاصة هي أنه لا ينبغي استخدام fswap إلا للفئات المعرفة ذاتيًا والتي يمكن إثبات أن التبديل السريع لا يفسد قيم مؤشراتها.
