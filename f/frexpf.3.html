frexp(3) دليل وظائف المكتبة frexp(3)

الاسم

frexp, frexpf, frexpl - تحويل رقم ذو فاصلة عائمة إلى مكونات كسرية وصحيحة

المكتبة

مكتبة الرياضيات (libm، -lm)

الملخص

#include <math.h>
double frexp(double x, int *e);
float frexpf(float x, int *e);
long double frexpl(long double x, int *e);
متطلبات ماكرو اختبار الميزة لـ glibc (انظر feature_test_macros(7)):

frexpf()، frexpl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

الوصف

تُستخدم هذه الدوال لتقسيم الرقم x إلى كسر طبيعي وأس يتم تخزينه في e.

قيمة الإرجاع

تُرجع هذه الدوال الكسر الطبيعي. إذا لم يكن المعامل x صفرًا، فإن الكسر الطبيعي هو x مضروبًا في قوة من اثنين، وقيمته المطلقة دائمًا في النطاق من 1/2 (شامل) إلى 1 (حصري)، أي [0.5,1).

إذا كان x صفرًا، فإن الكسر الطبيعي يكون صفرًا ويتم تخزين صفر في e.

إذا كان x قيمة NaN (ليس رقمًا)، فسيتم إرجاع NaN، وقيمة *e غير محددة.

إذا كان x ما لا نهاية موجبة (ما لا نهاية سالبة)، فسيتم إرجاع ما لا نهاية موجبة (ما لا نهاية سالبة)، وقيمة *e غير محددة.

الأخطاء

لا تحدث أخطاء.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
frexp ()، frexpf ()، frexpl () الأمان من حيث تعدد الخيوط آمن لـ MT

المعايير

C11، POSIX.1-2008.

التاريخ

C99، POSIX.1-2001.

المتغير الذي يُرجع double يتوافق أيضًا مع SVr4، 4.3BSD، C89.

أمثلة

البرنامج أدناه ينتج نتائج مثل ما يلي:


$ ./a.out 2560
frexp(2560, &e) = 0.625: 0.625 * 2^12 = 2560
$ ./a.out -4
frexp(-4, &e) = -0.5: -0.5 * 2^3 = -4

مصدر البرنامج

#include <float.h>
#include <math.h>
#include <stdio.h>
#include <stdlib.h>
int
main(int argc, char *argv[])
{
    double x, r;
    int e;
    x = strtod(argv[1], NULL);
    r = frexp(x, &e);
    printf("frexp(%g, &e) = %g: %g * %d^%d = %g\n", x, r, r, 2, e, x);
    exit(EXIT_SUCCESS);
}
