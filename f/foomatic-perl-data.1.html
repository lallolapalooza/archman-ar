FOOMATIC-PERL-DATA(1) دليل الأوامر العامة FOOMATIC-PERL-DATA(1)

الاسم

foomatic-perl-data - إنشاء هياكل بيانات Perl من XML

الملخص

foomatic-perl-data [ -O ] [ -C ] [ -P ] [ -D ] [ -o option=setting ] [ -o ... ] [ -v ] [ filename ]

خيارات

-O تحليل بيانات XML النظرة العامة

-C تحليل بيانات XML مجمعات الطابعة/برنامج التشغيل (الافتراضي)

-P تحليل بيانات إدخال الطابعة

-D تحليل بيانات إدخال برنامج التشغيل

-o option=setting إعدادات الخيارات الافتراضية لبيانات Perl التي تم إنشاؤها (مجمع فقط)

-v وضع مطول (تصحيح الأخطاء)

filename قراءة الإدخال من ملف وليس من الإدخال القياسي

حالة الخروج

foomatic-perl-data تعيد ...

المؤلف

مانفريد فاسمان <manolo@NCC-1701.B.Shuttle.de> لمشروع foomatic باستخدام مخرجات البرنامج الثنائي المرتبط.
