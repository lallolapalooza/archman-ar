fi_compare_atomicv(3)

الحزمة: libfabric

التراخيص: BSD-2-Clause OR GPL-2.0-or-later

NAME

fi_compare_atomicv — Compare and swap values for multiple atomic operations

SYNOPSIS

int fi_compare_atomicv(struct fid_mr *mr, const void *buf, uint64_t compare, void *swap, uint64_t *desc, void *desc_ctx, uint64_t count);

ARGUMENTS

mr
Fabric memory region handle.
buf
Pointer to the buffer containing the values to compare and swap.
compare
The value to compare against.
swap
The value to swap with if the compare succeeds.
desc
Array of descriptors for the atomic operations.
desc_ctx
User-specified context for the descriptors.
count
The number of atomic operations to perform.

DESCRIPTION

The fi_compare_atomicv function performs a compare and swap operation on multiple memory locations specified by the desc array. For each element in the desc array, the function compares the value at the memory location with the compare value. If the values match, the value at the memory location is replaced with the swap value.

The operation is performed atomically for each element. The buf argument is not used directly by this function but is passed to the underlying fabric provider.

The desc array contains descriptors that specify the target memory locations and other parameters for the atomic operations. The format of the descriptors depends on the underlying fabric provider.

The desc_ctx argument is a user-defined context that can be associated with each descriptor. This context can be used to track the completion of individual atomic operations.

The count argument specifies the number of atomic operations to perform.

FLAGS

This function does not support any flags.

RETURN VALUE

On success, fi_compare_atomicv returns 0. On failure, it returns a negative error code.

ERRORS

-FI_ENOMSG
No message available.
-FI_EADDRNOTAVAIL
Address not available.
-FI_EBUSY
Resource busy.
-FI_ENOMEM
Out of memory.
-FI_EFAULT
Bad address.
-FI_EINVAL
Invalid argument.

NOTES

The behavior of this function is dependent on the underlying fabric provider and its support for atomic operations.

The format of the descriptors in the desc array is provider-specific. Consult the documentation for your fabric provider for details.
