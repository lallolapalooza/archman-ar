FMIN(3P) دليل مبرمج POSIX FMIN(3P)

PROLOG

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق لينكس لهذه الواجهة (استشر صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة على لينكس.

NAME

fmin, fminf, fminl — تحديد الحد الأدنى للقيمة العددية لرقمين فاصلين عائمين

SYNOPSIS

#include <math.h>
double fmin(double x, double y);
float fminf(float x, float y);
long double fminl(long double x, long double y);

DESCRIPTION

تتوافق الوظائف الموصوفة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموصوفة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

يجب على هذه الدوال تحديد الحد الأدنى للقيمة العددية لمعاملاتها. سيتم التعامل مع معاملات NaN (ليس رقمًا) كبيانات مفقودة: إذا كان أحد المعاملات NaN والآخر رقميًا، فستختار هذه الدوال القيمة العددية.

RETURN VALUE

عند الانتهاء بنجاح، يجب أن تعيد هذه الدوال الحد الأدنى للقيمة العددية لمعاملاتها.

إذا كان أحد المعاملات فقط NaN، فيجب إعادة المعامل الآخر.

إذا كان x و y كلاهما NaN، فيجب إعادة NaN.

ERRORS

لا توجد أخطاء معرفة.
