puts(3) دليل الدوال المكتبية puts(3)

الاسم

fputc, fputs, putc, putchar, puts - إخراج الأحرف والسلاسل النصية

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdio.h>
int fputc(int c, FILE *stream);
int putc(int c, FILE *stream);
int putchar(int c);
int fputs(const char *restrict s, FILE *restrict stream);
int puts(const char *s);

الوصف

تكتب الدالة fputc() الحرف c، بعد تحويله إلى unsigned char، إلى stream.

الدالة putc() مكافئة للدالة fputc() باستثناء أنها قد تُنفذ كـ ماكرو قد يقيم stream أكثر من مرة.

putchar(c) مكافئة لـ putc(c, stdout).

تكتب الدالة fputs() السلسلة النصية s إلى stream، بدون بايت الإنهاء الصفري ('\0').

تكتب الدالة puts() السلسلة النصية s وسطرًا جديدًا لاحقًا إلى stdout.

يمكن خلط استدعاءات الدوال الموصوفة هنا مع بعضها البعض ومع استدعاءات لدوال إخراج أخرى من مكتبة stdio لنفس دفق الإخراج.

للنظائر التي لا تتطلب قفلًا، انظر unlocked_stdio(3).

قيمة الإرجاع

تعيد الدالتان fputc() و putc() و putchar() الحرف المكتوب كـ unsigned char محول إلى int أو EOF في حالة حدوث خطأ.

تعيد الدالتان puts() و fputs() عددًا غير سالب عند النجاح، أو EOF في حالة حدوث خطأ.

الأخطاء

لا يُنصح بخلط استدعاءات دوال الإخراج من مكتبة stdio مع استدعاءات منخفضة المستوى للدالة write(2) لمعرّف الملف المرتبط بنفس دفق الإخراج؛ ستكون النتائج غير محددة وعلى الأرجح ليست ما تريده.
