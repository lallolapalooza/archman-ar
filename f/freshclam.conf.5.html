freshclam.conf(5)

الحزمة: clamav

التراخيص: GPL-2.0-only

DESCRIPTION

The freshclam.conf(5) configuration file contains configuration options for the freshclam(1) utility.

FILE FORMAT

The configuration file consists of a list of configuration directives. Each directive is on a separate line, and may optionally be followed by an argument. Arguments containing spaces must be enclosed in quotes. Lines starting with a semicolon (;) and empty lines are ignored.

DIRECTIVES

DatabaseMirror TYPE,HOST
The DatabaseMirror directive specifies a mirror server to download virus definition databases from. The TYPE can be http, https or ftp. The HOST can be a hostname or an IP address. This directive can be specified multiple times. If no DatabaseMirror is specified, freshclam(1) will use the official mirror servers. It is recommended to specify at least one mirror for private networks or to balance the load on the official mirrors. The official mirrors are located at database.clamav.net.
DatabaseOwner USERNAME
The DatabaseOwner directive specifies the user who owns the virus definition database files. This option is useful when running freshclam(1) as root to change the ownership of the downloaded databases to a different user.
Default: the user running freshclam(1).
DatabaseDirectory DIRECTORY
The DatabaseDirectory directive specifies the directory where virus definition databases are stored.
Default: /var/lib/clamav.
PidFile PATH
The PidFile directive specifies the path to the file that will contain the process ID of freshclam(1) when running in daemon mode.
Default: /var/run/freshclam.pid.
LogRotate BOOL
If LogRotate is set to yes, freshclam(1) will rotate its log files when it detects that the log file has been renamed or removed. This is useful when used in conjunction with an external log rotation utility.
Default: yes
LogSyslog BOOL
If LogSyslog is set to yes, freshclam(1) will send its log messages to the syslog daemon.
Default: no
LogFile PATH
The LogFile directive specifies the path to the file that will contain the log messages from freshclam(1).
Default: /var/log/freshclam.log.
Debug BOOL
If Debug is set to yes, freshclam(1) will print verbose debug messages.
Default: no
Verbose BOOL
If Verbose is set to yes, freshclam(1) will print informational messages.
Default: no
ConnectRetries NUMBER
The number of connection retries before giving up.
Default: 3
HTTPProxyServer HOST
Use the specified HTTP proxy server to connect to the database mirror.
Default: disabled
HTTPProxyPort NUMBER
Use the specified port number for the HTTP proxy server.
Default: 8080
HTTPProxyUsername STRING
Username for HTTP proxy authentication.
Default: disabled
HTTPProxyPassword STRING
Password for HTTP proxy authentication.
Default: disabled
HTTPProxyAuthenticator STRING
Proxy authenticator string. For example, NTLM or Basic.
Default: disabled
ftpProxyServer HOST
Use the specified FTP proxy server to connect to the database mirror.
Default: disabled
ftpProxyPort NUMBER
Use the specified port number for the FTP proxy server.
Default: 2121
ftpProxyUsername STRING
Username for FTP proxy authentication.
Default: disabled
ftpProxyPassword STRING
Password for FTP proxy authentication.
Default: disabled
socksProxyServer HOST
Use the specified SOCKS proxy server to connect to the database mirror.
Default: disabled
socksProxyPort NUMBER
Use the specified port number for the SOCKS proxy server.
Default: 1080
socksProxyType TYPE

socks4:// SOCKS4 Proxy.
socks5:// SOCKS5 Proxy.
socks5h:// SOCKS5 Proxy. Proxy resolves URL hostname.
HTTPProxyUsername STR,HTTPProxyPassword STRING
Proxy usage is authenticated through given username and password.
Default: disabled
HTTPUserAgent STRING
If your servers are behind a firewall/proxy which applies User-Agent filtering, you can use this option to force the use of a different User-Agent header. As of ClamAV 0.103.3, this setting may not be used when updating from the clamav.net CDN and can only be used when updating from a private mirror.
Default: clamav/version_number
NotifyClamd STRING
Notify a running clamd(8) to reload its database after a download has occurred. The path for clamd.conf file must be provided.
Default: The default is to not notify clamd. See clamd.conf(5)'s option SelfCheck for how clamd(8) handles database updates in this case.
OnUpdateExecute STRING
Execute this command after the database has been successfully updated.
Default: disabled
OnErrorExecute STRING
Execute this command after a database update has failed.
Default: disabled
OnOutdatedExecute STRING
Execute this command when freshclam reports outdated version. In the command string %v will be replaced by the new version number.
Default: disabled
LocalIPAddress IP
Use IP as client address for downloading databases. Useful for multi homed systems.
Default: Use OS'es default outgoing IP address.
ConnectTimeout NUMBER
Timeout in seconds when connecting to database server.
Default: 10
ReceiveTimeout NUMBER
Maximum time in seconds for each download operation. 0 means no timeout.
Default: 0
Bytecode BOOL
This option enables downloading of bytecode.cvd, which includes additional detection mechanisms and improvements to the ClamAV engine.
Default: yes

FILES

/etc/clamav/freshclam.conf
