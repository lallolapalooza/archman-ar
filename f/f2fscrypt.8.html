f2fscrypt(8)

الحزمة: f2fs-tools

التراخيص: GPL

F2FSCRYPT(8) دليل مدير النظام F2FSCRYPT(8)

الاسم

f2fscrypt - أداة تشفير نظام ملفات f2fs

ملخص

f2fscrypt add_key -S [ -k keyring ] [-v] [-q] [ path ... ]
f2fscrypt new_session
f2fscrypt get_policy path ...
f2fscrypt set_policy policy path ...

الوصف

f2fscrypt يقوم بإدارة التشفير لأنظمة ملفات f2fs.

الأوامر

f2fscrypt add_key -S [ -k keyring ] [-v] [-q] [ path ... ]
يطلب من المستخدم عبارة مرور ويدخلها في مفتاح محدد. إذا لم يتم تحديد مفتاح، فسيستخدم f2fscrypt مفتاح الجلسة إذا كان موجودًا أو مفتاح جلسة المستخدم إذا لم يكن موجودًا.
إذا تم تحديد مسار واحد أو أكثر من المسارات الدليلية، فسيحاول f2fscrypt تعيين سياسة تلك الأدلة لاستخدام المفتاح الذي أدخله المستخدم للتو.
f2fscrypt get_policy path ...
يطبع السياسة للأدلة المحددة في سطر الأوامر.
f2fscrypt new_session
يعطي العملية المستدعية (عادةً ما تكون shell) مفتاح جلسة جديد، ويتجاهل مفتاح جلستها القديم.
f2fscrypt set_policy policy path ...
يعين السياسة للأدلة المحددة في سطر الأوامر. يجب أن تكون جميع الأدلة فارغة لتعيين السياسة؛ إذا كان الدليل يحتوي بالفعل على سياسة مطبقة، فسيتحقق f2fscrypt من أن السياسة تتطابق مع ما تم تحديده. السياسة هي معرف مفتاح تشفير يتكون من 16 حرفًا سداسي عشريًا.

ملاحظات

يجب أن يكون الدليل المستهدف فارغًا.

مثال

يقوم بتهيئة نظام ملفات f2fs يدعم التشفير.
# mkfs.f2fs -O encrypt /dev/sdxx
# mount /dev/sdxx /encrypted/
# mkdir /encrypted/dir
أولاً، أنشئ المفتاح في مجموعة المفاتيح باستخدام ملح بسيط
(أو قم بإنشاء ملح عشوائي).
ثم استخدمه لتعيين السياسة للدليل المراد تشفيره.
# f2fscrypt add_key -S 0x1234
  Enter passphrase (echo disabled):
  Added key with descriptor [28e21cc0c4393da1]
# f2fscrypt set_policy 28e21cc0c4393da1 /encrypted/dir
  Key with descriptor [28e21cc0c4393da1] applied to /encrypted/dir.
# touch /encrypted/dir/test.txt
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 test.txt
بعد كل إعادة تشغيل، يمكن استخدام نفس الأمر لتعيين المفتاح
فك تشفير الدليل وأبنائه.
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 zbx7tsUEMLzh+AUVMkQcnB
# f2fscrypt get_policy /encrypted/dir/
  /encrypted/dir/: 28e21cc0c4393da1
# f2fscrypt add_key -S 0x1234
  Enter passphrase (echo disabled):
  Added key with descriptor [28e21cc0c4393da1]
# ls -l /encrypted/dir/
  -rw-r--r--. 1 root root 0 Mar  5 21:41 test.txt
إظهار مجموعات مفاتيح العملية.
# keyctl show
  Session Keyring
    84022412 --alswrv      0     0  keyring: _ses
   204615789 --alswrv      0 65534   \_ keyring: _uid.0
   529474961 --alsw-v      0     0   \_ logon: f2fs:28e21cc0c4393da1
