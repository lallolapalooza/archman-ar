form_fieldtype(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

form_fieldtype(3X) استدعاءات المكتبة form_fieldtype(3X)

الاسم

form_fieldtype - تعريف أنواع حقول التحقق

الملخص

#include <form.h>
FIELDTYPE *new_fieldtype(
    bool (* const field_check)(FIELD *, const void *),
    bool (* const char_check)(int, const void *));
int free_fieldtype(FIELDTYPE *fieldtype);
int set_fieldtype_arg(
    FIELDTYPE *fieldtype,
    void *(* const make_arg)(va_list *),
    void *(* const copy_arg)(const void *),
    void  (* const free_arg)(void *));
int set_fieldtype_choice(
    FIELDTYPE *fieldtype,
    bool (* const next_choice)(FIELD *, const void *),
    bool (* const prev_choice)(FIELD *, const void *));
FIELDTYPE *link_fieldtype(FIELDTYPE *type1,
                          FIELDTYPE *type2);

الوصف

new_fieldtype

تقوم الدالة new_fieldtype بإنشاء نوع حقل جديد قابل للاستخدام للتحقق من صحة البيانات. معلمات هذه الدالة هي مؤشرات لدوال:

field_check
تقوم هذه الدالة بالتحقق من صحة سلسلة البيانات المدخلة في كل مرة يحاول المستخدم مغادرة حقل. لها وسيطتان:
  • الوسيط (FIELD *) يتم تمريره حتى يتمكن شرط التحقق من رؤية المخزن المؤقت للحقل، والأحجام، والسمات الأخرى.
  • الوسيط الثاني هو بنية كتلة وسيطات، وسيتم شرح المزيد عنها لاحقًا.
char_check
تقوم هذه الدالة بالتحقق من صحة أحرف الإدخال أثناء إدخالها. مكتبة النماذج تمررها الحرف المراد التحقق منه ومؤشر إلى بنية كتلة وسيطات.

free_fieldtype

تقوم الدالة free_fieldtype بتحرير المساحة المخصصة لنوع تحقق معين تم إنشاؤه بواسطة new_fieldtype.

set_fieldtype_arg

تقوم الدالة set_fieldtype_arg بربط ثلاث دوال لإدارة التخزين بنوع الحقل:

make_arg
يتم تطبيق هذه الدالة تلقائيًا على قائمة الوسيطات التي تعطيها set_field_type عند إرفاق التحقق من صحة الحقل. تقوم بتخزين الوسيطات في كائن كتلة وسيطات مخصص يتم استخدامه عند التحقق من صحة المدخلات.
copy_arg
يمكن للتطبيقات استخدام هذه الدالة لنسخ كتل الوسيطات.
free_arg
تحرر بنية كتلة الوسيطات.

يجب عليك توفير الدالة make_arg. الدالتان الأخريان اختياريتان: يمكنك توفير NULL لهما. في هذه الحالة، تفترض مكتبة النماذج أن make_arg لا تقوم بتخصيص الذاكرة ولكنها تقوم ببساطة بتحميل الوسيط في قيمة مفردة.

set_fieldtype_choice

يفترض محرك النماذج أن REQ_NEXT_CHOICE و REQ_PREV_CHOICE أن القيم الممكنة للحقل تشكل مجموعة مرتبة، ويوفر لمستخدم النماذج طريقة للانتقال عبر المجموعة.

تسمح الدالة set_fieldtype_choice لمبرمجي النماذج بتعريف دوال التتابع والسابق لنوع الحقل. تأخذ هذه الدوال مؤشر الحقل وبنية كتلة وسيطات كوسيطات.

link_fieldtype

تقوم الدالة link_fieldtype بإنشاء نوع حقل جديد من النوعين المعطيين. يتم ربطهما بواسطة "OR" منطقي.

قيمة الإرجاع

تُرجع الروتينات التي تُرجع مؤشرًا NULL عند حدوث خطأ. تقوم بتعيين errno وفقًا لنجاحها:

E_OK
نجح الروتين.
E_BAD_ARGUMENT
اكتشف الروتين وسيطًا غير صحيح أو خارج النطاق.
E_SYSTEM_ERROR
حدث خطأ في النظام، على سبيل المثال، فشل malloc.

تُرجع الروتينات التي تُرجع عددًا صحيحًا أحد الرموز التالية عند حدوث خطأ:

E_OK
نجح الروتين.
E_BAD_ARGUMENT
اكتشف الروتين وسيطًا غير صحيح أو خارج النطاق.
E_CONNECTED
الحقل متصل بالفعل بنموذج.
E_CURRENT
الحقل هو الحقل الحالي.
E_SYSTEM_ERROR
حدث خطأ في النظام (انظر errno(3)).

قابلية النقل

تحاكي هذه الروتينات مكتبة نماذج System V. لم تكن مدعومة في الإصدارات 7 أو BSD.
