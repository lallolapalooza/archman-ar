fgetgrent(3) دليل وظائف المكتبة fgetgrent(3)

الاسم

fgetgrent - الحصول على إدخال ملف المجموعة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <stdio.h>
#include <sys/types.h>
#include <grp.h>
struct group *fgetgrent(FILE *stream);
متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

fgetgrent():

    منذ glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 والإصدارات السابقة:
        _SVID_SOURCE

الوصف

تقوم الوظيفة fgetgrent() بإرجاع مؤشر إلى بنية تحتوي على معلومات المجموعة من الملف المشار إليه بواسطة stream. عند استدعائها للمرة الأولى، تُرجع الإدخال الأول؛ بعد ذلك، تُرجع الإدخالات المتتالية. يجب أن يكون للملف المشار إليه بواسطة stream نفس تنسيق /etc/group (انظر group(5)).

تم تعريف بنية group في <grp.h> على النحو التالي:


struct group {
    char   *gr_name;        /* اسم المجموعة */
    char   *gr_passwd;      /* كلمة مرور المجموعة */
    gid_t   gr_gid;         /* معرف المجموعة */
    char  **gr_mem;         /* مصفوفة مؤشرات منتهية بـ NULL
                               إلى أسماء أعضاء المجموعة */
};

قيمة الإرجاع

تقوم الوظيفة fgetgrent() بإرجاع مؤشر إلى بنية group، أو NULL إذا لم تكن هناك إدخالات أخرى أو حدث خطأ. في حالة حدوث خطأ، يتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

ENOMEM
ذاكرة غير كافية لتخصيص بنية group.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).
