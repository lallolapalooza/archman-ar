File__Find__Rule__Perl(3pm)

الحزمة: perl-file-find-rule-perl

File::Find::Rule::Perl(3) توثيق بيرل المساهمة File::Find::Rule::Perl(3)

الاسم

File::Find::Rule::Perl - قواعد شائعة للبحث عن أشياء متعلقة بـ Perl

الملخص

use File::Find::Rule       ();
use File::Find::Rule::Perl ();

# البحث عن جميع ملفات Perl التي تقل مساحتها عن 10 كيلو بايت
my @files = File::Find::Rule->perl_file
                            ->size('<10Ki')
                            ->in('dir');

# تحديد جميع الوحدات التي يقوم PAUSE بفهرستها
my @mod = File::Find::Rule->no_index
                          ->perl_module
                          ->in('My-Distribution');

الوصف

أكتب الكثير من الأشياء التي تتعامل مع ملفات Perl. ودائماً ما أزعجني أن العثور على "ملفات Perl" يتطلب نمط File::Find::Rule معقدًا بشكل معتدل.

File::Find::Rule::Perl يوفر طرقًا للعثور على أنواع مختلفة من الملفات المتعلقة بـ Perl، أو تكرار استعلامات البحث التي تم تشغيلها على توزيعة في أجزاء مختلفة من نظام CPAN البيئي.

الطرق

perl_module

تحدد القاعدة "perl_module" وحدات Perl. أي، الملفات التي تحمل الاسم "*.pm".

هذه القاعدة مكافئة لـ "->"file->name( '*.pm' )> ويتم تضمينها بشكل أساسي للكمال.

perl_test

تحدد القاعدة "perl_test" نصوص اختبار Perl. أي، الملفات التي تحمل الاسم "*.t".

هذه القاعدة مكافئة لـ "->"file->name( '*.t' )> ويتم تضمينها بشكل أساسي للكمال.

perl_installer

تحدد القاعدة "perl_installer" مثبتات توزيعة Perl. أي، تحدد ملفات "Makefile.PL" و "Build.PL".

perl_script

تحدد القاعدة "perl_script" نصوص Perl.

هذا هو أي ملف ينتهي بـ .pl، أو أي ملفات بدون امتدادات لها سطر "hash-bang" الخاص بـ Perl.

perl_file

تحدد القاعدة "perl_file" جميع الملفات التي تحتوي على كود Perl.

يشمل ذلك جميع الملفات التي تطابق القواعد المذكورة أعلاه "perl_module"، "perl_test"، "perl_installer" و "perl_script".

no_index

# توفير القواعد مباشرة
$rule->no_index(
    directory => [ 'inc', 't', 'examples' ],
    file      => [ 'Foo.pm', 'lib/Foo.pm' ],
);

# توفير ملف META.yml للاستخدام
$rule->no_index( 'META.yml' );

# توفير دليل جذر التوزيعة للبحث عن ملف META.yml فيه
$rule->no_index( 'My-Distribution' );

# التقاط ملف META.yml تلقائيًا من الدليل المستهدف
$rule->no_index->in( 'My-Distribution' );

تطبق القاعدة "no_index" مجموعة من القواعد وفقًا لقسم no_index في ملف "META.yml".
