fish - دليل للمستخدمين Bash

تُعدّ fish (الصدفة التفاعلية المفضلة) صدفة shell سهلة الاستخدام، ولكنها تتوافق مع bash، وهذا الدليل يفترض معرفة أساسية بـ bash.

يُستخدم فيش في كثير من الأحيان كبديل لـ bash، ولكن لديه الكثير من الميزات المتقدمة التي لا تتوافر في bash.

الميزات الرئيسية في fish:

  • الإكمال التلقائي مع اقتراحات: يكمل fish تلقائيًا أوامر والوسائط بالاستناد إلى التاريخ والملفات المتاحة.

  • إبراز بناء الجملة: يُبرز fish بناء الجملة أثناء الكتابة، مما يسهل اكتشاف الأخطاء.

  • الوصول إلى التاريخ: يمكن الوصول إلى سجل الأوامر بسهولة عن طريق الضغط على مفتاح السهم لأعلى.

  • البرمجة النصية: تُعدّ لغة البرمجة النصية في fish سهلة وقوية.

هذا الدليل يغطي بعض الاختلافات والميزات الرئيسية بين fish و bash.

أمثلة

فيما يلي بعض الأمثلة التي توضح الاختلافات بين fish و bash:

استبدال الأوامر

في bash، يتم استخدام الأقواس الخلفية ` `` ` أو الأقواس ` $(...) ` لاستبدال الأوامر. في fish، يمكنك استخدام الأقواس ` (...) ` مباشرة: 

# Bash
echo "Today is $(date)"

# Fish
echo "Today is (date)"

المتغيرات

في bash، يتم تعريف المتغيرات وتعيين قيم لها على النحو التالي: 

# Bash
MY_VAR="hello"
echo $MY_VAR

في fish، لا تحتاج إلى استخدام علامة الدولار ` $ ` عند تعيين قيمة لمتغير، ولكن تحتاج إليها عند استخدامه. 

# Fish
set MY_VAR "hello"
echo $MY_VAR

الأحرف البديلة (الجلوب)

يعمل توسيع الأحرف البديلة (الجلوب) بشكل مشابه في كلتا الصدفتين، ولكن fish لديه بعض التحسينات.

في bash، يمكنك استخدام أحرف بدل لتحديد الملفات: 

# Bash
ls *.txt

في fish، يمكنك أيضًا استخدامه، ولكنه غالبًا ما يكتمل تلقائيًا: 

# Fish
ls *.txt

علامات الاقتباس

تختلف قواعد علامات الاقتباس قليلاً بين bash و fish.

في bash، يتم استخدام علامات الاقتباس المزدوجة ` " "` لتوسيع المتغيرات والاحتفاظ بالمسافات، بينما تمنع علامات الاقتباس المفردة ` ' ' ` أي توسيع. 

# Bash
echo "My variable is $MY_VAR"
echo 'This is a literal string'

في fish، تعمل علامات الاقتباس المزدوجة ` " "` بشكل مشابه، ولكن يمكن استخدام علامات الاقتباس المفردة ` ' ' ` بشكل أقل. لدى fish أيضًا طريقة فريدة للاقتباس عن طريق وضع الاسم بين علامتي اقتباس. 

# Fish
echo "My variable is $MY_VAR"
echo 'This is a literal string'
echo "this string contains spaces"
echo 'this string contains spaces'
echo "string with \"escaped\" quotes"
echo 'string with \'escaped\' quotes'

معالجة السلاسل النصية

تُعدّ معالجة السلاسل النصية في fish أكثر قوة ومرونة. 

# Fish
set my_string "hello world"
echo $my_string[1] # يطبع 'h'
echo $my_string[-1] # يطبع 'd'
echo $my_string[1..5] # يطبع 'hello'

المتغيرات الخاصة

لدى fish مجموعة من المتغيرات الخاصة المضمنة التي تسهل المهام الشائعة. على سبيل المثال، ` $argv ` هو قائمة بالوسائط التي تم تمريرها إلى البرمجة النصية. 

# Fish
echo "First argument: $argv[1]"

استبدال العمليات

في bash، يمكنك استخدام استبدال العمليات لتمرير مخرجات أمر كملف إلى أمر آخر. في fish، يتم ذلك بشكل طبيعي. 

# Bash
diff <(command1) <(command2)

# Fish
diff (command1) (command2)

Heredocs

تدعم كلتا الصدفتين Heredocs، ولكن بناء الجملة مختلف قليلاً. 

# Bash
cat << EOF
This is line 1.
This is line 2.
EOF

# Fish
cat << EOF
This is line 1.
This is line 2.
EOF

الاختبار (test, [, [[)

لدى fish بنية ` test ` و ` [ ` و ` [[ ` مشابهة لـ bash، ولكن يمكن أن تكون أكثر قوة. 

# Fish
if test -f "myfile.txt"
  echo "myfile.txt exists"
end

if [ -f "myfile.txt" ]
  echo "myfile.txt exists"
end

if [[ -f "myfile.txt" ]]
  echo "myfile.txt exists"
end

التوسع الحسابي

تستخدم fish بناء ` math ` للتوسع الحسابي. 

# Fish
set a 5
set b 10
math $a + $b
# => 15

المطالبات

يتم تخصيص المطالبة في fish باستخدام متغيرات خاصة مثل ` fish_prompt `. 

# Fish
function fish_prompt
    printf '%s@%s %s> ' (whoami) (hostname|cut -d . -f 1) (prompt_pwd)
end

الكتل والحلقات

لدى fish بناء جملة واضح للكتل والحلقات. 

# Fish
for i in (seq 1 5)
    echo "Number: $i"
end

if status is-interactive
    echo "Interactive shell"
end

الصدفات الفرعية

يمكن تشغيل الأوامر في صدفة فرعية في fish باستخدام الأقواس ` (...) `. 

# Fish
echo (pwd)
# => /current/directory
echo (cd /tmp; pwd)
# => /tmp
echo (pwd)
# => /current/directory

الأوامر المضمنة والأوامر الأخرى

تختلف بعض الأوامر المضمنة وأسماؤها عن bash. على سبيل المثال، ` cd ` هو أمر مضمن في كليهما، ولكن fish لديه أيضًا ` chdir ` كاسم مستعار.

الأمر ` ls ` في fish له إخراج ملون افتراضي وأدوات مفيدة.

مرافق أخرى

يقدم fish العديد من المرافق الأخرى مثل ` type ` (لاستكشاف الأوامر)، ` history ` (لإدارة سجل الأوامر)، و ` bind ` (لتخصيص اختصارات لوحة المفاتيح).
