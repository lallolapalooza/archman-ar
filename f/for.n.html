for(n)

الحزمة: tcl

for(n) أوامر Tcl المضمنة for(n)

الاسم

for - حلقة 'For'

الموجز

for start test next body

الوصف

For هو أمر تكراري، مشابه في هيكله لبيان C for. يجب أن تكون الوسائط start و next و body عبارة عن سلاسل أوامر Tcl، و test هو سلسلة تعبير. يستدعي أمر for أولاً مترجم Tcl لتنفيذ start. ثم يقوم بتقييم test بشكل متكرر كتعبير؛ إذا كانت النتيجة غير صفرية، فإنه يستدعي مترجم Tcl على body، ثم يستدعي مترجم Tcl على next، ثم يكرر الحلقة. ينتهي الأمر عندما يتم تقييم test إلى 0. إذا تم استدعاء أمر continue داخل body، فسيتم تخطي أي أوامر متبقية في التنفيذ الحالي لـ body؛ تستمر المعالجة عن طريق استدعاء مترجم Tcl على next، ثم تقييم test، وهكذا. إذا تم استدعاء أمر break داخل body أو next، فسيعود أمر for فورًا. تشبه عملية break و continue البيانات المقابلة في C. يعيد For سلسلة فارغة.

ملاحظة: يجب تقريب test تقريبًا دائمًا في أقواس معقوفة. إذا لم يكن الأمر كذلك، فسيتم إجراء استبدالات المتغيرات قبل بدء تنفيذ أمر for، مما يعني أن التغييرات التي تم إجراؤها على المتغيرات بواسطة جسم الحلقة لن تؤخذ في الاعتبار في التعبير. من المحتمل أن يؤدي هذا إلى حلقة لا نهائية. إذا تم تقريب test في أقواس معقوفة، فسيتم تأجيل استبدالات المتغيرات حتى يتم تقييم التعبير (قبل كل تكرار للحلقة)، وبالتالي ستكون التغييرات في المتغيرات مرئية. انظر أدناه مثالاً:

أمثلة

طباعة سطر لكل عدد صحيح من 0 إلى 9:

for {set x 0} {$x<10} {incr x} {
    puts "x is $x"
}

إما حلقة لا نهائية أو عدم حدوث أي شيء لأن التعبير الذي يتم تقييمه هو في الواقع ثابت، أو حتى توليد خطأ! سيعتمد السلوك الفعلي على ما إذا كان المتغير x موجودًا قبل تشغيل أمر for وما إذا كانت قيمته أقل من أو أكبر من/تساوي عشرة، وذلك لأن التعبير سيتم استبداله قبل تنفيذ أمر for.

for {set x 0} $x<10 {incr x} {
    puts "x is $x"
}

طباعة قوى الرقم اثنين من 1 إلى 1024:

for {set x 1} {$x<=1024} {set x [expr {$x * 2}]} {
    puts "x is $x"
}
