NAME

\n

fping - send ICMP ECHO_REQUEST packets to network hosts

\n
\n
\n

SYNOPSIS

\n

fping [ options ] [ systems... ]

\n
\n
\n

DESCRIPTION

\n

fping is a program like ping which uses the Internet\n Control Message Protocol (ICMP) echo request to determine if a target host\n is responding. fping differs from ping in that you can specify\n any number of targets on the command line, or specify a file containing the\n lists of targets to ping. Instead of sending to one target until it times\n out or replies, fping will send out a ping packet and move on to the\n next target in a round-robin fashion. In the default mode, if a target\n replies, it is noted and removed from the list of targets to check; if a\n target does not respond within a certain time limit and/or retry limit it is\n designated as unreachable. fping also supports sending a specified\n number of pings to a target, or looping indefinitely (as in ping ).\n Unlike ping, fping is meant to be used in scripts, so its\n output is designed to be easy to parse. Current statistics can be obtained\n without termination of process with signal SIGQUIT (^\ from the keyboard on\n most systems).

\n
\n
\n

OPTIONS

\n
\n
-4, --ipv4
\n
Restrict name resolution and IPs to IPv4 addresses.
\n
-6, --ipv6
\n
Restrict name resolution and IPs to IPv6 addresses.
\n
-a, --alive
\n
Show systems that are alive. (Options -c and -C override\n -a.)
\n
-A, --addr
\n
Display targets by address rather than DNS name. Combined with -d, the\n output will be both the ip and (if available) the hostname.
\n
-b,\n --size=BYTES
\n
Number of bytes of ping data to send. The minimum size (normally 12) \n allows room for the data that fping needs to do its work (sequence\n number, timestamp). The reported received data size includes the IP header\n (normally 20 bytes) and ICMP header (8 bytes), so the minimum total size\n is 40 bytes. Default is 56, as in ping. Maximum is the theoretical\n maximum IP datagram size (64K), though most systems limit this to a\n smaller, system-dependent number. Cannot be used together with\n --icmp-timestamp.
\n
-B,\n --backoff=N
\n
Backoff factor. In the default mode, fping sends several requests\n to a target before giving up, waiting longer for a reply on each\n successive request. This parameter is the value by which the wait time\n (-t) is multiplied on each successive request; it must be entered\n as a floating-point number (x.y). The default is 1.5.
\n
-c,\n --count=N
\n
Number of request packets to send to each target. In this mode, a line is\n displayed for each received response (this can suppressed with -q\n or -Q). Also, statistics about responses for each target are\n displayed when all requests have been sent (or when interrupted). This\n option overrides -a or -u.
\n
-C,\n --vcount=N
\n
Similar to -c, but the per-target statistics are displayed in a\n format designed for automated response-time statistics gathering. For\n example:\n 
$ fping -C 5 -q somehost\nsomehost : 91.7 37.0 29.2 - 36.8\n
\n

shows the response time in milliseconds for each of the five\n requests, with the "-" indicating that\n no response was received to the fourth request. This option overrides\n -a or -u.

\n
\n
--check-source
\n
Discard Echo replies that are sourced from a different address than the\n target address. This avoids spurious reachability results on busy\n monitoring systems where two fping instances with the same lower 16\n bits of the process ID may be running at the same time.
\n
-d, --rdns
\n
Use DNS to lookup address of ping target. This allows you to give fping a\n list of IP addresses as input and print hostnames in the output. This is\n similar to option -n/--name, but will force a reverse-DNS\n lookup even if you give hostnames as target (NAME->IP->NAME).
\n
-D,\n --timestamp
\n
Add Unix timestamps in front of output lines generated with in looping or\n counting modes (-l, -c, or -C).\n

Subcommand:\n --timestamp-format=ctime|iso|rfc3339

\n

Allow to change the timestamp format of the -D option\n to the following format types.

\n

ctime = "%c" (Example: Mon Jun 10 07:50:00\n 2024)

\n

iso = "%Y-%m-%dT%T%z" (Example:\n 2024-06-10T07:50:00+0200)

\n

rfc3339 = "%Y-%m-%d\n %H:%M:%S" (Example: 2024-06-10\n 07:50:00)

\n
\n
-e, --elapsed
\n
Show elapsed (round-trip) time of packets.
\n
-f, --file
\n
Read list of targets from a file.
\n
-g, --generate\n addr/mask
\n
Generate a target list from a supplied IP netmask, or a starting and\n ending IP. Specify the netmask or start/end in the targets portion of the\n command line. If a network with netmask is given, the network and\n broadcast addresses will be excluded. ex. To ping the network\n 192.168.1.0/24, the specified command line could look like either:\n 
$ fping -g 192.168.1.0/24\n
\n

or

\n 
$ fping -g 192.168.1.1 192.168.1.254\n
\n
\n
-h, --help
\n
Print usage message.
\n
-H,\n --ttl=N
\n
Set the IP TTL field (time to live hops).
\n
--print-ttl
\n
Displays the IPv4 TTL value from the IP Header in the output. If\n fping cannot read the TTL value, "(TTL unknown)" is\n returned. IPv4 only, requires root privileges or cap_net_raw.
\n
-i,\n --interval=MSEC
\n
The minimum amount of time (in milliseconds) between sending a ping packet\n to any target (default is 10, minimum is 1).
\n
-I,\n --iface=IFACE
\n
Set the interface (requires SO_BINDTODEVICE support).
\n
--icmp-timestamp
\n
Send ICMP timestamp requests (ICMP type 13) instead of ICMP Echo requests.\n Print ICMP timestamps for originate, receive, and transmit, together with\n the local receive time in the same format, in addition to normal output.\n Cannot be used together with -b because ICMP timestamp messages\n have a fixed size. IPv4 only, requires root privileges or\n cap_net_raw.
\n
-k,\n --fwmark=FWMARK
\n
Set FWMARK on ping packets for policy-based routing. Requires Linux kernel\n 2.6.25<=, and root privileges or cap_net_admin.
\n
-l, --loop
\n
Loop sending packets to each target indefinitely. Can be interrupted with\n Ctrl-C; statistics about responses for each target are then\n displayed.
\n
-m, --all
\n
Send pings to each of a target host's multiple IP addresses (use of option\n '-A' is recommended).
\n
-M,\n --dontfrag
\n
Set the \"Don't Fragment\" bit in the IP header (used to\n determine/test the MTU).
\n
-n, --name
\n
If targets are specified as IP addresses, do a reverse-DNS lookup on them\n to print hostnames in the output.
\n
-N, --netdata
\n
Format output for netdata (-l -Q are required). See:\n https://netdata.cloud/
\n
-o, --outage
\n
Calculate \"outage time\" based on the number of lost pings and\n the interval used (useful for network convergence tests).
\n
