الملخص

#include <../fribidi/lib/fribidi.h>

void fribidi_get_bracket_types
(
const FriBidiChar *str,
const FriBidiStrIndex len,
const FriBidiCharType *types,
FriBidiBracketType *btypes
);

المعلمات

الوصف

تجد هذه الدالة الأحرف المقوسة لسلسلة من الأحرف. انظر fribidi_get_bracket() لمزيد من المعلومات حول الأحرف المقوسة التي تم إرجاعها بواسطة هذه الدالة.
