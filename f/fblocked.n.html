fblocked(n)

الحزمة: tcl

التراخيص: TCL

fblocked(n) أوامر Tcl المضمنة fblocked(n)

الاسم

fblocked - اختبار ما إذا كانت آخر عملية إدخال قد استنفدت كل الإدخال المتاح

الملخص

fblocked معرف_القناة

الوصف

يعيد الأمر fblocked القيمة 1 إذا كانت آخر عملية إدخال على معرف_القناة قد أعادت معلومات أقل مما هو مطلوب لأن كل الإدخال المتاح قد استنفد. على سبيل المثال، إذا تم استدعاء gets عندما تكون هناك ثلاثة أحرف فقط متاحة للإدخال ولا يوجد تسلسل نهاية سطر، فإن gets يعيد سلسلة فارغة واستدعاء لاحق لـ fblocked سيعيد القيمة 1.

يجب أن يكون معرف_القناة معرفًا لقناة مفتوحة مثل قناة Tcl قياسية (stdin، stdout، أو stderr)، أو القيمة التي يتم إرجاعها من استدعاء open أو socket، أو نتيجة لأمر إنشاء قناة مقدم من ملحق Tcl.

مثال

الأمر fblocked مفيد بشكل خاص عند كتابة خوادم الشبكة، لأنه يسمح لك بكتابة التعليمات البرمجية الخاصة بك بأسلوب سطر بسطر دون منع خدمة الاتصالات الأخرى. يمكن رؤية ذلك في خدمة الصدى البسيطة هذه:

# يتم استدعاء هذا كلما اتصل عميل جديد بالخادم proc connect {chan host port} {
set clientName [format <%s:%d> $host $port]
puts "connection from $clientName"
fconfigure $chan -blocking 0 -buffering line
fileevent $chan readable [list echoLine $chan $clientName] }

# يتم استدعاء هذا كلما توفرت بايت واحد على الأقل من بيانات الإدخال #، أو تم إغلاق القناة بواسطة العميل. proc echoLine {chan clientName} {
gets $chan line
if {[eof $chan]} {
puts "finishing connection from $clientName"
close $chan
} elseif {![fblocked $chan]} {
# لم ينتظر لحظر نهاية السطر
puts "$clientName - $line"
puts $chan $line
} }

# إنشاء مقبس الخادم والدخول في حلقة الأحداث للانتظار # للاتصالات الواردة... socket -server connect 12345 vwait forever
