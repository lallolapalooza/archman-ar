FEGETROUND(3P) دليل مبرمج POSIX FEGETROUND(3P)

مقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذا الواجهة (استشر صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

fegetround, fesetround — الحصول على اتجاه التقريب الحالي وتعيينه

التركيب

#include <fenv.h>
int fegetround(void);
int fesetround(int round);

الوصف

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذه الوحدة من POSIX.1-2017 تحيل إلى معيار ISO C.

تقوم الدالة fegetround() بالحصول على اتجاه التقريب الحالي.

تقوم الدالة fesetround() بإنشاء اتجاه التقريب الذي تمثله وسيطتها round. إذا لم تكن الوسيطة مساوية لقيمة ماكرو اتجاه التقريب، فلن يتغير اتجاه التقريب.

قيمة الإرجاع

تعيد الدالة fegetround() قيمة ماكرو اتجاه التقريب الذي يمثل اتجاه التقريب الحالي أو قيمة سالبة إذا لم يكن هناك ماكرو اتجاه تقريب كهذا أو لم يكن اتجاه التقريب الحالي قابلاً للتحديد.

تعيد الدالة fesetround() قيمة صفرية إذا وفقط إذا تم إنشاء اتجاه التقريب المطلوب.

الأخطاء

لا توجد أخطاء معرفة.

الأقسام التالية معلوماتية.

أمثلة

يقوم المثال التالي بحفظ اتجاه التقريب وتعيينه وإعادته، والإبلاغ عن خطأ والإجهاض إذا فشل تعيين اتجاه التقريب:

#include <fenv.h>
#include <assert.h>
void f(int round_dir)
{
    #pragma STDC FENV_ACCESS ON
    int save_round;
    int setround_ok;
    save_round = fegetround();
    setround_ok = fesetround(round_dir);
    assert(setround_ok == 0);
    /* ... */
    fesetround(save_round);
    /* ... */
}
