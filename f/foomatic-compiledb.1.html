FOOMATIC-COMPILEDB(1) دليل الأوامر العامة FOOMATIC-COMPILEDB(1)

الاسم

foomatic-compiledb - تجميع قاعدة بيانات طابعات/برامج تشغيل Foomatic

ملخص

foomatic-compiledb [ -t type ] [ -f ] [ -j n ] [  driver ...  ]

الوصف

يقوم foomatic-compiledb بإنشاء جميع ملفات PPD أو ملفات XML المجمعة لـ Foomatic لجميع مجموعات الطابعات/برامج التشغيل الممكنة، أو فقط لمجموعة محددة من برامج التشغيل. بشكل عام، لا ينبغي أن يكون ضروريًا باستثناء الأشخاص الذين يرغبون في إنشاء مجموعة من ملفات بيانات Foomatic للتوزيع. لتكوين طابعات فردية، تقوم foomatic-ppdfile(1)، وخاصة foomatic-configure(1)، بحساب ما يحتاجونه تلقائيًا.

خيارات

-t type
نوع ملف الإخراج، إما ppd أو xml.
-f
فرض: الكتابة في المجلد الوجهة حتى لو كان موجودًا بالفعل.
-j n
n = عدد عمليات العمل المراد تشغيلها
driver ...
إنشاء ملفات بيانات لهذه (لهذه) برامج التشغيل فقط

انظر أيضا

foomatic-ppdfile(1)،foomatic-configure(1)

حالة الخروج

يعيد foomatic-compiledb القيمة 0 ما لم يحدث شيء غير متوقع.

المؤلفون

مانفريد واسمان <manolo@NCC-1701.B.Shuttle.de> وتيل كامبيتر <till.kamppeter@gmail.com> لمشروع foomatic باستخدام المخرجات من الملف الثنائي المرتبط.

الأخطاء

يتم الاحتفاظ بالملفات الموجودة دائمًا بدلاً من الكتابة فوق الملفات الأقدم. لذا يوصى بحذف المجلد الوجهة (rm -rf dir) واستدعاء foomatic-compiledb بدون الخيار -f.

يرجى نشر تقارير الأخطاء على

http://lists.freestandards.org/mailman/listinfo/printing-foomatic
