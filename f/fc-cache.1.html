fc-cache(1)

الحزمة: fontconfig

التراخيص: HPND AND Unicode-DFS-2016

FC-CACHE(1) FC-CACHE(1)

الاسم

fc-cache - بناء ملفات معلومات الخطوط المخزنة مؤقتًا

ملخص

fc-cache [ -EfrsvVh ] [ --error-on-no-fonts ] [ --force ] [ --really-force ] [ -y dir | --sysroot dir ] [ --system-only ] [ --verbose ] [ --version ] [ --help ] [ dir ... ]

الوصف

يقوم fc-cache بفحص أدلة الخطوط على النظام وبناء ملفات معلومات الخطوط المخزنة مؤقتًا للتطبيقات التي تستخدم fontconfig لمعالجة الخطوط.

إذا لم يتم تقديم وسائط الدليل، يستخدم fc-cache كل دليل في تكوين الخط الحالي. يتم فحص كل دليل بحثًا عن ملفات الخطوط التي يمكن لـ FreeType قراءتها. يتم إنشاء مخزن مؤقت يحتوي على خصائص كل خط والملف المرتبط به. يستخدم هذا المخزن المؤقت لتسريع بدء تشغيل التطبيقات عند استخدام مكتبة fontconfig.

لاحظ أنه يجب تشغيل fc-cache مرة واحدة لكل بنية لإنشاء معلومات خطوط مخصصة لتلك البنية.

الخيارات

يتبع هذا البرنامج صيغة سطر الأوامر المعتادة لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتم تضمين ملخص للخيارات أدناه.

-E --error-on-no-fonts
رفع خطأ إذا لم يكن هناك خطوط في dir أو الأدلة في التكوين إذا لم يتم تقديمها.
-f --force
فرض إعادة إنشاء ملفات المخزن المؤقت التي تبدو محدثة، متجاوزًا التحقق من الطابع الزمني.
-r --really-force
مسح جميع ملفات المخزن المؤقت الموجودة وإعادة الفحص.
-s --system-only
فحص الأدلة على مستوى النظام فقط، مع استبعاد الأماكن الموجودة في الدليل الرئيسي للمستخدم.
-v --verbose
عرض معلومات الحالة أثناء التشغيل.
-y -sysroot dir
إضافة dir إلى جميع المسارات للفحص.
-h --help
عرض ملخص للخيارات.
-V --version
عرض إصدار البرنامج والخروج.
dir
الدليل المراد فحصه للخطوط.

رموز الإرجاع

يعيد fc-cache صفرًا إذا تم إنشاء المخازن المؤقتة بنجاح. بخلاف ذلك، يعيد غير صفر.

الملفات

%cachedir%/*-%arch%.cache-%version%
يتم إنشاء هذه الملفات بواسطة fc-cache وتحتوي على خرائط من أسماء الملفات إلى خصائص الخطوط. تقرأها مكتبة fontconfig عند بدء تشغيل التطبيق لتحديد الخطوط المناسبة.
