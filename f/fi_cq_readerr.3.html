fi_cq_readerr(3)

الحزمة: libfabric

التراخيص: BSD-2-Clause OR GPL-2.0-or-later

NAME

fi_cq_readerr — read an error completion from a completion queue

SYNOPSIS

#include <rdma/fabric.h>

int fi_cq_readerr(fi_cq_t *cq, void *buf, uint64_t count);

ARGUMENTS

- cq
The completion queue (CQ) to read from. A valid handle must be supplied.
- buf
The buffer to store the completion data. The buffer must be large enough to hold count number of fi_cq_entry structures. If buf is NULL, the function will not store any data but will return the number of available error completions.
- count
The maximum number of error completions to retrieve from the CQ. Must be greater than 0.

DESCRIPTION

The fi_cq_readerr function reads one or more error completions from the specified completion queue (cq).fi_cq_entry structure.

The fi_cq_readerr function is intended to be used with completion queues that support asynchronous error reporting. When an operation fails, the corresponding error information is posted to the CQ as an error completion.

The buf parameter points to the memory region where the retrieved error completions will be stored. The count parameter specifies the maximum number of error completions to be read. If buf is NULL, fi_cq_readerr will return the number of error completions currently available in the CQ without consuming them.

The function will attempt to read up to count error completions. If fewer are available, it will return the number of completions successfully read.

Error completions are distinct from regular completions and are typically associated with operations that did not complete successfully. They contain specific error codes and status information.

COMPLETION FIELDS

Each returned fi_cq_entry structure will contain the following fields relevant to error completions:

error
Fabric error code. This field is valid only for error completions.
flags
Flags associated with the completion. This field may contain specific error-related flags.
op_context
User-defined context associated with the operation that generated the error.
len
Indicates the number of bytes transferred for the operation that caused the error. This may not always be applicable or meaningful for error completions.
src_addr
The source address associated with the error, if applicable.
perf_data
Performance data, if enabled and applicable.

COMPLETION FLAGS

The flags field within the returned fi_cq_entry structure may contain specific flags indicating the nature of the error or completion. Common flags include:

FI_ERROR
This flag is always set for error completions returned by fi_cq_readerr.
FI_ More
Indicates that there are more completions pending in the CQ.
FI_ASYNC_ERR
Indicates an asynchronous error occurred.
FI_TX_ERROR
Indicates a transmit error.
FI_RX_ERROR
Indicates a receive error.

Refer to the Fabric API documentation for a complete list of completion flags.

COMPLETION EVENT SEMANTICS

When using event-driven CQs (e.g., those associated with an event queue), an error completion will trigger an event. The event data will contain information about the error completion.

TARGET COMPLETION SEMANTICS

fi_cq_readerr can be used with both event-driven and polled completion queues. For polled CQs, it provides a mechanism to explicitly retrieve error information.

NOTES

The function behaves similarly to fi_cq_read, but it specifically retrieves error completions. If an operation fails, the error information will be posted as an error completion, which can then be retrieved using fi_cq_readerr.

If count is larger than the number of available error completions, only the available completions will be returned. The caller should check the return value to determine the actual number of completions read.

It is important to handle errors gracefully. Applications should periodically check for error completions to identify and respond to operational failures.

The specific error codes returned in the error field are defined in rdma/fi_errno.h.

RETURN VALUES

On success, fi_cq_readerr returns the number of error completions read from the CQ, which will be less than or equal to count. If buf is NULL, it returns the number of error completions currently available.

On failure, fi_cq_readerr returns a negative errno value.

  • EAGAIN: No error completions are currently available. This is not considered an error.
  • EBADF: The specified CQ handle is invalid.
  • EINVAL: An invalid argument was provided (e.g., count is zero).
  • ENOMEM: Insufficient memory available.
  • EIO: An I/O error occurred.

Refer to fi_strerror(3) for a description of possible error codes returned with a completion.

Fabric errno values are defined in rdma/fi_errno.h.
