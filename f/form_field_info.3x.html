form_field_info(3x)

الحزمة: ncurses

التراخيص: MIT-open-group

form_field_info(3X) استدعاءات المكتبة form_field_info(3X)

الاسم

dynamic_field_info, field_info - استرداد خصائص الحقل

الملخص

#include <form.h>
int field_info(const FIELD *field,
               int *rows, int *cols,
               int *frow, int *fcol,
               int *nrow, int *nbuf);
int dynamic_field_info(const FIELD *field,
                       int *rows, int *cols, int *max);

الوصف

تقوم الدالة field_info بإرجاع الأحجام والسمات الأخرى التي تم تمريرها إلى الحقل عند إنشائه. السمات هي: الارتفاع، العرض، صف الزاوية العلوية اليسرى، عمود الزاوية العلوية اليسرى، عدد الصفوف خارج الشاشة، وعدد المخازن العاملة.

تقوم الدالة dynamic_field_info بإرجاع الحجم الفعلي للحقل، وحجمه الأقصى الممكن. إذا لم يكن للحقل حد حجم، فسيتم تعيين الموقع الذي تشير إليه الوسيطة الثالثة إلى 0. يمكن جعل الحقل ديناميكيًا عن طريق إيقاف تشغيل الخيار O_STATIC باستخدام field_opts_off.

قيمة الإرجاع

تقوم هذه الروتينات بإرجاع واحد مما يلي:

E_OK
نجحت الروتين.
E_SYSTEM_ERROR
حدث خطأ في النظام (انظر errno(3)).
E_BAD_ARGUMENT
اكتشفت الروتين وسيطة غير صحيحة أو خارج النطاق.

قابلية النقل

هذه الروتينات تحاكي مكتبة النماذج System V. لم تكن مدعومة في الإصدارات 7 أو BSD.

يتم قبول مؤشر فارغ (مؤشر صفري) لأي من قيم الإرجاع، لتجاهل تلك القيمة. ليست كل التطبيقات تسمح بذلك، على سبيل المثال، Solaris 2.7 لا يسمح بذلك.
