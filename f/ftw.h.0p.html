ftw.h(0P) دليل مبرمج POSIX ftw.h(0P)

PROLOG

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق لينكس لهذه الواجهة (استشر صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا يتم تطبيق الواجهة على لينكس.

NAME

ftw.h — اجتياز شجرة الملفات

SYNOPSIS

#include <ftw.h>

DESCRIPTION

سيحدد الرأس <ftw.h> بنية FTW، والتي يجب أن تتضمن على الأقل الأعضاء التالية:

int  base
int  level

سيحدد الرأس <ftw.h> الثوابت الرمزية التالية لاستخدامها كقيم للحجة الثالثة للدالة التي يوفرها التطبيق والتي تمرر كحجة ثانية إلى ftw() و nftw():

FTW_F
ملف غير دليل.
FTW_D
دليل.
FTW_DNR
دليل بدون إذن قراءة.
FTW_DP
دليل مع زيارة الدلائل الفرعية.
FTW_NS
نوع غير معروف؛ فشل stat().
FTW_SL
رابط رمزي.
FTW_SLN
رابط رمزي يشير إلى ملف غير موجود.

سيحدد الرأس <ftw.h> الثوابت الرمزية التالية لاستخدامها كقيم للحجة الرابعة إلى nftw():

FTW_PHYS
اجتياز فيزيائي، لا يتبع الروابط الرمزية. بخلاف ذلك، nftw() يتبع الروابط ولكنه لا يجتاز أي مسار يتقاطع مع نفسه.
FTW_MOUNT
الاجتياز لا يعبر نقطة تحميل.
FTW_DEPTH
يتم زيارة جميع الدلائل الفرعية قبل الدليل نفسه.
FTW_CHDIR
يتغير الاجتياز إلى كل دليل قبل قراءته.

سيتم الإعلان عن ما يلي كدوال وقد يتم تعريفه أيضًا كـ macros. سيتم توفير نماذج الدوال.

int ftw(const char *, int (*)(const char *, const struct stat *,
    int), int);
int nftw(const char *, int (*)(const char *, const struct stat *,
    int, struct FTW *), int, int);

سيحدد الرأس <ftw.h> بنية stat والأسماء الرمزية لـ st_mode وماكروات اختبار نوع الملف كما هو موصوف في <sys/stat.h>.

قد يؤدي تضمين الرأس <ftw.h> أيضًا إلى ظهور جميع الرموز من <sys/stat.h>.

الأقسام التالية إعلامية.
