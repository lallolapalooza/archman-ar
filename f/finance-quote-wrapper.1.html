FINANCE-QUOTE-WRAPPER(1) وثائق مساهمة من المستخدم لـ Perl FINANCE-QUOTE-WRAPPER(1)

الاسم

finance-quote-wrapper - واجهة داخلية بين gnucash و Finance::Quote

الملخص

finance-quote-wrapper

الوصف

المدخلات: تجزئة مشفرة بصيغة JSON لمساحات الأسماء والسلع التي يجب الاستعلام عن أسعارها. تذهب جميع العملات تحت مساحة الأسماء "currency"، وتُجمع السلع الأخرى وفقًا لمصدر الأسعار الذي يجب الاستعلام عنها منه. يجب أن يكون هناك أيضًا مفتاح "defaultcurrency" مع العملة التي يجب استخدامها كعملة أساسية لاقتباسات العملات.

{
"defaultcurrency": "EUR",
"currency": {
"XAG": "",
"HKD": "",
"USD": ""
},
"yahoo_json": {
"CSCO": ""
} }

المخرجات (على المخرج القياسي):

الأسعار المستردة بصيغة JSON لمزيد من المعالجة. هذه هي القيم الأولية التي أعادتها Finance::Quote. يتحمل المستدعي مسؤولية تحليل وتفسير النتائج.

في حالة فشل البرنامج، ستتم طباعة رسالة خطأ على المخرج القياسي للخطأ.
