FETESTEXCEPT(3P) دليل مبرمجي POSIX FETESTEXCEPT(3P)

الملحق

هذه الصفحة الدليلية هي جزء من دليل مبرمجي POSIX. قد يختلف تطبيق Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة في Linux.

الاسم

fetestexcept — اختبار علامات استثناءات الفاصلة العائمة

الملخص

#include <fenv.h>
int fetestexcept(int excepts);

الوصف

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

تحدد الدالة fetestexcept() أي مجموعة فرعية محددة من علامات استثناءات الفاصلة العائمة تم تعيينها حاليًا. تحدد المعلمة excepts علامات حالة الفاصلة العائمة المطلوب الاستعلام عنها.

قيمة الإرجاع

ترجع الدالة fetestexcept() قيمة OR الاستثنائية الثنائية لماكرو الاستثناءات ذات الفاصلة العائمة المقابلة لاستثناءات الفاصلة العائمة المعينة حاليًا والمضمنة في excepts.

الأخطاء

لا توجد أخطاء محددة.

الأقسام التالية إعلامية.

أمثلة

يستدعي المثال التالي الدالة f() إذا تم تعيين استثناء غير صالح، ثم الدالة g() إذا تم تعيين استثناء تجاوز:

#include <fenv.h>
/* ... */
{
    #pragma STDC FENV_ACCESS ON
    int set_excepts;
    feclearexcept(FE_INVALID | FE_OVERFLOW);
    // ربما توليد استثناءات
    set_excepts = fetestexcept(FE_INVALID | FE_OVERFLOW);
    if (set_excepts & FE_INVALID) f();
    if (set_excepts & FE_OVERFLOW) g();
    /* ... */
}
