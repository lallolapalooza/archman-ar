fts_set(3)

fts(3) دليل وظائف المكتبة fts(3)

الاسم

fts, fts_open, fts_read, fts_children, fts_set, fts_close - اجتياز تسلسل هرمي للملفات

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <sys/types.h>
#include <sys/stat.h>
#include <fts.h>
FTS *fts_open(char *const *path_argv, int options,
              typeof(int (const FTSENT **, const FTSENT **))
                  *_Nullable compar);
FTSENT *fts_read(FTS *ftsp);
FTSENT *fts_children(FTS *ftsp, int instr);
int fts_set(FTS *ftsp, FTSENT *f, int instr);
int fts_close(FTS *ftsp);

الوصف

توفر وظائف fts لاجتياز التسلسلات الهرمية للملفات. نظرة عامة بسيطة هي أن الدالة fts_open() ترجع "مقبض" (من النوع FTS *) يشير إلى تسلسل هرمي للملفات "تيار". يتم بعد ذلك تزويد هذا المقبض بوظائف fts الأخرى. ترجع الدالة fts_read() مؤشرًا إلى بنية تصف أحد الملفات في التسلسل الهرمي للملفات. ترجع الدالة fts_children() مؤشرًا إلى قائمة مترابطة من البنى، كل منها يصف أحد الملفات الموجودة في دليل في التسلسل الهرمي.

بشكل عام، تتم زيارة الدلائل مرتين قابلتين للتمييز؛ في الترتيب المسبق (قبل زيارة أي من أحفادها) وفي الترتيب اللاحق (بعد زيارة جميع أحفادها). تتم زيارة الملفات مرة واحدة. من الممكن اجتياز التسلسل الهرمي "بشكل منطقي" (زيارة الملفات التي تشير إليها الروابط الرمزية) أو "فعليًا" (زيارة الروابط الرمزية نفسها)، أو ترتيب اجتياز التسلسل الهرمي أو اقتطاع و/أو إعادة زيارة أجزاء من التسلسل الهرمي.

تم تعريف بنتين (وأنواع مرتبطة) في ملف التضمين <fts.h>. النوع الأول هو FTS، وهو الهيكل الذي يمثل التسلسل الهرمي للملفات نفسه. النوع الثاني هو FTSENT، وهو الهيكل الذي يمثل ملفًا في التسلسل الهرمي للملفات. عادةً، يتم إرجاع بنية FTSENT لكل ملف في التسلسل الهرمي للملفات. في صفحة الدليل هذه، "ملف" و "بنية FTSENT" يمكن تبادلهما بشكل عام.

يحتوي هيكل FTSENT على حقول تصف ملفًا. يحتوي الهيكل على الحقول التالية على الأقل (هناك حقول إضافية يجب اعتبارها خاصة بالتطبيق):


typedef struct _ftsent {
    unsigned short  fts_info;     /* علامات لهيكل FTSENT */
    char           *fts_accpath;  /* مسار الوصول */
    char           *fts_path;     /* مسار الجذر */
    short           fts_pathlen;  /* strlen(fts_path) +
                                     strlen(fts_name) */
    char           *fts_name;     /* اسم الملف */
    short           fts_namelen;  /* strlen(fts_name) */
    short           fts_level;    /* العمق (-1 إلى N) */
    int             fts_errno;    /* خطأ الملف */
    long            fts_number;   /* قيمة رقمية محلية */
    void           *fts_pointer;  /* قيمة عنوان محلية */
    struct _ftsent *fts_parent;   /* الدليل الأصل */
    struct _ftsent *fts_link;     /* هيكل الملف التالي */
    struct _ftsent *fts_cycle;    /* هيكل الدورة */
    struct stat    *fts_statp;    /* معلومات [l]stat(2) */
} FTSENT;

هذه الحقول معرفة كما يلي:

fts_info
إحدى القيم التالية التي تصف بنية FTSENT المُرجعة والملف الذي تمثله. باستثناء الدلائل بدون أخطاء (FTS_D)، تكون جميع هذه الإدخالات طرفية، أي أنها لن تتم زيارتها مرة أخرى، ولن تتم زيارة أي من أحفادها.
FTS_D
دليل تتم زيارته في ترتيب مسبق.
FTS_DC
دليل يسبب دورة في الشجرة. (سيتم ملء حقل fts_cycle الخاص ببنية FTSENT أيضًا.)
FTS_DEFAULT
أي بنية FTSENT تمثل نوع ملف غير موصوف بشكل صريح بأحد قيم fts_info الأخرى.
FTS_DNR
دليل لا يمكن قراءته. هذا عائد خطأ، وسيتم تعيين حقل fts_errno لتحديد سبب الخطأ.
FTS_DOT
ملف باسم "." أو ".." لم يتم تحديده كاسم ملف للدالة fts_open() (انظر FTS_SEEDOT).
FTS_DP
دليل تتم زيارته في ترتيب لاحق. ستظل محتويات بنية FTSENT دون تغيير من وقت إرجاعها في الترتيب المسبق، أي مع تعيين حقل fts_info إلى FTS_D.
FTS_ERR
هذا عائد خطأ، وسيتم تعيين حقل fts_errno لتحديد سبب الخطأ.
FTS_F
ملف عادي.
FTS_NS
ملف لم تكن معلومات [l]stat(2) متاحة له. محتويات حقل fts_statp غير محددة. هذا عائد خطأ، وسيتم تعيين حقل fts_errno لتحديد سبب الخطأ.
FTS_NSOK
ملف لم تكن معلومات [l]stat(2) مطلوبة له. محتويات حقل fts_statp غير محددة.
FTS_SL
رابط رمزي.
FTS_SLNONE
رابط رمزي مع هدف غير موجود. تشير محتويات حقل fts_statp إلى معلومات خصائص الملف للرابط الرمزي نفسه.
fts_accpath
مسار للوصول إلى الملف من الدليل الحالي.
fts_path
مسار الملف بالنسبة إلى جذر الاجتياز. يحتوي هذا المسار على المسار المحدد للدالة fts_open() كبادئة.
fts_pathlen
مجموع أطوال السلاسل المشار إليها بواسطة fts_path و fts_name.
fts_name
اسم الملف.
fts_namelen
طول السلسلة المشار إليها بواسطة fts_name.
fts_level
عمق الاجتياز، مرقم من -1 إلى N، حيث تم العثور على هذا الملف. بنية FTSENT التي تمثل أصل نقطة البداية (أو الجذر) للاجتياز مرقمة -1، وبنية FTSENT للجذر نفسه مرقمة 0.
fts_errno
إذا قامت الدالة fts_children() أو fts_read() بإرجاع بنية FTSENT تم تعيين حقل fts_info الخاص بها إلى FTS_DNR، FTS_ERR، أو FTS_NS، فإن حقل fts_errno يحتوي على رقم الخطأ (أي قيمة errno) الذي يحدد الخطأ. بخلاف ذلك، فإن محتويات حقل fts_errno غير محددة.
fts_number
يتم توفير هذا الحقل لاستخدام البرنامج التطبيقي ولا تقوم وظائف fts بتعديله. يتم تهيئته إلى 0.
fts_pointer
يتم توفير هذا الحقل لاستخدام البرنامج التطبيقي ولا تقوم وظائف fts بتعديله. يتم تهيئته إلى NULL.
fts_parent
مؤشر إلى بنية FTSENT التي تشير إلى الملف في التسلسل الهرمي الذي يعلو الملف الحالي مباشرة، أي الدليل الذي يعتبر هذا الملف عضوًا فيه. يتم أيضًا توفير بنية أصل لنقطة الدخول الأولية، ومع ذلك، فإن حقول fts_level و fts_number و fts_pointer فقط هي التي تضمن تهيئتها.
