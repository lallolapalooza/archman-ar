foreach(n)

الحزمة: tcl

foreach(n) أوامر Tcl المضمنة foreach(n)

الاسم

foreach - التكرار عبر جميع العناصر في قائمة واحدة أو أكثر

الملخص

foreach اسم_متغير قائمة نص_برمجي
foreach قائمة_متغير1 قائمة1 ?قائمة_متغير2 قائمة2 ...? نص_برمجي

الوصف

يقوم الأمر foreach بتنفيذ حلقة حيث تأخذ المتغيرات المتكررة قيماً من قائمة واحدة أو أكثر. في أبسط حالة، يوجد متغير حلقة واحد، اسم_متغير، وقائمة واحدة، قائمة، وهي قائمة بالقيم التي سيتم تعيينها لـ اسم_متغير. الوسيط نص_برمجي هو نص برمجي لـ Tcl. لكل عنصر من قائمة (بالترتيب من الأول إلى الأخير)، يقوم foreach بتعيين محتويات العنصر إلى اسم_متغير كما لو كان الأمر lindex قد تم استخدامه لاستخراج العنصر، ثم يقوم باستدعاء مترجم Tcl لتنفيذ نص_برمجي.

في الحالة العامة، يمكن أن يكون هناك أكثر من قائمة قيم (على سبيل المثال، قائمة1 و قائمة2)، ويمكن ربط كل قائمة قيم بقائمة من متغيرات الحلقة (على سبيل المثال، قائمة_متغير1 و قائمة_متغير2). أثناء كل تكرار للحلقة، يتم تعيين متغيرات كل قائمة_متغير قيماً متتالية من قائمة المقابلة. يتم استخدام القيم في كل قائمة بالترتيب من الأول إلى الأخير، ويتم استخدام كل قيمة مرة واحدة بالضبط. يكون العدد الإجمالي للتكرارات كافياً لاستخدام جميع القيم من جميع قوائم القيم. إذا لم تحتوِ قائمة قيم على عدد كافٍ من العناصر لكل متغير حلقة فيها في كل تكرار، يتم استخدام قيم فارغة للعناصر المفقودة.

يمكن استدعاء العبارتين break و continue داخل نص_برمجي، بنفس التأثير كما في الأمر for. يعيد Foreach سلسلة فارغة.

أمثلة

هذه الحلقة تطبع كل قيمة في قائمة مع مربعها ومكعبها:

set values {1 3 5 7 2 4 6 8}	;# أرقام فردية أولاً، للمتعة!
puts "القيمة\tالمربع\tالمكعب"	;# رأس جدول يبدو أنيقًا
foreach x $values {	;# الآن قم بالتكرار والطباعة...
    puts " $x\t [expr {$x**2}]\t [expr {$x**3}]"
}

تستخدم الحلقة التالية i و j كمتغيرات حلقة للتكرار عبر أزواج من عناصر قائمة واحدة.

set x {}
foreach {i j} {a b c d e f} {
    lappend x $j $i
}
# قيمة x هي "b a d c f e"
# هناك 3 تكرارات للحلقة.

تستخدم الحلقة التالية i و j للتكرار عبر قائمتين بالتوازي.

set x {}
foreach i {a b c} j {d e f g} {
    lappend x $i $j
}
# قيمة x هي "a d b e c f {} g"
# هناك 4 تكرارات للحلقة.

يتم دمج الشكلين في المثال التالي.

set x {}
foreach i {a b c} {j k} {d e f g} {
    lappend x $i $j $k
}
# قيمة x هي "a d e b f g c {} {}"
# هناك 3 تكرارات للحلقة.
