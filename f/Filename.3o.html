منذ 3.11.2

val concat : string -> string -> string

concat dir file يُرجع اسم ملف يحدد الملف file في الدليل dir .

val is_relative : string -> bool

يُرجع true إذا كان اسم الملف نسبيًا إلى الدليل الحالي، وfalse إذا كان مطلقًا (أي في Unix، يبدأ بـ / ).

val is_implicit : string -> bool

يُرجع true إذا كان اسم الملف نسبيًا ولا يبدأ بإشارة صريحة إلى الدليل الحالي ( ./ أو ../ في Unix)، وfalse إذا كان يبدأ بإشارة صريحة إلى الدليل الجذر أو الدليل الحالي.

val check_suffix : string -> string -> bool

check_suffix name suff يُرجع true إذا كان اسم الملف name ينتهي باللاحقة suff .

في منافذ Windows (بما في ذلك Cygwin)، تكون المقارنة غير حساسة لحالة الأحرف، بالاعتماد على String.lowercase_ascii . لاحظ أن هذا لا يطابق تمامًا تفسير تكافؤ أسماء الملفات غير الحساسة لحالة الأحرف من Windows.

val chop_suffix : string -> string -> string

chop_suffix name suff يزيل اللاحقة suff من اسم الملف name .

يرفع Invalid_argument إذا كان name لا ينتهي باللاحقة suff .

val chop_suffix_opt : suffix:string -> string -> string option

chop_suffix_opt ~suffix filename يزيل اللاحقة من filename إذا كان ذلك ممكنًا، أو يُرجع None إذا كان اسم الملف لا ينتهي باللاحقة.

في منافذ Windows (بما في ذلك Cygwin)، تكون المقارنة غير حساسة لحالة الأحرف، بالاعتماد على String.lowercase_ascii . لاحظ أن هذا لا يطابق تمامًا تفسير تكافؤ أسماء الملفات غير الحساسة لحالة الأحرف من Windows.

منذ 4.08

val extension : string -> string

extension name هي أقصر لاحقة ext لـ name0 حيث:

- name0 هي أطول لاحقة لـ name لا تحتوي على فاصل دليل؛

- ext تبدأ بنقطة؛

- ext مسبوقة بحرف واحد على الأقل غير نقطة في name0 .

إذا لم تكن هذه اللاحقة موجودة، فإن extension name هي السلسلة الفارغة.

منذ 4.04

val remove_extension : string -> string

يُرجع اسم الملف المعطى بدون امتداده، كما هو محدد في Filename.extension . إذا كان الامتداد فارغًا، تُرجع الدالة اسم الملف المعطى.

الثابت التالي ينطبق على أي اسم ملف s :

remove_extension s ^ extension s = s

منذ 4.04

val chop_extension : string -> string

مثل Filename.remove_extension ، لكنه يرفع Invalid_argument إذا كان الاسم المعطى له امتداد فارغ.

val basename : string -> string

تقسيم اسم ملف إلى اسم دليل / اسم ملف أساسي. إذا كان name اسم ملف صالحًا، فإن concat (dirname name) (basename name) يُرجع اسم ملف مكافئًا لـ name . علاوة على ذلك، بعد تعيين الدليل الحالي إلى dirname name (باستخدام Sys.chdir )، فإن الإشارات إلى basename name (وهو اسم ملف نسبي) تحدد نفس الملف مثل name قبل استدعاء Sys.chdir .

تتوافق هذه الدالة مع مواصفات POSIX.1-2008 لأداة basename.

val dirname : string -> string

انظر Filename.basename . تتوافق هذه الدالة مع مواصفات POSIX.1-2008 لأداة dirname.

val null : string

null هي "/dev/null" على POSIX و"NUL" على Windows. تمثل ملفًا على نظام التشغيل يتجاهل جميع عمليات الكتابة ويُرجع نهاية الملف عند القراءة.

منذ 4.10

val temp_file : ?temp_dir:string -> string -> string -> string

temp_file prefix suffix يُرجع اسم ملف مؤقت جديد في الدليل المؤقت. يتكون الاسم الأساسي للملف المؤقت من تسلسل prefix ، ثم عدد صحيح مختار بشكل مناسب، ثم suffix . تشير الوسيطة الاختيارية temp_dir إلى الدليل المؤقت المراد استخدامه، وتكون افتراضيًا النتيجة الحالية لـ Filename.get_temp_dir_name . يتم إنشاء الملف المؤقت فارغًا، بأذونات 0o600 (قابل للقراءة والكتابة فقط من قبل مالك الملف). يُضمن أن يكون الملف مختلفًا عن أي ملف آخر كان موجودًا عند استدعاء temp_file.

قبل 3.11.2 لا توجد وسيطة اختيارية ?temp_dir

يرفع Sys_error إذا تعذر إنشاء الملف.

val open_temp_file : ?mode:open_flag list -> ?perms:int -> ?temp_dir:string -> string -> string -> string * out_channel

مثل Filename.temp_file ، لكنه يُرجع كلاً من اسم ملف مؤقت جديد، وقناة إخراج مفتوحة (بشكل ذري) على هذا الملف. هذه الدالة أكثر أمانًا من temp_file : لا يوجد خطر من تعديل الملف المؤقت (مثل استبداله برابط رمزي) قبل أن يفتحه البرنامج. الوسيطة الاختيارية mode هي قائمة من الأعلام الإضافية للتحكم في فتح الملف. يمكن أن تحتوي على واحد أو أكثر من Open_append وOpen_binary وOpen_text . الافتراضي هو [Open_text] (الفتح في وضع النص). يتم إنشاء الملف بأذونات perms (افتراضيًا قابل للقراءة والكتابة فقط من قبل مالك الملف، 0o600 ).

قبل 4.03 لا توجد وسيطة اختيارية ?perms

قبل 3.11.2 لا توجد وسيطة اختيارية ?temp_dir

يرفع Sys_error إذا تعذر فتح الملف.

val temp_dir : ?temp_dir:string -> ?perms:int -> string -> string -> string

temp_dir prefix suffix يُنشئ ويُرجع اسم دليل مؤقت جديد بأذونات perms (افتراضيًا 0o700) داخل temp_dir . يتكون الاسم الأساسي للدليل المؤقت من تسلسل prefix ، ثم عدد صحيح مختار بشكل مناسب، ثم suffix . تشير الوسيطة الاختيارية temp_dir إلى الدليل المؤقت المراد استخدامه، وتكون افتراضيًا النتيجة الحالية لـ Filename.get_temp_dir_name . يتم إنشاء الدليل المؤقت فارغًا، بأذونات 0o700 (قابل للقراءة والكتابة والبحث فقط من قبل مالك الملف). يُضمن أن يكون الدليل مختلفًا عن أي دليل آخر كان موجودًا عند استدعاء temp_dir.

إذا لم يكن temp_dir موجودًا، فإن هذه الدالة لا تنشئه. بدلاً من ذلك، فإنها ترفع Sys_error.

منذ 5.1

يرفع Sys_error إذا تعذر إنشاء الدليل.

val get_temp_dir_name : unit -> string

اسم الدليل المؤقت: في Unix، قيمة متغير البيئة TMPDIR ، أو "/tmp" إذا لم يكن المتغير معينًا.

في Windows، القيمة التي تُرجعها GetTempPath2 (إذا كانت متاحة) أو GetTempPath .

يمكن تغيير الدليل المؤقت باستخدام Filename.set_temp_dir_name .

في Windows، قبل OCaml 5.4، كانت تُرجع قيمة متغير البيئة TEMP ، أو "." إذا لم يكن المتغير معينًا.

منذ 4.00

val set_temp_dir_name : string -> unit

تغيير الدليل المؤقت الذي تُرجعه Filename.get_temp_dir_name ويُستخدم بواسطة Filename.temp_file وFilename.open_temp_file . الدليل المؤقت هو قيمة محلية للنطاق تُورَّث من قبل النطاقات الفرعية.
