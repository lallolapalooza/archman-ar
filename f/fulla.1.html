fulla(1)

الحزمة: hugin

التراخيص: GPL-2.0-only

FULLA("1") HUGIN FULLA("1")

اسم

fulla - تصحيح تشوه العدسة، والتظليل، والانحراف اللوني

الملخص

fulla [خيارات] ملف(ات) الإدخال

الوصف

تطبيق تصحيح التظليل الشعاعي أو المسطح، بالإضافة إلى تصحيح التشوه الشعاعي الهندسي والانحراف اللوني العرضي.

يمكن استخدام fulla لتصحيح دفعة كبيرة من الملفات. يمكن قراءة معاملات التشوه الشعاعي من قاعدة بيانات العدسات.

يتم إجراء تصحيح التظليل بنفس الطريقة الموضحة في وثائق ملف نصي لـ nona، أو من قاعدة بيانات العدسة. يمكن إجراء تصحيح التظليل بناءً على حقل مسطح أو تحجيم شعاعي.

تصحيح التظليل عن طريق قسمة الحقل المسطح:
I = I / c, c = flat-field / mean(flat-field)

تصحيح التظليل الشعاعي:
I = I / c, c = a + b*r^2 + c*r^4 + d*r^6

تصحيح التشوه الشعاعي مطابق لما تم تنفيذه بواسطة PanoTools:

r_new = a*r^4 + b*r^3 + c*r^2 + d*r [1]

نظرًا لأن الانحرافات اللونية العرضية (TCA) تؤدي إلى أشياء ذات نطاقات مختلفة في القنوات الحمراء والخضراء والزرقاء، يمكن تصحيحها عن طريق تحجيم القناتين الحمراء والزرقاء لمطابقة القناة الخضراء. تقدم معظم التطبيقات، مثل Photoshop أو Picture Window Pro، تصحيح TCA عن طريق التحجيم الخطي. هذا يعادل تغيير المعامل d في المعادلة [1].

راجع http://hugin.sf.net/tutorials/tca لمعرفة طريقة تحديد هذه المعاملات.

خيارات

--green=db|a:b:c:d
معامل تصحيح التشوه الشعاعي لجميع القنوات، (a, b, c, d). حدد 'db' للبحث في قاعدة البيانات أو المعاملات الأربعة a:b:c:d
--blue=db|a:b:c:d
معاملات تصحيح التشوه الشعاعي للقناة الزرقاء، (a, b, c, d). يتم تطبيق هذا فوق معاملات التشوه لـ --green، استخدمه لتصحيح TCA. حدد 'db' للبحث في قاعدة البيانات أو المعاملات الأربعة a:b:c:d
--red=db|a:b:c:d
معاملات تصحيح التشوه الشعاعي للقناة الحمراء، (a, b, c, d). يتم تطبيق هذا فوق معاملات التشوه لـ --green، استخدمه لتصحيح TCA. حدد 'db' للبحث في قاعدة البيانات أو المعاملات الأربعة a:b:c:d
--camera-maker=Maker
صانع الكاميرا، للاستعلام من قاعدة البيانات
--camera-model=Cam
اسم الكاميرا، للاستعلام من قاعدة البيانات
--lensname=Lens
اسم العدسة، للاستعلام من قاعدة البيانات
حدد --camera-maker و --camera-model للكاميرات ذات العدسات الثابتة أو --lensname للعدسات القابلة للتبديل.
--focallength=50
حدد البعد البؤري بالملم، للاستعلام من قاعدة البيانات
--aperature=3.5
حدد الفتحة للاستعلام من قاعدة بيانات بيانات التظليل
--dont-rescale
لا تقم بإعادة تحجيم الصورة لتجنب الحدود السوداء.
--flatfield=filename
تصحيح التظليل عن طريق قسمة الحقل المسطح I = I / c, c = flatfield / mean(flatfield)
--vignetting=db|a:b:c:d
تصحيح التظليل (بالقسمة). حدد db للبحث في قاعدة البيانات أو المعاملات الأربعة a:b:c:d I = I / ( a + b*r^2 + c*r^4 + d*r^6)
--linear
قم بإجراء تصحيح التظليل في مساحة الألوان الخطية
--gamma=value
قيمة جاما لبيانات الإدخال. تستخدم لتصحيح جاما قبل وبعد تصحيح الحقل المسطح
threads=n
عدد الخيوط التي يجب استخدامها
-h|--help
عرض المساعدة
--output=name
تعيين اسم ملف الإخراج. إذا تم إعطاء أكثر من صورة واحدة، فسيتم استخدام الاسم كلاحقة. (اللاحقة الافتراضية: _corr)
--compression=value
ضغط ملفات الإخراج. لخرج jpeg: 0-100. لخرج tiff: PACKBITS, DEFLATE, LZW
--offset=X:Y
إزاحة أفقية ورأسية
--verbose
