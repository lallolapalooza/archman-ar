flatpak-remotes(1)

الحزمة: flatpak

التراخيص: LGPL-2.1-or-later

FLATPAK REMOTES(1) flatpak remotes FLATPAK REMOTES(1)

الاسم

flatpak-remotes - عرض المستودعات البعيدة

الملخص

flatpak remotes [خيار... ]

الوصف

يعرض المستودعات البعيدة المعروفة، بترتيب الأولوية.

افتراضيًا، يتم عرض كل من التثبيتات لكل مستخدم وعلى مستوى النظام. استخدم الخيارات --user أو --system أو --installation لتغيير هذا.

الخيارات

يتم فهم الخيارات التالية:

-h, --help

عرض خيارات المساعدة والخروج.

-u, --user

عرض التكوين لكل مستخدم.

--system

عرض التكوين الافتراضي على مستوى النظام.

--installation=NAME

عرض تثبيت على مستوى النظام بالاسم من بين تلك المعرفة في /etc/flatpak/installations.d/. استخدام --installation=default يعادل استخدام --system.

-d, --show-details

عرض المزيد من المعلومات لكل مستودع بالإضافة إلى الاسم. يعادل --columns=all.

--show-disabled

عرض المستودعات المعطلة.

-v, --verbose

طباعة معلومات التصحيح أثناء معالجة الأمر.

--ostree-verbose

طباعة معلومات تصحيح OSTree أثناء معالجة الأمر.

--columns=FIELD,...

تحديد المعلومات التي سيتم عرضها لكل مرجع. يمكنك سرد حقول متعددة، أو استخدام هذا الخيار عدة مرات.

ألحق :s[tart] أو :m[iddle] أو :e[nd] أو :f[ull] بأسماء الأعمدة لتغيير طريقة اقتطاع النص.

الحقول

يتم فهم الحقول التالية بواسطة الخيار --columns:

name

عرض اسم المستودع

title

عرض عنوان المستودع

url

عرض عنوان URL للمستودع

filter

عرض المسار إلى مرشح جانب العميل للمستودع.

collection

عرض معرف المجموعة للمستودع

priority

عرض أولوية المستودع

options

عرض الخيارات

comment

عرض التعليق

description

عرض الوصف

homepage

عرض الصفحة الرئيسية

icon

عرض الأيقونة

all

عرض جميع الأعمدة

help

عرض قائمة الأعمدة المتاحة

لاحظ أنه يمكن اختصار أسماء الحقول إلى بادئة فريدة.

أمثلة

$ flatpak remotes --user --show-details

testrepo	Test Repository	 http://209.132.179.91/repo/ no-gpg-verify
