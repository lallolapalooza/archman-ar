fi_nic - سمات بطاقة واجهة الشبكة

سمات بطاقة واجهة الشبكة

يحدد الهيكل fid_nic السمات لـ struct fi_info التي ترتبط مباشرة بأجهزة الشبكة الأساسية وقد يتم إرجاعها مباشرة من استدعاء fi_getinfo(3). يتم تعريف تنسيق fid_nic والهياكل الفرعية ذات الصلة أدناه.

لاحظ أنه قد لا تتوفر جميع حقول جميع الهياكل. سيتم تعيين الحقول غير المتاحة أو الحقول التي لا تنطبق على الجهاز المحدد إلى NULL أو 0.

struct fid_nic {
    struct fid             fid;
    struct fi_device_attr *device_attr;
    struct fi_bus_attr    *bus_attr;
    struct fi_link_attr   *link_attr;
    void                  *prov_attr;
};
struct fi_device_attr {
    char *name;
    char *device_id;
    char *device_version;
    char *vendor_id;
    char *driver;
    char *firmware;
};
struct fi_pci_attr {
    uint16_t domain_id;
    uint8_t  bus_id;
    uint8_t  device_id;
    uint8_t  function_id;
};
struct fi_bus_attr {
    enum fi_bus_type       bus_type;
    union {
        struct fi_pci_attr pci;
    } attr;
};
struct fi_link_attr {
    char               *address;
    size_t             mtu;
    size_t             speed;
    enum fi_link_state state;
    char               *network_type;
};

سمات الجهاز

تُستخدم سمات الجهاز لتحديد بطاقة واجهة الشبكة الافتراضية أو المادية المحددة المرتبطة بهيكل fi_info.

name
اسم نظام التشغيل المرتبط بالجهاز. قد يكون هذا اسم واجهة شبكة منطقية (مثل eth0 أو eno1) أو اسم ملف مطلق.
device_id
هذا معرف خاص بالبائع للجهاز أو المنتج.
device_version
يشير إلى إصدار الجهاز.
vendor_id
يشير إلى اسم البائع الذي يوزع بطاقة واجهة الشبكة.
driver
اسم برنامج التشغيل المرتبط بالجهاز.
firmware
إصدار برنامج الجهاز الثابت.

سمات الناقل

تُستخدم سمات الناقل لتحديد الموقع الفعلي لبطاقة واجهة الشبكة في النظام.

bus_type
يشير إلى نوع ناقل النظام حيث توجد بطاقة واجهة الشبكة. القيم الصالحة هي FI_BUS_PCI أو FI_BUS_UNKNOWN.
attr.pci.domain_id
المجال حيث يوجد ناقل PCI. صالح فقط إذا كان bus_type هو FI_BUS_PCI.
attr.pci.bus_id
معرف ناقل PCI حيث يوجد الجهاز. صالح فقط إذا كان bus_type هو FI_BUS_PCI.
attr.pci.device_id
المعرف على ناقل PCI حيث يوجد الجهاز. صالح فقط إذا كان bus_type هو FI_BUS_PCI.
attr.pci.function_id
الوظيفة في الجهاز المشار إليه. صالح فقط إذا كان bus_type هو FI_BUS_PCI.

سمات الارتباط

تصف سمات الارتباط تفاصيل منخفضة المستوى حول اتصال الشبكة بالنسيج.

address
العنوان الأساسي على مستوى الارتباط المرتبط ببطاقة واجهة الشبكة، مثل عنوان MAC. إذا كانت هناك عناوين متعددة متاحة، فسيتم الإبلاغ عن عنوان واحد فقط.
mtu
وحدة النقل القصوى لإطارات أو حزم مستوى الارتباط، بالبايت.
speed
معدل بيانات الارتباط النشط، معطى بالبت في الثانية.
state
حالة منفذ المادية الحالية. القيم الممكنة هي FI_LINK_UNKNOWN، و FI_LINK_DOWN، و FI_LINK_UP، للإشارة إلى ما إذا كانت حالة المنفذ غير معروفة أو غير قابلة للتطبيق (غير معروفة)، أو غير نشطة (متوقفة)، أو نشطة (مرتفعة).
network_type
يحدد نوع واجهة الشبكة النشطة حاليًا، مثل Ethernet أو InfiniBand.

سمات المزود

تشير سمات المزود إلى تفاصيل خاصة بالمزود للجهاز. هذه السمات خاصة بالمزود والجهاز. يمكن تفسير السمات بواسطة fi_tostr(3). قد تستخدم التطبيقات أيضًا حقول السمات الأخرى، مثل حقل prov_name المرتبط بـ fi_fabric_attr، لتحديد هيكل مناسب لتحويل السمات. تنسيق وتعريف هذا الحقل خارج نطاق إطار عمل نواة libfabric، ولكنه قد يكون متاحًا كجزء من ملف رأس خاص بالمزود مدرج مع حزمة libfabric.

ملاحظات

يتم إرجاع الهيكل fid_nic كجزء من استدعاء fi_getinfo(3). يتم تحريره تلقائيًا كجزء من استدعاء fi_freeinfo(3).
