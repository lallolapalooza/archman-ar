foomatic-printjob(1)

الحزمة: foomatic-db-engine

التراخيص: GPL-2.0-or-later

FOOMATIC-PRINTJOB(1) دليل الأوامر العامة FOOMATIC-PRINTJOB(1)

الاسم

foomatic-printjob - إدارة مهام الطباعة بطريقة مستقلة عن نظام التخزين المؤقت

الملخص

foomatic-printjob [ -s spooler ] [ -P queuename ] [ -o option1=value1 -o option2 ... ] [ -i ] [ file1 file2 ... ]

foomatic-printjob -Q [ -s spooler ] [ -P queuename ] [ -i ] [ -a ] [ user1 user2 ... ]

foomatic-printjob -R [ -s spooler ] [ -P queuename ] [ -i ] [ - | jobid1 jobid2 ... ]

foomatic-printjob -C [ -s spooler ] [ -i ] command [ arguments ]

foomatic-printjob -S [ -s spooler ] [ -i ]

foomatic-printjob -h [ -s spooler ] [ -P queuename ] [ -i ]

الوصف

foomatic-printjob يوفر واجهة مستقلة عن نظام التخزين المؤقت لإنشاء وإدارة مهام الطباعة وطوابير الطباعة. لاحظ أن الوسيطة الأولى تغير وضع الأمر، حيث أنها تجمع وظائف أوامر الطباعة المتعددة على غرار System V.

الخيارات

-sspooler
نوع نظام التخزين المؤقت المحدد.
-Pqueuename
تنطبق أي أوامر محددة على هذا الطابور بدلاً من الطابور الافتراضي.
-ooption=value
تعيين خيار للقيمة
-ooption
تعيين خيار التبديل
-#n
طباعة n نسخة
file1  file2  ...
الملفات المراد طباعتها، عند عدم إعطاء ملف، سيتم طباعة الإدخال القياسي
-Q
استعلام عن المهام في طابور. إذا تم تحديد قائمة بالمستخدمين، فسيتم الاستعلام عن مهام هؤلاء المستخدمين فقط.
-Q -a
استعلام عن المهام في جميع الطوابير. إذا تم تحديد قائمة بالمستخدمين، فسيتم الاستعلام عن مهام هؤلاء المستخدمين فقط.
-R [ - | jobid1 jobid2 ... ]
إزالة مهمة من طابور. استخدام - سيقوم بإزالة جميع المهام.
-C command [ arguments ]
تنفيذ أوامر التحكم للتلاعب بالطابور/المهمة. الأوامر هي أوامر أداة "lpc" الخاصة بـ BSD. استخدم أمر التحكم "help" للحصول على قائمة بالأوامر المدعومة. ملاحظة: كمية الأوامر تختلف باختلاف نظام التخزين المؤقت، لكن نفس الأوامر المعطاة تحت أنظمة تخزين مؤقت مختلفة تفعل نفس الشيء.
-i
الوضع التفاعلي: سيتم سؤالك إذا كان foomatic-printjob في شك بشأن شيء ما. بخلاف ذلك، يستخدم foomatic-printjob الكشف التلقائي أو يخرج بخطأ.
-S
حفظ نظام التخزين المؤقت المختار كنظام تخزين مؤقت افتراضي
-h
عرض هذه الرسالة أو عرض قائمة بالخيارات المتاحة إذا تم تحديد طابور

انظر أيضاً

foomatic-configure(1) والوثائق الخاصة بنظام التخزين المؤقت للطباعة الخاص بك.
