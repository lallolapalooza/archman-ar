subroutine zchkhs (integer nsizes, integer, dimension( * ) nn, integer ntypes, logical, dimension( * ) dotype, integer, dimension( 4 ) iseed, double precision thresh, integer nounit, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( lda, * ) h, complex*16, dimension( lda, * ) t1, complex*16, dimension( lda, * ) t2, complex*16, dimension( ldu, * ) u, integer ldu, complex*16, dimension( ldu, * ) z, complex*16, dimension( ldu, * ) uz, complex*16, dimension( * ) w1, complex*16, dimension( * ) w3, complex*16, dimension( ldu, * ) evectl, complex*16, dimension( ldu, * ) evectr, complex*16, dimension( ldu, * ) evecty, complex*16, dimension( ldu, * ) evectx, complex*16, dimension( ldu, * )uu, complex*16, dimension( * ) tau, complex*16, dimension( * ) work, integer nwork, double precision, dimension( * ) rwork, integer, dimension( * ) iwork, logical, dimension( * ) select, double precision, dimension( 16 ) result, integer info)

ZCHKHS

Purpose:

!>
!>    ZCHKHS  checks the nonsymmetric eigenvalue problem routines.
!>
!>            ZGEHRD factors A as  U H U' , where ' means conjugate
!>            transpose, H is hessenberg, and U is unitary.
!>
!>            ZUNGHR generates the unitary matrix U.
!>
!>            ZUNMHR multiplies a matrix by the unitary matrix U.
!>
!>            ZHSEQR factors H as  Z T Z' , where Z is unitary and T
!>            is upper triangular.  It also computes the eigenvalues,
!>            w(1), ..., w(n); we define a diagonal matrix W whose
!>            (diagonal) entries are the eigenvalues.
!>
!>            ZTREVC computes the left eigenvector matrix L and the
!>            right eigenvector matrix R for the matrix T.  The
!>            columns of L are the complex conjugates of the left
!!>            eigenvectors of T.  The columns of R are the right
!>            eigenvectors of T.  L is lower triangular, and R is
!>            upper triangular.
!>
!>            ZHSEIN computes the left eigenvector matrix Y and the
!>            right eigenvector matrix X for the matrix H.  The
!>            columns of Y are the complex conjugates of the left
!>            eigenvectors of H.  The columns of X are the right
!>            eigenvectors of H.  Y is lower triangular, and X is
!>            upper triangular.
!>
!>            ZTREVC3 computes left and right eigenvector matrices
!>            from a Schur matrix T and backtransforms them with Z
!>            to eigenvector matrices L and R for A. L and R are
!>            GE matrices.
!>
!>    When ZCHKHS is called, a number of matrix sizes () and a
!>    number of matrix types () are specified.  For each size ()
!>    and each type of matrix, one matrix will be generated and used
!>    to test the nonsymmetric eigenroutines.  For each matrix, 16
!>    tests will be performed:
!>
!>    (1)     | A - U H U**H | / ( |A| n ulp )
!>
!>    (2)     | I - UU**H | / ( n ulp )
!>
!>    (3)     | H - Z T Z**H | / ( |H| n ulp )
!>
!>    (4)     | I - ZZ**H | / ( n ulp )
!>
!>    (5)     | A - UZ H (UZ)**H | / ( |A| n ulp )
!>
!>    (6)     | I - UZ (UZ)**H | / ( n ulp )
!>
!>    (7)     | T(Z computed) - T(Z not computed) | / ( |T| ulp )
!>
!>    (8)     | W(Z computed) - W(Z not computed) | / ( |W| ulp )
!>
!>    (9)     | TR - RW | / ( |T| |R| ulp )
!>
!>    (10)    | L**H T - W**H L | / ( |T| |L| ulp )
!>
!>    (11)    | HX - XW | / ( |H| |X| ulp )
!>
!>    (12)    | Y**H H - W**H Y | / ( |H| |Y| ulp )
!>
!>    (13)    | AX - XW | / ( |A| |X| ulp )
!>
!>    (14)    | Y**H A - W**H Y | / ( |A| |Y| ulp )
!>
!>    (15)    | AR - RW | / ( |A| |R| ulp )
!>
!>    (16)    | LA - WL | / ( |A| |L| ulp )
!>
!>    The matrix sizes are specified by an array NN(1:NSIZES); the value of
!>    each element NN(j) specifies one size.
!>    The matrix types are specified by a logical array DOTYPE( 1:NTYPES );
!>    if DOTYPE(j) is .TRUE., then matrix type j will be generated.
!>    Currently, the list of possible types is:
!>
!>    (1)  The zero matrix.
!>    (2)  The identity matrix.
!>    (3)  A (transposed) Jordan block, with 1's on the diagonal.
!>
!>    (4)  A diagonal matrix with evenly spaced entries
!>         1, ..., ULP  and random complex angles.
!>         (ULP = (first number larger than 1) - 1 )
!>    (5)  A diagonal matrix with geometrically spaced entries
!>         1, ..., ULP  and random complex angles.
!>    (6)  A diagonal matrix with entries 1, ULP, ..., ULP**(N-1)
!>         and random complex angles.
!>
!>    (7)  Same as (4), but multiplied by SQRT( overflow threshold )
!>    (8)  Same as (4), but multiplied by SQRT( underflow threshold )
!>
!>    (9)  A matrix of the form  U' T U, where U is unitary and
!>         T has evenly spaced entries 1, ..., ULP with random complex
!>         angles on the diagonal and random O(1) entries in the upper
!>         triangle.
!>
!>    (10) A matrix of the form  U' T U, where U is unitary and
!>         T has geometrically spaced entries 1, ..., ULP with random
!>         complex angles on the diagonal and random O(1) entries in
!>         the upper triangle.
!>
!>    (11) A matrix of the form  U' T U, where U is unitary and
!>         T has entries 1, ULP,..., ULP**(N-1) with random
!>         complex angles on the diagonal and random O(1) entries in
!>         the upper triangle.
!>
!>    (12) A matrix of the form  U' T U, where U is unitary and
!>         T has complex eigenvalues randomly chosen from
!>         ULP < |z| < 1   and random O(1) entries in the upper
!>         triangle.
!>
!>    (13) A matrix of the form  X' T X, where X has condition
!>         SQRT( ULP ) and T has evenly spaced entries 1, ..., ULP
!>         with random complex angles on the diagonal and random O(1)
!>         entries in the upper triangle.
!>
!>    (14) A matrix of the form  X' T X, where X has condition
!>         SQRT( ULP ) and T has geometrically spaced entries
!>         1, ..., ULP with random complex angles on the diagonal
!>         and random O(1) entries in the upper triangle.
!>
!>    (15) A matrix of the form  X' T X, where X has condition
!>         SQRT( ULP ) and T has entries 1, ULP,..., ULP**(N-1)
!>         with random complex angles on the diagonal and random O(1)
!>         entries in the upper triangle.
!>
!>    (16) A matrix of the form  X' T X, where X has condition
!>         SQRT( ULP ) and T has complex eigenvalues randomly chosen
!>         from   ULP < |z| < 1   and random O(1) entries in the upper
!>         triangle.
!>
!>    (17) Same as (16), but multiplied by SQRT( overflow threshold )
!>
(18) مثل (16)، ولكن مضروبة في الجذر التربيعي (حد التجاوز السفلي) !> !> (19) مصفوفة غير متماثلة بإدخالات عشوائية تم اختيارها من |z| < 1 !> (20) مثل (19)، ولكن مضروبة في الجذر التربيعي (حد التجاوز العلوي) !> (21) مثل (19)، ولكن مضروبة في الجذر التربيعي (حد التجاوز السفلي) !> 
!> NSIZES - INTEGER
!> عدد أحجام المصفوفات المراد استخدامها. إذا كان صفرًا،
!> لا تفعل ZCHKHS شيئًا. يجب أن يكون على الأقل صفرًا.
!> لم يتم تعديله.
!>
!> NN - INTEGER array, dimension (NSIZES)
!> مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
!> سيتم تخطي القيم الصفرية. يجب أن تكون القيم على الأقل
!> صفرًا.
!> لم يتم تعديله.
!>
!> NTYPES - INTEGER
!> عدد العناصر في DOTYPE. إذا كان صفرًا، ZCHKHS
!> لا تفعل شيئًا. يجب أن يكون على الأقل صفرًا. إذا كان MAXTYP+1
!> و NSIZES هو 1، فسيتم تعريف نوع إضافي، MAXTYP+1، والذي
!> هو استخدام أي مصفوفة موجودة في A. هذا
!> مفيد فقط إذا كان DOTYPE(1:MAXTYP) هو .FALSE. و
!> DOTYPE(MAXTYP+1) هو .TRUE. .
!> لم يتم تعديله.
!>
!> DOTYPE - LOGICAL array, dimension (NTYPES)
!> إذا كان DOTYPE(j) هو .TRUE. ، فلكل حجم في NN
!> سيتم إنشاء مصفوفة بهذا الحجم ومن النوع j.
!> إذا كان NTYPES أصغر من الحد الأقصى لعدد الأنواع
!> المعرفة (PARAMETER MAXTYP)، فلن يتم إنشاء الأنواع NTYPES+1 حتى
!> MAXTYP. إذا كان NTYPES أكبر
!> من MAXTYP، فسيتم تجاهل DOTYPE(MAXTYP+1) حتى DOTYPE(NTYPES).
!> لم يتم تعديله.
!>
!> ISEED - INTEGER array, dimension (4)
!> عند الإدخال، تحدد ISEED البذرة لمولد الأرقام العشوائية.
!> يجب أن تكون عناصر المصفوفة بين 0 و 4095؛
!> إذا لم تكن كذلك، فسيتم تقليلها حسب 4096. أيضًا، يجب أن تكون ISEED(4)
!> فردية. يستخدم مولد الأرقام العشوائية تسلسل خطي متوافق
!> محدود بأعداد صحيحة صغيرة، لذلك
!> يجب أن ينتج أرقامًا عشوائية مستقلة عن الآلة.
!> يتم تغيير قيم ISEED عند الخروج، ويمكن استخدامها في
!> الاستدعاء التالي لـ ZCHKHS لمواصلة نفس تسلسل الأرقام العشوائية.
!> تم التعديل.
!>
!> THRESH - DOUBLE PRECISION
!> سيتم احتساب الاختبار على أنه إذا كان، محسوبًا على النحو
!> الموضح أعلاه، يتجاوز THRESH. لاحظ أن الخطأ
!> يتم قياسه ليكون O(1)، لذلك يجب أن يكون THRESH مضاعفًا معقولًا
!> صغيرًا لـ 1، على سبيل المثال، 10 أو 100. في الواقع،
!> لا ينبغي أن يعتمد على الدقة (أحادية مقابل مزدوجة)
!> أو حجم المصفوفة. يجب أن يكون على الأقل صفرًا.
!> لم يتم تعديله.
!>
!> NOUNIT - INTEGER
!> رقم وحدة FORTRAN لطباعة رسائل الخطأ
!> (على سبيل المثال، إذا أعادت روتينية IINFO قيمة غير صفرية.)
!> لم يتم تعديله.
!>
!> A - COMPLEX*16 array, dimension (LDA,max(NN))
!> يستخدم للاحتفاظ بالمصفوفة التي سيتم حساب قيمها الذاتية.
!> عند الخروج، تحتوي A على آخر مصفوفة تم استخدامها بالفعل.
!> تم التعديل.
!>
!> LDA - INTEGER
!> البعد الرئيسي لـ A، H، T1 و T2. يجب أن يكون
!> على الأقل 1 وعلى الأقل max( NN ).
!> لم يتم تعديله.
!>
!> H - COMPLEX*16 array, dimension (LDA,max(NN))
!> المصفوفة الهيسنبرغية العلوية التي تم حسابها بواسطة ZGEHRD.
!> عند الخروج، تحتوي H على الشكل الهيسنبرغي للمصفوفة في A.
!> تم التعديل.
!>
!> T1 - COMPLEX*16 array, dimension (LDA,max(NN))
!> مصفوفة شور (=) التي تم حسابها بواسطة ZHSEQR
!> إذا تم حساب Z. عند الخروج، تحتوي T1 على شكل شور
!> للمصفوفة في A.
!> تم التعديل.
!>
!> T2 - COMPLEX*16 array, dimension (LDA,max(NN))
!> مصفوفة شور التي تم حسابها بواسطة ZHSEQR عندما لا يتم حساب Z.
!> يجب أن تكون متطابقة مع T1.
!> تم التعديل.
!>
!> LDU - INTEGER
!> البعد الرئيسي لـ U، Z، UZ و UU. يجب أن يكون
!> على الأقل 1 وعلى الأقل max( NN ).
!> لم يتم تعديله.
!>
!> U - COMPLEX*16 array, dimension (LDU,max(NN))
!> المصفوفة الوحدوية التي تم حسابها بواسطة ZGEHRD.
!> تم التعديل.
!>
!> Z - COMPLEX*16 array, dimension (LDU,max(NN))
!> المصفوفة الوحدوية التي تم حسابها بواسطة ZHSEQR.
!> تم التعديل.
!>
!> UZ - COMPLEX*16 array, dimension (LDU,max(NN))
!> حاصل ضرب U في Z.
!> تم التعديل.
!>
!> W1 - COMPLEX*16 array, dimension (max(NN))
!> القيم الذاتية لـ A، كما تم حسابها بواسطة تحليل شور كامل
!> H = Z T Z'. عند الخروج، تحتوي W1 على
!> القيم الذاتية للمصفوفة في A.
!> تم التعديل.
!>
!> W3 - COMPLEX*16 array, dimension (max(NN))
!> القيم الذاتية لـ A، كما تم حسابها بواسطة تحليل شور جزئي
!> (Z غير محسوب، T محسوب فقط بالقدر
!> اللازم لتحديد القيم الذاتية). عند الخروج،
!> تحتوي W3 على القيم الذاتية للمصفوفة في A، ربما
!> تم تعطيلها بواسطة ZHSEIN.
!> تم التعديل.
!>
!> EVECTL - COMPLEX*16 array, dimension (LDU,max(NN))
!> المرافق المتبادل للمصفوفة (المثلثة العلوية) المتجهة اليسرى
!> للمصفوفة في T1.
!> تم التعديل.
!>
!> EVEZTR - COMPLEX*16 array, dimension (LDU,max(NN))
!> المصفوفة (المثلثة العلوية) المتجهة اليمنى
!> للمصفوفة في T1.
!> تم التعديل.
!>
!> EVECTY - COMPLEX*16 array, dimension (LDU,max(NN))
!> المرافق المتبادل للمصفوفة المتجهة اليسرى
!> للمصفوفة في H.
!> تم التعديل.
!>
!> EVECTX - COMPLEX*16 array, dimension (LDU,max(NN))
!> المصفوفة المتجهة اليمنى للمصفوفة في H.
!> تم التعديل.
!>
!> UU - COMPLEX*16 array, dimension (LDU,max(NN))
!> تفاصيل المصفوفة الوحدوية التي تم حسابها بواسطة ZGEHRD.
!> تم التعديل.
!>
!> TAU - COMPLEX*16 array, dimension (max(NN))
!> تفاصيل إضافية للمصفوفة الوحدوية التي تم حسابها بواسطة ZGEHRD.
!> تم التعديل.
!>
!> WORK - COMPLEX*16 array, dimension (NWORK)
!> مساحة عمل.
!> تم التعديل.
!>
!> NWORK - INTEGER
!> عدد الإدخالات في WORK. NWORK >= 4*NN(j)*NN(j) + 2.
!>
!> RWORK - DOUBLE PRECISION array, dimension (max(NN))
!> مساحة عمل. يمكن أن تتداخل مع IWORK، ولكن ليس SELECT.
!> تم التعديل.
!>
!> IWORK - INTEGER array, dimension (max(NN))
!> مساحة عمل.
!> تم التعديل.
!>
!> SELECT - LOGICAL array, dimension (max(NN))
!> مساحة عمل. يمكن أن تتداخل مع IWORK، ولكن ليس RWORK.
!> تم التعديل.
!>
!> RESULT - DOUBLE PRECISION array, dimension (16)
!> القيم المحسوبة بواسطة الاختبارات الأربعة عشر الموضحة أعلاه.
!> القيم محدودة حاليًا بـ 1/ulp، لتجنب
!> تجاوز الحد.
!> تم التعديل.
!>
!> INFO - INTEGER
!> إذا كان 0، فقد تم كل شيء بنجاح.
!> -1: NSIZES < 0
!> -2: بعض NN(j) < 0
!> -3: NTYPES < 0
!> -6: THRESH < 0
!> -9: LDA < 1 أو LDA < NMAX، حيث NMAX هو max( NN(j) ).
!> -14: LDU < 1 أو LDU < NMAX.
!> -26: NWORK صغير جدًا.
!> إذا أعادت ZLATMR، CLATMS، أو CLATME رمز خطأ، فإن
!> القيمة المطلقة له يتم إرجاعها.
!> إذا كان 1، فإن ZHSEQR لم يتمكن من العثور على جميع التحولات.
!> إذا كان 2، فإن كود EISPACK (للكتل الصغيرة) فشل.
!> إذا كان >2، فإن 30*N تكرارات لم تكن كافية للعثور على
!> قيمة ذاتية أو لتفكيك المشكلة.
!> تم التعديل.
!>
!>-----------------------------------------------------------------------
!>
!> بعض المتغيرات المحلية والمعلمات:
!> ---- ----- --------- --- ----------
!>
!> ZERO, ONE - REAL 0 و 1.
!> MAXTYP - الحد الأقصى لعدد الأنواع المعرفة.
!> MTEST - عدد الاختبارات المعرفة: يجب توخي الحذر
!> بأن (1) حجم RESULT، (2) عدد
!> الاختبارات التي تم إجراؤها بالفعل، و (3) MTEST تتفق.
!> NTEST - عدد الاختبارات التي تم إجراؤها على هذه المصفوفة
!> حتى الآن. يجب أن يكون أقل من MTEST، و
!> يساويها بحلول الاختبار الأخير. سيكون أقل
!> إذا كانت أي من الروتينات التي يتم اختبارها تشير
!> إلى أنها لم تتمكن من حساب المصفوفات التي
!> سيتم اختبارها.
!> NMAX - أكبر قيمة في NN.
!> NMATS - عدد المصفوفات التي تم إنشاؤها حتى الآن.
!> NERRS - عدد الاختبارات التي تجاوزت THRESH
!> حتى الآن (محسوبة بواسطة DLAFTS).
!> COND, CONDS,
!> IMODE - القيم التي سيتم تمريرها إلى مولدات المصفوفات.
!> ANORM - معيار A؛ تم تمريره إلى مولدات المصفوفات.
!>
!> OVFL, UNFL - حدود التجاوز العلوي والسفلي.
!> ULP, ULPINV - أدق دقة نسبية وعكسها.
!> RTOVFL, RTUNFL,
!> RTULP, RTULPI - الجذور التربيعية للقيم الأربعة السابقة.
!>
!> تفكك المصفوفات الأربعة التالية JTYPE:
!> KTYPE(j) - النوع العام (1-10) للنوع.
!> KMODE(j) - قيمة MODE التي سيتم تمريرها إلى مولد المصفوفة
!> للنوع.
!> KMAGN(j) - حجم الطلب ( O(1)،
!> O(overflow^(1/2) )، O(underflow^(1/2) )
!> KCONDS(j) - يحدد ما إذا كان CONDS سيكون 1 أو
!> 1/sqrt(ulp). (0 يعني غير ذي صلة.)
!>
