!>
!> ZCHKST2STG  تحقق من روتينات مشكلة القيم الذاتية الهرمية
!> باستخدام تقنيات الاختزال للمرحلتين. بما أن توليد
!> Q أو المتجهات غير متاح في هذا الإصدار، فإننا نقارن فقط
!> القيمة الذاتية الناتجة عند استخدام المرحلتين مع
!> القيمة المرجعية باستخدام الاختزال القياسي للمرحلة الواحدة
!> ZHETRD. لهذا الغرض، نقوم باستدعاء ZHETRD القياسي وحساب D1 باستخدام
!> DSTEQR، ثم نقوم باستدعاء ZHETRD_2STAGE للمرحلتين مع العلوي والسفلي
!> ونحسب D2 و D3 باستخدام DSTEQR ثم نستبدل الاختبارات
!> 3 و 4 بالاختبارين 11 و 12. يبقى الاختباران 1 و 2 للتحقق من أن
!> نتائج المرحلة الواحدة صحيحة ويمكن الوثوق بها.
!> سيتقارب روتين الاختبار هذا إلى ZCHKST في الإصدار التالي
!> عندما يتم تنفيذ المتجهات وتوليد Q.
!>
!>    ZHETRD يحلل A إلى  U S U* ، حيث * تعني منقولة مترافقة،
!>    S هو مصفوفة متماثلة شبه قطرية حقيقية، و U هي مصفوفة موحدة.
!>    يمكن لـ ZHETRD استخدام الجزء السفلي أو العلوي فقط
!>    من A؛ ZCHKST2STG يتحقق من كلا الحالتين.
!>    يتم تمثيل U كناتج لتحويلات هاوسهولدر
!>    ، والتي يتم تخزين متجهاتها في الأعمدة الـ n-1 الأولى
!>    من V، وعوامل القياس الخاصة بها في TAU.
!>
!>    ZHPTRD يفعل نفس الشيء مثل ZHETRD، باستثناء أن A و V مخزنان
!>    في تنسيق  .
!>
!>    ZUNGTR يبني المصفوفة U من محتويات V و TAU.
!>
!>    ZUPGTR يبني المصفوفة U من محتويات VP و TAU.
!>
!>    ZSTEQR يحلل S إلى  Z D1 Z* ، حيث Z هي المصفوفة الموحدة
!>    للمتجهات الذاتية و D1 هي مصفوفة قطرية تحتوي على
!>    القيم الذاتية على القطر.  D2 هي المصفوفة
!>    للقيم الذاتية المحسوبة عندما لا يتم حساب Z.
!>
!>    DSTERF يحسب D3، مصفوفة القيم الذاتية، بواسطة
!>    طريقة PWK، التي لا تنتج متجهات ذاتية.
!>
!>    ZPTEQR يحلل S إلى  Z4 D4 Z4* ، لمصفوفة
!>    هرمية موجبة محددة شبه قطرية.
!>    D5 هي مصفوفة القيم الذاتية المحسوبة عندما لا يتم حساب Z.
!>
!>    DSTEBZ يحسب قيمًا ذاتية مختارة.  WA1، WA2، و
!>    WA3 ستمثل القيم الذاتية المحسوبة بدقة مطلقة عالية،
!>    مع خيارات نطاق مختلفة.
!>    WR ستمثل القيم الذاتية المحسوبة بدقة نسبية عالية.
!>
!>    ZSTEIN يحسب Y، المتجهات الذاتية لـ S، مع إعطاء
!>    القيم الذاتية.
!>
!>    ZSTEDC يحلل S إلى Z D1 Z* ، حيث Z هي المصفوفة الموحدة
!>    للمتجهات الذاتية و D1 هي مصفوفة قطرية تحتوي على
!>    القيم الذاتية على القطر (خيار 'I'). قد تقوم أيضًا
!>    بتحديث مصفوفة موحدة مدخلة، عادةً ما تكون ناتج
!>    ZHETRD/ZUNGTR أو ZHPTRD/ZUPGTR (خيار 'V'). قد تقوم أيضًا
!>    بحساب القيم الذاتية فقط (خيار 'N').
!>
!>    ZSTEMR يحلل S إلى Z D1 Z* ، حيث Z هي المصفوفة الموحدة
!>    للمتجهات الذاتية و D1 هي مصفوفة قطرية تحتوي على
!>    القيم الذاتية على القطر (خيار 'I').  تستخدم ZSTEMR
!>    التمثيل القوي نسبيًا كلما أمكن ذلك.
!>
!> عند استدعاء ZCHKST2STG، يتم تحديد عدد من المصفوفات () و
!> عدد من المصفوفات ().  لكل حجم ()
!> وكل نوع مصفوفة، سيتم إنشاء مصفوفة واحدة واستخدامها
!> لاختبار الروتينات الذاتية الهرمية.  لكل مصفوفة، سيتم
!> إجراء عدد من الاختبارات:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='L', ... )
!>         يتم استبداله بـ | D1 - D2 | / ( |D1| ulp ) حيث D1 هي
!>         مصفوفة القيم الذاتية المحسوبة باستخدام S و D2 هي
!>         مصفوفة القيم الذاتية المحسوبة باستخدام S_2stage ناتج
!>         ZHETRD_2STAGE(, ,....). يتم حساب D1 و D2
!>         عبر DSTEQR('N',...)
!>
!> (4)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='L', ... )
!>         يتم استبداله بـ | D1 - D3 | / ( |D1| ulp ) حيث D1 هي
!>         مصفوفة القيم الذاتية المحسوبة باستخدام S و D3 هي
!>         مصفوفة القيم الذاتية المحسوبة باستخدام S_2stage ناتج
!>         ZHETRD_2STAGE(, ,....). يتم حساب D1 و D3
!>         عبر DSTEQR('N',...)
!>
!> (5-8)   نفس 1-4، ولكن لـ ZHPTRD و ZUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) ZSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        ZSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        ZSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        DSTERF
!>
!> (13)    0 إذا كانت القيم الذاتية الحقيقية (المحسوبة بعدد ستورم)
!>         لـ S تقع ضمن THRESH من
!>         تلك الموجودة في D1.  2*THRESH إذا لم تكن كذلك.  (تم اختباره باستخدام
!>         DSTECH)
!>
!> عندما تكون S محددة موجبة،
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) ZPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        ZPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       ZPTEQR('N',...)
!>
!> عندما تكون S أيضًا مهيمنة قطريًا بالعامل gamma < 1،
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ،
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          DSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!
