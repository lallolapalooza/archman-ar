• (16) U ( J , J ) V حيث U و V مصفوفتان وحدويتان عشوائيتان.
  • (17) U ( T1, T2 ) V حيث T1 و T2 مصفوفتان مثلثيتان علويتان بعناصر عشوائية O(1) فوق القطر وقطريات diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) و diag(T2) = Q*( 0, N-3, N-4,..., 1, 0, 0 )
  • (18) U ( T1, T2 ) V diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 ) diag(T2) = ( 0, 1, 0, 1,..., 1, 0 ) s = دقة الآلة.
  • (19) U ( T1, T2 ) V diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 ) diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
  • N-5 (20) U ( T1, T2 ) V diag(T1)=( 0, 0, 1, 1, a, ..., a =s, 0 ) diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
  • (21) U ( T1, T2 ) V diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 ) diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 ) حيث r1,..., r(N-4) عشوائية.
  • (22) U ( big*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )
  • (23) U ( small*T1, big*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )
  • (24) U ( small*T1, small*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )
  • (25) U ( big*T1, big*T2 ) V diag(T1) = P*( 0, 0, 1, ..., N-3, 0 ) diag(T2) = ( 0, 1, ..., 1, 0, 0 )
  • (26) U ( T1, T2 ) V حيث T1 و T2 مصفوفتان مثلثيتان علويتان عشوائيتان.

المعاملات

NSIZES 
          NSIZES هو عدد صحيح
          عدد أحجام المصفوفات المراد استخدامها. إذا كان صفراً،
          فإن ZCHKGG لا تفعل شيئاً. يجب أن يكون على الأقل صفراً.

NN

          NN هو مصفوفة أعداد صحيحة، ذات بعد (NSIZES)
          مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
          سيتم تخطي القيم الصفرية. يجب أن تكون القيم على الأقل
          صفراً.

NTYPES

          NTYPES هو عدد صحيح
          عدد العناصر في DOTYPE. إذا كان صفراً، فإن ZCHKGG
          لا تفعل شيئاً. يجب أن يكون على الأقل صفراً. إذا كان MAXTYP+1
          و NSIZES هو 1، فسيتم تعريف نوع إضافي، MAXTYP+1، وهو استخدام
          أي مصفوفة موجودة في A. هذا مفيد فقط إذا كان DOTYPE(1:MAXTYP) هو
          .FALSE. و DOTYPE(MAXTYP+1) هو .TRUE. .

DOTYPE

          DOTYPE هي مصفوفة منطقية، ذات بعد (NTYPES)
          إذا كان DOTYPE(j) هو .TRUE.، فلكل حجم في NN سيتم إنشاء
          مصفوفة بهذا الحجم ومن النوع j.
          إذا كان NTYPES أصغر من الحد الأقصى لعدد الأنواع
          المعرفة (PARAMETER MAXTYP)، فلن يتم إنشاء الأنواع NTYPES+1 حتى
          MAXTYP. إذا كان NTYPES أكبر
          من MAXTYP، سيتم تجاهل DOTYPE(MAXTYP+1) حتى DOTYPE(NTYPES).

ISEED

          ISEED هي مصفوفة أعداد صحيحة، ذات بعد (4)
          عند الإدخال، تحدد ISEED بذرة مولد الأرقام
          العشوائية. يجب أن تكون عناصر المصفوفة بين 0 و 4095؛
          إذا لم يكن الأمر كذلك، فسيتم تقليلها بمعيار 4096. أيضاً، يجب أن يكون ISEED(4)
          فرداً. يستخدم مولد الأرقام العشوائية متتالية خطية تلازمية محدودة بأعداد صحيحة صغيرة، وبالتالي
          يجب أن تنتج أرقاماً عشوائية مستقلة عن الآلة. سيتم تغيير
          قيم ISEED عند الخروج، ويمكن استخدامها في
          الاستدعاء التالي لـ ZCHKGG لمواصلة نفس تسلسل الأرقام العشوائية.

THRESH

          THRESH هو ضعف الدقة (DOUBLE PRECISION)
          سيتم احتساب اختبار كـ
          كما هو موضح أعلاه، يتجاوز THRESH. لاحظ أن الخطأ
          يتم قياسه ليكون O(1)، لذا يجب أن يكون THRESH مضاعفاً صغيراً بشكل معقول
          من 1، على سبيل المثال، 10 أو 100. على وجه الخصوص،
          يجب ألا يعتمد على الدقة (أحادية مقابل مزدوجة)
          أو حجم المصفوفة. يجب أن يكون على الأقل صفراً.

TSTDIF

          TSTDIF هو منطقي (LOGICAL)
          يحدد ما إذا كانت نسب الاختبار 13-15 سيتم حسابها و
          مقارنتها مع THRESH.
          = .FALSE.: سيتم حساب واختبار نسب الاختبار 1-12 فقط.
                     سيتم تعيين النسب 13-15 إلى صفر.
          = .TRUE.:  سيتم حساب واختبار جميع نسب الاختبار 1-15.

THRSHN

          THRSHN هو ضعف الدقة (DOUBLE PRECISION)
          عتبة الإبلاغ عن خطأ تطبيع المتجه الذاتي.
          إذا اختلف تطبيع أي متجه ذاتي عن 1 بأكثر
          من THRSHN*ulp، فسيتم طباعة رسالة خطأ خاصة. (يتم التعامل مع هذا بشكل منفصل عن الاختبارات الأخرى،
          حيث أن خطأ المترجم أو المبرمج فقط هو الذي ينبغي أن يتسبب في رسالة خطأ، على الأقل إذا كان THRSHN على الأقل 5--10.)

NOUNIT

          NOUNIT هو عدد صحيح
          رقم وحدة FORTRAN لطباعة رسائل الخطأ
          (على سبيل المثال، إذا أعادت روتينية IINFO بقيمة غير الصفر.)

A

          A هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          تستخدم لاحتواء المصفوفة A الأصلية. تستخدم كمدخل فقط
          إذا كان NTYPES=MAXTYP+1، و DOTYPE(1:MAXTYP)=.FALSE.، و
          DOTYPE(MAXTYP+1)=.TRUE.

LDA

          LDA هو عدد صحيح
          البعد الرائد لـ A, B, H, T, S1, P1, S2, و P2.
          يجب أن يكون على الأقل 1 وعلى الأقل max( NN ).

B

          B هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          تستخدم لاحتواء المصفوفة B الأصلية. تستخدم كمدخل فقط
          إذا كان NTYPES=MAXTYP+1، و DOTYPE(1:MAXTYP)=.FALSE.، و
          DOTYPE(MAXTYP+1)=.TRUE.

H

          H هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          المصفوفة الهيسنبيرجية العلوية التي تم حسابها من A بواسطة ZGGHRD.

T

          T هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          المصفوفة المثلثية العلوية التي تم حسابها من B بواسطة ZGGHRD.

S1

          S1 هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          المصفوفة الشير (المثلثية العلوية) التي تم حسابها من H بواسطة ZHGEQZ
          عندما يتم حساب Q و Z أيضاً.

S2

          S2 هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          المصفوفة الشير (المثلثية العلوية) التي تم حسابها من H بواسطة ZHGEQZ
          عندما لا يتم حساب Q و Z.

P1

          P1 هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          المصفوفة المثلثية العلوية التي تم حسابها من T بواسطة ZHGEQZ
          عندما يتم حساب Q و Z أيضاً.

P2

          P2 هي مصفوفة COMPLEX*16، ذات بعد (LDA, max(NN))
          المصفوفة المثلثية العلوية التي تم حسابها من T بواسطة ZHGEQZ
          عندما لا يتم حساب Q و Z.

U

          U هي مصفوفة COMPLEX*16، ذات بعد (LDU, max(NN))
          المصفوفة الوحدوية (اليسرى) التي تم حسابها بواسطة ZGGHRD.

LDU

          LDU هو عدد صحيح
          البعد الرائد لـ U, V, Q, Z, EVECTL, و EVEZTR. يجب
          أن يكون على الأقل 1 وعلى الأقل max( NN ).

V

          V هي مصفوفة COMPLEX*16، ذات بعد (LDU, max(NN))
          المصفوفة الوحدوية (اليمنى) التي تم حسابها بواسطة ZGGHRD.

Q

          Q هي مصفوفة COMPLEX*16، ذات بعد (LDU, max(NN))
          المصفوفة الوحدوية (اليسرى) التي تم حسابها بواسطة ZHGEQZ.

Z

          Z هي مصفوفة COMPLEX*16، ذات بعد (LDU, max(NN))
          المصفوفة الوحدوية (اليسرى) التي تم حسابها بواسطة ZHGEQZ.

ALPHA1

          ALPHA1 هي مصفوفة COMPLEX*16، ذات بعد (max(NN))

BETA1

          BETA1 هي مصفوفة COMPLEX*16، ذات بعد (max(NN))
          القيم الذاتية المعممة لـ (A,B) التي تم حسابها بواسطة ZHGEQZ
          عندما يتم حساب Q و Z والمصفوفات الشير الكاملة.

ALPHA3

          ALPHA3 هي مصفوفة COMPLEX*16، ذات بعد (max(NN))

BETA3

          BETA3 هي مصفوفة COMPLEX*16، ذات بعد (max(NN))
          القيم الذاتية المعممة لـ (A,B) التي تم حسابها بواسطة ZHGEQZ
          عندما لا يتم حساب Q أو Z أو المصفوفات الشير.

EVECTL

          EVECTL هي مصفوفة COMPLEX*16، ذات بعد (LDU, max(NN))
          مصفوفة المتجهات الذاتية اليسرى (المثلثية السفلى) لـ
          المصفوفات في S1 و P1.

EVECTR

          EVECTR هي مصفوفة COMPLEX*16، ذات بعد (LDU, max(NN))
          مصفوفة المتجهات الذاتية اليمنى (المثلثية العلوية) لـ
          المصفوفات في S1 و P1.

WORK

          WORK هي مصفوفة COMPLEX*16، ذات بعد (LWORK)

LWORK

          LWORK هو عدد صحيح
          عدد العناصر في WORK. يجب أن يكون على الأقل
          max( 4*N, 2 * N**2, 1 )، لجميع N=NN(j).

RWORK

          RWORK هي مصفوفة ضعف الدقة (DOUBLE PRECISION)، ذات بعد (2*max(NN))

LLWORK

          LLWORK هي مصفوفة منطقية (LOGICAL)، ذات بعد (max(NN))

RESULT

          RESULT هي مصفوفة ضعف الدقة (DOUBLE PRECISION)، ذات بعد (15)
          القيم التي تم حسابها بواسطة الاختبارات الموضحة أعلاه.
          القيم محدودة حالياً بـ 1/ulp، لتجنب
          الفيضان.

INFO

          INFO هو عدد صحيح
          = 0:  إنهاء ناجح.
          < 0:  إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية.
          > 0:  أعادت روتينية رمز خطأ. INFO هو
                القيمة المطلقة لقيمة INFO المعادة.
