ZCHKST

الغرض:

!>
!> يتحقق ZCHKST من إجراءات مسألة القيم الذاتية الهرميتية.
!>
!>    يحلل ZHETRD المصفوفة A إلى  U S U* ، حيث * تعني المنقول المرافق،
!>    S هي ثلاثية قطرية متماثلة حقيقية، و U وحدوية.
!>    يمكن لـ ZHETRD استخدام المثلث السفلي فقط أو المثلث العلوي فقط
!>    من A؛ يتحقق ZCHKST من كلتا الحالتين.
!>    يتم تمثيل U كحاصل ضرب تحويلات
!>    Householder، التي تُخزَّن متجهاتها في أول
!>    n-1 عمود من V، ومعاملات قياسها في TAU.
!>
!>    يفعل ZHPTRD نفس ما يفعله ZHETRD، باستثناء أن A و V تُخزَّنان
!>    بصيغة  .
!>
!>    يبني ZUNGTR المصفوفة U من محتويات V و TAU.
!>
!>    يبني ZUPGTR المصفوفة U من محتويات VP و TAU.
!>
!>    يحلل ZSTEQR المصفوفة S إلى  Z D1 Z* ، حيث Z هي المصفوفة
!>    الوحدوية للمتجهات الذاتية و D1 هي مصفوفة قطرية
!>    تحتوي القيم الذاتية على قطرها.  D2 هي مصفوفة
!>    القيم الذاتية المحسوبة عندما لا تُحسب Z.
!>
!>    يحسب DSTERF المصفوفة D3، مصفوفة القيم الذاتية، بطريقة
!>    PWK، التي لا تُنتج متجهات ذاتية.
!>
!>    يحلل ZPTEQR المصفوفة S إلى  Z4 D4 Z4* ، لمصفوفة
!>    ثلاثية قطرية هرميتية موجبة محددة.
!>    D5 هي مصفوفة القيم الذاتية المحسوبة عندما لا تُحسب
!>    Z.
!>
!>    يحسب DSTEBZ القيم الذاتية المختارة.  ستشير WA1 و WA2 و
!>    WA3 إلى القيم الذاتية المحسوبة بدقة
!>    مطلقة عالية، مع خيارات نطاق مختلفة.
!>    ستشير WR إلى القيم الذاتية المحسوبة بدقة نسبية
!>    عالية.
!>
!>    يحسب ZSTEIN المصفوفة Y، المتجهات الذاتية لـ S، بمعطى
!>    القيم الذاتية.
!>
!>    يحلل ZSTEDC المصفوفة S إلى Z D1 Z* ، حيث Z هي المصفوفة
!>    الوحدوية للمتجهات الذاتية و D1 هي مصفوفة قطرية
!>    تحتوي القيم الذاتية على قطرها (خيار 'I').  يمكنه أيضًا
!>    تحديث مصفوفة وحدوية مُدخلة، عادةً المخرجات
!>    من ZHETRD/ZUNGTR أو ZHPTRD/ZUPGTR (خيار 'V').  يمكنه
!>    أيضًا حساب القيم الذاتية فقط (خيار 'N').
!>
!>    يحلل ZSTEMR المصفوفة S إلى Z D1 Z* ، حيث Z هي المصفوفة
!>    الوحدوية للمتجهات الذاتية و D1 هي مصفوفة قطرية
!>    تحتوي القيم الذاتية على قطرها (خيار 'I').  يستخدم ZSTEMR
!>    التمثيل القوي نسبيًا كلما أمكن.
!>
!> عند استدعاء ZCHKST، يُحدَّد عدد من أحجام المصفوفات ()
!> وعدد من أنواع المصفوفات .  لكل حجم ()
!> ولكل نوع من المصفوفات، ستُولَّد مصفوفة واحدة وتُستخدم
!> لاختبار الإجراءات الذاتية الهرميتية.  لكل مصفوفة، سيُجرى
!> عدد من الاختبارات:
!>
!> (1)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='U', ... )
!>
!> (2)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='U', ... )
!>
!> (3)     | A - V S V* | / ( |A| n ulp ) ZHETRD( UPLO='L', ... )
!>
!> (4)     | I - UV* | / ( n ulp )        ZUNGTR( UPLO='L', ... )
!>
!> (5-8)   نفس 1-4، لكن لـ ZHPTRD و ZUPGTR.
!>
!> (9)     | S - Z D Z* | / ( |S| n ulp ) ZSTEQR('V',...)
!>
!> (10)    | I - ZZ* | / ( n ulp )        ZSTEQR('V',...)
!>
!> (11)    | D1 - D2 | / ( |D1| ulp )        ZSTEQR('N',...)
!>
!> (12)    | D1 - D3 | / ( |D1| ulp )        DSTERF
!>
!> (13)    0 إذا كانت القيم الذاتية الحقيقية (المحسوبة بعدّ Sturm)
!>         لـ S ضمن THRESH من
!>         تلك الموجودة في D1.  2*THRESH إذا لم تكن كذلك.  (تُختبر باستخدام
!>         DSTECH)
!>
!> بالنسبة لـ S الموجبة المحددة،
!>
!> (14)    | S - Z4 D4 Z4* | / ( |S| n ulp ) ZPTEQR('V',...)
!>
!> (15)    | I - Z4 Z4* | / ( n ulp )        ZPTEQR('V',...)
!>
!> (16)    | D4 - D5 | / ( 100 |D4| ulp )       ZPTEQR('N',...)
!>
!> عندما تكون S أيضًا مهيمنة قطريًا بالمعامل gamma < 1،
!>
!> (17)    max | D4(i) - WR(i) | / ( |D4(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              DSTEBZ( 'A', 'E', ...)
!>
!> (18)    | WA1 - D3 | / ( |D3| ulp )          DSTEBZ( 'A', 'E', ...)
!>
!> (19)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>                                              DSTEBZ( 'I', 'E', ...)
!>
!> (20)    | S - Y WA1 Y* | / ( |S| n ulp )  DSTEBZ, ZSTEIN
!>
!> (21)    | I - Y Y* | / ( n ulp )          DSTEBZ, ZSTEIN
!>
!> (22)    | S - Z D Z* | / ( |S| n ulp )    ZSTEDC('I')
!>
!> (23)    | I - ZZ* | / ( n ulp )           ZSTEDC('I')
!>
!> (24)    | S - Z D Z* | / ( |S| n ulp )    ZSTEDC('V')
!>
!> (25)    | I - ZZ* | / ( n ulp )           ZSTEDC('V')
!>
!> (26)    | D1 - D2 | / ( |D1| ulp )           ZSTEDC('V') و
!>                                              ZSTEDC('N')
!>
!> الاختبار 27 معطّل حاليًا لأن ZSTEMR لا
!> يضمن دقة نسبية عالية.
!>
!> (27)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              ZSTEMR('V', 'A')
!>
!> (28)    max | D6(i) - WR(i) | / ( |D6(i)| omega ) ,
!>          i
!>         omega = 2 (2n-1) ULP (1 + 8 gamma**2) / (1 - gamma)**4
!>                                              ZSTEMR('V', 'I')
!>
!> الاختبارات من 29 إلى 34 معطّلة حاليًا لأن ZSTEMR
!> لا يتعامل مع طلبات الطيف الجزئي.
!>
!> (29)    | S - Z D Z* | / ( |S| n ulp )    ZSTEMR('V', 'I')
!>
!> (30)    |I - ZZ* | / ( n ulp )           ZSTEMR('V', 'I')
!>
!> (31)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         ZSTEMR('N', 'I') مقابل CSTEMR('V', 'I')
!>
!> (32)    | S - Z D Z* | / ( |S| n ulp )    ZSTEMR('V', 'V')
!>
!> (33)    | I - ZZ* | / ( n ulp )           ZSTEMR('V', 'V')
!>
!> (34)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         ZSTEMR('N', 'V') مقابل CSTEMR('V', 'V')
!>
!> (35)    | S - Z D Z* | / ( |S| n ulp )    ZSTEMR('V', 'A')
!>
!> (36)    | I - ZZ* | / ( n ulp )           ZSTEMR('V', 'A')
!>
!> (37)    ( max { min | WA2(i)-WA3(j) | } +
!>            i     j
!>           max { min | WA3(i)-WA2(j) | } ) / ( |D3| ulp )
!>            i     j
!>         ZSTEMR('N', 'A') مقابل CSTEMR('V', 'A')
!>
!> يتم تحديد  بواسطة مصفوفة NN(1:NSIZES)؛ قيمة
!> كل عنصر NN(j) تحدد حجماً واحداً.
!> يتم تحديد  بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛
!> إذا كانت DOTYPE(j) تساوي .TRUE.، فسيتم توليد نوع المصفوفة .
!> حالياً، قائمة الأنواع الممكنة هي:
!>
!> (1)  المصفوفة الصفرية.
!> (2)  مصفوفة الوحدة.
!>
!> (3)  مصفوفة قطرية بعناصر متباعدة بالتساوي
!>      1, ..., ULP  وإشارات عشوائية.
!>      (ULP = (أول رقم أكبر من 1) - 1 )
!> (4)  مصفوفة قطرية بعناصر متباعدة هندسياً
!>      1, ..., ULP  وإشارات عشوائية.
!> (5)  مصفوفة قطرية بعناصر 1, ULP, ..., ULP
!>      وإشارات عشوائية.
!>
!> (6)  نفس (4)، لكن مضروبة في SQRT( عتبة الفائض )
!> (7)  نفس (4)، لكن مضروبة في SQRT( عتبة النقصان )
!>
!> (8)  مصفوفة من الشكل  U* D U، حيث U وحدوية و
!>      D لها عناصر متباعدة بالتساوي 1, ..., ULP بإشارات عشوائية
!>      على القطر.
!>
!> (9)  مصفوفة من الشكل  U* D U، حيث U وحدوية و
!>      D لها عناصر متباعدة هندسياً 1, ..., ULP بإشارات
!>      عشوائية على القطر.
!>
!> (10) مصفوفة من الشكل  U* D U، حيث U وحدوية و
!>      D لها عناصر 1, ULP,..., ULP بإشارات
!>      عشوائية على القطر.
!>
!> (11) نفس (8)، لكن مضروبة في SQRT( عتبة الفائض )
!> (12) نفس (8)، لكن مضروبة في SQRT( عتبة النقصان )
!>
!> (13) مصفوفة هيرميتية بعناصر عشوائية مختارة من (-1,1).
!> (14) نفس (13)، لكن مضروبة في SQRT( عتبة الفائض )
!> (15) نفس (13)، لكن مضروبة في SQRT( عتبة النقصان )
!> (16) نفس (8)، لكن العناصر القطرية كلها موجبة.
!> (17) نفس (9)، لكن العناصر القطرية كلها موجبة.
!> (18) نفس (10)، لكن العناصر القطرية كلها موجبة.
!> (19) نفس (16)، لكن مضروبة في SQRT( عتبة الفائض )
!> (20) نفس (16)، لكن مضروبة في SQRT( عتبة النقصان )
!> (21) مصفوفة ثلاثية الأقطار مسيطرة قطرياً بعناصر قطرية
!>      متباعدة هندسياً 1, ..., ULP.
!>

المعاملات

NSIZES 
!>          NSIZES هو INTEGER
!>          عدد أحجام المصفوفات المراد استخدامها.  إذا كانت صفراً،
!>          فإن ZCHKST لا يفعل شيئاً.  يجب أن تكون على الأقل صفراً.
!>

NN

!>          NN هو مصفوفة INTEGER، البعد (NSIZES)
!>          مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
!>          سيتم تخطي القيم الصفرية.  يجب أن تكون القيم على الأقل
!>          صفراً.
!>

NTYPES

!>          NTYPES هو INTEGER
!>          عدد العناصر في DOTYPE.   إذا كان صفراً، فإن ZCHKST
!>          لا يفعل شيئاً.  يجب أن يكون على الأقل صفراً.  إذا كان MAXTYP+1
!>          و NSIZES يساوي 1، فسيتم تعريف نوع إضافي، MAXTYP+1،
!>          وهو استخدام أياً كانت المصفوفة الموجودة في A.  هذا
!>          مفيد فقط إذا كانت DOTYPE(1:MAXTYP) تساوي .FALSE. و
!>          DOTYPE(MAXTYP+1) تساوي .TRUE. .
!>

DOTYPE

!>          DOTYPE هو مصفوفة LOGICAL، البعد (NTYPES)
!>          إذا كانت DOTYPE(j) تساوي .TRUE.، فسيتم لكل حجم في NN
!>          توليد مصفوفة بذلك الحجم ومن النوع j.
!>          إذا كان NTYPES أصغر من الحد الأقصى لعدد الأنواع
!>          المعرفة (PARAMETER MAXTYP)، فلن يتم توليد الأنواع NTYPES+1 حتى
!>          MAXTYP.  إذا كان NTYPES أكبر
!>          من MAXTYP، فسيتم تجاهل DOTYPE(MAXTYP+1) حتى DOTYPE(NTYPES).
!>

ISEED

!>          ISEED هو مصفوفة INTEGER، البعد (4)
!>          عند الإدخال، يحدد ISEED بذرة مولّد الأرقام
!>          العشوائية. يجب أن تكون عناصر المصفوفة بين 0 و 4095؛
!>          وإلا فسيتم اختزالها بمعامل 4096.  أيضاً، يجب أن يكون ISEED(4)
!>          فردياً.  يستخدم مولّد الأرقام العشوائية تسلسلاً
!>          خطياً متطابقاً محدوداً بأعداد صحيحة صغيرة، ولذلك
!>          يجب أن ينتج أرقاماً عشوائية مستقلة عن الآلة. يتم
!>          تغيير قيم ISEED عند الخروج، ويمكن استخدامها في
!>          الاستدعاء التالي لـ ZCHKST لمتابعة نفس تسلسل
!>          الأرقام العشوائية.
!>

THRESH

!>          THRESH هو DOUBLE PRECISION
!>          سيُعتبر الاختبار  إذا تجاوز ، المحسوب كما
!>          هو موضح أعلاه، قيمة THRESH.  لاحظ أن الخطأ
!>          مُقاس ليكون O(1)، لذا يجب أن تكون THRESH مضاعفاً
!>          صغيراً معقولاً للعدد 1، مثل 10 أو 100.  على وجه الخصوص،
!>          يجب ألا تعتمد على الدقة (المفردة مقابل المزدوجة)
!>          أو حجم المصفوفة.  يجب أن تكون على الأقل صفراً.
!>

NOUNIT

!>          NOUNIT هو INTEGER
!>          رقم وحدة FORTRAN لطباعة رسائل الخطأ
!>          (مثلاً، إذا أعادت روتين قيمة IINFO لا تساوي 0.)
!>

A

!>          A هو مصفوفة COMPLEX*16 من
!>                                  البعد ( LDA , max(NN) )
!>          يُستخدم لحفظ المصفوفة التي سيتم حساب قيمها الذاتية.
!>          عند الخروج، تحتوي A على آخر مصفوفة استُخدمت
!>          فعلياً.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي لـ A.  يجب أن يكون على الأقل
!>          1 وعلى الأقل max( NN ).
!>

AP

!>          AP هو مصفوفة COMPLEX*16 من
!>                      البعد( max(NN)*max(NN+1)/2 )
!>          المصفوفة A مخزنة بصيغة مضغوطة.
!>

SD

!>          SD هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          قطر المصفوفة ثلاثية الأقطار المحسوبة بواسطة ZHETRD.
!>          عند الخروج، تحتوي SD و SE على الشكل ثلاثي الأقطار
!>          للمصفوفة في A.
!>

SE

!>          SE هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          الأقطار الفرعية للمصفوفة ثلاثية الأقطار المحسوبة بواسطة
!>          ZHETRD.  عند الخروج، تحتوي SD و SE على الشكل ثلاثي الأقطار
!>          للمصفوفة في A.
!>

D1

!>          D1 هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          القيم الذاتية لـ A، كما حُسبت بواسطة ZSTEQR بالتزامن
!>          مع Z.  عند الخروج، تتوافق القيم الذاتية في D1 مع
!>          المصفوفة في A.
!>

D2

!>          D2 هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          القيم الذاتية لـ A، كما حُسبت بواسطة ZSTEQR إذا لم يتم
!>          حساب Z.  عند الخروج، تتوافق القيم الذاتية في D2 مع
!>          المصفوفة في A.
!>

D3

!>          D3 هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          القيم الذاتية لـ A، كما حُسبت بواسطة DSTERF.  عند الخروج،
!>          تتوافق القيم الذاتية في D3 مع المصفوفة في A.
!>

D4

!>          D4 هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          القيم الذاتية لـ A، كما حُسبت بواسطة ZPTEQR(V).
!>          يحلل ZPTEQR المصفوفة S إلى  Z4 D4 Z4*
!>          عند الخروج، تتوافق القيم الذاتية في D4 مع المصفوفة في A.
!>

D5

!>          D5 هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          القيم الذاتية لـ A، كما حُسبت بواسطة ZPTEQR(N)
!>          عندما لا يتم حساب Z. عند الخروج،
!>          تتوافق القيم الذاتية في D4 مع المصفوفة في A.
!>

WA1

!>          WA1 هو مصفوفة DOUBLE PRECISION من
!>                             البعد( max(NN) )
!>          جميع القيم الذاتية لـ A، محسوبة بدقة مطلقة

WA3

!>          WA3 هو مصفوفة DOUBLE PRECISION من

WR

!>          WR هو مصفوفة DOUBLE PRECISION من

!>          كما حُسبت بواسطة DSTEBZ.

U

LDU

V

!>          V هو مصفوفة COMPLEX*16 من
!>                             البعد( LDU, max(NN) ).
!>          متجهات Housholder المحسوبة بواسطة ZHETRD في اختزال A إلى
!>          الشكل ثلاثي الأقطار.  المتجهات المحسوبة مع UPLO='U' تكون
!>          في المثلث العلوي، والمتجهات المحسوبة مع UPLO='L'
!>          تكون في المثلث السفلي.  (كما هو موضح في ZHETRD، لا يتم
!>          تعيين الأقطار الفرعية والعلوية إلى 1، على الرغم من أن
!>          متجه Householder الحقيقي يحتوي على 1 في ذلك الموضع.  تقوم
!>          الروتينات التي تستخدم V، مثل ZUNGTR، بتعيين تلك المدخلات إلى
!>          1 قبل استخدامها، ثم استعادتها لاحقاً.)
!>

VP

!>          VP هو مصفوفة COMPLEX*16 من

TAU
