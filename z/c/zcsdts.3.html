الغرض:

!>
!> ZCSDTS تختبر ZUNCSD، والتي، نظرًا لمصفوفة X مقسمة موحدة بحجم M-by-M،
!>              Q  M-Q
!>       X = [ X11 X12 ] P   ،
!>           [ X21 X22 ] M-P
!>
!> تحسب CSD
!>
!>       [ U1    ]**T * [ X11 X12 ] * [ V1    ]
!>       [    U2 ]      [ X21 X22 ]   [    V2 ]
!>
!>                             [  I  0  0 |  0  0  0 ]
!>                             [  0  C  0 |  0 -S  0 ]
!>                             [  0  0  0 |  0  0 -I ]
!>                           = [---------------------] = [ D11 D12 ] .
!>                             [  0  0  0 |  I  0  0 ]   [ D21 D22 ]
!>                             [  0  S  0 |  0  C  0 ]
!>                             [  0  0  I |  0  0  0 ]
!>
!> وأيضًا SORCSD2BY1، والتي، نظرًا لـ
!>          Q
!>       [ X11 ] P   ،
!>       [ X21 ] M-P
!>
!> تحسب CSD ثنائية الأبعاد 1 × 2
!>
!>                                     [  I  0  0 ]
!>                                     [  0  C  0 ]
!>                                     [  0  0  0 ]
!>       [ U1    ]**T * [ X11 ] * V1 = [----------] = [ D11 ] ،
!>       [    U2 ]      [ X21 ]        [  0  0  0 ]   [ D21 ]
!>                                     [  0  S  0 ]
!>                                     [  0  0  I ]
!>

NAME

zcsdts - zcsdts

SYNOPSIS

#include <lapack.h>

INTEGER FUNCTION ZCSDTS(N, A, LDA, B, LDB, WORK, LWORK, RWORK, LRWORK, INFO)

Function/Subroutine Documentation

This subroutine is part of the LAPACK library. It is used for solving a system of linear equations. Specifically, it solves the complex singular value decomposition (SVD) of a general matrix.

The function `ZCSDTS` is designed to compute the singular value decomposition of a complex matrix A. The decomposition is of the form A = U * SIGMA * V**H, where U and V are unitary matrices and SIGMA is a real diagonal matrix with non-negative diagonal entries.

Arguments:

  • N: (input) INTEGER. The order of the matrix A.
  • A: (input/output) DOUBLE COMPLEX array, dimension (LDA, N). On entry, the N x N complex matrix A. On exit, the computed singular value decomposition of A.
  • LDA: (input) INTEGER. The leading dimension of the array A.
  • B: (output) DOUBLE COMPLEX array, dimension (LDB, N). This array is used for intermediate storage during the computation. The specific content on exit depends on the LAPACK routine's implementation.
  • LDB: (input) INTEGER. The leading dimension of the array B.
  • WORK: (workspace) DOUBLE COMPLEX array, dimension (LWORK). A workspace array used by the routine for intermediate computations.
  • LWORK: (input) INTEGER. The dimension of the array WORK.
  • RWORK: (workspace) DOUBLE PRECISION array, dimension (LRWORK). A workspace array used for real-valued intermediate computations.
  • LRWORK: (input) INTEGER. The dimension of the array RWORK.
  • INFO: (output) INTEGER. INFO = 0: successful exit. INFO < 0: if INFO = -i, then the i-th argument had an illegal value. INFO > 0: if INFO = i, then the algorithm failed to compute i singular values.
