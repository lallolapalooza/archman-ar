zcat(1)

الحزمة: gzip

التراخيص: GPL-3.0-or-later

GZIP(1) دليل الأوامر العامة GZIP(1)

الاسم

gzip، gunzip، zcat - ضغط أو فك ضغط الملفات

الملخص

gzip [ -acdfhklLnNrtvV19 ] [-S لاحقة] [ اسم ... ]
gunzip [ -acfhklLnNrtvV ] [-S لاحقة] [ اسم ... ]
zcat [ -fhLV ] [ اسم ... ]

الوصف

يقوم الأمر gzip بتقليل حجم الملفات المسماة باستخدام ترميز Lempel-Ziv (LZ77). كلما أمكن، يتم استبدال كل ملف بملف آخر بامتداد .gz، مع الاحتفاظ بنفس أذونات الملكية، وأوقات الوصول والتعديل. (الامتداد الافتراضي هو z لنظام MSDOS، ونظام FAT لنظام OS/2، ونظام FAT لنظام Windows NT، ونظام Atari.) إذا لم يتم تحديد أي ملفات، أو إذا كان اسم الملف هو "-"، فسيتم ضغط الإدخال القياسي إلى الإخراج القياسي. سيحاول الأمر gzip فقط ضغط الملفات العادية. على وجه الخصوص، سيتجاهل الروابط الرمزية.

إذا كان اسم الملف المضغوط طويلاً جدًا بالنسبة لنظام الملفات الخاص به، يقوم gzip بتقصيره. يحاول الأمر gzip تقصير الأجزاء التي يزيد طولها عن 3 أحرف فقط (يتم فصل الجزء بنقطة). إذا كان الاسم يتكون من أجزاء صغيرة فقط، فسيتم تقصير الأجزاء الأطول. على سبيل المثال، إذا كانت أسماء الملفات محدودة بـ 14 حرفًا، فسيتم ضغط gzip.msdos.exe إلى gzi.msd.exe.gz. لا يتم تقصير الأسماء على الأنظمة التي ليس لديها حد لطول اسم الملف.

افتراضيًا، يحتفظ gzip باسم الملف الأصلي والطابع الزمني في الملف المضغوط. يتم استخدام هذه المعلومات عند فك ضغط الملف باستخدام الخيار -N. يكون هذا مفيدًا عندما تم تقصير اسم الملف المضغوط أو عندما لم يتم الحفاظ على الطابع الزمني بعد نقل الملف.

يمكن استعادة الملفات المضغوطة إلى شكلها الأصلي باستخدام gzip -d أو gunzip أو zcat. إذا لم يكن الاسم الأصلي المحفوظ في الملف المضغوط مناسبًا لنظام الملفات الخاص به، فسيتم إنشاء اسم جديد من الاسم الأصلي لجعله صالحًا.

يأخذ gunzip قائمة بالملفات في سطر الأوامر الخاص به ويستبدل كل ملف ينتهي اسمه بـ .gz، أو -gz، أو .z، أو -z، أو _z (مع تجاهل حالة الأحرف) ويبدأ بالرقم السحري الصحيح بملف غير مضغوط بدون الامتداد الأصلي. يتعرف gunzip أيضًا على الامتدادات الخاصة .tgz و .taz كاختصارات لـ .tar.gz و .tar.Z على التوالي. عند الضغط، يستخدم gzip الامتداد .tgz عند الضرورة بدلاً من تقصير ملف بامتداد .tar.

يمكن لـ gunzip حاليًا فك ضغط الملفات التي تم إنشاؤها بواسطة gzip، أو zip، أو compress، أو compress -H، أو pack. يتم اكتشاف تنسيق الإدخال تلقائيًا. عند استخدام أول تنسيقين، يتحقق gunzip من CRC بقيمة 32 بت. بالنسبة لـ pack، يتحقق gunzip من الطول غير المضغوط. لم يتم تصميم تنسيق compress القياسي للسماح بفحوصات الاتساق. ومع ذلك، يمكن لـ gunzip أحيانًا اكتشاف ملف .Z تالف. إذا حصلت على خطأ عند فك ضغط ملف .Z، فلا تفترض أن ملف .Z صحيح لمجرد أن uncompress القياسي لا يشتكي. هذا يعني بشكل عام أن uncompress القياسي لا يتحقق من إدخاله، ويقوم بسعادة بإنشاء إخراج غير منطقي. تنسيق SCO compress -H (طريقة ضغط lzh) لا يتضمن CRC ولكنه يسمح أيضًا ببعض فحوصات الاتساق.

يمكن لـ gzip فك ضغط الملفات التي تم إنشاؤها بواسطة zip فقط إذا كانت تحتوي على عضو واحد مضغوط بطريقة 'deflate'. هذه الميزة مخصصة فقط للمساعدة في تحويل ملفات tar.zip إلى تنسيق tar.gz. لاستخراج ملف zip بعضو واحد، استخدم أمرًا مثل 'gunzip <foo.zip' أو 'gunzip -S .zip foo.zip'. لاستخراج ملفات zip بأعضاء متعددة، استخدم unzip بدلاً من gunzip.

الأمر zcat مطابق لـ gunzip -c. (على بعض الأنظمة، قد يتم تثبيت zcat باسم gzcat للحفاظ على الرابط الأصلي لـ compress.) يقوم zcat بفك ضغط قائمة ملفات في سطر الأوامر أو الإدخال القياسي الخاص به ويكتب البيانات غير المضغوطة إلى الإخراج القياسي. سيقوم zcat بفك ضغط الملفات التي تحتوي على الرقم السحري الصحيح بغض النظر عما إذا كان لها لاحقة .gz أم لا.

يستخدم الأمر gzip خوارزمية Lempel-Ziv المستخدمة في zip و PKZIP. يعتمد مقدار الضغط الذي تم الحصول عليه على حجم الإدخال وتوزيع السلاسل الفرعية الشائعة. عادةً ما يتم تقليل النصوص مثل الكود المصدري أو اللغة الإنجليزية بنسبة 60-70٪. الضغط بشكل عام أفضل بكثير من الضغط الذي يحققه LZW (المستخدم في compress)، أو ترميز هوفمان (المستخدم في pack)، أو ترميز هوفمان التكيفي (compact).

يتم إجراء الضغط دائمًا، حتى لو كان الملف المضغوط أكبر قليلاً من الأصل. أسوأ حالة للتوسع هي بضعة بايتات لرأس ملف gzip، بالإضافة إلى 5 بايتات لكل كتلة 32 كيلوبايت، أو نسبة توسع تبلغ 0.015٪ للملفات الكبيرة. العدد الفعلي للكتل المستخدمة في القرص لا يزداد تقريبًا.

يحافظ الأمر gzip عادةً على وضع الملف والطابع الزمني للتعديل عند الضغط أو فك الضغط. إذا كان لديك الامتيازات المناسبة، فإنه يحتفظ أيضًا بمالك الملف ومجموعته.

خيارات

-a --ascii
وضع نص ASCII: تحويل نهايات الأسطر باستخدام اصطلاحات محلية. هذا الخيار مدعوم فقط على بعض الأنظمة غير Unix. بالنسبة لنظام MSDOS، يتم تحويل CR LF إلى LF عند الضغط، ويتم تحويل LF إلى CR LF عند فك الضغط.
-c --stdout --to-stdout
كتابة الإخراج إلى الإخراج القياسي؛ الاحتفاظ بالملفات الأصلية دون تغيير. إذا كانت هناك ملفات إدخال متعددة، فسيتكون الإخراج من تسلسل من الأعضاء المضغوطة بشكل مستقل. للحصول على ضغط أفضل، قم بتجميع جميع ملفات الإدخال معًا قبل ضغطها.
-d --decompress --uncompress
فك الضغط.
-f --force
فرض الضغط أو فك الضغط حتى لو كان الملف يحتوي على روابط متعددة أو كان الملف المقابل موجودًا بالفعل، أو إذا كانت البيانات المضغوطة تُقرأ من طرفية أو تُكتب إليها. إذا لم تكن بيانات الإدخال بتنسيق يتعرف عليه gzip، وإذا تم أيضًا تحديد الخيار --stdout، فانسخ بيانات الإدخال دون تغيير إلى الإخراج القياسي: اجعل zcat يتصرف مثل cat. إذا لم يتم تحديد -f، وعندما لا يتم التشغيل في الخلفية، يطالب gzip بالتحقق مما إذا كان يجب الكتابة فوق ملف موجود.
-h --help
عرض شاشة المساعدة والخروج.
-k --keep
احتفظ (لا تحذف) بملفات الإدخال أثناء الضغط أو فك الضغط.
-l --list
لكل ملف مضغوط، قم بسرد الحقول التالية:


الحجم المضغوط: حجم الملف المضغوط
الحجم غير المضغوط: حجم الملف غير المضغوط
النسبة: نسبة الضغط (0.0٪ إذا كانت غير معروفة)
الاسم_غير_المضغوط: اسم الملف غير المضغوط

يتم إعطاء الحجم غير المضغوط على أنه -1 للملفات غير بتنسيق gzip، مثل الملفات .Z المضغوطة. للحصول على الحجم غير المضغوط لمثل هذا الملف، يمكنك استخدام:


zcat file.Z | wc -c

بالاقتران مع الخيار --verbose، يتم أيضًا عرض الحقول التالية:


الطريقة: طريقة الضغط
crc: CRC بقيمة 32 بت للبيانات غير المضغوطة
التاريخ والوقت: الطابع الزمني للملف غير المضغوط

طرق الضغط المدعومة حاليًا هي deflate، compress، lzh (SCO compress -H)، و pack. يتم إعطاء CRC على أنه ffffffff لملف غير بتنسيق gzip.

مع --name، يكون الاسم غير المضغوط والتاريخ والوقت هي تلك المخزنة داخل ملف الضغط إذا كانت موجودة.

مع --verbose، يتم أيضًا عرض إجمالي الأحجام ونسبة الضغط لجميع الملفات، ما لم تكن بعض الأحجام غير معروفة. مع --quiet، لا يتم عرض خطوط العنوان والإجمالي.

-L --license
عرض ترخيص gzip والخروج.
-n --no-name
عند الضغط، لا تقم بحفظ اسم الملف الأصلي والطابع الزمني افتراضيًا. (يتم دائمًا حفظ الاسم الأصلي إذا كان يجب تقصير الاسم.) عند فك الضغط، لا تقم باستعادة اسم الملف الأصلي إذا كان موجودًا (إزالة

zcat(1) - Arch Linux Manual Pages

NAME

zcat - decompresses using gzip and writes to standard output

SYNOPSIS

zcat [-fFLhc] [-n] [-S suffix] [-t] [-V] [-a] [-b bytes] [-c] [-d] [-k] [-N] [-o extension] [-q] [-r] [-s] [-T] [-U] [-v] [-Z] [file...]

DESCRIPTION

zcat is a filter that decompresses data compressed by gzip and writes the result to standard output. The standard gzip program can also be used to decompress with the command gzip -dc.

If the file specified on the command line is not in the gzip format, gzip will detect this and print a warning to the standard error. The incorrect file is not modified.

If no file name is given, or if the file name is -, then gzip reads from standard input and writes to standard output, with compression enabled for output if unden. This allows gzip to be used as a filter.

gzip uses the zlib library, which supports the compress format as well. So, gzip can decompress files compressed with compress. The decompression mode is automatically selected.

The decompression of gzip files is done transparently. If gzip finds a file that it cannot decompress (e.g., it is not in gzip format, or it is corrupted), it prints a message to standard error and continues with the next file.

OPTIONS

The options are similar to those of gzip, but are intended for decompressing files. Some options are ignored.

[-f
Force compression or decompression. If the compressed file has the (incorrect) `.Z' extension, and gzip is not specified, it will be processed.
-L
Display the gzip license.
-c
Write all output on standard output. De-compress or decompress transparently. This is always enabled.
-n
Do not save original file name.
-S suffix
Use suffix instead of the default suffix of. If no suffix is specified, then files without a suffix are tried.
-t
Test compression. Do not decompress, just check if the compressed file is valid.
-V
Output version information and exit.
-a
Text mode. Convert end-of-line codes to Unix format. This is the default for systems that use different end-of-line codes.
-b bytes
Limit the total size of the output to bytes bytes. This is the same as the -c option.
-d
Decompress.
-k
Keep temporary files.
-N
Save original file name.
-o extension
Use extension for the compressed file name. This is the same as the -S option.
-q
Quiet mode. Turn off all warnings and notices.
-r
Decompress recursively.
-s
Sift. Compress or decompress files separately.
-T
Test tar archives.
-U
Uncompress. This is the same as the -d option.
-v
Verbosely list files processed.
-Z
Decompress. This is the same as the -d option.

ADVANCED USAGE

A more advanced usage is to compress or decompress a file in memory. For example, to compress a file, you can use the command:

gzip -fc < file.txt > file.txt.gz

To decompress this file, you can use:

gzip -dc < file.txt.gz > file.txt

Or, more simply:

zcat < file.txt.gz > file.txt

ENVIRONMENT

The gzip command is affected by the following environment variables:

GZIP
Default options to be used when running gzip. Multiple options are separated by spaces and quoted if they contain spaces. The GZIP variable is not used when gzip is run by root.

Messages about incorrect or missing arguments are printed to standard error.

BUGS
