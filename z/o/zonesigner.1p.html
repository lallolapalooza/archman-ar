The zonesigner(1p) command is used to sign DNSSEC zone files.

KEYREC FILES

Keyrec files contain information about the cryptographic keys used for signing the zone.

ENTROPY

Entropy is a measure of randomness used in cryptographic operations. zonesigner requires sufficient entropy to generate strong keys.
