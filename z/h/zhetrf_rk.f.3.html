NAME

zhetrf_rk - zhetrf_rk computes the factorization of a general band matrix of bandwith k

SYNOPSIS

    SUBROUTINE zhetrf_rk( uplo, n, k, A, lda, ipiv, L, ldL, R, ldR, info )

      CHARACTER(LEN=1)    :: uplo
      INTEGER             :: n, k, lda, ldL, ldR, info
      COMPLEX(8)          :: A( lda, * )
      INTEGER             :: ipiv( * )
      COMPLEX(8)          :: L( ldL, * ), R( ldR, * )

Function/Subroutine Documentation

!> Solves the system of equations A * X = B.
!>
!> @param uplo Specifies whether the matrix A is upper or lower triangular.
!>        uplo = 'U' or 'u': A is upper triangular.
!>        uplo = 'L' or 'l': A is lower triangular.
!>
!> @param n The order of the matrix A. n >= 0.
!>
!> @param k The upper bandwidth of A. k >= 0.
!>
!> @param A The coefficient matrix A of dimension (lda, n).
!>
!> @param lda The leading dimension of the array A. lda >= max(1,n).
!>
!> @param ipiv The pivot indices of dimension (n). ipiv[i] records the
!>        row swapped with row i.
!>
!> @param L The factor L of dimension (ldL, n).
!>
!> @param ldL The leading dimension of the array L. ldL >= max(1,n).
!>
!> @param R The factor R of dimension (ldR, n).
!>
!> @param ldR The leading dimension of the array R. ldR >= max(1,n).
!>
!> @param info = 0: successful exit
!>         < 0: if info = -i, the i-th argument internal value was out of range.
!>         > 0: if info = i, the factorization has been completed, but a
!>              division by zero will occur if it is used to solve a system
!>              of equations.
!>
!> NOTE: INFO only stores the first occurrence of
!> a singularity, any subsequent occurrence of singularity
!> is not stored in INFO even though the factorization
!> always completes.
!>
