Function/Subroutine Documentation

                    

                        

                            ZHE SVXX computes a solution to a complex system of
                            Hermitian or real symmetric generalized
                            eigenvalue problems:

                        

                            (A - λ B) x = 0 or

                        

                            A x = λ B x

                        

                            where A and B are Hermitian or real symmetric
                            matrices and.

                        

                            It uses the s.v.d. based method described in

                        

                            [1] K. Finch, T. Gould, J. Halldorsson, and N. J. Higham,
                            “Condition Number and Accuracy
                            of the Solution of a Quadratic Eigenvalue Problem”,
                            SIAM Journal on Matrix Analysis and Applications,
                            37(2):629–650, 2016.

                        

                            This subroutine is the wrapper for the general
                            quadratic eigenvalue problem solver ZHE SVQ.

                        

                            This routine is called by ZHE SVXX.

                        

                            Returns the diagonal matrix D and the
                            upper triangular matrix U from the factorization
                            of Z. (For an explanation of D and U, see
                            zhesvxx.)

                        

                            If some componentwise error bound is not
                            guaranteed, then return with
                            RCOND = 0.0.

                        

                            ERROR BOUNDS

                        

                            Error bounds are computed by ZHE SVXX using the
                            singular values computed by ZHE SVQ.

                        

                            If RCOND (a value related to the reciprocal of the
                            condition number of the matrix pair (A, B)) is
                            returned as zero, then error bounds could not be
                            computed, and RCOND is not a reliable indicator
                            of the condition of the matrix pair.

                        

                            If RCOND > 0, the error bounds are guaranteed to
                            hold, provided that the library routines
                            used for the computation are accurate.

                        

                            The following two values are returned:

                        

                            a normwise error bound for the solution computed
                            by ZHE SVXX, and

                        

                            a componentwise error bound for the solution
                            computed by ZHE SVXX.

                        

                            The componentwise error bound is defined as:

                        

                            max { |x(i) - xbar(i)| / |xbar(i)| } for all i

                        

                            where xbar is the computed solution and x is the
                            true solution.

                        

                            The normwise error bound is defined as:

                        

                            || x - xbar || / || x ||

                        

                            where || . || denotes the 2-norm.

                        

                            The error bounds are computed under the assumption
                            that the input matrices A and B are Hermitian or
                            real symmetric.

                        

                            The value of NRHS is the number of right hand sides,
                            and hence the number of systems of equations to
                            solve.

                        

                            The value of J is the index of the first
                            right-hand side for which the error bound is
                            not guaranteed.

                        

                            If INFO = N+J, then the solution corresponding to
                            the Jth right-hand side is not guaranteed.

                        

                            The solutions corresponding to other right-hand sides
                            K with K > J may not be guaranteed as well, but
                            only the first such right-hand side is reported.

                        

                            If a small componentwise error is not requested
                            (PARAMS(3) = 0.0) then the Jth right-hand side is
                            the first with a normwise error bound that is
                            not guaranteed (the smallest J such that
                            ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3)
                            = 1.0) the Jth right-hand side is the first with
                            either a normwise or componentwise error bound
                            that is not guaranteed (the smallest J such that
                            either ERR_BNDS_NORM(J,1) = 0.0 or
                            ERR_BNDS_COMP(J,1) = 0.0). See the definition of
                            ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get
                            information about all of the right-hand sides
                            check ERR_BNDS_NORM or ERR_BNDS_COMP.
