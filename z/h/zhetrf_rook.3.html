الاسم

zhetrf_rook - إيجاد تفكيك شوري (Cholesky decomposition) لمصفوفة مركبة هيرميتية.

الملخص

SUBROUTINE zhetrf_rook( UPLO, N, A, LDA, NB, IPIV, WORK, LWORK, INFO )

  CHARACTER(1) :: UPLO
  INTEGER      :: N
  COMPLEX*16   :: A( LDA, * )
  INTEGER      :: LDA
  INTEGER      :: NB
  INTEGER      :: IPIV( * )
  COMPLEX*16   :: WORK( * )
  INTEGER      :: LWORK
  INTEGER      :: INFO

توثيق الدالة/الإجراء الفرعي

ZHETRF_ROOK تقوم بتفكيك مصفوفة مركبة هيرميتيةA بحجمNxN.

يتم استخدام خوارزمية تفكيك شوري مع تبديل صفوف وأعمدة (rook pivoting). هذا مفيد بشكل خاص عند التعامل مع مصفوفات غير محددة.

المعلمات

  • UPLO: (إدخال) CHARACTER*1. يحدد ما إذا كانت المصفوفة العلوية ('U') أو السفلية ('L') هي التي سيتم استخدامها.
  • N: (إدخال) INTEGER. رتبة المصفوفةA.
  • A: (إدخال/إخراج) COMPLEX*16 مصفوفة بحجمLDAxN. عند الإدخال، تحتوي على المصفوفة الهيرميتية. عند الإخراج، تحتوي على جزء من تفكيك شوري.
  • LDA: (إدخال) INTEGER. طول الصف الرئيسي للمصفوفةA.
  • NB: (إدخال) INTEGER. عرض الكتلة المستخدمة في تفكيك شوري.
  • IPIV: (إخراج) INTEGER مصفوفة بحجمN. تحتوي على معلومات التبديل.
  • WORK: (إخراج) COMPLEX*16 مصفوفة بحجمLWORK. مصفوفة عمل.
  • LWORK: (إدخال) INTEGER. طول مساحة العملWORK.
  • INFO: (إخراج) INTEGER. 0 إذا كان ناجحًا،<0 إذا كان هناك خطأ،>0 إذا كانت المصفوفة غير محددة.
