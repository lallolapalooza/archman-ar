توثيق الوظيفة/الروتين الفرعي

subroutine zhptrf (character uplo, integer n, complex*16, dimension( * ) ap, integer, dimension( * ) ipiv, integer info)

ZHPTRF

الغرض:

!>
!> ZHPTRF يحسب تحليل مصفوفة هرميتية مكدسة معقدة A باستخدام طريقة التنقيب القطري لبنش-كوفمان:
!>
!>    A = U*D*U**H  أو  A = L*D*L**H
!>
!> حيث U (أو L) هو حاصل ضرب مصفوفة تبديل ومصفوفة مثلثية عليا (سفلى) وحدوية،
!> و D مصفوفة هرميتية وقطرية كتلة مع كتل قطرية 1x1 و 2x2.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  يتم تخزين الجزء العلوي من A؛
!>          = 'L':  يتم تخزين الجزء السفلي من A.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

AP

!>          AP هو COMPLEX*16 array, dimension (N*(N+1)/2)
!>          عند الإدخال، الجزء العلوي أو السفلي من المصفوفة الهرميتية
!>          A، مكدسة عمودياً في مصفوفة خطية. يتم تخزين العمود j من A
!>          في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>
!>          عند الخروج، يتم تخزين المصفوفة القطرية الكتلة D والعوامل المستخدمة
!>          للحصول على العامل U أو L، كمصفوفة مثلثية مكدسة فوق A (انظر أدناه لمزيد من التفاصيل).
!>

IPIV

!>          IPIV هو INTEGER array, dimension (N)
!>          تفاصيل التبادلات وهيكل الكتلة لـ D.
!>          إذا كان IPIV(k) > 0، فإن الصفوف والأعمدة k و IPIV(k) تم تبديلها
!>          و D(k,k) هي كتلة قطرية 1x1.
!>          إذا كان UPLO = 'U' و IPIV(k) = IPIV(k-1) < 0، فإن الصفوف والأعمدة k-1 و -IPIV(k) تم تبديلها
!>          و D(k-1:k,k-1:k) هي كتلة قطرية 2x2. إذا كان UPLO = 'L' و IPIV(k) =
!>          IPIV(k+1) < 0، فإن الصفوف والأعمدة k+1 و -IPIV(k) تم تبديلها
!>          و D(k:k+1,k:k+1) هي كتلة قطرية 2x2.
!>

INFO

!>          INFO هو INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، فإن المعلمة i كانت لها قيمة غير قانونية
!>          > 0: إذا كان INFO = i، فإن D(i,i) يساوي صفرًا تمامًا. تم إكمال التحليل،
!>               ولكن المصفوفة القطرية الكتلة D منفردة تمامًا، وسوف يحدث قسمة على صفر إذا
!>               تم استخدامها لحل نظام من المعادلات.
!>

تفاصيل إضافية:

!>
!>  إذا كان UPLO = 'U'، فإن A = U*D*U**H، حيث
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  أي أن U هو حاصل ضرب الحدود P(k)*U(k)، حيث k يتناقص من n إلى
!>  1 بخطوات 1 أو 2، و D مصفوفة قطرية كتلة بكتل قطرية 1x1 و 2x2 D(k).
!>  P(k) هي مصفوفة تبديل كما تحددها IPIV(k)، و U(k) مصفوفة مثلثية عليا وحدوية، بحيث
!>  إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  إذا كان s = 1، فإن D(k) يحل محل A(k,k)، و v يحل محل A(1:k-1,k).
!>  إذا كان s = 2، فإن المثلث العلوي لـ D(k) يحل محل A(k-1,k-1)، A(k-1,k)،
!>  و A(k,k)، و v يحل محل A(1:k-2,k-1:k).
!>
!>  إذا كان UPLO = 'L'، فإن A = L*D*L**H، حيث
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  أي أن L هو حاصل ضرب الحدود P(k)*L(k)، حيث k يزداد من 1 إلى
!>  n بخطوات 1 أو 2، و D مصفوفة قطرية كتلة بكتل قطرية 1x1 و 2x2 D(k).
!>  P(k) هي مصفوفة تبديل كما تحددها IPIV(k)، و L(k) مصفوفة مثلثية سفلى وحدوية، بحيث
!>  إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  إذا كان s = 1، فإن D(k) يحل محل A(k,k)، و v يحل محل A(k+1:n,k).
!>  إذا كان s = 2، فإن المثلث السفلي لـ D(k) يحل محل A(k,k)، A(k+1,k)،
!>  و A(k+1,k+1)، و v يحل محل A(k+2:n,k:k+1).
!>
