subroutine zhbevx_2stage (jobz, range, uplo, n, kd, ab, ldab, q, ldq, vl, vu, il, iu, abstol, m, w, z, ldz, work, lwork, rwork, iwork, ifail, info)

ZHBEVX_2STAGE يحسب القيم الذاتية، واختياريًا، المتجهات الذاتية اليسرى و/أو اليمنى لمصفوفات هيرميتية معقدة

الغرض:

!>
!> ZHBEVX_2STAGE يحسب قيمًا ذاتية مختارة، واختياريًا، متجهات ذاتية
!> لمصفوفة هيرميتية معقدة A باستخدام تقنية المرحلتين (2stage)
!> للاختزال إلى مصفوفة ثلاثية الأقطار. يمكن اختيار القيم الذاتية والمتجهات الذاتية
!> عن طريق تحديد نطاق من القيم أو نطاق
!> من الفهارس للقيم الذاتية المطلوبة.
!>

المعلمات

JOBZ 
!>          JOBZ is CHARACTER*1
!>          = 'N':  حساب القيم الذاتية فقط؛
!>          = 'V':  حساب القيم الذاتية والمتجهات الذاتية.
!>                  غير متاح في هذا الإصدار.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          = 'A': سيتم العثور على جميع القيم الذاتية؛
!>          = 'V': سيتم العثور على جميع القيم الذاتية في الفترة نصف المفتوحة (VL,VU]
!>                 ؛
!>          = 'I': سيتم العثور على القيم الذاتية من IL-th إلى IU-th.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  يتم تخزين الجزء العلوي من A؛
!>          = 'L':  يتم تخزين الجزء السفلي من A.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A. N >= 0.
!>

KD

!>          KD is INTEGER
!>          عدد الأقطار الفائقة للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفائقة إذا كان UPLO = 'L'. KD >= 0.
!>

AB

!>          AB is COMPLEX*16 array, dimension (LDAB, N)
!>          عند الإدخال، الجزء العلوي أو السفلي من مصفوفة هيرميتية ذات نطاق
!>          A، مخزنة في أول KD+1 صفوف من المصفوفة.
!>          يتم تخزين العمود j من A في العمود j من المصفوفة AB
!>          على النحو التالي:
!>          إذا كان UPLO = 'U'، AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd)<=i<=j؛
!>          إذا كان UPLO = 'L'، AB(1+i-j,j) = A(i,j) لـ j<=i<=min(n,j+kd).
!>
!>          عند الخروج، يتم الكتابة فوق AB بالقيم التي تم إنشاؤها أثناء
!>          الاختزال إلى شكل ثلاثي الأقطار.
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرائد للمصفوفة AB. LDAB >= KD + 1.
!>

Q

!>          Q is COMPLEX*16 array, dimension (LDQ, N)
!>          إذا كان JOBZ = 'V'، فإن المصفوفة الوحدوية N-by-N المستخدمة في
!>                          الاختزال إلى شكل ثلاثي الأقطار.
!>          إذا كان JOBZ = 'N'، فلا يتم الرجوع إلى المصفوفة Q.
!>

LDQ

!>          LDQ is INTEGER
!>          البعد الرائد للمصفوفة Q. إذا كان JOBZ = 'V'، فإن
!>          LDQ >= max(1,N).
!>

VL

!>          VL is DOUBLE PRECISION
!>          إذا كان RANGE='V'، الحد الأدنى للفترة التي سيتم
!>          البحث فيها عن القيم الذاتية. VL < VU.
!>          لا يتم الرجوع إليها إذا كان RANGE = 'A' أو 'I'.
!>

VU

!>          VU is DOUBLE PRECISION
!>          إذا كان RANGE='V'، الحد الأعلى للفترة التي سيتم
!>          البحث فيها عن القيم الذاتية. VL < VU.
!>          لا يتم الرجوع إليها إذا كان RANGE = 'A' أو 'I'.
!>

IL

!>          IL is INTEGER
!>          إذا كان RANGE='I'، فهرس
!>          أصغر قيمة ذاتية سيتم إرجاعها.
!>          1 <= IL <= IU <= N، إذا كان N > 0؛ IL = 1 و IU = 0 إذا كان N = 0.
!>          لا يتم الرجوع إليها إذا كان RANGE = 'A' أو 'V'.
!>

IU

!>          IU is INTEGER
!>          إذا كان RANGE='I'، فهرس
!>          أكبر قيمة ذاتية سيتم إرجاعها.
!>          1 <= IL <= IU <= N، إذا كان N > 0؛ IL = 1 و IU = 0 إذا كان N = 0.
!>          لا يتم الرجوع إليها إذا كان RANGE = 'A' أو 'V'.
!>

ABSTOL

!>          ABSTOL is DOUBLE PRECISION
!>          التفاوت المطلق في الخطأ للقيم الذاتية.
!>          يتم قبول قيمة ذاتية تقريبية على أنها متقاربة
!>          عندما يتم تحديد أنها تقع في فترة [a,b]
!>          بعرض أقل من أو يساوي
!>
!>          ABSTOL + EPS * max( |a|,|b| ) ،
!>
!>          حيث EPS هي دقة الجهاز. إذا كانت ABSTOL أقل من
!>          أو تساوي الصفر، فسيتم استخدام EPS*|T| بدلاً منها،
!>          حيث |T| هو المعيار 1 للمصفوفة ثلاثية الأقطار التي تم الحصول عليها
!>          عن طريق اختزال AB إلى شكل ثلاثي الأقطار.
!>
!>          سيتم حساب القيم الذاتية بأكبر قدر من الدقة عندما يتم
!>          تعيين ABSTOL إلى ضعف حد الانخفاض (underflow threshold) 2*DLAMCH('S')، وليس صفرًا.
!>          إذا عادت هذه الروتينات الفرعية بـ INFO>0، مما يشير إلى أن بعض
!>          المتجهات الذاتية لم تتقارب، حاول تعيين ABSTOL إلى
!>          2*DLAMCH('S').
!>
!>          انظر بواسطة Demmel و
!>          Kahan، LAPACK Working Note #3.
!>

M

!>          M is INTEGER
!>          العدد الإجمالي للقيم الذاتية التي تم العثور عليها. 0 <= M <= N.
!>          إذا كان RANGE = 'A'، M = N، وإذا كان RANGE = 'I'، M = IU-IL+1.
!>

W

!>          W is DOUBLE PRECISION array, dimension (N)
!>          تحتوي العناصر M الأولى على القيم الذاتية المحددة بترتيب تصاعدي.
!>

Z

!>          Z is COMPLEX*16 array, dimension (LDZ, max(1,M))
!>          إذا كان JOBZ = 'V'، فعندما يكون INFO = 0، تحتوي الأعمدة M الأولى من Z
!>          على المتجهات الذاتية العمودية للمصفوفة A
!>          المقابلة للقيم الذاتية المحددة، مع حمل العمود i
!>          من Z للمتجه الذاتي المرتبط بـ W(i).
!>          إذا فشل متجه ذاتي في التقارب، فإن هذا العمود من Z
!>          يحتوي على أحدث تقريب للمتجه الذاتي، ويتم إرجاع فهرس
!>          المتجه الذاتي في IFAIL.
!>          إذا كان JOBZ = 'N'، فلا يتم الرجوع إلى Z.
!>          ملاحظة: يجب على المستخدم التأكد من توفير ما لا يقل عن max(1,M) أعمدة
!>          في المصفوفة Z؛ إذا كان RANGE = 'V'، فإن القيمة الدقيقة لـ M
!>          غير معروفة مسبقًا ويجب استخدام حد أعلى.
!>

LDZ

!>          LDZ is INTEGER
!>          البعد الرائد للمصفوفة Z. LDZ >= 1، وإذا
!>          كان JOBZ = 'V'، فإن LDZ >= max(1,N).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LWORK)
!>

LWORK

!>          LWORK is INTEGER
!>          طول المصفوفة WORK. LWORK >= 1، عندما يكون N <= 1؛
!>          وإلا
!>          إذا كان JOBZ = 'N' و N > 1، فيجب الاستعلام عن LWORK.
!>                                   LWORK = MAX(1, dimension) حيث
!>                                   dim

NAME

zhbevx_2stage - computes the eigenvalues and eigenvectors of a complex Hermitian-band matrix.

SYNOPSIS

 SUBROUTINE ZHBEVX_2STAGE(
        JOBZ, UPLO, RANGE, N, KD, AB, LDAB, Q, LDQ, VL, VU, IL, IU,
        OFFG, TOL, M, NZ, A, LDA, Z, LDZ, WORK, RWORK, IWORK,
        IFAIL, INFO)
 CHARACTER(LEN=1) JOBZ, UPLO, RANGE
 INTEGER N, KD, LDAB, LDQ, IL, IU, M, NZ, LDA, LDZ
 INTEGER WORK( * ), RWORK( * ), IWORK( * ), IFAIL( * )
 DOUBLE PRECISION VL, VU, OFFG, TOL
 COMPLEX*16 AB( LDAB, * ), Q( LDQ, * ), Z( LDZ, * )
 DOUBLE PRECISION WORK( * )
 COMPLEX*16 A( LDA, * ), Z( LDZ, * )

Function/Subroutine Documentation

ZHBEVX_2STAGE calculates the eigenvalues and eigenvectors of a complex Hermitian band matrix using a two-stage process. This routine is part of LAPACK's interface for band matrices.

Arguments

[in] JOBZ
CHARACTER*1. Specifies whether to compute eigenvectors.
JOBZ = 'N': Eigenvalues only.
JOBZ = 'V': Eigenvalues and eigenvectors.
[in] UPLO
CHARACTER*1. Specifies whether the matrix A is upper or lower Hermitian-band.
UPLO = 'U': Upper.
UPLO = 'L': Lower.
[in] RANGE
CHARACTER*1. Specifies the range of eigenvalues to be computed.
RANGE = 'A': All eigenvalues.
RANGE = 'V': All eigenvalues in the interval (VL, VU].
RANGE = 'I': VL-th through IU-th eigenvalues.
[in] N
INTEGER. The order of the matrix A. N >= 0.
[in] KD
INTEGER. The number of super- or sub-diagonals of the matrix A. KD >= 0.
[in,out] AB
COMPLEX*16 array, dimension (LDAB, N). On entry, the upper or lower Hermitian-band matrix AB. On exit, AB is overwritten by values generated during the reduction of AB to upper triangular form (or its transpose).
[in] LDAB
INTEGER. The leading dimension of the array AB. LDAB >= KD + 1.
[out] Q
COMPLEX*16 array, dimension (LDQ, N). If JOBZ = 'V', Q contains the orthonormal eigenvectors of A, with the i-th column of Q holding the eigenvector corresponding to the i-th eigenvalue in the array W. If JOBZ = 'N', Q is not referenced.
[in] LDQ
INTEGER. The leading dimension of the array Q. If JOBZ = 'V', LDQ >= max(1, N).
[in] VL
DOUBLE PRECISION. The lower bound of the interval for the desired eigenvalues. Not used if RANGE = 'A' or RANGE = 'I'.
[in] VU
DOUBLE PRECISION. The upper bound of the interval for the desired eigenvalues. Not used if RANGE = 'A' or RANGE = 'I'.
[in] IL
INTEGER. The starting index for the desired eigenvalues. Not used if RANGE = 'A' or RANGE = 'V'.
[in] IU
INTEGER. The ending index for the desired eigenvalues. Not used if RANGE = 'A' or RANGE = 'V'.
[out] OFFG
DOUBLE PRECISION. Offset for the diagonal entries of the general tridiagonal matrix.
[in] TOL
DOUBLE PRECISION. Tolerance for the eigenvalue computation. If TOL < 0, the default value is used. If TOL = 0, the default value is used. If TOL > 0, then the absolute and relative thresholds are set to TOL.
[out] M
INTEGER. The number of eigenvalues found.
[out] NZ
INTEGER. The number of eigenvectors computed. If JOBZ = 'A', NZ = N. If JOBZ = 'V', NZ = N. If JOBZ = 'N', NZ = 0.
[out] A
COMPLEX*16 array, dimension (LDA, N). If JOBZ = 'V', A contains the general tridiagonal matrix.
[in] LDA
INTEGER. The leading dimension of the array A. LDA >= N.
[out] Z
COMPLEX*16 array, dimension (LDZ, N). If JOBZ = 'V', Z contains the eigenvectors of the corresponding tridiagonal matrix.
[in] LDZ
INTEGER. The leading dimension of the array Z. LDZ >= N.
[out] WORK
COMPLEX*16 array, dimension (LWORK). For optimal performance, LWORK >= max(2*N, N*NB), where NB is the block size of the current implementation. If LWORK = -1, then the workspace query is assumed; the routine only calculates the optimal size of the WORK array, and returns this value as the first entry of the WORK array. The size of WORK array is calculated as: Dimension = max(2*N, N*NB) + N
where NB is the block size of the current implementation.
The dimension of the WORK array is at least max(2*N, N*NB) + N.
if JOBZ = 'V' and N > 1, LWORK must be queried.
If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal sizes of the WORK, RWORK and IWORK arrays, returns these values as the first entries of the WORK, RWORK and IWORK arrays, and no error message related to LWORK or LRWORK or LIWORK is issued by XERBLA.
The dimension of the WORK array is at least max(2*N, N*NB) + N. where NB is the block size of the current implementation. If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available.
[out] RWORK
DOUBLE PRECISION array, dimension (7*N).
[out] IWORK
INTEGER array, dimension (5*N).
[out] IFAIL
INTEGER array, dimension (N). If JOBZ = 'V', then if INFO = 0, the first M elements of IFAIL are zero. If INFO > 0, then IFAIL contains the indices of the eigenvectors that failed to converge. If JOBZ = 'N', then IFAIL is not referenced.
[out] INFO
INTEGER. = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value > 0: if INFO = i, then i eigenvectors failed to converge. Their indices are stored in array IFAIL.
!>                                   where KD is the size of the band.
!>                                   NTHREADS is the number of threads used when
!>                                   openMP compilation is enabled, otherwise =1.
!>          If JOBZ = 'V' and N > 1, LWORK must be queried. Not yet available.
!>
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal sizes of the WORK, RWORK and
!>          IWORK arrays, returns these values as the first entries of
!>          the WORK, RWORK and IWORK arrays, and no error message
!>          related to LWORK or LRWORK or LIWORK is issued by XERBLA.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (7*N)

IWORK

!>          IWORK is INTEGER array, dimension (5*N)

IFAIL

!>          IFAIL is INTEGER array, dimension (N)
!>          If JOBZ = 'V', then if INFO = 0, the first M elements of
