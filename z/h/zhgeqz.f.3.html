NAME

zhgeqz - subroutine to find the generalized Schur form of two complex matrices, H and T, and to compute the generalized eigenvalues and generalized Schur vectors.

SYNOPSIS

SUBROUTINE ZHGEQZ( JOB, COMPQ, COMPZ, N, ILOZ, IHIZ, A, LDA, B, LDB,
     &           ALPHA, BETA, Q, LDQ, Z, LDZ, WORK, LWORK, INFO )
  • JOB INTEGER

    Specifies whether to compute the generalized Schur factorizations of A and B.

    JOB = 0: compute the Schur factorizations of A and B only.

    JOB = 1: compute the Schur factorizations of A and B and the generalized Schur vectors.

  • COMPQ CHARACTER*1

    Specifies whether to compute the generalized Schur vectors Q.

    COMPQ = 'N': do not compute Q.

    COMPQ = 'V': compute Q.

  • COMPZ CHARACTER*1

    Specifies whether to compute the generalized Schur vectors Z.

    COMPZ = 'N': do not compute Z.

    COMPZ = 'V': compute Z.

  • N INTEGER

    The order of the matrices A and B. N >= 0.

  • ILOZ INTEGER

    The starting row and column index of the submatrix of Z that is required.

  • IHIZ INTEGER

    The ending row and column index of the submatrix of Z that is required.

  • A COMPLEX*16 array, dimension (LDA, N)

    On entry, the upper Hessenberg matrix A.

    On exit, if INFO = 0 and JOB = 1, A contains the generalized Schur factorization of A.

  • LDA INTEGER

    The leading dimension of A.

  • B COMPLEX*16 array, dimension (LDB, N)

    On entry, the upper triangular matrix B.

    On exit, if INFO = 0 and JOB = 1, B contains the generalized Schur factorization of B.

  • LDB INTEGER

    The leading dimension of B.

  • ALPHA COMPLEX*16 array, dimension (max(N,0))

    The first part of the distributed complex array ALPHA, containing the diagonal elements of the upper triangular matrix T, or the eigenvalues of the generalized eigenvalue problem A*z = lambda*B*z.

  • BETA COMPLEX*16 array, dimension (max(N,0))

    The first part of the distributed complex array BETA, containing the diagonal elements of the upper triangular matrix B, or values that determine the generalized eigenvalues of the generalized eigenvalue problem A*z = lambda*B*z.

    The generalized eigenvalues are the ratios ALPHA(i)/BETA(i).

  • Q COMPLEX*16 array, dimension (LDQ, N)

    On exit, if COMPQ = 'V', Q contains the unitary matrix Q such that Q*A*Q**H is upper triangular and Q*B*Q**H is upper triangular.

  • LDQ INTEGER

    The leading dimension of Q.

  • Z COMPLEX*16 array, dimension (LDZ, N)

    On exit, if COMPZ = 'V', Z contains the unitary matrix Z such that Z*A*Z**H is upper triangular and Z*B*Z**H is upper triangular.

  • LDZ INTEGER

    The leading dimension of Z.

  • WORK COMPLEX*16 array, dimension (LWORK)

    Workspace array.

  • LWORK INTEGER

    The dimension of the array WORK. LWORK >= max(N,1).

    If LWORK = -1, then LWORK is determined and the required workspace size is returned in the first entry of WORK.

  • INFO INTEGER

    = 0: successful exit.

    < 0: if INFO = -i, then the i-th argument had an illegal value.

    > 0: the QZ iteration failed to converge. The error is with INFO = i. The diagonal matrix R (in advanced notation) is not yet in Schur vector form, but ALPHA(i) and BETA(i) should be correct for i > INFO.

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines.

The routine computes the generalized Schur factorization of two complex matrices A and B, and optionally the generalized Schur vectors.

The generalized Schur factorization is defined as:

A = Q * H * Z**H
B = Q * T * Z**H

where Q and Z are unitary matrices, and H and T are upper triangular matrices.

The routine also computes the generalized eigenvalues of the problem A*x = lambda*B*x, which are given by the ratios of the diagonal elements of H and T:

lambda = H(i,i) / T(i,i)

If T(i,i) is zero, the generalized eigenvalue is infinite.

RWORK
RWORK is DOUBLE PRECISION array, dimension (N)
INFO

INFO is INTEGER

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

= 1,...,N: the QZ iteration did not converge. (H,T) is not in Schur form, but ALPHA(i) and BETA(i), i=INFO+1,...,N should be correct.

= N+1,...,2*N: the shift calculation failed. (H,T) is not in Schur form, but ALPHA(i) and BETA(i), i=INFO-N+1,...,N should be correct.
