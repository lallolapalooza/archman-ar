الغرض:

!>
!> ZHBGVD يحسب جميع القيم الذاتية، واختياريًا، المتجهات الذاتية
!> لمشكلة القيم الذاتية المعممة الهرميتية المحددة، ذات النطاق،
!> بالشكل A*x=(lambda)*B*x. هنا يُفترض أن A و B هرميتيتان
!> ومتناهيتان، وأن B موجبة محددة أيضًا. إذا كانت المتجهات الذاتية
!> مطلوبة، فإنه يستخدم خوارزمية التقسيم والغزو.
!>
!>

!>          = 'U':  المثلثات العلوية للمصفوفتين A و B مخزنة؛

!>

KB

!>          KB هو INTEGER
!>          عدد الأقطار الفائقة للمصفوفة B إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفرعية إذا كان UPLO = 'L'. KB >= 0.
!>

AB

!>          AB هي مصفوفة COMPLEX*16، ذات البعد (LDAB, N)
!>          عند الإدخال، المثلث العلوي أو السفلي للمصفوفة الهرميتية
!>          المحددة، مخزنة في أول ka+1 صفوف للمصفوفة.
!>          العمود j من A مخزن في العمود j للمصفوفة AB
!>          على النحو التالي:
!>          إذا كان UPLO = 'U'، فإن AB(ka+1+i-j,j) = A(i,j) لـ max(1,j-ka)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j) = A(i,j) لـ j<=i<=min(n,j+ka).
!>
!>          عند الخروج، يتم تدمير محتويات AB.
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرئيسي للمصفوفة AB.  LDAB >= KA+1.
!>

BB

!>          BB هي مصفوفة COMPLEX*16، ذات البعد (LDBB, N)
!>          عند الإدخال، المثلث العلوي أو السفلي للمصفوفة الهرميتية
!>          المحددة، مخزنة في أول kb+1 صفوف للمصفوفة.
!>          العمود j من B مخزن في العمود j للمصفوفة BB
!>          على النحو التالي:
!>          إذا كان UPLO = 'U'، فإن BB(kb+1+i-j,j) = B(i,j) لـ max(1,j-kb)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن BB(1+i-j,j) = B(i,j) لـ j<=i<=min(n,j+kb).
!>
!>          عند الخروج، عامل S من التحلل Cholesky المنفصل
!>          B = S**H*S، كما تم إرجاعه بواسطة ZPBSTF.
!>

LDBB

!>          LDBB هو INTEGER
!>          البعد الرئيسي للمصفوفة BB.  LDBB >= KB+1.
!>

W

!>          W هي مصفوفة DOUBLE PRECISION، ذات البعد (N)
!>          إذا كان INFO = 0، فإن القيم الذاتية مرتبة تصاعديًا.
!>

Z

!>          Z هي مصفوفة COMPLEX*16، ذات البعد (LDZ, N)
!>          إذا كان JOBZ = 'V'، فعندما يكون INFO = 0، تحتوي Z على المصفوفة Z للمتجهات
!>          الذاتية، حيث يحتوي العمود i من Z على المتجه الذاتي
!>          المرتبط بـ W(i). يتم تطبيع المتجهات الذاتية بحيث يكون Z**H*B*Z = I.
!>          إذا كان JOBZ = 'N'، فلا يتم الرجوع إلى Z.
!>

LDZ

!>          LDZ هو INTEGER
!>          البعد الرئيسي للمصفوفة Z.  LDZ >= 1، وإذا كان

!>

WORK

!>          WORK هي مصفوفة COMPLEX*16، ذات البعد (MAX(1,LWORK))

!>          IWORK، ويرجع هذه القيم كأول إدخالات
!>          للمصفوفات WORK و RWORK و IWORK، ولا يصدر XERBLA أي رسالة خطأ
!>          متعلقة بـ LWORK أو LRWORK أو LIWORK.

!>          < 0:  إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية

NAME

zhbgvd - computes the eigenvalues and eigenvectors of a complex Hermitian-definite generalized eigenvalue problem A*z = lambda*B*z, where A and B are Hermitian generalized band matrices.

Function/Subroutine Documentation

ZHBGVD computes the eigenvalues and eigenvectors of a complex Hermitian-definite generalized eigenvalue problem A*z = lambda*B*z, where A and B are Hermitian generalized band matrices.

Here A and B are assumed to satisfy the following conditions:

  • A is a Hermitian band matrix, stored in the array AB.
  • B is a Hermitian positive definite band matrix, stored in the array BB.

The problem is solved by reducing the problem to an ITI eigenvalue problem using the Cholesky decomposition of B, B = S*S', and then solving A*z = lambda*B*z for S' * A * S * y = lambda * y, where z = S * y.

The routines then call ZHPGVD to compute the eigenvalues and eigenvectors.

The arguments are:

JOBZ
CHARACTER*1.
= "V": compute the eigenvectors of the generalized eigenvalue problem.
= "N": compute the eigenvalues only.
UPLO
CHARACTER*1.
= "U": Upper triangle of A and B is stored.
= "L": Lower triangle of A and B is stored.
N
INTEGER. The order of the matrices A and B. N >= 0.
KA
INTEGER. The number of super-diagonals of A. 0 <= KA <= N-1.
KB
INTEGER. The number of super-diagonals of B. 0 <= KB <= N-1.
AB
COMPLEX*16 array, dimension (LDAB, K+1).
On entry, the upper or lower triangle of the Hermitian band matrix A, in the band storage format. See the description of ATBS for the format.
LDAB
INTEGER. The leading dimension of the array AB. LDAB >= LDAB.
BB
COMPLEX*16 array, dimension (LDBB, K+1).
On entry, the upper or lower triangle of the Hermitian positive definite band matrix B, in the band storage format. See the description of ATBS for the format.
LDBB
INTEGER. The leading dimension of the array BB. LDBB >= KB+1.
D
DOUBLE PRECISION array, dimension (N).
On exit, the eigenvalues, in ascending order. If UPLO = "U", the real parts of the eigenvalues are in D(1), ..., D(N). If UPLO = "L", the real parts of the eigenvalues are in D(1), ..., D(N).
Z
COMPLEX*16 array, dimension (LDZ, N).
If JOBZ = "V", Z contains the eigenvectors of the generalized eigenvalue problem. The normalisation and the sign is arbitrary for each eigenvector.
If JOBZ = "N", Z is not accessed.
LDZ
INTEGER. The leading dimension of the array Z. LDZ >= (N, 1) if JOBZ = "V", and LDZ >= 1 if JOBZ = "N".
WORK
COMPLEX*16 array, dimension (3*N).
RWORK
DOUBLE PRECISION array, dimension (N).
INFO
INTEGER.
= 0: successful exit.
< 0: if INFO = -i, the i-th argument had an illegal value.
> 0: if INFO = i, ZHEGV returned i eigenvectors of B that did not have positive real parts, and whose Cholesky factorization could not be computed.
