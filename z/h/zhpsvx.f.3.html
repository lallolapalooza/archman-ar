NAME

zhpsvx - A wrapper to ZHPSVX to convert from the conventional and packed storage formats to the standard lower- or upper-packaged format.

SYNOPSIS

    SUBROUTINE ZHPSVX(FACT, TRANS, N, NRHS, AB, LDAB, B, LDB, X, LDX, RCOND,
                     FERR, BERR, INFO)
        LOGICAL              :: FACT, TRANS
        INTEGER              :: INFO, LDB, LDAB, LDX, N, NRHS
        DOUBLE PRECISION     :: RCOND
        COMPLEX*16           :: AB( LDAB, * ), B( LDB, * ), X( LDX, * )
        DOUBLE PRECISION     :: BERR( * ), FERR( * )

The subroutine called, unless FACT is FALSE or FALSE.

    CALL ZHPTRF( UPLO, N, AB, INFO )
    CALL ZHPCON( UPLO, N, AB, RCOND, WORK, INFO )
    CALL ZHPsvx( UPLO, TRANS, N, NRHS, AB, LDAB, B, LDB, X, LDX, RCOND,
                 FERR, BERR, WORK, INFO )

Function/Subroutine Documentation

ZHPSVX

    zhpsvx.f(3)

This routine uses the Minimum Relative Residual (MRRR) algorithm to compute the solution to a complex conjugate transposed, symmetric, Hermitian positive definite band matrix A or a complex conjugate transposed, symmetric, Hermitian positive definite matrix A. The matrix A is represented in band storage format.

This routine is a wrapper to ZHPsvx to convert from the conventional and packed storage formats to the standard lower- or upper-packaged format.

Arguments:

FACT
LOGICAL. On entry, FACT specifies whether or not the factorization of the matrix A has been computed and passed to the routines.
True.
The array AB contains the factors R and T of the matrix A.
False.
The array AB must be the matrix A, and the routines will compute the factorization of A.

On exit, FACT is set to TRUE.

TRANS
LOGICAL. On entry, TRANS specifies the form of the system of equations to be solved.
True.
AH*X = B
False.
A*X = B
N
INTEGER. The order of the matrix A. N >= 0.
NRHS
INTEGER. The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.
AB
COMPLEX*16 array, dimension (LDAB,N). Before entry, the N-by-N part of AB must contain the upper and lower triangular matrices R and T, respectively. See the Further Details section for the storage format. On exit, if FACT is FALSE, AB is overwritten by details of the factorization and also by the factors R and T.
LDAB
INTEGER. The leading dimension of the array AB. LDAB >= max(1,N).
B
COMPLEX*16 array, dimension (LDB,NRHS). The N-by-NRHS matrix B, the right hand side matrix.
LDB
INTEGER. The leading dimension of the array B. LDB >= max(1,N).
X
COMPLEX*16 array, dimension (LDX,NRHS). On exit, the N-by-NRHS matrix containing the solution to the systems of equations.
LDX
INTEGER. The leading dimension of the array X. LDX >= max(1,N).
RCOND
DOUBLE PRECISION. On exit, the reciprocal of the condition number of the matrix A. The matrix A is nonsingular if RCOND is not equal to zero. The matrix is singular to working precision if RCOND is less than machine precision.
FERR
DOUBLE PRECISION array, dimension (NRHS). On exit, FERR(j) is an estimate of the relative forward error in the j-th solution vector, which is returned in the j-th column of X. FERR(j) is returned only if INFO = 0. A small relative error is returned only if the matrix A is nonsingular and the solution X is accurate.
BERR
DOUBLE PRECISION array, dimension (NRHS). On exit, BERR(j) is the componentwise error bound for the j-th solution vector, which is returned in the j-th column of X. BERR(j) is returned only if INFO = 0. BERR is returned only if INFO = 0.
INFO
INTEGER. = 0: Successful exit. The solution to the system of equations has been computed, and FERR and BERR have been computed. < 0: If INFO = -i, the i-th argument had an illegal value. > 0: If INFO = i, and i is <= N: D(i,i) is exactly zero. The factorization has been completed but the factor D is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned. = N+1: D is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.

Further Details:

      The packed storage scheme is illustrated by the following example
      when N = 4, UPLO = 'U':

      Two-dimensional storage of the Hermitian matrix A:

         a11 a12 a13 a14
             a22 a23 a24
                 a33 a34     (aij = conjg(aji))
                     a44

      Packed storage of the upper triangle of A:

      AP = [ a11, a12, a22, a13, a23, a33, a14, a24, a34, a44 ]
