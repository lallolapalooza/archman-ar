zip_file_attributes_init(3)

الحزمة: libzip

التراخيص: BSD

ZIP_FILE_ATTRIBUTES_INIT(3) دليل الدوال المكتبية ZIP_FILE_ATTRIBUTES_INIT(3)

الاسم

zip_file_attributes_init — تهيئة بنية سمات ملف الـ zip

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

void
zip_file_attributes_init(zip_file_attributes_t *attributes);

الوصف

تقوم الدالة zip_file_attributes_init() بتهيئة بنية zip_file_attributes_t بقيم افتراضية. يجب استدعاؤها قبل تعديل مثل هذه البنية لأول مرة.

انظر أيضًا

libzip(3), zip_source_function(3)

التاريخ

تمت إضافة zip_file_attributes_init() في libzip 1.7.0.
