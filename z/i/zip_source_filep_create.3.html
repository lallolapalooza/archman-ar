zip_source_filep_create(3)

الحزمة: libzip

التراخيص: BSD

ZIP_SOURCE_FILEP(3) دليل وظائف المكتبة ZIP_SOURCE_FILEP(3)

الاسم

zip_source_filep، zip_source_filep_create — إنشاء مصدر بيانات من FILE *

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

zip_source_t *
zip_source_filep(zip_t *archive, FILE *file, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_filep_create(FILE *file, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

الوصف

تقوم الدالتان zip_source_filep() و zip_source_filep_create() بإنشاء مصدر zip من تيار ملف. تقرأان len بايت من الموضع start من تيار الملف المفتوح file. لوصف الوسيط len، انظر zip_source_file(3).

إذا كان تيار الملف يدعم البحث، يمكن استخدام المصدر لفتح أرشيف zip للقراءة فقط.

يتم إغلاق تيار الملف عند تحرير المصدر، عادةً بواسطة zip_close(3).

قيم الإرجاع

عند الانتهاء بنجاح، يتم إرجاع المصدر المنشأ. بخلاف ذلك، يتم إرجاع NULL ويتم تعيين رمز الخطأ في archive أو error للإشارة إلى الخطأ.

الأخطاء

zip_source_filep() تفشل إذا:

[ZIP_ER_INVAL]
الوسائط file أو start أو len غير صالحة.
[ZIP_ER_MEMORY]
لم يكن من الممكن تخصيص الذاكرة المطلوبة.

انظر أيضًا

libzip(3)، zip_file_add(3)، zip_file_replace(3)، zip_source(5)، zip_source_file(3)

التاريخ

تمت إضافة zip_source_filep() و zip_source_filep_create() في libzip 1.0.

تمت إضافة ZIP_LENGTH_TO_END و ZIP_LENGTH_UNCHECKED في libzip 1.10.1.
