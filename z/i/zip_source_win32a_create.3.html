zip_source_win32a_create(3)

الحزمة: libzip

التراخيص: BSD

ZIP_SOURCE_WIN32A(3) دليل وظائف المكتبة ZIP_SOURCE_WIN32A(3)

الاسم

zip_source_win32a، zip_source_win32a_create — إنشاء مصدر بيانات من اسم ملف Windows ANSI

المكتبة

libzip (-lzip)

مُلَخَّص

#include <zip.h>

zip_source_t *
zip_source_win32a(zip_t *archive, const char *fname, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_win32a_create(const char *fname, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

الوصف

تقوم الدالتان zip_source_win32a() و zip_source_win32a_create() بإنشاء مصدر zip في Windows باستخدام اسم ANSI الخاص بـ Windows. تقومان بفتح fname وقراءة len بايت من الإزاحة start منه. لوصف وسيطة len، انظر zip_source_file(3).

إذا كان الملف يدعم الانتقال، يمكن استخدام المصدر لفتح أرشيف zip منه.

يتم فتح الملف وقراءته عند استخدام البيانات من المصدر، عادةً بواسطة zip_close() أو zip_open_from_source().

قيم الإرجاع

عند الاكتمال بنجاح، يتم إرجاع المصدر المنشأ. بخلاف ذلك، يتم إرجاع NULL ويتم تعيين رمز الخطأ في archive أو error للإشارة إلى الخطأ.

الأخطاء

zip_source_win32a() و zip_source_win32a_create() تفشل إذا:

[ZIP_ER_INVAL]
fname أو start أو len غير صالحة.
[ZIP_ER_MEMORY]
لم يكن بالإمكان تخصيص الذاكرة المطلوبة.
[ZIP_ER_OPEN]
فشل فتح fname.

انظر أيضًا

libzip(3)، zip_file_add(3)، zip_file_replace(3)، zip_source(5)، zip_source_file(3)، zip_source_win32handle(3)، zip_source_win32w(3)

التاريخ

تمت إضافة zip_source_win32a() و zip_source_win32a_create() في libzip 1.0.

ZIP_LENGTH_TO_END و ZIP_LENGTH_UNCHECKED تمت إضافتهما في libzip 1.10.1.
