zip_file_set_comment(3)

الحزمة: libzip

التراخيص: BSD

ZIP_FILE_SET_COMMENT(3) دليل الوظائف المكتبية ZIP_FILE_SET_COMMENT(3)

الاسم

zip_file_set_comment — تعيين تعليق لملف في أرشيف zip

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

int
zip_file_set_comment(zip_t *archive, zip_uint64_t index, const char *comment, zip_uint16_t len, zip_flags_t flags);

الوصف

تقوم الوظيفة zip_file_set_comment() بتعيين التعليق للملف الموجود في الموضع index في أرشيف zip إلى comment بطول len. إذا كان comment هو NULL وكان len يساوي 0، فسيتم إزالة تعليق الملف. يمكن أن يكون الوسيط flags أيًا مما يلي:

ZIP_FL_ENC_GUESS
تخمين ترميز comment (افتراضي). (يتم التعرف فقط على CP-437 و UTF-8).
ZIP_FL_ENC_UTF_8
تفسير comment كـ UTF-8.
ZIP_FL_ENC_CP437
تفسير comment كصفحة ترميز 437 (CP-437).

قيم الإرجاع

عند النجاح، يتم إرجاع 0. بخلاف ذلك، يتم إرجاع -1 ويتم تعيين معلومات الخطأ في archive للإشارة إلى الخطأ.

الأخطاء

تفشل zip_file_set_comment() إذا:

[ZIP_ER_INVAL]
index ليس فهرس ملف صالح في archive، أو len أقل من 0 أو أطول من الحد الأقصى لطول التعليق في ملف zip (65535)، أو comment ليس سلسلة UTF-8 صالحة.
[ZIP_ER_MEMORY]
لم يتمكن من تخصيص الذاكرة المطلوبة.
[ZIP_ER_RDONLY]
تم فتح archive في وضع القراءة فقط.

انظر أيضًا
