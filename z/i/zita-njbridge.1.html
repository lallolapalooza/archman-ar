NAME

zita-njbridge

JACK to JACK client with 10ms latency

SYNOPSIS

zita-njbridge [-h | --help] [-V | --version] [-d | --daemon] [-I | --info] [-c | --nocheck] [-p | --noprobe] [-l | --latency ms] [-s | --server server] [-c | --client client] [-m | --master client] [-n | --name name] [-o | --out channels] [-i | --in channels] [--buff time] [--filt delay]

DESCRIPTION

The zita-njbridge program is a JACK client that allows to connect two JACK servers, possibly running on different machines. It acts as a network bridge for JACK audio connections.

The program can operate in two modes:

  • As a server: In this mode, zita-njbridge acts as a JACK server. Other JACK clients can connect to it. This is the default mode.
  • As a client: In this mode, zita-njbridge connects to an existing JACK server. This is specified using the -s option.

The server mode is intended for bridging a local JACK server to a remote JACK server, where the remote server is started with the -s option.

The client mode is intended for connecting a local JACK server to a remote JACK server, where the remote server is started in the default mode (server mode).

The program aims for low latency. The default latency is 10 ms. This can be adjusted using the --buff option.

The resampler filter delay can be adjusted using the --filt option.

Diagnostic information can be obtained using the --info option.

OPTIONS

-h | --help
Print a usage message and exit.
-V | --version
Print version information and exit.
-d | --daemon
Run as a daemon. The program will detach from the terminal and run in the background.
-c | --nocheck
Disable the JACK status check. This can be useful if the JACK server is not yet running when zita-njbridge is started.
-p | --noprobe
Disable probing of the JACK server. This can be useful if the JACK server does not support probing.
-l | --latency ms
Set the target latency in milliseconds. The default is 10 ms.
-s | --server server
Connect to the specified JACK server. If this option is given, zita-njbridge will run as a client. The default is to run as a server.
-c | --client client
The name of the JACK client to connect to. This option is only used when zita-njbridge is running as a client (i.e., when -s is specified). The default client name is 'zita-njbridge'.
-m | --master client
The name of the JACK client to use as the master clock. This option is only used when zita-njbridge is running as a client. The default is to use the JACK server's internal clock.
-n | --name name
The name of the JACK client. This option is only used when zita-njbridge is running as a server. The default name is 'zita-njbridge'.
-o | --out channels

Set the number of output channels. The default channel list is '1,2'.
-i | --in channels

Set the number of input channels. The default channel list is '1,2'.
--buff time

Increase the target latency by the given time, in milliseconds. The default is 10 ms. See the description above for what exactly this means.
--filt delay

Set the resampler filter delay, in samples at the lower of the two sample rates, in the range 16..96. See above for details.
--info

Print additional diagnostic information. Four values will be printed four times per second: the number of jack periods during the last 1/4 second, the average resampler control loop error in frames, the average resampler ratio correction and the minumum number of frames available in the receive buffer.
