NAME

SYNOPSIS

DESCRIPTION

Zint is a barcode generator which has been designed to run on most platforms and is highly configurable. Zint can output barcodes in a wide range of raster and vector formats including PNG, JPG, SVG, EPS, PDF, GIF, and TIFF.

Zint has an extensive list of supported symbologies, and can also be extended to support new symbologies.

Zint can be used from the command line, or as a library (libzint) to add barcode generation to your own applications.

OPTIONS

Zint accepts the following command line options:

--data <data>, -d <data>
Specifies the data to be encoded in the barcode. This option is mandatory unless batch mode is used.
--barcode <type>, -b <type>
Specifies the barcode type to be generated. Use --list-types to see a list of available barcode types.
--output <file>, -o <file>
Specifies the output filename. If this option is omitted, the default output filename is out.png. The file extension determines the output format (e.g. .png for PNG, .svg for SVG).
--list-barcodes, --list-types
Lists all supported barcode types and their Zint internal names.
--test
Tests the Zint library installation by generating a sample barcode.
--verbose
Enables verbose output, providing more information about the barcode generation process.
--small-font
Uses a smaller font for the human-readable text, if applicable.
--border <width>
Sets the border width around the barcode in pixels. Default is 10 pixels.
--scale <factor>
Scales the barcode by the given factor. A factor of 1.0 means no scaling.
--auto-width
Automatically determines the optimal width for the barcode.
--auto-height
Automatically determines the optimal height for the barcode.
--height <pixels>
Sets the height of the barcode in pixels.
--width <pixels>
Sets the width of the barcode in pixels.
--frameless
Disables the display of the human-readable text.
--back-colour <rgb>
Sets the background colour of the barcode. The colour should be specified as a 6-digit hexadecimal RGB value (e.g., FF0000 for red).
--fore-colour <rgb>
Sets the foreground (bar) colour of the barcode. Specified as a 6-digit hexadecimal RGB value.
--text-colour <rgb>
Sets the colour of the human-readable text. Specified as a 6-digit hexadecimal RGB value.
--dot-size <pixels>
Sets the size of individual dots or modules in pixels. Applicable to some barcode types.
--text-position <pos>
Sets the position of the human-readable text. Valid values are above and below (default).
--barcode-position <pos>
Sets the position of the barcode itself within the output image. Valid values are center (default), left, and right.
--rotate <angle>
Rotates the barcode by the specified angle (0, 90, 180, 270).
--compensate
Compensates for printer dot gain (may vary depending on barcode type).
--underline
Underlines the human-readable text.
--quiet-zone <width>
Sets the width of the quiet zone (empty space) around the barcode in modules. Default is 10 modules.
--eci <eci_mode>
Sets the Extended Channel Interpretation (ECI) mode for the barcode.
--colour <colour>
Specifies a colour for a specific part of the barcode (syntax depends on barcode type).
--warn-error
Treats warnings as errors. If Zint generates a warning, the program will exit with an error status.
--batch
Enables batch mode, where data is read from an input file.
--input-file <file>, -i <file>
Specifies the input file to read data from in batch mode. Each line in the file is treated as a separate barcode data string.
--output-path <path>, -o <path>
Specifies the output path and filename pattern for batch mode. Special characters like '~' can be used for numbering (e.g., output-~~~.png).
--error-level <level>
Sets the error correction level for certain barcode types (e.g., QR Code). The level typically ranges from 0 to 3 or 4.
--error-correction <level>
An alias for --error-level.
--debug
Enables debug output, useful for diagnosing problems.
--show-plot
Displays a plot of the barcode generation process (may require additional libraries).
--version
Displays the Zint version information and exits.
--help
Displays a help message and exits.

EXAMPLES

Create “out.png” (or “out.gif” if zint built without PNG support) in the current directory, as a Code 128 symbol.

zint -d 'This Text'

Create “qr.svg” in the current directory, as a QR Code symbol.

zint -b QRCode -d 'This Text' -o 'qr.svg'

Use batch mode to read from an input file “ean13nos.txt” containing a list of 13-digit GTINs, each on a separate line, to create a series of EAN-13 barcodes, formatting the output filenames to “ean001.gif”, “ean002.gif” etc. using the special character “~”.

zint -b EANX --batch -i 'ean13nos.txt' -o 'ean~~~.gif'
