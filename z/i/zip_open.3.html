zip_open(3)

الحزمة: libzip

التراخيص: BSD

ZIP_OPEN(3) دليل وظائف المكتبة ZIP_OPEN(3)

الاسم

zip_open، zip_open_from_source — فتح أرشيف مضغوط

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

zip_t *
zip_open(const char *path، int flags، int *errorp);

zip_t *
zip_open_from_source(zip_source_t *zs، int flags، zip_error_t *ze);

الوصف

تقوم الدالة zip_open() بفتح أرشيف zip المحدد بواسطة path وتعيد مؤشرًا إلى struct zip، والذي يستخدم لمعالجة الأرشيف. يتم تحديد flags بواسطة أو القيم التالية، أو 0 لعدم وجود أي منها.

ZIP_CHECKCONS
إجراء فحوصات إضافية أكثر صرامة للاتساق على الأرشيف، والخطأ إذا فشلت.
ZIP_CREATE
إنشاء الأرشيف إذا لم يكن موجودًا.
ZIP_EXCL
خطأ إذا كان الأرشيف موجودًا بالفعل.
ZIP_TRUNCATE
إذا كان الأرشيف موجودًا، تجاهل محتوياته الحالية. بمعنى آخر، تعامله بنفس طريقة الأرشيف الفارغ.
ZIP_RDONLY
فتح الأرشيف في وضع القراءة فقط.

إذا حدث خطأ وكان errorp غير NULL، فسيتم تعيينه إلى رمز الخطأ المقابل.

تقوم الدالة zip_open_from_source() بفتح أرشيف zip مغلف بواسطة zip_source zs باستخدام flags المقدمة. في حالة حدوث خطأ، يتم ملء zip_error ze.

قيم الإرجاع

عند اكتمال العملية بنجاح، تعيد الدالتان zip_open() و zip_open_from_source() مؤشرًا إلى struct zip. بخلاف ذلك، يتم إرجاع NULL وتقوم zip_open() بتعيين *errorp للإشارة إلى الخطأ، بينما تقوم zip_open(source) بتعيين ze للإشارة إلى الخطأ.

أمثلة

إليك مثال حول كيفية الإبلاغ عن الأخطاء أثناء zip_open:

    zip_t *za;
    int err;

    if ((za = zip_open(name, 0, &err)) == NULL) {
        zip_error_t error;
        zip_error_init_with_code(&error, err);
        fprintf(stderr, "%s: cannot open zip archive '%s': %s\n",
	        progname, name, zip_error_strerror(&error));
        zip_error_fini(&error);
        return -1;
    }

الأخطاء

يتم فتح الأرشيف المحدد بواسطة path ما لم:

[ZIP_ER_EXISTS]
الملف المحدد بواسطة path موجود وتم تعيين ZIP_EXCL.
[ZIP_ER_INCONS]
تم العثور على تناقضات في الملف المحدد بواسطة path. غالبًا ما يكون هذا الخطأ ناتجًا عن تحديد ZIP_CHECKCONS ولكنه قد يحدث أيضًا بدونه.
[ZIP_ER_INVAL]
الوسيط path هو NULL.
[ZIP_ER_MEMORY]
لم يكن من الممكن تخصيص الذاكرة المطلوبة.
[ZIP_ER_NOENT]
الملف المحدد بواسطة path غير موجود ولم يتم تعيين ZIP_CREATE.
[ZIP_ER_NOZIP]
الملف المحدد بواسطة path ليس أرشيف zip.
[ZIP_ER_OPEN]
لم يكن من الممكن فتح الملف المحدد بواسطة path.
[ZIP_ER_READ]
حدث خطأ في القراءة؛ انظر errno للحصول على التفاصيل.
[ZIP_ER_SEEK]
الملف المحدد بواسطة path لا يسمح بالبحث.
بالنسبة للأرشيفات المنشأة حديثًا، لا تحاول zip_open() إنشاء الملف؛ يتم ذلك عند استدعاء zip_close(3) وسيتم الإبلاغ عن أي أخطاء، مثل نقص أذونات الكتابة، في ذلك الوقت.
