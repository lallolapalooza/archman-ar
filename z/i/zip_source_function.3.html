zip_source_function(3)

الحزمة: libzip

التراخيص: BSD

ZIP_SOURCE_FUNCTION(3) دليل وظائف المكتبة ZIP_SOURCE_FUNCTION(3)

الاسم

zip_source_function، zip_source_function_create — إنشاء مصدر بيانات من دالة

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

zip_source_t *
zip_source_function(zip_t *archive, zip_source_callback fn, void *userdata);

zip_source_t *
zip_source_function_create(zip_source_callback fn, void *userdata, zip_error_t *error);

الوصف

تقوم الدالتان zip_source_function() وzip_source_function_create() بإنشاء مصدر zip من الدالة التي يوفرها المستخدم fn، والتي يجب أن تكون من النوع التالي:

typedef zip_int64_t (*zip_source_callback)(void *userdata, void *data, zip_uint64_t len, zip_source_cmd_t cmd);

archive أو error تستخدم للإبلاغ عن الأخطاء ويمكن أن تكون NULL.

عند استدعائها بواسطة المكتبة، يكون الوسيط الأول هو الوسيط userdata الذي تم تمريره إلى الدالة. الوسيطان التاليان هما مخزن مؤقت data بحجم len عند تمرير البيانات أو توقع إعادتها، وإلا فإنهما NULL و 0. الوسيط الأخير، cmd، يحدد الإجراء الذي يجب أن تقوم به الدالة.

اعتمادًا على الاستخدامات، هناك ثلاث مجموعات مفيدة من الأوامر التي يجب أن تدعمها zip_source_callback():

مصدر قراءة
توفير بيانات متدفقة (لبيانات الملفات المضافة إلى الأرشيفات). يجب أن تدعم ZIP_SOURCE_OPEN، ZIP_SOURCE_READ، ZIP_SOURCE_CLOSE، ZIP_SOURCE_STAT، و ZIP_SOURCE_ERROR.

إذا كان المصدر الخاص بك يستخدم أي ذاكرة مخصصة (بما في ذلك userdata) فيجب عليه أيضًا تنفيذ ZIP_SOURCE_FREE لتجنب تسرب الذاكرة.

مصدر قراءة قابل للبحث
نفس السابق، ولكن من مصدر يسمح بالقراءة من إزاحات عشوائية (أيضًا للأرشيف المضغوط للقراءة فقط). يجب أن تدعم بالإضافة إلى ذلك ZIP_SOURCE_SEEK، ZIP_SOURCE_TELL، و ZIP_SOURCE_SUPPORTS.
مصدر قراءة/كتابة
نفس السابق، ولكن يسمح بالإضافة إلى ذلك بالكتابة (أيضًا للأرشيفات المضغوطة القابلة للكتابة). يجب أن تدعم بالإضافة إلى ذلك ZIP_SOURCE_BEGIN_WRITE، ZIP_SOURCE_COMMIT_WRITE، ZIP_SOURCE_ROLLBACK_WRITE، ZIP_SOURCE_SEEK_WRITE، ZIP_SOURCE_TELL_WRITE، و ZIP_SOURCE_REMOVE.

بالإضافة إلى ما سبق، فإن دعم الأمر الزائف ZIP_SOURCE_SUPPORTS_REOPEN يسمح باستدعاء zip_source_open() مرة أخرى بعد استدعاء zip_source_close().

ZIP_SOURCE_ACCEPT_EMPTY

إرجاع 1 إذا كان يجب قبول مصدر فارغ كملف مضغوط صالح. هذا هو الإعداد الافتراضي إذا لم يدعم المصدر هذا الأمر. يجب أن تعيد مصادر نظام الملفات القيمة 0.

ZIP_SOURCE_BEGIN_WRITE

تجهيز المصدر للكتابة. استخدم هذا لإنشاء أي ملفات مؤقتة.

ZIP_SOURCE_BEGIN_WRITE_CLONING

تجهيز المصدر للكتابة، مع الاحتفاظ بأول len بايت من الملف الأصلي. قم بتنفيذ هذا الأمر فقط إذا كان أكثر كفاءة من نسخ البيانات، وإذا لم يقم بالكتابة فوق الملف الأصلي بشكل مدمر (لا يزال يتعين عليك أن تكون قادرًا على تنفيذ ZIP_SOURCE_ROLLBACK_WRITE).

يجب أن تحدث الكتابة التالية في البايت offset.

ZIP_SOURCE_CLOSE

تم الانتهاء من القراءة.

ZIP_SOURCE_COMMIT_WRITE

إنهاء الكتابة إلى المصدر. استبدل البيانات الأصلية بالبيانات المكتوبة حديثًا. قم بتنظيف الملفات المؤقتة أو المخازن المؤقتة الداخلية. يجب أن تؤدي القراءة والكتابة اللاحقة من المصدر إلى إرجاع البيانات المكتوبة حديثًا.

ZIP_SOURCE_ERROR

الحصول على معلومات الخطأ. يشير data إلى مصفوفة من عددين صحيحين، والتي يجب ملؤها برمز خطأ libzip ورمز خطأ النظام المقابل للخطأ الذي حدث. انظر zip_errors(3) للحصول على تفاصيل حول رموز الخطأ. إذا قام المصدر بتخزين معلومات الخطأ في zip_error_t، فاستخدم zip_error_to_data(3) وأرجع قيمته. خلاف ذلك، أرجع 2 * sizeof(int).

ZIP_SOURCE_FREE

تنظيف وتحرير جميع الموارد، بما في ذلك userdata. لن يتم استدعاء دالة الاستدعاء مرة أخرى.

ZIP_SOURCE_GET_FILE_ATTRIBUTES

توفير معلومات حول البيانات المختلفة. ثم يجب وضع البيانات في الإدخال المناسب في الوسيط zip_file_attributes_t الذي تم تمريره، ويجب أن يتم دمج قيمة ZIP_FILE_ATTRIBUTES_* المناسبة في عضو valid للإشارة إلى أن البيانات المقابلة قد تم توفيرها. يمكن تهيئة بنية zip_file_attributes_t باستخدام zip_file_attributes_init(3).

وضع ASCII
إذا كان الملف ملف نصي بترميز ASCII. يمكن استخدامه بواسطة أدوات الاستخراج لتحويل نهايات الأسطر تلقائيًا (جزء من سمات الملف الداخلية). العضو ascii، العلامة ZIP_FILE_ATTRIBUTES_ASCII.
علامات بت للأغراض العامة (محدودة بعلامات الضغط)
علامة البت للأغراض العامة في الملف المضغوط في رؤوس الدليل المحلي والمركزي تحتوي على معلومات حول طريقة الضغط. العضو general_purpose_bit_flags
و general_purpose_bit_mask لتحديد الأعضاء التي تم تعيينها؛ الراية ZIP_FILE_ATTRIBUTES_GENERAL_PURPOSE_BIT_FLAGS.
سمات الملف الخارجي
سمات الملف الخارجية (عادة ما تكون خاصة بنظام التشغيل). العضو external_file_attributes، الراية ZIP_FILE_ATTRIBUTES_EXTERNAL_FILE_ATTRIBUTES.
الإصدار المطلوب
الحد الأدنى للإصدار المطلوب لفك ضغط هذا الإدخال (بالتنسيق المعتاد "major * 10 + minor"). العضو version_needed، الراية ZIP_FILE_ATTRIBUTES_VERSION_NEEDED.
نظام التشغيل
أحد أنظمة التشغيل كما هو محدد بواسطة ZIP_OPSYS_* المتغيرات (انظر zip.h). تؤثر هذه القيمة على تفسير سمات الملف الخارجية. العضو host_system، الراية ZIP_FILE_ATTRIBUTES_HOST_SYSTEM.

ZIP_SOURCE_OPEN

التحضير للقراءة.

ZIP_SOURCE_READ

قراءة البيانات في المخزن المؤقت data بالحجم len. إرجاع عدد البايتات التي تم وضعها في data عند النجاح، وصفر لنهاية الملف.

ZIP_SOURCE_REMOVE

إزالة الملف الأساسي. يتم استدعاء هذا إذا كان أرشيف zip فارغًا عند إغلاقه.

ZIP_SOURCE_ROLLBACK_WRITE

التراجع عن الكتابة إلى المصدر. تجاهل البيانات المكتوبة. تنظيف الملفات المؤقتة أو المخازن المؤقتة الداخلية. يجب أن تؤدي القراءة والكتابة اللاحقة من المصدر إلى إرجاع البيانات الأصلية.

ZIP_SOURCE_SEEK

تحديد الموضع للقراءة منه البايت التالي، مثل fseek(3). استخدم ZIP_SOURCE_GET_ARGS(3) لتحليل الوسيطات إلى الهيكل التالي:

struct zip_source_args_seek {
    zip_int64_t offset;
    int whence;
};

إذا كان حجم بيانات المصدر معروفًا، فاستخدم zip_source_seek_compute_offset(3) للتحقق من صحة الوسيطات وحساب الإزاحة الجديدة.

ZIP_SOURCE_SEEK_WRITE

تحديد الموضع للكتابة فيه البايت التالي، مثل fseek(3). انظر ZIP_SOURCE_SEEK للتفاصيل.

ZIP_SOURCE_STAT

الحصول على معلومات التعريفية لبيانات الإدخال. data يشير إلى struct zip_stat مخصص، والذي يجب تهيئته باستخدام zip_stat_init(3) ثم ملئه.

للبيانات غير المضغوطة وغير المشفرة، تكون جميع المعلومات اختيارية. ومع ذلك، املأ أكبر قدر ممكن من المعلومات المتاحة بسهولة.

إذا كانت البيانات مضغوطة، فيجب ملء ZIP_STAT_COMP_METHOD و ZIP_STAT_SIZE و ZIP_STAT_CRC.

إذا كانت البيانات مشفرة، فيجب ملء ZIP_STAT_ENCRYPTION_METHOD و ZIP_STAT_COMP_METHOD و ZIP_STAT_SIZE و ZIP_STAT_CRC.

يمكن حذف المعلومات المتاحة فقط بعد قراءة المصدر (على سبيل المثال، الحجم) في استدعاء سابق. ملاحظة: يمكن استدعاء zip_source_function() بهذه الوسيطة حتى بعد استدعائها بـ ZIP_SOURCE_CLOSE.

إرجاع sizeof(struct zip_stat) عند النجاح.

ZIP_SOURCE_SUPPORTS

إرجاع قناع بت يحدد الأوامر المدعومة. استخدم zip_source_make_command_bitmap(3). إذا لم يتم تنفيذ هذا الأمر، يُفترض أن المصدر هو مصدر قراءة بدون دعم للتحرك.

ZIP_SOURCE_TELL

إرجاع إزاحة القراءة الحالية في المصدر، مثل ftell(3).

ZIP_SOURCE_TELL_WRITE

إرجاع إزاحة الكتابة الحالية في المصدر، مثل ftell(3).

ZIP_SOURCE_WRITE

كتابة البيانات إلى المصدر. إرجاع عدد البايتات المكتوبة.

ZIP_SOURCE_SUPPORTS_REOPEN

لا يتم استدعاء هذا الأمر فعليًا أبدًا، ويشير الدعم له إلى القدرة على التعامل مع دورات فتح/قراءة/إغلاق متعددة.

قيم الإرجاع

يجب أن تعيد الأوامر -1 عند حدوث خطأ. سيتم استدعاء ZIP_SOURCE_ERROR لاسترداد رمز الخطأ. عند النجاح، تعيد الأوامر 0، ما لم يُنص على خلاف ذلك في الوصف أعلاه.

اتفاقيات الاستدعاء

ستصدر المكتبة دائمًا ZIP_SOURCE_OPEN قبل إصدار ZIP_SOURCE_READ أو ZIP_SOURCE_SEEK أو ZIP_SOURCE_TELL. عندما لم تعد ترغب في القراءة من هذا المصدر، ستصدر ZIP_SOURCE_CLOSE. إذا كانت المكتبة ترغب في قراءة البيانات مرة أخرى، فستصدر ZIP_SOURCE_OPEN مرة ثانية. إذا كانت الدالة غير قادرة على توفير البيانات مرة أخرى، فيجب أن تعيد -1.

سيتم استدعاء ZIP_SOURCE_BEGIN_WRITE أو ZIP_SOURCE_BEGIN_WRITE_CLONING قبل ZIP_SOURCE_WRITE أو ZIP_SOURCE_SEEK_WRITE أو ZIP_SOURCE_TELL_WRITE. عند اكتمال الكتابة، سيتم استدعاء ZIP_SOURCE_COMMIT_WRITE أو ZIP_SOURCE_ROLLBACK_WRITE.

يمكن إصدار ZIP_SOURCE_ACCEPT_EMPTY و ZIP_SOURCE_GET_FILE_ATTRIBUTES و ZIP_SOURCE_STAT في أي وقت.

ZIP_SOURCE_ERROR سيتم إصداره فقط استجابةً لإرجاع الدالة -1.

ZIP_SOURCE_FREE سيكون آخر أمر تم إصداره؛ إذا تم استدعاء ZIP_SOURCE_OPEN بنجاح، فسيتم استدعاء ZIP_SOURCE_CLOSE قبل ZIP_SOURCE_FREE، وبالمثل لـ ZIP_SOURCE_BEGIN_WRITE أو ZIP_SOURCE_BEGIN_WRITE_CLONING و ZIP_SOURCE_COMMIT_WRITE أو ZIP_SOURCE_ROLLBACK_WRITE.

قيم الإرجاع

عند الاكتمال بنجاح، يتم إرجاع المصدر المنشأ. بخلاف ذلك، يتم إرجاع NULL ويتم تعيين رمز الخطأ في archive أو error للإشارة إلى الخطأ (ما لم يكن NULL).

الأخطاء

zip_source_function() يفشل إذا:

[ZIP_ER_MEMORY]
لم يتم تخصيص الذاكرة المطلوبة.

NAME

zip_source_function - provide data from a function

LIBRARY

libzip, -lzip

SYNOPSIS

#include <zip.h>

int zip_source_function(zip_t *za, int(*func)(void *state, void *data, zip_uint64_t len), void *state);

int zip_source_function_compressed(zip_t *za, int(*func)(void *state, void *data, zip_uint64_t len), zip_uint64_t uncompressed_size, void *state);

DESCRIPTION

The zip_source_function() function is used to add a source of data to the archive from which the data will be read by calling the given function func. The function func will be called with state as the first argument. The function func must be prepared to read up to len bytes from the provided buffer data. If it reads less than len bytes, it must return the number of bytes read. If it wants to signal the end of the file, it must return 0. If an error occurs, it must return -1. The initial call to func will be with data as NULL and len set to 0, to allow the function to prepare itself.

The state argument is a pointer to arbitrary data that will be passed to the func function on each call. This is useful to pass a context to the function, for example, a file handle or a pointer to a structure.

The zip_source_function_compressed() function is similar to zip_source_function(), but it also takes an argument uncompressed_size, which specifies the uncompressed size of the data that will be provided. This is useful for compressing data when the size is known beforehand.

RETURN VALUES

On success, zip_source_function() and zip_source_function_compressed() return the index of the added source. On error, they return -1.

ERRORS

When an error occurs, the source will be closed and its contents discarded. The error will be reported by zip_error_get.

SEE ALSO

zip_add_dir(3), zip_add_entry(3), zip_file_add(3), zip_fd_open(3), zip_fclose(3), zip_fopen(3), zip_source(3)

HISTORY

The zip_source_function and zip_source_function_compressed functions were added in libzip 1.11.0.
