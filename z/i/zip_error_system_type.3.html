zip_error_system_type(3)

الحزمة: libzip

التراخيص: BSD

ZIP_ERROR_SYSTEM_TYPE(3) دليل وظائف المكتبة ZIP_ERROR_SYSTEM_TYPE(3)

الاسم

zip_error_system_type — نوع الخطأ النظامي

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

int
zip_error_system_type(const zip_error_t *ze);

الوصف

تقوم الدالة zip_error_system_type() بإرجاع نوع الجزء الخاص بالنظام لـ zip_error ze. حاليًا، الأنواع النظامية التالية معرفة:

ZIP_ET_NONE
الجزء الخاص بالنظام لـ ze غير مستخدم.
ZIP_ET_SYS
الجزء الخاص بالنظام لـ ze هو errno(2).
ZIP_ET_ZLIB
الجزء الخاص بالنظام لـ ze هو خطأ zlib(3).

انظر أيضًا

libzip(3)، zip_error_code_system(3)

التاريخ

تمت إضافة zip_error_system_type() في libzip 1.0.
