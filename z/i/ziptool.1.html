الاسم

ziptool — تعديل أرشيفات zip

ملخص

ziptool [-ceghnrst] [-l الطول] [-o الإزاحة] أرشيف-zip الأمر [وسيطات-الأمر ...] [الأمر [وسيطات-الأمر ...] ...]

الوصف

ziptool يقوم بتعديل أرشيف الـ zip أرشيف-zip وفقًا للـ أوامر المعطاة.

الخيارات المدعومة:

-c
التحقق من تناسق أرشيف الـ zip عند فتحه.
-e
خطأ إذا كان الأرشيف موجودًا بالفعل (مفيد فقط مع -n).
-g
تخمين ترميز اسم الملف (لأمر stat).
-h
عرض المساعدة.
-l الطول
قراءة الطول بايت فقط من الأرشيف. انظر أيضًا -o.
-n
إنشاء الأرشيف إذا لم يكن موجودًا. انظر أيضًا -e.
-o الإزاحة
البدء في قراءة أرشيف الإدخال من الإزاحة. انظر أيضًا -l.
-r
طباعة ترميز اسم الملف الخام دون ترجمة (لأمر stat).
-s
اتباع اصطلاح اسم الملف بدقة (لأمر stat).
-t
تجاهل محتويات الملف الحالية، إن وجدت. ملاحظة: استخدم هذا بحذر، فهو يحذف جميع محتويات الملفات الموجودة عند تعديل الأرشيف.

الأوامر

لجميع الأوامر أدناه، الفهرس يبدأ من الصفر. بمعنى آخر، الإدخال الأول في أرشيف الـ zip له الفهرس 0.

الأوامر والوسيطات المدعومة هي:

add الاسم المحتوى
إضافة ملف باسم الاسم باستخدام السلسلة النصية المحتوى من سطر الأوامر كبيانات.
add_dir الاسم
إضافة دليل باسم الاسم.
add_file الاسم الملف-للإضافة الإزاحة الطول
إضافة ملف باسم الاسم إلى الأرشيف، باستخدام الطول بايت من الملف الملف-للإضافة كبيانات إدخال، بدءًا من الإزاحة.
add_from_zip الاسم اسم-الأرشيف الفهرس الإزاحة الطول
إضافة ملف باسم الاسم إلى الأرشيف باستخدام بيانات من أرشيف zip آخر اسم-الأرشيف باستخدام الإدخال ذي الفهرس الفهرس والقراءة الطول بايت من الإزاحة.
cat الفهرس
إخراج محتويات الملف للإدخال الفهرس إلى الإخراج القياسي.
count_extra الفهرس الأعلام
طباعة عدد الحقول الإضافية لإدخال الأرشيف الفهرس باستخدام الأعلام.
count_extra_by_id الفهرس المعرف-الإضافي الأعلام
طباعة عدد الحقول الإضافية من النوع المعرف-الإضافي لإدخال الأرشيف الفهرس باستخدام الأعلام.
delete الفهرس
إزالة الإدخال الموجود في الفهرس الفهرس من أرشيف الـ zip.
delete_extra الفهرس فهرس-إضافي الأعلام
إزالة الحقل الإضافي رقم فهرس-إضافي من إدخال الأرشيف الفهرس باستخدام الأعلام.
delete_extra_by_id الفهرس المعرف-الإضافي فهرس-إضافي الأعلام
إزالة الحقل الإضافي رقم فهرس-إضافي من النوع المعرف-الإضافي من إدخال الأرشيف الفهرس باستخدام الأعلام.
get_archive_comment
طباعة تعليق الأرشيف.
get_archive_flag العلم
طباعة حالة علم الأرشيف العلم.
get_extra الفهرس فهرس-إضافي الأعلام
طباعة الحقل الإضافي رقم فهرس-إضافي لإدخال الأرشيف الفهرس باستخدام الأعلام.
get_extra_by_id الفهرس المعرف-الإضافي فهرس-إضافي الأعلام
طباعة الحقل الإضافي رقم فهرس-إضافي من النوع المعرف-الإضافي لإدخال الأرشيف الفهرس باستخدام الأعلام.
get_file_comment الفهرس
الحصول على تعليق الملف لإدخال الأرشيف الفهرس.
get_num_entries الأعلام
طباعة عدد الإدخالات في الأرشيف باستخدام الأعلام.
name_locate الاسم الأعلام
البحث عن إدخال في الأرشيف باسم الملف الاسم باستخدام الأعلام وطباعة فهرسه.
rename الفهرس الاسم
إعادة تسمية إدخال الأرشيف الفهرس إلى الاسم.
replace_file_contents الفهرس البيانات
استبدال محتويات الملف لإدخال الأرشيف الفهرس بالسلسلة النصية البيانات.
set_archive_comment التعليق
تعيين تعليق الأرشيف إلى التعليق.
get_archive_flag العلم القيمة
تعيين علم الأرشيف العلم إلى القيمة.
set_extra الفهرس المعرف-الإضافي فهرس-إضافي الأعلام القيمة
تعيين الحقل الإضافي رقم فهرس-إضافي من النوع المعرف-الإضافي لإدخال الأرشيف الفهرس باستخدام الأعلام إلى القيمة.
set_file_comment الفهرس التعليق
تعيين تعليق الملف لإدخال الأرشيف الفهرس إلى السلسلة النصية التعليق.
ziptool(1)

NAME

ziptool — utility to manipulate ZIP archives

SYNOPSIS

ziptool [ -alg ] [ -vlg ] [ -flg ] [ -Llg ] [ -Xlg ] archive command [ command_args ... ]

DESCRIPTION

The ziptool utility allows you to manipulate ZIP archives. It supports a lot of commands to add, delete, extract, list, rename, replace, set attributes and comments.

The archive is the ZIP archive to be manipulated. The command specifies the operation to perform. Some commands take command_args.

Global flags:

-a lg
Set archive flags lg. See Archive flags.
-v lg
Set archive flags lg. See Archive flags.
-f lg
Set file flags lg. See Flags.
-L lg
Set file flags lg. See Flags.
-X lg
Set file flags lg. See Flags.

Supported commands:

add filename data
Add file filename to the archive with data data.
cat index
Print archive entry index to stdout.
cd path
Change the current directory in the archive to path.
cp index new_filename
Copy archive entry index to new_filename.
delete index
Delete archive entry index.
get_archive_flag flag
Get value of archive flag flag.
get_file_comment index
Get comment of archive entry index.
get_file_encryption index
Get encryption method of archive entry index.
get_file_mtime index
Get modification time of archive entry index.
get_file_name index
Get filename of archive entry index.
get_file_type index
Get type of archive entry index.
get_num_entries
Get number of entries in the archive.
hardlink index new_filename
Create a hardlink to archive entry index with name new_filename.
list [pattern ...]
List archive entries matching pattern. If no patterns are given, all entries are listed.
mkdir dirname
Create directory dirname.
mv index new_filename
Rename archive entry index to new_filename.
open
Open archive.
read_from_file index filename
Read archive entry index into file filename.
rename index new_filename
Rename archive entry index to new_filename.
rmdir dirname
Remove empty directory dirname.
set_archive_comment comment
Set archive comment to comment.
set_file_comment index comment
Set comment of archive entry index to comment.
set_file_compression index method compression_flags
Set file compression method for archive entry index to method using compression_flags. Note: Currently, compression_flags are ignored.
set_file_encryption index method password
Set file encryption method for archive entry index to method with password password.
set_file_mtime index timestamp
Set file modification time for archive entry index to UNIX mtime timestamp.
set_file_mtime_all timestamp
Set file modification time for all archive entries to UNIX mtime timestamp.
set_password password
Set default password for encryption/decryption to password.
stat index
Print information about archive entry index.

Flags

Some commands take flag arguments. Each character in the argument sets the corresponding flag. Use 0 or the empty string for no flags.

Supported flags are:

4
ZIP_FL_ENC_CP437
8
ZIP_FL_ENC_UTF_8
C
ZIP_FL_NOCASE
c
ZIP_FL_CENTRAL
d
ZIP_FL_NODIR
l
ZIP_FL_LOCAL
r
ZIP_FL_ENC_RAW
s
ZIP_FL_ENC_STRICT
u
ZIP_FL_UNCHANGED

Archive flags

get_archive_flag and set_archive_flag work on the following flags:

  • create-or-keep-empty-file-for-archive
  • is-torrentzip
  • rdonly
  • want-torrentzip

Compression Methods

Some commands take compression method arguments. Supported methods are:

  • default
  • deflate
  • store

Encryption Methods

Some commands take encryption method arguments. Supported methods are:

  • none
  • AES-128
  • AES-192
  • AES-256

EXIT STATUS

The ziptool utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

Add a file called teststring.txt to the zip archive testbuffer.zip with data “This is a test.\n” where “\n” is replaced with a newline character:

ziptool testbuffer.zip add teststring.txt \"This is a test.\n\"

Delete the first file from the zip archive testfile.zip:

ziptool testfile.zip delete 0

SEE ALSO

zipcmp(1), zipmerge(1), libzip(3)

HISTORY

ziptool was added in libzip 1.1.
