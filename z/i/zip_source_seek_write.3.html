zip_source_seek_write(3)

الحزمة: libzip

التراخيص: BSD

ZIP_SOURCE_SEEK_WRITE(3) Library Functions Manual ZIP_SOURCE_SEEK_WRITE(3)

الاسم

zip_source_seek_write — تعيين إزاحة الكتابة في مصدر zip

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

int
zip_source_seek_write(zip_source_t *source, zip_int64_t offset, int whence);

الوصف

تقوم الدالة zip_source_seek_write() بتعيين إزاحة الكتابة الحالية للمصدر source. تمامًا مثل في fseek(3)، اعتمادًا على الوسيط whence، يتم حساب offset نسبة إلى:

SEEK_SET
بداية الملف
SEEK_CUR
إزاحة الكتابة الحالية في الملف
SEEK_END
نهاية الملف

قيم الإرجاع

عند اكتمال التنفيذ بنجاح، يتم إرجاع 0. بخلاف ذلك، يتم إرجاع -1 ويتم تعيين معلومات الخطأ في source للإشارة إلى الخطأ.
