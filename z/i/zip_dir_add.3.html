zip_dir_add(3)

الحزمة: libzip

التراخيص: BSD

ZIP_DIR_ADD(3) دليل وظائف المكتبة ZIP_DIR_ADD(3)

الاسم

zip_dir_add — إضافة دليل إلى أرشيف مضغوط

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

zip_int64_t
zip_dir_add(zip_t *archive, const char *name, zip_flags_t flags);

الوصف

تقوم الدالة zip_dir_add() بإضافة دليل إلى أرشيف مضغوط. تحدد الوسيطة archive الأرشيف المضغوط الذي يجب إضافة الدليل إليه. name هو اسم الدليل في الأرشيف المضغوط.

تضيف هذه الدالة إدخالاً إلى الأرشيف. لا تتحقق مما إذا كان دليل بهذا الاسم موجودًا في نظام الملفات، ولا تضيف محتوياته إذا كان موجودًا. يمكن أن تكون الوسيطة flags أيًا مما يلي:

ZIP_FL_ENC_GUESS
تخمين ترميز name (افتراضي). (يتم التعرف فقط على CP-437 و UTF-8.)
ZIP_FL_ENC_UTF_8
تفسير name كـ UTF-8.
ZIP_FL_ENC_CP437
تفسير name كصفحة رمز 437 (CP-437).

قيم الإرجاع

عند الانتهاء بنجاح، يتم إرجاع فهرس الإدخال الجديد في الأرشيف. بخلاف ذلك، يتم إرجاع -1 ويتم تعيين رمز الخطأ في archive للإشارة إلى الخطأ.

الأخطاء

تفشل zip_dir_add() إذا:

[ZIP_ER_EXISTS]
يوجد بالفعل إدخال يسمى name في الأرشيف.
[ZIP_ER_INVAL]
archive أو name هي NULL، أو أسماء ملفات غير صالحة مرمزة بـ UTF-8.
[ZIP_ER_MEMORY]
لم يتم تخصيص الذاكرة المطلوبة.

انظر أيضًا

libzip(3)، zip_file_add(3)
