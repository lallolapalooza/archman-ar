zip_file_set_encryption(3)

الحزمة: libzip

التراخيص: BSD

ZIP_FILE_SET_ENCRYPTION(3) دليل وظائف المكتبة ZIP_FILE_SET_ENCRYPTION(3)

الاسم

zip_file_set_encryption — تعيين طريقة التشفير للملف في ملف zip

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

int
zip_file_set_encryption(zip_t *archive, zip_uint64_t index, zip_uint16_t method, const char *password);

الوصف

الدالة zip_file_set_encryption() تعيّن طريقة التشفير للملف الموجود في الموضع index في أرشيف zip إلى method باستخدام كلمة المرور password. الـ method هو نفس القيمة التي يتم إرجاعها بواسطة zip_stat(3). بالنسبة للوسيط method، حاليًا يتم دعم القيم التالية فقط:

ZIP_EM_NONE
لا يوجد تشفير.
ZIP_EM_AES_128
تشفير Winzip AES-128.
ZIP_EM_AES_192
تشفير Winzip AES-192.
ZIP_EM_AES_256
تشفير Winzip AES-256.
ZIP_EM_TRAD_PKWARE
تشفير PKWare التقليدي. لا تستخدم هذه الطريقة، فهي ليست آمنة. تم توفيرها فقط للتوافق مع الإصدارات السابقة.

إذا كان password هو NULL، يتم استخدام كلمة المرور الافتراضية التي تم توفيرها بواسطة zip_set_default_password(3).

يمكن تحديد طريقة التشفير الحالية لملف في أرشيف zip باستخدام zip_stat(3).

قيم الإرجاع

عند الانتهاء بنجاح، يتم إرجاع 0. بخلاف ذلك، يتم إرجاع -1 ويتم تعيين معلومات الخطأ في archive للإشارة إلى الخطأ.

الأخطاء

zip_file_set_encryption() تفشل إذا:

[ZIP_ER_ENCRNOTSUPP]
تم طلب طريقة ضغط غير مدعومة.
[ZIP_ER_INVAL]
index ليس فهرس ملف صالح في archive، أو أن تركيبة الوسائط غير صالحة.
[ZIP_ER_MEMORY]
لم يتمكن من تخصيص الذاكرة المطلوبة.
[ZIP_ER_RDONLY]
ملف zip للقراءة فقط، لا يُسمح بإجراء تغييرات.
