zip_error_get(3)

الحزمة: libzip

التراخيص: BSD

ZIP_ERROR_GET(3) دليل الوظائف المكتبية ZIP_ERROR_GET(3)

الاسم

zip_error_get، zip_file_error_get — الحصول على رموز الخطأ للأرشيف أو الملف (واجهة مهملة)

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

void
zip_error_get(zip_t *archive, int *zep, int *sep);

void
zip_file_error_get(zip_file_t *file, int *zep, int *sep);

الوصف

الوظائف zip_error_get() و zip_file_error_get() مهملة. استخدم zip_error_code_system(3)، zip_error_code_zip(3)، zip_file_get_error(3)، و zip_get_error(3) بدلاً من ذلك.

بالنسبة لـ zip_error_get()، استبدل

int ze, se;
zip_error_get(za, &ze, &se);
بـ 
int ze, se;
zip_error_t *error = zip_get_error(za);
ze = zip_error_code_zip(error);
se = zip_error_code_system(error);
بالنسبة لـ zip_file_error_get()، استبدل 
int ze, se;
zip_file_error_get(zf, &ze, &se);
بـ 
int ze, se;
zip_error_t *error = zip_file_get_error(zf);
ze = zip_error_code_zip(error);
se = zip_error_code_system(error);

انظر أيضاً

libzip(3)، zip_error_code_system(3)، zip_error_code_zip(3)، zip_file_get_error(3)، zip_get_error(3)

التاريخ

تمت إضافة zip_error_get() في libzip 0.6. تم إهمالها في libzip 1.0، استخدم zip_get_error()، zip_error_code_zip()، / zip_error_code_system() بدلاً من ذلك.

تمت إضافة zip_file_error_get() في libzip 0.6. تم إهمالها في libzip 1.0، استخدم zip_file_get_error()، zip_error_code_zip()، / zip_error_code_system() بدلاً من ذلك.
