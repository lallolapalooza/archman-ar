zip_source_win32handle_create(3)

الحزمة: libzip

التراخيص: BSD

ZIP_SOURCE_WIN32HANDLE(3) دليل وظائف المكتبة ZIP_SOURCE_WIN32HANDLE(3)

الاسم

zip_source_win32handle، zip_source_win32handle_create — إنشاء مصدر بيانات من مقبض ملف Windows

المكتبة

libzip (-lzip)

الملخص

#include <zip.h>

zip_source_t *
zip_source_win32handle(zip_t *archive, HANDLE h, zip_uint64_t start, zip_int64_t len);

zip_source_t *
zip_source_win32handle_create(HANDLE h, zip_uint64_t start, zip_int64_t len, zip_error_t *error);

الوصف

تنشئ الوظائف zip_source_win32handle() و zip_source_win32handle_create() مصدر سحاب (zip source) من مقبض ملف Windows. تقرأ len بايت من الموضع start منه. إذا كانت len تساوي 0 أو -1، فيتم استخدام الملف بأكمله (بدءًا من start).

إذا كان الملف يدعم الإزاحة (seek)، فيمكن استخدام المصدر لفتح أرشيف سحاب منه.

يتم فتح الملف وقراءته عند استخدام البيانات من المصدر، عادةً بواسطة zip_close() أو zip_open_from_source().

قيم الإرجاع

عند الاكتمال بنجاح، يتم إرجاع المصدر المنشأ. بخلاف ذلك، يتم إرجاع NULL ويتم تعيين رمز الخطأ في archive أو error للإشارة إلى الخطأ.

الأخطاء

تفشل zip_source_w32handle() و zip_source_w32handle_create() إذا:

[ZIP_ER_INVAL]
كان h أو start أو len غير صالح.
[ZIP_ER_MEMORY]
تعذر تخصيص الذاكرة المطلوبة.

انظر أيضًا

التاريخ

تمت إضافة zip_source_win32handle() و zip_source_win32handle_create() في libzip 1.0.
