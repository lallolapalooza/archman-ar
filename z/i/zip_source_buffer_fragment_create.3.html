zip_source_buffer_fragment_create(3)

الحزمة: libzip

التراخيص: BSD

ZIP_SOURCE_BUFFER_FRAGMENT(3) دليل وظائف المكتبة ZIP_SOURCE_BUFFER_FRAGMENT(3)

الاسم

zip_source_buffer_fragment، zip_source_buffer_fragment_create — إنشاء مصدر بيانات مضغوط من مخازن مؤقتة متعددة

المكتبة

libzip (-lzip)

ملخص

#include <zip.h>

zip_source_t *
zip_source_buffer_fragment(zip_t *archive, zip_buffer_fragment_t *fragments, zip_uint64_t nfragments, int freep);

zip_source_t *
zip_source_buffer_fragment_create(zip_buffer_fragment_t *fragments, zip_uint64_t nfragments, int freep, zip_error_t *error);

الوصف

تقوم الدالتان zip_source_buffer_fragment() و zip_source_buffer_fragment_create() بإنشاء مصدر بيانات مضغوط من البيانات الموجودة في fragments. تحدد nfragments عدد الأجزاء. إذا كانت freep غير صفرية، فسيتم تحرير البيانات عندما لا تعود مطلوبة.

struct zip_stat {
    zip_uint8_t *data;    /* مؤشر إلى البيانات الفعلية */
    zip_uint64_t length;  /* طول هذا الجزء */
};

يجب أن تظل البيانات التي تشير إليها fragments صالحة طوال عمر المصدر الذي تم إنشاؤه. يمكن تجاهل fragments نفسها بمجرد إنشاء المصدر.

يمكن استخدام المصدر لفتح أرشيف مضغوط منه.

قيم الإرجاع

عند الانتهاء بنجاح، يتم إرجاع المصدر الذي تم إنشاؤه. بخلاف ذلك، يتم إرجاع NULL ويتم تعيين رمز الخطأ في archive أو error للإشارة إلى الخطأ.

الأخطاء

تفشل الدالتان zip_source_buffer() و zip_source_buffer_create() إذا:

[ZIP_ER_INVAL]
تكون nfragments أكبر من صفر و fragments تكون NULL.
[ZIP_ER_MEMORY]
لم يكن من الممكن تخصيص الذاكرة المطلوبة.

انظر أيضا

libzip(3)، zip_file_add(3)، zip_file_replace(3)، zip_open_from_source(3)، zip_source(5)

التاريخ

تمت إضافة الدالتان zip_source_buffer_fragment() و zip_source_buffer_fragment_create() في libzip 1.4.0.
