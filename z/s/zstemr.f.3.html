الغرض:

!>
!> ZSTEMR يحسب القيم الذاتية المختارة، وبشكل اختياري، المتجهات الذاتية
!> لمصفوفة ثلاثية الأقطار متماثلة حقيقية T. أي مصفوفة غير مختزلة كهذه لديها
!> مجموعة محددة جيدًا من القيم الذاتية الحقيقية المختلفة زوجيًا، والمتجهات الذاتية الحقيقية المقابلة متعامدة زوجيًا.
!>
!> يمكن حساب الطيف إما بالكامل أو جزئيًا عن طريق تحديد
!> إما نطاق (VL,VU] أو نطاق من المؤشرات IL:IU للقيم الذاتية المطلوبة.
!>
!> اعتمادًا على عدد القيم الذاتية المطلوبة، يتم حسابها إما
!> بواسطة التنصيف أو خوارزمية dqds. يتم حساب المتجهات الذاتية المتعامدة عدديًا
!> عن طريق استخدام عوامل تحليل L D L^T مناسبة مختلفة بالقرب من مجموعات
!> القيم الذاتية المتشابهة (يشار إليها باسم RRRs، التمثيلات القوية نسبيًا).
!> رسم تخطيطي غير رسمي للخوارزمية يتبع.
!>
!> لكل كتلة غير مختزلة (مصفوفة فرعية) من T،
!>    (أ) احسب T - sigma I = L D L^T، بحيث
!>        L و D تحدد جميع القيم الذاتية المطلوبة بدقة نسبية عالية.
!>        هذا يعني أن التغييرات النسبية الصغيرة في مدخلات D و L
!>        تسبب تغييرات نسبية صغيرة فقط في القيم الذاتية و
!>        المتجهات الذاتية. التمثيل القياسي (غير المفكك) للمصفوفة
!>        ثلاثية الأقطار T لا يمتلك هذه الخاصية بشكل عام.
!>    (ب) احسب القيم الذاتية بدقة مناسبة.
!>        إذا كانت المتجهات الذاتية مطلوبة، فإن الخوارزمية تحقق
!>        الدقة الكاملة للقيم الذاتية المحسوبة فقط قبل
!>        أن يتم حساب المتجهات المقابلة، انظر الخطوات ج) ود).
!>    (ج) لكل مجموعة من القيم الذاتية المتشابهة، اختر
!>        مُزيحًا جديدًا قريبًا من المجموعة، وابحث عن تحليل جديد، وقم بتحديث
!>        القيم الذاتية المزاحة بدقة مناسبة.
!>    (د) لكل قيمة ذاتية ذات فصل نسبي كبير بما فيه الكفاية، احسب
!>        المتجه الذاتي المقابل عن طريق تشكيل تحليل ملتوي يكشف عن الرتبة.
!>        ارجع إلى (ج) لأي مجموعات متبقية.
!>
!> لمزيد من التفاصيل، انظر:
!> - Inderjit S. Dhillon and Beresford N. Parlett:
!>   Linear Algebra and its Applications, 387(1), pp. 1-28, August 2004.
!> - Inderjit Dhillon and Beresford Parlett:  SIAM Journal on Matrix Analysis and Applications, Vol. 25,
!>   2004.  Also LAPACK Working Note 154.
!> - Inderjit Dhillon: ,
!>   Computer Science Division Technical Report No. UCB/CSD-97-971,
!>   UC Berkeley, May 1997.
!>
!> تفاصيل إضافية
!> 1. ZSTEMR تعمل فقط على الأجهزة التي تتبع معيار الفاصلة العائمة IEEE-754
!> في معالجتها لللانهايات و NaNs.
!> وهذا يسمح باستخدام حلقات داخلية فعالة تتجنب التحقق من
!> قواسم القسمة الصفرية.
!>
!> 2. يمكن استخدام إجراءات LAPACK لتقليل مصفوفة هيرميتية معقدة إلى
!> شكل ثلاثي الأقطار متماثل حقيقي.
!>
!> (أي مصفوفة ثلاثية الأقطار هيرميتية معقدة لها قيم حقيقية على قطرها
!> وأرقام قد تكون معقدة على الأقطار الفرعية. عن طريق تطبيق
!> تحويل تشابه مع مصفوفة قطرية مناسبة
!> diag(1,e^{i \phy_1}, ... , e^{i \phy_{n-1}})، يمكن تحويل
!> المصفوفة الهيرميتية المعقدة إلى مصفوفة متماثلة حقيقية ويمكن تجنب
!> الحسابات المعقدة تمامًا.)
!>
!> بينما المتجهات الذاتية للمصفوفة ثلاثية الأقطار المتماثلة الحقيقية حقيقية،
!> المتجهات الذاتية للمصفوفة الهيرميتية المعقدة الأصلية لها مدخلات معقدة
!> بشكل عام.
!> نظرًا لأن مشغلات LAPACK تستبدل بيانات المصفوفة بالمتجهات الذاتية،
!> يقبل ZSTEMR مساحة عمل معقدة لتسهيل التشغيل البيني
!> مع ZUNMTR أو ZUPMTR.
!>

NAME

zstemr - computes the eigenvectors of a real symmetric tridiagonal matrix T.

SYNOPSIS

      SUBROUTINE ZSTEMR(
         JOBZ, RANGE, N, DLAMDA, SE, Z, NZC, VL, VU, IL, IU,
         ISUPPZ, TRI2L, TRI2R, NBANDS, WORK, LWORK, IWORK, LIWORK,
         INFO
      )

The subroutine ZSTEMR is called by the subroutine ZSTEIN to compute the eigenvectors of T.

This routine calls the following LAPACK routines:

•
• DLARRE
•
• ZLARRV

This routine sets up the parameters for DLARRE and ZLARRV, and otherwise just takes care of the input and output.

For the benefit of ZSTEIN, ZSTEMR does not use DLARRE's parameter TRYRAC.

DLARRE is called to partition the problem according to the desired eigenvalues.

ZLARRV is called to compute the eigenvectors for each partition.

In the current implementation, TRI2L, TRI2R, NBANDS, and TRYRAC are not used.

Function/Subroutine Documentation

JOBZ

!>          JOBZ is CHARACTER*1
!>          • = 'N': Z may be used to store the eigenvectors.
!>          • = 'V': Z stores the eigenvectors of T.
!>

RANGE

!>          RANGE is CHARACTER*1
!>          • = 'A': all eigenvalues will be found.
!>          • = 'V': all eigenvalues in the interval (VL, VU] will be found.
!>          • = 'I': if IL < IU, all eigenvalues in the ordered
!>                 list of eigenvalues are selected, and hence
!>                 specific integers, hence the more numeric look.
!>                 For notational convenience, the whole spectrum
!>                 of lambda is sorted on this subroutine.
!>                 And a rank revealing split is performed for
!>                 each of the two or more subproblems.
!>

N

!>          N is INTEGER
!>          The order of the matrix T. N >= 0.
!>

DLAMDA

!>          DLAMDA is DOUBLE PRECISION array, dimension (N)
!>          On input, the eigenvalues of the symmetric tridiagonal matrix T,
!>          sorted in ascending order.
!>          On exit, DLAMDA contains the eigenvalues specified by RANGE.
!>

SE

!>          SE is DOUBLE PRECISION array, dimension (N)
!>          On input, the split points or slack values provided by
!>          ZSTEMR for the eigenvalues in DLAMDA.
!>          SE(i) is the slack value for eigenvalue DLAMDA(i).
!>          On exit, SE contains the split points for the eigenvalues
!>          specified by RANGE.
!>

Z

!>          Z is DOUBLE PRECISION array, dimension (NZC, N)
!>          On exit, if JOBZ = 'V', Z contains the eigenvectors of T.
!>          The i-th eigenvector is stored in the i-th column of Z.
!>          If JOBZ = 'N', Z is not used.
!>

NZC

!>          NZC is INTEGER
!>          The number of columns in the array Z. NZC is an input
!>          parameter.
!>          If RANGE = 'A', then NZC >= max(1,N).
!>          If RANGE = 'V', then NZC >= the number of eigenvalues in (VL, VU].
!>          If RANGE = 'I', then NZC >= IU-IL+1.
!>          If NZC = -1, then a workspace query is assumed; the
!>          routine calculates the number of columns of the array Z that
!>          are needed to hold the eigenvectors.
!>          This value is returned as the first entry of the Z array, and
!>          no error message related to NZC is issued by XERBLA.
!>

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension ( 2*max(1,M) )
!>          The support of the eigenvectors in Z, i.e., the indices
!>          indicating the nonzero elements in Z. The i-th computed eigenvector
!>          is nonzero only in elements ISUPPZ( 2*i-1 ) through
!>          ISUPPZ( 2*i ). This is relevant in the case when the matrix
!>          is split. ISUPPZ is only accessed when JOBZ is 'V' and N > 0.
!>

TRYRAC

!>          TRYRAC is LOGICAL
!>          If TRYRAC = .TRUE., indicates that the code should check whether
!>          the tridiagonal matrix defines its eigenvalues to high relative
!>          accuracy.  If so, the code uses relative-accuracy preserving
!>          algorithms that might be (a bit) slower depending on the matrix.
!>          If the matrix does not define its eigenvalues to high relative
!>          accuracy, the code can uses possibly faster algorithms.
!>          If TRYRAC = .FALSE., the code is not required to guarantee
!>          relatively accurate eigenvalues and can use the fastest possible
!>          techniques.
!>          On exit, a .TRUE. TRYRAC will be set to .FALSE. if the matrix
!>          does not define its eigenvalues to high relative accuracy.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (LWORK)
!>          On exit, if INFO = 0, WORK(1) returns the optimal
!>          (and minimal) LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK. LWORK >= max(1,18*N)
!>          if JOBZ = 'V', and LWORK >= max(1,12*N) if JOBZ = 'N'.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates the optimal size of the WORK array, returns
!>          this value as the first entry of the WORK array, and no error
!>          message related to LWORK is issued by XERBLA.
!>

IWORK

!>          IWORK is INTEGER array, dimension (LIWORK)
!>          On exit, if INFO = 0, IWORK(1) returns the optimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.  LIWORK >= max(1,10*N)
!>          if the eigenvectors are desired, and LIWORK >= max(1,8*N)
!>          if only the eigenvalues are to be computed.
!>          If LIWORK = -1, then a workspace query is assumed; the
!>          routine only calculates the optimal size of the IWORK array,
!>          returns this value as the first entry of the IWORK array, and
!>          no error message related to LIWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          On exit, INFO
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = 1X, internal error in DLARRE,
!>                if INFO = 2X, internal error in ZLARRV.
!>                Here, the digit X = ABS( IINFO ) < 10, where IINFO is
!>                the nonzero error code returned by DLARRE or
!>                ZLARRV, respectively.
!>
