NAME

zsytf2_rk - general tridiagonalization of a general rectangular matrix

SYNOPSIS

SUBROUTINE ZSYTF2_RK( UPLO, N, A, LDA, D, E, TAU, INFO )
  CHARACTER(LEN=1) UPLO
  INTEGER          N
  COMPLEX*16       A( LDA, * )
  INTEGER          LDA
  DOUBLE PRECISION D( * )
  DOUBLE PRECISION E( * )
  COMPLEX*16       TAU( * )
  INTEGER          INFO

Function/Subroutine Documentation

ZSYTF2_RK reduces a complex symmetric rectangular matrix A to tridiagonal form by a sequence of symmetric similarity transformations:

A = Q * T * QH

where T is a tridiagonal matrix, and Q is a unitary matrix. The routine computes the tridiagonal matrix T and the elements of the vector TAU representing the orthogonal transformations.

The matrix T is stored in the upper or lower triangular part of the array A. The diagonal elements of T are stored in the array D, and the super-diagonal elements are stored in the first N-1 elements of the array E. The sub-diagonal elements are implicitly stored in the elements E(1) to E(N-1).

The unitarily matrix Q is not explicitly computed. The triangular factorization of Q is represented by the elements of the array TAU.

Arguments:

UPLO

CHARACTER*1. Must be 'U' or 'L'.

  • If UPLO = 'U', A contains the upper triangular part.
  • If UPLO = 'L', A contains the lower triangular part.
N

INTEGER. The order of the matrix A.

A( LDA, * )

COMPLEX*16. The matrix A. Only the upper or lower triangular part needs to be provided, depending on UPLO.

LDA

INTEGER. The leading dimension of the array A.

D( * )

DOUBLE PRECISION. The diagonal elements of the tridiagonal matrix T.

E( * )

DOUBLE PRECISION. The super-diagonal elements of the tridiagonal matrix T. E(i) stores the element T(i,i+1). The elements E(1) to E(N-1) are used to store the sub-diagonal elements of T.

TAU( * )

COMPLEX*16. The vector TAU contains the scalar factors of the elementary reflectors used in the reduction.

INFO

INTEGER.

  • INFO = 0: successful exit.
  • INFO < 0: if INFO = -i, the i-th argument had an illegal value.

توثيق الدالة/الروتين الفرعي

ZSYTF2_RK تقوم بتحويل مصفوفة متماثلة مستطيلة معقدة A إلى شكل قطري عن طريق سلسلة من تحويلات التشابه المتماثلة:

A = Q * T * QH

حيث T هي مصفوفة قطرية، و Q هي مصفوفة موحدة. تحسب هذه الروتين المصفوفة القطرية T وعناصر المتجه TAU التي تمثل التحويلات المتعامدة.

يتم تخزين المصفوفة T في الجزء العلوي أو السفلي من الجزء المثلثي للمصفوفة A. يتم تخزين العناصر القطرية لـ T في المصفوفة D، ويتم تخزين عناصر فوق القطر الرئيسي في أول N-1 عنصر من عناصر المصفوفة E. يتم تخزين عناصر تحت القطر الرئيسي ضمنيًا في العناصر E(1) إلى E(N-1).

لا يتم حساب المصفوفة الموحدة Q بشكل صريح. يتم تمثيل تحليل المصفوفة المثلثية لـ Q بواسطة عناصر المتجه TAU.

المعاملات:

UPLO

CHARACTER*1. يجب أن تكون 'U' أو 'L'.

  • إذا كانت UPLO = 'U'، فإن A تحتوي على الجزء المثلثي العلوي.
  • إذا كانت UPLO = 'L'، فإن A تحتوي على الجزء المثلثي السفلي.
N

INTEGER. رتبة المصفوفة A.

A( LDA, * )

COMPLEX*16. المصفوفة A. فقط الجزء المثلثي العلوي أو السفلي المطلوب يحتاج إلى تقديمه، اعتمادًا على UPLO.

LDA

INTEGER. البعد الرئيسي للمصفوفة A.

D( * )

DOUBLE PRECISION. العناصر القطرية للمصفوفة القطرية T.

E( * )

DOUBLE PRECISION. عناصر فوق القطر الرئيسي للمصفوفة القطرية T. E(i) تخزن العنصر T(i,i+1). يتم استخدام العناصر E(1) إلى E(N-1) لتخزين عناصر تحت القطر الرئيسي لـ T.

TAU( * )

COMPLEX*16. يحتوي المتجه TAU على العوامل العددية للمنكسات الأساسية المستخدمة في الاختزال.

INFO

INTEGER.

  • INFO = 0: خروج ناجح.
  • INFO < 0: إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية.
