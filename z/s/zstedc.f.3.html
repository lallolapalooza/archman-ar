NAME

zstedc — ZSTEDC

SYNOPSIS

SUBROUTINE ZSTEDC( COMPZ, N, D, E, Z, LDZ, WORK, INFO )

Function/Subroutine Documentation

ZSTEDC computes the eigenvalues and eigenvectors of a general matrix which is already projected on a similar subspace, by means of the divide and conquer method.

This subroutine is intended to be called by ZSTEQR, ZSTEDR, or ZSTEvx.

Arguments

COMPZ
CHARACTER*1.

= 'N': Do not compute the eigenvectors.

= 'V': Compute the eigenvectors.

N
INTEGER.

The order of the matrix T. N >= 0.

To enter ZSTEDC, the number of rows and columns of the matrix must be equal.

D
DOUBLE PRECISION array, dimension (N).

On entry, the diagonal elements of the tridiagonal matrix T.

On exit, if INFO = 0, the eigenvalues of T.

E
DOUBLE PRECISION array, dimension (N-1).

On entry, the off-diagonal elements of the tridiagonal matrix T.

On exit, if INFO = 0, the elements of E are arbitrary.

Z
COMPLEX*16 array, dimension (LDZ, N).

On entry, an encoding of the eigenvectors of the symmetric tridiagonal matrix T. The problem is to solve the T*Z = Z*D equation.

On exit, if COMPZ = 'V' and INFO = 0, the orthonormal eigenvectors of the matrix T.

On exit, if COMPZ = 'N' and INFO = 0, the content of Z is not specified.

LDZ
INTEGER.

The leading dimension of the array Z. LDZ >= max(1, N).

WORK
COMPLEX*16 array, dimension (N).

Local array for WORK.

INFO
INTEGER.

INFO = 0: successful exit.

INFO < 0: if INFO = -i, then the i-th argument had an illegal value.

INFO > 0: if INFO = i, then the algorithm failed to converge; i off-diagonal elements of E have no corresponding eigenvalue/vector.

Author

Department of Energy (DOE)

Lawrence Livermore National Laboratory (LLNL)

This is a part of the implementation of the divide and conquer algorithm.

This subroutine is in the LAPACK auxiliary routines.
