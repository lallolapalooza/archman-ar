توثيق الوظيفة/الوحدة الفرعية

subroutine zsptri (character uplo, integer n, complex*16, dimension( * ) ap, integer, dimension( * ) ipiv, complex*16, dimension( * ) work, integer info)

ZSPTRI

الغرض:

!>
!> ZSPTRI تحسب معكوس مصفوفة متماثلة غير محددة معقدة A بتخزين مضغوط
!> باستخدام التحلل A = U*D*U**T أو
!> A = L*D*L**T الذي تم حسابه بواسطة ZSPTRF.
!>

المعاملات

UPLO 
!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت تفاصيل التحليل مخزنة
!>          كمصفوفة مثلثية عليا أو سفلى.
!>          = 'U':  مثلثية عليا، الشكل هو A = U*D*U**T;
!>          = 'L':  مثلثية سفلى، الشكل هو A = L*D*L**T.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP is COMPLEX*16 array, dimension (N*(N+1)/2)
!>          عند الإدخال، المصفوفة القطرية المعيارية D والمعاملات
!>          المستخدمة للحصول على العامل U أو L كما تم حسابه بواسطة ZSPTRF،
!>          مخزنة كمصفوفة مثلثية مضغوطة.
!>
!>          عند الخروج، إذا كان INFO = 0، فإن معكوس (المتماثل) للمصفوفة الأصلية،
!>          مخزن كمصفوفة مثلثية مضغوطة. العمود j
!>          من inv(A) مخزن في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = inv(A)(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'،
!>             AP(i + (j-1)*(2n-j)/2) = inv(A)(i,j) لـ j<=i<=n.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          تفاصيل التبادلات والبنية المعيارية لـ D
!>          كما تم تحديدهما بواسطة ZSPTRF.
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية
!>          > 0: إذا كان INFO = i، فإن D(i,i) = 0؛ المصفوفة منفردة ولا يمكن
!>               حساب معكوسها.
!>
