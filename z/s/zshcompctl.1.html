أعلام مع الوسائط

هذه لديها وسائط يحددها المستخدم لتحديد كيفية تكوين قائمة الإكمالات:

-k مصفوفة
الأسماء المأخوذة من عناصر $مصفوفة (لاحظ أن `$' لا يظهر في سطر الأوامر). بدلاً من ذلك، قد تكون الوسيطة مصفوفة نفسها مجموعة من القيم مفصولة بمسافات أو فواصل في أقواس، وفي هذه الحالة يمكن الهروب من أي فاصل باستخدام خط مائل خلفي؛ في هذه الحالة، يجب اقتباس الوسيطة. على سبيل المثال،
compctl -k "(cputime filesize datasize stacksize
	       coredumpsize resident descriptors)" limit
-g سلسلة_نجمة
يتم توسيع سلسلة_نجمة باستخدام توسيع أسماء الملفات؛ يجب اقتباسها لحمايتها من التوسيع الفوري. يتم أخذ أسماء الملفات الناتجة كإكمالات ممكنة. استخدم `*(/)' بدلاً من `*/' للدلائل. لا يتم تطبيق المعلمة الخاصة fignore على الملفات الناتجة. يمكن إعطاء أكثر من نمط واحد مفصولة بمسافات. (لاحظ أن توسيع الأقواس ليس جزءًا من التوسيع. استخدم الصيغة `(either|or)' لمطابقة البدائل.)
-s سلسلة_استبدال
يتم تقسيم سلسلة_استبدال إلى كلمات ثم يتم توسيع هذه الكلمات باستخدام جميع آليات توسيع الصدفة (انظر zshexpn(1)). يتم أخذ الكلمات الناتجة كإكمالات ممكنة. لا يتم تطبيق المعلمة الخاصة fignore على الملفات الناتجة. لاحظ أن -g أسرع لأسماء الملفات.
-K وظيفة
استدعاء الوظيفة المعطاة للحصول على الإكمالات. ما لم يبدأ الاسم بشرطة سفلية، يتم تمرير وسيطتين إلى الوظيفة: البادئة واللاحقة للكلمة التي يتم محاولة إكمالها، بعبارة أخرى، تلك الأحرف قبل موضع المؤشر، وتلك من موضع المؤشر فصاعدًا. يمكن الوصول إلى سطر الأوامر بأكمله باستخدام علامتي -c و -l للأمر المدمج read. يجب أن تقوم الوظيفة بتعيين المتغير reply إلى مصفوفة تحتوي على الإكمالات (إكمال واحد لكل عنصر)؛ لاحظ أنه لا ينبغي جعل reply محليًا للوظيفة. من مثل هذه الوظيفة، يمكن الوصول إلى سطر الأوامر باستخدام علامتي -c و -l للأمر المدمج read. على سبيل المثال،
function whoson { reply=(`users`); }
compctl -K whoson talk

يكمل فقط المستخدمين المسجلين دخولهم بعد `talk'. لاحظ أن `whoson' يجب أن تعيد مصفوفة، لذا `reply=`users`' سيكون غير صحيح.

-H عدد نمط
يتم أخذ الإكمالات الممكنة من آخر عدد من أسطر السجل. يتم أخذ الكلمات التي تطابق نمط فقط. إذا كان عدد صفرًا أو سالبًا، يتم البحث في السجل بأكمله، وإذا كان نمط سلسلة فارغة، يتم أخذ جميع الكلمات (كما في `*'). الاستخدام النموذجي هو
compctl -D -f + -H 0 ''

مما يجبر الإكمال على البحث في قائمة السجل عن كلمة إذا لم يتم العثور على تطابق لاسم ملف.

أعلام التحكم

هذه لا تحدد مباشرة أنواع الأسماء المراد إكمالها، بل تتحكم في الخيارات التي تفعل ذلك:

-Q
هذا يوجه الصدفة لعدم اقتباس أي أحرف خاصة في الإكمالات الممكنة. عادةً ما يتم إدراج نتائج الإكمال في سطر الأوامر مع اقتباس أي أحرف خاصة بحيث يتم تفسيرها كأحرف عادية. هذا مناسب لأسماء الملفات والسلاسل العادية. ومع ذلك، للتأثيرات الخاصة، مثل إدراج تعبير مقتبس بعلامات تنصيص عكسية من مصفوفة إكمال (-k) بحيث لن يتم تقييم التعبير حتى يتم تنفيذ السطر كاملاً، يجب استخدام هذا الخيار.
-P بادئة
يتم إدراج بادئة مباشرة قبل السلسلة المكتملة؛ سيتم إكمال أي جزء أولي مكتوب بالفعل وسيتم تجاهل بادئة بأكملها لأغراض الإكمال. على سبيل المثال،
compctl -j -P "%" kill

يُدرج علامة '%' بعد أمر kill ثم يكمل أسماء المهام.

-S لاحقة
عند العثور على إكمال، يتم إدراج لاحقة بعد السلسلة المكتملة. في حالة إكمال القائمة، يتم إدراج اللاحقة على الفور، ولكن لا يزال من الممكن التنقل عبر قائمة الإكمالات عن طريق الضغط على نفس المفتاح بشكل متكرر.
-W بادئة_ملف
مع بادئة_ملف الدليل: بالنسبة لإكمال الأوامر والملفات والدلائل والنجمية (الخيارات -c و -f و -/ و -g)، تتم إضافة بادئة الملف ضمنيًا قبل الإكمال. على سبيل المثال،
compctl -/ -W ~/Mail maildirs

يكمل أي دلائل فرعية لأي عمق تحت الدليل ~/Mail، على الرغم من أن هذه البادئة لا تظهر في سطر الأوامر. يمكن أن تكون بادئة_ملف أيضًا بالشكل الذي تقبله علامة -k، أي اسم مصفوفة أو قائمة حرفية بين قوسين. في هذه الحالة، سيتم البحث في جميع الدلائل في القائمة عن إكمالات ممكنة.

-q
إذا تم استخدامه مع لاحقة كما هو محدد بواسطة الخيار -S، فإن هذا يتسبب في إزالة اللاحقة إذا كان الحرف التالي الذي تم كتابته هو مسافة بيضاء أو لا يقوم بإدراج أي شيء أو إذا كانت اللاحقة تتكون من حرف واحد فقط وكان الحرف التالي الذي تم كتابته هو نفس الحرف؛ هذه هي نفس القاعدة المستخدمة للخيار AUTO_REMOVE_SLASH. الخيار مفيد جدًا لفواصل القوائم (فاصلة، نقطتين، إلخ).
-l أمر
يقيد هذا الخيار نطاق كلمات سطر الأوامر التي تعتبر وسائط. إذا تم دمجه مع أحد أنماط الإكمال الموسعة `p[...]' و `r[...]' أو `R[...]' (انظر القسم `إكمال موسع' أدناه) يتم تقييد النطاق بالوسائط المحددة في الأقواس. ثم يتم الإكمال كما لو تم تقديم هذه كوسائط للأمر أمر المقدم مع الخيار. إذا كانت سلسلة أمر فارغة، يتم بدلاً من ذلك أخذ الكلمة الأولى في النطاق كاسم أمر، ويتم إجراء إكمال اسم الأمر على الكلمة الأولى في النطاق. على سبيل المثال،
compctl -x 'r[-exec,;]' -l '' -- find

يكمل الوسائط بين `-exec' و `;' التالي (أو نهاية سطر الأوامر إذا لم يكن هناك مثل هذه السلسلة) كما لو كانت سطر أوامر منفصل.

-h أمر
عادةً ما تكمل zsh السلاسل المقتبسة كوحدة واحدة. مع هذا الخيار، يمكن إجراء الإكمال بشكل منفصل على أجزاء مختلفة من هذه السلاسل. يعمل مثل الخيار -l ولكنه يجعل كود الإكمال يعمل على أجزاء الكلمة الحالية المفصولة بمسافات. يتم إكمال هذه الأجزاء كما لو كانت وسائط للأمر أمر المعطى. إذا كان أمر سلسلة فارغة، يتم إكمال الجزء الأول كاسم أمر، كما هو الحال مع -l.
-U
استخدم القائمة الكاملة للإكمالات الممكنة، سواء كانت تطابق الكلمة في سطر الأوامر أم لا. سيتم حذف الكلمة المكتوبة حتى الآن. هذا مفيد جدًا مع وظيفة (مقدمة بواسطة الخيار -K) يمكنها فحص مكونات الكلمات التي تم تمريرها إليها (أو عبر علامتي -c و -l للأمر read) واستخدام معاييرها الخاصة لتحديد ما يتطابق. إذا لم يكن هناك إكمال، يتم الاحتفاظ بالكلمة الأصلية. نظرًا لأن الإكمالات الممكنة المنتجة نادرًا ما يكون لها بادئات ولواحق مشتركة مثيرة للاهتمام، يبدأ إكمال القائمة على الفور إذا تم تعيين AUTO_MENU وتم استخدام هذا العلم.
-y وظيفة_أو_متغير
القائمة المقدمة بواسطة وظيفة_أو_متغير

NAME

zshcompctl - control the shell's completion system

DESCRIPTION

This is an internal shell command that is used to control the shell's completion system. It is typically used within a zshcompinit hook function or within a shell script.

COMMAND FLAGS

-k
Enable completion for the current command. This is the default.
-k-
Disable completion for the current command.
-c
Clear all existing completion definitions for the current command.
-l
Load completion definitions from the specified files. If no files are specified, load the default completion definitions.
-p
Print the current completion definitions for the current command.
-s
Set the completion style for the current command. The style is specified by the argument.
-t
Set the completion type for the current command. The type is specified by the argument.
-u
Enable user-defined completions for the current command.
-x
Set the extended completion rules for the current command.
-g
Set the global completion rules for the current command.
-f
Set the file completion rules for the current command.
-o
Set the option completion rules for the current command.
-a
Set the argument completion rules for the current command.

ALTERNATIVE COMPLETION

Some commands can be handled by alternative completion mechanisms. For example, if you want to complete user names, you can use the -u flag. If you want to complete host names, you can use the -h flag. You can also specify a list of completions to choose from. For example, to complete from a list of user names, you can use the -u flag with a list of user names as the argument. Other commands such as rcp can be handled similarly.

If you insert an @ after the name, names from the array hosts (assumed to contain hostnames, though you must make the array yourself) will be completed. Other commands such as rcp can be handled similarly.

EXTENDED COMPLETION

N[index,string]...
Like n except that the string will be taken as a character class. Anything up to and including the indexth occurrence of any of the characters in string will not be considered part of the completion.
m[min,max]...
Matches if the total number of words lies between min and max inclusive.
r[str1,str2]...
Matches if the cursor is after a word with prefix str1. If there is also a word with prefix str2 on the command line after the one matched by str1 it matches only if the cursor is before this word. If the comma and str2 are omitted, it matches if the cursor is after a word with prefix str1.
R[str1,str2]...
Like r but using pattern matching instead.
q[str]...
Matches the word currently being completed is in single quotes and the str begins with the letter `s', or if completion is done in double quotes and str starts with the letter `d', or if completion is done in backticks and str starts with a `b'.

EXAMPLE

compctl -u -x 's[+] c[-1,-f],s[-f+]' \ 
  -g '~/Mail/*(:t)' - 's[-f],c[-1,-f]' -f -- mail

This is to be interpreted as follows:

If the current command is mail, then

if ((the current word begins with + and the previous word is -f)
or (the current word begins with -f+)), then complete the
non-directory part (the `:t' glob modifier) of files in the directory
~/Mail; else
if the current word begins with -f or the previous word was -f, then
complete any file; else
complete user names.
