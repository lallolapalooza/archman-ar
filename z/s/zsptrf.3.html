وثائق الوظيفة/الروتين الفرعي

subroutine zsptrf (character uplo, integer n, complex*16, dimension( * ) ap, integer, dimension( * ) ipiv, integer info)

ZSPTRF

الغرض:

!>
!> ZSPTRF يحسب تحليل مصفوفة متماثلة معقدة A
!> مخزنة بتنسيق مضغوط باستخدام طريقة التنقيب القطري لبونش-كوفمان:
!>
!>    A = U*D*U**T  أو  A = L*D*L**T
!>
!> حيث U (أو L) هو حاصل ضرب مصفوفة تبديل ومصفوفة مثلثية عليا (سفلى)
!> وحدوية، و D مصفوفة متماثلة وقطرية كتلية ذات كتل قطرية
!> بحجم 1x1 و 2x2.
!>

المعلمات

UPLO 
!>          UPLO هي CHARACTER*1
!>          = 'U':  يتم تخزين المثلث العلوي لـ A؛
!>          = 'L':  يتم تخزين المثلث السفلي لـ A.
!>

N

!>          N هي INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP هي مصفوفة COMPLEX*16، البعد (N*(N+1)/2)
!>          عند الإدخال، المثلث العلوي أو السفلي للمصفوفة المتماثلة
!>          A، مضغوطة عمودياً في مصفوفة خطية. يتم تخزين العمود j من A
!>          في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>
!>          عند الخروج، يتم تخزين المصفوفة القطرية الكتلية D والعوامل المستخدمة
!>          للحصول على العامل U أو L، كمصفوفة مثلثية مضغوطة
!>          تكتب فوق A (انظر أدناه لمزيد من التفاصيل).
!>

IPIV

!>          IPIV هي مصفوفة INTEGER، البعد (N)
!>          تفاصيل التبادلات وهيكل الكتل لـ D.
!>          إذا كان IPIV(k) > 0، فقد تم تبديل الصفوف والأعمدة k و IPIV(k)
!>          و D(k,k) هي كتلة قطرية بحجم 1x1.
!>          إذا كان UPLO = 'U' وكان IPIV(k) = IPIV(k-1) < 0، فقد تم تبديل
!>          الصفوف والأعمدة k-1 و -IPIV(k) و D(k-1:k,k-1:k)
!>          هي كتلة قطرية بحجم 2x2. إذا كان UPLO = 'L' وكان IPIV(k) =
!>          IPIV(k+1) < 0، فقد تم تبديل الصفوف والأعمدة k+1 و -IPIV(k)
!>          و D(k:k+1,k:k+1) هي كتلة قطرية بحجم 2x2.
!>

INFO

!>          INFO هي INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية
!>          > 0: إذا كان INFO = i، فإن D(i,i) تساوي صفر تماماً. تم إكمال
!>               التحليل، لكن المصفوفة القطرية الكتلية D منفردة تماماً،
!>               وسينتج قسمة على صفر إذا تم استخدامها لحل نظام معادلات.
!>

!>         Company
!>
!>  إذا كان UPLO = 'U'، فإن A = U*D*U**T، حيث
!>     U = P(n)*U(n)* ... *P(k)U(k)* ...,
!>  أي أن U هو حاصل ضرب الحدود P(k)*U(k)، حيث k تتناقص من n إلى
!>  1 بخطوات 1 أو 2، و D هي مصفوفة قطرية كتلية ذات كتل قطرية
!>  حجمها 1x1 و 2x2 وهي D(k). P(k) هي مصفوفة تبديل كما
!>  يتم تعريفها بواسطة IPIV(k)، و U(k) هي مصفوفة مثلثية عليا وحدوية،
!>  بحيث إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    v    0   )   k-s
!>     U(k) =  (   0    I    0   )   s
!>             (   0    0    I   )   n-k
!>                k-s   s   n-k
!>
!>  إذا كان s = 1، فإن D(k) تكتب فوق A(k,k)، و v تكتب فوق A(1:k-1,k).
!>  إذا كان s = 2، فإن المثلث العلوي لـ D(k) يكتب فوق A(k-1,k-1)، A(k-1,k)،
!>  و A(k,k)، و v تكتب فوق A(1:k-2,k-1:k).
!>
!>  إذا كان UPLO = 'L'، فإن A = L*D*L**T، حيث
!>     L = P(1)*L(1)* ... *P(k)*L(k)* ...,
!>  أي أن L هو حاصل ضرب الحدود P(k)*L(k)، حيث k تزداد من 1 إلى
!>  n بخطوات 1 أو 2، و D هي مصفوفة قطرية كتلية ذات كتل قطرية
!>  حجمها 1x1 و 2x2 وهي D(k). P(k) هي مصفوفة تبديل كما
!>  يتم تعريفها بواسطة IPIV(k)، و L(k) هي مصفوفة مثلثية سفلى وحدوية،
!>  بحيث إذا كانت الكتلة القطرية D(k) من الرتبة s (s = 1 أو 2)، فإن
!>
!>             (   I    0     0   )  k-1
!>     L(k) =  (   0    I     0   )  s
!>             (   0    v     I   )  n-k-s+1
!>                k-1   s  n-k-s+1
!>
!>  إذا كان s = 1، فإن D(k) تكتب فوق A(k,k)، و v تكتب فوق A(k+1:n,k).
!>  إذا كان s = 2، فإن المثلث السفلي لـ D(k) يكتب فوق A(k,k)، A(k+1,k)،
!>  و A(k+1,k+1)، و v تكتب فوق A(k+2:n,k:k+1).
!>
