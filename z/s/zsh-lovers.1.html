(Recursive) Globbing - Examples

يمكن العثور على قائمة بمؤهلات glob الصالحة في zshexpn(1). ملاحظة: **/ يعادل (*/)#! على سبيل المثال:

$ print (*/)#zsh_us.ps
zsh-4.2.3/Doc/zsh_us.ps
$ print **/zsh_us.ps
zsh-4.2.3/Doc/zsh_us.ps
# البحث عن `README' في جميع الدلائل الفرعية
  $ ls -l **/README
# البحث عن الدلائل التي تحتوي على كل من "index.php" و "index.html"، أو بشكل عام،
# الدلائل التي تحتوي على أكثر من ملف واحد يطابق "index.*"
  $ ls **/*(D/e:'[[ -e $REPLY/index.php && -e $REPLY/index.html ]]':)
  # أو
  $ ls **/*(D/e:'l=($REPLY/index.*(N)); (( $#l >= 2 ))':)
# أمر البحث للبحث عن اسم الدليل بدلاً من الاسم الأساسي
  $ print -rl /**/*~^*/path(|/*)
  # أو - بدون Zsh
  $ find / | grep -e /path/ -e '/path$'
# طباعة مسار الدلائل التي تحتوي على أكبر 10 ملفات C عادية
# في الدليل الحالي والدلائل الفرعية.

  $ chmod 700 **/(/) # المجلدات فقط

  $ print -rC2 -- ${1:[...]}/*(D:t)

  $ pcre_study
  $ print -l ./**/*(DN.e{'pcre_match $mapfile[$REPLY]'})
# مكافئ لـ "less /etc/passwd | grep -v root"
  $ zmodload zsh/mapfile
  $ IFS=$'\n\n'
  $ print -rl -- ${${=mapfile[/etc/passwd]}:#*root*}
# أو - للبحث غير الحساس لحالة الأحرف
  $ setopt extendedglob
  $ print -rl -- ${${=mapfile[/etc/passwd]}:#*(#i)root*}
# إذا كان ملف XML يحتوي على أشياء مثل ``<TAGA/>'' و ``<TAGB/>'', قم بترقيم
# هذه العلامات الفارغة (التي تنتهي بـ '/>') بحيث إذا تم العثور عليها بنفس
# الترتيب، تصبح العلامات السابقة ``<TAGA/>1</TAGA>'' و
# ``<TAGB/>2</TAGB>''
  $ zmodload zsh/mapfile
  $ cnt=0
  $ apfile[data.xml.new]=${(S)mapfile[data.xml]//\
  > (#im)<TAGA>*<\/TAGA>/<TAGA>$((++cnt))<\/TAGA>}
# إزالة جميع الملفات في Maildir/new للمستخدمين التي تحتوي على "filename="gone.src"
  $ zmodload zsh/{files,mapfile}
  $ rm -f /u1/??/*/Maildir/new/100*(.e{'[[ $mapfile[$REPLY] == \
    *filename=\"gone.scr\"* ]]'})
# استخراج العنوان من ملف postscript وإلحاق هذه القيمة بنهاية اسم الملف
  $ autoload -U zmv
  $ zmodload zsh/mapfile
  $ zmv '(*).ps' '$1-${${${mapfile[$f]##*%%Title: }%% *}//[^a-zA-Z0-9_]/}.ps'

الخيارات (OPTIONS)

خيارات التنقل (Navigation options)

auto_cd (يسمح بتغيير الدليل عن طريق إدخاله كأمر). auto_pushd (إضافة الأدلة تلقائيًا إلى قائمة push/pop) pushd_ignore_dups (وعدم تكرارها).

متفرقات (Misc)

no_hup (لا ترسل إشارة HUP إلى المهام الخلفية عند الخروج من ZSH). print_exit_value (عرض رسالة برمز الخروج عندما يعود أمر ما برمز خروج غير صفري)

خيارات السجل (History options)

hist_verify (اسمح للمستخدم بتحرير سطر الأوامر بعد توسيع السجل (مثل !ls) بدلاً من تشغيله فورًا) استخدم نفس ملف السجل لجميع الـ

setopt SHARE_HISTORY

الخصوصية / الأمان

no_clobber (أو set -C؛ لمنع إعادة توجيه > من اقتطاع الملف المحدد إذا كان موجودًا بالفعل)

تصحيح الإملاء

correct (تصحيح الإملاء للأوامر تلقائيًا). correct_all (تصحيح الإملاء لكل كلمة في سطر الأوامر تلقائيًا) dvorak (تخطيط لوحة المفاتيح dvorak)

لترحيل bashprompt الخاص بك إلى zsh، استخدم البرنامج النصي bash2zshprompt الموجود في توزيعة مصدر zsh ضمن Misc.

للترحيل من (t)csh إلى zsh، استخدم أداة c2z التي تحول أسماء المستعارات ومتغيرات البيئة والصدفة في csh إلى zsh. يتم ذلك عن طريق تشغيل csh، وجعل csh يبلغ عن أسماء المستعارات والمتغيرات. ثم يقوم البرنامج النصي بتحويلها إلى ملفات بدء تشغيل zsh. لديه بعض المشكلات ومعلومات الاستخدام التي تم توثيقها في أعلى هذا البرنامج النصي.

إليك وظائف لتعيين عنوان و status صعب لـ XTerm أو GNU Screen إلى zsh والدليل الحالي، على التوالي، عند عرض المطالبة، وإلى اسم الأمر وبقية سطر الأوامر، على التوالي، عند تنفيذ أمر:

function title {
      if [[ $TERM == "screen" ]]; then
        # Use these two for GNU Screen:
        print -nR $' 33k'$1$' 33'\
        print -nR $' 33]0;'$2$''
      elif [[ $TERM == "xterm" || $TERM == "rxvt" ]]; then
        # Use this one instead for XTerms:
        print -nR $' 33]0;'$*$''
      fi
}
function precmd { title zsh "$PWD" }
function preexec {
    emulate -L zsh
    local -a cmd; cmd=(${(z)1})
    title $cmd[1]:t "$cmd[2,-1]"
}
