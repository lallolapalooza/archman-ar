NAME

zsysvx - subroutine

SYNOPSIS

   SUBROUTINE ZSYSVX( FACT, UPLO, N, A, LDA, AF, LDAF, IPIV, B, LDB, X, LDX,
                        RCOND, FERR, BERR, WORK, LWORK, RWORK, INFO )

Parameters:

FACT

CHARACTER*1. FACT specifies whether or not the factorization of the matrix A is supplied on entry. See this integer parameter 

   = ‘N’: the routine ZSYTRF computes the factorization of A.
   = ‘F’: the factorization of A is supplied on entry in the arrays
    AF and IPIV.

UPLO

CHARACTER*1. UPLO specifies whether the matrix A is upper- or lower-triangular.

   = ‘U’: Upper triangle of A is stored and will be used.
   = ‘L’: Lower triangle of A is stored and will be used.

N

INTEGER. The order of the matrix A. N >= 0.

A

COMPLEX*16 array, dimension (LDA,N)

On entry, the symmetric or Hermitian matrix A.

If UPLO = ‘U’, the element A(i,j) for i <= j is stored. If UPLO = ‘L’, the element A(i,j) for i >= j is stored.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,N).

AF

COMPLEX*16 array, dimension (LDAF,N)

On exit, if FACT = ‘N’, AF contains the block L*U factorization of A stored in block form (see Notes below).

If FACT = ‘F’, AF contains the factorization of A.

LDAF

INTEGER. The leading dimension of the array AF. LDAF >= max(1,N).

IPIV

INTEGER array, dimension (N)

On exit, if FACT = ‘N’, IPIV contains the pivot indices of the factorization. Pivot indices index the block rows of AF. Column indices are not stored. If the pivot is of order k>1, then IPIV(i) = k and A(i,i) is the diagonal element of the k by k block.

If FACT = ‘F’, IPIV contains the pivot indices of the factorization.

B

COMPLEX*16 array, dimension (LDB,NRHS)

On entry, the right hand side matrix of the system A*X = B.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1,N).

X

COMPLEX*16 array, dimension (LDX,NRHS)

On exit, the solution matrix of the system A*X = B.

LDX

INTEGER. The leading dimension of the array X. LDX >= max(1,N).

RCOND

DOUBLE PRECISION. On exit, the reciprocal of the condition number of A. A is well-conditioned if RCOND is close to 1.

FERR

DOUBLE PRECISION array, dimension (NRHS)

On exit, the estimated forward error bound for each column of the solution X. If A is nonsingular, the estimate is such that norm(X(i) - X,1) / norm(X,1) <= FERR(i)

where X(i) is the ith column of X, and I denotes the iteration number.

BERR

DOUBLE PRECISION array, dimension (NRHS)

On exit, the estimated backward error bound for each column of the solution X. BERR(i) is an estimate of the smallest relative perturbation in each element of A(i) for the ith column of B, that would cause the ith system

A*x = b

to have x as the exact solution.

WORK

COMPLEX*16 array, dimension (MAX(1,LWORK))

On exit, if INFO = 0, WORK(1) returns the optimal LWORK.

LWORK

INTEGER. The length of WORK. LWORK >= max(1,2*N), and for best performance, when FACT = ‘N’, LWORK >= max(1,2*N,N*NB), where NB is the optimal blocksize for ZSYTRF.

If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.

RWORK

DOUBLE PRECISION array, dimension (N)

INFO

INTEGER.

= 0: successful exit

< 0: if INFO = -i, the i-th argument had an illegal value

> 0: if INFO = i, and i is

<= N: D(i,i) is exactly zero. The factorization has been completed but the factor D is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.

= N+1: D is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
