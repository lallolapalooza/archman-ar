double precision function zrzt02 (integer m, integer n, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork)

ZRZT02

الغرض:

!>
!> ZRZT02 تُرجع
!>      || I - Q'*Q || / ( M * eps)
!> حيث يتم تعريف المصفوفة Q بواسطة تحويلات هاوسهولدر
!> التي تم إنشاؤها بواسطة ZTZRZF.
!>

المعلمات

M 
!>          M هو عدد صحيح (INTEGER)
!>          عدد الصفوف في المصفوفة AF.
!>

N

!>          N هو عدد صحيح (INTEGER)
!>          عدد الأعمدة في المصفوفة AF.
!>

AF

!>          AF هي مصفوفة مركبة (COMPLEX*16)، الأبعاد (LDA,N)
!>          الناتج من ZTZRZF.
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البعد الرائد للمصفوفة AF.
!>

TAU

!>          TAU هي مصفوفة مركبة (COMPLEX*16)، الأبعاد (M)
!>          تفاصيل تحويلات هاوسهولدر كما تم إرجاعها بواسطة
!>          ZTZRZF.
!>

WORK

!>          WORK هي مصفوفة مركبة (COMPLEX*16)، الأبعاد (LWORK)
!>

LWORK

!>          LWORK هو عدد صحيح (INTEGER)
!>          طول مصفوفة WORK. LWORK >= N*N+N.
!>
