الاسم

zrzt01.f

الملخص

الدوال/الدُنيا


double precision function zrzt01 (m, n, a, af, lda, tau, work, lwork)
ZRZT01

توثيق الدالة/الدُنيا

double precision function zrzt01 (integer m, integer n, complex*16, dimension( lda, * ) a, complex*16, dimension( lda, * ) af, integer lda, complex*16, dimension( * ) tau, complex*16, dimension( lwork ) work, integer lwork)

ZRZT01

الغرض:

!>
!> ZRZT01 تعيد
!>      || A - R*Q || / ( M * eps * ||A|| )
!> لمصفوفة A شبه منحرفة علوية تم تحليلها باستخدام ZTZRZF.
!>

المعاملات

M 
!>          M هو صحيح (INTEGER)
!>          عدد صفوف المصفوفتين A و AF.
!>

N

!>          N هو صحيح (INTEGER)
!>          عدد أعمدة المصفوفتين A و AF.
!>

A

!>          A هي مصفوفة مركبة *16 (COMPLEX*16)، البعد (LDA,N)
!>          المصفوفة الأصلية شبه المنحرفة العلوية A ذات البعد M في N.
!>

AF

!>          AF هي مصفوفة مركبة *16 (COMPLEX*16)، البعد (LDA,N)
!>          الناتج من ZTZRZF للمصفوفة A المدخلة.
!>          المثلث السفلي غير مستخدم.
!>

LDA

!>          LDA هو صحيح (INTEGER)
!>          البعد الرائد للمصفوفتين A و AF.
!>

TAU

!>          TAU هي مصفوفة مركبة *16 (COMPLEX*16)، البعد (M)
!>          تفاصيل تحويلات هاوسهولدر كما تم إرجاعها بواسطة
!>          ZTZRZF.
!>

WORK

!>          WORK هي مصفوفة مركبة *16 (COMPLEX*16)، البعد (LWORK)
!>

LWORK

!>          LWORK هو صحيح (INTEGER)
!>          طول المصفوفة WORK. LWORK >= m*n + m.
!>
