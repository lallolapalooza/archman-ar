zellij(1) دليل الأوامر العام zellij(1)

الاسم

zellij - تشغيل zellij

الوصف

Zellij هو مساحة عمل موجهة للمطورين، الأشخاص الموجهين نحو العمليات، وأي شخص يحب الطرفية. في جوهره، هو مضاعف طرفية (مشابه لـ tmux و screen)، ولكنه مجرد طبقة بنية تحتية.

يتضمن Zellij نظام تخطيط، ونظام إضافات يسمح بإنشاء إضافات بأي لغة يتم ترجمتها إلى WebAssembly.

لعرض الجلسات قيد التشغيل حاليًا، قم بتشغيل: `zellij list-sessions` للاتصال بجلسة قيد التشغيل حاليًا، قم بتشغيل: `zellij attach [اسم-الجلسة]`

خيارات

قم بتشغيل `zellij --help` لرؤية الأعلام والأوامر الفرعية المتاحة.

الإعداد

يبحث Zellij عن ملف الإعداد بالترتيب التالي:

1.
الملف المقدم مع --config
2.
تحت المسار المقدم في متغير البيئة ZELLIJ_CONFIG_FILE
3.
الموقع الافتراضي (انظر قسم الملفات)
4.
الموقع النظامي

قم بتشغيل `zellij setup --check` لرؤية المشكلات المحتملة مع الإعداد.

التخطيطات

التخطيطات هي ملفات yaml يمكن لـ Zellij تحميلها عند بدء التشغيل عندما يتم توفير العلم --layout. افتراضيًا، سيقوم Zellij بتحميل تخطيط يسمى `default.yaml`، ولكن يمكن تغيير ذلك باستخدام خيار الإعداد `default_layout: [اسم-التخطيط]`.

على سبيل المثال، ملف مثل هذا:

---
direction: Vertical
parts:
    - direction: Horizontal
      split_size:
        Percent: 50
      parts:
        - direction: Vertical
          split_size:
            Percent: 50
        - direction: Vertical
          split_size:
            Percent: 50
    - direction: Horizontal
      split_size:
        Percent: 50

سيخبر Zellij بإنشاء هذا التخطيط:

+-----+-----+|     |     |+-----+     ||     |     |+-----+-----+

إنشاء التخطيطات

ملف التخطيط هو بنية شجرية متداخلة. يصف كل عقدة إما جزءًا (ورقة)، أو مساحة سيتم فيها إنشاء أجزائها (أبنائها).

كل عقدة لديها الحقول التالية:

  • direction: <Horizontal / Vertical> - سيتم إنشاء أبناء العقدة عن طريق تقسيم في الاتجاه المحدد.
  • split_size: - يشير هذا إما إلى نسبة مئوية من مساحة العقدة الأصل أو حجم ثابت من الأعمدة/الصفوف من مساحة الأصل.
  • Percent: <1-100>
  • Fixed: <عدد-الأسطر/عدد-الأعمدة>
•
plugin: /path/to/plugin.wasm - مسار اختياري إلى إضافة Zellij مترجمة. إذا تم تحديده، يتم تحميل إضافة في المساحة التي تم إنشاؤها. لمزيد من المعلومات، انظر قسم الإضافات.

اختصارات لوحة المفاتيح

يأتي Zellij مع مجموعة افتراضية من اختصارات لوحة المفاتيح التي تهدف إلى تلبية احتياجات أكبر عدد ممكن من المستخدمين، ولكن يمكن تجاوز هذا السلوك أو تعديله في ملفات الإعدادات الخاصة بالمستخدم. تتوفر المعلومات حول الارتباطات في قسم keybinds من الإعداد. على سبيل المثال، لتقديم اختصار لوحة مفاتيح يقوم بإنشاء علامة تبويب جديدة والانتقال إلى علامة التبويب 1 بعد الضغط على 'c'، يمكنك كتابة:

keybinds:
    normal:
        - action: [ NewTab, GoToTab: 1,]
          key: [ Char: 'c',]

حيث تشير "normal" إلى اسم وضع (انظر قسم الأوضاع)، ويحدد جزء "action" الإجراءات التي سيقوم Zellij بتنفيذها (انظر قسم الإجراءات)، ويستخدم "key" لسرد المفاتيح أو مجموعات المفاتيح المرتبطة بالإجراءات المحددة (انظر المفاتيح).

يمكن إلغاء ربط اختصارات لوحة المفاتيح الافتراضية إما لوضع معين، أو لكل وضع. يدعم إما قائمة من `keybinds`، أو قيمة منطقية تشير إلى أنه سيتم إلغاء ربط كل اختصار لوحة مفاتيح:

keybinds:
    unbind: true

سيؤدي ذلك إلى إلغاء ربط كل ربط افتراضي.

keybinds:
    unbind: [ Ctrl: 'p']

سيؤدي ذلك إلى إلغاء ربط كل ربط افتراضي لـ `^P` لكل وضع.

keybinds:
    normal:
        - unbind: true

سيؤدي ذلك إلى إلغاء ربط كل ربط افتراضي لوضع `normal`.

keybinds:
    normal:
        - unbind: [ Alt: 'n', Ctrl: 'g']

سيؤدي ذلك إلى إلغاء ربط كل ربط افتراضي لـ `n` و `^g` لوضع `normal`.

الإجراءات

  • Quit - يخرج من Zellij
  • SwitchToMode: <InputMode> - ينتقل إلى وضع الإدخال المحدد. انظر قسم الأوضاع للقيم الممكنة.
  • Resize: <Direction> - يعيد تحجيم الجزء الذي تم التركيز عليه في الاتجاه المحدد (واحد من: Left, Right, Up, Down).
  • FocusNextPane - ينقل التركيز إلى الجزء التالي إلى اليمين أو الأسفل إذا كان على حافة الشاشة.
  • FocusPreviousPane - ينقل التركيز إلى الجزء التالي إلى اليسار أو الأعلى إذا كان على حافة الشاشة.
  • SwitchFocus - يبقى لدعم الإرث. ينقل التركيز إلى جزء له المعرف التالي.
  • MoveFocus: <Direction> - ينقل التركيز في الاتجاه المحدد (Left, Right, Up, Down).
  • Clear - يمسح الشاشة الحالية.
  • DumpScreen: <File> - يفرغ الشاشة في الملف المحدد.
  • DumpLayout: <File> - يفرغ الشاشة في الملف المحدد أو الافتراضي.
  • EditScrollback - يستبدل الجزء الحالي بمخزن التمرير.
  • ScrollUp - يمرر للأعلى سطرًا واحدًا في الجزء الذي تم التركيز عليه.
  • ScrollDown - يمرر للأسفل سطرًا واحدًا في الجزء الذي تم التركيز عليه.
  • PageScrollUp - يمرر للأعلى صفحة واحدة في الجزء الذي تم التركيز عليه.
  • PageScrollDown - يمرر للأسفل صفحة واحدة في الجزء الذي تم التركيز عليه.
  • ToggleFocusFullscreen - يبدل بين الجزء الذي تم التركيز عليه بملء الشاشة والتخطيط العادي.
  • NewPane: <Direction> - يفتح جزءًا جديدًا في الاتجاه المحدد (Left, Right, Up, Down) بالنسبة للتركيز.
  • CloseFocus - يغلق الجزء الذي تم التركيز عليه.
  • NewTab - ينشئ علامة تبويب جديدة.
  • GoToNextTab - ينتقل إلى علامة التبويب التالية.
  • GoToPreviousTab - ينتقل إلى علامة التبويب السابقة.
  • CloseTab - يغلق علامة التبويب الحالية.
  • GoToTab: <Index> - ينتقل إلى علامة التبويب ذات رقم الفهرس المحدد.
  • Detach - يفصل الجلسة ويخرج.
  • ToggleActiveSyncTab - يبدل بين إرسال أوامر نصية إلى جميع الأجزاء في علامة التبويب الحالية والوضع العادي.
  • UndoRenameTab - يتراجع عن تغيير اسم علامة التبويب ويعيد الاسم السابق.
  • UndoRenamePane - يتراجع عن تغيير اسم الجزء ويعيد الاسم السابق.

المفاتيح

  • Char: <character> - حرف واحد بدون مفتاح تعديل.
  • Alt: <character> - حرف واحد مع مفتاح `Alt` كمفتاح تعديل.
  • Ctrl: <character> - حرف واحد مع مفتاح `Ctrl` كمفتاح تعديل.
  • F: <1-12> - أحد مفاتيح `F` (عادة في أعلى لوحة المفاتيح).
  • Backspace
  • Left / Right / Up / Down - مفاتيح الأسهم على لوحة المفاتيح.
  • Home
  • End
  • PageUp / PageDown
  • BackTab - مفتاح Tab للخلف.
  • Delete
  • Insert
  • Esc

الأوضاع

  • normal - وضع البدء الافتراضي لـ Zellij. يوفر القدرة على التبديل إلى أوضاع مختلفة، بالإضافة إلى بعض اختصارات التنقل السريعة.
  • locked - يعطل جميع اختصارات لوحة المفاتيح باستثناء الاختصار الذي سيحول الوضع إلى وضع عادي (ctrl-g افتراضيًا). مفيد عندما تتعارض اختصارات لوحة المفاتيح لـ Zellij مع تلك المستخدمة في التطبيقات التي تعمل داخل الأجزاء.
  • pane - وضع الجزء. يسمح بالتحكم في الجزء الذي تم التركيز عليه، مثل التحجيم، والتمرير، وتغيير حجم الأجزاء.
  • tab - وضع علامة التبويب. يسمح بالتحكم في علامات التبويب، مثل إنشاء علامات تبويب جديدة، والتبديل بينها، وإغلاقها.
  • scroll - وضع التمرير. يتيح لك التمرير في مخزن الإخراج لجزء ما.
  • session - وضع الجلسة. يسمح بالتحكم في الجلسة بأكملها، مثل فصلها أو إغلاقها.

الإضافات

تمثل إضافات Zellij مكونات واجهة مستخدم قابلة للتخصيص يتم تحميلها في مساحة في تخطيط Zellij. يتم تطوير الإضافات عن طريق كتابة شفرة في أي لغة يتم تجميعها إلى WebAssembly.

توجد الإضافات في:

  • ملفات التكوين، تحت مفتاح plugins.

  • مواقع إضافات النظام.

لكل إضافة، يمكنك تحديد:

  • location: - مسار إلى ملف `.wasm` الخاص بالإضافة.

  • path: - مسار إلى شفرة الإضافة الأساسية. إذا تم توفير هذا، فسيقوم Zellij تلقائيًا بإنشاء `path` إذا لم يتم العثور عليه. هذه مفيدة لتوفير الإضافات الشائعة.

  • run: - تحدد كيف سيتم تشغيل الإضافة. يمكن أن تكون إما `native` (تُستخدم للإضافات التي لا تستخدم واجهة Zellij) أو `plugin` (تُستخدم للإضافات التي تتواصل مع Zellij).

  • name: - اسم فريد للإضافة.

  • arguments: - مجموعة من الوسائط التي سيتم تمريرها إلى الإضافة عند إنشائها.

مثال لتحديد إضافة:

plugins:
    internal:
        - path: ~/.config/zellij/plugins/my_plugin.wasm
          run: plugin

للتحقق من وجود الإضافات، قم بتشغيل:

zellij setup --check --debug

zellij(1) — zellij documentation

NAME

zellij

a terminal multiplexer written in Rust

DESCRIPTION

Zellij is a terminal multiplexer that aims to be easy to use and highly extensible. It allows users to create, manage, and switch between multiple terminal sessions within a single window.

OPTIONS

The zellij command accepts the following options:

-s, --session [session-name]
Start a new session with the optional name.
-f, --config FILE
Load configuration from FILE.
-l, --layout FILE
Load layout from FILE.
-t, --theme NAME
Load theme NAME.
-h, --help
Print help information and exit.
-V, --version
Print version information and exit.

CONFIGURATION

Zellij can be configured via a configuration file. The default location for the configuration file is `$XDG_CONFIG_HOME/zellij/config.kdl`. If this file does not exist, Zellij will use its default configuration.

The configuration file allows users to customize various aspects of Zellij, including keybindings, plugins, and themes.

LAYOUTS

Layouts define the arrangement of panes and tabs within a Zellij session. Layouts can be defined in separate files and loaded using the `--layout` option or included in the main configuration file.

A layout file is written in KDL format and can define multiple panes and tabs, their sizes, and the programs to run within them.

KEYBINDINGS

Zellij provides a powerful keybinding system that allows users to control the multiplexer and its features. Keybindings can be customized in the configuration file.

The following modes and actions are available:

  • normal - The default mode, used for general navigation and commands.
  • locked - A mode that locks the pane, preventing accidental input.
  • pane - Includes instructions that manipulate the panes (adding new panes, moving, closing).
  • tab - Includes instructions that manipulate the tabs (adding new tabs, moving, closing).
  • resize - Allows resizing of the focused pane.
  • scroll - Allows scrolling within the focused pane.
  • renametab - is a "hidden" mode that can be passed to SwitchToMode action. It will trigger renaming of a tab.
  • renamepane - is a "hidden" mode that can be passed to SwitchToMode action. It will trigger renaming of a pane.
  • session - allows detaching from a session.

Theme

A color theme can be defined either in truecolor, 256 or hex color format. Truecolor:

fg: [0, 0, 0]

256:

fg: 0

Hex color:

fg: "#000000"
bg: "#000"

The color theme can be specified in the following way:

themes:
  default:
    fg: [0,0,0]
    bg: [0,0,0]
    black: [0,0,0]
    red: [0,0,0]
    green: [0,0,0]
    yellow: [0,0,0]
    blue: [0,0,0]
    magenta: [0,0,0]
    cyan: [0,0,0]
    white: [0,0,0]
    orange: [0,0,0]

If the theme is called `default`, then zellij will pick it on startup. To specify a different theme, run zellij with:

zellij options --theme [NAME]

or put the name in the configuration file with `theme: [NAME]`.

PLUGINS

Zellij has a plugin system based on WebAssembly. Any language that can run on WASI can be used to develop a plugin. To load a plugin include it in a layout file. Zellij comes with default plugins included: status-bar, strider, tab-bar.

FILES

Default user configuration directory location:

  • Linux: $XDG_HOME/zellij /home/alice/.config/zellij
  • macOS: /Users/Alice/Library/Application Support/com.Zellij-Contributors.zellij

Default user layout directory location:

  • Subdirectory called `layouts` inside of the configuration directory.
  • Linux: _$XDG_HOME/zellij/layouts /home/alice/.config/zellij/layouts
  • macOS: /Users/Alice/Library/Application/layouts Support/com.Zellij-Contributors.zellij/layouts

Default plugin directory location:

•
Linux: _$XDG_DATA_HOME/zellij/plugins /home/alice/.local/share/plugins

ENVIRONMENT

ZELLIJ_CONFIG_FILE Path of Zellij config to load. ZELLIJ_CONFIG_DIR Path of the Zellij config directory.
