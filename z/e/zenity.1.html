NAME

zenity — display GTK+ dialogs in shell scripts

DESCRIPTION

Zenity is a program that allows you to display GTK+ dialogs (like file choosers, progress bars, input boxes, etc.) in shell scripts. This program is part of the GNOME desktop environment.

Zenity is useful for creating simple graphical front-ends for command-line utilities, without needing to write a full graphical application.

For a complete list of available dialogs and their options, refer to the man page for zenity(1).

EXAMPLES

Here are a few examples of how to use Zenity:

Displaying an information dialog:

zenity --info --text="This is an informational message."

Asking for user input:

zenity --entry --text="Please enter your name:"

Displaying a file selection dialog:

zenity --file-selection

Displaying a progress bar:

# Simulate a long-running process
total=100
for i in $(seq 1 $total); do
    sleep 0.1
    zenity --progress --text="Processing item $i of $total..." --value=$i
done
