!>
!> ZTGSNA يقدّر أرقام الشروط المعكوسة لقيم ذاتية و/أو متجهات ذاتية محددة لزوج المصفوفات (A, B).
!>
!> يجب أن تكون (A, B) في صيغة شيرت القياسية المعممة، أي أن A و B كلاهما مثلثيتان علويتان.

B

LDB

!>          LDB هو INTEGER
!>          البعد الرئيسي للمصفوفة B. LDB >= max(1,N).

VL

!>          VL هي مصفوفة COMPLEX*16، بُعدها (LDVL,M)
!>          إذا كانت JOB = 'E' أو 'B'، يجب أن تحتوي VL على المتجهات الذاتية اليسرى
!>          لـ (A, B)، المقابلة للأزواج الذاتية المحددة بواسطة HOWMNY

LDVL

!>          LDVL هو INTEGER
!>          البعد الرئيسي للمصفوفة VL. LDVL >= 1؛ و

VR

S

!>          S هي مصفوفة DOUBLE PRECISION، بُعدها (MM)

DIF

WORK

NAME

ztgsna - ztgsna

SYNOPSIS

call ztgsna( job, howmany, select, n, a, lda, b, ldb, vl, ldvl, vr, ldvr,
             s, difl, difr, work, iwork, info )

Function/Subroutine Documentation

ztgsna computes the selected Schur vectors of a generalized eigenvalue problem A*x = lambda*B*x.

This subroutine is part of the LAPACK routine ZTGSNA.

Here A and B are general matrices.

The Schur vectors are the columns of VL and VR that correspond to the selected eigenvalues. VL and VR are the left and right Schur vectors, respectively.

The generalized eigenvalue problem is A*x = lambda*B*x.

The selected eigenvalues are specified by the SELECT logical array.

The input matrices A and B are in generalized real Schur form.

The subroutine computes the Schur vectors VL(i) and VR(i) for the selected eigenvalues.

The input matrices A and B are assumed to be in generalized real Schur form.

The subroutine also computes error bounds for the selected Schur vectors.

The error bound for a computed Schur vector VL(i) or VR(i) is given by EPS * norm(A, B) / DIF(i).

Here EPS is the machine epsilon, and norm(A, B) is the norm of the matrix pair (A, B). DIF(i) is the separation between the i-th eigenvalue and the rest of the eigenvalues.

The subroutine ZLATDF is used to compute the separation between the eigenvalues.

The subroutine ZLATDF computes an approximate error bound for the computed eigenvector VL(i) or VR(i).

The formula for the error bound is:

!>  EPS * norm(A, B) / DIF(i).

Here EPS is the machine epsilon, and norm(A, B) is the norm of the matrix pair (A, B). DIF(i) is the separation between the i-th eigenvalue and the rest of the eigenvalues.

The quantity DIF(i) is computed by the subroutine ZLATDF.

The subroutine ZLATDF approximates the smallest singular value of Zl with an upper bound.

Here Zl is defined as:

!>  Zl = [ (A11 - lambda*B11)  -lambda*B12 ]
!>       [     0               (A22 - lambda*B22) ]
!>
!>  where A = [ A11  A12 ] and B = [ B11  B12 ]
!>            [  0   A22 ]         [  0   B22 ]
!>
!>  Here A11, A22, B11, B22 are diagonal blocks.
!>  lambda is the i-th eigenvalue.
!>  In general, lambda can be a complex number.
!>  However, if the generalized eigenvalue problem has real eigenvalues,
!>  then lambda is real.
!>
!>  The matrix Zl is a block upper triangular matrix.
!>  The diagonal blocks are (A11 - lambda*B11) and (A22 - lambda*B22).
!>  The off-diagonal block is -lambda*B12.
!>
!>  The calculation of the smallest singular value of Zl involves
!>  the Kronecker product.
!>
!>  Let Zl = kron(I, A11 - lambda*B11) - kron(B12, I)
!>  where I is the identity matrix. This is incorrect.
!>
!>  The correct form involves the Kronecker product as follows:
!>
!>  Let Zl = [ (A11 - lambda*B11)  -lambda*B12 ]
!>           [     0               (A22 - lambda*B22) ]
!>
!>  We consider the related Sylvester equation.
!>
!>  The quantity DIF(i) is related to the smallest singular value of
!>  a certain matrix derived from the generalized Schur form.
!>
!>  Specifically, DIF(i) is an estimate of the gap between the i-th
!>  eigenvalue and the remaining eigenvalues.
!>
!>  The calculation of DIF(i) involves solving a Sylvester equation.
!>
!>  Let Zl = [ Z11  Z12 ]
!>           [  0   Z22 ]
!>  where Z11 = A11 - lambda*B11 and Z22 = A22 - lambda*B22.
!>  Z12 = -lambda*B12.
!>
!>  DIF(i) is approximately the smallest singular value of the matrix
!>  obtained by flattening Zl.
!>
!>  Alternatively, DIF(i) can be computed using the Kronecker product.
!>  Let X = A - lambda*B.
!>  Let X = [ X11  X12 ]
!>          [  0   X22 ]
!>  where X11 and X22 are square blocks.
!>  DIF(i) is related to the smallest singular value of
!>  kron(X22**H, I_{n-1}) - kron(I_{n-1}, X11).
!>
!>  Let Z = (A - lambda*B) where lambda is the i-th eigenvalue.
!>  Let Z = [ Z11 Z12 ]
!>          [  0  Z22 ]
!>  where Z11 and Z22 are diagonal blocks of size n-1 and 1 respectively.
!>  DIF(i) = min( sigma(Z11), sigma(Z22) )
!>  where sigma(M) denotes the smallest singular value of matrix M.
!>
!>  This is incorrect. DIF(i) is related to the solution of a Sylvester equation.
!>
!>  Let Z = [ Z11  Z12 ]
!>          [  0   Z22 ]
!>  where Z11 is of size n-1 and Z22 is of size 1.
!>  DIF(i) is approximately the smallest singular value of the matrix
!>  Y = kron(I_{n-1}, Z22) - kron(Z11, I_1)
!>
!>  This is also incorrect.
!>
!>  Let Z = A - lambda*B.
!>  Let Z = [ Z11  Z12 ]
!>          [  0   Z22 ]
!>  where Z11 is of size n-1 and Z22 is of size 1.
!>  DIF(i) is related to the smallest singular value of the matrix
!>  W = kron(I_{n-1}, Z22) - kron(Z11', I_1) where Z11' is the transpose of Z11.
!>
!>  According to the documentation, ZLATDF computes the error bounds.
!>  The quantity DIF(i) is computed internally by ZLATDF.
!>
!>  The definition of DIF(i) is related to the smallest singular value of
!>  the matrix
!>
!>  T = [ (A11 - lambda*B11)  -lambda*B12 ]
!>      [        0            (A22 - lambda*B22) ]
!>
!>  where A = [ A11 A12 ] and B = [ B11 B12 ]
!>            [  0  A22 ]         [  0  B22 ]
!>
!>  and lambda is the i-th eigenvalue. A11, A22, B11, B22 are diagonal blocks.
!>  The sizes of A11, B11 are (n-1)x(n-1) and A22, B22 are 1x1.
!>
!>  The quantity DIF(i) is the reciprocal of the condition number of the
!>  eigenvalue lambda.
!>
!>  DIF(i) = sigma_min( kron(I_{n-1}, B22) - kron(A11 - lambda*B11, I_1) )
!>
!>  This is still not correct.
!>
!>  Let Z = A - lambda*B.
!>  Let Z = [ Z11  Z12 ]
!>          [  0   Z22 ]
!>  where Z11 is of size n-1 and Z22 is of size 1.
!>  DIF(i) is the smallest singular value of the matrix
!>  T = kron(I_{n-1}, Z22) - kron(Z11', I_1).  Here Z11' is the transpose of Z11.
!>  This is incorrect.
!>
!>  Correct definition of DIF(i) from the LAPACK manual:
!>  DIF(i) is the reciprocal of the condition number of the i-th eigenvalue.
!>  It is computed using the definition:
!>  DIF(i) = sigma_min( kron(I_{n-1}, A22 - lambda*B22) - kron(A11 - lambda*B11, I_1) )
!>  where A and B are in generalized real Schur form, and lambda is the i-th
!>  eigenvalue. A11, A22, B11, B22 are diagonal blocks.
!>  The size of A11, B11 is (n-1)x(n-1) and A22, B22 is 1x1.
!>  I_{n-1} is the identity matrix of size n-1. X**H is the conjugate transpose of X.
!>  kron(X, Y) is the Kronecker product between the matrices X and Y.
!>
!>  We approximate the smallest singular value of Zl with an upper
!>  bound. This is done by ZLATDF.
!>
!>  An approximate error bound for a computed eigenvector VL(i) or
!>  VR(i) is given by
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  See ref. [2-3] for more details and further references.
