NAME

ztgsy2 - ZTGSY2 computes the solution to the generalized Sylvester equation.

Function/Subroutine Documentation

ZTGSY2 solves the generalized Sylvester equation:

A*X + X*B = C

A*X - D*X*B = C

A*X*E - D*X*B*F = C

A*X*E - D*X*B = C

with Z*, Z*B = C, Z*E - Z*B*F = C, or Z*E - Z*B = C, respectively, where

A, B, C, D, E, F, G, H are complex matrices. X is the unknown complex matrix, and

A, B, D, E are upper triangular matrices, and F, G, H are upper quasi-triangular matrices.

The matrices C, D, E, F, G, H are partitioned such that

C = [ C11 C12 ]

[ 0 C22 ]

D = [ D11 0 ]

[ D21 D22 ]

E = [ E11 0 ]

[ E21 E22 ]

F = [ F11 0 ]

[ F21 F22 ]

G = [ G11 G12 ]

[ 0 G22 ]

H = [ H11 H12 ]

[ 0 H22 ]

and X, C, D, E, F, G, H are block matrices of size (M,N).

The function is part of the LAPACK library.
