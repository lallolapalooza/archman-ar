الغرض:

!>
!> ZTGSNA يقدر أرقام شروط الاستقبال للقيم الذاتية والمتجهات الذاتية المحددة
!> لزوج المصفوفات (A, B).
!>
!> يجب أن يكون (A, B) في صيغة Schur المعيارية المعممة، أي أن A و
!> B كلاهما مثلثان علويتان.
!>

المعلمات

JOB 
!>          JOB is CHARACTER*1
!>          يحدد ما إذا كانت أرقام الشروط مطلوبة للقيم الذاتية (S)
!>          أو المتجهات الذاتية (DIF):
!>          = 'E': للقيم الذاتية فقط (S);
!>          = 'V': للمتجهات الذاتية فقط (DIF);
!>          = 'B': لكل من القيم الذاتية والمتجهات الذاتية (S و DIF).
!>

HOWMNY

!>          = 'A': حساب أرقام الشروط لجميع الأزواج الذاتية؛

!>          البعد الرئيسي للمصفوفة A. LDA >= max(1,N).

B

!>          المصفوفة المثلثة العلوية B في الزوج (A, B).

!>          البعد الرئيسي للمصفوفة B. LDB >= max(1,N).
!>

VL

!>          VL is COMPLEX*16 array, dimension (LDVL,M)
!>          إذا كان JOB = 'E' أو 'B'، يجب أن تحتوي VL على المتجهات الذاتية اليسرى
!>          لـ (A, B)، المطابقة للأزواج الذاتية المحددة بواسطة HOWMNY
!>          و SELECT. يجب تخزين المتجهات الذاتية في أعمدة متجاورة

LDVL

!>          LDVL is INTEGER
!>          البعد الرئيسي للمصفوفة VL. LDVL >= 1؛ و

VR

!>          VR is COMPLEX*16 array, dimension (LDVR,M)

!>          إذا كان JOB = 'V'، فلا يتم الرجوع إلى VR.
!>

LDVR

!>          LDVR is INTEGER
!>          البعد الرئيسي للمصفوفة VR. LDVR >= 1؛
!>          إذا كان JOB = 'E' أو 'B'، فإن LDVR >= N.

S

!>          S is DOUBLE PRECISION array, dimension (MM)

!>          إذا كان JOB = 'V'، فلا يتم الرجوع إلى S.
!>

DIF

!>          DIF is DOUBLE PRECISION array, dimension (MM)
!>          إذا كان JOB = 'V' أو 'B'، فإن تقديرات أرقام شروط الاستقبال
!>          للمتجهات الذاتية المحددة، مخزنة في عناصر متجاورة
!>          من المصفوفة.

!>          تقديرًا لمعيار فروبينيوس لـ Difl.
!>          إذا كان JOB = 'E'، فلا يتم الرجوع إلى DIF.

MM

!>          MM is INTEGER
!>          عدد العناصر في المصفوفتين S و DIF. MM >= M.

M

!>          M is INTEGER

WORK

LWORK

!>          LWORK is INTEGER

!>          إذا كان JOB = 'V' أو 'B'، فإن LWORK >= max(1,2*N*N).

IWORK

!>          IWORK is INTEGER array, dimension (N+2)
!>          إذا كان JOB = 'E'، فلا يتم الرجوع إلى IWORK.

INFO

!>          INFO is INTEGER
!>          = 0: خروج ناجح

Function/Subroutine Documentation

!>
!>  Purpose
!>  =======
!>
!>  ZTGSNA applies to the generalized real Schur decomposition of a pair
!>  (A, B). It computes the norm-based condition numbers for the
!>  eigenvalues and/or eigenvectors in the generalized Schur
!>  decomposition.
!>
!>  Arguments
!>  =========
!>
!>  JOB     (input) character*1
!>          Specifies whether condition numbers are to be computed for the
!>          left and/or right eigenvectors.
!>          = 'E': Computes condition numbers for the right eigenvectors only.
!>          = 'V': Computes condition numbers for the left eigenvectors only.
!>          = 'B': Computes condition numbers for both left and right
!>                 eigenvectors.
!>
!>  HOWMANY (input) character*1
!>          Specifies whether condition numbers are to be computed for all
!>          eigenvalues/eigenvectors (in which case the eigenvalues/vectors
!>          previously selected by ZTGSNA are ignored) or only for the
!>          eigenvalues/eigenvectors corresponding to the submatrix selected
!>          by the column partitioning of the generalized Schur decomposition.
!>          = 'A': Computes condition numbers for all eigenvalues/vectors.
!>          = 'S': Computes condition numbers for the selected eigenvalues
!>                 and eigenvectors.
!>
!>  SELECT  (input) logical array, dimension (N)
!>          If HOWMANY = 'S', SELECT indicates which eigenvalues/eigenvectors
!>          are to be selected. For example, if SELECT(j) is true, then the
!>          j-th eigenvalue/eigenvector (j-th column of VL and VR) will be
!>          selected.
!>          If HOWMANY = 'A', SELECT is ignored.
!>
!>  N       (input) integer
!>          The order of the matrices A and B. N >= 0.
!>
!>  A       (input) complex*16 array, dimension (LDA, N)
!>          On entry, the upper quasi-triangular matrix A in the generalized
!>          Schur decomposition.
!>
!>  LDA     (input) integer
!>          The leading dimension of the array A. LDA >= max(1, N).
!>
!>  B       (input) complex*16 array, dimension (LDB, N)
!>          On entry, the upper triangular matrix B in the generalized
!>          Schur decomposition. B must be upper triangular.
!>
!>  LDB     (input) integer
!>          The leading dimension of the array B. LDB >= max(1, N).
!>
!>  VL      (input/output) complex*16 array, dimension (LDVL, N)
!>          On entry, if JOB = 'V' or 'B', VL contains the left eigenvectors
!>          in the columns VL(i,j).
!>          On exit, if JOB = 'V' or 'B', VL contains the normalized left
!>          eigenvectors, and the condition numbers for the left
!>          eigenvectors are returned in the array S.
!>
!>  LDVL    (input) integer
!>          The leading dimension of the array VL. LDVL >= max(1, N).
!>
!>  VR      (input/output) complex*16 array, dimension (LDVR, N)
!>          On entry, if JOB = 'E' or 'B', VR contains the right eigenvectors
!>          in the columns VR(i,j).
!>          On exit, if JOB = 'E' or 'B', VR contains the normalized right
!>          eigenvectors, and the condition numbers for the right
!>          eigenvectors are returned in the array S.
!>
!>  LDVR    (input) integer
!>          The leading dimension of the array VR. LDVR >= max(1, N).
!>
!>  LWORK   (input) integer
!>          The dimension of the array WORK. LWORK >= max(1, 2*N).
!>          For optimal efficiency, LWORK >= max(1, 2*N, N*max(ln(N, 1), 4)).
!>          (This is an empirical suggestion.)
!>
!>  WORK    (workspace) complex*16 array, dimension (LWORK)
!>
!>  IWORK   (workspace) integer array, dimension (N)
!>
!>  INFO    (output) integer
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value.
!>          > 0: if INFO = i, the i-th eigenvalue/eigenvector could not be
!>               processed.
!>
!>  Details
!>  =======
!>
!>  The condition number for the j-th left eigenvector vL(j) is computed as
!>  the reciprocal of the smallest singular value of the (N-1)-by-(N-1)
!>  matrix Zl = In-1 - kron(vL(j)**H, vR(j)**T) * B(j,j), where vR(j) is the
!>  j-th right eigenvector.
!>
!>  The condition number for the j-th right eigenvector vR(j) is computed as
!>  the reciprocal of the smallest singular value of the (N-1)-by-(N-1)
!>  matrix Zr = In-1 - kron(vL(j)**H, vR(j)**T) * A(j,j).
!>
!>  The smallest singular value of Zl or Zr is approximated by the
!>  smallest singular value of the matrix W = D - diag(B(j,j), A(j,j)),
!>  where D is a diagonal matrix with entries D(i,i) = 1 for i = 1..N-1.
!>  This is done by ZLATDF.
!>
!>  An approximate error bound for a computed eigenvector VL(i) or
!>  VR(i) is given by
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  See ref. [2-3] for more details and further references.
!>

!>          عند الدخول، إذا كان JOB = 'E' أو 'B'، تحتوي VR على المتجهات
!>          الذاتية اليمنى في الأعمدة VR(i,j).
!>          عند الخروج، إذا كان JOB = 'E' أو 'B'، تحتوي VR على المتجهات
!>          الذاتية اليمنى المعيارية، ويتم إرجاع أرقام الشرط للمتجهات
!>          الذاتية اليمنى في المصفوفة S.
!>
!>  LDVR    (إدخال) integer
!>          البعد الرائد للمصفوفة VR. LDVR >= max(1, N).
!>
!>  LWORK   (إدخال) integer
!>          حجم المصفوفة WORK. LWORK >= max(1, 2*N).
!>          للحصول على أقصى كفاءة، LWORK >= max(1, 2*N, N*max(ln(N, 1), 4)).
!>          (هذا اقتراح تجريبي.)
!>
!>  WORK    (مساحة عمل) مصفوفة complex*16، حجم (LWORK)
!>
!>  IWORK   (مساحة عمل) مصفوفة integer، حجم (N)
!>
!>  INFO    (إخراج) integer
!>          = 0: انتهاء ناجح
!>          < 0: إذا كان INFO = -i، فإن المعلمة i-th كانت لها قيمة غير قانونية.
!>          > 0: إذا كان INFO = i، لم يتمكن من معالجة القيمة الذاتية/المتجه الذاتي i-th.
!>
!>  تفاصيل
!>  =======
!>
!>  يتم حساب رقم شرط المتجه الذاتي الأيسر j-th vL(j) على أنه مقلوب
!>  أصغر قيمة مفردة للمصفوفة (N-1)-by-(N-1) Zl = In-1 - kron(vL(j)**H, vR(j)**T) * B(j,j)،
!>  حيث vR(j) هو المتجه الذاتي الأيمن j-th.
!>
!>  يتم حساب رقم شرط المتجه الذاتي الأيمن j-th vR(j) على أنه مقلوب
!>  أصغر قيمة مفردة للمصفوفة (N-1)-by-(N-1) Zr = In-1 - kron(vL(j)**H, vR(j)**T) * A(j,j).
!>
!>  يتم تقريب أصغر قيمة مفردة لـ Zl أو Zr بواسطة أصغر قيمة مفردة للمصفوفة
!>  W = D - diag(B(j,j), A(j,j))، حيث D هي مصفوفة قطرية مدخلاتها
!>  D(i,i) = 1 لـ i = 1..N-1. يتم ذلك بواسطة ZLATDF.
!>
!>  يتم إعطاء حد خطأ تقريبي للمتجه الذاتي المحسوب VL(i) أو VR(i) بواسطة
!>
!>                      EPS * norm(A, B) / DIF(i).
!>
!>  انظر المراجع [2-3] لمزيد من التفاصيل والمراجع الإضافية.
!>
