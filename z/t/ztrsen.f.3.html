NAME

ztrsen.f - ztrsen computes the Schur factorization of a general rectangular matrix and updates the Schur factorization of a general rectangular matrix.

SYNOPSIS

SUBROUTINE ZTRSEN(
    JOB, SELECT, C, LD C, WR, WI, P, Q, TL, LD TL, TR, LD TR,
    WORK, INFO )
CHARACTER * 1 JOB
LOGICAL FUNCTION SELECT( X )
COMPLEX*16 C( * ), TL( * ), TR( * ), WORK( * )
INTEGER LD C, LD TL, LD TR, P, Q, INFO
DOUBLE PRECISION WI( * )

Function/Subroutine Documentation

ZTRSEN computes the Schur factorization of a general rectangular matrix and updates the Schur factorization of a general rectangular matrix.

This subroutine is part of the LAPACK routines that deal with Schur factorization.

Parameters
JOB
CHARACTER*1. Must be 'N' or 'S'.
  • If JOB = 'N', then the Schur factorization is not updated.
  • If JOB = 'S', then the Schur factorization is updated.
SELECT
LOGICAL FUNCTION of one argument.

SELECT is used to select eigenvalues to be moved to the top-left corner of the Schur matrix. For a given eigenvalue X, SELECT(X) must return .TRUE. if the eigenvalue is to be selected, and .FALSE. otherwise.

C
COMPLEX*16 array, dimension (LD C, N). The N-by-N upper quasi-triangular matrix C.
LD C
INTEGER. The leading dimension of the array C. LD C >= max(1, N).
WR
DOUBLE PRECISION array, dimension (N). The real parts of the eigenvalues of C.
WI
DOUBLE PRECISION array, dimension (N). The imaginary parts of the eigenvalues of C.
P
INTEGER. The number of eigenvalues selected by SELECT.
Q
INTEGER. The number of eigenvalues which are not selected by SELECT.
TL
COMPLEX*16 array, dimension (LD TL, N). The upper triangular matrix TL.
LD TL
INTEGER. The leading dimension of the array TL. LD TL >= max(1, N).
TR
COMPLEX*16 array, dimension (LD TR, N). The upper triangular matrix TR.
LD TR
INTEGER. The leading dimension of the array TR. LD TR >= max(1, N).
WORK
COMPLEX*16 array, dimension (N).
INFO
INTEGER.
  • = 0: Successfull exit.
  • > 0: If INFO = i, then the loop is entered at the i-th iteration after which the update could not be performed.
  • < 0: If INFO = -i, then the i-th argument had an illegal value.

WARNING

This routine is deprecated and may be removed in a future release. For updating the Schur factorization of a general rectangular matrix, use the routines from LAPACK 3.1+.

The computed separation between the computed right invariant subspace
and the computed left invariant subspace is
!>
!>                      EPS * norm(T) / SEP
!>
