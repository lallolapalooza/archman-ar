zabbix_server(8)

الحزمة: zabbix-server

التراخيص: GPL-2.0-only

ZABBIX_SERVER(8) دليل مدير النظام ZABBIX_SERVER(8)

الاسم

zabbix_server - خادم Zabbix

الملخص

zabbix_server [-c ملف-التكوين]
zabbix_server [-c ملف-التكوين] -R خيار-وقت-التشغيل
zabbix_server [-c ملف-التكوين] -T
zabbix_server -h
zabbix_server -V

الوصف

zabbix_server هو خادم Zabbix الأساسي.

خيارات

-c, --config ملف-التكوين
استخدام ملف-التكوين البديل بدلاً من الملف الافتراضي.
-f, --foreground
تشغيل خادم Zabbix في المقدمة.
-R, --runtime-control خيار-وقت-التشغيل
تنفيذ وظائف إدارية وفقًا لـ خيار-وقت-التشغيل.
خيارات التحكم في وقت التشغيل
config_cache_reload
إعادة تحميل ذاكرة التخزين المؤقت للتكوين. يتم تجاهلها إذا كانت الذاكرة المؤقتة قيد التحميل حاليًا. سيتم استخدام ملف التكوين الافتراضي (ما لم يتم تحديد خيار -c) للعثور على ملف PID وسيتم إرسال إشارة إلى العملية المدرجة في ملف PID.
snmp_cache_reload
إعادة تحميل ذاكرة التخزين المؤقت لـ SNMP.
housekeeper_execute
تنفيذ الـ housekeeper. يتم تجاهلها إذا كان الـ housekeeper قيد التنفيذ حاليًا.
trigger_housekeeper_execute
تنفيذ الـ housekeeper للمشغلات (إزالة المشكلات للمشغلات المحذوفة). يتم تجاهلها إذا كان الـ housekeeper للمشغلات قيد التنفيذ حاليًا.
secrets_reload
إعادة تحميل الأسرار من Vault. يتم تجاهلها إذا كانت ذاكرة التخزين المؤقت للتكوين أو الأسرار قيد التحميل حاليًا.
diaginfo[=قسم]
تسجيل معلومات التشخيص الداخلية للقسم المحدد. يمكن أن يكون القسم historycache، preprocessing، alerting، lld، valuecache، locks. بشكل افتراضي، يتم تسجيل معلومات التشخيص لجميع الأقسام.
prof_enable[=هدف]
تمكين التنميط، يؤثر على جميع العمليات إذا لم يتم تحديد الهدف.
prof_disable[=هدف]
تعطيل التنميط، يؤثر على جميع العمليات إذا لم يتم تحديد الهدف.
ha_status
عرض حالة مجموعة التوافر العالي (high availability). يمكن تنفيذه فقط على العقدة النشطة.
ha_remove_node
ha_remove_node[=اسم|معرف] إزالة عقدة توافر عالي بالاسم أو المعرف المدرج في ha_status. يمكن تنفيذه فقط على العقدة النشطة.
ha_set_failover_delay[=تأخير]
تعيين تأخير تجاوز الفشل في التوافر العالي. يمكن تحديد التأخير باستخدام لاحقات الوقت. يمكن تنفيذه فقط على العقدة النشطة.
log_level_increase[=هدف]
زيادة مستوى السجل، يؤثر على جميع العمليات إذا لم يتم تحديد الهدف.
log_level_decrease[=هدف]
تقليل مستوى السجل، يؤثر على جميع العمليات إذا لم يتم تحديد الهدف.
أهداف التحكم في مستوى السجل
نوع-العملية
جميع عمليات النوع المحدد (alerter، alert manager، availability manager، browser poller، configuration syncer، configuration syncer worker، connector manager، connector worker، discovery manager، escalator، ha manager، history poller، history syncer، housekeeper، http poller، icmp pinger، internal poller، ipmi manager، ipmi poller، java poller، odbc poller، poller، agent poller، http agent poller، snmp poller، preprocessing manager، proxy group manager، proxy poller، self-monitoring، service manager، snmp trapper، task manager، timer، trapper، unreachable poller، vmware collector)
نوع-العملية,N
نوع العملية ورقمها (مثل: poller,3)
معرف-العملية
معرف العملية
أهداف التحكم في التنميط
نوع-العملية
جميع عمليات النوع المحدد (alerter، alert manager، availability manager، configuration syncer، connector manager، connector worker، discovery manager، escalator، ha manager، history poller، history syncer، housekeeper، http poller، icmp pinger، internal poller، ipmi manager، ipmi poller، java poller، odbc poller، poller، agent poller، http agent poller، snmp poller، preprocessing manager، proxy group manager، proxy poller، self-monitoring، service manager، snmp trapper، task manager، timer، trapper، unreachable poller، vmware collector)
نوع-العملية,N
نوع العملية ورقمها (مثل: history syncer,1)
معرف-العملية
معرف العملية
نطاق
(rwlock، mutex، processing) يمكن استخدامه مع نوع العملية (مثل: history syncer,1,processing)
-T, --test-config
التحقق من صحة ملف التكوين والخروج.
-h, --help
عرض هذه المساعدة والخروج.
-V, --version
عرض معلومات الإصدار والخروج.

الملفات

/usr/local/etc/zabbix_server.conf
الموقع الافتراضي لملف تكوين خادم Zabbix (إذا لم يتم تعديله أثناء وقت الترجمة).
