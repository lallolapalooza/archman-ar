NAME

zgesvxx

ZGESVXX - solves a system of complex linear equations AX = B with a general MxN matrix A, and provides a detailed error analysis.

SYNOPSIS

    SUBROUTINE ZGESVXX(
           BIAS, FACT, EQUIL, TRANS, EQUED, M, N, NB,
           A, LDA, AF, LDAF, IPIV, CND, RCOND,
           B, LDB, X, LDX, WORK, RWORK, SRWORK,
           INFO, PARAMS )
    CHARACTER(LEN=1)      :: BIAS, FACT, EQUIL, TRANS, EQUED
    INTEGER               :: M, N, NB, LDA, LDAF, LDB, LDX, INFO
    INTEGER               :: IPIV( * )
    DOUBLE PRECISION      :: CND( * ), RCOND
    COMPLEX*16            :: A( * ), AF( * ), B( * ), X( * )
    COMPLEX*16            :: WORK( * )
    DOUBLE PRECISION      :: RWORK( * )
    DOUBLE PRECISION      :: SRWORK( * )
    INTEGER               :: PARAMS( * )

Function/Subroutine Documentation

ZGESVXX computes the solution to a complex system of linear equations AX = B, such as

      A * X = B

where A is an M-by-N matrix and X and B are M-by-NRHS matrices. Error bounds on the solution are computed, and high-accuracy computed solutions are optionally obtained.

A forward elimination and backward substitution pass is performed to solve the system of linear equations. The LU factorization with partial pivoting is used to factor the matrix A as

      A = P * L * U,

where P is a permutation matrix, L is unit triangular, and U is upper triangular. The solution is computed by solving P * L * Y = B and then U * X = Y.

An estimate on the condition number of the matrix A is computed and used to estimate the error in the computed solution.

If the routine is requested to compute a high-accuracy solution, an iterative refinement procedure is used to reduce the norm of the residual || B - A*X ||1.

Parameters

BIAS (input)

      BIAS is CHARACTER*1
      = 'N': Bias is not computed.
      = 'Y': Bias is computed.

FACT (input)

      FACT is CHARACTER*1
      Specifies the form of the system of equations.
      = 'E': Solve Equilibrated system
      = 'N': Solve Non-Equilibrated system

EQUIL (input)

      EQUIL is CHARACTER*1
      Specifies whether or not the matrix A has been equilibrated.
      = 'N': The matrix A is not equilibrated.
      = 'Y': The matrix A has been equilibrated.

TRANS (input)

      TRANS is CHARACTER*1
      Specifies the form of the system of equations.
      = 'N': Solve AX = B         (No transpose)
      = 'T': Solve A**T X = B     (Transpose)
      = 'C': Solve A**H X = B     (Conjugate transpose)

EQUED (input)

      EQUED is CHARACTER*1
      Specifies the form of the equilibration.
      = 'N': None,             no equilibration computed.
      = 'R': Row,              row equilibration computed and potentially applied.
      = 'C': Column,           column equilibration computed and potentially applied.
      = 'B': Both row and column equilibration computed and potentially applied.

M (input)

      M is INTEGER
      The number of rows of the matrix A.  M >= 0.

N (input)

      N is INTEGER
      The number of columns of the matrix A.  N >= 0.

NB (input)

      NB is INTEGER
      The blocking factor for the calls to the recursive routines.
      NB >= 1.

A (input/output)

      A is COMPLEX*16 array, dimension (LDA,N)
      On entry, the M-by-N coefficient matrix A.
      On exit, if EQUED = 'N', A is unchanged.
      If EQUED = 'R', the equilibrated matrix A is stored in A.
      If EQUED = 'C', the equilibrated matrix A is stored in A.
      If EQUED = 'B', the equilibrated matrix A is stored in A.

LDA (input)

      LDA is INTEGER
      The leading dimension of the array A.  LDA >= max(1,M).

AF (output)

      AF is COMPLEX*16 array, dimension (LDAF,N)
      On exit, AF contains the factorization of A, as returned by ZGETRF.

LDAF (input)

      LDAF is INTEGER
      The leading dimension of the array AF. LDAF >= max(1,M).

IPIV (output)

      IPIV is INTEGER array, dimension (min(M,N))
      On exit, IPIV contains the pivot indices, as returned by ZGETRF.
      pivot(k) = i indicates that the row i of the block occurring in
      row k of the LU factorization was swapped with row k.

CND (output)

      CND is DOUBLE PRECISION array, dimension (1)
      On exit, CND contains an estimate of the condition number of the matrix.
      The condition number is computed as the norm of A norm of inverse A.
      CND is computed if INFO = 0.

RCOND (output)

      RCOND is DOUBLE PRECISION
      On exit, RCOND is a lower bound on the reciprocal of the condition number
      of A. RCOND = 1/CND.
      RCOND is computed if INFO = 0.

B (input/output)

      B is COMPLEX*16 array, dimension (LDB,NRHS)
      On entry, the right-hand side matrix B.
      On exit, the M-by-NRHS solution matrix X.

LDB (input)

      LDB is INTEGER
      The leading dimension of the array B. LDB >= max(1,M).

X (output)

      X is COMPLEX*16 array, dimension (LDX,NRHS)
      On exit, X contains the solution matrix X to the system of equations.
      If B is also given, then X overwrites B.

LDX (input)

      LDX is INTEGER
      The leading dimension of the array X. LDX >= max(1,M).

WORK (workspace)

      WORK is COMPLEX*16 array, dimension (2*N)

RWORK (workspace)

      RWORK is DOUBLE PRECISION array, dimension (2*N)

SRWORK (workspace)

      SRWORK is DOUBLE PRECISION array, dimension (N)

INFO (output)

      INFO is INTEGER
      = 0: Successful exit. The solution to every right-hand side is
        guaranteed.
      < 0: If INFO = -i, the i-th argument had an illegal value.
      > 0 and <= N:  U(INFO,INFO) is exactly zero.  The factorization
        has been completed, but the factor U is exactly singular, so
        the solution and error bounds could not be computed. RCOND = 0
        is returned.
      = N+J: The solution corresponding to the Jth right-hand side is
        not guaranteed. The solutions corresponding to other right-
        hand sides K with K > J may not be guaranteed as well, but
        only the first such right-hand side is reported. If a small
        componentwise error is not requested (PARAMS(3) = 0.0) then
        the Jth right-hand side is the first with a normwise error
        bound that is not guaranteed (the smallest J such
