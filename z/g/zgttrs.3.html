توثيق الوظيفة/الإجراء الفرعي

subroutine zgttrs (character trans, integer n, integer nrhs, complex*16, dimension( * ) dl, complex*16, dimension( * ) d, complex*16, dimension( * ) du, complex*16, dimension( * ) du2, integer, dimension( * ) ipiv, complex*16, dimension( ldb, * ) b, integer ldb, integer info)

ZGTTRS

الغرض:

!>
!> ZGTTRS يحل أحد أنظمة المعادلات
!>    A * X = B,  A**T * X = B,  أو  A**H * X = B,
!> مع مصفوفة ثلاثية قطرية A باستخدام التحلل LU الذي تم حسابه
!> بواسطة ZGTTRF.
!>

المعلمات

TRANS 
!>          TRANS is CHARACTER*1
!>          يحدد شكل نظام المعادلات.
!>          = 'N':  A * X = B     (بدون تحويل)
!>          = 'T':  A**T * X = B  (تحويل)
!>          = 'C':  A**H * X = B  (مترافق التحويل)
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.
!>

NRHS

!>          NRHS is INTEGER
!>          عدد الأطراف اليمنى، أي عدد أعمدة
!>          المصفوفة B.  NRHS >= 0.
!>

DL

!>          DL is COMPLEX*16 array, dimension (N-1)
!>          المضاعفات (n-1) التي تحدد المصفوفة L من
!>          التحلل LU للمصفوفة A.
!>

D

!>          D is COMPLEX*16 array, dimension (N)
!>          العناصر القطرية n للمصفوفة المثلثية العلوية U من
!>          التحلل LU للمصفوفة A.
!>

DU

!>          DU is COMPLEX*16 array, dimension (N-1)
!>          العناصر (n-1) من القطر الفوقي العلوي الأول لـ U.
!>

DU2

!>          DU2 is COMPLEX*16 array, dimension (N-2)
!>          العناصر (n-2) من القطر الفوقي العلوي الثاني لـ U.
!>

IPIV

!>          IPIV is INTEGER array, dimension (N)
!>          مؤشرات المحاور؛ من أجل 1 <= i <= n، تم تبديل الصف i للمصفوفة
!>          مع الصف IPIV(i).  IPIV(i) سيكون دائمًا إما
!>          i أو i+1؛ IPIV(i) = i يشير إلى أن تبديل الصف لم يكن
!>          ضروريًا.
!>

B

!>          B is COMPLEX*16 array, dimension (LDB,NRHS)
!>          عند الإدخال، المصفوفة الخاصة بمتجهات الطرف الأيمن B.
!>          عند الخروج، سيتم استبدال B بمتجهات الحل X.
!>

LDB

!>          LDB is INTEGER
!>          البعد الرئيسي للمصفوفة B.  LDB >= max(1,N).
!>

INFO

!>          INFO is INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -k، فإن الوسيط k كان له قيمة غير قانونية
!>
