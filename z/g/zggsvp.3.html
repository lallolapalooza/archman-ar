الغرض:

!>
!> هذا الإجراء الفرعي مهمل واستبدل بالإجراء الفرعي ZGGSVP3.
!>
!> يحسب ZGGSVP مصفوفتين وحدويتين U و V و Q بحيث
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  if M-K-L >= 0;
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  if M-K-L < 0;
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> حيث تكون المصفوفة A12 بحجم KxK والمصفوفة B13 بحجم LxL غير مفردة
!> ومثلثية علوية؛ A23 تكون مثلثية علوية بحجم LxL إذا كان M-K-L >= 0،
!> وإلا فإن A23 تكون شبه منحرفة علوية بحجم (M-K)xL. K+L = الرتبة الرقمية الفعالة
!> للمصفوفة (A**H,B**H)**H بحجم (M+P)xN.
!>
!> هذا التحليل هو خطوة المعالجة المسبقة لحساب تحليل القيم المفردة المعممة (GSVD)،
!> انظر الإجراء الفرعي ZGGSVD.
!>

!>          numerical rank of matrix B and a subblock of A. Generally,
