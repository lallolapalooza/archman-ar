subroutine zgegv (jobvl حرفي، jobvr حرفي، n صحيح، complex*16، dimension( lda, * ) a، lda صحيح، complex*16، dimension( ldb, * ) b، ldb صحيح، complex*16، dimension( * ) alpha، complex*16، dimension( * ) beta، complex*16، dimension( ldvl, * ) vl، ldvl صحيح، complex*16، dimension( ldvr, * ) vr، ldvr صحيح، complex*16، dimension( * ) work، lwork صحيح، double precision، dimension( * ) rwork، info صحيح)

ZGEGV يحسب القيم الذاتية، اختياريًا، المتجهات الذاتية اليسرى و/أو اليمنى لزوج مصفوفات معقدة (A,B).

الغرض:

!>
!> تم إيقاف هذا الروتين وتم استبداله بالروتين ZGGEV.
!>
!> ZGEGV يحسب القيم الذاتية، اختياريًا، المتجهات الذاتية اليسرى و/أو اليمنى لزوج مصفوفات معقدة (A,B).
!> بالنظر إلى مصفوفتين مربعتين A و B،
!> فإن مشكلة القيمة الذاتية غير المتماثلة المعممة (GNEP) هي إيجاد
!> القيم الذاتية lambda والمتجهات الذاتية المقابلة (غير الصفرية) x بحيث
!>    A*x = lambda*B*x.
!>
!> شكل بديل هو إيجاد القيم الذاتية mu والمتجهات الذاتية المقابلة y بحيث
!>    mu*A*y = B*y.
!>
!> هذان الشكلان متكافئان مع mu = 1/lambda و x = y إذا
!> لم يكن lambda أو mu صفرًا. للتعامل مع حالة
!> أن lambda أو mu صفر أو صغير، يتم إرجاع قيمتين alpha و beta
!> لكل قيمة ذاتية، بحيث lambda = alpha/beta و
!> mu = beta/alpha.
!>
!> المتجهات x و y في المعادلات أعلاه هي متجهات ذاتية يمنى
!> للزوج المصفوفي (A,B). المتجهات u و v التي تحقق
!>    u**H*A = lambda*u**H*B  أو  mu*v**H*A = v**H*B
!> هي متجهات ذاتية يسرى لـ (A,B).
!>
!> ملاحظة: يقوم هذا الروتين بـ على A و B
!>

المعلمات

JOBVL 
!>          JOBVL هو CHARACTER*1
!>          = 'N':  لا تحسب المتجهات الذاتية المعممة اليسرى؛
!>          = 'V':  احسب المتجهات الذاتية المعممة اليسرى (المُرجعة
!>                  في VL).
!>

JOBVR

!>          JOBVR هو CHARACTER*1
!>          = 'N':  لا تحسب المتجهات الذاتية المعممة اليمنى؛
!>          = 'V':  احسب المتجهات الذاتية المعممة اليمنى (المُرجعة
!>                  في VR).
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفات A، B، VL، و VR. N >= 0.
!>

A

!>          A هو مصفوفة COMPLEX*16، البعد (LDA, N)
!>          عند الدخول، المصفوفة A.
!>          إذا كان JOBVL = 'V' أو JOBVR = 'V'، فعند الخروج A
!>          يحتوي على شكل Schur للمصفوفة A من التحلل المتماثل
!>          للزوج (A,B) بعد الموازنة. إذا لم يتم حساب
!>          أي متجهات ذاتية، فإن العناصر القطرية فقط
!>          لشكل Schur ستكون صحيحة. انظر ZGGHRD و ZHGEQZ
!>          للتفاصيل.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرائد للمصفوفة A. LDA >= max(1,N).
!>

B

!>          B هو مصفوفة COMPLEX*16، البعد (LDB, N)
!>          عند الدخول، المصفوفة B.
!>          إذا كان JOBVL = 'V' أو JOBVR = 'V'، فعند الخروج B يحتوي على
!>          المصفوفة المثلثية العلوية التي تم الحصول عليها من B في التحلل
!>          المتماثل المعمم للزوج (A,B) بعد الموازنة.
!>          إذا لم يتم حساب أي متجهات ذاتية، فإن العناصر القطرية فقط
!>          للمصفوفة B ستكون صحيحة. انظر ZGGHRD و ZHGEQZ
!>          للتفاصيل.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرائد للمصفوفة B. LDB >= max(1,N).
!>

ALPHA

!>          ALPHA هي مصفوفة COMPLEX*16، البعد (N)
!>          ثوابت ألفا المعقدة التي تحدد القيم الذاتية
!>          لـ GNEP.
!>

BETA

!>          BETA هي مصفوفة COMPLEX*16، البعد (N)
!>          ثوابت بيتا المعقدة التي تحدد القيم الذاتية لـ GNEP.
!>
!>          معًا، الكميات alpha = ALPHA(j) و beta = BETA(j)
!>          تمثل القيمة الذاتية j-th للزوج المصفوفي (A,B)، في
!>          أحد الأشكال lambda = alpha/beta أو mu = beta/alpha.
!>          نظرًا لأنه قد يحدث فيضان لكل من lambda أو mu، فلا ينبغي
!>          حسابها بشكل عام.
!>

VL

!>          VL هي مصفوفة COMPLEX*16، البعد (LDVL,N)
!>          إذا كان JOBVL = 'V'، فإن المتجهات الذاتية اليسرى u(j) مخزنة
!>          في أعمدة VL، بنفس ترتيب قيمها الذاتية.
!>          يتم قياس كل متجه ذاتي بحيث يكون أكبر عنصر فيه
!>          abs(real part) + abs(imag. part) = 1، باستثناء المتجهات الذاتية
!>          المقابلة لقيمة ذاتية مع alpha = beta = 0، والتي
!>          يتم تعيينها إلى صفر.
!>          لا يتم الرجوع إليها إذا كان JOBVL = 'N'.
!>

LDVL

!>          LDVL هو INTEGER
!>          البعد الرائد للمصفوفة VL. LDVL >= 1، و
!>          إذا كان JOBVL = 'V'، فإن LDVL >= N.
!>

VR

!>          VR هي مصفوفة COMPLEX*16، البعد (LDVR,N)
!>          إذا كان JOBVR = 'V'، فإن المتجهات الذاتية اليمنى x(j) مخزنة
!>          في أعمدة VR، بنفس ترتيب قيمها الذاتية.
!>          يتم قياس كل متجه ذاتي بحيث يكون أكبر عنصر فيه
!>          abs(real part) + abs(imag. part) = 1، باستثناء المتجهات الذاتية
!>          المقابلة لقيمة ذاتية مع alpha = beta = 0، والتي
!>          يتم تعيينها إلى صفر.
!>          لا يتم الرجوع إليها إذا كان JOBVR = 'N'.
!>

LDVR

!>          LDVR هو INTEGER
!>          البعد الرائد للمصفوفة VR. LDVR >= 1، و
!>          إذا كان JOBVR = 'V'، فإن LDVR >= N.
!>

WORK

!>          WORK هي مصفوفة COMPLEX*16، البعد (MAX(1,LWORK))
!>          عند الخروج، إذا كان INFO = 0، يقوم WORK(1) بإرجاع LWORK الأمثل.
!>

LWORK

!>          LWORK هو INTEGER
!>          بعد المصفوفة WORK. LWORK >= max(1,2*N).
!>          لأداء جيد، يجب أن يكون LWORK أكبر بشكل عام.
!>          لحساب القيمة المثلى لـ LWORK، استدعِ ILAENV للحصول على
!>          أحجام الكتل (لـ ZGEQRF، ZUNMQR، و ZUNGQR). ثم احسب:
!>          NB  -- الحد الأقصى لأحجام الكتل لـ ZGEQRF، ZUNMQR، و ZUNGQR؛
!>          LWORK الأمثل هو MAX( 2*N, N*(NB+1) ).
!>
!>          إذا كان LWORK = -1، فسيتم افتراض استعلام مساحة العمل؛ الروتين
!>          يحسب فقط الحجم الأمثل للمصفوفة WORK، ويرجع
!>          هذه القيمة كالإدخال الأول للمصفوفة WORK، ولا يتم إصدار أي رسالة خطأ
!>          متعلقة بـ LWORK بواسطة XERBLA.
!>

RWORK

!>          RWORK هي مصفوفة DOUBLE PRECISION، البعد (8*N)
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية.
!>          =1,...,N:
!>                فشلت تكرارات QZ. لم يتم حساب المتجهات الذاتية، ولكن

!>          > N:  الأخطاء التي تشير عادةً إلى مشاكل LAPACK:
!>                =N+1: عودة الخطأ من ZGGBAL
!>                =N+2: عودة الخطأ من ZGEQRF
!>                =N+3: عودة الخطأ من ZUNMQR

zgegv.f(3)

NAME

zgegv - computes the eigenvalues and eigenvectors of a general complex matrix pair (A, B)

SYNOPSIS

SUBROUTINE ZGEGV(
                           JOBVL, JOBVR, N, A, LDA, B, LDB, ALPHA, BETA, VL,
                           LDVL, VR, LDVR, WORK, LWORK, INFO
                    )

Parameters:

CHARACTER JOBVL
JOBVL is CHARACTER*1
='N': no eigenvectors and no left Schur vectors are computed;
='V': the left eigenvectors is computed.
CHARACTER JOBVR
JOBVR is CHARACTER*1
='N': no eigenvectors and no right Schur vectors are computed;
='V': the right eigenvectors is computed.
INTEGER N
N is INTEGER, dimension of the matrices A and B.
COMPLEX*16, DIMENSION( LDA, * ) A
A is COMPLEX*16 array, dimension (LDA,N)
On entry, the M-by-N matrix A.
On exit, A is changed if JOBVL = 'V' or JOBVR = 'V'.
The upper triangle of A is overwritten by the upper triangle
of its complex Schur form.
INTEGER LDA
LDA is INTEGER, dimension of the array A. LDA >= max(1, N).
COMPLEX*16, DIMENSION( LDB, * ) B
B is COMPLEX*16 array, dimension (LDB,N)
On entry, the M-by-N matrix B.
On exit, B is changed if JOBVL = 'V' or JOBVR = 'V'.
The upper triangle of B is overwritten by the upper triangle
of its complex Schur form.
INTEGER LDB
LDB is INTEGER, dimension of the array B. LDB >= max(1, N).
DOUBLE PRECISION, DIMENSION( * ) ALPHA
ALPHA is DOUBLE PRECISION array, dimension (N).
On exit, ALPHA(i) is the i-th eigenvalue.
For real eigenvalues, ALPHA(i) is the real part.
For complex eigenvalues, ALPHA(i) is the real part of the
eigenvalue.
DOUBLE PRECISION, DIMENSION( * ) BETA
BETA is DOUBLE PRECISION array, dimension (N).
On exit, BETA(i) is the i-th eigenvalue.
BETA(i) is the imaginary part of the eigenvalue.
COMPLEX*16, DIMENSION( LDVL, * ) VL
VL is COMPLEX*16 array, dimension (LDVL,N).
On exit, if JOBVL = 'V', the left eigenvectors
`v_i` are stored one per column: VL(i,j) = v_j. The v_j are
normalized so that the component of largest absolute
value is 1.
INTEGER LDVL
LDVL is INTEGER, dimension of the array VL. LDVL >= N.
COMPLEX*16, DIMENSION( LDVR, * ) VR
VR is COMPLEX*16 array, dimension (LDVR,N).
On exit, if JOBVR = 'V', the right eigenvectors
`v_i` are stored one per column: VR(i,j) = v_j. The v_j are
normalized so that the component of largest absolute
value is 1.
INTEGER LDVR
LDVR is INTEGER, dimension of the array VR. LDVR >= N.
COMPLEX*16, DIMENSION( * ) WORK
WORK is COMPLEX*16 array, dimension (LWORK).
INTEGER LWORK
LWORK is INTEGER
The dimension of the array WORK. LWORK >= max(1, 2*N).
For optimum performance LWORK >= N + 2*N*NB.
INTEGER INFO
INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value.
> 0: if INFO = i, ZGEGV (?!) failed. The algorithm for computing
eigenvalues did not converge; i eigenvectors, and none of
the left eigenvectors, did not converge.

Function/Subroutine Documentation

!> @brief This subroutine computes the eigenvalues and left and right eigenvectors
!>        of a complex pair of general matrices (A,B) of the same dimension.
!>
!> @param[in] JOBVL CHARACTER*1
!>            Specifies whether to compute the left eigenvectors.
!>            ='N': Do not compute the left eigenvectors.
!>            ='V': Compute the left eigenvectors.
!> @param[in] JOBVR CHARACTER*1
!>            Specifies whether to compute the right eigenvectors.
!>            ='N': Do not compute the right eigenvectors.
!>            ='V': Compute the right eigenvectors.
!> @param[in] N INTEGER
!>            The order of the matrices A and B. N >= 0.
!> @param[in,out] A COMPLEX*16 array, dimension (LDA, N)
!>            On entry, the matrix A.
!>            On exit, if JOBVL = 'V' or JOBVR = 'V', A contains the upper
!>            triangular matrix from the complex Schur decomposition of A.
!> @param[in] LDA INTEGER
!>            The leading dimension of the array A. LDA >= max(1, N).
!> @param[in,out] B COMPLEX*16 array, dimension (LDB, N)
!>            On entry, the matrix B.
!>            On exit, if JOBVL = 'V' or JOBVR = 'V', B contains the upper
!>            triangular matrix from the complex Schur decomposition of B.
!> @param[in] LDB INTEGER
!>            The leading dimension of the array B. LDB >= max(1, N).
!> @param[out] ALPHA DOUBLE PRECISION array, dimension (N)
!>            The real parts of the eigenvalues of the pair (A,B).
!> @param[out] BETA DOUBLE PRECISION array, dimension (N)
!>            The imaginary parts of the eigenvalues of the pair (A,B).
!> @param[out] VL COMPLEX*16 array, dimension (LDVL, N)
!>            If JOBVL = 'V', VL contains the left eigenvectors of A and B,
!>            stored one per column. The normalized eigenvectors are such that
!>            the element of largest absolute value is 1.
!> @param[in] LDVL INTEGER
!>            The leading dimension of the array VL. LDVL >= N.
!> @param[out] VR COMPLEX*16 array, dimension (LDVR, N)
!>            If JOBVR = 'V', VR contains the right eigenvectors of A and B,
!>            stored one per column. The normalized eigenvectors are such that
!>            the element of largest absolute value is 1.
!> @param[in] LDVR INTEGER
!>            The leading dimension of the array VR. LDVR >= N.
!> @param[out] WORK COMPLEX*16 array, dimension (LWORK)
!>            Work array for internal computations.
!> @param[in] LWORK INTEGER
!>            The size of the work array. LWORK >= max(1, 2*N).
!>            For optimum performance, LWORK should be at least N + 2*N*NB,
!>            where NB is the block size for the underlying Schur decomposition.
!> @param[out] INFO INTEGER
!>            = 0: Success.
!>            < 0: An illegal argument was detected.
!>            > 0: The algorithm failed to converge. The i-th failure occurred for
!>                 the i-th eigenvalue/eigenvector.
!>
!> @par Error Returns:
!>            =N+1: error return from ZGEBAL
!>            =N+2: error return from ZGEBAL
!>            =N+3: error return from ZGEBAL
!>            =N+4: error return from ZGEBAL
!>            =N+5: error return from ZGEBAL
!>            =N+6: error return from ZGEBAL
!>            =N+7: error return from ZTGEVC
!>            =N+8: error return from ZGGBAK (computing VL)
!>            =N+9: error return from ZGGBAK (computing VR)
!>            =N+10: error return from ZLASCL (various calls)
!>

Further Details:

!>
!>  Balancing
!>  ---------
!>
!>  This driver calls ZGGBAL to both permute and scale rows and columns
!>  of A and B.  The permutations PL and PR are chosen so that PL*A*PR
!>  and PL*B*R will be upper triangular except for the diagonal blocks
!>  A(i:j,i:j) and B(i:j,i:j), with i and j as close together as
!>  possible.  The diagonal scaling matrices DL and DR are chosen so
!>  that the pair  DL*PL*A*PR*DR, DL*PL*B*PR*DR have elements close to
!>  one (except for the elements that start out zero.)
!>
!>  After the eigenvalues and eigenvectors of the balanced matrices
!>  have been computed, ZGGBAK transforms the eigenvectors back to what
!>  they would have been (in perfect arithmetic) if they had not been
!>  balanced.
!>
!>  Contents of A and B on Exit
!>  -------- -- - --- - -- ----
!>
!>  If any eigenvectors are computed (either JOBVL='V' or JOBVR='V' or
!>  both), then on exit the arrays A and B will contain the complex Schur
!>  form[*] of the  versions of A and B.  If no eigenvectors
!>  are computed, then only the diagonal blocks will be correct.
!>
!>  [*] In other words, upper triangular form.
!>
