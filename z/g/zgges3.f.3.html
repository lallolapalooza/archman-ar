NAME

zgges3 — This subroutine computes the generalized eigenvalues and, optionally, the left and right Schur vectors of a complex general matrix pair (A, B).

SYNOPSIS

 SUBROUTINE ZGGES3(
  JOBVSL, JOBVSR, SORT, SELCTG,
  N, A, LDA, B, LDB, SDIM,
  ALPHA, BETA, VSL, LDVSL,
  VSR, LDVSR, WORK, LWORK, RWORK,
  BWORK, INFO )

Parameters:

JOBVSL

CHARACTER*1. Must be 'Y' or 'N'.

If JOBVSL = 'Y', compute the left Schur vectors L.

If JOBVSL = 'N', do not compute the left Schur vectors.

JOBVSR

CHARACTER*1. Must be 'Y' or 'N'.

If JOBVSR = 'Y', compute the right Schur vectors R.

If JOBVSR = 'N', do not compute the right Schur vectors.

SORT

CHARACTER*1. Must be 'Y' or 'N'.

If SORT = 'Y', the eigenvalues are reordered according to the criterion specified by the character function SELCTG.

If SORT = 'N', the eigenvalues are not reordered.

SELCTG

LOGICAL FUNCTION of a complex input argument.

If SORT = 'Y', SELCTG is used to select eigenvalues which will be ordered to the leading positions in the generalized Schur form. For example, if SELCTG(ALPHA(i), BETA(i)) is true, then the i-th eigenvalue pair is selected.

If SORT = 'N', SELCTG is not referenced.

N

INTEGER. The order of the matrices A and B. N >= 0.

A

COMPLEX*16 array, dimension (LDA, N).

On entry, the matrix A.

On exit, A is overwritten by its generalized Schur form.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1, N).

B

COMPLEX*16 array, dimension (LDB, N).

On entry, the matrix B.

On exit, B is overwritten by its generalized Schur form.

LDB

INTEGER. The leading dimension of the array B. LDB >= max(1, N).

SDIM

INTEGER.

If SORT = 'Y', SDIM is the number of selected eigenvalues, i.e., the number of selected pairs of complex numbers (ALPHA(i), BETA(i)). If SORT = 'N', SDIM is the number of eigenvalues that will be reordered to the leading positions. 0 <= SDIM <= N.

ALPHA

COMPLEX*16 array, dimension (N).

See DESCRIPTION.

BETA

COMPLEX*16 array, dimension (N).

See DESCRIPTION.

VSL

COMPLEX*16 array, dimension (LDVSL, N).

If JOBVSL = 'Y', VSL contains the left Schur vectors L. If JOBVSL = 'N', VSL is not referenced.

LDVSL

INTEGER. The leading dimension of the array VSL. If JOBVSL = 'Y', LDVSL >= N.

VSR

COMPLEX*16 array, dimension (LDVSR, N).

If JOBVSR = 'Y', VSR contains the right Schur vectors R. If JOBVSR = 'N', VSR is not referenced.

LDVSR

INTEGER. The leading dimension of the array VSR. If JOBVSR = 'Y', LDVSR >= N.

WORK

COMPLEX*16 array, dimension (LWORK).

LWORK

INTEGER. The dimension of the array WORK. LWORK >= max(1, 2*N).

For optimum performance, LWORK should be greater than or equal to N+N*NB, where NB is the block size of the algorithm.

If LWORK = -1, then a workspace query is assumed and the subroutine only calculates the optimal size of the WORK array. The optimal size is stored as the first entry of the WORK array.

RWORK

DOUBLE PRECISION array, dimension (8*N).

BWORK

LOGICAL array, dimension (N).

If SORT = 'Y', BWORK(i) is true if the i-th eigenvalue pair is to be selected, and false otherwise. If SORT = 'N', BWORK is not referenced.

On exit, if SORT = 'Y', BWORK(i) is true if the i-th eigenvalue pair is selected, and false otherwise.

INFO

INTEGER.

INFO = 0: successful exit

INFO < 0: If INFO = -i, the i-th argument had an illegal value.

INFO > 0: =1,...,N: The QZ iteration failed. (A,B) are not in Schur form, but ALPHA(j) and BETA(j) should be correct for j=INFO+1,...,N.

> N: =N+1: other than QZ iteration failed in ZLAQZ0 => N+2: after reordering, roundoff changed values of some complex eigenvalues so that leading eigenvalues in the Generalized Schur form no longer satisfy SELCTG=.TRUE. This could also be caused due to scaling. => N+3: reordering failed in ZTGSEN.

Function/Subroutine Documentation

This subroutine computes the generalized eigenvalues and, optionally, the left and right Schur vectors of a complex general matrix pair (A, B).

The eigenvalues are pairs of complex numbers (ALPHA(i), BETA(i)) such that

A*v(i) = ALPHA(i)*B*v(i)

and

u(i)*A = ALPHA(i)*u(i)*B

where u(i) and v(i) are the left and right eigenvectors, respectively.

The generalized Schur decomposition is computed:

A = Q*S*ZH

B = Q*T*ZH

where Q and Z are unitary matrices, and S and T are upper triangular matrices.

The eigenvalues are the diagonal entries of S divided by the diagonal entries of T, i.e., ALPHA(i)/BETA(i).

The function ZGGES3 is a wrapper for the recursive subroutine ZGEQPF, which computes the generalized Schur decomposition.

The routine sorts the eigenvalues according to the criterion specified by the character function SELCTG. The left and right Schur vectors are computed if requested.

The detailed implementation of the QZ algorithm and the reordering and Schur vector computation are handled by other LAPACK routines such as ZLAQZ0, ZTGSEN, and ZGGESX.

The workspace array WORK is used for intermediate calculations. The size of WORK, LWORK, should be at least max(1, 2*N). For optimal performance, it is recommended to provide a larger workspace.

The routine returns an integer INFO flag indicating the success of the computation. A positive value of INFO indicates a failure in the QZ iteration or reordering process.
