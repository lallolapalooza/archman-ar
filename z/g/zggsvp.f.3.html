NAME

zggsvp - computes the generalized Schur decomposition of a complex pair of general matrices (A, B)

SYNOPSIS

SUBROUTINE ZGGSVP(
     JOBU, JOBV, JOBU2, JOBV2, M, N, K, A, LDA, B, LDB,
     TOLA, TOLB, WORK, LWORK, INFO )

   CHARACTER          JOBU, JOBV, JOBU2, JOBV2
   INTEGER            INFO, K, LDA, LDB, LWORK, M, N
   DOUBLE PRECISION   TOLA, TOLB
   COMPLEX*16       A( LDA, * ), B( LDB, * ), WORK( * )

Function/Subroutine Documentation

ZGGSLV computes the generalized Schur decomposition of a complex pair of general matrices (A, B), that is, ZGGSLV reduces A and B to upper triangular form by means of unitary transformations: 

   A = Q * T * ( B is already upper triangular )
   B = Z * U

where Q and Z are unitary matrices. T is an upper triangular matrix.
