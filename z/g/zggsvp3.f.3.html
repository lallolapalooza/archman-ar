الغرض:

!>
!> ZGGSVP3 يحسب مصفوفات وحدوية U، V و Q بحيث
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  إذا كان M-K-L >= 0؛
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  إذا كان M-K-L < 0؛
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> حيث المصفوفة A12 بحجم K×K والمصفوفة B13 بحجم L×L غير منفردة
!> ومثلثة علوية؛ A23 هي مثلثة علوية بحجم L×L إذا كان M-K-L >= 0،
!> وإلا فإن A23 تكون شبه منحرفة علوية بحجم (M-K)×L. K+L = الرتبة العددية الفعالة
!> للمصفوفة (A**H,B**H)**H بحجم (M+P)×N.
!>
!> هذا التحلل هو خطوة المعالجة المسبقة لحساب التحلل الأحادي المعمم (GSVD)، انظر الإجراء الفرعي
!> ZGGSVD3.
!>

المعلمات

JOBU 
!>          JOBU هو CHARACTER*1
!>          = 'U':  يتم حساب المصفوفة الوحدوية U؛
!>          = 'N':  لا يتم حساب U.
!>

JOBV

!>          JOBV هو CHARACTER*1
!>          = 'V':  يتم حساب المصفوفة الوحدوية V؛
!>          = 'N':  لا يتم حساب V.
!>

JOBQ

!>          JOBQ هو CHARACTER*1
!>          = 'Q':  يتم حساب المصفوفة الوحدوية Q؛
!>          = 'N':  لا يتم حساب Q.
!>

M

!>          M هو INTEGER
!>          عدد صفوف المصفوفة A.  M >= 0.
!>

P

!>          P هو INTEGER
!>          عدد صفوف المصفوفة B.  P >= 0.
!>

N

!>          N هو INTEGER
!>          عدد أعمدة المصفوفتين A و B.  N >= 0.
!>

A

!>          A هو مصفوفة COMPLEX*16، حجمها (LDA,N)
!>          عند الإدخال، تحتوي A على المصفوفة المثلثية (أو شبه المنحرفة)
!>          الموصوفة في قسم الغرض.
!>          عند الخروج، تحتوي A على المصفوفة المثلثية (أو شبه المنحرفة)
!>          الموصوفة في قسم الغرض.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A. LDA >= max(1,M).
!>

B

!>          B هو مصفوفة COMPLEX*16، حجمها (LDB,N)
!>          عند الإدخال، تحتوي B على المصفوفة P×N.
!>          عند الخروج، تحتوي B على المصفوفة المثلثية الموصوفة في
!>          قسم الغرض.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرئيسي للمصفوفة B. LDB >= max(1,P).
!>

TOLA

!>          TOLA هو DOUBLE PRECISION
!>

TOLB

!>          TOLB هو DOUBLE PRECISION
!>
!>          TOLA و TOLB هما العتبتان لتحديد الرتبة العددية الفعالة
!>          للمصفوفة B وكتلة فرعية من A. بشكل عام،
!>          يتم ضبطهما على:
!>             TOLA = MAX(M,N)*norm(A)*MAZHEPS,
!>             TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>          قد يؤثر حجم TOLA و TOLB على حجم الأخطاء اللاحقة
!>          للتحلل.
!>

K

!>          K هو INTEGER
!>

L

!>          L هو INTEGER
!>
!>          عند الخروج، تحدد K و L أبعاد الكتل الفرعية
!>          الموصوفة في قسم الغرض.
!>          K + L = الرتبة العددية الفعالة للمصفوفة (A**H,B**H)**H.
!>

U

!>          U هي مصفوفة COMPLEX*16، حجمها (LDU,M)
!>          إذا كان JOBU = 'U'، تحتوي U على المصفوفة الوحدوية U.
!>          إذا كان JOBU = 'N'، لا يتم استخدام U.
!>

LDU

!>          LDU هو INTEGER
!>          البعد الرئيسي للمصفوفة U. LDU >= max(1,M) إذا
!>          كان JOBU = 'U'. LDU >= 1 خلاف ذلك.
!>

V

!>          V هي مصفوفة COMPLEX*16، حجمها (LDV,P)
!>          إذا كان JOBV = 'V'، تحتوي V على المصفوفة الوحدوية V.
!>          إذا كان JOBV = 'N'، لا يتم استخدام V.
!>

LDV

!>          LDV هو INTEGER
!>          البعد الرئيسي للمصفوفة V. LDV >= max(1,P) إذا
!>          كان JOBV = 'V'. LDV >= 1 خلاف ذلك.
!>

Q

!>          Q هي مصفوفة COMPLEX*16، حجمها (LDQ,N)
!>          إذا كان JOBQ = 'Q'، تحتوي Q على المصفوفة الوحدوية Q.
!>          إذا كان JOBQ = 'N'، لا يتم استخدام Q.
!>

LDQ

!>          LDQ هو INTEGER
!>          البعد الرئيسي للمصفوفة Q. LDQ >= max(1,N) إذا
!>          كان JOBQ = 'Q'. LDQ >= 1 خلاف ذلك.
!>

IWORK

!>          IWORK هي مصفوفة INTEGER، حجمها (N)
!>

RWORK

!>          RWORK هي مصفوفة DOUBLE PRECISION، حجمها (2*N)
!>

TAU

!>          TAU هي مصفوفة COMPLEX*16، حجمها (N)
!>

WORK

!>          WORK هي مصفوفة COMPLEX*16، حجمها (MAX(1,LWORK))
!>          عند الخروج، إذا كان INFO = 0، فإن WORK(1) يعيد LWORK الأمثل.
!>

LWORK

!>          LWORK هو INTEGER
!>          بعد المصفوفة WORK. LWORK >= 1.
!>
!>          إذا كان LWORK = -1، فسيتم افتراض استعلام عن مساحة العمل؛
!>          يقوم الإجراء فقط بحساب الحجم الأمثل لمصفوفة WORK، ويعيد
!>          هذه القيمة كالإدخال الأول لمصفوفة WORK، ولا تصدر XERBLA
!>          أي رسالة خطأ تتعلق بـ LWORK.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية.
!>
