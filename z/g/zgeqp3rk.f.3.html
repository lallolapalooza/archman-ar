ZGEQP3RK يحسب عامل QR مقطوع لمصفوفة معقدة m-by-n A باستخدام BLAS المستوى 3 ويستبدل المصفوفة B ذات الأبعاد m-by-nrhs بـ Q**H * B.

الغرض:

!>
!> ZGEQP3RK يؤدي مهمتين في وقت واحد:
!>
!> المهمة 1: تقوم الإجراء الفرعي بحساب عامل QR مقطوع (رتبة K) أو كامل الرتبة
!> بعامل Householder مع تبديل الأعمدة لمصفوفة معقدة M-by-N A باستخدام BLAS المستوى 3. K هو عدد الأعمدة
!> التي تم تحليلها، أي رتبة التحليل
!> R. K <= min(M,N).
!>
!>  A * P(K) = Q(K) * R(K)  =
!>
!>        = Q(K) * ( R11(K) R12(K) ) = Q(K) * (   R(K)_approx    )
!>                 ( 0      R22(K) )          ( 0  R(K)_residual ),
!>
!> حيث:
!>
!>  P(K)            هي مصفوفة تبديل N-by-N؛
!>  Q(K)            هي مصفوفة وحدوية M-by-M؛
!>  R(K)_approx   = ( R11(K), R12(K) ) هي تقريب من رتبة K للمصفوفة
!>                    كاملة R مع R11(K) مثلثة عليا K-by-K
!>                    و R12(K) مستطيلة K-by-N. الأقطار
!>                    لـ R11(K) تظهر بترتيب متناقص
!>                    بالقيمة المطلقة، والقيم المطلقة لجميع
!>                    الأقطار أكبر من المعيار 2 الأقصى للعمود للمصفوفة R22(K)
!>                    حتى خطأ التقريب.
!>  R(K)_residual = R22(K) هي الباقي لتقريب من رتبة K
!>                    للمصفوفة الكاملة R. وهي
!>                    مصفوفة مستطيلة (M-K)-by-(N-K)؛
!>  0               هي مصفوفة صفرية (M-K)-by-K.
!>
!> المهمة 2: في نفس الوقت، تقوم الإجراء الفرعي باستبدال مصفوفة B معقدة M-by-NRHS
!> بـ Q(K)**H * B باستخدام BLAS المستوى 3.
!>
!> =====================================================================
!>
!> المصفوفات A و B مخزنة عند الإدخال في المصفوفة A كـ
!> كتلتين يسرى ويمين A(1:M,1:N) و A(1:M, N+1:N+NRHS)
!> على التوالي.
!>
!>                                  N     NRHS
!>             array_A   =   M  [ mat_A, mat_B ]
!>
!> معايير الاقتطاع (أي، متى يتم إيقاف التحليل)
!> يمكن أن تكون أيًا مما يلي:
!>
!>   1) المعلمة المدخلة KMAX، الحد الأقصى لعدد الأعمدة
!>      KMAX لتحليلها، أي رتبة التحليل محدودة
!>      إلى KMAX. إذا كانت KMAX >= min(M,N)، فلن يتم استخدام المعيار.
!>
!>   2) المعلمة المدخلة ABSTOL، التفاوت المطلق لـ
!>      المعيار 2 الأقصى للعمود للمصفوفة المتبقية R22(K). هذا
!>      يعني أن التحليل يتوقف إذا كان هذا المعيار أقل أو
!>      يساوي ABSTOL. إذا كانت ABSTOL < 0.0، فلن يتم استخدام المعيار.
!>
!>   3) المعلمة المدخلة RELTOL، التفاوت لـ
!>      المعيار 2 الأقصى للعمود للمصفوفة المتبقية R22(K) مقسومًا
!>      على المعيار 2 الأقصى للعمود للمصفوفة الأصلية A، وهو
!>      يساوي abs(R(1,1)). هذا يعني أن التحليل يتوقف
!>      عندما تكون نسبة المعيار 2 الأقصى للعمود لـ R22(K) إلى
!>      المعيار 2 الأقصى للعمود لـ A أقل من أو تساوي RELTOL.
!>      إذا كانت RELTOL < 0.0، فلن يتم استخدام المعيار.
!>
!>   4) في حال عدم استخدام معايير الإيقاف ABSTOL أو RELTOL،
!>      وعندما تكون المصفوفة المتبقية R22(K) مصفوفة صفرية في
!>      بعض خطوات التحليل K. (هذا المعيار الضمني للإيقاف.)
!>
!>  تتوقف الخوارزمية عند تلبية أي من هذه الشروط أولاً،
!>  وإلا يتم تحليل المصفوفة A بالكامل.
!>
!>  لتحليل المصفوفة A بالكامل، استخدم القيم
!>  KMAX >= min(M,N)، ABSTOL < 0.0 و RELTOL < 0.0.
!>
!>  تعيد الإجراء الفرعي:
!>     أ) Q(K)، R(K)_approx = ( R11(K)، R12(K) )،
!>        R(K)_residual = R22(K)، P(K)، أي المصفوفات الناتجة
!>        من التحليل؛ P(K) ممثلة بـ JPIV،
!>        (إذا كان K = min(M,N)، فإن R(K)_approx هي المصفوفة الكاملة R،
!>        ولا توجد مصفوفة متبقية R(K)_residual)؛
!>     ب) K، عدد الأعمدة التي تم تحليلها،
!>        أي رتبة التحليل؛
!>     ج) MAXC2NRMK، المعيار 2 الأقصى للعمود للمصفوفة المتبقية
!>        R(K)_residual = R22(K)،
!>        (إذا كان K = min(M,N)، فإن MAXC2NRMK = 0.0)؛
!>     د) RELMAXC2NRMK يساوي MAXC2NRMK مقسومًا على MAXC2NRM، المعيار 2 الأقصى للعمود
!>        للمصفوفة الأصلية A، والذي يساوي abs(R(1,1))،
!>        (إذا كان K = min(M,N)، فإن RELMAXC2NRMK = 0.0)؛
!>     هـ) Q(K)**H * B، المصفوفة B مع تطبيق التحويل الوحدوي
!>        Q(K)**H من اليسار.
!>
!> مصفوفة التبديل N-by-N P(K) مخزنة بتنسيق مضغوط في
!> المصفوفة الصحيحة JPIV. من 1 <= j <= N، تم تبديل العمود j
!> للمصفوفة A بالعمود JPIV(j).
!>
!> المصفوفة الوحدوية M-by-M Q ممثلة كحاصل ضرب
!> لمُنعكسات هاوسهولدر الأولية
!>
!>     Q(K) = H(1) *  H(2) * . . . * H(K)،
!>
!> حيث K هو عدد الأعمدة التي تم تحليلها.
!>
!> كل H(j) لها الشكل
!>
!>     H(j) = I - tau * v * v**H,
!>
!> حيث 1 <= j <= K و
!>   I    هي مصفوفة هوية M-by-M،
!>   tau  هو مقياس معقد،
!>   v    هو متجه معقد حيث v(1:j-1) = 0 و v(j) = 1.
!>
!> يتم تخزين v(j+1:M) عند الخروج في A(j+1:M,j) و tau في TAU(j).
!>
!> انظر قسم التفاصيل الإضافية لمزيد من المعلومات.
!>

 CHARACTER

  * A( M, N ), TAU( MIN( M, N ) ), WORK( LWORK )
 INTEGER

Function/Subroutine Documentation

!> @brief zgeqp3rk computes the rank-revealing QR factorization of a
!>        complex m-by-n matrix A.
!>
!> ZGEQP3RK is based on the same BLAS3 Householder QR factorization
!> algorithm with column pivoting as in ZGEQP3 routine which uses
!> ZLARFG routine to generate Householder reflectors
!> for QR factorization.
!>
!> The rank-revealing QR factorization with column pivoting is
!> computed as
!>
!>   A*P = Q*R
!>
!> where P is a permutation matrix, Q is a unitary matrix, and R is
!> upper trapezoidal.
!>
!> The rank of A is the number of non-zero diagonal elements of R.
!>
!> Arguments
!>
!>   M           (input) INTEGER
!>               The number of rows of the matrix A. M >= 0.
!>
!>   N           (input) INTEGER
!>               The number of columns of the matrix A. N >= 0.
!>
!>   A           (input/output) COMPLEX*16 array, dimension (LDA,N)
!>               On entry, the m-by-n matrix A to be factorized.
!>               On exit, the upper trapezoidal matrix R and the
!>               lower triangular matrix L have been stored in A and
!>               TAU. The diagonal elements of R and the elements
!>               of L may be complex.
!>
!>   LDA         (input) INTEGER
!>               The leading dimension of the array A. LDA >= max(1,M).
!>
!>   JPVT        (input/output) INTEGER array, dimension (N)
!>               On entry, if JPVT(j) is positive, the j-th column
!>               of A is the j-th column of the initial matrix A.
!>               If JPVT(j) is zero, then the j-th column of A is
!>               permuted with the first available column of A whose
!>               rank is in 1..j-1.
!>               This is a symbolic permutation that ensures that the
!>               columns of A are permuted.
!>               On exit, if JPVT(j) > 0, then the j-th column of the
!>               initial matrix A has been permuted into the j-th
!>               column of A, and then modified.
!>               If JPVT(j) = 0, the j-th column of A was not a
!>               candidate for pivoting.
!>
!>   TAU         (output) COMPLEX*16 array, dimension (MIN(M,N))
!>               The scalar factors of the elementary Householder
!>               reflectors.
!>
!>   WORK        (workspace) COMPLEX*16 array, dimension (LWORK)
!>               On exit, WORK(1) is the minimum required dimension of WORK.
!>
!>   LWORK       (input) INTEGER
!>               The dimension of the array WORK. LWORK >= max(1,N).
!>               For optimal efficiency, LWORK >= max(1,N)*NB, where
!>               NB is the block size.
!>
!>   INFO        (output) INTEGER
!>               = 0:  successful exit
!>               < 0:  if INFO = -i, the i-th argument had an illegal
!>                     value.
!>               > 0:  The algorithm has detected that the current column
!>                     is rank deficient. The rank of the matrix A is
!>                     given by INFO.
!>
!> Example usage
!>
!>   Consider the following matrix A:
!>
!>     A = [ 1 + 1i, 2 + 2i, 3 + 3i ]
!>         [ 4 + 4i, 5 + 5i, 6 + 6i ]
!>
!>   We want to compute the rank-revealing QR factorization of A.
!>   Let M = 2, N = 3.
!>   LDA = 2.
!>   JPVT = [ 0, 0, 0 ].
!>   LWORK = 3.
!>   WORK = [ 0, 0, 0 ].
!>
!>   CALL ZGEQP3RK( M, N, A, LDA, JPVT, TAU, WORK, LWORK, INFO )
!>
!>   After the call, INFO will indicate the rank of the matrix.
!>   A will contain the upper trapezoidal matrix R.
!>   TAU will contain the scalar factors of the Householder reflectors.
!>   JPVT will contain the pivoting information.
!>
!> Implementation details
!>
!> 1) If INFO = 0, the rank of the matrix A is MIN(M,N).
!> 2) If INFO > 0, where 1 <= INFO <= MIN(M,N), then the rank of A
!>    is INFO. The (INFO+1)-th column of A contains the first
!>    column that is linearly dependent on the previous columns.
!> 3) If K = INFO and K <= MIN(M,N), then TAU(K) may contain NaN
!>    if j_1=K+1, TAU(K+1)
!>    may contain NaN.
!> 4) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN
!>    was detected, but +Inf (or -Inf) was detected and
!>    the routine continues the computation until completion.
!>    The (j_2-N)-th column of the matrix A contains the first
!>    occurrence of +Inf (or -Inf) in the factorization
!>    step K+1 ( when K columns have been factorized ).
!>

Further Details:

!> ZGEQP3RK is based on the same BLAS3 Householder QR factorization
!> algorithm with column pivoting as in ZGEQP3 routine which uses
!> ZLARFG routine to generate Householder reflectors
!> for QR factorization.
!>
!> We can also write:
!>
!>   A = A_approx(K) + A_residual(K)
!>
!> The low rank approximation matrix A(K)_approx from
!> the truncated QR factorization of rank K of the matrix A is:
!>
!>   A(K)_approx = Q(K) * ( R(K)_approx ) * P(K)**T
!>                        (     0     0 )
!>
!>               = Q(K) * ( R11(K) R12(K) ) * P(K)**T
!>                        (      0      0 )
!>
!> The residual A_residual(K) of the matrix A is:
!>
!>   A_residual(K) = Q(K) * ( 0              0 ) * P(K)**T =
!>                          ( 0  R(K)_residual )
!>
!>                 = Q(K) * ( 0        0 ) * P(K)**T
!>                          ( 0   R22(K) )
!>
!> The truncated (rank K) factorization guarantees that
!> the maximum column 2-norm of A_residual(K) is less than
!> or equal to MAXC2NRMK up to roundoff error.
!>
!> NOTE: An approximation of the null vectors
!>       of A can be easily computed from R11(K)
!>       and R12(K):
!>
!>       Null( A(K) )_approx = P * ( inv(R11(K)) * R12(K) )
!>                                 (         -I           )
!>
!>
