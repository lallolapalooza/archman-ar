Function/Subroutine Documentation

    This subroutine forms the generalized Schur factorization of an
    N-by-N complex matrix pair (A,B)

    A = Q * T * Z**H
    B = Q * U * Z**H
    where T and U are upper quasi-triangular matrices with T upper
    triangular, and Q and Z are unitary matrices.
    The generalized eigenvalues of the pair (A,B) are then the
    ratios ALPHA(i) / BETA(i).
    
    INFO: =0:  successful exit
          >0:  if INFO = i, then the i-th argument had an illegal value.
          >0:  if INFO = i > 0 and i <= N, then the QZ iteration failed
                to compute the Schur form. R(i+1) contains the number of
                unconverged
                eigenvalues.
          >0:  if INFO = i > N, then the QZ iteration failed.
                N+1: QZ iteration failed.
                N+2: After reordering, roundoff error prevents further
                     convergence.
                N+3: Reordering failed.
