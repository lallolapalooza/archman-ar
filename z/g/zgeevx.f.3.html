Function/Subroutine Documentation

ZGEEVX computes the eigenvalues and left and right eigenvectors of the complex general rectangular matrix A. It also allows users to compute the Schur factorization and reciprocal condition numbers for the eigenvalues and eigenvectors.

Input Parameters

BALANC CHARACTER*1
Specifies whether to balance the matrix before computing the eigenvalues and eigenvectors.
  • 'N': Do not balance the matrix.
  • 'P': Balance the matrix by permutation only.
  • 'S': Balance the matrix by scaling only.
  • 'B': Balance the matrix by permutation and scaling.
SENSE CHARACTER*1
Specifies the computation to be performed.
  • 'N': Computes only the eigenvalues and left and right eigenvectors.
  • 'E': Computes the eigenvalues and left and right eigenvectors, and estimates the reciprocal condition numbers for the eigenvalues only.
  • 'V': Computes the eigenvalues and left and right eigenvectors, and estimates the reciprocal condition numbers for the eigenvectors only.
  • 'B': Computes the eigenvalues and left and right eigenvectors, and estimates the reciprocal condition numbers for both the eigenvalues and the eigenvectors.
N INTEGER
The order of the matrix A. N >= 0.
A COMPLEX*16 array, dimension (LDA, N)
The N-by-N matrix A.
LDA INTEGER
The leading dimension of A. LDA >= max(1,N).
VL COMPLEX*16 array, dimension (LDVL, N)
If SENSE = 'E' or 'B', VL is the array to store the left eigenvectors. If SENSE = 'N' or 'V', VL is not used.
LDVL INTEGER
The leading dimension of VL. LDVL >= max(1,N) if SENSE = 'E' or 'B'.
VR COMPLEX*16 array, dimension (LDVR, N)
If SENSE = 'V' or 'B', VR is the array to store the right eigenvectors. If SENSE = 'N' or 'E', VR is not used.
LDVR INTEGER
The leading dimension of VR. LDVR >= max(1,N) if SENSE = 'V' or 'B'.
LWORK INTEGER
The dimension of the array WORK. LWORK must be at least max(1,2*N) if SENSE = 'N' or 'E', and N*N+2*N if SENSE = 'V' or 'B'. For good performance, LWORK should generally be larger.
RWORK DOUBLE PRECISION array, dimension (2*N)
Workspace array.
INFO INTEGER
  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value.
  • > 0: if INFO = i, the QR algorithm failed to compute all the eigenvalues, and no eigenvectors or condition numbers have been computed; elements 1:ILO-1 and i+1:N of W contain eigenvalues which have converged.

Output Parameters

A COMPLEX*16 array, dimension (LDA, N)
If BALANC = 'S' or 'B', A is overwritten by the balanced matrix.
VL COMPLEX*16 array, dimension (LDVL, N)
If SENSE = 'E' or 'B', VL contains the left eigenvectors. The column VL(i) is the eigenvector corresponding to the eigenvalue W(i).
VR COMPLEX*16 array, dimension (LDVR, N)
If SENSE = 'V' or 'B', VR contains the right eigenvectors. The column VR(i) is the eigenvector corresponding to the eigenvalue W(i).
ILO INTEGER
IHI INTEGER
ILO and IHI are integers such that A[ILO..IHI, ILO..IHI] is in upper Hessenberg form and the lower triangular part of A has been set to zero. If BALANC = 'N' or 'P', ILO = 1, IHI = N. Otherwise, 1 <= ILO <= IHI <= N.
LSCALE DOUBLE PRECISION array, dimension (N)
This is used to scale the rows and columns of A if BALANC = 'S' or 'B'.
RCONDV DOUBLE PRECISION array, dimension (N)
RCONDV(j) is the reciprocal condition number of the j-th right eigenvector.
WORK COMPLEX*16 array, dimension (MAX(1,LWORK))
On exit, if INFO = 0, WORK(1) returns the optimal LWORK.
LWORK INTEGER
The dimension of the array WORK. If SENSE = 'N' or 'E', LWORK >= max(1,2*N), and if SENSE = 'V' or 'B', LWORK >= N*N+2*N. For good performance, LWORK must generally be larger.
If LWORK = -1, then a workspace query is assumed; the routine only calculates the optimal size of the WORK array, returns this value as the first entry of the WORK array, and no error message related to LWORK is issued by XERBLA.
RWORK DOUBLE PRECISION array, dimension (2*N)
INFO INTEGER
  • = 0: successful exit
  • < 0: if INFO = -i, the i-th argument had an illegal value.
  • > 0: if INFO = i, the QR algorithm failed to compute all the eigenvalues, and no eigenvectors or condition numbers have been computed; elements 1:ILO-1 and i+1:N of W contain eigenvalues which have converged.
