NAME

zgtsvx

the subroutine to compute the solution to a complex general tridiagonal linear system with iterative refinement

SYNOPSIS

    SUBROUTINE ZGTSVX( FACT, TRANS, N, NRHS, DL, D, DR, DLUS, DUS, DRUS,
     &                  B, LDB, X, LDX, RCOND, FERR, BERR, WORK, RWORK,
     &                  INFO )

Parameters

CHARACTER * 1 FACT

Specifies whether or not the factored form of the coefficient matrix A is supplied on the entry to ZGTSVX.

'N'
The normal equations (A T A) or (A H A) will be used.
'F'
The factored form of A will be used.

CHARACTER * 1 TRANS

Specifies the form of the system of equations to be solved.

'N'
A x = b (No transpose)
'T'
A T x = b (Transpose)
'C'
A H x = b (Conjugate transpose)

INTEGER N

The order of the coefficient matrix A. N >= 0.

INTEGER NRHS

The number of right hand sides, i.e., the number of columns of the matrices B and X. NRHS >= 0.

COMPLEX*16 DL(N)
COMPLEX*16 D(N)
COMPLEX*16 DR(N)

Represent the coefficient matrix A. DL contains the subdiagonal elements, D the diagonal elements, and DR the superdiagonal elements. The elements of DL, D, and DR must have the same storage format as elements of A. If FACT = 'F', then DL, D, and DR must contain the factors U of A as computed by ZGTTRF.

COMPLEX*16 DLUS(N)
COMPLEX*16 DUS(N)
COMPLEX*16 DRUS(N)

Represent the coefficient matrix A (if FACT = 'F'). DLUS contains the subdiagonal elements, DUS the diagonal elements, and DRUS the superdiagonal elements of the upper triangular factor U.

COMPLEX*16 B(LDB,NRHS)

The right hand side matrix B. B is not used if TRANS = 'N' and FACT = 'F'.

INTEGER LDB

The leading dimension of the array B. LDB >= max(1,N).

COMPLEX*16 X(LDX,NRHS)

On exit, the solution matrix X to the system of equations Ax = B.

INTEGER LDX

The leading dimension of the array X. LDX >= max(1,N).

DOUBLE PRECISION RCOND

An estimate of the reciprocal condition number of the matrix A for the current problem. The pair of vectors (DL, D, DR) and (DLUS, DUS, DRUS) are the factors U of A.

DOUBLE PRECISION FERR(NRHS)

On exit, FERR(j) is an estimate of the forward error bound for the j-th solution vector, X(j), of the system A*X = B. If A is sufficiently non-singular, FERR(j) is an upper bound on the j-th element of the vector norm of the error ||X(j) - XTRUE(j)|| / ||XTRUE(j)||, where XTRUE(j) is the corresponding exact solution.

DOUBLE PRECISION BERR(NRHS)

On exit, BERR(j) is the componentwise relative backward error of the j-th solution vector X(j) of the system A*X = B. BERR(j) is the value of the smallest relative perturbation in the entries of A and B, which is required to make X(j) an exact solution.

COMPLEX*16 WORK(2*N)

Workspace array. On exit, WORK(1) contains the norm of the inverted matrix A.

DOUBLE PRECISION RWORK(N)

Workspace array.

INTEGER INFO

INFO = 0: successful exit

INFO < 0: if INFO = -i, the i-th argument had an illegal value.

INFO > 0: if INFO = i, and i is <= N: U(i,i) is exactly zero. The factorization has not been completed unless i = N, but the factor U is exactly singular, so the solution and error bounds could not be computed. RCOND = 0 is returned.

INFO = N+1: U is nonsingular, but RCOND is less than machine precision, meaning that the matrix is singular to working precision. Nevertheless, the solution and error bounds are computed because there are a number of situations where the computed solution can be more accurate than the value of RCOND would suggest.
