ZGEDMD تحسب تفكيك الأنماط الديناميكي (DMD) لزوج من مصفوفات البيانات اللحظية. من أجل المصفوفات المدخلة X و Y بحيث Y = A*X مع مصفوفة A غير قابلة للوصول، تحسب ZGEDMD عددًا معينًا من أزواج ريتز من فضاء فرعي لـ range(X) الذي يتم تحديده باستخدام المتجهات المفردة اليسرى الرائدة لـ X. اختياريًا، تعيد ZGEDMD البواقي لأزواج ريتز المحسوبة، أو المعلومات اللازمة لتنقيح متجهات ريتز، أو المتجهات الذاتية لتفكيك DMD الدقيق. لمزيد من التفاصيل، انظر المراجع المدرجة أدناه. لمزيد من التفاصيل حول التنفيذ انظر [3].

ZGEDMD computes a spectral decomposition of a matrix A, which is a product of two matrices X and Y.

The matrix A is not necessarily square.

It computes the Singular Value Decomposition (SVD) of A:

A = U * Sigma * V**H

and the eigenvalue decomposition of the matrix GY = Y**H * G * X.

The decomposition is computed for the matrix product XY, which is square if M = N.

INFO

INFO (output) INTEGER

==================================================================

= 0 :: Normal return.

= < 0 :: If INFO = -i, the i-th argument had an illegal value.

= 1 :: The computation of the SVD did not converge. The error estimates are not available, and no singular values and vectors are computed.

= 2 :: The computation of the SVD did not converge. The singular values and vectors are computed, but accuracy is not guaranteed.

Suggestion: Check the input data and/or repeat with different WHTSVD.

= 3 :: The computation of the eigenvalues did not converge.

= 4 :: If data scaling was requested on input and the procedure found inconsistency in the data such that for some column index i, X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set to zero if JOBS=='C'. The computation proceeds with original or modified data and warning flag is set with INFO=4.
