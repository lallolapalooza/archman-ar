NAME

zgesdd - performs a singular value decomposition of a general complex rectangular matrix.

SYNOPSIS

SUBROUTINE ZGESDD(
   JOBZ, M, N, A, LDA, S, U, LDU, VT, LDVT, WORK, LWORK, RWORK, IWORK, INFO
)
INTEGER
   INFO, LDA, LDU, LDVT, LWORK, M, N
CHARACTER
   JOBZ
COMPLEX*16
   A( LDA, * ), S( * ), U( LDU, * ), VT( LDVT, * ), WORK( * )
DOUBLE PRECISION
   RWORK( * )
INTEGER
   IWORK( * )

Function/Subroutine Documentation

This subroutine computes the singular value decomposition (SVD) of a complex matrix A, which is distributed. The SVD is useful in a variety of applications, including: * Least squares solutions * Eigenvalue problems * Data analysis * Signal processing The subroutine ZGESDD calculates the SVD of a general m-by-n matrix A, A = U * SIGMA * V^H, where SIGMA is an m-by-n matrix with nonnegative diagonal entries, U is an m-by-m unitary matrix, and V^H is an n-by-n unitary matrix. The diagonal entries of SIGMA are the singular values of A, which are returned in the array S in descending order. The columns of U and the rows of V^H are the left and right singular vectors, respectively.
