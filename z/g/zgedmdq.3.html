zgedmdq(3)

الحزمة: lapack-doc

التراخيص: custom

SYNOPSIS

call zgedmdq( JOBQ, JOBZ, M, N, A, LDA, WHTSVD, W, S, U, LDU, V, LDV, WORK, LWORK, IWORK, LIWORK, INFO )

Function/Subroutine Documentation

Purpose

!> The subroutine ZGEDMDQ computes the singular value decomposition (SVD)
!> of a general M-by-N matrix A = U * S * V**H, and
!> of A = U * S * V**H, by computing the SVD of
!> (A - sigma*I) if sigma is given and WHTSVD is 2,3,4.
!> ZGEDMDQ computes the SVD of A, or the SVD of A-sigma*I or A*A**H
!> or A**H*A.
!> The SVD is computed by first calling ZGEDMD to compute the SVD of
!> A, or of X = A*A**H or X = A**H*A. Then, if needed, the SVD of
!> (A - sigma*I) is computed by calling ZGEDSVD.
!>
!> Descriptions of the JOBQ, JOBZ, WHTSVD, and JOBS options:
!>
!> JOBQ: Indicates whether to compute the Q matrix (the matrix V in the
!>       singular value decomposition A = U * S * V**H).
!>       JOBQ = 'N': Do not compute Q.
!>       JOBQ = 'Q': Compute Q.
!>
!> JOBZ: Indicates whether to compute the Z matrix (the matrix U in the
!>       singular value decomposition A = U * S * V**H).
!>       JOBZ = 'N': Do not compute Z.
!>       JOBZ = 'V': Compute Z.
!>       JOBZ = 'F': Compute Z and store it in A.
!>
!> WHTSVD: Specifies the computation to be performed.
!>       WHTSVD = 1: Compute the SVD of A. A = U*S*V**H.
!>       WHTSVD = 2: Compute the SVD of A*A**H. A*A**H = U*S*V**H.
!>       WHTSVD = 3: Compute the SVD of A**H*A. A**H*A = U*S*V**H.
!>       WHTSVD = 4: Compute the SVD of A - sigma*I. A - sigma*I = U*S*V**H.
!>
!> JOBS: If WHTSVD=4, JOBS='C' indicates that if data scaling was requested
!>       on input and the procedure found inconsistency in the data
!>       such that for some column index i, X(:,i) = 0 but Y(:,i) /= 0,
!>       then Y(:,i) is set to zero if JOBS=='C'. The computation proceeds
!>       with original or modified data and a warning flag is set with INFO=4.
!>       If JOBS is not 'C', no modification is done.
!>
!>
!> Details on workspace size calculation:
!> Minimal required workspace size LZWORK for the WORK array.
!> Let MINMN = MIN(M,N).
!> LZWORK = MAX(2, MIN(M,N)+MLWQR, MINMN+MLWDMD)
!> where MLWQR and MLWDMD are workspace requirements from
!> ZGEQRF and ZGEDMD respectively.
!> LZWORK is further updated as follows:
!>    if   JOBZ == 'V' or JOBZ == 'F' THEN
!>         LZWORK = MAX(LZWORK, MINMN+MLWMQR)
!>    if   JOBQ == 'Q' THEN
!>         LZWORK = MAX(LZWORK, MINMN+MLWGQR)
!>

WORK

!>    WORK (workspace/output) REAL(KIND=WP) LWORK-by-1 array
!>    On exit,
!>    WORK(1:N-1) contains the singular values of
!>    the input submatrix F(1:M,1:N-1).
!>    If the call to ZGEDMDQ is only workspace query, then
!>    WORK(1) contains the minimal workspace length and
!>    WORK(2) is the optimal workspace length. hence, the
!>    length of work is at least 2.
!>    See the description of LWORK.
!>

LWORK

!>    LWORK (input) INTEGER
!>    The minimal length of the  workspace vector WORK.
!>    LWORK is the same as in ZGEDMD, because in ZGEDMDQ
!>    only ZGEDMD requires real workspace for snapshots
!>    of dimensions MIN(M,N)-by-(N-1).
!>    If on entry LWORK = -1, then a workspace query is
!>    assumed and the procedure only computes the minimal
!>    and the optimal workspace length for WORK.
!>

IWORK

!>    IWORK (workspace/output) INTEGER LIWORK-by-1 array
!>    Workspace that is required only if WHTSVD equals
!>    2 , 3 or 4. (See the description of WHTSVD).
!>    If on entry LWORK =-1 or LIWORK=-1, then the
!>    minimal length of IWORK is computed and returned in
!>    IWORK(1). See the description of LIWORK.
!>

LIWORK

!>    LIWORK (input) INTEGER
!>    The minimal length of the workspace vector IWORK.
!>    If WHTSVD == 1, then only IWORK(1) is used; LIWORK >=1
!>    Let M1=MIN(M,N), N1=N-1. Then
!>    If WHTSVD == 2, then LIWORK >= MAX(1,8*MIN(M1,N1))
!>    If WHTSVD == 3, then LIWORK >= MAX(1,M1+N1-1)
!>    If WHTSVD == 4, then LIWORK >= MAX(3,M1+3*N1)
!>    If on entry LIWORK = -1, then a workspace query is
!>    assumed and the procedure only computes the minimal
!>    and the optimal workspace lengths for both WORK and
!>    IWORK. See the descriptions of WORK and IWORK.
!>

INFO

!>    INFO (output) INTEGER
!>    -i < 0 :: On entry, the i-th argument had an
!>              illegal value
!>       = 0 :: Successful return.
!>       = 1 :: Void input. Quick exit (M=0 or N=0).
!>       = 2 :: The SVD computation of X did not converge.
!>              Suggestion: Check the input data and/or
!>              repeat with different WHTSVD.
!>       = 3 :: The computation of the eigenvalues did not
!>              converge.
!>       = 4 :: If data scaling was requested on input and
!>              the procedure found inconsistency in the data
!>              such that for some column index i,
!>              X(:,i) = 0 but Y(:,i) /= 0, then Y(:,i) is set
!>              to zero if JOBS=='C'. The computation proceeds
!>              with original or modified data and warning
!>              flag is set with INFO=4.
!>
