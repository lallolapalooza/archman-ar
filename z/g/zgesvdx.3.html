NAME

zgesvdx - [ZGESVDX] computes the singular value decomposition (SVD) of a general M-by-N matrix

SYNOPSIS

In the calling sequence, N and M are integers and all other variables are declared as follows:

CHARACTER
*JOBUZ, JOBUQ, JOBVT
INTEGER
M, N, LDA, LDU, LDVT, LISUB, LISVB, LDWORK, INFO
COMPLEX*16
A(LDA,N), U(LDU,M), VT(LDVT,N), WORK(LDWORK)
DOUBLE PRECISION
S(MIN(M,N)), RWORK(MAX(1,2*MAX(M,N)-6))

The subroutine call is:

CALL ZGESVDX( JOBUZ, JOBUQ, JOBVT, M, N, A, LDA, S, U, LDU, VT, LDVT, WORK, LDWORK, RWORK, INFO )

Function/Subroutine Documentation

ZGESVDX computes the singular value decomposition (SVD) of a general M-by-N matrix, A, such that

A = U * S * VT

where S is an M-by-N diagonal matrix with non-negative diagonal entries, U is an M-by-M unitary matrix, and VT is an N-by-N unitary matrix (V**H, where V is N-by-N unitary).

The singular values S( i ) are computed in descending order. U and VT may be computed explicitly or may be omitted.

Note that the routine calls the following auxiliary routines:

DBDSVDX/DSTEVX

INFO
INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value
> 0: if INFO = i, then i eigenvectors failed to converge
in DBDSVDX/DSTEVX.
if INFO = N*2 + 1, an internal error occurred in
DBDSVDX
