subroutine zgesvdq (joba حرفية, jobp حرفية, jobr حرفية, jobu حرفية, jobv حرفية, m عدد صحيح, n عدد صحيح, complex*16, dimension( lda, * ) a, lda عدد صحيح, s double precision, dimension( * ) , u complex*16, dimension( ldu, * ) , ldu عدد صحيح, v complex*16, dimension( ldv, * ) , ldv عدد صحيح, numrank عدد صحيح, iwork عدد صحيح, dimension( * ) , liwork عدد صحيح, cwork complex*16, dimension( * ) , lcwork عدد صحيح, rwork double precision, dimension( * ) , lrwork عدد صحيح, info عدد صحيح)

ZGESVDQ تحسب تحليل القيم المنفردة (SVD) لمصفوفة A معقدة من النوع M-by-N، حيث M >= N. تحليل SVD للمصفوفة A يُكتب على النحو التالي: [++] [xx] [x0] [xx] A = U * SIGMA * V^*, [++] = [xx] * [ox] * [xx] [++] [xx] حيث SIGMA مصفوفة قطرية من النوع N-by-N، U مصفوفة متعامدة من النوع M-by-N، و V مصفوفة وحدوية من النوع N-by-N. العناصر القطرية لـ SIGMA هي القيم المنفردة للمصفوفة A. أعمدة U و V هي المتجهات المنفردة اليسرى واليمنى للمصفوفة A على التوالي.

الغرض:

!>
!> ZCGESVDQ تحسب تحليل القيم المنفردة (SVD) لمصفوفة A معقدة من النوع M-by-N، حيث M >= N. تحليل SVD للمصفوفة A يُكتب على النحو التالي:
!>                                    [++]   [xx]   [x0]   [xx]
!>              A = U * SIGMA * V^*,  [++] = [xx] * [ox] * [xx]
!>                                    [++]   [xx]
!> حيث SIGMA مصفوفة قطرية من النوع N-by-N، U مصفوفة متعامدة من النوع M-by-N، و V مصفوفة وحدوية من النوع N-by-N. العناصر القطرية
!> لـ SIGMA هي القيم المنفردة للمصفوفة A. أعمدة U و V هي المتجهات المنفردة اليسرى واليمنى للمصفوفة A على التوالي.
!>

NAME

zgesvdq — compute the singular value decomposition (SVD) of a general complex matrix.

SYNOPSIS

SUBROUTINE ZGESVDQ(
   JOBU, JOBV, JOBR,        INTEGER,       COMPLEX*16,       INTEGER,
   A,                       LDA,             U,                 LDU,
   VT,                      LDVT,            S,                 WORK,
   LWORK,                   INFO
   )

   CHARACTER           JOBU, JOBV, JOBR
   INTEGER             LDA, LDU, LDVT, LWORK, INFO
   COMPLEX*16          A( LDA, * ),    U( LDU, * ),    VT( LDVT, * )
   DOUBLE PRECISION     S( * ),         WORK( * )

Function/Subroutine Documentation

This routine is part of the LAPACK routines for computing the Singular Value Decomposition (SVD).

The SVD is computed using a QR-based method that is particularly useful for computing the SVD of ill-conditioned matrices. The algorithm uses a rank-revealing QR factorization to find the numerical rank of the matrix and then proceeds to compute the SVD with high accuracy.

Parameters

JOBU

!>          JOBU is CHARACTER*1
!>          Specifies whether to compute the left singular vectors (U).
!>          = 'A': The full M x M unitary matrix U is returned.
!>          = 'S': The first N columns of U (corresponding to the N singular
!>                 values) are returned in U.
!>          = 'O': The first N columns of U are returned in A.
!>          = 'N': No singular vectors are computed.
!>          = 'R': The first NUMRANK columns of U are returned in U.
!>          = 'U': The first NUMRANK columns of U are returned in U.
!>

JOBV

!>          JOBV is CHARACTER*1
!>          Specifies whether to compute the right singular vectors (V**T).
!>          = 'A': The full N x N unitary matrix V**T is returned.
!>          = 'S': The first N rows of V**T (corresponding to the N singular
!>                 values) are returned in VT.
!>          = 'O': The first N rows of V**T are returned in A.
!>          = 'N': No singular vectors are computed.
!>          = 'R': The first NUMRANK rows of V**T are returned in VT.
!>          = 'U': The first NUMRANK rows of V**T are returned in VT.
!>

JOBR

!>          JOBR is CHARACTER*1
!>          Specifies whether to compute the rank revealing QR factorization.
!>          = 'N': No rank revealing QR factorization.
!>          = 'R': Rank revealing QR factorization is computed.
!>          = 'T': Rank revealing QR factorization is computed and the matrix A
!>                 is transposed before the QR factorization.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA, N)
!>          On entry, the M x N matrix A.
!>          On exit,
!>          if JOBU = 'O', A is overwritten by the first N columns of U.
!>          if JOBV = 'O', A is overwritten by the first N rows of V**T.
!>          if both JOBU = 'O' and JOBV = 'O', A contains the first N columns
!>          of U and the first N rows of V**T.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1, M).
!>

U

!>          U is COMPLEX*16 array, dimension (LDU, M) or (LDU, N) or (LDU, NUMRANK)
!>          On exit,
!>          if JOBU = 'A', U is an M x M matrix containing the unitary matrix U.
!>          if JOBU = 'S', U is an M x N matrix containing the first N columns of U.
!>          if JOBU = 'R' or 'U', U is an M x NUMRANK matrix containing the first
!>          NUMRANK columns of U.
!>

LDU

!>          LDU is INTEGER
!>          The leading dimension of the array U.
!>          if JOBU = 'A', LDU >= max(1, M).
!>          if JOBU = 'S', LDU >= max(1, M).
!>          if JOBU = 'R' or 'U', LDU >= max(1, M).
!>

VT

!>          VT is COMPLEX*16 array, dimension (LDVT, N) or (LDVT, NUMRANK)
!>          On exit,
!>          if JOBV = 'A', VT is an N x N matrix containing the unitary matrix V**T.
!>          if JOBV = 'S', VT is an N x N matrix containing the first N rows of V**T.
!>          if JOBV = 'R' or 'U', VT is an NUMRANK x N matrix containing the first
!>          NUMRANK rows of V**T.
!>

LDVT

!>          LDVT is INTEGER
!>          The leading dimension of the array VT.
!>          if JOBV = 'A', LDVT >= max(1, N).
!>          if JOBV = 'S', LDVT >= max(1, N).
!>          if JOBV = 'R' or 'U', LDVT >= max(1, NUMRANK).
!>

S

!>          S is DOUBLE PRECISION array, dimension (min(M, N)).
!>          On exit, the singular values, sorted in descending order.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (max(1, LWORK)).
!>          On exit,
!>          1. WORK(1) contains the numerical rank, NUMRANK, determined by the
!>             rank revealing QR factorization.
!>          2. If JOBU = 'R' and JOBV = 'R', WORK(2) contains the value of
!>             NUMRANK determined from the initial QR factorization.
!>          3. If JOBA = 'E' and JOBP = 'N', WORK(3) contains an estimate of the
!>             condition number of column scaled A.
!>          4. WORK(4) contains the number of singular values computed as exact
!>             zeros in ZGESVD applied to the upper triangular or trapezoidal R
!>             (from the initial QR factorization). In case of early exit (no call
!>             to ZGESVD, such as in the case of zero matrix) WORK(4) = -1.
!>
!>          If LWORK = -1, then on exit, if INFO = 0, WORK(1) returns the minimal
!>          LWORK.
!>

LWORK

!>          LWORK is INTEGER
!>          The dimension of the array WORK.
!>          If LWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the WORK array, and no error message related to LWORK is
!>          issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if ZBDSQR did not converge, INFO specifies how many superdiagonals
!>          of an intermediate bidiagonal form B (computed in ZGESVD) did not
!>          converge to zero.
!>

Further Details:

   1. The data movement (matrix transpose) is coded using simple nested
      DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
      Those DO-loops are easily identified in this source code - by the CONTINUE
      statements labeled with 11**. In an optimized version of this code, the
      nested DO loops should be replaced with calls to an optimized subroutine.
   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
      column norm overflow. This is the minial precaution and it is left to the
      SVD routine (CGESVD) to do its own preemptive scaling if potential over-
      or underflows are detected. To avoid repeated scanning of the array A,
      an optimal implementation would do all necessary scaling before calling
      CGESVD and the scaling in CGESVD can be switched off.
   3. Other comments related to code optimization are given in comments in the
      code, enclosed in [[double brackets]].

NUMRANK

!>          NUMRANK is the numerical rank first determined after the rank
!>          revealing QR factorization, following the strategy specified by the
!>          value of JOBA. If JOBV = 'R' and JOBU = 'R', only NUMRANK
!>          leading singular values and vectors are then requested in the call
!>          of CGESVD. The final value of NUMRANK might be further reduced if
!>          some singular values are computed as zeros.
!>

IWORK

!>          IWORK is INTEGER array, dimension (max(1, LIWORK)).
!>          On exit, IWORK(1:N) contains column pivoting permutation of the
!>          rank revealing QR factorization.
!>          If JOBP = 'P', IWORK(N+1:N+M-1) contains the indices of the sequence
!>          of row swaps used in row pivoting. These can be used to restore the
!>          left singular vectors in the case JOBU = 'F'.
!>
!>          If LIWORK, LCWORK, or LRWORK = -1, then on exit, if INFO = 0,
!!>          IWORK(1) returns the minimal LIWORK.
!>

LIWORK

!>          LIWORK is INTEGER
!>          The dimension of the array IWORK.
!>          LIWORK >= N + M - 1,  if JOBP = 'P';
!>          LIWORK >= N           if JOBP = 'N'.
!>
!>          If LIWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the CWORK, IWORK, and RWORK arrays, and no error
!>          message related to LCWORK is issued by XERBLA.
!>

CWORK

!>          CWORK is COMPLEX*12 array, dimension (max(2, LCWORK)), used as a workspace.
!>          On exit, if, on entry, LCWORK.NE.-1, CWORK(1:N) contains parameters
!>          needed to recover the Q factor from the QR factorization computed by
!>          ZGEQP3.
!>
!>          If LIWORK, LCWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          CWORK(1) returns the optimal LCWORK, and
!>          CWORK(2) returns the minimal LCWORK.
!>

LCWORK

!>          LCWORK is INTEGER
!>          The dimension of the array CWORK. It is determined as follows:
!>          Let  LWQP3 = N+1,  LWCON = 2*N, and let
!>          LWUNQ = { MAX( N, 1 ),  if JOBU = 'R', 'S', or 'U'
!>          { MAX( M, 1 ),  if JOBU = 'A'
!>          LWSVD = MAX( 3*N, 1 )
!>          LWLQF = MAX( N/2, 1 ), LWSVD2 = MAX( 3*(N/2), 1 ), LWUNLQ = MAX( N, 1 ),
!>          LWQRF = MAX( N/2, 1 ), LWUNQ2 = MAX( N, 1 )
!>          Then the minimal value of LCWORK is:
!>          = MAX( N + LWQP3, LWSVD )        if only the singular values are needed;
!>          = MAX( N + LWQP3, LWCON, LWSVD ) if only the singular values are needed,
!>                                   and a scaled condition estimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD, LWUNQ ) if the singular values and the left
!>                                   singular vectors are requested;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ) if the singular values and the left
!>                                   singular vectors are requested, and also
!>                                   a scaled condition estimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD )        if the singular values and the right
!>                                   singular vectors are requested;
!>          = N + MAX( LWQP3, LWCON, LWSVD ) if the singular values and the right
!>                                   singular vectors are requested, and also
!>                                   a scaled condition etimate requested;
!>
!>          = N + MAX( LWQP3, LWSVD, LWUNQ ) if the full SVD is requested with JOBV = 'R';
!>                                   independent of JOBR;
!>          = N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ) if the full SVD is requested,
!>                                   JOBV = 'R' and, also a scaled condition
!>                                   estimate requested; independent of JOBR;
!>          = MAX( N + MAX( LWQP3, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, N/2+LWLQF, N/2+LWSVD2, N/2+LWUNLQ, LWUNQ) ) if the
!>                         full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='N'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWLQF, N/2+LWSVD2, N/2+LWUNLQ, LWUNQ ) )
!>                         if the full SVD is requested with JOBV = 'A' or 'V', and
!>                         JOBR ='N', and also a scaled condition number estimate
!>                         requested.
!>          = MAX( N + MAX( LWQP3, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, N/2+LWQRF, N/2+LWSVD2, N/2+LWUNQ2, LWUNQ ) ) if the
!>                         full SVD is requested with JOBV = 'A', 'V', and JOBR ='T'
!>          = MAX( N + MAX( LWQP3, LWCON, LWSVD, LWUNQ ),
!>         N + MAX( LWQP3, LWCON, N/2+LWQRF, N/2+LWSVD2, N/2+LWUNQ2, LWUNQ ) )
!>                         if the full SVD is requested with JOBV = 'A', 'V' and
!>                         JOBR ='T', and also a scaled condition number estimate
!>                         requested.
!>          Finally, LCWORK must be at least two: LCWORK = MAX( 2, LCWORK ).
!>
!>          If LCWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the CWORK, IWORK, and RWORK arrays, and no error
!>          message related to LCWORK is issued by XERBLA.
!>

RWORK

!>          RWORK is DOUBLE PRECISION array, dimension (max(1, LRWORK)).
!>          On exit,
!>          1. If JOBA = 'E', RWORK(1) contains an estimate of the condition
!>          number of column scaled A. If A = C * D where D is diagonal and C
!>          has unit columns in the Euclidean norm, then, assuming full column rank,
!>          N^(-1/4) * RWORK(1) <= ||pinv(C)||_2 <= N^(1/4) * RWORK(1).
!>          Otherwise, RWORK(1) = -1.
!>          2. RWORK(2) contains the number of singular values computed as
!>          exact zeros in ZGESVD applied to the upper triangular or trapezoidal
!>          R (from the initial QR factorization). In case of early exit (no call to
!>          ZGESVD, such as in the case of zero matrix) RWORK(2) = -1.
!>
!>          If LIWORK, LCWORK, or LRWORK = -1, then on exit, if INFO = 0,
!>          RWORK(1) returns the minimal LRWORK.
!>

LRWORK

!>          LRWORK is INTEGER.
!>          The dimension of the array RWORK.
!>          If JOBP ='P', then LRWORK >= MAX(2, M, 5*N);
!>          Otherwise, LRWORK >= MAX(2, 5*N).
!>
!>          If LRWORK = -1, then a workspace query is assumed; the routine
!>          only calculates and returns the optimal and minimal sizes
!>          for the CWORK, IWORK, and RWORK arrays, and no error
!>          message related to LCWORK is issued by XERBLA.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit.
!>          < 0:  if INFO = -i, the i-th argument had an illegal value.
!>          > 0:  if ZBDSQR did not converge, INFO specifies how many superdiagonals
!>          of an intermediate bidiagonal form B (computed in ZGESVD) did not
!>          converge to zero.
!>

Further Details:

!>
!>   1. The data movement (matrix transpose) is coded using simple nested
!>   DO-loops because BLAS and LAPACK do not provide corresponding subroutines.
!>   Those DO-loops are easily identified in this source code - by the CONTINUE
!>   statements labeled with 11**. In an optimized version of this code, the
!>   nested DO loops should be replaced with calls to an optimized subroutine.
!>   2. This code scales A by 1/SQRT(M) if the largest ABS(A(i,j)) could cause
!>   column norm overflow. This is the minial precaution and it is left to the
!>   SVD routine (CGESVD) to do its own preemptive scaling if potential over-
!>   or underflows are detected. To avoid repeated scanning of the array A,
!>   an optimal implementation would do all necessary scaling before calling
!>   CGESVD and the scaling in CGESVD can be switched off.
!>   3. Other comments related to code optimization are given in comments in the
!>   code, enclosed in [[double brackets]].
!>
