ZGGSVP3

الغرض:

!>
!> ZGGSVP3 تحسب مصفوفات وحدوية U، V و Q بحيث
!>
!>                    N-K-L  K    L
!>  U**H*A*Q =     K ( 0    A12  A13 )  إذا كان M-K-L >= 0؛
!>                 L ( 0     0   A23 )
!>             M-K-L ( 0     0    0  )
!>
!>                  N-K-L  K    L
!>         =     K ( 0    A12  A13 )  إذا كان M-K-L < 0؛
!>             M-K ( 0     0   A23 )
!>
!>                  N-K-L  K    L
!>  V**H*B*Q =   L ( 0     0   B13 )
!>             P-L ( 0     0    0  )
!>
!> حيث المصفوفة A12 بحجم KxK والمصفوفة B13 بحجم LxL غير مفردة
!> علوية مثلثة؛ A23 هي علوية مثلثة بحجم LxL إذا كان M-K-L >= 0،
!> بخلاف ذلك A23 هي شبه منحرف علوي بحجم (M-K)xL. K+L = الرتبة العددية الفعلية
!> للمصفوفة (A**H,B**H)**H بحجم (M+P)xN.
!>
!> هذا التحليل هو خطوة المعالجة المسبقة لحساب تحليل القيمة المتفردة المعمم (GSVD)، انظر الروتين الفرعي
!> ZGGSVD3.
!>

المعلمات

JOBU 
!>          JOBU هو CHARACTER*1
!>          = 'U':  تحسب المصفوفة الوحدوية U؛
!>          = 'N':  لا تحسب U.
!>

JOBV

!>          JOBV هو CHARACTER*1
!>          = 'V':  تحسب المصفوفة الوحدوية V؛
!>          = 'N':  لا تحسب V.
!>

JOBQ

!>          JOBQ هو CHARACTER*1
!>          = 'Q':  تحسب المصفوفة الوحدوية Q؛
!>          = 'N':  لا تحسب Q.
!>

M

!>          M هو INTEGER
!>          عدد صفوف المصفوفة A. M >= 0.
!>

P

!>          P هو INTEGER
!>          عدد صفوف المصفوفة B. P >= 0.
!>

N

!>          N هو INTEGER
!>          عدد أعمدة المصفوفتين A و B. N >= 0.
!>

A

!>          A هي مصفوفة COMPLEX*16، البعد (LDA,N)
!>          عند الدخول، المصفوفة A بحجم M*N.
!>          عند الخروج، تحتوي A على المصفوفة المثلثية (أو شبه المنحرفة)
!>          الموصوفة في قسم الغرض.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي للمصفوفة A. LDA >= max(1,M).
!>

B

!>          B هي مصفوفة COMPLEX*16، البعد (LDB,N)
!>          عند الدخول، المصفوفة B بحجم P*N.
!>          عند الخروج، تحتوي B على المصفوفة المثلثية الموصوفة في
!>          قسم الغرض.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرئيسي للمصفوفة B. LDB >= max(1,P).
!>

TOLA

!>          TOLA هو DOUBLE PRECISION
!>

TOLB

!>          TOLB هو DOUBLE PRECISION
!>
!>          TOLA و TOLB هما العتبتان لتحديد الرتبة العددية الفعلية
!>          للمصفوفة B ولبلوك فرعي من A. بشكل عام،
!>             TOLA = MAX(M,N)*norm(A)*MAZHEPS،
!>             TOLB = MAX(P,N)*norm(B)*MAZHEPS.
!>          قد يؤثر حجم TOLA و TOLB على حجم الأخطاء الخلفية للتحليل.
!>

K

!>          K هو INTEGER
!>

L

!>          L هو INTEGER
!>
!>          عند الخروج، تحدد K و L أبعاد البلوكات الفرعية
!>          الموصوفة في قسم الغرض.
!>          K + L = الرتبة العددية الفعلية لـ (A**H,B**H)**H.
!>

U

!>          U هي مصفوفة COMPLEX*16، البعد (LDU,M)
!>          إذا كان JOBU = 'U'، تحتوي U على المصفوفة الوحدوية U.
!>          إذا كان JOBU = 'N'، لا يتم استخدام U.
!>

LDU

!>          LDU هو INTEGER
!>          البعد الرئيسي للمصفوفة U. LDU >= max(1,M) إذا
!>          كان JOBU = 'U'؛ LDU >= 1 بخلاف ذلك.
!>

V

!>          V هي مصفوفة COMPLEX*16، البعد (LDV,P)
!>          إذا كان JOBV = 'V'، تحتوي V على المصفوفة الوحدوية V.
!>          إذا كان JOBV = 'N'، لا يتم استخدام V.
!>

LDV

!>          LDV هو INTEGER
!>          البعد الرئيسي للمصفوفة V. LDV >= max(1,P) إذا
!>          كان JOBV = 'V'؛ LDV >= 1 بخلاف ذلك.
!>

Q

!>          Q هي مصفوفة COMPLEX*16، البعد (LDQ,N)
!>          إذا كان JOBQ = 'Q'، تحتوي Q على المصفوفة الوحدوية Q.
!>          إذا كان JOBQ = 'N'، لا يتم استخدام Q.
!>

LDQ

!>          LDQ هو INTEGER
!>          البعد الرئيسي للمصفوفة Q. LDQ >= max(1,N) إذا
!>          كان JOBQ = 'Q'؛ LDQ >= 1 بخلاف ذلك.
!>

IWORK

!>          IWORK هي مصفوفة INTEGER، البعد (N)
!>

RWORK

!>          RWORK هي مصفوفة DOUBLE PRECISION، البعد (2*N)
!>

TAU

!>          TAU هي مصفوفة COMPLEX*16، البعد (N)
!>

WORK

!>          WORK هي مصفوفة COMPLEX*16، البعد (MAX(1,LWORK))
!>          عند الخروج، إذا كان INFO = 0، فإن WORK(1) يعيد LWORK الأمثل.
!>

LWORK

!>          LWORK هو INTEGER
!>          بعد المصفوفة WORK. LWORK >= 1.
!>
!>          إذا كان LWORK = -1، فيفترض استعلام عن مساحة العمل؛ الروتين
!>          يحسب فقط الحجم الأمثل لمصفوفة WORK، ويعيد
!>          هذه القيمة كالإدخال الأول لمصفوفة WORK، ولا يصدر XERBLA أي رسالة خطأ
!>          متعلقة بـ LWORK.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعلمة i كانت قيمة غير قانونية.
!>
