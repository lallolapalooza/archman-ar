zgghd3(3)

الاسم

zgghd3 - تنسيق لدالة LAPACK للتعامل مع مشكلة القيم الذاتية المعممة.

الملخص

SUBROUTINE zgghd3(A, B, C, D, Q, Z, WORK, LWORK, INFO)

COMPLEX*16, dimension(lda,*) :: A

COMPLEX*16, dimension(ldb,*) :: B

COMPLEX*16, dimension(ldc,*) :: C

COMPLEX*16, dimension(ldd,*) :: D

COMPLEX*16, dimension(*) :: Q

COMPLEX*16, dimension(*) :: Z

COMPLEX*16, dimension(*) :: WORK

INTEGER lda, ldb, ldc, ldd, lwork, INFO

توثيق الدوال/الروتينات الفرعية

zgghd3 هي روتين فرعي في مكتبة LAPACK يستخدم لتقليل مشكلة القيم الذاتية المعممة (Generalized Eigenvalue Problem) إلى شكلها المبدئي.

المعاملات:

  • A: مصفوفة على شكل الجزء العلوي المثلثي، يتم تحديثها.
  • B: مصفوفة على شكل الجزء السفلي المثلثي، يتم تحديثها.
  • C: مصفوفة عادية، يتم تحديثها.
  • D: مصفوفة عادية، يتم تحديثها.
  • Q: مصفوفة الوحدة من الجزء الأيسر، يتم حسابها.
  • Z: مصفوفة الوحدة من الجزء الأيمن، يتم حسابها.
  • WORK: مخزن مؤقت للعمل.
  • LWORK: حجم المخزن المؤقت للعمل.
  • INFO: قيمة عددية تشير إلى حالة الخروج.

وصف عام:

يهدف هذا الروتين إلى تطبيق تحويلات وحدوية على المصفوفات A و B لتقليلها إلى الصيغة:

Q * A * Z = C

Q * B * Z = D

حيث C و D مصفوفتان مثلثيتان.

المؤلف

مكتبة LAPACK.
