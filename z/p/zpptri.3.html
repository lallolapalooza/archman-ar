توثيق الوظيفة/الروتين الفرعي

subroutine zpptri (character uplo, integer n, complex*16, dimension( * ) ap, integer info)

ZPPTRI

الغرض:

!>
!> ZPPTRI يحسب معكوس مصفوفة هيرميتية موجبة محددة A باستخدام تحليل تشوليسكي A = U**H*U أو A = L*L**H
!> الذي تم حسابه بواسطة ZPPTRF.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  يتم تخزين العامل المثلثي العلوي في AP؛
!>          = 'L':  يتم تخزين العامل المثلثي السفلي في AP.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A. N >= 0.
!>

AP

!>          AP is COMPLEX*16 array, dimension (N*(N+1)/2)
!>          عند الإدخال، العامل المثلثي U أو L من تحليل تشوليسكي
!>          A = U**H*U أو A = L*L**H، مجمعة عموديًا كسلسلة خطية.
!>          يتم تخزين العمود j من U أو L في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = U(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = L(i,j) لـ j<=i<=n.
!>
!>          عند الخروج، المثلث العلوي أو السفلي لمعكوس A (الهيرميتي)
!>          يكتب فوق العامل المدخل U أو L.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن العنصر (i,i) للعامل U أو L هو
!>                صفر، ولم يمكن حساب المعكوس.
!>
