Function/Subroutine Documentation

!> @brief Solves a system of linear equations AX = B with a symmetric positive
!>        definite matrix A, and provides a normwise and componentwise
!>        error estimate, and compares the error estimates with the error
!>        bound.
!>
!> @param PATH The path to the LAPACK routines.
!> @param TRANS The character string specifying the form of the system of
!>        equations.
!> @param N The number of rows and columns of the matrix A.
!> @param NRHS The number of right-hand sides.
!> @param A The symmetric positive definite matrix A of size N x N.
!> @param LDA The leading dimension of the array A.
!> @param AF The L-factor of the Cholesky factorization of A.
!> @param LDAF The leading dimension of the array AF.
!> @param IPIV The pivot indices from the factorization of A.
!> @param EQNRHS Flag indicating whether the right-hand side B is scaled
!!>        such that the solution X is equal to the exact solution.
!> @param RCOND The condition number of the matrix A.
!> @param SRCOND The scaled condition number of the matrix A.
!> @param B The right-hand side matrix B of size N x NRHS.
!> @param LDB The leading dimension of the array B.
!> @param X The solution matrix X of size N x NRHS.
!> @param LDX The leading dimension of the array X.
!> @param WORK The work array.
!> @param LWORK The dimension of the work array.
!> @param RWORK The real work array.
!> @param INFO The output information.
!>
!> @details
!> The routine ZPOSVXX computes the solution to a system of linear equations
!!> AX = B where A is a symmetric positive-definite matrix. It also computes
!> an estimate of the relative condition number of A, and the
!> error bounds:
!> ERR_BNDS_NORM(J,1) = min { U_J, J+1 }
!> ERR_BNDS_COMP(J,1) = min { U_J, J+1 }
!> where U_J is the J-th column of U, and U is the U-th column of the matrix
!> U.
!>
!> PARAMS(3) controls the output of the error bound.
!> If PARAMS(3) = 1.0 (default), J is the smallest integer such that
!> ERR_BNDS_NORM(J,1) = 0.0 or ERR_BNDS_COMP(J,1) = 0.0.
!> If PARAMS(3) = 0.0, J is the smallest integer such that
!> ERR_BNDS_NORM(J,1) = 0.0.
!>
!> The condition number is computed as
!>          RCOND = 1.0 / (smallest element of the array inv(A)*A)
!>          SRCOND = RCOND / N
!>
!> The error bound is computed as
!> ERR_BNDS_NORM(J,1) = min { U_J, J+1 }
!> ERR_BNDS_COMP(J,1) = min { U_J, J+1 }
!>
!> If PARAMS(3) = 1.0 (default), J is the smallest index such that
!> ERR_BNDS_NORM(J,1) = 0.0 or ERR_BNDS_COMP(J,1) = 0.0.
!> If PARAMS(3) = 0.0, J is the smallest index such that
!> ERR_BNDS_NORM(J,1) = 0.0.
!>
!> The value J is the smallest integer
!> !>         that ERR_BNDS_NORM(J,1) = 0.0). By default (PARAMS(3) = 1.0)
!>         the Jth right-hand side is the first with either a normwise or
!>         componentwise error bound that is not guaranteed (the smallest
!>         J such that either ERR_BNDS_NORM(J,1) = 0.0 or
!>         ERR_BNDS_COMP(J,1) = 0.0). See the definition of
!>         ERR_BNDS_NORM(:,1) and ERR_BNDS_COMP(:,1). To get information
!>         about all of the right-hand sides check ERR_BNDS_NORM or
!>         ERR_BNDS_COMP.
!>
