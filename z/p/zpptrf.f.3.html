توثيق الوظيفة/الإجراء الفرعي

subroutine zpptrf (character uplo, integer n, complex*16, dimension( * ) ap, integer info)

ZPPTRF

الغرض:

!>
!> ZPPTRF تحسب تحليل Cholesky لمصفوفة A الهرميتية الموجبة المحددة المعقدة والمخزنة بتنسيق مضغوط.
!>
!> التحليل له الشكل
!>    A = U**H * U,  إذا كان UPLO = 'U', أو
!>    A = L  * L**H,  إذا كان UPLO = 'L',
!> حيث U مصفوفة مثلثية عليا و L مصفوفة مثلثية سفلى.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  يتم تخزين المثلث العلوي لـ A؛
!>          = 'L':  يتم تخزين المثلث السفلي لـ A؛
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A. N >= 0.
!>

AP

!>          AP هو مصفوفة COMPLEX*16، البعد (N*(N+1)/2)
!>          عند الإدخال، المثلث العلوي أو السفلي للمصفوفة الهرميتية
!>          A، مضغوطة عمودياً في مصفوفة خطية. يتم تخزين العمود j من A
!>          في المصفوفة AP كالتالي:
!>          إذا كان UPLO = 'U', AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L', AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>          انظر أدناه لمزيد من التفاصيل.
!>
!>          عند الخروج، إذا كان INFO = 0، العامل المثلثي U أو L من
!>          تحليل Cholesky A = U**H*U أو A = L*L**H، بنفس
!>          تنسيق التخزين مثل A.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، كانت الوسيطة i ذات قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن الجزء الرئيسي الرائد من الرتبة i
!>                ليس موجباً، ولم يكن من الممكن إكمال التحليل.
!>

!>
!>  نظام التخزين المضغوط موضح بالمثال التالي
!>  عندما N = 4، UPLO = 'U':
!>
!>  التخزين ثنائي الأبعاد للمصفوفة الهرميتية A:
!>
!>     a11 a12 a13 a14
!>         a22 a23 a24
!>             a33 a34     (aij = conjg(aji))
!>                 a44
!>
!>  التخزين المضغوط للمثلث العلوي لـ A:
