subroutine zptt01 (integer n, double precision, dimension( * ) d, complex*16, dimension( * ) e, double precision, dimension( * ) df, complex*16, dimension( * ) ef, complex*16, dimension( * ) work, double precision resid)

ZPTT01

الغرض:

!>
!> ZPTT01 يعيد بناء مصفوفة ثلاثية قطرية A من تحليلها L*D*L' ويحسب الباقي
!>    norm(L*D*L' - A) / ( n * norm(A) * EPS )،
!> حيث EPS هو خطأ الآلة.
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>          ترتيب المصفوفة A.
!>

D

!>          D هو مصفوفة ذات دقة مزدوجة (DOUBLE PRECISION)، الأبعاد (N)
!>          العناصر القطرية n للمصفوفة ثلاثية القطرية A.
!>

E

!>          E هو مصفوفة مركبة*16 (COMPLEX*16)، الأبعاد (N-1)
!>          العناصر تحت القطرية (n-1) للمصفوفة ثلاثية القطرية A.
!>

DF

!>          DF هو مصفوفة ذات دقة مزدوجة (DOUBLE PRECISION)، الأبعاد (N)
!>          العناصر القطرية n للعامل L من تحليل L*D*L'
!>          للمصفوفة A.
!>

EF

!>          EF هو مصفوفة مركبة*16 (COMPLEX*16)، الأبعاد (N-1)
!>          العناصر تحت القطرية (n-1) للعامل L من
!>          تحليل L*D*L' للمصفوفة A.
!>

WORK

!>          WORK هي مصفوفة مركبة*16 (COMPLEX*16)، الأبعاد (2*N)
!>

RESID

!>          RESID هي دقة مزدوجة (DOUBLE PRECISION)
!>          norm(L*D*L' - A) / (n * norm(A) * EPS)
!>
