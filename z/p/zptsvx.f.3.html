ZPTSVX(3)

NAME

ZPTSVX - ZPTSVX computes the solution to a complex system of linear equations $Ax=b$ when $A$ is a general tridiagonal matrix with symmetric matrix $A$.

SYNOPSIS

SUBROUTINE ZPTSVX(
                 FACT, UPLO, N, NRHS, D, E, AF, LDAF, BSE, LD B,
                 X, LDX, RCOND, FERR, BERR, INFO )

    CHARACTER(LEN=1)    FACT, UPLO
    INTEGER             N, NRHS, LDAF, LDB, LDX
    DOUBLE PRECISION    D( * ), E( * ), AF( LDAF, * ), BSE( LDB, * ),
                         X( LDX, * ), RCOND, FERR( * ), BERR( * )
    INTEGER             INFO

Function/Subroutine Documentation

The routine ZPTSVX computes the solution to a complex system of linear equations $Ax=b$ when $A$ is a general tridiagonal matrix. This routine is generally the fastest way to solve this system. However, it is less accurate than the full reordering routine ZPTTRF.

The problem is solved by first calling the routines ZPTTRF and ZPTTTRF to factorize the matrix A. The factorization is in the form $A = P L U$, where $P$ is a permutation matrix, $L$ is lower triangular with unit diagonal entries, and $U$ is upper triangular. The solution is then computed by calling the routines ZPTTTRS and ZPTTRS to solve the triangular systems $Ly = Pb$ and $Ux = y$, respectively. The routine ZPTSVX provides the following options: - FACT = 'N': Computes the factorization and solves the system. - FACT = 'F': Assumes that the factorization is already computed and solves the system. The routine ZPTSVX can be used to compute an error bound for the solution. The error bound is computed by calling the routines ZPTGECO and ZPTTRS. The routine ZPTSVX has the following arguments: - FACT: CHARACTER*1. Specifies whether or not the factorization of A is supplied on entry. = 'N': The routine ZPTTRF will be called to compute the factorization. = 'F': The factorization of A is supplied on entry in AF. - UPLO: CHARACTER*1. Specifies whether A is upper or lower triangular. = 'U': A is upper triangular. = 'L': A is lower triangular. - N: INTEGER. The order of the matrix A. N >= 0. - NRHS: INTEGER. The number of right-hand sides, i.e., the number of columns in the arrays B and X. NRHS >= 0. - D: DOUBLE PRECISION array, dimension (N). The diagonal entries of the tridiagonal matrix A. - E: DOUBLE PRECISION array, dimension (N-1). The off-diagonal entries of the tridiagonal matrix A. - AF: DOUBLE PRECISION array, dimension (LDAF,N). If FACT = 'F', AF contains the factorization of A, computed by ZPTTRF. - LDAF: INTEGER. The leading dimension of the array AF. LDAF >= max(1,N). - B: DOUBLE PRECISION array, dimension (LDB,NRHS). The right-hand side matrix B. - LDB: INTEGER. The leading dimension of the array B. LDB >= max(1,N). - X: DOUBLE PRECISION array, dimension (LDX,NRHS). The solution matrix X. - LDX: INTEGER. The leading dimension of the array X. LDX >= max(1,N). - RCOND: DOUBLE PRECISION. The reciprocal of the condition number of A. - FERR: DOUBLE PRECISION array, dimension (NRHS). The forward error bound for each solution vector X( ,I). - BERR: DOUBLE PRECISION array, dimension (NRHS). The backward error bound for each solution vector X( ,I). - INFO: INTEGER. = 0: successful exit. < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i, U(i,i) is zero and the factorisation was not completed.
