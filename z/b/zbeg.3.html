DESCRIPTION

The ZCHK routines are called by the driver routines ZRUN to test the various BLAS level 2 routines.

The arguments to ZCHK routines are as follows:

SNAME Character*6. The name of the routine being tested.

EPS Double precision. The value of epsilon, the machine precision.

THRESH Double precision. The threshold used to determine if a test ratio is too large.

NOUT Integer. The unit number on which error messages will be printed.

NTRA Integer. The unit number on which trace information will be printed.

TRACE Logical. If .TRUE., then trace information is printed.

REWI Logical. If .TRUE., then the trace output file is rewound before each call.

FATAL Logical. If .TRUE., then the program will terminate if an error is found.

NIDIM Integer. The number of values of N to be tested.

IDIM Integer array dimension( NIDIM ). The values of N to be tested.

NKB Integer. The number of values of K to be tested.

KB Integer array dimension( NKB ). The values of K to be tested.

NALF Integer. The number of values of ALPHA to be tested.

ALF Complex*16 array dimension( NALF ). The values of ALPHA to be tested.

NBET Integer. The number of values of BETA to be tested.

BET Complex*16 array dimension( NBET ). The values of BETA to be tested.

NINC Integer. The number of values of INCX and INCY to be tested.

INC Integer array dimension( NINC ). The values of INCX and INCY to be tested.

NMAX Integer. The maximum value of N that will be used.

INCMAX Integer. The maximum value of INCX and INCY that will be used.

A Complex*16 array dimension( NMAX, NMAX ). The matrix A.

AA Complex*16 array dimension( NMAX*NMAX ). The matrix A (column-major order).

AS Complex*16 array dimension( NMAX*NMAX ). The matrix A (symmetric/Hermitian part).

X Complex*16 array dimension( NMAX ). The vector X.

XX Complex*16 array dimension( NMAX*INCMAX ). The vector X (column-major order).

XS Complex*16 array dimension( NMAX*INCMAX ). The vector X (scaled).

Y Complex*16 array dimension( NMAX ). The vector Y.

YY Complex*16 array dimension( NMAX*INCMAX ). The vector Y (column-major order).

YS Complex*16 array dimension( NMAX*INCMAX ). The vector Y (scaled).

YT Complex*16 array dimension( NMAX ). The vector Y (transposed/conjugate transposed).

G Double precision array dimension( NMAX ). The expected result.

Z Complex*16 array dimension( NMAX ). The actual result.
