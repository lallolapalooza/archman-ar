ZBBCSD

الغرض:

!>
!> ZBBCSD يحسب تفكيك CS لمصفوفة موحدة في شكل قطر ثنائي كتلي،
!>
!>
!>     [ B11 | B12 0  0 ]
!>     [  0  |  0 -I  0 ]
!> X = [----------------]
!>     [ B21 | B22 0  0 ]
!>     [  0  |  0  0  I ]
!>
!>                               [  C | -S  0  0 ]
!>                   [ U1 |    ] [  0 |  0 -I  0 ] [ V1 |    ]**H
!>                 = [---------] [---------------] [---------]   .
!>                   [    | U2 ] [  S |  C  0  0 ] [    | V2 ]
!>                               [  0 |  0  0  I ]
!>
!> X هي M-by-M، وكتلتها اليسرى العلوية هي P-by-Q، ويجب أن يكون Q أصغر من أو يساوي
!> P، M-P، أو M-Q. (إذا لم يكن Q هو المؤشر الأصغر، فيجب تبديل أو
!> إعادة ترتيب X. يمكن القيام بذلك في وقت ثابت باستخدام
!> خيارات TRANS وSIGNS. انظر ZUNCSD للحصول على التفاصيل.)
!>
!> المصفوفات القطرية الثنائية B11، B12، B21، و B22 ممثلة
!> ضمنيًا بالزوايا THETA(1:Q) و PHI(1:Q-1).
!>
!> المصفوفات الموحدة U1، U2، V1T، و V2T هي مدخلات/مخرجات.
!> يتم ضرب المصفوفات المدخلة مسبقًا أو لاحقًا بمصفوفات المتجهات المنفردة المناسبة.
!>

المعاملات

JOBU1 
!>          JOBU1 هو CHARACTER
!>          = 'Y':      يتم تحديث U1؛
!>          بخلاف ذلك:  لا يتم تحديث U1.
!>

JOBU2

!>          JOBU2 هو CHARACTER
!>          = 'Y':      يتم تحديث U2؛
!>          بخلاف ذلك:  لا يتم تحديث U2.
!>

JOBV1T

!>          JOBV1T هو CHARACTER
!>          = 'Y':      يتم تحديث V1T؛
!>          بخلاف ذلك:  لا يتم تحديث V1T.
!>

JOBV2T

!>          JOBV2T هو CHARACTER
!>          = 'Y':      يتم تحديث V2T؛
!>          بخلاف ذلك:  لا يتم تحديث V2T.
!>

TRANS

!>          TRANS هو CHARACTER
!>          = 'T':      يتم تخزين X، U1، U2، V1T، و V2T بترتيب الصفوف
!>                      (row-major)؛
!>          بخلاف ذلك:  يتم تخزين X، U1، U2، V1T، و V2T بترتيب الأعمدة
!>                      (column-major).
!>

M

!>          M هو INTEGER
!>          عدد الصفوف والأعمدة في X، المصفوفة الموحدة
!>          في شكل كتلة قطرية ثنائية.
!>

P

!>          P هو INTEGER
!>          عدد الصفوف في الكتلة اليسرى العلوية من X. 0 <= P <= M.
!>

Q

!>          Q هو INTEGER
!>          عدد الأعمدة في الكتلة اليسرى العلوية من X.
!>          0 <= Q <= MIN(P,M-P,M-Q).
!>

THETA

!>          THETA هو مصفوفة DOUBLE PRECISION، البعد (Q)
!>          عند الدخول، الزوايا THETA(1)،...،THETA(Q) التي، جنبًا إلى جنب مع
!>          PHI(1)، ...، PHI(Q-1)، تحدد المصفوفة في شكل كتلة قطرية ثنائية.
!>          عند الخروج، الزوايا التي تحدد جيب تمامها وجيبها
!>          الكتل القطرية في تفكيك CS.
!>

PHI

!>          PHI هو مصفوفة DOUBLE PRECISION، البعد (Q-1)
!>          الزوايا PHI(1)،...،PHI(Q-1) التي، جنبًا إلى جنب مع THETA(1)،...،
!>          THETA(Q)، تحدد المصفوفة في شكل كتلة قطرية ثنائية.
!>

U1

!>          U1 هو مصفوفة COMPLEX*16، البعد (LDU1,P)
!>          عند الدخول، مصفوفة P-by-P. عند الخروج، يتم ضرب U1
!>          بشكل لاحق بمصفوفة المتجهات المنفردة اليسرى المشتركة بين [ B11 ; 0 ] و
!>          [ B12 0 0 ; 0 -I 0 0 ].
!>

LDU1

!>          LDU1 هو INTEGER
!>          البعد الرئيسي للمصفوفة U1، LDU1 >= MAX(1,P).
!>

U2

!>          U2 هو مصفوفة COMPLEX*16، البعد (LDU2,M-P)
!>          عند الدخول، مصفوفة (M-P)-by-(M-P). عند الخروج، يتم
!>          ضرب U2 بشكل لاحق بمصفوفة المتجهات المنفردة اليسرى المشتركة بين
!>          [ B21 ; 0 ] و [ B22 0 0 ; 0 0 I ].
!>

LDU2

!>          LDU2 هو INTEGER
!>          البعد الرئيسي للمصفوفة U2، LDU2 >= MAX(1,M-P).
!>

V1T

!>          V1T هو مصفوفة COMPLEX*16، البعد (LDV1T,Q)
!>          عند الدخول، مصفوفة Q-by-Q. عند الخروج، يتم ضرب V1T
!>          مسبقًا بمرافق المنقول للمتجهات المنفردة اليمنى
!>          المشتركة بين [ B11 ; 0 ] و [ B21 ; 0 ].
!>

LDV1T

!>          LDV1T هو INTEGER
!>          البعد الرئيسي للمصفوفة V1T، LDV1T >= MAX(1,Q).
!>

V2T

!>          V2T هو مصفوفة COMPLEX*16، البعد (LDV2T,M-Q)
!>          عند الدخول، مصفوفة (M-Q)-by-(M-Q). عند الخروج، يتم
!>          ضرب V2T مسبقًا بمرافق المنقول للمتجهات المنفردة اليمنى
!>          المشتركة بين [ B12 0 0 ; 0 -I 0 ] و
!>          [ B22 0 0 ; 0 0 I ].
!>

LDV2T

!>          LDV2T هو INTEGER
!>          البعد الرئيسي للمصفوفة V2T، LDV2T >= MAX(1,M-Q).
!>

B11D

!>          B11D هو مصفوفة DOUBLE PRECISION، البعد (Q)
!>          عندما تتقارب ZBBCSD، تحتوي B11D على جيب تمام الزوايا THETA(1)،
!>          ...، THETA(Q). إذا فشلت ZBBCSD في التقارب، فإن B11D
!>          تحتوي على القطر الرئيسي للكتلة اليسرى العلوية المختزلة جزئيًا.
!>

B11E

!>          B11E هو مصفوفة DOUBLE PRECISION، البعد (Q-1)
!>          عندما تتقارب ZBBCSD، تحتوي B11E على الأصفار. إذا فشلت ZBBCSD
!>          في التقارب، فإن B11E تحتوي على القطر العلوي الفائق للكتلة
!>          اليسرى العلوية المختزلة جزئيًا.
!>

B12D

!>          B12D هو مصفوفة DOUBLE PRECISION، البعد (Q)
!>          عندما تتقارب ZBBCSD، تحتوي B12D على جيب الزوايا السالب THETA(1)،
!>          ...، THETA(Q). إذا فشلت ZBBCSD في التقارب، فإن
!>          B12D تحتوي على القطر الرئيسي للكتلة اليمنى العلوية المختزلة جزئيًا.
!>

B12E

!>          B12E هو مصفوفة DOUBLE PRECISION، البعد (Q-1)
!>          W
