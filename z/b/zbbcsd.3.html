NAME

ZBBCSD - computes the complete CS decomposition of two complex 2-by-2 block matrices

SYNOPSIS

SUBROUTINE ZBBCSD(
 JOBU, JOBV, JOBQ, M, N, A11, LDA11, A12, LDA12, A21, LDA21, A22, LDA22,
 THETA, PHI, U11, LDU11, U12, LDU12, U21, LDU21, U22, LDU22, V11, LDV11,
 V12, LDV12, V21, LDV21, V22, LDV22, Q11, Q12, Q21, Q22, RWORK, LRWORK,
 INFO
)
CHARACTER * 1 JOBU, JOBV, JOBQ
INTEGER M, N, LDA11, LDA12, LDA21, LDA22, LDU11, LDU12, LDU21, LDU22,
 LDV11, LDV12, LDV21, LDV22, LRWORK, INFO
COMPLEX*16 A11( LDA11, * ), A12( LDA12, * ), A21( LDA21, * ),
 A22( LDA22, * ), U11( LDU11, * ), U12( LDU12, * ), U21( LDU21, * ),
 U22( LDU22, * ), V11( LDV11, * ), V12( LDV12, * ), V21( LDV21, * ),
 V22( LDV22, * ), Q11( * ), Q12( * ), Q21( * ), Q22( * )
DOUBLE PRECISION THETA( * ), PHI( * ), RWORK( * )

Function/Subroutine Documentation

ZBBCSD computes the complete CS decomposition of two complex 2-by-2 block matrices.

Let A = [ A11 A12 ] and B = [ A21 A22 ] be two matrices where A11, A12, A21, A22 and A21, A22, A11, A12 are of size M-by-Q and N-Q by Q respectively. ZBBCSD computes the CS decomposition

A = U * [ R     0   ] * V'
        [ 0     I   ]
B = U * [ 0     I   ] * V'
        [ S     0   ]

where U and V are unitary matrices, R and S are diagonal matrices.

This routine is the wrapper for the recursive subroutine ZBB CSD, and does not perform the CS decomposition itself. It is called by the user routines.

Arguments:

JOBU

 JOBU is CHARACTER*1
 = 'U':  Unitary matrix U is computed.
 = 'N':  Unitary matrix U is not computed.

JOBV

 JOBV is CHARACTER*1
 = 'V':  Unitary matrix V is computed.
 = 'N':  Unitary matrix V is not computed.

JOBQ

 JOBQ is CHARACTER*1
 = 'Q':  Unitary matrices Q11, Q12, Q21, Q22 are computed.
 = 'N':  Unitary matrices Q11, Q12, Q21, Q22 are not computed.

M

 M is INTEGER
 The number of rows of A11, A12, A21, A22. M >= 0.

N

 N is INTEGER
 The number of columns of A11, A21. N >= 0.

A11

 A11 is COMPLEX*16 array, dimension (LDA11, K)
 where K = N - Q.
 The M-by-K part of the first block of the matrix A.

LDA11

 LDA11 is INTEGER
 The leading dimension of the array A11. LDA11 >= M.

A12

 A12 is COMPLEX*16 array, dimension (LDA12, Q)
 The M-by-Q part of the second block of the matrix A.

LDA12

 LDA12 is INTEGER
 The leading dimension of the array A12. LDA12 >= M.

A21

 A21 is COMPLEX*16 array, dimension (LDA21, K)
 The (N-Q)-by-K part of the first block of the matrix B.

LDA21

 LDA21 is INTEGER
 The leading dimension of the array A21. LDA21 >= N-Q.

A22

 A22 is COMPLEX*16 array, dimension (LDA22, Q)
 The (N-Q)-by-Q part of the second block of the matrix B.

LDA22

 LDA22 is INTEGER
 The leading dimension of the array A22. LDA22 >= N-Q.

THETA

 THETA is DOUBLE PRECISION array, dimension (Q)
 When ZBBCSD converges, THETA contains the angles
 THETA(1), ..., THETA(Q). If ZBBCSD fails to converge,
 then THETA contains the diagonal of the partially
 reduced top-left block.

PHI

 PHI is DOUBLE PRECISION array, dimension (Q)
 When ZBBCSD converges, PHI contains the angles
 PHI(1), ..., PHI(Q). If ZBBCSD fails to converge,
 then PHI contains the diagonal of the partially
 reduced bottom-left block.

U11

 U11 is COMPLEX*16 array, dimension (LDU11, K)
 When ZBBCSD converges, U11 contains the K columns of
 U corresponding to the first block.
 If ZBBCSD fails to converge, then U11 contains the
 subdiagonal of the partially reduced top-left block.

LDU11

 LDU11 is INTEGER
 The leading dimension of the array U11. LDU11 >= M.

U12

 U12 is COMPLEX*16 array, dimension (LDU12, Q)
 When ZBBCSD converges, U12 contains the Q columns of
 U corresponding to the second block.
 If ZBBCSD fails to converge, then U12 contains the
 subdiagonal of the partially reduced top-right block.

LDU12

 LDU12 is INTEGER
 The leading dimension of the array U12. LDU12 >= M.

U21

 U21 is COMPLEX*16 array, dimension (LDU21, K)
 When ZBBCSD converges, U21 contains the K columns of
 U corresponding to the first block.
 If ZBBCSD fails to converge, then U21 contains the
 subdiagonal of the partially reduced bottom-left block.

LDU21

 LDU21 is INTEGER
 The leading dimension of the array U21. LDU21 >= N-Q.

U22

 U22 is COMPLEX*16 array, dimension (LDU22, Q)
 When ZBBCSD converges, U22 contains the Q columns of
 U corresponding to the second block.
 If ZBBCSD fails to converge, then U22 contains the
 subdiagonal of the partially reduced bottom-right block.

LDU22

 LDU22 is INTEGER
 The leading dimension of the array U22. LDU22 >= N-Q.

V11

 V11 is COMPLEX*16 array, dimension (LDV11, K)
 When ZBBCSD converges, V11 contains the K columns of
 V corresponding to the first block.
 If ZBBCSD fails to converge, then V11 contains the
 subdiagonal of the partially reduced top-left block.

LDV11

 LDV11 is INTEGER
 The leading dimension of the array V11. LDV11 >= N.

V12

 V12 is COMPLEX*16 array, dimension (LDV12, Q)
 When ZBBCSD converges, V12 contains the Q columns of
 V corresponding to the second block.
 If ZBBCSD fails to converge, then V12 contains the
 subdiagonal of the partially reduced top-right block.

LDV12

 LDV12 is INTEGER
 The leading dimension of the array V12. LDV12 >= N.

V21

 V21 is COMPLEX*16 array, dimension (LDV21, K)
 When ZBBCSD converges, V21 contains the K columns of
 V corresponding to the first block.
 If ZBBCSD fails to converge, then V21 contains the
 subdiagonal of the partially reduced bottom-left block.

LDV21

 LDV21 is INTEGER
 The leading dimension of the array V21. LDV21 >= Q.

V22

 V22 is COMPLEX*16 array, dimension (LDV22, Q)
 When ZBBCSD converges, V22 contains the Q columns of
 V corresponding to the second block.
 If ZBBCSD fails to converge, then V22 contains the
 subdiagonal of the partially reduced bottom-right block.

LDV22

 LDV22 is INTEGER
 The leading dimension of the array V22. LDV22 >= Q.

Q11

 Q11 is COMPLEX*16 array, dimension (K)
 If JOBQ = 'Q', Q11 contains the first K diagonal
 elements of the unitary matrix Q.

Q12

 Q12 is COMPLEX*16 array, dimension (MIN(M,Q))
 If JOBQ = 'Q', Q12 contains the first MIN(M,Q)
 diagonal elements of the unitary matrix Q.

Q21

 Q21 is COMPLEX*16 array, dimension (K)
 If JOBQ = 'Q', Q21 contains the first K diagonal
 elements of the unitary matrix Q.

Q22

 Q22 is COMPLEX*16 array, dimension (Q)
 If JOBQ = 'Q', Q22 contains the Q diagonal elements
 of the unitary matrix Q.

RWORK

 RWORK is DOUBLE PRECISION array, dimension (MAX(1,LRWORK))
 On exit, if INFO = 0, RWORK(1) returns the optimal LRWORK.

LRWORK

 LRWORK is INTEGER
 The dimension of the array RWORK. LRWORK >= MAX(1,8*Q).
 If LRWORK = -1, then a workspace query is assumed; the
 routine only calculates the optimal size of the RWORK array,
 returns this value as the first entry of the work array, and
 no error message related to LRWORK is issued by XERBLA.

INFO

 INFO is INTEGER
 = 0:  successful exit.
 < 0:  if INFO = -i, the i-th argument had an illegal value.
 > 0:  if ZBBCSD did not converge, INFO specifies the number
 of nonzero entries in PHI, and A11, A12, etc.,
 contain the partially reduced matrix.

Internal Parameters:

 TOLMUL  DOUBLE PRECISION, default = MAX(10,MIN(100,EPS**(-1/8)))
         TOLMUL controls the convergence criterion of the QR loop.
         Angles THETA(i), PHI(i) are rounded to 0 or PI/2 when they
         are within TOLMUL*EPS of either bound.

References:

[1] Brian D. Sutton. Computing the complete CS decomposition. Numer. Algorithms, 50(1):33-65, 2009.
