الغرض:

!>
!> ZLAQZ0 يحسب القيم الذاتية لزوج المصفوفات الحقيقي (H,T)،
!> حيث H مصفوفة هسنبرغ عليا و T مصفوفة مثلثية عليا،
!> باستخدام طريقة QZ المزدوجة.
!> أزواج المصفوفات من هذا النوع يتم إنتاجها عن طريق الاختزال إلى
!> شكل هسنبرغ العام لمصفوفة حقيقية زوج (A,B):
!>
!>    A = Q1*H*Z1**H,  B = Q1*T*Z1**H,
!>
!> كما تم حسابه بواسطة ZGGHRD.
!>
!> إذا كان JOB='S'، فإن زوج هسنبرغ-مثلثي (H,T)
!> يتم اختزاله أيضًا إلى شكل شور العام،
!>
!>    H = Q*S*Z**H,  T = Q*P*Z**H,
!>
!> حيث Q و Z مصفوفات وحدوية، P و S مصفوفات مثلثية عليا.
!>
!> اختياريًا، يمكن ضرب المصفوفة الوحدوية Q من تحليل شور العام
!> لاحقًا في مصفوفة دخل Q1، ويمكن ضرب المصفوفة Z
!> لاحقًا في مصفوفة دخل Z1.
!> إذا كانت Q1 و Z1 هي المصفوفات الوحدوية من ZGGHRD التي قامت باختزال
!> زوج المصفوفات (A,B) إلى شكل هسنبرغ العام، فإن المصفوفات الناتجة
!> Q1*Q و Z1*Z هي العوامل الوحدوية من تحليل شور العام
!> لـ (A,B):
!>
!>    A = (Q1*Q)*S*(Z1*Z)**H,  B = (Q1*Q)*P*(Z1*Z)**H.
!>
!> لتجنب الفيضان، يتم حساب القيم الذاتية لزوج المصفوفات (H,T) (وبالمثل،
!> لـ (A,B)) كزوج من القيم (alpha,beta)، حيث alpha
!> مركب و beta حقيقي.
!> إذا كان beta غير صفري، فإن lambda = alpha / beta هي قيمة ذاتية
!> لمشكلة القيمة الذاتية غير المتناظرة العامة (GNEP)
!>    A*x = lambda*B*x
!> وإذا كان alpha غير صفري، فإن mu = beta / alpha هي قيمة ذاتية
!> للشكل البديل لـ GNEP
!>    mu*A*y = B*y.
!> يمكن قراءة القيم الذاتية مباشرة من شكل شور العام
!> :
!>   alpha = S(i,i), beta = P(i,i).
!>
!> Ref: C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>
!> Ref: B. Kagstrom, D. Kressner, , SIAM J. Numer.
!>      Anal., 29(2006), pp. 199--227.
!>
!> Ref: T. Steel, D. Camps, K. Meerbergen, R. Vandebril
!>

ZLAQZ0:

!> \brief \
!> The subroutine ZLAQZ0 reduces a pair of complex matrices (A, B) to the
!> generalized Schur form (S, T).
!>
!> \details
!> ZLAQZ0 is a subroutine in LAPACK library that reduces a pair of complex
!> matrices (A, B) to the generalized Schur form (S, T). The generalized
!> Schur decomposition is defined as:
!>
!> A = Q * S * Z**H
!> B = Q * T * Z**H
!>
!> where S and T are upper triangular matrices, and Q and Z are unitary
!> matrices. The diagonal elements of S and T form the generalized eigenvalues
!> alpha(i) / beta(i).
!>
!> This subroutine is typically used as a first step in solving the
!> generalized eigenvalue problem A*x = lambda*B*x.
!>
!> \param[in] A The first matrix, LDA x N.
!> \param[in] LDA LDA is INTEGER, the leading dimension of the array A. LDA >= max(1,N).
!> \param[in] B The second matrix, LDB x N.
!> \param[in] LDB LDB is INTEGER, the leading dimension of the array B. LDB >= max(1,N).
!> \param[out] ALPHAR DOUBLE PRECISION array of dimension N.
!> \param[out] ALPHAI DOUBLE PRECISION array of dimension N.
!> \param[out] BETA COMPLEX*16 array of dimension N.
!> \param[out] Q COMPLEX*16 array of dimension LDQ x N.
!>             If COMPZ = 'Q', the unitary matrix Q.
!>             If COMPZ = 'I', the unitary matrix Q is returned.
!>             If COMPZ = 'N', Q is not computed.
!> \param[in] Z COMPLEX*16 array of dimension LDZ x N.
!>             If COMPZ = 'V', the unitary matrix Z of right Schur vectors.
!>             Not referenced if COMPZ = 'N'.
!> \param[in] LDZ LDZ is INTEGER. The leading dimension of the array Z. LDZ >= 1.
!>             If COMPZ = 'V' or 'I', then LDZ >= N.
!> \param[in] WORK COMPLEX*16 array, dimension (MAX(1,LWORK)).
!>             On exit, if INFO >= 0, WORK(1) returns the optimal LWORK.
!> \param[in] RWORK DOUBLE PRECISION array of dimension N.
!> \param[in] LWORK LWORK is INTEGER. The dimension of the array WORK. LWORK >= max(1,N).
!>             If LWORK = -1, then a workspace query is assumed; the routine
!>             only calculates the optimal size of the WORK array, returns
!>             this value as the first entry of the WORK array, and no error
!>             message related to LWORK is issued by XERBLA.
!> \param[in] REC REC is INTEGER. REC indicates the current recursion level. Should be set
!>             to 0 on first call.
!> \param[in] INFO INFO is INTEGER.
!>             = 0: successful exit
!>             < 0: if INFO = -i, the i-th argument had an illegal value
!>             = 1,...,N: the QZ iteration did not converge.  (A,B) is not
!>                        in Schur form, but ALPHA(i) and
!>                        BETA(i), i=INFO+1,...,N should be correct.
!>
