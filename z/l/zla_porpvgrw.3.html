double precision function zla_porpvgrw (uplo, ncols, a, lda, af, ldaf, work)
ZLA_PORPVGRW تحسب عامل نمو المحور العكسي (reciprocal pivot growth factor) للـ norm(A)/norm(U) لمصفوفة متناظرة أو هيرميتية موجبة تمامًا.

توثيق الوظيفة/الإجراء الفرعي

double precision function zla_porpvgrw (character*1 uplo, integer ncols, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, double precision, dimension( * ) work)

ZLA_PORPVGRW تحسب عامل نمو المحور العكسي (reciprocal pivot growth factor) norm(A)/norm(U) لمصفوفة متناظرة أو هيرميتية موجبة تمامًا.

الغرض:

!>
!>
!> ZLA_PORPVGRW تحسب عامل نمو المحور العكسي (reciprocal pivot growth factor)
!> norm(A)/norm(U).  يتم استخدام الـ norm. إذا كان هذا أقل بكثير من 1،
!> فقد يكون استقرار تحليل LU للمصفوفة (المتوازنة) A ضعيفًا. هذا يعني أيضًا أن
!> الحل X، وتقديرات الأرقام الشرطية، وحدود الخطأ قد تكون غير موثوقة.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>       = 'U':  المثلث العلوي لـ A مخزن؛
!>       = 'L':  المثلث السفلي لـ A مخزن.
!>

NCOLS

!>          NCOLS هو INTEGER
!>     عدد أعمدة المصفوفة A. NCOLS >= 0.
!>

A

!>          A هو مصفوفة COMPLEX*16، البعد (LDA,N)
!>     عند الدخول، المصفوفة N-by-N A.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة COMPLEX*16، البعد (LDAF,N)
!>     العامل المثلثي U أو L من تحليل Cholesky
!>     A = U**T*U أو A = L*L**T، كما تم حسابه بواسطة ZPOTRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF.  LDAF >= max(1,N).
!>

WORK

!>          WORK هي مصفوفة DOUBLE PRECISION، البعد (2*N)
!>
