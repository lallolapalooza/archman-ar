الوظائف/الإجراءات الفرعية


double precision function zla_gercond_x (trans, n, a, lda, af, ldaf, ipiv, x, info, work, rwork)
ZLA_GERCOND_X تحسب رقم شرط المعيار اللانهائي لـ op(A)*diag(x) للمصفوفات العامة.

توثيق الوظيفة/الإجراء الفرعي

double precision function zla_gercond_x (character trans, integer n, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, complex*16, dimension( * ) x, integer info, complex*16, dimension( * ) work, double precision, dimension( * ) rwork)

ZLA_GERCOND_X تحسب رقم شرط المعيار اللانهائي لـ op(A)*diag(x) للمصفوفات العامة.

الغرض:

!>
!>    ZLA_GERCOND_X تحسب رقم شرط المعيار اللانهائي لـ
!>    op(A) * diag(X) حيث X هو متجه COMPLEX*16.
!>

المعلمات

TRANS 
!>          TRANS هو CHARACTER*1
!>     يحدد شكل نظام المعادلات:
!>       = 'N':  A * X = B     (بدون تبديل)
!>       = 'T':  A**T * X = B  (تبديل)
!>       = 'C':  A**H * X = B  (تبديل مترافق = تبديل)
!>

N

!>          N هو INTEGER
!>     عدد المعادلات الخطية، أي رتبة
!>     المصفوفة A.  N >= 0.
!>

A

!>          A هو COMPLEX*16 array, dimension (LDA,N)
!>     عند الدخول، المصفوفة A بحجم N-by-N.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF هو COMPLEX*16 array, dimension (LDAF,N)
!>     العوامل L و U من التحلل
!>     A = P*L*U كما تم حسابه بواسطة ZGETRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV هو INTEGER array, dimension (N)
!>     مؤشرات المحور من تحلل A = P*L*U
!>     كما تم حسابه بواسطة ZGETRF؛ تم تبديل الصف i من المصفوفة
!>     مع الصف IPIV(i).
!>

X

!>          X هو COMPLEX*16 array, dimension (N)
!>     المتجه X في الصيغة op(A) * diag(X).
!>

INFO

!>          INFO هو INTEGER
!>       = 0:  خروج ناجح.
!>     i > 0:  المعلمة i غير صالحة.
!>

WORK

!>          WORK هو COMPLEX*16 array, dimension (2*N).
!>     مساحة العمل.
!>

RWORK

!>          RWORK هو DOUBLE PRECISION array, dimension (N).
!>     مساحة العمل.
!>
