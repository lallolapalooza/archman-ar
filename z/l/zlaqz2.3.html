    NAME

    zlaqz2 - This subroutine is intended to be a computing-intensive auxiliary routine for the recurrent computation of the Schur factorization of a generalized eigenvalue problem.

    SYNOPSIS

    SUBROUTINE ZLAQZ2( ICHAR, ILO, IHI, NASL, NASR, A, LDA, B, LDB, Q, LDQ, Z, LDZ, WORK, RWORK, INFO)

    • CHARACTER\*1 ICHAR
    • INTEGER ILO, IHI, NASL, NASR, LDA, LDB, LDQ, LDZ, INFO
    • DOUBLE PRECISION WORK(*), RWORK(*)
    • COMPLEX\*16 A(LDA,*), B(LDB,*), Q(LDQ,*), Z(LDZ,*)

    Function/Subroutine Documentation

    ZLAQZ2 is a Fortran subroutine designed to assist in computing the Schur factorization of a generalized eigenvalue problem of the form (A - lambda*B)x = 0. Specifically, it performs a sequence of deflation steps on the generalized eigenvalue problem.

    The routine is intended for use in computing-intensive parts of algorithms where the overhead of subroutine calls might be significant. It operates on submatrices defined by the indices ILO and IHI.

    The parameters are:

    • ICHAR: A character indicating the type of deflation to perform.
    • ILO, IHI: Integers specifying the range of the submatrix to be deflated.
    • NASL, NASR: Integers indicating the number of deflation steps to be performed on the left and right sides, respectively.
    • A, B: Complex matrices representing the pair of matrices for the generalized eigenvalue problem.
    • LDA, LDB: Leading dimensions of matrices A and B.
    • Q, Z: Complex matrices used for accumulating orthogonal transformations.
    • LDQ, LDZ: Leading dimensions of matrices Q and Z.
    • WORK: A double precision work array.
    • RWORK: A double precision work array.
    • INFO: An integer output parameter indicating the status of the computation. A value of 0 indicates success, while a non-zero value indicates an error.

    This subroutine is part of the LAPACK (Linear Algebra PACKage) library, which provides routines for various linear algebra computations.
