الوظائف/الإجراءات الفرعية


double precision function zlanhs (norm, n, a, lda, work)
ZLANHS تُرجع قيمة المعيار 1، أو المعيار فروبنيوس، أو المعيار إنفينيتي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة هسنبرغ علوية.

توثيق الوظيفة/الإجراء الفرعي

double precision function zlanhs (character norm, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

ZLANHS تُرجع قيمة المعيار 1، أو المعيار فروبنيوس، أو المعيار إنفينيتي، أو أكبر قيمة مطلقة لأي عنصر في مصفوفة هسنبرغ علوية.

الغرض:

!>
!> ZLANHS  تُرجع قيمة المعيار واحد، أو المعيار فروبنيوس، أو
!> المعيار إنفينيتي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة
!> هسنبرغ A.
!>

تُرجع

ZLANHS 
!>
!>    ZLANHS = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يشير إلى  المعيار واحد لمصفوفة (مجموع الأعمدة الأقصى)،
!> normI  يشير إلى  المعيار إنفينيتي  لمصفوفة (مجموع الصفوف الأقصى)، و
!> normF  يشير إلى  المعيار فروبنيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسقًا.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في ZLANHS كما هو موضح
!>          أعلاه.
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين ZLANHS
!>          إلى الصفر.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          مصفوفة هسنبرغ العلوية N × N؛ الجزء السفلي من A تحت
!>          القطر الفرعي الأول غير مُشار إليه.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I'؛ بخلاف ذلك، لا يتم
!>          الإشارة إلى WORK.
!>
