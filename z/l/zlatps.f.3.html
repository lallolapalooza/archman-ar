zlatps(3) - LAPACK documentation

NAME

zlatps - zlapsy, zlatps, ztpsv, ztpsv_， ztpsv_routines perform a triangular matrix-vector multiplication, and its inverse

SYNOPSIS

 SUBROUTINE ZLATPS( UPLO, TRANS, DIAG, NORMF, N, AP, X, WORK, RWORK, INFO )

    CHARACTER(1) :: DIAG, NORMF, TRANS, UPLO
    INTEGER :: N
    REAL(8) :: RWORK( * )
    COMPLEX(8) :: AP( * ), WORK( * ), X( * )
    INTEGER :: INFO

Function/Subroutine Documentation

ZLATPS performs a triangular matrix-vector multiplication, and its inverse. This routine is part of the LAPACK routines that solve systems of linear equations and perform matrix factorizations.

The matrix A is an N-by-N upper or lower triangular matrix, and is non-unit, upper or lower triangular, or upper or lower triangular with unit diagonal. The matrix is stored in packed format in the array AP.

The routine performs one of the following operations:

  if NORMF = 'N':
     x := A * x
  else if NORMF = 'T':
     x := A**T * x
  else if NORMF = 'C':
     x := A**H * x
  else if NORMF = 'I':
     x := inv(A) * x

where A**T denotes the transpose of A, and A**H denotes the conjugate transpose of A.

If DIAG = 'U', the diagonal elements of A are assumed to be 1 and are not referenced.

The storage format for A is:

  If UPLO = 'U', then the upper triangle of A is stored column by column
  in the array AP. The length of the array AP is N*(N+1)/2.

  If UPLO = 'L', then the lower triangle of A is stored column by column
  in the array AP. The length of the array AP is N*(N+1)/2.

The array WORK is used as a workspace and has dimensions (N) if NORMF = 'I', and dimensions (1) otherwise.

The array RWORK is used as a workspace and has dimensions (N) if NORMF = 'I', and dimensions (1) otherwise.

INFO is an integer output variable. If the routine completes successfully, INFO is set to 0. If the routine encounters an error, INFO is set to a negative integer value indicating the position of the error.

وثائق الدالة/الإجراء الفرعي

تقوم ZLATPS بضرب مصفوفة ثلاثية بمتجه، وعكسها. هذا الإجراء هو جزء من روتينات LAPACK التي تحل أنظمة المعادلات الخطية وتجري عوامل المصفوفة.

المصفوفة A هي مصفوفة مربعة من حجم N-بـ N علوية أو سفلية، وهي غير وحدية، علوية أو سفلية ثلاثية، أو علوية أو سفلية ثلاثية مع قطر وحدي. تخزن المصفوفة بتنسيق مضغوط في المصفوفة AP.

يقوم الإجراء بأحد العمليات التالية:

  إذا كانت NORMF = 'N':
     x := A * x
  else if NORMF = 'T':
     x := A**T * x
  else if NORMF = 'C':
     x := A**H * x
  else if NORMF = 'I':
     x := inv(A) * x

حيث A**T تمثل منقول A، و A**H تمثل المرافق المنقول لـ A.

إذا كانت DIAG = 'U'، يُفترض أن عناصر القطر لـ A هي 1 ولا يتم الرجوع إليها.

تنسيق التخزين لـ A هو:

  إذا كانت UPLO = 'U'، يتم تخزين المثلث العلوي لـ A عمودًا بعمود
  في المصفوفة AP. طول المصفوفة AP هو N*(N+1)/2.

  إذا كانت UPLO = 'L'، يتم تخزين المثلث السفلي لـ A عمودًا بعمود
  في المصفوفة AP. طول المصفوفة AP هو N*(N+1)/2.

تستخدم المصفوفة WORK كمساحة عمل ولها أبعاد (N) إذا كانت NORMF = 'I'، وأبعاد (1) بخلاف ذلك.

تستخدم المصفوفة RWORK كمساحة عمل ولها أبعاد (N) إذا كانت NORMF = 'I'، وأبعاد (1) بخلاف ذلك.

INFO هو متغير إخراج صحيح. إذا اكتمل الإجراء بنجاح، يتم تعيين INFO إلى 0. إذا واجه الإجراء خطأ، يتم تعيين INFO إلى قيمة سلبية صحيحة تشير إلى موضع الخطأ.
