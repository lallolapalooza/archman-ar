ZLATB5

الغرض:

!>
!> ZLATB5 تحدد المعلمات لمولد المصفوفات بناءً على نوع المصفوفة المراد توليدها.
!>

المعلمات

PATH 
!>          PATH هو CHARACTER*3
!>          اسم مسار LAPACK.
!>

IMAT

!>          IMAT هو INTEGER
!>          مفتاح عدد صحيح يصف المصفوفة المراد توليدها لهذا
!>          المسار.
!>

N

!>          N هو INTEGER
!>          عدد الصفوف والأعمدة في المصفوفة المراد توليدها.
!>

TYPE

!>          TYPE هو CHARACTER*1
!>          نوع المصفوفة المراد توليدها:
!>          = 'S':  مصفوفة متماثلة
!>          = 'P':  مصفوفة موجبة متماثلة (شبه) محددة
!>          = 'N':  مصفوفة غير متماثلة
!>

KL

!>          KL هو INTEGER
!>          عرض النطاق السفلي للمصفوفة المراد توليدها.
!>

KU

!>          KU هو INTEGER
!>          عرض النطاق العلوي للمصفوفة المراد توليدها.
!>

ANORM

!>          ANORM هو DOUBLE PRECISION
!>          القيمة المعيارية المطلوبة للمصفوفة المراد توليدها. يتم
!>          قياس المصفوفة القطرية للقيم المنفردة أو القيم الذاتية بواسطة هذه
!>          القيمة.
!>

MODE

!>          MODE هو INTEGER
!>          مفتاح يشير إلى كيفية اختيار متجه القيم الذاتية.
!>

CNDNUM

!>          CNDNUM هو DOUBLE PRECISION
!>          الرقم الشرطي المطلوب.
!>

DIST

!>          DIST هو CHARACTER*1
!>          نوع التوزيع المراد استخدامه بواسطة مولد الأرقام
!>          العشوائية.
!>
