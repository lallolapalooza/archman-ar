subroutine zlaesy (complex*16 a, complex*16 b, complex*16 c, complex*16 rt1, complex*16 rt2, complex*16 evscal, complex*16 cs1, complex*16 sn1)

ZLAESY تحسب القيم الذاتية والمتجهات الذاتية لمصفوفة متماثلة معقدة 2x2.

الغرض:

!>
!> ZLAESY تحسب التحلل الذاتي لمصفوفة متماثلة 2x2
!>    ( ( A, B );( B, C ) )
!> بشرط أن يكون معيار مصفوفة المتجهات الذاتية أكبر من
!> قيمة حدية معينة.
!>
!> RT1 هي القيمة الذاتية ذات القيمة المطلقة الأكبر، و RT2 هي ذات
!> القيمة المطلقة الأصغر. إذا تم حساب المتجهات الذاتية، فإن
!> عند العودة ( CS1, SN1 ) هو المتجه الذاتي الواحدي لـ RT1، وبالتالي
!>
!> [  CS1     SN1   ] . [ A  B ] . [ CS1    -SN1   ] = [ RT1  0  ]
!> [ -SN1     CS1   ]   [ B  C ]   [ SN1     CS1   ]   [  0  RT2 ]
!>

المعاملات

A 
!>          A هو COMPLEX*16
!>          العنصر ( 1, 1 ) للمصفوفة المدخلة.
!>

B

!>          B هو COMPLEX*16
!>          العنصر ( 1, 2 ) للمصفوفة المدخلة. العنصر ( 2, 1 )
!>          معطى أيضًا بواسطة B، بما أن المصفوفة 2x2 متماثلة.
!>

C

!>          C هو COMPLEX*16
!>          العنصر ( 2, 2 ) للمصفوفة المدخلة.
!>

RT1

!>          RT1 هو COMPLEX*16
!>          القيمة الذاتية ذات المعيار الأكبر.
!>

RT2

!>          RT2 هو COMPLEX*16
!>          القيمة الذاتية ذات المعيار الأصغر.
!>

EVSCAL

!>          EVSCAL هو COMPLEX*16
!>          القيمة المعقدة التي تم قياس مصفوفة المتجهات الذاتية بها
!>          لجعلها متعامدة. إذا كان EVSCAL صفرًا، لم يتم حساب المتجهات الذاتية.
!>          هذا يعني شيئًا واحدًا من اثنين: لم يمكن تشخيص المصفوفة 2x2،
!>          أو كان معيار مصفوفة المتجهات الذاتية قبل القياس أكبر من القيمة
!>          الحدية THRESH (المحددة أدناه).
!>

CS1

!>          CS1 هو COMPLEX*16
!>

SN1

!>          SN1 هو COMPLEX*16
!>          إذا كان EVSCAL .NE. 0، فإن ( CS1, SN1 ) هو المتجه الذاتي الأيمن
!>          الواحدي لـ RT1.
!>
