GRADE

!>          GRADE هو CHARACTER*1
!>           يحدد تصنيف المصفوفة على النحو التالي:
!>           'N'  => لا تصنيف
!>           'L'  => تُضرب المصفوفة مسبقًا بالقطر( DL )
!>                   (فقط إذا كانت المصفوفة غير متناظرة)
!>           'R'  => تُضرب المصفوفة لاحقًا بالقطر( DR )
!>                   (فقط إذا كانت المصفوفة غير متناظرة)
!>           'B'  => تُضرب المصفوفة مسبقًا بالقطر( DL ) ولاحقًا
!>                         بالقطر( DR )
!>                   (فقط إذا كانت المصفوفة غير متناظرة)
!>           'H'  => تُضرب المصفوفة مسبقًا بالقطر( DL ) ولاحقًا
!>                         بالقطر( CONJG(DL) )
!>                   (فقط إذا كانت المصفوفة متناظرة هيرميتية أو غير متناظرة)
!>           'S'  => تُضرب المصفوفة مسبقًا بالقطر( DL ) ولاحقًا
!>                         بالقطر( DL )
!>                   (فقط إذا كانت المصفوفة متناظرة أو غير متناظرة)
!>           'E'  => تُضرب المصفوفة مسبقًا بالقطر( DL ) ولاحقًا
!>                         بمقلوب القطر( DL )
!>                         ( 'S' للتشابه )
!>                   (فقط إذا كانت المصفوفة غير متناظرة)
!>                   ملاحظة: إذا كانت GRADE='S'، فيجب أن يساوي M القيمة N.
!>           لم يتم التعديل.
!>

DL

!>          DL هو مصفوفة COMPLEX*16، بُعدها (M)
!>           إذا كانت MODEL=0، فإن هذه المصفوفة عند الإدخال تحدد المدخلات القطرية
!>           لمصفوفة قطرية تستخدم كما هو موضح تحت GRADE
!>           أعلاه. إذا لم تكن MODEL صفرًا، فسيتم تعيين DL
!>           وفقًا لـ MODEL و CONDL، بشكل مشابه للطريقة التي يتم بها تعيين D
!>           وفقًا لـ MODE و COND (باستثناء عدم وجود معامل DMAX لـ DL).
!>           إذا كانت GRADE='E'، فلا يمكن أن تحتوي DL على مدخلات صفرية.
!>           لم يتم الرجوع إليها إذا كانت GRADE = 'N' أو 'R'. تم تغييرها عند الخروج.
!>

MODEL

!>          MODEL هو INTEGER
!>           يحدد هذا كيفية حساب المصفوفة القطرية DL،
!>           تمامًا كما يحدد MODE كيفية حساب D.
!>           لم يتم التعديل.
!>

CONDL

!>          CONDL هو DOUBLE PRECISION
!>           عندما لا تكون MODEL صفرًا، يحدد هذا رقم الحالة
!>           لـ DL المحسوب. لم يتم التعديل.
!>

DR

!>          DR هو مصفوفة COMPLEX*16، بُعدها (N)
!>           إذا كانت MODER=0، فإن هذه المصفوفة عند الإدخال تحدد المدخلات القطرية
!>           لمصفوفة قطرية تستخدم كما هو موضح تحت GRADE
!>           أعلاه. إذا لم تكن MODER صفرًا، فسيتم تعيين DR
!>           وفقًا لـ MODER و CONDR، بشكل مشابه للطريقة التي يتم بها تعيين D
!>           وفقًا لـ MODE و COND (باستثناء عدم وجود معامل DMAX لـ DR).
!>           لم يتم الرجوع إليها إذا كانت GRADE = 'N'، 'L'، 'H' أو 'S'.
!>           تم تغييرها عند الخروج.
!>

MODER

!>          MODER هو INTEGER
!>           يحدد هذا كيفية حساب المصفوفة القطرية DR،
!>           تمامًا كما يحدد MODE كيفية حساب D.
!>           لم يتم التعديل.
!>

CONDR

!>          CONDR هو DOUBLE PRECISION
!>           عندما لا تكون MODER صفرًا، يحدد هذا رقم الحالة
!>           لـ DR المحسوب. لم يتم التعديل.
!>

PIVTNG

!>          PIVTNG هو CHARACTER*1
!>           عند الإدخال يحدد تبديلات المحاور على النحو التالي:
!>           'N' أو ' ' => لا شيء.
!>           'L' => تبديل الصفوف أو المحاور اليسرى (يجب أن تكون المصفوفة غير متناظرة).
!>           'R' => تبديل الأعمدة أو المحاور اليمنى (يجب أن تكون المصفوفة
!>                  غير متناظرة).
!>           'B' أو 'F' => تبديل كلا المحورين أو تبديل كامل، أي على كلا الجانبين.
!>                         في هذه الحالة، يجب أن يساوي M القيمة N
!>
!>           إذا كان هناك استدعاءان لـ ZLATMR لهما نفس النطاق الكامل (KL = M-1
!!>           و KU = N-1)، ويختلفان فقط في معاملي PIVTNG و PACK،
!>           فإن المصفوفات الناتجة ستختلف فقط في ترتيب الصفوف و/أو الأعمدة،
!>           وبخلاف ذلك تحتوي على نفس البيانات. لا يمكن الحفاظ على هذا الاتساق
!>           بعرض نطاق أقل من الكامل.
!>

IPIVOT

!>          IPIVOT هي مصفوفة INTEGER، بُعدها (N أو M)
!>           تحدد هذه المصفوفة التبديل المستخدم. بعد إنشاء المصفوفة الأساسية،
!>           يتم تبديل الصفوف أو الأعمدة أو كليهما. إذا تم اختيار تبديل الصفوف،
!>           يبدأ ZLATMR من الصف *الأخير* ويتبادل الصف M-th والصف IPIVOT(M)-th،
!>           ثم ينتقل إلى الصف قبل الأخير، ويتبادل الصف (M-1)-th والصف IPIVOT(M-1)-th،
!>           وهكذا. من حيث ، التبديل هو
!>           (1 IPIVOT(1)) (2 IPIVOT(2)) ... (M IPIVOT(M))
!>           حيث يتم تطبيق الدورة الأقصى يمينًا أولاً. هذا هو *عكس* تأثير
!!>           التبديل في LINPACK. الفكرة هي أن تحليل مصفوفة الوحدة (مع التبديل)
!>           التي تم تبديلها عكسيًا بهذه الطريقة يجب أن ينتج عنه متجه محور
!>           مطابق لـ IPIVOT.
!>           لم يتم الرجوع إليها إذا كانت PIVTNG = 'N'. لم يتم التعديل.
!>

KL

!>          KL هو INTEGER
!>           عند الإدخال يحدد النطاق السفلي للمصفوفة. على سبيل المثال،
!>           KL=0 يعني مثلثية علوية، KL=1 يعني هسنبرغ علوي، و KL على الأقل M-1
!>           يعني أن المصفوفة ليست نطاقية. يجب أن يساوي KU إذا كانت المصفوفة
!>           متناظرة أو متناظرة هيرميتية.
!>           لم يتم التعديل.
!>

KU

!>          KU هو INTEGER
!>           عند الإدخال يحدد النطاق العلوي للمصفوفة. على سبيل المثال،
!>           KU=0 يعني مثلثية سفلية، KU=1 يعني هسنبرغ سفلي، و KU على الأقل N-1
!>           يعني أن المصفوفة ليست نطاقية. يجب أن يساوي KL إذا كانت المصفوفة
!>           متناظرة أو متناظرة هيرميتية.
!>           لم يتم التعديل.
!>

SPARSE

!>          SPARSE هو DOUBLE PRECISION
!>           عند الإدخال يحدد ندرة المصفوفة إذا كان سيتم إنشاء مصفوفة نادرة.
!>           يجب أن تكون SPARSE بين 0 و 1. لإنشاء مصفوفة نادرة، لكل مدخل مصفوفة،
!>           يتم إنشاء رقم عشوائي موحد (0، 1) x ومقارنته بـ SPARSE؛ إذا كان x أكبر،
!>           يظل مدخل المصفوفة دون تغيير، وإذا كان x أصغر، يتم تعيين المدخل إلى صفر.
!>           وبالتالي، في المتوسط، سيتم تعيين جزء SPARSE من المدخلات إلى صفر.
!>           لم يتم التعديل.
!>

ANORM

!>          ANORM هو DOUBLE PRECISION
!>           عند الإدخال يحدد القيمة القصوى لمدخلات المصفوفة الناتجة
!>           (سيتم ضرب المصفوفة الناتجة بثابت بحيث يساوي أكبر مدخل مطلق لها ANORM)
!>           إذا كانت ANORM غير سالبة. إذا كانت ANORM سالبة، فلا يتم إجراء أي قياس.
!>           لم يتم التعديل.
!>

PACK

!>          PACK هو CHARACTER*1
!>           عند الإدخال يحدد تعبئة المصفوفة على النحو التالي:
!>           'N' => لا تعبئة
!>           'U' => صفر جميع المدخلات تحت القطر
!>                  (إذا كانت متناظرة أو متناظرة هيرميتية)
!>           'L' => صفر جميع المدخلات فوق القطر
!>                  (إذا كانت متناظرة أو متناظرة هيرميتية)
!>           'C' => تخزين المثلث العلوي عموديًا
!>                  (فقط إذا كانت المصفوفة متناظرة أو متناظرة هيرميتية أو
!>                   مثلثية علوية مربعة)
!>           'R' => تخزين المثلث السفلي عموديًا
!>                  (فقط إذا كانت المصفوفة متناظرة أو متناظرة هيرميتية أو
!>                   مثلثية سفلية مربعة)
!>                  (نفس نصف المثلث العلوي سطريًا إذا كانت متناظرة)
!>                  (نفس نصف المثلث العلوي المترافق سطريًا إذا كانت متناظرة هيرميتية)
!>           'B' => تخزين المثلث السفلي في مخطط تخزين النطاق
!>                  (فقط إذا كانت المصفوفة متناظرة أو متناظرة هيرميتية)
!>           'Q' => تخزين المثلث العلوي في مخطط تخزين النطاق
!>                  (فقط إذا كانت المصفوفة متناظرة أو متناظرة هيرميتية)
!>           'Z' => تخزين المصفوفة بأكملها في مخطط تخزين النطاق
!>                      (يمكن توفير التبديل باستخدام هذا
!>                      الخيار لتخزين A في الصفوف اللاحقة من
!>                      التخزين المخصص)
!>
!>           باستخدام هذه الخيارات، يمكن الحصول على مخططات تخزين LAPACK المعبأة
!>           والمحيطة المختلفة:
!>           GB               - استخدم 'Z'
!>           PB، HB أو TB     - استخدم 'B' أو 'Q'
!>           PP، HP أو TP     - استخدم 'C' أو 'R'
!>
!>           إذا اختلف استدعاءان لـ ZLATMR فقط في معامل PACK،
!>           فسيُنشئان مصفوفتين متكافئتين رياضيًا.
!>           لم يتم التعديل.
!>

A

!>          A هو مصفوفة COMPLEX*16، بُعدها (LDA,N)
!>           عند الخروج، A هي مصفوفة الاختبار المطلوبة. فقط المدخلات
!>           التي تكون مهمة عند الخروج سيتم الرجوع إليها (حتى لو كانت A
!>           بتنسيق تخزين معبأ أو نطاق). سيتم تعيين الأركان "غير المشغولة"
!>           في تنسيق النطاق إلى صفر.
!>

LDA

!>          LDA هو INTEGER
!>           عند الإدخال، يحدد LDA البعد الأول لـ A كما هو معلن في البرنامج
!>           المستدعي.
!>           إذا كانت PACK='N'، 'U' أو 'L'، يجب أن يكون LDA على الأقل 1، M.
!>           إذا كانت PACK='C' أو 'R'، يجب أن يكون LDA على الأقل 1.
!>           إذا كانت PACK='B' أو 'Q'، يجب أن يكون LDA هو MIN ( KU+1، N)
!>           إذا كانت PACK='Z'، يجب أن يكون LDA على الأقل KUU+KLL+1، حيث
!>           KUU = MIN ( KU، N-1 ) و KLL = MIN ( KL، M-1 )
!>           لم يتم التعديل.
!>

IWORK

!>          IWORK هي مصفوفة INTEGER، بُعدها (N أو M)
!>           مساحة عمل. لم يتم الرجوع إليها إذا كانت PIVTNG = 'N'. تم تغييرها عند الخروج.
!>

INFO

!>          INFO هو INTEGER
!>           معامل الخطأ عند الخروج:
!>             0 => عودة طبيعية
!>            -1 => M سالب أو غير مساوٍ لـ N و SYM='S' أو 'H'
!>            -2 => N سالب
!>            -3 => سلسلة DIST غير صالحة
!>            -5 => سلسلة SYM غير صالحة
!>            -7 => MODE خارج النطاق -6 إلى 6
!>            -8 => COND أقل من 1.0، و MODE ليس -6 أو 0 أو 6
!>           -10 => MODE ليس -6 أو 0 أو 6 و RSIGN سلسلة غير صالحة
!>           -11 => سلسلة GRADE غير صالحة، أو GRADE='E' و
!>                  M غير مساوٍ لـ N، أو GRADE='L'، 'R'، 'B'، 'S' أو 'E'
!>                  و SYM = 'H'، أو GRADE='L'، 'R'، 'B'، 'H' أو 'E'
!>                  و SYM = 'S'
!>           -12 => GRADE = 'E' و DL تحتوي على صفر
!>           -13 => MODEL خارج النطاق -6 إلى 6 و GRADE= 'L'، 'B'، 'H'،
!>                  'S' أو 'E'
!>           -14 => CONDL أقل من 1.0، GRADE='L'، 'B'، 'H'، 'S' أو 'E'،
!>                  و MODEL ليس -6 أو 0 أو 6
!>           -16 => MODER خارج النطاق -6 إلى 6 و GRADE= 'R' أو 'B'
!>           -17 => CONDR أقل من 1.0، GRADE='R' أو 'B'، و
!>                  MODER ليس -6 أو 0 أو 6
!>           -18 => سلسلة PIVTNG غير صالحة، أو PIVTNG='B' أو 'F' و
!>                  M غير مساوٍ لـ N، أو PIVTNG='L' أو 'R' و SYM='S'
!>                  أو 'H'
!>           -19 => IPIVOT يحتوي على رقم خارج النطاق و
!>                  PIVTNG لا يساوي 'N'
!>           -20 => KL سالب
!>           -21 => KU سالب، أو SYM=
'S' أو 'H' و KU لا تساوي KL
!>           -22 => SPARSE ليس ضمن النطاق 0. إلى 1.
!>           -24 => PACK سلسلة غير قانونية، أو PACK='U'، 'L'، 'B' أو 'Q'
!>                  و SYM='N'، أو PACK='C' و SYM='N' و إما KL
!>                  لا تساوي 0 أو N لا تساوي M، أو PACK='R' و
!>                  SYM='N'، و إما KU لا تساوي 0 أو N لا تساوي
!>                  M
!>           -26 => LDA صغير جدًا
!>             1 => عائد خطأ من ZLATM1 (حساب D)
!>             2 => لا يمكن قياس القطر إلى DMAX (أقصى إدخال هو 0)
!>             3 => عائد خطأ من ZLATM1 (حساب DL)
!>             4 => عائد خطأ من ZLATM1 (حساب DR)
!>             5 => ANORM موجب، ولكن المصفوفة التي تم إنشاؤها قبل
!>                  محاولة قياسها ليكون لها المعيار ANORM، هي صفر
!>
