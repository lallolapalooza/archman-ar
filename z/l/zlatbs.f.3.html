subroutine zlatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

ZLATBS تحل نظامًا مثلثيًا شريطيًا من المعادلات.

الغرض:

!>
!> ZLATBS تحل أحد الأنظمة المثلثية:
!>
!>    A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b,
!>
!> مع التحجيم لمنع الحمل الزائد، حيث A مصفوفة شريطية مثلثية علوية أو سفلية.
!> هنا A**T يمثل منقول A، و x و b هما متجهان بحجم n، و s هو عامل قياس،
!!> عادة ما يكون أقل من أو يساوي 1، تم اختياره بحيث تكون مكونات x أقل من
!> حد الحمل الزائد. إذا لم يتسبب النظام غير المقاس في حدوث حمل زائد،
!> يتم استدعاء روتين المستوى 2 BLAS ZTBSV. إذا كانت المصفوفة A مفردة
!> (A(j,j) = 0 لبعض j)، فإن s يتم تعيينه إلى 0 ويتم إرجاع حل غير تافه
!> لـ A*x = 0.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A علوية أم سفلية مثلثية.
!>          = 'U':  مثلثية علوية
!>          = 'L':  مثلثية سفلية
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد العملية المطبقة على A.
!>          = 'N':  حل A * x = s*b     (بدون منقول)
!>          = 'T':  حل A**T * x = s*b  (منقول)
!>          = 'C':  حل A**H * x = s*b  (منقول مترافق)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية موحدة أم لا.
!>          = 'N':  غير موحدة مثلثية
!>          = 'U':  موحدة مثلثية
!>

NORMIN

!>          NORMIN هو CHARACTER*1
!>          يحدد ما إذا كان CNORM قد تم تعيينه أم لا.
!>          = 'Y':  يحتوي CNORM على معايير الأعمدة عند الدخول
!>          = 'N':  لم يتم تعيين CNORM عند الدخول. عند الخروج، سيتم
!>                  حساب المعايير وتخزينها في CNORM.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A. N >= 0.
!>

KD

!>          KD هو INTEGER
!>          عدد الأقطار الفرعية أو الأقطار الفوقية في
!>          المصفوفة المثلثية A. KD >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX*16، حجمها (LDAB,N)
!>          المصفوفة المثلثية الشريطية العلوية أو السفلية A، مخزنة في
!>          أول KD+1 صفوف من المصفوفة. يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)    = A(i,j) لـ j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرائد للمصفوفة AB. LDAB >= KD+1.
!>

X

!>          X هي مصفوفة COMPLEX*16، حجمها (N)
!>          عند الدخول، الجانب الأيمن b للنظام المثلثي.
!>          عند الخروج، يتم الكتابة فوق X بمتجه الحل x.
!>

SCALE

!>          SCALE هو DOUBLE PRECISION
!>          عامل القياس s للنظام المثلثي
!>             A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b.
!>          إذا كان SCALE = 0، فإن المصفوفة A مفردة أو ذات قياس سيء،
!>          والمتجه x هو حل دقيق أو تقريبي لـ A*x = 0.
!>

CNORM

!>          CNORM هي مصفوفة DOUBLE PRECISION، حجمها (N)
!>
!>          إذا كان NORMIN = 'Y'، فإن CNORM هو وسيط إدخال و CNORM(j)
!>          يحتوي على معيار الجزء غير القطري للعمود j
!>          من A. إذا كان TRANS = 'N'، يجب أن يكون CNORM(j) أكبر من أو
!>          يساوي معيار اللانهاية، وإذا كان TRANS = 'T' أو 'C'، يجب أن يكون
!>          CNORM(j) أكبر من أو يساوي معيار 1.
!>
!>          إذا كان NORMIN = 'N'، فإن CNORM هو وسيط إخراج و CNORM(j)
!>          يعيد معيار 1 للجزء غير القطري للعمود j
!>          من A.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  انتهاء ناجح
!>          < 0:  إذا كان INFO = -k، فإن الوسيط k كان له قيمة غير قانونية
!>

تفاصيل إضافية:

!>
!> يتم حساب حد تقريبي لـ x؛ إذا كان هذا الحد أقل من الحمل الزائد،
!> يتم استدعاء ZTBSV، وإلا، يتم استخدام رمز محدد يتحقق من احتمال
!> حدوث الحمل الزائد أو القسمة على صفر في كل عملية.
!>
!> يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!> إذا كانت A مثلثية سفلية هي:
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> تحديد الحدود لمكونات x بعد j تكرارات للحلقة:
!>     M(j) = حد لـ x[1:j]
!>     G(j) = حد لـ x[j+1:n]
!> في البداية، ليكن M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!> ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> حيث CNORM(j+1) أكبر من أو يساوي معيار اللانهاية
!> للعمود j+1 من A، باستثناء القطر. وبالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> نظرًا لأن |x(j)| <= M(j)، فإننا نستخدم روتين المستوى 2 BLAS ZTBSV إذا كان
!> معكوس أكبر M(j)، j=1,..,n، أكبر من
!> max(underflow, 1/overflow).
!>
!> يتم أيضًا استخدام الحد على x(j) لتحديد متى يمكن تنفيذ خطوة في
!> المخطط العمودي دون خوف من الحمل الزائد. إذا
!> الحد المحسوب أكبر من ثابت كبير، يتم قياس x لمنع الحمل الزائد،
!> ولكن إذا تجاوز الحد، يتم تعيين x إلى 0، و x(j) إلى
!> 1، و scale إلى 0، ويتم العثور على حل غير تافه لـ A*x = 0.
!>
!> وبالمثل، يتم استخدام مخطط صفي لحل A**T *x = b أو
!> A**H *x = b. الخوارزمية الأساسية لـ A العلوية المثلثية هي
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end
!>
!> نقوم بحساب حدين في وقت واحد
!>       G(j) = حد لـ ( b(i) - A[1:i-1,i]' * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد لـ x(i)، 1<=i<=j
!>
!> القيم الأولية هي G(0) = 0، M(0) = max{b(i), i=1,..,n}، و نقوم
!> بإضافة القيد G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!> ثم الحد على x(j) هو:
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> ويمكننا استدعاء ZTBSV بأمان إذا كان 1/M(n) و 1/G(n) كلاهما أكبر
!> من max(underflow, 1/overflow).
!>

NAME

zlatbs - solves a general band triangular system of linear equations

SYNOPSIS

  SUBROUTINE ZLATBS(
               UPLO, TRANS, DIAG, NORMA, N, KD, NB, AR, LDA, B, LDB, INFO
             )

  CHARACTER          UPLO, TRANS, DIAG, NORMA
  INTEGER            N, KD, NB, LDA, LDB, INFO
  COMPLEX*16         AR( LDA, * ), B( LDB, * )

Function/Subroutine Documentation

ZLATBS solves one of the least squares problems: 1. minimize || B - A*X || 2. minimize || B - A**H*X || where A is an N x N band matrix, X and B are N x NB matrices, and A**H denotes the conjugate transpose of A. A is band matrix, in which the elements of each row are stored in the columns of AR starting from the diagonal and extending downwards. Specifically, if KD = 1, AR is upper triangular, and AR(i,j) = A(i,j) for j >= i and j-i <= KD if KD = -1, AR is lower triangular, and AR(i,j) = A(i,j) for j <= i and i-j <= abs(KD) UPLO (input) CHARACTER*1 = 'U': A is upper triangular. = 'L': A is lower triangular. TRANS (input) CHARACTER*1 = 'N': No transpose, i.e. solve A*X = B. = 'C': Conjugate transpose, i.e. solve A**H*X = B. DIAG (input) CHARACTER*1 = 'U': A is unit triangular. = 'N': A is not unit triangular. NORMA (input) CHARACTER*1 Specifies whether to normalize the linear system. = 'Y': Normalize the linear system. = 'N': Do not normalize the linear system. N (input) INTEGER The order of the matrix A. N >= 0. KD (input) INTEGER The number of super-diagonals of the matrix A if UPLO = 'U', or the number of sub-diagonals if UPLO = 'L'. KD determines the bandwidth of the matrix A. If UPLO = 'U', KD >= 0. If UPLO = 'L', KD <= 0. NB (input) INTEGER The number of columns of B and X. NB >= 1. AR (input) COMPLEX*16 array, dimension (LDA, k), where k is kd+1 when UPLO = 'U', and k is abs(kd)+1 when UPLO = 'L'. Before entry with UPLO = 'U', the (kd+1) by (N) matrix AR must contain the upper band part of the upper triangular matrix A, and the elements below the k-th super-diagonal must be zero. Before entry with UPLO = 'L', the (abs(kd)+1) by (N) matrix AR must contain the lower band part of the lower triangular matrix A, and the elements above the k-th sub-diagonal must be zero. LDA (input) INTEGER The leading dimension of the array AR. LDA >= max(1, kd+1) if UPLO = 'U', and LDA >= max(1, abs(kd)+1) if UPLO = 'L'. B (input/output) COMPLEX*16 array, dimension (LDB, NB). On entry, the N x NB matrix B. On exit, B is overwritten by the solution X. LDB (input) INTEGER The leading dimension of the array B. LDB >= N. INFO (output) INTEGER = 0: successful exit < 0: if INFO = -i, the i-th argument had an illegal value. > 0: if INFO = i, UD(i,i) is zero and the matrix U is singular.
