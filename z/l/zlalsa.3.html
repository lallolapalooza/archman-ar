zlalsa - zlalsa

Function/Subroutine Documentation

This subroutine is part of the LAPACK routines that compute the singular value decomposition (SVD) of a bidiagonal matrix.

Arguments

UPLO
CHARACTER*1

Specifies the form of the bidiagonal matrix. UPLO = 'U' indicates that the matrix is upper bidiagonal, and UPLO = 'L' indicates that the matrix is lower bidiagonal.

N
INTEGER

The order of the matrix. N ≥ 0.

A
COMPLEX*16 array, dimension (LDA, N)

The N-by-N bidiagonal matrix A.

LDA
INTEGER

The leading dimension of the array A. LDA ≥ max(1, N).

B
COMPLEX*16 array, dimension (LDB, N)

The N-by-N bidiagonal matrix B.

LDB
INTEGER

The leading dimension of the array B. LDB ≥ max(1, N).

C
COMPLEX*16 array, dimension (LDC, N)

The N-by-N bidiagonal matrix C.

LDC
INTEGER

The leading dimension of the array C. LDC ≥ max(1, N).

D
COMPLEX*16 array, dimension (LDD, N)

The N-by-N bidiagonal matrix D.

LDD
INTEGER

The leading dimension of the array D. LDD ≥ max(1, N).

E
COMPLEX*16 array, dimension (LDE, N)

The N-by-N bidiagonal matrix E.

LDE
INTEGER

The leading dimension of the array E. LDE ≥ max(1, N).

S
COMPLEX*16 array, dimension (LS)

The singular values of the bidiagonal matrix.

LS
INTEGER

The size of the array S. LS ≥ N.

R
REAL*8

The norm of the bidiagonal matrix.

T
COMPLEX*16

The trace of the bidiagonal matrix.

FAIL
REAL*8

The failure threshold.

IWORK
INTEGER array, dimension (3*N)

Work array.

INFO
INTEGER

= 0: successful exit.

< 0: if INFO = -i, the i-th argument had an illegal value.
