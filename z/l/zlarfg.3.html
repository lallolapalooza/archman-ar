subroutine zlarfg (integer n, complex*16 alpha, complex*16, dimension( * ) x, integer incx, complex*16 tau)

ZLARFG ينشئ عاكسًا أوليًا (مصفوفة هاوسهولدر).

الغرض:

!>
!> ZLARFG ينشئ عاكسًا أوليًا معقدًا H من الرتبة n، بحيث
!>
!>       H**H * ( alpha ) = ( beta ) ،   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> حيث alpha و beta قيمتان عدديتان، مع كون beta حقيقية، و x متجه
!> معقد من (n-1) عنصر. يتم تمثيل H بالشكل
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ،
!>                     ( v )
!>
!> حيث tau قيمة عددية معقدة و v متجه معقد من (n-1) عنصر. لاحظ أن H
!> ليست مصفوفة هرميتية.
!>
!> إذا كانت جميع عناصر x صفرية و alpha حقيقية، فإن tau = 0
!> وتُعتبر H مصفوفة الوحدة.
!>
!> بخلاف ذلك  1 <= real(tau) <= 2  و  abs(tau-1) <= 1 .
!>

المعلمات

!>          عند الإدخال، القيمة alpha.

!>
