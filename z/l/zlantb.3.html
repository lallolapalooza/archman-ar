double precision function zlantb (norm, uplo, diag, n, k, ab, ldab, work)
ZLANTB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة شريطية مثلثة.

وثائق الوظيفة/الروتين الفرعي

double precision function zlantb (character norm, character uplo, character diag, integer n, integer k, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

ZLANTB تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة شريطية مثلثة.

الغرض:

!>
!> ZLANTB  تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة
!> شريطية مثلثة A بحجم n × n، مع ( k + 1 ) أقطار.
!>

تُرجع

ZLANTB 
!>
!>    ZLANTB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تشير إلى المعيار 1 لمصفوفة (أقصى مجموع أعمدة)،
!> normI  تشير إلى المعيار اللانهائي  لمصفوفة (أقصى مجموع صفوف)، و
!> normF  تشير إلى معيار فروبينيوس  لمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسقًا.
!>

المعلمات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في ZLANTB كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثة علوية أم سفلية.
!>          = 'U':  مثلثة علوية
!>          = 'L':  مثلثة سفلية
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثة وحدوية أم لا.
!>          = 'N':  مثلثة غير وحدوية
!>          = 'U':  مثلثة وحدوية
!>

N

!>          N is INTEGER
!>          رتبة المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين ZLANTB
!>          إلى صفر.
!>

K

!>          K is INTEGER
!>          عدد الأقطار الفائقة للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفرعية للمصفوفة A إذا كان UPLO = 'L'.
!>          K >= 0.
!>

AB

!>          AB is COMPLEX*16 array, dimension (LDAB,N)
!>          المصفوفة الشريطية المثلثة العلوية أو السفلية A، مخزنة في
!>          أول k+1 صفوف من AB.  يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(k+1+i-j,j) = A(i,j) لـ max(1,j-k)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)   = A(i,j) لـ j<=i<=min(n,j+k).
!>          لاحظ أنه عندما يكون DIAG = 'U'، فإن العناصر في المصفوفة AB
!>          المقابلة للعناصر القطرية للمصفوفة A ليست مرجعية، ولكن يُفترض أنها واحد.
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= K+1.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I'؛ بخلاف ذلك، فإن WORK ليست
!>          مرجعية.
!>
