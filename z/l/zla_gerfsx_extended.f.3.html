ZLA_GERFSX_EXTENDED

الغرض:

!>
!> ZLA_GERFSX_EXTENDED يحسن الحل المحسوب لنظام المعادلات الخطية عن طريق
!> إجراء تنقيح تكراري بدقة إضافية ويوفر حدودًا للخطأ وتقديرات للخطأ الخلفي للحل.
!> يتم استدعاء هذا الروتين الفرعي بواسطة ZGERFSX لإجراء التنقيح التكراري.
!> بالإضافة إلى حد الخطأ المعياري، يوفر الكود حدًا أقصى للخطأ المكوني
!> إذا كان ذلك ممكنًا. انظر التعليقات لـ ERRS_N و ERRS_C للحصول على تفاصيل
!> حدود الخطأ. لاحظ أن هذا الروتين الفرعي مسؤول فقط عن تعيين
!> الحقول الثانية لـ ERRS_N و ERRS_C.
!>

المعلمات

PREC_TYPE 
!>          PREC_TYPE هو INTEGER
!>     يحدد الدقة الوسيطة التي سيتم استخدامها في التنقيح.
!>     يتم تعريف القيمة بواسطة ILAPREC(P) حيث P هو CHARACTER و P
!>          = 'S':  Single (أحادي)
!>          = 'D':  Double (مزدوج)
!>          = 'I':  Indigenous (أصلي)
!>          = 'X' أو 'E':  Extra (إضافي)
!>

!>          TRANS_TYPE هو INTEGER
!>     يحدد عملية النقل على A.
!>     يتم تعريف القيمة بواسطة ILATRANS(T) حيث T هو CHARACTER و T
!>          = 'N':  No transpose (بدون نقل)
!>          = 'T':  Transpose (نقل)
!>          = 'C':  Conjugate transpose (نقل مترافق)
!>

N

!>          N هو INTEGER
!>     عدد المعادلات الخطية، أي رتبة
!>     المصفوفة A. N >= 0.
!>

NRHS

!>          NRHS هو INTEGER
!>     عدد الأطراف اليمنى، أي عدد أعمدة
!>     المصفوفة B.
!>

A

!>          A هو مصفوفة COMPLEX*16، البعد (LDA,N)
!>     عند الدخول، المصفوفة A بحجم N-by-N.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A. LDA >= max(1,N).
!>

AF

!>          AF هو مصفوفة COMPLEX*16، البعد (LDAF,N)
!>     العوامل L و U من التحليل
!>     A = P*L*U كما تم حسابه بواسطة ZGETRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF. LDAF >= max(1,N).
!>

IPIV

!>          IPIV هو مصفوفة INTEGER، البعد (N)
!>     مؤشرات المحور من تحليل A = P*L*U
!>     كما تم حسابه بواسطة ZGETRF؛ تم تبديل الصف i من المصفوفة
!>     مع الصف IPIV(i).
!>

COLEQU

!>          COLEQU هو LOGICAL
!>     إذا كان .TRUE. فقد تم إجراء موازنة للأعمدة على A قبل استدعاء
!>     هذا الروتين. هذا ضروري لحساب الحل وحدود الخطأ
!>     بشكل صحيح.
!>

C

!>          C هو مصفوفة DOUBLE PRECISION، البعد (N)
!>     عوامل قياس الأعمدة لـ A. إذا كان COLEQU = .FALSE.، لم يتم الوصول إلى C.
!>     إذا تم إدخال C، يجب أن يكون كل عنصر من C قوى
!>     للأساس لضمان حل موثوق وتقديرات للأخطاء.
!>     القياس بقوى الأساس لا يسبب أخطاء تقريب إلا إذا
!>     كانت النتيجة تحت التدفق أو تجاوزت التدفق. أخطاء التقريب أثناء القياس
!>     تؤدي إلى التنقيح بمصفوفة ليست مكافئة للمصفوفة
!>     المدخلة، مما ينتج تقديرات للخطأ قد لا تكون
!>     موثوقة.
!>

B

!>          B هو مصفوفة COMPLEX*16، البعد (LDB,NRHS)
!>     مصفوفة الطرف الأيمن B.
!>

LDB

!>          LDB هو INTEGER
!>     البعد الرائد للمصفوفة B. LDB >= max(1,N).
!>

Y

!>          Y هو مصفوفة COMPLEX*16، البعد (LDY,NRHS)
!>     عند الدخول، مصفوفة الحل X، كما تم حسابها بواسطة ZGETRS.
!>     عند الخروج، مصفوفة الحل المحسنة Y.
!>

LDY

!>          LDY هو INTEGER
!>     البعد الرائد للمصفوفة Y. LDY >= max(1,N).
!>

BERR_OUT

!>          BERR_OUT هو مصفوفة DOUBLE PRECISION، البعد (NRHS)
!>     عند الخروج، تحتوي BERR_OUT(j) على الخطأ النسبي المكوني الخلفي
!>     للطرف الأيمن j من الصيغة
!>         max(i) ( abs(RES(i)) / ( abs(op(A_s))*abs(Y) + abs(B_s) )(i) )
!>     حيث abs(Z) هي القيمة المطلقة المكونية للمصفوفة
!>     أو المتجه Z. يتم حساب هذا بواسطة ZLA_LIN_BERR.
!>

N_NORMS

!>          N_NORMS هو INTEGER
!>     يحدد حدود الخطأ التي سيتم إرجاعها (انظر ERRS_N
!>     و ERRS_C).
!>     إذا كان N_NORMS >= 1، قم بإرجاع حدود الخطأ المعيارية.
!>     إذا كان N_NORMS >= 2، قم بإرجاع حدود الخطأ المكونية.
!>

ERRS_N

!>          ERRS_N هو مصفوفة DOUBLE PRECISION، البعد (NRHS, N_ERR_BNDS)
!>     لكل طرف أيمن، تحتوي هذه المصفوفة على معلومات حول
!>     حدود الخطأ المختلفة وأرقام الشرط المقابلة لـ
!>     الخطأ النسبي المعياري، والذي يتم تعريفه على النحو التالي:
!>
!>     الخطأ النسبي المعياري في المتجه الحل i:
!>             max_j (abs(XTRUE(j,i) - X(j,i)))
!>            ------------------------------
!>                  max_j abs(X(j,i))
!>
!>     يتم فهرست المصفوفة حسب نوع معلومات الخطأ كما هو موضح
!>     أدناه. يوجد حاليًا ما يصل إلى ثلاث قطع من المعلومات
!>     يتم إرجاعها.
!>
!>     الفهرس الأول في ERRS_N(i,:) يتوافق مع الطرف
!>     الأيمن i.
!>
!>     الفهرس الثاني في ERRS_N(:,err) يحتوي على الثلاثة
!>     حقول التالية:
!>     err = 1  boolean. الثقة في الإجابة إذا كان
!>              رقم الشرط المتبادل أقل من الحد
!>              sqrt(n) * slamch('Epsilon').
!>
!>     err = 2  حد الخطأ: الخطأ الأمامي المقدر،
!>              على الأرجح ضمن عامل 10 من الخطأ الحقيقي
!>              طالما أن الإدخال التالي أكبر من الحد
!>              sqrt(n) * slamch('Epsilon'). يجب أن يتم الوثوق في حد الخطأ هذا
!>              فقط إذا كان المنطق السابق صحيحًا.
!>
!>

NAME

zla_gerfsx_extended - Auxiliary routine for ZGECON, ZGERQ, ZGETRS, ZGETRF, ZTRCON, ZTRRS, ZTRSV

SYNOPSIS

    call zla_gerfsx_extended( &
                                 A, lda, b, ldb, x, ldx, xfact, y, ldy, work, lwork, iwork, &
                                 rnorm, rpvgrw, params, errs_n, errs_c, res, ayb, dy, y_tail, &
                                 rcond, ithresh, rthresh, dz_ub, ignore_cwise, info &
                              )

Function/Subroutine Documentation

    A is COMPLEX*16 array, dimension (LDA, N)
    On entry, A is the matrix or the relevant part of it.


    LDA is INTEGER
    On entry, LDA is the leading dimension of the array A.


    B is COMPLEX*16 array, dimension (LDB, NRHS)
    On entry, B is the matrix of right-hand sides.


    LDB is INTEGER
    On entry, LDB is the leading dimension of the array B.


    X is COMPLEX*16 array, dimension (LDX, NRHS)
    On entry, X is the computed solution to Ax = B.
    On exit, X contains the solution matrix with refinements.


    LDX is INTEGER
    On entry, LDX is the leading dimension of the array X.


    XFACT is COMPLEX*16 array, dimension (N)
    Workspace and on exit, XFACT contains information about the
    factorization of A.


    Y is COMPLEX*16 array, dimension (N)
    Workspace and on exit, Y contains information about the
    factorization of A.


    LDY is INTEGER
    On entry, LDY is the leading dimension of the array Y.


    WORK is COMPLEX*16 array, dimension (LWORK)
    Workspace and on exit, WORK contains information about the
    factorization of A.


    LWORK is INTEGER
    On entry, LWORK is the dimension of the array WORK.


    IWORK is INTEGER array, dimension (N)
    Workspace.


    RNORM is DOUBLE PRECISION array, dimension (NRHS)
    On entry, RNORM(i) contains the infinity norm of the i-th column
    of B.


    RPVGRW is DOUBLE PRECISION array, dimension (NRHS)
    On exit, RPVGRW(i) contains the infinity norm of the i-th column
    of the solution matrix X.


    PARAMS is DOUBLE PRECISION array, dimension (NYC)
    PARAMS(1) = ?
    PARAMS(2) = ?
    PARAMS(3) = Componentwise relative error parameter.  If PARAMS(3) = 0.0,
                componentwise error bounds are not computed.


    ERRS_N is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
    For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    normwise relative error, which is defined as follows:
    Normwise relative error in the i-th solution vector:
                   abs(x_true - x)
             ---------------------
                    abs(x)
    The array is indexed by the right-hand side i (on which the
    normwise relative error depends), and the type of error
    information as described below. There currently are up to three
    pieces of information returned for each right-hand side. If
    normwise accuracy is not requested (PARAMS(3) is not set to 1.0), then
    ERRS_N is not accessed. If N_ERR_BNDS < 3, then at most
    the first (:,N_ERR_BNDS) entries are returned.
    The first index in ERRS_N(i,:) corresponds to the i-th
    right-hand side.
    The second index in ERRS_N(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').
    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number: Estimated normwise
             reciprocal condition number.  Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*A, where S scales each row by a power of the
             radix so all absolute row sums of Z are approximately 1.
    This subroutine is only responsible for setting the second field
    above.
    See Lapack Working Note 165 for further details and extra
    cautions.


    ERRS_C is DOUBLE PRECISION array, dimension (NRHS, N_ERR_BNDS)
    For each right-hand side, this array contains information about
    various error bounds and condition numbers corresponding to the
    componentwise relative error, which is defined as follows:
    Componentwise relative error in the ith solution vector:
                   abs(XTRUE(j,i) - X(j,i))
             max_j ----------------------
                         abs(X(j,i))
    The array is indexed by the right-hand side i (on which the
    componentwise relative error depends), and the type of error
    information as described below. There currently are up to three
    pieces of information returned for each right-hand side. If
    componentwise accuracy is not requested (PARAMS(3) = 0.0), then
    ERRS_C is not accessed.  If N_ERR_BNDS < 3, then at most
    the first (:,N_ERR_BNDS) entries are returned.
    The first index in ERRS_C(i,:) corresponds to the ith
    right-hand side.
    The second index in ERRS_C(:,err) contains the following
    three fields:
    err = 1  boolean. Trust the answer if the
             reciprocal condition number is less than the threshold
             sqrt(n) * slamch('Epsilon').
    err = 2  error bound: The estimated forward error,
             almost certainly within a factor of 10 of the true error
             so long as the next entry is greater than the threshold
             sqrt(n) * slamch('Epsilon'). This error bound should only
             be trusted if the previous boolean is true.
    err = 3  Reciprocal condition number: Estimated componentwise
             reciprocal condition number.  Compared with the threshold
             sqrt(n) * slamch('Epsilon') to determine if the error
             estimate is . These reciprocal condition
             numbers are 1 / (norm(Z^{-1},inf) * norm(Z,inf)) for some
             appropriately scaled matrix Z.
             Let Z = S*(A*diag(x)), where x is the solution for the
             current right-hand side and S scales each row of
             A*diag(x) by a power of the radix so all absolute row
             sums of Z are approximately 1.
    This subroutine is only responsible for setting the second field
    above.
    See Lapack Working Note 165 for further details and extra
    cautions.


    RES is COMPLEX*16 array, dimension (N)
    Workspace to hold the intermediate residual.


    AYB is DOUBLE PRECISION array, dimension (N)
    Workspace.


    DY is COMPLEX*16 array, dimension (N)
    Workspace to hold the intermediate solution.


    Y_TAIL is COMPLEX*16 array, dimension (N)
    Workspace to hold the trailing bits of the intermediate solution.


    RCOND is DOUBLE PRECISION
    Reciprocal scaled condition number.  This is an estimate of the
    reciprocal Skeel condition number of the matrix A after
    equilibration (if done).  If this is less than the machine
    precision (in particular, if it is zero), the matrix is singular
    to working precision.  Note that the error may still be small even
    if this number is very small and the matrix appears ill-
    conditioned.


    ITHRESH is INTEGER
    The maximum number of residual computations allowed for
    refinement. The default is 10. For 'aggressive' set to 100 to
    permit convergence using approximate factorizations or
    factorizations other than LU. If the factorization uses a
    technique other than Gaussian elimination, the guarantees in
    ERRS_N and ERRS_C may no longer be trustworthy.


    RTHRESH is DOUBLE PRECISION
    Determines when to stop refinement if the error estimate stops
    decreasing. Refinement will stop when the next solution no longer
    satisfies norm(dx_{i+1}) < RTHRESH * norm(dx_i) where norm(Z) is
    the infinity norm of Z. RTHRESH satisfies 0 < RTHRESH <= 1. The
    default value is 0.5. For 'aggressive' set to 0.9 to permit
    convergence on extremely ill-conditioned matrices. See LAWN 165
    for more details.


    DZ_UB is DOUBLE PRECISION
    Determines when to start considering componentwise convergence.
    Componentwise convergence is only considered after each component
    of the solution Y is stable, which we define as the relative
    change in each component being less than DZ_UB. The default value
    is 0.25, requiring the first bit to be stable. See LAWN 165 for
    more details.


    IGNORE_CWISE is LOGICAL
    If .TRUE. then ignore componentwise convergence. Default value
    is .FALSE..


    INFO is INTEGER
      = 0:  Successful exit.
      < 0:  if INFO = -i, the ith argument to ZGETRS had an illegal
            value
