الوظائف/الإجراءات الفرعية


double precision function zlantr (norm, uplo, diag, m, n, a, lda, work)
ZLANTR تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة شبه منحرفة أو مصفوفة مثلثية.

توثيق الوظيفة/الإجراء الفرعي

double precision function zlantr (character norm, character uplo, character diag, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

ZLANTR تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة شبه منحرفة أو مصفوفة مثلثية.

الغرض:

!>
!> ZLANTR  تُرجع قيمة المعيار الواحد، أو معيار فروبينيوس، أو
!> المعيار اللانهائي، أو العنصر ذو القيمة المطلقة الأكبر لمصفوفة
!> شبه منحرفة أو مصفوفة مثلثية A.
!>

تُرجع

ZLANTR 
!>
!>    ZLANTR = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يمثل المعيار الواحد للمصفوفة (أقصى مجموع للأعمدة)،
!> normI  يمثل المعيار اللانهائي للمصفوفة (أقصى مجموع للصفوف)،
!!> و normF  يمثل معيار فروبينيوس للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في ZLANTR كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A شبه منحرفة علوية أم سفلية.
!>          = 'U':  شبه منحرفة علوية
!>          = 'L':  شبه منحرفة سفلية
!>          لاحظ أن A تكون مثلثية بدلاً من شبه منحرفة إذا كان M = N.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A لها قطر واحد أم لا.
!>          = 'N':  قطر غير واحد
!>          = 'U':  قطر واحد
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A.  M >= 0، وإذا كان
!>          UPLO = 'U'، فإن M <= N.  عندما يكون M = 0، يتم تعيين ZLANTR إلى صفر.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة A.  N >= 0، وإذا كان
!>          UPLO = 'L'، فإن N <= M.  عندما يكون N = 0، يتم تعيين ZLANTR إلى صفر.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          المصفوفة شبه المنحرفة A (A تكون مثلثية إذا كان M = N).
!>          إذا كان UPLO = 'U'، فإن الجزء شبه المنحرف العلوي من
!>          المصفوفة A بحجم m × n يحتوي على المصفوفة شبه المنحرفة العلوية،
!>          والجزء المثلثي السفلي تمامًا من A غير مشار إليه.
!>          إذا كان UPLO = 'L'، فإن الجزء شبه المنحرف السفلي من
!>          المصفوفة A بحجم m × n يحتوي على المصفوفة شبه المنحرفة السفلية،
!>          والجزء المثلثي العلوي تمامًا من A غير مشار إليه.  لاحظ
!>          أنه عندما يكون DIAG = 'U'، فإن عناصر القطر في A غير
!>          مشار إليها ويُفترض أنها واحد.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(M,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= M عندما يكون NORM = 'I'؛ بخلاف ذلك، لا تتم
!>          الإشارة إلى WORK.
!>
