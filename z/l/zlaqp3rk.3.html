subroutine zlaqp3rk (integer m, integer n, integer nrhs, integer ioffset, integer nb, double precision abstol, double precision reltol, integer kp1, double precision maxc2nrm, complex*16, dimension( lda, * ) a, integer lda, logical done, integer kb, double precision maxc2nrmk, double precision relmaxc2nrmk, integer, dimension( * ) jpiv, complex*16, dimension( * ) tau, double precision, dimension( * ) vn1, double precision, dimension( * ) vn2, complex*16, dimension( * ) auxv, complex*16, dimension( ldf, * ) f, integer ldf, integer, dimension( * ) iwork, integer info)

ZLAQP3RK تحسب خطوة من تحليل QR المقطوع مع محورية الأعمدة لمصفوفة معقدة m-by-n A block A(IOFFSET+1:M,1:N) باستخدام BLAS المستوى 3 على النحو التالي:

A * P(KB) = Q(KB) * R(KB).

يحاول الروتين تحليل NB عمودًا من A بدءًا من الصف IOFFSET+1 وتحديث المصفوفة المتبقية باستخدام BLAS 3 xGEMM. يتم إرجاع عدد الأعمدة المحللة فعليًا وهو أصغر من NB.

يتم محورية الكتلة A(1:IOFFSET,1:N) وفقًا لذلك، ولكن لا يتم تحليلها.

يقوم الروتين أيضًا بالكتابة فوق مصفوفة الجوانب اليمنى B المخزنة في A(IOFFSET+1:M,1:N+1:N+NRHS) بـ Q(KB)**H * B.

الحالات التي يكون فيها عدد الأعمدة المحللة KB < NB:

!>
!> (1) في بعض الحالات، بسبب الإلغاءات الكارثية، لا يمكنه تحليل جميع الأعمدة NB
!>     ويحتاج إلى تحديث المصفوفة المتبقية.
!>     لذلك، فإن العدد الفعلي للأعمدة المحللة في الكتلة التي تم إرجاعها
!>     في KB أصغر من NB. يتم إرجاع المنطق DONE على أنه FALSE.
!>     يجب أن يستمر تحليل المصفوفة الأصلية A_orig بالكتلة التالية.
!>
!> (2) كلما تم استيفاء معيار التوقف ABSTOL أو RELTOL،
!>     يتوقف تحليل المصفوفة الأصلية A_orig،
!>     يتم إرجاع المنطق DONE على أنه TRUE. عدد الأعمدة المحللة
!>     وهو أصغر من NB يتم إرجاعه في KB.
!>
!> (3) في حالة عدم استخدام كل من معايير التوقف ABSTOL أو RELTOL،
!>     وعندما تكون المصفوفة المتبقية مصفوفة صفرية في بعض خطوات التحليل KB،
!>     يتوقف تحليل المصفوفة الأصلية A_orig،
!>     يتم إرجاع المنطق DONE على أنه TRUE. عدد الأعمدة المحللة
!>     وهو أصغر من NB يتم إرجاعه في KB.
!>
!> (4) كلما تم اكتشاف NaN في المصفوفة A أو في المصفوفة TAU،
!>     يتوقف تحليل المصفوفة الأصلية A_orig،
!>     يتم إرجاع المنطق DONE على أنه TRUE. عدد الأعمدة المحللة
!>     وهو أصغر من NB يتم إرجاعه في KB. يتم تعيين المعلمة INFO
!>     إلى فهرس العمود لأول ظهور لـ NaN.
!>
!>

zlaqp3rk(3) - LAPACK

NAME

zlaqp3rk - this routine is obsolete and has been removed. It is replaced by zlaqp3.

SYNOPSIS

      SUBROUTINE ZLAQP3RK( M, N, K, NB, A, LDA, Q, LDQ,
     $                     LWORK, WORK, TAU, LDT, T, LDF,
     $                     INDTAU, AF, LDAF, B, LDB, INFO )

      INTEGER            INFO, K, LDA, LDAF, LDB, LDF, LDQ, LDT, LWORK,
     $                   M, N, NB

      COMPLEX*16         A( LDA, * ), AF( LDAF, * ), B( LDB, * ),
     $                   Q( LDQ, * ), T( LDT, * ), WORK( * )

      COMPLEX*16         TAU( * )

      INTEGER            INDTAU( * )

Function/Subroutine Documentation

Purpose:

This routine is obsolete and has been removed. It is replaced by zlaqp3.

The following is the documentation for the obsolete routine.

This routine implements a rank-revealing QR factorization of a complex matrix A with column pivoting, using Level 3 BLAS.

The factorization is intended to be used in iterative methods for solving least squares problems. The matrix A is updated in place.

The rank-revealing QR factorization is of the form

 A = Q * [ Q1 | Q2 ] * [ R11  R12 ] * [ Z  0 ]
         [    |    ]      [ 0   R22 ]   [ 0  I ]

where Z is an upper triangular matrix, Q is unitary, and R11 and R22 are upper triangular matrices. The diagonal elements of R11 and R22 determine the rank of A.

The factorization is computed in blocks of NB columns.

The routine computes the factorization A = P*Q*R, where P is a permutation matrix, Q is unitary and R is upper trapezoidal.

The implementation is based on the QR factorization with rank-revealing properties described in

[1]
C. H. Bischof and G. Quintana-Ortí, “A block QR factorization algorithm with controlled norm reduction,” SIAM J. Sci. Comput., 19(5):1486–1494, 1998.
[2]
Z. Drmac and Z. Bujanovic, “On the failure of rank revealing QR factorization software – a case study,” ACM Trans. Math. Softw., 35(2), Article 12, 2008.

Arguments

M

          M is INTEGER
          The number of rows of the matrix A. M >= 0.

N

          N is INTEGER
          The number of columns of the matrix A. N >= 0.

K

          K is INTEGER
          The number of columns of A to be factorized. 0 <= K <= N.

NB

          NB is INTEGER
          The block size for the QR factorization.

A

          A is COMPLEX*16 array, dimension (LDA,N)
          On entry, the M x N matrix A to be factorized.
          On exit, the factors are stored in A. The upper triangle of A
          stores the R factor, and the elements below the diagonal store
          the Householder vectors.

LDA

          LDA is INTEGER
          The leading dimension of the array A. LDA >= max(1,M).

Q

          Q is COMPLEX*16 array, dimension (LDQ,K)
          On entry, Q contains a unitary matrix.
          On exit, Q has been updated by multiplication from the left
          by the block Householder transformations.

LDQ

          LDQ is INTEGER
          The leading dimension of the array Q. LDQ >= max(1,M).

LWORK

          LWORK is INTEGER
          The dimension of the array WORK. LWORK >= NB*NB + NB.

WORK

          WORK is COMPLEX*16 array, dimension (LWORK)
          Workspace array.

TAU

          TAU is COMPLEX*16 array, dimension (min(M,N))
          On exit, TAU(i) contains the scalar factor of the elementary
          factor H(i), where N = min(M,N).

LDT

          LDT is INTEGER
          The leading dimension of the array T. LDT >= max(1,NB).

T

          T is COMPLEX*16 array, dimension (LDT,NB)
          On exit, T contains the block Householder transformations
          used to update the right-hand-side matrix B.

LDF

          LDF is INTEGER
          The leading dimension of the array F. LDF >= max(1,NB).

F

          F is COMPLEX*16 array, dimension (LDF,NB)
          Matrix F**H = L*(Y**H)*A.

INDTAU

          INDTAU is INTEGER array, dimension (NB)
          On exit, INDTAU(i) is the row index where the i-th
          factorization column is stored.

AF

          AF is COMPLEX*16 array, dimension (LDAF,NB)
          On exit, AF contains the upper triangular matrix T.
          The elements below the diagonal of AF are not set.

LDAF

          LDAF is INTEGER
          The leading dimension of the array AF. LDAF >= max(1,M).

B

          B is COMPLEX*16 array, dimension (LDB,NRHS)
          On entry, the right-hand-side matrix.
          On exit, B is updated by multiplication from the left by the
          block Householder transformations.

LDB

          LDB is INTEGER
          The leading dimension of the array B. LDB >= max(1,M).

INFO

          INFO is INTEGER
          = 0:  successful exit
          > 0:  if INFO = k, then the rank is k. The factorization
                completed successfully, but the effective rank of the
                matrix is less than k.
          < 0:  unsuccessful exit
               -i: the i-th argument had an illegal value.

Further Details:

!>             The structure of the algorithm is as follows:
!>
!>             Do NB = 1, K
!>                Compute the norm of the NB-th column of A.
!>                Find the pivot row k such that the NB-th column
!>                of A has the maximum norm among the columns
!>                from NB to N.
!>                Swap row NB and row k.
!>                Compute the Householder vector v for column NB.
!>                Update the right-hand-side matrix B. Both these
!>                blocks have been updated by multiplication from
!>                the left by Q(KB)**H.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A. LDA >= max(1,M).
!>

DONE

!>          DONE is LOGICAL
!>          TRUE: a) if the factorization completed before processing
!>                   all min(M-IOFFSET,NB,N) columns due to ABSTOL
!>                   or RELTOL criterion,
!>                b) if the factorization completed before processing
!>                   all min(M-IOFFSET,NB,N) columns due to the
!>                   residual matrix being a ZERO matrix.
!>                c) when NaN was detected in the matrix A
!>                   or in the array TAU.
!>          FALSE: otherwise.
!>

KB

!>          KB is INTEGER
!>          Factorization rank of the matrix A, i.e. the rank of
!>          the factor R, which is the same as the number of non-zero
!>          rows of the factor R.  0 <= KB <= min(M-IOFFSET,NB,N).
!>
!>          KB also represents the number of non-zero Householder
!>          vectors.
!>

MAXC2NRMK

!>          MAXC2NRMK is DOUBLE PRECISION
!>          The maximum column 2-norm of the residual matrix,
!>          when the factorization stopped at rank KB. MAXC2NRMK >= 0.
!>

RELMAXC2NRMK

!>          RELMAXC2NRMK is DOUBLE PRECISION
!>          The ratio MAXC2NRMK / MAXC2NRM of the maximum column
!>          2-norm of the residual matrix (when the factorization
!>          stopped at rank KB) to the maximum column 2-norm of the
!>          original matrix A_orig. RELMAXC2NRMK >= 0.
!>

JPIV

!>          JPIV is INTEGER array, dimension (N)
!>          Column pivot indices, for 1 <= j <= N, column j
!>          of the matrix A was interchanged with column JPIV(j).
!>

TAU

!>          TAU is COMPLEX*16 array, dimension (min(M-IOFFSET,N))
!>          The scalar factors of the elementary reflectors.
!>

VN1

!>          VN1 is DOUBLE PRECISION array, dimension (N)
!>          The vector with the partial column norms.
!>

VN2

!>          VN2 is DOUBLE PRECISION array, dimension (N)
!>          The vector with the exact column norms.
!>

AUXV

!>          AUXV is COMPLEX*16 array, dimension (NB)
!>          Auxiliary vector.
!>

F

!>          F is COMPLEX*16 array, dimension (LDF,NB)
!>          Matrix F**H = L*(Y**H)*A.
!>

LDF

!>          LDF is INTEGER
!>          The leading dimension of the array F. LDF >= max(1,N+NRHS).
!>

IWORK

!>          IWORK is INTEGER array, dimension (N-1).
!>          Is a work array. ( IWORK is used to store indices
!>          of  columns for norm downdating in the residual
!>          matrix ).
!>

INFO

!>          INFO is INTEGER
!>          1) INFO = 0: successful exit.
!>          2) If INFO = j_1, where 1 <= j_1 <= N, then NaN was
!>             detected and the routine stops the computation.
!>             The j_1-th column of the matrix A or the j_1-th
!>             element of array TAU contains the first occurrence
!>             of NaN in the factorization step KB+1 ( when KB columns
!>             have been factorized ).
!>
!>             On exit:
!>             KB                  is set to the number of
!>                                    factorized columns without
!>                                    exception.
!>             MAXC2NRMK           is set to NaN.
!>             RELMAXC2NRMK        is set to NaN.
!>             TAU(KB+1:min(M,N))     is not set and contains undefined
!>                                    elements. If j_1=KB+1, TAU(KB+1)
!>                                    may contain NaN.
!>          3) If INFO = j_2, where N+1 <= j_2 <= 2*N, then no NaN
!>             was detected, but +Inf (or -Inf) was detected and
!>             the routine continues the computation until completion.
!>             The (j_2-N)-th column of the matrix A contains the first
!>             occurrence of +Inf (or -Inf) in the actorization
!>             step KB+1 ( when KB columns have been factorized ).
!>
