zlatm2(3)

Name

zlatm2 - compute the scaled dot product of two vectors

Syntax

SUBROUTINE zlatm2( trans, n, alpha, x, incx, y, incy )
CHARACTER trans
INTEGER n
REAL*8 alpha
REAL*8 x( * )
INTEGER incx
REAL*8 y( * )
INTEGER incy

Description

zlatm2 computes the scaled dot product of two vectors:

    y := alpha * x * trans * y
trans

Specifies whether to transpose the vectors. If 'N', no transpose is performed. If 'T' or 'C', a transpose is performed.

n

The number of elements in the vectors.

alpha

The scaling factor.

x

The first vector.

incx

The increment for the elements of x.

y

The second vector.

incy

The increment for the elements of y.

الوصف

يقوم zlatm2 بحساب حاصل الضرب النقطي المتدرج للمتجهين:

    y := alpha * x * trans * y
trans

يحدد ما إذا كان سيتم تبديل المتجهات. إذا كانت 'N'، فلن يتم إجراء تبديل. إذا كانت 'T' أو 'C'، فسيتم إجراء تبديل.

n

عدد العناصر في المتجهات.

alpha

عامل القياس.

x

المتجه الأول.

incx

الزيادة لعناصر x.

y

المتجه الثاني.

incy

الزيادة لعناصر y.
