subroutine zlaic1 (integer job, integer j, complex*16, dimension( j ) x, double precision sest, complex*16, dimension( j ) w, complex*16 gamma, double precision sestpr, complex*16 s, complex*16 c)

ZLAIC1 تطبق خطوة واحدة من تقدير الشرط المتزايد.

الغرض:

!>
!> ZLAIC1 تطبق خطوة واحدة من تقدير الشرط المتزايد في
!> أبسط صيغتها:
!>
!> لتكن x، twonorm(x) = 1، متجهًا مفردًا تقريبيًا لمصفوفة مثلثية سفلية
!> بحجم j*j، L، بحيث
!>          twonorm(L*x) = sest
!> ثم تحسب ZLAIC1 sestpr، s، c بحيث
!> المتجه
!>                 [ s*x ]
!>          xhat = [  c  ]
!> هو متجه مفرد تقريبي للمصفوفة
!>                 [ L       0  ]
!>          Lhat = [ w**H gamma ]
!> بالمعنى التالي
!>          twonorm(Lhat*xhat) = sestpr.
!>
!> اعتمادًا على JOB، يتم حساب تقدير للقيمة المفردة الأكبر أو الأصغر.
!>
!> لاحظ أن [s c]**H و sestpr**2 هما زوج قيمة ذاتية للنظام
!>
!>     diag(sest*sest, 0) + [alpha  gamma] * [ conjg(alpha) ]
!>                                           [ conjg(gamma) ]
!>
!> حيث  alpha =  x**H * w.
!>
