الوظائف/الإجراءات الفرعية


double precision function zlansy (norm, uplo, n, a, lda, work)
ZLANSY ترجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة معقدة.

توثيق الوظيفة/الإجراء الفرعي

double precision function zlansy (character norm, character uplo, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

ZLANSY ترجع قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة معقدة.

الغرض:

!>
!> ZLANSY  ترجع قيمة المعيار واحد،  أو معيار فروبنيوس،  أو
!> المعيار اللانهائي،  أو  العنصر ذي القيمة المطلقة الأكبر  لمصفوفة
!> متماثلة معقدة A.
!>

ترجع

ZLANSY 
!>
!>    ZLANSY = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  تشير إلى  المعيار واحد للمصفوفة (أكبر مجموع أعمدة)،
!> normI  تشير إلى  المعيار اللانهائي  للمصفوفة  (أكبر مجموع صفوف) و
!> normF  تشير إلى  معيار فروبنيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في ZLANSY كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان سيتم الرجوع إلى الجزء العلوي أو السفلي المثلثي
!>          للمصفوفة المتماثلة A.
!>          = 'U':  يتم الرجوع إلى الجزء العلوي المثلثي من A
!>          = 'L':  يتم الرجوع إلى الجزء السفلي المثلثي من A
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين ZLANSY
!>          إلى صفر.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          المصفوفة المتماثلة A.  إذا كان UPLO = 'U'، فإن الجزء العلوي
!>          المثلثي ذي الأبعاد N × N في بداية A يحتوي على الجزء العلوي
!>          المثلثي للمصفوفة A، ولا يتم الرجوع إلى الجزء السفلي المثلثي
!>          الصارم من A.  إذا كان UPLO = 'L'، فإن الجزء السفلي المثلثي
!>          ذي الأبعاد N × N في بداية A يحتوي على الجزء السفلي المثلثي
!>          للمصفوفة A، ولا يتم الرجوع إلى الجزء العلوي المثلثي الصارم
!>          من A.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A.  LDA >= max(N,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'. بخلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
