subroutine zlatbs (character uplo, character trans, character diag, character normin, integer n, integer kd, complex*16, dimension( ldab, * ) ab, integer ldab, complex*16, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

ZLATBS تحل نظامًا مثلثيًا نطاقيًا.

الغرض:

!>
!> ZLATBS يحل أحد الأنظمة المثلثية
!>
!>    A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b,
!>
!> مع قياس لمنع تجاوز السعة، حيث A مصفوفة نطاقية مثلثية علوية أو سفلية.  حيث A**T تدل على منقول A، و x و b
!> متجهات مكونة من n عنصر، و s هو عامل قياس، عادة ما يكون أقل من أو
!!> يساوي 1، يتم اختياره بحيث تكون مكونات x أقل من
!> عتبة تجاوز السعة. إذا لم يتسبب النظام غير المقاس في
!> تجاوز السعة، يتم استدعاء روتين BLAS من المستوى 2 ZTBSV. إذا كانت المصفوفة A
!> منفردة (A(j,j) = 0 لبعض j)، فعندئذ يتم تعيين s إلى 0 ويتم
!> إرجاع حل غير تافه لـ A*x = 0.
!>

المعلمات

UPLO 
!>          UPLO is CHARACTER*1
!>          تحدد ما إذا كانت المصفوفة A علوية أم سفلية مثلثية.
!>          = 'U':  علوية مثلثية
!>          = 'L':  سفلية مثلثية
!>

TRANS

!>          TRANS is CHARACTER*1
!>          تحدد العملية المطبقة على A.
!>          = 'N':  حل A * x = s*b     (بدون منقول)
!>          = 'T':  حل A**T * x = s*b  (منقول)
!>          = 'C':  حل A**H * x = s*b  (منقول مرافق)
!>

DIAG

!>          DIAG is CHARACTER*1
!>          تحدد ما إذا كانت المصفوفة A وحدوية مثلثية أم لا.
!>          = 'N':  غير وحدوية مثلثية
!>          = 'U':  وحدوية مثلثية
!>

NORMIN

!>          NORMIN is CHARACTER*1
!>          تحدد ما إذا كان CNORM قد تم تعيينه أم لا.
!>          = 'Y':  يحتوي CNORM على معايير الأعمدة عند الإدخال
!>          = 'N':  لم يتم تعيين CNORM عند الإدخال. عند الخروج، سيتم
!>                  حساب المعايير وتخزينها في CNORM.
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          عدد الأقطار الفرعية أو الأقطار العلوية في
!>          المصفوفة المثلثية A.  KD >= 0.
!>

AB

!>          AB is COMPLEX*16 array, dimension (LDAB,N)
!>          المصفوفة المثلثية العلوية أو السفلية النطاقية A، مخزنة في
!>          أول KD+1 صفوف من المصفوفة. يتم تخزين العمود j من A في
!>          العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd)<=i<=j;
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)    = A(i,j) لـ j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB is INTEGER
!>          البعد الرئيسي للمصفوفة AB.  LDAB >= KD+1.
!>

X

!>          X is COMPLEX*16 array, dimension (N)
!>          عند الإدخال، الجانب الأيمن b للنظام المثلثي.
!>          عند الخروج، يتم الكتابة فوق X بالمتجه الحل x.
!>

SCALE

!>          SCALE is DOUBLE PRECISION
!>          عامل القياس s للنظام المثلثي
!>             A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b.
!>          إذا كان SCALE = 0، فإن المصفوفة A منفردة أو مقاسة بشكل سيء،
!>          والمتجه x هو حل صحيح أو تقريبي لـ A*x = 0.
!>

CNORM

!>          CNORM is DOUBLE PRECISION array, dimension (N)
!>
!>          إذا كان NORMIN = 'Y'، فإن CNORM هو وسيط إدخال و CNORM(j)
!>          يحتوي على معيار الجزء غير القطري من العمود j
!>          من A. إذا كان TRANS = 'N'، يجب أن يكون CNORM(j) أكبر من أو يساوي
!>          المعيار اللانهائي، وإذا كان TRANS = 'T' أو 'C'، يجب أن يكون CNORM(j)
!>          أكبر من أو يساوي المعيار 1.
!>
!>          إذا كان NORMIN = 'N'، فإن CNORM هو وسيط إخراج و CNORM(j)
!>          يعيد المعيار 1 للجزء غير القطري من العمود j
!>          من A.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  إنهاء ناجح
!>          < 0:  إذا كان INFO = -k، فإن الوسيط k كان له قيمة غير قانونية
!>

تفاصيل إضافية:

!>
!> يتم حساب حد تقريبي للمكونات x؛ إذا كان هذا أقل من تجاوز السعة، يتم
!> استدعاء ZTBSV، وإلا، يتم استخدام كود محدد يتحقق من احتمالية
!> تجاوز السعة أو القسمة على صفر عند كل عملية.
!>
!> يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!> إذا كانت A مثلثية سفلية هي
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> قم بتعريف حدود لمكونات x بعد j تكرارات للحلقة:
!>     M(j) = حد لـ x[1:j]
!>     G(j) = حد لـ x[j+1:n]
!> في البداية، لنفترض M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!> ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> حيث CNORM(j+1) أكبر من أو يساوي المعيار اللانهائي
!> للعمود j+1 من A، باستثناء القطر. وبالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> بما أن |x(j)| <= M(j)، نستخدم روتين BLAS من المستوى 2 ZTBSV إذا كان
!> مقلوب أكبر M(j) لـ j=1,..,n أكبر من
!> max(underflow, 1/overflow).
!>
!> يستخدم الحد لـ x(j) أيضًا لتحديد متى يمكن تنفيذ خطوة في
!> المخطط العمودي دون الخوف من تجاوز السعة. إذا
!> تجاوز الحد المحسوب ثابتًا كبيرًا، يتم قياس x لمنع تجاوز السعة، ولكن إذا
!> تجاوز الحد، يتم تعيين x إلى 0، و x(j) إلى
!> 1، و scale إلى 0، ويتم العثور على حل غير تافه لـ A*x = 0.
!>
!> وبالمثل، يتم استخدام مخطط صفي لحل A**T *x = b أو
!> A**H *x = b. الخوارزمية الأساسية لـ A العلوية المثلثية هي
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end
!>
!> نقوم بحساب حدين في نفس الوقت
!>       G(j) = حد لـ ( b(i) - A[1:i-1,i]' * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد لـ x(i)، 1<=i<=j
!>
!> القيم الابتدائية هي G(0) = 0، M(0) = max{b(i), i=1,..,n}، ونقوم
!> بإضافة القيد G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!> ثم الحد لـ x(j) هو
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> ويمكننا استدعاء ZTBSV بأمان إذا كان 1/M(n) و 1/G(n) كلاهما أكبر
!> من max(underflow, 1/overflow).
!>

zlatbs(3)

NAME

zlatbs - solve a band or general band matrix equation.

SYNOPSIS

SUBROUTINE ZLATBS( UPLO, TRANSR, DIAG, NORMB, N, NB, A, LDA, B, LDB, X, LDX, INFO )

Function/Subroutine Documentation

ZLATBS solves a system of linear equations of the form

A * X = B,

or

A**T * X = B,

or

A**H * X = B,

where A is a triangular band matrix, and the matrix A has been
factored by either the left or right Cholesky factorization.

Parameters

UPLO
(input) CHARACTER*1
Specifies whether the matrix A is upper or lower triangular.
= 'U': Upper triangular band matrix.
= 'L': Lower triangular band matrix.
TRANSR
(input) CHARACTER*1
Specifies the form of the matrix A.
= 'N': A is not transposed.
= 'T': A is transposed.
DIAG
(input) CHARACTER*1
Specifies whether or not the matrix is non-unit triangular.
= 'N': Not unit triangular.
= 'U': Unit triangular.
NORMB
(input) CHARACTER*1
Specifies the form of the matrix B.
= 'N': B is not transposed.
= 'T': B is transposed.
N
(input) INTEGER
The order of the matrix A. N >= 0.
NB
(input) INTEGER
The number of subdiagonals and superdiagonals in the band.
NB >= 0.
A
(input) DOUBLE PRECISION array, dimension (LDA, K+1)
The triangular band matrix A. The k-th column of A is in the
k-th column of the array A. The diagonal elements of A are in
A(K+1, K+1).
LDA
(input) INTEGER
The leading dimension of the array A. LDA >= K+1.
B
(input) DOUBLE PRECISION array, dimension (LDB, NRHS)
The right-hand side matrix B.
LDB
(input) INTEGER
The leading dimension of the array B. LDB >= max(1, N).
X
(output) DOUBLE PRECISION array, dimension (LDX, NRHS)
The solution matrix X.
LDX
(input) INTEGER
The leading dimension of the array X. LDX >= max(1, N).
INFO
(output) INTEGER
INFO:
= 0: successful exit
<> 0: if INFO = -i, the i-th parameter had an
illegal value.
