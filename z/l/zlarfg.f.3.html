subroutine zlarfg (integer n, complex*16 alpha, complex*16, dimension( * ) x, integer incx, complex*16 tau)

ZLARFG تنشئ عاكسًا أوليًا (مصفوفة هاوسهولدر).

الغرض:

!>
!> ZLARFG تنشئ عاكسًا أوليًا مركبًا H من الدرجة n، بحيث
!>
!>       H**H * ( alpha ) = ( beta ),   H**H * H = I.
!>              (   x   )   (   0  )
!>
!> حيث alpha و beta قيمتان عدديتان، مع كون beta حقيقية، و x متجه
!> مركب من (n-1) عنصر. تمثل H بالصيغة
!>
!>       H = I - tau * ( 1 ) * ( 1 v**H ) ,
!>                     ( v )
!>
!> حيث tau قيمة عددية مركبة و v متجه مركب من (n-1) عنصر. لاحظ أن H ليست
!> الهرمية.
!>
!> إذا كانت عناصر x كلها صفر و alpha حقيقية، فإن tau = 0
!> وتعتبر H مصفوفة الوحدة.
!>
!> خلاف ذلك 1 <= real(tau) <= 2 و abs(tau-1) <= 1 .
!>
