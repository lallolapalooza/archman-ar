وثائق الوظيفة/الإجراء الفرعي

subroutine zlatps (character uplo, character trans, character diag, character normin, integer n, complex*16, dimension( * ) ap, complex*16, dimension( * ) x, double precision scale, double precision, dimension( * ) cnorm, integer info)

ZLATPS يحل نظام مثلثي للمعادلات مع المصفوفة المحفوظة في تخزين مكدس.

الغرض:

!>
!> ZLATPS يحل أحد الأنظمة المثلثية
!>
!>    A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b,
!>
!> مع القياس لمنع الحمل الزائد، حيث A هي مصفوفة مثلثية علوية أو سفلية
!> مخزنة في شكل مكدس. هنا A**T تمثل منقول A، A**H تمثل المرافق المنقول لـ A، x و b
!> هما متجهات ذات N عناصر، و s هو عامل قياس، عادة ما يكون أقل من أو
!> يساوي 1، مختار بحيث تكون مكونات x أقل من
!> عتبة الحمل الزائد. إذا لم يتسبب النظام غير المقاس في حدوث حمل زائد،
!> يتم استدعاء روتين ZTPSV ذي المستوى 2 من BLAS. إذا كانت المصفوفة A
!> مفردة (A(j,j) = 0 لبعض j)، فسيتم تعيين s إلى 0 وحل غير بديهي لـ A*x = 0
!> يتم إرجاعه.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية علوية أم سفلية.
!>          = 'U':  مثلثية علوية
!>          = 'L':  مثلثية سفلية
!>

TRANS

!>          TRANS هو CHARACTER*1
!>          يحدد العملية المطبقة على A.
!>          = 'N':  حل A * x = s*b     (بدون منقول)
!>          = 'T':  حل A**T * x = s*b  (منقول)
!>          = 'C':  حل A**H * x = s*b  (منقول المرافق)
!>

DIAG

!>          DIAG هو CHARACTER*1
!>          يحدد ما إذا كانت المصفوفة A مثلثية وحدة أم لا.
!>          = 'N':  مثلثية غير وحدة
!>          = 'U':  مثلثية وحدة
!>

NORMIN

!>          NORMIN هو CHARACTER*1
!>          يحدد ما إذا كان CNORM قد تم تعيينه أم لا.
!>          = 'Y':  يحتوي CNORM على معايير الأعمدة عند الدخول
!>          = 'N':  لم يتم تعيين CNORM عند الدخول. عند الخروج، سيتم
!>                  حساب المعايير وتخزينها في CNORM.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A.  N >= 0.
!>

AP

!>          AP هو مصفوفة COMPLEX*16، بعدها (N*(N+1)/2)
!>          المصفوفة المثلثية العلوية أو السفلية A، مكدسة عمودياً في
!>          مصفوفة خطية. يتم تخزين العمود j من A في المصفوفة
!>          AP كما يلي:
!>          إذا كان UPLO = 'U'، فإن AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

X

!>          X هي مصفوفة COMPLEX*16، بعدها (N)
!>          عند الدخول، الجانب الأيمن b للنظام المثلثي.
!>          عند الخروج، يتم استبدال X بمتجه الحل x.
!>

SCALE

!>          SCALE هو DOUBLE PRECISION
!>          عامل القياس s للنظام المثلثي
!>             A * x = s*b,  A**T * x = s*b,  or  A**H * x = s*b.
!>          إذا كان SCALE = 0، فإن المصفوفة A مفردة أو سيئة القياس،
!>          والمتجه x هو حل صحيح أو تقريبي لـ A*x = 0.
!>

CNORM

!>          CNORM هي مصفوفة DOUBLE PRECISION، بعدها (N)
!>
!>          إذا كان NORMIN = 'Y'، فإن CNORM هو وسيط إدخال و CNORM(j)
!>          يحتوي على معيار الجزء غير القطري للعمود j
!>          من A. إذا كان TRANS = 'N'، يجب أن يكون CNORM(j) أكبر من أو يساوي
!>          المعيار اللانهائي، وإذا كان TRANS = 'T' أو 'C'، يجب أن يكون CNORM(j)
!>          أكبر من أو يساوي المعيار 1.
!>
!>          إذا كان NORMIN = 'N'، فإن CNORM هو وسيط إخراج و CNORM(j)
!>          يعيد المعيار 1 للجزء غير القطري للعمود j
!>          من A.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -k، فإن الوسيط k كان له قيمة غير قانونية
!>

تفاصيل إضافية:

!>
!> يتم حساب حد تقريبي للمتجه x؛ إذا كان أقل من الحمل الزائد، يتم استدعاء ZTPSV،
!> وإلا، يتم استخدام كود محدد يتحقق من احتمالية
!> حدوث حمل زائد أو قسمة على صفر في كل عملية.
!>
!> يتم استخدام مخطط عمودي لحل A*x = b. الخوارزمية الأساسية
!> إذا كانت A مثلثية سفلية هي
!>
!>       x[1:n] := b[1:n]
!>       for j = 1, ..., n
!>            x(j) := x(j) / A(j,j)
!>            x[j+1:n] := x[j+1:n] - x(j) * A[j+1:n,j]
!>       end
!>
!> نحدد حدودًا لمكونات x بعد j تكرارًا للحلقة:
!>     M(j) = حد للمتجه x[1:j]
!>     G(j) = حد للمتجه x[j+1:n]
!> في البداية، نضع M(0) = 0 و G(0) = max{x(i), i=1,...,n}.
!>
!> ثم للتكرار j+1 لدينا
!>     M(j+1) <= G(j) / | A(j+1,j+1) |
!>     G(j+1) <= G(j) + M(j+1) * | A[j+2:n,j+1] |
!>            <= G(j) ( 1 + CNORM(j+1) / | A(j+1,j+1) | )
!>
!> حيث CNORM(j+1) أكبر من أو يساوي المعيار اللانهائي
!> للعمود j+1 من A، باستثناء القطر. وبالتالي
!>
!>     G(j) <= G(0) product ( 1 + CNORM(i) / | A(i,i) | )
!>                  1<=i<=j
!> و
!>
!>     |x(j)| <= ( G(0) / |A(j,j)| ) product ( 1 + CNORM(i) / |A(i,i)| )
!>                                   1<=i< j
!>
!> نظرًا لأن |x(j)| <= M(j)، نستخدم روتين ZTPSV ذي المستوى 2 إذا كان
!> معكوس أكبر M(j)، j=1,..,n، أكبر من
!> max(underflow, 1/overflow).
!>
!> يستخدم الحد على x(j) أيضًا لتحديد متى يمكن تنفيذ خطوة في
!> طريقة عمودية دون خوف من الحمل الزائد. إذا
!> تجاوز الحد المحسوب ثابتًا كبيرًا، يتم قياس x لمنع الحمل الزائد،
!> ولكن إذا تجاوز الحد، يتم تعيين x إلى 0، x(j) إلى
!> 1، و scale إلى 0، ويتم العثور على حل غير بديهي لـ A*x = 0.
!>
!> وبالمثل، يتم استخدام مخطط صفي لحل A**T *x = b أو
!> A**H *x = b. الخوارزمية الأساسية لـ A مثلثية علوية هي
!>
!>       for j = 1, ..., n
!>            x(j) := ( b(j) - A[1:j-1,j]' * x[1:j-1] ) / A(j,j)
!>       end
!>
!> نقوم بحساب حدين بشكل متزامن
!>       G(j) = حد للمتجه ( b(i) - A[1:i-1,i]' * x[1:i-1] )، 1<=i<=j
!>       M(j) = حد للمتجه x(i)، 1<=i<=j
!>
!> القيم الأولية هي G(0) = 0، M(0) = max{b(i)، i=1,..,n}، ونحن
!> نضيف الشرط G(j) >= G(j-1) و M(j) >= M(j-1) لـ j >= 1.
!> ثم الحد على x(j) هو
!>
!>       M(j) <= M(j-1) * ( 1 + CNORM(j) ) / | A(j,j) |
!>
!>            <= M(0) * product ( ( 1 + CNORM(i) ) / |A(i,i)| )
!>                      1<=i<=j
!>
!> ويمكننا استدعاء ZTPSV بأمان إذا كان 1/M(n) و 1/G(n) كلاهما أكبر
!> من max(underflow, 1/overflow).
!>
