ZLARFB يطبق عاكس كتلة أو معكوسه المتقارن على مصفوفة مستطيلة عامة.

توثيق الوظيفة/الروتين الفرعي

subroutine zlarfb (character side, character trans, character direct, character storev, integer m, integer n, integer k, complex*16, dimension( ldv, * ) v, integer ldv, complex*16, dimension( ldt, * ) t, integer ldt, complex*16, dimension( ldc, * ) c, integer ldc, complex*16, dimension( ldwork, * ) work, integer ldwork)

ZLARFB يطبق عاكس كتلة H أو معكوسه المتقارن H**H على مصفوفة مستطيلة عامة C، من اليسار أو اليمين.

الغرض:

!>
!> ZLARFB يطبق عاكس كتلة معقد H أو معكوسه المتقارن H**H على مصفوفة
!> C ذات الأبعاد M-by-N المعقدة، من اليسار أو اليمين.
!>

المعاملات

SIDE 
!>          SIDE is CHARACTER*1
!>          = 'L': تطبيق H أو H**H من اليسار
!>          = 'R': تطبيق H أو H**H من اليمين
!>

TRANS

!>          TRANS is CHARACTER*1
!>          = 'N': تطبيق H (بدون تبديل)
!>          = 'C': تطبيق H**H (تبديل متقاطع)
!>

DIRECT

!>          DIRECT is CHARACTER*1
!>          يشير إلى كيفية تكوين H من حاصل ضرب العواكس الأولية
!>          = 'F': H = H(1) H(2) . . . H(k) (أمامي)
!>          = 'B': H = H(k) . . . H(2) H(1) (خلفي)
!>

STOREV

!>          STOREV is CHARACTER*1
!>          يشير إلى كيفية تخزين المتجهات التي تحدد العواكس الأولية:
!>          = 'C': عموديا
!>          = 'R': صفيا
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة C.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة C.
!>

K

!>          K is INTEGER
!>          رتبة المصفوفة T (= عدد العواكس الأولية التي يحدد حاصل ضربها
!>          العاكس الكتلي).
!>          إذا كان SIDE = 'L'، فإن M >= K >= 0؛
!>          إذا كان SIDE = 'R'، فإن N >= K >= 0.
!>

V

!>          V is COMPLEX*16 array, dimension
!>                                (LDV,K) if STOREV = 'C'
!>                                (LDV,M) if STOREV = 'R' and SIDE = 'L'
!>                                (LDV,N) if STOREV = 'R' and SIDE = 'R'
!>          انظر التفاصيل الإضافية.
!>

LDV

!>          LDV is INTEGER
!>          البعد الرئيسي للمصفوفة V.
!>          إذا كان STOREV = 'C' و SIDE = 'L'، فإن LDV >= max(1,M)؛
!>          إذا كان STOREV = 'C' و SIDE = 'R'، فإن LDV >= max(1,N)؛
!>          إذا كان STOREV = 'R'، فإن LDV >= K.
!>

T

!>          T is COMPLEX*16 array, dimension (LDT,K)
!>          المصفوفة المثلثية K-by-K T في تمثيل العاكس الكتلي.
!>

LDT

!>          LDT is INTEGER
!>          البعد الرئيسي للمصفوفة T. LDT >= K.
!>

C

!>          C is COMPLEX*16 array, dimension (LDC,N)
!>          عند الإدخال، المصفوفة C ذات الأبعاد M-by-N.
!>          عند الخروج، يتم استبدال C بـ H*C أو H**H*C أو C*H أو C*H**H.
!>

LDC

!>          LDC is INTEGER
!>          البعد الرئيسي للمصفوفة C. LDC >= max(1,M).
!>

WORK

!>          WORK is COMPLEX*16 array, dimension (LDWORK,K)
!>

LDWORK

!>          LDWORK is INTEGER
!>          البعد الرئيسي للمصفوفة WORK.
!>          إذا كان SIDE = 'L'، فإن LDWORK >= max(1,N)؛
!>          إذا كان SIDE = 'R'، فإن LDWORK >= max(1,M).
!>

تفاصيل إضافية:

!>
!>  يتم توضيح شكل المصفوفة V وتخزين المتجهات التي تحدد H(i)
!>  بشكل أفضل من خلال المثال التالي مع n = 5 و k = 3.
!>  الجزء المثلثي من V (بما في ذلك قطره) لا تتم الإشارة إليه.
!>
!>  DIRECT = 'F' و STOREV = 'C':         DIRECT = 'F' و STOREV = 'R':
!>
!>               V = (  1       )                 V = (  1 v1 v1 v1 v1 )
!>                   ( v1  1    )                     (     1 v2 v2 v2 )
!>                   ( v1 v2  1 )                     (        1 v3 v3 )
!>                   ( v1 v2 v3 )
!>                   ( v1 v2 v3 )
!>
!>  DIRECT = 'B' و STOREV = 'C':         DIRECT = 'B' و STOREV = 'R':
!>
!>               V = ( v1 v2 v3 )                 V = ( v1 v1  1       )
!>                   ( v1 v2 v3 )                     ( v2 v2 v2  1    )
!>                   (  1 v2 v3 )                     ( v3 v3 v3 v3  1 )
!>                   (     1 v3 )
!>                   (        1 )
!>
