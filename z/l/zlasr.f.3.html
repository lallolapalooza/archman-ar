ZLASR تطبق تسلسلًا من دوران المستوى على مصفوفة مستطيلة عامة.

توثيق الوظيفة/الإجراء الفرعي

subroutine zlasr (character side, character pivot, character direct, integer m, integer n, double precision, dimension( * ) c, double precision, dimension( * ) s, complex*16, dimension( lda, * ) a, integer lda)

ZLASR تطبق تسلسلًا من دوران المستوى الحقيقي على مصفوفة عقدية A، من اليسار أو اليمين.

الغرض:

!>
!> ZLASR تطبق تسلسلًا من دوران المستوى الحقيقي على مصفوفة عقدية
!> A، من اليسار أو اليمين.
!>
!> عندما يكون SIDE = 'L'، يكون التحويل بالشكل
!>
!>    A := P*A
!>
!> وعندما يكون SIDE = 'R'، يكون التحويل بالشكل
!>
!>    A := A*P**T
!>
!> حيث P هي مصفوفة متعامدة تتكون من تسلسل من دورانات المستوى z،
!> مع z = M عندما يكون SIDE = 'L' و z = N عندما يكون SIDE = 'R'،
!> و P**T هي منقولة P.
!>
!> عندما يكون DIRECT = 'F' (تسلسل أمامي)، فإن
!>
!>    P = P(z-1) * ... * P(2) * P(1)
!>
!> وعندما يكون DIRECT = 'B' (تسلسل خلفي)، فإن
!>
!>    P = P(1) * P(2) * ... * P(z-1)
!>
!> حيث P(k) هي مصفوفة دوران مستوى محددة بالدوران 2x2
!>
!>    R(k) = (  c(k)  s(k) )
!>         = ( -s(k)  c(k) ).
!>
!> عندما يكون PIVOT = 'V' (محور متغير)، يتم إجراء الدوران
!> للمستوى (k,k+1)، أي أن P(k) لها الشكل
!>
!>    P(k) = (  1                                            )
!>           (       ...                                     )
!>           (              1                                )
!>           (                   c(k)  s(k)                  )
!>           (                  -s(k)  c(k)                  )
!>           (                                1              )
!>           (                                     ...       )
!>           (                                            1  )
!>
!> حيث يظهر R(k) كتعديل رتبة 2 للمصفوفة الوحدة في الصفوف والأعمدة k و k+1.
!>
!> عندما يكون PIVOT = 'T' (محور علوي)، يتم إجراء الدوران
!> للمستوى (1,k+1)، لذا فإن P(k) لها الشكل
!>
!>    P(k) = (  c(k)                    s(k)                 )
!>           (         1                                     )
!>           (              ...                              )
!>           (                     1                         )
!>           ( -s(k)                    c(k)                 )
!>           (                                 1             )
!>           (                                      ...      )
!>           (                                             1 )
!>
!> حيث يظهر R(k) في الصفوف والأعمدة 1 و k+1.
!> وبالمثل، عندما يكون PIVOT = 'B' (محور سفلي)، يتم إجراء الدوران
!> للمستوى (k,z)، مما يعطي P(k) الشكل
!>
!>    P(k) = ( 1                                             )
!>           (      ...                                      )
!>           (             1                                 )
!>           (                  c(k)                    s(k) )
!>           (                         1                     )
!>           (                              ...              )
!>           (                                     1         )
!>           (                 -s(k)                    c(k) )
!>
!> حيث يظهر R(k) في الصفوف والأعمدة k و z. يتم إجراء الدورانات
!> دون تشكيل P(k) صراحةً.
!>

المعلمات

SIDE 
!>          SIDE is CHARACTER*1
!>          يحدد ما إذا كانت مصفوفة دوران المستوى P مطبقة على
!>          A من اليسار أو اليمين.
!>          = 'L':  يسار، حساب A := P*A
!>          = 'R':  يمين، حساب A:= A*P**T
!>

PIVOT

!>          PIVOT is CHARACTER*1
!>          يحدد المستوى الذي تكون فيه P(k) مصفوفة دوران مستوى
!>          = 'V':  محور متغير، المستوى (k,k+1)
!>          = 'T':  محور علوي، المستوى (1,k+1)
!>          = 'B':  محور سفلي، المستوى (k,z)
!>

DIRECT

!>          DIRECT is CHARACTER*1
!>          يحدد ما إذا كانت P تسلسلًا أماميًا أو خلفيًا لدورانات
!>          المستوى.
!>          = 'F':  أمامي، P = P(z-1)*...*P(2)*P(1)
!>          = 'B':  خلفي، P = P(1)*P(2)*...*P(z-1)
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A. إذا كان m <= 1، يتم العودة الفورية.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة A. إذا كان n <= 1، يتم العودة الفورية.
!>

C

!>          C is DOUBLE PRECISION array, dimension
!>                  (M-1) if SIDE = 'L'
!>                  (N-1) if SIDE = 'R'
!>          جيب التمام c(k) لدورانات المستوى.
!>

S

!>          S is DOUBLE PRECISION array, dimension
!>                  (M-1) if SIDE = 'L'
!>                  (N-1) if SIDE = 'R'
!>          جيب الجيب s(k) لدورانات المستوى. الجزء 2x2 لدوران
!>          المستوى للمصفوفة P(k)، R(k)، له الشكل
!>          R(k) = (  c(k)  s(k) )
!>                 ( -s(k)  c(k) ).
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          المصفوفة A ذات الأبعاد M x N. عند الخروج، يتم استبدال A بـ
!>          P*A إذا كان SIDE = 'R' أو بـ A*P**T إذا كان SIDE = 'L'.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرائد للمصفوفة A. LDA >= max(1,M).
!>
