double precision function zlantr (norm, uplo, diag, m, n, a, lda, work)
ZLANTR تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو أكبر قيمة مطلقة لمصفوفة شبه منحرفة أو مثلثية.

توثيق الوظيفة/الإجراء الفرعي

double precision function zlantr (character norm, character uplo, character diag, integer m, integer n, complex*16, dimension( lda, * ) a, integer lda, double precision, dimension( * ) work)

ZLANTR تُرجع قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذو أكبر قيمة مطلقة لمصفوفة شبه منحرفة أو مثلثية A.

الغرض:

!>
!> ZLANTR  تُرجع قيمة المعيار واحد،  أو معيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو  العنصر ذو أكبر قيمة مطلقة  لمصفوفة
!> شبه منحرفة أو مثلثية A.
!>

تُرجع

ZLANTR 
!>
!>    ZLANTR = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على  المعيار واحد للمصفوفة (أقصى مجموع للأعمدة)،
!> normI  يدل على  المعيار اللانهائي  للمصفوفة (أقصى مجموع للصفوف) و
!> normF  يدل على  معيار فروبينيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة ثابت.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          تحدد القيمة التي سيتم إرجاعها في ZLANTR كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          تحدد ما إذا كانت المصفوفة A شبه منحرفة علوية أو سفلية.
!>          = 'U':  شبه منحرفة علوية
!>          = 'L':  شبه منحرفة سفلية
!>          لاحظ أن A تكون مثلثية بدلاً من شبه منحرفة إذا كان M = N.
!>

DIAG

!>          DIAG is CHARACTER*1
!>          تحدد ما إذا كانت المصفوفة A ذات قطر وحدة أم لا.
!>          = 'N':  قطر غير وحدة
!>          = 'U':  قطر وحدة
!>

M

!>          M is INTEGER
!>          عدد صفوف المصفوفة A.  M >= 0، وإذا كان
!>          UPLO = 'U', فإن M <= N.  عندما M = 0، يتم تعيين ZLANTR إلى صفر.
!>

N

!>          N is INTEGER
!>          عدد أعمدة المصفوفة A.  N >= 0، وإذا كان
!>          UPLO = 'L', فإن N <= M.  عندما N = 0، يتم تعيين ZLANTR إلى صفر.
!>

A

!>          A is COMPLEX*16 array, dimension (LDA,N)
!>          المصفوفة شبه المنحرفة A (A تكون مثلثية إذا كان M = N).
!>          إذا كان UPLO = 'U'، فإن الجزء العلوي العلوي العلوي الأيسر الذي طوله m × n من
!>          المصفوفة A يحتوي على المصفوفة شبه المنحرفة العلوية، والجزء
!>          المثلثي السفلي الصارم لـ A غير مستخدم.
!>          إذا كان UPLO = 'L'، فإن الجزء السفلي السفلي السفلي الأيسر الذي طوله m × n من
!>          المصفوفة A يحتوي على المصفوفة شبه المنحرفة السفلية، والجزء
!>          المثلثي العلوي الصارم لـ A غير مستخدم.  لاحظ
!>          أنه عند DIAGONAL = 'U'، فإن عناصر القطر لـ A ليست
!>          مستخدمة ويفترض أنها واحد.
!>

LDA

!>          LDA is INTEGER
!>          البعد الرئيسي للمصفوفة A.  LDA >= max(M,1).
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= M عندما يكون NORM = 'I'.  بخلاف ذلك، فإن WORK غير
!>          مستخدم.
!>
