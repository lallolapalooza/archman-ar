double precision function zlansp (norm, uplo, n, ap, work)
ZLANSP تعيد قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة مقدمة في شكل مضغوط.

توثيق الوظيفة/الروتين الفرعي

double precision function zlansp (character norm, character uplo, integer n, complex*16, dimension( * ) ap, double precision, dimension( * ) work)

ZLANSP تعيد قيمة المعيار 1، أو معيار فروبنيوس، أو المعيار اللانهائي، أو العنصر ذي القيمة المطلقة الأكبر لمصفوفة متماثلة معقدة مقدمة في شكل مضغوط.

الغرض:

!>
!> ZLANSP  تعيد قيمة المعيار واحد،  أو معيار فروبنيوس،  أو
!> المعيار اللانهائي،  أو  العنصر ذي القيمة المطلقة الأكبر  لمصفوفة متماثلة
!> معقدة A،  المقدمة في شكل مضغوط.
!>

النتائج

ZLANSP 
!>
!>    ZLANSP = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يمثل  المعيار واحد لمصفوفة (أقصى مجموع أعمدة)،
!> normI  يمثل  المعيار اللانهائي  لمصفوفة  (أقصى مجموع صفوف) و
!> normF  يمثل  معيار فروبنيوس  لمصفوفة  (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعاملات

NORM 
!>          NORM is CHARACTER*1
!>          يحدد القيمة التي سيتم إرجاعها في ZLANSP كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي المثلثي للمصفوفة
!>          المتماثلة A قد تم تقديمه.
!>          = 'U':  الجزء العلوي المثلثي لـ A تم تقديمه
!>          = 'L':  الجزء السفلي المثلثي لـ A تم تقديمه
!>

N

!>          N is INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين ZLANSP
!>          إلى صفر.
!>

AP

!>          AP is COMPLEX*16 array, dimension (N*(N+1)/2)
!>          الجزء العلوي أو السفلي المثلثي للمصفوفة المتماثلة A، مضغوط
!>          عمودياً في مصفوفة خطية.  يتم تخزين العمود j للمصفوفة A
!>          في المصفوفة AP كما يلي:
!>          إذا كان UPLO = 'U'، AP(i + (j-1)*j/2) = A(i,j) لـ 1<=i<=j;
!>          إذا كان UPLO = 'L'، AP(i + (j-1)*(2n-j)/2) = A(i,j) لـ j<=i<=n.
!>

WORK

!>          WORK is DOUBLE PRECISION array, dimension (MAX(1,LWORK)),
!>          حيث LWORK >= N عندما يكون NORM = 'I' أو '1' أو 'O'؛ بخلاف ذلك،
!>          لا يتم الإشارة إلى WORK.
!>
