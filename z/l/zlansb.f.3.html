الوظائف/الإجراءات الفرعية


double precision function zlansb (norm, uplo, n, k, ab, ldab, work)
ZLANSB تُعيد قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي أكبر قيمة مطلقة لمصفوفة متناظرة ذات نطاق.

توثيق الوظيفة/الإجراء الفرعي

double precision function zlansb (character norm, character uplo, integer n, integer k, complex*16, dimension( ldab, * ) ab, integer ldab, double precision, dimension( * ) work)

ZLANSB تُعيد قيمة المعيار 1، أو معيار فروبينيوس، أو المعيار اللانهائي، أو العنصر ذي أكبر قيمة مطلقة لمصفوفة متناظرة ذات نطاق.

الغرض:

!>
!> ZLANSB  تُعيد قيمة المعيار واحد،  أو معيار فروبينيوس،  أو
!> المعيار اللانهائي،  أو العنصر ذي أكبر قيمة مطلقة لمصفوفة
!> متناظرة A ذات حجم n × n،  مع k قطر علوي.
!>

تُعيد

ZLANSB 
!>
!>    ZLANSB = ( max(abs(A(i,j))), NORM = 'M' or 'm'
!>             (
!>             ( norm1(A),         NORM = '1', 'O' or 'o'
!>             (
!>             ( normI(A),         NORM = 'I' or 'i'
!>             (
!>             ( normF(A),         NORM = 'F', 'f', 'E' or 'e'
!>
!> حيث  norm1  يدل على  المعيار واحد للمصفوفة (أقصى مجموع للأعمدة)،
!> normI  يدل على  المعيار اللانهائي  للمصفوفة  (أقصى مجموع للصفوف) و
!> normF  يدل على  معيار فروبينيوس  للمصفوفة (الجذر التربيعي لمجموع
!> المربعات).  لاحظ أن  max(abs(A(i,j)))  ليس معيار مصفوفة متسق.
!>

المعلمات

NORM 
!>          NORM هو CHARACTER*1
!>          يحدد القيمة المراد إعادتها في ZLANSB كما هو موضح
!>          أعلاه.
!>

UPLO

!>          UPLO هو CHARACTER*1
!>          يحدد ما إذا كان الجزء العلوي أو السفلي من المثلث للمصفوفة
!>          ذات النطاق A يتم توفيره.
!>          = 'U':  يتم توفير الجزء العلوي من المثلث
!>          = 'L':  يتم توفير الجزء السفلي من المثلث
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.  عندما N = 0، يتم تعيين ZLANSB
!>          إلى صفر.
!>

K

!>          K هو INTEGER
!>          عدد الأقطار العلوية أو الأقطار الفرعية للمصفوفة
!>          ذات النطاق A.  K >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX*16، بعد (LDAB,N)
!>          الجزء العلوي أو السفلي من المثلث للمصفوفة المتناظرة ذات النطاق A،
!>          مخزن في أول K+1 صف من AB.  يتم تخزين العمود j من A
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO = 'U'، فإن AB(k+1+i-j,j) = A(i,j) لـ max(1,j-k)<=i<=j؛
!>          إذا كان UPLO = 'L'، فإن AB(1+i-j,j)   = A(i,j) لـ j<=i<=min(n,j+k).
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرائد للمصفوفة AB.  LDAB >= K+1.
!>

WORK

!>          WORK هي مصفوفة DOUBLE PRECISION، بعد (MAX(1,LWORK))،
!>          حيث LWORK >= N عندما NORM = 'I' or '1' or 'O'; خلاف ذلك،
!>          لا يتم الرجوع إلى WORK.
!>
