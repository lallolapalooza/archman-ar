ZLARRV يحسب المتجهات الذاتية للمصفوفة الثلاثية T = L D LT بمعلومية L و D وتقريبات للقِيَم الذاتية للمصفوفة L D LT.

الغرض:

!>
!> ZLARRV يحسب المتجهات الذاتية للمصفوفة الثلاثية
!> T = L D L**T بمعلومية L و D وتقريبات للقِيَم الذاتية لـ L D L**T.
!> يجب أن تكون القِيَم الذاتية المُدخلة قد تم حسابها بواسطة DLARRE.
!>

NAME

zlarrv

ZLARRC is a subroutine that computes the eigenvalues of a symmetric tridiagonal matrix T which are contained in the interval [a,b].

SYNOPSIS

SUBROUTINE ZLARRV(N, VL, VU, D, E, PIVMIN, TOL, UBND, CSL, CSR,
                 INFO, WORK, IWORK, ISUPPZ)
INTEGER N
DOUBLE PRECISION VL, VU, PIVMIN, TOL, UBND, CSL, CSR
DOUBLE PRECISION D( * ), E( * )
INTEGER INFO
DOUBLE PRECISION WORK( * )
INTEGER IWORK( * )
INTEGER ISUPPZ( * )

Function/Subroutine Documentation

N

!>          N is INTEGER
!>          The order of the matrix T. 1 <= N <= NMAX

VL

!>          VL is DOUBLE PRECISION
!>          The lower bound of the interval.

VU

!>          VU is DOUBLE PRECISION
!>          The upper bound of the interval.

D

!>          D is DOUBLE PRECISION array, dimension (N)
!>          On entry to ZLARRV the array D contains the diagonal entries of
!>          the tridiagonal matrix T.

E

!>          E is DOUBLE PRECISION array, dimension (N-1)
!>          On entry to ZLARRV the array E contains the entries of the
!>          super- and sub-diagonal of the tridiagonal matrix T.

PIVMIN

!>          PIVMIN is DOUBLE PRECISION
!>          The minimum pivot in the bidiagonalization of T. This is used to
!>          decide on the condition number of the bidiagonal blocks.

TOL

!>          TOL is DOUBLE PRECISION
!>          The tolerance used for splitting the problem. If the difference
!>          between eigenvalues is smaller than TOL, the block is split.

UBOUND

!>          UBOUND is DOUBLE PRECISION
!>          A user-supplied bound for the eigenvalues.

CSL

!>          CSL is DOUBLE PRECISION
!>          The left boundary of the current Gerschgorin interval.

CSR

!>          CSR is DOUBLE PRECISION
!>          The right boundary of the current Gerschgorin interval.

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          > 0: A problem occurred in ZLARRV.
!>          < 0: One of the called subroutines signaled an internal problem.
!>               Needs inspection of the corresponding parameter IINFO
!>               for further information.
!>
!>          =-1:  Problem in DLARRB when refining a child's eigenvalues.
!>          =-2:  Problem in DLARRF when computing the RRR of a child.
!>                When a child is inside a tight cluster, it can be difficult
!>                to find an RRR. A partial remedy from the user's point of
!>                view is to make the parameter MINRGP smaller and recompile.
!>                However, as the orthogonality of the computed vectors is
!>                proportional to 1/MINRGP, the user should be aware that
!>                he might be trading in precision when he decreases MINRGP.
!>          =-3:  Problem in DLARRB when refining a single eigenvalue
!>                after the Rayleigh correction was rejected.
!>          = 5:  The Rayleigh Quotient Iteration failed to converge to
!>                full accuracy in MAXITR steps.

WORK

!>          WORK is DOUBLE PRECISION array, dimension (12*N)

IWORK

!>          IWORK is INTEGER array, dimension (7*N)

ISUPPZ

!>          ISUPPZ is INTEGER array, dimension (2*N)
!>          The support of the eigenvectors in Z. If the I-th eigenvalue belongs
!>          to the K-th block, then the eigenvector is stored in
!>          Z(ISUPPZ(2*K-1) : ISUPPZ(2*K)).
