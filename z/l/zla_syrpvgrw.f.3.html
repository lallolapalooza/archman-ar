double precision function zla_syrpvgrw (uplo, n, info, a, lda, af, ldaf, ipiv, work)
ZLA_SYRPVGRW تحسب عامل نمو المحور المعكوس norm(A)/norm(U) لمصفوفة غير محددة متناظرة.

توثيق الوظيفة/الإجراء الفرعي

double precision function zla_syrpvgrw (character*1 uplo, integer n, integer info, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldaf, * ) af, integer ldaf, integer, dimension( * ) ipiv, double precision, dimension( * ) work)

ZLA_SYRPVGRW تحسب عامل نمو المحور المعكوس norm(A)/norm(U) لمصفوفة غير محددة متناظرة.

الغرض:

!>
!>
!> ZLA_SYRPVGRW تحسب عامل نمو المحور المعكوس
!> norm(A)/norm(U).  يتم استخدام المعيار . إذا كان هذا
!> أقل بكثير من 1، فقد يكون استقرار تحليل LU للمصفوفة
!> (المتوازنة) A ضعيفًا. هذا يعني أيضًا أن
!> الحل X، وتقديرات الأرقام الشرطية، وحدود الخطأ قد تكون
!> غير موثوقة.
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>       = 'U':  يتم تخزين المثلث العلوي لـ A؛
!>       = 'L':  يتم تخزين المثلث السفلي لـ A.
!>

N

!>          N هو INTEGER
!>     عدد المعادلات الخطية، أي رتبة
!>     المصفوفة A.  N >= 0.
!>

INFO

!>          INFO هو INTEGER
!>     القيمة INFO التي تم إرجاعها من ZSYTRF، أي أن المحور في
!>     العمود INFO يساوي 0 بالضبط.
!>

A

!>          A هي مصفوفة COMPLEX*16، البعد (LDA,N)
!>     عند الإدخال، المصفوفة N-by-N A.
!>

LDA

!>          LDA هو INTEGER
!>     البعد الرائد للمصفوفة A.  LDA >= max(1,N).
!>

AF

!>          AF هي مصفوفة COMPLEX*16، البعد (LDAF,N)
!>     المصفوفة القطرية الفرعية D والعوامل المستخدمة
!>     للحصول على العامل U أو L كما تم حسابه بواسطة ZSYTRF.
!>

LDAF

!>          LDAF هو INTEGER
!>     البعد الرائد للمصفوفة AF.  LDAF >= max(1,N).
!>

IPIV

!>          IPIV هي مصفوفة INTEGER، البعد (N)
!>     تفاصيل التبادلات والهيكل الفرعي لـ D
!>     كما تم تحديده بواسطة ZSYTRF.
!>

WORK

!>          WORK هي مصفوفة DOUBLE PRECISION، البعد (2*N)
!>
