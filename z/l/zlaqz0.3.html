الغرض:

!>
!> ZLAQZ0 تحسب القيم الذاتية لزوج المصفوفات الحقيقي (H,T)،
!> حيث H مصفوفة هسنبرج عليا و T مصفوفة مثلثة عليا،
!> باستخدام طريقة QZ ذات الإزاحة المزدوجة.
!> أزواج المصفوفات من هذا النوع تنتج عن الاختزال إلى
!> شكل هسنبرج العامي لمصفوفة زوج حقيقي (A,B):
!>
!>    A = Q1*H*Z1**H,  B = Q1*T*Z1**H,
!>
!> كما تم حسابه بواسطة ZGGHRD.
!>
!> إذا كان JOB='S'، يتم اختزال زوج هسنبرج-مثلثي (H,T) أيضًا إلى
!> شكل شور عامي،
!>
!>    H = Q*S*Z**H,  T = Q*P*Z**H,
!>
!> حيث Q و Z مصفوفات وحدوية، P و S مصفوفات مثلثة عليا.
!>
!> اختياريًا، قد يتم ضرب المصفوفة الوحدوية Q من التحلل العامي للشور
!> بعديًا في مصفوفة الإدخال Q1، وقد يتم ضرب المصفوفة Z بعديًا في
!> مصفوفة الإدخال Z1.
!> إذا كانت Q1 و Z1 مصفوفات وحدوية من ZGGHRD التي اختزلت
!> زوج المصفوفات (A,B) إلى شكل هسنبرج العامي، فإن المصفوفات الناتجة
!> Q1*Q و Z1*Z هي العوامل الوحدوية من التحلل العامي للشور لـ (A,B):
!>
!>    A = (Q1*Q)*S*(Z1*Z)**H,  B = (Q1*Q)*P*(Z1*Z)**H.
!>
!> لتجنب الفائض، يتم حساب القيم الذاتية لزوج المصفوفات (H,T) (أو بشكل مكافئ،
!> لـ (A,B)) كزوج من القيم (alpha,beta)، حيث alpha معقدة و beta حقيقية.
!> إذا كانت beta غير صفرية، فإن lambda = alpha / beta هي قيمة ذاتية
!> للمشكلة الذاتية غير المتماثلة العامة (GNEP)
!>    A*x = lambda*B*x
!> وإذا كانت alpha غير صفرية، فإن mu = beta / alpha هي قيمة ذاتية
!> للشكل البديل لـ GNEP
!>    mu*A*y = B*y.
!> يمكن قراءة القيم الذاتية مباشرة من شكل شور العامي:
!>   alpha = S(i,i), beta = P(i,i).
!>
!> المرجع: C.B. Moler & G.W. Stewart, , SIAM J. Numer. Anal., 10(1973),
!>      pp. 241--256.
!>
!> المرجع: B. Kagstrom, D. Kressner, , SIAM J. Numer.
!>      Anal., 29(2006), pp. 199--227.
!>
!> المرجع: T. Steel, D. Camps, K. Meerbergen, R. Vandebril 
!>

NAME

zlaqz0 — wrapper for the QZ iteration subroutine

SYNOPSIS

SUBROUTINE ZLAQZ0( A, LDA, B, LDB, ALPHA, BETA, Q, Z, LDQ, LDZ, WORK, LWORK, REC, INFO )

  CHARACTER A( LDA, * )
  INTEGER LDA
  CHARACTER B( LDB, * )
  INTEGER LDB
  COMPLEX*16 ALPHA( * )
  COMPLEX*16 BETA( * )
  COMPLEX*16 Q( LDQ, * )
  COMPLEX*16 Z( LDZ, * )
  INTEGER LDQ
  INTEGER LDZ
  COMPLEX*16 WORK( * )
  INTEGER LWORK
  INTEGER REC
  INTEGER INFO

Function/Subroutine Documentation

This subroutine computes the eigenvalues of a generalized eigenvalue problem A*x = B*x of the matrix pair (A,B) and optionally the Schur vectors.

The generalized eigenvalue problem is to find the eigenvalues λ and the corresponding left eigenvectors y, and right eigenvectors x such that

y*A = λ*y*B, and A*x = λ*B*x.

The function is called with the matrix A and B in the generalized Hessenberg form and computes the eigenvalues α(i)/β(i) of the matrix pair (A,B).

The purpose of ZLAQZ0 is to provide a simplified interface to the QZ iteration subroutine (ZGEQPF).

The matrix pair (A,B) is assumed to be in generalized Hessenberg form. This means that there exist unitary matrices Q and Z such that

Q*AZ = A' and Q*BZ = B',

where A' is upper triangular and B' is upper triangular with potentially non-zero diagonal entries.

The eigenvalues are returned in the complex array ALPHA and real array BETA. The eigenvalues are the ratios ALPHA(i)/BETA(i).

The function also computes the unitary matrices Q and Z of left and right Schur vectors, respectively. The Schur vectors are the columns of the matrices Q and Z.

The function uses the QZ iteration method to compute the eigenvalues and Schur vectors. The QZ iteration is an iterative algorithm that converges to the Schur decomposition of the matrix pair (A,B).

Arguments

A

A is COMPLEX*16 array, dimension (LDA,N)

LDA

LDA is INTEGER
The leading dimension of A. LDA >= max(1,N).

B

B is COMPLEX*16 array, dimension (LDB,N)

LDB

LDB is INTEGER
The leading dimension of B. LDB >= max(1,N).

ALPHA

ALPHA is COMPLEX*16 array, dimension (N)

BETA

BETA is COMPLEX*16 array, dimension (N)

Q

Q is COMPLEX*16 array, dimension (LDQ,N)
If COMPZ = 'V', the unitary matrix of left Schur vectors of (A,B).
Not referenced if COMPZ = 'N'.

Z

Z is COMPLEX*16 array, dimension (LDZ,N)
If COMPZ = 'V', the unitary matrix of right Schur vectors of (A,B).
Not referenced if COMPZ = 'N'.

LDQ

LDQ is INTEGER
The leading dimension of the array Q. LDQ >= 1.
If COMPZ='V' or 'I', then LDQ >= N.

LDZ

LDZ is INTEGER
The leading dimension of the array Z. LDZ >= 1.
If COMPZ='V' or 'I', then LDZ >= N.

WORK

WORK is COMPLEX*16 array, dimension (MAX(1,LWORK))
On exit, if INFO >= 0, WORK(1) returns the optimal LWORK.

RWORK

RWORK is DOUBLE PRECISION array, dimension (N)

LWORK

LWORK is INTEGER
The dimension of the array WORK. LWORK >= max(1,N).

If LWORK = -1, then a workspace query is assumed; the routine
only calculates the optimal size of the WORK array, returns
this value as the first entry of the WORK array, and no error
message related to LWORK is issued by XERBLA.

REC

REC is INTEGER
   REC indicates the current recursion level. Should be set
   to 0 on first call.

INFO

INFO is INTEGER
= 0: successful exit
< 0: if INFO = -i, the i-th argument had an illegal value
= 1,...,N: the QZ iteration did not converge.  (A,B) is not
in Schur form, but ALPHA(i) and
BETA(i), i=INFO+1,...,N should be correct.
