!>
!> ZDRVBD تتحقق من وظائف تفكيك القيمة المفردة (SVD) ZGESVD,
!> ZGESDD, ZGESVJ, ZGEJSV, ZGESVDX, و ZGESVDQ.
!>
!> ZGESVD و ZGESDD تقوم بتحليل A = U diag(S) VT, حيث U و VT
!> وحدوية (unitary) و diag(S) قطرية مع مدخلات المصفوفة S على
!> قطرها. المدخلات S هي القيم المفردة، غير سالبة
!> ومخزنة بترتيب تنازلي. يمكن لـ U و VT اختيارياً ألا يتم
!> حسابهما، أو استبدالهما على A، أو حسابهما جزئياً.
!>
!> A هي M × N. لتكن MNMIN = min( M, N ). S لها بعد MNMIN.
!> U يمكن أن تكون M × M أو M × MNMIN. VT يمكن أن تكون N × N أو MNMIN × N.
!>
!> عند استدعاء ZDRVBD، يتم تحديد عدد من أبعاد المصفوفة (M's و N's)
!> وعدد من أنواع المصفوفات. لكل حجم (M,N)
!> ولكل نوع من المصفوفات، وللتخزين المؤقت الأدنى وكذلك
!> التخزين المؤقت الكافي للسماح بالتقسيم، سيتم
!> إنشاء مصفوفة M × N واستخدامها لاختبار روتينات SVD. لكل مصفوفة،
!> سيتم تحليل A إلى A = U diag(S) VT وسيتم حساب الاختبارات الـ 12 التالية:
!>
!> اختبار لـ ZGESVD:
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!> (5)   | U - Upartial | / ( M ulp ) حيث Upartial هي
!>       U محسوبة جزئياً.
!>
!> (6)   | VT - VTpartial | / ( N ulp ) حيث VTpartial هي
!>       VT محسوبة جزئياً.
!>
!> (7)   | S - Spartial | / ( MNMIN ulp |S| ) حيث Spartial هي
!>       متجه القيم المفردة من SVD الجزئية.
!>
!> اختبار لـ ZGESDD:
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!> (12)  | U - Upartial | / ( M ulp ) حيث Upartial هي
!>       U محسوبة جزئياً.
!>
!> (13)  | VT - VTpartial | / ( N ulp ) حيث VTpartial هي
!>       VT محسوبة جزئياً.
!>
!> (14)  | S - Spartial | / ( MNMIN ulp |S| ) حيث Spartial هي
!>       متجه القيم المفردة من SVD الجزئية.
!>
!> اختبار لـ ZGESVDQ:
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!> اختبار لـ ZGESVJ:
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>

!>

!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>

!>       (إرجاع 0 إذا كانت صحيحة، 1/ULP إذا كانت خاطئة.)
!>
!> (27)  | U - Upartial | / ( M ulp ) حيث Upartial هي
!>       U محسوبة جزئياً.
!>
!> (28)  | VT - VTpartial | / ( N ulp ) حيث VTpartial هي
!>       VT محسوبة جزئياً.

!>       متجه القيم المفردة من SVD الجزئية.
!>
!> اختبار لـ ZGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!>

!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> يتم تحديد أبعاد المصفوفات (M's و N's) بواسطة المصفوفات MM(1:NSIZES) و
!> NN(1:NSIZES)؛ قيمة كل زوج من العناصر (MM(j),NN(j))
!> تحدد بعدًا واحدًا. يتم تحديد أنواع المصفوفات بواسطة مصفوفة منطقية
!> DOTYPE( 1:NTYPES )؛ إذا كانت DOTYPE(j) تساوي .TRUE.، فسيتم إنشاء مصفوفة
!> من النوع j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  المصفوفة الصفرية.
!> (2)  المصفوفة الوحدة.
!> (3)  مصفوفة على الشكل A = U D V، حيث U و V وحدويتان و
!>      D لها مدخلات متباعدة بالتساوي 1، ...، ULP مع علامات عشوائية
!>      على القطر.
!> (4)  نفس (3)، ولكن مضروبة في عتبة التدفق السفلي / ULP.
!> (5)  نفس (3)، ولكن مضروبة في عتبة التدفق العلوي * ULP.

NAME

zdrvbd - a subroutine for the singular value decomposition of a complex matrix, but with a twist.

SYNOPSIS

SUBROUTINE ZDRVBD( Q, MMAX, NMAX, NTYPES, NMAXS, NVALS, NN, MM, DTYPES,

Parameters:

CHARACTER*1
Q
INTEGER
MMAX, NMAX, NTYPES, NMAXS, NVALS, NN, MM, DTYPES, NTYPES, NRUNS, ISHORT, NOUNIT, INFO
DOUBLE PRECISION
TOL, THRESH, S, SSAV, E, RWORK

A, U, VT, ASAV, USAV, VTSAV, WORK

LDA, LDU, LDVT, LWORK, IWORK

Function/Subroutine Documentation

This subroutine is a driver routine for the Singular Value Decomposition (SVD) subroutine ZGESVD. It generates random matrices of user-specified dimensions and distribution types and calls ZGESVD to compute their singular values and optionally their singular vectors. The routine is intended to be used to test the ZGESVD subroutine.

The routine accepts a list of matrix dimensions (M,N) and a list of matrix types. For each type and dimension pair, it generates a set of matrices and calls ZGESVD. The results are checked against expected values and stored in the SAVING arrays.

The specific parameters are:

Q

CHARACTER*1
On entry, Q specifies whether to compute the singular vectors U and VT.
Q = 'Y': U and VT are computed.
Q = 'N': U and VT are not computed.

MMAX

INTEGER
The maximum number of rows over all matrices to be generated.

NMAX

INTEGER
The maximum number of columns over all matrices to be generated.

NTYPES

INTEGER
The number of types of matrices to be generated.

NMAXS

INTEGER
The maximum number of matrix pairs (M,N) to be generated.

NVALS

INTEGER
The maximum number of singular values to be computed for any matrix.

NN

INTEGER array, dimension (NMAXS)
Contains the numbers of columns for the matrices to be generated.

MM

INTEGER array, dimension (NMAXS)
Contains the numbers of rows for the matrices to be generated.

DTYPES

INTEGER array, dimension (NTYPES)
Specifies the types of matrices to be generated. The possible values are
from 1 to 14, corresponding to different types of matrices and
distributions (e.g., random, diagonal, triangular, etc.).

NTYPES

INTEGER
The number of types of matrices to be generated. If NTYPES is larger
than the maximum number of types defined (PARAMETER MAXTYP), then
types NTYPES+1 through MAXTYP will not be generated. If NTYPES is
larger than MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be
ignored.

ISEED

INTEGER array, dimension (4)
On entry ISEED specifies the seed of the random number generator. The
array elements should be between 0 and 4095; if not they will be
reduced mod 4096. Also, ISEED(4) must be odd. The random number
generator uses a linear congruential sequence limited to small integers,
and so should produce machine independent random numbers. The values of
ISEED are changed on exit, and can be used in the next call to ZDRVBD to
continue the same random number sequence.

THRESH

DOUBLE PRECISION
A test will count as if the , computed as described above, exceeds
THRESH. Note that the error is scaled to be O(1), so THRESH should be a
reasonably small multiple of 1, e.g., 10 or 100. In particular, it
should not depend on the precision (single vs. double) or the size of
the matrix. It must be at least zero.

A

COMPLEX*16 array, dimension (LDA,max(NN))
Used to hold the matrix whose singular values are to be computed. On
exit, A contains the last matrix actually used.

LDA

INTEGER
The leading dimension of A. It must be at least 1 and at least max( MM ).

U

COMPLEX*16 array, dimension (LDU,max(MM))
Used to hold the computed matrix of right singular vectors. On exit, U
contains the last such vectors actually computed.

LDU

INTEGER
The leading dimension of U. It must be at least 1 and at least max( MM ).

VT

COMPLEX*16 array, dimension (LDVT,max(NN))
Used to hold the computed matrix of left singular vectors. On exit, VT
contains the last such vectors actually computed.

LDVT

INTEGER
The leading dimension of VT. It must be at least 1 and at least max( NN ).

ASAV

COMPLEX*16 array, dimension (LDA,max(NN))
Used to hold a different copy of the matrix whose singular values are to
be computed. On exit, A contains the last matrix actually used.

USAV

COMPLEX*16 array, dimension (LDU,max(MM))
Used to hold a different copy of the computed matrix of right singular
vectors. On exit, USAV contains the last such vectors actually computed.

VTSAV

COMPLEX*16 array, dimension (LDVT,max(NN))
Used to hold a different copy of the computed matrix of left singular
vectors. On exit, VTSAV contains the last such vectors actually computed.

S

DOUBLE PRECISION array, dimension (max(min(MM,NN)))
Contains the computed singular values.

SSAV

DOUBLE PRECISION array, dimension (max(min(MM,NN)))
Contains another copy of the computed singular values.

E

DOUBLE PRECISION array, dimension (max(min(MM,NN)))
Workspace for ZGESVD.

WORK

COMPLEX*16 array, dimension (LWORK)

LWORK

INTEGER
The number of entries in WORK. This must be at least
MAX(3*MIN(M,N)+MAX(M,N)**2,5*MIN(M,N),3*MAX(M,N)) for all
pairs (M,N)=(MM(j),NN(j))

RWORK

DOUBLE PRECISION array,
dimension ( 5*max(max(MM,NN)) )

IWORK

INTEGER array, dimension at least 8*min(M,N)

NOUNIT

INTEGER
The FORTRAN unit number for printing out error messages (e.g., if a
routine returns IINFO not equal to 0.)

INFO

INTEGER
If 0, then everything ran OK.
 -1: NSIZES < 0
 -2: Some MM(j) < 0
 -3: Some NN(j) < 0
 -4: NTYPES < 0
 -7: THRESH < 0
-10: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
-12: LDU < 1 or LDU < MMAX.
-14: LDVT < 1 or LDVT < NMAX, where NMAX is max( NN(j) ).
-21: LWORK too small.
If ZLATMS, or ZGESVD returns an error code, the absolute value of it is
returned.
