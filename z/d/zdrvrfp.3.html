الغرض:

!>
!> ZDRVRFP تختبر إجراءات LAPACK RFP:
!>     ZPFTRF، ZPFTRS، و ZPFTRI.
!>
!> يتبع هذا الإجراء الاختباري نفس الاختبارات الخاصة بـ ZDRVPO (اختبار لحل
!> مصفوفة متماثلة معرفة موجبة بالتنسيق الكامل).
!>
!> يتم إجراء الاختبارات بالتنسيق الكامل، ويتم إجراء التحويل من وإلى
!> تنسيق RFP باستخدام الإجراءات ZTRTTF و ZTFTTR.
!>
!> أولاً، يتم إنشاء مصفوفة A محددة بالحجم N. هناك تسعة أنواع
!> مختلفة من المصفوفات الممكنة.
!>  1. قطرية                        6. عشوائية، CNDNUM = sqrt(0.1/EPS)
!>  2. عشوائية، CNDNUM = 2              7. عشوائية، CNDNUM = 0.1/EPS
!> *3. الصف والعمود الأول صفر       8. قياس قريب من الحد الأدنى للتدفق
!> *4. الصف والعمود الأخير صفر       9. قياس قريب من الحد الأقصى للتدفق
!> *5. الصف والعمود الأوسط صفر
!> (* - تختبر مخارج الخطأ من ZPFTRF، ولا يتم حساب نسب الاختبار)
!> يتم إنشاء حل XACT بالحجم N-by-NRHS والجانب الأيمن B المرتبط به. ثم يتم استدعاء ZPFTRF لحساب L (أو U)،
!> العامل Cholesky للمصفوفة A. ثم يتم استخدام L (أو U) لحل نظام
!> المعادلات الخطي AX = B. ينتج عن هذا X. ثم يتم استخدام L (أو U) لحساب
!> معكوس A، وهو AINV. ثم يتم إجراء الاختبارات الأربعة التالية:
!> (1) norm( L*L' - A ) / ( N * norm(A) * EPS ) أو
!>     norm( U'*U - A ) / ( N * norm(A) * EPS )،
!> (2) norm(B - A*X) / ( norm(A) * norm(X) * EPS )،
!> (3) norm( I - A*AINV ) / ( N * norm(A) * norm(AINV) * EPS )،
!> (4) ( norm(X-XACT) * RCOND ) / ( norm(XACT) * EPS )،
!> حيث EPS هي دقة الآلة، RCOND هو رقم شرط A، و
!> norm( . ) هو المعيار 1 لـ (1،2،3) والمعيار اللانهائي لـ (4).
!> تحدث أخطاء عندما لا يكون معامل INFO كما هو متوقع. تحدث حالات فشل
!> عندما تكون نسبة الاختبار أكبر من THRES.
!>
