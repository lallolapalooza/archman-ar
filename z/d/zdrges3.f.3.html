ZDRGES3

الغرض:

!>
!> ZDRGES3 تتحقق من برنامج تشغيل مشكلة القيم الذاتية المعممة غير المتماثلة (شكل شور)
!> ZGGES3.
!>
!> ZGGES3 تقوم بتحليل A و B إلى Q*S*Z' و Q*T*Z' ، حيث ' تعني منقول مقترن
!> (conjugate transpose)، S و T تكونان مثلثية عليا (أي، في شكل شور المعمم)
!> و Q و Z وحدويتان (unitary). كما تحسب القيم الذاتية المعممة
!> (alpha(j),beta(j))، j=1,...,n. بالتالي،
!> w(j) = alpha(j)/beta(j) هو جذر المعادلة المميزة
!>
!> det( A - w(j) B ) = 0
!>
!> اختيارياً، تقوم بإعادة ترتيب القيم الذاتية بحيث تظهر مجموعة مختارة
!> من القيم الذاتية في الكتلة القطرية الأمامية لأشكال شور.
!>
!> عند استدعاء ZDRGES3، يتم تحديد عدد من حجم المصفوفة () و
!> عدد من نوع المصفوفة. لكل حجم () ولكل نوع من المصفوفات، سيتم إنشاء
!> زوج من المصفوفات (A, B) واستخدامه للاختبار. لكل زوج مصفوفات، سيتم
!> إجراء الاختبارات الـ 13 التالية ومقارنتها بالعتبة THRESH باستثناء
!> الاختبارات (5)، (11) و (13).
!>
!>
!> (1) | A - Q S Z' | / ( |A| n ulp ) (لا يوجد فرز للقيم الذاتية)
!>
!>
!> (2) | B - Q T Z' | / ( |B| n ulp ) (لا يوجد فرز للقيم الذاتية)
!>
!>
!> (3) | I - QQ' | / ( n ulp ) (لا يوجد فرز للقيم الذاتية)
!>
!>
!> (4) | I - ZZ' | / ( n ulp ) (لا يوجد فرز للقيم الذاتية)
!> (5) إذا كانت A في شكل شور (أي، شكل مثلثي) (لا يوجد فرز للقيم الذاتية)
!>
!> (6) إذا كانت القيم الذاتية = العناصر القطرية لشكل شور (S, T)،
!> أي، اختبار الحد الأقصى على j لـ D(j) حيث:
!>
!> |alpha(j) - S(j,j)| |beta(j) - T(j,j)|
!> D(j) = ------------------------ + -----------------------
!> max(|alpha(j)|,|S(j,j)|) max(|beta(j)|,|T(j,j)|)
!>
!> (لا يوجد فرز للقيم الذاتية)
!>
!> (7) | (A,B) - Q (S,T) Z' | / ( |(A,B)| n ulp )
!> (مع فرز القيم الذاتية).
!>
!> (8) | I - QQ' | / ( n ulp ) (مع فرز القيم الذاتية).
!>
!> (9) | I - ZZ' | / ( n ulp ) (مع فرز القيم الذاتية).
!>
!> (10) إذا كانت A في شكل شور (أي، شكل شبه مثلثي)
!> (مع فرز القيم الذاتية).
!>
!> (11) إذا كانت القيم الذاتية = العناصر القطرية لشكل شور (S, T)،
!> أي، اختبار الحد الأقصى على j لـ D(j) حيث:
!>
!> |alpha(j) - S(j,j)| |beta(j) - T(j,j)|
!> D(j) = ------------------------ + -----------------------
!> max(|alpha(j)|,|S(j,j)|) max(|beta(j)|,|T(j,j)|)
!>
!> (مع فرز القيم الذاتية).
!>
!> (12) إذا نجح الفرز وكان SDIM هو عدد القيم الذاتية
!> التي تم اختيارها.
!>
!> مصفوفات الاختبار
!> =============
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ يحدد كل عنصر NN(j) حجمًا واحدًا.
!> يتم تحديد أنواع المصفوفات بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كان DOTYPE(j) هو .TRUE.، فسيتم إنشاء نوع المصفوفة j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1) ( 0, 0 ) (زوج من المصفوفات الصفرية)
!>
!> (2) ( I, 0 ) (مصفوفة هوية ومصفوفة صفرية)
!>
!> (3) ( 0, I ) (مصفوفة هوية ومصفوفة صفرية)
!>
!> (4) ( I, I ) (زوج من مصفوفات الهوية)
!>
!> t t
!> (5) ( J , J ) (زوج من كتل جوردان المنقولة)
!>
!> ( I 0 )
!> (6) ( X, Y ) حيث X = ( J 0 ) و Y = ( t )
!> ( 0 I ) ( 0 J )
!> و I هي مصفوفة هوية k x k و J كتلة جوردان (k+1)x(k+1)؛ k=(N-1)/2
!>
!> (7) ( D, I ) حيث D هي diag( 0, 1,..., N-1 ) (مصفوفة قطرية بهذه المدخلات القطرية).
!> (8) ( I, D )
!>
!> (9) ( big*D, small*I ) حيث big تقترب من الفيضان و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 ) حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!> D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!> t t
!> (16) Q ( J , J ) Z حيث Q و Z مصفوفتان متعامدتان عشوائيتان.
!>
!> (17) Q ( T1, T2 ) Z حيث T1 و T2 مصفوفتان مثلثيتان علويتان
!> بمدخلات O(1) عشوائية فوق القطر والمدخلات القطرية diag(T1) =
!> ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!> ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!> diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!> s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, 1, 1-d, ..., 1-(N-5)*d=s, 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!> N-5
!> (20) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, 1, a, ..., a =s, 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!> diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!> حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!> diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z حيث T1 و T2 مصفوفتان مثلثيتان علويتان عشوائيتان.
!>
!>
