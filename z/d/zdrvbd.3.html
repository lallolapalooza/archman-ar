!>
!> ZDRVBD تتحقق من إجراءات تحليل القيم المفردة (SVD) ZGESVD,
!> ZGESDD, ZGESVJ, ZGEJSV, ZGESVDX, و ZGESVDQ.
!>
!> ZGESVD و ZGESDD تقوم بتحليل A = U diag(S) VT، حيث U و VT
!> وحدوية و diag(S) قطرية مع مدخلات المصفوفة S على
!> قطرها. مدخلات S هي القيم المفردة، غير سالبة
!> ومخزنة بترتيب تنازلي. يمكن اختياريًا عدم حساب U و VT،
!> أو الكتابة فوق A، أو حسابها جزئيًا.
!>
!> A هي M × N. لتكن MNMIN = min( M, N ). S أبعادها MNMIN.
!> يمكن أن تكون U بمقاس M × M أو M × MNMIN. يمكن أن تكون VT بمقاس N × N أو MNMIN × N.
!>
!> عند استدعاء ZDRVBD، سيتم تحديد عدد من أبعاد المصفوفة (M و N)
!> وعدد من أنواع المصفوفات. لكل حجم (M,N)
!> ولكل نوع مصفوفة، وللحد الأدنى من مساحة العمل وكذلك
!> مساحة العمل الكافية للسماح بالتجزئة، سيتم إنشاء
!> مصفوفة M × N واستخدامها لاختبار إجراءات SVD. لكل مصفوفة، سيتم
!> تحليل A إلى A = U diag(S) VT وسيتم حساب الاختبارات الـ 12 التالية:
!>
!> اختبار لـ ZGESVD:
!>
!> (1)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (2)   | I - U'U | / ( M ulp )
!>
!> (3)   | I - VT VT' | / ( N ulp )
!>
!> (4)   تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كان صحيحًا، 1/ULP إذا كان خاطئًا.)
!>
!> (5)   | U - Upartial | / ( M ulp ) حيث Upartial هي
!>       U محسوبة جزئيًا.
!>
!> (6)   | VT - VTpartial | / ( N ulp ) حيث VTpartial هي
!>       VT محسوبة جزئيًا.
!>
!> (7)   | S - Spartial | / ( MNMIN ulp |S| ) حيث Spartial هي
!>       متجه القيم المفردة من SVD الجزئي
!>
!> اختبار لـ ZGESDD:
!>
!> (8)   | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (9)   | I - U'U | / ( M ulp )
!>
!> (10)  | I - VT VT' | / ( N ulp )
!>
!> (11)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كان صحيحًا، 1/ULP إذا كان خاطئًا.)
!>
!> (12)  | U - Upartial | / ( M ulp ) حيث Upartial هي
!>       U محسوبة جزئيًا.
!>
!> (13)  | VT - VTpartial | / ( N ulp ) حيث VTpartial هي
!>       VT محسوبة جزئيًا.
!>
!> (14)  | S - Spartial | / ( MNMIN ulp |S| ) حيث Spartial هي
!>       متجه القيم المفردة من SVD الجزئي
!>
!> اختبار لـ ZGESVDQ:
!>
!> (36)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (37)  | I - U'U | / ( M ulp )
!>
!> (38)  | I - VT VT' | / ( N ulp )
!>
!> (39)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كان صحيحًا، 1/ULP إذا كان خاطئًا.)
!>
!> اختبار لـ ZGESVJ:
!>
!> (15)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (16)  | I - U'U | / ( M ulp )
!>
!> (17)  | I - VT VT' | / ( N ulp )
!>
!> (18)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كان صحيحًا، 1/ULP إذا كان خاطئًا.)
!>
!> اختبار لـ ZGEJSV:
!>
!> (19)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (20)  | I - U'U | / ( M ulp )
!>
!> (21)  | I - VT VT' | / ( N ulp )
!>
!> (22)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>        (إرجاع 0 إذا كان صحيحًا، 1/ULP إذا كان خاطئًا.)
!>
!> اختبار لـ ZGESVDX( 'V', 'V', 'A' )/ZGESVDX( 'N', 'N', 'A' )
!>
!> (23)  | A - U diag(S) VT | / ( |A| max(M,N) ulp )
!>
!> (24)  | I - U'U | / ( M ulp )
!>
!> (25)  | I - VT VT' | / ( N ulp )
!>
!> (26)  تحتوي S على MNMIN قيمة غير سالبة بترتيب تنازلي.
!>       (إرجاع 0 إذا كان صحيحًا، 1/ULP إذا كان خاطئًا.)
!>
!> (27)  | U - Upartial | / ( M ulp ) حيث Upartial هي
!>       U محسوبة جزئيًا.
!>
!> (28)  | VT - VTpartial | / ( N ulp ) حيث VTpartial هي
!>       VT محسوبة جزئيًا.
!>
!> (29)  | S - Spartial | / ( MNMIN ulp |S| ) حيث Spartial هي
!>       متجه القيم المفردة من SVD الجزئي
!>
!> اختبار لـ ZGESVDX( 'V', 'V', 'I' )
!>
!> (30)  | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (31)  | I - U'U | / ( M ulp )
!>
!> (32)  | I - VT VT' | / ( N ulp )
!>
!> اختبار لـ ZGESVDX( 'V', 'V', 'V' )
!>
!> (33)   | U' A VT''' - diag(S) | / ( |A| max(M,N) ulp )
!>
!> (34)   | I - U'U | / ( M ulp )
!>
!> (35)   | I - VT VT' | / ( N ulp )
!>
!> سيتم تحديد المصفوفات (M و N) بواسطة المصفوفات MM(1:NSIZES) و
!> NN(1:NSIZES)؛ قيمة كل زوج عناصر (MM(j),NN(j))
!> تحدد حجمًا واحدًا. سيتم تحديد أنواع المصفوفات بواسطة مصفوفة منطقية
!> DOTYPE( 1:NTYPES )؛ إذا كانت DOTYPE(j) هي .TRUE.، فسيتم
!> إنشاء مصفوفة من النوع j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  المصفوفة الصفرية.
!> (2)  المصفوفة الوحدة.
!> (3)  مصفوفة من الشكل U D V، حيث U و V وحدوية و
!>      D تحتوي على مدخلات متباعدة بشكل متساوٍ 1, ..., ULP مع علامات عشوائية
!>      على القطر.
!> (4)  نفس (3)، ولكن مضروبة في عتبة الانخفاض / ULP.
!> (5)  نفس (3)، ولكن مضروبة في عتبة الارتفاع * ULP.
!>

NAME

zdrvbd

The subroutine zdrvbd computes the singular values and optionally the left and right singular vectors of a general rectangular complex matrix.

SYNOPSIS

SUBROUTINE ZDRVBD(
   NTYPES, NSIZES, NN, MM,
   THRESH, SEED, A, LDA, U, LDU,
   VT, LDVT, ASAV, USAV, VTSAV,
   S, SSAV, E, WORK, LWORK,
   RWORK, IWORK, NOUNIT, INFO
)
INTEGER NTYPES, NSIZES
INTEGER NN( * ), MM( * )
DOUBLE PRECISION THRESH
INTEGER SEED( 4 )
COMPLEX*16 A( LDA, * ), U( LDU, * ), VT( LDVT, * ),
             ASAV( LDA, * ), USAV( LDU, * ), VTSAV( LDVT, * )
DOUBLE PRECISION S( * ), SSAV( * ), E( * )
COMPLEX*16 WORK( * )

On exit, INFO is zero if the subroutine executed successfully, otherwise

NTYPES

NTYPES is INTEGER
The number of types of matrices to be generated. If NTYPES is less than
or equal to 0, then no matrices are generated. If NTYPES is greater than
the maximum number of types defined (PARAMETER MAXTYP), then types
NTYPES+1 through MAXTYP will not be generated. If NTYPES is larger than
MAXTYP, DOTYPE(MAXTYP+1) through DOTYPE(NTYPES) will be ignored.

ISEED

ISEED is INTEGER array, dimension (4)
On entry ISEED specifies the seed of the random number
generator. The array elements should be between 0 and 4095;
if not they will be reduced mod 4096. Also, ISEED(4) must
be odd. The random number generator uses a linear
congruential sequence limited to small integers, and so
should produce machine independent random numbers. The
values of ISEED are changed on exit, and can be used in the
next call to ZDRVBD to continue the same random number
sequence.

THRESH

THRESH is DOUBLE PRECISION
A test will count as if the , computed as
described above, exceeds THRESH. Note that the error
is scaled to be O(1), so THRESH should be a reasonably
small multiple of 1, e.g., 10 or 100. In particular,
it should not depend on the precision (single vs. double)
or the size of the matrix. It must be at least zero.

A is COMPLEX*16 array, dimension (LDA,max(NN))
Used to hold the matrix whose singular values are to be
computed. On exit, A contains the last matrix actually
used.

LDA

The leading dimension of A. It must be at
least 1 and at least max( MM ).

U

U is COMPLEX*16 array, dimension (LDU,max(MM))
Used to hold the computed matrix of right singular vectors.

LDU is INTEGER

VT is COMPLEX*16 array, dimension (LDVT,max(NN))

VTSAV

INFO

INFO is INTEGER
If 0, then everything ran OK.
-1: NSIZES < 0
-2: Some MM(j) < 0
-3: Some NN(j) < 0
-4: NTYPES < 0
-7: THRESH < 0
-10: LDA < 1 or LDA < MMAX, where MMAX is max( MM(j) ).
-12: LDU < 1 or LDU < MMAX.
-14: LDVT < 1 or LDVT < NMAX, where NMAX is max( NN(j) ).
-21: LWORK too small.
If ZLATMS, or ZGESVD returns an error code, the
