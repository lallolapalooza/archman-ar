ZDRGEV

الغرض:

!>
!> يتحقق ZDRGEV من روتين مشغل مسألة القيمة الذاتية المعممة غير المتماثلة
!> ZGGEV.
!>
!> يحسب ZGGEV لزوج من المصفوفات غير المتماثلة n-by-n (A,B) القيم
!> الذاتية المعممة، واختياريًا، المتجهات الذاتية اليسرى واليمنى.
!>
!> القيمة الذاتية المعممة لزوج من المصفوفات (A,B) هي عدد قياسي w
!> أو نسبة alpha/beta = w، بحيث تكون A - w*B مفردة.  وعادةً ما
!> تُrepresented كالزوج (alpha,beta)، حيث يوجد تفسير معقول
!> لـ beta=0، وحتى لكليهما معًا.
!>
!> المتجه الذاتي المعمم الأيمن المقابل لقيمة ذاتية معممة
!> w لزوج من المصفوفات (A,B) هو متجه r بحيث
!> (A - wB) * r = 0.  والمتجه الذاتي المعمم الأيسر هو متجه l بحيث
!> l**H * (A - wB) = 0، حيث l**H هو المرافق-المنقول لـ l.
!>
!> عند استدعاء ZDRGEV، يتم تحديد عدد من أحجام المصفوفات ()
!> وعدد من أنواع المصفوفات.  لكل حجم ()
!> ولكل نوع من المصفوفات، سيتم توليد زوج من المصفوفات (A, B)
!> واستخدامه للاختبار.  لكل زوج مصفوفات، سيتم إجراء الاختبارات
!> التالية ومقارنتها بالعتبة THRESH.
!>
!> النتائج من ZGGEV:
!>
!> (1)  الحد الأقصى على جميع أزواج القيمة الذاتية/المتجه اليسرى (alpha/beta,l) من
!>
!>      | VL**H * (beta A - alpha B) |/( ulp max(|beta A|, |alpha B|) )
!>
!>      حيث VL**H هو المرافق-المنقول لـ VL.
!>
!> (2)  | |VL(i)| - 1 | / ulp وما إذا كان أكبر مكوّن حقيقيًا
!>
!>      VL(i) يشير إلى العمود i من VL.
!>
!> (3)  الحد الأقصى على جميع أزواج القيمة الذاتية/المتجه اليسرى (alpha/beta,r) من
!>
!>      | (beta A - alpha B) * VR | / ( ulp max(|beta A|, |alpha B|) )
!>
!> (4)  | |VR(i)| - 1 | / ulp وما إذا كان أكبر مكوّن حقيقيًا
!>
!>      VR(i) يشير إلى العمود i من VR.
!>
!> (5)  W(full) = W(partial)
!>      W(full) يشير إلى القيم الذاتية المحسوبة عندما يتم حساب كل من l و r
!>      أيضًا، وW(partial) يشير إلى القيم الذاتية
!>      المحسوبة عندما يتم حساب W فقط، أو W و r فقط، أو W و l فقط.
!>
!> (6)  VL(full) = VL(partial)
!>      VL(full) يشير إلى المتجهات الذاتية اليسرى المحسوبة عندما يتم حساب كل من l
!>      و r، وVL(partial) يشير إلى النتيجة
!>      عندما يتم حساب l فقط.
!>
!> (7)  VR(full) = VR(partial)
!>      VR(full) يشير إلى المتجهات الذاتية اليمنى المحسوبة عندما يتم حساب كل من l
!>      و r أيضًا، وVR(partial) يشير إلى النتيجة
!>      عندما يتم حساب l فقط.
!>
!>
!> مصفوفات الاختبار
!> ---- --------
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES); قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد الأنواع بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES ); إذا
!> كانت DOTYPE(j) صحيحة (.TRUE.)، فسيتم توليد نوع المصفوفة j.
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة وحدة ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة وحدة ومصفوفة صفرية)
!>
!> (4)  ( I, I )         (زوج من مصفوفات الوحدة)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان المنقولة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I هي مصفوفة وحدة k x k و J كتلة جوردان
!>                       (k+1)x(k+1)؛ k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هي diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!>                       بتلك العناصر القطرية.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث big قريب من الفائض و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     حيث Q و Z مصفوفات متعامدة عشوائية.
!>
!> (17) Q ( T1, T2 ) Z    حيث T1 و T2 مصفوفات مثلثية عليا
!>                        بعناصر عشوائية O(1) فوق القطر
!>                        وعناصر قطرية diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     حيث T1 و T2 مصفوفات مثلثية عليا
!>                         عشوائية.
!>
!>

المعاملات

NSIZES 
!>          NSIZES هو INTEGER
!>          عدد أحجام المصفوفات المراد استخدامها.  إذا كانت صفرًا،
!>          فإن ZDRGES لا يفعل شيئًا.  NSIZES >= 0.
!>

NN

!>          NN هي مصفوفة INTEGER، البعد (NSIZES)
!>          مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
!>          القيم الصفرية

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

سيتم تخطي القيم. NN >= 0. !>

NTYPES

!>          NTYPES هو INTEGER
!>          عدد العناصر في DOTYPE.   إذا كان صفراً، فإن ZDRGEV
!>          لا يفعل شيئاً.  يجب أن يكون على الأقل صفراً.  إذا كان MAXTYP+1
!>          و NSIZES هو 1، فإن نوعاً إضافياً، MAXTYP+1، يتم
!>          تعريفه، وهو استخدام أي مصفوفة موجودة في A.  هذا
!>          مفيد فقط إذا كان DOTYPE(1:MAXTYP) هو .FALSE. و
!>          DOTYPE(MAXTYP+1) هو .TRUE. .
!>

DOTYPE

!>          DOTYPE هو مصفوفة LOGICAL، البعد (NTYPES)
!>          إذا كان DOTYPE(j) هو .TRUE.، فلكل حجم في NN يتم
!>          توليد مصفوفة بذلك الحجم ومن النوع j.
!>          إذا كان NTYPES أصغر من الحد الأقصى لعدد الأنواع
!>          المعرفة (PARAMETER MAXTYP)، فإن الأنواع NTYPES+1 حتى
!>          MAXTYP لن يتم توليدها. إذا كان NTYPES أكبر
!>          من MAXTYP، فإن DOTYPE(MAXTYP+1) حتى DOTYPE(NTYPES)
!>          سيتم تجاهلها.
!>

ISEED

!>          ISEED هو مصفوفة INTEGER، البعد (4)
!>          عند الإدخال يحدد ISEED بذرة مولّد الأرقام
!>          العشوائية. يجب أن تكون عناصر المصفوفة بين 0 و 4095؛
!>          إذا لم تكن كذلك فسيتم اختزالها بمعامل 4096. أيضاً، يجب أن يكون ISEED(4)
!>          فردياً.  يستخدم مولّد الأرقام العشوائية تسلسلاً
!>          خطياً متطابقاً محدوداً بأعداد صحيحة صغيرة، ولذلك
!>          يجب أن ينتج أرقاماً عشوائية مستقلة عن الآلة. يتم
!>          تغيير قيم ISEED عند الخروج، ويمكن استخدامها في
!>          الاستدعاء التالي لـ ZDRGES لمتابعة نفس تسلسل
!>          الأرقام العشوائية.
!>

THRESH

!>          THRESH هو DOUBLE PRECISION
!>          سيُحسب الاختبار على أنه  إذا تجاوز ، المحسوب كما
!>          هو موصوف أعلاه، THRESH.  لاحظ أن الخطأ
!>          مُقاس ليكون O(1)، لذا يجب أن يكون THRESH مضاعفاً
!>          صغيراً معقولاً للعدد 1، مثل 10 أو 100.  على وجه الخصوص، يجب
!>          ألا يعتمد على الدقة (مفردة مقابل مزدوجة) أو حجم
!>          المصفوفة.  يجب أن يكون على الأقل صفراً.
!>

NOUNIT

!>          NOUNIT هو INTEGER
!>          رقم وحدة FORTRAN لطباعة رسائل الخطأ
!>          (مثلاً، إذا أعادت روتين قيمة IERR لا تساوي 0.)
!>

A

!>          A هو مصفوفة COMPLEX*16، البعد(LDA, max(NN))
!>          يُستخدم للاحتفاظ بمصفوفة A الأصلية.  يُستخدم كمدخل فقط
!>          إذا كان NTYPES=MAXTYP+1، DOTYPE(1:MAXTYP)=.FALSE.، و
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي لـ A، B، S، و T.
!>          يجب أن يكون على الأقل 1 وعلى الأقل max( NN ).
!>

B

!>          B هو مصفوفة COMPLEX*16، البعد(LDA, max(NN))
!>          يُستخدم للاحتفاظ بمصفوفة B الأصلية.  يُستخدم كمدخل فقط
!>          إذا كان NTYPES=MAXTYP+1، DOTYPE(1:MAXTYP)=.FALSE.، و
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S هو مصفوفة COMPLEX*16، البعد (LDA, max(NN))
!>          مصفوفة شكل Schur المحسوبة من A بواسطة ZGGEV.  عند الخروج، تحتوي S
!>          على مصفوفة شكل Schur المقابلة للمصفوفة
!>          الموجودة في A.
!>

T

!>          T هو مصفوفة COMPLEX*16، البعد (LDA, max(NN))
!>          المصفوفة المثلثية العليا المحسوبة من B بواسطة ZGGEV.
!>

Q

!>          Q هو مصفوفة COMPLEX*16، البعد (LDQ, max(NN))
!>          مصفوفة المتجهات الذاتية (اليسرى) المحسوبة بواسطة ZGGEV.
!>

LDQ

!>          LDQ هو INTEGER
!>          البعد الرئيسي لـ Q و Z. يجب أن
!>          يكون على الأقل 1 وعلى الأقل max( NN ).
!>

Z

!>          Z هو مصفوفة COMPLEX*16، البعد( LDQ, max(NN) )
!>          المصفوفة المتعامدة (اليمنى) المحسوبة بواسطة ZGGEV.
!>

QE

!>          QE هو مصفوفة COMPLEX*16، البعد( LDQ, max(NN) )
!>          QE تحتفظ بالمتجهات الذاتية اليمنى أو اليسرى المحسوبة.
!>

LDQE

!>          LDQE هو INTEGER
!>          البعد الرئيسي لـ QE. LDQE >= max(1,max(NN)).
!>

ALPHA

!>          ALPHA هو مصفوفة COMPLEX*16، البعد (max(NN))
!>

BETA

!>          BETA هو مصفوفة COMPLEX*16، البعد (max(NN))
!>
!>          القيم الذاتية المعممة لـ (A,B) المحسوبة بواسطة ZGGEV.
!>          ( ALPHAR(k)+ALPHAI(k)*i ) / BETA(k) هي القيمة الذاتية
!>          المعممة رقم k لـ A و B.
!>

ALPHA1

!>          ALPHA1 هو مصفوفة COMPLEX*16، البعد (max(NN))
!>

BETA1

!>          BETA1 هو مصفوفة COMPLEX*16، البعد (max(NN))
!>
!>          مثل ALPHAR، ALPHAI، BETA، تحتوي هذه المصفوفات على
!>          القيم الذاتية لـ A و B، لكن تلك المحسوبة عندما يحسب ZGGEV فقط
!>          تحليلاً جزئياً للقيم الذاتية، أي ليس
!>          القيم الذاتية والمتجهات الذاتية اليسرى واليمنى.
!>

WORK

!>          WORK هو مصفوفة COMPLEX*16، البعد (LWORK)
!>

LWORK

!>          LWORK هو INTEGER
!>          عدد العناصر في WORK.  LWORK >= N*(N+1)
!>

RWORK

!>          RWORK هو مصفوفة DOUBLE PRECISION، البعد (8*N)
!>          مساحة عمل حقيقية.
!>

RESULT

!>          RESULT هو مصفوفة DOUBLE PRECISION، البعد (2)
!>          القيم المحسوبة بواسطة الاختبارات الموصوفة أعلاه.
!>          القيم محدودة حالياً بـ 1/ulp، لتجنب الفائض.
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i له قيمة غير قانونية.
!>          > 0:  أعادت روتين رمز خطأ.  INFO هو
!>                القيمة المطلقة لقيمة INFO المُعادة.
!>
