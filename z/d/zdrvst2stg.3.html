NAME

zdrvst2stg — Check the routines that estimate the condition number of a complex Hermitian eigenvalue problem.

SYNOPSIS

CALL ZDRVST2STG( NN, NSIZES, NTTOT, NTYPES, ISEED, THRESH, NOUNIT, A, LDA, D1, D2, D3, WA1, WA2, WA3, U, LDU, V, TAU, Z, WORK, LWORK, RWORK, LRWORK, IWORK, LIWORK, RESULT, INFO )

Function/Subroutine Documentation

ZDRVST2STG is a driver routine that tests routines that estimate the condition number of a complex Hermitian eigenvalue problem. The drivers call the following routines:

• Routines that reduce a Hermitian-definite matrix to tridiagonal form (ZHETRD, ZHPTRD, ZHBTRD)

• Routines that compute the eigenvalues and eigenvectors of a tridiagonal matrix (ZSTEQR)

• Routines that compute the eigenvalues of a tridiagonal matrix (DSTERF)

• Routines that compute the Schur factorization of a matrix (ZHETRD + ZUNGC3)

• Routines that compute the eigenvectors of a Hermitian matrix (ZHEEVD, ZHEEVX, ZHPEVD, CHPEVX, ZHBEVD, CHBEVX)

The tests are carried out by generating random matrices with properties similar to those of the matrices used in the above routines, and then calling the routines to compute the condition number estimates.

Input/Output Parameters:

NN INTEGER array, dimension (NSIZES)

The sizes of the matrices to be generated. This must be an array of non-negative integers.

Modified.

NSIZES INTEGER

The number of values in NN.

Not modified.

NTTOT INTEGER

The total number of matrices generated so far.

Modified.

NTYPES INTEGER

The number of matrix types to be generated. Currently, this can be from 1 to 10.

Not modified.

ISEED INTEGER array, dimension (4)

The random number generator seed. The first 4096 values of ISEED are used to generate random numbers. If any of the values are between 0 and 4095 inclusive, they will be reduced mod 4096. Also, ISEED(4) must be odd. The random number generator uses a linear congruential sequence limited to small integers, and so should produce machine independent random numbers. The values of ISEED are changed on exit, and can be used in the next call to ZDRVST2STG to continue the same random number sequence.

Modified.

THRESH DOUBLE PRECISION

A test will count as a failure if the computed error, as described above, exceeds THRESH. Note that the error is scaled to be O(1), so THRESH should be a reasonably small multiple of 1, e.g., 10 or 100. In particular, it should not depend on the precision (single vs. double) or the size of the matrix. It must be at least zero.

Not modified.

NOUNIT INTEGER

The FORTRAN unit number for printing out error messages (e.g., if a routine returns IINFO not equal to 0.)

Not modified.

A COMPLEX*16 array, dimension (LDA, max(NN))

Used to hold the matrix whose eigenvalues are to be computed. On exit, A contains the last matrix actually used.

Modified.

LDA INTEGER

The leading dimension of A. It must be at least 1 and at least max(NN).

Not modified.

D1 DOUBLE PRECISION array, dimension (max(NN))

The eigenvalues of A, as computed by ZSTEQR simultaneously with Z. On exit, the eigenvalues in D1 correspond with the matrix in A.

Modified.

D2 DOUBLE PRECISION array, dimension (max(NN))

The eigenvalues of A, as computed by ZSTEQR if Z is not computed. On exit, the eigenvalues in D2 correspond with the matrix in A.

Modified.

D3 DOUBLE PRECISION array, dimension (max(NN))

The eigenvalues of A, as computed by DSTERF. On exit, the eigenvalues in D3 correspond with the matrix in A.

Modified.

WA1 DOUBLE PRECISION array, dimension

WA2 DOUBLE PRECISION array, dimension

WA3 DOUBLE PRECISION array, dimension

U COMPLEX*16 array, dimension (LDU, max(NN))

The unitary matrix computed by ZHETRD + ZUNGC3.

Modified.

LDU INTEGER

The leading dimension of U, Z, and V. It must be at least 1 and at least max(NN).

Not modified.

V COMPLEX*16 array, dimension (LDU, max(NN))

The Housholder vectors computed by ZHETRD in reducing A to tridiagonal form.

Modified.

TAU COMPLEX*16 array, dimension (max(NN))

The Householder factors computed by ZHETRD in reducing A to tridiagonal form.

Modified.

The unitary matrix of eigenvectors computed by ZHEEVD, ZHEEVX, ZHPEVD, CHPEVX, ZHBEVD, and CHBEVX.

Modified.

RESULT DOUBLE PRECISION array, dimension (??)

The values computed by the tests described above. The values are currently limited to 1/ulp, to avoid overflow.

INFO INTEGER

If 0, then everything ran OK.
-1: NSIZES < 0
-2: Some NN(j) < 0
-3: NTYPES < 0
-5: THRESH < 0
-9: LDA < 1 or LDA < NMAX, where NMAX is max( NN(j) ).
-16: LDU < 1 or LDU < NMAX.
-21: LWORK too small.
If DLATMR, SLATMS, ZHETRD, DORGC3, ZSTEQR, DSTERF,
or DORMC2 returns an error code, the
absolute value of it is returned.

Modified.
