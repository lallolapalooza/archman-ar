ZDRGES

الغرض:

!>
!> يتحقق ZDRGES من مشكلة القيم الذاتية المعممة غير المتماثلة (شكل شور)
!> مشغل المشكلة ZGGES.
!>
!> يحلل ZGGES المصفوفتين A و B إلى Q*S*Z'  و Q*T*Z' ، حيث ' تعني المرافق
!> المنقول، S و T مثلثيتان عليا (أي في شكل شور
!> المعمم)، و Q و Z وحدويتان. كما يحسب القيم الذاتية
!> المعممة (alpha(j),beta(j))، j=1,...,n.  وبالتالي،
!> w(j) = alpha(j)/beta(j) هو جذر المعادلة المميزة
!>
!>                 det( A - w(j) B ) = 0
!>
!> اختياريًا يعيد أيضًا ترتيب القيم الذاتية بحيث تظهر عنقود
!> مختار من القيم الذاتية في الكتلة القطرية الرئيسية من
!> أشكال شور.
!>
!> عند استدعاء ZDRGES، يتم تحديد عدد من أحجام المصفوفات () و
!> عدد من أنواع المصفوفات .  لكل حجم ()
!> ولكل نوع من المصفوفات، سيتم توليد زوج من المصفوفات (A, B)
!> واستخدامه للاختبار. لكل زوج مصفوفات، سيتم إجراء الاختبارات الـ 13
!> التالية ومقارنتها مع العتبة THRESH باستثناء
!> الاختبارات (5) و(11) و(13).
!>
!>
!> (1)   | A - Q S Z' | / ( |A| n ulp ) (بدون ترتيب القيم الذاتية)
!>
!>
!> (2)   | B - Q T Z' | / ( |B| n ulp ) (بدون ترتيب القيم الذاتية)
!>
!>
!> (3)   | I - QQ' | / ( n ulp ) (بدون ترتيب القيم الذاتية)
!>
!>
!> (4)   | I - ZZ' | / ( n ulp ) (بدون ترتيب القيم الذاتية)
!>
!> (5)   إذا كانت A في شكل شور (أي الشكل المثلثي) (بدون ترتيب
!>       القيم الذاتية)
!>
!> (6)   إذا كانت القيم الذاتية = العناصر القطرية لشكل شور (S, T)،
!>       أي اختبار الحد الأقصى على j لـ D(j)  حيث:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (بدون ترتيب القيم الذاتية)
!>
!> (7)   | (A,B) - Q (S,T) Z' | / ( |(A,B)| n ulp )
!>       (مع ترتيب القيم الذاتية).
!>
!> (8)   | I - QQ' | / ( n ulp ) (مع ترتيب القيم الذاتية).
!>
!> (9)   | I - ZZ' | / ( n ulp ) (مع ترتيب القيم الذاتية).
!>
!> (10)  إذا كانت A في شكل شور (أي الشكل شبه المثلثي)
!>       (مع ترتيب القيم الذاتية).
!>
!> (11)  إذا كانت القيم الذاتية = العناصر القطرية لشكل شور (S, T)،
!>       أي اختبار الحد الأقصى على j لـ D(j)  حيث:
!>
!>                     |alpha(j) - S(j,j)|        |beta(j) - T(j,j)|
!>           D(j) = ------------------------ + -----------------------
!>                  max(|alpha(j)|,|S(j,j)|)   max(|beta(j)|,|T(j,j)|)
!>
!>       (مع ترتيب القيم الذاتية).
!>
!> (12)  إذا نجح الترتيب وكان SDIM هو عدد القيم الذاتية
!>       التي تم اختيارها بواسطة CELECT.
!>
!> مصفوفات الاختبار
!> =============
!>
!> يتم تحديد أحجام مصفوفات الاختبار بواسطة مصفوفة
!> NN(1:NSIZES)؛ قيمة كل عنصر NN(j) تحدد حجمًا واحدًا.
!> يتم تحديد الأنواع بواسطة مصفوفة منطقية DOTYPE( 1:NTYPES )؛ إذا
!> كانت DOTYPE(j) تساوي .TRUE.، فسيتم توليد نوع المصفوفة .
!> حاليًا، قائمة الأنواع الممكنة هي:
!>
!> (1)  ( 0, 0 )         (زوج من المصفوفات الصفرية)
!>
!> (2)  ( I, 0 )         (مصفوفة وحدة ومصفوفة صفرية)
!>
!> (3)  ( 0, I )         (مصفوفة وحدة ومصفوفة صفرية)
!>
!> (4)  ( I, I )         (زوج من مصفوفات الوحدة)
!>
!>         t   t
!> (5)  ( J , J  )       (زوج من كتل جوردان المنقولة)
!>
!>                                     t                ( I   0  )
!> (6)  ( X, Y )         حيث  X = ( J   0  )  و Y = (      t )
!>                                  ( 0   I  )          ( 0   J  )
!>                       و I هي مصفوفة وحدة k x k و J كتلة جوردان
!>                       (k+1)x(k+1)؛ k=(N-1)/2
!>
!> (7)  ( D, I )         حيث D هي diag( 0, 1,..., N-1 ) (مصفوفة قطرية
!>                       بتلك العناصر القطرية.)
!> (8)  ( I, D )
!>
!> (9)  ( big*D, small*I ) حيث  قريب من الفائض و small=1/big
!>
!> (10) ( small*D, big*I )
!>
!> (11) ( big*I, small*D )
!>
!> (12) ( small*I, big*D )
!>
!> (13) ( big*D, big*I )
!>
!> (14) ( small*D, small*I )
!>
!> (15) ( D1, D2 )        حيث D1 هي diag( 0, 0, 1, ..., N-3, 0 ) و
!>                        D2 هي diag( 0, N-3, N-4,..., 1, 0, 0 )
!>           t   t
!> (16) Q ( J , J ) Z     حيث Q و Z مصفوفات متعامدة عشوائية.
!>
!> (17) Q ( T1, T2 ) Z    حيث T1 و T2 مصفوفات مثلثية عليا
!>                        بعناصر عشوائية O(1) فوق القطر
!>                        وعناصر قطرية diag(T1) =
!>                        ( 0, 0, 1, ..., N-3, 0 ) و diag(T2) =
!>                        ( 0, N-3, N-4,..., 1, 0, 0 )
!>
!> (18) Q ( T1, T2 ) Z    diag(T1) = ( 0, 0, 1, 1, s, ..., s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1,..., 1, 0 )
!>                        s = دقة الآلة.
!>
!> (19) Q ( T1, T2 ) Z    diag(T1)=( 0,0,1,1, 1-d, ..., 1-(N-5)*d=s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0 )
!>
!>                                                        N-5
!> (20) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, 1, a, ..., a   =s, 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>
!> (21) Q ( T1, T2 ) Z    diag(T1)=( 0, 0, 1, r1, r2, ..., r(N-4), 0 )
!>                        diag(T2) = ( 0, 1, 0, 1, ..., 1, 0, 0 )
!>                        حيث r1,..., r(N-4) عشوائية.
!>
!> (22) Q ( big*T1, small*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (23) Q ( small*T1, big*T2 ) Z    diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (24) Q ( small*T1, small*T2 ) Z  diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (25) Q ( big*T1, big*T2 ) Z      diag(T1) = ( 0, 0, 1, ..., N-3, 0 )
!>                                  diag(T2) = ( 0, 1, ..., 1, 0, 0 )
!>
!> (26) Q ( T1, T2 ) Z     حيث T1 و T2 مصفوفات مثلثية عليا
!>                         عشوائية.
!>
!>

المعاملات

NSIZES 
!>          NSIZES هو INTEGER
!>          عدد أحجام المصفوفات المراد استخدامها.  إذا كانت صفرًا،
!>          فإن DDRGES لا يفعل شيئًا.  NSIZES >= 0.
!>

NN

!>          NN هي مصفوفة INTEGER، البعد (NSIZES)
!>          مصفوفة تحتوي على الأحجام المراد استخدامها للمصفوفات.
!>          سيتم تخطي القيم الصفرية.  NN >= 0.
!>

NTYP

!>          NTYPES هو INTEGER
!>          عدد العناصر في DOTYPE. إذا كانت صفراً، فإن DDRGES
!>          لا يفعل شيئاً. يجب أن تكون على الأقل صفراً. إذا كانت MAXTYP+1
!>          و NSIZES هي 1، فإن نوعاً إضافياً، MAXTYP+1، يتم
!>          تعريفه، وهو استخدام أي مصفوفة موجودة في A عند الإدخال.
!>          هذا مفيد فقط إذا كانت DOTYPE(1:MAXTYP) هي .FALSE. و
!>          DOTYPE(MAXTYP+1) هي .TRUE. .
!>

DOTYPE

!>          DOTYPE هي مصفوفة LOGICAL، البعد (NTYPES)
!>          إذا كانت DOTYPE(j) هي .TRUE.، فلكل حجم في NN سيتم
!>          توليد مصفوفة بذلك الحجم ومن النوع j.
!>          إذا كانت NTYPES أصغر من الحد الأقصى لعدد الأنواع
!>          المعرفة (PARAMETER MAXTYP)، فإن الأنواع NTYPES+1 حتى
!>          MAXTYP لن يتم توليدها. إذا كانت NTYPES أكبر
!>          من MAXTYP، فإن DOTYPE(MAXTYP+1) حتى DOTYPE(NTYPES)
!>          سيتم تجاهلها.
!>

ISEED

!>          ISEED هي مصفوفة INTEGER، البعد (4)
!>          عند الإدخال تحدد ISEED بذرة مولّد الأرقام
!>          العشوائية. يجب أن تكون عناصر المصفوفة بين 0 و 4095؛
!>          إذا لم تكن كذلك فسيتم اختزالها بمعامل 4096. أيضاً، يجب أن تكون ISEED(4)
!>          فردية. يستخدم مولّد الأرقام العشوائية تسلسلاً
!>          خطياً متطابقاً محدوداً بأعداد صحيحة صغيرة، ولذا
!>          يجب أن ينتج أرقاماً عشوائية مستقلة عن الآلة. يتم
!>          تغيير قيم ISEED عند الخروج، ويمكن استخدامها في
!>          الاستدعاء التالي لـ DDRGES لمتابعة نفس تسلسل
!>          الأرقام العشوائية.
!>

THRESH

!>          THRESH هو DOUBLE PRECISION
!>          سيُعتبر الاختبار ناجحاً إذا تجاوزت القيمة، المحسوبة كما
!>          هو موصوف أعلاه، THRESH. لاحظ أن الخطأ
!>          مُقيَّس ليكون O(1)، لذا يجب أن تكون THRESH مضاعفاً
!>          صغيراً معقولاً للعدد 1، مثلاً 10 أو 100. على وجه الخصوص، يجب
!>          ألا تعتمد على الدقة (المفردة مقابل المزدوجة) أو حجم
!>          المصفوفة. THRESH >= 0.
!>

NOUNIT

!>          NOUNIT هو INTEGER
!>          رقم وحدة FORTRAN لطباعة رسائل الخطأ
!>          (مثلاً، إذا أعادت روتين قيمة IINFO لا تساوي 0.)
!>

A

!>          A هي مصفوفة COMPLEX*16، البعد(LDA, max(NN))
!>          تُستخدم لحفظ مصفوفة A الأصلية. تُستخدم كإدخال فقط
!>          إذا كانت NTYPES=MAXTYP+1، و DOTYPE(1:MAXTYP)=.FALSE.، و
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرئيسي لـ A و B و S و T.
!>          يجب أن يكون على الأقل 1 وعلى الأقل max( NN ).
!>

B

!>          B هي مصفوفة COMPLEX*16، البعد(LDA, max(NN))
!>          تُستخدم لحفظ مصفوفة B الأصلية. تُستخدم كإدخال فقط
!>          إذا كانت NTYPES=MAXTYP+1، و DOTYPE(1:MAXTYP)=.FALSE.، و
!>          DOTYPE(MAXTYP+1)=.TRUE.
!>

S

!>          S هي مصفوفة COMPLEX*16، البعد (LDA, max(NN))
!>          مصفوفة شكل شور المحسوبة من A بواسطة ZGGES. عند الخروج، تحتوي S
!>          على مصفوفة شكل شور المقابلة للمصفوفة
!>          في A.
!>

T

!>          T هي مصفوفة COMPLEX*16، البعد (LDA, max(NN))
!>          المصفوفة المثلثية العليا المحسوبة من B بواسطة ZGGES.
!>

Q

!>          Q هي مصفوفة COMPLEX*16، البعد (LDQ, max(NN))
!>          المصفوفة المتعامدة (اليسرى) المحسوبة بواسطة ZGGES.
!>

LDQ

!>          LDQ هو INTEGER
!>          البعد الرئيسي لـ Q و Z. يجب أن
!>          يكون على الأقل 1 وعلى الأقل max( NN ).
!>

Z

!>          Z هي مصفوفة COMPLEX*16، البعد( LDQ, max(NN) )
!>          المصفوفة المتعامدة (اليمنى) المحسوبة بواسطة ZGGES.
!>

ALPHA

!>          ALPHA هي مصفوفة COMPLEX*16، البعد (max(NN))
!>

BETA

!>          BETA هي مصفوفة COMPLEX*16، البعد (max(NN))
!>
!>          القيم الذاتية المعممة لـ (A,B) المحسوبة بواسطة ZGGES.
!>          ALPHA(k) / BETA(k) هي القيمة الذاتية المعممة k-th لـ A
!>          و B.
!>

WORK

!>          WORK هي مصفوفة COMPLEX*16، البعد (LWORK)
!>

LWORK

!>          LWORK هو INTEGER
!>          بُعد المصفوفة WORK.  LWORK >= 3*N*N.
!>

RWORK

!>          RWORK هي مصفوفة DOUBLE PRECISION، البعد ( 8*N )
!>          مساحة عمل حقيقية.
!>

RESULT

!>          RESULT هي مصفوفة DOUBLE PRECISION، البعد (15)
!>          القيم المحسوبة بواسطة الاختبارات الموصوفة أعلاه.
!>          القيم محدودة حالياً بـ 1/ulp، لتجنب الفائض.
!>

BWORK

!>          BWORK هي مصفوفة LOGICAL، البعد (N)
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  خروج ناجح
!>          < 0:  إذا كانت INFO = -i، فإن الوسيط i-th له قيمة غير قانونية.
!>          > 0:  أعاد روتين رمز خطأ. INFO هي
!>                القيمة المطلقة لقيمة INFO المُعادة.
!>
