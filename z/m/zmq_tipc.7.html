zmq_tipc(7)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_TIPC(7) دليل 0MQ ZMQ_TIPC(7)

الاسم

zmq_tipc — نقل أحادي البث 0MQ باستخدام TIPC

الملخص

TIPC هو بروتوكول IPC للعناقيد مع مخطط عناوين شفاف للموقع.

العنونة

نقطة نهاية 0MQ هي سلسلة تتكون من transport:// متبوعة address. يحدد transport البروتوكول الأساسي للاستخدام. يحدد address العنوان الخاص بالبروتوكول للاتصال به.

بالنسبة لبروتوكول TIPC، فإن transport هو tipc، ومعنى جزء address محدد أدناه.

تعيين اسم منفذ إلى مقبس

عند تعيين اسم منفذ إلى مقبس باستخدام zmq_bind() مع بروتوكول tipc، يتم تعريف endpoint بالشكل: {type, lower, upper}

•النوع هو المعرف الرقمي (u32) لخدمتك.
•يحدد السفلي والعلوي نطاقًا لخدمتك.

سيؤدي نشر نفس الخدمة بنطاقات معرفات متداخلة (lower/upper) إلى توزيع طلبات الاتصال عبر هذه النطاقات بطريقة مستديرة.

توصيل مقبس

عند توصيل مقبس بعنوان نظير باستخدام zmq_connect() مع بروتوكول tipc، يتم تفسير endpoint على أنه معرف الخدمة، متبوعًا بفاصلة ومعرف المثيل.

يجب أن يكون معرف المثيل ضمن النطاق السفلي/العلوي لاسم منفذ منشور ليكون العنوان صالحًا.

أمثلة

تعيين عنوان محلي إلى مقبس.

//  نشر معرف خدمة TIPC 5555
rc = zmq_bind(socket, "tipc://{5555,0,0}");
assert (rc == 0);
//  نشر خدمة TIPC 5555 بنطاق خدمة 0-100
rc = zmq_bind(socket, "tipc://{5555,0,100}");
assert (rc == 0);

توصيل مقبس.

//  الاتصال بالخدمة 5555 معرف المثيل 50
rc = zmq_connect(socket, "tipc://{5555,50}");
assert (rc == 0);
