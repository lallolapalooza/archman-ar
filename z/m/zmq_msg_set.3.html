zmq_msg_set(3)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_MSG_SET(3) دليل 0MQ ZMQ_MSG_SET(3)

الاسم

zmq_msg_set - تعيين خاصية الرسالة

الملخص

int zmq_msg_set (zmq_msg_t *message, int property, int value);

الوصف

تقوم الدالة zmq_msg_set() بتعيين الخاصية المحددة بواسطة المعامل property إلى قيمة المعامل value لجزء رسالة 0MQ الذي تشير إليه المعامل message.

حاليًا، لا تدعم الدالة zmq_msg_set() أي أسماء خصائص.

قيمة الإرجاع

تعيد الدالة zmq_msg_set() صفرًا في حالة النجاح. بخلاف ذلك، تعيد -1 وتعين errno إلى إحدى القيم المحددة أدناه.

الأخطاء

EINVAL

الخاصية المطلوبة property غير معروفة.

انظر أيضًا
