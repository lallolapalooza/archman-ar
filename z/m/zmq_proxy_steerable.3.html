zmq_proxy_steerable(3)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_PROXY_STEERABLE(3) دليل 0MQ ZMQ_PROXY_STEERABLE(3)

الاسم

zmq_proxy_steerable - بروكسي 0MQ مدمج مع تدفق التحكم

الملخص

int zmq_proxy_steerable (const void *frontend, const void *backend, const void *capture, const void *control);

الوصف

الدالة zmq_proxy_steerable() هي نسخة من الدالة zmq_proxy(). تقبل مقبس control رابع. عندما يكون مقبس control هو NULL، فإن الدالتين تعملان بشكل متطابق.

عند توفير مقبس control من النوع REP لدالة البروكسي، يمكن للتطبيق إرسال أوامر إلى البروكسي. الأوامر التالية مدعومة.

PAUSE

سيتوقف البروكسي عن نقل الرسائل بين نقاط النهاية الخاصة به.

RESUME

سيستأنف البروكسي نقل الرسائل بين نقاط النهاية الخاصة به.

TERMINATE

ستخرج الدالة البروكسي بقيمة إرجاع 0.

STATISTICS

سيبقى سلوك البروكسي دون تغيير وسيرد بمجموعة من القيم الملخصة البسيطة للرسائل التي تم إرسالها عبر البروكسي كما هو موضح لاحقًا.

هناك ثمانية قيم إحصائيات، كل منها بحجم uint64_t في الرد متعدد الأجزاء على أمر STATISTICS. وهذه هي:

• عدد الرسائل التي تم استلامها بواسطة مقبس الواجهة الأمامية
• عدد البايتات التي تم استلامها بواسطة مقبس الواجهة الأمامية
• عدد الرسائل التي تم إرسالها بواسطة مقبس الواجهة الأمامية
• عدد البايتات التي تم إرسالها بواسطة مقبس الواجهة الأمامية
• عدد الرسائل التي تم استلامها بواسطة مقبس الواجهة الخلفية
• عدد البايتات التي تم استلامها بواسطة مقبس الواجهة الخلفية
• عدد الرسائل التي تم إرسالها بواسطة مقبس الواجهة الخلفية
• عدد البايتات التي تم إرسالها بواسطة مقبس الواجهة الخلفية

قيمة الإرجاع

تُرجع الدالة zmq_proxy_steerable() القيمة 0 إذا تم استلام TERMINATE على مقبس التحكم الخاص بها. بخلاف ذلك، فإنها تُرجع -1 ويتم تعيين errno إلى ETERM أو EINTR (تم إنهاء سياق 0MQ المرتبط بأي من المقابس المحددة) أو EFAULT (كان مقبس الواجهة الأمامية أو الخلفية المقدم غير صالح).

مثال

إنشاء دالة لتشغيل البروكسي.

// إنشاء مقابس الواجهة الأمامية والخلفية المراد تمريرها
void *frontend = zmq_socket (context, ZMQ_ROUTER);
void *backend = zmq_socket (context, ZMQ_DEALER);
// إنشاء مقبس التحكم الخاص بالبروكسي
void *control = zmq_socket (context, ZMQ_REP);
// ربط المقابس.
zmq_bind (frontend, "tcp://*:5555");
zmq_bind (backend, "tcp://*:5556");
zmq_bind (control, "tcp://*:5557");
zmq_proxy_steerable(frontend, backend, NULL, control);

كود في خيط/عملية أخرى لتوجيه البروكسي..

void *control = zmq_socket (context, ZMQ_REQ);
zmq_connect (control, "tcp://*:5557");
zmq_msg_t msg;
zmq_send (control, "PAUSE", 5, 0);
zmq_msg_recv (&msg, control, 0));
zmq_send (control, "RESUME", 6, 0);
zmq_msg_recv (&msg, control, 0));
zmq_send (control, "STATISTICS", 10, 0);
while (1) {
    zmq_msg_recv (&msg, control, 0));
    printf(" %lu", *(uint64_t *)zmq_msg_data (&msg));
    if (!zmq_msg_get (&msg, ZMQ_MORE))
        break;
}
printf("\n");
zmq_send (control, "TERMINATE", 9, 0);
zmq_msg_recv (&msg, control, 0));
zmq_close(frontend);
zmq_close(backend);
zmq_close(control);
