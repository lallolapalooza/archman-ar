الاسم

zmq_ctx_set - ضبط خيارات السياق

الملخص

int zmq_ctx_set (void *context, int option_name, int option_value);

الوصف

تقوم الدالة zmq_ctx_set() بضبط الخيار المحدد بواسطة الوسيط option_name إلى قيمة الوسيط option_value.

تقبل الدالة zmq_ctx_set() الخيارات التالية:

ZMQ_BLOCKY: إصلاح سلوك الحظر

افتراضيًا، سيتم حظر السياق إلى الأبد عند استدعاء zmq_ctx_term. الافتراض وراء هذا السلوك هو أن الإنهاء المفاجئ سيؤدي إلى فقدان الرسائل. تستخدم معظم التطبيقات الواقعية شكلاً من أشكال المصافحة لضمان تلقي التطبيقات لرسائل الإنهاء، ثم إنهاء السياق مع ضبط ZMQ_LINGER على صفر على جميع المقابس. هذا الإعداد هو طريقة أسهل للحصول على نفس النتيجة. عند ضبط ZMQ_BLOCKY على false، يتم منح جميع المقابس الجديدة مهلة تأخير صفر. لا يزال يتعين عليك إغلاق جميع المقابس قبل استدعاء zmq_ctx_term.

القيمة الافتراضية true (السلوك القديم)

ZMQ_IO_THREADS: تعيين عدد خيوط الإدخال/الإخراج

يحدد الوسيط ZMQ_IO_THREADS حجم مجمع خيوط 0MQ لمعالجة عمليات الإدخال/الإخراج. إذا كان تطبيقك يستخدم فقط النقل inproc للمراسلة، يمكنك ضبطه على صفر، وإلا اضبطه على واحد على الأقل. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق.

القيمة الافتراضية 1

ZMQ_THREAD_SCHED_POLICY: تعيين سياسة الجدولة لخيوط الإدخال/الإخراج

يقوم الوسيط ZMQ_THREAD_SCHED_POLICY بضبط سياسة الجدولة لمجمع الخيوط الداخلي للسياق. هذا الخيار غير متاح على ويندوز. يمكن العثور على القيم المدعومة لهذا الخيار في ملف sched.h، أو على http://man7.org/linux/man-pages/man2/sched_setscheduler.2.html. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق.

القيمة الافتراضية -1

ZMQ_THREAD_PRIORITY: تعيين أولوية الجدولة لخيوط الإدخال/الإخراج

يقوم الوسيط ZMQ_THREAD_PRIORITY بضبط أولوية الجدولة لمجمع الخيوط الداخلي للسياق. هذا الخيار غير متاح على ويندوز. تعتمد القيم المدعومة لهذا الخيار على سياسة الجدولة المختارة. على لينكس، عندما تكون سياسة المجدول SCHED_OTHER أو SCHED_IDLE أو SCHED_BATCH، فإن مجدول النظام لن يستخدم أولوية الخيط بل "قيمة تشغيل" الخيط؛ في مثل هذه الحالات، إذا تم ضبط ZMQ_THREAD_PRIORITY على قيمة موجبة تمامًا، فسيتم استخدام مكالمة النظام "nice" لضبط قيمة التشغيل على -20 (أقصى أولوية) بدلاً من ضبط أولوية الخيط (التي يجب أن تكون صفرًا لهذه السياسات المجدولة). يمكن العثور على التفاصيل في ملف sched.h، أو على http://man7.org/linux/man-pages/man2/sched_setscheduler.2.html. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق.

القيمة الافتراضية -1

ZMQ_THREAD_AFFINITY_CPU_ADD: إضافة وحدة معالجة مركزية إلى قائمة الارتباط لخيوط الإدخال/الإخراج

يضيف الوسيط ZMQ_THREAD_AFFINITY_CPU_ADD وحدة معالجة مركزية محددة إلى قائمة الارتباط لمجمع الخيوط الداخلي للسياق. هذا الخيار مدعوم فقط على لينكس. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق. قائمة الارتباط الافتراضية فارغة وتعني أنه لن يتم تعيين أي ارتباط لوحدات معالجة مركزية صريح لخيوط السياق الداخلية.

القيمة الافتراضية -1

ZMQ_THREAD_AFFINITY_CPU_REMOVE: إزالة وحدة معالجة مركزية من قائمة الارتباط لخيوط الإدخال/الإخراج

يقوم الوسيط ZMQ_THREAD_AFFINITY_CPU_REMOVE بإزالة وحدة معالجة مركزية محددة من قائمة الارتباط لمجمع الخيوط الداخلي للسياق. هذا الخيار مدعوم فقط على لينكس. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق. قائمة الارتباط الافتراضية فارغة وتعني أنه لن يتم تعيين أي ارتباط لوحدات معالجة مركزية صريح لخيوط السياق الداخلية.

القيمة الافتراضية -1

ZMQ_THREAD_NAME_PREFIX: تعيين بادئة الاسم لخيوط الإدخال/الإخراج

يقوم الوسيط ZMQ_THREAD_NAME_PREFIX بضبط بادئة رقمية لكل خيط يتم إنشاؤه لمجمع الخيوط الداخلي للسياق. هذا الخيار مدعوم فقط على لينكس. هذا الخيار مفيد للمساعدة في التصحيح الذي يتم عبر "top -H" أو "gdb"؛ في حالة استخدام عمليات متعددة على النظام لـ ZeroMQ، يكون من المفيد توفير بادئة خاصة بالتطبيق عبر خيار السياق هذا لتمييز خيوط خلفية ZeroMQ التي تنتمي إلى عمليات مختلفة. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق.

القيمة الافتراضية -1

ZMQ_MAX_MSGSZ: تعيين الحد الأقصى لحجم الرسالة

يحدد الوسيط ZMQ_MAX_MSGSZ الحد الأقصى المسموح به لحجم الرسالة المرسلة في السياق. يمكنك الاستعلام عن القيمة القصوى المسموح بها باستخدام zmq_ctx_get(3) باستخدام الخيار ZMQ_MAX_MSGSZ.

القيمة الافتراضية INT_MAX
القيمة القصوى INT_MAX

ZMQ_ZERO_COPY_RECV: تحديد استراتيجية فك ترميز الرسالة

يحدد الوسيط ZMQ_ZERO_COPY_RECV ما إذا كان يجب على أداة فك ترميز الرسالة استخدام استراتيجية النسخ الصفري عند استلام الرسائل. يمكن أن تؤدي استراتيجية النسخ الصفري إلى زيادة استخدام الذاكرة في بعض الحالات. يتيح لك هذا الخيار استخدام استراتيجية النسخ الأقدم. يمكنك الاستعلام عن قيمة هذا الخيار باستخدام zmq_ctx_get(3) باستخدام الخيار ZMQ_ZERO_COPY_RECV. ملاحظة: في حالة المسودة، لم يتم توفيره بعد في الإصدارات المستقرة.

ZMQ_MAX_SOCKETS: تعيين الحد الأقصى لعدد المقابس

يحدد الوسيط ZMQ_MAX_SOCKETS الحد الأقصى لعدد المقابس المسموح بها في السياق. يمكنك الاستعلام عن القيمة القصوى المسموح بها باستخدام zmq_ctx_get(3) باستخدام الخيار ZMQ_SOCKET_LIMIT.

ZMQ_IPV6: تعيين خيار IPv6

عند تعيين ZMQ_IPV6 إلى 1، سيقوم 0MQ بربط جميع المقابس التي تم إنشاؤها على هذا السياق افتراضيًا بكل من IPv4 و IPv6. عند تعيينها إلى 0، سيتم ربط المقابس افتراضيًا بـ IPv4 فقط.

NAME

zmq_ctx_set, zmq_ctx_get - manipulate context options

SYNOPSIS

int zmq_ctx_set (void *context, int option_name, int option_value);
int zmq_ctx_get (void *context, int option_name);

DESCRIPTION

The zmq_ctx_set() function shall set the option option_name to the value option_value for the specified context. The zmq_ctx_get() function shall retrieve the value of the option option_name for the specified context.

The following options are supported:

ZMQ_MAX_SOCKETS:

Set maximum number of sockets.

Default value 255

ZMQ_MAX_MSGSZ:

Set maximum message size.

Default value 104857600

ZMQ_MAX_CONNECTIONS:

Set maximum number of connections.

Default value -1 (unlimited)

ZMQ_IPV6:

The ZMQ_IPV6 argument sets the IPv6 value for all sockets created in the context from this point onwards. A value of 1 means IPv6 is enabled, while 0 means the socket will use only IPv4. When IPv6 is enabled, a socket will connect to, or accept connections from, both IPv4 and IPv6 hosts.

Default value 0

RETURN VALUE

The zmq_ctx_set() function returns zero if successful. Otherwise it returns -1 and sets errno to one of the values defined below.

The zmq_ctx_get() function returns the value of the requested option if successful. Otherwise it returns -1 and sets errno to one of the values defined below.

ERRORS

EINVAL

The requested option option_name is unknown.

ENOMEM

Insufficient memory to set the requested option.

EXAMPLE

Setting a limit on the number of sockets.

void *context = zmq_ctx_new ();
zmq_ctx_set (context, ZMQ_MAX_SOCKETS, 256);
int max_sockets = zmq_ctx_get (context, ZMQ_MAX_SOCKETS);
assert (max_sockets == 256);

zmq_ctx_set, zmq_ctx_get - معالجة خيارات السياق

الملخص

int zmq_ctx_set (void *context, int option_name, int option_value);
int zmq_ctx_get (void *context, int option_name);

الوصف

تقوم الدالة zmq_ctx_set() بتعيين الخيار option_name إلى القيمة option_value للسياق المحدد context. تقوم الدالة zmq_ctx_get() باسترداد قيمة الخيار option_name للسياق المحدد context.

الخيارات التالية مدعومة:

ZMQ_MAX_SOCKETS:

تعيين الحد الأقصى لعدد المقابس.

القيمة الافتراضية 255

ZMQ_MAX_MSGSZ:

تعيين الحد الأقصى لحجم الرسالة.

القيمة الافتراضية 104857600

ZMQ_MAX_CONNECTIONS:

تعيين الحد الأقصى لعدد الاتصالات.

القيمة الافتراضية -1 (غير محدود)

ZMQ_IPV6:

يقوم الوسيط ZMQ_IPV6 بتعيين قيمة IPv6 لجميع المقابس التي تم إنشاؤها في السياق من هذه النقطة فصاعدًا. القيمة 1 تعني تمكين IPv6، بينما تعني 0 أن المقبس سيستخدم IPv4 فقط. عندما يتم تمكين IPv6، سيتصل المقبس بالمضيفين الذين يستخدمون IPv4 و IPv6، أو سيقبل الاتصالات منهم.

القيمة الافتراضية 0

قيمة الإرجاع

تعيد الدالة zmq_ctx_set() صفرًا إذا نجحت. وإلا، فإنها تعيد -1 وتعيّن errno إلى أحد القيم المعرفة أدناه.

تعيد الدالة zmq_ctx_get() قيمة الخيار المطلوب إذا نجحت. وإلا، فإنها تعيد -1 وتعيّن errno إلى أحد القيم المعرفة أدناه.

EINVAL

ENOMEM

لا توجد ذاكرة كافية لتعيين الخيار المطلوب.
