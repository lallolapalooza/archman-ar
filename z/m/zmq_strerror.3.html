zmq_strerror(3)

الحزمة: zeromq

ZMQ_STRERROR(3) دليل 0MQ ZMQ_STRERROR(3)

الاسم

zmq_strerror - الحصول على سلسلة رسالة خطأ 0MQ

الملخص

const char *zmq_strerror (int errnum);

الوصف

تقوم الدالة zmq_strerror() بإرجاع مؤشر إلى سلسلة رسالة الخطأ المقابلة لرقم الخطأ المحدد بواسطة الوسيط errnum. نظرًا لأن 0MQ يحدد أرقام أخطاء إضافية فوق تلك التي يحددها نظام التشغيل، يجب على التطبيقات استخدام zmq_strerror() بدلاً من الدالة القياسية strerror().

قيمة الإرجاع

تقوم الدالة zmq_strerror() بإرجاع مؤشر إلى سلسلة رسالة الخطأ.

الأخطاء

لا توجد أخطاء محددة.

مثال

عرض رسالة خطأ عند فشل تهيئة سياق 0MQ.

void *ctx = zmq_init (1, 1, 0);
if (!ctx) {
    printf ("حدث خطأ أثناء zmq_init(): %s\n", zmq_strerror (errno));
    abort ();
}
