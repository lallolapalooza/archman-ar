zmq_connect(3)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_CONNECT(3) دليل 0MQ ZMQ_CONNECT(3)

الاسم

zmq_connect - إنشاء اتصال صادر من المقبس

المُلَخَّص

int zmq_connect (void *socket, const char *endpoint);

الوصف

تقوم الدالة zmq_connect() بربط socket بنقطة نهاية endpoint ثم تقبل الاتصالات الواردة على تلك النقطة.

تتكون endpoint من سلسلة نصية تبدأ بـ transport:// متبوعة بعنوان address. تحدد transport البروتوكول الأساسي المراد استخدامه. يحدد address العنوان الخاص بالنقل للاتصال به.

يوفر 0MQ وسائل النقل التالية:

tcp

وسيلة نقل أحادية باستخدام TCP، انظر zmq_tcp(7)

ipc

وسيلة نقل محلية للاتصال بين العمليات، انظر zmq_ipc(7)

inproc

وسيلة نقل محلية للاتصال داخل العملية (بين المواضيع)، انظر zmq_inproc(7)

pgm, epgm

وسيلة نقل موثوقة متعددة الإرسال باستخدام PGM، انظر zmq_pgm(7)

vmci

واجهة اتصالات الآلة الافتراضية (VMCI)، انظر zmq_vmci(7)

udp

أحادية وغير موثوقة ومتعددة الإرسال باستخدام UDP، انظر zmq_udp(7)

كل أنواع المقابس 0MQ باستثناء ZMQ_PAIR و ZMQ_CHANNEL تدعم دلالات واحد إلى متعدد ومتعدد إلى واحد. تعتمد الدلالات الدقيقة على نوع المقبس ويتم تعريفها في zmq_socket(3).


ملاحظة

بالنسبة لمعظم وسائل النقل وأنواع المقابس، لا يتم إجراء الاتصال على الفور ولكن حسب الحاجة بواسطة 0MQ. وبالتالي فإن الاستدعاء الناجح لـ zmq_connect() لا يعني أنه تم إنشاء الاتصال أو كان بالإمكان إنشاؤه. بسبب هذا، بالنسبة لمعظم وسائل النقل وأنواع المقابس، فإن ترتيب ربط مقبس server وربط مقبس client به لا يهم. مقابس ZMQ_PAIR و ZMQ_CHANNEL هي استثناء، لأنها لا تعيد الاتصال بنقاط النهاية تلقائيًا.


ملاحظة

بعد zmq_connect()، لأنواع المقابس باستثناء ZMQ_ROUTER، يدخل المقبس حالته جاهزة العادية. على النقيض من ذلك، بعد zmq_bind() وحده، يدخل المقبس حالة صامت حيث يحظر المقبس أو يتجاهل الرسائل وفقًا لنوع المقبس، كما هو محدد في zmq_socket(3). يدخل مقبس ZMQ_ROUTER حالته جاهزة العادية لند لـ peer محدد فقط عند اكتمال المصافحة لهذا الند لـ peer، والتي قد تستغرق وقتًا عشوائيًا.


ملاحظة

بالنسبة لبعض أنواع المقابس، لا يكون للاتصالات المتعددة بنفس نقطة النهاية معنى حقيقي (انظر https://github.com/zeromq/libzmq/issues/788). بالنسبة لتلك الأنواع من المقابس، يتم تجاهل أي محاولة للاتصال بنقطة نهاية متصلة بالفعل بصمت (أي، تعود بصفر). ينطبق هذا السلوك على أنواع المقابس ZMQ_DEALER و ZMQ_SUB و ZMQ_PUB و ZMQ_REQ.

قيمة الإرجاع

تعيد الدالة zmq_connect() صفرًا إذا نجحت. بخلاف ذلك، فإنها تعيد -1 وتعيّن errno إلى أحد القيم المعرفة أدناه.

الأخطاء

EINVAL

نقطة النهاية المقدمة غير صالحة.

EPROTONOSUPPORT

بروتوكول transport المطلوب غير مدعوم.

ENOCOMPATPROTO

بروتوكول transport المطلوب غير متوافق مع نوع المقبس.

ETERM

تم إنهاء سياق 0MQ context المرتبط بـ socket المحدد.

ENOTSOCK

socket المقدم كان غير صالح.

EMTHREAD

لا يتوفر خيط I/O لإنجاز المهمة.

مثال

ربط مقبس مشترك (subscriber) بنقل داخل العملية (in-process) ونقل TCP.

/* إنشاء مقبس ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* ربطه بنقل داخل العملية بالعنوان 'my_publisher' */
int rc = zmq_connect (socket, "inproc://my_publisher");
assert (rc == 0);
/* ربطه بالمضيف server001، المنفذ 5555 باستخدام نقل TCP */
rc = zmq_connect (socket, "tcp://server001:5555");
assert (rc == 0);
