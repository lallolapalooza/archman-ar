zmq_unbind(3)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_UNBIND(3) دليل 0MQ ZMQ_UNBIND(3)

الاسم

zmq_unbind - إيقاف قبول الاتصالات على مقبس

الملخص

int zmq_unbind (void *socket, const char *endpoint);

الوصف

تقوم الدالة zmq_unbind() بإلغاء ربط المقبس المحدد بوسيط socket من نقطة النهاية المحددة بوسيط endpoint.

بالإضافة إلى ذلك، سيتم تجاهل طابور الرسائل الواردة المرتبط بنقطة النهاية. هذا يعني أنه بعد إلغاء ربط نقطة نهاية، من الممكن استلام رسائل منشؤها من نفس نقطة النهاية إذا كانت موجودة بالفعل في طابور الرسائل الواردة قبل إلغاء الربط.

الوسيط endpoint كما هو موصوف في zmq_bind(3)

إلغاء ربط عنوان حرف بدل من مقبس

عند استخدام حرف البدل * endpoint (الموصوف في zmq_tcp(7)، zmq_ipc(7)، zmq_udp(7) و zmq_vmci(7)) في zmq_bind()، يجب على المستدعي استخدام endpoint الحقيقي الذي تم الحصول عليه من خيار المقبس ZMQ_LAST_ENDPOINT لإلغاء ربط endpoint هذا من المقبس.

قيمة الإرجاع

تُرجع الدالة zmq_unbind() صفرًا في حالة النجاح. بخلاف ذلك، تُرجع -1 وتُعين errno إلى إحدى القيم المحددة أدناه.

الأخطاء

EINVAL

نقطة النهاية المقدمة غير صالحة.

ETERM

تم إنهاء سياق 0MQ context المرتبط بالمقبس socket المحدد.

ENOTSOCK

المقبس socket المقدم غير صالح.

ENOENT

نقطة النهاية المقدمة لم تكن مربوطة من قبل.

أمثلة

إلغاء ربط مقبس مشترك من نقل TCP.

/* إنشاء مقبس ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* الاتصال بالخادم المتصل، المنفذ 5555 باستخدام نقل TCP */
rc = zmq_bind (socket, "tcp://127.0.0.1:5555");
assert (rc == 0);
/* قطع الاتصال من نقطة النهاية المتصلة مسبقًا */
rc = zmq_unbind (socket, "tcp://127.0.0.1:5555");
assert (rc == 0);

إلغاء ربط مقبس مربوط بعلامة حرف البدل *.

/* إنشاء مقبس ZMQ_SUB */
void *socket = zmq_socket (context, ZMQ_SUB);
assert (socket);
/* ربطه بالمنفذ الظاهري المعين من قبل النظام باستخدام نقل TCP */
rc = zmq_bind (socket, "tcp://127.0.0.1:*");
assert (rc == 0);
/* الحصول على نقطة النهاية الحقيقية */
const size_t buf_size = 32;
char buf[buf_size];
rc = zmq_getsockopt (socket, ZMQ_LAST_ENDPOINT, buf, (size_t *)&buf_size);
assert (rc == 0);
/* إلغاء ربط المقبس بنقطة النهاية الحقيقية */
rc = zmq_unbind (socket, buf);
assert (rc == 0);

ملاحظة

لاحظ أنه بينما التنفيذ مشابه لـ zmq_disconnect()، إلا أن الدلالات مختلفة ويجب عدم استخدام الدالتين بالتبادل. يجب إلغاء ربط المقابس المربوطة، وقطع اتصال المقابس المتصلة.
