zmq_ctx_set_ext(3)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_CTX_SET_EXT(3) دليل 0MQ ZMQ_CTX_SET_EXT(3)

الاسم

zmq_ctx_set_ext - تعيين خيارات السياق الموسعة

الملخص

int zmq_ctx_set_ext (void *context, int option_name, const void *option_value, size_t option_len);

الوصف

تقوم الدالة zmq_ctx_set_ext() بتعيين الخيار المحدد بواسطة الوسيط option_name إلى القيمة المشار إليها بواسطة الوسيط option_value للسياق 0MQ المشار إليه بواسطة الوسيط context. الوسيط option_len هو حجم قيمة الخيار بالبايت. بالنسبة للخيارات التي تأخذ قيمة من نوع "سلسلة نصية"، يجب أن تكون بيانات البايت المقدمة إما خالية من البايتات الصفرية، أو تنتهي ببايت صفري واحد (حرف NUL ASCII المنتهي).

تقبل الدالة zmq_ctx_set_ext() جميع أسماء الخيارات التي تقبلها الدالة zmq_ctx_set(). الخيارات الأكثر منطقية لتعيينها باستخدام zmq_ctx_set_ext() بدلاً من zmq_ctx_set() هي الخيارات التالية:

ZMQ_THREAD_NAME_PREFIX: تعيين بادئة اسم لخيوط الإدخال/الإخراج

يقوم الوسيط ZMQ_THREAD_NAME_PREFIX بتعيين بادئة سلسلة نصية لكل خيط يتم إنشاؤه لمجموعة خيوط السياق الداخلية. هذا الخيار مدعوم فقط على لينكس. هذا الخيار مفيد للمساعدة في تصحيح الأخطاء الذي يتم عبر "top -H" أو "gdb"؛ في حالة استخدام عمليات متعددة على النظام لـ ZeroMQ، من المفيد توفير بادئة خاصة بالتطبيق عبر خيار السياق هذا لتمييز خيوط ZeroMQ الخلفية التي تنتمي إلى عمليات مختلفة. ينطبق هذا الخيار فقط قبل إنشاء أي مقابس على السياق.

نوع قيمة الخيار سلسلة نصية
وحدة قيمة الخيار غير قابل للتطبيق
القيمة الافتراضية سلسلة فارغة

قيمة الإرجاع

تعيد الدالة zmq_ctx_set_ext() صفرًا في حالة النجاح. بخلاف ذلك، تعيد -1 وتعين errno إلى أحد القيم المحددة أدناه.

الأخطاء

EINVAL

الخيار المطلوب option_name غير معروف.

EFAULT

السياق context المقدم غير صالح.

مثال

تعيين بادئة على أسماء خيوط ZMQ الداخلية:.

void *context = zmq_ctx_new ();
const char prefix[] = "MyApp";
size_t prefixLen = sizeof(prefix);
zmq_ctx_set (context, ZMQ_THREAD_NAME_PREFIX, &prefix, &prefixLen);
char buff[256];
size_t buffLen = sizeof(buff);
int rc = zmq_ctx_get (context, ZMQ_THREAD_NAME_PREFIX, &buff, &buffLen);
assert (rc == 0);
assert (buffLen == prefixLen);
