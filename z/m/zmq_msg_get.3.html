zmq_msg_get(3)

الحزمة: zeromq

التراخيص: MPL2

ZMQ_MSG_GET(3) دليل 0MQ ZMQ_MSG_GET(3)

الاسم

zmq_msg_get - الحصول على خاصية الرسالة

الملخص

int zmq_msg_get (zmq_msg_t *message, int property);

الوصف

تقوم الدالة zmq_msg_get() بإرجاع القيمة للخاصية المحددة بواسطة الوسيط property للرسالة المشار إليها بواسطة الوسيط message.

يمكن استرداد الخصائص التالية باستخدام الدالة zmq_msg_get():

ZMQ_MORE

يشير إلى وجود المزيد من إطارات الرسائل التي ستتبع message.

ZMQ_SRCFD

تقوم بإرجاع واصف الملف للمقبس الذي تمت قراءة message منه. هذا يسمح للتطبيق باسترداد نقطة النهاية البعيدة عبر getpeername(2). كن على علم بأن المقبس المعني قد يكون مغلقًا بالفعل، أو قد تم إعادة استخدامه. حاليًا، يتم تنفيذه فقط لمقابس TCP.

ZMQ_SHARED

يشير إلى أن الرسالة قد تشارك التخزين الأساسي مع نسخة أخرى من هذه الرسالة.

قيمة الإرجاع

ستقوم الدالة zmq_msg_get() بإرجاع القيمة للخاصية في حالة النجاح. وإلا، ستعيد -1 وتضبط errno على أحد القيم المحددة أدناه.

الأخطاء

EINVAL

الخاصية property المطلوبة غير معروفة.

مثال

استقبال رسالة متعددة الإطارات.

zmq_msg_t frame;
while (true) {
    //  إنشاء رسالة 0MQ فارغة لاحتواء إطار الرسالة
    int rc = zmq_msg_init (&frame);
    assert (rc == 0);
    //  حظر حتى تتوفر رسالة للاستلام من المقبس
    rc = zmq_msg_recv (socket, &frame, 0);
    assert (rc != -1);
    if (zmq_msg_get (&frame, ZMQ_MORE))
        fprintf (stderr, "more\n");
    else {
        fprintf (stderr, "end\n");
        break;
    }
    zmq_msg_close (&frame);
}
