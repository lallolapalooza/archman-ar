ZQRT17

وثائق الدالة/الإجراء الفرعي

double precision function zqrt17 (character trans, integer iresid, integer m, integer n, integer nrhs, complex*16, dimension( lda, * ) a, integer lda, complex*16, dimension( ldx, * ) x, integer ldx, complex*16, dimension( ldb, * ) b, integer ldb, complex*16, dimension( ldb, * ) c, complex*16, dimension( lwork ) work, integer lwork)

ZQRT17

الغرض:

!>
!> ZQRT17 تحسب النسبة
!>
!>    norm(R**H * op(A)) / ( norm(A) * alpha * max(M,N,NRHS) * EPS ),
!>
!> حيث R = B - op(A)*X, op(A) هي A أو A**H، اعتمادًا على TRANS، EPS
!> هي ثابت العتبة الآلية، و
!>
!>    alpha = norm(B) إذا كان IRESID = 1 (مشكلة صفرية للمتبقي)
!>    alpha = norm(R) إذا كان IRESID = 2 (بخلاف ذلك).
!>
!> المعيار المستخدم هو المعيار 1.
!>

المعلمات

TRANS 
!>          TRANS هي CHARACTER*1
!>          تحدد ما إذا كان يتم استخدام منقول (transpose) A أم لا.
!>          = 'N':  بدون منقول، op(A) = A.
!>          = 'C':  منقول مصاحب (Conjugate transpose)، op(A) = A**H.
!>

IRESID

!>          IRESID هو INTEGER
!>          IRESID = 1 يشير إلى مشكلة صفرية للمتبقي.
!>          IRESID = 2 يشير إلى متبقي غير صفري.
!>

M

!>          M هو INTEGER
!>          عدد صفوف المصفوفة A.
!>          إذا كان TRANS = 'N'، فإن عدد صفوف المصفوفة B.
!>          إذا كان TRANS = 'C'، فإن عدد صفوف المصفوفة X.
!>

N

!>          N هو INTEGER
!>          عدد أعمدة المصفوفة A.
!>          إذا كان TRANS = 'N'، فإن عدد صفوف المصفوفة X.
!>          إذا كان TRANS = 'C'، فإن عدد صفوف المصفوفة B.
!>

NRHS

!>          NRHS هو INTEGER
!>          عدد أعمدة المصفوفات X و B.
!>

A

!>          A هي مصفوفة COMPLEX*16، البعد (LDA,N)
!>          المصفوفة A ذات الأبعاد m × n.
!>

LDA

!>          LDA هو INTEGER
!>          البعد الرائد للمصفوفة A. LDA >= M.
!>

X

!>          X هي مصفوفة COMPLEX*16، البعد (LDX,NRHS)
!>          إذا كان TRANS = 'N'، فإن المصفوفة X ذات الأبعاد n × nrhs.
!>          إذا كان TRANS = 'C'، فإن المصفوفة X ذات الأبعاد m × nrhs.
!>

LDX

!>          LDX هو INTEGER
!>          البعد الرائد للمصفوفة X.
!>          إذا كان TRANS = 'N'، LDX >= N.
!>          إذا كان TRANS = 'C'، LDX >= M.
!>

B

!>          B هي مصفوفة COMPLEX*16، البعد (LDB,NRHS)
!>          إذا كان TRANS = 'N'، فإن المصفوفة B ذات الأبعاد m × nrhs.
!>          إذا كان TRANS = 'C'، فإن المصفوفة B ذات الأبعاد n × nrhs.
!>

LDB

!>          LDB هو INTEGER
!>          البعد الرائد للمصفوفة B.
!>          إذا كان TRANS = 'N'، LDB >= M.
!>          إذا كان TRANS = 'C'، LDB >= N.
!>

C

!>          C هي مصفوفة COMPLEX*16، البعد (LDB,NRHS)
!>

WORK

!>          WORK هي مصفوفة COMPLEX*16، البعد (LWORK)
!>

LWORK

!>          LWORK هو INTEGER
!>          طول المصفوفة WORK. LWORK >= NRHS*(M+N).
!>
