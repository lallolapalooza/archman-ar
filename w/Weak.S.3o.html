type data

نوع العناصر المخزنة في الجدول.

type t

نوع الجداول التي تحتوي على عناصر من نوع data. لاحظ أنه لا يمكن تسلسل مجموعات الهاش الضعيفة باستخدام output_value أو وظائف وحدة Marshal.

val create : int -> t

create n ينشئ مجموعة هاش ضعيفة فارغة جديدة، بحجم مبدئي n. سيتسع الجدول حسب الحاجة.

val clear : t -> unit

إزالة جميع العناصر من الجدول.

val merge : t -> data -> data

merge t x يعيد نسخة من x موجودة في t إن وجدت، وإلا فإنه يضيف x إلى t ويعيد x.

val add : t -> data -> unit

add t x يضيف x إلى t. إذا كان هناك بالفعل نسخة من x في t، فسيتم تحديد أي منها سيتم إرجاعه بواسطة استدعاءات find و merge اللاحقة.

val remove : t -> data -> unit

remove t x يزيل نسخة واحدة من x من t. لا يفعل شيئًا إذا لم تكن هناك نسخة من x في t.

val find : t -> data -> data

find t x يعيد نسخة من x موجودة في t.

يثير Not_found إذا لم يكن هناك عنصر كهذا.

val find_opt : t -> data -> data option

find_opt t x يعيد نسخة من x موجودة في t أو None إذا لم يكن هناك عنصر كهذا.

منذ 4.05

val find_all : t -> data -> data list

find_all t x يعيد قائمة بجميع النسخ من x الموجودة في t.

val mem : t -> data -> bool

mem t x يعيد true إذا كان هناك على الأقل نسخة واحدة من x في t، و false بخلاف ذلك.

val iter : (data -> unit) -> t -> unit

iter f t يستدعي f على كل عنصر من عناصر t، بترتيب غير محدد. غير محدد ما يحدث إذا حاول f تغيير t نفسها.

val fold : (data -> 'acc -> 'acc) -> t -> 'acc -> 'acc

fold f t init يحسب (f d1 (... (f dN init))) حيث d1 ... dN هي عناصر t بترتيب غير محدد. غير محدد ما يحدث إذا حاول f تغيير t نفسها.

val count : t -> int

عد العناصر في الجدول. count t يعطي نفس نتيجة fold (fun _ n -> n+1) t 0 ولكنه لا يؤخر إلغاء تخصيص العناصر الميتة.

val stats : t -> int * int * int * int * int * int

إعادة إحصائيات حول الجدول. الأرقام هي، بالترتيب: طول الجدول، عدد الإدخالات، مجموع أطوال الدلاء، أقصر طول دلو، طول الدلو الوسيط، أطول طول دلو.
