NAME

weechat-headless - WeeChat (a free, lightweight, scriptable, multi-platform, multi-protocol chat client) on a server.

SYNOPSIS

weechat-headless [options]

DESCRIPTION

WeeChat is a chat client. The weechat-headless command runs WeeChat without any graphical interface, suitable for use on a server or in scripts. It provides the core functionality of WeeChat, allowing you to connect to chat networks, join channels, and interact with other users through a command-line interface or by scripting.

This executable is typically used when you want to run WeeChat as a background service or when you do not have a graphical environment available.

OPTIONS

The following options are available:

-a, --path=PATH
Set WeeChat data path (default: ~/.weechat).
-d, --dir=DIR
Set WeeChat config directory (default: DIR/weechat/).
-p, --plugins=PLUGINS
Load only specified plugins.
-P, --no-plugins
Do not load any plugins.
-r, --run=COMMAND
Run a command and exit.
-s, --script-dir=DIR
Add a directory for scripts.
-v, --version
Display version information and exit.
-h, --help
Display help message and exit.

DEBUG OPTIONS

These options are primarily for debugging purposes:

-F, --free=VAR
Free memory variable at exit.
-l, --log-level=LEVEL
Set log level (0-6).
-t, --log-tags=TAGS
Set log tags (comma-separated).

PLUGIN OPTIONS

Options related to plugin management:

-e, --enable-plugin=PLUGIN
Enable a plugin.
-f, --disable-plugin=PLUGIN
Disable a plugin.

FILES

~/.weechat/: Default WeeChat data directory.

~/.weechat/weechat.conf: Default WeeChat configuration file.
