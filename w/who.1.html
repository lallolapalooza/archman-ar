who(1)

الحزمة: coreutils

التراخيص: GPL-3.0-or-later, GFDL-1.3-or-later

WHO(1) أوامر المستخدم WHO(1)

الاسم

who - عرض من قام بتسجيل الدخول

المُلَخَّص

who [خيار]... [ ملف | وسيط1 وسيط2 ]

الوصف

طباعة معلومات عن المستخدمين الذين سجلوا الدخول حاليًا.

-a, --all
نفس الشيء مثل -b -d --login -p -r -t -T -u
-b, --boot
وقت آخر إقلاع للنظام
-d, --dead
طباعة العمليات الميتة
-H, --heading
طباعة سطر عناوين الأعمدة
-l, --login
طباعة عمليات تسجيل دخول النظام
--lookup
محاولة توحيد أسماء المضيفين عبر DNS
-m
اسم المضيف والمستخدم المرتبط بالمدخل القياسي فقط
-p, --process
طباعة العمليات النشطة التي تم إنشاؤها بواسطة init
-q, --count
جميع أسماء تسجيل الدخول وعدد المستخدمين المسجلين
-r, --runlevel
طباعة مستوى التشغيل الحالي
-s, --short
طباعة الاسم والسطر والوقت فقط (افتراضي)
-t, --time
طباعة آخر تغيير لساعة النظام
-T, -w, --mesg
إضافة حالة رسالة المستخدم كـ + أو - أو ؟
-u, --users
قائمة المستخدمين المسجلين
--message
نفس الشيء مثل -T
--writable
نفس الشيء مثل -T
--help
عرض هذه المساعدة والخروج
--version
إخراج معلومات الإصدار والخروج

إذا لم يتم تحديد FILE، استخدم /var/run/utmp. /var/log/wtmp كـ FILE شائع. إذا تم إعطاء ARG1 ARG2، يُفترض -m: 'am i' أو 'mom likes' هي المعتادة.
