وصف تفصيلي

يمثل كائن بروتوكول على جانب العميل.

يعمل wl_proxy كوكيل على جانب العميل لكائن موجود في المترجم. الوكيل مسؤول عن تحويل الطلبات التي يقدمها العملاء باستخدام wl_proxy_marshal() إلى تنسيق سلك Wayland. يتم التعامل مع الأحداث القادمة من المترجم أيضًا بواسطة الوكيل، والذي بدوره سيستدعي المعالج الذي تم تعيينه باستخدام wl_proxy_add_listener().

ملاحظة

باستثناء الدالة wl_proxy_set_queue()، لا تستخدم دوال الوصول إلى wl_proxy عادةً بواسطة شيفرة العميل. يجب على العملاء عادةً استخدام الواجهة ذات المستوى الأعلى التي تم إنشاؤها بواسطة الماسح للتفاعل مع كائنات المترجم.

تعيين مستمع وكيل (مع الموزع)

المعلمات

proxy كائن الوكيل
dispatcher الموزع المراد استخدامه لهذا الوكيل
implementation تنفيذ المستمع الخاص بالموزع
data بيانات المستخدم المراد ربطها بالوكيل

القيم المرجعة

0 عند النجاح أو -1 عند الفشل

عيّن مستمع الوكيل لاستخدام dispatcher_func كموزع له و dispatcher_data كتنفيذ خاص به وبياناته الخاصة للمستخدم. إذا تم بالفعل تعيين مستمع، تفشل هذه الدالة ولا يتغير شيء.

التفاصيل الدقيقة لـ dispatcher_data تعتمد على الموزع المستخدم. هذه الدالة مخصصة للاستخدام بواسطة روابط اللغة، وليس شيفرة المستخدم.

يجب ألا يكون الوكيل غلاف وكيل.

int wl_proxy_add_listener (struct wl_proxy * proxy, void(** implementation )(void), void * data)

تعيين مستمع وكيل

المعلمات

proxy كائن الوكيل
implementation المستمع المراد إضافته إلى الوكيل
data بيانات المستخدم المراد ربطها بالوكيل

القيم المرجعة

0 عند النجاح أو -1 عند الفشل

عيّن مستمع الوكيل إلى implementation وبيانات المستخدم الخاصة به إلى data. إذا تم بالفعل تعيين مستمع، تفشل هذه الدالة ولا يتغير شيء.

implementation هو متجه من مؤشرات الدوال. بالنسبة لرمز تشغيل n، يجب أن يشير implementation[n] إلى معالج n للكائن المحدد.

يجب ألا يكون الوكيل غلاف وكيل.

المعلمات

القيم المرجعة

كائن وكيل مخصص حديثًا أو NULL عند الفشل

تنشئ هذه الدالة كائن وكيل جديدًا بالواجهة المقدمة. سيتم تعيين معرف للوكيل من مساحة معرّفات العميل. يجب إنشاء المعرف على جانب المترجم عن طريق إرسال طلب مناسب باستخدام wl_proxy_marshal().

سيرث الوكيل شاشة وطابور الأحداث الخاصين بكائن المصنع.

ملاحظة

لا ينبغي استخدام هذا عادةً بواسطة شيفرة غير مولدة.
