وصف تفصيلي

قائمة مزدوجة الارتباط.

بحد ذاتها، يمثل مثيل struct wl_list رأس الحارس لقائمة مزدوجة الارتباط، ويجب تهيئته باستخدام wl_list_init(). عند كون القائمة فارغة، تشير عضوا next و prev للرأس إلى رأس القائمة نفسه، وإلا فإن next تشير إلى العنصر الأول في القائمة، وتشير prev إلى العنصر الأخير في القائمة.

استخدم نوع struct wl_list لتمثيل كل من رأس القائمة والروابط بين العناصر داخل القائمة. استخدم wl_list_empty() لتحديد ما إذا كانت القائمة فارغة في O(1).

يجب أن تكون جميع العناصر في القائمة من نفس النوع. يجب أن يحتوي نوع العنصر على عضو struct wl_list، وغالبًا ما يسمى link بالعرف. قبل الإدراج، لا حاجة لتهيئة link عنصر ما - استدعاء wl_list_init() على عضو struct wl_list لعنصر فردي غير ضروري إذا كانت العملية التالية مباشرة هي wl_list_insert(). ومع ذلك، فإن الاصطلاح الشائع هو تهيئة link عنصر ما قبل الإزالة - تأكد من السلامة عن طريق استدعاء wl_list_init() قبل wl_list_remove().

ضع في اعتبارك مرجع قائمة struct wl_list foo_list، ونوع عنصر كـ struct element، وعضو الرابط للعنصر كـ struct wl_list link.

يقوم الكود التالي بتهيئة قائمة وإضافة ثلاثة عناصر إليها.

struct wl_list foo_list;
struct element {
        int foo;
        struct wl_list link;
};
struct element e1, e2, e3;
wl_list_init(&foo_list);
wl_list_insert(&foo_list, &e1.link);   // e1 هو العنصر الأول
wl_list_insert(&foo_list, &e2.link);   // e2 هو الآن العنصر الأول
wl_list_insert(&e2.link, &e3.link); // إدراج e3 بعد e2

تبدو القائمة الآن كـ [e2, e3, e1].

يوفر واجهة برمجة تطبيقات wl_list بعض وحدات الماكرو للمكررات. على سبيل المثال، للتكرار عبر قائمة بترتيب تصاعدي:

struct element *e;
wl_list_for_each(e, foo_list, link) {
        do_something_with_element(e);
}

NAME

wl_list - linked list structure

SYNOPSIS

struct wl_list {
  struct wl_list *next;
  struct wl_list *prev;
};

Macros:

#define WL_LIST_INIT(name) { &(name), &(name) }
#define WL_LIST_FOREACH(ptr, head) \
  for (ptr = (head)->next; ptr != (head); ptr = ptr->next)
#define WL_LIST_FOR_EACH(message_list, link) ...
#define WL_LIST_FOR_EACH_REVERSE(pos, head, member) ...
#define WL_LIST_FOR_EACH_REVERSE_SAFE(pos, tmp, head, member) ...
#define WL_LIST_FOR_EACH_SAFE(pos, tmp, head, member) ...

Detailed Description

A wl_list is a doubly linked list. It is designed to be embedded inside other structures. The list is circular, meaning that the next pointer of the last element points to the head of the list, and the prev pointer of the first element points to the head of the list.

This means that the list head itself can be the element, and it's a list of size zero. The list head's next and prev pointers will always point to itself.

wl_list provides macros for list manipulation. The basic idea is that each struct containing a wl_list needs a member that is a struct wl_list. Let's say we have struct my_struct { struct wl_list link; int data; };. To add this to a list, we would initialize the list head, say struct wl_list my_list; wl_list_init(&my_list);. Then, we can add items like this: struct my_struct *item = malloc(sizeof *item); item->data = 42; wl_list_insert(&my_list, &item->link);.

To iterate over the list, we use wl_list_for_each: struct my_struct *item; wl_list_for_each(item, &my_list, link) { printf("Item data: %d\n", item->data); }

To remove an item: wl_list_remove(&item->link);.

It is important to note that the wl_list macros take the wl_list member name as an argument. This is a common pattern in C for struct embedding.

Friends And Related Symbol Documentation

#define wl_list_for_each( pos, head, member) [related]

Value:

        for (pos = wl_container_of((head)->next, pos, member);   \
             &pos->member != (head);                                     \
             pos = wl_container_of(pos->member.next, pos, member))

Iterates over a list. The loop terminates when all elements have been visited. This macro is not safe for list modification during iteration. Specifically, removing the current element pos during the loop will break the iteration.

Example:

struct my_message {
        struct wl_list link;
        // ... other fields
        const char *message_text;
};
struct wl_list message_list; // Assume this list is populated
struct my_message *m;
wl_list_for_each(m, &message_list, link) {
        do_something_with_message(m);
}
