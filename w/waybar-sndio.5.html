waybar-sndio(5)

الحزمة: waybar

التراخيص: MIT

waybar-sndio(5) دليل تنسيق الملفات waybar-sndio(5)

الاسم

waybar - وحدة sndio

الوصف

تعرض وحدة sndio مستوى الصوت الحالي الذي تم الإبلاغ عنه بواسطة sndio(7).

بالإضافة إلى ذلك، يمكنك التحكم في مستوى الصوت عن طريق التمرير للأعلى أو للأسفل أثناء وجود المؤشر فوق الوحدة، والنقر على الوحدة يقوم بكتم الصوت أو إلغاء كتمه.

الإعدادات

format:
typeof: string
default: {volume}%
تنسيق كيفية عرض المعلومات.

rotate:
typeof: integer
قيمة موجبة لتدوير التسمية النصية (بزيادات 90 درجة).

max-length:
typeof: integer
الحد الأقصى للطول بالحروف الذي يجب أن تعرضه الوحدة.

min-length:
typeof: integer
الحد الأدنى للطول بالحروف الذي يجب أن تقبله الوحدة.

align:
typeof: float
محاذاة التسمية داخل الوحدة، حيث 0 للمحاذاة إلى اليسار و 1 للمحاذاة إلى اليمين. إذا تم تدوير الوحدة، فستتبع تدفق النص.

justify:
typeof: string
محاذاة النص داخل تسمية الوحدة، مما يسمح بخيارات 'left'، 'right'، أو 'center' لتحديد الموضع.

scroll-step:
typeof: int
default: 5
سرعة تغيير مستوى الصوت عند التمرير.

on-click:
typeof: string
الأمر الذي سيتم تنفيذه عند النقر على الوحدة.

يحل هذا محل السلوك الافتراضي لكتم الصوت أو إلغاء كتمه.

on-click-middle:
typeof: string
الأمر الذي سيتم تنفيذه عند النقر بالزر الأوسط (عجلة الماوس) على الوحدة.

on-click-right:
typeof: string
الأمر الذي سيتم تنفيذه عند النقر بزر الماوس الأيمن على الوحدة.

on-update:
typeof: string
الأمر الذي سيتم تنفيذه عند تحديث الوحدة.

on-scroll-up:
typeof: string
الأمر الذي سيتم تنفيذه عند التمرير للأعلى على الوحدة.
يحل هذا محل السلوك الافتراضي للتحكم في مستوى الصوت.

on-scroll-down:
typeof: string
الأمر الذي سيتم تنفيذه عند التمرير للأسفل على الوحدة.
يحل هذا محل السلوك الافتراضي للتحكم في مستوى الصوت.

smooth-scrolling-threshold:
typeof: double
العتبة التي سيتم استخدامها عند التمرير.

menu:
typeof: string
الإجراء الذي يعرض القائمة.

menu-file:
typeof: string
موقع ملف واصف القائمة. يجب أن يكون هناك عنصر من نوع

GtkMenu بمعرف menu

menu-actions:
typeof: array
الإجراءات المقابلة لأزرار القائمة.

expand:
typeof: bool
default: false
يتيح لهذه الوحدة استهلاك كل المساحة المتبقية ديناميكيًا.

بدائل التنسيق

{volume}: مستوى الصوت بالنسبة المئوية.

{raw_value}: مستوى الصوت كقيمة تم الإبلاغ عنها بواسطة sndio.

أمثلة

"sndio": {
	"format": "{raw_value} 🔊",
	"scroll-step": 3
}
