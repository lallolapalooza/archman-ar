waybar-sway-scratchpad(5)

الحزمة: waybar

التراخيص: MIT

waybar-sway-scratchpad(5) دليل تنسيقات الملفات waybar-sway-scratchpad(5)

الاسم

waybar - وحدة Sway scratchpad

الوصف

تقوم وحدة scratchpad بعرض حالة الـ scratchpad في Sway.

الإعدادات

يتم التعامل معها بواسطة sway/scratchpad.

format:
النوع: string
الافتراضي: {icon} {count}
التنسيق، كيف يجب عرض المعلومات.

show-empty:
النوع: bool
الافتراضي: false
خيار لعرض الوحدة عندما يكون الـ scratchpad فارغًا.

format-icons:
النوع: array/object
بناءً على عدد نوافذ الـ scratchpad الحالية، يتم اختيار الأيقونة المقابلة.

tooltip:
النوع: bool
الافتراضي: true
خيار لتعطيل التلميح عند تمرير المؤشر.

tooltip-format:
النوع: string
الافتراضي: {app}: {title}
التنسيق، كيف يجب عرض المعلومات في التلميح.

menu:
النوع: string
الإجراء الذي يعرض القائمة.

menu-file:
النوع: string
موقع ملف واصف القائمة. يجب أن يكون هناك عنصر من النوع

GtkMenu بالمعرف menu

menu-actions:
النوع: array
الإجراءات المقابلة لأزرار القائمة.

expand:
النوع: bool
الافتراضي: false
يمكّن هذه الوحدة من استهلاك كل المساحة المتبقية ديناميكيًا.

بدائل التنسيق

{icon}: أيقونة، كما هو محدد في format-icons.

{count}: عدد النوافذ في الـ scratchpad.

{app}: اسم التطبيق في الـ scratchpad.

{title}: عنوان التطبيق في الـ scratchpad.

أمثلة

"sway/scratchpad": {
	"format": "{icon} {count}",
	"show-empty": false,
	"format-icons": ["", "󰪂"],
	"tooltip": true,
	"tooltip-format": "{app}: {title}"
}
