This manual page is part of the POSIX Programmer's Manual. The\n Linux implementation of this interface may differ (consult the corresponding\n Linux manual page for details of Linux behavior), or the interface may not\n be implemented on Linux.

NAME

\n

wctob — wide-character to single-byte conversion

\n
\n
\n

SYNOPSIS

\n
#include <stdio.h>\n#include <wchar.h>
\n
int wctob(wint_t c);
\n
\n
\n

DESCRIPTION

\n

The functionality described on this reference page is aligned with\n the ISO C standard. Any conflict between the requirements described\n here and the ISO C standard is unintentional. This volume of\n POSIX.1‐2017 defers to the ISO C standard.

\n

The wctob() function shall determine whether c\n corresponds to a member of the extended character set whose character\n representation is a single byte when in the initial shift state.

\n

The behavior of this function shall be affected by the\n LC_CTYPE category of the current locale.

\n
\n
\n

RETURN VALUE

\n

The wctob() function shall return EOF if c does not\n correspond to a character with length one in the initial shift state. Otherwise, it shall return the single-byte representation of that character\n as an unsigned char converted to int.

\n
\n

مقدمة

\n

صفحة الدليل هذه هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق لينكس لهذه الواجهة (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة على لينكس.

\n
\n
\n

الاسم

\n

wctob — تحويل حرف عريض إلى بايت واحد

\n
\n
\n

الملخص

\n
#include <stdio.h>\n#include <wchar.h>
\n
int wctob(wint_t c);
\n
\n
\n

الوصف

\n

تتوافق الوظيفة الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C هو غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

\n

تقوم الدالة wctob() بتحديد ما إذا كان c يتوافق مع عضو في مجموعة الأحرف الموسعة التي تمثلها أحرفها ذات بايت واحد عند وجودها في حالة الإزاحة الأولية.

\n

سيتأثر سلوك هذه الدالة بفئة LC_CTYPE للموقع الحالي.

\n
\n
\n

قيمة الإرجاع

\n

سترجع الدالة wctob() القيمة EOF إذا كان c لا يتوافق مع حرف بطول بايت واحد في حالة الإزاحة الأولية. بخلاف ذلك، سترجع التمثيل أحادي البايت لهذا الحرف كـ unsigned char محوّل إلى int.
