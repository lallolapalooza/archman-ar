wl_object - كائن البروتوكول.

#include <wayland-server.h>

حقول البيانات


const struct wl_interface * interface

الوصف التفصيلي

كائن بروتوكول.

wl_object هو بنية غامضة تحدد كائن البروتوكول الأساسي لـ wl_proxy أو wl_resource.

ملاحظة

لا يتم استخدام الوظائف التي تصل إلى wl_object بشكل طبيعي بواسطة كود العميل. يجب على العملاء عادةً استخدام الواجهة ذات المستوى الأعلى التي تم إنشاؤها بواسطة الماسح للتفاعل مع كائنات المترجم.
