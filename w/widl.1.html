widl(1)

الحزمة: wine

التراخيص: LGPL-2.1-or-later

WIDL(1) دليل مطوري Wine WIDL(1)

الاسم

widl - مترجم لغة تعريف واجهة Wine (IDL)

نبذة

widl [خيارات] ملف_IDL
widl [خيارات] --dlldata-only اسم1 [اسم2...]

الوصف

عند عدم استخدام أي خيارات، سيقوم البرنامج بإنشاء ملف رأس، وربما ملفات العميل والخادم، وملفات الوكيل و dlldata، وملف typelib، وملف UUID، اعتمادًا على محتويات ملف IDL. إذا تم تقديم أي من الخيارات -c، -h، -p، -s، -t، -u أو --local-stubs، فسيقوم widl بإنشاء الملفات المطلوبة فقط، ولن يقوم بإنشاء أي ملفات أخرى. عند التشغيل مع --dlldata-only، سيقوم widl بإنشاء ملف dlldata فقط، وسيتضمن قائمة بالأسماء الممررة كمعاملات. عادةً ما يتم تحديث هذا الملف عن طريق قراءة widl لأي ملف dlldata موجود في كل مرة يتم تشغيله فيها، وإذا لزم الأمر، يقوم بإعادة إنشائه بنفس قائمة الأسماء، ولكن مع تضمين ملف الوكيل الحالي.

عند التشغيل بدون أي معاملات، سيقوم widl بطباعة رسالة مساعدة.

خيارات

خيارات عامة:

-V
طباعة رقم الإصدار والخروج.
-o, --output=اسم
تحديد اسم ملف الإخراج. عند إنشاء ملفات إخراج متعددة، يحدد هذا فقط الاسم الأساسي للملف؛ ثم يتم تسمية ملفات الإخراج المقابلة اسم.h، اسم_p.c، إلخ. إذا تم تحديد اسم ملف كامل مع امتداد، يتم إنشاء هذا الملف فقط.
-b, --target=وحدة_المعالجة_المركزية-الشركة_المصنعة[-النواة]-نظام_التشغيل
تحديد بنية الهدف عند التجميع المتقاطع. مواصفات الهدف بتنسيق autoconf القياسي كما يتم إرجاعه بواسطة config.sub.
-m32, -m64, --win32, --win64
فرض بنية الهدف لتكون 32 بت أو 64 بت.
--sysroot=دليل
إضافة بادئة لمسارات التضمين القياسية بـ دليل.
--nostdinc
لا تبحث في مسارات التضمين القياسية مثل /usr/include و /usr/local/include.

خيارات الملف الرأسي:

-h
إنشاء ملفات الرأس. اسم ملف الإخراج الافتراضي هو infil.h.
--oldnames
استخدام اصطلاحات التسمية القديمة.

خيارات مكتبة الأنواع:

-t
إنشاء مكتبة أنواع. اسم ملف الإخراج الافتراضي هو infil.tlb. إذا انتهى اسم ملف الإخراج بـ .res، فسيتم إنشاء ملف موارد ثنائي يحتوي على مكتبة الأنواع بدلاً من ذلك.
-L مسار
إضافة دليل إلى مسار البحث عن المكتبات لـ typelibs المستوردة. يمكن تحديد الخيار عدة مرات.
--oldtlb
إنشاء مكتبة أنواع بتنسيق قديم (تنسيق SLTG).

خيارات ملف UUID:

-u
إنشاء ملف UUID. اسم ملف الإخراج الافتراضي هو infil_i.c.

خيارات إنشاء الوكيل/الامتداد:

--align=n, --packing=n
تعيين حزم الهياكل إلى n. القيم المدعومة هي 2، 4، و 8.
-c
إنشاء ملف امتداد عميل. اسم ملف الإخراج الافتراضي هو infil_c.c.
-Os
إنشاء امتدادات مضمنة.
-Oi
إنشاء امتدادات مترجمة بأسلوب قديم.
-Oif, -Oic, -Oicf
إنشاء امتدادات مترجمة بالكامل بأسلوب جديد. هذا هو الافتراضي.
-p
إنشاء وكيل. اسم ملف الإخراج الافتراضي هو infil_p.c.
--prefix-all=بادئة
البادئة التي سيتم وضعها على اسم امتدادات العميل والخادم.
--prefix-client=بادئة
البادئة التي سيتم وضعها على اسم امتدادات العميل.
--prefix-server=بادئة
البادئة التي سيتم وضعها على اسم امتدادات الخادم.
-s
إنشاء ملف امتداد خادم. اسم ملف الإخراج الافتراضي هو infil_s.c.
--winrt
تمكين وضع Windows Runtime.
--ns_prefix
وضع بادئة لمساحات الأسماء.

خيارات البرنامج النصي للتسجيل:

-r
إنشاء برنامج نصي للتسجيل. اسم ملف الإخراج الافتراضي هو infil_r.rgs. إذا انتهى اسم ملف الإخراج بـ .res، فسيتم إنشاء ملف موارد ثنائي يحتوي على البرنامج النصي بدلاً من ذلك.

خيارات ملف Dlldata:

--dlldata-only اسم1 [اسم2...]
إعادة إنشاء ملف dlldata من الصفر باستخدام أسماء الوكلاء المحددة. اسم ملف الإخراج الافتراضي هو dlldata.c.

خيارات ملف البيانات الوصفية:

--winmd
إنشاء ملف بيانات وصفية لـ Windows Runtime. هذا يعني وضع --winrt. اسم ملف الإخراج الافتراضي هو infil.winmd.

خيارات المعالج المسبق:

-I مسار
إضافة دليل إلى مسار البحث عن التضمين. يُسمح بمسارات تضمين متعددة.
-D معرّف[=قيمة]
تعريف ماكرو المعالج المسبق معرّف بالقيمة قيمة.
-E
المعالجة المسبقة فقط.
-N
لا تقم بمعالجة الإدخال مسبقًا.

خيارات التصحيح:

-W
تمكين التحذيرات الهادفة.
-d n
تعيين مستوى التصحيح إلى العدد الصحيح غير السالب n. إذا كان مسبوقًا بـ 0x، فسيتم تفسيره كرقم سداسي عشري. لمعنى القيم، انظر قسم DEBUG.

خيارات متنوعة:

-app_config
تم التجاهل، موجود للتوافق مع midl.
--acf=ملف
استخدام ملف تكوين التطبيق المحدد.
--local-stubs=ملف
إنشاء امتدادات فارغة للطرق call_as/local في واجهة كائن وكتابتها إلى ملف.

التصحيح

مستوى التصحيح n هو قناع بت بالمعنى التالي:
- 0x01 إخبار أي مورد يتم تحليله (وضع مفصل)
- 0x02 تفريغ الهياكل الداخلية
- 0x04 إنشاء تتبع محلل (yydebug=1)
- 0x08 رسائل المعالج المسبق
- 0x10 رسائل محلل المعالج المسبق
- 0x20 تتبع محلل المعالج المسبق

الأخطاء

يمكن الإبلاغ عن الأخطاء في متعقب أخطاء Wine.

NAME

widl — The Wine Interface Definition Language compiler

SYNOPSIS

widl [options] idl_file

DESCRIPTION

widl is the Wine Interface Definition Language compiler. It is used to compile interface definition files (usually with an extension of .idl) into C-header and C-source files. These files can then be used to implement COM interfaces in Wine.

The IDL compiler is intended to be used primarily to compile the IDL files shipped with the Wine source tree. It is not guaranteed to be fully compliant with the Microsoft IDL compiler.

OPTIONS

See the Wine documentation for a full list of options.

DEBUG

See the Wine documentation for information on debugging widl.

BUGS

See the Wine documentation for known bugs.

AUTHORS

Dan Hipschman.

AVAILABILITY

widl is part of the Wine distribution, which is available through WineHQ, the Wine development headquarters.
