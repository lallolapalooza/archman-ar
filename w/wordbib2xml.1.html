الوصف

مجموعة برامج bibutils تقوم بالتحويل المتبادل بين صيغ مراجع مختلفة باستخدام مخطط وصف كائنات البيانات الوصفية (MODS)[2] من الإصدار 3.1 التابع لمكتبة الكونغرس[1]. على سبيل المثال، يمكن تحويل ملفات بصيغة RIS إلى Bibtex عن طريق إجراء تحويلين: RIS->MODS->Bibtex.

-h --help عرض المساعدة
-v --version عرض الإصدار
-a --add-refcount إضافة "_#"، حيث # هو عدد المراجع، إلى معرف المرجع
-s --single-refperfile وضع مرجع واحد لكل ملف باسم الملف حسب رقم المرجع
-i --input-encoding تفسير ملف الإدخال على أنه يستخدم مجموعة الأحرف المطلوبة (استخدم بدون وسيطة للحصول على القائمة الحالية المشتقة من مجموعات الأحرف في www.kostis.net[4]) unicode هو خيار لمجموعة الأحرف
-u --unicode-characters ترميز أحرف unicode مباشرة في الملف بدلاً من كيانات XML
-un --unicode-no-bom مثل -u، ولكن لا يتضمن علامة ترتيب البايت
-x --xml-entities ترميز أحرف unicode ككيانات XML (عكس -u)
-nl --no-latex لا تقم بتحويل تركيبات الأحرف بأسلوب latex
-s --single-refperfile مرجع واحد لكل ملف إخراج
-d --drop-key لا تضع مفتاح الاقتباس في حقل معرف mods
-c --corporation-file مع وسيطة تحدد ملفًا يحتوي على قائمة بأسماء الشركات لوضعها في <name type="corporate"></name> بدلاً من type="personal" وإزالة تشويه الأسماء
-a --asis مع وسيطة تحدد ملفًا يحتوي على قائمة بالأسماء لمعاملتها كما هي
-nt --nosplit-title لا تقسم العناوين إلى أزواج TITLE/SUBTITLE
--verbose إخراج مفصل
--debug إخراج مفصل جدًا (للتحقق من الأخطاء بشكل أساسي)

bib2xml

يقوم bib2xml بتحويل ملف مراجع بصيغة bibtex إلى ملف مراجع وسيط بصيغة XML. حدد الملفات المراد تحويلها في سطر الأوامر. يجب تحديد الملفات التي تحتوي على سلاسل استبدال bibtex قبل الملفات التي يتم فيها تحديد الاستبدالات (أو في نفس الملف قبل استخدامها). إذا لم يتم تحديد أي ملفات، فسيتم قراءة معلومات bibtex من الإدخال القياسي.

bib2xml bibtex_file.bib > output_file.xml

biblatex2xml

يقوم biblatex2xml بتحويل ملف مراجع بصيغة biblatex (لا ينبغي الخلط بينه وبين bibtex) إلى ملف مراجع وسيط بصيغة MODS XML.

biblatex2xml biblatex_file.bib > outputfile.xml

copac2xml

يقوم copac2xml بتحويل ملف مراجع بصيغة COPAC إلى ملف مراجع وسيط بصيغة MODS XML.

end2xml

يقوم end2xml بتحويل ملف مراجع بصيغة endnote النصية إلى ملف مراجع وسيط بصيغة XML. لن يعمل هذا البرنامج على المكتبة الثنائية؛ يجب تصدير الملف أولاً. تبدو صيغ Endnote الموسومة (تصدير بصيغة "Refer") مثل المثال 1، "ملف بصيغة refer مثال". توجد تعليمات جيدة جدًا للتأكد من أنك تصدر هذا بشكل صحيح على http://www.sonnysoftware.com/endnoteimport.html[5]

استخدام end2xml هو نفس استخدام bib2xml.

end2xml endnote_file.end > output_file.xml

ebi2xml

يقوم ebi2xml بتحويل ملف EBI XML إلى ملف مراجع وسيط بصيغة MODS XML.

endx2xml

يقوم endx2xml بتحويل ملف مراجع مصدّر بصيغة EndNote-XML إلى ملف مراجع وسيط بصيغة MODS XML. لن يعمل هذا البرنامج على المكتبة الثنائية؛ يجب تصدير الملف أولاً.

isi2xml

يقوم isi2xml بتحويل ملف مراجع بصيغة ISI-web-of-science إلى ملف مراجع وسيط بصيغة XML.

استخدام isi2xml هو نفس استخدام bib2xml.

isi2xml input_file.isi > output_file.xml

ris2xml

يقوم ris2xml بتحويل ملف مراجع بصيغة RIS إلى ملف مراجع وسيط بصيغة XML. استخدام ris2xml هو مثل end2xml و bib2xml

ris2xml ris_file.ris >	output_file.xml

wordbib2xml

يقوم wordbib2xml بتحويل ملف مراجع بصيغة Word2007 إلى ملف مراجع وسيط بصيغة XML.

bibutils - conversion utilities for bibliographic formats

NAME

bibutils - conversion utilities for bibliographic formats

SYNOPSIS

xml2bib [options] [xml_file.xml] [> output.bib]
xml2ads [options] [xml_file.xml] [> output.ads]
xml2ris [options] [xml_file.xml] [> output.ris]
xml2end [options] [xml_file.xml] [> output.end]
xml2wordbib [options] [xml_file.xml] [> output.word.xml]

DESCRIPTION

Bibutils is a suite of utilities for converting bibliography information between various formats. All utilities take input in MODS XML format (see Library of Congress[1, 2]) and produce output in one of several formats.

The MODS XML bibliography format is becoming increasingly common in library catalogues and institutional repositories. The tools provided here allow easy conversion to the more commonly used bibliographic formats.

The input file is taken from standard input if no file name is given. Output is sent to standard output if no file name is given.

Common Options Converting from MODS

Note that --output-encoding refers to the input file

-h --help display help
-v --version display version
-o --output-encoding interpret the input file as using the requested character set (use w/o argument for current list derived from character sets at www.kostis.net[4]) unicode is now a character set option
-s --single-refperfile put one reference per file name by the reference number
-nb --no-bom do not write Byte Order Mark if writing UTF8

xml2bib

xml2bib converts the MODS XML bibliography into a bibtex-formatted reference file. xml2bib usage is as for other tools

xml2bib xml_file.xml > output_file.bib

Since the BibTeX reference format is fairly flexible and seems to have the greatest number of personal preferences, it has also accumulated a number of specific options that are not available for other formats.

Starting with 3.24, xml2bib output uses lowercase tags and mixed case reference types for better interaction with other software. The older behavior with all uppercase tags/reference types can still be generated using the command-line switch -U/--uppercase.

xml2bib-specific Options:

-fc --finalcomma add final comma in the bibtex output for those that want it
-sd --singledash use one dash instead of two (longer dash in latex) between numbers in page output
-b --brackets use brackets instead of quotation marks around field data
-w --whitespace add beautifying whitespace to output
-U --uppercase use all uppercase for tags (field names) and reference types (pre-3.24 behavior)
-sk --strictkey only use alphanumeric characters for bibtex citation keys

xml2ads

xml2ads converts the MODS XML bibliography to the Smithsonian Astrophysical Observatory (SAO)/National Aeronautics and Space Administration (NASA) Astrophyics Data System or ADS reference format[6] (which is very similar to the tagged Endnote style). xml2ads usage is as for other tools

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris converts the MODS XML bibliography to RIS-formatted bibliography file. xml2ris usage is as for other tools

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end converts the MODS XML bibliography to tagged Endnote (refer-format) bibliography file. xml2end usage is as for other tools

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib converts the MODS XML bibliography to Word 2007-formatted XML bibliography file. xml2wordbib usage is as for other tools

xml2wordbib xml_file.xml >  output_file.word.xml

xml2wordbib was called xml2word in versions of bibutils prior to 3.40. It was renamed to avoid confusion with other tools. Hopefully this will not break too many scripts already in use.

الوصف

Bibutils هي مجموعة أدوات لتحويل المعلومات الببليوغرافية بين تنسيقات مختلفة. تأخذ جميع الأدوات مدخلات بتنسيق MODS XML (انظر مكتبة الكونجرس[1, 2]) وتنتج مخرجات بتنسيق واحد من عدة تنسيقات.

أصبح تنسيق MODS XML الببليوغرافي شائعًا بشكل متزايد في فهارس المكتبات والمستودعات المؤسسية. تتيح الأدوات المقدمة هنا التحويل السهل إلى التنسيقات الببليوغرافية الأكثر استخدامًا.

يتم أخذ ملف الإدخال من المدخل القياسي إذا لم يتم تحديد اسم ملف. يتم إرسال المخرجات إلى المخرجات القياسية إذا لم يتم تحديد اسم ملف.

خيارات شائعة للتحويل من MODS

لاحظ أن --output-encoding يشير إلى ملف الإدخال

-h --help عرض المساعدة
-v --version عرض الإصدار
-o --output-encoding تفسير ملف الإدخال على أنه يستخدم مجموعة الأحرف المطلوبة (استخدم بدون وسيطة للقائمة الحالية المستمدة من مجموعات الأحرف على www.kostis.net[4]) اليونيكود هو الآن خيار لمجموعة الأحرف
-s --single-refperfile وضع مرجع واحد لكل اسم ملف برقم المرجع
-nb --no-bom عدم كتابة علامة ترتيب البايتات إذا كنت تكتب UTF8

xml2bib

xml2bib يحول الببليوغرافيا MODS XML إلى ملف مرجع بتنسيق bibtex. استخدام xml2bib كما هو الحال مع الأدوات الأخرى

xml2bib xml_file.xml > output_file.bib

نظرًا لأن تنسيق المراجع BibTeX مرن إلى حد ما ويبدو أنه يمتلك أكبر عدد من التفضيلات الشخصية، فقد تراكمت لديه أيضًا عدد من الخيارات المحددة غير المتاحة للتنسيقات الأخرى.

بدءًا من الإصدار 3.24، يستخدم مخرجات xml2bib علامات بأحرف صغيرة وأنواع مراجع بأحرف مختلطة لتحسين التفاعل مع البرامج الأخرى. لا يزال من الممكن إنشاء السلوك القديم مع جميع العلامات / أنواع المراجع بأحرف كبيرة باستخدام مفتاح سطر الأوامر -U/--uppercase.

خيارات xml2bib المحددة:

-fc --finalcomma إضافة فاصلة نهائية في مخرجات bibtex لمن يريدونها
-sd --singledash استخدام شرطة واحدة بدلاً من اثنتين (شرطة أطول في latex) بين الأرقام في مخرجات الصفحات
-b --brackets استخدام أقواس بدلاً من علامات الاقتباس حول بيانات الحقل
-w --whitespace إضافة مسافات بادئة لتجميل المخرجات
-U --uppercase استخدام أحرف كبيرة لجميع العلامات (أسماء الحقول) وأنواع المراجع (سلوك ما قبل الإصدار 3.24)
-sk --strictkey استخدام الأحرف الأبجدية الرقمية فقط لمفاتيح الاستشهاد bibtex

xml2ads

xml2ads يحول الببليوغرافيا MODS XML إلى تنسيق مرجع نظام بيانات الفيزياء الفلكية لمعهد سميثسونيان لعلم الفلك والفيزياء الفلكية (SAO)/الإدارة الوطنية للملاحة الجوية والفضاء (NASA) أو تنسيق مرجع ADS[6] (وهو مشابه جدًا لأسلوب Endnote المسمى). استخدام xml2ads كما هو الحال مع الأدوات الأخرى

xml2ads xml_file.xml > output_file.ads

xml2ris

xml2ris يحول الببليوغرافيا MODS XML إلى ملف ببليوغرافي بتنسيق RIS. استخدام xml2ris كما هو الحال مع الأدوات الأخرى

xml2ris xml_file.xml > output_file.ris

xml2end

xml2end يحول الببليوغرافيا MODS XML إلى ملف ببليوغرافي بتنسيق Endnote المسمى (تنسيق refer). استخدام xml2end كما هو الحال مع الأدوات الأخرى

xml2end xml_file.xml >  output_file.end

xml2wordbib

xml2wordbib يحول الببليوغرافيا MODS XML إلى ملف ببليوغرافي XML بتنسيق Word 2007. استخدام xml2wordbib كما هو الحال مع الأدوات الأخرى

xml2wordbib xml_file.xml >  output_file.word.xml

كان اسم xml2wordbib هو xml2word في إصدارات bibutils السابقة للإصدار 3.40. تم تغيير اسمه لتجنب الالتباس مع الأدوات الأخرى. نأمل ألا يؤدي هذا إلى تعطيل العديد من البرامج النصية المستخدمة بالفعل.
