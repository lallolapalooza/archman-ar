NAME

\n

wavpack — WavPack lossless audio compressor

\n
\n\n
\n

SYNOPSIS

\n

wavpack [-a] [-b] [-c] [-d] [-f] [-h] [-i] [-j] [-l] [-m] [-n] [-o output.wv] [-p] [-q] [-r] [-s n] [-t] [-v] [-w -Encoder] [-w -Settings] [-w Field=Value] [-w Field=@file.ext] [-x[n] [-y] [-z[n] [--blocksize=n] [--checksum-bytes=n] [--disable-ddd] [--honor-mid] [--import=file.wv] [--license] [--optimize-int32] [--pair-unassigned-chans] [--pre-quantize=bits] [--raw-pcm] [--raw-pcm=sr,bits[f|s|u],chans,[le|be]] [--raw-pcm-skip=begin[,end]] [--threads=n] [--use-dns] [--version] [--write-binary-tag Field=@file.ext] [in.....

\n
\n\n
\n

DESCRIPTION

\n

The wavpack utility is a versatile compressor that provides lossless compression for audio files. It can also operate in a hybrid mode, which offers a configurable level of lossy compression while aiming to preserve the quality of the original audio.

\n
\n
-a
\n
disable audio processing and just store raw data
\n
-b
\n
write a WavPack file containing only raw, unprocessed audio data
\n
--blocksize=n
\n
set block size to n (default is 32768, maximum 1048575)
\n
-c
\n
create correction file (.wvc) with 3% overhead for error resilience
\n
--checksum-bytes=n
\n
set number of version 4 checksums to n (default 32)
\n
-d
\n
delete original files on successful completion of compression
\n
--disable-ddd
\n
disable dynamic digital delay noise reduction
\n
-f
\n
use default \"fast\" lossless compression
\n
-h
\n
use default \"high\" lossless compression
\n
--honor-mid
\n
honor mid/side coding setting in source file
\n
-i
\n
use default hybrid compression (lossy)
\n
--import=file.wv
\n
import WavPack files (lossless only)
\n
-j
\n
use default hybrid compression with median noise shaping, requires 3 or more channels
\n
--license
\n
display license information
\n
-l
\n
use default \"low\" lossless compression
\n
-m
\n
use default MD5 integrity checking
\n
-n
\n
no compute MD5, no verify; only for direct copy or unpack
\n
--optimize-int32
\n
New optimization targeting 32-bit integer audio files that were originally\n sourced from 32-bit float audio. Can improve compression by 10%, but is\n only applicable in lossless modes. Resulting files will only decode with\n 24-bit resolution on older decoders (i.e., technically lossy).
\n
--pair-unassigned-chans
\n
encode unassigned channels into stereo pairs
\n
--pre-quantize=bits
\n
pre-quantize samples to bits depth BEFORE encoding\n and MD5 calculation (common use would be\n --pre-quantize=20 for 24-bit or float material\n recorded with typical converters)
\n
-q
\n
quiet (keep console output to a minimum)
\n
-r
\n
parse headers to determine audio format and length but do not store the\n headers in the resulting WavPack file (a minimum header will be generated\n by wvunpack, but some non-audio metadata might be\n lost)
\n
--raw-pcm
\n
input data is raw pcm (44,100 Hz, 16-bit, 2-channels)
\n
--raw-pcm=sr,bits[f|s|u],chans,[le|be]
\n
Input data is raw pcm with specified sample-rate, bit-depth (float,\n unsigned, signed), number of channels, and endianness. Defaulted\n parameters may be omitted, specify bits=1 for\n DSD.
\n
--raw-pcm-skip=begin[,end]
\n
skip begin bytes before encoding raw PCM (header)\n and skip end bytes at the EOF (trailer)
\n
-sn
\n
Override default hybrid mode noise shaping where n\n is a float value between -1.0 and 1.0. Negative values move noise lower in\n freq, positive values move noise higher in freq; use 0 for no shaping\n (white noise).
\n
-t
\n
Copy input file's time stamp to output files.
\n
--threads=n
\n
Enable (or disable) multithreaded operation with n=1\n (no threading) to n=12 (max threads). Significantly\n improves the speed of lossless compression on multicore CPUs. In the\n hybrid modes, only multichannel files can utilize multithreading. Omitting\n the parameter will select an optimum number of threads.
\n
--use-dns
\n
force use of dynamic noise shaping (hybrid mode only)
\n
-v
\n
verify output file integrity after write (not for piped output)
\n
--version
\n
write program version to stdout
\n
-w\n -Encoder
\n
write encoder metadata to APEv2 tag (e.g., “Encoder=WavPack\n 5.8.0”)
\n
-w\n -Settings
\n
write user settings metadata to APEv2 tag (e.g.,\n “Settings=-hb384cx3”)
\n
-w\n “Field=Value”
\n
write the specified text metadata to APEv2 tag
\n
-w\n “Field=@file.ext”
\n
Write specified text metadata from file to APEv2 tag; normally used for\n embedded cuesheets and logs (field names “Cuesheet” and\n “Log”).
\n
--write-binary-tag\n “Field=@file.ext”
\n
Write the specified binary metadata file to APEv2 tag; normally used for\n cover art with the field name “Cover Art (Front)”.
\n
-x[n]
\n
extra encode processing, n = 0 to 6, default=1; -x0 for no extra\n processing, -x1 to -x3 to choose best of predefined filters, -x4 to -x6 to\n generate custom filters (very slow!)
\n
-y
\n
yes to all warnings; use with caution!
\n
-z[n]
\n
don't set (n=0 or omitted) or set (n=1) console title to indicate progress\n (leaves "WavPack Completed")
\n
