waybar-ext-workspaces(5)

الحزمة: waybar

التراخيص: MIT

waybar-wlr-workspaces(5) دليل تنسيقات الملفات waybar-wlr-workspaces(5)

الاسم

waybar - وحدة مساحات العمل wlr

الوصف

تعرض وحدة workspaces مساحات العمل المستخدمة حاليًا في مدير نوافذ wayland.

الإعداد

يتم معالجتها بواسطة ext/workspaces

format:
النوع: string
الافتراضي: {name}
التنسيق، كيف يتم عرض المعلومات.

format-icons:
النوع: array
بناءً على اسم وم state مساحة العمل، يتم اختيار الأيقونة المقابلة. انظر icons.

sort-by-name:
النوع: bool
الافتراضي: true
هل يجب فرز مساحات العمل حسب الاسم. سيتم فرز أسماء مساحات العمل عدديًا عندما تكون جميع الأسماء أرقامًا.

sort-by-coordinates:
النوع: bool
الافتراضي: false
هل يجب فرز مساحات العمل حسب الإحداثيات.
لاحظ أنه إذا كان كل من sort-by-name و sort-by-coordinates صحيحين، فسيكون الفرز حسب الاسم أولاً. إذا كان كلاهما خاطئين - سيتم إجراء الفرز حسب المعرف.

sort-by-id:
النوع: bool
الافتراضي: false
هل يجب فرز مساحات العمل حسب المعرف. سيتم فرز معرف مساحة العمل عدديًا عندما تكون جميع المعرفات أرقامًا. له الأسبقية على أي خيار فرز آخر.

all-outputs:
النوع: bool
الافتراضي: false
إذا تم تعيينه على false، سيتم عرض مجموعة مساحات العمل فقط في المخرج المخصص. بخلاف ذلك، يتم عرض جميع مجموعات مساحات العمل.

active-only:
النوع: bool
الافتراضي: false
إذا تم تعيينه على true، فسيتم عرض مساحات العمل النشطة أو العاجلة فقط.

ignore-hidden:
النوع: bool
الافتراضي: true
إذا تم تعيينه على false، فسيتم عرض مساحات العمل المخفية.

بدائل التنسيق

{name}: اسم مساحة العمل المعينة بواسطة مدير النوافذ.

{id}: معرف مساحة العمل المعين بواسطة مدير النوافذ.

{icon}: أيقونة، كما هو محدد في format-icons.

إجراءات النقر

activate: التبديل إلى مساحة العمل.

close: إغلاق مساحة العمل.

أيقونات

بالإضافة إلى مطابقة اسم مساحة العمل، يمكن تعيين format-icons التالية.

  • default: سيتم عرضه عندما لا يتم العثور على تطابق للسلسلة.
  • active: سيتم عرضه عندما تكون مساحة العمل نشطة

أمثلة

"ext/workspaces": {
	"format": "{name}: {icon}",
	"on-click": "activate",
	"format-icons": {
		"Workspace 1": "“\uE120”",
		"Workspace 2": "“\uE268”",
		"Workspace 3": "“\uE121”",
		"Workspace 4": "“\uE1BC”",
		"active": "“\uE192”",
		"default": "“\uE111”"
	},
	"sort-by-id": true
}
