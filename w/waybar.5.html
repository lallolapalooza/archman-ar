waybar(5)

الحزمة: waybar

التراخيص: MIT

waybar(5) دليل تنسيقات الملفات waybar(5)

الاسم

waybar - ملف التكوين

الوصف

يستخدم التكوين تنسيق ملف JSONC ويُسمى config أو config.jsonc.

المواقع الصالحة لهذا الملف هي:

  • $XDG_CONFIG_HOME/waybar/
  • ~/.config/waybar/
  • ~/waybar/
  • /etc/xdg/waybar/
  • /etc/xdg/waybar/

نقطة بداية جيدة هي التكوين الافتراضي الموجود في https://github.com/Alexays/Waybar/blob/master/resources/config.jsonc كما يمكن العثور على مثال تكوين بسيط في أسفل صفحة الدليل هذه.

تستخدم عناصر العرض المرئي لـ waybar ورقة أنماط CSS، راجع waybar-styles(5) للتفاصيل.

تكوين الشريط

expand-center
النوع: bool
الافتراضي: false
يمكّن modules-center من استهلاك كل المساحة المتبقية ديناميكيًا.

expand-left
النوع: bool
الافتراضي: false
يمكّن modules-left من استهلاك كل المساحة المتبقية ديناميكيًا.

expand-right
النوع: bool
الافتراضي: false
يمكّن modules-left من استهلاك كل المساحة المتبقية ديناميكيًا.

layer
النوع: string
الافتراضي: bottom
يحدد ما إذا كان الشريط يُعرض أمام (top) النوافذ أو خلفها (bottom)

.

output
النوع: string|array
يحدد الشاشة التي سيُعرض عليها هذا الشريط. يمكن استخدام علامة التعجب (!) لاستبعاد مخرج معين.

تتبع مواصفات المخرج مواصفات sway ويمكن أن تكون إما منفذ المخرج مثل "HDMI-A-1" أو سلسلة تتكون من الشركة المصنعة والطراز والرقم التسلسلي مثل "Some Company ABC123 0x00000000". راجع sway-output(5) للتفاصيل. في المصفوفة، يمكن استخدام النجمة '*' في النهاية لقبول جميع المخارج، في حال كانت جميع الإدخالات السابقة استبعادات.

position
النوع: string
الافتراضي: top
موضع الشريط، يمكن أن يكون top أو bottom أو left أو right.

height
النوع: integer
الارتفاع الذي سيستخدمه الشريط إن أمكن. اتركه فارغًا لقيمة ديناميكية.

width
النوع: integer
العرض الذي سيستخدمه الشريط إن أمكن. اتركه فارغًا لقيمة ديناميكية.

modules-left
النوع: array
الوحدات التي ستُعرض على اليسار.

modules-center
النوع: array
الوحدات التي ستُعرض في الوسط.

modules-right
النوع: array

الوحدات التي ستُعرض على اليمين.

margin
النوع: string
قيمة الهوامش باستخدام تنسيق CSS بدون وحدات.

margin-<top|left|bottom|right>
النوع: integer
قيمة الهوامش بدون وحدات.

no-center
النوع: bool
الافتراضي: false
خيار لتعطيل وحدات الوسط بالكامل، مفيد مع expand-*.

spacing
النوع: integer
حجم الفجوات بين الوحدات المختلفة.

name
النوع: string
اسم اختياري يُضاف كصنف CSS، لتنسيق أشرطة waybar المتعددة.

mode
النوع: string
يختار أحد أوضاع العرض المُعدّة مسبقًا. هذا مكافئ لأمر mode في sway-bar(5) ويدعم نفس القيم: dock وhide وinvisible وoverlay.
ملاحظة: قد لا تكون الأوضاع hide وinvisible مفيدة بدون Sway IPC.

start_hidden
النوع: bool
الافتراضي: false
خيار لبدء الشريط مخفيًا.

modifier-reset
النوع: string
الافتراضي: press

يحدد توقيت مفتاح التعديل لإعادة تعيين رؤية الشريط. لإعادة تعيين رؤية الشريط عند الضغط على مفتاح التعديل استخدم press. استخدم release لإعادة تعيين الرؤية عند تحرير مفتاح التعديل وفقط إذا لم يحدث أي إجراء آخر أثناء الضغط على المفتاح. هذا يمنع إخفاء الشريط عندما يُستخدم مفتاح التعديل لتبديل مساحة عمل أو تغيير وضع الربط أو بدء اختصار لوحة مفاتيح.

exclusive
النوع: bool
الافتراضي: true
خيار لطلب منطقة حصرية من المُركّب. عطّل هذا للسماح برسم نوافذ التطبيقات أسفل الشريط أو فوقه.

fixed-center
النوع: bool
الافتراضي: true

تفضيل موضع الوسط الثابت لكتلة `modules-center`. ستبقى الكتلة الوسطى في منتصف الشريط كلما أمكن. لا يزال من الممكن دفعها إذا احتاجت الكتل الأخرى مساحة أكبر. عند التعيين إلى false، تتم توسيط الكتلة الوسطى في المساحة بين الكتلة اليسرى والكتلة اليمنى.

passthrough
النوع: bool
الافتراضي: false
خيار لتمرير أي أحداث المؤشر إلى النافذة الموجودة أسفل الشريط.

مخصص للاستخدام مع طبقات top أو overlay وبدون منطقة حصرية.

ipc
النوع: bool
الافتراضي: false
خيار للاشتراك في أحداث تكوين ورؤية شريط Sway IPC والتحكم في waybar بأوامر swaymsg bar.
يتطلب تمرير قيمة bar_id من تكوين sway إما عبر وسيطة سطر الأوامر -b أو تحديدها بخيار id.

id
النوع: string
bar_id لـ Sway IPC. استخدم هذا إذا كنت بحاجة إلى تجاوز القيمة الممررة عبر وسيطة سطر الأوامر -b bar_id لنسخة الشريط المحددة.

include
النوع: string|array
مسارات ملفات تكوين إضافية.

يمكن أن يحتوي كل ملف على كائن واحد بأي من خيارات تكوين الشريط. في حالة الخيارات المكررة، تأخذ القيمة الأولى المحددة الأولوية، أي الملف المُضمِّن -> أول ملف مُضمَّن -> إلخ. يُسمح بالتضمينات المتداخلة، لكن تأكد من تجنب الاستيرادات الدائرية. بالنسبة لتكوين متعدد الأشرطة، تؤثر توجيهات include على كائن تكوين الشريط الحالي فقط.

reload_style_on_change
النوع: bool
الافتراضي: false
خيار لتمكين إعادة تحميل نمط css إذا تم اكتشاف تعديل على ملف ورقة الأنماط أو أي ملفات css مستوردة.

on-sigusr1
النوع: string
الافتراضي: toggle
الإجراء الذي يُنفذ عند تلقي إشارة الإنهاء SIGUSR1.
القيم الممكنة: show وhide وtoggle وreload و noop.
القيمة الافتراضية: toggle.

on-sigusr2
النوع: string
الافتراضي: reload
الإجراء الذي يُنفذ عند تلقي إشارة الإنهاء SIGUSR2.
القيم الممكنة: show وhide وtoggle وreload و noop.
القيمة الافتراضية: reload.

تنسيق الوحدة

يمكنك استخدام PangoMarkupFormat (راجع https://developer.gnome.org/pango/stable/PangoMarkupFormat.html#PangoMarkupFormat).

مثال:

"format": "<span style="italic">{}</span>"

نسخ متعددة من وحدة

إذا كنت تريد نسخة ثانية من وحدة، يمكنك إضافة لاحقة لها بـ '#' واسم مخصص. على سبيل المثال، إذا كنت تريد وحدة بطارية ثانية، يمكنك إضافة "battery#bat2" إلى وحداتك. لتكوين الوحدة المضافة حديثًا، تضيف أيضًا تكوين وحدة بالاسم نفسه.

قد يبدو هذا شيئًا مثل هذا (هذا مثال غير مكتمل):

"modules-right": ["battery", "battery#bat2"],
"battery": {
	"bat": "BAT1"
},
"battery#bat2": {
	"bat": "BAT2"
}

تكوين بسيط

قد يبدو ملف config بسيط مثل هذا:

{
	"layer": "top",
	""modules-left": ["sway/workspaces", "sway/mode"],
	"modules-center": ["sway/window"],
	"modules-right": ["battery", "clock"],
	"sway/window": {
		"max-length": 50
	},
	"battery": {
		"format": "{capacity}% {icon}",
		"format-icons": ["", "", "", "", ""]
	},
	"clock": {
		"format-alt": "{:%a, %d. %b  %H:%M}"
	}
}

الإشارات

يقبل Waybar الإشارات التالية:

SIGUSR1

افتراضيًا يبدّل رؤية الشريط (يخفيه إذا كان ظاهرًا، ويظهره إذا كان مخفيًا)
SIGUSR2
افتراضيًا يعيد تحميل (إعادة تعيين) الشريط
SIGINT
يُنهي الشريط

على سبيل المثال، لتبديل الشريط برمجيًا، يمكنك استدعاء `killall -SIGUSR1 waybar`.

إعداد إشارة المستخدم

معاملات الإعداد on-sigusr1 و on-sigusr2 تغيّر ما يحدث عندما تتلقى الأشرطة إشارتي SIGUSR1 و SIGUSR2.

هذا يعني أن الأوامر `killall -SIGUSR1 waybar` و `killall -SIGUSR2 waybar` يمكنها تنفيذ إجراء يحدده المستخدم.

وهذا يعني أيضًا أنه إذا كان لدى سكربت خارجي معرّف العملية (PID) للشريط فيمكنه تنفيذ منطق أكثر تعقيدًا لـ `show`/`hide`/`reload` لكل نسخة من Waybar. يمكن للمرء العثور على معرّف العملية مثلًا عبر `pgrep -a waybar` والذي يمكن بعد ذلك مطابقته باسم الإعداد أو معاملات أخرى.

معاني معاملات الإنهاء

show يبدّل الحالة إلى ظاهر (لكل شريط). hide يبدّل الحالة إلى مخفي (لكل شريط). toggle يبدّل الحالة بين ظاهر ومخفي (لكل شريط). reload يعيد تحميل جميع أشرطة Waybar لعملية Waybar الحالية (مكافئ أساسًا لإعادة التشغيل بإعداد محدّث يضبط قيم الرؤية الأولية). noop لا يفعل شيئًا عند استقبال إشارة الإنهاء.

إعداد متعدد المخارج

تقييد الإعداد بمخارج معينة

{
	"layer": "top",
	"output": "eDP-1",
	"modules-left": ["sway/workspaces", "sway/mode"],
	...
}
{
	"layer": "top",
	"output": ["eDP-1", "VGA"],
	"modules-left": ["sway/workspaces", "sway/mode"],
	...
}

إعداد مخارج متعددة

لا تحدد مخرجًا لإنشاء أشرطة متعددة على نفس الشاشة.

[{
	"layer": "top",
	"output": "eDP-1",
	"modules-left": ["sway/workspaces", "sway/mode"],
	...
}, {
	"layer": "top",
	"output": "VGA",
	"modules-right": ["clock"],
	...
}]

تدوير الوحدات

عند وضع Waybar على الجانب الأيسر أو الأيمن من الشاشة، يكون من المفيد أحيانًا القدرة على تدوير محتويات وحدة بحيث يمتد النص عموديًا. يمكن القيام بذلك باستخدام خاصية "rotate" للوحدة. مثال:

{
	"clock": {
		"rotate": 90
	}
}

الخيارات الصالحة لخاصية "rotate" هي: 0، 90، 180، و 270.

تبديل الأيقونة والتسمية

إذا كانت الوحدة تعرض تسمية وأيقونة معًا، فقد يكون من المرغوب فيه تبديلهما (على سبيل المثال، للألواح على الجانب الأيسر أو الأيمن من الشاشة، أو للمستخدم الذي يتبنى نصًا من اليمين إلى اليسار). يمكن تحقيق ذلك باستخدام خاصية "swap-icon-label"، التي تأخذ قيمة منطقية. مثال:

{
	"sway/window": {
		"swap-icon-label": true
	}
}

تجميع الوحدات

تسمح مجموعات الوحدات بتكديس الوحدات في أي اتجاه. افتراضيًا، عندما يكون الشريط موضوعًا في أعلى أو أسفل الشاشة، تُكدَّس الوحدات في المجموعة عموديًا. وبالمثل، عند وضعه على اليسار أو اليمين، تُكدَّس الوحدات في المجموعة أفقيًا. يمكن تغيير ذلك باستخدام خاصية "orientation".

تُعرَّف مجموعة الوحدات بتحديد وحدة باسم "group/some-group-name". يجب أيضًا إعداد المجموعة بقائمة من الوحدات المحتواة. مثال:

{
	"modules-right": ["group/hardware", "clock"],
	"group/hardware": {
		"orientation": "vertical",
		"modules": [
			"cpu",
			"memory",
			"battery"
		]
	},
	...
}

الخيارات الصالحة لخاصية "orientation" (الاختيارية) هي: "horizontal"، "vertical"، "inherit"، و "orthogonal" (الافتراضي).

أدراج المجموعة

قد تخفي المجموعة كل العناصر عدا واحدًا، وتُظهرها فقط عند تمرير الفأرة فوقها. لإعداد ذلك، يمكنك استخدام خاصية `drawer`، التي قيمتها كائن بالخصائص التالية:

transition-duration:
typeof: integer
default: 500
يحدد مدة حركة الانتقال بالمللي ثانية.

children-class:
typeof: string
default: "hidden"
يحدد صنف CSS الذي يُطبَّق على العناصر المخفية.

click-to-reveal:
typeof: bool
default: false
ما إذا كان النقر الأيسر يجب أن يكشف المحتوى بدلًا من تمرير الفأرة. لاحظ أن الوحدات المجمّعة قد لا تزال تعالج أحداث النقر الخاصة بها.

transition-left-to-right:
typeof: bool
default: true
يحدد اتجاه حركة الانتقال. إذا كانت true، ستنزلق العناصر المخفية من اليسار إلى اليمين. إذا كانت false، فستنزلق من اليمين إلى اليسار.

عندما يكون الشريط عموديًا، يُقرأ ذلك من الأعلى إلى الأسفل.
"group/power": {
    "orientation": "inherit",
    "drawer": {
        "transition-duration": 500,
        "children-class": "not-power",
        "transition-left-to-right": false,
    },
    "modules": [
        "custom/power", // First element is the "group leader" and won't ever be hidden
        "custom/quit",
        "custom/lock",
        "custom/reboot",
    ]
},
