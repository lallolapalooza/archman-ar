NAME

wl_shm_buffer — Wayland Shared Memory Buffer

SYNOPSIS

struct wl_shm_buffer

Detailed Description

The wl_shm_buffer object is an interface to a shared memory buffer. It is created by the client using the wl_shm.create_buffer request.

The shared memory buffer is backed by a file descriptor opened with O_RDWR. The client is responsible for allocating and managing the shared memory region.

The buffer can be used for passing image data to the compositor. The format and layout of the pixel data are defined by the pixel format specified when creating the buffer.

Member Function Documentation

int32_t wl_shm_buffer::stride

The stride is the number of bytes between the start of one row and the start of the next row of pixels. This value is often used to calculate the offset of a specific pixel in the buffer.

int32_t wl_shm_buffer::width

The width is the number of pixels in each row of the buffer.
