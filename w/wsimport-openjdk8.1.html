wsimport-openjdk8(1)

الحزمة: jdk8-openjdk

التراخيص: LicenseRef-Java

wsimport(1) أدوات خدمات الويب لجافا wsimport(1)

الاسم

wsimport - يقوم بإنشاء أصول JAX-WS المحمولة التي يمكن حزمها في ملف أرشيف تطبيق الويب (WAR) ويوفر مهمة Ant.

الملخص

wsimport [ خيارات ] wsdl
خيارات
خيارات سطر الأوامر. انظر الخيارات.
wsdl
الملف الذي يحتوي على وصف الخدمة المستندة إلى الويب القابل للقراءة آليًا، وكيف يمكن استدعاؤها، وما هي المعلمات التي تتوقعها، وما هي هياكل البيانات التي تعيدها.

الوصف

يقوم الأمر wsimport بإنشاء أصول JAX-WS المحمولة التالية. يمكن حزم هذه الأصول في ملف WAR مع مستندات WSDL والمخطط وتنفيذ نقطة النهاية لنشرها. يوفر الأمر wsimport أيضًا مهمة Ant wsimport، راجع علامة التبويب الأدوات في صفحة مهمة Wsimport Ant Task على http://jax-ws.java.net/nonav/2.1.1/docs/wsimportant.html

•
واجهة نقطة نهاية الخدمة (SEI)
•
الخدمة
•
فئة الاستثناء التي تتم مواءمتها من wsdl:fault (إن وجدت)
•
يتم اشتقاق سمة الاستجابة غير المتزامنة من استجابة wsdl:message (إن وجدت)
•
أنواع القيم التي تم إنشاؤها بواسطة JAXB (فئات جافا مواءمة من أنواع المخطط)

لبدء الأمر wsgen، قم بما يلي:

Oracle Solaris/Linux:

/bin/wsimport.sh -help

Windows:

\bin\wsimport.bat -help

الخيارات

-d directory

يحدد مكان وضع ملفات الإخراج التي تم إنشاؤها.
-b path

يحدد ملفات ربط JAX-WS أو JAXB الخارجية. يمكن تحديد ملفات ربط JAX-WS و JAXB متعددة باستخدام الخيار -b. يمكنك استخدام هذه الملفات لتخصيص أسماء الحزم، وأسماء الكائنات، وما إلى ذلك. لمزيد من المعلومات حول ملفات ربط JAX-WS و JAXB، راجع دليل المستخدم في قسم تخصيص WSDL على http://jax-ws.java.net/nonav/2.1.1/docs/wsimportant.html
-B jaxbOption

يمرر خيار jaxbOption إلى مترجم مخطط JAXB.
-catalog

يحدد ملف كتالوج لحل مراجع الكيانات الخارجية. يدعم الخيار -catalog تنسيقات TR9401 و XCatalog و OASIS XML Catalog. راجع دليل المستخدم في قسم دعم الكتالوج على http://jax-ws.java.net/nonav/2.1.1/docs/catalog-support.html
-extension

يسمح بامتدادات البائع. يمكن أن يؤدي استخدام الامتدادات إلى تطبيقات غير محمولة أو لا تعمل مع تطبيقات أخرى.
-help

يعرض رسالة مساعدة لأمر wsimport.
-httpproxy: host:port

يحدد خادم وكيل HTTP. المنفذ الافتراضي هو 8080.
-keep

يحافظ على الملفات التي تم إنشاؤها.
-p name

يحدد اسم حزمة مستهدفة لتجاوز تخصيصات WSDL والمخطط، والخوارزمية الافتراضية المحددة في المواصفات.
-s directory

يحدد مكان وضع ملفات المصدر التي تم إنشاؤها.
-verbose

يعرض رسائل المترجم.
-version

يطبع معلومات الإصدار.
-wsdllocation location

يحدد قيمة @WebServiceClient.wsdlLocation.
-target

ينشئ رمزًا وفقًا لإصدار مواصفات JAX-WS المحدد. الإصدار 2.0 ينشئ رمزًا متوافقًا مع مواصفات JAX-WS 2.0.
-quiet

يكتم إخراج أمر wsimport.

يمكن تحديد ملفات ربط JAX-WS و JAXB متعددة باستخدام الخيار -b، ويمكن استخدامها لتخصيص أشياء مختلفة مثل أسماء الحزم وأسماء الكائنات. يمكن العثور على مزيد من المعلومات حول ملفات ربط JAX-WS و JAXB في وثائق التخصيص على https://jax-ws.dev.java.net/nonav/2.1.1/docs/customizations.html

خيارات غير قياسية

-XadditionalHeaders

يواءم الرؤوس غير المرتبطة برسالة طلب أو استجابة مع معلمات طريقة جافا.
-Xauthfile file

عنوان URI لـ WSDL الذي يحدد الملف الذي يحتوي على معلومات التفويض. هذا العنوان URI بالتنسيق التالي:

http://user-name:password@host-name/web-service-name>?wsdl.

-Xdebug

يطبع معلومات التصحيح.
-Xno-addressing-databinding

يمكّن ربط W3C EndpointReferenceType بجافا.
-Xnocompile

لا يقوم بتجميع ملفات جافا التي تم إنشاؤها.

مثال

يقوم المثال التالي بإنشاء أصول جافا وتجميع الأصول عن طريق استيراد http://stockquote.example.com/quote?wsdl

wsimport -p stockquote http://stockquote.example.com/quote?wsdl

NAME

wsimport - JAX-WS API tools

SYNOPSIS

wsimport [options] wsdl_url

DESCRIPTION

wsimport is a JDK tool that enables you to execute the web service import tool. It generates, from a WSDL file, Java classes that can be used to invoke a web service.

OPTIONS

The following options are available:

  • -keep: Keep the generated source files.
  • -verbose: Print informational messages during the generation process.
  • -package name: Specifies the package name for the generated classes.
  • -p name: Same as -package.
  • -source version: Specifies the Java source version to generate (e.g., 1.5, 1.6).
  • -mkdir: Creates directories for the generated source files.
  • -destination dir: Specifies the directory where to place the generated files.
  • -httpproxyhost host: Specifies the HTTP proxy host.
  • -httpproxyport port: Specifies the HTTP proxy port.
  • -host host: Specifies the target host for the WSDL.
  • -port port: Specifies the target port for the WSDL.
  • -username user: Specifies the username for basic authentication.
  • -password pass: Specifies the password for basic authentication.
  • -wsdlLocation url: Specifies the location of the WSDL document.
  • -clientjar file: Generates a client JAR file containing the generated classes and the WSDL.
  • -extension: Allows the use of vendor extensions.
  • -catalog file: Specifies the XML catalog file to resolve public identifiers and system identifiers.
  • -version: Prints the version information of wsimport.
  • -help: Prints a help message.

NONSTANDARD OPTIONS

Some options may vary depending on the JDK version and implementation.

EXAMPLE

To generate Java classes from a WSDL file located at http://example.com/service?wsdl and save them in the current directory:

wsimport http://example.com/service?wsdl

To generate Java classes in the com.example.generated package and place them in the output directory:

wsimport -p com.example.generated -d output http://example.com/service?wsdl
