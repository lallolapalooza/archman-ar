wslay_event_set_error(3)

الحزمة: libwslay

التراخيص: MIT

WSLAY_EVENT_SET_ERROR(3) wslay WSLAY_EVENT_SET_ERROR(3)

الاسم

wslay_event_set_error - تعيين رمز الخطأ

الملخص

#include <wslay/wslay.h>

void wslay_event_set_error(wslay_event_context_ptr ctx, int val)

الوصف

wslay_event_set_error() يعين رمز الخطأ لإخبار المكتبة بوجود خطأ. تستخدم هذه الدالة عادةً في دوال رد النداء المعرفة من قبل المستخدم. راجع وصف دالة رد النداء لمعرفة رمز الخطأ الذي يجب استخدامه.

قيمة الإرجاع

wslay_event_set_error() لا تعيد قيمة.
