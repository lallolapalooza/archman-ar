wslay_event_queue_msg(3)

الحزمة: libwslay

التراخيص: MIT

WSLAY_EVENT_QUEUE_MSG(3) wslay WSLAY_EVENT_QUEUE_MSG(3)

الاسم

wslay_event_queue_msg - وضع رسالة في قائمة الانتظار للإرسال المستقبلي

الملخص

#include <wslay/wslay.h>

int wslay_event_queue_msg(wslay_event_context_ptr ctx, const struct wslay_event_msg *arg)
int wslay_event_queue_msg_ex(wslay_event_context_ptr ctx, const struct wslay_event_msg *arg, uint8_t rsv)

الوصف

wslay_event_queue_msg() و wslay_event_queue_msg_ex() تضعان الرسالة المحددة في arg في قائمة الانتظار. struct wslay_event_msg معرفة كالتالي:

struct wslay_event_msg {
    uint8_t        opcode;
    const uint8_t *msg;
    size_t         msg_length;
};

العضو opcode هو رمز تشغيل الرسالة. العضو msg هو مؤشر لبيانات الرسالة. العضو msg_length هو طول بيانات الرسالة.

تدعم هذه الدالة كلاً من رسائل التحكم والرسائل غير التحكمية، ويتم إرسال الرسالة المعطاة دون تجزئة. إذا كانت هناك حاجة إلى التجزئة، استخدم الدالة wslay_event_queue_fragmented_msg() بدلاً من ذلك.

هذه الدالة تقوم بنسخ msg بطول msg_length.

هذه الدالة تضع الرسالة في قائمة الانتظار فقط ولا ترسلها. استدعاء الدالة wslay_event_send() يرسل هذه الرسائل الموجودة في قائمة الانتظار.

wslay_event_queue_msg_ex() تقبل إضافيًا المعامل rsv، وهو بتات محجوزة للإرسال. لتعيين البتات المحجوزة، استخدم الماكرو WSLAY_RSV1_BIT، WSLAY_RSV2_BIT، و WSLAY_RSV3_BIT. انظر wslay_event_config_set_allowed_rsv_bits() لرؤية البتات المحجوزة المسموح بها لتعيينها.

قيمة الإرجاع

wslay_event_queue_msg() و wslay_event_queue_msg_ex() ترجع 0 إذا نجحت، أو ترجع رموز خطأ سالبة التالية:

WSLAY_ERR_NO_MORE_MSG
لم يتمكن من وضع الرسالة المعطاة في قائمة الانتظار. أحد الأسباب الممكنة هو أنه تم وضع/إرسال إطار تحكم للإغلاق، ولا يُسمح بوضع أي رسائل أخرى في قائمة الانتظار.
WSLAY_ERR_INVALID_ARGUMENT
الرسالة المعطاة غير صالحة؛ أو تم تعيين RSV1 لإطار تحكم؛ أو تم تعيين بت في rsv غير مسموح به (انظر wslay_event_config_set_allowed_rsv_bits()).
WSLAY_ERR_NOMEM
نفاد الذاكرة.
