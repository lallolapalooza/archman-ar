NAME

wifidump - يوفر واجهة لالتقاط إطارات Wi-Fi من مضيف بعيد عبر SSH.

SYNOPSIS

wifidump [ --help ] [ --version ] [ --extcap-interfaces ] [ --extcap-dlts ] [ --extcap-interface=<interface> ] [ --extcap-config ] [ --extcap-capture-filter=<capture filter> ] [ --capture ] [ --fifo=<path to file or pipe> ] [ --remote-host=<IP address> ] [ --remote-port=<TCP port> ] [ --remote-username=<username> ] [ --remote-password=<password> ] [ --sshkey=<public key path> ] [ --remote-interface=<interface> ] [ --remote-channel-frequency=<channel frequency> ] [ --remote-channel-width=<channel width> ]

wifidump --extcap-interfaces

wifidump --extcap-interface=<interface> --extcap-dlts

wifidump --extcap-interface=<interface> --extcap-config

wifidump --extcap-interface=<interface> --fifo=<path to file or pipe> --capture --remote-host=myremotehost --remote-port=22 --remote-username=user --remote-interface=eth2 --remote-channel-frequency=5180 --remote-channel-width=40

DESCRIPTION

Wifidump هو أداة extcap تتيح لك التقاط حركة مرور Wi-Fi من مضيف بعيد عبر اتصال SSH باستخدام tcpdump. الشرط لالتقاط إطارات Wi-Fi هو أن المضيف البعيد يجب أن يحتوي على الثنائيات اللازمة لإدارة ووضع الواجهة المطلوبة في وضع المراقبة. تشمل هذه الثنائيات: ip و iw و iwconfig. أيضًا، نظرًا لأن استخدام وضع المراقبة وإدارة واجهة Wi-Fi يتطلب امتيازات الجذر، يجب تكوين النظام للسماح للمستخدم المطلوب بتشغيل هذه الثنائيات باستخدام sudo دون إدخال كلمة مرور.

عادةً لا يتم استدعاء wifidump مباشرة. بدلاً من ذلك، يمكن تكوينه من خلال واجهة المستخدم الرسومية لـ Wireshark أو سطر الأوامر الخاص بها. سيؤدي ما يلي إلى تشغيل Wireshark وبدء الالتقاط من المضيف remotehost:

$ wireshark '-oextcap.wifidump.remotehost:remotehost' -i wifidump -k

للتحكم بشكل صريح في أمر الالتقاط عن بعد:

$ wireshark '-oextcap.wifidump.remotehost:remotehost' \
            '-oextcap.wifidump.remotechannelfrequency:5180' \
            '-oextcap.wifidump.remotechannelwidth:40' \
            -i wifidump -k

الواجهات المدعومة:

1. wifidump

OPTIONS

--help

اطبع وسائط البرنامج.

--version

اطبع إصدار البرنامج.

--extcap-interfaces

سرد الواجهات المتاحة.

--extcap-interface=<interface>

استخدم الواجهات المحددة.

--extcap-dlts

سرد DLTs للواجهة المحددة.

--extcap-config

سرد خيارات تكوين الواجهة المحددة.

--capture

بدء الالتقاط من الواجهة المحددة وكتابة بيانات الحزم الأولية إلى الموقع المحدد بواسطة --fifo.

--fifo=<path to file or pipe>

حفظ الحزم الملتقطة في ملف أو إرسالها عبر الأنابيب.

--remote-host=<remote host>

عنوان المضيف البعيد للالتقاط.

--remote-port=<remote port>

منفذ SSH للمضيف البعيد.

--remote-username=<username>

اسم المستخدم لمصادقة ssh.

--remote-password=<password>

كلمة المرور المراد استخدامها (إذا لم يتم استخدام ssh-agent و pubkey). تحذير: يتم تخزين كلمات المرور كنص عادي ومرئية لجميع المستخدمين على هذا النظام. يوصى باستخدام ملفات المفاتيح مع وكيل SSH.

--sshkey=<SSH private key path>

المسار إلى مفتاح خاص لـ SSH للمصادقة.

--remote-interface=<remote interface>

الواجهة الشبكية البعيدة للالتقاط منها.

--remote-channel-frequency=<channel frequency>

تردد القناة البعيدة بالميجاهرتز.

--remote-channel-width=<channel width>

عرض القناة البعيدة بالميجاهرتز.

--extcap-capture-filter=<capture filter>

مرشح الالتقاط. يتوافق مع القيمة المقدمة عبر خيار tshark -f، وحقل مرشح الالتقاط بجوار قائمة الواجهات في واجهة Wireshark.

EXAMPLES

لرؤية وسائط البرنامج:

wifidump --help

لرؤية إصدار البرنامج:

wifidump --version

لرؤية الواجهات:

wifidump --extcap-interfaces

يدعم واجهة واحدة فقط (wifidump).

مثال للإخراج

interface {value=wifidump}{display=Wi-Fi remote capture}

لرؤية DLTs الواجهة:

wifidump --extcap-interface=wifidump --extcap-dlts

مثال للإخراج

dlt {number=147}{name=wifidump}{display=Remote capture dependent DLT}

لرؤية خيارات تكوين الواجهة:

wifidump --extcap-interface=wifidump --extcap-config

للالتقاط:

wifidump --extcap-interface=wifidump --fifo=/tmp/wifidump.pcap --capture --remote-host 192.168.1.10 --remote-username user --remote-channel-frequency 5180 --remote-channel-width 40

Note

لإيقاف الالتقاط اضغط CTRL+C/kill/إنهاء التطبيق.

يمكن إعادة تسمية الثنائي wifidump لدعم مثيلات متعددة. على سبيل المثال، إذا أردنا أن يظهر wifidump مرتين في wireshark (على سبيل المثال، لمعالجة ملفات تعريف متعددة)، يمكننا نسخ wifi
