which(1)

الحزمة: which

التراخيص: GPL-3.0-or-later

WHICH(1) دليل الأوامر العامة WHICH(1)

الاسم

which - يعرض المسار الكامل (لأوامر) الطرفية.

الملخص

which [خيارات] [--] اسم_البرنامج [...]

الوصف

يأخذ Which وسيطًا واحدًا أو أكثر. لكل وسيط من وسائطه، يقوم بطباعة المسار الكامل للملفات التنفيذية التي كان سيتم تنفيذها عند إدخال هذا الوسيط في موجه الأوامر الطرفية إلى المخرج القياسي. يتم ذلك عن طريق البحث عن ملف تنفيذي أو نص برمجي في الدلائل المدرجة في متغير البيئة PATH باستخدام نفس الخوارزمية التي تستخدمها bash(1).

صفحة الدليل هذه تم إنشاؤها من الملف which.texinfo.

الخيارات

--all, -a
اطبع جميع الملفات التنفيذية المطابقة في PATH، وليس فقط الأولى.
--read-alias, -i
اقرأ الأسماء المستعارة من الإدخال القياسي، وقم بالإبلاغ عن الأسماء المطابقة في المخرج القياسي. هذا مفيد بالاشتراك مع استخدام اسم مستعار لـ which نفسه. على سبيل المثال
alias which=’alias | which -i’.
--skip-alias
تجاهل الخيار ‘--read-alias’، إن وجد. هذا مفيد للبحث صراحة عن الملفات التنفيذية العادية، مع استخدام الخيار ‘--read-alias’ في اسم مستعار أو دالة لـ which.
--read-functions
اقرأ تعريفات دوال الطرفية من الإدخال القياسي، وقم بالإبلاغ عن التعريفات المطابقة في المخرج القياسي. هذا مفيد بالاشتراك مع استخدام دالة طرفية لـ which نفسه. على سبيل المثال:
which() { declare -f | which --read-functions $@ }
export -f which
--skip-functions
تجاهل الخيار ‘--read-functions’، إن وجد. هذا مفيد للبحث صراحة عن الملفات التنفيذية العادية، مع استخدام الخيار ‘--read-functions’ في اسم مستعار أو دالة لـ which.
--skip-dot
تخطي الدلائل في PATH التي تبدأ بنقطة.
--skip-tilde
تخطي الدلائل في PATH التي تبدأ بشرطة مائلة (tilde) والملفات التنفيذية التي توجد في الدليل HOME.
--show-dot
إذا كان دليل في PATH يبدأ بنقطة وتم العثور على ملف تنفيذي مطابق لهذا المسار، فقم بطباعة "./اسم_البرنامج" بدلاً من المسار الكامل.
--show-tilde
إخراج شرطة مائلة (tilde) عندما يطابق دليل الدليل HOME. يتم تجاهل هذا الخيار عند استدعاء which كـ root.
--tty-only
التوقف عن معالجة الخيارات على اليمين إذا لم يكن على tty.
--version,-v,-V
طباعة معلومات الإصدار على المخرج القياسي ثم الخروج بنجاح.
--help
طباعة معلومات الاستخدام على المخرج القياسي ثم الخروج بنجاح.

قيمة الإرجاع

Which تعيد عدد الوسائط الفاشلة، أو -1 عندما لم يتم إعطاء ‘اسم_البرنامج’.

مثال

الطريقة الموصى بها لاستخدام هذه الأداة هي عن طريق إضافة اسم مستعار (csh) أو دالة طرفية (Bourne shell) لـ which كما يلي:

[ba]sh:


which ()
{
  (alias; declare -f) | /usr/bin/which --tty-only --read-alias --read-functions --show-tilde --show-dot $@
}
export -f which

[t]csh:


alias which ’alias | /usr/bin/which --tty-only --read-alias --show-dot --show-tilde’

سيؤدي هذا إلى طباعة ~ و ./ القابلة للقراءة عند بدء which من الموجه الخاص بك، مع الاستمرار في طباعة المسار الكامل عند استخدامه من نص برمجي:


> which q2
~/bin/q2
> echo $(which q2)
/home/carlo/bin/q2

مشاكل

يتم تحديد الدليل HOME عن طريق البحث عن متغير البيئة HOME، والذي يتوقف عند عدم وجود هذا المتغير. سيأخذ Which في الاعتبار دليلين متكافئين على أنهما مختلفان عندما يحتوي أحدهما على مسار يحتوي على رابط رمزي.
