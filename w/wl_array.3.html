وصف تفصيلي

مصفوفة ديناميكية

wl_array هي مصفوفة ديناميكية يمكن أن تنمو فقط حتى يتم تحريرها. وهي مخصصة للتخصيصات الصغيرة نسبيًا التي يكون حجمها متغيرًا أو غير معروف مسبقًا. بينما لا يتطلب إنشاء wl_array أن تكون جميع العناصر من نفس الحجم، فإن wl_array_for_each() يتطلب أن تكون جميع العناصر من نفس النوع والحجم.

وثائق وظائف الأعضاء

void * wl_array_add (struct wl_array * array, size_t size)

يزيد حجم المصفوفة بمقدار size بايت.

المعلمات

array المصفوفة التي سيتم زيادة حجمها
size عدد البايتات لزيادة حجم المصفوفة بها

القيم المعادة

مؤشر إلى بداية المساحة الملحقة حديثًا، أو NULL عند فشل تغيير الحجم.

int wl_array_copy (struct wl_array * array, struct wl_array * source)

ينسخ محتويات المصدر إلى المصفوفة.

المعلمات

array المصفوفة الوجهة للنسخ إليها
source المصفوفة المصدر للنسخ منها

القيم المعادة

0 عند النجاح، أو -1 عند الفشل

وثائق الأصدقاء والرموز ذات الصلة

#define wl_array_for_each( pos, array) [related]

القيمة:

        for (pos = (array)->data;                                        \
             (array)->size != 0 &&                                       \
             (const char *) pos < ((const char *) (array)->data + (array)->size); \
             (pos)++)

يتكرر فوق مصفوفة.

يعبر هذا الماكرو عن مكرر لكل عنصر في wl_array. يقوم بتعيين كل عنصر في المصفوفة إلى pos، والذي يمكن بعد ذلك الإشارة إليه في كتلة تعليمات لاحقة. يجب أن يكون pos مؤشرًا إلى نوع عنصر المصفوفة، ويجب أن تكون جميع عناصر المصفوفة من نفس النوع والحجم.

المعلمات

pos المؤشر الذي سيتم تعيين كل عنصر مصفوفة إليه
array المصفوفة للتكرار فوقها
