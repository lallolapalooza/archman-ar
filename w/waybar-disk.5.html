waybar-disk(5)

الحزمة: waybar

التراخيص: MIT

waybar-disk(5) دليل تنسيقات الملفات waybar-disk(5)

الاسم

waybar - وحدة القرص

الوصف

تعرض الوحدة disk مساحة القرص المستخدمة حاليًا.

الإعدادات

يتم الوصول إليها بواسطة disk

path:
typeof: string
default: "/"
أي مسار يقع في نظام الملفات أو نقطة تحميل يجب عرض المعلومات الخاصة به.

interval:
typeof: integer
default: 30
الفاصل الزمني الذي يتم فيه استطلاع المعلومات.

format:
typeof: string
default: "{percentage_used}%"
التنسيق، كيف يجب عرض المعلومات.

rotate:
typeof: integer
قيمة موجبة لتدوير التسمية النصية (بزيادات 90 درجة).

states:
typeof: object
عدد من حالات استخدام القرص التي يتم تنشيطها عند عتبات نسبة معينة (percentage_used). انظر waybar-states(5).

max-length:
typeof: integer
الحد الأقصى للطول بالحروف الذي يجب أن تعرضه الوحدة.

min-length:
typeof: integer
الحد الأدنى للطول بالحروف الذي يجب أن تقبله الوحدة.

align:
typeof: float
محاذاة التسمية داخل الوحدة، حيث 0 محاذاة لليسار و 1 محاذاة لليمين. إذا تم تدوير الوحدة، فستتبع تدفق النص.

justify:
typeof: string
محاذاة النص داخل تسمية الوحدة، مما يسمح بخيارات 'left'، 'right'، أو 'center' لتحديد الموضع.

on-click:
typeof: string
الأمر الذي سيتم تنفيذه عند النقر على الوحدة.

on-click-middle:
typeof: string
الأمر الذي سيتم تنفيذه عند النقر بزر الوسط على الوحدة باستخدام عجلة الماوس.

on-click-right:
typeof: string
الأمر الذي سيتم تنفيذه عند النقر بزر اليمين على الوحدة.

on-update:
typeof: string
الأمر الذي سيتم تنفيذه عند تحديث الوحدة.

on-scroll-up:
typeof: string
الأمر الذي سيتم تنفيذه عند التمرير لأعلى على الوحدة.

on-scroll-down:
typeof: string
الأمر الذي سيتم تنفيذه عند التمرير لأسفل على الوحدة.

smooth-scrolling-threshold:
typeof: double
العتبة التي سيتم استخدامها عند التمرير.

tooltip:
typeof: bool
default: true
خيار لتعطيل التلميح عند التحويم.

tooltip-format:
typeof: string
default: "{used} out of {total} used ({percentage_used}%)"
تنسيق المعلومات المعروضة في التلميح.

unit:
typeof: string
يستخدم مع specific_free، specific_used، و specific_total لإجبار الحساب دائمًا على أن يكون بوحدة معينة. يقبل kB، kiB، MB، Mib، GB، GiB، TB، TiB.

menu:
typeof: string
الإجراء الذي يعرض القائمة.

menu-file:
typeof: string
موقع ملف واصف القائمة. يجب أن يكون هناك عنصر من نوع

GtkMenu بالمعرف menu

menu-actions:
typeof: array
الإجراءات المقابلة لأزرار القائمة.

expand:
typeof: bool
default: false
يسمح لهذه الوحدة باستهلاك كل المساحة المتبقية ديناميكيًا.

بدائل التنسيق

{percentage_used}: نسبة القرص المستخدم.

{percentage_free}: نسبة مساحة القرص الخالية

{total}: إجمالي مساحة القرص أو القسم أو نقطة التحميل. يختار الوحدة تلقائيًا بناءً على المساحة المتبقية.

{used}: مقدار مساحة القرص المستخدمة. يختار الوحدة تلقائيًا بناءً على المساحة المتبقية.

{free}: مقدار مساحة القرص المتاحة للمستخدمين العاديين. يختار الوحدة تلقائيًا بناءً على المساحة المتبقية.

{path}: المسار المحدد في الإعدادات.

{specific_total}: إجمالي مساحة القرص أو القسم أو نقطة التحميل بوحدة معينة. افتراضيًا بايت.

{specific_used}: مقدار مساحة القرص المستخدمة بوحدة معينة. افتراضيًا بايت.

{specific_free}: مقدار مساحة القرص المتاحة للمستخدمين العاديين بوحدة معينة. افتراضيًا بايت.

أمثلة

"disk": {
	"interval": 30,
	"format": "{percentage_free}% free on {path}",
}
"disk": {
	"interval": 30,
	"format": "{specific_free:0.2f} GB out of {specific_total:0.2f} GB available. Alternatively {free} out of {total} available",
	"unit": "GB"
	// 1434.25 GB out of 2000.00 GB available. Alternatively 1.4TiB out of 1.9TiB available.
}
