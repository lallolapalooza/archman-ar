WMEMCPY(3P) دليل مبرمج POSIX WMEMCPY(3P)

PROLOG

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لمعرفة تفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

NAME

wmemcpy — نسخ أحرف واسعة في الذاكرة

SYNOPSIS

#include <wchar.h>
wchar_t *wmemcpy(wchar_t *restrict ws1, const wchar_t *restrict ws2,
    size_t n);

DESCRIPTION

تتوافق الوظائف الموضحة في صفحة المرجع هذه مع معيار ISO C. أي تعارض بين المتطلبات الموضحة هنا ومعيار ISO C غير مقصود. هذا المجلد من POSIX.1-2017 يحيل إلى معيار ISO C.

تقوم الدالة wmemcpy() بنسخ n حرف واسع من الكائن المشار إليه بواسطة ws2 إلى الكائن المشار إليه بواسطة ws1. لن تتأثر هذه الدالة بالمحل، وسيتم التعامل مع جميع قيم wchar_t بنفس الطريقة. لن يتم التعامل مع الحرف الواسع الفارغ وقيم wchar_t التي لا تتوافق مع أحرف صالحة بشكل خاص.

إذا كانت n صفرًا، يجب على التطبيق التأكد من أن ws1 و ws2 مؤشرات صالحة، وتقوم الدالة بنسخ صفر حرف واسع.

RETURN VALUE

تعيد الدالة wmemcpy() قيمة ws1.

ERRORS

لا توجد أخطاء محددة.
