winedump(1)

الحزمة: wine

التراخيص: LGPL-2.1-or-later

OPTIONS

-v
Show lots of detail while working (verbose). There are 3 levels of output while winedump is running. The default level, when neither -q or -v are given, prints the number of exported functions found in the dll, followed by the name of each function as it is processed, and a status indication of whether it was processed OK. With -v given, a lot of information is dumped while winedump works: this is intended to help debug any problems.

وضع الرمز

رمز
يقوم بفك تشفير رمز C++ رمز ثم يخرج.

الملفات

function_grep.pl
برنامج Perl النصي المستخدم لاسترداد نموذج الوظيفة.

الملفات الناتجة في وضع spec لـ foo.dll:

foo.spec
هذا هو ملف .spec.
foo_dll.h, foo_main.c
هذه هي ملفات الكود المصدري التي تحتوي على الحد الأدنى من الكود لبناء DLL وهمي. يحتوي ملف C على وظيفة واحدة، FOO_Init، والتي لا تفعل شيئًا (ولكن يجب أن تكون موجودة).
Makefile.in
هذا نموذج لـ configure لإنتاج ملف make. تم تصميمه لـ DLL سيتم إدراجه في شجرة كود Wine.

الأخطاء

فك تشفير أسماء C++ غير متزامن تمامًا مع التنفيذ في msvcrt. قد يكون من المفيد تقديم اسم C++ الخاص بك إلى مجموعة الاختبار الخاصة بـ msvcrt.

يمكن الإبلاغ عن الأخطاء على متعقب أخطاء Wine.
