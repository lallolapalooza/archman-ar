NAME

\n

wrc - Wine Resource Compiler

\n
\n
\n

SYNOPSIS

\n

wrc [options] [inputfile...]

\n
\n
\n

DESCRIPTION

\n

wrc compiles resources from inputfile into win16 and\n win32 compatible binary format.

\n

The source file is preprocessed with a builtin ANSI-C compatible\n preprocessor before the resources are compiled. See PREPROCESSOR\n below.

\n

wrc takes a series of inputfile as argument. The\n resources are read from standard input if no inputfile is given. If the\n output file is not specified with -o, then wrc will write the\n output to inputfile.res with .rc stripped, or to\n wrc.tab.res if no inputfile was given.

\n
\n
\n

OPTIONS

\n
\n
-D,\n --define=id[=val]
\n
Define preprocessor identifier id to (optionally) value val.\n See also PREPROCESSOR below.
\n
--debug=nn
\n
Set debug level to nn. The value is a bitmask consisting of\n 1=verbose, 2=dump internals, 4=resource parser trace, 8=preprocessor\n messages, 16=preprocessor scanner and 32=preprocessor parser trace.
\n
-E
\n
Preprocess only. The output is written to standard output if no outputfile\n was selected. The output is compatible with what gcc would generate.
\n
-h,\n --help
\n
Prints a summary message and exits.
\n
-i,\n --input=file
\n
The name of the input file. If this option is not used, then wrc\n will use the first non-option argument as the input file name. If there\n are no non-option arguments, then wrc will read from standard\n input.
\n
-I,\n --include-dir=path
\n
Add path to the list of directories to search for includes. It is\n allowed to specify -I multiple times. Include files are searched in\n the order in which the -I options were specified.\n
\n The search is compatible with gcc, in which '<>' quoted filenames are\n searched exclusively via the -I set path, whereas the\n '""' quoted filenames are first tried to be opened in the\n current directory. Also resource statements with file references are\n located in the same way.
\n
-J,\n --input-format=format
\n
Sets the input format. Valid options are 'rc' or 'rc16'. Setting the input\n to 'rc16' disables the recognition of win32 keywords.
\n
-l,\n --language=lang
\n
Set default language to lang. Default is the neutral language 0\n (i.e. "LANGUAGE 0, 0").
\n
-m16, -m32,\n -m64
\n
Generate resources for 16-bit, 32-bit or 64-bit platforms respectively.\n The only difference between 32-bit and 64-bit is whether the _WIN64\n preprocessor symbol is defined.
\n
--nls-dir=dir
\n
Specify the directory to search for the NLS files containing the codepage\n mapping tables.
\n
--nostdinc
\n
Do not search the standard include path, look for include files only in\n the directories explicitly specified with the -I option.
\n
--no-use-temp-file
\n
Ignored for compatibility with windres.
\n
-o, -fo,\n --output=file
\n
Write output to file. Default is inputfile.res with\n .rc stripped or wrc.tab.res if input is read from standard\n input.
\n
-O,\n --output-format=format
\n
Sets the output format. The supported formats are po, pot,\n res, and res16. If this option is not specified, the format\n defaults to res.\n
\n In po mode, if an output file name is specified it must match a known\n language name, like en_US.po; only resources for the specified\n language are output. If no output file name is specified, a separate\n .po file is created for every language encountered in the\n input.
\n
--pedantic
\n
Enable pedantic warnings. Notably redefinition of #define statements can\n be discovered with this option.
\n
--po-dir=dir
\n
Enable the generation of resource translations based on mo files loaded\n from the specified directory. That directory must follow the gettext\n convention, in particular it must contain one .mo file for each\n language, and a LINGUAS file listing the available languages.
\n
-r
\n
Ignored for compatibility with rc.
\n
--preprocessor=program
\n
This option may be used to specify the preprocessor to use, including any\n leading arguments. If not specified, wrc uses its builtin\n processor. To disable preprocessing, use --preprocessor=cat.
\n
--sysroot=dir
\n
Prefix the standard include paths with dir.
\n
--utf8,\n -u
\n
Set the default codepage of the input file to UTF-8.
\n
-U,\n --undefine=id
\n
Undefine preprocessor identifier id. Please note that only macros\n defined up to this point are undefined by this command. However, these\n include the special macros defined automatically by wrc. See also\n PREPROCESSOR below.
\n
--use-temp-file
\n
Ignored for compatibility with windres.
\n
-v,\n --verbose
\n
Turns on verbose mode (equivalent to -d 1).
\n
--version
\n
Print version and exit.
\n
\n
\n
\n

PREPROCESSOR

\n

The preprocessor is ANSI-C compatible with some of the extensions\n of the gcc preprocessor.

\n

The preprocessor recognizes these directives: #include, #define\n (both simple and macro), #undef, #if, #ifdef, #ifndef, #elif, #else, #endif,\n #error, #warning, #line, # (both null- and line-directive), #pragma\n (ignored), #ident (ignored).

\n

The preprocessor sets by default several defines:\n
\n - RC_INVOKED set to 1\n
\n - __WRC__ Major version of wrc\n
\n - __WRC_MINOR__ Minor version of wrc\n
\n - __WRC_PATCHLEVEL__ Patch level

\n

Win32 compilation mode also sets _WIN32 to 1.

\n

Special macros __FILE__, __LINE__, __TIME__ and __DATE__ are also\n recognized and expand to their respective equivalent.

\n
\n
\n

LANGUAGE SUPPORT

\n

Language, version and characteristics can be bound to all resource\n types that have inline data, such as RCDATA. This is an extension to\n Microsoft's resource compiler, which lacks this support completely. Only\n VERSIONINFO cannot have version and characteristics attached, but languages\n are propagated properly if you declare it correctly before the VERSIONINFO\n resource starts.

\n

Example:

\n
1 RCDATA DISCARDABLE\nLANGUAGE 1, 0\nVERSION 312\nCHARACTERISTICS 876\n{\n\t1, 2, 3, 4, 5, \"and whatever more data you want\"\n\t'00 01 02 03 04 05 06 07 08'\n}
\n
\n
\n

AUTHORS

\n

wrc was written by Bertho A. Stultiens and is a nearly\n complete rewrite of the first wine resource compiler (1994) by Martin von\n Loewis. Additional resource types were contributed by Ulrich Czekalla and\n Albert den Haan. Many cleanups by Dimitrie O. Paun in 2002-2003. Bugfixes\n have been contributed by many Wine developers.

أخطاء

- المعالج المسبق يتعرف على وحدات الماكرو ذات الوسائط المتغيرة، ولكنه لا يوسعها بشكل صحيح.
- يجب أن يكون الإبلاغ عن الأخطاء أكثر دقة، حيث أن رقم العمود والسطر المبلغ عنه حاليًا هما لأقرب رمز.
- يجب أن تختلف خيارات الذاكرة الافتراضية بين win16 و win32.

لا يوجد دعم لـ:
- RT_DLGINCLUDE، RT_VXD، RT_PLUGPLAY و RT_HTML (تنسيق غير معروف)
- وحدة التحكم PUSHBOX غير مدعومة بسبب نقص الوظائف الأصلية.

يتم تحليل الخطوط وإنشاؤها، ولكن لا يوجد دعم لإنشاء FONTDIR حتى الآن. يجب على المستخدم توفير مورد FONTDIR في المصدر لمطابقة موارد FONT.

يمكن الإبلاغ عن الأخطاء على متتبع أخطاء Wine.
