waybar-image(5)

الحزمة: waybar

التراخيص: MIT

waybar-image(5) دليل تنسيقات الملفات waybar-image(5)

الاسم

waybar - وحدة الصورة

الوصف

تعرض وحدة image صورة من مسار.

الإعداد

path:
النوع: string
المسار إلى الصورة.

exec:
النوع: string
المسار إلى النص البرمجي، والذي يجب أن يعيد مسار ملف الصورة.
سيتم تنفيذه فقط إذا لم يتم تعيين المسار

size:
النوع: integer
عرض/ارتفاع عرض الصورة.

interval:
النوع: integer
الفاصل الزمني (بالثواني) لإعادة عرض الصورة.
هذا مفيد إذا تغير محتويات path.
إذا لم يتم تحديد interval، فسيتم عرض الصورة مرة واحدة فقط.

signal:
النوع: integer
رقم الإشارة المستخدم لتحديث الوحدة.
يمكن استخدام هذا بدلاً من interval إذا تغير الملف بشكل غير منتظم.
الرقم صالح بين 1 و N، حيث SIGRTMIN+N = SIGRTMAX.

on-click:
النوع: string
الأمر الذي يتم تنفيذه عند النقر على الوحدة.

on-click-middle:
النوع: string
الأمر الذي يتم تنفيذه عند النقر بزر الماوس الأوسط على الوحدة.

on-update:
النوع: string
الأمر الذي يتم تنفيذه عند تحديث الوحدة.

on-scroll-up:
النوع: string
الأمر الذي يتم تنفيذه عند التمرير لأعلى على الوحدة.

on-scroll-down:
النوع: string
الأمر الذي يتم تنفيذه عند التمرير لأسفل على الوحدة.

smooth-scrolling-threshold:
النوع: double
عتبة الاستخدام عند التمرير.

tooltip:
النوع: bool
الافتراضي: true
خيار لتمكين التلميح عند التحويم.

expand:
النوع: bool
الافتراضي: false
يمكّن هذه الوحدة من استهلاك كل المساحة المتبقية ديناميكيًا.

مخرج النص البرمجي

على غرار وحدة custom، يتم فصل قيم الإخراج للنص البرمجي بـ سطر جديد. التنسيق التالي هو تنسيق الإخراج:

$path\n$tooltip

أمثلة

"image#album-art": {
	"path": "/tmp/mpd_art",
	"size": 32,
	"interval": 5,
	"on-click": "mpc toggle"
}
