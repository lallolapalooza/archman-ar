WWW__Mechanize__Link(3pm)

الحزمة: perl-www-mechanize

التراخيص: GPL, PerlArtistic

WWW::Mechanize::Link(3) توثيق Perl مقدم من المستخدم WWW::Mechanize::Link(3)

الاسم

WWW::Mechanize::Link - كائن رابط لـ WWW::Mechanize

الإصدار

الإصدار 2.20

المُلَخَّص

كائن رابط لتغليف كل الأشياء التي تحتاجها Mech ولكن لا يريد أحد التعامل معها كمصفوفة.

المُنشِئ

new()

my $link = WWW::Mechanize::Link->new( {
    url  => $url,
    text => $text,
    name => $name,
    tag  => $tag,
    base => $base,
    attr => $attr_href,
} );

للتوافق، يتم دعم الواجهة الأقدم هذه أيضًا:

new( $url, $text, $name, $tag, $base, $attr_href )

ينشئ ويعيد كائن "WWW::Mechanize::Link" جديد.

المُوصِلات

$link->url()

عنوان URL من الرابط

$link->text()

نص الرابط

$link->name()

السمة NAME من الوسم المصدر، إن وجدت.

$link->tag()

اسم الوسم (واحد من: "a", "area", "frame", "iframe" أو "meta").

$link->base()

عنوان URL الأساسي الذي تكون الروابط نسبية له.

$link->attrs()

يعيد مرجع هاش لجميع السمات وقيم السمات في الوسم.

$link->URI()

يعيد عنوان URL ككائن URI::URL.

$link->url_abs()

يعيد كائن URI::URL للشكل المطلق للسلسلة.
