waybar-sway-language(5)

الحزمة: waybar

التراخيص: MIT

waybar-sway-language(5) دليل تنسيقات الملفات waybar-sway-language(5)

الاسم

waybar - وحدة لغة sway

الوصف

تعرض وحدة language تخطيط لوحة المفاتيح الحالي في Sway

الإعداد

يتم تناولها بواسطة sway/language

format:
نوع: string
الافتراضي: {}
التنسيق، كيف يجب عرض التخطيط.

hide-single-layout:
نوع: bool
الافتراضي: false
يحدد رؤية الوحدة إذا تم تكوين تخطيط واحد

tooltip-format:
نوع: string
الافتراضي: {}
التنسيق، كيف يجب عرض التخطيط في التلميح.

tooltip:
نوع: bool
الافتراضي: true
خيار لتعطيل التلميح عند المرور فوقه.

menu:
نوع: string
الإجراء الذي يظهر القائمة.

menu-file:
نوع: string
موقع ملف واصف القائمة. يجب أن يكون هناك عنصر من نوع

GtkMenu بالمعرف menu

menu-actions:
نوع: array
الإجراءات المقابلة لأزرار القائمة.

expand:
نوع: bool
الافتراضي: false
يمكّن هذه الوحدة من استهلاك كل المساحة المتبقية ديناميكيًا.

استبدالات التنسيق

{short}: الاسم المختصر للتخطيط (مثل "us"). يساوي {}.

{shortDescription}: وصف مختصر للتخطيط (مثل "en").

{long}: الاسم الطويل للتخطيط (مثل "English (Dvorak)").

{variant}: متغير التخطيط (مثل "dvorak").

{flag}: علم البلد للتخطيط.

أمثلة

"sway/language": {
	"format": "{}",
},
"sway/language": {
	"format": "{short} {variant}",
}
