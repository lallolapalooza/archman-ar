NAME

QwtPolarRenderer - Render polar plots

SYNOPSIS

#include <qwt_polar_renderer.h>

QwtPolarRenderer : QObject

Detailed Description

This class can be used to render polar plots on different targets. The target can be a QPaintDevice like a QWidget or a QPrinter. The plot can be rendered on the screen or sent to a printer.

The plot is rendered into a bounding box, that is calculated from the plot's dimensions and an optional margin.

The rendering can be configured with different options:

  • QwtPolarRenderer::PaintAttribute - Options like antialiasing or text rendering.
