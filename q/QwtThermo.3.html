وصف تفصيلي

أداة الثرمومتر.

QwtThermo هي أداة تعرض قيمة ضمن نطاق. تدعم:

  • تخطيط أفقي أو رأسي؛
  • نطاق؛
  • مقياس؛
  • مستوى إنذار.

قد يتم حساب ألوان الملء من خريطة ألوان اختيارية. إذا لم يتم تعيين خريطة ألوان، تستخدم QwtThermo الألوان/الفرش التالية من لوحة الأدوات:

  • QPalette::Base خلفية الأنبوب
  • QPalette::ButtonText فرشاة الملء تحت مستوى الإنذار
  • QPalette::Highlight فرشاة الملء للقيم فوق مستوى الإنذار
  • QPalette::WindowText لمحور المقياس
  • QPalette::Text لتسميات المقياس

Detailed Description

A thermometer widget that visualizes a value. The thermometer consists of a pipe, which is filled according to the current value.

The thermometer's scale can be aligned to the left/right or top/bottom.

The fill color can be set using setFillBrush() or setColorMap().

If a QwtColorMap is used the alarm threshold has no effect.

The alarm threshold can be set using rmLevel().

The borders of the pipe and the pipe itself can be configured with setBorderWidth(), setPipeWidth().

The orientation can be changed with setOrientation().

The origin of the scale can be adjusted with setOrigin() and setOriginMode().

Member Enumeration Documentation

enum QwtThermo::OriginMode

Possible values for the origin mode.

OriginBottom
The origin is at the bottom (for vertical orientation) or left (for horizontal orientation).
OriginTop
The origin is at the top (for vertical orientation) or right (for horizontal orientation).
OriginCustom
The origin is set by setOrigin().

enum QwtThermo::ScalePosition

Possible positions for the scale.

LeftAxis
Scale is on the left (for vertical orientation) or bottom (for horizontal orientation).
RightAxis
Scale is on the right (for vertical orientation) or top (for horizontal orientation).
