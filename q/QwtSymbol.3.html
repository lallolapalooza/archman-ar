void QwtSymbol::setPath (const QPainterPath & path)

تعيين مسار فرشاة كرمز. يتم تمثيل الرمز بواسطة مسار فرشاة، حيث يتم رسم أصل نظام إحداثيات المسار (0، 0) إلى موضع الرمز.

عندما يكون للرمز حجم صالح، يتم تغيير حجم مسار الفرشاة ليناسب البعد. خلاف ذلك، يعتمد حجم الرمز على مربع الإحاطة للمسار.

مثال

يعرّف الكود التالي رمزًا يرسم سهمًا:
#include <qwt_symbol.h>
     QwtSymbol *symbol = new QwtSymbol();
     QPen pen( Qt::black, 2 );
     pen.setJoinStyle( Qt::MiterJoin );
     symbol->setPen( pen );
     symbol->setBrush( Qt::red );
     QPainterPath path;
     path.moveTo( 0, 8 );
     path.lineTo( 0, 5 );
     path.lineTo( -3, 5 );
     path.lineTo( 0, 0 );
     path.lineTo( 3, 5 );
     path.lineTo( 0, 5 );
     QTransform transform;
     transform.rotate( -30.0 );
     path = transform.map( path );
     symbol->setPath( path );
     symbol->setPinPoint( QPointF( 0.0, 0.0 ) );
     setSize( 10, 14 );

Detailed Description

This class is an abstract base class for geometric symbols, which can be used to render the data points of a plot item. See the Qt Documentation for details.

Member Enumeration Documentation

enum Style

The following symbols are available:

  • NoSymbol: No symbol is drawn.
  • Ellipse: An ellipse is drawn.
  • Rect: A rectangle is drawn.
  • Diamond: A diamond is drawn.
  • Triangle: A triangle is drawn.
  • Square: A square is drawn.
  • Cross: A cross is drawn.
  • XCross: An X-shaped cross is drawn.
  • HLine: A horizontal line is drawn.
  • VLine: A vertical line is drawn.
  • Star1, Star2, Star3, Star4, Star5: Different star shapes.
  • UserSymbol: User-defined symbol.
