Detailed Description

A dial widget is a circular slider widget. It is a subclass of QwtAbstractSlider and provides a dial widget with a scale and optionally a needle.

The dial can be used to select a value within a given range. The range can be set using scaleDraw()->setRange().

The dial has a needle, which indicates the current value. The needle can be of different styles, see QwtDialNeedle. The style can be changed using setNeedle().

The scale can be rotated or the needle can be rotated. The mode can be changed using setMode().

The arc of the scale can be changed using setScaleArc().
