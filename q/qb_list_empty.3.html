qb_list_empty(3)

الحزمة: libqb

التراخيص: LGPL-2.1-or-later

QB_LIST_EMPTY(3) دليل مبرمج libqb QB_LIST_EMPTY(3)

الاسم

qb_list_empty - اختبار سريع لمعرفة ما إذا كانت القائمة فارغة (تشير إلى نفسها).

الملخص

#include <qb/qblist.h>

static int32_t qb_list_empty(
    const struct qb_list_head   *head   /* مؤشر إلى رأس القائمة */
);
