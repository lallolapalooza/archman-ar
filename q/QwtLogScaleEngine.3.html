الاسم

QwtLogScaleEngine — محرك مقياس لوغاريتمي لـ Qwt.

الملخص

#include <qwt_log_scale_engine.h>

class QwtLogScaleEngine : public QwtLinearScaleEngine
{
public:
    explicit QwtLogScaleEngine(double log = 10.0);
    virtual ~QwtLogScaleEngine();

    virtual QwtScaleDiv divideScale(
        double lowerBound, double upperBound,
        int maxMajor, int maxMinor, double stepSize = 0.0 ) const override;

    double logBase() const;
    void setLogBase( double base );

private:
    void setLog10( double base );

    double m_log;
};

وصف مفصل

محرك مقياس لوغاريتمي. يقوم بتوسيع QwtLinearScaleEngine لتقديم مقياس لوغاريتمي.

يتم تحديد أساس اللوغاريتم بواسطة logBase.

تتيح divideScale تحديد كيفية تقسيم المقياس. في حالة المقياس اللوغاريتمي، فإنها تنتج حدوداً رئيسية وثانوية بناءً على الأساس المحدد.

توثيق دوال الأعضاء

divideScale

virtual QwtScaleDiv divideScale(
            double lowerBound, double upperBound,
            int maxMajor, int maxMinor, double stepSize = 0.0 ) const override;

تقسيم المقياس بين lowerBound و upperBound.

maxMajor هو الحد الأقصى لعدد العلامات الرئيسية.

maxMinor هو الحد الأقصى لعدد العلامات الثانوية بين علامتين رئيسيتين.

stepSize هو حجم خطوة محدد مسبقًا، إذا كان 0.0، يتم اختياره تلقائيًا.

تُرجع QwtScaleDiv الذي يحدد حدود المقياس الرئيسية والثانوية.
