وصف تفصيلي

عنصر واجهة المستخدم للعداد.

يحتوي العداد على تسمية تعرض رقمًا وزرًا أو زرين (بحد أقصى ثلاثة) على كل جانب من التسمية يمكن استخدامهما لزيادة أو تقليل قيمة العداد.

يتم تحديد نطاق العداد بواسطة قيمة دنيا وقيمة قصوى، وحجم خطوة. عندما يتم تعيين خاصية الالتفاف، يكون العداد دائريًا.

يمكن تحديد عدد الخطوات التي يزيد أو ينقص بها الزر قيمة العداد باستخدام setIncSteps(). يمكن تغيير عدد الأزرار باستخدام setNumButtons().

مثال:

#include <qwt_counter.h>
  QwtCounter *counter = new QwtCounter(parent);
  counter->setRange(0.0, 100.0);                  // من 0.0 إلى 100
  counter->setSingleStep( 1.0 );                  // حجم الخطوة 1.0
  counter->setNumButtons(2);                      // زرين لكل جانب
  counter->setIncSteps(QwtCounter::Button1, 1);   // الزر 1 يزيد خطوة واحدة
  counter->setIncSteps(QwtCounter::Button2, 20);  // الزر 2 يزيد 20 خطوة
  connect(counter, SIGNAL(valueChanged(double)), myClass, SLOT(newValue(double)));}

Detailed Description

Counter widget. The counter provides a graphical slider, which can be adjusted by mouse clicks or by using the wheel.

The counter is a child class of QwtAbstractSlider. The implementation is straight forward, but it might be useful to know the differences to the base class:

  • stepType controls, if the slider is adjusted by clicking on the slider frame (Stepper) or by moving a knob (Knob).

  • In Knob mode the knob can have different dimensions, than the slider. The knob is implemented as a widget, its size hints are calculated from the dimensions of the base slider.

  • The Layout controls the appearance of the counter.

  • The appearance of the arrow buttons can be controlled by setIncButton() and setDecButton().

  • When hexMode is enabled, the counter displays values in hexadecimal format.

  • When leadingZero is enabled, the counter displays leading zeros.
