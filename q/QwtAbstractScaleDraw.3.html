فئة أساسية مجردة لرسم المقاييس.

يمكن استخدام QwtAbstractScaleDraw لرسم مقاييس خطية أو لوغاريتمية.

بعد تحديد قسم المقياس ككائن QwtScaleDiv باستخدام setScaleDiv()، يمكن رسم المقياس باستخدام الدالة العضو draw().

QwtAbstractScaleDraw::setTicks - Qwt User's Guide

NAME

setTicks - Set ticks of a scale.

SYNOPSIS

            void setTicks(const std::map<double, 
            int> & ticks);

DESCRIPTION

Set the major ticks of the scale. The map associates the tick value with its tick length. The tick length is a value between 0 and 1. For example, 1.0 means that the tick has the same length as the axis. A value of 0.0 means that the tick is not visible.

The tick values are sorted internally. Ticks with values that are not in the interval [minScaleMax, maxScaleMax] (see scaleMaxMajor) are ignored.

The default ticks are returned by ticks().
