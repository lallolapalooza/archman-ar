الاسم

qb_timespec_add_ms - إضافة ملي ثانية إلى timespec.

الملخص

#include <qb/qbutil.h>

void qb_timespec_add_ms(
    struct timespec   *ts,  /* الـ ts المراد الإضافة إليه */
    int32_t            ms   /* مقدار الملي ثانية لزيادة ts */
);

المعلمات
