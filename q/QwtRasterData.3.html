وصف مفصل

QwtRasterData يحدد واجهة لأي نوع من بيانات الرسم النقطي.

QwtRasterData هي واجهة مجردة، تستخدمها QwtPlotRasterItem للعثور على القيم عند بكسلات رسمها النقطي.

يمكن الإشارة إلى الفجوات داخل المستطيل المحيط بالبيانات بقيم NaN (عند تعطيل WithoutGaps).

غالبًا ما يتم استخدام عنصر الرسم النقطي لعرض القيم من مصفوفة. بعد ذلك، تحتاج فئة بيانات الرسم النقطي المشتقة إلى تنفيذ نوع من إعادة التشكيل (resampling) تقوم بتعيين الرسم النقطي للمصفوفة إلى الرسم النقطي المطلوب لعنصر الرسم النقطي (اعتمادًا على دقة ومقاييس اللوحة).

QwtMatrixRasterData تنفذ بيانات الرسم النقطي التي تعيد قيمًا من مصفوفة ثنائية الأبعاد معينة.

Detailed Description

This class is the base class for all raster data classes. It provides an interface for accessing the data of a raster plot.

The data is organized in a grid of values. The interface allows to get the value at a specific coordinate (x, y) and to get information about the grid resolution.

The interface offers a way to specify attributes that might influence the rendering of the raster data. For example, the Attribute::CoolingHatching attribute can be set to indicate that the raster data represents cooling hatching, which might be rendered differently.

To render a raster plot the following steps are typically performed:

  1. The rendering device (e.g. a QPainter) reports the resolution it wants to render in by calling pixelHint.
  2. The QwtRasterData implementation can return a hint about the preferred resolution for rendering its data. An empty rectangle indicates that the data doesn't have a preferred resolution and can be rendered at the device's resolution.
  3. The rendering loop iterates through the pixels of the target rectangle. For each pixel the corresponding plot coordinates (x, y) are calculated.
  4. The value at (x, y) is retrieved using the value function.
  5. The value is mapped to a color and the pixel is painted.

Limiting the resolution of the image might significantly improve the performance and heavily reduce the amount of memory when rendering a QImage from the raster data.

pixelHint

pixelHint returns the geometry of a pixel, that can be used to calculate the resolution and alignment of the plot item, that is representing the data.

Width and height of the hint need to be the horizontal and vertical distances between 2 neighbored points. The center of the hint has to be the position of any point ( it doesn't matter which one ).

An empty hint indicates, that there are values for any detail level.

Limiting the resolution of the image might significantly improve the performance and heavily reduce the amount of memory when rendering a QImage from the raster data.

The default implementation returns an empty rectangle recommending to render in target device ( f.e. screen ) resolution.

area In most implementations the resolution of the data doesn't depend on the requested area.
