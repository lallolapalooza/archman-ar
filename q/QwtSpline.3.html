وصف تفصيلي

الفئة الأساسية لجميع الأشرطة المنحنية.

الشريط المنحني هو منحنى ممثل بسلسلة من كثيرات الحدود. تقريب الشريط هو عملية إيجاد كثيرات الحدود لمجموعة معينة من النقاط. عندما يحتفظ الخوارزمي بالنقاط الأولية، تسمى الاستكمال.

يمكن تصنيف الأشرطة المنحنية وفقًا لشروط كثيرات الحدود التي يتم تحقيقها عند نقاط البداية والنهاية للأجزاء:

•
الاستمرارية الهندسية
•
G0: تتصل كثيرات الحدود
•
G1: المشتقات الأولى متناسبة عند نقطة الاتصال
•
G2: المشتقات الأولى والثانية متناسبة عند نقطة الاتصال
•
الاستمرارية البارامترية
•
C0: تتصل المنحنيات
•
C1: المشتقات الأولى متساوية
•
C2: المشتقات الأولى والثانية متساوية

تتطلب الاستمرارية الهندسية أن تكون الهندسة مستمرة، بينما تتطلب الاستمرارية البارامترية أن تكون البارامترية الأساسية مستمرة. الاستمرارية البارامترية من الرتبة n تتضمن الاستمرارية الهندسية من الرتبة n، ولكن ليس العكس.

QwtSpline هي الفئة الأساسية لتقريبات الشريط من أي استمرارية.

Detailed Description

abstract base class for spline interpolations

The spline interpolation approximates a polygon (or a set of points) by piecewise polynomial functions. The interface of QwtSpline defines the common interface for all spline types.

The goal of a spline interpolation is to create a smooth curve, that passes through a given set of control points.

The interpolation algorithms usually need information about the boundary conditions ( tangent and/or value ) at the start and end point of the curve. The most common conditions are natural, clamped and parabolic.

The boundary conditions are defined by the enum BoundaryCondition.

The boundary types are defined by the enum BoundaryType.

A list of available spline implementations:

QwtSplineBasis
Basis splines (B-splines) are a generalization of Bézier curves.
QwtSplineC1
C1 spline interpolation.
QwtSplineC2
C2 spline interpolation.
QwtSplineCubic
Cubic spline interpolation.
QwtSplineInterpolating
Spline interpolation that interpolates the given points.
QwtSplineLocal
Spline interpolation that calculates the polynomials using a local algorithm.
QwtSplinePleasing
Spline interpolation that tries to find a pleasing shape of the curve.

uint QwtSpline::locality () const [virtual]

The locality of an spline interpolation identifies how many adjacent polynomials are affected, when changing the position of one point.

A locality of 'n' means, that changing the coordinates of a point has an effect on 'n' leading and 'n' following polynomials. Those polynomials can be calculated from a local subpolygon.

A value of 0 means, that the interpolation is not local and any modification of the polygon requires to recalculate all polynomials ( f.e cubic splines ).

Returns

Order of locality

Reimplemented in QwtSplinePleasing, QwtSplineLocal, QwtSplineCubic, and QwtSplineBasis.

NAME

QwtSpline - A base class for splines.

SYNOPSIS

#include <qwt_spline.h>

class QwtSpline: public QwtObject
{
public:
    enum
    {
        -- DefaultSpline = 0,
        -- MonoPoint = 1,
        -- Vector = 2,
        -- Bezier = 3,
        -- Cubic = 4,
        -- Composite = 5,
        -- MaxType = 6
    };

    enum
    {
        -- NoBoundary = 0,
        -- LeftBoundary = 1,
        -- RightBoundary = 2,
        -- BothBoundary = 3
    };

    QwtSpline( int type = DefaultSpline );
    virtual ~QwtSpline();

    void setPaintAttribute( PaintAttribute attribute, bool on = true );
    bool testPaintAttribute( PaintAttribute attribute ) const;

    virtual void setPoints( const QPointF *points, int size );
    virtual void setPoints( const QPolygonF &polygon );
    const QPolygonF &points() const;

    virtual void setBoundaryValue( Boundary edge, double value );
    double boundaryValue( Boundary edge ) const;

    virtual void setNodeValue( double value );
    double nodeValue() const;

    virtual QwtSpline *clone() const = 0;

    virtual void setSplineSize( int size );
    int splineSize() const;

    virtual void setSplineItem( const QwtSpline *spline );
    const QwtSpline *splineItem() const;

    virtual void setPen( const QPen &pen );
    QPen pen() const;

    virtual void setBrush( const QBrush &brush );
    QBrush brush() const;

    virtual void draw( QPainter *painter, const QPointF *points, int size ) const;
    virtual void draw( QPainter *painter, const QPolygonF &polygon ) const;

    static QwtSpline *createSpline( int type );

protected:
    void init();

private:
    void operator=( const QwtSpline & );
};

DESCRIPTION

This class is the base class for all splines in Qwt.

A spline is a piecewise polynomial function defined by a sequence of points. Splines are often used for curve fitting and interpolation.

QwtSpline is an abstract base class. You should use one of the concrete spline implementations provided by Qwt, such as QwtLinearSpline, QwtSplineFitter, QwtBezierSpline, etc.
