qb_atomic_int_add(3)

الحزمة: libqb

التراخيص: LGPL-2.1-or-later

QB_ATOMIC_INT_ADD(3) دليل مبرمج libqb QB_ATOMIC_INT_ADD(3)

الاسم

qb_atomic_int_add - يضيف قيمة بشكل ذري إلى العدد الصحيح المشار إليه بواسطة atomic.

ملخص

#include <qb/qbatomic.h>

void qb_atomic_int_add(
    volatile int32_t QB_GNUC_MAY_ALIAS   *atomic,  /* مؤشر إلى عدد صحيح */
    int32_t                               val      /* القيمة المراد إضافتها إلى *atomic */
);

المعاملات

atomic مؤشر إلى عدد صحيح

val القيمة المراد إضافتها إلى *atomic
