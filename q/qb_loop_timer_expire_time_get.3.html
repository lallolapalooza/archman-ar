qb_loop_timer_expire_time_get(3)

الحزمة: libqb

التراخيص: LGPL-2.1-or-later

QB_LOOP_TIMER_EXPIRE_TIME_GET(3) دليل مبرمج libqb QB_LOOP_TIMER_EXPIRE_TIME_GET(3)

الاسم

qb_loop_timer_expire_time_get - الحصول على وقت انتهاء صلاحية المؤقت، كما تم تعيينه عند إنشاء المؤقت.

الملخص

#include <qb/qbloop.h>

uint64_t qb_loop_timer_expire_time_get(
    struct qb_loop       *l,   /* مؤشر إلى نسخة الحلقة */
    qb_loop_timer_handle  th   /* مقبض المؤقت. */
);

المعاملات

l مؤشر إلى نسخة الحلقة

th مقبض المؤقت.

الوصف

قيمة الإرجاع

نانوثوانٍ سينتهي فيها صلاحية المؤقت

ملاحظة

إذا كان المؤقت قد انتهت صلاحيته بالفعل، فسيعيد 0
