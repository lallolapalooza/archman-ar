Detailed Description

Polar item with scale information. This is the base class for all items that need polar scale information, like QwtPolarGrid, QwtPolarSpectrogram, etc.

The items are organized in a tree, where each item can have a title and children. The title is visible in the legend. The z-value determines the painting order, the lower the value, the earlier the item is painted. All items are painted in increasing z-order.

The class offers an interface for setting and getting the polar axes scale information.

Member Enumeration Documentation

enum QwtPolarItem::ItemAttribute

Item Attributes

Rtti
If this attribute is enabled, the item will be identified by its run-time type information. This is useful to distinguish different item types in a plot.
AutoScale
When this attribute is enabled, the item calculates its bounding circle. This information is used by QwtPolarPlot::autoScale(), to adjust the scale of the plot.
Legend
When this attribute is enabled, the item will be shown in the plot's legend. The legend item will be the item's title.
