STDOUT

When the -Q option is specified without the -f option, the qstat utility shall display the following items for each successfully processed operand:

*
The queue name
*
The number of batch jobs in that state in the batch queue
*
The name of the state
*
The type of batch queue (execution or routing)
*
Additional implementation-defined information, if any, about the batch queue

If the operands presented to the qstat utility are batch server names, the -B option is specified, and the -f option is not specified, the qstat utility shall display the following items on a single line, in the stated order, with white space between each item, for each successfully processed operand:

*
The batch server name
*
The maximum number of batch jobs that shall be run in the batch queue concurrently
*
The total number of batch jobs managed by the batch server
*
The status of the batch server
*
For each state, the number of batch jobs in that state and the name of the state

If the operands presented to the qstat utility are server names, the -B option is specified, and the -f option is specified, the qstat utility shall display the following items for each successfully processed operand:

*
The server name
*
The maximum number of batch jobs that shall be run in the batch queue concurrently
*
The total number of batch jobs managed by the server
*
The status of the server
*
For each state, the number of batch jobs in that state and the name of the state
*
Additional implementation-defined information, if any, about the server

CONSEQUENCES OF ERRORS

بالإضافة إلى السلوك الافتراضي، لا يُطلب من أداة qstat كتابة رسالة تشخيصية إلى الخطأ القياسي عندما يشير رد الخطأ المستلم من خادم الدُفعات إلى أن معرف_المهمة الخاص بالدُفعات غير موجود على الخادم. سواء انتظر qstat لإخراج الرسالة التشخيصية أثناء محاولة تحديد موقع مهمة الدُفعات على خوادم أخرى أم لا ، فهو معرف للتنفيذ.

الأقسام التالية إعلامية.

RATIONALE

تسمح أداة qstat للمستخدمين بعرض حالة المهام وإدراج مهام الدُفعات في قوائم الانتظار.

قد تكون معاملات أداة qstat إما معرفات مهام أو قوائم انتظار (محددة كمعرفات وجهة) أو أسماء خوادم دفعات. تشير خيارات -Q و -B، أو غيابها، إلى طبيعة المعاملات.

تسمح الخيارات الأخرى لأداة qstat للمستخدم بالتحكم في كمية المعلومات المعروضة والشكل الذي يتم عرضه به. إذا أراد المستخدم عرض حالة مجموعة من المهام التي تطابق معايير الاختيار، فيمكن استخدام أداة qselect للحصول على مثل هذه القائمة.

يسمح الخيار -f للمستخدمين بطلب عرض "كامل" بتنسيق معرف للتنفيذ.

تاريخيًا، كانت أداة qstat جزءًا من NQS ومشتقاتها، الممارسة الحالية التي تستند إليها.

FUTURE DIRECTIONS

قد تتم إزالة أداة qstat في إصدار مستقبلي.
