NAME

QwtMagnifier - Base class for magnifying events.

SYNOPSIS

#include <qwt_magnifier.h>

class QwtMagnifier : public QObject
{
public:
    explicit QwtMagnifier( QWidget * canvas );
    virtual ~QwtMagnifier();

    void setCanvas( QWidget * canvas );
    QWidget *canvas() const;

    void setMouseButton( Qt::MouseButton button, Qt::KeyboardModifier modifier
        = Qt::NoModifier );
    void setMousePattern( Qt::MouseButton button, Qt::KeyboardModifier modifier
        = Qt::NoModifier );
    Qt::MouseButton button() const;
    Qt::KeyboardModifier keyPattern() const;

    void setAxis( int axis );
    int axis() const;

    void setZoomFactor( double factor );
    double zoomFactor() const;

    void setMagnifier( double factor );
    double magnifier() const;

    virtual void widgetEvent( QEvent * );
    virtual bool eventFilter( QObject *, QEvent * );
};

Detailed Description

This class is the base class for all magnifying and zooming mechanisms of QwtPlot.

QwtMagnifier provides basic functionality for magnifying and zooming of a target widget. The magnification is triggered by a mouse button click combination (see setMouseButton()). The direction of zooming depends on the mouse movements.

The target widget is a QwtPlotItem or any other widget that can be scrolled and zoomed using Qwt. The default is to zoom the plot itself.

The class zooms the axes of the plot specified by QwtMagnifier::setAxis(). If the axis is invalid, all axes will be zoomed.

The zoom factor is controlled by QwtMagnifier::setZoomFactor().

The magnification factor is controlled by QwtMagnifier::setMagnifier().

The magnification can be disabled/enabled using QwtPlot::setEnabled().

Note: QwtMagnifier is an abstract class. You need to derive from it and implement the pure virtual function(s) to get a working magnifier.

The derived classes are:

  • QwtPlotMagnifier
  • QwtPlotZoomer
