qb_rb_create_from_file(3)

الحزمة: libqb

التراخيص: LGPL-2.1-or-later

QB_RB_CREATE_FROM_FILE(3) دليل مبرمج libqb QB_RB_CREATE_FROM_FILE(3)

الاسم

qb_rb_create_from_file - تحميل المخزن المؤقت الدائري المحفوظ من ملف إلى الذاكرة المؤقتة.

الملخص

#include <qb/qbrb.h>

qb_ringbuffer_t * qb_rb_create_from_file(
    int32_t   fd,     /* ملف يحتوي على بيانات المخزن المؤقت الدائري المحفوظ. */
    uint32_t  flags   /* نفس الأعلام التي تم تمريرها إلى qb_rb_open()*/
);

المعلمات

fd ملف يحتوي على بيانات المخزن المؤقت الدائري المحفوظ.

flags نفس الأعلام التي تم تمريرها إلى qb_rb_open()
