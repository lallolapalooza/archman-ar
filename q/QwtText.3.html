وصف تفصيلي

فئة تمثل نصًا.

QwtText هو نص يتضمن مجموعة من السمات حول كيفية عرضه.

  • التنسيق
    قد يتضمن النص تسلسلات تحكم (مثل علامات) تصف كيفية عرضه. كل تنسيق (مثل MathML، TeX، Qt Rich Text) له مجموعته الخاصة من تسلسلات التحكم، والتي يمكن معالجتها بواسطة QwtTextEngine خاص لهذا التنسيق.
  • الخلفية
    قد يكون للنص خلفية، محددة بواسطة QPen و QBrush لتحسين رؤيتها. قد تكون زوايا الخلفية مستديرة.
  • الخط
    قد يكون للنص خط فردي.
  • اللون
    قد يكون للنص لون فردي.
  • علامات العرض
    علامات من Qt::AlignmentFlag و Qt::TextFlag تستخدم كما في QPainter::drawText().

Qwt Text Class

The QwtText class represents a text with a font, color, background and border. It can be rendered by a QwtTextEngine for different text formats.

The text can contain attributes like font, color, or alignment. These attributes can be specified directly using setFont(), setColor() and setRenderFlags(), or embedded within the text string using control sequences.

The exact interpretation of the text string and its attributes depends on the installed QwtTextEngine.

Public Types

LayoutAttribute
Layout attributes can be used to influence the layout of the text. Possible values are:
NoLayoutMetric
No special layout metric.
MinimumLayoutMetric
The layout metric is the minimum possible value.
CoreCharacterLayoutMetric
The layout metric is the core character. This is the default setting.
TrailingCharacterLayoutMetric
The layout metric is the trailing character.
WordBoundaryLayoutMetric
The layout metric is the word boundary.
UTF8LayoutMetric
The layout metric is the UTF-8 sequence.
TextPaintAttribute
Paint attributes can be used to control how the text is painted. Possible values are:
PaintAttribute
Abstract base class for paint attributes.
PaintAttribute_Mask
Mask for paint attributes.
TextExpandTabs
Expand tabs to spaces. This is the default setting.
TextShowSpecialCharacters
Show special characters like newlines. This is the default setting.
TextPaintBackground
Paint background. This is the default setting.
TextPaintBorder
Paint border. This is the default setting.
TextDecoration
Paint text decoration (underline, overline, strikethrough). This is the default setting.
TextTransform
Transform text (e.g. uppercase, lowercase). This is the default setting.
TextSingleLine
Text is rendered in a single line. By default tabs and newlines are treated as spaces. Setting this attribute disables this behavior.
TextUseUTF8
The text is treated as UTF-8 encoded. This is the default setting.
TextFromInputString
The text is interpreted as a plain text string without any control sequences.
TextStyledEscapes
The text string contains Qt style font and color escapes. Example: "<font>red</font>"
TextRichText
The text string contains Rich Text Formatting. Example: "<b>bold</b>"
TextHtml
The text string contains HTML.
TextLatex
The text string contains LaTeX commands.
TextMathML
The text string contains MathML.
TextSVG
The text string contains SVG.
TextPlain
The text is plain text.
AutoText
The text format is detected automatically.
OtherFormat
User defined text formats starting from this value are not processed by Qwt.
TextFormat
The text format can be specified using the following values:
RenderFlag
Render flags can be used to control the alignment of the text. Possible values are:
AlignLeft
Align the text to the left.
AlignRight
Align the text to the right.
AlignHCenter
Align the text horizontally centered.
AlignTop
Align the text to the top.
AlignBottom
Align the text to the bottom.
AlignVCenter
Align the text vertically centered.
AlignCenter
Align the text centered.
WordWrap
Wrap the text at word boundaries.
AutoWordWrap
Automatically wrap the text at word boundaries.
SplitIntegers
Split integers at word boundaries.
SplitVectorElements
Split vector elements at word boundaries.
TextEngine
The text engine used to render the text.
NoTextEngine
No text engine is used. The text is rendered as plain text.
BasicTextEngine
The basic text engine used for plain text and HTML. It uses the QwtPainter.
MathTextEngine
A text engine that can render LaTeX and MathML. This engine is not implemented yet.
SvgTextEngine
A text engine that can render SVG. This engine is not implemented yet.
OtherTextEngine
User defined text engines starting from this value are not used by Qwt.

Detailed Description

Text class.

The QwtText class encapsulates text rendering capabilities. It supports different text formats like plain text, rich text (HTML subset) and MathML. The text can be rendered using different text engines.

The default text engine is QwtPlainTextEngine. If Qt's rich text support is enabled (QwtSymbol::qt_rich_text is true) you can use QwtHtmlTextEngine as well.

You can install your own text engines using setTextEngine.

The text can be decorated with attributes like antialiasing or a border radius.

enum QwtText::TextFormat

Text formats

AutoText
The text format is determined automatically from the text.
PlainText
Plain text. All formatting information is ignored.
RichText
Rich text (HTML subset)
MathML
MathML
SVG
SVG
UTF8
UTF8 encoded text.

enum QwtText::PaintAttribute

Paint attributes

PaintAttribute
RenderAntialiased
Enable/disable antialiasing for text rendering.
RoundRobin
Enable/disable round robin rendering. If enabled, the text is rendered on different positions on subsequent renderings. This is useful for avoiding aliasing artifacts when rendering text in rapidly changing plots.

enum QwtText::LayoutAttribute

Layout attributes

LayoutAttribute
MinimizeWidth
When enabled, the layout engine tries to minimize the width of the text bounding box. This can be useful for text labels that need to fit into a tight space.
MinimizeHeight
When enabled, the layout engine tries to minimize the height of the text bounding box.
