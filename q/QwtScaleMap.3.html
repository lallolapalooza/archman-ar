Detailed Description

This class implements a mapping between a scale interval and a paint device interval. The mapping can be linear or non-linear (using QwtTransform).

A QwtScaleMap can be used for the X and Y axes of a plot item. The plot item specifies the scale intervals (e.g. the range of the axis) and the paint device intervals (e.g. the pixel range of the axis). The map then translates between the two coordinate systems.

The transformation can be set using setTransformation(). If no transformation is specified, a linear transformation is used by default.

The intervals can be set using setScaleInterval() and setPaintInterval().

The static member functions transform() and invTransform() are utility functions to transform points and rectangles using two scale maps (one for X, one for Y).
