NAME

QwtAnalogClock - a clock widget

SYNOPSIS

#include <qwt_analog_clock.h>
class QwtAnalogClock : public QwtDial

DESCRIPTION

An analog clock widget is a QwtDial that displays the current time.

The clock can be configured to show the current date and/or time, the seconds hand, or to run in a different time zone. All of the clock's hands (hour, minute, second) can be controlled individually.

The clock's face can be decorated by paint functions, that can be enabled/disabled and configured by the user.
