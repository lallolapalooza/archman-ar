Mandoc puede ser utilizado para convertir archivos de texto plano en páginas del manual con formato. Esto puede ser útil para documentar scripts, programas o cualquier otra información que deba presentarse en un formato de página del manual.

Instalación

Puedes instalar mandoc desde los repositorios oficiales de Arch Linux: 

sudo pacman -S mandoc

Uso

Para convertir un archivo de texto en una página del manual, puedes usar el comando mdoc o man proporcionado por mandoc.

Ejemplo usando mdoc: 

mdoc tu_archivo.txt > tu_pagina.ms

Luego, puedes ver la página del manual usando mandoc: 

mandoc -T man tu_pagina.ms

Ejemplo usando man (para un formato más similar a las páginas del manual tradicionales): 

man -O tu_archivo.txt

Mandoc también se utiliza internamente en Arch Linux para generar y mostrar páginas del manual de los paquetes.

Mandoc

Mandoc هي مجموعة أدوات لإنشاء وعرض صفحات الدليل (manual pages). تم تصميمها لتكون بديلاً حديثًا وأكثر أمانًا لأدوات صفحات الدليل التقليدية.

يمكن استخدام Mandoc لتحويل الملفات النصية العادية إلى صفحات دليل منسقة. يمكن أن يكون هذا مفيدًا لتوثيق البرامج النصية (scripts) أو البرامج أو أي معلومات أخرى تحتاج إلى تقديمها بتنسيق صفحة الدليل.

التثبيت

يمكنك تثبيت mandoc من مستودعات Arch Linux الرسمية: 

sudo pacman -S mandoc

الاستخدام

لتحويل ملف نصي إلى صفحة دليل، يمكنك استخدام الأمر mdoc أو man الذي توفره mandoc.

مثال باستخدام mdoc: 

mdoc tu_archivo.txt > tu_pagina.ms

بعد ذلك، يمكنك عرض صفحة الدليل باستخدام mandoc: 

mandoc -T man tu_pagina.ms

مثال باستخدام man (لتنسيق مشابه لصفحات الدليل التقليدية): 

man -O tu_archivo.txt

يتم استخدام Mandoc أيضًا داخليًا في Arch Linux لتوليد وعرض صفحات الدليل للحزم.

تمت ترجمة هذه الصفحة وتكييفها باستخدام mandoc لتحويل الدلائل.
