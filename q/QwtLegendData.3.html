NAME

QwtLegendData - Represents legend item data.

SYNOPSIS

#include <qwt_legend_data.h>

Inherits QwtColumnData.

class QwtLegendData : public QwtColumnData

DESCRIPTION

This class represents legend item data. It is used to store the data associated with a legend item, such as the text, icon, and flags.

CONSTRUCTION

The constructor initializes an empty QwtLegendData object.

METHODS

The following methods are available:

  • const QwtText &text() const: Returns the text of the legend item.
  • const QIcon &icon() const: Returns the icon of the legend item.
  • int flags() const: Returns the flags of the legend item.
  • void setText(const QwtText &text): Sets the text of the legend item.
  • void setIcon(const QIcon &icon): Sets the icon of the legend item.
  • void setFlags(int flags): Sets the flags of the legend item.

NOTE

This class is part of the Qwt library. For more information, please refer to the Qwt documentation.

الاسم

QwtLegendData - يمثل بيانات عنصر وسيلة الإيضاح.

الملخص

#include <qwt_legend_data.h>

يرث من QwtColumnData.

class QwtLegendData : public QwtColumnData

الوصف

هذه الفئة تمثل بيانات عنصر وسيلة الإيضاح. تُستخدم لتخزين البيانات المرتبطة بعنصر وسيلة إيضاح، مثل النص والأيقونة والعلامات.

الإنشاء

يقوم المُنشئ بتهيئة كائن QwtLegendData فارغ.

الأساليب

الأساليب التالية متاحة:

  • const QwtText &text() const: يعيد نص عنصر وسيلة الإيضاح.
  • const QIcon &icon() const: يعيد أيقونة عنصر وسيلة الإيضاح.
  • int flags() const: يعيد علامات عنصر وسيلة الإيضاح.
  • void setText(const QwtText &text): يضبط نص عنصر وسيلة الإيضاح.
  • void setIcon(const QIcon &icon): يضبط أيقونة عنصر وسيلة الإيضاح.
  • void setFlags(int flags): يضبط علامات عنصر وسيلة الإيضاح.

ملاحظة
