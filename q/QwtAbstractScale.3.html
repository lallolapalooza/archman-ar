Detailed Description

Abstract base class for scales.

The scale is the central concept for all widgets that need to display values in a specific range. It defines the range (lower/upper bound) and can be consulted for tick and label information.

The most important methods are:

  • lowerBound, upperBound : Get the range of the scale.
  • setScale : Set the range of the scale.
  • invalidate : For implementations that cache scale divisions this method signals that the cache needs to be rebuilt.

invalidate is usually called when the scale range or its properties related to tick calculation (like QwtScaleWidget::setTickInterval()) are changed.

virtual void QwtAbstractScale::invalidate ( )
pure virtualprotected

Invalidate cached scale divisions.

When the scale range or its properties related to tick calculation are changed, the internal cache of scale divisions has to be invalidated. Derived classes need to implement this method to rebuild the cache.
