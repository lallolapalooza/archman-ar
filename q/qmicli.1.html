NAME

`mbimcli` — command line interface for MBIM modems

SYNOPSIS

mbimcli [OPTIONS...] [--client-cid=N] [COMMAND]

DESCRIPTION

The `mbimcli` utility provides a command line interface to control MBIM modems. It allows interacting with various modem functions like network registration, data sessions, location services, and more. The tool uses the QRTR protocol to communicate with the modem services.

The command is structured as follows:

  mbimcli [global options] --client-cid=N client-specific command [command options]

Global options apply to the tool itself, such as specifying the device path. The `--client-cid=N` option assigns a client identifier (CID) for the session, which is often required for specific commands. `client-specific command` denotes the primary service area you want to interact with (e.g., `loc`, `dms`, `qmi`). `command options` are specific to the chosen client command.

If no client CID is specified with `--client-cid`, `mbimcli` will allocate a new one automatically. Some commands, especially those that set up long-running states or require persistent connections, may require specific client CIDs to be managed. The `--client-no-release-cid` option can be used to prevent `mbimcli` from releasing the CID upon exit, which is useful when you intend to reuse the same CID in subsequent commands.

GLOBAL OPTIONS

-d, --device=[PATH|URI]
Specify device path or QRTR URI (e.g. qrtr://0)
-p, --device-open-proxy
Request to use the 'qmi-proxy' proxy
--client-cid=N
Client connection identifier to use. If not specified, a new one will be allocated and released automatically.
--client-no-release-cid
Do not release the client CID when the connection is closed.
--verbose
Enable verbose output
--version
Show version information and exit
--help
Show help message and exit

EXAMPLES

To get the NMEA types enabled on the location service:

  $ mbimcli --loc-get-nmea-types

To set the operation mode to MSA (Mobile Station Assisted):

  $ mbimcli --loc-set-operation-mode=msa

To get the current USB composition:

  $ mbimcli --gas-dms-get-usb-composition

To send an AT command and get the reply:

  $ mbimcli --atr-send="AT+CGMI"

To list all network interface links from the `wwan0` interface:

  $ mbimcli --link-list=wwan0

To get the WWAN interface name:

  $ mbimcli --get-wwan-iface

To get the service version information:

  $ mbimcli --get-service-version-info
