التحكم المتقدم (تعديل سلوك qpdf)

خيارات التحكم المتقدم تتحكم في سلوك qpdf بطرق لا يحتاجها المستخدم عادةً ولكنها قد تكون مفيدة للمطورين أو الأشخاص الذين يحققون في مشاكل مع ملفات معينة.

خيارات ذات صلة:

--password-is-hex-key -- توفير مفتاح تشفير مشفر بنظام الـ hex
توفير مفتاح تشفير الملف الأساسي كسلسلة مشفرة بنظام الـ hex بدلاً من توفير كلمة مرور. هذا خيار خبير.
--suppress-password-recovery -- عدم محاولة ترميزات كلمة المرور المختلفة
قم بقمع السلوك المعتاد لـ qpdf في محاولة ترميزات مختلفة لكلمة مرور تحتوي على أحرف Unicode غير ASCII إذا لم تنجح المحاولة الأولى.
--password-mode -- تعديل كيفية تشفير qpdf لكلمات المرور
--password-mode=mode

قم بضبط دقيق لكيفية تحكم qpdf في ترميز كلمات مرور Unicode. الخيارات الصالحة هي auto، bytes، hex-bytes، و unicode.

--suppress-recovery -- قمع استعادة الأخطاء
تجنب محاولة الاستعادة عند العثور على أخطاء في جدول المراجع المتقاطعة للملف أو أطوال التدفق.
--ignore-xref-streams -- استخدام جداول المراجع المتقاطعة بدلاً من التدفقات
تجاهل أي تدفقات مراجع متقاطعة في الملف، والعودة إلى جداول المراجع المتقاطعة أو تشغيل استعادة المستند.

التحويل (إجراء تغييرات هيكلية على ملف PDF)

الخيارات أدناه تخبر qpdf بتطبيق تحويلات تغير الهيكل دون تغيير المحتوى.

خيارات ذات صلة:

--linearize -- تحسين الإخراج للويب (linearize)
إنشاء ملفات إخراج محسّنة للويب (linearized).
--encrypt -- بدء خيارات التشفير
--encrypt [options] --

قم بتشغيل qpdf --help=encryption للحصول على التفاصيل.

--decrypt -- إزالة التشفير من ملف الإدخال
إنشاء ملف إخراج غير مشفر حتى لو كان ملف الإدخال مشفرًا. عادةً ما يحتفظ qpdf بأي تشفير كان موجودًا في ملف الإدخال. هذا الخيار يتجاوز هذا السلوك.
--remove-restrictions -- إزالة القيود الأمنية من ملف الإدخال
إزالة القيود المرتبطة بملفات PDF الموقعة رقميًا. يمكن دمج هذا الخيار مع --decrypt للسماح بالتحرير الحر للملفات الموقعة/المشفرة سابقًا. هذا الخيار يبطل ويعطل أي توقيعات رقمية ولكنه يترك مظاهرها المرئية سليمة.
--copy-encryption -- نسخ تفاصيل تشفير ملف آخر
--copy-encryption=file

قم بنسخ تفاصيل التشفير من الملف المحدد بدلاً من الاحتفاظ بتشفير ملف الإدخال. استخدم --encryption-file-password لتحديد كلمة مرور ملف التشفير.

--encryption-file-password -- توفير كلمة المرور لـ --copy-encryption
--encryption-file-password=password

إذا كان الملف المسمى في --copy-encryption يتطلب كلمة مرور، استخدم هذا الخيار لتوفير كلمة المرور.

--qdf -- تمكين عرض كود PDF في محرر نصوص
إنشاء ملف PDF مناسب للعرض في محرر نصوص وحتى التحرير. هذا مخصص لتحرير كود PDF، وليس محتويات الصفحة. يتم إلغاء ضغط جميع التدفقات التي يمكن إلغاء ضغطها، ويتم تطبيع تدفقات المحتوى، من بين تغييرات أخرى. يمكن استخدام الأداة المصاحبة "fix-qdf" لإصلاح ملفات QDF التي تم تحريرها يدويًا. QDF هي ميزة خاصة بأداة qpdf. يرجى الاطلاع على فصل "QDF Mode" في الدليل.
--no-original-object-ids -- حذف معرفات الكائنات الأصلية في qdf
حذف التعليقات في ملف QDF التي تشير إلى معرف الكائن الذي كان للكائن في الملف الأصلي.
--compress-streams -- ضغط التدفقات غير المضغوطة
--compress-streams=[y|n]

يمنع --compress-streams=n برنامج qpdf من ضغط التدفقات غير المضغوطة. يمكن أن يكون هذا مفيدًا إذا كنت تترك بعض التدفقات غير مضغوطة عن قصد.

--decode-level -- التحكم في التدفقات التي سيتم إلغاء ضغطها
--decode-level=parameter

عند إلغاء ضغط التدفقات، تحكم في أنواع مخططات الضغط التي يجب إلغاء ضغطها:

•
none: لا تقم بإلغاء ضغط أي شيء. هذا هو الإعداد الافتراضي مع --json-output.
•
generalized: قم بإلغاء ضغط التدفقات المضغوطة باستخدام خوارزمية ضغط للأغراض العامة. هذا هو الإعداد الافتراضي باستثناء عندما يتم إعطاء --json-output.
•
specialized: بالإضافة إلى generalized، قم أيضًا بإلغاء ضغط التدفقات المضغوطة باستخدام مخطط ضغط متخصص ولكنه غير قابل للفقد.
•
all: بالإضافة إلى specialized، قم بإلغاء ضغط التدفقات المضغوطة باستخدام مخططات ضغط قابلة للفقد مثل JPEG (DCT). qpdf لا يعرف كيفية إلغاء ضغط جميع مخططات الضغط.
--stream-data -- التحكم في ضغط التدفق
--stream-data=parameter

يتحكم هذا الخيار في كيفية ضغط التدفقات في الإخراج. إنه أقل تفصيلاً من الخيارات الأحدث، --compress-streams و --decode-level.

المعلمات:

•
compress: نفس --compress-streams=y --decode-level=generalized
•
preserve: نفس --compress-streams=n --decode-level=none
•
uncompress: نفس --compress-streams=n --decode-level=generalized
--recompress-flate -- إلغاء ضغط وإعادة ضغط flate
مخطط الضغط العام الافتراضي الذي يستخدمه PDF هو flate، وهو نفس المستخدم بواسطة zip و gzip. عادةً ما يترك qpdf هذه التدفقات كما هي. يخبر هذا الخيار qpdf بإلغاء ضغط وإعادة ضغط التدفقات المضغوطة باستخدام flate. يمكن أن يكون هذا مفيدًا عند دمجه مع --compression-level.
--compression-level -- ضبط مستوى الضغط لـ flate
--compression-level=level

قم بتعيين مستوى ضغط من 1 (الأقل، الأسرع) إلى 9 (الأكثر، الأبطأ) عند ضغط الملفات باستخدام flate (المستخدم في zip و gzip)، وهو الضغط الافتراضي لمعظم ملفات PDF. تحتاج إلى --recompress-flate مع هذا الخيار إذا كنت ترغب في تغيير التدفقات المضغوطة بالفعل.

--jpeg-quality -- ضبط مستوى جودة JPEG لـ jpeg
--jpeg-quality=level

عند إعادة كتابة الصور باستخدام --optimize-images، قم بتعيين مستوى جودة من 0 (الأدنى) إلى 100 (الأعلى) لكتابة صور جديدة. تؤدي الجودة الأعلى إلى صور أكبر، وتؤدي الجودة الأقل إلى صور أصغر. هذا الخيار فعال فقط عند دمجه مع --optimize-images.

--normalize-content -- إصلاح أسطر جديدة في تدفقات المحتوى
--normalize-content=[y|n]

قم بتطبيع أسطر جديدة إلى أسطر جديدة بأسلوب UNIX في تدفقات محتوى PDF، وهو أمر مفيد لعرضها في محرر نصوص مبرمج عبر منصات متعددة. يتم تشغيل هذا أيضًا بواسطة --qdf.

--object-streams -- التحكم في استخدام تدفقات الكائنات
--object-streams=mode

تحكم في ما يفعله qpdf فيما يتعلق بتدفقات الكائنات. الخيارات:

•
preserve: احتفظ بتدفقات الكائنات الأصلية، إن وجدت (الافتراضي)
•
disable: قم بإنشاء ملفات إخراج بدون تدفقات كائنات
•
generate: قم بإنشاء تدفقات كائنات، وضغط الكائنات عند الإمكان
--preserve-unreferenced -- احتفظ بالكائنات غير المشار إليها
احتفظ بجميع الكائنات من الإدخال حتى لو لم تتم الإشارة إليها.
--remove-unreferenced-resources -- إزالة موارد الصفحة غير المشار إليها
--remove-unreferenced-resources=parameter

قم بإزالة الموارد من قاموس موارد الصفحة التي لا تتم الإشارة إليها في محتويات الصفحة. المعلمات: "auto" (الافتراضي)، "yes"، "no".

--preserve-unreferenced-resources -- استخدم --remove-unreferenced-resources=no
مرادف لـ --remove-unreferenced-resources=no. استخدم ذلك بدلاً من ذلك.
--newline-before-endstream -- فرض سطر جديد قبل endstream
لإضافة سطر جديد إضافي قبل endstream. استخدام هذا الخيار يمكّن qpdf من الحفاظ على PDF/A عند إعادة كتابة مثل هذه الملفات.
--coalesce-contents -- دمج تدفقات المحتوى
إذا كانت الصفحة تحتوي على مصفوفة من تدفقات المحتوى، فقم بدمجها في تدفق محتوى واحد.
--externalize-inline-images -- تحويل الصور المضمنة إلى صور عادية
قم بتحويل الصور المضمنة إلى صور عادية.
--ii-min-bytes -- ضبط الحد الأدنى للحجم لـ --externalize-inline-images
--ii-min-bytes=size-in-bytes

لا تقم بتحويل الصور المضمنة التي تقل عن هذا الحجم. الافتراضي هو 1024. استخدم 0 بدون حد أدنى.

--min-version -- تعيين الحد الأدنى لإصدار PDF
--min-version=version

فرض أن يكون إصدار PDF للمخرجات على الأقل بالإصدار المحدد. تنسيق رقم الإصدار هو "major.minor[.extension-level]"، والذي يحدد رأس الإصدار بـ "major.minor" ومستوى الامتداد، إذا تم تحديده، بـ "extension-level".

--force-version -- تعيين إصدار PDF للمخرجات
--force-version=version

فرض أن يكون رأس إصدار PDF لملف المخرجات هو القيمة المحددة، حتى لو كان الملف يستخدم ميزات قد لا تكون متاحة في هذا الإصدار.

نطاقات الصفحات (صيغة نطاق الصفحات)

يمكن العثور على وصف كامل لصيغة نطاق الصفحات، مع أمثلة، في الدليل. باختصار، النطاق هو قائمة مفصولة بفواصل للمجموعات. المجموعة هي رقم أو نطاق من الأرقام مفصولة بشرطة. يمكن إضافة x مسبقًا للمجموعة لاستبعاد أعضائها من المجموعة السابقة. يمكن أن يكون الرقم واحدًا مما يلي:

•
<n> حيث <n> يمثل رقم الصفحة <n>
•
r<n> هي الصفحة <n> من النهاية
•
z الصفحة الأخيرة، وهي نفس r1
•
a,b,c الصفحات a، b، و c
•
a-b الصفحات من a إلى b شاملة؛ إذا كان a > b، فإن هذا يعد تنازليًا
•
a-b,xc الصفحات من a إلى b باستثناء الصفحة c
•
a-b,xc-d الصفحات من a إلى b باستثناء الصفحات من c إلى d

يمكنك إضافة :even أو :odd لتحديد كل صفحة أخرى من المجموعة الناتجة من الصفحات، حيث يبدأ :odd بالصفحة الأولى و :even يبدأ بالصفحة الثانية. هذه صفحات فردية وزوجية من المجموعة الناتجة، وليست بناءً على أرقام الصفحات الأصلية.

التعديل (تغيير أجزاء من ملف PDF)

تجري خيارات التعديل تغييرات منهجية على أجزاء معينة من ملف PDF، مما يتسبب في عرض ملف PDF بشكل مختلف عن الأصل.

خيارات ذات صلة:

--pages -- بدء تحديد الصفحة
--pages [--file=]file [options] [...] --

قم بتشغيل qpdf --help=page-selection للحصول على التفاصيل.

--file -- مصدر للصفحات
--file=file

حدد الملف لعملية الصفحة الحالية. يتم استخدام هذا مع --pages، --overlay، و --underlay ويظهر بين الخيار و -- المنتهية. قم بتشغيل qpdf --help=page-selection للحصول على التفاصيل.

--range -- نطاق الصفحة
--range=numeric-range

حدد نطاق الصفحات لعملية الصفحة الحالية مع --pages. إذا تم حذفه، يتم تحديد جميع الصفحات. يتم استخدام هذا مع --pages ويظهر بين --pages و --. قم بتشغيل qpdf --help=page-selection للحصول على التفاصيل.

--collate -- تجميع مع --pages
--collate[=n[,m,...]]

قم بتجميع الصفحات المحددة مع --pages بدلاً من ربطها. مع معلمة رقمية، قم بالتجميع في مجموعات من n. الافتراضي هو 1. مع معلمات رقمية مفصولة بفواصل، خذ n من الملف الأول، m من الثاني، إلخ. قم بتشغيل qpdf --help=page-selection للحصول على تفاصيل إضافية.

--split-pages -- كتابة الصفحات إلى ملفات منفصلة
--split-pages[=n]

يتسبب هذا الخيار في قيام qpdf بإنشاء ملفات مخرجات منفصلة لكل صفحة أو مجموعة من الصفحات بدلاً من ملف مخرجات واحد.

يتم إنشاء أسماء الملفات من اسم ملف المخرجات المحدد على النحو التالي:

•
إذا ظهرت السلسلة %d في اسم ملف المخرجات، يتم استبدالها بنطاق صفحات مضاف إلى اليسار بأصفار بدءًا من 1
•
بخلاف ذلك، إذا انتهى اسم ملف المخرجات بـ .pdf (غير حساس لحالة الأحرف)، يتم إدراج نطاق صفحات مضاف إلى اليسار بأصفار، مسبوقًا بشرطة، قبل امتداد الملف
•
بخلاف ذلك، يتم إلحاق اسم الملف بنطاق صفحات مضاف إلى اليسار بأصفار مسبوقًا بشرطة.

نطاقات الصفحات هي أرقام صفحات فردية لمجموعات الصفحات الفردية أو first-last للمجموعات متعددة الصفحات.

--overlay -- بدء خيارات التراكب
--overlay file [options] --

قم بتراكب الصفحات من ملف PDF آخر على المخرجات. قم بتشغيل qpdf --help=overlay-underlay للحصول على التفاصيل.

--underlay -- بدء خيارات التضمين
--underlay file [options] --

قم بتضمين الصفحات من ملف PDF آخر على المخرجات. قم بتشغيل qpdf --help=overlay-underlay للحصول على التفاصيل.

--flatten-rotation -- إزالة الدوران من قاموس الصفحة
لكل صفحة تم تدويرها باستخدام المفتاح /Rotate في قاموس الصفحة، قم بإزالة المفتاح /Rotate وتنفيذ دلالات الدوران المتطابقة عن طريق تعديل محتويات الصفحة. يمكن أن يكون هذا مفيدًا إذا كان عارض PDF معطلاً يفشل في مراعاة بيانات التعريف لدوران الصفحة بشكل صحيح.
--flatten-annotations -- دفع التعليقات التوضيحية إلى المحتوى
--flatten-annotations=parameter

قم بدفع التعليقات التوضيحية للصفحة إلى تدفقات المحتوى. قد يكون هذا ضروريًا في بعض الحالات عند طباعة أو تقسيم الملفات. المعلمات: "all"، "print"، "screen".

--rotate -- تدوير الصفحات
--rotate=[+|-]angle[:page-range]

قم بتدوير الصفحات المحددة بمضاعفات 90 درجة بتحديد زوايا مطلقة أو نسبية. يمكن أن تكون "angle" 0، 90، 180، أو 270. أنت تريد تقريبًا دائمًا استخدام +angle أو -angle بدلاً من مجرد angle، كما نوقش في الدليل. قم بتشغيل qpdf --help=page-ranges للحصول على مساعدة بشأن نطاقات الصفحات.

--generate-appearances -- إنشاء مظاهر لحقول النماذج
تتكون حقول نماذج PDF من قيم ومظاهر، والتي قد تكون غير متسقة مع بعضها البعض إذا تم تعديل قيمة حقل نموذج دون تحديث مظهره. يخبر هذا الخيار qpdf بإنشاء تدفقات مظهر جديدة. هناك بعض القيود، والتي نوقشت في الدليل.
--optimize-images -- استخدام ضغط فعال للصور
حاول استخدام ضغط DCT (JPEG) للصور التي تقع ضمن قيود معينة طالما أن القيام بذلك يقلل من حجم الصورة بالبايت. انظر أيضًا المساعدة للخيار التالي:
--oi-min-width
--oi-min-height
--oi-min-area
--keep-inline-images
--oi-min-width -- الحد الأدنى للعرض لـ --optimize-images
--oi-min-width=width

لا تقم بتحسين الصور التي يقل عرضها عن القيمة المحددة.

--oi-min-height -- الحد الأدنى للارتفاع لـ --optimize-images
--oi-min-height=height

لا تقم بتحسين الصور التي يقل ارتفاعها عن القيمة المحددة.

--oi-min-area -- الحد الأدنى للمساحة لـ --optimize-images
--oi-min-area=area-in-pixels

لا تقم بتحسين الصور التي تقل مساحتها بالبكسل عن القيمة المحددة.

--keep-inline-images -- استبعاد الصور المضمنة من التحسين
منع اعتبار الصور المضمنة بواسطة --optimize-images.
--remove-info -- إزالة معلومات الملف
استبعاد معلومات الملف (باستثناء تاريخ التعديل) من ملف المخرجات.
--remove-metadata -- إزالة بيانات التعريف
استبعاد بيانات التعريف من ملف المخرجات.
--remove-page-labels -- إزالة أرقام الصفحات الصريحة
استبعاد تسميات الصفحات (أرقام الصفحات الصريحة) من ملف المخرجات.
--remove-structure -- إزالة بيانات التعريف
استبعاد شجرة البنية من ملف المخرجات.
--set-page-labels -- ترقيم الصفحات للمستند بأكمله
--set-page-labels label-spec ... --

قم بتعيين تسميات الصفحات (أرقام الصفحات الصريحة) للملف بأكمله. كل تسمية label-spec لها الصيغة

first-page:[type][/start[/prefix]]

حيث

•
"first-page" تمثل رقم صفحة تسلسلي باستخدام نفس صيغة نطاقات الصفحات: رقم، رقم مسبوق بـ "r" للإشارة إلى العد من النهاية، أو "z" للإشارة إلى الصفحة الأخيرة
•
"type" هو أحد الخيارات التالية: - D: أرقام عربية (أرقام) - A: أحرف أبجدية كبيرة - a: أحرف أبجدية صغيرة - R: أرقام رومانية كبيرة - r: أرقام رومانية صغيرة - محذوف: رقم الصفحة لا يظهر، على الرغم من أن البادئة،
إذا تم تحديدها، ستظل تظهر
•
"start" يجب أن يكون رقمًا >= 1
•
"prefix"` يمكن أن يكون أي سلسلة ويتم إلحاقها بكل تسمية صفحة.

{--overlay|--underlay} [--file=]file

[--from=[page-range]]

--

لاحظ استخدام "--" بمفردها لإنهاء خيارات الطبقة العلوية/السفلية.

بالنسبة للطبقة العلوية والسفلية، يتم تحديد ملف وكلمة مرور اختيارية، بالإضافة إلى سلسلة من نطاقات الصفحات الاختيارية. السلوك الافتراضي هو أنه يتم فرض كل صفحة من ملف الطبقة العلوية أو السفلية على الصفحة المقابلة للإخراج الأساسي حتى ينفد الصفحات، ويتم تجاهل أي صفحات إضافية. يمكنك أيضًا توفير نطاق صفحات مع --repeat لجعل هذه الصفحات تتكرر بعد استنفاد الصفحات الأصلية.

هذه الخيارات قابلة للتكرار. سيتم تكديس الصفحات بترتيب ظهورها: أولاً الطبقات السفلية، ثم الصفحة الأصلية، ثم الطبقات العلوية.

--to=page-range

أمثلة:

•

•

qpdf(1)

A tool for PDF transformation

qpdf is a command-line tool that performs structural transformations on PDF files. It can be used to merge PDF files, split them into pages, extract objects, and perform many other operations. qpdf is written in C++ and is designed to be fast and reliable.

SYNOPSIS

qpdf [options] infile [outfile]

DESCRIPTION

qpdf is a command-line tool that performs structural transformations on PDF files. It can be used to merge PDF files, split them into pages, extract objects, and perform many other operations. qpdf is written in C++ and is designed to be fast and reliable.

The primary operations that qpdf performs are given as options. The default behavior is to make a copy of the input file (possibly with some modifications, depending on the options) and write it to the output file. If no output file is specified, the output is written to standard output. If the input file is standard input, the output file must be specified.

qpdf processes PDF files by first parsing the entire file, including all objects and streams, and then writing out a new PDF file with the requested modifications. This means that qpdf is not suitable for operating on a PDF file while it is being written by another application. qpdf will also typically rewrite the entire file, which means that changes made by qpdf are visible to applications that do not correctly handle PDF files that have been modified by other tools.

USAGE (basic invocation)

The most basic use of qpdf is to copy a PDF file while possibly making some modifications. The basic syntax is:

qpdf [options] infile outfile

Where:

options
One or more command-line options that control how qpdf operates.
infile
The input PDF file. If omitted, standard input is used.
outfile
The output PDF file. If omitted, standard output is used. If both infile and outfile are omitted, qpdf behaves as if --help was given.

For example, to create a copy of a PDF file named input.pdf named output.pdf, you would run:

qpdf input.pdf output.pdf

To compress a PDF file named input.pdf and write the output to standard output, you would run:

qpdf --compress-input=y input.pdf /dev/stdout

To combine two PDF files, file1.pdf and file2.pdf, into a new file combined.pdf, you would run:

qpdf --empty --pages file1.pdf file2.pdf -- combined.pdf

This command uses the following options:

--empty
Start with an empty PDF file. This is necessary to be able to combine multiple files.
--pages file1.pdf file2.pdf --
Append all pages from file1.pdf and then all pages from file2.pdf to the output file. The double dash -- is important to separate the input files from the output file.

EXIT-STATUS (meanings of qpdf's exit codes)

qpdf returns an exit code to indicate the success or failure of its operation. The exit codes are as follows:

0
Success. The operation completed without errors.
1
General error. An unspecified error occurred during the operation.
2
File access error. An error occurred while trying to access or read a file.
3
Invalid command-line arguments. The options provided to qpdf were invalid.
4
PDF parsing error. qpdf encountered an error while parsing the input PDF file.
5
PDF writing error. qpdf encountered an error while writing the output PDF file.
6
Unsupported operation. The requested operation is not supported by qpdf.

COMPLETION (shell completion)

qpdf can provide shell completion for its options and arguments. To enable shell completion, you need to source the completion script in your shell configuration file (e.g., .bashrc, .zshrc). The script can typically be found in the qpdf installation directory or provided separately.

For example, in Bash, you might add the following line to your .bashrc:

source /path/to/qpdf_completion.sh

After sourcing the script, you can use the Tab key to auto-complete qpdf options and arguments.

HELP (information about qpdf)

qpdf provides several ways to get help:

--help
Display a summary of all available options and their descriptions.
--help=option
Display detailed help for a specific option. For example, qpdf --help=--pages will show detailed information about the --pages option.
--help=all
Display detailed help for all options. This is equivalent to running qpdf --help.

GENERAL (general options)

--version
Print the version of qpdf and exit.
--verbose
Print verbose output, including information about the objects being processed.
--quiet
Suppress all output except for errors.
--warnings
Print warnings about potential issues in the PDF file.
--strict-mode
Enable strict mode, which will cause qpdf to exit with an error code if any warnings are issued.
--check-coverage
Enable coverage checking. This is intended for use with automated tests and may not be useful for general users.
--deterministic-id
Use a fixed document ID. This is intended for testing only. Never use it for production files.
--default-object-stream-mode=mode
Set the default mode for object streams. Valid modes are never, always, and compress. never means no object streams will be created. always means object streams will be created for all objects. compress means object streams will be created only for objects that can be compressed. The default is compress.
--object-stream-mode=mode
Set the mode for object streams. This option overrides --default-object-stream-mode for specific objects. Valid modes are the same as for --default-object-stream-mode.
--default-stream-compress-mode=mode
Set the default compression mode for streams. Valid modes are none, fast, best, and default. The default is default.
--stream-compress-mode=mode
Set the compression mode for streams. This option overrides --default-stream-compress-mode for specific streams. Valid modes are the same as for --default-stream-compress-mode.
--compress-streams
Compress all streams. This is equivalent to --default-stream-compress-mode=best.
--compress-input-streams
Compress all streams in the input file. This is equivalent to --stream-compress-mode=best for all input streams.
--compress-output-streams
Compress all streams in the output file. This is equivalent to --stream-compress-mode=best for all output streams.
--uncompress-streams
Uncompress all streams. This is equivalent to --default-stream-compress-mode=none.
--uncompress-input-streams
Uncompress all streams in the input file. This is equivalent to --stream-compress-mode=none for all input streams.
--uncompress-output-streams
Uncompress all streams in the output file. This is equivalent to --stream-compress-mode=none for all output streams.
--object-compress-level=n
Set the compression level for object streams to n, where n is between 0 and 9. The default is 6.
--stream-compress-level=n
Set the compression level for streams to n, where n is between 0 and 9. The default is 6.
--decode-level=level
Set the decode level for streams. Valid levels are none, fast, best, and default. The default is default. This option affects how streams are decompressed.
--filter-streams
Apply filters to streams. This is intended for debugging and may not produce valid PDF files.
--no-recurse-objects
Do not recurse into objects when processing. This is intended for debugging.
--no-recurse-streams
Do not recurse into streams when processing. This is intended for debugging.
--preserve-compression
Preserve the compression of streams. This means that streams that are already compressed will not be recompressed.
--no-preserve-compression
Do not preserve the compression of streams. This means that all streams will be recompressed, even if they are already compressed.
--copy-all-streams
Copy all streams from the input file to the output file without recompressing them. This is equivalent to --preserve-compression.
--no-copy-all-streams
Do not copy all streams from the input file to the output file. This means that all streams will be recompressed.
--object-encryption=key
Encrypt objects with the specified key. This is intended for debugging and may not produce valid PDF files.
--no-object-encryption
Do not encrypt objects. This is the default behavior.
--object-stream-encryption=key
Encrypt object streams with the specified key. This is intended for debugging and may not produce valid PDF files.
--no-object-stream-encryption
Do not encrypt object streams. This is the default behavior.
--encrypt-aes-iv=iv
Use the specified initialization vector for AES encryption. This is intended for testing only and should not be used in production.
--no-encrypt-aes-iv
Do not use a specific initialization vector for AES encryption. This is the default behavior.
--static-id
Use a fixed document ID. This is intended for testing only. Never use it for production files.
--static-aes-iv
Use a static initialization vector for AES-CBC. This is intended for testing only so that output files can be reproducible. Never use it for production files. This option is not secure since it significantly weakens the encryption.

FILE OPERATIONS (options for manipulating files)

--empty
Create a new, empty PDF file. This is useful when creating a PDF file from scratch or when combining multiple PDF files.
--pages
--pages=input-file[:page-range][,input-file[:page-range]]...[--]output-file

--split-pages
Split the input PDF file into multiple output files, one for each page. The output file names are generated based on the input file name and the page number.
--merge
Merge multiple input PDF files into a single output PDF file. This is equivalent to using --pages with multiple input files.
--output-dir=directory
Specify the directory where output files should be placed. This is useful when splitting pages or creating multiple output files.
--overwrite
Overwrite existing output files without prompting.
--no-overwrite
Do not overwrite existing output files. If an output file already exists, qpdf will exit with an error.
--copy-document
Copy the entire document, including all objects and streams, to the output file. This is equivalent to running qpdf without any other options.
--copy-document-metadata
Copy only the document metadata from the input file to the output file.
--copy-fonts
Copy all fonts from the input file to the output file.
--copy-images
Copy all images from the input file to the output file.
--copy-stream-data
Copy all stream data from the input file to the output file.
--copy-object-data
Copy all object data from the input file to the output file.
--copy-all-data
Copy all data from the input file to the output file.

--check-linearization -- check linearization tables
Check to see whether a file is linearized and, if so, whether the linearization hint tables are correct.
--show-linearization -- show linearization hint tables
Check and display all data in the linearization hint tables.
--show-xref -- show cross reference data
Show the contents of the cross-reference table or stream (object locations in the file) in a human-readable form. This is especially useful for files with cross-reference streams, which are stored in a binary format.
--show-object -- show contents of an object
--show-object={trailer|obj[,gen]}

Show the contents of the given object. This is especially useful for inspecting objects that are inside of object streams (also known as "compressed objects").

--raw-stream-data -- show raw stream data
When used with --show-object, if the object is a stream, write the raw (compressed) binary stream data to standard output instead of the object's contents. See also --filtered-stream-data.
--filtered-stream-data -- show filtered stream data
When used with --show-object, if the object is a stream, write the filtered (uncompressed, potentially binary) stream data to standard output instead of the object's contents. See also --raw-stream-data.
--show-npages -- show number of pages
Print the number of pages in the input file on a line by itself. Useful for scripts.
--show-pages -- display page dictionary information
Show the object and generation number for each page dictionary object and for each content stream associated with the page.
--with-images -- include image details with --show-pages
When used with --show-pages, also shows the object and generation numbers for the image objects on each page.
--list-attachments -- list embedded files
Show the key and stream number for each embedded file. Combine with --verbose for more detailed information.
--show-attachment -- export an embedded file

This option is repeatable. If given, only the specified top-level keys will be included in the JSON output. Otherwise, all keys will be included. With --json-output, when not given, only the "qpdf" key will appear in the output.

--json-object -- limit which objects are in JSON
--json-object={trailer|obj[,gen]}

This option is repeatable. If given, only specified objects will be shown in the "objects" key of the JSON output. Otherwise, all objects will be shown.

--json-stream-data -- how to handle streams in json output
--json-stream-data={none|inline|file}

When used with --json, this option controls whether streams in json output should be omitted, written inline (base64-encoded) or written to a file. If "file" is chosen, the file will be the name of the output file appended with -nnn where nnn is the object number. The prefix can be overridden with --json-stream-prefix. The default is "none", except when --json-output is specified, in which case the default is "inline".

--json-stream-prefix -- prefix for json stream data files
--json-stream-prefix=file-prefix

When used with --json-stream-data=file, --json-stream-data=file-prefix sets the prefix for stream data files, overriding the default, which is to use the output file name. Whatever is given here will be appended with -nnn to create the name of the file that will contain the data for the stream stream in object nnn.

--json-output -- apply defaults for JSON serialization
--json-output[=version]

Implies --json=version. Changes default values for certain options so that the JSON output written is the most faithful representation of the original PDF and contains no additional JSON keys. See also --json-stream-data, --json-stream-prefix, and --decode-level.

--json-input -- input file is qpdf JSON
Treat the input file as a JSON file in qpdf JSON format. See the "qpdf JSON Format" section of the manual for information about how to use this option.
--update-from-json -- update a PDF from qpdf JSON
--update-from-json=qpdf-json-file

Update a PDF file from a JSON file. Please see the "qpdf JSON" chapter of the manual for information about how to use this option.

TESTING (options for testing or debugging)

The options below are useful when writing automated test code that includes files created by qpdf or when testing qpdf itself.

Related Options:

--static-id -- use a fixed document ID
Use a fixed value for the document ID. This is intended for testing only. Never use it for production files. See also qpdf --help=--deterministic-id.
--static-aes-iv -- use a fixed AES vector
Use a static initialization vector for AES-CBC. This is intended for testing only so that output files can be reproducible. Never use it for production files. This option is not secure since it significantly weakens the encryption.
--linearize-pass1 -- save pass 1 of linearization
--linearize-pass1=file

Write the first pass of linearization to the named file. The resulting file is not a valid PDF file. This option is useful only for debugging qpdf.

--test-json-schema -- test generated json against schema
This is used by qpdf's test suite to check consistency between the output of qpdf --json and the output of qpdf --json-help.
--report-memory-usage -- best effort report of memory usage
This is used by qpdf's performance test suite to report the maximum amount of memory used in supported environments.
