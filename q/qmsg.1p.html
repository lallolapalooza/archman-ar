QMSG(1P) دليل مبرمجي POSIX QMSG(1P)

مقدمة

هذه الصفحة اليدوية جزء من دليل مبرمجي POSIX. قد يختلف تنفيذ هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا يتم تنفيذ الواجهة في لينكس.

الاسم

qmsg — إرسال رسالة إلى الوظائف المجمعة

ملخص

qmsg [-EO] سلسلة_الرسالة معرف_الوظيفة...

الوصف

لإرسال رسالة إلى وظيفة مجمعة يعني طلب أن يقوم الخادم بكتابة سلسلة رسالة في ملف إخراج واحد أو أكثر للوظيفة المجمعة. يتم إرسال الرسالة إلى وظيفة مجمعة عن طريق طلب إلى خادم التجميع الذي يدير الوظيفة المجمعة. الأداة المساعدة qmsg هي عميل تجميع يمكن للمستخدم الوصول إليه يطلب إرسال رسائل إلى وظيفة مجمعة واحدة أو أكثر.

ستقوم الأداة المساعدة qmsg بكتابة رسائل في ملفات الوظائف المجمعة عن طريق إرسال *طلب رسالة وظيفة* إلى خادم التجميع الذي يدير الوظيفة المجمعة. الأداة المساعدة qmsg لن تكتب الرسالة مباشرة في ملفات الوظيفة المجمعة.

ستقوم الأداة المساعدة qmsg بإرسال *طلبات رسالة وظيفة* للوظائف المجمعة، وفقط لتلك الوظائف المجمعة، التي يتم تقديم معرف وظيفة مجمعة لها إلى الأداة المساعدة.

ستقوم الأداة المساعدة qmsg بإرسال *طلبات رسالة وظيفة* للوظائف المجمعة بالترتيب الذي يتم به تقديم معرفات الوظائف المجمعة الخاصة بها إلى الأداة المساعدة.

إذا فشلت الأداة المساعدة qmsg في معالجة أي معرف وظيفة مجمعة بنجاح، فستتابع الأداة المساعدة معالجة معرفات الوظائف المجمعة المتبقية، إن وجدت.

لن تخرج الأداة المساعدة qmsg قبل إرسال *طلب رسالة وظيفة* إلى الخادم الذي يدير الوظيفة المجمعة المقابلة لكل معرف وظيفة مجمعة تم معالجته بنجاح.

الخيارات

ستتوافق الأداة المساعدة qmsg مع حجم التعريفات الأساسية لـ POSIX.1-2017، *القسم 12.2*، *إرشادات بناء جملة الأداة المساعدة*.

سيتم دعم الخيارات التالية بواسطة التنفيذ:

-E
تحديد أن الرسالة مكتوبة إلى الخطأ القياسي لكل وظيفة مجمعة.

ستقوم الأداة المساعدة qmsg بكتابة الرسالة إلى الخطأ القياسي للوظيفة المجمعة.

-O
تحديد أن الرسالة مكتوبة إلى الإخراج القياسي لكل وظيفة مجمعة.

ستقوم الأداة المساعدة qmsg بكتابة الرسالة إلى الإخراج القياسي للوظيفة المجمعة.

إذا لم يتم تقديم الخيار -O أو -E إلى الأداة المساعدة qmsg، فستقوم الأداة المساعدة بكتابة الرسالة في ملف محدد بالتنفيذ. سيصف مستند التوافق للتنفيذ اسم وموقع الملف المحدد بالتنفيذ. إذا تم تقديم كل من الخيارين -O و -E إلى الأداة المساعدة qmsg، فستقوم الأداة المساعدة بكتابة الرسائل إلى كل من الإخراج القياسي والخطأ القياسي.

المعاملات

ستقبل الأداة المساعدة qmsg معاملين على الأقل، سلسلة_الرسالة وواحد أو أكثر من معرفات الوظائف المجمعة job_identifier.

سيكون المعامل سلسلة_الرسالة هو السلسلة التي سيتم كتابتها في ملف إخراج واحد أو أكثر للوظيفة المجمعة متبوعة بـ <سطر جديد>. إذا كانت السلسلة تحتوي على أحرف <مسافة>، فيجب على التطبيق التأكد من أن السلسلة موضوعة بين علامتي اقتباس. يجب ترميز سلسلة_الرسالة بمجموعة الأحرف المحمولة (انظر حجم التعريفات الأساسية لـ POSIX.1-2017، *القسم 6.1*، *مجموعة الأحرف المحمولة*).

جميع المعاملات المتبقية هي معرفات وظائف مجمعة job_identifier التي تتوافق مع بناء الجملة لمعرف وظيفة مجمعة job_identifier (انظر *القسم 3.3.1*، *معرف الوظيفة المجمعة*).

الإدخال القياسي

غير مستخدم.

ملفات الإدخال

لا شيء.

متغيرات البيئة

ستؤثر متغيرات البيئة التالية على تنفيذ qmsg:

LANG
توفير قيمة افتراضية للمتغيرات الدولية غير المعينة أو الفارغة. (انظر حجم التعريفات الأساسية لـ POSIX.1-2017، *القسم 8.2*، *متغيرات التدويل* أسبقية المتغيرات الدولية المستخدمة لتحديد قيم فئات اللغة المحلية.)
LC_ALL
إذا تم تعيينها إلى قيمة سلسلة غير فارغة، فستتجاوز قيم جميع متغيرات التدويل الأخرى.
LC_CTYPE
تحديد اللغة المحلية لتفسير تسلسلات البايتات لبيانات النص كأحرف (على سبيل المثال، أحرف أحادية البايت مقابل متعددة البايتات في المعاملات).
LC_MESSAGES

تحديد اللغة المحلية التي يجب استخدامها للتأثير على تنسيق ومحتوى الرسائل التشخيصية المكتوبة إلى الخطأ القياسي.
LOGNAME
تحديد اسم تسجيل دخول المستخدم.

عواقب الأخطاء

بالإضافة إلى السلوك الافتراضي، لن يُطلب من الأداة المساعدة qmsg كتابة رسالة تشخيصية إلى الخطأ القياسي عندما يشير رد الخطأ المستلم من خادم التجميع إلى أن معرف الوظيفة المجمعة job_identifier غير موجود على الخادم. ما إذا كانت الأداة المساعدة qmsg تنتظر لإخراج الرسالة التشخيصية أثناء محاولة تحديد موقع الوظيفة على خوادم أخرى هو محدد بالتنفيذ.

الأقسام التالية إعلامية.

استخدام التطبيق

المنطق

تسمح الأداة المساعدة qmsg للمستخدمين بكتابة رسائل في ملفات إخراج الوظائف قيد التشغيل. لدى المستخدمين، بما في ذلك المشغلون والمسؤولون، عدد من المناسبات التي يرغبون فيها في وضع رسائل في ملفات إخراج وظيفة مجمعة. على سبيل المثال، إذا كان قرص يتم استخدامه بواسطة وظيفة مجمعة يظهر أخطاء، فقد يلاحظ المشغل ذلك في مجرى الخطأ القياسي للوظيفة المجمعة.

توفر خيارات الأداة المساعدة qmsg للمستخدمين وسيلة لوضع الرسالة في مجرى الإخراج الذي يختارونه. مجرى الإخراج الافتراضي للرسالة — إذا لم يحدد المستخدم مجرى إخراج — محدد بالتنفيذ، حيث سيوفر العديد من التنفيذات، كتوسع لهذا الحجم من POSIX.1-2017، ملف سجل يعرض تاريخ تنفيذ الأداة المساعدة.

NAME

qmsg

- send a message to a batch job

SYNOPSIS

qmsg [-E | -O] -N jobname -m message

qmsg [-E | -O] -j jobid -m message

DESCRIPTION

The qmsg utility is used to send a message to a running batch job. The message can be directed to either standard output or standard error of the specified job.

OPTIONS

The qmsg utility shall conform to the Base Definitions volume of POSIX.1‐2017, Section 12.2, Utility Syntax Guidelines.

The following options shall be supported:

-E
Place the message in the standard error stream of the batch job.
-m message
Specifies the message to be sent to the job. The message argument shall be a string. If the message contains white space, it should be quoted.
-N jobname
Specifies the name of the job to which the message should be sent. This option is an alternative to specifying the job ID.
-O
Place the message in the standard output stream of the batch job.
-j jobid
Specifies the job ID of the job to which the message should be sent. This option is an alternative to specifying the job name.

OPERANDS

None.

STDIN

Not used.

INPUT FILES

None.

ENVIRONMENT VARIABLES

The following environment variables shall affect the execution of qmsg:

HOME
Used to determine the user's home directory, which may be needed for accessing configuration files.
LANG
Provide default locale settings.
LC_ALL
Provide override for the locale settings.
LC_CTYPE
Determine the locale for the interpretation of sequences of bytes of text data.
LC_MESSAGES
Determine the locale that should be used to format diagnostic messages written to standard error.
PATH
Used to find the required command executables.
USER
Determine the user requesting the operation, which may be needed for access control or configuration file lookup.

ASYNCHRONOUS EVENTS

None.

STDOUT

None.

STDERR

The standard error stream shall be used for diagnostic messages.

OUTPUT FILES

None.

EXTENDED DESCRIPTION

None.

EXIT STATUS

The following exit values shall be returned:

0
The message was successfully sent to the specified job.
>0
An error occurred.

CONSEQUENCES OF ERRORS

If the specified job cannot be found, or if the user does not have permission to send a message to the job, qmsg shall exit with a non-zero status.

APPLICATION USAGE

None.

EXAMPLES

1. Send the message "Processing complete." to the job with job ID 12345, directed to standard output:

qmsg -j 12345 -m "Processing complete." -O

2. Send the message "Warning: Input file not found." to the job named my_job, directed to standard error:

qmsg -N my_job -m "Warning: Input file not found." -E

RATIONALE

The qmsg utility provides a mechanism for sending messages to batch jobs. This can be useful for applications that need to communicate status information or receive commands from the administrator or other processes. The utility allows messages to be directed to either standard output or standard error, providing flexibility in how the messages are handled. The use of job names as an alternative to job IDs simplifies the process of targeting specific jobs.

The qselect utility can be used to acquire the appropriate list of job identifiers when a selection criterion is met.

The -E option allows users to place the message in the standard error stream of the batch job.

The -O option allows users to place the message in the standard output stream of the batch job.

Historically, the qmsg utility is an existing practice in the offerings of one or more implementors of an NQS-derived batch system. The utility has been found to be useful enough that it deserves to be included in this volume of POSIX.1‐2017.

FUTURE DIRECTIONS

The qmsg utility may be removed in a future version.
