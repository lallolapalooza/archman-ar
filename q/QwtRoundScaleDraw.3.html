Detailed Description

A scale is a representation of a numerical range. QwtRoundScaleDraw is the base class for scales, that are drawn on a circle.

A scale is controlled by a QwtScaleDiv object, which defines the tick positions and labels. The scale itself is drawn by a QwtScaleDraw implementation.

The scale can be rotated by using QwtAbstractScale::rotate(). The center and radius of the scale can be changed using moveCenter() and setRadius().

The scale is drawn by the drawScale() method. It is called by QwtAbstractScale whenever the scale needs to be updated.

The tick marks and labels can be customized by subclassing QwtRoundScaleDraw and overriding the drawTick() and drawLabel() methods.

void QwtRoundScaleDraw::setScaleDiv (const QwtScaleDiv &scaleDiv)

Set the scale division.

The scale division is a representation of the scale's ticks and labels. The default implementation drawScale() uses the information from the scale division to draw the ticks and labels.

It is possible to disable the drawing of ticks or labels by manipulating the QwtScaleDiv object before passing it to this function.

Example:

    QwtScaleDiv scaleDiv = scaleDraw->scaleDiv();
    scaleDiv.setLowerMargin(0.0);
    scaleDiv.setUpperMargin(0.0);
    scaleDiv.setSpacing(10); // Spacing between ticks and labels

    // For a clockwise scale, the interval has to be inverted
    // scaleDiv.setInterval( QwtInterval(e1, angle2), scale marks will not be drawn.
    if ( true ) // clockwise
    {
        scaleDiv.setInterval( QwtInterval(e2, e1) );
    }
    else // counter-clockwise
    {
        scaleDiv.setInterval( QwtInterval(e1, e2) );
    }

    scaleDraw->setScaleDiv(scaleDiv);

The default implementation of QwtScaleDraw draws ticks and labels aligned to the radius. When using a clockwise scale, the interval has to be inverted. This means that the lower bound of the interval needs to be the larger angle and the upper bound needs to be the smaller angle.

When the scale division is set with an interval, where the lower bound is larger than the upper bound (e.g. interval(270, 90)), the scale ticks are drawn clockwise. Otherwise, they are drawn counter-clockwise.
