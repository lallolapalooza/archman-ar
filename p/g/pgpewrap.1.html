pgpewrap(1)

الحزمة: mutt

التراخيص: GPL-2.0-or-later

pgpewrap(1) أدلة المستخدم pgpewrap(1)

الاسم

pgpewrap - أداة تعديل سطر الأوامر لـ Mutt

الصيغة

pgpewrap [ علامات ] -- بادئة [ مستلمين ]

الوصف

هذا برنامج صغير مكتوب بلغة C يقوم ببعض التعديلات على سطر الأوامر: الوسيط الأول هو أمر ليتم تنفيذه. عندما تصادف pgpewrap وسيط "--" (شرطة-شرطة)، فإنها ستفسر الوسيط التالي كبادئة توضع أمام جميع الوسائط التالية.

مثال


pgpewrap pgpe file -- -r a b c

سيؤدي ذلك إلى تنفيذ:


pgpe file -r a -r b -r c

هذا البرنامج النصي مطلوب مع PGP 5 ومع GPG، حيث أن واجهات سطر الأوامر الخاصة بهما لا يمكن خدمتها بشكل صحيح بواسطة آلية تنسيق mutt.
