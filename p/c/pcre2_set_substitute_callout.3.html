pcre2_set_substitute_callout(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_SUBSTITUTE_CALLOUT(3) دليل وظائف المكتبة PCRE2_SET_SUBSTITUTE_CALLOUT(3)

اسم

PCRE2 - تعبيرات نمطية متوافقة مع Perl (واجهة برمجة التطبيقات المعدلة)

ملخص

#include <pcre2.h>

int pcre2_set_substitute_callout(pcre2_match_context *mcontext,
  int (*callout_function)(pcre2_substitute_callout_block *, void *),
  void *callout_data);

وصف

تقوم هذه الدالة بتعيين حقول استدعاء الاستبدال في سياق المطابقة (المعامل الأول). يحدد المعامل الثاني دالة استدعاء، والمعامل الثالث هو عنصر بيانات غير شفاف يتم تمريره إليه. نتيجة هذه الدالة هي صفر دائمًا.

يوجد وصف كامل لواجهة برمجة التطبيقات الأصلية لـ PCRE2 في صفحة pcre2api ووصف لواجهة برمجة التطبيقات POSIX في صفحة pcre2posix.
