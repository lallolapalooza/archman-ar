الاسم

PCRE2 - تعابير نمطية متوافقة مع Perl (واجهة برمجة تطبيقات محدثة)

الملخص

#include <pcre2.h>

int pcre2_set_parens_nest_limit(pcre2_compile_context *ccontext,
  uint32_t value);

الوصف

تقوم هذه الوظيفة بتعيين، في سياق التجميع، أقصى عمق للأقواس المتداخلة في نمط. النتيجة دائمًا صفر.

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE2 الأصلية في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcre2posix.
