NAME

\n

pcp-dstat - versatile tool for generating system resource\n statistics

\n
\n
\n

SYNOPSIS

\n

pcp [pcp options] dstat\n [-acdfghilmnpqrstuvVy?] [-C cpus] [-G\n gpus] [-D disks] [-L DM devices]\n [-M MD devices] [-P partitions] [-I\n interrupts] [-N interfaces] [-o\n output-file] [-S swap-devices] [--bits]\n [--bw] [--color] [--float] [--integer]\n [--nocolor] [--noheaders] [--nomissed] [--noupdate]\n [--list] [--pidfile pid-file]\n [--plugin] [--all-plugins] [delay\n [count]]

\n
\n
\n

DESCRIPTION

\n

pcp-dstat is a general performance analysis tool allowing\n you to view multiple system resources instantly, for example you can compare\n disk usage in combination with interrupts from a disk controller, or compare\n the network bandwidth numbers directly with the disk throughput (in the same\n interval).

\n

It also cleverly gives you the most detailed information in\n columns and clearly indicates in what magnitude and unit the output is being\n displayed. Less confusion, fewer mistakes, more efficient.

\n

The delay is the delay in seconds between each update, and\n the count is the number of updates to display before exiting. The\n default delay is 1 second and count is unspecified (run until\n interrupted or end of archive is reached).

\n

This latest generation of Dstat, pcp-dstat, allows for\n analysis of historical performance data (in the PCP archive format created\n by pmlogger(1)), as well as distributed systems analysis of live\n performance data from remote hosts running the pmcd(1) process.

\n

The original Dstat notion of ``plugins'' is replaced by use of\n named metrics in a Performance Metric Name Space (PMNS(5)) supplied\n by Performance Metric Domain Agents (PMDAs). Metrics and other formatting\n information is now specified as plugin configuration files in\n pcp-dstat(5) format. This new style of plugin is either built-in\n (time-related reporting only), or sourced from the system-wide location\n ($PCP_SYSCONF_DIR/dstat) and/or sourced from an individual users set\n of personal plugins ($HOME/.pcp/dstat).

\n

The list of all available plugins can be seen using the\n --list dstat command line option.

\n
\n
\n

When invoked via the pcp(1) command, the\n -h/--host, -a/--archive,\n -O/--origin, -Z/--timezone and several other\n pcp options become indirectly available; refer to PCPIntro(1)\n for a complete description of these options.

إحصائيات الأقراص وأنظمة الملفات

--disk-read
عدد القطاعات التي تم قراءتها من الجهاز
--disk-write
عدد القطاعات التي تم كتابتها إلى الجهاز
--disk-ios
عدد عمليات الإدخال/الإخراج التي تم إصدارها إلى الجهاز
--disk-megs
معدل نقل البيانات (بالميجابايت في الثانية) الذي تم إصداره إلى الجهاز
--disk-sectors
حجم (بالقطاعات) الطلبات التي تم إصدارها إلى الجهاز
--disk-svctm
متوسط وقت الخدمة (بالمللي ثانية) لطلبات الإدخال/الإخراج التي تم إصدارها إلى الجهاز
--disk-tps
عدد التحويلات في الثانية التي تم إصدارها إلى الجهاز
--disk-util
نسبة وقت وحدة المعالجة المركزية التي تم خلالها إصدار طلبات الإدخال/الإخراج إلى الجهاز (استخدام عرض النطاق الترددي للجهاز)
--disk-wait
متوسط الوقت (بالمللي ثانية) لطلبات الإدخال/الإخراج الصادرة إلى الجهاز ليتم خدمتها

تمكين إحصائيات نظام الملفات (الملفات المفتوحة، inodes)
--freespace
المساحة المستخدمة والمتاحة لكل نظام ملفات
