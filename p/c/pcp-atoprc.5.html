NAME

pcp-atoprc - pcp-atop configuration file

DESCRIPTION

The pcp-atoprc configuration file is used to customize the output of the pcp-atop performance analysis tool. It allows users to define the layout of the output lines for both system and process information. Each line definition should be specified on a single line in the rcfile.

OPTIONS

The pcp-atoprc file can contain definitions for various output lines. These definitions start with a keyword followed by a list of column identifiers and their priorities.

The general format for a line definition is:

   keyword   <columnid>:<prio> [<columnid>:<prio> ...]

  • keyword: A predefined keyword that specifies the type of output line being defined.
  • columnid: The symbolic name of a column to be displayed.
  • prio: A positive integer indicating the priority of the column. Higher values have higher priority.

Columns are separated by spaces. They are displayed in the order they are specified, respecting their priorities. Columns that do not fit on the screen are dropped dynamically.

A special columnid, 'BLANKBOX', can be used to insert an empty column, typically with a low priority.

OWN DEFINITION OF OUTPUT LINE

Users can define the layout of process information lines using the keyword 'ownprocline'. This keyword can be selected with the key 'o' or the flag -o.

ownprocline
Defines the layout for process-related output lines. The columnids correspond to columns like 'PID', 'CMD', 'S', etc. The special columnid 'SORTITEM' can be used to display the currently sorted column (CPU%, DSK%, MEM%, or NET%).

Example of a user-defined process line:

   ownprocline   PID:20 PPID:10 SYSCPU:15 USRCPU:15 VGROW:14 VSIZE:12 RGROW:14 RSIZE:12 ST:8 EXC:7 S:11 SORTITEM:18 CMD:20

The following definitions are used internally by pcp-atop as default system lines and can be redefined in the rcfile:

ownsysprcline
Redefinition of the 'PRC' (Process) line:
 
ownsysprcline   PRCSYS:8 PRCUSER:8 BLANKBOX:0 PRCNPROC:7 PRCNZOMBIE:5 PRCCLONES:4 BLANKBOX:0 PRCNNEXIT:6
ownallcpuline
Redefinition of the 'CPU' line for total CPU utilization:
 
ownallcpuline   CPUSYS:8 CPUUSER:7 CPUIRQ:4 BLANKBOX:0 CPUIDLE:5 CPUWAIT:6 BLANKBOX:0 CPUSTEAL:1 CPUGUEST:3
ownonecpuline
Redefinition of the 'CPU' line for individual CPU utilization:
 
ownonecpuline   CPUISYS:8 CPUIUSER:7 CPUIIRQ:4 BLANKBOX:0 CPUIIDLE:5 CPUIWAIT:6 BLANKBOX:0 CPUISTEAL:1 CPUIGUEST:3
owncplline
Redefinition of the 'CPL' (Load Average) line:
 
owncplline   CPLAVG1:4 CPLAVG5:3 CPLAVG15:2 BLANKBOX:0 CPLCSW:6 CPLINTR:5 BLANKBOX:0 CPLNUMCPU:1
ownmemline
Redefinition of the 'MEM' (Memory) line:
 
ownmemline   MEMTOT:2 MEMFREE:5 MEMCACHE:3 MEMDIRTY:1 MEMBUFFER:3 MEMSLAB:3 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0
ownswpline
Redefinition of the 'SWP' (Swap) line:
 
ownswpline   SWPTOT:3 SWPFREE:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 SWPCOMMITTED:5 SWPCOMMITLIM:6
ownpagline
Redefinition of the 'PAG' (Paging) line:
 
ownpagline   PAGSCAN:3 PAGSTALL:1 BLANKBOX:0 PAGSWIN:4 PAGSWOUT:3
owndskline
Redefinition of lines labeled with 'LVM', 'MDD', and 'DSK' (Disk):
 
owndskline   DSKNAME:8 DSKBUSY:7 DSKNREAD:6 DSKNWRITE:6 DSKKBPERRD:4 DSKKBPERWR:4 DSKMBPERSECRD:5 DSKMBPERSECWR:5 DSKAVQUEUE:1 DSKAVIO:5
ownnettrline
Redefinition of the 'NET' line for transport protocols:
 
ownnettrline   NETTRANSPORT:9 NETTCPI:8 NETTCPO:8 NETUDPI:8 NETUDPO:8 NETTCPACTOPEN:6 NETTCPPASVOPEN:5 NETTCPRETRANS:4 NETTCPINERR:3 NETTCPORESET:20 NETUDPNOPORT:1 NETUDPINERR:3
ownnetnetline
Redefinition of the 'NET' line for network protocols (IP):
 
ownnetnetline   NETNETWORK:5 NETIPI:4 NETIPO:4 NETIPFRW:4 NETIPDELIV:4 BLANKBOX:0 BLANKBOX:0 BLANKBOX:0 NETICMPIN:1 NETICMPOUT:1
ownnetifline
Redefinition of the 'NET' line for network interfaces:
 
ownnetifline   NETNAME:8 NETPCKI:7 NETPCKO:7 NETSPEEDIN:6 NETSPEEDOUT:6 NETCOLLIS:3 NETMULTICASTIN:2 NETRCVERR:5 NETSNDERR:5 NETRCVDROP:4 NETSNDDROP:4

These lines are displayed in the order specified by pcp-atop, controlled by the -f flag. In a sufficiently wide window, all defined columns should be visible.
