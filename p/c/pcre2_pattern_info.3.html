pcre2_pattern_info(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_PATTERN_INFO(3) دليل وظائف المكتبة PCRE2_PATTERN_INFO(3)

الاسم

PCRE2 - تعبيرات قياسية متوافقة مع بيرل (واجهة برمجة تطبيقات معدلة)

الملخص

#include <pcre2.h>

int pcre2_pattern_info(const pcre2_code *code, uint32_t what,
   void *where);

الوصف

تُرجع هذه الوظيفة معلومات حول نمط مُترجم. وسيطاتها هي:


code مؤشر إلى نمط تعبير قياسي مُترجم
what ما هي المعلومات المطلوبة
where أين توضع المعلومات

القيم المعترف بها للوسيط what، والمعلومات التي تطلبها هي كالتالي:


PCRE2_INFO_ALLOPTIONS خيارات نهائية بعد الترجمة
PCRE2_INFO_ARGOPTIONS خيارات تم تمريرها إلى pcre2_compile()
PCRE2_INFO_BACKREFMAX رقم أعلى مرجع خلفي
PCRE2_INFO_BSR ما يطابقه \R:
PCRE2_BSR_UNICODE: نهايات أسطر يونيكود
PCRE2_BSR_ANYCRLF: CR، LF، أو CRLF فقط
PCRE2_INFO_CAPTURECOUNT عدد الأنماط الفرعية الملتقطة
PCRE2_INFO_DEPTHLIMIT حد عمق التراجع إذا تم تعيينه،
وإلا PCRE2_ERROR_UNSET
PCRE2_INFO_EXTRAOPTIONS خيارات إضافية تم تمريرها في
سياق الترجمة
PCRE2_INFO_FIRSTBITMAP خريطة بت للوحدات الأولى، أو NULL
PCRE2_INFO_FIRSTCODETYPE نوع معلومات بداية التطابق
0 لم يتم تعيين شيء
1 تم تعيين الوحدة الأولى
2 بداية السلسلة أو بعد سطر جديد
PCRE2_INFO_FIRSTCODEUNIT الوحدة الأولى عندما يكون النوع 1
PCRE2_INFO_FRAMESIZE حجم إطار التراجع
PCRE2_INFO_HASBACKSLASHC يُرجع 1 إذا كان النمط يحتوي على \C
PCRE2_INFO_HASCRORLF يُرجع 1 إذا كانت تطابقات CR أو LF الصريحة
موجودة في النمط
PCRE2_INFO_HEAPLIMIT حد ذاكرة الكومة إذا تم تعيينه،
وإلا PCRE2_ERROR_UNSET
PCRE2_INFO_JCHANGED يُرجع 1 إذا تم استخدام (?J) أو (?-J)
PCRE2_INFO_JITSIZE حجم الكود المترجم JIT، أو 0
PCRE2_INFO_LASTCODETYPE نوع معلومات يجب أن تكون موجودة
0 لم يتم تعيين شيء
1 تم تعيين الوحدة
PCRE2_INFO_LASTCODEUNIT الوحدة الأخيرة عندما يكون النوع 1
PCRE2_INFO_MATCHEMPTY 1 إذا كان النمط يمكن أن يطابق سلسلة
فارغة، 0 بخلاف ذلك
PCRE2_INFO_MATCHLIMIT حد التطابق إذا تم تعيينه،
وإلا PCRE2_ERROR_UNSET
PCRE2_INFO_MAXLOOKBEHIND طول (بالأحرف) لأطول تأكيد للمظهر الخلفي
PCRE2_INFO_MINLENGTH الحد الأدنى لطول السلاسل المتطابقة
PCRE2_INFO_NAMECOUNT عدد الأنماط الفرعية المسماة
PCRE2_INFO_NAMEENTRYSIZE حجم إدخالات جدول الأسماء
PCRE2_INFO_NAMETABLE مؤشر إلى جدول الأسماء
PCRE2_CONFIG_NEWLINE رمز تسلسل السطر الجديد:
PCRE2_NEWLINE_CR
PCRE2_NEWLINE_LF
PCRE2_NEWLINE_CRLF
PCRE2_NEWLINE_ANY
PCRE2_NEWLINE_ANYCRLF
PCRE2_NEWLINE_NUL
PCRE2_INFO_RECURSIONLIMIT مرادف مهمل لـ PCRE2_INFO_DEPTHLIMIT
PCRE2_INFO_SIZE حجم النمط المترجم

إذا كان where يساوي NULL، تُرجع الوظيفة مقدار الذاكرة المطلوبة للمعلومات المطلوبة، بالبايت. بخلاف ذلك، يجب أن يشير الوسيط where إلى عدد صحيح غير موقع بحجم 32 بت (uint32_t)، باستثناء قيم what التالية، عندئذ يجب أن يشير إلى متغير من النوع المعروض:


PCRE2_INFO_FIRSTBITMAP const uint8_t *
PCRE2_INFO_JITSIZE size_t
PCRE2_INFO_NAMETABLE PCRE2_SPTR
PCRE2_INFO_SIZE size_t

ناتج الوظيفة هو صفر عند النجاح أو:


PCRE2_ERROR_NULL الوسيط code هو NULL
PCRE2_ERROR_BADMAGIC لم يتم العثور على "رقم سحري"
PCRE2_ERROR_BADOPTION قيمة what غير صالحة
PCRE2_ERROR_BADMODE تم ترجمة النمط بوضع خاطئ
PCRE2_ERROR_UNSET المعلومات المطلوبة غير مُعينة

هناك وصف كامل لواجهة برمجة تطبيقات PCRE2 الأصلية في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcre2posix.
