pcre2_set_newline(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_NEWLINE(3) دليل الدوال المكتبية PCRE2_SET_NEWLINE(3)

الاسم

PCRE2 - التعبيرات النمطية المتوافقة مع Perl (واجهة برمجة التطبيقات المنقحة)

ملخص

#include <pcre2.h>

int pcre2_set_newline(pcre2_compile_context *ccontext,
  uint32_t value);

الوصف

تقوم هذه الدالة بتعيين اصطلاح السطر الجديد ضمن سياق الترجمة. يحدد هذا أي أحرف (أو تسلسلات أحرف) يتم التعرف عليها كسطور جديدة عند ترجمة الأنماط ومطابقتها. يجب أن يكون الوسيط الثاني أحد القيم التالية:


PCRE2_NEWLINE_CR حرف الإرجاع فقط
PCRE2_NEWLINE_LF حرف تغذية السطر فقط
PCRE2_NEWLINE_CRLF حرف الإرجاع متبوعًا بحرف تغذية السطر فقط
PCRE2_NEWLINE_ANYCRLF أي من الخيارات السابقة
PCRE2_NEWLINE_ANY أي تسلسل سطر جديد يونيكود
PCRE2_NEWLINE_NUL حرف NUL (صفر ثنائي)

تكون النتيجة صفرًا في حالة النجاح أو PCRE2_ERROR_BADDATA إذا كان الوسيط الثاني غير صالح.

يوجد وصف كامل لواجهة برمجة التطبيقات الأصلية لـ PCRE2 في صفحة pcre2api ووصف لواجهة برمجة التطبيقات POSIX في صفحة pcre2posix.
