pcre2_match_data_create_from_pattern(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_MATCH_DATA_CREATE_FROM_PATTERN(3) دليل الدوال المكتبية PCRE2_MATCH_DATA_CREATE_FROM_PATTERN(3)

الاسم

PCRE2 - التعبيرات النمطية المتوافقة مع Perl (واجهة برمجة التطبيقات المعدلة)

الملخص

#include <pcre2.h>

pcre2_match_data *pcre2_match_data_create_from_pattern(
  const pcre2_code *code, pcre2_general_context *gcontext);

الوصف

تقوم هذه الدالة بإنشاء كتلة بيانات مطابقة جديدة للاحتفاظ بنتيجة المطابقة. إذا كان الوسيط الأول NULL، فإن هذه الدالة تُرجع NULL، وإلا فإن الوسيط الأول يشير إلى نمط مجمّع. يتم استخدام عدد الأقواس الملتقطة داخل النمط لحساب عدد أزواج الإزاحات المطلوبة في كتلة بيانات المطابقة. تشكل هذه "متجه الإخراج" (ovector) داخل كتلة بيانات المطابقة، وتُستخدم لتحديد السلسلة النصية المطابقة وأي سلاسل نصية فرعية ملتقطة عند المطابقة باستخدام pcre2_match(). إذا كنت تستخدم pcre2_dfa_match()، التي تستخدم متجه الإخراج بطريقة مختلفة، فيجب عليك استخدام pcre2_match_data_create() بدلاً من هذه الدالة.

يشير الوسيط الثاني إلى سياق عام، لإدارة الذاكرة المخصصة، أو يكون NULL لاستخدام نفس مخصص الذاكرة الذي تم استخدامه للنمط المجمّع. تكون نتيجة الدالة NULL إذا تعذر الحصول على الذاكرة للكتلة أو إذا تم توفير NULL كوسيط أول.

هناك وصف كامل لواجهة برمجة التطبيقات الأصلية لـ PCRE2 في صفحة pcre2api ووصف لواجهة برمجة التطبيقات POSIX في صفحة pcre2posix.
