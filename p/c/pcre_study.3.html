pcre_study(3)

الحزمة: pcre

التراخيص: BSD

PCRE_STUDY(3) دليل وظائف المكتبة PCRE_STUDY(3)

الاسم

PCRE - تعابير نمطية متوافقة مع Perl

الملخص

#include <pcre.h>

pcre_extra *pcre_study(const pcre *code, int options,
     const char **errptr);

pcre16_extra *pcre16_study(const pcre16 *code, int options,
     const char **errptr);

pcre32_extra *pcre32_study(const pcre32 *code, int options,
     const char **errptr);

الوصف

تدرس هذه الدالة نمطًا مُجمَّعًا، لمعرفة ما إذا كان يمكن استخراج معلومات إضافية قد تسرع المطابقة. وسيطاتها هي:


code تعبير نمطي مُجمَّع
options خيارات لـ pcre[16|32]_study()
errptr مكان وضع رسالة الخطأ

إذا نجحت الدالة، فإنها تُرجع قيمة يمكن تمريرها إلى pcre[16|32]_exec() أو pcre[16|32]_dfa_exec() عبر وسيطاتها extra.

إذا أعادت الدالة NULL، فإما أنها لم تتمكن من العثور على أي معلومات إضافية، أو حدث خطأ. يمكنك التمييز بينهما بالنظر إلى قيمة الخطأ. إنها NULL في الحالة الأولى.

الخيار الوحيد هو PCRE_STUDY_JIT_COMPILE. يطلب التجميع في الوقت المناسب (just-in-time) إذا أمكن. إذا تم تجميع PCRE بدون دعم JIT، فسيتم تجاهل هذا الخيار. راجع صفحة pcrejit للحصول على مزيد من التفاصيل.

هناك وصف كامل لواجهة برمجة التطبيقات الأصلية لـ PCRE في صفحة pcreapi ووصف لواجهة برمجة التطبيقات POSIX في صفحة pcreposix.
