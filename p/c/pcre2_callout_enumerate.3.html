pcre2_callout_enumerate(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_COMPILE(3) دليل وظائف المكتبة PCRE2_COMPILE(3)

الاسم

PCRE2 - تعابير نمطية متوافقة مع Perl (واجهة برمجة تطبيقات معدلة)

ملخص

#include <pcre2.h>

int pcre2_callout_enumerate(const pcre2_code *code,
  int (*callback)(pcre2_callout_enumerate_block *, void *),
  void *callout_data);

الوصف

هذه الوظيفة تقوم بمسح نمط منتظم مجمّع واستدعاء وظيفة callback() لكل استدعاء داخل النمط. عائد الوظيفة هو صفر للنجاح وقيمة غير صفرية بخلاف ذلك. الوسائط هي:


code يشير إلى النمط المجمّع
callback وظيفة الاستدعاء
callout_data بيانات المستخدم التي يتم تمريرها إلى وظيفة الاستدعاء

يتم تمرير مؤشر إلى كتلة بيانات إلى وظيفة callback() تحتوي على الحقول التالية (ليس بالضرورة بهذا الترتيب):


uint32_t version رقم إصدار الكتلة
uint32_t callout_number رقم الاستدعاءات المرقمة
PCRE2_SIZE pattern_position إزاحة إلى العنصر التالي في النمط
PCRE2_SIZE next_item_length طول العنصر التالي في النمط
PCRE2_SIZE callout_string_offset إزاحة السلسلة داخل النمط
PCRE2_SIZE callout_string_length طول سلسلة الاستدعاء
PCRE2_SPTR callout_string يشير إلى سلسلة الاستدعاء أو يكون NULL

الوسيط الثاني الذي يتم تمريره إلى وظيفة callback() هو بيانات الاستدعاء التي تم تمريرها إلى pcre2_callout_enumerate(). يجب أن تُرجع وظيفة callback() صفرًا للنجاح. أي قيمة أخرى ستؤدي إلى إيقاف مسح النمط، مع تمرير القيمة كناتج لـ pcre2_callout_enumerate().

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE2 الأصلية في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcre2posix.
