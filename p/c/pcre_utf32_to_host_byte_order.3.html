pcre_utf32_to_host_byte_order(3)

الحزمة: pcre

التراخيص: BSD

PCRE_UTF32_TO_HOST_BYTE_ORDER(3) دليل وظائف المكتبة PCRE_UTF32_TO_HOST_BYTE_ORDER(3)

الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

الملخص

#include <pcre.h>

int pcre32_utf32_to_host_byte_order(PCRE_UCHAR32 *output,
     PCRE_SPTR32 input, int length, int *host_byte_order,
     int keep_boms);

الوصف

هذه الوظيفة، الموجودة فقط في مكتبة 32 بت، تقوم بتحويل سلسلة UTF-32 إلى الترتيب الصحيح للبايت الخاص بالمضيف الحالي، مع الأخذ في الاعتبار أي علامات ترتيب بايت (BOMs) داخل السلسلة. حججها هي:


output مؤشر إلى مخزن الإخراج المؤقت، قد يكون هو نفسه input
input مؤشر إلى مخزن الإدخال المؤقت
length عدد وحدات 32 بت في الإدخال، أو قيمة سالبة لسلسلة
منتهية بصفر
host_byte_order قيمة NULL أو قيمة غير صفرية مشيرة إليها تعني
البدء بترتيب بايت المضيف
keep_boms إذا كانت غير صفرية، يتم نسخ BOMs إلى سلسلة الإخراج

نتيجة الوظيفة هي عدد وحدات 32 بت الموضوعة في مخزن الإخراج المؤقت، بما في ذلك المحدد الصفري إذا كانت السلسلة منتهية بصفر.

إذا كان host_byte_order ليس NULL، فسيتم تعيينه للإشارة إلى ترتيب البايت الحالي في نهاية السلسلة.

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE الأصلية في صفحة pcreapi ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcreposix.
