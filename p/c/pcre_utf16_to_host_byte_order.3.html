pcre_utf16_to_host_byte_order(3)

الحزمة: pcre

التراخيص: BSD

PCRE_UTF16_TO_HOST_BYTE_ORDER(3) دليل الدوال للمكتبة PCRE_UTF16_TO_HOST_BYTE_ORDER(3)

الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

الخلاصة

#include <pcre.h>

int pcre16_utf16_to_host_byte_order(PCRE_UCHAR16 *output,
     PCRE_SPTR16 input, int length, int *host_byte_order,
     int keep_boms);

الوصف

هذه الدالة، الموجودة فقط في مكتبة 16 بت، تقوم بتحويل سلسلة UTF-16 إلى الترتيب الصحيح للنظام المضيف الحالي، مع مراعاة أي علامات ترتيب البايت (BOMs) داخل السلسلة. وسيطاتها هي:


output مؤشر إلى مخزن الإخراج، يمكن أن يكون نفس input
input مؤشر إلى مخزن الإدخال
length عدد وحدات 16 بت في الإدخال، أو قيمة سالبة لـ
سلسلة منتهية بصفر
host_byte_order قيمة NULL أو قيمة غير صفرية مشيرة إليها تعني
البدء بترتيب بايت المضيف
keep_boms إذا كانت غير صفرية، يتم نسخ علامات BOM إلى سلسلة الإخراج

نتيجة الدالة هي عدد وحدات 16 بت التي تم وضعها في مخزن الإخراج، بما في ذلك المنتهي الصفري إذا كانت السلسلة منتهية بصفر.

إذا لم يكن host_byte_order NULL، فسيتم تعيينه للإشارة إلى ترتيب البايت الحالي في نهاية السلسلة.
