pcp-mpstat(1)

PCP-MPSTAT(1) دليل الأوامر العامة PCP-MPSTAT(1)

الاسم

pcp-mpstat - تقرير عن إحصائيات وحدة المعالجة المركزية والتعطيل المتعلقة بها.

الملخص

pcp [خيارات pcp] mpstat [ -A ] [ -u ] [ -V ] [ -I { SUM | CPU | SCPU | ALL } ] [ -P { cpu1,cpu2 [,...] | ON | ALL } ] [ -t interval ] [ -s count ] [ -a archive ] [ -? ]

الوصف

يقوم أمر pcp-mpstat بالكتابة إلى المخرجات القياسية لأنشطة كل معالج متاح، حيث يكون المعالج 0 هو الأول. إذا لم يتم تحديد أي نشاط/خيار، فإن التقرير الافتراضي هو تقرير استخدام وحدة المعالجة المركزية (-u).

يحدد المعلم interval مقدار الوقت بالثواني بين كل تقرير. الافتراضي هو ثانية واحدة. تحدد قيمة المعلم count عدد العينات التي سيتم عرضها. الافتراضي هو مستمر.

الخيارات

عند الاستدعاء عبر أمر pcp(1)، تصبح خيارات pcp الإضافية -h/--host، -a/--archive، -O/--origin، -s/--samples، -t/--interval، -Z/--timezone والعديد من الخيارات الأخرى متاحة بشكل غير مباشر؛ راجع PCPIntro(1) للحصول على وصف كامل لهذه الخيارات.

الخيارات الإضافية لسطر الأوامر المتاحة لـ pcp-mpstat هي:

-A
هذا الخيار يعادل تحديد -u -I ALL -P ALL
-I { SUM | CPU | SCPU | ALL }
تقرير إحصائيات المقاطعة.
مع الكلمة المفتاحية SUM، يقوم الأمر pcp-mpstat بالإبلاغ عن العدد الإجمالي للمقاطعات لكل معالج. القيم التالية معروضة:

CPU

رقم المعالج. الكلمة المفتاحية all تشير إلى أن الإحصائيات محسوبة كمتوسطات بين جميع المعالجات.

intr/s

عرض العدد الإجمالي للمقاطعات المستلمة في الثانية بواسطة وحدة المعالجة المركزية أو وحدات المعالجة المركزية.

مع الكلمة المفتاحية CPU، يتم عرض عدد كل مقاطعة فردية مستلمة في الثانية بواسطة وحدة المعالجة المركزية أو وحدات المعالجة المركزية. المقاطعات هي تلك الموجودة ضمن شجرة مقاييس kernel.percpu.interrupts.

مع الكلمة المفتاحية SCPU، يتم عرض عدد كل مقاطعة برمجية فردية مستلمة في الثانية بواسطة وحدة المعالجة المركزية أو وحدات المعالجة المركزية. المقاطعات البرمجية هي تلك الموجودة ضمن شجرة kernel.percpu.softirqs.

الكلمة المفتاحية ALL تعادل تحديد جميع الكلمات المفتاحية المذكورة أعلاه، وبالتالي يتم عرض جميع إحصائيات المقاطعات.

-P { cpu1,cpu2[,...] | ON | ALL }
تحديد رقم المعالج الذي سيتم الإبلاغ عن الإحصائيات الخاصة به. cpu1 و cpu2 هي أرقام المعالجات. يمكن توفير قائمة بأرقام المعالجات المطلوبة. لاحظ أن المعالج 0 هو المعالج الأول.

الكلمة المفتاحية ON تشير إلى أن الإحصائيات سيتم الإبلاغ عنها لكل معالج متصل بالشبكة، بينما تشير الكلمة المفتاحية ALL إلى أنه سيتم الإبلاغ عن الإحصائيات لجميع المعالجات.

-u
تقرير استخدام وحدة المعالجة المركزية. القيم التالية معروضة:

CPU

رقم المعالج. الكلمة المفتاحية ALL تشير إلى أن الإحصائيات محسوبة كمتوسطات بين جميع المعالجات.

%usr

عرض النسبة المئوية لاستخدام وحدة المعالجة المركزية التي حدثت أثناء التنفيذ على مستوى المستخدم (التطبيق).

%nice

عرض النسبة المئوية لاستخدام وحدة المعالجة المركزية التي حدثت أثناء التنفيذ على مستوى المستخدم مع أولوية لطيفة (nice).

%sys

عرض النسبة المئوية لاستخدام وحدة المعالجة المركزية التي حدثت أثناء التنفيذ على مستوى النظام (النواة). لاحظ أن هذا لا يشمل الوقت المستغرق في خدمة مقاطعات الأجهزة والبرامج.

%iowait

عرض النسبة المئوية للوقت الذي كانت فيه وحدة المعالجة المركزية أو وحدات المعالجة المركزية خاملة بينما كان النظام لديه طلب إدخال/إخراج معلق للقرص.

%irq

عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لخدمة مقاطعات الأجهزة.

%soft

عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لخدمة مقاطعات البرامج.

%steal

عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية الظاهرية أو وحدات المعالجة المركزية الظاهرية في انتظار غير طوعي بينما كانت آلة المحاكاة تخدم معالجًا افتراضيًا آخر.

%guest

عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لتشغيل معالج افتراضي.

%gnice

عرض النسبة المئوية للوقت الذي استغرقته وحدة المعالجة المركزية أو وحدات المعالجة المركزية لتشغيل ضيف ذي أولوية لطيفة (niced).

%idle

عرض النسبة المئوية للوقت الذي كانت فيه وحدة المعالجة المركزية أو وحدات المعالجة المركزية خاملة ولم يكن لدى النظام طلب إدخال/إخراج معلق للقرص.

ملاحظة: في الأجهزة SMP، يكون المعالج الذي لا يحتوي على أي نشاط على الإطلاق معالجًا معطلاً (خارج الخدمة).

-s  N , --samples = N
تعيين عدد العينات التي سيتم عرضها. نظرًا لأن العينة الأولى تُستخدم للتحويل النسبي لبعض المقاييس، فإن العدد الإجمالي للعينات المبلغ عنها أقل بواحد من N. الافتراضي هو مستمر.
-t DELTA , --interval = DELTA
تعيين الفاصل الزمني بين عينتين. الافتراضي هو ثانية واحدة.
-a FILE , --archive = FILE
يتسبب في استخدام pcp-mpstat للأرشيف المحدد بدلاً من الاتصال بـ PMCD. الوسيطة لـ -a هي قائمة أسماء مفصولة بفواصل، كل منها قد يكون الاسم الأساسي للأرشيف أو اسم دليل يحتوي على أرشيف واحد أو أكثر.
-V , --version
طباعة رقم الإصدار ثم الخروج.
-? , --help
طباعة رسالة الاستخدام ثم الخروج.

أمثلة

pcp-mpstat -t 2 -s 5

عرض أربعة تقارير للإحصائيات العامة بين جميع المعالجات على فترات زمنية مدتها ثانيتان.

pcp mpstat -P ALL -t 2 -s 5

عرض أربعة تقارير للإحصائيات لجميع المعالجات على فترات زمنية مدتها ثانيتان.

ملاحظات

pcp-mpstat مستوحى من أمر mpstat(1) ويهدف إلى التوافق مع سطر الأوامر والمخرجات الخاصة به.

البيئة

يمكن استخدام متغيرات البيئة TZ و LC_TIME لتجاوز تنسيق عرض التاريخ الافتراضي لـ pcp-mpstat.

بيئة PCP

تُستخدم متغيرات البيئة التي تبدأ بالبادئة PCP_ لتهيئة أسماء الملفات والأدلة المستخدمة بواسطة PCP. في كل تثبيت، يحتوي الملف /etc/pcp.conf على القيم المحلية لهذه المتغيرات. قد يُستخدم المتغير $PCP_CONF لتحديد ملف تكوين بديل، كما هو موضح في pcp.conf(5).

بالنسبة لمتغيرات البيئة التي تؤثر على أدوات PCP، راجع pmGetOptions(3).

انظر أيضًا

PCPIntro(1)، pcp(1)، mpstat(1), pmParseInterval(3)، pmTraversePMNS(3) و environ(7).
