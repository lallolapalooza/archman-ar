pcre_get_stringnumber(3)

الحزمة: pcre

التراخيص: BSD

PCRE_GET_STRINGNUMBER(3) دليل وظائف المكتبة PCRE_GET_STRINGNUMBER(3)

الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

الملخص

#include <pcre.h>

int pcre_get_stringnumber(const pcre *code,
     const char *name);

int pcre16_get_stringnumber(const pcre16 *code,
     PCRE_SPTR16 name);

int pcre32_get_stringnumber(const pcre32 *code,
     PCRE_SPTR32 name);

الوصف

تقوم هذه الدالة المساعدة بإيجاد رقم قوس التقاط سلسلة فرعية مسماة في نمط مجمّع. وسيطاتها هي:


code تعبير نمطي مجمّع
name الاسم المطلوب رقمه

إن عائد الدالة هو رقم القوس إذا تم العثور على الاسم، أو PCRE_ERROR_NOSUBSTRING خلاف ذلك. عندما تكون الأسماء المكررة مسموحة (تم تعيين PCRE_DUPNAMES)، فإنه ليس من المحدد أي من الأرقام سيتم إرجاعه بواسطة pcre[16|32]_get_stringnumber(). يمكنك الحصول على القائمة الكاملة عن طريق استدعاء pcre[16|32]_get_stringtable_entries().

هناك وصف كامل لواجهة برمجة تطبيقات PCRE الأصلية في صفحة pcreapi ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcreposix.
