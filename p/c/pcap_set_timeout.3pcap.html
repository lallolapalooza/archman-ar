الحزمة: libpcap

التراخيص: BSD-3-Clause

PCAP_SET_TIMEOUT(3PCAP) PCAP_SET_TIMEOUT(3PCAP)

الاسم

pcap_set_timeout - ضبط مهلة مخزن الحزم المؤقت لمقبض التقاط غير نشط بعد

الملخص

#include <pcap/pcap.h>
int pcap_set_timeout(pcap_t *p, int to_ms);

الوصف

تقوم pcap_set_timeout() بضبط مهلة مخزن الحزم المؤقت التي سيتم استخدامها في مقبض التقاط عند تنشيط المقبض إلى to_ms، والتي تكون بوحدات المللي ثانية. (انظر pcap(3PCAP) لشرح مهلة مخزن الحزم المؤقت.)

السلوك، إذا لم يتم تحديد المهلة، غير معرف، كما هو الحال بالنسبة للسلوك إذا تم تعيين المهلة إلى صفر أو قيمة سالبة. نوصي دائمًا بضبط المهلة على قيمة غير صفرية ما لم يتم تعيين وضع فوري، وفي هذه الحالة تكون المهلة ليس لها تأثير.

قيمة الإرجاع

تُرجع pcap_set_timeout() 0 عند النجاح أو PCAP_ERROR_ACTIVATED إذا تم استدعاؤها على مقبض التقاط تم تنشيطه بالفعل.

انظر أيضا

pcap_create(3PCAP), pcap_activate(3PCAP), pcap_set_immediate_mode(3PCAP)
