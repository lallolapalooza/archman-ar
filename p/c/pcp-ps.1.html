PCP-PS(1) دليل الأوامر العامة PCP-PS(1)

الاسم

pcp-ps - تقرير إحصائيات عمليات لينكس.

السيناريو

pcp [خيارات pcp] ps [-e] [-U [اسم المستخدم]] [-V --version] [-c اسم الأمر] [-P pid1,pid2..] [-p pid1,pid2..] [-o col1,col2... أو ALL] [-Z المنطقة الزمنية] [-z] [-?]

الوصف

يُستخدم الأمر pcp-ps لمراقبة العمليات الفردية قيد التشغيل على النظام. باستخدام خيارات مختلفة، يساعد المستخدم على رؤية معلومات مفيدة متعلقة بالعمليات. تتضمن هذه المعلومات نسبة استخدام وحدة المعالجة المركزية، واستخدام الذاكرة والمكدس، والجدولة، والأولوية. افتراضيًا، يقدم pcp-ps بيانات حية للمضيف المحلي.

خيارات

عند الاستدعاء عبر الأمر pcp(1)، تتوفر خيارات pcp الأخرى مثل -h/--host، -O/--origin، -t/--interval، -Z/--timezone؛ ارجع إلى PCPIntro(1) لوصف كامل لهذه الخيارات.

الخيارات الإضافية لسطر الأوامر المتاحة لـ pcp-ps هي:

-e
عرض جميع العمليات.
PID معرف العملية.
TTY المحطة الطرفية المرتبطة بالعملية.
TIME إجمالي وقت وحدة المعالجة المركزية بتنسيق [DD-]hh:mm:ss (الوقت=TIME).
CMD اسم المهمة مع وسيطاتها الكاملة.
-c [اسم الأمر]
عرض اسم الأمر الحقيقي للمهام التي تتم مراقبتها بدلاً من UID. إذا تم تحديد اسم الأمر، فسيتم عرض المهام التي تنتمي إلى الأمر المحدد فقط.
-U [اسم المستخدم], --user-name[=اسم المستخدم]
عرض اسم المستخدم الحقيقي للمهام التي تتم مراقبتها بدلاً من UID. إذا تم تحديد اسم المستخدم، فسيتم عرض المهام التي تنتمي إلى المستخدم المحدد فقط.
-V, --version
طباعة رقم الإصدار ثم الخروج.
-p pid1,pid2.., --pid-list=pid1,pid2..
عرض العمليات ذات PIDs المدرجة فقط.
-P ppid1,ppid2.., --ppid-list=ppid1,ppid2..
عرض العمليات ذات PPIDs المدرجة فقط.
وهي عبارة عن وسيط واحد في شكل قائمة مفصولة بمسافات أو فواصل، توفر طريقة لتحديد أعمدة الإخراج الفردية.

الوسائط لـ -o هي:

COL HEADER الوصف
%cpu %CPU استخدام وحدة المعالجة المركزية للعملية
%mem %MEM الذاكرة الفعلية على الجهاز معبر عنها كنسبة مئوية
start START وقت بدء الأمر
time TIME إجمالي وقت وحدة المعالجة المركزية، المستخدم + النظام
cls CLS فئة جدولة العملية.
cmd CMD انظر اسم المهمة. (اسم مستعار args، command).
args COMMAND لعرض اسم البرنامج الكامل مع وسيطاته (استخدم في الموضع الأخير في قائمة -o لعرض الأمر بالكامل)
pid PID معرف العملية
ppid PPID معرف العملية الأصلية
pri PRI أولوية العملية
state S انظر s
rss RSS الذاكرة الفعلية غير المتبادلة التي استخدمتها المهمة
rtprio RTPRIO أولوية الوقت الحقيقي
pname Pname اسم العملية
tty TT وحدة التحكم الطرفية (المحطة)
uid UID انظر euid
uname USER انظر euser
vsize VSZ انظر vsz
wchan WCHAN اسم وظيفة النواة التي تكون العملية فيها نائمة

محددات التنسيق القياسية

فيما يلي الكلمات الرئيسية المختلفة التي يمكن استخدامها للتحكم في تنسيق الإخراج (على سبيل المثال، مع الخيار -o) أو لفرز العمليات المحددة.

على سبيل المثال: pcp-ps -o pid,user,args

CODE HEADER الوصف
pid PID رقم يمثل معرف العملية
%cpu %CPU استخدام وحدة المعالجة المركزية للعملية بتنسيق "##.#". حاليًا، هو الوقت المستخدم لوحدة المعالجة المركزية مقسومًا على الوقت الذي كانت فيه العملية قيد التشغيل (نسبة وقت وحدة المعالجة المركزية/الوقت الفعلي)، معبرًا عنه كنسبة مئوية.
%mem %MEM نسبة مئوية من حجم مجموعة العمليات المقيمة إلى الذاكرة الفعلية في الجهاز، معبر عنها كنسبة مئوية.
args COMMAND الأمر مع جميع وسيطاته كسلسلة نصية. قد تظهر التعديلات على الوسائط. قد يحتوي الإخراج في هذا العمود على مسافات. العملية المسجلة <defunct> هي شبه ميتة، تنتظر أن يتم تدميرها بالكامل بواسطة العملية الأصلية. أحيانًا قد لا تكون وسائط العملية متاحة؛ عندما يحدث هذا، سيتم طباعة اسم الملف التنفيذي بين قوسين.
class CLS فئة جدولة العملية. القيم الممكنة للحقل هي: - لا يتم الإبلاغ عنها TS SCHED_OTHER FF SCHED_FIFO RR SCHED_RR B SCHED_BATCH ISO SCHED_ISO IDL SCHED_IDLE DLN SCHED_DEADLINE ؟ قيمة غير معروفة.
s S عرض حالة الحد الأدنى. انظر أيضًا state إذا كنت تريد عرض معلومات إضافية.
euid EUID معرف المستخدم الفعال.
vsz VSZ حجم الذاكرة الافتراضية للعملية بوحدات KiB (1024 بايت). يتم حاليًا استبعاد عمليات تعيين الأجهزة؛ هذا عرضة للتغيير.
euser EUSER اسم المستخدم الفعال. سيكون هذا معرف المستخدم النصي، إذا كان بالإمكان الحصول عليه ويسمح عرض الحقل بذلك، أو تمثيل عشري بخلاف ذلك.
All N/A يعرض هذا الخيار USER، PID، PPID، PRI، %CPU، %MEM، VSZ، RSS، S، START، TIME، WCHAN و COMMAND.
-Z المنطقة الزمنية, --timezone=المنطقة الزمنية
افتراضيًا، يقدم pcp-ps الوقت المحلي حسب المنطقة الزمنية المحلية على النظام الذي يعمل عليه pcp-ps. يغير الخيار -Z المنطقة الزمنية إلى المنطقة الزمنية بالتنسيق لمتغير البيئة TZ كما هو موضح في environ(7).
-z , --hostzone
تغيير المنطقة الزمنية للإبلاغ إلى المنطقة الزمنية المحلية على المضيف الذي يتم.
