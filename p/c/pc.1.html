pc — a simple program to display the content of a file.

Synopsis

pc [OPTION]... [FILE]...

Description

The pc command is a straightforward utility designed to display the content of one or more files. It reads each specified file and outputs its contents to the standard output. If no files are specified, it reads from standard input.

Options

This command does not support any options.

Examples

To display the content of a file named myfile.txt: 

pc myfile.txt

To display the content of multiple files: 

pc file1.txt file2.txt

To display content piped from another command (e.g., ls): 

ls -l | pc
