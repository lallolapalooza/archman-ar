PCP2XML(1) دليل الأوامر العامة PCP2XML(1)

الاسم

pcp2xml - مصدر مقاييس pcp إلى xml

الملخص

pcp2xml [-5CGHIjLmnrRvVxXz?] [-4 action] [-8|-9 limit] [-a archive] [-A align] [--archive-folio folio] [-b|-B space-scale] [-c config] [--container container] [-D debug] [--daemonize] [-e derived] [-f format] [-F outfile] [-h host] [-i instances] [-J rank] [-K spec] [-N predicate] [-O origin] [-P|-0 precision] [-q|-Q count-scale] [-s samples] [-S starttime] [-t interval] [-T endtime] [-y|-Y time-scale] [-Z timezone] metricspec [...]

الوصف

pcp2xml هو أداة تصدير مقاييس أداء قابلة للتخصيص من PCP إلى XML. يمكن تحديد أي مقياس أداء متاح، سواء كان مباشرًا أو مؤرشفًا، نظامًا و/أو تطبيقًا، للتصدير باستخدام خيارات سطر الأوامر أو ملف تكوين.

pcp2xml هو قريب وثيق لـ pmrep(1). ارجع إلى pmrep(1) لوصف metricspec المقبول في سطر أوامر pcp2xml. انظر pmrep.conf(5) لوصف صيغة ملف تكوين pcp2xml.conf. تصف هذه الصفحة خيارات pcp2xml المحددة واختلافات ملف التكوين مع pmrep.conf(5). يسرد pmrep(1) أيضًا بعض أمثلة الاستخدام التي ينطبق معظمها على pcp2xml أيضًا.

فقط خيارات سطر الأوامر المدرجة في هذه الصفحة مدعومة، والخيارات الأخرى المتاحة لـ pmrep(1) غير مدعومة.

تتجاوز الخيارات عبر قيم البيئة (انظر pmGetOptions(3)) القيم الافتراضية الداخلية المقابلة (إن وجدت). تتجاوز خيارات ملف التكوين المتغيرات البيئية المقابلة (إن وجدت). تتجاوز خيارات سطر الأوامر خيارات ملف التكوين المقابلة (إن وجدت).

ملف التكوين

يستخدم pcp2xml ملف تكوين بصيغة موصوفة في pmrep.conf(5). الخيارات التالية مشتركة مع pmrep.conf: version، source، speclocal، derived، header، globals، samples، interval، type، type_prefer، ignore_incompat، names_change، instances، live_filter، rank، limit_filter، limit_filter_force، invert_filter، predicate، omit_flat، include_labels، precision، precision_force، count_scale، count_scale_force، space_scale، space_scale_force، time_scale، time_scale_force. يتم التعرف على بقية خيارات pmrep.conf ولكن يتم تجاهلها للتوافق.

خيارات pcp2xml المحددة

extended (boolean)

اكتب معلومات موسعة حول المقاييس. الخيار المقابل لسطر الأوامر هو -x. افتراضياتها no.

everything (boolean)

اكتب كل ما هو معروف عن المقاييس، بما في ذلك معرفات PCP الداخلية. ومع ذلك، يتم تجاهل التسميات للتوافق القديم. قم بتمكين include_labels لتضمينها أيضًا. الخيار المقابل لسطر الأوامر هو -X. افتراضياته no.

خيارات

الخيارات المتاحة لسطر الأوامر هي:

-0 precision, --precision-force=precision
مثل -P ولكن هذا الخيار سيقوم بتجاوز المواصفات لكل مقياس.
-4 action, --names-change=action
حدد الإجراء المطلوب اتخاذه عند تلقي حدث تغيير أسماء المقاييس أثناء أخذ العينات. تحدث هذه الأحداث عندما يكتشف PMDA مقاييس جديدة بعد بدء التشغيل، ويبلغ الأدوات العميلة قيد التشغيل مثل pcp2xml. القيم الصالحة لـ action هي update (تحديث المقاييس التي يتم أخذ عينات منها)، ignore (لا تفعل شيئًا - السلوك الافتراضي) و abort (إنهاء البرنامج إذا حدث مثل هذا الحدث).
-5, --ignore-unknown
تجاهل بصمت أي اسم مقياس لا يمكن حله. يجب العثور على مقياس واحد على الأقل لبدء الأداة.
-8 limit, --limit-filter=limit
حد النتائج للحالات التي تكون فيها القيم أعلى/أقل من limit. سيشمل الرقم الصحيح الإيجابي الحالات التي تكون فيها القيم عند الحد أو فوقه في التقارير. سيشمل الرقم الصحيح السلبي الحالات التي تكون فيها القيم عند الحد أو أقل منه في التقارير. قيمة الصفر لا تقوم بتصفية الحدود. هذا الخيار لن يتجاوز المواصفات المحتملة لكل مقياس. انظر أيضًا -J و -N.
-9 limit, --limit-filter-force=limit
مثل -8 ولكن هذا الخيار سيقوم بتجاوز المواصفات لكل مقياس.
-a archive, --archive=archive
يتم استرداد قيم مقاييس الأداء من مجموعة ملفات أرشيف Performance Co-Pilot (PCP) التي تم تحديدها بواسطة الوسيط archive، وهو قائمة بأسماء مفصولة بفواصل، قد يكون كل منها الاسم الأساسي للأرشيف أو اسم دليل يحتوي على أرشيف واحد أو أكثر.
-A align, --align=align
فرض محاذاة العينة الأولية على حدود وحدة زمن طبيعية align. ارجع إلى PCPIntro(1) لوصف كامل لصيغة align.
--archive-folio=folio
قراءة أرشيفات مصدر المقاييس من أرشيف PCP folio الذي تم إنشاؤه بواسطة أدوات مثل pmchart(1) أو، بشكل أقل تكرارًا، يدويًا باستخدام mkaf(1).
-b scale, --space-scale=scale
وحدة/مقياس لمقاييس المساحة (البايت)، القيم المحتملة تشمل bytes، Kbytes، KB، Mbytes، MB، وهكذا. هذا الخيار لن يتجاوز المواصفات المحتملة لكل مقياس. انظر أيضًا pmParseUnitsStr(3).
-B scale, --space-scale-force=scale
مثل -b ولكن هذا الخيار سيقوم بتجاوز المواصفات لكل مقياس.
-c config, --config=config
تحديد ملف أو دليل التكوين config المراد استخدامه. في حال كان config دليلًا، سيتم تضمين جميع الملفات الموجودة فيه التي تنتهي بـ .conf. الافتراضي هو الأول الذي تم العثور عليه من: ./pcp2xml.conf، $HOME/.pcp2xml.conf، $HOME/pcp/pcp2xml.conf، و $PCP_SYSCONF_DIR/pcp2xml.conf. للتفاصيل، انظر القسم أعلاه و pmrep.conf(5).
--container=container
جلب مقاييس الأداء من container المحدد، سواء كان محليًا أو بعيدًا (انظر -h).
-C, --check
الخروج قبل الإبلاغ عن أي قيم، ولكن بعد تحليل التكوين والمقاييس وطباعة الرؤوس المحتملة.
--daemonize
تشغيل كعملية daemon عند البدء.
-e derived, --derived=derived
تحديد مقاييس الأداء المشتقة. إذا بدأ derived بشرطة مائلة (``/'') أو بنقطة (``.'') فسيتم تفسيره كملف تكوين مقاييس PCP المشتقة، وإلا فسيتم تفسيره كتعابير مقاييس مشتقة مفصولة بفواصل أو فاصلات منقوطة. لوصف كامل للمقاييس المشتقة وملفات تكوين مقاييس PCP المشتقة انظر pmLoadDerivedConfig(3) و pmRegisterDerived(3). بدلاً من ذلك، باستخدام صيغة تكوين pmrep.conf(5)

OPTIONS

-c config, --config config
Specify the name and location of the configuration file. If the value does not contain a slash, it is treated as a base name, and searched for in the standard configuration file directories. See FILES for more details.
-D debug-options, --debug debug-options
Enable extra debugging output on stderr to assist with problem diagnosis. The set of debugging options is specified as a comma-separated list. See DEBUGGING OPTIONS.
-h, --host hostname
Specify the PCP host to connect to. By default, this is the local host.
-H, --headers
Print headers for the exported data.
-i indent, --indent indent
Set the number of spaces to use for XML indentation. Defaults to 4 spaces.
-j, --json
Output JSON instead of XML. This option implies --raw.
-l, --loop
Output data in a loop until interrupted. Useful for live data streams.
-n pmnsfile, --nss pmnsfile
Specify an alternative PMNS hierarchy. See pmns(5) for more details.
-o origin, --origin origin
Set the origin for all reported metrics. Defaults to the current time.
-p port, --port port
Specify the port number for the PCP collector to connect to. Defaults to 44321.
-P precision, --precision precision
Set the number of decimal places for floating point values. Defaults to 6.
-r, --raw
Do not convert metric values to text. This is useful for machine-readable output and when the consumer knows how to interpret the raw values.
-s samples, --samples samples
Specify the number of samples to retrieve. Defaults to 1.
-t interval, --interval interval
Specify the sample interval in seconds. This can be an integer or a floating point value. Defaults to 1 second.
-T timezone, --timezone timezone
Set the timezone for the reported time values. If this option is not specified, ISO 8601 -style UTC offsets are used (so something like -Z EST+5 will become UTC-5).
-?, --help
Display usage message and exit.

FILES

pcp2xml.conf
pcp2xml configuration file (see -c)
$PCP_SYSCONF_DIR/pmrep/*.conf
system provided default pmrep configuration files

PCP ENVIRONMENT

Environment variables with the prefix PCP_ are used to parameterize the file and directory names used by PCP. On each installation, the file /etc/pcp.conf contains the local values for these variables. The $PCP_CONF variable may be used to specify an alternative configuration file, as described in pcp.conf(5).

For environment variables affecting PCP tools, see pmGetOptions(3).

Of particular note, PCP_DISCRETE_ONCE can be set to ensure that discrete metric values are reported only once, unless they change at some point.

DEBUGGING OPTIONS

The -D or --debug option enables the output of additional diagnostics on stderr to help triage problems, although the information is sometimes cryptic and primarily intended to provide guidance for developers rather end-users. debug is a comma separated list of debugging options; use pmdbg(1) with the -l option to obtain a list of the available debugging options and their meaning.
