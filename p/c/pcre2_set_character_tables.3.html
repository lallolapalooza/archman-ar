pcre2_set_character_tables(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_CHARACTER_TABLES(3) دليل الدوال المكتبية PCRE2_SET_CHARACTER_TABLES(3)

الاسم

PCRE2 - تعبيرات نمطية متوافقة مع Perl (واجهة برمجة تطبيقات منقحة)

ملخص

#include <pcre2.h>

int pcre2_set_character_tables(pcre2_compile_context *ccontext,
  const uint8_t *tables);

الوصف

هذه الدالة تعين مؤشرًا إلى جداول أحرف مخصصة داخل سياق التجميع. يجب أن يشير الوسيط الثاني إلى مجموعة من جداول أحرف PCRE2 أو أن يكون NULL لطلب الجداول الافتراضية. النتيجة دائمًا صفر. يمكن إنشاء جداول الأحرف عن طريق استدعاء pcre2_maketables() أو عن طريق تشغيل أمر الصيانة pcre2_dftables في الوضع الثنائي (راجع وثائق pcre2build).

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE2 الأصلية في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcre2posix.
