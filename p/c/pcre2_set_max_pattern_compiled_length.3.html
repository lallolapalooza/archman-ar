pcre2_set_max_pattern_compiled_length(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_MAX_PATTERN_COMPILED_LENGTH(3) دليل الوظائف المكتبية PCRE2_SET_MAX_PATTERN_COMPILED_LENGTH(3)

الاسم

PCRE2 - تعبيرات نمطية متوافقة مع Perl (واجهة برمجة تطبيقات منقحة)

ملخص

#include <pcre2.h>

int pcre2_set_max_pattern_compiled_length(
  pcre2_compile_context *ccontext, PCRE2_SIZE value);

الوصف

تقوم هذه الوظيفة بتعيين، في سياق التحويل البرمجي، الحد الأقصى للحجم (بالبايت) للذاكرة المطلوبة للاحتفاظ بالنسخة المترجمة من نمط يستخدم هذا السياق. النتيجة هي دائمًا صفر. إذا احتاج نمط تم تمريره إلى pcre2_compile() والذي يشير إلى هذا السياق إلى المزيد من الذاكرة، فسيتم إنشاء خطأ. الافتراضي هو أكبر رقم يمكن لمتغير PCRE2_SIZE الاحتفاظ به، وهو غير محدود فعليًا.

يوجد وصف كامل لواجهة برمجة تطبيقات Native API الخاصة بـ PCRE2 في الصفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX API في الصفحة pcre2posix.
