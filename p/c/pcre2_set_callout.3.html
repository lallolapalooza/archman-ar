pcre2_set_callout(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_CALLOUT(3) دليل المكتبة PCRE2_SET_CALLOUT(3)

الاسم

PCRE2 - تعابير نمطية متوافقة مع Perl (واجهة برمجة تطبيقات معدلة)

الملخص

#include <pcre2.h>

int pcre2_set_callout(pcre2_match_context *mcontext,
  int (*callout_function)(pcre2_callout_block *),
  void *callout_data);

الوصف

تقوم هذه الدالة بتعيين حقول الاستدعاء في سياق المطابقة (الحجة الأولى). تحدد الحجة الثانية دالة استدعاء، والحجة الثالثة عنصر بيانات غير شفاف يتم تمريره إليها. نتيجة هذه الدالة هي دائما صفر.

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE2 الأصلية في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcre2posix.
