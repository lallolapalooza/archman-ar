pcre2_pattern_convert(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_PATTERN_CONVERT(3) دليل وظائف المكتبة PCRE2_PATTERN_CONVERT(3)

الاسم

PCRE2 - تعبيرات نمطية متوافقة مع Perl (واجهة برمجة تطبيقات محدثة)

ملخص

#include <pcre2.h>

int pcre2_pattern_convert(PCRE2_SPTR pattern, PCRE2_SIZE length,
  uint32_t options, PCRE2_UCHAR **buffer,
  PCRE2_SIZE *blength, pcre2_convert_context *cvcontext);

الوصف

هذه الدالة جزء من مجموعة وظائف تحويل الأنماط التجريبية. تقوم بتحويل نمط خارجي (على سبيل المثال، نمط glob) إلى نمط تعبير نمطي PCRE2. وسائطها هي:


pattern النمط الخارجي
length طول النمط المدخل أو PCRE2_ZERO_TERMINATED
options بتات الخيارات
buffer مؤشر إلى مؤشر إلى مخزن الإخراج المؤقت، أو NULL
blength مؤشر إلى حقل طول الإخراج
cvcontext مؤشر إلى سياق تحويل أو NULL

يتم إرجاع طول النمط المحول (باستثناء الصفر المنتهي) عبر blength. إذا كان buffer يشير إلى NULL، فإن الدالة تعيد طول الإخراج فقط. إذا كان buffer يشير إلى مؤشر NULL، فسيتم الحصول على ذاكرة مؤقتة للنمط المحول، باستخدام المخصص في السياق إذا كان موجودًا (أو malloc() بدلاً من ذلك)، وسيتم تحديث الحقل الذي يشير إليه buffer. إذا كان buffer يشير إلى حقل غير NULL، فيجب أن يشير ذلك إلى مخزن مؤقت طوله موجود في المتغير الذي يشير إليه blength. يتم تحديث هذه القيمة.

بتات الخيارات هي:


PCRE2_CONVERT_UTF المدخل هو UTF
PCRE2_CONVERT_NO_UTF_CHECK لا تتحقق من صحة UTF
PCRE2_CONVERT_POSIX_BASIC حول نمط POSIX الأساسي
PCRE2_CONVERT_POSIX_EXTENDED حول نمط POSIX الموسع
PCRE2_CONVERT_GLOB ) حول
PCRE2_CONVERT_GLOB_NO_WILD_SEPARATOR ) أنواع مختلفة
PCRE2_CONVERT_GLOB_NO_STARSTAR ) من glob

القيمة المرجعة من pcre2_pattern_convert() هي صفر عند النجاح أو رمز خطأ PCRE2 غير صفري.

يتم وصف وظائف تحويل الأنماط في وثائق pcre2convert.
