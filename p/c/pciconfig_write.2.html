pciconfig_read(2) دليل استدعاءات النظام pciconfig_read(2)

الاسم

pciconfig_read, pciconfig_write, pciconfig_iobase - معالجة معلومات جهاز pci

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <pci.h>
int pciconfig_read(unsigned long bus, unsigned long dfn,
                   unsigned long off, unsigned long size,
                   unsigned char *buf);
int pciconfig_write(unsigned long bus, unsigned long dfn,
                   unsigned long off, unsigned long size,
                   unsigned char *buf);
int pciconfig_iobase(int which, unsigned long bus,
                   unsigned long devfn);

الوصف

يتم بالفعل معالجة معظم التفاعل مع أجهزة PCI بواسطة طبقة PCI في النواة، وبالتالي لا ينبغي عادةً الوصول إلى هذه الاستدعاءات من مساحة المستخدم.

pciconfig_read()
يقرأ إلى buf من الجهاز dev عند الإزاحة off القيمة.
pciconfig_write()
يكتب من buf إلى الجهاز dev عند الإزاحة off القيمة.
pciconfig_iobase()
تمرر له زوج ناقل/devfn وتحصل على عنوان فعلي إما لإزاحة الذاكرة (للأشياء مثل prep، هذه 0xc0000000)، قاعدة الإدخال/الإخراج لدورات PIO، أو فتحات ISA إن وجدت.

قيمة الإرجاع

pciconfig_read()
عند النجاح، يتم إرجاع صفر. عند الخطأ، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.
pciconfig_write()
عند النجاح، يتم إرجاع صفر. عند الخطأ، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.
pciconfig_iobase()
ترجع معلومات حول مواقع مناطق الإدخال/الإخراج المختلفة في الذاكرة الفعلية وفقًا لقيمة which. القيم لـ which هي: IOBASE_BRIDGE_NUMBER, IOBASE_MEMORY, IOBASE_IO, IOBASE_ISA_IO, IOBASE_ISA_MEM.

الأخطاء

EINVAL
قيمة size غير صالحة. هذا لا ينطبق على pciconfig_iobase().
EIO
خطأ في الإدخال/الإخراج.
ENODEV
بالنسبة لـ pciconfig_iobase()، قيمة "hose" هي NULL. بالنسبة للاستدعاءات الأخرى، لم يتم العثور على خانة.
ENOSYS
النظام لم ينفذ هذه الاستدعاءات (لم يتم تعريف CONFIG_PCI).
EOPNOTSUPP
هذه القيمة المرجعة صالحة فقط لـ pciconfig_iobase(). يتم إرجاعها إذا كانت القيمة لـ which غير صالحة.
EPERM
لا يمتلك المستخدم صلاحية CAP_SYS_ADMIN. هذا لا ينطبق على pciconfig_iobase().

Linux.
