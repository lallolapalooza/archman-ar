pcre2_set_substitute_case_callout(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_SUBSTITUTE_CASE_CALLOUT(3) دليل الوظائف المكتبية PCRE2_SET_SUBSTITUTE_CASE_CALLOUT(3)

الاسم

PCRE2 - تعابير نمطية متوافقة مع Perl (واجهة برمجة تطبيقات محدثة)

ملخص

#include <pcre2.h>

int pcre2_set_substitute_case_callout(pcre2_match_context *mcontext,
  PCRE2_SIZE (*callout_function)(PCRE2_SPTR, PCRE2_SIZE,
                                 PCRE2_UCHAR *, PCRE2_SIZE,
                                 int, void *),
  void *callout_data);

الوصف

تقوم هذه الدالة بتعيين حقول استدعاء الاستبدال في سياق المطابقة (الوسيط الأول). يحدد الوسيط الثاني دالة استدعاء، والوسيط الثالث عنصر بيانات غامض يتم تمريره إليها. نتيجة هذه الدالة هي دائمًا صفر.

يوجد وصف كامل لواجهة برمجة تطبيقات Native API الخاصة بـ PCRE2 في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX API في صفحة pcre2posix.
