pcre2_substring_list_get(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SUBSTRING_LIST_GET(3) دليل وظائف المكتبة PCRE2_SUBSTRING_LIST_GET(3)

الاسم

PCRE2 - تعبيرات نمطية متوافقة مع Perl (واجهة برمجة تطبيقات معدلة)

ملخص

#include <pcre2.h>

int pcre2_substring_list_get(pcre2_match_data *match_data,
  PCRE2_UCHAR ***listptr, PCRE2_SIZE **lengthsptr);

الوصف

هذه وظيفة ملائمة لاستخراج جميع السلاسل الفرعية الملتقطة بعد مطابقة نمط. إنها تبني قائمة بمؤشرات إلى السلاسل، و (اختياريًا) قائمة ثانية تحتوي على أطوالها (بوحدات التعليمات البرمجية)، باستثناء صفر انتهاء يضاف إلى كل منها. يتم كل هذا في كتلة ذاكرة واحدة يتم الحصول عليها باستخدام نفس دالة تخصيص الذاكرة التي تم استخدامها للحصول على كتلة بيانات المطابقة. يمكن استخدام الوظيفة المساعدة pcre2_substring_list_free() لتحريرها عندما لا تكون مطلوبة بعد الآن. الوسائط هي:


match_data كتلة بيانات المطابقة
listptr أين تضع مؤشرًا إلى القائمة
lengthsptr أين تضع مؤشرًا إلى الأطوال، أو NULL

يتم وضع مؤشر إلى قائمة المؤشرات في المتغير الذي عنوانه في listptr. تنتهي القائمة بمؤشر NULL. إذا لم يكن lengthsptr NULL، يتم إنشاء قائمة مطابقة للأطوال، ويتم وضع عنوانها في lengthsptr. عائد الوظيفة هو صفر عند النجاح أو PCRE2_ERROR_NOMEMORY إذا لم يتم الحصول على ذاكرة كافية.

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE2 الأصلية في صفحة pcre2api ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcre2posix.
