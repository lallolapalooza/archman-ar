pcre_config(3)

الحزمة: pcre

التراخيص: BSD

PCRE_CONFIG(3) دليل وظائف المكتبة PCRE_CONFIG(3)

الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

ملخص

#include <pcre.h>

int pcre_config(int what, void *where);

int pcre16_config(int what, void *where);

int pcre32_config(int what, void *where);

الوصف

هذه الوظيفة تمكن البرنامج العميل من معرفة الميزات الاختيارية المتاحة في إصدار مكتبة PCRE الذي يستخدمه. الوسائط هي كالتالي:


what رمز يحدد المعلومات المطلوبة
where مؤشر إلى مكان وضع البيانات

يجب أن يشير الوسيط where إلى متغير عدد صحيح، باستثناء PCRE_CONFIG_MATCH_LIMIT، و PCRE_CONFIG_MATCH_LIMIT_RECURSION، و PCRE_CONFIG_PARENS_LIMIT، عندما يجب أن يشير إلى عدد صحيح غير موقع، وبالنسبة لـ PCRE_CONFIG_JITTARGET، عندما يجب أن يشير إلى سلسلة char ثابتة*. الرموز المتاحة هي:


PCRE_CONFIG_JIT دعم المترجم Just-In-Time (1=نعم 0=لا)
PCRE_CONFIG_JITTARGET سلسلة تحتوي على معلومات حول
بنية المعالج المستهدفة للمترجم JIT،
أو NULL إذا لم يكن هناك دعم JIT
PCRE_CONFIG_LINK_SIZE حجم الرابط الداخلي: 2، 3، أو 4
PCRE_CONFIG_PARENS_LIMIT حد تداخل الأقواس
PCRE_CONFIG_MATCH_LIMIT حد الموارد الداخلي
PCRE_CONFIG_MATCH_LIMIT_RECURSION
حد عمق الاستدعاء الداخلي
PCRE_CONFIG_NEWLINE قيمة تسلسل نهاية السطر الافتراضي:
13 (0x000d) لـ CR
10 (0x000a) لـ LF
3338 (0x0d0a) لـ CRLF
-2 لـ ANYCRLF
-1 لـ ANY
PCRE_CONFIG_BSR يشير إلى ما تطابقه \R افتراضيًا:
0 جميع نهايات الأسطر في Unicode
1 CR، LF، أو CRLF فقط
PCRE_CONFIG_POSIX_MALLOC_THRESHOLD
عتبة فتحات الإرجاع، التي فوقها
يتم استخدام malloc() بواسطة واجهة POSIX
PCRE_CONFIG_STACKRECURSE تنفيذ الاستدعاء (1=مكدس 0=كومة)
PCRE_CONFIG_UTF16 دعم UTF-16 (1=نعم
0=لا)؛ خيار لـ pcre16_config()
PCRE_CONFIG_UTF32 دعم UTF-32 (1=نعم
0=لا)؛ خيار لـ pcre32_config()
PCRE_CONFIG_UTF8 دعم UTF-8 (1=نعم 0=لا)؛
خيار لـ pcre_config()
PCRE_CONFIG_UNICODE_PROPERTIES
دعم خصائص Unicode
(1=نعم 0=لا)

تعيد الوظيفة 0 عند النجاح أو PCRE_ERROR_BADOPTION عند الفشل. يتم إعطاء هذا الخطأ أيضًا إذا تم تمرير PCRE_CONFIG_UTF16 أو PCRE_CONFIG_UTF32 إلى pcre_config()، إذا تم تمرير PCRE_CONFIG_UTF8 أو PCRE_CONFIG_UTF32 إلى pcre16_config()، أو إذا تم تمرير PCRE_CONFIG_UTF8 أو PCRE_CONFIG_UTF16 إلى pcre32_config().

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE الأصلية في صفحة pcreapi ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcreposix.
