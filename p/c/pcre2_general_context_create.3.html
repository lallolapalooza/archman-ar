pcre2_general_context_create(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_GENERAL_CONTEXT_CREATE(3) دليل الوظائف المكتبية PCRE2_GENERAL_CONTEXT_CREATE(3)

الاسم

PCRE2 - تعابير نمطية متوافقة مع Perl (واجهة برمجة التطبيقات المعدلة)

الملخص

#include <pcre2.h>

pcre2_general_context *pcre2_general_context_create(
  void *(*private_malloc)(size_t, void *),
  void (*private_free)(void *, void *), void *memory_data);

الوصف

يقوم هذا التابع بإنشاء وتهيئة سياق عام. تحدد الوسائط وظائف إدارة الذاكرة المخصصة وقيمة بيانات يتم تمريرها إليها عند استدعائها. يستخدم التابع private_malloc() للحصول على ذاكرة للسياق. إذا كان أي من الوسيطين الأولين NULL، يتم استخدام وظيفة إدارة الذاكرة للنظام. تكون النتيجة NULL إذا لم يتمكن من الحصول على ذاكرة.

يوجد وصف كامل لواجهة برمجة التطبيقات الأصلية لـ PCRE2 في صفحة pcre2api ووصف لواجهة برمجة التطبيقات POSIX في صفحة pcre2posix.
