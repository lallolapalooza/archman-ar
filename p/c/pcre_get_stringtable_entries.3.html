pcre_get_stringtable_entries(3)

الحزمة: pcre

التراخيص: BSD

PCRE_GET_STRINGTABLE_ENTRIES(3) دليل الوظائف المكتبية PCRE_GET_STRINGTABLE_ENTRIES(3)

الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

الملخص

#include <pcre.h>

int pcre_get_stringtable_entries(const pcre *code,
     const char *name, char **first, char **last);

int pcre16_get_stringtable_entries(const pcre16 *code,
     PCRE_SPTR16 name, PCRE_UCHAR16 **first, PCRE_UCHAR16 **last);

int pcre32_get_stringtable_entries(const pcre32 *code,
     PCRE_SPTR32 name, PCRE_UCHAR32 **first, PCRE_UCHAR32 **last);

الوصف

هذه الوظيفة المساعدة تبحث، بالنسبة لنمط مجمع، عن أول وآخر إدخال لاسم معين في الجدول الذي يترجم أسماء الأقواس الملتقطة إلى أرقام. عندما تكون الأسماء مطلوبة لتكون فريدة (PCRE_DUPNAMES غير معين)، يكون من الأسهل عادةً استخدام pcre[16|32]_get_stringnumber() بدلاً من ذلك.


code تعبير نمطي مجمع
name الاسم المطلوب إدخالاته
first المكان لإرجاع مؤشر إلى الإدخال الأول
last المكان لإرجاع مؤشر إلى الإدخال الأخير

ناتج الوظيفة هو طول كل إدخال، أو PCRE_ERROR_NOSUBSTRING إذا لم يتم العثور على أي منها.

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE الأصلية، بما في ذلك تنسيق إدخالات الجدول، في صفحة pcreapi، ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcreposix.
