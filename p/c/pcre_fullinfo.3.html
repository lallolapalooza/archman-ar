pcre_fullinfo(3)

الحزمة: pcre

التراخيص: BSD

PCRE_FULLINFO(3) دليل وظائف المكتبة PCRE_FULLINFO(3)

الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

الملخص

#include <pcre.h>

int pcre_fullinfo(const pcre *code, const pcre_extra *extra,
     int what, void *where);

int pcre16_fullinfo(const pcre16 *code, const pcre16_extra *extra,
     int what, void *where);

int pcre32_fullinfo(const pcre32 *code, const pcre32_extra *extra,
     int what, void *where);

الوصف

تُرجع هذه الوظيفة معلومات حول نمط تم تجميعه. وسيطاتها هي:


code تعبير نمطي مجمع
extra نتيجة pcre[16|32]_study() أو NULL
what ما هي المعلومات المطلوبة
where أين توضع المعلومات

المعلومات التالية متاحة:


PCRE_INFO_BACKREFMAX أعلى رقم مرجع خلفي
PCRE_INFO_CAPTURECOUNT عدد الأنماط الفرعية الملتقطة
PCRE_INFO_DEFAULT_TABLES مؤشر إلى الجداول الافتراضية
PCRE_INFO_FIRSTBYTE أول وحدة بيانات ثابتة للمطابقة، أو
-1 لبداية السلسلة
أو بعد سطر جديد، أو
-2 بخلاف ذلك
PCRE_INFO_FIRSTTABLE جدول وحدات البيانات الأولى (بعد الدراسة)
PCRE_INFO_HASCRORLF إرجاع 1 إذا كانت هناك مطابقات صريحة لـ CR أو LF
PCRE_INFO_JCHANGED إرجاع 1 إذا تم استخدام (?J) أو (?-J)
PCRE_INFO_JIT إرجاع 1 بعد تجميع JIT بنجاح
PCRE_INFO_JITSIZE حجم كود JIT المجمع
PCRE_INFO_LASTLITERAL آخر وحدة بيانات حرفية مطلوبة
PCRE_INFO_MINLENGTH الحد الأدنى لطول السلاسل المتطابقة
PCRE_INFO_MATCHEMPTY إرجاع 1 إذا كان النمط يمكن أن يطابق سلسلة فارغة،
0 بخلاف ذلك
PCRE_INFO_MATCHLIMIT حد المطابقة إذا تم تعيينه، وإلا PCRE_RROR_UNSET
PCRE_INFO_MAXLOOKBEHIND طول (بالأحرف) لأطول تأكيد نظرة خلفية
PCRE_INFO_NAMECOUNT عدد الأنماط الفرعية المسماة
PCRE_INFO_NAMEENTRYSIZE حجم إدخال جدول الأسماء
PCRE_INFO_NAMETABLE مؤشر إلى جدول الأسماء
PCRE_INFO_OKPARTIAL إرجاع 1 إذا كان يمكن تجربة المطابقة الجزئية
(دائماً يُرجع 1 بعد الإصدار 8.00)
PCRE_INFO_OPTIONS بتات الخيار المستخدمة للتجميع
PCRE_INFO_SIZE حجم النمط المجمع
PCRE_INFO_STUDYSIZE حجم بيانات الدراسة
PCRE_INFO_FIRSTCHARACTER أول وحدة بيانات ثابتة للمطابقة
PCRE_INFO_FIRSTCHARACTERFLAGS تُرجع
1 إذا كان هناك مجموعة أحرف بيانات أولى، والتي يمكن
بعد ذلك استرجاعها باستخدام PCRE_INFO_FIRSTCHARACTER،
2 إذا كان الحرف الأول في بداية سلسلة البيانات
أو بعد سطر جديد، و
0 بخلاف ذلك
PCRE_INFO_RECURSIONLIMIT حد العودية إذا تم تعيينه، وإلا PCRE_ERROR_UNSET
PCRE_INFO_REQUIREDCHAR آخر وحدة بيانات حرفية مطلوبة
PCRE_INFO_REQUIREDCHARFLAGS تُرجع 1 إذا تم تعيين حرف البيانات الأخير (والذي يمكن بعد ذلك
استرجاعه باستخدام PCRE_INFO_REQUIREDCHAR)؛ 0 بخلاف ذلك

يجب أن يشير الوسيط where إلى متغير عدد صحيح، باستثناء القيم what التالية:


PCRE_INFO_DEFAULT_TABLES const uint8_t *
PCRE_INFO_FIRSTCHARACTER uint32_t
PCRE_INFO_FIRSTTABLE const uint8_t *
PCRE_INFO_JITSIZE size_t
PCRE_INFO_MATCHLIMIT uint32_t
PCRE_INFO_NAMETABLE PCRE_SPTR16 (مكتبة 16 بت)
PCRE_INFO_NAMETABLE PCRE_SPTR32 (مكتبة 32 بت)
PCRE_INFO_NAMETABLE const unsigned char * (مكتبة 8 بت)
PCRE_INFO_OPTIONS unsigned long int
PCRE_INFO_SIZE size_t
PCRE_INFO_STUDYSIZE size_t
PCRE_INFO_RECURSIONLIMIT uint32_t
PCRE_INFO_REQUIREDCHAR uint32_t

يكون عائد الوظيفة صفرًا عند النجاح أو:


PCRE_ERROR_NULL كان الوسيط code هو NULL
كان الوسيط where هو NULL
PCRE_ERROR_BADMAGIC لم يتم العثور على "رقم السحر"
PCRE_ERROR_BADOPTION كانت قيمة what غير صالحة
PCRE_ERROR_UNSET لم يتم تعيين الخيار

يوجد وصف كامل لواجهة برمجة تطبيقات PCRE الأصلية في صفحة pcreapi ووصف لواجهة برمجة تطبيقات POSIX في صفحة pcreposix.
