الاسم

PCRE - تعبيرات نمطية متوافقة مع Perl

ملخص بناء جملة التعبيرات النمطية لـ PCRE

يتم وصف بناء الجملة الكاملة ودلالات التعبيرات النمطية التي تدعمها PCRE في وثائق pcrepattern. تحتوي هذه الوثيقة على ملخص سريع لبناء الجملة.

الاقتباس


\x حيث x ليس حرفًا أبجديًا رقميًا هو حرف x حرفي
\Q...\E تعامل الأحرف المغلقة كأحرف حرفية

الأحرف


\a إنذار، أي حرف BEL (سداسي عشري 07)
\cx "تحكم-x"، حيث x هو أي حرف ASCII
\e هروب (سداسي عشري 1B)
\f تغذية ورقية (سداسي عشري 0C)
\n سطر جديد (سداسي عشري 0A)
\r عودة المحرف (سداسي عشري 0D)
\t علامة جدولة (سداسي عشري 09)
\0dd حرف بالرمز الثماني 0dd
\ddd حرف بالرمز الثماني ddd، أو مرجع عكسي
\o{ddd..} حرف بالرمز الثماني ddd..
\xhh حرف بالرمز السداسي عشري hh
\x{hhh..} حرف بالرمز السداسي عشري hhh..

لاحظ أن \0dd هو دائمًا رمز ثماني، وأن \8 و \9 هما الحرفان الحرفيان "8" و "9".

أنواع الأحرف


. أي حرف باستثناء سطر جديد؛
في وضع dotall، أي حرف على الإطلاق
\C وحدة بيانات واحدة، حتى في وضع UTF (يفضل تجنبها)
\d رقم عشري
\D حرف ليس رقمًا عشريًا
\h حرف مسافة أفقية
\H حرف ليس مسافة أفقية
\N حرف ليس سطرًا جديدًا
\p{xx} حرف بالخاصية xx
\P{xx} حرف بدون الخاصية xx
\R تسلسل سطر جديد
\s حرف مسافة بيضاء
\S حرف ليس مسافة بيضاء
\v حرف مسافة رأسية
\V حرف ليس مسافة رأسية
\w حرف "كلمة"
\W حرف "غير كلمة"
\X مجموعة رسوم بيانية ممتدة يونيكود

بشكل افتراضي، تطابق \d و \s و \w الأحرف ASCII فقط، حتى في وضع UTF-8 أو في المكتبات ذات 16 بت و 32 بت. ومع ذلك، إذا كان المطابقة الخاصة بالموقع تحدث، فقد تطابق \s و \w أيضًا الأحرف ذات نقاط الرمز في النطاق 128-255. إذا تم تعيين خيار PCRE_UCP، يتم تغيير سلوك هذه التسلسلات الهروب لاستخدام خصائص Unicode وتطابق العديد من الأحرف.

خصائص فئة PCRE الخاصة لـ \p و \P


Xan أبجدي رقمي: اتحاد الخصائص L و N
Xps مسافة POSIX: الخاصية Z أو علامة جدولة، NL، VT، FF، CR
Xsp مسافة Perl: الخاصية Z أو علامة جدولة، NL، VT، FF، CR
Xuc حرف مسمى عالميًا: حرف يمكن تمثيله باسم حرف عالمي
Xwd كلمة Perl: الخاصية Xan أو شرطة سفلية

مسافة Perl و POSIX متماثلة الآن. أضاف Perl VT إلى مجموعة أحرف المسافة الخاصة به في الإصدار 5.18 وتغير PCRE في الإصدار 8.34.

فئات الأحرف


[...] فئة أحرف إيجابية
[^...] فئة أحرف سلبية
[x-y] نطاق (يمكن استخدامه للأحرف السداسية العشرية)
[[:xxx:]] مجموعة POSIX مسماة إيجابية
[[:^xxx:]] مجموعة POSIX مسماة سلبية


alnum أبجدي رقمي
alpha حرفي
ascii 0-127
blank مسافة أو علامة جدولة
cntrl حرف تحكم
digit رقم عشري
graph طباعة، باستثناء المسافة
lower حرف صغير

في PCRE، تتعرف أسماء مجموعات أحرف POSIX على الأحرف ASCII فقط بشكل افتراضي، ولكن بعضها يستخدم خصائص Unicode إذا تم تعيين PCRE_UCP. يمكنك استخدام \Q...\E داخل فئة أحرف.

NAME


pcrepattern - PCRE regular expression syntax summary

PCRE REGULAR EXPRESSION SYNTAX SUMMARY


expr|expr|expr...

QUOTING


\Q...\E quote literal characters
\x quote literal character x

CHARACTERS


. match any character (except newline by default)

CHARACTER TYPES


\d decimal digit
\D non-digit
\h horizontal whitespace
\H non-horizontal whitespace
\N non-newline character
\n newline character
\s whitespace character
\S non-whitespace character
\v vertical whitespace
\V non-vertical whitespace
\w word character
\W non-word character

For Unicode properties, see \p and \P below.

GENERAL CATEGORY PROPERTIES FOR \p AND \P


\p{XX} property XX
\P{XX} negation of property XX

XX can be a general category, script name, or derived property. See the documentation for details.

PCRE SPECIAL CATEGORY PROPERTIES FOR \p AND \P


\p{xx} property xx
\P{xx} negation of property xx

xx can be one of the following (case-insensitive):
Alnum, Assign, Blank, Cased, Caspian_Derived, Cased_Derived, Case_Ignorable,
Chr, Composed, Comp, Connector, Control, CR, C, Cn, Cc, Cf, Cs, Cue, Digit,
Display, Empty, Empty_Derived, EOL, Ext, Extended_Pictographic, GC, General_Category,
Graph, Grapheme_Base, Grapheme_Link, Hex, IDContinuations, Ideographic, IDS,
IDStart, Image, Index, Inherited, Inline, Invalid, In, IP, Italic, Join_Control,
L, LC, Letter, Len, Len_Derived, LF, Line_Break, Logical_Order_Exception, Lower,
Lower_Derived, L&C, Lowercase, M, Math, Mark, Max, Merge, Meter, Middle,
Misc, Mobile, N, Name, Name_Derived, NBSP, NChar, NFKC, NFKC_Derived, NFKD,
NFKD_Derived, NFD, NFD_Derived, NFC, NFC_Derived, Next, NoLineBreak, Noncharacter,
Not_Digit, Not_IDContinue, Not_IDStart, Not_Word, NUMERIC_TYPE_DECIMAL,
NUMERIC_TYPE_DIGIT, NUMERIC_TYPE_NONE, NUMERIC_TYPE_PRECEDENT, NUMERIC_TYPE_RE mainder,
NUMERIC_VALUE, O, Obsolete, OC, Other, OE, Other_Exotic, P, Pat, Pattern_White,
Pattern_Syntax, Pause, Pc, Pd, Pe, Pf, Pk, Phonetic, Pi, Pj, Pk, Pl, Pm, Pn,
Possessive, PP, Prep, Ps, Quotation, Q, R, Space, Space_Derived, S, SC, Script,
Soft_Blank, Space_Perl, Space_Unix, SP, Space_Legacy, ST, Start, STC, Strict,
Strong, Suggestion, T, Table, Terminal_Grapheme_Base, TD, Temp, Thin, THIN_SPACE,
Tidy, Tidy_Derived, Title, Title_Derived, Tl, TO, Tone, Tone_Base, Tone_Enhancer,
TR, Tr, Transfer, Translation, U, Uppercase, Upper_Derived, UR, V, VChar,
Version, Vertical, Visible, VSpace, W, White, WS, White_Derived, X, XidContinue,
XidStart, Z, Zl, Zp.

SCRIPT NAMES FOR \p AND \P


\p{Latin}, \p{Cyrillic}, \p{Greek}, \p{Arabic}, \p{Hebrew}, \p{Han}, \p{Hiragana}, \p{Katakana}, \p{Hangul}, \p{Ccc}, \p{Common}, \p{Inherited}, \p{Unknown}. Other script names are also supported.

CHARACTER CLASSES


[abc] match a, b, or c
[^abc] match any char except a, b, or c
[a-z] match any lowercase letter
[a-zA-Z0-9] match any letter or digit

Within a class, the following are recognized:


^ beginning of string (if first char)
- ranges (e.g. a-z)
\ quote metacharacter
[:name:] POSIX character class name
\p{XX} Unicode property XX
\P{XX} negation of Unicode property XX

POSIX classes:
Alnum Alpha Digit Lower Lower_Derived Upper Upper_Derived Digit Space
Print Punct Xdigit Word

QUANTIFIERS


* zero or more times
+ one or more times
? zero or one time
{n} exactly n times
{n,} n or more times
{n,m} between n and m times (inclusive)
*? +? ?? {n}? {n,}? {n,m}? match non-greedily (lazily)

ANCHORS AND SIMPLE ASSERTIONS


^ start of string or line (in multiline mode)
$ end of string or line (in multiline mode)
\A start of string
\Z end of string
\b word boundary
\B non-word boundary
\ < start of word
\ > end of word
\R newline sequence

MATCH POINT RESET


\K reset start of match

ALTERNATION


expr|expr|expr...

CAPTURING


(...) capturing group
(?<name>...) named capturing group (Perl)
(?'name'...) named capturing group (Perl)
(?P<name>...) named capturing group (Python)
(?:...) non-capturing group
(?|...) non-capturing group; reset group numbers for
capturing groups in each alternative

ATOMIC GROUPS


(?>...) atomic, non-capturing group

COMMENT


(?#....) comment (not nestable)

OPTION SETTING


(?i) caseless
(?J) allow duplicate names
(?m) multiline
(?s) single line (dotall)
(?U) default ungreedy (lazy)
(?x) extended (ignore white space)
(?-...) unset option(s)

The following are recognized only at the very start of a pattern or after one of the newline or \R options with similar syntax. More than one of them may appear.


(*LIMIT_MATCH=d) set the match limit to d (decimal number)
(*LIMIT_RECURSION=d) set the recursion limit to d (decimal number)
(*NO_AUTO_POSSESS) no auto-possessification (PCRE_NO_AUTO_POSSESS)
(*NO_START_OPT) no start-match optimization (PCRE_NO_START_OPTIMIZE)
(*UTF8) set UTF-8 mode: 8-bit library (PCRE_UTF8)
(*UTF16) set UTF-16 mode: 16-bit library (PCRE_UTF16)
(*UTF32) set UTF-32 mode: 32-bit library (PCRE_UTF32)
(*UTF) set appropriate UTF mode for the library in use
(*UCP) set PCRE_UCP (use Unicode properties for \d etc)

Note that LIMIT_MATCH and LIMIT_RECURSION can only reduce the value of the limits set by the caller of pcre_exec(), not increase them.

NEWLINE CONVENTION

These are recognized only at the very start of the pattern or after option settings with a similar syntax.


(*CR) carriage return only
(*LF) linefeed only
(*CRLF) carriage return followed by linefeed
(*ANYCRLF) all three of the above
(*ANY) any Unicode newline sequence

WHAT \R MATCHES

These are recognized only at the very start of the pattern or after option setting with a similar syntax.


(*BSR_ANYCRLF) CR, LF, or CRLF
(*BSR_UNICODE) any Unicode newline sequence

LOOKAHEAD AND LOOKBEHIND ASSERTIONS


(?=...) positive look ahead
(?!...) negative look ahead
(?<=...) positive look behind
(?<!...) negative look behind

Each top-level branch of a look behind must be of a fixed length.

BACKREFERENCES


\n reference by number (can be ambiguous)
\gn reference by number
\g{n} reference by number
\g{-n} relative reference by number
\k<name> reference by name (Perl)
\k'name' reference by name (Perl)
\g{name} reference by name (Perl)
\k{name} reference by name (.NET)
(?P=name) reference by name (Python)

SUBROUTINE REFERENCES (POSSIBLY RECURSIVE)


(?R) recurse whole pattern
(?n) call subpattern by absolute number
(?+n) call subpattern by relative number
(?-n) call subpattern by relative number
(?&name) call subpattern by name (Perl)
(?P>name) call subpattern by name (Python)
\g<name> call subpattern by name (Oniguruma)
\g'name' call subpattern by name (Oniguruma)
\g<n> call subpattern by absolute number (Oniguruma)
\g'n' call subpattern by absolute number (Oniguruma)
\g<+n> call subpattern by relative number (PCRE extension)
\g'+n' call subpattern by relative number (PCRE extension)
\g<-n> call subpattern by relative number (PCRE extension)
\g'-n' call subpattern by relative number (PCRE extension)

CONDITIONAL PATTERNS


(?(condition)yes-pattern)
(?(condition)yes-pattern|no-pattern)


(?(n)... absolute reference condition
(?(+n)... relative reference condition
(?(-n)... relative reference condition
(?(<name>)... named reference condition (Perl)
(?('name')... named reference condition (Perl)
(?(name)... named reference condition (PCRE)
(?(R)... overall recursion condition
(?(Rn)... specific group recursion condition
(?(R&name)... specific recursion condition
(?(DEFINE)... define subpattern for reference
(?(assert)... assertion condition

BACKTRACKING CONTROL

The following act immediately they are reached:


(*ACCEPT) force successful match
(*FAIL) force backtrack; synonym (*F)
(*MARK:NAME) set name to be passed back; synonym (*:NAME)

The following act only when a subsequent match failure causes a backtrack to reach them. They all force a match failure, but they differ in what happens afterwards. Those that advance the start-of-match point do so only if the pattern is not anchored.


(*COMMIT) overall failure, no advance of starting point
(*PRUNE) advance to next starting character
(*PRUNE:NAME) equivalent to (*MARK:NAME)(*PRUNE)
(*SKIP) advance to current matching position
(*SKIP:NAME) advance to position corresponding to an earlier
(*MARK:NAME); if not found, the (*SKIP) is ignored
(*THEN) local failure, backtrack to next alternation
(*THEN:NAME) equivalent to (*MARK:NAME)(*THEN)

CALLOUTS


(?C) callout
(?Cn) callout with data n
