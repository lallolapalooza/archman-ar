pcre2_set_compile_extra_options(3)

الحزمة: pcre2

التراخيص: BSD-2-Clause, BSD-3-Clause WITH PCRE2-exception

PCRE2_SET_COMPILE_EXTRA_OPTIONS(3) دليل وظائف المكتبة PCRE2_SET_COMPILE_EXTRA_OPTIONS(3)

الاسم

PCRE2 - تعبيرات نمطية متوافقة مع Perl (واجهة برمجة تطبيقات منقحة)

الملخص

#include <pcre2.h>

int pcre2_set_compile_extra_options(pcre2_compile_context *ccontext,
  uint32_t extra_options);

الوصف

تقوم هذه الوظيفة بتعيين بتات خيارات إضافية لـ pcre2_compile() التي تقيم في سياق التجميع. إنها تستبدل تمامًا كل البتات. الخيارات الإضافية هي:


PCRE2_EXTRA_ALLOW_LOOKAROUND_BSK السماح بـ \K في lookarounds
PCRE2_EXTRA_ALLOW_SURROGATE_ESCAPES السماح بـ \x{d800} إلى \x{dfff}
في أوضاع UTF-8 و UTF-32
PCRE2_EXTRA_ALT_BSUX معالجة \u، \U، و \x البديلة الموسعة
PCRE2_EXTRA_ASCII_BSD \d يبقى ASCII في وضع UCP
PCRE2_EXTRA_ASCII_BSS \s يبقى ASCII في وضع UCP
PCRE2_EXTRA_ASCII_BSW \w يبقى ASCII في وضع UCP
PCRE2_EXTRA_ASCII_DIGIT فئات POSIX [:digit:] و [:xdigit:]
تبقى ASCII في وضع UCP
PCRE2_EXTRA_ASCII_POSIX فئات POSIX تبقى ASCII في
وضع UCP
PCRE2_EXTRA_BAD_ESCAPE_IS_LITERAL التعامل مع الهروب غير الصالح كحرف
متبوع بحرف حرفي
PCRE2_EXTRA_CASELESS_RESTRICT تعطيل طي الأحرف المختلطة ASCII/غير ASCII
PCRE2_EXTRA_ESCAPED_CR_IS_LF تفسير \r كـ \n
PCRE2_EXTRA_MATCH_LINE تطابق الأنماط الخطوط الكاملة
PCRE2_EXTRA_MATCH_WORD تطابق الأنماط "الكلمات"
PCRE2_EXTRA_NEVER_CALLOUT منع الاستدعاءات في النمط
PCRE2_EXTRA_NO_BS0 منع \0 (ولكن ليس \00 أو \000)
PCRE2_EXTRA_PYTHON_OCTAL استخدام قواعد Python للأعداد الثمانية
PCRE2_EXTRA_TURKISH_CASING استخدام طي الأحرف التركية I

يوجد وصف كامل لواجهة برمجة التطبيقات الأصلية لـ PCRE2 في صفحة pcre2api ووصف لواجهة برمجة التطبيقات POSIX في صفحة pcre2posix.
