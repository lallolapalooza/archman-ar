pdnsutil(1)

الحزمة: powerdns

التراخيص: GPL-2.0-only

PDNSUTIL(1) خادم PowerDNS السلطوي PDNSUTIL(1)

الاسم

pdnsutil - أداة التحكم والوصول لسجلات PowerDNS و DNSSEC

الملخص

pdnsutil [خيار]... أمر

الوصف

pdnsutil (المعروفة سابقًا باسم pdnssec) هي أداة قوية تعتبر بوابة سهلة للمشغلين لإدارة DNSSEC وإدارة المناطق لـ PowerDNS. خلف الكواليس، تقوم pdnsutil بمعالجة قاعدة بيانات خلفية لـ PowerDNS، مما يعني أيضًا أنه بالنسبة للعديد من قواعد البيانات، يمكن تشغيل pdnsutil عن بُعد، ويمكنها تكوين مواد المفاتيح على خوادم مختلفة.

الخيارات

-h، --help
عرض ملخص الخيارات
-v، --verbose
كن أكثر تفصيلاً
-f، --force
فرض إجراء
-q، --quiet
كن هادئًا
--config-name <الاسم>
اسم التكوين الافتراضي
--config-dir <المجلد>
موقع pdns.conf. الافتراضي هو /etc/powerdns.

الأوامر

هناك العديد من الأوامر المتاحة. تتبع معظم الأوامر النمط pdnsutil <الكائن> <الإجراء> [وسائط...]، حيث <الكائن> هو اسم و <الإجراء> هو فعل؛ بعض الأوامر التي لا تنطبق على أي نوع كائن معين تستخدم الفعل فقط.

أوامر AUTOPRIMARY

autoprimary add IP NAMESERVER [الحساب]

إضافة إدخال autoprimary إلى الواجهة الخلفية. هذا يتيح استقبال تحديثات المناطق من خوادم أخرى.

autoprimary list

قائمة بجميع autoprimaries.

autoprimary remove IP NAMESERVER

إزالة autoprimary من الواجهة الخلفية. غير مدعوم بواسطة الواجهة الخلفية لـ BIND.

أوامر مناطق الكتالوج

catalog list-members CATALOG

قائمة بجميع أعضاء منطقة الكتالوج CATALOG

catalog set ZONE [CATALOG]

تغيير كتالوج ZONE إلى CATALOG. إذا تم حذف CATALOG، فإنه يزيل ZONE من الكتالوج الذي يوجد فيه.

أوامر بيانات وصفية للمنطقة

metadata add ZONE KIND VALUE [VALUE]...

إضافة VALUE إلى البيانات الوصفية KIND الموجودة لـ ZONE. ستُرجع خطأ إذا كان KIND لا يدعم قيمًا متعددة، استخدم metadata set لهذه القيم.

metadata get ZONE [KIND]...

الحصول على البيانات الوصفية للمنطقة. إذا لم يتم توفير KIND، فإنه يسرد جميع البيانات المعروفة.

metadata set ZONE KIND [VALUE]...

تعيين البيانات الوصفية KIND للمنطقة ZONE إلى VALUE، واستبدال جميع القيم الموجودة لـ KIND. القيمة المحذوفة تمسحها.

أوامر الشبكة

network list

قائمة بجميع الشبكات المعرفة مع طرق العرض المختارة.

network set NET [VIEW]

تعيين VIEW للشبكة NET، أو حذفها إذا لم يتم توفير وسيط VIEW.

أوامر سجلات المنطقة

في هذه الأوامر، يمكن أيضًا كتابة اسم الكائن rrset باسم record.

rrset add ZONE NAME TYPE [TTL] CONTENT

إضافة سجل واحد أو أكثر من NAME و TYPE إلى ZONE مع CONTENT و TTL اختياري. إذا لم يتم تعيين TTL، سيتم استخدام default-ttl المعد. يجب أن يكون NAME مطلقًا.

rrset delete ZONE NAME TYPE

حذف RRSET المسمى من المنطقة. يجب أن يكون NAME مطلقًا.

rrset hash ZONE RNAME

يقوم هذا الأمر المريح بتجزئة الاسم RNAME وفقًا لإعدادات NSEC3 للمنطقة ZONE. يرفض التجزئة للمناطق التي لا توجد بها إعدادات NSEC3.

rrset replace ZONE NAME TYPE [TTL] CONTENT [CONTENT...]

استبدال NAME الحالي في المنطقة ZONE بمجموعة جديدة.

أوامر متعلقة بـ TSIG

تقوم هذه الأوامر بمعالجة معلومات مفاتيح TSIG في قاعدة البيانات. تتطلب بعض الأوامر ALGORITHM، والتي يمكن أن تكون أيًا مما يلي:

  • hmac-md5
  • hmac-sha1
  • hmac-sha224
  • hmac-sha256
  • hmac-sha384
  • hmac-sha512

tsigkey activate ZONE NAME {primary,secondary,producer,consumer}

تمكين AXFR المصادق عليه بواسطة TSIG باستخدام المفتاح NAME للمنطقة ZONE. يقوم هذا بتعيين البيانات الوصفية للمنطقة TSIG-ALLOW-AXFR (primary/producer) أو AXFR-MASTER-TSIG (secondary/consumer).

tsigkey deactivate ZONE NAME {primary,secondary,producer,consumer}

تعطيل AXFR المصادق عليه بواسطة TSIG باستخدام المفتاح NAME للمنطقة ZONE.

tsigkey delete NAME

حذف مفتاح TSIG NAME. تحذير: هذا لا يعطل المفتاح المذكور.

tsigkey generate NAME ALGORITHM

إنشاء مفتاح TSIG جديد بالاسم NAME والخوارزمية المحددة.

tsigkey import NAME ALGORITHM KEY

استيراد KEY من الخوارزمية المحددة باسم NAME.

tsigkey list

عرض قائمة بجميع مفاتيح TSIG المكونة.

أوامر طرق العرض

views add-zone VIEW ZONE..VARIANT

إضافة ZONE VARIANT المعطاة إلى VIEW.

views del-zone VIEW ZONE..VARIANT

إزالة ZONE VARIANT من VIEW.

views list VIEW

قائمة بجميع المناطق داخل VIEW.

views list-all

قائمة بجميع أسماء طرق العرض.

أوامر معالجة المنطقة

zone check ZONE

فحص المنطقة ZONE للتأكد من صحتها.

zone check-all [exit-on-error]

فحص جميع المناطق للتأكد من صحتها، مع التوقف عند العثور على أول خطأ في أي منطقة إذا تم تحديد "exit-on-error".

zone clear ZONE

مسح السجلات في المنطقة ZONE، ولكن ترك المنطقة الفعلية والإعدادات دون تغيير

zone create ZONE
