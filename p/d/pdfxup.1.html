NAME

pdfxup – pdf poster (usually 2-up) layout creator

SYNOPSIS

pdfxup [-b|--book] [-o output.pdf] [-c cols] [-r rows] [-l|--landscape] [-p|--portrait] [-k|--keep-bbox] [-K|--keep-orig-bbox] [-x width] [-y height] [-B bbox] [-t|--tight] [-i margin] [-I space] [-W frame] [-p|--profile filename] [-d|--debug] [-v|--version] [-h|--help] input.pdf[:pages]

DESCRIPTION

pdfxup rearranges the pages of a PDF file in order to create a poster (usually 2-up).

The tool is especially designed to process Beamer PDFs, in order to get one or two slides per page.

pdfxup can handle several options to customize the output. Many of these options can be set using configuration files (see CONFIGURATION FILES).

OPTIONS

-b, --book
Creates a booklet layout. This means that page are printed in order 1, N, 2, N-1, 3, N-2, etc. This option is useful for printing booklets that can be folded in the middle.
-o output.pdf
Writes the output to output.pdf instead of stdout.
-c cols
Sets the number of columns to cols. Default value is 2.
-r rows
Sets the number of rows to rows. Default value is 1.
-l, --landscape
Sets the page orientation to landscape. Default is portrait.
-p, --portrait
Sets the page orientation to portrait. Default is portrait.
-k, --keep-bbox
Does not compute the bounding box. Uses the original one. This is useful when the PDF pages are already cropped.
-K, --keep-orig-bbox
Does not crop margins. Uses the original bounding box values. This is useful when the PDF pages are already cropped.
-x width
Sets the number of pages horizontally. Default is 2.
-y height
Sets the number of pages vertically. Default is 1.
-B bbox
Sets the bounding box. The bbox is a string like "llx lly urx ury". For example, "75 47 540 755".
-t, --tight
Sets tight frames around pages.
-i margin
Sets the margin around each page (inside the frame) to margin. Example: -i 10pt.
-I space
Sets the space between pages to space. Example: -I 10pt.
-W frame
Sets the frame width to frame. Example: -W 2mm.
--profile filename
Uses filename as a configuration file. This file is parsed as a shell script (see below).
-d, --debug
Prints debug information.
-v, --version
Prints version information and exits.
-h, --help
Prints help information and exits.

CONFIGURATION FILES

Files with extension .xup are bash scripts used to set some variables. If option "--config-file <file>" (or equivalent) is used, <file> is looked up with kpsewhich first, if it contains no '/'. If kpsewhich does not find it, then pdfxup checks if the file exists (using 'test -e') before sourcing it (the PATH variable will not be used to find it).

The script should only set some internal variables of pdfxup, such as NB_ROWS, NB_COLUMNS, LANDSCAPE (to set up a predefined layout). It can be used to set the bounding box, but it is often better to compute it on the first few pages of the document. Here are some examples of lines that can be put in a .xup file:

NB_COLUMNS=1
set the number of columns to 1
NB_ROWS=2
set the number of rows to 2
LANDSCAPE=0
set portrait mode
KEEP_ORIG_BBOX=1
do not crop margins
SET_BBOX="75 47 540 755"
set bounding box: lower left=(75,47); upper right=(540,755)
TIGHT_FRAME=1
set tight frames around pages
INNER_MARGINS=10pt
set margin around each page (inside the frame) to 10pt
INTERM_SPACES=10pt
set space between pages to 10pt
FRAME_WIDTH=2mm
set frame width to 2mm

Other available variables can be found in the setdefaultvalues function.

EXAMPLES

# pdfxup file.pdf
produces 2-up pdf file from file.pdf.
# pdfxup -bb 1-4 file.pdf
same behaviour, but computes the bounding box only using the first 4 pages (this saves time when processing long documents).
# pdfxup -b -o booklet.pdf file.pdf
same behaviour, but creates a booklet (as booklet.pdf).
# pdfxup -kbb -x1 -y2 -l0 beamer-frames.pdf
arranges 2 beamer frames per page (not reducing margins).
# pdfxup --mode beamer2 beamer-frames.pdf
arranges PDF pages according to beamer2.xup configuration file.
# pdfxup -kbb -x2 -y2 -l beamer-frames.pdf:1-12,15-19
arranges 4 beamer frames per page (not reducing margins), including only frames 1 to 12 and 15 to 19.
