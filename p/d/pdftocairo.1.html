الاسم

pdftocairo - تنسيق المستندات المحمولة (PDF) إلى PNG/JPEG/TIFF/PDF/PS/EPS/SVG باستخدام cairo

ملخص

pdftocairo [خيارات] ملف-PDF [ملف-الإخراج]

الوصف

يقوم pdftocairo بتحويل ملفات تنسيق المستندات المحمولة (PDF)، باستخدام جهاز إخراج cairo لمكتبة poppler PDF، إلى أي من التنسيقات التالية للإخراج:

  • تنسيق رسومات الشبكة المحمولة (PNG)
  • تنسيق تبادل JPEG (JPEG)
  • تنسيق ملف الصورة الموسوم (TIFF)
  • تنسيق المستندات المحمولة (PDF)
  • PostScript (PS)
  • Encapsulated PostScript (EPS)
  • رسومات المتجهات قابلة للتوسع (SVG)
  • طابعة ويندوز

يقرأ pdftocairo ملف PDF، ملف-PDF، ويكتب إلى ملف-الإخراج. تقوم تنسيقات الصور (PNG، JPEG، و TIFF) بإنشاء ملف لكل صفحة مع إضافة رقم الصفحة ونوع الملف إلى ملف-الإخراج. عند استخدام -singlefile مع تنسيقات الصور، يتم إضافة نوع الملف إلى ملف-الإخراج. عندما يكون تنسيق الإخراج تنسيق متجه (PDF، PS، EPS، و SVG)، يكون ملف-الإخراج هو اسم الملف الكامل.

إذا كان ملف-PDF هو “-” ، يتم قراءة PDF من الإدخال القياسي. إذا كان ملف-الإخراج هو “-” ، فسيتم كتابة ملف الإخراج إلى الإخراج القياسي. استخدام الإخراج القياسي غير صالح مع تنسيقات الصور إلا إذا تم استخدام -singlefile. إذا لم يتم استخدام ملف-الإخراج، فسيتم اشتقاق اسم ملف الإخراج من اسم ملف ملف-PDF.

ليست كل الخيارات صالحة مع جميع تنسيقات الإخراج. يجب استخدام واحد (وواحد فقط) من خيارات تنسيق الإخراج (-png، -jpeg، -tiff، -pdf، -print، -ps، -eps، أو -svg).

تعين خيارات الدقة (-r، -rx، -ry) دقة تنسيقات إخراج الصور. ستعتمد أبعاد الصورة على حجم صفحة PDF والدقة. بالنسبة لإخراج المتجهات، سيتم تسطيح المناطق من الصفحة التي لا يمكن تمثيلها بشكل أصلي في تنسيق الإخراج (مثل الشفافية في PS) بالدقة المحددة بواسطة خيارات الدقة.

يمكن استخدام خيارات -scale-to لتعيين حجم صورة ثابت. ستختلف دقة الصورة حسب حجم الصفحة. تستخدم خيارات الاقتصاص (-x، -y، -W، و -H) وحدات البكسل مع تنسيقات الصور ونقاط PostScript (1/72 بوصة) مع تنسيقات المتجهات. عند استخدام الاقتصاص مع إخراج المتجهات، يتم توسيط المنطقة المقتطعة ما لم يتم استخدام -nocenter، وفي هذه الحالة تكون المنطقة المقتطعة في أعلى اليسار (SVG) أو أسفل اليسار (PDF، PS، EPS).

خيارات

-png
إنشاء ملف (ملفات) PNG
-jpeg
إنشاء ملف (ملفات) JPEG. انظر أيضًا -jpegopt.
-tiff
إنشاء ملف (ملفات) TIFF
-pdf
إنشاء ملف PDF
-ps
إنشاء ملف PS
-eps
إنشاء ملف EPS. يحتوي ملف EPS على صورة واحدة، لذلك إذا استخدمت هذا الخيار مع ملف PDF متعدد الصفحات، فيجب عليك استخدام -f و -l لتحديد صفحة واحدة. لا يمكن استخدام خيارات حجم الصفحة (-origpagesizes، -paper، -paperw، -paperh) مع هذا الخيار.
-svg
إنشاء ملف SVG (رسومات المتجهات قابلة للتوسع)
-print
(ويندوز فقط) طباعة إلى طابعة نظام. انظر أيضًا -printer و -printeropt.
إذا لم يتم تحديد ملف إخراج، فسيتم إرسال الإخراج إلى الطابعة.
لا يمكن استخدام ملف الإخراج '-' مع هذا الخيار.
-printdlg
(ويندوز فقط) طباعة إلى طابعة نظام. يعرض مربع حوار الطباعة للسماح بتعديل خيارات الطباعة قبل الطباعة.
-f رقم
تحديد الصفحة الأولى للتحويل.
-l رقم
تحديد الصفحة الأخيرة للتحويل.
-o
إنشاء الصفحات الفردية فقط.
-e
إنشاء الصفحات الزوجية فقط.
-singlefile
يكتب الصفحة الأولى فقط ولا يضيف أرقامًا.
-r رقم
تحديد دقة X و Y، بالبكسل لكل بوصة لملفات الصور (أو المناطق المسطحة في إخراج المتجهات). الافتراضي هو 150 PPI.
-rx رقم
تحديد دقة X، بالبكسل لكل بوصة لملفات الصور (أو المناطق المسطحة في إخراج المتجهات). الافتراضي هو 150 PPI.
-ry رقم
تحديد دقة Y، بالبكسل لكل بوصة لملفات الصور (أو المناطق المسطحة في إخراج المتجهات). الافتراضي هو 150 PPI.
-scale-to رقم
يقوم بتغيير حجم الجانب الأطول من كل صفحة (العرض للصفحات الأفقية، الارتفاع للصفحات الرأسية) ليناسب عدد بكسلات scale-to. سيتم تحديد حجم الجانب الأقصر بواسطة نسبة العرض إلى الارتفاع للصفحة (PNG/JPEG/TIFF فقط).
-scale-to-x رقم
يقوم بتغيير حجم كل صفحة أفقيًا لتناسب عدد بكسلات scale-to-x. إذا تم تعيين scale-to-y إلى -1، فسيتم تحديد الحجم الرأسي بواسطة نسبة العرض إلى الارتفاع للصفحة (PNG/JPEG/TIFF فقط).
-scale-to-y رقم
يقوم بتغيير حجم كل صفحة رأسيًا لتناسب عدد بكسلات scale-to-y. إذا تم تعيين scale-to-x إلى -1، فسيتم تحديد الحجم الأفقي بواسطة نسبة العرض إلى الارتفاع للصفحة (PNG/JPEG/TIFF فقط).
-x رقم
تحديد إحداثي x للزاوية العلوية اليسرى لمنطقة الاقتصاص بالبكسل (إخراج الصورة) أو بالنقاط (إخراج المتجهات)
-y رقم
تحديد إحداثي y للزاوية العلوية اليسرى لمنطقة الاقتصاص بالبكسل (إخراج الصورة) أو بالنقاط (إخراج المتجهات)
-W رقم
تحديد عرض منطقة الاقتصاص بالبكسل (إخراج الصورة) أو بالنقاط (إخراج المتجهات) (الافتراضي هو 0)
-H رقم
تحديد ارتفاع منطقة الاقتصاص بالبكسل (إخراج الصورة) أو بالنقاط (إخراج المتجهات) (الافتراضي هو 0)
-sz رقم
تحديد حجم مربع الاقتصاص بالبكسل (إخراج الصورة) أو بالنقاط (إخراج المتجهات) (يعين -W و -H)
-cropbox
يستخدم مربع الاقتصاص بدلاً من مربع الوسائط عند إنشاء الملفات (PNG/JPEG/TIFF فقط)
-mono
إنشاء ملف أحادي اللون (PNG و TIFF فقط).
-gray
إنشاء ملف بتدرج الرمادي (PNG، JPEG، و TIFF فقط).
-antialias
تعيين خيار cairo antialias المستخدم للنص والرسم في ملفات الصور (أو المناطق المسطحة في إخراج المتجهات). الخيارات هي:
default
استخدام التنعيم الافتراضي للجهاز المستهدف. هذا هو الإعداد الافتراضي إذا لم يتم استخدام -antialias.
none
تم تعطيل التنعيم.
gray
قم بإجراء تنعيم أحادي اللون باستخدام تدرجات الرمادي.
subpixel
قم بإجراء التنعيم بالاستفادة من ترتيب العناصر الفرعية للبكسل على أجهزة مثل LCD.
fast
أشر إلى أن الواجهة الخلفية يجب أن تقوم ببعض التنعيم ولكن تفضل السرعة على الجودة.
good
يجب على الواجهة الخلفية الموازنة بين الجودة والأداء.
best
أشر إلى أن الواجهة الخلفية يجب أن تقدم بأعلى جودة، مع التضحية بالسرعة إذا لزم الأمر.

pdftocairo(1) - Arch manual pages

NAME

pdftocairo

convert PDF file to PS, EPS, SVG, or PNG file

SYNOPSIS

pdftocairo [options] [PDF-file [PS-file]]

DESCRIPTION

pdftocairo converts the specified PDF file to PostScript, Encapsulated PostScript, SVG, or PNG format. If PDF-file is specified as -, read from standard input.

If PS-file is specified as -, write to standard output. If PS-file is not specified, the output filename is derived from the input filename.

The output format is determined by the output file extension. Supported extensions are:

  • .ps - PostScript

    .eps - Encapsulated PostScript

  • .svg - Scalable Vector Graphics

  • .png - Portable Network Graphics

  • .tiff - Tagged Image File Format

  • .jpg - JPEG Image

If no output file is specified, the default output format is PostScript.

Note that pdftocairo does not support all PDF features. Some features, like encrypted PDF files or certain types of content, may not be rendered correctly.

OPTIONS

-a4paper
Set the paper size to A4 (PS,PDF,SVG only).
-blacktext
Convert all colored text to black (PS,PDF,SVG only).
-crop
Crop pages to the CropBox specified in the PDF file (PS,PDF,SVG only).
-cairo-output-file output-file
Write to output-file instead of the default output file. The default output file is derived from the input file name.
-cropbox
Use CropBox instead of MediaBox for page size (PS,PDF,SVG only).
-eps
Output Encapsulated PostScript.
-exactfit
Change the page size to exactly match the requested size. If the page size is smaller than the requested size, the page is scaled up.
-firstpage page-number
Specify the first page to convert.
-flip
Flip the image horizontally.
-gray
Convert to grayscale.
-help
Print a usage summary.
-icc icc-file
Use the specified ICC file as the output profile (PNG only). The profile will be embedded in the PNG file.
-ignoreimages
Ignore images when converting PDF to PostScript.
-imagemagick
Use ImageMagick for image conversion.
-jpegopt jpeg-options
When used with -jpeg, takes a list of options to control the jpeg compression. See JPEG OPTIONS for the available options.
-level2
Generate Level 2 PostScript (PS only).
-level3
Generate Level 3 PostScript (PS only). This enables all Level 2 features plus shading patterns and masked images. This is the default setting.
-nocenter
By default, PDF pages smaller than the paper (after any scaling) are centered on the paper. This option causes them to be aligned to the lower-left corner of the paper instead (PS,PDF,SVG only).
-nocrop
By default, printing output is cropped to the CropBox specified in the PDF file. This option disables cropping (PS,PDF,SVG only).
-nodisp
Do not display the output. Useful for batch processing.
-noexplicitlyclosedquotes
Do not add explicit closing quotes for strings.
-nofont নিকs
Do not embed font niks.
-noligatures
Do not use ligatures.
-nolocalstrings
Do not use local strings.
-noparentheses
Do not use parentheses for strings.
-noscale
Do not scale pages.
-noshrink
Don't scale PDF pages which are larger than the paper (PS,PDF,SVG only). By default, pages larger than the paper are shrunk to fit.
-novmfonts
Do not use VM fonts.
-opw password
Specify the owner password for the PDF file. Providing this will bypass all security restrictions.
-origpagesizes
This option is the same as "-paper match".
-page page-number
Convert only the specified page number.
-paper size
Set the paper size to one of "letter", "legal", "A4", or "A3" (PS,PDF,SVG only). This can also be set to "match", which will set the paper size of each page to match the size specified in the PDF file. If none the -paper, -paperw, or -paperh options are specified the default is to match the paper size.
-paperh size
Set the paper height, in points (PS,PDF,SVG only).
-paperw size
Set the paper width, in points (PS,PDF,SVG only).
-pdfile pdf-file
Read from the specified PDF file instead of the default input file.
-ps
Output PostScript.
-q
Don't print any messages or errors.
-quality number
Set JPEG quality (0-100).
-repeat count
Repeat the document count times.
-rgb
Convert to RGB color space.
-rotate degrees
Rotate the page by the specified number of degrees clockwise.
-scaled
Scale pages to fit the paper size.
-scale-to-page
Scale pages to match the paper size.
-split
Create separate files for each page.
-stdout
Write to standard output.
-struct
If the input file contains structural information about the document's content, write this information to the output file (PDF only).
-svgv
Output SVG version 1.1.
-tiff
Output TIFF.
-title title
Set the title of the output file.
-transp
Use a transparent page color instead of white (PNG and TIFF only).
-upw password
Specify the user password for the PDF file.
-v
Print copyright and version information.
-verbose
Print informational messages.
-webcolor
Use web colors.
-xlevel level
Set the PostScript level to level.

EXIT CODES

The poppler tools use the following exit codes:

0
No error.
1
Error opening a PDF file.
2
Error opening an output file.
3
Error related to PDF permissions.
4
Error related to ICC profile.
99
Other error.

JPEG OPTIONS

When JPEG output is specified, the -jpegopt option can be used to control the JPEG compression parameters. It takes a string of the form "<opt>=<val>[,<opt>=<val>]". Currently the available options are:

quality
Selects the JPEG quality value. The value must be an integer between 0 and 100.
progressive
Select progressive JPEG output. The possible values are "y", "n", indicating progressive (yes) or non-progressive (no), respectively.
optimize
Sets whether to compute optimal Huffman coding tables for the JPEG output, which will create smaller files but make an extra pass over the data. The value must be "y" or "n", with "y" performing optimization, otherwise the default Huffman tables are used.

WINDOWS PRINTER OPTIONS

In Windows, you can use the -print option to print directly to a system printer. Additionally, you can use the -printopt option to configure the printer. It takes a string of the form "<opt>=<val>[,<opt>=<val>]". Currently the available options are:

source
Selects the source paper tray to be used (bin). The possible values are "upper", "onlyone", "lower", "middle", "manual", "envelope", "envmanual", "auto", "tractor", "smallfmt", "largefmt", "largecapacity", "formsource", or a numeric value to choose a driver specific source.
duplex
Sets the duplex mode of the printer. The possible values are "off", "short" or "long", indicating no duplexing, short-edge binding, or long-edge binding, respectively. General option -duplex is a synonym of "duplex=long". If both options are specified, -printopt has priority.
