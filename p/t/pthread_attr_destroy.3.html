pthread_attr_init(3) دليل وظائف المكتبة pthread_attr_init(3)

الاسم

pthread_attr_init, pthread_attr_destroy - تهيئة وتدمير كائن سمات الخيط

المكتبة

مكتبة خيوط POSIX (libpthread, -lpthread)

الملخص

#include <pthread.h>
int pthread_attr_init(pthread_attr_t *attr);
int pthread_attr_destroy(pthread_attr_t *attr);

الوصف

تقوم الدالة pthread_attr_init() بتهيئة كائن سمات الخيط المشار إليه بواسطة attr بقيم السمات الافتراضية. بعد هذا الاستدعاء، يمكن تعيين السمات الفردية للكائن باستخدام دوال أخرى ذات صلة (مدرجة تحت انظر أيضًا)، ومن ثم يمكن استخدام الكائن في استدعاء واحد أو أكثر من استدعاءات pthread_create(3) التي تنشئ خيوطًا.

يؤدي استدعاء pthread_attr_init() على كائن سمات خيط تم تهيئته بالفعل إلى سلوك غير محدد.

عندما لا يعود كائن سمات الخيط مطلوبًا، يجب تدميره باستخدام الدالة pthread_attr_destroy(). لا يؤثر تدمير كائن سمات الخيط على الخيوط التي تم إنشاؤها باستخدام هذا الكائن.

بمجرد تدمير كائن سمات الخيط، يمكن إعادة تهيئته باستخدام pthread_attr_init(). أي استخدام آخر لكائن سمات خيط مدمر له نتائج غير محددة.

قيمة الإرجاع

عند النجاح، تعيد هذه الدوال 0؛ عند حدوث خطأ، فإنها تعيد رقم خطأ غير صفري.

الأخطاء

توثق POSIX.1 خطأ ENOMEM للدالة pthread_attr_init()؛ على Linux، تنجح هذه الدوال دائمًا (ولكن يجب على التطبيقات القابلة للنقل والمستقبلية التعامل مع خطأ محتمل على أي حال).

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

ملاحظات

يجب التعامل مع النوع pthread_attr_t على أنه غير شفاف: أي وصول إلى الكائن بخلاف وظائف pthreads غير قابل للنقل وينتج عنه نتائج غير محددة.

أمثلة

يستخدم البرنامج أدناه، اختياريًا، pthread_attr_init() ووظائف أخرى ذات صلة لتهيئة كائن سمات الخيط الذي يستخدم لإنشاء خيط واحد. بمجرد إنشائه، يستخدم الخيط الدالة pthread_getattr_np(3) (امتداد GNU غير قياسي) لاسترداد سمات الخيط، ثم يعرض هذه السمات.

إذا تم تشغيل البرنامج بدون وسيط سطر أوامر، فإنه يمرر NULL كوسيط attr للدالة pthread_create(3)، بحيث يتم إنشاء الخيط بسمات افتراضية. عند تشغيل البرنامج على Linux/x86-32 مع تطبيق خيوط NPTL، نرى ما يلي:

unlimited

        النطاق               = PTHREAD_SCOPE_SYSTEM
        الجدولة الموروثة   = PTHREAD_INHERIT_SCHED
        سياسة الجدولة   = SCHED_OTHER

        حجم الحارس          = 4096 بايت
        عنوان المكدس       = 0x40196000

عندما نوفر حجم مكدس كوسيط سطر أوامر، تقوم الدالة بتهيئة كائن سمات الخيط، وتعيين سمات مختلفة في هذا الكائن، وتمرير مؤشر إلى الكائن في استدعاء pthread_create(3). عند تشغيل البرنامج على Linux/x86-32 مع تطبيق خيوط NPTL، نرى ما يلي:

NAME

                    
pthread_attr_destroy — destroy thread attributes object

                

                

                    
LIBRARY

                    
Real-time threads library (libpthread)

                

                

                    
SYNOPSIS

                    
#include <pthread.h>

int
pthread_attr_destroy(pthread_attr_t *attr);
                    

                

                

                    
DESCRIPTION

                    
The pthread_attr_destroy() function destroys the thread attributes object specified by attr; the attributes object becomes an invalid reference. Subsequent use of the object, either by passing it to other pthread_attr_* functions or by passing it to pthread_create(3) is an error.

                    
A thread attributes object is created by pthread_attr_init(3). After a thread is created using pthread_create(3), the associated thread attributes object is no longer needed, and it can be destroyed using pthread_attr_destroy().

                    
It is safe to call pthread_attr_destroy() on an attribute object that has not been initialized, or that has already been destroyed; in this case, the function has no effect.

                

                

                    
RETURN VALUE

                    
On success, pthread_attr_destroy() returns 0.

                    
On failure, it returns a non-zero error number.

                

                

                    
ERRORS

                    
The pthread_attr_destroy() function does not set errno. The return value is used to indicate errors.

                    
The standard specifies no error conditions for pthread_attr_destroy(). However, if attr refers to an invalid attributes object (e.g., uninitialized, or already destroyed), the behavior is undefined.

                

                

                    
ATTRIBUTES

                    
For an explanation of the terms used in this section, see attributes(7).

STANDARDS

                    
The pthread_attr_destroy() function conforms to Version 1 of the POSIX Threads standard (IEEE Std 1003.1-2001).

                

                

                    
HISTORY

                    
pthread_attr_init(3) and pthread_attr_destroy() first appeared in.

                

                

                    
NOTES

                    
If the attributes object attr was used to create a thread, and the thread has not yet terminated, then calling pthread_attr_destroy() on attr may or may not be safe, depending on the implementation. It is generally recommended to destroy the attributes object only after the thread has terminated or after detaching the thread.

                    
If the thread attributes object contains dynamically allocated resources (e.g., stack memory allocated by pthread_attr_setstack(3)), pthread_attr_destroy() is responsible for freeing these resources.

                

                

                    
EXAMPLES

                    
// Example demonstrating pthread_attr_destroy
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <err.h>
#include <unistd.h>

void *thread_start(void *arg)
{
    // Thread function, does nothing in this example
    }

int
main(int argc, char *argv[])
{
    pthread_t thr;
    pthread_attr_t attr;
    int s;
    void *sp;
    size_t stack_size;
    pthread_attr_t *attrp = NULL;

    // Initialize thread attributes object
    s = pthread_attr_init(&attr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_attr_init");
    
    attrp = &attr; // Mark that we have initialized attributes

    if (argc > 1) {
        // Configure attributes if arguments are provided
        s = pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_DETACHED);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setdetachstate");
        s = pthread_attr_setinheritsched(&attr, PTHREAD_EXPLICIT_SCHED);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setinheritsched");
        
        // Set custom stack size and address
        stack_size = strtoul(argv[1], NULL, 0);
        s = posix_memalign(&sp, sysconf(_SC_PAGESIZE), stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "posix_memalign");
        printf("posix_memalign() allocated at %p\n", sp);
        s = pthread_attr_setstack(&attr, sp, stack_size);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_setstack");
    }

    // Create the thread
    s = pthread_create(&thr, attrp, &thread_start, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");

    // Destroy the attributes object
    if (attrp != NULL) {
        s = pthread_attr_destroy(attrp);
        if (s != 0)
            errc(EXIT_FAILURE, s, "pthread_attr_destroy");
    }

    // Pause indefinitely, waiting for another thread to call exit()
    pause();    
}
