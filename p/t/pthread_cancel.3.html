pthread_cancel(3) دليل وظائف المكتبة pthread_cancel(3)

الاسم

pthread_cancel - إرسال طلب إلغاء إلى مؤشر ترابط

المكتبة

مكتبة مؤشرات الترابط POSIX (libpthread، -lpthread)

الملخص

#include <pthread.h>
int pthread_cancel(pthread_t thread);

الوصف

تقوم الدالة pthread_cancel() بإرسال طلب إلغاء إلى مؤشر الترابط thread. يعتمد رد فعل مؤشر الترابط على طلب الإلغاء، ومتى يحدث، على سمتين تخضعان لسيطرة مؤشر الترابط هذا: حالة الإلغاء الخاصة به ونوعه.

يمكن أن تكون حالة الإلغاء الخاصة بمؤشر الترابط، والتي يتم تحديدها بواسطة pthread_setcancelstate(3)، إما مُمكّنة (الافتراضي للمؤشرات الجديدة) أو مُعطّلة. إذا قام مؤشر ترابط بتعطيل الإلغاء، فسيظل طلب الإلغاء معلقًا حتى يقوم مؤشر الترابط بتمكين الإلغاء. إذا قام مؤشر ترابط بتمكين الإلغاء، فإن نوع الإلغاء الخاص به يحدد متى يحدث الإلغاء.

قد يكون نوع الإلغاء الخاص بمؤشر الترابط، والذي يتم تحديده بواسطة pthread_setcanceltype(3)، إما غير متزامن أو مؤجل (الافتراضي للمؤشرات الجديدة). يعني الإلغاء غير المتزامن أن مؤشر الترابط يمكن إلغاؤه في أي وقت (عادةً على الفور، ولكن النظام لا يضمن ذلك). يعني الإلغاء المؤجل أن الإلغاء سيتأخر حتى يقوم مؤشر الترابط باستدعاء دالة تمثل نقطة إلغاء. يتم توفير قائمة بالدوال التي تكون أو قد تكون نقاط إلغاء في pthreads(7).

عندما يتم التعامل مع طلب إلغاء، تحدث الخطوات التالية لـ thread (بهذا الترتيب):

(1)
يتم تفريغ معالجات التنظيف للإلغاء (بالترتيب العكسي الذي تم بها دفعها) واستدعاؤها. (انظر pthread_cleanup_push(3).)
(2)
يتم استدعاء مدمرات البيانات الخاصة بمؤشر الترابط، بترتيب غير محدد. (انظر pthread_key_create(3).)
(3)
يتم إنهاء مؤشر الترابط. (انظر pthread_exit(3).)

تحدث الخطوات المذكورة أعلاه بشكل غير متزامن فيما يتعلق باستدعاء pthread_cancel(); يخبر رمز الإرجاع الخاص بـ pthread_cancel() المتصل فقط ما إذا كان طلب الإلغاء قد تم وضعه في قائمة الانتظار بنجاح.

بعد إنهاء مؤشر الترابط الملغى، فإن الانضمام مع مؤشر الترابط هذا باستخدام pthread_join(3) يحصل على PTHREAD_CANCELED كحالة خروج لمؤشر الترابط. (الانضمام مع مؤشر ترابط هو الطريقة الوحيدة لمعرفة اكتمال الإلغاء.)

قيمة الإرجاع

عند النجاح، تُرجع pthread_cancel() القيمة 0؛ عند حدوث خطأ، تُرجع رقم خطأ غير صفري.

الأخطاء

ESRCH
لم يتم العثور على مؤشر ترابط بالمعرف thread.

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
pthread_cancel () أمان مؤشرات الترابط MT-Safe

الإصدارات

في Linux، يتم تنفيذ الإلغاء باستخدام الإشارات. ضمن تنفيذ مؤشرات الترابط NPTL، يتم استخدام أول إشارة في الوقت الفعلي (أي الإشارة 32) لهذا الغرض. في LinuxThreads، يتم استخدام الإشارة الثانية في الوقت الفعلي، إذا كانت إشارات الوقت الفعلي متاحة، وإلا فسيتم استخدام SIGUSR2.

المعايير

POSIX.1-2008.

التاريخ

glibc 2.0 POSIX.1-2001.

أمثلة

يقوم البرنامج التالي بإنشاء مؤشر ترابط ثم إلغائه. ينضم مؤشر الترابط الرئيسي مع مؤشر الترابط الملغى للتحقق من أن حالة خروجه كانت PTHREAD_CANCELED. يوضح جلسة shell التالية ما يحدث عند تشغيل البرنامج:


$ ./a.out
thread_func(): started; cancelation disabled
main(): sending cancelation request
thread_func(): about to enable cancelation
main(): thread was canceled

مصدر البرنامج

#include <err.h>
#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
static void *
thread_func(void *ignored_argument)
{
    int s;
    /* Disable cancelation for a while, so that we don't
       immediately react to a cancelation request.  */
    s = pthread_setcancelstate(PTHREAD_CANCEL_DISABLE, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setcancelstate");
    printf("%s(): started; cancelation disabled\n", __func__);
    sleep(5);
    printf("%s(): about to enable cancelation\n", __func__);
    s = pthread_setcancelstate(PTHREAD_CANCEL_ENABLE, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_setcancelstate");
    /* sleep() is a cancelation point.  */
    sleep(1000);        /* Should get canceled while we sleep */
    /* Should never get here.  */
    printf("%s(): not canceled!\n", __func__);
    return NULL;
}
int
main(void)
{
    pthread_t thr;
    void *res;
    int s;
    /* Start a thread and then send it a cancelation request.  */
    s = pthread_create(&thr, NULL, &thread_func, NULL);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_create");
    sleep(2);           /* Give thread a chance to get started */
    printf("%s(): sending cancelation request\n", __func__);
    s = pthread_cancel(thr);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_cancel");
    /* Join with thread to see what its exit status was.  */
    s = pthread_join(thr, &res);
    if (s != 0)
        errc(EXIT_FAILURE, s, "pthread_join");
    if (res == PTHREAD_CANCELED)
        printf("%s(): thread was canceled\n", __func__);
    else
        printf("%s(): thread wasn't canceled (shouldn't happen!)\n",
               __func__);
    exit(EXIT_SUCCESS);
}
