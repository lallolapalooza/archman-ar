PTHREAD_BARRIER_DESTROY(3P) دليل مبرمج POSIX PTHREAD_BARRIER_DESTROY(3P)

مقدمة

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تنفيذ هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا تكون الواجهة مطبقة في لينكس.

الاسم

pthread_barrier_destroy, pthread_barrier_init — تدمير وتهيئة كائن حاجز

الملخص

#include <pthread.h>
int pthread_barrier_destroy(pthread_barrier_t *barrier);
int pthread_barrier_init(pthread_barrier_t *restrict barrier,
    const pthread_barrierattr_t *restrict attr, unsigned count);

الوصف

تقوم الدالة pthread_barrier_destroy() بتدمير الحاجز المشار إليه بواسطة barrier وتحرير أي موارد يستخدمها الحاجز. يكون تأثير الاستخدام اللاحق للحاجز غير محدد حتى يتم إعادة تهيئة الحاجز بواسطة استدعاء آخر لـ pthread_barrier_init(). قد تستخدم التنفيذية هذه الدالة لتعيين barrier إلى قيمة غير صالحة. النتائج غير محددة إذا تم استدعاء pthread_barrier_destroy() بينما كان أي خيط (thread) عالقًا عند الحاجز، أو إذا تم استدعاء هذه الدالة مع حاجز غير مهيأ.

تقوم الدالة pthread_barrier_init() بتخصيص أي موارد مطلوبة لاستخدام الحاجز المشار إليه بواسطة barrier وتقوم بتهيئة الحاجز بالسمات المشار إليها بواسطة attr. إذا كان attr يساوي NULL، يتم استخدام سمات الحاجز الافتراضية؛ يكون التأثير هو نفسه تمرير عنوان كائن سمات حاجز افتراضي. النتائج غير محددة إذا تم استدعاء pthread_barrier_init() بينما كان أي خيط عالقًا عند الحاجز (أي، لم يعد من استدعاء pthread_barrier_wait()). النتائج غير محددة إذا تم استخدام حاجز دون تهيئته أولاً. النتائج غير محددة إذا تم استدعاء pthread_barrier_init() مع تحديد حاجز مهيأ بالفعل.

يحدد الوسيط count عدد الخيوط التي يجب أن تستدعي pthread_barrier_wait() قبل أن يعود أي منها بنجاح من الاستدعاء. يجب أن تكون القيمة المحددة بواسطة count أكبر من الصفر.

إذا فشلت الدالة pthread_barrier_init()، فلن يتم تهيئة الحاجز وتكون محتويات barrier غير محددة.

انظر القسم 2.9.9، نسخ كائنات المزامنة والتعيينات البديلة لمزيد من المتطلبات.

قيمة الإرجاع

عند اكتمالها بنجاح، تعيد هذه الدوال صفرًا؛ وإلا، يتم إرجاع رقم خطأ للإشارة إلى الخطأ.

الأخطاء

ستفشل الدالة pthread_barrier_init() في الحالات التالية:

EAGAIN
يفتقر النظام إلى الموارد اللازمة لتهيئة حاجز آخر.
EINVAL
القيمة المحددة بواسطة count تساوي صفرًا.
ENOMEM
لا توجد ذاكرة كافية لتهيئة الحاجز.

لن تعيد هذه الدوال رمز خطأ [EINTR].

الأقسام التالية إعلامية.

المنطق

إذا اكتشفت التنفيذية أن القيمة المحددة بواسطة الوسيط barrier للدالة pthread_barrier_destroy() لا تشير إلى كائن حاجز مهيأ، فمن المستحسن أن تفشل الدالة وتُرجع خطأ [EINVAL].

إذا اكتشفت التنفيذية أن القيمة المحددة بواسطة الوسيط attr للدالة pthread_barrier_init() لا تشير إلى كائن سمات حاجز مهيأ، فمن المستحسن أن تفشل الدالة وتُرجع خطأ [EINVAL].

إذا اكتشفت التنفيذية أن القيمة المحددة بواسطة الوسيط barrier للدالة pthread_barrier_destroy() أو pthread_barrier_init() تشير إلى حاجز قيد الاستخدام (على سبيل المثال، في استدعاء pthread_barrier_wait()) بواسطة خيط آخر، أو اكتشفت أن القيمة المحددة بواسطة الوسيط barrier للدالة pthread_barrier_init() تشير إلى كائن حاجز مهيأ بالفعل، فمن المستحسن أن تفشل الدالة وتُرجع خطأ [EBUSY].

pthread_barrier_destroy(3p)

الوصف

pthread_barrier_destroy هي دالة في واجهة POSIX threads (pthreads) تُستخدم لتدمير حاجز.

الصيغة

int pthread_barrier_destroy(pthread_barrier_t *barrier);

المعاملات

  • barrier: مؤشر إلى متغير حاجز من نوع pthread_barrier_t.

القيمة المُعادة

عند النجاح، تُعيد الدالة 0. عند الفشل، تُعيد رقم خطأ موجب.

الأخطاء

  • EBUSY: إذا كان هناك أي مؤشرات threads تنتظر عند الحاجز.
  • EINVAL: إذا كانت قيمة barrier غير صالحة.

التوافق

هذه الدالة متوافقة مع معيار POSIX.1-2008.

ملاحظات

قبل استدعاء pthread_barrier_destroy، يجب التأكد من أن جميع مؤشرات threads التي قد تكون تنتظر عند الحاجز قد أكملت استدعاء pthread_barrier_wait الخاص بها. إذا لم يكن الأمر كذلك، فإن استدعاء pthread_barrier_destroy سيفشل مع الخطأ EBUSY.

بعد تدمير الحاجز، لا ينبغي استخدامه مرة أخرى.

مثال

#include <pthread.h>
#include <stdio.h>
#include <stdlib.h>

#define NUM_THREADS 5

pthread_barrier_t my_barrier;

void *thread_function(void *arg) {
    printf("Thread %ld is waiting at the barrier.\n", (long)arg);
    pthread_barrier_wait(&my_barrier);
    printf("Thread %ld has passed the barrier.\n", (long)arg);
    return NULL;
}

int main() {
    pthread_t threads[NUM_THREADS];
    int rc;
    long i;

    // Initialize the barrier
    rc = pthread_barrier_init(&my_barrier, NULL, NUM_THREADS);
    if (rc != 0) {
        fprintf(stderr, "Error initializing barrier: %d\n", rc);
        exit(EXIT_FAILURE);
    }

    // Create threads
    for (i = 0; i < NUM_THREADS; i++) {
        rc = pthread_create(&threads[i], NULL, thread_function, (void *)i);
        if (rc != 0) {
            fprintf(stderr, "Error creating thread %ld: %d\n", i, rc);
            exit(EXIT_FAILURE);
        }
    }

    // Wait for threads to complete (optional in this example, but good practice)
    for (i = 0; i < NUM_THREADS; i++) {
        pthread_join(threads[i], NULL);
    }

    // Destroy the barrier
    rc = pthread_barrier_destroy(&my_barrier);
    if (rc != 0) {
        fprintf(stderr, "Error destroying barrier: %d\n", rc);
        // Note: If EBUSY occurs here, it means some threads might still be stuck
        // or the barrier wasn't properly used.
        exit(EXIT_FAILURE);
    }

    printf("Barrier destroyed successfully.\n");

    return 0;
}
