pt-slave-delay - check MySQL replication slave lag

SYNOPSIS

pt-slave-delay [OPTIONS]

DESCRIPTION

pt-slave-delay is a tool that checks MySQL replication slave lag. It can monitor one or more slaves and report when they are lagging behind the master.

OPTIONS

This tool supports the following command-line options:

--ask-pass
Prompt for a password when connecting to MySQL.
--databases
Comma-separated list of databases to check. If not specified, all databases are checked.
--delay
The maximum allowed replication delay in seconds. If the lag exceeds this value, a warning is issued. Defaults to 60 seconds.
--host
Connect to this MySQL host. Defaults to localhost.
--interval
Check the replication lag every N seconds. Defaults to 30 seconds.
--password
Password to use when connecting to MySQL.
--port
Port to use for MySQL connection. Defaults to 3306.
--user
User to use when connecting to MySQL. Defaults to the current OS user.

EXAMPLE

Check replication lag for all slaves, with a maximum allowed delay of 120 seconds, checking every 60 seconds: 

    pt-slave-delay --delay 120 --interval 60

pt-slave-delay

pt-slave-delay - التحقق من تأخر استنساخ MySQL

الملخص

pt-slave-delay [خيارات]

الوصف

pt-slave-delay هي أداة تتحقق من تأخر استنساخ MySQL. يمكنها مراقبة واحد أو أكثر من الـ slaves والإبلاغ عندما يتأخرون عن الـ master.

الخيارات

تدعم هذه الأداة خيارات سطر الأوامر التالية:

--ask-pass
اطلب كلمة مرور عند الاتصال بـ MySQL.
--databases
قائمة مفصولة بفواصل بقواعد البيانات للتحقق منها. إذا لم يتم تحديدها، يتم التحقق من جميع قواعد البيانات.
--delay
أقصى تأخير استنساخ مسموح به بالثواني. إذا تجاوز التأخير هذه القيمة، يتم إصدار تحذير. القيمة الافتراضية هي 60 ثانية.
--host
الاتصال بـ مضيف MySQL هذا. الافتراضي هو localhost.
--interval
تحقق من تأخر الاستنساخ كل N ثانية. الافتراضي هو 30 ثانية.
--password
كلمة المرور المراد استخدامها عند الاتصال بـ MySQL.
--port
المنفذ المراد استخدامه لاتصال MySQL. الافتراضي هو 3306.
--user
المستخدم المراد استخدامه عند الاتصال بـ MySQL. الافتراضي هو مستخدم نظام التشغيل الحالي.

مثال

تحقق من تأخر الاستنساخ لجميع الـ slaves، مع أقصى تأخير مسموح به قدره 120 ثانية، والتحقق كل 60 ثانية: 

    pt-slave-delay --delay 120 --interval 60
