pthread_mutexattr_setkind_np(3) دليل الدوال المكتبية pthread_mutexattr_setkind_np(3)

الاسم

pthread_mutexattr_setkind_np, pthread_mutexattr_getkind_np - سمات إنشاء القفل (mutex) مهملة

الملخص

#include <pthread.h>
int pthread_mutexattr_setkind_np(pthread_mutexattr_t *attr, int kind);
int pthread_mutexattr_getkind_np(const pthread_mutexattr_t *attr,
                                 int *kind);

الوصف

هذه الدوال مهملة، استخدم pthread_mutexattr_settype(3) و pthread_mutexattr_gettype(3) بدلاً منها.

قيمة الإرجاع

pthread_mutexattr_getkind_np() ترجع دائماً 0.

pthread_mutexattr_setkind_np() ترجع 0 عند النجاح ورمز خطأ غير صفري عند الفشل.

الأخطاء

عند الفشل، ترجع pthread_mutexattr_setkind_np() رمز الخطأ التالي:

EINVAL
kind ليست PTHREAD_MUTEX_FAST_NP ولا PTHREAD_MUTEX_RECURSIVE_NP ولا PTHREAD_MUTEX_ERRORCHECK_NP.

راجع أيضاً

pthread_mutexattr_settype(3), pthread_mutexattr_gettype(3).
