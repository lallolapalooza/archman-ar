PTHREAD_ATTR_GETDETACHSTATE(3P) دليل مبرمج POSIX PTHREAD_ATTR_GETDETACHSTATE(3P)

مقدمة

هذه الصفحة الدليلية جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

pthread_attr_getdetachstate, pthread_attr_setdetachstate — الحصول وتعيين خاصية حالة الانفصال (detachstate)

الملخص

#include <pthread.h>
int pthread_attr_getdetachstate(const pthread_attr_t *attr,
    int *detachstate);
int pthread_attr_setdetachstate(pthread_attr_t *attr, int detachstate);

الوصف

تتحكم خاصية detachstate فيما إذا كان سيتم إنشاء الخيط في حالة منفصلة. إذا تم إنشاء الخيط بشكل منفصل، فإن استخدام معرّف الخيط المنشأ حديثًا بواسطة الدالة pthread_detach() أو pthread_join() يعتبر خطأ.

تقوم الدالتان pthread_attr_getdetachstate() و pthread_attr_setdetachstate()، على التوالي، بالحصول على خاصية detachstate وتعيينها في الكائن attr.

بالنسبة للدالة pthread_attr_getdetachstate()، يجب تعيين detachstate إما إلى PTHREAD_CREATE_DETACHED أو PTHREAD_CREATE_JOINABLE.

بالنسبة للدالة pthread_attr_setdetachstate()، يجب على التطبيق تعيين detachstate إما إلى PTHREAD_CREATE_DETACHED أو PTHREAD_CREATE_JOINABLE.

سيؤدي تعيين PTHREAD_CREATE_DETACHED إلى وضع جميع الخيوط المنشأة باستخدام attr في حالة منفصلة، بينما سيؤدي استخدام PTHREAD_CREATE_JOINABLE إلى وضع جميع الخيوط المنشأة باستخدام attr في حالة قابلة للانضمام. القيمة الافتراضية لخاصية detachstate هي PTHREAD_CREATE_JOINABLE.

السلوك غير محدد إذا كانت القيمة المحددة بواسطة الوسيط attr للدالة pthread_attr_getdetachstate() أو pthread_attr_setdetachstate() لا تشير إلى كائن سمات خيط تم تهيئته.

قيمة الإرجاع

عند اكتمالها بنجاح، تعيد الدالتان pthread_attr_getdetachstate() و pthread_attr_setdetachstate() القيمة 0؛ وإلا، يتم إرجاع رقم خطأ للإشارة إلى الخطأ.

تقوم الدالة pthread_attr_getdetachstate() بتخزين قيمة خاصية detachstate في detachstate عند النجاح.

الأخطاء

ستفشل الدالة pthread_attr_setdetachstate() إذا:

EINVAL
كانت قيمة detachstate غير صالحة

لن تعيد هاتان الدالتان رمز خطأ [EINTR].

الأقسام التالية معلوماتية.

أمثلة

استرجاع خاصية حالة الانفصال

يوضح هذا المثال كيفية الحصول على خاصية detachstate لكائن سمات الخيط.

#include <pthread.h>
pthread_attr_t thread_attr;
int            detachstate;
int            rc;
/* كود تهيئة thread_attr */
...
rc = pthread_attr_getdetachstate (&thread_attr, &detachstate);
if (rc!=0) {
    /* التعامل مع الخطأ */
    ...
}
else {
    /* القيم القانونية لـ detachstate هي:
     * PTHREAD_CREATE_DETACHED أو PTHREAD_CREATE_JOINABLE
     */
     ...
}

لا شيء.

المنطق

إذا اكتشف تطبيق أن القيمة المحددة بواسطة الوسيط attr للدالة pthread_attr_getdetachstate() أو pthread_attr_setdetachstate() لا تشير إلى كائن سمات خيط تم تهيئته، فمن المستحسن أن تفشل الدالة وبلغ عن خطأ [EINVAL].
