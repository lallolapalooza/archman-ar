NAME

pthread_join - join with a terminated thread

SYNOPSIS

#include <pthread.h>

int pthread_join(pthread_t thread, void **retval);

DESCRIPTION

The pthread_join() function shall suspend execution of the calling thread until the thread specified by thread terminates. When the terminated thread is joined with a calling thread, it shall be able to retrieve its termination status in the location pointed to by retval.

If retval is not NULL, then the value passed to pthread_exit() by the terminating thread, or the value returned by the thread's start routine, shall be placed in the location pointed to by retval. If the thread was terminated, and was not explicitly created with pthread_exit() or an explicit return from its start routine, then the value passed to pthread_exit(status) is the value status. If the thread was canceled, then the value passed to pthread_join() in retval is that of the macro PTHREAD_CANCELED.

If the thread specified by thread has already terminated, a return from pthread_join() shall occur immediately.

A thread can be joined with only a single other thread. If more than one thread attempts to join with the same thread, the behavior is undefined.

RETURN VALUE

On success, pthread_join() returns 0; otherwise, an error number is returned to indicate the error.

ERRORS

EINVAL
The value specified by thread is not a joinable thread.
ESRCH
No thread could be found with the ID equal to thread.
EDEADLK
A deadlock was detected. This can occur, for example, if a thread tries to join with itself, or if there is a cycle in the join dependencies.
