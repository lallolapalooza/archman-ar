pthread_mutex_getprioceiling(3p)

pthread_mutex_getprioceiling - get the priority ceiling of a mutex

Name

pthread_mutex_getprioceiling - get the priority ceiling of a mutex

Syntax

#include <pthread.h>

int pthread_mutex_getprioceiling(pthread_mutex_t *restrict mutex,
    int *restrict priority_ceiling);

Parameters

The function takes the following parameters:

mutex
A pointer to the mutex for which to retrieve the priority ceiling. The mutex must have been successfully initialized.
priority_ceiling
A pointer to an integer where the priority ceiling of the mutex will be stored.

Description

The pthread_mutex_getprioceiling function retrieves the priority ceiling of the mutex referred to by mutex.

The priority ceiling of a mutex is a scheduling priority. When a thread acquires a mutex with a priority ceiling, its effective scheduling priority is raised to the priority ceiling, if the ceiling is higher than the thread's current priority. This mechanism is used to prevent priority inversion.

The value of the priority ceiling is set when the mutex is initialized using pthread_mutex_init with the PTHREAD_PRIO_INHERIT or PTHREAD_PRIO_PROTECT attribute set, or when using pthread_mutex_setprioceiling.

Return Value

On success, pthread_mutex_getprioceiling returns 0.

On error, it returns a non-zero error number, and the contents of the location pointed to by priority_ceiling are indeterminate.

Errors

EINVAL
mutex or priority_ceiling is an invalid pointer, or the mutex has not been initialized.
ENOTSUP
The system does not support the priority ceiling feature for mutexes.

Examples

#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

int main() {
    pthread_mutex_t mutex;
    int prio_ceiling;
    int ret;

    // Initialize a mutex with priority ceiling support
    pthread_mutexattr_t attr;
    pthread_mutexattr_init(&attr);
    pthread_mutexattr_settype(&attr, PTHREAD_MUTEX_NORMAL);
    pthread_mutexattr_setprioceiling(&attr, 50); // Example priority ceiling
    pthread_mutex_init(&mutex, &attr);
    pthread_mutexattr_destroy(&attr);

    // Get the priority ceiling
    ret = pthread_mutex_getprioceiling(&mutex, &prio_ceiling);
    if (ret != 0) {
        perror("pthread_mutex_getprioceiling");
        return 1;
    }

    printf("Priority ceiling of the mutex: %d\n", prio_ceiling);

    // Destroy the mutex
    pthread_mutex_destroy(&mutex);

    return 0;
}

Conforming To

POSIX.1-2001, POSIX.1-2008.

pthread_mutex_getprioceiling(3p)

pthread_mutex_getprioceiling - الحصول على سقف الأولوية للـ mutex

الاسم

pthread_mutex_getprioceiling - الحصول على سقف الأولوية للـ mutex

الصيغة

#include <pthread.h>

int pthread_mutex_getprioceiling(pthread_mutex_t *restrict mutex,
    int *restrict priority_ceiling);

المعلمات

تأخذ الدالة المعلمات التالية:

mutex
مؤشر إلى الـ mutex الذي سيتم استرداد سقف الأولوية الخاص به. يجب أن يكون الـ mutex قد تم تهيئته بنجاح.
priority_ceiling
مؤشر إلى عدد صحيح حيث سيتم تخزين سقف أولوية الـ mutex.

الوصف

تقوم الدالة pthread_mutex_getprioceiling باسترداد سقف أولوية الـ mutex المشار إليه بواسطة mutex.

سقف أولوية الـ mutex هو أولوية جدولة. عندما تحصل خيط على mutex بسقف أولوية، يتم رفع أولوية الجدولة الفعالة الخاصة به إلى سقف الأولوية، إذا كان السقف أعلى من الأولوية الحالية للخيط. تُستخدم هذه الآلية لمنع انعكاس الأولوية.

يتم تعيين قيمة سقف الأولوية عند تهيئة الـ mutex باستخدام pthread_mutex_init مع تعيين السمة PTHREAD_PRIO_INHERIT أو PTHREAD_PRIO_PROTECT، أو عند استخدام pthread_mutex_setprioceiling.

قيمة الإرجاع

عند النجاح، ترجع الدالة pthread_mutex_getprioceiling القيمة 0.

عند حدوث خطأ، فإنها ترجع رقم خطأ غير صفري، وتكون محتويات الموقع الذي يشير إليه priority_ceiling غير محددة.

الأخطاء

EINVAL
mutex أو priority_ceiling هو مؤشر غير صالح، أو لم يتم تهيئة الـ mutex.
ENOTSUP
النظام لا يدعم ميزة سقف الأولوية للـ mutexes.

#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>

int main() {
    pthread_mutex_t mutex;
    int prio_ceiling;
    int ret;

    // Initialize a mutex with priority ceiling support
    pthread_mutexattr_t attr;

    pthread_mutexattr_setprioceiling(&attr, 50); // Example priority ceiling
    pthread_mutex_init(&mutex, &attr);
    pthread_mutexattr_destroy(&attr);

    // Get the priority ceiling
    ret = pthread_mutex_getprioceiling(&mutex, &prio_ceiling);
    if (ret != 0) {
        perror("pthread_mutex_getprioceiling");
        return 1;
    }

    printf("Priority ceiling of the mutex: %d\n", prio_ceiling);

    // Destroy the mutex
    pthread_mutex_destroy(&mutex);

    return 0;
}
