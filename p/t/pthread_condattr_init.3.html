pthread_condattr_init(3) دليل الدوال المكتبية pthread_condattr_init(3)

الاسم

pthread_condattr_init, pthread_condattr_destroy - سمات إنشاء الشرط

الشكل العام

#include <pthread.h>

int pthread_condattr_init(pthread_condattr_t *attr); int pthread_condattr_destroy(pthread_condattr_t *attr);

الوصف

يمكن تحديد سمات الشرط عند إنشاء الشرط، عن طريق تمرير كائن سمات الشرط كوسيط ثانٍ إلى pthread_cond_init(3). تمرير NULL يعادل تمرير كائن سمات الشرط مع تعيين جميع السمات إلى قيمها الافتراضية.

تنفيذ LinuxThreads لا يدعم أي سمات للشروط. الدوال المتعلقة بسمات الشروط مدرجة فقط للامتثال لمعيار POSIX.

تقوم pthread_condattr_init() بتهيئة كائن سمات الشرط attr وتعبئته بالقيم الافتراضية للسمات. تقوم pthread_condattr_destroy() بتدمير كائن سمات الشرط، والذي يجب عدم إعادة استخدامه حتى يتم إعادة تهيئته. كلتا الدالتين لا تفعلان شيئًا في تنفيذ LinuxThreads.

قيمة الإرجاع

pthread_condattr_init() و pthread_condattr_destroy() ترجعان دائمًا 0.

انظر أيضًا

pthread_cond_init(3).
