pthread_tryjoin_np(3) دليل الوظائف المكتبية pthread_tryjoin_np(3)

الاسم

pthread_tryjoin_np, pthread_timedjoin_np - محاولة الانضمام إلى خيط منتهٍ

المكتبة

مكتبة خيوط POSIX (libpthread, -lpthread)

الملخص

#define _GNU_SOURCE             /* انظر feature_test_macros(7) */
#include <pthread.h>
int pthread_tryjoin_np(pthread_t thread, void **retval);
int pthread_timedjoin_np(pthread_t thread, void **retval,
                         const struct timespec *abstime);

الوصف

تعمل هذه الوظائف بنفس طريقة pthread_join(3)، باستثناء الاختلافات الموضحة في هذه الصفحة.

تنفذ الوظيفة pthread_tryjoin_np() عملية انضمام غير حاجزة مع الخيط thread، وتعيد حالة انتهاء الخيط في *retval. إذا لم يكن thread قد انتهى بعد، فبدلاً من الحظر، كما تفعل pthread_join(3)، تعيد الاستدعاء خطأ.

تنفذ الوظيفة pthread_timedjoin_np() عملية انضمام مع مهلة زمنية. إذا لم يكن thread قد انتهى بعد، فإن الاستدعاء يحظر لمدة أقصاها، محددة في abstime، يتم قياسها مقابل ساعة CLOCK_REALTIME. إذا انتهت المهلة الزمنية قبل انتهاء thread، فيعيد الاستدعاء خطأ. الوسيط abstime هو هيكل timespec(3)، يحدد وقتًا مطلقًا مقاسًا منذ Epoch (انظر time(2)).

قيمة الإرجاع

عند النجاح، تعيد هذه الوظائف 0؛ عند حدوث خطأ، فإنها تعيد رقم خطأ.

الأخطاء

يمكن أن تفشل هذه الوظائف بنفس الأخطاء مثل pthread_join(3). يمكن أن تفشل pthread_tryjoin_np() بالإضافة إلى الأخطاء التالية:

EBUSY
thread لم يكن قد انتهى بعد وقت الاستدعاء.

يمكن أن تفشل pthread_timedjoin_np() بالإضافة إلى الأخطاء التالية:

EINVAL
قيمة abstime غير صالحة (tv_sec أقل من 0 أو tv_nsec أكبر من 1e9).
ETIMEDOUT
انتهت مهلة الاستدعاء قبل انتهاء thread.

pthread_timedjoin_np() لا تعيد الخطأ EINTR أبدًا.

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
pthread_tryjoin_np (), pthread_timedjoin_np () أمان الخيط MT-Safe

المعايير

GNU؛ لذا فإن اللاحقة "_np" (غير قابلة للنقل) في الأسماء.

التاريخ

glibc 2.3.3.

الأخطاء

تقيس الوظيفة pthread_timedjoin_np() الوقت عن طريق حساب داخلي لفترة نوم نسبية يتم قياسها بعد ذلك مقابل ساعة CLOCK_MONOTONIC بدلاً من ساعة CLOCK_REALTIME. نتيجة لذلك، لا تتأثر المهلة الزمنية بالتغييرات غير المتصلة على ساعة CLOCK_REALTIME.

أمثلة

ينتظر الكود التالي للانضمام لمدة تصل إلى 5 ثوانٍ:


struct timespec ts;
int s;
...
if (clock_gettime(CLOCK_REALTIME, &ts) == -1) {
    /* التعامل مع الخطأ */
}
ts.tv_sec += 5;
s = pthread_timedjoin_np(thread, NULL, &ts);
if (s != 0) {
    /* التعامل مع الخطأ */
}
