NAME

purifyeps — purify PostScript files for use with pdfTeX

SYNOPSIS

purifyeps [-flag...] [file...]

DESCRIPTION

The PostScript language specification allows arbitrary code to be included in a PostScript file. This can be a security risk, as it allows malicious code to be executed by a PostScript interpreter. purifyeps is a script that reads PostScript files, removes comments, and removes potentially dangerous commands, making them safe to include in documents processed by pdfTeX.

Although pdfTeX can process PostScript files directly, it normally only understands files that contain only level 3 PostScript commands. purifyeps strips out comments and any PostScript code that is not understood by pdfTeX.

In general, it is preferable to use the PDF, JPEG, PNG, or GIF file formats when possible, as they are directly understood by pdfTeX and do not require conversion. However, if you must use EPS files, purifyeps can help make them safe.

OPTIONS

Currently, no options are supported.

EXAMPLES

To purify a file named mygraphic.eps, run:

purifyeps mygraphic.eps

This will create a new file named mygraphic.eps which contains the purified PostScript code. The original file will be overwritten.

If you want to include EPS files in your LaTeX document and have pdfLaTeX understand them, you can instruct pdfLaTeX to use them. The pdfLaTeX configuration of the "graphics" and "graphicx" packages (pdftex.def) normally ignores .eps files. Putting the following LaTeX code in your document's preamble tells pdfLaTeX that all .eps files are in MPS format:

% Tell pdfLaTeX that all .eps files were produced by MetaPost.
\usepackage{graphicx} % or graphics
\usepackage{ifpdf}
\ifpdf
  \DeclareGraphicsRule{.eps}{mps}{*}{}
  \makeatletter
    \g@addto@macro\Gin@extensions{,.eps}
  \makeatother
\fi

FILES

The script uses the standard PostScript interpreter for cleaning the files. The name of the interpreter is hardcoded into the script.

BUGS

The script is not foolproof. It is possible for a malicious PostScript file to bypass the security checks. Use with caution.
