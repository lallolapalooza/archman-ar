PublicInbox__Git(3pm)

الحزمة: perl-publicinbox

التراخيص: AGPL

PublicInbox::Git(3) توثيق مساهمة المستخدم في Perl PublicInbox::Git(3)

الاسم

PublicInbox::Git - غلاف git

الإصدار

الإصدار 1.0

الملخص

use PublicInbox::Git;
chomp(my $git_dir = `git rev-parse --git-dir`);
$git_dir or die "يجب تحديد GIT_DIR=\n";
my $git = PublicInbox::Git->new($git_dir);

الوصف

واجهة برمجة تطبيقات غير مستقرة خارج طريقة "new". يتطلب تثبيت git(1).

الطرق

new

my $git = PublicInbox::Git->new($git_dir);

تهيئة كائن PublicInbox::Git جديد لاستخدامه مع PublicInbox::Import. هذه هي طريقة واجهة برمجة التطبيقات العامة الوحيدة التي ندعمها. كل شيء آخر في هذه الوحدة يخضع للتغيير.

راجع أيضًا

Git, PublicInbox::Import
