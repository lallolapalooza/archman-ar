puppet(8)

الحزمة: puppet

التراخيص: Apache-2.0

PUPPET(8) دليل Puppet PUPPET(8)

الاسم

puppet - أداة إدارة التكوين الآلي

الملخص

puppet أمر فرعي [خيارات] إجراء [خيارات]

الوصف

Puppet، محرك إدارة آلي لأنظمة Linux و Unix و Windows الخاصة بك، ينفذ المهام الإدارية (مثل إضافة المستخدمين، وتثبيت الحزم، وتحديث تكوينات الخادم) بناءً على مواصفات مركزية.

الأوامر

الشائعة

apply
    تطبيق تعليمات Puppet البرمجية محليًا

agent
    خدمة وكيل puppet

config
    التفاعل مع إعدادات Puppet.

help
    عرض مساعدة Puppet.

lookup
    بحث Hiera تفاعلي

module
    إنشاء وتثبيت والبحث عن وحدات في Puppet Forge.

resource
    واجهة طبقة تجريد الموارد

متخصصة

strings
    إنشاء توثيق Puppet باستخدام YARD.

catalog
    تجميع وحفظ وعرض وتحويل الفهارس.

describe
    عرض المساعدة حول أنواع الموارد

device
    إدارة أجهزة الشبكة عن بعد

doc
    إنشاء مراجع Puppet

epp
    التفاعل مباشرة مع محلل/عارض قوالب EPP.

facts
    استرداد وتخزين الحقائق.

filebucket
    تخزين واسترداد الملفات في filebucket

generate
    إنشاء كود Puppet من تعريفات Ruby.

node
    عرض وإدارة تعريفات العقد.

parser
    التفاعل مباشرة مع المحلل.

plugin
    التفاعل مع نظام المكونات الإضافية لـ Puppet.

script
    تشغيل نصوص برمجية لـ Puppet دون تجميع فهرس

ssl
    إدارة مفاتيح وشهادات SSL لعملاء Puppet SSL

انظر أيضًا

انظر puppet help <أمر فرعي> للحصول على المساعدة بشأن أمر فرعي محدد.

انظر puppet help <أمر فرعي> <إجراء> للحصول على المساعدة بشأن إجراء فرعي محدد.
