putpwent(3) دليل وظائف المكتبة putpwent(3)

الاسم

putpwent - كتابة إدخال في ملف كلمة المرور

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <stdio.h>
#include <sys/types.h>
#include <pwd.h>
int putpwent(const struct passwd *restrict p, FILE *restrict stream);
متطلبات ميزة الاختبار الكبرى لـ glibc (انظر feature_test_macros(7)):

putpwent():

    منذ glibc 2.19:
        _DEFAULT_SOURCE
    glibc 2.19 والإصدارات الأقدم:
        _SVID_SOURCE

الوصف

تقوم الدالة putpwent() بكتابة إدخال كلمة مرور من الهيكل p في الملف المرتبط بـ stream.

تم تعريف هيكل passwd في <pwd.h> على النحو التالي:


struct passwd {
    char    *pw_name;        /* اسم المستخدم */
    char    *pw_passwd;      /* كلمة مرور المستخدم */
    uid_t    pw_uid;         /* معرف المستخدم */
    gid_t    pw_gid;         /* معرف المجموعة */
    char    *pw_gecos;       /* الاسم الحقيقي */
    char    *pw_dir;         /* مجلد المنزل */
    char    *pw_shell;       /* برنامج الصدفة */
};

قيمة الإرجاع

ترجع الدالة putpwent() القيمة 0 عند النجاح. عند الفشل، ترجع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
تم تقديم وسيط غير صالح (NULL).

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).
