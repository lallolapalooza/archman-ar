NAME

prctl - process control operations

LIBRARY

Standard C library (libc, implemented in glibc)

SYNOPSIS

#include <sys/prctl.h>
int prctl(int option, unsigned long arg2, unsigned long arg3,
                          unsigned long arg4, unsigned long arg5);

DESCRIPTION

The prctl() system call is used to examine and change the operating characteristics of the calling process. The behavior of prctl() is determined by the value in the option argument.

The following options are available:

PR_CAPBSET_READ
Read the value of a capability bit. arg2 specifies the capability number. Returns the value of the capability bit (0 or 1). This operation is available from Linux 2.2.11.
PR_CAPBSET_DROP
Drop a capability bit. arg2 specifies the capability number. This operation is available from Linux 2.2.11.
PR_CAP_AMBIENT
Set or get ambient capabilities. arg2 specifies the operation: PR_CAP_AMBIENT_RAISE, PR_CAP_AMBIENT_LOWER, PR_CAP_AMBIENT_CLEAR_ALL. arg3 specifies the capability set. This operation is available from Linux 4.3.
PR_SET_CHILD_SUBREAPER
Set the PR_SET_CHILD_SUBREAPER bit for the calling process. If set, and the process becomes an ancestor of a process that is not a session leader and not the process group leader, then the calling process will receive a SIGCHLD signal when the child process terminates, even if the child is reparented to the init process. If arg2 is zero, the bit is cleared. This operation is available from Linux 3.4.
PR_GET_CHILD_SUBREAPER
Return the current PR_SET_CHILD_SUBREAPER setting of the calling process (0 or 1).
PR_SET_DUMPABLE
Set the dump mode for the calling process. The value in arg2 can be PR_DUMPABLE, PR_NOT_DUMPABLE, or PR_SUNDORMAL.
PR_GET_DUMPABLE
Return the current dump mode of the calling process.
PR_SET_ENDIAN
Set the endianness of the calling process. arg2 can be PR_ENDIAN_BIG or PR_ENDIAN_LITTLE.
PR_GET_ENDIAN
Return the current endianness of the calling process.
PR_SET_FPEMU
Set the floating-point emulator. arg2 can be PR_FPEMU_SIGBUS or PR_FPEMU_NOREGS.
PR_GET_FPEMU
Return the current floating-point emulator setting.
PR_SET_FPEXC
Set the floating-point exception mode. arg2 can be PR_FPEXC_DIVBYZERO, PR_FPEXC_OVERFLOW, PR_FPEXC_UNDERFLOW, PR_FPEXC_INVALID, PR_FPEXC_INEXACT.
PR_GET_FPEXC
Return the current floating-point exception mode.
PR_SET_IO_FLUSHER
Set or clear the I/O flusher flag. If set, the process will not perform I/O flushes. arg2 is 1 to set, 0 to clear.
PR_GET_IO_FLUSHER
Return the current I/O flusher flag setting.
PR_SET_KEEPCAPS
Set or clear the PR_SET_KEEPCAPS bit. If set, the calling process's capabilities are preserved across an execve(2). arg2 is 1 to set, 0 to clear.
PR_GET_KEEPCAPS
Return the current PR_SET_KEEPCAPS setting.
PR_SET_MM
Set memory management parameters. arg2 specifies the parameter to set. arg3 specifies the value.
PR_SET_VMA
Set virtual memory area properties. arg2 specifies the operation. arg3 specifies the address range. arg4 specifies the properties.
PR_MPX_ENABLE_MANAGEMENT
Enable Intel MPX (Memory Protection Keys) management. arg2 specifies the address range. This operation is available from Linux 4.0.
PR_MPX_DISABLE_MANAGEMENT
Disable Intel MPX management. This operation is available from Linux 4.0.
PR_SET_NAME
Set the name of the calling process. arg2 is a pointer to the name string. The maximum length of the name is 16 characters.
PR_GET_NAME
Get the name of the calling process. arg2 is a pointer to a buffer where the name will be stored. arg3 is the size of the buffer.
PR_SET_NO_NEW_PRIVS
Set or clear the PR_SET_NO_NEW_PRIVS bit. If set, the calling process cannot gain new privileges via execve(2). arg2 is 1 to set, 0 to clear.
PR_GET_NO_NEW_PRIVS
Return the current PR_SET_NO_NEW_PRIVS setting.
PR_SET_PDEATHSIG
Set the signal to be sent to the calling process when its parent dies. arg2 is the signal number. If arg2 is 0, no signal will be sent.
PR_GET_PDEATHSIG
Return the signal to be sent to the calling process when its parent dies.
PR_SET_PTRACER
Set the tracer process. arg2 is the PID of the tracer process. arg3 can be 0 or PR_PTRACE_SCOPED.
PR_SET_SECCOMP
Set the seccomp mode for the calling process. arg2 can be SECCOMP_MODE_STRICT or SECCOMP_MODE_FILTER.
PR_GET_SECCOMP
Return the current seccomp mode of the calling process.
PR_SET_SECUREBITS
Set the secure bits for the calling process. arg2 specifies the secure bits to set.
PR_GET_SECUREBITS
Return the current secure bits of the calling process.
PR_SET_SPECULATION_CTRL
Control speculation properties of the CPU. arg2 specifies the control. arg3 specifies the value.
PR_GET_SPECULATION_CTRL
Get speculation properties of the CPU.
PR_SVE_SET_VL
Set the SVE vector length. arg2 specifies the vector length. This operation is available on ARM SVE.
PR_SVE_GET_VL
Get the SVE vector length.
PR_SET_SYSCALL_USER_DISPATCH
Set syscall user dispatch. This operation is available from Linux 5.1.
PR_SET_TAGGED_ADDR_CTRL
Control tagged address usage. arg2 specifies the control. arg3 specifies the value. This operation is available from Linux 5.4.
PR_GET_TAGGED_ADDR_CTRL
Get tagged address usage control.
PR_TASK_PERF_EVENTS_DISABLE
Disable performance monitoring events for the calling process. This operation is available from Linux 2.6.31.
PR_TASK_PERF_EVENTS_ENABLE
Enable performance monitoring events for the calling process.
PR_SET_THP_DISABLE
Disable Transparent Huge Pages (THP) for the calling process. arg2 is 1 to disable, 0 to enable. This operation is available from Linux 3.14.
PR_GET_THP_DISABLE
Return the current THP setting.
PR_GET_TID_ADDRESS
Return the address of the thread ID structure. arg2 is a pointer to a pid_t *. This operation is available from Linux 3.1.
PR_SET_TIMERSLACK
Set the timer slack. arg2 is the timer slack value. This operation is available from Linux 2.6.38.
PR_GET_TIMERSLACK
Get the timer slack value.
PR_SET_TIMING
Set the process timing. arg2 can be PR_TIMING_TIMESTAMP or PR_TIMING_CPUCLOCK.
PR_GET_TIMING
Return the current process timing setting.
PR_SET_TSC
Set the TSC (Time Stamp Counter) behavior. arg2 can be PR_TSC_ENABLE or PR_TSC_DISABLE.
PR_GET_TSC
Return the current TSC setting.
PR_SET_UNALIGN
Set the unaligned access behavior. arg2 can be PR_UNALIGN_SIGBUS or PR_UNALIGN_NOP.
PR_GET_UNALIGN
Return the current unaligned access setting.
PR_GET_AUXV
Get the auxiliary vector. arg2 is a pointer to a buffer. arg3 is the size of the buffer. This operation is available from Linux 3.17.
PR_SET_MDWE
Set Memory-Dereference Write Enable. arg2 is a flag. This operation is available from Linux 5.15.
PR_GET_MDWE
Get Memory-Dereference Write Enable.
PR_RISCV_SET_ICACHE_FLUSH_CTX
Set the RISC-V icache flush context. This operation is available on RISC-V architecture.
PR_FUTEX_HASH
Set futex hash value. arg2 is the hash value. This operation is available from Linux 5.17.

RETURN VALUE

On success, prctl() returns 0. On failure, it returns -1, and errno is set appropriately.

ERRORS

The following errors can occur:

EINVAL
An invalid option was specified, or an invalid value was provided in arg2, arg3, arg4, or arg5.
EPERM
An attempt was made to change a process attribute that the caller does not have permission to change.
ESRCH
The process specified by option does not exist.

VERSIONS

The prctl() system call was introduced in Linux 2.1.57. The available options have been added over time.

STANDARDS

Linux.

HISTORY

Linux 2.1.57, glibc 2.0.6

CAVEATS

The prototype of the libc wrapper uses a variadic argument list. This makes it necessary to pass the arguments with the right width. When passing numeric constants, such as 0, use a suffix: 0L.

Careless use of some prctl() operations can confuse the user-space run-time environment, so these operations should be used with care.
