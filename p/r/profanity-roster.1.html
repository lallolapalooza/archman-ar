profanity-roster(1)

الحزمة: profanity

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/roster

الوصف

إدارة قائمتك (roster) وإعدادات عرض القائمة. تمرير بدون وسائط يسرد جميع جهات الاتصال في قائمتك.

الملخص

/roster

/roster online

/roster show [offline|resource|presence|status|empty|priority|contacts|rooms]

/roster hide [offline|resource|presence|status|empty|priority|contacts|rooms]

/roster by group|presence|none

/roster count unread|items|off

/roster count zero on|off

/roster color on|off

/roster order name|presence

/roster unread before|after|off

/roster room char <char>|none

/roster room private char <char>|none

/roster room position first|last

/roster room by service|none

/roster room order name|unread

/roster room unread before|after|off

/roster room title bookmark|jid|localpart|name

/roster private room|group|off

/roster private char <char>|none

/roster header char <char>|none

/roster presence indent <indent>

/roster contact char <char>|none

/roster contact indent <indent>

/roster resource char <char>|none

/roster resource indent <indent>

/roster resource join on|off

/roster size <percent>

/roster wrap on|off

/roster add <jid> [<nick>]

/roster remove <contact>

/roster remove_all contacts

/roster nick <jid> <nick>

/roster clearnick <jid>

/roster group

/roster group show <group>

/roster group add <group> <contat>

/roster group remove <group> <contact>

عرض غرف الدردشة في لوحة القائمة.

إخفاء لوحة القائمة.

إخفاء موارد الاتصال المتصلة في لوحة القائمة.

hide presence

إخفاء حضور جهة الاتصال في لوحة القائمة.

hide status

إخفاء المجموعات الفارغة في لوحة القائمة.

hide priority

إخفاء جهات الاتصال في لوحة القائمة.

إخفاء غرف الدردشة في لوحة القائمة.

by group

تجميع جهات الاتصال في لوحة القائمة حسب مجموعة القائمة.

by presence

تجميع جهات الاتصال في لوحة القائمة حسب الحضور.

by none

لا تجميع في لوحة القائمة.

count unread

عرض عدد الرسائل غير المقروءة مع رؤوس القائمة.

count items

عرض عدد العناصر مع رؤوس القائمة.

count off

لا تعرض أي عدد مع رؤوس القائمة.

count zero on

عرض عدد رؤوس القائمة عندما يكون 0.

count zero off

إخفاء عدد رؤوس القائمة عندما يكون 0.

تمكين أسماء الألوان المولدة (XEP-0392).

unread after

عرض عدد الرسائل غير المقروءة بعد جهة الاتصال.

unread off

ترتيب الغرف حسب الرسائل غير المقروءة، ثم حسب الاسم.

room unread before

عرض عدد الرسائل غير المقروءة قبل الغرفة.

room unread after

عرض عدد الرسائل غير المقروءة بعد الغرفة.

room unread off

لا تعرض عدد الرسائل غير المقروءة للغرف.

room title bookmark|jid|localpart|name

عرض اسم الإشارة المرجعية، أو JID، أو الجزء المحلي لـ JID، أو اسم الغرفة كعنوان للقائمة لـ MUCs.

private room

عرض الدردشات الخاصة بالغرفة مع الغرفة.

private group

عرض الدردشات الخاصة بالغرفة كمجموعة قائمة منفصلة.

private off

إزالة بادئة حرف رؤوس القائمة.

contact char <char>

بادئة جهات اتصال القائمة بحرف محدد.

contact char none

إزالة بادئة حرف جهات اتصال القائمة.

contact indent <indent>

إزاحة سطر جهة الاتصال بـ <indent> مسافات (من 0 إلى 10).

resource char <char>

بادئة موارد القائمة بحرف محدد.

resource char none

إزالة بادئة حرف موارد القائمة.

resource indent <indent>

إزاحة سطر المورد بـ <indent> مسافات (من 0 إلى 10).

resource join on|off

presence indent <indent>

إزاحة سطر الحضور بـ <indent> مسافات (-1 إلى 10)، قيمة -1 ستعرض الحضور في السطر السابق.

NAME

profanity-roster - Manage the roster (contact list)

DESCRIPTION

This page describes the commands available for managing the roster, which is the contact list for the Profanity XMPP client.

SYNOPSIS

/roster [command] [arguments]

ARGUMENTS

+

wrap on|off

تفعيل أو تعطيل التفاف الأسطر في لوحة قائمة جهات الاتصال.

add <jid> [<nick>]

إضافة عنصر جديد إلى قائمة جهات الاتصال.

remove <jid>

إزالة عنصر من قائمة جهات الاتصال.

remove_all contacts

إزالة جميع العناصر من قائمة جهات الاتصال.

nick <jid> <nick>

تغيير اسم مستعار لجهة اتصال.

clearnick <jid>

إزالة الاسم المستعار الحالي.

group show <group>

عرض جميع عناصر قائمة جهات الاتصال في مجموعة معينة.

group add <group> <contact>

إضافة جهة اتصال إلى مجموعة.

group remove <group> <contact>

إزالة جهة اتصال من مجموعة.

EXAMPLES

/roster

/roster add odin@valhalla.edda

/roster add odin@valhalla.edda Allfather

/roster remove loki@ownserver.org

/roster nick odin@valhalla.edda "All Father"

/roster clearnick thor@valhalla.edda

/roster size 15

/roster group

/roster group show friends

/roster group add friends fenris@ownserver.org

/roster group add family Brother

/roster group remove colleagues boss@work.com
