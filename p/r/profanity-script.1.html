profanity-script(1)

الحزمة: profanity

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/script

الوصف

تشغيل نصوص الأوامر. يتم تخزين النصوص في $XDG_DATA_HOME/profanity/scripts/ والذي عادة ما يكون $HOME/.local/share/profanity/scripts/.

الملخص

/script run <script>

/script list

/script show <script>

الوسائط

script run <script>

تنفيذ نص برمجي.

script list

قائمة بجميع النصوص البرمجية TODO.

script show <script>

عرض الأوامر في النص البرمجي TODO.

أمثلة

/script list

/script run myscript

/script show somescript
