الاسم

prerex_format -- تنسيق لوصف مخطط المتطلبات المسبقة

الوصف

يصف هذا الدليل تنسيق أوصاف مخطط المتطلبات المسبقة التي يمكن معالجتها بواسطة [pdf]latex (عادةً باستخدام ملف نمط prerex.sty(7) مناسب) وتحريرها باستخدام محرر prerex(1) التفاعلي (أو بواسطة أي محرر نصوص تقليدي).

المصطلحات

يتكون مخطط المتطلبات المسبقة من عدد من صناديق الدورات، مرتبطة بأسهم. الدورات إما نصف أو كاملة، وقد تكون مطلوبة أو اختيارية (أو لا شيء). يمكن لكل صندوق دورة أن يحتوي على رمز الدورة (الزاوية العلوية اليسرى)، عنوان الدورة (النصف السفلي)، ومعلومات الجدول الزمني (الزاوية العلوية اليمنى). يمكن أن يكون السهم إما متطلبًا مسبقًا (صلب)، أو متطلبًا مشتركًا (منقط)، أو موصى به (متقطع). عندما يكون السهم التقليدي غير مناسب، يمكن استخدام دورة مصغرة فوق صندوق الهدف.

الهيكل

يجب أن يحتوي الملف على نسخة واحدة بالضبط من بيئة LaTeX

\begin{chart} تعليمة ... \end{chart}

مع تعليمة واحدة على الأكثر في كل سطر. لاحظ أن برنامجًا مثل prerex(1) يحلل ملفات تنسيق prerex بدون استخدام TeX؛ على سبيل المثال، سيتم تجاهل تعريفات الماكرو ولن يتم توسيع استدعاءات الماكرو.

يمكن أن تسبق التعليمات مسافات بيضاء. تُعامل الأسطر التي تبدأ بـ % كتعليقات ويتم تجاهلها. ترتيب التعليمات ليس مهمًا إلا أن التعليمات الخاصة بصندوق المصدر والهدف للسهم يجب أن تسبق التعليمات الخاصة بالسهم. يتم وصف تنسيقات التعليمات في الأقسام التالية.

صناديق الدورات

تأخذ التعليمات التي تنتج صناديق الدورات الأشكال التالية:

\halfcourse x,y:{code}{title}{timetable}

\fullcourse x,y:{code}{title}{timetable}

\reqhalfcourse x,y:{code}{title}{timetable}

\reqfullcourse x,y:{code}{title}{timetable}

\opthalfcourse x,y:{code}{title}{timetable}

\optfullcourse x,y:{code}{title}{timetable}

حيث x,y هي إحداثيات النقطة المركزية للصندوق، بالنسبة إلى الأصل في نظام الإحداثيات في الزاوية السفلية اليسرى للمخطط. الوسائط code، title، و timetable هي نصوص اعتباطية (مع أقواس جيدة)، ربما تحتوي على ترميز LaTeX.

الأشكال التالية مشابهة ولكنها تأخذ وسيطًا إضافيًا لتحديد لون الخلفية (غير الافتراضي) لصندوق الدورة:

\halfcoursec x,y:{code}{title}{timetable}{color}
\fullcoursec x,y:{code}{title}{timetable}{color}
\reqhalfcoursec x,y:{code}{title}{timetable}{color}
\reqfullcoursec x,y:{code}{title}{timetable}{color}
\opthalfcoursec x,y:{code}{title}{timetable}{color}
\optfullcoursec x,y:{code}{title}{timetable}{color}

صناديق الدورات المصغرة والنصوص

يتم إنتاج دورة مصغرة بواسطة تعليمات من الشكل

\mini x,y:{code}

يتم إدراج سطر نص في المخطط بواسطة تعليمات من الشكل

\text x,y:{line-of-text}

الحد الأقصى المسموح به لطول رمز الدورة قد يكون أصغر من الحد الأقصى المسموح به لسطر نص.

الأسهم

يتم إنتاج الأسهم بين صناديق الدورات (أو من دورة مصغرة إلى صندوق دورة) بواسطة تعليمات من الشكل

\prereq x0,y0,x1,y1:

\coreq x0,y0,x1,y1:

\recomm x0,y0,x1,y1:

تنتج هذه التعليمات، على التوالي، أسهمًا صلبة، منقطة، ومتقطعة من الصندوق المركزي عند الإحداثيات x0,y0 إلى الصندوق المركزي عند الإحداثيات x1,y1.

في بعض التطبيقات، تحتوي بعض الأسهم افتراضيًا على انحناء غير صفري. من الممكن تجاوز الانحناء الافتراضي لسهم معين باستخدام التعليمات

\prereqc x0,y0,x1,y1;c:

\coreqc x0,y0,x1,y1;c:

\recommc x0,y0,x1,y1;c:

حيث c هو عدد صحيح في النطاق -100:100 يحدد الانحناء المطلوب؛ على سبيل المثال، c=0 سينتج سهمًا مستقيمًا. لتغيير الانحناء الافتراضي، قد يعيد برنامج المستخدم تعريف أمر \DefaultCurvature.

شبكة الإحداثيات

تنتج التعليمات التالية شبكة إحداثيات، وهي مفيدة لتحرير المخطط:

\grid

عادةً ما يتم وضع هذا قبل جميع التعليمات الأخرى بحيث تكون خطوط الشبكة في الخلفية، مغطاة بصناديق الدورات، المصغرات، والأسهم.

روابط الويب

قد ترتبط صناديق الدورات بعناوين الويب. يمكن للمستخدم تعيين عنوان URL لصناديق الدورات عن طريق إعادة تعريف أمر \CourseURL؛ عند استدعائه لصندوق دورة، يتم تزويده بثلاث وسائط، وهي x و y لإحداثيات الصندوق، المصغر، أو سطر النص، ووسيط code لصندوق الدورة. على سبيل المثال،

\renewcommand{\CourseURL}[3]{http://www.cs.queensu.ca/undergraduate/courses/#3.html}

مناسب للدورات في كلية علوم الحاسوب، جامعة كوينز. يمكن استخدام الوسيطين الأول والثاني لعرض إحداثيات صندوق، مصغر، أو سطر نص في بعض عارضات PDF أثناء مرور مؤشر الفأرة فوقها عند تحرير الملف المصدر.

prerex(5)

NAME

prerex - Preq script for makepkg

SYNOPSIS

prerex can be used to specify prerequisites for a package within the PKGBUILD.

DESCRIPTION

prerex is a simple script that makepkg can use to check for dependencies before attempting to build a package. It is typically used in the build() function of a PKGBUILD.

STRUCTURE

The prerex script is structured as a series of checks that must all pass for the build to proceed. Each check is defined by a keyword followed by arguments.

COURSE BOXES

COURSE_BOXES is a special type of check that verifies if certain courses are available. The format is:

COURSE_BOXES <course1> [<course2> ...]

This will check if course1, course2, etc. are installed.

MINI COURSE BOXES AND TEXT

MINI_COURSE_BOXES_AND_TEXT is similar to COURSE_BOXES but also checks for specific text within the course files. The format is:

MINI_COURSE_BOXES_AND_TEXT <course1>:<text1> [<course2>:<text2> ...]

This will check if course1 is installed and contains text1, and so on.

ARROWS

ARROWS is used to check for the presence of specific files or directories. The format is:

ARROWS <path1> [<path2> ...]

This will check if path1, path2, etc. exist.

COORDINATE_GRID

COORDINATE_GRID is a less common check, likely related to specific graphical environments. The format is:

COORDINATE_GRID <grid_id>

This checks for the existence or availability of a specific coordinate grid identified by grid_id.

WEB_LINKS

WEB_LINKS checks if specific URLs are accessible. The format is:

WEB_LINKS <url1> [<url2> ...]

This will check if url1, url2, etc. can be reached.
