PR_SET_NO_NEW_PRIVS(2const) PR_SET_NO_NEW_PRIVS(2const)

الاسم

PR_SET_NO_NEW_PRIVS - تعيين سمة no_new_privs للمسار الحالي

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <linux/prctl.h>  /* تعريف ثوابت PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_NO_NEW_PRIVS, 1L, 0L, 0L, 0L);

الوصف

تعيين سمة no_new_privs للمسار الحالي. مع تعيين no_new_privs إلى 1، يتعهد execve(2) بعدم منح امتيازات لفعل أي شيء لم يكن بالإمكان فعله بدون استدعاء execve(2) (على سبيل المثال، جعل بتات وضع المستخدم المعرف (set-user-ID) والمجموعة المعرفة (set-group-ID)، وقدرات الملفات غير وظيفية).

بمجرد تعيينها، لا يمكن إلغاء تعيين سمة no_new_privs. يتم توريث تعيين هذه السمة للأطفال الذين تم إنشاؤهم بواسطة fork(2) و clone(2)، ويتم الحفاظ عليها عبر execve(2).

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno لتوضيح الخطأ.

الأخطاء

EINVAL
المعامل الثاني لا يساوي 1L.

الملفات

/proc/pid/status
منذ Linux 4.10، يمكن عرض قيمة سمة no_new_privs للمسار عبر الحقل NoNewPrivs في هذا الملف.
