PR_SET_PTRACER(2const) PR_SET_PTRACER(2const)

الاسم

PR_SET_PTRACER - السماح للعمليات بتتبع (ptrace(2)) العملية المتصلة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <linux/prctl.h>  /* تعريف ثوابت PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_PTRACER, long pid);

الوصف

هذا ذو معنى فقط عندما يتم تمكين Yama LSM وفي الوضع 1 ("ptrace مقيد"، يمكن رؤيته عبر /proc/sys/kernel/yama/ptrace_scope).

عندما يتم تمرير "معرف عملية التتبع" في pid، تعلن العملية المتصلة أن عملية التتبع يمكنها ptrace(2) العملية المتصلة كما لو كانت سلفًا مباشرًا لها.

كل عملية PR_SET_PTRACER تحل محل "معرف عملية التتبع" السابق.

استخدام PR_SET_PTRACER مع تعيين pid إلى 0 يمسح "معرف عملية التتبع" الخاص بالمتصل. إذا كان pid هو PR_SET_PTRACER_ANY، يتم تعطيل قيود ptrace التي أدخلتها Yama بشكل فعال للعملية المتصلة.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند الخطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
pid ليست 0، وليست PR_SET_PTRACER_ANY، وليست معرف عملية موجود.

المعايير

لينكس.
