profanity-plugins(1)

الحزمة: profanity

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/plugins

الوصف

إدارة المكونات الإضافية. عدم تمرير أي وسائط يسرد المكونات الإضافية المثبتة والمكونات الإضافية العامة المتاحة للتثبيت المحلي. الدليل العام للمكونات الإضافية Python هو /usr/local/share/profanity/plugins وللمكونات الإضافية C هو /usr/local/lib64/profanity/plugins.

الملخص

/plugins

/plugins install [<path or URL>]

/plugins update [<path or URL>]

/plugins uninstall [<plugin>]

/plugins unload [<plugin>]

/plugins load [<plugin>]

/plugins reload [<plugin>]

/plugins python_version

الوسائط

install [<path or URL>]

تثبيت مكون إضافي، أو جميع المكونات الإضافية الموجودة في دليل (بشكل متكرر)، أو تنزيل وتثبيت مكون إضافي (اسم المكون الإضافي يعتمد على اسم الأساس). وتحميله/تحميلها.

update [<path or URL>]

إلغاء تثبيت ثم تثبيت المكون الإضافي. اسم المكون الإضافي المراد تحديثه هو اسم الأساس.

uninstall [<plugin>]

إلغاء تثبيت مكون إضافي.

load [<plugin>]

تحميل مكون إضافي موجود بالفعل في دليل المكونات الإضافية، وعدم تمرير أي وسائط يقوم بتحميل جميع المكونات الإضافية التي تم العثور عليها. سيتم تحميله عند البدء التالي أيضًا ما لم يتم إلغاء تحميله.

unload [<plugin>]

إلغاء تحميل مكون إضافي تم تحميله، وعدم تمرير أي وسائط سيقوم بإلغاء تحميل جميع المكونات الإضافية.

reload [<plugin>]

إعادة تحميل مكون إضافي، وعدم تمرير أي وسائط سيقوم بإعادة تحميل جميع المكونات الإضافية.

python_version

عرض إصدار مترجم Python.

أمثلة

/plugins install /home/steveharris/Downloads/metal.py

/plugins install https://raw.githubusercontent.com/profanity-im/profanity-plugins/master/stable/sounds.py

/plugins update /home/steveharris/Downloads/metal.py

/plugins update https://raw.githubusercontent.com/profanity-im/profanity-plugins/master/stable/sounds.py

/plugins uninstall browser.py

/plugins load browser.py

/plugins unload say.py

/plugins reload wikipedia.py
