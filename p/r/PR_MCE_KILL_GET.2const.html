PR_MCE_KILL_GET(2const) PR_MCE_KILL_GET(2const)

الاسم

PR_MCE_KILL_GET - الحصول على سياسة إنهاء تلف الذاكرة بسبب فحص الجهاز

المكتبة

مكتبة C القياسية (libc، -lc)

ملخص

#include <linux/prctl.h>  /* تعريف ثوابت PR_* */
#include <sys/prctl.h>
int prctl(PR_MCE_KILL_GET, 0L, 0L, 0L, 0L);

الوصف

إرجاع سياسة إنهاء فحص الجهاز الحالية لكل عملية؛ انظر PR_MCE_KILL_SET(2const).

قيمة الإرجاع

عند النجاح، تعيد هذه المكالمة القيمة غير السالبة الموضحة أعلاه. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

المعايير

Linux.

التاريخ

Linux 2.6.32.
