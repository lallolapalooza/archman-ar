profanity-resource(1)

الحزمة: profanity

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/resource

الوصف

تجاوز مورد جلسة الدردشة، وإدارة إعدادات عرض الموارد.

الاستخدام

/resource set <resource>

/resource off

/resource title on|off

/resource message on|off

الوسائط

set <resource>

تعيين المورد الذي سيتم إرسال الرسائل إليه.

off

السماح للخادم باختيار المورد الذي سيتم توجيه الرسائل إليه.

title on|off

إظهار أو إخفاء المورد الحالي في شريط العنوان.

message on|off

إظهار أو إخفاء المورد عند عرض رسالة واردة.
