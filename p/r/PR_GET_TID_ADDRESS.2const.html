\n
\n
\n

NAME

\n

PR_GET_TID_ADDRESS - get the clear_child_tid address

\n
\n
\n

LIBRARY

\n

Standard C library (libc, -lc)

\n
\n
\n

SYNOPSIS

\n
#include <linux/prctl.h>  /* Definition of PR_* constants */\n#include <sys/prctl.h>
\n
int prctl(PR_GET_TID_ADDRESS, int **addrp);
\n
\n
\n

DESCRIPTION

\n

Return the clear_child_tid address set by\nset_tid_address(2) and the clone(2)\n CLONE_CHILD_CLEARTID flag, in the location pointed to by\n addrp.

\n

This feature is available only if the kernel is built with the\n CONFIG_CHECKPOINT_RESTORE option enabled.

\n
\n
\n

RETURN VALUE

\n

On success, 0 is returned. On error, -1 is returned, and\n errno is set to indicate the error.

\n
\n
\n

ERRORS

\n
\n
EFAULT
\n
addrp is an invalid address.
\n
\n
\n
\n

STANDARDS

\n

Linux.

\n
\n
\n

HISTORY

\n

Linux 3.5.

\n
\n
\n

CAVEATS

\n

Note that since the prctl() system call does not have a\n compat implementation for the AMD64 x32 and MIPS n32 ABIs, and the kernel\n writes out a pointer using the kernel's pointer size, this operation expects\n a user-space buffer of 8 (not 4) bytes on these ABIs.

\n
\n
\n

SEE ALSO

\n

prctl(2)
