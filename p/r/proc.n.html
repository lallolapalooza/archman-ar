proc(n)

الحزمة: tcl

التراخيص: TCL

proc(n) أوامر Tcl المدمجة proc(n)

الاسم

proc - إنشاء إجراء Tcl

الملخص

proc name args body

الوصف

يقوم الأمر proc بإنشاء إجراء Tcl جديد باسم name، ليحل محل أي أمر أو إجراء موجود قد يكون بنفس الاسم. عند استدعاء الأمر الجديد، سيتم تنفيذ محتويات body بواسطة مترجم Tcl. في العادة، يكون name غير مؤهل (لا يتضمن أسماء مساحات الأسماء الحاوية)، ويتم إنشاء الإجراء الجديد في مساحة الأسماء الحالية. إذا كان name يتضمن أي مؤهلات لمساحة الأسماء، يتم إنشاء الإجراء في مساحة الأسماء المحددة. تحدد args الوسائط الرسمية للإجراء. تتكون من قائمة، قد تكون فارغة، كل عنصر منها يحدد وسيطًا واحدًا. كل محدد وسيط هو أيضًا قائمة تحتوي على حقل واحد أو حقلين. إذا كان هناك حقل واحد فقط في المحدد، فهو اسم الوسيط؛ إذا كان هناك حقلان، فإن الأول هو اسم الوسيط والثاني هو قيمته الافتراضية. تصبح الوسائط ذات القيم الافتراضية التي تتبعها وسائط غير افتراضية وسائط مطلوبة؛ يجب توفير عدد كافٍ من الوسائط الفعلية للسماح بجميع الوسائط حتى الوسيط الرسمي الأخير المطلوب.

عند استدعاء name، سيتم إنشاء متغير محلي لكل وسيط رسمي للإجراء؛ ستكون قيمته هي قيمة الوسيط المقابل في الأمر المستدعي أو القيمة الافتراضية للوسيط. يتم تعيين الوسائط الفعلية إلى الوسائط الرسمية بالترتيب الصارم. لا يلزم تحديد الوسائط ذات القيم الافتراضية في استدعاء الإجراء. ومع ذلك، يجب أن يكون هناك عدد كافٍ من الوسائط الفعلية لجميع الوسائط الرسمية التي لا تحتوي على افتراضات، ويجب ألا تكون هناك وسائط فعلية إضافية. تصبح الوسائط ذات القيم الافتراضية التي تتبعها وسائط غير افتراضية وسائط مطلوبة بحكم الأمر الواقع، على الرغم من أن هذا قد يتغير في إصدار مستقبلي من Tcl؛ يجب أن تضمن الشفرة المحمولة أن تأتي جميع الوسائط الاختيارية بعد جميع الوسائط المطلوبة.

هناك حالة خاصة واحدة للسماح بالإجراءات ذات الأعداد المتغيرة من الوسائط. إذا كان الوسيط الرسمي الأخير له الاسم “args”، فيمكن أن يحتوي استدعاء الإجراء على وسائط فعلية أكثر من عدد الوسائط الرسمية للإجراء. في هذه الحالة، يتم تجميع جميع الوسائط الفعلية بدءًا من الوسيط الذي سيتم تعيينه إلى args في قائمة (كما لو تم استخدام الأمر list)؛ يتم تعيين هذه القيمة المدمجة إلى المتغير المحلي args.

عند تنفيذ body، تشير أسماء المتغيرات عادةً إلى المتغيرات المحلية، والتي يتم إنشاؤها تلقائيًا عند الإشارة إليها وحذفها عند عودة الإجراء. يتم إنشاء متغير محلي واحد لكل وسيط من وسائط الإجراء. لا يمكن الوصول إلى المتغيرات الأخرى إلا عن طريق استدعاء أحد الأوامر global أو variable أو upvar أو namespace upvar. ستكون مساحة الأسماء الحالية عند تنفيذ body هي مساحة الأسماء التي يوجد بها اسم الإجراء، والتي ستكون مساحة الأسماء التي تم إنشاؤها فيها ما لم يتم تغييرها باستخدام rename.

يعيد الأمر proc سلسلة فارغة. عند استدعاء إجراء، تكون قيمة الإرجاع للإجراء هي القيمة المحددة في أمر return. إذا لم ينفذ الإجراء أمر return صريحًا، فإن قيمة الإرجاع الخاصة به هي قيمة آخر أمر تم تنفيذه في جسم الإجراء. إذا حدث خطأ أثناء تنفيذ جسم الإجراء، فإن الإجراء بأكمله سيعيد نفس الخطأ.

أمثلة

هذا إجراء يأخذ وسيطين ويطبع مجموعهما وحاصل ضربهما. كما أنه يعيد السلسلة “OK” إلى المستدعي كنتيجة صريحة.

proc printSumProduct {x y} {
    set sum [expr {$x + $y}]
    set prod [expr {$x * $y}]
    puts "sum is $sum, product is $prod"
    return "OK"
}

هذا إجراء يقبل عددًا تعسفيًا من الوسائط ويقوم بطباعتها، واحدًا تلو الآخر.

proc printArguments args {
    foreach arg $args {
        puts $arg
    }
}

هذا الإجراء يشبه إلى حد ما الأمر incr، باستثناء أنه يضرب محتويات المتغير المسمى بالقيمة، والتي تكون افتراضياً 2:

proc mult {varName {multiplier 2}} {
    upvar 1 $varName var
    set var [expr {$var * $multiplier}]
}
