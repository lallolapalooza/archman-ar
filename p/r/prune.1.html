prune(1)

الحزمة: graphviz

التراخيص: EPL

prune(1) دليل الأوامر العامة prune(1)

الاسم

prune - تقليم الرسوم البيانية الموجهة

ملخص

prune [ -n عقدة ] [ -N مواصفات-سمة ] [ -v ] [ -(h|?) ] [ ملفات ... ]

الوصف

يقرأ prune الرسوم البيانية الموجهة بنفس التنسيق الذي يستخدمه dot(1) ويزيل الرسوم البيانية الفرعية المتجذرة في العقد المحددة في سطر الأوامر عبر الخيارات. لن تتم إزالة هذه العقد نفسها، ولكن يمكن إعطاؤها سمات بحيث يمكن تحديدها بسهولة بواسطة محرر تدفق الرسوم البيانية مثل gvpr(1). يتعامل prune بشكل صحيح مع الدورات، والحلقات، والحواف المتعددة.

يمكن أن يظهر كلا الخيارين عدة مرات في سطر الأوامر. سيتم بعد ذلك معالجة جميع الرسوم البيانية الفرعية المتجذرة في العقد المحددة. إذا لم تكن العقدة موجودة، فسيقوم prune بتخطيها وطباعة رسالة تحذير إلى stderr. إذا تم تقديم سمات متعددة، فسيتم تطبيقها على جميع العقد التي تمت معالجتها. يكتب prune النتيجة إلى stdout.

خيارات

-n اسم
يحدد اسم العقدة المراد تقليمها.
-N مواصفات-سمة
يحدد السمة التي سيتم تعيينها (أو تغييرها إذا كانت موجودة) لأي عقدة تم تقليمها. مواصفات-سمة هي سلسلة نصية بالصيغة سمة=قيمة.
-v
الإخراج المطول.
-h -?
يطبع الاستخدام ويخرج.

أمثلة

رسم بياني إدخال test.gv بالشكل

digraph DG {
A -> B;
A -> C;

B -> D;
B -> E;
}

، تمت معالجته بالأمر

prune -n B test.gv

سينتج عنه الإخراج التالي (قد يكون الكود الفعلي منسقًا بطريقة مختلفة قليلاً).

digraph DG {
A -> B;
A -> C;
}

رسم بياني إدخال آخر test.gv بالشكل

digraph DG {
A -> B;
A -> C;

B -> D;
B -> E;

C -> E;
}

(لاحظ الحافة الإضافية من C إلى E)، تمت معالجته بالأمر

prune -n B -N color=red test.gv

ينتج عنه

digraph DG {
B [color=red];
A -> B;
A -> C;
C -> E;
}

لم تتم إزالة العقدة E لأن والدها الثاني C لم يتم تقليمه.

حالة الخروج

يعيد prune القيمة 0 عند الاكتمال الناجح. يعيد 1 في حالة حدوث خطأ.

انظر أيضا

dot(1), gvpr(1)
