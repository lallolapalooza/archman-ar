الوصف

تقع الدوال التي تتعامل مع ربطات المتغيرات ضمن أربع مجموعات - التعامل مع الإنشاء، تعيين القيم، الإخراج، وحذف ربطات المتغيرات.

الإنشاء

تقوم snmp_pdu_add_variable بإنشاء بنية ربط متغير جديدة، يتم تهيئتها بالاسم ( objid, objidlen )، الصيغة ( type ) والقيمة ( value , len ) المقدمة. ثم تتم إضافة ربط المتغير هذا إلى نهاية قائمة ربطات المتغيرات في PDU المحدد.

snmp_varlist_add_variable مماثلة، ولكنها تضيف ربط المتغير الجديد إلى نهاية قائمة ربطات المتغيرات المقدمة. عند إضافة ربط المتغير الأول إلى قائمة فارغة، ما عليك سوى تمرير عنوان رأس القائمة:


netsnmp_variable_list *vl = NULL;
snmp_varlist_add_variable(
&vl, name1, name1_len,
ASN_TYPE, &val1, val1_len);
snmp_varlist_add_variable(
&vl, name2, name2_len,
ASN_TYPE, &val2, val2_len);

في كلتا الحالتين، ستعيد الدالة مؤشرًا إلى بنية ربط المتغير الجديدة (أو NULL إذا فشل إنشاء ربط المتغير).

snmp_add_null_var هي دالة مساعدة لإضافة ربط متغير فارغ إلى PDU. دون الحاجة إلى تحديد قيمة NULL صراحة. هذه هي الآلية العادية لبناء طلب استرداد معلومات GET (أو ما شابه).
مرة أخرى، تعيد هذه الدالة مؤشرًا إلى ربط المتغير الجديد، أو NULL.

snmp_clone_varbind تنشئ نسخة من كل ربط متغير في القائمة المحددة، وتعيد مؤشرًا إلى رأس القائمة الجديدة (أو NULL إذا فشل النسخ).

تعيين القيم

تقوم snmp_set_var_objid بتعيين اسم بنية ربط المتغير إلى معرف الكائن المحدد.
تقوم snmp_set_var_typed_value بتعيين نوع الصيغة وقيمة بنية ربط المتغير.
تقوم snmp_set_var_value بتعيين قيمة بنية ربط المتغير، مع ترك نوع الصيغة دون تغيير.
snmp_set_var_typed_integer هي دالة مساعدة لتعيين نوع الصيغة وقيمة ربط متغير قائم على عدد صحيح 32 بت.

تعيد الدوال الأربع جميعها 0 إذا كان التعيين ناجحًا، أو 1 إذا لم يكن كذلك.

الإخراج

ستأخذ print_variable معرف كائن (كما تم إرجاعه بواسطة read_objid، snmp_parse_oid أو get_module_node) ونسخة من متغير كهذا، وتقوم بطباعة الشكل النصي لمعرف الكائن مع قيمة المتغير إلى المخرج القياسي.

تقوم fprint_variable بنفس الشيء، ولكنها تطبع إلى مؤشر FILE المحدد بواسطة المعامل الأولي.

تقوم snprint_variable بطباعة نفس المعلومات في المخزن المؤقت الذي يشير إليه buf والذي يبلغ طوله len. تعيد عدد الأحرف المطبوعة، أو -1 إذا لم يكن المخزن المؤقت كبيرًا بما فيه الكفاية. في الحالة الأخيرة، سيحتوي buf عادةً على نسخة مقطوعة من المعلومات (ولكن هذا السلوك غير مضمون). تحل هذه الدالة محل الدالة المهملة sprint_variable.

تقوم print_value، fprint_value، و snprint_value بنفس عمل روتينات print_variable المكافئة، ولكنها تعرض فقط قيمة المتغير، دون معرف الكائن المقابل.

لعرض OID لربط متغير، راجع netsnmp_mib_api(3).

الحذف

تقوم snmp_free_var بتحرير كل الذاكرة المستخدمة بواسطة بنية ربط المتغير المقدمة.
تقوم snmp_free_varbind بتحرير كل الذاكرة المستخدمة بواسطة كل بنية ربط متغير في قائمة ربطات المتغيرات المقدمة.
