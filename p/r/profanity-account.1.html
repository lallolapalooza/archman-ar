profanity-account(1)

الحزمة: profanity-gtk

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/account

الوصف

أوامر لإنشاء وإدارة الحسابات. الاستدعاء بدون وسائط سيعرض معلومات للحساب الحالي.

الوسائط

list

يسرد جميع الحسابات.

enable <account>

تمكين الحساب، وسيتم استخدامه للإكمال التلقائي.

show <account>

عرض تفاصيل الحساب المحدد.

disable <account>

تعطيل الحساب.

default set <account>

تعيين الحساب الافتراضي، المستخدم عند عدم تمرير وسيط إلى الأمر /connect.

default off

مسح إعداد الحساب الافتراضي.

add <account>

إنشاء حساب جديد.

remove <account>

إزالة حساب.

rename <account> <newaccount>

إعادة تسمية 'account' إلى 'newaccount'.

set <account> jid <jid>

تعيين معرف Jabber للحساب، سيتم استخدام اسم الحساب إذا لم يتم تعيينه.

set <account> server <server>

خادم الدردشة، إذا كان مختلفًا عن الجزء النطاقي من JID.

set <account> port <port>

المنفذ المستخدم للاتصال إذا لم يكن المنفذ الافتراضي (5222، أو 5223 لـ SSL).

set <account> status <presence>

حالة التواجد المراد استخدامها عند تسجيل الدخول.

set <account> status last

استخدام آخر حالة لك قبل تسجيل الخروج، عند تسجيل الدخول.

set <account> <presence> <priority>

تعيين الأولوية (-128..127) المراد استخدامها للتواجد المحدد.

set <account> resource <resource>

المورد المراد استخدامه لهذا الحساب، الافتراضي هو 'profanity'.

set <account> password <password>

كلمة مرور الحساب، لاحظ أنه يتم تخزينها حاليًا كنص عادي إذا تم تعيينها.

set <account> eval_password <command>

أمر shell يتم تقييمه لاسترداد كلمة المرور للحساب. يمكن استخدامه لاسترداد كلمة المرور من keyring.

set <account> muc <service>

خدمة دردشة MUC الافتراضية المراد استخدامها، الافتراضي هو استجابة disco info للخادم.

set <account> nick <nick>

الاسم المستعار الافتراضي المراد استخدامه عند الانضمام إلى غرف الدردشة.

set <account> otr <policy>

تجاوز سياسة OTR العامة لهذا الحساب، انظر /otr.

set <account> pgpkeyid <pgpkeyid>

تعيين معرف مفتاح PGP لهذا الحساب، انظر /pgp.

set <account> startscript <script>

تعيين البرنامج النصي المراد تنفيذه بعد الاتصال.

set <account> clientid "<name> <version>"

تعيين اسم عميل XMPP للاكتشاف وفقًا لـ XEP-0092. لمحبي الخصوصية. يوصى بتركه كما هو.

set <account> tls force

فرض اتصال TLS، والفشل إذا لم يكن من الممكن إنشاؤه، هذا هو السلوك الافتراضي.

set <account> tls allow

استخدام TLS للاتصال إذا كان متاحًا.

set <account> tls trust

فرض اتصال TLS والثقة في شهادة الخادم.

set <account> tls legacy

استخدام TLS القديم للاتصال. هذا يعني أن الخادم لا يدعم STARTTLS، ويتم فرض TLS مباشرة بعد إنشاء اتصال TCP.

set <account> tls disable

تعطيل TLS للاتصال.

set <account> auth default

استخدام عملية المصادقة الافتراضية.

set <account> auth legacy

السماح بالمصادقة القديمة.

set <account> theme <theme>

تعيين سمة واجهة المستخدم للحساب.

set <account> session_alarm <max_sessions>

التنبيه بشأن النشاط المشبوه إذا تجاوز عدد الجلسات max_sessions.

clear <account> server

إزالة إعداد الخادم لهذا الحساب.

clear <account> port

إزالة إعداد المنفذ لهذا الحساب.

clear <account> password

إزالة إعداد كلمة المرور لهذا الحساب.

clear <account> eval_password

إزالة إعداد eval_password لهذا الحساب.

clear <account> otr

إزالة إعداد سياسة OTR لهذا الحساب.

clear <account> pgpkeyid

إزالة pgpkeyid المرتبط بهذا الحساب.

clear <account> startscript

إزالة startscript المرتبط بهذا الحساب.

clear <account> clientid

إعادة تعيين اسم العميل إلى الافتراضي.

clear <account> theme

مسح إعداد السمة للحساب، وسيتم استخدام السمة العامة.

clear <account> resource

إزالة إعداد المورد لهذا الحساب.

clear <account> muc

إزالة إعداد خدمة MUC الافتراضية.

clear <account> session_alarm

تعطيل تنبيه الجلسة.

أمثلة

/account add me

/account set me jid ulfhednar@valhalla.edda

/account set me server talk.chat.com

/account set me port 5111

/account set me muc chatservice.mycompany.com
