NAME

procps_pids - return PIDs of processes

SYNOPSIS

#include <proc/proc.h>

int procps_pids(pid_t *pids, int n_pids);

DESCRIPTION

The function procps_pids() returns the PIDs of all processes running on the system. The PIDs are copied into the buffer pointed to by pids, which must be large enough to hold n_pids PIDs.

The number of processes running on the system can be obtained by calling procps_pids() with pids = NULL and n_pids = 0. The return value is the total number of processes.

RETURN VALUE

On success, procps_pids() returns the number of PIDs copied into the buffer pids. This value is less than or equal to n_pids.

If the buffer pids is not large enough to hold all available PIDs, the function returns n_pids and the caller can resize the buffer and call the function again.

If pids is NULL and n_pids is 0, the function returns the total number of processes running on the system.

On error, procps_pids() returns -1 and sets errno to indicate the error.

DEBUGGING

The function procps_pids() is not intended for debugging purposes.

ENVIRONMENT VARIABLE(S)

None.

الاسم

procps_pids - إرجاع معرفات العمليات (PIDs) للعمليات

الملخص

#include <proc/proc.h>

int procps_pids(pid_t *pids, int n_pids);

الوصف

تقوم الدالة procps_pids() بإرجاع معرفات العمليات (PIDs) لجميع العمليات قيد التشغيل على النظام. يتم نسخ معرفات العمليات (PIDs) إلى المخزن المؤقت الذي تشير إليه pids، والذي يجب أن يكون كبيرًا بما يكفي لاستيعاب n_pids من معرفات العمليات (PIDs).

يمكن الحصول على عدد العمليات قيد التشغيل على النظام عن طريق استدعاء procps_pids() مع pids = NULL و n_pids = 0. القيمة المرجعة هي العدد الإجمالي للعمليات.

قيمة الإرجاع

عند النجاح، تعيد الدالة procps_pids() عدد معرفات العمليات (PIDs) التي تم نسخها إلى المخزن المؤقت pids. هذه القيمة أقل من أو تساوي n_pids.

إذا لم يكن المخزن المؤقت pids كبيرًا بما يكفي لاستيعاب جميع معرفات العمليات (PIDs) المتاحة، تعيد الدالة n_pids ويمكن للمستدعي تغيير حجم المخزن المؤقت واستدعاء الدالة مرة أخرى.

إذا كان pids هو NULL و n_pids هو 0، تعيد الدالة العدد الإجمالي للعمليات قيد التشغيل على النظام.

عند حدوث خطأ، تعيد الدالة procps_pids() القيمة -1 وتعيّن متغير errno للإشارة إلى الخطأ.

التصحيح

الدالة procps_pids() ليست مخصصة لأغراض التصحيح.
