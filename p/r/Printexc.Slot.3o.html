منذ 4.02

type t = Printexc.backtrace_slot

val is_raise : t -> bool

is_raise slot يكون true عندما تشير slot إلى نقطة رفع في الكود، و false عندما تأتي من استدعاء دالة بسيط.

منذ 4.02

val is_inline : t -> bool

is_inline slot يكون true عندما تشير slot إلى استدعاء تم دمجه بواسطة المترجم، و false عندما يأتي من أي سياق آخر.

منذ 4.04

val location : t -> Printexc.location option

location slot ترجع معلومات الموقع للفتحة، إذا كانت متاحة، و None بخلاف ذلك.

بعض الأسباب المحتملة للفشل في إرجاع موقع هي كما يلي:

- الفتحة تتوافق مع رفع تم إدراجه بواسطة المترجم

- الفتحة تتوافق مع جزء من البرنامج لم يتم تجميعه بمعلومات تصحيح الأخطاء ( -g )

منذ 4.02

val name : t -> string option

name slot ترجع اسم الدالة أو التعريف الذي يحيط بالموقع المشار إليه بواسطة الفتحة.

name slot ترجع None إذا كان الاسم غير متاح، والذي قد يحدث لنفس الأسباب التي تجعل location ترجع None.

منذ 4.11

val format : int -> t -> string option

format pos slot ترجع التمثيل النصي لـ slot كما سيتم تنسيقه بواسطة raw_backtrace_to_string، بافتراض أنها العنصر pos -th من تتبع الخطأ: العنصر 0 -th يتم تنسيقه بشكل جميل بشكل مختلف عن الآخرين.

تتخطى دوال طباعة تتبع الأخطاء بالكامل بعض الفتحات غير الغنية بالمعلومات؛ في هذه الحالة، ترجع format pos slot None.
