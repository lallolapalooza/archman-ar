PR_SET_MM_START_DATA(2const) PR_SET_MM_END_DATA(2const)

الاسم

PR_SET_MM_START_DATA, PR_SET_MM_END_DATA - تعديل حقول واصف خريطة ذاكرة النواة

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <linux/prctl.h>  /* تعريف الثوابت PR_* */
#include <sys/prctl.h>
int prctl(PR_SET_MM, PR_SET_MM_START_DATA, unsigned long addr, 0L, 0L);
int prctl(PR_SET_MM, PR_SET_MM_END_DATA, unsigned long addr, 0L, 0L);

الوصف

PR_SET_MM_START_DATA
تعيين العنوان الذي تقع فوقه البيانات المهيأة وغير المهيأة (bss). يجب أن تكون منطقة الذاكرة المقابلة قابلة للقراءة والكتابة، ولكن ليست قابلة للتنفيذ أو المشاركة.
PR_SET_MM_END_DATA
تعيين العنوان الذي تقع أسفله البيانات المهيأة وغير المهيأة (bss). يجب أن تكون منطقة الذاكرة المقابلة قابلة للقراءة والكتابة، ولكن ليست قابلة للتنفيذ أو المشاركة.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EINVAL
addr أكبر من TASK_SIZE (الحد الأقصى لمساحة عنوان المستخدم لهذه المعمارية).
EINVAL
أذونات منطقة الذاكرة المقابلة ليست كما هو مطلوب.

Linux.
