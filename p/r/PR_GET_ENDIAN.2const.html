PR_GET_ENDIAN(2const) PR_GET_ENDIAN(2const)

الاسم

PR_GET_ENDIAN - الحصول على ترتيب البايتات للعملية المستدعاة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <linux/prctl.h>  /* تعريف ثوابت PR_* */
#include <sys/prctl.h>
int prctl(PR_GET_ENDIAN, int *endianness);

الوصف

إرجاع ترتيب البايتات للعملية المستدعاة، في الموقع الذي يشير إليه endianness.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند الفشل، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EFAULT
endianness هو عنوان غير صالح.

المعايير

Linux. PowerPC فقط.

التاريخ

Linux 2.6.18 (PowerPC).

انظر أيضًا

prctl(2), PR_SET_ENDIAN(2const)
