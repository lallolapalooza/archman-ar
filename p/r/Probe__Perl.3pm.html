Probe__Perl(3pm)

الحزمة: perl-probe-perl

التراخيص: PerlArtistic

Probe::Perl(3) وثائق Perl المساهمة من المستخدم Probe::Perl(3)

الاسم

Probe::Perl - معلومات حول perl قيد التشغيل حاليًا

الإصدار

version 0.03

الملخص

use Probe::Perl;
$p = Probe::Perl->new();

# إصدار هذا الـ perl كرقم عائم
$ver = $p->perl_version();
$ver = Probe::Perl->perl_version();

# تحويل سلسلة نصية متعددة النقاط إلى رقم عائم
$ver = $p->perl_version_to_float($ver);
$ver = Probe::Perl->perl_version_to_float($ver);

# التحقق مما إذا كان الـ perl المعطى هو نفسه قيد التشغيل حاليًا
$bool = $p->perl_is_same($perl_path);
$bool = Probe::Perl->perl_is_same($perl_path);

# العثور على مسار لمفسر الـ perl قيد التشغيل حاليًا
$path = $p->find_perl_interpreter();
$path = Probe::Perl->find_perl_interpreter();

# الحصول على @INC قبل إضافات وقت التشغيل
@paths = $p->perl_inc();
@paths = Probe::Perl->perl_inc();

# الحصول على النوع العام لنظام التشغيل
$type = $p->os_type();
$type = Probe::Perl->os_type();

# الوصول إلى قيم Config.pm
$val = $p->config('foo');
$val = Probe::Perl->config('foo');
$p->config('foo' => 'bar');  # تعيين محليًا
$p->config_revert('foo');  # تراجع

الوصف

توفر هذه الوحدة طرقًا للحصول على معلومات حول مفسر الـ perl قيد التشغيل حاليًا. بدأت في الأصل كشيفرة في مشروع "Module::Build"، ولكن تم فصلها هنا للاستخدام العام.

الطرق

new()
ينشئ كائن Probe::Perl جديد ويعيده. معظم الطرق في حزم Probe::Perl متاحة كطرق فئة، لذلك لا تحتاج دائمًا إلى إنشاء كائن جديد. ولكن إذا كنت ترغب في إنشاء عرض قابل للتعديل لبيانات "Config.pm"، فمن الضروري إنشاء كائن لتخزين القيم فيه.
config( $key [, $value] )
يعيد قيمة "Config.pm" المرتبطة بـ $key. إذا تم تحديد $value أيضًا، فسيتم تعيين القيمة إلى $value لهذا العرض للبيانات. في هذه الحالة، يجب استدعاء config() كطريقة كائن، وليس طريقة فئة.
config_revert( $key )
يزيل أي قيمة تم تعيينها بواسطة المستخدم في هذا العرض لبيانات "Config.pm".
find_perl_interpreter( )
يعيد المسار المطلق لمفسر الـ perl هذا. هذا في الواقع شيء صعب بعض الشيء اكتشافه أحيانًا - في هذه الحالات نستخدم perl_is_same() للتحقق.
perl_version( )
يعيد إصدار مفسر الـ perl هذا كرقم إصدار بأسلوب perl باستخدام perl_version_to_float(). يستخدم $^V إذا كان الـ perl الخاص بك حديثًا بما فيه الكفاية، وإلا فإنه يستخدم $].
perl_version_to_float( $version )
يقوم بتنسيق $version كرقم إصدار بأسلوب perl مثل 5.008001.
perl_is_same( $perl )
بالنظر إلى اسم مفسر perl، تحدد هذه الطريقة ما إذا كان لديه نفس التكوين مثل المفسر الذي تمثله مثيل perl الحالي. عادة ما يعني هذا أنه هو نفسه تمامًا
perl_inc( )
يعيد قائمة الدلائل في مسار @INC الخاص بـ perl هذا، *قبل* إضافة أي مدخلات من "use lib" أو $ENV{PERL5LIB} أو مفاتيح "-I".
os_type( [$osname] )
يعيد نوع OS عام (مثل "Unix"، "Windows"، "MacOS") لاسم OS المعطى. إذا لم يتم إعطاء اسم OS، فإنه يستخدم القيمة في $^O، وهي نفس قيمة $Config{osname}.
