profanity-executable(1)

الحزمة: profanity-gtk

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/executable

الوصف

تكوين البرنامج التنفيذي الذي يجب استدعاؤه عند أمر معين.

ملخص

/executable avatar set <cmdtemplate>

/executable avatar default

/executable urlopen set <cmdtemplate>

/executable urlopen default

/executable urlsave set <cmdtemplate>

/executable urlsave default

/executable editor set <cmdtemplate>

/executable editor default

/executable vcard_photo set <cmdtemplate>

/executable vcard_photo default

الوسائط

avatar set

تعيين البرنامج التنفيذي الذي يتم تشغيله بواسطة /avatar open. استخدم عارض الصور المفضل لديك.

avatar default

استعادة إلى الإعدادات الافتراضية.

urlopen set

تعيين البرنامج التنفيذي الذي يتم تشغيله بواسطة /url open. يأخذ قالب أمر يستبدل %u و %p بعنوان URL والمسار على التوالي.

urlopen default

استعادة إلى الإعدادات الافتراضية.

urlsave set

تعيين البرنامج التنفيذي الذي يتم تشغيله بواسطة /url save. يأخذ قالب أمر يستبدل %u و %p بعنوان URL والمسار على التوالي.

urlsave default

استخدم طريقة التنزيل المضمنة للحفظ.

editor set

تعيين المحرر المراد استخدامه مع /editor. يحتاج إلى محرر طرفي أو نص برمجي لتشغيل محرر رسومي.

editor default

استعادة إلى الإعدادات الافتراضية.

vcard_photo set

تعيين البرنامج التنفيذي الذي يتم تشغيله بواسطة /vcard photo open. يأخذ قالب أمر يستبدل %p بالمسار.

vcard_photo default

استعادة إلى الإعدادات الافتراضية.

أمثلة

/executable avatar xdg-open

/executable urlopen set "xdg-open %u"

/executable urlopen set "firefox %u"

/executable urlopen default

/executable urlsave set "wget %u -O %p"

/executable urlsave set "curl %u -o %p"

/executable urlsave default

/executable vcard_photo set "feh %p"

/executable editor set "emacsclient -t"
