profanity-tls(1)

الحزمة: profanity

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/tls

الوصف

التعامل مع شهادات TLS.

الملخص

/tls allow

/tls always

/tls deny

/tls cert [<fingerprint>]

/tls trust

/tls trusted

/tls revoke <fingerprint>

/tls certpath

/tls certpath set <path>

/tls certpath clear

/tls certpath default

المعاملات

allow

السماح للمتابعة بالاتصال بشهادة TLS.

always

السماح دائمًا بالاتصالات بشهادة TLS.

deny

إنهاء الاتصال.

cert

عرض شهادة TLS الحالية.

cert <fingerprint>

عرض تفاصيل الشهادة الموثوقة.

trust

إضافة شهادة TLS الحالية إلى الشهادات الموثوقة يدويًا.

trusted

عرض ملخص الشهادات الموثوقة يدويًا (مع '/tls always' أو '/tls trust').

revoke <fingerprint>

إزالة شهادة موثوقة يدويًا.

certpath

عرض مسار الشهادة الموثوقة.

certpath set <path>

تحديد مسار نظام الملفات الذي يحتوي على الشهادات الموثوقة.

certpath clear

مسح مسار الشهادات الموثوقة.

certpath default

استخدام مسار شهادات النظام الافتراضي، إذا تم العثور عليه.
