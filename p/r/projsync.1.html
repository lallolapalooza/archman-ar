projsync(1)

NAME

projsync - synchronize project files with a remote server

SYNOPSIS

projsync [-a] [-v] [-l LEVEL] [-c CONFIG] [-o OUTPUT] [-p PROJROOT] [-n PROJNAME] [-r REMOTE] [-s SERVER] [-t TIMEOUT] [-u USER] [-d DIR]

DESCRIPTION

projsync is a tool for synchronizing project files with a remote server. It can be used to back up project files to a remote server or to synchronize them between multiple machines.

The tool uses SSH for secure file transfer and supports various configuration options to customize the synchronization process.

EXAMPLES

Synchronize the project in the current directory to the remote server:

projsync -s my.server.com -u myuser -d /path/to/projects

Synchronize a specific project with a custom configuration file:

projsync -c myconfig.conf -n myproject -s my.server.com -u myuser -d /path/to/projects
