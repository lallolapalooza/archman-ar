PR_SET_SECCOMP(2const) PR_SET_SECCOMP(2const)

الاسم

PR_SET_SECCOMP - تعيين وضع الحوسبة الآمنة

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <linux/prctl.h>  /* تعريف الثوابت PR_* */
#include <sys/prctl.h>
[[deprecated]]
int prctl(PR_SET_SECCOMP, long mode, ...);
[[deprecated]]
int prctl(PR_SET_SECCOMP, SECCOMP_MODE_STRICT);
[[deprecated]]
int prctl(PR_SET_SECCOMP, SECCOMP_MODE_FILTER,
          struct sock_fprog *filter);

الوصف

تعيين وضع الحوسبة الآمنة (seccomp) للخيط المتصل، للحد من استدعاءات النظام المتاحة. يوفر استدعاء النظام seccomp(2) الأحدث مجموعة شاملة من وظائف PR_SET_SECCOMP، وهو الواجهة المفضلة للتطبيقات الجديدة.

يتم اختيار وضع seccomp عبر mode. يتم تعريف ثوابت seccomp في <linux/seccomp.h>. يمكن تحديد القيم التالية:

SECCOMP_MODE_STRICT (منذ Linux 2.6.23)
انظر وصف SECCOMP_SET_MODE_STRICT في seccomp(2).
هذه العملية متاحة فقط إذا تم تكوين النواة مع تمكين CONFIG_SECCOMP.
SECCOMP_MODE_FILTER (منذ Linux 3.5)
يتم تحديد استدعاءات النظام المسموح بها بواسطة مؤشر إلى فلتر حزم بيركلي (Berkeley Packet Filter) ممرر في filter. يمكن تصميمه لتصفية استدعاءات النظام العشوائية ووسائط استدعاءات النظام. انظر وصف SECCOMP_SET_MODE_FILTER في seccomp(2).
هذه العملية متاحة فقط إذا تم تكوين النواة مع تمكين CONFIG_SECCOMP_FILTER.

قيمة الإرجاع

عند النجاح، يتم إرجاع 0. عند الخطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EACCES
mode هو SECCOMP_MODE_FILTER، ولكن العملية لا تمتلك صلاحية CAP_SYS_ADMIN أو لم تقم بتعيين السمة no_new_privs (انظر PR_SET_NO_NEW_PRIVS(2const)).
EFAULT
mode هو SECCOMP_MODE_FILTER، و filter هو عنوان غير صالح.
EINVAL
mode ليس قيمة صالحة.
EINVAL
لم يتم تكوين النواة مع CONFIG_SECCOMP.
EINVAL
mode هو SECCOMP_MODE_FILTER، ولم يتم تكوين النواة مع CONFIG_SECCOMP_FILTER.
