profanity-alias(1)

الحزمة: profanity-gtk

التراخيص: GPL3

man(1) عميل Profanity XMPP man(1)

الاسم

/alias

الوصف

إضافة، إزالة أو سرد اختصارات الأوامر.

الملخص

/alias list

/alias add <name> <value>

/alias remove <name>

الحجج

list

سرد جميع الاختصارات.

add <name> <value>

إضافة اختصار أمر جديد. يجب ألا يحتوي اسم الاختصار على أي مسافات.

remove <name>

إزالة اختصار أمر.

أمثلة

/alias add friends /who online friends

/alias add /q /quit

/alias add urg /msg odin@valhalla.edda [URGENT]

/alias add afk /status set away "Away From Keyboard"

/alias remove q

/alias list
