pn53x-tamashell(1)

الحزمة: libnfc

pn53x-tamashell(1) دليل الأوامر العامة pn53x-tamashell(1)

الاسم

pn53x-tamashell - واجهة سطر أوامر تفاعلية لتواصل PN53x TAMA

الملخص

pn53x-tamashell [سكريبت]

الوصف

pn53x-tamashell هو أداة تفاعلية بسيطة لإرسال ما يسمى بأوامر TAMA واستقبال الردود. TAMA تشير إلى مجموعة الأوامر المدعومة من عائلة PN53x. الرسائل ثنائية ويتوقع الصدفة ترميزًا سداسي عشري. أوامر TAMA وملفات التعريف للردود (0xD4/0xD5) و CRC وأي تأطير إضافي يتم التعامل معه بشفافية.

يمكنك استخدام الواجهة التفاعلية (مع دعم readline) أو يمكنك كتابة ملف سكريبت خاص بك يتكون من أوامر وتعليقات (أي شيء يبدأ بـ ";" أو "#" أو "//"). يتم تجاهل المسافات ويمكن استخدامها لتحسين القراءة.

يتم دعم Shebang، ابدأ السكريبت الخاص بك ببساطة بـ:
#!/usr/bin/env pn53x-tamashell

الأوامر

p N لتقديم وقفة لمدة N مللي ثانية.

q أو Ctrl-d للخروج.

أمثلة

أمر GetFirmware هو D4 02، لذلك ما عليك سوى إرسال الأمر "02":


$ pn53x-tamashell
متصل بقارئ NFC: SCM Micro/SCL3711-NFC&RW - PN533 v2.7 (0x07)
> 02
Tx: 02
Rx: 33 02 07 07
> 40
Tx: 40
Rx: Command Not Acceptable
> q
وداعًا!

نفس الشيء، باستخدام سكريبت:


$ pn53x-tamashell << EOF
// هذا تعليق
02 // GetFirmware
40 // أمر مع وسائط مفقودة
EOF


متصل بقارئ NFC: SCM Micro/SCL3711-NFC&RW - PN533 v2.7 (0x07)
> // هذا تعليق
> 02 // GetFirmware
Tx: 02
Rx: 33 02 07 07
> 40 // أمر مع وسائط مفقودة
Tx: 40
Rx: Command Not Acceptable
> وداعًا!

الخيارات

script ملف سكريبت يحتوي على أوامر tama
