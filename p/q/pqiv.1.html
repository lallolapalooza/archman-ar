pqiv(1) دليل الأوامر العامة pqiv(1)

الاسم

pqiv - عارض صور قوي وسريع

الملخص

pqiv [خيارات] [اسم الملف(ات)...]

الوصف

pqiv هو عارض صور بسيط يعمل عبر سطر الأوامر مستوحى من qiv. إنه قابل للتخصيص بدرجة عالية ويدعم مجموعة متنوعة من التنسيقات.

خيارات

-c, --transparent-background
ارسم حدود نافذة pqiv بدون إطار وشفافة. في وضع النافذة، يؤدي النقر بالماوس إلى تنشيط وإلغاء تنشيط زخارف النافذة.
-d, --slideshow-interval=ثواني
في وضع عرض الشرائح (يتم تفعيله بواسطة --slideshow أو مفتاح s افتراضيًا)، قم بالتبديل بين الصور بهذا المعدل. القيم العشرية مدعومة، على سبيل المثال استخدم 0.5 للتبديل بين الصور بمعدل صورتين في الثانية.
-f, --fullscreen
ابدأ في وضع ملء الشاشة. يمكن تبديل وضع ملء الشاشة بالضغط على f أثناء التشغيل افتراضيًا.
-F, --fade
تلاشي بين الصور. انظر أيضًا --fade-duration.
-i, --hide-info-box
إخفاء صندوق المعلومات مبدئيًا. يمكن تبديل ظهور الصندوق بالضغط على i أثناء التشغيل افتراضيًا.
--font=الخط
حدد سلسلة خط Pango لصندوق المعلومات. لاحظ أن حجم الخط سيتم قياسه بالنسبة للنافذة.
-l, --lazy-load
يقوم pqiv عادةً بمعالجة جميع وسائط سطر الأوامر قبل عرض نافذته الرئيسية. مع هذا الخيار، تظهر النافذة فور العثور على الصورة الأولى وتحميلها.
-n, --sort
بدلاً من تخزين الصور بالترتيب الذي تم تقديمه بها في سطر الأوامر وتم العثور عليها داخل المجلدات، قم بفرزها. الترتيب الافتراضي حسب الاسم (الترتيب الطبيعي). انظر --sort-key لتغيير الترتيب.
-P, --window-position=الموضع
تعيين موضع النافذة الأولي. قد يكون الموضع إما
x,y
إحداثيات الشاشة، أو
off
عدم تحديد موضع النافذة على الإطلاق.
-r, --additional-from-stdin
قراءة أسماء ملفات/مجلدات إضافية من المدخل القياسي. يتعارض هذا الخيار مع --actions-from-stdin.
-s, --slideshow
ابدأ في وضع عرض الشرائح. يمكن تبديل وضع عرض الشرائح أثناء التشغيل بالضغط على s افتراضيًا.
-t, --scale-images-up
قياس الصور لأعلى لملء الشاشة بأكملها. يمكن تبديل هذا أثناء التشغيل بالضغط على t افتراضيًا. انظر أيضًا --disable-scaling.
-T, --window-title=العنوان
تعيين عنوان النافذة. يقوم pqiv باستبدال العديد من المتغيرات في العنوان:
$BASEFILENAME
اسم الملف الأساسي للملف الحالي (على سبيل المثال `image.png')،
$FILENAME
اسم الملف الحالي (على سبيل المثال `/home/user/image.png')،
$WIDTH
عرض الصورة الحالية بالبكسل،
$HEIGHT
ارتفاع الصورة الحالية بالبكسل،
$ZOOM
مستوى التكبير الحالي،
$IMAGE_NUMBER
فهرس الصورة الحالية،
$IMAGE_COUNT
إجمالي عدد الصور.

القيمة الافتراضية هي `pqiv: $FILENAME ($WIDTHx$HEIGHT) $ZOOM% [$IMAGE_NUMBER/$IMAGE_COUNT]'.

-z, --zoom-level=عشري
تعيين مستوى التكبير الأولي كقيمة عشرية، أي 1.0 تعادل 100%. ينطبق هذا فقط على الصورة الأولى، ويتم قياس الصور الأخرى وفقًا لوضع القياس (انظر --scale-images-up و --disable-scaling) وحجم النافذة.
-1, --command-1=الأمر
ربط الأمر الخارجي بالمفتاح 1. يمكنك استخدام 2..9 لربط أوامر إضافية. تسمح ميزة الإجراءات (انظر أدناه) بربط مفاتيح إضافية بأوامر أخرى. يتم تنفيذ الأمر باستخدام معالج Shell الافتراضي. يتم استبدال `$1' باسم الملف الحالي. ما لم يبدأ الأمر بـ `|' أو `-', إذا كان `$1' غير موجود، يتم إلحاق اسم الملف بسطر الأوامر.

إذا بدأ الأمر بـ `>', يتم عرض مخرجاته القياسية في نافذة منبثقة.

إذا بدأ الأمر بـ `|', يتم توجيه الصورة الحالية إلى مدخلاته القياسية، ويتم تحميل مخرجاته القياسية كصورة. يمكن استخدام هذا لمعالجة الصور، على سبيل المثال.

إذا بدأ الأمر بـ `-', يتم توجيه قائمة بالصور المحددة حاليًا إلى مدخلاته القياسية.

--action=الإجراء
تنفيذ إجراء محدد عند بدء pqiv. الصيغة هي
command(parameter); command(parameter);
انظر قسم الإجراءات أدناه للأوامر المتاحة.
--actions-from-stdin
مثل --action، ولكن اقرأ الإجراءات من المدخل القياسي. انظر قسم الإجراءات أدناه للصيغة والأوامر المتاحة. يتعارض هذا الخيار مع --additional-from-stdin.
--allow-empty-window
pqiv لا يعرض عادةً النافذة الرئيسية حتى يتم العثور على صورة واحدة، ويخرج عندما لا يتمكن من تحميل أي من الصور بعد الآن. مع هذا الخيار، ينتج عن كلتا الحالتين عرض نافذة pqiv فارغة.
--auto-montage-mode
الدخول تلقائيًا إلى وضع المونتاج إذا تم تشغيل pqiv بأكثر من صورة واحدة.
--background-pattern=النمط
يرسم pqiv لوحة متقلبة كخلفية للصور الشفافة. استخدم هذا الخيار لاستخدام خلفية بيضاء أو سوداء بدلاً من ذلك. القيم الصالحة هي checkerboard، white، و black.
--bind-key=مفتاح ربط
إعادة ربط مفتاح بإجراء. الصيغة هي
تسلسل المفاتيح { أمر(معلمة); أمر(معلمة); }
قد يكون تسلسل المفاتيح حرفًا واحدًا أو أكثر، أو أحرفًا خاصة مقدمة كـ `<name>'، حيث name هو محدد مفتاح GDK أو زر الماوس (`Mouse-1') أو اتجاه التمرير (`Mouse-Scroll-1'). إذا استخدمت، على سبيل المثال، `a<Control>b'، فيجب على المستخدم الضغط على `a' متبوعًا بـ Control + `b' لتشغيل الأمر. من الممكن ربط `a' و `ab' أيضًا. سيتم تأخير الإجراء المرتبط بـ `a' قليلاً للسماح للمستخدم بالضغط على `b'. الفاصلة المنقوطة التي تفصل بين الأوامر اختيارية. انظر الإجراءات أدناه للأوامر المتاحة.

إذا كنت بحاجة إلى معرفة اسم محدد المفاتيح، يمكنك تشغيل xev والضغط على المفتاح المطلوب. سيتم طباعة اسم المفتاح (keysym) بين قوسين، مسبوقًا بـ `keysym' وتمثيل سداسي عشري. بديل هو تشغيل xmodmap -pk. يخرج الأمر الأسماء الرمزية بين قوسين. أو استخدم القائمة في https://git.gnome.org/browse/gtk+/plain/gdk/gdkkeysyms.h.

يجمع pqiv ربط المفاتيح في سياقات مختلفة. حاليًا، وضع montage هو السياق الوحيد بخلاف الوضع الافتراضي: في وضع montage، يتم استخدام ربطات مفاتيح مختلفة. لتبديل السياق أثناء ربط تسلسلات المفاتيح، اكتب

@MONTAGE { ... }
وأدخل ربطات المفاتيح الخاصة داخل الأقواس المتعرجة.
--box-colors=لون المقدمة:لون الخلفية
تخصيص الألوان المستخدمة لرسم صندوق المعلومات وحدود وضع المونتاج. يمكن تحديد الألوان إما كقائمة مفصولة بفواصل لقيم RGB في النطاق من 0 إلى 255 أو كقيمة سداسية عشرية، على سبيل المثال، #aabbcc. القيمة الافتراضية هي #000000:#ffff00.
--browse-filenames
في وضع عرض الشرائح، انتقل إلى دليل الصورة الحالية عند انتهاء عرض الشرائح. يعمل هذا كطريقة لاستعراض الملفات.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

="permalink" href="#browse">--browse
لكل وسيط سطر أوامر، قم بتحميل جميع الصور الإضافية من دليل الصورة. pqiv سيظل يبدأ بالصورة التي تم تقديمها كالمعلمة الأولى.
--disable-backends=LIST OF BACKENDS
استخدم هذا الخيار لتعطيل بعض واجهات pqiv بشكل انتقائي. يمكنك تقديم قائمة مفصولة بفواصل من الواجهات هنا. الواجهات غير المتاحة يتم تجاهلها بصمت. تعطيل الواجهات التي لا تريدها سيسرع تحميل المجلدات بشكل كبير، خاصة إذا قمت بتعطيل واجهة الأرشيف. الواجهات المتاحة هي:
archive
دعم ملفات الأرشيف العامة
archive_cbx
دعم أرشيف الكتب المصورة *.cb؟
libav
دعم الفيديو، يعمل مع ffmpeg أيضًا
gdkpixbuf
الصور
poppler
PDF
spectre
PS/EPS
wand
ImageMagick، تنسيقات مختلفة، مثل PSD
webp
تنسيق WebP
--disable-scaling
تعطيل القياس تمامًا. يمكن تبديل هذا أثناء التشغيل بالضغط على t افتراضيًا. انظر أيضًا --scale-images-up.
--end-of-files-action=ACTION
إذا تم عرض جميع الملفات وتم عرض الصورة التالية، إما بطلب من المستخدم أو لأن عرض الشرائح نشط، يقوم pqiv افتراضيًا بالدوران وإعادة التشغيل عند الصورة الأولى. يمكن استخدام هذه المعلمة لتعديل هذا السلوك. الخيارات الصالحة لـ ACTION هي:
quit
إنهاء pqiv،
wait
انتظر حتى تصبح صورة جديدة متاحة. هذا له معنى فقط إذا تم استخدامه مع --watch-directories، على سبيل المثال،
wrap (افتراضي)
ابدأ من الصورة الأولى. في وضع العشوائية، اختر ترتيبًا عشوائيًا جديدًا،
wrap-no-reshuffle
مثل wrap، ولكن لا تعيد الخلط في الوضع العشوائي.
--enforce-window-aspect-ratio
إخبار مدير النافذة بفرض نسبة العرض إلى الارتفاع للنافذة. إذا تم تعيين هذا العلامة، فإن مدير النافذة المتوافق لن يسمح للمستخدمين بتغيير حجم نافذة pqiv إلى نسبة عرض إلى ارتفاع مختلفة. كان هذا هو السلوك الافتراضي، ولكن تميل مديري النوافذ إلى وجود أخطاء في الكود الذي يتعامل مع نسب العرض إلى الارتفاع المفروضة. إذا لم يتم تعيين العلامة وكانت نسب العرض إلى الارتفاع للنافذة والصورة غير متطابقة، فسيظل يتم رسم الصورة بنسبة العرض إلى الارتفاع الصحيحة، مع إضافة حدود سوداء على الجانبين.
--fade-duration=SECONDS
مع --fade، اجعل كل تلاشي بهذه المدة. يتم قبول القيم العشرية، على سبيل المثال 0.5 يجعل كل تلاشي يستغرق نصف ثانية.
--low-memory
حاول الحفاظ على استخدام الذاكرة في الحد الأدنى. يقوم pqiv افتراضيًا على سبيل المثال بتحميل الصورة التالية والسابقة مسبقًا لتسريع التنقل ويخزن الصور المصغرة مؤقتًا لتسريع إعادة الرسم. هذه العلامة تقوم بتعطيل مثل هذه التحسينات.
--max-depth=LEVELS
بالنسبة للمعلمات التي هي مجلدات، يبحث pqiv بشكل متكرر عن الصور. استخدم هذه المعلمة لتحديد العمق الذي يبحث فيه pqiv. مستوى 0 يعطل البحث المتكرر تمامًا، أي إذا قمت باستدعاء pqiv مع مجلد كمعلمة، فلن يبحث فيه على الإطلاق.
--negate
عرض صور سالبة. يمكنك تبديل هذه الميزة أثناء التشغيل بالضغط على n.
--shuffle
عرض الملفات بترتيب عشوائي. يتعارض هذا الخيار مع --sort. يتم إعادة خلط الملفات بعد عرض جميع الصور، ولكن ضمن دورة واحدة، الترتيب ثابت. يمكن تعطيل إعادة الخلط باستخدام --end-of-files-action. أثناء التشغيل، يمكنك استخدام Control + R افتراضيًا لتبديل وضع الخلط؛ هذا يحتفظ بترتيب الخلط، أي، يمكنك تعطيل وضع الخلط، وعرض بعض الصور، ثم تمكينه مرة أخرى واستئناف من آخر صورة قمت بعرضها سابقًا في وضع الخلط.
--show-bindings
عرض ربط مفاتيح لوحة المفاتيح والفأرة والخروج. يعرض هذا ربط المفاتيح بالصيغة المقبولة بواسطة --bind-key. انظر هناك، و قسم ACTIONS للحصول على تفاصيل حول الإجراءات المتاحة.
--sort-key=PROPERTY
المفتاح المستخدم للفرز. القيم المدعومة لـ PROPERTY هي:
name
للفرز حسب اسم الملف بترتيب طبيعي، على سبيل المثال abc32d قبل abc112d، ولكن b1 بعد كليهما،
mtime
للفرز حسب تاريخ تعديل الملف.
--thumbnail-size=WIDTHxHEIGHT
ضبط حجم الصور المصغرة في وضع montage. الافتراضي هو 128x128.
--thumbnail-preload=COUNT
تحميل مسبق لـ COUNT من الصور المصغرة المجاورة للصورة الحالية أثناء عرض الصور أو تحديدها في وضع montage. يمكن استخدام هذا لتسريع وضع montage، ولكنه سيؤدي إلى أحمال عالية على وحدة المعالجة المركزية.
--thumbnail-persistence=DIRECTORY/STATUS
الحفاظ على الصور المصغرة على القرص. أبسط طريقة لاستخدام هذا الخيار هي تقديم قيمة yes. يتم تخزين الصور المصغرة بعد ذلك وفقًا لـ معيار إدارة الصور المصغرة، في $XDG_CACHE_HOME/thumbnails/*. المعيار يسمح بتخزين الصور المصغرة بأحجام 128x128، 256x256، 512x512 و 1024x1024 حصريًا، ولا يحدد كيفية تخزين الصور المصغرة للملفات في الأرشيفات أو المستندات متعددة الصفحات. سيتم تخزين الصور المصغرة التي تنتهك هذه القيود في مجلد فرعي خاص x-pqiv. قدم standard لتخزين الصور المصغرة المتوافقة مع المعيار فقط. إذا لم يتم استخدام هذا الخيار، فلن يتم تحميل الصور المصغرة من ذاكرة التخزين المؤقت أيضًا - سيتم إنشاء أي صور مصغرة في كل مرة يتم فيها استخدام وضع montage. يمكن استخدام قيمة read-only لتحميل الصور المصغرة، ولكن عدم تخزينها أبدًا. read-only هو الافتراضي.
إذا قدمت local كقيمة للمعلمة، سيقوم pqiv بتخزين الصور المصغرة في مجلد فرعي يسمى .sh_thumbnails بالنسبة للصور كما هو محدد في معيار إدارة الصور المصغرة. خيارك الثالث هو تقديم اسم دليل. سيستخدم pqiv بعد ذلك هذا الدليل لتخزين الصور المصغرة فيه. يجب أن يتم تقديم المجلد كمسار مطلق، المسارات النسبية لا تعمل. لاحظ أن أي مجلد غير مسمى .sh_thumbnails سيتم اعتباره في --watch-directories. أيضًا، لاحظ أنه بينما سيقوم pqiv بتخزين الصور المصغرة في مجلد آخر، سيظل يحاول تحميلها من المجلدات القياسية أيضًا.
--recreate-window
حل بديل لمديري النوافذ الذين لا يتعاملون مع طلبات تغيير الحجم بشكل صحيح: بدلاً من تغيير الحجم، أعد إنشاء النافذة كلما تم تغيير الصورة. هذا لا يعيد رسم الصور عند حدوث تغييرات في التكبير وحده.
--scale-mode-screen-fraction=FRACTION
اضبط مقدار مساحة الشاشة التي يستخدمها pqiv عند القياس التلقائي للصور خارج وضع ملء الشاشة. الافتراضي هو 0.8 (80%).
--wait-for-images-to-appear
إذا لم يتم العثور على صور في المجلدات المحددة في سطر الأوامر، بدلاً من الخروج، انتظر حتى تظهر بعض الصور. يعمل هذا الخيار فقط بالتزامن مع --lazy-load و --watch-directories.
--watch-directories
مراقبة جميع المجلدات المقدمة كمعلمات لـ pqiv بحثًا عن ملفات جديدة وإضافتها عند ظهورها. في وضع --sort، يتم فرز الملفات في الموضع الصحيح، وإلا، يتم إلحاقها بنهاية القائمة. انظر أيضًا --watch-files، الذي يتعامل مع كيفية التعامل مع التغييرات في الصورة التي يتم عرضها حاليًا.
--watch-files=VALUE
مراقبة الملفات بحثًا عن تغييرات على القرص. الخيارات الصالحة لـ VALUE هي:
on (افتراضي)
مراقبة الملفات بحثًا عن تغييرات، وإعادة التحميل عند حدوث تغيير، وتخطي الملف التالي إذا تمت إزالة ملف،
changes-only
مراقبة الملفات بحثًا عن تغييرات، وإعادة التحميل عند حدوث تغيير، ولكن لا تفعل شيئًا إذا تمت إزالة ملف،
off
لا تراقب الملفات بحثًا عن تغييرات على الإطلاق.

لاحظ أنه سيظل الملف الذي تمت إزالته يُزال من قائمة صور pqiv عند تفريغه، أي إذا ابتعد المستخدم عن صورته بأكثر من صورة واحدة. (انظر أيضًا --low-memory.)

الإجراءات

الإجراءات هي اللبنات الأساسية للتحكم في pqiv. صيغة إدخال إجراء هي

COMMAND(PARAMETER)
حيث COMMAND هو أحد الأوامر الموصوفة فيما يلي و PARAMETER هو معلمة الأمر. لا يتم اقتباس السلاسل النصية. بدلاً من ذلك، يجب الهروب من القوس المغلق بشرطة مائلة للخلف إذا تم استخدامه في سلسلة نصية. على سبيل المثال، `command(echo \))' سيخرج قوسًا واحدًا `)'. الأوامر المتاحة هي:

add_file(STRING)
إضافة ملف أو مجلد.
animation_step(INT)
إيقاف الرسوم المتحركة، والتقدم بمقدار عدد الإطارات المحدد بالإضافة إلى واحد.
animation_continue()
متابعة الرسوم المتحركة المتوقفة.

OPTIONS

alt-f
Toggle fullscreen mode.
align(INT,INT,INT,INT)
Align the image to the window/screen border. Possible parameter values are the cardinal directions, e.g. NE will align the image to the north east, i.e. top right, corner. You can prepend the parameter by an additional C to perform the adjustment only if the image dimensions exceed the available space, and to center the image elsewise.
set_shift_x(INT)
Set the shift in horizontal direction to a fixed value.
set_shift_y(INT)
Set the shift in vertical direction to a fixed value.
set_slideshow_interval_absolute(DOUBLE)
Set the slideshow interval to the parameter value, in seconds.
set_slideshow_interval_relative(DOUBLE)
Adjust the slideshow interval additively by the parameter value. See also --slideshow-interval.
set_status_output(INT)
Set this to non-zero to make pqiv print status information for scripts to stdout, once upon activation and then whenever the user moves between images. The format is compatible with shell variable definitions. Variables currently implemented are CURRENT_FILE_NAME and CURRENT_FILE_INDEX. An output sweep always ends with an empty line.
set_thumbnail_preload(INT)
Change the amount of thumbnails to be preloaded. A value of zero disables the feature.
set_thumbnail_size(INT,INT)
Change the size of thumbnails. The order of the arguments is width, then height. Thumbnails are always scaled such that no side is larger than this limit.
shift_x(INT)
Shift the current image in x direction.
shift_y(INT)
Shift the current image in y direction.
toggle_background_pattern(INT)
Toggle between the different background patterns: 0 to toggle, 1 for checkerboard pattern, 2 for black, 3 for white.
toggle_fullscreen(INT)
Toggle fullscreen mode: 0 to toggle, 1 to go to fullscreen, 2 to return to window mode.
toggle_info_box()
Toggle the visibility of the info box.
toggle_mark()
Toggle the current image's mark.
toggle_negate_mode(INT)
Toggle negate (color inversion) mode: 0 to toggle, 1 to enable, 2 to disable.
toggle_scale_mode(INT)
Change the scale mode: Use 1 to disable scaling, 2 for automated scaledown (default), 3 to always scale images up, 4 to maintain the user-set zoom level, and 5 to maintain the window's size. 0 cycles through modes 1-3.
toggle_shuffle_mode(INT)
Toggle shuffle mode. Use 0 to cycle through the possible values, 1 to enable shuffle, and any other value to disable it.
toggle_slideshow()
Toggle slideshow mode.

ملف التكوين

Upon startup, pqiv parses the file ~/.config/pqivrc. It should be a INI-style key/value file with an options section. All long form parameters are valid keys. To set a boolean flag, set the value to 1. A set flag inverts the meaning of the associated parameter. E.g., if you set `fullscreen=1', then pqiv will start in fullscreen mode unless you supply -f upon startup.

As an example,

[options]
fullscreen=1
sort=1
command-1=|convert - -blur 20 -
will make pqiv start in fullscreen by default, sort the file list and bind a blur filter to key 1. The -f flag on the command line will make pqiv not start in fullscreen, and -n will make it not sort the list.

You can place key bindings in the format of the --bind-key parameter in a special [keybindings] section. E.g.,

[keybindings]
q { goto_file_relative(-1); }
w { goto_file_relative(1); }
x { send_keys(#1); }
<numbersign>1 { set_scale_level_absolute(1.); bind_key(x { send_keys(#2\); }); }
<numbersign>2 { set_scale_level_absolute(.5); bind_key(x { send_keys(#3\); }); }
<numbersign>3 { set_scale_level_absolute(0.25); bind_key(x { send_keys(#1\); }); }
will remap q and w to move between images, and set up x to cycle through 100%, 50% and 25% zoom levels.

Similarly, you can also specify (multiple) actions to be executed each time pqiv is started in a section called [actions].

For backwards compatibility with old versions of pqiv, if the file does not start with a section definition, the first line will be parsed as command line parameters.

You may place comments into the file by beginning a line with `;' or `#'. Comments at the end of a line are not supported.

Other supported paths for the configuration file are ~/.pqivrc, /etc/xdg/pqivrc and /etc/pqivrc. pqiv will use whichever file it finds first. You can use the environment variable PQIVRC_PATH to override the configuration file.

أمثلة

pqiv --bind-key="a { goto_file_byindex(0) }" --bind-key='c { command(echo -n $1 | xclip) }' --sort foo bar.pdf
Rebinds a to go back to the first image, c to store the path to the current image to the clipboard using xclip and loads all files from the foo folder and bar.pdf, sorted.
pqiv --slideshow --watch-directories --end-of-files-action=wait --slideshow-interval=0.001 test
Load all files from the test folder in a slideshow progressing very fast, and in the end wait until new files become available. This effectively displays new images as they appear in a directory and is useful e.g. if you output images from a script that you later intent to combine into a movie and wish to monitor progress.
