الاسم

Pqueue.MakeMin - دالة تصنيعية تبني تطبيقًا لهيكل طابور الأولوية الأدنى مع نوع مرتب كليًا للعناصر.

الوحدة

الوحدة Pqueue.MakeMin

التوثيق

دالة تصنيعية تبني تطبيقًا لهيكل طابور الأولوية الأدنى مع نوع مرتب كليًا للعناصر.

طوابير الأولوية الدنيا

type t

نوع طوابير الأولوية.

type elt

نوع عناصر طابور الأولوية.

val create : unit -> t

إرجاع طابور أولوية جديد، فارغ مبدئيًا.

val length : t -> int

إرجاع عدد العناصر في طابور الأولوية.

val is_empty : t -> bool

is_empty q تكون true إذا وفقط إذا كان q فارغًا، أي، إذا وفقط إذا كان length q = 0.

val add : t -> elt -> unit

add q x تضيف العنصر x إلى طابور الأولوية q.

val add_iter : t -> ((elt -> unit) -> 'x -> unit) -> 'x -> unit

add_iter q iter x تضيف كل عنصر من x إلى نهاية q. هذه هي iter (add q) x.

val min_elt : t -> elt option

min_elt q هو عنصر من q له الأولوية الدنيا أو None إذا كان الطابور فارغًا. لا يتم تعديل الطابور.

val get_min_elt : t -> elt

get_min_elt q تُرجع عنصرًا من q له الأولوية الدنيا، أو تثير استثناء Invalid_argument إذا كان الطابور فارغًا. لا يتم تعديل الطابور.

val pop_min : t -> elt option

pop_min q تزيل وتُرجع عنصرًا في الطابور q له الأولوية الدنيا، أو تُرجع None إذا كان الطابور فارغًا.

val remove_min : t -> unit

remove_min q تزيل عنصرًا في الطابور q له الأولوية الدنيا. لا تفعل شيئًا إذا كان q فارغًا.

val clear : t -> unit

clear q تزيل جميع العناصر من q.

val copy : t -> t

copy q هو طابور أولوية جديد بنفس عناصر q.

التحويلات من هياكل بيانات أخرى

val of_array : elt array -> t

of_array a تُرجع طابور أولوية جديد يحتوي على عناصر المصفوفة a. يعمل في وقت خطي.

val of_list : elt list -> t

of_list l تُرجع طابور أولوية جديد يحتوي على عناصر القائمة l. يعمل في وقت خطي.

val of_iter : ((elt -> unit) -> 'x -> unit) -> 'x -> t

of_iter iter x تُرجع طابور أولوية جديد يحتوي على عناصر x، التي تم الحصول عليها من iter.

على سبيل المثال، of_iter Seq.iter s تُرجع طابور أولوية جديد يحتوي على جميع عناصر التسلسل s (بشرط أن يكون محدودًا).

يعمل في وقت خطي (باستثناء الوقت المستغرق في iter).

التكرار

ترتيب اجتياز عناصر طابور الأولوية غير محدد.

يُعد تعديل طابور الأولوية (بإضافة أو إزالة العناصر) أثناء تكرار الطابور خطأ برمجيًا. قد يتم اكتشاف مثل هذا الخطأ والإبلاغ عنه بواسطة تطبيق المصفوفة الديناميكية الداعمة، ولكن هذا غير مضمون.

val iter_unordered : (elt -> unit) -> t -> unit

iter_unordered f q تطبق f على جميع العناصر في q. ترتيب تمرير العناصر إلى f غير محدد.

السلوك غير محدد إذا تم تعديل طابور الأولوية بواسطة f أثناء التكرار.

val fold_unordered : ('acc -> elt -> 'acc) -> 'acc -> t -> 'acc

fold_unordered f accu q هي (f (... (f (f accu x1) x2) ...)
xn) حيث x1,x2,...,xn هي عناصر q. ترتيب تمرير العناصر إلى f غير محدد.

السلوك غير محدد إذا تم تعديل طابور الأولوية بواسطة f أثناء التكرار.
