ioctl_kd(2) دليل استدعاءات النظام ioctl_kd(2)

الاسم

ioctl_kd - استدعاءات ioctl للطرفية الطرفية والنوافذ الافتراضية

الملخص

#include <linux/kd.h>  /* تعريف ثوابت العمليات */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

الوصف

العمليات التالية الخاصة بـ ioctl(2) لطرفية الطرفية والنوافذ الافتراضية مدعومة:

KDGETLED
الحصول على حالة مصابيح LED. يشير argp إلى char. الثلاث بتات الدنيا لـ *argp هي حالات مصابيح LED، كما يلي:
LED_CAP 0x04 مصتاح Caps Lock
LED_NUM 0x02 مصتاح Num Lock
LED_SCR 0x01 مصتاح Scroll Lock
KDSETLED
ضبط مصابيح LED. يتم ضبط مصابيح LED بناءً على الثلاث بتات الدنيا من argp (عدد صحيح غير موقع). ومع ذلك، إذا تم ضبط بت عالي المستوى، فسيتم إعادة تعيين مصابيح LED إلى حالتها العادية، وعرض حالة وظائف لوحة المفاتيح Caps Lock و Num Lock و Scroll Lock.

قبل Linux 1.1.54، عكست مصابيح LED حالات flags لوحة المفاتيح المقابلة، وقامت KDGETLED/KDSETLED أيضًا بتغيير flags لوحة المفاتيح. منذ Linux 1.1.54، يمكن لمصابيح LED عرض معلومات عشوائية، ولكن افتراضيًا تعرض flags لوحة المفاتيح. تستخدم استدعاءات ioctl التالية للوصول إلى flags لوحة المفاتيح:

KDGKBLED
الحصول على flags لوحة المفاتيح CapsLock و NumLock و ScrollLock (وليس مصابيح LED). يشير argp إلى char يتم ضبطه على حالة flags. الثلاث بتات الدنيا (قناع 0x7) تعطي الحالة الحالية للـ flags، والبتات الدنيا للـ nibble التالية (قناع 0x70) تعطي الحالة الافتراضية للـ flags. (من Linux 1.1.54.)
KDSKBLED
ضبط flags لوحة المفاتيح CapsLock و NumLock و ScrollLock (وليس مصابيح LED). argp هو عدد صحيح غير موقع يحتوي على الحالة المطلوبة للـ flags. الثلاث بتات الدنيا (قناع 0x7) تحمل حالة الـ flags، والبتات الدنيا للـ nibble التالية (قناع 0x70) تحمل الحالة الافتراضية للـ flags. (من Linux 1.1.54.)
KDGKBTYPE
الحصول على نوع لوحة المفاتيح. يعيد القيمة KB_101، المعرفة على أنها 0x02.
KDADDIO
إضافة منفذ إدخال/إخراج كمنفذ صالح. يعادل ioperm(arg,1,1).
KDDELIO
حذف منفذ إدخال/إخراج كمنفذ صالح. يعادل ioperm(arg,1,0).
KDENABIO
تمكين الإدخال/الإخراج للوحة الفيديو. يعادل ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
تعطيل الإدخال/الإخراج للوحة الفيديو. يعادل ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
ضبط وضع النص/الرسومات. argp هو عدد صحيح غير موقع يحتوي على أحد القيم التالية:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
الحصول على وضع النص/الرسومات. يشير argp إلى int يتم ضبطه على أحد القيم المذكورة أعلاه لـ KDSETMODE.
KDMKTONE
إنشاء نغمة بطول محدد. تحدد الـ 16 بت الدنيا من العدد الصحيح غير الموقع في argp الدورية في دورات الساعة، والـ 16 بت العليا تعطي المدة بالمللي ثانية. إذا كانت المدة صفرًا، فسيتم إيقاف الصوت. يعود التحكم فورًا. على سبيل المثال، argp = (125<<16) + 0x637 يحدد الصوت العادي المرتبط بـ ctrl-G. (لذلك، من Linux 0.99pl1؛ معطل في Linux 2.1.49-50.)
KIOCSOUND
تمكين أو تعطيل توليد الصوت. تحدد الـ 16 بت الدنيا من argp الدورية في دورات الساعة (أي، argp = 1193180/التردد). argp = 0 يعطل الصوت. في أي حال، يعود التحكم فورًا.
GIO_CMAP
الحصول على خريطة الألوان الحالية لنظام النواة. يشير argp إلى مصفوفة بحجم 48 بايت. (من Linux 1.3.3.)
PIO_CMAP
تعديل خريطة الألوان الافتراضية لوضع النص. يشير argp إلى مصفوفة بحجم 48 بايت تحتوي، بالترتيب، على قيم الأحمر والأخضر والأزرق للألوان الـ 16 للشاشة: 0 هو إيقاف، 255 هو أقصى سطوع. الألوان الافتراضية هي: أسود، أحمر داكن، أخضر داكن، بني، أزرق داكن، بنفسجي داكن، سماوي داكن، رمادي فاتح، رمادي داكن، أحمر ساطع، أخضر ساطع، أصفر، أزرق ساطع، بنفسجي ساطع، سماوي ساطع، أبيض. (من Linux 1.3.3.)
GIO_FONT
الحصول على خط الـ 256 حرفًا بالشكل الموسع. يشير argp إلى مصفوفة بحجم 8192 بايت. يفشل بخطأ EINVAL إذا كان الخط الحالي بحجم 512 حرفًا، أو إذا كانت الطرفية ليست في وضع النص.
GIO_FONTX
الحصول على خط الشاشة والمعلومات المرتبطة به. يشير argp إلى struct consolefontdesc (انظر PIO_FONTX). عند الاستدعاء، يجب تعيين الحقل charcount إلى الحد الأقصى لعدد الأحرف التي يمكن أن تتسع في المخزن المؤقت الذي يشير إليه chardata. عند العودة، يتم ملء الحقلين charcount و charheight ببيانات الخط الحالية المقابلة، ويحتوي chardata على بيانات الخط إذا كانت القيمة الأولية لـ charcount تشير إلى مساحة كافية؛ وإلا، لا يتم تعديل المخزن المؤقت ويتم تعيين errno إلى ENOMEM. (من Linux 1.3.1.)
PIO_FONT
تعيين خط الـ 256 حرفًا للشاشة. تحميل الخط إلى مولد أحرف EGA/VGA. يشير argp إلى مصفوفة بحجم 8192 بايت مع 32 بايت لكل حرف. فقط أول N منها يتم استخدامها لخط بحجم 8xN (0 N < 32). هذا الاستدعاء يبطل أيضًا تعيين Unicode.
PIO_FONTX
تعيين خط الشاشة ومعلومات العرض المرتبطة به. يشير argp إلى

struct consolefontdesc {
    unsigned short charcount;  /* عدد الأحرف في الخط
                                  (256 أو 512) */
    unsigned short charheight; /* خطوط المسح لكل
                                  حرف (1-32) */
    char          *chardata;   /* بيانات الخط بالشكل الموسع */
};

إذا لزم الأمر، سيتم تعديل الشاشة بشكل مناسب وسيتم إرسال SIGWINCH إلى العمليات المناسبة. يبطل هذا الاستدعاء أيضًا تعيين Unicode. (من Linux 1.3.1.)
PIO_FONTRESET
إعادة تعيين الخط والحجم وتعements Unicode إلى القيم الافتراضية عند الإقلاع. لا يتم استخدام argp، ولكن يجب تعيينه إلى NULL لضمان التوافق مع الإصدارات المستقبلية من Linux. (من Linux 1.3.28.)
GIO_SCRNMAP
الحصول على تعيين الشاشة لنظام النواة. يشير argp إلى منطقة بحجم E_TABSZ، والتي يتم تحميلها بمواضع الخط المستخدمة لعرض كل حرف. قد يعيد هذا الاستدعاء معلومات مفيدة إذا كان الخط الحالي أكبر من 256 حرفًا.
GIO_UNISCRNMAP
الحصول على تعيين أحرف Unicode الكامل للشاشة لنظام النواة. يشير argp إلى منطقة بحجم E_TABSZ*sizeof(unsigned short)، والتي يتم تحميلها بأحرف Unicode التي تمثل كل حرف. نوع خاص من Unicode، يبدأ من U+F000، يستخدم لتمثيل تعيينات "مباشرة إلى الخط". (من Linux 1.3.1.)
PIO_SCRNMAP
تحميل تعيين "المستخدم" (الرابع) في النواة الذي يعين البايتات إلى رموز شاشة الطرفية. يشير argp إلى منطقة بحجم E_TABSZ.
ioctl_console(2) — Arch Linux man pages

NAME

ioctl_console — operaciones de entrada/salida de consola del kernel

SYNOPSIS

#include <linux/vt.h>

#include <linux/kd.h>

long ioctl(int fd, unsigned long request, ...);

DESCRIPTION

La llamada al sistema ioctl() puede ser utilizada para realizar una variedad de operaciones de entrada/salida específicas de la consola. El fd se abre a un dispositivo de consola de tty (por ejemplo, /dev/tty0).

Las siguientes peticiones request son soportadas:

PIO_UNISCRNMAP
Carga la tabla "usada definida por el usuario" (cuarta) en el kernel que mapea bytes a Unicodes, que luego se traducen en símbolos de pantalla según el mapa actual de Unicode a fuentes cargado. Los Unicodes especiales comenzando por U+F000 pueden usarse directamente para mapear a los símbolos de la fuente. (Desde Linux 1.3.1.)
GIO_UNIMAP
Obtiene el mapeo de Unicode a fuentes del kernel. argp apunta a un

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

donde entries apunta a un arreglo de

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Desde Linux 1.1.92.)
PIO_UNIMAP
Coloca el mapeo de Unicode a fuentes en el kernel. argp apunta a un struct unimapdesc. (Desde Linux 1.1.92)
PIO_UNIMAPCLR
Limpiar la tabla, posiblemente indicar el algoritmo de hash. argp apunta a un

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 si no tiene opinión */
    unsigned short advised_hashstep;  /* 0 si no tiene opinión */
    unsigned short advised_hashlevel; /* 0 si no tiene opinión */
};

(Desde Linux 1.1.92.)
KDGKBMODE
Obtiene el modo de teclado actual. argp apunta a un long que se establece en uno de estos:
K_RAW 0x00 /* Modo raw (scancode) */
K_XLATE 0x01 /* Traduce los codigos de teclado usando el mapa de teclado */
K_MEDIUMRAW 0x02 /* Modo medio raw (scancode) */
K_UNICODE 0x03 /* Modo Unicode */
K_OFF 0x04 /* Modo desactivado (desde Linux 2.6.39) */
KDSKBMODE
Establece el modo de teclado actual. argp es un long igual a uno de los valores mostrados para KDGKBMODE.
KDGKBMETA
Obtiene el modo de manejo de teclas metálicas. argp apunta a un long que se establece en uno de estos:
K_METABIT 0x03 establece el bit alto
K_ESCPREFIX 0x04 prefijo de escape
KDSKBMETA
Establece el modo de manejo de teclas metálicas. argp es un long igual a uno de los valores mostrados arriba para KDGKBMETA.
KDGKBENT
Obtiene una entrada en la tabla de traducción de teclas (código de tecla a acción). argp apunta a un

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

donde los primeros dos miembros están llenos: kb_table selecciona la tabla de teclas (0 <= kb_table < MAX_NR_KEYMAPS), y kb_index es el código de tecla (0 <= kb_index < NR_KEYS). kb_value se establece en el código de acción correspondiente, o K_HOLE si no existe tal clave, o K_NOSUCHMAP si kb_table es inválido.
KDSKBENT
Establece una entrada en la tabla de traducción. argp apunta a un struct kbentry.
KDGKBSENT
Obtiene una cadena de tecla función. argp apunta a un

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string se establece en la cadena (terminada en null) correspondiente a la acción código kb_func de la tecla función.
KDGKBDIACR
Lee la tabla de acentos del kernel. argp apunta a un

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

donde kb_cnt es el número de entradas en el arreglo, cada una de las cuales es un

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Lee la entrada del tabla de código de teclado (escan code a código de teclado). argp apunta a un

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode se establece en el correspondiente código de teclado para el valor dado scancode. (89 <= scancode <= 255 solo. Para 1 <= scancode <= 88, keycode == scancode.) (Desde Linux 1.1.63.)
KDSETKEYCODE
Escribe la entrada del tabla de código de teclado. argp apunta a un struct kbkeycode. (Desde Linux 1.1.63.)
KDSIGACCEPT
El proceso llamante indica su disposición de aceptar el señal argp cuando es generada por una combinación de teclas apropiada. (1 <= argp <= NSIG). (Ver spawn_console() en linux/drivers/char/keyboard.c.)

RETURN VALUE

En éxito, 0 se devuelve (a no ser donde se indique). En fallo, -1 se devuelve, y errno se establece para indicar el error.

ERRORS

EINVAL
argp es inválido.

STANDARDS

Linux.

SEE ALSO
