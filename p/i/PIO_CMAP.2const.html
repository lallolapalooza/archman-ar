ioctl_kd(2) دليل استدعاءات النظام ioctl_kd(2)

الاسم

ioctl_kd - استدعاءات تحكم لطرفية الشاشة والنوافذ الافتراضية

الملخص

#include <linux/kd.h>  /* تعريف الثوابت التشغيلية */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

الوصف

عمليات Linux ioctl(2) التالية الخاصة بـ Linux متاحة لطرفية الشاشة والنوافذ الافتراضية:

KDGETLED
الحصول على حالة مؤشرات LED. argp يشير إلى char. البتات الثلاثة الأدنى من *argp تحدد حالة مؤشرات LED، من بين التالية:
LED_CAP 0x04 مؤشر Caps Lock
LED_NUM 0x02 مؤشر Num Lock
LED_SCR 0x01 مؤشر Scroll Lock
KDSETLED
تعيين مؤشرات LED. يتم تعيين مؤشرات LED وفقًا للبتات الثلاثة الأدنى من عدد صحيح unsigned long في argp. ومع ذلك، إذا تم تعيين بت أعلى، تعمل مؤشرات LED بشكل طبيعي: تعرض حالة وظائف لوحة المفاتيح Caps Lock و Num Lock و Scroll Lock.

قبل Linux 1.1.54، كانت مؤشرات LED تعكس فقط حالة علامات لوحة المفاتيح المقابلة، وكانت KDGETLED/KDSETLED تعدل أيضًا علامات لوحة المفاتيح. منذ Linux 1.1.54، يمكن لمؤشرات LED عرض معلومات عشوائية، ولكنها تعرض علامات لوحة المفاتيح افتراضيًا. تستخدم استدعاءات ioctl التالية للوصول إلى علامات لوحة المفاتيح:

KDGKBLED
الحصول على حالة علامات لوحة المفاتيح CapsLock و NumLock و ScrollLock (ليست LED). argp يشير إلى char يتم تعيينه إلى حالة العلامة. البتات الثلاثة الأدنى (قناع 0x7) تحدد الحالة الحالية للعلامة، والبتات الأدنى من الشبكة التالية (قناع 0x70) تحدد الحالة الافتراضية للعلامة. (منذ Linux 1.1.54).
KDSKBLED
تعيين علامات لوحة المفاتيح CapsLock و NumLock و ScrollLock (ليست LED). argp هو عدد صحيح unsigned long يحتوي على الحالة المطلوبة للعلامات. البتات الثلاثة الأدنى (قناع 0x7) تحدد حالة العلامات، والبتات الأدنى من الشبكة التالية (قناع 0x70) تحدد الحالة الافتراضية للعلامات. (منذ Linux 1.1.54).
KDGKBTYPE
الحصول على نوع لوحة المفاتيح. يعيد القيمة KB_101، المعرفة كـ 0x02.
KDADDIO
إضافة منفذ إدخال/إخراج كمنفذ صالح. يعادل ioperm(arg,1,1).
KDDELIO
إزالة منفذ إدخال/إخراج كمنفذ صالح. يعادل ioperm(arg,1,0).
KDENABIO
تمكين الاتصال مع لوحة الفيديو. يعادل ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
تعطيل الاتصال مع لوحة الفيديو. يعادل ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
تعيين وضع النص/الرسومات. argp هو عدد صحيح unsigned يحتوي على أحد القيم التالية:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
الحصول على وضع النص/الرسومات. argp يشير إلى int يتم تعيينه إلى أحد القيم الموضحة أعلاه لـ KDSETMODE.
KDMKTONE
إنشاء صوت بطول محدد. البتات الـ 16 الأدنى من عدد صحيح unsigned long في argp تحدد التردد في دورات الساعة، والبتات الـ 16 العليا تحدد المدة بالملي ثانية. إذا كانت المدة صفرًا، يتم تعطيل الصوت. يعود التحكم فورًا. على سبيل المثال، argp = (125<<16) + 0x637 يحدد الصوت الطبيعي المرتبط بـ ctrl-G. (لذلك، منذ Linux 0.99pl1؛ معطل في Linux 2.1.49-50).
KIOCSOUND
بدء أو إيقاف توليد الصوت. البتات الـ 16 الأدنى من argp تحدد التردد في دورات الساعة (أي argp = 1193180/frequency). argp = 0 يعطل الصوت. في كلتا الحالتين، يعود التحكم فورًا.
GIO_CMAP
الحصول على خريطة الألوان الحالية للنواة. argp يشير إلى مساحة بحجم 48 بايت. (منذ Linux 1.3.3).
PIO_CMAP
تغيير خريطة الألوان الافتراضية في وضع النص. argp يشير إلى مساحة بحجم 48 بايت تحتوي، بالترتيب، على قيم الأحمر والأخضر والأزرق للألوان الـ 16 المتاحة في وضع النص: 0 هو تعطيل، و 255 هو أقصى شدة. الألوان الافتراضية هي، بالترتيب: أسود، أحمر داكن، أخضر داكن، بني، أزرق داكن، بنفسجي داكن، سماوي داكن، رمادي فاتح، رمادي داكن، أحمر ساطع، أخضر ساطع، برتقالي، أزرق ساطع، بنفسجي ساطع، سماوي ساطع، أبيض. (منذ Linux 1.3.3).
GIO_FONT
الحصول على خط الشاشة بتنسيق موسع. argp يشير إلى مساحة بحجم 8192 بايت. يفشل برمز خطأ EINVAL إذا كان الخط الحالي هو خط 512 حرفًا، أو إذا كانت الشاشة ليست في وضع النص.
GIO_FONTX
الحصول على خط الشاشة والمعلومات المرتبطة به. argp يشير إلى struct consolefontdesc (انظر PIO_FONTX). عند الاستدعاء، يجب تعيين الحقل charcount إلى الحد الأقصى لعدد الأحرف التي يمكن أن تتناسب مع المخزن المؤقت الذي يشير إليه chardata. عند العودة، تحتوي الحقول charcount و charheight على البيانات المقابلة للخط الحالي، ويحتوي الحقل chardata على بيانات الخط إذا أشار حجم charcount الأولي إلى مساحة كافية؛ وإلا، لا يتم تعديل المخزن المؤقت ويتم تعيين errno إلى ENOMEM. (منذ Linux 1.3.1).
PIO_FONT
تعيين خط الشاشة المكون من 256 حرفًا. يقوم بتحميل الخط إلى مولد أحرف EGA/VGA. argp يشير إلى خريطة بحجم 8192 بايت، مع 32 بايت لكل حرف. يتم استخدام أول N فقط منها لخط 8xN (0 N N 32). يبطل هذا الاستدعاء أيضًا تعيين Unicode.
PIO_FONTX
تعيين خط الشاشة ومعلومات العرض. argp يشير إلى

struct consolefontdesc {
    unsigned short charcount;  /* عدد الأحرف في الخط
                                  (256 أو 512) */
    unsigned short charheight; /* أسطر المسح لكل
                                  حرف (1-32) */
    char          *chardata;   /* بيانات الخط بتنسيق موسع */
};

إذا لزم الأمر، يتم تغيير حجم الشاشة بشكل مناسب ويتم إرسال SIGWINCH إلى العمليات المناسبة. يبطل هذا الاستدعاء أيضًا تعيين Unicode. (منذ Linux 1.3.1).
PIO_FONTRESET
إعادة تعيين الخط، والحجم، وتعmeen Unicode إلى القيم الافتراضية عند التشغيل. لا يتم استخدام argp، ولكن يجب تعيينه إلى NULL لضمان التوافق مع إصدارات Linux المستقبلية. (منذ Linux 1.3.28).
GIO_SCRNMAP
الحصول على خريطة الشاشة للنواة. argp يشير إلى مساحة بحجم E_TABSZ، تحتوي على المواقع المستخدمة لعرض كل حرف. قد يعيد هذا الاستدعاء معلومات غير مفيدة إذا كان الخط الحالي أكبر من 256 حرفًا.
GIO_UNISCRNMAP
الحصول على خريطة Unicode الكاملة للشاشة للنواة. argp يشير إلى مساحة بحجم E_TABSZ*sizeof(unsigned short)، تحتوي على Unicodes التي تمثل كل حرف. تستخدم سلسلة خاصة من Unicodes، بدءًا من U+F000، لتمثيل تعيينات "مباشرة إلى الخط". (منذ Linux 1.3.1).
PIO_SCRNMAP
تحميل "الجدول القابل للتعريف" (الرابع) في النواة الذي يعين البايتات إلى رموز شاشة الطرفية. argp يشير إلى مساحة بحجم E_TABSZ.

NAME

PIO_UNISCRNMAP, GIO_UNIMAP, PIO_UNIMAP, PIO_UNIMAPCLR, KDGKBMODE, KDSKBMODE, KDGKBMETA, KDSKBMETA, KDGKBENT, KDSKBENT, KDGKBSENT, KDSKBSENT, KDGKBDIACR, KDGETKEYCODE, KDSETKEYCODE, KDSIGACCEPT - لوحة مفاتيح خاصة بـ ioctl

SYNOPSIS

#include <linux/kd.h>

long ioctl(int fd, unsigned long request, ...);

DESCRIPTION

هذه الوظائف هي واجهات ioctl لنظام لوحة المفاتيح.

PIO_UNISCRNMAP
يقوم بتحميل جدول "قابل للتعريف من قبل المستخدم" (الرابع) في النواة والذي يربط البايتات بـ Unicodes، والتي يتم بعد ذلك ترجمتها إلى رموز شاشة وفقًا لخريطة Unicode إلى الخط المحملة حاليًا. يمكن استخدام Unicodes الخاصة بدءًا من U+F000 للربط مباشرة برموز الخط. (منذ Linux 1.3.1.)
GIO_UNIMAP
الحصول على ربط Unicode إلى خط من النواة. argp يشير إلى

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

حيث entries تشير إلى مصفوفة من

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(منذ Linux 1.1.92.)
PIO_UNIMAP
وضع ربط Unicode إلى خط في النواة. argp يشير إلى struct unimapdesc. (منذ Linux 1.1.92)
PIO_UNIMAPCLR
مسح الجدول، وربما إعلام خوارزمية التجزئة. argp يشير إلى

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 if no opinion */
    unsigned short advised_hashstep;  /* 0 if no opinion */
    unsigned short advised_hashlevel; /* 0 if no opinion */
};

(منذ Linux 1.1.92.)
KDGKBMODE
الحصول على وضع لوحة المفاتيح الحالي. argp يشير إلى long والذي يتم تعيينه إلى أحد هذه القيم:
K_RAW 0x00 /* Raw (scancode) mode */
K_XLATE 0x01 /* Translate keycodes using keymap */
K_MEDIUMRAW 0x02 /* Medium raw (scancode) mode */
K_UNICODE 0x03 /* Unicode mode */
K_OFF 0x04 /* Disabled mode (since Linux 2.6.39) */
KDSKBMODE
تعيين وضع لوحة المفاتيح الحالي. argp هو long يساوي أحد القيم المعروضة لـ KDGKBMODE.
KDGKBMETA
الحصول على وضع معالجة مفتاح meta. argp يشير إلى long والذي يتم تعيينه إلى أحد هذه القيم:
K_METABIT 0x03 set high order bit
K_ESCPREFIX 0x04 escape prefix
KDSKBMETA
تعيين وضع معالجة مفتاح meta. argp هو long يساوي أحد القيم المعروضة أعلاه لـ KDGKBMETA.
KDGKBENT
الحصول على إدخال واحد في جدول ترجمة المفاتيح (رمز المفتاح إلى رمز الإجراء). argp يشير إلى

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

مع تعبئة أول عضوين: kb_table يختار جدول المفاتيح (0 <= kb_table < MAX_NR_KEYMAPS)، و kb_index هو رمز المفتاح (0 <= kb_index < NR_KEYS). يتم تعيين kb_value إلى رمز الإجراء المقابل، أو K_HOLE إذا لم يكن هناك مفتاح كهذا، أو K_NOSUCHMAP إذا كان kb_table غير صالح.
KDSKBENT
تعيين إدخال واحد في جدول الترجمة. argp يشير إلى struct kbentry.
KDGKBSENT
الحصول على سلسلة مفتاح وظيفة واحدة. argp يشير إلى

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

يتم تعيين kb_string إلى السلسلة (منتهية بـ null) المقابلة لرمز الإجراء لمفتاح الوظيفة kb_functh.
KDSKBSENT
تعيين إدخال سلسلة مفتاح وظيفة واحدة. argp يشير إلى struct kbsentry.
KDGKBDIACR
قراءة جدول النبرة في النواة. argp يشير إلى

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

حيث kb_cnt هو عدد الإدخالات في المصفوفة، وكل منها عبارة عن

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
قراءة إدخال جدول رمز المفتاح في النواة (رمز المسح إلى رمز المفتاح). argp يشير إلى

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

يتم تعيين keycode ليتوافق مع scancode المعطى. (89 <= scancode <= 255 فقط. لـ 1 <= scancode <= 88، keycode==scancode.) (منذ Linux 1.1.63.)
KDSETKEYCODE
كتابة إدخال جدول رمز المفتاح في النواة. argp يشير إلى struct kbkeycode. (منذ Linux 1.1.63.)
KDSIGACCEPT
يشير العملية المستدعية إلى استعدادها لقبول الإشارة argp عند توليدها عن طريق الضغط على تركيبة مفاتيح مناسبة. (1 <= argp <= NSIG). (انظر spawn_console() في linux/drivers/char/keyboard.c.)

RETURN VALUE

عند النجاح، يتم إرجاع 0 (باستثناء ما هو مشار إليه). عند الفشل، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

ERRORS

EINVAL
argp غير صالح.

STANDARDS

Linux.
