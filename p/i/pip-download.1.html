pip-download(1)

الحزمة: python-pip

التراخيص: MIT

PIP-DOWNLOAD(1) pip PIP-DOWNLOAD(1)

الاسم

pip-download - وصف أمر تحميل pip

الوصف

تحميل الحزم من:

  • PyPI (وغيرها من الفهارس) باستخدام محددات المتطلبات.
  • عناوين مشاريع VCS.
  • مجلدات المشاريع المحلية.
  • أرشيفات المصدر المحلية أو البعيدة.

يدعم pip أيضًا التحميل من "ملفات المتطلبات"، والتي توفر طريقة سهلة لتحديد بيئة كاملة ليتم تحميلها.

الاستخدام

python -m pip download [خيارات] <محدد المتطلب> [خيارات فهرس الحزمة] ...
python -m pip download [خيارات] -r <ملف المتطلبات> [خيارات فهرس الحزمة] ...
python -m pip download [خيارات] <عنوان مشروع VCS> ...
python -m pip download [خيارات] <مسار مشروع محلي> ...
python -m pip download [خيارات] <عنوان/مسار الأرشيف> ...

الخيارات

-c, --constraint <ملف>
تقييد الإصدارات باستخدام ملف القيود المحدد. يمكن استخدام هذا الخيار عدة مرات.

(متغير بيئة: PIP_CONSTRAINT)

--build-constraint <ملف>
تقييد تبعيات البناء باستخدام ملف القيود المحدد. يمكن استخدام هذا الخيار عدة مرات.

(متغير بيئة: PIP_BUILD_CONSTRAINT)

-r, --requirement <ملف>
التثبيت من ملف المتطلبات المحدد. يمكن استخدام هذا الخيار عدة مرات.

(متغير بيئة: PIP_REQUIREMENT)

--no-deps
لا تقم بتثبيت تبعيات الحزمة.

(متغير بيئة: PIP_NO_DEPS, PIP_NO_DEPENDENCIES)

--no-binary <format_control>
لا تستخدم الحزم الثنائية. يمكن توفيرها عدة مرات، وفي كل مرة تضاف إلى القيمة الموجودة. تقبل إما ":all:" لتعطيل جميع الحزم الثنائية، أو ":none:" لتفريغ المجموعة (لاحظ النقطتين)، أو اسم حزمة واحدة أو أكثر مع فاصلة بينها (بدون نقطتين). لاحظ أن بعض الحزم يصعب تجميعها وقد تفشل في التثبيت عند استخدام هذا الخيار عليها.

(متغير بيئة: PIP_NO_BINARY)

--only-binary <format_control>
لا تستخدم حزم المصدر. يمكن توفيرها عدة مرات، وفي كل مرة تضاف إلى القيمة الموجودة. تقبل إما ":all:" لتعطيل جميع حزم المصدر، أو ":none:" لتفريغ المجموعة، أو اسم حزمة واحدة أو أكثر مع فاصلة بينها. الحزم التي ليس لها توزيعات ثنائية ستفشل في التثبيت عند استخدام هذا الخيار عليها.

(متغير بيئة: PIP_ONLY_BINARY)

--prefer-binary
تفضيل الحزم الثنائية على حزم المصدر، حتى لو كانت حزم المصدر أحدث.

(متغير بيئة: PIP_PREFER_BINARY)

--src <مجلد>
المجلد الذي سيتم فيه استنساخ المشاريع القابلة للتعديل. الافتراضي في بيئة افتراضية هو "<مسار البيئة>/src". الافتراضي للتثبيتات العامة هو "<المجلد الحالي>/src".

(متغير بيئة: PIP_SRC, PIP_SOURCE, PIP_SOURCE_DIR, PIP_SOURCE_DIRECTORY)

--pre
تضمين إصدارات ما قبل الإصدار والإصدارات التطويرية. افتراضيًا، يجد pip الإصدارات المستقرة فقط.

(متغير بيئة: PIP_PRE)

--require-hashes
تتطلب تجزئة للتحقق من كل متطلب مقابلها، للتثبيتات القابلة للتكرار. يتم تضمين هذا الخيار ضمنيًا عندما يكون لدى أي حزمة في ملف المتطلبات خيار --hash.

(متغير بيئة: PIP_REQUIRE_HASHES)

--progress-bar <progress_bar>
تحديد ما إذا كان سيتم استخدام شريط التقدم. في وضع "auto"، سيقوم --quiet بقمع جميع أشرطة التقدم. [auto, on, off, raw] (الافتراضي: auto)

(متغير بيئة: PIP_PROGRESS_BAR)

--no-build-isolation
تعطيل العزل عند بناء توزيع مصدر حديث. يجب تثبيت تبعيات البناء المحددة بواسطة PEP 518 بالفعل إذا تم استخدام هذا الخيار.

(متغير بيئة: PIP_NO_BUILD_ISOLATION)

--check-build-dependencies
التحقق من تبعيات البناء.

(متغير بيئة: PIP_CHECK_BUILD_DEPENDENCIES)

--ignore-requires-python
تجاهل معلومات Requires-Python.

(متغير بيئة: PIP_IGNORE_REQUIRES_PYTHON)

-d, --dest <مجلد>
تحميل الحزم إلى <مجلد>.

(متغير بيئة: PIP_DEST, PIP_DESTINATION_DIR, PIP_DESTINATION_DIRECTORY)

--platform <platform>
استخدام العجلات المتوافقة مع <platform> فقط. الافتراضي هو منصة النظام قيد التشغيل. استخدم هذا الخيار عدة مرات لتحديد منصات متعددة تدعمها المفسر الهدف.

(متغير بيئة: PIP_PLATFORM)

--python-version <python_version>
إصدار مفسر Python المراد استخدامه للتحقق من توافق العجلات و "Requires-Python". الافتراضي هو إصدار مستمد من المفسر قيد التشغيل. يمكن تحديد الإصدار باستخدام ما يصل إلى ثلاثة أعداد صحيحة مفصولة بنقاط (على سبيل المثال، "3" لـ 3.0.0، "3.7" لـ 3.7.0، أو "3.7.3"). يمكن أيضًا إعطاء إصدار رئيسي-ثانوي كسلسلة نصية بدون نقاط (على سبيل المثال، "37" لـ 3.7.0).

(متغير بيئة: PIP_PYTHON_VERSION)

--implementation <implementation>
استخدام العجلات المتوافقة مع تنفيذ Python <implementation> فقط، على سبيل المثال 'pp'، 'jy'، 'cp'، أو 'ip'. إذا لم يتم تحديده، فإن تنفيذ المفسر الحالي هو المستخدم. استخدم 'py' لفرض العجلات غير المستقلة عن التنفيذ.

(متغير بيئة: PIP_IMPLEMENTATION)

--abi <abi>
استخدام العجلات المتوافقة مع abi Python <abi> فقط، على سبيل المثال 'pypy_41'. إذا لم يتم تحديده، فسيتم استخدام علامة abi المفسر الحالية. استخدم هذا الخيار عدة مرات لتحديد أكواد abi متعددة تدعمها المفسر الهدف. بشكل عام، ستحتاج إلى تحديد --implementation، --platform، و --python-version عند استخدام هذا الخيار.

(متغير بيئة: PIP_ABI)

--group <[path:]group>
تثبيت مجموعة تبعيات مسماة من ملف "pyproject.toml". إذا تم توفير مسار، يجب أن يكون اسم الملف "pyproject.toml". الافتراضي هو استخدام "pyproject.toml" في المجلد الحالي

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

pip-download(1) — pip documentation

NAME

pip-download - Download packages from the Python Package Index.

SYNOPSIS

pip download [options] <requirement> [...]
pip download [options] -r <requirements file> ...
pip download [options] <vcs project uri> ...
pip download [options] <archive url> ...

DESCRIPTION

Downloads packages from the Python Package Index. This command is useful for pre-downloading packages for later installation, for example, on a machine without internet access.

When installing from a requirements file, each requirement is downloaded individually.

OPTIONS

The options are the same as pip install, with the following exceptions:

--no-deps
Don't download dependencies.

(environment variable: PIP_NO_DEPS)

--dest DIR
Download the files to the specified directory. Default is the current directory.

(environment variable: PIP_DEST)

--platform PLATFORM
Only download wheels compatible with the specified platform.

(environment variable: PIP_PLATFORM)

--python-version VERSION
Only download wheels compatible with the specified Python version.

(environment variable: PIP_PYTHON_VERSION)

--implementation IMPLEMENTATION
Only download wheels compatible with the specified Python implementation.

(environment variable: PIP_IMPLEMENTATION)

--abi ABI
Only download wheels compatible with the specified ABI.

(environment variable: PIP_ABI)

--only-binary FORMAT
Don't build wheels. Only download wheels that match the given format.

(environment variable: PIP_ONLY_BINARY)

--no-binary FORMAT
Don't download wheels. Only download source distributions.

(environment variable: PIP_NO_BINARY)

--prefer-binary
Prefer downloading wheels over source distributions.

(environment variable: PIP_PREFER_BINARY)

--no-deps
Don't download dependencies.

(environment variable: PIP_NO_DEPS)

--no-clean
Don't clean up build directories.

(environment variable: PIP_NO_CLEAN)
