الاسم

pipewire-pulse-modules - وحدات PulseAudio الخاصة بـ PipeWire

الوصف

يحاكي PipeWire العديد من وحدات Pulseaudio. يدعم فقط وحداته المدمجة، ولا يمكنه تحميل وحدات خارجية مكتوبة لـ Pulseaudio.

تحميل الوحدات

يمكن تحميل الوحدات المدمجة باستخدام برامج عميل Pulseaudio، على سبيل المثال pactl load-module <module-name> <module-options>. يمكن أيضًا إضافتها إلى pipewire-pulse.conf، عادةً عن طريق ملف إسقاط في ~/.config/pipewire/pipewire-pulse.conf.d/ يحتوي على اسم الوحدة وحججها

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.cmd = [
    { cmd = "load-module" args = "module-null-sink sink_name=foo" flags = [ ] }
]

لعرض جميع الوحدات المحملة حاليًا، مع حججها:

pactl list modules

لقائمة مختصرة بالوحدات المحملة:

pactl list modules short

يمكن إلغاء تحميل الوحدات باستخدام اسم الوحدة أو رقم الفهرس:

pactl load-module <module-name> <parameters>
pactl unload-module <module-name|index#>

خيارات الوحدات الشائعة

تدعم معظم الوحدات التي تنشئ تدفقات/أجهزة الخصائص التالية:

sink_name, source_name

اسم وجهة الإخراج (أو مصدر الإدخال). الأحرف المسموح بها في الاسم هي a-z، A-Z، الأرقام، النقطة (.) والشرطة السفلية (_). يجب أن يكون الطول 1-128 حرفًا.

format

تنسيق العينة. صيغ الصوت المدعومة هي:

PCM

  • u8: عدد صحيح غير موقع بحجم 8 بت
  • aLaw: عدد صحيح مشفر A-law بحجم 8 بت
  • uLaw: عدد صحيح مشفر μ-law بحجم 8 بت
  • s16le: عدد صحيح موقع صغير النهاية (little-endian) بحجم 16 بت
  • s16be: عدد صحيح موقع كبير النهاية (big-endian) بحجم 16 بت
  • s16, s16ne: أسماء مستعارة لنهاية طبيعية لـ s16le أو s16be
  • s16re: اسم مستعار لنهاية عكسية لـ s16le أو s16be
  • float32le: فاصلة عائمة صغيرة النهاية بحجم 32 بت
  • float32be: فاصلة عائمة كبيرة النهاية بحجم 32 بت
  • float32, float32ne: أسماء مستعارة لنهاية طبيعية لـ float32le أو float32be
  • float32re: اسم مستعار لنهاية عكسية لـ float32le أو float32be
  • s32le: عدد صحيح موقع صغير النهاية بحجم 32 بت
  • s32be: عدد صحيح موقع كبير النهاية بحجم 32 بت
  • s32, s32ne: أسماء مستعارة لنهاية طبيعية لـ s32le أو s32be
  • s32re: اسم مستعار لنهاية عكسية لـ s32le أو s32be
  • s24le: عدد صحيح موقع صغير النهاية بحجم 24 بت (ملاحظة: يسمي ALSA هذا "S24_3LE")
  • s24be: عدد صحيح موقع كبير النهاية بحجم 24 بت (ملاحظة: يسمي ALSA هذا "S24_3BE")
  • s24, s24ne: أسماء مستعارة لنهاية طبيعية لـ s24le أو s24be
  • s24re: اسم مستعار لنهاية عكسية لـ s24le أو s24be
  • s24-32le: عدد صحيح موقع صغير النهاية بحجم 24 بت، معبأ في عدد صحيح بحجم 32 بت بحيث يتم تجاهل أهم 8 بت (ملاحظة: يسمي ALSA هذا "S24_LE")
  • s24-32be: عدد صحيح موقع كبير النهاية بحجم 24 بت، معبأ في عدد صحيح بحجم 32 بت بحيث يتم تجاهل أهم 8 بت (ملاحظة: يسمي ALSA هذا "S24_BE")
  • s24-32, s24-32ne: أسماء مستعارة لنهاية طبيعية لـ s24-32le أو s24-32be
  • s24-32re: اسم مستعار لنهاية عكسية لـ s24-32le أو s24-32be

صيغ الصوت المضغوط

أدناه قائمة بجميع الصيغ المضغوطة المدعومة. يستخدم الرمز في بداية كل سطر عند الحاجة إلى معرف نصي للصيغة (على سبيل المثال في ملفات التكوين أو سطر الأوامر). الصيغ التي ينتهي معرفها بـ -iec61937 يجب أن يتم تغليفها في إطارات IEC 61937، مما يجعل الصوت المضغوط يتصرف بشكل أشبه بصوت PCM العادي.

  • ac3-iec61937: Dolby Digital (DD / AC-3 / A/52)
  • eac3-iec61937: Dolby Digital Plus (DD+ / E-AC-3)
  • mpeg-iec61937: MPEG-1 أو MPEG-2 الجزء 3 (ليس MPEG-2 AAC)
  • dts-iec61937: DTS
  • mpeg2-aac-iec61937: MPEG-2 AAC (مدعوم منذ PulseAudio 4.0)
  • truehd-iec61937: Dolby TrueHD (تمت إضافته في PulseAudio 13.0، ولكنه لا يعمل حاليًا عمليًا)
  • dtshd-iec61937: DTS-HD Master Audio (تمت إضافته في PulseAudio 13.0، ولكنه لا يعمل حاليًا عمليًا)
  • pcm: PCM (ليست صيغة مضغوطة، ولكنها مدرجة هنا، لأن pcm هي واحدة من معرفات التشفير المعترف بها)
  • any: (معرف خاص للإشارة إلى أنه يمكن استخدام أي تشفير)

rate

معدل العينة.

channels

عدد قنوات الصوت.

channel_map

خريطة قناة. قائمة بأسماء قنوات مفصولة بفواصل. أسماء القنوات المعرفة حاليًا هي: left, right, mono, center, front-left, front-right, front-center, rear-center, rear-left, rear-right, lfe, subwoofer, front-left-of-center, front-right-of-center, side-left, side-right, aux0, aux1 إلى aux15, top-center, top-front-left, top-front-right, top-front-center, top-rear-left, top-rear-right, top-rear-center

sink_properties, source_properties

تعيين خصائص إضافية لوجهة الإخراج / مصدر الإدخال. على سبيل المثال، يمكنك تعيين الوصف مباشرة عند تحميل الوحدة عن طريق تعيين هذه المعلمة.

load-module module-alsa-sink sink_name=headphones sink_properties=device.description=Headphones

  • NAME

    pipewire-pulse-modules - PipeWire PulseAudio compatibility modules

DESCRIPTION

The PipeWire PulseAudio compatibility module can load additional modules that extend its functionality. These modules are loaded dynamically using the pipewire-pulse(1) daemon configuration.

LOADING MODULES

Modules can be loaded by adding lines like the following to the ~/.config/pipewire/pipewire-pulse.conf file:

context.modules = [ { name = libpipewire-module-x11-bell args = { ... } } ... ]

The name specifies the module to load and args are the module-specific arguments.

COMMON MODULE OPTIONS

All modules support the following options:

name
The name of the module to load. This is typically a shared object file name like libpipewire-module-foo.so.
args
A dictionary of arguments to pass to the module. The available arguments are module-specific.
