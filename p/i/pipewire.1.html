NAME

pipewire - a low-latency, graph based multimedia framework

SYNOPSIS

pipewire [OPTIONS...]

DESCRIPTION

PipeWire is a multimedia server and API for Linux. It provides audio and video processing and hardware access. It is designed to be low-latency and to work well on both desktop and embedded systems.

The pipewire daemon implements the core PipeWire functionality. It manages devices, nodes, and the connections between them.

OPTIONS

The following options are supported:

-h --help
Print a help message and exit.
-c config
Load additional configuration file. This option can be specified multiple times.
-r
Do not fork into the background. Stay in the foreground.
-m
Exit when the last client disconnects.
-n name
Set the instance name.
-g group
Set the GStreamer group.
-L level
Set the log level.
-I interface
Set the network interface.
-C context
Set the network context.
-S socket
Set the Unix domain socket.
-M mountpoint
Set the mountpoint.
-P pipe
Set the pipe.
-T threads
Set the number of threads.
-s size
Set the buffer size.
-p priority
Set the priority.
-l latency
Set the latency.
-d device
Set the device.
-u user
Set the user.
-G group
Set the group.
-R rate
Set the sample rate.
-F format
Set the sample format.
-c channels
Set the number of channels.
-m mode
Set the mode.
-v
Enable verbose logging.
-q
Quiet mode.
-V
Print version information and exit.

RUNTIME SETTINGS

PipeWire reads configuration files from the following directories, in order:

  • The user's configuration directory: $XDG_CONFIG_HOME/pipewire/ or ~/.config/pipewire/
  • The system-wide configuration directory: /etc/pipewire/
  • The site-specific configuration directory: /usr/local/etc/pipewire/
  • The default configuration directory: /usr/share/pipewire/

The main configuration file is typically pipewire.conf. Additional configuration files can be loaded from the pipewire.conf.d/ directories.

The configuration files specify settings for various PipeWire modules and components. The following is a partial list of configurable parameters:

context.properties

Properties for the PipeWire context. This includes settings like the instance name, log level, and default device.

context.modules

Modules to load into the PipeWire context. This can include modules for audio, video, ALSA, PulseAudio, JACK, and other devices.

stream.properties

Properties for individual streams. This includes settings like format, rate, and channels.

node.properties

Properties for individual nodes. This includes settings like name, description, and priority.

ENVIRONMENT VARIABLES

The following environment variables can be used to control PipeWire's behavior:

PIPEWIRE_DEBUG

Set the log level for PipeWire. This is a comma-separated list of subsystems to log. Common values include:
core
Log core PipeWire events.
protocol-native
Log native protocol events.
protocol-pipewire
Log PipeWire protocol events.
alsa
Log ALSA events.
pulse
Log PulseAudio events.
jack
Log JACK events.
module
Log module loading events.
device
Log device events.
all
Log all events.
For example, to enable logging for the core and ALSA subsystems, set PIPEWIRE_DEBUG=core,alsa.

PIPEWIRE_ADMIN

If set, PipeWire will run in administrative mode, which allows for more control over devices and streams.

PIPEWIRE_CONFIG_DIR

Set the directory to use for PipeWire configuration files.

PIPEWIRE_DATA_DIR

Set the directory to use for PipeWire data files.

PIPEWIRE_PLUGIN_DIR

Set the directory to use for PipeWire plugin files.

SPA_DEBUG

Set the log level for SPA plugins. This is usually controlled by the PIPEWIRE_DEBUG variable when the plugins are managed by PipeWire but some standalone tools (like spa-inspect) uses this variable.

ACP_BUILDDIR

If set, the ACP profiles are loaded from the builddir.

ACP_PATHS_DIR

ACP_PROFILES_DIR

Used to locate the ACP paths and profile directories respectively.

LADSPA_PATH

Comma separated list of directories where the ladspa plugins can be found.

LIBJACK_PATH

Directory where the jack1 or jack2 libjack.so can be found.
