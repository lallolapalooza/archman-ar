NAME

pipe2, pipe - create a pipe for interprocess communication

LIBRARY

Standard C library (libc, -lc)

SYNOPSIS

#include <fcntl.h>
#include <unistd.h>

int pipe2(int pipefd[2], int flags);
int pipe(int pipefd[2]);

DESCRIPTION

The pipe2() system call creates a pipe and places the two file descriptors of the pipe ends into the array pointed to by pipefd. The file descriptor pipefd[0] is for the read end of the pipe, and pipefd[1] is for the write end of the pipe.

The flags argument is a bitmask that can be used to specify behavior of the pipe. The following flags are recognized:

O_CLOEXEC
Set the close-on-exec flag for the new file descriptors. If this flag is set, the file descriptors will be closed in the child process after a successful fork(2). (See fcntl(2) for the F_SETFD operation).
O_DIRECT
Attempt to minimize cache effects of the transfer between user and kernel space. This may affect performance.
O_NONBLOCK
Do not block on pipe full or empty. See fcntl(2) for the effect of the O_NONBLOCK flag.

The pipe() function is equivalent to calling pipe2(pipefd, 0).

Data written to the write end (pipefd[1]) can be read back from the read end (pipefd[0]) in the same order in which it was written.

The pipe is implemented as a buffer. If the buffer is full, a write(2) will block until there is enough space in the buffer. If the buffer is empty, a read(2) will block until there is data in the buffer.

If the write end of the pipe is closed (pipefd[1]), a read(2) on the read end (pipefd[0]) will return 0 (end-of-file) after all data in the pipe has been read.

If the read end of the pipe is closed (pipefd[0]), a write(2) on the write end (pipefd[1]) will fail with the error EPIPE. If the MSG_NOSIGNAL flag is not set for the write, then the signal SIGPIPE will be sent to the calling process.

The maximum number of bytes that can be written atomically to a pipe is determined by the system limit PIPE_BUF (see <limits.h>). Writes of less than or equal to PIPE_BUF bytes are guaranteed to be atomic; that is, the data will be written in a single, uninterrupted operation. This means that if multiple processes (or threads) are writing to the same pipe, a write of size less than or equal to PIPE_BUF will not be interleaved with writes from other processes (or threads).

The size of the pipe buffer is not specified by any standard, but is typically a small number of kilobytes.

The pipe is created with read and write file descriptors that are the same as the calling process. If the O_CLOEXEC flag is not specified, the file descriptors will be inherited by child processes created by fork(2).

RETURN VALUE

On success, pipe2() returns 0, and the file descriptors for the pipe ends are stored in the array pipefd. On failure, -1 is returned, and errno is set appropriately.

pipe() is equivalent to pipe2(pipefd, 0), so it also returns 0 on success and -1 on failure.

ERRORS

EACCES
Could not create a pipe. This might happen due to resource limitations.
EMFILE
The current user has reached the maximum number of open file descriptors.
ENFILE
The system limit on the total number of open files has been reached.
ENOMEM
Not enough memory to allocate pipe buffers.
EINVAL
flags contains an invalid value.

VERSIONS

The pipe2() system call was introduced in Linux kernel 2.6.27.

STANDARDS

The pipe() function is specified by POSIX.1-2008.

The pipe2() function is a Linux extension.

HISTORY

pipe() has been available since early versions of Unix.

pipe2() was added in Linux kernel 2.6.27.

EXAMPLES

The following example demonstrates the use of pipe2() to create a pipe and write data to it from a child process.

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/wait.h>
#include <unistd.h>

int
main(int argc, char *argv[])
{
    int pipefd[2];
    pid_t cpid;

    if (argc != 2) {
        fprintf(stderr, "Usage: %s <string>\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    if (pipe2(pipefd, 0) == -1)  /* Create a pipe */
        err(EXIT_FAILURE, "pipe2");

    cpid = fork();
    if (cpid == -1) {
        err(EXIT_FAILURE, "fork");
    }

    if (cpid == 0) {    /* Child process */
        /* Close the unused read end */
        if (close(pipefd[0]) == -1)
            err(EXIT_FAILURE, "close read end");

        /* Write the argument to the pipe */
        if (write(pipefd[1], argv[1], strlen(argv[1])) != strlen(argv[1]))
            err(EXIT_FAILURE, "write");

        /* Close the write end, signaling EOF to the reader */
        if (close(pipefd[1]) == -1)
            err(EXIT_FAILURE, "close write end");

        exit(EXIT_SUCCESS);
    } else {            /* Parent process */
        char buf[1024];
        ssize_t numRead;

        /* Close the unused write end */
        if (close(pipefd[1]) == -1)
            err(EXIT_FAILURE, "close write end");

        /* Read from the pipe */
        while ((numRead = read(pipefd[0], buf, sizeof(buf) - 1)) > 0) {
            buf[numRead] = '\0';  /* Null-terminate the buffer */
            printf("Received: %s", buf);
        }
        if (numRead == -1)
            err(EXIT_FAILURE, "read");

        /* Close the read end */
        if (close(pipefd[0]) == -1)
            err(EXIT_FAILURE, "close read end");

        /* Wait for the child process to finish */
        if (wait(NULL) == -1)
            err(EXIT_FAILURE, "wait");

        exit(EXIT_SUCCESS);
    }
}

الاسم

pipe2, pipe - إنشاء قناة (pipe) للاتصال بين العمليات

المكتبة

مكتبة C القياسية (libc, -lc)

الملخص

#include <fcntl.h>
#include <unistd.h>

int pipe2(int pipefd[2], int flags);
int pipe(int pipefd[2]);

الوصف

يقوم استدعاء النظام pipe2() بإنشاء قناة ويضع واصفي الملفين لطرفي القناة في المصفوفة التي يشير إليها pipefd. واصف الملف pipefd[0] هو لطرف القراءة للقناة، و pipefd[1] هو لطرف الكتابة للقناة.

الوسيط flags هو قناع بت يمكن استخدامه لتحديد سلوك القناة. يتم التعرف على الأعلام التالية:

O_CLOEXEC
تعيين علامة الإغلاق عند التنفيذ لواصفي الملفات الجدد. إذا تم تعيين هذا العلم، فسيتم إغلاق واصفات الملفات في العملية الفرعية بعد نجاح fork(2). (انظر fcntl(2) لعملية F_SETFD).
O_DIRECT
محاولة تقليل تأثيرات التخزين المؤقت للنقل بين مساحة المستخدم والنواة. قد يؤثر هذا على الأداء.
O_NONBLOCK
لا تقم بالحظر عند امتلاء القناة أو فراغها. انظر fcntl(2) لتأثير العلم O_NONBLOCK.

الدالة pipe() مكافئة لاستدعاء pipe2(pipefd, 0).

يمكن قراءة البيانات المكتوبة إلى طرف الكتابة (pipefd[1]) مرة أخرى من طرف القراءة (pipefd[0]) بنفس الترتيب الذي تمت الكتابة به.

يتم تنفيذ القناة كـ مخزن مؤقت. إذا كان المخزن المؤقت ممتلئًا، فإن عملية write(2) ستحظر حتى يكون هناك مساحة كافية في المخزن المؤقت. إذا كان المخزن المؤقت فارغًا، فإن عملية read(2) ستحظر حتى تكون هناك بيانات في المخزن المؤقت.

إذا تم إغلاق طرف الكتابة للقناة (pipefd[1])، فإن عملية read(2) على طرف القراءة (pipefd[0]) ستعيد 0 (نهاية الملف) بعد قراءة جميع البيانات في القناة.

إذا تم إغلاق طرف القراءة للقناة (pipefd[0])، فإن عملية write(2) على طرف الكتابة (pipefd[1]) ستفشل مع الخطأ EPIPE. إذا لم يتم تعيين العلم MSG_NOSIGNAL لعملية الكتابة، فسيتم إرسال الإشارة SIGPIPE إلى العملية المستدعية.

يتم تحديد الحد الأقصى لعدد البايتات التي يمكن كتابتها بشكل ذري إلى قناة بواسطة حد النظام PIPE_BUF (انظر <limits.h>). تعتبر عمليات الكتابة التي تقل عن أو تساوي PIPE_BUF بايت عملية ذرية؛ أي، سيتم كتابة البيانات في عملية واحدة غير متقطعة. هذا يعني أنه إذا كانت عمليات متعددة (أو سلاسل محادثة) تكتب إلى نفس القناة، فإن عملية كتابة بحجم يساوي أو أقل من PIPE_BUF لن تتداخل مع عمليات الكتابة من عمليات (أو سلاسل محادثة) أخرى.

حجم مخزن القناة المؤقت غير محدد بأي معيار، ولكنه عادة ما يكون عددًا صغيرًا من الكيلوبايتات.

يتم إنشاء القناة مع واصفي ملفات القراءة والكتابة اللذين هما نفس العملية المستدعية. إذا لم يتم تحديد العلم O_CLOEXEC، فسيتم توريث واصفي الملفات من قبل العمليات الفرعية التي تم إنشاؤها بواسطة fork(2).

قيمة الإرجاع

عند النجاح، تعيد pipe2() القيمة 0، ويتم تخزين واصفي الملفات لطرفي القناة في المصفوفة pipefd. عند الفشل، يتم إرجاع -1، ويتم تعيين errno بشكل مناسب.

pipe() مكافئة لـ pipe2(pipefd, 0)، لذا فهي تعيد أيضًا 0 عند النجاح و -1 عند الفشل.

الأخطاء

EACCES
لم يتمكن من إنشاء قناة. قد يحدث هذا بسبب قيود الموارد.
EMFILE
وصل المستخدم الحالي إلى الحد الأقصى لعدد واصفات الملفات المفتوحة.
ENFILE
تم الوصول إلى حد النظام للعدد الإجمالي للملفات المفتوحة.
ENOMEM
لا توجد ذاكرة كافية لتخصيص مخازن القناة المؤقتة.
EINVAL
يحتوي flags على قيمة غير صالحة.

أمثلة

يوضح المثال التالي استخدام pipe2() لإنشاء قناة وكتابة بيانات إليها من عملية فرعية.

#include <err.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <sys/wait.h>
#include <unistd.h>

int
main(int argc, char *argv[])
{
    int pipefd[2];
    pid_t cpid;

    if (argc != 2) {
        fprintf(stderr, "Usage: %s <string>\n", argv[0]);
        exit(EXIT_FAILURE);
    }

    if (pipe2(pipefd, 0) == -1)  /* Create a pipe */
        err(EXIT_FAILURE, "pipe2");

    cpid = fork();
    if (cpid == -1) {
        err(EXIT_FAILURE, "fork");
    }

    if (cpid == 0) {    /* Child process */
        /* Close the unused read end */
        if (close(pipefd[0]) == -1)
            err(EXIT_FAILURE, "close read end");

        /* Write the argument to the pipe */
        if (write(pipefd[1], argv[1], strlen(argv[1])) != strlen(argv[1]))
            err(EXIT_FAILURE, "write");

        /* Close the write end, signaling EOF to the reader */
        if (close(pipefd[1]) == -1)
            err(EXIT_FAILURE, "close write end");

        exit(EXIT_SUCCESS);
    } else {            /* Parent process */
        char buf[1024];
        ssize_t numRead;

        /* Close the unused write end */
        if (close(pipefd[1]) == -1)
            err(EXIT_FAILURE, "close write end");

        /* Read from the pipe */
        while ((numRead = read(pipefd[0], buf, sizeof(buf) - 1)) > 0) {
            buf[numRead] = '\0';  /* Null-terminate the buffer */
            printf("Received: %s", buf);
        }
        if (numRead == -1)
            err(EXIT_FAILURE, "read");

        /* Close the read end */
        if (close(pipefd[0]) == -1)
            err(EXIT_FAILURE, "close read end");

        /* Wait for the child process to finish */
        if (wait(NULL) == -1)
            err(EXIT_FAILURE, "wait");

        exit(EXIT_SUCCESS);
    }
}
