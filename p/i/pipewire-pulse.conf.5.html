الوصف

تكوين لـ daemon PipeWire المتوافق مع PulseAudio.

صيغة ملف التكوين ومنطق البحث هما نفس ما هو مستخدم في pipewire.conf(5).

يمكن استخدام ملفات التكوين الإضافية pipewire-pulse.conf.d/*.conf، وهي موصى بها. راجع pipewire.conf(5).

أقسام ملف التكوين

stream.properties

قاموس. تقوم هذه الخصائص بتكوين خصائص خادم PipeWire Pulseaudio.

stream.rules

قاموس. تقوم هذه الخصائص بتكوين خصائص خادم PipeWire Pulseaudio.

pulse.properties

قاموس. تقوم هذه الخصائص بتكوين خصائص خادم PipeWire Pulseaudio.

pulse.cmd

مصفوفة من القواميس. مجموعة من الأوامر التي سيتم تنفيذها عند بدء التشغيل.

pulse.rules

مصفوفة من القواميس. مجموعة من قواعد المطابقة والإجراءات التي سيتم تطبيقها على العملاء.

راجع libpipewire-module-protocol-pulse(7) للحصول على وصف تفصيلي.

بالإضافة إلى ذلك، يمكن أيضًا تحديد أقسام تكوين سياق PipeWire، راجع pipewire.conf(5).

خصائص التدفق

يحتوي قسم stream.properties على خصائص التدفقات التي ينشئها خادم pipewire-pulse.

الخيارات المتاحة موصوفة في pipewire-client.conf(5) stream.properties.

بعض هذه الخصائص تتوافق مع إدخالات تكوين PulseAudio /etc/pulse/default.pa على النحو التالي:

PulseAudio PipeWire Notes remixing-use-all-sink-channels channelmix.upmix remixing-produce-lfe channelmix.lfe-cutoff اضبط على > 0 لتفعيل remixing-consume-lfe channelmix.mix-lfe lfe-crossover-freq channelmix.lfe-cutoff

مثال

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
stream.properties = {
    #node.latency = 1024/48000
    #node.autoconnect = true
    #resample.disable = false
    #resample.quality = 4
    #monitor.channel-volumes = false
    #channelmix.disable = false
    #channelmix.min-volume = 0.0
    #channelmix.max-volume = 10.0
    #channelmix.normalize = false
    #channelmix.mix-lfe = true
    #channelmix.upmix = true
    #channelmix.upmix-method = psd  # none, simple
    #channelmix.lfe-cutoff = 150.0
    #channelmix.fc-cutoff = 12000.0
    #channelmix.rear-delay = 12.0
    #channelmix.stereo-widen = 0.0
    #channelmix.hilbert-taps = 0
    #dither.noise = 0
    #dither.method = none # rectangular, triangular, triangular-hf, wannamaker3, shaped5
    #debug.wav-path = ""
}

قواعد التدفق

يعمل قسم stream.rules بنفس الطريقة التي يعمل بها pipewire-client.conf(5) stream.rules.

خصائص PulseAudio

لقسم pulse.properties، راجع libpipewire-module-protocol-pulse(7) للخيارات المتاحة.

قواعد PulseAudio

لكل عميل، يمكن كتابة مجموعة من القواعد في قسم pulse.rules لتكوين إعدادات خاصة بالعميل أو لفرض بعض التكوينات الخاصة بالتدفق في Pulse.

المظهر العام لهذا القسم هو كما يلي ويتبع تخطيط قواعد المطابقة، راجع pipewire(1).

راجع libpipewire-module-protocol-pulse(7) للخيارات المتاحة.

مثال

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.rules = [
    {
        # skype does not want to use devices that don't have an S16 sample format.
        matches = [
             { application.process.binary = "teams" }
             { application.process.binary = "teams-insiders" }
             { application.process.binary = "skypeforlinux" }
        ]
        actions = { quirks = [ force-s16-info ] }
    }
    {
        # speech dispatcher asks for too small latency and then underruns.
        matches = [ { application.name = "~speech-dispatcher*" } ]
        actions = {
            update-props = {
                pulse.min.req          = 1024/48000     # 21ms
                pulse.min.quantum      = 1024/48000     # 21ms
            }
        }
    }
]

أوامر PulseAudio

كجزء من إجراء بدء تشغيل الخادم، يمكنك تنفيذ بعض الأوامر الإضافية مع قسم pulse.cmd في pipewire-pulse.conf.

# ~/.config/pipewire/pipewire-pulse.conf.d/custom.conf
pulse.cmd = [
    { cmd = "load-module" args = "module-always-sink" flags = [ ] }
    { cmd = "load-module" args = "module-switch-on-connect" }
    { cmd = "load-module" args = "module-gsettings" flags = [ "nofail" ] }
]
...

يمكن أيضًا تشغيل أوامر إضافية عبر قسم context.exec، راجع pipewire.conf(5).

الأوامر المدعومة:

load-module

تحميل وحدة Pulseaudio المحددة عند بدء التشغيل، كما لو كان ذلك باستخدام pactl(1) لتحميل الوحدة.

وحدات PulseAudio

لمحتويات قسم pulse.modules، راجع pipewire-pulse-modules(7).
