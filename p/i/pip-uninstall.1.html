pip-uninstall(1)

الحزمة: python-pip

التراخيص: MIT

PIP-UNINSTALL(1) pip PIP-UNINSTALL(1)

الاسم

pip-uninstall - وصف أمر إلغاء تثبيت pip

الوصف

إلغاء تثبيت الحزم.

يمكن لـ pip إلغاء تثبيت معظم الحزم المثبتة. الاستثناءات المعروفة هي:

  • حزم distutils النقية المثبتة باستخدام python setup.py install، والتي لا تترك أي بيانات تعريف لتحديد الملفات التي تم تثبيتها.
  • مغلفات البرامج النصية المثبتة باستخدام python setup.py develop.

الاستخدام

python -m pip uninstall [options] <package> ...
python -m pip uninstall [options] -r <requirements file> ...

الخيارات

-r, --requirement <file>
إلغاء تثبيت جميع الحزم المدرجة في ملف المتطلبات المحدد. يمكن استخدام هذا الخيار عدة مرات.

(متغير بيئة: PIP_REQUIREMENT)

-y, --yes
لا تسأل عن تأكيد عمليات حذف إلغاء التثبيت.

(متغير بيئة: PIP_YES)

--root-user-action <root_user_action>
الإجراء في حالة تشغيل pip كمستخدم جذر [تحذير، تجاهل] (الافتراضي: تحذير)

(متغير بيئة: PIP_ROOT_USER_ACTION)

--break-system-packages
السماح لـ pip بتعديل تثبيت Python مُدار خارجيًا

(متغير بيئة: PIP_BREAK_SYSTEM_PACKAGES)
