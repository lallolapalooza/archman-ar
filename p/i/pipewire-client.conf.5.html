NAME

pipewire-client.conf - PipeWire client configuration

DESCRIPTION

The pipewire-client.conf file is used to configure the behaviour of PipeWire clients.

SYNOPSIS

/etc/pipewire/client.conf

~/.config/pipewire/client.conf

DESCRIPTION

The pipewire-client.conf file allows users to customize how PipeWire clients behave. This includes settings for stream properties, rules, ALSA client properties, and ALSA client rules.

CONFIGURATION FILE SECTIONS

The configuration file is divided into several sections:

  • context.properties: Global properties for the PipeWire context.
  • context.modules: Loadable modules for the PipeWire context.
  • stream.properties: Default properties for all audio streams.
  • stream.rules: Rules for managing audio streams.
  • alsa.client.properties: Default properties for ALSA clients.
  • alsa.client.rules: Rules for managing ALSA clients.
  • session.suspend-timeout-seconds: Timeout for suspending inactive streams.

STREAM PROPERTIES

This section defines default properties for audio streams. Example properties include:

  • audio.channels: Number of audio channels.
  • audio.position: Speaker positions (e.g., FL, FR).
  • audio.rate: Audio sample rate.

STREAM RULES

This section defines rules for stream management. Rules can be used to match streams based on their properties and apply specific actions, such as setting priorities or routing them to specific devices.

ALSA CLIENT PROPERTIES

This section defines default properties for ALSA clients. These properties can influence how ALSA devices are represented and managed by PipeWire.

ALSA CLIENT RULES

This section defines rules for ALSA client management. Similar to stream rules, these can be used to match ALSA clients and apply specific configurations.

ENVIRONMENT VARIABLES

The following environment variables can affect the behavior of PipeWire clients:

  • PIPEWIRE_CONFIG_DIR: Specifies the directory for configuration files.
  • PIPEWIRE_RUNTIME_DIR: Specifies the directory for runtime files.
