ioctl_kd(2) دليل استدعاءات النظام ioctl_kd(2)

الاسم

ioctl_kd - استدعاءات ioctls لمحطة طرفية ووحدات تحكم افتراضية

الملخص

#include <linux/kd.h>  /* تعريف ثوابت العمليات */
#include <sys/ioctl.h>
int ioctl(int fd, unsigned long op, void *argp);

الوصف

عمليات ioctl(2) التالية الخاصة بلينكس مدعومة لمحطات طرفية ووحدات تحكم افتراضية.

KDGETLED
الحصول على حالة مصابيح LED. argp يشير إلى char. يتم تعيين البتات الثلاثة السفلية لـ *argp إلى حالة مصابيح LED، على النحو التالي:
LED_CAP 0x04 مصباح قفل المفاتيح (caps lock led)
LED_NUM 0x02 مصباح قفل الأرقام (num lock led)
LED_SCR 0x01 مصباح قفل التمرير (scroll lock led)
KDSETLED
تعيين مصابيح LED. يتم تعيين مصابيح LED لتتوافق مع البتات الثلاثة السفلية للعدد الصحيح غير الموقّع في argp. ومع ذلك، إذا تم تعيين بت ذي ترتيب أعلى، فإن مصابيح LED تعود إلى وضعها الطبيعي: عرض حالة وظائف لوحة المفاتيح مثل قفل المفاتيح، قفل الأرقام، وقفل التمرير.

قبل لينكس 1.1.54، كانت مصابيح LED تعكس فقط حالة علامات لوحة المفاتيح المقابلة، وكان KDGETLED/KDSETLED يغيران أيضًا علامات لوحة المفاتيح. منذ لينكس 1.1.54، يمكن جعل مصابيح LED تعرض معلومات عشوائية، ولكن افتراضيًا تعرض علامات لوحة المفاتيح. تستخدم استدعاءات ioctls التالية للوصول إلى علامات لوحة المفاتيح.

KDGKBLED
الحصول على علامات لوحة المفاتيح لقفل المفاتيح، قفل الأرقام، قفل التمرير (ليست مصابيح). argp يشير إلى حرف يتم تعيين حالة العلامة له. تحصل البتات ذات الترتيب المنخفض الثلاثة (قناع 0x7) على حالة العلامة الحالية، وتحصل البتات ذات الترتيب المنخفض من الرباعية التالية (قناع 0x70) على حالة العلامة الافتراضية. (منذ لينكس 1.1.54.)
KDSKBLED
تعيين علامات لوحة المفاتيح لقفل المفاتيح، قفل الأرقام، قفل التمرير (ليست مصابيح). argp هو عدد صحيح غير موقّع يحتوي على حالة العلامة المطلوبة. البتات ذات الترتيب المنخفض الثلاثة (قناع 0x7) تحتوي على حالة العلامة، والبتات ذات الترتيب المنخفض من الرباعية التالية (قناع 0x70) تحتوي على حالة العلامة الافتراضية. (منذ لينكس 1.1.54.)
KDGKBTYPE
الحصول على نوع لوحة المفاتيح. يعيد هذا القيمة KB_101، المعرّفة بـ 0x02.
KDADDIO
إضافة منفذ إدخال/إخراج كمنفذ صالح. مكافئ لـ ioperm(arg,1,1).
KDDELIO
حذف منفذ إدخال/إخراج كمنفذ صالح. مكافئ لـ ioperm(arg,1,0).
KDENABIO
تمكين الإدخال/الإخراج للوحة الفيديو. مكافئ لـ ioperm(0x3b4, 0x3df-0x3b4+1, 1).
KDDISABIO
تعطيل الإدخال/الإخراج للوحة الفيديو. مكافئ لـ ioperm(0x3b4, 0x3df-0x3b4+1, 0).
KDSETMODE
تعيين وضع النص/الرسومات. argp هو عدد صحيح غير موقّع يحتوي على أحد الخيارات التالية:
KD_TEXT 0x00
KD_GRAPHICS 0x01
KDGETMODE
الحصول على وضع النص/الرسومات. argp يشير إلى int يتم تعيينه إلى أحد القيم الموضحة أعلاه لـ KDSETMODE.
KDMKTONE
إنشاء نغمة بطول محدد. تحدد الـ 16 بت السفلية للعدد الصحيح غير الموقّع في argp الفترة بالدورات الزمنية، وتحدد الـ 16 بت العلوية المدة بالمللي ثانية. إذا كانت المدة صفرًا، يتم إيقاف الصوت. يعود التحكم فورًا. على سبيل المثال، argp = (125<<16) + 0x637 ستحدد التنغيم المرتبط عادةً بـ ctrl-G. (وبالتالي، منذ لينكس 0.99pl1؛ معطل في لينكس 2.1.49-50.)
KIOCSOUND
بدء أو إيقاف توليد الصوت. تحدد الـ 16 بت السفلية لـ argp الفترة بالدورات الزمنية (أي، argp = 1193180/frequency). argp = 0 يوقف الصوت. في كلتا الحالتين، يعود التحكم فورًا.
GIO_CMAP
الحصول على خريطة الألوان الافتراضية الحالية من النواة. argp يشير إلى مصفوفة بحجم 48 بايت. (منذ لينكس 1.3.3.)
PIO_CMAP
تغيير خريطة الألوان الافتراضية للنص. argp يشير إلى مصفوفة بحجم 48 بايت تحتوي، بالترتيب، على قيم الأحمر والأخضر والأزرق للألوان الـ 16 المتاحة للشاشة: 0 مطفأ، و 255 كامل الشدة. الألوان الافتراضية هي، بالترتيب: أسود، أحمر داكن، أخضر داكن، بني، أزرق داكن، بنفسجي داكن، سماوي داكن، رمادي فاتح، رمادي داكن، أحمر ساطع، أخضر ساطع، أصفر، أزرق ساطع، بنفسجي ساطع، سماوي ساطع، وأبيض. (منذ لينكس 1.3.3.)
GIO_FONT
الحصول على خط الشاشة المكون من 256 حرفًا في شكل موسع. argp يشير إلى مصفوفة بحجم 8192 بايت. يفشل مع رمز الخطأ EINVAL إذا كان الخط المحمّل حاليًا خطًا مكونًا من 512 حرفًا، أو إذا كانت الوحدة الطرفية ليست في وضع النص.
GIO_FONTX
الحصول على خط الشاشة والمعلومات المرتبطة به. argp يشير إلى struct consolefontdesc (انظر PIO_FONTX). عند الاستدعاء، يجب تعيين الحقل charcount إلى الحد الأقصى لعدد الأحرف التي ستتناسب مع المخزن المؤقت المشار إليه بواسطة chardata. عند العودة، يتم ملء charcount و charheight بالبيانات المقابلة للخط المحمّل حاليًا، وتحتوي مصفوفة chardata على بيانات الخط إذا كانت القيمة الأولية لـ charcount تشير إلى مساحة كافية متاحة؛ وإلا، يتم ترك المخزن المؤقت دون تغيير ويتم تعيين errno إلى ENOMEM. (منذ لينكس 1.3.1.)
PIO_FONT
تعيين خط الشاشة المكون من 256 حرفًا. تحميل الخط في مولد أحرف EGA/VGA. argp يشير إلى خريطة بحجم 8192 بايت، مع 32 بايت لكل حرف. يتم استخدام أول N منها فقط لخط 8xN (0 < N <= 32). يبطل هذا الاستدعاء أيضًا تعيين Unicode.
PIO_FONTX
تعيين خط الشاشة ومعلومات التصيير المرتبطة به. argp يشير إلى

struct consolefontdesc {
    unsigned short charcount;  /* الأحرف في الخط
                                  (256 أو 512) */
    unsigned short charheight; /* خطوط المسح لكل
                                  حرف (1-32) */
    char          *chardata;   /* بيانات الخط في
                                  شكل موسع */
};

إذا لزم الأمر، سيتم تغيير حجم الشاشة بشكل مناسب، وسيتم إرسال SIGWINCH إلى العمليات المناسبة. يبطل هذا الاستدعاء أيضًا تعيين Unicode. (منذ لينكس 1.3.1.)
PIO_FONTRESET
إعادة تعيين خط الشاشة، والحجم، وتعليم Unicode إلى الإعدادات الافتراضية عند الإقلاع. argp غير مستخدم، ولكن يجب تعيينه إلى NULL لضمان التوافق مع الإصدارات المستقبلية من لينكس. (منذ لينكس 1.3.28.)
GIO_SCRNMAP
الحصول على خريطة الشاشة من النواة. argp يشير إلى مساحة بحجم E_TABSZ، والتي يتم تحميلها بمواقع الخطوط المستخدمة لعرض كل حرف. من المحتمل أن يعيد هذا الاستدعاء معلومات غير مفيدة إذا كان الخط المحمّل حاليًا أكثر من 256 حرفًا.
GIO_UNISCRNMAP
الحصول على خريطة شاشة Unicode كاملة من النواة. argp يشير إلى مساحة بحجم E_TABSZ*sizeof(unsigned short)، والتي يتم تحميلها بـ Unicodes التي تمثلها كل حرف. يتم استخدام مجموعة خاصة من Unicodes، تبدأ من U+F000، لتمثيل تعيينات "الوصول المباشر إلى الخط". (منذ لينكس 1.3.1.)
PIO_SCRNMAP
تحميل الجدول "القابل للتعريف من قبل المستخدم" (الرابع) في النواة والذي يقوم بتعيين البايتات إلى رموز شاشة الوحدة الطرفية. argp يشير إلى مساحة بحجم E_TABSZ.

Section 2

NAME

PIO_UNISCRNMAP, GIO_UNIMAP, PIO_UNIMAP, PIO_UNIMAPCLR, KDGKBMODE, KDSKBMODE, KDGKBMETA, KDSKBMETA, KDGKBENT, KDSKBENT, KDGKBSENT, KDSKBSENT, KDGKBDIACR, KDGETKEYCODE, KDSETKEYCODE, KDSIGACCEPT - keyboard and console ioctl requests

SYNOPSIS

#include <linux/kd.h>

int ioctl(int fd, int request, ...);

DESCRIPTION

These requests interact with the kernel's keyboard and console handling.

PIO_UNISCRNMAP
Loads the "user definable" (fourth) table in the kernel which maps bytes into Unicodes, which are then translated into screen symbols according to the currently loaded Unicode-to-font map. Special Unicodes starting at U+F000 can be used to map directly to the font symbols. (Since Linux 1.3.1.)
GIO_UNIMAP
Get Unicode-to-font mapping from kernel. argp points to a

struct unimapdesc {
    unsigned short  entry_ct;
    struct unipair *entries;
};

where entries points to an array of

struct unipair {
    unsigned short unicode;
    unsigned short fontpos;
};

(Since Linux 1.1.92.)
PIO_UNIMAP
Put unicode-to-font mapping in kernel. argp points to a struct unimapdesc. (Since Linux 1.1.92)
PIO_UNIMAPCLR
Clear table, possibly advise hash algorithm. argp points to a

struct unimapinit {
    unsigned short advised_hashsize;  /* 0 if no opinion */
    unsigned short advised_hashstep;  /* 0 if no opinion */
    unsigned short advised_hashlevel; /* 0 if no opinion */
};

(Since Linux 1.1.92.)
KDGKBMODE
Gets current keyboard mode. argp points to a long which is set to one of these:
K_RAW 0x00 /* Raw (scancode) mode */
K_XLATE 0x01 /* Translate keycodes using keymap */
K_MEDIUMRAW 0x02 /* Medium raw (scancode) mode */
K_UNICODE 0x03 /* Unicode mode */
K_OFF 0x04 /* Disabled mode (since Linux 2.6.39) */
KDSKBMODE
Sets current keyboard mode. argp is a long equal to one of the values shown for KDGKBMODE.
KDGKBMETA
Gets meta key handling mode. argp points to a long which is set to one of these:
K_METABIT 0x03 set high order bit
K_ESCPREFIX 0x04 escape prefix
KDSKBMETA
Sets meta key handling mode. argp is a long equal to one of the values shown above for KDGKBMETA.
KDGKBENT
Gets one entry in key translation table (keycode to action code). argp points to a

struct kbentry {
    unsigned char  kb_table;
    unsigned char  kb_index;
    unsigned short kb_value;
};

with the first two members filled in: kb_table selects the key table (0 <= kb_table < MAX_NR_KEYMAPS), and kb_index is the keycode (0 <= kb_index < NR_KEYS). kb_value is set to the corresponding action code, or K_HOLE if there is no such key, or K_NOSUCHMAP if kb_table is invalid.
KDSKBENT
Sets one entry in translation table. argp points to a struct kbentry.
KDGKBSENT
Gets one function key string. argp points to a

struct kbsentry {
    unsigned char kb_func;
    unsigned char kb_string[512];
};

kb_string is set to the (null-terminated) string corresponding to the kb_functh function key action code.
KDSKBSENT
Sets one function key string entry. argp points to a struct kbsentry.
KDGKBDIACR
Read kernel accent table. argp points to a

struct kbdiacrs {
    unsigned int   kb_cnt;
    struct kbdiacr kbdiacr[256];
};

where kb_cnt is the number of entries in the array, each of which is a

struct kbdiacr {
    unsigned char diacr;
    unsigned char base;
    unsigned char result;
};

KDGETKEYCODE
Read kernel keycode table entry (scan code to keycode). argp points to a

struct kbkeycode {
    unsigned int scancode;
    unsigned int keycode;
};

keycode is set to correspond to the given scancode. (89 <= scancode <= 255 only. For 1 <= scancode <= 88, keycode==scancode.) (Since Linux 1.1.63.)
KDSETKEYCODE
Write kernel keycode table entry. argp points to a struct kbkeycode. (Since Linux 1.1.63.)
KDSIGACCEPT
The calling process indicates its willingness to accept the signal argp when it is generated by pressing an appropriate key combination. (1 <= argp <= NSIG). (See spawn_console() in linux/drivers/char/keyboard.c.)

RETURN VALUE

On success, 0 is returned (except where indicated). On failure, -1 is returned, and errno is set to indicate the error.

ERRORS

EINVAL
argp is invalid.

STANDARDS

Linux.
