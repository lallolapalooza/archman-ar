الوصف

تكوين عملاء PipeWire JACK.

تنسيق ملف التكوين ومنطق البحث هو نفس منطق ملف pipewire.conf(5).

يمكن استخدام ملفات التكوين الإضافية jack.conf.d/*.conf، وهي موصى بها. انظر pipewire.conf(5).

أقسام ملف التكوين

jack.properties

تكوين عميل JACK.

jack.rules

قواعد مطابقة عميل JACK.

بالإضافة إلى ذلك، يمكن أيضًا تحديد أقسام تكوين سياق PipeWire، انظر pipewire.conf(5).

خصائص JACK

يمكن أن يحتوي ملف التكوين على قسم إضافي خاص بـ JACK يسمى jack.properties كالتالي:

# ~/.config/pipewire/jack.conf.d/custom.conf
jack.properties = {
    #rt.prio             = 88
    #node.latency        = 1024/48000
    #node.lock-quantum   = true
    #node.force-quantum  = 0
    #jack.show-monitor   = true
    #jack.merge-monitor  = true
    #jack.show-midi      = true
    #jack.short-name     = false
    #jack.filter-name    = false
    #jack.filter-char    = " "
    #
    # allow:           لا تقيد طلبات الاتصال الذاتي
    # fail-external:   فشل طلبات الاتصال الذاتي بالمنافذ الخارجية فقط
    # ignore-external: تجاهل طلبات الاتصال الذاتي بالمنافذ الخارجية فقط
    # fail-all:        فشل جميع طلبات الاتصال الذاتي
    # ignore-all:      تجاهل جميع طلبات الاتصال الذاتي
    #jack.self-connect-mode  = allow
    #jack.locked-process     = true
    #jack.default-as-system  = false
    #jack.fix-midi-events    = true
    #jack.global-buffer-size = false
    #jack.passive-links      = false
    #jack.max-client-ports   = 768
    #jack.fill-aliases       = false
    #jack.writable-input     = false
    #jack.flag-midi2         = false
}

راجع stream.properties في pipewire-client.conf(5) للحصول على شرح لخصائص العقد العامة.

من الممكن أيضًا الحصول على إعدادات لكل عميل، انظر قواعد المطابقة أدناه.

rt.prio

لتقييد الأولوية الحقيقية التي يمكن لعملاء jack اكتسابها.

node.latency

لفرض حجم ذاكرة تخزين مؤقت أدنى محدد لتطبيقات JACK، قم بتكوين: 
node.latency = 1024/48000


يقوم هذا بتكوين حجم ذاكرة تخزين مؤقت قدره 1024 عينة عند 48 كيلوهرتز. إذا كانت الرسم البياني قيد التشغيل بمعدل عينات مختلف، فسيتم تعديل حجم الذاكرة المؤقتة وفقًا لذلك.

node.lock-quantum

للتأكد من عدم حدوث تغييرات كمية تلقائية أثناء تشغيل تطبيقات JACK، قم بتكوين: 
node.lock-quantum = true


يمكن بعد ذلك تغيير الكمية فقط عن طريق البيانات الوصفية أو عند بدء تشغيل تطبيق باستخدام node.force-quantum. ستتمكن تطبيقات JACK أيضًا من استخدام jack_set_buffersize() لتجاوز الكمية.

node.force-quantum

لفرض الكمية على قيمة معينة وتجنب التغييرات عليها: 
node.force-quantum = 1024


يمكن بعد ذلك تغيير الكمية فقط عن طريق البيانات الوصفية أو عند بدء تشغيل تطبيق باستخدام node.force-quantum (أو تطبيقات JACK التي تستخدم jack_set_buffersize() لتجاوز الكمية).

jack.show-monitor

عرض عميل المراقبة ومنافذه.

jack.merge-monitor

يكشف منافذ الالتقاط ومنافذ المراقبة على نفس عميل جهاز JACK. هذه هي الطريقة التي يعرض بها JACK منافذ المراقبة للعملاء. القيمة الافتراضية هي عدم دمجها معًا لأن هذا يؤدي إلى واجهات مستخدم أكثر سهولة في الاستخدام بشكل عام. يتم إنشاء عميل إضافي بلاحقة Monitor يحتوي على منافذ المراقبة.

على سبيل المثال، هذا هو (جزء من) نتيجة jack_lsp مع الإعداد الافتراضي (jack.merge-monitor = false):

قارن:

jack.merge-monitor = true jack.merge-monitor = false Built-in Audio Analog Stereo:playback_FL Built-in Audio Analog Stereo:playback_FL Built-in Audio Analog Stereo:monitor_FL Built-in Audio Analog Stereo Monitor:monitor_FL Built-in Audio Analog Stereo:playback_FR Built-in Audio Analog Stereo:playback_FR Built-in Audio Analog Stereo:monitor_FR Built-in Audio Analog Stereo Monitor:monitor_FR

jack.show-midi

عرض عملاء MIDI ومنافذهم.

jack.short-name

لاستخدام أسماء أقصر لأسماء عملاء الأجهزة استخدم jack.short-name = true. قارن:

jack.short-name = true jack.short-name = false HDA Intel PCH:playback_FL Built-in Audio Analog Stereo:playback_FL HDA Intel PCH Monitor:monitor_FL Built-in Audio Analog Stereo Monitor:monitor_FL HDA Intel PCH:playback_FR Built-in Audio Analog Stereo:playback_FR HDA Intel PCH Monitor:monitor_FR Built-in Audio Analog Stereo Monitor:monitor_FR

jack.filter-name

jack.filter-char

سيستبدل جميع الأحرف الخاصة بـ jack.filter-char. بالنسبة للعملاء، الأحرف الخاصة هي ()[].:*$ وللمنافذ هي ()[].*$. استخدم هذا الخيار عندما لا يتمكن العميل من التعامل مع الأحرف الخاصة. (كانت الإصدارات الأقدم من PortAudio معروفة باستخدام أسماء العملاء والمنافذ كتعبيرات نمطية، وبالتالي فشلت عندما تكون هناك أحرف خاصة في الاسم).

jack.self-connect-mode

تقييد العميل من إجراء اتصالات لنفسه ومنه. القيم الممكنة ومعانيها ملخصة كما يلي:

السلوك القيمة allow لا تقيد طلبات الاتصال الذاتي. fail-external فشل طلبات الاتصال الذاتي بالمنافذ الخارجية فقط. ignore-external تجاهل طلبات الاتصال الذاتي بالمنافذ الخارجية فقط. fail-all فشل جميع طلبات الاتصال الذاتي. ignore-all تجاهل جميع طلبات الاتصال الذاتي.

jack.locked-process

تأكد من عدم إمكانية استدعاء العملية والاستدعاءات في نفس الوقت. هذه هي العملية العادية ولكن يمكن تعطيلها في حالة تمكن عميل معين من التعامل مع ذلك.

jack.default-as-system

قم بتسمية المصدر والمصرف الافتراضيين كنظام وترقيم المنافذ لزيادة التوافق مع برامج JACK.

jack.default-as-system = false jack.default-as-system = true HDA Intel PCH:playback_FL system:playback_1 HDA Intel PCH Monitor:monitor_FL system:monitor_1 HDA Intel PCH:playback_FR system:playback_2 HDA Intel PCH Monitor:monitor_FR system:monitor_2

jack.fix-midi-events

إصلاح أحداث NoteOn ذات السرعة 0 إلى NoteOff. هذا هو السلوك القياسي في JACK وبالتالي يتم تمكينه افتراضيًا لزيادة التوافق. خاصةً أن إضافات LV2 لا تسمح بـ NoteOn بسرعة 0.

jack.global-buffer-size

عندما يحتوي العميل على هذا الخيار، سيتم تطبيق تغييرات حجم الذاكرة المؤقتة بشكل عام ودائم لجميع عملاء PipeWire الذين يستخدمون البيانات الوصفية.

jack.passive-links

يجعل عملاء JACK يقومون بإنشاء روابط سلبية. يعمل هذا الخيار فقط عندما تم تكوين مصنع الروابط (link-factory) الخاص بالخادم باستخدام الخيار allow.link.passive.

jack.max-client-ports

قم بتحديد عدد المنافذ المسموح بها لكل عميل إلى هذه القيمة.

jack.fill-aliases

قم بتعيين اسم المنفذ alias1 و alias2 تلقائيًا على المنافذ.

jack.writable-input

يجعل مخازن الإدخال قابلة للكتابة. هذا هو الافتراضي لأن بعض عملاء JACK يكتبون إلى مخزن الإدخال. ومع ذلك، يمكن أن يتسبب هذا في تلف في العملاء الآخرين عندما يقرؤون أيضًا من المخزن.

قم بتعيين هذا إلى true لتجنب تلف المخزن إذا كنت تتعامل فقط مع عملاء غير معيبين.

jack.flag-midi2

استخدم علامة JACK MIDI2 الجديدة على منافذ MIDI2 (UMP). تم تعطيل هذا افتراضيًا

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
