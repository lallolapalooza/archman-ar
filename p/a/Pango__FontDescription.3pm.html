NAME

Pango::FontDescription - Wrapper for PangoFontDescription

HIERARCHY

Glib::Boxed
Pango::FontDescription

METHODS

The following methods are available:

  • new

    Create a new Pango::FontDescription object.

    Can be called as:

    • Pango::FontDescription->new()
    • Pango::FontDescription->new("fontname")
    • Pango::FontDescription->new("family:style:variant:weight:stretch:size")

  • new_from_string

    Create a new Pango::FontDescription object from a string.

    Example:

    • Pango::FontDescription->new_from_string("Sans Bold 12")

  • set_family

    Set the font family.

    Example:

    • $desc->set_family("Times New Roman")

  • get_family

    Get the font family.

  • set_style

    Set the font style.

    Example:

    • $desc->set_style("Italic")

  • get_style

    Get the font style.

  • set_variant

    Set the font variant.

    Example:

    • $desc->set_variant("Small Caps")

  • get_variant

    Get the font variant.

  • set_weight

    Set the font weight.

    Example:

    • $desc->set_weight("Bold")

  • get_weight

    Get the font weight.

  • set_stretch

    Set the font stretch.

    Example:

    • $desc->set_stretch("Condensed")

  • get_stretch

    Get the font stretch.

  • set_size

    Set the font size in Pango units.

    Example:

    • $desc->set_size(12 * Pango::SCALE)

  • get_size

    Get the font size in Pango units.

  • merge

    Merge another font description into this one.

  • merge_static

    Merge another font description into this one.

  • equal

    Check if two font descriptions are equal.

  • hash

    Get a hash value for the font description.

  • to_string

    Convert the font description to a string.

  • free

    Free the font description.
