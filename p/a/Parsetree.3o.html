فيما يلي إعلانات الأنواع وتمثيلها، لـ Parsetree.type_declaration.ptype_kind و Parsetree.type_declaration.ptype_manifest مختلف:

- type t عندما تكون type_kind هي Parsetree.type_kind.Ptype_abstract و manifest هي None ،

- type t = T0 عندما تكون type_kind هي Parsetree.type_kind.Ptype_abstract و manifest هي Some T0 ،

- type t = C of T | ... عندما تكون type_kind هي Parsetree.type_kind.Ptype_variant و manifest هي None ،

- type t = T0 = C of T | ... عندما تكون type_kind هي Parsetree.type_kind.Ptype_variant و manifest هي Some T0 ،

- type t = {l: T; ...} عندما تكون type_kind هي Parsetree.type_kind.Ptype_record و manifest هي None ،

- type t = T0 = {l : T; ...} عندما تكون type_kind هي Parsetree.type_kind.Ptype_record و manifest هي Some T0 ،

- type t = .. عندما تكون type_kind هي Parsetree.type_kind.Ptype_open و manifest هي None .
