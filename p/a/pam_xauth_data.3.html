pam_xauth_data(3)

الحزمة: pam

التراخيص: GPL-2.0-only

PAM_XAUTH_DATA(3) دليل Linux-PAM PAM_XAUTH_DATA(3)

الاسم

pam_xauth_data - بنية تحتوي على بيانات مصادقة X

الملخص

#include <security/pam_appl.h>
struct pam_xauth_data {
    int namelen;
    char *name;
    int datalen;
    char *data;
};

الوصف

تحتوي بنية pam_xauth_data على بيانات مصادقة X المستخدمة لإنشاء اتصال بشاشة X. باستخدام هذه الآلية، يمكن للتطبيق توصيل بيانات مصادقة X لوحدات خدمة PAM. وهذا يسمح للوحدات بإنشاء اتصال بشاشة X الخاصة بالمستخدم من أجل تسمية جلسة المستخدم عند تسجيل الدخول، أو عرض ملاحظات مرئية، أو لأغراض أخرى.

يحتوي الحقل name على اسم طريقة المصادقة، مثل "MIT-MAGIC-COOKIE-1". يحتوي الحقل namelen على طول هذا السلسلة، باستثناء حرف NUL اللاحق.

يحتوي الحقل data على البيانات الخاصة بطريقة المصادقة المقابلة للاسم المحدد. يحتوي الحقل datalen على طولها بالبايت.

يمكن تغيير بيانات مصادقة X باستخدام العنصر PAM_XAUTH_DATA. يمكن الاستعلام عنه وتعيينه باستخدام pam_get_item(3) و pam_set_item (3) على التوالي. يجب أن تكون القيمة المستخدمة لتعيينها مؤشرًا إلى بنية pam_xauth_data. يتم إجراء نسخة داخلية لكل من البنية نفسها وحقولها بواسطة PAM عند تعيين العنصر.
