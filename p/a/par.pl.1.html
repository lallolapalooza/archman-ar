par.pl(1)

الحزمة: perl-par-packer

التراخيص: GPL

PAR(1) وثائق Perl المساهمة من المستخدم PAR(1)

الاسم

par.pl - إنشاء وتشغيل أرشيفات Perl

ملخص

(يرجى الاطلاع على pp للحصول على طرق سهلة لإنشاء ملفات تنفيذية مستقلة، أو نصوص برمجية، أو أرشيفات PAR من برامج perl.)

لإنشاء توزيع PAR من توزيع وحدة CPAN:

% par.pl -p                 # إنشاء توزيع PAR ضمن المسار الحالي
% par.pl -p Foo-0.01        # افتراض توزيع CPAN غير مضغوط في Foo-0.01/

لمعالجة توزيع PAR:

% par.pl -i Foo-0.01-i386-freebsd-5.8.0.par # تثبيت
% par.pl -i http://foo.com/Foo-0.01         # يضيف تلقائيًا اسم الجهاز + إصدار perl
% par.pl -i cpan://AUTRIJUS/PAR-0.74        # يستخدم دليل المؤلف CPAN
% par.pl -u Foo-0.01-i386-freebsd-5.8.0.par # إلغاء التثبيت
% par.pl -s Foo-0.01-i386-freebsd-5.8.0.par # توقيع
% par.pl -v Foo-0.01-i386-freebsd-5.8.0.par # تحقق

لاستخدام Hello.pm من ./foo.par:

% par.pl -A./foo.par -MHello
% par.pl -A./foo -MHello    # جزء .par اختياري

نفس الشيء، ولكن ابحث عن foo.par في @INC;

% par.pl -Ifoo.par -MHello
% par.pl -Ifoo -MHello      # نفس الشيء

تشغيل test.pl أو script/test.pl من foo.par:

% par.pl foo.par test.pl    # يبحث عن 'main.pl' افتراضيًا،
                            # وإلا فسيتم تشغيل 'test.pl'

لإنشاء نص برمجي يحتوي على ملف PAR بداخله:

% par.pl -O./foo.pl foo.par
% ./foo.pl test.pl          # نفس الشيء أعلاه

لتضمين الوحدات النمطية غير الأساسية والكائنات المشتركة الضرورية لتنفيذ PAR (مثل "Zlib"، "IO"، "Cwd"، إلخ)، استخدم العلامة -b:

% par.pl -b -O./foo.pl foo.par
% ./foo.pl test.pl          # يعمل في أي مكان مع تثبيت الوحدات الأساسية

إذا كنت ترغب أيضًا في تضمين الوحدات الأساسية، فاستخدم العلامة -B بدلاً من ذلك:

% par.pl -B -O./foo.pl foo.par
% ./foo.pl test.pl          # يعمل في أي مكان مع مترجم perl

هذا مفيد بشكل خاص عند إنشاء ملفات تنفيذية ثنائية مستقلة؛ انظر pp للتفاصيل.

الوصف

يقدم هذا الأمر المستقل نفس ميزات "perl -MPAR" تقريبًا، باستثناء أنه يأخذ ملفات .par محملة مسبقًا عبر "-Afoo.par" بدلاً من "-MPAR=foo.par".

بالإضافة إلى ذلك، يتيح لك تحويل توزيع CPAN إلى توزيع PAR، بالإضافة إلى معالجة هذه التوزيعات. لمزيد من المعلومات حول توزيعات PAR، راجع PAR::Dist.

محمل PAR الثنائي (parl)

إذا كان لديك مترجم C، أو حزمة ثنائية مبنية مسبقًا من PAR متاحة لمنصتك، فسيتم تثبيت إصدار ثنائي من par.pl أيضًا باسم parl. يمكنك استخدامه لتشغيل ملفات .par:

# تشغيل script/run.pl في الأرشيف، يستخدم lib/* كمكتبات
% parl myapp.par run.pl     # تشغيل run.pl أو script/run.pl في myapp.par
% parl otherapp.pl          # تشغيل نصوص perl العادية أيضًا

ومع ذلك، إذا كان أرشيف .par يحتوي على main.pl أو script/main.pl، فسيتم استخدامه بدلاً من ذلك:

% parl myapp.par run.pl     # تشغيل main.pl، مع 'run.pl' كـ @ARGV

أخيرًا، تجعل الخيار "-O" ملفًا تنفيذيًا ثنائيًا مستقلاً من ملف PAR:

% parl -B -Omyapp myapp.par
% ./myapp                   # تشغيله في أي مكان بدون ثنائيات perl

مع العلامة "--par-options"، يمكن للملفات التنفيذية التي تم إنشاؤها العمل كـ "parl" لتعبئة ملفات ثنائية جديدة:

% ./myapp --par-options -Omyap2 myapp.par   # مطابق لـ ./myapp
% ./myapp --par-options -Omyap3 myap3.par   # الآن مع PAR مختلف

تنسيق الملف التنفيذي المستقل

تنسيق الملف التنفيذي المستقل هو ببساطة ربط العناصر التالية:

  • الملف التنفيذي نفسه

    إما بتنسيق نص عادي (par.pl) أو بتنسيق تنفيذي أصلي (parl أو parl.exe).

  • أي عدد من الملفات المضمنة

    تُستخدم هذه عادةً لتمهيد الاعتماديات XS المختلفة لـ PAR. يحتوي كل قسم على:

السلسلة السحرية ""FILE""
طول اسم الملف بتنسيق pack('N') بالإضافة إلى 9
8 بايتات من CRC32 مشفرة سداسيًا لمحتوى الملف
شرطة مائلة واحدة (""/"")
اسم الملف (بدون مسار)
طول الملف بتنسيق pack('N')
محتوى الملف (غير مضغوط)
  • ملف PAR واحد

    هذا مجرد ملف zip يبدأ بالسلسلة السحرية ""PK\003\004"".

  • قسم النهاية

    اسم ذاكرة التخزين المؤقت المحسوب مسبقًا. سلسلة pack('Z40') لقيمة -T (--tempcache) أو تجزئة الملف، متبوعة بـ "\0CACHE". يتم حساب تجزئة الملف باستخدام Digest::SHA.

    عدد pack('N') للطول الإجمالي لأقسام FILE و PAR، متبوعًا بسلسلة سحرية من 8 بايتات: ""\012PAR.pm\012"".
