الوصف

توفر وظائف PAPPL للوصول إلى كائن الطابعة. يتم إنشاء الطابعات وحذفها بواسطة تطبيق الطابعة بينما تتم إدارة دورة حياة كائنات pappl_printer_t تلقائيًا بواسطة كائن النظام لتطبيق الطابعة.

تقوم الدالة papplPrinterCreate بإنشاء طابعة جديدة بينما تقوم الدالة papplPrinterDelete بحذف طابعة.

تقوم الدالة papplPrinterPause بإيقاف طابعة بينما تقوم الدالة papplPrinterResume بتشغيل طابعة.

تقوم دوال papplPrinterGet بالحصول على القيم الحالية المرتبطة بطابعة بينما تقوم دوال papplPrinterSet بتعيين القيم الحالية المرتبطة بطابعة.

توفر الدوال papplPrinterCancelAddJobs, papplPrinterFindJob, papplPrinterGetNumberOfActiveJobs, papplPrinterGetNumberOfCompletedJobs, papplPrinterGetNumberOfJobs, papplPrinterIterateActiveJobs, papplPrinterIterateAllJobs, و papplPrinterIterateCompletedJobs الوصول إلى المهام الموجودة في قائمة انتظار الطابعة.

توفر الدالة papplPrinterOpenDevice الوصول إلى الجهاز المرتبط بالطابعة عندما لا تكون تعالج مهمة. يجب إغلاق الجهاز لاحقًا باستخدام الدالة papplPrinterCloseDevice حتى تتمكن الطابعة من استئناف معالجة المهام.

Cancel all jobs on the printer.

void papplPrinterCancelAllJobs (
    pappl_printer_t *printer
);

This function cancels all jobs on the printer. If any job is currently being printed, it will be stopped at a convenient time (usually the end of a page) so that the printer will be left in a known state.

This function creates, opens, or removes a file for a printer. NAME

pappl-printer - PAPPL printer functions

LIBRARY

PAPPL Library (libpappl)

SYNOPSIS

#include <pappl/pappl-printer.h>

DESCRIPTION

The PAPPL library provides functions for managing printers, print jobs, and print queues using the Printer Application Framework (PAPPL).

This man page covers the various data types and callback functions used by PAPPL for printer management.

ENUMERATIONS

PAPPL defines several enumerations for various printer settings and capabilities. These are typically represented as bitfields.

pappl_finishings_t
Bitfield for IPP "finishings" values.
pappl_identify_actions_t
Bitfield for IPP "identify-actions" values.
pappl_kind_t
Bitfield for IPP "printer-kind" values.
pappl_label_mode_t
Bitfield for IPP "label-mode-xxx" values.
pappl_media_tracking_t
Bitfield for IPP "media-tracking" values.
pappl_raster_type_t
Bitfield for IPP "pwg-raster-document-type-supported" values.
pappl_scaling_t
Bitfield for IPP "print-scaling" values.
pappl_sides_t
Bitfield for IPP "sides" values.
pappl_uoptions_t
USB gadget options bitfield.

FUNCTIONS

PAPPL defines several callback function types for various printer operations.
