الحزمة: libpwquality

NAME

pam_pwquality — password strength checking module

SYNOPSIS

pam_pwquality.so [option...]

DESCRIPTION

The pam_pwquality PAM module checks the quality of a new password against a set of rules. The rules are configurable via the configuration file /etc/security/pwquality.conf and command line options.

The checks performed are:

  • cracklib(3) dictionary check.
  • Check if the password contains the username.
  • Check for common password patterns.
  • Check for substrings from a list of bad words.

The module can be configured to either reject passwords that fail the checks or just print a warning message.

OPTIONS

dictcheck=N
إذا كانت قيمتها غير صفرية، فتحقق مما إذا كانت كلمة المرور (مع التعديلات المحتملة) تتطابق مع كلمة في قاموس. حاليًا، يتم إجراء فحص القاموس باستخدام مكتبة cracklib. الافتراضي هو 1، مما يعني أن هذا الفحص ممكّن.
usercheck=N
إذا كانت قيمتها غير صفرية، فتحقق مما إذا كانت كلمة المرور (مع التعديلات المحتملة) تحتوي على اسم المستخدم في شكل ما. الافتراضي هو 1، مما يعني أن هذا الفحص ممكّن. لا يتم إجراؤه لأسماء المستخدمين الأقصر من 3 أحرف.
usersubstr=N
إذا كانت أكبر من 3 (بسبب الحد الأدنى للطول في usercheck)، فتحقق مما إذا كانت كلمة المرور تحتوي على سلسلة فرعية من اسم المستخدم بطول N على الأقل في شكل ما. الافتراضي هو 0، مما يعني أن هذا الفحص معطل.
enforcing=N
إذا كانت قيمتها غير صفرية، فارفض كلمة المرور إذا فشلت في الفحوصات، وإلا فقم فقط بطباعة رسالة التحذير. الافتراضي هو 1، مما يعني أن كلمة المرور الضعيفة مرفوضة (للمستخدمين غير الجذر).
badwords=<list of words>
الكلمات التي يزيد طولها عن 3 أحرف من هذه القائمة المفصولة بمسافات يتم البحث عنها بشكل فردي ويتم حظرها في كلمة المرور الجديدة. افتراضيًا، القائمة فارغة، مما يعني أن هذا الفحص معطل.
dictpath=/path/to/dict
يسمح هذا الخيار بتحديد مسار غير افتراضي لقواميس cracklib.
enforce_for_root
ستقوم الوحدة بإرجاع خطأ عند فشل الفحص حتى لو كان المستخدم الذي يغير كلمة المرور هو الجذر. هذا الخيار معطل افتراضيًا، مما يعني أنه يتم فقط طباعة الرسالة حول الفحص الفاشل ولكن يمكن للجذر تغيير كلمة المرور على أي حال. لاحظ أن الجذر لا يُطلب منه كلمة المرور القديمة، لذا فإن الفحوصات التي تقارن كلمة المرور القديمة والجديدة لا يتم إجراؤها.
local_users_only
لن تختبر الوحدة جودة كلمة المرور للمستخدمين غير الموجودين في ملف /etc/passwd. لا تزال الوحدة تطلب كلمة المرور، لذا يمكن للوحدات التالية في المكدس استخدام خيار use_authtok. هذا الخيار معطل افتراضيًا.
use_authtok
يُستخدم هذا الوسيط لـ فرض على الوحدة عدم مطالبة المستخدم بكلمة مرور جديدة ولكن استخدام الكلمة التي قدمتها وحدة password المكدسة السابقة.

أنواع الوحدات المقدمة

يتم توفير نوع وحدة password فقط.

قيم الإرجاع

PAM_SUCCESS
كلمة المرور الجديدة تمر بجميع الفحوصات.
PAM_AUTHTOK_ERR
لم يتم إدخال كلمة مرور جديدة، أو لم يكن من الممكن تحديد اسم المستخدم، أو تفشل كلمة المرور الجديدة في فحوصات القوة.
PAM_AUTHTOK_RECOVERY_ERR
لم يتم توفير كلمة المرور القديمة بواسطة وحدة مكدسة سابقة أو لم يتم طلبها من المستخدم. قد يحدث الخطأ الأول إذا تم تحديد use_authtok.
PAM_SERVICE_ERR
حدث خطأ داخلي.

أمثلة

كمثال على استخدام هذه الوحدة، نوضح كيف يمكن تكديسها مع مكون كلمة المرور لـ pam_unix(8).

#
# هذه الأسطر تكدس وحدتين من نوع كلمة المرور. في هذا المثال،
# يُمنح المستخدم 3 فرص لإدخال كلمة مرور قوية.
# يضمن الوسيط "use_authtok" أن وحدة pam_unix لا
# تطالب بكلمة مرور، ولكن بدلاً من ذلك تستخدم الكلمة التي تم توفيرها بواسطة
# pam_pwquality.
#
password required pam_pwquality.so retry=3
password required pam_unix.so use_authtok

مثال آخر للحالة التي تريد فيها استخدام تشفير كلمة المرور sha256:

#
# تسمح هذه الأسطر للأنظمة الحديثة بدعم كلمات مرور بطول 14
# بايت على الأقل مع رصيد إضافي قدره 2 للأرقام و 2 للأحرف الأخرى، ويجب أن تحتوي
# كلمة المرور الجديدة على 3 بايت على الأقل غير موجودة في
# كلمة المرور القديمة
#
password required pam_pwquality.so \
              difok=3 minlen=15 dcredit=2 ocredit=2
password required pam_unix.so use_authtok nullok sha256

وهنا مثال آخر في حالة عدم رغبتك في استخدام الأرصدة:

#
# تتطلب هذه الأسطر من المستخدم اختيار كلمة مرور بحد أدنى
# طول 8 وبحد أدنى رقم واحد، حرف كبير واحد،
# وحرف واحد آخر
#
password required pam_pwquality.so \
              dcredit=-1 ucredit=-1 ocredit=-1 lcredit=0 minlen=8
password required pam_unix.so use_authtok nullok sha256
