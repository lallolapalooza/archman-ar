NAME

pam_unix — an authentication, account, session, and password module for the Pluggable Authentication Modules library

SYNOPSIS

pam_unix.so

DESCRIPTION

The pam_unix module is a PAM module that handles authentication, account management, session management, and password management. It uses the local system's user accounts, typically stored in /etc/passwd, /etc/shadow, and /etc/group files.

This module relies on the facilities provided by the shadow suite, if installed, for accessing the /etc/shadow and /etc/gshadow files.

OPTIONS

The pam_unix module can be configured with the following options:

nullok
Allows users to log in without a password (i.e., an empty password).
use_authtok
Use the password supplied by the user as the authentication token. This is useful for applications that already prompt for a password and don't want PAM to prompt again.
yescrypt
Use the yescrypt password hashing algorithm. This is the default if no other algorithm is specified.
sha512
Use the SHA512 password hashing algorithm.
sha256
Use the SHA256 password hashing algorithm.
md5
Use the MD5 password hashing algorithm.
sha1
Use the SHA1 password hashing algorithm.
des
Use the DES password hashing algorithm.

MODULE TYPES PROVIDED

The following module types are provided by pam_unix:

  • auth: Handles user authentication.
  • account: Handles account verification, such as checking if an account is expired or if the user is allowed to log in at a certain time.
  • session: Handles session setup and teardown, such as creating home directories or mounting user filesystems.
  • password: Handles password management, such as changing user passwords.

RETURN VALUES

These return values are the common return values for PAM modules.

PAM_SUCCESS
Authentication, account, session, or password management was successful.
PAM_AUTH_ERR
Authentication failure, often due to an incorrect username or password.
PAM_ACCT_EXPIRED
Account has expired.
PAM_SESSION_ERR
Error occurred during session management.
PAM_PASSWORD_ERR
Error occurred during password management.
PAM_NEW_AUTHTOK_REQD
A new authentication token (password) is required.
PAM_OLDAUTH_ERR
The old authentication token was incorrect.
PAM_AUTHTOK_EXPIRED
The authentication token has expired.

EXAMPLES

To configure pam_unix to authenticate users using the local password database, allow logins without a password, and use the yescrypt hashing algorithm, you might have a line like this in a PAM configuration file (e.g., /etc/pam.d/system-login):

auth       required     pam_unix.so use_authtok nullok yescrypt
account    required     pam_unix.so
session    required     pam_unix.so
password   required     pam_unix.so use_authtok sha512

A minimal configuration in /etc/pam.d/login might look like:

auth       required     pam_unix.so
account    required     pam_unix.so
session    required     pam_unix.so

الاسم

pam_unix — وحدة مصادقة، وحساب، وجلسة، وكلمة مرور لمكتبة وحدات المصادقة القابلة للتوصيل

الملخص

pam_unix.so

الوصف

وحدة pam_unix هي وحدة PAM تتعامل مع المصادقة، وإدارة الحسابات، وإدارة الجلسات، وإدارة كلمات المرور. تستخدم حسابات المستخدمين المحلية للنظام، والتي عادة ما يتم تخزينها في ملفات /etc/passwd، و /etc/shadow، و /etc/group.

تعتمد هذه الوحدة على المرافق التي توفرها مجموعة shadow، إذا كانت مثبتة، للوصول إلى ملفات /etc/shadow و /etc/gshadow.

الخيارات

يمكن تكوين وحدة pam_unix بالخيارات التالية:

nullok
يسمح للمستخدمين بتسجيل الدخول بدون كلمة مرور (أي، كلمة مرور فارغة).
use_authtok
استخدم كلمة المرور التي قدمها المستخدم كرمز مصادقة. هذا مفيد للتطبيقات التي تطالب بالفعل بكلمة مرور ولا تريد من PAM المطالبة مرة أخرى.
yescrypt
استخدم خوارزمية تجزئة كلمات المرور yescrypt. هذا هو الإعداد الافتراضي إذا لم يتم تحديد خوارزمية أخرى.
sha512
استخدم خوارزمية تجزئة كلمات المرور SHA512.
sha256
استخدم خوارزمية تجزئة كلمات المرور SHA256.
md5
استخدم خوارزمية تجزئة كلمات المرور MD5.
sha1
استخدم خوارزمية تجزئة كلمات المرور SHA1.
des
استخدم خوارزمية تجزئة كلمات المرور DES.

أنواع الوحدات المقدمة

يتم توفير أنواع الوحدات التالية بواسطة pam_unix:

  • auth: تتعامل مع مصادقة المستخدم.
  • account: تتعامل مع التحقق من الحساب، مثل التحقق مما إذا كان الحساب منتهي الصلاحية أو إذا كان يُسمح للمستخدم بتسجيل الدخول في وقت معين.
  • session: تتعامل مع إعداد وإنهاء الجلسات، مثل إنشاء الدلائل الرئيسية أو تحميل أنظمة ملفات المستخدم.
  • password: تتعامل مع إدارة كلمات المرور، مثل تغيير كلمات مرور المستخدمين.

قيم الإرجاع

هذه هي قيم الإرجاع الشائعة لوحدات PAM.

PAM_SUCCESS
نجحت المصادقة أو إدارة الحساب أو الجلسة أو كلمة المرور.
PAM_AUTH_ERR
فشل المصادقة، غالبًا بسبب اسم مستخدم أو كلمة مرور غير صحيحة.
PAM_ACCT_EXPIRED
انتهت صلاحية الحساب.
PAM_SESSION_ERR
حدث خطأ أثناء إدارة الجلسة.
PAM_PASSWORD_ERR
حدث خطأ أثناء إدارة كلمة المرور.
PAM_NEW_AUTHTOK_REQD
مطلوب رمز مصادقة جديد (كلمة مرور).
PAM_OLDAUTH_ERR
كان رمز المصادقة القديم غير صحيح.
PAM_AUTHTOK_EXPIRED
انتهت صلاحية رمز المصادقة.

أمثلة

لتهيئة pam_unix لمصادقة المستخدمين باستخدام قاعدة بيانات كلمات المرور المحلية، والسماح بتسجيل الدخول بدون كلمة مرور، واستخدام خوارزمية التجزئة yescrypt، قد يكون لديك سطر مثل هذا في ملف تكوين PAM (على سبيل المثال، /etc/pam.d/system-login):

auth       required     pam_unix.so use_authtok nullok yescrypt
account    required     pam_unix.so
session    required     pam_unix.so
password   required     pam_unix.so use_authtok sha512

قد يبدو تكوين بسيط في /etc/pam.d/login كما يلي:

auth       required     pam_unix.so
account    required     pam_unix.so
session    required     pam_unix.so
