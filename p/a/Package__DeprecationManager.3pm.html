Package__DeprecationManager(3pm)

الحزمة: perl-package-deprecationmanager

التراخيص: Artistic2.0

Package::DeprecationManager(3) وثائق Perl مقدمة من المساهمين Package::DeprecationManager(3)

الاسم

Package::DeprecationManager - إدارة تحذيرات الإهمال لتوزيعك

الإصدار

الإصدار 0.18

الملخص

package My::Class;
use Package::DeprecationManager -deprecations => {
    'My::Class::foo' => '0.02',
    'My::Class::bar' => '0.05',
    'feature-X'      => '0.07',
};
sub foo {
    deprecated( 'Do not call foo!' );
    ...
}
sub bar {
    deprecated();
    ...
}
sub baz {
    my %args = @_;
    if ( $args{foo} ) {
        deprecated(
            message => ...,
            feature => 'feature-X',
        );
    }
}
package Other::Class;
use My::Class -api_version => '0.04';
My::Class->new()->foo(); # يحذر
My::Class->new()->bar(); # لا يحذر
My::Class->new()->bar(); # لا يحذر مرة أخرى

الوصف

تسمح لك هذه الوحدة بإدارة مجموعة من الإهمالات لوحدة نمطية واحدة أو أكثر.

عند استيراد "Package::DeprecationManager"، يجب عليك توفير مجموعة من "-deprecations" كمرجع تجزئة. المفاتيح هي أسماء "الميزات"، والقيم هي الإصدار الذي تم فيه إهمال هذه الميزة.

في كثير من الحالات، يمكنك ببساطة استخدام الاسم المؤهل بالكامل لدالة فرعية أو طريقة كاسم للميزة. هذا يعمل في الحالات التي يتم فيها إهمال الدالة الفرعية بأكملها. ومع ذلك، يمكن أن تكون أسماء الميزات أي سلسلة نصية. هذا مفيد إذا كنت لا ترغب في إهمال دالة فرعية كاملة، بل مجرد استخدام معين.

يمكنك أيضًا توفير مرجع مصفوفة اختياري في المعلمة "-ignore".

يمكن أن تكون القيم التي يجب تجاهلها أسماء حزم أو تعبيرات عادية (مصنوعة باستخدام "qr//"). استخدم هذا لتجاهل الحزم في توزيعك التي يمكن أن تظهر في مسار الاستدعاء عند استخدام ميزة مهملة.

كجزء من عملية الاستيراد، تقوم "Package::DeprecationManager" بتصدير دالتين فرعيتين إلى المتصل بها. إنها توفر دالة import() للمتصل ودالة deprecated().

تسمح الدالة الفرعية import() للمتصلين بفئة الخاصة بك بتحديد معلمة "-api_version". إذا تم توفير ذلك، يتم إصدار تحذيرات الإهمال فقط للإهمالات التي لها إصدارات API أقدم من الإصدار المحدد.

يجب عليك استدعاء الدالة الفرعية deprecated() في كل دالة فرعية مهملة. عند استدعائها، ستقوم بإصدار تحذير باستخدام Carp::cluck().

يمكن استدعاء الدالة الفرعية deprecated() بعدة طرق. إذا لم تمرر أي وسيطات، فستقوم بتوليد رسالة تحذير مناسبة. إذا مررت وسيطة واحدة، فسيتم استخدامها كرسالة التحذير.

أخيرًا، يمكنك استدعائها بوسائط مسماة. حاليًا، الأسماء المسموح بها هي "message" و "feature". يجب أن تتوافق الوسيطة "feature" مع اسم الميزة الممررة في تجزئة "-deprecations".

إذا لم تحدد ميزة بشكل صريح، فإن الدالة الفرعية deprecated() تستخدم caller() لتحديد متصلها، باستخدام اسمها الكامل المؤهل للدالة الفرعية.

يتم إصدار تحذير إهمال معين مرة واحدة فقط لكل حزمة. تتتبع هذه الوحدة هذا بناءً على اسم الميزة ور رسالة الخطأ نفسها. هذا يعني أنه إذا قمت بتوفير عدة رسائل خطأ مختلفة لنفس الميزة، فستظهر جميع هذه الأخطاء.

وظائف import() أخرى

تعمل هذه الوحدة عن طريق تثبيت دالة "import" في أي حزمة تستخدمها. إذا كانت هذه الحزمة لديها بالفعل دالة "import"، فسيتم استدعاء تلك "import" بعد إزالة أي وسيطات تم تمريرها لـ "Package::DeprecationManager". تحتاج إلى تعريف دالة "import" الخاصة بك قبل أن "use Package::DeprecationManager" لكي يعمل هذا:

package HasExporter;
use Exporter qw( import );
use Package::DeprecationManager -deprecations => {
    'HasExporter::foo' => '0.02',
};
our @EXPORT_OK = qw( some_sub another_sub );

التبرعات

إذا كنت ترغب في شكرى على العمل الذي قمت به في هذه الوحدة، يرجى النظر في تقديم "تبرع" لي عبر PayPal. أقضي الكثير من وقت فراغي في إنشاء برامج مجانية، وسأقدر أي دعم قد ترغب في تقديمه.

يرجى ملاحظة أنني لا أقترح أنه يجب عليك فعل ذلك حتى أواصل العمل على هذا البرنامج المحدد. سأستمر في القيام بذلك، بقدر ما فعلت في الماضي، طالما أنه يثير اهتمامي.

بالمثل، فإن التبرع المقدم بهذه الطريقة من المحتمل ألا يجعلني أعمل على هذا البرنامج كثيرًا، إلا إذا حصلت على العديد من التبرعات لدرجة أنني أستطيع التفكير في العمل على البرامج المجانية بدوام كامل، وهو ما يبدو غير مرجح في أحسن الأحوال.

للتبرع، قم بتسجيل الدخول إلى PayPal وأرسل الأموال إلى autarch@urth.org أو استخدم الزر الموجود في هذه الصفحة: http://www.urth.org/~autarch/fs-donation.html
