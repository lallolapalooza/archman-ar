اسم

partclone - الأداة لنسخ واستعادة قسم.

ملخص

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] target} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

الوصف

partclone.[fstype] هو جزء من مشروع Partclone. يوفر Partclone أدوات لعمل نسخ احتياطي للكتل المستخدمة وهو مصمم لتوافق أعلى مع نظام الملفات باستخدام مكتبات موجودة، على سبيل المثال، يتم استخدام e2fslibs لقراءة الكتل المستخدمة لقسم ext2.

يشمل نظام الملفات المدعوم من Partclone: btrfs، ext2، ext3، ext4، reiserfs، reiser4، xfs، و jfs لنظام LINUX. كما يدعم بعض أنظمة التشغيل غير لنظام لينكس، على سبيل المثال: NTFS، FAT، و EXFAT (لنظام Windows)، HFS plus (لـ MAC OS)، UFS2 (لـ FreeBSD)، VMFS (لـ VMWARE Vsphere)، و MINIX (لـ MINIX3).

يمكن تشغيل جميع أدوات partclone مثل partclone.[fstype] وهي تشبه fsck أو mkfs. على سبيل المثال، لعمل نسخة احتياطية/استعادة hfsplus، قم فقط بتشغيل partclone.hfsp

       نظام الملفات                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       أخرى (نظام ملفات غير مدعوم)   partclone.imager

خيارات

يتبع البرنامج بناء جملة سطر الأوامر المعتاد لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتضمن ملخصًا للخيارات أدناه.

-s FILE, --source FILE

ملف المصدر. يمكن أن يكون FILE ملف صورة (تم إنشاؤه بواسطة partclone) أو جهازًا حسب الإجراء الذي تتخذه. عادةً، يكون مصدر النسخ الاحتياطي هو الجهاز، ومصدر الاستعادة هو ملف الصورة.

يتم دعم استقبال البيانات من خط الأنابيب (pipe line) فقط للاستعادة، تجاهل خيار -s أو استخدام '-' يعني استقبال البيانات من stdin.

-o FILE, --output FILE

ملف الإخراج. يمكن أن يكون FILE ملف صورة (سيقوم partclone بإنشائه) أو جهازًا حسب الإجراء الذي تتخذه. عادةً، يتم نسخ الإخراج احتياطيًا إلى ملف صورة واستعادة الإخراج إلى الجهاز.

يتم دعم إرسال البيانات إلى خط الأنابيب (pipe line) أيضًا فقط للنسخ الاحتياطي، تجاهل خيار -o أو استخدام '-' يعني إرسال البيانات إلى stdout.

-O FILE, --overwrite FILE

الكتابة فوق FILE، والكتابة فوقه إذا كان موجودًا.

-W FILE, --restore_raw_file FILE

إنشاء ملف خام خاص لجهاز الحلقة.

-c, --clone

حفظ القسم بتنسيق الصورة الخاص.

-r, --restore

استعادة القسم من تنسيق الصورة الخاص.

-b, --dev-to-dev

نسخ جهاز محلي إلى جهاز مباشرة، المصدر والإخراج كلاهما جهاز.

-D, --domain

إنشاء ملف سجل نطاق GNU Ddrescue من جهاز المصدر. هذا ملف قابل للقراءة البشرية يحدد فيه + الكتل المستخدمة و؟ الكتل الحرة.

--offset_domain=X

إضافة X (بالبايت) إلى جميع المواقع المبلغ عنها في ملف سجل النطاق.

--restore_raw_file

إنشاء ملف خام خاص لجهاز الحلقة.

-L FILE, --logfile FILE

وضع مسار خاص لتسجيل معلومات سجل partclone. (الافتراضي /var/log/partclone.log)

-R, --rescue

الاستمرار بعد أخطاء قراءة القرص.

-C, --no_check

لا تتحقق من حجم الجهاز والمساحة الخالية.

-N, --ncurses

استخدام واجهة مستخدم نصية Ncurses.

-I, --ignore_fschk

تجاهل فحص نظام الملفات.

-i, --ignore_crc

تجاهل خطأ فحص crc.

-F, --force

فرض التقدم.

-f sec, --UI-fresh sec

وضع ثانية خاصة بفواصل زمنية مختلفة.

-z size, --buffer_size size

حجم المخزن المؤقت للقراءة/الكتابة (الافتراضي: 1048576)

-q, --quiet

تعطيل رسالة التقدم.

-dlevel, --debug level

تعيين مستوى التصحيح [1|2|3].

-x, --compresscmd CMD

بدء CMD كأنبوب إخراج لضغط صورة النسخ.

-aX, --checksum-mode=X

صيغة المجموع الاختباري المراد استخدامها لإضافة اكتشاف الأخطاء

حيث X:

0: لا يوجد مجموع اختباري (لا تباطؤ، أصغر صورة)

1: CRC32 (سريع الحساب، اكتشاف أساسي)

2: xxHash خوارزمية تجزئة فائقة السرعة غير تشفيرية

-kX, --blocks-per-checksum=X

كتابة مجموع اختباري واحد لكل X كتلة.

-w, --skip_write_error

الاستمرار في الاستعادة أثناء أخطاء الكتابة.

--write-direct-io

كتابة البيانات إلى قسم TARGET دون ذاكرة تخزين مؤقت.

--read-direct-io

قراءة البيانات من قسم SOURCE دون ذاكرة تخزين مؤقت.

-B, --no_block_detail

عرض رسالة التقدم بدون تفاصيل الكتلة.

--binary-prefix

عرض التقدم بحجم بت (الافتراضي هو MB، GB...)

--prog-second

عرض التقدم بالثواني (الافتراضي هو الدقائق).

-E, --offset=X

إضافة إزاحة X (بالبايت) إلى الإخراج.

-T, --btfiles

استعادة الكتلة كملف لـ ClonezillaBT.

-t, --btfiles_torrent

استعادة الكتلة كملف لـ ClonezillaBT ولكن يتم إنشاء التورنت فقط.

-n, --note NOTE

عرض ملاحظة رسالة (128 كلمة).

-h, --help

عرض ملخص الخيارات.

-v, --version

عرض الإصدار.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

NAME

partclone.hfs+ - A program to clone or restore HFS+ file system.

SYNOPSIS

partclone.hfs+ [-R | -c] [-s source] [-o output] [-C] [-d] [-F] [-N] [-q] [-v] [-z n] [-b] [-e] [-E] [-x]

DESCRIPTION

partclone.hfs+ is a program that helps you clone or restore HFS+ file system. It uses the hfsplus filesystem library to achieve this. It can clone a partition to an image file, or restore an image file to a partition.

The partition must be unmounted before cloning or restoring.

partclone.hfs+ can handle split files, gzip compression, and other compression methods.

OPTIONS

-c
Clone: Clone the source file system to the output file.
-r
Restore: Restore the source image file to the output partition.
-s source
Source: Specify the source file or partition. Use "-" for standard input.
-o output
Output: Specify the output file or partition. Use "-" for standard output.
-C
Check: Check the image file integrity.
-d
Debug: Enable debug messages.
-F
Force: Force the operation, even if warnings are issued.
-N
No prompt: Do not prompt for confirmation.
-q
Quiet: Suppress progress information.
-v
Verbose: Display verbose output.
-z n
Number of parts: Split the image file into multiple parts, each with a size of n MB.
-b
Basic: Use basic mode, without compression or split files.
-e
Exit on error: Exit immediately if an error occurs.
-E
Exit on warning: Exit immediately if a warning occurs.
-x
Disable checksums: Disable checksum verification for image files.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
