الحزمة: partclone

التراخيص: GPL-2.0-or-later

NAME

partclone.ext3

create, restore, clone an image file for ext3 filesystem.

SYNOPSIS

partclone.ext3 [ -c ] [ -r ] [ -s source ] [ -o output ] [ -b ] [ -d ] [ -i ] [ -N number ] [ -v ] [ -Z block size ] [ -P partition name ]

DESCRIPTION

partclone is a program that clone, save used space and its program support program which are based on the filesystem.

partclone is trying to be small, fast and simple. It provides saving and restoring partition to image file. It also can save partition to partition, it can clone.

The program can save only the used blocks in the image file. This will make the image file smaller and faster to create and restore.

partclone supports several file systems, such as:

ext2, ext3, ext4
reiserfs
xfs
btrfs
ntfs
fat32
hfs+

And the image file format can be compressed by gzip, bzip2, lzop, or xz.

partclone can also create a clone of a partition to another partition. This is useful when you want to clone one partition to another directly without creating an image file.

OPTIONS

The following options are available:

-c, --clone
Clone mode. Save partition to partition.
-r, --restore
Restore mode. Restore image file to partition.
-s, --source source
Source. Can be a device, an image file, or stdin.
-o, --output output
Output. Can be a device, an image file, or stdout.
-d, --debug
Display debug information.
-i, --ignore-bad-blocks
Ignore bad blocks during clone or restore.
-N, --nthreads number
Number of threads to use for parallel processing.
-v, --verbose
Display verbose information.
-Z, --block-size block size
Set the block size for the filesystem.
-P, --partition-name partition name
Specify the partition name to be saved or restored.

If no options are specified, partclone will try to guess the mode based on the source and output arguments.

partclone.ext3 specifically targets ext3 filesystems. Other partclone utilities like partclone.ext2, partclone.ext4, etc., are available for their respective filesystem types. You can also use the generic partclone command which will attempt to detect the filesystem type automatically.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
