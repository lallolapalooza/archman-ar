NAME

Params::Check - A module for the validation of subroutine arguments

SYNOPSIS

 use Params::Check;

 sub my_function {
     my ($template, $args_in) = @_;
     my $args_out = check($template, $args_in);

     # Do something with $args_out.
     # Or, if check fails, croak with an error message
     croak Params::Check::last_error() unless $args_out;

     return $args_out;
 }

DESCRIPTION

Params::Check is a module that will check subroutine arguments. It uses a template to define what arguments are expected, and then checks an incoming list of arguments against this template.

The template itself is a hashref, which takes the following keys:

$param
The name of the parameter. This is the only required key.
type
The expected type of the parameter. This can be one of the following:
SCALAR
The parameter must be a scalar value.
ARRAYREF
The parameter must be a reference to an array.
HASHREF
The parameter must be a reference to a hash.
CODE
The parameter must be a code reference.
GLOB
The parameter must be a glob reference.
REF
The parameter must be a reference of any type.
REGEXP
The parameter must be a reference to a regular expression.
UNDEF
The parameter must be undef.
NUMBER
The parameter must be a number (integer or floating point).
INTEGER
The parameter must be an integer.
FLOAT
The parameter must be a floating point number.
CLASSNAME
The parameter must be a string that is a valid class name.
OBJECT
The parameter must be an object.
HASH
The parameter must be a hashref and contains only keys that are defined in the template.
ARRAY
The parameter must be an arrayref and contains only values that are defined in the template.
STRING
The parameter must be a string.
default
A default value to use if the parameter is not provided.
required
If set to true, the parameter is required and must be provided.
store
A reference to a scalar, array or hash where the value should be stored. This value will be modified.
callbacks
A code reference to a subroutine that will be called with the value of the parameter. The subroutine should return true if the value is acceptable, or false otherwise.
defined
If set to true, the parameter must be defined. Default is false.
array
If set to true, the parameter is allowed to occur multiple times. The value will be stored as an arrayref.
strict_type
If set to true, the type checking will be stricter. For example, if type is set to INTEGER, then 1.0 will not be accepted.
hash
If set to true, the parameter is allowed to occur multiple times. The value will be stored as a hashref.
unique
If set to true, the parameter cannot occur more than once. Default is false.
help
A string describing the parameter. This is used when generating help messages.

The incoming arguments are expected to be a list of key/value pairs. These can be simple scalars, or hashes, or array references.

Params::Check returns a hashref containing the checked arguments, or false if an error occurred. Use Params::Check::last_error() to retrieve the error message.

The following options can be passed to the check function:

verbose
If set to true, Params::Check will output warnings and explanations as to why certain things may have failed.
strict_type
If set to true, the type checking will be stricter. For example, if type is set to INTEGER, then 1.0 will not be accepted.
allow_unknown
If set to true, unknown options will still be present in the return value, rather than filtered out.
strip_leading_dashes
If set to true, all keys passed in the following manner: 
 function( -key => 'val' );
will have their leading dashes stripped.
no_duplicates
If set to true, all keys in the template that are marked as to be stored in a scalar, will also be removed from the result set.
preserve_case
If set to true, Params::Check will no longer convert all keys from the user input to lowercase, but instead expect them to be in the case the template provided. This is useful when you want to use similar keys with different casing in your templates.
only_allow_defined
If set to true, Params::Check will require all values passed to be defined.
sanity_check_template
If set to true, Params::Check will sanity check templates, validating for errors and unknown keys.
warnings_fatal
If set to true, Params::Check will croak when an error during template validation occurs, rather than return false.

Params::Check also exports the following functions:

check
The main function for checking arguments.
last_error
Returns the last error message.
set_callbacks
Allows you to set custom callbacks.
set_types
Allows you to set custom types.

It is useful if you want to report then some other way than "carp"'ing when the verbose flag is on.

It is exported upon request.

Global Variables

The behaviour of Params::Check can be altered by changing the following global variables:

$Params::Check::VERBOSE

This controls whether Params::Check will issue warnings and explanations as to why certain things may have failed. If you set it to 0, Params::Check will not output any warnings.

The default is 1 when warnings are enabled, 0 otherwise;

$Params::Check::STRICT_TYPE

This works like the "strict_type" option you can pass to "check", which will turn on "strict_type" globally for all calls to "check".

The default is 0;

$Params::Check::ALLOW_UNKNOWN

If you set this flag, unknown options will still be present in the return value, rather than filtered out. This is useful if your subroutine is only interested in a few arguments, and wants to pass the rest on blindly to perhaps another subroutine.

The default is 0;

$Params::Check::STRIP_LEADING_DASHES

If you set this flag, all keys passed in the following manner:

function( -key => 'val' );

will have their leading dashes stripped.

$Params::Check::NO_DUPLICATES

If set to true, all keys in the template that are marked as to be stored in a scalar, will also be removed from the result set.

Default is false, meaning that when you use "store" as a template key, "check" will put it both in the scalar you supplied, as well as in the hashref it returns.

$Params::Check::PRESERVE_CASE

If set to true, Params::Check will no longer convert all keys from the user input to lowercase, but instead expect them to be in the case the template provided. This is useful when you want to use similar keys with different casing in your templates.

Understand that this removes the case-insensitivity feature of this module.

Default is 0;

$Params::Check::ONLY_ALLOW_DEFINED

If set to true, Params::Check will require all values passed to be "defined". If you wish to enable this on a 'per key' basis, use the template option "defined" instead.

Default is 0;

$Params::Check::SANITY_CHECK_TEMPLATE

If set to true, Params::Check will sanity check templates, validating for errors and unknown keys. Although very useful for debugging, this can be somewhat slow in hot-code and large loops.

To disable this check, set this variable to "false".

Default is 1;

$Params::Check::WARNINGS_FATAL

If set to true, Params::Check will "croak" when an error during template validation occurs, rather than return "false".

Default is 0;

$Params::Check::CALLER_DEPTH

This global modifies the argument given to caller() by Params::Check::check() and is useful if you have a custom wrapper function around Params::Check::check(). The value must be an integer, indicating the number of wrapper functions inserted between the real function call and Params::Check::check().

Example wrapper function, using a custom stacktrace:

sub check {
    my ($template, $args_in) = @_;
    local $Params::Check::WARNINGS_FATAL = 1;
    local $Params::Check::CALLER_DEPTH = $Params::Check::CALLER_DEPTH + 1;
    my $args_out = Params::Check::check($template, $args_in);
    my_stacktrace(Params::Check::last_error) unless $args_out;
    return $args_out;
}

Default is 0;
