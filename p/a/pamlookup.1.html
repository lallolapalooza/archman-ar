NAME

pamlookup - look up values in a lookup image

SYNOPSIS

pamlookup [input.pgm] [input.ppm]
[-lookupfile=lookup.ppm]
[-default=R G B | -defaultindex=N]
[-verbose] [pam options]

DESCRIPTION

This program creates a new image by looking up pixel values from an input image in a separate lookup image.

The input image is typically a PBM or PPM image where each pixel value is an index into the lookup image. For example, if an input pixel has value 3, the program looks up the pixel at row 3 in the lookup image.

There are two basic modes of operation, depending on the type of the input image:

PBM input: Each pixel is a single bit, 0 or 1. These are used as indices into a two-row lookup image. A value of 0 selects the first row, and 1 selects the second row. If the lookup image is smaller than 2 rows, the behavior is undefined.

PPM input: Each pixel is a tuple (R,G,B). These are used as indices into a lookup image with arbitrary dimensions. The input pixel's R, G, and B values are used to select a pixel in the lookup image. For example, a pixel with value (3, 4, 5) would select the pixel at row 3, column 4, color 5 in the lookup image. Note that the color index (the third dimension) is only valid if the lookup image has color components greater than 1. If the input image has only 1 or 2 components, the third component is assumed to be 0.

If the input pixel value exceeds the dimensions of the lookup image, the default value is used. If no default value is specified, and the input pixel value is out of bounds, the program terminates with an error.

The output image will have the same dimensions as the input image.

OPTIONS

-lookupfile=lookup.ppm
Specifies the lookup image. If this option is not given, the program expects the lookup image as the second input, or as standard input if only one input image is given.

-default=R G B
Specifies the default color to use when an input pixel's value is out of bounds in the lookup image. The values R, G, and B are integers between 0 and 255.

-defaultindex=N
Specifies the default index to use when an input pixel's value is out of bounds in the lookup image. This option is only applicable when the input image is PBM. A value of 0 selects the first row of the lookup image, and 1 selects the second row.

-verbose
Prints information about the operation to stderr.

EXAMPLES

Suppose we have two PBM images, image1.pbm and image2.pbm, where each pixel can take one of four values: (0,0), (0,1), (1,0), or (1,1). We want to create a new image where these values are mapped to different colors.

First, we combine the two input PBMs into a single PAM image. This is a convenience step; the program can also accept two separate PBM inputs.


    pamstack image1.pbm image2.pbm >bothimages.pam

Note that this image has 1 of 4 possible tuple values at each location: (0,0), (0,1), (1,0), or (1,1).

Now, we create a lookup table that we can index with those 4 values:


    ppmmake white 1 1 >white.ppm
    ppmmake black 1 1 >black.ppm
    ppmmake red   1 1 >red.ppm
    ppmmake green 1 1 >green.ppm
    pnmcat -leftright black.ppm red.ppm   >blackred.ppm
    pnmcat -leftright green.ppm white.ppm >greenwhite.ppm
    pnmcat -topbottom blackred.ppm greenwhite.ppm >lookup.ppm

Finally, we look up the indices from our index in our lookup table and produce the output:


    pamlookup bothimages.ppm -lookupfile=lookup.ppm >imagediff.ppm
