Path__Class__File(3pm)

الحزمة: perl-path-class

التراخيص: PerlArtistic, GPL

Path::Class::File(3pm) وثائق Perl المساهمة من المستخدم Path::Class::File(3pm)

الاسم

Path::Class::File - كائنات تمثل الملفات

الإصدار

الإصدار 0.37

الملخص

use Path::Class;  # يقوم بتصدير file() افتراضياً
my $file = file('foo', 'bar.txt');  # كائن Path::Class::File
my $file = Path::Class::File->new('foo', 'bar.txt'); # نفس الشيء
# يتم تحويله إلى سلسلة نصية 'foo/bar.txt' على يونكس، 'foo\bar.txt' على ويندوز، إلخ.
print "file: $file\n";
if ($file->is_absolute) { ... }
if ($file->is_relative) { ... }
my $v = $file->volume; # يمكن أن يكون 'C:' على ويندوز، سلسلة فارغة
                       # على يونكس، 'Macintosh HD:' على ماك
$file->cleanup; # تنفيذ تنظيف منطقي للمسار
$file->resolve; # تنفيذ تنظيف فيزيائي للمسار
my $dir = $file->dir;  # كائن Path::Class::Dir
my $abs = $file->absolute; # تحويل إلى مسار مطلق
my $rel = $file->relative; # تحويل إلى مسار نسبي

الوصف

الفئة "Path::Class::File" تحتوي على وظائف لمعالجة أسماء الملفات بطريقة متوافقة مع الأنظمة المختلفة.

الطرق

$file = Path::Class::File->new( <dir1>, <dir2>, ..., <file> )
$file = file( <dir1>, <dir2>, ..., <file> )
ينشئ كائن "Path::Class::File" جديدًا ويعيده. تحدد الوسائط المسار إلى الملف. يمكن أيضًا تحديد أي وحدة تخزين كوسيط أول، أو كجزء من الوسيط الأول. يمكنك استخدام صيغة محايدة للنظام: 
my $file = file( 'foo', 'bar', 'baz.txt' );

أو صيغة أصلية للنظام:

my $file = file( 'foo/bar/baz.txt' );

أو مزيج من الاثنين:

my $file = file( 'foo/bar', 'baz.txt' );

جميع الأمثلة الثلاثة أعلاه تنشئ مسارات نسبية. لإنشاء مسار مطلق، استخدم إما الصيغة الأصلية للنظام للقيام بذلك:

my $file = file( '/var/tmp/foo.txt' );

أو استخدم سلسلة فارغة كوسيط أول:

my $file = file( '', 'var', 'tmp', 'foo.txt' );

إذا بدت الصيغة الثانية محرجة، فهذا متعمد إلى حد ما - المسارات مثل "/var/tmp" أو "\Windows" ليست مفاهيم متوافقة مع الأنظمة المختلفة في المقام الأول، لذا ربما لا ينبغي أن تظهر في الكود الخاص بك إذا كنت تحاول أن تكون متوافقًا مع الأنظمة المختلفة. الصيغة الأولى جيدة تمامًا، لأن المسارات مثل هذه قد تأتي من ملفات التكوين، مدخلات المستخدم، أو أي شيء آخر.

$file->stringify
يتم استدعاء هذه الطريقة داخليًا عندما يتم استخدام كائن "Path::Class::File" في سياق سلسلة نصية، لذا فإن ما يلي متكافئ: 
$string = $file->stringify;
$string = "$file";
$file->volume
يعيد وحدة التخزين (على سبيل المثال "C:" على ويندوز، "Macintosh HD:" على ماك، إلخ.) للكائن، إن وجدت. خلاف ذلك، يعيد سلسلة فارغة.
$file->basename
يعيد اسم الملف كسلسلة نصية، بدون جزء الدليل (إن وجد).
$file->components
يعيد قائمة بمكونات دليل هذا الملف، متبوعة بالاسم الأساسي.

ملاحظة: على عكس "$dir->components"، هذه الطريقة لا تقبل حاليًا أي وسائط لتحديد أي عناصر من القائمة سيتم إرجاعها. قد تفعل ذلك في المستقبل. حاليًا، تثير استثناءً إذا كانت هذه الوسائط موجودة.

$file->is_dir
يعيد قيمة منطقية تشير إلى ما إذا كان هذا الكائن يمثل دليلاً. ليس من المستغرب أن كائنات "Path::Class::File" تعيد دائمًا خطأ، وكائنات Path::Class::Dir تعيد دائمًا صحيحًا.
$file->is_absolute
يعيد صحيحًا أو خطأ اعتمادًا على ما إذا كان الملف يشير إلى محدد مسار مطلق (مثل "/usr/local/foo.txt" أو "\Windows\Foo.txt").
$file->is_relative
يعيد صحيحًا أو خطأ اعتمادًا على ما إذا كان الملف يشير إلى محدد مسار نسبي (مثل "lib/foo.txt" أو ".\Foo.txt").
$file->cleanup
ينفذ تنظيفًا منطقيًا لمسار الملف. على سبيل المثال: 
my $file = file('/foo//baz/./foo.txt')->cleanup;
# $file يمثل الآن '/foo/baz/foo.txt'؛
$dir->resolve
ينفذ تنظيفًا فيزيائيًا لمسار الملف. على سبيل المثال: 
my $file = file('/foo/baz/../foo.txt')->resolve;
# $file يمثل الآن '/foo/foo.txt'، بافتراض عدم وجود روابط رمزية

هذا يستشير بالفعل نظام الملفات للتحقق من صلاحية المسار.

$dir = $file->dir
يعيد كائن "Path::Class::Dir" يمثل الدليل الذي يحتوي على هذا الملف.
$dir = $file->parent
مرادف للطريقة dir().
$abs = $file->absolute
يعيد كائن "Path::Class::File" يمثل $file كمسار مطلق. وسيط اختياري، يُعطى كسلسلة نصية أو ككائن Path::Class::Dir، يحدد الدليل الذي سيتم استخدامه كأساس للنسبية - وإلا فسيتم استخدام الدليل الحالي.
$rel = $file->relative
يعيد كائن "Path::Class::File" يمثل $file كمسار نسبي. وسيط اختياري، يُعطى كسلسلة نصية أو ككائن "Path::Class::Dir"، يحدد الدليل الذي سيتم استخدامه كأساس للنسبية - وإلا فسيتم استخدام الدليل الحالي.
$foreign = $file->as_foreign($type)
يعيد كائن "Path::Class::File" يمثل $file كما سيتم تحديده على نظام من النوع $type. تشمل الأنواع المعروفة "Unix"، "Win32"، "Mac"، "VMS"، و "OS2"، أي شيء يوجد له فئة فرعية من "File::Spec".

ستحتفظ جميع الكائنات المولدة (الأدلة الفرعية، الملفات، الأصول، إلخ) بهذا النوع أيضًا.

$foreign = Path::Class::File->new_foreign($type, @args)
يعيد كائن "Path::Class::File" يمثل ملفًا كما سيتم تحديده على نظام من النوع $type. تشمل الأنواع المعروفة "Unix"، "Win32"، "Mac"، "VMS"، و "OS2"، أي شيء يوجد له فئة فرعية من "File::Spec".

الوسائط في @args هي نفسها كما سيتم تحديدها في new().

$fh = $file->open($mode, $permissions)
يمرر الوسائط المعطاة، بما في ذلك $file، إلى "IO::File->new" (الذي بدوره يستدعي "IO::File->open" ويعيد النتيجة ككائن IO::File. إذا فشل الفتح، يتم إرجاع "undef" ويتم تعيين $!.
$fh = $file->openr()
اختصار لـ: 
$fh = $file->open('r') or croak "Can't read $file: $!";
$fh = $file->openw()
اختصار لـ: 
$fh = $file->open('w') or croak "Can't write to $file: $!";
$fh = $file->opena()
اختصار لـ: 
$fh = $file->open('a') or croak "Can't append to $file: $!";
$file->touch
يضبط وقت التعديل والوصول للملف المحدد إلى الآن، إذا كان الملف موجودًا. إذا لم يكن موجودًا، سيقوم touch() بإنشائه، و - نعم! - سيضبط وقت التعديل والوصول إليه إلى الآن.
$file->slurp()
في سياق قياسي، يعيد محتويات $file كسلسلة نصية. في سياق قائمة، يعيد أسطر $file (وفقًا لكيفية

METHODS

$file->slurp( @args );
Reads the contents of the file into a list of lines. If the file is empty, it returns an empty list.

If called in scalar context, it returns the entire file contents as a single string (equivalent to Perl's do). If the file can't be read, this method will throw an exception.

If you want chomp() run on each line of the file, pass a true value for the "chomp" or "chomped" parameters:

my @lines = $file->slurp(chomp => 1);

You may also use the "iomode" parameter to pass in an IO mode to use when opening the file, usually IO layers (though anything accepted by the MODE argument of open() is accepted here). Just make sure it's a reading mode.

my @lines = $file->slurp(iomode => ':crlf');
my $lines = $file->slurp(iomode => '<:encoding(UTF-8)');

The default "iomode" is "r".

Lines can also be automatically split, mimicking the perl command-line option "-a" by using the "split" parameter. If this parameter is used, each line will be returned as an array ref.

my @lines = $file->slurp( chomp => 1, split => qr/\s*,\s*/ );

The "split" parameter can only be used in a list context.

$file->spew( $content );
The opposite of "slurp", this takes a list of strings and prints them to the file in write mode. If the file can't be written to, this method will throw an exception.

The content to be written can be either an array ref or a plain scalar. If the content is an array ref then each entry in the array will be written to the file.

You may use the "iomode" parameter to pass in an IO mode to use when opening the file, just like "slurp" supports.

$file->spew(iomode => '>:raw', $content);

The default "iomode" is "w".

$file->spew_lines( $content );
Just like "spew", but, if $content is a plain scalar, appends $/ to it, or, if $content is an array ref, appends $/ to each element of the array.

Can also take an "iomode" parameter like "spew". Again, the default "iomode" is "w".

$file->traverse(sub { ... }, @args)
Calls the given callback on $file. This doesn't do much on its own, but see the associated documentation in Path::Class::Dir.
$file->remove()
This method will remove the file in a way that works well on all platforms, and returns a boolean value indicating whether or not the file was successfully removed.

remove() is better than simply calling Perl's unlink() function, because on some platforms (notably VMS) you actually may need to call unlink() several times before all versions of the file are gone - the remove() method handles this process for you.

$st = $file->stat()
Invokes File::stat::stat() on this file and returns a File::stat object representing the result.
$st = $file->lstat()
Same as stat(), but if $file is a symbolic link, lstat() stats the link instead of the file the link points to.
$class = $file->dir_class()
Returns the class which should be used to create directory objects.

Generally overridden whenever this class is subclassed.

$copy = $file->copy_to( $dest );
Copies the $file to $dest. It returns a Path::Class::File object when successful, "undef" otherwise.
$moved = $file->move_to( $dest );
Moves the $file to $dest, and updates $file accordingly.

It returns $file is successful, "undef" otherwise.
