الاسم

pacparser - مكتبة لتحليل ملفات تكوين البروكسي التلقائي (PAC).

واجهة برمجة التطبيقات (API) لمكتبة pacparser، وهي مكتبة لاستخدام ملفات تكوين البروكسي التلقائي (PAC). راجع الصفحة الرئيسية للمشروع: http://github.com/pacparser/pacparser لمزيد من المعلومات.

يقوم بتقييم سلسلة نص PAC المحددة في سياق JavaScript الذي تم إنشاؤه بواسطة pacparser_init.

int pacparser_parse_pac (const char *pacfile)

يحلل ملف PAC المحدد.

مهمل

استخدم pacparser_parse_pac_file بدلاً من ذلك.

المعلمات:

pacfile ملف PAC المراد تحليله.

يعيد:

0 عند الفشل و 1 عند النجاح.

نفس وظيفة pacparser_parse_pac_file. مضمن فقط للتوافق مع الإصدارات السابقة.

char* pacparser_find_proxy (const char *url, const char *host)

يجد بروكسي لعنوان URL والمضيف المحددين.

المعلمات:

url عنوان URL للبحث عن بروكسي له.
host جزء المضيف من عنوان URL.

يعيد:

سلسلة البروكسي عند النجاح و NULL عند حدوث خطأ.

يجد بروكسي لعنوان URL والمضيف المحددين. يجب استدعاء هذه الوظيفة فقط بعد تهيئة محرك pacparser (باستخدام pacparser_init) وبعد تحليل نص PAC (باستخدام pacparser_parse_pac_file أو pacparser_parse_pac_string).

char* pacparser_just_find_proxy (const char *pacfile, const char *url, const char *host)

يجد بروكسي لملف PAC وعنوان URL والمضيف المحددين.

المعلمات:

pacfile ملف PAC المراد تحليله.
url عنوان URL للبحث عن بروكسي له.
host جزء المضيف من عنوان URL.

يعيد:

سلسلة البروكسي عند النجاح و NULL عند حدوث خطأ.

هذه الوظيفة هي غلاف لوظائف pacparser_init، pacparser_parse_pac_file، pacparser_find_proxy، و pacparser_cleanup. إذا كنت تريد فقط معرفة البروكسي لمجموعة معينة من ملف PAC وعنوان URL والمضيف، فهذه هي الوظيفة التي يجب استدعاؤها. هذه الوظيفة تعتني بكل التهيئة والتنظيف.

void pacparser_cleanup (void)

يدمر سياق JavaScript. يجب استدعاء هذه الوظيفة بمجرد الانتهاء من استخدام محرك pacparser.

void pacparser_setmyip (const char *ip)

يحدد عنوان IP الخاص بي.

المعلمات:

ip عنوان IP مخصص.

يحدد عنوان IP الخاص بي إلى قيمة مخصصة. هذا هو عنوان IP الذي تعيده وظيفة JavaScript myIpAddress().

void pacparser_set_error_printer (pacparser_error_printerfunc)

يحدد وظيفة طباعة الأخطاء.

المعلمات:

func وظيفة الطباعة.

يحدد وظيفة طباعة الأخطاء ذات الوسائط المتغيرة. إذا لم يتم تعيينها، فسيتم طباعة الرسائل إلى stderr. إذا بدأت الرسائل بـ DEBUG: أو WARNING:، فهي ليست رسائل خطأ كارثية، وإلا فهي كذلك. يمكن استدعاؤها قبل pacparser_init().

void pacparser_enable_microsoft_extensions (void)

(مهمل) تمكين ملحقات Microsoft IPv6 PAC. مهمل. ملحقات IPv6 (وظائف *Ex) ممكّنة افتراضيًا الآن.

char* pacparser_version (void)

يعيد إصدار pacparser.

يعيد:

سلسلة الإصدار إذا تم تعريف الإصدار، '' بخلاف ذلك.

يتم تحديد سلسلة الإصدار في وقت البناء. إذا تم بناؤه من حزمة تم إصدارها، فإن الإصدار يتوافق مع أحدث علامة إصدار (git). إذا تم بناؤه من المستودع، فإنه يتوافق مع آخر مراجعة للمستودع.
