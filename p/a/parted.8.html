parted(8)

الحزمة: parted

التراخيص: GPL3

PARTED(8) دليل GNU Parted PARTED(8)

الاسم

parted - برنامج لمعالجة الأقسام

الملخص

parted [خيارات] [جهاز [أمر [خيارات...]...]]

الوصف

parted هو برنامج لمعالجة أقسام القرص. يدعم تنسيقات متعددة لجدول الأقسام، بما في ذلك MS-DOS و GPT. وهو مفيد لإنشاء مساحة لأنظمة تشغيل جديدة، وإعادة تنظيم استخدام القرص، ونسخ البيانات إلى أقراص صلبة جديدة.

تصف صفحة الدليل هذه parted بإيجاز. يتم توزيع التوثيق الكامل مع الحزمة بتنسيق GNU Info.

الخيارات

-h, --help
يعرض رسالة مساعدة
-l, --list
يسرد تخطيط الأقسام على جميع أجهزة الكتل
-m, --machine
يعرض مخرجات قابلة للتحليل آليًا
-j, --json
يعرض مخرجات JSON
-s, --script
لا يطلب أبدًا تدخل المستخدم
-f, --fix
يجيب تلقائيًا بـ "إصلاح" على الاستثناءات في وضع النصي
-v, --version
يعرض الإصدار
-a نوع-المحاذاة, --align نوع-المحاذاة
تعيين المحاذاة للأقسام التي تم إنشاؤها حديثًا، أنواع المحاذاة الصالحة هي:
none
استخدم الحد الأدنى من المحاذاة التي تسمح بها نوع القرص.
cylinder
محاذاة الأقسام مع الأسطوانات.
minimal
استخدم الحد الأدنى من المحاذاة كما هو معطى من خلال معلومات طوبولوجيا القرص. سيستخدم هذا وقيمة opt معلومات التخطيط التي يوفرها القرص لمحاذاة عناوين جدول الأقسام المنطقية مع كتل فعلية على الأقراص. قيمة min هي الحد الأدنى من المحاذاة المطلوبة لمحاذاة القسم بشكل صحيح مع الكتل المادية، مما يتجنب تدهور الأداء.
optimal
استخدم المحاذاة المثلى كما هو معطى من خلال معلومات طوبولوجيا القرص. هذا يحاذي مضاعف حجم الكتلة المادية بطريقة تضمن الأداء الأمثل.

الأوامر

[device]
جهاز الكتلة المراد استخدامه. عندما لا يتم توفير أي شيء، سيستخدم parted أول جهاز كتلة يجده.
[command [options]]
يحدد الأمر المراد تنفيذه. إذا لم يتم توفير أمر، فسيقدم parted موجه أوامر. الأوامر الممكنة هي:
help [command]
طباعة المساعدة العامة، أو المساعدة حول command إذا تم تحديده.
align-check type partition
تحقق مما إذا كان partition يفي بشرط المحاذاة من type. يجب أن يكون type "minimal" أو "optimal".
mklabel label-type
إنشاء label قرص جديد (جدول أقسام) من label-type. يجب أن يكون label-type أحد "aix", "amiga", "bsd", "dvh", "gpt", "loop", "mac", "msdos", "pc98", أو "sun".
mkpart [part-type name fs-type] start end
إنشاء قسم جديد. يمكن تحديد part-type فقط مع جداول أقسام msdos و dvh، ويجب أن يكون أحد "primary", "logical", أو "extended". name مطلوب لجداول أقسام GPT و fs-type اختياري. يمكن أن يكون fs-type أحد "btrfs", "ext2", "ext3", "ext4", "fat16", "fat32", "hfs", "hfs+", "linux-swap", "ntfs", "reiserfs", "udf", أو "xfs".
name partition name
تعيين اسم partition إلى name. تعمل هذه الخيار فقط على جداول أقراص Mac و PC98 و GPT. يمكن وضع الاسم داخل علامتي اقتباس مزدوجتين، إذا لزم الأمر. واعتمادًا على الشل، قد تحتاج أيضًا إلى وضعه داخل علامتي اقتباس فرديتين حتى لا تزيل الشل علامتي الاقتباس المزدوجتين.
print print-type
عرض جدول الأقسام. print-type اختياري، ويمكن أن يكون أحد devices, free, list, أو all.
quit
الخروج من parted.
rescue start end
استعادة قسم مفقود كان يقع بين start و end. إذا تم العثور على قسم، فسيسأل parted عما إذا كنت تريد إنشاء إدخال له في جدول الأقسام.
resizepart partition end
تغيير موضع end للقسم partition. لاحظ أن هذا لا يعدل أي نظام ملفات موجود في القسم.
rm partition
حذف القسم partition.
select device
اختيار device كجهاز حالي للتعديل. عادة ما يكون device جهاز قرص صلب Linux، ولكنه يمكن أن يكون قسمًا، جهاز RAID برمجي، أو وحدة تخزين منطقية LVM إذا لزم الأمر.
set partition flag state
تغيير حالة flag على partition إلى state. العلامات المدعومة هي: "boot", "root", "swap", "hidden", "raid", "lvm", "lba", "legacy_boot", "irst", "msftres", "esp", "chromeos_kernel", "bls_boot", "linux-home", "no_automount", "bios_grub", و "palo". يجب أن يكون state إما "on" أو "off".
unit unit
تعيين unit كوحدة لاستخدامها عند عرض المواقع والأحجام، ولتفسير تلك التي قدمها المستخدم عندما لا تكون متبوعة بوحدة صريحة. يمكن أن يكون unit أحد "s" (قطاعات)، "B" (بايت)، "kB", "MB", "KiB", "MiB", "GB", "GiB", "TB", "TiB", "%" (نسبة من حجم الجهاز)، "cyl" (أسطوانات)، "chs" (أسطوانات، رؤوس، قطاعات)، أو "compact" (ميجابايت للإدخال، وشكل سهل القراءة للإخراج).
toggle partition flag
تبديل حالة flag على partition.
type partition id or uuid
في MS-DOS، قم بتعيين النوع الملقب. معرف القسم إلى id. id هو قيمة بين "0x01" و "0xff". في GPT، قم بتعيين نوع المعرف uuid للقسم partition إلى uuid.
disk_set flag state
تغيير flag على القرص إلى state. يمكن أن تكون العلامة إما "on" أو "off". قد تكون بعض هذه العلامات أو كلها متاحة، اعتمادًا على label القرص الذي تستخدمه. العلامات المدعومة هي: "pmbr_boot" على GPT لتمكين علامة التمهيد على قسم MBR الواقي لـ GPT.
disk_toggle flag
تبديل حالة الـ

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

parted(8)

NAME

parted

disk partition manipulator

SYNOPSIS

parted [OPTION...] [DEVICE [COMMAND...]]

DESCRIPTION

parted is a utility to manipulate the partition table of a disk. It can create, destroy, resize, move, and print disk partitions and file systems.

When parted is invoked without arguments, it starts an interactive session. In this session, parted understands a basic set of commands.

When parted is invoked with a device name, it operates on that device non-interactively. This is useful for scripting. The commands should be supplied as separate arguments.

parted supports both the older MBR partition table format and the newer GPT format. It can detect the format of a disk and work with it.

OPTIONS

-h, --help
Display a list of commands and exit.
-h, --version [VERSION]
Display version information and exit.
-h, --machine
Output is in a machine readable format.
-h, --script
Execute commands from script, not interactively.

COMMANDS

The following commands are available in the interactive session and for non-interactive use:

about
Display information about parted, including supported file systems and the current version.
align-check part [part ...]
Checks if partition alignment is optimal for the specified partition(s).
break part
Deletes the specified partition from the partition table.
check part
Checks the partition table for errors.
cp [from-file] [to-file]
Copies a partition.
disk [disk-ID]
Sets the target disk.
exit [-reason]
Exits parted. If any unwritten changes are pending, it exits without writing them. If -reason is supplied, it is printed to standard output.
help [command]
Prints general help, or help on the specified command.
mkfs part [fs-type]
Creates a file system on the specified partition.
mklabel [gpt | msdos | bsd | sun | svga0 | loop0]
Creates a new disk label (partition table).
mkpart part [fs-type start end]
Creates a new partition.
move part start end
Moves a partition.
name part name
Sets the name of the partition.
print [disk | free | all]
Prints partition table, free unpartitioned space or all available information.
quit
Exits parted without writing any changes.
rescue start end
Recovers lost partitions.
resizepart part end
Resizes the specified partition.
select part
Selects a disk to work on.
set part flag
Sets or unsets a flag on a partition.
set-name part name
Sets the name of the partition.
toggle part flag
Toggles the specified flag on the disk flag.
version
Display version information and a copyright message.

REPORTING BUGS

Report bugs to <bug-parted@gnu.org>

SEE ALSO

fdisk(8), mkfs(8), The parted program is fully documented in the info(1) format GNU partitioning software manual.
