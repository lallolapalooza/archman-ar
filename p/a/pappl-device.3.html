Structure for custom device URI callbacks.

\n

The papplDeviceURIFuncs structure defines a set of callback functions that can be used to implement custom device URI schemes. A printer application can use this structure to define how PAPPL interacts with a specific type of device.

\n
typedef struct pappl_device_uri_funcs_s {\n    pappl_list_cb_t list_cb;\n    pappl_open_cb_t open_cb;\n    pappl_close_cb_t close_cb;\n    pappl_read_cb_t read_cb;\n    pappl_write_cb_t write_cb;\n    pappl_status_cb_t status_cb;\n    pappl_supplies_cb_t supplies_cb;\n    pappl_id_cb_t id_cb;\n} pappl_device_uri_funcs_t;\n
\n

The list_cb callback is used to discover available devices for the URI scheme. It is optional.

\n

The open_cb callback is used to open a connection to a device and allocate any necessary device-specific data.

\n

The close_cb callback is used to close the connection to a device and free any allocated device-specific data.

\n

The read_cb callback is used to read data from a device.

\n

The write_cb callback is used to write data to a device.

\n

The status_cb callback is used to get basic printer status information from a device. It is optional.

\n

The supplies_cb callback is used to get supply level information from a device. It is optional.

\n

The id_cb callback is used to get the current IEEE-1284 device ID from a device. It is optional.

\n

A custom device URI scheme can be added to PAPPL using the papplAddDeviceURI function, passing a pointer to a populated pappl_device_uri_funcs_t structure.

Add a custom device URI scheme.

\n
bool papplAddDeviceURI (\n    const char *scheme,\n    pappl_devtype_t dtype,\n    pappl_device_uri_funcs_t *funcs\n);\n
\n

This function adds support for a custom device URI scheme. The scheme parameter specifies the URI scheme (e.g., \"x-foo\"). The dtype parameter specifies the device type, which should be PAPPL_DTYPE_CUSTOM_LOCAL for locally connected printers or PAPPL_DTYPE_CUSTOM_NETWORK for network printers. The funcs parameter is a pointer to a pappl_device_uri_funcs_t structure containing the callback functions for the new URI scheme.

\n

Once added, the named scheme can receive print data, report status information, and so forth. PAPPL includes support for the following URI schemes:

\n
    \n
  • dnssd: Network printers discovered using DNS-SD.
    • \n
  • file: Character device files, plain files, and directories.
    • \n
  • snmp: Network printers discovered using SNMPv1.
    • \n
  • socket: Network printers using a hostname or numeric IP address.
    • \n
  • usb: Class 1 (unidirectional) or 2 (bidirectional) USB printers.
    • \n
\n

The \"scheme\" parameter specifies the URI scheme and must consist of lowercase letters, digits, \"-\", \"_\", and/or \".\", for example \"x-foo\" or \"com.example.bar\".

\n

The \"dtype\" parameter specifies the device type and should be PAPPL_DTYPE_CUSTOM_LOCAL for locally connected printers and PAPPL_DTYPE_CUSTOM_NETWORK for network printers.

\n

Each of the callbacks corresponds to one of the papplDevice functions:

\n
    \n
  • \"list_cb\": Implements discovery of devices (optional)
    • \n
  • \"open_cb\": Opens communication with a device and allocates any device-\n
    \n specific data as needed
    • \n
  • \"close_cb\": Closes communication with a device and frees any device-\n
    \n specific data as needed
    • \n
  • \"read_cb\": Reads data from a device
    • \n
  • \"write_cb\": Write data to a device
    • \n
  • \"status_cb\": Gets basic printer state information from a device\n (optional)
    • \n
  • \"supplies_cb\": Gets supply level information from a device\n (optional)
    • \n
  • \"id_cb\": Gets the current IEEE-1284 device ID from a device\n (optional)
    • \n
\n

The \"open_cb\" callback typically calls\n papplDeviceSetData to store a pointer to contextual information for\n the connection while the \"close_cb\", \"id_cb\",\n \"read_cb\", \"write_cb\", \"status_cb\", and\n \"supplies_cb\" callbacks typically call papplDeviceGetData\n to retrieve it.

NAME


pappl-device - PAPPL device functions






LIBRARY


PAPPL (`libpappl.so.2`)







SYNOPSIS


#include <pappl/pappl-device.h>






DESCRIPTION


The PAPPL library provides functions for managing printers and
    devices, including the functions described in this manual page for interacting
    with devices.






ENUMERATIONS





  pappl_devtype_t




  Device type bitfield.









FUNCTIONS




papplDeviceAddScheme


Add a device URI scheme.


bool papplDeviceAddScheme (
    const char *scheme,
    pappl_devtype_t types,
    pappl_devlist_cb_t list_cb,
    pappl_devopen_cb_t open_cb,
    pappl_devid_cb_t id_cb,
    pappl_devclose_cb_t close_cb,
    pappl_devread_cb_t read_cb,
    pappl_devwrite_cb_t write_cb,
    pappl_devstatus_cb_t status_cb,
    pappl_devsupplies_cb_t supplies_cb
);


This function adds support for a new device URI scheme. The
    supported device types are provided by the types argument. The
    callback functions are used by PAPPL to discover, open, identify, and
    communicate with devices using this scheme.






papplDeviceClose


Close a device.


void papplDeviceClose (
    pappl_device_t *device
);


This function closes the specified device connection.






papplDeviceEnum


Enumerate devices.


bool papplDeviceEnum (
    pappl_device_cb_t cb,
    void *data,
    pappl_deverror_cb_t err_cb,
    void *err_data
);


This function enumerates all supported devices and calls the
    provided callback function cb for each device found. The
    callback function receives device information, the device URI, and the device
    ID string, along with the user-provided data pointer.






papplDeviceFlush


Flush device output buffer.


bool papplDeviceFlush (
    pappl_device_t *device
);


This function flushes any buffered data to the device immediately.






papplDeviceGetID


Get device ID string.


const char * papplDeviceGetID (
    pappl_device_t *device
);


This function returns the device ID string for the specified
    device.






papplDeviceGetMetrics


Get device metrics.


pappl_devmetrics_t * papplDeviceGetMetrics (
    pappl_device_t *device
);


This function returns a pointer to the device metrics structure for
    the specified device.






papplDeviceGetName


Get device name.


const char * papplDeviceGetName (
    pappl_device_t *device
);


This function returns the name of the specified device.






papplDeviceGetTransportName


Get device transport name.


const char * papplDeviceGetTransportName (
    pappl_device_t *device
);


This function returns the transport name (e.g., "usb", "tcp",
    "dnssd") for the specified device.






papplDeviceGetURI


Get device URI.


const char * papplDeviceGetURI (
    pappl_device_t *device
);


This function returns the URI for the specified device.






papplDeviceOpen


Open a device.


pappl_device_t * papplDeviceOpen (
    const char *device_uri,
    const char *name,
    pappl_deverror_cb_t err_cb,
    void *err_data
);


This function opens the device specified by device_uri
    and returns a pointer to a pappl_device_t structure representing
    the open device. The name parameter can be used to provide a
    human-readable name for the device.






papplDeviceRead


Read from a device.


ssize_t  papplDeviceRead (
    pappl_device_t *device,
    void *buffer,
    size_t bytes
);


This function reads data from the device. Depending on the device,
    this function may block indefinitely.






papplDeviceRemoveScheme


Remove the named device URI scheme.


void papplDeviceRemoveScheme (
    const char *scheme
);


This function removes support for the named device URI scheme. Use
    only when you want to disable a URI scheme for security or functional
    reasons, for example to disable the "file" URI scheme.






papplDeviceRemoveTypes


Remove device URI schemes of the specified types.


void papplDeviceRemoveTypes (
    pappl_devtype_t types
);


This function removes device URI schemes of the specified types.
    Use only when you want to disable URI schemes for security or functional
    reasons, for example to disable all network URI schemes.






papplDeviceSetData


Set device-specific data.


void papplDeviceSetData (
    pappl_device_t *device,
    void *data
);


This function sets any device-specific data needed to communicate
    with the device. It is normally only called from the open callback that was
    registered for the device URI scheme.






papplDeviceWrite


Write to a device.


ssize_t  papplDeviceWrite (
    pappl_device_t *device,
    const void *buffer,
    size_t bytes
);


This function buffers data that will be sent to the device. Call
    the papplDeviceFlush function to ensure that the data is immediately
    sent to the device.
