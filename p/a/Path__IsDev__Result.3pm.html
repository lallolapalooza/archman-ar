Path__IsDev__Result(3pm)

الحزمة: perl-path-isdev

التراخيص: PerlArtistic

Path::IsDev::Result(3) وثائق Perl المساهمة من قبل المستخدم Path::IsDev::Result(3)

الاسم

Path::IsDev::Result - حاوية النتائج

الإصدار

version 1.001003

الملخص

use Path::IsDev::Result;
my $result = Path::IsDev::Result->new( path => '/some/path/that/exists' ):
if ( $heuristcset->matches( $result ) ) {
    print Dumper($result);
}

الوصف

هذا مكون داخلي جديد نسبيًا لـ Path::IsDev.

الغرض منه هو توصيل الحالة بين الأشياء الداخلية، وإعطاء نوع من السياق القابل للفحص حول سبب حدوث الأشياء في أماكن مختلفة دون اللجوء إلى طباعة رسائل التصحيح في كل مكان.

الآن بدلاً من تفعيل وضع التصحيح، طالما يمكنك الحصول على نتيجة، يمكنك فحص تلك النتيجة وطباعتها في النقطة التي تحتاجها.

الطرق

"BUILD"

"add_reason"

استدعِ هذه الطريقة من أسلوب لفحص الأسلوب وبيانات التعريف ذات الصلة.

$result->add_reason( $heuristic, $matchvalue, $reason_summary, \%contextinfo );

على سبيل المثال:

sub Foo::matches  {
    my ( $self , $result_object ) = @_;
    if ( $result_object->path->child('bar')->exists ) {
        $result_object->add_reason( $self, 1, "child 'bar' exists" , {
            child => 'bar',
            'exists?' => 1,
            child_path => $result_object->path->child('bar')
        });
        $result_object->result(1);
        return 1;
    }
    return;
}

لاحظ هنا أن $matchvalue يجب أن يكون نتيجة منطق المطابقة ذي الصلة، وليس التأثير العام.

على سبيل المثال، تراكيب "excludes" لا تزال بحاجة إلى إضافة أسباب "$matchvalue == 1"، ولكن لا ينبغي لها تعيين "$result_object->result(1)". (في الواقع، تعيين "result" هو عمل الأسلوب الفردي، وليس المطابقات التي تم دمجها فيه)
