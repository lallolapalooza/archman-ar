pam_succeed_if(8)

الحزمة: pam

التراخيص: GPL-2.0-only

PAM_SUCCEED_IF(8) دليل Linux-PAM PAM_SUCCEED_IF(8)

الاسم

pam_succeed_if - اختبار خصائص الحساب

المُلَخَّص

pam_succeed_if.so [علامة...] [شرط...]

الوصف

تم تصميم pam_succeed_if.so للنجاح أو الفشل في المصادقة بناءً على خصائص الحساب الخاص بالمستخدم الذي تتم مصادقته أو قيم عناصر PAM الأخرى. أحد الاستخدامات هو اختيار ما إذا كان سيتم تحميل وحدات أخرى بناءً على هذا الاختبار.

يجب تزويد الوحدة بشرط واحد أو أكثر كوسائط للوحدة، ولن تنجح المصادقة إلا إذا تم استيفاء جميع الشروط.

خيارات

العلامات التالية مدعومة:

debug

يقوم بتشغيل رسائل التصحيح المرسلة إلى syslog.

use_uid

تقييم الشروط باستخدام حساب المستخدم الذي يعمل التطبيق تحت UID الخاص به بدلاً من المستخدم الذي تتم مصادقته.

quiet

لا تقم بتسجيل الفشل أو النجاح في سجل النظام.

quiet_fail

لا تقم بتسجيل الفشل في سجل النظام.

quiet_success

لا تقم بتسجيل النجاح في سجل النظام.

audit

تسجيل المستخدمين غير المعروفين في سجل النظام.

الشروط ثلاث كلمات: حقل، اختبار، وقيمة للاختبار من أجلها.

الحقول المتاحة هي user، uid، gid، shell، home، ruser، rhost، tty و service:

field < number

الحقل له قيمة أقل عدديًا من number.

field <= number

الحقل له قيمة أقل أو تساوي عدديًا number.

field eq number

الحقل له قيمة تساوي عدديًا number.

field >= number

الحقل له قيمة أكبر أو تساوي عدديًا number.

field > number

الحقل له قيمة أكبر عدديًا من number.

field ne number

الحقل له قيمة مختلفة عدديًا عن number.

field = string

الحقل يطابق السلسلة المعطاة بالضبط.

field != string

الحقل لا يطابق السلسلة المعطاة.

field =~ glob

الحقل يطابق النمط العام المعطى.

field !~ glob

الحقل لا يطابق النمط العام المعطى.

field in item:item:...

الحقل مدرج في قائمة العناصر مفصولة بنقطتين رأسيتين.

field notin item:item:...

الحقل غير مدرج في قائمة العناصر مفصولة بنقطتين رأسيتين.

user ingroup group[:group:....]

المستخدم موجود في المجموعة (المجموعات) المعطاة.

user notingroup group[:group:....]

المستخدم غير موجود في المجموعة (المجموعات) المعطاة.

user innetgr netgroup

(user,host) موجود في netgroup المعطى.

user notinnetgr group

(user,host) غير موجود في netgroup المعطى.

أنواع الوحدات النمطية المقدمة

جميع أنواع الوحدات النمطية (account، auth، password و session) مقدمة.

قيم الإرجاع

PAM_SUCCESS

كان الشرط صحيحًا.

PAM_AUTH_ERR

كان الشرط خاطئًا.

PAM_SERVICE_ERR

حدث خطأ في الخدمة أو لا يمكن تحليل الوسائط بشكل صحيح.

أمثلة

لتقليد سلوك pam_wheel، باستثناء عدم وجود بديل للمجموعة 0 الذي يتم تقريبه فقط عن طريق التحقق أيضًا من عضوية مجموعة الجذر:

auth required pam_succeed_if.so quiet user ingroup wheel:root

نظرًا لتطابق النوع، فإنه يقوم فقط بتحميل قاعدة othermodule إذا كان UID أكبر من 500. اضبط الرقم بعد default لتخطي عدة قواعد.

type [default=1 success=ignore] pam_succeed_if.so quiet uid > 500
type required othermodule.so arguments...
