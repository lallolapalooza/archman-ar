parent(3perl) دليل مبرمجي بيرل parent(3perl)

الاسم

parent - إنشاء علاقة وراثة مع الفئات الأساسية في وقت الترجمة

الملخص

package Baz;
use parent qw(Foo Bar);

الوصف

يسمح لك بتحميل وحدات نمطية متعددة، مع إعداد الوراثة من تلك الوحدات في نفس الوقت. تأثيره مشابه جدًا لـ

package Baz;
BEGIN {
    require Foo;
    require Bar;
    push @ISA, qw(Foo Bar);
}

افتراضيًا، تحتاج كل فئة أساسية إلى العيش في ملف خاص بها. إذا كنت ترغب في الحصول على فئة فرعية وفئتها الأساسية في نفس الملف، يمكنك إخبار "parent" بعدم تحميل أي وحدات نمطية باستخدام الخيار "-norequire":

package Foo;
sub exclaim { "I CAN HAS PERL" }
package DoesNotLoadFooBar;
use parent -norequire, 'Foo', 'Bar';
# لن يبحث عن Foo.pm أو Bar.pm

هذا يعادل الكود التالي:

package Foo;
sub exclaim { "I CAN HAS PERL" }
package DoesNotLoadFooBar;
push @DoesNotLoadFooBar::ISA, 'Foo', 'Bar';

هذا مفيد أيضًا في حالة وجود فئة نمطية في ملف ذي اسم مختلف:

package MyHash;
use Tie::Hash;
use parent -norequire, 'Tie::StdHash';

هذا يعادل الكود التالي:

package MyHash;
require Tie::Hash;
push @ISA, 'Tie::StdHash';

إذا كنت ترغب في تحميل فئة فرعية من ملف لا يعتبره "require" اسم ملف مؤهل (أي أنه لا ينتهي بـ ".pm" أو ".pmc")، استخدم الكود التالي:

package MySecondPlugin;
require './plugins/custom.plugin'; # يحتوي على Plugin::Custom
use parent -norequire, 'Plugin::Custom';
