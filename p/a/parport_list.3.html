parport_list(3)

الحزمة: libieee1284

التراخيص: GPL-2.0-or-later

PARPORT_LIST(3) هياكل PARPORT_LIST(3)

الاسم

parport_list - مجموعة من منافذ المتوازي

الملخص

#include <ieee1284.h>

الوصف

هيكل parport_list هو مجرد متجه من هياكل parport.

أعضاء الهيكل

يحتوي الهيكل على الأعضاء التالية:

struct parport_list {
  /* عدد العناصر في المتجه. */
  int portc;
  /* المنافذ. */
  struct parport **portv;
};
