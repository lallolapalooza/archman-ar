pam_vsyslog(3)

الحزمة: pam

التراخيص: GPL-2.0-only

PAM_SYSLOG(3) دليل Linux-PAM PAM_SYSLOG(3)

الاسم

pam_syslog, pam_vsyslog - إرسال الرسائل إلى مسجل النظام

ملخص

#include <syslog.h>
#include <security/pam_ext.h>

void pam_syslog(const pam_handle_t *pamh, int priority, const char *fmt, ...);

void pam_vsyslog(const pam_handle_t *pamh, int priority, const char *fmt, va_list args);

الوصف

تقوم الدالة pam_syslog بتسجيل الرسائل باستخدام syslog(3) وهي مخصصة للاستخدام الداخلي بواسطة Linux-PAM ووحدات خدمة PAM. يتم تشكيل الوسيط priority عن طريق ORing قيم facility والمستوى كما هو موثق في صفحة دليل syslog(3).

تقوم الدالة pam_vsyslog بنفس مهمة pam_syslog() مع الاختلاف أنها تأخذ مجموعة من الوسائط التي تم الحصول عليها باستخدام وحدات ماكرو قائمة الوسائط المتغيرة stdarg(3).

pam(8)

المعايير

وظائف pam_syslog و pam_vsyslog هي امتدادات لـ Linux-PAM.
