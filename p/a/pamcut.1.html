NAME

pamcut - cut out rectangular regions from PAM images

SYNOPSIS

pamcut [options] [file...]

DESCRIPTION

pamcut reads one or more PAM images as input, and cuts out one or more rectangular regions from each image, writing the resulting images to standard output.

The regions to be cut out are specified by options. If multiple regions are specified, pamcut produces a separate output image for each region.

The input images must all be in PAM format. If the input images are not in PAM format, you can convert them to PAM using pamtopam.

The output images are also in PAM format.

OPTIONS

The following options are available:

-top-left-x=X

The x-coordinate of the top-left corner of the region to cut out. The default is 0.

-top-left-y=Y

The y-coordinate of the top-left corner of the region to cut out. The default is 0.

-width=W

The width of the region to cut out. The default is the width of the input image.

-height=H

The height of the region to cut out. The default is the height of the input image.

-columns=C

The number of columns to cut out. This is an alternative to -width.

-rows=R

The number of rows to cut out. This is an alternative to -height.

-pixels=P

The number of pixels to cut out. This is an alternative to -columns and -rows.

-index=I

The index of the region to cut out. This is an alternative to specifying the coordinates and dimensions. The index is 0-based.

-verbose

Print information about the operation to standard error.

-quiet

Suppress all output to standard error.

-help

Print a help message and exit.

-version

Print version information and exit.

EXAMPLES

Cut out a 100x50 region from the top-left corner of input.pam: 

pamcut -width=100 -height=50 input.pam > output.pam

Cut out a region starting at x=20, y=30 with a width of 80 and a height of 60 from input.pam: 

pamcut -top-left-x=20 -top-left-y=30 -width=80 -height=60 input.pam > output.pam

Cut out the 5th region (index 4) from input.pam: 

pamcut -index=4 input.pam > output.pam
