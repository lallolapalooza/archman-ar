NAME

partclone.fat16

clone FAT16 file system

SYNOPSIS

partclone.fat16 [-c|-r] [-d] [-s source] [-o output]

DESCRIPTION

partclone.fat16 is a tool that allows you to clone, save and restore any file system like a Clonezilla. This tool copies the used blocks of the file system. So it is faster than dd if the file system is not full.

The file system supported by partclone.fat16 are FAT16.

Only the used blocks will be copied. This means it is possible to save a larger partition to a smaller partition, as long as the source is not full.

It also supports the compressed image format which Clonezilla uses. This can save disk space.

OPTIONS

-c, --clone
Clone the file system. Save the file system to an image file.

-r, --restore
Restore the file system. Clone an image file back to the partition.

-d, --debug
Enable debug information output.

-s, --source source
The source partition or image file. Use '-' for stdin.

-o, --output output
The output partition or image file. Use '-' for stdout.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.

الاسم

partclone.fat16

استنساخ نظام ملفات FAT16

الملخص

partclone.fat16 [-c|-r] [-d] [-s المصدر] [-o الخرج]

الوصف

partclone.fat16 هي أداة تسمح لك باستنساخ وحفظ واستعادة أي نظام ملفات مثل Clonezilla. هذه الأداة تنسخ الكتل المستخدمة من نظام الملفات. لذلك فهي أسرع من dd إذا لم يكن نظام الملفات ممتلئًا.

أنظمة الملفات التي يدعمها partclone.fat16 هي FAT16.

سيتم نسخ الكتل المستخدمة فقط. هذا يعني أنه من الممكن حفظ قسم أكبر في قسم أصغر، طالما أن المصدر غير ممتلئ.

كما أنها تدعم تنسيق الصورة المضغوطة الذي تستخدمه Clonezilla. هذا يمكن أن يوفر مساحة القرص.

الخيارات

-c, --clone
استنساخ نظام الملفات. حفظ نظام الملفات إلى ملف صورة.

-r, --restore
استعادة نظام الملفات. استنساخ ملف صورة مرة أخرى إلى القسم.

-d, --debug
تمكين إخراج معلومات التصحيح.

-s, --source المصدر
القسم المصدر أو ملف الصورة. استخدم '-' لـ stdin.

-o, --output الخرج
القسم المصدر أو ملف الصورة. استخدم '-' لـ stdout.

الملفات

/var/log/partclone.log

ملف السجل الخاص بـ partclone

أمثلة

 استنساخ /dev/hda1 إلى hda1.img وعرض معلومات التصحيح.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 استعادة /dev/hda1 من hda1.img وعرض معلومات التصحيح.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 استعادة صورة من clonezilla (مقسمة، مضغوطة،) مع مصدر stdin
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

التشخيص

قد تصدر التشخيصات التالية على stderr:

يوفر partclone بعض رموز الإرجاع، والتي يمكن استخدامها في البرامج النصية:

الكود التشخيص
0 انتهى البرنامج بنجاح.
1 يبدو أن الاستنساخ أو الاستعادة فشلت.
