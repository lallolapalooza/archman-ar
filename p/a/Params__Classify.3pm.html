Params::Classify(3pm) توثيق Perl المساهم به من قبل المستخدم Params::Classify(3pm)

الاسم

Params::Classify - تصنيف أنواع الوسائط

الملخص

use Params::Classify qw(
    scalar_class
    is_undef check_undef
    is_string check_string
    is_number check_number
    is_glob check_glob
    is_regexp check_regexp
    is_ref check_ref ref_type
    is_blessed check_blessed blessed_class
    is_strictly_blessed check_strictly_blessed
    is_able check_able);
$c = scalar_class($arg);
if(is_undef($arg)) {
check_undef($arg);
if(is_string($arg)) {
check_string($arg);
if(is_number($arg)) {
check_number($arg);
if(is_glob($arg)) {
check_glob($arg);
if(is_regexp($arg)) {
check_regexp($arg);
if(is_ref($arg)) {
check_ref($arg);
$t = ref_type($arg);
if(is_ref($arg, "HASH")) {
check_ref($arg, "HASH");
if(is_blessed($arg)) {
check_blessed($arg);
if(is_blessed($arg, "IO::Handle")) {
check_blessed($arg, "IO::Handle");
$c = blessed_class($arg);
if(is_strictly_blessed($arg, "IO::Pipe::End")) {
check_strictly_blessed($arg, "IO::Pipe::End");
if(is_able($arg, ["print", "flush"])) {
check_able($arg, ["print", "flush"]);

الوصف

توفر هذه الوحدة وظائف مختلفة لاختبار النوع. هذه مخصصة للدوال التي، على عكس معظم أكواد Perl، تهتم بنوع البيانات التي تعمل عليها. على سبيل المثال، ترغب بعض الدوال في التصرف بشكل مختلف اعتمادًا على نوع وسائطها (مثل الدوال المتجاوزة في C++).

هناك نكهتان من الدوال في هذه الوحدة. الدوال من النكهة الأولى توفر فقط تصنيف النوع، للسماح للكود بالتمييز بين أنواع الوسائط. الدوال من النكهة الثانية تجمع بين النوع الأكثر شيوعًا من التمييز بين الأنواع: التحقق من أن الوسيط هو من النوع المتوقع. تأتي الدوال في أزواج متطابقة، من النكهتين، وبالتالي تتعامل دوال الإنفاذ مع المتطلبات الأبسط فقط للوسائط من الأنواع التي تغطيها دوال التصنيف. يمكن، بالطبع، بناء إنفاذ أنواع أكثر تعقيدًا باستخدام دوال التصنيف، أو قد يكون من الأنسب استخدام وحدة مصممة للمهمة الأكثر تعقيدًا، مثل Params::Validate.

تم تنفيذ هذه الوحدة في XS، مع نسخة Perl نقية احتياطية للأنظمة التي لا يمكنها التعامل مع XS.

تصنيف النوع

تقسم هذه الوحدة القيم العددية إلى الفئات التالية:

  • undef
  • سلسلة نصية (قيمة عددية عادية محددة)
  • typeglob (نعم، typeglobs مناسبة للمتغيرات العددية)
  • تعبير نمطي (كائنات تعبير نمطي من الدرجة الأولى في Perl 5.11 فصاعدًا)
  • مرجع إلى كائن غير مبارك (يتم تصنيفه بشكل أكبر حسب نوع البيانات الفعلي للكائن المشار إليه)
  • مرجع إلى كائن مبارك (يتم تصنيفه بشكل أكبر حسب الفئة التي تم مباركته إليها)

هذه الفئات متبادلة وغير متداخلة ويجب أن تكون شاملة. تم اختيار هذا التصنيف ليكون الأكثر فائدة عندما يرغب المرء في التمييز بين أنواع القيم العددية. تصنيفات أخرى ممكنة. (على سبيل المثال، يتم تمييز فئتي المراجع بميزة في الكائن المشار إليه؛ Perl لا يعامل هذا داخليًا كميزة للمرجع.)

الدوال

تأخذ كل من هذه الدوال وسيطًا عدديًا واحدًا (ARG) ليتم اختباره، ربما مع وسائط أخرى تحدد تفاصيل الاختبار. أي قيمة عددية مقبولة للوسيط ليتم اختباره. كل دالة "is_" تُرجع نتيجة قيمة حقيقية بسيطة، تكون صحيحة إذا كان ARG من النوع الذي يتم التحقق منه. كل دالة "check_" تُرجع بشكل طبيعي إذا كان الوسيط من النوع الذي يتم التحقق منه، أو سوف "die" إذا لم يكن كذلك.

التصنيف

scalar_class(ARG)
يحدد أي من الفئات الخمس الموصوفة أعلاه يندرج فيها ARG. يُرجع "UNDEF"، "STRING"، "GLOB"، "REGEXP"، "REF"، أو "BLESSED" وفقًا لذلك.

القيمة غير المحددة

is_undef(ARG)
check_undef(ARG)
تحقق مما إذا كان ARG هو "undef". is_undef(ARG) يعادل تمامًا "!defined(ARG)"، ويتم تضمينه للاكتمال.

السلاسل النصية

is_string(ARG)
check_string(ARG)
تحقق مما إذا كان ARG محددًا وهو قيمة عددية عادية (ليست مرجعًا، أو typeglob، أو تعبيرًا نمطيًا). هذا ما يفكر فيه المرء عادة كسلسلة نصية في Perl. في الواقع، يمكن تحويل أي قيمة عددية (بما في ذلك "undef" والمراجع) إلى سلسلة نصية، ولكن إذا كنت تحاول تصنيف قيمة عددية، فأنت لا ترغب في القيام بذلك.
is_number(ARG)
check_number(ARG)
تحقق مما إذا كان ARG محددًا وقيمة عددية عادية (أي، يفي بـ "is_string" أعلاه) وهو رقم مقبول لـ Perl. هذا ما يفكر فيه المرء عادة كرقم.

لاحظ أن القيم العددية البسيطة (التي تفي بـ "is_string") قد تحتوي على قيم رقمية وسلسلة نصية مستقلة، على الرغم من الادعاء المعتاد بأنها تحتوي على قيمة واحدة فقط. تعتبر مثل هذه القيمة العددية رقمًا إذا كانت قيمتها الرقمية موجودة بالفعل (على سبيل المثال، تم إنشاؤها بواسطة حرف رقمي أو حساب حسابي) أو إذا كان نص قيمتها يحتوي على صيغة مقبولة لرقم (بحيث يمكن تحويله). حيث تحتوي قيمة عددية على قيم رقمية وسلسلة نصية منفصلة (انظر "dualvar" في Scalar::Util)، فمن الممكن أن يكون لها قيمة رقمية مقبولة بينما نص قيمتها لا يحتوي على صيغة رقمية مقبولة. كن حذرًا في استخدام مثل هذه القيمة في سياق رقمي فقط، إذا كنت تستخدمها كرقم. "scalar_num_part" في Scalar::Number يستخرج الجزء الرقمي لقيمة عددية كرقم عادي. ( "0+ARG" يكفي لذلك ما لم تكن بحاجة إلى الحفاظ على الأصفار ذات الإشارة في نقطة عائمة.)

يمكن أن يكون الرقم إما عددًا صحيحًا أصليًا أو قيمة نقطة عائمة أصلية، وهناك العديد من الأنواع الفرعية لقيمة النقطة العائمة. للتصنيف، والتعامل الآخر مع الأرقام في القيم العددية، انظر Scalar::Number. لتفاصيل نوعي البيانات الرقميين، انظر Data::Integer و Data::Float.

تختلف هذه الدالة عن "looks_like_number" (انظر "looks_like_number" في Scalar::Util؛ أيضًا "looks_like_number" في perlapi لوصف على مستوى أدنى) في استثناء "undef"، typeglobs، والمراجع. سبب إرجاع "looks_like_number" لقيم صحيحة لـ "undef" أو typeglobs هو أمر غامض. المراجع، إذا تم التعامل معها كأرقام، تُقيم إلى العنوان في الذاكرة الذي تشير إليه؛ هذا مفيد لمقارنة المراجع من حيث المساواة، ولكنه ليس مفيدًا بخلاف ذلك لمعاملة المراجع كأرقام. قد تحتوي المراجع المباركة على عوامل تشغيل رقمية متجاوزة، ولكن إذا كان الأمر كذلك، فإنها لا تتصرف بالضرورة مثل الأرقام العادية. "looks_like_number" مرتبك أيضًا بواسطة dualvars: فهو ينظر إلى الجزء النصي من القيمة العددية.

Typeglobs

is_glob(ARG)
check_glob(ARG)
تحقق مما إذا كان ARG هو typeglob.

Regexps

Params::Classify(3pm)

NAME

Params::Classify - determine the type of arguments passed to your subroutines

SYNOPSIS

 use Params::Classify qw(:all);

 sub my_sub {
  my ($arg1, $arg2) = @_;

  check_string($arg1);
  check_arrayref($arg2);

  if (is_blessed($arg1, 'Some::Class')) {
   ...
  }
 }

DESCRIPTION

This module provides a set of functions that allow you to check the type of arguments passed to your subroutines. It is particularly useful for implementing argument checking in object-oriented code, and for parsing complex argument lists.

All functions are exported by default, unless you import specific functions, or import nothing.

 use Params::Classify qw(is_string check_string);
 use Params::Classify qw(:types); # Imports is_string, is_arrayref, etc.
 use Params::Classify qw(:checks); # Imports check_string, check_arrayref, etc.
 use Params::Classify qw(:all);    # Imports all functions
 use Params::Classify;             # Imports nothing. Call functions as
                                  # Params::Classify::is_string(...)

The functions generally come in two flavours: a predicate function starting with "is_", which returns true or false, and a checking function starting with "check_", which throws an exception if the check fails.

In addition to the basic types, the module can also check for references to blessed objects, and references to unblessed objects.

TYPE CLASSIFICATION

The functions in this module classify arguments in the following way:

SCALAR
References to scalars. Note that this includes references to references, and references to arrays and hashes that have been aliased to scalars.
ARRAY
References to arrays.
HASH
References to hashes.
CODE
References to subroutines.
FORMAT
References to format strings.
GLOB
References to symbol table entries (globs).
Regexp
References to regular expression match objects.
Unblessed
References to objects that have not been blessed.
Blessed
References to objects that have been blessed.
String
Plain scalars that are strings.
Number
Plain scalars that are numbers.
Integer
Plain scalars that are integers.
Boolean
Plain scalars that are true or false.
Undef
The undefined value.

FUNCTIONS

Scalar types

is_scalar(ARG)
check_scalar(ARG)
Check whether ARG is a reference to a scalar value.
is_string(ARG)
check_string(ARG)
Check whether ARG is a scalar value that is a string.
is_number(ARG)
check_number(ARG)
Check whether ARG is a scalar value that is a number.
is_integer(ARG)
check_integer(ARG)
Check whether ARG is a scalar value that is an integer.
is_boolean(ARG)
check_boolean(ARG)
Check whether ARG is a scalar value that is true or false.
is_undef(ARG)
check_undef(ARG)
Check whether ARG is the undefined value.

Array and Hash References

is_arrayref(ARG)
check_arrayref(ARG)
Check whether ARG is an array reference.
is_hashref(ARG)
check_hashref(ARG)
Check whether ARG is a hash reference.

Code References

is_coderef(ARG)
check_coderef(ARG)
Check whether ARG is a code reference.

Glob References

is_glob(ARG)
check_glob(ARG)
Check whether ARG is a glob reference.

Regexp References

is_regexp(ARG)
check_regexp(ARG)
Check whether ARG is a regexp object.

References to Unblessed Objects

is_ref(ARG)
check_ref(ARG)
Check whether ARG is a reference to an unblessed object. If it is, then the referenced data type can be determined using "ref_type" (see below), which will return a string such as "HASH" or "SCALAR".
ref_type(ARG)
Returns "undef" if ARG is not a reference to an unblessed object. Otherwise, determines what type of object is referenced. Returns "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", or "IO" accordingly.

Note that, unlike "ref", this does not distinguish between different types of referenced scalar. A reference to a string and a reference to a reference will both return "SCALAR". Consequently, what "ref_type" returns for a particular reference will not change due to changes in the value of the referent, except for the referent being blessed.

is_ref(ARG, TYPE)
check_ref(ARG, TYPE)
Check whether ARG is a reference to an unblessed object of type TYPE, as determined by "ref_type". TYPE must be a string. Possible TYPEs are "SCALAR", "ARRAY", "HASH", "CODE", "FORMAT", and "IO".

References to Blessed Objects

is_blessed(ARG)
check_blessed(ARG)
Check whether ARG is a reference to a blessed object. If it is, then the class into which the object was blessed can be determined using "blessed_class".
is_blessed(ARG, CLASS)
check_blessed(ARG, CLASS)
Check whether ARG is a reference to a blessed object that claims to be an instance of CLASS (via its "isa" method; see "isa" in perlobj). CLASS must be a string, naming a Perl class.
blessed_class(ARG)
Returns "undef" if ARG is not a reference to a blessed object. Otherwise, returns the class into which the object is blessed.

"ref" (see "ref" in perlfunc) gives the same result on references to blessed objects, but different results on other types of value. "blessed_class" is actually identical to "blessed" in Scalar::Util.

is_strictly_blessed(ARG)
check_strictly_blessed(ARG)
Check whether ARG is a reference to a blessed object, identically to "is_blessed". This exists only for symmetry; the useful form of "is_strictly_blessed" appears below.
is_strictly_blessed(ARG, CLASS)
check_strictly_blessed(ARG, CLASS)
Check whether ARG is a reference to an object blessed into CLASS exactly. CLASS must be a string, naming a Perl class. Because this excludes subclasses, this is rarely what one wants, but there are some specialised occasions where it is useful.
is_able(ARG)
check_able(ARG)
Check whether ARG is a reference to a blessed object, identically to "is_blessed". This exists only for symmetry; the useful form of "is_able" appears below.
is_able(ARG, METHODS)
check_able(ARG, METHODS)
Check whether ARG is a reference to a blessed object that claims to implement the methods specified by METHODS (via its "can" method; see "can" in perlobj). METHODS must be either a single method name or a reference to an array of method names. Each method name is a string. This interface check is often more appropriate than a direct ancestry check (such as "is_blessed" performs).

BUGS

Probably ought to handle something like Params::Validate's scalar type specification system, which makes much the same distinctions.
