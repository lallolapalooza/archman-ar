NAME

partclone.vfat — clone a partition of FAT filesystem

SYNOPSIS

partclone.vfat [-c] [-R] [-s source] [-o output] [-d]

DESCRIPTION

The partclone.vfat utility is used to save and restore a partition of FAT filesystem. FAT filesystem is commonly used in DOS, Windows (FAT12, FAT16, FAT32, exFAT) and some other systems.

The command is the same as partclone(8), but it is specialized for FAT filesystem.

partclone.vfat can clone the partition and save it to a file, or restore the partition from a saved image file.

The program supports the following features:

  • Clone partition to image file.
  • Restore partition from image file.
  • Clone partition to partition.
  • Support gzip, bzip2, lzo, etc compression.
  • Support split image file.

OPTIONS

The options are the same as partclone(8). See partclone(8) for details.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 Clone FAT partition /dev/hda1 to hda1.img and display debug information.
   partclone.vfat -c -d -s /dev/hda1 -o hda1.img
 Restore FAT partition /dev/hda1 from hda1.img and display debug information.
   partclone.vfat -r -d -s hda1.img -o /dev/hda1
 Restore FAT image from clonezilla (split, gzip,) with stdin source
   cat sda1.vfat-ptcl-img.gz.a* | gunzip -c | partclone.vfat -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
