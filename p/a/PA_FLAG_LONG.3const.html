الوصف

تخدم هذه الوظائف لتوسيع و/أو تعديل سلوك عائلة وظائف printf(3).

register_printf_specifier()

تقوم هذه الوظيفة بتسجيل محدد تحويل مخصص لعائلة وظائف printf(3).

spec
الحرف الذي سيتم استخدامه كمحدد تحويل في سلسلة التنسيق.
func
دالة استدعاء سيتم تنفيذها بواسطة عائلة وظائف printf(3) لتنسيق وسائط الإدخال في تدفق الإخراج stream.
stream
تدفق الإخراج حيث يجب طباعة الإخراج المنسق. يمثل هذا التدفق الإخراج بشفافية، حتى في حالة الوظائف التي تكتب إلى سلسلة.
info
بنية تحتفظ بمعلومات السياق، بما في ذلك المعدلات المحددة في سلسلة التنسيق. تحتوي هذه على نفس محتويات بنية arginfo.
args
مصفوفة من المؤشرات إلى الوسائط لوظيفة تشبه printf(3).
arginfo
دالة استدعاء سيتم تنفيذها بواسطة عائلة وظائف printf(3) لمعرفة عدد الوسائط التي يجب تحليلها للمحدد المخصص وأنواعها أيضًا.
info
بنية تحتفظ بمعلومات السياق، بما في ذلك المعدلات المحددة في سلسلة التنسيق. تحتوي هذه على نفس محتويات دالة func.
n
عدد الوسائط المتبقية للتحليل.
argtypes
يجب تعيين هذه المصفوفة لتحديد نوع كل من الوسائط التي سيتم تحليلها. يمثل كل عنصر في المصفوفة أحد الوسائط المراد تحليلها، بنفس الترتيب الذي يتم تمريرها به إلى وظيفة تشبه printf(3). يجب تعيين كل عنصر إلى نوع أساسي (PA_*) من التعداد أعلاه، أو نوع مخصص، ويتم تركيبه اختياريًا مع معدل طول مناسب (PA_FLAG_*).

يتم تحديد النوع باستخدام أحد الثوابت التالية:

PA_INT
int.
PA_CHAR
int، تم تحويله إلى char.
PA_WCHAR
wchar_t.
PA_STRING
const char *، سلسلة منتهية بـ '\0'.
PA_WSTRING
const wchar_t *، سلسلة أحرف واسعة منتهية بـ L'\0'.
PA_POINTER
void *.
PA_FLOAT
float.
PA_DOUBLE
double.
PA_LAST
TODO.
size
بالنسبة للأنواع المعرفة من قبل المستخدم، يجب أيضًا تحديد حجم النوع (بالبايت) من خلال هذه المصفوفة. بخلاف ذلك، اتركها غير مستخدمة.

يتم استدعاء arginfo قبل func، ويقوم بإعداد بعض المعلومات اللازمة لاستدعاء func.

قيمة الإرجاع

register_printf_specifier() و register_printf_modifier() و register_printf_type() ترجع صفرًا عند النجاح، أو -1 عند حدوث خطأ.

دوال الاستدعاء

يجب أن ترجع دالة الاستدعاء من نوع printf_function عدد الأحرف التي تم كتابتها، أو -1 عند حدوث خطأ.

يجب أن ترجع دالة الاستدعاء من نوع printf_arginfo_size_function عدد الوسائط المراد تحليلها بواسطة هذا المحدد. كما أنها تمرر معلومات حول نوع تلك الوسائط إلى المتصل عبر argtypes. عند حدوث خطأ، يجب أن ترجع -1.

الأخطاء

EINVAL
لم يكن المحدد حرفًا صالحًا.

NAME

PA_FLAG_LONG - Long flag

LIBRARY

libpulse (part of PulseAudio)

SYNOPSIS

#define PA_FLAG_LONG 0x00000001

DESCRIPTION

The PA_FLAG_LONG flag is used in the pulseaudio_client library to indicate that a given flag is a long flag (e.g. --long-option).

RETURN VALUE

This is a preprocessor macro, it does not return a value.

HISTORY
