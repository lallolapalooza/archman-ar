pam_syslog(3)

الحزمة: pam

التراخيص: GPL-2.0-only

PAM_SYSLOG(3) دليل Linux-PAM PAM_SYSLOG(3)

الاسم

pam_syslog, pam_vsyslog - إرسال رسائل إلى مسجل النظام

الملخص

#include <syslog.h>
#include <security/pam_ext.h>

void pam_syslog(const pam_handle_t *pamh, int priority, const char *fmt, ...);

void pam_vsyslog(const pam_handle_t *pamh, int priority, const char *fmt, va_list args);

الوصف

تقوم الدالة pam_syslog بتسجيل الرسائل باستخدام syslog(3) وهي مخصصة للاستخدام الداخلي بواسطة Linux-PAM ووحدات خدمة PAM. يتم تشكيل الوسيط priority عن طريق ORing لقيم الوحدة (facility) والمستوى (level) كما هو موثق في صفحة دليل syslog(3).

تقوم الدالة pam_vsyslog بنفس مهمة pam_syslog() مع الاختلاف أنها تأخذ مجموعة من الوسائط التي تم الحصول عليها باستخدام ماكرو قائمة الوسائط المتغيرة stdarg(3).

المعايير

الدالتان pam_syslog و pam_vsyslog هما امتدادات لـ Linux-PAM.
