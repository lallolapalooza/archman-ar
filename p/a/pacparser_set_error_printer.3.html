الاسم

pacparser - مكتبة لتحليل ملفات التكوين التلقائي للوكيل (PAC).

واجهة برمجة التطبيقات لمكتبة pacparser، وهي مكتبة لاستخدام ملفات التكوين التلقائي للوكيل (PAC). انظر الصفحة الرئيسية للمشروع: http://github.com/pacparser/pacparser لمزيد من المعلومات.

char* pacparser_find_proxy (const char *url, const char *host)

البحث عن وكيل لعنوان URL والمضيف المحددين.

المعلمات:

url عنوان URL للبحث عن وكيل له.
host جزء المضيف من عنوان URL.

العودة:

سلسلة الوكيل عند النجاح و NULL عند حدوث خطأ.

يبحث عن وكيل لعنوان URL والمضيف المحددين. يجب استدعاء هذه الوظيفة فقط بعد تهيئة محرك pacparser (باستخدام pacparser_init) وتحليل نص PAC (باستخدام pacparser_parse_pac_file أو pacparser_parse_pac_string).

char* pacparser_just_find_proxy (const char *pacfile, const char *url, const char *host)

البحث عن وكيل لملف PAC وعنوان URL والمضيف المحددين.

المعلمات:

pacfile ملف PAC للتحليل.
url عنوان URL للبحث عن وكيل له.
host جزء المضيف من عنوان URL.

العودة:

سلسلة الوكيل عند النجاح و NULL عند حدوث خطأ.

هذه الوظيفة هي غلاف حول وظائف pacparser_init، pacparser_parse_pac_file، pacparser_find_proxy و pacparser_cleanup. إذا كنت تريد فقط معرفة الوكيل لمجموعة معينة من ملف PAC وعنوان URL والمضيف، فهذه هي الوظيفة التي يجب استدعاؤها. تتولى هذه الوظيفة جميع عمليات التهيئة والتنظيف.

void pacparser_cleanup (void)

يقوم بتدمير سياق JavaScript. يجب استدعاء هذه الوظيفة بمجرد الانتهاء من استخدام محرك pacparser.

void pacparser_setmyip (const char *ip)

تعيين عنوان IP الخاص بي.

المعلمات:

ip عنوان IP مخصص.

يقوم بتعيين عنوان IP الخاص بي إلى قيمة مخصصة. هذا هو عنوان IP الذي يتم إرجاعه بواسطة وظيفة JavaScript myIpAddress().

void pacparser_set_error_printer (pacparser_error_printerfunc)

تعيين وظيفة طباعة الأخطاء.

المعلمات:

func وظيفة الطباعة.

يقوم بتعيين وظيفة طباعة الأخطاء ذات الوسائط المتغيرة. إذا لم يتم تعيينها، يتم طباعة الرسائل إلى stderr. إذا بدأت الرسائل بـ DEBUG: أو WARNING:، فهي ليست رسائل خطأ قاتلة، وإلا فهي كذلك. يمكن استدعاؤها قبل pacparser_init().

void pacparser_enable_microsoft_extensions (void)

(مهمل) تمكين امتدادات Microsoft IPv6 PAC. مهمل. تم تمكين امتدادات IPv6 (وظائف *Ex) افتراضيًا الآن.

char* pacparser_version (void)

إرجاع إصدار pacparser.

العودة:

سلسلة الإصدار إذا تم تعريف الإصدار، '' بخلاف ذلك.

يتم تحديد سلسلة الإصدار وقت البناء. إذا تم البناء من حزمة تم إصدارها، فإن الإصدار يتوافق مع أحدث علامة إصدار (git). إذا تم البناء من المستودع، فإنه يتوافق مع آخر مراجعة للمستودع.
