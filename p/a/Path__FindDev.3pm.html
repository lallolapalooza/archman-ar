Path__FindDev(3pm)

الحزمة: perl-path-finddev

التراخيص: PerlArtistic

Path::FindDev(3) وثائق Perl مساهمة من المستخدم Path::FindDev(3)

الاسم

Path::FindDev - ابحث عن مسار تطوير في مكان ما في التسلسل الهرمي العلوي.

الإصدار

الإصدار v0.5.3

الوصف

تعد هذه الحزمة في الغالب طبقة ربط حول "Path::IsDev" مع بعض حيل تتبع الدلائل.

use Path::FindDev qw( find_dev );
if ( my $root = find_dev('/some/path/to/something/somewhere')) {
    print "development root = $root";
} else {
    print "No development root :(";
}

الوظائف

find_dev

my $result = find_dev('/some/path');

إذا تم العثور على دليل "dev" في "/some/path" أو فوقه، فسيتم إرجاعه كـ "Path::Tiny".

إذا مررت تكوينات للاستيراد:

use Path::FindDev find_dev => { set => $someset };

ثم سيقوم "find_dev" المصدّر بتمرير اسم المجموعة هذا إلى "Path::IsDev".

على الرغم من أنه يجب عليك القيام بذلك فقط إذا

  • المجموعة الافتراضية غير كافية لاستخدامك
  • لا تريد تجاوز المجموعة بواسطة %ENV

بالإضافة إلى ذلك، يمكنك استدعاء find_dev مباشرة:

require Path::FindDev;
my $result = Path::FindDev::find_dev('/some/path');

مما يمنع، بحكم التصميم، قدرتك على تحديد مجموعة بديلة في الكود.

حالات الاستخدام المثالية

هل وجدت نفسك تفعل

use FindBin;
use lib "$FindBin::Bin/../../../tlib"

في اختبار؟

هل وجدت نفسك قلقًا بشأن دلالات نظام الملفات وحاولت

use FindBin;
use Path::Tiny qw(path)
use lib path($FindBin::Bin)->parent->parent->parent->child('tlib')->stringify;

هل فعلت أيًا مما سبق في اختبار، فقط لتجد أنك بحاجة إلى نقل الاختبار إلى تسلسل هرمي أعمق، وبالتالي، تحتاج إلى إعادة كتابة كل تحليلات المسار الخاصة بك؟

هل واجهت هذه المشكلة لعدة ملفات؟

لا أكثر!

use FindBin;
use Path::FindDev qw(find_dev);
use lib find_dev($FindBin::Bin)->child('t','tlib')->stringify;

^ يجب أن يعمل، بغض النظر عن الاختبار الذي تضع فيه، وبغض النظر عن $CWD الذي يحدث عند استدعائه.
