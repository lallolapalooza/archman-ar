int pacparser_parse_pac (const char *pacfile)

استخدم pacparser_parse_pac_file بدلاً من ذلك.

المعاملات:

pacfile ملف PAC المراد تحليله.

القيمة المرجعة:

0 عند الفشل و 1 عند النجاح.

نفس pacparser_parse_pac_file. تم تضمينها فقط للتوافق مع الإصدارات السابقة.

char* pacparser_find_proxy (const char *url, const char *host)

البحث عن وكيل لعنوان URL والمضيف المحددين.

المعاملات:

url عنوان URL الذي سيتم البحث عن وكيل له.
host جزء المضيف من عنوان URL.

القيمة المرجعة:

سلسلة الوكيل عند النجاح و NULL عند حدوث خطأ.

يبحث عن وكيل لعنوان URL والمضيف المحددين. يجب استدعاء هذه الوظيفة فقط بعد تهيئة محرك pacparser (باستخدام pacparser_init) وتحليل نص PAC (باستخدام pacparser_parse_pac_file أو pacparser_parse_pac_string).

char* pacparser_just_find_proxy (const char *pacfile, const char *url, const char *host)

البحث عن وكيل لملف PAC وعنوان URL والمضيف المحددين.

المعاملات:

pacfile ملف PAC المراد تحليله.
url عنوان URL الذي سيتم البحث عن وكيل له.
host جزء المضيف من عنوان URL.

القيمة المرجعة:

سلسلة الوكيل عند النجاح و NULL عند حدوث خطأ.

هذه الوظيفة هي غلاف حول الوظائف pacparser_init، pacparser_parse_pac_file، pacparser_find_proxy و pacparser_cleanup. إذا كنت ترغب فقط في معرفة الوكيل لمجموعة معينة من ملف PAC وعنوان URL والمضيف، فهذه هي الوظيفة التي يجب استدعاؤها. تتولى هذه الوظيفة جميع عمليات التهيئة والتنظيف.

void pacparser_cleanup (void)

يقوم بتدمير سياق JavaScript. يجب استدعاء هذه الوظيفة بمجرد الانتهاء من استخدام محرك pacparser.

void pacparser_setmyip (const char *ip)

تعيين عنوان IP الخاص بي.

المعاملات:

ip عنوان IP مخصص.

يعين عنوان IP الخاص بي إلى قيمة مخصصة. هذا هو عنوان IP الذي يتم إرجاعه بواسطة وظيفة JavaScript myIpAddress().

void pacparser_set_error_printer (pacparser_error_printerfunc)

تعيين وظيفة طباعة الأخطاء.

المعاملات:

func وظيفة الطباعة.

تعيين وظيفة طباعة الأخطاء ذات الوسائط المتغيرة. إذا لم يتم تعيينها، فسيتم طباعة الرسائل إلى stderr. إذا بدأت الرسائل بـ DEBUG: أو WARNING:، فهي ليست رسائل خطأ قاتلة، وإلا فهي كذلك. يمكن استدعاؤها قبل pacparser_init().

void pacparser_enable_microsoft_extensions (void)

(مهمل) تمكين ملحقات Microsoft IPv6 PAC. مهمل. تمكين ملحقات IPv6 (وظائف *Ex) افتراضيًا الآن.

char* pacparser_version (void)

إرجاع إصدار pacparser.

القيمة المرجعة:

سلسلة الإصدار إذا تم تحديد الإصدار، '' بخلاف ذلك.

يتم تحديد سلسلة الإصدار في وقت البناء. إذا تم بناؤها من حزمة تم إصدارها، يتوافق الإصدار مع أحدث علامة إصدار (git). إذا تم بناؤها من المستودع، فإنها تتوافق مع الالتزام الرئيسي للمستودع.
