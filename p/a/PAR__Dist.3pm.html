الحزمة: perl-par-dist

PAR::Dist(3) وثائق حزم Perl المساهمة PAR::Dist(3)

الاسم

PAR::Dist - إنشاء ومعالجة توزيعات PAR

ملخص

كأمر في الصدفة:

% perl -MPAR::Dist -eblib_to_par

في البرامج:

use PAR::Dist;
my $dist = blib_to_par(); # إنشاء توزيعة PAR باستخدام ./blib/
install_par($dist);       # تثبيتها على النظام
uninstall_par($dist);     # إلغاء تثبيتها من النظام
sign_par($dist);          # توقيعها باستخدام Module::Signature
verify_par($dist);        # التحقق منها باستخدام Module::Signature
install_par("http://foo.com/DBI-1.37-MSWin32-5.8.0.par"); # يعمل أيضًا
install_par("http://foo.com/DBI-1.37"); # يحدد تلقائيًا اسم البنية + إصدار Perl
install_par("cpan://SMUELLER/PAR-Packer-0.975"); # يستخدم دليل مؤلف CPAN

الوصف

تقوم هذه الوحدة بإنشاء ومعالجة توزيعات PAR. وهي ملفات PAR خاصة بالبنية، تحتوي على كل شيء تحت الدليل blib/ لتوزيعات CPAN بعد مرحلة "make" أو "Build"، و META.yml يصف البيانات الوصفية لتوزيعة CPAN الأصلية، و MANIFEST يفصل جميع الملفات الموجودة بداخله. توزيعات PAR الموقعة رقميًا ستحتوي أيضًا على ملف SIGNATURE.

اصطلاح تسمية مثل هذه التوزيعات هو:

$NAME-$VERSION-$ARCH-$PERL_VERSION.par

على سبيل المثال،

PAR-Dist-0.01-i386-freebsd-5.8.0.par

يتوافق مع الإصدار 0.01 من "PAR-Dist" على CPAN، مبني للإصدار Perl 5.8.0 على بنية "i386-freebsd".

الوظائف

يتم تصدير العديد من الوظائف افتراضيًا. ما لم يُذكر خلاف ذلك، يمكنها إما أن تأخذ جدولًا من المعلمات المسماة، أو وسيطًا واحدًا (يُعتبر $path لـ "blib_to_par" و $dist للوظائف الأخرى)، أو لا تأخذ أي وسيط (في هذه الحالة، يتم استخدام أول PAR في الدليل الحالي).

وبالتالي، في دليل يحتوي على "test.par" واحد فقط، تكون جميع الاستدعاءات التالية مكافئة:

% perl -MPAR::Dist -e"install_par( dist => 'test.par' )"
% perl -MPAR::Dist -e"install_par( 'test.par' )"
% perl -MPAR::Dist -einstall_par;

إذا بدا $dist عنوان URL، فسيتم استدعاء "LWP::Simple::mirror" لنسخه محليًا تحت $ENV{PAR_TEMP} (أو "$TEMP/par/" إذا لم يتم تحديده)، وستعمل الوظيفة على الملف المحلي الذي تم الحصول عليه. إذا بدأ عنوان URL بـ "cpan://AUTHOR/"، فسيتم توسيعه تلقائيًا إلى دليل مؤلف CPAN (على سبيل المثال، "http://www.cpan.org/modules/by-authors/id/A/AU/AUTHOR/").

إذا لم يكن لدى $dist امتداد ملف يبدأ بحرف أو شرطة سفلية، فسيتم إضافة شرطة و $suffix (افتراضيًا "ARCH-$PERL_VERSION.par") إليه.

blib_to_par

يأخذ أزواج مفتاح-قيمة كمعلمات أو وسيط واحد يشير إلى المسار الذي يحتوي على الدليل blib/.

ينشئ توزيعة PAR من الدليل blib/ تحت "path"، أو تحت الدليل الحالي إذا لم يتم تحديده. إذا كان blib/ غير موجود، فسيتم تشغيل Build أو make أو Build.PL أو Makefile.PL تلقائيًا لإنشائه.

يعيد اسم ملف PAR الذي تم إنشاؤه.

المعلمات الصالحة هي:

path
يحدد المسار الذي يحتوي على الدليل blib/ الذي يتم إنشاء توزيعة PAR منه.
name, version, suffix
تحدد هذه السمات الاسم والإصدار واللاحقة الخاصة بالتوزيعة. يمكن تحديد الاسم والإصدار تلقائيًا من ملفات META.yml أو Makefile.PL للتوزيعة. يتم إنشاء اللاحقة من اسم البنية الخاصة بك وإصدار Perl الخاص بك افتراضيًا.
dist
اسم ملف PAR الذي سيتم إنشاؤه.
quiet
يتم تعيينه إلى صحيح لكبت أكبر قدر ممكن من المخرجات.

install_par

يقوم بتثبيت توزيعة PAR على النظام، باستخدام "ExtUtils::Install::install_default".

إذا تم توفير وسيط واحد فقط، فيتم التعامل معه كقيمة للمعلمة "dist".

المعلمات المسماة الصالحة هي:

dist
ملف .par المراد تثبيته. تنطبق الوظائف الاستدلالية الموضحة في الوظائف.
prefix
تتم إضافة هذه السلسلة إلى بداية جميع مسارات التثبيت. إذا لم يتم تحديدها، فسيتم استخدام قيمة المتغير البيئي "PERL_INSTALL_ROOT".
uninstall_shadows
يتوافق مع خيار "uninstall_shadows" الخاص بـ ExtUtils::Install. وفقًا لدليلها: إذا تم تعيين "uninstall_shadows" على صحيح، فسيتم إلغاء تثبيت أي إصدار مختلف في @INC. هذا هو "make install UNINST=1".
verbose
يتوافق مع خيار "verbose" الخاص بـ ExtUtils::Install. وفقًا لدليلها: إذا كان "verbose" صحيحًا، فسيتم طباعة كل ملف تم إزالته. هذا هو "make install VERBINST=1". قيم "verbose" التي تتراوح من 1 إلى 5 تعرض المزيد والمزيد من مخرجات التشخيص. مستوى التفصيل الافتراضي لـ PAR::Dist هو 1.

إذا كنت ستقوم فقط بالتثبيت في perl قيد التشغيل، يمكنك التوقف عن قراءة بقية هذا القسم.

بالإضافة إلى ذلك، يمكنك استخدام معلمات مختلفة لتغيير وجهات التثبيت الافتراضية. لا تحتاج عادةً إلى القلق بشأن هذا، إلا إذا كنت تقوم بالتثبيت في دليل مستخدم محلي. يسرد القسم التالي أسماء المعلمات وقيمها الافتراضية:

Parametro         De          A
inst_lib          blib/lib      $Config{installsitelib} (*)
inst_archlib      blib/arch     $Config{installsitearch}
inst_script       blib/script   $Config{installscript}
inst_bin          blib/bin      $Config{installbin}
inst_man1dir      blib/man1     $Config{installman1dir}
inst_man3dir      blib/man3     $Config{installman3dir}
packlist_read                   $Config{sitearchexp}/auto/$name/.packlist
packlist_write                  $Config{installsitearch}/auto/$name/.packlist

تُستخدم المعلمة "packlist_write" للتحكم في مكان كتابة ملف .packlist. (وهو ضروري لإلغاء التثبيت.) تحدد المعلمة "packlist_read" ملف .packlist لدمجه إذا كان موجودًا. عن طريق تعيين أي من وجهات التثبيت أعلاه إلى "undef"، يمكنك إزالة تلك الوجهة تمامًا. على سبيل المثال، تمرير "inst_man1dir => undef, inst_man3dir => undef" يعني أنه لن يتم تثبيت صفحات الدليل الموجودة. هذا غير متاح لقوائم الحزم.

مرة أخرى، ستكون القيم الافتراضية هي site العادية لـ %Config.

(*) إذا كان inst_archlib الخاص بـ ".par" (عادةً "blib/arch") غير فارغ، فسيتم تثبيت الكود في inst_lib (عادةً "blib/lib") أيضًا في المسار inst_archlib. هذا منطقي للوحدات XS. ومع ذلك، إذا قمت بتجاوز "inst_lib"، فسيتم تجاوز هذا التحويل التلقائي أيضًا! يمكنك استخدام المعلمة المسماة "auto_inst_lib_conversion => 1" لإعادة تمكين التحويل لـ inst_lib المخصصة.

أخيرًا، يمكنك تحديد "custom_targets"...

PAR::Dist(3pm)

NAME

PAR::Dist - build and manage PAR archives

SYNOPSIS

use PAR::Dist;
# ... functions ...

DESCRIPTION

This module provides functions to manipulate PAR archives. It is a wrapper around ExtUtils::Install, Module::Signature, and the PAR archive format itself.

PAR is a package archive format for Perl, designed to make it easy to distribute and run Perl applications without requiring the user to install them first. PAR files are self-contained and can be executed directly.

FUNCTIONS

blib_to_par

Turns the contents of the blib directory into a PAR archive. This is usually done after you have prepared the contents of the PAR archive in the blib directory.

Takes a list of named parameters:

name
The name of the PAR distribution. This is used for the META.yml file. Required.
version
The version of the PAR distribution. This is used for the META.yml file. Required.
arch
The architecture name, e.g. x86_64-linux. Defaults to the architecture name derived from $Config::Config{archname}.
perl
The Perl version, e.g. 5.8.7. Defaults to $].
output
The output filename for the PAR archive. Defaults to "$name-$version-$arch-$perl.par".
manifile
The path to the META.yml file. Defaults to "META.yml".
packlist_write
A reference to a hash of files to install. This is used to generate the .packlist file. If not provided, it will be generated from the contents of the blib directory.
compress
The compression method to use. Defaults to "zip". Can be "none", "gzip", or "bzip2".
overwrite
If true, an existing PAR archive with the same name will be overwritten. Defaults to false.

The function returns the name of the created PAR archive on success, or undef on failure.

par_to_blib

Extracts the contents of a PAR archive into the blib directory. This is the reverse operation of blib_to_par.

Takes a list of named parameters:

dist
The name of the PAR archive file. Required.
targetdir
The directory to extract the contents to. Defaults to the current directory.
install_target
A reference to a hash of custom installation targets. See install_par for details.

The function returns true on success, or false on failure.

install_par

Installs the contents of a PAR archive into the Perl library directory using "ExtUtils::Install::install".

Takes a list of named parameters:

dist
The name of the PAR archive file. Required.
targetdir
The target directory for installation. Defaults to "blib".
packlist_write
A reference to a hash of files to install. This is used to generate the .packlist file. If not provided, it will be generated from the contents of the PAR archive.
install_target
A reference to a hash of custom installation targets such as 
custom_targets => { 'blib/my_data' => '/some/path/my_data' }

You can use this to install the .par archives contents to arbitrary locations.

uninstall_par

Uninstalls all previously installed contents of a PAR distribution, using "ExtUtils::Install::uninstall".

Takes almost the same parameters as "install_par", but naturally, the installation target parameters do not apply. The only exception to this is the "packlist_read" parameter which specifies the .packlist file to read the list of installed files from. It defaults to "$Config::Config{installsitearch}/auto/$name/.packlist".

Additionally, the "uninstall_shadows" parameter of "install_par" isn't available.

sign_par

Digitally sign a PAR distribution using "gpg" or Crypt::OpenPGP, via Module::Signature.

verify_par

Verify the digital signature of a PAR distribution using "gpg" or Crypt::OpenPGP, via Module::Signature.

Returns a boolean value indicating whether verification passed; $! is set to the return code of "Module::Signature::verify".

merge_par

Note: Since version 0.32 of PAR::Dist, this function requires a YAML reader. The order of precedence is:

YAML:XS YAML YAML::Syck YAML::Tiny

Merges two or more PAR distributions into one. First argument must be the name of the distribution you want to merge all others into. Any following arguments will be interpreted as the file names of further PAR distributions to merge into the first one.

merge_par('foo.par', 'bar.par', 'baz.par')

This will merge the distributions "foo.par", "bar.par" and "baz.par" into the distribution "foo.par". "foo.par" will be overwritten!

The original META.yml of "foo.par" is retained, but augmented with any "provides", "requires", "recommends", "build_requires", and "configure_requires" sections from the other .par files.

remove_man

Remove the man pages from a PAR distribution. Takes one named parameter: dist which should be the name (and path) of the PAR distribution file. The calling conventions outlined in the "FUNCTIONS" section above apply.

The PAR archive will be extracted, stripped of all "man\d?" and "html" subdirectories and then repackaged into the original file.

get_meta

Opens a PAR archive and extracts the contained META.yml file. Returns the META.yml file as a string.

Takes one named parameter: dist. If only one parameter is passed, it is treated as the dist parameter. (Have a look at the description in the "FUNCTIONS" section above.)

Returns undef if no PAR archive or no META.yml within the archive were found.

parse_dist_name

First argument must be a distribution file name. The file name is parsed into distribution name, distribution version, architecture name, and perl version.

Returns the results as a list in the above order. If any or all of the above cannot be determined, returns undef instead of the undetermined elements.

Supported formats are:

Math-Symbolic-0.502-x86_64-linux-gnu-thread-multi-5.8.7

Math-Symbolic-0.502

The ".tar.gz" or ".par" extensions as well as any preceding paths are stripped before parsing. Starting with "PAR::Dist" 0.22, versions containing a preceding "v" are parsed correctly.

This function is not exported by default.

generate_blib_stub

Creates a blib/lib subdirectory in the current directory and prepares a META.yml with meta information for a new PAR distribution. First argument should be the name of the PAR distribution in a format understood by parse_dist_name(). Alternatively, named arguments resembling those of "blib_to_par" are accepted.

After running "generate_blib_stub" and injecting files into the blib directory, you can create a PAR distribution using "blib_to_par". This function is useful for creating custom PAR distributions from scratch. (I.e. not from an unpacked CPAN distribution) Example:

use PAR::Dist;
use File::Copy 'copy';
generate_blib_stub(
  name => 'MyApp', version => '1.00'
);
copy('MyApp.pm', 'blib/lib/MyApp.pm');
blib_to_par(); # generates the .par file!

"generate_blib_stub" will not overwrite existing files.

contains_binaries

This function is not exported by default.

Opens a PAR archive tries to determine whether that archive contains platform-specific binary code.

Takes one named parameter: dist. If only one parameter is passed, it is treated as the dist parameter. (Have a look at the description in the "FUNCTIONS" section above.)

Throws a fatal error if the PAR archive could not be found.

Returns one if the PAR was found to contain binary code and zero otherwise.
