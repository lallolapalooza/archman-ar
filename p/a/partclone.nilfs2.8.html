NAME

partclone.ext3 — copy a partition with ext3 file system

SYNOPSIS

partclone.ext3 [OPTION...]

DESCRIPTION

The partclone.ext3 command copies the ext3 file system. It is part of the partclone package, which is a tool that copies raw partitions and filesystems. partclone can be used to clone disks or partitions. It can copy only used blocks to save disk space. It supports many file systems, including ext2, ext3, ext4, btrfs, reiserfs, xfs, ntfs, and vfat.

This manual page describes the partclone.ext3 command.

OPTIONS

The options are the same as partclone(8).

Additional options for partclone.ext3:

-d, --debug

Dump debug information to stderr.

-c, --clone

Clone mode. Copy the source partition to the destination image file.

-r, --restore

Restore mode. Copy the image file to the destination partition.

-s, --source DEVICE

Source device or image file.

-o, --output DEVICE

Output device or image file.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.ext3 -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
