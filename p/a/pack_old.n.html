NAME

pack - geometry manager for Tk widgets

SYNOPSIS

package require Tk
pack ?widget? ?options?

DESCRIPTION

The pack command is used to manage the geometry of other widgets. It is one of the three geometry managers available in Tk, along with grid and place. The pack command is used to arrange widgets in a parent widget. The widgets are packed relative to each other in a block. The size and position of the block are determined by the sizes of the widgets within it and the options specified for the pack command.

The pack command takes the following arguments:

?widget?
The widget to be managed. If no widget is specified, pack operates on the currently selected widget.
?options?
Various options to control the packing behavior. These options include:
-side side
Specifies which side of the parent widget the widget should be packed against. Possible values are top, bottom, left, or right. The default is top.
-fill fill
Specifies whether the widget should expand to fill extra space allocated to it. Possible values are none, x, y, or both. The default is none.
-expand ?boolean?
Specifies whether the widget should expand to fill extra space in the parent widget. If boolean is true, the widget will expand. The default is false.
-padx num
Adds extra horizontal padding around the widget. The value num is in screen units.
-pady num
Adds extra vertical padding around the widget. The value num is in screen units.
-ipadx num
Adds extra internal horizontal padding within the widget. The value num is in screen units.
-ipady num
Adds extra internal vertical padding within the widget. The value num is in screen units.
-anchor anchor
Specifies where the widget should be placed within its allocated space if it does not fill the entire space. Possible values are combinations of n, s, e, w, center.
-before other_widget
Packs the widget before other_widget in the packing order.
-after other_widget
Packs the widget after other_widget in the packing order.
-in master_widget
Specifies the parent widget in which to pack the widget. If not specified, the parent of the widget is used.
-raise
Raises the widget to the top of the stacking order within its parent.
-forget
Removes the widget from the packing order. This is equivalent to unmapping the widget.
-slaves ?other_widgets?
Specifies a list of widgets that should be packed relative to the current widget. If no other_widgets are specified, it returns a list of the slaves of the current widget.

The pack command returns an empty string upon success, and raises an error if an invalid option or argument is given.
