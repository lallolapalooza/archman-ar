الاسم

partclone - الأداة لنسخ واستعادة قسم.

الملخص

الوصف

partclone.[fstype] هو جزء من مشروع Partclone. يوفر Partclone أدوات لعمل نسخ احتياطي للكتل المستخدمة ويتصميم لتوافق أعلى مع نظام الملفات باستخدام المكتبات الموجودة، على سبيل المثال، يتم استخدام e2fslibs لقراءة الكتلة المستخدمة من قسم ext2.

نظام الملفات المدعوم من Partclone يشمل btrfs، ext2، ext3، ext4، reiserfs، reiser4، xfs و jfs لنظام LINUX. كما يدعم بعض أنظمة التشغيل غير اللينكس، على سبيل المثال: NTFS، FAT و EXFAT (لـ Windows)، HFS plus (MAC OS)، UFS2 (FreeBSD)، VMFS (VMWare Vsphere) و MINIX (MINIX3).

يمكن تشغيل جميع أدوات partclone مثل partclone.[fstype] وهو مشابه جدًا لـ fsck أو mkfs. على سبيل المثال، لعمل نسخة احتياطية/استعادة hfsplus، قم فقط بتشغيل partclone.hfsp

       نظام الملفات                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       أخرى (نظام ملفات غير مدعوم)   partclone.imager

الخيارات

يتبع البرنامج صيغة سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتضمن ملخصًا للخيارات أدناه.

-s FILE, --source FILE

ملف المصدر. يمكن أن يكون الملف ملف صورة (تم إنشاؤه بواسطة partclone) أو جهازًا يعتمد على الإجراء الخاص بك. عادةً، يكون مصدر النسخ الاحتياطي هو الجهاز، ومصدر الاستعادة هو ملف الصورة.

استقبال البيانات من خط الأنابيب مدعوم فقط للاستعادة، تجاهل خيار -s أو استخدام '-' يعني استقبال البيانات من stdin.

-o FILE, --output FILE

ملف الإخراج. يمكن أن يكون الملف ملف صورة (سينشئه partclone) أو جهازًا يعتمد على الإجراء الخاص بك. عادةً، يتم النسخ الاحتياطي إلى ملف صورة والاستعادة إلى جهاز.

إرسال البيانات إلى خط الأنابيب مدعوم أيضًا للنسخ الاحتياطي، تجاهل خيار -o أو استخدام '-' يعني إرسال البيانات إلى stdout.

-O FILE, --overwrite FILE

الكتابة فوق الملف، الكتابة فوقه إذا كان موجودًا.

-W FILE, --restore_raw_file FILE

إنشاء ملف خام خاص لجهاز الحلقة.

-c, --clone

حفظ القسم بتنسيق الصورة الخاص.

-r, --restore

استعادة القسم من تنسيق الصورة الخاص.

-b, --dev-to-dev

نسخ الجهاز المحلي إلى الجهاز مباشرة، المصدر والإخراج كلاهما جهاز.

-D, --domain

إنشاء ملف سجل GNU Ddrescue domain من جهاز المصدر. هذا ملف قابل للقراءة البشرية يحدد فيه + الكتل المستخدمة و؟ المناطق الفارغة.

--offset_domain=X

إضافة X (بالبايت) إلى جميع المواقع المبلغ عنها في ملف سجل domain

--restore_raw_file

إنشاء ملف خام خاص لجهاز الحلقة.

-L FILE, --logfile FILE

وضع مسار خاص لتسجيل معلومات سجل partclone. (الافتراضي /var/log/partclone.log)

-R, --rescue

الاستمرار بعد أخطاء قراءة القرص.

-C, --no_check

لا تتحقق من حجم الجهاز والمساحة الخالية.

-N, --ncurses

استخدام واجهة المستخدم النصية Ncurses.

-I, --ignore_fschk

تجاهل فحص نظام الملفات.

-i, --ignore_crc

تجاهل خطأ فحص crc.

-F, --force

فرض التقدم.

-f sec, --UI-fresh sec

وضع ثانية خاصة بفاصل زمني مختلف.

-z size, --buffer_size size

حجم مخزن القراءة/الكتابة (الافتراضي: 1048576)

-q, --quiet

تعطيل رسالة التقدم.

-dlevel, --debug level

تعيين مستوى التصحيح [1|2|3]

-x, --compresscmd CMD

بدء CMD كأنبوب إخراج لضغط الصورة المستنسخة.

-aX, --checksum-mode=X

صيغة فحص المجموع المستخدمة لإضافة اكتشاف الأخطاء

حيث X:

0: لا يوجد فحص مجموع (لا تباطؤ، أصغر صورة)

1: CRC32 (سريع الحساب، اكتشاف أساسي)

2: xxHash خوارزمية تجزئة سريعة للغاية غير تشفيرية

-kX, --blocks-per-checksum=X

كتابة فحص مجموع واحد لكل X كتلة.

-w, --skip_write_error

الاستمرار في الاستعادة أثناء أخطاء الكتابة.

--write-direct-io

كتابة البيانات إلى قسم TARGET بدون ذاكرة تخزين مؤقت.

--read-direct-io

قراءة البيانات من قسم SOURCE بدون ذاكرة تخزين مؤقت.

-B, --no_block_detail

عرض رسالة التقدم بدون تفاصيل الكتلة.

--binary-prefix

عرض التقدم بحجم البت (الافتراضي هو ميجابايت، جيجابايت...).

--prog-second

عرض التقدم بالثواني (الافتراضي هو الدقيقة).

-E, --offset=X

إضافة إزاحة X (بايت) إلى الإخراج.

-T, --btfiles

استعادة الكتلة كملف لـ ClonezillaBT.

-t, --btfiles_torrent

استعادة الكتلة كملف لـ ClonezillaBT ولكن إنشاء تورنت فقط.

-n, --note NOTE

عرض مذكرة الرسالة (128 كلمة).

-h, --help

عرض ملخص الخيارات.

-v, --version

عرض الإصدار

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
