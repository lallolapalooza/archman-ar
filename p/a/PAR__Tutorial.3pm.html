PAR::Tutorial(3) وثائق Perl المقدمة من المستخدم PAR::Tutorial(3)

الاسم

PAR::Tutorial - التعبئة والتوزيع عبر الأنظمة الأساسية مع PAR

الملخص

هذا برنامج تعليمي حول PAR، ظهر لأول مرة في مؤتمر Perl السابع. النسخة HTML من هذا البرنامج التعليمي متاحة عبر الإنترنت على http://search.cpan.org/perldoc?PAR::Tutorial

الوصف

حول توزيع تطبيقات Perl

% sshnuke.pl 10.2.2.2 -rootpw="Z1ON0101"
مطلوب Perl v5.6.1 -- هذا فقط v5.6.0، توقف عند sshnuke.pl السطر 1.
فشل BEGIN -- إلغاء التجميع عند sshnuke.pl السطر 1.
  • س: "مساعدة! لا يمكنني تشغيل برنامجك!"
  • ج1: تثبيت Perl و "perl -MCPAN -e'install(...)'"
  • كيف نعرف الوحدات المطلوبة؟
  • قد تتسبب الإصدارات الجديدة من وحدات CPAN في كسر "sshnuke.pl"
•
ج2: تثبيت Perl و "tar zxf my_perllib.tgz"
•
قد يؤدي ذلك إلى الكتابة فوق الوحدات الموجودة؛ ليس عبر الأنظمة الأساسية على الإطلاق
•
ج3: استخدام الملف التنفيذي الذي تم إنشاؤه بواسطة "perlcc sshnuke.pl"
•
من المستحيل تصحيح الأخطاء؛ "perlcc" عادةً لا تعمل على أي حال

PAR، أدوات أرشفة Perl

•
افعل ما تفعله JAR (Java Archive) لـ Perl
  • تجميع الوحدات والنصوص البرمجية والملفات الأخرى في ملف Zip
  • سهل الإنشاء والتحديث والاستخراج
  • تناسق الإصدارات: يحل مشاكل التوافق الأمامي
  • تم تطويره بواسطة المجتمع: "par@perl.org"
•
يمكن حزم ملفات PAR في نصوص برمجية مكتفية ذاتيًا
  • يفحص تلقائيًا نصوص Perl البرمجية بحثًا عن التبعيات
  • يجمع جميع الوحدات الطرف الثالث الضرورية معها
  • يتطلب فقط Perl الأساسي للتشغيل على الجهاز المستهدف
  • يأتي PAR أيضًا مع "pp"، حزمة Perl: 
    % pp -o sshnuke.exe sshnuke.pl # ملف تنفيذي مستقل!

تعبئة بسيطة

  • ملفات PAR هي مجرد ملفات Zip مع وحدات بداخلها
  • يمكن لأي أدوات Zip إنشاؤها: 
    % zip foo.par Hello.pm World.pm # حزم وحدتين
% zip -r bar.par lib/ # احصل على جميع الوحدات في lib/
  • لتحميل الوحدات من ملفات PAR: 
    use PAR;
use lib "foo.par"; # الجزء .par اختياري
use Hello;
  • هذا يعمل أيضًا: 
    use PAR "/home/mylibs/*.par"; # ضعها كلها في @INC
use Hello;

محملات PAR

  • استخدم "par.pl" لتشغيل الملفات داخل أرشيف PAR: 
    % par.pl foo.par # يبحث عن 'main.pl' افتراضيًا
% par.pl foo.par test.pl # يشغل script/test.pl في foo.par
  • نفس الشيء، مع "parl" أو "parl.exe" المستقل: 
    % parl foo.par # لا حاجة لـ perl أو PAR.pm!
% parl foo.par test.pl # نفس الشيء
  • يمكن لمُحمّل PAR أن يسبق نفسه بملف PAR:
  • "-b" يجمع الوحدات غير الأساسية المطلوبة بواسطة "PAR.pm": 
    % par.pl -b -O./foo.pl foo.par # نص برمجي مكتفٍ ذاتيًا
  • "-B" يجمع الوحدات الأساسية بالإضافة إلى "-b": 
    % parl -B -O./foo.exe foo.par # ثنائي مكتفٍ ذاتيًا

مسح التبعيات

  • مسح التبعيات بشكل متكرر باستخدام "scandeps.pl": 
    % scandeps.pl sshnuke.pl
# الأسطورة: [أساسي] [خارجي] [وحدة فرعية] [؟ غير موجود على CPAN]
'Crypt::SSLeay' => '0', # خارجي #
'Net::HTTP' => '0', # #
'Crypt::SSLeay::X509' => '0', # وحدة فرعية # Crypt::SSLeay
'Net::HTTP::Methods' => '0', # وحدة فرعية # Net::HTTP
'Compress::Zlib' => '0', # خارجي # Net::HTTP::Methods
  • مسح سطر واحد، سرد جميع الملفات المتضمنة: 
    % scandeps.pl -V -e "use Dynaloader;"
...
# auto/DynaLoader/dl_findfile.al [تحميل تلقائي]
# auto/DynaLoader/extralibs.ld [تحميل تلقائي]
# auto/File/Glob/Glob.bs [بيانات]
# auto/File/Glob/Glob.so [مشترك]
...

حزمة Perl: "pp"

  • يجمع المسح، والضغط، وتضمين المحمل: 
    % pp -o out.exe src.pl # .exe مكتفٍ ذاتيًا
% out.exe # يعمل في أي مكان على نفس نظام التشغيل
  • تجميع وحدات إضافية: 
    % pp -o out.exe -M CGI src.pl # حزم CGI + تبعياتها أيضًا
  • حزم أسطر الأوامر: 
    % pp -o out.exe -e 'print "Hi!"' # يحول سطر الأوامر إلى ملف تنفيذي
  • إنشاء ملفات PAR بدلاً من الملفات التنفيذية: 
    % pp -p src.pl # ينشئ 'source.par'
% pp -B -p src.pl # تضمين الوحدات الأساسية

كيف تعمل

•
خيارات سطر الأوامر مطابقة تقريبًا لخيارات "perlcc"
•
تدعم أيضًا الخيارات الطويلة بأسلوب "gcc": 
% pp --gui --verbose --output=out.exe src.pl
  • عبء مبدئي صغير؛ لا يوجد عبء وقت التشغيل
  • يتم إزالة POD (Plain Old Documentation) من التبعيات قبل التعبئة
  • تقوم بتحميل الوحدات مباشرة في الذاكرة عند الطلب
  • يتم استخراج المكتبات المشتركة (DLLs) باستخدام File::Temp
  • تعمل على Perl 5.6.0 أو أحدث
  • تم اختبارها على Win32 (VC++ و MinGW)، FreeBSD، NetBSD، Linux، MacOSX، Cygwin، AIX، Solaris، HP-UX، Tru64...

تجميع برامج متعددة

  • سؤال شائع: 
    > لقد استخدمت pp لإنشاء العديد من التطبيقات المستقلة التي تعمل بشكل
> رائع، المشكلة الوحيدة هي أنه مع كل ملف تنفيذي أقوم بإنشائه، أفترض أن
> parl.exe مدمج بطريقة ما في الملف التنفيذي الناتج.
  • الحل البديل الواضح: 
    يمكنك شحن parl.exe بمفردها، جنبًا إلى جنب مع ملفات .par التي تم إنشاؤها
بواسطة "pp -p"، وتشغيل تلك الملفات PAR عن طريق ربطها بـ parl.exe.
  • على الأنظمة الأساسية التي تحتوي على "ln"، يوجد حل أفضل: 
    % pp --output=a.out a.pl b.pl # نصان برمجيان في واحد!
% ln a.out b.out # الرابط الرمزي يعمل أيضًا
% ./a.out # يشغل a.pl
% ./b.out # يشغل b.pl

حزم عبر الأنظمة الأساسية

  • بالطبع، لا يوجد تنسيق ثنائي عبر الأنظمة الأساسية
  • حزم PAR المكتوبة بـ pure-perl تكون عبر الأنظمة الأساسية بشكل افتراضي
  • ومع ذلك، فإن وحدات XS خاصة بإصدار Perl والنظام الأساسي
  • يمكن لإصدارات متعددة من وحدة XS التعايش في ملف PAR
  • لنفترض أننا نحتاج إلى "out.par" على Win32 و Finix: 
    C:\> pp --multiarch --output=out.par src.pl
...انسخ src.pl و out.par إلى جهاز Finix...
% pp --multiarch --output=out.par src.pl
  • الآن يعمل على كلا النظامين الأساسيين: 
    % parl out.par # يشغل src.p
