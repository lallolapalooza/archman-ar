PARTCLONE(8) دليل مستخدم Partclone PARTCLONE(8)

الاسم

partclone - الأداة لنسخ واستعادة قسم.

ملخص

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] target} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

الوصف

partclone.[fstype] هو جزء من مشروع Partclone. يوفر Partclone أدوات لنسخ الكتل المستخدمة وتصميم توافق أعلى لنظام الملفات باستخدام المكتبات الموجودة، على سبيل المثال، يتم استخدام e2fslibs لقراءة الكتلة المستخدمة لقسم ext2.

يشمل نظام الملفات المدعوم من Partclone btrfs، ext2، ext3، ext4، reiserfs، reiser4، xfs و jfs لنظام LINUX. كما يدعم بعض أنظمة التشغيل غير لينكس، على سبيل المثال NTFS، FAT و EXFAT (لنظام ويندوز)، HFS plus (نظام MAC OS)، UFS2 (نظام FreeBSD)، VMFS (نظام VMWare Vsphere) و MINIX (نظام MINIX3).

يمكن تشغيل جميع أدوات partclone مثل partclone.[fstype] وهي مشابهة جدًا لـ fsck أو mkfs. على سبيل المثال، لنسخ/استعادة hfsplus، قم فقط بتشغيل partclone.hfsp

       نظام الملفات                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       أخرى (نظام ملفات غير مدعوم)   partclone.imager

خيارات

يتبع البرنامج صيغة سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتضمن ملخصًا للخيارات أدناه.

-s FILE, --source FILE

ملف المصدر. يمكن أن يكون الملف ملف صورة (تم إنشاؤه بواسطة partclone) أو جهازًا اعتمادًا على الإجراء الخاص بك. عادةً، مصدر النسخ الاحتياطي هو الجهاز، ومصدر الاستعادة هو ملف الصورة.

يتم دعم تلقي البيانات من خط الأنابيب فقط للاستعادة، وتجاهل خيار -s أو استخدام '-' يعني تلقي البيانات من stdin.

-o FILE, --output FILE

ملف الإخراج. يمكن أن يكون الملف ملف صورة (سيقوم partclone بإنشائه) أو جهازًا اعتمادًا على الإجراء الخاص بك. عادةً، يتم النسخ الاحتياطي للإخراج إلى ملف صورة ويتم استعادة الإخراج إلى الجهاز.

يتم أيضًا دعم إرسال البيانات إلى خط الأنابيب فقط للنسخ الاحتياطي، وتجاهل خيار -o أو استخدام '-' يعني إرسال البيانات إلى stdout.

-O FILE, --overwrite FILE

الكتابة فوق الملف، الكتابة فوقه إذا كان موجودًا.

-W FILE, --restore_raw_file FILE

إنشاء ملف خام خاص لجهاز الحلقة.

-c, --clone

حفظ القسم بتنسيق الصورة الخاص.

-r, --restore

استعادة القسم من تنسيق الصورة الخاص.

-b, --dev-to-dev

نسخ الجهاز المحلي إلى جهاز بشكل مباشر، المصدر والإخراج كلاهما جهاز.

-D, --domain

إنشاء ملف سجل نطاق GNU Ddrescue من جهاز المصدر. هذا ملف قابل للقراءة البشرية يمثل فيه + المناطق المستخدمة وعلامات ؟ المناطق الحرة.

--offset_domain=X

إضافة X (بالبايت) إلى جميع المواقع المبلغ عنها في ملف سجل النطاق

--restore_raw_file

إنشاء ملف خام خاص لجهاز الحلقة.

-L FILE, --logfile FILE

وضع مسار خاص لتسجيل معلومات سجل partclone. (الافتراضي /var/log/partclone.log)

-R, --rescue

المتابعة بعد أخطاء قراءة القرص.

-C, --no_check

لا تحقق من حجم الجهاز والمساحة الحرة.

-N, --ncurses

استخدام واجهة مستخدم نصية Ncurses.

-I, --ignore_fschk

تجاهل فحص نظام الملفات.

-i, --ignore_crc

تجاهل خطأ فحص crc.

-F, --force

فرض التقدم.

-f sec, --UI-fresh sec

وضع ثوانٍ خاصة بفاصل زمني مختلف.

-z size, --buffer_size size

حجم المخزن المؤقت للقراءة/الكتابة (الافتراضي: 1048576)

-q, --quiet

تعطيل رسالة التقدم.

-dlevel, --debug level

تعيين مستوى التصحيح [1|2|3]

-x, --compresscmd CMD

ابدأ CMD كأنبوب إخراج لضغط صورة النسخ

-aX, --checksum-mode=X

صيغة التحقق المستخدمة لإضافة الكشف عن الأخطاء

حيث X:

0: لا يوجد تحقق (لا تباطؤ، أصغر صورة)

1: CRC32 (سريع الحساب، اكتشاف أساسي)

2: xxHash خوارزمية تجزئة سريعة جدًا غير تشفيرية

-kX, --blocks-per-checksum=X

كتابة تحقق واحد لكل X كتل

-w, --skip_write_error

متابعة الاستعادة أثناء أخطاء الكتابة

--write-direct-io

كتابة البيانات إلى قسم TARGET بدون ذاكرة تخزين مؤقت

--read-direct-io

قراءة البيانات من قسم SOURCE بدون ذاكرة تخزين مؤقت

-B, --no_block_detail

عرض رسالة التقدم بدون تفاصيل الكتلة

--binary-prefix

عرض التقدم بحجم البت (الافتراضي هو ميجابايت، جيجابايت...)

--prog-second

عرض التقدم بالثواني (الافتراضي هو الدقيقة)

-E, --offset=X

إضافة إزاحة X (بايت) إلى الإخراج

-T, --btfiles

استعادة الكتلة كملف لـ ClonezillaBT.

-t, --btfiles_torrent

استعادة الكتلة كملف لـ ClonezillaBT ولكن فقط إنشاء تورنت.

-n, --note NOTE

عرض ملاحظة الرسالة (128 كلمة).

-h, --help

عرض ملخص الخيارات.

-v, --version

عرض الإصدار

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

partclone.extfs(8)

NAME

partclone.extfs

clone, save, restore, make a disk image or cloning

SYNOPSIS

partclone.extfs [-h] [-version] [-clone | -restore] [-s source] [-o output] [-c] [-d] [-N] [-F] [-P] [-q] [-p percentage] [-b block_size] [-e error_block]

DESCRIPTION

partclone is a program that helps you clone, save, restore, make a disk image or cloning. Partclone works like clonezilla. Partclone is a part of clonezilla. It is a command line tool that allows you to save or restore a partition to a specified file or device. It only saves the used blocks, so it is much faster than dd. This utility supports many file systems, like ext2, ext3, ext4, reiserfs, reiser4, btrfs, xfs, ntf, fat32, hfs+, ufs, etc. Partclone is also able to clone to multicast network.

The partclone.extfs is the Partclone's utility for the extfs file system.

The partclone tool provides the following return codes:

0 Program exited successfully.

1 Clone or Restore seem failed.

OPTIONS

-b">-b block_size
Set block size. Default is 1M.
-c">-c
Calculate the disk usage.
-d">-d
Display debug information.
-e">-e error_block
The number of error blocks to be saved.
-F">-F
Force overwrite. If the output file exists, it will be overwritten.
-h">-h
Display help information.
-N">-N
No prompt. If the output is a device, it will be overwritten without prompting.
-p">-p percentage
Set percentage of blocks to be saved.
-P">-P
Create partition table image.
-q">-q
Quiet mode. Do not display progress information.
-r">-r
Restore mode. If not specified, clone mode is assumed.
-s">-s source
The source file or device.
-o">-o output
The output file or device.
-version">-version
Display version information.

The clone or restore mode is determined by the command name. partclone.extfs assumes clone mode, while partclone.extfs-restore assumes restore mode. However, you can override this with the -r option.

The program exit status is 0 on success, and non-zero on failure. A return code of 1 means that the clone or restore operations failed. The exact meaning of other non-zero return codes can be found in the man page of partclone. However, the diagnostic messages printed to stderr should be sufficient to determine the cause of failure.

When cloning, partclone saves only the used blocks. This saves time and disk space. Partclone also supports splitting the image file into multiple smaller files. This can be useful for storing images on media with limited capacity, like CDs or DVDs.

When restoring, partclone restores the image file to the specified device. If the image file was split into multiple smaller files, partclone will automatically concatenate them before restoring.

The program supports the following file systems:

ext2, ext3, ext4, reiserfs, reiser4, btrfs, xfs, ntf, fat32, hfs+, ufs.

The program also supports the following advanced features:

Multicast network cloning, partition table cloning, disk usage calculation, splitting image files, resuming interrupted operations, and more.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
