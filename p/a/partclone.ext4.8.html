PARTCLONE(8) دليل مستخدم Partclone PARTCLONE(8)

الاسم

partclone - الأداة لاستنساخ واستعادة قسم.

الملخص

partclone.[fstype] {[-c | --clone] [-r | --restore] [-b | --dev-to-dev]} {[-s | --source] source} {[[-o | --output] [-O | --overwrite]] target} [[-dX | --debug=X] [--restore_raw_file] [-z | --buffer_size] [-N | --ncurses] [-q | --quiet] [-f | --UI-fresh] [-F | --force] [-I | --ignore_fschk] [-i | --ignore_crc] [-C | --nocheck] [-R | --rescue] [-L | --logfile] logfile [-R | --rescue] [-L | --logfile] logfile [-X | --compresscmd] [-D | --domain] [--offset_domain] [-aX | --checksum-mode=X] [-kX | --blocks-per-checksum=X] [-K | --no-reseed] [-w | --skip_write_error] [-E | --offset=X] [-T | --btfiles] [-t | --btfiles_torrent] [-n | --note] [-B | --no_block_detail] [--binary-prefix] [--prog-second] [--write-direct-io] [--read-direct-io]]

الوصف

partclone.[fstype] هو جزء من مشروع Partclone. يوفر Partclone أدوات لعمل نسخ احتياطي للكتل المستخدمة وتصميم للتوافق الأعلى لنظام الملفات باستخدام مكتبات موجودة، على سبيل المثال، يتم استخدام e2fslibs لقراءة الكتلة المستخدمة من قسم ext2.

يشمل نظام الملفات المدعوم من Partclone btrfs، ext2، ext3، ext4، reiserfs، reiser4، xfs و jfs لنظام LINUX. كما يدعم بعض أنظمة التشغيل غير لنظام لينكس، على سبيل المثال: NTFS، FAT و EXFAT (لـ Windows)، HFS plus (لـ MAC OS)، UFS2 (لـ FreeBSD)، VMFS (لـ VMWare Vsphere) و MINIX (لـ MINIX3).

يمكن تشغيل جميع أدوات partclone مثل partclone.[fstype] بشكل مشابه لـ fsck أو mkfs. على سبيل المثال، لعمل نسخة احتياطية/استعادة hfsplus، ما عليك سوى تشغيل partclone.hfsp

       نظام الملفات                 partclone.[fstype]
       btrfs                       partclone.btrfs
       ext2, ext3, ext4            partclone.[ext2 | ext3 | ext4]
       reiserfs 3.5                partclone.reiserfs
       reiser 4                    partclone.reiser4
       xfs                         partclone.xfs
       ufs | ufs2                  partclone.ufs
       jfs                         partclone.jfs
       hfs plusfs                  partclone.[hfs+ | hfsplus]
       vmfs                        partclone.[vmfs | vmfs5]
       ntfs                        partclone.ntfs
       fat12, fat16, fat32         partclone.[fat12 | fat16 | fat32]
       exfat                       partclone.exfat
       minix                       partclone.minix
       f2fs                        partclone.f2fs
       nilfs2                      partclone.nilfs2
       apfs                        partclone.apfs
       أخرى (نظام ملفات غير مدعوم)   partclone.imager

الخيارات

يتبع البرنامج صيغة سطر الأوامر القياسية لـ GNU، مع خيارات طويلة تبدأ بشرطتين (`-'). يتم تضمين ملخص للخيارات أدناه.

-s FILE, --source FILE

ملف المصدر. يمكن أن يكون الملف ملف صورة (تم إنشاؤه بواسطة partclone) أو جهازًا يعتمد على إجراءاتك. عادةً، مصدر النسخ الاحتياطي هو جهاز، ومصدر الاستعادة هو ملف صورة.

يتم دعم استقبال البيانات من خط الأنابيب فقط عند الاستعادة، تجاهل خيار -s أو استخدام '-' يعني استقبال البيانات من stdin.

-o FILE, --output FILE

ملف الإخراج. يمكن أن يكون الملف ملف صورة (سينشئه partclone) أو جهازًا يعتمد على إجراءاتك. عادةً، يتم نسخ النسخ الاحتياطي إلى ملف صورة والاستعادة إلى جهاز.

إرسال البيانات إلى خط الأنابيب مدعوم أيضًا للنسخ الاحتياطي فقط، تجاهل خيار -o أو استخدام '-' يعني إرسال البيانات إلى stdout.

-O FILE, --overwrite FILE

استبدال الملف، سيتم الكتابة فوقه إذا كان موجودًا.

-W FILE, --restore_raw_file FILE

إنشاء ملف خام خاص لجهاز الحلقة (loop device).

-c, --clone

حفظ القسم بتنسيق الصورة الخاص.

-r, --restore

استعادة القسم من تنسيق الصورة الخاص.

-b, --dev-to-dev

نسخ محلي من جهاز إلى جهاز مباشرة، المصدر والإخراج كلاهما جهاز.

-D, --domain

إنشاء ملف سجل مجال GNU Ddrescue من الجهاز المصدر. هذا ملف قابل للقراءة البشرية يتم فيه تمييز + للكتل المستخدمة و ؟ للكتل الحرة.

--offset_domain=X

إضافة X (بالبايت) إلى جميع المواقع المبلغ عنها في ملف سجل المجال.

--restore_raw_file

إنشاء ملف خام خاص لجهاز الحلقة.

-L FILE, --logfile FILE

وضع مسار خاص لتسجيل معلومات سجل partclone. (الافتراضي /var/log/partclone.log)

-R, --rescue

الاستمرار بعد أخطاء قراءة القرص.

-C, --no_check

لا تتحقق من حجم الجهاز والمساحة الحرة.

-N, --ncurses

استخدام واجهة المستخدم النصية Ncurses.

-I, --ignore_fschk

تجاهل فحص نظام الملفات.

-i, --ignore_crc

تجاهل خطأ فحص crc.

-F, --force

فرض التقدم.

-f sec, --UI-fresh sec

وضع ثانية خاصة لفواصل زمنية مختلفة.

-z size, --buffer_size size

حجم مخزن القراءة/الكتابة المؤقت (الافتراضي: 1048576)

-q, --quiet

تعطيل رسالة التقدم.

-dlevel, --debug level

تعيين مستوى التصحيح [1|2|3]

-x, --compresscmd CMD

بدء CMD كأنبوب إخراج لضغط الصورة المستنسخة.

-aX, --checksum-mode=X

صيغة المجموع الاختباري (checksum) المستخدمة لإضافة اكتشاف الأخطاء.

حيث X:

0: لا يوجد مجموع اختباري (لا إبطاء، أصغر صورة)

1: CRC32 (حساب سريع، اكتشاف أساسي)

2: xxHash خوارزمية تجزئة سريعة للغاية غير تشفيرية

-kX, --blocks-per-checksum=X

كتابة مجموع اختباري واحد لكل X كتلة.

-w, --skip_write_error

الاستمرار في الاستعادة أثناء أخطاء الكتابة.

--write-direct-io

كتابة البيانات إلى القسم الهدف بدون ذاكرة تخزين مؤقت.

--read-direct-io

قراءة البيانات من القسم المصدر بدون ذاكرة تخزين مؤقت.

-B, --no_block_detail

عرض رسالة التقدم بدون تفاصيل الكتلة.

--binary-prefix

عرض التقدم بحجم البت (الافتراضي هو MB، GB...).

--prog-second

عرض التقدم بالثواني (الافتراضي هو الدقائق).

-E, --offset=X

إضافة إزاحة X (بالبايت) إلى الإخراج.

-T, --btfiles

استعادة الكتلة كملف لـ ClonezillaBT.

-t, --btfiles_torrent

استعادة الكتلة كملف لـ ClonezillaBT ولكن فقط إنشاء تورنت.

-n, --note NOTE

عرض ملاحظة الرسالة (128 كلمة).

-h, --help

عرض ملخص الخيارات.

-v, --version

عرض الإصدار.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

partclone.ext4(8) — Arch Linux

NAME

partclone.ext4

partclone tool for ext4 filesystem

SYNOPSIS

partclone.ext4 [-c|-r] [-d] [-s source] [-o output] [-N nthreads] [-b blocksize] [-F force] [-Z offset]

DESCRIPTION

partclone is a tool to clone, save and restore partitions. It saves and restores only the used blocks, increasing performance and saving storage space. The filesystem is not damaged during the operation.

partclone.ext4 is used to clone and restore ext4 filesystem.

OPTIONS

The following options are available:

-c, --clone
Clone the partition. This is the default action if neither -c nor -r is specified.
-r, --restore
Restore the partition.
-d, --debug
Enable debug output.
-s, --source source
Specify the source file or device. Use "-" to read from stdin.
-o, --output output
Specify the output file or device. Use "-" to write to stdout.
-N, --nthreads nthreads
Set the number of threads to use for cloning or restoring. Default is 1.
-b, --blocksize blocksize
Set the block size for cloning or restoring. Default is 1MB.
-F, --force
Force overwrite of the output file or device.
-Z, --offset offset
Set the offset for the output device. This is useful when restoring to a larger partition.

FILES

/var/log/partclone.log

The log file of partclone

EXAMPLES

 clone /dev/hda1 to hda1.img and display debug information.
   partclone.ext3 -c -d -s /dev/hda1 -o hda1.img
 restore /dev/hda1 from hda1.img and display debug information.
   partclone.extfs -r -d -s hda1.img -o /dev/hda1
 restore image from clonezilla (split, gzip,) with stdin source
   cat sda1.ext3-ptcl-img.gz.a* | gunzip -c | partclone.ext3 -d -r -s - -o /dev/sda1

DIAGNOSTICS

The following diagnostics may be issued on stderr:

partclone provides some return codes, that can be used in scripts:

Code Diagnostic
0 Program exited successfully.
1 Clone or Restore seem failed.
