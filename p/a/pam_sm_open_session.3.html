pam_sm_open_session(3)

الحزمة: pam

التراخيص: GPL-2.0-only

PAM_SM_OPEN_SESSION(3) دليل Linux-PAM PAM_SM_OPEN_SESSION(3)

الاسم

pam_sm_open_session - وظيفة خدمة PAM لبدء إدارة الجلسة

الملخص

#include <security/pam_modules.h>

int pam_sm_open_session(pam_handle_t *pamh, int flags, int argc, const char **argv);

الوصف

وظيفة pam_sm_open_session هي تطبيق وحدة الخدمة لواجهة pam_open_session(3).

يتم استدعاء هذه الوظيفة لبدء جلسة. القيمة الصالحة الوحيدة لـ flags هي صفر أو:

PAM_SILENT

لا تصدر أي رسائل.

قيم الإرجاع

PAM_SESSION_ERR

لا يمكن إنشاء/إزالة إدخال للجلسة المحددة.

PAM_SUCCESS

تم بدء الجلسة بنجاح.
