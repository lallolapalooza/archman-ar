الاسم

pappl-mainloop - وظائف حلقة pappl الرئيسية

المكتبة

إطار تطبيق الطابعة (libpappl، "pkg-config --cflags --libs pappl")

ملخص

#include <pappl/pappl.h>

int
papplMainloop(int argc, char *argv[], const char *version, const char *footer_html, int num_drivers, pappl_driver_t *drivers, pappl_driver_cb_t driver_cb, pappl_ml_autoadd_cb_t autoadd_cb, const char *subcmd_name, pappl_ml_subcmd_cb_t subcmd_cb, pappl_ml_system_cb_t system_cb, pappl_ml_usage_cb_t usage_cb, void *data);

الوصف

تقوم وظيفة

mainloop ببدء تشغيل تطبيق الطابعة وتدعم الوسائط القياسية لسطر الأوامر والسلوكيات.

الوظائف

papplMainloop

تشغيل حلقة رئيسية قياسية لتطبيقات الطابعة.

int  papplMainloop (
    int argc,
    char *argv[],
    const char *version,
    const char *footer_html,
    int num_drivers,
    pappl_pr_driver_t *drivers,
    pappl_pr_autoadd_cb_t autoadd_cb,
    pappl_pr_driver_cb_t driver_cb,
    const char *subcmd_name,
    pappl_ml_subcmd_cb_t subcmd_cb,
    pappl_ml_system_cb_t system_cb,
    pappl_ml_usage_cb_t usage_cb,
    void *data
);

تقوم هذه الوظيفة بتشغيل حلقة رئيسية قياسية لتطبيق طابعة. الوسائط "argc" و "argv" هي تلك التي تم تمريرها إلى وظيفة main.

تحدد الوسيطة "version" رقم إصدار رقمي لتطبيق الطابعة يتوافق مع إرشادات الإصدار الدلالي مع ما يصل إلى أربعة أرقام، على سبيل المثال "1.2.3.4".

تحدد الوسيطة "footer_html" نص HTML لاستخدامه في تذييل الواجهة الويب. إذا كانت NULL، يتم حذف التذييل.

تحدد الوسائط "num_drivers" و "drivers" و "driver_cb" قائمة بالمشغلات واستدعاء المشغل للطابعات. حدد 0 و NULL إذا تم تكوين المشغلات في استدعاء النظام. تحدد الوسيطة "autoadd_cb" استدعاء لإضافة طابعات جديدة تلقائيًا باستخدام الأمر الفرعي "autoadd" وللكشف التلقائي عن المشغل عند الإضافة يدويًا.

تحدد الوسيطة "usage_cb" استدعاء يعرض ملخصًا للاستخدام/المساعدة. إذا كانت NULL، يتم عرض ملخص عام حسب الحاجة.

تحدد الوسيطان "subcmd_name" و "subcmd_cb" اسم واستدعاء لأمر فرعي مخصص. إذا كانت NULL، فلن يتم دعم أوامر فرعية مخصصة.

تحدد الوسيطة "system_cb" وظيفة تقوم بإنشاء كائن pappl_system_t جديد. إذا كانت NULL، يتم إنشاء كائن نظام افتراضي.

توفر الوسيطة "data" بيانات خاصة بالتطبيق لكل من الاستدعاءات.

papplMainloopShutdown

طلب إيقاف تشغيل نظام قيد التشغيل.

void papplMainloopShutdown (void);

تطلب هذه الوظيفة إيقاف تشغيل النظام الذي بدأته papplMainloop.

الأنواع

pappl_ml_subcmd_cb_t

استدعاء أمر فرعي

typedef int (*pappl_ml_subcmd_cb_t)(const char *base_name, int num_options, cups_option_t *options, int num_files, char **files, void *data);

pappl_ml_system_cb_t

استدعاء النظام

typedef pappl_system_t * (*pappl_ml_system_cb_t)(int num_options, cups_option_t *options, void *data);

pappl_ml_usage_cb_t

استدعاء استخدام البرنامج

typedef void (*pappl_ml_usage_cb_t)(void *data);
