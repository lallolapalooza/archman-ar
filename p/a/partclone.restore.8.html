NAME

partclone.restore - partclone restore utility

SYNOPSIS

partclone.restore -c <clonefile> -s <source_device> -d <destination_device> [OPTION]...

DESCRIPTION

partclone.restore is a utility that restores a saved partition image to a specified device. It supports various file systems and can efficiently restore partitions by only copying used blocks.

OPTIONS

-c, --clonefile <clonefile>
Specifies the path to the saved partition image file.
-s, --source <source_device>
Specifies the source device where the image was created from. This is needed for some file system types to correctly adjust the restored partition.
-d, --destination <destination_device>
Specifies the destination device where the partition image will be restored.
-N, --no_rebuild_fs
Do not rebuild the file system after restoring. This can be useful if the file system is already compatible or if you intend to rebuild it manually.
-F, --force_overwrite
Force overwrite of the destination device without confirmation. Use with caution.
-v, --verbose
Enable verbose output, showing more details during the restore process.
-h, --help
Display a help message and exit.
-V, --version
Display version information and exit.

FILES

No specific configuration files are used by partclone.restore.

EXAMPLES

Restore a partition image named my_partition.pcl to the device /dev/sda1, assuming it was originally created from /dev/sda1:

# partclone.restore -c my_partition.pcl -s /dev/sda1 -d /dev/sda1

Restore an image to a different device /dev/sdb1, forcing overwrite:

# partclone.restore -c my_partition.pcl -s /dev/sda1 -d /dev/sdb1 -F

DIAGNOSTICS

partclone.restore will exit with a non-zero status code if an error occurs. Error messages will be printed to standard error.

BUGS

Report bugs to the partclone mailing list or issue tracker.
