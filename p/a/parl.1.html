parl(1)

الحزمة: perl-par-packer

التراخيص: GPL

PARL(1) وثائق Perl مقدمة من المستخدم PARL(1)

الاسم

parl - محمل PAR الثنائي

الملخص

(الرجاء الرجوع إلى pp للحصول على طرق مريحة لإنشاء ملفات تنفيذية مكتفية ذاتياً، أو نصوص برمجية، أو أرشيفات PAR من برامج perl.)

لإنشاء توزيعة PAR من توزيعة CPAN module:

% parl -p                 # إنشاء توزيعة PAR تحت المسار الحالي
% parl -p Foo-0.01        # افتراض توزيعة CPAN غير مضغوطة في Foo-0.01/

لمعالجة توزيعة PAR:

% parl -i Foo-0.01-i386-freebsd-5.8.0.par   # تثبيت
% parl -i http://foo.com/Foo-0.01           # يضيف تلقائياً اسم الأرشيف + إصدار perl
% parl -i cpan://AUTRIJUS/PAR-0.74          # يستخدم دليل مؤلف CPAN
% parl -u Foo-0.01-i386-freebsd-5.8.0.par   # إلغاء التثبيت
% parl -s Foo-0.01-i386-freebsd-5.8.0.par   # توقيع
% parl -v Foo-0.01-i386-freebsd-5.8.0.par   # تحقق

لاستخدام Hello.pm من ./foo.par:

% parl -A./foo.par -MHello
% parl -A./foo -MHello      # جزء .par اختياري

نفس الشيء، ولكن ابحث عن foo.par في @INC;

% parl -Ifoo.par -MHello
% parl -Ifoo -MHello        # نفس الشيء

تشغيل test.pl أو script/test.pl من foo.par:

% parl foo.par test.pl      # يبحث عن 'main.pl' افتراضيًا،
                            # وإلا قم بتشغيل 'test.pl'

لإنشاء ملف تنفيذي مكتفٍ ذاتياً يحتوي على ملف PAR:

% parl -O./foo foo.par
% ./foo test.pl             # نفس الشيء أعلاه

لتضمين الوحدات النمطية غير الأساسية وكائنات مشتركة ضرورية لتنفيذ PAR (مثل "Zlib"، "IO"، "Cwd"، إلخ)، استخدم العلامة -b:

% parl -b -O./foo foo.par
% ./foo test.pl             # يعمل في أي مكان مع تثبيت الوحدات النمطية الأساسية

إذا كنت ترغب أيضًا في تضمين الوحدات النمطية الأساسية، فاستخدم العلامة -B بدلاً من ذلك:

% parl -B -O./foo foo.par
% ./foo test.pl             # يعمل في أي مكان مع مفسر perl

هذا مفيد بشكل خاص عند إنشاء ملفات تنفيذية ثنائية مستقلة؛ راجع pp للحصول على التفاصيل.

الوصف

يقدم هذا الأمر المستقل تقريبًا نفس وظيفة "perl -MPAR"، باستثناء أنه يأخذ ملفات .par المحملة مسبقًا عبر "-Afoo.par" بدلاً من "-MPAR=foo.par".

بالإضافة إلى ذلك، يتيح لك تحويل توزيعة CPAN إلى توزيعة PAR، بالإضافة إلى معالجة هذه التوزيعات. لمزيد من المعلومات حول توزيعات PAR، راجع PAR::Dist.

يمكنك استخدامه لتشغيل ملفات .par:

# يشغل script/run.pl في الأرشيف، ويستخدم lib/* الخاص به كمكتبات
% parl myapp.par run.pl     # يشغل run.pl أو script/run.pl في myapp.par
% parl otherapp.pl          # يشغل أيضًا نصوص perl العادية

ومع ذلك، إذا كان أرشيف .par يحتوي على main.pl أو script/main.pl، فسيتم استخدامه بدلاً من ذلك:

% parl myapp.par run.pl     # يشغل main.pl، مع 'run.pl' كـ @ARGV

أخيرًا، الخيار "-O" ينشئ ملفًا تنفيذيًا ثنائيًا مستقلًا من ملف PAR:

% parl -B -Omyapp myapp.par
% ./myapp                   # تشغيله في أي مكان بدون ملفات perl التنفيذية

باستخدام العلامة "--par-options"، يمكن للملفات التنفيذية التي تم إنشاؤها أن تعمل كـ "parl" لتعبئة ملفات تنفيذية جديدة:

% ./myapp --par-options -Omyap2 myapp.par   # مطابق لـ ./myapp
% ./myapp --par-options -Omyap3 myap3.par   # الآن مع PAR مختلف

للحصول على شرح لتنسيق الملفات التنفيذية المستقلة، يرجى الرجوع إلى par.pl.
