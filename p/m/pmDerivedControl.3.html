pmDerivedControl(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMDERIVEDCONTROL(3) دليل وظائف المكتبة PMDERIVEDCONTROL(3)

الاسم

pmGetDerivedControl, pmSetDerivedControl - الحصول على وتعيين ضوابط للمقاييس المشتقة

C موجز

#include <pcp/pmapi.h>

int pmGetDerivedControl(int what, int *valuep);
int pmSetDerivedControl(int what, int value);

cc ... -lpcp

الوصف

قد تُستخدم هذه الروتينات للتأثير على سلوك خدمات المقاييس المشتقة التي يتم تفعيلها للمقاييس المشتقة العامة باستخدام pmRegisterDerived(3)، pmRegisterDerivedMetric(3) و pmLoadDerivedConfig(3)، أو المقاييس المشتقة لكل سياق باستخدام pmAddDerived(3) و pmAddDerivedMetric(3).

يحدد الوسيط what ضابطًا، ويوفر الوسيط value قيمة لـ pmSetDerivedControl ويستخدم الوسيط valuep لإرجاع القيمة لـ pmGetDerivedControl.

للوسيط what أحد القيم التالية:

PCP_DERIVED_GLOBAL_LIMIT
الحد الأقصى لعدد المقاييس المشتقة العامة التي يمكن تعريفها. القيمة -1 تعني عدم وجود حد.
PCP_DERIVED_CONTEXT_LIMIT
الحد الأقصى لعدد المقاييس المشتقة لكل سياق التي يمكن تعريفها. القيمة -1 تعني عدم وجود حد.
PCP_DERIVED_DEBUG_SYNTAX
تشخيصات التصحيح أثناء تحليل تعبير المقياس المشتق. القيمة 1 تفعل التشخيصات، والقيمة 0 تعطلها.
PCP_DERIVED_DEBUG_SEMANTICS
تشخيصات التصحيح لفحوصات الدلالات أثناء ربط المقاييس في تعبير المقياس المشتق بالمقاييس المتاحة في سياق PMAPI جديد. القيمة 1 تفعل التشخيصات، والقيمة 0 تعطلها.
PCP_DERIVED_DEBUG_EVAL
تشخيصات التصحيح عند استخدام المقاييس المشتقة في عمليات PMAPI مثل pmFetch(3)، pmGetChildren(3)، pmGetChildrenStatus(3)، pmLookupDesc(3)، pmLookupName(3)، pmNameAll(3)، pmNameID(3) و pmTraversePMNS(3).

قيم الإرجاع

كلتا الروتينتين ترجعان 0 عند النجاح، وإلا قيمة أقل من 0 يمكن فك تشفيرها باستخدام pmErrStr(3).

راجع أيضًا

PCPIntro(1)، pmAddDerived(3)، pmAddDerivedMetric(3)، PMAPI(3)، pmErrStr(3)، pmLoadDerivedConfig(3)، pmRegisterDerived(3)، pmRegisterDerivedMetric(3) و PMNS(5).
