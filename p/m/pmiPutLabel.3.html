pmiPutLabel(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMIPUTLABEL(3) دليل وظائف المكتبة PMIPUTLABEL(3)

الاسم

pmiPutLabel - إضافة تسميات إلى أرشيف الإخراج

C ملخص

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutLabel(unsigned int type,
unsigned int id, unsigned int instance, const char *name, const char *value);

cc ... -lpcp_import -lpcp

ملخص Perl

use PCP::LogImport;

pmiPutLabel($type,
$id, $instance, $name, $value);

الوصف

كجزء من واجهة برمجة تطبيقات استيراد سجلات Performance Co-Pilot (انظر LOGIMPORT(3))، تقوم pmiPutLabel بإضافة تسمية للسياق العام أو لمجال معين، أو مجموعة، أو عنصر، أو مجال مثيل، أو مثيل.

يجب أن يكون type أحد الخيارات التالية: PM_LABEL_CONTEXT, PM_LABEL_DOMAIN, PM_LABEL_CLUSTER, PM_LABEL_ITEM, PM_LABEL_INDOM, أو PM_LABEL_INSTANCES.

إذا كان type هو PM_LABEL_CONTEXT، فسيتم تجاهل id و instance. بخلاف ذلك، يجب أن يتطابق id مع مجال، أو مجموعة، أو مقياس، أو مجال مثيل تم تعريفه مسبقًا في استدعاء لـ pmiAddMetric(3).

إذا كان type هو PM_LABEL_INSTANCES، فيجب أن يتطابق instance مع رقم مثيل للمجال المحدد. بخلاف ذلك، يتم تجاهل instance.

name هو سلسلة نصية تحتوي على اسم التسمية المراد إضافتها.

value هو سلسلة نصية تحتوي على قيمة التسمية المراد إضافتها.

لن تتم كتابة أي بيانات حتى يتم استدعاء pmiWrite(3)، لذلك عادةً ما تُستخدم استدعاءات متعددة لـ pmiPutLabel لتجميع عدة تسميات قبل استدعاء pmiWrite(3).

التشخيص

ترجع pmiPutLabel صفرًا عند النجاح، وإلا فإنها ترجع قيمة سالبة يمكن تحويلها إلى رسالة خطأ عن طريق استدعاء pmiErrStr(3).
