NAME

pmfault - Performance Co-Pilot fault injection support

C SYNOPSIS

#include <pcp/fault.h>

int pmFaultInject(const char *file, int line, const char *func, ...);
int pmFaultPoint(const char *file, int line, const char *func, ...);
int pmFaultReturn(const char *file, int line, const char *func, ...);
void pmFaultStatus(FILE *ofp, int detail);
int pmFaultControl(const char *control_file);
int pmFaultSuppression(int enable);

DESCRIPTION

The Performance Co-Pilot (PCP) infrastructure includes a simple fault injection framework, designed primarily for testing and debugging PCP clients and servers.

This framework allows the programmer to inject faults (like memory allocation failures) at specific points in the code, using macros defined in <pcp/fault.h>. The primary macros are:

    PM_FAULT_POINT(name, ...)
    PM_FAULT_RETURN(name, ...)

The fault injection mechanism is controlled by a configuration file, and can be enabled or disabled at run time.

The core functions are:

pmFaultInject
This is the main function called by the fault injection macros. It takes the source file, line number, and function name, along with a variable number of arguments that are used to identify the specific fault point (e.g., a string name). It checks the fault control file to see if a fault should be injected at this location.
pmFaultPoint
This macro expands to a call to pmFaultInject, typically used to simulate a point where an error might occur, but not necessarily cause an immediate failure.
pmFaultReturn
This macro also expands to a call to pmFaultInject. It's typically used at the beginning of a function or block to simulate a failure that causes the function to return prematurely, often with an error code or a specific return value.
pmFaultStatus
Prints a summary of the fault injection status to the specified file pointer. The detail argument controls the level of detail in the output.
pmFaultControl
Loads fault injection rules from the specified control file. This function is usually called implicitly based on the PM_FAULT_CONTROL environment variable.
pmFaultSuppression
Enables or disables the entire fault injection mechanism. A non-zero argument enables it, and zero disables it.

RUN-TIME CONTROL

The behavior of the fault injection mechanism can be controlled at run time using a control file. A typical control file might contain entries like:

    sample.event.records[fungus]: pmUnpackEventRecords: Cannot allocate memory
    sample.event.records[bogus]: pmUnpackEventRecords: Cannot allocate memory

This indicates that when the code at the specified location (e.g., within the function `pmUnpackEventRecords` in the file `sample.event.records`) is executed, and the context matches (e.g., the argument `fungus` or `bogus`), a fault should be injected, simulating a "Cannot allocate memory" error.

The fault injection mechanism keeps track of how many times each fault point has been triggered and how many actual faults have been injected. A summary report can be obtained using pmFaultStatus.

=== Fault Injection Summary Report ===
libpcp/events.c:1: guard trip>2, 5 trips, 3 faults

EXAMPLES

Refer to the PCP and PCP QA source code.

The macro definitions are in src/include/pcp/fault.h.

src/libpcp/src/fault.c contains all of the the underlying implementation.

src/libpcp_fault and src/libpcp_fault/src contains the recipe and Makefiles for creating and installing libpcp_fault.so and <pcp/fault.h>.

PM_FAULT_RETURN was initiallly used in the following libpcp source files: derive_parser.y.in, pdu.c and result.c.

PM_FAULT_POINT. was initiallly used in the following libpcp source files: derive_parser.y.in, desc.c, e_indom.c, e_labels.c, err.c, events.c, exec.c, fetch.c, help.c, instance.c, interp.c, labels.c, logmeta.c, pmns.c, p_profile.c and store.c.

The ``fault'' group of QA tests show examples of control file use. To see which tests are involved

$ cd qa
$ check -n -g fault

DIAGNOSTICS

Some non-recoverable errors are reported on stderr.

ENVIRONMENT

PM_FAULT_CONTROL
Full path to the fault injection control file.
LD_PRELOAD
Force libpcp_fault to be used in preference to libpcp.
