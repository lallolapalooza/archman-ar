pmSeriesQuery(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMSERIESQUERY(3) دليل وظائف المكتبة PMSERIESQUERY(3)

الاسم

pmSeriesQuery، pmSeriesWindow، pmSeriesValues، pmSeriesLoad - استعلام سريع وقابل للتوسع للسلاسل الزمنية

C ملخص

#include <pcp/pmwebapi.h>

int pmSeriesQuery(pmSeriesSettings *sp،
sds *query، pmSeriesFlags flags، void *arg);

int pmSeriesWindow(pmSeriesSettings *sp،
sds *window، pmSeriesTimeWindow *window، void *arg);

int pmSeriesValues(pmSeriesSettings *sp،
pmSeriesTimeWindow *window، int count، sds *series، void *arg);

int pmSeriesLoad(pmSeriesSettings *sp،
sds *query، pmSeriesFlags flags، void *arg);

cc ... -lpcp_web

الوصف

يتم البحث عن معرفات وقيم السلاسل الزمنية باستخدام خدمات السلاسل الزمنية السريعة والقابلة للتوسع لـ Performance Co-Pilot (PCP) باستخدام الأداة المساعدة pmseries(1)، وخدمة واجهة برمجة تطبيقات REST المرتبطة بها pmproxy(1).

يتم مشاركة تطبيق هذه المرافق وهو متاح أيضًا للبرامج الأخرى لاستخدامه. يتم توفير الوظائف من خلال واجهات برمجة التطبيقات غير المتزامنة، والتي تعمل بطريقة تعتمد على الأحداث حيث يتم استدعاء ردود الاتصال لكل مجموعة من معرفات السلاسل أو هياكل القيم التي يتم إرجاعها. يجب تسجيل ردود الاتصال هذه باستخدام pmSeriesSetup(3) قبل إجراء أي استدعاءات لواجهة برمجة تطبيقات الاستعلام.

كنمط عام، تأخذ هذه الواجهات معلمة غامضة (مؤشر void *)، arg. سيتم تمرير هذا المؤشر دون تغيير ويستخدم عادةً للوصول إلى بنية بيانات تحتفظ بالحالة داخل البرنامج المتصل.

اعتمادًا على سلسلة query الخاصة بـ pmseries المقدمة، تعمل pmSeriesQuery في أحد وضعين.

أولاً، إذا لم يتم توفير مواصفات نافذة زمنية (أقواس مربعة)، فستقوم الواجهة بإرجاع معرفات السلاسل المتطابقة فقط ولا توجد قيم. يتم إرجاع هذه المعرفات عبر رد الاتصال on_match المسجل باستخدام pmSeriesSetup. إذا كان تعبير query يتضمن استدعاءات للدوال أو عوامل رياضية (بدلاً من أسماء المقاييس البسيطة)، فسيتم إنشاء المعرف المرجع ديناميكيًا وربطه بشكل دائم بالتعبير. يمكن استرداد تعبير query باستخدام استدعاء واجهة برمجة التطبيقات pmSeriesExprs(3). انظر أيضًا PMWEBAPI(3) والخي ار -e إلى pmseries(1).

الوضع الثاني هو عندما يتم استخدام مواصفات نافذة زمنية في سلسلة query، أو عند استخدام واجهة pmSeriesValues. يوفر هذا الوضع قيمًا وطوابع زمنية لجميع معرفات السلاسل الزمنية المتطابقة التي تحتوي على نقاط بيانات ضمن window الزمنية المقدمة. في هذه الحالة، يتم إرجاع النتائج عبر رد الاتصال on_value المسجل باستخدام pmSeriesSetup. يتم توفير روتين مساعد لإنشاء بنية window زمنية من مواصفات زمنية محاطة بأقواس مربعة في شكل pmSeriesWindow.

يمكن الحصول على بيانات وصفية إضافية (أسماء المقاييس، التسميات، الوحدات، الدلالات، النوع، إلخ) حول السلاسل الزمنية المتطابقة وقيمها باستخدام الواجهات الموصوفة في صفحة الدليل pmSeriesDescs(3).

عادةً، تتم معالجة تحميل السلاسل الزمنية تلقائيًا بواسطة خادم pmproxy، الذي يستخدم سلسلة واجهات pmDiscoverSetup(3) لاكتشاف وتحميل السلاسل الزمنية المسجلة تلقائيًا من pmlogger(1). ومع ذلك، من الممكن أيضًا تحميل السلاسل الزمنية يدويًا من أرشيف PCP باستخدام واجهة pmSeriesLoad. يجب أن توفر سلسلة query المقدمة أرشيفًا أو دليلًا لتحميل البيانات منه باستخدام الكلمة المفتاحية source.path.

التشخيص

حيثما تُرجع هذه الوظائف رمز حالة، يكون دائمًا صفرًا عند النجاح. عند الفشل، يتم إرجاع رمز خطأ PMAPI سالب.

انظر أيضًا

pmproxy(1)، pmlogger(1)، pmSeriesSetup(3)، pmSeriesDescs(3)، pmDiscoverSetup(3)، PMAPI(3) و PMWEBAPI(3).
