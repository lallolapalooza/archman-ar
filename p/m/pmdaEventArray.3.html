الوصف

يتم تشجيع وكيل مجال المقاييس الأداء (PMDA) الذي يرغب في تصدير سجلات الأحداث (أو سجلات التتبع) على استخدام مقياس من نوع PM_TYPE_EVENT أو PM_TYPE_HIGHRES_EVENT لتشفير مجموعة من سجلات الأحداث في مصفوفة مجمعة واحدة.

الفرق الوحيد بين نوعي المقياس هو دقة الطابع الزمني المرتبط بكل منهما - في شكل عالي الدقة، يكون بالمقياس النانوي (انظر clock_gettime(2))، وإلا فهو بالميكرو ثانية (انظر gettimeofday(2)). للتبسيط، سنشير فقط إلى واجهة برمجة التطبيقات وهياكل البيانات ذات الدقة الأقل فيما يلي - ومع ذلك، فإن المتغيرات ذات الدقة الأعلى كلها مسماة بشكل مشابه وتستخدم بنفس الطريقة.

يتم تعريف صيغة المصفوفة المجمعة لسجلات الأحداث في <pcp/pmapi.h> وتتكون من هيكل pmEventArray يحتوي على عدد متغير من هياكل pmEventRecord، كل منها يحتوي على عدد متغير من هياكل pmEventParameter، والتي بدورها قد تحتوي على قيمة بطول متغير لكل معامل من كل سجل أحداث.

يتم تعريف المعادلات عالية الدقة في نفس الموقع، والهياكل تحمل نفس الأسماء. لاحظ أن هيكل pmEventParameter لا يحتوي على طابع زمني مرتبط به، وبالتالي لا يوجد له نظير عالي الدقة.

تم تصميم الروتينات الموصوفة هنا لمساعدة مطور PMDA في بناء مصفوفة مجمعة من سجلات الأحداث، وإدارة جميع تخصيصات الذاكرة المطلوبة للاحتفاظ بكل مثيل لمصفوفة سجلات الأحداث في مخزن مؤقت متجاور. الاستخدام الطبيعي سيكون كجزء من طريقة pmdaFetchCallBack الخاصة بـ PMDA.

يتم استخدام pmdaEventNewArray لإنشاء مصفوفة أحداث جديدة. القيمة المعادة هي عدد صحيح صغير يستخدم كمعامل idx للروتينات الأخرى لتحديد مصفوفة أحداث معينة. إذا لزم الأمر، يمكن لـ PMDA إنشاء واستخدام مصفوفات أحداث متعددة.

لبدء دورة جديدة وإعادة ملء مصفوفة أحداث من البداية، قم باستدعاء pmdaEventResetArray.

إذا انتهى PMDA من استخدام مصفوفة أحداث، يمكن استخدام pmdaEventReleaseArray لتحرير التخزين الأساسي و "إغلاق" مصفوفة الأحداث بحيث تعيد المحاولات اللاحقة لاستخدام idx القيمة PM_ERR_NOCONTEXT.

لبدء سجل حدث جديد، استخدم pmdaEventAddRecord. يتم توفير الطابع الزمني لسجل الحدث عبر tp وقد يتم استخدام المعامل flags لتعيين حقل التحكم الذي يحدد نوع سجل الحدث - قد يكون flags "أو" بbitwise لواحد أو أكثر من قيم PM_EVENT_FLAG_* المعرفة في <pcp/pmapi.h> (ولكن لاحظ أنه لا ينبغي استخدام PM_EVENT_FLAG_MISSED في هذا السياق).

إذا تم فقدان سجلات أحداث، سواء لأن PMDA لا يستطيع المواكبة أو لأن عميل PMAPI لا يستطيع المواكبة، فيمكن استخدام pmdaEventAddMissedRecord. idx و tp لهما نفس المعنى كما هو الحال مع pmdaEventAddRecord و nmissed هو عدد سجلات الأحداث التي تم فقدانها في هذه النقطة من السلسلة الزمنية لسجلات الأحداث. يمكن استدعاء pmdaEventAddMissedRecord عدة مرات لمجموعة واحدة من سجلات الأحداث إذا كان هناك أكثر من حلقة "سجل حدث مفقود" واحدة.

بمجرد بدء سجل حدث عن طريق استدعاء pmdaEventAddRecord، يمكن إضافة معامل حدث واحد أو أكثر باستخدام pmdaEventAddParam. يصف المعاملان pmid و type معرف PMID للمعامل ونوع البيانات (واحد من قيم PM_TYPE_* من <pcp/pmapi.h>) للقيمة التي يتم تمريرها عبر avp. يجب أن يكون type نوعًا يكون حجم القيمة فيه ضمنيًا من type أو من طول قيمة السلسلة (لـ PM_TYPE_STRING) أو مشفرًا داخل avp->vbp (لـ PM_TYPE_AGGREGATE).

بمجرد بناء المصفوفة المجمعة، يجب استخدام pmdaEventGetAddr لتهيئة حقلي ea_type و ea_len في بداية pmEventArray وإرجاع العنوان الأساسي للمصفوفة المجمعة التي تم تعيينها للحقل vp لهيكل pmAtomValue الذي يجب أن تعيده طريقة pmdaFetchCallBack.

pmdaEventHighResAddParam و pmdaEventHighResGetAddr هي أسماء سابقة لـ pmdaEventAddHighResParam و pmdaEventGetHighResAddr (على التوالي) تم الاحتفاظ بها للتوافق مع الإصدارات السابقة.

مثال

يوضح الكود الهيكلي التالي كيف يمكن استخدام هذه الروتينات.

int             sts;
int             myarray;
int             first = 1;
pmEventArray    eap;
if (first) {
   first = 0;
   if ((myarray = pmdaEventNewArray()) < 0) {
      // تقرير خطأ وفشل
   }
}
pmdaEventResetArray(myarray);
// التكرار فوق جميع سجلات الأحداث التي سيتم تصديرها
... {
   struct timeval   stamp;
   int              flags;
   // تعيين الطابع الزمني وتعيين العلامات إلى 0 أو أي تركيبة
   // من PM_EVENT_FLAG_POINT, PM_EVENT_FLAG_START, PM_EVENT_FLAG_ID,
   // إلخ.
   if ((sts = pmdaEventAddRecord(myarray, &stamp, flags)) < 0) {
      // تقرير خطأ وفشل
   }
   // التكرار فوق جميع المعاملات لهذا السجل الحدث
   ... {
      pmID          pmid;
      int           type;
      pmAtomValue   atom;
      // إنشاء pmid, type و atom للمعامل
      // وقيمته
      if ((sts = pmdaEventAddParam(myarray, pmid, type, &atom)) < 0) {
	 // تقرير خطأ وفشل
      }
   }
   // إذا تم فقدان بعض سجلات الأحداث (يمكن أن تكون في بداية
   // المجموعة المصدرة، أو في النهاية، أو في المنتصف، أو
   // تركيبة من حلقات سجلات مفقودة متعددة)
   ... {
      int              nmissed;
      struct timeval   stamp;
      if ((sts = pmdaEventAddMissedRecord(myarray, &stamp, nmissed)) < 0) {
	 // تقرير خطأ وفشل
      }
   }
}
// إنهاء
eap = pmdaEventGetAddr(myarray);
