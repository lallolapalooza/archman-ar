PMHTTPNEWCLIENT(3) دليل دوال المكتبة PMHTTPNEWCLIENT(3)

الاسم

pmhttpNewClient, pmhttpFreeClient, pmhttpClientFetch - واجهات عميل HTTP بسيطة

C ملخص

#include <pcp/pmapi.h>
#include <pcp/pmhttp.h>

struct http_client *pmhttpNewClient(void);
void pmhttpFreeClient(struct http_client *client);
int pmhttpClientFetch(struct http_client *client,
const char *url, char *bodybuf, size_t bodylen, char *typebuf, size_t typelen);

cc ... -lpcp_web

الوصف

pmhttpNewClient تقوم بتخصيص وتهيئة عميل HTTP غير شفاف يكون جاهزًا لإجراء طلبات من خادم.

واجهة طلب عنوان URL pmhttpClientFetch تصدر طلب HTTP GET إلى الخادم المحدد في url المقدم. يتم إرجاع نص الاستجابة في المخزن المؤقت bodybuf الذي يوفره المتصل، بطول bodylen بايت. يمكن أيضًا توفير مخزن مؤقت اختياري typebuf، بطول typelen بايت، (إذا لم يكن NULL) سيحتوي على قيمة ترويسة content-type التي تم إرجاعها من الخادم.

المعلمة url هي عنوان URL بتنسيق RFC1630. عادةً ما تسبقها "http://"، ومع ذلك تدعم هذه الواجهات أيضًا مقابس مجال Unix. يتم استبدالها بـ "unix://"، متبوعة بالمسار الكامل لنظام الملفات لمقبس مجال Unix المطلوب.

لتحرير الموارد المرتبطة بعميل HTTP، بما في ذلك إغلاق أي اتصال خادم دائم تم إنشاؤه سابقًا، يتم ذلك باستخدام الإجراء pmhttpFreeClient.

التشخيصات

pmhttpNewClient ستعيد NULL عند الفشل، والذي يمكن أن يحدث فقط عند عدم إمكانية تخصيص الذاكرة.

pmhttpClientFetch ستعيد عدد البايتات التي تم وضعها في المخزن المؤقت bodybuf، أو رمز خطأ معكوس يشير إلى طبيعة الفشل.
