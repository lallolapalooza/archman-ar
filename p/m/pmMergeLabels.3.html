pmMergeLabels(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMMERGELABELS(3) دليل وظائف المكتبة PMMERGELABELS(3)

الاسم

pmMergeLabels, pmMergeLabelSets - دمج مجموعات من تسميات مقاييس الأداء

C ملخص

#include <pcp/pmapi.h>

int pmMergeLabels(char **sets,
int nsets, char *buffer, int length);

int pmMergeLabelSets(pmLabelSet **sets,
int nsets, char *buffer, int length, int (*filter) (const pmLabel *, const char *, void *), void *arg);

cc ... -lpcp

PYTHON ملخص

from pcp import pmapi

buffer = pmapi.pmContext().pmMergeLabels(sets)
buffer = pmapi.pmContext().pmMergeLabelSets(sets, filter)

الوصف

تأخذ pmMergeLabels مجموعات متعددة (nsets) من sets تسميات مقاييس الأداء و تدمجها في buffer نتيجة واحد من length بايت. كل من المدخلات sets والنتيجة buffer هي أزواج name:value في صيغة "JSONB" الموصوفة في pmLookupLabels(3).

واجهة pmMergeLabelSets تخدم نفس الغرض، ولكن تسمح بدمج sets مفهرسة من التسميات. صيغة بنية بيانات pmLabelSet موصوفة بالتفصيل في pmLookupLabels(3).

على الرغم من أن الأسماء قد تتكرر عبر sets التسميات المقدمة، فإن الأسماء المكررة غير مسموح بها في buffer النهائي. يتم تقليل أي أسماء تسميات تحدث في أكثر من واحدة من sets التسميات المدخلة إلى واحد باستخدام القواعد الموصوفة في قسم "PRECEDENCE" في pmLookupLabels. يعتبر موقع كل عنصر في مصفوفة sets مهماً من حيث قواعد الأسبقية - تعتبر المواقع السابقة ذات أسبقية أقل من المواقع اللاحقة.

يجب أن تكون القيم كيانات JSON بدائية (مثل الأرقام، السلاسل)، مصفوفات أحادية البعد، أو خرائط (أي، مصفوفات ترابطية بسيطة).

بالإضافة إلى استخدام sets التسميات المفهرسة، توفر واجهة pmMergeLabelSets دالة رد اتصال filter اختيارية. إذا لم تكن NULL، سيتم استدعاء هذه الدالة لكل تسمية سيتم إضافتها إلى buffer الناتج، مما يسمح بتحكم أدق في المجموعة المدمجة النهائية. يمكن استخدام هذه الآلية لـ filter التسميات الفردية بناءً على اسمها، قيمتها، و/أو علاماتها. إذا عادت دالة filter بقيمة صفر (false)، فسيتم تصفية التسمية المعطاة من المجموعة الناتجة. أي قيمة غير صفرية تشير إلى أنه يجب تضمين التسمية في buffer.

مثال PYTHON

import sys
import json
from pcp import pmapi
import cpmapi as c_api
def merge_callback(label, jsondata, data=None):
    d = json.loads(jsondata)
    labelsD.update(d)
    return 0
ctx = pmapi.pmContext()
for metric in sys.argv[1:]:
    pmid = ctx.pmLookupName(metric)[0]
    lset = ctx.pmLookupLabels(pmid)
    labelsD = {}
    ctx.pmMergeLabelSets(lset, merge_callback)
    print("== %s ===" % metric)
    for n,v in labelsD.items():
        print("    %s = %s" % (n,v))
    ctx.pmFreeLabelSets(lset)

التشخيص

عند النجاح، تعيد كل من pmMergeLabels و pmMergeLabelSets عدد البايتات المكتوبة في buffer المقدم.

الفشل في تحليل السلاسل المدخلة، الفشل في تخصيص الذاكرة، أو أي عدم اتساق داخلي تم العثور عليه سيؤدي إلى رمز إعادة سالب.
