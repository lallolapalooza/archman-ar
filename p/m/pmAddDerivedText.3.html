pmAddDerivedText(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMADDDERIVEDTEXT(3) دليل الوظائف المكتبية PMADDDERIVEDTEXT(3)

الاسم

pmAddDerivedText - إضافة نص مساعدة للمقياس المشتق

C ملخص

#include <pcp/pmapi.h>

int pmAddDerivedText(const char *name,


int type, const char *text);

cc ... -lpcp

الوصف

توفر المقاييس المشتقة وسيلة لتوسيع مساحة أسماء مقاييس الأداء (PMNS) بمقاييس جديدة محددة من جانب عميل PCP باستخدام تعبيرات على مقاييس الأداء الحالية. يتم تعريف المقاييس المشتقة العامة باستخدام pmRegisterDerived(3) أو pmRegisterDerivedMetric(3) أو pmLoadDerivedConfig(3)، ويتم تعريف المقاييس المشتقة لكل سياق باستخدام pmAddDerived(3) أو pmAddDerivedMetric(3).

بمجرد تحديد مقياس مشتق، يمكن استخدام pmAddDerivedText لربط text المساعدة بالمقياس المشتق المحدد بواسطة name.

قد يكون نص المساعدة "سطر واحد" موجزًا أو كتلة نصية "متعددة الأسطر" أكثر تفصيلاً، ويجب أن يكون type هو PM_TEXT_ONELINE أو PM_TEXT_HELP على التوالي. لربط كلا نمطي نص المساعدة بمقياس مشتق، ستحتاج إلى استدعاء pmAddDerivedText مرتين بقيم مختلفة لـ type.

بمجرد ربط نوع معين من نصوص المساعدة بمقياس مشتق، لا يمكن حذفه أو إعادة تعريفه.

يمكن للتطبيقات التي تستخدم واجهة برمجة تطبيقات مقاييس الأداء (PMAPI) استرداد نصوص المساعدة لمقاييس محددة باستخدام pmLookupText(3).

التشخيصات

تعيد pmAddDerivedText صفرًا عند النجاح، وإلا رمز خطأ.

يشير الخطأ PM_ERR_NAME إلى أن name لا يتوافق مع مقياس مشتق تم تعريفه مسبقًا.

ستؤدي الاستدعاءات المتكررة لنفس name و type إلى إعادة قيمة PM_ERR_TEXT.

تشير القيمة المرجعة PM_ERR_ARG إلى أن type ليس إحدى القيم المتوقعة.

راجع أيضًا

PCPIntro(1)، pmAddDerived(3)، pmAddDerivedMetric(3)، PMAPI(3)، pmLoadDerivedConfig(3)، pmLookupText(3)، pmRegisterDerived(3)، pmRegisterDerivedMetric(3) و PMNS(5).
