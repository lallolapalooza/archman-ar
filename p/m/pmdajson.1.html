PMDAJSON(1) دليل الأوامر العامة PMDAJSON(1)

الاسم

pmdajson - وكيل مجال مقاييس الأداء (PMDA) بصيغة JSON

الوصف

pmdajson هو وكيل مجال مقاييس الأداء (PMDA) يقوم بتصدير المقاييس من مصادر عشوائية تقوم بإنشاء صيغة JSON (JavaScript Object Notation).

يلزم وجود زوج واحد على الأقل من مدخلات JSON لكي يوفر pmdajson مقاييس لعملاء PCP؛ أحدهما يصف بيانات وصفية للمقاييس والآخر يحتوي على بيانات قيم المقاييس. يتم قراءة البيانات الوصفية مرة واحدة من ملف عند بدء تشغيل PMDA، بينما تتم قراءة البيانات في كل مرة يتم فيها طلب قيم المقاييس من قبل عميل PCP. تتم قراءة البيانات إما من ملف JSON أو من أمر خارجي يقوم بإنشاء مخرجات JSON. يمكن استخدام أكثر من زوج واحد من مدخلات JSON لدعم عدد تعسفي من مصادر المقاييس في أدلة معدة بشكل مختلف.

وصف صيغة JSON العامة متاح على http://www.json.org/.

مصادر بيانات JSON

يقرأ pmdajson ملف تكوين JSON إلزامي

$PCP_PMDAS_DIR/json/config.json

يمكن أن يحتوي هذا الملف على خيارات PMDA التالية باستخدام صيغة JSON:

  • directory_list
  • trusted_directory_list

يبحث pmdajson في الأدلة المدرجة لهذه الخيارات بحثًا عن ملفات باسم metadata.json و(افتراضيًا) data.json. تصف ملفات البيانات الوصفية JSON أسماء المقاييس وأنواعها وتفاصيل أخرى لبيانات مقاييس JSON المرتبطة بها. اسم ملف بيانات JSON قابل للتكوين، ويمكن أن يكون أيضًا أمرًا خارجيًا بدلاً من ملف بيانات يتم تحديثه بشكل دوري (بواسطة أدوات خارجية).

كل زوج من هذه الملفات/الأوامر JSON الموجودة يشكل مصدر بيانات JSON.

على سبيل المثال، دعنا نفترض ملف بيانات JSON البسيط التالي الذي يحتوي على قيم لمقياسين، أحدهما من نوع سلسلة والآخر رقمي:

  {
    "string_value": "testing, 1, 2, 3",
    "read_count": 0
  }

لهذه المقاييس، سيكون ملف البيانات الوصفية المطلوب من قبل pmdajson:

  {
    "metrics": [
      {
        "name": "string_value",
        "pointer": "/string_value",
        "type": "string"
      },
      {
        "name": "read_count",
        "pointer": "/read_count",
        "type": "integer",
        "description": "Times values read"
      }
    ]
  }

لمزيد من التفاصيل حول صيغة البيانات الوصفية لـ JSON والخيارات، راجع ملف README المضمن كجزء من تثبيت pmdajson.

نموذج الأمان

مصادر بيانات JSON المدرجة في خيار directory_list ليست موثوقة، مما يعني أنه إذا تم استخدام أوامر خارجية لإنشاء بيانات JSON المطلوبة، فسيتم تشغيل هذه الأوامر تحت المستخدم nobody.

مصادر بيانات JSON المدرجة في خيار trusted_directory_list موثوق بها، مما يعني أنه إذا تم استخدام أوامر خارجية لإنشاء بيانات JSON المطلوبة، فسيتم تشغيل هذه الأوامر تحت المستخدم root.

لمزيد من التفاصيل حول الأمان ووصف تشغيل الأوامر الخارجية، راجع ملف README المضمن كجزء من تثبيت pmdajson.

التثبيت

قم بتثبيت JSON PMDA باستخدام سكربت التثبيت كـ root:

# cd $PCP_PMDAS_DIR/json
# ./Install

لإلغاء التثبيت، قم بما يلي كـ root:

# cd $PCP_PMDAS_DIR/json
# ./Remove

يتم تشغيل pmdajson بواسطة pmcd(1) ولا يجب تنفيذه مباشرة أبدًا. تقوم سكربتات التثبيت والإزالة بإعلام pmcd(1) عند تثبيت الوكيل أو إزالته.

الملفات

$PCP_PMDAS_DIR/json/README
وثائق إضافية لملفات JSON المستخدمة بواسطة pmdajson
$PCP_PMDAS_DIR/json/config.json
ملف تكوين لوكيل pmdajson
$PCP_PMDAS_DIR/json/Install
سكربت تثبيت لوكيل pmdajson
$PCP_PMDAS_DIR/json/Remove
سكربت إلغاء تثبيت لوكيل pmdajson
$PCP_LOG_DIR/pmcd/json.log
ملف السجل الافتراضي للرسائل من وكيل pmdajson

بيئة PCP

تُستخدم متغيرات البيئة التي تبدأ بالبادئة PCP_ لمعلمة أسماء الملفات والأدلة التي يستخدمها PCP. عند كل تثبيت، يحتوي الملف /etc/pcp.conf على القيم المحلية لهذه المتغيرات. قد يتم استخدام المتغير $PCP_CONF لتحديد ملف تكوين بديل، كما هو موضح في pcp.conf(5).
