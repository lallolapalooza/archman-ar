pmiPutValueHandle(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMIPUTVALUEHANDLE(3) دليل وظائف المكتبة PMIPUTVALUEHANDLE(3)

الاسم

pmiPutValueHandle - إضافة قيمة لزوج مقياس-مثيل عبر مقبض

C ملخص

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutValueHandle(int handle, const char *value);

cc ... -lpcp_import -lpcp

Perl ملخص

use PCP::LogImport;

pmiPutValueHandle($handle, $value);

الوصف

كجزء من واجهة برمجة تطبيقات Performance Co-Pilot Log Import API (انظر LOGIMPORT(3))، تقوم pmiPutValueHandle بإضافة قيمة واحدة إلى سجل الإخراج الحالي لمقياس ومثيل معين، باستخدام handle الذي تم تعريفه بواسطة استدعاء سابق لـ pmiGetHandle(3).

يجب أن تكون value بتنسيق متوافق مع نوع المقياس كما هو محدد في استدعاء pmiAddMetric(3).

لن يتم كتابة أي بيانات حتى يتم استدعاء pmiWrite(3)، لذا عادةً ما يتم استخدام استدعاءات متعددة لـ pmiPutValueHandle أو pmiPutValue(3) لتجميع قيم البيانات لعدة أزواج من المقاييس-المثيلات قبل استدعاء pmiWrite(3).

التشخيص

تُرجع pmiPutValueHandle صفرًا عند النجاح وإلا تُرجع قيمة سالبة يمكن تحويلها إلى رسالة خطأ عن طريق استدعاء pmiErrStr(3).

انظر أيضًا

LOGIMPORT(3), pmiErrStr(3), pmiGetHandle(3), pmiPutResult(3), pmiPutValue(3), pmiPutText(3), pmiPutLabel(3) و pmiWrite(3).
