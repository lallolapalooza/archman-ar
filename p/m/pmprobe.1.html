NAME

pmprobe — discover Performance Co-Pilot PMNS metric names and values

SYNOPSIS

pmprobe [-h host] [-i instance] [-q query] [-v]

pmprobe [-h host] [-i instance] [-q query] [-l]

pmprobe [-h host] [-i instance] [-q query] [-a]

pmprobe [-h host] [-i instance] [-q query] [-t]

pmprobe [-h host] [-i instance] [-q query] [-c count]

pmprobe [-h host] [-i instance] [-q query] [-D debug]

pmprobe [-V]

pmprobe [-?]

DESCRIPTION

The pmprobe utility is used to query the Performance Co-Pilot PMNS (Performance Metrics Name Space) for information about performance metrics.

It can be used to list available metrics, to discover metric semantics, and to retrieve current or historical metric values.

The pmprobe command takes a space-separated list of metric names or metric specifications as command line arguments. For each argument, pmprobe will print information about that metric.

If a query contains any wildcards (e.g., *), then it is treated as a pattern match against the PMNS.

Metrics can be qualified with instance domain specifiers, for example, disk.dev(sda) or disk.dev["sda"]. The disk.dev.read metric might have instances such as sda, sdb, etc. The available instances for a metric can be listed using the -i option.

The output format depends on the type of metric and the options specified.

OPTIONS

The options available for pmprobe are:

-h host
Connect to the Performance Metrics Collector Daemon (pmcd) on the specified host. If not specified, the default is to connect to a local pmcd.
-i instance
Fetch the value for the specified instance. If instance is empty, then all instances are fetched. This option can be specified multiple times to fetch multiple instances.
-q query
Specify a query to perform. This is typically a metric name or a pattern. If not specified, the command line arguments are used as queries.
-v
Verbose output. This option can be specified multiple times to increase verbosity.
-l
List all available metrics. This is useful for exploring the PMNS.
-a
Fetch all instances for the specified metric(s). This is equivalent to using -i "".
-t
Fetch only the metric type. This can be used to check if a metric exists and what its type is.
-c count
Fetch only the specified number of count values. This is useful for fetching a limited number of time series data points.
-D debug
Enable debugging output. The debug argument is a comma-separated list of debugging options. See the DEBUGGING OPTIONS section below for more details.
-V
Print version information and exit.
-?
Print a usage message and exit.

PCP ENVIRONMENT

Environment variables with the prefix PCP_ are used to parameterize the file and directory names used by PCP. On each installation, the file /etc/pcp.conf contains the local values for these variables. The $PCP_CONF variable may be used to specify an alternative configuration file, as described in pcp.conf(5).

For environment variables affecting PCP tools, see pmGetOptions(3).

DEBUGGING OPTIONS

The -D or --debug option enables the output of additional diagnostics on stderr to help triage problems, although the information is sometimes cryptic and primarily intended to provide guidance for developers rather end-users. debug is a comma separated list of debugging options; use pmdbg(1) with the -l option to obtain a list of the available debugging options and their meaning.

Debugging options specific to pmprobe are as follows:

Option Description
appl0 batch information when -b used
