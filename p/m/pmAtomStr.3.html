PMATOMSTR(3) دليل وظائف المكتبة PMATOMSTR(3)

الاسم

pmAtomStr, pmAtomStr_r - تحويل قيمة مقياس الأداء إلى سلسلة نصية

C | الملخص

#include <pcp/pmapi.h>

const char *pmAtomStr(const pmAtomValue *avp, int type);
char *pmAtomStr_r(const pmAtomValue *avp,
int type, char *buf, int buflen);

cc ... -lpcp

الوصف

يمكن ترميز جميع قيم مقاييس الأداء في اتحاد pmAtomValue، معرفة على النحو التالي؛

typedef union {
    __int32_t    l;     /* 32-بت موقّع */
    __uint32_t   ul;    /* 32-بت غير موقّع */
    __int64_t    ll;    /* 64-بت موقّع */
    __uint64_t   ull;   /* 64-بت غير موقّع */
    float        f;     /* 32-بت نقطة عائمة */
    double       d;     /* 64-بت نقطة عائمة */
    char         *cp;   /* مؤشر char */
    pmValueBlock *vbp;  /* مؤشر pmValueBlock */
} pmAtomValue;

بالنظر إلى قيمة المقياس الأداء المشار إليها بواسطة avp، ونوع المقياس الأداء المعرف بواسطة type، ستقوم pmAtomStr بإنشاء قيمة المقياس المقابلة كسلسلة نصية، مناسبة للإخراج التشخيصي أو التقريري. تقوم الدالة pmAtomStr_r بنفس الشيء، ولكنها تخزن النتيجة في مخزن مؤقت يوفره المستخدم buf بطول buflen، والذي يجب أن يتسع لما لا يقل عن 80 بايت.

عادةً ما يتم استخراج القيمة لـ type من بنية pmDesc، بعد استدعاء pmLookupDesc(3) لمقياس أداء معين.

إذا كان type هو PM_TYPE_STRING، فسيتم اقتطاع القيم الأطول من 38 حرفًا بعد 34 حرفًا، وسيتم عرض الاقتطاع بنقاط حذف ``...'' في نهاية القيمة.

إذا كان type هو PM_TYPE_AGGREGATE، فسيتم عرض ما يصل إلى أول ثلاث كلمات 32-بت كقيم سداسية عشرية.

إذا كان type هو PM_TYPE_EVENT، فسيتم إنشاء ملخص لعدد سجلات الأحداث الموجودة في القيمة.

يتم الاحتفاظ بالقيمة المرجعة من pmAtomStr في مخزن مؤقت ثابت واحد، لذلك القيمة المرجعة صالحة فقط حتى الاستدعاء التالي لـ pmAtomStr.

ملاحظات

pmAtomStr ترجع مؤشرًا إلى مخزن مؤقت ثابت وبالتالي فهي ليست آمنة للاستخدام المتزامن (thread-safe). يجب على التطبيقات متعددة الخيوط استخدام pmAtomStr_r بدلاً من ذلك.
