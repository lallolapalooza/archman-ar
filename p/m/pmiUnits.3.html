pmiUnits(3)

الحزمة: pcp

PMIUNITS(3) دليل وظائف المكتبة PMIUNITS(3)

الاسم

pmiUnits, pmiID, pmiInDom - إنشاء هياكل بيانات المقاييس الأساسية

C الموجز

#include <pcp/pmapi.h>
#include <pcp/import.h>

pmID pmiID(int domain, int cluster, int item);
pmInDom pmiInDom(int domain, int serial);
pmUnits pmiUnits(int dimSpace,
int dimTime, int dimCount, int scaleSpace, int scaleTime, int scaleCount);

cc ... -lpcp_import -lpcp

Perl الموجز

use PCP::LogImport;

$pmid = pmiID($domain, $cluster, $item);
$indom = pmiInDom($domain, $serial);
$units = pmiUnits($dimSpace,
$dimTime, $dimCount, $scaleSpace, $scaleTime, $scaleCount);

الوصف

كجزء من واجهة برمجة تطبيقات استيراد سجلات Performance Co-Pilot (انظر LOGIMPORT(3))، توفر هذه الروتينات طرقًا مريحة (خاصة للاستخدام النصي) لإنشاء هياكل pmID و pmInDom و pmUnits على التوالي، ليتم استخدامها في استدعاءات لاحقة لـ pmiAddMetric(3) و pmiAddInstance(3).

ارجع إلى pmLookupDesc(3) للحصول على وصف كامل للقيم ودلالات مكونات هيكل pmUnits، وبالتالي قيم الوسائط الصالحة لـ pmiUnits.

انظر أيضًا

LOGIMPORT(3)، pmiAddMetric(3)، pmiAddInstance(3) و pmLookupDesc(3).
