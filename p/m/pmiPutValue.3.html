pmiPutValue(3)

الحزمة: pcp

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later, CC-BY-3.0

PMIPUTVALUE(3) دليل وظائف المكتبة PMIPUTVALUE(3)

الاسم

pmiPutValue - إضافة قيمة لزوج مقياس-مثيل

C موجز

#include <pcp/pmapi.h>
#include <pcp/import.h>

int pmiPutValue(const char *name,
const char *instance, const char *value);

cc ... -lpcp_import -lpcp

Perl موجز

use PCP::LogImport;

pmiPutValue($name, $instance, $value);

الوصف

كجزء من واجهة برمجة تطبيقات استيراد سجلات Performance Co-Pilot (انظر LOGIMPORT(3))، تضيف pmiPutValue قيمة واحدة إلى سجل الإخراج الحالي لمقياس ومثيل معين.

يجب أن يتطابق اسم المقياس name مع اسم تم تعريفه مسبقًا في استدعاء لـ pmiAddMetric(3).

بالنسبة للمقاييس الفردية (تلك المعرفة بنطاق مثيل PM_INDOM_NULL)، يجب أن يكون المثيل instance هو NULL أو سلسلة فارغة، وإلا يجب أن يتطابق المثيل instance مع اسم مثيل تم تعريفه مسبقًا في استدعاء لـ pmiAddInstance(3) لنطاق مثيل المقياس.

يجب أن تكون القيمة value بتنسيق متوافق مع نوع المقياس كما هو محدد في استدعاء لـ pmiAddMetric(3).

لن يتم كتابة أي بيانات حتى يتم استدعاء pmiWrite(3)، لذلك عادةً ما تُستخدم استدعاءات متعددة لـ pmiPutValue أو pmiPutValueHandle(3) لتجميع قيم البيانات لعدة أزواج مقياس-مثيل قبل استدعاء pmiWrite(3).

التشخيصات

ترجع pmiPutValue صفرًا عند النجاح وإلا قيمة سالبة يمكن تحويلها إلى رسالة خطأ عن طريق استدعاء pmiErrStr(3).

انظر أيضًا

LOGIMPORT(3)، pmiAddInstance(3)، pmiAddMetric(3)، pmiErrStr(3)، pmiPutResult(3)، pmiPutValueHandle(3)، pmiPutText(3)، pmiPutLabel(3) و pmiWrite(3).
