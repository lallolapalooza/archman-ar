PMDAMONGODB(1) دليل الأوامر العامة PMDAMONGODB(1)

الاسم

pmdamongodb - مقاييس قاعدة بيانات MongoDB

الوصف

pmdamongodb هو وكيل مجال مقاييس الأداء (PMDA) الخاص بـ Performance Co-Pilot (PCP) والذي يستخرج بيانات الأداء المباشرة من خادم قاعدة بيانات MongoDB قيد التشغيل.

الإعداد

أولاً، يتطلب pmdamongodb تثبيت حزم دعم pymongo - وهي وحدة Python للأغراض العامة للاستعلام عن MongoDB.

بعد ذلك، يقرأ pmdamongodb ملف تكوين اختياري بنمط ini:

$PCP_PMDAS_DIR/mongodb/mongodb.conf

يسمح هذا الملف حاليًا بقسمين، أحدهما لتكوين اتصال مقبس MongoDB، والآخر للمصادقة.

[connection]

host (localhost)
الاتصال بمقبس MongoDB على اسم المضيف المحدد.
port (27017)
الاتصال بمقبس MongoDB على المنفذ المحدد.

[authentication]

username (فارغ)
اسم المستخدم للاتصال بقاعدة البيانات.
password (فارغ)
كلمة المرور للاتصال بقاعدة البيانات.

التثبيت

للتثبيت، يجب القيام بما يلي بصلاحيات الجذر:

# cd $PCP_PMDAS_DIR/mongodb
# ./Install

لإلغاء التثبيت، يجب القيام بما يلي بصلاحيات الجذر:

# cd $PCP_PMDAS_DIR/mongodb
# ./Remove

يتم تشغيل pmdamongodb بواسطة pmcd(1) ويجب عدم تنفيذه مباشرة أبدًا. تقوم نصوص Install و Remove بإعلام pmcd(1) عند تثبيت الوكيل أو إزالته.

الملفات

$PCP_PMDAS_DIR/mongodb/mongodb.conf
ملف تكوين لوكيل pmdamongodb
$PCP_PMDAS_DIR/mongodb/Install
برنامج تثبيت وكيل pmdamongodb
$PCP_PMDAS_DIR/mongodb/Remove
برنامج إلغاء تثبيت وكيل pmdamongodb
$PCP_LOG_DIR/pmcd/mongodb.log
ملف السجل الافتراضي للرسائل من وكيل pmdamongodb

لاحظ أن القيمة العادية/الافتراضية لـ $PCP_PMDAS_DIR هي /var/lib/pcp/pmdas والقيمة الافتراضية لـ $PCP_LOG_DIR هي /var/log/pcp ولكن هذه الإعدادات تعتمد على النظام الأساسي.

بيئة PCP

تُستخدم متغيرات البيئة التي تحمل البادئة PCP_ لتهيئة أسماء الملفات والدلائل المستخدمة بواسطة PCP. في كل تثبيت، يحتوي الملف /etc/pcp.conf على القيم المحلية لهذه المتغيرات. يمكن استخدام المتغير $PCP_CONF لتحديد ملف تكوين بديل، كما هو موضح في pcp.conf(5).
