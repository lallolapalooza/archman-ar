pmgetopt(1)

pmgetopt - تحليل خيارات سطر الأوامر لواجهات برمجة تطبيقات Performance Co-Pilot

الاسم

pmgetopt - تحليل خيارات سطر الأوامر لواجهات برمجة تطبيقات Performance Co-Pilot

الملخص

pmgetopt [-c] [-h] [-l] [-p] [-t] [-v] [-a value] [-d domain] [-D domain] [-m metric] [-M metric] [-n name] [-N name] [-o output] [-P profile] [-r root] [-S source] [-u user] [-U user] [-w width] [-W width] [-x debug] [-X debug]

الوصف

تُستخدم الأداة pmgetopt لتحليل خيارات سطر الأوامر التي قد تُستخدم في واجهات برمجة تطبيقات Performance Co-Pilot (PCP). لا تقوم الأداة نفسها بإجراء أي عمليات PCP؛ إنها مخصصة لتقديم مثال للمبرمجين حول كيفية تحليل خيارات PCP الشائعة.

تقوم pmgetopt بالتحليل فقط من خلال الوسيطة الأولى وهي argv[1]. تتم معالجة الخيارات بناءً على هذه الوسيطة. إذا لم يتم تقديم أي خيارات، فسيتم طباعة رسالة مساعدة افتراضية.

الخيارات

-c
يطبع خيار تكوين.
-h
يطبع خيار مساعدة.
-l
يطبع خيار قائمة.
-p
يطبع خيار ملف تعريف.
-t
يطبع خيار وقت.
-v
يطبع خيار إصدار.
-a value
يحدد القيمة المراد استخدامها مع خيار -a.
-d domain
يحدد نطاقًا (domain) لـ PMDA.
-D domain
يحدد نطاقًا (domain) للـ PMDA (يُستخدم كـ -d).
-m metric
يحدد اسم المقياس (metric).
-M metric
يحدد اسم المقياس (metric) (يُستخدم كـ -m).
-n name
يحدد اسم خدمة.
-N name
يحدد اسم خدمة (يُستخدم كـ -n).
-o output
يحدد تنسيق الإخراج.
-P profile
يحدد ملف ملف تعريف.
-r root
يحدد جذر PMNS.
-S source
يحدد مصدر البيانات.
-u user
يحدد اسم المستخدم.
-U user
يحدد اسم المستخدم (يُستخدم كـ -u).
-w width
يحدد عرض الإخراج.
-W width
يحدد عرض الإخراج (يُستخدم كـ -w).
-x debug
يحدد مستوى التصحيح (debug).
-X debug
يحدد مستوى التصحيح (debug) (يُستخدم كـ -x).

الإعداد

لا يوجد إعداد محدد مطلوب لهذه الأداة.

أمثلة

مثال 1: عرض خيار المساعدة

$ pmgetopt -h

سيؤدي هذا إلى طباعة رسالة مساعدة افتراضية.

مثال 2: تحليل خيار وقت ومقياس

$ pmgetopt -t -m disk.size

سيقوم هذا بتحليل خيار الوقت (-t) وخيار المقياس (-m disk.size) وطباعة المعلومات ذات الصلة.

بيئة PCP

لا تتأثر الأداة pmgetopt بمتغيرات بيئة PCP.

خيارات التصحيح

يمكن استخدام الخيار -x أو -X مع قيمة عددية لتحديد مستوى التفاصيل في إخراج التصحيح.

  • -x 1: إخراج تصحيح أساسي.
  • -x 2: إخراج تصحيح مفصل.
