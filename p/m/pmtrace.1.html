PMTRACE(1) دليل الأوامر العامة PMTRACE(1)

الاسم

pmtrace - تتبع الأداء من سطر الأوامر

الملخص

pmtrace [-q?] [-c value | -e command | -v value] [-h host] [-S state] tag

الوصف

يوفر pmtrace واجهة سطر أوامر بسيطة لوكيل نطاق مقاييس الأداء (PMDA) الخاص بالتتبع والمكتبة المرتبطة بها pcp_trace.

السلوك الافتراضي لـ pmtrace هو توفير بيانات تتبع النقاط لوكيل PMDA الخاص بالتتبع، باستخدام الوسيط tag كاسم تعريف مرتبط بكل نقطة تتبع. يصبح الوسيط tag بعد ذلك معرف مثيل ضمن مجموعة مقاييس trace.point.

خيارات

الخيارات المتاحة لسطر الأوامر هي:

-c value
يسمح بتصدير عداد value عشوائي عبر مقاييس trace.count.
-e command
يسمح بتنفيذ command عشوائي. سيتم قياس هذا command كمعاملة نظرًا لأن له نقاط بداية ونهاية محددة جيدًا. تتوفر المعلومات من خلال مقاييس trace.transact.
-h host
يرسل بيانات التتبع إلى وكيل PMDA الخاص بالتتبع الذي يعمل على host، بدلاً من الجهاز المحلي. هذا يتجاوز استخدام متغير البيئة PCP_TRACE_HOST.
-q
يقمع الرسائل من تتبع ناجح، بحيث يعمل pmtrace بصمت.
-S state
يمكّن تصحيح الأخطاء والتتبع الداخلي. قيمة state هي مزيج من بتات من علامات التصحيح كما هو محدد في pmtracestate(3)، وقد يتم تحديدها باستخدام صيغة الأعداد العشرية أو الست عشرية المنصوص عليها في strtol(3).
-v value
يسمح بتصدير value عشوائي ذو فاصلة عائمة عبر مقاييس trace.observe.
-?
يعرض رسالة الاستخدام ويخرج.

التشخيصات

يتم إنشاء جميع الرسائل على الخطأ القياسي وهي مصممة لتكون واضحة بذاتها.

حالة خروج pmtrace دائمًا صفر باستثناء عندما يكون الخيار -e قيد الاستخدام، وفي هذه الحالة يتم إرجاع حالة خروج command.

الملفات

$PCP_DEMOS_DIR/trace/pmtrace.c
الكود المصدري لـ pmtrace

البيئة

نظرًا لأن pmtrace يستخدم روتينات مكتبة libpcp_trace، فإنه يحترم متغيرات البيئة PCP_TRACE_HOST و PCP_TRACE_PORT و PCP_TRACE_TIMEOUT. ارجع إلى pmdatrace(3) للحصول على وصف مفصل لدلالات كل منها.

بيئة PCP

تُستخدم متغيرات البيئة ذات البادئة PCP_ لتهيئة أسماء الملفات والدلائل التي يستخدمها PCP. في كل تثبيت، يحتوي الملف /etc/pcp.conf على القيم المحلية لهذه المتغيرات. يمكن استخدام المتغير $PCP_CONF لتحديد ملف تكوين بديل، كما هو موضح في pcp.conf(5).
