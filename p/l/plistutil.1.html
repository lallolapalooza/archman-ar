plistutil(1)

الحزمة: libplist

التراخيص: LGPL-2.1-or-later

plistutil(1) دليل الأوامر العامة plistutil(1)

الاسم

plistutil - تحويل ملف plist بين الصيغة الثنائية، XML، و JSON

الاختصار

plistutil [خيارات] [-i ملف] [-o ملف]

الوصف

يسمح plistutil بتحويل ملف قائمة الخصائص (Property List) بين الصيغة الثنائية، XML، و JSON.

الخيارات

-i, --infile ملف
ملف الإدخال لتحويل منه. إذا تم حذف هذا الوسيط أو تم تمرير "-" كاسم ملف، فسيقرأ plistutil من الإدخال القياسي.
-o, --outfile ملف
ملف الإخراج للتحويل إليه. إذا تم حذف هذا الوسيط أو تم تمرير "-" كاسم ملف، فسيقوم plistutil بالكتابة إلى الإخراج القياسي.
-f, --format [bin|xml|json|openstep]
فرض صيغة الإخراج، بغض النظر عن نوع الإدخال. هذا مفيد إذا لم تكن صيغة الإدخال معروفة، ولكن صيغة الإخراج يجب أن تكون دائمًا بصيغة معينة (مثل xml أو json).

إذا تم حذفها، سيتم تحويل بيانات plist بصيغة XML إلى ثنائية والعكس صحيح. للتحويل إلى/من JSON أو OpenStep، يجب تحديد صيغة الإخراج.

-p, --print ملف
طباعة PList بصيغة قابلة للقراءة للبشر.
-c, --compact
JSON و OpenStep فقط: طباعة الإخراج بصيغة مضغوطة. افتراضيًا، سيتم تنسيق الإخراج بشكل جميل.
-s, --sort
فرز جميع عقد القاموس أبجديًا حسب المفتاح قبل التحويل إلى صيغة الإخراج.
-h, --help
طباعة معلومات الاستخدام.
-d, --debug
تمكين إخراج التصحيح الموسع.
-v, --version
طباعة معلومات الإصدار.

أمثلة

plistutil -i test.plist -o out.plist
تحويل test.plist والكتابة إلى out.plist. إذا كان test.plist بصيغة XML، فسيكون out.plist بصيغة ثنائية. إذا كان test.plist بصيغة ثنائية، فسيكون out.plist بصيغة XML.
plistutil -i test.plist -o out.plist -f bin
نفس الشيء كما في السابق، ولكن سيكون الإخراج دائمًا بصيغة ثنائية.
plistutil -i test.plist -f xml
طباعة test.plist كـ plist بصيغة XML، بغض النظر عن صيغة الإدخال.
plistutil -i test.plist -f xml -o -
نفس الشيء كما في السابق.
plistutil -i test.plist -f json
طباعة test.plist كـ PList بصيغة JSON، بغض النظر عن صيغة الإدخال.
cat test.plist |plistutil -f xml
أخذ بيانات plist من الإدخال القياسي - تم تمريرها عبر cat - وكتابة الإخراج بصيغة XML إلى الإخراج القياسي.
