podman-images(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-images(1) دليل الأوامر العامة podman-images(1)

الاسم

podman-images - سرد الصور في التخزين المحلي

ملخص

podman images [خيارات] [صورة]

podman image list [خيارات] [صورة]

podman image ls [خيارات] [صورة]

الوصف

يعرض الصور المخزنة محليًا، وأسمائها، ومعرفاتها.

الخيارات

--all, -a

إظهار كل الصور (افتراضيًا يتم استبعاد طبقات الصور الوسيطة). الافتراضي هو خطأ.

--digests

إظهار هويات الصور

--filter, -f=مرشح

تقديم قيم المرشح.

يكون تنسيق وسيطة المرشحات هو مفتاح=قيمة أو مفتاح!=قيمة. إذا كان هناك أكثر من مرشح واحد، فقم بتمرير خيارات متعددة: --filter foo=bar --filter bif=baz.

المرشحات المدعومة:

المرشح الوصف
id الترشيح حسب معرف الصورة.
before الترشيح حسب الصور التي تم إنشاؤها قبل الصورة المحددة (اسم أو علامة).
containers الترشيح حسب الصور التي تحتوي على حاوية قيد التشغيل.
dangling الترشيح حسب الصور المتدلية (غير المستخدمة).
digest الترشيح حسب الهوية.
intermediate الترشيح حسب الصور التي تكون متدلية وليس لها أطفال
label الترشيح حسب الصور التي تحتوي على (أو لا تحتوي على، في حالة استخدام label!=[...] ) الملصقات المحددة.
manifest الترشيح حسب الصور التي هي قوائم manifest.
readonly الترشيح حسب الصور للقراءة فقط أو للقراءة/الكتابة.
reference الترشيح حسب اسم الصورة.
after/since الترشيح حسب الصور التي تم إنشاؤها بعد الصورة المحددة (اسم أو علامة).
until الترشيح حسب الصور التي تم إنشاؤها حتى المدة الزمنية أو الوقت المحدد.

يقبل وسيط المرشح id سلسلة معرف الصورة.

يقبل وسيط المرشح before التنسيقات: <اسم_الصورة>[:<علامة>]، <معرف_الصورة> أو <صورة@هوية>.

مرشح containers يعرض الصور التي تحتوي على حاوية قيد التشغيل تستند إلى هذه الصورة.

مرشح dangling يعرض الصور التي تشغل مساحة على القرص ولا تخدم أي غرض. الصورة المتدلية هي طبقة نظام ملفات تم استخدامها في بناء سابق للصورة ولم تعدشار إليها بواسطة أي صورة. يتم تمييزها بالعلامة <none>، وتستهلك مساحة على القرص ولا تخدم أي غرض نشط.

يقبل وسيط المرشح digest سلسلة هوية الصورة.

مرشح intermediate يعرض الصور التي تكون متدلية وليس لها أطفال.

يقبل وسيط المرشح label تنسيقين. أحدهما هو label=مفتاح أو label=مفتاح=قيمة، والذي يعرض الصور ذات الملصقات المحددة. التنسيق الآخر هو label!=مفتاح أو label!=مفتاح=قيمة، والذي يعرض الصور التي لا تحتوي على الملصقات المحددة.

مرشح manifest يعرض الصور التي هي قوائم manifest.

مرشح readonly يعرض، افتراضيًا، كلاً من الصور للقراءة فقط والصور للقراءة/الكتابة. يمكن تكوين الصور للقراءة فقط عن طريق تعديل additionalimagestores في الملف /etc/containers/storage.conf.

يقبل وسيط المرشح reference نمط مرجع الصورة <اسم_الصورة>[:<علامة>].

يقبل وسيط المرشح after أو since التنسيقات: <اسم_الصورة>[:<علامة>]، <معرف_الصورة> أو <صورة@هوية>.

يقبل وسيط المرشح until التنسيقات: مدة golang، وقت RFC3339، أو طابع زمني Unix ويعرض جميع الصور التي تم إنشاؤها حتى ذلك الوقت.

--format=تنسيق

تغيير تنسيق الإخراج الافتراضي. يمكن أن يكون هذا من نوع مدعوم مثل 'json' أو قالب Go. يتم سرد العناصر النائبة الصالحة لقالب Go أدناه:

العنصر النائب الوصف
.Containers عدد الحاويات التي تستخدم هذه الصورة
.Created الوقت المنقضي منذ إنشاء الصورة
.CreatedAt وقت إنشاء الصورة، YYYY-MM-DD HH:MM:SS +nnnn
.CreatedSince نفس .Created
.CreatedTime نفس .CreatedAt
.Dangling نفس .IsDangling
.Digest هوية الصورة
.History تاريخ طبقة الصورة
.ID معرف الصورة (مقتطع)
.Id معرف الصورة (SHA كامل)
.IsDangling هل الصورة متدلية؟ (صحيح/خطأ)
.IsReadOnly هل الصورة للقراءة فقط؟ (صحيح/خطأ)
.Labels ... map[] من الملصقات
.Names اسم الصورة الكامل (FQIN)
.ParentId SHA كامل لمعرف الصورة الأصل، أو null (سلسلة)
.ReadOnly نفس .IsReadOnly
.RepoDigests map[] من صفر أو أكثر من سلاسل repo/name@sha256:SHA
.Repository مستودع الصورة
.RepoTags map[] من صفر أو أكثر من سلاسل FQIN لهذه الصورة
.SharedSize يبدو دائمًا 0
.Size حجم الطبقة على القرص (سلسلة سهلة القراءة)
.Tag علامة الصورة
.VirtualSize حجم الطبقة على القرص (بايت)

--history

عرض تاريخ أسماء الصور. إذا تم إعادة تسمية صورة أو إلغاء تسميتها، فإن تاريخ اسم الصورة يتم إلحاقه في البداية (أحدث صورة أولاً). هذا مفيد بشكل خاص عند التراجع عن عملية علامة أو إذا كانت الصورة لا تحتوي على اسم لأنها تم إلغاء تسميتها.

--no-trunc

لا تقم بقطع الإخراج (الافتراضي خطأ).

--noheading, -n

تضمين رؤوس الجدول من القائمة.

--quiet, -q

يسرد معرفات الصور فقط.

--sort=فرز

فرز حسب created، id، repository، size أو tag (الافتراضي: created) عند الفرز حسب repository يتم أيضًا الفرز حسب tag كمعيار ثانٍ لتقديم إخراج مستقر.

أمثلة

سرد جميع الصور غير المتدلية في التخزين المحلي:

$ podman images
REPOSITORY                         TAG         IMAGE ID      CREATED       SIZE
quay.io/podman/stable              latest      e0b7dabc3352  22 hours ago  331 MB
docker.io/library/alpine           latest      9c6f07244728  5 days ago    5.83 MB
registry.fedoraproject.org/fedora  latest      2ecb6df95994  3 weeks ago   169 MB
quay.io/libpod/testimage           20220615    f26aa69bb3f3  2 months ago  8.4 MB

سرد جميع الصور التي تطابق الاسم المحدد:

$ podman images stable
REPOSITORY             TAG         IMAGE ID      CREATED       SIZE
quay.io/podman/stable  latest      e0b7dabc3352  22 hours ago  331 MB

سرد معرفات الصور لجميع الصور في تخزين الحاويات:

# podman image ls --quiet
e3d42bcaf643
ebb91b73692b
4526339ae51c

سرد جميع الصور دون إظهار الرؤوس:

# podman images --noheading
docker.io/kubernetes/pause                   latest   e3d42bcaf643   3 years ago   251 kB
<none>                                       <none>   ebb91b73692b   4 weeks ago   27.2 MB
docker.io/library/ubuntu                     latest   4526339ae51c   6 weeks ago   126 MB

سرد جميع الصور دون اقتطاع الإخراج:

# podman image list --no-
