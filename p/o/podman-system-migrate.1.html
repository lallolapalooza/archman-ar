NAME

\n

podman-system-migrate - Migrate existing containers to a new\n podman version

\n
\n
\n

SYNOPSIS

\n

podman system migrate [options]

\n
\n
\n

DESCRIPTION

\n

podman system migrate migrates containers to the latest\n podman version.

\n

podman system migrate takes care of migrating existing\n containers to the latest version of podman if any change is necessary.

\n

"Rootless Podman uses a pause process to keep the\n unprivileged namespaces alive. This prevents any change to the\n /etc/subuid and /etc/subgid files from being propagated to the\n rootless containers while the pause process is running.

\n

\nFor these changes to be propagated, it is necessary to first stop\n all running containers associated with the user and to also stop the pause\n process and delete its pid file. Instead of doing it manually, podman\n system migrate can be used to stop both the running containers and\n the pause process. The /etc/subuid and /etc/subgid files can\n then be edited or changed with usermod to recreate the user namespace with\n the newly configured mappings.

\n
\n
\n

OPTIONS

\n
\n

--new-runtime=runtime

\n

Set a new OCI runtime for all containers. This can be used after a\n system upgrade which changes the default OCI runtime to move all containers\n to the new runtime. There are no guarantees that the containers continue to\n work under the new runtime, as some runtimes support differing options and\n configurations.

\n
\n
\n
\n

EXAMPLES

\n

Normal invocation

\n
### No output is expected from this command.\n$ podman system migrate
\n

Migration to a new OCI runtime (e.g., from crun to runc)

\n
### Create a container using the current default runtime (e.g., crun)\n$ podman create --name test-alpine alpine\n### Confirm the current runtime\n$ podman container inspect test-alpine | grep OCIRuntime\n          "OCIRuntime": "crun",\n### Migrate all containers to use a new runtime (e.g., runc)\n$ podman system migrate --new-runtime runc\n### Verify the container is now using the new runtime\n$ podman container inspect test-alpine | grep OCIRuntime\n          "OCIRuntime": "runc",\n
\n

الاسم

\n

podman-system-migrate - ترحيل الحاويات الموجودة إلى إصدار podman جديد

\n
\n
\n

الملخص

\n

podman system migrate [خيارات]

\n
\n
\n

الوصف

\n

podman system migrate يقوم بترحيل الحاويات إلى أحدث\n إصدار من podman.

\n

podman system migrate يعتني بترحيل الحاويات الحالية إلى أحدث\n إصدار من podman إذا كان أي تغيير ضروريًا.

\n

"يستخدم Rootless Podman عملية توقف مؤقت للحفاظ على نطاقات الأسماء غير المميزة\n قيد التشغيل. هذا يمنع أي تغيير في\n ملفات /etc/subuid و /etc/subgid من الانتشار إلى الحاويات عديمة الجذور\n أثناء تشغيل عملية التوقف المؤقت.

\n

\nلكي تنتشر هذه التغييرات، من الضروري أولاً إيقاف جميع الحاويات قيد التشغيل المرتبطة بالمستخدم\n وإيقاف عملية التوقف المؤقت وحذف ملف pid الخاص بها. بدلاً من القيام بذلك يدويًا، يمكن استخدام\n podman system migrate لإيقاف كل من الحاويات قيد التشغيل وعملية التوقف المؤقت.\n يمكن بعد ذلك تحرير ملفات /etc/subuid و /etc/subgid أو تغييرها باستخدام usermod\n لإعادة إنشاء نطاق أسماء المستخدم مع تعيينات تم تكوينها حديثًا.

\n
\n
\n

خيارات

\n
\n

--new-runtime=runtime

\n

تعيين وقت تشغيل OCI جديد لجميع الحاويات. يمكن استخدام هذا بعد ترقية النظام\n التي تغير وقت التشغيل الافتراضي لنقل جميع الحاويات إلى وقت التشغيل الجديد.\n لا توجد ضمانات بأن الحاويات ستستمر في العمل تحت وقت التشغيل الجديد، حيث تدعم بعض أوقات التشغيل\n خيارات وتكوينات مختلفة.

\n
\n
\n
\n

أمثلة

\n

الاستدعاء العادي

\n
### لا يُتوقع أي إخراج من هذا الأمر.\n$ podman system migrate
\n

الترحيل إلى وقت تشغيل OCI جديد (على سبيل المثال، من crun إلى runc)

\n
### إنشاء حاوية باستخدام وقت التشغيل الافتراضي الحالي (على سبيل المثال، crun)\n$ podman create --name test-alpine alpine\n### تأكيد وقت التشغيل الحالي\n$ podman container inspect test-alpine | grep OCIRuntime\n          "OCIRuntime": "crun",\n### ترحيل جميع الحاويات لاستخدام وقت تشغيل جديد (على سبيل المثال، runc)\n$ podman system migrate --new-runtime runc\n### التحقق من أن الحاوية تستخدم الآن وقت التشغيل الجديد\n$ podman container inspect test-alpine | grep OCIRuntime\n          "OCIRuntime": "runc",\n
