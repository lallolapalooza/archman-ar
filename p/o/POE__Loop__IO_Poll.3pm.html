POE__Loop__IO_Poll(3pm)

الحزمة: perl-poe

التراخيص: GPL, PerlArtistic

POE::Loop::IO_Poll(3) وثائق Perl التي ساهم بها المستخدم POE::Loop::IO_Poll(3)

sub skip_tests {
return "IO::Poll is not 100% compatible with $^O" if (
$^O eq "MSWin32" and not $ENV{POE_DANTIC}
);
return "IO::Poll tests require the IO::Poll module" if (
do { eval "use IO::Poll"; $@ }
); }

الاسم

POE::Loop::IO_Poll - جسر يسمح بتشغيل POE بواسطة IO::Poll

الملخص

انظر POE::Loop.

الوصف

تطبق POE::Loop::IO_Poll الواجهة الموثقة في POE::Loop. لذلك ليس لديها وثائق خاصة بها. يرجى الرجوع إلى POE::Loop لمزيد من التفاصيل.

انظر أيضًا

POE, POE::Loop, IO::Poll, POE::Loop::PerlSignals
