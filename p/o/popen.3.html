popen(3) دليل وظائف المكتبة popen(3)

الاسم

popen, pclose - ربط مجرى تيار بـ أو من عملية

المكتبة

مكتبة C القياسية (libc، -lc)

ملخص

#include <stdio.h>
FILE *popen(const char *command, const char *type);
int pclose(FILE *stream);
متطلبات ماكرو اختبار الميزات لـ glibc (انظر feature_test_macros(7)):

popen(), pclose():

    _POSIX_C_SOURCE >= 2
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

الوصف

تقوم وظيفة popen() بفتح عملية عن طريق إنشاء أنبوب، وعمل fork، واستدعاء shell. نظرًا لأن الأنبوب أحادي الاتجاه بطبيعته، فإن الوسيط type يمكنه تحديد القراءة أو الكتابة فقط، وليس كليهما؛ وبالتالي يكون مجرى التيار الناتج للقراءة فقط أو للكتابة فقط.

الوسيط command هو مؤشر إلى سلسلة نصية منتهية بصفر تحتوي على سطر أوامر shell. يتم تمرير هذا الأمر إلى /bin/sh باستخدام الخيار -c؛ يتم التفسير، إن وجد، بواسطة shell.

الوسيط type هو مؤشر إلى سلسلة نصية منتهية بصفر يجب أن تحتوي إما على الحرف 'r' للقراءة أو الحرف 'w' للكتابة. منذ glibc 2.9، يمكن لهذا الوسيط أن يتضمن بشكل إضافي الحرف 'e'، مما يؤدي إلى تعيين علامة إغلاق عند التنفيذ (FD_CLOEXEC) على واصف الملف الأساسي؛ انظر وصف العلامة O_CLOEXEC في open(2) لمعرفة الأسباب التي قد تجعل هذا مفيدًا.

القيمة المرجعة من popen() هي مجرى I/O قياسي عادي من جميع النواحي باستثناء أنه يجب إغلاقه باستخدام pclose() بدلاً من fclose(3). الكتابة إلى مجرى تيار كهذا تكتب إلى الإدخال القياسي للأمر؛ الإخراج القياسي للأمر هو نفس إخراج العملية التي استدعت popen()، ما لم يتم تعديل ذلك بواسطة الأمر نفسه. على العكس، فإن القراءة من مجرى التيار تقرأ الإخراج القياسي للأمر، والإدخال القياسي للأمر هو نفس الإدخال القياسي للعملية التي استدعت popen().

لاحظ أن مجاري تيار الإخراج لـ popen() مخزنة مؤقتًا افتراضيًا.

تقوم pclose() بالانتظار حتى تنتهي العملية المرتبطة وتعيد حالة خروج الأمر كما أعادتها wait4(2).

قيمة الإرجاع

popen(): عند النجاح، تعيد مؤشرًا إلى مجرى تيار مفتوح يمكن استخدامه للقراءة أو الكتابة إلى الأنبوب؛ إذا فشلت استدعاءات fork(2) أو pipe(2)، أو إذا لم تتمكن الوظيفة من تخصيص الذاكرة، يتم إرجاع NULL.

pclose(): عند النجاح، تعيد حالة خروج الأمر؛ إذا أعادت wait4(2) خطأ، أو تم اكتشاف خطأ آخر، يتم إرجاع -1.

عند الفشل، تحدد كلتا الوظيفتين errno للإشارة إلى الخطأ.

الأخطاء

لا تحدد وظيفة popen() errno إذا فشل تخصيص الذاكرة. إذا فشل fork(2) أو pipe(2) الأساسي، يتم تعيين errno للإشارة إلى الخطأ. إذا كان الوسيط type غير صالح، وتم اكتشاف هذا الشرط، يتم تعيين errno إلى EINVAL.

إذا لم تتمكن pclose() من الحصول على حالة الابن، يتم تعيين errno إلى ECHILD.

تحذيرات

اقرأ تحذيرات system(3) بعناية.

أخطاء

نظرًا لأن الإدخال القياسي لأمر تم فتحه للقراءة يشارك إزاحة البحث الخاص به مع العملية التي استدعت popen()، إذا قامت العملية الأصلية بعملية قراءة مخزنة مؤقتًا، فقد لا يكون موضع إدخال الأمر كما هو متوقع. بالمثل، قد يتداخل الإخراج من أمر تم فتحه للكتابة مع إخراج العملية الأصلية. يمكن تجنب الأخير عن طريق استدعاء fflush(3) قبل popen().

الفشل في تنفيذ shell لا يمكن تمييزه عن فشل shell في تنفيذ الأمر، أو خروج فوري للأمر. التلميح الوحيد هو حالة خروج 127.

popen(3)

popen - execute a shell command

SYNOPSIS

#include <stdio.h>

FILE *popen(const char *command, const char *type);

int pclose(FILE *stream);

DESCRIPTION

The popen() function executes a command specified by command in a new process. The argument type is a string, either "r" for reading from the command's standard output, or "w" for writing to the command's standard input. The return value is a stream pointer associated with the standard input or standard output of the command. This stream can be read from or written to, just like any other stdio stream, until fclose(3) is called on it.

When type is "r", the stream is connected to the standard output of command. When type is "w", the stream is connected to the standard input of command.

The pclose() function closes the file descriptor associated with a stream opened by a previous call to popen(). It returns the exit status of the command to be closed.

If command is a null pointer, popen() returns null and sets errno to EINVAL.

If type is not "r" or "w", popen() returns null and sets errno to EINVAL.

If fork(2) or execve(2) fails, popen() returns null and sets errno appropriately.

If popen() successfully opens the pipe, but cannot fork or execute the shell, it closes the pipe and sets errno to ECHILD.

pclose() returns -1 if the stream was not produced by a call to popen() or if the process terminated abnormally. Otherwise, it returns the exit status of the command.

RETURN VALUE

On success, popen() returns a pointer to a FILE object. On failure, popen() returns NULL and sets errno.

On success, pclose() returns the exit status of the terminated command. On failure, pclose() returns -1.

NOTES

The popen() function should not be used for commands that require complex input or output, as it only allows for reading from or writing to the standard output or standard input of the command.

SEE ALSO

sh(1), execve(2), fork(2), pipe(2), stdio(3)
