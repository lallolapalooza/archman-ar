الاسم

Unicode::LineBreak~[ja] - UAX #14 Unicode خط كسر خوارزمية

ملخص

use Unicode::LineBreak;
$lb = Unicode::LineBreak->new();
$broken = $lb->break($string);

الوصف

Unicode::LineBreak ينفذ خوارزمية خط كسر Unicode الموصوفة في الملحق 14 [UAX #14] لمعيار Unicode. عند تحديد مواضع الكسر، فإنه يأخذ في الاعتبار خاصية East_Asian_Width المحددة في الملحق 11 [UAX #11].

مصطلحات

يستخدم المصطلحات التالية بشكل ملائم:

كسر إلزامي [mandatory break] هو كسر يحدده القواعد الأساسية ويتم تنفيذه بشكل إلزامي بغض النظر عن الأحرف المحيطة. هناك أيضًا كسر مباشر [direct break] و كسر غير مباشر [indirect break].

الأحرف الأبجدية [alphabetic characters] هي الأحرف التي يمكن عادةً كسر الخط بعدها أو قبله. الأحرف التصويرية [ideographic characters] هي الأحرف التي يمكن عادةً كسر الخط بعدها أو قبله.

يجب على الدالة الفرعية إصلاح أجزاء النص وإرجاعها. لإظهار عدم وجود إصلاح، يجب إرجاع "undef". علاوة على ذلك، يؤثر الإصلاح في نصوص "sot"، "sop"، "sol" على تحديد الجزء التالي، لكن الإصلاح في نصوص أخرى لا يؤثر.

ملاحظة: الفهارس النصية هي في الواقع فئات أحرف مكتوبة. انظر Unicode::GCString~[ja].

على سبيل المثال، يقوم الكود التالي بإزالة المسافات البيضاء في نهاية السطر وتطبيق فواصل الأسطر.

sub fmt {
    if ($_[1] =~ /^eo/) {
        return "\n";
    }
    return undef;
}
my $lb = Unicode::LineBreak->new(Format => \&fmt);
$output = $lb->break($text);

وظيفة تقسيم الأسطر المعرفة من قبل المستخدم

عندما يتجاوز السطر الناتج عن التقسيم العشوائي حدود CharMax أو ColMax أو ColMin، يمكن إجراء "تقسيم عاجل" على النص الموروث. إذا تم تحديد مرجع للدالة الفرعية في خيار "Urgent"، يجب أن تأخذ هذه الدالة الفرعية 2 معاملات.

@بعد التقسيم = &الدالة الفرعية(SELF, STR);

SELF هو كائن Unicode::LineBreak، و STR هو النص Unicode المراد تقسيمه.

يجب أن تقوم الدالة الفرعية بإرجاع مصفوفة تمثل نتيجة تقسيم STR النص.

ملاحظة: الفهارس النصية هي في الواقع فئات أحرف مكتوبة. انظر Unicode::GCString~[ja].

على سبيل المثال، يقوم الكود التالي بإدخال شرطات في أسماء بعض المركبات الكيميائية (مثل التيتين) لجعلها قابلة للكسر.

sub hyphenize {
    return map {$_ =~ s/yl$/yl-/; $_} split /(\w+?yl(?=\w))/, $_[1];
}
my $lb = Unicode::LineBreak->new(Urgent => \&hyphenize);
$output = $lb->break("Methionylthreonylthreonylglutaminylarginyl...");

عند تحديد مرجع لإحدى الدالتين الفرعيتين [REGEX, SUBREF] في خيار "Prep"، يجب أن تأخذ الدالة الفرعية 2 معاملات.

@بعد التقسيم = &الدالة الفرعية(SELF, STR);

SELF هو كائن Unicode::LineBreak، و STR هو النص Unicode المراد مطابقته لـ REGEX.

يجب أن تقوم الدالة الفرعية بإرجاع مصفوفة تمثل نتيجة تقسيم STR النص.

على سبيل المثال، يقوم الكود التالي بتقسيم عناوين HTTP باستخدام قاعدة [CMOS].

my $url = qr{http://[\x21-\x7E]+}i;
sub breakurl {
    my $self = shift;
    my $str = shift;
    return split m{(?<=[/]) (?=[^/]) |
                   (?<=[^-.]) (?=[-~.,_?\#%=&]) |
                   (?<=[=&]) (?=.)}x, $str;
}
my $lb = Unicode::LineBreak->new(Prep => [$url, \&breakurl]);
$output = $lb->break($string);

الحفاظ على الحالة

يستخدم كائن Unicode::LineBreak كمرجع هش. يمكن تخزين أي عنصر خلال فترة حياة الكائن.

على سبيل المثال، يقوم الكود التالي بتقسيم الفقرات باستخدام أسطر فارغة.

sub paraformat {
    my $self = shift;
    my $action = shift;
    my $str = shift;

    if ($action eq 'sot' or $action eq 'sop') {
        $self->{'line'} = '';
    } elsif ($action eq '') {
        $self->{'line'} = $str;
    } elsif ($action eq 'eol') {
        return "\n";
    } elsif ($action eq 'eop') {
        if (length $self->{'line'}) {
            return "\n\n";
        } else {
            return "\n";
        }
    } elsif ($action eq 'eot') {
        return "\n";
    }
    return undef;
}
my $lb = Unicode::LineBreak->new(Format => \&paraformat);
$output = $lb->break($string);

حساب طول النص

عند تحديد مرجع لدالة فرعية لخيار "Sizing"، يجب أن تأخذ هذه الدالة الفرعية 5 معاملات.

$عدد الأسطر = &الدالة الفرعية(SELF, LEN, PRE, SPC, STR);

SELF هو كائن Unicode::LineBreak، LEN هو طول النص السابق، PRE هو النص السابق، SPC هو المسافة البيضاء المضافة، و STR هو النص Unicode المراد معالجته.

يجب على الدالة الفرعية حساب عدد الأسطر لـ "PRE.SPC.STR" وإرجاعها. لا يلزم أن يكون عدد الأسطر عددًا صحيحًا. يمكن اختيار وحدة عدد الأسطر بحرية، ولكن يجب أن تكون متسقة مع خيار "ColMin" أو "ColMax".

ملاحظة: الفهارس النصية هي في الواقع فئات أحرف مكتوبة. انظر Unicode::GCString~[ja].

على سبيل المثال، يعالج الكود التالي السجلات التي تحتوي على علامات جدولة بمعدل 8 أعمدة لكل سطر.

sub tabbedsizing {
    my ($self, $cols, $pre, $spc, $str) = @_;

    my $spcstr = $spc.$str;
    while ($spcstr->lbc == LB_SP) {
        my $c = $spcstr->item(0);
        if ($c eq "\t") {
            $cols += 8 - $cols % 8;
        } else {
            $cols += $c->columns;
        }
        $spcstr = $spcstr->substr(1);
    }
    $cols += $spcstr->columns;
    return $cols;
};
my $lb = Unicode::LineBreak->new(LBClass => [ord("\t") => LB_SP],
                                 Sizing => \&tabbedsizing);
$output = $lb->break($string);

NAME

Unicode::LineBreak - Unicode line breaking algorithm

SYNOPSIS

use Unicode::LineBreak qw(
    lb_check
    lb_get_breaks
);

# Check if a string can be broken at a certain position
if (lb_check($string, $pos)) {
    # Can break
}

# Get all possible breaking positions
my @breaks = lb_get_breaks($string);

DESCRIPTION

This module implements the Unicode Line Breaking Algorithm, defined in UAX #14.

The algorithm classifies characters into categories and then applies rules to determine where line breaks are allowed. The classification and rules are based on UnicodeData.txt and LineBreak.txt data files from the Unicode Character Database.

This module provides two main functions:

lb_check
Checks if a line break is allowed at a specific position within a string.
lb_get_breaks
Returns a list of all allowed line breaking positions within a string.

PUBLIC INTERFACE

lb_check ($string, $pos)
Given a string and a position, returns true if a line break is permitted between the character at index $pos-1 and the character at index $pos. Returns false otherwise.
lb_get_breaks ($string)
Given a string, returns a list of all valid line breaking positions. A position i in the returned list means that a line break is allowed between the character at index i-1 and the character at index i.
lb_is_forward_able ($string)
Given a string, returns true if the string is allowed to be followed by another string in a line break. This corresponds to the LB8 rule (must have a mandatory break or no break allowed).
lb_is_backward_able ($string)
Given a string, returns true if the string is allowed to precede another string in a line break. This corresponds to the LB9 rule (must have a mandatory break or no break allowed).

CUSTOMIZATION

The behavior of the module can be customized by providing a configuration file. The default configuration is loaded from Unicode/LineBreak/Defaults.pm. If a configuration file is provided to the "new" method or the options argument of the "config" method, it overrides the defaults.

See Unicode/LineBreak/Defaults.pm.sample for details.

標準への適合性

The character properties used in this module are based on Unicode Standard version 8.0.0.

This module implements the reference implementation UAX14-C2.

IMPLEMENTATION NOTES

  • Choices are made on whether to treat some ideographic characters as NS or ID.
  • Choices are made on whether to treat hangul syllables and hangul jamo as ID or AL.
  • Choices are made on how to classify characters categorized as AI: either AL or ID.
  • Characters classified as CB are not resolved.
  • Characters classified as CJ are always resolved as NS. A more lenient interpretation is provided.
  • For Southeast Asian mnemonic systems, characters classified as SA that do not correspond to single character graphemes are resolved as AL. However, characters whose Grapheme_Cluster_Break property value is Extend or SpacingMark are resolved as CM.
  • Characters classified as SG or XX are resolved as AL.
  • Code points within the following UCS ranges that do not have explicit character assignments are assigned default properties: 
    Range               | UAX #14    | UAX #11    | Explanation
-------------------------------------------------------------
U+20A0..U+20CF     | PR [*1]    | N [*2]     | Currency Symbols
U+3400..U+4DBF     | ID         | W          | CJK Ideographs
U+4E00..U+9FFF     | ID         | W          | CJK Ideographs
U+D800..U+DFFF     | AL (SG)    | N          | Surrogates
U+E000..U+F8FF     | AL (XX)    | F or N (A) | Private Use Area
U+F900..U+FAFF     | ID         | W          | CJK Ideographs
U+20000..U+2FFFD   | ID         | W          | CJK Ideographs
U+30000..U+3FFFD   | ID         | W          | CJK Ideographs
U+F0000..U+FFFFD   | AL (XX)    | F or N (A) | Private Use Area
U+100000..U+10FFFD | AL (XX)    | F or N (A) | Private Use Area
Others Unassigned   | AL (XX)    | N          | Unassigned, Reserved, Noncharacters
-------------------------------------------------------------
[*1] Excludes U+20A7 Peso Sign (PO), U+20B6 Euro-New Sign (PO), U+20BB
  Scandinavia-Mark Sign (PO), U+20BE Riel Sign (PO).
[*2] Excludes U+20A9 Won Sign (H), U+20AC Euro Sign (F or N (A)).
  • Characters whose general category is Mn, Me, Cc, Cf, Zl, or Zp are treated as characters that do not cause forward progress.
