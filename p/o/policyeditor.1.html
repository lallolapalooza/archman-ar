policyeditor(1)

الحزمة: icedtea-web

التراخيص: GPL2

policyeditor(1) دليل الأوامر العامة policyeditor(1)

الاسم

policyeditor - عرض وتعديل إعدادات سياسة الأمان لـ javaws و ملحق المتصفح

الملخص

policyeditor
policyeditor [-file] policy_file

الوصف

policyeditor هو تطبيق واجهة رسومية مع دعم محدود لسطر الأوامر لعرض وتعديل إعدادات سياسة الأمان للتطبيقات الصغيرة المستخدمة من قبل تطبيق IcedTea-Web لتنفيذ javaws و ملحق المتصفح. إنه يهدف إلى أن يكون بديلاً أبسط وأسهل استخدامًا وأكثر سهولة من JDK Policy Tool القياسي. من المحتمل أن يستخدم المسؤولون والمستخدمون المتقدمون الذين يحتاجون إلى تحكم دقيق في ملفات السياسة أداة Policy Tool بدلاً من PolicyEditor.

إذا تم تنفيذه بدون أي وسائط، فلن يتم فتح أي ملف، وسيؤدي حفظ الملف إلى ظهور مطالبة بمكان حفظه. بخلاف ذلك، إذا تم تقديم مسار ملف كوسيط لسطر الأوامر، فسيتم فتح هذا المسار وتحليله كملف سياسة.

الخيارات

-codebase url
يحدد عنوان URL لقاعدة كود التطبيق الصغير. يمكن استخدام هذا مع خيارات المحدد الأخرى لتحديد إدخال سياسة عند فتح المحرر؛ إذا لم يكن هذا المعرف موجودًا، فسيتم إنشاؤه ثم تحديده. (مطلوب وسيط واحد بالضبط)
-defaultfile
يحدد أن ملف سياسة المستخدم الافتراضي يجب فتحه. هذا هو الملف الذي يستخدمه IcedTea-Web عادةً لاتخاذ قرارات بشأن السياسات المخصصة والأذونات للتطبيقات الصغيرة في وقت التشغيل، ما لم يتم تكوينه بخلاف ذلك. (لا يلزم وسيط)
-file policy_file
يحدد مسار ملف سياسة لفتحه. إذا تم تقديم وسيط واحد بالضبط، ولم يكن هذا العلم، فسيتم تفسيره كمسار ملف لفتحه، كما لو كان هذا العلم قد تم تقديمه أولاً. هذا العلم موجود بشكل أساسي للتوافق مع Policy Tool. (مطلوب وسيط واحد بالضبط)
-help
يطبع معلومات حول الأوامر المدعومة والاستخدام الأساسي. (لا يلزم وسيط)
-principals class_name principal_name
يحدد أزواج اسم الفئة/اسم المسؤول (مفصولة بمسافات) لمعرف إدخال السياسة. يمكن استخدام هذا مع خيارات المحدد الأخرى لتحديد إدخال سياسة عند فتح المحرر؛ إذا لم يكن هذا المعرف موجودًا، فسيتم إنشاؤه ثم تحديده. (مطلوب عدد زوجي من الوسطاء مع param=value كوسيط صالح)
-signedby certificate_alias
يحدد اسم مستعار لشهادة مخزنة في مخزن المفاتيح. يمكن استخدام هذا مع خيارات المحدد الأخرى لتحديد إدخال سياسة عند فتح المحرر؛ إذا لم يكن هذا المعرف موجودًا، فسيتم إنشاؤه ثم تحديده. (مطلوب وسيط واحد بالضبط)
-verbose
تمكين الإخراج المطول. (لا يلزم وسيط)

أمثلة

policyeditor
عرض محرر الواجهة الرسومية بدون فتح ملف.
policyeditor -file $XDG_CONFIG_HOME/icedtea-web/security/java.policy
عرض الواجهة الرسومية وفتح ملف السياسة الافتراضي.

الملفات

$XDG_CACHE_HOME/icedtea-web/cache/recently_used
معلومات إضافية حول العناصر في الذاكرة المؤقتة
$XDG_CONFIG_HOME/icedtea-web/security/java.policy
يحتوي على الأذونات الممنوحة للتطبيقات غير الموقعة المختارة. يتم التحكم فيه بواسطة deployment.user.security.policy

حيث يتم تعيين $XDG_CONFIG_DIR و $XDG_CACHE_DIR و $XDG_RUNTIME_DIR على النحو ~/.config و ~/.cache و /tmp أو /var/tmp إذا لم يتم تعيينها.

http://icedtea.classpath.org/wiki/IcedTea-Web#Filing_bugs

policyeditor(1)

NAME

policyeditor - configure security policies for the Java Runtime Environment

SYNOPSIS

policyeditor [options]

DESCRIPTION

The policyeditor is a graphical tool for managing the security policies of the Java Runtime Environment (JRE). It allows you to grant or deny permissions to Java applications based on their origin or codebase.

This tool is particularly useful for developers and system administrators who need to fine-tune the security settings of their Java applications.

OPTIONS

The policyeditor command does not accept any command-line options. It is a graphical application that is typically launched from a menu or by typing its name in a terminal.

EXAMPLES

To launch the policy editor, simply type the following command in your terminal:

policyeditor

This will open the graphical interface where you can configure the Java security policies.

FILES

~/.java.policy
The user-specific policy file.
/etc/java.policy
The system-wide policy file.

BUGS

Report bugs to the IcedTea-Web bug tracker at <https://github.com/jrh/icedtea-web/issues>.

AUTHOR

The policyeditor was developed by the IcedTea-Web project. See the project website for more information.
