podman-machine(1) دليل الأوامر العامة podman-machine(1)

الاسم

podman-machine - إدارة الجهاز الافتراضي لـ Podman

الملخص

podman machine أمر فرعي

الوصف

podman machine هو مجموعة من الأوامر الفرعية التي تدير الجهاز الافتراضي لـ Podman.

يتطلب Podman على MacOS و Windows جهازًا افتراضيًا. هذا لأن الحاويات هي لينكس - الحاويات لا تعمل على أي نظام تشغيل آخر لأن الوظائف الأساسية للحاويات مرتبطة بنواة لينكس. يجب استخدام podman machine لإدارة أجهزة MacOS و Windows، ولكن يمكن استخدامه اختياريًا على لينكس.

جميع أوامر podman machine تعمل فقط بدون صلاحيات الجذر.

ملاحظة: يتم إدارة ملف تكوين podman-machine ضمن الدليل $XDG_CONFIG_HOME/containers/podman/machine/. قد يؤدي تغيير متغير البيئة $XDG_CONFIG_HOME أثناء تشغيل الأجهزة إلى سلوك غير متوقع.

يمكن تعديل سلوك Podman machine عبر قسم [machine] في ملف containers.conf(5).
