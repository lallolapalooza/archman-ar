podman-container-ps(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-ps(1) دليل الأوامر العامة podman-ps(1)

الاسم

podman-ps - طباعة معلومات حول الحاويات

ملخص

podman ps [خيارات]

podman container ps [خيارات]

podman container list [خيارات]

podman container ls [خيارات]

الوصف

podman ps يسرد الحاويات قيد التشغيل على النظام. استخدم الخيار --all لعرض معلومات جميع الحاويات. افتراضيًا، يعرض:

  • معرف الحاوية
  • اسم الصورة التي تستخدمها الحاوية
  • الأمر الذي تنفذه الحاوية
  • وقت إنشاء الحاوية
  • حالة الحاوية
  • تعيينات المنافذ التي تستخدمها الحاوية
  • أسماء بديلة للحاوية

الخيارات

--all, -a

عرض جميع الحاويات، الافتراضي هو عرض الحاويات قيد التشغيل فقط.

ملاحظة: تشارك Podman تخزين الحاويات مع أدوات أخرى مثل Buildah و CRI-O. في بعض الحالات، قد توجد حاويات خارجية هذه أيضًا في نفس التخزين. استخدم الخيار --external لعرض هذه الحاويات الخارجية. تعرض الحاويات الخارجية حالة "التخزين".

--external

عرض الحاويات الخارجية التي لا تتحكم بها Podman ولكنها مخزنة في تخزين الحاويات. يتم إنشاء هذه الحاويات الخارجية بشكل عام عبر تقنيات حاويات أخرى مثل Buildah أو CRI-O وقد تعتمد على نفس صور الحاويات التي تستخدمها Podman أيضًا. يتم تمييز الحاويات الخارجية بـ "buildah" أو "storage" في عمود الأمر والحالة في ناتج ps.

--filter, -f

تصفية الحاويات التي يتم عرضها في الإخراج. يمكن تقديم عوامل تصفية متعددة باستخدام استخدامات متعددة لعلامة --filter. تعمل عوامل التصفية التي لها نفس المفتاح بشكل شامل مع الاستثناء الوحيد لـ label وهو حصري. تعمل عوامل التصفية ذات المفاتيح المختلفة دائمًا بشكل حصري.

عوامل التصفية الصالحة مدرجة أدناه:

التصفية الوصف
id [معرف] معرف الحاوية (مطابقة بادئة CID افتراضيًا؛ تقبل التعبيرات العادية)
name [اسم] اسم الحاوية (يقبل التعبيرات العادية)
label [مفتاح] أو [مفتاح=قيمة] تسمية مخصصة للحاوية
label! [مفتاح] أو [مفتاح=قيمة] تسمية غير مخصصة للحاوية
exited [عدد صحيح] رمز خروج الحاوية
status [الحالة] حالة الحاوية: 'created'، 'initialized'، 'exited'، 'paused'، 'running'، 'unknown'
ancestor [اسم الصورة] الصورة أو السلالة المستخدمة لإنشاء الحاوية (تقبل التعبيرات العادية)
before [معرف] أو [اسم] الحاويات التي تم إنشاؤها قبل هذه الحاوية
since [معرف] أو [اسم] الحاويات التي تم إنشاؤها منذ هذه الحاوية
volume [اسم المجلد] أو [وجهة نقطة التركيب] المجلد المركب في الحاوية
health [الحالة] صحي أو غير صحي
pod [بود] اسم أو معرف كامل أو جزئي للبود
network [شبكة] اسم أو معرف كامل للشبكة
until [وقت وتاريخ] الحاوية التي تم إنشاؤها قبل المدة أو الوقت المحدد.
command [الأمر] الأمر الذي تنفذه الحاوية، يتم أخذ argv[0] فقط

--format=format

طباعة الحاويات بشكل جميل بتنسيق JSON أو باستخدام قالب Go

العناصر النائبة الصالحة لقالب Go مدرجة أدناه:

العنصر النائب الوصف
.AutoRemove إذا كان صحيحًا، يتم إزالة الحاويات عند الخروج
.CIDFile ملف معرف الحاوية
.Command الأمر المقتبس المستخدم
.Created ... وقت إنشاء الحاوية، سنة-شهر-يوم ساعة:دقيقة:ثانية
.CreatedAt وقت إنشاء الحاوية (نفس ما سبق)
.CreatedHuman وقت الإنشاء، نسبي
.ExitCode رمز خروج الحاوية
.Exited "true" إذا كانت الحاوية قد خرجت
.ExitedAt وقت خروج الحاوية (ثواني الحقبة)
.ExposedPorts ... خريطة المنافذ المكشوفة في هذه الحاوية
.ID معرف الحاوية
.Image اسم/معرف الصورة
.ImageID معرف الصورة
.IsInfra "true" إذا كانت حاوية بنية تحتية
.Label string التسمية المحددة للحاوية
.Labels ... جميع التسميات المخصصة للحاوية
.Mounts المجلدات المركبة في الحاوية
.Names اسم الحاوية
.Networks عرض جميع الشبكات المتصلة بالحاوية
.Pid معرف العملية على النظام المضيف
.Pod البود المرتبط بالحاوية (SHA)
.PodName اسم البود للحاوية
.Ports المنافذ المعاد توجيهها والمكشوفة
.Restarts عرض عدد مرات إعادة تشغيل الحاوية
.RunningFor الوقت المنقضي منذ بدء تشغيل الحاوية
.Size حجم الحاوية
.StartedAt وقت بدء تشغيل الحاوية (ثواني الحقبة)
.State وصف سهل الفهم لحالة الحاوية
.Status حالة الحاوية

--help, -h

طباعة بيان الاستخدام

--last, -n

طباعة آخر n حاويات تم إنشاؤها (جميع الحالات)

--latest, -l

عرض أحدث حاوية تم إنشاؤها (جميع الحالات) (هذا الخيار غير متاح مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

--namespace, --ns

عرض معلومات مساحة الأسماء

--no-trunc

عدم اقتطاع الإخراج (الافتراضي false).

--noheading

تجاهل عناوين الجدول من قائمة الحاويات.

--pod, -p

عرض البودات التي ترتبط بها الحاويات

--quiet, -q

طباعة معرفات الحاويات الرقمية فقط

--size, -s

عرض الحجم الإجمالي للملف

--sort=created

الفرز حسب الأمر، الإنشاء، المعرف، الصورة، الأسماء، التشغيل، الحجم، أو الحالة. ملاحظة: الفرز حسب الحجم يفرز حسب حجم نظام الملفات الجذري، وليس أبجديًا مثل بقية الخيارات

--sync

فرض مزامنة حالة الحاوية مع وقت تشغيل OCI. في بعض الحالات، يمكن أن تصبح حالة الحاوية في وقت التشغيل غير متزامنة مع حالة Podman. يقوم هذا بتحديث حالة Podman بناءً على ما يبلغه وقت تشغيل OCI. المزامنة القسرية أبطأ بكثير، ولكن يمكنها حل مشاكل الحالة غير المتسقة.

--watch, -w

تحديث الإخراج بالحاويات الحالية على فترات زمنية بالثواني.

أمثلة

عرض الحاويات قيد التشغيل.
