POSIX_TRACE_EVENTSET_ADD(3P) دليل مبرمج POSIX POSIX_TRACE_EVENTSET_ADD(3P)

مقدمة

هذه الصفحة اليدوية هي جزء من دليل مبرمج POSIX. قد يختلف تنفيذ Linux لهذه الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة على Linux.

الاسم

posix_trace_eventset_add, posix_trace_eventset_del, posix_trace_eventset_empty, posix_trace_eventset_fill, posix_trace_eventset_ismember — التعامل مع مجموعات أنواع أحداث التتبع (TRACING)

الملخص

#include <trace.h>
int posix_trace_eventset_add(trace_event_id_t event_id,
    trace_event_set_t *set);
int posix_trace_eventset_del(trace_event_id_t event_id,
    trace_event_set_t *set);
int posix_trace_eventset_empty(trace_event_set_t *set);
int posix_trace_eventset_fill(trace_event_set_t *set, int what);
int posix_trace_eventset_ismember(trace_event_id_t event_id,
    const trace_event_set_t *restrict set, int *restrict ismember);

الوصف

تقوم هذه البدائيات بالتعامل مع مجموعات أنواع أحداث التتبع. تعمل هذه البدائيات على كائنات بيانات يمكن للتطبيق الوصول إليها، وليس على مرشح أحداث التتبع الحالي لأي تدفق تتبع.

وظائف posix_trace_eventset_add() و posix_trace_eventset_del()، على التوالي، تقوم بإضافة أو حذف نوع حدث التتبع الفردي المحدد بواسطة قيمة الوسيط event_id إلى أو من مجموعة أنواع أحداث التتبع المشار إليها بالوسيط set. إضافة نوع حدث تتبع موجود بالفعل في المجموعة أو حذف نوع حدث تتبع غير موجود في المجموعة لا يعتبر خطأ.

تقوم وظيفة posix_trace_eventset_empty() بتهيئة مجموعة أنواع أحداث التتبع المشار إليها بالوسيط set بحيث يتم استبعاد جميع أنواع أحداث التتبع المعرفة، سواء كانت نظامية أو مستخدمة، من المجموعة.

تقوم وظيفة posix_trace_eventset_fill() بتهيئة مجموعة أنواع أحداث التتبع المشار إليها بالوسيط set، بحيث يتم تضمين مجموعة أنواع أحداث التتبع المحددة بواسطة الوسيط what في المجموعة. يجب أن تتكون قيمة الوسيط what من إحدى القيم التالية، كما هي معرفة في ملف الترويسة <trace.h>:

POSIX_TRACE_WOPID_EVENTS

يتم تضمين جميع أنواع أحداث تتبع النظام المعرفة حسب التنفيذ والمستقلة عن العمليات في المجموعة.
POSIX_TRACE_SYSTEM_EVENTS

يتم تضمين جميع أنواع أحداث تتبع النظام المعرفة حسب التنفيذ في المجموعة، بالإضافة إلى تلك المعرفة في POSIX.1‐2008.
POSIX_TRACE_ALL_EVENTS

يتم تضمين جميع أنواع أحداث التتبع المعرفة، سواء كانت نظامية أو مستخدمة، في المجموعة.

يجب على التطبيقات استدعاء posix_trace_eventset_empty() أو posix_trace_eventset_fill() مرة واحدة على الأقل لكل كائن من النوع trace_event_set_t قبل أي استخدام آخر لهذا الكائن. إذا لم يتم تهيئة كائن كهذا بهذه الطريقة، ولكنه تم تقديمه كواسطة لأي من الوظائف posix_trace_eventset_add() أو posix_trace_eventset_del() أو posix_trace_eventset_ismember()، فستكون النتائج غير محددة.

تقوم وظيفة posix_trace_eventset_ismember() باختبار ما إذا كان نوع حدث التتبع المحدد بقيمة الوسيط event_id عضوًا في المجموعة المشار إليها بالوسيط set. القيمة المرجعة في الكائن المشار إليه بالوسيط ismember هي صفر إذا كان معرف نوع حدث التتبع ليس عضوًا في المجموعة وقيمة غير صفرية إذا كان عضوًا في المجموعة.

posix_trace_eventset_add(3p) — Arch manual pages

NAME

posix_trace_eventset_add — add an event or event range to an event set

SYNOPSIS

#include <sys/trace.h>

int posix_trace_eventset_add(posix_trace_event_set_t *set , trace_event_id_t event_id );

DESCRIPTION

The posix_trace_eventset_add() function shall add the event specified by event_id to the event set pointed to by set.

If the event specified by event_id is already present in the event set set, the call shall have no effect.

The value of event_id must be a valid event identifier defined by the POSIX trace facility. Valid event identifiers are in the range [TRACE_EVENT_MIN, TRACE_EVENT_MAX], where TRACE_EVENT_MIN and TRACE_EVENT_MAX are constants defined in <sys/trace.h>.

The behavior is undefined if set does not point to a valid, initialized trace event set.

RETURN VALUE

On success, posix_trace_eventset_add() shall return 0.

On failure, it shall return an error number.

ERRORS

[EINVAL]
The value of event_id is not a valid trace event identifier.

The POSIX trace facility is not available on the system.
