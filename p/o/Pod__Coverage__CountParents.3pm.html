Pod__Coverage__CountParents(3pm)

الحزمة: perl-pod-coverage

التراخيص: GPL, PerlArtistic

Pod::Coverage::CountParents(3) وثائق Perl المقدمة من المستخدم Pod::Coverage::CountParents(3)

الاسم

Pod::Coverage::CountParents - فئة فرعية من Pod::Coverage تفحص شجرة الوراثة

الملخص

# كلها في استدعاء واحد
use Pod::Coverage::CountParents package => 'Fishy';
# كائن موجه بشكل مباشر
use Pod::Coverage::CountParents;
my $pc = new Pod::Coverage::CountParents package => 'Pod::Coverage';
print "We rock!" if $pc->coverage == 1;

الوصف

تقوم هذه الوحدة بتوسيع Pod::Coverage لتشمل الوثائق من الفئات الأصلية عند تحديد تغطية الكود.

إذا كنت تريد وثائق كاملة، نقترح عليك مراجعة وثائق Pod::Coverage.
