podman-machine-cp(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-machine-cp(1) دليل الأوامر العامة podman-machine-cp(1)

الاسم

podman machine cp - نسخ المحتويات بأمان بين الجهاز المضيف والآلة الافتراضية

الملخص

podman machine cp [خيارات] مسار_المصدر مسار_الوجهة

الوصف

استخدم النسخ الآمن (scp) لنسخ الملفات أو الأدلة بين الآلة الافتراضية وجهازك المضيف.

podman machine cp لا يدعم النسخ بين آلتين افتراضيتين، الأمر الذي يتطلب تشغيل آلتين في نفس الوقت.

بالإضافة إلى ذلك، سيقوم podman machine cp تلقائيًا بنسخ الملفات والأدلة بشكل تكراري.

الخيارات

--help

طباعة بيان الاستخدام.

--quiet, -q

كبت إخراج حالة النسخ.

أمثلة

نسخ ملف من جهازك المضيف إلى آلة Podman قيد التشغيل.

$ podman machine cp ~/configuration.txt podman-machine-default:~/configuration.txt
...
Copy Successful

نسخ ملف من آلة Podman قيد التشغيل إلى جهازك المضيف.

$ podman machine cp podman-machine-default:~/logs/log.txt ~/logs/podman-machine-default.txt
...
Copy Successful

نسخ دليل من جهازك المضيف إلى آلة Podman قيد التشغيل.

$ podman machine cp ~/.config podman-machine-default:~/.config
...
Copy Successful

نسخ دليل من آلة Podman قيد التشغيل إلى جهازك المضيف.

$ podman machine cp podman-machine-default:~/.config ~/podman-machine-default.config
...
Copy Successful
