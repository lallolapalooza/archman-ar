podman-port(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-port(1) دليل الأوامر العام podman-port(1)

الاسم

podman port - عرض تعيينات المنافذ للحاوية

الملخص

podman port [خيارات] حاوية [منفذ-خاص[/بروتوكول]]

podman container port [خيارات] حاوية [منفذ-خاص[/بروتوكول]]

الوصف

عرض تعيينات المنافذ لـ الحاوية أو البحث عن المنفذ العام الذي يتم تحويله إلى منفذ-خاص.

الخيارات

--all, -a

عرض جميع تعيينات المنافذ المعروفة للحاويات قيد التشغيل؛ عند استخدام هذا الخيار، لا يمكن استخدام أسماء الحاويات أو مرشحات المنافذ/البروتوكولات الخاصة.

--latest, -l

بدلاً من تقديم اسم الحاوية أو معرفها، استخدم آخر حاوية تم إنشاؤها. ملاحظة: يمكن أن تكون آخر حاوية تم تشغيلها من مستخدمين آخرين لـ Podman على المضيف. (هذا الخيار غير متاح مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

مثال

عرض جميع تعيينات المنافذ:

# podman port -a
b4d2f05432e482e017b1a4b2eae15fa7b4f6fb7e9f65c1bde46294fdef285906
80/udp -> 0.0.0.0:44327
80/tcp -> 0.0.0.0:44327
#

عرض تعيينات المنافذ لحاوية معينة:

# podman port b4d2f054
80/udp -> 0.0.0.0:44327
80/tcp -> 0.0.0.0:44327
#

عرض تعيينات المنافذ المحددة لحاوية معينة:

# podman port b4d2f054 80
 0.0.0.0:44327
#

عرض تعيينات المنافذ لحاوية معينة للمنفذ 80 وبروتوكول tcp:

# podman port b4d2f054 80/tcp
0.0.0.0:44327
#
