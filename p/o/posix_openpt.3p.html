POSIX_OPENPT(3P) دليل مبرمج POSIX POSIX_OPENPT(3P)

PROLOG

هذه الصفحة اليدوية جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا يتم تنفيذ الواجهة على Linux.

NAME

posix_openpt — فتح جهاز طرفي وهمي

SYNOPSIS

#include <stdlib.h>
#include <fcntl.h>
int posix_openpt(int oflag);

DESCRIPTION

تقوم الدالة posix_openpt() بإنشاء اتصال بين جهاز رئيسي لطرفية وهمية وبين واصف ملف. يتم تخصيص واصف الملف كما هو موصوف في القسم 2.14، تخصيص واصف الملف ويمكن استخدامه بواسطة وظائف الإدخال/الإخراج الأخرى التي تشير إلى تلك الطرفية الوهمية.

سيتم تعيين علامات حالة الملف وأنماط الوصول إلى الملف للوصف المفتوح للملف وفقًا لقيمة oflag.

تُنشأ القيم الخاصة بـ oflag عن طريق OR منطقي شامل للبتات من العلامات التالية، المعرفة في <fcntl.h>:

O_RDWR
فتح للقراءة والكتابة.
O_NOCTTY
إذا تم تعيينها، فإن posix_openpt() لن تتسبب في أن تصبح أداة الطرفية هي الطرفية المتحكمة في العملية.

سلوك القيم الأخرى لمعامل oflag غير محدد.

RETURN VALUE

عند الانتهاء بنجاح، تقوم الدالة posix_openpt() بفتح واصف ملف لجهاز طرفية رئيسي وهمي وإرجاع عدد صحيح غير سالب يمثل واصف الملف. بخلاف ذلك، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

ERRORS

ستفشل الدالة posix_openpt() إذا:

EMFILE
جميع واصفات الملفات المتاحة للعملية مفتوحة حاليًا.
ENFILE
العدد الأقصى المسموح به للملفات مفتوح حاليًا في النظام.

قد تفشل الدالة posix_openpt() إذا:

EINVAL
قيمة oflag غير صالحة.
EAGAIN
نفاد موارد الطرفية الوهمية.
ENOSR
نفاد موارد STREAMS.

الأقسام التالية إعلامية.

EXAMPLES

فتح طرفية وهمية وإرجاع اسم الجهاز التابع وواصف ملف

#include <fcntl.h>
#include <stdio.h>
int masterfd, slavefd;
char *slavedevice;
masterfd = posix_openpt(O_RDWR|O_NOCTTY);
if (masterfd == -1
    || grantpt (masterfd) == -1
    || unlockpt (masterfd) == -1
    || (slavedevice = ptsname (masterfd)) == NULL)
    return -1;
printf("slave device is: %s\n", slavedevice);
slavefd = open(slavedevice, O_RDWR|O_NOCTTY);
if (slavefd < 0)
    return -1;

APPLICATION USAGE

هذه الدالة هي طريقة للحصول بشكل قابل للنقل على واصف ملف لجهاز طرفي رئيسي لطرفية وهمية. يمكن استخدام الدوال grantpt() و ptsname() لمعالجة إذن الوضع والملكية، وللحصول على اسم الجهاز التابع، على التوالي.

RATIONALE

نظر مطورو المعيار في مسألة إضافة جهاز خاص لاستنساخ أجهزة الطرفية الرئيسية: جهاز /dev/ptmx. ومع ذلك، لم يتم التوصل إلى توافق في الآراء، وشعر أنه من شأن إضافة دالة جديدة السماح بتنفيذات أخرى. تم تصميم الدالة posix_openpt() لتكون مكملة للدوال grantpt() و ptsname() و unlockpt().

في التطبيقات التي تدعم جهاز الاستنساخ /dev/ptmx، فإن فتح الجهاز الرئيسي لطرفية وهمية يكون ببساطة:

mfdp = open("/dev/ptmx", oflag );
if (mfdp < 0)
    return -1;
