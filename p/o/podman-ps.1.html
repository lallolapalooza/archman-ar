podman-ps(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-ps(1) دليل الأوامر العامة podman-ps(1)

الاسم

podman-ps - طباعة معلومات عن الحاويات

ملخص

podman ps [خيارات]

podman container ps [خيارات]

podman container list [خيارات]

podman container ls [خيارات]

الوصف

podman ps يسرد الحاويات قيد التشغيل على النظام. استخدم العلامة --all لعرض معلومات جميع الحاويات. بشكل افتراضي، يسرد:

  • معرف الحاوية
  • اسم الصورة التي تستخدمها الحاوية
  • الأمر الذي تنفذه الحاوية
  • وقت إنشاء الحاوية
  • حالة الحاوية
  • تعيينات المنافذ التي تستخدمها الحاوية
  • أسماء بديلة للحاوية

خيارات

--all, -a

عرض جميع الحاويات، الافتراضي هو الحاويات قيد التشغيل فقط.

ملاحظة: تشارك Podman تخزين الحاويات مع أدوات أخرى مثل Buildah و CRI-O. في بعض الحالات، قد توجد هذه الحاويات الخارجية أيضًا في نفس التخزين. استخدم العلامة --external لعرض هذه الحاويات الخارجية. تعرض الحاويات الخارجية حالة "التخزين".

--external

عرض الحاويات الخارجية غير التي تتحكم فيها Podman ولكنها مخزنة في تخزين الحاويات. هذه الحاويات الخارجية يتم إنشاؤها عمومًا عبر تقنيات حاويات أخرى مثل Buildah أو CRI-O وقد تعتمد على نفس صور الحاويات التي تستخدمها Podman أيضًا. يتم تحديد الحاويات الخارجية بواسطة "buildah" أو "storage" في عمود الأمر والحالة في إخراج ps.

--filter, -f

تصفية الحاويات التي يتم عرضها في الإخراج. يمكن إعطاء عوامل تصفية متعددة باستخدام --filter بشكل متكرر. تعمل عوامل التصفية بنفس المفتاح بشكل شمولي مع الاستثناء الوحيد لـ label الذي يكون حصريًا. تعمل عوامل التصفية بمفاتيح مختلفة دائمًا بشكل حصري.

عوامل التصفية الصالحة مدرجة أدناه:

عامل التصفية الوصف
id [معرف] معرف الحاوية (مطابقة بادئة CID افتراضيًا؛ يقبل التعبيرات النمطية)
name [الاسم] اسم الحاوية (يقبل التعبيرات النمطية)
label [مفتاح] أو [مفتاح=قيمة] تسمية مخصصة للحاوية
label! [مفتاح] أو [مفتاح=قيمة] تسمية غير مخصصة للحاوية
exited [عدد صحيح] رمز خروج الحاوية
status [الحالة] حالة الحاوية: 'created'، 'initialized'، 'exited'، 'paused'، 'running'، 'unknown'
ancestor [اسم الصورة] صورة أو سلالة مستخدمة لإنشاء الحاوية (يقبل التعبيرات النمطية)
before [معرف] أو [اسم] الحاويات التي تم إنشاؤها قبل هذه الحاوية
since [معرف] أو [اسم] الحاويات التي تم إنشاؤها بعد هذه الحاوية
volume [اسم الحجم] أو [وجهة نقطة التحميل] حجم مثبت في الحاوية
health [الحالة] صحية أو غير صحية
pod [الحاوية] اسم أو معرف كامل أو جزئي للحاوية
network [الشبكة] اسم أو معرف كامل للشبكة
until [تاريخ ووقت] تم إنشاء الحاوية قبل المدة أو الوقت المحدد.
command [الأمر] الأمر الذي تنفذه الحاوية، يتم أخذ argv[0] فقط

--format=format

طباعة الحاويات بشكل جميل بصيغة JSON أو باستخدام قالب Go

العناصر النائبة الصالحة لقالب Go مدرجة أدناه:

العنصر النائب الوصف
.AutoRemove إذا كان صحيحًا، يتم إزالة الحاويات عند الخروج
.CIDFile ملف معرف الحاوية
.Command الأمر المستخدم بين علامتي التنصيص
.Created ... وقت إنشاء الحاوية، سنة-شهر-يوم ساعة:دقيقة:ثانية
.CreatedAt وقت إنشاء الحاوية (نفس ما ورد أعلاه)
.CreatedHuman وقت الإنشاء، نسبي
.ExitCode رمز خروج الحاوية
.Exited "true" إذا كانت الحاوية قد خرجت
.ExitedAt وقت خروج الحاوية (بالثواني الزمنية)
.ExposedPorts ... خريطة المنافذ المكشوفة على هذه الحاوية
.ID معرف الحاوية
.Image اسم/معرف الصورة
.ImageID معرف الصورة
.IsInfra "true" إذا كانت حاوية بنية تحتية
.Label string التسمية المحددة للحاوية
.Labels ... جميع التسميات المخصصة للحاوية
.Mounts الأحجام المثبتة في الحاوية
.Names اسم الحاوية
.Networks عرض جميع الشبكات المتصلة بالحاوية
.Pid معرف العملية على نظام المضيف
.Pod الحاوية المرتبطة بها الحاوية (SHA)
.PodName اسم الحاوية للحاوية
.Ports المنافذ المعاد توجيهها والمكشوفة
.Restarts عرض عدد مرات إعادة تشغيل الحاوية
.RunningFor الوقت المنقضي منذ بدء تشغيل الحاوية
.Size حجم الحاوية
.StartedAt وقت بدء تشغيل الحاوية (بالثواني الزمنية)
.State وصف سهل القراءة لحالة الحاوية
.Status حالة الحاوية

--help, -h

طباعة بيان الاستخدام

--last, -n

طباعة آخر n حاويات تم إنشاؤها (جميع الحالات)

--latest, -l

عرض أحدث حاوية تم إنشاؤها (جميع الحالات) (هذه العلامة غير متاحة مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

--namespace, --ns

عرض معلومات مساحة الاسم

--no-trunc

عدم اقتطاع الإخراج (الافتراضي false).

--noheading

تجاهل عناوين الجدول من قائمة الحاويات.

--pod, -p

عرض الحاويات التي ترتبط بها الحاويات

--quiet, -q

طباعة المعرفات الرقمية للحاويات فقط

--size, -s

عرض إجمالي حجم الملف

--sort=created

الفرز حسب الأمر، الإنشاء، المعرف، الصورة، الأسماء، التشغيل، الحجم، أو الحالة"، ملاحظة: اختيار الحجم يفرز حسب حجم rootFs، وليس أبجديًا مثل بقية الخيارات

--sync

فرض مزامنة حالة الحاوية مع وقت تشغيل OCI. في بعض الحالات، قد تصبح حالة الحاوية في وقت التشغيل غير متزامنة مع حالة Podman. هذا يقوم بتحديث حالة Podman بناءً على ما يبلغه وقت تشغيل OCI. المزامنة القسرية أبطأ بكثير، ولكنها يمكن أن تحل مشاكل الحالة غير المتناسقة.

--watch, -w

تحديث الإخراج بالحاويات الحالية على فترات زمنية بالثواني.

أمثلة

سرد الحاويات قيد التشغيل.

$ podman ps
CONTAINER ID  IMAGE                            COMMAND    CREATED        STATUS        PORTS                                                   NAMES
4089df24d4f3  docker.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

الاسم

podman-ps - قائمة الحاويات

نظره عامة

podman ps [options]

الوصف

يعرض الأمر podman ps معلومات حول الحاويات. بشكل افتراضي، يتم عرض الحاويات قيد التشغيل فقط.

خيارات

تحدد الخيارات المعلومات التي يتم عرضها:

-a، --all
عرض جميع الحاويات (التي تعمل أو لا تعمل).
--filter، -f key=value
قم بتصفية المخرجات بناءً على شرط محدد. القيم الممكنة لـ key هي:
  • pod - معرف أو اسم الـ pod.
  • status - حالة الحاوية (مثل: created، running، exited، paused).
  • volume - اسم المجلد.
  • network - اسم الشبكة.
  • name - اسم الحاوية.
  • label - تسمية الحاوية.
--format format
استخدم تنسيق Go لإنشاء مخرجات جميلة.
--last، -l
عرض الحاوية التي تم إنشاؤها مؤخرًا.
--namespaces، --ns
عرض مساحات أسماء الحاوية.
--pod
عرض الحاويات المرتبطة بالـ pods.
--quiet، -q
عرض معرفات الحاويات فقط.
--size
عرض حجم الحاوية.
--sort key
قم بفرز المخرجات.
--external
عرض الحاويات الخارجية (التي تم إنشاؤها بواسطة أدوات أخرى غير Podman).
