الحزمة: postfix

التراخيص: EPL-2.0 OR IPL-1.0, BSD-4-Clause-UC

NAME

postscreen - Postfix protocol filtering daemon

SYNOPSIS

postscreen [-7] [-e] [-c config_dir]

DESCRIPTION

The postscreen(8) daemon implements a network server that rejects mail from unwanted clients before they can send mail. It runs in front of the actual Postfix SMTP server (smtpd(8)) and acts as a network firewall that understands the SMTP protocol.

postscreen(8) implements a strategy that significantly reduces the load from spam and worms on busy mail servers. It works by implementing a per-client IP address "allowlist" that caches the results of time-consuming SMTP protocol tests, DNSBL lookups, and other checks.

The goal is to reject as much mail as possible from unwanted clients with minimal CPU and network load. It expects to be configured to accept mail from clients that pass its checks, and to pass the rest of the mail to the real Postfix SMTP server for normal processing.

postscreen(8) is typically run as a privileged daemon that listens on network interface port 25, and passes mail to a non-privileged smtpd(8) process running on a different port (e.g., 10025).
