podman-image-scp(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-image-scp(1) دليل الأوامر العامة podman-image-scp(1)

الاسم

podman-image-scp - نسخ صورة بأمان من مضيف إلى آخر

الملخص

podman image scp [خيارات] اسم[:علامة]

الوصف

يقوم الأمر podman image scp بنسخ صور الحاويات بين المضيفين عبر الشبكة. يمكن لهذا الأمر نسخ الصور إلى المضيف البعيد أو من المضيف البعيد بالإضافة إلى النسخ بين مضيفين بعيدين. ملاحظة: يتم استخدام :: لتحديد اسم الصورة بناءً على ما إذا كان Podman يحفظ أو يقوم بتحميل. يمكن أيضًا نقل الصور من تخزين rootful إلى تخزين rootless على نفس الجهاز دون استخدام sshd. هذه الميزة غير مدعومة على العميل البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2).

podman image scp [خيارات عامة]

podman image scp [خيارات] الاسم[:العلامة] [اسم المضيف::]

podman image scp [خيارات] [اسم المضيف::]اسم الصورة

podman image scp [خيارات] [اسم المضيف::]اسم الصورة [اسم المضيف::]

الخيارات

--help, -h

طباعة بيان الاستخدام

--quiet, -q

أمثلة

نسخ الصورة المحددة إلى التخزين المحلي:

$ podman image scp alpine
Loaded image: docker.io/library/alpine:latest

نسخ الصورة المحددة من التخزين المحلي إلى الاتصال البعيد:

$ podman image scp alpine Fedora::/home/charliedoern/Documents/alpine
Getting image source signatures
Copying blob 72e830a4dff5 done
Copying config 85f9dc67c7 done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

نسخ الصورة المحددة من الاتصال البعيد إلى الاتصال البعيد:

$ podman image scp Fedora::alpine RHEL::
Loaded image: docker.io/library/alpine:latest

نسخ الصورة المحددة عبر ssh إلى التخزين المحلي:

$ podman image scp charliedoern@192.168.68.126:22/run/user/1000/podman/podman.sock::alpine
WARN[0000] Unknown connection name given. Please use system connection add to specify the default remote socket location
Getting image source signatures
Copying blob 9450ef9feb15 [--------------------------------------] 0.0b / 0.0b
Copying config 1f97f0559c done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

نسخ الصورة المحددة من حساب الجذر إلى تخزين المستخدمين المحلي:

$ sudo podman image scp root@localhost::alpine username@localhost::
Copying blob e2eb06d8af82 done
Copying config 696d33ca15 done
Writing manifest to image destination
Storing signatures
Getting image source signatures
Copying blob 5eb901baf107 skipped: already exists
Copying config 696d33ca15 done
Writing manifest to image destination
Storing signatures
Loaded image: docker.io/library/alpine:latest

$ sudo podman image scp root@localhost::alpine
