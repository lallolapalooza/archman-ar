podman-quadlet-list(1) دليل الأوامر العامة podman-quadlet-list(1)

الاسم

podman-quadlet-list - قائمة الكوادلت المثبتة

ملخص

podman quadlet list [خيارات]

الوصف

يسرد جميع الكوادلت المعدة للمستخدم الحالي.

الخيارات

--filter, -f=فلتر

قم بتصفية الإخراج بناءً على الشروط المعطاة.

يأتي الوسيط filters بتنسيق key=value. إذا كان هناك أكثر من filter واحد، فمرر خيارات متعددة: --filter foo=bar --filter bif=baz.

الفلاتر المدعومة:

الفلتر الوصف
name التصفية حسب اسم الكوادلت.

--format=تنسيق

طباعة الإخراج بتنسيق JSON أو باستخدام قالب Go (الافتراضي "{{range .}}{{.Name}}\t{{.UnitName}}\t{{.Path}}\t{{.Status}}\n{{end -}}")

اطبع النتائج باستخدام قالب Go.

عنصر نائب الوصف
.App اسم التطبيق إذا كان الكوادلت جزءًا من تطبيق
.Name اسم ملف الكوادلت
.Path مسار ملف الكوادلت على القرص
.Status حالة الكوادلت المقابلة لوحدة systemd
.UnitName اسم وحدة systemd المقابلة للكوادلت

أمثلة

أمر قائمة بسيط

$ podman quadlet list
NAME                            UNIT NAME                     PATH ON DISK                                                          STATUS      APPLICATION
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  Not loaded
sample-quadlet.container        sample-quadlet.service        /home/user/.config/containers/systemd/sample-quadlet.container        Not loaded

تصفية القائمة حسب الاسم.

$ podman quadlet list --filter 'name=test*'
NAME                            UNIT NAME                     PATH ON DISK                                                          STATUS      APPLICATION
test-service-quadlet.container  test-service-quadlet.service  /home/user/.config/containers/systemd/test-service-quadlet.container  Not loaded

تنسيق إخراج القائمة لحقل معين.

$ podman quadlet list --format '{{ .UnitName }}'
UNIT NAME
test-service-quadlet.service
sample-quadlet.service
