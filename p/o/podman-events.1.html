podman-events(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-events(1) دليل الأوامر العامة podman-events(1)

الاسم

podman events - مراقبة أحداث Podman

ملخص

podman events [خيارات]

podman system events [خيارات]

الوصف

مراقبة وطباعة الأحداث التي تحدث في Podman. كل حدث يتضمن طابع زمني، نوع، حالة، اسم (إذا كان قابلاً للتطبيق)، وصورة (إذا كانت قابلة للتطبيق). آلية التسجيل الافتراضية هي journald. يمكن تغيير هذا في containers.conf عن طريق تغيير قيمة events_logger إلى file. يتم قبول file و journald فقط. يتوفر أيضًا مسجل none، ولكن هذه الآلية التسجيل تعطل الأحداث تمامًا؛ لا يتم الإبلاغ عن أي شيء بواسطة podman events.

افتراضيًا، يتم استخدام وضع التدفق، حيث تتم طباعة الأحداث الجديدة فور حدوثها. يمكن سرد الأحداث السابقة عبر --since و --until.

نوع الحدث pod يبلغ عن الحالات التالية:

النوع secret يبلغ عن الحالات التالية:

أحداث الإنشاء المفصلة

يؤدي تعيين events_container_create_inspect_data=true في containers.conf(5) إلى توجيه Podman لإنشاء أحداث إنشاء حاوية أكثر تفصيلاً تتضمن حمولة JSON بمعلومات مفصلة حول الحاويات. حمولة JSON متطابقة مع حمولة podman-container-inspect(1). الحقل المرتبط في journald يسمى PODMAN_CONTAINER_INSPECT_DATA.

الخيارات

--filter, -f=filter

تصفية الأحداث التي يتم عرضها. يجب أن تكون بتنسيق "filter=value". الفلاتر التالية مدعومة:

الفلتر الوصف
container [اسم أو معرّف] اسم أو معرّف الحاوية
event event_status (موصوف أعلاه)
image [اسم أو معرّف] اسم أو معرّف الصورة
label [مفتاح] أو [مفتاح=قيمة] تسمية
pod [اسم أو معرّف] اسم أو معرّف الـ pod
volume [اسم أو معرّف] اسم أو معرّف الـ volume
type Event_type (موصوف أعلاه)

في حالة استخدام معرّف، قد يكون المعرّف في شكله الكامل أو المختصر. يتم تعيين الحدث "die" إلى "died" للتوافق مع Docker.

--format

تنسيق الإخراج إلى JSON Lines أو باستخدام قالب Go المحدد.

العنصر النائب الوصف
.Attributes ... created_at, _by, labels, والمزيد (map[])
.ContainerExitCode رمز الخروج (int)
.ContainerInspectData حمولة الفحص الخاص بالحاوية
.Error رسالة الخطأ في حالة كون حالة الحدث خطأ (مثل pull-error)
.HealthStatus حالة الصحة (string)
.ID معرّف الحاوية (SHA كامل 64 بت)
.Image اسم الصورة التي يتم تشغيلها (string)
.Name اسم الحاوية (string)
.Network اسم الشبكة المستخدمة (string)
.PodID معرّف الـ pod المرتبط بالحاوية، إن وجد
.Status حالة الحدث (مثل create, start, died, ...)
.Time طابع زمني للحدث (string)
.TimeNano طابع زمني للحدث بدقة النانو ثانية (int64)
.Type نوع الحدث (مثل image, container, pod, ...)

--help

طباعة بيان الاستخدام.

--no-trunc

عدم اقتطاع الإخراج (الافتراضي true).

--since=timestamp

عرض جميع الأحداث التي تم إنشاؤها منذ الطابع الزمني المحدد

--stream

تدفق الأحداث وعدم الخروج بعد قراءة آخر حدث معروف (الافتراضي true).

--until=timestamp

عرض جميع الأحداث التي تم إنشاؤها حتى الطابع الزمني المحدد

يمكن أن تكون قيم since و until طوابع زمنية RFC3339Nano أو سلسلة مدة Go مثل 10m، 5h. إذا لم يتم توفير قيم since أو until، يتم عرض الأحداث الجديدة فقط.

معرّفات Journald

يستخدم backend الأحداث journald في Podman معرّفات journald التالية. يمكنك استخدام المعرّفات لتصفية أحداث Podman مباشرة باستخدام journalctl.

المعرّف الوصف
SYSLOG_IDENTIFIER يتم تعيينه دائمًا إلى "podman"
PODMAN_EVENT حالة الحدث كما هو موصوف أعلاه
PODMAN_TYPE نوع الحدث كما هو موصوف أعلاه
PODMAN_TIME الطابع الزمني عند كتابة الحدث
PODMAN_NAME اسم كائن الحدث (مثل حاوية، صورة)
PODMAN_ID معرّف كائن الحدث (مثل حاوية، صورة)
PODMAN_EXIT_CODE رمز خروج الحاوية
PODMAN_POD_ID معرّف الـ pod الخاص بالحاوية
PODMAN_LABELS تسميات الحاوية
PODMAN_HEALTH_STATUS حالة صحة الحاوية
PODMAN_CONTAINER_INSPECT_DATA حمولة JSON الخاصة بـ podman-inspect كما هو موصوف أعلاه
PODMAN_NETWORK_NAME اسم الشبكة

أمثلة

عرض أحداث Podman:

$ podman events
2019-03-02 10:33:42.312377447 -0600 CST container create 34503c192940 (image=docker.io/library/alpine:latest, name=friendly_allen)
2019-03-02 10:33:46.958768077 -0600 CST container init 34503c192940 (image=docker.io/library/alpine:latest, name=friendly_allen)
2019-03-02 10:33:46.973661968 -0600 CST container start 34503c192940 (image=docker.io/library/alpine:latest, name=friendly_allen)
2019-03-02 10:33:50.833761479 -0600 CST container stop 34503c192940 (image=docker.io/library/alpine:latest, name=friendly_allen)
2019-03-02 10:33:51.047104966 -0600 CST container cleanup 34503c192940 (image=docker.io/library/alpine:latest, name=friendly_allen)

عرض أحداث إنشاء حاويات Podman فقط:

$ podman events -f event=create
2019-03-02 10:36:01.375685062 -0600 CST container cre

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
