PROLOG

هذه الصفحة الدليلية جزء من دليل مبرمجي POSIX. قد يختلف تنفيذ هذا الواجهة في لينكس (راجع صفحة دليل لينكس المقابلة لتفاصيل سلوك لينكس)، أو قد لا يتم تنفيذ الواجهة على لينكس.

الاسم

posix_trace_attr_getlogsize, posix_trace_attr_getmaxdatasize, posix_trace_attr_getmaxsystemeventsize, posix_trace_attr_getmaxusereventsize, posix_trace_attr_getstreamsize, posix_trace_attr_setlogsize, posix_trace_attr_setmaxdatasize, posix_trace_attr_setstreamsize — استرداد وتعيين سمات حجم دفق التتبع (TRACING)

الملخص

#include <sys/types.h>
#include <trace.h>
int posix_trace_attr_getlogsize(const trace_attr_t *restrict attr,
    size_t *restrict logsize);
int posix_trace_attr_getmaxdatasize(const trace_attr_t *restrict attr,
    size_t *restrict maxdatasize);
int posix_trace_attr_getmaxsystemeventsize(
    const trace_attr_t *restrict attr,
    size_t *restrict eventsize);
int posix_trace_attr_getmaxusereventsize(
    const trace_attr_t *restrict attr,
    size_t data_len, size_t *restrict eventsize);
int posix_trace_attr_getstreamsize(const trace_attr_t *restrict attr,
    size_t *restrict streamsize);
int posix_trace_attr_setlogsize(trace_attr_t *attr,
    size_t logsize);
int posix_trace_attr_setmaxdatasize(trace_attr_t *attr,
    size_t maxdatasize);
int posix_trace_attr_setstreamsize(trace_attr_t *attr,
    size_t streamsize);

الوصف

يقوم الدالة posix_trace_attr_getlogsize() بنسخ حجم السجل، بالبايت، من سمة log-max-size لكائن السمات الذي يشير إليه الوسيط attr إلى المتغير الذي يشير إليه الوسيط logsize. حجم السجل هذا هو الحد الأقصى الإجمالي للبايتات التي يجب تخصيصها لأحداث النظام والتتبع المستخدم في سجل التتبع. القيمة الافتراضية لسمة log-max-size معرفة من قبل التنفيذ.

تقوم الدالة posix_trace_attr_setlogsize() بتعيين الحد الأقصى للحجم المسموح به، بالبايت، في سمة log-max-size لكائن السمات الذي يشير إليه الوسيط attr، باستخدام قيمة الحجم التي يوفرها الوسيط logsize.

سيتم استخدام حجم سجل التتبع إذا تم تعيين سمة log-full-policy إلى POSIX_TRACE_LOOP أو POSIX_TRACE_UNTIL_FULL. إذا تم تعيين سمة log-full-policy إلى POSIX_TRACE_APPEND، فسيتجاهل التنفيذ سمة log-max-size.

تقوم الدالة posix_trace_attr_getmaxdatasize() بنسخ الحد الأقصى لحجم بيانات حدث التتبع المستخدم، بالبايت، من سمة max-data-size لكائن السمات الذي يشير إليه الوسيط attr إلى المتغير الذي يشير إليه الوسيط maxdatasize. القيمة الافتراضية لسمة max-data-size معرفة من قبل التنفيذ.

تقوم الدالة posix_trace_attr_getmaxsystemeventsize() بحساب الحد الأقصى لحجم الذاكرة، بالبايت، المطلوب لتخزين حدث تتبع نظام واحد. يتم حساب هذه القيمة لكائن سمات دفق التتبع الذي يشير إليه الوسيط attr ويتم إرجاعها في المتغير الذي يشير إليه الوسيط eventsize.

يجب أن تكون القيم التي تم إرجاعها كأحجام الذاكرة القصوى لأحداث التتبع المستخدمة والنظام بحيث إذا كان مجموع أحجام الذاكرة القصوى لمجموعة من أحداث التتبع التي يمكن تسجيلها في دفق تتبع أقل من أو يساوي سمة stream-min-size لذلك دفق التتبع، فإن النظام يوفر الموارد اللازمة لتسجيل كل أحداث التتبع تلك، دون فقدان.

تقوم الدالة posix_trace_attr_getmaxusereventsize() بحساب الحد الأقصى لحجم الذاكرة، بالبايت، المطلوب لتخزين حدث تتبع مستخدم واحد تم إنشاؤه بواسطة استدعاء posix_trace_event() مع وسيط data_len يساوي قيمة data_len المحددة في هذا الاستدعاء. يتم حساب هذه القيمة لكائن سمات دفق التتبع الذي يشير إليه الوسيط attr ويتم إرجاعها في المتغير الذي يشير إليه الوسيط eventsize.

تقوم الدالة posix_trace_attr_getstreamsize() بنسخ حجم الدفق، بالبايت، من سمة stream-min-size لكائن السمات الذي يشير إليه الوسيط attr إلى المتغير الذي يشير إليه الوسيط streamsize.

هذا الحجم الدفق هو الحجم الإجمالي الحالي للذاكرة المخصصة لأحداث النظام والتتبع المستخدم في دفق التتبع. القيمة الافتراضية لسمة stream-min-size معرفة من قبل التنفيذ. يشير حجم الدفق إلى الذاكرة المستخدمة لتخزين سجلات أحداث التتبع. يجب عدم تضمين بيانات الدفق الأخرى (على سبيل المثال، قيم سمات التتبع) في هذا الحجم.

تقوم الدالة posix_trace_attr_setmaxdatasize() بتعيين الحد الأقصى للحجم المسموح به، بالبايت، في سمة max-data-size لكائن السمات الذي يشير إليه الوسيط attr، باستخدام قيمة الحجم التي يوفرها الوسيط maxdatasize. هذا الحجم الأقصى هو الحد الأقصى للحجم المسموح به لوسيط بيانات المستخدم الذي يمكن تمريره إلى posix_trace_event(). يُسمح للتنفيذ باقتطاع البيانات التي تم تمريرها إلى trace_user_event والتي تكون أطول من maxdatasize.

تقوم الدالة posix_trace_attr_setstreamsize() بتعيين الحد الأدنى للحجم المسموح به، بالبايت، في سمة stream-min-size لكائن السمات الذي يشير إليه الوسيط attr، باستخدام قيمة الحجم التي يوفرها الوسيط streamsize.

posix_trace_attr_getlogsize.3p

POSIX trace attribute getlogsize

PROLOG

2017

NAME

posix_trace_attr_getlogsize, posix_trace_attr_setlogsize — retrieve and set the trace log size attribute

SYNOPSIS

#include <trace.h>

int posix_trace_attr_getlogsize(const trace_attr_t *attr, size_t *logsize);
int posix_trace_attr_setlogsize(trace_attr_t *attr, size_t logsize);

DESCRIPTION

The posix_trace_attr_getlogsize() function shall retrieve the value of the trace log size attribute from the object referenced by attr and store it in the location referenced by logsize.

The posix_trace_attr_setlogsize() function shall set the trace log size attribute of the object referenced by attr to the specified logsize value.

The trace log size attribute specifies the maximum size, in bytes, of the trace log buffer.

If the logsize argument is zero, the trace log size attribute shall be set to a system-wide default value.

The trace log size attribute is a boolean attribute. If the trace log size attribute is not supported by the system, the functions shall return an error.

The following trace log size values are supported:

Trace log size attribute
The size of the trace log buffer in bytes.

RETURN VALUE

On success, both functions shall return 0. Otherwise, they shall return an error number.

ERRORS

The posix_trace_attr_getlogsize() function shall fail if:

EINVAL
The value specified by attr is not a valid trace attribute object.
ENOSYS
The posix_trace_attr_getlogsize() function is not supported by the system.

The posix_trace_attr_setlogsize() function shall fail if:

EINVAL
The value specified by attr is not a valid trace attribute object.
EINVAL
The logsize value is not supported by the system.
ENOSYS
The posix_trace_attr_setlogsize() function is not supported by the system.

EXAMPLES

   #include <trace.h>
   #include <stdio.h>

   int main() {
       trace_attr_t attr;
       size_t logsize;
       int ret;

       ret = posix_trace_attr_init(&attr);
       if (ret != 0) {
           perror("posix_trace_attr_init");
           return 1;
       }

       ret = posix_trace_attr_setlogsize(&attr, 1024);
       if (ret != 0) {
           perror("posix_trace_attr_setlogsize");
           return 1;
       }

       ret = posix_trace_attr_getlogsize(&attr, &logsize);
       if (ret != 0) {
           perror("posix_trace_attr_getlogsize");
           return 1;
       }

       printf("Trace log size: %zu\n", logsize);

       return 0;
   }

APPLICATION USAGE

These functions are intended for use by applications that need to control the size of the trace log buffer.

RATIONALE

The trace log size attribute allows applications to specify the maximum size of the trace log buffer. This can be useful for controlling the amount of memory used by the trace log, or for ensuring that the trace log does not become too large.

FUTURE DIRECTIONS

The trace log size attribute may be extended in the future to support more fine-grained control over the trace log buffer.
