Pod::Simple::PullParserToken(3perl) دليل مبرمجي بيرل Pod::Simple::PullParserToken(3perl)

الاسم

Pod::Simple::PullParserToken -- رموز من Pod::Simple::PullParser

الملخص

بالنظر إلى $parser الذي هو كائن من فئة Pod::Simple::PullParser (أو فئة فرعية)...

while(my $token = $parser->get_token) {
  $DEBUG and print STDERR "Token: ", $token->dump, "\n";
  if($token->is_start) {
    ...access $token->tagname, $token->attr, etc...
  } elsif($token->is_text) {
    ...access $token->text, $token->text_r, etc...
  } elsif($token->is_end) {
    ...access $token->tagname...
  }
}

(انظر أيضًا Pod::Simple::PullParser)

الوصف

عندما تقوم بـ $parser->get_token على كائن Pod::Simple::PullParser، يجب أن تحصل على كائن من فئة فرعية من Pod::Simple::PullParserToken.

ستضيف الفئات الفرعية طرقًا، وستورث أيضًا هذه الطرق:

$token->type
هذه تُرجع نوع الرمز. سيكون هذا إما السلسلة النصية "start"، أو السلسلة النصية "text"، أو السلسلة النصية "end".

بمجرد أن تعرف نوع الكائن، فإنك تعرف إلى أي فئة فرعية ينتمي، وبالتالي ما هي الطرق التي يدعمها.

نعم، يمكنك ربما فعل الشيء نفسه باستخدام كود مثل $token->isa('Pod::Simple::PullParserEndToken')، لكن هذا ليس جميلًا مثل استخدام $token->type فقط، أو حتى الاختصارات التالية:

$token->is_start
هذا اختصار لـ "$token->type() eq "start""
$token->is_text
هذا اختصار لـ "$token->type() eq "text""
$token->is_end
هذا اختصار لـ "$token->type() eq "end""
$token->dump
هذه تُرجع قيمة مفيدة ممثلة كسلسلة نصية لهذا الكائن. هذا مفيد لتصحيح الأخطاء، كما في: 
while(my $token = $parser->get_token) {
  $DEBUG and print STDERR "Token: ", $token->dump, "\n";
  ...
}

انظر أيضًا

فئاتي الفرعية: Pod::Simple::PullParserStartToken, Pod::Simple::PullParserTextToken, و Pod::Simple::PullParserEndToken.
