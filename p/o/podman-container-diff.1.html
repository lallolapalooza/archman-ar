podman-container-diff(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-container-diff(1) دليل الأوامر العامة podman-container-diff(1)

الاسم

podman-container-diff - فحص التغييرات في نظام ملفات الحاوية

الملخص

podman container diff [خيارات] حاوية [حاوية]

الوصف

يعرض التغييرات في نظام ملفات الحاوية. تتم مقارنة الحاوية بطبقتها الأم أو بالحجة الثانية عند تقديمها.

يُسبق الإخراج بالرموز التالية:

رمز الوصف
A تمت إضافة ملف أو دليل.
D تم حذف ملف أو دليل.
C تم تغيير ملف أو دليل.

الخيارات

--format

تغيير الإخراج إلى تنسيق مختلف. التنسيق الوحيد الصالح لـ podman container diff هو json.

--latest, -l

بدلاً من تقديم اسم الحاوية أو معرفها، استخدم آخر حاوية تم إنشاؤها. ملاحظة: يمكن أن تكون آخر حاوية تم تشغيلها من مستخدمين آخرين لـ Podman على الجهاز المضيف. (هذا الخيار غير متاح مع عميل Podman عن بُعد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

أمثلة

# podman container diff container1
C /usr
C /usr/local
C /usr/local/bin
A /usr/local/bin/docker-entrypoint.sh
$ podman container diff --format json container1 container2
{
     "added": [
          "/test"
     ]
}
$ podman container diff --latest
C /etc
