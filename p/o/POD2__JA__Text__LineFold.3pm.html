NAME

Text::LineFold~[ja] - نص للطي

SYNOPSIS

use Text::LineFold;
$lf = Text::LineFold->new();

# طي النص
$folded = $lf->fold($string, 'PLAIN');
$indented = $lf->fold(' ' x 8, ' ' x 4, $string);
# فك طي النص
$unfolded = $lf->unfold($string, 'FIXED');

DESCRIPTION

Text::LineFold يطوي ويفك طي النص العادي. الهدف الرئيسي هو رسائل البريد الإلكتروني، وهو يدعم أيضًا الصيغة المتدفقة في RFC 3676.

واجهات عامة

new ([KEY => VALUE, ...])
منشئ. لمعنى KEY => VALUE، انظر الطريقة config.
$self->config (KEY)
$self->config ([KEY => VAL, ...])
طريقة المثيل. الحصول على الإعدادات أو تحديثها. يمكن تحديد المفاتيح التالية: VALUE أزواج.
Charset => CHARSET
مجموعة الأحرف المستخدمة لترميز سلسلة الإدخال. سلسلة أو كائن MIME::Charset. القيمة الافتراضية هي "UTF-8".
Language => LANGUAGE
تستخدم لتحديد اللغة / المنطقة للسياق، بالإضافة إلى خيار Charset. القيمة الافتراضية هي "XX". انظر أيضًا "Context" in Unicode::LineBreak~[ja] خيار.
Newline => STRING
سلسلة سطر جديد. القيمة الافتراضية هي "\n".
OutputCharset => CHARSET
مجموعة الأحرف المستخدمة لترميز نتيجة fold()/unfold(). سلسلة أو كائن MIME::Charset. إذا تم تعيين القيمة الخاصة "_UNICODE_"، تكون النتيجة سلسلة Unicode. القيمة الافتراضية هي قيمة خيار Charset.
TabSize => NUMBER
عدد المسافات لكل حرف جدولة. تعيينه إلى 0 يتجاهل أحرف الجدولة. القيمة الافتراضية هي 8.

$self->fold (STRING, [METHOD])
$self->fold (INITIAL_TAB, SUBSEQUENT_TAB, STRING, ...)
مثيل الطريقة. يطوي سلسلة النص STRING. يزيل المسافات البيضاء الزائدة في نهاية السطر وأحرف الجدولة الأفقية، ثم يستبدلها بالسلسلة المحددة بواسطة خيار Newline، ويضيف سطرًا جديدًا في نهاية النص إذا لزم الأمر. تُعامل أحرف الجدولة الأفقية على أنها مسافات جدولة وفقًا لـ خيار TabSize.

في الصيغة المكونة من ثلاثة عناصر، يمكن تحديد الخيارات التالية كوسيط METHOD:

"FIXED"
الأسطر التي تبدأ بـ ">" لا يتم طيها. يتم فصل الفقرات بسطر فارغ.
"FLOWED"
الصيغة "Format=Flowed; DelSp=Yes" المحددة في RFC 3676.
"PLAIN"
الطريقة الافتراضية. يطوي جميع الأسطر.

الصيغة المكونة من أربعة عناصر مشابهة لـ "wrap()" in Text::Wrap. يطوي جميع الأسطر. يتم إدراج INITIAL_TAB في بداية الأسطر الجديدة، و SUBSEQUENT_TAB في بداية الأسطر الأخرى.

$self->unfold (STRING, METHOD)
سلسلة النص STRING تُفك طيات أسطرها وتُدمج.

يمكن تحديد الخيارات التالية كوسيط METHOD:

"FIXED"
الطريقة الافتراضية. الأسطر التي تبدأ بـ ">" لا يتم فك طياتها. تُفسر الأسطر الفارغة كفواصل فقرات.
"FLOWED"
يفك طي الصيغة "Format=Flowed; DelSp=Yes" المحددة في RFC 3676.
"FLOWEDSP"
يفك طي الصيغة
