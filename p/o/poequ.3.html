!>
!> CPOEQU تحسب عوامل القياس للصف والعمود المخصصة لموازنة مصفوفة هيرميتية موجبة محددة A وتقليل رقم حالتها (بالنسبة للمعيار الثنائي). تحتوي S على عوامل القياس،
!> S(i) = 1/sqrt(A(i,i))، مختارة بحيث تحتوي المصفوفة المقاسة B ذات العناصر B(i,j) = S(i)*A(i,j)*S(j) على واحدات على القطر. هذا
!> الاختيار لـ S يضع رقم حالة B في حدود عامل N من
!> أصغر رقم حالة ممكن لجميع قياسات الأقطار الممكنة.
!>

المعاملات

N 
!>          N هو عدد صحيح (INTEGER)
!>          مرتبة المصفوفة A. N >= 0.
!>

A

!>          A هي مصفوفة مركبة (COMPLEX)، بأبعاد (LDA,N)
!>          المصفوفة الهيرميتية الموجبة المحددة من الدرجة N*N التي يتم حساب عوامل قياسها. يتم الرجوع فقط إلى العناصر القطرية لـ A.
!>

LDA

!>          LDA هو عدد صحيح (INTEGER)
!>          البعد الرائد للمصفوفة A. LDA >= max(1,N).
!>

S

!>          S هي مصفوفة حقيقية (REAL)، بأبعاد (N)
!>          إذا كان INFO = 0، فإن S تحتوي على عوامل القياس للمصفوفة A.
!>

SCOND

!>          SCOND هو عدد حقيقي (REAL)
!>          إذا كان INFO = 0، فإن S تحتوي على نسبة أصغر S(i) إلى
!>          أكبر S(i). إذا كان SCOND >= 0.1 ولم يكن AMAX كبيرًا جدًا أو صغيرًا جدًا، فلا يستحق الأمر القياس باستخدام S.
!>

AMAX

!>          AMAX هو عدد حقيقي (REAL)
!>          القيمة المطلقة لأكبر عنصر في المصفوفة. إذا كان AMAX قريبًا جدًا من تجاوز السعة أو قريبًا جدًا من نقص السعة، فيجب قياس المصفوفة.
!>

INFO

!>          INFO هو عدد صحيح (INTEGER)
!>          = 0:  خروج ناجح
!>          < 0:  إذا كان INFO = -i، فإن المعامل i كان له قيمة غير قانونية
!>          > 0:  إذا كان INFO = i، فإن العنصر القطري i غير موجب.
!>

poequ(3)

NAME

poequ, zpoequ - equilibrate a general Hermitian positive definite matrix

SYNOPSIS

    SUBROUTINE POEQU( N, A, LDA, S, SCOND, AMAX, INFO )

        INTEGER           N
        REAL              A( LDA, * )
        INTEGER           LDA
        REAL              S( * )
        REAL              SCOND
        REAL              AMAX
        INTEGER           INFO

    SUBROUTINE ZPOEQU( N, A, LDA, S, SCOND, AMAX, INFO )

        INTEGER           N
        DOUBLE PRECISION  A( LDA, * )
        INTEGER           LDA
        DOUBLE PRECISION  S( * )
        DOUBLE PRECISION  SCOND
        DOUBLE PRECISION  AMAX
        INTEGER           INFO

Detailed Description

The routines poequ and zpoequ compute row and column scalings intended to equilibrate a Hermitian positive definite matrix A and reduce its condition number (with respect to the 2-norm). S contains the scale factors, S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix B with elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal. This choice of S puts the condition number of B within a factor N of the smallest possible condition number over all possible diagonal scalings.

These routines are not intended for use in mixed-precision arithmetic.

Function Documentation

subroutine poequ (integer n, real, dimension( lda, * ) a, integer lda, real, dimension( * ) s, real scond, real amax, integer info)

POEQU

Purpose:

!>
!> POEQU computes row and column scalings intended to equilibrate a
!> Hermitian positive definite matrix A and reduce its condition number
!> (with respect to the two-norm).  S contains the scale factors,
!> S(i) = 1/sqrt(A(i,i)), chosen so that the scaled matrix B with
!> elements B(i,j) = S(i)*A(i,j)*S(j) has ones on the diagonal.  This
!> choice of S puts the condition number of B within a factor N of the
!> smallest possible condition number over all possible diagonal
!> scalings.
!>

Parameters

N 
!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          The N-by-N Hermitian positive definite matrix whose scaling
!>          factors are to be computed.  Only the diagonal elements of A
!>          are referenced.
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

S

!>          S is REAL array, dimension (N)
!>          If INFO = 0, S contains the scale factors for A.
!>

SCOND

!>          SCOND is REAL
!>          If INFO = 0, S contains the ratio of the smallest S(i) to
!>          the largest S(i).  If SCOND >= 0.1 and AMAX is neither too
!>          large nor too small, it is not worth scaling by S.
!>

AMAX

!>          AMAX is REAL
!>          Absolute value of largest matrix element.  If AMAX is very
!>          close to overflow or very close to underflow, the matrix
!>          should be scaled.
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>          > 0:  if INFO = i, the i-th diagonal element is nonpositive.
!>
