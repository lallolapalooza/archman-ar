podman-container-rm(1)

NAME
podman-container-rm - Remove one or more containers
SYNOPSIS
podman container rm [options] CONTAINER [CONTAINER...]
DESCRIPTION
Removes one or more containers. A running container must be stopped before it can be removed, unless the -f (or --force) option is used.
OPTIONS
-f, --force
Force the removal of a running container. The container will be stopped (SIGKILL) before being removed.
-a, --all
Remove all containers.
-v, --volumes
Remove the volumes associated with the container. The volumes must not be associated with any other container.
EXAMPLES
# Remove a container named mycontainer
$ podman container rm mycontainer

# Remove multiple containers
$ podman container rm container1 container2

# Force remove a running container
$ podman container rm -f runningcontainer

# Remove all containers
$ podman container rm -a

# Remove container and its volumes
$ podman container rm -v mycontainer
Exit Status
0 Success
1 Error
