podman-network-inspect(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-network-inspect(1) دليل الأوامر العامة podman-network-inspect(1)

الاسم

podman network inspect - عرض تكوين الشبكة لشبكة واحدة أو أكثر

المُلَخَّص

podman network inspect [خيارات] network [network ...]

الوصف

عرض تكوين الشبكة (بتنسيق JSON).

الخيارات

--format, -f=format

طباعة الشبكات بتنسيق JSON أو باستخدام قالب Go.

العنصر النائب الوصف
.Containers ... الحاويات قيد التشغيل على هذه الشبكة.
.Created ... الطابع الزمني عند إنشاء الشبكة
.DNSEnabled الشبكة لديها DNS مفعل (قيمة منطقية)
.Driver مشغل الشبكة
.ID معرف الشبكة
.Internal الشبكة داخلية (قيمة منطقية)
.IPAMOptions ... خيارات IPAM للشبكة
.IPv6Enabled الشبكة لديها شبكة فرعية IPv6 (قيمة منطقية)
.Labels ... تسميات الشبكة
.Name اسم الشبكة
.Network ... نوع الشبكة المتداخلة
.NetworkDNSServers مصفوفة خوادم DNS المستخدمة في هذه الشبكة
.NetworkInterface اسم واجهة الشبكة على المضيف
.Options ... خيارات الشبكة
.Routes قائمة المسارات الثابتة لهذه الشبكة
.Subnets قائمة الشبكات الفرعية على هذه الشبكة

مثال

فحص شبكة podman الافتراضية.

$ podman network inspect podman
[
    {
        "name": "podman",
        "id": "2f259bab93aaaaa2542ba43ef33eb990d0999ee1b9924b557b7be53c0b7a1bb9",
        "driver": "bridge",
        "network_interface": "podman0",
        "created": "2021-06-03T12:04:33.088567413+02:00",
        "subnets": [
            {
                "subnet": "10.88.0.0/16",
                "gateway": "10.88.0.1"
            }
        ],
        "ipv6_enabled": false,
        "internal": false,
        "dns_enabled": false,
        "ipam_options": {
            "driver": "host-local"
        }
    }
]

عرض الشبكة الفرعية والبوابة لشبكة.

$ podman network inspect podman --format "{{range .Subnets}}Subnet: {{.Subnet}} Gateway: {{.Gateway}}{{end}}"
Subnet: 10.88.0.0/16 Gateway: 10.88.0.1
