podman-system-connection-add(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-system-connection-add(1) دليل الأوامر العامة podman-system-connection-add(1)

الاسم

podman-system-connection-add - تسجيل وجهة لخدمة Podman

الملخص

podman system connection add [خيارات] اسم وجهة

الوصف

تسجيل وجهة ssh لخدمة (خدمات) Podman عن بعد. يتم تقديم وجهة ssh على النحو التالي:


- [user@]hostname[:port]
- ssh://[user@]hostname[:port]
- unix://path
- tcp://hostname:port

يتم مطالعة المستخدم بكلمة مرور تسجيل الدخول عبر ssh أو عبارة مرور ملف المفتاح حسب الحاجة. يتم دعم ssh-agent إذا كان قيد التشغيل.

الخيارات

--default, -d

جعل الوجهة الجديدة هي الوجهة الافتراضية لهذا المستخدم. القيمة الافتراضية هي false.

--identity=path

المسار إلى ملف هوية ssh. إذا كان ملف الهوية مشفرًا، يطالب Podman المستخدم بعبارة المرور. إذا لم يتم تقديم أي ملف هوية ولم يتم تحديد مستخدم، فإن Podman يستخدم المستخدم الذي يقوم بتشغيل أمر podman بشكل افتراضي. يطالب Podman بكلمة مرور تسجيل الدخول على الخادم البعيد.

--port, -p=port

منفذ وجهة ssh. القيمة الافتراضية هي 22.

--socket-path=path

المسار إلى مقبس مجال Unix الخاص بخدمة Podman على مضيف وجهة ssh

--tls-ca=path

المسار إلى ملف PEM يحتوي على حزمة سلطة الشهادات للتحقق من شهادة الخادم.

--tls-cert=path

المسار إلى ملف PEM يحتوي على شهادة عميل TLS لتقديمها للخادم. يجب أيضًا توفير --tls-key.

--tls-key=path

المسار إلى ملف PEM يحتوي على المفتاح الخاص المطابق لـ --tls-cert. يجب أيضًا توفير --tls-cert.

مثال

إضافة اتصال نظام مسمى:

$ podman system connection add QA podman.example.com

إضافة اتصال نظام باستخدام بيانات SSH:

$ podman system connection add --identity ~/.ssh/dev_rsa production ssh://root@server.example.com:2222

إضافة اتصال نظام مسمى إلى مقبس Unix محلي:

$ podman system connection add testing unix:///run/podman/podman.sock

إضافة اتصال نظام مسمى إلى مقبس TCP محلي:

$ podman system connection add debug tcp://localhost:8080

إضافة اتصال بمنفذ مخصص:

$ podman system connection add --port 2222 staging user@staging.example.com

إضافة اتصال بمسار مقبس مخصص:

$ podman system connection add --socket-path /run/user/1000/podman/podman.sock remote-user user@remote.example.com

إضافة اتصال وجعله افتراضيًا:

$ podman system connection add --default production root@prod.example.com

إضافة اتصال نظام مسمى إلى مقبس TCP بعيد مؤمن عبر TLS:

$ podman system connection add secure-debug --tls-cert=tls.crt --tls-key=tls.key --tls-ca=ca.crt tcp://podman.example.com:8443
