subroutine cposvx (character fact, character uplo, integer n, integer nrhs, complex, dimension( lda, * ) a, integer lda, complex, dimension( ldaf, * ) af, integer ldaf, character equed, real, dimension( * ) s, complex, dimension( ldb, * ) b, integer ldb, complex, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, complex, dimension( * ) work, real, dimension( * ) rwork, integer info)

CPOSVX تحسب حل نظام المعادلات الخطية A * X = B لمصفوفات PO

الغرض:

!>
!> CPOSVX تستخدم تحليل Cholesky A = U**H*U أو A = L*L**H لحساب حل
!> نظام المعادلات الخطية المعقدة
!>    A * X = B,
!> حيث A مصفوفة مترافقة موجبة محددة بحجم N*N، و X و B مصفوفتان بحجم N*NRHS.
!>
!> يتم أيضًا توفير حدود الخطأ للحل وتقدير للشرط.
!>

الوصف:

!>
!> يتم تنفيذ الخطوات التالية:
!>
!> 1. إذا كان FACT = 'E'، يتم حساب عوامل القياس الحقيقية لموازنة
!>    النظام:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    يعتمد ما إذا كان النظام سيتم موازنته على قياس المصفوفة A، ولكن إذا تم استخدام
!>    الموازنة، يتم استبدال A بـ diag(S)*A*diag(S) و B بـ diag(S)*B.
!>
!> 2. إذا كان FACT = 'N' أو 'E'، يتم استخدام تحليل Cholesky لتحليل
!>    المصفوفة A (بعد الموازنة إذا كان FACT = 'E') كـ
!>       A = U**H* U، إذا كان UPLO = 'U'، أو
!>       A = L * L**H، إذا كان UPLO = 'L'،
!>    حيث U مصفوفة مثلثية عليا و L مصفوفة مثلثية سفلى.
!>
!> 3. إذا كان المحدد الرئيسي الأساسي من الرتبة i غير موجب،
!>    فإن الروتين يعود بـ INFO = i. خلاف ذلك، يتم استخدام الشكل المحلل
!>    لـ A لتقدير رقم شرط المصفوفة A. إذا كان مقلوب رقم الشرط أقل من الدقة
!>    للآلة، يتم إرجاع INFO = N+1 كتحذير، ولكن الروتين
!>    يستمر في حساب X وحساب حدود الخطأ كما هو موضح أدناه.
!>
!> 4. يتم حل نظام المعادلات من أجل X باستخدام الشكل المحلل
!>    لـ A.
!>
!> 5. يتم تطبيق تحسين تكراري لتحسين الحل المحسوب
!>    و حساب حدود الخطأ وتقديرات الخطأ الخلفي له.
!>
!> 6. إذا تم استخدام الموازنة، يتم ضرب المصفوفة X مسبقًا بـ
!>    diag(S) بحيث تحل النظام الأصلي قبل
!>    الموازنة.
!>

subroutine sposvx (character fact, character uplo, integer n, integer nrhs, real, dimension( lda, * ) a, integer lda, real, dimension( ldaf, * ) af, integer ldaf, character equed, real, dimension( * ) s, real, dimension( ldb, * ) b, integer ldb, real, dimension( ldx, * ) x, integer ldx, real rcond, real, dimension( * ) ferr, real, dimension( * ) berr, real, dimension( * ) work, integer, dimension( * ) iwork, integer info)

SPOSVX computes the solution to system of linear equations A * X = B for PO matrices

Purpose:

!>
!> SPOSVX uses the Cholesky factorization A = U**T*U or A = L*L**T to
!> compute the solution to a real system of linear equations
!>    A * X = B,
!> where A is an N-by-N symmetric positive definite matrix and X and B
!> are N-by-NRHS matrices.
!>
!> Error bounds on the solution and a condition estimate are also
!> provided.
!>

Description:

!>
!> The following steps are performed:
!>
!> 1. If FACT = 'E', real scaling factors are computed to equilibrate
!!>    the system:
!>       diag(S) * A * diag(S) * inv(diag(S)) * X = diag(S) * B
!>    Whether or not the system will be equilibrated depends on the
!>    scaling of the matrix A, but if equilibration is used, A is
!>    overwritten by diag(S)*A*diag(S) and B by diag(S)*B.
!>
!> 2. If FACT = 'N' or 'E', the Cholesky decomposition is used to
!>    factor the matrix A (after equilibration if FACT = 'E') as
!>       A = U**T* U,  if UPLO = 'U', or
!>       A = L * L**T,  if UPLO = 'L',
!>    where U is an upper triangular matrix and L is a lower triangular
!>    matrix.
!>
!> 3. If the leading principal minor of order i is not positive,
!>    then the routine returns with INFO = i. Otherwise, the factored
!>    form of A is used to estimate the condition number of the matrix
!>    A.  If the reciprocal of the condition number is less than machine
!>    precision, INFO = N+1 is returned as a warning, but the routine
!>    still goes on to solve for X and compute error bounds as
!>    described below.
!>
!> 4. The system of equations is solved for X using the factored form
!>    of A.
!>
!> 5. Iterative refinement is applied to improve the computed solution
!>    matrix and calculate error bounds and backward error estimates
!>    for it.
!>
!> 6. If equilibration was used, the matrix X is premultiplied by
!>    diag(S) so that it solves the original system before
!>    equilibration.
!>

Parameters

FACT 
!>          FACT is CHARACTER*1
!>          Specifies whether or not the factored form of the matrix A is
!>          supplied on entry, and if not, whether the matrix A should be
!>          equilibrated before it is factored.
!>          = 'F':  On entry, AF contains the factored form of A.
!>                  If EQUED = 'Y', the matrix A has been equilibrated
!>                  with scaling factors given by S.  A and AF will not
!>                  be modified.
!>          = 'N':  The matrix A will be copied to AF and factored.
!>          = 'E':  The matrix A will be equilibrated if necessary, then
!>                  copied to AF and factored.
!>

UPLO

!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The number of linear equations, i.e., the order of the
!>          matrix A.  N >= 0.
!>

NRHS

!>          NRHS is INTEGER
!>          The number of right hand sides, i.e., the number of columns
!>          of the matrices B and X.  NRHS >= 0.
!>

A

!>          A is REAL array, dimension (LDA,N)
!>          On entry, the symmetric matrix A, except if FACT = 'F' and
!>          EQUED = 'Y', then A must contain the equilibrated matrix
!>          diag(S)*A*diag(S).  If UPLO = 'U', the leading
!>          N-by-N upper triangular part of A contains the upper
!>          triangular part of the matrix A, and the strictly lower
!>          triangular part of A is not referenced.  If UPLO = 'L', the
!>          leading N-by-N lower triangular part of A contains the lower
!>          triangular part of the matrix A, and the strictly upper
!>          triangular part of A is not referenced.  A is not modified if
!>          FACT = 'F' or 'N', or if FACT = 'E' and EQUED = 'N' on exit.
!>
!>          On exit, if FACT = 'E' and EQUED = 'Y', A is overwritten by
!>          diag(S)*A*diag(S).
!>

LDA

!>          LDA is INTEGER
!>          The leading dimension of the array A.  LDA >= max(1,N).
!>

AF

!>          AF is REAL array, dimension (LDAF,N)
!>          If FACT = 'F', then AF is an input argument and on entry

LDAF

EQUED

S

NAME

                    
posvx — query the condition number of a general linear matrix equation

                

                

                    
SYNOPSIS

                    
SUBROUTINE POSVX(FACT, TRANS, N, NRHS, A, LDA, AF, LDAF, IPIV, EQUED, S,
                 LDS, B, LDB, X, LDX, RCOND, FERR, BERR, WORK, RWORK,
                 INFO)
  CHARACTER FACT, TRANS, EQUED
  INTEGER INFO, LDA, LDAF, LDB, LDS, LDX, N, NRHS
  REAL(KIND=8) RCOND
  COMPLEX(KIND=16) A(LDA, *), AF(LDAF, *), B(LDB, *), WORK(*), X(LDX, *)
  INTEGER IPIV(*)
  REAL(KIND=8) S(*), FERR(*), BERR(*), RWORK(*)
                    

                

                

                    
Detailed Description

                    
POSVX solves a system of equations A*X = B for a
                        general approximate problem or a general matrix equation
                        A*X = B.

                    
The general problem is to solve A*X = B for a
                        general matrix A. In the general case, EQUED is not
                        used because the scaling of A to make it symmetric
                        positive definite is not possible.

                    
The equilibrated problem is to solve
                        A*X = B for a general matrix A. The solution of the
                        equilibrated system is computed by solving
                        eq CONJ(TRANS)*X = eqB, where
                        eq = diag(S) and eqB = eq * B.

                    
This routine is in the general form for
                        least squares routines. It calls the panel routines
                        ZPOSCO, ZPOCO, ZPORFS, ZPORFSX and ZPORvx.

                    
Arguments

                    

                        
FACT CHARACTER*1

                        

                            
Specifies the form of the system of
                                equations.

                            
'E': The parameters
                                EQUED, S, and B will be used to scale the
                                problem before being solved. This option is
                                only valid for square matrices A.

                            
'N': The direct form
                                of the problem is solved.

                            
'F': The solutions
                                to the equations A*X = B will be computed in
                                place, the equilibration factors S will be
                                computed and optionlly applied to A and B.

                            
Constraint: FACT = 'E', 'F', or 'N'.

                        

                        
TRANS CHARACTER*1

                        

                            
Specifies the form of the system of
                                equations.

                            
'N': System.

                            
'T': Transposed
                                system.

                            
'C': Conjugate
                                transposed system.

                            
Constraint: TRANS = 'N', 'T', or 'C'.

                        

                        
N INTEGER

                        

                            
The number of linear equations, i.e.,
                                the dimension of the square matrix A. N >= 0.

                        

                        
NRHS INTEGER

                        

                            
The number of right hand sides, i.e.,
                                the number of columns of the matrices B and
                                X. NRHS >= 0.

                        

                        
A COMPLEX*16 array, dimension (LDA,N)

                        

                            
The n-by-n matrix A.

                            
If FACT = 'F',
                                then A is overwritten by values generated during
                                the execution of ZGECO.

                        

                        
LDA INTEGER

                        

                            
The leading dimension of A. LDA >=
                                max(1,N).

                        

                        
AF COMPLEX*16 array, dimension (LDAF,N)

                        

                            
The n-by-n factorisation of A. A
                                is maintained on exit unless FACT =
                                'F', in which case, A is overwritten
                                by values generated during the execution of
                                ZGECO.

                        

                        
LDAF INTEGER

                        

                            
The leading dimension of AF.
                                LDAF >= max(1,N).

                        

                        
IPIV INTEGER array, dimension (N)

                        

                            
The pivot indices derived from the
                                factorization of A.

                        

                        
EQUED CHARACTER*1

                        

                            
'Y': The matrices A
                                and B have been copied to work arrays and
                                factored, and then the equilibrium
                                transformation was applied.

                            
'N': The matrices A
                                and B have not been scaled, and were not
                                factored.

                            
On entry, if FACT = 'E',
                                EQUED must be set to 'Y' or 'N'.

                            
On exit, if FACT = 'E',
                                EQUED is set to 'Y' if the matrix
                                has been restored for iterative refinement.

                            
On exit, if FACT = 'N',
                                EQUED is set to 'N'.

                            
On exit, if FACT = 'F',
                                EQUED is set to 'Y' or 'N'.

                        

                        
S REAL*8 array, dimension (N)

                        

                            
If FACT = 'E',
                                S is used to scale the matrix A. On entry, S
                                must contain the diagonal elements of the
                                diagonal matrix used to scale A. On exit, S
                                contains the diagonal elements of the diagonal
                                matrix used to scale B.

                            
If FACT = 'F',
                                S is an output argument, and the N elements of
                                S contain the scaling factors computed for the
                                row equilibrium of A.

                            
If FACT = 'N',
                                S is not used.

                            
If EQUED = 'Y'
                                on entry, the diagonal elements of S must be
                                positive. If EQUED = 'N'
                                on entry, S is not referenced.

                        

                        
LDS INTEGER

                        

                            
The leading dimension of the array
                                S. LDS >= max(1,N).

                            
If FACT = 'N',
                                LDS is not used.

                        

                        
B COMPLEX*16 array, dimension (LDB,NRHS)

                        

                            
B is COMPLEX*16 array, dimension (LDB,NRHS)
                                On entry, the N-by-NRHS righthand side matrix B.
                                On exit, if EQUED = 'N', B is not modified; if EQUED = 'Y',
                                B is overwritten by diag(S) * B.

                        

                        
LDB INTEGER

                        

                            
The leading dimension of the array
                                B. LDB >= max(1,N).

                        

                        
X COMPLEX*16 array, dimension (LDX,NRHS)

                        

                            
If INFO = 0 or INFO = N+1, the N-by-NRHS
                                solution matrix X to the original system of
                                equations. Note that if EQUED = 'Y', A and B
                                are modified on exit, and the solution to the
                                equilibrated system is inv(diag(S))*X.

                        

                        
LDX INTEGER

                        

                            
The leading dimension of the array
                                X. LDX >= max(1,N).

                        

                        
RCOND REAL*8

                        

                            
The estimate of the reciprocal
                                condition number of the matrix A after
                                equilibration (if done). If RCOND is less
                                than the machine precision (in particular,
                                if RCOND = 0), the matrix is singular to
                                working precision. This condition is
                                indicated by a return code of INFO > 0.

                        

                        
FERR REAL*8 array, dimension (NRHS)

                        

                            
The estimated forward error bound
                                for each solution vector X(j) (the j-th
                                column of the solution matrix X). If XTRUE
                                is the true solution corresponding to X(j),
                                FERR(j) is an estimated upper bound for the
                                magnitude of the largest element in
                                (X(j) - XTRUE) divided by the magnitude of
                                the largest element in X(j). The estimate
                                is as reliable as the estimate for RCOND,
                                and is almost always a slight
                                overestimate of the true error.

                        

                        
BERR REAL*8 array, dimension (NRHS)

                        

                            
The componentwise relative
                                backward error of each solution vector X(j)
                                (i.e., the smallest relative change in any
                                element of A or B that makes X(j) an exact
                                solution).

                        

                        
WORK COMPLEX*16 array, dimension (2*N)

                        

                        

                        
RWORK REAL*8 array, dimension (N)

                        

                        

                        
INFO INTEGER

                        

                            
= 0: successful
                                exit

                            
< 0: if INFO = -i,
                                the i-th argument had an illegal value

                            
> 0: if INFO = i,
                                and i is

                            
<= N: the leading
                                principal minor of order i of A is not
                                positive, so the factorization could not be
                                completed, and the solution has not been
                                computed. RCOND = 0 is returned.

                            
= N+1: U is
                                nonsingular, but RCOND is less than machine
                                precision, meaning that the matrix is
                                singular to working precision. Nevertheless,
                                the solution and error bounds are computed
                                because there are a number of situations where
                                the computed solution can be more accurate than
                                the value of RCOND would suggest.
