الحزمة: podman

التراخيص: Apache-2.0

podman-image-trust(1) دليل الأوامر العامة podman-image-trust(1)

الاسم

podman-image-trust - إدارة سياسة الثقة بصور سجل الحاويات

الملخص

podman image trust set|show [خيارات] registry[/repository]

الوصف

يدير أي سجلات يجب الوثوق بها كمصدر لصور الحاويات بناءً على موقعها. (هذا الخيار غير متاح مع عميل Podman عن بعد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

يتم تحديد الموقع بواسطة النقل والمضيف السجل للصورة. باستخدام صورة الحاوية هذه docker://docker.io/library/busybox كمثال، docker هو النقل و docker.io هو مضيف السجل.

تُعرّف الثقة في /etc/containers/policy.json ويتم تطبيقها عندما يحاول المستخدم سحب صورة عن بعد من سجل. تصف سياسة الثقة في policy.json نطاق سجل (سجل و/أو مستودع) للثقة. يمكن أن تستخدم هذه الثقة المفاتيح العامة للصور الموقعة.

يتم تقييم نطاق الثقة من الأكثر تحديدًا إلى الأقل تحديدًا. بعبارة أخرى، يمكن أن تكون السياسة:

  • محددة لسجل كامل.
  • محددة لمستودع معين في هذا السجل.
  • محددة لصورة موقعة معينة داخل السجل.

القائمة التالية هي أمثلة لقيم النطاق الصالحة المستخدمة في policy.json من الأكثر تحديدًا إلى الأقل تحديدًا:

docker.io/library/busybox:notlatest

docker.io/library/busybox

docker.io/library

docker.io

إذا لم يتم العثور على تكوين لأي من هذه النطاقات، يتم استخدام القيمة الافتراضية (المحددة باستخدام "default" بدلاً من REGISTRY[/REPOSITORY]).

يوفر نوع الثقة طريقة لـ:

السماح بقائمة ("accept") أو رفض قائمة ("reject") السجلات أو طلب توقيع بسيط (“signedBy”) ، طلب توقيع sigstore ("sigstoreSigned").

يمكن تحديث الثقة باستخدام الأمر podman image trust set لنطاق ثقة موجود.

الخيارات

--help, -h

طباعة عبارة الاستخدام.

set خيارات

--pubkeysfile, -f=KEY1

مسار إلى مفتاح عام مُصدّر على النظام المحلي. يتم الإشارة إلى مسارات المفاتيح
في policy.json. يمكن استخدام أي مسار لملف ولكن يوصى بتحديد موقع الملف في /etc/pki/containers. يمكن استخدام الخيارات عدة مرات ل
طلب أن يتم توقيع صورة بواسطة مفاتيح متعددة. الخيار --pubkeysfile مطلوب لأنواع
signedBy و sigstoreSigned.

--type, -t=value

نوع الثقة لإدخال السياسة هذا.
القيم المقبولة:
signedBy (الافتراضي): يتطلب توقيعات بسيطة مع قائمة مقابلة
من المفاتيح العامة
sigstoreSigned: يتطلب توقيعات sigstore مع قائمة مقابلة
من المفاتيح العامة
accept: لا يتطلب أي توقيعات لنطاق السجل
هذا
reject: لا يقبل الصور لنطاق السجل هذا

show خيارات

--json, -j

إخراج الثقة كـ JSON للمعالجة الآلية

--noheading, -n

تجاهل عناوين الجدول من القائمة.

--raw

إخراج ملف سياسة الثقة كـ JSON خام

أمثلة

قبول جميع الصور غير الموقعة من سجل:

sudo podman image trust set --type accept docker.io

تعديل سياسة الثقة الافتراضية:

sudo podman image trust set -t reject default

عرض سياسة الثقة للنظام:

podman image trust show
TRANSPORT      NAME                        TYPE        ID                   STORE
all            default                     reject
repository     docker.io/library           accept
repository     registry.access.redhat.com  signed      security@redhat.com  https://access.redhat.com/webassets/docker/content/sigstore
repository     registry.redhat.io          signed      security@redhat.com  https://registry.redhat.io/containers/sigstore
repository     docker.io                   reject
docker-daemon                              accept
