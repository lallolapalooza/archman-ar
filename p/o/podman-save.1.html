podman-save(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-save(1) دليل الأوامر العامة podman-save(1)

الاسم

podman-save - حفظ صورة (صور) في أرشيف

الملخص

podman save [خيارات] اسم[:علامة]

podman image save [خيارات] اسم[:علامة]

الوصف

يقوم podman save بحفظ صورة إلى ملف محلي أو دليل. يكتب podman save إلى المخرج القياسي (STDOUT) افتراضيًا ويمكن إعادة توجيهه إلى ملف باستخدام علامة output. تقمع علامة quiet الإخراج عند تعيينها. يقوم podman save بحفظ الطبقات الأصلية للصور ويمكن تحميل الصور باستخدام podman load. لتصدير الحاويات، استخدم podman export. ملاحظة: : هو حرف مقيد ولا يمكن أن يكون جزءًا من اسم الملف.

الخيارات

--compress

ضغط طبقات صور الأرشيف عند الدفع إلى دليل باستخدام النقل 'dir'. (الافتراضي هو نفس نوع الضغط، مضغوط أو غير مضغوط، مثل المصدر)

ملاحظة: يمكن تعيين هذه العلامة فقط مع --format=docker-dir.

--format=format

تنسيق صورة للإنتاج، أحد الخيارات التالية:

التنسيق الوصف
docker-archive أرشيف tar متوافق مع docker load(1) (الافتراضي)
oci-archive أرشيف tar باستخدام تنسيق صورة OCI
oci-dir دليل باستخدام تنسيق صورة OCI
docker-dir نقل dir (انظر containers-transports(5)) مع نوع manifest v2s2

--help, -h

طباعة بيان الاستخدام

--multi-image-archive, -m

السماح بإنشاء أرشيفات تحتوي على أكثر من صورة واحدة. يتم تفسير الأسماء الإضافية على أنها صور بدلاً من علامات. مدعوم فقط لـ --format=docker-archive. يمكن تعديل الافتراضي لهذه العلامة عبر علامة multi_image_archive="true"|"false" في containers.conf.

--output, -o=file

الكتابة إلى ملف، الافتراضي هو المخرج القياسي (STDOUT)

--quiet, -q

كتم الإخراج

--uncompressed

قبول الطبقات غير المضغوطة عند استخدام أحد تنسيقات OCI.

أمثلة

حفظ صورة في ملف محلي دون عرض التقدم.

$ podman save --quiet -o alpine.tar alpine:2.6

حفظ صورة إلى المخرج القياسي وإعادة توجيه المحتوى عبر الصدفة.

$ podman save alpine > alpine-all.tar

حفظ صورة بتنسيق oci-archive في الملف المحلي.

$ podman save -o oci-alpine.tar --format oci-archive alpine

حفظ صورة مضغوطة بتنسيق docker-dir.

$ podman save --compress --format docker-dir -o alp-dir alpine
