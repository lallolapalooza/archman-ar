powerprofilesctl(1)

الحزمة: power-profiles-daemon

التراخيص: GPL-3.0-only

POWERPROFILESCTL(1) برنامج التحكم في خدمات ملفات تعريف الطاقة POWERPROFILESCTL(1)

الاسم

powerprofilesctl - أداة سطر الأوامر للتحكم في خدمة ملفات تعريف الطاقة

الملخص

powerprofilesctl [-h] {list,list-holds,list-actions,get,set,configure-action,configure-battery-aware,query-battery-aware,launch,version} ...

المعاملات الموضعية

powerprofilesctl list

عرض ملفات تعريف الطاقة المتاحة

الاستخدام: powerprofilesctl list [-h]

powerprofilesctl list-holds

عرض الإيقافات الحالية لملف تعريف الطاقة

الاستخدام: powerprofilesctl list-holds [-h]

powerprofilesctl list-actions

عرض الإجراءات المتاحة لملف تعريف الطاقة

الاستخدام: powerprofilesctl list-actions [-h]

powerprofilesctl get

طباعة ملف تعريف الطاقة النشط حاليًا

الاستخدام: powerprofilesctl get [-h]

powerprofilesctl set

تعيين ملف تعريف الطاقة النشط حاليًا

الاستخدام: powerprofilesctl set [-h] {}

المعاملات:

{}
الملف الشخصي لاستخدامه في أمر `set`

powerprofilesctl configure-action

تكوين الإجراء الذي سيتم اتخاذه لملف التعريف

الاستخدام: powerprofilesctl configure-action [-h] [--enable] [--disable] action

المعاملات:

action
الإجراء المراد تغييره لـ configure-action

الخيارات:

--enable
تمكين الإجراء
--disable
تعطيل الإجراء

powerprofilesctl configure-battery-aware

تشغيل أو إيقاف التغييرات الديناميكية بناءً على مستوى البطارية أو محول الطاقة

الاستخدام: powerprofilesctl configure-battery-aware [-h] [--enable] [--disable]

الخيارات:

--enable
تمكين الوعي بالبطارية
--disable
تعطيل الوعي بالبطارية

powerprofilesctl query-battery-aware

الاستعلام عما إذا كانت التغييرات الديناميكية بناءً على مستوى البطارية أو محول الطاقة ممكّنة

الاستخدام: powerprofilesctl query-battery-aware [-h]

powerprofilesctl launch

تشغيل أمر مع الاحتفاظ بملف تعريف طاقة

الاستخدام: powerprofilesctl launch [-h] [--profile PROFILE] [--reason REASON]
[--appid APPID]
[arguments ...]

تشغيل الأمر مع الاحتفاظ بملف تعريف طاقة، إما ملف التعريف عالي الأداء، أو الملف الموفر للطاقة. افتراضيًا، الاحتفاظ بالملف الشخصي يكون للملف عالي الأداء، ولكنه قد لا يكون متاحًا على جميع الأنظمة. انظر الأمر `list` للحصول على قائمة بالملفات الشخصية المتاحة.

المعاملات:

arguments
الأمر المطلوب تشغيله

الخيارات:

--profile PROFILE, -p PROFILE
الملف الشخصي المراد استخدامه في أمر `launch`
--reason REASON, -r REASON
السبب المراد استخدامه في أمر `launch`
--appid APPID, -i APPID
معرف التطبيق المراد استخدامه في أمر `launch`

powerprofilesctl version

طباعة معلومات الإصدار والخروج

الاستخدام: powerprofilesctl version [-h]

تعليقات

استخدم “powerprofilesctl COMMAND --help” للحصول على مساعدة مفصلة للأوامر الفردية
