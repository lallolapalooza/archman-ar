podman-machine-os(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-machine-os(1) دليل الأوامر العامة podman-machine-os(1)

الاسم

podman-machine-os - إدارة نظام تشغيل جهاز Podman الافتراضي

الملخص

podman machine os أمر فرعي

الوصف

podman machine os هي مجموعة من الأوامر الفرعية التي تدير نظام تشغيل جهاز Podman الافتراضي.

الأوامر الفرعية

الأمر صفحة الدليل الوصف
apply podman-machine-os-apply(1) تطبيق صورة OCI على نظام تشغيل جهاز Podman

انظر أيضًا

podman(1)، podman-machine(1)، podman-machine-os-apply(1)
