podman-network-connect(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-network-connect(1) دليل الأوامر العامة podman-network-connect(1)

الاسم

podman network connect - توصيل حاوية بشبكة

الملخص

podman network connect [خيارات] شبكة حاوية

الوصف

يقوم بتوصيل حاوية بشبكة. يمكن توصيل حاوية بشبكة بالاسم أو المعرف. بمجرد الاتصال، يمكن للحاوية التواصل مع الحاويات الأخرى في نفس الشبكة.

الخيارات

--alias=name

إضافة اسم مستعار خاص بالشبكة للحاوية. إذا كانت الشبكة ممكّنة DNS (podman network inspect -f {{.DNSEnabled}} <NAME>)، فيمكن استخدام هذه الأسماء المستعارة لحل الأسماء على الشبكة المحددة. يمكن تحديد خيارات --alias متعددة كمدخلات. ملاحظة: عند استخدام CNI، لا يمكن للحاوية الوصول إلا إلى الأسماء المستعارة على الشبكة الأولى التي تنضم إليها. هذا القيد غير موجود مع netavark/aardvark-dns.

--ip=address

تعيين عنوان IPv4 ثابت لهذه الحاوية على هذه الشبكة.

--ip6=address

تعيين عنوان IPv6 ثابت لهذه الحاوية على هذه الشبكة.

--mac-address=address

تعيين عنوان MAC ثابت لهذه الحاوية على هذه الشبكة.

أمثلة

توصيل حاوية محددة بشبكة مسماة:

podman network connect test web

توصيل حاوية محددة بشبكة مسماة مع اسمين مستعارين:

podman network connect --alias web1 --alias web2 test web

توصيل حاوية محددة بشبكة مسماة مع عنوان IP ثابت:

podman network connect --ip 10.89.1.13 test web

توصيل حاوية محددة بشبكة مسماة مع عنوان MAC ثابت:

podman network connect --mac-address 92:d0:c6:0a:29:33 test web
