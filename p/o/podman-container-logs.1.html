podman-container-logs(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-logs(1) دليل الأوامر العامة podman-logs(1)

الاسم

podman logs - عرض سجلات حاوية أو أكثر

الصيغة

podman logs [خيارات] حاوية [حاوية...]

podman container logs [خيارات] حاوية [حاوية...]

الوصف

يقوم أمر podman logs باسترداد مجمع لأي سجلات موجودة لحاوية أو أكثر في وقت التنفيذ. هذا لا يضمن ترتيب التنفيذ عند دمجه مع podman run (أي، قد لا يكون الأمر run قد أنتج أي سجلات في الوقت الذي تم فيه تنفيذ podman logs).

الخيارات

--color

إخراج الحاويات بألوان مختلفة في السجل.

--follow, -f

متابعة إخراج السجل. القيمة الافتراضية هي false.

ملاحظة: عند متابعة حاوية يتم إزالتها بواسطة podman container rm أو إزالتها عند الخروج (podman run --rm ...)، هناك احتمال أن تتم إزالة ملف السجل قبل أن يقرأ podman logs المحتوى النهائي.

--latest, -l

بدلاً من توفير اسم الحاوية أو معرفها، استخدم آخر حاوية تم إنشاؤها. ملاحظة: يمكن أن تكون آخر حاوية تم تشغيلها من قبل مستخدمين آخرين لـ Podman على الجهاز المضيف. (هذا الخيار غير متاح مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

--names, -n

إخراج أسماء الحاويات بدلاً من معرفات الحاويات في السجل.

--since=TIMESTAMP

عرض السجلات منذ TIMESTAMP. يمكن أن يكون الخيار --since طوابع زمنية Unix، أو طوابع زمنية بتنسيق التاريخ، أو سلاسل مدة Go (مثل 10m، 1h30m) يتم حسابها بالنسبة لوقت الجهاز العميل. تشمل التنسيقات المدعومة للطوابع الزمنية بتنسيق التاريخ RFC3339Nano، RFC3339، 2006-01-02T15:04:05، 2006-01-02T15:04:05.999999999، 2006-01-02Z07:00، و 2006-01-02.

--tail=LINES

إخراج العدد المحدد من LINES في نهاية السجلات. يجب أن تكون LINES عددًا صحيحًا. القيمة الافتراضية هي -1، والتي تطبع جميع الأسطر

--timestamps, -t

عرض الطوابع الزمنية في مخرجات السجل. القيمة الافتراضية هي false

--until=TIMESTAMP

عرض السجلات حتى TIMESTAMP. يمكن أن يكون الخيار --until طوابع زمنية Unix، أو طوابع زمنية بتنسيق التاريخ، أو سلاسل مدة Go (مثل 10m، 1h30m) يتم حسابها بالنسبة لوقت الجهاز العميل. تشمل التنسيقات المدعومة للطوابع الزمنية بتنسيق التاريخ RFC3339Nano، RFC3339، 2006-01-02T15:04:05، 2006-01-02T15:04:05.999999999، 2006-01-02Z07:00، و 2006-01-02.

podman-container-logs.1

Name
podman-container-logs - Fetch the logs of a container

Synopsis
podman container logs [options] CONTAINER

Description
The podman container logs command retrieves the logs from a container. The logs can be retrieved in plain text or JSON format. If the container is running, the logs are streamed in real-time. Options: -a, --all display all logs. By default, only the last 8KiB of logs are displayed. -f, --follow follow log output. This is the default for running containers. -n, --lines uint Show the last NUM lines of logs (default 8192). --since timestamp limit logs since a specific timestamp. The timestamp is a date-time string like 2023-01-01T10:00:00Z, or a relative duration like 2h, 5m, 10s. --tail uint Show the last NUM lines of logs (default is 8192). -t, --timestamps enable timestamps. The timestamps are displayed in RFC3339Nano format. Examples: podman container logs mycontainer podman container logs --follow mycontainer podman container logs --tail 100 mycontainer podman container logs --since 10m mycontainer podman container logs --timestamps mycontainer

podman container logs - جلب سجلات حاوية

المتغير
podman container logs [خيارات] CONTAINER

الوصف
يقوم أمر podman container logs بجلب السجلات من حاوية. يمكن استرجاع السجلات بتنسيق نص عادي أو JSON. إذا كانت الحاوية قيد التشغيل، يتم بث السجلات في الوقت الفعلي. الخيارات: -a, --all عرض جميع السجلات. افتراضيًا، يتم عرض آخر 8 كيلوبايت من السجلات فقط. -f, --follow متابعة إخراج السجلات. هذا هو الافتراضي للحاويات قيد التشغيل. -n, --lines uint عرض آخر NUM سطر من السجلات (الافتراضي 8192). --since timestamp تحديد السجلات منذ وقت محدد. الطابع الزمني هو سلسلة نصية للتاريخ والوقت مثل 2023-01-01T10:00:00Z، أو مدة نسبية مثل 2h، 5m، 10s. --tail uint عرض آخر NUM سطر من السجلات (الافتراضي هو 8192). -t, --timestamps تمكين الطوابع الزمنية. يتم عرض الطوابع الزمنية بتنسيق RFC3339Nano. أمثلة: podman container logs mycontainer podman container logs --follow mycontainer podman container logs --tail 100 mycontainer podman container logs --since 10m mycontainer podman container logs --timestamps mycontainer
