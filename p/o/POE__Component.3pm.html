POE__Component(3pm)

الحزمة: perl-poe

التراخيص: GPL, PerlArtistic

POE::Component(3) وثائق Perl المساهمة من قبل المستخدم POE::Component(3)

الاسم

POE::Component - كائنات موجهة بالأحداث أو أنظمة فرعية

الملخص

انظر المكونات المحددة.

الوصف

تُعد "مكونات" POE وحدات موجهة بالأحداث تغلف بشكل عام ميزات البرنامج متوسطة إلى عالية المستوى. على سبيل المثال، يقوم POE::Component::Client::DNS بإجراء عمليات بحث غير متزامنة للمحللات بناءً على الرسائل. POE::Component::Server::TCP هو خادم شبكة غير متزامن أساسي.

تم إنشاء مساحة اسم POE::Component كمكان للمساهمين لنشر وحداتهم القائمة على POE دون الحاجة إلى التنسيق مع التوزيع الرئيسي لـ POE. تسبق المساحة اسم الاتفاقية -X، وإلا كنت ستقرأ عن POEx بدلاً من ذلك.

كما هو الحال مع العديد من الأشياء في Perl، هناك أكثر من طريقة لتنفيذ واجهات المكونات. تعرض المكونات الأحدث واجهات كائنية التوجه، والبعض الآخر يستخدم Moose، ولكن الأقدم منها يعتمد على الرسائل فقط.

المكونات كائنية التوجه

إحدى الطرق لإنشاء مكونات كائنية التوجه هي تضمين مثيل POE::Session داخل كائن. يتم ذلك عن طريق إنشاء الجلسة أثناء مُنشئ الكائن، وتعيين اسم المستعار للجلسة لشيء فريد، وحفظ نسخة من الاسم المستعار في الكائن.

package Asynchrotron;
my $alias_index = 0;
sub new {
  my $class = shift;
  my $self = bless {
    alias => __PACKAGE__ . " " . ++$alias_index;
  }, $class;
  POE::Session->create(
    object_states => [
      $self => {
        _start       => "_poe_start",
        do_something => "_poe_do_something",
      },
    ],
  );
  return $self;
}
sub _poe_start {
  $_[KERNEL]->alias_set($_[OBJECT]->{alias});
}

يسمح الاسم المستعار لطرق الكائن بتمرير الأحداث إلى الجلسة دون الحاجة إلى تخزين شيء ما عن الجلسة. تنقل الدالة call() الخاصة بـ POE::Kernel التنفيذ من سياق الجلسة المستدعية إلى جلسة المكون.

sub do_something {
  my $self = shift;
  print "Inside the caller's session right now: @_\n";
  $poe_kernel->call($self->{alias}, "do_something", @_);
}
sub _poe_do_something {
  my @args = @_[ARG0..$#_];
  print "Inside the component's session now: @args\n";
  $_[OBJECT]{count}++;
}

كل من $_[HEAP] و $_[OBJECT] مرئيان داخل جلسة المكون. يمكن استخدام $_[HEAP] للتغليف الخاص للغاية، بينما يمكن استخدام $_[OBJECT] للبيانات المرئية بواسطة الملحقات.

sub get_count {
  my $self = shift;
  return $self->{count}; # $_[OBJECT]{count} above
}

قد تؤدي كثرة الجلسات إلى إبطاء إنشاء الكائنات وتدميرها، لذا تجنب إنشائها لكل كائن.

انظر أيضًا

يحتوي قسم SEE ALSO في POE على جدول محتويات يغطي توزيع POE بأكمله.

POE::Stage هو مشروع ناشئ لتوحيد مكونات POE، وجعل POE::Kernel أكثر كائنية التوجه، وتوفير سكر مرئي ودلالي للعديد من جوانب تطوير POE::Component الشائعة. كما أنه أسهل في الكتابة. يرجى استكشاف المشروع. الأفكار والمساهمات الصغيرة مطلوبة بشدة للمساعدة في إطلاق المشروع.

قيد التنفيذ

توثيق العملية المعتادة (ولكن ليست إلزامية!) لإنشاء ونشر مكون.

المؤلفون وحقوق النشر

يرجى الاطلاع على POE لمزيد من المعلومات حول المؤلفين والمساهمين.
