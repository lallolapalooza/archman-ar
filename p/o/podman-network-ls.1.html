podman-network-ls(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-network-ls(1) دليل الأوامر العامة podman-network-ls(1)

الاسم

podman network ls - عرض ملخص للشبكات

الموجز

podman network ls [خيارات]

الوصف

يعرض قائمة بالشبكات الموجودة في podman.

الخيارات

--filter, -f=مرشح=قيمة

تقديم قيم المرشحات.

صيغة الوسيط filters هي مفتاح=قيمة. إذا كان هناك أكثر من مرشح واحد، فمرر خيارات متعددة: --filter foo=bar --filter bif=baz.

المرشحات المدعومة:

المرشح الوصف
driver الترشيح حسب نوع المشغل.
id الترشيح حسب معرف الشبكة الكامل أو الجزئي.
label الترشيح حسب الشبكات التي تحتوي (أو لا تحتوي، في حالة استخدام label!=[...]) على الملصقات المحددة.
name الترشيح حسب اسم الشبكة (يقبل التعبيرات النمطية).
until الترشيح حسب الشبكات التي تم إنشاؤها قبل الطابع الزمني المحدد.
dangling الترشيح حسب الشبكات التي لا توجد بها حاويات مرفقة.

يقبل مرشح driver القيم: bridge، macvlan، ipvlan.

يقبل مرشح label صيغتين. الأولى هي label=مفتاح أو label=مفتاح=قيمة، والتي تعرض الصور بالملصقات المحددة. الصيغة الأخرى هي label!=مفتاح أو label!=مفتاح=قيمة، والتي تعرض الصور بدون الملصقات المحددة.

يمكن لمرشح until أن يكون طوابع زمنية Unix، أو طوابع زمنية منسقة بتاريخ، أو سلاسل مدة Go (مثل 10m، 1h30m) محسوبة بالنسبة لوقت الجهاز.

يقبل مرشح dangling القيم true أو false.

--format=تنسيق

تغيير صيغة الإخراج الافتراضية. يمكن أن يكون هذا من نوع مدعوم مثل 'json' أو قالب Go. الأماكن النائبة الصالحة لقالب Go مدرجة أدناه:

المكان النائب الوصف
.Created ... الطابع الزمني لإنشاء الشبكة
.DNSEnabled الشبكة لديها DNS ممكّن (قيمة منطقية)
.Driver مشغل الشبكة
.ID معرف الشبكة
.Internal الشبكة داخلية (قيمة منطقية)
.IPAMOptions ... خيارات IPAM للشبكة
.IPv6Enabled الشبكة لديها نطاق IPv6 فرعي (قيمة منطقية)
.Labels ملصقات الشبكة
.Name اسم الشبكة
.NetworkDNSServers مصفوفة خوادم DNS المستخدمة في هذه الشبكة
.NetworkInterface اسم واجهة الشبكة على المضيف
.Options ... خيارات الشبكة
.Routes قائمة الطرق الثابتة لهذه الشبكة
.Subnets قائمة النطاقات الفرعية على هذه الشبكة

--no-trunc

لا تقطع معرف الشبكة.

--noheading, -n

استبعاد عناوين الجدول من القائمة.

--quiet, -q

يقيد خيار quiet الإخراج ليقتصر على أسماء الشبكات فقط.

مثال

عرض الشبكات:

$ podman network ls
NETWORK ID    NAME         DRIVER
88a7120ee19d  podman       bridge
6dd508dbf8cd  podman6  bridge
8e35c2cd3bf6  podman5  macvlan

عرض أسماء الشبكات فقط:

$ podman network ls -q
podman
podman2
outside
podman9

عرض اسم الشبكة التي تدعم مكون bridge الإضافي:

$ podman network ls --filter driver=bridge --format {{.Name}}
podman
podman2
podman9

قائمة الشبكات مع نطاقاتها الفرعية:

$ podman network ls --format "{{.Name}}: {{range .Subnets}}{{.Subnet}} {{end}}"
podman: 10.88.0.0/16
podman3: 10.89.30.0/24 fde4:f86f:4aab:e68f::/64
macvlan:
