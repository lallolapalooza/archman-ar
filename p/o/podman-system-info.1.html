podman-system-info(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-info(1) دليل الأوامر العامة podman-info(1)

الاسم

podman-info - عرض معلومات متعلقة بـ Podman

الاستخدام

podman info [خيارات]

podman system info [خيارات]

الوصف

يعرض معلومات خاصة بالمضيف، وإحصاءات التخزين الحالية، وسجلات حاويات البرامج المكونة، وبنية Podman.

الخيارات

--format, -f=format

تغيير تنسيق الإخراج إلى "json" أو قالب Go.

العنصر النائب معلومات تتعلق بـ ...
.Host ... ...المضيف الذي يعمل عليه Podman
.Plugins ... ...الإضافات الخارجية
.Registries ... ...السجلات المكونة
.Store ... ...مشغل التخزين والمسارات
.Version ... ...إصدار Podman

يتفرع كل مما سبق إلى مجالات فرعية إضافية، أكثر مما يمكن سرده بشكل معقول في هذا المستند.

استخراج قائمة مسجلات الحاويات باستخدام قالب Go

إذا كان إكمال الأوامر النصية ممكّنًا، اكتب podman info --format={{. ثم اضغط على [TAB] مرتين.

$ podman info --format={{.
{{.Host.         {{.Plugins.      {{.Registries}}  {{.Store.        {{.Version.

اضغط على R [TAB] [ENTER] لطباعة معلومات المسجلات.

$ podman info -f {{.Registries}}
map[search:[registry.fedoraproject.org registry.access.redhat.com docker.io quay.io]]
$

لا يزال الإخراج يحتوي على خريطة ومصفوفة. يمكن استخراج قيمة الخريطة باستخدام

$ podman info -f '{{index .Registries "search"}}'
[registry.fedoraproject.org registry.access.redhat.com docker.io quay.io]

يمكن طباعة المصفوفة كمدخل واحد في كل سطر

$ podman info -f '{{range index .Registries "search"}}{{.}}\n{{end}}'
registry.fedoraproject.org
registry.access.redhat.com
docker.io
quay.io

استخراج قائمة مسجلات الحاويات من JSON باستخدام jq

يمكن استخدام معالج JSON سطر الأوامر jq لاستخراج قائمة مسجلات الحاويات.

$ podman info -f json | jq '.registries["search"]'
[
  "registry.fedoraproject.org",
  "registry.access.redhat.com",
  "docker.io",
  "quay.io"
]

يمكن طباعة المصفوفة كمدخل واحد في كل سطر

$ podman info -f json | jq -r '.registries["search"] | .[]'
registry.fedoraproject.org
registry.access.redhat.com
docker.io
quay.io

لاحظ أن حقول هياكل قالب Go تبدأ بحروف كبيرة. عند تشغيل podman info أو podman info --format=json، تبدأ نفس الأسماء بحروف صغيرة.
