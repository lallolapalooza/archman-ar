podman-system-events(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-events(1) دليل الأوامر العامة podman-events(1)

الاسم

podman-events - مراقبة أحداث Podman

الملخص

podman events [خيارات]

podman system events [خيارات]

الوصف

مراقبة وطباعة الأحداث التي تحدث في Podman. كل حدث يتضمن طابعًا زمنيًا، نوعًا، حالة، اسمًا (إن وجد)، وصورة (إن وجدت). آلية التسجيل الافتراضية هي journald. يمكن تغيير ذلك في containers.conf عن طريق تغيير قيمة events_logger إلى file. فقط file و journald مقبولان. يتوفر أيضًا مسجل none، ولكنه يعطل الأحداث تمامًا؛ لا يتم الإبلاغ عن أي شيء بواسطة podman events.

بشكل افتراضي، يتم استخدام وضع التدفق، وطباعة الأحداث الجديدة فور حدوثها. يمكن سرد الأحداث السابقة عبر --since و --until.

نوع الحدث container يبلغ عن الحالات التالية:
* attach
* checkpoint
* cleanup
* commit
* connect
* create
* died
* disconnect
* exec
* exec_died
* exited
* export
* import
* init
* kill
* mount
* pause
* prune
* remove
* rename
* restart
* restore
* start
* stop
* sync
* unmount
* unpause
* update

نوع الحدث pod يبلغ عن الحالات التالية:
* create
* kill
* pause
* remove
* start
* stop
* unpause

نوع الحدث image يبلغ عن الحالات التالية:
* loadFromArchive,
* mount
* pull
* pull-error
* push
* remove
* save
* tag
* unmount
* untag

النوع system يبلغ عن الحالات التالية:
* refresh
* renumber

النوع volume يبلغ عن الحالات التالية:
* create
* prune
* remove

النوع secret يبلغ عن الحالات التالية:
* create
* remove

أحداث إنشاء مفصلة

ضبط events_container_create_inspect_data=true في containers.conf(5) يوجه Podman لإنشاء أحداث إنشاء حاويات أكثر تفصيلاً تتضمن حمولة JSON بمعلومات مفصلة حول الحاويات. حمولة JSON متطابقة مع حمولة podman-container-inspect(1). الحقل المرتبط في journald يسمى PODMAN_CONTAINER_INSPECT_DATA.

خيارات

--filter, -f=مرشح

تصفية الأحداث التي يتم عرضها. يجب أن تكون بالتنسيق "مرشح=قيمة". المرشحات التالية مدعومة:

مرشح الوصف
container [الاسم أو المعرف] اسم أو معرف الحاوية
event event_status (موضح أعلاه)
image [الاسم أو المعرف] اسم أو معرف الصورة
label [مفتاح] أو [مفتاح=قيمة] تسمية
pod [الاسم أو المعرف] اسم أو معرف الـ pod
volume [الاسم أو المعرف] اسم أو معرف المجلد (volume)
type Event_type (موضح أعلاه)

في حالة استخدام معرف، قد يكون المعرف بشكله الكامل أو المختصر. يتم ربط الحدث "die" بـ "died" للتوافق مع Docker.

--format

تنسيق الإخراج إلى JSON Lines أو باستخدام قالب Go المحدد.

عنصر نائب الوصف
.Attributes ... created_at, _by, labels, والمزيد (map[])
.ContainerExitCode رمز الخروج (int)
.ContainerInspectData حمولة فحص الحاوية
.Error رسالة خطأ في حالة كون حالة الحدث خطأ (مثل pull-error)
.HealthStatus حالة الصحة (string)
.ID معرف الحاوية (SHA كامل 64 بت)
.Image اسم الصورة التي يتم تشغيلها (string)
.Name اسم الحاوية (string)
.Network اسم الشبكة المستخدمة (string)
.PodID معرف الـ pod المرتبط بالحاوية، إن وجد
.Status حالة الحدث (مثل create, start, died, ...)
.Time الطابع الزمني للحدث (string)
.TimeNano الطابع الزمني للحدث بدقة النانو ثانية (int64)
.Type نوع الحدث (مثل image, container, pod, ...)

--help

طباعة بيان الاستخدام.

--no-trunc

عدم اقتطاع الإخراج (الافتراضي true).

--since=الطابع الزمني

عرض جميع الأحداث التي تم إنشاؤها منذ الطابع الزمني المحدد

--stream

تدفق الأحداث وعدم الخروج بعد قراءة آخر حدث معروف (الافتراضي true).

--until=الطابع الزمني

عرض جميع الأحداث التي تم إنشاؤها حتى الطابع الزمني المحدد

يمكن أن تكون قيم since و until طوابع زمنية RFC3339Nano أو سلسلة مدة Go مثل 10m، 5h. إذا لم يتم توفير أي قيم since أو until، يتم عرض الأحداث الجديدة فقط.

معرفات JOURNALD

يستخدم backend الأحداث journald الخاص بـ Podman معرفات journald التالية. يمكنك استخدام المعرفات لتصفية أحداث Podman مباشرة باستخدام journalctl.

المعرف الوصف
SYSLOG_IDENTIFIER يتم تعيينه دائمًا على "podman"
PODMAN_EVENT حالة الحدث كما هو موضح أعلاه
PODMAN_TYPE نوع الحدث كما هو موضح أعلاه
PODMAN_TIME الطابع الزمني عند كتابة الحدث
PODMAN_NAME اسم كائن الحدث (مثل حاوية، صورة)
PODMAN_ID معرف كائن الحدث (مثل حاوية، صورة)
PODMAN_EXIT_CODE رمز خروج الحاوية
PODMAN_POD_ID معرف الـ pod الخاص بالحاوية
PODMAN_LABELS تسميات الحاوية
PODMAN_HEALTH_STATUS حالة صحة الحاوية
PODMAN_CONTAINER_INSPECT_DATA حمولة JSON لـ podman-inspect كما هو موضح أعلاه
PODMAN_NETWORK_NAME اسم الشبكة

عرض أحداث إنشاء حاويات Podman فقط:

الاسم

podman-system-events - عرض أحداث Podman

ملخص

podman system events [options]

الوصف

يعرض الأمر podman system events سجل الأحداث للعمليات التي تم إنشاؤها بواسطة Podman. يمكن تصفية الأحداث حسب نوع الحدث (مثل حاوية أو pod) أو حسب اسم الوحدة.

خيارات

--filter=type
قم بتصفية الأحداث حسب النوع. الأنواع الصالحة هي: container، image، pod، volume، network.
--since=timestamp
عرض الأحداث التي وقعت بعد الطابع الزمني المحدد. يمكن أن يكون الطابع الزمني قيمة نسبية (مثل 5m لـ 5 دقائق) أو طابع زمني مطلق.
--until=timestamp
عرض الأحداث التي وقعت قبل الطابع الزمني المحدد. يمكن أن يكون الطابع الزمني قيمة نسبية (مثل 5m لـ 5 دقائق) أو طابع زمني مطلق.
--format=format
تنسيق الإخراج. يمكن أن يكون json أو قالب go. الافتراضي هو نص عادي.
-i, --stream
تدفق الأحداث في الوقت الفعلي.

معرفات Journald

إذا تم تمكين journald، يتم تسجيل أحداث Podman في journald. يمكن استخدام معرفات journald التالية لتصفية الأحداث:

CONTAINER_NAME
اسم الحاوية.
POD_NAME
اسم الـ pod.
IMAGE_NAME
اسم الصورة.
VOLUME_NAME
اسم وحدة التخزين.
