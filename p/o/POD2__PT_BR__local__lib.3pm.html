الحزمة: perl-local-lib

التراخيص: PerlArtistic, GPL

POD2::PT_BR::local::lib(3) وثائق مستخدم مقدمة من Perl POD2::PT_BR::local::lib(3)

الاسم

local::lib~[pt_br] - أنشئ واستخدم دليل lib/ محلي لوحدات Perl باستخدام PERL5LIB

الملخص

في الكود -

use local::lib; # إعداد lib محلي في ~/perl5
use local::lib '~/foo'; # نفس الشيء، ولكن ~/foo
# أو...
use FindBin;
use local::lib "$FindBin::Bin/../suporte";  # مكتبات دعم محلية للتطبيق

من سطر الأوامر (shell) -

# تثبيت LWP واعتماداته التي لم يتم العثور عليها في دليل '~/perl5'
perl -MCPAN -Mlocal::lib -e 'CPAN::install(LWP)'
# عرض بعض الأوامر المفيدة لـ shell فقط
$ perl -Mlocal::lib
export PERL_MB_OPT='--install_base /home/username/perl5'
export PERL_MM_OPT='INSTALL_BASE=/home/username/perl5'
export PERL5LIB='/home/username/perl5/lib/perl5/i386-linux:/home/username/perl5/lib/perl5'
export PATH="/home/username/perl5/bin:$PATH"

تقنية 'التمهيد'

طريقة شائعة لتثبيت local::lib هي باستخدام ما يعرف بتقنية "التمهيد". إنها مقاربة جيدة إذا لم يكن مسؤول النظام قد قام بتثبيت local::lib. في هذه الحالة، ستحتاج إلى تثبيت local::lib في دليل المستخدم الخاص بك.

إذا كانت لديك صلاحيات إدارية، فستظل بحاجة إلى تكوين متغيرات البيئة الخاصة بك، كما هو موضح في الخطوة 4، أدناه. بدونها، ستظل تقوم بتثبيت الوحدات في CPAN الخاص بالنظام ولن تستخدم نصوص Perl الخاصة بك المسار إلى lib/ الذي حددته باستخدام local::lib.

بشكل افتراضي، يقوم local::lib بتثبيت وحدات CPAN ونفسه في ~/perl5.

يجب على مستخدمي Windows قراءة "الاختلافات عند استخدام هذه الوحدة على Win32".

1. قم بتنزيل وفك ضغط local::lib من CPAN (ابحث عن "Download" في صفحة CPAN الخاصة بـ local::lib). قم بذلك كمستخدم عادي، وليس كـ root أو مسؤول. قم بفك ضغط الملف في دليل المستخدم الخاص بك أو في أي مكان مناسب آخر.

2. قم بتشغيل هذا:

perl Makefile.PL --bootstrap

إذا سأل النظام عما إذا كان يجب تكوين كل شيء يمكن تكوينه تلقائيًا، فمن المحتمل أن تجيب بنعم (yes).

لتثبيت local::lib في دليل غير افتراضي، ستحتاج إلى تحديده عند استدعاء التمهيد، على النحو التالي:

perl Makefile.PL --bootstrap=~/foo

3. قم بتشغيل هذا: (يفترض local::lib أن لديك أمر 'make' مثبتًا على نظامك)

make test && make install

4. الآن نحتاج إلى تكوين متغيرات البيئة المناسبة حتى يستخدم Perl دليل lib/ الذي تم إنشاؤه حديثًا. إذا كنت تستخدم bash أو shell Bourne أخرى، يمكنك القيام بذلك عن طريق إضافة السطر التالي إلى نص تهيئة shell الخاص بك:

echo 'eval $(perl -I$HOME/perl5/lib/perl5 -Mlocal::lib)' >>~/.bashrc

إذا كنت تستخدم shell C، يمكنك القيام بذلك على النحو التالي:

/bin/csh
echo $SHELL
/bin/csh
perl -I$HOME/perl5/lib/perl5 -Mlocal::lib >> ~/.cshrc

إذا قمت بتمرير دليل غير افتراضي إلى التمهيد، فستحتاج إلى تحديده في استدعاء local::lib، على هذا النحو:

echo 'eval $(perl -I$HOME/foo/lib/perl5 -Mlocal::lib=$HOME/foo)' >>~/.bashrc

بعد تحديث ملف تكوين shell الخاص بك، تأكد من معالجته مرة أخرى للحصول على التغييرات في shell الحالي الخاص بك. تستخدم shells Bourne ". ~/.bashrc" لهذا الغرض، بينما تستخدم shells C "source ~/.cshrc".

إذا كنت على جهاز بطيء أو تعمل بقيود مساحة قرص كبيرة، يمكنك تعطيل الإنشاء التلقائي لصفحات الدليل من POD عند تثبيت الوحدات. للقيام بذلك، فقط قم بتمرير الوسيط "--no-manpages" أثناء التمهيد:

perl Makefile.PL --bootstrap --no-manpages

لتجنب الاضطرار إلى إجراء العديد من عمليات التمهيد لبيئات وحدات Perl مختلفة في نفس حساب المستخدم - على سبيل المثال، إذا كنت تستخدم local::lib لتطوير تطبيقات مستقلة مختلفة - يمكنك استخدام تثبيت تمهيد واحد لـ local::lib لتثبيت الوحدات في أدلة مختلفة على النحو التالي:

cd ~/meudir1
perl -Mlocal::lib=./
eval $(perl -Mlocal::lib=./)  ### لتهيئة البيئة في shell هذه فقط
printenv                      ### لاحظ أن ~/meudir1 موجود في PERL5LIB
perl -MCPAN -e install ...    ### أي وحدات تريدها
cd ../meudir2
... كرر ...

لبيئات متعددة مخصصة لتطبيقات متعددة، قد تحتاج إلى تضمين إصدار معدل من تعليمات "use FindBin" في المثال "في الكود" أعلاه. إذا قمت بشيء مثل ما هو موضح أعلاه، فستكون لديك مجموعة من وحدات Perl في "~/meudir1/lib". إذا كان لديك نص برمجي في "~/meudir1/scripts/meuscript.pl"، فستحتاج إلى إخباره بمكان العثور على الوحدات التي قمت بتثبيتها له في "~/meudir1/lib".

في "~/meudir1/scripts/meuscript.pl":

use strict;
use warnings;
use local::lib "$FindBin::Bin/..";  ### يشير إلى ~/meudir1 و local::lib تجد lib/
use lib "$FindBin::Bin/../lib";     ### يشير إلى ~/meudir1/lib

ضع هذا قبل أي كتلة BEGIN { ... } تحتاج إلى الوحدات المثبتة.

الاختلافات عند استخدام هذه الوحدة على Win32

لتهيئة متغيرات البيئة المناسبة لجلسة "CMD.exe" الحالية الخاصة بك، يمكنك القيام بذلك على النحو التالي:

C:\>perl -Mlocal::lib
set PERL_MB_OPT=--install_base C:\DOCUME~1\ADMINI~1\perl5
set PERL_MM_OPT=INSTALL_BASE=C:\DOCUME~1\ADMINI~1\perl5
set PERL5LIB=C:\DOCUME~1\ADMINI~1\perl5\lib\perl5;C:\DOCUME~1\ADMINI~1\perl5\lib\perl5\MSWin32-x86-multi-thread
set PATH=C:\DOCUME~1\ADMINI~1\perl5\bin;%PATH%
### لتهيئة البيئة في shell هذه فقط
C:\>perl -Mlocal::lib > %TEMP%\tmp.bat && %TEMP%\tmp.bat && del %TEMP%\temp.bat
### بدلاً من $(perl -Mlocal::lib=./)

إذا كنت ترغب في أن تكون إعدادات البيئة دائمة، فستحتاج إلى إضافتها في لوحة التحكم -> النظام، أو استخدام App::local::lib::Win32Helper.

يتم تحويل "~" إلى دليل ملف تعريف المستخدم (الدليل باسم المستخدم داخل "Documents and Settings" (Windows XP أو أقدم) أو "Users" (Windows Vista والأحدث)) ما لم يكن $ENV{HOME} موجودًا. بعد ذلك، يتم تقصير اسم الدليل وإنشاء الأدلة الفرعية (مما يعني أن الدليل يجب أن يكون موجودًا).

LIMITAÇÕES

As ferramentas auxiliares do perl não conseguem lidar com nomes de diretórios contendo espaços, então não é possível fazer seu bootstrap do local::lib em um diretório com espaços. O que você pode fazer é mover seu local::lib para um diretório com espaços após ter instalado todos os módulos dentro dele. Mas esteja ciente que você não poderá atualizar ou instalar outros módulos do CPAN nesse diretório local após a mudança.

A detecção da shell é relativamente básica. Neste momento, qualquer coisa com csh no nome será tratada como a C shell ou compatível, e todo o resto será tratado como Bourne, exceto em sistemas Win32. Caso a variável de ambiente "SHELL" não esteja disponível, assumiremos tratar-se de uma shell compatível com a Bourne.

A técnica de bootstrap é um hack e usará o CPAN.pm para o ExtUtils::MakeMaker mesmo que você tenha o CPANPLUS instalado.

Destrói qualquer valor pré-existente nas variáveis de ambiente PERL5LIB, PERL_MM_OPT e PERL_MB_OPT.

Provavelmente deveria auto-configurar o CPAN caso isso ainda não tenha sido feito.

Correções (patches) são muito bem-vindos para quaisquer dos itens acima.

Em sistemas Win32, não há uma forma de escrever no registro as variáveis de ambiente criadas, para que elas persistam a uma reinicialização.

SOLUÇÃO DE PROBLEMAS

Se você configurou o local::lib para instalar módulos do CPAN em algum lugar do seu 'home', e mais tarde tentou instalar um módulo fazendo "cpan -i Foo::Bar", mas ele falhou com um erro como: "Warning: You do not have permissions to install into /usr/lib64/perl5/site_perl/5.8.8/x86_64-linux at /usr/lib64/perl5/5.8.8/Foo/Bar.pm" e em algum lugar no seu log de instalação houver um erro dizendo "'INSTALL_BASE' is not a known MakeMaker parameter name", então você de alguma forma perdeu seu ExtUtils::MakeMaker atualizado.

Para remediar a situação, execute novamente o procedimento de bootstrap descrito acima.

Então, execute "rm -r ~/.cpan/build/Foo-Bar*"

Finalmente, execute novamente o "cpan -i Foo::Bar" e ele deve instalar sem problemas.

AMBIENTE

SHELL
COMSPEC
O local::lib procura pela variável de ambiente "SHELL" do usuário ao processar e exibir os comandos a serem adicionados no arquivo de configuração da shell.

Em sistemas Win32, "COMSPEC" também será examinado.
