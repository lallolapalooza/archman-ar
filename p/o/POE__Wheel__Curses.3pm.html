POE__Wheel__Curses(3pm)

الحزمة: perl-poe

التراخيص: GPL, PerlArtistic

POE::Wheel::Curses(3) وثائق Perl من مساهمة المستخدم POE::Wheel::Curses(3)

الاسم

POE::Wheel::Curses - إدخال غير حاجب للنوافذ

الملخص

use Curses;
use POE qw(Wheel::Curses);
POE::Session->create(
  inline_states => {
    _start => sub {
      $_[HEAP]{console} = POE::Wheel::Curses->new(
        InputEvent => 'got_keystroke',
      );
    },
    got_keystroke => sub {
      my $keystroke = $_[ARG0];
      # اجعل المفاتيح التحكمية والموسعة قابلة للطباعة.
      if ($keystroke lt ' ') {
        $keystroke = '<' . uc(unctrl($keystroke)) . '>';
      }
      elsif ($keystroke =~ /^\d{2,}$/) {
        $keystroke = '<' . uc(keyname($keystroke)) . '>';
      }
      # فقط اعرضها.
      addstr($keystroke);
      noutrefresh();
      doupdate;
      # يجب الخروج بطريقة ما.
      delete $_[HEAP]{console} if $keystroke eq "<^C>";
    },
  }
);
POE::Kernel->run();
exit;

الوصف

POE::Wheel::Curses ينفذ إدخالًا غير حاجب لبرامج Curses.

سيقوم POE::Wheel::Curses بإصدار "InputEvent" من اختيارك كلما تم تسجيل حدث إدخال على جهاز إدخال معروف (لوحة المفاتيح وأحيانًا الفأرة، اعتمادًا على مكتبة curses). وفي الوقت نفسه، يمكن للتطبيقات القيام بأشياء أخرى مثل مراقبة اتصالات الشبكة أو العمليات الفرعية، أو إدارة المؤقتات وما شابه.

الطرق العامة

POE::Wheel::Curses بسيط للغاية.

جديد

new() ينشئ كائن POE::Wheel::Curses جديدًا. أثناء البناء، تسجل العجلة مراقب إدخال لـ STDIN (عبر select_read()) وتسجل معالجًا داخليًا لمعالجة ضغطات المفاتيح.

new() تقبل معلمة واحدة فقط "InputEvent". "InputEvent" تحتوي على اسم الحدث الذي ستصدره العجلة كلما كان هناك إدخال على وحدة التحكم أو الطرفية. كما هو الحال مع جميع العجلات، سيتم إرسال الحدث إلى الجلسة التي كانت نشطة عند بناء العجلة.

تجدر الإشارة إلى أن التطبيق قد يكون لديه كائن POE::Wheel::Curses نشط واحد فقط.

الأحداث والمعلمات

هذه هي الأحداث التي يرسلها POE::Wheel::Curses.

InputEvent

"InputEvent" يحدد الحدث الذي سيتم إصداره عندما يكتشف POE::Wheel::Curses إدخال وحدة التحكم ويقرأه. يتضمن هذا الحدث معلمتين:

$_[ARG0] تحتوي على ضغطة المفتاح الخام كما تلقاها Curses::getch(). قد يقوم التطبيق بمعالجة ضغطة المفتاح باستخدام Curses::unctrl() و Curses::keyname() على ضغطة المفتاح.

$_[ARG1] تحتوي على معرف كائن POE::Wheel::Curses.

أحداث الفأرة ليست محمولة. اعتبارًا من أكتوبر 2009، يعود الأمر للتطبيق لتحديد ما إذا كان سيتم استدعاء mousemask().

انظر أيضاً

توثق Curses ما يمكن فعله باستخدام Curses. انظر أيضًا صفحة الدليل لأي إصدار من libcurses مثبت (curses، ncurses، إلخ).

POE::Wheel يصف العجلات بشكل عام.

قسم SEE ALSO في POE يحتوي على جدول محتويات يغطي توزيع POE بأكمله.

الأخطاء

لا توجد أخطاء معروفة، على الرغم من أن تطبيقات curses تختلف على نطاق واسع.
