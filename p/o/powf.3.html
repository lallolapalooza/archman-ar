powf(3) - صفحة الدليل

الاسم

powf - دالة رفع عدد عشري إلى قوة عدد عشري

الملخص

#include <math.h>

float powf(float base, float exponent);

الوصف

تُرجع الدالة powf القيمة base مرفوعة إلى الأس exponent.

المعاملات

  • base: الأساس.
  • exponent: الأس.

قيمة الإرجاع

تُرجع الدالة powf القيمة baseexponent. في حالة حدوث خطأ، تُرجع NaN ويتم تعيين errno بشكل مناسب.

الأخطاء

  • EDOM: إذا كان base سالبًا وكان exponent ليس عددًا صحيحًا.
  • ERANGE: إذا كانت النتيجة كبيرة جدًا بحيث لا يمكن تمثيلها.

أمثلة

```c #include #include int main() { float base = 2.0f; float exponent = 3.0f; float result = powf(base, exponent); printf("%.2f^%.2f = %.2f\n", base, exponent, result); // Output: 2.00^3.00 = 8.00 return 0; } ```

السمات

للحصول على معلومات حول خصائص هذه الدوال، راجع attributes(7).

المعايير

تمت مطابقة هذه الدوال مع C99.

التاريخ

تمت إضافة هذه الدوال في GCC 4.0.

الأخطاء

لا توجد أخطاء معروفة حاليًا.
