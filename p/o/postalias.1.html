NAME

postalias

postalias - create/update/query Postfix alias database

SYNOPSIS

    postalias [-c config_dir] [-i] [-l] [-n] [-N] [-q name] [-q name@domain] [-R] [-r] [-v] [filename...]

DESCRIPTION

The postalias command is a utility for creating and updating Postfix lookup tables, typically used for the alias database. It reads text input, converts it into a binary indexed file format, and stores the result in the location specified by the alias database parameter.

The command takes zero or more filenames as arguments. If no filenames are specified, postalias reads from standard input. The input format is text lines, one alias per line, in the form:

    name: recipient1, recipient2, ...

Whitespace surrounding the name and the recipients is ignored. Names are case-insensitive. Recipients are case-sensitive.

When postalias is run without the -q option, it expects to build or update a database. It will first create a temporary database file in the same directory as the final database, then copy the temporary file to the final destination. This ensures that the database is always in a consistent state.

If the alias database is specified as a text file (e.g., /etc/aliases), postalias will first process the text file and then call newaliases to build the database.

The default location for the alias database is specified by the alias_database parameter.

OPTIONS

-c config_dir
Use the Postfix configuration file specified in config_dir. If this option is not specified, the default configuration directory (usually /etc/postfix) is used.
-i
When processing multiple input files, or when reading from standard input after processing files, this option causes the existing database to be overwritten rather than appended to. Use with caution.
-l
Append the results of the specified input files to the existing alias database. This is the default behavior when no -i or -q option is specified.
-n
Do not update the alias database. This option is useful for checking the syntax of an alias file without actually modifying the database.
-N
Do not create the alias database if it does not exist. The command will exit with an error if the database file is not found.
-q name
-q name@domain
Query the alias database for the specified name. postalias will print the corresponding recipient list to standard output, or nothing if the name is not found. This option implies -n.
-R
Treat the alias name as a fully qualified domain name. This option is rarely needed.
-r
Treat the alias name as a fully qualified domain name. This option is rarely needed.
-v
Enable verbose logging. This option is useful for debugging.

DIAGNOSTICS

The command exits with status 0 on success, or 1 on error.

ENVIRONMENT

MAIL_CONFIG
Directory with Postfix configuration files.
MAIL_VERBOSE
Enable verbose logging for debugging purposes.

CONFIGURATION PARAMETERS

The following main.cf parameters are especially relevant to this program.

The text below provides only a parameter summary. See postconf(5) for more details including examples.

alias_database (see 'postconf -d' output)
The alias databases for local(8) delivery that are updated with "newaliases" or with "sendmail -bi".
config_directory (see 'postconf -d' output)
The default location of the Postfix main.cf and master.cf configuration files.
berkeley_db_create_buffer_size (16777216)
The per-table I/O buffer size for programs that create Berkeley DB hash or btree tables.
berkeley_db_read_buffer_size (131072)
The per-table I/O buffer size for programs that read Berkeley DB hash or btree tables.
default_database_type (see 'postconf -d' output)
The default database type for use in newaliases(1), postalias(1) and postmap(1) commands.
import_environment (see 'postconf -d' output)
The list of environment variables that a privileged Postfix process will import from a non-Postfix parent process, or name=value environment overrides.
smtputf8_enable (yes)
Enable preliminary SMTPUTF8 support for the protocols described in RFC 6531, RFC 6532, and RFC 6533.
syslog_facility (mail)
The syslog facility of Postfix logging.
syslog_name (see 'postconf -d' output)
A prefix that is prepended to the process name in syslog records, so that, for example, "smtpd" becomes "prefix/smtpd".

Available in Postfix 2.11 and later:

lmdb_map_size (16777216)
The initial OpenLDAP LMDB database size limit in bytes.
