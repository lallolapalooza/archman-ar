NAME

popen, pclose - start a process pipeline

SYNOPSIS

#include <stdio.h>
FILE *popen(const char *command, const char *type);
int pclose(FILE *stream);

DESCRIPTION

The popen() function shall open a process pipe. By the argument command, it shall create a new process that has a pipe with either the calling process or the process described by the argument command. The argument type is a string which is either the literal "r" or "w". If type is "r", then the file pointer returned by popen() is connected to the standard output of the process described by command. If type is "w", then the file pointer returned by popen() is connected to the standard input of the process described by command.

The pclose() function shall close the pipe created by a previous call to popen() and return the status of the command interpreter.

RETURN VALUE

On success, popen() returns a pointer to a buffered stream associated with one end of a pipe. On error, it returns a NULL pointer.

If stream is a NULL pointer, pclose() returns -1. Otherwise, pclose() returns the termination status of the process associated with stream. This status is in the same format as that returned by waitpid(). If the status is unavailable (e.g., the child process died from a signal), the return value is undefined.

ERRORS

The popen() function may fail if:

ECHILD
No child processes.
EMFILE
Too many currently open file descriptors.
ENOMEM
Insufficient memory available.
ENOSPC
A file system is full.
ENOTTY
The file command refers to is not a regular file.
ENOENT
The specified command or shell does not exist.
ETIMEDOUT
A connection timed out.
EACCES
Search permission is denied for a component of the path prefix of the file specified by command.
