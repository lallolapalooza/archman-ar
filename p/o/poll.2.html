">

قيمة الإرجاع

عند النجاح، تعيد الدالة poll() قيمة غير سالبة تمثل عدد العناصر في pollfds التي تم تعيين حقول revents الخاصة بها إلى قيمة غير صفرية (مما يشير إلى حدث أو خطأ). تشير قيمة إرجاع صفر إلى أن استدعاء النظام قد انتهت مهلته قبل أن تصبح أي واصفات ملف جاهزة.

عند حدوث خطأ، يتم إرجاع -1، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

EFAULT
fds تشير خارج مساحة العنوان التي يمكن الوصول إليها للعملية. المصفوفة المعطاة كوسيط لم تكن ضمن مساحة عنوان برنامج الاستدعاء.
EINTR
حدثت إشارة قبل أي حدث مطلوب؛ انظر signal(7).
EINVAL
قيمة nfds تتجاوز قيمة RLIMIT_NOFILE.
EINVAL
(ppoll()) قيمة المهلة المعبر عنها في *tmo_p غير صالحة (سالبة).
ENOMEM
فشل في تخصيص ذاكرة لهياكل بيانات النواة.

الإصدارات

في بعض أنظمة UNIX الأخرى، يمكن أن تفشل الدالة poll() مع الخطأ EAGAIN إذا فشل النظام في تخصيص موارد داخلية للنواة، بدلاً من ENOMEM كما تفعل Linux. يسمح POSIX بهذا السلوك. قد يرغب المستخدمون الذين يكتبون برامج محمولة في التحقق من EAGAIN والتكرار، تمامًا كما هو الحال مع EINTR.

تعرّف بعض التطبيقات الثابتة غير القياسية INFTIM بقيمة -1 لاستخدامها كـ timeout للدالة poll(). هذه الثابتة غير متوفرة في glibc.

الاختلافات بين مكتبة C والنواة

استدعاء نظام Linux ppoll() يعدل وسيط tmo_p الخاص به. ومع ذلك، تخفي دالة الغلاف glibc هذا السلوك باستخدام متغير محلي لوسيط المهلة الذي يتم تمريره إلى استدعاء النظام. وبالتالي، فإن دالة glibc ppoll() لا تعدل وسيط tmo_p الخاص بها.

لدى استدعاء نظام ppoll() الخام وسيط خامس، size_t sigsetsize، الذي يحدد حجم sigmask بالبايت. تحدد دالة الغلاف glibc ppoll() هذا الوسيط كقيمة ثابتة (تساوي sizeof(kernel_sigset_t)). انظر sigprocmask(2) لمناقشة الاختلافات بين مفهوم النواة ومفهوم libc لمجموعة الإشارات.

المعايير

POSIX.1-2024.

التاريخ

ملاحظات

لا يتأثر تشغيل poll() و ppoll() بالعلم O_NONBLOCK.

لمناقشة ما قد يحدث إذا تم إغلاق واصف ملف تتم مراقبته بواسطة poll() في مؤشر ترابط آخر، انظر select(2).

الأخطاء

انظر مناقشة الإشعارات الزائفة بالجاهزية تحت قسم الأخطاء في select(2).

أمثلة

يفتح البرنامج أدناه كل ملف مسمى في وسائط سطر الأوامر الخاص به ويراقب واصفات الملفات الناتجة من أجل الاستعداد للقراءة (POLLIN). يتكرر البرنامج، مستخدمًا poll() بشكل متكرر لمراقبة واصفات الملفات، ويطبع عدد واصفات الملفات الجاهزة عند الإرجاع. لكل واصف ملف جاهز، يقوم البرنامج:

•
يعرض حقل revents المُرجع بشكل يمكن للبشر قراءته؛
•
إذا كان واصف الملف قابلاً للقراءة، يقرأ بعض البيانات منه، ويعرض تلك البيانات على الإخراج القياسي؛ و
•
إذا لم يكن واصف الملف قابلاً للقراءة، ولكن حدث حدث آخر (يفترض أن يكون POLLHUP)، يقوم بإغلاق واصف الملف.

لنفترض أننا قمنا بتشغيل البرنامج في طرفية واحدة، طالبين منه فتح أنبوب FIFO:


$ mkfifo myfifo;
$ ./poll_input myfifo;

في نافذة طرفية ثانية، نقوم بفتح FIFO للكتابة، نكتب بعض البيانات إليه، ثم نغلق FIFO:


$ echo aaaaabbbbbccccc > myfifo;

في الطرفية التي نقوم بتشغيل البرنامج فيها، سنرى عندها:


Opened "myfifo" on fd 3
About to poll()
Ready: 1
  fd=3; events: POLLIN POLLHUP
    read 10 bytes: aaaaabbbbb
About to poll()
Ready: 1
  fd=3; events: POLLIN POLLHUP
    read 6 bytes: ccccc
About to poll()
Ready: 1
  fd=3; events: POLLHUP
    closing fd 3
All file descriptors closed.  Bye.

في الإخراج أعلاه، نرى أن poll() قد عادت ثلاث مرات:

•
عند الإرجاع الأول، كانت البتات التي تم إرجاعها في حقل revents هي POLLIN، مما يشير إلى أن واصف الملف قابل للقراءة، و POLLHUP، مما يشير إلى أن الطرف الآخر من FIFO قد تم إغلاقه. استهلك البرنامج بعد ذلك بعض المدخلات المتاحة.
•
الإرجاع الثاني من poll() أشار أيضًا إلى POLLIN و POLLHUP؛ استهلك البرنامج بعد ذلك آخر المدخلات المتاحة.
•
عند الإرجاع النهائي، أشار poll() فقط إلى POLLHUP على FIFO، عند هذه النقطة تم إغلاق واصف الملف وانتهى البرنامج.

مصدر البرنامج

/* poll_input.c
   Licensed under GNU General Public License v2 or later.
*/
#include <err.h>
#include <fcntl.h>
#include <poll.h>
#include <stdio.h>
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
int
main(int argc, char *argv[])
{
    int            ready;
    char           buf[10];
    nfds_t         num_open_fds, nfds;
    ssize_t        s;
    struct pollfd  *pfds;
    if (argc < 2) {
       fprintf(stderr, "Usage: %s file...\n", argv[0]);
       exit(EXIT_FAILURE);
    }
    num_open_fds = nfds = argc - 1;
    pfds = calloc(nfds, sizeof(struct pollfd));
    if (pfds == NULL)
        err(EXIT_FAILURE, "malloc");
    /* Open each file on command line, and add it to 'pfds' array.  */
    for (nfds_t j = 0; j < nfds; j++) {
        pfds[j].fd = open(argv[j + 1], O_RDONLY);
        if (pfds[j].fd == -1)
            err(EXIT_FAILURE, "open");
        printf("Opened \"%s\" on fd %d\n", argv[j + 1], pfds[j].fd);
        pfds[j].events = POLLIN;
    }
    /* Keep calling poll() as long as at least one file descriptor is
       open.  */
    while (num_open_fds > 0) {
        printf("About to poll()\n");
        ready = poll(pfds, nfds, -1);
        if (ready == -1)
            err(EXIT_FAILURE, "poll");
        printf("Ready: %d\n", ready);
        /* Deal with array returned by poll().  */
        for (nfds_t j = 0; j < nfds; j++) {
            if (pfds[j].revents != 0) {
                printf("  fd=%d; events: %s%s%s\n", pfds[j].fd,
                       (pfds[j].revents & POLLIN)  ? "POLLIN "  : "",
                       (pfds[j].revents & POLLHUP) ? "POLLHUP " : "",
                       (pfds[j].revents & POLLERR) ? "POLLERR " : "");
                if (pfds[j].revents & POLLIN) {
                    s = read(pfds[j].fd, buf, sizeof(buf));
                    if (s == -1)
                        err(EXIT_FAILURE, "read");
                    printf("    read %zd bytes: %.*s\n",
                           s, (int) s, buf);
                } else {                /* POLLERR | POLLHUP */
                    printf("    closing fd %d\n", pfds[j].fd);
                    if (close(pfds[j].fd) == -1)
                        err(EXIT_FAILURE, "close");
                    num_open_fds--;
                }
            }
        }
    }
    printf("All file descriptors closed.  Bye.\n");
    exit(EXIT_SUCCESS);
}

NAME

poll - synchronous I/O multiplexing

SYNOPSIS

#include <poll.h>

int poll(struct pollfd fds[], nfds_t nfds, int timeout);

DESCRIPTION

The poll() system call is a way to multiplex input/output operations on multiple file descriptors, all at the same time, without having to write custom code to deal with each of them separately. This is useful when you have a number of I/O channels and you want to wait until any one of them is ready for some kind of I/O (either reading or writing).

The first argument, fds, is a pointer to an array of struct pollfd structures. This array describes the file descriptors to be monitored. The second argument, nfds, is the number of elements in the fds array.

The struct pollfd is defined as:

   typedef struct {
       int   fd;         /* file descriptor to monitor */
       short events;     /* events of interest */
       short revents;    /* events that actually occurred */
   } pollfd;

The fd member contains the file descriptor number. A value of -1 in fd is ignored.

The events member is a bitmask indicating the type of events the user is interested in monitoring for the given file descriptor. The possible events are:

POLLIN
There is data to be read.
POLLPRI
There is urgent data to be read.
POLLOUT
Writing is possible.
POLLERR
An error has occurred on the specified file descriptor.
POLLHUP
Hangup of a device or stream.
POLLNVAL
The specified file descriptor is invalid.

The revents member is filled in by the kernel with the events that actually occurred for the file descriptor. The user should not set this member.

The timeout argument specifies the number of milliseconds to wait for an event. A value of -1 means wait indefinitely. A value of 0 means return immediately (poll will not block). A positive value means poll will block for at most that many milliseconds.

poll() returns the number of file descriptors in the fds array that have been triggered (i.e., for which revents is non-zero). If the timeout expires, poll() returns 0.

If poll() is interrupted by a signal, it returns -1 and sets errno to EINTR.

The nfds argument is of type nfds_t, which is an unsigned integer type. It specifies the number of elements in the fds array. The system should support a value of at least FD_SETSIZE.

The POLLIN, POLLPRI, POLLOUT, POLLERR, POLLHUP, and POLLNVAL flags are defined in <poll.h>.

The POLLRDNORM flag is the same as POLLIN. The POLLWRNORM flag is the same as POLLOUT.

The POLLRDHUP flag indicates that a peer has performed an orderly shutdown of the connection.

The POLLMSG flag indicates that a message is available on a message queue.

The poll() function shall monitor each file descriptor specified in the array of pollfd structures pointed to by the fds argument for the occurrence of any of the event flags specified in the events member of the structure.

If the timeout argument is greater than zero, the call will block until at least one of the specified events occurs for any of the monitored file descriptors, or until the time limit expires.

If the timeout argument is zero, the call will return immediately.

If the timeout argument is -1, the call will block indefinitely until at least one of the specified events occurs for any of the monitored file descriptors.

If the poll() call returns due to the timeout expiring, no events are pending, and the value returned is 0.

If the poll() call returns because one or more of the specified events has occurred, the value returned is the number of file descriptors for which events have occurred. The revents member of the corresponding pollfd structures are set to indicate the events that occurred.

If an error occurs on a file descriptor, the POLLERR event shall be set in the revents member for that file descriptor. If a hangup occurs on a file descriptor, the POLLHUP event shall be set in the revents member for that file descriptor. If the file descriptor is invalid, the POLLNVAL event shall be set in the revents member for that file descriptor.

If poll() is interrupted by a signal, it returns -1 and sets errno to EINTR.

RETURN VALUE

On success, poll() returns a non-negative value indicating the number of file descriptors for which events have occurred. This value can be 0 if the timeout expired. On error, poll() returns -1 and sets errno to indicate the error.

ERRORS

EBADF
An invalid file descriptor was given in the array pointed to by fds.
EINTR
A signal was caught before any of the specified events occurred.
EINVAL
The nfds argument is negative, or the timeout argument is negative and not -1.
ENOMEM
Insufficient memory to allocate internal data structures.

VERSIONS

The poll() system call was introduced in Linux kernel 2.5.44.

STANDARDS

POSIX.1-2008

HISTORY

The poll() system call is a replacement for select() and was introduced in POSIX.1-2001.

NOTES

The maximum number of file descriptors that can be monitored by poll() is determined by the system limit on the number of open file descriptors per process. This limit can be checked using ulimit -n.

The timeout argument is specified in milliseconds. If the timeout is very long, it may be rounded up to the nearest second by the kernel.

The POLLERR, POLLHUP, and POLLNVAL events are always reported, regardless of the events requested by the user. If any of these events are set in revents, the corresponding events field can be ignored.

It is possible for poll() to return with a non-zero return value, but with all revents fields still zero. This can happen if the timeout expires while poll() is in progress.

BUGS

None known.

EXAMPLES

The following example demonstrates how to use poll() to wait for data on standard input:

#include <stdio.h>
#include <poll.h>
#include <unistd.h>

int main(void) {
    struct pollfd fds[1];
    char buf[100];
    int ret;

    /* Watch stdin for input */
    fds[0].fd = STDIN_FILENO;
    fds[0].events = POLLIN;

    /* Wait for stdin to be ready, with a timeout of 5 seconds */
    ret = poll(fds, 1, 5000);

    if (ret == -1) {
        perror("poll");
        return 1;
    } else if (ret == 0) {
        printf("Timeout occurred after 5 seconds\n");
        return 0;
    }

    /* Data is available on stdin */
    if (fds[0].revents & POLLIN) {
        int n = read(STDIN_FILENO, buf, sizeof(buf) - 1);
        if (n > 0) {
            buf[n] = '\0';
            printf("Read from stdin: %s\n", buf);
        } else if (n == 0) {
            printf("End of file on stdin\n");
        } else {
            perror("read");
            return 1;
        }
    }

    return 0;
}
