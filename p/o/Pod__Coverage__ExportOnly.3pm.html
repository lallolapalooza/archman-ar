Pod__Coverage__ExportOnly(3pm)

الحزمة: perl-pod-coverage

التراخيص: GPL, PerlArtistic

Pod::Coverage::ExportOnly(3) وثائق Perl التي ساهم بها المستخدم Pod::Coverage::ExportOnly(3)

الاسم

Pod::Coverage::ExportOnly - فئة فرعية من Pod::Coverage تفحص فقط الوظائف المصدرة

الملخص

# كلها في استدعاء واحد
use Pod::Coverage::ExportOnly package => 'Fishy';
# كائنية بحتة
use Pod::Coverage::ExportOnly;
my $pc = new Pod::Coverage::ExportOnly package => 'Pod::Coverage';
print "We rock!" if $pc->coverage == 1;

الوصف

تمدد هذه الوحدة Pod::Coverage لفحص الأشياء التي تم إعدادها صراحة للتصدير بواسطة وحدات Exporter أو UNIVERSAL::exports. إذا كنت تريد توثيقًا كاملاً، نقترح عليك التحقق من وثائق Pod::Coverage

انظر أيضًا

Pod::Coverage, Exporter, UNIVERSAL::exports
