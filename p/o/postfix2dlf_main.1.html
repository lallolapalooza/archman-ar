postfix2dlf_main(1)

الحزمة: lire

التراخيص: GPL-2.0-only

POSTFIX2DLF_MAIN.IN(1) وثائق Lire لـ LogReport POSTFIX2DLF_MAIN.IN(1)

الاسم

postfix2dlf_main - تحويل إخراج postfix2dlf_pre إلى بريد إلكتروني dlf

الملخص

postfix2dlf_main dumpfile

الوصف

يتوقع postfix2dlf_main ملف سجل postfix معالج مسبقًا، كما هو مكتوب بواسطة postfix2dlf_pre(1) على STDIN. يقوم بطباعة ملف DLF لبريد Lire على stdout، باستخدام قاعدة بيانات Berkeley في dumpfile، والتي تحتوي على تعيين من hostname-queueid إلى عدد الأسطر بهذا المعرف.

المطورون

الهياكل البيانية هي نفسها تلك الموجودة في sendmail2dlf.

%msg يخزن جميع المعلومات قيد المعالجة حاليًا من السجل. في sendmail2dlf، يتم فهرسة هذه الهاش بواسطة معرفات dlf:

$dlfid = $log->{'hostname'} . $log->{'queueid'}

. في postfix2dlf نستخدم فقط معرف قائمة الانتظار، في الوقت الحالي.

قيم القياسية:

$msg{$dlfid} = {
  logrelay        => ...,
  queueid         => ...,
  time            => ...,
  nrcpts          => ...,
  from_user       => ...,
  from_domain     => ...,
  from_relay_host => ...,
  from_relay_ip   => ...,
  size            => ...,
  msgid           => ...,
};

علاوة على ذلك:

$del = $msg{$dlfid}->{deliveries}{$to};

$to هو عنوان بريد إلكتروني كما تم إرجاعه بواسطة &Lire::Email::sanitize_tos.

$del->{to_user}   = ....;
$del->{to_domain} = ....;

مفاتيح $del أخرى بقيم قياسية:

to_relay_host
to_relay_ip
delay
xdelay
stat
xstat

.

غالبًا ما يتم تعيين المرجع الهاش $msg{$dlfid} إلى `$cur'.

أمثلة

من النادر استخدام postfix2dlf_main بمفرده: يتم استدعاؤه بواسطة postfix2dlf(1). راجع صفحة دليل postfix2dlf للحصول على أمثلة ومعلومات الاستخدام.

انظر أيضًا

postfix2dlf(1)، postfix2dlf_pre(1)، sendmail2dlf(1)
