الحزمة: podman

التراخيص: Apache-2.0

podman-ps(1) دليل الأوامر العامة podman-ps(1)

الاسم

podman-ps - طباعة معلومات عن الحاويات

ملخص

podman ps [خيارات]

podman container ps [خيارات]

podman container list [خيارات]

podman container ls [خيارات]

الوصف

podman ps تسرد الحاويات قيد التشغيل على النظام. استخدم العلامة --all لعرض معلومات جميع الحاويات. افتراضيًا، تعرض:

  • معرف الحاوية
  • اسم الصورة التي تستخدمها الحاوية
  • الأمر الذي تنفذه الحاوية
  • الوقت الذي تم فيه إنشاء الحاوية
  • حالة الحاوية
  • تخطيطات المنافذ التي تستخدمها الحاوية
  • أسماء بديلة للحاوية

الخيارات

--all, -a

عرض جميع الحاويات، الافتراضي هو الحاويات قيد التشغيل فقط.

ملاحظة: يتشارك Podman تخزين الحاويات مع أدوات أخرى مثل Buildah و CRI-O. في بعض الحالات، قد توجد هذه الحاويات الخارجية أيضًا في نفس التخزين. استخدم الخيار --external لرؤية هذه الحاويات الخارجية. تعرض الحاويات الخارجية حالة 'التخزين'.

--external

عرض الحاويات الخارجية التي لا يتحكم فيها Podman ولكنها مخزنة في تخزين الحاويات. يتم إنشاء هذه الحاويات الخارجية بشكل عام عبر تقنيات حاويات أخرى مثل Buildah أو CRI-O وقد تعتمد على نفس صور الحاويات التي يستخدمها Podman أيضًا. يتم تمييز الحاويات الخارجية إما بـ 'buildah' أو 'storage' في عمود الأمر (COMMAND) والحالة (STATUS) في مخرجات ps.

--filter, -f

تصفية الحاويات التي يتم عرضها في المخرجات. يمكن تقديم عوامل تصفية متعددة باستخدام استدعاءات متعددة لـ --filter. تعمل عوامل التصفية بنفس المفتاح بشكل شامل مع الاستثناء الوحيد هو label وهو حصري. تعمل عوامل التصفية بمفاتيح مختلفة دائمًا بشكل حصري.

عوامل التصفية الصالحة مدرجة أدناه:

عامل التصفية الوصف
id [معرف] معرف الحاوية (مطابقة بادئة CID افتراضيًا؛ تقبل التعبيرات العادية)
name [الاسم] اسم الحاوية (تقبل التعبيرات العادية)
label [المفتاح] أو [المفتاح=القيمة] التسمية المعينة للحاوية
label! [المفتاح] أو [المفتاح=القيمة] التسمية غير المعينة للحاوية
exited [عدد صحيح] رمز خروج الحاوية
status [الحالة] حالة الحاوية: 'created'، 'initialized'، 'exited'، 'paused'، 'running'، 'unknown'
ancestor [اسم الصورة] الصورة أو النسلة المستخدمة لإنشاء الحاوية (تقبل التعبيرات العادية)
before [المعرف] أو [الاسم] الحاويات التي تم إنشاؤها قبل هذه الحاوية
since [المعرف] أو [الاسم] الحاويات التي تم إنشاؤها منذ هذه الحاوية
volume [اسم الحجم] أو [نقطة تحميل الجهاز] الحجم المحمل في الحاوية
health [الحالة] صحي أو غير صحي
pod [البود] اسم البود أو معرفه الكامل أو الجزئي
network [الشبكة] اسم الشبكة أو معرفها الكامل
until [وقت/تاريخ] حاوية تم إنشاؤها قبل المدة أو الوقت المحدد.
command [الأمر] الأمر الذي تنفذه الحاوية، يتم أخذ argv[0] فقط

--format=format

تنسيق جميل للحاويات بتنسيق JSON أو باستخدام قالب Go

العناصر النائبة الصالحة لقالب Go مدرجة أدناه:

العنصر النائب الوصف
.AutoRemove إذا كان صحيحًا، تتم إزالة الحاويات عند الخروج
.CIDFile ملف معرف الحاوية
.Command الأمر المقتبس المستخدم
.Created ... وقت إنشاء الحاوية، السنة-الشهر-اليوم الساعة:الدقيقة:الثانية
.CreatedAt وقت إنشاء الحاوية (نفس ما سبق)
.CreatedHuman وقت الإنشاء، نسبي
.ExitCode رمز خروج الحاوية
.Exited "true" إذا كانت الحاوية قد خرجت
.ExitedAt وقت خروج الحاوية (ثواني الحقبة)
.ExposedPorts ... خريطة المنافذ المعروضة على هذه الحاوية
.ID معرف الحاوية
.Image اسم/معرف الصورة
.ImageID معرف الصورة
.IsInfra "true" إذا كانت حاوية البنية التحتية
.Label string التسمية المحددة للحاوية
.Labels ... جميع التسميات المعينة للحاوية
.Mounts الأحجام المحملة في الحاوية
.Names اسم الحاوية
.Networks عرض جميع الشبكات المتصلة بالحاوية
.Pid معرف العملية على نظام المضيف
.Pod البود الذي ترتبط به الحاوية (SHA)
.PodName اسم البود للحاوية
.Ports المنافذ المعاد توجيهها والمعروضة
.Restarts عرض عدد مرات إعادة تشغيل الحاوية
.RunningFor الوقت المنقضي منذ بدء تشغيل الحاوية
.Size حجم الحاوية
.StartedAt وقت بدء تشغيل الحاوية (ثواني الحقبة)
.State وصف ودود لحالة الحاوية
.Status حالة الحاوية

--help, -h

طباعة بيان الاستخدام

--last, -n

طباعة آخر n حاوية تم إنشاؤها (جميع الحالات)

--latest, -l

عرض أحدث حاوية تم إنشاؤها (جميع الحالات) (هذا الخيار غير متوفر مع عميل Podman البعيد، بما في ذلك أجهزة Mac و Windows (باستثناء WSL2))

--namespace, --ns

عرض معلومات مساحة الأسماء

--no-trunc

لا تقم باقتطاع المخرجات (الافتراضي false).

--noheading

تجاهل رؤوس الجدول من قائمة الحاويات.

--pod, -p

عرض البودات التي ترتبط بها الحاويات

--quiet, -q

طباعة معرفات الحاويات الرقمية فقط

--size, -s

عرض الحجم الكلي للملف

--sort=created

الفرز حسب الأمر، تم الإنشاء، المعرف، الصورة، الأسماء، التشغيل، الحجم، أو الحالة". ملاحظة: يؤدي اختيار الحجم إلى الفرز حسب حجم نظام الملفات الجذر، وليس أبجديًا مثل بقية الخيارات

--sync

فرض مزامنة حالة الحاوية مع وقت تشغيل OCI. في بعض الحالات، قد تصبح حالة الحاوية في وقت التشغيل غير متزامنة مع حالة Podman. يقوم هذا بتحديث حالة Podman بناءً على ما يبلغه وقت تشغيل OCI. المزامنة القسرية أبطأ بكثير، ولكنها يمكن أن تحل مشاكل الحالة غير المتناسقة.

--watch, -w

تحديث المخرجات بالحاويات الحالية على فترات زمنية بالثواني.

أمثلة

قائمة الحاويات قيد التشغيل.

$ podman ps
معرف الحاوية  الصورة                            الأمر                تم الإنشاء            الحالة                 المنافذ                                                 الأسماء
4089df24d

الاسم

podman-container-list - سرد حاويات Podman

الملخص

podman container list [options]

podman ps [options]

الوصف

تسرد الأوامر podman container list و podman ps الحاويات التي تم إنشاؤها بواسطة Podman.

يتم عرض قائمة الحاويات افتراضيًا. يتم عرض الحاويات النشطة فقط.

# podman ps
CONTAINER ID  IMAGE       COMMAND     CREATED     STATUS      PORTS     NAMES
f7d4028125c5  redis:alpine  redis-server  25 hours ago  Up 25 hours ago  6379/tcp  redis-container

يمكنك عرض جميع الحاويات، بما في ذلك تلك التي تم إيقافها، باستخدام الخيار -a أو --all.

# podman ps -a
CONTAINER ID  IMAGE       COMMAND     CREATED     STATUS                    PORTS     NAMES
f7d4028125c5  redis:alpine  redis-server  25 hours ago  Up 25 hours ago  6379/tcp  redis-container
a247b15f309b  alpine:latest  sleep 100   27 hours ago  Exited (0) 27 hours ago            my-container

الخيارات

--all, -a

يسرد جميع الحاويات، بما في ذلك الحاويات التي تم إيقافها.

--cancel

في حالة استخدام podman ps -a، قم بإلغاء قائمة حاويات المكونات الخارجية.

--cert-dir=/path/to/directory

يحتوي على ملفات شهادات mTLS.

--cid-file=""

اسم ملف لكتابة معرف الحاوية الأول.

--cidfile=""

اسم ملف لكتابة معرف الحاوية الأول.

--filter=condition, -f=condition

قم بتصفية إخراج الحاويات. يتوفر عامل التصفية التالي:

ancestor=image

سرد الحاويات المستندة إلى صورة أو حاوية معينة.

created=date

سرد الحاويات التي تم إنشاؤها بعد أو في وقت معين.

exit_code=integer

سرد الحاويات التي انتهت برمز الخروج المحدد.

expose=port

سرد الحاويات التي تم الكشف عن المنفذ المحدد لها.

health=state

سرد الحاويات التي تكون حالتها الصحية state.

id=ID

سرد الحاويات ذات المعرف المحدد.

is-volume=true|false

سرد وحدات التخزين المرتبطة بالحاويات.

label=label

سرد الحاويات ذات التسمية المحددة.

name=name

سرد الحاويات ذات الاسم المحدد.

network=network

سرد الحاويات المتصلة بالشبكة المحددة.

pod=pod

سرد الحاويات الموجودة في الجراب المحدد.

status=status

سرد الحاويات ذات الحالة المحددة.

volume=volume

سرد الحاويات التي تستخدم وحدة التخزين المحددة.

format=format

استخدم تنسيق Go لإنشاء عرض فريد لمعرفات الحاويات.

latest, -l

عرض الحاوية الأخيرة.

no-trunc

لا تقم باقتطاع معرفات الحاويات الطويلة.

namespace, --ns

عرض مساحات أسماء الحاويات.

pod

عرض المعلومات المتعلقة بالجراب.

quiet, -q

عرض معرفات الحاويات فقط.

size, -s

عرض الحجم الإجمالي لوحدات التخزين للحاويات.

sort=key

قم بفرز الإخراج. المفتاح الافتراضي هو created. يمكن استخدام المفاتيح التالية: size، names، id، image، command، created، status، ports.

--external

عرض الحاويات الخارجية التي تم إنشاؤها بواسطة أدوات بخلاف Podman.

أمثلة

عرض الحاويات النشطة.

$ podman ps
CONTAINER ID  IMAGE       COMMAND     CREATED     STATUS      PORTS     NAMES
f7d4028125c5  redis:alpine  redis-server  25 hours ago  Up 25 hours ago  6379/tcp  redis-container

عرض جميع الحاويات (نشطة أو غير نشطة).

$ podman ps -a

f7d4028125c5  redis:alpine  redis-server  25 hours ago  Up 25 hours ago  6379/tcp  redis-container

عرض جميع الحاويات بما في ذلك حجمها. ملاحظة: قد يستغرق هذا وقتًا أطول لأن Podman يحتاج إلى حساب الحجم من نظام الملفات.

$ podman ps -a -s
