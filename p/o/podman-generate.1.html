podman-generate(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-generate(1) دليل الأوامر العامة podman-generate(1)

الاسم

podman-generate - إنشاء بيانات منظمة بناءً على الحاويات أو البودات أو وحدات التخزين

الملخص

podman generate subcommand

الوصف

يقوم أمر الإنشاء بإنشاء مخرجات منظمة (مثل YAML) بناءً على حاوية أو بود أو وحدة تخزين.

الأوامر

الأمر صفحة الدليل الوصف
kube podman-kube-generate(1) إنشاء YAML Kubernetes بناءً على الحاويات أو البودات أو وحدات التخزين.
spec podman-generate-spec(1) إنشاء JSON Specgen بناءً على الحاويات أو البودات.
systemd podman-generate-systemd(1) [تم إيقافه] إنشاء ملف (ملفات) وحدة systemd لحاوية أو بود.

انظر أيضًا

podman(1), podman-pod(1), podman-container(1)
