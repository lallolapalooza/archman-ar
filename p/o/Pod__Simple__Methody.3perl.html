Pod::Simple::Methody(3perl) دليل مبرمجي بيرل Pod::Simple::Methody(3perl)

الاسم

Pod::Simple::Methody -- تحويل أحداث Pod::Simple إلى استدعاءات للدوال

الملخص

require 5;
use strict;
package SomePodFormatter;
use base qw(Pod::Simple::Methody);
sub handle_text {
  my($self, $text) = @_;
  ...
}
sub start_head1 {
  my($self, $attrs) = @_;
  ...
}
sub end_head1 {
  my($self) = @_;
  ...
}

... ودوال `start_` و `end_` لأي أحداث أخرى تريد التقاطها.

الوصف

هذه الفئة تهم الأشخاص الذين يكتبون منسقي Pod بناءً على Pod::Simple.

هذه الفئة (وهي صغيرة جدًا - اقرأ المصدر) تتجاوز دوال `_handle_element_start` و `_handle_text` و `_handle_element_end` الخاصة بـ Pod::Simple بحيث يتم تحويل أحداث المحلل إلى استدعاءات للدوال. (بخلاف ذلك، هذه الفئة فرعية من Pod::Simple وترث جميع دوالها).

يمكنك استخدام هذه الفئة كأساس لمنسق/معالج Pod.

استدعاء الدوال

عندما يرى Pod::Simple على سبيل المثال "=head1 مرحباً"، فإنه يفعل هذا بشكل أساسي:

$parser->_handle_element_start( "head1", \%attributes );
$parser->_handle_text( "مرحباً" );
$parser->_handle_element_end( "head1" );

ولكن إذا قمت بإنشاء فئة فرعية من Pod::Simple::Methody، فسيقوم بدلاً من ذلك بما يلي عند رؤية "=head1 مرحباً":

$parser->start_head1( \%attributes ) if $parser->can('start_head1');
$parser->handle_text( "مرحباً" )   if $parser->can('handle_text');
$parser->end_head1()                 if $parser->can('end_head1');

إذا أرسل Pod::Simple حدثًا يحتوي اسم العنصر فيه على شرطة أو نقطة أو نقطتين، فسيحتوي اسم الدالة المقابل على شرطة سفلية بدلاً منها. على سبيل المثال، "foo.bar:baz" تصبح start_foo_bar_baz و end_foo_bar_baz.

راجع مصدر Pod::Simple::Text كمثال على استخدام هذه الفئة.
