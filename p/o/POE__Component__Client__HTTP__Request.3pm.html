POE__Component__Client__HTTP__Request(3pm)

الحزمة: perl-poe-component-client-http

التراخيص: GPL, PerlArtistic

POE::Component::Client::HTTP::Request(3) وثائق مساهمة من مستخدمي Perl POE::Component::Client::HTTP::Request(3)

الاسم

POE::Component::Client::HTTP::Request - فئة طلب HTTP

الإصدار

الإصدار 0.949

الملخص

# يستخدم داخلياً بواسطة POE::Component::Client::HTTP

الوصف

يقوم POE::Component::Client::HTTP::Request بتغليف حالة طلبات POE::Component::Client::HTTP طوال دورة حياتها. تبين أن هناك الكثير من الحالة لإدارتها.

المنشئ

new معلمات مسماة

إنشاء كائن POE::Component::Client::HTTP لإدارة طلب. يأخذ المنشئ عدة معلمات مسماة:

Request => HTTP_REQUEST
يقوم كائن POE::Component::Client::HTTP::Request بتغليف كائن HTTP::Request عادي. مطلوب.
Factory => POE_COMPONENT_CLIENT_HTTP_REQUESTFACTORY
قد يقوم الطلب بإنشاء طلبات إضافية أثناء حياته، على سبيل المثال عند اتباع عمليات إعادة التوجيه. تحدد معلمة Factory الـ POE::Component::Client::HTTP::RequestFactory التي يمكن استخدامها لإنشائها. مطلوب.
Postback => RESPONSE_POSTBACK
يقوم POE::Component::Client::HTTP بإنشاء استدعاء خلفي سيتم استخدامه لإرسال الردود إلى الجلسة الطالبة. مطلوب.
Progress => PROGRESS_POSTBACK
يحدد إشعار التقدم إذا طلب المستخدم أحداث التقدم. اختياري.
Proxy
يحدد الوكيل المستخدم لهذا الطلب، إذا طلبه المستخدم. اختياري.

الأساليب

ID

إرجاع معرف الطلب الفريد.

return_response

يرسل استجابة مرة أخرى إلى جلسة المستخدم. يتم استدعاؤه بواسطة POE::Component::Client::HTTP عند وصول استجابة كاملة.

add_eof

يتم استدعاؤه بواسطة POE::Component::Client::HTTP للإشارة إلى وصول EOF.

add_content PARSED_DATA

يتم استدعاؤه بواسطة POE::Component::Client::HTTP لإضافة بيانات المحتوى إلى استجابة يتم بناؤها تدريجياً. إذا كان PARSED_DATA كائنًا، فيتم التعامل معه ككائن HTTP::Headers ويتم دمج رؤوسه في الاستجابة التي يتم بناؤها بواسطة الطلب. بخلاف ذلك، يتم إلحاق PARSED_DATA بمحتوى الاستجابة.

timer TIMER

مُوصل للتعامل مع مؤقت المهلة الخاص بالطلب. يحدد مؤقت الطلب إذا تم تحديد TIMER، وإلا فإنه يجلب ببساطة المؤقت المرتبط حاليًا بالطلب.

create_timer TIMEOUT

ينشئ ويحدد مؤقتًا لهذا الطلب. TIMEOUT هو عدد الثواني التي يمكن أن يعيشها هذا الطلب.

remove_timeout

إيقاف تشغيل المؤقت المرتبط بهذا الطلب، والتخلص منه.

postback POSTBACK

مُوصل للتعامل مع الاستدعاء الخلفي المرتبط بهذا الطلب. يحدد الاستدعاء الخلفي إذا كان POSTBACK معرفًا، وإلا فإنه يسترجعه ببساطة.

does_redirect SOMETHING

FIXME - لست متأكدًا مما يفعله هذا المُوصل.

check_redirect

تحقق مما إذا كانت الاستجابة الأخيرة هي إعادة توجيه، وما إذا كان مسموحًا للطلب باتباع عمليات إعادة التوجيه، وما إذا لم يتم الوصول إلى الحد الأقصى لعدد عمليات إعادة التوجيه. ابدأ عملية إعادة توجيه إذا كانت جميع الشروط مواتية.

close_connection

يحتوي كل كائن طلب نشط على اتصال داخلي. يقوم هذا الأسلوب بإغلاقه.

send_to_wheel

إرسال الطلب إلى المقبس المرتبط بهذا الطلب.

wheel

مُوصل لإرجاع العجلة المرتبطة بهذا الطلب.

error ERROR_CODE, ERROR_MESSAGE

إنشاء استجابة خطأ، وإرسالها مرة أخرى إلى جلسة المستخدم.

connect_error CONNECT_FAILURE_MESSAGE

إنشاء استجابة خطأ في الاتصال، وإرسالها مرة أخرى إلى جلسة المستخدم.

host

إرجاع المضيف الذي يحاول هذا الطلب العمل معه.

port

إرجاع المنفذ الذي يحاول هذا الطلب العمل معه.

scheme

إرجاع المخطط لهذا الطلب.
