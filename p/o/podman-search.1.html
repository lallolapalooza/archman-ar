podman-search(1)

الحزمة: podman

التراخيص: Apache-2.0

NAME

podman-search - Search image registries for images

SYNOPSIS

podman search [ --all | -a ] [ --filter filter [ --filter filter ] ] [ --format format ] [ --limit limit ] [ --login ] [ --no-trunc ] [ --registry registry ] [ --tls-verify bool ] term

DESCRIPTION

Searches registries for images that match the given search term.

Podman searches the registries that are configured in the containers-registries.d(5) directory. If Podman cannot find the image in the configured registries, it will attempt to search the Docker Hub registry.

The search command can be used to find images that are available for pulling.

The podman search command allows you to search for image names and descriptions.

OPTIONS

--all, -a
Show all results from all registries. By default, podman search only returns results from the default registries. This option will search all configured registries and the Docker Hub.
--filter, -f
Filter output based on the boolean expression given. Valid filters:
  • is-automated (boolean)
  • is-official (boolean)
  • stars (integer)
--format
Pretty-print images based on the Go template format used in Go's text/template package, using the data at the top level of the JSON returned by the registry.
--login
Use the credentials for the specified registry. If no registry is specified, it will use the credentials for the default registry. If no credentials are found, it will prompt the user for credentials.
--no-trunc
Don't truncate output
--registry
Search the specified registry for images. If this option is not specified, Podman will search all configured registries and the Docker Hub.
--tls-verify
Require TLS certificate validation when communicating with the registry (bool). Default: true.

EXAMPLES

Search for the latest official Ubuntu image:

podman search --filter is-official=true ubuntu

Search for the latest Ubuntu image and show all results:

podman search -a ubuntu

Search for the latest Ubuntu image and show only the top 10 results:

podman search --limit 10 ubuntu

Search for the latest Ubuntu image in the specified registry:

podman search --registry registry.fedoraproject.org ubuntu

Search for images with more than 100 stars:

podman search --filter stars=100 ubuntu

FILES

/etc/containers/registries.d/*: Used to configure registries that Podman will search.

SEE ALSO

podman(1), containers-registries.d(5)
