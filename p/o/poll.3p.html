poll(3p)

الحزمة: man-pages

oceeds as follows:

1.
يضبط المعلمة timeout إلى 500 مللي ثانية.
2.
يفتح أجهزة STREAMS /dev/dev0 و /dev/dev1، ثم يقوم بعمل poll لها، مع تحديد POLLOUT و POLLWRBAND كأحداث ذات أهمية.

أسماء أجهزة STREAMS /dev/dev0 و /dev/dev1 هي أمثلة فقط لكيفية تسمية أجهزة STREAMS؛ قد تختلف اتفاقيات تسمية STREAMS بين الأنظمة المتوافقة مع POSIX.1‐2008.

3.
يستخدم المتغير ret لتحديد ما إذا كان قد حدث حدث على أي من جهازي STREAMS. يتم إعطاء الدالة poll() 500 مللي ثانية للانتظار حتى يحدث حدث (إذا لم يكن قد حدث قبل استدعاء poll()).
4.
يتحقق من القيمة التي تم إرجاعها بواسطة ret. إذا تم إرجاع قيمة موجبة، يمكن القيام بأحد الإجراءات التالية:
أ.
يمكن كتابة بيانات الأولوية إلى STREAM المفتوح على نطاقات أولوية أكبر من 0، لأن حدث POLLWRBAND قد حدث على STREAM المفتوح (fds[0] أو fds[1]).
ب.
يمكن كتابة بيانات إلى STREAM المفتوح على نطاق الأولوية 0، لأن حدث POLLOUT قد حدث على STREAM المفتوح (fds[0] أو fds[1]).
5.
إذا لم تكن القيمة التي تم إرجاعها قيمة موجبة، فسيتم رفض الإذن بكتابة بيانات إلى STREAM المفتوح (على أي نطاق أولوية).
6.
إذا حدث حدث POLLHUP على STREAM المفتوح (fds[0] أو fds[1])، فإن الجهاز الموجود على STREAM المفتوح قد تم فصله. 
#include <stropts.h>
#include <poll.h>
...
struct pollfd fds[2];
int timeout_msecs = 500;
int ret;
    int i;
/* فتح جهاز STREAMS. */
fds[0].fd = open("/dev/dev0", ...);
fds[1].fd = open("/dev/dev1", ...);
fds[0].events = POLLOUT | POLLWRBAND;
fds[1].events = POLLOUT | POLLWRBAND;
ret = poll(fds, 2, timeout_msecs);
if (ret > 0) {
    /* حدث حدث على أحد fds. */
    for (i=0; i<2; i++) {
        if (fds[i].revents & POLLWRBAND) {
        /* يمكن كتابة بيانات الأولوية على الجهاز رقم i. */
...
        }
        if (fds[i].revents & POLLOUT) {
        /* يمكن كتابة بيانات على الجهاز رقم i. */
...
        }
        if (fds[i].revents & POLLHUP) {
        /* حدث انقطاع اتصال على الجهاز رقم i. */
...
        }
    }
}

استخدام التطبيق

لا شيء.

الأساس المنطقي

لا يحدث حدث POLLHUP لـ FIFOs لمجرد أن FIFO غير مفتوح للكتابة. إنه يحدث فقط عندما يتم إغلاق FIFO بواسطة آخر كاتب ويستمر حتى يفتح أي عملية FIFO للكتابة أو حتى يتم إغلاق جميع واصفات الملفات للقراءة فقط لـ FIFO.
