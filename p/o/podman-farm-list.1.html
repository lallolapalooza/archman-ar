podman-farm-list(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-farm-list(1) دليل الأوامر العامة podman-farm-list(1)

الاسم

podman farm list - عرض المزارع الموجودة

الملخص

podman farm list [خيارات]

podman farm ls [خيارات]

الوصف

يعرض جميع المزارع الموجودة.

الخيارات

--format=format

تغيير تنسيق الإخراج الافتراضي. يمكن أن يكون هذا من نوع مدعوم مثل 'json' أو قالب Go. الأماكن النائبة الصالحة لقالب Go مدرجة أدناه:

النائب الوصف
.Connections قائمة بجميع اتصالات النظام في المزرعة
.Default يشير إلى ما إذا كانت المزرعة هي الافتراضية
.Name اسم المزرعة
.ReadWrite يشير إلى ما إذا كان يمكن تعديل هذه المزرعة باستخدام أوامر podman farm

مثال

عرض جميع المزارع:

$ podman farm list
Name        Connections  Default     ReadWrite
farm1       [f38 f37]    false       true
farm2       [f37]        true        true

عرض المزارع بتنسيق JSON:

$ podman farm list --format json
[
  {
    "Name": "farm1",
    "Connections": [
      "f38",
      "f37"
    ],
    "Default": false,
    "ReadWrite": true
  },
  {
    "Name": "farm2",
    "Connections": [
      "f37"
    ],
    "Default": true,
    "ReadWrite": true
  }
]

عرض أسماء المزارع فقط:

$ podman farm list --format "{{.Name}}"
farm1
farm2

عرض معلومات مفصلة عن المزرعة:

$ podman farm list --format "Farm: {{.Name}} (Default: {{.Default}}, ReadWrite: {{.ReadWrite}})\nConnections: {{.Connections}}"
Farm: farm1 (Default: false, ReadWrite: true)
Connections: [f38 f37]
Farm: farm2 (Default: true, ReadWrite: true)
Connections: [f37]
