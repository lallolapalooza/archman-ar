podman-volume-create(1)

الحزمة: podman

التراخيص: Apache-2.0

tral-1 bucket:/prefix /mnt

مكافئ عبر mount(8)

$ mount -t fuse.s3fs -o use_xattr,endpoint=aq-central-1 bucket:/prefix /mnt

مكافئ عبر podman volume create

$ podman volume create s3fs-fuse-volume -o type=fuse.s3fs -o device=bucket:/prefix -o o=use_xattr,endpoint=aq-central-1

يمكن بعد ذلك تحميل المجلد في حاوية باستخدام

$ podman run -v s3fs-fuse-volume:/s3:z --rm -it fedora:latest

يرجى الاطلاع على الخيارات المتاحة على الويكي الخاص بهم.

الاستخدام مع مستخدمي الحاويات الآخرين

يعمل المثال أعلاه لأن المجلد تم تحميله كمستخدم المضيف وداخل الحاوية يتم تعيين root إلى المستخدم في المضيف.

إذا تم الوصول إلى التحميل بواسطة مستخدم مختلف داخل الحاوية، فسيتم رفع خطأ "Permission denied".

$ podman run --user bin:bin -v s3fs-fuse-volume:/s3:z,U --rm -it fedora:latest
$ ls /s3
# ls: /s3: Permission denied

في عالم FUSE، يتم حماية التحميلات للمستخدم الذي قام بتحميلها؛ حدد خيار التحميل allow_other إذا احتاج المستخدمون الآخرون إلى الوصول. > ملاحظة: سيؤدي هذا إلى إزالة إجراءات أمان FUSE العادية على نقطة التحميل، بعد ذلك، سيتعين على أذونات نظام الملفات العادية حمايتها

$ podman volume create s3fs-fuse-other-volume -o type=fuse.s3fs -o device=bucket:/prefix -o o=allow_other,use_xattr,endpoint=aq-central-1
$ podman run --user bin:bin -v s3fs-fuse-volume:/s3:z,U --rm -it fedora:latest
$ ls /s3

يجب أن يكون البادئة موجودة

سيفشل s3fs في التحميل إذا لم تكن البادئة موجودة في الدلو.

قم بإنشاء دليل s3 عن طريق وضع كائن فارغ عند المفتاح prefix/ المطلوب

$ aws s3api put-object --bucket bucket --key prefix/

إذا كان الأداء هو الأولوية، يرجى الاطلاع على goofys الأكثر أداءً.
