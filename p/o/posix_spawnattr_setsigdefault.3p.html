POSIX_SPAWNATTR_SETSIGDEFAULT(3P) دليل مبرمج POSIX POSIX_SPAWNATTR_SETSIGDEFAULT(3P)

PROLOG

هذه الصفحة الدليلية هي جزء من دليل مبرمج POSIX. قد يختلف تطبيق Linux لهذا الواجهة (راجع صفحة دليل Linux المقابلة لتفاصيل سلوك Linux)، أو قد لا تكون الواجهة مطبقة في Linux.

NAME

posix_spawnattr_setsigdefault — تعيين سمة spawn-sigdefault لكائن سمات الاستدعاء (نظام الوقت الحقيقي المتقدم)

SYNOPSIS

#include <signal.h>
#include <spawn.h>
int posix_spawnattr_setsigdefault(posix_spawnattr_t *restrict attr,
    const sigset_t *restrict sigdefault);

DESCRIPTION

راجع posix_spawnattr_getsigdefault().
