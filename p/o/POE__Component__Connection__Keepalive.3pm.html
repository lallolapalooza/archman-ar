POE__Component__Connection__Keepalive(3pm)

الحزمة: perl-poe-component-client-keepalive

التراخيص: GPL, PerlArtistic

POE::Component::Connection::Keepalive(3) توثيق مساهمات المستخدم Perl POE::Component::Connection::Keepalive(3)

الاسم

POE::Component::Connection::Keepalive - غلاف عجلة لمقبس يتم الاحتفاظ به

الإصدار

الإصدار 0.272

ملخص

راجع الملخص الخاص بـ POE::Component::Client::Keepalive للحصول على مثال كامل يعمل.
my $connection = $response->{connection};
$heap->{connection} = $connection;
$connection->start( InputEvent => "got_input" );
delete $heap->{connection};  # عند الانتهاء منه.

الوصف

POE::Component::Connection::Keepalive هي فئة مساعدة لـ POE::Component::Client::Keepalive. إنها تغلف المقابس المُدارة، وتوفر بعض الميزات الإضافية.

تقوم كائنات الاتصال بتحرير المقابس الأساسية الخاصة بها عند تدميرها. هذا يلغي الحاجة إلى تحرير المقابس صراحةً عند الانتهاء منها.

تدير كائنات الاتصال كائنات POE::Wheel::ReadWrite داخليًا، مما يوفر القليل من الجهد.

جديد
ينشئ نسخة جديدة من POE::Component::Connection::Keepalive. يقبل معلمتين: مقبض المقبس (socket) ومرجع لكائن POE::Component::Client::Keepalive لإدارة المقبس عند تدمير الاتصال. 
my $conn = POE::Component::Connection::Keepalive->new(
  socket  => $socket_handle,
  manager => $poe_component_client_keepalive,
);

عادةً ما يتم استدعاء new() بواسطة كائن POE::Component::Client::Keepalive.

ابدأ
يبدأ كائن POE::Wheel::ReadWrite. يتم تمرير جميع المعلمات باستثناء Handle لـ start() مباشرةً إلى مُنشئ POE::Wheel::ReadWrite. يتم توفير Handle بواسطة كائن الاتصال. ترجع start() مرجعًا لكائن POE::Wheel::ReadWrite الجديد، ولكن ليس من الضروري حفظ نسخة من تلك العجلة. يحتفظ كائن الاتصال بنسخة من المرجع داخليًا، لذا ستظل العجلة موجودة طالما استمر الاتصال. سيتم تدمير كائن POE::Wheel::ReadWrite عند تدمير كائن الاتصال. 
# اتصال غير متزامن من Client::Keepalive.
sub handle_connection {
  my $connection_info = $_[ARG0];
  $_[HEAP]->{connection} = $connection_info->{connection};
  $heap->{connection}->start(
    InputEvent => "got_input",
    ErrorEvent => "got_error",
  );
}
# إيقاف الاتصال (والعجلة) عند حدوث خطأ.
sub handle_error {
  delete $_[HEAP]->{connection};
}
عجلة
ترجع مرجعًا لكائن POE::Wheel::ReadWrite الداخلي، بحيث يمكن استدعاء الوظائف عليه. 
$heap->{connection}->wheel()->pause_input();
إغلاق
يغلق الاتصال فورًا. يستدعي أيضًا shutdown_input() و shutdown_output() على العجلة.
