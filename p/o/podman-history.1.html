podman-history(1)

الحزمة: podman

التراخيص: Apache-2.0

podman-history(1) دليل الأوامر العامة podman-history(1)

الاسم

podman-history - عرض تاريخ الصورة

الملخص

podman history [خيارات] image[:tag|@digest]

podman image history [خيارات] image[:tag|@digest]

الوصف

يعرض podman history تاريخ الصورة عن طريق طباعة معلومات حول كل طبقة مستخدمة في الصورة. تتضمن المعلومات المطبوعة لكل طبقة: الإنشاء (الوقت والتاريخ)، الإنشاء بواسطة، الحجم، والتعليق. يمكن اقتطاع الإخراج أو عدم اقتطاعه باستخدام العلامة --no-trunc. إذا تم تعيين العلامة --human، يتم طباعة وقت الإنشاء والحجم بتنسيق يمكن للبشر قراءته. تعرض العلامة --quiet معرف الصورة فقط عند تعيينها، وتستخدم العلامة --format لطباعة المعلومات باستخدام قالب Go المقدم من المستخدم.

الخيارات

--format=format

تغيير الإخراج لتنسيق مثل "json" أو قالب Go.

الأماكن النائبة الصالحة لقالب Go مدرجة أدناه:

العنصر النائب الوصف
.Comment تعليق الطبقة
.Created إذا كانت --human، فالوقت المنقضي منذ الإنشاء، وإلا وقت الإنشاء
.CreatedAt وقت إنشاء طبقة الصورة
.CreatedBy الأمر المستخدم لإنشاء الطبقة
.CreatedSince الوقت المنقضي منذ إنشاء طبقة الصورة
.ID معرف الصورة
.Size حجم الطبقة على القرص
.Tags علامات الصورة

--help, -h

طباعة بيان الاستخدام

--human, -H

عرض الأحجام والتواريخ بتنسيق قابل للقراءة البشرية (افتراضي true).

--no-trunc

عدم اقتطاع الإخراج (افتراضي false).

--quiet, -q

طباعة المعرفات الرقمية فقط (افتراضي false).

أمثلة

عرض تاريخ الصورة المحددة:

$ podman history debian
ID              CREATED       CREATED BY                                      SIZE       COMMENT
b676ca55e4f2c   9 weeks ago   /bin/sh -c #(nop) CMD ["bash"]                  0 B
<missing>       9 weeks ago   /bin/sh -c #(nop) ADD file:ebba725fb97cea4...   45.14 MB

عرض تاريخ الصورة المحددة دون اقتطاع المحتوى واستخدام بيانات خام:

$ podman history --no-trunc=true --human=false debian
ID              CREATED                CREATED BY                                      SIZE       COMMENT
b676ca55e4f2c   2017-07-24T16:52:55Z   /bin/sh -c #(nop) CMD ["bash"]                  0
<missing>       2017-07-24T16:52:54Z   /bin/sh -c #(nop) ADD file:ebba725fb97cea4...   45142935

عرض التاريخ المنسق للصورة المحددة:

$ podman history --format "{{.ID}} {{.Created}}" debian
b676ca55e4f2c   9 weeks ago
<missing>       9 weeks ago

$ podman history --format json debian
