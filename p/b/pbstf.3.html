subroutine cpbstf (character uplo, integer n, integer kd, complex, dimension( ldab, * ) ab, integer ldab, integer info)

CPBSTF

الغرض:

!>
!> CPBSTF يحسب تحليل تشوليسكي المقسم لمصفوفة هرميتية موجبة محددة ذات نطاق A.
!>
!> تم تصميم هذه الروتين لاستخدامه بالاقتران مع CHBGST.
!>
!> التحليل له الشكل A = S**H*S حيث S هي مصفوفة نطاق
!> بنفس عرض النطاق مثل A والهيكل التالي:
!>
!>   S = ( U    )
!>       ( M  L )
!>
!> حيث U مثلثية عليا من الرتبة m = (n+kd)/2، و L مثلثية سفلى
!> من الرتبة n-m.
!>

المعاملات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  يتم تخزين المثلث العلوي لـ A؛
!>          = 'L':  يتم تخزين المثلث السفلي لـ A.
!>

N

!>          N هو INTEGER
!>          رتبة المصفوفة A. N >= 0.
!>

KD

!>          KD هو INTEGER
!>          عدد الأقطار الفرعية للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفرعية إذا كان UPLO = 'L'. KD >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX، أبعادها (LDAB,N)
!>          عند الدخول، المثلث العلوي أو السفلي للمصفوفة الهرميتية ذات النطاق
!>          A، مخزنة في الصفوف الـ kd+1 الأولى من المصفوفة.
!>          يتم تخزين العمود j من A في العمود j من المصفوفة AB
!>          على النحو التالي:
!>          إذا كان UPLO = 'U'، AB(kd+1+i-j,j) = A(i,j) لـ max(1,j-kd)<=i<=j؛
!>          إذا كان UPLO = 'L'، AB(1+i-j,j)    = A(i,j) لـ j<=i<=min(n,j+kd).
!>
!>          عند الخروج، إذا كان INFO = 0، فإن العامل S من تحليل تشوليسكي المقسم
!>          A = S**H*S. انظر التفاصيل الإضافية.
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرائد للمصفوفة AB. LDAB >= KD+1.
!>

INFO

!>          INFO هو INTEGER
!>          = 0: خروج ناجح
!>          < 0: إذا كان INFO = -i، كان المعامل i له قيمة غير قانونية
!>          > 0: إذا كان INFO = i، لم يكن من الممكن إكمال التحليل،
!>               لأن العنصر المحدث a(i,i) كان سالبًا؛
!>               المصفوفة A ليست موجبة محددة.
!>

!>  S = ( s11  s12  s13                     )

!>   *    *   a13  a24  a35  a46  a57   *    *   s13  s24  s53**H s64**H s75**H
!>   *   a12  a23  a34  a45  a56  a67   *   s12  s23  s34  s54**H s65**H s76**H
!>  a11  a22  a33  a44  a55  a66  a77  s11  s22  s33  s44  s55    s66    s77
!>
!>  إذا كان UPLO = 'L'، فإن المصفوفة AB تحتوي على:
!>
!>  عند الدخول:                          عند الخروج:
!>
!>  a11  a22  a33  a44  a55  a66  a77  s11  s22  s33  s44  s55  s66  s77
!>  a21  a32  a43  a54  a65  a76   *   s12**H s23**H s34**H s54  s65  s76   *
!>  a31  a42  a53  a64  a64   *    *  s13**H s24**H s53    s64  s75   *    *
!>  عناصر المصفوفة المشار إليها بـ * لا تستخدمها الروتين؛ s12**H تشير إلى
!>  conjg(s12)؛ عناصر S القطرية حقيقية.
!>

NAME

pbstf - cpbstf, dpbstf, spbstf, zpbstf

computes a split Cholesky factorization of a band matrix

SYNOPSIS

 SUBROUTINE CPBSTF(UPLO, N, KD, AB, LDAB, INFO)
        CHARACTER*1 UPLO
        INTEGER N, KD, LDAB, INFO
        COMPLEX*16 AB(LDAB, *)
 
 SUBROUTINE DPBSTF(UPLO, N, KD, AB, LDAB, INFO)
        CHARACTER*1 UPLO
        INTEGER N, KD, LDAB, INFO
        DOUBLE PRECISION AB(LDAB, *)
 
 SUBROUTINE SPBSTF(UPLO, N, KD, AB, LDAB, INFO)
        CHARACTER*1 UPLO
        INTEGER N, KD, LDAB, INFO
        REAL AB(LDAB, *)
 
 SUBROUTINE ZPBSTF(UPLO, N, KD, AB, LDAB, INFO)
        CHARACTER*1 UPLO
        INTEGER N, KD, LDAB, INFO
        COMPLEX*16 AB(LDAB, *)

Detailed Description

This routine computes a split Cholesky factorization of a band matrix. It is designed to be used in conjunction with routines that reduce a band matrix to tridiagonal form, such as sbgst, dbgst, zhbgst, and chbgst.

The factorization has the form A = S ∗ S for complex Hermitian matrices and A = S T S for real symmetric matrices, where S is a band matrix of the same bandwidth as A and has the following structure:

S = ( U M L )

where U is upper triangular of order m = ( n + kd ) / 2 , and L is lower triangular of order n - m .

The band storage scheme is illustrated by the following example, when N = 7 , KD = 2 :

S = ( s 11 s 12 s 13 s 22 s 23 s 24 s 33 s 34 s 44 s 53 s 54 s 55 s 64 s 65 s 66 s 75 s 76 s 77 )

CPBSTF

Purpose:

!>
!> CPBSTF computes a split Cholesky factorization of a complex
!> Hermitian positive definite band matrix A.
!>
!> This routine is designed to be used in conjunction with CHBGST.
!>
!> The factorization has the form  A = S**H*S  where S is a band matrix
!> of the same bandwidth as A and the following structure:
!>
!>   S = ( U    )
!>       ( M  L )
!>
!> where U is upper triangular of order m = (n+kd)/2, and L is lower
!> triangular of order n-m.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangle of A is stored;
!>          = 'L':  Lower triangle of A is stored.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB is COMPLEX*16 array, dimension (LDAB,N)
!>          On entry, the upper or lower triangle of the Hermitian band
!>          matrix A, stored in the first kd+1 rows of the array.  The
!>          j-th column of A is stored in the j-th column of the array AB
!>          as follows:
!>          if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO = 'L', AB(1+i-j,j)    = A(i,j) for j<=i<=min(n,j+kd).
!>
!>          On exit, if INFO = 0, the factor S from the split Cholesky
!>          factorization A = S**H*S. See Further Details.
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KD+1.
!>

INFO

!>          INFO is INTEGER
!>          = 0: successful exit
!>          < 0: if INFO = -i, the i-th argument had an illegal value
!>          > 0: if INFO = i, the factorization could not be completed,
!>               because the updated element a(i,i) was negative; the
!>               matrix A is not positive definite.
!>
