CPBCON

الغرض:

!>
!> CPBCON يقدّر مقلوب رقم الشرط (بالـ 1-norm) لمصفوفة معقدة هرميتية موجبة محددة من النوع الفرقة، باستخدام
!> تحليل Cholesky A = U**H*U أو A = L*L**H الذي تم حسابه بواسطة
!> CPBTRF.
!>
!> يتم الحصول على تقدير لـ norm(inv(A))، ويتم حساب مقلوب رقم الشرط على أنه RCOND = 1 / (ANORM * norm(inv(A))).
!>

المعلمات

UPLO 
!>          UPLO هو CHARACTER*1
!>          = 'U':  عامل المثلث العلوي مخزن في AB؛
!>          = 'L':  عامل المثلث السفلي مخزن في AB.
!>

N

!>          N هو INTEGER
!>          ترتيب المصفوفة A.  N >= 0.
!>

KD

!>          KD هو INTEGER
!>          عدد الأقطار الفوقية للمصفوفة A إذا كان UPLO = 'U'،
!>          أو عدد الأقطار الفرعية إذا كان UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB هو مصفوفة COMPLEX، بُعد (LDAB,N)
!>          العامل المثلث U أو L من تحليل Cholesky
!>          A = U**H*U أو A = L*L**H للمصفوفة الفرقة A، مخزنة في
!>          الصفين الأولين KD+1 من المصفوفة. يتم تخزين العمود j من U أو L
!>          في العمود j من المصفوفة AB كما يلي:
!>          إذا كان UPLO ='U'، فإن AB(kd+1+i-j,j) = U(i,j) لـ max(1,j-kd)<=i<=j؛
!>          إذا كان UPLO ='L'، فإن AB(1+i-j,j)    = L(i,j) لـ j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB هو INTEGER
!>          البعد الرئيسي للمصفوفة AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM هو REAL
!>          الـ 1-norm (أو infinity-norm) للمصفوفة الهرميتية الفرقة A.
!>

RCOND

!>          RCOND هو REAL
!>          مقلوب رقم شرط المصفوفة A،
!>          محسوبًا على أنه RCOND = 1/(ANORM * AINVNM)، حيث AINVNM هو
!>          تقدير لـ 1-norm لـ inv(A) الذي تم حسابه في هذا الروتين.
!>

WORK

!>          WORK هو مصفوفة COMPLEX، بُعد (2*N)
!>

RWORK

!>          RWORK هو مصفوفة REAL، بُعد (N)
!>

INFO

!>          INFO هو INTEGER
!>          = 0:  الخروج بنجاح
!>          < 0:  إذا كان INFO = -i، فإن الوسيط i كان له قيمة غير قانونية
!>

LAPACK

NAME

pbcon, zpbccon - estimates the reciprocal of the condition number of a band matrix.

SYNOPSIS

SUBROUTINE PBCON(
     CHARACTER*1 UPLO,
     INTEGER N,
     INTEGER KD,
     REAL array AB( LDAB, * ),
     INTEGER LDAB,
     REAL ANORM,
     REAL RCOND,
     REAL array WORK( * ),
     INTEGER IWORK( * ),
     INTEGER INFO )
SUBROUTINE ZPBCON(
     CHARACTER*1 UPLO,
     INTEGER N,
     INTEGER KD,
     COMPLEX*16 array AB( LDAB, * ),
     INTEGER LDAB,
     DOUBLE PRECISION ANORM,
     DOUBLE PRECISION RCOND,
     COMPLEX*16 array WORK( * ),
     DOUBLE PRECISION array RWORK( * ),
     INTEGER INFO )

Detailed Description

This routine estimates the reciprocal of the condition number of a band matrix A, in either the upper or lower band triangular form, and it is computed using the information gained during the Cholesky factorization.

Function Documentation

PBCON

Purpose:

!>
!> PBCON estimates the reciprocal of the condition number (in the
!> 1-norm) of a real positive definite band matrix using the Cholesky
!> factorization A = U**T*U or A = L*L**T computed by SPBTRF.
!>
!> An estimate is obtained for norm(inv(A)), and the reciprocal of the
!> condition number is computed as RCOND = 1 / (ANORM * AINVNM), where
!> AINVNM is an estimate of the 1-norm of inv(A) computed in this
!> routine.
!>

Parameters

UPLO 
!>          UPLO is CHARACTER*1
!>          = 'U':  Upper triangular factor stored in AB;
!>          = 'L':  Lower triangular factor stored in AB.
!>

N

!>          N is INTEGER
!>          The order of the matrix A.  N >= 0.
!>

KD

!>          KD is INTEGER
!>          The number of superdiagonals of the matrix A if UPLO = 'U',
!>          or the number of subdiagonals if UPLO = 'L'.  KD >= 0.
!>

AB

!>          AB is REAL array, dimension (LDAB,N)
!>          The triangular factor U or L from the Cholesky factorization
!>          A = U**T*U or A = L*L**T of the band matrix A, stored in the
!>          first KD+1 rows of the array.  The j-th column of U or L is
!>          stored in the j-th column of the array AB as follows:
!>          if UPLO ='U', AB(kd+1+i-j,j) = U(i,j) for max(1,j-kd)<=i<=j;
!>          if UPLO ='L', AB(1+i-j,j)    = L(i,j) for j<=i<=min(n,j+kd).
!>

LDAB

!>          LDAB is INTEGER
!>          The leading dimension of the array AB.  LDAB >= KD+1.
!>

ANORM

!>          ANORM is REAL
!>          The 1-norm (or infinity-norm) of the symmetric band matrix A.
!>

RCOND

!>          RCOND is REAL
!>          The reciprocal of the condition number of the matrix A,
!>          computed as RCOND = 1/(ANORM * AINVNM), where AINVNM is an
!>          estimate of the 1-norm of inv(A) computed in this routine.
!>

WORK

!>          WORK is REAL array, dimension (3*N)
!>

IWORK

!>          IWORK is INTEGER array, dimension (N)
!>

INFO

!>          INFO is INTEGER
!>          = 0:  successful exit
!>          < 0:  if INFO = -i, the i-th argument had an illegal value
!>
