SYNOPSIS

                    
  SUBROUTINE ZPBRFS( UPLO, N, KD, NRHS, AB, LDAB, AFB, LDAFB, B, LDB, X, LDX,
                     FERR, BERR, WORK, RWORK, INFO )
    CHARACTER * 1           UPLO
    INTEGER                 KD, LDB, LDAB, LDAFB, LDX, N, NRHS
    DOUBLE PRECISION        BERR( NRHS ), FERR( NRHS ), RWORK( N )
    COMPLEX*16              AB( LDAB, N ), AFB( LDAFB, N ), B( LDB, NRHS ),

Detailed Description

                    
zpbrfs estimates the condition number of a
                        general band matrix A and provides high accuracy
                        residualפיקs and error bounds for the solution of a
                        band-structured general matrix A and its corresponding
                        band-structured linear system ZPBTRF.

                    
Arguments

                    

                        
 UPLO

                        
 CHARACTER*1
                            
Specifies whether the upper or lower
                                triangular part of the band matrix A is
                                stored in the array AB and AF B, and whether
                                the matrix is upper or lower triangular.

                            
U -- Upper triangular

                            
L -- Lower triangular

                        

                        
 N

                        
 INTEGER
                            
The order of the matrix A. N >= 0.

                        

                        
 KD

                        
 INTEGER
                            
The number of super- or subdiagonals
                                in the band matrix A. KD >= 0.

                        

                        
 NRHS

                        
 INTEGER
                            
The number of right hand sides, i.e.,
                                the number of columns of the matrices B and
                                X. NRHS >= 0.

                        

                        
 AB

                        
 COMPLEX*16 array, dimension (LDAB,N)
                            
The upper or lower triangle of the
                                Hermitian band matrix A, stored in the first
                                KD+1 rows of the array. The j-th column of A
                                is stored in the j-th column of the array AB
                                as follows:

                            
if UPLO = 'U', AB(kd+1+i-j,j) = A(i,j)
                                for max(1,j-kd)<=i<=j;

                            
if UPLO = 'L', AB(1+i-j,j) = A(i,j)
                                for j<=i<=min(n,j+kd).

                        

                        
 LDAB

                        
 INTEGER
                            
The leading dimension of the array
                                AB. LDAB >= KD+1.

                        

                        
 AFB

                        
 COMPLEX*16 array, dimension (LDAFB,N)
                            
The triangular factor U or L from the
                                Cholesky factorization A = U**H*U or A =
                                L*L**H of the band matrix A as computed by
                                ZPBTRF, in the same storage format as A (see
                                AB).

                        

                        
 LDAFB

                        
 INTEGER
                            
The leading dimension of the array
                                AFB. LDAFB >= KD+1.

                        

                        
 B

                        
 COMPLEX*16 array, dimension (LDB,NRHS)
                            
The right hand side matrix B.

                        

                        
 LDB

                        
 INTEGER
                            
The leading dimension of the array
                                B. LDB >= max(1,N).

                        

                        
 X

                        
 COMPLEX*16 array, dimension (LDX,NRHS)
                            
On entry, the solution matrix X, as
                                computed by ZPBTRS. On exit, the improved
                                solution matrix X.

                        

                        
 LDX

                        
 INTEGER
                            
The leading dimension of the array
                                X. LDX >= max(1,N).

                        

                        
 FERR

                        
 DOUBLE PRECISION array, dimension (NRHS)
                            
The estimated forward error bound for
                                each solution vector X(j) (the j-th column of
                                the solution matrix X). If XTRUE is the true
                                solution corresponding to X(j), FERR(j) is an
