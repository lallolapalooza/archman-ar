pskc_set_device_startdate(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

pskc_set_device_startdate(3) libpskc pskc_set_device_startdate(3)

الاسم

pskc_set_device_startdate - وظيفة API

الملخص

#include <pskc.h>

void pskc_set_device_startdate(pskc_key_t * key, const struct tm * startdate);

الوسائط

pskc_key_t * key
مقبض pskc_key_t، من pskc_get_keypackage().
const struct tm * startdate
مؤشر إلى هيكل tm مع تاريخ بدء الجهاز لتعيينه.

الوصف

تعيين تاريخ بدء معلومات الجهاز لحزمة المفاتيح PSKC. يشير هذا العنصر إلى تاريخ بدء تشغيل جهاز (مثل الموجود على بطاقة الدفع، والذي يتم استخدامه عندما لا تكون أرقام الإصدار مطبوعة على البطاقات).

2.2.0
