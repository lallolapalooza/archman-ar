pskc_set_cryptomodule_id(3) libpskc pskc_set_cryptomodule_id(3)

الاسم

pskc_set_cryptomodule_id - وظيفة API

الموجز

#include <pskc.h>

void pskc_set_cryptomodule_id(pskc_key_t * key, const char * cid);

المعاملات

pskc_key_t * key
مقبض pskc_key_t، من pskc_get_keypackage().
const char * cid
معرف وحدة التشفير المراد تعيينه

الوصف

تعيين قيمة معرف وحدة التشفير PSKC KeyPackage. يحمل هذا العنصر معرفًا فريدًا لوحدة التشفير وهو خاص بالتطبيق. وباعتبارها كذلك، فهي تساعد في تحديد وحدة تشفير معينة يتم توفير المفتاح لها أو تم توفيره لها.

يتم تخزين المؤشر في container، وليس نسخة من البيانات، لذلك يجب عليك عدم إلغاء تخصيص البيانات قبل استدعاء آخر لهذه الوظيفة أو الاستدعاء الأخير لأي وظيفة تستخدم container.
