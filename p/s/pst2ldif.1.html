pst2ldif(1)

الحزمة: libpst

التراخيص: GPL

PST2LDIF(1) أدوات libpst - الإصدار 0.6 PST2LDIF(1)

الاسم

pst2ldif - استخراج جهات الاتصال من ملف .pst الخاص بـ MS Outlook بتنسيق .ldif

الملخص

pst2ldif [-V] [-b قاعدة-ldap] [-c فئة] [-d ملف-تصحيح] [-l سطر-إضافي] [-o] [-h] اسم-ملف-pst

الخيارات

-V

عرض إصدار البرنامج. سيتم تجاهل الخيارات اللاحقة بعد ذلك.

-b قاعدة-ldap

يحدد قيمة قاعدة ldap المستخدمة في سجلات dn. من المحتمل أن ترغب في استخدام شيء مثل "o=organization, c=US".

-c فئة

يحدد قيم objectClass لعناصر جهات الاتصال. يجب تعريف هذه الفئة في المخطط الذي يستخدمه خادم LDAP الخاص بك، وبحد أدنى يجب أن تحتوي على سمات ldap الموضحة أدناه. يمكن تحديد هذا الخيار عدة مرات لإنشاء إدخالات بفئات كائن متعددة.

-d ملف-تصحيح

تحديد اسم ملف سجل التصحيح. أصبح ملف السجل الآن ملفًا نصيًا، بدلاً من الملف الثنائي المستخدم في الإصدارات السابقة.

-l سطر-إضافي

تحديد سطر إضافي ليتم إضافته إلى كل إدخال ldap. يمكن تحديد هذا الخيار عدة مرات لإضافة أسطر متعددة إلى كل إدخال ldap.

-o

استخدام مخطط ldap القديم، بدلاً من مخطط ldap الجديد الافتراضي. يقوم المخطط القديم بإنشاء سمات postalAddress متعددة لإدخال واحد. يقوم المخطط الجديد بإنشاء سمة postalAddress واحدة (و homePostalAddress عند توفرها) مع فواصل $ كما هو محدد في RFC4517. استخدام المخطط القديم يقوم أيضًا بإنشاء إدخالين إضافيين بادئين، أحدهما لـ "dn:ldap base"، والآخر لـ "dn: cn=root, ldap base".

-h

عرض ملخص للخيارات. سيتم تجاهل الخيارات اللاحقة بعد ذلك.

الوصف

pst2ldif يقرأ معلومات جهات الاتصال من ملف .pst الخاص بـ MS Outlook وينتج ملف .ldif يمكن استخدامه لاستيراد جهات الاتصال هذه إلى قاعدة بيانات LDAP. يتم إنشاء سمات ldap التالية لمخطط ldap القديم:

cn
givenName
sn
personalTitle
company
mail
postalAddress
l
st
postalCode
c
homePhone
telephoneNumber
facsimileTelephoneNumber
mobile
description
السمات التالية يتم إنشاؤها لمخطط ldap الجديد:
cn
givenName
sn
title
o
mail
postalAddress
homePostalAddress
l
st
postalCode
c
homePhone
telephoneNumber
facsimileTelephoneNumber
mobile
description
labeledURI
