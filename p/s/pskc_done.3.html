الاسم

pskc_done - دالة API

ملخص

#include <pskc.h>

void pskc_done(pskc_t * container);

الوسائط

pskc_t * container
مقبض pskc_t، من pskc_init().

الوصف

تُحرر هذه الدالة الموارد المرتبطة بمقبض PSKC container.
