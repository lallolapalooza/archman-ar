pskc_set_key_data_time(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

pskc_set_key_data_time(3) libpskc pskc_set_key_data_time(3)

الاسم

pskc_set_key_data_time - وظيفة API

الملخص

#include <pskc.h>

void pskc_set_key_data_time(pskc_key_t * key, uint32_t datatime);

المعاملات

pskc_key_t * key
مقبض pskc_key_t، من pskc_get_keypackage().
uint32_t datatime
قيمة وقت البيانات المراد تعيينها.

الوصف

تعيين قيمة وقت بيانات مفتاح حزمة PSKC. يحتوي هذا العنصر على الوقت لخوارزميات OTP المستندة إلى الوقت. (إذا تم استخدام فترات زمنية، فإن هذا العنصر يحمل عدد الفترات الزمنية التي مرت منذ نقطة بداية محددة، عادة ما تكون تعتمد على الخوارزمية).

منذ

2.2.0
