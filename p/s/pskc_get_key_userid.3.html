pskc_get_key_userid(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

pskc_get_key_userid(3) libpskc pskc_get_key_userid(3)

الاسم

pskc_get_key_userid - وظيفة API

الملخص

#include <pskc.h>

const char * pskc_get_key_userid(pskc_key_t * key);

المعاملات

pskc_key_t * key
مقبض pskc_key_t، من pskc_get_keypackage().

الوصف

الحصول على قيمة معرف مستخدم مفتاح حزمة المفاتيح PSKC.

يعيد

سلسلة نصية ثابتة (لا يجب تحريرها) تحتوي على المحتوى، أو NULL إذا لم يتم تعيينها.
