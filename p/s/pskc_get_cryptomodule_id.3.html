pskc_get_cryptomodule_id(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

pskc_get_cryptomodule_id(3) libpskc pskc_get_cryptomodule_id(3)

الاسم

pskc_get_cryptomodule_id - دالة API

ملخص

#include <pskc.h>

const char * pskc_get_cryptomodule_id(pskc_key_t * key);

المعاملات

pskc_key_t * key
مقبض pskc_key_t، من pskc_get_keypackage().

الوصف

احصل على قيمة معرف CryptoModule لحزمة المفاتيح PSKC. يحمل هذا العنصر معرفًا فريدًا لـ CryptoModule وهو خاص بالتنفيذ. على هذا النحو، فإنه يساعد في تحديد CryptoModule معين تم توفير المفتاح إليه أو تم توفيره إليه.

القيم المعادة

سلسلة نصية ثابتة (لا يجب إلغاء تخصيصها) تحتوي على المحتوى، أو NULL إذا لم يتم تعيينها.
