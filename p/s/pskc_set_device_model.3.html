pskc_set_device_model(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

pskc_set_device_model(3) libpskc pskc_set_device_model(3)

الاسم

pskc_set_device_model - وظيفة API

الملخص

#include <pskc.h>

void pskc_set_device_model(pskc_key_t * key, const char * model);

المعاملات

pskc_key_t * key
مقبض pskc_key_t من، على سبيل المثال، pskc_add_keypackage().
const char * model
سلسلة نصية باسم النموذج المراد تعيينه.

الوصف

قم بتعيين قيمة نموذج معلومات الجهاز PSKC KeyPackage DeviceInfo. يصف هذا العنصر نموذج الجهاز (على سبيل المثال، "one-button-HOTP-token-V1").

يتم تخزين المؤشر في container، وليس نسخة من البيانات، لذلك يجب عدم إلغاء تخصيص البيانات قبل استدعاء آخر لهذه الوظيفة أو الاستدعاء الأخير لأي وظيفة تستخدم container.
