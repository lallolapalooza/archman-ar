pskc_set_key_algparm_resp_checkdigits(3)

الحزمة: oath-toolkit

التراخيص: GPL-3.0-or-later

pskc_set_key_algparm_resp_checkdigits(3) libpskc pskc_set_key_algparm_resp_checkdigits(3)

الاسم

pskc_set_key_algparm_resp_checkdigits - دالة API

الملخص

#include <pskc.h>

void pskc_set_key_algparm_resp_checkdigits(pskc_key_t * key, int checkdigit);

المعاملات

pskc_key_t * key
مقبض pskc_key_t، من pskc_get_keypackage().
int checkdigit
قيمة غير صفرية للإشارة إلى تعيين خانة التحقق CheckDigit صحيحة، 0 خلاف ذلك.

الوصف

تعيين قيمة استجابة PSKC KeyPackage Key AlgorithmParameters ResponseFormat CheckDigits. تشير هذه السمة إلى ما إذا كان الجهاز يحتاج إلى إلحاق خانة تحقق Luhn، كما هو محدد في [ISOIEC7812]، بالاستجابة. هذا صالح فقط إذا تم تعيين السمة 'Encoding' إلى 'DECIMAL'. إذا كانت القيمة TRUE، فسيلحق الجهاز خانة تحقق Luhn بالاستجابة. إذا كانت القيمة FALSE، فلن يلحق الجهاز خانة تحقق Luhn بالاستجابة.
