php-config(1)

الحزمة: php

التراخيص: PHP-3.01

php-config(1) لغة البرمجة النصية php-config(1)

اسم

php-config - الحصول على معلومات حول تكوين PHP وخيارات التجميع

ملخص

php-config [خيارات]

وصف

php-config هو برنامج نصي بسيط للحصول على معلومات حول تكوين PHP المثبت.

خيارات

--prefix
بادئة الدليل حيث تم تثبيت PHP، على سبيل المثال /usr/local
--includes
قائمة خيارات -I مع جميع ملفات التضمين
--ldflags
رايات LD التي تم تجميع PHP بها
--libs
مكتبات إضافية تم تجميع PHP بها
--man-dir
بادئة الدليل حيث تم تثبيت صفحات الدليل
--extension-dir
الدليل حيث يتم البحث عن الامتدادات افتراضيًا
--include-dir
بادئة الدليل حيث يتم تثبيت ملفات الرأس افتراضيًا
--lib-dir
الدليل حيث يتم تثبيت المكتبات افتراضيًا
--lib-embed
اسم مكتبة PHP المضمنة
--php-binary
المسار الكامل لثنائي PHP CLI أو CGI
--php-sapis
عرض جميع وحدات SAPI المتاحة
--configure-options
خيارات التكوين لإعادة إنشاء تكوين تثبيت PHP الحالي
--ini-path
الدليل الذي يقرأ منه PHP ملف تكوين INI الخاص به (php.ini)
--ini-dir
الدليل الذي يقوم PHP بفحصه للحصول على ملفات تكوين INI إضافية
--version
إصدار PHP
--vernum
إصدار PHP كرقم صحيح
