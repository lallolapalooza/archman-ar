phar-legacy.phar(1)

الحزمة: php-legacy

التراخيص: PHP-3.01

PHAR(1) أوامر المستخدم PHAR(1)

اسم

phar, phar.phar - أداة سطر أوامر PHAR (أرشيف PHP)

ملخص

phar <command> [options] ...

وصف

يوفر تنسيق ملف PHAR طريقة لوضع تطبيقات PHP بأكملها في ملف واحد يسمى "phar" (أرشيف PHP) لتسهيل التوزيع والتثبيت.

باستخدام أمر phar، يمكنك إنشاء أو تحديث أو استخراج أرشيفات PHP.

الأوامر: add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

أمر add

إضافة إدخالات إلى حزمة PHAR.

المعاملات المطلوبة:

-f file
يحدد ملف file الخاص بـ phar للعمل عليه.
...
أي عدد من الملفات والمجلدات المدخلة. إذا تم استخدام -i، فسيتم تعبئة الملفات التي تطابق التعبير المنتظم المحدد فقط. إذا تم استخدام -x، فسيتم استبعاد الملفات التي تطابق هذا التعبير المنتظم.

المعاملات الاختيارية:

-a alias
يوفر اسم alias لملف phar.
-c algo
خوارزمية الضغط (انظر COMPRESSION )
-i regex
يحدد تعبيرًا منتظمًا للملفات المدخلة.
-l level
عدد الدلائل الفرعية السابقة التي سيتم إزالتها من إدخالات الملفات
-x regex
تعبير منتظم للملفات المدخلة لاستبعادها.

أمر meta-del

حذف معلومات التعريف التعريفية لإدخال PHAR أو حزمة PHAR.

إذا تم إعطاء -k، فمن المتوقع أن تكون بيانات التعريف مصفوفة وأن يتم حذف المؤشر المحدد.

إذا تم حذف شيء ما، تكون قيمة الإرجاع 0 وإلا فإنها تكون 1.

المعاملات المطلوبة:

-f file
يحدد ملف file الخاص بـ phar للعمل عليه.

المعاملات الاختيارية:

-e entry
اسم entry للعمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-k index
مؤشر index الفرعي للعمل عليه.

أمر meta-get

الحصول على معلومات التعريف التعريفية لإدخال PHAR أو حزمة PHAR بتنسيق تسلسلي. إذا لم يتم تحديد ملف إخراج لبيانات التعريف، يتم استخدام stdout. يمكنك أيضًا تحديد مؤشر معين باستخدام -k. في هذه الحالة، من المتوقع أن تكون بيانات التعريف مصفوفة ويتم إرجاع قيمة المؤشر المحدد باستخدام echo بدلاً من استخدام التسلسل. إذا لم يكن هذا المؤشر موجودًا أو لم تكن هناك بيانات تعريف، فإن قيمة الإرجاع هي 1.

المعاملات المطلوبة:

-f file
يحدد ملف file الخاص بـ phar للعمل عليه.

المعاملات الاختيارية:

-e entry
اسم entry للعمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-k index
مؤشر index الفرعي للعمل عليه.

أمر meta-set

تعيين بيانات التعريف لإدخال PHAR أو حزمة PHAR باستخدام إدخال تسلسلي. إذا لم يتم تحديد ملف إدخال لبيانات التعريف، يتم استخدام stdin. يمكنك أيضًا تحديد مؤشر معين باستخدام -k. في هذه الحالة، من المتوقع أن تكون بيانات التعريف مصفوفة وسيتم تعيين قيمة المؤشر المحدد. إذا لم تكن بيانات التعريف موجودة أو كانت فارغة، فسيتم إنشاء مصفوفة جديدة. إذا كانت بيانات التعريف موجودة وقيمة مسطحة، فإن قيمة الإرجاع هي 1. باستخدام -k أيضًا، يتم أخذ الإدخال مباشرة بدلاً من أن يكون تسلسليًا.

المعاملات المطلوبة:

-f file
يحدد ملف file الخاص بـ phar للعمل عليه.
-m meta
بيانات تعريف لتخزينها مع الإدخال (بيانات PHP تسلسلية).

المعاملات الاختيارية:

-e entry
اسم entry للعمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-k index
مؤشر index الفرعي للعمل عليه.

أمر pack

تعبئة الملفات في أرشيف PHAR.

عند استخدام -s <stub>، يتم استبعاد ملف stub من قائمة الملفات/المجلدات المدخلة. لإنشاء أرشيف يحتوي على فئة PHP_Archive الخاصة بـ PEAR، قم بتوجيه المعامل -p إلى PHP/Archive.php.

المعاملات المطلوبة:

-f file
يحدد ملف file الخاص بـ phar للعمل عليه.
...
أي عدد من الملفات والمجلدات المدخلة. إذا تم استخدام -i، فسيتم تعبئة الملفات التي تطابق التعبير المنتظم المحدد فقط. إذا تم استخدام -x، فسيتم استبعاد الملفات التي تطابق هذا التعبير المنتظم.

المعاملات الاختيارية:

-a alias
يوفر اسم alias لملف phar.
-b bang
سطر الهاش-بانغ لبدء الأرشيف (مثل #!/usr/bin/php). علامة الهاش نفسها '#!' والسطر الجديد

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

اسم

phar - أداة سطر الأوامر لمعالجة أرشيفات PHAR

ملخص

phar [options] command [command-options] [file(s)]

وصف

phar هي أداة سطر أوامر للعمل مع أرشيفات PHAR. تسمح للمستخدمين بإنشاء ومعالجة وفحص أرشيفات PHAR.

يمكن استخدام الأمر phar مع العديد من الأوامر الفرعية، لكل منها خياراته الخاصة. فيما يلي وصف موجز للأوامر المتاحة:

أمر الإضافة

إضافة ملفات إلى أرشيف PHAR. إذا لم يتم تحديد ملف PHAR، فسيتم إنشاؤه.

المتطلبات:

-f file
يحدد ملف PHAR الذي سيتم العمل عليه.

الخيارات:

-a alias
اسم مستعار لمسار الملف.
-c algo
خوارزمية الضغط (انظر COMPRESSION).
-p loader
موقع ملف فئة PHP_Archive (pear list-files PHP_Archive). يمكنك استخدام '0' أو '1' لتحديد موقعه تلقائيًا باستخدام أمر pear المذكور. عند استخدام '0' لا يصدر الأمر خطأ عند عدم العثور على ملف الفئة. هذا المفتاح يضيف أيضًا بعض التعليمات البرمجية حول الرمز المميز بحيث يتم تسجيل الفئة PHP_Archive كغلاف تدفق phar:// إذا لزم الأمر. وأخيرًا، سيضيف هذا المفتاح الملف phar.inc من هذه الحزمة ويحمله لضمان وجود الفئة Phar.
-b bang
سطر الهاش بانغ لبدء الأرشيف (على سبيل المثال #!/usr/bin/php). الهاش نفسه '#!' والحرف الجديد اختياريان.
-s stub
حدد ملف الرمز المميز.
