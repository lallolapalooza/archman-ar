int PHYSFS_caseFold (const PHYSFS_uint32 from, PHYSFS_uint32 * to)

"طي" نقطة رمز يونيكود إلى مكافئها الصغير. (هذا للاستخدام المحدود، المتقدم. إذا لم ترَ حاجة فورية، يمكنك تجاهل هذه الدالة إلى الأبد.)

تحول نقطة رمز يونيكود إلى مكافئها الصغير. نقاط الرمز الضارة والتي لا تحتوي على مكافئ صغير يتم إرجاعها دون تغيير.

ملاحظة: قد تحصل على نقاط رمز متعددة في الإرجاع! على سبيل المثال، حرف eszett الألماني سيتم "طيّه" إلى نقطتي رمز صغيرتين من 's'. النظرية هي أنه إذا قمت بطي سلسلتين، واحدة تحتوي على eszett والأخرى تحتوي على 'SS'، فستتطابق.

تحذير

أولئك الذين يدرسون يونيكود على دراية بمشكلة "التركية I". هذه الواجهة لا تتعامل معها. تفترض أن هذا الحرف في جميع أنحاء يونيكود سيتم "طيّه" بشكل غير صحيح. إذا لم تكن تعرف ما هذا، يمكنك تجاهل هذه المشكلة بالنسبة لمعظم الكوكب، لكن الكمال مستحيل.

المعلمات

from نقطة الرمز المراد طيها.
to المخزن المؤقت حيث يتم تخزين قيم نقاط الرمز المطوية. يجب أن يشير إلى مساحة لـ 3 فتحات PHYSFS_uint32 على الأقل.

int PHYSFS_deinit (void )

إلغاء تهيئة مكتبة PhysicsFS. يغلق أي ملفات مفتوحة بواسطة PhysicsFS، ومسح مسارات البحث/الكتابة، وتحرير الذاكرة، وإبطال جميع مقابض ملفاتك.

ملاحظة: قد تفشل هذه المكالمة إذا كان هناك ملف مفتوح للكتابة لم يتم إغلاقه (على سبيل المثال، كان نظام التشغيل يقوم بتخزين الكتابات مؤقتًا في نظام ملفات شبكي، وفشل خادم الملفات، أو فشل قرص صلب، وما إلى ذلك). من الأفضل عمومًا إغلاق جميع مقابض الكتابة قبل استدعاء هذه الدالة، للتعامل مع فشل محدد بسلاسة.

int PHYSFS_enumerate (const char * dir, PHYSFS_EnumerateCallback c, void * d)

Obtiene una lista de archivos de un directorio en una ruta de búsqueda, utilizando una función de retorno de llamada definida por el aplicador, con informes de errores. Internamente, PHYSFS_enumerateFiles() llama a esta función y luego construye una lista antes de devolverla al aplicador, por lo que la funcionalidad es idéntica, excepto por cómo se presenta la información al aplicador.

A diferencia de PHYSFS_enumerateFiles(), esta función no devuelve una matriz. En su lugar, llama a una función especificada por el aplicador una vez por cada elemento en la ruta de búsqueda:

static PHYSFS_EnumerateCallbackResult printDir(void *data, const char *origdir, const char *fname)
{
    printf(" * We've got [%s] in [%s].\n", fname, origdir);
    return PHYSFS_ENUM_OK;  // dame más datos, por favor.
}
// ...
PHYSFS_enumerate("/some/path", printDir, NULL);

Los elementos que se envían a la función de retorno de llamada no están garantizados en ningún orden específico. No se realiza ninguna ordenación en este nivel y, si la necesita, debería usar PHYSFS_enumerateFiles(), que garantiza el orden alfabético. Esta forma informa lo que se encuentra en cada archivo archivado antes de pasar al siguiente. Incluso dentro de un archivo, no podemos garantizar el orden en que se descubren los datos. Cualquier orden que encuentres en estas devoluciones de llamada es pura suerte. No deberías depender de ello. Dado que recorre toda la lista de archivos, puedes recibir nombres de archivo duplicados.

Esta API y las propias funciones de retorno de llamada pueden informar de errores. Antes de esta API, las funciones de retorno de llamada tenían que aceptar cada elemento enumerado, incluso si solo buscaban un objeto específico y querían detenerse después, o tenían un error grave y no podían alertar a nadie. Además, si PhysicsFS tenía un problema (error de disco o similar), no podía informarlo al aplicador, simplemente tenía que omitir elementos o detener la enumeración por completo, y el llamador no sabría que se habían perdido algunos datos en el camino.

Ahora el llamador puede estar seguro de que obtuvo un conjunto completo de datos, y si quiere detener la enumeración antes, su función de retorno de llamada tiene el control. Consulte la documentación de PHYSFS_EnumerateCallback para obtener detalles sobre cómo debe comportarse su función de retorno de llamada.

Parámetros

dir Directorio, en notación independiente del sistema operativo, a enumerar.
c Función de retorno de llamada para notificar sobre elementos en la ruta de búsqueda.
d Datos definidos por el aplicador que se pasan a la función de retorno de llamada. Puede ser NULL.

Devuelve

Distinto de cero en caso de éxito, cero en caso de fallo. Usa PHYSFS_getLastErrorCode() para obtener el error específico. Si la función de retorno de llamada devuelve PHYSFS_ENUM_STOP para detener antes, esto se considera un éxito. Las funciones de retorno de llamada que devuelvan PHYSFS_ENUM_ERROR harán que esta función devuelva cero y establezca el código de error en PHYSFS_ERR_APP_CALLBACK.

Los directorios que coinciden se interpolan. char **rc = PHYSFS_enumerateFiles("savegames");
char **i;
for (i = rc; *i != NULL; i++)
    printf(" * We've got [%s].\n", *i);
PHYSFS_freeList(rc);
