التراخيص: PHP-3.01

-r 'print_r(dba_handlers(1));'
php -R 'echo strip_tags($argn)."\n";'
هذا الأمر PHP يقوم بتجريد وسوم HTML سطراً بسطر وإخراج النتيجة. لرؤية كيف يعمل، يمكنك أولاً النظر إلى أمر PHP التالي ´php -d html_errors=1 -i´ الذي يستخدم PHP لإخراج معلومات التكوين بتنسيق HTML. إذا قمت بدمج هذين الأمرين ´php ...|php ...´ فسترى ما يحدث.
php -E 'echo "Lines: $argi\n";'
باستخدام أمر PHP هذا، يمكنك عد الأسطر التي يتم إدخالها.
php -R '@$l+=count(file($argn));' -E 'echo "Lines:$l\n";'
في هذا المثال، تتوقع PHP أن يكون كل سطر إدخال عبارة عن ملف. يقوم بعد جميع أسطر الملفات المحددة بواسطة كل سطر إدخال ويعرض النتيجة المجمعة. يمكنك دمج هذا مع أدوات مثل find وتغيير النص البرمجي لـ php.
php -R 'echo "$argn\n"; fgets(STDIN);'
نظرًا لأن لديك وصولاً إلى STDIN من داخل -B و -R و -F و -E، يمكنك تخطي أسطر الإدخال معينة باستخدام التعليمات البرمجية الخاصة بك. ولكن لاحظ أنه في مثل هذه الحالات، يقوم $argi فقط بعد الأسطر التي تتم معالجتها بواسطة php نفسها. بعد قراءة هذا، ستخمن ما يفعله البرنامج أعلاه: تخطي كل سطر إدخال ثانٍ.
