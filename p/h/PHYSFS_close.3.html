تحذير

منذ PhysicsFS 2.1، استخدم PHYSFS_EnumerateCallback مع PHYSFS_enumerate() للحصول على مزيد من التحكم في العملية.

تُستخدم هذه الإدخالات للإبلاغ عن قائمة بإدخالات الدليل إلى جهة اتصال أصلية، إدخال واحد لكل استدعاء رد اتصال. جميع السلاسل النصية مرمزة بـ UTF-8. لا ينبغي للدوال محاولة تعديل أو تحرير الذاكرة لأي سلاسل نصية.

تُستخدم استدعاءات رد الاتصال هذه، منذ PhysicsFS 1.1، كبديل للدوال التي تعيد قوائم يجب تحريرها باستخدام PHYSFS_freeList(). يشير استدعاء رد الاتصال إلى أن المكتبة لا تحتاج إلى الاحتفاظ بقائمة كاملة وجميع السلاسل النصية.

لاحظ أن الترتيب الموعود في إصدارات القائمة قد لا يتم الحفاظ عليه في إصدارات استدعاء رد الاتصال. تحقق من التوثيق لواجهات برمجة التطبيقات المحددة، ولكن قد لا تكون السلاسل النصية مرتبة كما توقعت وقد تحصل على سلاسل نصية مكررة.

المعلمات

data مؤشر إلى بيانات معرفة من قبل المستخدم، تم تمريرها بواسطة واجهة برمجة التطبيقات التي استدعت في النهاية استدعاء رد الاتصال.
origdir سلسلة نصية تحتوي على المسار الكامل، بترقيم مستقل عن النظام، للدليل الذي يحتوي على هذا الملف. في معظم الحالات، يكون هذا هو الدليل الذي طلبت منه القائمة، والذي تم تمريره في استدعاء رد الاتصال للراحة.
fname اسم الملف الذي يتم سرده. قد لا يكون بترتيب أبجدي مقارنة باستدعاءات رد الاتصال الأخرى التي تم استدعاؤها، ولن يحتوي على المسار الكامل. يمكنك إعادة بناء المسار الكامل باستخدام $origdir/$fname ... قد يكون الملف دليلاً فرعياً، أو ملفًا، أو رابطًا رمزيًا، وما إلى ذلك.

يعيد

قيمة من PHYSFS_EnumerateCallbackResult. جميع القيم الأخرى غير معرفة (حاليًا)؛ لا تستخدمها.

افتراضيًا، ستتحقق PhysicsFS مما إذا كان الملف رابطًا رمزيًا حقًا أثناء مكالمات الفتح وستفشل إذا كان كذلك. خلاف ذلك، يمكن أن يأخذك الرابط خارج مسارات الكتابة والبحث، ويضر بالأمان.

إذا كنت ترغب في تحمل هذا الخطر، قم باستدعاء هذه الدالة بمعامل غير صفري. لاحظ أن هذا يتعلق أكثر بتدريع لغة البرمجة النصية للبرنامج، في حالة محاولة البرامج النصية غير الموثوق بها الإضرار بالنظام. بشكل عام، قد يكون لدى المستخدم سبب مشروع لإنشاء رابط رمزي، لذا ما لم تشعر بوجود خطر محدد في السماح بها، يجب عليك السماح بها.

PHYSFS_writeUBE16(3) — physfs — 3.2.0

NAME

PHYSFS_writeUBE16, PHYSFS_writeUBE32, PHYSFS_writeUBE64, PHYSFS_writeULE16, PHYSFS_writeULE32, PHYSFS_writeULE64 — write platform-specific endian integers to a PHYSFS_File

LIBRARY

PhysicsFS Library (libphysfs, -lphysfs)

SYNOPSIS

#include <physfs.h>

int PHYSFS_writeUBE16(PHYSFS_File *file, PHYSFS_uint16 val);
int PHYSFS_writeUBE32(PHYSFS_File *file, PHYSFS_uint32 val);
int PHYSFS_writeUBE64(PHYSFS_File *file, PHYSFS_uint64 val);
int PHYSFS_writeULE16(PHYSFS_File *file, PHYSFS_uint16 val);
int PHYSFS_writeULE32(PHYSFS_File *file, PHYSFS_uint32 val);
int PHYSFS_writeULE64(PHYSFS_File *file, PHYSFS_uint64 val);

DESCRIPTION

These functions are convenience functions that convert an unsigned integer from the platform's native byte order to a specific endianness (big-endian or little-endian) and write it to a PHYSFS_File.

All functions convert the value val to the specified endianness and write it to the specified file. If the platform's native byte order already matches the target endianness, the value is written directly. Otherwise, the bytes are swapped before writing.

The PHYSFS_writeUBE16 and PHYSFS_writeULE16 functions handle 16-bit unsigned integers.

The PHYSFS_writeUBE32 and PHYSFS_writeULE32 functions handle 32-bit unsigned integers.

The PHYSFS_writeUBE64 and PHYSFS_writeULE64 functions handle 64-bit unsigned integers.

Warning: PHYSFS_uint64 is only 32 bits on platforms without any sort of 64-bit support. On such platforms, these functions will effectively behave like their 32-bit counterparts, but they will still attempt to convert and write a 64-bit value.

PARAMETERS

PHYSFS_File *file
The PhysicsFS file handle to which to write.
PHYSFS_uint16 val, PHYSFS_uint32 val, PHYSFS_uint64 val
The value to convert and write.

RETURN VALUES

Returns zero on failure, non-zero on success. On failure, you can find out what went wrong from PHYSFS_getLastErrorCode().

EXAMPLE

PHYSFS_File *fp = PHYSFS_openWrite("output.bin");
if (fp == NULL) {
    // Handle error...
}

PHYSFS_uint32 value = 0x12345678;
if (PHYSFS_writeUBE32(fp, value) == 0) {
    // Handle error...
}

if (PHYSFS_writeULE32(fp, value) == 0) {
    // Handle error...
}

if (PHYSFS_close(fp) == 0) {
    // Handle error...
}
