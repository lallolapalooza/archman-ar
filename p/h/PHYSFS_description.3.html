الاسم

PHYSFS_ArchiveInfo - معلومات حول الأرشيفات المختلفة التي تدعمها PhysicsFS.

الملخص

#include <physfs.h>

حقول البيانات


const char * extension
const char * description
const char * author
const char * url
int supportsSymlinks

الوصف التفصيلي

معلومات حول الأرشيفات المختلفة التي تدعمها PhysicsFS.

يقدم لك هذا الهيكل تفاصيل حول أنواع الأرشيفات المدعومة في هذا التنفيذ من PhysicsFS. تميل الأرشيفات إلى أن تكون أشياء مثل ملفات ZIP وما شابه.

تحذير

ليست كل الملفات الثنائية متساوية! يمكن بناء PhysicsFS مع أو بدون دعم لأرشيفات مختلفة. يمكنك التحقق باستخدام PHYSFS_supportedArchiveTypes() لمعرفة ما إذا كان نوع الأرشيف الخاص بك مدعومًا.
