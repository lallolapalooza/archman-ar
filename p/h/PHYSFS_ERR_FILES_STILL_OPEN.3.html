#define PHYSFS_file PHYSFS_File

تعريف توافق API 1.0. PHYSFS_file مطابق لـ PHYSFS_File. هذا #define موجود للتوافق الرجعي مع API 1.0، والذي كان لديه اتفاقية كتابة غير متسقة في هذه الحالة. يجب على الشفرة الجديدة استخدام PHYSFS_File، حيث قد يتم إزالة هذا #define في يوم من الأيام.

void PHYSFS_permitSymbolicLinks (int allow)

Yuan atau melarang pelacakan tautan simbolis. Beberapa sistem file fisik dan file arsip berisi file yang hanyalah penunjuk ke file lain. Saat membuka tautan simbolis fisik, ini akan secara transparan membuka file yang ditunjuknya.

Secara default, PhysicsFS memeriksa apakah file tersebut benar-benar tautan simbolis selama panggilan buka dan gagal jika demikian. Jika tidak, tautan tersebut dapat membawa Anda keluar dari jalur baca dan tulis, sehingga membahayakan keamanan.

Jika Anda ingin mengambil risiko itu, panggil fungsi ini dengan nilai bukan nol. Ini lebih untuk pembatasan bahasa skrip, kalau-kalau skrip yang tidak dipercaya mencoba membahayakan sistem. Secara umum, pengguna mungkin memiliki alasan yang sah untuk membuat tautan simbolis, jadi Anda seharusnya tidak melarangnya kecuali Anda merasakan bahaya tertentu.

Tautan simbolis hanya akan terlihat secara eksplisit ketika menyangkut nama file dalam notasi independen platform. Artinya, saat jalur pencarian dan jalur tulis diatur, dll., Tautan simbolis tidak akan pernah terlihat.

Catatan: PHYSFS_stat() selalu memeriksa jalur yang ditentukan; jika jalur tersebut adalah tautan simbolis, itu tidak akan pernah diikuti dalam keadaan apa pun. Jika tidak diizinkan melalui fungsi ini, PHYSFS_stat() akan mengabaikan tautan tersebut dan memperlakukan kueri seolah-olah jalur itu tidak ada.

Izin tautan simbolis dapat diaktifkan atau dinonaktifkan kapan saja setelah PHYSFS_init() dipanggil, dan dinonaktifkan secara default.

Parameter

allow bukan nol untuk mengizinkan tautan simbolis, nol untuk menolaknya.

مقارنة غير حساسة لحالة الأحرف لسلسلتين UTF-16. هذا بديل لـ strcasecmp/stricmp ويتوقع أن تكون كلتا السلسلتين بتشفير UTF-16. سيقوم بإجراء "طي الحالة" لتحديد ما إذا كانت نقاط رمز Unicode في السلاسل متطابقة.

سيبلغ عن السلسلة التي تعتبر "أكبر من" الأخرى، ولكن كن على علم بأن هذا لا يعني بالضرورة شيئًا: قد تكون 'a' "أصغر من" 'b'، ولكن لا يوجد علاقة أبجدية ذات معنى بين Kuten اليابانية وحرف Lambda اليوناني، ولكن القدرة على تعيين "قيمة" موثوقة تجعل خوارزميات الفرز ممكنة، حتى لو لم تكن منطقية تمامًا. يجب أن يعامل معظم الحالات القيمة المرجعة على أنها "متساوية" أو "غير متساوية".

مثل stricmp، يتوقع هذا أن تكون كلتا السلسلتين منتهية بـ NULL.

DESCRIPTION

These functions write a fixed-size integer value to a PHYSFS_File. The value is converted from the platform's native byte order to the specified endianness before being written.

The ‘B’ in the function names means big-endian, and ‘L’ means little-endian. The ‘U’ means unsigned. The numbers 16, 32, and 64 mean the number of bits in the value.

For example, PHYSFS_writeBE16 writes an unsigned 16-bit value in big-endian format.

Warning

The size of PHYSFS_uint64 is 32 bits on platforms that do not support 64-bit integers. Behavior might be unexpected on those platforms.
