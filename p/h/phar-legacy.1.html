phar-legacy(1)

الحزمة: php-legacy

التراخيص: PHP-3.01

PHAR(1) أوامر المستخدم PHAR(1)

الاسم

phar, phar.phar - أداة سطر أوامر PHAR (أرشيف PHP)

الملخص

phar <الأمر> [الخيارات] ...

الوصف

يوفر تنسيق ملف PHAR طريقة لوضع تطبيقات PHP كاملة في ملف واحد يُسمى "phar" (أرشيف PHP) لتسهيل التوزيع والتثبيت.

باستخدام الأمر phar يمكنك إنشاء أرشيفات PHP أو تحديثها أو استخراجها.

الأوامر: add compress delete extract help help-list info list meta-del meta-get meta-set pack sign stub-get stub-set tree version

أمر add

إضافة مدخلات إلى حزمة PHAR.

الوسائط المطلوبة:

-f file
يحدد ملف phar file المراد العمل عليه.
...
أي عدد من ملفات ومجلدات الإدخال. إذا تم استخدام -i فسيتم حزم الملفات المطابقة للتعبير النمطي المعطى فقط. إذا تم إعطاء -x فلن يتم حزم الملفات المطابقة لذلك التعبير النمطي.

الوسائط الاختيارية:

-a alias
توفير اسم alias لملف phar.
-c algo
خوارزمية الضغط (انظر الضغط )
-i regex
يحدد تعبيرًا نمطيًا لملفات الإدخال.
-l level
عدد المجلدات الفرعية السابقة المراد إزالتها من مدخلات الملفات
-x regex
تعبير نمطي لملفات الإدخال المراد استبعادها.

أمر compress

ضغط أو فك ضغط جميع الملفات أو مدخل محدد.

الوسائط المطلوبة:

-c algo
خوارزمية الضغط (انظر الضغط )
-f file
يحدد ملف phar file المراد العمل عليه.

الوسائط الاختيارية:

-e entry
اسم entry المراد العمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).

حذف مدخل من أرشيف PHAR

الوسائط المطلوبة:

-e entry
اسم entry المراد العمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-f file
يحدد ملف phar file المراد العمل عليه.

أمر extract

استخراج حزمة PHAR إلى دليل.

الوسائط المطلوبة:

يحدد ملف phar file المراد العمل عليه.

الوسائط الاختيارية:

يحدد تعبيرًا نمطيًا لملفات الإدخال.
-x regex
تعبير نمطي لملفات الإدخال المراد استبعادها.
...
الدليل المراد الاستخراج إليه (الافتراضي هو '.').

الوسائط الاختيارية:

أمر meta-del

حذف المعلومات الوصفية لمدخل PHAR أو حزمة PHAR.

إذا تم إعطاء -k فمن المتوقع أن تكون البيانات الوصفية مصفوفة ويتم حذف الفهرس المعطى.

إذا تم حذف شيء ما فإن قيمة الإرجاع هي 0 وإلا فهي 1.

الوسائط المطلوبة:

-f file
يحدد ملف phar file المراد العمل عليه.

الوسائط الاختيارية:

-e entry
اسم entry المراد العمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-k index
فهرس الاشتراك index المراد العمل عليه.

أمر meta-get

الحصول على المعلومات الوصفية لمدخل PHAR أو حزمة PHAR بصيغة متسلسلة. إذا لم يتم تحديد ملف إخراج للبيانات الوصفية فسيتم استخدام المخرجات القياسية. يمكنك أيضًا تحديد فهرس معين باستخدام -k. في هذه الحالة من المتوقع أن تكون البيانات الوصفية مصفوفة ويتم إرجاع قيمة الفهرس المعطى باستخدام echo بدلاً من serialize. إذا لم يكن ذلك الفهرس موجودًا أو لم تكن هناك بيانات وصفية فقيمة الإرجاع هي 1.

الوسائط المطلوبة:

-f file
يحدد ملف phar file المراد العمل عليه.

الوسائط الاختيارية:

-e entry
اسم entry المراد العمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-k index
فهرس الاشتراك index المراد العمل عليه.

أمر meta-set

تعيين البيانات الوصفية لمدخل PHAR أو حزمة PHAR باستخدام إدخال متسلسل. إذا لم يتم تحديد ملف إدخال للبيانات الوصفية فسيتم استخدام الإدخال القياسي. يمكنك أيضًا تحديد فهرس معين باستخدام -k. في هذه الحالة من المتوقع أن تكون البيانات الوصفية مصفوفة ويتم تعيين قيمة الفهرس المعطى. إذا لم تكن البيانات الوصفية موجودة أو كانت فارغة فسيتم إنشاء مصفوفة جديدة. إذا كانت البيانات الوصفية موجودة وقيمة مسطحة فقيمة الإرجاع هي 1. أيضًا باستخدام -k يتم أخذ الإدخال مباشرة بدلاً من تسلسله.

الوسائط المطلوبة:

-f file
يحدد ملف phar file المراد العمل عليه.
-m meta
البيانات الوصفية المراد تخزينها مع المدخل (بيانات php متسلسلة).

الوسائط الاختيارية:

-e entry
اسم entry المراد العمل عليه (يجب أن يتضمن اسم الدليل الداخلي لـ PHAR إن وجد).
-k index
فهرس الاشتراك index المراد العمل عليه.

أمر pack

حزم الملفات في أرشيف PHAR.

عند استخدام -s <stub>، يتم استبعاد ملف stub من قائمة ملفات/مجلدات الإدخال. لإنشاء أرشيف يحتوي على فئة PEAR PHP_Archive وجّه وسيطة -p إلى PHP/Archive.php.

الوسائط المطلوبة:

-f file
يحدد ملف phar file المراد العمل عليه.
...
أي عدد من ملفات ومجلدات الإدخال. إذا تم استخدام -i فسيتم حزم الملفات المطابقة للتعبير النمطي المعطى فقط. إذا تم إعطاء -x فلن يتم حزم الملفات المطابقة لذلك التعبير النمطي.

الوسائط الاختيارية:

-a alias
توفير اسم alias لملف phar.
-b bang
سطر hash-bang لبدء الأرشيف (مثل #!/usr/bin/php). علامة التجزئة نفسها '#!' والسطر الجديدine character are optional.
-c algo
خوارزمية الضغط (انظر COMPRESSION )
-h hash
يحدد خوارزمية hash (انظر HASH )
-i regex
يحدد تعبيرًا نمطيًا لملفات الإدخال.
-l level
عدد الأدلة الفرعية السابقة التي يجب إزالتها من إدخالات الملفات
-p loader
موقع ملف الصنف PHP_Archive (pear list-files PHP_Archive). يمكنك استخدام '0' أو '1' لتحديد موقعه تلقائيًا باستخدام أمر pear المذكور. عند استخدام '0' لا يتوقف الأمر بخطأ عندما يتعذر تحديد موقع ملف الصنف. يضيف هذا المفتاح أيضًا بعض الشيفرة حول الـ stub بحيث يتم تسجيل الصنف PHP_Archive كغلاف تدفق phar:// إذا لزم الأمر. وأخيرًا سيضيف هذا المفتاح الملف phar.inc من هذه الحزمة و يحمّله لضمان وجود الصنف Phar.
-s stub
اختر ملف stub.
-x regex
تعبير نمطي لملفات الإدخال المراد استبعادها.
-y key
مفتاح خاص لتوقيع OpenSSL.

stub-set command

تعيين stub لملف PHAR. إذا لم يتم تحديد ملف إدخال كـ stub فسيتم استخدام stdin.

الوسائط المطلوبة:

-f file
يحدد ملف phar file المراد العمل عليه.

الوسائط الاختيارية:

-b bang
سطر hash-bang لبدء الأرشيف (مثل #!/usr/bin/php). علامة التجزئة نفسها '#!' ومحرف السطر الجديد اختياريان.
-p loader
موقع ملف الصنف PHP_Archive (pear list-files PHP_Archive). يمكنك استخدام '0' أو '1' لتحديد موقعه تلقائيًا باستخدام أمر pear المذكور. عند استخدام '0' لا يتوقف الأمر بخطأ عندما يتعذر تحديد موقع ملف الصنف. يضيف هذا المفتاح أيضًا بعض الشيفرة حول الـ stub بحيث يتم تسجيل الصنف PHP_Archive كغلاف تدفق phar:// إذا لزم الأمر. وأخيرًا سيضيف هذا المفتاح الملف phar.inc من هذه الحزمة و يحمّله لضمان وجود الصنف Phar.
-s stub
اختر ملف stub.
