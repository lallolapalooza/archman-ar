int PHYSFS_enumerate (const char * dir, PHYSFS_EnumerateCallback c, void * d)

للحصول على قائمة بالملفات من مسار بحث، باستخدام دالة استدعاء محددة من قبل المستخدم، مع الإبلاغ عن الأخطاء. داخليًا، PHYSFS_enumerateFiles() تستدعي هذه الدالة فقط ثم تبني قائمة قبل العودة إلى التطبيق، لذلك الوظائف متطابقة، بخلاف كيفية تقديم المعلومات إلى التطبيق.

على عكس PHYSFS_enumerateFiles()، هذه الدالة لا تعيد مصفوفة. بدلاً من ذلك، تستدعي دالة محددة من قبل المستخدم مرة واحدة لكل عنصر في مسار البحث:

static PHYSFS_EnumerateCallbackResult printDir(void *data, const char *origdir, const char *fname)
{
    printf(" * We've got [%s] in [%s].\n", fname, origdir);
    return PHYSFS_ENUM_OK;  // أعطني المزيد من البيانات، من فضلك.
}
// ...
PHYSFS_enumerate("/some/path", printDir, NULL);

العناصر المرسلة إلى دالة الاستدعاء غير مضمون أن تكون بأي ترتيب. لا يتم إجراء أي فرز على هذا المستوى، وإذا كنت بحاجة إلى ذلك، يجب عليك استخدام PHYSFS_enumerateFiles()، التي تضمن الترتيب الأبجدي. هذا الشكل يبلغ عما يتم اكتشافه في كل ملف قبل الانتقال إلى الملف التالي. حتى داخل ملف واحد، لا يمكننا ضمان ترتيب اكتشاف البيانات. * أي فرز تجده في دوال الاستدعاء هذه هو مجرد حظ. لا تعتمد عليه. * نظرًا لأن هذه الدالة تمر عبر قائمة الملفات بأكملها، فقد تتلقى أسماء ملفات مكررة.

واجهة برمجة التطبيقات هذه ودوال الاستدعاء نفسها قادرة على الإبلاغ عن الأخطاء. قبل واجهة برمجة التطبيقات هذه، كان على دوال الاستدعاء قبول كل عنصر تم إحصاؤه، حتى لو كانوا يبحثون فقط عن كائن معين ويريدون التوقف بعد ذلك، أو لديهم خطأ جسيم ولم يتمكنوا من إبلاغ أي شخص. علاوة على ذلك، إذا واجه PhysicsFS نفسه مشكلة (خطأ في القرص أو ما شابه)، فلن يتمكن من إبلاغ التطبيق المستدعي، وسيتعين عليه ببساطة تخطي العناصر أو إنهاء الإحصاء، ولن يعرف المستدعي أنه فقد بعض البيانات أثناء العملية.

الآن يمكن للمستدعي التأكد من حصوله على مجموعة كاملة من البيانات، وإذا كان يريد إيقاف الإحصاء مبكرًا، فإن دالة الاستدعاء الخاصة به تتحكم في ذلك. انظر الوثائق لـ PHYSFS_EnumerateCallback للحصول على تفاصيل حول كيفية تصرف دالة الاستدعاء الخاصة بك.

المعلمات

dir العنوان، بتنسيق مستقل عن النظام الأساسي، المراد إحصاؤه.
c دالة الاستدعاء للإبلاغ عن عناصر مسار البحث.
d بيانات محددة من قبل التطبيق تم تمريرها إلى دالة الاستدعاء. يمكن أن تكون NULL.

القيمة المعادة

غير صفرية عند النجاح، صفر عند الفشل. استخدم PHYSFS_getLastErrorCode() للحصول على الخطأ المحدد. إذا أعادت دالة الاستدعاء PHYSFS_ENUM_STOP للإيقاف مبكرًا، فسيتم اعتبارها نجاحًا. دوال الاستدعاء التي تعيد PHYSFS_ENUM_ERROR ستتسبب في أن تعيد هذه الدالة صفرًا وتعيين رمز الخطأ إلى PHYSFS_ERR_APP_CALLBACK.

NAME

PHYSFS_writeSLE16, PHYSFS_writeSLE32, PHYSFS_writeSLE64, PHYSFS_writeUBE16, PHYSFS_writeUBE32, PHYSFS_writeUBE64 — write integer values in specific endianness to a PHYSFS_File.

SYNOPSIS

#include <physfs.h>

int PHYSFS_writeSLE16( PHYSFS_File *file, PHYSFS_uint16 val)

int PHYSFS_writeSLE32(PHYSFS_File *file, PHYSFS_uint32 val)

Detailed Description

These functions are convenience wrappers around PHYSFS_writeLE16() and PHYSFS_writeBE16() etc. They convert an unsigned integer value from the host's native byte order to the specified endianness (little-endian or big-endian) and then write it to the given PHYSFS_File.
