php-fpm(8)

الحزمة: php-fpm

التراخيص: PHP-3.01

PHP-FPM(8) لغة برمجة نصية PHP-FPM(8)

الاسم

php-fpm - مدير عمليات PHP السريع CGI 'PHP-FPM'

الملخص

php-fpm [خيارات]

الوصف

PHP هي لغة برمجة نصية للأغراض العامة مستخدمة على نطاق واسع وهي مناسبة بشكل خاص لتطوير الويب ويمكن تضمينها في HTML. هذا هو أحد تنويعات PHP التي ستعمل في الخلفية كخادم (daemon)، تستمع لطلبات CGI. يتم تسجيل المخرجات في /var/log/php-fpm.log.

يتم تعيين معظم الخيارات في ملف الإعدادات. ملف الإعدادات هو /etc/php/php-fpm.conf. بشكل افتراضي، سيستجيب php-fpm لطلبات CGI التي تستمع على localhost المنفذ 9000. لذلك، يتوقع php-fpm أن يقوم خادم الويب الخاص بك بإعادة توجيه جميع الطلبات للملفات التي تنتهي بـ '.php' إلى المنفذ 9000 ويجب عليك تحرير ملف إعدادات خادم الويب الخاص بك بشكل مناسب.

الخيارات

-C
لا تقم بتغيير الدليل إلى دليل البرنامج النصي
--php-ini مسار|ملف
-c مسار|ملف
ابحث عن ملف php.ini في الدليل مسار أو استخدم الملف المحدد ملف
--no-php-ini
-n
لن يتم استخدام أي ملف php.ini
--define foo[=bar]
-d foo[=bar]
عرّف إدخال INI foo بالقيمة bar
-e
قم بإنشاء معلومات موسعة للمصحح/المحلل
--help
-h
المساعدة هذه
--info
-i
معلومات وتكوين PHP
--modules
-m
عرض الوحدات المترجمة
--version
-v
رقم الإصدار
--prefix مسار
-p
حدد مسار بادئة بديل (الافتراضي هو /usr)
--pid ملف
-g
حدد موقع ملف PID.
--fpm-config ملف
-y
حدد مسارًا بديلاً لملف تكوين مدير عمليات FastCGI (الافتراضي هو /etc/php/php-fpm.conf)
--test
-t
اختبر ملف تكوين FPM واخرج. إذا تم استدعاؤه مرتين (-tt)، فسيتم تفريغ التكوين قبل الخروج.
--daemonize
-D
فرض التشغيل في الخلفية وتجاهل خيار daemonize من ملف التكوين.
--nodaemonize
-F
فرض البقاء في المقدمة وتجاهل خيار daemonize من ملف التكوين.
--force-stderr
-O
فرض إخراج إلى stderr في nodaemonize حتى لو لم يكن stderr جهازًا طرفيًا.
--allow-to-run-as-root
-R
السماح للمجمع بالتشغيل كـ root (معطل افتراضيًا)

الملفات

php-fpm.conf
ملف التكوين لخادم php-fpm.
php.ini
ملف تكوين PHP القياسي.

أمثلة

لأي أنظمة يونكس تستخدم init.d لمدير العمليات الرئيسي الخاص بها، يجب عليك استخدام البرنامج النصي init المقدم لبدء وإيقاف خادم php-fpm.

sudo /etc/init.d/php-fpm start
لأي أنظمة يونكس تستخدم systemd لمدير العمليات الرئيسي الخاص بها، يجب عليك استخدام ملف الوحدة (unit file) المقدم لبدء وإيقاف خادم php-fpm.
sudo systemctl start php-fpm.service
إذا لم يكن لدى التثبيت الخاص بك برنامج نصي init مناسب، قم بتشغيل php-fpm بدون وسائط. سيتم تشغيله كخادم (عملية خلفية) افتراضيًا. يحدد الملف /var/run/php-fpm.pid ما إذا كان php-fpm قيد التشغيل بالفعل. بمجرد البدء، يستجيب php-fpm للعديد من إشارات POSIX:
SIGINT,SIGTERM إنهاء فوري
SIGQUIT توقف لطيف
SIGUSR1 إعادة فتح ملف السجل
SIGUSR2 إعادة تحميل لطيف لجميع العمال + إعادة تحميل تكوين/ثنائي fpm

نصائح

سيعمل خادم PHP-FPM CGI بشكل جيد مع معظم خوادم الويب الشهيرة، بما في ذلك Apache2 و lighttpd و nginx.

php-fpm(8)

FastCGI Process Manager for PHP

NAME

php-fpm — FastCGI Process Manager for PHP

SYNOPSIS

php-fpm [options]

DESCRIPTION

php-fpm (FastCGI Process Manager) is an alternative PHP FastCGI implementation with additional features useful for busy sites and performance-critical applications.

OPTIONS

This utility has no command line options.

SIGNALS

SIGusr1

Requests all child processes to reload their configuration. It does not interrupt the current requests and does not disconnect users. This is the recommended way to reload the configuration after a change.

SIGusr2

Requests all child processes to terminate gracefully. Existing connections are not killed and requests in progress are completed. New connections are accepted until all child processes have terminated. It is then possible to restart the master process.

SIGterm

Requests all child processes to terminate immediately. Existing connections are killed and requests in progress are aborted. This signal should only be used when a quick shutdown is required.

FILES

/etc/php/php-fpm.conf

Main configuration file for php-fpm.

/etc/php/php-fpm.d/*.conf

Pool configuration files for php-fpm.
