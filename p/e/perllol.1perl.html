شرائح

إذا كنت تريد الوصول إلى شريحة (جزء من صف) في مصفوفة متعددة الأبعاد، فسيتعين عليك القيام ببعض الفهرسة المتقدمة. هذا لأنه بينما لدينا اختصار لطيف للعناصر الفردية عبر سهم المؤشر للرجوع، لا يوجد مثل هذا الملائم للشرائح.

إليك كيفية القيام بعملية واحدة باستخدام حلقة. سنفترض متغير @AoA كما كان من قبل.

@part = ();
$x = 4;
for ($y = 7; $y < 13; $y++) {
    push @part, $AoA[$x][$y];
}

يمكن استبدال نفس الحلقة بعملية شريحة:

@part = $AoA[4]->@[ 7..12 ];

الآن، ماذا لو كنت تريد شريحة ثنائية الأبعاد، مثل أن يمتد $x من 4..8 ويمتد $y من 7 إلى 12؟ هممم... إليك الطريقة البسيطة:

@newAoA = ();
for ($startx = $x = 4; $x <= 8; $x++) {
    for ($starty = $y = 7; $y <= 12; $y++) {
        $newAoA[$x - $startx][$y - $starty] = $AoA[$x][$y];
    }
}

يمكننا تقليل بعض الحلقات من خلال الشرائح

for ($x = 4; $x <= 8; $x++) {
    push @newAoA, [ $AoA[$x]->@[ 7..12 ] ];
}

إذا كنت من محبي تحويلات شوتز، فمن المحتمل أنك اخترت `map` لذلك

@newAoA = map { [ $AoA[$_]->@[ 7..12 ] ] } 4 .. 8;

على الرغم من أنه إذا اتهمك مديرك بالبحث عن الأمان الوظيفي (أو انعدام الأمان السريع) من خلال رمز غير قابل للفهم، فسيكون من الصعب الجدال. :-) إذا كنت مكانك، سأضع ذلك في دالة:

@newAoA = splice_2D( \@AoA, 4 => 8, 7 => 12 );
sub splice_2D {
    my $lrr = shift;        # ref to array of array refs!
    my ($x_lo, $x_hi,
        $y_lo, $y_hi) = @_;
    return map {
        [ $lrr->[$_]->@[ $y_lo .. $y_hi ] ]
    } $x_lo .. $x_hi;
}
