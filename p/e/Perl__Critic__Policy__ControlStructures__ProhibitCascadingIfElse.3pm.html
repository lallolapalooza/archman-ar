Perl__Critic__Policy__ControlStructures__ProhibitCascadingIfElse(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::ControlStructures::ProhibitCascadingIfElse(3pm) وثائق Perl المساهمة من المستخدم Perl::Critic::Policy::ControlStructures::ProhibitCascadingIfElse(3pm)

الاسم

Perl::Critic::Policy::ControlStructures::ProhibitCascadingIfElse - لا تكتب سلاسل طويلة من "if-elsif-elsif-elsif-elsif...else".

الانتماء

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

الوصف

سلاسل "if-elsif" الطويلة يصعب استيعابها، خاصة إذا كانت أطول من صفحة واحدة أو شاشة. إذا كنت تختبر المساواة، استخدم بحثًا في الهاش بدلاً من ذلك.

if ($condition1) {         #موافق
    $foo = 1;
}
elsif ($condition2) {      #موافق
    $foo = 2;
}
elsif ($condition3) {      #موافق
    $foo = 3;
}
elsif ($condition4) {      #كثير جدًا!
    $foo = 4;
}
else {                     #موافق
    $foo = $default;
}

التكوين

يمكن تكوين هذه السياسة بحد أقصى لعدد بدائل "elsif" المسموح بها. القيمة الافتراضية هي 2. يمكن تحديد ذلك عبر عنصر "max_elsif" في ملف .perlcriticrc:

[ControlStructures::ProhibitCascadingIfElse]
max_elsif = 3
