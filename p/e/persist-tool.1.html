persist-tool(1)

الحزمة: syslog-ng

التراخيص: GPL-2.0-or-later, LGPL-2.1-or-later

persist-tool(1) صفحة دليل persist-tool persist-tool(1)

الاسم

persist-tool --- ملف تكوين {{ site.product.short_name }}

ملخص

persist-tool [command] [options]

الوصف

هذه الصفحة الدليلية هي مجرد ملخص.

تطبيق persist-tool هو أداة يمكن استخدامها لتفريغ محتويات ملف persist، والتلاعب بمحتواه.

[](/assets/images/caution.png) **تحذير:** persist-tool هي أداة خاصة لخبراء syslog-ng. لا تستخدم الأداة إلا إذا كنت تعرف بالضبط ما تفعله. سوء تكوينها سيؤدي إلى ضرر لا يمكن إصلاحه لملف persist، دون أي تحذير.

القيود: * لا يمكن استخدام وظائف persist-state إلا مع ملفات persist من نوع SLP4 أو أحدث. الملفات القديمة غير مدعومة. * لا تدعم الأحرف البديلة في أسماء الملفات والأدلة.

أمر dump

dump [options] [persist_file]

استخدم الأمر dump لطباعة المحتوى الحالي لملف persist بتنسيق JSON على الوحدة الطرفية.

الأمر dump لديه الخيارات التالية: * --help أو -?

عرض رسالة مساعدة موجزة.

مثال: persist-tool dump

persist-tool dump /usr/var/syslog-ng.persist

إخراج صالح هو التالي:

run_id = { "value": "00 00 00 00 0C 00 00 00 " }
host_id = { "value": "00 00 00 00 5F 49 2F 01 " }

أمر add

add [options] [input_file]

استخدم الأمر add لإضافة أو تعديل إدخال حالة محدد في ملف persist. يجب أن يكون إدخال الحالة بنفس التنسيق الذي يعرضه الأمر dump. إذا كان إدخال الحالة المعطى موجودًا بالفعل، فسيتم تحديثه. وإلا، فستتم إضافة قيمة جديدة. إذا كانت حالة persist المعطاة غير صالحة، فسيتم تخطيها.

لاستخدام الأمر add: استخدم persist-tool dump لطباعة محتوى ملف persist الحالي، وأعد توجيهه إلى ملف. قم بتحرير محتوى هذا الملف. استخدم persist-tool add مع هذا الملف لتعديل persist.

الأمر add لديه الخيارات التالية: * --help أو -?

عرض رسالة مساعدة موجزة.
•
--output-dir=<directory> أو -o

معامل مطلوب. الدليل الذي يقع فيه ملف persist. يجب أن يكون اسم ملف persist المخزن في هذا الدليل هو syslog-ng.persist.

•
--persist-name=<filename> أو -p

معامل اختياري. اسم ملف persist الذي سيتم إنشاؤه. القيمة الافتراضية: syslog-ng.persist.

مثال: add dump_persist

/usr/bin/persist-tool add dump_persist -o .

إخراج صالح هو التالي:

log_reader_curpos(Application)      OK
affile_sd_curpos(/var/aaa.txt)        OK

إخراج غير صالح هو التالي:

log_reader_curpos(Application)      OK
wrong
FAILED (error: Invalid entry syntax)
affile_sd_curpos(/var/aaa.txt)        OK
