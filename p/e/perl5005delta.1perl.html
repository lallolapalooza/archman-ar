الاسم

perl5005delta — ما الجديد في perl5.005

الوصف

يوثق هذا المستند الاختلافات بين إصدار 5.004 وهذا الإصدار.

حول نظام الإصدار الجديد

يتم تطوير Perl الآن على مسارين: مسار صيانة يقوم بتحديثات صغيرة وآمنة لإصدارات الإنتاج الصادرة مع التركيز على التوافق؛ ومسار تطوير يتابع تطورًا أكثر جرأة. إصدارات الصيانة (التي يجب اعتبارها ذات جودة إنتاج) لديها أرقام إصدارات فرعية تتراوح من 1 إلى 49، وإصدارات التطوير (التي يجب اعتبارها ذات جودة "ألفا") تتراوح من 50 إلى 99.

Perl 5.005 هو المنتج المشترك لنظام التطوير الجديد المزدوج المسار.

التغييرات غير المتوافقة

تحذير: هذا الإصدار غير متوافق ثنائيًا مع Perl 5.004

بدءًا من Perl 5.004_50، كانت هناك العديد من التغييرات العميقة والواسعة النطاق على الهياكل الداخلية للغة. إذا كان لديك امتدادات محملة ديناميكيًا قمت ببنائها تحت perl 5.003 أو 5.004، يمكنك الاستمرار في استخدامها مع 5.004، ولكن ستحتاج إلى إعادة بناء وإعادة تثبيت هذه الامتدادات لاستخدامها مع 5.005. راجع INSTALL للحصول على تعليمات مفصلة حول كيفية الترقية.

تغير هيكل التثبيت الافتراضي

تم تصميم الإعدادات الافتراضية الجديدة لـ Configure للسماح بالترقية السلسة من 5.004 إلى 5.005، ولكن يجب عليك قراءة INSTALL لمناقشة مفصلة للتغييرات للتكيف مع نظامك.

توافق مصدر Perl

عندما لا يتم تمكين أي من الميزات التجريبية، يجب أن تكون هناك قضايا توافق مصدر Perl قليلة جدًا مرئية للمستخدم.

إذا تم تمكين الخيوط (threads)، فإن بعض المحاذير تنطبق. تصبح @_ و $_ متغيرات محلية (lexical variables). يجب أن يكون تأثير ذلك شفافًا إلى حد كبير للمستخدم، ولكن هناك بعض الحالات الحدية التي سيحتاج فيها المستخدمون إلى أن يكونوا على دراية بالقضايا. على سبيل المثال، ينتج local(@_) رسالة "لا يمكن إضفاء الطابع المحلي على متغير محلي @_ ...". قد يتم تمكين هذا في إصدار مستقبلي.

تم تقديم بعض الكلمات المفتاحية الجديدة. من المتوقع بشكل عام أن يكون لهذه الكلمات تأثير ضئيل جدًا على التوافق. انظر "الكلمة المفتاحية الجديدة "INIT""، "الكلمة المفتاحية الجديدة "lock""، و "عامل التشغيل الجديد "qr//"".

بعض الكلمات الفارغة (barewords) محجوزة الآن. سيؤدي استخدام هذه الكلمات إلى إثارة تحذير إذا طلبتها باستخدام التبديل "-w". انظر ""our" هي الآن كلمة محجوزة".

توافق مصدر C

كانت هناك تغييرات كبيرة في الهياكل الداخلية لدعم الميزات الجديدة في هذا الإصدار.

  • مصادر النواة تتطلب الآن مترجم C ANSI

    مترجم C ANSI هو الآن مطلوب لبناء perl. انظر INSTALL.

  • يجب الآن الإشارة إلى جميع متغيرات Perl العامة باستخدام بادئة صريحة

    جميع متغيرات Perl العامة التي يمكن استخدامها بواسطة الامتدادات الآن لها بادئة "PL_". يجب على الامتدادات الجديدة "عدم" الإشارة إلى متغيرات Perl العامة بأسمائها غير المؤهلة. للحفاظ على السلامة، نوفر توافقًا محدودًا للخلف للمتغيرات العامة التي يتم استخدامها على نطاق واسع مثل "sv_undef" و "na" (والتي يجب كتابتها الآن كـ "PL_sv_undef"، "PL_na" إلخ)

    إذا وجدت أن امتداد XS الخاص بك لا يتم تجميعه بعد الآن لأن متغير عام في Perl غير مرئي، فحاول إضافة بادئة "PL_" إلى المتغير العام وأعد البناء.

    يوصى بشدة بالإشارة إلى جميع الوظائف في واجهة برمجة تطبيقات Perl (API) التي لا تبدأ بـ "perl" باستخدام بادئة "Perl_". يتم دعم أسماء الوظائف الفارغة بدون بادئة "Perl_" باستخدام وحدات ماكرو (macros)، ولكن هذا الدعم قد يتوقف في إصدار مستقبلي.

    انظر perlapi.

  • تمكين الخيوط له قضايا توافق المصدر

    يتطلب Perl المبني مع تمكين الخيوط من الامتدادات استخدام الماكرو الجديد "dTHR" لتهيئة المقبض للوصول إلى بيانات لكل خيط. إذا رأيت خطأ في المترجم يتحدث عن المتغير "thr" غير معرّف (عند بناء وحدة تحتوي على كود XS)، فأنت بحاجة إلى إضافة "dTHR;" في بداية الكتلة التي سببت الخطأ.

    يجب استخدام استدعاء واجهة برمجة التطبيقات (API) "perl_get_sv("@",GV_ADD)" بدلاً من الوصول مباشرة إلى متغيرات Perl العامة مثل GvSV(errgv). استدعاء واجهة برمجة التطبيقات متوافق مع الإصدارات السابقة من Perl ويوفر توافق المصدر مع تمكين الخيوط.

    انظر "توافق مصدر C" لمزيد من المعلومات.

التوافق الثنائي

هذا الإصدار غير متوافق ثنائيًا مع الإصدارات الأقدم. يجب إعادة تجميع جميع الامتدادات. علاوة على ذلك، فإن الثنائيات المبنية مع تمكين الخيوط غير متوافقة مع الثنائيات المبنية بدونها. يجب أن يكون هذا شفافًا إلى حد كبير للمستخدم، حيث أن جميع التكوينات غير المتوافقة ثنائيًا لها اسم معماري فريد خاص بها، وتثبت امتدادات الثنائيات في مواقع فريدة. هذا يسمح بالتعايش بين عدة تكوينات في نفس التسلسل الهرمي للمجلدات. انظر INSTALL.

قد تؤثر إصلاحات الأمان على التوافق

تم تصحيح عدد قليل من تسربات التلوث (taint leaks) وإغفالات التلوث (taint omissions). قد يؤدي هذا إلى "فشل" البرامج النصية التي كانت تعمل مع الإصدارات الأقدم. يوفر التجميع باستخدام -DINCOMPLETE_TAINTS نسخة perl مع الحد الأدنى من التغييرات على سلوك التلوث. ولكن لاحظ أن نسخة perl الناتجة ستكون بها ثغرات أمنية معروفة.

لم تعد النصوص ذات السطر الواحد (oneliners) باستخدام التبديل "-e" تنشئ ملفات مؤقتة.

تخفيف التحذيرات الإلزامية الجديدة التي تم تقديمها في 5.004

تم جعل العديد من التحذيرات الجديدة التي تم تقديمها في 5.004 اختيارية. لا تزال بعض هذه التحذيرات موجودة، ولكن الميزات الجديدة في perl تجعلها أقل مشكلة في كثير من الأحيان. انظر "التشخيصات الجديدة".

perl5005delta - changes in Perl 5.005

NAME

perl5005delta - changes in Perl 5.005

DESCRIPTION

This document describes the changes between Perl 5.004 and Perl 5.005.

PORTABILITY

None.

DIAGNOSTICS

None.

MODULES AND DISTRIBUTIONS

The following modules and distributions have been added or significantly updated:

Filter::Simple
A simple interface to Filter::cpp and Filter::grep.
I18N::Collate
Natively comparable strings based on the current locale. Previously experimental.
Module::Build
A new build system for Perl modules, intended to be a replacement for ExtUtils::MakeMaker.
Unicode::Map
A base class for Unicode mapping modules.
Unicode::Map::ISO_8859_1
Mapping between Unicode and ISO 8859-1 (Latin-1).
Unicode::Map::UTF8
Mapping between Unicode and UTF-8.
Unicode::String
A class for representing Unicode strings.
XS::Utils
Utility functions for writing XS code.
Apache::Cookie
A module for handling cookies in Apache.
CGI::Ajax
A module for implementing Ajax functionality in CGI scripts.
DBI
The Database Interface module has been updated to version 1.15.
GD
The GD graphics library module has been updated.
HTML::Parser
A module for parsing HTML documents.
LWP
The Live Web Protocol modules have been updated.
Mail::Sendmail
A module for sending mail using sendmail.
Net::Daemon
A module for creating network daemons.
PerlMagick
The PerlMagick module has been updated.
Pod::Parser
A module for parsing Pod documentation.
Tk
The Tk toolkit module has been updated.
URI
A module for working with URIs.
XML::Parser
A module for parsing XML documents.

UTILITIES

cpan
The CPAN client has been updated to version 1.48.
perlbug
The Perl bug reporting script has been updated.
perldoc
The Pod documentation viewer has been updated.
splain
A module for explaining error messages.

PERFORMANCE

Several performance improvements have been made, including:

  • Faster regular expression matching.
  • Faster string manipulation.
  • Faster subroutine calls.
  • Faster module loading.

INTERNAL CHANGES

The following internal changes have been made:

  • Improved memory management.
  • More consistent internal data structures.
  • Better support for embedding Perl in other applications.

KNOWN PROBLEMS

None.

INSTALLATION

To install Perl 5.005, run the following commands:

./Configure -des
make
make install

ACKNOWLEDGEMENTS

Thanks to the Perl community for their continued support.

AUTHOR

This document was written by Larry Wall.

SEE ALSO

perl(1), perlvar(1)

HISTORY

Perl 5.005 was released on March 29, 1998.
