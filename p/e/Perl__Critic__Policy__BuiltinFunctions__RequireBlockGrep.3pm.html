Perl__Critic__Policy__BuiltinFunctions__RequireBlockGrep(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::BuiltinFunctions::RequireBlockGrep(3pm) User Contributed Perl Documentation Perl::Critic::Policy::BuiltinFunctions::RequireBlockGrep(3pm)

الاسم

Perl::Critic::Policy::BuiltinFunctions::RequireBlockGrep - اكتب "grep { /$pattern/ } @list" بدلاً من "grep /$pattern/, @list".

الانتماء

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

الوصف

نماذج التعبير لـ "grep" و "map" محرجة وصعبة القراءة. استخدم الأشكال الكتلية بدلاً من ذلك.

@matches = grep  /pattern/,    @list;        # ليس جيدًا
@matches = grep { /pattern/ }  @list;        # جيد
@mapped = map  transform($_),    @list;      # ليس جيدًا
@mapped = map { transform($_) }  @list;      # جيد

التكوين

هذه السياسة غير قابلة للتكوين باستثناء الخيارات القياسية.
