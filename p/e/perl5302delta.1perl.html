NAME

perl5302delta - Changes leading to Perl 5.30.2

DESCRIPTION

This document describes the changes leading to Perl 5.30.2. Perl 5.30.2 is a maintenance release of Perl 5.30, containing bug fixes and security patches.

Changes for Perl 5.30.2

This section lists the changes made to Perl between the 5.30.1 and 5.30.2 releases.

Bug Fixes

This release contains numerous bug fixes. Some of the notable ones include:

  • Fixes to the regular expression engine to prevent potential crashes with certain complex patterns.
  • Corrections in the handling of Unicode characters in string operations.
  • Improvements in the performance of file I/O operations.
  • Fixes related to memory management and garbage collection.
  • Updates to various modules in the core distribution.

For a detailed list of all bug fixes, please refer to the Changes file in the Perl source distribution.

Acknowledgements

We would like to thank all the contributors who reported bugs, submitted patches, and otherwise helped to improve Perl.

Reporting Bugs

If you find any bugs in Perl, please report them to the Perl bug tracking system at rt.perl.org.

Give Thanks

If you wish to express your gratitude to the Perl developers, you can do so by contributing to the Perl Foundation or by sending a message of appreciation to the Perl community.

الوصف

التغييرات لـ Perl 5.30.2

يسرد هذا القسم التغييرات التي تم إجراؤها على Perl بين إصداري 5.30.1 و 5.30.2.

إصلاحات الأخطاء

يتضمن هذا الإصدار العديد من إصلاحات الأخطاء. بعض الملاحظات تشمل:

  • تم إصلاح محرك التعبيرات العادية لمنع الأعطال المحتملة مع أنماط معقدة معينة.
  • تم تصحيح التعامل مع أحرف Unicode في عمليات السلاسل النصية.
  • تم تحسين أداء عمليات الإدخال/الإخراج للملفات.
  • تم إصلاح المشكلات المتعلقة بإدارة الذاكرة وجمع البيانات المهملة.
  • تم تحديث الوحدات المختلفة في التوزيع الأساسي.

للحصول على قائمة مفصلة بجميع إصلاحات الأخطاء، يرجى الرجوع إلى ملف Changes في توزيع مصدر Perl.

شكر وتقدير

الإبلاغ عن الأخطاء

إذا وجدت أي أخطاء في Perl، يرجى الإبلاغ عنها في نظام تتبع أخطاء Perl على rt.perl.org.
