Perl__Critic__Policy__RegularExpressions__ProhibitUselessTopic(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::RegularExpressions::ProhibitUselessTopic(3pm) وثائق Perl المساهم بها من قبل المستخدم Perl::Critic::Policy::RegularExpressions::ProhibitUselessTopic(3pm)

الاسم

Perl::Critic::Policy::RegularExpressions::ProhibitUselessTopic - لا تستخدم <$_> للمطابقة مع التعبيرات العادية.

الانتماء

هذه السياسة جزء من توزيع Perl::Critic.

الوصف

ليس من الضروري تحديد متغير الموضوع <$_> عند المطابقة مع تعبير عادي.

تتم عمليات المطابقة أو الاستبدال مقابل المتغيرات، مثل:

$x =~ /foo/;
$x =~ s/foo/bar/;
$x =~ tr/a-mn-z/n-za-m/;

إذا لم يتم تحديد متغير، فإن المطابقة تكون مقابل <$_>.

# هذان متطابقان.
/foo/;
$_ =~ /foo/;
# هذان متطابقان.
s/foo/bar/;
$_ =~ s/foo/bar/;
# هذان متطابقان.
tr/a-mn-z/n-za-m/;
$_ =~ tr/a-mn-z/n-za-m/;

ينطبق هذا أيضًا على المطابقة السلبية.

# هذان متطابقان
if ( $_ !~ /DEBUG/ ) { ...
if ( !/DEBUG ) { ...

يتضمن <"$_ =~"> أو <"$_ !~"> أمر غير ضروري، يضيف تعقيدًا، وليس لغة Perl اصطلاحية.

التكوين

هذه السياسة غير قابلة للتكوين باستثناء الخيارات القياسية.
