Perl__Critic__Policy__NamingConventions__Capitalization(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::NamingConventions::Capitalization(3pm) وثائق مساهمات مستخدمي Perl Perl::Critic::Policy::NamingConventions::Capitalization(3pm)

الاسم

Perl::Critic::Policy::NamingConventions::Capitalization - تمييز مكونات البرنامج المختلفة حسب حالة الأحرف.

الانتماء

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

الوصف

يوصي كونواي بتمييز مكونات البرنامج المختلفة حسب حالة الأحرف.

الإجراءات الفرعية (subroutines) والطرق (methods) والمتغيرات العادية كلها بأحرف صغيرة.

my $foo;            # موافق
my $foo_bar;        # موافق
sub foo {}          # موافق
sub foo_bar {}      # موافق
my $Foo;            # غير موافق
my $foo_Bar;        # غير موافق
sub Foo     {}      # غير موافق
sub foo_Bar {}      # غير موافق

أسماء الحزم والفئات (packages and class names) تكون بأحرف كبيرة.

package IO::Thing;     # موافق
package Web::FooBar    # موافق
package foo;           # غير موافق
package foo::Bar;      # غير موافق

الثوابت (Constants) تكون بأحرف كبيرة بالكامل.

Readonly::Scalar my $FOO = 42;  # موافق
Readonly::Scalar my $foo = 42;  # غير موافق

هناك آراء أخرى حول التفاصيل، على سبيل المثال، في perlstyle. يمكن تكوين هذه السياسة لتتناسب مع أي نمط يمكنك التفكير فيه تقريبًا.

التكوين

يمكنك تحديد قواعد حالة الأحرف للأشياء التالية: "packages" (الحزم)، "subroutines" (الإجراءات الفرعية)، "local_lexical_variables" (المتغيرات المعجمية المحلية)، "scoped_lexical_variables" (المتغيرات المعجمية ذات النطاق)، "file_lexical_variables" (المتغيرات المعجمية للملف)، "global_variables" (المتغيرات العامة)، "constants" (الثوابت)، و "labels" (التسميات).

"constants" هي أشياء معرّفة عبر constant أو Readonly.

use constant FOO => 193;
Readonly::Array my @BAR => qw< a b c >;

"global_variables" هي أي شيء معرّف باستخدام "local"، "our"، أو vars. "file_lexical_variables" هي متغيرات معرّفة في نطاق الملف.

"scoped_lexical_variables" هي متغيرات معرّفة داخل كتل فارغة ليست داخل أي إجراءات فرعية أو هياكل تحكم أخرى؛ هذه تُنشأ عادةً للحد من نطاق المتغيرات لمجموعة معينة من الإجراءات الفرعية. على سبيل المثال:

sub foo { ... }
{
    my $thingy;
    sub bar { ... $thingy ... }
    sub baz { ... $thingy ... }
}

جميع تعريفات المتغيرات الأخرى تعتبر "local_lexical_variables".

كل من خيارات "packages"، "subroutines"، "local_lexical_variables"، "scoped_lexical_variables"، "file_lexical_variables"، "global_variables"، "constants"، و "labels" يمكن تحديدها كواحدة من ":single_case"، ":all_lower"، ":all_upper:"، ":starts_with_lower"، ":starts_with_upper"، أو ":no_restriction" أو تعبير نمطي (regular expression)؛ أي قيمة لا تبدأ بنقطتين رأسيتين، ":"، تعتبر تعبيرًا نمطيًا. العلامة ":single_case" تعني أن الاسم يمكن أن يكون بأحرف صغيرة بالكامل أو بأحرف كبيرة بالكامل. إذا تم تحديد تعبير نمطي، فإنه محاط بـ "\A" و "\z".

افتراضيات "packages" هي ":starts_with_upper". افتراضيات "subroutines"، "local_lexical_variables"، "scoped_lexical_variables"، "file_lexical_variables"، و "global_variables" هي ":single_case". وافتراضيات "constants" و "labels" هي ":all_upper".

هناك خيارات مقابلة "package_exemptions"، "subroutine_exemptions"، "local_lexical_variable_exemptions"، "scoped_lexical_variable_exemptions"، "file_lexical_variable_exemptions"، "global_variable_exemptions"، "constant_exemptions"، و "label_exemptions" وهي قوائم من التعبيرات النمطية للاستثناء من قاعدة حالة الأحرف المقابلة. تنتهي هذه القيم أيضًا بكونها محاطة بـ "\A" و "\z".

افتراضيات "package_exemptions" هي "main". افتراضيات "global_variable_exemptions" هي "\$VERSION @ISA @EXPORT(?:_OK)? %EXPORT_TAGS \$AUTOLOAD %ENV %SIG \$TODO". افتراضيات "subroutine_exemptions" هي "AUTOLOAD BUILD BUILDARGS CLEAR CLOSE DELETE DEMOLISH DESTROY EXISTS EXTEND FETCH FETCHSIZE FIRSTKEY GETC NEXTKEY POP PRINT PRINTF PUSH READ READLINE SCALAR SHIFT SPLICE STORE STORESIZE TIEARRAY TIEHANDLE TIEHASH TIESCALAR UNSHIFT UNTIE WRITE" والتي يجب أن تغطي جميع الإجراءات الفرعية القياسية في Perl بالإضافة إلى تلك من Moose.

لاحظ أن "package_exemptions" لا تتحقق من أسماء الحزم الكاملة. بالنسبة لـ "Foo::Bar::baz"، ستتحقق من "Foo"، "Bar" و "baz" بالتتابع.

على سبيل المثال، إذا كنت تريد أن تكون جميع المتغيرات المحلية بأحرف صغيرة بالكامل وأن تبدأ المتغيرات العامة بـ "G_" وبخلاف ذلك لا تحتوي على شرطات سفلية، ولكن تستثني أي متغير اسمه يحتوي على "THINGY"، يمكنك وضع ما يلي في ملف .perlcriticrc الخاص بك:

[NamingConventions::Capitalization]
local_lexical_variables = :all_lower
global_variables = G_(?:(?!_)\w)+
global_variable_exemptions = .*THINGY.*

قيد الإنجاز

معالجة "use vars". معاملة الإجراءات الفرعية الثابتة مثل المتغيرات الثابتة. معالجة مقابض الملفات الفارغة. هناك حاجة إلى "مخططات" أو طرق لتحديد "perlstyle" أو "pbp". التفريق بين الثوابت المعجمية Readonly في النطاقات.

الأخطاء

لن تلتقط هذه السياسة مشاكل في تعريف $y أدناه:

for (my $x = 3, my $y = 5; $x < 57; $x += 3) {
    ...
}
