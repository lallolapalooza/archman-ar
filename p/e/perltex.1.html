NAME

perltex - PerlTEX

SYNOPSIS

perltex [options] [files]

DESCRIPTION

PerlTEX is a typesetting system that integrates Perl code into LaTeX documents. It allows you to generate dynamic content, perform complex calculations, and automate repetitive tasks within your LaTeX documents.

OPTIONS

-v, --version
Display version information and exit.
-h, --help
Display help message and exit.
-o output_file, --output=output_file
Specify the output file name.
-I dir
Add a directory to Perl's include path (@INC).

EXAMPLES

# Compile a LaTeX document with embedded Perl code
perltex mydocument.tex

# Compile and specify the output file
perltex -o output.pdf mydocument.tex

ENVIRONMENT

PERLTEX_LIB: A colon-separated list of directories to search for Perl modules.

FILES

.perltexrc: Configuration file for PerlTEX.

NOTES

Ensure that you have both Perl and a LaTeX distribution installed on your system.

SEE ALSO

latex(1), perl(1)

الاسم

perltex - PerlTEX

الملخص

perltex [خيارات] [ملفات]

الوصف

PerlTEX هو نظام تنضيد يدمج كود Perl في مستندات LaTeX. يسمح لك بإنشاء محتوى ديناميكي، وإجراء حسابات معقدة، وأتمتة المهام المتكررة داخل مستندات LaTeX الخاصة بك.

الخيارات

-v, --version
عرض معلومات الإصدار والخروج.
-h, --help
عرض رسالة المساعدة والخروج.
-o ملف_الإخراج, --output=ملف_الإخراج
تحديد اسم ملف الإخراج.
-I مجلد
إضافة مجلد إلى مسار تضمين Perl (@INC).

أمثلة

# تجميع مستند LaTeX مع كود Perl مضمن
perltex mydocument.tex

# تجميع وتحديد ملف الإخراج
perltex -o output.pdf mydocument.tex

البيئة

PERLTEX_LIB: قائمة مفصولة بنقطتين (:) للمجلدات التي يجب البحث فيها عن وحدات Perl.

الملفات

.perltexrc: ملف تكوين لـ PerlTEX.

ملاحظات

تأكد من تثبيت كل من Perl وتوزيع LaTeX على نظامك.

انظر أيضًا

latex(1), perl(1)
