Perl__Critic__Policy__References__ProhibitDoubleSigils(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::References::ProhibitDoubleSigils(3pm) وثائق Perl التي ساهم بها المستخدم Perl::Critic::Policy::References::ProhibitDoubleSigils(3pm)

الاسم

Perl::Critic::Policy::References::ProhibitDoubleSigils - اكتب "@{ $array_ref }" بدلاً من "@$array_ref".

الانتماء

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

الوصف

عند إلغاء مرجعية مرجع، ضع أقواسًا حول المرجع لفصل العلامات. خاصة للمبتدئين، الأقواس تلغي أي ارتباك محتمل حول الأسبقية النسبية للعلامات.

push @$array_ref, 'foo', 'bar', 'baz';      # ليس جيداً
push @{ $array_ref }, 'foo', 'bar', 'baz';  # جيد
foreach ( keys %$hash_ref ){}               # ليس جيداً
foreach ( keys %{ $hash_ref } ){}           # جيد

الإعداد

هذه السياسة غير قابلة للتكوين باستثناء الخيارات القياسية.
