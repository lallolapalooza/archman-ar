Perl__Critic__Utils(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Utils(3pm) وثائق Perl المساهم بها من قبل المستخدم Perl::Critic::Utils(3pm)

الاسم

Perl::Critic::Utils - إجراءات مساعدة عامة وثوابت لـ Perl::Critic والتوزيعات المشتقة.

الوصف

توفر هذه الوحدة عدة إجراءات ثابتة ومتغيرات مفيدة لتطوير فئات Perl::Critic::Policy الفرعية. ما لم تكن تكتب وحدات Policy، فمن المحتمل ألا تهتم بهذه الحزمة.

دعم الواجهة

تعتبر هذه وحدة عامة. أي تغييرات على واجهتها ستمر بدورة إهمال.

إجراءات قابلة للاستيراد

"find_keywords( $doc, $keyword )"
مهمل: منذ الإصدار 0.11، يتم تقييم كل Policy عند كل عنصر في المستند. لذلك لا ينبغي لك البحث عن كلمة مفتاحية معينة. إذا كنت *ترغب* في استخدام هذا، يرجى استيراده عبر العلامة ":deprecated"، بدلاً من استيراده مباشرة، لوضع علامة على الوحدة بأنها بحاجة إلى تحديث.

بالنظر إلى مستند PPI::Document كـ $doc، تعيد مرجعًا إلى مصفوفة تحتوي على جميع عناصر PPI::Token::Word التي تطابق $keyword. يمكن استخدام هذا للعثور على أي دالة مدمجة، أو استدعاء طريقة، أو كلمة مجردة، أو كلمة مفتاحية محجوزة. لن تطابق المتغيرات، أو أسماء الروتين الفرعي، أو السلاسل النصية الحرفية، أو الأرقام، أو الرموز. إذا لم يحتو المستند على أي مطابقات، تعيد undef.

is_assignment_operator( $element )
بالنظر إلى PPI::Token::Operator أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل أحد عوامل التعيين (على سبيل المثال، "= &&= ||= //= += -= " إلخ).
is_perl_global( $element )
بالنظر إلى PPI::Token::Symbol أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل أحد المتغيرات العامة التي توفرها وحدة English، أو أحد المتغيرات العامة المدمجة مثل %SIG، %ENV، أو @ARGV. يتم تجاهل الإشارة على الرمز، لذلك الأشياء مثل $ARGV أو $ENV ستعيد true.
is_perl_builtin( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة.
is_perl_bareword( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل كلمة مجردة (على سبيل المثال، "if"، "else"، "sub"، "package").
is_perl_filehandle( $element )
بالنظر إلى PPI::Token::Word، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل أحد مقابض الملفات العامة (على سبيل المثال، "STDIN"، "STDERR"، "STDOUT"، "ARGV"). لاحظ أن هذه الدالة ستعيد false إذا تم إعطاؤها مقبض ملف ممثل كـ typeglob (على سبيل المثال، *STDIN)
is_perl_builtin_with_list_context( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة التي توفر سياق قائمة (list context) للعناصر التالية.
is_perl_builtin_with_multiple_arguments( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة التي *يمكن* أن تأخذ وسائط متعددة.
is_perl_builtin_with_no_arguments( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة التي *لا يمكن* أن تأخذ أي وسائط.
is_perl_builtin_with_one_argument( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة التي تأخذ وسيطًا *واحدًا وفقط*.
is_perl_builtin_with_optional_argument( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة التي تأخذ *لا تزيد عن وسيط واحد*.

مجموعات القيم التي تعيد لها is_perl_builtin_with_multiple_arguments()، is_perl_builtin_with_no_arguments()، is_perl_builtin_with_one_argument()، و is_perl_builtin_with_optional_argument() قيمة true هي مجموعات منفصلة واتحادها هو بالضبط مجموعة القيم التي تعيد لها is_perl_builtin() قيمة true.

is_perl_builtin_with_zero_and_or_one_arguments( $element )
بالنظر إلى PPI::Token::Word، أو PPI::Statement::Sub، أو سلسلة نصية، تعيد true إذا كان هذا الرمز يمثل استدعاء لأي من الدوال المدمجة التي تأخذ صفرًا و/أو وسيطًا واحدًا.

تعيد true إذا كانت أي من is_perl_builtin_with_no_arguments()، is_perl_builtin_with_one_argument()، و is_perl_builtin_with_optional_argument() تعيد true.

is_qualified_name( $name )
بالنظر إلى سلسلة نصية، أو PPI::Token::Word، أو PPI::Token::Symbol، تجيب عما إذا كانت تحتوي على مكون وحدة، أي تحتوي على "::".
precedence_of( $element )
بالنظر إلى PPI::Token::Operator أو سلسلة نصية، تعيد أسبقية المعامل، حيث 1 هي أعلى أسبقية. تعيد undef إذا تعذر تحديد الأسبقية (وهو ما يحدث عادة لأنه ليس معاملًا).
is_hash_key( $element )
بالنظر إلى PPI::Element، تعيد true إذا كان العنصر مفتاح HashMap حرفي. لا تفرق PPI بين الكلمات المجردة العادية (مثل الكلمات المفتاحية أو استدعاءات الروتين الفرعي) والكلمات المجردة في مؤشرات HashMap (التي تعتبر حرفية). لذلك هذه الإجراءات المساعدة مفيدة إذا كانت Policy الخاصة بك تبحث عن عناصر PPI::Token::Word وتريد تصفية نوع مؤشر HashMap. في كلا المثالين التاليين، يعتبر "foo" مفتاح HashMap: 
$hash1{foo} = 1;
%hash2 = (foo => 1);

ولكن إذا اتبعت الكلمة المجردة بقائمة وسائط، فإن perl تعاملها كاستدعاء دالة. لذا في هذه الأمثلة، "foo" *ليست* تعتبر مفتاح HashMap:

$hash1{ foo() } = 1;
&hash2 = (foo() => 1);
is_included_module_name( $element )
بالنظر إلى PPI::Token::Word، تعيد true إذا كان العنصر هو اسم وحدة يتم تضمينها عبر "use"، أو "require"، أو "no".
is_integer( $value )
تجيب عما إذا كان المعلمة، كسلسلة نصية، تبدو كقيمة عدد صحيح.
is_class_name( $element )
بالنظر إلى PPI::Token::Word، تعيد true إذا كان العنصر الذي يتبع هذا العنصر مباشرة هو عامل إلغاء المرجع "->". عندما يكون للكلمة المجردة "->" على الجانب *الأيمن*، فهذا يعني عادةً أنها اسم الفئة (التي يتم استدعاء طريقة منها).
is_label_pointer( $element )
بالنظر إلى PPI::Token::Word، تعيد true

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

"next"، "last"، "redo"، أو "goto". لاحظ أن هذا ليس هو نفس الشيء مثل تعريف التسمية.
is_method_call( $element )
بالنظر إلى PPI::Token::Word، يعيد صحيحًا إذا كان العنصر الذي يسبق هذا العنصر مباشرة هو عامل الإلغاء "&ndash;&gt;". عندما يكون للكلمة المجردة "&ndash;&gt;" على الجانب **الأيسر**، فإنها تعني عادةً أنها اسم طريقة (يتم استدعاؤها من فئة).
is_package_declaration( $element )
بالنظر إلى PPI::Token::Word، يعيد صحيحًا إذا كان العنصر اسم حزمة يتم تعريفها.
is_subroutine_name( $element )
بالنظر إلى PPI::Token::Word، يعيد صحيحًا إذا كان العنصر اسم تعريف روتين فرعي. هذا مفيد للتمييز بين الكلمات المجردة واستدعاءات الدوال عن تعريفات الروتين الفرعي.
is_function_call( $element )
بالنظر إلى PPI::Token::Word، يعيد صحيحًا إذا كان العنصر يبدو كاستدعاء لدالة ثابتة. على وجه التحديد، تعيد هذه الدالة صحيحًا إذا كانت "is_hash_key"، "is_method_call"، "is_subroutine_name"، "is_included_module_name"، "is_package_declaration"، "is_perl_bareword"، "is_perl_filehandle"، "is_label_pointer"، و "is_subroutine_name" كلها تعيد خطأ للعنصر المعطى.
first_arg( $element )
بالنظر إلى PPI::Element الذي يُفترض أنه استدعاء دالة (وهو عادةً PPI::Token::Word)، يعيد الوسيط الأول. هذا مشابه لـ parse_arg_list() ويتبع نفس المنطق. لاحظ أنه بالنسبة للشفرة: 
int($x + 0.5)

ستعيد هذه الدالة $x فقط، وليس التعبير بأكمله. هذا يختلف عن سلوك parse_arg_list(). تنبيه آخر هو:

int(($x + $y) + 0.5)

الذي يعيد "($x + $y)" كـ PPI::Structure::List.

parse_arg_list( $element )
بالنظر إلى PPI::Element الذي يُفترض أنه استدعاء دالة (وهو عادةً PPI::Token::Word)، يقسم تعبيرات الوسائط إلى صفائف من الرموز. يعيد قائمة تحتوي على مراجع لكل من تلك الصفائف. هذا مفيد لأن الأقواس اختيارية عند استدعاء دالة، و PPI يحللها بشكل مختلف جدًا. لذلك، هذه الطريقة هي شجرة تحليل فقيرة. إنها ليست مضمونة لأنها لا تحترم الأسبقية. بشكل عام، أنا لا أحب الطريقة التي تعمل بها هذه الدالة، لذلك لا تعتمد عليها لتكون مستقرة (أو موجودة).
split_nodes_on_comma( @nodes )
هذه لها نفس نوع الإرجاع مثل parse_arg_list() ولكنها تتوقع أن يتم تمرير العقد التي تمثل داخل القائمة، مثل: 
'foo', 1, 2, 'bar'
is_script( $document )
**تم إهمال هذه الروتين الفرعي وستتم إزالته في إصدار مستقبلي.** يجب عليك استخدام طريقة "is_program()" في Perl::Critic::Document بدلاً من ذلك.
is_in_void_context( $token )
بالنظر إلى PPI::Token، أجب عما إذا كان يبدو أنه في سياق فارغ.
policy_long_name( $policy_name )
بالنظر إلى اسم فئة السياسة بالشكل الطويل أو القصير، يعيد الشكل الطويل.
policy_short_name( $policy_name )
بالنظر إلى اسم فئة السياسة بالشكل الطويل أو القصير، يعيد الشكل القصير.
all_perl_files( @directories )
بالنظر إلى قائمة الدلائل، يبحث بشكل متكرر في جميع الدلائل (من الأعلى إلى الأسفل) ويعيد قائمة بمسارات لجميع الملفات التي هي ملفات رمز Perl. يتم تخطي أي ملفات إدارية لـ CVS أو Subversion، وكذلك الأشياء التي تبدو ملفات مؤقتة أو احتياطية.

ملف رمز Perl هو:

  • أي ملف ينتهي بـ .PL، .pl، .pm، .psgi، أو .t
  • أي ملف يحتوي على سطر أول مع shebang يحتوي على 'perl'
severity_to_number( $severity )
إذا تم تقديم $severity كرقم صحيح، تعيد هذه الدالة $severity ولكن تم تطبيعه ليكون بين $SEVERITY_LOWEST و $SEVERITY_HIGHEST. إذا تم تقديم $severity كسلسلة نصية، تعيد هذه الدالة رقم الشدة المقابل. إذا لم يكن للسلسلة النصية رقم مقابل، فستقوم هذه الدالة بإلقاء استثناء.
is_valid_numeric_verbosity( $severity )
يجيب عما إذا كان الوسيط له ترجمة إلى تنسيق انتهاك.
verbosity_to_format( $verbosity_level )
بالنظر إلى مستوى الإسهاب بين 1 و 10، يعيد سلسلة التنسيق المحددة مسبقًا المقابلة. هذه التنسيقات مناسبة للتمرير إلى طريقة "set_format" في Perl::Critic::Violation. راجع وثائق perlcritic للحصول على قائمة بالتنسيقات المحددة مسبقًا.
hashify( @list )
بالنظر إلى @list، يعيد هاش حيث تكون @list هي المفاتيح وكل قيمة هي 1. يتم تجاهل القيم المكررة في @list بصمت.
interpolate( $literal )
بالنظر إلى سلسلة نصية $literal قد تحتوي على أحرف تحكم (مثل '\t' '\n')، تقوم هذه الدالة بعمل استيفاء مزدوج على السلسلة النصية وتعيدها كما لو كانت قد تم تعريفها في علامتي اقتباس مزدوجتين. على سبيل المثال: 
'foo \t bar \n' ...becomes... "foo \t bar \n"
shebang_line( $document )
بالنظر إلى PPI::Document، اختبر ما إذا كان يبدأ بـ "#!". إذا كان الأمر كذلك، فإنه يعيد هذا السطر. وإلا، فإنه يعيد undef.
words_from_string( $str )
بالنظر إلى سلسلة التكوين $str، يعيد جميع الكلمات من السلسلة. هذا أكثر أمانًا من التقسيم على المسافات البيضاء.
"is_unchecked_call( $element, $autodie_modules )"
بالنظر إلى PPI::Element، اختبر ما إذا كان يحتوي على استدعاء دالة لا يتم التحقق من قيمتها المرجعة. الوسيط الثاني هو مرجع صفيف لأسماء الوحدات التي تصدر "autodie". يتم تضمين الوحدة "autodie" دائمًا في هذه القائمة بشكل افتراضي.

توفر ثوابت الأحرف هذه أسماء واضحة للسلاسل النصية شائعة الاستخدام التي قد يكون من الصعب قراءتها عند إحاطتها بعلامات اقتباس وعلامات ترقيم أخرى. يمكن استيرادها دفعة واحدة عبر الوسم ":characters".

تحدد ثوابت الأرقام هذه الشدة النسبية لانتهاك كل Perl::Critic::Policy. يجب أن تعيد طريقتي "get_severity" و "default_severity" لكل فئة فرعية من Policy إحدى هذه القيم. يمكن استيرادها عبر الوسم ":severities".
$DEFAULT_VERBOSITY
مستوى الإسهاب الرقمي الافتراضي.
$DEFAULT_VERBOSITY_WITH_FILE_NAME
مستوى الإسهاب الرقمي الذي يتوافق مع التنسيق المشار إليه بواسطة $DEFAULT_VERBOSITY، ولكن مع اسم الملف مسبوقًا به.
$TRUE
$FALSE
هذه قيم منطقية بسيطة. 1 و 0 على التوالي. كن حذرًا عند استخدامها مع المساواة السلسلة النصية. "$FALSE ne $EMPTY". يمكن استيرادها عبر الوسم ":booleans".

IMPORT TAGS

":constants"
The constants used by Perl::Critic.

Includes: $SCOLON, $SPACE, $SLASH, $BSLASH $LEFT_PAREN $RIGHT_PAREN

":classification"
Includes: "is_assignment_operator", "is_class_name", "is_function_call", "is_hash_key", "is_included_module_name", "is_integer", "is_label_pointer", "is_method_call", "is_package_declaration", "is_perl_bareword", "is_perl_builtin", "is_perl_filehandle", "is_perl_global", "is_perl_builtin_with_list_context" "is_perl_builtin_with_multiple_arguments" "is_perl_builtin_with_no_arguments" "is_perl_builtin_with_one_argument" "is_perl_builtin_with_optional_argument" "is_perl_builtin_with_zero_and_or_one_arguments" "is_qualified_name", "is_script", "is_subroutine_name", "is_unchecked_call" "is_valid_numeric_verbosity"

See also Perl::Critic::Utils::PPI.

":data_conversion"
Generic manipulation, not having anything specific to do with Perl::Critic.

Includes: "hashify", "words_from_string", "interpolate"

":ppi"
Things for dealing with PPI, other than classification.

Includes: "first_arg", "parse_arg_list"

See also Perl::Critic::Utils::PPI.

":internal_lookup"
Translations between internal representations.

Includes: "severity_to_number", "verbosity_to_format"

":language"
Information about Perl not programmatically available elsewhere.

Includes: "precedence_of"

":deprecated"
Not surprisingly, things that are deprecated. It is preferred to use this tag to get to these functions, rather than the function names themselves, so as to mark any module using them as needing cleanup.

Includes: "find_keywords"
