PERLUNICOOK(1perl) دليل مبرمجي Perl PERLUNICOOK(1perl)

الاسم

perlunicook - أمثلة طبخ عامة للتعامل مع Unicode في Perl

الوصف

تحتوي صفحة الدليل هذه على وصفات قصيرة توضح كيفية التعامل مع عمليات Unicode الشائعة في Perl، بالإضافة إلى برنامج كامل في النهاية. يُفترض أن أي متغيرات غير معلنة في الوصفات الفردية تحتوي على قيمة مناسبة سابقة.

أمثلة

℞ 0: مقدمة قياسية

ما لم يُذكر خلاف ذلك، تتطلب جميع الأمثلة أدناه هذه المقدمة القياسية لتعمل بشكل صحيح، مع تعديل "#!" للعمل على نظامك:

#!/usr/bin/env perl
use v5.36;     # أو أحدث للحصول على ميزة "unicode_strings"،
               #   بالإضافة إلى strict، warnings
use utf8;      # حتى يمكن أن تكون النصوص الحرفية والمعرفات في UTF-8
use warnings  qw(FATAL utf8);    # تحويل مشاكل الترميز إلى أخطاء قاتلة
use open      qw(:std :encoding(UTF-8)); # تدفقات غير معلنة في UTF-8
use charnames qw(:full :short);  # غير مطلوب في v5.16

هذا *يجعل* حتى مبرمجي Unix يقومون بعمل "binmode" لتدفقاتهم الثنائية، أو فتحها باستخدام ":raw"، ولكن هذه هي الطريقة الوحيدة للوصول إليها بشكل قابل للنقل على أي حال.

تحذير: "use autodie" (قبل 2.26) و "use open" لا يتوافقان مع بعضهما البعض.

℞ 1: مرشح عام ذكي بـ Unicode

قم دائمًا بتفكيك البيانات عند الدخول، ثم إعادة تجميعها عند الخروج.

use Unicode::Normalize;
while (<>) {
    $_ = NFD($_);   # تفكيك + إعادة ترتيب معيارية
    ...
} continue {
    print NFC($_);  # إعادة تجميع (حيثما أمكن) + إعادة ترتيب معيارية
}

℞ 2: ضبط تحذيرات Unicode بدقة

اعتبارًا من v5.14، يميز Perl ثلاث فئات فرعية من تحذيرات UTF-8.

use v5.14;                  # تحذيرات فرعية غير متاحة قبل ذلك
no warnings "nonchar";      # 66 حرفًا غير حرفي محظور
no warnings "surrogate";    # تفاهات UTF-16/CESU-8
no warnings "non_unicode";  # لنقاط الترميز فوق 0x10_FFFF

℞ 3: إعلان المصدر بـ utf8 للمعories والنصوص الحرفية

بدون الإعلان الحاسم "use utf8"، لن تعمل الأحرف في النصوص الحرفية والمعرفات بشكل صحيح. إذا كنت تستخدم المقدمة القياسية المذكورة أعلاه، فقد حدث هذا بالفعل. إذا فعلت ذلك، يمكنك القيام بأشياء مثل هذه:

use utf8;
my $measure   = "Ångström";
my @μsoft     = qw( cp852 cp1251 cp1252 );
my @ὑπέρμεγας = qw( ὑπέρ  μεγας );
my @鯉        = qw( koi8-f koi8-u koi8-r );
my $motto     = "👪 💗 🐪"; # عائلة، قلب متزايد، جمل

إذا نسيت "use utf8"، فسيتم إساءة تفسير البايتات العالية كأحرف منفصلة، ولن يعمل أي شيء بشكل صحيح.

℞ 4: الأحرف وأرقامها

تعمل الوظائف "ord" و "chr" بشفافية على جميع نقاط الترميز، وليس فقط على ASCII وحده - ولا حتى على Unicode وحده.

# أحرف ASCII
ord("A")
chr(65)
# أحرف من لوحة الأحرف الأساسية متعددة اللغات
ord("Σ")
chr(0x3A3)
# ما وراء BMP
ord("𝑛")               # حرف N صغير مائل رياضي
chr(0x1D45B)
# ما وراء Unicode! (حتى MAXINT)
ord("\x{20_0000}")
chr(0x20_0000)

℞ 5: نصوص حرفية Unicode حسب رقم الحرف

في نص حرفي مُدمج، سواء كان سلسلة نصية مزدوجة الاقتباس أو تعبيرًا عاديًا، يمكنك تحديد حرف برقم باستخدام الهروب "\x{HHHHHH}".

String: "\x{3a3}"
Regex:  /\x{3a3}/
String: "\x{1d45b}"
Regex:  /\x{1d45b}/
# حتى النطاقات غير BMP في التعبيرات العادية تعمل بشكل جيد
/[\x{1D434}-\x{1D467}]/

℞ 6: الحصول على اسم الحرف حسب رقمه

use charnames ();
my $name = charnames::viacode(0x03A3);

℞ 7: الحصول على رقم الحرف حسب اسمه

use charnames ();
my $number = charnames::vianame("GREEK CAPITAL LETTER SIGMA");

℞ 8: أسماء أحرف Unicode

استخدم ترميز "\N{charname}" للحصول على الحرف بهذا الاسم لاستخدامه في النصوص الحرفية المدمجة (السلاسل النصية المزدوجة الاقتباس والتعبيرات العادية). في v5.16، يوجد ضمنيًا

use charnames qw(:full :short);

ولكن قبل v5.16، يجب عليك التصريح صراحةً عن مجموعة أسماء الأحرف التي تريدها. أسماء ":full" هي اسم حرف Unicode الرسمي، أو الاسم المستعار، أو التسلسل، والتي تشترك جميعها في مساحة اسم واحدة.

use charnames qw(:full :short latin greek);
"\N{MATHEMATICAL ITALIC SMALL N}"      # :full
"\N{GREEK CAPITAL LETTER SIGMA}"       # :full

أي شيء آخر هو اختصار مريح خاص بـ Perl. حدد نصًا واحدًا أو أكثر بالأسماء إذا كنت تريد أسماء مختصرة خاصة بالنص.

"\N{Greek:Sigma}"                      # :short
"\N{ae}"                               #  latin
"\N{epsilon}"                          #  greek

يدعم إصدار v5.16 أيضًا استيراد ":loose" لمطابقة أسماء الأحرف بشكل غير صارم، والذي يعمل تمامًا مثل المطابقة غير الصارمة لأسماء الخصائص: أي أنه يتجاهل حالة الأحرف والمسافات البيضاء والشرطات السفلية:

"\N{euro sign}"                        # :loose (من v5.16)

بدءًا من v5.32، يمكنك أيضًا استخدام

qr/\p{name=euro sign}/

للحصول على أسماء أحرف Unicode الرسمية في التعبيرات العادية. تتم المطابقة غير الصارمة دائمًا لهذه.

℞ 9: تسلسلات Unicode المسماة

تبدو هذه مثل أسماء الأحرف تمامًا ولكنها تُرجع أحرفًا متعددة. لاحظ وظيفة طباعة المتجه %vx في "printf".

use charnames qw(:full);
my $seq = "\N{LATIN CAPITAL LETTER A WITH MACRON AND GRAVE}";
printf "U+%v04X\n", $seq;
U+0100.0300

℞ 10: أحرف مخصصة مسماة

استخدم ":alias" لإعطاء أسماء مستعارة مجددة تعتمد على النطاق الزمني الخاص بك للأحرف الموجودة، أو حتى لإعطاء الأحرف الخاصة غير المسماة أسماء مفيدة.

use charnames ":full", ":alias" => {
    ecute => "LATIN SMALL LETTER E WITH ACUTE",
    "APPLE LOGO" => 0xF8FF, # حرف خاص للاستخدام الخاص
};
"\N{ecute}"
"\N{APPLE LOGO}"

℞ 11: أسماء نقاط ترميز CJK

تأتي الرموز الصينية مثل «東京» بأسماء أحرف مثل "CJK UNIFIED IDEOGRAPH-6771" و "CJK UNIFIED IDEOGRAPH-4EAC"، لأن «أسماءها» تختلف. تحتوي وحدة CPAN "Unicode::Unihan" على قاعدة بيانات كبيرة لفك تشفير هذه (وغيرها الكثير)، بشرط أن تعرف كيف تفهم مخرجاتها.

# cpan -i Unicode::Unihan
use Unicode::Unihan;
my $str = "東京";
my $unhan = Unicode::Unihan->new;
for my $lang (qw(Mandarin Cantonese Korean JapaneseOn JapaneseKun)) {
    printf "CJK $str in %-12s is ", $lang;
    say $unhan->$lang($str);
}

يطبع:

CJK 東京 in Mandarin     is DONG1JING1
CJK 東京 in Cantonese    is dung1ging1
CJK 東京 in Korean       is TONGKYENG
CJK 東京 in JapaneseOn   is TOUKYOU KEI KIN
CJK 東京 in JapaneseKun  is HIGASHI AZUMAMIYAKO

إذا كان لديك مخطط تحويل صوتي محدد في ذهنك، فاستخدم الوحدة المحددة:

# cpan -i Lingua::JA::Romanize::Japanese
use Lingua::JA::Romanize::Japanese;
my $k2r = Lingua::JA::Romanize::Japanese->new;
my $str = "東京";
say "Japanese for $str is ", $k2r->chars($str);

يطبع

Japanese for 東京 is toukyou
