These custom names are lexically scoped, and so a given code point may have different names in different scopes. The name used is what is in effect at the time the "\N{}" is expanded. - section: title: Octal escapes content: | There are two forms of octal escapes. Each is used to specify a character by its code point specified in base 8.

One form, available starting in Perl 5.14 looks like "\o{...}", where the dots represent one or more octal digits. It can be used for any Unicode character.

It was introduced to avoid the potential problems with the other form, available in all Perls. That form consists of a backslash followed by three octal digits. One problem with this form is that it can look exactly like an old-style backreference (see "Disambiguation rules between old-style octal escapes and backreferences" below.) You can avoid this by making the first of the three digits always a zero, but that makes \077 the largest code point specifiable.

In some contexts, a backslash followed by two or even one octal digits may be interpreted as an octal escape, sometimes with a warning, and because of some bugs, sometimes with surprising results. Also, if you are creating a regex out of smaller snippets concatenated together, and you use fewer than three digits, the beginning of one snippet may be interpreted as adding digits to the ending of the snippet before it. See "Absolute referencing" for more discussion and examples of the snippet problem.

Note that a character expressed as an octal escape is considered a character without special meaning by the regex engine, and will match "as is".

To summarize, the "\o{}" form is always safe to use, and the other form is safe to use for code points through \077 when you use exactly three digits to specify them.

Mnemonic: 0ctal or octal.

Examples (assuming an ASCII platform)

$str = "Perl";
$str =~ /\o{120}/;  # Match, "\120" is "P".
$str =~ /\120/;     # Same.
$str =~ /\o{120}+/; # Match, "\120" is "P",
                    # it's repeated at least once.
$str =~ /\120+/;    # Same.
$str =~ /P\053/;    # No match, "\053" is "+" and taken literally.
/\o{23073}/         # Black foreground, white background smiling face.
/\o{4801234567}/    # Raises a warning, and yields chr(4).
/\o{ 400}/          # LATIN CAPITAL LETTER A WITH MACRON
/\o{ 400 }/         # Same. These show blanks are allowed adjacent to
                    # the braces
- section: title: Disambiguation rules between old-style octal escapes and backreferences content: | Octal escapes of the "\000" form outside of bracketed character classes potentially clash with old-style backreferences (see "Absolute referencing" below). They both consist of a backslash followed by numbers. So Perl has to use heuristics to determine whether it is a backreference or an octal escape. Perl uses the following rules to disambiguate:
1.
If the backslash is followed by a single digit, it's a backreference.
2.
If the first digit following the backslash is a 0, it's an octal escape.
3.
If the number following the backslash is N (in decimal), and Perl already has seen N capture groups, Perl considers this a backreference. Otherwise, it considers it an octal escape. If N has more than three digits, Perl takes only the first three for the octal escape; the rest are matched as is. 
my $pat  = "(" x 999;
         $pat .= "a";
         $pat .= ")" x 999;
      /^($pat)\1000$/;   #  Matches 'aa'; there are 1000 capture groups.
      /^$pat\1000$/;     #  Matches 'a@0'; there are 999 capture groups
                         #  and \1000 is seen as \100 (a '@') and a '0'.

You can force a backreference interpretation always by using the "\g{...}" form. You can the force an octal interpretation always by using the "\o{...}" form, or for numbers up through \077 (= 63 decimal), by using three digits, beginning with a "0".

- section: title: Modifiers content: | A number of backslash sequences have to do with changing the character, or characters following them. "\l" will lowercase the character following it, while "\u" will uppercase (or, more accurately, titlecase) the character following it. They provide functionality similar to the functions "lcfirst" and "ucfirst".

To uppercase or lowercase several characters, one might want to use "\L" or "\U", which will lowercase/uppercase all characters following them, until either the end of the pattern or the next occurrence of "\E", whichever comes first. They provide functionality similar to what the functions "lc" and "uc" provide.

"\Q" is used to quote or escape (disable) pattern metacharacters, up to the next "\E" or the end of the pattern. "\Q" adds a backslash to any character that could have special meaning to Perl. In the ASCII range, it quotes every character that isn't a letter, digit, or underscore. See "quotemeta" in perlfunc for details on what gets quoted for non-ASCII code points. Using this ensures that any character between "\Q" and "\E" will be matched literally, not interpreted as a metacharacter by the regex engine.

"\F" can be used to casefold all characters following, up to the next "\E" or the end of the pattern. It provides the functionality similar to the "fc" function.

Mnemonic: Lowercase, Uppercase, Fold-case, Quotemeta, End.

Examples

$sid     = "sid";
$greg    = "GrEg";
$miranda = "(Miranda)";
$str     =~ /\u$sid/;        # Matches 'Sid'
$str     =~ /\L$greg/;       # Matches 'greg'
$str     =~ /\Q$miranda\E/;  # Matches '(Miranda)', as if the pattern
                             #   had been written as /\(Miranda\)/

الاستدعاء

إذا تم استخدام أقواس التقاط في تعبير عادي، يمكننا الإشارة إلى الجزء من السلسلة المصدر الذي تمت مطابقته، ومطابقة نفس الشيء بالضبط. هناك ثلاث طرق للإشارة إلى هذا الاستدعاء العكسي: مطلق، نسبي، وبالاسم.

الاستدعاء المطلق

إما "\gN" (بدءًا من Perl 5.10.0)، أو "\N" (النمط القديم) حيث N هو رقم عشري موجب (غير موقّع) بأي طول هو مرجع مطلق لمجموعة التقاط.

N تشير إلى المجموعة رقم N من الأقواس، لذا "\gN" تشير إلى أي شيء تمت مطابقته بواسطة تلك المجموعة من الأقواس. وبالتالي "\g1" تشير إلى مجموعة الالتقاط الأولى في التعبير العادي.

يمكن كتابة النموذج "\gN" بشكل مكافئ كـ "\g{N}" مما يتجنب الغموض عند بناء تعبير عادي عن طريق ربط سلاسل أقصر. بخلاف ذلك، إذا كان لديك تعبير عادي "qr/$x$y/"، و$x يحتوي على "\g1"، و$y يحتوي على "37"، ستحصل على "/\g137/" وهو على الأرجح ليس ما قصدته.

في نموذج "\N"، لا يجب أن يبدأ N بـ "0"، ويجب أن يكون هناك على الأقل N مجموعة التقاط، وإلا يعتبر N تهريبًا ثمانيًا (ولكن شيء مثل "\18" هو نفس الشيء مثل "\0018"؛ أي، التهريب الثماني "\001" متبوعًا برقم حرفي "8").

اختصار: group (مجموعة).

أمثلة

/(\w+) \g1/;    # يبحث عن كلمة مكررة، (على سبيل المثال "cat cat").
/(\w+) \1/;     # نفس الشيء؛ مكتوب بالنمط القديم.
/(\w+) \g{1}/;  # نفس الشيء، باستخدام الصيغة الآمنة بالأقواس المعقوفة
/(\w+) \g{ 1 }/;# نفس الشيء، يوضح المسافات الاختيارية المجاورة للأقواس المعقوفة
/(.)(.)\g2\g1/; # يطابق قلابًا رباعي الأحرف (على سبيل المثال "ABBA").

الاستدعاء النسبي

"\g-N" (بدءًا من Perl 5.10.0) يُستخدم للعنونة النسبية. (يمكن كتابته كـ "\g{-N}".) يشير إلى المجموعة رقم N قبل "\g{-N}".

الميزة الكبيرة لهذا النموذج هي أنه يسهل كتابة أنماط مع استدعاءات يمكن تضمينها في أنماط أكبر، حتى لو كان النمط الأكبر يحتوي أيضًا على مجموعات التقاط.

أمثلة

/(A)        # المجموعة 1
 (          # المجموعة 2
   (B)      # المجموعة 3
   \g{-1}   # يشير إلى المجموعة 3 (B)
   \g{-3}   # يشير إلى المجموعة 1 (A)
   \g{ -3 } # نفس الشيء، يوضح المسافات الاختيارية المجاورة للأقواس المعقوفة
 )
/x;         # يطابق "ABBA".
my $qr = qr /(.)(.)\g{-2}\g{-1}/;  # يطابق 'abab'، 'cdcd'، إلخ.
/$qr$qr/                           # يطابق 'ababcdcd'.

الاستدعاء المسمى

"\g{name}" (بدءًا من Perl 5.10.0) يمكن استخدامه للاستدعاء العكسي لمجموعة التقاط مسماة، مما يلغي تمامًا الحاجة إلى التفكير في مواضع مخزن الالتقاط.

للتوافق مع تعبيرات .Net العادية، "\g{name}" يمكن كتابتها أيضًا كـ "\k{name}"، "\k<name>" أو "\k'name'".

لتجنب أي غموض، لا يجب أن يبدأ name برقم ولا يحتوي على شرطة.

أمثلة

/(?<word>\w+) \g{word}/   # يبحث عن كلمة مكررة، (على سبيل المثال "cat cat")
/(?<word>\w+) \k{word}/   # نفس الشيء.
/(?<word>\w+) \g{ word }/ # نفس الشيء، يوضح المسافات الاختيارية المجاورة
                          # للأقواس المعقوفة
/(?<word>\w+) \k{ word }/ # نفس الشيء.
/(?<word>\w+) \k<word>/   # نفس الشيء. لا توجد أقواس معقوفة، لذا لا توجد مسافات
                          # مسموح بها
/(?<letter1>.)(?<letter2>.)\g{letter2}\g{letter1}/
                          # يطابق قلابًا رباعي الأحرف (على سبيل المثال
                          # "ABBA")

التأكيدات

التأكيدات هي شروط يجب أن تكون صحيحة؛ فهي لا تطابق أجزاء من السلسلة الفرعية فعليًا. هناك ستة تأكيدات مكتوبة كسلاسل مائلة للخلف.

\A
"\A" تطابق فقط في بداية السلسلة. إذا لم يتم استخدام المعدل "/m"، فإن "/\A/" يعادل "/^/". ومع ذلك، إذا تم استخدام المعدل "/m"، فإن "/^/" يطابق فواصل الأسطر الداخلية، ولكن معنى "/\A/" لا يتغير بسبب المعدل "/m". "\A" تطابق في بداية السلسلة بغض النظر عما إذا كان المعدل "/m" مستخدمًا.
\z, \Z
"\z" و "\Z" تطابقان في نهاية السلسلة. إذا لم يتم استخدام المعدل "/m"، فإن "/\Z/" يعادل "/$/"؛ أي، تطابق في نهاية السلسلة، أو قبل سطر جديد في نهاية السلسلة. إذا تم استخدام المعدل "/m"، فإن "/$/" يطابق فواصل الأسطر الداخلية، ولكن معنى "/\Z/" لا يتغير بسبب المعدل "/m". "\Z" تطابق في نهاية السلسلة (أو قبل سطر جديد نهائي) بغض النظر عما إذا كان المعدل "/m" مستخدمًا.

"\z" هو مثل "\Z"، إلا أنه لا يطابق قبل سطر جديد نهائي. "\z" يطابق في نهاية السلسلة فقط، بغض النظر عن المعدلات المستخدمة، وليس فقط قبل سطر جديد. إنها طريقة لربط المطابقة بنهاية السلسلة الحقيقية في جميع الظروف.

\G
"\G" يُستخدم عادةً فقط بالاشتراك مع المعدل "/g". إذا تم استخدام المعدل "/g" وتمت المطابقة في سياق كمي، يتذكر Perl مكان انتهاء المطابقة الأخيرة في السلسلة المصدر، وفي المرة التالية، ستبدأ المطابقة من حيث انتهت في المرة السابقة.

"\G" تطابق النقطة التي انتهت فيها المطابقة السابقة على تلك السلسلة، أو بداية تلك السلسلة إذا لم تكن هناك مطابقة سابقة.

اختصار: Global (عام).

perlrebackslash - Perl regular expressions

perl v5.42.0 perlrebackslash(1perl)
2025-07-13 perl v5.42.0
\X

It matches a "Unicode grapheme cluster". This is a sequence of one or more Unicode code points that are treated by Unicode as a single user-perceived character. For example, an accented character like e followed by a combining acute accent (\x{301}) forms a grapheme cluster. Specifically, the character e (U+0065) followed by COMBINING ACUTE ACCENT (U+0301) would be represented as P\x{307}. This would be composed using a G followed by a Unicode "COMBINING UPWARDS ARROW BELOW", and would be displayed by Unicode-aware software as if it were a single character.

The match is greedy and non-backtracking, so that the cluster is never broken up into smaller components.

See also "\b{gcb}".

Mnemonic: eXtended Unicode character.

Examples

$str =~ s/foo\Kbar/baz/g; # Change any 'bar' following a 'foo' to 'baz'
$str =~ s/(.)\K\g1//g;    # Delete duplicated characters.
"\n"   =~ /^\R$/;         # Match, \n   is a generic newline.
"\r"   =~ /^\R$/;         # Match, \r   is a generic newline.
"\r\n" =~ /^\R$/;         # Match, \r\n is a generic newline.
"P\x{307}" =~ /^\X$/     # \X matches a P with a dot above.
