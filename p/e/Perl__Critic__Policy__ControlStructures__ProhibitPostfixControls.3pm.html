Perl__Critic__Policy__ControlStructures__ProhibitPostfixControls(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::ControlStructures::ProhibitPostfixControls(3pm) وثائق Perl المساهمة من المستخدم Perl::Critic::Policy::ControlStructures::ProhibitPostfixControls(3pm)

الاسم

Perl::Critic::Policy::ControlStructures::ProhibitPostfixControls - اكتب "if($condition){ do_something() }" بدلاً من "do_something() if $condition".

الانتماء

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

الوصف

كونواي يثبط استخدام هياكل التحكم اللاحقة (PostFix Control Structures) ("if"، "for"، "unless"، "until"، "when"، "while") لأنها تخفي تدفق التحكم. إن هياكل "unless" و "until" شريرة بشكل خاص لأنها تؤدي إلى نفي مزدوج يصعب فهمه. الاستخدام الوحيد المقبول لـ "if"/"when" اللاحقة هو عندما تتبع كسر حلقة مثل "last"، "next"، "redo"، أو "continue".

do_something() if $condition;           # غير مقبول
if ($condition) { do_something() }      # مقبول
do_something() while $condition;        # غير مقبول
while ($condition) { do_something() }   # مقبول
do_something() unless $condition;       # غير مقبول
do_something() unless ! $condition;     # سيء جداً
if (! $condition) { do_something() }    # مقبول
do_something() until $condition;        # غير مقبول
do_something() until ! $condition;      # سيء جداً
while (! $condition) { do_something() } # مقبول
do_something($_) for @list;             # غير مقبول
LOOP:
for my $n (0..100) {
    next if $condition;                 # مقبول
    last LOOP if $other_condition;      # مقبول أيضاً
    next when m< 0 \z >xms;             # مقبول أيضاً
}

التكوين

يمكن تحديد مجموعة من الهياكل التي سيتم تجاهلها بواسطة هذه السياسة عن طريق إعطاء قيمة لـ 'allow' كسلسلة من الكلمات المفتاحية مفصولة بمسافات: "if"، "for"، "unless"، "until"، "when"، و/أو "while". مثال على تحديد هياكل تدفق التحكم المسموح بها في ملف .perlcriticrc:

[ControlStructures::ProhibitPostfixControls]
allow = for if until

بشكل افتراضي، يتم حظر جميع الكلمات المفتاحية لهياكل التحكم اللاحقة.

يمكن أيضاً تكوين مجموعة دوال تدفق التحكم المعفاة من القيود باستخدام التوجيه 'flowcontrol' في ملف .perlcriticrc الخاص بك:

[ControlStructures::ProhibitPostfixControls]
flowcontrol = warn die carp croak cluck confess goto exit

هذا مفيد إذا كنت تستخدم وحدات إضافية تضيف أشياء مثل "assert" أو "throw".

ملاحظات

تُستخدم الدوال "die"، "croak"، و "confess" بشكل متكرر كتدفقات تحكم تمامًا مثل "next" أو "last". لذلك تسمح لك هذه السياسة باستخدام "if" لاحقة عندما تبدأ العبارة بإحدى هذه الدوال. من الشائع أيضًا استخدام "warn"، "carp"، و "cluck" مع "if" لاحقة، لذلك يُسمح بها أيضًا.

تمت إضافة الكلمة المفتاحية "when" إلى اللغة بعد كتابة Perl Best Practices. تتعامل هذه السياسة مع "when" بنفس الطريقة التي تتعامل بها مع "if"، أي أنها مسموح بها بعد هياكل تدفق التحكم. شكرًا لـ brian d foy على الإلهام http://www.effectiveperlprogramming.com/blog/543.

الأخطاء

ابحث عن حالة "do {} while" وغير الشرح للإشارة إلى الصفحة 123 عند العثور عليها. RT #37905.
