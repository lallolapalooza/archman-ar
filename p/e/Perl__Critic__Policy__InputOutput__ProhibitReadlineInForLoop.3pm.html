NAME

Perl::Critic::Policy::InputOutput::ProhibitReadlineInForLoop - اكتب "while( $line = <> ){...}" بدلاً من "for(<>){...}".

AFFILIATION

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

DESCRIPTION

استخدام عامل القراءة (readline operator) في حلقة "for" أو "foreach" بطيء جدًا. قائمة تكرار الحلقة تنشئ سياق قائمة، مما يتسبب في أن يقرأ عامل القراءة مجرى الإدخال بأكمله قبل بدء التكرار. بدلاً من ذلك، فقط استخدم حلقة "while"، والتي تقرأ سطرًا واحدًا فقط في كل مرة.

for my $line ( <$file_handle> ){ do_something($line) }      # ليس جيدًا
while ( my $line = <$file_handle> ){ do_something($line) }  # جيد

CONFIGURATION

هذه السياسة غير قابلة للتكوين باستثناء الخيارات القياسية.
