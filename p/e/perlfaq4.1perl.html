البيانات: الأرقام

لماذا أحصل على كسور عشرية طويلة (مثل 19.9499999999999) بدلاً من الأرقام التي يجب أن أحصل عليها (مثل 19.95)؟

للشرح الطويل، راجع مقال David Goldberg بعنوان "ما يجب أن يعرفه كل عالم كمبيوتر عن حساب الفاصلة العائمة" (http://web.cse.msu.edu/~cse320/Documents/FloatingPoint.pdf).

داخليًا، يقوم جهاز الكمبيوتر الخاص بك بتمثيل أرقام الفاصلة العائمة بالنظام الثنائي. أجهزة الكمبيوتر الرقمية (مثل القوى الثنائية) لا يمكنها تخزين جميع الأرقام بدقة. تفقد بعض الأرقام الحقيقية الدقة في هذه العملية. هذه مشكلة في كيفية تخزين أجهزة الكمبيوتر للأرقام وتؤثر على جميع لغات البرمجة، وليس فقط Perl.

يعرض perlnumber التفاصيل المزعجة لتمثيلات الأرقام والتحويلات.

لتقييد عدد المنازل العشرية في أرقامك، يمكنك استخدام الدالة "printf" أو "sprintf". راجع "حساب الفاصلة العائمة" في perlop لمزيد من التفاصيل.

printf "%.2f", 10/3;
my $number = sprintf "%.2f", 10/3;

لماذا الدالة int() معطلة؟

على الأرجح أن الدالة int() تعمل بشكل جيد. المشكلة في الأرقام ليست تمامًا كما تعتقد.

أولاً، راجع الإجابة على "لماذا أحصل على كسور عشرية طويلة (مثل 19.9499999999999) بدلاً من الأرقام التي يجب أن أحصل عليها (مثل 19.95)؟".

على سبيل المثال، هذا

print int(0.6/0.2-2), "\n";

في معظم أجهزة الكمبيوتر سيطبع 0، وليس 1، لأن حتى الأرقام البسيطة مثل 0.6 و 0.2 لا يمكن تمثيلها بدقة بواسطة أرقام الفاصلة العائمة. ما تعتقده في الأعلى "ثلاثة" هو في الواقع أقرب إلى 2.9999999999999995559.

لماذا لا يتم تفسير بياناتي الثمانية (octal) بشكل صحيح؟

(مساهمة من brian d foy)

ربما تحاول تحويل سلسلة نصية إلى رقم، وهو ما تقوم Perl بتحويله كرقم عشري فقط. عندما تقوم Perl بتحويل سلسلة نصية إلى رقم، فإنها تتجاهل المسافات البادئة والأصفار، ثم تفترض أن باقي الأرقام في القاعدة 10:

my $string = '0644';
print $string + 0;  # يطبع 644
print $string + 44; # يطبع 688، بالتأكيد ليس ثمانيًا!

تحدث هذه المشكلة عادةً عند استخدام إحدى دوال Perl المدمجة التي تحمل نفس اسم أمر Unix الذي يستخدم أرقامًا ثمانية كوسائط على سطر الأوامر. في هذا المثال، "chmod" على سطر الأوامر يعرف أن وسيطته الأولى ثمانية لأن هذا ما يفعله:

%prompt> chmod 644 file

إذا كنت تريد استخدام نفس الأرقام الحرفية (644) في Perl، عليك أن تخبر Perl بمعاملتها كأرقام ثمانية إما عن طريق إضافة بادئة 0 للأرقام أو باستخدام "oct":

chmod(     0644, $filename );  # صحيح، له بادئة صفر
chmod( oct(644), $filename );  # صحيح أيضًا

تأتي المشكلة عندما تأخذ أرقامك من شيء تعتقد Perl أنه سلسلة نصية، مثل وسيط سطر الأوامر في @ARGV:

chmod( $ARGV[0],      $filename );  # خطأ، حتى لو كانت "0644"
chmod( oct($ARGV[0]), $filename );  # صحيح، تعامل مع السلسلة النصية كثمانية

يمكنك دائمًا التحقق من القيمة التي تستخدمها عن طريق طباعتها بصيغة ثمانية للتأكد من أنها تطابق ما تعتقد أنه يجب أن تكون عليه. اطبعها بصيغة ثمانية وعشرية:

printf "0%o %d", $number, $number;

هل لدى Perl دالة round()؟ ماذا عن ceil() و floor()؟ الدوال المثلثية؟

تذكر أن int() تقوم ببساطة بالاقتطاع نحو الصفر. للتقريب لعدد معين من المنازل العشرية، تعد sprintf() أو printf() هي المسار الأسهل عادةً.

printf("%.3f", 3.1415926535);   # يطبع 3.142

تنفذ الوحدة POSIX (جزء من توزيع Perl القياسي) الدوال ceil() و floor() وعددًا من الدوال الرياضية والمثلثية الأخرى.

use POSIX;
my $ceil   = ceil(3.5);   # 4
my $floor  = floor(3.5);  # 3

في إصدارات Perl من 5.000 إلى 5.003، تم إجراء العمليات المثلثية في الوحدة Math::Complex. مع الإصدار 5.004، تنفذ الوحدة Math::Trig (جزء من توزيع Perl القياسي) الدوال المثلثية. داخليًا، تستخدم الوحدة Math::Complex ويمكن لبعض الدوال الخروج من المحور الحقيقي إلى المستوى المركب، على سبيل المثال، الجيب العكسي لـ 2.

يمكن أن يكون للتقريب في التطبيقات المالية آثار خطيرة، ويجب تحديد طريقة التقريب المستخدمة بدقة. في هذه الحالات، ربما يكون من الأفضل عدم الوثوق بأي نظام تقريب تستخدمه Perl، بل تنفيذ الدالة التي تحتاجها بنفسك.

لترى لماذا، لاحظ كيف ستظل تواجه مشكلة في التناوب عند النقطة الوسطى:

for (my $i = -5; $i <= 5; $i += 0.5) { printf "%.0f ",$i }
-5 -4 -4 -4 -3 -2 -2 -2 -1 -0 0 0 1 2 2 2 3 4 4 4 5

لا تلم Perl. الأمر نفسه كما هو الحال في C. IEEE تقول علينا أن نفعل هذا. أرقام Perl التي تحتوي قيمها المطلقة على أعداد صحيحة أقل من 2**31 (على أجهزة 32 بت) ستعمل إلى حد كبير مثل الأعداد الصحيحة الرياضية. الأرقام الأخرى غير مضمونة.

String Manipulation

(contributed by brian d foy)

How do I remove duplicate or consecutive characters?

You can use the substitution operator to find pairs of characters (or runs of characters) and replace them with a single instance. In this substitution, we find a character in "(.)". The memory parentheses store the matched character in the back-reference "\g1" and we use that to require that the same thing immediately follow it. We replace that part of the string with the character in $1.

s/(.)\g1/$1/g;

We can also use the transliteration operator, "tr///". In this example, the search list side of our "tr///" contains nothing, but the "c" option complements that so it contains everything. The replacement list also contains nothing, so the transliteration is almost a no-op since it won't do any replacements (or more exactly, replace the character with itself). However, the "s" option squashes duplicated and consecutive characters in the string so a character does not show up next to itself

my $str = 'Haarlem';   # in the Netherlands
$str =~ tr///cs;       # Now Harlem, like in New York

How do I expand function calls in a string?

(contributed by brian d foy)

This is documented in perlref, and although it's not the easiest thing to read, it does work. In each of these examples, we call the function inside the braces used to dereference a reference. If we have more than one return value, we can construct and dereference an anonymous array. In this case, we call the function in list context.

print "The time values are @{ [localtime] }.\n";

If we want to call the function in scalar context, we have to do a bit more work. We can really have any code we like inside the braces, so we simply have to end with the scalar reference, although how you do that is up to you, and you can use code inside the braces. Note that the use of parens creates a list context, so we need "scalar" to force the scalar context on the function:

print "The time is ${\(scalar localtime)}.\n"
print "The time is ${ my $x = localtime; \$x }.\n";

If your function already returns a reference, you don't need to create the reference yourself.

sub timestamp { my $t = localtime; \$t }
print "The time is ${ timestamp() }.\n";

The "Interpolation" module can also do a lot of magic for you. You can specify a variable name, in this case "E", to set up a tied hash that does the interpolation for you. It has several other methods to do this as well.

use Interpolation E => 'eval';
print "The time values are $E{localtime()}.\n";

In most cases, it is probably easier to simply use string concatenation, which also forces scalar context.

print "The time is " . localtime() . ".\n";

How do I find matching/nesting anything?

To find something between two single characters, a pattern like "/x([^x]*)x/" will get the intervening bits in $1. For multiple ones, then something more like "/alpha(.*?)omega/" would be needed. For nested patterns and/or balanced expressions, see the so-called (?PARNO) construct (available since perl 5.10). The CPAN module Regexp::Common can help to build such regular expressions (see in particular Regexp::Common::balanced and Regexp::Common::delimited).

More complex cases will require to write a parser, probably using a parsing module from CPAN, like Regexp::Grammars, Parse::RecDescent, Parse::Yapp, Text::Balanced, or Marpa::R2.

How do I reverse a string?

Use reverse() in scalar context, as documented in "reverse" in perlfunc.

my $reversed = reverse $string;

How do I expand tabs in a string?

You can do it yourself:

1 while $string =~ s/\t+/' ' x (length($&) * 8 - length($`) % 8)/e;

Or you can just use the Text::Tabs module (part of the standard Perl distribution).

use Text::Tabs;
my @expanded_lines = expand(@lines_with_tabs);

How do I reformat a paragraph?

Use Text::Wrap (part of the standard Perl distribution):

use Text::Wrap;
print wrap("\t", '  ', @paragraphs);

The paragraphs you give to Text::Wrap should not contain embedded newlines. Text::Wrap doesn't justify the lines (flush-right).

Or use the CPAN module Text::Autoformat. Formatting files can be easily done by making a shell alias, like so:

alias fmt="perl -i -MText::Autoformat -n0777 \
    -e 'print autoformat $_, {all=>1}' $*"

See the documentation for Text::Autoformat to appreciate its many capabilities.

How can I access or change N characters of a string?

You can access the first characters of a string with substr(). To get the first character, for example, start at position 0 and grab the string of length 1.

my $string = "Just another Perl Hacker";
my $first_char = substr( $string, 0, 1 );  #  'J'

To change part of a string, you can use the optional fourth argument which is the replacement string.

substr( $string, 13, 4, "Perl 5.8.0" );

You can also use substr() as an lvalue.

substr( $string, 13, 4 ) =  "Perl 5.8.0";

How do I change the Nth occurrence of something?

You have to keep track of N yourself. For example, let's say you want to change the fifth occurrence of "whoever" or "whomever" into "whosoever" or "whomsoever", case insensitively. These all assume that $_ contains the string to be altered.

$count = 0;
s{((whom?)ever)}{
++$count == 5       # is it the 5th?
    ? "${2}soever"  # yes, swap
    : $1            # renege and leave it there
    }ige;

In the more general case, you can use the "/g" modifier in a "while" loop, keeping count of matches.

$WANT = 3;
$count = 0;
$_ = "One fish two fish red fish blue fish";
while (/(\w+)\s+fish\b/gi) {
    if (++$count == $WANT) {
        print "The third fish is a $1 one.\n";
    }
}

That prints out: "The third fish is a red one." You can also use a repetition count and repeated pattern like this:

/(?:\w+\s+fish\s+){2}(\w+)\s+fish/i;

How can I count the number of occurrences of a substring within a string?

There are a number of ways, with varying efficiency. If you want a count of a certain single character (X) within a string, you can use the "tr///" function like so:

my $string = "ThisXlineXhasXsomeXx'sXinXit";
my $count = ($string =~ tr/X//);
print "There are $count X characters in the string";

This is fine if you are just looking for a single character. However, if you are trying to count multiple character substrings within a larger string, "tr///" won't work. What you can do is wrap a while() loop around a global pattern match. For example, let's count negative integers:

my $string = "-9 55 48 -2 23 -76 4 14 -44";
my $count = 0;
while ($string =~ /-\d+/g) { $count++ }
print "There are $count negative numbers in the string";

Another version uses a global match in list context, then assigns the result to a scalar, producing a count of the number of matches.

my $count = () = $string =~ /-\d+/g;

How do I capitalize all the words on one line?

(contributed by brian d foy)

Damian Conway's Text::Autoformat handles all of the thinking for you:

use Text::Autoformat;
my $s = "Going to the desert with a camel";
printf "%-10s %s\n", "original:", $s;
for my $style (qw( sentence title highlight )) {
    printf "%-10s %s\n",
        "$style:",
        autoformat($s, { case => $style }) =~ s/\R+\z//r;
}

Each style has a different idea of what it should do with small words:

original:  Going to the desert with a camel
sentence:  Going to the desert with a camel
title:     Going To The Desert With A Camel
highlight: Going to the Desert with a Camel

Trying this yourself in a simple regex has more than a few pitfalls. Perl "words" are groups of "\w+", but that's not what you want to capitalize. Some of those characters aren't even letters. What if you used a word boundary, "\b"?

my $string = "A camel's journey";
$string =~ s/\b(\w)/\U$1/g;  # A Camel'S Journey

How is Perl supposed to know not to capitalize that "s"? You could work harder to look for preceding whitespace or the beginning of the string:

$string =~ s/( (?:^|\s) \w ) /\U$1/xg; # A Camel's Journey

Or maybe you match the entire group, lowercase it all ("L"), then uppercase the first letter ("\u"):

$string =~ s/([\w']+)/\u\L$1/g;

كيف يمكنني تقسيم سلسلة نصية محددة بـ [حرف] باستثناء عندما تكون داخل [حرف]؟

يمكن للعديد من الوحدات التعامل مع هذا النوع من التحليل - Text::Balanced، Text::CSV، Text::CSV_XS، و Text::ParseWords، من بين وحدات أخرى.

خذ الحالة النموذجية لمحاولة تقسيم سلسلة نصية مفصولة بفواصل إلى حقولها المختلفة. لا يمكنك استخدام "split(/,/)" لأنك لا يجب أن تقسم إذا كانت الفاصلة داخل علامات اقتباس. على سبيل المثال، خذ سطر بيانات كهذا:

SAR001,"","Cimetrix, Inc","Bob Smith","CAM",N,8,1,0,7,"Error, Core Dumped"

نظرًا لقيود علامات الاقتباس، تعد هذه مشكلة معقدة إلى حد ما. لحسن الحظ، لدينا جيفري فريدل، مؤلف كتاب Mastering Regular Expressions، ليتولى هذه الأمور نيابة عنا. يقترح (بافتراض أن سلسلتك النصية موجودة في $text):

my @new = ();
push(@new, $+) while $text =~ m{
    "([^\"\\]*(?:\\.[^\"\\]*)*)",? # groups the phrase inside the quotes
   | ([^,]+),?
   | ,
}gx;
push(@new, undef) if substr($text,-1,1) eq ',';

إذا كنت ترغب في تمثيل علامات الاقتباس داخل حقل محدد بعلامات اقتباس، فقم بالهروب منها باستخدام الشرطات المائلة العكسية (مثال: "like \"this\"".

بدلاً من ذلك، تسمح لك وحدة Text::ParseWords (جزء من توزيع Perl القياسي) بقول:

use Text::ParseWords;
@new = quotewords(",", 0, $text);

ومع ذلك، لتحليل أو إنشاء CSV، يوصى بشدة باستخدام Text::CSV بدلاً من تنفيذها بنفسك؛ ستوفر على نفسك أخطاء غريبة تظهر لاحقًا باستخدام كود تم اختباره وإثباته في الإنتاج لسنوات.

كيف أتخلص من المسافات البيضاء من بداية/نهاية سلسلة نصية؟

(مساهمة من brian d foy)

يمكن لعملية الاستبدال القيام بذلك من أجلك. بالنسبة لسطر واحد، تريد استبدال كل المسافات البادئة أو اللاحقة بلا شيء. يمكنك القيام بذلك بزوج من عمليات الاستبدال:

s/^\s+//;
s/\s+$//;

يمكنك أيضًا كتابة ذلك كعملية استبدال واحدة، على الرغم من أن العبارة المجمعة أبطأ من العبارات المنفصلة. قد لا يهمك ذلك، مع ذلك:

s/^\s+|\s+$//g;

في هذا التعبير العادي، يطابق التناوب إما في بداية السلسلة أو نهايتها نظرًا لأن المرسات لها أسبقية أقل من التناوب. مع العلم "/g"، تقوم عملية الاستبدال بإجراء جميع المطابقات الممكنة، لذا تحصل على كليهما. تذكر، السطر الجديد اللاحق يطابق "\s+"، ويمكن للمرسى "$" المطابقة مع النهاية المطلقة للسلسلة، لذلك يختفي السطر الجديد أيضًا. فقط أضف السطر الجديد إلى الإخراج، والذي له فائدة إضافية تتمثل في الحفاظ على الأسطر "الفارغة" (المكونة بالكامل من مسافات بيضاء) التي ستزيلها "^\s+" بنفسها:

while( <> ) {
    s/^\s+|\s+$//g;
    print "$_\n";
}

بالنسبة لسلسلة نصية متعددة الأسطر، يمكنك تطبيق التعبير العادي على كل سطر منطقي في السلسلة النصية بإضافة العلم "/m" (لـ "متعدد الأسطر"). مع العلم "/m"، يتطابق "$" قبل سطر جديد مضمن، لذا لا يزيله. لا يزال هذا النمط يزيل السطر الجديد في نهاية السلسلة:

$string =~ s/^\s+|\s+$//gm;

تذكر أن الأسطر المكونة بالكامل من مسافات بيضاء ستختفي، حيث يمكن للجزء الأول من التناوب مطابقة السلسلة بأكملها واستبدالها بلا شيء. إذا كنت بحاجة إلى الاحتفاظ بالأسطر الفارغة المضمنة، فعليك القيام بالمزيد من العمل. بدلاً من مطابقة أي مسافات بيضاء (لأن ذلك يشمل سطرًا جديدًا)، قم فقط بمطابقة المسافات البيضاء الأخرى:

$string =~ s/^[\t\f ]+|[\t\f ]+$//mg;

كيف أقوم بملء سلسلة نصية بمسافات أو برقم بأصفار؟

في الأمثلة التالية، $pad_len هو الطول الذي ترغب في ملء السلسلة به، $text أو $num يحتوي على السلسلة التي سيتم ملؤها، و $pad_char يحتوي على حرف الملء. يمكنك استخدام ثابت سلسلة بحرف واحد بدلاً من المتغير $pad_char إذا كنت تعرف ما هو مقدمًا. وبنفس الطريقة يمكنك استخدام عدد صحيح بدلاً من $pad_len إذا كنت تعرف طول الملء مقدمًا.

الطريقة الأبسط تستخدم الدالة "sprintf". يمكنها الملء من اليسار أو اليمين بالمسافات ومن اليسار بالأصفار ولن تقوم باقتطاع النتيجة. الدالة "pack" يمكنها فقط ملء السلاسل من اليمين بالمسافات وستقوم باقتطاع النتيجة إلى حد أقصى للطول $pad_len.

# الملء من اليسار لسلسلة نصية بمسافات (بدون اقتطاع):
my $padded = sprintf("%${pad_len}s", $text);
my $padded = sprintf("%*s", $pad_len, $text);  # نفس الشيء
# الملء من اليمين لسلسلة نصية بمسافات (بدون اقتطاع):
my $padded = sprintf("%-${pad_len}s", $text);
my $padded = sprintf("%-*s", $pad_len, $text); # نفس الشيء
# الملء من اليسار لرقم بأصفار (بدون اقتطاع):
my $padded = sprintf("%0${pad_len}d", $num);
my $padded = sprintf("%0*d", $pad_len, $num); # نفس الشيء
# الملء من اليمين لسلسلة نصية بمسافات باستخدام pack (سيتم اقتطاعها):
my $padded = pack("A$pad_len",$text);

إذا كنت بحاجة إلى الملء بحرف آخر غير المسافة أو الصفر، يمكنك استخدام إحدى الطرق التالية. كلها تولد سلسلة ملء باستخدام العامل "x" وتدمجها مع $text. هذه الطرق لا تقوم باقتطاع $text.

الملء من اليسار واليمين بأي حرف، إنشاء سلسلة نصية جديدة:

my $padded = $pad_char x ( $pad_len - length( $text ) ) . $text;
my $padded = $text . $pad_char x ( $pad_len - length( $text ) );

الملء من اليسار واليمين بأي حرف، تعديل $text مباشرة:

substr( $text, 0, 0 ) = $pad_char x ( $pad_len - length( $text ) );
$text .= $pad_char x ( $pad_len - length( $text ) );

(مساهمة من brian d foy)

إذا كنت تعرف الأعمدة التي تحتوي على البيانات، يمكنك استخدام "substr" لاستخراج عمود واحد.

my $column = substr( $line, $start_column, $length );

يمكنك استخدام "split" إذا كانت الأعمدة مفصولة بمسافات بيضاء أو بمحدد آخر، طالما أن المسافات البيضاء أو المحدد لا يمكن أن تظهر كجزء من البيانات.

my $line    = ' fred barney   betty   ';
my @columns = split /\s+/, $line;

my $line    = 'fred||barney||betty';
my @columns = split /\|/, $line;
    # ( 'fred', '', 'barney', '', 'betty' );

إذا كنت ترغب في التعامل مع قيم مفصولة بفواصل، فلا تفعل ذلك لأن هذا التنسيق أكثر تعقيدًا بعض الشيء. استخدم إحدى الوحدات التي تتعامل مع هذا التنسيق، مثل Text::CSV، Text::CSV_XS، أو Text::CSV_PP.

my @fields = unpack( "A8 A8 A8 A16 A4", $line );

لاحظ أن المسافات في وسيط التنسيق لـ "unpack" لا تمثل مسافات حرفية. إذا كانت لديك بيانات مفصولة بمسافات، فقد ترغب في "split" بدلاً من ذلك.

كيف أتعامل مع القوائم المترابطة؟

(ساهم بها brian d foy)

مصفوفات Perl لا حجم ثابت لها، لذلك لا تحتاج إلى قوائم مترابطة إذا كنت تريد فقط إضافة أو إزالة عناصر. يمكنك استخدام عمليات المصفوفات مثل "push"، "pop"، "shift"، "unshift"، أو "splice" للقيام بذلك.

ومع ذلك، يمكن أن تكون القوائم المترابطة مفيدة في بعض الأحيان في المواقف التي تريد فيها "تقسيم" مصفوفة بحيث يكون لديك العديد من المصفوفات الصغيرة بدلاً من مصفوفة كبيرة واحدة. يمكنك الاحتفاظ بالمصفوفات أطول من أكبر مؤشر مصفوفة في Perl، وتأمين مصفوفات أصغر بشكل منفصل في البرامج المتوازية، وإعادة تخصيص ذاكرة أقل، أو إدراج عناصر بسرعة في منتصف السلسلة.

يقوم Steve Lembark بتفصيل ذلك في حديثه في YAPC::NA 2009 بعنوان "Perly Linked Lists" (http://www.slideshare.net/lembark/perly-linked-lists)، على الرغم من أنه يمكنك فقط استخدام وحدة LinkedList::Single الخاصة به.

my @array = qw( a b c );
my $i = 0;
while( 1 ) {
    print $array[ $i++ % @array ], "\n";
    last if $i > 20;
}

use Tie::Cycle;
tie my $cycle, 'Tie::Cycle', [ qw( FFFFFF 000000 FFFF00 ) ];
print $cycle; # FFFFFF
print $cycle; # 000000
print $cycle; # FFFF00

use Array::Iterator::Circular;

كيف أقوم بخلط مصفوفة بشكل عشوائي؟

إذا كان لديك Perl 5.8.0 أو أحدث مثبتًا، أو إذا كان لديك Scalar-List-Utils 1.03 أو أحدث مثبتًا، فيمكنك قول:

use List::Util 'shuffle';
@shuffled = shuffle(@list);

إذا لم يكن الأمر كذلك، يمكنك استخدام خلط Fisher-Yates.

sub fisher_yates_shuffle {
    my $deck = shift;  # $deck هو مرجع لمصفوفة
    return unless @$deck; # يجب ألا تكون فارغة!
    my $i = @$deck;
    while (--$i) {
        my $j = int rand ($i+1);
        @$deck[$i,$j] = @$deck[$j,$i];
    }
}
# خلط مجموعة ملفات mpeg الخاصة بي
#
my @mpeg = <audio/*/*.mp3>;
fisher_yates_shuffle( \@mpeg );    # تعيين @mpeg عشوائيا في مكانها
print @mpeg;

لاحظ أن التنفيذ أعلاه يقوم بخلط مصفوفة في مكانها، على عكس List::Util::shuffle() التي تأخذ قائمة وتعيد قائمة مخلوطة جديدة.

ربما رأيت خوارزميات خلط تعمل باستخدام splice، واختيار عنصر آخر بشكل عشوائي لتبديل العنصر الحالي به

srand;
@new = ();
@old = 1 .. 10;  # مجرد عرض توضيحي
while (@old) {
    push(@new, splice(@old, rand @old, 1));
}

هذا سيء لأن splice هو بالفعل O(N)، وبما أنك تقوم بذلك N مرة، فقد اختفعت خوارزمية تربيعية؛ أي O(N**2). هذا لا يتوسع، على الرغم من أن Perl فعال للغاية لدرجة أنك لن تلاحظ هذا على الأرجح حتى يكون لديك مصفوفات كبيرة جدًا.

كيف أقوم بمعالجة/تعديل كل عنصر في مصفوفة؟

استخدم "for"/"foreach":

for (@lines) {
    s/foo/bar/;    # تغيير تلك الكلمة
    tr/XZ/ZX/;    # تبديل تلك الأحرف
}

ها هو مثال آخر؛ دعنا نحسب أحجام الكرات:

my @volumes = @radii;
for (@volumes) {   # تغيرت أجزاء @volumes
    $_ **= 3;
    $_ *= (4/3) * 3.14159;  # سيتم طي هذا الثابت
}

والتي يمكن القيام بها أيضًا باستخدام map() والتي تم إنشاؤها لتحويل قائمة إلى أخرى:

my @volumes = map {$_ ** 3 * (4/3) * 3.14159} @radii;

إذا كنت ترغب في القيام بنفس الشيء لتعديل قيم الـ hash، يمكنك استخدام الدالة "values". اعتبارًا من Perl 5.6، لا يتم نسخ القيم، لذلك إذا قمت بتعديل $orbit (في هذه الحالة)، فأنت تقوم بتعديل القيمة.

for my $orbit ( values %orbits ) {
    ($orbit **= 3) *= (4/3) * 3.14159;
}

قبل perl 5.6، أعادت "values" نسخًا من القيم، لذلك غالبًا ما تحتوي شفرة Perl القديمة على تركيبات مثل @orbits{keys %orbits} بدلاً من "values %orbits" حيث سيتم تعديل الـ hash.

استخدم الدالة rand() (انظر "rand" في perlfunc):

my $index   = rand @array;
my $element = $array[$index];

أو ببساطة:

my $element = $array[ rand @array ];

كيف أقوم بترتيب N عناصر من قائمة؟

استخدم وحدة List::Permutor على CPAN. إذا كانت القائمة عبارة عن مصفوفة بالفعل، جرب وحدة Algorithm::Permute (أيضًا على CPAN). إنها مكتوبة بلغة XS وهي فعالة جدًا:

use Algorithm::Permute;
my @array = 'a'..'d';
my $p_iterator = Algorithm::Permute->new ( \@array );
while (my @perm = $p_iterator->next) {
   print "next permutation: (@perm)\n";
}

للحصول على تنفيذ أسرع، يمكنك القيام بذلك:

use Algorithm::Permute;
my @array = 'a'..'d';
Algorithm::Permute::permute {
    print "next permutation: (@array)\n";
} @array;

إليك برنامج صغير يقوم بتوليد جميع التباديل لجميع الكلمات في كل سطر من المدخلات. الخوارزمية المتضمنة في الدالة permute() نوقشت في المجلد 4 (لا يزال غير منشور) من كتاب Knuth's The Art of Computer Programming وستعمل على أي قائمة:

#!/usr/bin/perl -n
# مولد تباديل مرتبة Fischer-Krause
sub permute (&@) {
    my $code = shift;
    my @idx = 0..$#_;
    while ( $code->(@_[@idx]) ) {
        my $p = $#idx;
        --$p while $idx[$p-1] > $idx[$p];
        my $q = $p or return;
        push @idx, reverse splice @idx, $p;
        ++$q while $idx[$p-1] > $idx[$q];
        @idx[$p-1,$q]=@idx[$q,$p-1];
    }
}
permute { print "@_\n" } split;

توفر وحدة Algorithm::Loops أيضًا الدوال "NextPermute" و "NextPermuteNum" التي تجد بكفاءة جميع التباديل الفريدة لمصفوفة، حتى لو كانت تحتوي على قيم مكررة، وتقوم بتعديلها في مكانها: إذا كانت عناصرها مرتبة بترتيب عكسي، فسيتم عكس المصفوفة، مما يجعلها مرتبة، وتعيد خطأ؛ وإلا، فسيتم إعادة التبديل التالي.

يستخدم "NextPermute" ترتيب السلاسل النصية، و "NextPermuteNum" ترتيب الأرقام، لذلك يمكنك تعداد جميع تباديل 0..9 هكذا:

use Algorithm::Loops qw(NextPermuteNum);
my @list= 0..9;
do { print "@list\n" } while NextPermuteNum @list;

كيف أقوم بفرز مصفوفة حسب (أي شيء)؟

قم بتوفير دالة مقارنة لـ sort() (الموصوفة في "sort" في perlfunc):

@list = sort { $a <=> $b } @list;

دالة الفرز الافتراضية هي cmp، وهي مقارنة سلاسل نصية، والتي ستفرز "(1, 2, 10)" إلى "(1, 10, 2)". "<=>"، المستخدمة أعلاه، هي عامل مقارنة الأرقام.

إذا كان لديك دالة معقدة مطلوبة لسحب الجزء الذي تريد الفرز عليه، فلا تقم بذلك داخل دالة الفرز. اسحبه أولاً، لأن BLOCK الفرز يمكن استدعاؤه عدة مرات لنفس العنصر. إليك مثال لكيفية سحب الكلمة الأولى بعد الرقم الأول في كل عنصر، ثم فرز تلك الكلمات بشكل غير حساس لحالة الأحرف.

my @idx;
for (@data) {
    my $item;
    ($item) = /\d+\s*(\S+)/;
    push @idx, uc($item);
}
my @sorted = @data[ sort { $idx[$a] cmp $idx[$b] } 0 .. $#idx ];

والتي يمكن كتابتها أيضًا بهذه الطريقة، باستخدام خدعة أصبحت تُعرف باسم تحويل شوتز (Schwartzian Transform):

my @sorted = map  { $_->[0] }
    sort { $a->[1] cmp $b->[1] }
    map  { [ $_, uc( (/\d+\s*(\S+)/)[0]) ] } @data;

إذا كنت بحاجة إلى الفرز حسب عدة حقول، فإن النموذج التالي مفيد.

my @sorted = sort {
    field1($a) <=> field1($b) ||
    field2($a) cmp field2($b) ||
    field3($a) cmp field3($b)
} @data;

يمكن دمج هذا بشكل ملائم مع الحساب المسبق للمفاتيح كما هو موضح أعلاه.

راجع مقال sort في مجموعة "Far More Than You Ever Wanted To Know" في http://www.cpan.org/misc/olddoc/FMTEYEWTK.tgz لمزيد من المعلومات حول هذا النهج.

انظر أيضًا السؤال لاحقًا في perlfaq4 حول فرز الـ hashes.

كيف أتعامل مع مصفوفات البتات؟

استخدم pack() و unpack()، أو vec() وعمليات البت.

على سبيل المثال، ليس عليك تخزين البتات الفردية في مصفوفة (مما يعني أنك تهدر الكثير من المساحة). لتحويل مصفوفة بتات إلى سلسلة نصية، استخدم vec() لتعيين البتات الصحيحة. هذا يعين $vec ليكون البت N معينًا فقط إذا كان $ints[N] معينًا:

my @ints = (...); # مصفوفة بتات، على سبيل المثال ( 1, 0, 0, 1, 1, 0 ... )
my $vec = '';
foreach( 0 .. $#ints ) {
    vec($vec,$_,1) = 1 if $ints[$_];
}

السلسلة النصية $vec تستهلك فقط عدد البتات التي تحتاجها. على سبيل المثال، إذا كان لديك 16 إدخالًا في @ints، فإن $vec يحتاج فقط إلى بايتين لتخزينها (باستثناء تكاليف المتغير القياسي).

إليك كيف، عند وجود متجه في $vec، يمكنك الحصول على تلك

بتات في مصفوفة @ints الخاصة بك:

sub bitvec_to_list {
    my $vec = shift;
    my @ints;
    # ابحث عن كثافة البايتات الفارغة ثم اختر الخوارزمية الأفضل
    if ($vec =~ tr/\0// / length $vec > 0.95) {
        use integer;
        my $i;
        # هذه الطريقة أسرع مع البايتات الفارغة في الغالب
        while($vec =~ /[^\0]/g ) {
            $i = -9 + 8 * pos $vec;
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
            push @ints, $i if vec($vec, ++$i, 1);
        }
    }
    else {
        # هذه الطريقة خوارزمية عامة سريعة
        use integer;
        my $bits = unpack "b*", $vec;
        push @ints, 0 if $bits =~ s/^(\d)// && $1;
        push @ints, pos $bits while($bits =~ /1/g);
    }
    return \@ints;
}

تصبح هذه الطريقة أسرع كلما كان متجه البتات أكثر تفرقًا. (بإذن من تيم بونـس ووينفريد كونيغ.)

يمكنك جعل حلقة `while` أقصر بكثير مع هذا الاقتراح من بنجامين غولدبرغ:

while($vec =~ /[^\0]+/g ) {
    push @ints, grep vec($vec, $_, 1), $-[0] * 8 .. $+[0] * 8;
}

أو استخدم وحدة CPAN Bit::Vector:

my $vector = Bit::Vector->new($num_of_bits);
$vector->Index_List_Store(@ints);
my @ints = $vector->Index_List_Read();

لماذا تعيد defined() القيمة صحيحة على المصفوفات والخرائط الفارغة؟

القصة المختصرة هي أنه يجب عليك استخدام `defined` على القيم المفردة أو الدوال، وليس على المجموعات (المصفوفات والخرائط). انظر "defined" في perlfunc في الإصدار 5.004 أو أحدث من Perl لمزيد من التفاصيل.

البيانات: الخرائط (المصفوفات الترابطية)

كيف أعالج خريطة بأكملها؟

(مقدمة من بريان دي فوي)

هناك طريقتان يمكنك من خلالهما معالجة خريطة بأكملها. يمكنك الحصول على قائمة بالمفاتيح، ثم المرور عبر كل مفتاح، أو الحصول على زوج مفتاح-قيمة واحد في كل مرة.

للمرور عبر جميع المفاتيح، استخدم الدالة "keys". هذه تستخرج جميع مفاتيح الخريطة وتعيدها لك كقائمة. يمكنك بعد ذلك الحصول على القيمة من خلال المفتاح المحدد الذي تعالجه:

foreach my $key ( keys %hash ) {
    my $value = $hash{$key};
    ...
}

بمجرد حصولك على قائمة المفاتيح، يمكنك معالجة هذه القائمة قبل معالجة عناصر الخريطة. على سبيل المثال، يمكنك فرز المفاتيح بحيث يمكنك معالجتها بترتيب أبجدي:

foreach my $key ( sort keys %hash ) {
    my $value = $hash{$key};
    ...
}

أو، قد ترغب في معالجة بعض العناصر فقط. إذا كنت ترغب فقط في التعامل مع المفاتيح التي تبدأ بـ "text:"، يمكنك تحديد تلك فقط باستخدام "grep":

foreach my $key ( grep /^text:/, keys %hash ) {
    my $value = $hash{$key};
    ...
}

إذا كانت الخريطة كبيرة جدًا، فقد لا ترغب في إنشاء قائمة طويلة من المفاتيح. لتوفير بعض الذاكرة، يمكنك الحصول على زوج مفتاح-قيمة واحد في كل مرة باستخدام each()، والتي تعيد زوجًا لم تره بعد:

while( my( $key, $value ) = each( %hash ) ) {
    ...
}

يعيد عامل التشغيل "each" الأزواج بترتيب عشوائي ظاهريًا، لذلك إذا كان الترتيب مهمًا بالنسبة لك، فسيتعين عليك الالتزام بطريقة "keys".

يمكن أن يكون عامل التشغيل each() صعبًا بعض الشيء. لا يمكنك إضافة أو حذف مفاتيح الخريطة أثناء استخدامه دون احتمال تخطي أو إعادة معالجة بعض الأزواج بعد أن تعيد Perl بناء جدول الخريطة داخليًا. بالإضافة إلى ذلك، تحتوي الخريطة على مكرر واحد فقط، لذلك إذا قمت بخلط "keys"، "values"، أو "each" على نفس الخريطة، فإنك تخاطر بإعادة تعيين المكرر وتعطيل معالجتك. انظر إدخال "each" في perlfunc لمزيد من التفاصيل.

كيف أدمج خريطتين؟

(مقدمة من بريان دي فوي)

قبل أن تقرر دمج خريطتين، يجب عليك أن تقرر ما يجب فعله إذا كانت كلتا الخريطتين تحتويان على مفاتيح متطابقة وما إذا كنت تريد ترك الخرائط الأصلية كما كانت.

إذا كنت تريد الاحتفاظ بالخرائط الأصلية، انسخ خريطة واحدة (%hash1) إلى خريطة جديدة (%new_hash)، ثم أضف المفاتيح من الخريطة الأخرى (%hash2) إلى الخريطة الجديدة. التحقق من وجود المفتاح بالفعل في %new_hash يمنحك فرصة لاتخاذ قرار بشأن ما يجب فعله مع التكرارات:

my %new_hash = %hash1; # make a copy; leave %hash1 alone
foreach my $key2 ( keys %hash2 ) {
    if( exists $new_hash{$key2} ) {
        warn "Key [$key2] is in both hashes!";
        # handle the duplicate (perhaps only warning)
        ...
        next;
    }
    else {
        $new_hash{$key2} = $hash2{$key2};
    }
}

إذا لم تكن تريد إنشاء خريطة جديدة، يمكنك لا يزال استخدام تقنية التكرار هذه؛ فقط استبدل %new_hash بـ %hash1.

foreach my $key2 ( keys %hash2 ) {
    if( exists $hash1{$key2} ) {
        warn "Key [$key2] is in both hashes!";
        # handle the duplicate (perhaps only warning)
        ...
        next;
    }
    else {
        $hash1{$key2} = $hash2{$key2};
    }
  }

إذا كنت لا تهتم بأن تقوم خريطة بالكتابة فوق مفاتيح وقيم خريطة أخرى، يمكنك ببساطة استخدام شريحة خريطة لإضافة خريطة إلى أخرى. في هذه الحالة، تحل القيم من %hash2 محل القيم من %hash1 عندما يكون لديهما مفاتيح مشتركة:

@hash1{ keys %hash2 } = values %hash2;

ماذا يحدث إذا قمت بإضافة أو إزالة مفاتيح من خريطة أثناء التكرار عليها؟

(مقدمة من بريان دي فوي)

الإجابة السهلة هي "لا تفعل ذلك!"

إذا قمت بالتكرار على الخريطة باستخدام each()، يمكنك حذف المفتاح الذي تم إرجاعه مؤخرًا دون القلق بشأنه. إذا قمت بحذف أو إضافة مفاتيح أخرى، فقد يتخطى المكررها أو يكررها لأن Perl قد يعيد ترتيب جدول الخريطة. انظر إدخال each() في perlfunc.

كيف يمكنني البحث عن عنصر خريطة بواسطة القيمة؟

قم بإنشاء خريطة عكسية:

my %by_value = reverse %by_key;
my $key = $by_value{$value};

هذا ليس فعالاً بشكل خاص. سيكون أكثر كفاءة من حيث المساحة استخدام:

while (my ($key, $value) = each %by_key) {
    $by_value{$value} = $key;
}

إذا كان يمكن أن تحتوي خريطتك على قيم متكررة، فإن الطرق المذكورة أعلاه ستجد مفتاحًا واحدًا فقط من المفاتيح المرتبطة. قد يثير هذا قلقك أو لا. إذا كان يثير قلقك، يمكنك دائمًا عكس الخريطة إلى خريطة مصفوفات بدلاً من ذلك:

while (my ($key, $value) = each %by_key) {
     push @{$key_list_by_value{$value}}, $key;
}

كيف يمكنني معرفة عدد الإدخالات في خريطة؟

(مقدمة من بريان دي فوي)

هذا مشابه جدًا لـ "كيف أعالج خريطة بأكملها؟"، أيضًا في perlfaq4، ولكنه أبسط قليلاً في الحالات الشائعة.

يمكنك استخدام الدالة المضمنة keys() في سياق قيمة مفردة لمعرفة عدد الإدخالات التي لديك في خريطة:

my $key_count = keys %hash; # must be scalar context!

إذا كنت تريد معرفة عدد الإدخالات التي لها قيمة معرفة، فهذا مختلف قليلاً. يجب عليك التحقق من كل قيمة. "grep" مفيدة:

my $defined_value_count = grep { defined } values %hash;

يمكنك استخدام نفس البنية لعد الإدخالات بأي طريقة تريدها. إذا كنت تريد عدد المفاتيح التي تحتوي على حروف متحركة فيها، فما عليك سوى الاختبار لذلك بدلاً من ذلك:

my $vowel_count = grep { /[aeiou]/ } keys %hash;

يعيد "grep" في سياق قيمة مفردة العدد. إذا كنت تريد قائمة بالعناصر المتطابقة، فما عليك سوى استخدامه في سياق قائمة بدلاً من ذلك:

my @defined_values = grep { defined } values %hash;

الدالة keys() تعيد تعيين المكرر أيضًا، مما يعني أنك قد ترى نتائج غريبة إذا استخدمت هذا بين استخدامات عوامل تشغيل الخرائط الأخرى مثل each().

كيف أقوم بفرز خريطة (اختياريًا حسب القيمة بدلاً من المفتاح)؟

(مقدمة من بريان دي فوي)

لفرز خريطة، ابدأ بالمفاتيح. في هذا المثال، نعطي قائمة المفاتيح لدالة الفرز التي تقارنها كسلاسل نصية. تحتوي قائمة الإخراج على المفاتيح بترتيب السلاسل النصية. بمجرد حصولنا على المفاتيح، يمكننا المضي قدمًا

من خلالها لإنشاء تقرير يسرد المفاتيح بترتيب السلسلة: 

my @keys = sort { $a cmp $b } keys %hash;
foreach my $key ( @keys ) {
    printf "%-20s %6d\n", $key, $hash{$key};
}

يمكننا أن نكون أكثر براعة في كتلة sort() رغم ذلك. بدلاً من مقارنة المفاتيح، يمكننا حساب قيمة بها واستخدام تلك القيمة للمقارنة.

على سبيل المثال، لجعل تقريرنا مرتبًا غير حساس لحالة الأحرف، نستخدم "fc" لتحويل المفاتيح إلى أحرف صغيرة بأمان قبل مقارنتها: 

use v5.16;
my @keys = sort { fc($a) cmp fc($b) } keys %hash;

الإصدارات السابقة من هذه الإجابة استخدمت "lc"، ولكن هذا يمكن أن يعطي نتائج غير متوقعة مع بعض سلاسل Unicode. انظر "fc" في perlfunc للحصول على التفاصيل. تقوم وحدة Unicode::UCD بنفس الشيء للإصدارات الأقدم من Perl.

ملاحظة: إذا كان الحساب مكلفًا أو كان يحتوي على العديد من العناصر، فقد ترغب في النظر في تحويل Schwartzian لتحويل نتائج الحساب.

إذا أردنا الفرز حسب قيمة التجزئة بدلاً من ذلك، نستخدم مفتاح التجزئة للبحث عنها. لا نزال نحصل على قائمة من المفاتيح، ولكن هذه المرة يتم ترتيبها حسب قيمتها: 

my @keys = sort { $hash{$a} <=> $hash{$b} } keys %hash;

من هناك يمكننا أن نصبح أكثر تعقيدًا. إذا كانت قيم التجزئة متساوية، يمكننا توفير فرز ثانوي على مفتاح التجزئة: 

use v5.16;
my @keys = sort {
    $hash{$a} <=> $hash{$b}
        or
    fc($a) cmp fc($b)
} keys %hash;

كيف يمكنني دائمًا الاحتفاظ بالتجزئة الخاصة بي مرتبة؟

يمكنك النظر في استخدام وحدة "DB_File" و tie() باستخدام ربط التجزئة $DB_BTREE كما هو موثق في "قواعد بيانات في الذاكرة" في DB_File. قد تكون وحدة Tie::IxHash من CPAN مفيدة أيضًا. على الرغم من أن هذا يحافظ على ترتيب التجزئة الخاصة بك، فقد لا تحب التباطؤ الذي تعاني منه من واجهة tie. هل أنت متأكد من أنك بحاجة إلى القيام بذلك؟ :)

ما هو الفرق بين "delete" و "undef" مع التجزئات؟

تحتوي التجزئات على أزواج من القيم الأحادية: الأول هو المفتاح، والثاني هو القيمة. سيتم تحويل المفتاح إلى سلسلة، على الرغم من أن القيمة يمكن أن تكون أي نوع من القيم الأحادية: سلسلة، رقم، أو مرجع. إذا كان المفتاح $key موجودًا في %hash، فستعيد exists($hash{$key}) القيمة true. يمكن أن تكون القيمة لمفتاح معين "undef"، وفي هذه الحالة ستكون $hash{$key} "undef" بينما ستعيد "exists $hash{$key}" القيمة true. هذا يتوافق مع كون ($key، "undef") في التجزئة.

الصور تساعد ... إليك جدول %hash: 

  keys  values
+------+------+
|  a   |  3   |
|  x   |  7   |
|  d   |  0   |
|  e   |  2   |
+------+------+

وتتحقق هذه الشروط 

$hash{'a'}                       is true
$hash{'d'}                       is false
defined $hash{'d'}               is true
defined $hash{'a'}               is true
exists $hash{'a'}                is true (Perl 5 only)
grep ($_ eq 'a', keys %hash)     is true

إذا قلت الآن 

undef $hash{'a'}

الآن يقرأ جدولك: 

  keys  values
+------+------+
|  a   | undef|
|  x   |  7   |
|  d   |  0   |
|  e   |  2   |
+------+------+

وتتحقق هذه الشروط الآن؛ التغييرات بالأحرف الكبيرة: 

$hash{'a'}                       is FALSE
$hash{'d'}                       is false
defined $hash{'d'}               is true
defined $hash{'a'}               is FALSE
exists $hash{'a'}                is true (Perl 5 only)
grep ($_ eq 'a', keys %hash)     is true

لاحظ آخر اثنين: لديك قيمة غير معرفة، ولكن مفتاح معرف!

الآن، انظر إلى هذا: 

delete $hash{'a'}

الآن يقرأ جدولك: 

  keys  values
+------+------+
|  x   |  7   |
|  d   |  0   |
|  e   |  2   |
+------+------+

وتتحقق هذه الشروط الآن؛ التغييرات بالأحرف الكبيرة: 

$hash{'a'}                       is false
$hash{'d'}                       is false
defined $hash{'d'}               is true
defined $hash{'a'}               is false
exists $hash{'a'}                is FALSE (Perl 5 only)

لماذا لا تقوم التجزئات المرتبطة بي بتمييز معرف/موجود؟

يعتمد هذا على تنفيذ التجزئة المرتبطة لـ EXISTS(). على سبيل المثال، لا يوجد مفهوم غير معرف مع التجزئات المرتبطة بملفات DBM*. وهذا يعني أيضًا أن exists() و defined() يفعلان نفس الشيء مع ملف DBM*، وما ينتهي بهما فعله ليس ما يفعلانه مع التجزئات العادية.

كيف يمكنني إعادة تعيين عملية each() في منتصف الطريق؟

(مساهمة من brian d foy)

يمكنك استخدام الدوال "keys" أو "values" لإعادة تعيين "each". لإعادة تعيين المكرر المستخدم بواسطة "each" ببساطة دون القيام بأي شيء آخر، استخدم أحدهما في سياق فارغ: 

keys %hash; # resets iterator, nothing else.
values %hash; # resets iterator, nothing else.

انظر وثائق "each" في perlfunc.

كيف يمكنني الحصول على المفاتيح الفريدة من تجزئتين؟

أولاً، تستخرج المفاتيح من التجزئات إلى قوائم، ثم تحل مشكلة "إزالة التكرارات" الموضحة أعلاه. على سبيل المثال: 

my %seen = ();
for my $element (keys(%foo), keys(%bar)) {
    $seen{$element}++;
}
my @uniq = keys %seen;

أو بشكل موجز أكثر: 

my @uniq = keys %{{%foo,%bar}};

أو إذا كنت تريد حقًا توفير المساحة: 

my %seen = ();
while (defined ($key = each %foo)) {
    $seen{$key}++;
}
while (defined ($key = each %bar)) {
    $seen{$key}++;
}
my @uniq = keys %seen;

كيف يمكنني تخزين مصفوفة متعددة الأبعاد في ملف DBM؟

قم بتحويل البنية إلى سلسلة بنفسك (غير ممتع)، أو احصل على وحدة MLDBM (التي تستخدم Data::Dumper) من CPAN وضعها فوق DB_File أو GDBM_File. قد تجرب أيضًا DBM::Deep، ولكنه قد يكون بطيئًا بعض الشيء.

كيف يمكنني جعل التجزئة الخاصة بي تتذكر الترتيب الذي وضعت به العناصر فيها؟

استخدم Tie::IxHash من CPAN. 

use Tie::IxHash;
tie my %myhash, 'Tie::IxHash';
for (my $i=0; $i<20; $i++) {
    $myhash{$i} = 2*$i;
}
my @keys = keys %myhash;
# @keys = (0,1,2,3,...)

لماذا يقوم تمرير عنصر غير معرف في تجزئة إلى روتين فرعي بإنشائه؟

(مساهمة من brian d foy)

هل تستخدم إصدارًا قديمًا جدًا من Perl؟

عادةً، الوصول إلى قيمة مفتاح التجزئة لمفتاح غير موجود لن ينشئ المفتاح.

my %hash  = ();
my $value = $hash{ 'foo' };
print "This won't print\n" if exists $hash{ 'foo' };

كان تمرير $hash{ 'foo' } إلى روتين فرعي حالة خاصة، ومع ذلك. نظرًا لأنه يمكنك التعيين مباشرة إلى $_[0]، كان على Perl أن يكون جاهزًا لإجراء هذا التعيين، لذلك أنشأ مفتاح التجزئة مسبقًا: 

my_sub( $hash{ 'foo' } );
print "This will print before 5.004\n" if exists $hash{ 'foo' };
sub my_sub {
    # $_[0] = 'bar'; # create hash key in case you do this
    1;
}

منذ Perl 5.004، ومع ذلك، فإن هذه الحالة هي حالة خاصة، وينشئ Perl مفتاح التجزئة فقط عند إجراء التعيين: 

my_sub( $hash{ 'foo' } );
print "This will print, even after 5.004\n" if exists $hash{ 'foo' };
sub my_sub {
    $_[0] = 'bar';
}

ومع ذلك، إذا كنت تريد السلوك القديم (وفكر مليًا في ذلك لأنه تأثير جانبي غريب)، يمكنك تمرير شريحة تجزئة بدلاً من ذلك. لم تجعل Perl 5.004 هذه حالة خاصة: 

my_sub( @hash{ qw/foo/ } );

كيف يمكنني إنشاء ما يعادل Perl لهيكل C/فئة C++/تجزئة أو مصفوفة من التجزئات أو المصفوفات؟

عادةً ما يكون مرجع تجزئة، ربما مثل هذا: 

$record = {
    NAME   => "Jason",
    EMPNO  => 132,
    TITLE  => "deputy peon",
    AGE    => 23,
    SALARY => 37_000,

How can I get the reference to a hash entry?

You can't directly. Perl doesn't let you get a reference to a hash entry.

There are some workarounds. You can get a reference to the hash itself, and then pass keys to the subroutities. Or you can use the "Tie::RefHash" module from CPAN. This module allows you to tie a hash to a class that provides references to its values.

Here's a simplified example using "Tie::RefHash":

use Tie::RefHash;
tie my %rh, 'Tie::RefHash';
my $scalar = 10;
$rh{$scalar} = \$scalar;
my $arrayref = [1, 2, 3];
$rh{$arrayref} = \$arrayref;

Now $rh behaves like a regular hash, but its values are references. When you access $rh with a key, it stringifies the key, finds the reference, and returns it.

Note that this module requires Perl 5.005 or later. If you are using an older version of Perl, you will need to use a different method.

A common method for older Perls is to use a hash of hashes, where the inner hash holds the references. For example:

my %hash;
my $scalar = 10;
$hash{scalar_key} = { value => \$scalar };
my $arrayref = [1, 2, 3];
$hash{arrayref_key} = { value => \$arrayref };

This approach is less elegant but works in all versions of Perl.

How can I check if a key exists in a multilevel hash?

(contributed by brian d foy)

The trick to this problem is avoiding accidental autovivification. If you want to check three keys deep, you might naively try this:

my %hash;
if( exists $hash{key1}{key2}{key3} ) {
    ...;
}

Even though you started with a completely empty hash, after that call to "exists" you've created the structure you needed to check for "key3":

%hash = (
          'key1' => {
                      'key2' => {}
                    }
        );

That's autovivification. You can get around this in a few ways. The easiest way is to just turn it off. The lexical "autovivification" pragma is available on CPAN. Now you don't add to the hash:

{
    no autovivification;
    my %hash;
    if( exists $hash{key1}{key2}{key3} ) {
        ...;
    }
}

The Data::Diver module on CPAN can do it for you too. Its "Dive" subroutine can tell you not only if the keys exist but also get the value:

use Data::Diver qw(Dive);
my @exists = Dive( \%hash, qw(key1 key2 key3) );
if(  ! @exists  ) {
    ...; # keys do not exist
}
elsif(  ! defined $exists[0]  ) {
    ...; # keys exist but value is undef
}

You can easily do this yourself too by checking each level of the hash before you move onto the next level. This is essentially what Data::Diver does for you:

if( check_hash( \%hash, qw(key1 key2 key3) ) ) {
    ...;
}
sub check_hash {
   my( $hash, @keys ) = @_;
   return unless @keys;
   foreach my $key ( @keys ) {
       return unless eval { exists $hash->{$key} };
       $hash = $hash->{$key};
    }
   return 1;
}

How can I prevent addition of unwanted keys into a hash?

Since version 5.8.0, hashes can be restricted to a fixed number of given keys. Methods for creating and dealing with restricted hashes are exported by the Hash::Util module.

Data: Misc

How do I handle binary data correctly?

Perl is binary-clean, so it can handle binary data just fine. On Windows or DOS, however, you have to use "binmode" for binary files to avoid conversions for line endings. In general, you should use "binmode" any time you want to work with binary data.

Also see "binmode" in perlfunc or perlopentut.

If you're concerned about 8-bit textual data then see perllocale. If you want to deal with multibyte characters, however, there are some gotchas. See the section on Regular Expressions.

How do I determine whether a scalar is a number/whole/integer/float?

Assuming that you don't care about IEEE notations like "NaN" or "Infinity", you probably just want to use a regular expression (see also perlretut and perlre):

use 5.010;
if ( /\D/ )
    { say "\thas nondigits"; }
if ( /^\d+\z/ )
    { say "\tis a whole number"; }
if ( /^-?\d+\z/ )
    { say "\tis an integer"; }
if ( /^[+-]?\d+\z/ )
    { say "\tis a +/- integer"; }
if ( /^-?(?:\d+\.?|\.\d)\d*\z/ )
    { say "\tis a real number"; }
if ( /^[+-]?(?=\.?\d)\d*\.?\d*(?:e[+-]?\d+)?\z/i )
    { say "\tis a C float" }

There are also some commonly used modules for the task. Scalar::Util (distributed with 5.8) provides access to perl's internal function "looks_like_number" for determining whether a variable looks like a number. Data::Types exports functions that validate data types using both the above and other regular expressions. Thirdly, there is Regexp::Common which has regular expressions to match various types of numbers. Those three modules are available from the CPAN.

If you're on a POSIX system, Perl supports the "POSIX::strtod" function for converting strings to doubles (and also "POSIX::strtol" for longs). Its semantics are somewhat cumbersome, so here's a

  • "getnum" wrapper function for more convenient access. This function takes a string and returns the number it found, or "undef" for input that isn't a C float. The "is_numeric" function is a front end to "getnum" if you just want to say, "Is this a float?"

    sub getnum {
    use POSIX qw(strtod);
    my $str = shift;
    $str =~ s/^\s+//;
    $str =~ s/\s+$//;
    $! = 0;
    my($num, $unparsed) = strtod($str);
    if (($str eq '') || ($unparsed != 0) || $!) {
            return undef;
    }
    else {
        return $num;
    }
}
sub is_numeric { defined getnum($_[0]) }

    • How do I keep persistent data across program calls?

    For some specific applications, you can use one of the DBM modules. See AnyDBM_File. More generically, you should consult the FreezeThaw or Storable modules from CPAN. Starting from Perl 5.8, Storable is part of the standard distribution. Here's one example using Storable's "store" and "retrieve" functions:

    use Storable;
store(\%hash, "filename");
# later on...
$href = retrieve("filename");        # by ref
%hash = %{ retrieve("filename") };   # direct to hash

    How do I print out or copy a recursive data structure?

    The Data::Dumper module on CPAN (or the 5.005 release of Perl) is great for printing out data structures. The Storable module on CPAN (or the 5.8 release of Perl), provides a function called "dclone" that recursively copies its argument.

    use Storable qw(dclone);
$r2 = dclone($r1);

    Where $r1 can be a reference to any kind of data structure you'd like. It will be deeply copied. Because "dclone" takes and returns references, you'd have to add extra punctuation if you had a hash of arrays that you wanted to copy.

    %newhash = %{ dclone(\%oldhash) };

    How do I define methods for every class/object?

    (contributed by Ben Morrow)

    You can use the "UNIVERSAL" class (see UNIVERSAL). However, please be very careful to consider the consequences of doing this: adding methods to every object is very likely to have unintended consequences. If possible, it would be better to have all your objects inherit from some common base class, or to use an object system like Moose that supports roles.
