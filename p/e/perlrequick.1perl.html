PERLREQUICK(1perl) دليل المبرمجين بيرل PERLREQUICK(1perl)

الاسم

perlrequick - دليل بيرل السريع للتعبيرات القياسية

الوصف

تتناول هذه الصفحة الأساسيات جداً لفهم وإنشاء واستخدام التعبيرات القياسية ('regexes') في بيرل.

الدليل

تفترض هذه الصفحة أنك تعرف بالفعل أشياء مثل، ما هو "النمط" (pattern)، والصيغة الأساسية لاستخدامها. إذا لم تكن كذلك، فراجع perlretut.

مطابقة الكلمات البسيطة

أبسط تعبير قياسي هو مجرد كلمة، أو بشكل أعم، سلسلة من الأحرف. تعبير قياسي يتكون من كلمة يطابق أي سلسلة تحتوي على تلك الكلمة:

"Hello World" =~ /World/;  # يطابق

في هذه العبارة، "World" هو تعبير قياسي، و "//" الذي يحيط بـ "/World/" يخبر بيرل بالبحث عن تطابق في سلسلة. العامل "=~" يربط السلسلة بمطابقة التعبير القياسي وينتج قيمة صحيحة إذا تطابق التعبير القياسي، أو قيمة خاطئة إذا لم يتطابق. في حالتنا، "World" تطابق الكلمة الثانية في "Hello World"، لذا فإن العبارة صحيحة. هذه الفكرة لها العديد من الاختلافات.

عبارات مثل هذه مفيدة في الشروط:

print "It matches\n" if "Hello World" =~ /World/;  # اطبع "إنه يطابق" إذا "Hello World" تطابق /World/

يمكن عكس حس المطابقة باستخدام العامل "!~":

print "It doesn't match\n" if "Hello World" !~ /World/; # اطبع "لا يتطابق" إذا "Hello World" لا تطابق /World/

يمكن استبدال السلسلة الحرفية في التعبير القياسي بمتغير:

$greeting = "World";
print "It matches\n" if "Hello World" =~ /$greeting/; # اطبع "إنه يطابق" إذا "Hello World" تطابق $greeting

إذا كنت تطابق مع $_، يمكن حذف جزء "$_ =~":

$_ = "Hello World";
print "It matches\n" if /World/; # اطبع "إنه يطابق" إذا /World/

أخيراً، يمكن تغيير المحددات الافتراضية "//" للمطابقة إلى محددات اعتباطية بوضع حرف 'm' في المقدمة:

"Hello World" =~ m!World!;   # يطابق، محددة بـ '!'
"Hello World" =~ m{World};   # يطابق، لاحظ الأقواس المتطابقة '{}'
"/usr/bin/perl" =~ m"/perl"; # يطابق بعد '/usr/bin'،
                             # '/' تصبح حرفاً عادياً

يجب أن تطابق التعبيرات القياسية جزءًا من السلسلة *بالضبط* حتى تعتبر العبارة صحيحة:

"Hello World" =~ /world/;  # لا يتطابق، حساسية الأحرف
"Hello World" =~ /o W/;    # يطابق، ' ' هو حرف عادي
"Hello World" =~ /World /; # لا يتطابق، لا يوجد ' ' في النهاية

سيقوم بيرل دائمًا بالمطابقة في أبكر نقطة ممكنة في السلسلة:

"Hello World" =~ /o/;       # يطابق 'o' في 'Hello'
"That hat is red" =~ /hat/; # يطابق 'hat' في 'That'

لا يمكن استخدام جميع الأحرف 'كما هي' في المطابقة. بعض الأحرف، تسمى **الأحرف الخاصة** (metacharacters)، تعتبر خاصة، ومحجوزة للاستخدام في ترميز التعبيرات القياسية. الأحرف الخاصة هي

{}[]()^$.|*+?\

يمكن مطابقة حرف خاص حرفياً بوضع شرطة مائلة عكسية قبله:

"2+2=4" =~ /2+2/;    # لا يتطابق، '+' حرف خاص
"2+2=4" =~ /2\+2/;   # يطابق، \+ يعامل كـ + عادي
'C:\WIN32' =~ /C:\\WIN/;                       # يطابق
"/usr/bin/perl" =~ /\/usr\/bin\/perl/;  # يطابق

في التعبير القياسي الأخير، يتم أيضاً إزالة الشرطة المائلة '/'، لأنها تستخدم لتحديد التعبير القياسي.

معظم الأحرف الخاصة ليست خاصة دائماً، وأحرف أخرى (مثل تلك التي تحدد النمط) تصبح خاصة في ظروف مختلفة. هذا يمكن أن يكون مربكاً ويؤدي إلى نتائج غير متوقعة. "use re 'strict'" يمكن أن تنبهك إلى المخاطر المحتملة.

يتم تمثيل الأحرف غير القابلة للطباعة في ASCII بواسطة **تسلسلات الهروب** (escape sequences). أمثلة شائعة هي "\t" للجدولة (tab)، "\n" لسطر جديد (newline)، و "\r" لحرف الإرجاع (carriage return). يتم تمثيل البايتات العشوائية بواسطة تسلسلات الهروب الثمانية، مثال: "\033"، أو تسلسلات الهروب الست عشرية، مثال: "\x1B":

"1000\t2000" =~ m(0\t2)  # يطابق
"cat" =~ /\143\x61\x74/  # يطابق في ASCII، ولكن
                         # طريقة غريبة لكتابة cat

يتم التعامل مع التعبيرات القياسية بشكل كبير مثل السلاسل ذات الاقتباس المزدوج، لذلك يعمل استبدال المتغيرات:

$foo = 'house';
'cathouse' =~ /cat$foo/;   # يطابق
'housecat' =~ /${foo}cat/; # يطابق

مع كل التعبيرات القياسية أعلاه، إذا تطابق التعبير القياسي في أي مكان في السلسلة، فقد اعتبر ذلك تطابقاً. لتحديد *مكان* يجب أن يتطابق، سنستخدم **مراسي** (anchors) الأحرف الخاصة "^" و "$". المرساة "^" تعني المطابقة في بداية السلسلة والمرساة "$" تعني المطابقة في نهاية السلسلة، أو قبل سطر جديد في نهاية السلسلة. بعض الأمثلة:

"housekeeper" =~ /keeper/;         # يطابق
"housekeeper" =~ /^keeper/;        # لا يتطابق
"housekeeper" =~ /keeper$/;        # يطابق
"housekeeper\n" =~ /keeper$/;      # يطابق
"housekeeper" =~ /^housekeeper$/;  # يطابق

استخدام فئات الأحرف

تسمح **فئة الأحرف** (character class) بمجموعة من الأحرف الممكنة، بدلاً من حرف واحد فقط، للمطابقة في نقطة معينة في التعبير القياسي. هناك عدد من الأنواع المختلفة لفئات الأحرف، ولكن عادةً عندما يستخدم الناس هذا المصطلح، فإنهم يشيرون إلى النوع الموصوف في هذا القسم، والذي يسمى تقنياً "فئات الأحرف المقوسة"، لأنها محددة بأقواس "[...]"، مع مجموعة الأحرف التي يجب مطابقتها داخلها. لكننا سنتخلى عن "المقوسة" أدناه لتتوافق مع الاستخدام الشائع. إليك بعض الأمثلة على فئات الأحرف (المقوسة):

/cat/;            # يطابق 'cat'
/[bcr]at/;        # يطابق 'bat', 'cat', أو 'rat'
"abc" =~ /[cab]/; # يطابق 'a'

في العبارة الأخيرة، حتى لو كان 'c' هو الحرف الأول في الفئة، فإن أبكر نقطة يمكن للتعبير القياسي المطابقة فيها هي 'a'.

/[yY][eE][sS]/; # يطابق 'yes' بطريقة غير حساسة لحالة الأحرف
                # 'yes', 'Yes', 'YES', إلخ.
/yes/i;         # يطابق أيضاً 'yes' بطريقة غير حساسة لحالة الأحرف

يوضح المثال الأخير المطابقة مع **معدّل** (modifier) 'i'، الذي يجعل المطابقة غير حساسة لحالة الأحرف.

تحتوي فئات الأحرف أيضاً على أحرف عادية وأحرف خاصة، ولكن مجموعات الأحرف العادية والخاصة داخل فئة الأحرف تختلف عن تلك الموجودة خارج فئة الأحرف. الأحرف الخاصة لفئة الأحرف هي "-]\^$" ويتم مطابقتها باستخدام هروب (escape):

/[\]c]def/; # يطابق ']def' أو 'cdef'
$x = 'bcr';
/[$x]at/;   # يطابق 'bat', 'cat', أو 'rat'
/[\$x]at/;  # يطابق '$at' أو 'xat'
/[\\$x]at/; # يطابق '\at', 'bat', 'cat', أو 'rat'

الحرف الخاص '-' يعمل كعامل نطاق (range operator) داخل فئات الأحرف، بحيث يصبح "[0123456789]" و "[abc...xyz]" التي تبدو مملة أكثر أناقة "[0-9]" و "[a-z]":

/item[0-9]/;  # يطابق 'item0' أو ... أو 'item9'
/[0-9a-fA-F]/;  # يطابق رقماً ست عشرياً

إذا كان '-' هو الحرف الأول أو الأخير في فئة الأحرف، فيتم التعامل معه كحرف عادي.

الحرف الخاص "^" في الموضع الأول من فئة الأحرف يدل على **فئة أحرف منفية** (negated character class)، والتي تطابق أي حرف باستثناء تلك الموجودة في الأقواس. يجب أن يتطابق كل من "[...]" و "[^...]" مع حرف، وإلا فشل المطابقة. ثم

/[^a]at/;  # لا يطابق 'aat' أو 'at'، ولكنه يطابق
           # كل 'bat', 'cat', '0at', '%at', إلخ. الأخرى
/[^0-9]/;  # يطابق حرفاً غير رقمي
/[a^]at/;  # يطابق 'aat' أو '^at'؛ هنا '^' عادي

لدى بيرل العديد من الاختصارات لفئات الأحرف الشائعة. (هذه التعريفات هي تلك التي يستخدمها بيرل في الوضع الآمن ASCII مع

; لتعديل. وإلا فقد تتطابق مع العديد من أحرف Unicode غير ASCII أيضاً. انظر "تسلسلات الشرطة المائلة العكسية" في perlrecharclass للحصول على التفاصيل.)

  • \d هو رقم ويمثل 
    [0-9]
  • \s هو حرف مسافة بيضاء ويمثل 
    [\ \t\r\n\f]
  • \w هو حرف كلمة (أبجدي رقمي أو _) ويمثل 
    [0-9a-zA-Z_]
  • \D هو عكس \d؛ إنه يمثل أي حرف باستثناء الرقم 
    [^0-9]
  • \S هو عكس \s؛ إنه يمثل أي حرف غير مسافة بيضاء 
    [^\s]
  • \W هو عكس \w؛ إنه يمثل أي حرف غير كلمة 
    [^\w]
  • النقطة '.' تطابق أي حرف باستثناء "\n"

يمكن استخدام الاختصارات "\d\s\w\D\S\W" داخل وخارج فئات الأحرف. إليك بعض الاستخدامات:

/\d\d:\d\d:\d\d/; # يطابق تنسيق الوقت hh:mm:ss
/[\d\s]/;         # يطابق أي رقم أو حرف مسافة بيضاء
/\w\W\w/;         # يطابق حرف كلمة، متبوعاً بـ
                  # حرف غير كلمة، متبوعاً بحرف كلمة
/..rt/;           # يطابق أي حرفين، متبوعاً بـ 'rt'
/end\./;          # يطابق 'end.'
/end[.]/;         # نفس الشيء، يطابق 'end.'

مرساة الكلمة "\b" تطابق حدًا بين حرف كلمة وحرف غير كلمة "\w\W" أو "\W\w":

$x = "Housecat catenates house and cat";
$x =~ /\bcat/;  # يطابق cat في 'catenates'
$x =~ /cat\b/;  # يطابق cat في 'housecat'
$x =~ /\bcat\b/;  # يطابق 'cat' في نهاية السلسلة

في المثال الأخير، تعتبر نهاية السلسلة حد كلمة.

لمعالجة اللغات الطبيعية (بحيث، على سبيل المثال، يتم تضمين علامات الحذف في الكلمات)، استخدم بدلاً من ذلك "\b{wb}"

"don't" =~ / .+? \b{wb} /x;  # يطابق السلسلة بأكملها

المطابقة هذا أو ذاك

يمكننا مطابقة سلاسل أحرف مختلفة باستخدام حرف التعريف الخاص **بالتناوب** '|'. لمطابقة "dog" أو "cat"، ننشئ التعبير المنتظم "dog|cat". كما هو الحال سابقاً، سيحاول Perl مطابقة التعبير المنتظم في أقرب نقطة ممكنة في السلسلة. عند كل موضع حرف، سيحاول Perl أولاً مطابقة البديل الأول، "dog". إذا لم تتطابق "dog"، فسيحاول Perl بعد ذلك البديل التالي، "cat". إذا لم تتطابق "cat" أيضاً، يفشل التطابق وينتقل Perl إلى الموضع التالي في السلسلة. إليك بعض الأمثلة:

"cats and dogs" =~ /cat|dog|bird/;  # يطابق "cat"
"cats and dogs" =~ /dog|cat|bird/;  # يطابق "cat"

على الرغم من أن "dog" هو البديل الأول في التعبير المنتظم الثاني، إلا أن "cat" يمكنه المطابقة في وقت مبكر من السلسلة.

"cats"          =~ /c|ca|cat|cats/; # يطابق "c"
"cats"          =~ /cats|cat|ca|c/; # يطابق "cats"

عند موضع حرف معين، فإن البديل الأول الذي يسمح للتعبير المنتظم بالنجاح هو الذي سيتم مطابقته. هنا، تتطابق جميع البدائل في موضع السلسلة الأول، لذا تحدث المطابقات الأولى.

تجميع الأشياء والمطابقة الهرمية

تسمح أحرف التعريف الخاصة **بالتجميع** "()" بمعاملة جزء من التعبير المنتظم كوحدة واحدة. يتم تجميع أجزاء التعبير المنتظم عن طريق وضعها بين قوسين. التعبير المنتظم house(cat|keeper) يعني مطابقة "house" متبوعاً إما "cat" أو "keeper". إليك بعض الأمثلة الأخرى

/(a|b)b/;    # يطابق 'ab' أو 'bb'
/(^a|b)c/;   # يطابق 'ac' في بداية السلسلة أو 'bc' في أي مكان
/house(cat|)/;  # يطابق إما 'housecat' أو 'house'
/house(cat(s|)|)/;  # يطابق إما 'housecats' أو 'housecat' أو
                    # 'house'. لاحظ أن المجموعات يمكن أن تكون متداخلة.
"20" =~ /(19|20|)\d\d/;  # يطابق البديل الفارغ '()\d\d'،
                         # لأن '20\d\d' لا يمكن أن تتطابق

استخراج المطابقات

تسمح أحرف التعريف الخاصة **بالتجميع** "()" أيضاً باستخراج أجزاء السلسلة التي تمت مطابقتها. لكل مجموعة، الجزء الذي تمت مطابقته بالداخل يذهب إلى المتغيرات الخاصة $1، $2، وهكذا. يمكن استخدامها كمتغيرات عادية:

# استخراج الساعات والدقائق والثواني
$time =~ /(\d\d):(\d\d):(\d\d)/;  # مطابقة تنسيق hh:mm:ss
$hours = $1;
$minutes = $2;
$seconds = $3;

في سياق القائمة، فإن المطابقة "/regex/" مع المجموعات ستعيد قائمة بالقيم المطابقة "($1,$2,...)". لذا يمكننا إعادة كتابتها كـ

($hours, $minutes, $second) = ($time =~ /(\d\d):(\d\d):(\d\d)/);

إذا كانت المجموعات في تعبير منتظم متداخلة، فإن $1 يحصل على المجموعة ذات القوس الافتتاحي الأيسر، $2 القوس الافتتاحي التالي، وهكذا. على سبيل المثال، إليك تعبير منتظم معقد والمتغيرات المطابقة المشار إليها أدناه:

/(ab(cd|ef)((gi)|j))/;
 1  2      34

ترتبط بالمتغيرات المطابقة $1، $2، ... **المرجعات** "\g1"، "\g2"، .... المرجعات هي متغيرات مطابقة يمكن استخدامها *داخل* التعبير المنتظم:

/(\w\w\w)\s\g1/; # العثور على تسلسلات مثل 'the the' في السلسلة

$1، $2، ... يجب استخدامها خارج التعبير المنتظم فقط، و "\g1"، "\g2"، ... داخل التعبير المنتظم فقط.

مطابقة التكرارات

تسمح أحرف التعريف الخاصة **بالمحدد الكمي** "?"، "*"، "+"، و "{}" بتحديد عدد تكرارات جزء من التعبير المنتظم الذي نعتبره تطابقًا. يتم وضع المحددات الكمية مباشرة بعد الحرف أو فئة الأحرف أو المجموعة التي نريد تحديدها. ولها المعاني التالية:

  • "a?" = تطابق 'a' مرة واحدة أو 0 مرة
  • "a*" = تطابق 'a' 0 مرة أو أكثر، أي أي عدد من المرات
  • "a+" = تطابق 'a' مرة واحدة أو أكثر، أي مرة واحدة على الأقل
  • "a{n,m}" = تطابق على الأقل "n" مرة، ولكن ليس أكثر من "m" مرة.
  • "a{n,}" = تطابق على الأقل "n" مرة أو أكثر
  • "a{,n}" = تطابق "n" مرة أو أقل (تمت الإضافة في الإصدار 5.34)
  • "a{n}" = تطابق بالضبط "n" مرة

إليك بعض الأمثلة:

/[a-z]+\s+\d*/;  # يطابق كلمة صغيرة، مسافة على الأقل، و
                 # أي عدد من الأرقام
/(\w+)\s+\g1/;    # يطابق الكلمات المكررة بطول عشوائي
$year =~ /^\d{2,4}$/;  # للتأكد من أن السنة لا تقل عن 2 ولا تزيد عن
                      # 4 أرقام
$year =~ /^\d{ 4 }$|^\d{2}$/; # مطابقة أفضل؛ استبعاد التواريخ المكونة من 3 أرقام

ستحاول هذه المحددات الكمية مطابقة أكبر قدر ممكن من السلسلة، مع الاستمرار في السماح للتعبير المنتظم بالمطابقة. لذا لدينا

$x = 'the cat in the hat';
$x =~ /^(.*)(at)(.*)$/; # يطابق،
                        # $1 = 'the cat in the h'
                        # $2 = 'at'
                        # $3 = ''   (0 تطابقات)

المحدد الكمي الأول ".*" يلتقط أكبر قدر ممكن من السلسلة مع السماح للتعبير المنتظم بالمطابقة. المحدد الكمي الثاني ".*" ليس لديه سلسلة متبقية، لذا فإنه يتطابق 0 مرة.

مزيد من المطابقة

هناك بعض الأشياء الإضافية التي قد ترغب في معرفتها حول عوامل المطابقة. يسمح المعدل العام "/g" لعامل المطابقة بالمطابقة داخل سلسلة أكبر عدد ممكن من المرات. في سياق القياسي، ستنتقل المطابقات المتتالية مع سلسلة "/g" من تطابق إلى آخر، مع الاحتفاظ بسجل الموضع في السلسلة أثناء تقدمها. يمكنك الحصول على الموضع أو تعيينه باستخدام الدالة pos(). على سبيل المثال،

$x = "cat dog house"; # 3 كلمات
while ($x =~ /(\w+)/g) {
    print "Word is $1, ends at position ", pos $x, "\n";
}

يطبع

Word is cat, ends at position 3
Word is dog, ends at position 7
Word is house, ends at position 13

يفشل التطابق أو تغيير السلسلة المستهدفة يعيد تعيين الموضع. إذا كنت لا تريد إعادة تعيين الموضع بعد فشل المطابقة، أضف "/c"، كما في "/regex/gc".

في سياق القائمة، يعيد "/g" قائمة بالمجموعات المطابقة، أو إذا لم تكن هناك مجموعات، قائمة بالمطابقات للتعبير المنتظم بأكمله. لذا

perlrequick - Quick reference for Perl regular expressions

NAME

perlrequick - Quick reference for Perl regular expressions

DESCRIPTION

This is a quick reference guide to Perl's regular expression operators and syntax. It is not meant to be a substitute for the full perlre manual page or the more tutorial-oriented perlretut.

The Guide

Perl's regular expression matching operator is "m//", which is usually abbreviated as "//". It's used in context like this:

$string =~ m/regex/flags

The "s///" operator is used for substitution. It has the same syntax as "m//", but with a substitution string after the second delimiter:

$string =~ s/regex/replacement/flags

If the match or substitution is performed on the default variable $_, the "=~" operator is optional:

/regex/flags                  # same as $_ =~ /regex/flags
s/regex/replacement/flags     # same as $_ =~ s/regex/replacement/flags

The "tr///" operator (or its synonym "y///") is used for character translation or deletion.

$string =~ tr/set1/set2/flags
$string =~ y/set1/set2/flags

These operators return the number of matches found (for "m//") or substitutions made (for "s///" and "tr///"). If used in a scalar context, they return the number of matches/substitutions or false if no match was found. In list context, they return a list of all the matched substrings (for "m//") or a list of the number of matches and the number of substitutions made (for "s///" and "tr///").

The "m//" operator and the regex part of the "s///" operator automatically set the special variables $1, $2, etc., to the substrings captured by parentheses in the regex.

$_ = "the cat in the hat";
if (/c(a)t/) {
    print "Found '$1' in the word 'cat'\n"; # prints Found 'a' in the word 'cat'
}

Here are some common regular expression flags:

i
Case-insensitive matching.
m
Multiline mode. "^" and "$" match the start and end of the string respectively. With "m", they match the start and end of lines.
s
Single-line mode. The "." character matches any character, including newline characters.
x
Extended mode. Whitespace is ignored, and comments can be added using "#".

The "s///" operator has a few extra flags:

g
Global replacement. Replace all occurrences of the regex in the string, not just the first.
r
Non-destructive. Return the result of the substitution instead of modifying the original string.
e
Evaluate the replacement string as Perl code.

Here are some examples:

$x = "Time to feed the cat!";
$x =~ s/cat/hacker/;   # $x contains "Time to feed the hacker!"
$y = "'quoted words'";
$y =~ s/^'(.*)'$/$1/;  # strip single quotes,
                       # $y contains "quoted words"

With the "s///" operator, the matched variables $1, $2, etc. are immediately available for use in the replacement expression. With the global modifier, "s///g" will search and replace all occurrences of the regex in the string:

$x = "I batted 4 for 4";
$x =~ s/4/four/;   # $x contains "I batted four for 4"
$x = "I batted 4 for 4";
$x =~ s/4/four/g;  # $x contains "I batted four for four"

The non-destructive modifier "s///r" causes the result of the substitution to be returned instead of modifying $_ (or whatever variable the substitute was bound to with "=~"):

$x = "I like dogs.";
$y = $x =~ s/dogs/cats/r;
print "$x $y\n"; # prints "I like dogs. I like cats."
$x = "Cats are great.";
print $x =~ s/Cats/Dogs/r =~ s/Dogs/Frogs/r =~
    s/Frogs/Hedgehogs/r, "\n";
# prints "Hedgehogs are great."
@foo = map { s/[a-z]/X/r } qw(a b c 1 2 3);
# @foo is now qw(X X X 1 2 3)

The evaluation modifier "s///e" wraps an "eval{...}" around the replacement string and the evaluated result is substituted for the matched substring. Some examples:

# reverse all the words in a string
$x = "the cat in the hat";
$x =~ s/(\w+)/reverse $1/ge;   # $x contains "eht tac ni eht tah"
# convert percentage to decimal
$x = "A 39% hit rate";
$x =~ s!(\d+)%!$1/100!e;       # $x contains "A 0.39 hit rate"

The last example shows that "s///" can use other delimiters, such as "s!!!" and "s{}{}", and even "s{}//". If single quotes are used "s'''", then the regex and replacement are treated as single-quoted strings.

The split operator

"split /regex/, string" splits "string" into a list of substrings and returns that list. The regex determines the character sequence that "string" is split with respect to. For example, to split a string into words, use

$x = "Calvin and Hobbes";
@word = split /\s+/, $x;  # $word[0] = 'Calvin'
                          # $word[1] = 'and'
                          # $word[2] = 'Hobbes'

To extract a comma-delimited list of numbers, use

$x = "1.618,2.718,   3.142";
@const = split /,\s*/, $x;  # $const[0] = '1.618'
                            # $const[1] = '2.718'
                            # $const[2] = '3.142'

If the empty regex "//" is used, the string is split into individual characters. If the regex has groupings, then the list produced contains the matched substrings from the groupings as well:

$x = "/usr/bin";
@parts = split m!(/)!, $x;  # $parts[0] = ''
                            # $parts[1] = '/'
                            # $parts[2] = 'usr'
                            # $parts[3] = '/'
                            # $parts[4] = 'bin'

Since the first character of $x matched the regex, "split" prepended an empty initial element to the list.

"use re 'strict'"

New in v5.22, this applies stricter rules than otherwise when compiling regular expression patterns. It can find things that, while legal, may not be what you intended.

See 'strict' in re.
