perlsh(1p)

الحزمة: perl-term-readline-gnu

التراخيص: PerlArtistic, GPL

PERLSH(1) وثائق Perl المساهم بها من قبل المستخدم PERLSH(1)

الاسم

perlsh - مُقَيِّم Perl سطر واحد مع وظيفة تحرير السطر ووظيفة
إكمال أسماء المتغيرات

الملخص

perlsh

الوصف

هذا البرنامج يقرأ الإدخال سطراً بسطر، ويقوم بتقييمه بواسطة مترجم Perl، ثم يطبع النتيجة. إذا كانت النتيجة قائمة، فسيتم طباعة كل قيمة في القائمة سطراً بسطر. يمكن استخدام هذا البرنامج كآلة حاسبة قوية جداً تتمتع بكامل وظائف Perl.

هذا مثال لبرنامج وحدة Term::ReadLine::Gnu. عندما تقوم بإدخال سطر، تكون وظيفة تحرير السطر لمكتبة GNU Readline متاحة. وظيفة إكمال أسماء رموز Perl متاحة أيضًا.

قبل البدء، يقرأ هذا البرنامج الملف ~/.perlshrc ويقوم بتقييم محتويات الملف.

عند إنهاء هذا البرنامج، يتم حفظ محتويات مخزن السجل (history buffer) في ملف ~/.perlsh_history، ويتم قراءته عند الاستدعاء التالي.

المتغيرات

يمكنك تخصيص سلوك "perlsh" عن طريق تعيين المتغيرات التالية في ~/.perlshrc؛

$PerlSh::PS1
سلسلة المطالبة الرئيسية. يمكن استخدام الأحرف الخاصة التالية التي تم إلغاء الهروب منها. 
\h: اسم المضيف
\u: اسم المستخدم
\w: اسم الحزمة
\!: رقم السجل

القيمة الافتراضية هي `"\w[\!]$ "'.

$PerlSh::PS2
سلسلة المطالبة الثانوية. القيمة الافتراضية هي `"> "'.
$PerlSh::HISTFILE
اسم الملف الذي يتم حفظ سجل الأوامر فيه. القيمة الافتراضية هي "~/.perlsh_history".
$PerlSh::HISTSIZE
إذا لم تكن "undef"، فهذا هو الحد الأقصى لعدد الأوامر التي سيتم تذكرها في السجل. القيمة الافتراضية هي 256.
$PerlSh::STRICT
إذا كانت صحيحة، قم بتقييد البنيات غير الآمنة. انظر "use strict" في صفحة دليل perl. القيمة الافتراضية هي 0؛

الملفات

~/.perlshrc
يتم تقييم هذا الملف عند التهيئة. إذا تم تعريف روتين فرعي "afterinit" في هذا الملف، فسيتم تقييمه بعد التهيئة. إليك مثال. 
# -*- mode: perl -*-
# تحويل عشري إلى ست عشري
sub h { map { sprintf("0x%x", $_ ) } @_;}
sub tk {
    $t->tkRunning(1);
    use Tk;
    $mw = MainWindow->new();
}
# لتصحيح أخطاء Term::ReadLine::Gnu
sub afterinit {
    *t = \$PerlSh::term;
    *a = \$PerlSh::attribs;
}
~/.perlsh_history
~/.inputrc
ملف تهيئة لمكتبة GNU Readline. ارجع إلى دليلها للحصول على التفاصيل.
