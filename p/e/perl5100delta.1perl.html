تحسينات أساسية

الـ pragma "feature"

يُستخدم الـ "feature" pragma لتمكين بناء الجملة الجديد الذي قد يكسر التوافق الخلفي لـ Perl مع الإصدارات الأقدم من اللغة. إنه pragma موضعي، مثل "strict" أو "warnings".

تتوفر حاليًا الميزات الجديدة التالية: "switch" (يضيف عبارة switch)، "say" (يضيف وظيفة مدمجة "say")، و "state" (يضيف الكلمة الرئيسية "state" لتعريف متغيرات "ثابتة"). تم وصف هذه الميزات في أقسامها الخاصة في هذه الوثيقة.

يتم أيضًا تحميل الـ "feature" pragma ضمنيًا عند طلب الحد الأدنى من إصدار perl (مع البناء "use VERSION") أكبر من أو يساوي 5.9.5. انظر feature لمزيد من التفاصيل.

المفتاح الجديد لسطر الأوامر -E

-E يعادل -e، ولكنه يمكّن ضمنيًا جميع الميزات الاختيارية (مثل "use feature ":5.10"").

المشغل defined-or

تم تنفيذ مشغل جديد "//" (defined-or). التعبير التالي:

$a // $b

هو ببساطة مكافئ لـ

defined $a ? $a : $b

والعبارة

$c //= $d;

يمكن الآن استخدامها بدلاً من

$c = $d unless defined $c;

يحتوي المشغل "//" على نفس أسبقية وربط المشغل "||". تم اتخاذ عناية خاصة لضمان أن هذا المشغل يفعل ما تريده مع عدم كسر التعليمات البرمجية القديمة، ولكن قد يتم تحليل بعض الحالات الطرفية التي تتضمن التعبير العادي الفارغ بشكل مختلف الآن. انظر perlop لمزيد من التفاصيل.

المشغل Switch و Smart Match

يحتوي Perl 5 الآن على عبارة switch. وهي متاحة عندما يكون use feature 'switch' ساري المفعول. تقدم هذه الميزة ثلاث كلمات رئيسية جديدة: "given" و "when" و "default":

given ($foo) {
    when (/^abc/) { $abc = 1; }
    when (/^def/) { $def = 1; }
    when (/^xyz/) { $xyz = 1; }
    default { $nothing = 1; }
}

يتم تقديم وصف أكثر اكتمالاً لكيفية مطابقة Perl لمتغير switch مع شروط "when" في "Switch statements" في perlsyn.

يسمى هذا النوع من المطابقة smart match، ومن الممكن أيضًا استخدامه خارج عبارات switch، عبر المشغل الجديد "~~". انظر "Smart matching in detail" في perlsyn.

ساهم في هذه الميزة روبن هيوستن.

التعبيرات العادية

أنماط متكررة
من الممكن الآن كتابة أنماط متكررة دون استخدام البناء "(??{})". هذه الطريقة الجديدة أكثر كفاءة، وفي كثير من الحالات أسهل في القراءة.

يمكن الآن معاملة كل قوس التقاط كنمط مستقل يمكن دخوله باستخدام بناء الجملة "(?PARNO)" ("PARNO" اختصار لـ "رقم القوس"). على سبيل المثال، النمط التالي سيطابق الأقواس الزاوية المتداخلة المتوازنة:

/
 ^                      # بداية السطر
 (                      # بداية مخزن الالتقاط 1
    <                   #   مطابقة قوس زاوية مفتوح
    (?:                 #   مطابقة واحدة من:
        (?>             #     لا تتراجع عن داخل هذه المجموعة
            [^<>]+      #       حرف واحد أو أكثر ليس أقواس زاوية
        )               #     نهاية مجموعة عدم التراجع
    |                   #     ... أو ...
        (?1)            #     كرر النمط 1 وحاول مرة أخرى
    )*                  #   0 مرة أو أكثر.
    >                   #   مطابقة قوس زاوية مغلق
 )                      # نهاية مخزن الالتقاط واحد
 $                      # نهاية السطر
/x

يجب ملاحظة مستخدمي PCRE أن ميزة التعبيرات العادية المتكررة في Perl تسمح بالتراجع إلى نمط متكرر، بينما في PCRE يكون التكرار ذريًا أو "تملكيًا" بطبيعته. كما في المثال أعلاه، يمكنك إضافة (?>) للتحكم في هذا بشكل انتقائي. (إيف أورتون)

مخازن التقاط مسماة
من الممكن الآن تسمية أقواس الالتقاط في نمط والإشارة إلى المحتويات الملتقطة بالاسم. بناء الجملة للتسمية هو "(?<NAME>....)". من الممكن الرجوع إلى مخزن مسمى باستخدام بناء الجملة "\k<NAME>". في التعليمات البرمجية، يمكن استخدام الهاشات السحرية الجديدة "%+" و "%-" للوصول إلى محتويات مخازن الالتقاط.

وبالتالي، لاستبدال جميع الأحرف المزدوجة بنسخة واحدة، يمكن للمرء كتابة

s/(?<letter>.)\k<letter>/$+{letter}/g

فقط المخازن ذات المحتويات المحددة ستكون "مرئية" في الهاش "%+"، لذلك من الممكن القيام بشيء مثل

foreach my $name (keys %+) {
    print "content of buffer '$name' is $+{$name}\n";
}

الهاش "%-" أكثر اكتمالاً بعض الشيء، لأنه سيحتوي على مصفوفات تحتوي على قيم من جميع مخازن الالتقاط المسماة بشكل مشابه، إذا كان هناك العديد منها.

تم تنفيذ "%+" و "%-" كهاشات مرتبطة من خلال الوحدة الجديدة "Tie::Hash::NamedCapture".

سيجد المستخدمون الذين تعرضوا لمحرك التعبيرات العادية .NET أن تطبيق Perl يختلف في أن الترتيب الرقمي للمخازن متسلسل، وليس "غير مسمى أولاً، ثم مسمى". وبالتالي في النمط

/(A)(?<B>B)(C)(?<D>D)/

$1 سيكون 'A'، $2 سيكون 'B'، $3 سيكون 'C' و $4 سيكون 'D' وليس $1 هو 'A'، $2 هو 'C' و $3 هو 'B' و $4 هو 'D' الذي قد يتوقعه مبرمج .NET. يعتبر هذا ميزة. :-) (إيف أورتون)

محدِّدات تملكية
يدعم Perl الآن بناء الجملة "المحدد التملكي" لنمط "المطابقة الذرية". بشكل أساسي، يطابق المحدد التملكي أكبر قدر ممكن ولا يتراجع أبدًا. وبالتالي يمكن استخدامه للتحكم في التراجع. بناء الجملة مشابه للمطابقة غير الجشعة، باستثناء أنه بدلاً من استخدام '؟' كـ modifier، يتم استخدام '+'. وبالتالي "?+" و "*+" و "++" و "{min,max}+" هي الآن محددات قانونية. مرجعيات رجوع نسبية
صيغة جديدة "\g{N}" أو "\gN" حيث "N" هو عدد صحيح عشري يسمح بشكل أكثر أمانًا لتدوين مرجع الرجوع وكذلك السماح بالمرجعيات النسبية. هذا من شأنه أن يسهل إنشاء وتضمين الأنماط التي تحتوي على مراجع رجوع. انظر "مخازن الالتقاط" في perlre. (إيف أورتون)
"\K" هروب
تمت إضافة وظيفة وحدة Jeff Pinyan Regexp::Keep إلى النواة. في التعابير العادية، يمكنك الآن استخدام الهروب الخاص "\K" كوسيلة للقيام بشيء مثل نظرة خلفية إيجابية ذات طول عائم. وهي مفيدة أيضًا في الاستبدالات مثل: 
s/(foo)bar/$1/g

والتي يمكن الآن تحويلها إلى

s/foo\Kbar//g

وهو أكثر كفاءة بكثير. (إيف أورتون)

المسافات العمودية والأفقية، وفواصل الأسطر
تتعرف التعابير العادية الآن على "\v" و "\h" التي تطابق المسافات العمودية والأفقية على التوالي. "\V" و "\H" تطابق منطقيًا مكملاتها.

"\R" تطابق فاصل أسطر عام، أي المسافات العمودية، بالإضافة إلى التسلسل متعدد الأحرف "\x0D\x0A".

عمليات التقاط اختيارية قبل وبعد المطابقة مع العلامة /p
هناك علامة جديدة "/p" للتعابير العادية. استخدام هذا يجعل المحرك يحافظ على نسخة من جزء السلسلة المطابقة قبل السلسلة الفرعية المطابقة للمتغير الخاص الجديد "${^PREMATCH}"، والجزء بعد السلسلة الفرعية المطابقة للمتغير "${^POSTMATCH}"، والسلسلة الفرعية المطابقة نفسها للمتغير "${^MATCH}".

لا يزال Perl قادرًا على تخزين هذه السلاسل الفرعية في المتغيرات الخاصة "$`"، "$'"، $&، ولكن استخدام هذه المتغيرات في أي مكان في البرنامج يضيف عقوبة لجميع مطابقات التعابير العادية، بينما إذا استخدمت العلامة "/p" والمتغيرات الخاصة الجديدة بدلاً من ذلك، فإنك تدفع فقط للتعابير العادية التي تم استخدام العلامة فيها.

لمزيد من التفاصيل حول المتغيرات الجديدة، راجع perlvar؛ لاستخدام علامة التعبير العادي، راجع perlop و perlre.

say()

say() هي دالة مدمجة جديدة، متاحة فقط عندما يكون "use feature 'say'" ساري المفعول، وهي مشابهة لـ print()، ولكنها تضيف ضمنيًا سطرًا جديدًا إلى السلسلة المطبوعة. انظر "say" في perlfunc. (روبن هيوستن)

المتغير المحلي $_

يمكن الآن جعل المتغير الافتراضي $_ متغيرًا محليًا، عن طريق تعريفه مثل أي متغير محلي آخر، باستخدام

my $_;

ستستخدم العمليات التي تعتمد افتراضيًا على $_ الإصدار المحلي النطاقي لـ $_ عندما يكون موجودًا، بدلاً من $_ العام.

في كتلة "map" أو "grep"، إذا تم بالفعل استخدام $_ مع my، فإن $_ داخل الكتلة يكون محليًا أيضًا (ومحصورًا في الكتلة).

في نطاق تم فيه جعل $_ محليًا، لا يزال بإمكانك الوصول إلى الإصدار العام لـ $_ باستخدام $::_، أو ببساطة أكبر، عن طريق تجاوز التعريف المحلي باستخدام "our $_". (رافائيل غارسيا سواريز)

النموذج "_"

تمت إضافة حرف نموذج جديد. "_" يعادل "$" ولكنه افتراضيًا إلى $_ إذا لم يتم توفير الوسيط المقابل (كلاهما "$" و "_" يشيران إلى قيمة عددية). نظرًا للطبيعة الاختيارية للوسيط، لا يمكنك استخدامه إلا في نهاية نموذج، أو قبل فاصلة منقوطة.

هذا له عواقب طفيفة غير متوافقة: تم تعديل الدالة prototype() لإرجاع "_" لبعض الدوال المدمجة في الحالات المناسبة (على سبيل المثال، prototype('CORE::rmdir')). (رافائيل غارسيا سواريز)

كتل UNITCHECK

تم تقديم كتلة التعليمات البرمجية الخاصة الجديدة "UNITCHECK"، بالإضافة إلى "BEGIN"، "CHECK"، "INIT" و "END".

كتل "CHECK" و "INIT"، بينما هي مفيدة لبعض الأغراض المتخصصة، يتم تنفيذها دائمًا عند الانتقال بين تجميع وتنفيذ البرنامج الرئيسي، وبالتالي فهي عديمة الفائدة كلما تم تحميل التعليمات البرمجية في وقت التشغيل. من ناحية أخرى، يتم تنفيذ كتل "UNITCHECK" بعد تجميع الوحدة التي عرفتها مباشرة. انظر perlmod لمزيد من المعلومات. (أليكس جو)

المُقْضِي الجديد، "mro"

تمت إضافة مُقْضِي جديد، "mro" (لترتيب استدعاء الأساليب). يسمح بتبديل، على أساس كل فئة، الخوارزمية التي يستخدمها Perl للعثور على الأساليب الموروثة في حالة التسلسل الهرمي المتعدد الوراثة. لم يتغير ترتيب استدعاء الأساليب الافتراضي (DFS، للبحث العميق أولاً). يتوفر ترتيب استدعاء أساليب آخر: خوارزمية C3. انظر mro لمزيد من المعلومات. (براندون بلاك)

لاحظ أنه بسبب التغييرات في تنفيذ البحث الهرمي للفئة، فإن التعليمات البرمجية التي كانت تستخدم سابقًا *ISA ستتعطل على الأرجح. على أي حال، كان لـ undef'ing *ISA تأثير جانبي لإزالة السحر على مصفوفة @ISA وكان يجب عدم القيام به في المقام الأول. أيضًا، لم يعد التخزين المؤقت *::ISA::CACHE:: موجودًا؛ لإعادة تعيين ذاكرة التخزين المؤقت لـ @ISA، تحتاج الآن إلى استخدام واجهة برمجة تطبيقات "mro"، أو ببساطة تعيين القيمة لـ @ISA (على سبيل المثال، مع "@ISA = @ISA").

readdir() قد تُرجع "اسم ملف قصير" على Windows

قد تُرجع الدالة readdir() "اسم ملف قصير" عندما يحتوي اسم الملف الطويل على أحرف خارج صفحة الرموز ANSI. وبالمثل، قد تُرجع Cwd::cwd() اسم دليل قصير، وقد تُرجع glob() أسماء قصيرة أيضًا. على نظام الملفات NTFS، يمكن دائمًا تمثيل هذه الأسماء القصيرة في صفحة الرموز ANSI. لن يكون هذا صحيحًا لجميع برامج تشغيل أنظمة الملفات الأخرى؛ على سبيل المثال، يقوم نظام الملفات FAT بتخزين أسماء الملفات القصيرة في صفحة الرموز OEM، لذلك تظل بعض الملفات الموجودة على وحدات FAT غير قابلة للوصول عبر واجهات برمجة تطبيقات ANSI.

بالمثل، تتم معالجة $^X و @INC و $ENV{PATH} مسبقًا عند بدء التشغيل للتأكد من أن جميع المسارات صالحة في صفحة الرموز ANSI (إذا أمكن).

تعمل الدالة Win32::GetLongPathName() الآن على إرجاع اسم الملف الطويل الصحيح المشفر بـ UTF-8 بدلاً من استخدام أحرف الاستبدال لفرض الاسم في صفحة الرموز ANSI. يمكن استخدام الدالة الجديدة Win32::GetANSIPathName() لتحويل مسار طويل إلى مسار قصير فقط إذا لم يكن المسار الطويل قابلاً للتمثيل في صفحة الرموز ANSI.

تم تحسين العديد من الدوال الأخرى في وحدة "Win32" لقبول الوسائط المشفرة بـ UTF-8. يرجى رؤية Win32 للتفاصيل.

readpipe() يمكن الآن تجاوزها

الدالة المدمجة readpipe() يمكن الآن تجاوزها. يسمح تجاوزها أيضًا بتجاوز نظيرتها العاملة، "qx//" (المعروفة أيضًا بـ ``). علاوة على ذلك، فهي افتراضيًا لـ $_ إذا لم يتم توفير وسيط. (رافائيل غارسيا سواريز)

الوسيط الافتراضي لـ readline()

readline() تفترض الآن *ARGV إذا لم يتم توفير وسيط. (رافائيل غارسيا سواريز)

متغيرات state()

تم تقديم فئة جديدة من المتغيرات. متغيرات الحالة مشابهة لمتغيرات "my"، ولكن يتم تعريفها باستخدام الكلمة المفتاحية "state" بدلاً من "my". وهي مرئية فقط في نطاقها المحلي، ولكن قيمتها دائمة: على عكس متغيرات "my"، فهي لا تُعرّف عند دخول النطاق، بل تحتفظ بقيمتها السابقة. (رافائيل غارسيا سواريز، نيكولاس كلارك)

لاستخدام متغيرات الحالة، يحتاج المرء إلى تمكينها باستخدام

use feature 'state';

أو باستخدام مفتاح سطر الأوامر "-E" في النصوص أحادية السطر. انظر "Persistent Private Variables" في perlsub.

عوامل اختبار الملفات المكدسة

كشكل جديد من السكر النحوي، أصبح من الممكن الآن تكديس عوامل اختبار الملفات. يمكنك الآن كتابة "-f -w -x $file" في صف واحد لتعني "-x $file && -w _ && -f _". انظر "-X" في perlfunc.

UNIVERSAL::DOES()

لدى الفئة "UNIVERSAL" أسلوب جديد، DOES(). تمت إضافته لحل المشكلات الدلالية مع أسلوب isa(). isa() يتحقق من الوراثة، بينما تم تصميم DOES() ليتم تجاوزه عندما...

يستخدم المؤلفون أنواعًا أخرى من العلاقات بين الفئات (بالإضافة إلى الوراثة). (ملون)

انظر "$obj->DOES( ROLE )" في UNIVERSAL.

التنسيقات

تم تحسين التنسيقات بعدة طرق. يمكن استخدام حقل جديد، "^*"، للنص ذي العرض المتغير، سطر واحد في كل مرة. يتم الآن التعامل مع الأحرف الفارغة بشكل صحيح في سطور الصورة. سيؤدي استخدام "@#" و "~~" معًا إلى خطأ في وقت التصريف، حيث أن حقول التنسيق هذه غير متوافقة. تم تحسين perlform، وتم إصلاح الأخطاء المتنوعة.

معدلات ترتيب البايت لـ pack() و unpack()

هناك معدلان جديدان لترتيب البايت، ">" (big-endian) و "<" (little-endian)، يمكن إلحاقهما بمعظم أحرف أو مجموعات القالب الخاصة بـ pack() و unpack() لفرض ترتيب بايت معين لهذا النوع أو المجموعة. انظر "pack" في perlfunc و perlpacktut للحصول على التفاصيل.

"no VERSION"

يمكنك الآن استخدام "no" متبوعة برقم إصدار لتحديد أنك تريد استخدام إصدار أقدم من perl من الإصدار المحدد.

التعبئة وسلاسل UTF-8

تم تغيير دلالات pack() و unpack() فيما يتعلق بالبيانات المشفرة بـ UTF-8. تتم المعالجة الآن افتراضيًا حرفًا بحرف بدلاً من بايت ببايت على الترميز الأساسي. على وجه الخصوص، التعليمات البرمجية التي استخدمت أشياء مثل "pack("a*", $string)" لرؤية تشفير السلسلة ستعيد الآن ببساطة $string الأصلية. يمكن أيضًا ترقية السلاسل المعبأة أثناء المعالجة عندما تقوم بتخزين أحرف محدثة. يمكنك الحصول على السلوك القديم باستخدام "use bytes".

للتوافق مع pack()، يشير "C0" في قوالب unpack() إلى أن البيانات ستتم معالجتها في وضع الأحرف، أي حرفًا بحرف؛ على العكس من ذلك، يشير "U0" في unpack() إلى وضع UTF-8، حيث تتم معالجة السلسلة المعبأة في شكلها المشفر بـ UTF-8 من Unicode على أساس بايت ببايت. هذا معكوس فيما يتعلق بـ perl 5.8.X، لكنه الآن متوافق بين pack() و unpack().

علاوة على ذلك، يمكن أيضًا استخدام "C0" و "U0" في قوالب pack() لتحديد وضعي الأحرف والبايت على التوالي.

"C0" و "U0" في منتصف تنسيق pack أو unpack يتحول الآن إلى وضع الترميز المحدد، مع احترام تجميع الأقواس. في السابق، تم تجاهل الأقواس.

أيضًا، هناك تنسيق حرف جديد لـ pack()، "W"، والذي يهدف إلى استبدال "C" القديم. يتم الاحتفاظ بـ "C" للأحرف غير الموقعة المشفرة كبايت في التمثيل الداخلي للسلسلة. يمثل "W" قيم الأحرف غير الموقعة (المنطقية)، والتي يمكن أن تكون أكبر من 255. لذلك فهو أكثر قوة عند التعامل مع البيانات المشفرة بـ UTF-8 المحتملة (حيث سيتجاوز "C" القيم خارج النطاق 0..255، ولن يحترم تشفير السلسلة).

من الناحية العملية، هذا يعني أن تنسيقات pack أصبحت الآن محايدة للترميز، باستثناء "C".

من أجل الاتساق، تقوم "A" في unpack() الآن بتقليم جميع مسافات يونيكود البيضاء من نهاية السلسلة. قبل perl 5.9.2، كانت تقوم فقط بإزالة أحرف المسافة ASCII الكلاسيكية.

Pragmas

"base"
The "base" pragma now warns if a class tries to inherit from itself. (Curtis "Ovid" Poe)
"strict" and "warnings"
"strict" and "warnings" will now complain loudly if they are loaded via incorrect casing (as in "use Strict;"). (Johan Vromans)
"version"
The "version" module provides support for version objects.
"warnings"
The "warnings" pragma doesn't load "Carp" anymore. That means that code that used "Carp" routines without having loaded it at compile time might need to be adjusted; typically, the following (faulty) code won't work anymore, and will require parentheses to be added after the function name: 
use warnings;
require Carp;
Carp::confess 'argh';
"less"
"less" now does something useful (or at least it tries to). In fact, it has been turned into a lexical pragma. So, in your modules, you can now test whether your users have requested to use less CPU, or less memory, less magic, or maybe even less fat. See less for more. (Joshua ben Jore)

New modules

  • "encoding::warnings", by Audrey Tang, is a module to emit warnings whenever an ASCII character string containing high-bit bytes is implicitly converted into UTF-8. It's a lexical pragma since Perl 5.9.4; on older perls, its effect is global.
  • "Module::CoreList", by Richard Clamp, is a small handy module that tells you what versions of core modules ship with any versions of Perl 5. It comes with a command-line frontend, "corelist".
  • "Math::BigInt::FastCalc" is an XS-enabled, and thus faster, version of "Math::BigInt::Calc".
  • "Compress::Zlib" is an interface to the zlib compression library. It comes with a bundled version of zlib, so having a working zlib is not a prerequisite to install it. It's used by "Archive::Tar" (see below).
  • "IO::Zlib" is an "IO::"-style interface to "Compress::Zlib".
  • "Archive::Tar" is a module to manipulate "tar" archives.
  • "Digest::SHA" is a module used to calculate many types of SHA digests, has been included for SHA support in the CPAN module.
  • "ExtUtils::CBuilder" and "ExtUtils::ParseXS" have been added.
  • "Hash::Util::FieldHash", by Anno Siegel, has been added. This module provides support for field hashes: hashes that maintain an association of a reference with a value, in a thread-safe garbage-collected way. Such hashes are useful to implement inside-out objects.
  • "Module::Build", by Ken Williams, has been added. It's an alternative to "ExtUtils::MakeMaker" to build and install perl modules.
  • "Module::Load", by Jos Boumans, has been added. It provides a single interface to load Perl modules and .pl files.
  • "Module::Loaded", by Jos Boumans, has been added. It's used to mark modules as loaded or unloaded.
  • "Package::Constants", by Jos Boumans, has been added. It's a simple helper to list all constants declared in a given package.
  • "Win32API::File", by Tye McQueen, has been added (for Windows builds). This module provides low-level access to Win32 system API calls for files/dirs.
  • "Locale::Maketext::Simple", needed by CPANPLUS, is a simple wrapper around "Locale::Maketext::Lexicon". Note that "Locale::Maketext::Lexicon" isn't included in the perl core; the behaviour of "Locale::Maketext::Simple" gracefully degrades when the later isn't present.
  • "Params::Check" implements a generic input parsing/checking mechanism. It is used by CPANPLUS.
  • "Term::UI" simplifies the task to ask questions at a terminal prompt.
  • "Object::Accessor" provides an interface to create per-object accessors.
  • "Module::Pluggable" is a simple framework to create modules that accept pluggable sub-modules.
  • "Module::Load::Conditional" provides simple ways to query and possibly load installed modules.
  • "Time::Piece" provides an object oriented interface to time functions, overriding the built-ins localtime() and gmtime().
  • "IPC::Cmd" helps to find and run external commands, possibly interactively.
  • "File::Fetch" provide a simple generic file fetching mechanism.
  • "Log::Message" and "Log::Message::Simple" are used by the log facility of "CPANPLUS".
  • "Archive::Extract" is a generic archive extraction mechanism for .tar (plain, gzipped or bzipped) or .zip files.
  • "CPANPLUS" provides an API and a command-line tool to access the CPAN mirrors.
  • "Pod::Escapes" provides utilities that are useful in decoding Pod E<...> sequences.
  • "Pod::Simple" is now the backend for several of the Pod-related modules included with Perl.

Selected Changes to Core Modules

"Attribute::Handlers"
"Attribute::Handlers" can now report the caller's file and line number. (David Feldman)

All interpreted attributes are now passed as array references. (Damian Conway)

"B::Lint"
"B::Lint" is now based on "Module::Pluggable", and so can be extended with plugins. (Joshua ben Jore)
"B"
It's now possible to access the lexical pragma hints ("%^H") by using the method B::COP::hints_hash(). It returns a "B::RHE" object, which in turn can be used to get a hash reference via the method B::RHE::HASH(). (Joshua ben Jore)
"Thread"
As the old 5005thread threading model has been removed, in favor of the ithreads scheme, the "Thread" module is now a compatibility wrapper, to be used in old code only. It has been removed from the default list of dynamic extensions.

Utility Changes

perl -d
The Perl debugger can now save all debugger commands for sourcing later; notably, it can now emulate stepping backwards, by restarting and rerunning all bar the last command from a saved command history.

It can also display the parent inheritance tree of a given class, with the "i" command.

ptar
"ptar" is a pure perl implementation of "tar" that comes with "Archive::Tar".
ptardiff
"ptardiff" is a small utility used to generate a diff between the contents of a tar archive and a directory tree. Like "ptar", it comes with "Archive::Tar".
shasum
"shasum" is a command-line utility, used to print or to check SHA digests. It comes with the new "Digest::SHA" module.
corelist
The "corelist" utility is now installed with perl (see "New modules" above).
h2ph and h2xs
"h2ph" and "h2xs" have been made more robust with regard to "modern" C code.

"h2xs" implements a new option "--use-xsloader" to force use of "XSLoader" even in backwards compatible modules.

The handling of authors' names that had apostrophes has been fixed.

Any enums with negative values are now skipped.

perlivp
"perlivp" no longer checks for *.ph files by default. Use the new "-a" option to run all tests.
find2perl
"find2perl" now assumes "-print" as a default action. Previously, it needed to be specified explicitly.

Several bugs have been fixed in "find2perl", regarding "-exec" and "-eval". Also the options "-path", "-ipath" and "-iname" have been added.
