perfquery(8) تشخيص InfiniBand perfquery(8)

الاسم

perfquery - استعلام عدادات منفذ InfiniBand على منفذ واحد

الملخص

perfquery [خيارات] [<lid|guid> [[منافذ] [قناع_إعادة_تعيين]]]

الوصف

يستخدم perfquery GMPs لإدارة الأداء (PerfMgt) للحصول على عدادات المنفذ (عدادات الأداء الأساسية والأخطاء) وعدادات المنفذ الموسعة وعدادات بيانات إرسال المنفذ (PortXmitDataSL) وبيانات استقبال المنفذ (PortRcvDataSL) وتفاصيل أخطاء استقبال المنفذ (PortRcvErrorDetails) وتفاصيل تجاهل الإرسال (PortXmitDiscardDetails) وعدادات السرعات الموسعة للمنفذ (PortExtendedSpeedsCounters) أو التحكم في عينات المنفذ (PortSamplesControl) من PMA في العقدة/المنفذ المحدد. يعرض اختياريًا العدادات المجمعة لجميع منافذ العقدة. أخيرًا، يمكنه إعادة تعيينها بعد القراءة، أو مجرد إعادة تعيين العدادات.

ملاحظة: في عدادات المنفذ (PortCounters)، وعدادات المنفذ الموسعة (PortCountersExtended)، وبيانات إرسال المنفذ (PortXmitDataSL)، وبيانات استقبال المنفذ (PortRcvDataSL)، تمثل المكونات التي تمثل البيانات (مثل PortXmitData و PortRcvData) الأوكتاوات مقسومة على 4 بدلاً من مجرد الأوكتاوات.

ملاحظة: إدخال منفذ 255 يشير إلى إجراء عملية على جميع المنافذ.

ملاحظة: بالنسبة لعدادات المنفذ (PortCounters)، والعدادات الموسعة (ExtendedCounters)، وإعادة التعيين، يمكن تحديد منافذ متعددة إما بقائمة مفصولة بفواصل أو بنطاق منافذ. انظر الأمثلة أدناه.

الخيارات

-x, --extended
عرض عدادات المنفذ الموسعة بدلاً من عدادات المنفذ (الأساسية). لاحظ أن سمة عدادات المنفذ الموسعة اختيارية.
-X, --xmtsl
عرض عداد بيانات الإرسال SL. هذا عداد اختياري لجودة الخدمة (QoS).
-S, --rcvsl
عرض عداد بيانات الاستقبال SL. هذا عداد اختياري لجودة الخدمة (QoS).
-D, --xmtdisc
عرض تفاصيل تجاهل الإرسال. هذا عداد اختياري.
-E, --rcverr
عرض تفاصيل أخطاء الاستقبال. هذا عداد اختياري.
-D, --xmtdisc
عرض تفاصيل تجاهل الإرسال. هذا عداد اختياري.
-T, --extended_speeds
عرض عدادات سرعة المنفذ الموسعة. هذا عداد اختياري.
--oprcvcounters
عرض عدادات الاستقبال لكل رمز عملية (Op code). هذا عداد اختياري.
--flowctlcounters
عرض عدادات التحكم في التدفق. هذا عداد اختياري.
--vloppackets
عرض الحزم المستلمة لكل رمز عملية (Op code) ولكل VL. هذا عداد اختياري.
--vlopdata
عرض البيانات المستلمة لكل رمز عملية (Op code) ولكل VL. هذا عداد اختياري.
--vlxmitflowctlerrors
عرض أخطاء تحديث التحكم في التدفق لكل VL. هذا عداد اختياري.
--vlxmitcounters
عرض عدادات الانتظار للإرسال لكل VL. هذا عداد اختياري.
--swportvlcong
عرض ازدحام منفذ VL البرمجي. هذا عداد اختياري.
--rcvcc
عرض عدادات التحكم في ازدحام الاستقبال. هذا عداد اختياري.
--slrcvfecn
عرض عدادات SL Rcv FECN. هذا عداد اختياري.
--slrcvbecn
عرض عدادات SL Rcv BECN. هذا عداد اختياري.
--xmitcc
عرض عدادات التحكم في ازدحام الإرسال. هذا عداد اختياري.
--vlxmittimecc
عرض عدادات التحكم في ازدحام وقت إرسال VL. هذا عداد اختياري.
-c, --smplctl
عرض التحكم في عينات المنفذ.
-a, --all_ports
عرض العدادات المجمعة لجميع منافذ LID الوجهة، أو إعادة تعيين جميع العدادات لجميع المنافذ، أو إذا تم تحديد منافذ متعددة، قم بتجميع عدادات المنافذ المحددة. إذا لم تدعم LID الوجهة علامة AllPortSelect، فسيتم تكرار جميع المنافذ لمحاكاة سلوك AllPortSelect.
-l, --loop_ports
إذا تم تحديد جميع المنافذ بواسطة المستخدم (إما من خلال الخيار -a أو المنفذ 255) أو تم تحديد منافذ متعددة، فتكرار كل منفذ بدلاً من إجراء عملية تجميع.
-r, --reset_after_read
إعادة تعيين العدادات بعد القراءة.
-R, --Reset_only
إعادة تعيين العدادات فقط.

علامات العنوان

-G, --Guid العنوان المحدد هو GUID المنفذ

-L, --Lid العنوان المحدد هو LID

-s, --sm_port <smlid> استخدم 'smlid' كـ LID الهدف لاستعلامات SA.

علامات اختيار المنفذ

-C, --Ca <ca_name> استخدم اسم CA المحدد.

-P, --Port <ca_port> استخدم منفذ CA المحدد.

اختيار المنفذ المحلي

دعم منافذ متعددة / CA متعددة: عندما لا يتم تحديد جهاز IB أو منفذ (انظر "معلمات umad المحلية" أدناه)، تحدد مكتبة libibumad المنفذ المراد استخدامه بالمعايير التالية:

1.
المنفذ الأول النشط.
2.
إذا لم يتم العثور عليه، المنفذ الأول الذي تم تشغيله (وصلة فعلية مرفوعة).

إذا تم تحديد اسم منفذ و/أو CA، تحاول مكتبة libibumad تلبية طلب المستخدم، وستفشل إذا لم يكن ذلك ممكنًا.

على سبيل المثال:

ibaddr                 # استخدم المنفذ الأول (المعيار #1 أعلاه)
ibaddr -C mthca1       # اختر أفضل منفذ من "mthca1" فقط.
ibaddr -P 2            # استخدم المنفذ الثاني (النشط/الفعال) من أول جهاز IB متاح.
ibaddr -C mthca0 -P 2  # استخدم المنفذ المحدد فقط.

علامات التصحيح

-d
رفع مستوى تصحيح IB. يمكن استخدامه عدة مرات (-ddd أو -d -d -d).
-e
عرض أخطاء الإرسال والاستقبال (مهلات وأخرى).

-h, --help عرض رسالة الاستخدام.

-v, --verbose
زيادة مستوى تفصيل التطبيق. يمكن استخدامه عدة مرات (-vv أو -v -v -v).

-V, --version عرض معلومات الإصدار.

علامات التكوين

-t, --timeout <timeout_ms> تجاوز المهلة الافتراضية لـ MADS المطلوب.

-y, --m_key <key>
استخدم M_key المحدد للطلبات. إذا تم تحديد قيمة غير رقمية (مثل 'x')، فسيتم مطالبتك بقيمة.

--config, -z <config_file> تحديد ملف تكوين بديل.

perfquery(8) — Arch Linux

NAME

perfquery — query InfiniBand port performance counters

SYNOPSIS

perfquery [OPTION...] [LID PORT]

DESCRIPTION

The perfquery utility queries InfiniBand port performance counters. It can be used to retrieve counters from local ports or from remote ports specified by LID (Local Identifier) and port number.

OPTIONS

-a, --all
Query all ports on the specified LID.
-l, --local
Query local ports.
-x, --extended
Query extended performance counters.
-r, --reset
Reset the performance counters after querying.
-R, --reset-only
Reset the performance counters without querying.
-h, --help
Display help text and exit.
-v, --version
Display version information and exit.

Port ranges can be specified using a hyphen (e.g., 1-10) or comma-separated lists (e.g., 1,4,8).

If LID and PORT are not specified, and -l is not used, then performance counters for all local ports are displayed.

FILES

A global configuration file ibdiag.conf can be provided to set some of the common options for all tools. See supplied config file for details.

EXAMPLES

perfquery                # read local port performance counters
perfquery 32 1           # read performance counters from lid 32, port 1
perfquery -x 32 1        # read extended performance counters from lid 32, port 1
perfquery -a 32          # read perf counters from lid 32, all ports
perfquery -r 32 1        # read performance counters and reset
perfquery -x -r 32 1     # read extended performance counters and reset
perfquery -R 0x20 1      # reset performance counters of port 1 only
perfquery -x -R 0x20 1   # reset extended performance counters of port 1 only
perfquery -R -a 32       # reset performance counters of all ports
perfquery -R 32 2 0x0fff # reset only error counters of port 2
perfquery -R 32 2 0xf000 # reset only non-error counters of port 2
perfquery -a 32 1-10     # read performance counters from lid 32, port 1-10, aggregate output
perfquery -l 32 1-10     # read performance counters from lid 32, port 1-10, output each port
perfquery -a 32 1,4,8    # read performance counters from lid 32, port 1, 4, and 8, aggregate output
perfquery -l 32 1,4,8    # read performance counters from lid 32, port 1, 4, and 8, output each port
