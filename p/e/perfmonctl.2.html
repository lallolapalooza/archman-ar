perfmonctl(2) دليل استدعاءات النظام perfmonctl(2)

الاسم

perfmonctl - واجهة لوحدة مراقبة الأداء IA-64

الملخص

#include <syscall.h>
#include <perfmon.h>
long perfmonctl(int narg;
                int fd, int cmd, void arg[narg], int narg);

ملاحظة: لا توجد دالة مساعدة glibc لاستدعاء النظام هذا؛ انظر HISTORY.

الوصف

يقدم استدعاء النظام perfmonctl() الخاص بـ IA-64 واجهة لوحدة مراقبة الأداء (PMU). تتكون وحدة مراقبة الأداء من سجلات PMD (بيانات مراقبة الأداء) وسجلات PMC (التحكم في مراقبة الأداء)، والتي تجمع إحصائيات الأجهزة.

يطبق perfmonctl() العملية cmd على وسائط الإدخال المحددة بواسطة arg. يتم تحديد عدد الوسائط بواسطة narg. تحدد الوسيطة fd سياق perfmon للعمل عليه.

القيم المدعومة لـ cmd هي:

PFM_CREATE_CONTEXT
perfmonctl(int fd, PFM_CREATE_CONTEXT, pfarg_context_t *ctxt, 1);
إعداد سياق.
يتم تجاهل الوسيطة fd. يتم إنشاء سياق perfmon جديد كما هو محدد في ctxt ويتم إرجاع واصف الملف الخاص به في ctxt->ctx_fd.
يمكن استخدام واصف الملف في استدعاءات لاحقة لـ perfmonctl() ويمكن استخدامه لقراءة إشعارات الأحداث (النوع pfm_msg_t) باستخدام read(2). يمكن استقصاء واصف الملف باستخدام select(2)، poll(2)، و epoll(7).
يمكن تدمير السياق عن طريق استدعاء close(2) على واصف الملف.
PFM_WRITE_PMCS
perfmonctl(int fd, PFM_WRITE_PMCS, pfarg_reg_t *pmcs, n);
تعيين سجلات PMC.
PFM_WRITE_PMDS
perfmonctl(int fd, PFM_WRITE_PMDS, pfarg_reg_t *pmds, n);
تعيين سجلات PMD.
PFM_READ_PMDS
perfmonctl(int fd, PFM_READ_PMDS, pfarg_reg_t *pmds, n);
قراءة سجلات PMD.
PFM_START
perfmonctl(int fd, PFM_START, NULL, 0);
بدء المراقبة.
PFM_STOP
perfmonctl(int fd, PFM_STOP, NULL, 0);
إيقاف المراقبة.
PFM_LOAD_CONTEXT
perfmonctl(int fd, PFM_LOAD_CONTEXT, pfarg_load_t *largs, 1);
إرفاق السياق بخيط.
PFM_UNLOAD_CONTEXT
perfmonctl(int fd, PFM_UNLOAD_CONTEXT, NULL, 0);
فصل السياق عن خيط.
PFM_RESTART
perfmonctl(int fd, PFM_RESTART, NULL, 0);
إعادة تشغيل المراقبة بعد تلقي إشعار تجاوز.
PFM_GET_FEATURES
perfmonctl(int fd, PFM_GET_FEATURES, pfarg_features_t *arg, 1);
PFM_DEBUG
perfmonctl(int fd, PFM_DEBUG, val, 0);
إذا كانت val غير صفرية، فقم بتمكين وضع التصحيح، وإلا فقم بتعطيله.
PFM_GET_PMC_RESET_VAL
perfmonctl(int fd, PFM_GET_PMC_RESET_VAL, pfarg_reg_t *req, n);
إعادة تعيين سجلات PMC إلى القيم الافتراضية.

قيمة الإرجاع

يعيد perfmonctl() صفرًا عند نجاح العملية. عند حدوث خطأ، يتم إرجاع -1 ويتم تعيين errno للإشارة إلى الخطأ.

المعايير

Linux على IA-64.

التاريخ

تمت الإضافة في Linux 2.4؛ تمت الإزالة في Linux 5.10.

كان استدعاء النظام هذا معطلاً لسنوات عديدة، وتمت إزالته في النهاية في Linux 5.10.

لا توفر glibc دالة مساعدة لاستدعاء النظام هذا؛ على النواة حيث يوجد، قم باستدعائه باستخدام syscall(2).
