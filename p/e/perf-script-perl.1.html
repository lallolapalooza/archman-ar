الحزمة: perf

التراخيص: GPL-2.0-only

PERF-SCRIPT-PERL(1) دليل perf PERF-SCRIPT-PERL(1)

الاسم

perf-script-perl - معالجة بيانات التتبع باستخدام نص Perl

الملخص

perf script [-s [Perl]:script[.pl] ]

الوصف

يُستخدم خيار نص perf script هذا لمعالجة بيانات perf script باستخدام مترجم Perl المدمج في perf. يقرأ ويعالج ملف الإدخال ويعرض نتائج تحليل التتبع المنفذة في نص Perl المحدد، إن وجد.

نصوص البداية

يمكنك تجنب قراءة بقية هذا المستند عن طريق تشغيل perf script -g perl في نفس الدليل الذي يوجد فيه ملف تتبع perf.data. سيؤدي ذلك إلى إنشاء نص بداية يحتوي على معالج لكل نوع حدث في ملف التتبع؛ يقوم ببساطة بطباعة كل حقل متاح لكل حدث في ملف التتبع.

يمكنك أيضًا إلقاء نظرة على النصوص الموجودة في ~/libexec/perf-core/scripts/perl للحصول على أمثلة نموذجية توضح كيفية القيام بأشياء أساسية مثل تجميع بيانات الأحداث، وطباعة النتائج، وما إلى ذلك. أيضًا، يحاول النص check-perf-script.pl، على الرغم من أنه غير مثير للاهتمام بالنسبة لنتائجه، ممارسة جميع ميزات البرمجة النصية الرئيسية.

معالجات الأحداث

عند استدعاء perf script باستخدام نص تتبع، يتم استدعاء دالة معالج معرفة من قبل المستخدم لكل حدث في التتبع. إذا لم تكن هناك دالة معالج محددة لنوع حدث معين، يتم تجاهل الحدث (أو تمريره إلى دالة trace_unhandled، انظر أدناه) ويتم معالجة الحدث التالي.

يتم تمرير معظم قيم حقول الحدث كمعلمات لدالة المعالج؛ بعض الحقول الأقل شيوعًا ليست كذلك - تلك متاحة كمكالمات مرة أخرى إلى تنفيذ perf (انظر أدناه).

كمثال، يمكن استخدام أمر perf record التالي لتسجيل جميع أحداث sched_wakeup في النظام:

# perf record -a -e sched:sched_wakeup

يجب تسجيل التتبعات المقصودة للمعالجة باستخدام نص برمجي مع الخيار المذكور أعلاه: -a لتمكين جمع النظام بأكمله.

يحدد ملف التنسيق لحدث sched_wakeup الحقول التالية (انظر /sys/kernel/tracing/events/sched/sched_wakeup/format):

.ft C
 format:
        field:unsigned short common_type;
        field:unsigned char common_flags;
        field:unsigned char common_preempt_count;
        field:int common_pid;
        field:char comm[TASK_COMM_LEN];
        field:pid_t pid;
        field:int prio;
        field:int success;
        field:int target_cpu;
.ft

سيتم تعريف دالة المعالج لهذا الحدث على النحو التالي:

.ft C
sub sched::sched_wakeup
{
   my ($event_name, $context, $common_cpu, $common_secs,
       $common_nsecs, $common_pid, $common_comm,
       $comm, $pid, $prio, $success, $target_cpu) = @_;
}
.ft

تأخذ دالة المعالج الشكل subsystem::event_name.

تتضمن وسيطات $common_* في قائمة وسيطات المعالج مجموعة الوسيطات التي تم تمريرها إلى جميع معالجات الأحداث؛ بعض الحقول تتوافق مع حقول common_* في ملف التنسيق، ولكن بعضها تم تصنيعه، وبعض حقول common_* ليست شائعة بما يكفي ليتم تمريرها إلى كل حدث كوسيطات ولكنها متاحة كوظائف مكتبية.

فيما يلي وصف موجز لكل من وسيطات الأحداث الثابتة:

$event_name                اسم الحدث كنص
$context                   'بسكويت' غير شفاف يستخدم في المكالمات الراجعة إلى perf
$common_cpu                وحدة المعالجة المركزية التي حدث عليها الحدث
$common_secs               جزء الثواني من وقت طابع الحدث
$common_nsecs              جزء النانو ثانية من وقت طابع الحدث
$common_pid                معرف العملية للمهمة الحالية
$common_comm               اسم العملية الحالية

جميع الحقول المتبقية في ملف تنسيق الحدث لها نظائر كوسيطات لدالة المعالج بنفس الاسم، كما هو موضح في المثال أعلاه.

يوفر ما سبق الأساسيات اللازمة للوصول المباشر إلى كل حقل من كل حدث في التتبع، مما يغطي 90٪ مما تحتاج إلى معرفته لكتابة نص تتبع مفيد. تغطي الأقسام أدناه الباقي.

تخطيط النص

يجب أن يبدأ كل نص Perl script perf بإنشاء مسار بحث لوحدة Perl واستخدام عدد قليل من وحدات الدعم ('use' - انظر أوصاف الوحدات أدناه):

.ft C
 use lib "$ENV{'PERF_EXEC_PATH'}/scripts/perl/Perf-Trace-Util/lib";
 use lib "./Perf-Trace-Util/lib";
 use Perf::Trace::Core;
 use Perf::Trace::Context;
 use Perf::Trace::Util;
.ft

يمكن أن يحتوي بقية النص على دوال معالجة ودوال دعم بأي ترتيب.

بخلاف دوال معالجة الأحداث التي تمت مناقشتها أعلاه، يمكن لكل نص برمجي تنفيذ مجموعة من الدوال الاختيارية:

trace_begin، إذا تم تعريفه، يتم استدعاؤه قبل معالجة أي حدث ويعطي النصوص فرصة للقيام بمهام الإعداد:

.ft C
 sub trace_begin
 {
 }
.ft

trace_end، إذا تم تعريفه، يتم استدعاؤه بعد معالجة جميع الأحداث ويعطي النصوص فرصة للقيام بمهام نهاية النص، مثل عرض النتائج:

.ft C
sub trace_end
{
}
.ft

trace_unhandled، إذا تم تعريفه، يتم استدعاؤه بعد ذلك لأي حدث لا يحتوي على معالج محدد بشكل صريح له. يتم تمرير مجموعة الوسيطات الشائعة القياسية إليه:

.ft C
sub trace_unhandled
{
    my ($event_name, $context, $common_cpu, $common_secs,
        $common_nsecs, $common_pid, $common_comm) = @_;
}
.ft

تقدم الأقسام التالية أوصافًا لكل وحدة Perl النصية المدمجة في perf ووظائفها المرتبطة بها.

الوحدات والوظائف المتاحة

تصف الأقسام التالية الوظائف والمتغيرات المتاحة عبر وحدات Perl المختلفة Perf::Trace::*. لاستخدام الوظائف والمتغيرات من وحدة معينة، أضف السطر المقابل use Perf::Trace::XXX إلى نص perf script الخاص بك.

وحدة Perf::Trace::Core

توفر هذه الوظائف بعض الوظائف الأساسية للنصوص البرمجية للمستخدم.

توفر الوظائف flag_str و symbol_str سلاسل نصية سهلة القراءة للحقول الرمزية والحقول الرمزية. تتوافق هذه مع السلاسل والقيم التي تم تحليلها من حقول print fmt في ملفات تنسيق الحدث:

flag_str($event_name, $field_name, $field_value) - تُرجع التمثيل النصي المقابل لـ $field_value للحقل الرمزي $field_name للحدث $event_name
symbol_str($event_name, $field_name, $field_value) - تُرجع التمثيل النصي المقابل لـ $field_value للحقل الرمزي $field_name للحدث $event_name

وحدة Perf::Trace::Context

بعض حقول common في ملف تنسيق الحدث ليست شائعة جدًا، ولكن يجب جعلها في متناول النصوص البرمجية للمستخدم مع ذلك.

تحدد Perf::Trace::Context مجموعة من الوظائف التي يمكن استخدامها للوصول إلى هذه البيانات في سياق الحدث الحالي. تتوقع كل من هذه الوظائف متغير $context، وهو نفس متغير $context الذي تم تمريره إلى كل معالج حدث كوسيط ثانٍ.

common_pc($context) - تُرجع عدد common_preempt للحدث الحالي
common_flags($context) - تُرجع common_flags للحدث الحالي
common_lock_depth($context) - تُرجع common_lock_depth للحدث الحالي

وحدة Perf::Trace::Util

وظائف أدوات مساعدة مختلفة للاستخدام مع perf script:

nsecs($secs, $nsecs) - تُرجع إجمالي النانو ثانية بالنظر إلى زوج الثواني/النانو ثانية
nsecs_secs($nsecs) - تُرجع جزء الثواني الكامل بالنظر إلى النانو ثانية
nsecs_nsecs($nsecs) - تُرجع الباقي من النانو ثانية بالنظر إلى النانو ثانية
nsecs_str($nsecs) - تُرجع سلسلة نصية قابلة للطباعة بالشكل secs.nsecs
avg($total, $n) - تُرجع المتوسط بالنظر إلى مجموع وعدد إجمالي للقيم
