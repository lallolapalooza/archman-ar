perf-annotate(1)

الحزمة: perf

التراخيص: GPL-2.0-only

--type-data

Show data type information. If this option is not specified, then the default behavior is to show counts only, otherwise it’d show all data types it finds.

--type-stat

Show stats for the data type annotation.

--skip-empty

Do not display empty (or dummy) events.

--code-with-type

Show data type info in code annotation (for memory instructions only). Currently it only works with --stdio option.

perf-record(1), perf-report(1)
