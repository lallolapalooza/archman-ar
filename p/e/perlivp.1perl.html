PERLIVP(1perl) دليل مبرمجي Perl PERLIVP(1perl)

الاسم

perlivp - إجراء التحقق من تثبيت Perl

الملخص

perlivp [-p] [-v] [-h]

الوصف

تم إعداد برنامج perlivp في وقت بناء شفرة مصدر Perl لاختبار إصدار Perl الذي تم بناؤه تحته. يمكن استخدامه بعد تشغيل:

make install

(أو الإجراء المكافئ لمنصتك) للتحقق من تثبيت perl ومكتباته بشكل صحيح. يتم التحقق من التثبيت الصحيح من خلال مخرجات تبدو كالتالي:

ok 1
ok 2

إلخ.

خيارات

-h مساعدة
يطبع رسالة مساعدة موجزة.
-p طباعة مقدمة
يقدم وصفًا لكل اختبار قبل إجرائه.
-v مطول
يقدم معلومات مفصلة حول كل اختبار، بعد إجرائه. لاحظ أن أي اختبارات فاشلة يجب أن تطبع بعض المعلومات الإضافية سواء تم استخدام -v أم لا.

التشخيصات

  • print "# Perl binary '$perlpath' does not appear executable.\n";

    من المحتمل أن يحدث هذا لملف Perl التنفيذي لم يتم تثبيته بشكل صحيح. قم بتصحيحه عن طريق إجراء تثبيت صحيح.

  • print "# Perl version '$]' installed, expected $ivp_VERSION.\n";

    من المحتمل أن يحدث هذا لـ Perl لم يتم تثبيته بشكل صحيح. قم بتصحيحه عن طريق إجراء تثبيت صحيح.

  • print "# Perl \@INC directory '$_' does not appear to exist.\n";

    من المحتمل أن يحدث هذا لشجرة مكتبات Perl لم يتم تثبيتها بشكل صحيح. قم بتصحيحه عن طريق إجراء تثبيت صحيح.

  • print "# Needed module '$_' does not appear to be properly installed.\n";

    إحدى الوحدتين اللتين يستخدمهما perlivp لم تكن موجودة في التثبيت. هذا خطأ جسيم لأنه يؤثر سلبًا على قدرة perlivp على العمل. قد تتمكن من تصحيح هذا عن طريق إجراء تثبيت Perl صحيح.

  • print "# Required module '$_' does not appear to be properly installed.\n";

    فشل محاولة "eval " require $module""، على الرغم من أن قائمة الامتدادات أشارت إلى أنه يجب أن ينجح. قم بتصحيحه عن طريق إجراء تثبيت صحيح.

  • print "# Unnecessary module 'bLuRfle' appears to be installed.\n";

    قد يشير فشل هذا الاختبار إلى أنك قمت في الواقع بتثبيت وحدة bLuRfle.pm أو أن اختبار "eval " require \"$module_name.pm\"; "" قد يعطي نتائج مضللة مع تثبيتك لـ Perl. إذا كانت حالتك هي الأخيرة، فيرجى إبلاغ المؤلف.

  • print "# file",+($#missing == 0) ? '' : 's'," missing from installation:\n";

    تبين أن هناك ملفًا واحدًا أو أكثر مفقودًا وفقًا لتشغيل "ExtUtils::Installed -> validate()" على تثبيتك. قم بتصحيحه عن طريق إجراء تثبيت صحيح.

لمزيد من المعلومات حول كيفية إجراء تثبيت صحيح، استشر ملف INSTALL الذي يأتي مع شفرة Perl المصدر وملف README لمنصتك.
