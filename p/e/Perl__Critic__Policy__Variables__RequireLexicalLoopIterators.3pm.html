Perl__Critic__Policy__Variables__RequireLexicalLoopIterators(3pm)

الحزمة: perl-perl-critic

التراخيص: PerlArtistic

Perl::Critic::Policy::Variables::RequireLexicalLoopIterators(3pm) وثائق Perl المساهمة من المستخدم Perl::Critic::Policy::Variables::RequireLexicalLoopIterators(3pm)

الاسم

Perl::Critic::Policy::Variables::RequireLexicalLoopIterators - كتابة "for my $element (@list) {...}" بدلاً من "for $element (@list) {...}".

الانتماء

هذه السياسة جزء من التوزيع الأساسي لـ Perl::Critic.

الوصف

تطلب منك هذه السياسة استخدام متغيرات تكرار حلقة معجمية بأسلوب "my":

foreach my $zed (...) {
    ...
}

ما لم تستخدم "my"، تستخدم حلقات "for" / "foreach" متغيرًا عالميًا تكون قيمته "local" للكتلة. بمعنى آخر،

foreach $zed (...) {
    ...
}

يعادل تقريبًا

{
    local $zed
    foreach $zed (...) {
        ...
    }
}

قد لا يبدو هذا صفقة كبيرة حتى ترى رمزًا مثل

my $bicycle;
for $bicycle (@things_attached_to_the_bike_rack) {
    if (
            $bicycle->is_red()
        and $bicycle->has_baseball_card_in_spokes()
        and $bicycle->has_bent_kickstand()
    ) {
        $bicycle->remove_lock();
        last;
    }
}
if ( $bicycle and $bicycle->is_unlocked() ) {
    ride_home($bicycle);
}

وهو ما لن يسمح لك بالوصول في الوقت المناسب لتناول العشاء مع عائلتك لأن $bicycle خارج الحلقة لا يتغير بالحلقة. قد تكون قد فتحت قفل دراجتك، ولكن لا يمكنك تذكر أي واحدة هي.

تم تقديم متغيرات الحلقة المعجمية في Perl 5.004. لا تبلغ هذه السياسة عن انتهاكات في التعليمات البرمجية التي تحدد صراحةً إصدارًا سابقًا من Perl (على سبيل المثال، "require 5.002;").

التكوين

هذه السياسة غير قابلة للتكوين باستثناء الخيارات القياسية.
