هل يمكنني استخدام تعبيرات Perl العادية لمطابقة نص متوازن؟

(مساهمة من brian d foy)

يجب أن تكون محاولتك الأولى على الأرجح هي الوحدة النصية Text::Balanced، وهي موجودة في مكتبة Perl القياسية منذ Perl 5.8. تحتوي على مجموعة متنوعة من الدوال للتعامل مع النصوص المعقدة. يمكن للوحدة Regexp::Common المساعدة أيضًا من خلال توفير أنماط جاهزة يمكنك استخدامها.

اعتبارًا من Perl 5.10، يمكنك مطابقة النصوص المتوازنة باستخدام التعبيرات العادية من خلال الأنماط التكرارية. قبل Perl 5.10، كان عليك اللجوء إلى حيل مختلفة مثل استخدام كود Perl في تسلسلات "(??{})".

إليك مثال يستخدم تعبيرًا عاديًا تكراريًا. الهدف هو التقاط كل النص الموجود داخل أقواس زاوية، بما في ذلك النص الموجود في الأقواس الزاوية المتداخلة. يحتوي هذا النص النموذجي على مجموعتين "رئيسيتين": مجموعة بمستوى واحد من التداخل ومجموعة بمستويين من التداخل. يوجد خمس مجموعات إجمالاً في أقواس زاوية:

I have some <brackets in <nested brackets> > and
<another group <nested once <nested twice> > >
and that's it.

يستخدم التعبير العادي لمطابقة النص المتوازن ميزتين جديدتين (في Perl 5.10) للتعبيرات العادية. تمت تغطية هذه الميزات في perlre وهذا المثال هو نسخة معدلة من إحداها في تلك الوثائق.

أولاً، إضافة علامة "+" الحصرية إلى أي كمي (quantifier) يجد أطول تطابق ولا يتراجع. هذا مهم لأنك تريد معالجة أي أقواس زاوية من خلال التكرار، وليس التراجع. المجموعة "[^<>]++" تجد حرفًا واحدًا أو أكثر من الأحرف غير القوسية بدون تراجع.

ثانيًا، تشير "(?PARNO)" الجديدة إلى النمط الفرعي في مجموعة الالتقاط المعينة بالرقم "PARNO". في التعبير العادي التالي، تجد مجموعة الالتقاط الأولى (وتتذكر) النص المتوازن، وتحتاج إلى نفس النمط داخل المخزن المؤقت الأول لتجاوز النص المتداخل. هذا هو الجزء التكراري. تستخدم "(?1)" النمط الموجود في مجموعة الالتقاط الخارجية كجزء مستقل من التعبير العادي.

بتجميع كل شيء معًا، لديك:

#!/usr/local/bin/perl5.10.0
my $string =<<"HERE";
I have some <brackets in <nested brackets> > and
<another group <nested once <nested twice> > >
and that's it.
HERE
my @groups = $string =~ m/
        (                   # start of capture group 1
        <                   # match an opening angle bracket
            (?:
                [^<>]++     # one or more non angle brackets, non backtracking
                  |
                (?1)        # found < or >, so recurse to capture group 1
            )*
        >                   # match a closing angle bracket
        )                   # end of capture group 1
        /xg;
$" = "\n\t";
print "Found:\n\t@groups\n";

يُظهر الإخراج أن Perl وجدت المجموعتين الرئيسيتين:

Found:
    <brackets in <nested brackets> >
    <another group <nested once <nested twice> > >

مع القليل من العمل الإضافي، يمكنك الحصول على جميع المجموعات الموجودة داخل أقواس زاوية حتى لو كانت موجودة داخل أقواس زاوية أخرى. في كل مرة تحصل فيها على تطابق متوازن، قم بإزالة المحدد الخارجي الخاص به (وهو الذي طابقته للتو، لذا لا تطابقه مرة أخرى) وأضفه إلى قائمة انتظار للمعالجة. استمر في القيام بذلك حتى لا تحصل على أي مطابقات:

#!/usr/local/bin/perl5.10.0
my @queue =<<"HERE";
I have some <brackets in <nested brackets> > and
<another group <nested once <nested twice> > >
and that's it.
HERE
my $regex = qr/
        (                   # start of bracket 1
        <                   # match an opening angle bracket
            (?:
                [^<>]++     # one or more non angle brackets, non backtracking
                  |
                (?1)        # recurse to bracket 1
            )*
        >                   # match a closing angle bracket
        )                   # end of bracket 1
        /x;
$" = "\n\t";
while( @queue ) {
    my $string = shift @queue;
    my @groups = $string =~ m/$regex/g;
    print "Found:\n\t@groups\n\n" if @groups;
    unshift @queue, map { s/^<//; s/>$//; $_ } @groups;
}

يُظهر الإخراج جميع المجموعات. تظهر المطابقات الخارجية أولاً وتظهر المطابقات المتداخلة لاحقًا:

Found:
    <brackets in <nested brackets> >
    <another group <nested once <nested twice> > >
Found:
    <nested brackets>
Found:
    <nested once <nested twice> >
Found:
    <nested twice>

ماذا يعني أن التعبيرات العادية جشعة؟ كيف يمكنني تجاوز ذلك؟

معظم الناس يقصدون أن التعبيرات العادية الجشعة تطابق أكبر قدر ممكن. من الناحية الفنية، الكميات (quantifiers) ("?"، "*"، "+"، "{}") هي الجشعة وليست النمط بأكمله؛ يفضل Perl الجشع المحلي والإشباع الفوري على الجشع العام. للحصول على إصدارات غير جشعة لنفس الكميات، استخدم ("??"، "*?"، "+?"، "{}?").

مثال:

my $s1 = my $s2 = "I am very very cold";
$s1 =~ s/ve.*y //;      # I am cold
$s2 =~ s/ve.*?y //;     # I am very cold

لاحظ كيف توقف الاستبدال الثاني عن المطابقة بمجرد أن صادف "y ". الكمي "*?" يخبر محرك التعبيرات العادية بشكل فعال بالبحث عن تطابق بأسرع ما يمكن وتمرير التحكم إلى ما هو تالي في السلسلة، كما لو كنت تلعب لعبة البطاطا الساخنة.

كيف أعالج كل كلمة في كل سطر؟

استخدم الدالة split:

while (<>) {
    foreach my $word ( split ) {
        # do something with $word here
    }
}

لاحظ أن هذه ليست كلمة بالمعنى الإنجليزي حقًا؛ إنها مجرد أجزاء من أحرف غير بيضاء متتالية.

للعمل فقط مع التسلسلات الأبجدية الرقمية (بما في ذلك الشرطات السفلية)، قد ترغب في التفكير في

while (<>) {
    foreach $word (m/(\w+)/g) {
        # do something with $word here
    }
}

كيف يمكنني طباعة ملخص لتكرار الكلمات أو تكرار الأسطر؟

للقيام بذلك، عليك تحليل كل كلمة في تدفق الإدخال. سنتظاهر بأنك تقصد بالكلمة جزءًا من الأحرف الأبجدية أو الواصلات أو علامات الاقتباس، بدلاً من فكرة الكلمة المكونة من أجزاء غير بيضاء كما ورد في السؤال السابق:

my (%seen);
while (<>) {
    while ( /(\b[^\W_\d][\w'-]+\b)/g ) {   # misses "`sheep'"
        $seen{$1}++;
    }
}
while ( my ($word, $count) = each %seen ) {
    print "$count $word\n";
}

إذا كنت تريد فعل الشيء نفسه للأسطر، فلن تحتاج إلى تعبير عادي:

my (%seen);
while (<>) {
    $seen{$_}++;
}
while ( my ($line, $count) = each %seen ) {
    print "$count $line";
}

إذا كنت تريد طباعة هذه في ترتيب مرتب، انظر perlfaq4: "How do I sort a hash (optionally by value instead of key)؟".

كيف يمكنني إجراء مطابقة تقريبية؟

انظر الوحدة String::Approx المتاحة من CPAN.

كيف أطابق العديد من التعبيرات العادية بكفاءة في وقت واحد؟

(مساهمة من brian d foy)

تريد تجنب تجميع تعبير عادي في كل مرة تريد مطابقة. في هذا المثال، يجب على Perl إعادة تجميع التعبير العادي لكل تكرار لحلقة "foreach" نظرًا لأن $pattern يمكن أن يتغير:

my @patterns = qw( fo+ ba[rz] );
LINE: while( my $line = <> ) {
    foreach my $pattern ( @patterns ) {
        if( $line =~ m/\b$pattern\b/i ) {
            print $line;
            next LINE;
        }
    }
}

يقوم المعامل "qr//" بتجميع تعبير عادي، ولكنه لا يطبقه. عندما تستخدم الإصدار المجمع مسبقًا من التعبير العادي، يقوم Perl بعمل أقل. في هذا المثال، أدرجت "map" لتحويل كل نمط إلى شكله المجمع مسبقًا. بقية البرنامج متطابق، ولكنه أسرع:

my @patterns = map { qr/\b$_\b/i } qw( fo+ ba[rz] );
LINE: while( my $line = <> ) {
    foreach my $pattern ( @patterns ) {
        if( $line =~ m/$pattern/ ) {
            print $line;
            next LINE;
        }
    }
}

في بعض الحالات، قد تتمكن من تحويل عدة أنماط إلى تعبير عادي واحد. كن حذرًا من المواقف التي تتطلب التراجع. في هذا المثال، يتم تجميع التعبير العادي مرة واحدة فقط لأن $regex لا يتغير بين التكرارات:

my $regex = join '|', qw( fo+ ba[rz] );
while( my $line = <> ) {
    print if $line =~ m/\b(?:$regex)\b/i;
}

يمكن أيضًا استخدام الدالة "list2re" في Data::Munge على CPAN لتكوين تعبير عادي واحد يطابق قائمة من السلاسل الحرفية (وليس التعبيرات العادية).

لمزيد من التفاصيل حول كفاءة التعبيرات العادية، انظر Mastering Regular Expressions بواسطة Jeffrey Friedl. يشرح كيف يعمل محرك التعبيرات العادية ولماذا تكون بعض الأنماط غير فعالة بشكل مدهش. بمجرد فهمك لكيفية تطبيق Perl للتعبيرات العادية، يمكنك ضبطها لحالات فردية.

لماذا لا تعمل عمليات البحث عن حدود الكلمات باستخدام "\b" معي؟

(مساهمة من brian d foy)

تأكد من أنك تعرف ما تفعله \b حقًا: إنها الحدود بين حرف كلمة، \w، وشيء ليس حرف كلمة. هذا الشيء الذي ليس حرف كلمة قد يكون \W، ولكنه يمكن أن يكون أيضًا بداية أو نهاية السلسلة.

إنها ليست (ليست!) الحدود بين المسافات البيضاء وغير المسافات البيضاء، وليست الشيء بين الكلمات الذي نستخدمه لإنشاء جمل.
