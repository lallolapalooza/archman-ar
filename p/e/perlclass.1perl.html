الاسم

class - هيكل أساسي لتعريف الأصناف في Perl

الملخص

use v5.36;
use experimental 'class';

package My::Class;

field $name :param;
field $age  :param :reader;

ADJUST {
    die "Age must be positive" unless $self.age > 0;
}

method greet () {
    say "Hello, my name is $self.name and I am $self.age years old.";
}

package main;

my $person = My::Class->new(name => 'Alice', age => 30);
$person->greet;

say $person.age; # uses the reader method

الوصف

توفر الكلمة المفتاحية "class" بنية أساسية لتعريف الأصناف (classes) في Perl. تهدف إلى توفير طريقة أكثر تجريدًا ومنظمة لإنشاء الأصناف مقارنة بالنماذج التقليدية المستندة إلى الـ "bless".

يتم تعريف الأصناف باستخدام الصيغة:

package My::Class;
class My::Class {
    ...
}

يتم تنفيذ كتلة "class" عند تحميل الحزمة. يمكن كتابة الحقول (fields) والأساليب (methods) وكتل "ADJUST" داخل كتلة "class".

الحقول

يتم تعريف حقول الكائن باستخدام الكلمة المفتاحية "field". يمكن أن يكون للحقول سمات (attributes) تتحكم في سلوكها.

field $variable_name :attribute1 :attribute2(value);

يتم تحديد نوع الحقل باستخدام الـ sigil (مثل $ للأسكالار، @ للمصفوفة، % للهاش).

الأساليب

يتم تعريف الأساليب باستخدام الكلمة المفتاحية "method".

method method_name (parameters?) {
    ...
}

يمكن الوصول إلى الكائن الحالي داخل الأسلوب باستخدام "$self".

كتل ADJUST

تسمح كتل "ADJUST" بتنفيذ كود مخصص أثناء إنشاء الكائن، بعد تهيئة الحقول.

ADJUST {
    # Code to run during object construction
    ...
}

الكلمات المفتاحية

"ADJUST"
كتلة يتم تنفيذها أثناء إنشاء الكائن.
"class"
كلمة مفتاحية لتعريف صنف.
"field"
كلمة مفتاحية لتعريف حقل الكائن.
"method"
كلمة مفتاحية لتعريف أسلوب الكائن.

السمات

يمكن تطبيق السمات على الحقول والأساليب لتعديل سلوكها. السمات المدعومة حاليًا هي:

سمات الصنف

:isa

تحدد صنفًا أبًا أو واجهة يجب أن يرثها الصنف الحالي. يمكن أن تطلب حدًا أدنى لإصدار الصنف الأب.

class SubClass :isa(BaseClass 1.23) { ... }

سيحاول استخدام السمة ":isa" استدعاء "require" للوحدة المسماة إذا لم تكن محملة بالفعل.

سمات الحقول

:param

يحدد أن الحقل يجب أن يأخذ قيمته من معامل مسمى يتم تمريره إلى المنشئ (constructor). افتراضيًا، يكون اسم المعامل هو نفس اسم الحقل، ولكن يمكن تحديد اسم مختلف.

field $x :param;
field $y :param(the_y_value);

إذا لم يكن هناك تعبير افتراضي، فيجب تمرير المعامل عند إنشاء الكائن، وإلا سيتم طرح استثناء. مع وجود تعبير افتراضي، يصبح المعامل اختياريًا.

:reader

ينشئ تلقائيًا طريقة وصول للقراءة (reader accessor) للحقل. الأسلوب المُنشأ سيحمل نفس اسم الحقل (بدون الـ sigil) وسيعيد قيمة متغير الحقل.

field $s :reader;
# يعادل
field $s;
method s () { return $s; }

يمكن تحديد اسم مختلف للأسلوب المُنشأ.

field $x :reader(get_x);
# ينشئ أسلوبًا
method get_x () { return $x; }

يمكن تطبيق أساليب القراءة على الحقول غير العددية. عند استدعائها في سياق قائمة، فإنها تعيد محتويات الحقل؛ في سياق عددي، فإنها تعيد عدد العناصر.

field @users :reader;
...
scalar $instance->users;

:writer

ينشئ تلقائيًا طريقة وصول للكتابة (writer accessor) للحقل. الأسلوب المُنشأ سيقبل وسيطًا واحدًا وسيعين قيمته إلى متغير الحقل ويعيد الكائن نفسه.

field $s :writer;
# يعادل
field $s;
method set_s($new) { $s = $new; return $self; }

افتراضيًا، سيكون اسم الأسلوب هو "set_" متبوعًا باسم الحقل، ولكن يمكن تحديد اسم مختلف.

field $x :writer(write_x);
# ينشئ أسلوبًا
method write_x ($new) { ... }

حاليًا، يمكن تطبيق أساليب الكتابة فقط على الحقول العددية. محاولات تطبيق هذه السمة على حقل غير عددي ستؤدي إلى استثناء قاتل أثناء الترجمة. قد يتم تخفيف هذا في إصدار مستقبلي للسماح بأساليب الكتابة على حقول المصفوفات أو الهاش.

سمات الأساليب

لا يوجد حاليًا.

دورة حياة الكائن

الإنشاء

تبدأ حياة كل كائن باستدعاء المنشئ (constructor). اسم المنشئ دائمًا هو "new" ويتم استدعاؤه كاستدعاء أسلوب على اسم الصنف:

my $object = My::Class->new(%arguments);

أثناء إنشاء الكائن، يتم البحث عن حقول الصنف في الهاش %arguments وتعبئتها حيثما أمكن.

التعديل

تعديل الكائن هو طريقة لتشغيل كود عشوائي معرف من قبل المستخدم أثناء إنشاء الكائن. يتم ذلك عن طريق وضع الكود في كتل "ADJUST". في كل مرة يتم فيها إنشاء كائن، يتم تنفيذ كتل "ADJUST" الخاصة به (بالترتيب الذي تم الإعلان عنها به).

class WellAdjusted {
    field $x :param;
    ADJUST {
        say "Hello!";
    }
    ADJUST {
        say "x = $x";
    }
}
my $object = WellAdjusted->new(x => 42);
# المخرجات:
#   Hello!
#   x = 42

تتشابه كتل "ADJUST" نحويًا مع كتل "BEGIN" أو "INIT"، والتي تعمل مرة واحدة فقط. ومع ذلك، فإن كتل "ADJUST"، مثل الأساليب، لديها وصول إلى $self (متغير قاموسي يحتوي على الكائن الذي يتم إنشاؤه) بالإضافة إلى جميع حقول الكائن التي تم إنشاؤها حتى تلك النقطة.

العمر الافتراضي

بعد مرحلة الإنشاء، يكون الكائن جاهزًا للاستخدام.

استخدام "blessed" ("Scalar::Util::blessed" أو "builtin::blessed") على الكائن سيعيد اسم الصنف، بينما "reftype" ("Scalar::Util::reftype" أو "builtin::reftype") سيعيد السلسلة النصية 'OBJECT'.

الهدم

يتم تدمير الكائن عندما يختفي آخر مرجع له، تمامًا كما هو الحال مع هياكل البيانات الأخرى في Perl.

ملاحظات للتنفيذ المستقبلي

هذه الميزة لا تزال تجريبية وغير مكتملة جدًا. تقدم القائمة التالية نظرة عامة على الميزات التي لا تزال بحاجة إلى إضافة أو تغيير:

  • الأدوار (Roles)

    بعض الصيغ لتحديد دور (ربما كلمة مفتاحية "role")، ولاستهلاك دور في صنف (ربما سمة :does()).

  • معاملات لكتل ADJUST

    بعض الصيغ لتحديد أن كتلة "ADJUST" يمكنها استهلاك معاملات مسماة، والتي تصبح جزءًا من واجهة المنشئ للصنف. قد يكون هذا مستوحى من خطة مماثلة لإضافة وسائط مسماة إلى توقيعات الإجراءات الفرعية.

    class X {
    ADJUST (:$alpha, :$beta = 123) {
       ...
    }
}
my $obj = X->new(alpha => 456);
  • كتل ADJUST ككتل حقيقية

    حاليًا، يتم تغليف كل كتلة ADJUST في CV (إجراء فرعي) خاص بها يتم استدعاؤه مع الحمل الزائد الكامل لـ ENTERSUB. يجب أن يكون من الممكن استخدام نفس الآلية التي تجعل جميع تعبيرات تهيئة الحقول تظهر ضمن نفس CV على كتل ADJUST أيضًا، ودمجها جميعًا في CV واحد لكل صنف. سيؤدي هذا إلى تسريع استدعائها إذا كان للصنف أكثر من واحد.

  • المزيد من سمات إنشاء أساليب الوصول

    سمات لطلب إنشاء أنواع أخرى من أساليب الوصول للحقول. من المحتمل ":writer".

    class X {
    field $name :writer;
}

    يعادل

    class X {
    field $name;
    method set_name ($new) { $name = $new; return $self; }
}
  • البرمجة الوصفية (Metaprogramming)

    تمديد لواجهة البرمجة الوصفية (مقترح حاليًا بواسطة PPC0022 https://github.com/Perl/PPCs/pull/25) والتي تضيف معرفة بالأصناف، الأساليب، الحقول، كتل ADJUST، وتفاصيل أخرى متعلقة بالصنف.

  • تخصيص الامتداد

    طرق يمكن للوحدات الخارجية من خلالها التفاعل مع نظام الأصناف، بما في ذلك القدرة على توفير سمات جديدة للصنف أو الحقل.

الأخطاء المعروفة

تم اكتشاف الأخطاء التالية في الميزة التجريبية "class":

  • منذ Perl v5.38، قد يؤدي الوراثة من صنف أب تم تعريفه في نفس الملف ولم يتم ختمه بالفعل إلى حدوث خطأ تجزئة. [GH #20890 https://github.com/Perl/perl5/issues/20890]
  • منذ Perl v5.38 ومع ميزة "refaliasing" التجريبية، تحاول استبدال متغير حقل يؤدي إلى حدوث خطأ تجزئة. [GH #20947 https://github.com/Perl/perl5/issues/20947]
  • منذ Perl v5.38، من الممكن إنشاء صنف به تغليف غير محكم (leaky encapsulation)، مما قد يؤدي إلى حدوث خطأ تجزئة. [GH #20956 https://github.com/Perl/perl5/issues/20956]
  • في Perl v5.38، لم تكن الوراثة من صنف تحاول دائمًا تحميل الصنف الأب (تم إصلاحها في Perl v5.40). [GH #21332 https://github.com/Perl/perl5/issues/21332]
