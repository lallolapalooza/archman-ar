NAME

make-pp - packaging a perl program into a standalone binary

SYNOPSIS

B<make-pp> [options] <program.pl> [args]

    make-pp --target=my_program my_program.pl
    make-pp --target=my_program --force my_program.pl
    make-pp --target=my_program --output=./bin/my_program my_program.pl

DESCRIPTION

This command takes a perl program and packs it into a standalone binary executable. The executable contains the program itself, the perl runtime, all core perl libraries, and all installed site and local perl modules.

The purpose of this command is to create an executable that can be deployed to environments where perl and its dependencies might not be pre-installed. It aims to provide a simple, albeit potentially heavy-weight, solution for distributing Perl applications.

The generated binary is intended to be runnable on systems with the same operating system and architecture as the system where make-pp was run.

OPTIONS

The following options are available:

--target=<name>
Specifies the name of the target executable. This is a required option.
--output=<path>
Specifies the output path for the standalone executable. If not provided, the executable will be created in the current directory with the name specified by --target.
--force
Overwrite the target executable if it already exists. By default, make-pp will not overwrite an existing file and will exit with an error.
--verbose
Enable verbose output, showing more details about the packaging process.
--help
Display a help message and exit.
--version
Display the version information and exit.

HOW IT WORKS

make-pp essentially bundles the following into a single executable file:

  1. The input Perl program (‘program.pl’).
  2. The Perl runtime interpreter.
  3. All core Perl libraries that come with the current Perl installation.
  4. All libraries installed in the site- பகுதிகளில் (site_lib).
  5. All libraries managed by `perlbrew lib` if a local Perl environment is currently active.

The resulting binary is designed to be self-contained and runnable on another machine having the same OS and architecture. This simplifies deployment by removing the need to install Perl or its dependencies separately on the target machine.

It is important to note that this approach is often considered "overkill" for packaging a single program. The generated executable will contain a complete Perl environment, which is significantly larger than the exact runtime dependencies of the program itself. make-pp is intended as a convenient, albeit not the most optimized, solution for the complex problem of precisely determining and bundling the runtime dependencies of an arbitrary Perl program.
