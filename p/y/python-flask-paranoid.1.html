FLASK-PARANOID(1) #

FLASK-PARANOID
flask-paranoid is a Flask extension that helps you to secure your sessions by checking for changes in the remote IP address or user agent string. If either of these have changed, it invalidates the session.

Installation #

You can install the extension using pip:

$ pip install flask-paranoid

Usage #

First, import the extension and initialize it with your Flask application:

from flask import Flask
from flask_paranoid import Paranoid

app = Flask(__name__)
paranoid = Paranoid(app)

By default, the extension checks for changes in both the remote IP address and the user agent string. You can configure its behavior using the following options:

  • PARANOID_CHECK_IP (boolean, default: True): Enable/disable checking for changes in the remote IP address.
  • PARANOID_CHECK_USER_AGENT (boolean, default: True): Enable/disable checking for changes in the user agent string.
  • PARANOID_SESSION_TOKEN_KEY (string, default: '_paranoid_session'): The key used to store the session token in Flask's session.
  • PARANOID_SESSION_CLEANUP_MECHANISM (string, default: 'before_request'): The mechanism used to clean up the session. Possible values are 'before_request', 'after_request', and 'never'.

For example, to only check the user agent string and use a different session cleanup mechanism:

app.config.update(
    PARANOID_CHECK_IP=False,
    PARANOID_SESSION_CLEANUP_MECHANISM='after_request'
)

Configuration #

The extension can be configured using Flask's configuration object.

CHANGING THE ALGORITHM #

By default, the extension uses a simple comparison of the current IP address and user agent string against the values stored in the session. If you need to implement a more complex algorithm, you can provide a custom function to the Paranoid constructor:

def custom_paranoid_check(session, request):
                    # Your custom logic here
                    # Return True if the session is valid, False otherwise
                    pass

                paranoid = Paranoid(app, check_func=custom_paranoid_check)

CHANGING WHERE THE TOKEN IS STORED #

The session token is stored in Flask's session by default. You can change this by providing a custom storage mechanism:

def custom_token_storage(session):
                    # Return the token
                    pass

                def custom_token_retrieval(request):
                    # Return the token
                    pass

                paranoid = Paranoid(app,
                                    token_storage=custom_token_storage,
                                    token_retrieval=custom_token_retrieval)

USING A DIFFERENT SESSION CLEANUP MECHANISM #

The extension can clean up the session before or after each request, or never. You can configure this using the PARANOID_SESSION_CLEANUP_MECHANISM configuration option:

app.config['PARANOID_SESSION_CLEANUP_MECHANISM'] = 'after_request'
