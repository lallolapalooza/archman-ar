الاسم

pyotp - PyOTP

PyOTP هي مكتبة بايثون لإنشاء والتحقق من كلمات المرور ذات الاستخدام الواحد. يمكن استخدامها لتطبيق طرق المصادقة الثنائية (2FA) أو المصادقة متعددة العوامل (MFA) في تطبيقات الويب وفي أنظمة أخرى تتطلب تسجيل الدخول للمستخدمين.

  • ضمان سرية النقل باستخدام HTTPS
  • ضمان سرية مفتاح HOTP/TOTP بتخزين المفاتيح في قاعدة بيانات ذات وصول متحكم به
  • رفض هجمات إعادة الاستخدام عن طريق رفض كلمات المرور ذات الاستخدام الواحد التي استخدمها العميل (يتطلب هذا تخزين آخر طابع زمني مصدق، OTP، أو تجزئة OTP في قاعدة بياناتك، ورفض OTP عند رؤية تطابق)
  • تحديد معدل (تقييد المعدل) هجمات القوة الغاشمة ضد وظيفة تسجيل الدخول الخاصة بتطبيقك (انظر RFC 4226، القسم 7.3)
  • عند تطوير تطبيق "من الصفر"، ضع في اعتبارك دعم FIDO U2F/WebAuthn بالإضافة إلى HOTP/TOTP. تستخدم U2F التشفير غير المتماثل لتجنب استخدام تصميم المفتاح المشترك، مما يقوي حل MFA الخاص بك ضد الهجمات من جانب الخادم. كما أن U2F للأجهزة تخفي المفتاح السري في جهاز مخصص لغرض واحد، مما يقوي عملائك ضد الهجمات من جانب العميل. ومن خلال أتمتة نطاق بيانات الاعتماد لمعرفات الجهة المعتمدة (أصول التطبيق/أسماء النطاقات)، تضيف U2F حماية ضد هجمات التصيد الاحتيالي. أحد تطبيقات FIDO U2F/WebAuthn هو المشروع الشقيق لـ PyOTP، وهو PyWARP.

نظرة عامة سريعة على استخدام كلمات المرور ذات الاستخدام الواحد على هاتفك

  • تتضمن كلمات المرور ذات الاستخدام الواحد مفتاحًا سريًا مشتركًا، مخزنًا على الهاتف والخادم
  • يمكن إنشاء كلمات المرور ذات الاستخدام الواحد على الهاتف بدون اتصال بالإنترنت
  • يجب دائمًا استخدام كلمات المرور ذات الاستخدام الواحد كعامل مصادقة ثانٍ (إذا فُقد هاتفك، يظل حسابك مؤمنًا بكلمة مرور)
  • تسمح لك تطبيقات كلمات المرور ذات الاستخدام الواحد مثل Google Authenticator وغيرها بتخزين مفاتيح OTP متعددة وتوفيرها باستخدام QR Code

التثبيت

pip install pyotp

الاستخدام

كلمات المرور ذات الاستخدام الواحد القائمة على الوقت

import pyotp
import time
totp = pyotp.TOTP('base32secret3232')
totp.now() # => '492039'
# تم التحقق من OTP للوقت الحالي
totp.verify('492039') # => True
time.sleep(30)
totp.verify('492039') # => False

كلمات المرور ذات الاستخدام الواحد القائمة على العداد

import pyotp
hotp = pyotp.HOTP('base32secret3232')
hotp.at(0) # => '260182'
hotp.at(1) # => '055283'
hotp.at(1401) # => '316439'
# تم التحقق من OTP مع عداد
hotp.verify('316439', 1401) # => True
hotp.verify('316439', 1402) # => False

إنشاء مفتاح سري

تم توفير دالة مساعدة لإنشاء مفتاح سري Base32 مكون من 32 حرفًا، متوافق مع Google Authenticator وتطبيقات OTP الأخرى:

pyotp.random_base32()

ترغب بعض التطبيقات في تنسيق المفتاح السري كسلسلة مشفرة بصيغة Hex:

pyotp.random_hex()  # يعيد مفتاحًا سريًا مشفرًا بصيغة Hex مكونًا من 40 حرفًا

متوافق مع Google Authenticator

تعمل PyOTP مع تطبيق Google Authenticator لهواتف iPhone و Android، وكذلك مع تطبيقات OTP الأخرى مثل Authy. تتضمن PyOTP القدرة على إنشاء عناوين URI للتزويد لاستخدامها مع ماسح QR Code المدمج في تطبيقات عميل MFA هذه:

يتم دعم تحليل هذه العناوين أيضًا:

pyotp.parse_uri('otpauth://totp/Secure%20App:alice%40google.com?secret=JBSWY3DPEHPK3PXP&issuer=Secure%20App')
>>> <pyotp.totp.TOTP object at 0xFFFFFFFF>
pyotp.parse_uri('otpauth://hotp/Secure%20App:alice%40google.com?secret=JBSWY3DPEHPK3PXP&issuer=Secure%20App&counter=0'
>>> <pyotp.totp.HOTP object at 0xFFFFFFFF>

•
pyotp.contrib.Steam(): تطبيق لـ Steam TOTP. يستخدم نفس واجهة برمجة التطبيقات مثل pyotp.TOTP().
