الاسم

pysmi - مترجم SNMP SMI

التوثيق

توثيق PySMI

مكتبة PySMI ذات نمطية عالية. المكون الأعلى مستوى يسمى compiler (المترجم) وهو يعمل ككائن رئيسي يواجه المستخدم. معظم المكونات الأخرى يتم ربطها بكائن compiler قبل استخدامه.

عادةً، يطلب المستخدم من compiler أداء تحويل معين لوحدة MIB مسماة. سيقوم المترجم بما يلي:

  • البحث في مصادر بياناته عن وحدة MIB معينة (يتم تحديدها بالاسم) مع ملاحظة أوقات آخر تعديل لها.
  • البحث في مستودعات المترجم التي تدير وحدات MIB المحولة بالفعل عن وحدات أحدث من وحدة MIB المصدر المقابلة.
  • إذا تم العثور على وحدة MIB محولة حديثًا، تتوقف العملية هنا.
  • بخلاف ذلك، يقوم المترجم بتمرير محتوى وحدة MIB ASN.1 إلى مكون lexer (المحلل الصرفي).
  • يقوم المحلل الصرفي بإرجاع تسلسل من محتويات MIB ASN.1 المميزة. ثم يقوم المترجم بتمرير هذا التسلسل من الرموز إلى مكون parser (المحلل النحوي).
  • يقوم المحلل النحوي بتشغيل خوارزمية LR على MIB المميز، وبالتالي تحويل محتويات MIB إلى شجرة بناء مجردة (AST) مع ملاحظة وحدات MIB الأخرى التي يتم الرجوع إليها من MIB قيد التحليل.
  • في حالة فشل المحلل النحوي، وهو ما يكون عادةً مؤشرًا على بناء جملة MIB ASN.1 معطل، قد يحاول المترجم جلب محتويات MIB المحولة مسبقًا من المصدر المعد. تسمى هذه العملية borrowing (استعارة) في PySMI.
  • في حالة اكتمال نجاح المحلل النحوي، سيقوم المترجم بتمرير AST المنتج إلى مكون code generator (مولد الكود).
  • يقوم مولد الكود بالمرور على شجرة AST المدخلة الخاصة به ويقوم بالتحويل الفعلي للبيانات.
  • قد يتم تكرار الخطوات المذكورة أعلاه لكل وحدة MIB التي يتم الرجوع إليها حيث يكتشف المحلل النحوي. بمجرد عدم وجود تبعيات غير محلولة، سيقوم المترجم باستدعاء مكون writer (الكاتب) الخاص به لتخزين جميع وحدات MIB المحولة.

يتم تحديد موقع وحدات MIB ASN.1 ونكهة بناء الجملة الخاصة بها، وكذلك شكل التحويل المطلوب، بواسطة المكونات المقابلة التي تم اختيارها وتهيئتها للمترجم.

أداة mibdump

الأداة mibdump.py هي واجهة سطر أوامر لمكتبة PySMI. يمكن استخدام هذه الأداة للتنزيل التلقائي لوحدات SNMP MIB وتحويلها إلى تنسيقات مختلفة.

تحديد مصدر MIB

يمكن إعطاء الخيار --mib-source عدة مرات. يجب أن تحدد كل نسخة من --mib-source عنوان URL حيث يجب البحث عن وحدات MIB ASN.1 وتنزيلها. في الوقت الحالي، يتم دعم ثلاث طرق لمصادر MIB:

  • الملفات المحلية. يمكن أن يكون هذا دليلًا عالي المستوى حيث توجد ملفات MIB. سيتم اجتياز الدلائل الفرعية تلقائيًا أيضًا. مثال: file:///usr/share/snmp
  • أرشيفات ZIP التي تحتوي على ملفات MIB. سيتم اجتياز الدلائل الفرعية وأرشيفات ZIP المضمنة تلقائيًا. مثال: zip://mymibs.zip
  • HTTP/HTTPS. عنوان URL محدد بالكامل حيث يتم تحديد اسم وحدة MIB بواسطة عنصر نائب @mib@. عند البحث عن MIB معين، سيقوم PySMI باستبدال هذا العنصر النائب باسم وحدة MIB التي يبحث عنها. مثال: http://mibs.snmplabs.com/asn1/@mib@
  • SFTP/FTP. عنوان URL محدد بالكامل بما في ذلك اسم مستخدم وكلمة مرور FTP. يتم تحديد اسم وحدة MIB بواسطة عنصر نائب @mib@. عند البحث عن MIB معين، سيقوم PySMI باستبدال هذا العنصر النائب باسم وحدة MIB الذي يبحث عنه. مثال: http://mibs.snmplabs.com/asn1/@mib@

عند محاولة جلب وحدة MIB، ستحاول الأداة mibdump.py تجربة كل من وسائل النقل --mib-source المعدة بترتيب التحديد حتى أول نجاح.

افتراضيًا، ستبحث الأداة mibdump.py في:

  • file:///usr/share/snmp
  • http://mibs.snmplabs.com/asn1/@mib@

بمجرد إعطاء خيار --mib-source آخر، لن يتم استخدام هذه الافتراضات ويجب تقديمها يدويًا إلى mibdump.py إذا لزم الأمر.

تجهيز أسماء وحدات MIB

لا يوجد معيار واحد لكيفية تسمية ملفات وحدات MIB. افتراضيًا، ستحاول الأداة mibdump.py عددًا قليلاً من التخمينات عند محاولة العثور على ملف يحتوي على وحدة MIB معينة. ستحاول الأحرف الكبيرة والصغيرة، وملف مسمى باسم MIB، ومحاولة إضافة امتدادات مختلفة إلى الملف (.mib، .my، إلخ)، ومحاولة إضافة/إزالة الجزء '-MIB' من اسم الملف. إذا لم يتطابق شيء، ستعتبر الأداة mibdump.py أن --mib-source الذي تم فحصه لا يحتوي على وحدة MIB التي تبحث عنها.

هناك احتمال ضئيل، مع ذلك، أن يؤدي المطابقة الضبابية إلى الحصول على MIB خاطئ. إذا حدث ذلك، يمكنك تعطيل الغموض المذكور أعلاه عن طريق إعطاء mibdump.py علامة --disable-fuzzy-source.

تجنب التحويل المفرط

قد يحدث أن العديد من وحدات MIB تشير إلى وحدة MIB واحدة مشتركة. في هذه الحالة، ستقوم الأداة mibdump.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

تحديد مصدر MIB

  • ملفات محلية. يمكن أن يكون هذا دليلاً عالي المستوى حيث توجد ملفات MIB. سيتم اجتياز الدلائل الفرعية تلقائيًا أيضًا. مثال: file:///usr/share/snmp
  • أرشيفات ZIP تحتوي على ملفات MIB. سيتم اجتياز الدلائل الفرعية وأرشيفات ZIP المضمنة تلقائيًا. مثال: zip://mymibs.zip
  • HTTP/HTTPS. عنوان URL محدد بالكامل حيث يتم تحديد اسم وحدة MIB بواسطة عنصر نائب @mib@. عند البحث عن MIB محدد، ستقوم PySMI باستبدال هذا العنصر النائب باسم وحدة MIB التي تبحث عنها. مثال: http://mibs.snmplabs.com/asn1/@mib@

عند محاولة جلب وحدة MIB، سيحاول أداة mibcopy.py استخدام كل من وسائل نقل --mib-source المكونة بالترتيب الذي تم تحديده حتى أول نجاح.

بشكل افتراضي، ستبحث mibcopy.py:

  • file:///usr/share/snmp
  • http://mibs.snmplabs.com/asn1/@mib@

بمجرد إعطاء خيار --mib-source آخر، لن يتم استخدام هذه الافتراضيات ويجب تقديمها يدويًا إلى mibcopy.py إذا لزم الأمر.

تعيين دليل الوجهة

تقوم mibcopy.py بكتابة MIBs إلى الدليل <DESTINATION>.

تجاهل أخطاء التحويل

بشكل افتراضي، ستتوقف PySMI عند أول خطأ فادح يحدث أثناء تحويل سلسلة من MIBs. إذا كنت ترغب في أن تتجاهل PySMI الأخطاء الفادحة، وبالتالي تخطي MIB الفاشلة، فاستخدم الخيار --ignore-errors.

ضع في اعتبارك أن تخطي تحويل MIBs التي يتم استيرادها بواسطة MIBs أخرى قد يجعل MIBs التابعة غير متسقة للاستخدام.

تسريعات طفيفة

يمكن استخدام الخيار --cache-directory للإشارة إلى دليل مؤقت قابل للكتابة حيث قد يقوم محلل PySMI (مثل Ply) بتخزين جداول البحث الخاصة به. من المفترض أن يؤدي ذلك إلى تحسين أداء PySMI قليلاً.

مكتبة PySMI

كائن MibCompiler هو الواجهة العليا لميزات مكتبة PySMI. يجمع القطع المنفصلة للبنية التحتية للمترجم معًا ويدير سير عمل تحويل ASN.1 MIB.

يوضح هذا المثال بعض ميزاته:

from pysmi.reader import HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
httpSources = [('mibs.snmplabs.com', 80, '/asn1/@mib@')]
# store compiled MIBs by calling this function
def store_mibs(mibName, jsonDoc, cbCtx):
    print('# MIB module %s' % mibName)
    print(jsonDoc)
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(store_mibs)
)
# pull ASN.1 MIBs over HTTP
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# never recompile MIBs with ASN.1 MACROs
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
status = mibCompiler.compile(*inputMibs)
print(status)

مترجم MIB

حالة الترجمة

يتم استخدام مثيل فئة MibStatus بواسطة MibCompiler.compiler() للإشارة إلى نتيجة عملية تحويل MIB.

مصادر MIB

توفر PySMI عددًا قليلاً من آليات النقل المتميزة لجلب MIBs بالاسم من مواقع محددة. في جميع الحالات، قد لا يكون تطابق اسم وحدة MIB مع اسم الملف دقيقًا - يمكن إجراء بعض التغيير الطفيف في الاسم للتخفيف من التغييرات المحتملة في اسم ملف MIB.

قارئ الملفات المحلية

يبحث مثيل فئة FileReader عن ملفات MIB في الدلائل المحددة على المضيف الذي يقوم بتشغيل PySMI.

قارئ أرشيف ZIP

يبحث مثيل فئة ZipReader عن ملفات MIB في أرشيف ZIP محلي. سيتم اجتياز الدلائل الفرعية لـ ZIP وأرشيفات ZIP المضمنة.

قارئ HTTP

يحاول مثيل فئة HttpReader تنزيل ملفات MIB باستخدام عنوان URL المكون.

قارئ FTP

يحاول مثيل فئة FtpReader تنزيل ملفات MIB من خادم FTP المكون.

قارئ الاستدعاء

يحاول مثيل فئة CallbackReader جلب ملفات MIB عن طريق استدعاء كائن المستخدم.

الترجمة الشرطية

هناك حالات قد لا يتم فيها إجراء تحويل MIB أو يجب عدم إجرائه. تشمل هذه الحالات:

  • MIBs الأساسية التي تحتوي على أجزاء منفذة يدويًا أو MACROs ASN.1
  • MIBs المهملة التي أعيد تنفيذها بالكامل ضمن MIBs حديثة
  • MIBs تم تحويلها بالفعل

يتوقع MibCompiler من المستخدم توفير كائن searcher يسمح أو يتجاوز تحويل MIB لاسم معين بناءً على أي سبب يعرفه.

الباحث عن ملفات Python

يمكن التحقق من MIBs المحولة التي تم حفظها على شكل ملفات Python باستخدام مثيلات فئة PyFileSearcher.

البحث عن حزم Python

يمكن تخزين بعض MIBs، وغالبًا الأساسية منها، في حزمة Python. يمكن التحقق من وجودها باستخدام مثيلات فئة PyPackageSearcher.

تجاهل MIBs بشكل غير مشروط

يمكن استبعاد MIBs الأساسية أو المهملة التي لا ينبغي تحويلها أبدًا عن طريق سرد أسمائها في مثيل فئة StubSearcher.

تهيئة المحلل

يمكن كتابة MIBs بإحدى نسختين رئيسيتين من لغة SMI (v1 و v2). قد تحتوي بعض MIBs على أخطاء نموذجية.

توفر PySMI طريقة لتخصيص المحلل لاستهلاك أي من قواعد SMI الرئيسية وكذلك للتعافي من الأخطاء المعروفة في ملفات MIB.

محلل SMI

تُكتب MIBs SNMP بلغتين خاصتين - SMIv1 و SMIv2. الإصدار الأول من SMI مهمل، ومعظم MIBs مكتوبة الآن بقواعد SMIv2. هناك أيضًا جهود تهدف إلى تحسين SMIv2، ولكن هذه MIBs في أقلية كبيرة في وقت كتابة هذا.

تم تصميم PySMI للتعامل مع كل من SMIv1 و SMIv2. الطريقة التي يتم بها ذلك هي أن SMIv2 يعتبر الأساس والأكثر اكتمالاً، بينما SMIv1 هو تخصص لصيغة SMIv2.

لكي يحصل المستخدم على محلل SMIv2، يجب استدعاء الدالة parserFactory مع كائن لهجة SMI.

يجب تمرير كائن المحلل إلى كائن MibCompiler.

ملاحظة:

يرجى ملاحظة أن الدالة parserFactory ترجع فئة، وليس مثيل فئة. تأكد من إنشاء مثيل لها عند تمريرها إلى منشئ الفئة MibCompiler.

لهجات لغة SMI

تقدم PySMI مجموعة معدة مسبقًا من خيارات استرخاء قواعد المحلل لتبسيط استخدامها:

  • pysmi.parser.dialect.smiV2 - قواعد SMIv2 القياسية
  • pysmi.parser.dialect.smiV1 - قواعد SMIv1 القياسية
  • pysmi.parser.dialect.smiV1Relaxed - قواعد SMIv1 المسترخية تسمح ببعض الانحرافات

يجب تمرير كائن القواعد إلى الدالة parserFactory.

from pysmi.parser.dialect import smiV1
from pysmi.parser.smi import parserFactory
SmiV1Parser = parserFactory(**smiV1)

من الواضح أن العديد من MIBs الإنتاجية تم شحنها في حالة معيبة من الناحية التركيبية. تحاول PySMI تجاوز هذه المشكلات من خلال السماح ببعض استرخاءات قواعد SMI الإضافية. يمكنك تمكين كل هذه الاسترخاءات دفعة واحدة لزيادة عدد MIBs، الموجودة في الحياة البرية، والتي تم تجميعها بنجاح.

from pysmi.parser.dialect import smiV1Relaxed
from pysmi.parser.smi import parserFactory
RelaxedSmiV1Parser = parserFactory(**smiV1Relaxed)

ترجمة MIBs إلى JSON

البحث عن MIBs محددة بتنسيق ASN.1 في مواقع الويب ومواقع FTP المكونة، وترجمتها إلى مستندات JSON وطباعتها على المخرج القياسي.

محاولة دعم كل من تنسيقي SMIv1 و SMIv2 لـ SMI، بالإضافة إلى الانحرافات الشائعة عن بناء الجملة الرسمي الموجودة في الواقع.

from pysmi.reader import FileReader, HttpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import JsonCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('reader', 'compiler'))
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
def printOut(mibName, jsonDoc, cbCtx):
    print('\n\n# MIB module %s' % mibName)
    print(jsonDoc)
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiStarParser(), JsonCodeGen(), CallbackWriter(printOut)
)
# search for source MIBs here
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# search for source MIBs at Web sites
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*JsonCodeGen.baseMibs))
# run recursive MIB compilation
results = mibCompiler.compile(*inputMibs)
print('\n# Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

ترجمة MIBs من الويب

البحث عن MIBs محددة بتنسيق ASN.1 في مواقع الويب ومواقع FTP المكونة، وترجمتها إلى تنسيق pysnmp وحفظ وحدات Python كملفات نصية عادية في دليل محلي.

محاولة دعم كل من تنسيقي SMIv1 و SMIv2 لـ SMI، بالإضافة إلى الانحرافات الشائعة عن بناء الجملة الرسمي الموجودة في الواقع.

في هذا المثال، نقوم بتعطيل التحقق التلقائي من الاعتماديات عند ترجمة MIB باستخدام العلامة noDeps.

أيضًا، لا نتحقق مما إذا كان الملف الهدف موجودًا بالفعل، وبالتالي تحدث ترجمة MIB في كل مرة يتم فيها الاستدعاء.

from pysmi.reader import HttpReader
from pysmi.reader import FtpReader
from pysmi.searcher import StubSearcher
from pysmi.writer import PyFileWriter

inputMibs = ['IF-MIB', 'IP-MIB']

    ('mibs.snmplabs.com', 80, '/asn1/@mib@')

    ('ftp.cisco.com', '/pub/mibs/v2/@mib@')

ترجمة MIBs بتنسيق SMIv1/v2

البحث عن MIBs محددة بتنسيق ASN.1 في الدلائل المحلية المكونة، وترجمتها إلى تنسيق pysnmp إذا لم يتم ذلك بعد، وحفظ وحدات Python كملفات نصية عادية في دليل محلي.

محاولة دعم كل من تنسيقي SMIv1 و SMIv2 لـ SMI، بالإضافة إلى الانحرافات الشائعة عن بناء الجملة الرسمي الموجودة في الواقع.

عند تحديد ما إذا كانت الترجمة مطلوبة، تحقق من جميع الأماكن المعروفة حيث يمكن العثور على MIBs الخاصة بـ pysnmp.

يمكنك فرض إعادة ترجمة MIB عن طريق تمرير العلامة rebuild إلى مترجم MIB (انظر أدناه).

الاستدعاء الافتراضي لمترجم MIB لا ينشئ تعليقات ونصوصًا [كبيرة محتملة] موجودة في MIBs. إذا كنت بحاجة إليها في وحدات MIB الخاصة بـ pysnmp، فما عليك سوى تمرير العلامة genTexts إلى مترجم MIB.

from pysmi.reader import FileReader
from pysmi.searcher import PyFileSearcher, PyPackageSearcher, StubSearcher
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDirectories = ['/usr/share/snmp/mibs']
dstDirectory = '.pysnmp-mibs'
# Initialize compiler infrastructure
mibCompiler = MibCompiler(SmiStarParser(),
                          PySnmpCodeGen(),
                          PyFileWriter(dstDirectory))
# search for source MIBs here
mibCompiler.addSources(*[FileReader(x) for x in srcDirectories])
# check compiled MIBs in our own productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# ...and at default PySNMP MIBs packages
mibCompiler.addSearchers(*[PyPackageSearcher(x) for x in PySnmpCodeGen.defaultMibPackages])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# run [possibly recursive] MIB compilation
results = mibCompiler.compile(*inputMibs)  #, rebuild=True, genTexts=True)
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

ترجمة MIBs بتنسيق SMIv2

استدعاء دالة استدعاء مستخدم لتوفير نص MIB، وترجمة سلسلة نصية معينة إلى تنسيق MIB الخاص بـ pysnmp، وتمرير النتائج إلى دالة استدعاء مستخدم أخرى للتخزين.

هنا نتوقع التعامل فقط مع MIBs الصالحة بتنسيق SMIv2.

نستخدم العلامة noDeps لمنع مترجم MIB من محاولة ترجمة MIBs المستوردة أيضًا.

import sys
from pysmi.reader import CallbackReader
from pysmi.searcher import StubSearcher
from pysmi.writer import CallbackWriter
from pysmi.parser import SmiV2Parser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
inputMibs = ['IF-MIB', 'IP-MIB']
srcDir = '/usr/share/snmp/mibs/'  # we will read MIBs from here
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiV2Parser(),
    PySnmpCodeGen(),
    # out own callback function stores results in its own way
    CallbackWriter(lambda m, d, c: sys.stdout.write(d))
)
# our own callback function serves as a MIB source here
mibCompiler.addSources(
  CallbackReader(lambda m, c: open(srcDir+m+'.txt').read())
)
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# run non-recursive MIB compilation
results = mibCompiler.compile(*inputMibs, **dict(noDeps=True))
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

استعارة MIBs الخاصة بـ pysnmp عند الفشل

البحث عن MIBs محددة بتنسيق ASN.1 في مواقع الويب/FTP المكونة. إذا لم يتم العثور على MIB المطلوبة أو فشلت ترجمتها لسبب ما، حاول تنزيل نسخة مترجمة مسبقًا من MIB الفاشلة وتخزينها محليًا كما لو كنا قد ترجمناها.

from pysmi.reader import HttpReader
from pysmi.searcher import PyFileSearcher
from pysmi.searcher import StubSearcher
from pysmi.borrower import PyFileBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('borrower', 'reader', 'searcher'))
inputMibs = ['BORROWED-MIB']
httpSources = [ 
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')
]
httpBorrowers = [
    ('mibs.snmplabs.com', 80, '/pysnmp/notexts/@mib@')
]
dstDirectory = '.pysnmp-mibs'
# Initialize compiler infrastructure
mibCompiler = MibCompiler(
    SmiStarParser(), PySnmpCodeGen(), PyFileWriter(dstDirectory)
)
# search for source MIBs at Web sites
mibCompiler.addSources(*[HttpReader(*x) for x in httpSources])
# never recompile MIBs with MACROs
mibCompiler.addSearchers(StubSearcher(*PySnmpCodeGen.baseMibs))
# check compiled/borrowed MIBs in our own productions
mibCompiler.addSearchers(PyFileSearcher(dstDirectory))
# search for compiled MIBs at Web sites if source is not available or broken
mibCompiler.addBorrowers(*[PyFileBorrower(HttpReader(*x)).setOptions(genTexts=False) for x in httpBorrowers])
# run non-recursive MIB compilation
results = mibCompiler.compile(*inputMibs)
print('Results: %s' % ', '.join(['%s:%s' % (x, results[x]) for x in results]))

استعارة MIBs الخاصة بـ pysnmp دائمًا

محاولة استعارة ملف (ملفات) MIB مترجمة مسبقًا من pysnmp من موقع ويب.

في هذا المثال، لا يتم بذل أي محاولة للعثور على مصدر MIB بتنسيق ASN.1 وترجمته.

يتم تخزين MIBs الخاصة بـ pysnmp التي تم جلبها في دليل محلي.

from pysmi.searcher import PyFileSearcher
from pysmi.borrower import PyFileBorrower
from pysmi.writer import PyFileWriter
from pysmi.parser import SmiStarParser
from pysmi.codegen import PySnmpCodeGen
from pysmi.compiler import MibCompiler
# from pysmi import debug
# debug.setLogger(debug.Debug('borrower', 'reader', 'searcher'))
inputMibs = ['SNMP-FRAMEWORK-MIB']
httpSources = [
    ('mibs.snmplabs.com', 80, '/asn1/@mib@')

    ('mibs.snmplabs.com', 80, '/pysnmp/full/@mib@')
