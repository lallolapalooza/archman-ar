python-sshtunnel(1)

الحزمة: python-sshtunnel

التراخيص: MIT

--remote_bind_address IP:PORT [IP:PORT ...] تسلسل عنوان الربط البعيد: ip_1:port_1 ip_2:port_2 ... ip_n:port_n يعادل ssh -Lxxxx:IP_ADDRESS:PORT إذا تم حذف المنفذ، فإنه افتراضيًا إلى 22. مثال: -R 10.10.10.10: 10.10.10.10:5900 -L [IP:PORT [IP:PORT ...]], --local_bind_address [IP:PORT [IP:PORT ...]] تسلسل عنوان الربط المحلي: ip_1:port_1 ip_2:port_2 ... ip_n:port_n يمكن أن تكون العناصر أيضًا مجالات مقبس UNIX صالحة: /tmp/foo.sock /tmp/bar.sock ... /tmp/baz.sock يعادل ssh -LPORT:xxxxxxxxx:xxxx، مع كون عنوان IP المحلي اختياريًا. افتراضيًا، سيستمع على جميع الواجهات (0.0.0.0) وسيختار منفذًا عشوائيًا. مثال: -L :40000 -k SSH_HOST_KEY, --ssh_host_key SSH_HOST_KEY مفتاح مضيف البوابة -K KEY_FILE, --private_key_file KEY_FILE ملف مفتاح RSA/DSS/ECDSA الخاص -S KEY_PASSWORD, --private_key_password KEY_PASSWORD كلمة مرور مفتاح RSA/DSS/ECDSA الخاص -t, --threaded السماح بالاتصالات المتزامنة لكل نفق -v, --verbose زيادة تفاصيل الإخراج (الافتراضي: خطأ) -V, --version عرض رقم الإصدار والخروج -x IP:PORT, --proxy IP:PORT عنوان IP ومنفذ وكيل SSH إلى الوجهة -c SSH_CONFIG_FILE, --config SSH_CONFIG_FILE ملف تكوين SSH، افتراضيًا ~/.ssh/config -z, --compress طلب ضغط الخادم عبر نقل SSH -n, --noagent تعطيل البحث عن المفاتيح من وكيل SSH -d [FOLDER [FOLDER ...]], --host_pkey_directories [FOLDER [FOLDER ...]] قائمة بالمجلدات التي يمكن العثور فيها على مفاتيح SSH الخاصة (بتنسيق `id_*`)

sshtunnel - بدء أنفاق SSH عبر بوابة بعيدة.

يعمل sshtunnel عن طريق فتح اتصال إعادة توجيه منفذ SSH في الخلفية، باستخدام المواضيع.

يتم إغلاق الاتصال (الاتصالات) عند استدعاء طريقة SSHTunnelForwarder.stop() بشكل صريح أو استخدامها كسياق.

sshtunnel.SSH_TIMEOUT = 0.1
المهلة (بالثواني) لمقبس النقل (socket.settimeout)
sshtunnel.TUNNEL_TIMEOUT = 10.0
المهلة (بالثواني) لاتصال النفق (مهلة open_channel)
sshtunnel.DEFAULT_LOGLEVEL = 40
المستوى الافتراضي إذا لم يتم تمرير مسجل (خطأ)
sshtunnel.DEFAULT_SSH_DIRECTORY = '~/.ssh'
مسار ملف تكوين SSH اختياري
sshtunnel.check_address(address)
تحقق مما إذا كان تنسيق العنوان صحيحًا
الوسائط:
address (tuple):
(str, int) يمثل عنوان IP ومنفذًا، على التوالي

ملاحظة:

بدلاً من ذلك، يمكن أن يكون address محليًا str عند العمل مع مقابس UNIX، إذا كان النظام الأساسي يدعمها
يثير:
ValueError:
يتم رفعه عندما يكون للعنوان تنسيق غير صحيح
مثال:
>>> check_address(('127.0.0.1', 22))
sshtunnel.check_addresses(address_list, is_remote=False)
تحقق مما إذا كان تنسيق العناوين صحيحًا
الوسائط:
address_list (list[tuple]):
تسلسل أزواج (str, int)، كل منها يمثل عنوان IP ومنفذًا على التوالي

ملاحظة:

عندما يدعم النظام الأساسي، يمكن أن يكون عنصر واحد أو أكثر في القائمة من نوع str، يمثل مقبس UNIX صالح
is_remote (boolean):
ما إذا كان قائمة العناوين
يثير:
AssertionError:
يتم رفعه عندما تحتوي address_list على عنصر غير صالح
ValueError:
يتم رفعه عندما يكون لأي عنوان في القائمة تنسيق غير صحيح

مثال:

>>> check_addresses([('127.0.0.1', 22), ('127.0.0.1', 2222)])
sshtunnel.create_logger(logger=None, loglevel=None, capture_warnings=True, add_paramiko_handler=True)
إرفاق أو إنشاء مسجل جديد وإضافة معالج وحدة تحكم إذا لم يكن موجودًا

الوسائط:

logger (Optional[logging.Logger]):
logging.Logger instance؛ يتم إنشاء نسخة جديدة إذا كان هذا الوسيط فارغًا
loglevel (Optional[str or int]):
logging.Logger's level، إما كسلسلة (أي ERROR) أو بتنسيق رقمي (10 == DEBUG)

ملاحظة:

قيمة 1 == TRACE تمكن وضع التتبع
capture_warnings (boolean):
تمكين/تعطيل التقاط الأحداث التي سجلتها الوحدة التحذيرية إلى معالجات logger

افتراضي: True

ملاحظة:

تم تجاهله في python 2.6
add_paramiko_handler (boolean):
ما إذا كان سيتم إضافة معالج وحدة تحكم لمسجل paramiko.transport إذا لم يكن هناك معالج

افتراضي: True

الإرجاع:
logging.Logger
exception sshtunnel.BaseSSHTunnelForwarderError(*args, **kwargs)
الاستثناء الذي تثيره أخطاء SSHTunnelForwarder
exception sshtunnel.HandlerSSHTunnelForwarderError(*args, **kwargs)
استثناء لأخطاء إعادة توجيه النفق
class sshtunnel.SSHTunnelForwarder(ssh_address_or_host=None, ssh_config_file='~/.ssh/config', ssh_host_key=None, ssh_password=None, ssh_pkey=None, ssh_private_key_password=None, ssh_proxy=None, ssh_proxy_enabled=True, ssh_username=None, local_bind_address=None, local_bind_addresses=None, logger=None, mute_exceptions=False, remote_bind_address=None, remote_bind_addresses=None, set_keepalive=5.0, threaded=True, compression=None, allow_agent=True, host_pkey_directories=None, *args, **kwargs)
فئة نفق SSH
  • تهيئة نفق SSH إلى مضيف بعيد وفقًا للوسائط المدخلة
اختياريًا:
  • قراءة ملف تكوين SSH (عادةً ~/.ssh/config)
  • تحميل المفاتيح من وكيل SSH قيد التشغيل (أي Pageant، GNOME Keyring)

يثير:

BaseSSHTunnelForwarderError:
يتم رفعه بواسطة طرق فئة SSHTunnelForwarder
HandlerSSHTunnelForwarderError:
يتم رفعه بواسطة مواضيع إعادة توجيه النفق

ملاحظة:

يمكن استخدام السمات mute_exceptions و raise_exception_if_any_forwarder_have_a_problem (مهملة) لكتم معظم الاستثناءات التي يتم رفعها من هذه الفئة

وسائط الكلمات الرئيسية:

ssh_address_or_host (tuple or str):
عنوان IP أو اسم مضيف البوابة البعيدة. يمكن أن يكون زوجًا من عنصرين (str, int) يمثل عنوان IP والمنفذ، على التوالي، أو str يمثل عنوان IP فقط

تمت الإضافة في الإصدار 0.0.4.

>
ssh_config_file (str):
ملف تهيئة SSH الذي سيتم قراءته. إذا تم تعيينه صراحةً إلى None، فسيتم تخطي تحليل هذه التهيئة

الافتراضي: SSH_CONFIG_FILE

تمت الإضافة في الإصدار 0.0.4.

ssh_host_key (str):
تمثيل سطر في ملف "known hosts" بأسلوب OpenSSH.

سيتم مقارنة بصمة المفتاح لـ REMOTE GATEWAY بهذا المفتاح المضيف لمنع انتحال شخصية خادم SSH. مهم عند استخدام كلمات المرور لتجنب محاولة تسجيل الدخول عن طريق الخطأ إلى آلة خاطئة (ربما آلة مهاجم)

ssh_username (str):
اسم المستخدم للمصادقة عليه في REMOTE SERVER

الافتراضي: اسم المستخدم المحلي الحالي

ssh_password (str):
نص يمثل كلمة المرور المستخدمة للاتصال بـ REMOTE SERVER أو لفتح مفتاح خاص.

ملاحظة:

تجنب ترميز كلمة المرور السرية مباشرة في الكود، حيث قد تكون مرئية وتجعل خدمتك عرضة للهجمات
ssh_port (int):
رقم منفذ اختياري لخدمة SSH على REMOTE GATEWAY، عندما يكون `ssh_address_or_host` سلسلة نصية تمثل جزء IP عنوان REMOTE GATEWAY

الافتراضي: 22

ssh_pkey (str or paramiko.PKey):
اسم ملف المفتاح الخاص (str) للحصول على المفتاح العام منه أو مفتاح عام (paramiko.pkey.PKey)
ssh_private_key_password (str):
كلمة مرور لـ ssh_pkey مشفر

ملاحظة:

تجنب ترميز كلمة المرور السرية مباشرة في الكود، حيث قد تكون مرئية وتجعل خدمتك عرضة للهجمات

ملاحظة:

ssh_proxy (socket-like object or tuple):
خادم وكيل سيتم تمرير جميع حركة مرور SSH من خلاله. قد يكون على سبيل المثال مثيل paramiko.proxy.ProxyCommand. راجع وثائق المعامل `sock` لـ paramiko.transport.Transport أو ProxyCommand في ssh_config(5) لمزيد من المعلومات.

من الممكن أيضًا تحديد عنوان الوكيل كزوج من النوع (str, int) يمثل IP ومنفذ الوكيل

ملاحظة:

يتم تجاهله إذا كان ssh_proxy_enabled هو False

تمت الإضافة في الإصدار 0.0.5.

ssh_proxy_enabled (boolean):
تمكين/تعطيل وكيل SSH. إذا كان True ويحتوي ملف ssh_config_file للمستخدم على توجيه ProxyCommand يتطابق مع ssh_address_or_host المحدد، فسيتم إنشاء كائن paramiko.proxy.ProxyCommand سيتم تمرير جميع حركة مرور SSH من خلاله

الافتراضي: True

تمت الإضافة في الإصدار 0.0.4.

local_bind_address (tuple):
زوج محلي بالتنسيق (str, int) يمثل IP ومنفذ الجانب المحلي للأنفاق. كلا العنصرين في الزوج اختياريان، لذا ('', 8000) و ('10.0.0.1', ) قيم صالحة

الافتراضي: ('0.0.0.0', RANDOM_PORT)

تم التغيير في الإصدار 0.0.8: تمت إضافة القدرة على استخدام مقبس مجال UNIX كعنوان ربط محلي

local_bind_addresses (list[tuple]):
في حالة إنشاء أكثر من نفق واحد في وقت واحد، يمكن تحديد قائمة بالأزواج (بنفس التنسيق مثل local_bind_address)، مثل [(ip1, port_1), (ip_2, port2), ...]

الافتراضي: [local_bind_address]

تمت الإضافة في الإصدار 0.0.4.

remote_bind_address (tuple):
زوج بعيد بالتنسيق (str, int) يمثل IP ومنفذ الجانب البعيد للأنفاق.
remote_bind_addresses (list[tuple]):
في حالة إنشاء أكثر من نفق واحد في وقت واحد، يمكن تحديد قائمة بالأزواج (بنفس التنسيق مثل remote_bind_address)، مثل [(ip1, port_1), (ip_2, port2), ...]

الافتراضي: [remote_bind_address]

تمت الإضافة في الإصدار 0.0.4.

allow_agent (boolean):

compression (boolean):
تشغيل/إيقاف ضغط النقل. افتراضيًا، يتم تعطيل الضغط لأنه قد يؤثر سلبًا على الجلسات التفاعلية

mute_exceptions (boolean):
السماح بكتم استثناءات BaseSSHTunnelForwarderError أو HandlerSSHTunnelForwarderError عند تمكينها

set_keepalive (float):
الفترة الزمنية بالثواني التي يتم فيها، إذا لم يتم إرسال أي بيانات عبر الاتصال، إرسال حزمة 'keepalive' (وتجاهلها بواسطة المضيف البعيد). قد يكون هذا مفيدًا للحفاظ على الاتصالات حية عبر NAT. يمكنك تعيينه إلى 0.0 لتعطيل keepalive.

الافتراضي: 5.0 (لا يتم إرسال حزم keepalive)

تمت الإضافة في الإصدار 0.0.7.

threaded (boolean):
السماح بالاتصالات المتزامنة عبر نفق واحد

الافتراضي: True

تمت الإضافة في الإصدار 0.0.3.

ssh_address (str):
تم استبداله بـ ssh_address_or_host، زوج من النوع (str, int) يمثل IP ومنفذ REMOTE SERVER

تم إهماله منذ الإصدار 0.0.4.

ssh_host (str):
تم استبداله بـ ssh_address_or_host، زوج من النوع (str, int) يمثل IP ومنفذ REMOTE SERVER

تم إهماله منذ الإصدار 0.0.4.

ssh_private_key (str or paramiko.PKey):
تم استبداله بـ ssh_pkey، والذي يمكن أن يمثل إما اسم ملف مفتاح خاص (str) أو مفتاح عام (paramiko.pkey.PKey)

تم إهماله منذ الإصدار 0.0.8.

raise_exception_if_any_forwarder_have_a_problem (boolean):
السماح بكتم استثناءات BaseSSHTunnelForwarderError أو HandlerSSHTunnelForwarderError عند تعيينه إلى False

الافتراضي: True

تم إهماله منذ الإصدار 0.0.8: (استخدم mute_exceptions بدلاً من ذلك)

سمات:

tunnel_is_up (dict):
وصف ما إذا كان الجانب الآخر من النفق قد تم الإبلاغ عنه على أنه يعمل (ويجب علينا إغلاقه) أم لا (تخطي إغلاق هذا النفق)

ملاحظة:

لا ينبغي تعديل هذه السمة

ملاحظة:

عندما يتم تعطيل skip_tunnel_checkup أو عندما يكون الربط المحلي مقبس UNIX، ستكون القيمة دائمًا True

{('127.0.0.1', 55550): True,   # هذا النفق يعمل

حيث 55550 و 55551 هي منافذ الربط المحلي
