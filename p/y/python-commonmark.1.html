NAME

python-commonmark - A Python library for parsing Markdown and CommonMark. Supports CommonMark spec 0.29.

INSTALLATION

This man page is for the python-commonmark package which can be installed from the Arch User Repository.

$ pacman -S python-commonmark

Or you can install it via pip:

$ pip install commonmark

USAGE

The primary interface to the commonmark parser is the commonmark.Parser class. Instantiate it and call its parse method:

import commonmark

parser = commonmark.Parser()
text = "# Hello world!"
ast = parser.parse(text)

# ast is a commonmark.node.Node object, the root of the AST.
# You can then iterate through the AST using NodeWalker or directly.
# For example, to print all the text nodes:
for node in ast.walker():
    if node.t == 'text':
        print(node.literal)

الاستخدام

الواجهة الأساسية لمحلل commonmark هي الفئة commonmark.Parser. قم بإنشاء نسخة منها واستدعاء طريقة parse الخاصة بها:

import commonmark

parser = commonmark.Parser()
text = "# Hello world!"
ast = parser.parse(text)

# ast هو كائن commonmark.node.Node، وهو جذر الشجرة التركيبية (AST).
# يمكنك بعد ذلك التنقل عبر الشجرة التركيبية باستخدام NodeWalker أو مباشرة.
# على سبيل المثال، لطباعة جميع عقد النص:
for node in ast.walker():
    if node.t == 'text':
        print(node.literal)
