NAME

pypresence - Python RPC library for Discord

INSTALLATION

pip install pypresence

LINKS

Python RPC library for Discord: https://github.com/qwertyquerty/pypresence

Discord Developer Portal: https://discord.com/developers/applications

INFORMATION

This library allows for the creation of Discord Rich Presences.

For this library to work, you need to create a Discord application on the Discord Developer Portal.

You will need to copy the client_id of your application and paste it into the Client() constructor.
