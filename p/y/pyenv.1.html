pyenv(1)

الحزمة: pyenv

التراخيص: MIT

PYENV(1) دليل الأوامر العامة PYENV(1)

الاسم

pyenv - إدارة بسيطة لإصدارات Python

الملخص

pyenv <أمر> [<وسائط>]

الوصف

يسمح لك pyenv بالتبديل بسهولة بين إصدارات متعددة من Python. إنه بسيط وغير مزعج، ويتبع تقليد يونكس للأدوات ذات الغرض الواحد التي تقوم بشيء واحد بشكل جيد.


للبدء باستخدام pyenv

1.
أضف ما يلي إلى $HOME/.bashrc
if command -v pyenv 1>/dev/null 2>&1; then
   eval "$(pyenv init - bash)" 
fi

إضافة هذا السطر تُمكّن البرامج الوسيطة (shims). يرجى التأكد من وضع هذا السطر بالقرب من نهاية ملف تكوين الصدفة لأنه يتلاعب بـ PATH أثناء التهيئة.

ملاحظة Debian:
قم بتعديل ملف ~/.bashrc فقط بدلاً من إنشاء
~/.bash_profile
ملاحظة Zsh: قم بتعديل ملف ~/.zshrc بدلاً من ~/.bashrc

تحذير: إذا قمت بتكوين نظامك بحيث يشير المتغير BASH_ENV إلى .bashrc. يجب عليك تقريبًا وضع السطر المذكور أعلاه في .bash_profile، و ليس في .bashrc. بخلاف ذلك، قد تواجه سلوكًا غريبًا، مثل دخول pyenv في حلقة لا نهائية. راجع #264 https://github.com/pyenv/pyenv/issues/264 للتفاصيل.

2.
أعد تشغيل الصدفة الخاصة بك حتى تسري تغييرات المسار. يمكنك الآن البدء في استخدام pyenv.
exec "$SHELL"
3.
قم بتثبيت إصدارات Python في $(pyenv root)/versions. على سبيل المثال، لتنزيل وتثبيت Python 3.6.12، قم بتشغيل:
pyenv install 3.6.12

ملاحظة: إذا كنت بحاجة إلى تمرير خيارات تكوين للبناء، يرجى استخدام متغير البيئة CONFIGURE_OPTS. إذا كنت تواجه مشكلة في تثبيت إصدار Python، يرجى زيارة صفحة الويكي حول مشاكل البناء الشائعة https://github.com/pyenv/pyenv/wiki/Common-build-problems

ملاحظة الوكيل (Proxy): إذا كنت تستخدم وكيلًا، قم بتصدير متغيرات البيئة HTTP_PROXY و HTTPS_PROXY.

إيقاف استخدام pyenv

إن بساطة pyenv تجعل من السهل تعطيله مؤقتًا، أو إلغاء تثبيته من النظام. لـ تعطيل pyenv في إدارة إصدارات Python الخاصة بك، ببساطة قم بإزالة سطر pyenv init من تكوين بدء تشغيل الصدفة الخاص بك. سيؤدي ذلك إلى إزالة دليل البرامج الوسيطة (shims) لـ pyenv من PATH، وستقوم الاستدعاءات المستقبلية مثل python بتشغيل إصدار Python الخاص بالنظام، كما كان قبل pyenv.

سيظل pyenv متاحًا في سطر الأوامر، لكن تطبيقات Python الخاصة بك لن تتأثر بتبديل الإصدارات.

خيارات سطر الأوامر

مثل git، يقوم الأمر pyenv بتفويض الأوامر الفرعية بناءً على وسيطته الأولى.

بعض أوامر pyenv المفيدة هي:

commands
قائمة بجميع أوامر pyenv المتاحة
exec
تشغيل ملف تنفيذي بالإصدار المحدد من Python
global
تعيين أو عرض إصدار(ات) Python العالمي(ة)
help
عرض المساعدة لأمر معين
hooks
قائمة ببرامج الخطاف (hook scripts) لأمر pyenv معين
init
تكوين بيئة الصدفة لـ pyenv
install
تثبيت إصدار Python باستخدام python-build
local
تعيين أو عرض إصدار(ات) Python المحلي(ة) الخاص(ة) بالتطبيق
prefix
عرض البادئة لإصدار Python
rehash
إعادة تجزئة البرامج الوسيطة (shims) لـ pyenv (قم بتشغيل هذا بعد تثبيت الملفات التنفيذية)
root
عرض دليل الجذر حيث يتم الاحتفاظ بالإصدارات والبرامج الوسيطة
shell
تعيين أو عرض إصدار Python الخاص بالصدفة
shims
قائمة بالبرامج الوسيطة (shims) الموجودة لـ pyenv
uninstall
إلغاء تثبيت إصدارات Python
version
عرض إصدار(ات) Python الحالي(ة) ومصدره
version-file
تحديد الملف الذي يحدد إصدار pyenv الحالي
version-name
عرض إصدار Python الحالي
version-origin
شرح كيفية تعيين إصدار Python الحالي
versions
قائمة بجميع إصدارات Python المتاحة لـ pyenv
whence
قائمة بجميع إصدارات Python التي تحتوي على الملف التنفيذي المحدد
which
عرض المسار الكامل لملف تنفيذي

انظر `pyenv help <command>' للحصول على معلومات حول أمر معين. للحصول على توثيق كامل، راجع قسم مرجع الأوامر.

الخيارات

-h, --help
عرض ملخص للخيارات.
-v, --version
عرض إصدار البرنامج.

المقارنة

pyenv يفعل...

  • يسمح لك بـ تغيير إصدار Python العالمي على أساس كل مستخدم.
  • يوفر دعمًا لـ إصدارات Python الخاصة بالمشاريع.
  • يسمح لك بـ تجاوز إصدار Python باستخدام متغير بيئة.
  • يبحث عن الأوامر من إصدارات متعددة من Python في وقت واحد. قد يكون هذا مفيدًا للاختبار عبر إصدارات Python باستخدام tox.

على عكس pythonbrew و pythonz، pyenv لا...

  • يعتمد على Python نفسه. تم إنشاء pyenv من نصوص shell نقية. لا توجد مشكلة في التمهيد (bootstrap) لـ Python.
  • يحتاج إلى تحميله في الصدفة الخاصة بك. بدلاً من ذلك، يعمل نهج البرامج الوسيطة (shims) الخاص بـ pyenv عن طريق إضافة دليل إلى $PATH الخاص بك.
  • يدير virtualenv. بالطبع، يمكنك إنشاء virtualenv بنفسك، أو استخدام pyenv-virtualenv لأتمتة العملية.

كيف يعمل

بشكل عام، يعترض pyenv أوامر Python باستخدام برامج تنفيذية وسيطة (shim executables) تم حقنها في PATH الخاص بك، ويحدد إصدار Python الذي تم تحديده بواسطة تطبيقك، ويمرر أوامرك إلى تثبيت Python الصحيح.

فهم PATH

عندما تقوم بتشغيل أمر مثل python أو pip، يبحث نظام التشغيل الخاص بك في قائمة من الأدلة للعثور على ملف تنفيذي بهذا الاسم. تعيش قائمة الأدلة هذه في متغير بيئة يسمى PATH، مع فصل كل دليل في القائمة بنقطتين رأسيتين (colon):

/usr/local/bin:/usr/bin:/bin

يتم البحث في الأدلة الموجودة في PATH من اليسار إلى اليمين، لذا فإن الملف التنفيذي المطابق الموجود في دليل في بداية القائمة له الأسبقية على ملف آخر في النهاية. في هذا المثال، سيتم البحث في الدليل /usr/local/bin أولاً، ثم /usr/bin

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.
