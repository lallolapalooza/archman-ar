الاسم

pkgdata - بيانات الحزمة للاستخدام بواسطة ICU

الملخص

pkgdata [ -h, -?, --help ] [ -v, --verbose ] [ -c, --copyright | -C, --comment تعليق ] [ -m, --mode وضع ] -p, --name اسم -O, --bldopt خيارات [ -e, --entrypoint اسم ] [ -r, --revision إصدار ] [ -F, --rebuild ] [ -I, --install ] [ -s, --sourcedir مصدر ] [ -d, --destdir وجهة ] [ -T, --tempdir دليل ] [ ملف ... ]

الوصف

يقوم pkgdata بأخذ مجموعة من ملفات البيانات وتعبئتها للاستخدام بواسطة ICU أو التطبيقات التي تستخدم ICU. السبب النموذجي لتعبئة الملفات باستخدام pkgdata هو تسهيل توزيعها وتسريع تحميلها بواسطة ICU وتقليل استهلاكها لموارد النظام المحدودة مثل واصفات الملفات. تسمح بيانات الحزمة أيضًا بتوزيع التطبيقات مع عدد أقل من ملفات الموارد، أو حتى بدونها على الإطلاق إذا كانت ترتبط مباشرة بالبيانات المعبأة.

يدعم pkgdata عددًا قليلاً من طرق التعبئة المختلفة التي تخدم أغراضًا مختلفة.

وضع التعبئة الافتراضي هو common، أو archive. في هذا الوضع، يتم تجميع ملفات البيانات المختلفة معًا كملف يعتمد على البنية (architecture-dependent) يمكن لاحقًا تعيينه في الذاكرة (memory mapped) للاستخدام بواسطة ICU. سيتم البحث عن البيانات المعبأة باستخدام هذا الوضع ضمن دليل بيانات ICU. هذه التعبئة سهلة الاستخدام لحزم موارد التطبيقات، على سبيل المثال، طالما أن التطبيق يمكنه تثبيت الملف المعبأ في دليل بيانات ICU.

وضع التعبئة الآخر هو وضع dll، أو library، حيث يتم تجميع ملفات البيانات في مكتبة مشتركة. كان ICU قادرًا على تحميل هذه المكتبات المشتركة ديناميكيًا، ولكن اعتبارًا من ICU 2.0، تمت إزالة هذا الدعم. لا يزال هذا الوضع مفيدًا لغرضين رئيسيين: بناء ICU نفسه، حيث يتم تعبئة بيانات ICU كمكتبة مشتركة بشكل افتراضي؛ وبناء حزم موارد مرتبطة بالتطبيق الذي يستخدمها. يمكن بعد ذلك وضع هذه الحزم الموارد في أي مكان يبحث فيه محمل الروابط الديناميكي للنظام عن المكتبات المشتركة، بدلاً من إجبارها على العيش داخل دليل بيانات ICU.

وضع التعبئة static مشابه لوضع المكتبة المشتركة باستثناء أنه ينتج مكتبة ثابتة.

أخيرًا، يدعم pkgdata وضع files الذي يقوم ببساطة بنسخ ملفات البيانات بدلاً من تعبئتها كملف واحد أو مكتبة. هذا الوضع مخصص بشكل أساسي لتوفير الدعم لبناء ICU قبل تعبئته كحزم صغيرة منفصلة للتوزيع مع أنظمة التشغيل مثل Debian GNU/Linux على سبيل المثال. يرجى الرجوع إلى وثائق التعبئة في توزيعة مصدر ICU لمزيد من المعلومات حول استخدام هذا الوضع.

يقوم pkgdata ببناء، وتعبئة، وتثبيت، أو تنظيف البيانات المناسبة بناءً على الخيارات المعطاة دون الحاجة إلى استدعاء GNU make بعد الآن.

الخيارات

-h, -?, --help
طباعة المساعدة حول الاستخدام والخروج.
-v, --verbose
عرض رسائل إضافية مفيدة أثناء التنفيذ.
-c, --copyright
تضمين إشعار حقوق النشر في البيانات الثنائية.
-C, --comment تعليق
يتضمن التعليق المحدد في البيانات الناتجة بدلاً من إشعار حقوق النشر لـ ICU.
-m, --mode وضع
تعيين وضع التعبئة الذي سيستخدمه pkgdata. تم شرح الأوضاع المختلفة ومعناها في قسم الوصف أعلاه. أسماء الأوضاع الصالحة هي common (أو archive)، dll (أو library)، و files.
-O, --bldopt خيارات
تحديد الخيارات للباني. يستخدم الباني داخليًا بواسطة pkgdata لتوليد ملف الحزمة الصحيح. تشمل هذه الخيارات، على سبيل المثال لا الحصر، تعيين المتغيرات المستخدمة بواسطة make(1) أثناء بناء الملف المعبأ. ملاحظة: إذا كان icu-config متاحًا، فلن تكون هذا الخيار ضروريًا.
-p, --name اسم
تعيين اسم الملف المعبأ إلى اسم. يستخدم هذا الاسم أيضًا كاسم نقطة دخول افتراضية بعد تحويله إلى معرف C صالح.
-e, --entrypoint اسم
تعيين نقطة دخول البيانات (تستخدم للربط بالبيانات في شكل مكتبة مشتركة) إلى اسم. اسم نقطة الدخول الافتراضي هو الاسم المحدد بواسطة الخيار -n, --name.
-r, --revision إصدار
تمكين ترقيم إصدارات المكتبة المشتركة المنتجة في وضع dll، أو library. رقم الإصدار له التنسيق major.minor.patchlevel وجميع الأجزاء باستثناء major اختيارية. إذا تم توفير major فقط، فسيتم افتراض الإصدار لغرض الترقيم على أنه major.0.
-F, --rebuild
فرض إعادة بناء جميع البيانات وإعادة تعبئتها.
-I, --install
تثبيت الملف المعبأ (أو جميع الملفات في وضع files). إذا تم تعيين المتغير DESTDIR، فسيتم استخدامه للتثبيت.
-s, --sourcedir مصدر
تعيين دليل المصدر إلى مصدر. دليل المصدر الافتراضي هو الدليل الحالي.
-d, --destdir وجهة
تعيين دليل الوجهة إلى وجهة. دليل الوجهة الافتراضي هو الدليل الحالي.
-T, --tempdir دليل
تعيين الدليل المستخدم لإنشاء الملفات المؤقتة إلى دليل. الدليل المؤقت الافتراضي هو نفس دليل الوجهة كما هو محدد بواسطة الخيار -d, --destdir.

    NAME

    pkgdata - get package data

    SYNOPSIS

    pkgdata [options] [package]...

    DESCRIPTION

    pkgdata is a utility that retrieves various pieces of information about installed Arch Linux packages.

    It can display metadata such as package name, version, description, dependencies, maintainer, license, and more.

    If no package is specified, pkgdata will attempt to retrieve information for all installed packages.

    OPTIONS

    -n, --name
    Display the package name.
    -v, --version
    Display the package version.
    -d, --description
    Display the package description.
    -D, --depends
    Display the package dependencies.
    -M, --maintainer
    Display the package maintainer.
    -L, --license
    Display the package license.
    -h, --help
    Display help message and exit.
    -a, --all
    Display all available information for the specified package(s).

    AUTHORS

    The original implementation was likely part of the Arch Linux packaging tools.

    Current maintainers can be found in the Arch Linux package metadata.
