PkgConfig__LibPkgConf__Fragment(3pm)

الحزمة: perl-pkgconfig-libpkgconf

التراخيص: Artistic-1.0-Perl OR GPL-1.0-or-later

PkgConfig::LibPkgConf::Fragment(3) وثائق Perl مقدمة من المستخدم PkgConfig::LibPkgConf::Fragment(3)

الاسم

PkgConfig::LibPkgConf::Fragment - علامة واحدة للمترجم أو الرابط

ملخص

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->scan_all(sub {
  my($client, $package) = @_;
  # $package isa PkgConfig::LibPkgConf::Package
  foreach my $frag ($package->list_libs)
  {
    # $frag isa PkgConfig::LibPkgConf::Fragment
    if($frag->type eq 'L')
    {
      say "مسار المكتبة: ", $frag->data;
    }
    elsif($frag->type eq 'l')
    {
      say "اسم المكتبة: ", $frag->data;
    }
  }
});

النوع

my $type = $frag->type;

نوع العلامة. قد يكون "undef" إذا لم يكن هناك نوع.

البيانات

my $data = $frag->data;

بيانات الجزء.

إلى_سلسلة

my $string = $frag->to_string;
my $string = "$frag";

التمثيل النصي للجزء. يمكنك أيضًا تضمين كائن الجزء داخل سلسلة لتحويله إلى سلسلة.
