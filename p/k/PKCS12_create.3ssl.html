PKCS12_CREATE(3ssl) OpenSSL PKCS12_CREATE(3ssl)

الاسم

PKCS12_create, PKCS12_create_ex, PKCS12_create_cb, PKCS12_create_ex2 - إنشاء بنية PKCS#12

ملخص

 #include <openssl/pkcs12.h>
 PKCS12 *PKCS12_create(const char *pass, const char *name, EVP_PKEY *pkey,
                       X509 *cert, STACK_OF(X509) *ca,
                       int nid_key, int nid_cert, int iter, int mac_iter, int keytype);
 PKCS12 *PKCS12_create_ex(const char *pass, const char *name, EVP_PKEY *pkey,
                          X509 *cert, STACK_OF(X509) *ca, int nid_key, int nid_cert,
                          int iter, int mac_iter, int keytype,
                          OSSL_LIB_CTX *ctx, const char *propq);
 typedef int PKCS12_create_cb(PKCS12_SAFEBAG *bag, void *cbarg);
 PKCS12 *PKCS12_create_ex2(const char *pass, const char *name, EVP_PKEY *pkey,
                           X509 *cert, STACK_OF(X509) *ca, int nid_key, int nid_cert,
                           int iter, int mac_iter, int keytype,
                           OSSL_LIB_CTX *ctx, const char *propq,
                           PKCS12_create_cb *cb, void *cbarg);
=head1 DESCRIPTION

PKCS12_create() تنشئ بنية PKCS#12.

pass هي عبارة المرور المراد استخدامها. name هو friendlyName المراد استخدامه للشهادة والمفتاح المقدمين. pkey هو المفتاح الخاص المراد تضمينه في البنية و cert الشهادات المقابلة له. ca، إذا لم تكن NULL، هي مجموعة اختيارية من الشهادات المراد تضمينها أيضًا في البنية.

nid_key و nid_cert هما خوارزميات التشفير التي ينبغي استخدامها للمفتاح والشهادة على التوالي. الأوضاع GCM، CCM، XTS، و OCB غير مدعومة. iter هو عدد تكرارات خوارزمية التشفير المراد استخدامه و mac_iter هو عدد تكرارات MAC المراد استخدامه. keytype هو نوع المفتاح.

PKCS12_create_ex() مطابق لـ PKCS12_create() ولكن يسمح باستخدام سياق مكتبة ctx واستعلام خاصية propq لتحديد تطبيقات الخوارزميات.

PKCS12_create_ex2() مطابق لـ PKCS12_create_ex() ولكنه يسمح بتحديد دالة رد اتصال معرفة من قبل المستخدم cb من نوع PKCS12_create_cb ويسمح أيضًا بتمرير وسيط اختياري cbarg إلى دالة رد الاتصال.

سيتم استدعاء cb إذا تم تحديده لكل حقيبة آمنة (safebag) تتم إضافتها إلى بنية PKCS12 ويسمح بمعالجة اختيارية من التطبيق على الحقيبة الآمنة المرتبطة. على سبيل المثال، يمكن أن يكون أحد هذه الاستخدامات إضافة سمات إلى الحقيبة الآمنة.

ملاحظات

يمكن تعيين المعلمات nid_key، nid_cert، iter، mac_iter و keytype جميعها إلى الصفر وسيتم استخدام القيم الافتراضية المعقولة.

هذه القيم الافتراضية هي: تشفير AES المستند إلى كلمة المرور (PBES2 مع PBKDF2 و AES-256-CBC) للمفاتيح الخاصة والشهادات، عدد تكرارات اشتقاق مفتاح PBKDF2 و MAC وهو PKCS12_DEFAULT_ITER (حاليا 2048)، وخوارزمية MAC هي HMAC مع SHA2-256. خوارزمية اشتقاق مفتاح MAC المستخدمة لبنية PKCS#12 الخارجية هي PKCS12KDF.

العدد الافتراضي لتكرارات MAC هو 1 للحفاظ على التوافق مع البرامج القديمة التي لم تفسر عدد تكرارات MAC. إذا لم تكن هناك حاجة لهذا التوافق، فيجب تعيين mac_iter إلى PKCS12_DEFAULT_ITER.

keytype يضيف علامة لتخزين المفتاح الخاص. هذا امتداد غير قياسي يتم تفسيره حاليًا بواسطة MSIE فقط. إذا تم تعيينه إلى الصفر، يتم حذف العلامة، وإذا تم تعيينه إلى KEY_SIG، يمكن استخدام المفتاح للتوقيع فقط، وإذا تم تعيينه إلى KEY_EX، يمكن استخدامه للتوقيع والتشفير. كان هذا الخيار مفيدًا لبرامج التصدير القديمة التي يمكنها استخدام مفاتيح التوقيع فقط بأحجام عشوائية ولكن كان لديها قيود على الأحجام المسموح بها للمفاتيح التي يمكن استخدامها للتشفير.

إذا كان name هو NULL وكانت cert تحتوي على alias، فسيتم استخدام ذلك لـ friendlyName المقابل في بنية PKCS12 بدلاً من ذلك. وبالمثل، إذا كان pkey هو NULL وكانت cert تحتوي على keyid، فسيتم استخدام ذلك لـ localKeyID المقابل في بنية PKCS12 بدلاً من المعرف المحسوب من pkey.

بالنسبة لجميع الشهادات في ca، إذا كانت الشهادة تحتوي على alias أو keyid، فسيتم استخدام ذلك لـ friendlyName أو localKeyID المقابل في بنية PKCS12.

يمكن أن يكون pkey أو cert أو كليهما NULL للإشارة إلى عدم الحاجة إلى مفتاح أو شهادة. في الإصدارات السابقة، كان يجب أن يكون كلاهما موجودين أو يتم إرجاع خطأ فادح.

يمكن تعيين nid_key أو nid_cert إلى -1 للإشارة إلى عدم استخدام التشفير.

يمكن تعيين mac_iter إلى -1 ومن ثم سيتم حذف MAC بالكامل. يمكن أن يكون هذا مفيدًا عند التشغيل مع موفر FIPS لأن PKCS12KDF ليس خوارزمية معتمدة من FIPS.

PKCS12_create() تفترض ترميز عبارة المرور المقدمة. انظر passphrase-encoding(7) لمزيد من المعلومات.

إذا تم تحديد cb، فيجب أن تعود بـ 1 للنجاح و -1 لخطأ فادح. العودة بـ 0 مخصصة لعدم إضافة الحقيبة في النهاية.

قيم الإرجاع

PKCS12_create() تعيد بنية PKCS12 صالحة أو NULL إذا حدث خطأ.

تاريخ

PKCS12_create_ex() تمت إضافتها في OpenSSL 3.0. PKCS12_create_ex2() تمت إضافتها في OpenSSL 3.2.

تم تغيير القيم الافتراضية لخوارزميات التشفير وخوارزمية MAC وعدد تكرارات اشتقاق مفتاح MAC في OpenSSL 3.0 لتصبح معايير أكثر حداثة.
