PKCS12_item_decrypt_d2i(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_ITEM_DECRYPT_D2I(3ssl) OpenSSL PKCS12_ITEM_DECRYPT_D2I(3ssl)

الاسم

PKCS12_item_decrypt_d2i, PKCS12_item_decrypt_d2i_ex, PKCS12_item_i2d_encrypt, PKCS12_item_i2d_encrypt_ex - وظائف تشفير/فك تشفير عناصر PKCS12

الموجز

#include <openssl/pkcs12.h>
void *PKCS12_item_decrypt_d2i(const X509_ALGOR *algor, const ASN1_ITEM *it,
                              const char *pass, int passlen,
                              const ASN1_OCTET_STRING *oct, int zbuf);
void *PKCS12_item_decrypt_d2i_ex(const X509_ALGOR *algor, const ASN1_ITEM *it,
                                 const char *pass, int passlen,
                                 const ASN1_OCTET_STRING *oct, int zbuf,
                                 OSSL_LIB_CTX *libctx,
                                 const char *propq);
ASN1_OCTET_STRING *PKCS12_item_i2d_encrypt(X509_ALGOR *algor,
                                           const ASN1_ITEM *it,
                                           const char *pass, int passlen,
                                           void *obj, int zbuf);
ASN1_OCTET_STRING *PKCS12_item_i2d_encrypt_ex(X509_ALGOR *algor,
                                              const ASN1_ITEM *it,
                                              const char *pass, int passlen,
                                              void *obj, int zbuf,
                                              OSSL_LIB_CTX *ctx,
                                              const char *propq);

الوصف

PKCS12_item_decrypt_d2i() و PKCS12_item_decrypt_d2i_ex() تقوم بفك تشفير سلسلة البايتات التي تحتوي على كائن مرمّز بتنسيق ASN.1 باستخدام الخوارزمية algor وكلمة المرور pass بطول passlen. إذا كانت zbuf غير صفرية، فسيتم مسح المخزن المؤقت للإخراج بعد فك التشفير.

PKCS12_item_i2d_encrypt() و PKCS12_item_i2d_encrypt_ex() تقوم بتشفير كائن ASN.1 it باستخدام الخوارزمية algor وكلمة المرور pass بطول passlen، مع إرجاع كائن مرمّز في obj. إذا كانت zbuf غير صفرية، فسيتم مسح المخزن المؤقت الذي يحتوي على ترميز الإدخال بعد التشفير.

الوظائف التي تنتهي بـ _ex() تسمح باستخدام سياق المكتبة ctx واستعلام الخصائص propq لاختيار تطبيقات الخوارزميات.

قيم الإرجاع

PKCS12_item_decrypt_d2i() و PKCS12_item_decrypt_d2i_ex() ترجع الكائن الذي تم فك تشفيره أو NULL إذا حدث خطأ.

PKCS12_item_i2d_encrypt() و PKCS12_item_i2d_encrypt_ex() ترجع البيانات المشفرة كسلسلة بايتات ASN.1 أو NULL إذا حدث خطأ.

انظر أيضًا
