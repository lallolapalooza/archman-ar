PKCS12_gen_mac(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_GEN_MAC(3ssl) OpenSSL PKCS12_GEN_MAC(3ssl)

الاسم

PKCS12_gen_mac, PKCS12_setup_mac, PKCS12_set_mac, PKCS12_set_pbmac1_pbkdf2, PKCS12_verify_mac, PKCS12_get0_mac - وظائف لإنشاء ومعالجة بنية PKCS#12 MAC

الملخص

#include <openssl/pkcs12.h>
int PKCS12_gen_mac(PKCS12 *p12, const char *pass, int passlen,
                   unsigned char *mac, unsigned int *maclen);
int PKCS12_verify_mac(PKCS12 *p12, const char *pass, int passlen);
int PKCS12_set_mac(PKCS12 *p12, const char *pass, int passlen,
                   unsigned char *salt, int saltlen, int iter,
                   const EVP_MD *md_type);
int PKCS12_set_pbmac1_pbkdf2(PKCS12 *p12, const char *pass, int passlen,
                                  unsigned char *salt, int saltlen, int iter,
                                  const EVP_MD *md_type,
                                  const char *prf_md_name);
int PKCS12_setup_mac(PKCS12 *p12, int iter, unsigned char *salt,
                     int saltlen, const EVP_MD *md_type);
void PKCS12_get0_mac(const ASN1_OCTET_STRING **pmac,
                     const X509_ALGOR **pmacalg,
                     const ASN1_OCTET_STRING **psalt,
                     const ASN1_INTEGER **piter,
                     const PKCS12 *p12);

الوصف

تقوم PKCS12_gen_mac() بإنشاء HMAC على كائن PKCS#12 بأكمله باستخدام كلمة المرور المقدمة جنبًا إلى جنب مع مجموعة من المعلمات المكوّنة بالفعل. آلية توليد المفاتيح الافتراضية المستخدمة هي PKCS12KDF.

تقوم PKCS12_verify_mac() بالتحقق من HMAC لكائن PKCS#12 باستخدام كلمة المرور المقدمة.

تقوم PKCS12_setup_mac() بتعيين جزء MAC لهيكل PKCS#12 بالمعلمات المقدمة.

تقوم PKCS12_set_mac() بتعيين MAC ومعلمات MAC في كائن PKCS#12. تقوم PKCS12_set_pbmac1_pbkdf2() بتعيين MAC ومعلمات MAC في كائن PKCS#12 عند استخدام PBMAC1 مع PBKDF2 لحماية كائن PKCS#12.

pass هي عبارة المرور المراد استخدامها في HMAC. salt هي قيمة الملح المراد استخدامها، iter هو عدد التكرارات و md_type هي دالة تلخيص الرسالة المراد استخدامها. prf_md_name تحدد التلخيص المستخدم لـ PBKDF2 في PBMAC1 KDF.

تقوم PKCS12_get0_mac() باسترداد أي قيمة MAC مضمنة، كائن X509_ALGOR، salt، وعدد iter من كائن PKCS12.

ملاحظات

إذا كان salt هو NULL، فسيتم إنشاء واستخدام ملح مناسب.

إذا كان iter هو 1، فسيتم حذف عدد التكرارات من بنية PKCS#12.

تقوم PKCS12_gen_mac()، PKCS12_verify_mac()، PKCS12_set_mac() و PKCS12_set_pbmac1_pbkdf2() بعمل افتراضات بشأن ترميز عبارة المرور المعطاة. انظر passphrase-encoding(7) لمزيد من المعلومات.

قيم الإرجاع

جميع الدوال التي ترجع عددًا صحيحًا ترجع 1 عند النجاح و 0 إذا حدث خطأ.

البيئة

LEGACY_GOST_PKCS12
إذا تم تعيين متغير البيئة هذا، فسيتم إجراء توليد MAC الذي يستخدم خوارزميات التجزئة GOST R 34.11-94 أو GOST 34.11-2012 بالطريقة المعتادة وليس وفقًا للمواصفات المقدمة في التوصية المنهجية MP 26.2.002-2012 (أو في إصداراتها اللاحقة، توصية التوحيد القياسي P 50.1.112-2016 أو P 1323565.1.041-2022) للجنة التقنية 26، والتي تنص على أن المفتاح المستخدم لتوليد MAC يجب أن يكون آخر 32 بايت من التسلسل المكون من 96 بايت والذي تم إنشاؤه بواسطة PKCS5_PBKDF2_HMAC(3) وليس التسلسل بأكمله.
