PkgConfig__LibPkgConf__Package(3pm)

الحزمة: perl-pkgconfig-libpkgconf

التراخيص: Artistic-1.0-Perl OR GPL-1.0-or-later

PkgConfig::LibPkgConf::Package(3) وثائق بيرل من مساهمات المستخدم PkgConfig::LibPkgConf::Package(3)

الاسم

PkgConfig::LibPkgConf::Package - يمثل حزمة

الملخص

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;
$client->env;

my $pkg = $client->find('libarchive');

# الاستخدام مع system في شكل عددي:
my $cflags = $pkg->cflags;
my $libs = $pkg->libs;
system "$cc $cflags foo.c";
system "$cc -o foo foo.o $libs";

# الاستخدام مع system في شكل قائمة:
my @cflags = $pkg->list_cflags;
my @libs   = $pkg->list_libs;
system $cc, @cflags, 'foo.c';
system $cc, -p => 'foo', 'foo.o', @libs;

الوصف

يخزن كائن PkgConfig::LibPkgConf::Package معلومات الحزمة. جزء من معلومات الحزمة هو المترجم وموصل الأعلام (flags). يمكن استرداد هذا كسلاسل نصية باستخدام "cflags" و "libs" وكقائمة باستخدام "list_cflags" و "list_libs". في الشكل النصي، يتم الاحتفاظ بالهروب (escapes)، ولكن في شكل القائمة، يتم تحويل الهروب من المسافات البيضاء إلى مسافات. هذا يعني أنه إذا كنت تستخدم الشكل النصي لـ "system"/"exec"، يجب عليك استخدام الملحقات النصية، وإذا كنت تستخدم شكل القائمة لـ "system"/"exec"، يجب عليك استخدام ملحقات القائمة.

الطرق

libs

أعلام المكتبة. يتضمن هذا عادةً أشياء مثل "-L/foo/lib" و "-lfoo".

libs_static

أعلام المكتبة الثابتة.

cflags

أعلام المترجم. يتضمن هذا عادةً أشياء مثل "-I/foo/include" و "-DFOO=1".

cflags_static

أعلام المترجم الثابتة.

list_libs

my @fragments = $package->list_libs;

أعلام المكتبة كقائمة من الأجزاء (fragments) PkgConfig::LibPkgConf::Fragment. هذا مشابه للطريقة "libs" أعلاه، ولكن نظرًا لأنها تُرجع قائمة بدلاً من سلسلة نصية واحدة، يمكن استخدامها لتصفية الأعلام المحددة. على سبيل المثال:

# يعادل pkgconf --libs-only-L
my @lib_dirs = grep { $_->type eq 'L' } $package->list_libs;
# يعادل pkgconf --libs-only-l
my @libs = grep { $_->type eq 'l' } $package->list_libs;

list_libs_static

my @fragments = $package->list_libs_static;

مشابه لـ "list_libs"، ولكن لأعلام المكتبات الثابتة.

list_cflags

my @fragments = $package->list_cflags;

أعلام المترجم كقائمة من الأجزاء (fragments) PkgConfig::LibPkgConf::Fragment. هذا مشابه للطريقة "cflags" أعلاه، ولكن نظرًا لأنها تُرجع قائمة بدلاً من سلسلة نصية واحدة، يمكن استخدامها لتصفية الأعلام المحددة. على سبيل المثال:

# يعادل pkgconf --cflags-only-I
my @include_dirs = grep { $_->type eq 'I' } $package->list_cflags;
# يعادل pkgconf --cflags-only-other
my @other_cflags = grep { $_->type ne 'I' } $package->list_cflags;

list_cflags_static

my @fragments = $package->list_cflags_static;

مشابه لـ "list_cflags"، ولكن لأعلام المترجم الثابتة.

variable

my $value = $package->variable($key);

ابحث عن قيمة المفتاح المحدد. تُرجع القيمة إذا تم العثور عليها، وإلا فإنها تُرجع undef (فنيًا قائمة فارغة).
