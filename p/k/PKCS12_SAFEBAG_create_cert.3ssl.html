PKCS12_SAFEBAG_create_cert(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_SAFEBAG_CREATE_CERT(3ssl) OpenSSL PKCS12_SAFEBAG_CREATE_CERT(3ssl)

الاسم

PKCS12_SAFEBAG_CREATE_CERT, PKCS12_SAFEBAG_CREATE_CRL, PKCS12_SAFEBAG_CREATE_SECRET, PKCS12_SAFEBAG_CREATE0_P8INF, PKCS12_SAFEBAG_CREATE0_PKCS8, PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT, PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT_EX - إنشاء كائنات PKCS#12 safeBag

الملخص

#include <openssl/pkcs12.h>
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE_CERT(X509 *x509);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE_CRL(X509_CRL *crl);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE_SECRET(int type, int vtype,
                                             const unsigned char* value,
                                             int len);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE0_P8INF(PKCS8_PRIV_KEY_INFO *p8);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE0_PKCS8(X509_SIG *p8);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT(int pbe_nid,
                                                    const char *pass,
                                                    int passlen,
                                                    unsigned char *salt,
                                                    int saltlen, int iter,
                                                    PKCS8_PRIV_KEY_INFO *p8inf);
PKCS12_SAFEBAG *PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT_EX(int pbe_nid,
                                                       const char *pass,
                                                       int passlen,
                                                       unsigned char *salt,
                                                       int saltlen, int iter,
                                                       PKCS8_PRIV_KEY_INFO *p8inf,
                                                       OSSL_LIB_CTX *ctx,
                                                       const char *propq);

الوصف

PKCS12_SAFEBAG_CREATE_CERT() تنشئ PKCS12_SAFEBAG جديد من نوع NID_certBag يحتوي على الشهادة المزودة.

PKCS12_SAFEBAG_CREATE_CRL() تنشئ PKCS12_SAFEBAG جديد من نوع NID_crlBag يحتوي على قائمة إلغاء الشهادات (crl) المزودة.

PKCS12_SAFEBAG_CREATE_SECRET() تنشئ PKCS12_SAFEBAG جديد من نوع يتوافق مع secretBag الخاص بـ PKCS#12. يتم تمييز محتويات secretBag بالمعرف type بقيمة ASN1 من النوع vtype تم بناؤها باستخدام البايتات الموجودة في value بطول len.

PKCS12_SAFEBAG_CREATE0_P8INF() تنشئ PKCS12_SAFEBAG جديد من نوع NID_keyBag يحتوي على بنية PKCS8 المزودة.

PKCS12_SAFEBAG_CREATE0_PKCS8() تنشئ PKCS12_SAFEBAG جديد من نوع NID_pkcs8ShroudedKeyBag يحتوي على بنية PKCS8 المزودة.

PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT() تنشئ PKCS12_SAFEBAG جديد من نوع NID_pkcs8ShroudedKeyBag عن طريق تشفير بنية PKCS8 p8inf المزودة. إذا كان pbe_nid يساوي 0، يتم استخدام خوارزمية تشفير افتراضية. pass هي عبارة المرور و iter هو عدد التكرارات. إذا كان iter يساوي صفرًا، يتم استخدام القيمة الافتراضية 2048. إذا كان salt يساوي NULL، يتم إنشاء قيمة عشوائية للملح.

PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT_EX() مطابقة لـ PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT() ولكنها تسمح باستخدام سياق مكتبة ctx واستعلام الخصائص propq لاختيار تطبيقات الخوارزميات.

ملاحظات

PKCS12_SAFEBAG_CREATE_PKCS8_ENCRYPT() تفترض فيما يتعلق بترميز عبارة المرور المقدمة. راجع passphrase-encoding(7) لمزيد من المعلومات.

تمت إضافة PKCS12_SAFEBAG_CREATE_SECRET() في OpenSSL 3.0.

قيم الإرجاع

جميع هذه الوظائف ترجع بنية PKCS12_SAFEBAG صالحة أو NULL في حالة حدوث خطأ.
