PKCS12_key_gen_utf8_ex(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_KEY_GEN_UTF8_EX(3ssl) OpenSSL PKCS12_KEY_GEN_UTF8_EX(3ssl)

الاسم

PKCS12_key_gen_asc, PKCS12_key_gen_asc_ex, PKCS12_key_gen_uni, PKCS12_key_gen_uni_ex, PKCS12_key_gen_utf8, PKCS12_key_gen_utf8_ex - توليد مفتاح PKCS#12 قائم على كلمة المرور

الملخص

#include <openssl/pkcs12.h>
int PKCS12_key_gen_asc(const char *pass, int passlen, unsigned char *salt,
                       int saltlen, int id, int iter, int n,
                       unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_asc_ex(const char *pass, int passlen, unsigned char *salt,
                          int saltlen, int id, int iter, int n,
                          unsigned char *out, const EVP_MD *md_type,
                          OSSL_LIB_CTX *ctx, const char *propq);
int PKCS12_key_gen_uni(unsigned char *pass, int passlen, unsigned char *salt,
                       int saltlen, int id, int iter, int n,
                       unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_uni_ex(unsigned char *pass, int passlen, unsigned char *salt,
                          int saltlen, int id, int iter, int n,
                          unsigned char *out, const EVP_MD *md_type,
                          OSSL_LIB_CTX *ctx, const char *propq);
int PKCS12_key_gen_utf8(const char *pass, int passlen, unsigned char *salt,
                        int saltlen, int id, int iter, int n,
                        unsigned char *out, const EVP_MD *md_type);
int PKCS12_key_gen_utf8_ex(const char *pass, int passlen, unsigned char *salt,
                           int saltlen, int id, int iter, int n,
                           unsigned char *out, const EVP_MD *md_type,
                           OSSL_LIB_CTX *ctx, const char *propq);

الوصف

تقوم هذه الطرق بتوليد مفتاح وفقًا لـ PKCS#12 (RFC7292) باستخدام كلمة مرور إدخال pass بطول passlen، وملح salt بطول saltlen، وعدد تكرارات iter وخوارزمية تلخيص md_type. يحدد بايت المعرّف id كيفية استخدام المفتاح الناتج:

  • إذا كان المعرّف = 1، فإن البتات شبه العشوائية التي يتم إنتاجها ستُستخدم كمادة مفتاح لإجراء التشفير أو فك التشفير.
  • إذا كان المعرّف = 2، فإن البتات شبه العشوائية التي يتم إنتاجها ستُستخدم كـ IV (قيمة أولية) للتشفير أو فك التشفير.
  • إذا كان المعرّف = 3، فإن البتات شبه العشوائية التي يتم إنتاجها ستُستخدم كمفتاح تكامل لـ MAC.

يتم تحديد تنسيق كلمة المرور المدخلة بواسطة الطريقة المختارة:

  • PKCS12_key_gen_asc() و PKCS12_key_gen_asc_ex() تتوقعان كلمة مرور بتنسيق ASCII.
  • PKCS12_key_gen_uni() و PKCS12_key_gen_uni_ex() تتوقعان كلمة مرور بتنسيق Unicode.
  • PKCS12_key_gen_utf8() و PKCS12_key_gen_utf8_ex() تتوقعان كلمة مرور مشفرة بـ UTF-8.

pass هي كلمة المرور المستخدمة في التوليد بطول passlen. pass هو معلمة اختيارية ويمكن أن يكون NULL. إذا كان passlen هو -1، فستقوم الدالة بحساب طول pass باستخدام strlen().

salt هو الملح المستخدم في التوليد بطول saltlen. إذا كان salt هو NULL، فيجب أن يكون saltlen 0. لن تحاول الدالة حساب طول salt لأنه ليس من المفترض أن يكون منتهيًا بـ NULL.

iter هو عدد التكرارات ويجب أن تكون قيمته أكبر من أو تساوي 1. تقترح RFC 2898 عدد تكرارات لا يقل عن 1000. أي iter أقل من 1 يتم التعامل معه كتكرار واحد.

digest هي وظيفة تلخيص الرسالة المستخدمة في التوليد.

سيتم كتابة المفتاح المشتق في out. يتم تحديد حجم المخزن المؤقت out عبر n.

تسمح الدوال التي تنتهي بـ _ex() باستخدام سياق مكتبة ctx واستعلام خاصية propq لاختيار تطبيقات الخوارزميات.

ملاحظات

يعد التطبيق النموذجي لهذه الدالة هو توليد مواد مفتاح لخوارزمية تشفير من كلمة مرور في pass، وملح في salt، وعدد تكرارات.

زيادة المعلمة iter تبطئ الخوارزمية مما يجعل من الصعب على المهاجم إجراء هجوم القوة الغاشمة باستخدام عدد كبير من كلمات المرور المرشحة.

قيم الإرجاع

تعيد 1 عند النجاح أو 0 عند الخطأ.
