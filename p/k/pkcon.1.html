PKCON(1) أوامر المستخدم PKCON(1)

الاسم

pkcon - عميل سطر الأوامر لـ PackageKit

الملخص

pkcon [خيار...] [أمر]

الوصف

توضح صفحة الدليل هذه بإيجاز أمر pkcon.

pkcon هو عميل سطر الأوامر لـ PackageKit.

الأوامر

يعرف pkcon الأوامر التالية. اعتمادًا على الواجهة الخلفية المستخدمة، قد لا يكون بعضها متاحًا.

backend-details

طباعة معلومات حول الواجهة الخلفية PackageKit المستخدمة.

get-roles

قائمة الأدوار التي يمكن أن يمتلكها المعاملة.

get-groups

قائمة مجموعات الحزم المتاحة.

get-filters

قائمة المرشحات المتاحة.

get-transactions

قائمة المعاملات المعروفة.

get-time ROLE

طباعة الوقت الذي مر منذ آخر معاملة بالدور المحدد.

search [name|details|group|file] DATA

البحث عن حزمة تطابق البيانات المعطاة. يتم البحث في معلومات الحزمة المشار إليها بالحجة الأولى: الاسم، التفاصيل، المجموعة، أو الملفات.

install PACKAGES

تثبيت الحزم المعطاة من المستودعات.

install-local FILES

تثبيت الحزم المعطاة من نظام الملفات المحلي.

download DIRECTORY PACKAGES

تنزيل الحزم المعطاة من المستودعات، وتخزينها في الدليل المحدد.

install-sig TYPE KEY_ID PACKAGE

تثبيت توقيع حزمة. يتم دعم توقيعات GPG فقط في الوقت الحالي.

remove PACKAGE

إزالة الحزمة المعطاة.

update [PACKAGES]

تحديث النظام عن طريق تثبيت التحديثات المتاحة. إذا تم تحديد قائمة بالحزم، فقم بتثبيت التحديثات لهذه الحزم فقط.

refresh [force]

تحديث المعلومات المخزنة مؤقتًا حول التحديثات المتاحة.

resolve PACKAGE

حل اسم الحزمة المحدد وطباعة معلومات حول الحزم المثبتة أو المتاحة والتحديثات.

upgrade-system DISTRIBUTION [minimal|default|complete]

ترقية النظام إلى التوزيعة المعطاة.

get-updates

قائمة التحديثات المتاحة.

get-distro-upgrades

قائمة ترقيات التوزيعة المتاحة.

depends-on PACKAGE

قائمة التبعيات للحزمة المعطاة.

required-by PACKAGE

قائمة الحزم التي تتطلب الحزمة المعطاة.

get-details PACKAGE

طباعة تفاصيل حول الحزمة المتاحة أو المثبتة بالاسم المحدد.

get-details-local FILE

طباعة تفاصيل حول الحزمة المحلية.

get-files PACKAGE

قائمة الملفات الموجودة في الحزمة المعطاة.

get-files-local FILE

قائمة الملفات الموجودة في الحزمة المحلية.

get-update-detail PACKAGE

طباعة سجل تغييرات الحزمة للحزمة المعطاة.

get-packages

قائمة جميع الحزم المتاحة والمثبتة.

repo-list

قائمة جميع مستودعات الحزم المهيأة.

repo-enable REPOSITORY

تمكين المستودع المحدد.

repo-disable REPOSITORY

تعطيل المستودع المحدد.

repo-set-data REPOSITORY PARAMETER DATA

تعيين المعلمة المحددة إلى القيمة المحددة للمستودع.

repo-remove REPOSITORY PARAMETER

إزالة المستودع واختياريًا أي حزم مثبتة منه.

what-provides STRING

قائمة الحزم التي توفر السلسلة المعطاة.

accept-eula EULA_ID

قبول اتفاقية ترخيص المستخدم النهائي (EULA) بالمعرف المحدد.

get-categories

قائمة الفئات المتاحة.

repair

محاولة إصلاح قاعدة بيانات حزم النظام.

offline-get-prepared

طباعة معلومات حول تحديث غير متصل بالإنترنت تم إعداده. إذا لم يتم إعداد تحديث غير متصل بالإنترنت، فاخرج برمز خروج 1.

offline-trigger

تشغيل تحديث غير متصل بالإنترنت.

offline-status

طباعة معلومات حول نتيجة آخر تحديث غير متصل بالإنترنت.

الخيارات

يمكن استخدام الخيارات التالية للتأثير على سلوك pkcon.

--version

طباعة إصدار البرنامج والخروج.

-h, --help

عرض خيارات المساعدة.

--help-all

عرض جميع خيارات المساعدة.

--filter FILTER

تعيين المرشح للاستخدام.

-y, --noninteractive

تثبيت الحزم دون طلب تأكيد.

--only-download

إعداد المعاملة عن طريق تنزيل الحزم فقط.

-n, --background

تشغيل الأمر باستخدام عرض النطاق الترددي الخامل للشبكة وأيضًا باستخدام طاقة أقل.

-p, --plain

طباعة مخرجات قابلة للقراءة آليًا إلى الشاشة، بدلاً من استخدام عناصر واجهة مستخدم متحركة.

-v, --verbose

إظهار معلومات التصحيح.

-c, --cache-age AGE

تعيين الحد الأقصى للعمر المقبول للبيانات الوصفية المخزنة مؤقتًا، بالثواني. استخدم -1 لـ 'أبدًا'.

--allow-untrusted

السماح بتثبيت الحزم غير الموثوق بها.

--allow-downgrade

السماح بخفض إصدار الحزم أثناء المعاملة.

--allow-reinstall

السماح بإعادة تثبيت الحزم أثناء المعاملة.

قيم الإرجاع

0

نجاح

1

فشل مع خطأ داخلي متنوع.

3

فشل مع خطأ في بناء الجملة، أو فشل في تحليل الأمر.

4

فشل لأنه لم يتم العثور على ملف أو دليل.

5

لم يتم القيام بأي شيء مفيد.

6

فشل الإعداد الأولي، على سبيل المثال، تعيين وكيل الشبكة.

7

فشلت المعاملة، راجع الخطأ المفصل لمزيد من المعلومات.

الاسم

pkcon - واجهة سطر الأوامر لـ PackageKit

الملخص

pkcon [options] [action]

الوصف

pkcon هي واجهة سطر أوامر لـ PackageKit، وهي طبقة مجردة لإدارة الحزم. تسمح لك بإجراء عمليات مختلفة تتعلق بالحزم مثل البحث والتثبيت والإزالة والتحديث.

الأوامر

  • search name: البحث عن الحزم التي تطابق name.
  • install package_name: تثبيت الحزمة package_name.
  • remove package_name: إزالة الحزمة package_name.
  • update: تحديث قائمة الحزم المتاحة.
  • upgrade: ترقية جميع الحزم المثبتة.
  • info package_name: عرض معلومات حول الحزمة package_name.
  • reinstall package_name: إعادة تثبيت الحزمة package_name.
  • lock package_name: قفل الحزمة package_name لمنع تثبيتها أو إزالتها.
  • unlock package_name: إلغاء قفل الحزمة package_name.
  • what-requires file_or_package: عرض الحزم التي تتطلب file_or_package.
  • changes-since date: عرض الحزم التي تغيرت منذ date.
  • history: عرض سجل العمليات.
  • get-updates: الحصول على قائمة التحديثات المتاحة.
  • get-details package_id: الحصول على تفاصيل الحزمة package_id.
  • get-description package_id: الحصول على وصف الحزمة package_id.
  • get-dependencies package_id: الحصول على تبعيات الحزمة package_id.
  • get-packages: الحصول على قائمة بجميع الحزم المثبتة.
  • get-remote-packages: الحصول على قائمة بجميع الحزم المتاحة من المستودعات البعيدة.
  • get-local-packages: الحصول على قائمة بجميع الحزم المثبتة محليًا.
  • get-all-updates: الحصول على قائمة بجميع التحديثات المتاحة.
  • get-installed-updates: الحصول على قائمة بالتحديثات للحزم المثبتة.
  • get-dist-tags: الحصول على قائمة بعلامات التوزيع المتاحة.
  • get-dist-tag-packages tag: الحصول على قائمة الحزم المرتبطة بعلامة التوزيع tag.
  • get-package-installed package_id: التحقق مما إذا كانت الحزمة package_id مثبتة.
  • get-package-available package_id: التحقق مما إذا كانت الحزمة package_id متاحة.
  • get-package-upgradable package_id: التحقق مما إذا كانت الحزمة package_id قابلة للترقية.
  • get-package-source package_id: الحصول على اسم حزمة المصدر للحزمة package_id.
  • quit: الخروج من pkcon.

الخيارات

  • -h, --help: عرض رسالة المساعدة والخروج.
  • -v, --version: عرض معلومات الإصدار والخروج.
  • --auto-agree-with-licenses: الموافقة تلقائيًا على جميع التراخيص.
  • --allow-change-held-packages: السماح بتغيير الحزم المحجوزة.
  • --allow-arch-change: السماح بتغيير البنية.
  • --allow-dependencies-change: السماح بتغيير التبعيات.
  • --allow-remove-essential: السماح بإزالة الحزم الأساسية.
  • --allow-unverified: السماح بتثبيت الحزم غير الموثقة.
  • --disable-system-upgrade: تعطيل ترقيات النظام.
  • --ignore-lock: تجاهل الأقفال.
  • --ignore-releasever: تجاهل إصدار الإصدار.
  • --ignore-package package: تجاهل الحزمة package.
  • --disable-excludes: تعطيل الاستثناءات.
  • --install-recommends: تثبيت الحزم الموصى بها.
  • --install-suggests: تثبيت الحزم المقترحة.
  • --download-only: تنزيل الحزم فقط دون تثبيتها.
  • --download-dir dir: تحديد الدليل لتنزيل الحزم.
  • --skip-broken: تخطي الحزم المعطوبة.
  • --with-new-pkgs: تثبيت الحزم الجديدة.
  • --only-upgrade: الترقية فقط.
  • --only-install: التثبيت فقط.
  • --only-remove: الإزالة فقط.
  • --no-autoremove: عدم إزالة التبعيات تلقائيًا.
  • --no-block: عدم حظر العمليات.
  • --no-progress: عدم عرض شريط التقدم.
  • --verbose: عرض معلومات مفصلة.
  • --debug: عرض معلومات التصحيح.
  • --log-file file: تحديد ملف السجل.
  • --log-level level: تحديد مستوى السجل.

قيم الإرجاع

تعود pkcon بقيمة 0 عند النجاح، و 1 عند الفشل.
