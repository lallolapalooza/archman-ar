class="permalink" href="#shared">--shared
حساب رسم بياني تبعية بسيط مناسب فقط للربط المشترك. هذا الخيار يتجاوز --static.
--short-errors
عند طباعة رسائل خطأ حول الوحدات التي لم يتم العثور عليها أو تتعارض مع بعضها البعض، تجنب طباعة تعليمات إضافية ومفصلة تشرح الأساليب المحتملة لحل المشكلة.
--silence-errors
لا تطبع أي رسائل خطأ أو تحذير أو تصحيح على الإطلاق. يتجاوز كل من --debug و --errors-to-stdout و --print-errors. يتم تجاوز هذا الخيار وتعطيله إذا تم تعيين متغير البيئة PKG_CONFIG_DEBUG_SPEW.
--simulate
يحاكي حل رسم بياني تبعية بناءً على الوحدات المطلوبة على سطر الأوامر. يفرغ سلسلة من الأشجار التي تمثل حالة محلل pkgconf. هذا الخيار متاح فقط إذا لم يتم تعريف ماكرو المعالج المسبق PKGCONF_LITE أثناء الترجمة.
--solution
يطبع أسماء الوحدات المطلوبة مع وسيطات module وتبعياتها إلى المخرج القياسي. هذا الخيار متاح فقط إذا لم يتم تعريف ماكرو المعالج المسبق PKGCONF_LITE أثناء الترجمة.
--static
حساب رسم بياني تبعية أعمق واستخدام علامات المترجم/الرابط المخصصة للربط الثابت. يتم تجاوز هذا الخيار بواسطة --shared.
--uninstalled
إنهاء بنتيجة غير صفرية إذا استخدم محلل التبعية وحدة "غير مثبتة" كجزء من حله.
--validate package ...
التحقق من صحة ملفات '.pc' محددة. هذا الخيار يعني --print-errors و --errors-to-stdout.
--variable=varname
بالنسبة للوحدة الأولى module المقدمة في سطر الأوامر، اطبع قيمة المتغير بالاسم varname إلى المخرج القياسي. يتم تجاهل أي وسيطات لاحقة بصمت. هذا الخيار يعني --maximum-traverse-depth=1 ويتجاوز ويعطل جميع علامات --cflags و --libs.
--verbose
لهذا الخيار تأثير فقط إذا تم تحديد --modversion أيضًا. يطبع اسم الوحدة module المقابلة ونقطتين قبل كل رقم إصدار.
--version
طباعة رقم إصدار برنامج pkgconf إلى المخرج القياسي والخروج. يتم تجاهل معظم الخيارات الأخرى وجميع وسيطات سطر الأوامر.
--with-path=path
إضافة الدليل path إلى بداية مسار البحث عن الوحدات، مما يعطيه الأولوية على جميع الدلائل الأخرى بما في ذلك تلك من PKG_CONFIG_PATH و PKG_CONFIG_LIBDIR.

البيئة

CPATH
قائمة إضافية أولى مفصولة بنقطتين لمسارات التضمين التي تم تصفيتها بنفس الطريقة مثل PKG_CONFIG_SYSTEM_INCLUDE_PATH.
CPLUS_INCLUDE_PATH
قائمة إضافية ثالثة مفصولة بنقطتين لمسارات التضمين التي تم تصفيتها بنفس الطريقة مثل PKG_CONFIG_SYSTEM_INCLUDE_PATH.
C_INCLUDE_PATH
قائمة إضافية ثانية مفصولة بنقطتين لمسارات التضمين التي تم تصفيتها بنفس الطريقة مثل PKG_CONFIG_SYSTEM_INCLUDE_PATH.
DESTDIR
إذا تم تعيينه على نفس القيمة مثل PKG_CONFIG_SYSROOT_DIR، فسيعمل بنفس الطريقة كما لو تم تعيين PKG_CONFIG_FDO_SYSROOT_RULES. إذا لم يتم تعيين PKG_CONFIG_SYSROOT_DIR أو تم تعيينه على قيمة مختلفة، يتم تجاهل DESTDIR.
LIBRARY_PATH
قائمة إضافية مفصولة بنقطتين لمسارات المكتبة التي تم تصفيتها بنفس الطريقة مثل PKG_CONFIG_SYSTEM_LIBRARY_PATH.
OBJC_INCLUDE_PATH
قائمة إضافية رابعة مفصولة بنقطتين لمسارات التضمين التي تم تصفيتها بنفس الطريقة مثل PKG_CONFIG_SYSTEM_INCLUDE_PATH.
PKG_CONFIG_ALLOW_SYSTEM_CFLAGS
إذا تم تعيينه، فإن هذا المتغير له نفس تأثير الخيار --keep-system-cflags.
PKG_CONFIG_ALLOW_SYSTEM_LIBS
إذا تم تعيينه، فإن هذا المتغير له نفس تأثير الخيار --keep-system-libs.
PKG_CONFIG_DEBUG_SPEW
إذا تم تعيينه، يتجاوز ويعطل الخيار --silence-errors.
PKG_CONFIG_DISABLE_UNINSTALLED
إذا تم تعيينه، فإنه يتيح نفس السلوك مثل العلامة --no-uninstalled.
PKG_CONFIG_DONT_DEFINE_PREFIX
إذا تم تعيينه، فإن هذا المتغير له نفس تأثير الخيار --dont-define-prefix.
PKG_CONFIG_DONT_RELOCATE_PATHS
إذا تم تعيينه، فإنه يعطل ميزة إعادة تحديد المسارات.
PKG_CONFIG_FDO_SYSROOT_RULES
إذا تم تعيينه، اتبع قواعد بادئة النظام الجذر التي يستخدمها pkg-config من freedesktop.org.
PKG_CONFIG_IGNORE_CONFLICTS
إذا تم تعيينه، تجاهل قواعد Conflicts في الوحدات. له نفس تأثير الخيار --ignore-conflicts.
PKG_CONFIG_LIBDIR
قائمة مفصولة بنقطتين لدلائل ذات أولوية منخفضة حيث يتم البحث عن ملفات pc(5). يتم إنشاء مسار البحث عن الوحدات عن طريق إلحاق هذه القائمة بـ PKG_CONFIG_PATH، والتي تتمتع بأولوية أعلى. إذا لم يتم تعريف PKG_CONFIG_LIBDIR، يتم إلحاق القائمة الافتراضية المترجمة في برنامج pkgconf من ماكرو المعالج المسبق PKG_DEFAULT_PATH بدلاً من ذلك. إذا تم تعريف PKG_CONFIG_LIBDIR ولكنها فارغة، فلن يتم إلحاق شيء.
PKG_CONFIG_LOG
إذا تم تعيينه، سجل معلومات حول الوحدات المحددة في الملف بالاسم المخزن في هذا المتغير. لمزيد من التفاصيل، انظر خيار سطر الأوامر --log-file، الذي يتجاوز هذا المتغير.
PKG_CONFIG_MAXIMUM_TRAVERSE_DEPTH
فرض حد على العمق المسموح به في رسم بياني التبعية. يتجاوز هذا المتغير الخيار --maximum-traverse-depth، ولكنه يتم تجاوزه بواسطة الخيارات الأخرى المذكورة هناك.
PKG_CONFIG_MSVC_SYNTAX
إذا تم تعيينه، استخدم بناء جملة MSVC لمخرج --cflags و --env و --libs. لهذا المتغير نفس تأثير الخيار --msvc-syntax. إذا تم تعريف ماكرو المعالج المسبق PKGCONF_LITE أثناء الترجمة، يتم تجاهل هذا المتغير.
PKG_CONFIG_PATH
قائمة مفصولة بنقطتين لدلائل ذات أولوية عالية حيث يتم البحث عن ملفات pc(5). يتم إنشاء مسار البحث عن الوحدات عن طريق إلحاق الدليل المحدد بـ --with-path، إن وجد، وما لم يتم تحديد --env-only، عن طريق إلحاق إما PKG_CONFIG_LIBDIR أو الدلائل الافتراضية المدمجة ذات الأولوية الأقل.
PKG_CONFIG_PRELOADED_FILES
قائمة مفصولة بنقطتين لملفات pc(5) التي يتم تحميلها قبل أي ملفات pkg-config أخرى. تحصل هذه الحزم على أولوية أعلى من أي ملفات pc(5) أخرى من شأنها أن توفر حزمة معينة.
PKG_CONFIG_PURE_DEPGRAPH
إذا تم تعيينه، فإنه يتيح نفس السلوك مثل العلامة --pure.
PKG_CONFIG_RELOCATE_PATHS
إذا تم تعيينه، فإن هذا المتغير له نفس تأثير الخيار --define-prefix.
PKG_CON

NAME

pkgconf — query information about installed libraries

SYNOPSIS

pkgconf [-C file] [-W warning] [--ignore-system-roots] [--no-system-roots] [--root=root] [--prefix=prefix] [--libs|--libs-only-L|--libs-only-other] [--cflags|--cflags-only-I|--cflags-only-other] [--static] [--variable=name] [-e|--exists] [-d|--delineated] [-m|--modversion] [-p|--print-requires] [-q|--quiet] [--uninstalled] [-v|--version] [-?|--help] package[...]

DESCRIPTION

The pkgconf utility is a command-line tool that helps you compile and link applications. It queries installed libraries for header and library paths, and other information needed to build software. It is designed to be a modern replacement for the older pkg-config utility.

The pkgconf utility reads .pc files which contain metadata about installed libraries. These files are searched for in directories specified by the PKG_CONFIG_PATH environment variable, or in default system directories.

For each package specified on the command line, pkgconf prints compiler and linker flags to standard output.

The behaviour of pkgconf can be modified by various command-line options and environment variables.

For a description of the .pc file format, see pc(5).

ENVIRONMENT

PKG_CONFIG_ALLOW_SYSTEM_CFLAGS
If set, pkgconf will print system include paths specified in the .pc files. By default, system include paths are ignored.
PKG_CONFIG_ALLOW_SYSTEM_LIBS
If set, pkgconf will print system library paths specified in the .pc files. By default, system library paths are ignored.
PKG_CONFIG_DONT_RELOCATE
If set, pkgconf will not attempt to relocate paths specified in the .pc files when using --root.
PKG_CONFIG_FALLBACK_SYSTEM_PATH
A colon-separated list of directories to search for .pc files if PKG_CONFIG_PATH is not set or does not contain any matching files.
PKG_CONFIG_FLAGS
If set, this variable will be appended to the command line. It is useful for setting default options.
PKG_CONFIG_LIBDIR
A colon-separated list of directories in which to search for .pc files. This variable overrides PKG_CONFIG_PATH.
PKG_CONFIG_PATH
A colon-separated list of directories in which to search for .pc files. The default path is searched if PKG_CONFIG_PATH is not set or is empty.
PKG_CONFIG_SYSROOT_DIR
If set, this variable defines a ‘sysroot’ directory, which will be prepended to every path variable beginning with the prefix variable in a given pc(5) file. Useful for cross compilation. The value of this environment variable is also copied into the global variable pc_sysrootdir.
PKG_CONFIG_SYSTEM_INCLUDE_PATH
Colon-separated list of include paths that are filtered out and not printed by the --cflags and --cflags-only-I options because they are considered system include paths. If not defined, the default list compiled into the pkgconf program from the SYSTEM_INCLUDEDIR preprocessor macro is used instead. This variable is a pkgconf-specific extension. Any directories listed in the environment variables CPATH, C_INCLUDE_PATH, CPLUS_INCLUDE_PATH, and OBJC_INCLUDE_PATH are also filtered out.
PKG_CONFIG_SYSTEM_LIBRARY_PATH
Colon-separated list of library paths that are filtered out and not printed by the --libs and --libs-only-L options because they are considered system library paths. If not defined, the default list compiled into the pkgconf program from the SYSTEM_LIBDIR preprocessor macro is used instead. This variable is a pkgconf-specific extension.
PKG_CONFIG_TOP_BUILD_DIR
The value of the pc_top_builddir global variable. If this environment variable is not defined, the string "$(top_builddir)" is used as the value of pc_top_builddir.

EXIT STATUS

The pkgconf utility exits 0 on success, and >0 if an error occurs.

EXAMPLES

Displaying the CFLAGS of a package:

$ pkgconf --cflags foo
-fPIC -I/usr/include/foo
