PKCS12_PBE_keyivgen(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_PBE_keyivgen(3ssl) OpenSSL PKCS12_PBE_KEYIVGEN(3ssl)

الاسم

PKCS12_PBE_keyivgen, PKCS12_PBE_keyivgen_ex, PKCS12_pbe_crypt, PKCS12_pbe_crypt_ex - تشفير PKCS#12 المستند إلى كلمة المرور

ملخص

#include <openssl/evp.h>
int PKCS12_PBE_keyivgen(EVP_CIPHER_CTX *ctx, const char *pass, int passlen,
                        ASN1_TYPE *param, const EVP_CIPHER *cipher,
                        const EVP_MD *md_type, int en_de);
int PKCS12_PBE_keyivgen_ex(EVP_CIPHER_CTX *ctx, const char *pass, int passlen,
                           ASN1_TYPE *param, const EVP_CIPHER *cipher,
                           const EVP_MD *md_type, int en_de,
                           OSSL_LIB_CTX *libctx, const char *propq);
unsigned char *PKCS12_pbe_crypt(const X509_ALGOR *algor,
                                const char *pass, int passlen,
                                const unsigned char *in, int inlen,
                                unsigned char **data, int *datalen,
                                int en_de);
unsigned char *PKCS12_pbe_crypt_ex(const X509_ALGOR *algor,
                                   const char *pass, int passlen,
                                   const unsigned char *in, int inlen,
                                   unsigned char **data, int *datalen,
                                   int en_de, OSSL_LIB_CTX *libctx,
                                   const char *propq);

الوصف

تأخذ الدوال PKCS12_PBE_keyivgen() و PKCS12_PBE_keyivgen_ex() كلمة مرور pass بطول passlen، ومعلمات param، ودالة تجزئة الرسائل md_type وتقوم باشتقاق مفتاح وفقًا لـ PKCS#12. ثم يتم استخدام المفتاح الناتج لتهيئة سياق التشفير ctx مع تشفير cipher للتشفير (en_de=1) أو فك التشفير (en_de=0).

تسمح الدالة PKCS12_PBE_keyivgen_ex() أيضًا للتطبيق بتحديد سياق المكتبة libctx واستعلام الخصائص propq لاختيار تطبيقات الخوارزمية المناسبة.

ستقوم الدالتان PKCS12_pbe_crypt() و PKCS12_pbe_crypt_ex() بتشفير أو فك تشفير مخزن مؤقت بناءً على الخوارزمية الموجودة في algor وكلمة المرور pass بطول passlen. الإدخال من in بطول inlen والإخراج إلى مخزن مؤقت تم تخصيصه باستخدام malloc والذي يتم إرجاعه في *data بطول datalen. يتم تحديد العملية بواسطة en_de، التشفير (en_de=1) أو فك التشفير (en_de=0).

تسمح الدالة PKCS12_pbe_crypt_ex() للتطبيق بتحديد سياق المكتبة libctx واستعلام الخصائص propq لاختيار تطبيقات الخوارزمية المناسبة.

pass هي كلمة المرور المستخدمة في اشتقاق المفتاح بطول passlen. pass هو معلمة اختيارية ويمكن أن تكون NULL. إذا كانت passlen تساوي -1، فستقوم الدالة بحساب طول pass باستخدام strlen().

salt هو الملح المستخدم في اشتقاق المفتاح بطول saltlen. إذا كان salt يساوي NULL، فيجب أن تكون saltlen تساوي 0. لن تحاول الدالة حساب طول salt لأنه لا يُفترض أن يكون منتهيًا بحرف NULL.

iter هو عدد التكرارات ويجب أن تكون قيمته أكبر من أو تساوي 1. تقترح RFC 2898 عدد تكرارات لا يقل عن 1000. أي iter أقل من 1 يتم معاملته كتكرار واحد.

digest هي دالة تجزئة الرسائل المستخدمة في اشتقاق المفتاح.

الدوال التي تنتهي بـ _ex() تأخذ معلمات اختيارية libctx و propq والتي تستخدم لاختيار تطبيقات الخوارزمية المناسبة.

ملاحظات

تُستخدم هذه الدوال عادةً في PKCS#12 لتشفير الكائنات.

لا تفترض هذه الدوال أي شيء بخصوص كلمة المرور المقدمة. سيتم معاملتها ببساطة كسلسلة بايت.

قيم الإرجاع

تُرجع الدالتان PKCS12_PBE_keyivgen() و PKCS12_PBE_keyivgen_ex() القيمة 1 عند النجاح أو 0 عند حدوث خطأ.

تُرجع الدالتان PKCS12_pbe_crypt() و PKCS12_pbe_crypt_ex() مخزنًا مؤقتًا يحتوي على الإخراج أو NULL في حالة حدوث خطأ.
