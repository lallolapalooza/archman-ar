pkill(1)

الحزمة: procps-ng

التراخيص: GPL, LGPL

EXAMPLES

Example 1: Find the process ID of the named daemon:

$ pgrep -u root named

Example 2: Make syslog reread its configuration file:

$ pkill -HUP syslogd

Example 3: Give detailed information on all xterm processes:

$ ps -fp $(pgrep -d, -x xterm)

Example 4: Make all chrome processes run nicer:

$ renice +4 $(pgrep chrome)

Example 5: Wait for a process with a known PID to finish:

$ echo ${PID} | pidwait -F -

ملاحظات

اسم العملية المستخدم للمطابقة محدود بـ 15 حرفًا موجودة في ناتج /proc/pid/stat. استخدم الخيار -f للمطابقة مقابل سطر الأوامر الكامل، /proc/pid/cmdline. قد لا يكون لدى الخيوط نفس اسم العملية مثل العملية الأم ولكن سيكون لديها نفس سطر الأوامر.

لن يقوم pgrep أو pkill أو pidwait الذي يعمل بإبلاغ نفسه كمطابقة مطلقًا.

سيفشل الخيار -O --older بصمت إذا تم تحميل /proc مع الخيار subset=pid.

الأخطاء

لا يمكن دمج الخيارات -n و -o و -v. أخبرني إذا كنت بحاجة إلى القيام بذلك.

يتم الإبلاغ عن العمليات المنتهية (Defunct).

يتطلب pidwait استدعاء النظام pidfd_open(2) الذي ظهر لأول مرة في Linux 5.3.
