PkgConfig::LibPkgConf::Client(3pm)

The PkgConfig::LibPkgConf::Client module is a Perl wrapper for libpkgconf, which is a library that provides an API for pkg-config.

This module allows Perl programs to interact with the pkg-config system, querying for information about installed libraries and their dependencies.

NAME

PkgConfig::LibPkgConf::Client - Perl wrapper for libpkgconf

SYNOPSIS

use PkgConfig::LibPkgConf::Client;

my $client = PkgConfig::LibPkgConf::Client->new;

my $info = $client->query('glib-2.0');

if ($info) {
    print "Cflags: " . $info->{cflags} . "\n";
    print "Libs: " . $info->{libs} . "\n";
} else {
    print "glib-2.0 not found.\n";
}

DESCRIPTION

PkgConfig::LibPkgConf::Client provides a Perl interface to the libpkgconf library, allowing you to query information about installed packages in a system that uses the pkg-config mechanism. This includes flags for compilation (cflags) and linking (libs), as well as other metadata.

CONSTRUCTOR

new

Creates a new PkgConfig::LibPkgConf::Client object.

ATTRIBUTES

pkgconf_dir

Specifies a directory to search for pkg-config files. Defaults to the system default.

METHODS

query( $package_name )

Queries for information about the specified package. Returns a hash reference containing keys like cflags, libs, version, etc., or undef if the package is not found.

query_list( $package_names )

Queries for information about multiple packages. Takes an array reference of package names and returns an array reference of hash references, one for each successfully queried package.

available( $package_name )

Checks if a package is available. Returns true if available, false otherwise.

search_prefix( $package_name )

Searches for a package's installation prefix. Returns the prefix path or undef.
