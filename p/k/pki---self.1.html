NAME

strongswan - secure IPsec-based VPN solution

SYNOPSIS

strongswan [options] [configfile]

DESCRIPTION

strongSwan is a high-throughput VPN solution which implements IPsec and IKE protocols.

OPTIONS

  • -c, --config <file>

    Use <file> as configuration file.

  • -d, --debug <level>

    Set debug level to <level>.

  • -D, --debug-sockets <level>

    Set debug level for sockets to <level>.

  • -h, --help

    Show help message.

  • -L, --list-certs

    List available certificates.

  • -l, --list-conns

    List available connections.

  • -v, --version

    Show version information.

EXAMPLES

# Start strongSwan with the default configuration file
# strongswan

    
# Start strongSwan with a custom configuration file

    
# strongswan --config /etc/strongswan/strongswan.conf

    

    
# List available certificates

    
# strongswan --list-certs
