PKCS12_decrypt_skey(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_DECRYPT_SKEY(3ssl) OpenSSL PKCS12_DECRYPT_SKEY(3ssl)

الاسم

PKCS12_decrypt_skey, PKCS12_decrypt_skey_ex - وظائف فك تشفير مفتاح PKCS12 المشفر

الملخص

#include <openssl/pkcs12.h>
PKCS8_PRIV_KEY_INFO *PKCS12_decrypt_skey(const PKCS12_SAFEBAG *bag,
                                         const char *pass, int passlen);
PKCS8_PRIV_KEY_INFO *PKCS12_decrypt_skey_ex(const PKCS12_SAFEBAG *bag,
                                            const char *pass, int passlen,
                                            OSSL_LIB_CTX *ctx,
                                            const char *propq);

الوصف

PKCS12_decrypt_skey() يقوم بفك تشفير مفتاح PKCS#8 المشفر الموجود داخل bag باستخدام كلمة المرور pass المقدمة بطول passlen.

PKCS12_decrypt_skey_ex() مشابه لما سبق ولكنه يسمح باستخدام سياق المكتبة ctx واستعلام الخصائص propq لتحديد تطبيقات الخوارزمية.

قيم الإرجاع

سترجع كلتا الدالتين المفتاح المفكوك تشفيره أو NULL إذا حدث خطأ.

متوافق مع

IETF RFC 7292 (https://tools.ietf.org/html/rfc7292)

انظر أيضًا

PKCS8_decrypt_ex(3)، PKCS8_encrypt_ex(3)، PKCS12_add_key_ex(3)، PKCS12_SAFEBAG_create_pkcs8_encrypt_ex(3)

التاريخ

تمت إضافة PKCS12_decrypt_skey_ex() في OpenSSL 3.0.
