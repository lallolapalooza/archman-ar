الاسم

pkgctl-repo-create - إنشاء مستودع حزم GitLab جديد

الملخص

pkgctl repo create [OPTIONS] [PKGBASE...]

الوصف

إنشاء مستودع تغليف Git جديد في النطاق الاسمي لـ GitLab.

يتطلب هذا الأمر مصادقة API صالحة لـ GitLab. لإعداد رمز GitLab جديد أو التحقق من الرمز الحالي، يرجى الرجوع إلى الأمر الفرعي auth للحصول على مزيد من التعليمات.

إذا تم استدعاؤه بدون معلمة، حاول إنشاء مستودع تغليف بناءً على PKGBUILD من دليل العمل الحالي.

الخيارات

-c, --clone

استنساخ مستودع Git بعد الإنشاء

-h, --help

عرض نص المساعدة

انظر أيضاً

pkgctl-auth(1) pkgctl-repo-clone(1) pkgctl-repo-configure(1)
