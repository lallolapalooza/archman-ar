الاسم

pkgctl-repo - إدارة مستودعات تغليف Git وتكوينها

الملخص

pkgctl repo [OPTIONS] [SUBCOMMAND]

الوصف

إدارة مستودعات تغليف Git والمساعدة في تكوينها وفقًا لمواصفات التوزيع.

يتم تعيين معلومات مؤلف Git والمفتاح الموقع المستخدم من makepkg.conf الذي تتم قراءته من أي موقع صالح مثل /etc أو XDG_CONFIG_HOME. يمكن استخدام الأمر configure لمزامنة مواصفات التوزيع وإعدادات makepkg.conf للمستودعات المستنسخة مسبقًا.

يمكن استخدام الخيار غير المتميز لنسخ مستودعات التغليف دون الوصول إلى SSH باستخدام HTTPS للقراءة فقط.

الخيارات

-h, --help

عرض نص المساعدة

الأوامر الفرعية

pkgctl repo clean

إزالة الملفات غير المتعقبة من شجرة العمل

pkgctl repo clone

نسخ مستودع تغليف

pkgctl repo configure

تكوين نسخة وفقًا لمواصفات التوزيع

pkgctl repo create

إنشاء مستودع تغليف GitLab جديد

pkgctl repo switch

تبديل مستودع تغليف إلى إصدار محدد

pkgctl repo web

فتح موقع مستودع التغليف
