الاسم

pkgctl-repo-configure - تكوين نسخة وفقًا لمواصفات التوزيع

الملخص

pkgctl repo configure [خيارات] [مسار...]

الوصف

يقوم بتكوين مستودعات تغليف Git وفقًا لمواصفات التوزيع وإعدادات makepkg.conf.

يتم إعداد معلومات مؤلف Git والمفتاح المستخدم للتوقيع من makepkg.conf المقروء من أي موقع صالح مثل /etc أو XDG_CONFIG_HOME.

يتم تحديد بروتوكول الواجهة عن بعد تلقائيًا من عنوان البريد الإلكتروني للمؤلف عن طريق اختيار SSH لجميع هويات المبرمجين الرسميين، وبروتوكول HTTPS للقراءة فقط بخلاف ذلك.

يتم تطبيق استثناءات Git الافتراضية والخطافات على المستودع الذي تم تكوينه.

الخيارات

--protocol https

تكوين عنوان URL للواجهة لاستخدام HTTPS

-j, --jobs N

قم بتشغيل ما يصل إلى N مهمة بالتوازي. افتراضيًا، يكون عدد المهمات مساويًا لعدد وحدات المعالجة المتاحة. للمعالجة المتسلسلة، تحتاج هذه الخيار إلى تمرير القيمة 1.

-h, --help

عرض نص المساعدة
