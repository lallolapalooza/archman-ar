PKGINFO(5)

الحزمة: alpm-pkginfo

التراخيص: Apache-2.0 OR MIT, CC-BY-SA-4.0

backup

مسار ملف نسبي في الحزمة، يشير إلى ملف يجب على مدير الحزم الاحتفاظ بنسخ احتياطية له في حال تغييره أو حذفه أثناء إجراء تحديث للحزمة (انظر ملفات .pacnew و .pacsave الخاصة بـ pacman). يمكن تعيين هذه الكلمة المفتاحية صفر مرة أو أكثر. يجب أن تكون القيمة مسار ملف Unix نسبي صالح (مثال: etc/package.conf).

depend

اعتماد وقت التشغيل للحزمة (مكون افتراضي أو حزمة). يمكن تعيين هذه الكلمة المفتاحية صفر مرة أو أكثر. القيمة هي علاقة حزمة alpm من نوع اعتماد وقت التشغيل (مثال: example أو example=1.0.0).

optdepend

اعتماد اختياري للحزمة (مكون افتراضي أو حزمة). يمكن تعيين هذه الكلمة المفتاحية صفر مرة أو أكثر. القيمة هي علاقة حزمة alpm من نوع اعتماد اختياري (مثال: example أو example: هذا وصف).

makedepend

اعتماد وقت البناء للحزمة (مكون افتراضي أو حزمة). يمكن تعيين هذه الكلمة المفتاحية صفر مرة أو أكثر. القيمة هي علاقة حزمة alpm من نوع اعتماد البناء (مثال: example أو example=1.0.0).

checkdepend

اعتماد لتشغيل اختبارات المشروع الأصلي للحزمة. يمكن تعيين هذه الكلمة المفتاحية صفر مرة أو أكثر. القيمة هي علاقة حزمة alpm من نوع اعتماد الاختبار (مثال: example أو example=1.0.0).

أمثلة

pkgname = example
pkgbase = example
xdata = pkgtype=pkg
pkgver = 1:1.0.0-1
pkgdesc = مشروع يقوم بشيء ما
url = https://example.org
builddate = 1729181726
packager = John Doe <john@example.org>
size = 181849963
arch = any
license = GPL-3.0-or-later
license = LGPL-3.0-or-later
replaces = other-package>0.9.0-3
group = package-group
group = other-package-group
conflict = conflicting-package<1.0.0
conflict = other-conflicting-package<1.0.0
provides = some-component
provides = some-other-component=1:1.0.0-1
backup = etc/example/config.toml
backup = etc/example/other-config.txt
depend = glibc
depend = gcc-libs
optdepend = python: لملف special-python-script.py
optdepend = ruby: لملف special-ruby-script.rb
makedepend = cmake
makedepend = python-sphinx
checkdepend = extra-test-tool
checkdepend = other-extra-test-tool
