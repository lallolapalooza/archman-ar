PKCS12_pack_p7encdata(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

PKCS12_PACK_P7ENCDATA(3ssl) OpenSSL PKCS12_PACK_P7ENCDATA(3ssl)

الاسم

PKCS12_pack_p7encdata, PKCS12_pack_p7encdata_ex - حزم مجموعة من PKCS12 safeBags في كائن بيانات مشفر PKCS#7

الملخص

#include <openssl/pkcs12.h>
PKCS7 *PKCS12_pack_p7encdata(int pbe_nid, const char *pass, int passlen,
                             unsigned char *salt, int saltlen, int iter,
                             STACK_OF(PKCS12_SAFEBAG) *bags);
PKCS7 *PKCS12_pack_p7encdata_ex(int pbe_nid, const char *pass, int passlen,
                                unsigned char *salt, int saltlen, int iter,
                                STACK_OF(PKCS12_SAFEBAG) *bags,
                                OSSL_LIB_CTX *ctx, const char *propq);

الوصف

تقوم PKCS12_pack_p7encdata() بإنشاء كائن PKCS#7 ContentInfo من نوع بيانات مشفرة من مجموعة safeBags bags. يمكن أن يكون معرف الخوارزمية في pbe_nid خوارزمية تشفير تستند إلى كلمة مرور PKCS#12 أو PKCS#5، أو خوارزمية تشفير. إذا تم تمرير خوارزمية تشفير، فسيتم استخدام خوارزمية PKCS#5 PBES2 مع هذه الخوارزمية كمعامل. كلمة المرور pass بطول passlen، والملح salt بطول saltlen، وعدد التكرارات iter هي مدخلات في عملية التشفير.

تعمل PKCS12_pack_p7encdata_ex() بشكل مشابه لما سبق ولكنها تسمح بسياق مكتبة ctx واستعلام خاص propq لاستخدامهما لتحديد تطبيق الخوارزمية.

قيم الإرجاع

كائن PKCS7 في حالة النجاح، أو NULL في حالة حدوث خطأ.
