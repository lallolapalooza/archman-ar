pvresize(8)

الحزمة: lvm2

التراخيص: GPL-2.0-only, LGPL-2.1-only

PVRESIZE(8) دليل مدير النظام PVRESIZE(8)

الاسم

pvresize — تغيير حجم وحدات التخزين الفعلية

الملخص

pvresize position_args
option_args

الوصف

pvresize يغير حجم وحدة التخزين الفعلية (PV). قد تكون وحدة التخزين الفعلية موجودة بالفعل في مجموعة وحدات تخزين (VG) وقد تحتوي على وحدات تخزين منطقية (LVs) نشطة مخصصة لها.

الاستخدام

pvresize PV...

[ -A|--autobackup y|n ]
[ --reportformat basic|json|json_std ]
[ --setphysicalvolumesize Size[m|UNIT] ]
[ COMMON_OPTIONS ]

—

خيارات شائعة لـ LVM:

[ -d|--debug ... ]
[ -h|--help ]
[ -q|--quiet ... ]
[ -t|--test ]
[ -v|--verbose ... ]
[ -y|--yes ]
[ --commandprofile String ]
[ --config String ]
[ --devices PV ]
[ --devicesfile String ]
[ --driverloaded y|n ]
[ --journal String ]
[ --lockopt String ]
[ --longhelp ]
[ --nohints ]
[ --nolocking ]
[ --profile String ]
[ --version ]

الخيارات

-A|--autobackup y|n
يحدد ما إذا كان سيتم نسخ البيانات الوصفية احتياطيًا تلقائيًا بعد إجراء تغيير. يُنصح بشدة بتمكين هذا! انظر vgcfgbackup(8) لمزيد من المعلومات.
--commandprofile String
ملف تعريف الأمر لاستخدامه في تكوين الأوامر. انظر lvm.conf(5) لمزيد من المعلومات حول ملفات التعريف.
--config String
إعدادات التكوين للأمر. هذه تتجاوز إعدادات lvm.conf(5). يستخدم الوسيط String نفس تنسيق lvm.conf(5)، أو قد يستخدم صيغة القسم/الحقل. انظر lvm.conf(5) لمزيد من المعلومات حول التكوين.
-d|--debug ...
تعيين مستوى التصحيح. كرر من 1 إلى 6 مرات لزيادة تفاصيل الرسائل المرسلة إلى ملف السجل و/أو syslog (إذا تم تكوينه).
--devices PV
يقيد الأجهزة التي يمكن رؤيتها والوصول إليها بواسطة الأمر. الأجهزة غير المدرجة ستظهر على أنها مفقودة. يمكن تكرار هذا الخيار، أو قبوله كقائمة مفصولة بفواصل من الأجهزة. هذا يتجاوز ملف الأجهزة.
--devicesfile String
ملف يسرد الأجهزة التي يجب أن يستخدمها LVM. يجب أن يكون الملف موجودًا في /etc/lvm/devices/ ويتم إدارته باستخدام الأمر lvmdevices(8). هذا يتجاوز إعدادات devices/devicesfile و devices/use_devicesfile في lvm.conf(5).
--driverloaded y|n
إذا تم تعيينه على "لا"، فلن يحاول الأمر استخدام device-mapper. للاختبار والتصحيح.
-h|--help
عرض نص المساعدة.
--journal String
تسجيل المعلومات في سجل systemd. هذه المعلومات إضافية للمعلومات التي تم تمكينها بواسطة إعداد السجل/المجلة في lvm.conf. command: تسجيل معلومات حول الأمر. output: تسجيل الإخراج الافتراضي للأمر. debug: تسجيل تصحيح الأخطاء الكامل للأمر.
--lockopt String
يستخدم لتمرير خيارات لحالات خاصة إلى lvmlockd. انظر lvmlockd(8) لمزيد من المعلومات.
--longhelp
عرض نص المساعدة الطويل.
--nohints
لا تستخدم ملف التلميحات لتحديد مواقع الأجهزة لوحدات التخزين الفعلية. قد يقرأ الأمر المزيد من الأجهزة للعثور على وحدات التخزين الفعلية عند عدم استخدام التلميحات. سيظل الأمر يقوم بإبطال صلاحية ملفات التلميحات القياسية حيثما كان ذلك مناسبًا.
--nolocking
تعطيل القفل. استخدم بحذر، قد تؤدي الأوامر المتزامنة إلى نتائج غير صحيحة.
--profile String
اسم مستعار لـ --commandprofile أو --metadataprofile، اعتمادًا على الأمر.
-q|--quiet ...
قم بقمع الإخراج ورسائل السجل. يتجاوز --debug و --verbose. كرر مرة واحدة لقمع أي مطالبات وإجابة "لا".
--reportformat basic|json|json_std
يتجاوز تنسيق الإخراج الحالي للتقارير والذي يتم تحديده عالميًا بواسطة إعداد report/output_format في lvm.conf(5). basic هو التنسيق الأصلي مع الأعمدة والصفوف. إذا كان هناك أكثر من تقرير واحد لكل أمر، يتم تحديد كل تقرير مسبقًا باسم التقرير للتعريف. json ينتج إخراج تقرير بتنسيق JSON. json_std ينتج إخراج تقرير بتنسيق JSON وهو أكثر توافقًا مع معيار JSON. انظر lvmreport(7) لمزيد من المعلومات.
--setphysicalvolumesize Size[m|UNIT]
يتجاوز الحجم المكتشف تلقائيًا لوحدة التخزين الفعلية. استخدم بحذر، أو قبل تقليل الحجم الفعلي للجهاز.
-t|--test
تشغيل في وضع الاختبار. لن تقوم الأوامر بتحديث البيانات الوصفية. يتم تنفيذ ذلك عن طريق تعطيل جميع عمليات كتابة البيانات الوصفية ولكن مع ذلك إرجاع النجاح للدالة المستدعاة. قد يؤدي هذا إلى رسائل خطأ غير عادية في العمليات متعددة المراحل إذا اعتمدت أداة على قراءة البيانات الوصفية التي تعتقد أنها قد تغيرت ولكنها لم تتغير.
-v|--verbose ...
تعيين مستوى الإسهاب. كرر من 1 إلى 4 مرات لزيادة تفاصيل الرسائل المرسلة إلى stdout و stderr.
--version
عرض معلومات الإصدار.
-y|--yes
لا تطلب التأكيد بشكل تفاعلي ولكن افترض دائمًا الإجابة "نعم". استخدم بحذر شديد. (للإجابة التلقائية بـ "لا"، انظر -qq).

المتغيرات

PV
اسم وحدة التخزين الفعلية (Physical Volume)، مسار جهاز تحت /dev. بالنسبة للأوامر التي تدير الأقسام الفعلية (PEs)، يقبل وسيط PV الموضعي بشكل عام لاحقة تشير إلى نطاق (أو نطاقات متعددة) من الأقسام الفعلية (PEs). عندما يتم حذف القسم الأول، فإنه افتراضيًا يبدأ من بداية الجهاز، وعندما يتم حذف القسم الأخير، فإنه افتراضيًا يصل إلى النهاية.
نطاق البداية والنهاية (شامل): PV[:PE-PE] ...
نطاق البداية والطول (بدءًا من 0): PV[:PE+PE] ...
String
انظر وصف الخيار للحصول على معلومات حول محتوى السلسلة.
Size[UNIT]
الحجم هو رقم إدخال يقبل وحدة اختيارية. يتم دائمًا التعامل مع وحدات الإدخال على أنها قيم أساسها اثنان، بغض النظر عن حالة الأحرف، على سبيل المثال "k" و "K" كلاهما يشيران إلى 1024. وحدة الإدخال الافتراضية محددة بالحرف، متبوعًا بـ |UNIT. يمثل UNIT وحدات إدخال أخرى محتملة: b|B هو بايت، s|S هو قطاعات بحجم 512 بايت، k|K هو KiB، m|M هو MiB، g|G هو GiB، t|T هو TiB، p|P هو PiB، e|E هو EiB. (لا ينبغي الخلط بين هذا وبين التحكم في الإخراج --units، حيث تعني الأحرف الكبيرة

pvresize(8) — LVM TOOLS 2.03.37(2)

الاسم

pvresize — تعديل حجم جهاز مادي (PV).

الملخص

pvresize [OPTIONS] DEVICE...

الوصف

يقوم الأمر pvresize بتغيير حجم جهاز مادي (PV) في LVM. يتم استخدام هذا الأمر عادةً بعد تغيير حجم الجهاز الأساسي (مثل القسم أو القرص) الذي يمثل PV.

إذا تم توسيع الجهاز الأساسي، فسوف تحاول pvresize توسيع PV لملء المساحة المتاحة. إذا تم تقليص الجهاز الأساسي، فسوف تحاول pvresize تقليص PV إلى حجم جديد محدد.

يجب أن تكون الحجم الجديد للـ PV متوافقًا مع حجم الأقسام التي تم إنشاؤها على هذا الـ PV. على سبيل المثال، إذا كنت تقوم بتقليص PV، فيجب التأكد من أن الأقسام المنطقية (LVs) التي تم إنشاؤها على هذا الـ PV قد تم تقليصها مسبقًا لتناسب الحجم الجديد.

يمكن استخدام pvresize مع الأجهزة المادية التي تمثل أقسامًا أو أقراصًا كاملة.

الاستخدام

DEVICE
اسم الجهاز المادي (PV) الذي سيتم تعديل حجمه. يمكن تحديد جهاز واحد أو أكثر.

الخيارات

--setphysicalvolumesize SIZE
يقوم بتعيين الحجم الفعلي للجهاز المادي (PV) إلى SIZE. يستخدم هذا الخيار عادةً عند تقليص PV. يجب أن يكون SIZE أصغر من الحجم الحالي للـ PV. يتم رفض التقليص إذا كانت هناك بيانات تتجاوز الحجم الجديد.
--restoresize
يقوم باستعادة حجم PV إلى حجمه السابق. يستخدم هذا الخيار بشكل نادر، وعادةً ما يتم استخدامه في سيناريوهات استعادة الأخطاء.
--update-physicalvolumesize
يقوم بتحديث حجم PV ليعكس الحجم الحالي للجهاز الأساسي. يستخدم هذا الخيار عند توسيع PV.
-h, --help
يعرض رسالة مساعدة ثم يخرج.
-V, --version
يعرض معلومات الإصدار ثم يخرج.
SIZE
حجم يمكن تحديده بوحدات البايت، أو باستخدام لاحقات مثل K، M، G، T، P، E، Z، Y (أو مضاعفاتها مثل KB، MB، GB، إلخ). يمكن أيضًا تحديد حجم بـ 1024 (Kibibyte) باستخدام البادئات iB، KiB، MiB، GiB، TiB، PiB، EiB، ZiB، YiB (على سبيل المثال، 10GiB). يتم استخدام مضاعفات 1000 (Kilobyte) افتراضيًا (على سبيل المثال، 10GB). (مضاعفات 1000.)

متغيرات البيئة

راجع lvm(8) للحصول على معلومات حول متغيرات البيئة التي يستخدمها LVM. على سبيل المثال، يمكن عمومًا استبدال LVM_VG_NAME بمعامل VG المطلوب.

ملاحظات

سيرفض pvresize تقليص PV إذا كان يحتوي على مساحات مخصصة تتجاوز النهاية الجديدة.

أمثلة

توسيع PV بعد تكبير القسم.

pvresize /dev/sda1

تقليص PV قبل تقليص القسم (تأكد من أن حجم PV مناسب لحجم القسم الجديد المقصود).

pvresize --setphysicalvolumesize 40G /dev/sda1
