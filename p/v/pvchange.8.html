NAME

pvchange — change characteristics of a physical volume

SYNOPSIS

pvchange [-A|--alloc allocation_policy] [-b | --backup] [-B | --partial] [-d | --debug] [-h | --help] [-K | --monitor monitor_type] [-m | --mergemetadata] [-p | --partial] [-q | --quiet] [-t | --test] [-u | --uuid] [-v | --verbose ...] [--version] [-y | --yes] [--add | --remove] [--alloc allocation_policy] [--allocatable | --not-allocatable] [--devices device_list] [--long-host-names | --short-host-names] [--max-physical-logins number] [--max-logical-logins number] [--physicalvolumes physicalvolume_list] [--pvlogins number] [--refresh] [--storage-host host_name] [--systemid string] [--uuid] [-x | --allocatable] PhysicalVolumeSpec [PhysicalVolumeSpec...]

DESCRIPTION

Changes attributes of one or more physical volumes (PVs). See pv(5) for more information on PVs.

USAGE

The PVs to be changed are given as arguments. The attributes to change are specified with options.

OPTIONS

-A|--alloc allocation_policy
Sets the allocation policy for the PV. This determines how physical extents are allocated on the PV. The policy can be set to:
contiguous
Only contiguous extents will be allocated.
cling
Extent will be allocated on the same PV if possible.
normal
Default policy. Extents are allocated anywhere on any PV.
any
Extents are allocated anywhere on any PV.
cluster
Same as normal, but with cluster-wide consideration.
-b|--backup
This option is not supported.
-B|--partial
Allow partial PVs to be added. A partial PV is a PV that is missing some metadata. This option is usually used when the PV is added to a clusted VG. If the PV is not part of a cluster, it should be made whole with pvck(8).
-d|--debug
Enable debugging output.
-h|--help
Display help information.
-K|--monitor monitor_type
Set the monitor type for the PV. This is used in clustered environments.
-m|--mergemetadata
Merge metadata from PVs that are no longer visible to the system. This option is used to recover metadata from PVs that have been removed from the system.
-p|--partial
Allow partial PVs to be added. This is the same as -B.
-q|--quiet
Suppress some output messages.
-t|--test
Run in test mode. Commands will not update metadata. This is implemented by disabling all metadata writing but nevertheless returning success to the calling function. This may lead to unusual error messages in multi-stage operations if a tool relies on reading back metadata it believes has changed but hasn't.
-u|--uuid
Generate new random UUID for specified PVs.
-v|--verbose ...
Set verbose level. Repeat from 1 to 4 times to increase the detail of messages sent to stdout and stderr.
--version
Display version information.
-y|--yes
Do not prompt for confirmation interactively but always assume the answer yes. Use with extreme caution. (For automatic no, see -qq.)
-x|--allocatable
Enable allocation of physical extents on the PV. This is the default.
--allocatable
Enable allocation of physical extents on the PV. This is the default.
--add
Add the PV to a volume group. This option is used when creating a new volume group or adding an existing PV to a volume group.
--alloc allocation_policy
Sets the allocation policy for the PV. This is the same as -A.
--not-allocatable
Disable allocation of physical extents on the PV. This is useful when the PV is failing or when it will be removed from the system.
--physicalvolumes physicalvolume_list
This option is deprecated and will be removed in future releases. Use positional arguments instead.
--remove
Remove the PV from a volume group. This option is used when removing a PV from a volume group.

VARIABLES

PV
Physical Volume name, a device path under /dev. For commands managing physical extents, a PV positional arg generally accepts a suffix indicating a range (or multiple ranges) of physical extents (PEs). When the first PE is omitted, it defaults to the start of the device, and when the last PE is omitted it defaults to end.
Start and end range (inclusive): PV[:PE-PE] ...
Start and length range (counting from 0): PV[:PE+PE] ...
Select
Select indicates that a required positional parameter can be omitted if the --select option is used. No arg appears in this position.
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables used by lvm. For example, LVM_VG_NAME can generally be substituted for a required VG parameter.

EXAMPLES

Disallow the allocation of physical extents on a PV (e.g. because of disk errors, or because it will be removed after freeing it).
pvchange -x n /dev/sdk1
