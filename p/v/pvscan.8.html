الوصف

عند استدعائه بدون الخيار --cache، يسرد pvscan وحدات التخزين الفيزيائية (PVs) على النظام، مثل pvs(8) أو pvdisplay(8).

عند استخدام --cache، يقوم pvscan بتحديث حالة LVM في وقت التشغيل على النظام، أو مع -aay يقوم بالتنشيط التلقائي.

pvscan --cache device

إذا كان الجهاز موجودًا، يسجل LVM أن وحدة التخزين الفيزيائية على الجهاز متصلة. إذا لم يكن الجهاز موجودًا، يزيل LVM سجل الاتصال لوحدة التخزين الفيزيائية. يقرأ pvscan الجهاز المسمى فقط.

pvscan --cache

يحدث حالة وقت التشغيل لجميع أجهزة LVM.

pvscan --cache -aay device

يقوم بخطوات --cache للجهاز، ثم يتحقق مما إذا كانت مجموعة وحدات التخزين (VG) التي تستخدم الجهاز كاملة. إذا كان الأمر كذلك، يتم تنشيط وحدات التخزين المنطقية (LVs) في VG، بنفس الطريقة التي يقوم بها vgchange -aay vgname. (يمكن استبدال اسم الجهاز بأرقام رئيسية وثانوية.)

pvscan --cache -aay

يقوم بخطوات --cache لجميع الأجهزة، ثم ينشط تلقائيًا أي مجموعات وحدات تخزين كاملة.

pvscan --cache --listvg|--listlvs device

يقوم بخطوات --cache للجهاز، ثم يطبع اسم مجموعة وحدات التخزين التي تستخدم الجهاز، أو أسماء وحدات التخزين المنطقية التي تستخدم الجهاز. عادةً ما يتم تضمين --checkcomplete للتحقق مما إذا كانت جميع وحدات التخزين الفيزيائية لمجموعة وحدات التخزين أو وحدات التخزين المنطقية متصلة. عند استدعاء هذا الأمر بواسطة قاعدة udev، يجب أن يتوافق الإخراج مع مواصفات قاعدة udev (انظر --udevoutput.) ستستخدم قاعدة udev النتائج لإجراء التنشيط التلقائي.

يمكن تمكين/تعطيل التنشيط التلقائي لمجموعات وحدات التخزين أو وحدات التخزين المنطقية باستخدام vgchange أو lvchange مع --setautoactivation y|n، أو عن طريق إضافة أسماء إلى lvm.conf(5) activation/auto_activation_volume_list.

انظر lvmautoactivation(7) لمزيد من المعلومات حول كيفية استخدام pvscan للتنشيط التلقائي.

الخيارات

-a|--activate y|n|ay
التنشيط التلقائي لوحدات التخزين المنطقية في مجموعة وحدات تخزين عندما تكمل وحدات التخزين الفيزيائية الممسوحة مجموعة وحدات التخزين. (فقط **ay** قابل للتطبيق.)
-A|--allpvs
عرض معلومات حول وحدات التخزين الفيزيائية خارج ملف الأجهزة. يعرض معرف الجهاز لوحدات التخزين الفيزيائية المدرجة في ملف الأجهزة.
--autoactivation String
تحديد ما إذا كان التنشيط التلقائي قيد الاستخدام من حدث. يتيح ذلك للأمر تطبيق الإعدادات الخاصة بتنشيط الأحداث، مثل تحسينات مسح الأجهزة باستخدام ملفات pvs_online التي تم إنشاؤها بواسطة عمليات مسح pvscans المستندة إلى الأحداث.
--cache
مسح جهاز واحد أو أكثر وتسجيل أنها متصلة.
--checkcomplete
التحقق مما إذا كانت جميع الأجهزة المستخدمة بواسطة مجموعة وحدات تخزين أو وحدة تخزين منطقية موجودة، وطباعة "complete" أو "incomplete" لكل مجموعة وحدات تخزين أو وحدة تخزين منطقية مدرجة. يتم استخدام هذا الخيار كجزء من التنشيط التلقائي المستند إلى الأحداث، لذا لن يقوم pvscan بأي شيء إذا تم تعيين هذا الخيار و event_activation=0 في إعدادات التكوين.
--commandprofile String

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

-a|--all
All available physical volumes.
--commandprofile String
The command profile to use for command configuration. See lvm.conf(5) for more information about profiles.
--config String
Config settings for the command. These override lvm.conf(5) settings. The String arg uses the same format as lvm.conf(5), or may use section/field syntax. See lvm.conf(5) for more information about config.
-d|--debug ...
Set debug level. Repeat from 1 to 6 times to increase the detail of messages sent to the log file and/or syslog (if configured).

Restricts the devices that are visible and accessible to the command. Devices not listed will appear to be missing. This option can be repeated, or accepts a comma separated list of devices. This overrides the devices file.

Suppress output and log messages. Overrides --debug and --verbose. Repeat once to also suppress any prompts with answer 'no'.

VARIABLES

PV
Physical Volume name, a device path under /dev. For commands managing physical extents, a PV positional arg generally accepts a suffix indicating a range (or multiple ranges) of physical extents (PEs). When the first PE is omitted, it defaults to the start of the device, and when the last PE is omitted it defaults to end.
Start and end range (inclusive): PV[:PE-PE] ...
Start and length range (counting from 0): PV[:PE+PE] ...
String
See the option description for information about the string content.
Size[UNIT]
Size is an input number that accepts an optional unit. Input units are always treated as base two values, regardless of capitalization, e.g. 'k' and 'K' both refer to 1024. The default input unit is specified by letter, followed by |UNIT. UNIT represents other possible input units: b|B is bytes, s|S is sectors of 512 bytes, k|K is KiB, m|M is MiB, g|G is GiB, t|T is TiB, p|P is PiB, e|E is EiB. (This should not be confused with the output control --units, where capital letters mean multiple of 1000.)

Scan for Physical Volumes, Devices or Volume Groups

NAME

pvscan — scan for Physical Volumes, Devices or Volume Groups

SYNOPSIS

pvscan [options]

DESCRIPTION

The pvscan command scans for Physical Volumes (PVs), Devices or Volume Groups (VGs) on your system.

It also supports scanning for specific devices or hosts (in clustered environments).

The command can optionally discover and activate all Volume Groups found on the system.

USAGE

Scan all available block devices for LVM metadata and report any found Physical Volumes:

    pvscan

Scan only specific devices:

    pvscan /dev/sda1 /dev/sdb

Scan the specified devices and activate any Volume Groups found:

    pvscan --activate y /dev/sda1 /dev/sdb

Scan for devices on a remote host (in clustered environments):

    pvscan --host remote_host

OPTIONS

-a |--activate y|n|a
Determine whether to activate Volume Groups found during the scan. y: activate all found Volume Groups. n: do not activate any Volume Groups. a: activate all found Volume Groups, except for those that are already active.
-b |--background
Run in background. This option is useful for systems that need to continue booting before LVM devices are available.
-d |--debug
Enable detailed debugging output.
-h |--help
Display help text and exit.
-H |--host hostname
Scan for devices and Volume Groups on a remote host. This option is only relevant in clustered LVM environments.
-m |--monitor
Show metadata in the output. This option is useful for debugging and troubleshooting.
-p |--partial
Scan for partial Volume Groups. A partial Volume Group is a Volume Group where not all Physical Volumes are available.
-v |--verbose
Enable verbose output.
-y |--yes
Assume "yes" to all prompts. This option is useful for scripting and automation.

VARIABLES

The following variables can be set to change the behavior of pvscan:

PVSCAN_JOBS
Specifies the maximum number of parallel jobs for scanning devices. The default is typically the number of CPU cores available.

ENVIRONMENT VARIABLES

See lvm(8) for information about environment variables.
