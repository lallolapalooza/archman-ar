NAME

dpftrf, spftrf, cpftrf, zpftrf - Cholesky factorization of a rectangular full packed (RFP) matrix

SYNOPSIS

CALL DPFTTRF( TRANSR, UPLO, N, A, INFO )

CALL SPFTTRF( TRANSR, UPLO, N, A, INFO )

CALL CPFTTRF( TRANSR, UPLO, N, A, INFO )

CALL ZPFTTRF( TRANSR, UPLO, N, A, INFO )

DESCRIPTION

This routine is deprecated. The new interface is described in Section 4.3 of the online documentation. This routine is provided for compatibility with earlier versions.

The routines compute the Cholesky factorization of a real or complex rectangular full packed (RFP) matrix A.

The factorization has the form:

If UPLO = 'U' then A = U**T * U, if UPLO = 'L' then A = L * L**T.

Here U is a triangular band matrix and L is a lower triangular band matrix.

The input matrix A is stored in RFP format. RFP format is a storage scheme for a triangular band matrix which is obtained from the standard storage scheme for a triangular matrix by using the BLAS functionTRMM to tile the matrix with blocks of size nb x nb, where nb is the block size.

The storage scheme is described in Further Details.

PARAMETERS

TRANSR

TRANSR is CHARACTER*1

On entry, TRANSR specifies the storage format for A. It is recommended that TRANSR = 'N' for the Normal form of RFP storage and TRANSR = 'T' for the Transpose form of RFP storage.

Unchanged on exit.

UPLO

UPLO is CHARACTER*1

On entry, UPLO specifies whether the matrix A is upper- or lower-triangular as follows:

UPLO = 'U' => A is upper triangular.
UPLO = 'L' => A is lower triangular.

Unchanged on exit.

N

N is INTEGER

On entry, N specifies the order of the rectangular full packed matrix A. N must be at least 0.

Unchanged on exit.

A

A is a DOUBLE PRECISION (DPFTTRF), REAL (SPFTTRF), COMPLEX*16 (CPFTTRF), or COMPLEX*16 (ZPFTTRF) array.

On entry, the array A contains the RFP matrix to be factorized. The dimensions of A depend on N, TRANSR and UPLO. See "Further Details".

On exit, A is the RFP matrix A, such that:

if UPLO = 'U' then A = U**T * U,
if UPLO = 'L' then A = L * L**T.

Here U is an upper triangular matrix and L is a lower triangular matrix. The factorization is in RFP format.

INFO

INFO is INTEGER

On exit, INFO is an integer and:

INFO = 0:  successful exit
INFO < 0:  if INFO = -i, the i-th argument had an illegal value.
INFO > 0:  if INFO = i, the leading principal minor of order i
           is not positive, and the factorization could not be
           completed.
