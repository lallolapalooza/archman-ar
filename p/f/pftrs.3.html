NAME

pftrs — solves a system of linear equations A*X = B for a triangular matrix A in RFP format with multiple right hand sides.

SYNOPSIS

 SUBROUTINE PFTRS( UPLO, TRANSR, N, NRHS, A, LDA, B, LDB, INFO )

       CHARACTER * 1           UPLO
       CHARACTER * 1           TRANSR
       INTEGER                 N
       INTEGER                 NRHS
       COMPLEX*16              A( N*(N+1)/2 )
       INTEGER                 LDA
       COMPLEX*16              B( LDB, NRHS )
       INTEGER                 LDB
       INTEGER                 INFO

Detailed Description

This routine is deprecated and is provided for backward compatibility only. For new projects, use ZPTSVX.

PFTRES solves a system of linear equations A*X = B for a triangular matrix A in RFP (Rectangular Full Packed) format with multiple right hand sides.

A is an N-by-N complex matrix and X and B are N-by-NRHS complex matrices. RFP format is described in Further Details.

Information about the selected factorization:
 The plot below shows the storage layout of the Cholesky factorization of a general N x N rectangular full packed (RFP) matrix, A. The upper triangle of A is shown.

Layout of RFP Format:

Let N be the order of the matrix. The number of elements in the RFP matrix A is N*(N+1)/2.

  • If UPLO = 'U', A stores the upper triangle of the original matrix.
  • If UPLO = 'L', A stores the lower triangle of the original matrix.

The matrix A is stored in a one-dimensional array. The storage scheme is determined by the relationship between the standard packed format (AP) and the rectangular full packed (RFP) format. The RFP format is a transformation of the packed format used for triangular matrices.

The subroutine requires the matrix A to be in RFP format, which is computed by the function ZPFTRF.
