الحزمة: ppc64le-elf-binutils

التراخيص: GPL

NAME

addr2line — convert segment addresses to line numbers

SYNOPSIS

ppc64le-elf-addr2line [options...] [address...]

DESCRIPTION

addr2line is a utility that translates addresses, given in hexadecimal, into file names and line numbers. It can also be used to translate addresses into functions names.

addr2line is part of the GNU Binutils package.

OPTIONS

-i, --inlines
Print the inner function name for inlined functions. If a call is inlined, print the file and line number of the caller, and the file, line number and function name of the callee. The default behaviour is to print only the caller's information.
-j, --objects-file-map
Look up symbols in DWARF debugging sections.
-p, --demangle
Demangle C++ symbol names. This option enables demangling for all symbol names, including C symbols.
-e ehdr
Specify the executable for which to look up addresses. If not specified, addr2line assumes the addresses are in the file a.out.
-C, --demangle[=style]
Demangle according to style. The default style is auto. This option can be specified multiple times.
-o file
Add the specified file to the list of input files. This is useful if you want to examine addresses in several binary files.
-a, --address-radix=radix
The radix for printing addresses.
-l, --line-number
Print the function name, file name, and line number.
-f, --functions
Print the function name.
-h, --help
Show the help message.
-v, --version
Show the version of addr2line.

الاسم

addr2line — تحويل عناوين القطاعات إلى أرقام أسطر

نبذة

ppc64le-elf-addr2line [خيارات...] [عنوان...]

الوصف

addr2line هو أداة تقوم بترجمة العناوين، المعطاة بالنظام الست عشري، إلى أسماء ملفات وأرقام أسطر. يمكن استخدامها أيضًا لترجمة العناوين إلى أسماء وظائف.

addr2line جزء من حزمة GNU Binutils.

خيارات

-i, --inlines
طباعة اسم الوظيفة الداخلية للوظائف المضمنة. إذا تم تضمين استدعاء، اطبع اسم الملف ورقم السطر للمستدعي، واسم الملف ورقم السطر والوظيفة للمستدعى. السلوك الافتراضي هو طباعة معلومات المستدعي فقط.
-j, --objects-file-map
البحث عن الرموز في أقسام التصحيح DWARF.
-p, --demangle
فك تشفير أسماء الرموز C++. يتيح هذا الخيار فك التشفير لجميع أسماء الرموز، بما في ذلك رموز C.
-e ehdr
تحديد الملف التنفيذي الذي سيتم البحث عن العناوين فيه. إذا لم يتم تحديده، يفترض addr2line أن العناوين موجودة في الملف a.out.
-C, --demangle[=style]
فك التشفير وفقًا لـ style. النمط الافتراضي هو auto. يمكن تحديد هذا الخيار عدة مرات.
-o file
إضافة الملف المحدد file إلى قائمة الملفات المدخلة. هذا مفيد إذا كنت ترغب في فحص العناوين في عدة ملفات ثنائية.
-a, --address-radix=radix
النظام الأساسي لطباعة العناوين.
-l, --line-number
طباعة اسم الوظيفة واسم الملف ورقم السطر.
-f, --functions
طباعة اسم الوظيفة.
-h, --help
عرض رسالة المساعدة.
-v, --version
عرض إصدار addr2line.
