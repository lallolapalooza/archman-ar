pppdump(8)

الحزمة: ppp

التراخيص: GPL, BSD

PPPDUMP(8) دليل مدير النظام PPPDUMP(8)

الاسم

pppdump - تحويل ملف سجل PPP إلى تنسيق قابل للقراءة

ملخص

pppdump [ -h | -p [ -d ]] [ -r ] [ -a ] [ -m mru ] [ ملف ... ]

الوصف

تقوم الأداة المساعدة pppdump بتحويل الملفات المكتوبة باستخدام خيار record الخاص بـ pppd إلى تنسيق يمكن للبشر قراءته. إذا تم تحديد اسم ملف واحد أو أكثر، ستقوم pppdump بقراءة كل منها بالتتابع؛ وإلا، ستقرأ من مدخلاتها القياسية. في كلتا الحالتين، يتم كتابة النتيجة إلى المخرج القياسي.

الخيارات هي كالتالي:

-h
يطبع البايتات المرسلة والمستقبلة بالنظام الست عشري. إذا لم يتم تحديد هذا الخيار أو الخيار -p، يتم طباعة البايتات كأحرف نفسها، مع طباعة الأحرف غير القابلة للطباعة وغير ASCII كتسلسلات هروب.
-p
يجمع البايتات المرسلة والمستقبلة في حزم PPP، ويقوم بتفسير تأطير HDLC غير المتزامن وأحرف الهروب وفحص تسلسل التحقق من الإطار (FCS) لكل حزمة. يتم طباعة الحزم كقيم سداسية عشرية وكأحرف (يتم طباعة الأحرف غير القابلة للطباعة كنقطة '.').
-d
مع الخيار -p، يتسبب هذا الخيار في أن تقوم pppdump بفك ضغط الحزم التي تم ضغطها باستخدام طريقتي BSD-Compress أو Deflate.
-r
يعكس مؤشرات الاتجاه، بحيث تتم طباعة 'sent' للبايتات أو الحزم المستلمة، و'rcvd' للبايتات أو الحزم المرسلة.
-a
يطبع الأوقات المطلقة.
-m mru
استخدم mru كحد أقصى لوحدة الاستقبال (MRU) لكلا اتجاهي الارتباط عند التحقق من حزم PPP التي تتجاوز الطول (مع الخيار -p).
