PPIx__Utilities__Node(3pm)

الحزمة: perl-ppix-utilities

PPIx::Utilities::Node(3) وثائق مساهمات المستخدم في بيرل PPIx::Utilities::Node(3)

الاسم

PPIx::Utilities::Node - امتدادات لـ PPI::Node.

الإصدار

يصف هذا المستند الإصدار 1.1.0 من PPIx::Utilities::Node.

الملخص

use PPIx::Utilities::Node qw< split_ppi_node_by_namespace >;
my $dom = PPI::Document->new("...");
while (
    my ($namespace, $sub_doms) = each split_ppi_node_by_namespace($dom)
) {
    foreach my $sub_dom ( @{$sub_doms} ) {
        ...
    }
}

الوصف

هذه مجموعة من الوظائف للتعامل مع PPI::Nodes.

الواجهة

لا يتم تصدير أي شيء افتراضيًا.

split_ppi_node_by_namespace($node)

يعيد الأشجار الفرعية لكل مساحة اسم في العقدة كمرجع إلى جدول من المراجع إلى مصفوفات من PPI::Nodes. لنفترض أن لدينا الكود التالي:

#!perl
my $x = blah();
package Foo;
my $y = blah_blah();
{
    say 'Whee!';
    package Bar;
    something();
}
thingy();
package Baz;
da_da_da();
package Foo;
foreach ( blrfl() ) {
    ...
}

عند استدعاء هذه الوظيفة على PPI::Document للكود أعلاه، فإنها تعيد قيمة تبدو كالتالي، مع استخدام حرفيات السلاسل متعددة الأسطر للأجزاء الفعلية للكود بدلاً من أشجار PPI لتسهيل القراءة:

{
    main    => [
        q<
            #!perl
            my $x = blah();
        >,
    ],
    Foo     => [
        q<
            package Foo;
            my $y = blah_blah();
            {
                say 'Whee!';
            }
            thingy();
        >,
        q<
            package Foo;
            foreach ( blrfl() ) {
                ...
            }
        >,
    ],
    Bar     => [
        q<
            package Bar;
            something();
        >,
    ],
    Baz     => [
        q<
            package Baz;
            da_da_da();
        >,
    ],
}

لاحظ أن القيمة المرجعة تحتوي على نسخ من العقد الأصلية، وليس العقد الأصلية نفسها بسبب الحاجة إلى التعامل مع مساحات الأسماء التي ليست على نطاق الملف. (لاحظ كيف يختلف العنصر الأول لـ "Foo" أعلاه عن الكود الأصلي.)
