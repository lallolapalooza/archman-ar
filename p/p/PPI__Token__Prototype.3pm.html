الاسم

PPI::Token::Prototype - واصف نموذج دالة فرعية

الوراثة

PPI::Token::Prototype
isa PPI::Token::Quote::Literal
    isa PPI::Token::Quote
        isa PPI::Token
            isa PPI::Element

الملخص

sub ($@) prototype;

الوصف

على الرغم من أنها تبدو إلى حد ما مثل قائمة أو شرط، فإن نموذج الدالة الفرعية يشبه السلسلة النصية إلى حد كبير. وظيفتها هي تقديم تلميحات لمترجم Perl حول نوع الوسائط التي تتوقعها دالة فرعية معينة، والتي يستخدمها المترجم للتحقق من صحة المعلمات في وقت الترجمة، ويسمح للمبرمجين باستخدام الوظائف دون أقواس صريحة للمعلمات.

نظرًا لظهور الترميز الكائني في Perl، والذي يتجاهل هذه النماذج، فإنها غالبًا ما تستخدم للسماح بأشياء تشبه الثوابت، و"لتوسيع" اللغة وإنشاء أشياء تعمل ككلمات رئيسية ووظائف أساسية.

# إنشاء شيء يعمل كثابت
sub MYCONSTANT () { 10 }

# إنشاء وظيفة تبدو أساسية مثل "any"
sub any (&@) { ... }

if ( any { $_->cute } @babies ) {
      ...
}

الطرق

توفر هذه الفئة طريقة إضافية واحدة تتجاوز تلك التي حددتها الفئات الأصلية PPI::Token و PPI::Element.

prototype

تقوم المساعد "prototype" بإرجاع نمط النموذج الفعلي، مجردًا من الأقواس المحيطة وجميع المسافات البيضاء. هذا يعكس سلوك وظيفة Perl المضمنة "prototype".

لاحظ أن تجريد الأقواس والمسافات البيضاء يعني أن القيمة التي ترجعها "prototype" يمكن أن تكون سلسلة فارغة.
