الاسم

ppmshadow - إضافة ظلال محاكاة لصورة PPM

الملخص

ppmshadow [-b حجم_التعتيم] [-k] [-t] [-x إزاحة_x] [-y إزاحة_y] [ملف_ppm]

الوصف

هذا البرنامج جزء من Netpbm(1)

يضيف ppmshadow ظلاً محاكاة إلى صورة، مما يعطي انطباعًا بأن محتويات الصورة تطفو فوق الصفحة، ملقيةً ظلًا منتشرًا على الخلفية. يمكن أن تكون الظلال سوداء، كما تلقيها الأجسام المعتمة، أو شفافة، حيث تأخذ الظلال لون الجسم الذي يلقيها. يمكنك تحديد وضوح الظل وإزاحته عن الصورة باستخدام خيارات سطر الأوامر.

يرى ppmshadow صورتك كواجهة أمامية على خلفية. لون الخلفية هو أي لون هو البكسل العلوي الأيسر لصورتك. الخلفية هي كل وحدات البكسل التي لها هذا اللون والواجهة الأمامية هي كل شيء آخر. الظل الذي يولده ppmshadow هو ظل للواجهة الأمامية، ملقى على الخلفية.

الظل بنفس حجم الواجهة الأمامية، بالإضافة إلى بعض الحواف كما يحددها الخيار -b. يتم اقتطاعه ليناسب صورتك. أبعاد الصورة الناتجة هي نفس أبعاد الصورة المدخلة.

يمكنك استخدام pamcomp لوضع صورة أمامية فوق خلفية قبل تشغيل ppmshadow عليها. يمكنك استخدام ppmmake لإنشاء صورة الخلفية (مجرد صورة بلون واحد).

الخيارات

-b حجم_التعتيم
يحدد مسافة مصدر الضوء من الصورة. القيم الأكبر تحرك مصدر الضوء أقرب، مما يلقي ظلًا أكثر انتشارًا، بينما الإعدادات الأصغر تحرك الضوء أبعد، مما ينتج عنه ظل أكثر حدة. حجم_التعتيم هو عدد وحدات البكسل من الحواف الموجودة في الظل، بعد المكان الذي سيكون فيه الظل إذا لم يكن هناك تعتيم.

الافتراضي هو 11 بكسل.

لاحظ أن هذا الخيار يتحكم فقط في تأثير الحواف الناتج عن تقريب مصدر الضوء من الكائن. لا يجعل الظل ينمو أو يتقلص كما يحدث في العالم الحقيقي إذا قمت بتحريك مصدر ضوء نقطي أقرب وإلى أبعد من كائن.

-k
احتفظ بملفات الصور المؤقتة الوسيطة. عند تصحيح الأخطاء، توفر هذه الملفات الوسيطة العديد من الأدلة على مصدر الخطأ. انظر أدناه للحصول على قائمة بمحتويات كل ملف.
-t
اعتبر المواد غير الخلفية في الصورة شفافة - فهي تلقي ظلالًا بلونها الخاص بدلاً من الظل الأسود، وهو الافتراضي. غالبًا ما ينتج عن هذا صور ضبابية وصعبة القراءة ولكن في بعض الظروف قد تبدو أفضل.
-x إزاحة_x
يحدد إزاحة مصدر الضوء إلى يسار الصورة. الإعدادات الأكبر لـ إزاحة_x تزحزح الظل إلى اليمين، كما يلقيه ضوء أبعد إلى اليسار. إذا لم يتم تحديده، تكون الإزاحة الأفقية نصف حجم_التعتيم (أعلاه)، إلى اليسار.
-y إزاحة_y

يحدد إزاحة مصدر الضوء فوق الجزء العلوي من الصورة. الإعدادات الأكبر تزحزح الظل إلى الأسفل، بما يتوافق مع تحريك الضوء أبعد فوق الجزء العلوي من الصورة. إذا لم تحدد -y، فإن الإزاحة الرأسية تكون افتراضيًا نفس الإزاحة الأفقية (أعلاه)، إلى الأعلى.

الملفات

الإدخال هو ملف PPM يسمى بواسطة وسيط سطر الأوامر ملف_ppm؛ إذا لم تحدد ملف_ppm، فإن الإدخال هو الإدخال القياسي.

الإخراج هو ملف PPM، مكتوب إلى الإخراج القياسي.

يقوم ppmshadow بإنشاء عدد من الملفات المؤقتة أثناء تنفيذه. ينشئ مجلدًا جديدًا لها، /tmp/ppmshadowpid، حيث pid هو معرف عملية ppmshadow. إذا تم تعيين متغير البيئة TMPDIR، يقوم ppmshadow بإنشاء المجلد هناك بدلاً من /tmp.

في التشغيل العادي، يقوم ppmshadow بحذف كل ملف مؤقت بمجرد الانتهاء منه ولا يترك أي حطام بعد اكتماله. للاحتفاظ بالملفات الوسيطة لتصحيح الأخطاء، استخدم خيار سطر الأوامر -k.

الملفات المؤقتة هي:

infile.ppm
نسخة من المدخلات.
bgmask.ppm
قناع ثنائي موجب
convkernel.ppm
نواة التفاف لتمويه الظل
blurred.ppm
صورة ظل مموهة وملونة
blurred2.ppm
صورة ظل مموهة قبل التلوين
shadow.ppm
صورة ظل مقطوعة، مزاحة حسب المطلوب
background.ppm
صورة فارغة بخلفية صورة المصدر
shadow.ppm
ظل مزاح
fgmask.ppm
ملف قناع معكوس
justfg.ppm
الواجهة الأمامية فقط. الباقي أسود. الصورة الأصلية مضروبة في القناع المعكوس.
shadback.ppm
الظل الناتج مضروب في القناع الموجب
allbutfg.ppm
كل شيء ما عدا الواجهة الأمامية (منطقة الواجهة الأمامية سوداء).

القيود

يجب أن تحتوي الصورة المصدر على مساحة كافية على الحواف في الاتجاه الذي يلقى فيه الظل لاستيعاب الظل - إذا لم تفعل ذلك، فقد تفشل بعض الخطوات الداخلية. يمكنك عادةً توسيع حافة صورة تم قصها بشكل ضيق جدًا باستخدام pnmmargin قبل معالجتها باستخدام ppmshadow.

البكسلات السوداء والبكسلات ذات اللون نفسه مثل خلفية الصورة لا تلقي ظلًا. إذا تسبب هذا في "ثقوب" غير مقصودة في الظل، فاملأ المناطق المعنية بلون يختلف عن الأسود أو الخلفية بقيم RGB تبلغ 1، والتي لن تكون محسوسة للمشاهد. نظرًا لأن المقارنة دقيقة، فإن المناطق المعدلة ستلقي الآن ظلالًا.

يعتبر لون الخلفية للصورة المصدر (الذي يتم الحفاظ عليه في الإخراج) هو لون البكسل في الزاوية العلوية اليسرى للصورة المدخلة. إذا لم يكن هذا البكسل جزءًا من الخلفية، فما عليك سوى إضافة حدود بكسل واحد في الجزء العلوي من الصورة، وإنشاء صورة الظل، ثم حذف الحدود منها.

إذا حدث خطأ ما في الطريق، فإن رسائل الخطأ من برامج Netpbm المختلفة التي يستدعيها ppmshadow لن تقدم، بشكل عام، أي دليل أو دليل ضئيل على المكان الذي أخطأ فيه ppmshadow. في هذه الحالة، حدد الخيار -k وافحص النتائج الوسيطة في الملفات المؤقتة (التي يتسبب هذا الخيار في الاحتفاظ بها). إذا قمت بتشغيل الأوامر التي يشغلها ppmshadow على هذه الملفات يدويًا، يمكنك تحديد مكان المشكلة. في الحالات الإشكالية التي ترغب فيها في تعديل عملية إنشاء الصورة يدويًا أثناء التنقل، يمكنك الاحتفاظ بالملفات الوسيطة باستخدام الخيار -k ، وتعديلها بشكل مناسب باستخدام محرر صور، ثم إعادة تجميعها مع الخطوات المستخدمة بواسطة الكود في ppmshadow.

راجع ملف ppmshadow.doc في شجرة مصادر Netpbm للحصول على تفاصيل إضافية وأمثلة للملفات الوسيطة وتصحيح أخطاء ppmshadow.

الظلال سوداء افتراضيًا، كما تلقيها مادة معتمة في الصورة تحجب الضوء الأبيض. استخدم الخيار -t لمحاكاة المواد الشفافة، حيث يأخذ الظل لون الكائن الذي يلقيه. إذا كان التباين بين الصورة والخلفية غير كافٍ، فقد ينتج عن الخيار -t نتائج غير جذابة تشبه تمويهًا بسيطًا للصورة الأصلية.

ppmshadow 1

create a shadow behind an object

NAME

ppmshadow - create a shadow behind an object

SYNOPSIS

ppmshadow [-blur blur] [-blur blur] [-shades shades] [-shades shades] [-light light] [-light light] [-page page] [-page page] [-o output.ppm] [input.ppm]

DESCRIPTION

ppmshadow takes as input a PBM image that represents an object, and outputs a PPM image of the object with a shadow behind it. The shadow is a blurred, darker version of the object, offset from the object by the specified amount.

The input PBM image should represent the object as black pixels (value 1) and the background as white pixels (value 0). ppmshadow treats the black pixels as the object and generates a shadow behind them.

The shadow is generated by blurring the object and then offsetting it. The blurring is done by convolution with a Gaussian kernel. The offset is determined by the -light option.

OPTIONS

-blur blur

Specifies the amount of blur to apply to the shadow. Higher values result in a softer, more spread-out shadow. The default is 3.

-shades shades

Specifies the number of shades of gray to use for the shadow. A higher value results in a darker shadow. The default is 256.

-light light

Specifies the direction of the light source. This determines the offset of the shadow. The value is a pair of numbers, representing the x and y components of the light vector. For example, -light 1 1 means the light is coming from the top-left, so the shadow will be offset to the bottom-right. The default is -light 4 4.

-page page

Specifies the size of the output image. The shadow will be extended to fill this area. The value is a pair of numbers, representing the width and height of the page. The default is to use the dimensions of the input image.

-o output.ppm

Specifies the output file name. If not specified, the output will be written to standard output.

FILES

None

LIMITATIONS

The largest convolution kernel that pnmconvol could use was 11 by 11. ppmshadow includes a horrible, CPU-time-burning kludge which, if a blur greater than 11 is requested, performs an initial convolution with an 11 x 11 kernel, then calls pnmsmooth (which is itself a program that calls pnmconvol with a 3 x 3 kernel) as many times as the requested blur exceeds 11. It's ugly, but it gets the job done on those rare occasions where you need a blur greater than 11.

If you wish to generate an image at high resolution, then scale it to publication size with pamscale in order to eliminate jagged edges by resampling, it's best to generate the shadow in the original high resolution image, prior to scaling it down in size. If you scale first and then add the shadow, you'll get an unsightly jagged stripe between the edge of material and its shadow, due to resampled pixels intermediate between the image and background obscuring the shadow.

EXIT STATUS

ppmshadow returns status 0 if processing was completed without errors, and a nonzero Unix error code if an error prevented generation of output. Some errors may result in the script aborting, usually displaying error messages from various Netpbm components it uses, without returning a nonzero error code. When this happens, the output file will be empty, so be sure to test this if you need to know if the program succeeded.
