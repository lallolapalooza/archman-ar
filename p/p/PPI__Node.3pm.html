PPI__Node(3pm)

الحزمة: perl-ppi

التراخيص: PerlArtistic

PPI::Node(3) توثيق مساهمة المستخدم في Perl PPI::Node(3)

الاسم

PPI::Node - فئة عقدة PPI مجردة، عنصر يمكن أن يحتوي على عناصر أخرى

الوراثة

PPI::Node
isa PPI::Element

الملخص

# إنشاء عقدة نموذجية (مستند في هذه الحالة)
my $Node = PPI::Document->new;

# إضافة عنصر إلى العقدة (في هذه الحالة، رمز)
my $Token = PPI::Token::Word->new('my');
$Node->add_element( $Token );

# الحصول على عناصر العقدة
my @elements = $Node->children;

# البحث عن جميع الكلمات المجردة داخل عقدة
my $barewords = $Node->find( 'PPI::Token::Word' );

# البحث بمعايير أكثر تعقيدًا
my $my_tokens = $Node->find( sub { $_[1]->content eq 'my' } );

# إزالة كل المسافات البيضاء
$Node->prune( 'PPI::Token::Whitespace' );

# الإزالة بمعايير أكثر تعقيدًا
$Node->prune( sub { $_[1]->content eq 'my' } );

الوصف

توفر الفئة "PPI::Node" فئة أساسية مجردة لفئات العناصر القادرة على احتواء عناصر أخرى مثل PPI::Document و PPI::Statement و PPI::Structure.

بالإضافة إلى تلك المدرجة أدناه، تنطبق جميع الطرق التي تنطبق على كائنات PPI::Element أيضًا على كائنات "PPI::Node".

الطرق

النطاق

تُرجع الطريقة "scope" قيمة صحيحة إذا كانت العقدة تمثل حدود نطاق معجمي، أو قيمة خاطئة إذا لم تكن كذلك.

add_element $Element

تضيف الطريقة "add_element" كائن PPI::Element إلى نهاية "PPI::Node". نظرًا لأن العناصر تحتفظ بروابط مع الوالد، يمكن إضافة عنصر واحد فقط إلى عقدة واحدة.

تُرجع قيمة صحيحة إذا تمت إضافة PPI::Element. تُرجع "undef" إذا كان العنصر موجودًا بالفعل داخل عقدة أخرى، أو لم يتم تمرير كائن PPI::Element إلى الطريقة.

العناصر

تصل الطريقة "elements" إلى جميع العناصر الفرعية هيكليًا داخل كائن "PPI::Node". لاحظ أنه في حالة فئات PPI::Structure، يشمل هذا رموز الأقواس في كلا الطرفين.

تُرجع قائمة بصفر أو أكثر من كائنات PPI::Element.

بدلاً من ذلك، إذا تم استدعاؤها في سياق قياسي، تُرجع الطريقة "elements" عدد العناصر.

العنصر_الأول

تصل الطريقة "first_element" إلى العنصر الأول هيكليًا داخل كائن "PPI::Node". كما هو الحال مع الطريقة "elements"، يتضمن ذلك رموز الأقواس لكائنات PPI::Structure.

تُرجع كائن PPI::Element، أو "undef" إذا لم يكن كائن "PPI::Node" يحتوي على أي عناصر لأي سبب.

العنصر_الأخير

تصل الطريقة "last_element" إلى العنصر الأخير هيكليًا داخل كائن "PPI::Node". كما هو الحال مع الطريقة "elements"، يتضمن ذلك رموز الأقواس لكائنات PPI::Structure.

تُرجع كائن PPI::Element، أو "undef" إذا لم يكن كائن "PPI::Node" يحتوي على أي عناصر لأي سبب.

الأبناء

تصل الطريقة "children" إلى جميع العناصر الفرعية معجميًا داخل كائن "PPI::Node". لاحظ أنه في حالة فئات PPI::Structure، فإن هذا لا يشمل رموز الأقواس في كلا طرفي الهيكل.

تُرجع قائمة بصفر أو أكثر من كائنات PPI::Element.

بدلاً من ذلك، إذا تم استدعاؤها في سياق قياسي، تُرجع الطريقة "children" عدد الأبناء المعجميين.

الأبناء_الهامون

الطريقة "schildren" هي في الواقع مجرد اختصار، وهي النسخة المهمة فقط من الطريقة العادية "children".

في سياق القائمة، تُرجع قائمة بالأبناء المهمين. في السياق القياسي، تُرجع عدد الأبناء المهمين.

الابن $index

تصل الطريقة "child" إلى كائن PPI::Element فرعي حسب موضعه داخل العقدة.

تُرجع كائن PPI::Element، أو "undef" إذا لم يكن هناك عنصر فرعي في تلك العقدة.

الابن_الهام $index

يتجاهل الهيكل المعجمي للغة Perl العناصر 'غير المهمة'، مثل المسافات البيضاء والتعليقات، بينما يعامل PPI هذه العناصر كرموز صالحة حتى يتمكن من إعادة تجميع الملف في أي وقت. لهذا السبب، في العديد من المواقف، هناك حاجة للعثور على عنصر داخل عقدة حسب الفهرس، مع عد العناصر الهامة فقط.

تُرجع الطريقة "schild" عنصرًا فرعيًا حسب الفهرس، مع تجاهل العناصر غير الهامة. يتم تحديد فهرس العنصر الفرعي بنفس الطريقة كما في مصفوفة عادية، مع العنصر الأول في الفهرس 0، والفهارس السالبة المستخدمة لتحديد موضع "من النهاية".

يحتوي $Element

تُستخدم الطريقة "contains" لتحديد ما إذا كان كائن PPI::Element آخر "ضمن" "PPI::Node" منطقيًا. بالنسبة للحالة الخاصة لرموز الأقواس على جانبي كائن PPI::Structure، فإنها تعتبر بشكل عام "ضمن" كائن PPI::Structure، حتى لو لم تكن في الواقع ضمن عناصر PPI::Structure.

تُرجع قيمة صحيحة إذا كان PPI::Element ضمننا، وقيمة خاطئة إذا لم يكن كذلك، أو "undef" عند حدوث خطأ.

بحث $class | \&wanted

تُستخدم الطريقة "find" للبحث داخل شجرة التعليمات البرمجية عن كائنات PPI::Element التي تفي بشرط معين.

لتحديد الشرط، يمكن تزويد الطريقة إما باسم فئة بسيط (كامل أو مختصر)، أو مرجع "CODE" / دالة.

# البحث عن جميع علامات الاقتباس الفردية في مستند (وهو عقدة)
$Document->find('PPI::Quote::Single');

# نفس الشيء مع اسم فئة مختصر
$Document->find('Quote::Single');

# أي شيء أكثر تفصيلاً، نستخدم الدالة الفرعية
$Document->find( sub {
      # في المستوى الأعلى من الملف...
      $_[1]->parent == $_[0]
      and (
              # ... البحث عن جميع التعليقات والـ POD
              $_[1]->isa('PPI::Token::Pod')
              or
              $_[1]->isa('PPI::Token::Comment')
      )
} );

سيتم تمرير وسيطتين إلى الدالة: "PPI::Node" المستوى الأعلى الذي تبحث فيه، و PPI::Element الحالي الذي يختبر الشرط.

يجب أن تُرجع الدالة المجهولة إحدى القيم الثلاث. تشير إرجاع قيمة صحيحة إلى تطابق الشرط، وتشير قيمة خاطئة معرفة (0 أو '') إلى عدم التطابق، وتشير "undef" إلى عدم التطابق وعدم النزول.

في الحالة الأخيرة، سيتخطى المشي في الشجرة أي شيء أسفل العنصر الذي يُرجع "undef" وينتقل إلى العنصر التالي على نفس المستوى.

لإيقاف البحث بالكامل وإرجاع "undef" على الفور، تم تزويد الشرط

NAME

PPI::Node - A node in a PPI document parse tree

INHERITANCE

PPI::Node is a subclass of PPI::Element.

SYNOPSIS

  my $node = PPI::Node->new;
  $node->name( 'MyPackage' );
  $node->add_content( PPI::Statement::Include->new( ... ) );
  my @children = $node->find( 'PPI::Statement' );

DESCRIPTION

A PPI::Node is a subclass of PPI::Element that represents a recursive structural element of a Perl document, such as a package, a subroutine, or a block.

Nodes can contain other elements, including other nodes, via the METHODS section below.

METHODS

new

Creates and returns a new PPI::Node object, which is a subclass of PPI::Element.

name $name

Gets or sets the name of the node. For a package node, this would be the package name. For a subroutine node, this would be the subroutine name. For a block node, this would be "undef".

add_content $element

Adds the given PPI::Element to the end of the node's content list.

Returns the element that was added.

add_content_before $Element, $Replacement

Adds the $Replacement element immediately before the specified $Element.

Returns the replacement element.

add_content_after $Element, $Replacement

Adds the $Replacement element immediately after the specified $Element.

Returns the replacement element.

content

Returns a list of all the direct children of the node. This will be a mix of PPI::Element objects, including other PPI::Node objects.

depth

Returns the depth of the node within the tree. The root node is at depth 0.

find $class | \&wanted

Searches the node (and its children, recursively) for elements that match the given condition. The condition can be either a class name (e.g., "PPI::Statement::Include") or an anonymous subroutine (a closure) that takes a single PPI::Element object and returns true or false.

The search is done depth-first.

If a wanted sub is provided, it will be called for every element in the tree, including nodes. If the sub returns false or throws an exception, the search continues. If the sub returns true, the element is considered a match.

If a class name is provided, it will find all elements that are instances of that class or a subclass thereof.

Note that if the wanted logic is provided, and it returns true for an element, then that element is included in the result list, but the search continues below that element to find any further matches.

If the wanted logic itself causes an exception, the find method will throw an exception.

Returns a reference to an array of the matching elements, or false if no elements match.

find_first $class | \&wanted

Works like find, but returns only the first element that matches the condition.

Returns the matching element, or false if no element matches.

find_any $class | \&wanted

Works like find, but returns true as soon as it finds *any* matching element, and false otherwise. It does not return the elements themselves.

Returns true if any elements match the condition, or false otherwise.

remove_child $Element

Removes the specified child element from the node. The child element must be a direct child of the node.

Returns the removed element if successful, or false otherwise.

replace_child $Element, $Replacement

Replaces the specified child element with the replacement element. Both elements must be direct children of the node.

Returns the replacement element if successful, or false otherwise.

prune $class | \&wanted

Removes all elements from the node (and its descendants) that match the given condition. The condition is the same as for find.

Returns the number of elements removed.

select_child $class | \&wanted

Returns a list of direct children of the node that match the given condition. This is like find, but it only searches the immediate children and does not recurse.

Returns a list of matching child elements.

select_first_child $class | \&wanted

Returns the first direct child of the node that matches the given condition. This is like find_first, but it only searches the immediate children and does not recurse.

Returns the matching child element, or false if no child matches.

select_any_child $class | \&wanted

Returns true if any direct child of the node matches the given condition, and false otherwise. This is like find_any, but it only searches the immediate children and does not recurse.

Returns true if any child matches, or false otherwise.

remove_child $Element, $Wanted

Works like remove_child, but instead of taking a specific element to remove, it takes a condition (class or wanted sub) and removes the first child that matches the condition.

Returns the removed element, or false if no matching child is found.

replace_child $Element, $Replacement, $Wanted

Works like replace_child, but instead of taking a specific element to replace, it takes a condition (class or wanted sub) and replaces the first child that matches the condition with the $Replacement element.

Returns the replacement element, or false if no matching child is found.

prune $class | \&wanted

Works like prune, but only operates on the direct children of the node, without recursing.

Returns the number of elements removed.

--- implicit methods ---

Methods documented in PPI::Element are also available and should behave identically unless otherwise noted.
