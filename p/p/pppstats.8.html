pppstats(8)

NAME

pppstats - display PPP statistics

SYNOPSIS

pppstats [-a] [-c] [-i interface]

DESCRIPTION

The pppstats command displays statistics about the Point-to-Point Protocol (PPP) connections on the system. By default, it displays statistics for all active PPP interfaces. If the -i option is specified, it displays statistics only for the given interface.

The following options are available:

-a
Display statistics in ASCII format.
-c
Clear statistics after displaying them.
-i interface
Display statistics for the specified interface.
