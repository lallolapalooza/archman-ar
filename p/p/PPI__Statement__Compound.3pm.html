PPI__Statement__Compound(3pm)

الحزمة: perl-ppi

التراخيص: PerlArtistic

PPI::Statement::Compound(3) توثيق مساهم من مستخدم Perl PPI::Statement::Compound(3)

الاسم

PPI::Statement::Compound - يصف جميع العبارات المركبة

الملخص

# عبارة if مركبة
if ( foo ) {
    bar();
} else {
    baz();
}
# عبارة حلقة مركبة
foreach ( @list ) {
    bar($_);
}

الوراثة

PPI::Statement::Compound
isa PPI::Statement
    isa PPI::Node
        isa PPI::Element

الوصف

"PPI::Statement::Compound" تُستخدم الكائنات لوصف جميع الأشكال الحالية للعبارات المركبة، كما هو موضح في perlsyn.

يشمل ذلك كتل باستخدام "if"، "unless"، "for"، "foreach"، "while"، و "continue". يرجى ملاحظة أن هذا لا يشمل العبارات "البسيطة" ذات الشروط اللاحقة. يرجى ملاحظة أيضًا أن "do" ليست جزءًا من عبارة مركبة أيضًا.

# هذه ليست عبارة مركبة
my $foo = 1 if $condition;
# هذه أيضًا ليست عبارة مركبة
do { ... } until $condition;

الطرق

"PPI::Statement::Compound" لديها عدد من الطرق بالإضافة إلى طرق PPI::Statement و PPI::Node و PPI::Element القياسية.

النوع

تقوم طريقة "type" بإرجاع النوع النحوي للعبارة المركبة.

هناك أربعة أنواع أساسية للعبارات المركبة.

يشمل النوع 'if' جميع أشكال عبارات if و unless، بما في ذلك أي أجزاء 'elsif' أو 'else' من العبارة المركبة.

يصف النوع 'while' عبارات while و until القياسية، ولكن مرة أخرى لا يصف العبارات البسيطة مع while لاحقة.

يغطي النوع 'for' حلقات for بأسلوب C، بغض النظر عما إذا تم الإعلان عنها باستخدام 'for' أو 'foreach'.

يغطي النوع 'foreach' الحلقات التي تتكرر عبر المجموعات، بغض النظر عما إذا تم الإعلان عنها باستخدام 'for' أو 'foreach'.

جميع المركبات هي تباين على واحد من هذه الأربعة.

ترجع السلسلة البسيطة 'if'، 'for'، 'foreach' أو 'while'، أو "undef" إذا تعذر تحديد النوع.
