ppdc(1) OpenPrinting ppdc(1)

الاسم

ppdc - مترجم ppd لـ cups (مهمل)

الملخص

ppdc [ -D name[=value] ] [ -I include-directory ] [ -c message-catalog ] [ -d output-directory ] [ -l language(s) ] [ -m ] [ -t ] [ -v ] [ -z ] [ --cr ] [ --crlf ] [ --lf ] source-file

الوصف

يقوم ppdc بترجمة ملفات مصدر PPDC إلى ملف (ملفات) PPD واحد أو أكثر. هذا البرنامج مهمل وسيتم إزالته في إصدار مستقبلي من CUPS.

الخيارات

يدعم ppdc الخيارات التالية:

-D name[=value]
يحدد المتغير المسمى للاستخدام في ملف المصدر. يعادل استخدام التوجيه #define في ملف المصدر.
-I include-directory
يحدد دليل تضمين بديل. يمكن توفير خيارات -I متعددة لإضافة أدلة إضافية.
-c message-catalog
يحدد ملف كتالوج رسائل واحد بتنسيق GNU gettext (filename.po) أو Apple strings (filename.strings) لاستخدامه في الترجمة.
-d output-directory
يحدد دليل الإخراج لملفات PPD. دليل الإخراج الافتراضي هو "ppd".
-l language(s)
يحدد لغة واحدة أو أكثر لاستخدامها عند ترجمة ملف (ملفات) PPD. اللغة الافتراضية هي "en" (الإنجليزية). افصل بين اللغات المتعددة بفواصل، على سبيل المثال "de_DE,en_UK,es_ES,es_MX,es_US,fr_CA,fr_FR,it_IT" سيؤدي إلى إنشاء ملفات PPD بلغات ألمانية، إنجليزية بريطانية، إسبانية (إسبانيا، المكسيك، والولايات المتحدة)، فرنسية (فرنسا وكندا)، وإيطالية في كل ملف.
-m
يحدد أن اسم ملف الإخراج يجب أن يعتمد على قيمة ModelName بدلاً من FileName أو PCFileName.
-t
يحدد أنه يجب اختبار ملفات PPD بدلاً من إنشائها.
-v
يحدد إخراجًا مفصلاً، وهو في الأساس حالة تشغيل للملفات التي يتم تحميلها أو كتابتها. -z يقوم بإنشاء ملفات PPD مضغوطة (filename.ppd.gz). الافتراضي هو إنشاء ملفات PPD غير مضغوطة.
--cr
--crlf
--lf
يحدد نهاية السطر المراد استخدامها - حرف الإرجاع، حرف الإرجاع وحرف تغذية الأسطر، أو حرف تغذية الأسطر وحده. الافتراضي هو استخدام حرف تغذية الأسطر وحده.

ملاحظات

ملفات PPD مهملة ولن يتم دعمها بعد الآن في إصدار الميزات المستقبلي من CUPS. يمكن دعم الطابعات التي لا تدعم IPP باستخدام تطبيقات مثل ippeveprinter(1).
