PPI__Structure__Block(3pm)

الحزمة: perl-ppi

التراخيص: PerlArtistic

PPI::Structure::Block(3) وثائق Perl المساهمة من المستخدم PPI::Structure::Block(3)

الاسم

PPI::Structure::Block - أقواس معقوفة تمثل كتلة كود

الملخص

sub foo { ... }

grep { ... } @list;

if ( condition ) {
    ...
}

LABEL: {
    ...
}

الوراثة

PPI::Structure::Block
isa PPI::Structure
    isa PPI::Node
        isa PPI::Element

الوصف

"PPI::Structure::Block" هي الفئة المستخدمة لجميع الأقواس المعقوفة التي تمثل كتل الكود. يشمل ذلك الروتينات الفرعية، والعبارات المركبة، وأي أقواس كتل أخرى.

الأساليب

"PPI::Structure::Block" لا تحتوي على أساليب تتجاوز تلك المتوفرة من أساليب PPI::Structure و PPI::Node و PPI::Element القياسية.
