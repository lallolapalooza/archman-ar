PPIx__Utilities__Statement(3pm)

الحزمة: perl-ppix-utilities

التراخيص: PerlArtistic

PPIx::Utilities::Statement(3) توثيق بيرل من مساهمة المستخدم PPIx::Utilities::Statement(3)

الاسم

PPIx::Utilities::Statement - امتدادات لـ PPI::Statement.

الإصدار

يصف هذا المستند الإصدار 1.1.0 من PPIx::Utilities::Statement.

الملخص

use PPI::Document qw< >;
use PPIx::Utilities::Statement qw<
    get_constant_name_elements_from_declaring_statement
>;
my $document = PPI::Document->new(\'Readonly::Scalar my $THINGY => 47.2;');
# يعيد PPI::Token::Symbol لـ "$THINGY".
my ($constant) = get_constant_name_elements_from_declaring_statement(
    $document->schild(0)
);

الوصف

هذه مجموعة من الدوال للتعامل مع PPI::Statements.

الواجهة

لا يتم تصدير أي شيء افتراضيًا.

get_constant_name_elements_from_declaring_statement($statement)

نظرًا لـ PPI::Statement، إذا كانت الجملة عبارة عن بيان تعريف Readonly أو Const::Fast أو "use constant"، فستعيد أسماء الأشياء التي يتم تعريفها.

نظرًا لـ

use constant 1.16 FOO => 'bar';

ستعيد هذه الدالة PPI::Token::Word التي تحتوي على 'FOO'. نظرًا لـ

use constant 1.16 { FOO => 'bar', 'BAZ' => 'burfle' };

ستعيد هذه الدالة قائمة بـ PPI::Tokens التي تحتوي على 'FOO' و 'BAZ'. وبالمثل، نظرًا لـ

Readonly::Hash my %FOO => ( bar => 'baz' );

أو

const my %FOO => ( bar => 'baz' );

ستعيد هذه الدالة PPI::Token::Symbol التي تحتوي على '%FOO'.
