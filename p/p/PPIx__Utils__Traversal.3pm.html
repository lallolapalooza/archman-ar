PPIx__Utils__Traversal(3pm)

الحزمة: perl-ppix-utils

التراخيص: PerlArtistic

PPIx::Utils::Traversal(3) وثائق حزم Perl المساهمة PPIx::Utils::Traversal(3)

الاسم

PPIx::Utils::Traversal - دوال مساعدة للتنقل في وثائق PPI

الملخص

use PPIx::Utils::Traversal ':all';

الوصف

هذه الحزمة هي جزء من مكون PPIx::Utils الذي يحتوي على دوال للتنقل في وثائق PPI.

الدوال

يمكن استيراد جميع الدوال بالاسم، أو باستخدام العلامة ":all".

first_arg

my $first_arg = first_arg($element);

بالنظر إلى عنصر PPI يفترض أنه استدعاء دالة (عادةً ما يكون PPI::Token::Word)، يتم إرجاع الوسيط الأول. هذا مشابه لـ "parse_arg_list" ويتبع نفس المنطق. لاحظ أنه بالنسبة للكود:

int($x + 0.5)

هذه الدالة تعيد فقط $x، وليس العدد الصحيح بأكمله. هذا يختلف عن سلوك "parse_arg_list". اعتبار آخر هو:

int(($x + $y) + 0.5)

الذي يعيد "($x + $y)" ككائن PPI::Structure::List.

parse_arg_list

my @args = parse_arg_list($element);

بالنظر إلى عنصر PPI يفترض أنه استدعاء دالة (عادةً ما يكون PPI::Token::Word)، فإنها تقسم تعبيرات الوسائط إلى مصفوفات من التوكنات. تعيد قائمة تحتوي على مراجع لكل من هذه المصفوفات. هذا مفيد لأن الأقواس اختيارية عند استدعاء دالة، و PPI يحللها بطريقة مختلفة جدًا. لذلك، هذه الطريقة هي شجرة تحليل على مستوى عقدة PPI. إنها ليست موثوقة لأنها لا تحترم الأسبقية. بشكل عام، لن أقدر العمل الذي تقوم به هذه الدالة كثيرًا، لذا لا تعتمد عليها للاستقرار (أو حتى الوجود).

split_nodes_on_comma

my @args = split_nodes_on_comma(@nodes);

لها نفس نوع الإرجاع مثل "parse_arg_list" ولكنها تتوقع أن يتم تمرير عقد تمثل محتويات قائمة، مثل:

'foo', 1, 2, 'bar'

get_next_element_in_same_simple_statement

my $element = get_next_element_in_same_simple_statement($element);

بالنظر إلى عنصر PPI، تعيد هذه الإجراءات الفرعية العنصر التالي في نفس الجملة البسيطة، وفقًا للمعايير "is_ppi_simple_statement" في PPIx::Utils::Classification. إذا لم يتم العثور على العنصر التالي، فإنها تعيد ببساطة "undef".

إذا كان $element فارغًا أو ليس كائنًا، فإننا نعيد ببساطة "undef".

إذا كان $element يفي بـ "is_ppi_simple_statement" في PPIx::Utils::Classification، فإننا نعيد "undef"، **باستثناء** أنه لديه أب هو PPI::Structure::List.

إذا كان $element هو آخر عنصر مهم في عقدة PPI الخاصة به، فإننا نستبدله بأبها ونكرر مرة أخرى.

بخلاف ذلك، نعيد "$element->snext_sibling()".

get_previous_module_used_on_same_line

my $element = get_previous_module_used_on_same_line($element);

بالنظر إلى عنصر PPI، تعيد هذه الدالة عنصر PPI الذي يمثل اسم الوحدة المضمنة بواسطة "use" أو "require" السابق على نفس السطر مثل $element. إذا لم يتم العثور عليه، فإنها تعيد ببساطة "undef".

على سبيل المثال، مع السطر:

use version; our $VERSION = ...;

بالنظر إلى PPI::Token::Symbol لـ $VERSION، فإنها تعيد "version".

إذا كان العنصر المعطى في "use" أو "require"، فإنها تعيد نتيجة "use" أو "require" السابق على السطر.

get_constant_name_elements_from_declaring_statement

my @constants = get_constant_name_elements_from_declaring_statement($statement);

بالنظر إلى بيان PPI، إذا كان البيان هو إعلان Readonly، ReadonlyX، أو Const::Fast، أو بيان "use constant"، فإنها تعيد أسماء العناصر المعرفة.

بالنظر إلى:

use constant 1.16 FOO => 'bar';

تعيد PPI::Token::Word مع 'FOO'. بالنظر إلى:

use constant 1.16 { FOO => 'bar', 'BAZ' => 'burfle' };

تعيد قائمة بـ PPI::Tokens مع 'FOO' و 'BAZ'. بالمثل، بالنظر إلى:

Readonly::Hash my %FOO => ( bar => 'baz' );

أو:

const my %FOO => ( bar => 'baz' );

تعيد PPI::Token::Symbol مع '%FOO'.

split_ppi_node_by_namespace

my $subtrees = split_ppi_node_by_namespace($node);

تعيد الأشجار الفرعية لكل مساحة أسماء في العقدة كمصفوفة من مراجع المصفوفات لـ PPI::Nodes. على سبيل المثال، إذا كان لدينا الكود التالي:

#!perl
my $x = blah();
package Foo;
my $y = blah_blah();
{
    say 'Whee!';
    package Bar;
    something();
}
thingy();
package Baz;
da_da_da();
package Foo;
foreach ( blrfl() ) {
    ...
}

استدعاء هذه الدالة على PPI::Document للمثال أعلاه يعيد قيمة تبدو كالتالي، باستخدام أسطر كود متعددة الأسطر للأجزاء الفعلية بدلاً من أشجار PPI لتسهيل القراءة:

{
    main    => [
        q<
            #!perl
            my $x = blah();
        >,
    ],
    Foo     => [
        q<
            package Foo;
            my $y = blah_blah();
            {
                say 'Whee!';
            }
            thingy();
        >,
        q<
            package Foo;
            foreach ( blrfl() ) {
                ...
            }
        >,
    ],
    Bar     => [
        q<
            package Bar;
            something();
        >,
    ],
    Baz     => [
        q<
            package Baz;
            da_da_da();
        >,
    ],
}

ملاحظة: القيمة المعاد تحتوي على نسخ من العقد الأصلية، وليس العقد نفسها بسبب الحاجة إلى التعامل مع مساحات الأسماء غير الملفات. (لاحظ كيف يختلف العنصر الأول لـ "Foo" أعلاه عن الأصل.)
