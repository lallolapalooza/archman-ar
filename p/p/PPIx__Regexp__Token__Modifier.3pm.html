PPIx__Regexp__Token__Modifier(3pm)

الحزمة: perl-ppix-regexp

التراخيص: PerlArtistic

الاسم

PPIx-Regexp

ملخص

use PPIx::Regexp;

الوراثة

PPIx::Regexp

الوصف

PPIx::Regexp هي وحدة Perl توفر دعمًا للتعبيرات النمطية لوحدة PPI (واجهة محلل Perl).

الطرق

توفر PPIx::Regexp طرقًا لتحليل واستخراج التعبيرات النمطية من كود Perl.

الدعم

للدعم، يرجى الرجوع إلى صفحة المشكلات على GitHub أو الاتصال بالمؤلف مباشرة.
