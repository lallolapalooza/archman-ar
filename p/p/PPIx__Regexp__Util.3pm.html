PPIx::Regexp::Util(3pm)

NAME

PPIx::Regexp::Util - A module for using regular expressions with PPI

SYNOPSIS

use PPIx::Regexp::Util;

DESCRIPTION

This module provides utility functions for working with regular expressions within the PPI (Perl Parsing and Interpolation) framework. It helps in parsing, analyzing, and manipulating regular expression strings and their associated data.

SUBROUTINES

The module exports the following subroutines:

  • parse_regexp( $string ): Parses a given string as a regular expression.
  • is_regexp( $string ): Checks if a given string can be parsed as a regular expression.
  • regexp_to_string( $regexp_object ): Converts a regular expression object back into a string.

EXPORT TAGS

The module exports the following tags:

  • :all: Exports all the above subroutines.
