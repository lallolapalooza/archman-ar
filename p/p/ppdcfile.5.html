ppdcfile(5) OpenPrinting ppdcfile(5)

الاسم

ppdcfile - تنسيق ملف مصدر مترجم ppd الخاص بـ CUPS (مهمل)

الوصف

يقرأ مترجم PPD الخاص بـ CUPS ملفات وصفية تحتوي على أوصاف لملف PPD واحد أو أكثر ليتم إنشاؤها بواسطة ppdc(1). توفر صفحة الدليل هذه مرجعًا سريعًا للكلمات الرئيسية المدعومة ويجب استخدامها جنبًا إلى جنب مع المساعدة عبر الإنترنت الخاصة بـ CUPS.

تنسيق ملف المصدر هو نص ASCII عادي يمكن تحريره باستخدام محرر النصوص المفضل لديك. يتم دعم التعليقات باستخدام آليات التعليق C (/* ... */) و C++ (// ...).

يمكن تجميع معلومات برنامج تشغيل الطابعة ومشاركتها باستخدام الأقواس المعقوفة ({ ... })؛ يتم كتابة ملفات PPD عند رؤية قوس إغلاق أو نهاية الملف، وعند تعريف توجيه PCFileName.

يمكن وضع التوجيهات في أي مكان في سطر ويتبعها قيمة واحدة أو أكثر. فيما يلي قائمة بالتوجيهات المتاحة والقيم التي تقبلها:

#define name value
#elif {name | value}
#else
#endif
#font name encoding "version" charset status
#if {name | value}
#include <filename>
#include "filename"
#media name width length
#media "name/text" width length
#po locale "filename"
