Image__ExifTool__Import(3pm)

الحزمة: perl-image-exiftool

التراخيص: Artistic-1.0-Perl OR GPL-3.0-or-later

Image::ExifTool::Import(3) توثيق بيرل مساهمة من المستخدم Image::ExifTool::Import(3)

الاسم

Image::ExifTool::Import - استيراد ملفات قاعدة بيانات CSV و JSON

الملخص

use Image::ExifTool::Import qw(ReadCSV ReadJSON);
$err = ReadCSV($csvFile, \%database);
$err = ReadJSON($jsonfile, \%database);

الوصف

يحتوي هذا الموديول على روتينات لاستيراد معلومات العلامات من ملفات قواعد بيانات CSV (قيم مفصولة بفواصل) و JSON (تدوين كائن جافاسكريبت).

التصدير

لا يتم تصدير شيء افتراضيًا، ولكن يمكن تصدير ReadCSV و ReadJSON.

الطرق

ReadCSV / ReadJSON

قراءة ملف CSV أو JSON في جدول بيانات.

المدخلات:
0) اسم ملف CSV أو مرجع ملف.

1) مرجع هاش لكائن قاعدة البيانات.

2) سلسلة اختيارية تستخدم لتمثيل قيمة علامة غير محددة (مفقودة). (تستخدم لحذف العلامات.)

3) لـ ReadCSV، هذا هو المحدد لإدخالات CSV، مع قيمة افتراضية هي ",". لـ ReadJSON، هذه هي مجموعة الأحرف لتحويل تسلسلات الهروب Unicode في السلاسل، مع قيمة افتراضية هي "UTF8". انظر خيار ExifTool Charset للحصول على قائمة بمجموعات الأحرف الصالحة.

قيمة الإرجاع:
ترجع هذه الدوال سلسلة خطأ، أو undef عند النجاح وتملأ هاش قاعدة البيانات بالإدخالات من ملف CSV أو JSON. يتم تخزين الإدخالات بناءً على عمود SourceFile في معلومات CSV أو JSON، ويتم تخزينها كعمليات بحث هاش لاسم/قيمة العلامة لكل SourceFile. يتم تخزين ترتيب المفاتيح (ترتيب أعمدة CSV أو الترتيب في كائن JSON) كمرجع ARRAY في عنصر "_ordered_keys_" خاص بها في هذا الهاش.
