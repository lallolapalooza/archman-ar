idmap_rid(8)

الحزمة: samba

التراخيص: GPL-3.0-or-later

IDMAP_RID(8) أدوات إدارة النظام IDMAP_RID(8)

الاسم

idmap_rid - الواجهة الخلفية idmap_rid لـ Samba لـ Winbind

الوصف

توفر الواجهة الخلفية idmap_rid طريقة لاستخدام مخطط تعيين خوارزمي لتعيين UIDs/GIDs و SIDs. لا يلزم وجود قاعدة بيانات في هذه الحالة لأن التعيين حتمي.

حاليًا، يجب أن يكون هناك تكوين idmap صريح لكل نطاق يجب أن يستخدم الواجهة الخلفية idmap_rid، باستخدام نطاقات منفصلة.

ملاحظة: لا يمكن استخدام الواجهة الخلفية idmap_rid كواجهة خلفية افتراضية. يحتاج المرء عادةً إلى تعريف نطاق idmap افتراضي قابل للكتابة، باستخدام واجهة خلفية مثل tdb أو ldap يمكنها إنشاء معرفات يونكس، من أجل التمكن من تعيين SIDs المضمنة والنطاقات الأخرى، وأيضًا من أجل التمكن من إنشاء تعيينات المجموعات. انظر المثال أدناه.

خيارات IDMAP

range = low - high

يحدد نطاق uid و gid المتطابق المتاح الذي تكون الواجهة الخلفية مسؤولة عنه. لاحظ أن النطاق يعمل كمرشح. إذا كانت معرفات UID أو GID المحددة خوارزميًا تقع خارج النطاق، يتم تجاهلها ويتم التخلص من التعيين المقابل. الغرض منه هو تجنب تداخل UID/GID عرضي بين المعرفات المحلية وتلك المعرفة عن بعد.

base_rid = INTEGER

يحدد العدد الصحيح الأساسي المستخدم لبناء SIDs من UID أو GID، ولإعادة تأسيس UID أو GID الذي تم الحصول عليه من SID. هذا يعني أنه يتم تصفية SIDs ذات RID أقل من RID الأساسي. الافتراضي هو عدم تقييد RIDs المسموح بها على الإطلاق، أي قيمة base_rid تساوي 0.

استخدام هذا المعامل لم يعد مستحسنًا.

صيغ التعيين

يتم حساب معرف يونكس لـ RID بهذه الطريقة:

ID = RID - BASE_RID + LOW_RANGE_ID.

وبالمقابل، فإن صيغة حساب RID لمعرف يونكس معين هي:

RID = ID + BASE_RID - LOW_RANGE_ID.

أمثلة

يوضح هذا المثال كيفية تكوين نطاقين باستخدام idmap_rid، النطاق الرئيسي والنطاق الموثوق به، مع ترك مخطط تعيين id الافتراضي في tdb. يوضح المثال أيضًا استخدام المعامل base_rid للنطاق الموثوق به.

[global]
security = domain
workgroup = MAIN
idmap config * : backend        = tdb
idmap config * : range          = 1000000-1999999
idmap config MAIN : backend     = rid
idmap config MAIN : range       = 10000 - 49999
idmap config TRUSTED : backend  = rid
idmap config TRUSTED : range    = 50000 - 99999
idmap config TRUSTED : base_rid = 500000

المؤلف

تم إنشاء برنامج Samba الأصلي والأدوات المساعدة ذات الصلة بواسطة Andrew Tridgell. يتم تطوير Samba الآن بواسطة فريق Samba كمشروع مفتوح المصدر بنفس طريقة تطوير نواة Linux.
