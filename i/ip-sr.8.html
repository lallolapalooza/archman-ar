الحزمة: iproute2

التراخيص: GPL-2.0-or-later

IP-SR(8) Linux IP-SR(8)

اسم

ip sr - إدارة توجيه المقطع IPv6

ملخص


ip sr { أمر | مساعدة }

ip sr hmac show

ip sr hmac set معرف_المفتاح خوارزمية

ip sr tunsrc show

ip sr tunsrc set عنوان

الوصف

يُستخدم الأمر ip sr لتكوين معلمات توجيه المقطع IPv6 (SRv6) الداخلية.

تشمل هذه المعلمات الربط بين معرف مفتاح HMAC وخوارزمية التجزئة والسر التي ترتبط به، وعنوان IPv6 المستخدم كمصدر للحزم المغلفة.

يطلب الأمر ip sr hmac set "عبارة مرور" تنتهي بسطر جديد والتي سيتم استخدامها كسر HMAC لمعرف المفتاح المقابل. هذه "عبارة المرور" لا يتم توسيعها، وتُستخدم مباشرة كمفتاح HMAC. لذلك، يجب أن تحتوي على ما يكفي من الإنتروبيا لاستخدامها كمفتاح. على سبيل المثال، سيكون الاستخدام الصحيح هو استخدام عبارة مرور تم إنشاؤها باستخدام head -c 32 /dev/random | base64 -w 0.

عبارة مرور فارغة تزيل الربط.

الخوارزميات المدعومة حاليًا لـ ALGO هي sha1 و sha256.

إذا تم تعيين مصدر النفق إلى العنوان :: (وهو الافتراضي)، فسيتم تحديد عنوان واجهة الخروج. نظرًا لأن هذه العملية قد تعيق الأداء، فمن المستحسن تعيين عنوان غير افتراضي.

أمثلة

تكوين ربط HMAC لمعرف المفتاح 42 وخوارزمية التجزئة SHA-256

# ip sr hmac set 42 sha256

تعيين عنوان مصدر النفق إلى 2001:db8::1

# ip sr tunsrc set 2001:db8::1

أخطاء

ip sr hmac set لا توسع عبارة المرور.
