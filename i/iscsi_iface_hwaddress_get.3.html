iscsi_iface_hwaddress_get(3)

الحزمة: open-iscsi

التراخيص: GPL

iscsi_iface_hwaddress_get(3) دليل API iscsi_iface_hwaddress_get(3)

الاسم

iscsi_iface_hwaddress_get - استرداد عنوان الأجهزة لواجهة iSCSI المحددة

الخلاصة

const char * iscsi_iface_hwaddress_get (struct iscsi_iface *iface);

الوسائط

iface
مؤشر إلى 'struct iscsi_iface'. إذا كان هذا المؤشر NULL، فسيتم إنهاء برنامجك بتأكيد.

الوصف

استرداد عنوان الأجهزة لواجهة iSCSI المحددة.

الإرجاع

const char *. لا حاجة لتحرير هذه الذاكرة، سيتم تحرير الموارد بواسطة iscsi_session_free أو iscsi_sessions_free.
