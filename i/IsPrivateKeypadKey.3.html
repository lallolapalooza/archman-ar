IsPrivateKeypadKey(3)

الحزمة: libx11

التراخيص: MIT AND X11

IsCursorKey(3) وظائف XLIB IsCursorKey(3)

الاسم

IsCursorKey, IsFunctionKey, IsKeypadKey, IsMiscFunctionKey, IsModifierKey, IsPFKey, IsPrivateKeypadKey - وحدات ماكرو لتصنيف مفتاح المفاتيح (keysym).

الصيغة

int IsCursorKey(KeySym keysym);

int IsFunctionKey(KeySym keysym);

int IsKeypadKey(KeySym keysym);

int IsMiscFunctionKey(KeySym keysym);

int IsModifierKey(KeySym keysym);

int IsPFKey(KeySym keysym);

int IsPrivateKeypadKey(KeySym keysym);

الوسائط

keysym
يحدد مفتاح المفاتيح (KeySym) الذي سيتم اختباره.

الوصف

تقوم وحدة الماكرو IsCursorKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) المحدد هو مفتاح مؤشر.

تقوم وحدة الماكرو IsFunctionKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) هو مفتاح وظيفة.

تقوم وحدة الماكرو IsKeypadKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) المحدد هو مفتاح لوحة المفاتيح.

تقوم وحدة الماكرو IsMiscFunctionKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) المحدد هو مفتاح وظيفة متنوعة.

تقوم وحدة الماكرو IsModifierKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) المحدد هو مفتاح تعديل.

تقوم وحدة الماكرو IsPFKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) المحدد هو مفتاح PF.

تقوم وحدة الماكرو IsPrivateKeypadKey بإرجاع True إذا كان مفتاح المفاتيح (KeySym) المحدد هو مفتاح لوحة مفاتيح خاص بالبائع.
