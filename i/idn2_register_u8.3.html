idn2_register_u8(3)

الحزمة: libidn2

التراخيص: GPL2, LGPL3

idn2_register_u8(3) libidn2 idn2_register_u8(3)

الاسم

idn2_register_u8 - وظيفة API

الملخص

#include <idn2.h>

int idn2_register_u8(const uint8_t * ulabel, const uint8_t * alabel, uint8_t ** insertname, int flags);

المعاملات

const uint8_t * ulabel
سلسلة إدخال UTF-8 و Unicode NFC منتهية بصفر، أو NULL.
const uint8_t * alabel
سلسلة إدخال مشفرة بـ ACE (xn--) منتهية بصفر، أو NULL.
uint8_t ** insertname
متغير إخراج مخصص حديثًا بالاسم المراد تسجيله في DNS.
int flags
idn2_flags اختيارية لتعديل السلوك.

الوصف

قم بإجراء تحويل سلسلة التسجيل IDNA2008 على تسمية المجال ulabel و alabel ، كما هو موضح في القسم 4 من RFC 5891. لاحظ أن ulabel الإدخال يجب أن يكون مشفرًا بـ UTF-8 وأن يكون بتنسيق Unicode NFC.

مرر IDN2_NFC_INPUT في flags لتحويل إدخال ulabel إلى تنسيق NFC قبل المعالجة الإضافية.

يوصى بتوفير كل من ulabel و alabel لتحسين التحقق من الأخطاء، ولكن توفير أحدهما فقط سيعمل. يعد تمرير alabel فقط أفضل من ulabel فقط. راجع RFC 5891 القسم 4 لمزيد من المعلومات.

بعد الإصدار 0.11: قد يكون insertname NULL لاختبار تحويل src دون تخصيص ذاكرة.

القيم المرجعة

عند التحويل الناجح، يتم إرجاع IDN2_OK، عندما لا يتطابق ulabel و alabel المعطيان، يتم إرجاع IDN2_UALABEL_MISMATCH، عندما تكون أي من تسميات الإدخال طويلة جدًا، يتم إرجاع IDN2_TOO_BIG_LABEL، عندما لا يبدو alabel تسمية A صحيحة، يتم إرجاع IDN2_INVALID_ALABEL، أو يتم إرجاع رمز خطأ آخر.
