io_uring_prep_send(3) - Linux manual pages

NAME

io_uring_prep_send, io_uring_prep_sendmsg, io_uring_prep_sendto - prepare a send or sendto operation

SYNOPSIS

#include <liburing.h>

void io_uring_prep_send(struct io_uring_sqe *sqe, int sockfd,
                        const void *buf, size_t len, int flags);
void io_uring_prep_sendmsg(struct io_uring_sqe *sqe, int sockfd,
                           const struct msghdr *msg, unsigned int flags);
void io_uring_prep_sendto(struct io_uring_sqe *sqe, int sockfd, const void *buf,
                          size_t len, int flags, const struct sockaddr *dest_addr,
                          socklen_t dest_len);

DESCRIPTION

These functions prepare an asynchronous send operation for the given submission queue entry (SQE).

The `io_uring_prep_send` function prepares a standard send operation. It will send `len` bytes from the buffer pointed to by `buf` over the socket file descriptor `sockfd`. The `flags` are the same as for the standard send() system call.

The `io_uring_prep_sendmsg` function prepares a sendmsg operation. It sends the message described by `msg` over the socket file descriptor `sockfd`. The `flags` are the same as for the standard sendmsg() system call.

The `io_uring_prep_sendto` function prepares a sendto operation. It will send `len` bytes from the buffer pointed to by `buf` over the socket file descriptor `sockfd` to the destination address specified by `dest_addr` and `dest_len`. The `flags` are the same as for the standard sendto() system call.

RETURN VALUE

None.

ERRORS

The errors returned are the same as for the corresponding system calls (send, sendmsg, sendto). In particular, see EAGAIN and EWOULDBLOCK if the socket is non-blocking and the send buffer is full.
