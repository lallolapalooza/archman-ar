ip-token(8) لينكس ip-token(8)

الاسم

ip-token - دعم معرف الواجهة المرمّزة

الموجز


ip token { أمر | help }

ip token set TOKEN dev DEV

ip token del dev DEV

ip token get [ dev DEV ]

ip token [ list ]

الوصف

يُستخدم دعم معرف الواجهة المرمّزة لـ IPv6 لتعيين عناوين جزء المضيف المعروفة للعقد مع الاستمرار في الحصول على بادئة شبكة عالمية من إعلانات الموجه. الهدف الأساسي للمعّرفات المرمّزة هو منصات الخادم حيث يتم تكوين العناوين يدويًا عادةً، بدلاً من استخدام DHCPv6 أو SLAAC. باستخدام المعّرفات المرمّزة، لا يزال بإمكان المضيفين تحديد بادئة شبكتهم باستخدام SLAAC، ولكن يمكن إعادة ترقيمهم تلقائيًا بسهولة أكبر في حالة تغيير بادئة شبكتهم [1]. يتم وصف المعّرفات المرمّزة لـ IPv6 في المسودة [1]: <draft-chown-6man-tokenised-ipv6-identifiers-02>.

ip token set - تعيين رمز الواجهة

تعيين رمز الواجهة للنواة.

TOKEN
رمز معرف الواجهة.
dev DEV
واجهة الشبكة.

ip token del - حذف رمز الواجهة

حذف رمز الواجهة من النواة.

dev DEV
واجهة الشبكة.

ip token get - الحصول على رمز الواجهة من النواة

عرض معرف واجهة مرمّز لجهاز شبكة معين. **الوسائط**: تتوافق مع وسائط ip token set ولكن يجب ترك TOKEN.

ip token list - سرد جميع رموز الواجهات

سرد جميع معّرفات الواجهات المرمّزة لواجهات الشبكة من النواة.
