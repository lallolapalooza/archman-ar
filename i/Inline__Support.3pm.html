Inline__Support(3pm)

الحزمة: perl-inline

التراخيص: GPL, PerlArtistic

Inline::Support(3) توثيق بيرل مساهم به Inline::Support(3)

اسم

Inline-Support - معلومات الدعم لـ Inline.pm والوحدات ذات الصلة.

وصف

تحتوي هذه الوثيقة على جميع معلومات الدعم الحديثة لـ "Inline.pm" ووحدات دعم لغات Inline (ILSMs) المعترف بها المتاحة على CPAN.

اللغات المدعومة

اللغة الأكثر أهمية التي تدعمها Inline هي "C". وذلك لأن Perl نفسها مكتوبة بلغة "C". من خلال منح نصوص Perl الخاصة بك الوصول إلى "C"، فإنك تمنحها فعليًا وصولًا إلى جميع التفاصيل الداخلية الرائعة لـ Perl. (تنبيه للمبرمج :-)

حتى كتابة هذه السطور، تدعم Inline أيضًا:

  • C++
  • Java
  • Python
  • Tcl
  • Assembly
  • CPR
  • وحتى Inline::Foo! :)

المشاريع التي أود رؤيتها تحدث في عام 2001 هي:

  • Fortran
  • Ruby
  • Lisp
  • Guile
  • Bash
  • Perl4

المنصات المدعومة

يجب أن يعمل "Inline::C" في أي مكان يمكن فيه تثبيت وحدات امتداد CPAN (تلك التي تستخدم XS)، باستخدام تنسيق التثبيت النموذجي:

perl Makefile.PL
make
make test
make install

تم اختباره على العديد من أنواع Unix و Windows.

ملاحظة: يتطلب "Inline::C" Perl 5.005 أو أعلى لأن "Parse::RecDescent" يتطلب ذلك. (شيء يتعلق بالمشغل "qr")

تم اختبار Inline بنجاح في وقت أو آخر على المنصات التالية:

  • Linux
  • Solaris
  • SunOS
  • HPUX
  • AIX
  • FreeBSD
  • OpenBSD
  • BeOS
  • OS X
  • WinNT
  • Win2K
  • WinME
  • Win98
  • Cygwin

اختبارات Microsoft تستحق شرحًا إضافيًا. استخدمت ما يلي:

  • Windows NT 4.0 (حزمة الخدمة 6)
  • Perl 5.005_03 (ActiveState build 522)
  • MS Visual C++ 6.0
  • أداة `make` المسماة "nmake" (موزعة مع Visual C++)

"Inline::C" يجلب كل تكويناته الأساسية (بما في ذلك أي أداة "make" سيتم استخدامها) من "Config.pm". نظرًا لأن إصدار MSWin32 الخاص بك من Perl جاء على الأرجح من ActiveState (كتوزيع ثنائي) فإن "Config.pm" سيشير إلى أن "nmake" هو أداة "make" الخاصة بالنظام. وذلك لأن ActiveState تستخدم Visual C++ لتجميع Perl.

لتثبيت "Inline.pm" (أو أي وحدة CPAN أخرى) على MSWin32 مع Visual C++، استخدم ما يلي:

perl Makefile.PL
nmake
nmake test
nmake install

تم أيضًا جعل Inline يعمل مع Mingw32/gcc على جميع منصات Windows. هذا مترجم مجاني لنظام Windows. يجب عليك أيضًا استخدام perl تم تجميعه بواسطة هذا المترجم.

تم إجراء اختبار "Cygwin" على جهاز Windows 98 باستخدام برنامج طبقة منفذ Unix/Win32 الخاص بـ Cygwin من Cygnus. تم أيضًا تجميع ثنائي "perl" على هذا الجهاز باستخدام مجموعة أدوات Cygwin ("gcc"). هذا البرنامج متاح مجانًا من http://sources.redhat.com/cygwin/

إذا تمكنت من تشغيل Inline على منصة جديدة، فيرجى إرسال بريد إلكتروني إلي. إذا لم ينجح الأمر، فأخبرني بذلك أيضًا وسأرى ما يمكن فعله.

انظر أيضًا

للحصول على معلومات عامة حول Inline انظر Inline.

للحصول على معلومات حول استخدام Inline مع C انظر Inline::C.

للحصول على برامج نموذجية تستخدم Inline مع C انظر Inline::C-Cookbook.

للحصول على معلومات حول كتابة وحدة دعم لغة Inline الخاصة بك، انظر Inline-API.

قائمة بريد Inline هي inline@perl.org

للاشتراك، أرسل بريدًا إلكترونيًا إلى inline-subscribe@perl.org
