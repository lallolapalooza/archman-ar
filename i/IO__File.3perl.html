IO::File(3perl) دليل مبرمجي بيرل IO::File(3perl)

الاسم

IO::File - توفير دوال كائنية لمقابض الملفات

الملخص

use IO::File;
my $fh = IO::File->new();
if ($fh->open("< file")) {
    print <$fh>;
    $fh->close;
}
my $fh = IO::File->new("> file");
if (defined $fh) {
    print $fh "bar\n";
    $fh->close;
}
my $fh = IO::File->new("file", "r");
if (defined $fh) {
    print <$fh>;
    undef $fh;       # يغلق الملف تلقائيًا
}
my $fh = IO::File->new("file", O_WRONLY|O_APPEND);
if (defined $fh) {
    print $fh "corge\n";
    my $pos = $fh->getpos;
    $fh->setpos($pos);
    undef $fh;       # يغلق الملف تلقائيًا
}
autoflush STDOUT 1;

الوصف

"IO::File" يرث من "IO::Handle" و "IO::Seekable". توسع هذه الفئات بدوال خاصة بمقابض الملفات.

الباني

new ( FILENAME [,MODE [,PERMS]] )
ينشئ "IO::File". إذا تلقى أي معاملات، يتم تمريرها إلى الدالة "open"؛ إذا فشل الفتح، يتم تدمير الكائن. وإلا، يتم إعادته إلى المتصل.
new_tmpfile
ينشئ "IO::File" مفتوح للقراءة/الكتابة على ملف مؤقت تم إنشاؤه حديثًا. على الأنظمة التي يكون فيها ذلك ممكنًا، يكون الملف المؤقت مجهول الهوية (أي يتم إلغاء ربطه بعد الإنشاء، ولكن يتم الاحتفاظ به مفتوحًا). إذا لم يكن من الممكن إنشاء أو فتح الملف المؤقت، يتم تدمير كائن "IO::File". وإلا، يتم إعادته إلى المتصل.

الدوال

open( FILENAME [,MODE [,PERMS]] )
open( FILENAME, IOLAYERS )
تقبل "open" معاملًا واحدًا أو اثنين أو ثلاثة. بمعامل واحد، هو مجرد واجهة أمامية للدالة المدمجة "open". بمعاملين أو ثلاثة، المعامل الأول هو اسم ملف قد يتضمن مسافات بيضاء أو أحرفًا خاصة أخرى، والمعامل الثاني هو وضع الفتح، اختياريًا متبوعًا بقيمة إذن الملف.

إذا تلقت "IO::File::open" سلسلة وضع بيرل (">"، "+<"، إلخ) أو سلسلة وضع ANSI C fopen() ("w"، "r+"، إلخ)، فإنها تستخدم عامل التشغيل الأساسي لـ "open" في بيرل (ولكنها تحمي أي أحرف خاصة).

إذا تلقت "IO::File::open" وضعًا رقميًا، فإنها تمرر هذا الوضع وقيمة الأذونات الاختيارية إلى عامل التشغيل "sysopen" في بيرل. الأذونات الافتراضية هي 0666.

إذا تلقت "IO::File::open" وضعًا يتضمن الحرف ":"، فإنها تمرر جميع المعاملات الثلاث إلى عامل التشغيل ذي المعاملات الثلاثة "open".

للراحة، تصدّر "IO::File" ثوابت O_XXX من وحدة Fcntl، إذا كانت هذه الوحدة متاحة.

ملاحظة

قد تقوم بعض أنظمة التشغيل بإجراء IO::File::new() أو IO::File::open() على دليل دون أخطاء. هذا السلوك غير محمول وغير مقترح للاستخدام. يُقترح استخدام opendir() و readdir() أو "IO::Dir" بدلاً من ذلك.
