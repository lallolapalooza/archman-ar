inputattach(1)

الحزمة: joyutils

التراخيص: GPL

NAME

inputattach - إرفاق أجهزة الإدخال إلى مدخلات Linux

SYNOPSIS

inputattach [-d] [-n] [-q] [-v] [-b bus] [-p product] [-s vendor] [-t type] [-u usb_device] [-i input_device] [-o output_device]

DESCRIPTION

يقوم الأمر inputattach بربط جهاز إدخال USB معين، أو جهاز USB محدد بواسطة معرف البائع/المنتج/الحافلة، أو جهاز USB متصل عبر منفذ معين، بجهاز إدخال Linux (مثل لوحة المفاتيح أو الماوس).

عندما يتم تشغيل inputattach دون أي خيارات، فإنه سيقوم بإرفاق جميع أجهزة USB التي يتعرف عليها كنواة Linux.

OPTIONS

-d
فصل جهاز الإدخال بدلاً من إرفاقه.
-n
لا تعرض قائمة الأجهزة المرفقة.
-q
وضع الهدوء. لا تعرض أي مخرجات.
-v
وضع المطوّل. يعرض معلومات مفصلة حول ما يقوم به البرنامج.
-b bus
محدد الحافلة.
-p product
معرف المنتج.
-s vendor
معرف البائع.
-t type
نوع جهاز الإدخال (مثل keyboard أو mouse).
-u usb_device
معرف جهاز USB.
-i input_device
مسار جهاز الإدخال Linux (على سبيل المثال، /dev/input/event0).
-o output_device
مسار جهاز الإخراج Linux (على سبيل المثال، /dev/console).
