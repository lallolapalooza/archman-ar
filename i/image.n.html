image(n)

الحزمة: tk

التراخيص: TCL

image(n) أوامر Tk المضمنة image(n)

الاسم

image - إنشاء ومعالجة الصور

الملخص

image option ?arg arg ...?

الوصف

يُستخدم الأمر image لإنشاء الصور وحذفها والاستعلام عنها. يمكن أن يأخذ عدة أشكال مختلفة، اعتمادًا على الوسيط option. الأشكال القانونية هي:

image create type ?name? ?option value ...?
ينشئ صورة جديدة وأمرًا بنفس الاسم ويعيد اسمه. يحدد type نوع الصورة، والذي يجب أن يكون واحدًا من الأنواع المعرفة حاليًا (مثل bitmap). يحدد name اسم الصورة؛ إذا تم حذفه، فإن Tk يختار اسمًا بالشكل imagex، حيث x هو عدد صحيح. قد يكون هناك أي عدد من أزواج option-value، والتي توفر خيارات تكوين للصورة الجديدة. يتم تعريف مجموعة الخيارات القانونية بشكل منفصل لكل نوع صورة؛ انظر أدناه للحصول على تفاصيل حول خيارات أنواع الصور المضمنة. إذا كانت هناك صورة موجودة بالاسم المحدد، فسيتم استبدالها بالصورة الجديدة وسيتم إعادة عرض جميع مثيلات تلك الصورة بالمحتويات الجديدة. من المهم ملاحظة أن أمر الصورة سيقوم بالكتابة فوق أي إجراء قد يكون محددًا حاليًا بالاسم المعطى، لذا اختر الاسم بحكمة. يوصى باستخدام مساحة اسم منفصلة لأسماء الصور (مثل، ::img::logo، ::img::large).
image delete ?name name ...?
يحذف كل صورة من الصور المسماة ويعيد سلسلة فارغة. إذا كانت هناك مثيلات للصور معروضة في أدوات، فلن يتم حذف الصور فعليًا حتى يتم تحرير جميع المثيلات. ومع ذلك، سيتم إسقاط الارتباط بين المثيلات ومدير الصور. ستحتفظ المثيلات الموجودة بأحجامها ولكن ستعاد عرضها كمناطق فارغة. إذا تم إعادة إنشاء صورة محذوفة باستخدام استدعاء آخر لـ image create، فستستخدم المثيلات الموجودة الصورة الجديدة.
image height name
يعيد سلسلة عشرية تعطي ارتفاع الصورة name بالبكسل.
image inuse name
يعيد قيمة منطقية تشير إلى ما إذا كانت الصورة المعطاة بالاسم name قيد الاستخدام بواسطة أي أدوات.
image names
يعيد قائمة تحتوي على أسماء جميع الصور الموجودة.
image type name
يعيد نوع الصورة name (قيمة الوسيط type إلى image create عند إنشاء الصورة).
image types
يعيد قائمة عناصرها هي جميع أنواع الصور الصالحة (أي، جميع القيم التي يمكن توفيرها للوسيط type إلى image create).
image width name
يعيد سلسلة عشرية تعطي عرض الصورة name بالبكسل.

قد تكون العمليات الإضافية (مثل كتابة الصورة إلى ملف) متاحة كأوامر فرعية لأمر مثيل الصورة. راجع صفحة الدليل لنوع الصورة المحدد للحصول على التفاصيل.

أنواع الصور المضمنة

أنواع الصور التالية معرفة بواسطة Tk بحيث تكون متاحة في أي تطبيق Tk. قد تحدد التطبيقات أو الإضافات الفردية أنواعًا إضافية.

bitmap
تعرض كل بكسل في الصورة لونًا أماميًا، أو لونًا خلفيًا، أو لا شيء. راجع دليل bitmap لمزيد من المعلومات.
photo
يعرض مجموعة متنوعة من الصور كاملة الألوان، باستخدام التمويه لتقريب الألوان على الشاشات ذات القدرات اللونية المحدودة. راجع دليل photo لمزيد من المعلومات.
