IP-NTABLE(8) لينكس IP-NTABLE(8)

الاسم

ip-ntable - تهيئة جدول الجيران

ملخص


ip [ خيارات ] ntable { أمر | help }

ip ntable change name اسم [ dev جهاز ] [ thresh1 قيمة ] [ thresh2 قيمة ] [ thresh3 قيمة ] [ gc_int مللي ثانية ] [ base_reachable مللي ثانية ] [ retrans مللي ثانية ] [ gc_stale مللي ثانية ] [ delay_probe مللي ثانية ] [ queue طول ] [ app_probs قيمة ] [ ucast_probes قيمة ] [ mcast_probes قيمة ] [ mcast_reprobes قيمة ] [ anycast_delay مللي ثانية ] [ proxy_delay مللي ثانية ] [ proxy_queue طول ] [ locktime مللي ثانية ]

ip ntable show [ dev جهاز ] [ name اسم ]

الوصف

ip ntable يتحكم في معلمات جداول الجيران.

ip ntable show - عرض جداول جيران IP

يعرض هذا الأمر معلمات وإحصائيات جدول الجيران.

dev جهاز
عرض الجدول المرتبط بهذا الجهاز فقط.
name اسم
يعرض الجدول بالاسم المحدد فقط.

ip ntable change - تعديل معلمة الجدول

يسمح هذا الأمر بتعديل معلمات الجدول مثل المؤقتات وأطوال قوائم الانتظار.

name اسم
اسم الجدول المراد تعديله.
dev جهاز
اسم الجهاز لتعديل قيم الجدول.

أمثلة

ip ntable show dev eth0

يعرض معلمات جدول الجيران (ARP لـ IPv4 و ndisc لـ IPv6) على الجهاز eth0.

ip ntable change name arp_cache queue 8 dev eth0

يغير عدد الحزم التي يتم وضعها في قائمة الانتظار أثناء حل العنوان من القيمة الافتراضية (3) إلى 8 حزم.
