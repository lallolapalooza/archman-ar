NAME

isql - Interactive SQL shell for unixODBC

SYNOPSIS

isql [options] [dsn [uid [pwd]]]

DESCRIPTION

The isql program is a command-line interface to the unixODBC driver manager. It allows you to connect to any ODBC data source defined in your ODBC configuration files and execute SQL statements.

ARGUMENTS

dsn
The Data Source Name (DSN) to connect to. If not specified, isql will prompt for it.
uid
The user ID to use for the connection. If not specified, isql will prompt for it.
pwd
The password to use for the connection. If not specified, isql will prompt for it.

OPTIONS

-v
Verbose mode. Prints connection information and diagnostic messages.
-b
Batch mode. Reads commands from standard input and executes them without prompting.
-f file
Read commands from the specified file.
-x keyword=value
Set an ODBC connection attribute.
-L
List available data sources.
-?
Display help message.

COMMANDS

Within the isql interactive shell, the following commands are available:

connect [dsn [uid [pwd]]]
Connect to a data source.
disconnect
Disconnect from the current data source.
quit
Exit isql.
help
Display help message.
\command
Execute a shell command.
SQL statement
Execute an SQL statement.

EXAMPLES

Connect to a data source named "mydb" with user "myuser" and password "mypass":

isql mydb myuser mypass

Connect interactively and list available data sources:

isql -L

Execute a SQL query from a file:

isql -f query.sql mydb myuser mypass

TROUBLESHOOTING

If you encounter connection problems, ensure that your DSN is correctly defined in /etc/odbc.ini or $HOME/.odbc.ini, and that the appropriate ODBC driver is installed and configured.

Use the -v option to enable verbose output for more detailed diagnostics.

Consult the unixODBC Administrator Manual for further assistance.

FILES

/etc/odbc.ini

ملف التكوين الذي يحتوي على تعريفات أسماء مصادر البيانات (DSN) على مستوى النظام. راجع odbc.ini(5) لمزيد من المعلومات.

$HOME/.odbc.ini

ملف التكوين الذي يحتوي على تعريفات أسماء مصادر البيانات (DSN) الخاصة بالمستخدم. راجع odbc.ini(5) لمزيد من المعلومات.
