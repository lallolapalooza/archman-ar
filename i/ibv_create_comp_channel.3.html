IBV_CREATE_COMP_CHANNEL(3) دليل مبرمج Libibverbs IBV_CREATE_COMP_CHANNEL(3)

الاسم

ibv_create_comp_channel, ibv_destroy_comp_channel - إنشاء أو تدمير قناة أحداث الإكمال

الملخص

#include <infiniband/verbs.h>

struct ibv_comp_channel *ibv_create_comp_channel(struct ibv_context
                                                 *context);

int ibv_destroy_comp_channel(struct ibv_comp_channel *channel);

الوصف

ibv_create_comp_channel() تنشئ قناة أحداث إكمال لسياق جهاز RDMA context.

ibv_destroy_comp_channel() تدمر قناة أحداث الإكمال channel.

قيمة الإرجاع

ibv_create_comp_channel() ترجع مؤشرًا إلى قناة أحداث الإكمال المنشأة، أو NULL إذا فشل الطلب.

ibv_destroy_comp_channel() ترجع 0 عند النجاح، أو قيمة errno عند الفشل (مما يشير إلى سبب الفشل).

ملاحظات

تعتبر "قناة الإكمال" تجريدًا قدمته مكتبة libibverbs ولا يوجد في مواصفات أفعال بنية InfiniBand أو مواصفات أفعال بروتوكول RDMA. قناة الإكمال هي أساسًا واصف ملف يستخدم لتسليم إشعارات الإكمال إلى عملية مساحة المستخدم. عندما يتم إنشاء حدث إكمال لطابور إكمال (CQ)، يتم تسليم الحدث عبر قناة الإكمال المرفقة بهذا CQ. قد يكون هذا مفيدًا لتوجيه أحداث الإكمال إلى خيوط معالجة مختلفة باستخدام قنوات إكمال متعددة.

ibv_destroy_comp_channel() تفشل إذا كانت أي CQs لا تزال مرتبطة بقناة أحداث الإكمال التي يتم تدميرها.
