IP-IOAM(8) Linux IP-IOAM(8)

الاسم

ip ioam - IPv6 In-situ OAM (IOAM)

ملخص


ip ioam { الأمر | help }

ip ioam namespace show

ip ioam namespace add المعرف [ data DATA32 ] [ wide DATA64 ]

ip ioam namespace del المعرف

ip ioam schema show

ip ioam schema add المعرف البيانات

ip ioam schema del المعرف

ip ioam namespace set المعرف schema { المعرف | none }

ip ioam monitor

الوصف

يُستخدم الأمر ip ioam لتكوين المعلمات الداخلية لـ IPv6 In-situ OAM (IOAM6)، وتحديداً مساحات أسماء IOAM والمخططات الخاصة بها.

تتضمن هذه المعلمات أيضاً الربط بين مساحة أسماء IOAM ومخطط IOAM.

يعرض الأمر ip ioam monitor بيانات IOAM المستلمة.

أمثلة

تكوين مساحة أسماء IOAM (المعرف = 1) مع كل من البيانات (32 بت) والبيانات الواسعة (64 بت)

# ip ioam namespace add 1 data 0xdeadbeef wide 0xcafec0caf00dc0de

ربط مخطط IOAM موجود (المعرف = 7) بمساحة أسماء IOAM موجودة (المعرف = 1)

# ip ioam namespace set 1 schema 7
