IPC__Run__Win32Process(3pm)

الحزمة: perl-ipc-run

التراخيص: GPL, PerlArtistic

IPC::Run::Win32Process(3) وثائق Perl المساهمة من المستخدم IPC::Run::Win32Process(3)

الاسم

IPC::Run::Win32Process -- توصيل سطور الأوامر غير القياسية عبر IPC::Run.

ملخص

use File::Spec ();
use IPC::Run qw(run);
use IPC::Run::Win32Process ();
use Win32 ();
$find_exe = File::Spec->catfile(Win32::GetFolderPath(Win32::CSIDL_SYSTEM),
                                'find.exe');
run(IPC::Run::Win32Process->new($ENV{COMSPEC}, q{cmd.exe /c echo ""}),
    '|', IPC::Run::Win32Process->new($find_exe, q{find_exe """"""}),
    '>', \$out);

الوصف

تسهل هذه الفئة تنفيذ برامج Windows التي لا تستخدم قواعد تحليل سطر الأوامر القياسية https://docs.microsoft.com/en-us/cpp/cpp/main-function-command-line-args#parsing-c-command-line-arguments. من أبرز البرامج التي لديها قواعد غير قياسية cmd.exe و cscript.exe وبرامج Cygwin التي يتم استدعاؤها من برامج غير Cygwin. ستستخدم IPC::Run السلسلتين، حرفياً، كوسيطات lpApplicationName و lpCommandLine للدالة CreateProcessA(). يوفر هذا تحكماً غير مفلتر في سطر أوامر العملية الفرعية.

الوظائف والطرق

new
IPC::Run::Win32Process->new( $lpApplicationName, $lpCommandLine );
IPC::Run::Win32Process->new( $ENV{COMSPEC}, q{cmd.exe /c echo ""} );
