IBV_ALLOC_PD(3) دليل مبرمج Libibverbs IBV_ALLOC_PD(3)

الاسم

ibv_alloc_pd, ibv_dealloc_pd - تخصيص أو إلغاء تخصيص نطاق حماية (PDs)

الملخص

#include <infiniband/verbs.h>

struct ibv_pd *ibv_alloc_pd(struct ibv_context *context);

int ibv_dealloc_pd(struct ibv_pd *pd);

الوصف

ibv_alloc_pd() يقوم بتخصيص نطاق حماية (PD) لسياق جهاز RDMA context.

ibv_dealloc_pd() يقوم بإلغاء تخصيص نطاق الحماية pd.

قيمة الإرجاع

ibv_alloc_pd() ترجع مؤشرًا إلى نطاق الحماية المخصص، أو NULL إذا فشل الطلب.

ibv_dealloc_pd() ترجع 0 عند النجاح، أو قيمة errno عند الفشل (مما يشير إلى سبب الفشل).

ملاحظات

ibv_dealloc_pd() قد تفشل إذا كان أي مورد آخر لا يزال مرتبطًا بنطاق الحماية الذي يتم تحريره.
