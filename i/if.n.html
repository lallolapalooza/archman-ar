if(n)

الحزمة: tcl

التراخيص: TCL

if(n) أوامر Tcl المضمنة if(n)

الاسم

if - تنفيذ نصوص برمجية شرطيًا

الملخص

if expr1 ?then? body1 elseif expr2 ?then? body2 elseif ... ?else? ?bodyN?

الوصف

يقوم الأمر if بتقييم expr1 كتعبير (بنفس الطريقة التي يقوم بها expr بتقييم حجته). يجب أن تكون قيمة التعبير قيمة منطقية (قيمة رقمية، حيث 0 خاطئة وأي شيء آخر صحيح، أو قيمة نصية مثل true أو yes للصحيح و false أو no للخطأ)؛ إذا كانت صحيحة، فسيتم تنفيذ body1 عن طريق تمريرها إلى مترجم Tcl. بخلاف ذلك، يتم تقييم expr2 كتعبير وإذا كان صحيحًا، فسيتم تنفيذ body2، وهكذا. إذا لم تقم أي من التعبيرات بتقييم صحيح، فسيتم تنفيذ bodyN. الوسيطان then و else هما "كلمات ضوضاء" اختيارية لجعل الأمر أسهل للقراءة. يمكن أن يكون هناك أي عدد من عبارات elseif، بما في ذلك الصفر. يمكن أيضًا حذف BodyN طالما تم حذف else أيضًا. القيمة المرجعة من الأمر هي نتيجة نص الجسم البرمجي الذي تم تنفيذه، أو سلسلة فارغة إذا لم يكن أي من التعبيرات غير صفري ولم يكن هناك bodyN.

أمثلة

شرط بسيط:

if {$vbl == 1} { puts "vbl is one" }

مع بند else:

if {$vbl == 1} {
    puts "vbl is one"
} else {
    puts "vbl is not one"
}

مع بند elseif أيضًا:

if {$vbl == 1} {
    puts "vbl is one"
} elseif {$vbl == 2} {
    puts "vbl is two"
} else {
    puts "vbl is not one or two"
}

تذكر، يمكن أن تكون التعبيرات متعددة الأسطر، ولكن في هذه الحالة قد يكون من الجيد استخدام الكلمة المفتاحية الاختيارية then للتوضيح:

if {
    $vbl == 1
    || $vbl == 2
    || $vbl == 3
} then {
    puts "vbl is one, two or three"
}
