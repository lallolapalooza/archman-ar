ip-stats(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

IP-STATS(8) Linux IP-STATS(8)

الاسم

ip-stats - إدارة وعرض إحصائيات الواجهة

الاختصار


ip stats { الأمر | help }

ip stats show [ dev DEV ] [ group GROUP [ subgroup SUBGROUP [ suite SUITE ] ... ] ... ] ...

ip stats set dev DEV l3_stats { on | off }

الوصف

ip stats set
يُستخدم لتبديل ما إذا كانت مجموعة معينة من إحصائيات الأجهزة (HW) تُجمع على جهاز شبكة (netdevice) معين. مجموعات الإحصائيات التالية مدعومة:


l3_stats إحصائيات الطبقة الثالثة (L3) تعكس حركة المرور التي تحدث في جهاز الأجهزة (HW) على كائن يتوافق مع جهاز الشبكة (netdevice) البرمجي.

ip stats show
يُستخدم لعرض الإحصائيات على جهاز شبكة (netdevice) معين، أو لتفريغ الإحصائيات عبر جميع أجهزة الشبكة (netdevices). افتراضيًا، يتم طلب جميع الإحصائيات. من الممكن تصفية الإحصائيات المطلوبة باستخدام الكلمات المفتاحية group و subgroup.

من الممكن تحديد مجموعات متعددة، أو مجموعات فرعية متعددة لمجموعة واحدة. عندما لا يتم توفير مجموعات فرعية لمجموعة، يتم طلب جميع المجموعات الفرعية.

المجموعات التالية معترف بها:

group link - إحصائيات الربط. نفس المجموعة التي تعرضها "ip -s link show".

group offload - مجموعة تحتوي على عدد من الإحصائيات الموجهة للأجهزة (HW). انظر أدناه للمجموعات الفرعية الفردية داخل هذه المجموعة.

group xstats - إحصائيات موسعة. تحدد مجموعة فرعية نوع جهاز الشبكة (netdevice) لعرض الإحصائيات الخاصة به.

group xstats_slave - إحصائيات موسعة للتابع (slave) لجهاز شبكة (netdevice) من نوع معين. تحدد مجموعة فرعية نوع جهاز الشبكة الرئيسي (master).

group afstats - مجموعة لإحصائيات أجهزة الشبكة الخاصة بنطاق العنوان (address-family).

group offload المجموعات الفرعية:

subgroup cpu_hit - مجموعة إحصائيات cpu_hit مفيدة على أجهزة الشبكة (netdevices) الخاصة بالأجهزة (HW). تعكس إحصائيات link على هذه الأجهزة كلاً من حركة المرور في مسار البيانات للأجهزة (HW) والبرامج. ثم تعكس إحصائيات cpu_hit فقط حركة مرور مسار بيانات البرامج.

subgroup hw_stats_info - هذه المجموعة لا تتضمن إحصائيات حركة المرور، بل تتواصل مع حالة الإحصائيات الأخرى. من خلال هذه المجموعة الفرعية، من الممكن اكتشاف ما إذا كانت إحصائية معينة قد تم تمكينها، وعندما كانت كذلك، ما إذا كان أي مشغل جهاز (device driver) قد قام بتكوين جهازه لجمع هذه الإحصائيات. على سبيل المثال، تم تمكين l3_stats في الحالة التالية، ولكن لم يقم أي مشغل جهاز بتثبيتها:

# ip stats show dev swp1 group offload subgroup hw_stats_info
56: swp1: group offload subgroup hw_stats_info
l3_stats on used off

بعد إضافة عنوان L3 إلى جهاز الشبكة، سيتم تثبيت العداد:

# ip addr add dev swp1 192.0.2.1/28
# ip stats show dev swp1 group offload subgroup hw_stats_info
56: swp1: group offload subgroup hw_stats_info
l3_stats on used on

subgroup l3_stats - تعكس هذه الإحصائيات حركة مرور الطبقة الثالثة (L3) التي تحدث في الأجهزة (HW) على كائن يتوافق مع جهاز الشبكة (netdevice). لاحظ أن هذه المجموعة معطلة افتراضيًا وتحتاج إلى تمكينها أولاً من خلال ip stats set.

على سبيل المثال:

# ip stats show dev swp2.200 group offload subgroup l3_stats
112: swp2.200: group offload subgroup l3_stats on used on
RX: bytes packets errors dropped mcast
8900 72 2 0 3
TX: bytes packets errors dropped
7176 58 0 0

لاحظ كيف أن معلومات l3_stats_info للمجموعة المحددة هي أيضًا جزء من التفريغ.

group xstats و group xstats_slave المجموعات الفرعية:

subgroup bridge - إحصائيات متنوعة على الجسور (bridges) وتوابعها (slaves).

suite stp - إحصائيات STP
suite mcast - إحصائيات IGMP / MLD
suite vlan - إحصائيات حركة المرور لكل VLAN

subgroup bond [ suite 802.3ad ] - إحصائيات حركة مرور LACP على أجهزة bond وتوابعها.

group afstats المجموعات الفرعية:

subgroup mpls - إحصائيات حركة مرور MPLS التي تظهر على جهاز الشبكة (netdevice). على سبيل المثال:

# ip stats show dev veth01 group afstats subgroup mpls
3: veth01: group afstats subgroup mpls
RX: bytes packets errors dropped noroute
0 0 0 0 0
TX: bytes packets errors dropped
216 2 0 0

أمثلة

# ip stats set dev swp1 l3_stats on

يُمكّن جمع إحصائيات الطبقة الثالثة (L3) للأجهزة (HW) على swp1.

# ip stats show group offload

يعرض جميع إحصائيات التفريغ (offload) على جميع أجهزة الشبكة (netdevices).

# ip stats show dev swp1 group link

يعرض إحصائيات الربط (link) على جهاز الشبكة المحدد.
