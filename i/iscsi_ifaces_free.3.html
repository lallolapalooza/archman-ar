iscsi_ifaces_free(3)

الحزمة: open-iscsi

التراخيص: GPL

iscsi_ifaces_free(3) دليل API iscsi_ifaces_free(3)

الاسم

iscsi_ifaces_free - تحرير ذاكرة مصفوفة المؤشرات 'struct iscsi_iface'

الملخص

void iscsi_ifaces_free (struct iscsi_iface **ifaces, uint32_t iface_count);

الوسائط

ifaces
مؤشر لمصفوفة مؤشرات 'struct iscsi_iface'.
iface_count
uint32_t، حجم مصفوفة مؤشرات 'struct iscsi_iface'.

الوصف

تحرير ذاكرة مصفوفة مؤشرات 'iscsi_iface' التي تم إنشاؤها بواسطة. إذا كان المؤشر 'ifaces' المقدم NULL أو 'iface_count' يساوي 0، فلن يتم فعل شيء.

الإرجاع

void
