التراخيص: GPL

IW(8) Linux IW(8)

الاسم

iw - عرض / معالجة أجهزة لاسلكية وتكوينها

الموجز


iw [ خيارات ] { help [ أمر ] | كائن أمر }

كائن := { dev | phy | reg }

خيارات := { --version | --debug }

خيارات

--version
طباعة معلومات الإصدار والخروج.
--debug
تمكين تصحيح رسائل netlink.

IW - صيغة الأوامر

الكائن

dev <اسم الواجهة>
- واجهة الشبكة.
phy <اسم الجهاز المادي>
- جهاز الأجهزة اللاسلكية (بالاسم).
phy#<فهرس الجهاز المادي>
- جهاز الأجهزة اللاسلكية (بالفهرس).
reg
- وكيل تنظيمي.

الأمر

يحدد الإجراء المراد تنفيذه على الكائن. مجموعة الإجراءات الممكنة تعتمد على نوع الكائن. iw help ستعرض جميع الأوامر المدعومة، بينما iw help command ستعرض المساعدة لجميع الأوامر المطابقة.

انظر أيضًا

ip(8), crda(8), regdbdump(8), regulatory.bin(5).

وثائق في ويكي النواة.
