icmodmap(1)

الحزمة: icmake

التراخيص: GPL-3.0-or-later

DESCRIPTION

The command icmodmap is used to map modules. Modules are distributed using a separate directory tree gcm.cache, which is installed in the main directory of the package. The command icmodmap sets up the necessary soft-links, so that the C compiler can find the module-compiled system header files. It also defines the soft-link square/gcm.cache -> ../gcm.cache: those soft-links are defined in all sub-directories used by the program, allowing all source files in all of the program’s sub-directories to import all modules defined in the main directory’s gcm.cache directory.
