INN__Config(3pm)

الحزمة: inn

التراخيص: custom:INN

INN::Config(3pm) وثائق InterNetNews INN::Config(3pm)

الاسم

INN::Config - تصدير جميع المتغيرات التي قد تحتاجها نصوص Perl الخاصة بـ INN

الوصف

وحدة Perl هذه تقوم بإعداد أي وجميع المتغيرات التي قد تحتاجها نصوص Perl الخاصة بـ INN. بشكل أكثر تحديدًا، تسمح باستخدام متغيرات inn.conf: يتم توفيرها جميعًا بواسطة innconfval، بالإضافة إلى إصدار INN (في المتغير $INN::Config::VERSION لشكله المختصر، وفي $INN::Config::version لشكله الكامل). كما يتم توفير متغيرات مفيدة أخرى (دلائل، ملفات، برامج، أقنعة، معلمات). يمكن الحصول على القائمة الكاملة باستخدام النص البرمجي التالي الذي يطبعها:

use lib '<pathnews>/lib/perl';
use INN::Config;
use Data::Dumper;
my ($varname, $value);
foreach my $var (@INN::Config::EXPORT_OK) {
    if ($var =~ /^\$(.*)$/) {
        $varname = "INN::Config::$1";
        $value = Dumper($$varname);
        $value =~ s/^\$VAR1 = //;
        print "\$$varname = $value";
    } elsif ($var =~ /^\@(.*)$/) {
        $varname = "INN::Config::$1";
        $value = Dumper(\@$varname);
        $value =~ s/^\$VAR1 = //;
        print "\@$varname = $value";
    }
}

سيتم تحميل نص برمجي محلي باسم innshellvars.pl.local في pathetc، إذا كان موجودًا وقابلاً للتنفيذ، في نهاية تشغيل هذه الوحدة. الاستخدام النموذجي هو إضافة أو تجاوز المتغيرات.

تحتاج فقط إلى تعريف الوحدة في بداية النصوص:

use lib '<pathnews>/lib/perl';
use INN::Config;

بعد ذلك، يمكنك على سبيل المثال استخدام:

print $INN::Config::localmaxartsize;

لطباعة قيمة localmaxartsize كما هي محددة في inn.conf.

يمكنك أيضًا تحديد إصدار عند استيراد الوحدة. إذا كتبت:

use INN::Config 2.5.0;

فقط إصدارات INN التي تزيد عن 2.5.0 ستكون قادرة على تشغيل نص Perl البرمجي.

من الممكن أيضًا استيراد المتغيرات مباشرة في مساحتك الاسمية إذا حددت ما تريد استيراده:

use INN::Config qw($localmaxartsize $pathbin);

لاحظ أنه تم توفير innshellvars.pl قديم في pathnews/lib لأسباب التوافق مع نصوص Perl القديمة غير المرفقة مع INN. تم استخدامه بواسطة إصدارات INN السابقة لـ 2.5.0. ومع ذلك، لا تزال النصوص البرمجية المقابلة لـ Shell و Tcl قيد الاستخدام: innshellvars و innshellvars.tcl. إنها تقدم نفس القدرات مثل هذه الوحدة.
