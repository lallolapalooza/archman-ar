idn2_to_unicode_44i(3)

الحزمة: libidn2

التراخيص: GPL2, LGPL3

idn2_to_unicode_44i(3) libidn2 idn2_to_unicode_44i(3)

الاسم

idn2_to_unicode_44i - وظيفة API

الملخص

#include <idn2.h>

int idn2_to_unicode_44i(const uint32_t * in, size_t inlen, uint32_t * out, size_t * outlen, int flags);

الوسائط

const uint32_t * in
مصفوفة الإدخال بنقاط رمز UTF-32.
size_t inlen
عدد نقاط رمز مصفوفة الإدخال
uint32_t * out
مصفوفة الإخراج بنقاط رمز UTF-32.
size_t * outlen
عند الإدخال، الحد الأقصى لحجم مصفوفة الإخراج بنقاط رمز UTF-32، عند الخروج، الحجم الفعلي لمصفوفة الإخراج بنقاط رمز UTF-32.
int flags
غير مستخدم حاليًا.

الوصف

عملية ToUnicode تأخذ تسلسلاً من نقاط رمز UTF-32 التي تشكل تسمية نطاق واحدة وتعيد تسلسلاً من نقاط رمز UTF-32. إذا كان تسلسل الإدخال تسمية بصيغة ACE، فإن النتيجة ستكون تسمية دولية مكافئة ليست بصيغة ACE، وإلا فسيتم إرجاع التسلسل الأصلي دون تغيير.


قد تكون output مساوية لـ NULL لاختبار البحث عن input دون تخصيص ذاكرة.

2.0.0
