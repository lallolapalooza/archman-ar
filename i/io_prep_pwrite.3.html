io_prep_pwrite(3)

الحزمة: libaio

التراخيص: LGPL-2.0-or-later

io_prep_pwrite(3) Linux AIO io_prep_pwrite(3)

الاسم

io_prep_pwrite - إعداد iocb للكتابة غير المتزامنة

الملخص

#include <errno.h>

#include <libaio.h>

inline void io_prep_pwrite(struct iocb *iocb, int fd, void *buf, size_t count, long long offset);

struct iocb {
	void		*data;
	unsigned	key;
	short		aio_lio_opcode;
	short		aio_reqprio;
	int		aio_fildes;
};

الوصف

io_prep_write() هي دالة مساعدة لإعداد عمليات كتابة متوازية.

يتم كتابة البايتات الـ iocb->u.c.nbytes = count من الملف الذي الموصوف فيه iocb->aio_fildes = fd من المخزن المؤقت الذي يبدأ في iocb->u.c.buf = buf. تبدأ الكتابة من الموضع المطلق ioc->u.c.offset = offset في الملف.

تعود هذه الدالة فوراً. لجدولة العملية، يجب استدعاء الدالة io_submit(3).

تؤدي العمليات غير المتزامنة المتزامنة باستخدام نفس iocb إلى نتائج غير محددة.
