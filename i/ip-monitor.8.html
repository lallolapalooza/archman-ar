ip-monitor(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

IP-MONITOR(8) لينكس IP-MONITOR(8)

الاسم

ip-monitor, rtmon - مراقبة الحالة

ملخص


ip monitor [ all | قائمة-الكائنات ] [ file اسم-الملف ] [ label ] [ all-nsid ] [ dev الجهاز ]

خيارات

-t, -timestamp
يطبع طابعًا زمنيًا قبل رسالة الحدث على سطر منفصل بالتنسيق:
Timestamp: <اليوم> <الشهر> <DD> <hh:mm:ss> <YYYY> <usecs> ميكروثانية
<الحدث>
-ts, -tshort
يطبع طابعًا زمنيًا قصيرًا قبل رسالة الحدث على نفس السطر بالتنسيق:
[<YYYY>-<MM>-<DD>T<hh:mm:ss>.<ms>] <الحدث>

الوصف

يمكن للأداة ip مراقبة حالة الأجهزة والعناوين والمسارات بشكل مستمر. هذا الخيار له تنسيق مختلف قليلاً. وتحديداً، الأمر monitor هو الأول في سطر الأوامر ثم تتبع قائمة الكائنات:

ip monitor [ all | قائمة-الكائنات ] [ file اسم-الملف ] [ label ] [ all-nsid ] [ dev الجهاز ]

قائمة-الكائنات هي قائمة بأنواع الكائنات التي نريد مراقبتها. قد تحتوي على link، address، route، mroute، maddress، acaddress، prefix، neigh، netconf، rule، stats، nsid و nexthop. إذا لم يتم تقديم وسيطة file، تفتح ip RTNETLINK، وتستمع إليها، وتلغي تغييرات الحالة بالتنسيق الموضح في الأقسام السابقة.

إذا تم تعيين خيار label، يتم عرض بادئة قبل كل رسالة لإظهار عائلة الرسالة. على سبيل المثال:


[NEIGH]10.16.0.112 dev eth0 lladdr 00:04:23:df:2f:d0 REACHABLE [LINK]3: eth1: <BROADCAST,MULTICAST> mtu 1500 qdisc pfifo_fast state DOWN group default
link/ether 52:54:00:12:34:57 brd ff:ff:ff:ff:ff:ff

إذا تم تعيين خيار all-nsid، يستمع البرنامج إلى جميع مساحات أسماء الشبكة التي لديها nsid معين في مساحة اسم الشبكة حيث يعمل البرنامج. يتم عرض بادئة لإظهار مساحة اسم الشبكة التي تنشأ منها الرسالة. مثال:


[nsid 0]10.16.0.112 dev eth0 lladdr 00:04:23:df:2f:d0 REACHABLE

إذا تم تقديم خيار file، فإن البرنامج لا يستمع إلى RTNETLINK، ولكن يفتح الملف المحدد، ويلغي محتوياته. يجب أن يحتوي الملف على رسائل RTNETLINK محفوظة بتنسيق ثنائي. يمكن إنشاء مثل هذا الملف باستخدام الأداة المساعدة rtmon. تحتوي هذه الأداة المساعدة على صيغة سطر أوامر مشابهة لـ ip monitor. من المثالي، يجب بدء rtmon قبل إصدار أمر تكوين الشبكة الأول. على سبيل المثال، إذا قمت بإدراج:


rtmon file /var/log/rtmon.log

في برنامج بدء تشغيل، ستتمكن من عرض السجل الكامل لاحقًا.

ومع ذلك، من الممكن بدء rtmon في أي وقت. يقوم بإلحاق السجل بلقطة الحالة التي تم تفريغها في لحظة البدء.

إذا تم تقديم خيار dev، فإن البرنامج يطبع فقط الأحداث المتعلقة بهذا الجهاز.
