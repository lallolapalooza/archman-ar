ip-tcp_metrics(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

IP-TCP_METRICS(8) Linux IP-TCP_METRICS(8)

اسم

ip-tcp_metrics - إدارة مقاييس TCP

ملخص


ip [ خيارات ] tcp_metrics { أمر | help }

ip tcp_metrics { show | flush } محدد

ip tcp_metrics delete [ address ] عنوان

محدد := [ [ address ] بادئة ]

الوصف

يُستخدم ip tcp_metrics للتلاعب بالإدخالات في النواة التي تحتفظ بمعلومات TCP لوجهات IPv4 و IPv6. يتم إنشاء الإدخالات عندما ترغب مآخذ TCP في مشاركة المعلومات للوجهات ويتم تخزينها في ذاكرة تخزين مؤقت مفهرسة بعنوان الوجهة. قد تتضمن المعلومات المحفوظة قيمًا للمقاييس (تم الحصول عليها في البداية من المسارات)، و TSVAL حديث لأغراض إعادة تدوير TIME-WAIT، وحالة لميزة Fast Open، وما إلى ذلك. لأسباب تتعلق بالأداء، لا يمكن لذاكرة التخزين المؤقت أن تنمو فوق الحد المحدد ويتم استبدال الإدخالات الأقدم بمعلومات جديدة، وأحيانًا يتم استعادتها واستخدامها لوجهات جديدة. لا تزيل النواة الإدخالات أبدًا، يمكن مسحها فقط باستخدام هذه الأداة.

ip tcp_metrics show - عرض الإدخالات المخزنة مؤقتًا

address بادئة (افتراضي)
بادئة أو عنوان IPv4/IPv6. إذا لم يتم توفير بادئة، يتم عرض جميع الإدخالات.

قد يحتوي الإخراج على المعلومات التالية:

age <S.MMM>sec - الوقت بعد إنشاء الإدخال، أو إعادة تعيينه، أو تحديثه بمقاييس من المآخذ. يتم إعادة تعيين الإدخال وتحديثه عند استخدامه بمقاييس من المسار إذا لم يتم تحديث المقاييس في الساعة الأخيرة. لا تقوم جميع القيم المخزنة مؤقتًا بإعادة تعيين العمر عند التحديث.

cwnd <N> - قيمة مقياس CWND

fo_cookie <HEX-STRING> - قيمة الكوكي المستلمة في SYN-ACK لاستخدامها بواسطة Fast Open للملفات التالية

fo_mss <N> - قيمة MSS المستلمة في SYN-ACK لاستخدامها بواسطة Fast Open للملفات التالية

fo_syn_drops <N>/<S.MMM>sec ago - عدد إسقاطات ملفات SYN الأولية الصادرة مع البيانات المكتشفة عن طريق مراقبة SYN-ACK المستلم بعد إعادة إرسال SYN. تعرض الثواني الوقت بعد آخر إسقاط لـ SYN ويمكن استخدامها مع عدد الإسقاطات لتعطيل Fast Open لبعض الوقت.

reordering <N> - قيمة مقياس إعادة الترتيب

rtt <N>us - قيمة مقياس RTT

rttvar <N>us - قيمة مقياس RTTVAR

ssthresh <SSTHRESH> - قيمة مقياس SSTHRESH

tw_ts <TSVAL>/<SEC>sec ago - TSVAL حديث والثواني بعد حفظها في مأخذ TIME-WAIT

ip tcp_metrics delete - حذف إدخال واحد

address ADDRESS (افتراضي)
عنوان IPv4/IPv6. العنوان هو وسيط مطلوب.

ip tcp_metrics flush - مسح الإدخالات

يمسح هذا الأمر الإدخالات المحددة بمعايير معينة.

هذا الأمر له نفس الوسائط مثل show.

أمثلة

ip tcp_metrics show address 192.168.0.0/24

يعرض الإدخالات للوجهات من الشبكة الفرعية

ip tcp_metrics show 192.168.0.0/24

نفس الشيء ولكن الكلمة المفتاحية address اختيارية

ip tcp_metrics

العرض الافتراضي هو عرض كل شيء

ip tcp_metrics delete 192.168.0.1

يزيل الإدخال لـ 192.168.0.1 من ذاكرة التخزين المؤقت.

ip tcp_metrics flush 192.168.0.0/24

يزيل الإدخالات للوجهات من الشبكة الفرعية

ip tcp_metrics flush all

يزيل جميع الإدخالات من ذاكرة التخزين المؤقت

ip -6 tcp_metrics flush all

يزيل جميع إدخالات IPv6 من ذاكرة التخزين المؤقت مع الاحتفاظ بإدخالات IPv4.
