Code(1) دليل الأوامر العامة Code(1)

الاسم

io.elementary.code - محرر نصوص يعمل من أجلك

الملخص

io.elementary.code [خيار...] [ملف...]

الوصف

Code هو محرر النصوص الذي يعمل من أجلك. يقوم بحفظ ملفاتك تلقائيًا، مما يعني أنها محدثة دائمًا. بالإضافة إلى ذلك، فإنه يتذكر علامات التبويب الخاصة بك، لذلك لا تفقد مكانك أبدًا، حتى بين الجلسات.

اجعله ملكك. تم بناء Code من الألف إلى الياء ليكون قابلاً للتوسيع. اجعل الأمور خفيفة الوزن وبسيطة للغاية، أو قم بتثبيت إضافات لتحويل Code إلى بيئة تطوير متكاملة كاملة؛ هذا اختيارك. ومع مجموعة من التفضيلات المفيدة، يمكنك تعديل السلوك والواجهة حسب رغبتك.

إنها elementary. تم تصميم Code ليكون محرر النصوص المثالي لنظام elementary OS، مما يعني أنه يتبع عن كثب المعايير العالية للتصميم والسرعة والاتساق. إنها جذابة، ولكن ليست مشتتة للانتباه.

تعمل مع لغتك. سواء كنت تصوغ التعليمات البرمجية بلغة Vala، أو تنشئ نصوصًا برمجية بلغة PHP، أو تقوم بإنشاء علامات في HTML، فإن Code قد غطتك. استمتع بتمييز كامل للصيغة مع جميع لغات البرمجة والنصوص البرمجية ولغات الترميز تقريبًا.

خيارات

-t, --new-tab
افتح علامة تبويب جديدة.
-n, --new-window
افتح نافذة جديدة.
-h, --help
عرض رسالة مساعدة والخروج.
-v, --version
طباعة معلومات الإصدار والخروج.
--display=العرض
شاشة X للاستخدام.
