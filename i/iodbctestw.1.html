iodbctestw(1)

الحزمة: libiodbc

التراخيص: LGPL

iodbctest(1) مدير تعريفات iODBC iodbctest(1)

الاسم

iodbctest, iodbctestw - برامج توضيحية لـ iODBC

الملخص

iodbctest ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=value]"]
iodbctestw ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=value]"]

الوصف

برنامج iodbctest وبرنامج iodbtestw هما برنامجان بسيطان لـ ODBC، يوضحان قوة واجهة برمجة تطبيقات ODBC للاتصال بأي قاعدة بيانات تدعم ODBC، وإصدار أوامر SQL واسترداد نتائج الاستعلام.

يستخدم برنامج iodbctest استدعاءات واجهة برمجة تطبيقات ODBC القياسية للاتصال باستخدام أي DSN، ولكنه يسترد جميع النتائج في وضع ASCII.

يستخدم برنامج iodbctestw استدعاءات واجهة برمجة تطبيقات ODBC Unicode للاتصال باستخدام أي DSN، ويسترد جميع النتائج في وضع Unicode.

الخيارات

يستخدم برنامج iodbctest الدالة SQLDriverConnect لإجراء اتصال باستخدام أي تعريف ODBC متوافق متاح. هذا يسمح للمستخدم بتجاوز أي سمة اتصال ODBC في سلسلة DSN.

يجب أن تبدأ سلاسل الاتصال إما بـ DSN=xxx أو DRIVER=xxxx متبوعة اختياريًا بسمات DSN أخرى مفصولة بفاصلة منقوطة، على سبيل المثال:

DSN=ora9;UID=scott;PWD=tiger;DATABASE=ora9u

يجب أن تكون أي سمات مطلوبة لاتصال صحيح غير موجودة في سلسلة اتصال DSN موجودة في ملف odbc.ini.

إذا تم تمرير سلسلة الاتصال كوسيط إلى برنامج iodbctest، فيجب وضع السلسلة بين علامتي اقتباس لأن معظم الصدف تستخدم الفاصلة المنقوطة كفاصل للأوامر. إذا تم إدخال سلسلة الاتصال في المطالبة التفاعلية، فلا يجب استخدام علامات الاقتباس.

بعد إنشاء اتصال ناجح، يتم سؤال المستخدم عن أمر SQL ليتم إرساله إلى قاعدة البيانات. لا يمكن لأمر SQL أن يمتد عبر عدة أسطر.

إذا أعاد أمر SQL مجموعة نتائج واحدة أو أكثر، يتم جلب كل مجموعة نتائج باستخدام مخازن مؤقتة للأحرف وعرضها في جدول.

بالإضافة إلى ذلك، يفهم برنامج iodbctest بضعة أوامر خاصة:

qualifiers

يعرض قائمة بالمعرفات باستخدام استدعاء كتالوج SQLTables.
owners

يعرض قائمة بالمالكين باستخدام استدعاء كتالوج SQLTables.
tables

يعرض قائمة بالجداول باستخدام استدعاء كتالوج SQLTables.
types

يعرض قائمة بأنواع الجداول باستخدام استدعاء كتالوج SQLTables.
datatypes

يعرض قائمة بأنواع البيانات باستخدام استدعاء كتالوج SQLGetTypeInfo.
reconnect

يجري قطع اتصال/إعادة اتصال بالمعلومات المحفوظة أثناء أول SQLDriverConnect.
quit (أو exit)

يخرج من البرنامج ويعود إلى الصدفة.

أمثلة

ابدأ برنامج iodbctest واحصل على قائمة بـ DSNs قبل إجراء اتصال:

    $ iodbctest
    OpenLink ODBC Demonstration program
    This program shows an interactive SQL processor
    Enter ODBC connect string (? shows list): ?
    DSN                              | Driver
    -----------------------------------------------------------------
    ora9                             | OpenLink Generic ODBC Driver
    mysql                            | OpenLink Generic ODBC Driver
    mysqllite                        | OpenLink Lite for MySQL
    myodbc                           | MyODBC Driver
    pgsql                            | OpenLink Generic ODBC Driver
    tds                              | OpenLink Generic ODBC Driver
    Enter ODBC connect string (? shows list): DSN=ora9;PWD=tiger
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>

اتصل بنسخة Oracle 9 التي تم إعدادها مسبقًا في ملف odbc.ini:

    $ iodbctest "DSN=ora9;UID=scott;PWD=tiger"
    iODBC Demonstration program
    This program shows an interactive SQL processor
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>select * from emp
    ID               |NAME
    -----------------+-------------------------------------------
    1                |Record 1
    2                |Record 2
    2                |Record 3
     result set 1 returned 3 rows.
    SQL> quit
