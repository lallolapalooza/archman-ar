iptraf-ng(8)

الحزمة: iptraf-ng

التراخيص: GPL2

IPTRAF-NG(8) دليل مسؤول النظام IPTRAF-NG(8)

الاسم

iptraf - مراقب شبكة LAN تفاعلي ملون لبروتوكول الإنترنت

الملخص

iptraf-ng { [ -f ] [ { -i iface | -g | -d iface | -s iface | -z iface | -l iface } [ -t timeout ] [ -B [ -L logfile ] ] ] | [ -h ] }

الوصف

iptraf-ng هو مراقب لشبكة LAN لبروتوكول الإنترنت يعتمد على ncurses ويقوم بإنشاء إحصائيات متنوعة للشبكة بما في ذلك معلومات TCP، عدد حزم UDP، معلومات ICMP و OSPF، معلومات تحميل Ethernet، إحصائيات العقد، أخطاء المجموع الاختباري IP، وغيرها.

إذا تم إصدار الأمر iptraf-ng بدون أي خيارات لسطر الأوامر، يبدأ البرنامج في وضع تفاعلي، مع الوصول إلى المرافق المختلفة عبر القائمة الرئيسية.

الخيارات

يمكن أيضًا توفير هذه الخيارات للأمر:

-i iface
ابدأ مراقب حركة مرور IP فورًا على الواجهة المحددة، أو على جميع الواجهات إذا تم تحديد "-i all"
-g
ابدأ إحصائيات الواجهة العامة فورًا
-d iface
يسمح لك ببدء الإحصائيات التفصيلية على الواجهة المحددة (iface) فورًا
-s iface
يسمح لك بمراقبة حركة مرور TCP و UDP على الواجهة المحددة (iface) فورًا
-z iface
يعرض عدد الحزم حسب الحجم على الواجهة المحددة
-l iface
ابدأ مراقب محطات LAN على الواجهة المحددة، أو على جميع واجهات LAN إذا تم تحديد "-l all"
-t timeout
يخبر IPTraf-ng بتشغيل المرفق المحدد لمدة timeout دقائق فقط. يتم استخدام هذا الخيار فقط مع أحد المعلمات المذكورة أعلاه.
-B
إعادة توجيه المخرج القياسي إلى / dev / null، وإغلاق الإدخال القياسي، وتشغيل العملية في الخلفية. يمكن استخدامه فقط مع أحد معلمات استدعاء المرفق أعلاه. أرسل إشارة USR2 إلى العملية الخلفية لإنهاءها.
-L logfile
يسمح لك بتحديد اسم ملف سجل بديل. اسم ملف السجل الافتراضي يعتمد إما على الواجهة المحددة (إحصائيات الواجهة التفصيلية، إحصائيات خدمة TCP/UDP، تفصيل حجم الحزم)، أو مثيل المرفق (مراقب حركة مرور IP، مراقب محطة LAN). إذا لم يتم تحديد مسار، يتم وضع ملف السجل في /var/log/iptraf-ng
-f
يمسح جميع الأقفال والعدادات، مما يجعل هذه النسخة من IPTraf-ng تعتقد أنها الأولى قيد التشغيل. يجب استخدام هذا فقط للاسترداد من إنهاء غير طبيعي أو تعطل النظام.
-h
يعرض ملخصًا للأوامر

الإشارات


SIGUSR1 - تدوير ملفات السجل أثناء تشغيل البرنامج
SIGUSR2 - إنهاء عملية IPTraf-ng تعمل في الخلفية.

الملفات


/var/log/iptraf-ng/*.log - ملف السجل
/var/lib/iptraf-ng/* - ملفات بيانات IPTraf-ng المهمة

انظر أيضًا
