idna_to_ascii_8z(3)

الحزمة: libidn

التراخيص: GPL3, LGPL

idna_to_ascii_8z(3) libidn idna_to_ascii_8z(3)

الاسم

idna_to_ascii_8z - دالة API

الملخص

#include <idna.h>

int idna_to_ascii_8z(const char * input, char ** output, int flags);

المعاملات

const char * input
مدخل نصي UTF-8 ينتهي بصفر.
char ** output
مؤشر إلى سلسلة نصية مخرجة مخصصة حديثًا.
int flags
قيمة Idna_flags، على سبيل المثال، IDNA_ALLOW_UNASSIGNED أو IDNA_USE_STD3_ASCII_RULES.

الوصف

تحويل اسم نطاق UTF-8 إلى سلسلة نصية ASCII. قد يحتوي اسم النطاق على عدة تسميات، مفصولة بنقاط. يجب على المتصل إلغاء تخصيص مخزن الإخراج.

قيمة الإرجاع: تُرجع IDNA_SUCCESS عند النجاح، أو رمز خطأ.
