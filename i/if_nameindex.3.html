if_nameindex(3) دليل وظائف المكتبة if_nameindex(3)

الاسم

if_nameindex، if_freenameindex - الحصول على أسماء وفهارس واجهات الشبكة

المكتبة

مكتبة C القياسية (libc،  -lc)

الملخص

#include <net/if.h>
struct if_nameindex *if_nameindex(void);
void if_freenameindex(struct if_nameindex *ptr);

الوصف

تقوم الدالة if_nameindex() بإرجاع مصفوفة من هياكل if_nameindex، كل منها يحتوي على معلومات حول إحدى واجهات الشبكة على النظام المحلي. يحتوي هيكل if_nameindex على المدخلات التالية على الأقل:


unsigned int if_index;  /* فهرس الواجهة (1، 2، ...) */
char        *if_name;   /* الاسم المنتهي بصفر ("eth0"، إلخ) */

يحتوي حقل if_index على فهرس الواجهة. يشير حقل if_name إلى اسم الواجهة المنتهي بصفر. نهاية المصفوفة يشار إليها بمدخل يحتوي على if_index تم تعيينه إلى صفر و if_name تم تعيينه إلى NULL.

هيكل البيانات الذي تم إرجاعه بواسطة if_nameindex() يتم تخصيصه ديناميكيًا ويجب تحريره باستخدام if_freenameindex() عندما لا يعود مطلوبًا.

قيمة الإرجاع

عند النجاح، ترجع if_nameindex() مؤشرًا إلى المصفوفة؛ عند الخطأ، يتم إرجاع NULL، ويتم تعيين errno للإشارة إلى الخطأ.

الأخطاء

قد تفشل if_nameindex() وتعيين errno إذا:

ENOBUFS
موارد غير كافية متاحة.

قد تفشل if_nameindex() أيضًا لأي من الأخطاء المحددة لـ socket(2)، bind(2)، ioctl(2)، getsockname(2)، recvmsg(2)، sendto(2)، أو malloc(3).

السمات

لشرح المصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
if_nameindex ()، if_freenameindex () سلامة الخيوط MT-Safe

المعايير

POSIX.1-2008، RFC 3493.

التاريخ

glibc 2.1. POSIX.1-2001. BSDi.

قبل glibc 2.3.4، كان التطبيق يدعم الواجهات التي تحتوي على عناوين IPv4 فقط. دعم الواجهات التي لا تحتوي على عناوين IPv4 متاح فقط على النوى التي تدعم netlink.

أمثلة

يوضح البرنامج أدناه استخدام الدوال الموصوفة في هذه الصفحة. مثال على المخرجات التي قد ينتجها هذا البرنامج هو:


$ ./a.out;
1: lo
2: wlan0
3: em1

مصدر البرنامج

#include <net/if.h>
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
int
main(void)
{
    struct if_nameindex *if_ni, *i;
    if_ni = if_nameindex();
    if (if_ni == NULL) {
        perror("if_nameindex");
        exit(EXIT_FAILURE);
    }
    for (i = if_ni; !(i->if_index == 0 && i->if_name == NULL); i++)
        printf("%u: %s\n", i->if_index, i->if_name);
    if_freenameindex(if_ni);
    exit(EXIT_SUCCESS);
}
