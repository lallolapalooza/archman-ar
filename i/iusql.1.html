OSCILLATION RANGE

The oscillation range is the difference between the highest and lowest values returned for the same signal during the test period. A value of zero means that the signal returned the same value every time.

SIGNALS

The following signals are provided by iusql:

ALL
Returns all signals.
AUTHENTICATION
Returns the authentication state.
AVERAGE
Returns the average value.
CONNECTION
Returns the connection state.
CUSTOM
Returns custom signals.
MAXIMUM
Returns the maximum value.
MINIMUM
Returns the minimum value.
OSCILLATION
Returns the oscillation range.
PERCENTAGE
Returns the percentage of the maximum value.
STATE
Returns the state of the signal.
SYSTEM
Returns system signals.
TIME
Returns the time the signal was received.
VALUE
Returns the value of the signal.
VARIANCE
Returns the variance.

FILES

/etc/odbc.ini

Configuration file containing system-wide Data Source Name (DSN) definitions. See odbc.ini(5) for more information.

$HOME/.odbc.ini

Configuration file containing user-specific Data Source Name (DSN) definitions. See odbc.ini(5) for more information.
