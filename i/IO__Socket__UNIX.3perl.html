IO::Socket::UNIX(3perl) دليل مبرمجي Perl IO::Socket::UNIX(3perl)

الاسم

IO::Socket::UNIX - واجهة كائنية لمقابس مجال AF_UNIX

الملخص

use IO::Socket::UNIX;
my $SOCK_PATH = "$ENV{HOME}/unix-domain-socket-test.sock";
# الخادم:
my $server = IO::Socket::UNIX->new(
    Type => SOCK_STREAM(),
    Local => $SOCK_PATH,
    Listen => 1,
);
my $count = 1;
while (my $conn = $server->accept()) {
    $conn->print("Hello " . ($count++) . "\n");
}
# العميل:
my $client = IO::Socket::UNIX->new(
    Type => SOCK_STREAM(),
    Peer => $SOCK_PATH,
);
# الآن اقرأ واكتب من $client

الوصف

"IO::Socket::UNIX" يوفر واجهة كائنية لإنشاء واستخدام المقابس في مجال AF_UNIX. تم بناؤه على واجهة IO::Socket ويتوارث جميع الطرق المعرفة بواسطة IO::Socket.

الباني

new ( [ARGS] )
ينشئ كائن "IO::Socket::UNIX"، وهو مرجع لرمز تم إنشاؤه حديثًا (انظر حزمة Symbol). يأخذ "new" اختياريًا وسيطات، وهذه الوسيطات تكون في أزواج مفتاح-قيمة.

بالإضافة إلى أزواج المفتاح-القيمة التي تقبلها IO::Socket، يوفر "IO::Socket::UNIX".

Type        نوع المقبس (مثل SOCK_STREAM أو SOCK_DGRAM)
Local       مسار أنبوب الملف المحلي
Peer        مسار أنبوب الملف للطرف المقابل
Listen      حجم قائمة الانتظار للإنصات

إذا تم تمرير وسيطة واحدة فقط إلى الباني، فمن المفترض أنها مواصفات "Peer".

إذا تم توفير الوسيطة "Listen"، ولكنها خاطئة، فسيتم تعيين حجم قائمة الانتظار إلى 5.

إذا فشل الباني، فسيعيد "undef" وسيضبط متغير الحزمة $IO::Socket::errstr ليحتوي على رسالة خطأ.

$sock = IO::Socket::UNIX->new(...)
    or die "Cannot create socket - $IO::Socket::errstr\n";

لأسباب تتعلق بالتوافق مع الإصدارات السابقة، يتم أيضًا تعيين رسالة الخطأ إلى المتغير العام $@، وقد تجد لا يزال التعليمات البرمجية القديمة تبحث هنا بدلاً من ذلك.

$sock = IO::Socket::UNIX->new(...)
    or die "Cannot create socket - $@\n";

الطرق

hostpath()
يعيد المسار إلى أنبوب الملف في الطرف المحلي
peerpath()
يعيد المسار إلى أنبوب الملف في الطرف المقابل
