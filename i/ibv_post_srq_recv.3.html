IBV_POST_SRQ_RECV(3) دليل مبرمج Libibverbs IBV_POST_SRQ_RECV(3)

الاسم

ibv_post_srq_recv - نشر قائمة طلبات العمل (WRs) إلى قائمة انتظار الاستقبال المشتركة (SRQ)

الشكل

#include <infiniband/verbs.h>

int ibv_post_srq_recv(struct ibv_srq *srq, struct ibv_recv_wr *wr,
                      struct ibv_recv_wr **bad_wr);

الوصف

ibv_post_srq_recv() تنشر القائمة المرتبطة من طلبات العمل (WRs) بدءًا من wr إلى قائمة انتظار الاستقبال المشتركة (SRQ) srq. تتوقف عن معالجة طلبات العمل من هذه القائمة عند أول فشل (يمكن اكتشافه على الفور أثناء نشر الطلبات)، وتعيد طلب العمل الفاشل هذا من خلال bad_wr.

الوسيط wr هو بنية ibv_recv_wr، كما هو محدد في <infiniband/verbs.h>.

struct ibv_recv_wr {
uint64_t                wr_id;     /* معرف طلب العمل المحدد من قبل المستخدم */
struct ibv_recv_wr     *next;      /* مؤشر إلى طلب العمل التالي في القائمة، NULL إذا كان طلب العمل الأخير */
struct ibv_sge         *sg_list;   /* مؤشر إلى مصفوفة s/g */
int                     num_sge;   /* حجم مصفوفة s/g */
};
struct ibv_sge {
uint64_t                addr;      /* عنوان بداية مخزن الذاكرة المحلي */
uint32_t                length;    /* طول المخزن */
uint32_t                lkey;      /* مفتاح منطقة الذاكرة المحلية */
};

قيمة الإرجاع

ibv_post_srq_recv() تعيد 0 عند النجاح، أو قيمة errno عند الفشل (والتي تشير إلى سبب الفشل).

ملاحظات

يمكن استخدام المخازن المؤقتة التي يستخدمها طلب العمل بأمان فقط بعد تنفيذ طلب العمل بالكامل واسترداد إكمال العمل من قائمة الإكمال (CQ) المقابلة.

إذا كان طلب العمل يتم نشره إلى QP UD، فسيتم وضع رأس التوجيه العام (GRH) للرسالة الواردة في الـ 40 بايت الأولى من المخزن (المخازن) في قائمة التوزيع. إذا لم يكن هناك GRH في الرسالة الواردة، فإن البايتات الأولى ستكون غير محددة. هذا يعني أنه في جميع الحالات، ستبدأ البيانات الفعلية للرسالة الواردة بإزاحة 40 بايت في المخزن (المخازن) في قائمة التوزيع.
