IsCursorKey(3)

الحزمة: libx11

التراخيص: MIT AND X11

IsCursorKey(3) وظائف XLIB IsCursorKey(3)

الاسم

IsCursorKey, IsFunctionKey, IsKeypadKey, IsMiscFunctionKey, IsModifierKey, IsPFKey, IsPrivateKeypadKey - وحدات ماكرو لتصنيف مفاتيح الرموز (keysym).

الصيغة

int IsCursorKey(KeySym keysym);

int IsFunctionKey(KeySym keysym);

int IsKeypadKey(KeySym keysym);

int IsMiscFunctionKey(KeySym keysym);

int IsModifierKey(KeySym keysym);

int IsPFKey(KeySym keysym);

int IsPrivateKeypadKey(KeySym keysym);

المعاملات

keysym
يحدد مفتاح الرمز (KeySym) المراد اختباره.

الوصف

تعيد وحدة الماكرو IsCursorKey القيمة True إذا كان مفتاح الرمز المحدد هو مفتاح مؤشر.

تعيد وحدة الماكرو IsFunctionKey القيمة True إذا كان مفتاح الرمز هو مفتاح وظيفة.

تعيد وحدة الماكرو IsKeypadKey القيمة True إذا كان مفتاح الرمز المحدد هو مفتاح لوحة المفاتيح.

تعيد وحدة الماكرو IsMiscFunctionKey القيمة True إذا كان مفتاح الرمز المحدد هو مفتاح وظيفة متنوع.

تعيد وحدة الماكرو IsModifierKey القيمة True إذا كان مفتاح الرمز المحدد هو مفتاح تعديل.

تعيد وحدة الماكرو IsPFKey القيمة True إذا كان مفتاح الرمز المحدد هو مفتاح PF.

تعيد وحدة الماكرو IsPrivateKeypadKey القيمة True إذا كان مفتاح الرمز المحدد هو مفتاح لوحة مفاتيح خاص بالبائع.
