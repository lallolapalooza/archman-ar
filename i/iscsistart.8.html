iscsistart(8)

الحزمة: open-iscsi

التراخيص: GPL

ISCSISTART(8) دليل مسؤول لينكس ISCSISTART(8)

الاسم

iscsistart - أداة تمهيد iSCSI

الملخص

iscsistart [خيار]

الوصف

سيقوم iscsistart ببدء جلسة باستخدام الإعدادات التي تم تمريرها، أو باستخدام معلومات التمهيد iBFT أو Open Firmware [OF]. لا ينبغي تشغيل هذا البرنامج لإدارة الجلسات. استخدامه الأساسي هو بدء الجلسات المستخدمة لتمهيد جذر iSCSI.

الخيارات

[-c|--config=]ملف-الإعدادات
قراءة الإعدادات من ملف-الإعدادات بدلاً من الملف الافتراضي /etc/iscsi/iscsid.conf.
[-i|--initiatorname=]الاسم
تعيين اسم المبادِر (InitiatorName) إلى الاسم (مطلوب إذا لم يتم استخدام iBFT أو OF)
[-t|--targetname=]الاسم
تعيين اسم الهدف (TargetName) إلى الاسم (مطلوب إذا لم يتم استخدام iBFT أو OF)
[-g|--tgpt=]N
تعيين علامة مجموعة بوابة الهدف (target portal group tag) إلى N (مطلوب إذا لم يتم استخدام iBFT أو OF)
[-a|--address=]A.B.C.D
تعيين عنوان IP إلى A.B.C.D (مطلوب إذا لم يتم استخدام iBFT أو OF)
[-p|--port=]N
تعيين المنفذ إلى N (اختياري. الافتراضي 3260)
[-u|--username=]N
تعيين اسم المستخدم إلى N (اختياري)
[-w|--password=]N
تعيين كلمة المرور إلى N (اختياري)
[-U|-username_in=]N
تعيين اسم المستخدم الوارد إلى N (اختياري)
[-W|--password_in=]N
تعيين كلمة المرور الواردة إلى N (اختياري)
[-d|--debug=]مستوى-التصحيح
طباعة معلومات التصحيح
[-b|--fwparam_connect]
إنشاء جلسة إلى الهدف باستخدام معلومات iBFT أو OF
[-N|--fwparam_network]
تشغيل الشبكة كما هو محدد بواسطة iBFT أو OF
[-f|--fwparam_print]
طباعة معلومات iBFT أو OF إلى STDOUT
[-P|--param=]الاسم=القيمة
تعيين المعلمة بالاسم NAME إلى VALUE. NAME هو أحد الإعدادات في سجل العقدة أو iscsid.conf. يمكن تمرير معلمات متعددة.
[-h|--help]
عرض هذه المساعدة والخروج
[-v|--version]
عرض الإصدار والخروج
