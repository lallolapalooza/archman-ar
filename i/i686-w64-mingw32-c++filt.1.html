NAME

c++filt - C++filt

SYNOPSIS

c++filt [-i] [-n] [-p] [-C NAME] [demangler] [mangled-name... ]

DESCRIPTION

This utility demangles C++ symbol names. It is typically used to make the output of compilers, linkers, and debuggers more readable.

OPTIONS

-i
Demangle in place. This option is only valid if a single mangled-name is given and it is a file name. The contents of the file are overwritten with the demangled names.
-n
Do not prepend a underscore to mangled names. Some compilers (like older versions of g++) do not do this.
-p
Prepend a underscore to mangled names. This is the default behavior.
-C NAME
Demangle symbol names relative to the given namespace NAME.

If no mangled-name is given, c++filt reads from standard input.

If demangler is given, it is used as the demangling program instead of the default.
