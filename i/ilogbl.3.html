ilogb(3) دليل وظائف المكتبة ilogb(3)

الاسم

ilogb، ilogbf، ilogbl - الحصول على الأس الصحيح لقيمة نقطة عائمة

المكتبة

مكتبة الرياضيات (libm، -lm)

المختصر

#include <math.h>
int ilogb(double x);
int ilogbf(float x);
int ilogbl(long double x);
متطلبات ميزة الاختبار Macro لـ glibc (انظر feature_test_macros(7)):

ilogb():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || _XOPEN_SOURCE >= 500
        || /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

ilogbf()، ilogbl():

    _ISOC99_SOURCE || _POSIX_C_SOURCE >= 200112L
        || /* منذ glibc 2.19: */ _DEFAULT_SOURCE
        || /* glibc <= 2.19: */ _BSD_SOURCE || _SVID_SOURCE

الوصف

تُرجع هذه الوظائف جزء الأس من الوسيطة الخاصة بها كعدد صحيح مع إشارة. عند عدم حدوث خطأ، تكون هذه الوظائف مكافئة لوظائف logb(3) المقابلة، محولة إلى int.

قيمة الإرجاع

عند النجاح، تُرجع هذه الوظائف الأس لـ x، كعدد صحيح مع إشارة.

إذا كان x صفرًا، يحدث خطأ نطاق، وتُرجع الوظائف FP_ILOGB0.

إذا كان x قيمة NaN (ليس رقمًا)، يحدث خطأ نطاق، وتُرجع الوظائف FP_ILOGBNAN.

إذا كان x قيمة لا نهائية سالبة أو لا نهائية موجبة، يحدث خطأ نطاق، وتُرجع الوظائف INT_MAX.

الأخطاء

انظر math_error(7) للحصول على معلومات حول كيفية تحديد ما إذا كان خطأ قد حدث عند استدعاء هذه الوظائف.

يمكن أن تحدث الأخطاء التالية:

خطأ نطاق: x صفر أو NaN
يتم رفع استثناء نقطة عائمة غير صالح (FE_INVALID)، ويتم تعيين errno إلى EDOM (ولكن انظر BUGS).
خطأ نطاق: x لا نهائي
يتم رفع استثناء نقطة عائمة غير صالح (FE_INVALID)، ويتم تعيين errno إلى EDOM (ولكن انظر BUGS).

السمات

للحصول على شرح للمصطلحات المستخدمة في هذا القسم، انظر attributes(7).

الواجهة السمة القيمة
ilogb ()، ilogbf ()، ilogbl () أمان الخيط MT-Safe

المعايير

C11، POSIX.1-2008.

التاريخ

C99، POSIX.1-2001.

الأخطاء

قبل glibc 2.16، كانت الأخطاء التالية موجودة في تنفيذ glibc لهذه الوظائف:

•
حالة خطأ النطاق حيث x صفر أو NaN لم تسبب تعيين errno أو (على بعض المعماريات) رفع استثناء نقطة عائمة.
•
حالة خطأ النطاق حيث x لا نهائي لم تسبب تعيين errno أو رفع استثناء نقطة عائمة.

انظر أيضاً

log(3)، logb(3)، significand(3)
