الاسم

io_uring_for_each_cqe - تكرار الأحداث المكتملة المعلقة

ملخص

#include <liburing.h>
io_uring_for_each_cqe(struct io_uring *ring,
                      unsigned head,
                      struct io_uring_cqe *cqe) { }

الوصف

تعد io_uring_for_each_cqe(3) ماكرو مساعد يكرر الأحداث المكتملة المتعلقة بـ ring باستخدام head كمكرر مؤقت، ويشير cqe إلى كل حدث معلق عند التكرار.

يوفر هذا المساعد طريقة فعالة لتكرار جميع الأحداث المعلقة في الـ ring، ثم تقدم صف الـ CQ عن طريق استدعاء io_uring_cq_advance(3) مع عدد وحدات CQEs المستهلكة عند الانتهاء. نظرًا لأن تحديث حالة صف الـ CQ المرئي للنواة يتضمن كتابة مرتبة، فإن القيام بذلك مرة واحدة لعدد من الأحداث يكون أكثر كفاءة من معالجة كل إكمال بشكل منفصل واستدعاء io_uring_cqe_seen(3) لكل منها.

مثال

void handle_cqes(struct io_uring *ring)
{
	struct io_uring_cqe *cqe;
	unsigned head;
	unsigned i = 0;
	io_uring_for_each_cqe(ring, head, cqe) {
		/* handle completion */
		printf("cqe: %d\n", cqe->res);
		i++;
	}
	io_uring_cq_advance(ring, i);
}
