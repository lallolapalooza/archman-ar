ipc(2) دليل استدعاءات النظام ipc(2)

الاسم

ipc - استدعاءات نظام System V IPC

المكتبة

مكتبة C القياسية (libc، -lc)

الملخص

#include <linux/ipc.h>        /* تعريف الثوابت المطلوبة */
#include <sys/syscall.h>      /* تعريف الثوابت SYS_* */
#include <unistd.h>
int syscall(SYS_ipc, unsigned int call, int first,
            unsigned long second, unsigned long third, void *ptr,
            long fifth);

ملاحظة: لا توفر glibc غلافًا لـ ipc()، مما يستلزم استخدام syscall(2).

الوصف

ipc() هي نقطة دخول مشتركة للنواة لاستدعاءات System V IPC للرسائل، وأشباه الموصلات، والذاكرة المشتركة. تحدد call الدالة IPC التي سيتم استدعاؤها؛ يتم تمرير الوسائط الأخرى إلى الاستدعاء المناسب.

يجب على برامج مساحة المستخدم استدعاء الدوال المناسبة بأسمائها المعتادة. فقط مطورو المكتبة القياسية ومهندسو النواة يحتاجون إلى معرفة ipc().

الإصدارات

على بعض المعماريات — على سبيل المثال x86-64 و ARM — لا يوجد استدعاء نظام ipc()؛ بدلاً من ذلك، يتم تنفيذ msgctl(2)، semctl(2)، shmctl(2)، وهكذا بالفعل كاستدعاءات نظام منفصلة.
