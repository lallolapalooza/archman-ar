WITH-ALL-VALUES "false"

WITH-ALL-VALUES "/تعبير نمطي/"
يتطلب أن تتطابق جميع قيم السمة EXPECT مع التعبير النمطي، الذي يجب أن يتوافق مع صيغة التعبير النمطي POSIX. المقارنات حساسة لحالة الأحرف.
WITH-DISTINCT-VALUES
يتطلب أن تكون جميع قيم السمة EXPECT فريدة. المقارنات حساسة لحالة الأحرف. فقط سمات charset، collection، enum، integer، keyword، mimeMediaType، naturalLanguage، rangeOfInteger، resolution، uriScheme تدعم هذا القيد.
WITH-HOSTNAME "سلسلة حرفية"
WITH-HOSTNAME "/تعبير نمطي/"
يتطلب أن تحتوي قيمة URI واحدة على الأقل على اسم مضيف مطابق.
WITH-RESOURCE "سلسلة حرفية"
WITH-RESOURCE "/تعبير نمطي/"
يتطلب أن تحتوي قيمة URI واحدة على الأقل على مورد مطابق (بما في ذلك الـ / البادئة).
WITH-SCHEME "سلسلة حرفية"
WITH-SCHEME "/تعبير نمطي/"
يتطلب أن تحتوي قيمة URI واحدة على الأقل على مخطط مطابق.
WITH-VALUE "سلسلة حرفية"
يتطلب أن تتطابق قيمة واحدة على الأقل من السمة EXPECT مع السلسلة الحرفية. المقارنات حساسة لحالة الأحرف.
WITH-VALUE <رقم
WITH-VALUE =رقم
WITH-VALUE >رقم
WITH-VALUE رقم[,...,رقم]
يتطلب أن تتطابق قيمة واحدة على الأقل من السمة EXPECT مع الرقم (الأرقام) أو المقارنة الرقمية. عند مقارنة قيم rangeOfInteger، فإن المعاملات "<" و ">" تتحقق فقط من الحد الأعلى للنطاق.
WITH-VALUE "false"
WITH-VALUE "true"
يتطلب أن تتطابق قيمة واحدة على الأقل من السمة EXPECT مع القيمة المنطقية المعطاة.
WITH-VALUE "/تعبير نمطي/"
يتطلب أن تتطابق قيمة واحدة على الأقل من السمة EXPECT مع التعبير النمطي، الذي يجب أن يتوافق مع صيغة التعبير النمطي POSIX. المقارنات حساسة لحالة الأحرف.
WITH-VALUE-FROM اسم السمة
يتطلب أن تتطابق قيمة (قيم) السمة EXPECT مع القيمة (القيم) الموجودة في السمة المحددة. على سبيل المثال، "EXPECT job-sheets WITH-VALUE-FROM job-sheets-supported" يتطلب أن تكون قيمة "job-sheets" مدرجة كقيمة للسمة "job-sheets-supported".

قيود STATUS

القيود التالية مفهومة بعد توجيه اختبار STATUS:

DEFINE-MATCH اسم المتغير
يحدد المتغير إلى "1" عندما تتطابق STATUS. تأثير جانبي لهذا القيد هو أن STATUS هذا لن يفشل اختبارًا أبدًا.
DEFINE-NO-MATCH اسم المتغير
يحدد المتغير إلى "1" عندما لا تتطابق STATUS. تأثير جانبي لهذا القيد هو أن STATUS هذا لن يفشل اختبارًا أبدًا.
IF-DEFINED اسم المتغير
يجعل STATUS ينطبق فقط إذا كان المتغير المحدد معرفًا.
IF-NOT-DEFINED اسم المتغير
يجعل STATUS ينطبق فقط إذا لم يكن المتغير المحدد معرفًا.
REPEAT-LIMIT رقم

يحدد الحد الأقصى لعدد مرات التكرار. القيمة الافتراضية هي 1000.
REPEAT-MATCH
REPEAT-NO-MATCH
يحدد أن الاختبار الحالي يجب تكراره عندما يتطابق رمز حالة الاستجابة أو لا يتطابق مع القيمة المحددة بواسطة توجيه STATUS.

VARIABLES

The ipptool(8) program maintains a list of variables that can be used in any literal string or attribute value by specifying "$variable-name". Aside from variables defined using the -d option or DEFINE directive, the following pre-defined variables are available:

$$
Inserts a single "$" character.
$ENV[name]
Inserts the value of the named environment variable, or an empty string if the environment variable is not defined.
$date-current
Inserts the current date and time using the ISO-8601 format ("yyyy-mm-ddThh:mm:ssZ").
$date-start
Inserts the starting date and time using the ISO-8601 format ("yyyy-mm-ddThh:mm:ssZ").
$filename
Inserts the filename provided to ipptool(8) with the -f option.
$filetype
Inserts the MIME media type for the filename provided to ipptool(8) with the -f option.
$hostname
Inserts the hostname from the URI provided to ipptool(8).
$job-id
Inserts the last "job-id" attribute value returned in a test response or 0 if no "job-id" attribute has been seen.
$job-uri
Inserts the last "job-uri" attribute value returned in a test response or an empty string if no "job-uri" attribute has been seen.
$notify-subscription-id
Inserts the last "notify-subscription-id" attribute value returned in a test response or 0 if no "notify-subscription-id" attribute has been seen.
$port
Inserts the port number from the URI provided to ipptool(8).
$resource
Inserts the resource path from the URI provided to ipptool(8).
$scheme
Inserts the scheme from the URI provided to ipptool(8).
$uri
Inserts the URI provided to ipptool(8).
$uriuser
Inserts the username from the URI provided to ipptool(8), if any.
$user
Inserts the current user's login name.
