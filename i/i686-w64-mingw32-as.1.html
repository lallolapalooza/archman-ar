NAME

i686-w64-mingw32-as - GNU assembler

SYNOPSIS

as [-I] [--help] [--version] [-EL] [-g] [-mcpu=cpu] [-mfpu=fpu] [-mfloat-abi=abi] [-march=arch] [-msabi=msabi] [-mpad] [-mno-pad] [-mregnames] [-mno-regnames] [-mthreads] [-mno-threads] [-municode] [-mno-unicode] [-mguard] [-mno-guard] [-m64] [-m32] [-EB|-EL] [-o file] [-R dir] [-v] [-W] [--strip] [--traditional] [-x] [--] [objfile... ]

TARGET

i686-w64-mingw32

DESCRIPTION

The GNU assembler, as, runs on the target machine to assemble source code. It supports a variety of object file formats, including COFF, ECOFF, and B.out. It can also produce executables directly.

The i686-w64-mingw32-as executable is part of the GNU Binutils package and is specifically configured for the i686-w64-mingw32 target, meaning it's used for assembling code for 32-bit Windows environments using the MinGW-w64 toolchain.

The assembler reads assembly language input files, processes them, and writes the corresponding object code to an output file.

OPTIONS

The options are those defined by the GNU assembler. For a detailed list and explanation, refer to the full GNU Binutils documentation.

Some common options include:

  • -o file: Place the output into file file.
  • --help: Display a summary of the assembler options.
  • --version: Display the version number of the assembler.
  • -v: Print the assembler version number and exit.
  • -mcpu=cpu: Specify the target CPU.
  • -march=arch: Specify the target architecture.
  • -m32 / -m64: Specify 32-bit or 64-bit mode.
