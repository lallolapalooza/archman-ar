id_t(3type) id_t(3type)

الاسم

pid_t, uid_t, gid_t, id_t - معرف العملية/المستخدم/المجموعة

المكتبة

مكتبة C القياسية (libc)

الملخص

#include <sys/types.h>
typedef /* ... */ pid_t;
typedef /* ... */ uid_t;
typedef /* ... */ gid_t;
typedef /* ... */ id_t;

الوصف

pid_t هو نوع بيانات يستخدم لتخزين معرفات العمليات، معرفات مجموعات العمليات، ومعرفات الجلسات. وهو نوع عدد صحيح موقع.

uid_t هو نوع بيانات يستخدم للاحتفاظ بمعرفات المستخدمين. وهو نوع عدد صحيح.

gid_t هو نوع بيانات يستخدم للاحتفاظ بمعرفات المجموعات. وهو نوع عدد صحيح.

id_t هو نوع بيانات يستخدم للاحتفاظ بمعرف عام. وهو نوع عدد صحيح يمكن استخدامه للاحتفاظ بـ pid_t أو uid_t أو gid_t.

المعايير

POSIX.1-2024.

التاريخ

POSIX.1-2001.

ملاحظات

توفر الرؤوس التالية أيضًا pid_t: <fcntl.h>, <sched.h>, <signal.h>, <spawn.h>, <sys/msg.h>, <sys/sem.h>, <sys/shm.h>, <sys/wait.h>, <termios.h>, <time.h>, <unistd.h>, و <utmpx.h>.

توفر الرؤوس التالية أيضًا uid_t: <pwd.h>, <signal.h>, <stropts.h>, <sys/ipc.h>, <sys/stat.h>, و <unistd.h>.

توفر الرؤوس التالية أيضًا gid_t: <grp.h>, <pwd.h>, <signal.h>, <stropts.h>, <sys/ipc.h>, <sys/stat.h>, و <unistd.h>.

توفر الرأس التالية أيضًا id_t: <sys/resource.h>.
