iscsi_nodes_free(3)

الحزمة: open-iscsi

التراخيص: GPL

iscsi_nodes_free(3) دليل API iscsi_nodes_free(3)

الاسم

iscsi_nodes_free - تحرير ذاكرة مصفوفة المؤشرات 'struct iscsi_node'

الملخص

void iscsi_nodes_free (struct iscsi_node **nodes, uint32_t node_count);

الوسائط

nodes
مؤشر لمصفوفة مؤشرات 'struct iscsi_node'.
node_count
uint32_t، حجم مصفوفة مؤشرات 'struct iscsi_node'.

الوصف

تحرير ذاكرة مصفوفة مؤشرات 'iscsi_node' التي تم إنشاؤها بواسطة إذا كان مؤشر 'nodes' المقدم هو NULL أو 'node_count' هو 0، لا تفعل شيئًا.
