ipq_set_mode(3)

الحزمة: iptables

التراخيص: GPL-2.0-only

IPQ_SET_MODE(3) دليل مبرمج لينكس IPQ_SET_MODE(3)

الاسم

ipq_set_mode — تعيين وضع طابور ip_queue

النبذة

#include <linux/netfilter.h>
#include <libipq.h>

int ipq_set_mode(const struct ipq_handle *h, uint8_t mode, size_t range);

الوصف

تقوم الدالة ipq_set_mode بإرسال رسالة إلى وحدة طابور ip_queue في النواة، تحدد ما إذا كان سيتم نسخ بيانات التعريف الخاصة بالحزمة فقط، أو بيانات التعريف بالإضافة إلى حمولات الحزمة إلى مساحة المستخدم.

المعلم h هو مقبض سياق يجب أن يكون قد تم إرجاعه بنجاح مسبقًا من استدعاء ipq_create_handle.

يجب أن يكون المعلم mode أحد الخيارات التالية:

IPQ_COPY_META
نسخ بيانات التعريف الخاصة بالحزمة فقط إلى مساحة المستخدم.
IPQ_COPY_PACKET
نسخ بيانات التعريف الخاصة بالحزمة وحمولات الحزمة إلى مساحة المستخدم.

يستخدم المعلم range لتحديد عدد البايتات من الحمولة التي سيتم نسخها إلى مساحة المستخدم. وهو صالح فقط لوضع IPQ_COPY_PACKET ويتم تجاهله بخلاف ذلك. الحد الأقصى للقيمة المفيدة لـ range هو 65535 (سيتم تقييد القيم الأكبر إلى هذا بواسطة ip_queue).

تستخدم ipq_set_mode عادةً فورًا بعد ipq_create_handle لتمكين تدفق الحزم إلى مساحة المستخدم.

لاحظ أنه نظرًا لأن آلية النقل Netlink الأساسية غير متصلة، فإن وحدة ip_queue لا تعرف أن تطبيق مساحة المستخدم جاهز للتواصل حتى يستلم رسالة مثل هذه.

قيمة الإرجاع

عند الفشل، يتم إرجاع -1.
عند النجاح، يتم إرجاع قيمة موجبة غير صفرية.

الأخطاء

عند الفشل، ستكون رسالة الخطأ الوصفية متاحة عبر الدالة ipq_errstr.

التشخيص

قد يحدث فشل شائع نسبيًا إذا لم يتم تحميل وحدة ip_queue. في هذه الحالة، المقطع البرمجي التالي:

status = ipq_set_mode(h, IPQ_COPY_META, 0);
if (status < 0) {
	ipq_perror("myapp");
	ipq_destroy_handle(h);
	exit(1);
}

سينتج عنه الإخراج التالي:

myapp: Failed to send netlink message: Connection refused
