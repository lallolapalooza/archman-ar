icestormdb(1)

الحزمة: zeroc-ice

التراخيص: GPL, custom:ice

icestormdb(1) دليل الأوامر العامة icestormdb(1)

الاسم

icestormdb - أداة استيراد/تصدير قاعدة بيانات IceStorm.

ملخص

icestormdb [خيارات]

الوصف

أداة icestormdb هي أداة سطر أوامر لاستيراد وتصدير قواعد بيانات IceStorm. التوثيق الكامل لأداة icestormdb متاح عبر الإنترنت على:


https://doc.zeroc.com/ice/3.7/ice-services/icestorm/icestorm-database-utility

خيارات

-h, --help

عرض مساعدة البرنامج.
-v, --version

عرض إصدار Ice.
-v, --version

عرض إصدار Ice.
--import FILE

استيراد قاعدة البيانات من الملف المحدد.
--export FILE

تصدير قاعدة البيانات إلى الملف المحدد.
--dbpath DIR

مصدر أو وجهة بيئة قاعدة البيانات.
--mapsize VALUE

تعيين حجم خريطة LMDB بالميجابايت (اختياري، للاستيراد فقط).
-d, --debug

طباعة رسائل التصحيح.

انظر أيضًا

icestormadmin(1)
