ipmi_ui(1)

الحزمة: openipmi

التراخيص: LGPL2.1

- title: SYSTEM EVENT LOG (SEL) content: | An event is specified by the MC it came from in the format "(channel addr)" and a log number. The same log number may exist in multiple MCs. Events are displayed in the log window as they come in. If they can be correlated with a sensor, they will be display with as much information as possible. - command: delevent args: "channel mc-addr log-num" description: | Delete the given event. Note that many SELs do not support individual deletes, so this may only delete the local copy of the event, not the one in the SEL. In this case, to delete events in the SEL, you must delete *all* the events in the SEL and wait about 10 seconds for OpenIPMI to do a full SEL clear. - command: clear_sel description: | Delete all events in the SEL. This process may take some time, so if you do this and quit immediately it may not be complete. - command: list_sel description: | List all events in the local copy of the SELs. This is only the local copy, if the copies in the actual have change, this won't be reflected. - command: get_sel_time args: "channel mc-num" description: | Get the time in the SEL for the given MC. - title: MANAGMENT CONTROLLERS (MCs) content: | In OpenIPMI, you normally don't deal with management controllers. They are considered internal to the system. However, for debugging, information about them is provided. - command: mcs description: | List all the MCs in the system and whether they are active. MCs are displayed in the format "(channel address)". - command: mc args: "channel mc-addr" description: | Display a boatload of information about the MC, mostly coming from the get device id command. - command: mccmd args: "channel mc-addr LUN NetFN Cmd [data ...]" description: | Send an IPMI command to the given MC. The MC must exist and be active to do this. - command: mc_reset args: "channel mc-addr [warm | cold]" description: | Send a warm or cold reset command to the given MC. The action the MC takes is system-specific. - command: scan args: "channel mc-addr" description: | Scan for an MC at the given address. If the MC exists but OpenIPMI didn't know about it, it will be added. If the MC no longer exists, then it will be removed. - command: mc_events_enable args: "channel mc-num enabled" description: | Enable or disable event generation for the given MC. - command: mc_events_enabled args: "channel mc-num" description: | Prints out if the events are enabled for the given MC. - title: LAN Parameter Configuration content: | OpenIPMI has functions that make it easier to configure the LAN parameters of a LAN connection. Note that the LAN parameters have a lock that OpenIPMI attempts to use. If you read the LAN parameters, they will be locked until you either write them or clear the lock. - command: readlanparm args: "channel mc-num channel" description: | Read lanparm information from an MC and display it in the display window. - command: viewlanparm description: | Show current lanparm information in the display window. - command: writelanparm args: "channel mc-num channel" description: | Write the current LANPARM information to an MC. Note that this must be the MC that the parameters were read from. - command: clearlanparmlock args: "[channel mc-num channel]" description: | Clear a LANPARM lock. If the MC is given, then the LANPARM lock is directly cleared. If not given, then the LANPARM lock for the current parms is cleared. - command: setlanparm args: "config [selector] value" description: | Set the given config item to the value. The optional selector is used for items that take a selector, like "auth" or any of the items in "destination". - title: Platform Event Filter (PEF) content: | OpenIPMI contains function to help manage the PEF settings on a BMC. Note that the PEF parameters have a lock that OpenIPMI attempts to use. If you read the PEF parameters, they will be locked until you either write them or clear the lock. - command: readpef args: "channel mc-num" description: | Read the PEF information from an MC. - command: clearpeflock args: "[channel mc-num]" description: | Clear a PEF lock. If the MC is given, then the PEF lock on that MC is directly cleared. If no MC is given, then the current PEF's lock is cleared. - command: viewpef description: | Show current pef information in the display window. - command: writepef args: "channel mc-num" description: | Write the current PEF information to an MC. - command: setpef args: "config [selector] value" description: | Set the given config item to the value. The optional selector is used for items that take a selector, like anything in the event filters, alert policies, or alert strings. - command: pet args: "connection channel ip-addr mac_addr eft-selector policy-num apt-selector lan-dest-selector" description: | Set up the connection for the domain to send PET traps from the given connection to the given IP/MAC address over the given channel. This does all the LAN and PEF configuration required to configure a system to send event traps. - title: CONNECTIONS content: | OpenIPMI can maintain multiple connections to a single domain. It will generally only use one of these at a time (although the other will constantly be under test). This is the "active" connection. You can query and set which connection is active. The connection number is the connection from the command line. You can specify two connections on the command line (the part beginning with "**lan**", "**smi**", etc.). The first connection you specify is *connection zero, the second is connection 1. - command: is_con_active args: "connection" description: | Print out if the given connection is active or not. - command: activate_con args: "connection" description: | Activate the given connection. - title: OTHER COMMANDS content: | - command: msg args: "channel IPMB-addr LUN NetFN Cmd [data ...]" description: | Send an IPMI command to the given IPMB address. This is available in case the given MC cannot be found or enabled. - command: sdrs args: "channel mc-addr do-sensors" description: | Dump all the sdrs from the given MC. If *do-sensors* is **true**, then dump the device SDR. If it is **false**, dump the main SDR repository on the MC. - command: scan args: "channel IPMB-addr" description: | Perform an IPMB bus scan for the given IPMB, to try to detect an MC at the given address. IPMB bus scanning can be slow, this can help speed things up if you already know the address. - command: quit description: Leave the program. - command: reconnect description: | Attempt to disconnect and reconnect to the IPMI controller. This is primarily for testing. - command: display_win description: | Set the display window (left window) for scrolling, just in case the "**F1**" key doesn't work. - command: log_win description: | Set the log window (right window) for scrolling, just in case the "**F2**" key doesn't work. - command: help description: Dump some terse help output about all the commands. - title: ERROR OUTPUT content: | All error output goes to the log window. - title: SEE ALSO content: | ipmilan(8) - title: KNOWN PROBLEMS content: | Our name is legion. - title: AUTHOR content: | Corey Minyard
