IMGTOOL(1) أداة لمعالجة صور وسائط MESS IMGTOOL(1)

الاسم

imgtool - أداة لمعالجة صور وسائط MESS

الملخص

imgtool create format image [option ...]
imgtool dir format image [path]
imgtool get format image file [newname] [--filter=filter] [--fork=fork]
imgtool put format image file ... [newname] [option ...] [--filter=filter] [--fork=fork]
imgtool getall format image [path] [--filter=filter]
imgtool del format image file ...
imgtool mkdir format image directory
imgtool rmdir format image directory ...
imgtool readsector|writesector format image track head sector file
imgtool identify image
imgtool listformats|listfilters
imgtool listdriveroptions format

الوصف

imgtool هي أداة لصيانة ومعالجة صور الأقراص وأنواع أخرى من الصور التي يحتاج مستخدمو MESS إلى التعامل معها. تشمل الوظائف استرداد الملفات وتخزينها وتحقق CRC والتحقق من الصحة. يمكن أن تكون ملفات الصور أيضًا داخل ملفات .zip.

خيارات

create
ينشئ صورة. يمكن تحديد معلمات خاصة بالصورة اختيارية، راجع الأمر imgtool listdriveroptions للحصول على قائمة كاملة.
dir
يسرد محتويات صورة.
get
يحصل على ملف واحد من صورة. يمكن تحديد مرشح لتحويل تنسيقات الملفات المخصصة إلى ASCII، راجع الأمر imgtool listfilters للحصول على قائمة كاملة. يمكن إعادة تسمية الملف اختياريًا.
put
يضع ملفات (ملفات) على صورة (يدعم الأحرف البديلة وإعادة التسمية). يتم توفير مرشحات لتحويل ملفات ASCII إلى تنسيقات ملفات مخصصة، راجع الأمر imgtool listfilters للحصول على قائمة كاملة.
getall
يحصل على جميع الملفات من صورة. يمكن تحديد مرشحات لتحويل تنسيقات الملفات المخصصة إلى ASCII، راجع الأمر imgtool listfilters للحصول على قائمة كاملة.
del
يحذف ملفًا على صورة.
mkdir
ينشئ مجلدًا على صورة.
rmdir
يحذف مجلدات على صورة.
readsector
يستخرج محتويات قطاع واحد من صورة إلى ملف.
writesector
يكتب محتوى الملف إلى قطاع محدد على صورة.
identify
يحاول التعرف على تنسيق ملف الصورة.
listformats
يسرد جميع تنسيقات ملفات الصور التي تدعمها imgtool.
listfilters
يسرد جميع المرشحات التي تدعمها imgtool. المرشحات هي وسيلة لمعالجة البيانات التي يتم كتابتها إلى صورة أو قراءتها منها بطريقة معينة.
listdriveroptions
يسرد جميع الخيارات الخاصة بالتنسيق لأوامر imgtool put و imgtool create.

أمثلة

imgtool dir coco_jvc_rsdos myimageinazip.zip

imgtool get coco_jvc_rsdos myimage.dsk myfile.bin mynewfile.txt

imgtool getall coco_jvc_rsdos myimage.dsk
