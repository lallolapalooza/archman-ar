iscsi_log_priority_str(3)

الحزمة: open-iscsi

التراخيص: GPL

iscsi_log_priority_str(3) دليل API iscsi_log_priority_str(3)

الاسم

iscsi_log_priority_str - تحويل أولوية السجل إلى سلسلة نصية.

الملخص

const char * iscsi_log_priority_str (int priority);

المعاملات

priority
int. أولوية السجل.

الوصف

تحويل أولوية السجل إلى سلسلة نصية (const char *).

القيمة المُرجعة

const char *. يرجى عدم تحرير المؤشر المُرجع. السلاسل النصية الصالحة هي:

* "ERROR" لـ LIBISCSI_LOG_PRIORITY_ERROR

* "WARN" لـ LIBISCSI_LOG_PRIORITY_WARNING

* "INFO" لـ LIBISCSI_LOG_PRIORITY_INFO

* "DEBUG" لـ LIBISCSI_LOG_PRIORITY_DEBUG

* "Invalid argument" لأولوية سجل غير صالحة.
