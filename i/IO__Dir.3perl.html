IO::Dir(3perl) دليل مبرمجي بيرل IO::Dir(3perl)

الاسم

IO::Dir - توفير وظائف الكائنات لمقابض الدليل

ملخص

use IO::Dir;
my $d = IO::Dir->new(".");
if (defined $d) {
    while (defined($_ = $d->read)) { something($_); }
    $d->rewind;
    while (defined($_ = $d->read)) { something_else($_); }
    undef $d;
}
tie my %dir, 'IO::Dir', ".";
foreach (keys %dir) {
    print $_, " " , $dir{$_}->size,"\n";
}

الوصف

توفر الحزمة "IO::Dir" واجهتين لروتينات قراءة الدليل في بيرل.

الواجهة الأولى هي نهج الكائنات. توفر "IO::Dir" مُنشئ كائنات ووظائف، وهي مجرد أغلفة حول روتينات قراءة الدليل المدمجة في بيرل.

new ( [ DIRNAME ] )
"new" هو المُنشئ لكائنات "IO::Dir". يقبل وسيطًا اختياريًا واحدًا، والذي إذا تم تقديمه، فسيمرره "new" إلى "open"

الوظائف التالية هي أغلفة للدوال المتعلقة بالدليل المدمجة في بيرل (تمت إزالة 'dir' اللاحقة من الأسماء). انظر perlfunc للحصول على تفاصيل هذه الدوال.

open ( DIRNAME )
read ()
seek ( POS )
tell ()
rewind ()
close ()

توفر "IO::Dir" أيضًا واجهة لقراءة الأدلة عبر جدول مرتبطة. يوسع الجدول المرتبطة الواجهة بما يتجاوز مجرد روتينات قراءة الدليل باستخدام "lstat"، من حزمة "File::stat"، "unlink"، "rmdir" و "utime".

tie %hash, 'IO::Dir', DIRNAME [, OPTIONS ]

ستكون مفاتيح الجدول هي أسماء الإدخالات في الدليل. قراءة قيمة من الجدول ستكون نتيجة استدعاء "File::stat::lstat". حذف عنصر من الجدول سيؤدي إلى حذف الملف أو الدليل الفرعي المقابل، بشرط تضمين "DIR_UNLINK" في "OPTIONS".

سيؤدي التعيين إلى عنصر في الجدول إلى تعديل الطوابع الزمنية للملف. إذا كان الملف غير موجود، فسيتم إنشاؤه. سيؤدي تعيين عدد صحيح واحد إلى عنصر في الجدول إلى تغيير كل من وقت الوصول ووقت التعديل إلى تلك القيمة. بدلاً من ذلك، يمكن تمرير مرجع إلى مصفوفة من قيمتين. سيتم استخدام عنصر المصفوفة الأول لتعيين وقت الوصول والعنصر الثاني لتعيين وقت التعديل.
