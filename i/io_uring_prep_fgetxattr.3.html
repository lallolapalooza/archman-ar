io_uring_prep_getxattr(3) دليل liburing io_uring_prep_getxattr(3)

الاسم

io_uring_prep_getxattr, io_uring_prep_fgetxattr - تحضير طلب للحصول على قيمة سمة موسعة

النبذة

#include <liburing.h>
void io_uring_prep_getxattr(struct io_uring_sqe *sqe,
                            const char *name,
                            char *value,
                            const char *path,
                            unsigned int len);
void io_uring_prep_fgetxattr(struct io_uring_sqe *sqe,
                             int fd,
                             const char *name,
                             char *value,
                             unsigned int len);

الوصف

تقوم الدالة io_uring_prep_getxattr(3) بتحضير طلب للحصول على قيمة سمة موسعة. يتم إعداد إدخال صف الانتظار للإرسال sqe للحصول على value للسمة الموسعة التي تم تعريفها بواسطة name والمرتبطة بالمسار path المحدد في نظام الملفات. تحدد الوسيطة len حجم (بالبايت) value.

الدالة io_uring_prep_fgetxattr(3) مطابقة للدالة io_uring_prep_getxattr(3)، ولكنها تستعلم عن الملف المفتوح المشار إليه بواسطة fd بدلاً من path.

تقوم هذه الدالة بتحضير طلب getxattr(2) غير متزامن. راجع صفحة الدليل تلك للحصول على التفاصيل.
