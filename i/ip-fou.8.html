ip-fou(8)

الحزمة: iproute2

التراخيص: GPL-2.0-or-later

IP-FOU(8) Linux IP-FOU(8)

الاسم

ip-fou - تكوين منفذ استقبال Foo-over-UDP

ip-gue - تكوين منفذ استقبال التغليف العام UDP

الموجز


ip [ خيارات ] fou { أمر | help }

ip fou add port منفذ { gue | ipproto بروتوكول } [ local عنوان IP ] [ peer عنوان IP ] [ peer_port منفذ ] [ dev اسم جهاز ]
ip fou del port منفذ [ local عنوان IP ] [ peer عنوان IP ] [ peer_port منفذ ] [ dev اسم جهاز ]
ip fou show

الوصف

تُستخدم أوامر ip fou لإنشاء وحذف منافذ الاستقبال لـ Foo-over-UDP (FOU) وكذلك Generic UDP Encapsulation (GUE).

يسمح Foo-over-UDP بتغليف حزم بروتوكول IP مباشرة فوق UDP. يستنتج المستلم بروتوكول الحزمة المستلمة على منفذ FOU UDP ليكون البروتوكول المحدد للمنفذ.

يقوم Generic UDP Encapsulation (GUE) بتغليف حزم بروتوكول IP داخل UDP ورأس تغليف. يحتوي رأس التغليف على رقم بروتوكول IP للحزمة المغلفة.

عند إنشاء منفذ استقبال FOU أو GUE، يتم تحديد رقم المنفذ في الوسيط PORT. إذا تم استخدام FOU، يتم تحديد رقم بروتوكول IP المرتبط بالمنفذ في الوسيط PROTO. يمكنك ربط منفذ بعنوان محلي / واجهة، عن طريق تحديد العنوان في الوسيط IFADDR المحلي أو الجهاز في الوسيط IFNAME. إذا كنت ترغب في توصيل المنفذ، يمكنك تحديد عنوان النظير في الوسيط IFADDR للنظير ومنفذ النظير في الوسيط PORT للنظير.

يتم حذف منفذ استقبال FOU أو GUE عن طريق تحديد PORT في أمر الحذف، بالإضافة إلى العنوان المحلي / الواجهة أو عنوان / منفذ النظير (إذا تم تعيينه).

أمثلة

تكوين منفذ استقبال FOU لـ GRE مرتبط بالمنفذ 7777

# ip fou add port 7777 ipproto 47

تكوين منفذ استقبال FOU لـ IPIP مرتبط بالمنفذ 8888

# ip fou add port 8888 ipproto 4

تكوين منفذ استقبال GUE مرتبط بالمنفذ 9999

# ip fou add port 9999 gue

حذف منفذ استقبال GUE المرتبط بالمنفذ 9999

# ip fou del port 9999

تكوين منفذ استقبال FOU لـ GRE مرتبط بالعنوان 1.2.3.4 والمنفذ 7777

# ip fou add port 7777 ipproto 47 local 1.2.3.4
