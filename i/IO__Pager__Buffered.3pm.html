IO__Pager__Buffered(3pm)

الحزمة: perl-io-pager

التراخيص: GPL, PerlArtistic

IO::Pager::Buffered(3) توثيق مساهمة المستخدم في بيرل IO::Pager::Buffered(3)

الاسم

IO::Pager::Buffered - توجيه المخرجات المؤجلة إلى PAGER إذا كان الوجهة TTY

الملخص

use IO::Pager::Buffered;
{
  local $token = IO::Pager::Buffered::open local *STDOUT;
  print <<"  HEREDOC" ;
  ...
  A bunch of text later
  HEREDOC
}
{
  # يمكنك أيضًا استخدام مقبض ملف عددي...
  my $token = IO::Pager::Buffered::open($FH) or warn($!);
  print $FH "No globs or barewords for us thanks!\n" while 1;
}
{
  # ... أو واجهة كائن
  my $token = new IO::Pager::Buffered;
  $token->print("OO shiny...\n") while 1;
}

الوصف

تم تصميم الفئات الفرعية لـ IO::Pager لتحديد ما إذا كان سيتم توجيه مخرجات مقبض الملف إلى برنامج محدد في PAGER برمجيًا؛ يتم تحديده وتعيينه بواسطة IO::Pager في وقت التشغيل إذا لم يتم تعريفه بعد.

تقوم هذه الفئة الفرعية بتخزين كافة المخرجات مؤقتًا للعرض حتى تعود إلى النطاق الأصلي أو يحدث مسح يدوي. إذا لم يكن هذا ما تريده، فابحث عن فئة فرعية أخرى مثل IO::Pager::Unbuffered. على الرغم من أنه قد لا يكون شائعًا، إلا أن هذا قد يكون مفيدًا في بعض الحالات، مثل تخزين كافة المخرجات إلى STDOUT أثناء حدوث العملية حتى تكون التحذيرات على STDERR أكثر وضوحًا، ثم عرض المخرجات الأقل إلحاحًا من STDOUT لاحقًا. أو، بدلاً من ذلك، ترك المخرجات إلى STDOUT تمر وتأجيل التحذيرات للمراجعة لاحقًا.

الطرق

تفاصيل الطريقة الخاصة بالفئة أدناه، يتم وراثة الطرق الأخرى من IO::Pager.

open( [FILEHANDLE] )

إنشاء مثيل جديد لـ IO::Pager لتقسيم FILEHANDLE إذا لزم الأمر. قم بتعيين القيمة المرجعة إلى متغير نطاق. لا تحدث المخرجات حتى يتم مسح مقبض الملف أو إغلاقه.

new( [FILEHANDLE] )

مطابق تقريبًا لـ open، باستثناء أنك ستحصل على IO::Handle إذا لم يكن هناك TTY للسماح بالبرمجة المستقلة عن IO::Pager.

close( FILEHANDLE )

يمسح المخزن المؤقت إلى PAGER ويغلق مقبض الملف للكتابة. عادةً، عند استخدام متغير نطاق معجمي أو محلي للاحتفاظ بالرمز المميز الذي توفره open، فإن الاستدعاءات الصريحة لـ close غير ضرورية. ومع ذلك، إذا كنت تستخدم IO::Pager::Buffered مع STDOUT أو STDERR غير محلي، فأغلق مقبض الملف لعرض المحتوى المخزن مؤقتًا أو انتظر التنظيف العام للذاكرة بعد انتهاء البرنامج.

بدلاً من ذلك، قد تفضل استخدام مقبض ملف غير أساسي مع IO::Pager، واستدعاء "select" في perlfunc لجعله الافتراضي للمخرجات.

tell( FILEHANDLE )

يعيد حجم المخزن المؤقت بالبايت.

flush( FILEHANDLE )

يمسح محتويات المخزن المؤقت على الفور.

إذا لم ينتهِ آخر طباعة بسطر جديد، فسيتم مسح النص من السطر الجديد السابق حتى نهاية المخزن المؤقت ولكنه غير مرجح أن يظهر حتى تتم طباعة سطر جديد ومسحه.

محاذير

إذا قمت بخلط العمليات المخزنة مؤقتًا وغير المخزنة مؤقتًا، فإن ترتيب المخرجات غير محدد، ومن المحتمل أن يختلف لـ TTY مقابل ملف. انظر perlfunc.

يتم استخدام $، انظر perlvar.

ربما ترغب في فعل شيء بـ SIGPIPE على سبيل المثال؛

eval {
  local $SIG{PIPE} = sub { die };
  local $STDOUT = IO::Pager::open(*STDOUT);
  while (1) {
    # Do something
  }
}
# Do something else
