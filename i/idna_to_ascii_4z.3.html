idna_to_ascii_4z(3)

الحزمة: libidn

التراخيص: GPL3, LGPL

idna_to_ascii_4z(3) libidn idna_to_ascii_4z(3)

الاسم

idna_to_ascii_4z - وظيفة API

الملخص

#include <idna.h>

int idna_to_ascii_4z(const uint32_t * input, char ** output, int flags);

المعاملات

const uint32_t * input
سلسلة UTF-32 المدخلة المنتهية بصفر.
char ** output
مؤشر إلى سلسلة الإخراج المخصصة حديثًا.
int flags
قيمة Idna_flags، على سبيل المثال IDNA_ALLOW_UNASSIGNED أو IDNA_USE_STD3_ASCII_RULES.

الوصف

تحويل اسم نطاق UCS-4 إلى سلسلة ASCII. قد يحتوي اسم النطاق على عدة تسميات، مفصولة بنقاط. يجب إلغاء تخصيص المخزن المؤقت للإخراج بواسطة المتصل.

قيمة الإرجاع: تُرجع IDNA_SUCCESS عند النجاح، أو رمز خطأ.
