الاسم

io_uring_register_files - تسجيل واصفات الملفات

الاختصار

#include <liburing.h>
int io_uring_register_files(struct io_uring *ring,
                            const int *files,
                            unsigned nr_files);
int io_uring_register_files_tags(struct io_uring *ring,
                                 const int *files,
                                 const __u64 *tags,
                                 unsigned nr);
int io_uring_register_files_sparse(struct io_uring *ring,
                                   unsigned nr_files);
int io_uring_register_files_update(struct io_uring *ring,
                                   unsigned off,
                                   const int *files,
                                   unsigned nr_files);
int io_uring_register_files_update_tag(struct io_uring *ring,
                                   unsigned off,
                                   const int *files,
                                   const __u64 *tags,
                                   unsigned nr_files);

الوصف

تقوم الدالة io_uring_register_files(3) بتسجيل nr_files عدد من واصفات الملفات المحددة بواسطة المصفوفة files التابعة لـ ring للعمليات اللاحقة.

تتصرف الدالة io_uring_register_files_tags(3) بنفس طريقة الدالة io_uring_register_files(3) ولكنها تأخذ بالإضافة إلى ذلك المعلمة tags. انظر IORING_REGISTER_BUFFERS2 لوصف وسم الموارد.

تقوم الدالة io_uring_register_files_sparse(3) بتسجيل جدول ملفات فارغ لعدد nr_files من واصفات الملفات. يجب تحديث هذه الملفات قبل الاستخدام، باستخدام على سبيل المثال io_uring_register_files_update_tag(3). لاحظ أنه إذا تجاوز حجم الجدول المتناثر ما تسمح به RLIMIT_NOFILE، فإن io_uring_register_files_sparse(3) ستحاول رفع الحد باستخدام setrlimit (2) وإعادة محاولة العملية. إذا فشل التسجيل بعد القيام بذلك، فسيتم إرجاع خطأ. المتغير المتناثر متاح في الأنوية 5.19 وما بعدها.

يعد تسجيل جدول ملفات شرطًا مسبقًا لاستخدام أي طلب يستخدم واصفات مباشرة.

الملفات المسجلة لها حمل أقل لكل عملية من الملفات العادية. هذا بسبب قيام النواة بالحصول على عدد مراجع لملف عند بدء عملية، وإسقاطه عند الانتهاء. عندما تكون طاولة ملفات العملية مشتركة، على سبيل المثال إذا كانت العملية قد أنشأت أي مؤشرات ترابط، فإن هذه التكلفة تزداد أكثر. استخدام الملفات المسجلة يقلل من تكلفة إدارة مراجع الملفات عبر العمليات التي تعمل على ملف.

تقوم الدالة io_uring_register_files_update(3) بتحديث الملفات المسجلة الموجودة. off هو الإزاحة التي تبدأ منها التحديث لعدد nr_files من الملفات المحددة بواسطة المصفوفة files التابعة لـ ring.

تتصرف الدالة io_uring_register_files_update_tag(3) بنفس طريقة الدالة io_uring_register_files_update(3) ولكنها تأخذ بالإضافة إلى ذلك المعلمة tags. انظر IORING_REGISTER_BUFFERS2 لوصف وسم الموارد.

قيمة الإرجاع

عند النجاح، ترجع io_uring_register_files(3)، io_uring_register_files_tags(3)، و io_uring_register_files_sparse(3) القيمة 0. ترجع io_uring_register_files_update(3) و io_uring_register_files_update_tag(3) عدد الملفات التي تم تحديثها. عند الفشل، ترجع -errno.
