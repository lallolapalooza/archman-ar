io_uring_register_buffers(3) دليل liburing io_uring_register_buffers(3)

اسم

io_uring_register_buffers - تسجيل المخازن المؤقتة لعمليات المخازن المؤقتة الثابتة

ملخص

#include <liburing.h>
int io_uring_register_buffers(struct io_uring *ring,
                              const struct iovec *iovecs,
                              unsigned nr_iovecs);
int io_uring_register_buffers_tags(struct io_uring *ring,
                                   const struct iovec *iovecs,
                                   const __u64 *tags,
                                   unsigned nr);
int io_uring_register_buffers_sparse(struct io_uring *ring,
                                     unsigned nr_iovecs);
int io_uring_register_buffers_update_tag(struct io_uring *ring,
                                         unsigned off,
                                         const struct iovec *iovecs,
                                         const __u64 *tags,
                                         unsigned nr);

وصف

تقوم الدالة io_uring_register_buffers(3) بتسجيل nr_iovecs عدد من المخازن المؤقتة المحددة بواسطة المصفوفة iovecs التابعة لـ ring.

تتصرف الدالة io_uring_register_buffers_tags(3) بنفس طريقة الدالة io_uring_register_buffers(3) ولكنها تأخذ أيضًا معامل tags. انظر IORING_REGISTER_BUFFERS2 لوصف وسم الموارد.

تقوم الدالة io_uring_register_buffers_sparse(3) بتسجيل nr_iovecs مخزن مؤقت فارغ تابع لـ ring. يجب تحديث هذه المخازن المؤقتة قبل الاستخدام، باستخدام على سبيل المثال io_uring_register_buffers_update_tag(3).

بعد أن يقوم المتصل بتسجيل المخازن المؤقتة، يمكن استخدامها مع إحدى دوال المخازن المؤقتة الثابتة.

تعتبر المخازن المؤقتة المسجلة تحسينًا مفيدًا بالاقتران مع القراءة والكتابة O_DIRECT، حيث تقوم بتعيين النطاق المحدد في النواة مرة واحدة عند تسجيل المخزن المؤقت بدلاً من إجراء تعيين وإلغاء تعيين لكل عملية إدخال/إخراج في كل مرة يتم فيها إجراء إدخال/إخراج إلى هذا النطاق. بالإضافة إلى ذلك، تتجنب أيضًا معالجة عدد مراجع الصفحة لكل عملية إدخال/إخراج.

تقوم الدالة io_uring_register_buffers_update_tag(3) بتحديث المخازن المؤقتة المسجلة بأخرى جديدة، إما بتحويل إدخال متفرق إلى إدخال حقيقي، أو استبدال إدخال موجود. off هو الإزاحة التي يبدأ عندها التحديث، nr هو عدد المخازن المؤقتة المحددة بواسطة المصفوفة iovecs التابعة لـ ring. تشير tags إلى مصفوفة من الوسوم. انظر IORING_REGISTER_BUFFERS2 لوصف وسم الموارد.

قيمة الإرجاع

عند النجاح، ترجع io_uring_register_buffers(3)، io_uring_register_buffers_tags(3) و io_uring_register_buffers_sparse(3) القيمة 0. ترجع io_uring_register_buffers_update_tag(3) عدد المخازن المؤقتة التي تم تحديثها. عند الفشل، ترجع -errno.
