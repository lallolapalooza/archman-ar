IBV_QUERY_GID(3) دليل مبرمج Libibverbs IBV_QUERY_GID(3)

الاسم

ibv_query_gid - استعلام عن جدول GID الخاص بمنفذ InfiniBand

ملخص

#include <infiniband/verbs.h>
int ibv_query_gid(struct ibv_context *context,
                  uint8_t port_num,
                  int index,
                  union ibv_gid *gid);

الوصف

ibv_query_gid() ترجع قيمة GID في الإدخال index من المنفذ port_num لسياق الجهاز context عبر المؤشر gid.

قيمة الإرجاع

ibv_query_gid() ترجع 0 عند النجاح، و -1 عند الخطأ.

انظر أيضًا

ibv_open_device(3)، ibv_query_device(3)، ibv_query_pkey(3)، ibv_query_port(3)
