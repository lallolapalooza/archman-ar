idn2_to_ascii_4z(3)

الحزمة: libidn2

التراخيص: GPL2, LGPL3

idn2_to_ascii_4z(3) libidn2 idn2_to_ascii_4z(3)

الاسم

idn2_to_ascii_4z - دالة API

الملخص

#include <idn2.h>

int idn2_to_ascii_4z(const uint32_t * input, char ** output, int flags);

المعاملات

const uint32_t * input
سلسلة Unicode (UCS-4) المدخلة المنتهية بصفر.
char ** output
مؤشر إلى سلسلة الإخراج المخصصة حديثًا والمنتهية بصفر.
int flags
idn2_flags اختيارية لتعديل السلوك.

الوصف

قم بتحويل اسم نطاق UCS-4 إلى سلسلة ASCII باستخدام قواعد IDNA2008. قد يحتوي اسم النطاق على عدة تسميات، مفصولة بنقاط. يجب إلغاء تخصيص مخزن الإخراج بواسطة المتصل.

السلوك الافتراضي لهذه الدالة (عندما تكون العلامات صفرًا) هو تطبيق قواعد IDNA2008 بدون تعديلات TR46. نظرًا لأن المعالجة غير الانتقالية لـ TR46 منتشرة في الوقت الحاضر، فعند عدم التأكد، يوصى باستدعاء هذه الدالة مع علامتي IDN2_NONTRANSITIONAL و IDN2_NFC_INPUT لضمان التوافق مع البرامج الأخرى.

قيمة الإرجاع: تُرجع IDN2_OK عند النجاح، أو رمز الخطأ.
