is(n)

الحزمة: tcl

التراخيص: TCL

is(n) [incr Tcl] is(n)

الاسم

itcl::is - اختبار الوسيط لمعرفة ما إذا كان فئة أو كائن

الملخص

itcl::is option ?arg arg ...?

الوصف

يُستخدم الأمر is للتحقق مما إذا كان الوسيط المعطى فئة أو كائنًا؛ اعتمادًا على الخيار المعطى. إذا كان الوسيط فئة أو كائنًا، فسيتم إرجاع 1. بخلاف ذلك، سيتم إرجاع 0. يتعرف الأمر is أيضًا على الأوامر المغلفة في أمر itcl code.

يحدد الوسيط option الإجراء الذي يتم تنفيذه بواسطة الأمر. Options القانونية (التي يمكن اختصارها) هي:

is class command
يرجع 1 إذا كان الأمر فئة، ويرجع 0 بخلاف ذلك.

يجب إعطاء الاسم المؤهل بالكامل للفئة كوسيط command. لذا، إذا كانت فئة ما موجودة في مساحة اسم، فيجب تحديد مساحة الاسم أيضًا. لذلك، إذا كانت فئة C موجودة في مساحة اسم N، فيجب استدعاء الأمر على النحو التالي:

is N::C
    أو
is ::N::C
is object ?-class className? command
يرجع 1 إذا كان command كائنًا، ويرجع 0 بخلاف ذلك.

إذا تم تحديد المعامل الاختياري "-class"، فسيتم التحقق من command في سياق الفئة المعطاة. لاحظ أن className يجب أن تكون موجودة. إذا لم تكن كذلك، فسيتم طرح خطأ. لذلك، إذا كان className غير مؤكد لوجوده كفئة، فسيحتاج المبرمج إلى التحقق من وجوده مسبقًا، أو تغليفه في عبارة catch.

لذلك، إذا كان c كائنًا في الفئة C، في مساحة الاسم N، فإليك الاحتمالات (كلها ترجع 1):

set obj [N::C c]
itcl::is object N::c
itcl::is object c
itcl::is object $obj
itcl::is object [itcl::code c]
