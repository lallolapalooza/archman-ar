iodbctest(1)

الحزمة: libiodbc

التراخيص: LGPL

iodbctest(1) مدير تعريفات iODBC iodbctest(1)

الاسم

iodbctest, iodbctestw - برامج توضيحية لـ iODBC

الملخص

iodbctest ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=value]"]
iodbctestw ["DSN=xxxx[;UID=xxxx][;PWD=xxxx][;OPT=value]"]

الوصف

برنامج iodbctest وبرامج iodbtestw هي برامج عينة بسيطة لـ ODBC، تُظهر قوة واجهة برمجة تطبيقات ODBC للاتصال بأي قاعدة بيانات تدعم ODBC، وإصدار أوامر SQL واسترداد نتائج الاستعلام.

يستخدم برنامج iodbctest استدعاءات واجهة برمجة تطبيقات ODBC القياسية للاتصال باستخدام أي DSN، ولكنه يسترد جميع النتائج في وضع ASCII.

يستخدم برنامج iodbctestw استدعاءات واجهة برمجة تطبيقات Unicode لـ ODBC للاتصال باستخدام أي DSN، ويسترد جميع النتائج في وضع Unicode.

الخيارات

يستخدم برنامج iodbctest الدالة SQLDriverConnect لإجراء اتصال باستخدام أي تعريف تعريف ODBC متاح. يتيح ذلك للمستخدم تجاوز أي سمة اتصال ODBC في سلسلة DSN.

يجب أن تبدأ سلاسل الاتصال إما بسمة DSN=xxx أو بسمة DRIVER=xxxx، تليها اختياريًا سمات DSN أخرى مفصولة بفاصلة منقوطة، على سبيل المثال:

DSN=ora9;UID=scott;PWD=tiger;DATABASE=ora9u

يجب أن تكون أي سمات مطلوبة لاتصال صحيح وغير مدخلة في سلسلة اتصال DSN موجودة في ملف odbc.ini.

إذا تم تمرير سلسلة الاتصال كوسيط لبرنامج iodbctest، فيجب اقتباس السلسلة لأن معظم الأوامر تستخدم الفاصلة المنقوطة كمحدد للأوامر. إذا تم إدخال سلسلة الاتصال في موجه تفاعلي، فلا يجب استخدام علامات الاقتباس.

بعد إنشاء اتصال ناجح، يُطالب المستخدم بإدخال أمر SQL ليتم إرساله إلى قاعدة البيانات. لا يمكن أن يمتد أمر SQL عبر أسطر متعددة.

إذا أعاد أمر SQL مجموعة نتائج واحدة أو أكثر، يتم جلب كل مجموعة نتائج باستخدام مخازن مؤقتة للأحرف وعرضها في جدول.

بالإضافة إلى ذلك، يفهم برنامج iodbctest بعض الأوامر الخاصة:

qualifiers

عرض قائمة بالمؤهلات باستخدام استدعاء كتالوج SQLTables.
owners

عرض قائمة بالمالكين باستخدام استدعاء كتالوج SQLTables.
tables

عرض قائمة بالجداول باستخدام استدعاء كتالوج SQLTables.
types

عرض قائمة بأنواع الجداول باستخدام استدعاء كتالوج SQLTables.
datatypes

عرض قائمة بأنواع البيانات باستخدام استدعاء كتالوج SQLGetTypeInfo.
reconnect

إجراء قطع اتصال/إعادة اتصال بالمعلومات المحفوظة أثناء أول SQLDriverConnect.
quit (أو exit)

الخروج من البرنامج والعودة إلى الواجهة.

أمثلة

بدء تشغيل برنامج iodbctest والحصول على قائمة بـ DSNs قبل إجراء اتصال:

    $ iodbctest
    OpenLink ODBC Demonstration program
    This program shows an interactive SQL processor
    Enter ODBC connect string (? shows list): ?
    DSN                              | Driver
    -----------------------------------------------------------------
    ora9                             | OpenLink Generic ODBC Driver
    mysql                            | OpenLink Generic ODBC Driver
    mysqllite                        | OpenLink Lite for MySQL
    myodbc                           | MyODBC Driver
    pgsql                            | OpenLink Generic ODBC Driver
    tds                              | OpenLink Generic ODBC Driver
    Enter ODBC connect string (? shows list): DSN=ora9;PWD=tiger
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>

الاتصال ببيئة Oracle 9 تم إعدادها مسبقًا في ملف odbc.ini:

    $ iodbctest "DSN=ora9;UID=scott;PWD=tiger"
    iODBC Demonstration program
    This program shows an interactive SQL processor
    Driver: 05.20.0316 OpenLink Generic ODBC Driver (oplodbc.so)
    SQL>select * from emp
    ID               |NAME
    -----------------+-------------------------------------------
    1                |Record 1
    2                |Record 2
    2                |Record 3
     result set 1 returned 3 rows.
    SQL> quit
