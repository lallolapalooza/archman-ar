الاسم

io_uring_register_files - تسجيل واصفات الملفات

الملخص

#include <liburing.h>
int io_uring_register_files(struct io_uring *ring,
                            const int *files,
                            unsigned nr_files);
int io_uring_register_files_tags(struct io_uring *ring,
                                 const int *files,
                                 const __u64 *tags,
                                 unsigned nr);
int io_uring_register_files_sparse(struct io_uring *ring,
                                   unsigned nr_files);
int io_uring_register_files_update(struct io_uring *ring,
                                   unsigned off,
                                   const int *files,
                                   unsigned nr_files);
int io_uring_register_files_update_tag(struct io_uring *ring,
                                   unsigned off,
                                   const int *files,
                                   const __u64 *tags,
                                   unsigned nr_files);

الوصف

تقوم الدالة io_uring_register_files(3) بتسجيل nr_files عدد من واصفات الملفات المحددة بالمصفوفة files التابعة لـ ring للعمليات اللاحقة.

الدالة io_uring_register_files_tags(3) تعمل بنفس طريقة الدالة io_uring_register_files(3) ولكنها تأخذ معاملًا إضافيًا وهو tags. انظر IORING_REGISTER_BUFFERS2 لوصف وسم الموارد.

تقوم الدالة io_uring_register_files_sparse(3) بتسجيل جدول ملفات فارغ لعدد nr_files من واصفات الملفات. يجب تحديث هذه الملفات قبل استخدامها، باستخدام مثلًا io_uring_register_files_update_tag(3). لاحظ أنه إذا تجاوز حجم الجدول المتناثر ما يسمح به RLIMIT_NOFILE، فإن io_uring_register_files_sparse(3) ستحاول رفع الحد باستخدام **setrlimit (2)** وإعادة محاولة العملية. إذا فشل التسجيل بعد ذلك، فسيتم إرجاع خطأ. المتغير المتناثر متاح في النواة 5.19 وما بعدها.

تسجيل جدول ملفات هو شرط مسبق لاستخدام أي طلب يستخدم واصفات مباشرة.

الملفات المسجلة لها حمل أقل لكل عملية من الملفات العادية. ويرجع ذلك إلى أن النواة تحصل على عداد مرجعي للملف عند بدء عملية، وتخفضه عند الانتهاء. عندما تتم مشاركة جدول ملفات العملية، على سبيل المثال إذا كانت العملية قد أنشأت أي خيوط، فإن هذه التكلفة تزداد أكثر. استخدام الملفات المسجلة يقلل من حمل إدارة المراجع للملفات عبر الطلبات التي تعمل على ملف.

تقوم الدالة io_uring_register_files_update(3) بتحديث الملفات المسجلة الموجودة. off هو الإزاحة التي سيتم بدء التحديث عليها لعدد nr_files من الملفات المحددة بالمصفوفة files التابعة لـ ring.

الدالة io_uring_register_files_update_tag(3) تعمل بنفس طريقة الدالة io_uring_register_files_update(3) ولكنها تأخذ معاملًا إضافيًا وهو tags. انظر IORING_REGISTER_BUFFERS2 لوصف وسم الموارد.

قيمة الإرجاع

عند النجاح، ترجع io_uring_register_files(3)، io_uring_register_files_tags(3) و io_uring_register_files_sparse(3) القيمة 0. io_uring_register_files_update(3) و io_uring_register_files_update_tag(3) ترجع عدد الملفات التي تم تحديثها. عند الفشل، ترجع -errno.
