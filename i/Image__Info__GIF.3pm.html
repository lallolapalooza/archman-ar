Image__Info__GIF(3pm)

الحزمة: perl-image-info

التراخيص: PerlArtistic, GPL

Image::Info::GIF(3) وثائق Perl مساهمة من المستخدم Image::Info::GIF(3)

الاسم

Image::Info::GIF - دعم تنسيق GIF لـ Image::Info

الملخص

use Image::Info qw(image_info dim);
my $info = image_info("image.gif");
if (my $error = $info->{error}) {
    die "لا يمكن تحليل معلومات الصورة: $error\n";
}
my $color = $info->{color_type};
my($w, $h) = dim($info);

الوصف

توفر هذه الوحدة أسماء المفاتيح القياسية بالإضافة إلى

GIF_Loop
يتم تمثيل امتداد Netscape-2.0 لتسلسل الرسوم المتحركة المتكررة بواسطة المفتاح GIF_Loop للصورة الأولى. القيمة هي إما "forever" أو رقم يشير إلى عدد التكرارات.

رأس1 الدوال

process_file()

$info->process_file($source, $options);

يعالج ملفًا واحدًا ويضبط حقول المعلومات الموجودة في الكائن $info.
