IO::Poll(3perl) دليل مبرمجين بيرل IO::Poll(3perl)

الاسم

IO::Poll - واجهة كائنية لاستدعاء poll النظام

الملخص

use IO::Poll qw(POLLRDNORM POLLWRNORM POLLIN POLLHUP);
$poll = IO::Poll->new();
$poll->mask($input_handle => POLLIN);
$poll->mask($output_handle => POLLOUT);
$poll->poll($timeout);
$ev = $poll->events($input);

الوصف

"IO::Poll" هي واجهة بسيطة لروتين poll على مستوى النظام.

الطرق

mask ( IO [, EVENT_MASK ] )
إذا تم توفير EVENT_MASK، فإذا كان EVENT_MASK غير صفري، فسيتم إضافة IO إلى قائمة واصفات الملفات وسيتحقق استدعاء poll التالي من أي حدث محدد في EVENT_MASK. إذا كان EVENT_MASK صفريًا، فسيتم إزالة IO من قائمة واصفات الملفات.

إذا لم يتم توفير EVENT_MASK، فستكون القيمة المرجعة هي قيمة قناع الحدث الحالي لـ IO.

poll ( [ TIMEOUT ] )
استدعاء روتين poll على مستوى النظام. إذا لم يتم تحديد TIMEOUT، فسيتوقف الاستدعاء. يعيد عدد المقابض التي حدثت فيها أحداث، أو -1 عند حدوث خطأ.
events ( IO )
يعيد قناع الحدث الذي يمثل الأحداث التي وقعت على IO أثناء الاستدعاء الأخير لـ "poll".
remove ( IO )
إزالة IO من قائمة واصفات الملفات لاستدعاء poll التالي.
handles( [ EVENT_MASK ] )
يعيد قائمة بالمقابض. إذا لم يتم توفير EVENT_MASK، فسيتم إرجاع قائمة بجميع المقابض المعروفة. إذا تم توفير EVENT_MASK، فسيتم إرجاع قائمة بالمقابض التي حدثت فيها إحدى الأحداث المحددة بواسطة EVENT_MASK أثناء الاستدعاء الأخير لـ "poll".
