iscsi_context_new(3)

الحزمة: open-iscsi

التراخيص: GPL

iscsi_context_new(3) دليل API iscsi_context_new(3)

الاسم

iscsi_context_new - إنشاء struct iscsi_context.

الملخص

struct iscsi_context * iscsi_context_new (void);

الوسائط

void
لا توجد وسائط

الوصف

مستوى التسجيل الافتراضي (LIBISCSI_LOG_PRIORITY_DEFAULT) هو LIBISCSI_LOG_PRIORITY_WARNING مما يعني أن رسائل التحذير والخطأ فقط سيتم إعادة توجيهها إلى دالة معالج التسجيل. ستقوم دالة معالج التسجيل الافتراضية بطباعة رسالة التسجيل إلى STDERR، لتغيير ذلك، يرجى استخدام iscsi_context_log_func_set لتعيين دالة معالج تسجيل خاصة بك، تحقق من صفحة الدليل libopeniscsiusr.h(3) للتفاصيل.

الإرجاع

مؤشر إلى 'struct iscsi_context'. يجب تحريره بواسطة iscsi_context_free.
