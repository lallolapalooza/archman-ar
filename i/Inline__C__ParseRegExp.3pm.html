Inline__C__ParseRegExp(3pm)

الحزمة: perl-inline-c

Inline::C::ParseRegExp(3) وثائق Perl المساهمة من المستخدم Inline::C::ParseRegExp(3)

الاسم

Inline::C::ParseRegExp - محلل Inline::C الجديد والمحسن

الملخص

use Inline C => DATA =>
           USING => ParseRegExp;

الوصف

هذه الوحدة هي نسخة أسرع بكثير من محلل Parse::RecDescent الخاص بـ Inline::C. إنها تستند إلى التعبيرات العادية بدلاً من ذلك.
