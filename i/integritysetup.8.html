integritysetup(8)

- type: markdown content: | تُستخدم لتغيير وظيفة تدقيق سلامة التشفير. ملاحظة، إنها لا تغير طول العلامة. هذا الخيار متاح منذ إصدار نواة لينكس 5.13. - type: paragraph content: | --integrity-recovery-mode, -R - type: indented content: | وضع الاسترداد (لا يوجد سجل، لا يوجد فحص للعلامة). - type: paragraph content: | --interleave-sectors sectors - type: indented content: | عدد القطاعات المتداخلة. - type: paragraph content: | --journal-commit-time ms - type: indented content: | وقت الالتزام بالمللي ثانية. يتم كتابة السجل عند مرور هذا الوقت (ولم يتم إصدار عملية مسح صريحة). - type: paragraph content: | --journal-crypt algorithm - type: indented content: | خوارزمية التشفير لمنطقة بيانات السجل. يمكنك استخدام تشفير كتلة هنا، مثل cbc-aes أو تشفير تدفق، على سبيل المثال، chacha20 أو ctr-aes. - type: paragraph content: | خيارات تشفير السجل مخصصة للاختبار فقط. استخدام تشفير السجل لا معنى له بدون تشفير البيانات. - type: paragraph content: | --journal-crypt-key-file file - type: indented content: | الملف الذي يحتوي على مفتاح تشفير السجل. - type: paragraph content: | --journal-crypt-key-size bytes - type: indented content: | حجم مفتاح تشفير السجل. الحد الأقصى هو 4096 بايت. - type: paragraph content: | --journal-integrity algorithm - type: indented content: | خوارزمية سلامة لمنطقة السجل. انظر خيار --integrity للمواصفات التفصيلية. - type: paragraph content: | --journal-integrity-key-file file - type: indented content: | الملف الذي يحتوي على مفتاح السلامة. - type: paragraph content: | --journal-integrity-key-size bytes - type: indented content: | حجم مفتاح سلامة السجل. الحد الأقصى هو 4096 بايت. - type: paragraph content: | --journal-size, -j butes - type: indented content: | حجم السجل. - type: paragraph content: | --journal-watermark percent - type: indented content: | علامة مائية للسجل بالنسبة المئوية. عندما يتجاوز حجم السجل هذه العلامة المائية، سيتم بدء مسح السجل. - type: paragraph content: | --no-wipe - type: indented content: | لا تقم بمسح الجهاز بعد التهيئة. الجهاز الذي لم يتم مسحه في البداية سيحتوي على تدقيقات سلامة غير صالحة. - type: paragraph content: | --progress-frequency seconds - type: indented content: | اطبع سطراً منفصلاً كل <seconds> مع تقدم المسح. - type: paragraph content: | --progress-json - type: indented content: | يطبع بيانات تقدم المسح بتنسيق JSON، وهو مناسب لمعالجة الآلات في الغالب. يقوم بطباعة سطر منفصل كل نصف ثانية (أو بناءً على قيمة --progress-frequency). يبدو إخراج JSON كما يلي أثناء تقدم المسح (باستثناء أنه سطر واحد مضغوط): - type: indented content: | ```json { "device":"/dev/sda", // backing device or file "device_bytes":"8192", // bytes wiped so far "device_size":"44040192", // total bytes to wipe "speed":"126877696", // calculated speed in bytes per second (based on progress so far) "eta_ms":"2520012", // estimated time to finish wipe in milliseconds "time_ms":"5561235" // total time spent wiping device in milliseconds } ``` - type: paragraph content: | ملاحظة على الأرقام في إخراج JSON: نظرًا لقيود محللات JSON، يتم تمثيل جميع الأرقام في صيغة سلسلة بسبب الحاجة إلى أعداد صحيحة غير موقعة كاملة 64 بت. - type: paragraph content: | --sector-size, -s bytes - type: paragraph content: | يمكن أن يكون الحجم أصغر من حجم إخراج وظيفة التجزئة؛ في هذه الحالة، سيتم تخزين جزء فقط من التجزئة. - type: paragraph content: | --usage - type: indented content: | إظهار مساعدة الخيارات المختصرة. -
