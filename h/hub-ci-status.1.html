hub-ci-status(1)

الحزمة: hub

التراخيص: MIT

hub-ci-status(1) دليل hub hub-ci-status(1)

الاسم

hub-ci-status - عرض حالة فحوصات GitHub لالتزام.

الملخص

hub ci-status [-v] [COMMIT]

الخيارات

-v, --verbose

طباعة تقرير مفصل لجميع فحوصات الحالة وروابطها.

-f, --format FORMAT

طباعة فحوصات الحالة بشكل جميل باستخدام FORMAT (يعني --verbose). انظر قسم "التنسيقات الجميلة" في git-log(1) لبعض التفاصيل الإضافية حول كيفية استخدام العناصر النائبة في التنسيق. العناصر النائبة المتاحة للفحوصات هي:

%U: رابط فحص الحالة هذا

%S: حالة الفحص (مثل "success"، "failure")

%sC: تعيين اللون إلى الأحمر أو الأخضر أو الأصفر، اعتمادًا على الحالة

%t: اسم فحص الحالة

--color[=WHEN]

تمكين الإخراج الملون حتى لو لم يكن المخرج القياسي طرفية. يمكن أن تكون WHEN واحدة من "always" (الافتراضي لـ --color)، "never"، أو "auto" (الافتراضي).

COMMIT

معرف التزام SHA أو اسم فرع (الافتراضي: "HEAD").

المخرجات وحالات الخروج المحتملة:

  • success, neutral: 0
  • failure, error, action_required, cancelled, timed_out: 1
  • pending: 2
