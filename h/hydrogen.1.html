HYDROGEN(29) أوامر المستخدم HYDROGEN(29)

الاسم

hydrogen - آلة طبول بسيطة / متسلسل خطوات.

الخلاصة

hydrogen [-v] [-h] -s file

الوصف

Hydrogen 1.2.6 [http://www.hydrogen-music.org]. حقوق النشر 2002-2008 Alessandro Cominu، حقوق النشر 2008-2025 فريق تطوير hydrogen.

Hydrogen هي آلة طبول متقدمة لنظام GNU/Linux. هدفها الرئيسي هو تقديم برمجة طبول احترافية تعتمد على الأنماط، سهلة وبديهية.

يأتي Hydrogen بدون أي ضمان على الإطلاق. هذا برنامج مجاني، وترحب بكم في إعادة توزيعه بشروط معينة. انظر ملف COPYING للتفاصيل.

خيارات

-P, --data PATH - استخدم مسار بيانات نظام بديل

-d, --driver AUDIODRIVER - استخدم مشغل الصوت المحدد (jack, alsa, oss)

-s, --song FILE - تحميل أغنية (*.h2song) عند البدء

-p, --playlist FILE - تحميل قائمة تشغيل (*.h2playlist) عند البدء

-k, --kit drumkit_name - تحميل مجموعة طبول عند البدء

-i, --install FILE - تثبيت مجموعة طبول (*.h2drumkit)

-O, --osc-port - استخدام منفذ OSC مخصص

-n, --nosplash - إخفاء شاشة البداية

-V[Level], --verbose[=Level] - طباعة الكثير من معلومات التصحيح

المستوى، إذا كان موجودًا، قد يكون None، Error، Warning، Info، Debug أو 0xHHHH

-L, --log-file - استخدام ملف سجل مخصص

-T, --log-timestamps - إضافة طوابع زمنية لجميع رسائل السجل

-v, --version - عرض معلومات الإصدار

-h, --help - عرض رسالة المساعدة هذه

الملفات

hydrogen.conf

الإعدادات الافتراضية والإعدادات عند بدء التشغيل لـ Hydrogen.

data/*

يمكن أن تحتوي على بيانات المستخدم مثل مجموعات الطبول، الأنماط، قوائم التشغيل، الأغاني، ...

البيئة

LADSPA_PATH

مسار إلى إضافات LADSPA.
