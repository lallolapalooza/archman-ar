الاسم

hatari - محاكي Atari ST/STE/TT/Falcon

الملخص

hatari [خيارات] [دليل|صورة قرص|برنامج]

الوصف

Hatari هو محاكي Atari ST/STE/TT/Falcon لنظام Linux والأنظمة الأخرى المدعومة بواسطة مكتبة SDL (الرسومات، الإدخال، والصوت متعددة المنصات).

باستخدام Hatari، يمكنك تشغيل الألعاب، العروض، أو التطبيقات المكتوبة لـ Atari ST، STE، أو Falcon. دعم Atari TT تجريبي. يدعم Hatari صور الأقراص شائعة الاستخدام *.st، *.msa، و *.stx، بالإضافة إلى محاكاة الأقراص الصلبة.

لتشغيل المحاكي، يلزم وجود صورة ROM لنظام TOS. EmuTOS، وهو تطبيق مجاني لنظام TOS، يأتي مع Hatari. يقوم بالتمهيد بشكل أسرع من إصدارات TOS الأصلية ولا يحتاج إلى برامج تشغيل أقراص صلبة منفصلة، ولكن بعض البرامج المعيبة (عادةً أقراص مرنة فقط) لن تعمل بشكل صحيح معه. للحصول على أفضل توافق، يوصى باستخدام ROM لنظام TOS من جهاز Atari حقيقي.

كوسيط، يمكنك تقديم اسم دليل يجب محاكاته كقرص صلب افتراضي GEMDOS، أو صورة قرص مرن، أو برنامج Atari يجب تشغيله تلقائيًا. في الحالة الأخيرة، سيتم استخدام دليل البرنامج كمحرك C: الذي سيتم بدء هذا البرنامج منه. هذه الاختصارات تقابل الخيارات "-d <dir>"، "--disk-a <floppy image>"، و "-d <dir> --auto C:\<program>".

سيتم التمهيد من صورة القرص أو الدليل المقدم آخر مرة في سطر الأوامر، إما كخيار أو كوسيط (والذي يتوافق مع A: أو C:).

الخيارات

تنقسم خيارات Hatari إلى عدة فئات:

خيارات عامة

-h, --help
طباعة خيارات سطر الأوامر وإنهاء
-v, --version
طباعة معلومات الإصدار وإنهاء
--confirm-quit <bool>
ما إذا كان Hatari يؤكد الخروج
-c, --configfile <filename>
قراءة قيم تكوين إضافية من <الملف>، هذه تتجاوز القيم المقروءة من ملفات التكوين العامة وملفات التكوين الخاصة بالمستخدم
-k, --keymap <file>
تحميل تخطيط لوحة المفاتيح من <الملف>. سيتم استخدام تخطيط "رمزي" كبديل للمفاتيح غير المعرفة هناك
--country <x>
تعيين رمز بلد EmuTOS ROM على أجهزة Mega/ST/STe التي تفتقر إلى NVRAM، عندما يشير EmuTOS إلى دعمه لعدة رموز.

في صور EmuTOS بحجم 512 كيلوبايت، يحدد رمز البلد تخطيط لوحة مفاتيح TOS وتحديث الشاشة (US = 60Hz NTSC، 50Hz PAL بخلاف ذلك). في صور EmuTOS بحجم 1024 كيلوبايت (التي تأتي مع ملفات Hatari الثنائية وتدعم لغات متعددة)، يحدد رمز البلد أيضًا لغة TOS.

بدلاً من ذلك، يمكنك استخدام أداة "tos-lang-change" من مشروع EmuTOS لتعديل رمز البلد في ملف صورة ROM نفسه. هذا يعمل أيضًا مع TOS v4

--layout <x>
تعيين قيمة تخطيط لوحة المفاتيح NVRAM. بينما تمتلك أجهزة TT و Falcon ذاكرة NVRAM، فإن إصدارات ROM TOS v4 و EmuTOS 512 كيلوبايت / 1024 كيلوبايت فقط تدعم تخطيطات متعددة.

بغض النظر عما إذا كان تغيير تخطيط لوحة المفاتيح يتم عبر رمز بلد ROM أو إعداد NVRAM، فقد يؤثر ذلك على تعيينات المفاتيح الخاصة بك في ملفات تعيين مفاتيح Hatari، أو وسائط واجهة المستخدم الرسومية Python لـ Hatari، أو حقن المفاتيح في نصوص الأتمتة الخاصة بك لمصحح Hatari، أو FIFO الأوامر، أو أداة hconsole

--language <x>
تعيين قيمة لغة NVRAM. بينما تمتلك أجهزة TT و Falcon ذاكرة NVRAM، فإن إصدارات ROM TOS v4 و EmuTOS 1024 كيلوبايت فقط تدعم لغات متعددة. الافتراضي مأخوذ من متغير البيئة LANG
--fast-forward <bool>
تجاوز الأجزاء المملة عن طريق تشغيل المحاكي بأقصى سرعة. يتم ذلك عن طريق تخطي تحديث الإطارات وتأخيرات VBL. الحد الأعلى لتخطي الإطارات يتم تحديده باستخدام خيار --frameskips ويظهر في حقل "FS" في شريط الحالة
--auto <program>
يقوم بتشغيل البرنامج المحدد تلقائيًا، إذا وجده نظام TOS. يجب تقديم البرنامج مع المسار الكامل الذي سيحصل عليه تحت المحاكاة، على سبيل المثال "C:\DIR\PROGRAM.PRG". يتم تحقيق ذلك عن طريق توفير ملف INF افتراضي لنظام TOS لمحرك الأقراص للتمهيد (A: أو C:)، والذي يخبر نظام TOS ببدء تشغيل البرنامج المحدد --fast-forward-key-repeat <bool> استخدام تكرار المفاتيح التلقائي عند استخدام وضع التمرير السريع (الافتراضي صحيح)

خيارات العرض الشائعة

-m, --mono
ابدأ في وضع أحادي اللون بدلاً من اللون
--monitor <x>
تحديد نوع الشاشة (x = أحادي/rgb/vga/tv)
--tos-res <x>
تحديد دقة TOS للشاشات الملونة (x = منخفض/متوسط/عالي/ttlow/ttmed)
-f, --fullscreen
بدء المحاكي في وضع ملء الشاشة
-w, --window
بدء المحاكي في وضع النافذة
--grab
التقاط الماوس (أيضًا) في وضع النافذة
--resizable <bool>
السماح بتغيير حجم النافذة
--borders <bool>
عرض حدود شاشة ST/STE/Falcon (للعروض ذات الدقة المنخفضة/المتوسطة التي تتجاوز المسح)
--frameskips <x>
تخطي <x> إطار بعد كل إطار معروض لتسريع المحاكاة (0=معطل، >4 يستخدم تخطي الإطارات تلقائيًا مع القيمة المعطاة كحد أقصى)
--slowdown <x>
إبطاء المحاكاة بمعامل x (يستخدم كمضاعف لوقت انتظار VBL)
--mousewarp <bool>
للحفاظ على مزامنة ماوس المضيف بشكل أفضل مع مؤشر ماوس Atari، قم بتوسييطه في نافذة Hatari عند إعادة الضبط البارد وتغييرات الدقة
--statusbar <bool>
عرض شريط الحالة (مع مصابيح LED للأقراص المرنة وما إلى ذلك)
--drive-led <bool>
عرض مصباح LED مدمج للقرص عندما لا يكون شريط الحالة معروضًا
--max-width <x>
العرض المفضل / الأقصى لنافذة Hatari
--max-height <x>
الارتفاع المفضل / الأقصى لنافذة Hatari.

خيارات العرض والارتفاع القصوى هي جزء من محاكاة شاشة Atari في Hatari. إنها تحدد الحجم الذي يجب أن يستهدفه Hatari للإطار الداخلي لمكتبة SDL، ومقدار حدود شاشة Atari المرئية.

يتم بعد ذلك قياس الإطار إلى نافذة إخراج Hatari بناءً على عامل التكبير المحدد لـ Hatari (انظر أدناه).

الهدف من ذلك هو عرض جميع الدقات بنفس الحجم تقريبًا، كما هو الحال على شاشة Atari حقيقية. يدعم Hatari القياس الصحيح للأعداد الصحيحة داخلية بعض القيود على ذلك، لذا فهو خيار للمستخدمين الخبراء.

ملاحظة: السبب الوحيد لتغيير الإعدادات الافتراضية يجب أن يكون تحديد هذا إلى دقة أقل لأسباب الأداء، على سبيل المثال، للتسجيل المرئي، أو على الأنظمة الأقل قوة حقًا، لجعل الشاشة تقوم بكل قياسات دقة ST-low عن طريق إجبار Hatari على طلب دقة CGA / QVGA من SDL.

-z, --zoom <x>
هذا الخيار يتجاوز خيارات العرض والارتفاع القصوى بحيث يتم مضاعفة دقة ST-low على سبيل المثال، ويتمتع كل الدقات (باستثناء TT-high) بنفس الحجم تقريبًا، كما هو الحال على شاشة CRT حقيقية.

يتم استخدام عامل التكبير بعد ذلك لتوسيعه (أو تقليصه) إلى نافذة إخراج Hatari. بهذه الطريقة، ينتج عن القياس دائمًا نافذة Hatari بنفس الحجم تقريبًا.

hatari(1) - Hatari emulator

DESCRIPTION

The Hatari project aims to create a high quality, portable and well-featured Atari 16/32-bit computer emulator. It is written in C, and uses the SDL library for graphics, input and sound.

This manual page describes the options for the Hatari emulator.

OPTIONS

General options

-h, --help
Display a short help message listing all command line options.
-v, --version
Display version information and exit.
-l, --license
Display license information and exit.
-f, --conf file
Use specified configuration file instead of the default (‘~/.config/hatari/hatari.cfg’).
-s, --save-state file
Save the emulator state to the given file and exit.
-L, --load-state file
Load the emulator state from the given file and continue emulation.
-p, --print-config
Print the current configuration (including defaults and command line overrides) to stdout and exit.

Common display options

-A, --fullscreen
Run Hatari in fullscreen mode.
-W, --window
Run Hatari in windowed mode.
-f, --fast-forward [factor]
Enable fast-forward mode. Without a parameter, fast-forward runs as fast as possible. With a parameter, fast-forward runs at `factor`*current_speed.
-S, --slow-down [factor]
Enable slow-down mode. Runs emulation at 1/`factor` of the normal speed.
-o, --overscan [amount]
Enable overscan mode. Hatari will draw `amount` extra pixels around the screen.
-Z, --zoom [zoom]
Set the zoom factor for the windowed mode. Can be a float value like 1.5 or an integer like 2.
-t, --title title
Set the window title.
-g, --grab-focus
Grab the mouse pointer when in fullscreen mode.
-G, --ungrab-focus
Do not grab the mouse pointer when in fullscreen mode.
-a, --alt-grab
Grab the mouse pointer also when the pointer is outside the window.
-A, --alt-ungrab
Do not grab the mouse pointer when the pointer is outside the window.

ST/STE specific display options

-m, -- Monochrome
Select the Monochrome screen mode.
-g, --GrayScale
Select the GrayScale screen mode.
-c, --Color
Select the Color screen mode.
-H, --HBLANK
Enable HBLANK interrupts.
-V, --VBLANK
Enable VBLANK interrupts.

TT/Falcon specific display options

-C, --Color24bit
Select the 24 bit screen mode.
-K, --Kbmodes
Enable KB modes.

VDI options

-R, --run-vdi [mode]
Run VDI driver in the specified mode.

Screen capture options

-S, --snapshot-dir dir
Directory to save snapshots.
-P, --printer-dir dir
Directory to save printer output.

Devices options

-j, --joystick device
Use specified device as joystick.
-J, --joy2 device
Use specified device as second joystick.
-m, --mouse device
Use specified device as mouse.

Floppy drive options

-d, --drive drive,file
Use image file as the specified drive.

Hard drive options

-H, --hard-drive drive,file
Use image file as the specified hard drive.
-D, --directory drive,dir
Use directory as the specified hard drive.

Memory options

-M, --memory size
Set the amount of RAM in Megabytes.

ROM options

-r, --romfile file
Use the specified file as the TOS ROM image.

CPU/FPU/bus options

-c, --cpu type
Select the CPU type.
-F, --fpu type
Select the FPU type.
-B, --bus type
Select the bus type.

Misc system options

-s, --system type
Select the system type.
-a, --acsi-controller type
Select the ACSI controller type.
-c, --cdrom-controller type
Select the CD-ROM controller type.
-i, --ide-controller type
Select the IDE controller type.
-p, --parallel-port type
Select the parallel port type.
-s, --serial-port type
Select the serial port type.

Sound options

-A, --audio-device device
Use the specified audio device.
-S, --sample-rate rate
Set the sample rate for the audio device.

Debug options

-d, --debug flag
Set the debug flags.

INPUT HANDLING

Emulated Atari ST joystick

The emulated Atari ST joystick can be controlled either by a real joystick plugged into your computer, or by the keyboard. By default, the keyboard is configured to use the cursor keys for the joystick directions, and the Control+Alt keys as the fire button.

Emulated Atari ST mouse

The emulated Atari ST mouse can be controlled either by a real mouse connected to your computer, or by the keyboard. By default, the keyboard is configured to use the I, J, K, L keys for mouse movement, and the U and O keys for the left and right mouse buttons, respectively.

You can switch between mouse and keyboard control by pressing Right-Alt. The mouse emulation automatically switches to keyboard control when the mouse pointer leaves the emulator window.

Emulated Atari ST keyboard

Most keys on your computer's keyboard are mapped directly to the emulated Atari ST keyboard. Some special keys, like the Alt, Control, and Shift keys, have different meanings in the emulated system. For example, the left Control key acts as the emulated Atari ST's alternate function key (used for things like selecting text in programs).

The F1-F12 keys are mapped to the emulated Atari ST's function keys. The Escape key acts as the emulated Atari ST's Help key.

Keyboard shortcuts during emulation

The following keyboard shortcuts are available during emulation:

F1
Display the Hatari menu.
F12
Toggle pause/resume emulation.
Control+Alt+Delete
Reset the emulated computer.
Control+Alt+F1
Take a screenshot.
Control+Alt+F2
Start/stop recording sound output.
Control+Alt+F3
Start/stop recording screen output.
Control+Alt+F4
Toggle fast forward mode.
Control+Alt+F5
Toggle slow down mode.
Control+Alt+F12
Toggle joystick/mouse emulation.
Control+Alt+Shift+P
Toggle printer output.
Control+Alt+Shift+S
Save Hatari state.
Control+Alt+Shift+L
Load Hatari state.

Keyboard shortcuts for the SDL GUI

The following keyboard shortcuts are available when using the SDL GUI:

Up/Down arrow keys
Move the file list by one page, mouse wheel and Alt + cursor keys scroll it by one item. Enter on the focused file name selects it. Enter on the OK button accepts the selected file. ESC cancels the dialog/selection.
Alert dialogs
Enter accepts and ESC cancels the dialog.

FILES AND DIRECTORIES

/etc/hatari.cfg (or /usr/local/etc/hatari.cfg)
The global configuration file of Hatari.
~/.config/hatari/
The (default) directory for user's personal Hatari files; hatari.cfg (configuration file), hatari.nvram (NVRAM content file), hatari.sav (Hatari memory state snapshot file which Hatari can load/save automatically when it starts/exits), hatari.prn (printer output file),
/usr/share/hatari/ (or /usr/local/share/hatari/)
The global data directory of Hatari.
tos.img
The TOS ROM image will be loaded from the data directory of Hatari unless it is specified on the command line or the configuration file.
