Detailed Description

This section describes the functions that manage memory attributes. Memory attributes provide a way to query and control properties of memory resources, such as locality, interleaving, and NUMA policies.

The library provides a set of built-in memory attribute types, and allows for the registration of custom types.

The functions allow for getting and setting attribute values on specific objects (e.g., nodes, cores, devices) in the topology.

Special memory page types can also be managed, allowing for fine-grained control over memory page properties.

Enumeration Type Documentation

hwloc_memattr_type_t
An enumeration type representing different memory attribute types. Built-in types include HWLOC_MEMATTR_TYPE_MEMBIND, HWLOC_MEMATTR_TYPE_NUMA, and HWLOC_MEMATTR_TYPE_CLOSE. HWLOC_MEMATTR_TYPE_NONE represents no specific attribute.
hwloc_memattr_value_t
An unsigned integer type used to represent the value of a memory attribute.

Function Documentation

  • hwloc_memattrs_get_value: Retrieves the value of a specific memory attribute type for a given object.
  • hwloc_memattrs_set_value: Sets the value of a specific memory attribute type for a given object. Flags can be used to specify attributes like interleaving or locality.
  • hwloc_memattrs_get_type_support: Checks if a specific memory attribute type is supported by the system.
  • hwloc_memattrs_get_type_support_in_range: Retrieves the range of supported values for a given memory attribute type.
  • hwloc_memattrs_get_type_by_name: Retrieves the internal type identifier for a memory attribute given its name.
  • hwloc_memattrs_get_name_by_type: Retrieves the name of a memory attribute given its internal type identifier.
  • hwloc_memattrs_register_type: Registers a new custom memory attribute type.
  • hwloc_memattrs_get_first_type: Retrieves the first supported memory attribute type in the topology.
  • hwloc_memattrs_get_next_type: Retrieves the next supported memory attribute type in the topology.
  • hwloc_memattrs_add_special_memory_page_type: Adds a special memory page type to an object.
  • hwloc_memattrs_get_special_memory_page_type: Retrieves the properties of a special memory page type for a given object.
  • hwloc_memattrs_get_special_memory_page_type_count: Returns the number of special memory page types associated with an object.
  • hwloc_memattrs_get_special_memory_page_type_by_id: Retrieves information about a special memory page type using its ID.
  • hwloc_memattrs_remove_special_memory_page_type: Removes a special memory page type from an object.
  • hwloc_memattrs_set_page_type_attribute: Sets an attribute for a specific page type on an object.
  • hwloc_memattrs_get_page_type_attribute: Retrieves an attribute for a specific page type on an object.
