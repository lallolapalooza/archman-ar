NAME

hetd2 - Computes the eigenvalues and eigenvectors of a complex Hermitian tridiagonal matrix.

SYNOPSIS

SUBROUTINE ZHETD2(
    UPLO, N, A, LDA, D, E, TAU, INFO
)
CHARACTER * 1
complex(8) :: A( LDA, * )
complex(8) :: TAU( * )
INTEGER :: N, LDA, INFO
REAL * 8 :: D( * ), E( * )

Detailed Description

hetd2 computes the eigenvalues and eigenvectors of a complex Hermitian tridiagonal matrix.

This is a simpler version of ZHEMMD2. It is expected to be less efficient than the blocked routines.

Arg:
    UPLO    (input) CHARACTER*1
            = 'U':  Upper triangle of A is stored;
            = 'L':  Lower triangle of A is stored.

    N       (input) INTEGER
            The order of the matrix A.  N >= 0.

    A       (input/output) COMPLEX*16 array, dimension (LDA, N)
            On entry, the N-by-N Hermitian tridiagonal matrix A.
            On exit, if UPLO = 'U', the upper triangle of A is overwritten.
            The main diagonal stores the real parts of the eigenvalues, and
            the first subdiagonal stores the imaginary parts (which should be zero).
            The elements of the vectors defining the elementary reflectors
            are stored in the remaining available space.
            If UPLO = 'L', the lower triangle of A is overwritten.
            The main diagonal stores the real parts of the eigenvalues, and
            the first superdiagonal stores the imaginary parts (which should be zero).
            The elements of the vectors defining the elementary reflectors
            are stored in the remaining available space.

    LDA     (input) INTEGER
            The leading dimension of the array A.  LDA >= max(1, N).

    D       (output) DOUBLE PRECISION array, dimension (N)
            The eigenvalues of the matrix A.

    E       (output) DOUBLE PRECISION array, dimension (N-1)
            The imaginary parts of the complex eigenvalues, or the
            off-diagonal elements of the tridiagonal matrix T.
            Specifically, E(i) contains the imaginary part of the i-th
            eigenvalue, or the off-diagonal element A(i, i+1) (if UPLO='U')
            or A(i+1, i) (if UPLO='L') of the original matrix.

    TAU     (output) COMPLEX*16 array, dimension (N-1)
            The scalar factors of the elementary reflectors.

    INFO    (output) INTEGER
            = 0:  successful exit
            < 0:  if INFO = -i, the i-th argument had an illegal value.

Further Details:

  If UPLO = 'U', the matrix Q is represented as a product of elementary
  reflectors

     Q = H(n-1) . . . H(2) H(1).

  Each H(i) has the form

     H(i) = I - tau * v * v**H

  where tau is a complex scalar, and v is a complex vector with
  v(i+1:n) = 0 and v(i) = 1; v(1:i-1) is stored on exit in
  A(1:i-1,i+1), and tau in TAU(i).

  If UPLO = 'L', the matrix Q is represented as a product of elementary
  reflectors

     Q = H(1) H(2) . . . H(n-1).

  Each H(i) has the form

     H(i) = I - tau * v * v**H

  where tau is a complex scalar, and v is a complex vector with
  v(1:i) = 0 and v(i+1) = 1; v(i+2:n) is stored on exit in A(i+2:n,i),
  and tau in TAU(i).

  The contents of A on exit are illustrated by the following examples
  with n = 5:

  if UPLO = 'U':                       if UPLO = 'L':

    (  d   e   v2  v3  v4 )              (  d                  )
    (      d   e   v3  v4 )              (  e   d              )
    (          d   e   v4 )              (  v1  e   d          )
    (              d   e  )              (  v1  v2  e   d      )
    (                  d  )              (  v1  v2  v3  e   d  )

  where d and e denote diagonal and off-diagonal elements of T, and vi
  denotes an element of the vector defining H(i).
