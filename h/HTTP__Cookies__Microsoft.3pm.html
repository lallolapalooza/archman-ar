HTTP__Cookies__Microsoft(3pm)

الحزمة: perl-http-cookies

التراخيص: PerlArtistic, GPL

HTTP::Cookies::Microsoft(3) وثائق بيرل المساهمة من المستخدم HTTP::Cookies::Microsoft(3)

الاسم

HTTP::Cookies::Microsoft - الوصول إلى ملفات تعريف الارتباط الخاصة بمايكروسوفت

الإصدار

الإصدار 6.11

الملخص

use LWP;
use HTTP::Cookies::Microsoft;
use Win32::TieRegistry(Delimiter => "/");
my $cookies_dir = $Registry->
     {"CUser/Software/Microsoft/Windows/CurrentVersion/Explorer/Shell Folders/Cookies"};
$cookie_jar = HTTP::Cookies::Microsoft->new(
                  file     => "$cookies_dir\\index.dat",
                  'delayload' => 1,
              );
my $browser = LWP::UserAgent->new;
$browser->cookie_jar( $cookie_jar );

الوصف

هذه فئة فرعية من "HTTP::Cookies" تقوم بتحميل ملفات تعريف الارتباط الخاصة بـ Microsoft Internet Explorer 5.x و 6.x لنظام Windows (MSIE).

راجع وثائق HTTP::Cookies.

الطرق

الطرق التالية متاحة:

$cookie_jar = HTTP::Cookies::Microsoft->new;
يأخذ المنشئ معاملات من نمط التجزئة. بالإضافة إلى معاملات HTTP::Cookies العادية، يتعرف HTTP::Cookies::Microsoft على ما يلي: 
delayload:       تأخير تحميل بيانات ملفات تعريف الارتباط حتى يتم إجراء طلب فعلي.
                 ينتج عن هذا وقت تشغيل أسرع ما لم تستخدم معظم ملفات تعريف الارتباط
                 حيث يتم تحميل بيانات ملف تعريف الارتباط للنطاق فقط عند الطلب.

تحذيرات

يرجى ملاحظة أن الكود لا يدعم الحفظ بتنسيق ملفات تعريف الارتباط الخاصة بـ MSIE.
