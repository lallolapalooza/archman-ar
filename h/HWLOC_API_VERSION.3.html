HWLOC_API_VERSION(3)

الحزمة: hwloc

التراخيص: BSD-3-Clause

hwlocality_api_version(3) دليل وظائف المكتبة hwlocality_api_version(3)

الاسم

hwlocality_api_version - إصدار الواجهة البرمجية للتطبيق

ملخص

ماكرو


#define HWLOC_API_VERSION 0x00020c00
#define HWLOC_COMPONENT_ABI 7

وظائف


unsigned hwloc_get_api_version (void)

وصف تفصيلي

وثائق تعريف الماكرو

#define HWLOC_API_VERSION 0x00020c00

يشير في وقت البناء إلى إصدار واجهة hwloc API المستخدمة. يتم تحديث هذا الرقم إلى (X<<16)+(Y<<8)+Z عندما يقوم إصدار جديد X.Y.Z بتعديل الواجهة البرمجية بالفعل.

يمكن للمستخدمين التحقق من الميزات المتاحة في وقت البناء باستخدام هذا الرقم (انظر كيف أتعامل مع تغييرات الواجهة البرمجية؟).

ملاحظة

لا ينبغي الخلط بين هذا وبين HWLOC_VERSION، إصدار المكتبة. عادةً ما يكون لإصدارين مستقرين من نفس السلسلة نفس HWLOC_API_VERSION حتى لو كان HWLOC_VERSION الخاص بهما مختلفًا.

#define HWLOC_COMPONENT_ABI 7

إصدار ABI للمكون والإضافات الحالي (انظر hwloc/plugins.h)

وثائق الوظائف

unsigned hwloc_get_api_version (void)

يشير في وقت التشغيل إلى إصدار واجهة hwloc API الذي تم استخدامه في وقت البناء. يجب أن يكون HWLOC_API_VERSION إذا كنت تعمل على نفس الإصدار.

العودة

رقم إصدار وقت البناء.
