الاسم

hwlocality_glibc_sched - التشغيل المتبادل مع جدولة glibc

ملخص

الدوال

int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topology, hwloc_cpuset_t hwlocset, const cpu_set_t *schedset, size_t schedsetsize)

وصف مفصل

يقدم هذا الواجهة طرقًا للتحويل بين مجموعات وحدات المعالجة المركزية (cpusets) الخاصة بـ hwloc ومجموعات وحدات المعالجة المركزية (cpusets) الخاصة بـ glibc مثل تلك التي يتم التعامل معها بواسطة sched_getaffinity() أو pthread_attr_setaffinity_np().

ملاحظة

يجب أن تتطابق طوبولوجيا topology مع الجهاز الحالي.

توثيق الدالة

int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topology, hwloc_cpuset_t hwlocset, const cpu_set_t * schedset, size_t schedsetsize) [inline]

تحويل مجموعة وحدات المعالجة المركزية لجدولة glibc schedset إلى مجموعة وحدات المعالجة المركزية لـ hwloc. يمكن استخدام هذه الدالة قبل استدعاء sched_setaffinity أو أي دالة أخرى تأخذ cpu_set_t كمعامل مدخل.

يجب أن يكون schedsetsize هو sizeof(cpu_set_t) ما لم يكن schedset قد تم تخصيصه ديناميكيًا باستخدام CPU_ALLOC.

الإرجاع

0 عند النجاح.

-1 مع تعيين errno إلى ENOMEM إذا فشل أي إعادة تخصيص داخلي.
