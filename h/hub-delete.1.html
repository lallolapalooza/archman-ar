hub-delete(1)

الحزمة: hub

التراخيص: MIT

hub-delete(1) دليل hub hub-delete(1)

الاسم

hub-delete - حذف مستودع موجود على GitHub.

الموجز

hub delete [-y] [ORGANIZATION/]NAME

الخيارات

-y, --yes

تخطي مطالبة التأكيد وحذف المستودع فوراً.

[ORGANIZATION/]NAME

اسم المستودع على GitHub.

أمثلة

$ hub delete recipes
[ تم حذف المستودع الشخصي على GitHub ]
$ hub delete sinatra/recipes
[ تم حذف المستودع في منظمة GitHub ]
