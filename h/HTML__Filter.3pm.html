HTML__Filter(3pm)

الحزمة: perl-html-parser

التراخيص: PerlArtistic

HTML::Filter(3) وثائق Perl المساهمة من المستخدم HTML::Filter(3)

الاسم

HTML::Filter - تصفية نص HTML من خلال المحلل

ملاحظة

تم إيقاف هذه الوحدة. يوفر الآن "HTML::Parser" وظائف "HTML::Filter" بكفاءة أكبر بكثير باستخدام المعالج الافتراضي "default".

الملخص

require HTML::Filter;
$p = HTML::Filter->new->parse_file("index.html");

الوصف

"HTML::Filter" هو محلل HTML يقوم بشكل افتراضي بطباعة النص الأصلي لكل عنصر HTML (إصدار بطيء من cat(1) بشكل أساسي). يمكن تجاوز طرق الاستدعاء العكسي لتعديل التصفية لعناصر HTML معينة، ويمكنك تجاوز طريقة output() التي يتم استدعاؤها لطباعة نص HTML.

"HTML::Filter" هي فئة فرعية من "HTML::Parser". هذا يعني أنه يجب تقديم المستند إلى المحلل عن طريق استدعاء طرق $p->parse() أو $p->parse_file().

أمثلة

المثال الأول هو مرشح يزيل جميع التعليقات من ملف HTML. يتم تحقيق ذلك عن طريق تجاوز طريقة التعليق (comment) للقيام لا شيء.

package CommentStripper;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub comment { }  # تجاهل التعليقات

المثال الثاني يوضح مرشحًا يزيل أي <TABLE>s موجودة في ملف HTML. نقوم بتخصيص طرق start() و end() لعد علامات الجدول ثم نمنع الطباعة عندما نكون داخل جدول.

package TableStripper;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub start
{
   my $self = shift;
   $self->{table_seen}++ if $_[0] eq "table";
   $self->SUPER::start(@_);
}
sub end
{
   my $self = shift;
   $self->SUPER::end(@_);
   $self->{table_seen}-- if $_[0] eq "table";
}
sub output
{
    my $self = shift;
    unless ($self->{table_seen}) {
        $self->SUPER::output(@_);
    }
}

إذا كنت ترغب في تجميع النص المحلل داخليًا، فقد ترغب في القيام بشيء مثل هذا:

package FilterIntoString;
require HTML::Filter;
@ISA=qw(HTML::Filter);
sub output { push(@{$_[0]->{fhtml}}, $_[1]) }
sub filtered_html { join("", @{$_[0]->{fhtml}}) }
