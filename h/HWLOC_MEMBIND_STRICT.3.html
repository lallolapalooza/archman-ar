HWLOC_MEMBIND_STRICT(3)

الحزمة: hwloc

التراخيص: BSD-3-Clause

mbind_policy_t

سياسة ربط الذاكرة. يمكن استخدام هذه الثوابت لاختيار سياسة الربط. لا يمكن استخدام سوى سياسة واحدة في كل مرة (أي لا يمكن دمج القيم معًا).

لا تدعم جميع الأنظمة جميع أنواع الربط. يمكن استخدام hwloc_topology_get_support() للاستعلام عن دعم سياسة ربط الذاكرة الفعلي في نظام التشغيل المستخدم حاليًا. راجع قسم "الوصف التفصيلي" في ربط الذاكرة لوصف الأخطاء التي يمكن أن تحدث.

تعداد

HWLOC_MEMBIND_DEFAULT
إعادة تعيين سياسة تخصيص الذاكرة إلى الإعداد الافتراضي للنظام. اعتمادًا على نظام التشغيل، قد يتوافق هذا مع HWLOC_MEMBIND_FIRSTTOUCH (Linux، FreeBSD)، أو HWLOC_MEMBIND_BIND (AIX، HP-UX، Solaris، Windows). لا يتم إرجاع هذه السياسة أبدًا بواسطة وظائف الحصول على ربط الذاكرة. يتم تجاهل وسيطة عقدة العقد.
HWLOC_MEMBIND_FIRSTTOUCH
تخصيص كل صفحة ذاكرة بشكل فردي في عقدة NUMA المحلية للمؤشر الذي يلمسها. عادةً ما تكون عقدة العقد المعطاة هي hwloc_topology_get_topology_nodeset() بحيث يمكن للمؤشر الذي يلمس تشغيل وتخصيص العقدة في أي عقدة في النظام.

على AIX، إذا كانت عقدة العقد أصغر، يتم تخصيص الصفحات محليًا (إذا كانت العقدة المحلية في عقدة العقد) أو من عقدة عشوائية غير محلية (بخلاف ذلك).

HWLOC_MEMBIND_BIND
تخصيص الذاكرة على العقد المحددة. قد يختلف السلوك الفعلي قليلاً بين أنظمة التشغيل، خاصة عند امتلاء (بعض) العقد المطلوبة. على Linux، بشكل افتراضي، يتم استخدام سياسة MPOL_PREFERRED_MANY (أو MPOL_PREFERRED). ومع ذلك، إذا تم أيضًا إعطاء علامة hwloc الصارمة، فسيتم استخدام سياسة Linux MPOL_BIND بدلاً من ذلك.
HWLOC_MEMBIND_INTERLEAVE
تخصيص الذاكرة على العقد المعطاة بترتيب متداخل / دائري. يعتمد التخطيط الدقيق للذاكرة عبر عقد NUMA المتعددة على نظام التشغيل / النظام. يمكن أن يكون التداخل مفيدًا عندما تقوم المؤشرات الموزعة عبر عقد NUMA المحددة بالوصول إلى نطاق الذاكرة بالكامل بشكل متزامن، حيث سيقوم التداخل بتوازن إشارات الذاكرة.
HWLOC_MEMBIND_WEIGHTED_INTERLEAVE
تخصيص الذاكرة على العقد المعطاة بترتيب متداخل / موزون. يعتمد التخطيط الدقيق للذاكرة عبر عقد NUMA المتعددة على نظام التشغيل / النظام. يمكن أن يكون التداخل الموزون مفيدًا عندما تقوم المؤشرات الموزعة عبر عقد NUMA المحددة بقدرات عرض نطاق ترددي مختلفة بالوصول إلى نطاق الذاكرة بالكامل بشكل متزامن، حيث سيقوم التداخل بتوازن إشارات الذاكرة.
HWLOC_MEMBIND_NEXTTOUCH
لكل صفحة مرتبطة بهذه السياسة، في المرة التالية التي يتم لمسها (وفي المرة التالية فقط)، يتم نقلها من موقعها الحالي إلى عقدة NUMA المحلية للمؤشر الذي حدث فيه مرجع الذاكرة (إذا كانت بحاجة إلى نقل على الإطلاق).
HWLOC_MEMBIND_MIXED
يتم إرجاعه بواسطة وظائف get_membind() عندما يكون لدى مؤشرات متعددة أو أجزاء من منطقة ذاكرة سياسات ربط ذاكرة مختلفة. يتم إرجاعه أيضًا عندما يكون الربط غير معروف لأن خطافات الربط فارغة عند تحميل الطوبولوجيا من XML بدون HWLOC_THISSYSTEM=1، وما إلى ذلك.

توثيق الوظيفة

void * hwloc_alloc (hwloc_topology_t topology, size_t len)

تخصيص بعض الذاكرة. هذا يعادل malloc()، باستثناء أنه يحاول تخصيص ذاكرة محاذية للصفحات من نظام التشغيل.

الإرجاع

مؤشر إلى المنطقة المخصصة، أو NULL عند حدوث خطأ.

ملاحظة

يجب تحرير الذاكرة المخصصة باستخدام hwloc_free().

void * hwloc_alloc_membind (hwloc_topology_t topology, size_t len, hwloc_const_bitmap_t set, hwloc_membind_policy_t policy, int flags)

تخصيص بعض الذاكرة على عقد ذاكرة NUMA المحددة بواسطة set.

الإرجاع

مؤشر إلى المنطقة المخصصة.

NULL مع تعيين errno إلى ENOSYS إذا لم يكن الإجراء مدعومًا وتم إعطاء HWLOC_MEMBIND_STRICT.

NULL مع تعيين errno إلى EXDEV إذا لم يكن الربط قابلاً للتنفيذ وتم إعطاء HWLOC_MEMBIND_STRICT.

NULL مع تعيين errno إلى ENOMEM إذا فشل تخصيص الذاكرة حتى قبل محاولة الربط.

إذا تم تحديد HWLOC_MEMBIND_BYNODESET، فسيتم اعتبار set عقدة عقد. وإلا، فهي مجموعة معالجة.

ملاحظة

يجب تحرير الذاكرة المخصصة باستخدام hwloc_free().

void * hwloc_alloc_membind_policy (hwloc_topology_t topology, size_t len, hwloc_const_bitmap_t set, hwloc_membind_policy_t policy, int flags) [inline]

تخصيص بعض الذاكرة على عقد ذاكرة NUMA المحددة بواسطة set. أولاً، حاول التخصيص بشكل صحيح باستخدام hwloc_alloc_membind(). عند الفشل، يتم تغيير سياسة ربط ذاكرة العملية أو المؤشر الحالي باستخدام hwloc_set_membind() قبل تخصيص الذاكرة. وبالتالي، تعمل هذه الوظيفة في المزيد من الحالات، على حساب تغيير الحالة الحالية (مما قد يؤثر على التخصيصات المستقبلية التي لا تحدد أي سياسة).

إذا تم تحديد HWLOC_MEMBIND_BYNODESET، فسيتم اعتبار set عقدة عقد. وإلا، فهي مجموعة معالجة.

الإرجاع

مؤشر إلى المنطقة المخصصة، أو NULL عند حدوث خطأ.

int hwloc_free (hwloc_topology_t topology, void * addr, size_t len)

تحرير الذاكرة التي تم تخصيصها مسبقًا بواسطة hwloc_alloc() أو hwloc_alloc_membind().

الإرجاع

0 عند النجاح، -1 عند حدوث خطأ.

int hwloc_get_area_membind (hwloc_topology_t topology, const void * addr, size_t len, hwloc_bitmap_t set, hwloc_membind_policy_t * policy, int flags)

الاستعلام عن وحدات المعالجة المركزية القريبة من عقدة NUMA المادية (العقد) وسياسة الربط للذاكرة المحددة بواسطة (addr, len ). يتم ملء خريطة البت set (التي تم تخصيصها مسبقًا بواسطة المتصل) بربط منطقة الذاكرة.

هذه الوظيفة لديها معلمات إخراج اثنتين: set و policy. تعتمد القيم التي تم إرجاعها في هذه المعلمات على كل من العلامات التي تم تمريرها وسياسات ربط الذاكرة وعقد العقد للصفحات في نطاق العنوان.

إذا تم تحديد HWLOC_MEMBIND_STRICT، فسيتم أولاً فحص الصفحات المستهدفة لمعرفة ما إذا كان لديها جميعًا نفس سياسة ربط الذاكرة وعقدة العقد. إذا لم يكن الأمر كذلك، فسيتم إرجاع -1 وتعيين errno إلى EXDEV. إذا كانت متطابقة عبر جميع الصفحات، فسيتم إرجاع set و policy في set و policy، على التوالي.

إذا لم يتم تحديد HWLOC_MEMBIND_STRICT، فسيتم حساب اتحاد جميع عقد NUMA التي تحتوي على صفحات في نطاق العنوان. إذا كانت جميع الصفحات في الهدف لها نفس السياسة، فسيتم إرجاعها في policy. بخلاف ذلك، سيتم تعيين policy إلى HWLOC_MEMBIND_MIXED.

إذا تم تحديد HWLOC_MEMBIND_BYNODESET، فسيتم اعتبار set عقدة عقد. وإلا، فهي مجموعة معالجة.

إذا تم تحديد أي علامات أخرى، فسيتم إرجاع -1 وتعيين errno إلى EINVAL.

الإرجاع

0 عند النجاح.

-1 مع تعيين errno إلى EINVAL إذا كان len يساوي 0.

int hwloc_get_area_memlocation (hwloc_topology_t topology, const void * addr, size_t len, hwloc_bitmap_t set, int flags)

الحصول على عقد NUMA حيث يتم تخصيص الذاكرة المحددة بواسطة (addr, len ) فعليًا. يتم ملء خريطة البت set (التي تم تخصيصها مسبقًا بواسطة المتصل) وفقًا لعقد NUMA حيث يتم تخصيص صفحات منطقة الذاكرة فعليًا. إذا لم يتم تخصيص أي صفحة بالفعل، فقد يكون set فارغًا.

إذا امتدت الصفحات إلى عقد متعددة، فليس من المحدد ما إذا كانت تمتد بشكل عادل، أو ما إذا كان معظمها على عقدة واحدة، وما إلى ذلك.

قد يقوم نظام التشغيل بنقل صفحات الذاكرة من معالج إلى آخر في أي وقت وفقًا لربطها، لذلك قد ترجع هذه الوظيفة شيئًا قديمًا بالفعل.
