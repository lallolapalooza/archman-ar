حساب الفرق بين طوبولوجيتين. يتم تخزين الفرق كقائمة من إدخالات hwloc_topology_diff_t تبدأ عند diff. يتم حسابه عن طريق إجراء مسح شامل للعمق لكلا شجري الطوبولوجيا بشكل متزامن.

إذا كان الفرق بين كائنين معقدًا جدًا بحيث لا يمكن تمثيله (على سبيل المثال إذا كانت بعض الكائنات لها أنواع مختلفة، أو أعداد مختلفة من الأطفال)، يتم وضع إدخال فرق خاص من النوع HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX. لا يستمر حساب الفرق أسفل هذه الكائنات. لذا يعني كل إدخال فرق كهذا أن الفرق بين شجرتين فرعيتين لم يكن من الممكن حسابه.

الارجاع

0 إذا كان يمكن تمثيل الفرق بشكل صحيح.

0 مع diff يشير إلى NULL إذا لم يكن هناك فرق بين الطوبولوجيتين.

1 إذا كان الفرق معقدًا جدًا (انظر أعلاه). ستكون بعض الإدخالات في القائمة من النوع HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

-1 عند أي خطأ آخر.

ملاحظة

flags غير مستخدم حاليًا. يجب أن يكون 0.

يجب تحرير diff الناتج باستخدام hwloc_topology_diff_destroy().

يمكن فقط تصدير diff الناتج إلى XML أو تمريره إلى hwloc_topology_diff_apply() إذا تم إرجاع 0، أي إذا لم يتم إدراج أي إدخال من النوع HWLOC_TOPOLOGY_DIFF_TOO_COMPLEX.

قد يتم تعديل diff الناتج عن طريق إزالة بعض الإدخالات من القائمة. يجب تحرير الإدخالات التي تمت إزالتها عن طريق تمريرها إلى hwloc_topology_diff_destroy() (ممكن كقائمة أخرى).

int hwloc_topology_diff_export_xml (hwloc_topology_diff_t diff, const char * refname, const char * xmlpath)

تصدير قائمة بفروقات الطوبولوجيا إلى ملف XML. إذا لم يكن NULL، فإن refname يحدد سلسلة تعريف للطوبولوجيا المرجعية التي تم استخدامها كأساس عند حساب هذا الفرق. عادة ما يكون هذا المعرف هو اسم ملف XML الآخر الذي يحتوي على الطوبولوجيا المرجعية. يتم إرجاع هذه السمة عند قراءة الفرق من XML.

الارجاع

0 عند النجاح، -1 عند الخطأ.

int hwloc_topology_diff_export_xmlbuffer (hwloc_topology_diff_t diff, const char * refname, char ** xmlbuffer, int * buflen)

تصدير قائمة بفروقات الطوبولوجيا إلى مخزن مؤقت XML. إذا لم يكن NULL، فإن refname يحدد سلسلة تعريف للطوبولوجيا المرجعية التي تم استخدامها كأساس عند حساب هذا الفرق. عادة ما يكون هذا المعرف هو اسم ملف XML الآخر الذي يحتوي على الطوبولوجيا المرجعية. يتم إرجاع هذه السمة عند قراءة الفرق من XML.

ينتهي المخزن المؤقت المُرجع بـ \0 والذي يتم تضمينه في الطول المُرجع.

الارجاع

0 عند النجاح، -1 عند الخطأ.

ملاحظة

يجب تحرير مخزن XML المؤقت لاحقًا باستخدام hwloc_free_xmlbuffer().

int hwloc_topology_diff_load_xml (const char * xmlpath, hwloc_topology_diff_t * diff, char ** refname)

تحميل قائمة بفروقات الطوبولوجيا من ملف XML. إذا لم يكن NULL، فسيتم ملء refname بسلسلة تعريف الطوبولوجيا المرجعية لملف الفرق، إن وجدت في ملف XML. عادة ما يكون هذا المعرف هو اسم ملف XML الآخر الذي يحتوي على الطوبولوجيا المرجعية.

الارجاع

0 عند النجاح، -1 عند الخطأ.

ملاحظة

يجب على المتصل تحرير المؤشر المُرجع في refname لاحقًا.

int hwloc_topology_diff_load_xmlbuffer (const char * xmlbuffer, int buflen, hwloc_topology_diff_t * diff, char ** refname)

تحميل قائمة بفروقات الطوبولوجيا من مخزن مؤقت XML. بناء قائمة بالفروقات من المخزن المؤقت للذاكرة XML المُعطى في xmlbuffer وطوله buflen (بما في ذلك \0 في النهاية). قد يكون هذا المخزن المؤقت قد تم ملؤه سابقًا بواسطة hwloc_topology_diff_export_xmlbuffer().

الارجاع

0 عند النجاح، -1 عند الخطأ.

ملاحظة
