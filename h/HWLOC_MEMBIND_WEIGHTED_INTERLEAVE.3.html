NAME

EAVE - EAVE-3d library

SYNOPSIS

#include <eave.h>

int eave_init(void);

void eave_cleanup(void);

int eave_load(const char *filename);

void eave_unload(int id);

int eave_get_polygon(int id, int poly_index, EAVE_POLYGON *polygon);

int eave_get_num_polygons(int id);

int eave_ray_intersect(const EAVE_RAY *ray, EAVE_INTERSECT *intersect);

DESCRIPTION

The EAVE-3d library provides an interface to load and query 3d models. It supports the Wavefront OBJ format.

FUNCTIONS

eave_init() initializes the EAVE-3d library. It must be called before any other EAVE functions.

eave_cleanup() cleans up the EAVE-3d library. It must be called when you are done with the library.

eave_load(const char *filename) loads a 3d model from the specified file. It returns a unique identifier for the model, or -1 on error.

eave_unload(int id) unloads the 3d model with the given identifier.

eave_get_polygon(int id, int poly_index, EAVE_POLYGON *polygon) retrieves the polygon at the specified index from the model with the given identifier. It returns 0 on success, or -1 on error.

eave_get_num_polygons(int id) returns the number of polygons in the model with the given identifier.

eave_ray_intersect(const EAVE_RAY *ray, EAVE_INTERSECT *intersect) performs a ray intersection test with all loaded models. It returns 1 if an intersection was found, 0 otherwise.
