IDN SUPPORT

IDN is an abbreviation for Internationalizing Domain Names. The BIND package supports IDN through the optional libidn library.

If libidn is present, IDN support is enabled by default. IDN support is disabled if the IDN_DISABLE environment variable is set when host runs.
