hts(1)

الحزمة: httptunnel

التراخيص: GPL2

HTS(1) دليل الأوامر العامة HTS(1)

الاسم

hts - خادم httptunnel

الملخص

hts [خيارات] [منفذ]

الوصف

هذه الصفحة اليدوية توثق باختصار أمر hts.

يستمع hts لاتصالات httptunnel الواردة في PORT (المنفذ الافتراضي هو 8888). عند إنشاء اتصال، يتم إعادة توجيه الإدخال/الإخراج إلى الوجهة المحددة بواسطة مفتاح --device أو --forward-port.

الخيارات

يتبع البرنامج صيغة سطر أوامر GNU المعتادة، مع خيارات طويلة تبدأ بشرطتين (--). يتضمن ملخصًا للخيارات أدناه.

-h, --help
عرض ملخص للخيارات.
-c, --content-length BYTES
استخدام طلبات HTTP PUT بحجم BYTES (يمكن التعرف على البوادئ k، M، و G)
-d, --device DEVICE
استخدام DEVICE للإدخال والإخراج
-F, --forward-port HOST:PORT
الاتصال بـ PORT في HOST واستخدامه للإدخال والإخراج
-k, --keep-alive SECONDS
إرسال بايتات keepalive كل SECONDS ثانية (الافتراضي هو 5)
-M, --max-connection-age SEC
الحد الأقصى لوقت بقاء الاتصال مفتوحًا هو SEC ثانية (الافتراضي هو 300)
-S, --strict-content-length
كتابة عدد بايتات Content-Length دائمًا في الطلبات
-V, --version
إخراج معلومات الإصدار والخروج
-p, --pid-file LOCATION
كتابة ملف PID إلى LOCATION
