HTML__LinkExtor(3pm)

الحزمة: perl-html-parser

التراخيص: PerlArtistic

HTML::LinkExtor(3) وثائق Perl من مساهمة المستخدم HTML::LinkExtor(3)

الاسم

HTML::LinkExtor - استخراج الروابط من مستند HTML

ملخص

require HTML::LinkExtor;
$p = HTML::LinkExtor->new(\&cb, "http://www.perl.org/");
sub cb {
    my($tag, %links) = @_;
    print "$tag @{[%links]}\n";
}
$p->parse_file("index.html");

الوصف

HTML::LinkExtor هو محلل HTML يقوم باستخراج الروابط من مستند HTML. HTML::LinkExtor هو فئة فرعية من HTML::Parser. هذا يعني أنه يجب تقديم المستند إلى المحلل عن طريق استدعاء الأساليب $p->parse() أو $p->parse_file().

$p = HTML::LinkExtor->new
$p = HTML::LinkExtor->new( $callback )
$p = HTML::LinkExtor->new( $callback, $base )
يقبل المُنشئ وسيطين اختياريين. الأول هو مرجع إلى روتين استدعاء. سيتم استدعاؤه عند العثور على الروابط. إذا لم يتم توفير استدعاء، فسيتم تجميع الروابط داخليًا ويمكن استردادها عن طريق استدعاء الأسلوب $p->links().

الوسيط $base هو عنوان URL أساسي اختياري يُستخدم لجعل جميع عناوين URL التي تم العثور عليها مطلقة. تحتاج إلى تثبيت وحدة URI إذا قمت بتوفير $base.

يتم استدعاء الاستدعاء باسم العلامة بالأحرف الصغيرة كوسيط أول، ثم جميع سمات الارتباط كأزواج مفتاح/قيمة منفصلة. تتم إزالة جميع السمات غير المرتبطة.

$p->links
يعيد قائمة بجميع الروابط التي تم العثور عليها في المستند. ستكون القيم المُرجعة عبارة عن مصفوفات مجهولة تحتوي على العناصر التالية: 
[$tag, $attr => $url1, $attr2 => $url2,...]

سيقوم الأسلوب $p->links أيضًا بقص قائمة الروابط الداخلية. هذا يعني أنه إذا تم استدعاء الأسلوب مرتين دون أي تحليل بينهما، فستعيد الاستدعاء الثاني قائمة فارغة.

لاحظ أيضًا أن $p->links سيكون فارغًا دائمًا إذا تم توفير روتين استدعاء عند إنشاء HTML::LinkExtor.

مثال

هذا مثال يوضح كيف يمكنك استخراج الروابط من مستند تم تلقيه باستخدام LWP:

use LWP::UserAgent;
use HTML::LinkExtor;
use URI::URL
$url = "http://www.perl.org/";  # على سبيل المثال
$ua = LWP::UserAgent->new;
# إعداد استدعاء يجمع روابط الصور
my @imgs = ();
sub callback {
   my($tag, %attr) = @_;
   return if $tag ne 'img';  # نحن ننظر فقط عن كثب إلى <img ...>
   push(@imgs, values %attr);
}
# إنشاء المحلل. للأسف، نحن لا نعرف الأساس بعد
# (قد يكون مختلفًا عن $url)
$p = HTML::LinkExtor->new(\&callback);
# طلب المستند وتحليله فور وصوله
$res = $ua->request(HTTP::Request->new(GET => $url),
                    sub {$p->parse($_[0])});
# توسيع جميع عناوين URL للصور إلى عناوين مطلقة
my $base = $res->base;
@imgs = map { $_ = url($_, $base)->abs; } @imgs;
# طباعتها
print join("\n", @imgs), "\n";
