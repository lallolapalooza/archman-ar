NAME

hpcdtoppm

convert Photo-CD image to PPM format

SYNOPSIS

hpcdtoppm [-v] [-ycc] [-1|-Base/16|-128x192] [-2|-Base/4|-256x384] [-3|-Base|-512x768] [-4|-4Base|-1024x1536] [-5|-16Base|-2048x3072] [-6|-64Base|-4096x6144] [pcdfile]

DESCRIPTION

The hpcdtoppm program converts a Photo-CD image to the Portable Pixmap (PPM) format. The Photo-CD format is a proprietary format from Kodak, used for storing images on CD-ROM. It is based on the Kodak Photo-CD system specification.

The program supports the following resolutions:

-1 or -Base/16 or -128x192
Extracts the Base/16 image (128x192 pixels).
-2 or -Base/4 or -256x384
Extracts the Base/4 image (256x384 pixels).
-3 or -Base or -512x768
Extracts the Base image (512x768 pixels).
-4 or -4Base or -1024x1536
Extracts the 4Base image (1024x1536 pixels).
-5 or -16Base or -2048x3072
Extracts the 16Base image (2048x3072 pixels).
-6 or -64Base or -4096x6144
Extracts the 64Base image (4096x6144 pixels). This resolution can only be extracted from ProPhotoCD images. The path for the 64Base extension files is derived from the path to the image file. This means that it does not work on stdin, and the directory structure must be exactly the same as on the ProPhotoCD.

The following options are also supported:

-v
Enable verbose output. This option is not implemented.
-ycc
Write the image in a variation of the PPM format where samples are YCC instead of RGB. This is useful for color correction, as the Y channel is more or less a grayscale representation of the image. The YCC values are scaled to the range 0-255. (See the ppm(5) man page for a description of the PPM format and the YCC variant, and the pnmcolorcorrect(1) man page for details on color correction using YCC samples).

If no image file is specified, the program reads from standard input.

Postcript Output

For Postscript output (options -ps, -eps, -psg, -epsg, -psd, -epsg) you can define both the resolution and placement of the image. Both size and position are specified in points (1/72 inch).

The position of the image (where the origin is assumed to be at the lower left corner of the page) is controlled by the -pl and -pb options (applicable at all resolutions).

The size of color and grayscale images is changed with the -pw and -ph options. Every image pixel is mapped onto one Postscript pixel.

There are three modes of control for dithered Postscript:

Image size

(-pw and -ph)
Printer resolution
(-dpi)
Scaling factor
(-fak)

These three factors are interdependent, hence no more then two can be specified simultaneously. Using -dpi and the -pw/-ph options together often yields pleasing results. Even using the default values for these options will produce results differing from those obtained without use of the options.

Limitations

The program ignores read protection.

The -i option is not working correctly.

Available information obout the Photo-CD format is vague; this program was developed by trial-and-error after staring at hex-dumps. Please send bugs reports and patches to the author.
