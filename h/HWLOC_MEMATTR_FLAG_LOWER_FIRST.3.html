HWLOC_MEMATTR_FLAG_LOWER_FIRST(3)

الحزمة: hwloc

التراخيص: BSD-3-Clause

NAME

HWLOC_MEMATTR_FLAG_LOWER_FIRST - Flags for memory attributes.

SYNOPSIS

#include <hwloc.h>

typedef enum hwloc_memattr_flag_e {
  HWLOC_MEMATTR_FLAG_NONE = 0,
  HWLOC_MEMATTR_FLAG_LOWER_FIRST = 1,
  HWLOC_MEMATTR_FLAG_TSCX = 2,
  HWLOC_MEMATTR_FLAG_PAGE_SHIFT = 4,
  HWLOC_MEMATTR_FLAG_ACCESSIBLE = 8,
  HWLOC_MEMATTR_FLAG_SWAPPED = 16,
  HWLOC_MEMATTR_FLAG_DISCARDED = 32,
  HWLOC_MEMATTR_FLAG_VOLATILE = 64,
  HWLOC_MEMATTR_FLAG_HUGEPAGE = 128,
  HWLOC_MEMATTR_FLAG_IO = 256,
  HWLOC_MEMATTR_FLAG_IO_TRANSLATION = 512,
  HWLOC_MEMATTR_FLAG_PAGE_SIZE = 1024,
  HWLOC_MEMATTR_FLAG_HWLOC_MEMORY = 2048,
  HWLOC_MEMATTR_FLAG_PAGE_LOCALITY = 4096,
  HWLOC_MEMATTR_FLAG_ALL = 8191
} hwloc_memattr_flag_t;

Detailed Description

The hwloc_memattr_flag_t type is used to describe the attributes of memory. These flags can be passed to functions like hwloc_memattr_get_flags to query specific memory attributes.

  • HWLOC_MEMATTR_FLAG_NONE: No specific attributes are set.
  • HWLOC_MEMATTR_FLAG_LOWER_FIRST: Indicates that lower memory banks appear first in the hierarchy.
  • HWLOC_MEMATTR_FLAG_TSCX: Relates to the Thermal, Static, Cooling, and power management features.
  • HWLOC_MEMATTR_FLAG_PAGE_SHIFT: Specifies the page shift value for memory.
  • HWLOC_MEMATTR_FLAG_ACCESSIBLE: Indicates if the memory is accessible.
  • HWLOC_MEMATTR_FLAG_SWAPPED: Indicates if the memory has been swapped out.
  • HWLOC_MEMATTR_FLAG_DISCARDED: Indicates if the memory has been discarded.
  • HWLOC_MEMATTR_FLAG_VOLATILE: Indicates if the memory is volatile.
  • HWLOC_MEMATTR_FLAG_HUGEPAGE: Indicates if the memory uses huge pages.
  • HWLOC_MEMATTR_FLAG_IO: Indicates if the memory is related to I/O.
  • HWLOC_MEMATTR_FLAG_IO_TRANSLATION: Indicates if the memory involves I/O translation.
  • HWLOC_MEMATTR_FLAG_PAGE_SIZE: Specifies the page size of the memory.
  • HWLOC_MEMATTR_FLAG_HWLOC_MEMORY: Indicates memory managed by hwloc.
  • HWLOC_MEMATTR_FLAG_PAGE_LOCALITY: Indicates the locality of the memory page.
  • HWLOC_MEMATTR_FLAG_ALL: A bitmask representing all known memory attributes.

Function Documentation

This section contains documentation for functions related to memory attributes. Please refer to the specific function man pages for detailed information.

  • hwloc_memattr_get_flags: Get memory attributes.
