http(1)

الحزمة: httpie

التراخيص: BSD-3-Clause

http(1) دليل HTTPie http(1)

الاسم

http

الملخص

http [METHOD] URL [REQUEST_ITEM ...]

الوصف

HTTPie: عميل HTTP عصري وسهل الاستخدام لسطر الأوامر لعصر واجهات برمجة التطبيقات. https://httpie.io

الوسائط الموضعية

تأتي هذه الوسائط بعد أي علامات وبالترتيب الذي تم سردها به. URL مطلوب فقط.

METHOD

طريقة HTTP المستخدمة للطلب (GET، POST، PUT، DELETE، ...).

يمكن حذف هذه الوسيطة، وفي هذه الحالة سيستخدم HTTPie POST إذا كان هناك بعض البيانات ليتم إرسالها، وإلا GET:


$ http example.org # => GET
$ http example.org hello=world # => POST

URL

عنوان URL للطلب. المخطط الافتراضي هو 'http://' إذا لم يتضمن عنوان URL واحدًا. (يمكنك تجاوز هذا باستخدام: --default-scheme=http/https)

يمكنك أيضًا استخدام اختصار للمضيف المحلي


$ http :3000 # => http://localhost:3000
$ http :/foo # => http://localhost/foo

REQUEST_ITEM

أزواج مفتاح-قيمة اختيارية ليتم تضمينها في الطلب. يحدد الفاصل المستخدم النوع:

':' رؤوس HTTP:


Referer:https://httpie.io Cookie:foo=bar User-Agent:bacon/1.0

'==' معلمات URL التي سيتم إلحاقها بعنوان URI للطلب:


search==httpie

'=' حقول البيانات التي سيتم تسلسلها في كائن JSON (مع --json، -j)
أو بيانات النموذج (مع --form، -f):


name=HTTPie language=Python description='CLI HTTP client'

':=' حقول JSON غير نصية (فقط مع --json، -j):


awesome:=true amount:=42 colors:='["red", "green", "blue"]'

'@' حقول نموذج ملف (فقط مع --form أو --multipart):


cv@~/Documents/CV.pdf
cv@'~/Documents/CV.pdf;type=application/pdf'

'.@' حقل بيانات مثل '='، ولكنه يأخذ مسار ملف ويتضمن محتوياته:


essay=@Documents/essay.txt

':=@' حقل JSON خام مثل ':=', ولكنه يأخذ مسار ملف ويتضمن محتوياته:


package:=@./package.json

يمكنك استخدام شرطة مائلة عكسية للهروب من فاصل متعارض في اسم الحقل:


field-name-with\:colon=value

أنواع المحتوى المحددة مسبقًا

--json, -j

(افتراضي) يتم تسلسل عناصر البيانات من سطر الأوامر ككائن JSON. يتم تعيين رؤوس Content-Type و Accept إلى application/json (إذا لم يتم تحديدها).

--form, -f

يتم تسلسل عناصر البيانات من سطر الأوامر كحقول نموذج.

يتم تعيين Content-Type إلى application/x-www-form-urlencoded (إذا لم يتم تحديده). يؤدي وجود أي حقول ملف إلى طلب multipart/form-data.

--multipart

مشابه لـ --form، ولكنه يرسل دائمًا طلب multipart/form-data (أي، حتى بدون ملفات).

--boundary

حدد سلسلة فاصل مخصصة لطلبات multipart/form-data. له تأثير فقط عند استخدامه مع --form.

--raw

يتيح لك هذا الخيار تمرير بيانات طلب خام بدون معالجة إضافية (على عكس بناء الجملة لعناصر الطلب المهيكلة):


$ http --raw='data' pie.dev/post

يمكنك تحقيق نفس الشيء عن طريق توجيه البيانات عبر stdin:


$ echo data | http pie.dev/post

أو اجعل HTTPie يقوم بتحميل البيانات الخام من ملف:


$ http pie.dev/post @data.txt

خيارات معالجة المحتوى

--compress, -x

المحتوى مضغوط (مشفر) باستخدام خوارزمية Deflate. يتم تعيين رأس Content-Encoding إلى deflate.

يتم تخطي الضغط إذا بدا أن نسبة الضغط سلبية. يمكن فرض الضغط عن طريق تكرار الوسيطة.

معالجة الإخراج

--pretty

يتحكم في معالجة الإخراج. يمكن أن تكون القيمة "none" لعدم تنسيق الإخراج (افتراضي للإخراج المعاد توجيهه)، "all" لتطبيق الألوان والتنسيق (افتراضي لإخراج الطرفية)، "colors"، أو "format".

--style, -s STYLE

نمط تلوين الإخراج (الافتراضي هو "auto"). يمكن أن يكون واحدًا مما يلي:


auto, pie, pie-dark, pie-light, solarized

للعثور على جميع الأنماط المتاحة في نظامك، جرب:

$ http --style

يتبع النمط "auto" أنماط ألوان ANSI الخاصة بطرفيتك. لكي تعمل الأنماط غير الآلية بشكل صحيح، يرجى التأكد من تعيين متغير البيئة $TERM إلى "xterm-256color" أو ما شابه (على سبيل المثال، عن طريق `export TERM=xterm-256color' في ~/.bashrc).

--unsorted

يعطل جميع عمليات الفرز أثناء تنسيق الإخراج. إنه اختصار لـ:


--format-options=headers.sort:false,json.sort_keys:false

--sorted

يعيد تمكين جميع خيارات الفرز أثناء تنسيق الإخراج. إنه اختصار لـ:


--format-options=headers.sort:true,json.sort_keys:true

--response-charset ENCODING

تجاوز ترميز الاستجابة لأغراض عرض الطرفية، على سبيل المثال:


--response-charset=utf8
--response-charset=big5

--response-mime MIME_TYPE

تجاوز نوع MIME للاستجابة للتلوين والتنسيق للطرفية، على سبيل المثال:


--response-mime=application/json
--response-mime=text/xml

--format-options

يتحكم في تنسيق الإخراج. ذات صلة فقط عندما يتم تمكين التنسيق من خلال --pretty=all (صريح أو ضمني) أو --pretty=format. الخيارات التالية هي الخيارات الافتراضية:


headers.sort:true
json.format:true
json.indent:4
json.sort_keys:true
xml.format:true
xml.indent:2

يمكنك استخدام هذه الوسيطة عدة مرات، وكذلك تحديد خيارات متعددة مفصولة بفواصل.
