hwlocality_helper_find_inside(3)

الحزمة: hwloc

التراخيص: BSD-3-Clause

NAME

hwlocality_helper_find_inside - Find objects inside a cpuset

SYNOPSIS

#include <hwloc.h>

int hwloc_get_obj_inside_cpuset_by_depth (hwloc_topology_t topology,
        hwloc_const_cpuset_t set, int depth, unsigned idx);
hwloc_obj_t hwloc_get_obj_inside_cpuset_by_type (hwloc_topology_t
        topology, hwloc_const_cpuset_t set, hwloc_obj_type_t type,
        unsigned idx);

Detailed Description

These functions return objects that are included in the CPU set set.

The hwloc_get_obj_inside_cpuset_by_depth() function returns the (logically) idx -th object at depth depth that is included in CPU set set.

The hwloc_get_obj_inside_cpuset_by_type() function returns the idx -th object of type type that is included in CPU set set.

The index idx is logical: it only counts objects whose CPU set is not empty and which are included in the given CPU set set.

For example, if the given CPU set is HWLOC_CPUBIND_PROCESS and the topology is a NUMA machine with 2 NUMA nodes, and only the first NUMA node contains PUs included in the given CPU set, then calling hwloc_get_obj_inside_cpuset_by_depth(topology, set, HWLOC_TYPE_DEPTH_NUMANODE, 0) will return the first NUMA node object, and calling hwloc_get_obj_inside_cpuset_by_depth(topology, set, HWLOC_TYPE_DEPTH_NUMANODE, 1) will return NULL.

If the requested object is not found, NULL is returned.

hwloc_get_obj_inside_cpuset_by_depth

Returns

the object if found.

NULL if there is no object at depth depth that is included in the set.

The logical index among the objects included in the set if any.

-1 if the object is not included in the set.

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if obj does not have CPU sets (I/O objects).

hwloc_get_obj_inside_cpuset_by_type

Returns

the object if any.

NULL if there is no such object.

NULL if there is no depth for given type.

NULL if there are multiple depths for given type, the caller should fallback to hwloc_get_obj_inside_cpuset_by_depth().

Note

Objects with empty CPU sets are ignored (otherwise they would be considered included in any given set).

This function cannot work if objects of the given type do not have CPU sets (I/O or Misc objects).
