وصف تفصيلي

توثيق الدوال

int hwloc_obj_add_info (hwloc_obj_t obj, const char * name, const char * value)

إضافة زوج الاسم والقيمة المعطى إلى سمات معلومات الكائن المعطى. يتم إلحاق زوج المعلومات بمصفوفة المعلومات الحالية حتى لو كان هناك زوج آخر بنفس الاسم موجودًا بالفعل.

يتم نسخ السلاسل المدخلة قبل إضافتها في معلومات الكائن.

يعيد

0 عند النجاح، -1 عند الخطأ.

ملاحظة

قد تُستخدم هذه الدالة لفرض ألوان الكائنات في المخرجات الرسومية lstopo عن طريق إضافة 'lstopoStyle' كاسم و 'Background=#rrggbb' كقيمة. انظر CUSTOM COLORS في صفحة دليل lstopo(1) لمزيد من التفاصيل.

إذا كانت name أو value تحتوي على أحرف غير قابلة للطباعة، فسيتم إسقاطها عند التصدير إلى XML، انظر hwloc_topology_export_xml() في hwloc/export.h.

const char * hwloc_obj_get_info_by_name (hwloc_obj_t obj, const char * name) [inline]

البحث عن الاسم المعطى في معلومات الكائن وإعادة القيمة المقابلة. إذا تطابقت سمات معلومات متعددة مع الاسم المعطى، يتم إرجاع الأولى فقط.

يعيد

مؤشر إلى سلسلة القيمة إذا كانت موجودة.

NULL إذا لم توجد سمة معلومات كهذه.

ملاحظة

يجب ألا يقوم المستدعي بتحرير السلسلة، فهي تنتمي إلى مكتبة hwloc.

int hwloc_obj_set_subtype (hwloc_topology_t topology, hwloc_obj_t obj, const char * subtype)

تعيين (أو استبدال) النوع الفرعي للكائن. يتم نسخ النوع الفرعي المعطى داخليًا، والمستدعي مسؤول عن تحرير النوع الفرعي الأصلي إذا لزم الأمر.

إذا كان هناك بالفعل نوع فرعي آخر في الكائن، يتم استبداله. قد يكون النوع الفرعي المعطى NULL لإزالة النوع الفرعي الموجود.

ملاحظة

هذه الدالة مخصصة في الغالب لتهيئة النوع الفرعي للكائنات المضافة بواسطة المستخدم مثل المجموعات باستخدام hwloc_topology_alloc_group_object().

يعيد

0 عند النجاح.

-1 مع تعيين errno إلى ENOMEM عند فشل تخصيص الذاكرة.

المؤلف

تم الإنشاء تلقائيًا بواسطة Doxygen لمجموعة العتاد (hwloc) من الكود المصدري.
