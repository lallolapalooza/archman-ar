hashkit_get_distribution_function(3)

الحزمة: libmemcached-awesome

التراخيص: BSD

NAME

hashkit_get_distribution_function, hashkit_set_distribution_function, hashkit_set_custom_distribution_function - استرداد وتعيين دالة التجزئة للتوزيع

SYNOPSIS

#include <libhashkit/hashkit.h>

hashkit_return_t
hashkit_set_distribution_function(hashkit_st *hash,
    hashkit_hash_algorithm_t algorithm);

hashkit_hash_algorithm_t
hashkit_get_distribution_function(const hashkit_st *hash);

hashkit_return_t
hashkit_set_custom_distribution_function(hashkit_st *hash,
    hashkit_hash_fn *function, void *context);
Parameters
  • hash -- مؤشر إلى بنية hashkit_st مهيأة
  • algorithm -- خوارزمية التجزئة المراد استخدامها
Parameters
  • hash -- مؤشر إلى بنية hashkit_st مهيأة
Parameters
  • hash -- مؤشر إلى بنية hashkit_st مهيأة
  • function -- مؤشر إلى دالة hashkit_hash_fn لاستخدامها كدالة تجزئة توزيع مخصصة لـ HASHKIT_HASH_CUSTOM
  • context -- مؤشر إلى سياق مستخدم يديره بشكل غير شفاف لدالة تجزئة التوزيع المخصصة
hashkit_hash_algorithm_t hashkit_set_distribution_function(const hashkit_st *hash, hashkit_hash_algorithm_t algorithm)
Parameters
hash -- مؤشر إلى بنية hashkit_st مهيأة
algorithm -- خوارزمية التجزئة المراد استخدامها
Returns
HASHKIT_SUCCESS عند النجاح.
hashkit_hash_algorithm_t hashkit_get_distribution_function(const hashkit_st *hash)
Parameters
hash -- مؤشر إلى بنية hashkit_st مهيأة
Returns
hashkit_hash_algorithm_t تشير إلى خوارزمية تجزئة التوزيع المحددة حاليًا للاستخدام
hashkit_return_t hashkit_set_custom_distribution_function(hashkit_st *hash, hashkit_hash_fn *function, void *context)
Parameters
  • hash -- مؤشر إلى بنية hashkit_st مهيأة
  • function -- مؤشر إلى دالة hashkit_hash_fn لاستخدامها كدالة تجزئة توزيع مخصصة لـ HASHKIT_HASH_CUSTOM
  • context -- مؤشر إلى سياق مستخدم يديره بشكل غير شفاف لدالة تجزئة التوزيع المخصصة

DESCRIPTION

تُستخدم هذه الدوال لتعيين واسترداد دوال تجزئة المفاتيح والتوزيع.

RETURN VALUE

hashkit_set_function()، hashkit_set_custom_function() وما يعادلها من دوال التوزيع تُرجع hashkit_return_t::HASHKIT_SUCCESS عند النجاح.

hashkit_get_function() و hashkit_get_distribution_function() تُرجع hashkit_hash_algorithm_t تشير إلى دالة التجزئة المستخدمة.
