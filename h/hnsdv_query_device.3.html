HNSDV_QUERY_DEVICE(3) يدوي HNS Direct Verbs HNSDV_QUERY_DEVICE(3)

الاسم

hnsdv_query_device - الاستعلام عن سمات جهاز hns المحددة

الملخص

#include <infiniband/hnsdv.h>
int hnsdv_query_device(struct ibv_context *context,
                       struct hnsdv_context *attrs_out);

الوصف

يقوم hnsdv_query_device() بالاستعلام عن سمات جهاز hns المحددة.

المعاملات

يرجى الاطلاع على صفحة الدليل ibv_query_device(3) للمتغير context.

attrs_out

struct hnsdv_context {
        uint64_t comp_mask;
        uint64_t flags;
        uint8_t congest_type;
        uint8_t reserved[7];
};
comp_mask
قناع بت يحدد أي الحقول في البنية صالحة:

HNSDV_CONTEXT_MASK_CONGEST_TYPE: خوارزمية التحكم في الازدحام مدعومة.

congest_type
قناع بت للخوارزميات المدعومة للتحكم في الازدحام.

HNSDV_QP_CREATE_ENABLE_DCQCN: إشعار الازدحام الكمي لمركز البيانات HNSDV_QP_CREATE_ENABLE_LDCP: بروتوكول التحكم بزمن وصول منخفض HNSDV_QP_CREATE_ENABLE_HC3: تحكم Huawei المدمج في الازدحام HNSDV_QP_CREATE_ENABLE_DIP: إشعار الازدحام الكمي المستند إلى عنوان IP الوجهة.

قيمة الإرجاع

تُرجع hnsdv_query_device() القيمة 0 عند النجاح، أو قيمة errno عند الفشل (والتي تشير إلى سبب الفشل).
