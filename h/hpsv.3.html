SPPSV: solve symmetric positive-definite tridiagonal systems of linear equations

SPPSV

Purpose

  SPPSV computes the solution to a real system of linear equations
     A * X = B,
  where A is an N-by-N symmetric positive-definite tridiagonal matrix,
  and X and B are N-by-NRHS matrices.

This is the Level 3 Basic Linear Algebra Subprograms (BLAS) interface to the subroutines that compute the solution to a system of linear equations.
