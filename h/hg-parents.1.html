hg-parents(1)

الحزمة: mercurial

التراخيص: GPL

HG(PARENTS) HG(PARENTS)

الاسم

hg parents - عرض الآباء للمجلد العامل أو المراجعة (مهمل)

الخلاصة

hg parents [-r REV] [FILE]

الوصف

طباعة المراجعات الأبوية للمجلد العامل. إذا تم تقديم مراجعة عبر -r/--rev، فسيتم طباعة مراجعة الأصل لتلك المراجعة. إذا تم تقديم وسيطة ملف، فسيتم طباعة المراجعة التي تم فيها تغيير الملف آخر مرة (قبل مراجعة المجلد العامل أو الوسيطة لـ --rev إذا تم تقديمها).

هذا الأمر يعادل:

hg log -r "p1()+p2()" أو
hg log -r "p1(REV)+p2(REV)" أو
hg log -r "max(::p1() and file(FILE))+max(::p2(FILE))" أو
hg log -r "max(::p1(REV) and file(FILE))+max(::p2(REV) and file(FILE))"

راجع hg summary و hg help revsets للمعلومات ذات الصلة.

يعود بـ 0 عند النجاح.

الخيارات

-r,--rev <REV>
عرض آباء المراجعة المحددة
--style <STYLE>
العرض باستخدام ملف خريطة القالب (مهمل)
-T,--template <TEMPLATE>
العرض باستخدام القالب
