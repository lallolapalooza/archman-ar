NAME

zhseqr — Schur factorization of a general complex matrix

SYNOPSIS

  SUBROUTINE ZHSEQR( JOB, COMPZ, N, ILO, IHI, A, LDA, W, Z, LDZ, WORK, LWORK,
                   INFO )

CHARACTER JOB

CHARACTER COMPZ

INTEGER N, ILO, IHI, LDA, LDZ, LWORK, INFO

COMPLEX *16 A(LDA, N), Z(LDZ, N)

COMPLEX *16 WORK(LWORK)

COMPLEX *16 W(N)

Detailed Description

This routine is deprecated. Please use ZUNGQR instead.

ZHSEQR computes the Schur factorization of a complex general matrix A = Q*T*Q‗, where T is the upper quasi-triangular matrix (upper triangular if A is normal) and Q is a unitary matrix. The matrix A is overwriten by the matrices Q and T.

The Schur factorization is computed by means of an algorithm based on the multi-shift QR algorithm. This algorithm is described in detail in.

Parameters

JOB

CHARACTER*1. = 'S': Compute only the Schur factorization T of A.

'N': Compute the Schur factorization T and optionally the matrix Q.

COMPZ

CHARACTER*1. = 'I': Compute the unitary matrix Z such that A = Z*T*Z‗.

'N': Do not compute the matrix Z.

Z is initialized to the identity matrix when

JOB = 'S' and COMPZ = 'I'.

N

INTEGER. The order of the matrix A. N >= 0.

ILO

INTEGER. If N > 0, ILO and IHI specify the range [ILO,IHI] of the matrix A which is to be reduced. The submatrix A(ILO:IHI,ILO:IHI is expected to be in Schur form, and the submatrix A(1:ILO-1, ILO:IHI) and A(ILO:IHI, IHI+1:N) are zero. May be computed by ZGEBAL.

If N = 0, ILO = 1, IHI = 0.

IHI

INTEGER. Default value is N.

A

COMPLEX*16 array, dimension (LDA, N). On entry, the leading N-by-N upper Hessenberg part of the array A contains the matrix to be factored. The elements below the subdiagonal can be any complex numbers.

On exit, if JOB = 'S', A contains the Schur factorization and optionally the matrix Z. The upper quasi-triangular matrix T is stored in the upper triangle of A, and the elements below the diagonal are destroyed.

If JOB = 'N' and COMPZ = 'I', A contains T and Z.

LDA

INTEGER. The leading dimension of the array A. LDA >= max(1,N).

W

COMPLEX*16 array, dimension (N). On exit, the computed eigenvalues are stored in the array W.

Z

COMPLEX*16 array, dimension (LDZ, N). If COMPZ = 'I', then on exit Z contains the unitary matrix Q, with the Schur vectors in the columns ILO to IHI. If COMPZ = 'N', then Z is not accessed.

LDZ

INTEGER. The leading dimension of the array Z. If COMPZ = 'I', LDZ >= max(1,N). Otherwise, LDZ is not referenced and the spec is not used.

WORK

COMPLEX*16 array, dimension (LWORK). On exit, WORK(1) contains the optimal value of LWORK.

LWORK

INTEGER. The dimension of the array WORK. LWORK >= N. For optimum performance it is suggested that LWORK >= max(1,N) + 2*max(1,IHI-ILO+1) + max(max(1,IHI-ILO+1), 64).

INFO

INTEGER. = 0: successful exit

< 0: if INFO = -i, then the i-th argument had an illegal value.

> 0: if INFO = i > 0, then the QR algorithm failed to compute all the eigenvalues. I off-diagonal elements of T remain non-zero because convergence was not achieved. However, the computed Z is a unitary matrix, and T is in the form of T = Z*T*Z‗ where T is upper quasi-triangular. The values of INFO and JOB determine the final state of Z:

If INFO > 0 and COMPZ = 'I', then on exit (final value of Z) = U

where U is the unitary matrix in (*) (regardless of the value of JOB.)

If INFO > 0 and COMPZ = 'N', then Z is not accessed.

            ILAENV(ISPEC,'ZHSEQR',JOB(:1)//COMPZ(:1),N,ILO,IHI,LWORK).
            It is suggested that these defaults be adjusted in order

            ISPEC=12: The ZLAHQR vs ZLAQR0 crossover point.
                      Default: 75. (Must be at least 11.)

            ISPEC=13: Recommended deflation window size.
                      This depends on ILO, IHI and NS.  NS is the
                      number of simultaneous shifts returned
                      by ILAENV(ISPEC=15).  (See ISPEC=15 below.)
                      The default for (IHI-ILO+1) <= 500 is NS.
                      The default for (IHI-ILO+1) >  500 is 3*NS/2.

            ISPEC=14: Nibble crossover point. (See IPARMQ for
                      details.)  Default: 14% of deflation window
                      size.

            ISPEC=15: Number of simultaneous shifts in a multishift
                      QR iteration.

                      If IHI-ILO+1 is ...
                      greater than      ...but less    ... the
                      or equal to ...      than        default is

                           1               30          NS =   2(+)
                          30               60          NS =   4(+)
                          60              150          NS =  10(+)
                         150              590          NS =  **
                         590             3000          NS =  64
                        3000             6000          NS = 128
                        6000             infinity      NS = 256

                  (+)  By default some or all matrices of this order
                       are passed to the implicit double shift routine
                       ZLAHQR and this parameter is ignored.  See
                       ISPEC=12 above and comments in IPARMQ for
                       details.
                  (**)  The asterisks (**) indicate an ad-hoc
                       function of N increasing from 10 to 64.

            ISPEC=16: Select structured matrix multiply.
                      If the number of simultaneous shifts (specified
                      by ISPEC=15) is less than 14, then the default
                      for ISPEC=16 is 0.  Otherwise the default for
                      ISPEC=16 is 2.
