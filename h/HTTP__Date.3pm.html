HTTP__Date(3pm)

الحزمة: perl-http-date

التراخيص: PerlArtistic, GPL

HTTP::Date(3) توثيق Perl من مساهمي المستخدم HTTP::Date(3)

الاسم

HTTP::Date - HTTP::Date - روتينات تحويل التاريخ

الإصدار

الإصدار 6.06

الملخص

use HTTP::Date;
$string = time2str($time);    # تنسيق كتاريخ GMT ASCII
$time = str2time($string);    # تحويل تاريخ ASCII إلى وقت الآلة

الوصف

توفر هذه الوحدة وظائف تتعامل مع تنسيقات التاريخ المستخدمة بواسطة بروتوكول HTTP (وبعضها الآخر). يتم تصدير أول وظيفتين فقط، time2str() و str2time()، افتراضيًا.

time2str( [$time] )
تقوم الوظيفة time2str() بتحويل وقت الآلة (الثواني منذ الحقبة) إلى سلسلة نصية. إذا تم استدعاء الوظيفة بدون وسيطة أو بوسيطة غير معرفة، فستستخدم الوقت الحالي.

السلسلة النصية المُرجعة هي بالتنسيق المفضل لبروتوكول HTTP. وهي مجموعة فرعية ذات طول ثابت من التنسيق المحدد بواسطة RFC 1123، ممثلة في التوقيت العالمي (GMT). مثال على طابع زمني بهذا التنسيق هو:

Sun, 06 Nov 1994 08:49:37 GMT
str2time( $str [, $zone] )
تقوم الوظيفة str2time() بتحويل سلسلة نصية إلى وقت الآلة. تقوم بإرجاع "undef" إذا كان تنسيق $str غير معروف، وإلا فإنها ترجع ما يمكن لوظائف "Time::Local" استخلاصه من الوقت المحلل. قد لا تعمل التواريخ قبل حقبة النظام على جميع أنظمة التشغيل. تنسيقات التاريخ المعترف بها هي نفسها الخاصة بـ parse_date().

تأخذ الوظيفة أيضًا وسيطة اختيارية ثانية تحدد المنطقة الزمنية الافتراضية المراد استخدامها عند تحويل التاريخ. يتم تجاهل هذه المعلمة إذا تم العثور على المنطقة الزمنية في سلسلة التاريخ نفسها. إذا كانت هذه المعلمة مفقودة، ولم يكن تنسيق سلسلة التاريخ يحتوي على أي تحديد للمنطقة الزمنية، فسيتم افتراض المنطقة الزمنية المحلية.

إذا لم تكن المنطقة الزمنية ""GMT"" أو رقمية (مثل "-0800" أو "+0100")، فيجب تثبيت وحدة "Time::Zone" للتعرف على التاريخ.

parse_date( $str )
ستحاول هذه الوظيفة تحليل سلسلة تاريخ، ثم إرجاعها كقائمة من القيم الرقمية متبوعة بمحدد منطقة زمنية (قد يكون غير معرف)؛ ($year, $month, $day, $hour, $min, $sec, $tz). سيكون $year هو العام الكامل المكون من 4 أرقام، وتبدأ أرقام $month من 1 (لشهر يناير).

في سياق قياسي، يتم استيفاء الأرقام في سلسلة نصية بتنسيق "YYYY-MM-DD hh:mm:ss TZ" ويتم إرجاعها.

إذا لم يتم التعرف على التاريخ، فسيتم إرجاع القائمة الفارغة ( "undef" في سياق قياسي).

الوظيفة قادرة على تحليل التنسيقات التالية:

"Wed, 09 Feb 1994 22:23:32 GMT"       -- تنسيق HTTP
"Thu Feb  3 17:03:55 GMT 1994"        -- تنسيق ctime(3)
"Thu Feb  3 00:00:00 1994",           -- تنسيق ANSI C asctime()
"Tuesday, 08-Feb-94 14:15:29 GMT"     -- تنسيق HTTP rfc850 قديم
"Tuesday, 08-Feb-1994 14:15:29 GMT"   -- تنسيق HTTP rfc850 معطل
"03/Feb/1994:17:03:55 -0700"   -- تنسيق ملف السجل المشترك
"09 Feb 1994 22:23:32 GMT"     -- تنسيق HTTP (بدون يوم الأسبوع)
"08-Feb-94 14:15:29 GMT"       -- تنسيق rfc850 (بدون يوم الأسبوع)
"08-Feb-1994 14:15:29 GMT"     -- تنسيق rfc850 معطل (بدون يوم الأسبوع)
"1994-02-03 14:15:29 -0100"    -- تنسيق ISO 8601
"1994-02-03 14:15:29"          -- المنطقة الزمنية اختيارية
"1994-02-03"                   -- التاريخ فقط
"1994-02-03T14:15:29"          -- استخدام T كفاصل
"19940203T141529Z"             -- تنسيق ISO 8601 المدمج
"19940203"                     -- التاريخ فقط
"08-Feb-94"         -- تنسيق HTTP rfc850 قديم (بدون يوم الأسبوع، بدون وقت)
"08-Feb-1994"       -- تنسيق HTTP rfc850 معطل (بدون يوم الأسبوع، بدون وقت)
"09 Feb 1994"       -- تنسيق HTTP جديد مقترح (بدون يوم الأسبوع، بدون وقت)
"03/Feb/1994"       -- تنسيق ملف السجل المشترك (بدون وقت، بدون إزاحة)
"Feb  3  1994"      -- تنسيق Unix 'ls -l'
"Feb  3 17:03"      -- تنسيق Unix 'ls -l'
"11-15-96  03:52PM"   -- تنسيق Windows 'dir'
"11-15-1996  03:52PM" -- تنسيق Windows 'dir' مع عام مكون من 4 أرقام

يتجاهل المحلل المسافات البيضاء البادئة واللاحقة. كما أنه يسمح بفقدان الثواني وأن يكون الشهر رقميًا في معظم التنسيقات.

إذا كان العام مفقودًا، فسيتم افتراض أن التاريخ هو أول تاريخ مطابق *قبل* الشهر الحالي. إذا تم تقديم العام برقمين فقط، فستقوم parse_date() بتحديد القرن الذي يجعل العام أقرب تاريخًا إلى التاريخ الحالي.

time2iso( [$time] )
نفس time2str()، ولكنه يرجع سلسلة نصية بتنسيق "YYYY-MM-DD hh:mm:ss" تمثل الوقت بالمنطقة الزمنية المحلية.
time2isoz( [$time] )
نفس time2str()، ولكنه يرجع سلسلة نصية بتنسيق "YYYY-MM-DD hh:mm:ssZ" تمثل التوقيت العالمي.
