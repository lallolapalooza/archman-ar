hub-init(1)

الحزمة: hub

التراخيص: MIT

hub-init(1) دليل hub hub-init(1)

الاسم

hub-init - تهيئة مستودع git وإضافة جهاز تحكم عن بعد يشير إلى GitHub.

الملخص

hub init -g

خيارات

-g

بعد تهيئة المستودع محليًا، أضف جهاز التحكم عن بعد "origin" الذي يشير إلى مستودع "USER/REPO" على GitHub.

USER هو اسم مستخدم GitHub الخاص بك، بينما REPO هو اسم الدليل الحالي.

أمثلة

$ hub init -g
> git init
> git remote add origin git@github.com:USER/REPO.git
