الاسم

hwlocality_glibc_sched - التوافق مع جدولة glibc.

الملخص

الوظائف


int hwloc_cpuset_to_glibc_sched_affinity (hwloc_topology_t topology, hwloc_const_cpuset_t hwlocset, cpu_set_t *schedset, size_t schedsetsize)
int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topology, hwloc_cpuset_t hwlocset, const cpu_set_t *schedset, size_t schedsetsize)

الوصف المفصل

توفر هذه الواجهة طرقًا للتحويل بين مجموعات وحدات المعالجة المركزية (cpusets) الخاصة بـ hwloc ومجموعات وحدات المعالجة المركزية (cpusets) الخاصة بـ glibc مثل تلك التي يتم التعامل معها بواسطة sched_getaffinity() أو pthread_attr_setaffinity_np().

ملاحظة

يجب أن تتطابق طوبولوجيا topology مع الجهاز الحالي.

توثيق الوظائف

int hwloc_cpuset_from_glibc_sched_affinity (hwloc_topology_t topology, hwloc_cpuset_t hwlocset, const cpu_set_t * schedset, size_t schedsetsize) [inline]

تحويل مجموعة تجريد جدولة glibc schedset إلى مجموعة وحدات المعالجة المركزية (cpuset) الخاصة بـ hwloc. يمكن استخدام هذه الوظيفة قبل استدعاء sched_setaffinity أو أي وظيفة أخرى تأخذ cpu_set_t كمعامل إدخال.

يجب أن يكون schedsetsize هو sizeof(cpu_set_t) ما لم يكن schedset قد تم تخصيصه ديناميكيًا باستخدام CPU_ALLOC.

يعيد

0 عند النجاح.

-1 مع تعيين errno إلى ENOMEM إذا فشل إعادة تخصيص داخلي.
