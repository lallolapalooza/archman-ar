HTTP__Lite(3pm)

الحزمة: perl-http-lite

التراخيص: GPL, PerlArtistic

cal_addr ( $ip )
حدد صراحةً عنوان IP المحلي. 0.0.0.0 (الافتراضي) يسمح للنظام بالاختيار.
local_port ( $port )
حدد صراحةً المنفذ المحلي. 0 (الافتراضي والموصى به) يسمح للنظام بالاختيار.
method ( $method )
اضبط الطريقة صراحةً. يؤدي استخدام prepare_post أو reset إلى تجاوز هذا الإعداد. الخيارات المعتادة هي GET، POST، PUT، HEAD

أمثلة

# احصل على وطباعة رؤوس ونص صفحة CPAN الرئيسية
use HTTP::Lite;
$http = HTTP::Lite->new;
$req = $http->request("http://www.cpan.org/")
    or die "Unable to get document: $!";
die "Request failed ($req): ".$http->status_message()
  if $req ne "200";
@headers = $http->headers_array();
$body = $http->body();
foreach $header (@headers)
{
  print "$header$CRLF";
}
print "$CRLF";
print "$body$CRLF";
# إرسال استعلام POST إلى محرك بحث USENET dejanews
use HTTP::Lite;
$http = HTTP::Lite->new;
%vars = (
         "QRY" => "perl",
         "ST" => "MS",
         "svcclass" => "dncurrent",
         "DBS" => "2"
        );
$http->prepare_post(\%vars);
$req = $http->request("http://www.deja.com/dnquery.xp")
  or die "Unable to get document: $!";
print "req: $req\n";
print $http->body();

غير منفذ

- FTP
- HTTPS (SSL)
- المصادقة/التفويض/مصادقة الوكيل
  غير مدعومة بشكل مباشر، وتتطلب MIME::Base64.
- عمليات إعادة التوجيه (الموقع) لا يتم اتباعها تلقائيًا
- عمليات POST متعددة الأجزاء/بيانات النموذج (multipart/form-data) غير مدعومة بشكل مباشر (ضرورية
  لتحميل الملفات).

أخطاء

ترسل بعض خوادم HTTP/1.1 المعطلة أحجام مقاطع غير صحيحة عند نقل الملفات. تم تعطيل وضع HTTP/1.1 الآن افتراضيًا.

انظر أيضاً

هذه الوحدة (HTTP::Lite) ليست بالتأكيد أفضل وحدة لاحتياجاتك.

بالنسبة لمعظم الاستخدامات، تعتبر HTTP::Tiny خيارًا جيدًا. إذا كنت بحاجة إلى ميزات إضافية، فراجع LWP.

يمكنك أيضًا قراءة هذه المراجعة لوحدات CPAN لإنشاء طلبات HTTP http://neilb.org/reviews/http-requesters.html.
