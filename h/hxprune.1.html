الحزمة: html-xml-utils

HXPRUNE(1) HTML-XML-utils HXPRUNE(1)

الاسم

hxprune - إزالة العناصر المحددة من ملف HTML

الموجز

hxprune [ -c class ] [ -x ] [ file ]

الوصف

hxprune تزيل العناصر المحددة خصيصًا (مع محتواها وعناصرها الفرعية) من ملف HTML. افتراضيًا، تزيل العناصر التي تحتوي على سمة فئة (class) بقيمة "exclude". يتم تحليل سمة الفئة كقائمة كلمات مفصولة بمسافات، وإذا كانت إحدى هذه الكلمات هي "exclude"، فلن يتم نسخ العنصر إلى المخرجات.

خيارات

الخيارات التالية مدعومة:

-c class
تحديد فئة مختلفة عن "exclude".
-x
فرض الإخراج بأسلوب XML، أي بدون سمات مختصرة ومع شرطة مائلة (/) لتمييز العناصر الفارغة.
