himalaya-folder(1)

الحزمة: himalaya

التراخيص: MIT

folder(1) دليل الأوامر العامة folder(1)

الاسم

folder - إنشاء، سرد، وتنظيف مجلداتك (المعروفة أيضًا بصناديق البريد)

ملخص

folder [-h|--help] <أوامر فرعية>

الوصف

إنشاء، سرد، وتنظيف مجلداتك (المعروفة أيضًا بصناديق البريد).

المجلد (المعروف أيضًا بصندوق البريد، أو الدليل) هو حاوية رسائل. يسمح لك هذا الأمر الفرعي بإدارتها.

خيارات

-h, --help
طباعة المساعدة (عرض ملخص باستخدام '-h')

أوامر فرعية

folder-add(1)
إنشاء المجلد المحدد
folder-list(1)
سرد جميع المجلدات
folder-expunge(1)
إفراغ المجلد المحدد
folder-purge(1)
تنظيف المجلد المحدد
folder-delete(1)
حذف المجلد المحدد
folder-help(1)
طباعة هذه الرسالة أو مساعدة الأوامر الفرعية المحددة
folder
