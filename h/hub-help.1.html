hub-help(1)

الحزمة: hub

التراخيص: MIT

hub-help(1) دليل hub hub-help(1)

اسم

hub-help - عرض صفحة المساعدة لأمر.

ملخص

hub help hub
hub help COMMAND
hub help hub-COMMAND [--plain-text]

خيارات

hub-COMMAND

استخدم هذا التنسيق لعرض المساعدة لملحقات hub لأمر git موجود.

--plain-text

تجاوز آلية البحث عن صفحة الدليل وعرض نص المساعدة الخام.
