hxwls(1)

الحزمة: html-xml-utils

التراخيص: W3C

HXWLS(1) HTML-XML-utils HXWLS(1)

الاسم

hxwls - سرد الروابط في ملف HTML

الملخص

hxwls [ -l ] [ -t ] [ -r ] [ -h ] [ -a ] [ -b أساس ] [ ملف ]

الوصف

يقوم الأمر hxwls بقراءة ملف HTML (الإدخال القياسي افتراضيًا) وطباعة جميع الروابط التي يجدها. تتم كتابة المخرجات إلى المخرج القياسي.

الخيارات

الخيارات المدعومة هي:

-l
إنتاج قائمة طويلة. بدلاً من مجرد URI، يطبع hxwls ثلاثة أعمدة: اسم العنصر، وقيمة السمة REL، و URI الهدف.
-t
إنتاج قائمة مجمعة. يطبع hxwls أربعة أعمدة: URI للمستند نفسه، واسم العنصر، وقيمة السمة REL، و URI الهدف.
-r
طباعة عناوين URL النسبية كما هي، دون تحويلها إلى عناوين URL مطلقة.
-b أساس
استخدام أساس كعنوان URL الأساسي الأولي. إذا كان هناك عنصر <base> في المستند، فإنه سيتجاوز الخيار -b.
-h
المخرجات بصيغة HTML. سيتم سرد المخرجات في شكل عناصر <a>.
-a
تحويل أي معرفات موارد دولية (IRIs) إلى عناوين URL ASCII فقط. يتسبب هذا في ترميز أي أحرف غير ASCII في مسار URI كبايتات مشفرة بنسبة مئوية وأحرف غير ASCII في اسم المجال كترميز punycode. (ترميز Punycode متاح فقط إذا تم تجميع hxwls بدعم libidn.)

المعاملات

المعامل المدعوم هو:

ملف
اسم أو عنوان URL لملف HTML. إذا غاب، يتم قراءة الإدخال القياسي بدلاً من ذلك.

التشخيص

القيم الخروج التالية يتم إرجاعها:

0
اكتمال ناجح.
> 0
حدث خطأ في تحليل ملف HTML. سيحاول hxwls تصحيح الخطأ وإنتاج مخرجات على أي حال.
