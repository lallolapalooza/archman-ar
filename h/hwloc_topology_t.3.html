الوصف التفصيلي

توثيق النوع المعرف

typedef struct hwloc_topology* hwloc_topology_t

سياق الطوبولوجيا. يجب تهيئته باستخدام hwloc_topology_init() وبنائه باستخدام hwloc_topology_load().

توثيق الدالة

int hwloc_topology_abi_check (hwloc_topology_t topology)

تحقق من توافق الطوبولوجيا مع مكتبة hwloc الحالية. هذا مفيد عند استخدام نفس بنية الطوبولوجيا (في الذاكرة) في مكتبات مختلفة قد تستخدم تثبيتات hwloc مختلفة (على سبيل المثال، إذا قامت مكتبة بتضمين إصدار معين من hwloc، بينما تستخدم مكتبة أخرى تثبيت hwloc الافتراضي على مستوى النظام).

إذا كانت جميع المكتبات/البرامج تستخدم نفس تثبيت hwloc، فإن هذه الدالة ترجع دائمًا نجاحًا.

القيمة المعادة

0 عند النجاح.

-1 مع قيمة errno المعينة إلى EINVAL إذا كانت غير متوافقة.

ملاحظة

إذا كانت المشاركة بين العمليات باستخدام hwloc_shmem_topology_write()، فإن الفحص ذي الصلة يتم بالفعل داخل hwloc_shmem_topology_adopt().

void hwloc_topology_check (hwloc_topology_t topology)

تشغيل فحوصات داخلية على بنية الطوبولوجيا. يتوقف البرنامج إذا تم اكتشاف عدم تناسق في الطوبولوجيا المقدمة.

المعلمات

topology هي الطوبولوجيا المراد فحصها

ملاحظة

هذا الإجراء مفيد للمطورين فقط.

يجب أن تكون الطوبولوجيا المدخلة قد تم تحميلها مسبقًا باستخدام hwloc_topology_load().

void hwloc_topology_destroy (hwloc_topology_t topology)

إنهاء وتحرير سياق الطوبولوجيا.

المعلمات

topology هي الطوبولوجيا المراد تحريرها

int hwloc_topology_dup (hwloc_topology_t * newtopology, hwloc_topology_t oldtopology)

مضاعفة طوبولوجيا. يتم مضاعفة بنية الطوبولوجيا بأكملها بالإضافة إلى كائناتها في بنية جديدة.

هذا مفيد للاحتفاظ بنسخة احتياطية أثناء تعديل الطوبولوجيا.

القيمة المعادة

0 عند النجاح، -1 عند الخطأ.

ملاحظة

بيانات المستخدم للكائنات (userdata) لا تتم مضاعفتها لأن hwloc لا تعرف ما تشير إليه. ستشير الكائنات في كل من الطوبولوجيا القديمة والجديدة إلى نفس بيانات المستخدم.

int hwloc_topology_init (hwloc_topology_t * topologyp)

تخصيص سياق الطوبولوجيا.

المعلمات

topologyp يتم تعيين مؤشر إلى السياق المخصص الجديد.

القيمة المعادة

0 عند النجاح، -1 عند الخطأ.

int hwloc_topology_load (hwloc_topology_t topology)

بناء الطوبولوجيا الفعلية. بناء الطوبولوجيا الفعلية بعد تهيئتها باستخدام hwloc_topology_init() وتعديلها باستخدام روتينات تكوين واستعلام اكتشاف الطوبولوجيا و تغيير مصدر اكتشاف الطوبولوجيا. لا يمكن استدعاء أي روتينات أخرى قبل ذلك باستخدام سياق الطوبولوجيا هذا.

المعلمات

topology هي الطوبولوجيا المراد تحميلها بالكائنات.

القيمة المعادة

0 عند النجاح، -1 عند الخطأ.

ملاحظة

عند الفشل، تتم إعادة تهيئة الطوبولوجيا. يجب إما تدميرها باستخدام hwloc_topology_destroy() أو تكوينها وتحميلها مرة أخرى.

يمكن استدعاء هذه الدالة مرة واحدة فقط لكل طوبولوجيا.

قد يتغير ربط الخيط أو العملية الحالية مؤقتًا أثناء هذا الاستدعاء ولكنه سيتم استعادته قبل إعادته.

انظر أيضًا

تكوين واستعلام اكتشاف الطوبولوجيا و تغيير مصدر اكتشاف الطوبولوجيا
