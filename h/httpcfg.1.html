httpcfg(1)

الحزمة: mono

التراخيص: GPL, LGPL2.1, MPL

Mono(httpcfg) Mono(httpcfg)

الاسم

httpcfg - إدارة شهادات Mono لـ HttpListener

الملخص

httpcfg [options] certificate

الوصف

تُستخدم هذه الأداة لإدارة الشهادات المستخدمة بواسطة فئة الخادم المضمن HttpListener عندما يتم تكوين HttpListener كخادم HTTPS بدلاً من خادم HTTP.

يجب عليك اختيار أحد الإجراءات الممكنة: إضافة (add)، حذف (delete)، أو قائمة (list).

عند إضافة شهادة (-add)، يجب عليك توفير المعلومات التالية: شهادة (مع العلم -cert) وملف مفتاح خاص (مع الوسيط -pvk، اسم الملف عادةً ما يكون "key") ورقم منفذ (مع العلم -port).

عند حذف شهادة (-del أو -delete) تحتاج إلى توفير رقم المنفذ.

المعلمات

-add
يضيف تركيبة شهادة/مفتاح خاص جديدة ليتم استخدامها عند منفذ معين بواسطة واجهة برمجة تطبيقات HttpListener.
-del, -delete
يحذف الشهادات المرتبطة بالمنفذ المحدد (يجب تحديده بشكل منفصل).
-list
يسرد جميع الشهادات المعروفة.
-port PORT
يحدد المنفذ لإضافة الشهادات إليه، أو إزالة الشهادات منه.
-pvk FILE
يحدد ملف المفتاح الخاص.
-cert CERT
يحدد ملف الشهادة المراد استخدامه.

أمثلة

httpcfg -add -port 8081 -pvk myfile.pvk -cert MyCert

لمزيد من التفاصيل حول إنشاء ملف الشهادة والمفتاح الخاص، راجع صفحة الويب التالية:

http://www.mono-project.com/docs/web/using-clientcertificates-with-xsp/

ملفات

يتم تخزين الشهادات في الدليل ~/.mono/httplistener
