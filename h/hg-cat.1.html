hg-cat(1)

الحزمة: mercurial

التراخيص: GPL

HG(CAT) HG(CAT)

الاسم

hg cat - إخراج الملفات الحالية أو المحددة

الملخص

hg cat [خيار]... ملف...

الوصف

اطبع الملفات المحددة كما كانت في المراجعة المعطاة. إذا لم يتم تحديد مراجعة، يتم استخدام المراجع السابق لدليل العمل.

قد يكون الإخراج إلى ملف، وفي هذه الحالة يتم إعطاء اسم الملف باستخدام سلسلة قالب. راجع hg help templates. بالإضافة إلى كلمات القالب الشائعة، يتم دعم قواعد التنسيق التالية:

%%

حرف "%" حرفي

%s

اسم الملف الأساسي الذي يتم طباعته

%d

اسم الدليل للملف الذي يتم طباعته، أو '.' إذا كان في جذر المستودع

%p

اسم المسار النسبي للجذر للملف الذي يتم طباعته

%H

تجزئة التغيير (40 رقم سداسي عشري)

%R

رقم مراجعة التغيير

%h

تجزئة التغيير المختصرة (12 رقم سداسي عشري)

%r

رقم مراجعة التغيير المضاف إليه أصفار

%b

اسم الملف الأساسي للمستودع الذي يتم تصديره

\

حرف "" حرفي

القالب:

الكلمات المفتاحية التالية مدعومة بالإضافة إلى الكلمات المفتاحية والوظائف الشائعة للقوالب. انظر أيضًا hg help templates.

data
سلسلة نصية. محتوى الملف.
path
سلسلة نصية. المسار المطلق للملف في المستودع.

يعيد 0 عند النجاح.

خيارات

-o,--output <FORMAT>
طباعة الإخراج إلى ملف بالاسم المنسق
-r,--rev <REV>
طباعة المراجعة المعطاة
--decode
تطبيق أي فلتر فك ترميز مطابق
-I,--include <PATTERN[+]>
تضمين الأسماء التي تطابق الأنماط المعطاة
-X,--exclude <PATTERN[+]>
استبعاد الأسماء التي تطابق الأنماط المعطاة
-T,--template <TEMPLATE>
عرض باستخدام القالب

[+] يمكن تحديد الخيار المشار إليه بعلامة عدة مرات
