NAME

ZSYTRS_ROOK - ZSYTRS_ROOK solves a complex system of equations

SYNOPSIS

 SUBROUTINE ZSYTRS_ROOK( UPLO, N, NRHS, A, LDA, IPIV, B, LDB, INFO )

Detailed Description

ZSYTRS_ROOK solves a system of linear equations

 A * X = B

with a complex symmetric matrix A using the factorization A = P * U * D * U**H * Q or A = P * L * D * L**H * Q computed by ZSYTRF_ROOK.

Here P and Q are permutation matrices of the same type as the matrix P in ZSYTRF_ROOK, U is a complex upper triangular matrix, L is a complex lower triangular matrix and D is a real block diagonal matrix. P, Q, U, L and D are described by the arrays A, IPIV and the argument UPLO.

Arguments

UPLO

 CHARACTER*1
 ='U': Upper triangle of A is stored and taken from the factorization.
 ='L': Lower triangle of A is stored and taken from the factorization.

N

 INTEGER
 The order of the matrix A.  N >= 0.

NRHS

 INTEGER
 The number of right hand sides, i.e., the number of columns in the
 array B. NRHS >= 0.

A

 COMPLEX*16 array, dimension (LDA,N)
 On entry, the block diagonal matrix D and the multipliers used to
 obtain the factor U or L as computed by ZSYTRF_ROOK.

LDA

 LDA is INTEGER
 The leading dimension of the array A.  LDA >= max(1,N).

IPIV

 IPIV is INTEGER array, dimension (N)
 Details of the interchanges and the block structure of D
 as determined by ZSYTRF_ROOK.

B

 COMPLEX*16 array, dimension (LDB,NRHS)
 On entry, the right hand side matrix B.
 On exit, the solution matrix X.

LDB

 LDB is INTEGER
 The leading dimension of the array B.  LDB >= max(1,N).

INFO

 INFO is INTEGER
 = 0:  successful exit
 < 0:  if INFO = -i, the i-th argument had an illegal value
