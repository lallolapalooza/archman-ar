hub-issue(1)

الحزمة: hub

التراخيص: MIT

hub-issue(1) دليل hub hub-issue(1)

الاسم

hub-issue - إدارة مشاكل GitHub للمستودع الحالي.

الملخص

hub issue [-a ASSIGNEE] [-c CREATOR] [-@ USER] [-s STATE] [-f FORMAT] [-M MILESTONE] [-l LABELS] [-d DATE] [-o SORT_KEY [-^]] [-L LIMIT]
hub issue show [-f FORMAT] NUMBER
hub issue create [-oc] [-m MESSAGE|-F FILE] [--edit] [-a USERS] [-M MILESTONE] [-l LABELS]
hub issue update NUMBER [-m MESSAGE|-F FILE] [--edit] [-a USERS] [-M MILESTONE] [-l LABELS] [-s STATE]
hub issue labels [--color]
hub issue transfer NUMBER REPO

الأوامر

بدون وسائط، اعرض قائمة بالمشاكل المفتوحة.

show

اعرض مشكلة موجودة محددة بواسطة NUMBER.

create

افتح مشكلة في المستودع الحالي.

update

حدث حقول مشكلة موجودة محددة بواسطة NUMBER. استخدم --edit لتعديل العنوان والرسالة بشكل تفاعلي في محرر النصوص.

labels

اعرض التسميات المتاحة في هذا المستودع.

transfer

انقل مشكلة إلى مستودع آخر.

الخيارات

-a, --assignee ASSIGNEE

في وضع القائمة، اعرض فقط المشاكل المعينة لـ ASSIGNEE.

-a, --assign USERS

قائمة مفصولة بفواصل من أسماء مستخدمي GitHub لتعيينها للمشكلة التي تم إنشاؤها.

-c, --creator CREATOR

اعرض فقط المشاكل التي أنشأها CREATOR.

-@, --mentioned USER

اعرض فقط المشاكل التي تذكر USER.

-s, --state STATE

اعرض المشاكل بالحالة STATE (الافتراضي: "open").

-f, --format FORMAT

اطبع محتويات المشاكل بشكل جميل باستخدام التنسيق FORMAT (الافتراضي: "%sC%>(8)%i%Creset %t% l%n"). راجع قسم "التنسيقات الجميلة" في git-log(1) للحصول على تفاصيل إضافية حول كيفية استخدام العناصر النائبة في التنسيق. العناصر النائبة المتاحة للمشاكل هي:

%I: رقم المشكلة

%i: رقم المشكلة مسبوقًا بـ "#"

%U: عنوان URL لهذه المشكلة

%S: الحالة (أي "open"، "closed")

%sC: ضبط اللون إلى الأحمر أو الأخضر، اعتمادًا على حالة المشكلة.

%t: العنوان

%l: التسميات الملونة

%L: التسميات الأولية، مفصولة بفواصل

%b: نص المشكلة

%au: اسم تسجيل الدخول للمؤلف

%as: قائمة المعينين مفصولة بفواصل

%Mn: رقم المعلم

%Mt: عنوان المعلم

%NC: عدد التعليقات

%Nc: عدد التعليقات موضوعة بين قوسين، أو سلسلة فارغة إذا كانت صفرًا.

%cD: تاريخ الإنشاء (بدون وقت)

%cr: تاريخ الإنشاء، نسبي

%ct: تاريخ الإنشاء، الطابع الزمني لـ UNIX

%cI: تاريخ الإنشاء، تنسيق ISO 8601

%uD: تاريخ التحديث (بدون وقت)

%ur: تاريخ التحديث، نسبي

%ut: تاريخ التحديث، الطابع الزمني لـ UNIX

%uI: تاريخ التحديث، تنسيق ISO 8601

%n: سطر جديد

%%: علامة % حرفية

--color[=WHEN]

تمكين الإخراج الملون حتى لو لم يكن الإخراج القياسي طرفية. WHEN يمكن أن يكون أحد الخيارات التالية: "always" (الافتراضي لـ --color)، "never"، أو "auto" (الافتراضي).

-m, --message MESSAGE

النص حتى أول سطر فارغ في MESSAGE يعتبر عنوان المشكلة، والباقي يستخدم كوصف للمشكلة بتنسيق Markdown.

عند تمرير --message متعددة، يتم ربط قيمها مع سطر فارغ بينها.

عندما لا يتم توفير --message ولا --file لـ issue create، سيتم فتح محرر نصوص لكتابة العنوان والوصف.

-F, --file FILE

اقرأ عنوان ووصف المشكلة من FILE. مرر "-" للقراءة من الإدخال القياسي بدلاً من ذلك. راجع --message لقواعد التنسيق.

-e, --edit

افتح عنوان ووصف المشكلة في محرر نصوص قبل الإرسال. يمكن استخدام هذا بالاشتراك مع --message أو --file.

-o, --browse

افتح المشكلة الجديدة في متصفح ويب.

-c, --copy

ضع عنوان URL للمشكلة الجديدة في الحافظة بدلاً من طباعتها.

-M, --milestone NAME

اعرض فقط المشاكل لمعلم GitHub بالاسم NAME.

عند فتح مشكلة، أضف هذه المشكلة إلى معلم GitHub بالاسم NAME. تمرير رقم المعلم غير مستحسن.

-l, --labels LABELS

اعرض فقط المشاكل بتسميات معينة.

عند فتح مشكلة، أضف قائمة تسميات مفصولة بفواصل إلى هذه المشكلة.

-d, --since DATE

اعرض فقط المشاكل التي تم تحديثها في أو بعد DATE بتنسيق ISO 8601.

-o, --sort KEY

فرز المشاكل المعروضة حسب "created" (الافتراضي)، "updated" أو "comments".

-^ --sort-ascending

فرز حسب التواريخ التصاعدية بدلاً من التنازلية.

-L, --limit LIMIT

اعرض أول LIMIT مشكلة فقط.

--include-pulls

تضمين طلبات السحب بالإضافة إلى المشاكل.

--color

تمكين الإخراج الملون لقائمة التسميات.
