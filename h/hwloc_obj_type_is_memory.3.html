وصف مفصل

كل نوع كائن هو إما عادي (أي أن hwloc_obj_type_is_normal() ترجع 1)، أو ذاكرة (أي أن hwloc_obj_type_is_memory() ترجع 1) أو إدخال/إخراج (أي أن hwloc_obj_type_is_io() ترجع 1) أو متنوع (أي أنه يساوي HWLOC_OBJ_MISC). لا يمكن أن يكون من أكثر من نوع واحد من هذه الأنواع.

انظر أيضًا نوع الكائن في المصطلحات والتعاريف.

توثيق الوظائف

int hwloc_obj_type_is_cache (hwloc_obj_type_t type)

تحقق مما إذا كان نوع الكائن هو ذاكرة تخزين مؤقت لوحدة المعالجة المركزية (بيانات، موحدة أو تعليمات). ذاكرة التخزين المؤقت الجانبية للذاكرة ليست ذاكرة تخزين مؤقت لوحدة المعالجة المركزية.

ترجع

1 إذا كان كائن من النوع type هو ذاكرة تخزين مؤقت، 0 خلاف ذلك.

int hwloc_obj_type_is_dcache (hwloc_obj_type_t type)

تحقق مما إذا كان نوع الكائن هو ذاكرة تخزين مؤقت للبيانات أو موحدة لوحدة المعالجة المركزية. ذاكرة التخزين المؤقت الجانبية للذاكرة ليست ذاكرة تخزين مؤقت لوحدة المعالجة المركزية.

ترجع

1 إذا كان كائن من النوع type هو ذاكرة تخزين مؤقت للبيانات أو موحدة لوحدة المعالجة المركزية، 0 خلاف ذلك.

int hwloc_obj_type_is_icache (hwloc_obj_type_t type)

تحقق مما إذا كان نوع الكائن هو ذاكرة تخزين مؤقت للتعليمات لوحدة المعالجة المركزية. ذاكرة التخزين المؤقت الجانبية للذاكرة ليست ذاكرة تخزين مؤقت لوحدة المعالجة المركزية.

ترجع

1 إذا كان كائن من النوع type هو ذاكرة تخزين مؤقت للتعليمات لوحدة المعالجة المركزية، 0 خلاف ذلك.

int hwloc_obj_type_is_io (hwloc_obj_type_t type)

تحقق مما إذا كان نوع الكائن هو إدخال/إخراج. كائنات الإدخال/الإخراج هي كائنات متصلة بآبائها في قائمة أطفال الإدخال/الإخراج. هذا يشمل حاليًا الجسور، وأجهزة PCI وأنظمة التشغيل.

ترجع

1 إذا كان كائن من النوع type هو كائن إدخال/إخراج، 0 خلاف ذلك.

int hwloc_obj_type_is_memory (hwloc_obj_type_t type)

تحقق مما إذا كان نوع الكائن هو ذاكرة. كائنات الذاكرة هي كائنات متصلة بآبائها في قائمة أطفال الذاكرة. هذا يشمل حاليًا عقد NUMA وذاكرة التخزين المؤقت الجانبية للذاكرة.

ترجع

1 إذا كان كائن من النوع type هو كائن ذاكرة، 0 خلاف ذلك.

int hwloc_obj_type_is_normal (hwloc_obj_type_t type)

تحقق مما إذا كان نوع الكائن عاديًا. الكائنات العادية هي كائنات من التسلسل الهرمي الرئيسي لوحدة المعالجة المركزية (آلة، حزمة، نواة، وحدة معالجة منطقية، ذاكرات تخزين مؤقت لوحدة المعالجة المركزية، إلخ)، ولكنها ليست عقد NUMA، أو أجهزة إدخال/إخراج، أو كائنات متنوعة.

إنها متصلة بالأصل كأطفال عاديين، وليس كأطفال ذاكرة، أو إدخال/إخراج، أو متنوعين.

ترجع

1 إذا كان كائن من النوع type هو كائن عادي، 0 خلاف ذلك.
