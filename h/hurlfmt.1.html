hurlfmt(1)

الحزمة: hurl

التراخيص: Apache-2.0

hurl(1) دليل Hurl hurl(1)

الاسم

hurlfmt - تنسيق ملفات Hurl

ملخص

hurlfmt [خيارات] [ملف...]

الوصف

hurlfmt يقوم بتنسيق ملفات Hurl وتحويلها من/إلى صيغ أخرى.

بدون ملف، اقرأ المدخل القياسي.

بشكل افتراضي، يقوم hurlfmt بإخراج نسخة منسقة وملونة من ملف hurl المدخل.


$ hurl hello.hurl
GET http://localhost:8000/hello


HTTP/1.0 200

يمكن استخدام hurlfmt للتحويل إلى صيغ أخرى.


$ hurl hello.hurl --output json | jq
{
"entries": [
{
"request": {
"method": "GET",
"url": "http://localhost:8000/hello"
},
"response": {
"version": "HTTP/1.0",
"status": 200
}
}
]
}

يمكن أيضًا استخدام hurlfmt لتحويل أمر curl إلى Hurl


$ echo "curl http://localhost:8000/custom-headers -H 'Fruit:Raspberry'" | hurlfmt --in curl
GET http://localhost:8000/custom-headers
Fruit: Raspberry

خيارات

--check

تشغيل في وضع الفحص. يخرج برمز 0 إذا كان الإدخال منسقًا بشكل صحيح، و 1 بخلاف ذلك.

لا يمكن استخدام هذا مع --output.

هذا الخيار ليس مستقرًا بعد.

--color

تلوين الإخراج.

لا يمكن استخدام هذا مع --in-place.

--in <FORMAT>

تحديد صيغة الإدخال: hurl أو curl.

--in-place

تعديل الملف في مكانه.

يمكن استخدام هذا فقط مع الإخراج النصي.

--no-color

عدم تلوين الإخراج.

--out <FORMAT>

تحديد صيغة الإخراج: hurl، json أو html.

-o, --output <FILE>

كتابة الإخراج إلى الملف بدلاً من stdout.

--standalone

إخراج ملف html كامل مع css بدلاً من جزء html (افتراضي).

يمكن استخدام هذا فقط مع إخراج html.

-h, --help

مساعدة الاستخدام.

-V, --version
