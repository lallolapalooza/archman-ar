HTML__PullParser(3pm)

الحزمة: perl-html-parser

التراخيص: PerlArtistic

HTML::PullParser(3) وثائق بيرل المساهمة من المستخدم HTML::PullParser(3)

الاسم

HTML::PullParser - واجهة بديلة لـ HTML::Parser

الملخص

use HTML::PullParser;
$p = HTML::PullParser->new(file => "index.html",
                           start => 'event, tagname, @attr',
                           end   => 'event, tagname',
                           ignore_elements => [qw(script style)],
                          ) || die "Can't open: $!";
while (my $token = $p->get_token) {
    #... do something with $token
}

الوصف

HTML::PullParser هي واجهة بديلة لفئة HTML::Parser. إنها تقلب HTML::Parser من الداخل إلى الخارج. تقوم بربط ملف (أو أي كائن IO::Handle أو سلسلة نصية) بالمحلل وقت الإنشاء ثم تستدعي بشكل متكرر $parser->get_token للحصول على العلامات والنصوص الموجودة في المستند الذي تم تحليله.

الطرق التالية متوفرة:

$p = HTML::PullParser->new( file => $file, %options )
$p = HTML::PullParser->new( doc => \$doc, %options )
يمكن جعل "HTML::PullParser" يحلل من ملف أو مستند حرفي بناءً على ما إذا كان الخيار "file" أو "doc" يتم تمريره إلى مُنشئ المحلل.

يمكن أن يكون "file" المقدم إما اسم ملف أو كائن مقبض ملف. إذا تم تمرير اسم ملف، ولم يكن من الممكن فتحه للقراءة، فسيُرجع المنشئ قيمة غير محددة وسيوضح $! سبب فشله. خلاف ذلك، يُفترض أن يكون الوسيط كائنًا يمكن لـ "HTML::PullParser" قراءته() منه عندما يحتاج إلى المزيد من البيانات. سيتم قراءة() التدفق حتى نهاية الملف (EOF)، ولكن لن يتم إغلاقه.

يمكن تمرير "doc" بشكل عادي أو كمرجع إلى قيمة نصية. إذا تم تمرير مرجع، فلا ينبغي تغيير قيمة هذه القيمة النصية قبل استخراج جميع الرموز.

بعد ذلك، يجب إعداد المعلومات التي سيتم إرجاعها لأنواع الرموز المختلفة. يتم ذلك ببساطة عن طريق ربط مواصفات الوسائط (كما هو محدد في HTML::Parser) بالأحداث التي لديك اهتمام بها. على سبيل المثال، إذا كنت تريد أن يتم الإبلاغ عن رموز "start" كسلسلة نصية 'S' متبوعة باسم العلامة والسمات، فقد تمرر خيار "start" مثل هذا:

$p = HTML::PullParser->new(
       doc   => $document_to_parse,
       start => '"S", tagname, @attr',
       end   => '"E", tagname',
     );

أخيرًا، يمكن تمرير خيارات "HTML::Parser" الأخرى، مثل "ignore_tags" و "unbroken_text". لاحظ أنه لا يجب عليك استخدام خيارات _event_h لإعداد معالجات المحلل. هذا من شأنه أن يربك المنطق الداخلي لـ "HTML::PullParser".

$token = $p->get_token
ستُرجع هذه الطريقة الرمز التالي الموجود في مستند HTML، أو "undef" في نهاية المستند. يتم إرجاع الرمز كمرجع مصفوفة. يتطابق محتوى هذه المصفوفة مع مواصفات الوسائط التي تم إعدادها أثناء إنشاء "HTML::PullParser".
$p->unget_token( @tokens )
إذا اكتشفت أنك قرأت عددًا كبيرًا جدًا من الرموز، يمكنك إعادتها، بحيث يتم إرجاعها مرة أخرى في المرة التالية التي يتم فيها استدعاء $p->get_token.

أمثلة

يعرض البرنامج النصي 'eg/hform' كيف يمكننا تحليل قسم النموذج في HTML::Documents باستخدام HTML::PullParser.
