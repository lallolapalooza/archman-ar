SYNOPSIS

#include <search.h>

int hcreate(size_t nel);

ENTRY *hsearch(ENTRY item, ACTION action, HSEARCH_FUNCPtr *fn);

void hdestroy(void);

DESCRIPTION

The hcreate function allocates a hash table with at least nel entries.

The hsearch function searches the hash table for an entry whose key matches the key of the item argument. The action argument specifies what to do if the item is found or not found.

action can be ENTER or FIND.

If action is ENTER:

  • If the item is found, the existing entry is returned.
  • If the item is not found, it is inserted into the table, and a pointer to the new entry is returned.

If action is FIND:

  • If the item is found, a pointer to the entry is returned.
  • If the item is not found, NULL is returned.

The hdestroy function deallocates the hash table created by hcreate.

The ENTRY structure is defined as:

typedef struct { char *key; void *data; } ENTRY;

RETURN VALUE

hcreate returns 1 on success, and 0 on failure (e.g., if memory allocation fails).

hsearch returns a pointer to the found entry if action is FIND and the entry is found, or if action is ENTER. It returns NULL if action is FIND and the entry is not found.

hdestroy returns nothing.

ERRORS

No specific errors are documented for these functions.

EXAMPLES

The following example demonstrates the usage of hcreate, hsearch, and hdestroy:

#include <stdio.h>
#include <search.h>

int main() {
    ENTRY e, *ep;
    hcreate(100); // Create a hash table with 100 entries

    e.key = "apple";
    e.data = (void *)1;
    ep = hsearch(e, ENTER, NULL); // Insert "apple"
    printf("Inserted key: %s, data: %ld\n", ep->key, (long)ep->data);

    e.key = "banana";
    e.data = (void *)2;
    ep = hsearch(e, ENTER, NULL); // Insert "banana"
    printf("Inserted key: %s, data: %ld\n", ep->key, (long)ep->data);

    e.key = "apple";
    ep = hsearch(e, FIND, NULL); // Find "apple"
    if (ep != NULL) {
        printf("Found key: %s, data: %ld\n", ep->key, (long)ep->data);
    } else {
        printf("Key %s not found\n", e.key);
    }

    e.key = "cherry";
    ep = hsearch(e, FIND, NULL); // Try to find "cherry"
    if (ep != NULL) {
        printf("Found key: %s, data: %ld\n", ep->key, (long)ep->data);
    } else {
        printf("Key %s not found\n", e.key);
    }

    hdestroy(); // Destroy the hash table
    return 0;
}

APPLICATION USAGE

These functions are typically used for implementing symbol tables, caches, or any situation where fast key-based lookups are required.

RATIONALE

The hash table implementation provided by these functions is a simple and efficient way to manage key-value pairs. The separation of creation, searching, and destruction functions allows for flexible management of hash table resources.

FUTURE DIRECTIONS

Considerations for future development might include:

  • Thread-safety: Making the hash table operations thread-safe.
  • Custom hash functions: Allowing users to provide their own hash functions for different data types.
  • Resizing capabilities: Implementing automatic resizing of the hash table when it becomes too full.
