HTML__FormatText(3pm)

الحزمة: perl-html-formatter

التراخيص: GPL, PerlArtistic

HTML::FormatText(3) وثائق Perl المساهمة من المستخدم HTML::FormatText(3)

الاسم

HTML::FormatText - تنسيق HTML كنص عادي

الإصدار

إصدار 2.16

الملخص

use HTML::TreeBuilder;
$tree = HTML::TreeBuilder->new->parse_file("test.html");
use HTML::FormatText;
$formatter = HTML::FormatText->new(leftmargin => 0, rightmargin => 50);
print $formatter->format($tree);

أو ببساطة أكثر:

use HTML::FormatText;
my $string = HTML::FormatText->format_file(
    'test.html',
    leftmargin => 0, rightmargin => 50
    );

الوصف

HTML::FormatText هو منسق ينتج نصًا عاديًا. يتم تجاهل جميع سمات الأحرف (غامق/مائل/تحته خط). لم يتم تطبيق تنسيق جداول HTML ونماذجها.

HTML::FormatText مبني على HTML::Formatter وتطبق وثائق تلك الوحدة على هذا - خاصة "new" في HTML::Formatter، و "format_file" في HTML::Formatter، و "format_string" في HTML::Formatter.

قد تحدد المعلمات التالية عند إنشاء المنسق:

leftmargin (اسم مستعار lm)
عمود الهامش الأيسر. القيمة الافتراضية هي 3.
rightmargin (اسم مستعار rm)
عمود الهامش الأيمن. القيمة الافتراضية هي 72.
