HWLOC_TOPOLOGY_FLAG_RESTRICT_TO_MEMBINDING(3)

الحزمة: hwloc

الاسم

hwloc_topology_set_all_types_filter, hwloc_topology_set_cache_types_filter, hwloc_topology_set_flags, hwloc_topology_set_icache_types_filter, hwloc_topology_set_io_types_filter, hwloc_topology_set_type_filter, hwloc_topology_set_userdata - تعيين خيارات طوبولوجيا hwloc

#include <hwloc.h>

الوصف

تُستخدم دوال الإعداد هذه لتهيئة الطوبولوجيا قبل تحميلها أو للتحكم في كيفية عرضها.

hwloc_topology_set_all_types_filter

تعيين الترشيح لجميع أنواع الكائنات. إذا كانت بعض الأنواع لا تدعم هذا الترشيح، فسيتم تجاهلها بصمت.

الإرجاع

0 عند النجاح، -1 عند الخطأ.

hwloc_topology_set_cache_types_filter

تعيين الترشيح لجميع أنواع كائنات ذاكرة التخزين المؤقت لوحدة المعالجة المركزية. لا يتم تضمين ذاكرات التخزين المؤقت الجانبية للذاكرة لأنها ليست ذاكرات تخزين مؤقت لوحدات المعالجة المركزية.

الإرجاع

0 عند النجاح، -1 عند الخطأ.

hwloc_topology_set_flags

تعيين علامات ORed للطوبولوجيا غير المحملة بعد. قم بتعيين مجموعة ORed من hwloc_topology_flags_e على طوبولوجيا لم يتم تحميلها بعد.

إذا تم استدعاء هذه الدالة عدة مرات، فإن الاستدعاء الأخير سيمحو ويستبدل مجموعة العلامات التي تم تعيينها سابقًا.

افتراضيًا، لا يتم تعيين أي علامات (0).

قد يتم استرداد العلامات المعينة في طوبولوجيا باستخدام hwloc_topology_get_flags().

الإرجاع

0 عند النجاح.

-1 عند الخطأ، على سبيل المثال إذا كانت العلامات غير صالحة.

hwloc_topology_set_icache_types_filter

تعيين الترشيح لجميع أنواع كائنات ذاكرة التخزين المؤقت لتعليمات وحدة المعالجة المركزية. لا يتم تضمين ذاكرات التخزين المؤقت الجانبية للذاكرة لأنها ليست ذاكرات تخزين مؤقت لوحدات المعالجة المركزية.

الإرجاع

0 عند النجاح، -1 عند الخطأ.

hwloc_topology_set_io_types_filter

تعيين الترشيح لجميع أنواع كائنات الإدخال/الإخراج.

الإرجاع

0 عند النجاح، -1 عند الخطأ.

hwloc_topology_set_type_filter

تعيين الترشيح لنوع الكائن المحدد.

الإرجاع

0 عند النجاح، -1 عند الخطأ.

hwloc_topology_set_userdata

تعيين مؤشر بيانات المستخدم الخاص بالطوبولوجيا. يمكن لكل طوبولوجيا تخزين مؤشر بيانات خاص واحد تقدمه التطبيق. يتم تهيئته إلى NULL. لن يقوم hwloc بتعديله أبدًا.

استخدمه حسب رغبتك، بعد hwloc_topology_init() وحتى hwloc_topolog_destroy().

لا يتم تصدير هذا المؤشر إلى XML.
