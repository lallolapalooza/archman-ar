hg-paths(1)

الحزمة: mercurial

التراخيص: GPL

HG(PATHS) HG(PATHS)

الاسم

hg paths - عرض الأسماء المستعارة للمستودعات البعيدة

الملخص

hg paths [الاسم]

الوصف

عرض تعريف الاسم الرمزي NAME. إذا لم يتم توفير اسم، فاعرض تعريف جميع الأسماء المتاحة.

الخيار -q/--quiet يكبت كل المخرجات عند البحث عن NAME ويعرض أسماء المسارات فقط عند سرد جميع التعريفات.

أسماء المسارات معرفة في قسم [paths] في ملف التكوين الخاص بك و في /etc/mercurial/hgrc. إذا تم التشغيل داخل مستودع، فسيتم استخدام .hg/hgrc أيضًا.

الأسماء الافتراضية للمسارات default و default-push لها معنى خاص. عند إجراء عملية دفع (push) أو سحب (pull)، يتم استخدامها كبدائل إذا لم يتم تحديد موقع في سطر الأوامر. عندما يتم تعيين default-push، فسيتم استخدامه للدفع وسيتم استخدام default للسحب؛ بخلاف ذلك، يتم استخدام default كبديل لكليهما. عند استنساخ مستودع، يتم كتابة مصدر الاستنساخ كـ default في .hg/hgrc.

ملاحظة
default و default-push ينطبقان على جميع العمليات الواردة (مثل hg incoming) والعمليات الصادرة (مثل hg outgoing، hg email و hg bundle).

انظر hg help urls لمزيد من المعلومات.

القالب:

الكلمات المفتاحية التالية مدعومة. انظر أيضًا hg help templates.

name
سلسلة نصية. الاسم الرمزي لللقب المسار.
pushurl
سلسلة نصية. عنوان URL لعمليات الدفع.
url
سلسلة نصية. عنوان URL أو مسار الدليل للعمليات الأخرى.
