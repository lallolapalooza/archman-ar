NAME

Hash::Ordered - Hash object that remembers the order of keys

VERSION

0.014

SYNOPSIS

  use Hash::Ordered;

  my $ho = Hash::Ordered->new;
  $ho->{'foo'} = 'bar';
  $ho->{'baz'} = 'qux';

  print join(" ", $ho->keys), "\n"; # foo baz
  print join(" ", $ho->values), "\n"; # bar qux
  print join(" ", $ho->items), "\n"; # foo=bar baz=qux

DESCRIPTION

Hash::Ordered is a subclass of Hash::Map that allows you to maintain the order of keys inserted into the hash.

It provides methods to retrieve keys, values, and key/value pairs in the order they were originally inserted.

METHODS

Hash::Ordered inherits all methods from Hash::Map and provides the following:

$ho->keys
Returns a list of keys in insertion order.
$ho->values
Returns a list of values in insertion order.
$ho->items
Returns a list of key/value pairs in insertion order.
$ho->first_key
Returns the first key inserted.
$ho->last_key
Returns the last key inserted.
$ho->delete_first
Deletes and returns the first key/value pair.
$ho->delete_last
Deletes and returns the last key/value pair.

OVERLOADING

Hash::Ordered supports the following operator overloads:

  • Dereferencing (%)
  • Array dereferencing (@)
  • Stringification ("")
  • Numeric conversion (0+)
  • Boolean conversion (scalar)

TIED INTERFACE

Hash::Ordered can be used as a tied hash. When tied, it behaves like a standard hash but preserves insertion order.

  use Hash::Ordered;
  my %hash;
  tie %hash, 'Hash::Ordered';

  $hash{'foo'} = 'bar';
  $hash{'baz'} = 'qux';

  print join(" ", keys %hash), "\n"; # foo baz

CAVEATS

While Hash::Ordered preserves insertion order, it does not guarantee that keys will remain in that order if they are deleted and re-inserted. However, it does guarantee that keys will be iterated in the order they were first encountered.

Performance may be slightly slower than a standard hash for very large datasets due to the overhead of maintaining order.

MOTIVATION

Sometimes, the order in which data is inserted into a hash is important. Standard Perl hashes do not guarantee key order. Hash::Ordered provides a way to have the convenience of a hash interface while retaining the insertion order of keys.
