hwlocality_linux - مساعدات خاصة بنظام لينكس

وصف تفصيلي

يشمل ذلك مساعدات لمعالجة ملفات cpumap الخاصة بنواة لينكس، ومكافئات hwloc لاستدعاءات النظام Linux sched_setaffinity و sched_getaffinity.

توثيق الوظيفة

int hwloc_linux_get_tid_cpubind (hwloc_topology_t topology, pid_t tid, hwloc_cpuset_t set)

الحصول على الربط الحالي للخيط tid. يتم ملء مجموعة وحدات المعالجة المركزية set (التي خصصها المستدعي مسبقًا) بقائمة وحدات المعالجة التي تم ربط الخيط بها آخر مرة.

السلوك مطابق تمامًا لاستدعاء النظام Linux sched_getaffinity، ولكنه يستخدم مجموعة وحدات معالجة مركزية hwloc.

المرتجعات

0 عند النجاح، -1 عند حدوث خطأ.

ملاحظة

هذا يعادل استدعاء hwloc_get_proc_cpubind() مع HWLOC_CPUBIND_THREAD كعلامات.

int hwloc_linux_get_tid_last_cpu_location (hwloc_topology_t topology, pid_t tid, hwloc_bitmap_t set)

الحصول على وحدة المعالجة المركزية الفعلية الأخيرة التي عمل عليها الخيط tid. يتم ملء مجموعة وحدات المعالجة المركزية set (التي خصصها المستدعي مسبقًا) بوحدة المعالجة المركزية التي عمل عليها الخيط آخر مرة.

المرتجعات

0 عند النجاح، -1 عند حدوث خطأ.

ملاحظة

هذا يعادل استدعاء hwloc_get_proc_last_cpu_location() مع HWLOC_CPUBIND_THREAD كعلامات.

int hwloc_linux_read_path_as_cpumask (const char * path, hwloc_bitmap_t set)

تحويل مسار ملف cpumask الخاص بنواة لينكس إلى مجموعة hwloc bitmap set. قد يتم استخدامه عند قراءة مجموعة وحدات المعالجة المركزية من سمات sysfs مثل topology و caches للمعالجات، أو local_cpus للأجهزة.

المرتجعات

0 عند النجاح، -1 عند حدوث خطأ.

ملاحظة

تتجاهل هذه الوظيفة متغير البيئة HWLOC_FSROOT.

int hwloc_linux_set_tid_cpubind (hwloc_topology_t topology, pid_t tid, hwloc_const_cpuset_t set)

ربط خيط tid بوحدات المعالجة المركزية المحددة في المجموعة set. السلوك مطابق تمامًا لاستدعاء النظام Linux sched_setaffinity، ولكنه يستخدم مجموعة hwloc.

المرتجعات

0 عند النجاح، -1 عند حدوث خطأ.

ملاحظة

هذا يعادل استدعاء hwloc_set_proc_cpubind() مع HWLOC_CPUBIND_THREAD كعلامات.
