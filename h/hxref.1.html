hxref(1)

الحزمة: html-xml-utils

التراخيص: W3C

HXREF(1) HTML-XML-utils HXREF(1)

الاسم

hxref - إنشاء روابط متقاطعة داخل وبين ملفات HTML

الملخص

hxref [ -x ] [ -l ] [ -b base ] [ -i index ] [ -- ] [ input [ output ] ]

الوصف

يقوم الأمر hxref بربط العناصر المضمنة بعناصر DFN ذات المحتوى نفسه. يقوم بإضافة سمات ID عند الضرورة. إذا لم يكن محتوى DFN أو عنصر آخر مناسبًا، يمكن استخدام السمة TITLE لتوفير المصطلح المراد استخدامه للمقارنات.

هذا مثال:


<p>A <dfn>b-box</dfn> is defined to be...
<p>For every b there is a <em>b-box</em>...

سيكون ناتج hxref مشابهًا لهذا:


<p>A <dfn id="b-box">b-box</dfn> is defined to be...
<p>For every b there is a <a href="#b-box"><em>b-box</em></a>...

خيارات

الخيارات التالية مدعومة:

-x
استخدم اصطلاحات XML: العناصر الفارغة تُكتب مع شرطة مائلة في النهاية: <IMG />
-b base
يحدد البادئة لمعرفات URL التي تم إنشاؤها. افتراضيًا، base فارغة، مما يؤدي إلى إنشاء معرفات URL مثل "#b-box" أعلاه. إذا تم تعيين base إلى، على سبيل المثال، "http://xyz/"، ستبدو معرفات URL مثل "http://xyz/#b-box".
-i index
يوجه hxref لقراءة المصطلحات من ملف قاعدة بيانات قبل البحث عنها في المستند، وبعد ذلك يخزن المصطلحات التي تم العثور عليها في نفس الملف. عناصر DFN في المستند لها الأولوية على المصطلحات الموجودة في index. هذا يسمح بتشغيل hxref عدة مرات على ملفات مختلفة، لجعل الملفات تشير إلى بعضها البعض. قد يكون من الضروري تشغيل الأوامر مرتين، لحل جميع الروابط المتقاطعة.
-l
حاول استخدام معلومات خاصة باللغة لمطابقة المثيلات مع تعريفاتها. حاليًا، اللغة الإنجليزية فقط مدعومة والقواعد الوحيدة المطبقة هي البحث بدون "s" نهائية ("trees" تطابق "tree")، بدون "es" نهائية ("bosses" تطابق "boss") ومع "y" بدلاً من "ies" نهائية ("bounties" تطابق "bounty"). يحدد hxref اللغة من سمات "lang" و "xml:lang" في المستند.

العوامل التشغيلية

العوامل التشغيلية التالية مدعومة:

input
اسم ملف HTML. إذا كان غائبًا، يتم قراءة الإدخال القياسي بدلاً من ذلك. الاسم الخاص "-" يشير أيضًا إلى الإدخال القياسي. يمكن أن يكون input معرف URL.
output
الملف المراد الكتابة إليه. إذا كان غائبًا، يتم استخدام الإخراج القياسي. لا يمكن أن يكون هذا معرف URL.

التشخيص

قيم الخروج التالية يتم إرجاعها:

0
اكتمال ناجح.
> 0
حدث خطأ في تحليل ملف HTML. سيحاول hxref تصحيح الخطأ وإنتاج مخرجات على أي حال.

الأخطاء

استعادة الخطأ لـ HTML غير الصحيح بدائية.

يقوم البرنامج بإنشاء سمات ID، لكنه لا ينشئ علامات <a name=...>، لذا فإن الروابط تعمل فقط في المتصفحات التي تتعرف على سمات ID.

قواعد مطابقة صيغ الجمع الإنجليزية بدائية. لا يتم استخدام قاموس. على سبيل المثال، سيتم اعتبار "bees" جمعًا لـ "be".

لا توجد حاليًا طريقة لتعيين اللغة الافتراضية للمستند عندما لا تحتوي العنصر الجذر على سمة "lang" أو "xml:lang".

يحاول hxref أولاً إنشاء سمات ID "قابلة للقراءة"، عن طريق تشكيل ID من الأحرف والأرقام الموجودة في محتوى العنصر، ويتراجع إلى إنشاء معرفات عشوائية إذا لم يعثر على ما يكفي. ومع ذلك، فإن الخوارزمية في هذا الإصدار بدائية وتعطي نتائج معقولة فقط للأحرف والأرقام ASCII.
