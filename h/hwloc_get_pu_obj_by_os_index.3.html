NAME

hwloc_get_pu_obj_by_os_index - get PU object by OS index

SYNOPSIS

#include <hwloc.h>

    hwloc_obj_t hwloc_get_pu_obj_by_os_index(const hwloc_topology_t topology, unsigned os_index);

Detailed Description

Returns the object of type HWLOC_OBJ_PU with os_index. This function is useful for converting a CPU set into the PU objects it contains. When retrieving the current binding (e.g. with hwloc_get_cpubind()), one may iterate over the bits of the resulting CPU set with hwloc_bitmap_foreach_begin(), and find the corresponding PUs with this function.

Returns

the PU object, or NULL if none matches.

NAME

hwloc_get_pu_obj_by_os_index - الحصول على كائن PU حسب فهرس النظام

SYNOPSIS

#include <hwloc.h>

    hwloc_obj_t hwloc_get_pu_obj_by_os_index(const hwloc_topology_t topology, unsigned os_index);

Detailed_Description

يُرجع الكائن من النوع HWLOC_OBJ_PU الذي له فهرس النظام os_index. هذه الدالة مفيدة لتحويل مجموعة وحدات المعالجة المركزية إلى كائنات PU التي تحتوي عليها. عند استرداد الربط الحالي (على سبيل المثال، باستخدام hwloc_get_cpubind())، قد يقوم المرء بالتكرار فوق بتات مجموعة وحدات المعالجة المركزية الناتجة باستخدام hwloc_bitmap_foreach_begin()، والعثور على كائنات PU المقابلة باستخدام هذه الدالة.

Returns

كائن PU، أو NULL إذا لم يتطابق أي شيء.
