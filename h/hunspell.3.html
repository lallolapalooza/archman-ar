hunspell - تدقيق إملائي، وتحديد الجذر، وتوليد وتحليل صرفي

الوصف

توفر روتينات مكتبة Hunspell للمستخدم وظائف لغوية على مستوى الكلمات: التدقيق الإملائي والتصحيح، وتحديد الجذر، والتوليد والتحليل الصرفي بأسلوب العناصر والترتيب.

يحتوي رأس C الاختياري على واجهة C لمكتبة C++ مع مُنشئ ومُدمّر Hunspell_create و Hunspell_destroy، ومعلمة HunHandle إضافية (الكائن المخصص) في دوال التغليف (انظر في ملف رأس C hunspell.h).

يمكن استخدام وظائف التدقيق الإملائي الأساسية، spell() و suggest()، لتحديد الجذر، والتوليد الصرفي، والتحليل بواسطة نصوص إدخال XML (انظر واجهة برمجة تطبيقات XML).

المُنشئ والمُدمّر

يحتاج مُنشئ Hunspell إلى مسارات ملفات الملحق والقاموس. (في بيئة WIN32، استخدم المسارات المشفرة بنظام UTF-8 التي تبدأ بالبادئة الطويلة للمسار \\?\ للتعامل مع ترميز الأحرف المستقل عن النظام وأسماء المسارات الطويلة جدًا.) انظر صفحة الدليل hunspell(4) لتنسيق القاموس. المعلمة key الاختيارية مخصصة للقواميس المشفرة بواسطة أداة hzip لتوزيع Hunspell.

القواميس الإضافية

تقوم الدالة add_dic() بتحميل ملف قاموس إضافي. تستخدم القواميس الإضافية ملف الملحق لكائن Hunspell المخصص. الحد الأقصى لعدد القواميس الإضافية محدود في الكود المصدري (20).

التدقيق الإملائي والتصحيح

ترجع الدالة spell() قيمة غير صفرية، إذا تم التعرف على الكلمة المدخلة بواسطة المدقق الإملائي، وقيمة صفر إذا لم يتم ذلك. ترجع المتغيرات المرجعية الاختيارية مصفوفة بت (info) والكلمة الجذرية للكلمة المدخلة. تشير بتات المعلومات التي يتم فحصها باستخدام وحدات الماكرو SPELL_COMPOUND، SPELL_FORBIDDEN أو SPELL_WARN إلى الكلمات المركبة، والكلمات المحظورة صراحة، والكلمات التي يحتمل أن تكون سيئة. من الإصدار 1.3، القيمة المرجعة غير الصفرية هي 2 للكلمات في القاموس التي تحمل علامة "WARN" (الكلمات التي يحتمل أن تكون سيئة).

تحتوي الدالة suggest() على معلمتين للإدخال، متغير مرجعي لقائمة الاقتراحات الناتجة، وكلمة مدخلة. ترجع الدالة عدد الاقتراحات. سيحتوي المتغير المرجعي على عنوان قائمة الاقتراحات المخصصة حديثًا أو NULL، إذا كانت قيمة suggest() صفرًا. الحد الأقصى لعدد الاقتراحات محدود في الكود المصدري.

يمكن لـ spell() و suggest() التعرف على إدخال XML، انظر قسم واجهة برمجة تطبيقات XML.

الوظائف الصرفية

الدوال البسيطة stem() و analyze() مشابهة لـ suggest()، ولكن بدلاً من الاقتراحات، ترجع جذور الكلمات ونتائج التحليل الصرفي. تنتظر الدالة البسيطة generate() كلمة ثانية أيضًا. ستكون هذه الكلمة الإضافية وملحقها نموذجًا للتوليد الصرفي للأشكال المطلوبة للكلمة الأولى.

تستخدم دوال stem() و generate() الموسعة نتائج التحليل الصرفي:

char ** result, result2;
int n1 = analyze(&result, "words");
int n2 = stem(&result2, result, n1);

التعليق الصرفي لمكتبة Hunspell له معرفات حقول ثابتة (حرفان و نقطتين)، انظر صفحة الدليل hunspell(4).

char ** result;
char * affix = "is:plural"; // description depends from dictionaries, too
int n = generate(&result, "word", &affix, 1);
for (int i = 0; i < n; i++) printf("%s\n", result[i]);

تخصيص الذاكرة

تحرر الدالة free_list() الذاكرة التي خصصتها دوال suggest() و analyze و generate و stem().

وظائف أخرى

الدوال add() و add_with_affix() و remove() هي دوال مساعدة لتنفيذ قاموس شخصي لإضافة وإزالة الكلمات من القاموس الأساسي أثناء التشغيل. تستخدم add_with_affix() كلمة جذرية ثانية كنموذج للملحقات والتركيب الممكن للكلمة الجديدة.

ترجع الدالة get_dic_encoding() "ISO8859-1" أو ترميز الأحرف المحدد في ملف الملحق باستخدام الكلمة المفتاحية "SET".

ترجع الدالة get_csconv() جدول حالة الأحرف ذي 8 بتات لترميز القاموس.

ترجع الدالتان get_wordchars() و get_wordchars_utf16() أحرف الكلمات الإضافية المحددة في ملف الملحق للتقطيع بواسطة الكلمة المفتاحية "WORDCHARS".

ترجع الدالة get_version() سلسلة إصدار المكتبة.

واجهة برمجة تطبيقات XML

ترجع الدالة spell() قيمة غير صفرية للإدخال "<؟xml؟>" مما يشير إلى دعم واجهة برمجة تطبيقات XML.

تقوم الدالة suggest() بتحديد الجذر، وتحليل، وتوليد أشكال الكلمة المدخلة، إذا تم إضافتها باستخدام أحد بناء الجملة "SPELLML" التالية:

<?xml?>
<query type="analyze">
<word>dogs</word>
</query>
<?xml?>
<query type="stem">
<word>dogs</word>
</query>
<?xml?>
<query type="generate">
<word>dog</word>
<word>cats</word>
</query>
<?xml?>
<query type="generate">
<word>dog</word>
<code><a>is:pl</a><a>is:poss</a></code>
</query>
<?xml?>
<query type="add">
<word>word</word>
</query>
<?xml?>
<query type="add">
<word>word</word>
<word>model_word_for_affixation_and_compounding</word>
</query>

نتائج استعلام type="stem" والدالة المكتبية stem() هي نفسها. نتيجة استعلام type="analyze" هي سلسلة تحتوي على عنصر <code><a>result1</a><a>result2</a>...</code>. يمكن استخدام هذا العنصر في بناء الجملة الثاني لاستعلام type="generate".
