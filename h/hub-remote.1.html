hub-remote(1)

الحزمة: hub

التراخيص: MIT

hub-remote(1) دليل hub hub-remote(1)

الاسم

hub-remote - إضافة بعيد git لمستودع GitHub.

الاستخدام

hub remote add [-p] [خيارات] USER[/REPOSITORY]
hub remote set-url [-p] [خيارات] NAME USER[/REPOSITORY]

خيارات

-p

(مهمل) استخدم بروتوكول ssh: بدلاً من git: لعنوان URL البعيد. يتم استخدام بروتوكول ssh: القابل للكتابة تلقائيًا للمستودعات الخاصة بك، ومستودعات GitHub Enterprise، والمستودعات الخاصة أو القابلة للدفع.

USER[/REPOSITORY]

إذا كان USER هو "origin"، فسيتم استبدال هذه القيمة باسم مستخدم GitHub الخاص بك. REPOSITORY افتراضيًا هو اسم الدليل الحالي.

أمثلة

$ hub remote add jingweno
> git remote add jingweno git://github.com/jingweno/REPO.git
$ hub remote add origin
> git remote add origin git@github.com:USER/REPO.git
