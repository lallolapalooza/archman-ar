الحزمة: jose

JOSE-B64-DEC(1)   JOSE-B64-DEC(1)

الاسم

jose-b64-dec - يفك ترميز بيانات Base64 الآمنة لـ URL إلى ثنائي

الملخص

jose b64 dec -i B64 [-O BIN]

نظرة عامة

يقوم الأمر jose b64 dec بفك ترميز بيانات Base64 الآمنة لـ URL إلى تنسيق ثنائي.

خيارات

•-i FILE, --base64=FILE : اقرأ بيانات Base64 (آمنة لـ URL) من FILE
•-i -, --base64=- : اقرأ بيانات Base64 (آمنة لـ URL) من الإدخال القياسي
•-O FILE, --binary=FILE : اكتب البيانات الثنائية إلى FILE
•-O -, --binary=- : اكتب البيانات الثنائية إلى الإخراج القياسي

أمثلة

فك ترميز رسالة بسيطة:

$ echo SGVsbG8sIFdvcmxkCg | jose b64 dec -i-
Hello, World
