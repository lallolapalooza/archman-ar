JRUNSCRIPT(1) JDK Commands JRUNSCRIPT(1)

NAME

jrunscript - تشغيل واجهة نصية سطر أوامر تدعم الأوضاع التفاعلية والدفعية

SYNOPSIS

ملاحظة:

هذه الأداة تجريبية وغير مدعومة.

jrunscript [خيارات] [وسائط]

خيارات
تمثل هذه خيارات سطر الأوامر لـ jrunscript التي يمكن استخدامها. راجع خيارات لـ أمر jrunscript.
وسائط
تأتي الوسائط، عند استخدامها، مباشرة بعد الخيارات أو اسم الأمر. راجع الوسائط.

DESCRIPTION

الأمر jrunscript هو واجهة نصية سطر أوامر مستقلة عن اللغة. يدعم الأمر jrunscript كلاً من الوضع التفاعلي (قراءة-تقييم-طباعة) ووضع الدفعات (خيار -f) لتنفيذ النصوص البرمجية. افتراضيًا، JavaScript هي اللغة المستخدمة، ولكن يمكن استخدام الخيار -l لتحديد لغة مختلفة. من خلال استخدام Java للتواصل مع لغة البرمجة النصية، يدعم الأمر jrunscript أسلوب البرمجة الاستكشافية.

إذا تم استخدام JavaScript، فقبل أن يقوم بتقييم نص برمجي محدد بواسطة المستخدم، يقوم الأمر jrunscript بتهيئة دوال وأشياء مضمنة معينة، والتي توثق في مواصفات API لـ دوال JavaScript المضمنة في jrunscript.

OPTIONS FOR THE JRUNSCRIPT COMMAND

-cp مسار أو -classpath مسار
يشير إلى مكان وجود أي ملفات فئة يحتاج النص البرمجي إلى الوصول إليها.
-Dاسم=قيمة
يضبط خاصية نظام Java.
-Jعلامة
يمرر علامة مباشرة إلى آلة Java الافتراضية التي يعمل عليها الأمر jrunscript.
-l لغة
يستخدم لغة البرمجة النصية المحددة. افتراضيًا، يتم استخدام JavaScript. لاستخدام لغات برمجة نصية أخرى، يجب عليك تحديد ملف JAR الخاص بمحرك البرمجة النصية المقابل باستخدام الخيار -cp أو -classpath.
-e نص برمجي
يقوم بتقييم النص البرمجي المحدد. يمكن استخدام هذا الخيار لتشغيل نصوص برمجية من سطر واحد محددة بالكامل على سطر الأوامر.
-encoding ترميز
يحدد ترميز الأحرف المستخدم لقراءة ملفات النصوص البرمجية.
-f ملف-نص-برمجي
يقوم بتقييم ملف النص البرمجي المحدد (وضع الدفعات).
-f -
يدخل الوضع التفاعلي لقراءة وتقييم نص برمجي من المدخل القياسي.
-help أو -?
يعرض رسالة مساعدة ويخرج.
-q
يسرد جميع محركات البرمجة النصية المتاحة ويخرج.

ARGUMENTS

إذا كانت الوسائط موجودة ولم يتم استخدام خيار -e أو -f، فإن الوسيط الأول هو ملف النص البرمجي والباقي من الوسائط، إن وجدت، يتم تمريرها كوسائط للنص البرمجي. إذا تم استخدام الوسائط مع الخيار -e أو -f، فسيتم تمرير جميع الوسائط كوسائط للنص البرمجي. إذا كانت الوسائط -e و -f مفقودة، فسيتم استخدام الوضع التفاعلي.

EXAMPLE OF EXECUTING INLINE SCRIPTS

jrunscript -e "print('hello world')"

jrunscript -e "cat('http://www.example.com')"

EXAMPLE OF USING SPECIFIED LANGUAGE AND EVALUATE THE SCRIPT FILE

jrunscript -l js -f test.js

EXAMPLE OF INTERACTIVE MODE


jrunscript
js> print('Hello World\n');
Hello World
js> 34 + 55
89.0
js> t = new java.lang.Thread(function() { print('Hello World\n'); })
Thread[Thread-0,5,main]
js> t.start()
js> Hello World
js>

RUN SCRIPT FILE WITH SCRIPT ARGUMENTS

في هذا المثال، ملف test.js هو ملف النص البرمجي. يتم تمرير الوسائط arg1 و arg2 و arg3 إلى النص البرمجي. يمكن للنص البرمجي الوصول إلى هذه الوسائط باستخدام مصفوفة وسائط.

jrunscript test.js arg1 arg2 arg3
