JLN(JLN)

الحزمة: judy

التراخيص: LGPL

JudyL(3) دليل وظائف المكتبة JudyL(3)

الاسم

وحدات JudyL - مكتبة C لإنشاء والوصول إلى مصفوفة ديناميكية من الكلمات، باستخدام كلمة كفهرس.

الملخص

cc [flags] sourcefiles -lJudy
#include <Judy.h>
int      Rc_int;                          // رمز الإرجاع - عدد صحيح
Word_t   Rc_word;                         // رمز الإرجاع - كلمة غير موقّعة
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // مؤشر إلى القيمة المرجعة
Pvoid_t PJLArray = (Pvoid_t) NULL;        // تهيئة مصفوفة JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

الوصف

مصفوفة JudyL هي المكافئ لمصفوفة من القيم بحجم كلمة. يتم عنونة القيمة بواسطة الفهرس (المفتاح). قد تكون المصفوفة متفرقة، وقد يكون الفهرس أي رقم بحجم كلمة. يتم تخصيص الذاكرة لدعم المصفوفة عند إدراج أزواج الفهرس/القيمة، ويتم تحريرها عند حذف أزواج الفهرس/القيمة. يمكن أيضًا اعتبار مصفوفة JudyL كـ "mapper"، أي "ربط" كلمة بكلمة/مؤشر آخر.

كما هو الحال مع المصفوفة العادية، لا توجد فهارس مكررة في مصفوفة JudyL.

يمكن استخدام القيمة كقيمة قياسية، أو مؤشر إلى هيكل أو كتلة بيانات (أو حتى مصفوفة Judy أخرى).

يتم تخصيص مصفوفة JudyL باستخدام مؤشر NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

باستخدام الوحدات الموضحة هنا، بدلاً من استدعاءات وظائف JudyL، يرسل التعامل مع الأخطاء الافتراضي رسالة إلى الخطأ القياسي وينهي البرنامج بـ exit(1);. للحصول على طرق أخرى للتعامل مع الأخطاء، راجع قسم الأخطاء. JLI( PValue, PJLArray, Index); // JudyLIns()

نظرًا لأن أشكال الوحدات تكون أحيانًا أسرع ولها واجهة تعامل مع الأخطاء أبسط من وظائف JudyL المكافئة، فهي الطريقة المفضلة لاستدعاء وظائف JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
أدخل الفهرس والقيمة في مصفوفة JudyL المسماة PJLArray. إذا تم إدراج الفهرس بنجاح، يتم تهيئة القيمة إلى 0. إذا كان الفهرس موجودًا بالفعل، فلن يتم تعديل القيمة.
إرجاع PValue يشير إلى القيمة. يمكن لبرنامجك استخدام هذا المؤشر لقراءة أو تعديل القيمة حتى يتم تنفيذ JLI() (إدراج) أو JLD() (حذف) أو JLFA() (تحرير المصفوفة) أخرى على PJLArray. أمثلة:
*PValue = 1234;
Value = *PValue;
إرجاع PValue تم ضبطه على PJERR إذا فشل malloc(). ملاحظة: JLI() و JLD() يعيدان تنظيم مصفوفة JudyL. لذلك، تصبح PValue التي تم إرجاعها من استدعاءات JudyL السابقة غير صالحة ويجب إعادة الحصول عليها.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
حذف زوج الفهرس / القيمة من مصفوفة JudyL.
إرجاع Rc_int مضبوطًا على 1 إذا نجحت العملية. إرجاع Rc_int مضبوطًا على 0 إذا لم يكن الفهرس موجودًا. إرجاع Rc_int مضبوطًا على JERR إذا فشل malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
الحصول على المؤشر PValue المرتبط بـ الفهرس في مصفوفة Judy المسماة PJLArray.
إرجاع PValue يشير إلى القيمة. إرجاع PValue مضبوطًا على NULL إذا لم يكن الفهرس موجودًا. إرجاع PValue مضبوطًا على PJERR إذا فشل malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
عد عدد الفهارس الموجودة في مصفوفة JudyL المسماة PJLArray بين Index1 و Index2 (شاملة).
إرجاع Rc_word مضبوطًا على العدد. يمكن أن تكون القيمة المرجعة 0 صالحة كعدد.
لعد جميع الفهارس الموجودة في مصفوفة JudyL، استخدم:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
تحديد Nth فهرس موجود في مصفوفة JudyL المسماة PJLArray (Nth = 1 يعيد أول فهرس موجود).
إرجاع PValue يشير إلى قيمته و Index مضبوطًا على Nth فهرس إذا تم العثور عليه، وإلا إرجاع PValue مضبوطًا على NULL (قيمة Index غير محددة).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
بالنظر إلى مؤشر إلى مصفوفة JudyL، قم بتحرير المصفوفة بأكملها (أسرع بكثير من استخدام حلقة JLN()، JLD()).
إرجاع Rc_word مضبوطًا على عدد البايتات التي تم تحريرها و PJLArray مضبوطًا على NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
إرجاع Rc_word مضبوطًا على عدد بايتات الذاكرة التي تم malloc()'ed بواسطة PJLArray. هذه روتينية سريعة جدًا، ويمكن استخدامها قبل وبعد استدعاء JLI() أو JLD() مع تأثير أداء ضئيل.

وظائف بحث JudyL
تسمح لك JLF()، JLN()، JLL()، JLP() بالبحث عن فهارس في المصفوفة. يمكنك البحث بشكل شامل أو حصري، في كلا الاتجاهين الأمامي أو العكسي. إذا نجحت العملية، يتم إرجاع Index مضبوطًا على الفهرس الموجود، ويتم إرجاع PValue مضبوطًا على مؤشر إلى القيمة الخاصة بـ Index. إذا فشلت العملية، يتم إرجاع PValue مضبوطًا على NULL، ولا يحتوي Index على معلومات مفيدة. يجب اختبار PValue للتأكد من أنه غير NULL قبل استخدام Index، حيث أن فشل البحث ممكن.
تسمح لك JLFE()، JLNE()، JLLE()، JLPE() بالبحث عن فهارس غير موجودة ("فارغة") في المصفوفة. يمكنك البحث بشكل شامل أو حصري، في كلا الاتجاهين الأمامي أو العكسي. إذا نجحت العملية، يتم إرجاع Index مضبوطًا على فهرس غير موجود ("فارغ")، ويتم إرجاع Rc_int مضبوطًا على 1. إذا فشلت العملية، يتم إرجاع Rc_int مضبوطًا على 0، ولا يحتوي Index على معلومات مفيدة. يجب التحقق من Rc_int قبل استخدام Index، حيث أن فشل البحث ممكن.

JLF(PValue, PJLArray, Index) // JudyLFirst()
البحث (شامل) عن أول فهرس موجود يساوي أو أكبر من الفهرس المُمرر. (ابدأ بـ Index = 0 للعثور على أول فهرس في المصفوفة.) عادةً ما تُستخدم JLF() لبدء مسح بترتيب أبجدي للفهارس الموجودة في مصفوفة JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
البحث (حصري) عن الفهرس التالي الموجود الذي يكون أكبر من الفهرس المُمرر. عادةً ما تُستخدم JLN() للمتابعة مسح بترتيب أبجدي للفهارس الموجودة في مصفوفة JudyL، أو لتحديد "جوار" لفهرس معين.
