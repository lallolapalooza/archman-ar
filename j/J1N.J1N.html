Nota: Sin definir 'JUDYERROR_NOTEST', el 'goto out_of_memory_handling' nunca se ejecutará y se optimizará el compilador. El método por defecto se utilizará — la macro imprimirá información de error si ocurre un error, como se explica arriba.

Con 'JUDYERROR_NOTEST' definida, el 'goto out_of_memory_handling' se ejecutará cuando un error ocurra — lo cual debería suceder solo cuando se deje el 'malloc()'.

3) Método de la macro JUDYERROR () especificado por el usuario

La macro JUDYERROR () (en Judy.h) proporciona flexibilidad para manejar retornos de error según las necesidades de su programa, aún cuando se utilice las macros Judy en lugar de llamadas de función. Puede utilizar una macro diferente JUDYERROR () según sus necesidades. El siguiente ejemplo es una alternativa posible al método por defecto. Se usa para distinguir entre los dos tipos de errores (descriptos arriba) y explicitamente testear los errores restantes JU_ERRNO_NOMEM posibles en su programa.

// Este es un ejemplo de la API de macros Judy para continuar cuando hay memoria insuficiente y imprimir y salir(1) cuando cualquier otro error ocurra.
#ifndef JUDYERROR_NOTEST
#include <stdio.h>  // necesario para fprintf()
// Este es la macro que las APIs de macros Judy usan para los códigos de retorno -1:
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    if ((JudyErrno) != JU_ERRNO_NOMEM) /* ! un fallo de malloc() */         \
    {                                                                     \
        (void) fprintf(stderr, "Archivo '%s', línea %d: %s(), "               \
            "JU_ERRNO_* == %d, ID == %d\n",                               \
            CallerFile, CallerLine,                                       \
            JudyFunc, JudyErrno, JudyErrID);                              \
        exit(1);                                                          \
    }                                                                     \
}
#endif // JUDYERROR_NOTEST no definido
Esta macro de manejo de errores debe incluirse antes del enunciado #include <Judy.h> en su programa.
