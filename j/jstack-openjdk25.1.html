jstack-openjdk25(1)

الحزمة: jdk-openjdk

التراخيص: LicenseRef-Java

JSTACK(1) أوامر JDK JSTACK(1)

الاسم

jstack - طباعة تتبعات المكدس لـ Java للخيوط (threads) لعملية Java محددة

الملخص

ملاحظة: هذا الأمر تجريبي وغير مدعوم.

jstack [خيارات] pid

خيارات
يمثل هذا خيارات سطر الأوامر لـ jstack. انظر خيارات أمر jstack.
pid
معرف العملية (process ID) الذي تتم طباعة تتبع المكدس له. يجب أن تكون العملية عملية Java. للحصول على قائمة بعمليات Java قيد التشغيل على جهاز، استخدم إما الأمر ps أو، إذا كانت عمليات JVM لا تعمل في مثيل docker منفصل، الأمر jps.

الوصف

يقوم الأمر jstack بطباعة تتبعات المكدس لـ Java للخيوط (threads) لعملية Java محددة. لكل إطار Java، يتم طباعة اسم الفئة الكامل، اسم الطريقة، فهرس البايت كود (BCI)، ورقم السطر، عند توفرها. لا يتم فك ترميز أسماء C++ المشوشة. لفك ترميز أسماء C++، يمكن توجيه إخراج هذا الأمر إلى c++filt. عندما تعمل العملية المحددة على JVM 64 بت، قد تحتاج إلى تحديد الخيار -J-d64، على سبيل المثال: jstack -J-d64 pid.

ملاحظة:

هذا الأمر غير مدعوم وقد لا يكون متاحًا في الإصدارات المستقبلية من JDK. في أنظمة Windows حيث ملف dbgeng.dll غير موجود، يجب تثبيت أدوات التصحيح لـ Windows حتى تعمل هذه الأدوات. يجب أن يتضمن متغير البيئة PATH موقع jvm.dll المستخدم من قبل العملية المستهدفة، أو الموقع الذي تم إنتاج ملف التفريغ الأساسي (core dump) منه.
