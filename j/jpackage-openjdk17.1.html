jpackage-openjdk17(1)

الحزمة: jdk17-openjdk

التراخيص: LicenseRef-Java

--linux-package-deps
الحزم أو القدرات المطلوبة للتطبيق
--linux-rpm-license-type <type string>
نوع الترخيص ("License: <value>" من ملف .spec لـ RPM)
--linux-app-release <release string>
قيمة الإصدار لملف .spec لـ RPM <name> أو قيمة مراجعة DEB لملف تحكم DEB
--linux-app-category <category string>
قيمة المجموعة لملف .spec لـ RPM <name> أو قيمة القسم لملف تحكم DEB
--linux-shortcut
ينشئ اختصارًا للتطبيق.

أمثلة JPACKAGE


إنشاء حزمة تطبيق ؛ مناسبة للنظام المضيف:


لتطبيق معياري:
  jpackage -n name -p modulePath -m moduleName/className
لتطبيق غير معياري:
  jpackage -i inputDir -n name \
    --main-class className --main-jar myJar.jar
من صورة تطبيق تم بناؤها مسبقًا:
  jpackage -n name --app-image appImageDir


إنشاء صورة تطبيق:


لتطبيق معياري:
  jpackage --type app-image -n name -p modulePath \
    -m moduleName/className
لتطبيق غير معياري:
  jpackage --type app-image -i inputDir -n name \
    --main-class className --main-jar myJar.jar
لتوفير خياراتك الخاصة لـ jlink ، قم بتشغيل jlink بشكل منفصل:
  jlink --output appRuntimeImage -p modulePath \
    --add-modules moduleName \
    --no-header-files [...]
  jpackage --type app-image -n name \
    -m moduleName/className --runtime-image appRuntimeImage


إنشاء حزمة وقت تشغيل Java:


jpackage -n name --runtime-image <runtime-image>
