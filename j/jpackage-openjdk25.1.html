خيارات منصة لينكس (متوفرة فقط عند التشغيل على لينكس)

--linux-deb-maintainer عنوان-البريد-الإلكتروني
المسؤول عن حزمة .deb
--linux-menu-group اسم-مجموعة-القوائم
مجموعة القوائم التي يتم وضع هذا التطبيق فيها
--linux-package-deps سلسلة-تبعيات-الحزم
الحزم أو القدرات المطلوبة للتطبيق
--linux-rpm-license-type النوع
نوع الترخيص ("License: القيمة" لملف RPM .spec)
--linux-app-release الإصدار
قيمة الإصدار لملف RPM <name>.spec أو قيمة مراجعة Debian لملف تحكم DEB
--linux-app-category قيمة-الفئة
قيمة المجموعة لملف RPM <name>.spec أو قيمة القسم لملف تحكم DEB
--linux-shortcut
ينشئ اختصارًا للتطبيق.

خيارات منصة macOS (متوفرة فقط عند التشغيل على macOS):

--mac-dmg-content محتوى-إضافي [,محتوى-إضافي...]
يتضمن كل المحتوى المشار إليه في dmg.

يمكن استخدام هذا الخيار أكثر من مرة.

أمثلة jpackage

إنشاء حزمة تطبيق مناسبة للنظام المضيف:

لتطبيق وحدي:
    jpackage -n name -p modulePath -m moduleName/className
لتطبيق غير وحدي:
    jpackage -i inputDir -n name \
        --main-class className --main-jar myJar.jar
 من صورة تطبيق تم إنشاؤها مسبقًا:
    jpackage -n name --app-image appImageDir

إنشاء صورة تطبيق:

لتطبيق وحدي:
    jpackage --type app-image -n name -p modulePath \
        -m moduleName/className
 لتطبيق غير وحدي:
    jpackage --type app-image -i inputDir -n name \
        --main-class className --main-jar myJar.jar
 لتوفير خياراتك الخاصة لـ jlink، قم بتشغيل jlink بشكل منفصل:
    jlink --output appRuntimeImage -p modulePath \
        --add-modules moduleName \
        --no-header-files [<خيارات jlink إضافية>...]
    jpackage --type app-image -n name \
        -m moduleName/className --runtime-image appRuntimeImage

إنشاء حزمة وقت تشغيل Java:

jpackage -n name --runtime-image <صورة-وقت-التشغيل>

توقيع صورة التطبيق المحددة مسبقًا (على macOS):

jpackage --type app-image --app-image <صورة-التطبيق> \
    --mac-sign [<خيارات توقيع إضافية>...]
 ملاحظة: الخيارات الإضافية الوحيدة المسموح بها في هذا الوضع هي:
      مجموعة خيارات التوقيع الإضافية لنظام macOS و --verbose

jpackage و jlink

سيستخدم jpackage أداة jlink لإنشاء وقت تشغيل Java ما لم يتم استخدام الخيار --runtime-image. ستتضمن صورة وقت تشغيل Java التي تم إنشاؤها على Windows مكتبات وقت التشغيل MS المجمعة مع JDK. إذا كانت هناك حاجة لإصدار مختلف من مكتبات وقت التشغيل MS للتطبيق، فسيحتاج المستخدم إلى إضافتها/استبدالها بنفسه.

دليل موارد jpackage

يمكن تجاوز الأيقونات والملفات النموذجية والموارد الأخرى الخاصة بـ jpackage عن طريق إضافة موارد بديلة إلى هذا الدليل. سيقوم jpackage بالبحث عن الملفات بأسماء محددة في دليل الموارد.

ملفات دليل الموارد التي يتم النظر فيها فقط عند التشغيل على لينكس:

<اسم-المشغل>.png
أيقونة مشغل التطبيق

المورد الافتراضي هو JavaApp.png

<اسم-المشغل>.desktop
ملف سطح مكتب سيتم استخدامه مع الأمر xdg-desktop-menu

يتم النظر فيه مع مشغلات التطبيقات المسجلة لربط الملفات و/أو التي تحتوي على أيقونة

المورد الافتراضي هو template.desktop

ملفات دليل الموارد التي يتم النظر فيها فقط عند إنشاء مثبت لينكس DEB/RPM:

<اسم-الحزمة>-<اسم-المشغل>.service
ملف وحدة systemd لمشغل التطبيق المسجل كتطبيق من نوع خدمة خلفية

المورد الافتراضي هو unit-template.service

ملفات دليل الموارد التي يتم النظر فيها فقط عند إنشاء مثبت لينكس RPM:

ملف مواصفات RPM

المورد الافتراضي هو template.spec
