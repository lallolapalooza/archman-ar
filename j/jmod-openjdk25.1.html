jmod-openjdk25(1)

الحزمة: jdk-openjdk

التراخيص: LicenseRef-Java

الاسم

jmod — إنشاء ملفات JMOD

الملخص

jmod create [options] jmod-file
jmod extract [options] jmod-file
jmod hash [options] jmod-file
jmod list [options] jmod-file
jmod describe [options] jmod-file

الوصف

تُستخدم أداة jmod لإنشاء ملفات JMOD، والتي توفر طريقة لتجميع محتويات الوحدة النمطية، بما في ذلك البايت كود، والموارد، ومكتبات النظام الأصلية، والإعلانات الأخرى.

يتم استخدام الأداة jmod لإنشاء ملفات JMOD، واستخراج محتوياتها، وحساب قيم التجزئة (hash) للوحدات النمطية المعتمدة، وإدراج الوحدات النمطية، ووصف محتويات الوحدات النمطية.

يمكنك استخدام الأداة jmod مع الخيارات التالية:

create
إنشاء ملف JMOD.
extract
استخراج محتويات ملف JMOD.
hash
حساب قيم التجزئة (hash) للوحدات النمطية المعتمدة وتسجيلها في ملف JMOD.
list
إدراج محتويات ملف JMOD.
describe
وصف محتويات ملف JMOD.

خيارات لـ jmod

يمكن استخدام الخيارات التالية مع الأداة jmod لإنشاء ملف JMOD:

--class-path path-list
يحدد المسار الذي يحتوي على ملفات الفئة (.class) لإنشاء ملف JMOD.
--cmds directory
يحدد الدليل الذي يحتوي على أوامر الوحدة النمطية.
--configfiles directory
يحدد الدليل الذي يحتوي على ملفات التكوين للوحدة النمطية.
--date date-time
يحدد تاريخ ووقت إدخالات ملف JMOD. الصيغة هي YYYY-MM-DDThh:mm:ssZ أو YYYY-MM-DDThh:mm:ss.SSSZ.
--header-files directory
يحدد الدليل الذي يحتوي على ملفات الرأس للوحدة النمطية.
--header-output-dir directory
يحدد الدليل حيث سيتم وضع ملفات الرأس التي تم إنشاؤها.
--help
عرض رسالة المساعدة.
--libs directory
يحدد الدليل الذي يحتوي على مكتبات النظام الأصلية للوحدة النمطية.
--main-class class-name
يحدد الفئة الرئيسية للوحدة النمطية.
--man-pages directory
يحدد الدليل الذي يحتوي على صفحات الدليل للوحدة النمطية.
--module-version version
يحدد إصدار الوحدة النمطية.
--os-arch architecture
يحدد معماريات نظام التشغيل للوحدة النمطية.
--os-name name
يحدد أسماء أنظمة التشغيل للوحدة النمطية.
--os-version version
يحدد إصدارات أنظمة التشغيل للوحدة النمطية.
--platform-deps directory
يحدد الدليل الذي يحتوي على التبعيات الأصلية للوحدة النمطية.
--src-dirs directory
يحدد الدليل الذي يحتوي على ملفات المصدر للوحدة النمطية.
--version
عرض معلومات الإصدار.
jmod-file
اسم ملف JMOD المراد إنشاؤه.

مثال لإنشاء ملف JMOD:

#Wed Dec 07 00:40:19 EST 2016
create --class-path mods/com.greetings --module-path mlib
  --cmds commands --config configfiles --header-files src/h
  --libs lib --main-class com.greetings.Main
  --man-pages man --module-version 1.0
  --os-arch "x86_x64" --os-name "macOS"
  --os-version "10.10.5" greetingsmod

خيارات إضافية لـ jmod

بالإضافة إلى الخيارات الموصوفة في خيارات لـ jmod، الخيارات التالية هي خيارات إضافية يمكن استخدامها مع الأمر.

--do-not-resolve-by-default
استبعاد من مجموعة الجذر الافتراضية للوحدات النمطية
--warn-if-resolved
تلميح لأداة لإصدار تحذير إذا تم حل الوحدة النمطية. أحد الخيارات: deprecated، deprecated-for-removal، أو incubating.

مثال لإنشاء jmod

المثال التالي هو إنشاء ملف JMOD:

jmod create --class-path mods/com.greetings --cmds commands
  --config configfiles --header-files src/h --libs lib
  --main-class com.greetings.Main --man-pages man --module-version 1.0
  --os-arch "x86_x64" --os-name "macOS"
  --os-version "10.10.5" greetingsmod

إنشاء ملف JMOD يحدد التاريخ للإدخالات على أنه 2022 March 15 00:00:00:

jmod create --class-path build/foo/classes --date 2022-03-15T00:00:00Z
   jmods/foo1.jmod

مثال لتجزئة jmod

يوضح المثال التالي ما يحدث عند محاولة ربط وحدة طرفية (في هذا المثال، ma) بوحدة مطلوبة (mb)، ولا تتطابق قيمة التجزئة المسجلة في الوحدة المطلوبة مع تلك الموجودة في الوحدة الطرفية.

1.
إنشاء وتجميع ملفات .java التالية:
•
jmodhashex/src/ma/module-info.java
module ma {
  requires mb;
}
•
jmodhashex/src/mb/module-info.java
module mb {
}
•
jmodhashex2/src/ma/module-info.java
module ma {
  requires mb;
}
•
jmodhashex2/src/mb/module-info.java
module mb {
}
2.
إنشاء أرشيف JMOD لكل وحدة نمطية. قم بإنشاء الدلائل jmodhashex/jmods و jmodhashex2/jmods، ثم قم بتشغيل الأوامر التالية من الدليل jmodhashex، ثم من الدليل jmodhashex2:
•
jmod create --class-path mods/ma jmods/ma.jmod
•
jmod create --class-path mods/mb jmods/mb.jmod
3.
اختياريًا، قم بمعاينة الأمر jmod hash. قم بتشغيل الأمر التالي من الدليل jmodhashex:

jmod hash --dry-run -module-path jmods --hash-modules .*

يقوم الأمر بطباعة ما يلي:

Dry run:
mb
  hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a

يشير هذا إلى أن الأمر jmod hash (بدون الخيار --dry-run) سيسجل قيمة التجزئة للوحدة الطرفية ma في الوحدة النمطية mb.

4.
تسجيل قيم التجزئة في ملفات أرشيف JMOD الموجودة في الدليل jmodhashex. قم بتشغيل الأمر التالي من الدليل jmodhashex:

jmod hash --module-path jmods --hash-modules .*

يقوم الأمر بطباعة ما يلي:

Hashes are recorded in module mb

5.
طباعة معلومات حول كل أرشيف JMOD الموجود في الدليل jmodhashex. قم بتشغيل الأوامر المميزة باللون الأحمر من الدليل jmodhashex:
jmod describe jmods/ma.jmod
ma
  requires mandated java.base
  requires mb
jmod describe jmods/mb.jmod
mb
  requires mandated java.base
  hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a
6.
محاولة إنشاء صورة تشغيل تحتوي على الوحدة النمطية ma من الدليل jmodhashex2 ولكن الوحدة النمطية mb من الدليل jmodhashex. قم بتشغيل الأمر التالي من الدليل jmodhashex2:
•
Linux و macOS:

jlink --module-path $JAVA_HOME/jmods:jmods/ma.jmod:../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

•
Windows:

jlink --module-path %JAVA_HOME%/jmods;jmods/ma.jmod;../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

يقوم الأمر بطباعة رسالة خطأ مشابهة لما يلي:

Error: Hash of ma (a2d77889b0cb067df02a3abc39b01ac1151966157a68dc4241562c60499150d2) differs to
expected hash (07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a) recorded in mb
2025 JDK 25.0.1
