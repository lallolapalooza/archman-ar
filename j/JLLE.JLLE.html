JLLE(JLLE)

الحزمة: judy

التراخيص: LGPL

JudyL(3) دليل وظائف المكتبة JudyL(3)

الاسم

ماكرو JudyL - مكتبة C لإنشاء والوصول إلى مصفوفة ديناميكية من الكلمات، باستخدام كلمة كفهرس.

الملخص

cc [flags] ملفات المصدر -lJudy
#include <Judy.h>
int      Rc_int;                          // رمز الإرجاع - عدد صحيح
Word_t   Rc_word;                         // رمز الإرجاع - كلمة غير موقعة
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // مؤشر إلى القيمة المرجعة
Pvoid_t PJLArray = (Pvoid_t) NULL;        // تهيئة مصفوفة JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

الوصف

مصفوفة JudyL هي المكافئ لمصفوفة من القيم بحجم كلمة. يتم عنونة القيمة (Value) بواسطة الفهرس (Index). يمكن أن تكون المصفوفة متناثرة، ويمكن أن يكون الفهرس (Index) أي رقم بحجم كلمة. يتم تخصيص الذاكرة لدعم المصفوفة مع إدراج أزواج الفهرس/القيمة، ويتم تحريرها مع حذف أزواج الفهرس/القيمة. يمكن أيضًا اعتبار مصفوفة JudyL بمثابة معين، أي "تعيين" كلمة إلى كلمة/مؤشر آخر.

كما هو الحال مع المصفوفة العادية، لا توجد فهارس مكررة في مصفوفة JudyL.

يمكن استخدام القيمة كقيمة قياسية، أو مؤشر إلى بنية أو كتلة بيانات (أو حتى مصفوفة Judy أخرى).

يتم تخصيص مصفوفة JudyL بمؤشر NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

باستخدام الماكرو الموضح هنا، بدلاً من استدعاءات وظائف JudyL، يقوم معالجة الأخطاء الافتراضية بإرسال رسالة إلى الخطأ القياسي وإنهاء البرنامج باستخدام exit(1);. بالنسبة لطرق معالجة الأخطاء الأخرى، انظر قسم الأخطاء (ERRORS). JLI( PValue, PJLArray, Index); // JudyLIns()

نظرًا لأن أشكال الماكرو أحيانًا أسرع ولها واجهة معالجة أخطاء أبسط من وظائف JudyL المكافئة، فهي الطريقة المفضلة لاستدعاء وظائف JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
إدراج الفهرس (Index) والقيمة (Value) في مصفوفة JudyL PJLArray. إذا تم إدراج الفهرس (Index) بنجاح، يتم تهيئة القيمة (Value) إلى 0. إذا كان الفهرس (Index) موجودًا بالفعل، فلا يتم تعديل القيمة (Value).
إرجاع PValue يشير إلى القيمة (Value). يمكن لبرنامجك استخدام هذا المؤشر لقراءة أو تعديل القيمة (Value) حتى يتم تنفيذ استدعاء JLI() (إدراج) أو JLD() (حذف) أو JLFA() (تحرير مصفوفة) التالي على PJLArray. أمثلة:
*PValue = 1234;
Value = *PValue;
إرجاع PValue مضبوطًا على PJERR إذا حدث فشل في malloc(). ملاحظة: JLI() و JLD() يعيدان تنظيم مصفوفة JudyL. لذلك، يصبح PValue الذي تم إرجاعه من استدعاءات JudyL السابقة غير صالح ويجب إعادة الحصول عليه.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
حذف زوج الفهرس (Index) /القيمة (Value) من مصفوفة JudyL.
إرجاع Rc_int مضبوطًا على 1 إذا نجحت العملية. إرجاع Rc_int مضبوطًا على 0 إذا لم يكن الفهرس (Index) موجودًا. إرجاع Rc_int مضبوطًا على JERR إذا حدث فشل في malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
الحصول على المؤشر PValue المرتبط بـ الفهرس (Index) في مصفوفة Judy PJLArray.
إرجاع PValue يشير إلى القيمة (Value). إرجاع PValue مضبوطًا على NULL إذا لم يكن الفهرس (Index) موجودًا. إرجاع PValue مضبوطًا على PJERR إذا حدث فشل في malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
عد عدد الفهارس الموجودة في مصفوفة JudyL PJLArray بين Index1 و Index2 (شاملة).
إرجاع Rc_word مضبوطًا على العدد. يمكن أن تكون القيمة المرجعة 0 صالحة كنتيجة عد.
لعد جميع الفهارس الموجودة في مصفوفة JudyL، استخدم:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
تحديد الفهرس Nth الموجود في مصفوفة JudyL PJLArray (Nth = 1 يعيد الفهرس الأول الموجود).
إرجاع PValue يشير إلى قيمته و Index مضبوطًا على الفهرس Nth إذا تم العثور عليه، وإلا فإرجاع PValue مضبوطًا على NULL (قيمة Index غير محددة).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
بالمقارنة مع مؤشر إلى مصفوفة JudyL، قم بتحرير المصفوفة بأكملها (أسرع بكثير من استخدام حلقة JLN()، JLD()).
إرجاع Rc_word مضبوطًا على عدد البايتات التي تم تحريرها و PJLArray مضبوطًا على NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
إرجاع Rc_word مضبوطًا على عدد البايتات من الذاكرة التي تم تخصيصها (malloc()) بواسطة PJLArray. هذه روتينية سريعة جدًا، ويمكن استخدامها قبل وبعد استدعاء JLI() أو JLD() بأقل تأثير على الأداء.

وظائف بحث JudyL
تسمح لك JLF()، JLN()، JLL()، JLP() بالبحث عن فهارس في المصفوفة. يمكنك البحث بشكل شامل أو حصري، في اتجاهين متعاكسين أو متوافقين. إذا نجحت العملية، يتم إرجاع Index مضبوطًا على الفهرس الذي تم العثور عليه، ويتم إرجاع PValue مضبوطًا على مؤشر إلى قيمة (Value) الفهرس (Index). إذا فشلت العملية، يتم إرجاع PValue مضبوطًا على NULL، و Index لا يحتوي على معلومات مفيدة. يجب اختبار PValue للتأكد من أنه ليس NULL قبل استخدام Index، نظرًا لاحتمالية فشل البحث.
تسمح لك JLFE()، JLNE()، JLLE()، JLPE() بالبحث عن فهارس غير موجودة ("فارغة") في المصفوفة. يمكنك البحث بشكل شامل أو حصري، في اتجاهين متعاكسين أو متوافقين. إذا نجحت العملية، يتم إرجاع Index مضبوطًا على فهرس غير موجود ("فارغ")، ويتم إرجاع Rc_int مضبوطًا على 1. إذا فشلت العملية، يتم إرجاع Rc_int مضبوطًا على 0، و Index لا يحتوي على معلومات مفيدة. يجب التحقق من Rc_int قبل استخدام Index، نظرًا لاحتمالية فشل البحث.

JLF(PValue, PJLArray, Index) // JudyLFirst()
بحث (شامل) عن أول فهرس موجود يساوي أو أكبر من الفهرس (Index) الممرر. (ابدأ بـ Index = 0 للعثور على أول فهرس في المصفوفة.) عادةً ما تُستخدم JLF() لـ بدء مسح بترتيب أبجدي للفهارس الموجودة في مصفوفة JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
بحث (حصري) عن الفهرس التالي الموجود الأكبر من الفهرس (Index) الممرر. عادةً ما تُستخدم JLN() لـ متابعة مسح بترتيب أبجدي للفهارس الموجودة في مصفوفة JudyL، أو لتحديد "جار" لفهرس معين.
