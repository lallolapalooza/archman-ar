jinfo-openjdk21(1)

الحزمة: jdk21-openjdk

التراخيص: LicenseRef-Java

JINFO(1) أوامر JDK JINFO(1)

اسم

jinfo - إنشاء معلومات تكوين Java لعملية Java محددة

الملخص

ملاحظة: هذا الأمر تجريبي وغير مدعوم.

jinfo [خيار] معرف_العملية

خيار
يمثل هذا خيارات سطر الأوامر لأمر jinfo. راجع خيارات أمر jinfo.
معرف_العملية
معرف العملية الذي سيتم طباعة معلومات التكوين الخاصة به. يجب أن تكون العملية عملية Java. للحصول على قائمة بعمليات Java قيد التشغيل على جهاز، استخدم أمر ps أو، إذا لم تكن عمليات JVM قيد التشغيل في مثيل docker منفصل، الأمر jps.

الوصف

يطبع أمر jinfo معلومات تكوين Java لعملية Java محددة. تشمل معلومات التكوين خصائص نظام Java وأعلام سطر أوامر JVM. إذا كانت العملية المحددة تعمل على JVM 64 بت، فقد تحتاج إلى تحديد الخيار -J-d64، على سبيل المثال:

jinfo -J-d64 -sysprops معرف_العملية

هذا الأمر غير مدعوم وقد لا يكون متاحًا في الإصدارات المستقبلية من JDK. في أنظمة Windows حيث لا يوجد dbgeng.dll، يجب تثبيت أدوات تصحيح أخطاء Windows لكي تعمل هذه الأدوات. يجب أن يحتوي متغير البيئة PATH على موقع jvm.dll المستخدم بواسطة العملية المستهدفة أو الموقع الذي تم إنتاج ملف تفريغ النواة منه.

خيارات أمر jinfo

ملاحظة:

إذا لم يتم استخدام أي من الخيارات التالية، فسيتم طباعة كل من الأعلام سطر الأوامر وأزواج اسم-قيمة خاصية النظام.

-flag name
يطبع اسم وقيمة العلم المحدد في سطر الأوامر.
-flag [+|-]name
يمكّن أو يعطّل العلم المنطقي المحدد في سطر الأوامر.
-flag name=value
يضبط العلم المحدد في سطر الأوامر على القيمة المحددة.
-flags
يطبع الأعلام سطر الأوامر التي تم تمريرها إلى JVM.
-sysprops
يطبع خصائص نظام Java كأزواج اسم-قيمة.
-h أو -help
يطبع رسالة مساعدة.
