NAME

JSON::WebToken - JSON Web Token

SYNOPSIS

use JSON::WebToken;

my $token = JSON::WebToken->new->encode({
    iss => 'me',
    exp => time + 3600,
    jwt => {
        foo => 'bar',
    },
});

my $decoded = JSON::WebToken->new->decode($token);
print $decoded->{jwt}->{foo}; # prints "bar"

DESCRIPTION

This module implements the JSON Web Token (JWT) standard.

JWT is a compact, URL-safe means of representing claims to be transferred between two parties. It is an open standard (RFC 7519) that defines a compact and self-contained way for securely transmitting information between parties as a JSON object. This information can be verified and trusted because it is digitally signed or HMAC-protected and can also be encrypted.

METHODS

new
Creates a new JSON::WebToken object.
encode ( \%claims )
Encodes the given claims into a JWT. The claims can be any valid JSON structure.
decode ( $token )
Decodes a JWT into its constituent claims.

الوصف

تنفذ هذه الوحدة معيار JSON Web Token (JWT).

JWT هو وسيلة موجزة وآمنة للاستخدام في عناوين URL لتمثيل المطالبات التي سيتم نقلها بين طرفين. إنه معيار مفتوح (RFC 7519) يحدد طريقة موجزة ومكتفية ذاتيًا لنقل المعلومات بأمان بين الأطراف ككائن JSON. يمكن التحقق من هذه المعلومات والثقة بها لأنها موقعة رقميًا أو محمية بـ HMAC، ويمكن أيضًا تشفيرها.

الطرق

new
ينشئ كائن JSON::WebToken جديدًا.
encode ( \%claims )
ترميز المطالبات المعطاة إلى JWT. يمكن أن تكون المطالبات أي بنية JSON صالحة.
decode ( $token )
فك ترميز JWT إلى مطالباته المكونة.
