الاسم

jose - مجموعة أدوات لأداء توقيع وتشفير كائنات JSON

الملخص

jose alg [-k KIND]

jose b64 dec -i B64 [-O BIN]

jose b64 enc -I BIN [-o B64]

jose jwe dec -i JWE [-I CT] -k JWK [-p] [-O PT]

jose jwe enc [-i JWE] -I PT -k JWK [-p] [-r RCP] [-o JWE] [-O CT] [-c]

jose jwe fmt -i JWE [-I CT] [-o JWE] [-O CT] [-c]

jose jwk exc [-i JWK] -l JWK -r JWK [-o JWK]

jose jwk gen -i JWK [-o JWK]

jose jwk pub -i JWK [-o JWK]

jose jwk thp -i JWK [-a ALG] [-o THP]

jose jwk use -i JWK [-a] [-r] -u OP

jose jws fmt -i JWS [-I PAY] [-o JWS] [-O PAY] [-c]

jose jws sig [-i JWS] [-I PAY] [-s SIG] -k JWK [-o JWS] [-O PAY] [-c]

jose jws ver -i JWS [-I PAY] -k JWK [-O PAY] [-a]

نظرة عامة

José هو تطبيق بلغة C لمعايير توقيع وتشفير كائنات JavaScript. بشكل خاص، يهدف José نحو تطبيق المعايير التالية:

•RFC 7515 - توقيع ويب JSON (JWS)
•RFC 7516 - تشفير ويب JSON (JWE)
•RFC 7517 - مفتاح ويب JSON (JWK)
•RFC 7518 - خوارزميات ويب JSON (JWA)
•RFC 7519 - رمز ويب JSON (JWT)
•RFC 7520 - أمثلة على حماية المحتوى باستخدام JOSE
•RFC 7638 - بصمة مفتاح ويب JSON (JWK)

توفر أداة سطر الأوامر José مرافق لما يلي:

•ترميز وفك ترميز Base64 الآمنة لـ URL
•إنشاء وإدارة المفاتيح
•التشفير وفك التشفير
•التوقيع والتحقق
