الاسم

json-glib-format - أداة تنسيق JSON

الملخص

json-glib-format [خيارات...] <ملف> [<ملف>...]

الوصف

json-glib-format يوفر واجهة سطر أوامر بسيطة لتنسيق بيانات JSON. يقرأ قائمة أو عناوين URL، ويطبق قواعد التنسيق المحددة على بيانات JSON، ويخرج بيانات JSON المنسقة إلى المخرج القياسي أو إلى ملف.

يتم تحديد الموارد التي سيتم تشغيلها بواسطة وسيطة FILE.

الخيارات

-h, --help

اطبع رسالة مساعدة واخرج.

--output=FILE

يعيد توجيه الإخراج إلى FILE بدلاً من استخدام المخرج القياسي.

-p, --prettify

يجعل الإخراج أجمل، عن طريق إضافة مسافات وتعريج. هذه الوسيطة مفيدة لتحسين قابلية قراءة بيانات JSON، على حساب حجمها.

--indent-spaces=SPACES

يغير عدد المسافات المستخدمة لتعريج بيانات JSON من القيمة الافتراضية 2. يتم النظر في هذه الوسيطة فقط إذا تم استخدام --prettify.
