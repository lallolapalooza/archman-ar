jmod-openjdk17(1)

الحزمة: jdk17-openjdk

التراخيص: LicenseRef-Java

NAME

jmod - أداة لإدارة ملفات الوحدات النمطية

SYNOPSIS

jmod [OPTIONS] COMMAND

DESCRIPTION

تقوم أداة jmod بإنشاء وإدارة ملفات الأرشيف النمطية، والتي هي تنسيق تعبئة الوحدات النمطية.

يمكنك التعليق على الخطوط عن طريق إضافة رمز التجزئة (#) في بداية السطر.

فيما يلي مثال لملف خيارات لأمر jmod:

#Wed Dec 07 00:40:19 EST 2016
create --class-path mods/com.greetings --module-path mlib
  --cmds commands --config configfiles --header-files src/h
  --libs lib --main-class com.greetings.Main
  --man-pages man --module-version 1.0
  --os-arch "x86_x64" --os-name "Mac OS X"
  --os-version "10.10.5" greetingsmod

خيارات إضافية لأمر jmod

بالإضافة إلى الخيارات الموضحة في خيارات أمر jmod، إليك خيارات إضافية يمكن استخدامها مع الأمر.

--do-not-resolve-by-default
استبعاد من مجموعة الجذر الافتراضية للوحدات
--warn-if-resolved
تلميح لأداة لإصدار تحذير إذا تم حل الوحدة. أحد الخيارات: deprecated، deprecated-for-removal، أو incubating.

مثال على إنشاء jmod

فيما يلي مثال على إنشاء ملف JMOD:

jmod create --class-path mods/com.greetings --cmds commands
  --config configfiles --header-files src/h --libs lib
  --main-class com.greetings.Main --man-pages man --module-version 1.0
  --os-arch "x86_x64" --os-name "Mac OS X"
  --os-version "10.10.5" greetingsmod

مثال على تجزئة jmod

يوضح المثال التالي ما يحدث عند محاولة ربط وحدة ورقة (في هذا المثال، ma) بوحدة مطلوبة (mb)، وقيمة التجزئة المسجلة في الوحدة المطلوبة لا تتطابق مع قيمة الوحدة الورقة.

1.
إنشاء وترجمة ملفات .java التالية:
•
jmodhashex/src/ma/module-info.java
module ma {
  requires mb;
}
•
jmodhashex/src/mb/module-info.java
module mb {
}
•
jmodhashex2/src/ma/module-info.java
module ma {
  requires mb;
}
•
jmodhashex2/src/mb/module-info.java
module mb {
}
2.
إنشاء أرشيف JMOD لكل وحدة. قم بإنشاء الدلائل jmodhashex/jmods و jmodhashex2/jmods، ثم قم بتشغيل الأوامر التالية من الدليل jmodhashex، ثم من الدليل jmodhashex2:
•
jmod create --class-path mods/ma jmods/ma.jmod
•
jmod create --class-path mods/mb jmods/mb.jmod
3.
اختياريًا، معاينة أمر jmod hash. قم بتشغيل الأمر التالي من الدليل jmodhashex:

jmod hash --dry-run -module-path jmods --hash-modules .*

يقوم الأمر بطباعة ما يلي:

Dry run:
mb
  hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a

يشير هذا إلى أن أمر jmod hash (بدون الخيار --dry-run) سيقوم بتسجيل قيمة التجزئة للوحدة الورقة ma في الوحدة mb.

4.
تسجيل قيم التجزئة في ملفات أرشيف JMOD الموجودة في الدليل jmodhashex. قم بتشغيل الأمر التالي من الدليل jmodhashex:

jmod hash --module-path jmods --hash-modules .*

يقوم الأمر بطباعة ما يلي:

Hashes are recorded in module mb

5.
طباعة معلومات حول كل أرشيف JMOD الموجود في الدليل jmodhashex. قم بتشغيل الأوامر المميزة بالخط الغامق من الدليل jmodhashex:
jmod describe jmods/ma.jmod
ma
  requires mandated java.base
  requires mb
jmod describe jmods/mb.jmod
mb
  requires mandated java.base
  hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a
6.
محاولة إنشاء صورة وقت تشغيل تحتوي على الوحدة ma من الدليل jmodhashex2 ولكن الوحدة mb من الدليل jmodhashex. قم بتشغيل الأمر التالي من الدليل jmodhashex2:
•
Linux و OS X:

jlink --module-path $JAVA_HOME/jmods:jmods/ma.jmod:../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

•
Windows:

jlink --module-path %JAVA_HOME%/jmods;jmods/ma.jmod;../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

يطبع الأمر رسالة خطأ مشابهة لما يلي:

Error: Hash of ma (a2d77889b0cb067df02a3abc39b01ac1151966157a68dc4241562c60499150d2) differs to
expected hash (07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a) recorded in mb
