jose-b64-enc(1)

الحزمة: jose

التراخيص: Apache-2.0

JOSE-B64-ENC(1)   JOSE-B64-ENC(1)

الاسم

jose-b64-enc - يقوم بتشفير البيانات الثنائية إلى Base64 آمنة لـ URL

الملخص

jose b64 enc -I BIN [-o B64]

نظرة عامة

يقوم الأمر jose b64 enc بتشفير البيانات الثنائية إلى تنسيق Base64 آمنة لـ URL.

خيارات

•-I FILE, --binary=FILE : قراءة البيانات الثنائية من FILE
•-I -, --binary=- : قراءة البيانات الثنائية من الإدخال القياسي
•-o FILE, --base64=FILE : كتابة Base64 (آمنة لـ URL) إلى FILE
•-o -, --base64=- : كتابة Base64 (آمنة لـ URL) إلى الإخراج القياسي

أمثلة

تشفير رسالة بسيطة:

$ echo "Hello, World" | jose b64 enc -I-
SGVsbG8sIFdvcmxkCg
