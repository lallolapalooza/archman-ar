jcmd-openjdk11(1)

الحزمة: jdk11-openjdk

التراخيص: LicenseRef-Java

jcmd(1) أدوات استكشاف الأخطاء وإصلاحها jcmd(1)

الاسم

jcmd - يرسل طلبات أوامر التشخيص إلى آلة Java الظاهرية (JVM) قيد التشغيل.

الملخص

jcmd [-l|-h|-help]
jcmd pid|main-class PerfCounter.print
jcmd pid|main-class -f filename
jcmd pid|main-class command[ arguments]

الوصف

تُستخدم الأداة المساعدة jcmd لإرسال طلبات أوامر التشخيص إلى JVM. يجب استخدامها على نفس الجهاز الذي تعمل عليه JVM، ويجب أن يكون لديها نفس معرفات المستخدم والمجموعة الفعالة المستخدمة لتشغيل JVM.


ملاحظة
لاستدعاء أوامر التشخيص من جهاز بعيد أو بمعرفات مختلفة، يمكنك استخدام الواجهة com.sun.management.DiagnosticCommandMBean. لمزيد من المعلومات حول الواجهة DiagnosticCommandMBean، راجع وثائق API على http://docs.oracle.com/javase/8/docs/jre/api/management/extension/com/sun/management/DiagnosticCommandMBean.html

إذا قمت بتشغيل jcmd بدون وسائط أو مع الخيار -l، فسيتم طباعة قائمة بمعرفات عمليات Java قيد التشغيل مع الفئة الرئيسية ووسائط سطر الأوامر التي تم استخدامها لتشغيل العملية. طباعة jcmd مع الخيار -h أو -help يطبع رسالة المساعدة للأداة.

إذا قمت بتحديد معرف العملية (pid) أو الفئة الرئيسية (main-class) كوسيط أول، ترسل jcmd طلب أمر التشخيص إلى عملية Java بالمعرف المحدد أو إلى جميع عمليات Java بالاسم المحدد للفئة الرئيسية. يمكنك أيضًا إرسال طلب أمر التشخيص إلى جميع عمليات Java المتاحة عن طريق تحديد 0 كمعرف للعملية. استخدم أحد الخيارات التالية كطلب أمر التشخيص:

Perfcounter.print

يطبع عدادات الأداء المتاحة لعملية Java المحددة. قد تختلف قائمة عدادات الأداء مع عملية Java.

-f filename

اسم الملف الذي تتم قراءة أوامر التشخيص منه وإرسالها إلى عملية Java المحددة. يُستخدم فقط مع الخيار -f. يجب كتابة كل أمر في الملف على سطر واحد. يتم تجاهل الأسطر التي تبدأ بعلامة رقم (#). ينتهي معالجة الملف عند قراءة جميع الأسطر أو عند قراءة سطر يحتوي على الكلمة المفتاحية stop.

command [arguments]

الأمر الذي سيتم إرساله إلى عملية Java المحددة. يمكن الحصول على قائمة أوامر التشخيص المتاحة لعملية معينة عن طريق إرسال الأمر help إلى هذه العملية. لكل أمر تشخيص مجموعة خاصة به من الوسائط. لرؤية الوصف، والصيغة، وقائمة بالوسائط المتاحة لأمر ما، استخدم اسم الأمر كوسيط للأمر help.

ملاحظة: إذا كانت أي وسائط تحتوي على مسافات، فيجب عليك إحاطتها بعلامات اقتباس مفردة أو مزدوجة (' أو "). بالإضافة إلى ذلك، يجب عليك الهروب من علامات الاقتباس المفردة أو المزدوجة بشرطة مائلة للخلف (\) لمنع shell نظام التشغيل من معالجة علامات الاقتباس. بدلاً من ذلك، يمكنك إحاطة هذه الوسائط بعلامات اقتباس مفردة ثم بعلامات اقتباس مزدوجة (أو بعلامات اقتباس مزدوجة ثم بعلامات اقتباس مفردة).

الخيارات

الخيارات متعارضة.

-f filename

يقرأ الأوامر من الملف المحدد. يمكن استخدام هذا الخيار فقط إذا قمت بتحديد معرف العملية أو الفئة الرئيسية كوسيط أول. يجب كتابة كل أمر في الملف على سطر واحد. يتم تجاهل الأسطر التي تبدأ بعلامة رقم (#). ينتهي معالجة الملف عند قراءة جميع الأسطر أو عند قراءة سطر يحتوي على الكلمة المفتاحية stop.

-h
-help

يطبع رسالة مساعدة.

-l

يطبع قائمة بمعرفات عمليات Java قيد التشغيل مع الفئة الرئيسية ووسائط سطر الأوامر.
