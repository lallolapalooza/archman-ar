jhsdb-openjdk21(1)

الحزمة: jdk21-openjdk

التراخيص: LicenseRef-Java

JHSDB(1) أوامر JDK JHSDB(1)

الاسم

jhsdb - الاتصال بعملية Java أو تشغيل مصحح أخطاء ما بعد الوفاة لتحليل محتويات تفريغ الذاكرة من آلة Java الافتراضية (JVM) التي تعطلت

الملخص

jhsdb clhsdb --pid pid | --exe executable --core coredump

jhsdb hsdb --pid pid | --exe executable --core coredump

jhsdb debugd (--pid pid | --exe executable --core coredump) [options]

jhsdb jstack (--pid pid | --exe executable --core coredump | --connect [server-id@]debugd-host) [options]

jhsdb jmap (--pid pid | --exe executable --core coredump | --connect [server-id@]debugd-host) [options]

jhsdb jinfo (--pid pid | --exe executable --core coredump | --connect [server-id@]debugd-host) [options]

jhsdb jsnap (--pid pid | --exe executable --core coredump | --connect [server-id@]debugd-host) [options]

pid
معرف العملية التي يجب أن يتصل بها أداة jhsdb. يجب أن تكون العملية عملية Java. للحصول على قائمة بعمليات Java قيد التشغيل على جهاز، استخدم الأمر ps أو، إذا لم تكن عمليات JVM تعمل في مثيل docker منفصل، الأمر jps.
executable
ملف Java التنفيذي الذي تم إنتاج تفريغ الذاكرة منه.
coredump
ملف الذاكرة الذي يجب أن تتصل به أداة jhsdb.
[server-id@]debugd-host
معرف خادم اختياري وعنوان خادم التصحيح البعيد (debugd).
options
خيارات سطر الأوامر لوضع jhsdb. راجع خيارات وضع debugd، خيارات وضع jstack، خيارات وضع jmap، خيارات وضع jinfo، و خيارات وضع jsnap.

ملاحظة:

يجب توفير pid أو زوج من الملفات executable و core أو [server-id@]debugd-host لأوضاع debugd، jstack، jmap، jinfo، و jsnap.

الوصف

يمكنك استخدام أداة jhsdb للاتصال بعملية Java أو لتشغيل مصحح أخطاء ما بعد الوفاة لتحليل محتويات تفريغ الذاكرة من آلة Java الافتراضية (JVM) التي تعطلت. هذا الأمر تجريبي وغير مدعوم.

ملاحظة:

سيؤدي توصيل أداة jhsdb بعملية حية إلى تعليق العملية ومن المحتمل أن تتعطل العملية عند فصل مصحح الأخطاء.

يمكن تشغيل أداة jhsdb في أي من الأوضاع التالية:

jhsdb clhsdb
يبدأ مصحح الأخطاء التفاعلي في سطر الأوامر.
jhsdb hsdb
يبدأ مصحح الأخطاء التفاعلي بواجهة رسومية.
jhsdb debugd
يبدأ خادم التصحيح البعيد.
jhsdb jstack
يطبع معلومات المكدس والأقفال.
jhsdb jmap
يطبع معلومات الذاكرة.
jhsdb jinfo
يطبع معلومات JVM الأساسية.
jhsdb jsnap
يطبع معلومات عداد الأداء.
jhsdb command --help
يعرض الخيارات المتاحة لـ command.

خيارات وضع debugd

--serverid server-id
معرف فريد اختياري لخادم التصحيح هذا. هذا مطلوب إذا تم تشغيل خوادم تصحيح متعددة على نفس الجهاز.
--rmiport port
يحدد رقم المنفذ الذي يتم ربط موصل RMI به. إذا لم يتم تحديده، يتم استخدام منفذ متاح عشوائيًا.
--registryport port
يحدد منفذ تسجيل RMI. يتجاوز هذا الخيار خاصية النظام 'sun.jvm.hotspot.rmi.port'. إذا لم يتم تحديده، يتم استخدام خاصية النظام. إذا لم يتم تعيين خاصية النظام، يتم استخدام المنفذ الافتراضي 1099.
--hostname hostname
يحدد اسم المضيف الذي يتم ربط موصل RMI به. يمكن أن تكون القيمة اسم مضيف أو عنوان IPv4/IPv6. يتجاوز هذا الخيار خاصية النظام 'java.rmi.server.hostname'. إذا لم يتم تحديده، يتم استخدام خاصية النظام. إذا لم يتم تعيين خاصية النظام، يتم استخدام اسم المضيف الخاص بالنظام.

خيارات وضع jinfo

--flags
يطبع علامات VM.
--sysprops
يطبع خصائص نظام Java.
بدون خيار
يطبع علامات VM وخصائص نظام Java.

خيارات وضع jmap

بدون خيار
يطبع نفس المعلومات مثل Solaris pmap.
--heap
يطبع ملخص ذاكرة Java.
--binaryheap
يفرغ ذاكرة Java بتنسيق hprof الثنائي.
--dumpfile name
اسم ملف التفريغ.
--histo
يطبع الرسم البياني لذاكرة كائنات Java.
--clstats
يطبع إحصائيات محمل الفئة.
--finalizerinfo
يطبع معلومات حول الكائنات التي تنتظر التصفية النهائية.

خيارات وضع jstack

--locks
يطبع معلومات أقفال java.util.concurrent.
--mixed
يحاول طباعة إطارات Java والمحلية إذا سمحت المنصة بذلك.

خيارات وضع jsnap

--all
يطبع جميع عدادات الأداء.
