jack_property(1) دليل الأوامر العامة jack_property(1)

الاسم

jack_property - عميل JACK لسرد وتعيين وحذف معلومات البيانات الوصفية

الملخص

jack_property -l
jack_property [ -c | -p ] -l المعرف
jack_property [ -c | -p ] -l المعرف المفتاح
jack_property [ -c | -p ] -s المعرف المفتاح القيمة [ النوع ]
jack_property [ -c | -p ] -d المعرف
jack_property [ -c | -p ] -d المعرف المفتاح
jack_property -D

الوصف

يمكن استخدام jack_property لسرد وتعيين وحذف أي وجميع البيانات الوصفية المرتبطة بالمنافذ والعملاء لخادم JACK.

هناك ثلاث طرق رئيسية لاستخدام الأمر. يُستخدم الخيار -l لسرد البيانات الوصفية الموجودة. يُستخدم الخيار -s لتعيين البيانات الوصفية. تُستخدم الخيارات -d/-D لحذف البيانات الوصفية.

المعرف هو عادةً UUID (يمكن إظهار UUIDs للمنافذ والعملاء باستخدام jack_lsp(1)). إذا تم استخدام الخيار -c، فسيتم تفسير المعرف كاسم عميل، وسيتم البحث عن UUID الخاص به داخليًا واستخدامه لعملية البيانات الوصفية ذات الصلة. إذا تم استخدام الخيار -p، فسيتم تفسير المعرف كاسم منفذ وسيتم البحث عن UUID الخاص به داخليًا واستخدامه لعملية البيانات الوصفية ذات الصلة.

المفتاح هو سلسلة نصية عشوائية تحدد البيانات الوصفية المراد العمل عليها.

القيمة هي سلسلة نصية عشوائية تحدد قيمة البيانات الوصفية المراد إنشاؤها.

النوع هو نوع MIME اختياري، يُعطى كسلسلة نصية. ينتج عن نوع فارغ لقطعة من البيانات الوصفية تفسيرها على أنها "text/UTF-8".

خيارات

-l
يسرد جميع البيانات الوصفية المحددة حاليًا
-l identifier
يسرد جميع البيانات الوصفية المحددة حاليًا لـ المعرف
-l identifier key
يعرض قيمة البيانات الوصفية المرتبطة بالمفتاح لـ المعرف
-d identifier
يحذف جميع البيانات الوصفية لـ المعرف
-d identifier key
يحذف البيانات الوصفية المرتبطة بالمفتاح المفتاح لـ المعرف
-D
يحذف جميع البيانات الوصفية المحددة حاليًا
-s identifier key value [ type ]
يعين البيانات الوصفية المرتبطة بالمفتاح المفتاح إلى القيمة القيمة لـ المعرف، مع تعيين نوعها إلى النوع إذا تم تقديمه
-c
يفسر معرفًا معينًا كاسم عميل بدلاً من UUID
-p
يفسر معرفًا معينًا كاسم منفذ بدلاً من UUID
