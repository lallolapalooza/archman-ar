jhsdb-openjdk25(1)

JHSDB(1) أوامر JDK JHSDB(1)

الاسم

jhsdb - الاتصال بعملية Java أو تشغيل مصحح أخطاء بعد الوفاة لتحليل محتويات تفريغ أساسي من آلة Java الافتراضية (JVM) المتعطلة

الملخص

تحذير: الأمر الفرعي debugd والخيارات --connect تم إيقافها. سيتم إزالتها في إصدار مستقبلي.

jhsdb clhsdb [--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي]

jhsdb hsdb [--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي]

jhsdb debugd (--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي) [خيارات]

jhsdb jstack (--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي | --connect [معرف الخادم@] مضيف debugd) [خيارات]

jhsdb jmap (--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي | --connect [معرف الخادم@] مضيف debugd) [خيارات]

jhsdb jinfo (--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي | --connect [معرف الخادم@] مضيف debugd) [خيارات]

jhsdb jsnap (--pid معرف العملية | --exe الملف التنفيذي --core ملف التفريغ الأساسي | --connect [معرف الخادم@] مضيف debugd) [خيارات]

معرف العملية
معرف العملية الذي يجب أن يتصل به أداة jhsdb. يجب أن تكون العملية عملية Java. للحصول على قائمة بعمليات Java التي تعمل على جهاز، استخدم الأمر ps أو، إذا كانت عمليات JVM لا تعمل في مثيل docker منفصل، الأمر jps.
الملف التنفيذي
ملف Java التنفيذي الذي تم إنتاج تفريغ الذاكرة الأساسي منه.
ملف التفريغ الأساسي
الملف الأساسي الذي يجب أن تتصل به أداة jhsdb.
[معرف الخادم@] مضيف debugd
معرف خادم اختياري وعنوان خادم التصحيح البعيد (debugd).
خيارات
خيارات سطر الأوامر لوضع jhsdb. راجع خيارات وضع debugd، خيارات وضع jstack، خيارات وضع jmap، خيارات وضع jinfo، و خيارات وضع jsnap.

ملاحظة:

يجب توفير إما معرف العملية أو زوج من الملفات التنفيذية و الأساسية أو [معرف الخادم@] مضيف debugd لوضع debugd، jstack، jmap، jinfo و jsnap.

الوصف

يمكنك استخدام أداة jhsdb للاتصال بعملية Java أو لتشغيل مصحح أخطاء بعد الوفاة لتحليل محتويات تفريغ الذاكرة الأساسي من آلة Java الافتراضية (JVM) المتعطلة. هذا الأمر تجريبي وغير مدعوم.

ملاحظة:

سيؤدي توصيل أداة jhsdb بعملية حية إلى تعليق العملية وربما تعطلها عند فصل المصحح.

يمكن تشغيل أداة jhsdb بأي من الأوضاع التالية:

jhsdb clhsdb
يبدأ مصحح الأخطاء التفاعلي سطر الأوامر.
jhsdb hsdb
يبدأ مصحح الأخطاء الرسومي التفاعلي.
jhsdb debugd
يبدأ خادم التصحيح البعيد.
jhsdb jstack
يطبع معلومات المكدس والأقفال.
jhsdb jmap
يطبع معلومات الذاكرة المؤقتة.
jhsdb jinfo
يطبع معلومات JVM الأساسية.
jhsdb jsnap
يطبع معلومات عدادات الأداء.
jhsdb أمر --help
يعرض الخيارات المتاحة للـ أمر.

خيارات وضع debugd

--serverid معرف الخادم
معرف فريد اختياري لخادم التصحيح هذا. هذا مطلوب إذا تم تشغيل خوادم تصحيح متعددة على نفس الجهاز.
--rmiport المنفذ
يحدد رقم المنفذ الذي يتم ربط موصل RMI به. إذا لم يتم تحديده، يتم استخدام منفذ متاح عشوائيًا.
--registryport المنفذ
يحدد منفذ سجل RMI. يتجاوز هذا الخيار خاصية النظام 'sun.jvm.hotspot.rmi.port'. إذا لم يتم تحديده، يتم استخدام خاصية النظام. إذا لم يتم تعيين خاصية النظام، يتم استخدام المنفذ الافتراضي 1099.
--hostname اسم المضيف
يحدد اسم المضيف الذي يرتبط به موصل RMI. يمكن أن تكون القيمة اسم مضيف أو عنوان IPv4/IPv6. يتجاوز هذا الخيار خاصية النظام 'java.rmi.server.hostname'. إذا لم يتم تحديده، يتم استخدام خاصية النظام. إذا لم يتم تعيين خاصية النظام، يتم استخدام اسم المضيف للنظام.

خيارات وضع jinfo

--flags
يطبع علامات VM.
--sysprops
يطبع خصائص نظام Java.
لا يوجد خيار
يطبع علامات VM وخصائص نظام Java.

خيارات وضع jmap

لا يوجد خيار
يطبع نفس المعلومات التي يطبعها Solaris pmap.
--heap
يطبع ملخص الذاكرة المؤقتة لـ java.
--binaryheap
يفرغ الذاكرة المؤقتة لـ java بتنسيق ثنائي hprof.
--dumpfile الاسم
اسم ملف التفريغ.
--histo
يطبع قائمة الذاكرة المؤقتة لكائنات java.
--clstats
يطبع إحصائيات محمل الفئة.
--finalizerinfo
يطبع معلومات حول الكائنات التي تنتظر الإنهاء.

خيارات وضع jstack
