الوصف

توجد مكافئات ماكرو لكل استدعاء دالة. نظرًا لأن أشكال الماكرو يمكن أن تكون أسرع ولها واجهة معالجة أخطاء أبسط من الدوال المكافئة، فهي الشكل المفضل لاستدعاء وظائف Judy1. راجع Judy1(3) لمزيد من المعلومات. يتم تضمين تعريفات استدعاءات الدوال هنا للاكتمال.

أحد التحديات عند استخدام استدعاءات دوال Judy1 هو تحديد ما إذا كان يجب تمرير مؤشر أو عنوان مؤشر. نظرًا لأن الدوال التي تعدل مصفوفة Judy1 يجب أن تعدل أيضًا المؤشر إلى مصفوفة Judy1، فيجب عليك تمرير عنوان المؤشر بدلاً من المؤشر نفسه. يمكن أن يؤدي هذا إلى أخطاء يصعب تصحيحها في البرنامج. في الممارسة العملية، تسمح الماكرو للمترجمين باكتشاف أخطاء البرمجة عند تمرير مؤشرات بدلاً من عناوين المؤشرات.

تحتوي استدعاءات دوال Judy1 على معلمة إضافية غير محددة في استدعاءات الماكرو. هذه المعلمة هي إما مؤشر إلى بنية أخطاء، أو NULL (في هذه الحالة لا يتم إرجاع معلومات تفصيلية).

في الأوصاف التالية، توصف الدوال من حيث كيفية استخدام وحدات الماكرو (فقط في حالة #define JUDYERROR_NOTEST 1). هذا هو الاستخدام المقترح لوحدات الماكرو بعد تصحيح أخطاء برنامجك بالكامل. عندما لا يتم تحديد وحدة الماكرو JUDYERROR_NOTEST، يتم إعلان بنية أخطاء لتخزين معلومات الخطأ التي ترجعها دوال Judy1 عند حدوث خطأ.

لاحظ موضع & في الدوال المختلفة.

يمكن أن يكون العائد 0 خطأ، أو عددًا صحيحًا صالحًا، أو يشير إلى حالة خاصة لمصفوفة ممتلئة بالكامل (فقط على أجهزة 32 بت). إذا لزم الأمر، يمكن استخدام الكود التالي لتمييز هذا العائد: 
JError_t JError;
Rc_word = Judy1Count(PJ1Array, Index1, Index2, &JError);
if (Rc_word == 0)
{
    if (JU_ERRNO(&JError) == JU_ERRNO_NONE)
        printf("Judy1 array population == 0\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_FULL)
        printf("Judy1 array population == 2^32\n");
    if (JU_ERRNO(&JError) == JU_ERRNO_NULLPPARRAY)
        goto NullArray;
    if (JU_ERRNO(&JError) >  JU_ERRNO_NFMAX)
        goto Null_or_CorruptArray;
}
