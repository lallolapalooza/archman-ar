jcmd-openjdk8(1)

الحزمة: jdk8-openjdk

التراخيص: LicenseRef-Java

jcmd(1) أدوات استكشاف الأخطاء وإصلاحها jcmd(1)

الاسم

jcmd - يرسل طلبات أوامر تشخيصية إلى آلة جافا الافتراضية (JVM) قيد التشغيل.

الملخص

jcmd [-l|-h|-help]
jcmd pid|main-class PerfCounter.print
jcmd pid|main-class -f filename
jcmd pid|main-class command[ arguments]

الوصف

تُستخدم الأداة jcmd لإرسال طلبات أوامر تشخيصية إلى JVM. يجب استخدامها على نفس الجهاز الذي تعمل عليه JVM، ويجب أن يكون لها نفس معرّفات المستخدم والمجموعة الفعالة التي تم استخدامها لتشغيل JVM.


ملاحظة
لاستدعاء الأوامر التشخيصية من جهاز بعيد أو بمعرفات مختلفة، يمكنك استخدام الواجهة com.sun.management.DiagnosticCommandMBean. لمزيد من المعلومات حول الواجهة DiagnosticCommandMBean، راجع وثائق API على http://docs.oracle.com/javase/8/docs/jre/api/management/extension/com/sun/management/DiagnosticCommandMBean.html

إذا قمت بتشغيل jcmd بدون وسائط أو بالخيار -l، فإنها تطبع قائمة بمعرفات عمليات Java قيد التشغيل مع الفئة الرئيسية ووسائط سطر الأوامر التي تم استخدامها لتشغيل العملية. طباعة jcmd بالخيار -h أو -help تطبع رسالة مساعدة الأداة.

إذا قمت بتحديد معرّف العملية (pid) أو الفئة الرئيسية (main-class) كوسيط أول، فإن jcmd ترسل طلب الأمر التشخيصي إلى عملية Java بالمعرّف المحدد أو إلى جميع عمليات Java بالاسم المحدد للفئة الرئيسية. يمكنك أيضًا إرسال طلب الأمر التشخيصي إلى جميع عمليات Java المتاحة عن طريق تحديد 0 كمعرّف للعملية. استخدم أحد الخيارات التالية كطلب للأمر التشخيصي:

Perfcounter.print

تطبع عدادات الأداء المتاحة لعملية Java المحددة. قد تختلف قائمة عدادات الأداء مع عملية Java.

-f filename

اسم الملف الذي سيتم منه قراءة الأوامر التشخيصية وإرسالها إلى عملية Java المحددة. يُستخدم فقط مع الخيار -f. يجب كتابة كل أمر في الملف على سطر واحد. يتم تجاهل الأسطر التي تبدأ برمز الرقم (#). ينتهي معالجة الملف عند قراءة جميع الأسطر أو عند قراءة سطر يحتوي على الكلمة المفتاحية stop.

command [arguments]

الأمر الذي سيتم إرساله إلى عملية Java المحددة. يمكن الحصول على قائمة الأوامر التشخيصية المتاحة لعملية معينة عن طريق إرسال الأمر help إلى هذه العملية. لكل أمر تشخيصي مجموعة خاصة به من الوسائط. لرؤية الوصف وبناء الجملة وقائمة الوسائط المتاحة لأمر ما، استخدم اسم الأمر كوسيط للأمر help.

ملاحظة: إذا كانت أي وسائط تحتوي على مسافات، فيجب وضعها بين علامتي اقتباس مفردتين أو مزدوجتين (' أو "). بالإضافة إلى ذلك، يجب عليك تهريب علامات الاقتباس المفردة أو المزدوجة بشرطة مائلة عكسية (\) لمنع shell نظام التشغيل من معالجة علامات الاقتباس. بدلاً من ذلك، يمكنك وضع هذه الوسائط بين علامتي اقتباس مفردتين ثم بين علامتي اقتباس مزدوجتين (أو بين علامتي اقتباس مزدوجتين ثم بين علامتي اقتباس مفردتين).

الخيارات

الخيارات حصرية متبادلة.

-f filename

يقرأ الأوامر من الملف المحدد. يمكن استخدام هذا الخيار فقط إذا قمت بتحديد معرّف العملية أو الفئة الرئيسية كوسيط أول. يجب كتابة كل أمر في الملف على سطر واحد. يتم تجاهل الأسطر التي تبدأ برمز الرقم (#). تنتهي معالجة الملف عند قراءة جميع الأسطر أو عند قراءة سطر يحتوي على الكلمة المفتاحية stop.

-h
-help

يطبع رسالة مساعدة.

-l

يطبع قائمة بمعرفات عمليات Java قيد التشغيل مع الفئة الرئيسية ووسائط سطر الأوامر.
