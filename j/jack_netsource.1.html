jack_netsource(1)

الحزمة: jack-example-tools

التراخيص: GPL2, GPL3

jack_netsource(1) دليل الأوامر العامة jack_netsource(1)

الاسم

jack_netsource - عميل رئيسي لشبكة Jack لسيد واحد

الملخص

jack_netsource [ -H اسم_المضيف ] [ خيارات ]

الوصف

jack_netsource الجانب الرئيسي لاتصال الشبكة. يمثل سيد jackd -dnet في رسم بياني رئيسي لـ jack. يتم تكوين معظم معلمات الاتصال عبر المصدر الشبكي، وسيقوم العبد بإعداد نفسه وفقًا لخيارات سطر الأوامر المعطاة لـ jack_netsource.
تسمح Netjack باتصالات صوتية بزمن استجابة منخفض عبر شبكات IP العامة. عند استخدام opus للضغط، من الممكن حتى إنشاء روابط عبر الأطلسي، مع زمن استجابة لا يتجاوز وقت الاستجابة الفعلي.
ولكن الاستخدام الرئيسي هو بالطبع شبكة محلية، حيث يمكنها تحقيق زمن استجابة يعادل فترة Jack واحدة.

الخيارات

-h نص المساعدة هذا
-H مضيف العبد

اسم مضيف Jack العبد
-o عدد القنوات

عدد قنوات تشغيل الصوت
-i عدد القنوات

عدد قنوات التقاط الصوت
-O عدد القنوات

عدد قنوات تشغيل MIDI
-I عدد القنوات

عدد قنوات التقاط MIDI
-n فترات

زمن استجابة الشبكة بفترات Jack
-p المنفذ

منفذ UDP الذي يستمع إليه العبد
-r منفذ الرد

منفذ UDP الذي نستمع إليه
-B منفذ الربط

منفذ الرد، للاستخدام في بيئات NAT
-b عمق البت

تعيين النقل لاستخدام 16 بت أو 8 بت
-P كيلوبت

استخدام ترميز Opus مع <kbits> لكل قناة
-m mtu

افتراض هذا MTU للرابط
-R N

التكرار: إرسال الحزم N مرات.
-e

تخطي تحويل ترتيب البايتات من مضيف إلى شبكة
-N اسم jack

يبلغ عن اسم عميل مختلف لـ jack
-s, --server اسم_الخادم

الاتصال بخادم jack المسمى اسم_الخادم
-h, --help

عرض نص المساعدة/الاستخدام
-v, --version

إخراج معلومات الإصدار والخروج

أمثلة

تشغيل رابط ثنائي الاتجاه بـ 4 قنوات صوتية بزمن استجابة فترة واحدة وبدون قنوات MIDI. تتدفق البيانات الصوتية غير المضغوطة عبر السلك:
على hostA:

jackd -d alsa
jack_netsource -H hostB -n1 -i4 -o4 -I0 -O0

على hostB:

jackd -d net
2022 4
