jinfo-openjdk11(1)

الحزمة: jdk11-openjdk

التراخيص: LicenseRef-Java

jinfo(1) أدوات استكشاف الأخطاء وإصلاحها jinfo(1)

الاسم

jinfo - إنشاء معلومات التكوين. هذا الأمر تجريبي وغير مدعوم.

الاستخدام

jinfo [ خيار ] pid
jinfo [ خيار ] executable core
jinfo [ خيار ] [ servier-id ] remote-hostname-or-IP
خيار
خيارات سطر الأوامر. انظر الخيارات.
pid
معرف العملية (PID) الذي سيتم طباعة معلومات التكوين الخاصة به. يجب أن تكون العملية عملية Java. للحصول على قائمة بعمليات Java قيد التشغيل على جهاز، استخدم أمر jps(1).
executable
ملف Java التنفيذي الذي تم منه إنتاج تفريغ النواة.
core
ملف النواة الذي سيتم طباعة معلومات التكوين الخاصة به.
remote-hostname-or-IP
اسم مضيف أو عنوان IP لخادم تصحيح الأخطاء عن بعد. انظر jsadebugd(1).
server-id
معرف فريد اختياري لاستخدامه عند تشغيل خوادم تصحيح أخطاء متعددة على نفس المضيف البعيد.

الوصف

يقوم الأمر jinfo بطباعة معلومات تكوين Java لعملية Java محددة أو ملف نواة أو خادم تصحيح أخطاء عن بعد. تشمل معلومات التكوين خصائص نظام Java وبيئات تشغيل Java الافتراضية (JVM) سطر الأوامر. إذا كانت العملية المحددة قيد التشغيل على JVM 64 بت، فقد تحتاج إلى تحديد الخيار -J-d64، على سبيل المثال: jinfo-J-d64 -sysprops pid.

هذه الأداة غير مدعومة وقد لا تكون متاحة في الإصدارات المستقبلية من JDK. في أنظمة Windows حيث dbgeng.dll غير موجود، يجب تثبيت أدوات تصحيح الأخطاء لنظام Windows لكي تعمل هذه الأدوات. يجب أن يحتوي متغير البيئة PATH على موقع jvm.dll المستخدم بواسطة العملية المستهدفة أو الموقع الذي تم إنتاج ملف تفريغ الانهيار منه. على سبيل المثال، set PATH=%JDK_HOME%\jre\bin\client;%PATH%.

الخيارات

بدون خيار
يطبع كلاً من علامات سطر الأوامر وخصائص نظام اسم-قيمة.
-flag name

يطبع اسم وقيمة علامة سطر الأوامر المحددة.
-flag [+|-]name

يمكّن أو يعطّل علامة سطر الأوامر المنطقية المحددة.
-flag name=value

يعيّن علامة سطر الأوامر المحددة إلى القيمة المحددة.
-flags

يطبع علامات سطر الأوامر التي تم تمريرها إلى JVM.
-sysprops

يطبع خصائص نظام Java كأزواج اسم-قيمة.
-h

يطبع رسالة مساعدة.
-help

يطبع رسالة مساعدة.
