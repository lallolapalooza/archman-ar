jsadebugd-openjdk8(1)

الحزمة: jdk8-openjdk

التراخيص: LicenseRef-Java

jsadebugd(1) أدوات استكشاف الأخطاء وإصلاحها jsadebugd(1)

الاسم

jsadebugd - يتصل بعملية Java أو ملف أساسي ويعمل كخادم تصحيح. هذه الأداة تجريبية وغير مدعومة.

الملخص

jsadebugd pid [ server-id ]
jsadebugd executable core [ server-id ]
pid
معرف العملية التي يتصل بها خادم التصحيح. يجب أن تكون العملية عملية Java. للحصول على قائمة بعمليات Java قيد التشغيل على جهاز، استخدم الأمر jps(1). لا يمكن أن يكون هناك أكثر من نسخة واحدة من خادم التصحيح متصلة بعملية واحدة.
executable
ملف Java التنفيذي الذي تم إنتاج تفريغ الأساس منه.
core
ملف الأساس الذي يجب أن يتصل به خادم التصحيح.
server-id
معرف فريد اختياري مطلوب عند بدء تشغيل خوادم تصحيح متعددة على نفس الجهاز. يجب على العملاء البعيدين استخدام هذا المعرف لتحديد خادم التصحيح المحدد للاتصال به. داخل جهاز واحد، يجب أن يكون هذا المعرف فريدًا.

الوصف

يقوم الأمر jsadebugd بالاتصال بعملية Java أو ملف أساسي ويعمل كخادم تصحيح. يمكن للعملاء البعيدين مثل jstack و jmap و jinfo الاتصال بالخادم عبر استدعاء الأساليب عن بعد لـ Java (RMI). قبل بدء تشغيل الأمر jsadebugd، ابدأ سجل RMI باستخدام الأمر rmiregistry كما يلي حيث $JAVA_HOME هو دليل تثبيت JDK:

rmiregistry -J-Xbootclasspath/p:$JAVA_HOME/lib/sajdi.jar

إذا لم يتم تشغيل سجل RMI، فسيقوم الأمر jsadebugd بتشغيل سجل RMI على منفذ قياسي (1099) داخليًا. يمكن إيقاف خادم التصحيح عن طريق إرسال SIGINT إليه. لإرسال SIGINT اضغط Ctrl+C.

ملاحظة: هذه الأداة غير مدعومة وقد تكون متاحة أو لا تكون متاحة في الإصدارات المستقبلية من JDK. في أنظمة Windows التي لا يوجد بها dbgeng.dll، يجب تثبيت أدوات التصحيح لنظام Windows لكي تعمل هذه الأدوات. يجب أن يحتوي متغير البيئة PATH على موقع jvm.dll المستخدمة بواسطة العملية المستهدفة أو الموقع الذي تم إنتاج ملف تفريغ التعطل منه. على سبيل المثال، set PATH=%JDK_HOME%\jre\bin\client;%PATH%.
