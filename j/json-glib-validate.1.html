الحزمة: json-glib

JSON-GLIB-VALIDATE(1) معالجة النص JSON-GLIB-VALIDATE(1)

الاسم

json-glib-validate - أداة التحقق من صحة JSON

الملخص

json-glib-validate [خيارات...] <ملف>

الوصف

يوفر json-glib-validate واجهة سطر أوامر بسيطة للتحقق من صحة بيانات JSON. يتيح لك سرد عناوين URI التي تشير إلى بيانات JSON والتحقق من أن البيانات تتوافق مع صيغة JSON.

يتم تحديد الموارد التي سيتم العمل عليها بواسطة وسيط FILE.

إذا كانت بيانات JSON صالحة، سيتم إنهاء json-glib-validate برمز خروج 0؛ إذا كانت البيانات غير صالحة، سيتم طباعة خطأ على stderr وسيتم إنهاء json-glib-validate برمز خروج غير صفري.

الخيارات

-h, --help
