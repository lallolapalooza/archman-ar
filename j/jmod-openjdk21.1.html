NAME

jmod - create and manage Java JMOD archives

SYNOPSIS

jmod create [OPTION]... JMODFILE

jmod extract [OPTION]... JMODFILE

jmod list [OPTION]... JMODFILE...

jmod describe JMODFILE...

jmod hash [OPTION]... JMODFILE...

DESCRIPTION

The jmod command is used to create and manage Java JMOD archives. A JMOD archive is a directory structure that contains the module information, the module's code, and other resources.

The JMOD archive format is defined in JEP 320, "Remove the Experimental Runtime Image."

The following is an example of what happens when you try to link a leaf module (in this example, ma) with a required module (mb), and the hash value recorded in the required module doesn't match that of the leaf module.

1.
Create and compile the following .java files:
•
jmodhashex/src/ma/module-info.java

module ma {
  requires mb;
}
•
jmodhashex/src/mb/module-info.java

module mb {
}
•
jmodhashex2/src/ma/module-info.java

module ma {
  requires mb;
}
•
jmodhashex2/src/mb/module-info.java

module mb {
}
2.
Create a JMOD archive for each module. Create the directories jmodhashex/jmods and jmodhashex2/jmods, and then run the following commands from the jmodhashex directory, then from the jmodhashex2 directory:
•
jmod create --class-path mods/ma jmods/ma.jmod
•
jmod create --class-path mods/mb jmods/mb.jmod
3.
Optionally preview the jmod hash command. Run the following command from the jmodhashex directory:

jmod hash --dry-run -module-path jmods --hash-modules .*

The command prints the following:


Dry run:
mb
  hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a

This indicates that the jmod hash command (without the --dry-run option) will record the hash value of the leaf module ma in the module mb.

4.
Record hash values in the JMOD archive files contained in the jmodhashex directory. Run the following command from the jmodhashex directory:

jmod hash --module-path jmods --hash-modules .*

The command prints the following:

Hashes are recorded in module mb

5.
Print information about each JMOD archive contained in the jmodhashex directory. Run the highlighted commands from the jmodhashex directory:

jmod describe jmods/ma.jmod
ma
  requires mandated java.base
  requires mb
jmod describe jmods/mb.jmod
mb
  requires mandated java.base
  hashes ma SHA-256 07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a
6.
Attempt to create a runtime image that contains the module ma from the directory jmodhashex2 but the module mb from the directory jmodhashex. Run the following command from the jmodhashex2 directory:
•
Linux and macOS:

jlink --module-path $JAVA_HOME/jmods:jmods/ma.jmod:../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

•
Windows:

jlink --module-path %JAVA_HOME%/jmods;jmods/ma.jmod;../jmodhashex/jmods/mb.jmod --add-modules ma --output ma-app

The command prints an error message similar to the following:


Error: Hash of ma (a2d77889b0cb067df02a3abc39b01ac1151966157a68dc4241562c60499150d2) differs to
expected hash (07667d5032004b37b42ec2bb81b46df380cf29e66962a16481ace2e71e74073a) recorded in mb

OPTIONS FOR JMOD

jmod create

Create a JMOD archive.

--class-path classpath
Specify a list of directories and JAR files to search for class files.
--help
Print the help message.

jmod extract

Extract the contents of a JMOD archive.

--dir dir
Extract the contents of the JMOD archive into the specified directory.
--help
Print the help message.

jmod list

List the contents of one or more JMOD archives.

--help
Print the help message.

jmod describe

Describe the contents of one or more JMOD archives.

--help
Print the help message.

EXTRA OPTIONS FOR JMOD

jmod hash

Compute and record hash values for modules.

--dry-run
Print the hash values that would be recorded without actually modifying the JMOD archives.
--hash-modules pattern
Specify a regular expression pattern to match module names for which hash values should be computed and recorded.
--help
Print the help message.
--module-path path
Specify a list of directories in which to find module archives.

JMOD CREATE EXAMPLE

Create a JMOD archive named ma.jmod from the classes in the `mods/ma` directory:

jmod create --class-path mods/ma jmods/ma.jmod

JMOD HASH EXAMPLE

Compute and record hash values for all modules found in the `jmods` directory, and store them in the `mb.jmod` archive:

jmod hash --module-path jmods --hash-modules .*
