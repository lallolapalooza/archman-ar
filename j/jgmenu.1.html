jgmenu(1)

الحزمة: jgmenu

التراخيص: GPL

OPTIONS

-config-file=file
Use file as configuration file. See Configuration File section below for details.
-dmenu-mode=bool
Enable or disable dmenu mode. In this mode, jgmenu will print selected item to stdout and exit. Default is 0.
-fn font
Use font font. See X Logical Font Description. Default is system default.
-h
Show help message and exit.
-i
Ignore case in search input.
-m margin
Set top and bottom margins to margin pixels. Default is 5.
-p position
Set menu position. Default is top-left.
-s
Enable smart mode. In this mode, the menu will present itself in a way that is consistent with the following variables: menu_halign, menu_valign, menu_width, menu_height.
-t theme
Load theme from theme file. See THEMES section. Default is system default.
-v
Show version information and exit.
-x menu_x
Set left margin to menu_x pixels. Default is 0.
-y menu_y
Set top margin to menu_y pixels. Default is 0.

EXAMPLES

•
Show a menu with entries from the file ~/data/menu.csv:
jgmenu --config-file=~/data/jgmenurc --csv-cmd="cat ~/data/menu.csv"
•
Show a typical application menu:
jgmenu < /etc/jgmenu/menu.csv
•
Show a menu created by the lx command:
jgmenu --csv-cmd=lx
•
Show a menu using the mint-2 theme and a larger font:
jgmenu -t mint-2 -fn "DejaVu Sans Mono 10"
•
Show a menu where selected item is printed to stdout:
jgmenu --dmenu-mode

CONFIGURATION FILE

If no file is specified using the –config-file= option, the XDG Base Directory Specification is adhered to. I.e:

•
Global config in ${XDG_CONFIG_DIRS:-/etc/xdg}
•
User config override in ${XDG_CONFIG_HOME:-$HOME/.config}

For most users ~/.config/jgmenu/jgmenurc is appropriate.

Global config variables are set in the following order (i.e. bottom of list has higher precedence):

•
built-in defaults (config.c)
•
tint2rc config file (can be specified by TINT2_CONFIG environment variable)
•
jgmenurc config file (can be specified by –config-file=)
•
command line arguments

Syntax

Lines beginning with # are ignored.

All other lines are recognised as setting variables in the format

key = value

White spaces are mostly ignored.

Values

Unless otherwise specified, values as treated as simple strings.

Here follow some specific types:

boolean
When a variable takes a boolean value, only 0 and 1 are accepted. 0 means false; 1 means true.
integer
When a variable takes an integer value, only numerical values are accepted. The only valid characters are digits (0-9) and minus-sign. All integer variables relating to geometry and position are interpreted as pixel values unless otherwise specified.
color
When a variable takes a color value, only the syntax #rrggbb aa is recognised, where rr, gg and bb represent hexadecimal values (00-ff) for the colours red, green and blue respectively; and aa stands for the alpha channel value expressed as a percentage (0-100) (i.e. 100 means no transparency and 0 means fully transparent.) For example #ff0000 100 represents red with no transparency, whereas #000088 50 means dark blue with 50% transparency.
pathname
When a variable takes a pathname value, it is evaluated as a string. If the first character is tilde (~), it will be replaced by the the environment variable $HOME just as a shell would expand it.

DESCRIPTION

jgmenu is a generic menu system written in C, used primarily with the X Window System.

It supports customisable menus (using a custom format or reading from the standard desktop entry files), and has extensive options for customisation of appearance and behaviour.

jgmenu is typically invoked by a hotkey or a desktop launcher. jgmenu can read from a number of sources, and can be configured to run commands when menu items are selected. It can be used to launch applications, open files, or perform any other command.

This document describes the configuration file, the command line options, and the structure of the menu system.

OPTIONS

The following options are available:

-p, --print
Print the menu to stdout in the specified format and exit. By default, this is the CSV format. For example, to print the menu in the format expected by dmenu, use -p --dmenu.
-d, --dmenu
Use the dmenu format for output when -p is specified.
-i, --iconic
Use icons in the menu. This is the default behaviour.
-t, --text
Do not use icons in the menu. This is the default behaviour if icons are not found.
-c, --color
Use colours in the menu. This is the default behaviour.
-o, --opacity
Use opacity in the menu. This is the default behaviour.
-W, --width=N
Set the menu width to N pixels. Defaults to 150.
-H, --height=N
Set the menu height to N pixels. Defaults to 400.
-A, --alpha=N
Set the menu opacity to N (0-255). Defaults to 255 (fully opaque).
-f, --font=fontname
Use fontname for the menu text. Defaults to Sans.
-S, --menu-style=style
Set the menu style to style. Available styles are: vertical, horizontal, none.
-R, --reverse
Reverse the order of menu items.
-I, --icon-theme=themename
Use the specified icon theme. Defaults to the system icon theme.
-s, --simple
Use a simple menu style (no icons, no colours). This is equivalent to setting --menu-style=none --no-color --no-opacity.
--vsimple
Use a very simple menu style (no icons, no colours, no startup script). This is equivalent to setting --menu-style=none --no-color --no-opacity --no-startup.
-N, --near
Position the menu near the mouse pointer.
-C, --center, --centre
Position the menu in the center of the screen.
-M, --mouse
Position the menu at the mouse pointer. This is the default behaviour.
--no-mouse
Do not position the menu at the mouse pointer.
-a, --auto-scroll
Automatically scroll the menu if the number of items exceeds the menu height.
--no-auto-scroll
Do not automatically scroll the menu.
-h, --hide-on-select
Hide the menu after an item is selected.
--no-hide-on-select
Do not hide the menu after an item is selected.
-v, --version
Print version information and exit.
-?, --help
Print help information and exit.

USER INTERFACE

jgmenu provides a graphical menu system. The appearance and behaviour of the menu can be customized via a configuration file and command line options.

The menu can be displayed in a vertical or horizontal layout, and can include icons, text, or both. The menu can also be configured to use colors, opacity, and different fonts.

When an item is selected, jgmenu can either execute a command, open a file, or perform a custom action. The menu can be hidden automatically after selection, or remain visible.

CONFIGURATION FILE

jgmenu uses a configuration file located at $HOME/.config/jgmenu/jgmenurc. If this file does not exist, jgmenu will use its default settings.

The configuration file is divided into sections, each starting with a section header in square brackets (e.g., [menu]).

The following options can be set in the configuration file:

[menu]
menu_padding_top=N
Set the top padding of the menu to N pixels.
menu_padding_bottom=N
Set the bottom padding of the menu to N pixels.
menu_padding_left=N
Set the left padding of the menu to N pixels.
menu_padding_right=N
Set the right padding of the menu to N pixels.
menu_style=style
Set the menu style to style. Available styles are: vertical, horizontal, none.
menu_width=N
Set the menu width to N pixels.
menu_height=N
Set the menu height to N pixels.
menu_font=fontname
Use fontname for the menu text.
menu_color_normal=color
Set the normal text color.
menu_color_selected=color
Set the selected text color.
menu_color_background=color
Set the background color.
menu_opacity=N
Set the menu opacity to N (0-255).
[item]
item_margin_x=N
Set the horizontal margin of menu items to N pixels.
item_margin_y=N
Set the vertical margin of menu items to N pixels.
icon_size=N
Set the icon size to N pixels.
icon_to_text_spacing=N
Set the spacing between icons and text to N pixels.
arrow_width=N
Set the width of the arrow for submenus to N pixels.
[position]
position=pos
Set the menu position to pos. Available options are: mouse, center, near.
menu_margin_x=N
Set the horizontal margin of the menu to N pixels.
menu_margin_y=N
Set the vertical margin of the menu to N pixels.
sub_spacing=N
Set the spacing between submenus to N pixels.
[behavior]
auto_scroll=true|false
Enable or disable auto scrolling.
hide_on_select=true|false
Enable or disable hiding the menu on item selection.

Comments in the configuration file start with a #.

Inter-Process Communication (IPC)

jgmenu supports inter-process communication (IPC) via a Unix domain socket. This allows other applications to control jgmenu, such as opening, closing, or updating the menu.

The IPC socket is typically located at $HOME/.cache/jgmenu/jgmenu.sock. You can specify a different location using the --socket option when starting jgmenu.

The following commands can be sent to jgmenu via the socket:

open
Open the menu.
close
Close the menu.
update
Update the menu (re-read configuration and menu files).
restart
Restart jgmenu.
quit
Quit jgmenu.

Example: To open the menu using netcat:

echo "open" | nc -U $HOME/.cache/jgmenu/jgmenu.sock

HOOKS

A hook in jgmenu is a rule which optionally triggers a command and then performs a restart if a file or directory has changed since the last time the instance of jgmenu was mapped (=made visible - normally by running jgmenu_run).

Hooks are specified in the file $HOME/.config/jgmenu/hooks are take the format

<file>,<command>

For example, to synchronise with the GTK theme, use this hook:

~/.config/gtk-3.0/settings.ini,jgmenu_run gtktheme

Leave the <command> empty to just restart.

A number of restart-hooks are built-in by default, for example ~/.config/jgmenu/{jgmenurc,append.csv,prepend.csv} and /usr/share/applications.

To list all the built-in hooks, use the keyword print in the hook file (on a line on its own). In order to remove all the built-in hooks, use the keyword clear.

STARTUP SCRIPT

Unless the --vsimple argument is used, the file ~/.config/jgmenu/startup is executed on initial startup.
