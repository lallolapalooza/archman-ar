NAME

jfs_debugfs

JFS filesystem debugger

SYNOPSIS

jfs_debugfs [ -f logfile ] [ -i inode ] [ -p ] [ -w ] [ -V ] device

DESCRIPTION

jfs_debugfs is an interactive tool for examining and manipulating JFS filesystem structures. It can be used to dump filesystem metadata, and to modify it. Most operations require that the filesystem not be mounted, or at least not be mounted read-write. The JFS journal log may be specified with the -f option.

If the filesystem has been journaled, the journal log file must be supplied with the -f option. Otherwise, jfs_debugfs will try to find the journal log by itself.

You can specify an inode to start debugging with the -i option. If no inode is specified, then inode 2 (the root directory) is used.

If the -p option is specified, jfs_debugfs will print the filesystem parameters before starting the subcommand mode.

If the -w option is specified, jfs_debugfs will open the filesystem read-write. Use with caution!

The -V option prints the version and exits.

COMMANDS

When jfs_debugfs starts, it enters subcommand mode. It prints a prompt, and waits for input. The following subcommands are supported:

?
Print a list of available commands.
b
Print the contents of the block group descriptor table.
c
Print the contents of the JFS control block.
d directory_inode
Print the contents of the specified directory inode.
e inode
Print the contents of the specified inode.
f
Print the filesystem parameters.
i inode [file_set]
Print the contents of the specified inode in the specified file set. The file set is the inode's file set number, which is usually 0. The inode is given in decimal.
l
Print the contents of the journal log.
m inode [file_set]
Modify the specified inode in the specified file set. The file set is the inode's file set number, which is usually 0. The inode is given in decimal.
p
Print the contents of the filesystem parameters.
q
Quit jfs_debugfs.
s
Print the filesystem state.
t
Print the filesystem statistics.
v
Print the contents of the VFS inode list.
x
Toggle subcommand mode.

When subcommand mode is toggled on with the x command, you can navigate the filesystem tree. The current node is indicated by a pointer. The following subcommands are supported:

l
visit left sibling
m
modify current node
p
visit parent node (not parent directory)
r
visit right sibling
[0-9]
visit the n'th child node
x
exit subcommand mode

REPORTING BUGS

If you find a bug in JFS or jfs_debugfs, please report it via the bug tracking system ("Report Bugs" section) of the JFS project web site:

http://jfs.sourceforge.net/

Please send as much pertinent information as possible, including the complete output of running jfs_fsck with the -v and -n options on the JFS device.

الاسم

jfs_debugfs

مصحح أخطاء نظام ملفات JFS

الملخص

jfs_debugfs [ -f logfile ] [ -i inode ] [ -p ] [ -w ] [ -V ] device

الوصف

jfs_debugfs هو أداة تفاعلية لفحص والتلاعب ببنيات نظام ملفات JFS. يمكن استخدامه لتفريغ بيانات نظام الملفات الوصفية، وتعديلها. تتطلب معظم العمليات أن لا يكون نظام الملفات محملاً، أو على الأقل ليس محملاً للقراءة والكتابة. يمكن تحديد ملف سجل JFS باستخدام الخيار -f.

إذا كان نظام الملفات قد تم تسجيله، فيجب توفير ملف السجل باستخدام الخيار -f. وإلا، سيحاول jfs_debugfs العثور على سجل JFS بنفسه.

يمكنك تحديد inode لبدء التصحيح باستخدام الخيار -i. إذا لم يتم تحديد inode، فسيتم استخدام inode 2 (الدليل الجذر).

إذا تم تحديد الخيار -p، فسيقوم jfs_debugfs بطباعة معلمات نظام الملفات قبل بدء وضع الأوامر الفرعية.

إذا تم تحديد الخيار -w، فسيقوم jfs_debugfs بفتح نظام الملفات للقراءة والكتابة. استخدمه بحذر!

الخيار -V يطبع الإصدار ويخرج.

الأوامر

عند بدء jfs_debugfs، فإنه يدخل وضع الأوامر الفرعية. يطبع موجه انتظار، وينتظر الإدخال. الأوامر الفرعية التالية مدعومة:

?
طباعة قائمة بالأوامر المتاحة.
b
طباعة محتويات جدول وصف مجموعة الكتل.
c
طباعة محتويات كتلة تحكم JFS.
d directory_inode
طباعة محتويات inode الدليل المحدد.
e inode
طباعة محتويات inode المحدد.
f
طباعة معلمات نظام الملفات.
i inode [file_set]
طباعة محتويات inode المحدد في مجموعة الملفات المحددة. مجموعة الملفات هي رقم مجموعة ملفات inode، والتي تكون عادة 0. يتم تقديم inode بالصيغة العشرية.
l
طباعة محتويات سجل JFS.
m inode [file_set]
تعديل inode المحدد في مجموعة الملفات المحددة. مجموعة الملفات هي رقم مجموعة ملفات inode، والتي تكون عادة 0. يتم تقديم inode بالصيغة العشرية.
p
طباعة محتويات معلمات نظام الملفات.
q
الخروج من jfs_debugfs.
s
طباعة حالة نظام الملفات.
t
طباعة إحصائيات نظام الملفات.
v
طباعة محتويات قائمة VFS inode.
x
تبديل وضع الأوامر الفرعية.

عند تبديل وضع الأوامر الفرعية باستخدام الأمر x، يمكنك التنقل في شجرة نظام الملفات. يتم الإشارة إلى العقدة الحالية بواسطة مؤشر. الأوامر الفرعية التالية مدعومة:

l
زيارة الأخ الأيسر
m
تعديل العقدة الحالية
p
زيارة العقدة الأب (ليس الدليل الأب)
r
زيارة الأخ الأيمن
[0-9]
زيارة العقدة الابنة n
x
الخروج من وضع الأوامر الفرعية

الإبلاغ عن الأخطاء

إذا وجدت خطأ في JFS أو jfs_debugfs، فيرجى الإبلاغ عنه عبر نظام تتبع الأخطاء (قسم "Report Bugs") في موقع JFS المشروع على الويب:

http://jfs.sourceforge.net/

يرجى إرسال أكبر قدر ممكن من المعلومات ذات الصلة، بما في ذلك الإخراج الكامل لتشغيل jfs_fsck مع الخيارات -v و -n على جهاز JFS.
