ملاحظة: بدون تعريف 'JUDYERROR_NOTEST'، فإن 'goto out_of_memory_handling' لن يتم تنفيذه أبداً وسيتم تحسينه من قبل المترجم. سيتم استخدام الطريقة الافتراضية -- سيقوم الماكرو بطباعة معلومات الخطأ إذا حدث خطأ كما هو موضح أعلاه.

مع تعريف 'JUDYERROR_NOTEST'، سيتم تنفيذ 'goto out_of_memory_handling' عند حدوث خطأ -- والذي يجب أن يحدث فقط عندما تفشل malloc().

3) طريقة الماكرو JUDYERROR() المحددة من قبل المستخدم

يوفر الماكرو JUDYERROR() (في Judy.h) مرونة في التعامل مع إرجاع الأخطاء حسب الحاجة لتناسب برنامجك مع الاستمرار في استخدام ماكرو مصفوفة Judy بدلاً من استدعاءات الدوال. يمكنك استخدام ماكرو JUDYERROR() مختلف ليناسب احتياجاتك. المثال التالي هو بديل محتمل للافتراضي. يتم استخدامه للتمييز بين نوعين من الأخطاء (الموصوفة أعلاه)، ويختبر صراحةً أخطاء JU_ERRNO_NOMEM المتبقية الممكنة في برنامجك.

// هذا مثال لماكرو واجهة برمجة التطبيقات Judy للاستمرار عند نفاد الذاكرة
// والطباعة والخروج (1) عند حدوث أي خطأ آخر.
#ifndef JUDYERROR_NOTEST
#include <stdio.h>  // مطلوب لـ fprintf()
// هذا هو الماكرو الذي تستخدمه واجهات برمجة تطبيقات ماكرو Judy لرموز الإرجاع -1:
#define JUDYERROR(CallerFile, CallerLine, JudyFunc, JudyErrno, JudyErrID) \
{                                                                         \
    if ((JudyErrno) != JU_ERRNO_NOMEM) /* ! فشل malloc() */         \
    {                                                                     \
        (void) fprintf(stderr, "File '%s', line %d: %s(), "               \
            "JU_ERRNO_* == %d, ID == %d\n",                               \
            CallerFile, CallerLine,                                       \
            JudyFunc, JudyErrno, JudyErrID);                              \
        exit(1);                                                          \
    }                                                                     \
}
#endif // لم يتم تعريف JUDYERROR_NOTEST
يجب تضمين ماكرو معالجة الأخطاء هذا قبل عبارة #include <Judy.h> في برنامجك.
