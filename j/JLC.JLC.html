JLC(JLC)

الحزمة: judy

التراخيص: LGPL

JudyL(3) دليل وظائف المكتبة JudyL(3)

الاسم

وحدات JudyL - مكتبة C لإنشاء والوصول إلى مصفوفة ديناميكية من الكلمات، باستخدام كلمة كفهرس.

الملخص

cc [flags] sourcefiles -lJudy
#include <Judy.h>
int      Rc_int;                          // رمز الإرجاع - عدد صحيح
Word_t   Rc_word;                         // رمز الإرجاع - كلمة غير موقعة
Word_t   Index, Index1, Index2, Nth;
PWord_t  PValue;                          // مؤشر للقيمة المرجعة
Pvoid_t PJLArray = (Pvoid_t) NULL;        // تهيئة مصفوفة JudyL
JLI( PValue,  PJLArray, Index);          // JudyLIns()
JLD( Rc_int,  PJLArray, Index);          // JudyLDel()
JLG( PValue,  PJLArray, Index);          // JudyLGet()
JLC( Rc_word, PJLArray, Index1, Index2); // JudyLCount()
JLBC(PValue,  PJLArray, Nth, Index);     // JudyLByCount()
JLFA(Rc_word, PJLArray);                 // JudyLFreeArray()
JLMU(Rc_word, PJLArray);                 // JudyLMemUsed()
JLF( PValue,  PJLArray, Index);          // JudyLFirst()
JLN( PValue,  PJLArray, Index);          // JudyLNext()
JLL( PValue,  PJLArray, Index);          // JudyLLast()
JLP( PValue,  PJLArray, Index);          // JudyLPrev()
JLFE(Rc_int,  PJLArray, Index);          // JudyLFirstEmpty()
JLNE(Rc_int,  PJLArray, Index);          // JudyLNextEmpty()
JLLE(Rc_int,  PJLArray, Index);          // JudyLLastEmpty()
JLPE(Rc_int,  PJLArray, Index);          // JudyLPrevEmpty()

الوصف

مصفوفة JudyL هي المكافئ لمصفوفة من القيم بحجم كلمة. يتم الوصول إلى القيمة بواسطة فهرس (مفتاح). قد تكون المصفوفة متفرقة، وقد يكون الفهرس أي رقم بحجم كلمة. يتم تخصيص الذاكرة لدعم المصفوفة عند إدراج أزواج الفهرس/القيمة، ويتم تحريرها عند حذف أزواج الفهرس/القيمة. يمكن أيضًا التفكير في مصفوفة JudyL كمخطط، أي "رسم خرائط" كلمة إلى كلمة/مؤشر آخر.

كما هو الحال مع مصفوفة عادية، لا توجد فهارس مكررة في مصفوفة JudyL.

يمكن استخدام القيمة كقيمة عددية، أو مؤشر إلى بنية أو كتلة بيانات (أو حتى مصفوفة Judy أخرى).

يتم تخصيص مصفوفة JudyL بمؤشر NULL

Pvoid_t PJLArray = (Pvoid_t) NULL;

باستخدام وحدات الماكرو الموضحة هنا، بدلاً من استدعاءات وظائف JudyL، ترسل معالجة الأخطاء الافتراضية رسالة إلى الخطأ القياسي وتنهي البرنامج باستخدام exit(1);. لطرق معالجة الأخطاء الأخرى، انظر قسم الأخطاء. JLI( PValue, PJLArray, Index); // JudyLIns()

نظرًا لأن أشكال الماكرو تكون أحيانًا أسرع ولها واجهة معالجة أخطاء أبسط من وظائف JudyL المكافئة، فهي الطريقة المفضلة لاستدعاء وظائف JudyL.


JLI(PValue, PJLArray, Index) // JudyLIns()
إدراج فهرس و قيمة في مصفوفة JudyL PJLArray. إذا تم إدراج الفهرس بنجاح، يتم تهيئة القيمة إلى 0. إذا كان الفهرس موجودًا بالفعل، فلا يتم تعديل القيمة.
إرجاع PValue يشير إلى القيمة. يمكن لبرنامجك استخدام هذا المؤشر لقراءة أو تعديل القيمة حتى يتم تنفيذ JLI() (إدراج) أو JLD() (حذف) أو JLFA() (تحرير المصفوفة) التالية على PJLArray. أمثلة:
*PValue = 1234;
Value = *PValue;
إرجاع PValue مضبوط على PJERR إذا حدث فشل في malloc(). ملاحظة: JLI() و JLD() يعيدان تنظيم مصفوفة JudyL. لذلك، يصبح PValue المرجع من استدعاءات JudyL السابقة غير صالح ويجب إعادة الحصول عليه.

JLD(Rc_int, PJLArray, Index) // JudyLDel()
حذف زوج الفهرس/القيمة من مصفوفة JudyL.
إرجاع Rc_int مضبوط على 1 إذا نجح. إرجاع Rc_int مضبوط على 0 إذا لم يكن الفهرس موجودًا. إرجاع Rc_int مضبوط على JERR إذا حدث فشل في malloc().

JLG(PValue, PJLArray, Index) // JudyLGet()
الحصول على المؤشر PValue المرتبط بـ الفهرس في مصفوفة Judy PJLArray.
إرجاع PValue يشير إلى القيمة. إرجاع PValue مضبوط على NULL إذا لم يكن الفهرس موجودًا. إرجاع PValue مضبوط على PJERR إذا حدث فشل في malloc().

JLC(Rc_word, PJLArray, Index1, Index2) // JudyLCount()
عد عدد الفهارس الموجودة في مصفوفة JudyL PJLArray بين Index1 و Index2 (بما في ذلك).
إرجاع Rc_word مضبوط على العدد. يمكن أن تكون القيمة المرجعة 0 صالحة كعدد.
لعد جميع الفهارس الموجودة في مصفوفة JudyL، استخدم:
JLC(Rc_word, PJLArray, 0, -1);

JLBC(PValue, PJLArray, Nth, Index) // JudyLByCount()
تحديد موقع Nth فهرس موجود في مصفوفة JudyL PJLArray (Nth = 1 يرجع الفهرس الأول الموجود).
إرجاع PValue يشير إلى القيمة الخاصة به و Index مضبوط على Nth فهرس إذا تم العثور عليه، وإلا إرجاع PValue مضبوط على NULL (قيمة Index غير محددة).

JLFA(Rc_word, PJLArray) // JudyLFreeArray()
بالنظر إلى مؤشر إلى مصفوفة JudyL، قم بتحرير المصفوفة بأكملها (أسرع بكثير من استخدام حلقة JLN()، JLD()).
إرجاع Rc_word مضبوط على عدد البايتات المحررة و PJLArray مضبوط على NULL.

JLMU(Rc_word, PJLArray) // JudyLMemUsed()
إرجاع Rc_word مضبوط على عدد البايتات من الذاكرة التي تم malloc()ed بواسطة PJLArray. هذه روتينية سريعة جدًا، ويمكن استخدامها قبل وبعد استدعاء JLI() أو JLD() مع تأثير أداء قليل.

وظائف بحث JudyL
تسمح لك JLF()، JLN()، JLL()، JLP() بالبحث عن فهارس في المصفوفة. يمكنك البحث بشكل شامل أو حصري، في اتجاهات أمامية أو عكسية. إذا نجحت، يتم إرجاع Index مضبوطًا على الفهرس الذي تم العثور عليه، ويتم إرجاع PValue مضبوطًا على مؤشر إلى القيمة الخاصة بالفهرس. إذا فشلت، يتم إرجاع PValue مضبوطًا على NULL، ولا يحتوي Index على أي معلومات مفيدة. يجب اختبار PValue للقيمة غير NULL قبل استخدام Index، نظرًا لأن فشل البحث ممكن.
تسمح لك JLFE()، JLNE()، JLLE()، JLPE() بالبحث عن فهارس غير موجودة ("فارغة") في المصفوفة. يمكنك البحث بشكل شامل أو حصري، في اتجاهات أمامية أو عكسية. إذا نجحت، يتم إرجاع Index مضبوطًا على فهرس غير موجود ("فارغ")، ويتم إرجاع Rc_int مضبوطًا على 1. إذا فشلت، يتم إرجاع Rc_int مضبوطًا على 0، ولا يحتوي Index على أي معلومات مفيدة. يجب التحقق من Rc_int قبل استخدام Index، نظرًا لأن فشل البحث ممكن.

JLF(PValue, PJLArray, Index) // JudyLFirst()
البحث (بشكل شامل) عن أول فهرس موجود يساوي أو أكبر من الفهرس الممرر. (ابدأ بـ Index = 0 للعثور على أول فهرس في المصفوفة.) يتم استخدام JLF() عادةً لبدء مسح بترتيب أبجدي للفهارس الموجودة في مصفوفة JudyL.

JLN(PValue, PJLArray, Index) // JudyLNext()
البحث (بشكل حصري) عن الفهرس التالي الموجود الأكبر من الفهرس الممرر. يتم استخدام JLN() عادةً لمتابعة مسح بترتيب أبجدي للفهارس الموجودة في مصفوفة JudyL، أو لتحديد موقع "مجاور" لفهرس معين.
