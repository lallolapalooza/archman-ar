X11__Protocol__Connection(3pm)

الحزمة: perl-x11-protocol

التراخيص: GPL, PerlArtistic

Protocol::Connection(3) وثائق Perl المساهمة من قبل المستخدم Protocol::Connection(3)

الاسم

X11::Protocol::Connection - فئة أساسية مجردة لوحدة Perl لعمليات الاتصال بين عميل وخادم X11

الملخص

# في وحدة كائن الاتصال
package X11::Protocol::Connection::CarrierPigeon;
use X11::Protocol::Connection;
@ISA = ('X11::Protocol::Connection');
sub open { ... }
sub give { ... }
sub get { ... }
sub fh { ... }
...
# في البرنامج
$connection = X11::Protocol::Connection::CarrierPigeon
  ->open($host, $display_number);
$x = X11::Protocol->new($connection);
$connection->give($data);
$reply = unpack("I", $connection->get(4));
use IO::Select;
$sel = IO::select->new($connection->fh);
if ($sel->can_read == $connection->fh) ...

الوصف

هذه الوحدة هي فئة أساسية مجردة لمختلف وحدات X11::Protocol::Connection::* التي توفر اتصالات لخوادم X لوحدة X11::Protocol. توفر نماذج أولية للطرق التالية:

open

$conn = X11::Protocol::Connection::Foo->open($host, $display_num)

افتح اتصالاً بالشاشة المحددة (مرقمة من 0) على $host المحدد.

give

$conn->give($data)

أرسل البيانات المعطاة إلى الخادم. عادة، تُستخدم هذه الطريقة فقط بواسطة وحدة البروتوكول نفسها.

get

$data = $conn->get($n)

اقرأ $n بايت من البيانات من الخادم. عادة، تُستخدم هذه الطريقة فقط بواسطة وحدة البروتوكول نفسها.

fh

$filehandle = $conn->fh

أرجع كائنًا مناسبًا للاستخدام كمقبض ملف. هذا مفيد بشكل أساسي لإجراء select() واستدعاءات النظام المماثلة.
