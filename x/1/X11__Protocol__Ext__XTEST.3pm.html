NAME

X11::Protocol::Ext::XTEST — XTEST extension for Perl

SYNOPSIS

 use X11::Protocol::Ext::XTest;

 my $proto = X11::Protocol::Connection->new;
 $proto->init_extension('XTEST');

 $proto->XTestFakeKeyEvent($key, 1, 0, 0);
 $proto->XTestFakeKeyEvent($key, 0, 0, 0);
 $proto->XTestFakeMotionEvent(100, 200, 0);
 $proto->XTestFakeButtonEvent(1, 1, 0, 0);
 $proto->XTestFakeButtonEvent(1, 0, 0, 0);
 $proto->XTestGrabControl(1);
 $proto->XTestGrabControl(0);

DESCRIPTION

The XTEST extension provides the ability to simulate keyboard and mouse events, and to control client behavior during server grabs.

This module implements the XTEST protocol extension as specified by the X Consortium.

It exports the following functions:

XTestFakeKeyEvent, XTestFakeMotionEvent, XTestFakeButtonEvent, XTestFakeCrossingEvent, XTestFakeProximityEvent, XTestFakeTRE
These functions allow you to simulate keyboard and mouse events. They take the following arguments:
  • $key: The keycode for keyboard events, or button number for button events.
  • $is_press: 1 for key press or button press, 0 for key release or button release.
  • $delay: A delay in milliseconds before sending the event.
  • $event_type: The type of event to send. For XTestFakeKeyEvent, this is usually 0 for key press and 1 for key release. For XTestFakeButtonEvent, this is usually 4 for button press and 5 for button release.
  • $x, $y: The coordinates for motion events.
  • $detail: The detail for crossing and proximity events.
XTestGrabControl
This function controls the current client's behavior during a GrabServer() by another client.
  • $impervious: If 1, the current client can continue to make requests, i.e., it is impervious to server grabs by other clients. If 0, the current client behaves as normal, and its requests wait during any GrabServer() by another client.

REQUESTS

The following functions correspond to the XTEST protocol requests:

XTestFakeKeyEvent
Simulates a key press or release.
XTestFakeMotionEvent
Simulates a pointer motion event.
XTestFakeButtonEvent
Simulates a button press or release.
XTestFakeCrossingEvent
Simulates a pointer crossing event.
XTestFakeProximityEvent
Simulates a pointer proximity event.
XTestFakeTRE
Simulates a generic event.
XTestGrabControl
Controls client behavior during server grabs.

GrabServer Imperviousness

"$X->XTestGrabControl ($impervious)"
Control the current client's behaviour during a GrabServer() by another client.

If $impervious is 1 then the current client can continue to make requests, ie. it's impervious to server grabs by other clients.

If $impervious is 0 then the current client behaves as normal. Its requests wait during any GrabServer() by another client.
