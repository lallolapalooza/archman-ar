X11__Protocol__Ext__XINERAMA(3pm)

الحزمة: perl-x11-protocol-other

التراخيص: GPL

X11::Protocol::Ext::XINERAMA(3) وثائق Perl ساهم بها المستخدم X11::Protocol::Ext::XINERAMA(3)

الاسم

X11::Protocol::Ext::XINERAMA - معلومات عرض الشاشات المتعددة

الملخص

use X11::Protocol;
my $X = X11::Protocol->new;
$X->init_extension('XINERAMA')
  or print "امتداد XINERAMA غير متاح";

الوصف

Xinerama يجمع شاشتين أو أكثر لتشكيل شاشة واحدة كبيرة. يتيح امتداد XINERAMA للعملاء الاستعلام عن الإعداد.

طلبات "PanoramiX" 1.0 تأخذ معامل $window للسماح بأكثر من شاشة X واحدة مكونة من شاشات فيزيائية متعددة، ولكن في الواقع، الخوادم لم تشكل سوى شاشة واحدة بهذه الطريقة وطلبات "Xinerama" 1.1 لا تحتوي على ذلك.

انظر examples/xinerama-info.pl لبرنامج نموذجي يقوم بتفريغ معلومات حالة Xinerama.

الطلبات

الطلبات التالية متاحة مع init_extension() لكل "EXTENSIONS" في X11::Protocol.

my $bool = $X->init_extension('XINERAMA');

Xinerama 1.0

"($server_major, $server_minor) = $X->PanoramiXQueryVersion ($client_major, $client_minor)"
التفاوض على إصدار بروتوكول مع الخادم. $client_major و $client_minor هو ما يريده العميل، أما $server_major و $server_minor المُعادان فهما ما سيقوم به الخادم، والتي قد تكون أقل من المطلوب (ولكن ليست أكثر).

الكود الحالي في هذه الوحدة يدعم حتى 1.1. النية هي التفاوض تلقائياً ضمن init_extension() إذا/عند الضرورة،

"$flag = $X->PanoramiXGetState ($window)"
إعادة قيمة غير صفرية إذا كان Xinerama نشطاً على شاشة $window (معرف XID).
"$count = $X->PanoramiXGetScreenCount ($window)"
إعادة عدد الشاشات الفيزيائية على شاشة $window (معرف XID).
"($width, $height) = $X->PanoramiXGetScreenSize ($window, $monitor)"
إعادة الحجم بالبكسل للشاشة الفيزيائية رقم $monitor (عدد صحيح، 0 للشاشة الأولى) على شاشة $window (معرف XID).

Xinerama 1.1

"$bool = $X->XineramaIsActive ()"
إعادة قيمة غير صفرية إذا كان Xinerama نشطاً على خادم $X.
"@rectangles = $X->XineramaQueryScreens ()"
إعادة المناطق المستطيلة التي تتكون منها الشاشات الفيزيائية. الإعادة هي قائمة من مصفوفات مشتركة، 
[ $x,$y, $width,$height ]

يمثل $x و $y الزاوية العلوية اليسرى للشاشة في الشاشة المدمجة.

الأخطاء

"Xsun"

تشير الشائعات إلى أن خادم "Xsun" مع Xinerama 1.0 كان لديه رقم طلب 4 مختلف عن "XineramaIsActive" الخاص بـ Xinerama 1.1 أعلاه.

http://blogs.sun.com/alanc/entry/xinerama_protocol_clashes_on_solaris

لا يوجد محاولة للتعامل مع هذا هنا، حتى الآن. إذا أبلغ PanoramiXQueryVersion() عن 1.0، فيجب ألا تستخدم XineramaIsActive() على أي حال، لذلك لا يوجد تعارض. إذا قمت بذلك وكان الخادم هو "Xsun"، فتوقع إما رد خطأ في الطول، أو أن يتكيف الخادم مع طول الطلب ويتصرف كـ "XineramaIsActive".

PanoramiXGetScreenSize() تجاوز سعة المخزن المؤقت

قد لا تتحقق الأكواد المبكرة للخادم مثل X11R6.4 من نطاق رقم الشاشة في PanoramiXGetScreenSize(). هل قراءة القيم الكبيرة لأجزاء من الذاكرة العشوائية أو تسببت في خطأ مميت؟ لا تفعل ذلك.

X.org بعد 1.5.x، "منع تجاوز المخزن المؤقت في ProcPanoramiXGetScreenSize"، http://cgit.freedesktop.org/xorg/xserver/commit/?id=2b266eda6e23d16116f8a8e258192df353970279

ملاحظات أخرى

لمحاكاة بعض Xinerama لاختبار خادم "Xdmx" يمكنه مضاعفة خادمين أو أكثر لتقديم شاشة واحدة كبيرة. يمكن أن تكون خوادم فرعية مثل "Xnest" أو "Xephyr" نوافذ على عرض X موجود. على سبيل المثال، تشغيل "Xdmx" كشاشة ":102"،

Xephyr :5 -screen 200x100 &
Xephyr :6 -screen 190x110 &
sleep 1
Xdmx -display :5 -display :6 +xinerama -input :5 -input :6 :102

"Xephyr" ينفذ بعض الامتدادات أصليًا، بينما "Xnest" يعتمد على قدرات الخادم المستهدف. أو للتشغيل دون الاهتمام بالنظر إلى أي شيء "Xvfb" في الذاكرة أو ملف القرص.

NAME

X11::Protocol::Ext::XINERAMA - Xinerama extension

SYNOPSIS

use X11::Protocol::Ext::XINERAMA;

# This module is intended for import by other modules.
# See X11::Protocol::Request for examples.

DESCRIPTION

The Xinerama extension allows clients to determine the arrangement of screens that compose the X screen.

This module provides an interface to the Xinerama extension for the Perl programming language.

EXAMPLE

Here's a simple example of how to use the Xinerama extension to get the screen information:

use X11::Protocol;
use X11::Protocol::Ext::XINERAMA;

my $x = X11::Protocol->new;

# Check if the Xinerama extension is available
unless ($x->has_extension('XINERAMA')) {
    die "Xinerama extension not available\n";
}

# Get the screen information
my ($screen_count, $screen_info) = $x->XineramaQueryScreens;

print "Number of screens: $screen_count\n";
for my $screen (@$screen_info) {
    printf "Screen: %dx%d+%d+%d\n",
        $screen->{width}, $screen->{height},
        $screen->{x}, $screen->{y};
}

BUGS

None reported.

OTHER NOTES

The Xinerama extension is an older mechanism for managing multiple screens. Newer systems may use RandR (X Resize, Rotate and Reflect Extension) for more advanced screen management.

X11::Protocol::Ext::XINERAMA - امتداد Xinerama

الملخص

use X11::Protocol::Ext::XINERAMA;

# هذه الوحدة مخصصة للاستيراد بواسطة وحدات أخرى.
# انظر X11::Protocol::Request للأمثلة.

الوصف

امتداد Xinerama يسمح للعملاء بتحديد ترتيب الشاشات التي تشكل شاشة X.

توفر هذه الوحدة واجهة لامتداد Xinerama للغة البرمجة Perl.

مثال

إليك مثال بسيط لكيفية استخدام امتداد Xinerama للحصول على معلومات الشاشة:

use X11::Protocol;
use X11::Protocol::Ext::XINERAMA;

my $x = X11::Protocol->new;

# التحقق مما إذا كان امتداد Xinerama متاحًا
unless ($x->has_extension('XINERAMA')) {
    die "امتداد Xinerama غير متاح\n";
}

# الحصول على معلومات الشاشة
my ($screen_count, $screen_info) = $x->XineramaQueryScreens;

print "عدد الشاشات: $screen_count\n";
for my $screen (@$screen_info) {
    printf "الشاشة: %dx%d+%d+%d\n",
        $screen->{width}, $screen->{height},
        $screen->{x}, $screen->{y};
}

أخطاء

لم يتم الإبلاغ عن أي أخطاء.

ملاحظات أخرى

امتداد Xinerama هو آلية قديمة لإدارة الشاشات المتعددة. قد تستخدم الأنظمة الأحدث RandR (امتداد تغيير حجم وتدوير وعكس X) لإدارة شاشات أكثر تقدمًا.
