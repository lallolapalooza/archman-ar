XBell(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XBell, XBellKeyboard, XPutLibraryInfo – إصدار رنين/تنبيه/إصدار إنذار

LIBRARY

X11-13

SYNOPSIS

#include <X11/Xlib.h>

   int XBell(Display *display, int event_code);
   int XBellKeyboard(Display *display, int event_code);
   int XPutLibraryInfo(Display *display, int info_code);

ARGUMENTS

display
يحدد اتصال الخادم.
event_code
يحدد رمز الحدث. يجب أن يكون 0 أو 1.
info_code
يحدد رمز المعلومات.

DESCRIPTION

تقوم وظائف XBell وXBellKeyboard بإصدار رنين للجهاز. يعتمد سلوك الجهاز على إعدادات الجهاز. يمكن استخدام XBellKeyboard لإصدار رنين من لوحة المفاتيح.

تقوم وظيفة XPutLibraryInfo بتزويد الخادم بمعلومات حول مكتبة X Client.

STRUCTURES

لا يوجد.

DIAGNOSTICS

عند حدوث خطأ، تقوم وظائف X عادةً بإرجاع قيمة خطأ. يمكن التقاط هذه الأخطاء باستخدام XErrors.

يمكن للمرء أن يفسر هذا الخطأ.
