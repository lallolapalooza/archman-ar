X509_get0_uids(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

X509_GET0_UIDS(3ssl) OpenSSL X509_GET0_UIDS(3ssl)

الاسم

X509_get0_uids, X509_ACERT_get0_issuerUID - الحصول على معرفات فريدة للشهادة وشهادة السمات

التركيب

 #include <openssl/x509.h>
 void X509_get0_uids(const X509 *x, const ASN1_BIT_STRING **piuid,
                     const ASN1_BIT_STRING **psuid);
 #include <openssl/x509_acert.h>
 ASN1_BIT_STRING *X509_ACERT_get0_issuerUID(X509_ACERT *x);
=head1 DESCRIPTION

X509_get0_uids() تعيّن *piuid و *psuid إلى معرفات المُصدر والمُستلم الفريدة للشهادة x أو NULL إذا لم تكن الحقول موجودة.

X509_ACERT_get0_issuerUID() تُرجع معرف المُصدر الفريد لشهادة السمات x أو NULL إذا لم يكن الحقل موجودًا.

ملاحظات

حقول المعرفات الفريدة للمُصدر والمُستلم نادرة جدًا في الممارسة العملية خارج حالات الاختبار.

قيم الإرجاع

X509_get0_uids() لا تُرجع قيمة.

X509_ACERT_get0_issuerUID() تُرجع معرفًا فريدًا عند النجاح أو NULL عند الفشل.

التاريخ

X509_get0_uids() تمت إضافتها في OpenSSL 1.1.0.

X509_ACERT_get0_issuerUID() تمت إضافتها في OpenSSL 3.4.
