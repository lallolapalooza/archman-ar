الوصف

الغرض من البنية X509_STORE هو أن تكون آلية موحدة للاحتفاظ بالمعلومات حول شهادات X.509 و CRLs، وبناء والتحقق من صحة سلاسل الشهادات التي تنتهي في جذور موثوقة. تسمح بآليات بحث متعددة وأداء توسيع فعال مع عدد كبير من الشهادات، والكثير من المرونة في كيفية إجراء عمليات التحقق والسياسات.

تفاصيل عملية بناء السلسلة والتحقق منها موصوفة في "بناء مسار الشهادة" في openssl-verification-options(1) و "التحقق من صحة مسار الشهادة" في openssl-verification-options(1).

X509_STORE_new(3) تنشئ بنية X509_STORE فارغة، والتي لا تحتوي على أي معلومات حول الشهادات الموثوقة أو مكان وجود هذه الشهادات على القرص، وهي بشكل عام غير قابلة للاستخدام. عادةً، ستتم إضافة الشهادات الموثوقة إلى X509_STORE لإعدادها للاستخدام، عبر آليات مثل X509_STORE_add_lookup() و X509_LOOKUP_file()، أو PEM_read_bio_X509_AUX() و X509_STORE_add_cert(). يمكن أيضًا إضافة CRLs، وتكوين العديد من السلوكيات حسب الرغبة.

بمجرد تكوين X509_STORE بشكل مناسب، يتم استخدام X509_STORE_CTX_new() لإنشاء X509_STORE_CTX للاستخدام مرة واحدة لكل عملية بناء سلسلة وتحقق. تتضمن هذه العملية توفير شهادة الكيان النهائي التي سيتم التحقق منها ومجموعة إضافية من الشهادات غير الموثوق بها التي يمكن استخدامها في بناء السلسلة. على هذا النحو، من المتوقع أن تكون الشهادات المضمنة في X509_STORE شهادات تمثل كيانات موثوقة مثل سلطات الشهادات الجذرية (CAs). تمثل OpenSSL هذه الشهادات الموثوقة داخليًا ككائنات X509 مع X509_CERT_AUX مرتبط بها، كما يتم إنتاجه بواسطة PEM_read_bio_X509_AUX() والروتينات المماثلة التي تشير إلى X509_AUX. ومع ذلك، لا تزال الواجهات العامة التي تعمل على هذه الشهادات الموثوقة تعمل على مؤشرات لكائنات X509.

X509_STORE_add_cert() و X509_STORE_add_crl() تضيف الكائن المعني إلى التخزين المحلي لـ X509_STORE. لا ينبغي إضافة الكائنات غير الموثوق بها بهذه الطريقة. تتم زيادة عدد المراجع للكائن المضاف بواحد، وبالتالي يحتفظ المتصل بالملكية للكائن ويحتاج إلى تحريره عندما لم يعد مطلوبًا.

X509_STORE_set_depth()، X509_STORE_set_flags()، X509_STORE_set_purpose()، X509_STORE_set_trust()، و X509_STORE_set1_param() تعيين القيم الافتراضية للقيم المقابلة المستخدمة في التحقق من صحة سلسلة الشهادات. يتم توثيق سلوكها في صفحات دليل X509_VERIFY_PARAM المقابلة، على سبيل المثال، X509_VERIFY_PARAM_set_depth(3). X509_STORE يجب ألا يكون NULL.

X509_STORE_add_lookup() تجد أو تنشئ X509_LOOKUP(3) مع X509_LOOKUP_METHOD(3) meth وتضيفه إلى X509_STORE store. هذا يربط أيضًا X509_STORE بالبحث، لذا يمكن لوظائف X509_LOOKUP البحث عن الكائنات في هذا المخزن.

X509_STORE_load_file_ex() تقوم بتحميل شهادات موثوقة إلى X509_STORE من ملف معين. يتم استخدام سياق المكتبة libctx والاستعلام عن الخصائص propq عند جلب الخوارزميات من الموفرين.

X509_STORE_load_file() مشابه لـ X509_STORE_load_file_ex() ولكنه يستخدم NULL لسياق المكتبة libctx والاستعلام عن الخصائص propq.

X509_STORE_load_path() تقوم بتحميل شهادات موثوقة إلى X509_STORE من مسار دليل معين. يجب أن تكون الشهادات في الدليل بتنسيقها المشفر، كما هو موثق في X509_LOOKUP_hash_dir(3).

X509_STORE_load_store_ex() تقوم بتحميل شهادات موثوقة إلى X509_STORE من مخزن في معرف URI معين. يتم استخدام سياق المكتبة libctx والاستعلام عن الخصائص propq عند جلب الخوارزميات من الموفرين.

X509_STORE_load_store() مشابه لـ X509_STORE_load_store_ex() ولكنه يستخدم NULL لسياق المكتبة libctx والاستعلام عن الخصائص propq.

X509_STORE_load_locations_ex() تجمع بين X509_STORE_load_file_ex() و X509_STORE_load_path() لمسار ملف و/أو دليل معين. يُسمح بتحديد ملف فقط، أو دليل فقط، أو كلا المسارين.

X509_STORE_load_locations() مشابه لـ X509_STORE_load_locations_ex() ولكنه يستخدم NULL لسياق المكتبة libctx والاستعلام عن الخصائص propq.

X509_STORE_set_default_paths_ex() هي مسماة بشكل خاطئ إلى حد ما، حيث أنها لا تحدد المسارات الافتراضية التي يجب استخدامها لتحميل الشهادات. بدلاً من ذلك، تقوم بتحميل الشهادات إلى X509_STORE من المسارات الافتراضية المدمجة. يتم استخدام سياق المكتبة libctx والاستعلام عن الخصائص propq عند جلب الخوارزميات من الموفرين.

X509_STORE_set_default_paths() مشابه لـ X509_STORE_set_default_paths_ex() ولكنه يستخدم NULL لسياق المكتبة libctx والاستعلام عن الخصائص propq.

قيم الإرجاع

X509_STORE_add_cert()، X509_STORE_add_crl()، X509_STORE_set_depth()، X509_STORE_set_flags()، X509_STORE_set_purpose()، X509_STORE_set_trust()، X509_STORE_load_file_ex()، X509_STORE_load_file()، X509_STORE_load_path()، X509_STORE_load_store_ex()، X509_STORE_load_store()، X509_STORE_load_locations_ex()، X509_STORE_load_locations()، X509_STORE_set_default_paths_ex() و X509_STORE_set_default_paths() ترجع 1 عند النجاح أو 0 عند الفشل.

X509_STORE_add_lookup() ترجع X509_LOOKUP(3) المعثور عليه أو المنشأ، أو NULL عند حدوث خطأ.

X509_STORE_add_cert

October 1, 2025

NAME

X509_STORE_add_cert, X509_STORE_remove_cert, X509_STORE_get_by_subject, X509_STORE_get1_cert, X509_STORE_set_flags
X509_STORE_add_cert, X509_STORE_remove_cert, X509_STORE_get_by_subject, X509_STORE_get1_cert, X509_STORE_set_flags - add, remove, or retrieve certificates from a certificate store

SYNOPSIS

 #include <openssl/x509.h>

 int X509_STORE_add_cert(X509_STORE *ctx, X509 *x);
 int X509_STORE_remove_cert(X509_STORE *ctx, X509 *x);
 X509_OBJECT *X509_STORE_get_by_subject(X509_STORE_CTX *ctx,
                                        int type, X509_NAME *name,
                                        X509_OBJECT *obj);
 X509 *X509_STORE_get1_cert(X509_STORE *ctx, X509_NAME *name);
 unsigned long X509_STORE_set_flags(X509_STORE *ctx, unsigned long flags);

DESCRIPTION

The following functions are available:
X509_STORE_add_cert()
adds the certificate x to the store ctx. If a certificate with the same subject name already exists, it is not added.
X509_STORE_remove_cert()
removes the certificate x from the store ctx. Note that the reference count of the certificate is decremented, and it may be freed if no other references exist.
X509_STORE_get_by_subject()
searches the store ctx for an object of the given type with the given name. The type can be X509_LU_CERT (for certificates), X509_LU_CRL (for certificate revocation lists), or X509_LU_ espécies (for all objects). The search is performed by subject name for certificates and issuer name for CRLs. If an object is found, it is placed in the obj argument and a reference to it is returned. If obj is NULL, then a new X509_OBJECT is allocated. Otherwise, the existing X509_OBJECT is used. The caller is responsible for freeing the returned X509_OBJECT (if allocated) and the contained certificate or CRL. The function returns a pointer to the found object, or NULL if no suitable object is found.
X509_STORE_get1_cert()
retrieves a certificate from the store ctx whose subject name matches name. A new reference to the certificate is returned. The caller is responsible for freeing the certificate using X509_free(). If no certificate is found, NULL is returned. The function returns NULL on error.
X509_STORE_set_flags()
sets the flags for the certificate store ctx to flags. The flags determine various aspects of certificate verification. The previous flags are returned. See X509_VERIFY_PARAM_set_flags(3) for a list of possible flags.

RETURN VALUES

X509_STORE_add_cert()
returns 1 on success, 0 on failure.
X509_STORE_remove_cert()
returns 1 on success, 0 on failure.
X509_STORE_get_by_subject()
returns a pointer to the found X509_OBJECT on success, or NULL on failure or if no object is found.
X509_STORE_get1_cert()
returns a pointer to a new reference of the found certificate on success, or NULL on failure or if no certificate is found.
X509_STORE_set_flags()
returns the previous flags value.

SEE ALSO

X509_STORE_new(3), X509_STORE_CTX_new(3), X509_VERIFY_PARAM_set_flags(3)

HISTORY

The functions X509_STORE_add_cert(), X509_STORE_remove_cert(), X509_STORE_get_by_subject(), X509_STORE_get1_cert(), and X509_STORE_set_flags() were added in OpenSSL 0.9.7.
