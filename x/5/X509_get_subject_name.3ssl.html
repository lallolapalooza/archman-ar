X509_get_subject_name(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

X509_GET_SUBJECT_NAME(3ssl) OpenSSL X509_GET_SUBJECT_NAME(3ssl)

الاسم

X509_NAME_hash_ex, X509_NAME_hash, X509_get_subject_name, X509_set_subject_name, X509_subject_name_hash, X509_get_issuer_name, X509_set_issuer_name, X509_issuer_name_hash, X509_REQ_get_subject_name, X509_REQ_set_subject_name, X509_ACERT_get0_issuerName, X509_ACERT_set1_issuerName, X509_CRL_get_issuer, X509_CRL_set_issuer_name - الحصول على تجزئات X509_NAME أو الحصول على أسماء المصدر وتعيينها

الخلاصة

#include <openssl/x509.h>
unsigned long X509_NAME_hash_ex(const X509_NAME *x, OSSL_LIB_CTX *libctx,
                                const char *propq, int *ok);
X509_NAME *X509_get_subject_name(const X509 *x);
int X509_set_subject_name(X509 *x, const X509_NAME *name);
unsigned long X509_subject_name_hash(X509 *x);
X509_NAME *X509_get_issuer_name(const X509 *x);
int X509_set_issuer_name(X509 *x, const X509_NAME *name);
unsigned long X509_issuer_name_hash(X509 *x);
X509_NAME *X509_REQ_get_subject_name(const X509_REQ *req);
int X509_REQ_set_subject_name(X509_REQ *req, const X509_NAME *name);
X509_NAME *X509_CRL_get_issuer(const X509_CRL *crl);
int X509_CRL_set_issuer_name(X509_CRL *x, const X509_NAME *name);

تم إهمال الماكرو التالي منذ OpenSSL 3.0، ويمكن إخفاؤه بالكامل عن طريق تعريف OPENSSL_API_COMPAT بقيمة إصدار مناسبة، انظر openssl_user_macros(7):

#define X509_NAME_hash(x) X509_NAME_hash_ex(x, NULL, NULL, NULL)

الوصف

X509_NAME_hash_ex() تُرجع قيمة تجزئة للاسم x أو 0 عند الفشل، باستخدام أي سياق مكتبة libctx واستعلام خاصية propq مُعطى. قد يكون وسيط النتيجة ok فارغًا أو يستخدم لإرجاع 1 للنجاح و 0 للفشل. قد يحدث الفشل بسبب خطأ في تخصيص الذاكرة أو إذا لم يكن هناك تنفيذ SHA1 متاح.

X509_NAME_hash() تُرجع قيمة تجزئة للاسم x أو 0 عند الفشل، باستخدام سياق المكتبة الافتراضي واستعلام الخاصية الافتراضي.

X509_get_subject_name() تُرجع اسم الموضوع للشهادة x. القيمة المرجعة هي مؤشر داخلي يجب عدم تحريره. x يجب ألا يكون فارغًا.

X509_set_subject_name() تعيّن اسم المصدر للشهادة x إلى name. يتم نسخ المعامل name داخليًا ويجب تحريره عندما لم يعد مطلوبًا.

X509_subject_name_hash() تُرجع قيمة تجزئة لاسم الموضوع للشهادة x.

X509_get_issuer_name()، X509_set_issuer_name()، و X509_issuer_name_hash() متطابقة مع X509_get_subject_name()، X509_set_subject_name()، و X509_subject_name_hash() باستثناء أنها تتعلق باسم المصدر لـ x.

وبالمثل، X509_REQ_get_subject_name()، X509_REQ_set_subject_name()، X509_ACERT_get0_issuerName()، X509_ACERT_set1_issuerName()، X509_CRL_get_issuer() و X509_CRL_set_issuer_name() تحصل على أو تعيّن أسماء الموضوع أو المصدر لطلبات الشهادات أو قوائم إلغاء الشهادات على التوالي.

نظرًا لعدم وجود اسم موضوع لشهادات السمات، يمكن فقط تعيين اسم المصدر. للحصول على تفاصيل حول تعيين هويات حامل X509_ACERT، انظر X509_ACERT_set0_holder_entityName(3).

قيم الإرجاع

X509_get_subject_name()، X509_get_issuer_name()، X509_REQ_get_subject_name() X509_ACERT_get0_issuerName() و X509_CRL_get_issuer() تُرجع مؤشر X509_NAME.

X509_NAME_hash_ex()، X509_NAME_hash()، X509_subject_name_hash() و X509_issuer_name_hash() تُرجع البايتات الأربعة الأولى من قيمة تجزئة SHA1، محولة إلى unsigned long بترتيب البايتات الصغير (little endian)، أو 0 عند الفشل.

X509_set_subject_name()، X509_set_issuer_name()، X509_REQ_set_subject_name()، X509_ACERT_get0_issuerName() و X509_CRL_set_issuer_name() تُرجع 1 للنجاح و 0 للفشل.

أخطاء

في حالة إرجاع X509_NAME_hash()، X509_subject_name_hash()، أو X509_issuer_name_hash() قيمة 0، لا يزال من غير الواضح ما إذا كانت هذه هي قيمة التجزئة الفعلية أو بسبب فشل. من الأفضل استخدام X509_NAME_hash_ex() بدلاً من ذلك.

التاريخ

X509_REQ_get_subject_name() هي دالة في OpenSSL 1.1.0 وماكرو في الإصدارات الأقدم.

X509_CRL_get_issuer() هي دالة في OpenSSL 1.1.0. تم إضافتها سابقًا في OpenSSL 1.0.0 كـ ماكرو.

تم تحويل X509_NAME_hash() إلى ماكرو وتم إهمالها في OpenSSL 3.0.

X509_ACERT_get0_issuerName()، X509_ACERT_set1_issuerName() تم إضافتها في OpenSSL 3.4.
