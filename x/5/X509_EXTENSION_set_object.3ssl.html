X509_EXTENSION_set_object(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

X509_EXTENSION_SET_OBJECT(3ssl) OpenSSL X509_EXTENSION_SET_OBJECT(3ssl)

الاسم

X509_EXTENSION_set_object, X509_EXTENSION_set_critical, X509_EXTENSION_set_data, X509_EXTENSION_create_by_NID, X509_EXTENSION_create_by_OBJ, X509_EXTENSION_get_object, X509_EXTENSION_get_critical, X509_EXTENSION_get_data - وظائف مساعدة للامتدادات

الملخص

int X509_EXTENSION_set_object(X509_EXTENSION *ex, const ASN1_OBJECT *obj);
int X509_EXTENSION_set_critical(X509_EXTENSION *ex, int crit);
int X509_EXTENSION_set_data(X509_EXTENSION *ex, ASN1_OCTET_STRING *data);
X509_EXTENSION *X509_EXTENSION_create_by_NID(X509_EXTENSION **ex,
                                             int nid, int crit,
                                             ASN1_OCTET_STRING *data);
X509_EXTENSION *X509_EXTENSION_create_by_OBJ(X509_EXTENSION **ex,
                                             const ASN1_OBJECT *obj, int crit,
                                             ASN1_OCTET_STRING *data);
ASN1_OBJECT *X509_EXTENSION_get_object(X509_EXTENSION *ex);
int X509_EXTENSION_get_critical(const X509_EXTENSION *ex);
ASN1_OCTET_STRING *X509_EXTENSION_get_data(X509_EXTENSION *ne);

الوصف

X509_EXTENSION_set_object() يضبط نوع الامتداد لـ ex إلى obj. يتم نسخ المؤشر obj داخليًا لذا يجب تحرير obj بعد الاستخدام.

X509_EXTENSION_set_critical() يضبط أهمية ex إلى crit. إذا كان crit صفرًا، يكون الامتداد غير هام، وإلا فإنه هام.

X509_EXTENSION_set_data() يضبط البيانات في الامتداد ex إلى data. يتم نسخ المؤشر data داخليًا.

X509_EXTENSION_create_by_NID() ينشئ امتدادًا من النوع nid، الأهمية crit باستخدام البيانات data. يتم إرجاع الامتداد المنشأ وكتابته إلى *ex مع إعادة استخدام أو تخصيص امتداد جديد إذا لزم الأمر، لذا يجب أن يكون *ex إما NULL أو بنية X509_EXTENSION صالحة، ويجب ألا يكون مؤشرًا غير مهيأ.

X509_EXTENSION_create_by_OBJ() مطابق لـ X509_EXTENSION_create_by_NID() باستثناء أنه ينشئ امتدادًا باستخدام obj بدلاً من NID.

X509_EXTENSION_get_object() يرجع نوع الامتداد لـ ex كمؤشر ASN1_OBJECT. المؤشر المرجع هو قيمة داخلية يجب عدم تحريرها.

X509_EXTENSION_get_critical() يرجع أهمية الامتداد ex. يرجع 1 إذا كان هامًا و 0 إذا كان غير هام.

X509_EXTENSION_get_data() يرجع البيانات للامتداد ex. المؤشر المرجع هو قيمة داخلية يجب عدم تحريرها.

ملاحظات

هذه الوظائف تعالج محتويات الامتداد مباشرة. معظم التطبيقات سترغب في تحليل أو ترميز وإضافة امتداد: يجب عليهم استخدام وظائف ترميز وفك ترميز الامتداد بدلاً من ذلك مثل X509_add1_ext_i2d() و X509_get_ext_d2i().

البيانات المرتبطة بامتداد هي ترميز الامتداد في بنية ASN1_OCTET_STRING.

قيم الإرجاع

X509_EXTENSION_set_object() X509_EXTENSION_set_critical() و X509_EXTENSION_set_data() ترجع 1 للنجاح و 0 للفشل.

X509_EXTENSION_create_by_NID() و X509_EXTENSION_create_by_OBJ() ترجع مؤشر X509_EXTENSION أو NULL إذا حدث خطأ.

X509_EXTENSION_get_object() يرجع مؤشر ASN1_OBJECT.

X509_EXTENSION_get_critical() يرجع 0 لغير هام و 1 لهام.

X509_EXTENSION_get_data() يرجع مؤشر ASN1_OCTET_STRING.
