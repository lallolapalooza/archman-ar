X509_ACERT_add1_attr(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

X509_ACERT_ADD1_ATTR(3ssl) OpenSSL X509_ACERT_ADD1_ATTR(3ssl)

الاسم

X509_ACERT_add1_attr, X509_ACERT_add1_attr_by_NID, X509_ACERT_add1_attr_by_OBJ, X509_ACERT_add1_attr_by_txt, X509_ACERT_delete_attr - دوال سمات X509_ACERT

الملخص

#include <openssl/x509_acert.h>
int X509_ACERT_add1_attr(X509_ACERT *x, X509_ATTRIBUTE *attr);
int X509_ACERT_add1_attr_by_NID(X509_ACERT *x, int nid, int type,
                                const void *bytes, int len);
int X509_ACERT_add1_attr_by_OBJ(X509_ACERT *x, const ASN1_OBJECT *obj,
                                int type, const void *bytes, int len);
int X509_ACERT_add1_attr_by_txt(X509_ACERT *x, const char *attrname, int type,
                                const unsigned char *bytes, int len);
X509_ATTRIBUTE *X509_ACERT_delete_attr(X509_ACERT *x, int loc);

الوصف

X509_ACERT_add1_attr() تضيف سمة X509_ATTRIBUTE المُنشأة attr إلى بنية X509_ACERT الموجودة x.

X509_ACERT_add1_attr_by_NID() و X509_ACERT_add1_attr_by_OBJ() تضيفان سمة من النوع nid أو obj بقيمة من النوع ASN1 type مُنشأة باستخدام len بايت من bytes.

X509_ACERT_add1_attr_by_txt() تضيف سمة من النوع attrname بقيمة من النوع ASN1 type مُنشأة باستخدام len بايت من bytes.

X509_ACERT_delete_attr() ستقوم بحذف السمة رقم loc من x وإعادة مؤشر إليها أو NULL إذا كان هناك أقل من loc سمة موجودة في x.

قيم الإرجاع

X509_ACERT_add1_attr() و X509_ACERT_add1_attr_by_NID() و X509_ACERT_add1_attr_by_OBJ() تعيد 1 للنجاح و 0 للفشل.

X509_ACERT_delete_attr() تعيد مؤشر X509_ATTRIBUTE عند النجاح أو NULL عند الفشل.
