X509_ACERT_get_attr(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

X509_ACERT_GET_ATTR(3ssl) OpenSSL X509_ACERT_GET_ATTR(3ssl)

الاسم

X509_ACERT_get_attr, X509_ACERT_get_attr_by_NID, X509_ACERT_get_attr_by_OBJ, X509_ACERT_get_attr_count - استرداد السمات من بنية X509_ACERT

الملخص

#include <openssl/x509_acert.h>
X509_ATTRIBUTE *X509_ACERT_get_attr(const X509_ACERT *x, int loc);
int X509_ACERT_get_attr_by_NID(const X509_ACERT *x, int nid, int lastpos);
int X509_ACERT_get_attr_by_OBJ(const X509_ACERT *x, const ASN1_OBJECT *obj,
                               int lastpos);
int X509_ACERT_get_attr_count(const X509_ACERT *x);

الوصف

X509_ACERT_get0_attr() تسترد السمة locth X509_ATTRIBUTE من X509_ACERT x. X509_ACERT_get_attr_count() تعيد العدد الإجمالي للسمات في X509_ACERT.

X509_ACERT_get_attr_by_NID() و X509_ACERT_get_attr_by_OBJ() تستردان موقع السمة التالية المطابقة لـ nid أو obj بعد lastpos. يجب أن يتم تعيين lastpos مبدئيًا إلى -1. إذا لم تكن هناك إدخالات أخرى، يتم إرجاع -1. إذا كان nid غير صالح (لا يتوافق مع OID صالح)، يتم إرجاع -2.

قيم الإرجاع

X509_ACERT_get0_attr() تعيد X509_ATTRIBUTE من شهادة سمة، أو NULL إذا لم يتم العثور على السمة المحددة.

X509_ACERT_get_attr_by_NID() و X509_ACERT_get_attr_by_OBJ() تعيدان موقع السمة التالية المطلوبة أو -1 إذا لم يتم العثور عليها. يمكن لـ X509_ACERT_get_attr_by_NID() أيضًا إرجاع -2 إذا كان NID المقدم غير صالح.

X509_ACERT_get_attr_count() تعيد عدد السمات في شهادة السمة المحددة.

التاريخ

تمت إضافة X509_ACERT_get0_attr()، X509_ACERT_get_attr_by_NID()، X509_ACERT_get_attr_by_OBJ() و X509_ACERT_get_attr_count() في OpenSSL 3.4.
