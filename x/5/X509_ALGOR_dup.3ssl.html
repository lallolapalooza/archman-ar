X509_ALGOR_dup(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

X509_ALGOR_DUP(3ssl) OpenSSL X509_ALGOR_DUP(3ssl)

الاسم

X509_ALGOR_dup، X509_ALGOR_set0، X509_ALGOR_get0، X509_ALGOR_set_md، X509_ALGOR_cmp، X509_ALGOR_copy - وظائف AlgorithmIdentifier

الملخص

#include <openssl/x509.h>
X509_ALGOR *X509_ALGOR_dup(X509_ALGOR *alg);
int X509_ALGOR_set0(X509_ALGOR *alg, ASN1_OBJECT *aobj, int ptype, void *pval);
void X509_ALGOR_get0(const ASN1_OBJECT **paobj, int *pptype,
                     const void **ppval, const X509_ALGOR *alg);
void X509_ALGOR_set_md(X509_ALGOR *alg, const EVP_MD *md);
int X509_ALGOR_cmp(const X509_ALGOR *a, const X509_ALGOR *b);
int X509_ALGOR_copy(X509_ALGOR *dest, const X509_ALGOR *src);

الوصف

X509_ALGOR_dup() يعيد نسخة من alg.

X509_ALGOR_set0() تضبط معرف OID للخوارزمية الخاص بـ alg إلى aobj ونوع المعلمة المرتبط به إلى ptype مع القيمة pval. إذا كان ptype هو V_ASN1_UNDEF يتم حذف المعلمة، وإلا فإن ptype و pval لهما نفس المعنى مثل المعلمات type و value للدالة ASN1_TYPE_set(). يتم استخدام جميع المعلمات المقدمة داخليًا، لذلك يجب عدم تحريرها بعد نجاح هذه المكالمة؛ بخلاف ذلك، يبقى الملكية للمتصل ويبقى alg دون تغيير.

X509_ALGOR_get0() هي عكس X509_ALGOR_set0(): تعيد معرف OID للخوارزمية في *paobj والمعلمة المرتبطة به في *pptype و *ppval من AlgorithmIdentifier alg.

X509_ALGOR_set_md() تضبط AlgorithmIdentifier alg إلى القيم المناسبة لخوارزمية تلخيص الرسالة md.

X509_ALGOR_cmp() تقارن a و b وتعيد 0 إذا كانت لديهما ترميزات متطابقة وغير ذلك.

X509_ALGOR_copy() تنسخ القيم المصدر إلى هياكل الوجهة؛ مع إنشاء نسخة من كل منها (وتحرير أي شيء يشير إليه *dest).

قيم الإرجاع

X509_ALGOR_dup() يعيد بنية X509_ALGOR صالحة أو NULL إذا حدث خطأ.

X509_ALGOR_set0() و X509_ALGOR_copy() تعيدان 1 عند النجاح أو 0 عند الخطأ.

X509_ALGOR_get0() و X509_ALGOR_set_md() لا تعيدان أي قيم.

X509_ALGOR_cmp() تعيد 0 إذا كانت المعلمتان لهما ترميزات متطابقة وغير ذلك.

التاريخ

تمت إضافة X509_ALGOR_copy() في 1.1.1e.
