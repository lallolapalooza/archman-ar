X509_digest(3ssl)

الحزمة: openssl

التراخيص: Apache-2.0

الاسم

X509_digest, X509_digest_sig, X509_CRL_digest, X509_pubkey_digest, X509_NAME_digest, X509_REQ_digest, PKCS7_ISSUER_AND_SERIAL_digest - الحصول على ملخص لمختلف الكائنات

الملخص

#include <openssl/x509.h>
int X509_digest(const X509 *data, const EVP_MD *type, unsigned char *md,
                unsigned int *len);
ASN1_OCTET_STRING *X509_digest_sig(const X509 *cert,
                                   EVP_MD **md_used, int *md_is_fallback);
int X509_CRL_digest(const X509_CRL *data, const EVP_MD *type, unsigned char *md,
                    unsigned int *len);

                    unsigned char *md, unsigned int *len);

                     unsigned char *md, unsigned int *len);

                                   const EVP_MD *type, unsigned char *md,

الوصف

X509_digest_sig() يحسب ملخصًا للشهادة المعطاة cert باستخدام نفس خوارزمية التجزئة الموجودة في خوارزمية التوقيع الخاصة بها، إذا كان الملخص جزءًا لا يتجزأ من معرف خوارزمية توقيع الشهادة. بخلاف ذلك، يتم تحديد خوارزمية تجزئة احتياطية على النحو التالي: SHA512 إذا كانت خوارزمية التوقيع ED25519، SHAKE256 إذا كانت ED448، وإلا SHA256. يتم تعيين معاملات الإخراج على النحو التالي. ما لم يكن md_used فارغًا، يتم توفير خوارزمية التجزئة المستخدمة في *md_used ويجب تحريرها من قبل المتصل (إذا لم تكن فارغة). ما لم يكن md_is_fallback فارغًا، يتم تعيين *md_is_fallback إلى 1 إذا كانت خوارزمية التجزئة المستخدمة هي خوارزمية احتياطية، وإلا إلى 0.

X509_pubkey_digest() يعيد ملخصًا للتمثيل DER للمفتاح العام في كائن X509 data المحدد.

جميع الوظائف الأخرى الموضحة هنا تعيد ملخصًا للتمثيل DER لكامل كائنات data الخاصة بها.

يحدد المعامل type التجزئة المراد استخدامها، مثل EVP_sha1(). md هو مؤشر إلى المخزن المؤقت حيث سيتم نسخ الملخص ويفترض أنه كبير بما يكفي؛ يُقترح الثابت EVP_MAX_MD_SIZE. المعامل len، إذا لم يكن فارغًا، يشير إلى مكان سيتم فيه تخزين حجم الملخص.

قيم الإرجاع

X509_digest_sig() يعيد مؤشر ASN1_OCTET_STRING عند النجاح، وإلا NULL.

جميع الوظائف الأخرى الموضحة هنا تعيد 1 للنجاح و 0 للفشل.
