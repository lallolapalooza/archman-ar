XftFontInfoDestroy(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة تقوم برسم النصوص والرسومات:

  • باستخدام المعلومات المقدمة من مكتبة Fontconfig،
  • تقوم Xft بتحويل glyphs الخطوط باستخدام مُرسم الخطوط FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X للتقديم (X Rendering Extension).

صفحة الدليل هذه تكاد لا تخدش سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، بالإضافة إلى XFT_MINOR مضروبًا في 100، بالإضافة إلى XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت إصدار Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " تحتاج إلى إصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اصطلاح تسمية، حيث يتم إضافة البادئة "Xft" إلى جميع الأسماء.

من Xlib...

لا تتبع أنواع بيانات Xlib اصطلاح تسمية. تم توثيقها في Xlib - واجهة لغة C.

تستخدم Xft هذه الأسماء: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual, و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معلن في <X11/X.h>، هذا هو معرف مورد X، على سبيل المثال، نافذة مرتبطة بشاشة عرض. يمكن استخدام كل من النوافذ و pixmaps كمصادر ووجهات في عمليات الرسومات. تُعرف هذه النوافذ و pixmaps بشكل جماعي باسم drawables. ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسومات.
Region
معلن في <X11/Xutil.h> و <X11/Xregion.h>، Region هي مجموعة تعسفية من مواقع البكسل التي يمكن لـ Xlib معالجتها. داخليًا، يتم تمثيل Region باتحاد عدد تعسفي من المستطيلات. تحتفظ Xlib بمستطيل يخبره بمدى هذا الاتحاد.
Visual
معلن في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول تعيين الألوان المحتمل.

من XRender...

تستلهم أنواع بيانات امتداد X للتقديم (X Render Extension) من Xlib، ولكنها تفتقر إلى التوثيق المقابل. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا لمكتبة libXrender).

تستخدم Xft هذه الأسماء: Picture, XGlyphInfo, XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اصطلاح تسمية، حيث يتم إضافة البادئة "Fc" إلى جميع الأسماء، وهي موثقة في مرجع مطوري Fontconfig.

تستخدم Xft هذه الأسماء من Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern, و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اصطلاح تسمية، حيث يتم إضافة البادئة "FT_" إلى جميع الأسماء، وهي موثقة في مرجع واجهة برمجة تطبيقات FreeType.

تستخدم Xft هذه الأسماء: FT_Face, FT_Library, و FT_UInt.

يستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل glyphs.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ فهو يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig والنمط المرتبط بالخط.

يتم ملء XftFonts باستخدام أي من الدوال XftFontOpen()، XftFontOpenName()، XftFontOpenXlfd()، XftFontOpenInfo()، أو XftFontOpenPattern(). يتم استخدام XftFontCopy() لمضاعفة XftFonts، ويتم استخدام XftFontClose() لوضع علامة على XftFont كغير مستخدم. يتم تخصيص XftFonts داخليًا، وعد المراجع، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

تستخدم دوال XftDrawGlyphs()، وعائلة دوال XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec()، XftFonts لرسم النصوص إلى كائن XftDraw، والذي قد يتوافق مع رسم X أساسي أو رسم امتداد X للتقديم (X Rendering Extension).

تُستخدم الدوال XftGlyphExtents() وعائلة دوال XftTextExtents*() لتحديد الامتدادات (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية glyph أو حرف XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). تُرجع XftCharIndex() فهرس الحرف الخاص بـ XftFont المقابل لنقطة ترميز Unicode معينة.

تستخدم الدوال XftGlyphRender()، XftGlyphSpecRender()، XftCharSpecRender()، وعائلة دوال XftTextRender*()، XftFonts للرسم في هياكل Picture الخاصة بامتداد X للتقديم (X Rendering Extension).

ملاحظة: توفر الدوال XftDrawGlyphs()، وعائلة دوال XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لرسم الخطوط مستقلة عن توفر امتداد X للتقديم (X Rendering Extension) على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن المعلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص XftFontInfo objects وتحريرها داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

يرتبط كل هيكل XftFontInfo قيد الاستخدام بمعرف فريد، والذي يمكن استرجاعه باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor برسم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب تقدمه الشاشة المرئية لـ X المستخدمة).

تطلب الدوال XftColorAllocName() و XftColorAllocValue() تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. تطلب الدالة XftColorFree() من خادم X تحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام الدوال XftDrawSrcPicture()، XftDrawGlyphs()، عائلة دوال XftDrawString*()، XftDrawCharSpec()، XftDrawCharFontSpec()، XftDrawGlyphSpec()، XftDrawGlyphFontSpec()، و XftDrawRect() لرسم كائنات مختلفة باستخدام

XftDraw

هو كائن غير شفاف يحتوي على معلومات تُستخدم للرسم على كائن قابل للرسم (drawable) في X باستخدام بروتوكول أساسي أو امتداد X Rendering.

يتم إنشاء كائنات XftDraw باستخدام أي من الدوال التالية: XftDrawCreate() (التي تربط XftDraw بكائن قابل للرسم موجود في X)، XftDrawCreateBitmap()، أو XftDrawCreateAlpha()، ويتم تدميرها باستخدام XftDrawDestroy(). يمكن تغيير كائن X القابل للرسم المرتبط بـ XftDraw باستخدام XftDrawChange(). يتم تخصيص وتحرير كائنات XftDraw داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

يمكن الاستعلام عن خصائص X Display و Drawable و Colormap و Visual لكائن XftDraw باستخدام XftDrawDisplay() و XftDrawDrawable() و XftDrawColormap() و XftDrawVisual() على التوالي.

تستخدم العديد من الدوال كائنات XftDraw: XftDrawCharFontSpec() و XftDrawCharSpec() و XftDrawGlyphFontSpec() و XftDrawGlyphSpec() و XftDrawGlyphs() و XftDrawRect() و XftDrawSetClip() و XftDrawSetClipRectangles() و XftDrawSetSubwindowMode() وعائلة XftDrawString*().

يتم إرجاع امتداد X Rendering Picture المرتبط بـ XftDraw بواسطة XftDrawPicture() و XftDrawSrcPicture(). يتم استخدامه بواسطة XftCharFontSpecRender() و XftCharSpecRender() و XftGlyphFontSpecRender() و XftGlyphRender() و XftGlyphSpecRender() وعائلة XftTextRender*().

الوظائف

التهيئة

عادةً ما لا يقوم التطبيق الذي يستخدم Xft بتهيئة المكتبة بشكل صريح. يحدث هذا عادةً كأثر جانبي لفتح خط.

عندما تبدأ Xft بالتهيئة، تقوم بجمع معلومات حول الشاشة، وتخزن بعض هذه المعلومات في نمط Fontconfig (وهو في الأساس مجموعة من الخصائص ذات القيم المصنفة). يمكن للتطبيق المستدعي تعديل هذا النمط لتغيير سلوك المكتبة.

لا يتم تخزين كل المعلومات التي تم جمعها في نمط. يتم تخزين الباقي في هياكل بيانات داخلية. تجعل Xft بعض هذه البيانات متاحة للتطبيق عبر وظائف.

Bool XftDefaultHasRender (
	Display	*dpy);

الحصول على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وإرجاع true إذا وجدت Xft أن الشاشة تدعم امتداد X Render، وإذا كان بإمكانها العثور على XRenderPictFormat مناسب (نوع بيانات X Render الذي يشبه Visual الخاص بـ Xlib) على الشاشة.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

الحصول على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وتعيين نمط Fontconfig الذي يحمل الخصائص الافتراضية التي ستستخدمها Xft لهذه الشاشة.

تستخدم Xft هذه الخصائص مبدئيًا للحصول على هذه الحدود:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). هذا هو الحد الأقصى لذاكرة الرموز الرسومية لجميع الخطوط التي تستخدمها Xft (الافتراضي: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). هذا هو الحد الأقصى لعدد الخطوط غير المشار إليها (الافتراضي: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). عندما تكون صحيحة، تتتبع Xft استخدام ذاكرة الرموز الرسومية لتحسين الأداء عند اتخاذ قرار بشأن ما يجب إلغاء تحميله عند الوصول إلى الحد الأقصى لذاكرة الرموز الرسومية (الافتراضي: false).
تستخدم Xft أيضًا هذه الخصائص الافتراضية في XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

تقوم Xft بملء الخصائص المفقودة في pattern المعطى باستخدام الخصائص الافتراضية للشاشة المحددة dpy، على سبيل المثال، كما تم تعيينها في XftDefaultSet().

تستخدم تطبيقات Xft النموذجية هذه الوظيفة للمساعدة في اختيار Fontconfig لخط مناسب. يتم استبدال هذه الخصائص قبل استدعاء FcDefaultSubstitute():
FC_ANTIALIAS
صحيحة إذا كان يجب على FreeType استخدام تنعيم الحواف (الافتراضي: False). (الافتراضي: True).
FC_AUTOHINT
صحيحة إذا كان يجب على FreeType استخدام التلميح التلقائي (الافتراضي: False).
FC_DPI
النقاط/البوصة المستخدمة للدقة (الافتراضي: محسوبة من ارتفاع الشاشة).
FC_EMBOLDEN
صحيحة إذا كان يجب استخدام FT_GlyphSlot_Embolden() لجعل الخط غامقًا (الافتراضي: False).
FC_HINTING
صحيحة إذا كان يجب استخدام التلميح عند ملء الخصائص لفتح خط (الافتراضي: True).
FC_HINT_STYLE
نمط التلميح المستخدم عند ملء الخصائص لفتح خط (الافتراضي: FC_HINT_FULL).
FC_LCD_FILTER
المعلمة التي يتم تمريرها إلى FT_Library_SetLcdFilter() عند تحميل الرموز الرسومية (الافتراضي: FC_LCD_DEFAULT).
FC_MINSPACE
الحد الأدنى لقيمة المسافة المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: False).
FC_RGBA
قيمة RGBA المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: محسوبة عن طريق استدعاء XRenderQuerySubpixelOrder()).
FC_SCALE
المقياس المستخدم في Fontconfig (الافتراضي: 1.0).
XFT_MAX_GLYPH_MEMORY
الحد الأقصى للذاكرة لخط واحد (الافتراضي: 1024*1024).
XFT_RENDER
صحيحة إذا كانت الشاشة تدعم امتداد X Render (الافتراضي: نتيجة من XftDefaultHasRender()).
FcBool XftInit (

فتح ومطابقة الخطوط



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
تأخذ XftFontOpen قائمة من ثلاثيات عناصر النمط بالشكل field و type و value (تنتهي بـ NULL)، وتطابق هذا النمط مع الخطوط المتاحة، وتفتح الخط المطابق، وتضبط حجمه بشكل صحيح للشاشة رقم screen على الشاشة dpy. ترجع الخط المطابق، أو NULL إذا لم يتم العثور على تطابق.

  




مثال:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
يفتح هذا خط “charter” بحجم 12 نقطة. يتم تحويل حجم النقطة تلقائيًا إلى حجم البكسل الصحيح بناءً على دقة الشاشة.

XftFontInfoDestroy(3)

        
libXft 2.3.9 — X Version 11

    

    

        
NAME

        
XftFontInfoDestroy — destroy XftFontInfo structure

    

    

        
SYNOPSIS

        
#include <X11/Xft/Xft.h>

void XftFontInfoDestroy (
    XftFontInfo *info
);
        

    

    

        
DESCRIPTION

        
The XftFontInfoDestroy() function destroys the
            structure pointed to by info. If the structure contains a
            FreeType face, it is destroyed with FT_Done_Face(). If the
            structure contains a font pattern, the pattern is destroyed with
            FcPatternDestroy().

    

    

        
CONSTANTS

        

            
XftFontInfo

            
A structure containing information about a font, including its
                FreeType face and fontconfig pattern. It also contains a
                reference count for the FreeType face.

        

    

    

        
DATA TYPES

        

            
XftFont

            
A structure representing an opened font. It contains an
                XftFontInfo pointer and other information needed for
                rendering.

        

    

    

        
FUNCTIONS

        

            
XftFontInfo * XftFontInfoCreate (

            

                
	Display		*dpy,
	FcPattern	*pat
;


                
Creates an XftFontInfo structure from the
                    given Fontconfig pattern pat and display dpy.
                    This function is typically used internally by Xft functions,
                    but can be called directly if needed.

            

        

        

            
XftFont * XftFontOpen (

            

                
	Display		*dpy,
	FcPattern	*pat
;


                
Opens a font matching the given Fontconfig pattern
                    pat for the display dpy. If a font is found,
                    an XftFont structure is returned. Otherwise, NULL is
                    returned.

            

        

        

            
XftFont * XftFontOpenInfo (

            

                
	Display		*dpy,
	XftFontInfo	*info,
	FcBool		 need_bitmaps
;


                
Opens a font using the provided XftFontInfo
                    structure info. The need_bitmaps argument
                    indicates whether bitmaps are required for the font. This
                    function is typically used internally.

            

        

        

            
XftFont * XftFontOpenPattern (

            

                
	Display		*dpy,
	FcPattern	*pat
;


                
Opens a font matching the given Fontconfig pattern
                    pat for the display dpy, using an
                    XftFontInfo structure. This is equivalent to calling
                    XftFontInfoCreate followed by
                    XftFontOpenInfo.

            

        

        

            
FcBool XftNameParse (

            

                
	const FcPattern	*pat,
	char	*name,
	int	 len);


                
Parses the given Fontconfig pattern pat into
                    a string representation and stores it in the buffer pointed
                    to by name, up to a maximum length of len.
                    Returns FcTrue on success, FcFalse otherwise.

            

        

        

            
FcPattern * XftNameParse (

            

                
	const char	*name);


                
Xft uses Fontconfig to parse the name,
                    passing the name to FcNameParse(), returning
                    the result.

            

        

        

            
FcBool XftNameUnparse (

            

                
	FcPattern	*pat,
	char	*dest,
	int	 len);


                
Like XfgNameParse(), Xft uses
                    Fontconfig. In this case, it uses FcNameUnparse(),
                    which converts the pattern pat back into a string
                    that can be parsed. XftNameUnparse() stores the
                    result via the caller's pointer dest, but checks
                    first if it will fit, using the len parameter. If it
                    fits, Xft copies the string and returns
                    FcTrue, otherwise it returns FcFalse.

            

        

        

            
Manipulating Font data

            

                
void XftFontLoadGlyphs (

                

                    
	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


                    
Using FT_Load_Glyph(), load nglyphs
                        for the glyph indices (Unicode values) listed in the
                        array glyphs from the given font pub.

                

            

            

                

                
Loading a glyph entails more than just reading data into
                    memory. Xft uses the Fontconfig pattern associated
                    with the display dpy (e.g., via
                    XftDefaultSet()) to determine whether to use a
                    bounding box, clip the glyphs into those bounds, scale the
                    glyphs, compute font metrics, and add it to the X Render
                    extension using XRenderAddGlyphs().

            

            

                
void XftFontUnloadGlyphs (

                

                    
	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


                    
Discards data for up to nglyph glyphs
                        whose glyph indices (Unicode values) are listed in the
                        array glyphs for the given font pub. If
                        the glyphs were added to the X Render extension,
                        Xft removes those using XRenderFreeGlyphs().
                        Xft keeps track of the amount of memory used for
                        glyphs, and updates the usage associated with the
                        display dpy.

                

                
FT_Face XftLockFace (

                

                    
	XftFont	*pub);


                    
If no FreeType 2 “face” (in-memory
                        representation of a given typeface in a given style)
                        has been created for the pub font, create one
                        using FT_New_Face(). Face-locks are a reference
                        count used by Xft to ensure that only one face
                        is created, and that it is retained until the font is
                        no longer used.

                

            

            

                

                
Face-locking is used directly in XftCharIndex() and
                    XftFontLoadGlyphs(), which in turn are used in many
                    functions of Xft.

                

                
Face-locking was introduced in version 1 (October 2002). A few
                    applications, such as Gdk/Gimp relied upon these functions. In
                    version 2.1.9 (June 2006), face-locking was retained as part
                    of the public API when improved shared-library
                    configurations provided for hiding private symbols.

            

            

                
void XftUnlockFace (

                

                    
	XftFont	*pub);


                    
Decrements the reference count for the FreeType
                        2 “face” associated with the font.

                

            

            

                

                
FT_Face objects are deallocated using
                    FT_Done_Face(). Xft does this in
                    XftFontInfoDestroy() and when cleaning up on failure
                    in XftFontInfoCreate() and
                    XftFontOpenPattern().

            

        

    

    

        
DEBUGGING

        
Xft reads the environment variable XFT_DEBUG
            and converts that to an integer. Each bit in the resulting value
            tells Xft to print debugging information to the standard
            output:

        

            
1

            
font-opening

            
2

            
additional font-matching and opening (verbose)

            
4

            
shows details about the XRenderPictFormat which will be
                used.

            
8

            
shows the string which XftDrawString8() will draw.

            
16

            
shows which font-ids are matched.

            
32

            
shows useful information about the glyphs which will be drawn

            
64

            
shows an ASCII-art representation of the glyphs.

            
128

            
shows details about the memory-cache management

            
256

            
shows details about managing glyph cached-memory

            
512

            
shows a report on memory-usage

            
1024

            
shows details on extended management of glyph cached-memory

        

    

    

        
COMPATIBILITY

        
As of version 2 (May 2002), Xft became relatively
            stable. It is expected to retain source and binary compatibility in
            future releases.

        
Xft provides a compatibility interface to its
            previous major version, Xft 1.x, described below.

        

            
Xft 1.x Header File

            
#include <X11/Xft/XftCompat.h>

        

        

            
Xft 1.x Data Types

            

                
XftPattern

                
holds a set of names with associated value lists; each name
                    refers to a property of a font. XftPatterns are used
                    as inputs to the matching code as well as holding
                    information about specific fonts.

                
XftFontSet

                
contains a list of XftPatterns. Internally, Xft
                    uses this data structure to hold sets of fonts. Externally,
                    Xft returns the results of listing fonts in this
                    format.

                
XftObjectSet

                
holds a set of names and is used to specify which fields from
                    fonts are placed in the list of returned patterns when
                    listing fonts.
