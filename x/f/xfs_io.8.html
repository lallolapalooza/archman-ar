extsize [ -R | -D ] [\n value ]
\n
Display and/or modify the preferred extent size used when allocating space\n for the currently open file. If the -R option is specified, a\n recursive descent is performed for all directory entries below the\n currently open file (-D can be used to restrict the output to\n directories only). If the target file is a directory, then the inherited\n extent size is set for that directory (new files created in that directory\n inherit that extent size). The value should be specified in bytes,\n or using one of the usual units suffixes (k, m, g, b, etc). The extent\n size is always reported in units of bytes.

If the target file is a directory, then the\n inherited CoW extent size is set for that directory (new files created in\n that directory inherit that CoW extent size). The value should be\n specified in bytes, or using one of the usual units suffixes (k, m, g, b,\n etc). The extent size is always reported in units of bytes.

أوامر إدخال/إخراج مصفوفة في الذاكرة

mmap [ N | [[ -rwxS ] [-s size ] offset length ]]
بدون وسائط، يعرض mmap التعيينات الحالية. تحديد وسيط رقمي واحد N يضبط التعيين الحالي. إذا تم تحديد وسيطين (نطاق محدد بواسطة offset و length)، يتم إنشاء تعيين جديد يمتد عبر النطاق، ويمكن إعطاء وضع الحماية كمزيج من PROT_READ (-r) و PROT_WRITE (-w) و PROT_EXEC (-x). سيتم إنشاء التعيين باستخدام علامة MAP_SHARED افتراضيًا، أو باستخدام العلامات الخاصة بنظام Linux (MAP_SYNC | MAP_SHARED_VALIDATE) إذا تم توفير -S. يتم استخدام -s size لتنفيذ عملية mmap(size) && munmap(size) أولاً، لمحاولة حجز بعض مساحة الذاكرة الحرة القابلة للتوسيع، إذا كان size أكبر من المعلمة length. ولكن لا يوجد ضمان بأن الذاكرة بعد length ( حتى size) ستظل حرة. مثال "mmap -rw -s 8192 1024" ستقوم بتعيين ذاكرة بحجم 0 ~ 1024 بايت، ولكنها ستحاول حجز مساحة حرة من 1024 ~ 8192 (لا يوجد ضمان). هذه المساحة الحرة ستكون مفيدة لـ "mremap 8192" بدون علامة MREMAP_MAYMOVE.
mm
راجع أمر mmap.
mremap [ -f <new_address> ] [ -m ] new_length
يغير حجم التعيين الحالي إلى new_length. يتم التحكم فيما إذا كان يمكن نقل التعيين بواسطة العلامات التي يتم تمريرها؛ MREMAP_FIXED (-f) أو MREMAP_MAYMOVE (-m). تحدد new_length عنوانًا محاذيًا للصفحة يجب نقل التعيين إليه. يمكن ضبطه على 139946004389888 أو 4096k أو 1g وما إلى ذلك.
mrm
راجع أمر mremap.
munmap
يلغي تعيين الذاكرة الحالي.
mu
راجع أمر munmap.
mread [ -f | -v ] [ -r ] [ offset length ]
يصل إلى شريحة من التعيين الحالي في الذاكرة، ويقوم بتفريغها اختياريًا إلى مجرى الإخراج القياسي (باستخدام الخيار -v أو -f) للفحص. تتم عمليات الوصول بشكل تسلسلي من offset البداية افتراضيًا، ولكن يمكن أيضًا القيام بها من النهاية للخلف عبر التعيين إذا تم تحديد الخيار -r. يختلف الوضعان المطولان فقط في الإزاحات النسبية التي يعرضانها، الخيار -f نسبي لبداية الملف، بينما يعرض -v الإزاحات النسبية لبداية التعيين.
mr
راجع أمر mread.
mwrite [ -r ] [ -S seed ] [ offset length ]
يخزن بايت في الذاكرة لنطاق ضمن تعيين. القيمة الافتراضية المخزنة هي 'X'، مكررة لملء النطاق المحدد، ولكن يمكن تغيير ذلك باستخدام الخيار -S. تتم عمليات تخزين الذاكرة بشكل تسلسلي من إزاحة البداية افتراضيًا، ولكن يمكن أيضًا القيام بها من النهاية للخلف عبر التعيين إذا تم تحديد الخيار -r.
mw
راجع أمر mwrite.
msync [ -i ] [ -a | -s ] [ offset length ]
يكتب جميع النسخ المعدلة من الصفحات فوق النطاق المحدد (أو التعيين بأكمله إذا لم يتم تحديد نطاق) إلى مواقع تخزينها الخلفية. أيضًا، يقوم اختياريًا بالإبطال (-i) بحيث يتم الحصول على المراجع اللاحقة للصفحات من مواقع التخزين الخلفية الخاصة بها (بدلاً من النسخ المخزنة مؤقتًا). يمكن إجراء المسح بشكل متزامن (-s) أو غير متزامن (-a).
ms
راجع أمر msync.
madvise [ -d | -r | -s | -w ] [ offset length ]
يعدل سلوك ذاكرة التخزين المؤقت للصفحات عند العمل على التعيين الحالي. تكون وسائط النطاق مطلوبة بواسطة بعض أوامر النصيحة ([*] أدناه). بدون وسائط، يتم تضمين نصيحة POSIX_MADV_NORMAL (إعادة القراءة الافتراضية).
-d
لن تكون الصفحات مطلوبة (POSIX_MADV_DONTNEED[*]).
-r
توقع مراجع صفحات عشوائية (POSIX_MADV_RANDOM)، مما يضبط إعادة القراءة إلى صفر.
-s
توقع مراجع صفحات متسلسلة (POSIX_MADV_SEQUENTIAL)، مما يضاعف إعادة القراءة الافتراضية للملف.
-w
تنصح بأن الصفحات المحددة ستكون مطلوبة مرة أخرى (POSIX_MADV_WILLNEED[*]) مما يجبر على أقصى إعادة قراءة.
mincore
يقوم بتفريغ قائمة بالصفحات أو نطاقات من الصفحات الموجودة حاليًا في الذاكرة الرئيسية، للتعيين الحالي في الذاكرة.

أوامر نظام الملفات

aginfo [ -a agno ]
عرض معلومات حول أو تحديث حالة مجموعات التخصيص.

-a
التصرف فقط على مجموعة تخصيص محددة.
bulkstat [ -a agno ] [ -d ] [ -e endino ] [ -m ] [ -n batchsize ] [ -q ] [ -s startino ] [ -v version"]
عرض معلومات إحصائية خام حول مجموعة من الـ inodes في نظام ملفات XFS. الخيارات هي كما يلي:
-a agno
عرض النتائج فقط من مجموعة التخصيص المعطاة. إذا لم يتم تحديدها، سيتم عرض جميع النتائج التي تم إرجاعها.
-d
طباعة معلومات تصحيح الأخطاء حول نتائج المكالمة.
-e endino
التوقف عن عرض السجلات عند الوصول إلى رقم الـ inode هذا. افتراضياً، يتوقف عندما تتوقف استدعاءات النظام عن إرجاع النتائج.
-m
تضمين الدلائل الوصفية (metadata directories) في المخرجات.
-n batchsize
استرداد ما لا يزيد عن هذا العدد من السجلات لكل مكالمة. الافتراضي هو 4,096.
-q
تشغيل بهدوء. لا يقوم بتحليل أو إخراج معلومات bulkstat المستردة.
-s startino
عرض سجلات تخصيص الـ inode بدءًا من هذا الـ inode. الافتراضي هو أول inode في نظام الملفات. إذا كان الـ inode المحدد غير مخصص، ستبدأ النتائج مع الـ inode المخصص التالي في نظام الملفات.
-v version
استخدام إصدار معين لواجهة النواة. الإصدارات المدعومة حاليًا هي 1 و 5.
bulkstat_single [ -d ] [ -m ] [ -v version ] [ inum... | special... ]
عرض معلومات إحصائية خام حول الـ inodes الفردية في نظام ملفات XFS. الخيارات -d و -m و -v هي نفسها الموجودة في أمر bulkstat. يجب أن تكون الوسائط عبارة عن أرقام inodes أو أي من القيم الخاصة التالية:
root
عرض معلومات حول inode الدليل الجذر.
freeze
تعليق جميع طلبات إدخال/إخراج الكتابة إلى نظام ملفات الملف الحالي. متاح فقط في الوضع الخبير ويتطلب امتيازات.
thaw
التراجع عن آثار عملية تجميد نظام الملفات. متاح فقط في الوضع الخبير ويتطلب امتيازات.
inject [ tag ]
حقن أخطاء في نظام ملفات لمراقبة سلوك نظام الملفات في نقاط محددة في ظل ظروف معاكسة. بدون وسيط tag، يعرض قائمة علامات الأخطاء المتاحة. متاح فقط في الوضع الخبير ويتطلب امتيازات.
rginfo [ -r rgno ]
عرض معلومات حول أو تحديث حالة مجموعات تخصيص البيانات في الوقت الفعلي.

-r
التصرف فقط على مجموعة بيانات في الوقت الفعلي محددة.
resblks [ blocks ]
الحصول و/أو تعيين عدد الكتل المحجوزة لنظام الملفات باستخدام استدعاءات النظام XFS_IOC_GET_RESBLKS أو XFS_IOC_SET_RESBLKS. ملاحظة -- يمكن أن يكون هذا مفيدًا لاختبار سلوك نفاد المساحة. متاح فقط في الوضع الخبير ويتطلب امتيازات.
shutdown [ -f ]
إجبار نظام الملفات على الإغلاق، ومنع أي عمليات إدخال/إخراج أخرى. يقوم XFS وأنظمة الملفات الأخرى بتنفيذ هذه الوظيفة، على الرغم من أن تفاصيل التنفيذ قد تختلف قليلاً. متاح فقط في الوضع الخبير ويتطلب امتيازات.
افتراضياً، لن يحاول نظام الملفات مسح المعاملات المكتملة إلى القرص قبل إغلاق نظام الملفات. هذا يحاكي فشل القرص أو الانهيار.
-f
إجبار نظام الملفات على مسح جميع المعاملات المكتملة إلى القرص قبل إغلاق نظام الملفات، مما يطابق سلوك XFS عند مواجهة تلف حرج.
statfs [ -c ] [ -g ] [ -s ]
الإبلاغ عن إحصائيات محددة للملف
]
يسرد جميع خصائص نظام الملفات التي تم تخزينها في نظام الملفات. إذا تم تحديد العلامة -v، فإنها تطبع قيم الخصائص.
setfsprops name=value [ name=value... ]
تعيين خصائص نظام الملفات المعطاة إلى القيم المحددة.
removefsprops name [ names... ]
إزالة خصائص نظام الملفات المعطاة.
