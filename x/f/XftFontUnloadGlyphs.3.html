XftFontUnloadGlyphs(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة تقوم برسم النصوص والرسومات:

  • باستخدام المعلومات المقدمة من مكتبة Fontconfig،
  • تقوم Xft بتحويل رموز الخطوط باستخدام مُرسِّم FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X للتقديم (X Rendering Extension).

صفحة الدليل هذه بالكاد تخدش سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، زائد XFT_MINOR مضروبًا في 100، زائد XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت الإصدار لـ Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " تحتاج إلى إصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "Xft"

من Xlib...

لا تتبع أنواع بيانات Xlib اصطلاح تسمية. يتم توثيقها في Xlib - واجهة لغة C.

تستخدم Xft هذه الأسماء: Bool، Colormap، Display، Drawable، Pixmap، Region، Visual، و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معرّف في <X11/X.h>، وهو معرف مورد X، على سبيل المثال، نافذة مرتبطة بشاشة العرض. يمكن استخدام كل من النوافذ والصور (pixmaps) كمصادر ووجهات في عمليات الرسومات. تُعرف هذه النوافذ والصور مجتمعة بأنها رسومات (drawables). ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسومات.
Region
معرّف في <X11/Xutil.h> و <X11/Xregion.h>، Region هو مجموعة اعتباطية من مواقع البكسل التي يمكن لـ Xlib معالجتها. داخليًا، يتم تمثيل Region باتحاد عدد اعتباطي من المستطيلات. تحتفظ Xlib بمستطيل يخبرها بمدى هذا الاتحاد.
Visual
معرّف في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول تعيين الألوان الممكن.

من XRender...

تستلهم أنواع بيانات مكتبة X Rendering Extension من Xlib، لكنها تفتقر إلى التوثيق المقابل. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا لمكتبة libXrender).

تستخدم Xft هذه الأسماء: Picture، XGlyphInfo، XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "Fc" وهي موثقة في مرجع مطوري Fontconfig.

تستخدم Xft هذه الأسماء من Fontconfig: FcBool، FcChar8، FcChar16، FcChar32، FcCharSet، FcEndian، FcFontSet، FcPattern، و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "FT_" وهي موثقة في مرجع واجهة برمجة تطبيقات FreeType.

تستخدم Xft هذه الأسماء: FT_Face، FT_Library، و FT_UInt.

يستخدم FreeType 2 FT_UInt (عدد صحيح غير مُشار إليه) لتمثيل الرموز (glyphs).

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ يحتوي على مقاييس خط عامة ومؤشرات إلى مجموعة أحرف Fontconfig والنمط المرتبط بالخط.

يتم تعبئة XftFonts باستخدام أي من XftFontOpen()، XftFontOpenName()، XftFontOpenXlfd()، XftFontOpenInfo()، أو XftFontOpenPattern(). يتم استخدام XftFontCopy() لنسخ XftFonts، ويتم استخدام XftFontClose() لوضع علامة على XftFont كمستخدم. يتم تخصيص XftFonts داخليًا، ويتم عد مراجعها، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

تستخدم XftDrawGlyphs()، عائلة XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() XftFonts لرسم النصوص إلى كائن XftDraw، والذي قد يتوافق مع رسم X أساسي أو رسم امتداد X للتقديم (X Rendering Extension).

تُستخدم XftGlyphExtents() وعائلة XftTextExtents*() لتحديد أبعاد (أقصى أبعاد) لـ XftFont.

يمكن تحديد تغطية الرموز (glyphs) أو الأحرف لـ XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). ترجع XftCharIndex() فهرس الحرف الخاص بـ XftFont المقابل لنقطة رمز Unicode معينة.

تستخدم XftGlyphRender()، XftGlyphSpecRender()، XftCharSpecRender()، وعائلة XftTextRender*() XftFonts للرسم في هياكل Picture الخاصة بامتداد X للتقديم (X Rendering Extension).

ملاحظة: توفر XftDrawGlyphs()، عائلة XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لتقديم الخطوط تكون مستقلة عن توفر امتداد X للتقديم (X Rendering Extension) على خادم X.

XftFontInfo

هو كائن مبهم يخزن معلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص كائنات XftFontInfo داخليًا وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

يرتبط كل هيكل XftFontInfo قيد الاستخدام بمعرف فريد، والذي يمكن استرداده باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor بتقديم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب تقدمه شاشة العرض X المستخدمة).

تقوم XftColorAllocName() و XftColorAllocValue() بطلب تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. تقوم XftColorFree() بإعلام خادم X بتحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام XftDrawSrcPicture()، XftDrawGlyphs()، عائلة XftDrawString*()، XftDrawCharSpec()، XftDrawCharFontSpec()، XftDrawGlyphSpec()، XftDrawGlyphFontSpec()، و XftDrawRect() لرسم عناصر مختلفة باستخدام

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

XftDraw

هو كائن غير شفاف يحتوي على معلومات تُستخدم للرسم على رسم X باستخدام البروتوكول الأساسي أو امتداد X Rendering.

يتم إنشاء كائنات XftDraw باستخدام أي من الدوال XftDrawCreate() (التي تربط XftDraw برسم X موجود)، أو XftDrawCreateBitmap()، أو XftDrawCreateAlpha()، ويتم تدميرها باستخدام XftDrawDestroy(). يمكن تغيير رسم X المرتبط بـ XftDraw باستخدام XftDrawChange(). يتم تخصيص وتحرير كائنات XftDraw داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص مساحة لها أو تحريرها.

يمكن الاستعلام عن خصائص X Display و Drawable و Colormap و Visual الخاصة بـ XftDraw باستخدام XftDrawDisplay() و XftDrawDrawable() و XftDrawColormap() و XftDrawVisual() على التوالي.

تستخدم العديد من الدوال كائنات XftDraw: XftDrawCharFontSpec() و XftDrawCharSpec() و XftDrawGlyphFontSpec() و XftDrawGlyphSpec() و XftDrawGlyphs() و XftDrawRect() و XftDrawSetClip() و XftDrawSetClipRectangles() و XftDrawSetSubwindowMode() وعائلة الدوال XftDrawString*().

يتم إرجاع امتداد X Rendering Picture المرتبط بـ XftDraw بواسطة XftDrawPicture() و XftDrawSrcPicture(). يتم استخدامه بواسطة XftCharFontSpecRender() و XftCharSpecRender() و XftGlyphFontSpecRender() و XftGlyphRender() و XftGlyphSpecRender() وعائلة الدوال XftTextRender*().

الوظائف

التهيئة

التطبيق النموذجي الذي يستخدم Xft لا يقوم بتهيئة المكتبة بشكل صريح. يتم ذلك عادةً كأثر جانبي لفتح خط.

عندما تبدأ Xft، تقوم بجمع معلومات حول الشاشة، وتخزين بعض تلك المعلومات في نمط Fontconfig (وهو في الأساس مجموعة من الخصائص ذات القيم المصنفة). يمكن للتطبيق المستدعي تعديل هذا النمط لتغيير سلوك المكتبة.

لا يتم تخزين كل المعلومات المجمعة في نمط. يتم تخزين الباقي في هياكل بيانات داخلية. يجعل Xft بعض هذه المعلومات متاحة للتطبيق عبر الدوال.

Bool XftDefaultHasRender (
	Display	*dpy);

الحصول على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وإرجاع صحيح إذا وجدت Xft أن الشاشة تدعم امتداد X Render، وإذا كان بإمكانها العثور على XRenderPictFormat مناسب (نوع بيانات X Render الذي يشبه Visual في Xlib) على الشاشة.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

الحصول على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وتعيين نمط Fontconfig الذي يحمل الخصائص الافتراضية التي ستستخدمها Xft لهذه الشاشة.

تستخدم Xft هذه الخصائص في البداية للحصول على هذه الحدود:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). هذا هو الحد الأقصى لذاكرة الرموز لجميع الخطوط التي تستخدمها Xft (الافتراضي: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). هذا هو الحد الأقصى لعدد الخطوط غير المشار إليها (الافتراضي: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). عندما يكون صحيحًا، تتتبع Xft استخدام ذاكرة الرموز لتحسين الأداء عند اتخاذ قرار بشأن ما يجب إلغاء تحميله عند الوصول إلى الحد الأقصى لذاكرة الرموز (الافتراضي: خطأ).
تستخدم Xft أيضًا هذه الخصائص الافتراضية في XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

تملأ Xft الخصائص المفقودة في pattern المحدد باستخدام الخصائص الافتراضية للشاشة المحددة dpy، على سبيل المثال، كما تم تعيينها في XftDefaultSet().

التطبيقات النموذجية لـ Xft تستخدم هذه الدالة للمساعدة في اختيار Fontconfig لخط مناسب. يتم استبدال هذه الخصائص قبل استدعاء FcDefaultSubstitute():
FC_ANTIALIAS
صحيح إذا كان FreeType يجب أن يستخدم تنعيم الحواف (الافتراضي: خطأ). (الافتراضي: صحيح).
FC_AUTOHINT
صحيح إذا كان FreeType يجب أن يستخدم التلميح التلقائي (الافتراضي: خطأ).
FC_DPI
نقاط/بوصة مستخدمة للدقة (الافتراضي: يتم حسابها من ارتفاع الشاشة).
FC_EMBOLDEN
صحيح إذا كان يجب استخدام FT_GlyphSlot_Embolden() لتغميق خط (الافتراضي: خطأ).
FC_HINTING
صحيح إذا كان يجب استخدام التلميح عند ملء الخصائص لفتح خط (الافتراضي: صحيح).
FC_HINT_STYLE
نمط التلميح المستخدم عند ملء الخصائص لفتح خط (الافتراضي: FC_HINT_FULL).
FC_LCD_FILTER
المعلمة التي تم تمريرها إلى FT_Library_SetLcdFilter() عند تحميل الرموز (الافتراضي: FC_LCD_DEFAULT).
FC_MINSPACE
الحد الأدنى لمساحة القيمة المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: خطأ).
FC_RGBA
قيمة RGBA المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: يتم حسابها عن طريق استدعاء XRenderQuerySubpixelOrder()).
FC_SCALE
المقياس المستخدم في Fontconfig (الافتراضي: 1.0).
XFT_MAX_GLYPH_MEMORY
الحد الأقصى للذاكرة لخط واحد (الافتراضي: 1024*1024).
XFT_RENDER
صحيح إذا كانت الشاشة تدعم امتداد X Render (الافتراضي: نتيجة من XftDefaultHasRender()).
FcBool XftInit (

  • Xft sets the clip_type for the draw parameter to
      XftClipTypeRegion if the r parameter was not null. Otherwise
      it sets the clip_type to XftClipTypeNone.
    • 
  
  • Finally, Xft updates clipping for existing objects, updates the
      clip_mask for its X Render Picture object and sets the
      clipping-mask in the graphic context (GC) associated with the
      XftDraw parameter.
    • 






  

  
XftDrawSetClip() returns True if no change was necessary, or
      if the operation succeeded. It returns False if it was unable to
      create the new Region().





  
Bool

  

    
XftDrawSetClipRectangles (
	XftDraw	*draw,
	int	 xOrigin,
	int	 yOrigin,
	_Xconst XRectangle	*rects,
	int	 n);


    
Like XftDrawSetClip(),
        XftDrawSetClipRectangles() sets up clipping for the given
        XftDraw parameter draw but uses a set of n
        rectangles (the rects parameter) which could be used to construct
        a Region .

  





  

  
Xft sets the clip_type for draw to XftClipTypeRectangles and
      uses XSetClipRectangles() for core (X11) clipping and
      XRenderSetPictureClipRectangles() for X Render clipping.





  
void

  

    
XftDrawSetSubwindowMode (
	XftDraw	*draw,
	int	 mode);


    
Sets the subwindow-mode for the given XftDraw parameter
        draw. The mode can be either ClipByChildren (the default),
        or IncludeInferiors:

  






    
  
  • For ClipByChildren, both source and destination windows are
      additionally clipped by all viewable InputOutput children.
    • 
  
  • For IncludeInferiors, neither source nor destination window is
      clipped by inferiors. This will result in including subwindow contents in
      the source and drawing through subwindow boundaries of the
    destination.
    • 






  

  
In addition to the subwindow-mode maintained by Xft, it updates the
      subwindow mode for any associated graphics context GC using
      XSetSubwindowMode() as well as for an X Render Picture using
      XRenderChangePicture().

void

  

    
XftDrawGlyphFontSpec (
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Draw a list of glyphs associated with fonts at specified
        coordinates, passed as an array of len XftGlyphFontSpec
        structures via the parameter glyphs. All of the glyphs are drawn
        using the color specified in the color parameter.

  





  

  
For each entry in the glyphs array:






    
  
  • If the associated font uses the X Render extension, then Xft uses
      XftGlyphFontSpecRender() to draw the glyph, using a Picture
      obtained from calling XftDrawSrcPicture () with the draw and
      color parameters.
    • 
  
  • Otherwise, Xft provides an analogous feature using Xlib.
    • 






  
void

  

    
XftGlyphFontSpecRender (
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
This involves several steps:

  






    
  
  • First, Xft ensures that the glyphs array is complete using
      XftFontCheckGlyph() and loading any missing glyphs with
      XftFontLoadGlyphs().
    • 
  
  • Then Xft examines the glyphs to find the maximum Unicode value.
      That determines the encoding size, i.e., the width.
    • 
  
  • Then, for each glyph, Xft checks if its Unicode value is handled by
      the corresponding font. If not, the value is set to zero (0), to ignore
      it. While doing this, Xft also remembers which was the first font
      used, and computes the position at which each glyph will be drawn.
    • 
  
  • Xft then constructs an equivalent array of glyphs in the format
      expected by the X Render library.
    • 
  
  • Finally, XftGlyphFontSpecRender() uses the X Render extension to
      draw the glyphs, with the appropriate XRenderCompositeText*()
      function according to the width, and discards temporary data.
    • 




  

  
The op, dst, src, srcx, and srcy
      parameters are used as described in the documentation for the X Render
      library.

التوافق


اعتبارًا من الإصدار 2 (مايو 2002)، أصبح Xft مستقرًا نسبيًا.
    من المتوقع أن يحافظ على التوافق في المصدر والتوافق الثنائي في الإصدارات
    المستقبلية.


يوفر Xft واجهة توافق مع الإصدار الرئيسي السابق، Xft
    1.x، الموضح أدناه.




ملف رأس Xft   1.x


#include <X11/Xft/XftCompat.h>






أنواع بيانات Xft   1.x



  
XftPattern

  
يحتوي على مجموعة من الأسماء مع قوائم قيم مرتبطة؛ يشير كل اسم إلى خاصية
      للخط. تستخدم XftPattern كمدخلات لرمز المطابقة وكذلك للاحتفاظ
      بمعلومات حول خطوط معينة.

  
XftFontSet

  
يحتوي على قائمة من XftPattern. داخليًا، يستخدم
      Xft هيكل البيانات هذا للاحتفاظ بمجموعات الخطوط. خارجيًا، يعيد
      Xft نتائج قائمة الخطوط بهذا التنسيق.

  
XftObjectSet

  
يحتوي على مجموعة من الأسماء ويستخدم لتحديد أي حقول من الخطوط يتم
      وضعها في قائمة الأنماط المعادة عند سرد الخطوط.
