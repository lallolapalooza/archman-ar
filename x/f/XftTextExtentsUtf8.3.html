XftTextExtentsUtf8(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة ترسم النصوص والرسومات:

  • باستخدام المعلومات المقدمة من مكتبة Fontconfig،
  • Xft تحول رموز الخطوط باستخدام مولد الأشكال FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X Rendering.

صفحة الدليل هذه بالكاد تخدش سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الفرعي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، بالإضافة إلى XFT_MINOR مضروبًا في 100، بالإضافة إلى XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت إصدار Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " نحتاج إلى إصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اتفاقية تسمية، تسبق جميع الأسماء بـ "Xft"

من Xlib...

لا تتبع أنواع بيانات Xlib اتفاقية تسمية. وهي موثقة في Xlib - C Language Interface.

يستخدم Xft هذه الأسماء: Bool، Colormap، Display، Drawable، Pixmap، Region، Visual، و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معلن عنه في <X11/X.h>، هذا هو معرف مورد X، على سبيل المثال، نافذة مرتبطة بعرض. يمكن استخدام كل من النوافذ والصور (pixmaps) كمصادر ووجهات في عمليات الرسومات. تُعرف هذه النوافذ والصور مجتمعة باسم قابلة للرسم (drawables). ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسومات.
Region
معلن عنه في <X11/Xutil.h> و <X11/Xregion.h>، Region هو مجموعة اعتباطية من مواقع البكسل التي يمكن لـ Xlib معالجتها. داخليًا، يتم تمثيل Region باتحاد عدد اعتباطي من المستطيلات. تحتفظ Xlib بمستطيل يخبرنا بمدى هذا الاتحاد.
Visual
معلن عنه في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول تعيين الألوان الممكن.

من XRender...

أنواع بيانات مكتبة X Render Extension مستوحاة من Xlib، ولكن تفتقر إلى الوثائق المقابلة. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا عامًا لـ libXrender).

يستخدم Xft هذه الأسماء: Picture، XGlyphInfo، XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اتفاقية تسمية، تسبق جميع الأسماء بـ "Fc" والتي يتم توثيقها في Fontconfig Developers Reference.

يستخدم Xft أسماء Fontconfig هذه: FcBool، FcChar8، FcChar16، FcChar32، FcCharSet، FcEndian، FcFontSet، FcPattern، و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اتفاقية تسمية، تسبق جميع الأسماء بـ "FT_" والتي يتم توثيقها في FreeType API Reference.

يستخدم Xft هذه الأسماء: FT_Face، FT_Library، و FT_UInt.

يستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل الرموز (glyphs).

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ فهو يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig والنمط المرتبطين بالخط.

يتم ملء XftFonts باستخدام أي من XftFontOpen()، XftFontOpenName()، XftFontOpenXlfd()، XftFontOpenInfo()، أو XftFontOpenPattern(). يتم استخدام XftFontCopy() لمضاعفة XftFonts، ويتم استخدام XftFontClose() لوضع علامة على XftFont كغير مستخدم. يتم تخصيص XftFonts داخليًا، وعدها مرجعيًا، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

تستخدم XftDrawGlyphs()، عائلة XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() XftFonts لرسم النصوص إلى كائن XftDraw، والذي قد يتوافق مع رسم أساسي لـ X أو رسم امتداد X Rendering.

تُستخدم XftGlyphExtents() وعائلة XftTextExtents*() لتحديد الامتدادات (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية الرموز (glyphs) أو الأحرف لـ XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). ترجع XftCharIndex() فهرس الحرف الخاص بـ XftFont المقابل لنقطة ترميز Unicode معينة.

تستخدم XftGlyphRender()، XftGlyphSpecRender()، XftCharSpecRender()، وعائلة XftTextRender*() XftFonts لل رسم في هياكل Picture الخاصة بـ X Rendering Extension.

ملاحظة: توفر XftDrawGlyphs()، وعائلة XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لرسم الخطوط مستقلة عن توفر امتداد X Rendering على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن معلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، ويتم تحريرها باستخدام XftFontInfoDestroy()، ويتم مقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص XftFontInfo داخليًا وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

كل هيكل XftFontInfo قيد الاستخدام مرتبط بمعرف فريد، يمكن استرداده باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor برسم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب تقدمه رؤية X المستخدمة).

يقوم XftColorAllocName() و XftColorAllocValue() بطلب تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. يطلب XftColorFree() من خادم X تحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام XftDrawSrcPicture()، XftDrawGlyphs()، عائلة XftDrawString*()، XftDrawCharSpec()، XftDrawCharFontSpec()، XftDrawGlyphSpec()، XftDrawGlyphFontSpec()، و XftDrawRect() لرسم كائنات مختلفة باستخدام

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

This man page describes the Xft library and its associated data types and functions. It is intended for use by developers who want to render text using TrueType fonts in X applications.

The Xft library provides a convenient interface to the FreeType library, allowing applications to render TrueType fonts using the X Rendering Extension. Xft uses the Fontconfig library to locate and match fonts, making it easy to use a wide variety of fonts in applications.

The Xft library is designed to be used with the X Rendering Extension, which provides hardware acceleration for 2D graphics rendering. This allows applications to render text and other graphics smoothly and efficiently.

The Xft library also provides support for color fonts and anti-aliasing, allowing applications to render text with high quality.

XftDraw

is an opaque object which holds information used to render to an X drawable using either the core protocol or the X Rendering extension.

XftDraw objects are created with any of XftDrawCreate() (which associates an XftDraw with an existing X drawable), XftDrawCreateBitmap(), or XftDrawCreateAlpha(), and destroyed with XftDrawDestroy(). The X drawable associated with an XftDraw can be changed with XftDrawChange(). XftDraw objects are internally allocated and freed by Xft; the programmer does not ordinarily need to allocate or free storage for them.

The X Display, Drawable, Colormap, and Visual properties of an XftDraw can be queried with XftDrawDisplay(), XftDrawDrawable(), XftDrawColormap(), and XftDrawVisual(), respectively.

Several functions use XftDraw objects: XftDrawCharFontSpec(), XftDrawCharSpec(), XftDrawGlyphFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphs(), XftDrawRect(), XftDrawSetClip(), XftDrawSetClipRectangles(), XftDrawSetSubwindowMode(), and the XftDrawString*() family.

The X Rendering Extension Picture associated with an XftDraw is returned by XftDrawPicture(), and XftDrawSrcPicture(). It is used by XftCharFontSpecRender(), XftCharSpecRender(), XftGlyphFontSpecRender(), XftGlyphRender(), XftGlyphSpecRender(), and the XftTextRender*() family.

FUNCTIONS

Initialization

A typical application using Xft does not explicitly initialize the library. That is usually done as a side-effect of opening a font.

When Xft initializes, it collects information about the display, and stores some of that information in a Fontconfig pattern (essentially a collection of properties with typed values). The calling application can modify that pattern to change the library's behavior.

Not all of the collected information is stored in a pattern. The remainder is stored in internal data structures. Xft makes some of that available to the application via functions.

Bool XftDefaultHasRender (
	Display	*dpy);

Obtain information about the display dpy if not done already, and return true if Xft found that the display supports the X Render extension, and if it is able to find a suitable XRenderPictFormat (X Render's datatype which is analogous to Xlib's Visual) on the display.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

Obtain information about the display dpy if not done already, and set the Fontconfig pattern holding default properties which Xft will use for this display.

Xft uses those properties initially to obtain these limits:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). This is the maximum amount of glyph memory for all fonts used by Xft (default: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). This is the maximum number of unreferenced fonts (default: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). When true, Xft tracks usage of glyph memory to improve performance when deciding which to unload when the maximum amount of glyph memory is reached (default: false).
Xft also uses these default properties in XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

Xft fills in missing properties in the given pattern using default properties for the specified display dpy, e.g., as set in XftDefaultSet().

Typical Xft applications use this function to help Fontconfig choose a suitable font. These properties are substituted before calling FcDefaultSubstitute():
FC_ANTIALIAS
True if FreeType should use antialiasing (default: False). (default: True).
FC_AUTOHINT
True if FreeType should use autohinting (default: False).
FC_DPI
Dots/inch used for resolution (default: computed from the display height).
FC_EMBOLDEN
True if FT_GlyphSlot_Embolden() should be used to embolden a font (default: False).
FC_HINTING
True if hinting should be used when filling in properties to open a font (default: True).
FC_HINT_STYLE
Hinting style used when filling in properties to open a font (default: FC_HINT_FULL).
FC_LCD_FILTER
Parameter passed to FT_Library_SetLcdFilter() when loading glyphs (default: FC_LCD_DEFAULT).
FC_MINSPACE
Minimum space value used when filling in properties to open a font (default: False).
FC_RGBA
RGBA value used when filling in properties to open a font (default: computed by calling XRenderQuerySubpixelOrder()).
FC_SCALE
Scale used in Fontconfig (default: 1.0).
XFT_MAX_GLYPH_MEMORY
Maximum memory for one font (default: 1024*1024).
XFT_RENDER
True if the display supports X Render extension (default: result from XftDefaultHasRender()).
FcBool XftInit (
	_Xconst char	*config);

Initializes the Fontconfig library (calling FcInit()).

The config parameter is unused.
Xft does not deinitialize the Fontconfig library when it is done.
FcBool XftInitFtLibrary (void);

    
Initializes the FreeType library (calling
        FT_Init_FreeType() to create a library object) if it has not
        already been initialized. This is needed before using the FreeType
        library to read font data from a file.

  





  

  
Xft calls XftInitFtLibrary() internally via
      XftFontInfoCreate() and XftFontOpenPattern().

  

  
Xft does not discard the library object (e.g., using
      FT_Done_FreeType()) when it is done.

Opening   and Matching Fonts



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
XftFontOpen takes a list of pattern element triples of
        the form field, type, value (terminated with a
        NULL), matches that pattern against the available fonts, and opens the
        matching font, sizing it correctly for screen number screen on
        display dpy. Return the matched font, or NULL if no match is
        found.

  




Example:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
This opens the “charter” font at 12 points. The point size
      is automatically converted to the correct pixel size based on the
      resolution of the monitor.

NAME


Xft - X FreeType library






SYNOPSIS


#include <X11/Xft/Xft.h>






DESCRIPTION


The Xft library provides a bridge between the X Window
    System, the FreeType 2 library, and the Fontconfig font-configuration
    interface. It provides a method for applications to render fonts using
    FreeType 2 and to query font information through Fontconfig.


Xft aims to provide a modern, flexible, and feature-rich
    interface for font handling in X applications.




Fonts and Patterns


Font selection in Xft is based on Fontconfig
    patterns. A pattern is a structure that holds a set of name-value pairs,
    where names represent font properties (like family, style, size) and values
    specify the desired attributes. Applications construct patterns to specify
    their font requirements, and Fontconfig uses these patterns to find
    the best matching font available on the system.


Xft uses these patterns to open fonts via
    XftFontOpenPattern(). This function returns an XftFont
    structure, which contains information about the selected font, including
    metrics, glyph data, and a pointer to the underlying FreeType 2 face
    structure.






Rendering


Xft leverages the X Render extension for high-quality
    font rendering. It can render text directly to an X drawable (like a window
    or pixmap) using functions like XftDrawString(),
    XftDrawGlyphSpec(), etc. The rendering process involves loading glyphs
    from the font using FreeType 2 and then drawing them using the X Render
    extension's glyph drawing capabilities.


Xft also provides functions to query font metrics and
    text extents (e.g., XftTextExtentsUtf8()), allowing applications to
    calculate the space required for rendering text accurately.






Glyphs


Xft manages glyphs, which are the graphical representations
    of characters. It can load glyphs using FreeType 2 and cache them for
    efficient rendering. Functions like XftFontLoadGlyphs() and
    XftFontUnloadGlyphs() allow applications to control glyph loading
    and unloading, optimizing memory usage.








CONSTANTS


Various constants are defined by Xft for use in its
    functions and data structures. These often relate to font properties,
    rendering flags, and error codes.






DATA TYPES



  
XftFont

  
Represents an opened font. It contains font metrics, references to the
      underlying FreeType 2 face, and information for rendering.

  
XftPattern

  
A structure used to describe font properties. It's used for matching
      fonts and for holding font information.

  
XftColor

  
Represents a color, typically used for text rendering.

  
XftDraw

  
Represents a drawable surface (window or pixmap) configured for Xft
      rendering.

  
FcPattern

  
(From Fontconfig) Represents a font pattern.

  
FcConfig

  
(From Fontconfig) Represents the font configuration.

shows details about the XRenderPictFormat used.

shows the string being drawn by XftDrawString8().

shows which font-ids are matched.

  
32

  
shows useful information about the glyphs being drawn.

  
64

  
shows an ASCII-art representation of the glyphs.

  
128

  
shows details about memory-cache management.

  
256

  
shows details about managing glyph cached-memory.

  
512

  
shows a report on memory usage.

COMPATIBILITY


Xft aims to maintain compatibility between its versions.
    Specifically, it provides compatibility with the Xft 1.x interface.




Xft 1.x Header File


For compatibility with Xft 1.x, include:


    #include <X11/Xft/XftCompat.h>







Xft 1.x Data Types


The following data types were used in Xft 1.x and may be relevant
    for compatibility:



  
XftPattern

  
Holds a set of names with associated value lists; each name refers to a
      property of a font. Used as input for matching and for holding font
      information.

  
XftFontSet

  
Contains a list of XftPatterns. Used internally by Xft to
      hold sets of fonts and externally to return the results of font listing
      operations.

  
XftObjectSet

  
Holds a set of names. Used to specify which fields from fonts are included
      in lists of patterns when querying fonts.
