XftColorFree(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة تقوم برسم النصوص والرسومات:

  • باستخدام المعلومات التي توفرها مكتبة Fontconfig،
  • تقوم Xft بتحويل رموز الخطوط باستخدام عارض FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X للرسم.

صفحة الدليل هذه بالكاد تخدش سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، بالإضافة إلى XFT_MINOR مضروبًا في 100، بالإضافة إلى XFT_REVISION.
XftVersion
هو اسم بديل لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت إصدار Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد
                 الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " نحتاج إلى الإصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "Xft"

من Xlib...

لا تتبع أنواع بيانات Xlib اصطلاح تسمية. تم توثيقها في Xlib - واجهة لغة C.

تستخدم Xft هذه الأسماء: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual, و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معلن عنه في <X11/X.h>، هذا هو معرف مورد X، على سبيل المثال، نافذة مرتبطة بعرض. يمكن استخدام كل من النوافذ والـ pixmaps كمصادر ووجهات في عمليات الرسومات. تسمى هذه النوافذ والـ pixmaps بشكل جماعي بـ drawables. ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسومات.
Region
معلن عنه في <X11/Xutil.h> و <X11/Xregion.h>، Region هي مجموعة عشوائية من مواقع البكسل التي يمكن لـ Xlib معالجتها. داخليًا، يتم تمثيل Region باتحاد عدد عشوائي من المستطيلات. تحتفظ Xlib بمستطيل يبلغها بمدى هذا الاتحاد.
Visual
معلن عنه في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول مخطط الألوان الممكن.

من XRender...

تم استلهام أنواع بيانات مكتبة امتداد X للرسم من Xlib، ولكنها تفتقر إلى الوثائق المقابلة. ارجع إلى ملف الرأس للتفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا لمكتبة libXrender).

تستخدم Xft أسماء Fontconfig هذه: Picture, XGlyphInfo, XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "Fc" وهي موثقة في دليل مطوري Fontconfig.

تستخدم Xft أسماء Fontconfig هذه: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern, و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "FT_" وهي موثقة في دليل واجهة برمجة تطبيقات FreeType.

تستخدم Xft هذه الأسماء: FT_Face, FT_Library, و FT_UInt.

تستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل الرموز.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الرئيسي الذي يهم المبرمجين الذين يستخدمون Xft؛ فهو يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig ونمط الخط المرتبط بالخط.

يتم ملء XftFonts باستخدام أي من XftFontOpen()، XftFontOpenName()، XftFontOpenXlfd()، XftFontOpenInfo()، أو XftFontOpenPattern(). يستخدم XftFontCopy() لنسخ XftFonts، ويستخدم XftFontClose() لتمييز XftFont كغير مستخدم. يتم تخصيص XftFonts داخليًا، ويتم عد المراجع، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

تستخدم XftDrawGlyphs()، وعائلة XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec() XftFonts لرسم النص إلى كائن XftDraw، والذي قد يتوافق مع إما كائن رسم X أساسي أو كائن رسم امتداد X للرسم.

تستخدم XftGlyphExtents() وعائلة XftTextExtents*() لتحديد امتدادات (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية الرموز أو الأحرف لـ XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). XftCharIndex() ترجع فهرس الأحرف الخاص بـ XftFont المقابل لنقطة رمز Unicode معينة.

تستخدم XftGlyphRender()، و XftGlyphSpecRender()، و XftCharSpecRender()، وعائلة XftTextRender*() XftFonts للرسم في هياكل Picture الخاصة بامتداد X للرسم.

ملاحظة: توفر XftDrawGlyphs()، وعائلة XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لرسم الخطوط مستقلة عن توفر امتداد X للرسومات على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن معلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص كائنات XftFontInfo داخليًا وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

يرتبط كل هيكل XftFontInfo قيد الاستخدام بمعرف فريد، والذي يمكن استرجاعه باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor برسم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب يقدمه عرض X قيد الاستخدام).

تطلب XftColorAllocName() و XftColorAllocValue() تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. تطلب XftColorFree() من خادم X تحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام XftDrawSrcPicture()، و XftDrawGlyphs()، وعائلة XftDrawString*()، و XftDrawCharSpec()، و XftDrawCharFontSpec()، و XftDrawGlyphSpec()، و XftDrawGlyphFontSpec()، و XftDrawRect() لرسم عناصر مختلفة باستخدامها.

XftDraw

هو كائن غير شفاف يحتوي على معلومات تُستخدم للعرض على رسم X باستخدام البروتوكول الأساسي أو امتداد X Rendering.

يتم إنشاء كائنات XftDraw باستخدام أي من XftDrawCreate() (التي تربط XftDraw برسم X موجود) أو XftDrawCreateBitmap() أو XftDrawCreateAlpha()، ويتم تدميرها باستخدام XftDrawDestroy(). يمكن تغيير رسم X المرتبط بـ XftDraw باستخدام XftDrawChange(). يتم تخصيص كائنات XftDraw وتحريرها داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

يمكن الاستعلام عن خصائص X Display و Drawable و Colormap و Visual الخاصة بـ XftDraw باستخدام XftDrawDisplay() و XftDrawDrawable() و XftDrawColormap() و XftDrawVisual() على التوالي.

تستخدم العديد من الوظائف كائنات XftDraw: XftDrawCharFontSpec() و XftDrawCharSpec() و XftDrawGlyphFontSpec() و XftDrawGlyphSpec() و XftDrawGlyphs() و XftDrawRect() و XftDrawSetClip() و XftDrawSetClipRectangles() و XftDrawSetSubwindowMode() وعائلة XftDrawString*().

يتم إرجاع امتداد X Rendering Picture المرتبط بـ XftDraw بواسطة XftDrawPicture() و XftDrawSrcPicture(). يتم استخدامه بواسطة XftCharFontSpecRender() و XftCharSpecRender() و XftGlyphFontSpecRender() و XftGlyphRender() و XftGlyphSpecRender() وعائلة XftTextRender*().

الوظائف

التهيئة

التطبيق النموذجي الذي يستخدم Xft لا يقوم بتهيئة المكتبة بشكل صريح. يتم ذلك عادةً كنتيجة جانبية لفتح خط.

عندما تقوم Xft بالتهيئة، فإنها تجمع معلومات حول العرض، وتخزن بعض تلك المعلومات في نمط Fontconfig (أساسًا مجموعة من الخصائص ذات القيم المصنفة). يمكن للتطبيق المستدعي تعديل هذا النمط لتغيير سلوك المكتبة.

لا يتم تخزين جميع المعلومات المجمعة في نمط. يتم تخزين الباقي في هياكل بيانات داخلية. توفر Xft بعض هذه المعلومات للتطبيق عبر الوظائف.

Bool XftDefaultHasRender (
	Display	*dpy);

الحصول على معلومات حول العرض dpy إذا لم يتم ذلك بالفعل، وإرجاع true إذا وجدت Xft أن العرض يدعم امتداد X Render، وإذا كان قادرًا على العثور على XRenderPictFormat مناسب (نوع بيانات X Render الذي يماثل Visual في Xlib) على العرض.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

الحصول على معلومات حول العرض dpy إذا لم يتم ذلك بالفعل، وتعيين نمط Fontconfig الذي يحتوي على الخصائص الافتراضية التي ستستخدمها Xft لهذا العرض.

تستخدم Xft تلك الخصائص مبدئيًا للحصول على هذه الحدود:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). هذا هو الحد الأقصى لذاكرة الرموز لجميع الخطوط التي تستخدمها Xft (الافتراضي: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). هذا هو الحد الأقصى لعدد الخطوط غير المشار إليها (الافتراضي: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). عندما تكون صحيحة، تتعقب Xft استخدام ذاكرة الرموز لتحسين الأداء عند اتخاذ قرار بشأن ما يجب إلغاء تحميله عند الوصول إلى الحد الأقصى لذاكرة الرموز (الافتراضي: false).
تستخدم Xft أيضًا هذه الخصائص الافتراضية في XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

تقوم Xft بملء الخصائص المفقودة في pattern المعطى باستخدام الخصائص الافتراضية للعرض المحدد dpy، على سبيل المثال، كما هو محدد في XftDefaultSet().

تستخدم تطبيقات Xft النموذجية هذه الوظيفة لمساعدة Fontconfig في اختيار خط مناسب. يتم استبدال هذه الخصائص قبل استدعاء FcDefaultSubstitute():
FC_ANTIALIAS
صحيح إذا كان FreeType يجب أن يستخدم تلطيف الحواف (الافتراضي: False). (الافتراضي: True).
FC_AUTOHINT
صحيح إذا كان FreeType يجب أن يستخدم التلميح التلقائي (الافتراضي: False).
FC_DPI
نقاط/بوصة المستخدمة للدقة (الافتراضي: محسوب من ارتفاع العرض).
FC_EMBOLDEN
صحيح إذا كان يجب استخدام FT_GlyphSlot_Embolden() لجعل الخط أكثر سمكًا (الافتراضي: False).
FC_HINTING
صحيح إذا كان يجب استخدام التلميح عند ملء الخصائص لفتح خط (الافتراضي: True).
FC_HINT_STYLE
أسلوب التلميح المستخدم عند ملء الخصائص لفتح خط (الافتراضي: FC_HINT_FULL).
FC_LCD_FILTER
معلمة يتم تمريرها إلى FT_Library_SetLcdFilter() عند تحميل الرموز (الافتراضي: FC_LCD_DEFAULT).
FC_MINSPACE
قيمة المساحة الدنيا المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: False).
FC_RGBA
قيمة RGBA المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: محسوب عن طريق استدعاء XRenderQuerySubpixelOrder()).
FC_SCALE
المقياس المستخدم في Fontconfig (الافتراضي: 1.0).
XFT_MAX_GLYPH_MEMORY
الحد الأقصى للذاكرة لخط واحد (الافتراضي: 1024*1024).
XFT_RENDER
صحيح إذا كان العرض يدعم امتداد X Render (الافتراضي: نتيجة من XftDefaultHasRender()).

NAME


Xft - font handling library






SYNOPSIS


#include <X11/Xft/Xft.h>







DESCRIPTION


The Xft library provides font handling for X applications.
    It is based on FreeType 2 and Fontconfig. This library provides functions for
    opening, rendering, and managing fonts. It integrates with the X Render
    extension for efficient font rendering.




Font handling functions



  
FcPattern *XftFontOpen (

  

    
	Display	*dpy,
	FcPattern	*pat);


    
Opens a font matching the given pattern. If multiple fonts match,
        the best match is chosen. Returns a pointer to an XftFont structure
        on success, or NULL on failure.

  

  
FcPattern *XftFontOpenName (

  

    
	Display	*dpy,
	char	*name);


    
Opens a font given its name. The name is parsed using Fontconfig.
        Returns a pointer to an XftFont structure on success, or NULL
        on failure.

  

  
FcPattern *XftFontOpenInfo (

  

    
	Display	*dpy,
	FcPattern	*pat,
	XftFontInfo	**info);


    
Similar to XftFontOpen(), but also returns font information
        in the info argument.

  

  
XftFont *XftFontOpen padrões() (

  

    
	Display	*dpy,
	FcPattern	*pat);


    
Opens a font matching the given pattern. This function is
        an alias for XftFontOpen().

  

  
void XftFontClose (

  

    
	Display	*dpy,
	XftFont	*font);


    
Closes the specified font and frees associated resources.

  








Pattern handling functions



  
FcPattern *XftNameParse (

  

    
	char	*name);


    
Parses a font name string into a Fontconfig pattern.
        Xft uses Fontconfig to parse the name, passing the name to
        FcNameParse(), returning the result.

  

  
FcBool XftNameUnparse (

  

    
	FcPattern	*pat,
	char	*dest,
	int	 len);


    
Converts a Fontconfig pattern back into a font name string.
        Xft uses Fontconfig. In this case, it uses FcNameUnparse(),
        which converts the pattern pat back into a string that can be
        parsed. XftNameUnparse() stores the result via the caller's
        pointer dest, but checks first if it will fit, using the len
        parameter. If it fits, Xft copies the string and returns
        FcTrue, otherwise it returns FcFalse.

  








Manipulating   Font data



  
void XftFontLoadGlyphs (

  

    
	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


    
Loads glyphs for the specified font. Using
        FT_Load_Glyph(), load nglyphs for the glyph indices (Unicode
        values) listed in the array glyphs from the given font pub.

  





  

  
Loading a glyph entails more than just reading data into memory.
      Xft uses the Fontconfig pattern associated with the display
      dpy (e.g., via XftDefaultSet()) to determine whether to use
      a bounding box, clip the glyphs into those bounds, scale the glyphs,
      compute font metrics, and add it to the X Render extension using
      XRenderAddGlyphs().





  
void XftFontUnloadGlyphs (

  

    
	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);


    
Unloads glyphs from the specified font. Discards data for up to
        nglyph glyphs whose glyph indices (Unicode values) are listed in
        the array glyphs for the given font pub. If the glyphs
        were added to the X Render extension, Xft removes those using
        XRenderFreeGlyphs(). Xft keeps track of the amount of memory
        used for glyphs, and updates the usage associated with the display
        dpy.

  

  
FT_Face XftLockFace (

  

    
	XftFont	*pub);


    
Locks the FreeType face for the font. If no FreeType 2
        “face” (in-memory representation of a given typeface in a given
        style) has been created for the pub font, create one using
        FT_New_Face(). Face-locks are a reference count used by Xft to
        ensure that only one face is created, and that it is retained until the
        font is no longer used.

  





  

  
Face-locking is used directly in XftCharIndex() and
      XftFontLoadGlyphs(), which in turn are used in many functions of
      Xft.

  

  
Face-locking was introduced in version 1 (October 2002). A few
      applications, such as Gdk/Gimp relied upon these functions. In version
      2.1.9 (June 2006), face-locking was retained as part of the public API
      when improved shared-library configurations provided for hiding private
      symbols.





  
void XftUnlockFace (

  

    
	XftFont	*pub);


    
Unlocks the FreeType face for the font. Decrements the reference
        count for the FreeType 2 “face” associated with the font.

  





  

  
FT_Face objects are deallocated using FT_Done_Face().
      Xft does this in XftFontInfoDestroy() and when cleaning up
      on failure in XftFontInfoCreate() and
      XftFontOpenPattern().










DEBUGGING


Xft reads the environment variable XFT_DEBUG and
    converts that to an integer. Each bit in the resulting value tells
    Xft to print debugging information to the standard output:



  
1

  
font-opening

  
2

  
additional font-matching and opening (verbose)

  
4

  
shows details about the XRenderPictFormat which will be used.

  
8

  
shows the string which XftDrawString8() will draw.

  
16

  
shows which font-ids are matched.

  
32

  
shows useful information about the glyphs which will be drawn

  
64

  
shows an ASCII-art representation of the glyphs.

  
128

  
shows details about the memory-cache management

  
256

  
shows details about managing glyph cached-memory

  
512

  
shows a report on memory-usage

  
1024

  
shows details on extended management of glyph cached-memory








COMPATIBILITY


As of version 2 (May 2002), Xft became relatively stable.
    It is expected to retain source and binary compatibility in future
    releases.


Xft provides a compatibility interface to its previous
    major version, Xft 1.x, described below.




Xft   1.x Header File


#include <X11/Xft/XftCompat.h>






Xft   1.x Data Types



  
XftPattern

  
holds a set of names with associated value lists; each name refers to a
      property of a font. XftPatterns are used as inputs to the matching
      code as well as holding information about specific fonts.

  
XftFontSet

  
contains a list of XftPatterns. Internally, Xft uses this
      data structure to hold sets of fonts. Externally, Xft returns the
      results of listing fonts in this format.

  
XftObjectSet

  
holds a set of names and is used to specify which fields from fonts are
      placed in the list of returned patterns when listing fonts.
