Xft(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) X Version 11 Xft(3)

الاسم

Xft - واجهة مكتبة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة ترسم النصوص والرسومات:

  • باستخدام المعلومات التي توفرها مكتبة Fontconfig،
  • تقوم Xft بتحويل رموز الخطوط (glyphs) باستخدام برنامج FreeType لتصيير (rasterizer)، و
  • تعرض بيانات الخطوط المحولة باستخدام امتداد X للرسم (X Rendering Extension).

صفحة الدليل هذه لا تتجاوز السطح الخارجي لهذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، بالإضافة إلى XFT_MINOR مضروبًا في 100، بالإضافة إلى XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت الإصدار الخاصة بـ Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " نحتاج إلى إصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اصطلاح تسمية، حيث يتم إضافة البادئة "Xft" إلى جميع الأسماء.

من Xlib...

لا تتبع أنواع بيانات Xlib اصطلاح تسمية. تم توثيقها في Xlib - واجهة لغة C.

تستخدم Xft هذه الأسماء: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual, و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معلن عنه في <X11/X.h>، وهو معرّف مورد X، على سبيل المثال، نافذة مرتبطة بعرض. يمكن استخدام كل من النوافذ والـ pixmaps كمصادر ووجهات في عمليات الرسومات. تُعرف هذه النوافذ والـ pixmaps مجتمعة باسم drawables. ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسومات.
Region
معلن عنه في <X11/Xutil.h> و <X11/Xregion.h>، Region هي مجموعة عشوائية من مواقع البكسل التي يمكن لـ Xlib معالجتها. داخليًا، Region تمثل اتحاد عدد عشوائي من المستطيلات. تحتفظ Xlib بمستطيل يخبرها بمدى هذا الاتحاد.
Visual
معلن عنه في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول تعيين الألوان المحتمل.

من XRender...

أنواع بيانات مكتبة امتداد X للرسم مستوحاة من Xlib، ولكن تفتقر إلى التوثيق المقابل. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا لـ libXrender).

تستخدم Xft هذه الأسماء: Picture, XGlyphInfo, XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اصطلاح تسمية، حيث يتم إضافة البادئة "Fc" إلى جميع الأسماء، والتي تم توثيقها في مرجع مطوري Fontconfig.

تستخدم Xft هذه الأسماء من Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern, و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اصطلاح تسمية، حيث يتم إضافة البادئة "FT_" إلى جميع الأسماء، والتي تم توثيقها في مرجع واجهة برمجة تطبيقات FreeType.

تستخدم Xft هذه الأسماء: FT_Face, FT_Library, و FT_UInt.

يستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل رموز الخطوط (glyphs).

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ فهو يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig والنمط المرتبط بالخط.

يتم ملء XftFonts باستخدام أي من الوظائف: XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), أو XftFontOpenPattern(). تُستخدم XftFontCopy() لتكرار XftFonts، وتُستخدم XftFontClose() لتمييز XftFont على أنه غير مستخدم. يتم تخصيص XftFonts وإدارة عداد المراجع وتحريرها داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

تستخدم XftDrawGlyphs()، وعائلة الدوال XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() XftFonts لرسم النص في كائن XftDraw، والذي قد يتوافق مع رسم X أساسي أو رسم امتداد X للرسم.

تُستخدم XftGlyphExtents() وعائلة الدوال XftTextExtents*() لتحديد مدى (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية الرموز أو أحرف XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). تُرجع XftCharIndex() فهرس الحرف الخاص بـ XftFont المقابل لنقطة رمز Unicode معينة.

تستخدم XftGlyphRender() و XftGlyphSpecRender() و XftCharSpecRender() وعائلة الدوال XftTextRender*() XftFonts للرسم في هياكل Picture الخاصة بامتداد X للرسم.

ملاحظة: توفر XftDrawGlyphs()، وعائلة الدوال XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لرسم الخطوط مستقلة عن توفر امتداد X للرسومات على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن معلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص وتحرير كائنات XftFontInfo داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

كل هيكل XftFontInfo قيد الاستخدام يرتبط بمعرف فريد، يمكن استرداده باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor برسم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب تقدمه رؤية X المستخدمة).

تقوم XftColorAllocName() و XftColorAllocValue() بطلب تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. تقوم XftColorFree() بإخبار خادم X بتحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام XftDrawSrcPicture() و XftDrawGlyphs() وعائلة الدوال XftDrawString*() و XftDrawCharSpec() و XftDrawCharFontSpec() و XftDrawGlyphSpec() و XftDrawGlyphFontSpec() و XftDrawRect() لرسم عناصر مختلفة باستخدامها.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

n، باستثناء أنه يأخذ سلسلة نمط Fontconfig (التي يتم تمريرها إلى مكتبة Fontconfig FcNameParse().

XftFont *XftFontOpenXlfd (
	Display	*dpy,
	int	 screen,
	_Xconst char	*xlfd)

XftFontOpenXlfd يعمل بنفس طريقة عمل XftFontOpen، باستثناء أنه يأخذ سلسلة تحتوي على وصف خط X المنطقي (XLFD)، ويستخدم الوظيفة XftXlfdParse().

FcPattern *XftFontMatch (
	Display	*dpy,
	int	 screen,
	_Xconst FcPattern	*pattern,
	FcResult	*result);

XftFontMatch، التي تستخدم أيضًا داخليًا بواسطة وظائف XftFontOpen*، يمكن استخدامها أيضًا مباشرة لتحديد نمط خط Fontconfig الناتج عن طلب فتح خط Xft.

FcPattern *XftXlfdParse (
	_Xconst char	*xlfd_orig,
	Bool	ignore_scalable,
	Bool	complete);

XftXlfdParse تقوم بتحليل المعلمة xlfd_orig وفقًا للوثيقة X Logical Font Description Conventions، لكنها تتجاهل بعض الحقول: setwidth_name، add_style_name، spacing، و average_width.

XftXlfdParse تنشئ نمط Fontconfig، وتعيين الخاصية XFT_XLFD إلى القيمة xlfd_orig، وتعيين المعلومات المجمعة إلى خصائص Fontconfig. يتم تجاهل الحقول الفارغة أو "*":
FC_FOUNDRY
من foundry.
FC_FAMILY
من family.
FC_WEIGHT
weight_name، مع القيمة الافتراضية FC_WEIGHT_MEDIUM.
FC_SLANT
من slant، مع القيمة الافتراضية FC_SLANT_ROMAN.
FC_SIZE
من point_size.
FC_PIXEL_SIZE
من pixel_size. إذا تم تعيين point_size، وكذلك resolution_x و resolution_y، فإن القيمة يتم تحويلها لتحويل ارتفاع الخط إلى نقاط.

تحديد امتدادات النص

يوفر Xft العديد من الوظائف لتحديد الارتفاع والعرض اللازمين لعرض سلسلة نصية. بعد حساب الإزاحة، في الحالات التي سيتم فيها تحويل السلسلة لأعلى، أو لأسفل، أو لليسار، أو لليمين، يشار إلى هذه الأرقام باسم امتدادات النص.

void XftTextExtents8 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtents8 تحسب امتدادات البكسل على العرض dpy لعدد لا يزيد عن len من الرموز في string الذي يتكون من أحرف ثمانية البتات عند رسمه بالخط font، وتقوم بتخزينها في extents.

void XftTextExtents16 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar16	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtents16 تحسب امتدادات البكسل على العرض dpy لعدد لا يزيد عن len من الرموز في string الذي يتكون من أحرف ستة عشر بت عند رسمه بالخط font، وتقوم بتخزينها في extents.

void XftTextExtents32 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar32	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtents32 تحسب امتدادات البكسل على العرض dpy لعدد لا يزيد عن len من الرموز في string الذي يتكون من أحرف اثنان وثلاثون بت عند رسمه بالخط font، وتقوم بتخزينها في extents.

void XftTextExtentsUtf8 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtentsUtf8 تحسب امتدادات البكسل على العرض dpy لعدد لا يزيد عن len من البايتات لسلسلة مرمزة بـ UTF-8 عند رسمها بالخط font، وتقوم بتخزينها في extents.

void XftTextExtentsUtf16 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	FcEndian	 endian,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtentsUtf16 تحسب امتدادات البكسل على العرض dpy لعدد لا يزيد عن len من البايتات لسلسلة مرمزة بـ UTF-16LE أو UTF-16BE عند رسمها بالخط font، وتقوم بتخزينها في extents. يجب تحديد نظام ترتيب البايتات (endianness) للسلسلة string في endian.

void XftGlyphExtents (
	Display	*dpy,
	XftFont	*font,
	_Xconst FT_UInt	*glyphs,
	int	 nglyphs,
	XGlyphInfo	*extents);

XftGlyphExtents، التي تستخدم أيضًا داخليًا بواسطة وظائف XftTextExtents*()، تحسب امتدادات البكسل على العرض dpy لعدد لا يزيد عن nglyphs في المصفوفة glyphs المرسومة بالخط font، وتقوم بتخزينها في extents.

إذا كانت أي من glyphs مفقودة (يتم تحديدها بفحص باستخدام XftFontCheckGlyph())، يتم ملء الإدخال المقابل في extents بالأصفار.

إدارة XftColor

Bool XftColorAllocName (
	Display	*dpy,
	_Xconst Visual	*visual,
	Colormap	 cmap,
	_Xconst char	*name,
	XftColor	*result);

استخدم XAllocNamedColor() للبحث عن اللون المسمى name للشاشة المرتبطة بخريطة الألوان cmap.

  • إذا أعادت XAllocNamedColor() قيمة غير صفرية، فإن XftColorAllocName() تملأ حقل البكسل XftColor الناتج بأقرب لون تدعمه الشاشة، بالإضافة إلى حقول الأحمر والأخضر والأزرق الدقيقة من قاعدة البيانات، وتعيد True.
  • إذا أعادت XAllocNamedColor() صفرًا، فإن XftColorAllocName() تعيد False، ولا تقوم بتحديث XftColor المشار إليه بواسطة result.
المعلمة visual غير مستخدمة.
Bool XftColorAllocValue (
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);

تخصيص قيمة لون:

  • إذا كان فئة visual هي TrueColor، فإن XftColorAllocValue() تعين حقل pixel في XftColor المشار إليه بواسطة result باستخدام حقول الأحمر والأخضر والأزرق من المعلمة color.
  • إذا كانت فئة visual ليست TrueColor، فإن XftColorAllocValue() تستدعي XAllocColor() لتخصيص إدخال في خريطة الألوان cmap. تعيد هذه القيمة البكسل للون الأقرب للعناصر RGB المحددة التي تدعمها الأجهزة.
إذا نجحت XAllocColor()، فإن XftColorAllocValue() تخزن قيمة البكسل هذه في XRenderColor المشار إليها بواسطة result وتعيد True.
إذا فشلت XAllocColor()، فإن XftColorAllocValue() تعيد False ولا تعدل النتيجة.
void XftColorFree (
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	XftColor	*color);

إذا كانت فئة visual ليست TrueColor، فإن Xft تستدعي XFreeColors() لتحرير الإدخال من خريطة الألوان cmap التي تم تخصيص قيمة البكسل الخاصة بها في المعلمة color بواسطة XftColorAllocName().

إدارة XftDraw

XftDraw *XftDrawCreate (
	Display	*dpy,
	Drawable	 drawable,
	Visual	*visual,
	Colormap	 colormap);

XftDrawCreate تنشئ بنية يمكن استخدامها لرسم النص والمستطيلات باستخدام drawable و visual و colormap المحددة على display.

XftDraw *XftDrawCreateBitmap (
	Display	*dpy
>, Pixmap bitmap);

XftDrawCreateBitmap يتصرف مثل XftDrawCreate()، باستثناء أنه يستخدم X pixmap بعمق لون 1 بدلاً من X drawable.

XftDraw * XftDrawCreateAlpha (
	Display	*dpy,
	Pixmap	 pixmap,
	int	 depth);

XftDrawCreateAlpha يتصرف مثل XftDrawCreate()، باستثناء أنه يستخدم X pixmap بعمق لون depth بدلاً من X drawable.

void XftDrawChange (
	XftDraw	*draw,
	Drawable	 drawable);

XftDrawChange يغير ربط X drawable الخاص بكائن الرسم Xft الموجود draw من قيمته الحالية إلى drawable.

Display *XftDrawDisplay (
	XftDraw	*draw);

XftDrawDisplay يعيد مؤشرًا إلى العرض المرتبط بكائن الرسم Xft draw.

Drawable XftDrawDrawable (
	XftDraw	*draw);

XftDrawDrawable يعيد X drawable المرتبط بكائن الرسم Xft draw.

Colormap XftDrawColormap (
	XftDraw	*draw);

XftDrawColormap() يعيد خريطة الألوان المرتبطة بكائن الرسم Xft draw.

Visual *XftDrawVisual (
	XftDraw	*draw);

XftDrawVisual يعيد مؤشرًا إلى المرئي المرتبط بكائن الرسم Xft draw.

Picture XftDrawPicture (
	XftDraw	*draw);

XftDrawPicture يعيد الصورة المرتبطة بكائن الرسم Xft draw.

إذا كان خادم X لا يدعم امتداد X Rendering، فسيتم إرجاع 0.
Picture XftDrawSrcPicture (
	XftDraw	*draw,
	_Xconst XftColor	*color);

يعيد كائن X Render Picture، والذي يستخدم لرسم الأحرف، على سبيل المثال، مع XftGlyphRender() أو XftGlyphSpecRender() أو XftGlyphFontSpecRender()، بواسطة XftDrawGlyphs() أو XftDrawGlyphSpec() أو XftDrawGlyphFontSpec()، على التوالي.

إذا كان خادم X لا يدعم امتداد X Render، فإن هذه الدوال تستخدم XftGlyphCore() أو XftGlyphSpecCore() أو XftGlyphFontSpecCore().
void XftDrawDestroy (
	XftDraw	*draw);

XftDrawDestroy يدمر draw (الذي تم إنشاؤه بواسطة إحدى دوال XftDrawCreate*()) ويحرر الذاكرة التي تم تخصيصها له.

Bool XftDrawSetClip (
	XftDraw	*draw,
	Region	 r);

يقوم بإعداد قص للمنطقة لـ XftDraw المحدد draw بدءًا بمنطقة Region:

  • إذا لم تكن معلمة Region r فارغة، فإن Xft تنشئ Region جديدة (لنسخ المعلمة)،
  • تقوم Xft بتدمير أي منطقة قص موجودة.
  • تقوم Xft بتعيين clip_type للمعلمة draw إلى XftClipTypeRegion إذا لم تكن معلمة r فارغة. وإلا، فإنها تقوم بتعيين clip_type إلى XftClipTypeNone.
  • أخيرًا، تقوم Xft بتحديث قص الكائنات الموجودة، وتحديث clip_mask لكائن Picture الخاص بـ X Render، وتعيين قناع القص في سياق الرسومات (GC) المرتبط بمعلمة XftDraw.
XftDrawSetClip() تعيد True إذا لم يكن هناك تغيير ضروري، أو إذا نجحت العملية. وتعيد False إذا لم تتمكن من إنشاء Region() جديدة.
Bool XftDrawSetClipRectangles (
	XftDraw	*draw,
	int	 xOrigin,
	int	 yOrigin,
	_Xconst XRectangle	*rects,
	int	 n);

مثل XftDrawSetClip()، تقوم XftDrawSetClipRectangles() بإعداد قص للمنطقة لـ XftDraw المحدد draw ولكنها تستخدم مجموعة من n مستطيلات (معلمة rects) يمكن استخدامها لإنشاء Region.

تقوم Xft بتعيين clip_type لـ draw إلى XftClipTypeRectangles وتستخدم XSetClipRectangles() للقص الأساسي (X11) و XRenderSetPictureClipRectangles() لقص X Render.
void XftDrawSetSubwindowMode (
	XftDraw	*draw,
	int	 mode);

يقوم بتعيين وضع النافذة الفرعية لـ XftDraw المحدد draw. يمكن أن يكون الوضع إما ClipByChildren (الافتراضي)، أو IncludeInferiors:

  • بالنسبة لـ ClipByChildren، يتم قص كل من نوافذ المصدر والوجهة إضافيًا بواسطة جميع الأطفال المرئيين من نوع InputOutput.
  • بالنسبة لـ IncludeInferiors، لا يتم قص أي من نافذة المصدر أو الوجهة بواسطة النوافذ الفرعية. سيؤدي هذا إلى تضمين محتويات النافذة الفرعية في المصدر والرسم عبر حدود النوافذ الفرعية للوجهة.
بالإضافة إلى وضع النافذة الفرعية الذي تحتفظ به Xft، فإنه يقوم بتحديث وضع النافذة الفرعية لأي سياق رسومات GC مرتبط باستخدام XSetSubwindowMode() وكذلك للصورة X Render باستخدام XRenderChangePicture().

لكل إدخال في مصفوفة glyphs:
  • إذا كان الخط المرتبط يستخدم امتداد X Render، فإن Xft تستخدم XftGlyphFontSpecRender() لرسم الحرف، باستخدام Picture تم الحصول عليها من استدعاء XftDrawSrcPicture () مع معلمتي draw و color.
  • بخلاف ذلك، توفر Xft ميزة مماثلة باستخدام Xlib.

	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,

يتضمن هذا عدة خطوات:

  • أولاً، تضمن Xft أن مصفوفة glyphs كاملة باستخدام XftFontCheckGlyph() وتحميل أي أحرف مفقودة باستخدام XftFontLoadGlyphs().
  • ثم تفحص Xft الأحرف لتحديد أقصى قيمة Unicode. وهذا يحدد حجم الترميز، أي width.
  • ثم، لكل حرف، تتحقق Xft مما إذا كانت قيمة Unicode الخاصة به مدعومة من قبل الخط المقابل. إذا لم يكن كذلك، يتم تعيين القيمة إلى صفر (0)، لتجاهلها. أثناء القيام بذلك، تتذكر Xft أيضًا الخط الأول المستخدم، وتحسب الموضع الذي سيتم فيه رسم كل حرف.
  • ثم تنشئ Xft مصفوفة مكافئة من الأحرف بالتنسيق المتوقع من مكتبة X Render.
  • أخيرًا، تستخدم XftGlyphFontSpecRender() امتداد X Render لرسم الأحرف، مع دالة XRenderCompositeText*() المناسبة وفقًا لـ width، وتتخلص من البيانات المؤقتة.
تستخدم المعلمات op و dst و src و srcx و srcy كما هو موضح في الوثائق الخاصة بمكتبة X Render.

DESCRIPTION

The libXft library provides an interface between X applications and the FreeType font library, allowing applications to use TrueType fonts. It uses Fontconfig for font matching and management.

Font configuration and matching

FcPattern * XftFontOpen (Display *dpy, FcPattern *pat);
FcPattern * XftFontOpenName (Display *dpy, FcPattern *pat);
FcPattern * XftFontOpenXlfd (Display *dpy, char *name);
void XftFontClose (Display *dpy, FcPattern *pat);
These functions are used to open and close fonts. XftFontOpen is the general purpose function. XftFontOpenName opens a font specified by a name string. XftFontOpenXlfd opens a font specified by an X Logical Font Description (XLFD) string. XftFontClose closes a font. The returned FcPattern contains the font information. If the font cannot be opened, NULL is returned.
FcPattern * XftFontMatch (Display *dpy, FcPattern *pat);
Finds the best matching font for the given pattern. This function uses Fontconfig to perform the font matching. The returned pattern contains the information of the matched font.
FcPattern * XftFontConfig (Display *dpy);
Returns the default Fontconfig pattern for the given display. This pattern can be used to configure font matching behavior.

Name parsing and unparsing

FcBool XftNameParse (
	_Xconst char	*name,
	FcPattern	**pat);

Parses a font name string into a Fontconfig pattern. The parsed pattern is returned via the pat pointer. This function returns FcTrue on success and FcFalse on failure.

FcBool XftNameUnparse (
	FcPattern	*pat,
	char	*dest,
	int	 len);

Converts a Fontconfig pattern back into a font name string. The string is stored in the buffer pointed to by dest, with a maximum length of len. This function returns FcTrue if the string fits and is successfully written, and FcFalse otherwise.

Manipulating Font data

void XftFontLoadGlyphs (
	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);

Loads glyphs for the given font. The glyphs array contains the glyph indices (Unicode values) to load. If need_bitmaps is FcTrue, bitmaps for the glyphs will also be loaded. This function uses FreeType to load the glyph data and may interact with the X Render extension to manage glyphs.

Loading a glyph involves more than just reading data into memory. Xft uses the Fontconfig pattern associated with the display dpy (e.g., via XftDefaultSet()) to determine whether to use a bounding box, clip the glyphs into those bounds, scale the glyphs, compute font metrics, and add it to the X Render extension using XRenderAddGlyphs().
void XftFontUnloadGlyphs (
	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);

Unloads glyphs that were previously loaded using XftFontLoadGlyphs(). If the glyphs were added to the X Render extension, they are removed using XRenderFreeGlyphs(). The memory usage for glyphs is updated accordingly.

FT_Face XftLockFace (
	XftFont	*pub);

Acquires a reference count on the FreeType face object associated with the font. If no face object exists, it is created using FT_New_Face(). This ensures that the face is not deallocated while it is in use. Returns the FT_Face object.

Face-locking is used internally by functions like XftCharIndex() and XftFontLoadGlyphs().
Face-locking was introduced in version 1. In version 2.1.9, it was retained as part of the public API.
void XftUnlockFace (
	XftFont	*pub);

Decrements the reference count for the FreeType face object. When the reference count reaches zero, the face object may be deallocated using FT_Done_Face().

FT_Face objects are deallocated using FT_Done_Face(). Xft does this in XftFontInfoDestroy() and when cleaning up on failure in XftFontInfoCreate() and XftFontOpenPattern().

DEBUGGING

Xft reads the environment variable XFT_DEBUG and interprets its value as a bitmask to control debugging output to standard output:

1
Font opening information.
2
Verbose font matching and opening information.
4
Details about the XRenderPictFormat being used.
8
The string that XftDrawString8() will draw.
16
Information about matched font IDs.
32
Details about glyphs to be drawn.
64
ASCII-art representation of glyphs.
128
Details about memory cache management.
256
Details about managing cached glyph memory.
512
Memory usage report.
1024
Details about extended management of cached glyph memory.

COMPATIBILITY

As of version 2 (May 2002), Xft became relatively stable. It is expected to retain source and binary compatibility in future releases.

Xft provides a compatibility interface to its previous major version, Xft 1.x.

Xft 1.x Header File

#include <X11/Xft/XftCompat.h>

Xft 1.x Data Types

XftPattern
Holds a set of names with associated value lists; each name refers to a property of a font. XftPatterns are used as inputs to the matching code as well as holding information about specific fonts.
XftFontSet
Contains a list of XftPatterns. Internally, Xft uses this data structure to hold sets of fonts. Externally, Xft returns the results of listing fonts in this format.
XftObjectSet
Holds a set of names and is used to specify which fields from fonts are placed in the list of returned patterns when listing fonts.
