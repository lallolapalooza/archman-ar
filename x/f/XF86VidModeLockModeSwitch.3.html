الوسائط

display
يحدد الاتصال بخادم X.
screen
يحدد رقم الشاشة التي تنطبق عليها الإعدادات.
event_base_return
يعيد رقم الحدث الأساسي للامتداد.
error_base_return
يعيد رقم الخطأ الأساسي للامتداد.
major_version_return
يعيد رقم الإصدار الرئيسي للامتداد.
minor_version_return
يعيد رقم الإصدار الثانوي للامتداد.
dotclock_return
يعيد الساعة لسطر الوضع.
modecount_return
يعيد عدد أوضاع الفيديو المتاحة في الخادم.
zoom
إذا كان أكبر من الصفر، يشير إلى أن الخادم يجب أن ينتقل إلى الوضع التالي، وإلا ينتقل إلى الوضع السابق.
lock
يشير إلى أنه يجب قفل تبديل الوضع، إذا كان غير صفري.
modeline
يحدد أو يعيد قيم التوقيت لوضع الفيديو.
aftermode
يحدد قيم التوقيت لوضع الفيديو الذي سيتم إضافة الوضع الجديد بعده.
modesinfo
يعيد قيم التوقيت وساعات النقاط لجميع أوضاع الفيديو المتاحة.
monitor
يعيد معلومات حول الشاشة.
x
يحدد موقع X المطلوب لمنطقة العرض.
x_return
يعيد موقع X الحالي لمنطقة العرض.
y
يحدد موقع Y المطلوب لمنطقة العرض.
y_return
يعيد موقع Y الحالي لمنطقة العرض.

الوصف

The XFree86-VidMode extension provides a means for clients to query and modify the video modes supported by the X server. This library provides functions to query the capabilities of the extension, query and modify video timings, query monitor information, and control the viewport and gamma settings.

قيم الإرجاع

All functions return True on success, and False on failure, unless otherwise noted. The specific failure conditions are detailed in the XFree86-VidMode extension documentation.
