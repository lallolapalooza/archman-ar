الاسم

xfreerdp3 - عميل FreeRDP X11

الملخص

xfreerdp3 [ملف] [خيارات] [/v:خادم[:منفذ]]

الوصف

xfreerdp3 هو عميل بروتوكول سطح المكتب البعيد (RDP) X11 وهو جزء من مشروع FreeRDP. يتضمن خادم RDP في العديد من إصدارات Windows. تشمل الخوادم البديلة ogon، gnome-remote-desktop، xrdp و VRDP (VirtualBox).

خيارات قبول الشهادة. استخدم بحذر!
* deny ... إلغاء الاتصال تلقائيًا إذا لم تتطابق الشهادة، بدون تفاعل المستخدم.
* ignore ... تجاهل فحوصات الشهادة تمامًا (تجاوز جميع الخيارات الأخرى)
* name ... استخدم <اسم> البديل بدلاً من موضوع الشهادة لمطابقة الشهادات المخزنة محليًا
* tofu ... قبول الشهادة بشكل غير مشروط عند الاتصال الأول ورفضها في الاتصالات اللاحقة إذا لم تتطابق الشهادة
* fingerprints ... قائمة بتجزئات الشهادات التي يتم قبولها بشكل غير مشروط للاتصال

إذا كانت لوحة المفاتيح مستولى عليها، فلن تعمل اختصارات النظام المحلية وسيتم إرسالها إلى النظام البعيد.

قطع اتصال الجلسة وإنهاء التطبيق

برنامج نصي للإجراءات

ينفذ برنامجًا نصيًا معرفًا مسبقًا عند الضغط على مفتاح. إذا لم يكن البرنامج النصي موجودًا، فسيتم تجاهله. يمكن توفير البرامج النصية في الموقع الافتراضي $XDG_CONFIG_HOME/freerdp/action.sh أو كوسيطة لسطر الأوامر /action:script:<path>. سيستقبل البرنامج النصي المزيج الحالي للمفاتيح كوسيطة. يتم تحليل خرج البرنامج النصي بحثًا عن key-local الذي يشير إلى أن البرنامج النصي استخدم مزيج المفاتيح، وإلا فسيتم إعادة توجيه المزيج إلى النظام البعيد.

متغيرات البيئة

متغيرات بيئة wlog

يستخدم xfreerdp3 wLog كمرفق تسجيل له، يمكنك الرجوع إلى صفحة الدليل المقابلة (wlog(7)) لمزيد من المعلومات. الوسائط التي تم تمريرها عبر /log-level أو /log-filters لها الأسبقية على متغيرات البيئة.

FREERDP_ASKPASS

تعيين برنامج لطلب كلمات المرور على غرار SSH_ASKPASS

التكوين العام (عميل مشترك)

التنسيق والموقع:

الموقع المشترك لإعدادات الشهادات هو /etc/FreeRDP/certificates.json

تنسيق الملف هو JSON

isActionScriptAllowed

قيمة منطقية JSON

السماح ببرامج نصوص الإجراءات أو حظرها. الافتراضي (إذا لم يتم تعيين الخيار) هو السماح ببرامج نصوص الإجراءات.

أمثلة

#!/bin/bash
# وصلنا مزيج مفاتيح
if [ "$1" = "key" ];
then
	# وصلنا وسيطة واحدة 'key'
	# عرض جميع التركيبات المدعومة باستخدام echo
	if [ $# -eq 1 ];
	then
		echo "ctrl+alt+f1"
		echo "ctrl+alt+f2"
	else
		# نريد الإجراء لمزيج واحد
		# استخدم 'key-local' لعدم إعادة التوجيه إلى جلسة RDP
		if [ "$2" = "ctrl+alt+f1" ];
		then
			echo "key-local"
		fi
		if [ "$2" = "ctrl+alt+f2" ];
		then
				echo "/usr/local/bin/somescript.sh"
		fi
	fi
fi
if [ "$1" = "xevent" ];
	then
		if [ $# -eq 1 ];
		then
			echo "FocusIn"
			echo "SelectionClear"
		else
			if [ "$2" = "SelectionNotify" ];
			then
				echo "/usr/local/bin/someprogram"
			fi
		fi
	fi
مثال لبرنامج نصي للإجراءات لأحداث المفاتيح، يعرض ctrl+alt+f1 ليتم التعامل معه بواسطة مدير النوافذ المحلي و ctrl+alt+f2 لتنفيذ برنامج نصي.

تحدد القيمة المرجعة للبرنامج ما إذا كان المفتاح يتم التعامل معه محليًا أو عن بُعد (0 للمحلي، > 0 للبعيد، < 0 للأخطاء)

xfreerdp3 connection.rdp /p:Pwd123! /f

الاتصال في وضع ملء الشاشة باستخدام تكوين مخزن connection.rdp وكلمة المرور Pwd123!

xfreerdp3 /u:USER /size:50%h /v:rdp.contoso.com

الاتصال بالمضيف rdp.contoso.com بالمستخدم USER وحجم 50 بالمائة من الارتفاع. إذا تم تعيين العرض (w) بدلاً من الارتفاع (h) مثل /size:50%w. يتم استخدام 50 بالمائة من العرض.

xfreerdp3 /u:CONTOSO\\JohnDoe /p:Pwd123! /v:rdp.contoso.com

الاتصال بالمضيف rdp.contoso.com بالمستخدم CONTOSO\\JohnDoe وكلمة المرور Pwd123!

xfreerdp3 /u:JohnDoe /p:Pwd123! /w:1366 /h:768 /v:192.168.1.100:4489

الاتصال بالمضيف 192.168.1.100 على المنفذ 4489 بالمستخدم JohnDoe، وكلمة المرور Pwd123!. يتم تعيين عرض الشاشة إلى 1366 والارتفاع إلى 768

xfreerdp3 /u:JohnDoe /p:Pwd123! /vmconnect:C824F53E-95D2-46C6-9A18-23A5BB403532 /v:192.168.1.100

إنشاء اتصال بالمضيف 192.168.1.100 بالمستخدم JohnDoe، وكلمة المرور Pwd123! والاتصال بوحدة تحكم Hyper-V (استخدم المنفذ 2179، تعطيل التفاوض) باستخدام VMID C824F53E-95D2-46C6-9A18-23A5BB403532
