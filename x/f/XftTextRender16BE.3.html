XftTextRender16BE(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة تقوم برسم النصوص والرسومات:

  • باستخدام المعلومات المقدمة من مكتبة Fontconfig،
  • تقوم Xft بتحويل رموز الخطوط باستخدام مولد الخطوط FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X Rendering.

صفحة الدليل هذه بالكاد تخدش سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، زائد XFT_MINOR مضروبًا في 100، زائد XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت إصدار Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " نحتاج إلى إصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اتفاقية تسمية، حيث تسبق جميع الأسماء بـ "Xft"

من Xlib...

لا تتبع أنواع بيانات Xlib اتفاقية تسمية. وهي موثقة في Xlib - C Language Interface.

تستخدم Xft هذه الأسماء: Bool، Colormap، Display، Drawable، Pixmap، Region، Visual، و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معرّف في <X11/X.h>، وهو معرف مورد X، على سبيل المثال، نافذة مرتبطة بعرض. يمكن استخدام كل من النوافذ والصور (pixmaps) كمصادر ووجهات في عمليات الرسوميات. تُعرف هذه النوافذ والصور مجتمعة باسم "drawables". ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسوميات.
Region
معرّف في <X11/Xutil.h> و <X11/Xregion.h>، Region هو مجموعة اعتباطية من مواقع البكسل التي يمكن لـ Xlib التلاعب بها. داخليًا، يتم تمثيل Region باتحاد عدد اعتباطي من المستطيلات. تحتفظ Xlib بمستطيل يحدد نطاق هذا الاتحاد.
Visual
معرّف في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول تعيين الألوان المحتمل.

من XRender...

تستلهم أنواع بيانات مكتبة امتداد X Render من Xlib، ولكنها تفتقر إلى التوثيق المقابل. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا تفصيليًا لـ libXrender).

تستخدم Xft هذه الأسماء: Picture، XGlyphInfo، XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اتفاقية تسمية، حيث تسبق جميع الأسماء بـ "Fc" وهي موثقة في Fontconfig Developers Reference.

تستخدم Xft هذه الأسماء من Fontconfig: FcBool، FcChar8، FcChar16، FcChar32، FcCharSet، FcEndian، FcFontSet، FcPattern، و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اتفاقية تسمية، حيث تسبق جميع الأسماء بـ "FT_" وهي موثقة في FreeType API Reference.

تستخدم Xft هذه الأسماء: FT_Face، FT_Library، و FT_UInt.

يستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل رموز الخطوط.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig ونمط الخط المرتبط بالخط.

يتم ملء XftFonts باستخدام أي من XftFontOpen()، XftFontOpenName()، XftFontOpenXlfd()، XftFontOpenInfo()، أو XftFontOpenPattern(). يتم استخدام XftFontCopy() لتكرار XftFonts، ويتم استخدام XftFontClose() لوضع علامة على XftFont كغير مستخدم. يتم تخصيص XftFonts داخليًا، وعدها بالمرجع، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

تستخدم XftDrawGlyphs()، عائلة XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() XftFonts لرسم النص إلى كائن XftDraw، والذي قد يتوافق مع رسم أساسي لـ X أو رسم امتداد X Rendering.

تُستخدم XftGlyphExtents() وعائلة XftTextExtents*() لتحديد نطاقات (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية رموز الخطوط أو الأحرف لـ XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). تُرجع XftCharIndex() مؤشر XftFont الخاص بالرمز المقابل لنقطة ترميز Unicode معينة.

تستخدم XftGlyphRender()، XftGlyphSpecRender()، XftCharSpecRender()، وعائلة XftTextRender*() XftFonts للرسم في هياكل Picture الخاصة بامتداد X Rendering.

ملاحظة: توفر XftDrawGlyphs()، وعائلة XftDrawString*()، XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لرسم الخطوط مستقلة عن توفر امتداد X Rendering على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن معلومات حول الخط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص XftFontInfo داخليًا وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

كل هيكل XftFontInfo قيد الاستخدام يرتبط بمعرف فريد، والذي يمكن استرجاعه باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;

يسمح كائن XftColor برسم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب يقدمه العرض البصري لـ X قيد الاستخدام).

تطلب XftColorAllocName() و XftColorAllocValue() تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. تُعلم XftColorFree() خادم X بتحرير اللون المخصص حاليًا لـ XftColor.

Bool XftDrawSetClip (
	XftDraw	*draw,
	Region	 r);

Set up clipping for the given XftDraw parameter draw starting with a Region:

  • If the Region parameter r is not null, Xft creates a new Region (to copy the parameter),
  • Xft destroys any existing clipping region.
  • Xft sets the clip_type for the draw parameter to XftClipTypeRegion if the r parameter was not null. Otherwise it sets the clip_type to XftClipTypeNone.
  • Finally, Xft updates clipping for existing objects, updates the clip_mask for its X Render Picture object and sets the clipping-mask in the graphic context (GC) associated with the XftDraw parameter.
XftDrawSetClip() returns True if no change was necessary, or if the operation succeeded. It returns False if it was unable to create the new Region().
Bool XftDrawSetClipRectangles (
	XftDraw	*draw,
	int	 xOrigin,
	int	 yOrigin,
	_Xconst XRectangle	*rects,
	int	 n);

Like XftDrawSetClip(), XftDrawSetClipRectangles() sets up clipping for the given XftDraw parameter draw but uses a set of n rectangles (the rects parameter) which could be used to construct a Region .

Xft sets the clip_type for draw to XftClipTypeRectangles and uses XSetClipRectangles() for core (X11) clipping and XRenderSetPictureClipRectangles() for X Render clipping.
void XftDrawSetSubwindowMode (
	XftDraw	*draw,
	int	 mode);

Sets the subwindow-mode for the given XftDraw parameter draw. The mode can be either ClipByChildren (the default), or IncludeInferiors:

  • For ClipByChildren, both source and destination windows are additionally clipped by all viewable InputOutput children.
  • For IncludeInferiors, neither source nor destination window is clipped by inferiors. This will result in including subwindow contents in the source and drawing through subwindow boundaries of the destination.
In addition to the subwindow-mode maintained by Xft, it updates the subwindow mode for any associated graphics context GC using XSetSubwindowMode() as well as for an X Render Picture using XRenderChangePicture().

void XftDrawGlyphFontSpec (
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);

Draw a list of glyphs associated with fonts at specified coordinates, passed as an array of len XftGlyphFontSpec structures via the parameter glyphs. All of the glyphs are drawn using the color specified in the color parameter.

For each entry in the glyphs array:
  • If the associated font uses the X Render extension, then Xft uses XftGlyphFontSpecRender() to draw the glyph, using a Picture obtained from calling XftDrawSrcPicture () with the draw and color parameters.
  • Otherwise, Xft provides an analogous feature using Xlib.
void XftGlyphFontSpecRender (
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);

This involves several steps:

  • First, Xft ensures that the glyphs array is complete using XftFontCheckGlyph() and loading any missing glyphs with XftFontLoadGlyphs().
  • Then Xft examines the glyphs to find the maximum Unicode value. That determines the encoding size, i.e., the width.
  • Then, for each glyph, Xft checks if its Unicode value is handled by the corresponding font. If not, the value is set to zero (0), to ignore it. While doing this, Xft also remembers which was the first font used, and computes the position at which each glyph will be drawn.
  • Xft then constructs an equivalent array of glyphs in the format expected by the X Render library.
  • Finally, XftGlyphFontSpecRender() uses the X Render extension to draw the glyphs, with the appropriate XRenderCompositeText*() function according to the width, and discards temporary data.
The op, dst, src, srcx, and srcy parameters are used as described in the documentation for the X Render library.

NAME


Xft - X FreeType library






SYNOPSIS


#include <X11/Xft/Xft.h>







DESCRIPTION


The Xft library provides font handling for X Window System applications
    using the FreeType library. It implements scalable font handling, using
    TrueType fonts and other font formats supported by FreeType. Xft uses
    Fontconfig for font matching and management.




Fonts


Xft uses Fontconfig to match font patterns to available fonts.
    A font pattern is a set of name-value pairs. Xft supports the following
    font-related properties:



    
family

    
Font family name (e.g., “Bitstream Vera”, “Times
        New Roman”).

    
style

    
Font style (e.g., “Roman”, “Bold”,
        “Italic”).

    
size

    
Font size in points (e.g., 12.0).

    
weight

    
Font weight (e.g., 400 for normal, 700 for bold).

    
slant

    
Font slant (e.g., 0 for normal, 10 for italic).

    
width

    
Font width (e.g., 100 for normal).

    
foundry

    
Font foundry name.

    
charset

    
Character set supported by the font (e.g., “iso10646-1”).

    
fontversion

    
Font version number.

    
fullname

    
Full font name.

    
file

    
Path to the font file.

    
index

    
Index of the font within the file (for multi-font files).

    
scalable

    
Boolean indicating if the font is scalable.

    
outline

    
Boolean indicating if the font is an outline font.

    
bitmap

    
Boolean indicating if the font is a bitmap font.

    
pixelsize

    
The rendered pixel size of the font.

    
scalable

    
Boolean indicating if the font is scalable.




Xft uses Fontconfig's FcPattern type to represent font
    patterns.






Rendering


Xft uses the X Render Extension for rendering glyphs. It can render
    glyphs with anti-aliasing, sub-pixel rendering, and various color depths.








CONSTANTS


Xft defines several constants related to font properties and
    rendering:



    
XFT_BACKGROUND

    
Background color property.

    
XFT_FOREGROUND

    
Foreground color property.

    
XFT_FONT

    
Font pattern property.

    
XFT_RENDER_PIXEL_WIDTH

    
Pixel width for rendering.

    
XFT_RENDER_PIXEL_HEIGHT

    
Pixel height for rendering.

    
XFT_RENDER_FORMAT

    
Pixel format for rendering.

Represents a color, including alpha channel.

Represents an opened font, including FreeType face information and

Represents a set of XftPatterns, used for font listing.

    
XftDraw

    
Represents a drawable surface for rendering text.

DEBUGGING


The environment variable XFT_DEBUG can be set to an integer
    value to control debugging output. Each bit in the value corresponds to a
    different debugging category:



    
1

    
Font opening information.

    
2

    
Verbose font matching and opening.

    
4

    
Details about the X Render Pictformat used.

    
8

    
The string being drawn by XftDrawString8().

    
16

    
Font IDs matched.

    
32

    
Information about glyphs to be drawn.

    
64

    
ASCII-art representation of glyphs.

    
128

    
Memory cache management details.

    
256

    
Glyph cache memory management details.

    
512

    
Memory usage report.

    
1024

    
Extended glyph cache memory management details.








COMPATIBILITY


Xft version 2 aims for API and ABI compatibility with previous
    versions. An compatibility header, <X11/Xft/XftCompat.h>,
    provides definitions for Xft 1.x data types such as XftPattern,
    XftFontSet, and XftObjectSet.
