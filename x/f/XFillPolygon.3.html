XFillPolygon(3)

الحزمة: libx11

التراخيص: MIT AND X11

XFillRectangle(3) وظائف XLIB XFillRectangle(3)

الاسم

XFillRectangle, XFillRectangles, XFillPolygon, XFillArc, XFillArcs - ملء المستطيلات، المضلعات، أو الأقواس

الصيغة

int XFillRectangle(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height);

int XFillRectangles(Display *display, Drawable d, GC gc, XRectangle *rectangles, int nrectangles);

int XFillPolygon(Display *display, Drawable d, GC gc, XPoint *points, int npoints, int shape, int mode);

int XFillArc(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height, int angle1, int angle2);

int XFillArcs(Display *display, Drawable d, GC gc, XArc *arcs, int narcs);

المعاملات

angle1
يحدد بداية القوس بالنسبة لموضع الساعة الثالثة من المركز، بوحدات الدرجات * 64.
angle2
يحدد مسار القوس ومدى امتداده بالنسبة لبداية القوس، بوحدات الدرجات * 64.
arcs
يحدد مصفوفة من الأقواس.
d
يحدد العنصر القابل للرسم.
display
يحدد الاتصال بخادم X.
gc
يحدد مجموعة الرسومات (GC).
mode
يحدد وضع الإحداثيات. يمكنك تمرير CoordModeOrigin أو CoordModePrevious.
narcs
يحدد عدد الأقواس في المصفوفة.
npoints
يحدد عدد النقاط في المصفوفة.
nrectangles
يحدد عدد المستطيلات في المصفوفة.
points
يحدد مصفوفة من النقاط.
rectangles
يحدد مصفوفة من المستطيلات.
shape
يحدد شكلاً يساعد الخادم على تحسين الأداء. يمكنك تمرير Complex، Convex، أو Nonconvex.
width

height
حدد العرض والارتفاع، وهما أبعاد المستطيل المراد ملؤه أو المحورين الرئيسيين والثانويين للقوس.
x

y
حدد إحداثيات x و y، والتي تكون نسبية إلى أصل العنصر القابل للرسم وتحدد الزاوية العلوية اليسرى للمستطيل.

الوصف

تقوم وظائف XFillRectangle و XFillRectangles بملء المستطيل أو المستطيلات المحددة كما لو تم تحديد طلب بروتوكول FillPolygon ذي الأربع نقاط لكل مستطيل:

[x,y] [x+width,y] [x+width,y+height] [x,y+height]

تستخدم كل وظيفة إحداثيات x و y، وأبعاد العرض والارتفاع، ومجموعة الرسومات (GC) التي تحددها.

تقوم XFillRectangles بملء المستطيلات بالترتيب المدرج في المصفوفة. بالنسبة لأي مستطيل معين، لا ترسم XFillRectangle و XFillRectangles بكسلًا أكثر من مرة. إذا تقاطعت المستطيلات، يتم رسم البكسلات المتقاطعة عدة مرات.

تستخدم كلتا الوظيفتين مكونات GC التالية: الوظيفة، قناع المستوى، نمط الملء، وضع النافذة الفرعية، أصل x للقص، أصل y للقص، وقناع القص. كما تستخدمان المكونات التالية المعتمدة على وضع GC: اللون الأمامي، اللون الخلفي، البلاطة، النقش، أصل x للبلاطة، وأصل y للبلاطة.

يمكن أن تولد XFillRectangle و XFillRectangles أخطاء BadDrawable، BadGC، و BadMatch.

تقوم XFillPolygon بملء المنطقة المغلقة بالمسار المحدد. يتم إغلاق المسار تلقائيًا إذا كانت النقطة الأخيرة في القائمة لا تتطابق مع النقطة الأولى. لا ترسم XFillPolygon بكسلًا من المنطقة أكثر من مرة. تعالج CoordModeOrigin جميع الإحداثيات على أنها نسبية إلى الأصل، وتعالج CoordModePrevious جميع الإحداثيات بعد الأولى على أنها نسبية إلى النقطة السابقة.

اعتمادًا على الشكل المحدد، يحدث ما يلي:

  • إذا كان الشكل Complex، فقد يتقاطع المسار مع نفسه. لاحظ أن النقاط المتطابقة والمتجاورة في المسار لا تُعامل على أنها تقاطع ذاتي.
  • إذا كان الشكل Convex، لكل زوج من النقاط داخل المضلع، فإن القطعة المستقيمة التي تربطها لا تتقاطع مع المسار. إذا كان العميل يعرف ذلك، فإن تحديد Convex يمكن أن يحسن الأداء. إذا حددت Convex لمسار غير محدب، فإن النتائج الرسومية غير محددة.
  • إذا كان الشكل Nonconvex، فإن المسار لا يتقاطع مع نفسه، ولكن الشكل ليس محدبًا بالكامل. إذا كان العميل يعرف ذلك، فإن تحديد Nonconvex بدلاً من Complex قد يحسن الأداء. إذا حددت Nonconvex لمسار يتقاطع مع نفسه، فإن النتائج الرسومية غير محددة.

تتحكم قاعدة الملء (fill-rule) في GC في سلوك ملء المضلعات التي تتقاطع مع نفسها.

تستخدم هذه الوظيفة مكونات GC التالية: الوظيفة، قناع المستوى، نمط الملء، قاعدة الملء، وضع النافذة الفرعية، أصل x للقص، أصل y للقص، وقناع القص. كما تستخدم المكونات التالية المعتمدة على وضع GC: اللون الأمامي، اللون الخلفي، البلاطة، النقش، أصل x للبلاطة، وأصل y للبلاطة.

يمكن أن تولد XFillPolygon أخطاء BadDrawable، BadGC، BadMatch، و BadValue.

لكل قوس، تقوم XFillArc أو XFillArcs بملء المنطقة المغلقة بالمسار الرفيع اللانهائي الذي وصفه القوس المحدد، وبناءً على وضع القوس (arc-mode) المحدد في GC، قطعة خط واحدة أو اثنتين. بالنسبة لـ ArcChord، يتم استخدام قطعة الخط الواحدة التي تربط نقاط نهاية القوس. بالنسبة لـ ArcPieSlice، يتم استخدام قطعتي الخط اللتين تربطان نقاط نهاية القوس بالمركز. تقوم XFillArcs بملء الأقواس بالترتيب المدرج في المصفوفة. بالنسبة لأي قوس معين، لا ترسم XFillArc و XFillArcs بكسلًا أكثر من مرة. إذا تقاطعت المناطق، يتم رسم البكسلات المتقاطعة عدة مرات.

تستخدم كلتا الوظيفتين مكونات GC التالية: الوظيفة، قناع المستوى، نمط الملء، وضع القوس، وضع النافذة الفرعية، أصل x للقص، أصل y للقص، وقناع القص. كما تستخدمان المكونات التالية المعتمدة على وضع GC: اللون الأمامي، اللون الخلفي، البلاطة، النقش، أصل x للبلاطة، وأصل y للبلاطة.

يمكن أن تولد XFillArc و XFillArcs أخطاء BadDrawable، BadGC، و BadMatch.

التشخيصات

BadDrawable
قيمة لمعامل Drawable لا تسمي نافذة أو صورة نقطية محددة.
BadGC
قيمة لمعامل GContext لا تسمي سياق رسومات (GContext) محددًا.
BadMatch
يتم استخدام نافذة InputOnly كـ Drawable.
BadMatch
بعض المعاملات أو أزواج المعاملات لها النوع والنطاق الصحيح ولكنها تفشل في المطابقة بطريقة أخرى مطلوبة من قبل الطلب.
BadValue
بعض القيم الرقمية تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لمعامل، يتم قبول النطاق الكامل الذي يحدده نوع المعامل. يمكن لأي معامل معرف كمجموعة من البدائل توليد هذا الخطأ.
