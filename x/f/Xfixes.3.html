Xfixes(3)

الحزمة: libxfixes

التراخيص: MIT, HPND-sell-variant

XFIXES(3) إصدار X 11 XFIXES(3)

الاسم

XFixes - إصدارات معززة من طلبات البروتوكول الأساسي

الصيغة

#include <X11/extensions/Xfixes.h>

Bool XFixesQueryExtension (Display *dpy,
	int *event_base_return, int *error_base_return);

Status XFixesQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

void XFixesChangeSaveSet (Display *dpy,
	Window window,
	int mode,
	int target,
	int map);

المعاملات

display
يحدد الاتصال بخادم X.
window
يحدد النافذة.
mode
يحدد عملية مجموعة الحفظ (SetModeInsert/SetModeDelete).
target
يحدد الهدف عند تنفيذ مجموعة الحفظ (SaveSetNearest/SaveSetRoot). في وضع SaveSetNearest، سيتم إعادة تعيين نافذة عضو مجموعة الحفظ إلى أقرب نافذة غير مملوكة لعميل مجموعة الحفظ. في وضع SaveSetRoot، سيتم إعادة تعيين نافذة عضو مجموعة الحفظ إلى النافذة الجذر.
map
يحدد وضع الخريطة (SaveSetMap/SaveSetUnmap) الذي يختار ما إذا كانت نافذة عضو مجموعة الحفظ ستتم تعيينها أو إلغاء تعيينها أثناء معالجة مجموعة الحفظ.

الوصف

Xfixes هي مكتبة بسيطة مصممة للربط مع امتداد X Fixes. يوفر هذا الامتداد للتطبيقات حلولاً بديلة لقيود مختلفة في البروتوكول الأساسي.

قيود

سيظل Xfixes متوافقًا مع الإصدارات السابقة بعد الإصدار 1.0.
