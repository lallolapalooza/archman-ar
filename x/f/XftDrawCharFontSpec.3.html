XftDrawCharFontSpec(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة ترسم النصوص والرسومات:

  • باستخدام المعلومات المقدمة من مكتبة Fontconfig،
  • تقوم Xft بتحويل أشكال الحروف باستخدام راسمة FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X للرسم.

هذه الصفحة اليدوية بالكاد تخدش سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، بالإضافة إلى XFT_MINOR مضروبًا في 100، بالإضافة إلى XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت الإصدار لـ Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("الإصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " نحتاج إلى إصدار 2.1.7 على الأقل.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "Xft"

من Xlib...

لا تتبع أنواع بيانات Xlib اصطلاح تسمية. وهي موثقة في Xlib - واجهة لغة C.

تستخدم Xft هذه الأسماء: Bool، Colormap، Display، Drawable، Pixmap، Region، Visual، و XRectangle.

بعض أنواع البيانات ذات أهمية خاصة لـ Xft:

Drawable
معلن عنه في <X11/X.h>، وهو معرف مورد X، على سبيل المثال، نافذة مرتبطة بعرض. يمكن استخدام كل من النوافذ والصور (pixmaps) كمصادر ووجهات في عمليات الرسم. تُعرف هذه النوافذ والصور مجتمعة باسم الرسوم (drawables). ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسم.
Region
معلن عنه في <X11/Xutil.h> و <X11/Xregion.h>، Region هي مجموعة اعتباطية من مواقع البكسل التي يمكن لـ Xlib معالجتها. داخليًا، يتم تمثيل Region باتحاد عدد اعتباطي من المستطيلات. تحتفظ Xlib بمستطيل يخبرنا بامتداد هذا الاتحاد.
Visual
معلن عنه في <X11/Xutil.h>، يحتوي هذا الهيكل على معلومات حول تعيين الألوان المحتمل.

من XRender...

أنواع بيانات مكتبة امتداد X للرسم مستوحاة من Xlib، ولكن تفتقر إلى التوثيق المقابل. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا عامًا لـ libXrender).

تستخدم Xft هذه الأسماء: Picture، XGlyphInfo، XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "Fc" وهي موثقة في مرجع مطوري Fontconfig.

تستخدم Xft أسماء Fontconfig هذه: FcBool، FcChar8، FcChar16، FcChar32، FcCharSet، FcEndian، FcFontSet، FcPattern، و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اصطلاح تسمية، حيث تسبق جميع الأسماء بـ "FT_" وهي موثقة في مرجع واجهة برمجة تطبيقات FreeType.

تستخدم Xft هذه الأسماء: FT_Face، FT_Library، و FT_UInt.

يستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل أشكال الحروف.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ فهو يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig ونمط الخط المرتبط بالخط.

يتم ملء XftFonts باستخدام أي من XftFontOpen()، XftFontOpenName()، XftFontOpenXlfd()، XftFontOpenInfo()، أو XftFontOpenPattern(). يستخدم XftFontCopy() لنسخ XftFonts، ويستخدم XftFontClose() لتمييز XftFont على أنه غير مستخدم. يتم تخصيص XftFonts داخليًا، وعد مرجعها، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

تستخدم XftDrawGlyphs()، وعائلة XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec() XftFonts لرسم النصوص إلى كائن XftDraw، والذي قد يتوافق مع رسم أساسي لـ X أو رسم امتداد X للرسم.

تستخدم XftGlyphExtents() وعائلة XftTextExtents*() لتحديد امتدادات (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية أشكال الحروف أو الأحرف لـ XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). تعيد XftCharIndex() فهرس الحرف الخاص بـ XftFont المقابل لنقطة شفرة يونيكود معينة.

تستخدم XftGlyphRender()، و XftGlyphSpecRender()، و XftCharSpecRender()، وعائلة XftTextRender*() XftFonts للرسم في هياكل Picture لامتداد X للرسم.

ملاحظة: توفر XftDrawGlyphs()، وعائلة XftDrawString*()، و XftDrawCharSpec()، و XftDrawGlyphSpec() وسيلة لرسم الخطوط تكون مستقلة عن توفر امتداد X للرسم على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن معلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص كائنات XftFontInfo داخليًا وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

كل هيكل XftFontInfo قيد الاستخدام مرتبط بمعرف فريد، يمكن استرداده باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor برسم النصوص والعناصر الأخرى بلون معين (أو أقرب تقريب تقدمه واجهة X المستخدمة).

تطلب XftColorAllocName() و XftColorAllocValue() تخصيص لون من خادم X (إذا لزم الأمر) وتهيئة أعضاء XftColor. تطلب XftColorFree() من خادم X تحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام XftDrawSrcPicture()، و XftDrawGlyphs()، وعائلة XftDrawString*()، و XftDrawCharSpec()، و XftDrawCharFontSpec()، و XftDrawGlyphSpec()، و XftDrawGlyphFontSpec()، و XftDrawRect() لرسم كائنات مختلفة باستخدام

ng it.

XftDraw

هو كائن غير شفاف يحمل معلومات تُستخدم للرسم على كائن قابل للرسم (drawable) في X باستخدام البروتوكول الأساسي أو امتداد X Rendering.

يتم إنشاء كائنات XftDraw باستخدام أي من الدوال التالية: XftDrawCreate() (التي تربط XftDraw بكائن قابل للرسم موجود في X)، XftDrawCreateBitmap()، أو XftDrawCreateAlpha(). ويتم تدميرها باستخدام XftDrawDestroy(). يمكن تغيير كائن X القابل للرسم المرتبط بـ XftDraw باستخدام XftDrawChange(). يتم تخصيص وإلغاء تخصيص كائنات XftDraw داخليًا بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

يمكن الاستعلام عن خصائص X Display، Drawable، Colormap، و Visual لكائن XftDraw باستخدام XftDrawDisplay()، XftDrawDrawable()، XftDrawColormap()، و XftDrawVisual() على التوالي.

تستخدم العديد من الدوال كائنات XftDraw: XftDrawCharFontSpec()، XftDrawCharSpec()، XftDrawGlyphFontSpec()، XftDrawGlyphSpec()، XftDrawGlyphs()، XftDrawRect()، XftDrawSetClip()، XftDrawSetClipRectangles()، XftDrawSetSubwindowMode()، وعائلة الدوال XftDrawString*().

يتم إرجاع امتداد X Rendering Picture المرتبط بـ XftDraw بواسطة XftDrawPicture()، و XftDrawSrcPicture(). ويُستخدم بواسطة الدوال XftCharFontSpecRender()، XftCharSpecRender()، XftGlyphFontSpecRender()، XftGlyphRender()، XftGlyphSpecRender()، وعائلة الدوال XftTextRender*().

الوظائف

التهيئة

عادةً لا تقوم التطبيقات النموذجية التي تستخدم Xft بتهيئة المكتبة بشكل صريح. يحدث ذلك عادةً كأثر جانبي لفتح خط.

عندما تقوم Xft بالتهيئة، فإنها تجمع معلومات حول الشاشة، وتخزن بعض هذه المعلومات في نمط Fontconfig (وهو عبارة عن مجموعة من الخصائص ذات القيم ذات الأنواع). يمكن للتطبيق المتصل تعديل هذا النمط لتغيير سلوك المكتبة.

لا يتم تخزين كل المعلومات التي تم جمعها في نمط. يتم تخزين الباقي في هياكل بيانات داخلية. تجعل Xft بعض هذه البيانات متاحة للتطبيق عبر دوال.

Bool XftDefaultHasRender (
	Display	*dpy);

تحصل على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وترجع true إذا وجدت Xft أن الشاشة تدعم امتداد X Render، وإذا كانت قادرة على العثور على XRenderPictFormat مناسب (نوع بيانات X Render الذي يشبه Visual في Xlib) على الشاشة.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

تحصل على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وتقوم بتعيين نمط Fontconfig الذي يحتوي على الخصائص الافتراضية التي ستستخدمها Xft لهذه الشاشة.

تستخدم Xft هذه الخصائص مبدئيًا للحصول على هذه الحدود:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). هذا هو الحد الأقصى لذاكرة الرموز الرسومية لجميع الخطوط التي تستخدمها Xft (الافتراضي: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). هذا هو الحد الأقصى لعدد الخطوط غير المشار إليها (الافتراضي: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). عندما يكون صحيحًا، تتتبع Xft استخدام ذاكرة الرموز الرسومية لتحسين الأداء عند اتخاذ قرار بشأن ما يجب إلغاء تحميله عندما يتم الوصول إلى الحد الأقصى لذاكرة الرموز الرسومية (الافتراضي: false).
تستخدم Xft أيضًا هذه الخصائص الافتراضية في XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

تقوم Xft بملء الخصائص المفقودة في pattern المحدد باستخدام الخصائص الافتراضية للشاشة المحددة dpy، على سبيل المثال، كما تم تعيينها في XftDefaultSet().

تستخدم تطبيقات Xft النموذجية هذه الدالة لمساعدة Fontconfig في اختيار خط مناسب. يتم استبدال هذه الخصائص قبل استدعاء FcDefaultSubstitute():
FC_ANTIALIAS
صحيح إذا كان يجب على FreeType استخدام تنعيم الحواف (الافتراضي: False). (الافتراضي: True).
FC_AUTOHINT
صحيح إذا كان يجب على FreeType استخدام التلميح التلقائي (الافتراضي: False).
FC_DPI
نقاط/بوصة مستخدمة للدقة (الافتراضي: يتم حسابها من ارتفاع الشاشة).
FC_EMBOLDEN
صحيح إذا كان يجب استخدام FT_GlyphSlot_Embolden() لتكثيف خط (الافتراضي: False).
FC_HINTING
صحيح إذا كان يجب استخدام التلميح عند ملء الخصائص لفتح خط (الافتراضي: True).
FC_HINT_STYLE
أسلوب التلميح المستخدم عند ملء الخصائص لفتح خط (الافتراضي: FC_HINT_FULL).
FC_LCD_FILTER
معامل يتم تمريره إلى FT_Library_SetLcdFilter() عند تحميل الرموز الرسومية (الافتراضي: FC_LCD_DEFAULT).
FC_MINSPACE
قيمة الحد الأدنى للمسافة المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: False).
FC_RGBA
قيمة RGBA المستخدمة عند ملء الخصائص لفتح خط (الافتراضي: يتم حسابها عن طريق استدعاء XRenderQuerySubpixelOrder()).
FC_SCALE
المقياس المستخدم في Fontconfig (الافتراضي: 1.0).
XFT_MAX_GLYPH_MEMORY
الحد الأقصى للذاكرة لخط واحد (الافتراضي: 1024*1024).
XFT_RENDER
صحيح إذا كانت الشاشة تدعم امتداد X Render (الافتراضي: النتيجة من XftDefaultHasRender()).
FcBool XftInit (
	_Xconst char	*config);

يقوم بتهيئة مكتبة Fontconfig (باستدعاء FcInit()).

المعلمة config غير مستخدمة.
Xft لا تقوم بإلغاء تهيئة مكتبة Fontconfig عند الانتهاء.
FcBool XftInitFtLibrary (void);

    
يقوم بتهيئة مكتبة FreeType (باستدعاء
        FT_Init_FreeType() لإنشاء كائن مكتبة) إذا لم يتم تهيئتها بالفعل. هذا
        ضروري قبل استخدام مكتبة FreeType لقراءة بيانات الخطوط من ملف.

  





  

  
تقوم Xft باستدعاء XftInitFtLibrary() داخليًا عبر
      XftFontInfoCreate() و XftFontOpenPattern().

  

  
Xft لا تتخلص من كائن المكتبة (على سبيل المثال، باستخدام
      FT_Done_FreeType()) عند الانتهاء.





  
int XftGetVersion (void);

  

    

    
إرجاع XftVersion، مما يتيح للتطبيق تحديد الإصدار الفعلي لـ

فتح ومطابقة الخطوط



  
XftFont *XftFontOpen (

  

    
	Display	*dpy,
	int	 screen,
	...);


    
تأخذ XftFontOpen قائمة ثلاثيات من عناصر النمط بالشكل
        field, type, value (تنتهي بـ NULL)، تطابق هذا النمط
        مع الخطوط المتاحة، وتفتح الخط المطابق، وتضبط حجمه بشكل صحيح للشاشة رقم
        screen على الشاشة dpy. ترجع الخط المطابق، أو NULL إذا لم يتم
        العثور على تطابق.

  




مثال:
  




    font = XftFontOpen (dpy, screen,
                        XFT_FAMILY, XftTypeString, "charter",
                        XFT_SIZE, XftTypeDouble, 12.0,
                        NULL);




  

  
يفتح هذا الخط "charter" بحجم 12 نقطة. يتم تحويل حجم النقطة تلقائيًا إلى الحجم الصحيح بالبكسل بناءً على دقة الشاشة.

FcPattern *XftXlfdParse (

  

    
	_Xconst char	*xlfd_orig,
	Bool	ignore_scalable,
	Bool	complete);


    
تقوم XftXlfdParse بتحليل المعلمة xlfd_orig
        وفقاً لوثيقة X Logical Font Description Conventions،
        لكنها تتجاهل بعض الحقول: setwidth_name،
        add_style_name، spacing، و average_width.

  




  

  
تقوم XftXlfdParse بإنشاء نمط Fontconfig، مع تعيين الخاصية
      XFT_XLFD بقيمة xlfd_orig، وتقوم بتعيين المعلومات المجمعة
      إلى خصائص Fontconfig. يتم تجاهل الحقول الفارغة أو التي تحتوي على " *":

من foundry.

  
FC_FAMILY

  
من family.

  
FC_WEIGHT

  
weight_name، الافتراضي هو FC_WEIGHT_MEDIUM.

  
FC_SLANT

  
من slant، الافتراضي هو FC_SLANT_ROMAN.

Set up clipping for the given XftDraw parameter

	XftDraw	*draw,
	int	 mode);


    
Sets the subwindow-mode for the given XftDraw parameter
        draw. The mode can be either ClipByChildren (the default),
        or IncludeInferiors:

void

  

    
XftDrawGlyphFontSpec (
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Draw a list of glyphs associated with fonts at specified
        coordinates, passed as an array of len XftGlyphFontSpec
        structures via the parameter glyphs. All of the glyphs are drawn
        using the color specified in the color parameter.

  





  

  
For each entry in the glyphs array:






    
  
  • If the associated font uses the X Render extension, then Xft uses
      XftGlyphFontSpecRender() to draw the glyph, using a Picture
      obtained from calling XftDrawSrcPicture () with the draw and
      color parameters.
    • 
  
  • Otherwise, Xft provides an analogous feature using Xlib.
    • 






  
void

  

    
XftGlyphFontSpecRender (
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
This involves several steps:

  






    
  
  • First, Xft ensures that the glyphs array is complete using
      XftFontCheckGlyph() and loading any missing glyphs with
      XftFontLoadGlyphs().
    • 
  
  • Then Xft examines the glyphs to find the maximum Unicode value.
      That determines the encoding size, i.e., the width.
    • 
  
  • Then, for each glyph, Xft checks if its Unicode value is handled by
      the corresponding font. If not, the value is set to zero (0), to ignore
      it. While doing this, Xft also remembers which was the first font
      used, and computes the position at which each glyph will be drawn.
    • 
  
  • Xft then constructs an equivalent array of glyphs in the format
      expected by the X Render library.
    • 
  
  • Finally, XftGlyphFontSpecRender() uses the X Render extension to
      draw the glyphs, with the appropriate XRenderCompositeText*()
      function according to the width, and discards temporary data.
    • 




  

  
The op, dst, src, srcx, and srcy
      parameters are used as described in the documentation for the X Render
      library.
