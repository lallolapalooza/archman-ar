XForceScreenSaver(3)

الحزمة: libx11

التراخيص: MIT AND X11

XSetScreenSaver(3) وظائف XLIB XSetScreenSaver(3)

الاسم

XSetScreenSaver, XForceScreenSaver, XActivateScreenSaver, XResetScreenSaver, XGetScreenSaver - معالجة شاشة التوقف

الصيغة

int XSetScreenSaver(Display *display, int timeout, int interval, int prefer_blanking, int allow_exposures);

int XForceScreenSaver(Display *display, int mode);

int XActivateScreenSaver(Display *display);

int XResetScreenSaver(Display *display);

int XGetScreenSaver(Display *display, int *timeout_return, int *interval_return, int *prefer_blanking_return, int *allow_exposures_return);

المعاملات

allow_exposures
يحدد قيم التحكم في شاشة التوقف. يمكنك تمرير DontAllowExposures، AllowExposures، أو DefaultExposures.
allow_exposures_return
يعيد قيمة التحكم الحالية في شاشة التوقف (DontAllowExposures، AllowExposures، أو DefaultExposures).
display
يحدد الاتصال بخادم X.
interval
يحدد الفترة الزمنية، بالثواني، بين تغييرات شاشة التوقف.
interval_return
يعيد الفترة الزمنية بين استدعاءات شاشة التوقف.
mode
يحدد الوضع الذي سيتم تطبيقه. يمكنك تمرير ScreenSaverActive أو ScreenSaverReset.
prefer_blanking
يحدد كيفية تمكين تعتيم الشاشة. يمكنك تمرير DontPreferBlanking، PreferBlanking، أو DefaultBlanking.
prefer_blanking_return
يعيد تفضيل تعتيم الشاشة الحالي (DontPreferBlanking، PreferBlanking، أو DefaultBlanking).
timeout
يحدد المهلة الزمنية، بالثواني، حتى يتم تشغيل شاشة التوقف.
timeout_return
يعيد المهلة الزمنية، بالثواني، حتى يتم تشغيل شاشة التوقف.

الوصف

يتم تحديد المهلة الزمنية والفترة الزمنية بالثواني. المهلة الزمنية 0 تعطل شاشة التوقف (لكن شاشة التوقف النشطة لا يتم إلغاء تنشيطها)، والمهلة الزمنية -1 تعيد الإعدادات الافتراضية. القيم السالبة الأخرى تولد خطأ BadValue. إذا كانت قيمة المهلة الزمنية غير صفرية، فإن XSetScreenSaver تمكن شاشة التوقف. الفترة الزمنية 0 تعطل حركة الأنماط العشوائية. يتم تحديد كلتا القيمتين ضمن نطاق عدد صحيح موقع 16 بت بواسطة بروتوكول الأسلاك، على الرغم من النموذج الأولي C. إذا لم يتم إنشاء أي إدخال من الأجهزة (لوحة المفاتيح، الماوس، وما إلى ذلك) خلال عدد الثواني المحدد للمهلة الزمنية بعد تمكين شاشة التوقف، يتم تنشيط شاشة التوقف.

لكل شاشة، إذا كان التعتيم مفضلاً وكانت الأجهزة تدعم تعتيم الفيديو، فإن الشاشة تصبح فارغة ببساطة. وإلا، إذا كانت التعرضات مسموحة أو يمكن إعادة إنشاء الشاشة دون إرسال أحداث Expose للعملاء، يتم تجانب الشاشة مع بلاط خلفية النافذة الجذرية، مع إعادة ترتيب عشوائي كل فترة زمنية. وإلا، فإن حالات الشاشة لا تتغير، ولا يتم تنشيط شاشة التوقف. يتم إلغاء تنشيط شاشة التوقف، ويتم استعادة جميع حالات الشاشة عند الإدخال التالي من لوحة المفاتيح أو المؤشر أو عند الاستدعاء التالي لـ XForceScreenSaver مع الوضع ScreenSaverReset.

إذا كانت طريقة شاشة التوقف المعتمدة على الخادم تدعم التغيير الدوري، فإن معامل الفترة الزمنية يعمل كإشارة حول مدة فترة التغيير، والصفر يشير إلى عدم وجود تغيير دوري. تشمل أمثلة طرق تغيير الشاشة تبديل لوحة الألوان بشكل دوري، أو تحريك صورة أيقونة حول الشاشة بشكل دوري، أو تجانب الشاشة ببلاط خلفية النافذة الجذرية، مع إعادة ترتيب عشوائي بشكل دوري.

يمكن لـ XSetScreenSaver توليد خطأ BadValue.

إذا كان الوضع المحدد هو ScreenSaverActive وكانت شاشة التوقف غير نشطة حاليًا، فإن XForceScreenSaver تنشط شاشة التوقف حتى لو تم تعطيل شاشة التوقف بمهلة زمنية صفرية. إذا كان الوضع المحدد هو ScreenSaverReset وكانت شاشة التوقف نشطة حاليًا، فإن XForceScreenSaver تلغي تنشيط شاشة التوقف إذا كانت نشطة، ويتم إعادة تعيين مؤقت التنشيط إلى حالته الأولية (كما لو تم تلقي إدخال من الجهاز).

يمكن لـ XForceScreenSaver توليد خطأ BadValue.

تقوم الدالة XActivateScreenSaver بتنشيط شاشة التوقف.

تقوم الدالة XResetScreenSaver بإعادة تعيين شاشة التوقف.

تقوم الدالة XGetScreenSaver بالحصول على قيم شاشة التوقف الحالية.

التشخيصات

BadValue
قيمة رقمية ما تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق محدد لمعامل، يتم قبول النطاق الكامل الذي تحدده نوع المعامل. يمكن لأي معامل معرف كمجموعة من البدائل توليد هذا الخطأ.
