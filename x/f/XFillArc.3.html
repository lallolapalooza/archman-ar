XFillArc(3)

الحزمة: libx11

التراخيص: MIT AND X11

XFillRectangle(3) دوال XLIB XFillRectangle(3)

الاسم

XFillRectangle, XFillRectangles, XFillPolygon, XFillArc, XFillArcs - ملء المستطيلات، المضلعات، أو الأقواس

الصيغة

int XFillRectangle(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height);

int XFillRectangles(Display *display, Drawable d, GC gc, XRectangle *rectangles, int nrectangles);

int XFillPolygon(Display *display, Drawable d, GC gc, XPoint *points, int npoints, int shape, int mode);

int XFillArc(Display *display, Drawable d, GC gc, int x, int y, unsigned int width, unsigned int height, int angle1, int angle2);

int XFillArcs(Display *display, Drawable d, GC gc, XArc *arcs, int narcs);

المعاملات

angle1
يحدد بداية القوس بالنسبة لموضع الساعة الثالثة من المركز، بوحدات درجات * 64.
angle2
يحدد مسار القوس ومدى امتداده بالنسبة لبداية القوس، بوحدات درجات * 64.
arcs
يحدد مصفوفة من الأقواس.
d
يحدد القابلية للسحب.
display
يحدد الاتصال بخادم X.
gc
يحدد GC.
mode
يحدد وضع الإحداثيات. يمكنك تمرير CoordModeOrigin أو CoordModePrevious.
narcs
يحدد عدد الأقواس في المصفوفة.
npoints
يحدد عدد النقاط في المصفوفة.
nrectangles
يحدد عدد المستطيلات في المصفوفة.
points
يحدد مصفوفة من النقاط.
rectangles
يحدد مصفوفة من المستطيلات.
shape
يحدد شكلًا يساعد الخادم على تحسين الأداء. يمكنك تمرير Complex، Convex، أو Nonconvex.
width

height
تحدد العرض والارتفاع، وهما أبعاد المستطيل المراد ملؤه أو المحاور الرئيسية والثانوية للقوس.
x

y
تحدد إحداثيات x و y، وهي نسبية إلى أصل القابلية للسحب وتحدد الزاوية العلوية اليسرى للمستطيل.

الوصف

تقوم دالتا XFillRectangle و XFillRectangles بملء المستطيل المحدد أو المستطيلات كما لو كان قد تم تحديد طلب بروتوكول FillPolygon ذي الأربع نقاط لكل مستطيل:

[x,y] [x+width,y] [x+width,y+height] [x,y+height]

تستخدم كل دالة إحداثيات x و y، وأبعاد العرض والارتفاع، و GC التي تحددها.

تقوم XFillRectangles بملء المستطيلات بالترتيب المذكور في المصفوفة. لأي مستطيل معين، لا ترسم XFillRectangle و XFillRectangles بكسلًا أكثر من مرة. إذا تقاطعت المستطيلات، يتم رسم البكسلات المتقاطعة عدة مرات.

تستخدم كلتا الدالتين مكونات GC التالية: الوظيفة، قناع المستوى، نمط الملء، وضع النافذة الفرعية، أصل x للمقطع، أصل y للمقطع، وقناع المقطع. كما تستخدم مكونات GC المعتمدة على الوضع التالية: اللون الأمامي، اللون الخلفي، البلاط، النقش، أصل x للبلاط، وأصل y للبلاط.

يمكن لدالتي XFillRectangle و XFillRectangles إنشاء أخطاء BadDrawable، BadGC، و BadMatch.

تقوم XFillPolygon بملء المنطقة المغلقة بالمسار المحدد. يتم إغلاق المسار تلقائيًا إذا كانت النقطة الأخيرة في القائمة لا تتزامن مع النقطة الأولى. لا ترسم XFillPolygon بكسلًا من المنطقة أكثر من مرة. يعامل CoordModeOrigin جميع الإحداثيات على أنها نسبية إلى الأصل، ويعامل CoordModePrevious جميع الإحداثيات بعد الأولى على أنها نسبية إلى النقطة السابقة.

اعتمادًا على الشكل المحدد، يحدث ما يلي:

  • إذا كان الشكل Complex، فقد يتقاطع المسار مع نفسه. لاحظ أن النقاط المتجاورة المتطابقة في المسار لا تعتبر تقاطعًا ذاتيًا.
  • إذا كان الشكل Convex، فلكل زوج من النقاط داخل المضلع، فإن القطعة المستقيمة التي تربط بينهما لا تتقاطع مع المسار. إذا كان العميل يعرف ذلك، فيمكن أن يؤدي تحديد Convex إلى تحسين الأداء. إذا قمت بتحديد Convex لمسار غير محدب، فإن النتائج الرسومية غير محددة.
  • إذا كان الشكل Nonconvex، فإن المسار لا يتقاطع مع نفسه، ولكن الشكل ليس محدبًا بالكامل. إذا كان العميل يعرف ذلك، فقد يؤدي تحديد Nonconvex بدلاً من Complex إلى تحسين الأداء. إذا قمت بتحديد Nonconvex لمسار يتقاطع مع نفسه، فإن النتائج الرسومية غير محددة.

قاعدة الملء لـ GC تتحكم في سلوك ملء المضلعات التي تتقاطع مع نفسها.

تستخدم هذه الدالة مكونات GC التالية: الوظيفة، قناع المستوى، نمط الملء، قاعدة الملء، وضع النافذة الفرعية، أصل x للمقطع، أصل y للمقطع، وقناع المقطع. كما تستخدم مكونات GC المعتمدة على الوضع التالية: اللون الأمامي، اللون الخلفي، البلاط، النقش، أصل x للبلاط، وأصل y للبلاط.

يمكن لـ XFillPolygon إنشاء أخطاء BadDrawable، BadGC، BadMatch، و BadValue.

لكل قوس، تقوم XFillArc أو XFillArcs بملء المنطقة المغلقة بالمسار ذي السمك اللامتناهي الموصوف بالقوس المحدد، واعتمادًا على وضع القوس المحدد في GC، خط أو خطين. بالنسبة لـ ArcChord، يتم استخدام الخط المستقيم الوحيد الذي يربط بين نهايات القوس. بالنسبة لـ ArcPieSlice، يتم استخدام الخطين اللذين يربطان بين نهايات القوس مع النقطة المركزية. تقوم XFillArcs بملء الأقواس بالترتيب المذكور في المصفوفة. لأي قوس معين، لا ترسم XFillArc و XFillArcs بكسلًا أكثر من مرة. إذا تقاطعت المناطق، يتم رسم البكسلات المتقاطعة عدة مرات.

تستخدم كلتا الدالتين مكونات GC التالية: الوظيفة، قناع المستوى، نمط الملء، وضع القوس، وضع النافذة الفرعية، أصل x للمقطع، أصل y للمقطع، وقناع المقطع. كما تستخدم مكونات GC المعتمدة على الوضع التالية: اللون الأمامي، اللون الخلفي، البلاط، النقش، أصل x للبلاط، وأصل y للبلاط.

يمكن لـ XFillArc و XFillArcs إنشاء أخطاء BadDrawable، BadGC، و BadMatch.

التشخيصات

BadDrawable
قيمة معامل Drawable لا تسمي نافذة أو بيكسماپ محددة.
BadGC
قيمة معامل GContext لا تسمي GContext محددة.
BadMatch
يتم استخدام نافذة InputOnly كـ Drawable.
BadMatch
بعض المعاملات أو أزواج المعاملات لها النوع الصحيح والنطاق الصحيح ولكنها تفشل في المطابقة بطريقة أخرى تتطلبها الطلبية.
BadValue
تقع قيمة رقمية ما خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لمعامل، يتم قبول النطاق الكامل الذي تحدده نوع المعامل. يمكن لأي معامل معرف كمجموعة من البدائل أن ينشئ هذا الخطأ.
