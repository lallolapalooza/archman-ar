الوصف

The XFree86-VidMode extension provides services for querying and setting video modes. It is particularly useful for applications that need to directly control the display's resolution, refresh rate, and other timing parameters. This extension is a successor to the older XFree86-DGA extension.

الامتداد

The XFree86-VidMode extension provides a means for applications to query and set the video modes supported by the X server. It allows for detailed control over monitor settings, including resolution, refresh rate, and timing parameters. The extension is particularly useful for graphics-intensive applications such as games and multimedia players, as well as for system administration tasks related to display configuration.

The extension is organized into several functions, each designed to perform a specific task related to video mode management. These functions allow applications to query information about the current video mode, retrieve a list of supported modes, add or delete custom modes, modify existing modes, and switch between different modes.

In addition to mode management, the extension also provides functionality for querying and setting monitor characteristics, such as horizontal and vertical sync ranges, and for controlling the gamma correction of the display. Viewport management is also supported, allowing applications to control the position of the visible area on the screen.

تهيئة الامتداد

Before using any of the XF86VidMode functions, you must first query the extension to ensure it is available and to obtain its event and error base numbers. This is done using the XF86VidModeQueryExtension() function:

    Bool XF86VidModeQueryExtension(Display *display,
                                   int *event_base_return,
                                   int *error_base_return);

If the extension is available, this function returns True and sets event_base_return and error_base_return to the appropriate base numbers. Otherwise, it returns False.

You may also want to query the version of the extension supported by the server:

    Bool XF86VidModeQueryVersion(Display *display,
                                 int *major_version_return,
                                 int *minor_version_return);

This function returns True if the extension is available and sets major_version_return and minor_version_return to the major and minor version numbers, respectively. If the extension is not available, it returns False.

Finally, to ensure compatibility between the client and server versions of the extension, you should call:

    Bool XF86VidModeSetClientVersion(Display *display);

This function should be called after querying the version and before making any other VidMode requests.

الاستعلام عن أوضاع الفيديو

To get the current video mode line for a screen, use:

    Bool XF86VidModeGetModeLine(Display *display,
                                int screen,
                                int *dotclock_return,
                                XF86VidModeModeLine *modeline);

This function fills the provided modeline structure with the timing parameters of the current video mode and returns the dot clock in dotclock_return. It returns True on success and False on failure.

To get a list of all available video modes, use:

    Bool XF86VidModeGetAllModeLines(Display *display,
                                     int screen,
                                     int *modecount_return,
                                     XF86VidModeModeInfo ***modesinfo);

This function returns the total number of available modes in modecount_return and a pointer to an array of XF86VidModeModeInfo structures in modesinfo. Each structure describes one video mode. The caller is responsible for freeing the memory allocated for modesinfo using Xfree().

To obtain information about the monitor connected to a screen, use:

    Bool XF86VidModeGetMonitor(Display *display,
                               int screen,
                               XF86VidModeMonitor *monitor);

This function fills the provided monitor structure with information about the monitor's vendor, model, and supported horizontal and vertical sync ranges. The caller is responsible for freeing the memory allocated for the vendor, model, hsync, and vsync fields of the monitor structure.

إدارة أوضاع الفيديو

You can add a new video mode to the server's list of supported modes using:

    Bool XF86VidModeAddModeLine(Display *display,
                                int screen,
                                XF86VidModeModeInfo *modeline,
                                XF86VidModeModeInfo *aftermode);

The modeline parameter specifies the new mode to add, and aftermode specifies the mode after which the new mode should be inserted. If aftermode is NULL, the new mode is added to the end of the list.

To remove a video mode, use:

    Bool XF86VidModeDeleteModeLine(Display *display,
                                   int screen,
                                   XF86VidModeModeInfo *modeline);

The modeline parameter specifies the mode to remove.

To modify an existing video mode, use:

    Bool XF86VidModeModModeLine(Display *display,
                                int screen,
                                XF86VidModeModeLine *modeline);

The modeline parameter specifies the new timing parameters for the current mode.

Before adding or modifying a mode, you can validate its parameters using:

    Status XF86VidModeValidateModeLine(Display *display,
                                       int screen,
                                       XF86VidModeModeLine *modeline);

This function returns True if the mode is valid and False otherwise. The status can be checked for more detailed error information.

التبديل بين أوضاع الفيديو

To switch to the next or previous video mode, use:

    Bool XF86VidModeSwitchMode(Display *display,
                               int screen,
                               int zoom);

If zoom is greater than zero, the next mode is selected; otherwise, the previous mode is selected.

To switch directly to a specific video mode, use:

    Bool XF86VidModeSwitchToMode(Display *display,
                                 int screen,
                                 XF86VidModeModeInfo *modeline);

The modeline parameter specifies the desired mode to switch to.

To prevent or allow mode switching, use:

    Bool XF86VidModeLockModeSwitch(Display *display,
                                   int screen,
                                   int lock);

If lock is non-zero, mode switching is locked. If lock is zero, mode switching is unlocked.

إدارة منطقة العرض

To get the current viewport position, use:

    Bool XF86VidModeGetViewPort(Display *display,
                                int screen,
                                int *x_return,
                                int *y_return);

This function returns the current X and Y coordinates of the viewport in x_return and y_return.

To set the viewport position, use:

    Bool XF86VidModeSetViewPort(Display *display,
                                int screen,
                                int x,
                                int y);

The x and y parameters specify the desired new coordinates for the viewport.

تصحيح جاما

To get the current gamma correction settings, use:

    Bool XF86VidModeGetGamma(Display *display,
                             int screen,
                             XF86VidModeGamma *Gamma);

This function returns the current gamma values for red, green, and blue in the Gamma structure.

To set the gamma correction settings, use:

    Bool XF86VidModeSetGamma(Display *display,
                             int screen,
                             XF86VidModeGamma *Gamma);

The Gamma parameter specifies the desired new gamma values.

The XF86-VidMode extension also supports querying and setting the gamma ramp, which provides finer control over the color correction. To get the gamma ramp, use:

    Bool XF86VidModeGetGammaRamp(Display *display,
                                 int screen,
                                 int size,
                                 unsigned short *red_array,
                                 unsigned short *green_array,
                                 unsigned short *blue_array);

The size parameter specifies the number of entries in each color array. The red_array, green_array, and blue_array parameters are pointers to arrays that will be filled with the gamma ramp data.

To set the gamma ramp, use:

    Bool XF86VidModeSetGammaRamp(Display *display,
                                 int screen,
                                 int size,
                                 unsigned short *red_array,
                                 unsigned short *green_array,
                                 unsigned short *blue_array);

To query the size of the gamma ramp supported by the server, use:

    Bool XF86VidModeGetGammaRampSize(Display *display,
                                     int screen,
                                     int *size);

This function returns the size of the gamma ramp in size.
