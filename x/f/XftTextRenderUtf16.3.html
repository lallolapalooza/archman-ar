XftDraw

هو كائن غير شفاف يحتوي على معلومات تُستخدم للرسم على كائن قابل للرسم (drawable) في X باستخدام البروتوكول الأساسي أو امتداد X Rendering.

يتم إنشاء كائنات XftDraw باستخدام أي من الدوال التالية: XftDrawCreate() (التي تربط كائن XftDraw بكائن قابل للرسم موجود في X)، أو XftDrawCreateBitmap()، أو XftDrawCreateAlpha(). ويتم تدميرها باستخدام XftDrawDestroy(). يمكن تغيير كائن X القابل للرسم المرتبط بـ XftDraw باستخدام XftDrawChange(). يتم تخصيص وتحرير كائنات XftDraw داخليًا بواسطة Xft؛ ولا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة تخزين لها.

يمكن الاستعلام عن خصائص Display و Drawable و Colormap و Visual الخاصة بـ X لكائن XftDraw باستخدام الدوال XftDrawDisplay() و XftDrawDrawable() و XftDrawColormap() و XftDrawVisual() على التوالي.

تستخدم العديد من الدوال كائنات XftDraw: XftDrawCharFontSpec() و XftDrawCharSpec() و XftDrawGlyphFontSpec() و XftDrawGlyphSpec() و XftDrawGlyphs() و XftDrawRect() و XftDrawSetClip() و XftDrawSetClipRectangles() و XftDrawSetSubwindowMode() وعائلة الدوال XftDrawString*().

يتم إرجاع امتداد X Rendering Picture المرتبط بـ XftDraw بواسطة XftDrawPicture() و XftDrawSrcPicture(). ويتم استخدامه بواسطة الدوال XftCharFontSpecRender() و XftCharSpecRender() و XftGlyphFontSpecRender() و XftGlyphRender() و XftGlyphSpecRender() وعائلة الدوال XftTextRender*().

الدوال

التهيئة

التطبيق النموذجي الذي يستخدم Xft لا يقوم بتهيئة المكتبة بشكل صريح. يحدث ذلك عادةً كأثر جانبي لفتح خط.

عند تهيئة Xft، تقوم بجمع معلومات حول الشاشة، وتخزين بعض تلك المعلومات في نمط Fontconfig (وهو أساسًا مجموعة من الخصائص ذات القيم المعرفة النوع). يمكن للتطبيق المستدعي تعديل هذا النمط لتغيير سلوك المكتبة.

لا يتم تخزين جميع المعلومات المجمعة في نمط. يتم تخزين الباقي في هياكل بيانات داخلية. يوفر Xft بعضًا من تلك المعلومات للتطبيق عبر الدوال.

Bool XftDefaultHasRender (
	Display	*dpy);

الحصول على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وإرجاع true إذا وجدت Xft أن الشاشة تدعم امتداد X Render، وإذا كانت قادرة على العثور على XRenderPictFormat مناسب (نوع بيانات X Render الذي يماثل Visual في Xlib) على الشاشة.

Bool XftDefaultSet (
	Display	*dpy,
	FcPattern	*defaults);

الحصول على معلومات حول الشاشة dpy إذا لم يتم ذلك بالفعل، وتعيين نمط Fontconfig الذي يحتوي على الخصائص الافتراضية التي ستستخدمها Xft لهذه الشاشة.

تستخدم Xft هذه الخصائص مبدئيًا للحصول على هذه الحدود:
XFT_MAX_GLYPH_MEMORY
(maxglyphmemory). هذا هو الحد الأقصى لذاكرة الجليفات لجميع الخطوط التي تستخدمها Xft (افتراضي: 4*1024*1024).
XFT_MAX_UNREF_FONTS
(maxunreffonts). هذا هو الحد الأقصى لعدد الخطوط غير المشار إليها (افتراضي: 16).
XFT_TRACK_MEM_USAGE
(trackmemusage). عند تعيينه إلى true، تتتبع Xft استخدام ذاكرة الجليفات لتحسين الأداء عند اتخاذ قرار بشأن ما يجب إلغاء تحميله عند الوصول إلى الحد الأقصى لذاكرة الجليفات (افتراضي: false).
تستخدم Xft أيضًا هذه الخصائص الافتراضية في XftDefaultSubstitute().
void XftDefaultSubstitute (
	Display	*dpy,
	int	 screen,
	FcPattern	*pattern);

تقوم Xft بملء الخصائص المفقودة في pattern المعطى باستخدام الخصائص الافتراضية للشاشة المحددة dpy، مثل تلك المعينة في XftDefaultSet().

تستخدم تطبيقات Xft النموذجية هذه الدالة للمساعدة في Fontconfig في اختيار خط مناسب. يتم استبدال هذه الخصائص قبل استدعاء FcDefaultSubstitute():
FC_ANTIALIAS
(true إذا كان يجب على FreeType استخدام التنعيم (antialiasing) (افتراضي: False)). (افتراضي: True).
FC_AUTOHINT
(true إذا كان يجب على FreeType استخدام التلميح التلقائي (autohinting) (افتراضي: False)).
FC_DPI
النقاط/البوصة المستخدمة للدقة (افتراضي: محسوبة من ارتفاع الشاشة).
FC_EMBOLDEN
(true إذا كان يجب استخدام FT_GlyphSlot_Embolden() لتغميق الخط (افتراضي: False)).
FC_HINTING
(true إذا كان يجب استخدام التلميح عند ملء الخصائص لفتح خط (افتراضي: True)).
FC_HINT_STYLE
نمط التلميح المستخدم عند ملء الخصائص لفتح خط (افتراضي: FC_HINT_FULL).
FC_LCD_FILTER
المعلمة التي يتم تمريرها إلى FT_Library_SetLcdFilter() عند تحميل الجليفات (افتراضي: FC_LCD_DEFAULT).
FC_MINSPACE
الحد الأدنى للمسافة المستخدمة عند ملء الخصائص لفتح خط (افتراضي: False).
FC_RGBA
قيمة RGBA المستخدمة عند ملء الخصائص لفتح خط (افتراضي: محسوبة عن طريق استدعاء XRenderQuerySubpixelOrder()).
FC_SCALE
المقياس المستخدم في Fontconfig (افتراضي: 1.0).
XFT_MAX_GLYPH_MEMORY
الحد الأقصى للذاكرة لخط واحد (افتراضي: 1024*1024).
XFT_RENDER
(true إذا كانت الشاشة تدعم امتداد X Render (افتراضي: نتيجة من XftDefaultHasRender())).
FcBool XftInit (
	_Xconst char	*config);

يقوم بتهيئة مكتبة Fontconfig (باستدعاء FcInit()).

المعلمة config غير مستخدمة.
لا تقوم Xft بإلغاء تهيئة مكتبة Fontconfig عند الانتهاء.
FcBool XftInitFtLibrary (void);

    
يقوم بتهيئة مكتبة FreeType (باستدعاء FT_Init_FreeType() لإنشاء كائن مكتبة) إذا لم يتم تهيئتها بالفعل. هذا ضروري قبل استخدام مكتبة FreeType لقراءة بيانات الخطوط من ملف.

  





  

  
تقوم Xft باستدعاء XftInitFtLibrary() داخليًا عبر XftFontInfoCreate() و XftFontOpenPattern().

  

  
لا تتخلص Xft من كائن المكتبة (على سبيل المثال، باستخدام FT_Done_FreeType()) عند الانتهاء.

	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);


    
تخصيص قيمة لون:

  






    
  
  • إذا كان فئة visual هي TrueColor، فإن XftColorAllocValue()
      تضبط حقل pixel في XftColor المشار إليه بواسطة result
      باستخدام حقول الأحمر والأخضر والأزرق من المعامل color.
    • 
  
  • إذا كانت فئة visual ليست TrueColor، فإن XftColorAllocValue()

      من قبل الجهاز.
    •

      result وتعيد True.

      تعيد False ولا تعدل النتيجة.

The Xft library provides functions for rendering fonts using
    FreeType. In order to render text, you must first create an XftDraw
    object, which serves as a drawing context. The XftDraw object is
    associated with an X drawable, such as a window or a pixmap. The functions
    described below can be used to create and manipulate XftDraw
    objects.

Bool XftDrawSetClip (

  

    
	XftDraw	*draw,
	Region	 r);


    
Set up clipping for the given XftDraw parameter
        draw starting with a Region:

  






    
  
  • If the Region parameter r is not null, Xft creates a
      new Region (to copy the parameter),
    • 
  
  • Xft destroys any existing clipping region.
    • 
  
  • Xft sets the clip_type for the draw parameter to
      XftClipTypeRegion if the r parameter was not null. Otherwise
      it sets the clip_type to XftClipTypeNone.
    • 
  
  • Finally, Xft updates clipping for existing objects, updates the
      clip_mask for its X Render Picture object and sets the
      clipping-mask in the graphic context (GC) associated with the
      XftDraw parameter.
    • 






  

  
XftDrawSetClip() returns True if no change was necessary, or
      if the operation succeeded. It returns False if it was unable to
      create the new Region().

	int	 xOrigin,
	int	 yOrigin,
	_Xconst XRectangle	*rects,
	int	 n);


    
Like XftDrawSetClip(),
        XftDrawSetClipRectangles() sets up clipping for the given
        XftDraw parameter draw but uses a set of n
        rectangles (the rects parameter) which could be used to construct
        a Region .

  





  

  
Xft sets the clip_type for draw to XftClipTypeRectangles and
      uses XSetClipRectangles() for core (X11) clipping and
      XRenderSetPictureClipRectangles() for X Render clipping.





  
void XftDrawSetSubwindowMode (

  

    
	XftDraw	*draw,
	int	 mode);


    
Sets the subwindow-mode for the given XftDraw parameter
        draw. The mode can be either ClipByChildren (the default),
        or IncludeInferiors:

  






    
  
  • For ClipByChildren, both source and destination windows are
      additionally clipped by all viewable InputOutput children.
    • 
  
  • For IncludeInferiors, neither source nor destination window is
      clipped by inferiors. This will result in including subwindow contents in
      the source and drawing through subwindow boundaries of the
    destination.
    • 






  

  
In addition to the subwindow-mode maintained by Xft, it updates the
      subwindow mode for any associated graphics context GC using
      XSetSubwindowMode() as well as for an X Render Picture using
      XRenderChangePicture().

void XftDrawGlyphFontSpec (

  

    
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);


    
Draw a list of glyphs associated with fonts at specified
        coordinates, passed as an array of len XftGlyphFontSpec
        structures via the parameter glyphs. All of the glyphs are drawn
        using the color specified in the color parameter.

  





  

  
For each entry in the glyphs array:






    
  
  • If the associated font uses the X Render extension, then Xft uses
      XftGlyphFontSpecRender() to draw the glyph, using a Picture
      obtained from calling XftDrawSrcPicture () with the draw and
      color parameters.
    • 
  
  • Otherwise, Xft provides an analogous feature using Xlib.
    • 






  
void XftGlyphFontSpecRender (

  

    
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);


    
This involves several steps:

  






    
  
  • First, Xft ensures that the glyphs array is complete using
      XftFontCheckGlyph() and loading any missing glyphs with
      XftFontLoadGlyphs().
    • 
  
  • Then Xft examines the glyphs to find the maximum Unicode value.
      That determines the encoding size, i.e., the width.
    • 
  
  • Then, for each glyph, Xft checks if its Unicode value is handled by
      the corresponding font. If not, the value is set to zero (0), to ignore
      it. While doing this, Xft also remembers which was the first font
      used, and computes the position at which each glyph will be drawn.
    • 
  
  • Xft then constructs an equivalent array of glyphs in the format
      expected by the X Render library.
    • 
  
  • Finally, XftGlyphFontSpecRender() uses the X Render extension to
      draw the glyphs, with the appropriate XRenderCompositeText*()
      function according to the width, and discards temporary data.
    • 




  

  
The op, dst, src, srcx, and srcy
      parameters are used as described in the documentation for the X Render
      library.

Xft, libXft - font objects






SYNOPSIS


#include <X11/Xft/Xft.h>







DESCRIPTION


The libXft library provides access to font
    rendering capabilities. It integrates with Fontconfig for font selection and
    FreeType 2 for font rasterization.


This document describes the functions for manipulating font
    patterns and loading/unloading font data.






CONSTANTS


The following boolean constants are defined:



  
FcTrue

  
Represents a true value.

  
FcFalse

  
Represents a false value.








DATA TYPES



  
FcPattern

  
An opaque structure representing a font pattern. It holds a set of font
      properties and their corresponding values.

  
XftFont

  
A structure representing an opened font. It contains information about the
      font, including its metrics and FreeType face.

  
FT_Face

  
A type defined by FreeType 2, representing an in-memory representation of a
      typeface.

  
FT_UInt

  
An unsigned integer type defined by FreeType 2, often used for glyph
      indices.








FUNCTIONS



  
FcPattern * XftFontMatch (

  

    
	Display	*dpy,
	int	 screen,
	const FcPattern	*s,
	FcPattern	**m);


    
Finds the best font matching the pattern s for the
        display dpy and screen screen. If a match is found, the
        matching pattern is returned in m and the font pattern is
        returned as the function result. The caller is responsible for freeing
        the returned patterns using FcPatternDestroy().

	Display	*dpy,
	FcPattern	*pat);


    
Opens a font matching the given pattern pat for the
        display dpy. Returns a pointer to an XftFont structure if
        successful, otherwise NULL. The caller is responsible for freeing
        the font using XftFontClose().
