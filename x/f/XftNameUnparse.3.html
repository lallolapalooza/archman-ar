Bool XftDrawSetClip (
	XftDraw	*draw,
	Region	 r);

يقوم بإعداد القص للمعلمة XftDraw المحددة draw بدءًا من Region:

  • إذا كانت المعلمة Region r ليست فارغة، فإن Xft ينشئ Region جديدة (لنسخ المعلمة)،
  • يقوم Xft بتدمير أي منطقة قص موجودة.
  • يقوم Xft بتعيين نوع القص (clip_type) للمعلمة draw إلى XftClipTypeRegion إذا لم تكن المعلمة r فارغة. وإلا، فإنه يعين نوع القص إلى XftClipTypeNone.
  • أخيرًا، يقوم Xft بتحديث القص للكائنات الموجودة، ويحدث قناع القص (clip_mask) لكائن Picture الخاص بـ X Render، ويعين قناع القص في سياق الرسم (GC) المرتبط بمعلمة XftDraw.
XftDrawSetClip() يعيد True إذا لم يكن هناك تغيير ضروري، أو إذا نجحت العملية. يعيد False إذا لم يتمكن من إنشاء Region() جديدة.
Bool XftDrawSetClipRectangles (
	XftDraw	*draw,
	int	 xOrigin,
	int	 yOrigin,
	_Xconst XRectangle	*rects,
	int	 n);

مثل XftDrawSetClip()، يقوم XftDrawSetClipRectangles() بإعداد القص للمعلمة XftDraw المحددة draw ولكن باستخدام مجموعة من n مستطيلات (المعلمة rects) التي يمكن استخدامها لإنشاء Region.

يقوم Xft بتعيين نوع القص (clip_type) لـ draw إلى XftClipTypeRectangles ويستخدم XSetClipRectangles() للقص الأساسي (X11) و XRenderSetPictureClipRectangles() لقص X Render.
void XftDrawSetSubwindowMode (
	XftDraw	*draw,
	int	 mode);

يقوم بتعيين وضع النافذة الفرعية (subwindow-mode) للمعلمة XftDraw المحددة draw. يمكن أن يكون الوضع إما ClipByChildren (الافتراضي) أو IncludeInferiors:

  • بالنسبة لـ ClipByChildren، يتم قص كل من نوافذ المصدر والوجهة إضافيًا بواسطة جميع الأطفال المرئيين من نوع InputOutput.
  • بالنسبة لـ IncludeInferiors، لا يتم قص أي من نافذة المصدر أو الوجهة بواسطة النوافذ الفرعية. سيؤدي هذا إلى تضمين محتويات النوافذ الفرعية في المصدر والرسم عبر حدود النوافذ الفرعية للوجهة.
بالإضافة إلى وضع النافذة الفرعية الذي تحتفظ به Xft، فإنه يقوم بتحديث وضع النافذة الفرعية لأي سياق رسم (GC) مرتبط باستخدام XSetSubwindowMode() بالإضافة إلى صورة X Render باستخدام XRenderChangePicture().

XftCharFontSpecRender() تحول المعلمة chars من XftCharFontSpec إلى XftGlyphFontSpec، وتمرر المصفوفة المحولة مع المعلمات الأخرى دون تغيير إلى XftGlyphFontSpecRender() لرسم البيانات.

void XftDrawGlyphFontSpec (
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);

ترسم قائمة من الأحرف المرتبطة بالخطوط في إحداثيات محددة، تم تمريرها كمصفوفة من len هياكل XftGlyphFontSpec عبر المعلمة glyphs. يتم رسم جميع الأحرف باستخدام اللون المحدد في المعلمة color.

لكل إدخال في مصفوفة glyphs:
  • إذا كان الخط المرتبط يستخدم امتداد X Render، فإن Xft يستخدم XftGlyphFontSpecRender() لرسم الحرف، باستخدام Picture تم الحصول عليها عن طريق استدعاء XftDrawSrcPicture () مع معلمات draw و color.
  • بخلاف ذلك، توفر Xft ميزة مماثلة باستخدام Xlib.
void XftGlyphFontSpecRender (
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);

يتضمن هذا عدة خطوات:

  • أولاً، يتأكد Xft من أن مصفوفة glyphs كاملة باستخدام XftFontCheckGlyph() وتحميل أي أحرف مفقودة باستخدام XftFontLoadGlyphs().
  • بعد ذلك، يقوم Xft بفحص الأحرف للعثور على قيمة Unicode القصوى. يحدد هذا حجم الترميز، أي العرض.
  • بعد ذلك، لكل حرف، يتحقق Xft مما إذا كانت قيمة Unicode الخاصة به تتم معالجتها بواسطة الخط المقابل. إذا لم يكن الأمر كذلك، يتم تعيين القيمة إلى صفر (0) لتجاهلها. أثناء القيام بذلك، يتذكر Xft أيضًا أي خط تم استخدامه لأول مرة، ويحسب الموضع الذي سيتم فيه رسم كل حرف.
  • بعد ذلك، يقوم Xft ببناء مصفوفة مكافئة من الأحرف بالتنسيق الذي تتوقعه مكتبة X Render.
  • أخيرًا، يستخدم XftGlyphFontSpecRender() امتداد X Render لرسم الأحرف، مع دالة XRenderCompositeText*() المناسبة وفقًا للعرض، ويتجاهل البيانات المؤقتة.
تستخدم المعلمات op و dst و src و srcx و srcy كما هو موضح في وثائق مكتبة X Render.
