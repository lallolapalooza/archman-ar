الوصف

The XFree86-VidMode extension provides a means to query and set various properties of the X server's video modes. This includes setting the current resolution, the available resolutions, the viewport, and gamma correction.

XF86VidModeQueryExtension() checks if the VidMode extension is available and returns the base event and error numbers for it.

XF86VidModeQueryVersion() returns the version of the XFree86-VidMode extension that the server supports.

XF86VidModeSetClientVersion() should be called by clients to indicate the version of the VidMode extension they are using. This is used to ensure compatibility between the client and the server.

XF86VidModeGetModeLine() retrieves the current video mode line for the specified screen. This includes timing information such as horizontal and vertical display sizes, sync start and end points, and total pixel counts, as well as the current dot clock value.

XF86VidModeGetAllModeLines() retrieves all available video modes for the specified screen. It returns the number of modes and an array of XF86VidModeModeInfo structures, each describing a video mode.

XF86VidModeAddModeLine() adds a new video mode to the server's list of available modes. The new mode is inserted after the specified aftermode. If aftermode is NULL, the new mode is added to the end of the list.

XF86VidModeDeleteModeLine() removes a video mode from the server's list of available modes.

XF86VidModeModModeLine() modifies the current video mode line for the specified screen. This function is typically used to change the resolution or other timing parameters of the display.

XF86VidModeValidateModeLine() checks if a given video mode line is valid for the specified screen. It returns a status indicating whether the mode is valid and usable.

XF86VidModeSwitchMode() switches the video mode on the specified screen to the next or previous available mode. If zoom is greater than zero, it switches to the next mode; otherwise, it switches to the previous mode.

XF86VidModeSwitchToMode() switches the video mode on the specified screen to a specific mode described by the provided modeline.

XF86VidModeLockModeSwitch() locks or unlocks the ability to switch video modes. If lock is non-zero, mode switching is disabled. If lock is zero, mode switching is re-enabled.

XF86VidModeGetMonitor() retrieves information about the monitor connected to the specified screen. This includes the manufacturer and model names, and the supported horizontal and vertical sync ranges.

XF86VidModeGetViewPort() retrieves the current position of the viewport on the specified screen. The viewport is the visible portion of the screen's frame buffer.

XF86VidModeSetViewPort() sets the position of the viewport on the specified screen. This is typically used for panning across a larger virtual screen.

XF86VidModeGetDotClocks() retrieves information about the dot clocks supported by the graphics hardware for the specified screen. This includes flags, the number of supported clocks, the maximum dot clock value, and a list of the supported clock frequencies.

XF86VidModeGetGamma() retrieves the current gamma correction values for the specified screen.

XF86VidModeSetGamma() sets the gamma correction values for the specified screen.

XF86VidModeGetGammaRamp() retrieves the current gamma ramp (color lookup table) for the specified screen. It returns the size of the ramp and the red, green, and blue color values for each entry in the ramp.

XF86VidModeSetGammaRamp() sets the gamma ramp for the specified screen using the provided red, green, and blue color values.

XF86VidModeGetGammaRampSize() retrieves the size of the gamma ramp supported by the specified screen.

XF86VidModeGetPermissions() retrieves information about the permissions for accessing the VidMode extension. This function is not described in detail here but is part of the extension.

قيم الإرجاع

All functions return True on success, and False on failure, except for XF86VidModeValidateModeLine() which returns a Status value.

وصف

توفر هذه الدوال واجهة لملحق الخادم XFree86-VidModeExtension والذي يسمح بالاستعلام عن أوضاع الفيديو وتعديلها ديناميكيًا والتحكم في تبديل الأوضاع. يجب ربط التطبيقات التي تستخدم هذه الدوال بـ -lXxf86vm

دوال MODELINE

تُستخدم الدالة XF86VidModeGetModeLine للاستعلام عن إعدادات وضع الفيديو المحدد حاليًا. يجب على البرنامج المستدعي تمرير مؤشر إلى بنية XF86VidModeModeLine يكون قد خصصها بالفعل. تملأ الدالة حقول البنية.

إذا كانت هناك أي قيم خاصة بالخادم (تنطبق حاليًا على خادم S3 فقط) ، فستقوم الدالة بتخصيص مساحة تخزين لها. لذلك ، إذا كانت حقل privsize غير صفري ، يجب على البرنامج المستدعي استدعاء Xfree(private) لتحرير مساحة التخزين.

تُرجع XF86VidModeGetAllModeLines إعدادات جميع أوضاع الفيديو. يقوم البرنامج المستدعي بتوفير عنوان لمؤشر سيتم تعيينه بواسطة الدالة للإشارة إلى مصفوفة من هياكل XF86VidModeModeInfo. يتم تخصيص الذاكرة التي تشغلها المصفوفة ديناميكيًا بواسطة الدالة XF86VidModeGetAllModeLines ويجب أن يحررها المتصل. العنصر الأول في المصفوفة يقابل وضع الفيديو الحالي.

يمكن استخدام الدالة XF86VidModeModModeLine لتغيير إعدادات وضع الفيديو الحالي شريطة أن تكون الإعدادات المطلوبة صالحة (على سبيل المثال ، لا تتجاوز قدرات الشاشة).

لإضافة وضع إلى قائمة الأوضاع المتاحة ، يمكن استخدام الدالة XF86VidModeAddModeLine. بافتراض أن الإعدادات صالحة ، سيتم إضافة وضع الفيديو بعد الوضع الموجود الذي يتطابق مع التوقيتات المحددة بواسطة المعلمة aftermode. لاعتبارها مطابقة ، يجب أن تتطابق جميع حقول بنية XF86VidModeModeInfo المقدمة ، باستثناء حقلي privsize و private. إذا كانت المعلمة aftermode صفرًا ، فسيتم إضافة الوضع بعد الوضع الحالي.

يمكن حذف الأوضاع باستخدام الدالة XF86VidModeDeleteModeLine. يجب أن يتطابق الوضع المحدد مع وضع موجود. لاعتبارها مطابقة ، يجب أن تتطابق جميع حقول بنية XF86VidModeModeInfo المقدمة ، باستثناء حقلي privsize و private. إذا كان الوضع المراد حذفه هو الوضع الحالي ، فسيحدث تبديل للوضع إلى الوضع التالي أولاً. لا يمكن حذف آخر وضع متبقٍ.

يمكن التحقق من صلاحية الوضع باستخدام الدالة XF86VidModeValidateModeLine. إذا كان بإمكان الخادم استخدام الوضع المحدد (أي ، يفي بجميع القيود المفروضة على وضع من خلال مجموعة الخادم والبطاقة والشاشة) ، فإن الدالة تُرجع MODE_OK ، وإلا فإنها تُرجع قيمة تشير إلى سبب عدم صلاحية الوضع (كما هو محدد في xf86.h)

دوال تبديل الأوضاع

عند استدعاء الدالة XF86VidModeSwitchMode ، سيقوم الخادم بتغيير وضع الفيديو إلى وضع الفيديو التالي (أو السابق). يمكن استخدام الدالة XF86VidModeSwitchToMode للتبديل مباشرة إلى الوضع المحدد. المطابقة كما هو محدد في وصف الدالة XF86VidModeAddModeLine أعلاه. يمكن استخدام الدالة XF86VidModeLockModeSwitch للسماح أو منع تبديل الأوضاع سواء كان الطلب لتبديل الأوضاع قادمًا من استدعاء للدوال XF86VidModeSwitchMode أو XF86VidModeSwitchToMode أو من إحدى تسلسلات مفاتيح تبديل الأوضاع.

ملاحظة: بسبب الطبيعة غير المتزامنة لبروتوكول X ، يلزم استدعاء XFlush إذا كان التطبيق يريد رؤية تغيير الوضع على الفور. ليتم إبلاغه بحالة تنفيذ الطلب ، يجب تثبيت معالج أخطاء مخصص باستخدام XSetErrorHandler قبل استدعاء دالة تبديل الوضع.

دوال الشاشة

يتم إرجاع المعلومات التي يعرفها الخادم حول الشاشة بواسطة الدالة XF86VidModeGetMonitor. يشير حقلا hsync و vsync كل منهما إلى مصفوفة من هياكل XF86VidModeSyncRange. تحتوي المصفوفات على عناصر nhsync و nvsync على التوالي. ستكون القيمتان hi و low متساويتين إذا تم إعطاء قيمة منفصلة في ملف XF86Config.

تشير حقلا vendor و model و hsync و vsync إلى مساحة تخزين مخصصة ديناميكيًا يجب أن يحررها المتصل.

دوال العرض

يمكن استخدام الدالتين XF86VidModeGetViewPort و XF86VidModeSetViewPort للاستعلام عن وتغيير موقع الزاوية العلوية اليسرى لمنطقة العرض في الشاشة الافتراضية ، على التوالي.

دوال أخرى

يمكن استخدام الدالة XF86VidModeQueryVersion لتحديد إصدار الملحق المدمج في الخادم.

تُرجع الدالة XF86VidModeQueryExtension أقل قيم أخطاء وأحداث مرقمة تم تعيينها للملحق.

أخطاء

تحتاج الدوال XF86VidModeSetClientVersion و XF86VidModeGetDotClocks و XF86VidModeGetGamma و XF86VidModeSetGamma و XF86VidModeSetGammaRamp و XF86VidModeGetGammaRamp و XF86VidModeGetGammaRampSize و XF86VidModeGetPermissions إلى توثيق. في غضون ذلك ، تحقق من الكود المصدري للحصول على معلومات حول كيفية استخدامها.
