الحزمة: libxft

التراخيص: HPND-sell-variant

Xft Library

The Xft library provides support for drawing text with TrueType fonts over X. It uses the fontconfig library to find fonts, and the FreeType library to render them.

Font Selection

The following functions are used to select fonts:

XftFont *XftFontOpen (
	Display	*dpy,
	int	 screen,
	_Xconst FcPattern	*pattern);

XftFontOpen opens a font matching the specified pattern for the given screen on the display dpy. The pattern is a Fontconfig pattern, which is a set of properties used to identify a font. The function returns a pointer to an XftFont structure, which can be used to draw text with the selected font.

XftFont *XftFontOpenName (
	Display	*dpy,
	int	 screen,
	_Xconst char	*name);

XftFontOpenName is similar to XftFontOpen, except that it takes a font name string (which is passed to the Fontconfig library's FcNameParse() function).

XftFont *XftFontOpenXlfd (
	Display	*dpy,
	int	 screen,
	_Xconst char	*xlfd)

XftFontOpenXlfd behaves as XftFontOpen does, except that it takes a string containing an X Logical Font Description (XLFD), and uses the XftXlfdParse() function.

FcPattern *XftFontMatch (
	Display	*dpy,
	int	 screen,
	_Xconst FcPattern	*pattern,
	FcResult	*result);

Also used internally by the XftFontOpen* functions, XftFontMatch can also be used directly to determine the Fontconfig font pattern resulting from an Xft font open request.

FcPattern *XftXlfdParse (
	_Xconst char	*xlfd_orig,
	Bool	ignore_scalable,
	Bool	complete);

XftXlfdParse parses the xlfd_orig parameter according to the X Logical Font Description Conventions document, but ignores some of the fields: setwidth_name, add_style_name, spacing, and average_width.

XftXlfdParse creates a Fontconfig pattern, setting the property XFT_XLFD to the xlfd_orig value, and maps the collected information to Fontconfig properties. Empty or “*” fields are ignored:
FC_FOUNDRY
from foundry.
FC_FAMILY
from family.
FC_WEIGHT
weight_name, defaulting to FC_WEIGHT_MEDIUM.
FC_SLANT
from slant, defaulting to FC_SLANT_ROMAN.
FC_SIZE
from point_size.
FC_PIXEL_SIZE
from pixel_size. If point_size was set, as well as resolution_xand resolution_y, then the value is scaled convert the font's height to points.

Determining Text Extents

Xft provides several functions for determining the required height and width for displaying a text-string. After accounting for the offset, in cases where the string will be shifted up, down, left or right, these numbers are referred to as text extents.

void XftTextExtents8 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtents8 computes the pixel extents on display dpy of no more than len glyphs of a string consisting of eight-bit characters when drawn with font, storing them in extents.

void XftTextExtents16 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar16	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtents16 computes the pixel extents on display dpy of no more than len glyphs of a string consisting of sixteen-bit characters when drawn with font, storing them in extents.

void XftTextExtents32 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar32	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtents32 computes the pixel extents on display dpy of no more than len glyphs of a string consisting of thirty-two-bit characters when drawn with font, storing them in extents.

void XftTextExtentsUtf8 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtentsUtf8 computes the pixel extents on display dpy of no more than len bytes of a UTF-8 encoded string when drawn with font, storing them in extents.

void XftTextExtentsUtf16 (
	Display	*dpy,
	XftFont	*font,
	_Xconst FcChar8	*string,
	FcEndian	 endian,
	int	 len,
	XGlyphInfo	*extents);

XftTextExtentsUtf16 computes the pixel extents on display dpy of no more than len bytes of a UTF-16LE- or UTF-16BE-encoded string when drawn with font, storing them in extents. The endianness of string must be specified in endian.

void XftGlyphExtents (
	Display	*dpy,
	XftFont	*font,
	_Xconst FT_UInt	*glyphs,
	int	 nglyphs,
	XGlyphInfo	*extents);

Also used internally by the XftTextExtents*() functions, XftGlyphExtents computes the pixel extents on display dpy of no more than nglyphs in the array glyphs drawn with font, storing them in extents.

If any of the glyphs are missing (determined by a check with XftFontCheckGlyph()), the corresponding entry in extents is filled with zeroes.

Managing XftColor

Bool XftColorAllocName (
	Display	*dpy,
	_Xconst Visual	*visual,
	Colormap	 cmap,
	_Xconst char	*name,
	XftColor	*result);

Use XAllocNamedColor() to look up the named color name for the screen associated with the colormap cmap.

  • If XAllocNamedColor() returns nonzero, XftColorAllocName() fills in the resulting XftColor pixel field with the closest color supported by the screen, as well as the exact red, green and blue fields from the database, and returns True.
  • If XAllocNamedColor() returns zero, XftColorAllocName() returns False, and does not update the XftColor referenced by result.
The visual parameter is unused.
Bool XftColorAllocValue (
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	_Xconst XRenderColor	*color,
	XftColor	*result);

Allocate a color value:

  • If the visual class is TrueColor, XftColorAllocValue() sets the pixel field in the XftColor referenced by result using the red, green and blue fields from the color parameter.
  • If the visual class is not TrueColor, XftColorAllocValue() calls XAllocColor() to allocate an entry in the colormap cmap. which returns the pixel value of the color closest to the specified RGB elements supported by the hardware.
If XAllocColor() succeeds XftColorAllocValue() stores that pixel value in the XRenderColor referenced by result and returns True.
If XAllocColor() fails, XftColorAllocValue() returns False and does not modify the result.
void XftColorFree (
	Display	*dpy,
	Visual	*visual,
	Colormap	 cmap,
	XftColor	*color);

If the visual class is not TrueColor, Xft calls XFreeColors() to free the entry from the colormap cmap whose pixel value in the color parameter was allocated by XftColorAllocName().

Managing XftDraw

XftDraw *XftDrawCreate (
	Display	*dpy,
	Drawable	 drawable,
	Visual	*visual,
	Colormap	 colormap);

XftDrawCreate creates a structure that can be used to render text and rectangles using the specified drawable, visual, and colormap on display.

XftDraw *XftDrawCreateBitmap (
	Display	*
dpy, Pixmap bitmap);

XftDrawCreateBitmap يتصرف مثل XftDrawCreate()، باستثناء أنه يستخدم X pixmap بعمق لون 1 بدلاً من X drawable.

XftDraw * XftDrawCreateAlpha (
	Display	*dpy,
	Pixmap	 pixmap,
	int	 depth);

XftDrawCreateAlpha يتصرف مثل XftDrawCreate()، باستثناء أنه يستخدم X pixmap بعمق لون depth بدلاً من X drawable.

void XftDrawChange (
	XftDraw	*draw,
	Drawable	 drawable);

XftDrawChange يغير ربط X drawable لكائن Xft الحالي draw من قيمته الحالية إلى drawable.

Display *XftDrawDisplay (
	XftDraw	*draw);

XftDrawDisplay يعيد مؤشرًا إلى العرض المرتبط بكائن Xft draw.

Drawable XftDrawDrawable (
	XftDraw	*draw);

XftDrawDrawable يعيد X drawable المرتبط بكائن Xft draw.

Colormap XftDrawColormap (
	XftDraw	*draw);

XftDrawColormap() يعيد colormap المرتبط بكائن Xft draw.

Visual *XftDrawVisual (
	XftDraw	*draw);

XftDrawVisual يعيد مؤشرًا إلى visual المرتبط بكائن Xft draw.

Picture XftDrawPicture (
	XftDraw	*draw);

XftDrawPicture يعيد picture المرتبط بكائن Xft draw.

إذا كان خادم X لا يدعم امتداد X Rendering، يتم إرجاع 0.
Picture XftDrawSrcPicture (
	XftDraw	*draw,
	_Xconst XftColor	*color);

يعيد كائن X Render Picture، الذي يستخدم لرسم الأحرف، على سبيل المثال، باستخدام XftGlyphRender()، XftGlyphSpecRender()، أو XftGlyphFontSpecRender()، بواسطة XftDrawGlyphs()، XftDrawGlyphSpec()، XftDrawGlyphFontSpec()، على التوالي.

إذا كان خادم X لا يدعم امتداد X Render، فإن هذه الوظائف تستخدم XftGlyphCore()، XftGlyphSpecCore()، أو XftGlyphFontSpecCore().
void XftDrawDestroy (
	XftDraw	*draw);

XftDrawDestroy يقوم بتدمير draw (الذي تم إنشاؤه بواسطة إحدى وظائف XftDrawCreate*()) ويحرر الذاكرة التي تم تخصيصها له.

Bool XftDrawSetClip (
	XftDraw	*draw,
	Region	 r);

يقوم بإعداد الاقتصاص لمعامل XftDraw المعطى draw بدءًا من Region:

  • إذا لم يكن معامل Region r فارغًا، يقوم Xft بإنشاء Region جديد (لنسخ المعامل)،
  • يقوم Xft بتدمير أي منطقة اقتصاص موجودة.
  • يقوم Xft بتعيين clip_type للمعامل draw إلى XftClipTypeRegion إذا لم يكن المعامل r فارغًا. وإلا، فإنه يعين clip_type إلى XftClipTypeNone.
  • أخيرًا، يقوم Xft بتحديث الاقتصاص للكائنات الموجودة، وتحديث clip_mask لكائن X Render Picture الخاص به، وتعيين قناع الاقتصاص في سياق الرسومات (GC) المرتبط بمعامل XftDraw.
XftDrawSetClip() يعيد True إذا لم يكن هناك تغيير ضروري، أو إذا نجحت العملية. يعيد False إذا لم يكن قادرًا على إنشاء Region جديد.
Bool XftDrawSetClipRectangles (
	XftDraw	*draw,
	int	 xOrigin,
	int	 yOrigin,
	_Xconst XRectangle	*rects,
	int	 n);

مثل XftDrawSetClip()، يقوم XftDrawSetClipRectangles() بإعداد الاقتصاص لمعامل XftDraw المعطى draw ولكنه يستخدم مجموعة من n مستطيلات (المعامل rects) والتي يمكن استخدامها لإنشاء Region.

يقوم Xft بتعيين clip_type للمعامل draw إلى XftClipTypeRectangles ويستخدم XSetClipRectangles() للاقتصاص الأساسي (X11) و XRenderSetPictureClipRectangles() للاقتصاص X Render.
void XftDrawSetSubwindowMode (
	XftDraw	*draw,
	int	 mode);

يقوم بتعيين وضع النافذة الفرعية للمعامل XftDraw المعطى draw. يمكن أن يكون الوضع إما ClipByChildren (الافتراضي)، أو IncludeInferiors:

  • بالنسبة لـ ClipByChildren، يتم اقتصاص كل من النافذة المصدر والوجهة بشكل إضافي بواسطة جميع الأطفال المرئيين من نوع InputOutput.
  • بالنسبة لـ IncludeInferiors، لا يتم اقتصاص أي من النافذة المصدر أو الوجهة بواسطة النوافذ الفرعية. سيؤدي هذا إلى تضمين محتويات النوافذ الفرعية في المصدر والرسم عبر حدود النوافذ الفرعية للوجهة.
بالإضافة إلى وضع النافذة الفرعية الذي تحتفظ به Xft، فإنه يقوم بتحديث وضع النافذة الفرعية لأي سياق رسومات (GC) مرتبط باستخدام XSetSubwindowMode() وكذلك لـ X Render Picture باستخدام XRenderChangePicture().

رسم السلاسل النصية

void XftDrawString8 (
	XftDraw	*d,
	_Xconst XftColor	*color,
	XftFont	*font,
	int	 x,
	int	 y,
	_Xconst FcChar8	*string,
	int	 len);

XftDrawString8 يرسم ما لا يزيد عن len حرفًا من string إلى drawable Xft d باستخدام font بلون color في الموضع x، y.

رسم أشياء أخرى

void XftDrawRect (
	XftDraw	*d,
	_Xconst XftColor	*color,
	int	 x,
	int	 y,
	unsigned int	 width,
	unsigned int	 height);

XftDrawRect يرسم مستطيلًا مصمتًا باللون color والعرض width والارتفاع height المحدد في الموضع x، y إلى drawable Xft d.

void XftCharFontSpecRender (
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftCharFontSpec	*chars,
	int	 len);

XftCharFontSpecRender() يقوم بتحويل المعامل chars من XftCharFontSpec إلى XftGlyphFontSpec، ويمرر المصفوفة المحولة مع المعاملات الأخرى دون تغيير إلى XftGlyphFontSpecRender() لرسم البيانات.

void XftDrawGlyphFontSpec (
	XftDraw	*draw,
	_Xconst XftColor	*color,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 len);

يرسم قائمة من الأحرف المرتبطة بالخطوط في إحداثيات محددة، يتم تمريرها كمصفوفة من len بنية XftGlyphFontSpec عبر المعامل glyphs. يتم رسم جميع الأحرف باستخدام اللون المحدد في المعامل color.

لكل إدخال في مصفوفة glyphs:
  • إذا كان الخط المرتبط يستخدم امتداد X Render، فإن Xft يستخدم XftGlyphFontSpecRender() لرسم الحرف، باستخدام Picture تم الحصول عليها عن طريق استدعاء XftDrawSrcPicture () مع المعاملين draw و color.
  • بخلاف ذلك، يوفر Xft ميزة مماثلة باستخدام Xlib.
void XftGlyphFontSpecRender (
	Display	*dpy,
	int	 op,
	Picture	 src,
	Picture	 dst,
	int	 srcx,
	int	 srcy,
	_Xconst XftGlyphFontSpec	*glyphs,
	int	 nglyphs);

يتضمن هذا عدة خطوات:

  • أولاً، يتأكد Xft من اكتمال مصفوفة glyphs باستخدام XftFontCheckGlyph() وتحميل أي أحرف مفقودة باستخدام XftFontLoadGlyphs().
  • بعد ذلك، يفحص Xft الأحرف للعثور على أقصى قيمة Unicode. هذا يحدد حجم الترميز، أي width.
  • بعد ذلك، لكل حرف، يتحقق Xft مما إذا كانت قيمة Unicode الخاصة به مدعومة من قبل الخط المقابل. إذا لم يكن كذلك، يتم تعيين القيمة إلى صفر (0)، لتجاهلها. أثناء القيام بذلك، يتذكر Xft أيضًا أي خط تم استخدامه أولاً، ويحسب الموضع الذي سيتم فيه رسم كل حرف.
  • يقوم Xft بعد ذلك ببناء مصفوفة مكافئة من الأحرف بالتنسيق المتوقع من قبل مكتبة X Render.
  • أخيرًا، تستخدم XftGlyphFontSpecRender() امتداد X Render لرسم الأحرف، باستخدام دالة XRenderCompositeText*() المناسبة وفقًا لـ width، وتتخلص من البيانات المؤقتة.
تستخدم المعاملات op و dst و src و srcx و srcy كما هو موضح في وثائق مكتبة X Render.
