XFocusChangeEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XFocusChangeEvent(3) XLIB FUNCTIONS XFocusChangeEvent(3)

الاسم

XFocusChangeEvent - بنية حدث التركيز الداخل والخارج

الهياكل

بنية أحداث FocusIn و FocusOut تحتوي على:

typedef struct {
        int type;       /* FocusIn or FocusOut */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window window;  /* window of event */
        int mode;       /* NotifyNormal, NotifyGrab, NotifyUngrab */
        int detail;
                /*
                * NotifyAncestor, NotifyVirtual, NotifyInferior,
                * NotifyNonlinear,NotifyNonlinearVirtual, NotifyPointer,
                * NotifyPointerRoot, NotifyDetailNone
                */
} XFocusChangeEvent;
typedef XFocusChangeEvent XFocusInEvent;
typedef XFocusChangeEvent XFocusOutEvent;

عندما تستلم هذه الأحداث، يتم تعيين أعضاء البنية على النحو التالي.

يتم تعيين عضو النوع (type) على ثابت اسم الحدث الذي يعرفه بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل بنية XGraphicsExposeEvent مع تعيين عضو النوع (type) إلى GraphicsExpose. يتم تعيين عضو العرض (display) إلى مؤشر إلى العرض الذي تمت قراءة الحدث منه. يتم تعيين عضو إرسال الحدث (send_event) إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو المسلسل (serial) من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من 16 بت الأقل أهمية إلى قيمة 32 بت كاملة. يتم تعيين عضو النافذة (window) إلى النافذة الأكثر فائدة لوحدات تحكم الأدوات.

يتم تعيين عضو النافذة (window) إلى النافذة التي تم إنشاء حدث FocusIn أو FocusOut عليها. هذه هي النافذة التي يستخدمها خادم X للإبلاغ عن الحدث. يتم تعيين عضو الوضع (mode) للإشارة إلى ما إذا كانت أحداث التركيز هي أحداث تركيز عادية، أو أحداث تركيز أثناء الالتقاط، أو أحداث تركيز عند تنشيط الالتقاط، أو أحداث تركيز عند إلغاء تنشيط الالتقاط. يمكن لخادم X تعيين عضو الوضع (mode) إلى NotifyNormal، NotifyWhileGrabbed، NotifyGrab، أو NotifyUngrab.

جميع أحداث FocusOut الناتجة عن إلغاء ربط نافذة يتم إنشاؤها بعد أي حدث UnmapNotify؛ ومع ذلك، فإن بروتوكول X لا يقيد ترتيب أحداث FocusOut فيما يتعلق بالأحداث التي تم إنشاؤها EnterNotify، LeaveNotify، VisibilityNotify، و Expose.

اعتمادًا على وضع الحدث، يتم تعيين عضو التفاصيل (detail) للإشارة إلى تفاصيل الإشعار ويمكن أن يكون NotifyAncestor، NotifyVirtual، NotifyInferior، NotifyNonlinear، NotifyNonlinearVirtual، NotifyPointer، NotifyPointerRoot، أو NotifyDetailNone.
