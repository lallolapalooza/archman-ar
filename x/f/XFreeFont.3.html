الوصف

تقوم الدالة XLoadFont بتحميل الخط المحدد وترجع معرف الخط المرتبط به. إذا لم يكن اسم الخط بتشفير الأحرف المحمول للمضيف (Host Portable Character Encoding)، فإن النتيجة تعتمد على التنفيذ. لا يهم استخدام الأحرف الكبيرة أو الصغيرة. عند استخدام الأحرف "؟" و "*" في اسم خط، يتم إجراء مطابقة نمط ويتم استخدام أي خط مطابق. في النمط، يطابق الحرف "؟" أي حرف فردي، ويطابق الحرف "*" أي عدد من الأحرف. يتم تحديد تنسيق منظم لأسماء الخطوط في معيار اتحاد X "اتفاقيات وصف الخطوط المنطقية لـ X" (X Logical Font Description Conventions). إذا فشلت XLoadFont في تحميل الخط المحدد، فستحدث خطأ BadName. لا ترتبط الخطوط بشاشة معينة ويمكن تخزينها كمكون لأي GC. عندما لا يكون الخط مطلوبًا بعد الآن، قم باستدعاء XUnloadFont.

يمكن لـ XLoadFont إنتاج أخطاء BadAlloc و BadName.

تقوم الدالة XQueryFont بإرجاع مؤشر إلى بنية XFontStruct، التي تحتوي على معلومات مرتبطة بالخط. يمكنك الاستعلام عن خط أو عن الخط المخزن في GC. سيكون معرف الخط المخزن في بنية XFontStruct هو معرف GContext، وتحتاج إلى توخي الحذر عند استخدام هذا المعرف في دوال أخرى (انظر XGContextFromGC). إذا كان الخط غير موجود، ترجع XQueryFont قيمة NULL. لتحرير هذه البيانات، استخدم XFreeFontInfo.

يمكن لـ XLoadQueryFont إنتاج خطأ BadAlloc.

توفر الدالة XLoadQueryFont الطريقة الأكثر شيوعًا للوصول إلى خط. تقوم XLoadQueryFont بفتح (تحميل) الخط المحدد وإرجاع مؤشر إلى بنية XFontStruct المناسبة. إذا لم يكن اسم الخط بتشفير الأحرف المحمول للمضيف، فإن النتيجة تعتمد على التنفيذ. إذا كان الخط غير موجود، ترجع XLoadQueryFont قيمة NULL.

تقوم الدالة XFreeFont بحذف الارتباط بين معرف مورد الخط والخط المحدد وتحرير بنية XFontStruct. سيتم تحرير الخط نفسه عندما لا تشير أي موارد أخرى إليه. يجب عدم الرجوع إلى البيانات والخط مرة أخرى.

يمكن لـ XFreeFont إنتاج خطأ BadFont.

بالنظر إلى الرمز (atom) لتلك الخاصية، ترجع الدالة XGetFontProperty قيمة خاصية الخط المحددة. ترجع XGetFontProperty أيضًا False إذا لم تكن الخاصية محددة أو True إذا كانت محددة. توجد مجموعة من الرموز المعرفة مسبقًا لخصائص الخطوط، والتي يمكن العثور عليها في X11/Xatom.h. تحتوي هذه المجموعة على الخصائص القياسية المرتبطة بخط. على الرغم من أنه ليس مضمونًا، فمن المحتمل أن تكون خصائص الخطوط المعرفة مسبقًا موجودة.

تقوم الدالة XUnloadFont بحذف الارتباط بين معرف مورد الخط والخط المحدد. سيتم تحرير الخط نفسه عندما لا تشير أي موارد أخرى إليه. يجب عدم الرجوع إلى الخط مرة أخرى.

يمكن لـ XUnloadFont إنتاج خطأ BadFont.

البُنى (STRUCTURES)

تحتوي بنية XFontStruct على جميع المعلومات الخاصة بالخط وتتكون من معلومات خاصة بالخط بالإضافة إلى مؤشر إلى مصفوفة من هياكل XCharStruct للأحرف الموجودة في الخط. تحتوي هياكل XFontStruct و XFontProp و XCharStruct على:

typedef struct {
	short lbearing;	/* origin to left edge of raster */
	short rbearing;	/* origin to right edge of raster */
	short width;	/* advance to next char's origin */
	short ascent;	/* baseline to top edge of raster */
	short descent;	/* baseline to bottom edge of raster */
	unsigned short attributes;	/* per char flags (not predefined) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* normal 16 bit characters are two bytes */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* hook for extension to hang data */
	Font fid;	/* Font id for this font */
	unsigned direction;	/* hint about the direction font is painted */
	unsigned min_char_or_byte2;	/* first character */
	unsigned max_char_or_byte2;	/* last character */
	unsigned min_byte1;	/* first row that exists */
	unsigned max_byte1;	/* last row that exists */
	Bool all_chars_exist;	/* flag if all characters have nonzero size */
	unsigned default_char;	/* char to print for undefined character */
	int n_properties;	/* how many properties there are */
	XFontProp *properties;	/* pointer to array of additional properties */
	XCharStruct min_bounds;	/* minimum bounds over all existing char */
	XCharStruct max_bounds;	/* maximum bounds over all existing char */
	XCharStruct *per_char;	/* first_char to last_char information */
	int ascent;	/* logical extent above baseline for spacing */
	int descent;	/* logical decent below baseline for spacing */
} XFontStruct;

يدعم X عمليات النصوص أحادية البايت/الحرف، وثنائية البايت/الحرف، وأحرف 16 بت. لاحظ أنه يمكن استخدام أي من هذه الأشكال مع خط، ولكن طلب النص أحادي البايت/الحرف يمكنه تحديد بايت واحد فقط (أي، الصف الأول من خط ثنائي البايت). يجب أن تنظر إلى الخطوط ثنائية البايت كمصفوفة ثنائية الأبعاد من الأحرف المعرفة: يحدد byte1 نطاق الصفوف المعرفة، ويحدد byte2 نطاق الأعمدة المعرفة للخط. تحتوي الخطوط أحادية البايت/الحرف على صف واحد معرف، ويحدد نطاق byte2 المحدد في البنية نطاقًا من الأحرف.

يتم تحديد الصندوق المحيط للحرف بواسطة XCharStruct لذلك الحرف. عندما تكون الأحرف غائبة من خط، يتم استخدام default_char. عندما تكون جميع الأحرف بنفس الحجم، يتم استخدام المعلومات الموجودة في حدود الحد الأدنى والأقصى لبنية XFontStruct فقط.

تتمتع أعضاء بنية XFontStruct بالدلالات التالية:

  • يمكن أن يكون العضو direction إما FontLeftToRight أو FontRightToLeft. إنه مجرد تلميح حول ما إذا كانت معظم عناصر XCharStruct لها مقياس عرض حرف موجب (FontLeftToRight) أو سالب (FontRightToLeft). لا يعرف بروتوكول النواة دعمًا للنص الرأسي.
  • إذا كان كلا العضوين min_byte1 و max_byte1 صفرين، يحدد min_char_or_byte2 الفهرس الخطي للحرف المقابل للعنصر الأول في مصفوفة per_char، ويحدد max_char_or_byte2 الفهرس الخطي للحرف للعنصر الأخير.
إذا كان أي من min_byte1 أو max_byte1 غير صفري، فإن كلا من min_char_or_byte2 و max_char_or_byte2 أقل من 256، وتكون قيم الفهرس ثنائية البايت للحرف المقابلة للعنصر N في مصفوفة per_char (بدءًا من 0):
byte1 = N/D + min_byte1
byte2 = N\D + min_char_or_byte2
حيث: 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = قسمة صحيحة
        \ = int

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

XFreeFont(3) — libX11

NAME

XFreeFont - free font structures

SYNTAX

#include <X11/Xlib.h>

int XFreeFont(Display *display, XFontStruct *font_struct_return);

ARGUMENTS

display
Specifies the connection to the X server.
font_struct_return

Specifies the memory that was allocated by XLoadFont(), XLoadQueryFont(), or XQueryFont() for the font structure.

DESCRIPTION

The function XFreeFont() frees the memory that was allocated for the specified font structure.

You must call XFreeFont() for each font structure that was allocated by XLoadQueryFont() or XQueryFont().

To free the font structure that was allocated by XLoadFont(), you must call XUnloadFont() for each font structure that was allocated by XLoadFont().

STRUCTURES

The XFontStruct structure contains information about the font. The members are:

int min_bounds
struct {
    short lbearing;
    short rbearing;
    short ascent;
    short descent;
    unsigned int width;
} min_bounds;
int max_bounds
struct {
    short lbearing;
    short rbearing;
    short ascent;
    short descent;
    unsigned int width;
} max_bounds;

Font identifier.
int default_char
Font structure for the default character.

Pointer to per-character information. If this is NULL, all glyphs have the same information.

Number of minimum left bearings.
int min_right_bearings
Number of minimum right bearings.
int font_ascent
Ascent of the font.
int font_descent
Descent of the font.
int max_overlap
Maximum font overlap.
int first_col
First column index.
int last_col
Last column index.
int min_bounds_of_char
Minimum bounds of character.

Maximum bounds of character.

Boolean indicating if all characters exist.

Draw direction.

Minimum draw x coordinate.

    int ascent;
    int descent;
    int linespace;

} font_metrics;
  • If the per_char pointer is NULL, all glyphs between the first and last character indexes inclusive have the same information, as given by both min_bounds and max_bounds.
  • If all_chars_exist is True, all characters in the per_char array have nonzero bounding boxes.
  • The default_char member specifies the character that will be used when an undefined or nonexistent character is printed. The default_char is a 16-bit character (not a 2-byte character). For a font using 2-byte matrix format, the default_char has byte1 in the most-significant byte and byte2 in the least significant byte. If the default_char itself specifies an undefined or nonexistent character, no printing is performed for an undefined or nonexistent character.
  • The min_bounds and max_bounds members contain the most extreme values of each individual XCharStruct component over all elements of this array (and ignore nonexistent characters). The bounding box of the font (the smallest rectangle enclosing the shape obtained by superimposing all of the characters at the same origin [x,y]) has its upper-left coordinate at: 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
Its width is: 
max_bounds.rbearing - min_bounds.lbearing
Its height is: 
max_bounds.ascent + max_bounds.descent
  • The ascent member is the logical extent of the font above the baseline that is used for determining line spacing. Specific characters may extend beyond this.
  • The descent member is the logical extent of the font at or below the baseline that is used for determining line spacing. Specific characters may extend beyond this.
  • If the baseline is at Y-coordinate y, the logical extent of the font is inclusive between the Y-coordinate values (y - font.ascent) and (y + font.descent - 1). Typically, the minimum interline spacing between rows of text is given by ascent + descent.

For a character origin at [x,y], the bounding box of a character (that is, the smallest rectangle that encloses the character's shape) described in terms of XCharStruct components is a rectangle with its upper-left corner at:

[x + lbearing, y - ascent]

Its width is:

rbearing - lbearing

Its height is:

ascent + descent

The origin for the next character is defined to be:

[x + width, y]

The lbearing member defines the extent of the left edge of the character ink from the origin. The rbearing member defines the extent of the right edge of the character ink from the origin. The ascent member defines the extent of the top edge of the character ink from the origin. The descent member defines the extent of the bottom edge of the character ink from the origin. The width member defines the logical width of the character.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadFont
A value for a Font or GContext argument does not name a defined Font.
BadName
A font or color of the specified name does not exist.

XFreeFont - تحرير هياكل الخطوط

الصيغة

#include <X11/Xlib.h>

int XFreeFont(Display *display, XFontStruct *font_struct_return);

المعاملات

display
يحدد الاتصال بخادم X.
font_struct_return

يحدد الذاكرة التي تم تخصيصها بواسطة XLoadFont() أو XLoadQueryFont() أو XQueryFont() لهيكل الخط.

الوصف

تقوم الدالة XFreeFont() بتحرير الذاكرة التي تم تخصيصها لهيكل الخط المحدد.

يجب عليك استدعاء XFreeFont() لكل هيكل خط تم تخصيصه بواسطة XLoadQueryFont() أو XQueryFont().

لتحرير هيكل الخط الذي تم تخصيصه بواسطة XLoadFont()، يجب عليك استدعاء XUnloadFont() لكل هيكل خط تم تخصيصه بواسطة XLoadFont().

الهياكل

  • إذا كان المؤشر per_char هو NULL، فإن جميع الأشكال بين فهارس الحرف الأول والأخير شاملة لها نفس المعلومات، كما هو محدد بواسطة كل من min_bounds و max_bounds.
  • إذا كان all_chars_exist هو True، فإن جميع الأحرف في مصفوفة per_char لها مربعات حدود غير صفرية.
  • يحدد العضو default_char الحرف الذي سيتم استخدامه عند طباعة حرف غير معرف أو غير موجود. default_char هو حرف 16 بت (وليس حرفًا من حرفين). بالنسبة لخط يستخدم تنسيق مصفوفة من حرفين، يحتوي default_char على البايت الأول في البايت الأكثر أهمية والبايت الثاني في البايت الأقل أهمية. إذا حدد default_char نفسه حرفًا غير معرف أو غير موجود، فلن يتم إجراء أي طباعة لحرف غير معرف أو غير موجود.
  • تحتوي الأعضاء min_bounds و max_bounds على القيم القصوى لكل مكون فردي من مكونات XCharStruct عبر جميع عناصر هذه المصفوفة (وتتجاهل الأحرف غير الموجودة). مربع حدود الخط (أصغر مستطيل يحيط بالشكل الناتج عن تراكب جميع الأحرف عند نفس الأصل [x,y]) له إحداثي زاويته العلوية اليسرى عند: 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
عرضه هو: 
max_bounds.rbearing - min_bounds.lbearing
ارتفاعه هو: 
max_bounds.ascent + max_bounds.descent
  • العضو ascent هو الامتداد المنطقي للخط فوق خط الأساس المستخدم لتحديد تباعد الأسطر. قد تمتد الأحرف المحددة إلى ما وراء هذا.
  • العضو descent هو الامتداد المنطقي للخط عند خط الأساس أو تحته المستخدم لتحديد تباعد الأسطر. قد تمتد الأحرف المحددة إلى ما وراء هذا.
  • إذا كان خط الأساس عند الإحداثي y، فإن الامتداد المنطقي للخط يكون شاملاً بين قيم الإحداثي y (y - font.ascent) و (y + font.descent - 1). عادةً، يتم تحديد الحد الأدنى لتباعد الأسطر بين صفوف النص بواسطة ascent + descent.

بالنسبة لأصل حرف عند [x,y]، فإن مربع حدود الحرف (أي، أصغر مستطيل يحيط بشكل الحرف) الموصوف من حيث مكونات XCharStruct هو مستطيل زاويته العلوية اليسرى عند:

[x + lbearing, y - ascent]

عرضه هو:

rbearing - lbearing

ارتفاعه هو:

ascent + descent

يتم تعريف أصل الحرف التالي ليكون:

[x + width, y]

يحدد العضو lbearing امتداد الحافة اليسرى لحبر الحرف من الأصل. يحدد العضو rbearing امتداد الحافة اليمنى لحبر الحرف من الأصل. يحدد العضو ascent امتداد الحافة العلوية لحبر الحرف من الأصل. يحدد العضو descent امتداد الحافة السفلية لحبر الحرف من الأصل. يحدد العضو width العرض المنطقي للحرف.
