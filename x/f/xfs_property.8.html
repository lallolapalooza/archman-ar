xfs_property(8) دليل مدير النظام xfs_property(8)

اسم

xfs_property - فحص وتحرير الخصائص حول نظام ملفات XFS

ملخص

xfs_property target get name...
xfs_property target list [ -v ]
xfs_property target set name=value...
xfs_property target remove name...
xfs_property -V

الوصف

xfs_property تسترجع، تسرد، تعين، أو تزيل خصائص نظام ملفات XFS. خصائص نظام الملفات هي سمات يتحكم بها الجذر (root) يتم تعيينها على الدليل الجذر لنظام الملفات لتمكين مسؤول النظام من التنسيق مع برامج مساحات المستخدم (userspace programs).

target هو أحد الخيارات التالية: الدليل الجذر لنظام ملفات مثبت؛ جهاز كتلي (block device) يحتوي على نظام ملفات XFS؛ أو ملف عادي يحتوي على نظام ملفات XFS.

خيارات

-V
طباعة رقم الإصدار والخروج.

أوامر

get
name... طباعة قيم خصائص نظام الملفات المعطاة.
list
يسرد أسماء جميع خصائص نظام الملفات. إذا تم تحديد الخيار -v، فإنه يطبع القيم أيضًا.
set
name=value... تعيين خصائص نظام الملفات المعطاة إلى القيم المحددة وطباعة ما تم تعيينه.
remove
name... إلغاء تعيين خصائص نظام الملفات المعطاة.

خصائص نظام الملفات

الخصائص المعروفة لنظام ملفات XFS هي:

autofsck انظر xfs_scrub(8) لمزيد من المعلومات.
