XftDrawDisplay(3)

الحزمة: libxft

التراخيص: HPND-sell-variant

Xft(3) إصدار X 11 Xft(3)

الاسم

Xft - مكتبة واجهة X FreeType

الملخص

#include <X11/Xft/Xft.h>

الوصف

Xft هي مكتبة بسيطة ترسم النصوص والرسومات:

  • باستخدام المعلومات التي تقدمها مكتبة Fontconfig،
  • تقوم Xft بتحويل صور الخطوط باستخدام مُحسِّن FreeType، و
  • تعرض بيانات الخط المحولة باستخدام امتداد X Rendering Extension.

هذه الصفحة الدليلية تكاد لا تلامس سطح هذه المكتبة.

الثوابت

XFT_MAJOR
هو رقم الإصدار الرئيسي لـ Xft.
XFT_MINOR
هو رقم الإصدار الثانوي لـ Xft.
XFT_REVISION
هو رقم المراجعة لـ Xft.
XFT_VERSION
هو XFT_MAJOR مضروبًا في 10000 (عشرة آلاف)، زائد XFT_MINOR مضروبًا في 100، زائد XFT_REVISION.
XftVersion
هو اسم مستعار لـ XFT_VERSION.

يوضح المثال التالي كيف يمكن استخدام ثوابت إصدار Xft: 

    #if (XFT_VERSION >= 20107)
    (void) puts("إصدار 2.1.7 أو أحدث من مكتبة Xft قيد الاستخدام.");
    #else
    (void) printf("إصدار غير كافٍ من Xft (%d.%d.%d) مثبت؛
                  " تحتاج على الأقل إلى الإصدار 2.1.7.\n", XFT_MAJOR,
                  XFT_MINOR,
                  XFT_REVISION);
    #endif

أنواع البيانات

تتبع أنواع بيانات Xft اصطلاح تسمية، مع إضافة البادئة "Xft" لجميع الأسماء

من Xlib...

لا تتبع أنواع بيانات Xlib اصطلاح تسمية. يتم توثيقها في Xlib - واجهة لغة C.

تستخدم Xft هذه الأسماء: Bool, Colormap, Display, Drawable, Pixmap, Region, Visual, و XRectangle.

بعض أنواع البيانات ذات صلة خاصة بـ Xft:

Drawable
معرف X للمورد، مثل نافذة مرتبطة بالعرض. يمكن استخدام كل من النوافذ و pixmaps كمصادر ووجهات في عمليات الرسومات. تُعرف هذه النوافذ و pixmaps بشكل جماعي باسم drawables. ومع ذلك، لا يمكن استخدام نافذة InputOnly كمصدر أو وجهة في عملية رسومات.
Region
مجموعة اعتباطية من مواقع البكسل التي يمكن لـ Xlib التعامل معها. داخليًا، يتم تمثيل Region باتحاد عدد اعتباطي من المستطيلات. تحتفظ Xlib بمستطيل يوضح لها نطاق هذا الاتحاد.
Visual
يحتوي هذا الهيكل على معلومات حول تعيين الألوان الممكنة.

من XRender...

تستلهم أنواع بيانات مكتبة X Render Extension من Xlib، ولكنها تفتقر إلى الوثائق المقابلة. ارجع إلى ملف الرأس للحصول على التفاصيل:

<X11/extensions/Xrender.h>

أو اقرأ الكود المصدري (الذي يوفر مخططًا عامًا لـ libXrender).

تستخدم Xft هذه الأسماء: Picture, XGlyphInfo, XRenderColor.

من Fontconfig...

تتبع أنواع بيانات Fontconfig اصطلاح تسمية، مع إضافة البادئة "Fc" لجميع الأسماء، والتي يتم توثيقها في مرجع مطوري Fontconfig.

تستخدم Xft هذه الأسماء من Fontconfig: FcBool, FcChar8, FcChar16, FcChar32, FcCharSet, FcEndian, FcFontSet, FcPattern, و FcResult.

من FreeType 2...

تتبع أنواع بيانات FreeType 2 اصطلاح تسمية، مع إضافة البادئة "FT_" لجميع الأسماء، والتي يتم توثيقها في مرجع واجهة برمجة تطبيقات FreeType.

تستخدم Xft هذه الأسماء: FT_Face, FT_Library, و FT_UInt.

تستخدم FreeType 2 FT_UInt (عدد صحيح غير موقع) لتمثيل الصور.

XftFont


typedef struct _XftFont {
	int	 ascent;
	int	 descent;
	int	 height;
	int	 max_advance_width;
	FcCharSet	*charset;
	FcPattern	*pattern;
} XftFont;

XftFont هو هيكل البيانات الأساسي الذي يهم المبرمجين الذين يستخدمون Xft؛ فهو يحتوي على مقاييس الخط العامة ومؤشرات إلى مجموعة أحرف Fontconfig والنمط المرتبط بالخط.

يتم ملء XftFonts باستخدام أي من XftFontOpen(), XftFontOpenName(), XftFontOpenXlfd(), XftFontOpenInfo(), أو XftFontOpenPattern(). يتم استخدام XftFontCopy() لمضاعفة XftFonts، ويتم استخدام XftFontClose() لوضع علامة على XftFont بأنه غير مستخدم. يتم تخصيص XftFonts داخليًا، ويتم حساب المراجع، وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

تستخدم XftDrawGlyphs(), عائلة XftDrawString*(), XftDrawCharSpec(), و XftDrawGlyphSpec() XftFonts لرسم النصوص إلى كائن XftDraw، والذي قد يتوافق مع كل من رسم X الأساسي أو رسم امتداد X Rendering Extension.

تُستخدم XftGlyphExtents() وعائلة XftTextExtents*() لتحديد نطاقات (الأبعاد القصوى) لـ XftFont.

يمكن تحديد تغطية الصور أو الأحرف لـ XftFont باستخدام XftFontCheckGlyph() أو XftCharExists(). تُرجع XftCharIndex() فهرس الحرف الخاص بـ XftFont المقابل لنقطة ترميز Unicode معطاة.

تستخدم XftGlyphRender(), XftGlyphSpecRender(), XftCharSpecRender(), وعائلة XftTextRender*() XftFonts للرسم في هياكل Picture الخاصة بامتداد X Rendering Extension.

ملاحظة: توفر XftDrawGlyphs(), عائلة XftDrawString*(), XftDrawCharSpec(), و XftDrawGlyphSpec() وسيلة لرسم الخطوط مستقلة عن توفر امتداد X Rendering Extension على خادم X.

XftFontInfo

هو كائن غير شفاف يخزن معلومات حول خط. يتم إنشاء هياكل XftFontInfo باستخدام XftFontInfoCreate()، وتحريرها باستخدام XftFontInfoDestroy()، ومقارنتها باستخدام XftFontInfoEqual(). يتم تخصيص كائنات XftFontInfo داخليًا وتحريرها بواسطة Xft؛ لا يحتاج المبرمج عادةً إلى تخصيص أو تحرير مساحة لها.

كل هيكل XftFontInfo قيد الاستخدام مرتبط بمعرف فريد، والذي يمكن استرجاعه باستخدام XftFontInfoHash(). يمكن فتح XftFont بناءً على بيانات XftFontInfo باستخدام XftFontOpenInfo().

XftColor


typedef struct _XftColor {
	unsigned long	 pixel;
	XRenderColor	 color;
} XftColor;

يسمح كائن XftColor برسم النصوص وعناصر أخرى بلون معين (أو أقرب تقريب تقدمه واجهة X المستخدمة).

تطلب XftColorAllocName() و XftColorAllocValue() تخصيص لون من خادم X (إذا لزم الأمر) وتهيئ أعضاء XftColor. تطلب XftColorFree() من خادم X تحرير اللون المخصص حاليًا لـ XftColor.

بمجرد تهيئة XftColor، يمكن استخدام XftDrawSrcPicture(), XftDrawGlyphs(), عائلة XftDrawString*(), XftDrawCharSpec(), XftDrawCharFontSpec(), XftDrawGlyphSpec(), XftDrawGlyphFontSpec(), و XftDrawRect() لرسم كائنات مختلفة باستخدامها.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

XftFontList

SYNOPSIS

#include <X11/Xft/Xft.h>

DESCRIPTION

The Xft library provides a bridge between the X server and the FreeType library. It allows applications to render fonts using FreeType with the X Render Extension.

Font matching and opening

XftFont *XftFontOpen (
	Display *dpy,
	FcPattern *pat);

Opens a font matching the specified pat. Returns a pointer to a XftFont structure representing the font, or NULL on failure. The pat is copied, so it can be freed after this call.

XftFont *XftFontOpenName (
	Display *dpy,
	_Xconst char *name);

Opens a font matching the specified font name name. This is a convenience function that calls XftNameParse() to create a pattern, then calls XftFontOpen().

XftFont *XftFontOpenPAM (
	Display *dpy,
	FcPattern *pat);

Opens a font matching the specified pat using the Xft default font pattern. This is intended for use with the X Render extension.

XftFont *XftFontMatch (
	Display *dpy,
	int	 screen,
	FcPattern *pat,
	FcResult *result);

Matches a font pattern against the available fonts on the specified screen. Returns a pointer to a XftFont structure representing the best match, or NULL on failure. The result parameter is set to indicate success or the reason for failure.

void XftFontClose (
	XftFont *font);

Closes the specified font, freeing any resources associated with it.

Font listing

XftFontList *XftFontList (
	Display *dpy,
	int	 screen);

Returns a list of all available fonts on the specified screen. The list is returned as an XftFontList structure, which contains an array of XftFont pointers. The list should be freed using XftFontListFree().

Character encoding and glyph mapping

FcChar32 XftCharIndex (
	Display *dpy,
	XftFont *font,
	FcChar32 uchars);

Returns the glyph index for the specified Unicode character uchars in the given font. Returns 0 if the character is not supported by the font.

FcBool XftCharFits (
	XftFont *font,
	FcChar32 uchars);

Returns FcTrue if the specified Unicode character uchars is supported by the given font, and FcFalse otherwise.

XftGlyphFontSpec *XftGlyphFontSpec (
	Display *dpy,
	XftFont *font,
	FcChar32 *uchars,
	int	 nchars);

Returns an array of XftGlyphFontSpec structures, one for each character in uchars. Each structure contains the glyph index and font to be used for rendering the corresponding character.

void XftGlyphFontSpecFree (
	XftGlyphFontSpec *glyphs);

Frees the memory allocated by XftGlyphFontSpec().

void XftGlyphExtents (
	XftFont *font,
	XftGlyphSpec *glyphs,
	int	 nglyphs,
	XftXRectangle *extents);

Calculates the bounding box of the specified glyphs in the given font.

Pattern matching and font names

FcPattern *XftPatternCreate (
	void);

Creates an empty font pattern.

FcPattern *XftPatternDuplicate (
	FcPattern *pat);

Duplicates the given font pattern.

void XftPatternDestroy (
	FcPattern *pat);

Destroys the given font pattern.

FcBool XftPatternCopy (
	FcPattern *dst,
	FcPattern *src);

Copies the contents of src pattern to dst pattern.

FcBool XftPatternEqual (
	FcPattern *p1,
	FcPattern *p2);

Compares two font patterns for equality.

FcBool XftPatternAdd (
	FcPattern *pat,
	_Xconst char *name,
	FcValue	 value);

Adds a value to the pattern. The type of the value is determined by the type of the value union member used.

FcBool XftPatternAddNameList (
	FcPattern *pat,
	_Xconst char *name,
	FcValue	 value);

Adds a list of names to the pattern.

FcBool XftPatternAddInteger (
	FcPattern *pat,
	_Xconst char *name,
	int	 i);

Adds an integer value to the pattern.

FcBool XftPatternAddDouble (
	FcPattern *pat,
	_Xconst char *name,
	double	 d);

Adds a double value to the pattern.

FcBool XftPatternAddBool (
	FcPattern *pat,
	_Xconst char *name,
	FcBool	 b);

Adds a boolean value to the pattern.

FcBool XftPatternAddString (
	FcPattern *pat,
	_Xconst char *name,
	_Xconst char *s);

Adds a string value to the pattern.

FcBool XftPatternAddMatrix (
	FcPattern *pat,
	_Xconst char *name,
	FcMatrix *m);

Adds a matrix value to the pattern.

FcBool XftPatternAddOpaque (
	FcPattern *pat,
	_Xconst char *name,
	pointer	 p);

Adds an opaque pointer to the pattern.

FcBool XftPatternGet (
	FcPattern *pat,
	_Xconst char *name,
	int	 n,
	FcValue	*value);

Gets the value of the specified property from the pattern.

void XftPatternDel (
	FcPattern *pat,
	_Xconst char *name);

Deletes the specified property from the pattern.

FcPattern *XftNameParse (
	_Xconst char *name);

Parses a font name string and returns a font pattern. Xft uses Fontconfig to parse the name, passing the name to FcNameParse(), returning the result.

FcBool XftNameUnparse (
	FcPattern *pat,
	char	*dest,
	int	 len);

Like XfgNameParse(), Xft uses Fontconfig. In this case, it uses FcNameUnparse(), which converts the pattern pat back into a string that can be parsed. XftNameUnparse() stores the result via the caller's pointer dest, but checks first if it will fit, using the len parameter. If it fits, Xft copies the string and returns FcTrue, otherwise it returns FcFalse.

Manipulating Font data

void XftFontLoadGlyphs (
	Display	*dpy,
	XftFont	*pub,
	FcBool	 need_bitmaps,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);

Using FT_Load_Glyph(), load nglyphs for the glyph indices (Unicode values) listed in the array glyphs from the given font pub.

Loading a glyph entails more than just reading data into memory. Xft uses the Fontconfig pattern associated with the display dpy (e.g., via XftDefaultSet()) to determine whether to use a bounding box, clip the glyphs into those bounds, scale the glyphs, compute font metrics, and add it to the X Render extension using XRenderAddGlyphs().
void XftFontUnloadGlyphs (
	Display	*dpy,
	XftFont	*pub,
	_Xconst FT_UInt	*glyphs,
	int	 nglyph);

Discards data for up to nglyph glyphs whose glyph indices (Unicode values) are listed in the array glyphs for the given font pub. If the glyphs were added to the X Render extension, Xft removes those using XRenderFreeGlyphs(). Xft keeps track of the amount of memory used for glyphs, and updates the usage associated with the display dpy.

FT_Face XftLockFace (
	XftFont	*pub);

If no FreeType 2 “face” (in-memory representation of a given typeface in a given style) has been created for the pub font, create one using FT_New_Face(). Face-locks are a reference count used by Xft to ensure that only one face is created, and that it is retained until the font is no longer used.

Face-locking is used directly in XftCharIndex() and XftFontLoadGlyphs(), which in turn are used in many functions of Xft.
Face-locking was introduced in version 1 (October 2002). A few applications, such as Gdk/Gimp relied upon these functions. In version 2.1.9 (June 2006), face-locking was retained as part of the public API when improved shared-library configurations provided for hiding private symbols.
void XftUnlockFace (
	XftFont	*pub);

Decrements the reference count for the FreeType 2 “face” associated with the font.

FT_Face objects are deallocated using FT_Done_Face(). Xft does this in XftFontInfoDestroy() and when cleaning up on failure in XftFontInfoCreate() and XftFontOpenPattern().

DEBUGGING

Xft reads the environment variable XFT_DEBUG and converts that to an integer. Each bit in the resulting value tells Xft to print debugging information to the standard output:

1
font-opening
2
additional font-matching and opening (verbose)
4
shows details about the XRenderPictFormat which will be used.
8
shows the string which XftDrawString8() will draw.
16
shows which font-ids are matched.
32
shows useful information about the glyphs which will be drawn
64
shows an ASCII-art representation of the glyphs.
128
shows details about the memory-cache management
256
shows details about managing glyph cached-memory
512
shows a report on memory-usage
1024
shows details on extended management of glyph cached-memory

COMPATIBILITY

As of version 2 (May 2002), Xft became relatively stable. It is expected to retain source and binary compatibility in future releases.

Xft provides a compatibility interface to its previous major version, Xft 1.x, described below.

Xft 1.x Header File

#include <X11/Xft/XftCompat.h>

Xft 1.x Data Types

XftPattern
holds a set of names with associated value lists; each name refers to a property of a font. XftPatterns are used as inputs to the matching code as well as holding information about specific fonts.
XftFontSet
contains a list of XftPatterns. Internally, Xft uses this data structure to hold sets of fonts. Externally, Xft returns the results of listing fonts in this format.
XftObjectSet
holds a set of names and is used to specify which fields from fonts are placed in the list of returned patterns when listing fonts.
