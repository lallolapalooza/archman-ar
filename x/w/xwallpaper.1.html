التراخيص: ISC

NAME

xwallpaper — Sets the wallpaper for an X Window System session.

SYNOPSIS

xwallpaper [OPTIONS] <image-file>

DESCRIPTION

The xwallpaper utility is used to set the wallpaper for an X Window System session. It supports various image formats and allows for different scaling and tiling options.

OPTIONS

--scale
Scales the image to fit the screen without distortion.
--tile
Tiles the image across the screen.
--center
Centers the image on the screen.
--fill
Fills the screen with the image, preserving aspect ratio and potentially cropping.
--gtk-root
Uses the GTK root window for setting the wallpaper (if available).
--display <display>
Specifies the X display to use.
-h, --help
Displays a help message and exits.
-v, --version
Displays version information and exits.

EXAMPLES

Set an image as wallpaper, scaled to fit the screen:

xwallpaper --scale /path/to/your/image.jpg

Tile an image across the screen:

xwallpaper --tile /path/to/your/pattern.png
