XWindowAttributes(3)

الحزمة: libx11

التراخيص: MIT AND X11

XGetWindowAttributes(3) وظائف XLIB XGetWindowAttributes(3)

الاسم

XGetWindowAttributes, XGetGeometry, XWindowAttributes - الحصول على سمات النافذة الحالية أو الهندسة وهيكل سمات النافذة الحالي

الصيغة

Status XGetWindowAttributes(Display *display, Window w, XWindowAttributes *window_attributes_return);

Status XGetGeometry(Display *display, Drawable d, Window *root_return, int *x_return, int *y_return, unsigned int *width_return, unsigned int *height_return, unsigned int *border_width_return, unsigned int *depth_return);

الوسائط

border_width_return
يعيد عرض الحدود بالبكسل.
d
يحدد الكائن القابل للرسم، والذي يمكن أن يكون نافذة أو صورة نقطية (pixmap).
depth_return
يعيد عمق الكائن القابل للرسم (بايتات لكل بكسل للكائن).
display
يحدد الاتصال بخادم X.
root_return
يعيد النافذة الجذر.
w
يحدد النافذة التي تريد الحصول على سماتها الحالية.
width_return

height_return
يعيد أبعاد الكائن القابل للرسم (العرض والارتفاع).
window_attributes_return
يعيد سمات النافذة المحددة في هيكل XWindowAttributes.
x_return

y_return
يعيد إحداثيات x و y التي تحدد موقع الكائن القابل للرسم. بالنسبة للنافذة، تحدد هذه الإحداثيات الزاوية الخارجية العلوية اليسرى بالنسبة لأصل النافذة الأم. بالنسبة للصور النقطية، تكون هذه الإحداثيات دائمًا صفرًا.

الوصف

تقوم الدالة XGetWindowAttributes بإعادة السمات الحالية للنافذة المحددة إلى هيكل XWindowAttributes. وتعيد قيمة غير صفرية عند النجاح؛ وإلا، تعيد قيمة صفرية.

يمكن لـ XGetWindowAttributes إنشاء أخطاء BadDrawable و BadWindow.

تقوم الدالة XGetGeometry بإعادة النافذة الجذر والهندسة الحالية للكائن القابل للرسم. تتضمن هندسة الكائن القابل للرسم إحداثيات x و y، العرض والارتفاع، عرض الحدود، والعمق. يتم وصفها في قائمة الوسائط. من القانوني تمرير نافذة فئتها InputOnly إلى هذه الدالة. وتعيد قيمة غير صفرية عند النجاح؛ وإلا، تعيد قيمة صفرية.

الهياكل

يحتوي هيكل XWindowAttributes على:

typedef struct {
        int x, y;       /* موقع النافذة */
        int width, height;      /* عرض وارتفاع النافذة */
        int border_width;       /* عرض حدود النافذة */
        int depth;      /* عمق النافذة */
        Visual *visual; /* هيكل المرئيات المرتبط */
        Window root;    /* جذر الشاشة التي تحتوي على النافذة */
        int class;      /* InputOutput, InputOnly*/
        int bit_gravity;        /* أحد قيم جاذبية البت */
        int win_gravity;        /* أحد قيم جاذبية النافذة */
        int backing_store;      /* NotUseful, WhenMapped, Always */
        unsigned long backing_planes;   /* مستويات يجب الحفاظ عليها إن أمكن */
        unsigned long backing_pixel;    /* القيمة المستخدمة عند استعادة المستويات */
        Bool save_under;        /* منطقي، هل يجب حفظ البتات الموجودة أسفل؟ */
        Colormap colormap;      /* خريطة الألوان التي يجب ربطها بالنافذة */
        Bool map_installed;     /* منطقي، هل خريطة الألوان مثبتة حاليًا*/
        int map_state;  /* IsUnmapped, IsUnviewable, IsViewable */
        long all_event_masks;   /* مجموعة الأقنعة التي تهتم بها جميع الجهات */
        long your_event_mask;   /* قناع الحدث الخاص بي */
        long do_not_propagate_mask;     /* مجموعة الأحداث التي لا يجب أن تنتشر */
        Bool override_redirect; /* قيمة منطقية لـ override-redirect */
        Screen *screen; /* مؤشر خلفي للشاشة الصحيحة */
} XWindowAttributes;

يتم تعيين أعضاء x و y إلى الزاوية الخارجية العلوية اليسرى بالنسبة لأصل النافذة الأم. يتم تعيين أعضاء العرض والارتفاع إلى الحجم الداخلي للنافذة، باستثناء الحدود. يتم تعيين عضو border_width إلى عرض حدود النافذة بالبكسل. يتم تعيين عضو depth إلى عمق النافذة (أي، بتات لكل بكسل للكائن). العضو visual هو مؤشر إلى هيكل Visual الخاص بالشاشة. يتم تعيين العضو root إلى النافذة الجذر للشاشة التي تحتوي على النافذة. يتم تعيين العضو class إلى فئة النافذة ويمكن أن يكون إما InputOutput أو InputOnly.

يتم تعيين عضو bit_gravity إلى جاذبية البت للنافذة ويمكن أن يكون أحد القيم التالية:

ForgetGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

يتم تعيين عضو win_gravity إلى جاذبية النافذة ويمكن أن يكون أحد القيم التالية:

UnmapGravity EastGravity
NorthWestGravity SouthWestGravity
NorthGravity SouthGravity
NorthEastGravity SouthEastGravity
WestGravity StaticGravity
CenterGravity

لمزيد من المعلومات حول الجاذبية، راجع القسم 3.3.

يتم تعيين عضو backing_store للإشارة إلى كيفية قيام خادم X بالحفاظ على محتويات النافذة ويمكن أن يكون WhenMapped أو Always أو NotUseful. يتم تعيين عضو backing_planes للإشارة (مع بتات مضبوطة على 1) إلى مستويات البت التي تحمل بيانات ديناميكية يجب الحفاظ عليها في backing_stores وأثناء save_unders. يتم تعيين عضو backing_pixel للإشارة إلى القيم التي يجب استخدامها للمستويات غير المضبوطة في backing_planes.

يتم تعيين عضو save_under إلى True أو False. يتم تعيين عضو colormap إلى خريطة الألوان للنافذة المحددة ويمكن أن يكون معرف خريطة الألوان أو None. يتم تعيين عضو map_installed للإشارة إلى ما إذا كانت خريطة الألوان مثبتة حاليًا ويمكن أن تكون True أو False. يتم تعيين عضو map_state للإشارة إلى حالة النافذة ويمكن أن يكون IsUnmapped أو IsUnviewable أو IsViewable. يتم استخدام IsUnviewable إذا كانت النافذة مرئية ولكن أحد الأسلاف غير مرئي.

يتم تعيين عضو all_event_masks إلى OR الشامل ثنائي البت لجميع أقنعة الأحداث المحددة على النافذة من قبل جميع العملاء. يتم تعيين عضو your_event_mask إلى OR الشامل ثنائي البت لجميع أقنعة الأحداث المحددة من قبل العميل الذي يقوم بالاستعلام. يتم تعيين عضو do_not_propagate_mask إلى OR الشامل ثنائي البت لمجموعة الأحداث التي لا يجب أن تنتشر.

يتم تعيين عضو override_redirect للإشارة إلى ما إذا كانت هذه النافذة تتجاوز مرافق التحكم في الهيكل ويمكن أن تكون True أو False. يجب على عملاء مدير النوافذ تجاهل النافذة إذا كان هذا العضو True.

يتم تعيين عضو screen إلى مؤشر شاشة يمنحك مؤشرًا خلفيًا للشاشة الصحيحة. هذا يسهل الحصول على معلومات الشاشة دون الحاجة إلى التكرار فوق حقول النافذة الجذر لرؤية الحقل الذي يتطابق.

التشخيصات

BadDrawable
قيمة وسيطة Drawable لا تسمي نافذة أو صورة نقطية معرفة.
BadWindow
قيمة وسيطة Window لا تسمي نافذة معرفة.
