XWindowChanges(3)

الحزمة: libx11

التراخيص: MIT AND X11

XConfigureWindow(3) دوال XLIB XConfigureWindow(3)

الاسم

XConfigureWindow, XMoveWindow, XResizeWindow, XMoveResizeWindow, XSetWindowBorderWidth, XWindowChanges - تهيئة النوافذ وهيكل تغييرات النافذة

الصيغة

int XConfigureWindow(Display *display, Window w, unsigned value_mask, XWindowChanges *changes);

int XMoveWindow(Display *display, Window w, int x, y);

int XResizeWindow(Display *display, Window w, unsigned width, unsigned height);

int XMoveResizeWindow(Display *display, Window w, int x, int y, unsigned width, unsigned height);

int XSetWindowBorderWidth(Display *display, Window w, unsigned width);

المعاملات

display
يحدد الاتصال بخادم X.
value_mask
يحدد القيم التي سيتم تعيينها باستخدام المعلومات الموجودة في هيكل القيم. هذا القناع هو OR الشامل ثنائي البت لقيم بتات النافذة القابلة للتهيئة.
values
يحدد هيكل XWindowChanges.
w
يحدد النافذة التي سيتم إعادة تهيئتها أو نقلها أو تغيير حجمها.
width
يحدد عرض حد النافذة.
width

height
حدد العرض والارتفاع، وهما الأبعاد الداخلية للنافذة.
x

y
حدد إحداثيات x و y، والتي تحدد الموقع الجديد للبكسل العلوي الأيسر لحد النافذة أو النافذة نفسها إذا لم يكن لها حدود أو تحدد الموضع الجديد للنافذة بالنسبة للأصل.

الوصف

تستخدم الدالة XConfigureWindow القيم المحددة في هيكل XWindowChanges لإعادة تهيئة حجم النافذة وموضعها وحدها وترتيب تكديسها. القيم غير المحددة تؤخذ من الهندسة الحالية للنافذة.

إذا تم تحديد نافذة شقيقة بدون وضع تكديس أو إذا لم تكن النافذة شقيقة فعليًا، فسيؤدي ذلك إلى حدوث خطأ BadMatch. لاحظ أن الحسابات الخاصة بـ BottomIf و TopIf و Opposite تتم بالنسبة لهندسة النافذة النهائية (كما يتم التحكم فيها بواسطة الحجج الأخرى التي تم تمريرها إلى XConfigureWindow)، وليس هندستها الأولية. سيتم التخلص من أي محتويات مخزنة للنافذة، أو العناصر التابعة لها، والنوافذ الجديدة المرئية، أو تغييرها لتعكس محتويات الشاشة الحالية (اعتمادًا على التنفيذ).

يمكن لـ XConfigureWindow توليد أخطاء BadMatch و BadValue و BadWindow.

الدالة XMoveWindow تنقل النافذة المحددة إلى إحداثيات x و y المحددة، ولكنها لا تغير حجم النافذة، أو ترفع النافذة، أو تغير حالة تعيين النافذة. نقل نافذة معينة قد يؤدي إلى فقدان محتويات النافذة اعتمادًا على ما إذا كانت النافذة محجوبة بواسطة نوافذ غير تابعة لها وما إذا كانت لا توجد مساحة تخزين احتياطية. إذا تم فقدان محتويات النافذة، فإن خادم X يولد أحداث Expose. نقل نافذة معينة يولد أحداث Expose على أي نوافذ محجوبة سابقًا.

إذا كان علم تجاوز إعادة التوجيه للنافذة هو False وكان هناك عميل آخر قد حدد SubstructureRedirectMask على الأصل، فإن خادم X يولد حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. بخلاف ذلك، يتم نقل النافذة.

يمكن لـ XMoveWindow توليد خطأ BadWindow.

الدالة XResizeWindow تغير الأبعاد الداخلية للنافذة المحددة، ولا تشمل حدودها. هذه الدالة لا تغير الإحداثي العلوي الأيسر للنافذة أو الأصل ولا تعيد ترتيب النافذة. تغيير حجم النافذة المعينة قد يؤدي إلى فقدان محتوياتها وتوليد أحداث Expose. إذا تم تصغير نافذة معينة، فإن تغيير حجمها يولد أحداث Expose على النوافذ التي كانت النافذة المعينة تحجبها سابقًا.

إذا كان علم تجاوز إعادة التوجيه للنافذة هو False وكان هناك عميل آخر قد حدد SubstructureRedirectMask على الأصل، فإن خادم X يولد حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. إذا كان العرض أو الارتفاع صفرًا، فسيؤدي ذلك إلى حدوث خطأ BadValue.

يمكن لـ XResizeWindow توليد أخطاء BadValue و BadWindow.

الدالة XMoveResizeWindow تغير حجم وموقع النافذة المحددة دون رفعها. قد يؤدي نقل وتغيير حجم نافذة معينة إلى توليد حدث Expose على النافذة. اعتمادًا على معلمات الحجم والموقع الجديدة، قد يؤدي نقل وتغيير حجم النافذة إلى توليد أحداث Expose على النوافذ التي كانت النافذة تحجبها سابقًا.

إذا كان علم تجاوز إعادة التوجيه للنافذة هو False وكان هناك عميل آخر قد حدد SubstructureRedirectMask على الأصل، فإن خادم X يولد حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. بخلاف ذلك، يتم تغيير حجم النافذة وموقعها.

يمكن لـ XMoveResizeWindow توليد أخطاء BadValue و BadWindow.

الدالة XSetWindowBorderWidth تعين عرض حد النافذة المحددة إلى العرض المحدد.

يمكن لـ XSetWindowBorderWidth توليد خطأ BadWindow.

الهياكل

يحتوي هيكل XWindowChanges على:

/* بتات قناع قيم تهيئة النافذة */

#define CWX (1<<0)
#define CWY (1<<1)
#define CWWidth (1<<2)
#define CWHeight (1<<3)
#define CWBorderWidth (1<<4)
#define CWSibling (1<<5)
#define CWStackMode (1<<6) 
/* القيم */
typedef struct {
        int x, y;
        int width, height;
        int border_width;
        Window sibling;
        int stack_mode;
} XWindowChanges;

تستخدم الأعضاء x و y لتعيين إحداثيات النافذة x و y، والتي تكون نسبة إلى أصل الأصل وتشير إلى موضع الزاوية الخارجية العلوية اليسرى للنافذة. تستخدم الأعضاء width و height لتعيين الحجم الداخلي للنافذة، ولا تشمل الحد، ويجب أن تكون غير صفرية، وإلا فسيؤدي ذلك إلى حدوث خطأ BadValue. لا يكون للعبث بتهيئة النافذة الجذر أي تأثير.

العضو border_width يستخدم لتعيين عرض الحد بالبكسل. لاحظ أن تعيين عرض الحد فقط يترك الزاوية الخارجية العلوية اليسرى للنافذة في موضع ثابت ولكنه يحرك الموضع المطلق لأصل النافذة. إذا حاولت تعيين سمة border_width لنافذة InputOnly بقيمة غير صفرية، فسيحدث خطأ BadMatch.

العضو sibling يستخدم لتعيين النافذة الشقيقة لعمليات التكديس. العضو stack_mode يستخدم لتعيين كيفية إعادة تكديس النافذة ويمكن تعيينه إلى Above، Below، TopIf، BottomIf، أو Opposite.

التشخيصات

BadMatch
تم استخدام نافذة InputOnly كـ Drawable.
BadMatch
بعض الحجج أو زوج من الحجج لهما النوع والنطاق الصحيح ولكنهما يفشلان في المطابقة بطريقة أخرى مطلوبة بواسطة الطلب.
BadValue
قيمة رقمية ما تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لحجة، يتم قبول النطاق الكامل الذي يحدده نوع الحجة. يمكن لأي حجة محددة كمجموعة من البدائل أن تولد هذا الخطأ.
BadWindow

XWindowChanges(3)

NAME

XWindowChanges - structure for specifying window geometry and attributes

SYNTAX

typedef struct {
    int x, y;
    int width, height;
    int border_width;
    int sibling;
    unsigned int stack_mode;
} XWindowChanges;

ARGUMENTS

x, y
Specify the x and y coordinates of the upper-left corner of the window relative to its parent's origin.
width, height
Specify the width and height of the window.
border_width
Specify the border width of the window.
sibling
Specify the window that the new window should be stacked relative to. This must be a sibling window, or the background or None.

If sibling is None, the new window is stacked at the top or bottom of the stack, depending on stack_mode.

If sibling is a sibling window, the new window is stacked immediately above or below the sibling window, depending on stack_mode.

If sibling is the background window, the new window is stacked above the background window.

stack_mode
Specify the stacking order for the window. It can be one of Below, Above, TopIf, or BottomIf.

DESCRIPTION

The XWindowChanges structure is used by Xlib functions that change the geometry or stacking order of a window, such as XChangeWindowAttributes(3), XConfigureWindow(3), and XCreateWindow(3).

Not all fields in the XWindowChanges structure are used by every function. A separate value mask is used to indicate which fields are valid.

STRUCTURES

The XWindowChanges structure contains the following members:

x, y
The x and y coordinates of the upper-left corner of the window relative to its parent's origin.
width, height
The width and height of the window.
border_width
The width of the window's border.
sibling
The sibling window. This must be a sibling window, the background window, or None.
stack_mode
The stacking mode. Can be one of Above, Below, TopIf, or BottomIf.

DIAGNOSTICS

When a function that uses XWindowChanges encounters an error, it generates a:

BadMatch
A value in the XWindowChanges structure is invalid for the specified window. For example, a value might be out of range or inconsistent with the window's attributes.
BadValue
An invalid value was provided for one of the arguments. For example, an invalid stack_mode value.
BadWindow
A specified Window argument does not name a defined Window.

XChangeWindowAttributes(3), XCreateWindow(3), XDestroyWindow(3), XMapWindow(3), XRaiseWindow(3), XUnmapWindow(3)

XWindowChanges - بنية لتحديد هندسة النافذة وسماتها

typedef struct {
    int x, y;

الوسائط

x, y
تحديد إحداثيات x و y للزاوية العلوية اليسرى للنافذة بالنسبة إلى أصل الأصل الخاص بها.
width, height
تحديد عرض النافذة وارتفاعها.
border_width
تحديد عرض حدود النافذة.
sibling
تحديد النافذة التي يجب أن تُكدس النافذة الجديدة بالنسبة إليها. يجب أن تكون هذه نافذة شقيقة، أو الخلفية، أو None.

إذا كانت sibling هي None، تُكدس النافذة الجديدة في الأعلى أو الأسفل من المكدس، اعتمادًا على stack_mode.

إذا كانت sibling نافذة شقيقة، تُكدس النافذة الجديدة مباشرة فوق أو تحت النافذة الشقيقة، اعتمادًا على stack_mode.

إذا كانت sibling هي نافذة الخلفية، تُكدس النافذة الجديدة فوق نافذة الخلفية.

stack_mode
تحديد وضع التكديس للنافذة. يمكن أن يكون أحد الخيارات التالية: Below، Above، TopIf، أو BottomIf.

الوصف

يستخدم الهيكل XWindowChanges بواسطة وظائف Xlib التي تغير هندسة النافذة أو ترتيب تكديسها، مثل XChangeWindowAttributes(3)، XConfigureWindow(3)، و XCreateWindow(3).

ليست كل الحقول في الهيكل XWindowChanges مستخدمة بواسطة كل وظيفة. يتم استخدام قناع قيمة منفصل للإشارة إلى الحقول الصالحة.

البنى

يحتوي الهيكل XWindowChanges على الأعضاء التالية:

x, y
إحداثيات x و y للزاوية العلوية اليسرى للنافذة بالنسبة إلى أصل الأصل الخاص بها.
width, height
عرض النافذة وارتفاعها.
border_width
عرض حدود النافذة.
sibling
النافذة الشقيقة. يجب أن تكون هذه نافذة شقيقة، أو نافذة الخلفية، أو None.
stack_mode
وضع التكديس. يمكن أن يكون أحد الخيارات التالية: Above، Below، TopIf، أو BottomIf.

التشخيصات

عندما تواجه وظيفة تستخدم XWindowChanges خطأً، فإنها تولد:

BadMatch
قيمة في الهيكل XWindowChanges غير صالحة للنافذة المحددة. على سبيل المثال، قد تكون القيمة خارج النطاق أو غير متسقة مع سمات النافذة.
BadValue
تم توفير قيمة غير صالحة لأحد الوسائط. على سبيل المثال، قيمة stack_mode غير صالحة.
BadWindow
وسيط النافذة المحدد لا يسمي نافذة معرفة.
