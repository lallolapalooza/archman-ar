XwcTextPropertyToTextList(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

Xutf8TextListToTextProperty, Xutf8TextPropertyToTextList, XwcTextPropertyToTextList, XwcTextListToTextProperty - convert between text property and list of strings

SYNOPSIS

#include <X11/Xutil.h>

int Xutf8TextListToTextProperty(
    const char *const *list,
    int count,
    XICCEncodingStyle style,
    XTextProperty *text_prop_return
);

int Xutf8TextPropertyToTextList(
    const XTextProperty *text_prop,
    const char ***list_return,
    int *count_return
);

int XwcTextListToTextProperty(
    const wchar_t *const *list,
    int count,
    XICCEncodingStyle style,
    XTextProperty *text_prop_return
);

int XwcTextPropertyToTextList(
    const XTextProperty *text_prop,
    const wchar_t ***list_return,
    int *count_return
);

ARGUMENTS

list
Specifies the list of strings.
count
Specifies the number of strings in the list.
style
Specifies the desired encoding style for the text property.
text_prop_return
Returns the XTextProperty structure.
text_prop
Specifies the XTextProperty structure.
list_return
Returns a pointer to the list of strings. The caller is responsible for freeing this list using XFreeStringList() or XFree.
count_return
Returns the number of strings in the returned list.

DESCRIPTION

The functions Xutf8TextListToTextProperty and Xutf8TextPropertyToTextList are extensions introduced by The XFree86 Project, Inc., in their 4.0.2 release. Their presence is indicated by the macro X_HAVE_UTF8_STRING.

The functions XwcTextListToTextProperty and XwcTextPropertyToTextList are similar to the Xutf8TextListToTextProperty and Xutf8TextPropertyToTextList functions, but they operate on lists of wide characters (wchar_t) instead of byte strings (char).

The XICCEncodingStyle enumeration defines the desired encoding for the text property.

The return values indicate success or failure. XNoMemory indicates that the server ran out of memory. XLocaleNotSupported indicates that the requested encoding style is not supported. XConverterNotFound indicates that no suitable converter could be found.

STRUCTURES

The XTextProperty structure contains:

typedef struct {
        unsigned char *value;   /* property data */
        Atom encoding;  /* type of property */
        int format;     /* 8, 16, or 32 */
        unsigned long nitems;   /* number of items in value */
} XTextProperty;

The XICCEncodingStyle structure contains:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */
        XCompoundTextStyle,     /* COMPOUND_TEXT */
        XTextStyle,             /* text in owner's encoding (current locale) */
        XStdICCTextStyle,       /* STRING, else COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;

الوصف

الوظائف Xutf8TextListToTextProperty و Xutf8TextPropertyToTextList هي امتدادات قدمتها شركة The XFree86 Project, Inc.، في إصدارها 4.0.2. يتم الإشارة إلى وجودها بالماكرو X_HAVE_UTF8_STRING.

الوظائف XwcTextListToTextProperty و XwcTextPropertyToTextList مشابهة لوظائف Xutf8TextListToTextProperty و Xutf8TextPropertyToTextList، ولكنها تعمل على قوائم أحرف عريضة (wchar_t) بدلاً من سلاسل بايت (char).

التعداد XICCEncodingStyle يحدد الترميز المطلوب لخاصية النص.

تشير قيم الإرجاع إلى النجاح أو الفشل. XNoMemory يشير إلى أن الخادم نفد من الذاكرة. XLocaleNotSupported يشير إلى أن نمط الترميز المطلوب غير مدعوم. XConverterNotFound يشير إلى أنه لم يتم العثور على محول مناسب.

الهياكل

typedef struct {
        unsigned char *value;   /* بيانات الخاصية */

        int format;     /* 8، 16، أو 32 */
        unsigned long nitems;   /* عدد العناصر في value */
} XTextProperty;

البنية XICCEncodingStyle تحتوي على:

#define XNoMemory -1
#define XLocaleNotSupported -2
#define XConverterNotFound -3 
typedef enum {
        XStringStyle,           /* STRING */

        XStdICCTextStyle,       /* STRING، وإلا COMPOUND_TEXT */
        XUTF8StringStyle        /* UTF8_STRING */
} XICCEncodingStyle;
