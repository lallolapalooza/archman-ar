الوصف

تقوم الوظيفة XReadBitmapFile بقراءة ملف يحتوي على خريطة نقطية. يتم تحليل الملف بتشفير اللغة المحلية الحالية. القدرة على قراءة تنسيقات أخرى غير التنسيق القياسي تعتمد على التنفيذ. إذا تعذر فتح الملف، تعيد XReadBitmapFile القيمة BitmapOpenFailed. إذا تمكن من فتح الملف ولكنه لا يحتوي على بيانات خريطة نقطية صالحة، فإنه يعيد BitmapFileInvalid. إذا تم تخصيص مساحة عمل غير كافية، فإنه يعيد BitmapNoMemory. إذا كان الملف قابلاً للقراءة وصالحًا، فإنه يعيد BitmapSuccess.

تعيد XReadBitmapFile ارتفاع وعرض الخريطة النقطية، كما تمت قراءتها من الملف، إلى width_return و height_return. ثم تنشئ صورة نقطية بالحجم المناسب، وتقرأ بيانات الخريطة النقطية من الملف إلى الصورة النقطية، وتعين الصورة النقطية لمتغير bitmap الخاص بالمتصل. يجب على المتصل تحرير الصورة النقطية باستخدام XFreePixmap عند الانتهاء. إذا كانت name_x_hot و name_y_hot موجودة، فإن XReadBitmapFile تعيدها إلى x_hot_return و y_hot_return؛ وإلا، فإنها تعيد -1، -1.

يمكن لـ XReadBitmapFile إنشاء أخطاء BadAlloc و BadDrawable.

تقوم الوظيفة XReadBitmapFileData بقراءة ملف يحتوي على خريطة نقطية، بنفس الطريقة التي تعمل بها XReadBitmapFile، ولكنها تعيد البيانات مباشرة بدلاً من إنشاء صورة نقطية في الخادم. يتم إرجاع بيانات الخريطة النقطية في data_return؛ يجب على العميل تحرير هذه المساحة عند الانتهاء منها عن طريق استدعاء XFree. الحالة وقيم الإرجاع الأخرى هي نفسها الخاصة بـ XReadBitmapFile.

تكتب الوظيفة XWriteBitmapFile خريطة نقطية إلى ملف بتنسيق X الإصدار 11. يتم اشتقاق الاسم المستخدم في ملف الإخراج من اسم الملف عن طريق حذف البادئة الدليلية. يتم كتابة الملف بتشفير اللغة المحلية الحالية. إذا تعذر فتح الملف للكتابة، فإنه يعيد BitmapOpenFailed. إذا تم تخصيص ذاكرة غير كافية، تعيد XWriteBitmapFile القيمة BitmapNoMemory؛ بخلاف ذلك، عند عدم وجود خطأ، فإنها تعيد BitmapSuccess. إذا لم تكن x_hot و y_hot تساوي -1، -1، فإن XWriteBitmapFile تكتبهما كإحداثيات لنقطة الاتصال للخريطة النقطية.

يمكن لـ XWriteBitmapFile إنشاء أخطاء BadDrawable و BadMatch.

تنشئ الوظيفة XCreatePixmapFromBitmapData صورة نقطية بالعمق المحدد ثم تقوم بإجراء XPutImage بتنسيق الخريطة النقطية للبيانات فيها. يجب أن يكون العمق مدعومًا من قبل شاشة الكائن القابل للرسم المحدد، أو تحدث نتيجة لخطأ BadMatch.

يمكن لـ XCreatePixmapFromBitmapData إنشاء أخطاء BadAlloc و BadMatch.

تسمح لك الوظيفة XCreateBitmapFromData بتضمين ملف خريطة نقطية تم كتابته بواسطة XWriteBitmapFile (تنسيق X الإصدار 11 فقط) في برنامج C الخاص بك (باستخدام #include) دون قراءة ملف الخريطة النقطية. المثال التالي ينشئ خريطة نقطية رمادية:

#include "gray.bitmap"

Pixmap bitmap;
bitmap = XCreateBitmapFromData(display, window, gray_bits, gray_width, gray_height);

إذا تم تخصيص ذاكرة عمل غير كافية، تعيد XCreateBitmapFromData القيمة None. تقع على عاتقك مسؤولية تحرير الصورة النقطية باستخدام XFreePixmap عند الانتهاء.

يمكن لـ XCreateBitmapFromData إنشاء خطأ BadAlloc.

التشخيص

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadDrawable
قيمة معامل Drawable لا تسمي نافذة أو صورة نقطية معرفة.
BadMatch
يتم استخدام نافذة InputOnly ككائن قابل للرسم.

XWriteBitmapFile

3

Xlib Functions Manual

NAME

XWriteBitmapFile - writes a bitmap to a file.

SYNTAX


    Bool XWriteBitmapFile(
        Display *display,
        char *filename,
        Pixmap bitmap,
        unsigned int width,
        unsigned int height,
        int   foreground,
        int   background
    );

ARGUMENTS

display
Specifies the connection to the X server.
filename
Specifies the file to which the bitmap is written.
bitmap
Specifies the pixmap to be written.
width
Specifies the width of the bitmap in pixels.
height
Specifies the height of the bitmap in pixels.
foreground
Specifies the foreground pixel value for the bitmap.
background
Specifies the background pixel value for the bitmap.

DESCRIPTION

The function XWriteBitmapFile writes the specified bitmap to the specified file. The bitmap is written in X11 bitmap file format. The foreground and background pixel values are used to create the bitmap. If the foreground or background pixel values are not specified, the default values are used.

DIAGNOSTICS

On success, XWriteBitmapFile returns True . On failure, it returns False .

XWriteBitmapFile

3

دليل دوال Xlib

الاسم

XWriteBitmapFile - يكتب صورة نقطية إلى ملف.

الصيغة


    Bool XWriteBitmapFile(
        Display *display,
        char *filename,
        Pixmap bitmap,
        unsigned int width,
        unsigned int height,
        int   foreground,
        int   background
    );

الوسائط

display
يحدد الاتصال بخادم X.
filename
يحدد الملف الذي تُكتب إليه الصورة النقطية.
bitmap
يحدد المصغرة (pixmap) التي سيتم كتابتها.
width
يحدد عرض الصورة النقطية بالبكسل.
height
يحدد ارتفاع الصورة النقطية بالبكسل.
foreground
يحدد قيمة بكسل المقدمة (foreground) للصورة النقطية.
background
يحدد قيمة بكسل الخلفية (background) للصورة النقطية.

الوصف

تقوم الدالة XWriteBitmapFile بكتابة الصورة النقطية المحددة إلى الملف المحدد. تُكتب الصورة النقطية بتنسيق ملف X11 bitmap. تُستخدم قيم بكسلات المقدمة والخلفية لإنشاء الصورة النقطية. إذا لم يتم تحديد قيم بكسلات المقدمة أو الخلفية، يتم استخدام القيم الافتراضية.

التشخيص

عند النجاح، تعيد الدالة XWriteBitmapFile القيمة True . عند الفشل، تعيد القيمة False .
