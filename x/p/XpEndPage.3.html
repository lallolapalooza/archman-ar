XpEndPage(3)

الحزمة: libxp

التراخيص: X11, X11-distribute-modifications-variant

XpEndPage(3Xp) وظائف XPRINT XpEndPage(3Xp)

الاسم

XpEndPage - يشير إلى نهاية صفحة طباعة.

الملخص


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpEndPage ( display )
Display *display;

الوصف

يشير XpEndPage إلى نهاية صفحة طباعة، ويؤدي إلى إخفاء النافذة. يتم تجميع جميع بيانات الصفحة الناتجة ودمجها مع البيانات المرسلة سابقًا بواسطة XpPutDocumentData. لن يحدث أي توليد لبيانات المستند لعمليات العرض إلى النوافذ المقابلة بعد استدعاء XpEndPage.

بالنسبة للعملاء الذين يختارون XPPrintMask (انظر XpSelectInput)، يتم إنشاء حدث XPPrintNotify مع تعيين حقل التفاصيل الخاص به إلى XPEndPageNotify عندما يكمل خادم طباعة X استدعاء XpEndPage.

المعاملات

display
يحدد مؤشرًا إلى بنية العرض؛ تم إرجاعه من XOpenDisplay.

التشخيص

XPBadSequence
لم يتم استدعاء الوظيفة بالترتيب الصحيح فيما يتعلق باستدعاءات خدمة طباعة X الأخرى؛ على سبيل المثال، تم استدعاء XpStartPage قبل XpStartJob أو تم استدعاؤه لنوع المستند XPDocRaw.

انظر أيضًا

XpPutDocumentData.(3Xp)، XpSelectInput(3Xp)، XpStartPage(3Xp)
