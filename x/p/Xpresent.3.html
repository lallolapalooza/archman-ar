Xpresent(3)

الحزمة: libxpresent

التراخيص: MIT

XPRESENT(3) إصدار X 11 XPRESENT(3)

اسم

Xpresent - امتداد X Present

الصيغة

#include <X11/extensions/Xpresent.h>

Bool XPresentQueryExtension (Display *dpy, int *major_opcode_return,
	int *event_base_return, int *error_base_return);

Status XPresentQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

int XPresentVersion (void);

المعاملات

dpy
يحدد الاتصال بخادم X.

الوصف

Xpresent هي مكتبة مصممة للتعامل مع امتداد X Present. يوفر امتداد Present طريقة للتطبيقات لتحديث محتويات نوافذها من صورة نقطية (pixmap) بطريقة محددة جيدًا، مع المزامنة مع تحديث الشاشة وربما استخدام آلية أكثر كفاءة من نسخ محتويات الصورة النقطية المصدر.

تقوم الدالة XPresentQueryExtension بالتحقق مما إذا كان خادم X المحدد بواسطة dpy يدعم امتداد X Present. إذا كان الخادم لا يدعم الامتداد، فإنه يعيد False. إذا كان الخادم يدعم الامتداد، فإنه يعيد True، ويضبط قيم major_opcode_return و event_base_return و error_base_return إذا كانت المؤشرات ليست NULL.

يجب على العملاء استدعاء الدالة XPresentQueryExtension للتحقق من أن الخادم يدعم الامتداد قبل استدعاء أي دالة أخرى لهذا الامتداد.

تقوم الدالة XPresentQueryVersion بضبط القيم التي يشير إليها major_version_return و minor_version_return إلى إصدار الامتداد الذي يدعمه خادم X المحدد بواسطة dpy. تعيد الدالة XPresentQueryVersion إصدار مكتبة libXpresent المستخدمة، كما هو محدد بواسطة ماكرو PRESENT_VERSION في <X11/extensions/Xpresent.h>.
