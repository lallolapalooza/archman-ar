XPixmapFormatValues(3)

الحزمة: libx11

التراخيص: MIT AND X11

ImageByteOrder(3) وظائف XLIB ImageByteOrder(3)

الاسم

ImageByteOrder, BitmapBitOrder, BitmapPad, BitmapUnit, DisplayHeight, DisplayHeightMM, DisplayWidth, DisplayWidthMM, XListPixmapFormats, XPixmapFormatValues - وظائف وماكرو تنسيق الصور

الصيغة

XPixmapFormatValues *XListPixmapFormats(Display *display, int *count_return);

int ImageByteOrder(Display *display);

int BitmapBitOrder(Display *display);

int BitmapPad(Display *display);

int BitmapUnit(Display *display);

int DisplayHeight(Display *display, int screen_number);

int DisplayHeightMM(Display *display, int screen_number);

int DisplayWidth(Display *display, int screen_number);

int DisplayWidthMM(Display *display, int screen_number);

الوسائط

display
يحدد الاتصال بخادم X.
count_return
يعيد عدد تنسيقات الـ pixmap المدعومة بواسطة الشاشة.
screen_number
يحدد رقم الشاشة المناسب على خادم الاستضافة.

الوصف

تقوم الدالة XListPixmapFormats بإعادة مصفوفة من هياكل XPixmapFormatValues التي تصف أنواع صور تنسيق Z المدعومة بواسطة الشاشة المحددة. إذا كانت الذاكرة غير كافية، تعيد XListPixmapFormats القيمة NULL. لتحرير التخزين المخصص لهياكل XPixmapFormatValues، استخدم XFree.

يقوم الماكرو ImageByteOrder بتحديد ترتيب البايت المطلوب للصور لكل وحدة مسح في تنسيق XY (bitmap) أو لكل قيمة بكسل في تنسيق Z.

يعيد الماكرو BitmapBitOrder القيمة LSBFirst أو MSBFirst للإشارة إلى ما إذا كان البت الأيسر في الـ bitmap كما هو معروض على الشاشة هو البت الأقل أهمية أو الأكثر أهمية في الوحدة.

يعيد الماكرو BitmapPad عدد البتات التي يجب حشو كل سطر مسح بها.

يعيد الماكرو BitmapUnit حجم وحدة سطر المسح للـ bitmap بالبتات.

يعيد الماكرو DisplayHeight ارتفاع الشاشة المحددة بالبكسل.

يعيد الماكرو DisplayHeightMM ارتفاع الشاشة المحددة بالميليمتر.

يعيد الماكرو DisplayWidth عرض الشاشة بالبكسل.

يعيد الماكرو DisplayWidthMM عرض الشاشة المحددة بالميليمتر.

الهياكل

يوفر هيكل XPixmapFormatValues واجهة لمعلومات تنسيق الـ pixmap التي يتم إرجاعها في وقت إعداد الاتصال. يتضمن:

typedef struct {
        int depth;
        int bits_per_pixel;
        int scanline_pad;
} XPixmapFormatValues;
