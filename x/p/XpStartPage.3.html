XpStartPage(3)

الحزمة: libxp

التراخيص: X11, X11-distribute-modifications-variant

XpStartPage(3Xp) وظائف XPRINT XpStartPage(3Xp)

الاسم

XpStartPage - يشير إلى بداية صفحة طباعة.

الملخص


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpStartPage ( display, window )
Display *display;
Window window;

الوسائط

display
يحدد مؤشرًا إلى بنية العرض؛ تم إرجاعه من XOpenDisplay.
window
يحدد معرف النافذة.

الوصف

تشير XpStartPage إلى بداية صفحة طباعة جديدة، حيث تمثل النافذة الرسم الذي يمثل الصفحة. يجب أن تكون window نافذة فرعية لنافذة الجذر لسياق الطباعة الحالي، وإلا سيتم إنشاء خطأ BadWindow. لن يحدث إنشاء لبيانات المستند لعمليات العرض على النافذة أو نوافذها الفرعية قبل XpStartPage.

تتسبب XpStartPage في ظهور النافذة. انظر XpGetPageDimensions و XResizeWindow للحصول على تفاصيل حول تغيير حجم النافذة بحجم الوسائط المحددة قبل استدعاء XpStartPage. ضمن تسلسل XpStartPage و XpEndPage، ستؤدي محاولات تغيير حجم النافذة أو نقلها أو إلغاء تعيينها إلى نتائج غير معرفة. لتغيير حجم النوافذ الفرعية أو نقلها، تنطبق الدلالات القياسية لـ ConfigureWindow، باستثناء أنه قد يتم تجاهل محتويات أي نافذة تم تكوينها. سيتم إنشاء حدث Expose إذا تم تجاهل محتويات النافذة.

يجب إجراء جميع التغييرات على مجمع سمات XPPageAttr (انظر XpSetAttributes) قبل استدعاء XpStartPage، وبعد ذلك سيتم إنشاء خطأ XPBadSequence إذا تم محاولة إجراء تغييرات، حتى يتم استدعاء XpEndPage.

بالنسبة للعملاء الذين يختارون XPPrintMask (انظر XpSelectInput)، سيتم إنشاء حدث XPPrintNotify مع تعيين حقل التفصيل الخاص به إلى XPStartPageNotify عندما يكمل خادم طباعة X XpStartPage. إذا تم أيضًا تحديد حدث Expose (انظر XSelectInput)، فسيتم إنشاء أحداث الكشف قبل XPPrintNotify.

لا يحتاج العميل إلى الانتظار لـ XPStartPageNotify قبل استدعاء أي إجراءات عرض X أخرى.

التشخيص

BadWindow
القيمة المحددة للنافذة غير صالحة.
XPBadContext
لم يتم تعيين معرف سياق طباعة صالح قبل إجراء هذا الاستدعاء.
XPBadSequence
لم يتم استدعاء الوظيفة بالترتيب الصحيح فيما يتعلق باستدعاءات ملحق طباعة X الأخرى؛ على سبيل المثال، تم استدعاء XpStartPage قبل XpStartJob أو تم استدعاؤها لنوع مستند XPDocRaw.
