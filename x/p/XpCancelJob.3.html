XpCancelJob(3)

الحزمة: libxp

التراخيص: X11, X11-distribute-modifications-variant

XpCancelJob(3Xp) XPRINT FUNCTIONS XpCancelJob(3Xp)

اسم

XpCancelJob - إلغاء مهمة طباعة واحدة.

الملخص


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpCancelJob ( display, discard )
Display *display;
Bool discard;

المعاملات

display
يحدد مؤشرًا إلى هيكل العرض؛ تم إرجاعه من XOpenDisplay.
discard
عندما يكون TRUE، يحدد أنه يجب تجاهل جميع أحداث XPPrintNotify.

الوصف

XpCancelJob تقوم بإلغاء مهمة قيد التقدم. إذا بدأت المهمة بوضع الإخراج XPGetData، يتم إنهاء تدفق البيانات إلى XpGetDocumentData. بالنسبة للعديد من لغات وصف الصفحات، قد يؤدي هذا الإنهاء التعسفي إلى إبطال الإخراج.

إذا بدأت المهمة بوضع الإخراج XPSpool، اعتمادًا على برنامج تشغيل الطابعة والبرنامج المساعد، فقد يتم إلغاء المهمة بالكامل أو قد يتم إنشاء مهمة جزئية.

إذا كان discard هو TRUE، فسيتم تجاهل جميع أحداث XPPrintNotify ذات حقل التفاصيل XPEndPageNotify أو XPEndDocNotify أو XPEndJobNotify قبل أن تعود XpCancelJob.

بالنسبة للعملاء الذين يختارون XPPrintMask (انظر XpSelectInput)، سيتم إنشاء حدث XPPrintNotify مع تعيين حقل التفاصيل الخاص به إلى XPEndJobNotify.

التشخيصات

XPBadContext
لم يتم تعيين معرف سياق طباعة صالح قبل إجراء هذا الاستدعاء.
XPBadSequence
لم يتم استدعاء الدالة بالترتيب الصحيح بالنسبة لاستدعاءات خدمة طباعة X الأخرى (على سبيل المثال، XpEndJob قبل XpStartJob).
