الوصف

تقوم وظيفة XPutImage بدمج صورة مع مستطيل من الكائن القابل للرسم المحدد. يتم رسم قسم الصورة المحدد بواسطة معاملات src_x و src_y و width و height على الجزء المحدد من الكائن القابل للرسم. إذا تم استخدام تنسيق XYBitmap، يجب أن يكون عمق الصورة واحدًا، وإلا فسيتم توليد خطأ BadMatch. تحدد البكسل الأمامي في GC المصدر للبتات واحد في الصورة، ويحدد البكسل الخلفي المصدر للبتات صفر. بالنسبة لـ XYPixmap و ZPixmap، يجب أن يتطابق عمق الصورة مع عمق الكائن القابل للرسم، وإلا فسيتم توليد خطأ BadMatch.

إذا كانت خصائص الصورة (على سبيل المثال، byte_order و bitmap_unit) تختلف عما يتطلبه الخادم، تقوم XPutImage بإجراء التحويلات المناسبة تلقائيًا.

تستخدم هذه الوظيفة مكونات GC التالية: function، plane-mask، subwindow-mode، clip-x-origin، clip-y-origin، و clip-mask. كما أنها تستخدم المكونات المعتمدة على وضع GC هذه: foreground و background.

يمكن أن تولد XPutImage أخطاء BadDrawable، BadGC، BadMatch، و BadValue.

تعيد وظيفة XGetImage مؤشرًا إلى بنية XImage. توفر لك هذه البنية محتويات المستطيل المحدد من الكائن القابل للرسم بالتنسيق الذي تحدده. إذا كان معامل التنسيق هو XYPixmap، فإن الصورة تحتوي فقط على مستويات البت التي مررتها إلى معامل plane_mask. إذا طلب معامل plane_mask مجموعة فرعية فقط من مستويات العرض، فسيكون عمق الصورة المعاد هو عدد المستويات المطلوبة. إذا كان معامل التنسيق هو ZPixmap، فإن XGetImage تعيد صفرًا للبتات في جميع المستويات غير المحددة في معامل plane_mask. لا تقوم الوظيفة بأي فحص نطاق لقيم plane_mask وتتجاهل البتات الزائدة.

تعيد XGetImage عمق الصورة إلى عضو depth في بنية XImage. عمق الصورة هو كما تم تحديده عند إنشاء الكائن القابل للرسم، باستثناء عند الحصول على مجموعة فرعية من المستويات بتنسيق XYPixmap، عندما يتم توفير العمق عن طريق عدد البتات المعينة إلى 1 في plane_mask.

إذا كان الكائن القابل للرسم عبارة عن pixmap، فيجب أن يكون المستطيل المحدد مدرجًا بالكامل ضمن pixmap، وإلا فسيتم توليد خطأ BadMatch. إذا كان الكائن القابل للرسم عبارة عن نافذة، فيجب أن تكون النافذة مرئية، ويجب أن يكون صحيحًا أنه إذا لم تكن هناك نوافذ فرعية أو متداخلة، فإن المستطيل المحدد للنافذة سيكون مرئيًا بالكامل على الشاشة ومدرجًا بالكامل ضمن الحواف الخارجية للنافذة، وإلا فسيتم توليد خطأ BadMatch. لاحظ أنه يمكن تضمين حدود النافذة وقراءتها باستخدام هذا الطلب. إذا كانت النافذة تحتوي على backing-store، يتم إرجاع محتويات backing-store للمناطق من النافذة التي تحجبها نوافذ غير فرعية. إذا كانت النافذة لا تحتوي على backing-store، فإن المحتويات المعاد لهذه المناطق المحجوبة غير محددة. كما أن المحتويات المعاد للمناطق المرئية للنوافذ الفرعية بعمق مختلف عن عمق النافذة المحدد غير محددة. لا يتم تضمين صورة المؤشر (cursor) في المحتويات المعاد. إذا حدثت مشكلة، تعيد XGetImage القيمة NULL.

يمكن أن تولد XGetImage أخطاء BadDrawable، BadMatch، و BadValue.

تقوم وظيفة XGetSubImage بتحديث dest_image بالصورة الفرعية المحددة بنفس الطريقة التي تقوم بها XGetImage. إذا كان معامل التنسيق هو XYPixmap، فإن الصورة تحتوي فقط على مستويات البت التي مررتها إلى معامل plane_mask. إذا كان معامل التنسيق هو ZPixmap، فإن XGetSubImage تعيد صفرًا للبتات في جميع المستويات غير المحددة في معامل plane_mask. لا تقوم الوظيفة بأي فحص نطاق لقيم plane_mask وتتجاهل البتات الزائدة. كإجراء مريح، تعيد XGetSubImage مؤشرًا إلى نفس بنية XImage المحددة بواسطة dest_image.

يجب أن يكون عمق بنية XImage الوجهة هو نفس عمق الكائن القابل للرسم. إذا كانت الصورة الفرعية المحددة لا تتناسب مع الموقع المحدد في الصورة الوجهة، فسيتم قص الحواف اليمنى والسفلية. إذا كان الكائن القابل للرسم عبارة عن pixmap، فيجب أن يكون المستطيل المحدد مدرجًا بالكامل ضمن pixmap، وإلا فسيتم توليد خطأ BadMatch. إذا كان الكائن القابل للرسم عبارة عن نافذة، فيجب أن تكون النافذة مرئية، ويجب أن يكون صحيحًا أنه إذا لم تكن هناك نوافذ فرعية أو متداخلة، فإن المستطيل المحدد للنافذة سيكون مرئيًا بالكامل على الشاشة ومدرجًا بالكامل ضمن الحواف الخارجية للنافذة، وإلا فسيتم توليد خطأ BadMatch. إذا كانت النافذة تحتوي على backing-store، يتم إرجاع محتويات backing-store للمناطق من النافذة التي تحجبها نوافذ غير فرعية. إذا كانت النافذة لا تحتوي على backing-store، فإن المحتويات المعاد لهذه المناطق المحجوبة غير محددة. كما أن المحتويات المعاد للمناطق المرئية للنوافذ الفرعية بعمق مختلف عن عمق النافذة المحدد غير محددة. إذا حدثت مشكلة، تعيد XGetSubImage القيمة NULL.

يمكن أن تولد XGetSubImage أخطاء BadDrawable، BadGC، BadMatch، و BadValue.

XPutImage(3)

NAME

XPutImage - write image to X server

SYNTAX

    #include <X11/Xlib.h>

    Status XPutImage(Display *display, Drawable d, GC gc, XImage *image,
                        int x, int y, int left_pad, int top_pad,
                        unsigned int depth);

ARGUMENTS

display Specifies the connection to the X server.
d Specifies the drawable (a window or a pixmap).
gc Specifies the GC.
image Specifies the image to be sent to the server.
x Specifies the x-coordinate relative to the drawable's origin in the clipping rectangle.
y Specifies the y-coordinate relative to the drawable's origin in the clipping rectangle.
left_pad Specifies the number of pixels to the left of the image data for XYFormat images.
top_pad Specifies the number of pixels to the top of the image data for XYFormat images.
depth Specifies the depth of the image.

DESCRIPTION

The XPutImage function writes an image to the specified drawable. The image is clipped by the GC's clip-mask and the GC's clip-box. The image data is written into the drawable at the specified x and y coordinates, relative to the drawable's origin. The left_pad and top_pad arguments are used to specify the offset for XYFormat images. For ZFormat images, these arguments are ignored.

The depth argument specifies the image depth. If the drawable has a different depth than the image, an error may occur.

DIAGNOSTICS

BadGC
A value for a graphics context argument does not correspond to a created GC.
BadDrawable
A value for a drawable argument does not exist.
BadMatch
The arguments chosen from the argument list do not have matching types or ranges.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.
