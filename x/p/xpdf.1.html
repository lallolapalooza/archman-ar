وضع خادم بعيد

يقوم تشغيل xpdf مع الخيار "-remote" بوضعه في وضع الخادم البعيد. ستكون جميع خيارات سطر الأوامر المتبقية أوامر (راجع قسم الأوامر). ستؤدي الاستدعاءات اللاحقة لـ "xpdf -remote" مع نفس اسم الخادم البعيد إلى إرسال الأوامر إلى المثيل الحالي لـ xpdf. تعد أوامر "checkOpenFile" مفيدة هنا لأشياء مثل تغيير الصفحات. على سبيل المثال:


# بدء تشغيل xpdf، وفتح something.pdf.
xpdf -remote foo 'openFile(something.pdf)'


# التبديل إلى الصفحة 7 في something.pdf المفتوح بالفعل. إذا أغلق
# المستخدم xpdf في هذه الأثناء، فسيتم إعادة تشغيله وإعادة فتح
# الملف.
xpdf -remote foo 'checkOpenFileAtPage(something.pdf, 7)'

NAME

xpdf - Portable Document Format (PDF) viewer

SYNOPSIS

xpdf [options] [file.pdf ...]

DESCRIPTION

xpdf is a viewer for Portable Document Format (PDF) files. It can display PDF files, search for text, and print PDF files. xpdf supports most PDF features, including encryption, hyperlinks, and forms.

CONFIGURATION FILE

xpdf can be configured using a configuration file named xpdfrc. The configuration file can be located in the user's home directory (~/.xpdfrc) or in the system-wide configuration directory (/etc/xpdfrc).

OPTIONS

xpdf supports a variety of command-line options to control its behavior. Some of the most common options include:

-cfg config-file
Specifies a configuration file to use.
-display display
Specifies the X display to use.
-fonts font-dir
Specifies a directory to search for fonts.
-help
Displays a help message.
-p page-number
Opens the PDF file at the specified page number.
-print
Prints the PDF file to the default printer.
-rv
Inverts the colors of the PDF file.
-size widthxheight
Sets the initial window size.
-t printer
Prints the PDF file to the specified printer.
-v
Displays the version information.
-z zoom-level
Sets the initial zoom level.

CONTROLS

xpdf provides a toolbar and keyboard shortcuts for navigation and other common actions. The toolbar includes buttons for:

  • Opening and closing files
  • Going to the previous/next page
  • Zooming in/out
  • Printing
  • Searching for text

Keyboard shortcuts include:

Arrow keys
Scroll the page.
PageUp/PageDown
Go to the previous/next page.
Home/End
Go to the first/last page.
+ / -
Zoom in/out.
Ctrl+F
Find text.
Ctrl+P
Print.
Ctrl+Q
Quit.

Full-screen mode

xpdf supports a full-screen mode, which can be activated by pressing the 'f' key. In full-screen mode, the toolbar and window decorations are hidden, allowing for a more immersive viewing experience. Press 'f' again to exit full-screen mode.

COMMANDS

xpdf supports a set of internal commands that can be accessed via the command line or through the configuration file. Some common commands include:

open file.pdf
Opens the specified PDF file.
close
Closes the current PDF file.
print
Prints the current PDF file.
quit
Exits xpdf.

REMOTE SERVER MODE

xpdf can run as a remote server, allowing other applications to access its functionality over the network. This mode is typically used by applications that need to process PDF files without a graphical user interface.

EXIT CODES

xpdf returns an exit code to indicate the success or failure of its operation. The following exit codes are defined:

0
Success.
1
Error opening a PDF file.
2
Error opening an output file.
3
Error related to PDF permissions.
99
Other error.
