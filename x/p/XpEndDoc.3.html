XpEndDoc(3)

الحزمة: libxp

التراخيص: X11, X11-distribute-modifications-variant

XpEndDoc(3Xp) وظائف الطباعة XpEndDoc(3Xp)

الاسم

XpEndDoc - يشير إلى نهاية وثيقة الطباعة.

الملخص


cc [ flag... ] file... -lXp [ library... ]
#include <X11/extensions/Print.h>

void XpEndDoc ( display )
Display *display;

المعاملات

display
يحدد مؤشرًا إلى بنية العرض؛ تم إرجاعه من XOpenDisplay.

الوصف

تشير XpEndDoc إلى نهاية وثيقة الطباعة. يتم تجميع كافة بيانات الوثيقة الناتجة ودمجها مع البيانات المرسلة مسبقًا بواسطة XpPutDocumentData.

بالنسبة للعملاء الذين يختارون XPPrintMask (انظر XpSelectInput)، يتم إنشاء حدث XPPrintNotify مع تعيين حقله التفصيلي إلى XPEndDocNotify.

التشخيصات

XPBadContext
لم يتم تعيين معرف سياق طباعة صالح قبل إجراء هذا الاستدعاء.
XPBadSequence
لم يتم استدعاء الدالة بالترتيب الصحيح فيما يتعلق بمكالمات خدمة الطباعة الأخرى لـ X. (مثال، XpEndDoc قبل XpStartDoc).

انظر أيضًا

XpPutDocumentData(3Xp)، XpSelectInput(3Xp)، XpStartDoc(3Xp)

libXp 1.0.4 X Version 11
