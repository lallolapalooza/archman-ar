الوصف

تقوم وظيفة XPutImage بدمج صورة مع مستطيل من العنصر القابل للرسم المحدد. يتم رسم جزء الصورة المحدد بواسطة معاملات src_x و src_y وعرض وارتفاع على الجزء المحدد من العنصر القابل للرسم. إذا تم استخدام تنسيق XYBitmap، يجب أن يكون عمق الصورة واحدًا، وإلا فسيحدث خطأ BadMatch. تحدد البكسل الأمامي في GC مصدر البتات واحد في الصورة، وتحدد البكسل الخلفي مصدر البتات صفر. بالنسبة لـ XYPixmap و ZPixmap، يجب أن يتطابق عمق الصورة مع عمق العنصر القابل للرسم، وإلا فسيحدث خطأ BadMatch.

إذا كانت خصائص الصورة (على سبيل المثال، ترتيب البايت ووحدة البت) تختلف عن ما يتطلبه الخادم، تقوم XPutImage بإجراء التحويلات المناسبة تلقائيًا.

تستخدم هذه الوظيفة مكونات GC هذه: الوظيفة، قناع المستوى، وضع النافذة الفرعية، أصل clip-x، أصل clip-y، وقناع clip. كما أنها تستخدم هذه المكونات المعتمدة على وضع GC: الأمامي والخلفي.

يمكن لـ XPutImage إنشاء أخطاء BadDrawable و BadGC و BadMatch و BadValue.

تقوم وظيفة XGetImage بإرجاع مؤشر إلى بنية XImage. توفر لك هذه البنية محتويات المستطيل المحدد للعنصر القابل للرسم بالتنسيق الذي تحدده. إذا كان المعامل format هو XYPixmap، فستحتوي الصورة على مستويات البت التي مررتها إلى المعامل plane_mask فقط. إذا كان المعامل plane_mask يطلب فقط مجموعة فرعية من مستويات العرض، فسيكون عمق الصورة المرتجعة هو عدد المستويات المطلوبة. إذا كان المعامل format هو ZPixmap، فإن XGetImage تعيد البتات في جميع المستويات غير المحددة في plane_mask على أنها صفر. لا تقوم الوظيفة بإجراء أي فحص للحدود على قيم plane_mask وتتجاهل البتات الزائدة.

تقوم XGetImage بإرجاع عمق الصورة إلى العضو depth في بنية XImage. عمق الصورة هو كما تم تحديده عند إنشاء العنصر القابل للرسم، باستثناء عند الحصول على مجموعة فرعية من المستويات بتنسيق XYPixmap، حيث يتم إعطاء العمق بواسطة عدد البتات التي تم تعيينها إلى 1 في plane_mask.

إذا كان العنصر القابل للرسم عبارة عن pixmap، فيجب أن يكون المستطيل المحدد موجودًا بالكامل داخل الـ pixmap، وإلا فسيحدث خطأ BadMatch. إذا كان العنصر القابل للرسم عبارة عن نافذة، فيجب أن تكون النافذة قابلة للعرض، ويجب أن يكون صحيحًا أنه إذا لم تكن هناك نوافذ تابعة أو متداخلة، فإن المستطيل المحدد للنافذة سيكون مرئيًا بالكامل على الشاشة وموجودًا بالكامل داخل الحواف الخارجية للنافذة، وإلا فسيحدث خطأ BadMatch. لاحظ أنه يمكن تضمين حدود النافذة وقراءتها باستخدام هذا الطلب. إذا كانت للنافذة ذاكرة احتياطية، فسيتم إرجاع محتويات الذاكرة الاحتياطية للمناطق من النافذة التي تحجبها نوافذ غير تابعة. إذا لم تكن للنافذة ذاكرة احتياطية، فإن المحتويات المرتجعة لهذه المناطق المحجوبة غير محددة. المحتويات المرتجعة للمناطق المرئية للنوافذ التابعة ذات عمق مختلف عن عمق النافذة المحدد هي أيضًا غير محددة. لا يتم تضمين صورة المؤشر (cursor) في المحتويات المرتجعة. إذا حدثت مشكلة، فإن XGetImage ترجع NULL.

يمكن لـ XGetImage إنشاء أخطاء BadDrawable و BadMatch و BadValue.

تقوم وظيفة XGetSubImage بتحديث dest_image بالصورة الفرعية المحددة بنفس طريقة XGetImage. إذا كان المعامل format هو XYPixmap، فستحتوي الصورة على مستويات البت التي مررتها إلى المعامل plane_mask فقط. إذا كان المعامل format هو ZPixmap، فإن XGetSubImage تعيد البتات في جميع المستويات غير المحددة في plane_mask على أنها صفر. لا تقوم الوظيفة بإجراء أي فحص للحدود على قيم plane_mask وتتجاهل البتات الزائدة. كإجراء مريح، ترجع XGetSubImage مؤشرًا إلى نفس بنية XImage التي تم تحديدها بواسطة dest_image.

يجب أن يكون عمق بنية XImage الوجهة مطابقًا لعمق العنصر القابل للرسم. إذا لم تتناسب الصورة الفرعية المحددة مع الموقع المحدد في الصورة الوجهة، فسيتم قص الحواف اليمنى والسفلية. إذا كان العنصر القابل للرسم عبارة عن pixmap، فيجب أن يكون المستطيل المحدد موجودًا بالكامل داخل الـ pixmap، وإلا فسيحدث خطأ BadMatch. إذا كان العنصر القابل للرسم عبارة عن نافذة، فيجب أن تكون النافذة قابلة للعرض، ويجب أن يكون صحيحًا أنه إذا لم تكن هناك نوافذ تابعة أو متداخلة، فإن المستطيل المحدد للنافذة سيكون مرئيًا بالكامل على الشاشة وموجودًا بالكامل داخل الحواف الخارجية للنافذة، وإلا فسيحدث خطأ BadMatch. إذا كانت للنافذة ذاكرة احتياطية، فسيتم إرجاع محتويات الذاكرة الاحتياطية للمناطق من النافذة التي تحجبها نوافذ غير تابعة. إذا لم تكن للنافذة ذاكرة احتياطية، فإن المحتويات المرتجعة لهذه المناطق المحجوبة غير محددة. المحتويات المرتجعة للمناطق المرئية للنوافذ التابعة ذات عمق مختلف عن عمق النافذة المحدد هي أيضًا غير محددة. إذا حدثت مشكلة، فإن XGetSubImage ترجع NULL.

يمكن لـ XGetSubImage إنشاء أخطاء BadDrawable و BadGC و BadMatch و BadValue.

XGetImage(3) — X Version 11

NAME

XGetImage, XGetPixel, XPutImage, XPutPixel, XSubImage, XAddPixel — get, put, and manipulate images

SYNTAX

XImage *XGetImage(Display *display, Drawable d, int x, int y, unsigned int width, unsigned int height, unsigned long plane_mask, int format);


unsigned long XGetPixel(XImage *image, int x, int y);


XPutImage(Display *display, Drawable d, GC gc, XImage *image, int x, int y, int dst_x, int dst_y, unsigned int width, unsigned int height);


XPutPixel(XImage *image, int x, int y, unsigned long pixel);


XImage *XSubImage(XImage *image, int x, int y, unsigned int width, unsigned int height);


void XAddPixel(XImage *image, long value);

ARGUMENTS

All functions accept the following arguments:

display
Specifies the connection to the X server.
d
Specifies the drawable (window or pixmap).
x
Specifies the x-coordinate for the image.
y
Specifies the y-coordinate for the image.
width
Specifies the width for the image.
height
Specifies the height for the image.
plane_mask
Specifies the z-axis plane mask for reading and writing pixels.
format
Specifies the format for the image. It can be XYPixmap, ZPixmap, or PixmapFormat.
gc
Specifies the GC to use for drawing the image.
image
Specifies the image structure.
dst_x
Specifies the destination x-coordinate for the image.
dst_y
Specifies the destination y-coordinate for the image.
pixel
Specifies the pixel value.
value
Specifies the value to add to each pixel.

DESCRIPTION

XGetImage reads a rectangular region of pixels from a drawable and returns them as an XImage structure. The XImage structure contains information about the image, including its format, dimensions, and pixel data.

XGetPixel returns the pixel value at the specified coordinates within an XImage structure.

XPutImage writes a rectangular region of pixels from an XImage structure to a drawable. The gc argument specifies the graphics context to use for drawing.

XPutPixel sets the pixel value at the specified coordinates within an XImage structure.

XSubImage creates a new XImage structure that is a subregion of an existing XImage structure.

XAddPixel adds a value to each pixel in an XImage structure.

DIAGNOSTICS

If the image format is not supported or if the specified coordinates or dimensions are out of range, the following errors may occur:

BadDrawable
A value for a Drawable argument is not a valid Drawable.
BadGC
A value for a GC argument is not a valid GC.
BadMatch
Some argument values are valid but do not make sense together.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.
