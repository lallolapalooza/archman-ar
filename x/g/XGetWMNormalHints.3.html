XGetWMNormalHints(3)

الحزمة: libx11

التراخيص: MIT AND X11

XAllocSizeHints(3) XLIB FUNCTIONS XAllocSizeHints(3)

الاسم

XAllocSizeHints, XSetWMNormalHints, XGetWMNormalHints, XSetWMSizeHints, XGetWMSizeHints, XSizeHints - تخصيص هيكل تلميحات الحجم وتعيين أو قراءة خاصية WM_NORMAL_HINTS لنافذة

الصيغة

XSizeHints *XAllocSizeHints(void);

void XSetWMNormalHints(Display *display, Window w, XSizeHints *hints);

Status XGetWMNormalHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return);

void XSetWMSizeHints(Display *display, Window w, XSizeHints *hints, Atom property);

Status XGetWMSizeHints(Display *display, Window w, XSizeHints *hints_return, long *supplied_return, Atom property);

المعاملات

display
يحدد الاتصال بخادم X.
hints
يحدد تلميحات الحجم للنافذة في حالتها العادية.
hints
يحدد هيكل XSizeHints المراد استخدامه.
hints_return
يعيد تلميحات الحجم للنافذة في حالتها العادية.
property
يحدد اسم الخاصية.
supplied_return
يعيد التلميحات التي تم تقديمها من قبل المستخدم.
w
يحدد النافذة.

الوصف

تخصص الدالة XAllocSizeHints هيكل XSizeHints وتعيد مؤشراً إليه. لاحظ أن جميع الحقول في هيكل XSizeHints يتم تعيينها مبدئيًا إلى الصفر. إذا لم تكن هناك ذاكرة كافية متاحة، تعيد XAllocSizeHints القيمة NULL. لتحرير الذاكرة المخصصة لهذا الهيكل، استخدم XFree.

تستبدل الدالة XSetWMNormalHints تلميحات الحجم لخاصية WM_NORMAL_HINTS على النافذة المحددة. إذا لم تكن الخاصية موجودة بالفعل، تقوم XSetWMNormalHints بتعيين تلميحات الحجم لخاصية WM_NORMAL_HINTS على النافذة المحددة. يتم تخزين الخاصية بنوع WM_SIZE_HINTS وتنسيق 32.

يمكن أن تولد XSetWMNormalHints أخطاء BadAlloc و BadWindow.

تعيد الدالة XGetWMNormalHints تلميحات الحجم المخزنة في خاصية WM_NORMAL_HINTS على النافذة المحددة. إذا كانت الخاصية من نوع WM_SIZE_HINTS، بتنسيق 32، وطويلة بما يكفي لاحتواء هيكل تلميحات حجم قديم (قبل ICCCM) أو جديد، تقوم XGetWMNormalHints بتعيين الحقول المختلفة لهيكل XSizeHints، وتعيين الوسيط supplied_return إلى قائمة الحقول التي تم تقديمها من قبل المستخدم (سواء كانت تحتوي على قيم معرفة أم لا)، وتعيد حالة غير صفرية. بخلاف ذلك، تعيد حالة صفرية.

إذا أعادت XGetWMNormalHints بنجاح وتم قراءة خاصية تلميحات حجم قديمة (قبل ICCCM)، فس تحتوي الوسيط supplied_return على الأجزاء التالية:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

إذا كانت الخاصية طويلة بما يكفي لاحتواء الحجم الأساسي وحقول ميلاد النافذة أيضًا، فس تحتوي الوسيط supplied_return أيضًا على الأجزاء التالية:

PBaseSize|PWinGravity

يمكن أن تولد XGetWMNormalHints خطأ PN BadWindow.

تستبدل الدالة XSetWMSizeHints تلميحات الحجم للخاصية المحددة على النافذة المسماة. إذا لم تكن الخاصية المحددة موجودة بالفعل، تقوم XSetWMSizeHints بتعيين تلميحات الحجم للخاصية المحددة على النافذة المسماة. يتم تخزين الخاصية بنوع WM_SIZE_HINTS وتنسيق 32. لتعيين تلميحات الحجم العادية للنافذة، يمكنك استخدام الدالة XSetWMNormalHints.

يمكن أن تولد XSetWMSizeHints أخطاء BadAlloc و BadAtom و BadWindow.

تعيد الدالة XGetWMSizeHints تلميحات الحجم المخزنة في الخاصية المحددة على النافذة المسماة. إذا كانت الخاصية من نوع WM_SIZE_HINTS، بتنسيق 32، وطويلة بما يكفي لاحتواء هيكل تلميحات حجم قديم (قبل ICCCM) أو جديد، تقوم XGetWMSizeHints بتعيين الحقول المختلفة لهيكل XSizeHints، وتعيين الوسيط supplied_return إلى قائمة الحقول التي تم تقديمها من قبل المستخدم (سواء كانت تحتوي على قيم معرفة أم لا)، وتعيد حالة غير صفرية. بخلاف ذلك، تعيد حالة صفرية. للحصول على تلميحات الحجم العادية للنافذة، يمكنك استخدام الدالة XGetWMNormalHints.

إذا أعادت XGetWMSizeHints بنجاح وتم قراءة خاصية تلميحات حجم قديمة (قبل ICCCM)، فس تحتوي الوسيط supplied_return على الأجزاء التالية:

(USPosition|USSize|PPosition|PSize|PMinSize|
 PMaxSize|PResizeInc|PAspect)

إذا كانت الخاصية طويلة بما يكفي لاحتواء الحجم الأساسي وحقول ميلاد النافذة أيضًا، فس تحتوي الوسيط supplied_return أيضًا على الأجزاء التالية:

PBaseSize|PWinGravity

يمكن أن تولد XGetWMSizeHints أخطاء BadAtom و BadWindow.

الخصائص

WM_NORMAL_HINTS
تلميحات الحجم لنافذة في حالتها العادية. النوع C لهذه الخاصية هو XSizeHints.

الهياكل

يحتوي هيكل XSizeHints على:

/* أقنعة بتات تلميحات الحجم */

#define USPosition (1L << 0) /* المستخدم حدد x، y */
#define USSize (1L << 1) /* المستخدم حدد العرض، الارتفاع */
#define PPosition (1L << 2) /* البرنامج حدد الموضع */
#define PSize (1L << 3) /* البرنامج حدد الحجم */
#define PMinSize (1L << 4) /* البرنامج حدد الحد الأدنى للحجم */
#define PMaxSize (1L << 5) /* البرنامج حدد الحد الأقصى للحجم */
#define PResizeInc (1L << 6) /* البرنامج حدد زيادات إعادة التحجيم */
#define PAspect (1L << 7) /* البرنامج حدد نسب الأبعاد الدنيا والقصوى */
#define PBaseSize (1L << 8)
#define PWinGravity (1L << 9)
#define PAllHints (PPosition| PSize| PMinSize| PMaxSize| PResizeInc| PAspect) 
/* القيم */
typedef struct {
        long flags;     /* يحدد أي الحقول في هذا الهيكل معرفة */
        int x, y;       /* مهمل */
        int width, height;      /* مهمل */
        int min_width, min_height;
        int max_width, max_height;
        int width_inc, height_inc;
        struct {
               int x;   /* البسط */
               int y;   /* المقام */
        } min_aspect, max_aspect;
        int base_width, base_height;
        int win_gravity;
        /* قد يتم توسيع هذا الهيكل في المستقبل */
} XSizeHints;

تم إهمال الأعضاء x و y و width و height الآن، وهي متروكة فقط لأسباب التوافق. تحدد الأعضاء min_width و min_height الحد الأدنى لحجم النافذة الذي لا يزال يسمح للتطبيق بأن يكون مفيدًا. تحدد الأعضاء max_width و max_height الحد الأقصى لحجم النافذة. تحدد الأعضاء width_inc و height_inc متتالية حسابية للأحجام (من الحد الأدنى إلى الحد الأقصى) التي تفضل النافذة إعادة تحجيمها إليها. يتم التعبير عن الأعضاء min_aspect و max_aspect كنسب x و y، وهي تسمح للتطبيق بتحديد نطاق نسب الأبعاد التي يفضلها. تحدد الأعضاء base_width و base_height الحجم المطلوب للنافذة. سيقوم مدير النوافذ بتفسير موضع النافذة وعرض حدودها لوضع نقطة المستطيل الخارجي للنافذة الكلية المحددة بواسطة عضو win_gravity. يشمل المستطيل الخارجي للنافذة أي حدود أو زخارف يوفرها مدير النوافذ. بمعنى آخر، إذا قرر مدير النوافذ وضع النافذة حيث تقع نافذة CLI

NAME

XGetWMNormalHints, XSetWMNormalHints — set or get window manager properties for normal-sized hints

SYNTAX

Bool XGetWMNormalHints
    (Display *display, Window w, XWMHints **hints_ret, Bool *supplied_ret);
Status XSetWMNormalHints
    (Display *display, Window w, XWMHints *hints);

ARGUMENTS

...

DESCRIPTION

The XGetWMNormalHints function retrieves the WM_NORMAL_HINTS property from the specified window w on the specified display display. It returns the retrieved hints in the structure pointed to by hints_ret. If the property was not set, supplied_ret will be False. Otherwise, it will be True. If the property was set, the caller is responsible for freeing the memory allocated for the structure pointed to by hints_ret using XFree().

The XSetWMNormalHints function sets the WM_NORMAL_HINTS property on the specified window w on the specified display display. The hints are taken from the structure pointed to by hints. This function returns zero on success, and a non-zero value on failure. The window manager uses the contents of the WM_NORMAL_HINTS property to determine how a window can be resized.

PROPERTIES

WM_NORMAL_HINTS

STRUCTURES

The XWMHints structure is defined in <X11/Xutil.h> as follows:

typedef struct {
    int flags;
    XIconPosition x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int base_width, base_height;
    double width_inc, height_inc;
    XCoord gravity;
} XWMHints;

The fields are:

flags
A bitmask specifying which fields in this structure are set. The possible bits are IconPositionHint, IconSizeHint, MinSizeHint, MaxSizeHint, BaseSizeHint, GravityHint, AllHints, and PositionHint.
x, y
The x and y coordinates for the top-left corner of the application's icon window relative to the P's hot-spot.
width, height
The desired width and height of the application window.
min_width, min_height
The minimum width and height of the window.
max_width, max_height
The maximum width and height of the window.
base_width, base_height
The base width and height of the window. The window size can be expressed as width = base_width + (width_inc * number_of_width_increments) and height = base_height + (height_inc * number_of_height_increments).
width_inc, height_inc
The increments for width and height. These are used in conjunction with the base_width and base_height fields to specify the allowable dimensions of the window.
gravity
The window gravity for the window. This specifies the location on the parent window's border named by the win_gravity will be placed where the client window would have been placed in the absence of a window manager.

Note that use of the PAllHints macro is highly discouraged.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadAtom
A value for an Atom argument does not name a defined Atom.
BadWindow
A value for a Window argument does not name a defined Window.

الوصف

تقوم الدالة XGetWMNormalHints باسترداد الخاصية WM_NORMAL_HINTS من النافذة المحددة w على الشاشة المحددة display. وتعيد التلميحات المستردة في الهيكل المشار إليه بواسطة hints_ret. إذا لم يتم تعيين الخاصية، فسيكون supplied_ret خطأ (False). بخلاف ذلك، سيكون صحيحًا (True). إذا تم تعيين الخاصية، فإن المتصل مسؤول عن تحرير الذاكرة المخصصة للهيكل المشار إليه بواسطة hints_ret باستخدام XFree().

تقوم الدالة XSetWMNormalHints بتعيين الخاصية WM_NORMAL_HINTS على النافذة المحددة w على الشاشة المحددة display. يتم أخذ التلميحات من الهيكل المشار إليه بواسطة hints. تعيد هذه الدالة صفرًا عند النجاح، وقيمة غير صفرية عند الفشل. يستخدم مدير النوافذ محتويات الخاصية WM_NORMAL_HINTS لتحديد كيفية تغيير حجم النافذة.

الخصائص

WM_NORMAL_HINTS

الهياكل

يتم تعريف الهيكل XWMHints في <X11/Xutil.h> على النحو التالي:

typedef struct {
    int flags;
    XIconPosition x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int base_width, base_height;
    double width_inc, height_inc;
    XCoord gravity;
} XWMHints;

الحقول هي:

flags
قناع بت يحدد الحقول الموجودة في هذا الهيكل. القيم الممكنة هي IconPositionHint، IconSizeHint، MinSizeHint، MaxSizeHint، BaseSizeHint، GravityHint، AllHints، و PositionHint.
x، y
إحداثيات x و y للزاوية العلوية اليسرى لنافذة أيقونة التطبيق بالنسبة لنقطة الاتصال (hot-spot).
width، height
العرض والارتفاع المطلوبان لنافذة التطبيق.
min_width، min_height
الحد الأدنى للعرض والارتفاع للنافذة.
max_width، max_height
الحد الأقصى للعرض والارتفاع للنافذة.
base_width، base_height
العرض والارتفاع الأساسيان للنافذة. يمكن التعبير عن حجم النافذة كـ width = base_width + (width_inc * number_of_width_increments) و height = base_height + (height_inc * number_of_height_increments).
width_inc، height_inc
زيادات العرض والارتفاع. تُستخدم هذه بالاقتران مع الحقول base_width و base_height لتحديد الأبعاد المسموح بها للنافذة.
gravity
جاذبية النافذة (window gravity) للنافذة. يحدد هذا الموقع على حدود النافذة الأصلية المسماة بواسطة win_gravity حيث سيتم وضع نافذة العميل في حالة عدم وجود مدير نوافذ.

لاحظ أن استخدام الماكرو PAllHints غير مستحسن بشدة.
