XGetWMHints(3)

الحزمة: libx11

التراخيص: MIT AND X11

XGetWMHints

XGetWMHints - الحصول على تلميحات نافذة مدير النوافذ

الاسم

XGetWMHints - الحصول على تلميحات نافذة مدير النوافذ

الصيغة

int XGetWMHints(
    Display *display,
    Window w,
    XWMHints **wmhints_return
);

المعاملات

  • display: يحدد اتصال الخادم.
  • w: يحدد النافذة التي تريد الحصول على تلميحاتها.
  • wmhints_return: مؤشر إلى مؤشر XWMHints، حيث يتم إرجاع التلميحات.

الوصف

يقوم XGetWMHints باسترداد تلميحات نافذة مدير النوافذ للنافذة المحددة w من الخادم display. يتم تخزين البيانات المستردة في بنية XWMHints التي يشير إليها wmhints_return. يجب على المستدعي تخصيص الذاكرة لهذه البنية.

الخصائص

بنية XWMHints تحتوي على الحقول التالية:

  • flags: مجموعة من العلامات التي تحدد الحقول الموجودة في البنية.
  • initial_state: الحالة الأولية للنافذة (مثلاً، NormalState أو IconicState).
  • icon_pixmap: رمز النافذة.
  • icon_window: نافذة الأيقونة.
  • icon_x، icon_y: موقع نافذة الأيقونة.
  • normal_hints: تلميحات النافذة القياسية (مثل حجم النافذة).

الهياكل

typedef struct {
    long flags;
    int initial_state;
    Pixmap icon_pixmap;
    Window icon_window;
    int icon_x;
    int icon_y;
    XSizeHints normal_hints;
} XWMHints;

التشخيص

إذا فشل استرداد تلميحات نافذة مدير النوافذ، فستعيد الدالة 0، وإلا فإنها تعيد قيمة غير صفرية.
