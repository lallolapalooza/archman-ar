xgettext(1)

الحزمة: gettext

التراخيص: GFDL-1.2-only, GPL-2.0-only, GPL-2.0-or-later, LGPL-2.0-only

XGETTEXT(1) أوامر المستخدم XGETTEXT(1)

الاسم

xgettext - استخراج سلاسل gettext من المصدر

الملخص

xgettext [خيار] [ملف_إدخال]...

الوصف

استخراج السلاسل القابلة للترجمة من ملفات الإدخال المعطاة.

الوسائط الإلزامية للخيار الطويل إلزامية للخيار القصير أيضًا. وبالمثل للوسائط الاختيارية.

موقع ملف الإدخال:

INPUTFILE ...
ملفات الإدخال
-f, --files-from=ملف
الحصول على قائمة بملفات الإدخال من الملف
-D, --directory=مجلد
إضافة المجلد إلى قائمة البحث عن ملفات الإدخال

إذا كان ملف الإدخال هو -، يتم قراءة الإدخال القياسي.

موقع ملف الإخراج:

-d, --default-domain=اسم
استخدام NAME.po للإخراج (بدلاً من messages.po)
-o, --output=ملف
كتابة الإخراج إلى الملف المحدد
-p, --output-dir=مجلد
سيتم وضع ملفات الإخراج في المجلد DIR

إذا كان ملف الإخراج هو -، يتم كتابة الإخراج إلى الإخراج القياسي.

اختيار لغة ملف الإدخال:

-L, --language=اسم
التعرف على اللغة المحددة (C، C++، ObjectiveC، PO، Python، Java، JavaProperties، C#، JavaScript، TypeScript، TSX، Scheme، Guile، Lisp، EmacsLisp، librep، Rust، Go، Ruby، Shell، awk، Lua، Modula-2، D، Smalltalk، Vala، Tcl، Perl، PHP، GCC-source، YCP، NXStringTable، RST، RSJ، Glade، GSettings، Desktop)
-C, --c++
اختصار لـ --language=C++

بشكل افتراضي، يتم تخمين اللغة اعتمادًا على امتداد اسم ملف الإدخال.

تفسير ملف الإدخال:

--from-code=اسم
ترميز ملفات الإدخال (باستثناء Python، Tcl، Glade)

بشكل افتراضي، يُفترض أن ملفات الإدخال هي بتنسيق ASCII.

وضع التشغيل:

-j, --join-existing
ضم الرسائل مع الملف الموجود
-x, --exclude-file=ملف.po
لا يتم استخراج الإدخالات من FILE.po
-cTAG, --add-comments=علامة
وضع كتل التعليقات التي تبدأ بالعلامة وتسبق أسطر الكلمات المفتاحية في ملف الإخراج
-c, --add-comments
وضع جميع كتل التعليقات التي تسبق أسطر الكلمات المفتاحية في ملف الإخراج
--check=اسم
إجراء فحص نحوي للرسائل (ellipsis-unicode، space-ellipsis،
quote-unicode، bullet-unicode)
--sentence-end=نوع
نوع يصف نهاية الجملة (مسافة واحدة، وهو الافتراضي،
أو مسافة مزدوجة)

خيارات خاصة باللغة:

-a, --extract-all
استخراج جميع السلاسل (لغات C، C++، ObjectiveC، Python، Java، C#، JavaScript، TypeScript، TSX، Scheme، Guile، Lisp، EmacsLisp، librep، Rust، Go، Shell، awk، Lua، Modula-2، D، Vala، Tcl، Perl، PHP، GCC-source، Glade، GSettings فقط)
-kWORD, --keyword=كلمة
البحث عن كلمة ككلمة مفتاحية إضافية
-k, --keyword
عدم استخدام الكلمات المفتاحية الافتراضية (لغات C، C++، ObjectiveC، Python، Java، C#، JavaScript، TypeScript، TSX، Scheme، Guile، Lisp، EmacsLisp، librep، Rust، Go، Shell، awk، Lua، Modula-2، D، Vala، Tcl، Perl، PHP، GCC-source، Glade، GSettings، Desktop فقط)
--flag=كلمة:ARG:علامة
علامة إضافية للسلاسل داخل الوسيط رقم ARG من الكلمة المفتاحية WORD
(لغات C، C++، ObjectiveC، Python فقط،
Java، C#، JavaScript، TypeScript، TSX، Scheme، Guile، Lisp، EmacsLisp، librep، Rust، Go، Shell، awk، Lua، Modula-2، D، Vala، Tcl، Perl، PHP، GCC-source، YCP)
--tag=كلمة:تنسيق
يحدد سلوك قوالب النصوص الموسومة بالوسم WORD
(لغة JavaScript فقط)
-T, --trigraphs
فهم ثلاثيات ANSI C للإدخال (مهملة؛ لغات C، C++، ObjectiveC فقط)
--its=ملف
تطبيق قواعد ITS من الملف (للغات المستندة إلى XML فقط)
--qt
التعرف على سلاسل تنسيق Qt (لغة C++ فقط)
--kde
التعرف على سلاسل تنسيق KDE 4 (لغة C++ فقط)
--boost
التعرف على سلاسل تنسيق Boost (لغة C++ فقط)
--debug
نتائج أكثر تفصيلاً للتعرف على تنسيق السلسلة

تفاصيل الإخراج:

--color
استخدام الألوان والسمات النصية الأخرى دائمًا
--color=متى
استخدام الألوان والسمات النصية الأخرى إذا كان WHEN. WHEN يمكن أن يكون 'always' (دائمًا)، 'never' (أبدًا)، 'auto' (تلقائي)، أو 'html'.
--style=ملف_نمط
تحديد ملف قواعد CSS لـ --color
-e, --no-escape
عدم استخدام فواصل C في الإخراج (افتراضي)
-E, --escape
استخدام فواصل C في الإخراج، لا أحرف موسعة
--force-po
كتابة ملف PO حتى لو كان فارغًا
-i, --indent
كتابة ملف .po باستخدام نمط المسافات البادئة
--no-location
عدم كتابة أسطر '#: filename:line'
-n, --add-location
إنشاء أسطر '#: filename:line' (افتراضي)
--strict
كتابة ملف .po متوافق تمامًا مع Uniforum
--properties-output
كتابة ملف .properties بلغة Java
--stringtable-output
كتابة ملف .strings بتنسيق NeXTstep/GNUstep
--itstool
كتابة تعليقات itstool
-w, --width=عدد
تعيين عرض صفحة الإخراج
--no-wrap
عدم كسر أسطر الرسائل الطويلة، التي تزيد عن عرض صفحة الإخراج، إلى عدة أسطر
