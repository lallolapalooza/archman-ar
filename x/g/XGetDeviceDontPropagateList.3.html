XGetDeviceDontPropagateList(3)

الحزمة: libxi

التراخيص: MIT-open-group, SMLNJ, MIT

XCHANGEDEVICEDONTPRO(3)   XCHANGEDEVICEDONTPRO(3)

NAME

XChangeDeviceDontPropagateList, XGetDeviceDontPropagateList - استعلام أو تغيير قائمة عدم الانتشار للأجهزة الموسعة

SYNOPSIS

#include <X11/extensions/XInput.h>
int XChangeDeviceDontPropagateList( Display *display,
                                    Window window,
                                    int count,
                                    XEventClass *event_list,
                                    int mode);
XEventClass* XGetDeviceDontPropagateList( Display *display,
                                          Window window,
                                          int *count);
display
       يحدد الاتصال بخادم X.
window
       يحدد النافذة التي سيتم استعلام أو تعديل قائمة عدم الانتشار الخاصة بها.
event_list
       يحدد مؤشرًا إلى قائمة فئات الأحداث.
mode
       يحدد الوضع. يمكنك تمرير AddToList، أو
       DeleteFromList.
count
       يحدد عدد فئات الأحداث في القائمة.

DESCRIPTION

يقوم طلب XChangeDeviceDontPropagateList بتعديل قائمة الأحداث التي
    لا ينبغي نشرها إلى نوافذ الأصل للنافذة الحدث. يسمح هذا الطلب بإضافة
    أحداث الامتداد إلى تلك القائمة أو حذفها منها. بشكل افتراضي، يتم نشر جميع
    الأحداث إلى نوافذ الأصل. بمجرد تعديلها، تظل القائمة معدلة طوال عمر
    النافذة. لا تتم إزالة الأحداث من القائمة لأن العميل الذي أضافها قد انتهى.
لا يُسمح بقمع انتشار الأحداث لجميع أحداث امتداد الإدخال. إذا كانت فئة
    الحدث المحددة هي فئة لا يمكن قمعها، فسيؤدي ذلك إلى خطأ BadClass.
الأحداث التي يمكن قمعها تشمل DeviceKeyPress، DeviceKeyRelease، DeviceButtonPress، DeviceButtonRelease، DeviceMotionNotify، ProximityIn، و ProximityOut. 
يمكن لـ XChangeDeviceDontPropagateList إنشاء خطأ BadDevice أو BadClass أو
    BadValue.
يستعلم طلب XGetDeviceDontPropagateList عن قائمة الأحداث التي لا ينبغي
    نشرها إلى نوافذ الأصل للنافذة الحدث.
يمكن لـ XGetDeviceDontPropagateList إنشاء خطأ BadClass أو BadWindow.

DIAGNOSTICS

BadDevice
       تم تحديد جهاز غير صالح. الجهاز المحدد غير موجود أو لم يتم
       فتحه بواسطة هذا العميل عبر XOpenInputDevice. قد يحدث هذا
       الخطأ أيضًا إذا قام عميل آخر بتسبب في أن يصبح الجهاز المحدد
       جهاز لوحة مفاتيح X أو جهاز مؤشر X عبر طلبات
       XChangeKeyboardDevice أو XChangePointerDevice.
BadValue
       تقع قيمة رقمية ما خارج نطاق القيم التي يقبلها الطلب. ما لم
       يتم تحديد نطاق معين لحجة، يتم قبول النطاق الكامل الذي
       تحدده نوع الحجة. أي حجة محددة كمجموعة من البدائل يمكن
       أن تولد هذا الخطأ.
BadWindow
       تم تحديد معرف نافذة غير صالح.
BadClass
       تم تحديد فئة حدث غير صالحة.
