XGetVisualInfo(3)

الحزمة: libx11

التراخيص: MIT AND X11

XGetVisualInfo(3) وظائف XLIB XGetVisualInfo(3)

الاسم

XGetVisualInfo، XMatchVisualInfo، XVisualIDFromVisual، XVisualInfo - الحصول على معلومات الرؤية وهيكل الرؤية

الصيغة

XVisualInfo *XGetVisualInfo(Display *display، long vinfo_mask، XVisualInfo *vinfo_template، int *nitems_return)؛

Status XMatchVisualInfo(Display *display، int screen، int depth، int class، XVisualInfo *vinfo_return)؛

VisualID XVisualIDFromVisual(Visual *visual)؛

الوسائط

class
يحدد فئة الشاشة.
depth
يحدد عمق الشاشة.
display
يحدد الاتصال بخادم X.
nitems_return
يعيد عدد هياكل الرؤية المطابقة.
screen
يحدد الشاشة.
visual
يحدد نوع الرؤية.
vinfo_mask
يحدد قيمة قناع الرؤية.
vinfo_return
يعيد معلومات الرؤية المطابقة.
vinfo_template
يحدد سمات الرؤية التي سيتم استخدامها في مطابقة هياكل الرؤية.

الوصف

ترجع الدالة XGetVisualInfo قائمة بهياكل الرؤية التي لها سمات متساوية مع السمات المحددة بواسطة vinfo_template. إذا لم تتطابق أي هياكل رؤية مع القالب باستخدام vinfo_mask المحدد، فإن XGetVisualInfo ترجع NULL. لتحرير البيانات التي ترجعها هذه الدالة، استخدم XFree.

ترجع الدالة XMatchVisualInfo معلومات الرؤية لرؤية تتطابق مع العمق والفئة المحددين لشاشة. نظرًا لأنه يمكن أن توجد عدة رؤى تتطابق مع العمق والفئة المحددين، فإن الرؤية الدقيقة المختارة غير محددة. إذا تم العثور على رؤية، فإن XMatchVisualInfo ترجع قيمة غير صفرية والمعلومات على الرؤية إلى vinfo_return. بخلاف ذلك، عندما لا يتم العثور على رؤية، ترجع XMatchVisualInfo صفرًا.

ترجع الدالة XVisualIDFromVisual معرف الرؤية لنوع الرؤية المحدد.

الهياكل

يحتوي هيكل XVisualInfo على:

/* بتات قناع معلومات الرؤية */

#define VisualNoMask 0x0
#define VisualIDMask 0x1
#define VisualScreenMask 0x2
#define VisualDepthMask 0x4
#define VisualClassMask 0x8
#define VisualRedMaskMask 0x10
#define VisualGreenMaskMask 0x20
#define VisualBlueMaskMask 0x40
#define VisualColormapSizeMask 0x80
#define VisualBitsPerRGBMask 0x100
#define VisualAllMask 0x1FF 
/* القيم */
typedef struct {
        Visual *visual;
        VisualID visualid;
        int screen;
        int depth;
        int class;
        unsigned long red_mask;
        unsigned long green_mask;
        unsigned long blue_mask;
        int colormap_size;
        int bits_per_rgb;
} XVisualInfo;
