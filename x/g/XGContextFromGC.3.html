The planes attribute is of type long, and it specifies which planes\n of the destination are to be modified, one bit per plane. A monochrome\n display has only one plane and will be the least significant bit of the\n word. In graphics operations, given a source and destination pixel, the\n result is computed bitwise on corresponding bits of the pixels. That is, a\n Boolean operation is performed in each bit plane.
