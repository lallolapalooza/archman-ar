XGetWMSizeHints(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XGetWMSizeHints — get window manager size hints

SYNTAX

Boolean XGetWMSizeHints(Display *display, Window w,
      XWMSizeHints **size_props_return, long *supplied_return);

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
size_props_return
When the function returns, contains a pointer to the XWMSizeHints structure containing the size hints, or NULL if no size hints are available.
supplied_return
When the function returns, contains a bitmask indicating which fields in the XWMSizeHints structure are valid.

DESCRIPTION

The XGetWMSizeHints function retrieves the WM_NORMAL_HINTS property for the specified window and returns it.

If the WM_NORMAL_HINTS property is not set or is not of the correct type, the function returns False and sets *size_props_return to NULL and *supplied_return to 0.

If the property is retrieved successfully, the function allocates memory for the XWMSizeHints structure, fills it with the property data, and returns True. The caller is responsible for freeing this memory using XFree when it is no longer needed.

The *supplied_return argument is a bitmask that indicates which fields in the XWMSizeHints structure are valid. The possible bits are defined in <X11/Xutil.h> as:

#define PPosition (1L << 0)
#define PSize (1L << 1)
#define PMinSize (1L << 2)
#define PAspect (1L << 3)
#define PMaxSize (1L << 4)
#define PResizeInc (1L << 5)
#define PWinGravity (1L << 6)

If the PPosition bit is set, the x and y members are valid.

If the PSize bit is set, the width and height members are valid.

If the PMinSize bit is set, the min_width and min_height members are valid.

If the PAspect bit is set, the min_aspect.x , min_aspect.y , max_aspect.x , and max_aspect.y members are valid.

If the PMaxSize bit is set, the max_width and max_height members are valid.

If the PResizeInc bit is set, the width_inc and height_inc members are valid.

If the PWinGravity bit is set, the win_gravity member is valid.

The window manager uses these hints to determine how the client window should be resized and positioned.

PROPERTIES

WM_NORMAL_HINTS

STRUCTURES

XWMSizeHints
typedef struct {
    long flags;
    int x, y;
    int width, height;
    int min_width, min_height;
    int max_width, max_height;
    int width_inc, height_inc;
    struct {
        int x, y;
    } min_aspect, max_aspect;
    int win_gravity;
} XWMSizeHints;

The win_gravity field specifies the gravity of the window on the parent window's border. If PWinGravity is set, the position on the parent window's border named by the win_gravity will be placed where the client window would have been placed in the absence of a window manager.

Note that use of the PAllHints macro is highly discouraged.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadAtom
A value for an Atom argument does not name a defined Atom.
BadWindow
A value for a Window argument does not name a defined Window.

الاسم

XGetWMSizeHints — الحصول على تلميحات حجم مدير النوافذ

الصيغة

Boolean XGetWMSizeHints(Display *display, Window w,
      XWMSizeHints **size_props_return, long *supplied_return);

المعاملات

display
يحدد الاتصال بخادم X.
w
يحدد النافذة.
size_props_return
عندما تعود الدالة، تحتوي على مؤشر إلى بنية XWMSizeHints تحتوي على تلميحات الحجم، أو NULL إذا لم تكن هناك تلميحات حجم متاحة.
supplied_return
عندما تعود الدالة، تحتوي على قناع بت يشير إلى أي حقول في بنية XWMSizeHints صالحة.

الوصف

تقوم الدالة XGetWMSizeHints باسترداد خاصية WM_NORMAL_HINTS للنافذة المحددة وإعادتها.

إذا لم يتم تعيين الخاصية WM_NORMAL_HINTS أو لم تكن من النوع الصحيح، فإن الدالة تعود بالقيمة False وتعيّن *size_props_return إلى NULL و *supplied_return إلى 0.

إذا تم استرداد الخاصية بنجاح، فإن الدالة تخصص ذاكرة لبنية XWMSizeHints ، وتملأها ببيانات الخاصية، وتعيد True. يتحمل المستدعي مسؤولية تحرير هذه الذاكرة باستخدام XFree عندما لم تعد مطلوبة.

الوسيط *supplied_return هو قناع بت يشير إلى أي حقول في بنية XWMSizeHints صالحة. يمكن تعريف الأقنعة الممكنة في <X11/Xutil.h> على النحو التالي:

#define PPosition (1L << 0)
#define PSize (1L << 1)
#define PMinSize (1L << 2)
#define PAspect (1L << 3)
#define PMaxSize (1L << 4)
#define PResizeInc (1L << 5)
#define PWinGravity (1L << 6)

إذا تم تعيين بت PPosition ، فإن الأعضاء x و y صالحة.

إذا تم تعيين بت PSize ، فإن الأعضاء width و height صالحة.

إذا تم تعيين بت PMinSize ، فإن الأعضاء min_width و min_height صالحة.

إذا تم تعيين بت PAspect ، فإن الأعضاء min_aspect.x ، min_aspect.y ، max_aspect.x ، و max_aspect.y صالحة.

إذا تم تعيين بت PMaxSize ، فإن الأعضاء max_width و max_height صالحة.

إذا تم تعيين بت PResizeInc ، فإن الأعضاء width_inc و height_inc صالحة.

إذا تم تعيين بت PWinGravity ، فإن العضو win_gravity صالحة.

يستخدم مدير النوافذ هذه التلميحات لتحديد كيفية تغيير حجم النافذة العميل وتحديد موضعها.

الخصائص

WM_NORMAL_HINTS

البنى

    int x, y;
    int width, height;
    int min_width, min_height;

        int x, y;
    } min_aspect, max_aspect;

يحدد الحقل win_gravity جاذبية النافذة على حدود النافذة الأصل. إذا تم تعيين PWinGravity ، فسيتم وضع الموضع على حدود النافذة الأصل المسماة بواسطة win_gravity حيث كان من المفترض أن يتم وضع نافذة العميل في حالة عدم وجود مدير نوافذ.

لاحظ أن استخدام الماكرو PAllHints غير مستحسن للغاية.
