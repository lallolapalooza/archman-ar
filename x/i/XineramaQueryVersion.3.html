XineramaQueryVersion(3)

الحزمة: libxinerama

التراخيص: MIT, MIT-open-group, X11

XINERAMA(3) دليل وظائف المكتبة XINERAMA(3)

الاسم

Xinerama - واجهة برمجة التطبيقات لملحق Xinerama لبروتوكول X11

الملخص

#include <X11/extensions/Xinerama.h>

Bool XineramaQueryExtension (Display *dpy,
	int *event_base_return, int *error_base_return);

Status XineramaQueryVersion (Display *dpy,
	int *major_version_return,
	int *minor_version_return);

Bool XineramaIsActive (Display *dpy);

XineramaScreenInfo * XineramaQueryScreens (Display *dpy,
	int *number);

الوسائط

display
يحدد الاتصال بخادم X.
event_base_return
يحدد موقع الإرجاع لرمز الحدث الأساسي المعين
error_base_return
يحدد موقع الإرجاع لرمز الخطأ الأساسي المعين
major_version_return
يعيد الإصدار الرئيسي الذي يدعمه الخادم
minor_version_return
يعيد الإصدار الفرعي الذي يدعمه الخادم
number
يعيد عدد الإدخالات في مصفوفة XineramaScreenInfo المرجعة.

الوصف

Xinerama هي مكتبة بسيطة مصممة للتفاعل مع ملحق Xinerama للحصول على معلومات حول أجهزة الإخراج المادية التي يمكن دمجها في شاشة X منطقية واحدة.

الوظائف

XineramaQueryExtension()

تستعلم وظيفة XineramaQueryExtension من خادم X لتحديد توفر ملحق Xinerama. إذا كان الملحق متاحًا، تكون القيمة المرجعة True، ويتم تعيين event_base_return و error_base_return إلى رقم الحدث الأساسي ورقم الخطأ الأساسي للملحق، على التوالي. بخلاف ذلك، تكون القيمة المرجعة False، وقيم event_base_return و error_base_return غير محددة.

XineramaQueryVersion()

تعيد وظيفة XineramaQueryVersion إصدار ملحق Xinerama الذي ينفذه خادم X. يتم إرجاع الإصدار في major_version_return و minor_version_return. سيتم زيادة الإصدار الرئيسي للتغييرات غير المتوافقة مع البروتوكول، وسيتم زيادة الإصدار الفرعي للتغييرات الصغيرة المتوافقة تصاعديًا.

إذا كانت مكتبة Xinerama متوافقة مع الإصدار الذي أعاده الخادم، فإنها تعيد قيمة غير صفرية. إذا لم يدعم الخادم ملحق XINERAMA، أو إذا حدث خطأ أثناء الاتصالات مع الخادم، أو إذا كانت إصدارات بروتوكول الخادم والمكتبة غير متوافقة، فإنها تعيد صفرًا.

XineramaIsActive()

تعيد وظيفة XineramaIsActive عامل تشغيل منطقي يستخدم لتحديد ما إذا كان Xinerama نشطًا على الشاشة. تعيد True للنشط و False لغير النشط.

XineramaQueryScreens()

تعيد وظيفة XineramaQueryScreens() معلومات حول كل جهاز إخراج فردي داخل شاشة Xinerama. يتم تحديث العدد الصحيح المشار إليه بواسطة الوسيط number إلى عدد أجهزة الإخراج المدرجة في المصفوفة المرجعة لهياكل XineramaScreenInfo. تعيد XineramaQueryScreens() القيمة NULL وتعين number إلى 0 إذا كان Xinerama غير نشط.

يجب تحرير المؤشر المرجع باستخدام XFree(3) عند عدم الحاجة إليه.

ملاحظة

استخدمت واجهة برمجة التطبيقات الأصلية المقدمة للتفاعل مع ملحق XINERAMA أسماء وظائف تبدأ بـ XPanoramiX. تم إيقاف هذه الواجهة الآن ويجب استخدام هذه الواجهة بدلاً منها في البرامج الجديدة.
