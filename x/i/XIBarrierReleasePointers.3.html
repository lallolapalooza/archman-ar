XIBarrierReleasePointers(3)

الحزمة: libxi

التراخيص: MIT-open-group, SMLNJ, MIT

XIBARRIERRELEASEPOIN(3)   XIBARRIERRELEASEPOIN(3)

الاسم

XIBarrierReleasePointer, XIBarrierReleasePointers - السماح لحركة المؤشر عبر حاجز المؤشر

الملخص

#include <X11/extensions/XInput2.h>
int XIBarrierReleasePointer( Display *display,
                             int deviceid,
                             PointerBarrier barrier,
                             BarrierEventID eventid);
int XIBarrierReleasePointers( Display *display,
                              XIBarrierReleasePointerInfo *barriers,
                              int num_barriers);
display
       يحدد الاتصال بخادم X.
deviceid
       يحدد الجهاز المسموح له بالحركة عبر الحاجز.
barrier
       يحدد الحاجز.
eventid
       يحدد معرف الحدث الفريد لتسلسل أحداث الحاجز هذا.
barriers
       قائمة بالمعرفات الثلاثية (deviceid، barrier، eventid).
num_barriers
       عدد العناصر في barriers.

الوصف

إذا كان المؤشر مقيدًا بحاجز مؤشر، فقم بتحرير المؤشر من الحاجز واسمح له بالعبور مع الحركة التالية.
إذا ابتعد المؤشر عن الحاجز، فلن يقوم هذا الطلب بأي شيء.
هذا الطلب يحرر المؤشر فقط لتسلسل أحداث الحاجز المحدد. إذا تحرك المؤشر بعيدًا عن الحاجز أو عبره، يتم إنشاء حدث XI_BarrierLeave. سيتم تعيين معرف حدث جديد لحركة المؤشر المستقبلية المقيدة بهذا الحاجز، وسيتطلب طلب XIBarrierReleasePointer جديد.
إذا لم يكن المؤشر محظورًا حاليًا بواسطة الحاجز أو انتهى تسلسل أحداث الحاجز، فلن يقوم هذا الطلب بأي شيء.
يمكن لـ XIBarrierReleasePointer و XIBarrierReleasePointers إنشاء خطأ BadDevice أو BadValue.

التشخيصات

BadDevice
       تم تحديد جهاز غير صالح. الجهاز غير موجود أو ليس جهاز مؤشر رئيسي.
BadValue
       قيمة لوسيط PointerBarrier لا تشير إلى حاجز مؤشر محدد.
