XIUngrabKeycode(3)

الحزمة: libxi

التراخيص: MIT-open-group, SMLNJ, MIT

NAME

XIUngrabKeycode, XIUngrabButton, XIUngrabKeyboard, XIUngrabPointer,
XIUngrabTouchBegin, XIUngrabPinchGestureBegin and XIUngrabSwipeGestureBegin
- Ungrab devices.

SYNOPSIS

#include <X11/extensions/XInput.h>

int XIUngrabKeycode(
    Display *dpy,
    int deviceid,
    int first_keycode,
    int count,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);
int XIUngrabButton(
    Display *dpy,
    int deviceid,
    int button,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);
int XIUngrabKeyboard(
    Display *dpy,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);
int XIUngrabPointer(
    Display *dpy,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);
int XIUngrabTouchBegin(
    Display *dpy,
    int deviceid,
    int num_touches,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);
int XIUngrabPinchGestureBegin(
    Display *dpy,
    int deviceid,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);
int XIUngrabSwipeGestureBegin(
    Display *dpy,
    int deviceid,
    unsigned int modifiers,
    XIGrabModifiersState *modifiers_inout
);

DESCRIPTION

The XIUngrabKeycode function releases the passive grab on the specified
keycodes of the specified device. The grab is released on keycodes
first_keycode through first_keycode + count - 1, using the specified
modifiers. Only those modifiers which are currently active are masked out.
All further active modifiers are passed through.

The XIUngrabButton function releases the passive grab on the specified
button of the specified device. The grab is released on button, using the
specified modifiers. Only those modifiers which are currently active are masked
out. All further active modifiers are passed through.

The XIUngrabKeyboard function releases all passive grabs on the keyboard.
The grab is released on all keys, using the specified modifiers. Only those
modifiers which are currently active are masked out. All further active
modifiers are passed through.

The XIUngrabPointer function releases all passive grabs on the pointer.
The grab is released on all buttons, using the specified modifiers. Only
those modifiers which are currently active are masked out. All further
active modifiers are passed through.

The XIUngrabTouchBegin function releases the passive grab on touch events.
The grab is released on the specified device, with the specified number of
touches, using the specified modifiers. Only those modifiers which are
currently active are masked out. All further active modifiers are passed
through.

The XIUngrabPinchGestureBegin function releases the passive grab on pinch
gestures. The grab is released on the specified device, using the specified
modifiers. Only those modifiers which are currently active are masked out.
All further active modifiers are passed through.

The XIUngrabSwipeGestureBegin function releases the passive grab on swipe
gestures. The grab is released on the specified device, using the specified
modifiers. Only those modifiers which are currently active are masked out.
All further active modifiers are passed through.

All functions may generate BadDevice, BadMatch, BadValue and BadWindow errors.

RETURN VALUE

XIGrabButton, XIGrabKeycode, XIGrabTouchBegin and
XIGrabPinchGestureBegin and XIGrabSwipeGestureBegin return the number of
modifier combination that could not establish a passive grab. The
modifiers are returned in modifiers_inout, along with the respective
error for this modifier combination. If XIGrabButton, XIGrabKeycode
or XIGrabTouchBegin return zero, passive grabs with all requested
modifier combinations were established successfully.

DIAGNOSTICS

BadDevice
       An invalid deviceid was specified.
BadMatch
       This error may occur if XIGrabButton specified a device
       that has no buttons, or XIGrabKeycode specified a device
       that has no keys,
       or XIGrabTouchBegin specified a device that is not touch-capable,
       or XIGrabPinchGestureBegin specified a device that is not gesture-capable,
       or XIGrabSwipeGestureBegin specified a device that is not gesture-capable.
BadValue
       Some numeric value falls outside the range of values
       accepted by the request. Unless a specific range is
       specified for an argument, the full range defined by the
       argument's type is accepted. Any argument defined as a
       set of alternatives can generate this error.
BadWindow
       A value for a Window argument does not name a defined
       Window.

BUGS

The protocol headers for XI 2.0 did not provide
XIGrabModeAsync or XIGrabModeSync. Use GrabModeSync and
GrabModeAsync instead, respectively.

الوصف

تقوم الدالة XIUngrabKeycode بتحرير الاستيلاء السلبي على رموز المفاتيح المحددة للجهاز المحدد. يتم تحرير الاستيلاء على رموز المفاتيح من first_keycode إلى first_keycode + count - 1، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

تقوم الدالة XIUngrabButton بتحرير الاستيلاء السلبي على الزر المحدد للجهاز المحدد. يتم تحرير الاستيلاء على الزر، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

تقوم الدالة XIUngrabKeyboard بتحرير جميع عمليات الاستيلاء السلبي على لوحة المفاتيح. يتم تحرير الاستيلاء على جميع المفاتيح، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

تقوم الدالة XIUngrabPointer بتحرير جميع عمليات الاستيلاء السلبي على المؤشر. يتم تحرير الاستيلاء على جميع الأزرار، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

تقوم الدالة XIUngrabTouchBegin بتحرير الاستيلاء السلبي على أحداث اللمس. يتم تحرير الاستيلاء على الجهاز المحدد، مع العدد المحدد للمسات، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

تقوم الدالة XIUngrabPinchGestureBegin بتحرير الاستيلاء السلبي على إيماءات القرص. يتم تحرير الاستيلاء على الجهاز المحدد، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

تقوم الدالة XIUngrabSwipeGestureBegin بتحرير الاستيلاء السلبي على إيماءات المسح. يتم تحرير الاستيلاء على الجهاز المحدد، باستخدام المعدلات المحددة. يتم فقط إخفاء المعدلات النشطة حاليًا. يتم تمرير جميع المعدلات النشطة الإضافية.

قد تولد جميع الدوال أخطاء BadDevice و BadMatch و BadValue و BadWindow.

قيمة الإرجاع

XIGrabButton، XIGrabKeycode، XIGrabTouchBegin و
XIGrabPinchGestureBegin و XIGrabSwipeGestureBegin ترجع عدد تركيبة المعدلات التي لم تتمكن من تأسيس استيلاء سلبي. يتم إرجاع المعدلات في modifiers_inout، جنبًا إلى جنب مع الخطأ المقابل لتركيبة المعدلات هذه. إذا أعادت XIGrabButton أو XIGrabKeycode أو XIGrabTouchBegin صفرًا، فقد تم تأسيس عمليات الاستيلاء السلبي بنجاح مع جميع تركيبات المعدلات المطلوبة.

التشخيصات

BadDevice
       تم تحديد deviceid غير صالح.
BadMatch
       قد يحدث هذا الخطأ إذا حددت XIGrabButton جهازًا
       لا يحتوي على أزرار، أو حددت XIGrabKeycode جهازًا
       لا يحتوي على مفاتيح،
       أو حددت XIGrabTouchBegin جهازًا غير قادر على اللمس،
       أو حددت XIGrabPinchGestureBegin جهازًا غير قادر على الإيماءات،
       أو حددت XIGrabSwipeGestureBegin جهازًا غير قادر على الإيماءات.
BadValue
       بعض القيم الرقمية تقع خارج نطاق القيم
       التي يقبلها الطلب. ما لم يتم تحديد نطاق معين
       لمعامل، يتم قبول النطاق الكامل الذي تحدده
       نوع المعامل. يمكن لأي معامل معرف كمجموعة
       من البدائل أن يولد هذا الخطأ.
BadWindow
       قيمة لمعامل Window لا تشير إلى Window معرف.

الأخطاء

لم توفر رؤوس البروتوكول الخاصة بـ XI 2.0
XIGrabModeAsync أو XIGrabModeSync. استخدم GrabModeSync و
GrabModeAsync بدلاً من ذلك، على التوالي.
