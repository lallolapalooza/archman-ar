XISelectEvents(3)

الحزمة: libxi

التراخيص: MIT-open-group, SMLNJ, MIT

XISELECTEVENTS(3)   XISELECTEVENTS(3)

الاسم

XISelectEvents, XIGetSelectedEvents - تحديد أحداث XI2 أو الحصول عليها من النافذة.

ملخص

#include <X11/extensions/XInput2.h>
Status XISelectEvents( Display *display,
                       Window win,
                       XIEventMask *masks,
                       int num_masks);
display
       يحدد الاتصال بخادم X.
masks
       قناع أحداث الجهاز.
num_masks
       عدد الأقنعة في masks.
win
       يحدد النافذة.
XIEventMask *XIGetSelectedEvents( Display *display,
                                  Window win,
                                  int *num_masks_return);
display
       يحدد الاتصال بخادم X.
num_masks_return
       عدد الأقنعة في القيمة المرجعة.
win
       يحدد النافذة.

الوصف

يجب تحديد أحداث XI2 باستخدام XISelectEvents.
تقوم XISelectEvents بتعيين قناع الأحداث لهذا العميل على النافذة win.
لا يتم الإبلاغ عن الأحداث الإضافية لهذا العميل إلا إذا تطابق نوع الحدث مع قناع الحدث المحدد.
تتجاوز الأقنعة قناع الحدث المحدد مسبقًا لهذا الجهاز.
إذا كان deviceid جهازًا صالحًا، يتم تحديد قناع الحدث لهذا الجهاز فقط.
إذا كان deviceid هو XIAllDevices أو XIAllMasterDevices، يتم تحديد قناع الحدث لجميع الأجهزة أو
لجميع الأجهزة الرئيسية على التوالي. قناع الحدث الفعال هو
الـ OR ثنائي البت لقناع XIAllDevices و XIAllMasterDevices وقناع الحدث الخاص بالجهاز المعني.
typedef struct {
    int deviceid;
    int mask_len;
    unsigned char* mask;
} XIEventMask;
تحدد mask_len طول القناع بالبايت. mask هو قناع ثنائي بالشكل (1 << event type).
يجب أن يكون deviceid إما جهازًا أو XIAllDevices أو XIAllMasterDevices.
يجوز للعميل إرسال عدة أقنعة بنفس deviceid في طلب واحد ولكن القناع الأخير فقط سيكون فعالًا.
يمكن لـ XISelectEvents توليد خطأ BadValue، أو BadDevice، أو BadWindow.
تقوم XIGetSelectedEvents بإرجاع الأحداث التي حددها هذا العميل على النافذة المحددة.
إذا لم يتم تحديد أي أحداث على هذه النافذة، فإن XIGetSelectedEvents ترجع NULL ويتم تعيين
num_masks_return إلى 0. إذا حدث خطأ داخلي، فإن XIGetSelectedEvents ترجع NULL ويتم تعيين
num_masks_return إلى -1. بخلاف ذلك، ترجع XIGetSelectedEvent أقنعة الأحداث المحددة
لجميع الأجهزة بما في ذلك أقنعة XIAllDevices و XIAllMasterDevices.
يجب على المستدعي تحرير البيانات المرجعة باستخدام XFree().

التشخيصات

BadValue
       قيمة خارج النطاق المسموح به.
BadWindow
       قيمة لمعامل Window لا تحدد نافذة معرفة.
BadDevice
       تم تحديد جهاز غير صالح. الجهاز غير موجود.
