XQueryBestStipple(3)

الحزمة: libx11

التراخيص: MIT AND X11

XQueryBestSize(3) وظائف XLIB XQueryBestSize(3)

الاسم

XQueryBestSize، XQueryBestTile، XQueryBestStipple - تحديد الأحجام الفعالة

الصيغة

Status XQueryBestSize(Display *display، int class، Drawable which_screen، unsigned int width، unsigned int height، unsigned int *width_return، unsigned int *height_return);

Status XQueryBestTile(Display *display، Drawable which_screen، unsigned int width، unsigned int height، unsigned int *width_return، unsigned int *height_return);

Status XQueryBestStipple(Display *display، Drawable which_screen، unsigned int width، unsigned int height، unsigned int *width_return، unsigned int *height_return);

الوسائط

class
يحدد الفئة التي تهتم بها. يمكنك تمرير TileShape، CursorShape، أو StippleShape.
display
يحدد الاتصال بخادم X.
width

height
حدد العرض والارتفاع.
which_screen
يحدد أي عنصر قابل للرسم على الشاشة.
width_return

height_return
إرجاع عرض وارتفاع الكائن المدعوم بشكل أفضل بواسطة أجهزة العرض.

الوصف

تُرجع الدالة XQueryBestSize أفضل حجم أو أقرب حجم للحجم المحدد. بالنسبة لـ CursorShape، يكون هذا هو أكبر حجم يمكن عرضه بالكامل على الشاشة المحددة بواسطة which_screen. بالنسبة لـ TileShape، يكون هذا هو الحجم الذي يمكن تبليطه بأسرع وقت. بالنسبة لـ StippleShape، يكون هذا هو الحجم الذي يمكن استسهاله بأسرع وقت. بالنسبة لـ CursorShape، يشير العنصر القابل للرسم إلى الشاشة المطلوبة. بالنسبة لـ TileShape و StippleShape، يشير العنصر القابل للرسم إلى الشاشة وربما فئة النافذة وعمقها. لا يمكن استخدام نافذة InputOnly كعنصر قابل للرسم لـ TileShape أو StippleShape، وإلا فستحدث خطأ BadMatch.

يمكن أن تُنشئ XQueryBestSize أخطاء BadDrawable، BadMatch، و BadValue.

تُرجع الدالة XQueryBestTile أفضل حجم أو أقرب حجم، أي الحجم الذي يمكن تبليطه بأسرع وقت على الشاشة المحددة بواسطة which_screen. يشير العنصر القابل للرسم إلى الشاشة وربما فئة النافذة وعمقها. إذا تم استخدام نافذة InputOnly كعنصر قابل للرسم، فستحدث خطأ BadMatch.

يمكن أن تُنشئ XQueryBestTile أخطاء BadDrawable و BadMatch.

تُرجع الدالة XQueryBestStipple أفضل حجم أو أقرب حجم، أي الحجم الذي يمكن استسهاله بأسرع وقت على الشاشة المحددة بواسطة which_screen. يشير العنصر القابل للرسم إلى الشاشة وربما فئة النافذة وعمقها. إذا تم استخدام نافذة InputOnly كعنصر قابل للرسم، فستحدث خطأ BadMatch.

يمكن أن تُنشئ XQueryBestStipple أخطاء BadDrawable و BadMatch.

التشخيصات

BadMatch
تم استخدام نافذة InputOnly كعنصر قابل للرسم.
BadDrawable
قيمة وسيطة للعنصر القابل للرسم لا تسمي نافذة أو صورة نقطية (Pixmap) معرفة.
BadMatch
القيم غير موجودة لنافذة InputOnly.
BadValue
بعض القيم الرقمية تقع خارج نطاق القيم التي تقبلها الطلب. ما لم يتم تحديد نطاق معين لوسيطة، يتم قبول النطاق الكامل الذي تحدده نوع الوسيطة. يمكن لأي وسيطة محددة كمجموعة من البدائل أن تُنشئ هذا الخطأ.
