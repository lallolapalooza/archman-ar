XQueryKeymap(3)

الحزمة: libx11

التراخيص: MIT AND X11

XChangeKeyboardControl(3) وظائف XLIB XChangeKeyboardControl(3)

الاسم

XChangeKeyboardControl, XGetKeyboardControl, XAutoRepeatOn, XAutoRepeatOff, XBell, XQueryKeymap, XKeyboardControl - معالجة إعدادات لوحة المفاتيح وهيكل التحكم في لوحة المفاتيح

الصيغة

int XChangeKeyboardControl(Display *display, unsigned long value_mask, XKeyboardControl *values);

int XGetKeyboardControl(Display *display, XKeyboardState *values_return);

int XAutoRepeatOn(Display *display);

int XAutoRepeatOff(Display *display);

int XBell(Display *display, int percent);

int XQueryKeymap(Display *display, char keys_return[32]);

الوسيطات

display
يحدد الاتصال بخادم X.
keys_return
يعيد مصفوفة من البايتات تحدد المفاتيح التي يتم الضغط عليها. كل بت يمثل مفتاحًا واحدًا من لوحة المفاتيح.
percent
يحدد مستوى الصوت للجرس، والذي يمكن أن يتراوح بين -100 و 100 شاملة.
value_mask
يحدد الضوابط التي سيتم تغييرها. هذا القناع هو OR المستبعد ذو البتات لأقنعة التحكم الصحيحة.
values
يحدد قيمة واحدة لكل بت تم تعيينه إلى 1 في القناع.
values_return
يعيد قيم التحكم الحالية في لوحة المفاتيح إلى هيكل XKeyboardState المحدد.

الوصف

تقوم وظيفة XChangeKeyboardControl بالتحكم في خصائص لوحة المفاتيح المحددة بواسطة هيكل XKeyboardControl. يحدد الوسيط value_mask القيم التي سيتم تغييرها.

يمكن أن تنتج XChangeKeyboardControl أخطاء BadMatch و BadValue.

تقوم وظيفة XGetKeyboardControl بإرجاع قيم التحكم الحالية للوحة المفاتيح إلى هيكل XKeyboardState.

تقوم وظيفة XAutoRepeatOn بتشغيل التكرار التلقائي للوحة المفاتيح على العرض المحدد.

تقوم وظيفة XAutoRepeatOff بإيقاف التكرار التلقائي للوحة المفاتيح على العرض المحدد.

تقوم وظيفة XBell بإصدار صوت جرس على لوحة المفاتيح على العرض المحدد، إن أمكن. مستوى الصوت المحدد نسبي إلى مستوى الصوت الأساسي للوحة المفاتيح. إذا كانت القيمة الوسيط percent ليست في النطاق -100 إلى 100 شاملة، ينتج خطأ BadValue. مستوى الصوت الذي يرن به الجرس عندما يكون الوسيط percent غير سالب هو:

base - [(base * percent) / 100] + percent

مستوى الصوت الذي يرن به الجرس عندما يكون الوسيط percent سالبًا هو:

base + [(base * percent) / 100]

لتغيير مستوى الصوت الأساسي للجرس، استخدم XChangeKeyboardControl.

يمكن لـ XBell إنتاج خطأ BadValue.

تقوم وظيفة XQueryKeymap بإرجاع متجه بتات للحالة المنطقية للوحة المفاتيح، حيث يشير كل بت تم تعيينه إلى 1 إلى أن المفتاح المقابل يتم الضغط عليه حاليًا. يتم تمثيل المتجه بـ 32 بايت. البايت N (من 0) يحتوي على البتات للمفاتيح 8N إلى 8N + 7 مع البت الأقل أهمية في البايت الذي يمثل المفتاح 8N.

لاحظ أن الحالة المنطقية لجهاز (كما يراها عملاء التطبيقات) قد تتأخر عن الحالة المادية إذا تم تجميد معالجة أحداث الجهاز.

الهياكل

يحتوي هيكل XKeyboardControl على:

/* أقنعة البتات لـ ChangeKeyboardControl */

#define KBKeyClickPercent (1L<<0)
#define KBBellPercent (1L<<1)
#define KBBellPitch (1L<<2)
#define KBBellDuration (1L<<3)
#define KBLed (1L<<4)
#define KBLedMode (1L<<5)
#define KBKey (1L<<6)
#define KBAutoRepeatMode (1L<<7) 
/* القيم */
typedef struct {
        int key_click_percent;
        int bell_percent;
        int bell_pitch;
        int bell_duration;
        int led;
        int led_mode;   /* LedModeOn, LedModeOff */
        int key;
        int auto_repeat_mode;   /* AutoRepeatModeOff, AutoRepeatModeOn,
                                AutoRepeatModeDefault */
} XKeyboardControl;

يحدد عضو key_click_percent مستوى الصوت للنقرات الرئيسية بين 0 (إيقاف) و 100 (صاخب) شاملة، إن أمكن. القيمة -1 تعيد الافتراضي. القيم السالبة الأخرى تنتج خطأ BadValue.

يحدد عضو bell_percent مستوى الصوت الأساسي للجرس بين 0 (إيقاف) و 100 (صاخب) شاملة، إن أمكن. القيمة -1 تعيد الافتراضي. القيم السالبة الأخرى تنتج خطأ BadValue. يحدد عضو bell_pitch تردد الجرس (بالهرتز)، إن أمكن. القيمة -1 تعيد الافتراضي. القيم السالبة الأخرى تنتج خطأ BadValue. يحدد عضو bell_duration مدة الجرس بالمللي ثانية، إن أمكن. القيمة -1 تعيد الافتراضي. القيم السالبة الأخرى تنتج خطأ BadValue.

إذا تم تحديد كل من led_mode و led، يتم تغيير حالة هذا LED، إن أمكن. يمكن تعيين عضو led_mode إلى LedModeOn أو LedModeOff. إذا تم تحديد led_mode فقط، يتم تغيير حالة جميع مصابيح LED، إن أمكن. يتم دعم ما يصل إلى 32 مصباح LED مرقمة من واحد. لا يوجد تفسير قياسي لمصابيح LED. إذا تم تحديد led بدون led_mode، ينتج خطأ BadMatch.

إذا تم تحديد كل من auto_repeat_mode و key، يتم تغيير auto_repeat_mode لذلك المفتاح (وفقًا لـ AutoRepeatModeOn، AutoRepeatModeOff، أو AutoRepeatModeDefault)، إن أمكن. إذا تم تحديد auto_repeat_mode فقط، يتم تغيير وضع التكرار التلقائي العام للوحة المفاتيح بأكملها، إن أمكن، ولا يؤثر على الإعدادات لكل مفتاح. إذا تم استخدام مفتاح بدون auto_repeat_mode، ينتج خطأ BadMatch. لكل مفتاح وضع فردي سواء كان سيتم تكراره تلقائيًا أم لا، وإعداد افتراضي لهذا الوضع. بالإضافة إلى ذلك، هناك وضع عام سواء كان سيتم تمكين التكرار التلقائي أم لا، وإعداد افتراضي لهذا الوضع. عندما يكون الوضع العام AutoRepeatModeOn، يجب أن تتبع المفاتيح أوضاع التكرار التلقائي الفردية الخاصة بها. عندما يكون الوضع العام AutoRepeatModeOff، لا يجب أن تتكرر أي مفاتيح تلقائيًا. المفتاح الذي يتم تكراره تلقائيًا ينتج أحداث KeyPress و KeyRelease متناوبة. عند استخدام مفتاح كمعدّل، من المرغوب فيه ألا يتم تكرار المفتاح تلقائيًا، بغض النظر عن إعداد التكرار التلقائي الخاص به.

يحتوي هيكل XKeyboardState على:

typedef struct {
        int key_click_percent;
        int bell_percent;
        unsigned int bell_pitch, bell_duration;
        unsigned long led_mask;
        int global_auto_repeat;
        char auto_repeats[32];
} XKeyboardState;

بالنسبة لمصابيح LED، يتوافق البت الأقل أهمية في led_mask مع LED واحد، وكل بت تم تعيينه إلى 1 في led_mask يشير إلى مصباح LED مضاء. يمكن تعيين عضو global_auto_repeat إلى AutoRepeatModeOn أو AutoRepeatModeOff. عضو auto_repeats هو متجه بتات. كل بت تم تعيينه إلى 1 يشير إلى تمكين التكرار التلقائي للمفتاح المقابل. يتم تمثيل المتجه بـ 32 بايت. البايت N (من 0) يحتوي على البتات للمفاتيح 8N إلى 8N + 7 مع البت الأقل أهمية في البايت الذي يمثل المفتاح 8N.

التشخيص

BadMatch
بعض الوسيطات أو زوج من الوسيطات له النوع والنطاق الصحيحين ولكنه يفشل في المطابقة بطريقة أخرى مطلوبة من قبل الطلب.
BadValue
بعض القيم الرقمية تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لوسيط، يتم قبول النطاق الكامل الذي تحدده طبيعة الوسيط. أي وسيط معرف كمجموعة من البدائل

XQueryKeymap(3) — libX11 1.8.12

NAME

XQueryKeymap — query the keyboard mapping

SYNTAX

#include <X11/Xlib.h>

int XQueryKeymap(
    Display *display,
    unsigned char key_vec[32]
);

ARGUMENTS

supply the keyboard mapping.

display
Specifies the connection to the X server.
key_vec
Returns the keyboard mapping.

DESCRIPTION

The XQueryKeymap function returns a keymap vector, which describes the current keyboard mapping.

STRUCTURES

The keymap vector is an array of 32 bytes. Each byte in the keymap vector indicates which keys are pressed. Each bit in a byte corresponds to a keycode. If the bit is set, the corresponding keycode is pressed. The mapping from bits to keycodes is as follows:

“
Bit 0 of byte 0 corresponds to keycode 0.
“
Bit 7 of byte 0 corresponds to keycode 7.
“
Bit 0 of byte 1 corresponds to keycode 8.
“
Bit 7 of byte 31 corresponds to keycode 255.

DIAGNOSTICS

On error, XQueryKeymap returns a negative value.

BadAlloc
The server failed to allocate memory.
