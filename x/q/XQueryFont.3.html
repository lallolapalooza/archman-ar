XQueryFont(3)

الحزمة: libx11

التراخيص: MIT AND X11

XLoadFont(3) وظائف XLIB XLoadFont(3)

الاسم

XLoadFont، XQueryFont، XLoadQueryFont، XFreeFont، XGetFontProperty، XUnloadFont، XCharStruct، XFontProp، XChar2b، XFontStruct - تحميل أو إلغاء تحميل الخطوط وهياكل مقاييس الخطوط

الصيغة

Font XLoadFont(Display *display, _Xconst char *name);

XFontStruct *XQueryFont(Display *display, XID font_ID);

XFontStruct *XLoadQueryFont(Display *display, _Xconst char *name);

int XFreeFont(Display *display, XFontStruct *font_struct);

Bool XGetFontProperty(XFontStruct *font_struct, Atom atom, unsigned long *value_return);

int XUnloadFont(Display *display, Font font);

المعاملات

atom
يحدد الذرة لاسم الخاصية التي تريد إرجاعها.
display
يحدد الاتصال بخادم X.
font
يحدد الخط.
font_ID
يحدد معرّف الخط أو معرّف GContext.
font_struct
يحدد التخزين المرتبط بالخط.
gc
يحدد GC.
name
يحدد اسم الخط، وهو سلسلة نصية تنتهي بصفر.
value_return
يرجع قيمة خاصية الخط.

الوصف

تقوم الدالة XLoadFont بتحميل الخط المحدد وترجع معرّف الخط المرتبط به. إذا لم يكن اسم الخط موجودًا في ترميز الأحرف المحمول على المضيف، فإن النتيجة تعتمد على التنفيذ. لا يهم استخدام الأحرف الكبيرة أو الصغيرة. عند استخدام الأحرف '؟' و '*' في اسم خط، يتم إجراء مطابقة نمط ويتم استخدام أي خط مطابق. في النمط، سيطابق الحرف '؟' أي حرف واحد، وسيُطابق الحرف '*' أي عدد من الأحرف. يتم تحديد تنسيق منظم لأسماء الخطوط في مواصفات معيار اتحاد X اتفاقيات وصف الخطوط المنطقية لـ X. إذا فشلت XLoadFont في تحميل الخط المحدد، تحدث خطأ BadName. لا ترتبط الخطوط بشاشة معينة ويمكن تخزينها كمكون لأي GC. عندما لا يعود الخط مطلوبًا، يتم استدعاء XUnloadFont.

يمكن لـ XLoadFont إنشاء أخطاء BadAlloc و BadName.

تقوم الدالة XQueryFont بإرجاع مؤشر إلى بنية XFontStruct، والتي تحتوي على معلومات مرتبطة بالخط. يمكنك الاستعلام عن خط أو الخط المخزن في GC. سيكون معرّف الخط المخزن في بنية XFontStruct هو معرّف GContext، ويجب عليك توخي الحذر عند استخدام هذا المعرّف في دوال أخرى (انظر XGContextFromGC). إذا كان الخط غير موجود، فإن XQueryFont يرجع NULL. لتحرير هذه البيانات، استخدم XFreeFontInfo.

يمكن لـ XLoadQueryFont إنشاء خطأ BadAlloc.

توفر الدالة XLoadQueryFont الطريقة الأكثر شيوعًا للوصول إلى الخط. تقوم XLoadQueryFont بفتح (تحميل) الخط المحدد وإرجاع مؤشر إلى بنية XFontStruct المناسبة. إذا لم يكن اسم الخط في ترميز الأحرف المحمول على المضيف، فإن النتيجة تعتمد على التنفيذ. إذا كان الخط غير موجود، فإن XLoadQueryFont يرجع NULL.

تقوم الدالة XFreeFont بحذف الارتباط بين معرّف مورد الخط والخط المحدد وتحرير بنية XFontStruct. سيتم تحرير الخط نفسه عندما لا تشير أي موارد أخرى إليه. لا ينبغي الرجوع إلى البيانات والخط مرة أخرى.

يمكن لـ XFreeFont إنشاء خطأ BadFont.

بالنظر إلى الذرة لتلك الخاصية، ترجع الدالة XGetFontProperty قيمة خاصية الخط المحددة. ترجع XGetFontProperty أيضًا False إذا لم يتم تعريف الخاصية أو True إذا تم تعريفها. توجد مجموعة من الذرات المعرفة مسبقًا لخصائص الخطوط، والتي يمكن العثور عليها في X11/Xatom.h. تحتوي هذه المجموعة على الخصائص القياسية المرتبطة بالخط. على الرغم من عدم ضمان ذلك، فمن المرجح أن تكون خصائص الخطوط المعرفة مسبقًا موجودة.

تقوم الدالة XUnloadFont بحذف الارتباط بين معرّف مورد الخط والخط المحدد. سيتم تحرير الخط نفسه عندما لا تشير أي موارد أخرى إليه. لا ينبغي الرجوع إلى الخط مرة أخرى.

يمكن لـ XUnloadFont إنشاء خطأ BadFont.

الهياكل

تحتوي بنية XFontStruct على جميع المعلومات الخاصة بالخط وتتكون من معلومات خاصة بالخط بالإضافة إلى مؤشر إلى مصفوفة من هياكل XCharStruct للأحرف الموجودة في الخط. تحتوي هياكل XFontStruct و XFontProp و XCharStruct على:

typedef struct {
	short lbearing;	/* origin to left edge of raster */
	short rbearing;	/* origin to right edge of raster */
	short width;	/* advance to next char's origin */
	short ascent;	/* baseline to top edge of raster */
	short descent;	/* baseline to bottom edge of raster */
	unsigned short attributes;	/* per char flags (not predefined) */
} XCharStruct;
typedef struct {
	Atom	name;
	unsigned long card32;
} XFontProp;
typedef struct {	/* normal 16 bit characters are two bytes */
    unsigned char byte1;
    unsigned char byte2;
} XChar2b;
typedef struct {
	XExtData *ext_data;	/* hook for extension to hang data */
	Font fid;	/* Font id for this font */
	unsigned direction;	/* hint about the direction font is painted */
	unsigned min_char_or_byte2;	/* first character */
	unsigned max_char_or_byte2;	/* last character */
	unsigned min_byte1;	/* first row that exists */
	unsigned max_byte1;	/* last row that exists */
	Bool all_chars_exist;	/* flag if all characters have nonzero size */
	unsigned default_char;	/* char to print for undefined character */
	int n_properties;	/* how many properties there are */
	XFontProp *properties;	/* pointer to array of additional properties */
	XCharStruct min_bounds;	/* minimum bounds over all existing char */
	XCharStruct max_bounds;	/* maximum bounds over all existing char */
	XCharStruct *per_char;	/* first_char to last_char information */
	int ascent;	/* logical extent above baseline for spacing */
	int descent;	/* logical decent below baseline for spacing */
} XFontStruct;

يدعم X عمليات النص بأحرف/بايت واحد، مصفوفات أحرف/بايت ثنائية، وأحرف 16 بت. لاحظ أنه يمكن استخدام أي من هذه الأشكال مع خط، ولكن طلب نص بأحرف/بايت واحد يمكن أن يحدد بايت واحد فقط (أي، الصف الأول لخط مكون من بايتين). يجب عليك اعتبار الخطوط المكونة من بايتين كمصفوفة ثنائية الأبعاد من الأحرف المعرفة: يحدد البايت الأول نطاق الصفوف المعرفة، ويحدد البايت الثاني نطاق الأعمدة المعرفة للخط. تحتوي الخطوط ذات البايت الواحد/الحرف الواحد على صف واحد معرف، ويحدد نطاق البايت الثاني المحدد في البنية نطاقًا من الأحرف.

يتم تحديد مربع الإحاطة للحرف بواسطة XCharStruct الخاص بهذا الحرف. عندما تكون الأحرف غائبة عن خط، يتم استخدام الحرف الافتراضي (default_char). عندما تكون جميع أحرف الخطوط بنفس الحجم، يتم استخدام المعلومات الموجودة في الحدود الدنيا والعليا (min and max bounds) لبنية XFontStruct فقط.

تتمتع أعضاء بنية XFontStruct بالدلالات التالية:

  • يمكن أن يكون العضو direction إما FontLeftToRight أو FontRightToLeft. إنه مجرد تلميح حول ما إذا كانت معظم عناصر XCharStruct لها مقياس عرض حرف موجب (FontLeftToRight) أو سالب (FontRightToLeft). بروتوكول النواة لا يحدد دعمًا للنص العمودي.
  • إذا كان العضوان min_byte1 و max_byte1 صفرين، فإن min_char_or_byte2 يحدد الفهرس الخطي للحرف المقابل للعنصر الأول في مصفوفة per_char، و max_char_or_byte2 يحدد الفهرس الخطي للحرف للعنصر الأخير.
إذا كان أي من min_byte1 أو max_byte1 غير صفري، فإن كل من min_char_or_byte2 و max_char_or_byte2 أقل من 256، وقيم فهارس الأحرف ثنائية البايت المقابلة لعنصر مصفوفة per_char N (عدًا من 0) هي:
byte1 = N/D + min_byte1
byte2 = N\D + min_char_or_byte2
حيث: 
        D = max_char_or_byte2 - min_char_or_byte2 + 1
        / = قسمة صحيحة
        \ = في
XQueryFont(3) — libX11 — X Version 11

NAME

XQueryFont, XQueryPyFont — obtain font information

SYNTAX

 XFontStruct *XQueryFont(Display *display, XFontProp *font_properties);
 XFontStruct *XQueryPyFont(Display *display, XFontProp *font_properties);

ARGUMENTS

1. display: Specifies the connection to the X server.

2. font_properties: Specifies the font properties to query.

DESCRIPTION

The function XQueryFont returns a pointer to a font structure. The font structure contains information about the font. The font properties are specified by the font_properties argument. If the font is not found, XQueryFont returns NULL.

The function XQueryPyFont is similar to XQueryFont, but it also queries the glyph information for the font. This information is stored in the per_char member of the XFontStruct structure.

The XFontStruct structure contains the following members:

STRUCTURES

XFontProp
This structure contains properties of a font.
XCharStruct
This structure contains information about the bounding box of a character.
XFontStruct
This structure contains information about a font.
fid
The font ID.
direction
The text direction of the font. Can be False for left-to-right or True for right-to-left.
min_char_offset
The minimum offset of a character in the font.
max_char_offset
The maximum offset of a character in the font.
min_bounds
The minimum bounding box of all characters in the font.
max_bounds
The maximum bounding box of all characters in the font.
overall_ascender
The maximum ascent of any character in the font.
overall_descender
The maximum descent of any character in the font.
per_char
A pointer to an array of XCharStruct structures, one for each character in the font. If this pointer is NULL, then all characters in the font have the same bounding box information as specified by min_bounds and max_bounds.
nigua
The number of characters in the per_char array.
delta
The logical width of the default character.
min_logical_width
The minimum logical width of any character in the font.
max_logical_width
The maximum logical width of any character in the font.
font_ascent
The logical extent of the font above the baseline.
font_descent
The logical extent of the font at or below the baseline.
all_chars_exist
A boolean value indicating whether all characters in the font exist. If True, all characters in the per_char array have nonzero bounding boxes.
default_char
The character that will be used when an undefined or nonexistent character is printed. The default_char is a 16-bit character. For a font using a 2-byte matrix format, the default_char has byte1 in the most-significant byte and byte2 in the least significant byte. If the default_char itself specifies an undefined or nonexistent character, no printing is performed for an undefined or nonexistent character.
  • If the per_char pointer is NULL, all glyphs between the first and last character indexes inclusive have the same information, as given by both min_bounds and max_bounds.
  • If all_chars_exist is True, all characters in the per_char array have nonzero bounding boxes.
  • The default_char member specifies the character that will be used when an undefined or nonexistent character is printed. The default_char is a 16-bit character (not a 2-byte character). For a font using 2-byte matrix format, the default_char has byte1 in the most-significant byte and byte2 in the least significant byte. If the default_char itself specifies an undefined or nonexistent character, no printing is performed for an undefined or nonexistent character.
  • The min_bounds and max_bounds members contain the most extreme values of each individual XCharStruct component over all elements of this array (and ignore nonexistent characters). The bounding box of the font (the smallest rectangle enclosing the shape obtained by superimposing all of the characters at the same origin [x,y]) has its upper-left coordinate at: 
    [x + min_bounds.lbearing, y - max_bounds.ascent]
Its width is: 
max_bounds.rbearing - min_bounds.lbearing
Its height is: 
max_bounds.ascent + max_bounds.descent
  • The ascent member is the logical extent of the font above the baseline that is used for determining line spacing. Specific characters may extend beyond this.
  • The descent member is the logical extent of the font at or below the baseline that is used for determining line spacing. Specific characters may extend beyond this.
  • If the baseline is at Y-coordinate y, the logical extent of the font is inclusive between the Y-coordinate values (y - font.ascent) and (y + font.descent - 1). Typically, the minimum interline spacing between rows of text is given by ascent + descent.

For a character origin at [x,y], the bounding box of a character (that is, the smallest rectangle that encloses the character's shape) described in terms of XCharStruct components is a rectangle with its upper-left corner at:

[x + lbearing, y - ascent]

Its width is:

rbearing - lbearing

Its height is:

ascent + descent

The origin for the next character is defined to be:

[x + width, y]

The lbearing member defines the extent of the left edge of the character ink from the origin. The rbearing member defines the extent of the right edge of the character ink from the origin. The ascent member defines the extent of the top edge of the character ink from the origin. The descent member defines the extent of the bottom edge of the character ink from the origin. The width member defines the logical width of the character.

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadFont
A value for a Font or GContext argument does not name a defined Font.
BadName
A font or color of the specified name does not exist.
