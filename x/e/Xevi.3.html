XEVI(3) وظائف X XEVI(3)

الاسم

XeviQueryExtension, XeviQueryVersion, XeviGetVisualInfo - وظائف معلومات العرض الموسعة لـ X

ملخص

#include <X11/extensions/XEVI.h>

Bool XeviQueryExtension (Display *dpy);

Bool XeviQueryVersion (Display *dpy,
int *major_version_return,
int *minor_version_return);

int XeviGetVisualInfo (Display *dpy, VisualID *visual,
int n_visual, ExtendedVisualInfo ** evi_return,
int * n_info_return);

الوصف

ملحق معلومات العرض الموسعة لـ X11 (EVI) يسمح للعميل بتحديد معلومات حول عروض X الأساسية بما يتجاوز ما يوفره البروتوكول الأساسي.

تحتوي مكتبة واجهة برمجة تطبيقات تطبيق EVI على الواجهات الموصوفة أدناه. باستثناء XeviQueryExtension، إذا تم استدعاء أي من هذه الروتينات مع عرض لا يدعم الامتداد، فسيتم استدعاء ExtensionErrorHandler (والذي يمكن تعيينه باستخدام XSetExtensionErrorHandler ويعمل بنفس طريقة XSetErrorHandler) وسترجع الدالة بعد ذلك.

XeviQueryExtension ترجع True إذا كان امتداد معلومات العرض الموسعة متاحًا على العرض المحدد. يجب على العميل استدعاء XeviQueryExtension قبل استدعاء أي وظيفة EVI أخرى من أجل التفاوض على إصدار بروتوكول متوافق؛ وإلا سيحصل العميل على سلوك غير محدد (قد يعمل EVI أو لا يعمل).

XeviQueryVersion ترجع True إذا نجح الطلب؛ يتم إرجاع قيم إصدار البروتوكول الرئيسي والثانوي الذي يدعمه الخادم في major_version_return و minor_version_return.

XeviGetVisualInfo ترجع قائمة بهياكل ExtendedVisualInfo التي تصف معلومات العرض بما يتجاوز ما يدعمه البروتوكول الأساسي. يشمل ذلك معلومات الطبقات ذات الصلة بالأنظمة التي تدعم مستويات التراكب و/أو المستويات السفلية، والمعلومات التي تسمح للتطبيقات بتحديد مستوى دعم الأجهزة لخرائط الألوان المتعددة بشكل أفضل. ترجع XeviGetVisualInfo Success إذا نجحت، أو خطأ X بخلاف ذلك. إذا كان الوسيط visual هو NULL، فسيتم إرجاع معلومات لجميع العروض لجميع الشاشات. بخلاف ذلك، فهو مؤشر إلى قائمة العروض التي يتم الرغبة في معلومات العرض الموسعة لها. n_visual هو عدد العناصر في مصفوفة visual. evi_return يرجع مؤشرًا إلى قائمة ExtendedVisualInfo. عند الانتهاء، يجب على العميل تحرير القائمة باستخدام XFree. n_info_return يرجع عدد العناصر في مصفوفة evi_return.

يحتوي هيكل ExtendedVisualInfo على الحقول التالية: 

VisualID	core_visual_id
int 	screen
int 	level
unsigned int	transparency_type
unsigned int	transparency_value
unsigned int	min_hw_colormaps
unsigned int	max_hw_colormaps
unsigned int	num_colormap_conflicts
VisualID *  	colormap_conflicts

المزيج من core_visual_id ورقم screen يحدد بصريًا العرض الذي يتم وصفه.

level يرجع رقم المستوى للعرض، 0 للطائرات العادية، > 0 للتراكبات، < 0 للمستويات السفلية.

transparency_type يرجع نوع الشفافية التي يدعمها العرض. XEVI_TRANSPARENCY_NONE إذا لم تكن هناك وحدات بكسل شفافة، XEVI_TRANSPARENCY_PIXEL إذا كان العرض يدعم وحدة بكسل شفافة، XEVI_TRANSPARENCY_MASK إذا كان العرض يدعم مستويات شفافة.

transparency_value يرجع قيمة البكسل/المستوى لتعيين الشفافية إذا لم يكن transparency_type XEVI_TRANSPARENCY_NONE.

min_hw_colormaps و max_hw_colormaps يرجعان الحد الأدنى والأقصى لعدد خرائط الألوان للأجهزة التي تدعم العرض.

num_colormap_conflicts يرجع عدد العناصر في colormap_conflicts. ترجع هذه المصفوفة قائمة بالعروض التي قد تسبب تعارضات في استخدام خريطة الألوان للأجهزة. على سبيل المثال، إذا تم تحميل خريطة ألوان للأجهزة بدقة 12 بت لدعم خرائط الألوان بدقة 8 بت، فإن عروض 8 بت المقابلة ستتعارض مع عروض 12 بت.

الأخطاء

XeviGetVisualInfo سترجع BadValue إذا تم تمرير معرف عرض غير قانوني، BadAccess إذا لم يستجب خادم X، BadAlloc إذا فشل تخصيص الذاكرة.
