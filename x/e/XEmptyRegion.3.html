XEmptyRegion(3)

الحزمة: libx11

التراخيص: MIT AND X11

XEmptyRegion(3) وظائف XLIB XEmptyRegion(3)

الاسم

XEmptyRegion, XEqualRegion, XPointInRegion, XRectInRegion - تحديد ما إذا كانت المناطق فارغة أو متساوية

الصيغة

Bool XEmptyRegion(Region r);

Bool XEqualRegion(Region r1, Region r2);

Bool XPointInRegion(Region r, int x, int y);

int XRectInRegion(Region r, int x, int y, unsigned int width, unsigned int height);

المعاملات

r
تحدد المنطقة.
r1

r2
تحدد المنطقتين.
width

height
تحدد العرض والارتفاع، والتي تحدد المستطيل.
x

y
تحدد إحداثيات x و y، والتي تحدد النقطة أو إحداثيات الزاوية العلوية اليسرى للمستطيل.

الوصف

تقوم الدالة XEmptyRegion بإرجاع True إذا كانت المنطقة فارغة.

تقوم الدالة XEqualRegion بإرجاع True إذا كانت المنطقتان لهما نفس الإزاحة والحجم والشكل.

تقوم الدالة XPointInRegion بإرجاع True إذا كانت النقطة (x, y) محتواة في المنطقة r.

تقوم الدالة XRectInRegion بإرجاع RectangleIn إذا كان المستطيل بالكامل داخل المنطقة المحددة، و RectangleOut إذا كان المستطيل بالكامل خارج المنطقة المحددة، و RectanglePart إذا كان المستطيل جزئيًا داخل المنطقة المحددة.
