xcb_map_request_event_t(3)

الحزمة: libxcb

التراخيص: X11

xcb_map_request_event_t(3) أحداث XCB xcb_map_request_event_t(3)

الاسم

xcb_map_request_event_t - النافذة تريد أن يتم تعيينها

ملخص

#include <xcb/xproto.h>

بنية بيانات الحدث

typedef struct xcb_map_request_event_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    xcb_window_t parent;
    xcb_window_t window;
} xcb_map_request_event_t;

حقول الحدث

response_type
نوع هذا الحدث، في هذه الحالة XCB_MAP_REQUEST. هذا الحقل موجود أيضًا في xcb_generic_event_t ويمكن استخدامه للتمييز بين الأحداث.
sequence
رقم التسلسل لآخر طلب تم معالجته بواسطة خادم X11.
parent
النافذة الأم لـ window.
window
النافذة التي سيتم تعيينها.

انظر أيضاً

xcb_generic_event_t(3), xcb_map_window(3)
