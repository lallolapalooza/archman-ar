الحزمة: libx11

التراخيص: MIT AND X11

XConfigureEvent(3) وظائف XLIB XConfigureEvent(3)

اسم

XConfigureEvent - بنية حدث ConfigureNotify

البنى

تحتوي بنية أحداث ConfigureNotify على:

typedef struct {
        int type;       /* ConfigureNotify */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window event;
        Window window;
        int x, y;
        int width, height;
        int border_width;
        Window above;
        Bool override_redirect;
} XConfigureEvent;

عند تلقي هذا الحدث، يتم تعيين أعضاء البنية على النحو التالي.

يتم تعيين عضو النوع إلى ثابت اسم الحدث الذي يحدده بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل بنية XGraphicsExposeEvent مع تعيين عضو النوع إلى GraphicsExpose. يتم تعيين عضو العرض إلى مؤشر إلى العرض الذي تمت قراءة الحدث منه. يتم تعيين عضو send_event إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو الرقم التسلسلي من الرقم التسلسلي الذي تم الإبلاغ عنه في البروتوكول ولكن تم توسيعه من أقل 16 بت أهمية إلى قيمة كاملة 32 بت. يتم تعيين عضو النافذة إلى النافذة الأكثر فائدة لمرسلي الأدوات.

يتم تعيين عضو الحدث إما إلى النافذة المعاد تكوينها أو إلى والدتها، اعتمادًا على ما إذا كان StructureNotify أو SubstructureNotify قد تم تحديده. يتم تعيين عضو النافذة إلى النافذة التي تغير حجمها أو موضعها أو حدودها و/أو ترتيب تكديسها.

يتم تعيين أعضاء x و y إلى الإحداثيات بالنسبة إلى أصل النافذة الأم وتشير إلى موضع الزاوية الخارجية العلوية اليسرى للنافذة. يتم تعيين أعضاء العرض والارتفاع إلى الحجم الداخلي للنافذة، ولا يشمل الحدود. يتم تعيين عضو border_width إلى عرض حدود النافذة، بالبكسل.

يتم تعيين عضو above إلى النافذة الشقيقة ويستخدم لعمليات التكديس. إذا قام خادم X بتعيين هذا العضو إلى None، فإن النافذة التي تغيرت حالتها تكون في أسفل المكدس بالنسبة للنوافذ الشقيقة. ومع ذلك، إذا تم تعيين هذا العضو إلى نافذة شقيقة، يتم وضع النافذة التي تغيرت حالتها فوق هذه النافذة الشقيقة.

يتم تعيين عضو override_redirect إلى سمة override-redirect للنافذة. عادةً ما يجب على عملاء مدير النوافذ تجاهل هذه النافذة إذا كان عضو override_redirect هو True.
