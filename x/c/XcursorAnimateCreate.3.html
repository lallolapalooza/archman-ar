XcursorAnimateCreate(3)


الحزمة: libxcursor


التراخيص: HPND-sell-variant


        

            

                



NAME


XcursorAnimateCreate, XcursorAnimateDestroy, XcursorAnimateNextFrame, XcursorAnimationDestroy - create and destroy cursors from animations






SYNOPSIS


#include <Xcursor/Xcursor.h>


XcursorAnimation * XcursorAnimateCreate (Display *dpy, XcursorImage *image);


void XcursorAnimateDestroy (XcursorAnimation *animation);


XcursorImage * XcursorAnimateNextFrame (XcursorAnimation *animation);


void XcursorAnimationDestroy (XcursorImage *image);






DESCRIPTION


The Xcursor library provides functions for loading and manipulating cursors. Animations are represented by a sequence of frames, where each frame is an XcursorImage. The XcursorAnimation structure holds the sequence of frames and the current frame index.


The function
    XcursorAnimateCreate() creates a new XcursorAnimation object from a
    given XcursorImage. The XcursorImage is assumed to contain animation frames
    as described in the XcursorImage structure documentation.


The function
    XcursorAnimateDestroy() destroys an XcursorAnimation object and frees
    all associated resources.


The function
    XcursorAnimateNextFrame() returns the next XcursorImage in the animation
    sequence. It updates the internal state of the XcursorAnimation object to
    point to the next frame. If the end of the animation sequence is reached, it
    wraps around to the beginning.


The function
    XcursorAnimationDestroy() destroys an XcursorImage object that was
    obtained from an animation sequence using
    XcursorAnimateNextFrame(). Note that this function does not destroy the
    XcursorAnimation object itself, only the image frame.






FUNCTIONAL OVERVIEW


These functions allow applications to create, manage, and display animated cursors. An application can load a cursor image that contains multiple frames for an animation, create an XcursorAnimation object, and then repeatedly call XcursorAnimateNextFrame() to get the next frame to display. When the animation is no longer needed, XcursorAnimateDestroy() should be called to free the animation resources. Similarly, each frame obtained via XcursorAnimateNextFrame() should be explicitly destroyed using XcursorAnimationDestroy() when it is no longer needed.






DATATYPES



  
XcursorAnimation

  
An opaque structure representing an animated cursor.

  
XcursorImage

  
A structure representing a single cursor image, which may contain multiple frames for animation.








FUNCTIONS



  
XcursorAnimateCreate

  
Creates an XcursorAnimation object from an XcursorImage.

  
XcursorAnimateDestroy

  
Destroys an XcursorAnimation object.

  
XcursorAnimateNextFrame

  
Retrieves the next frame (as an XcursorImage) from an XcursorAnimation.

  
XcursorAnimationDestroy

  
Destroys an XcursorImage obtained from XcursorAnimateNextFrame.








ENVIRONMENT



  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.

Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.

الاسم


XcursorAnimateCreate، XcursorAnimateDestroy، XcursorAnimateNextFrame، XcursorAnimationDestroy - إنشاء وتدمير مؤشرات من الرسوم المتحركة






الملخص


#include <Xcursor/Xcursor.h>


XcursorAnimation * XcursorAnimateCreate (Display *dpy, XcursorImage *image);


void XcursorAnimateDestroy (XcursorAnimation *animation);


XcursorImage * XcursorAnimateNextFrame (XcursorAnimation *animation);


void XcursorAnimationDestroy (XcursorImage *image);






الوصف


توفر مكتبة Xcursor وظائف لتحميل ومعالجة المؤشرات. يتم تمثيل الرسوم المتحركة بتسلسل من الإطارات، حيث كل إطار هو XcursorImage. يحتفظ الهيكل XcursorAnimation بتسلسل الإطارات ومؤشر الإطار الحالي.


تقوم الدالة XcursorAnimateCreate() بإنشاء كائن XcursorAnimation جديد من XcursorImage معطى. يُفترض أن XcursorImage يحتوي على إطارات الرسوم المتحركة كما هو موضح في توثيق هيكل XcursorImage.


تقوم الدالة XcursorAnimateDestroy() بتدمير كائن XcursorAnimation وتحرير جميع الموارد المرتبطة به.


تقوم الدالة XcursorAnimateNextFrame() بإرجاع XcursorImage التالي في تسلسل الرسوم المتحركة. تقوم بتحديث الحالة الداخلية لكائن XcursorAnimation للإشارة إلى الإطار التالي. إذا تم الوصول إلى نهاية تسلسل الرسوم المتحركة، فإنها تعود إلى البداية.


تقوم الدالة XcursorAnimationDestroy() بتدمير كائن XcursorImage الذي تم الحصول عليه من تسلسل رسوم متحركة باستخدام XcursorAnimateNextFrame(). لاحظ أن هذه الدالة لا تدمر كائن XcursorAnimation نفسه، بل تدمر إطار الصورة فقط.






نظرة عامة وظيفية


تسمح هذه الوظائف للتطبيقات بإنشاء وإدارة وعرض المؤشرات المتحركة. يمكن للتطبيق تحميل صورة مؤشر تحتوي على إطارات متعددة للرسوم المتحركة، وإنشاء كائن XcursorAnimation، ثم استدعاء XcursorAnimateNextFrame() بشكل متكرر للحصول على الإطار التالي للعرض. عندما لم تعد الرسوم المتحركة مطلوبة، يجب استدعاء XcursorAnimateDestroy() لتحرير موارد الرسوم المتحركة. وبالمثل، يجب تدمير كل إطار تم الحصول عليه عبر XcursorAnimateNextFrame() بشكل صريح باستخدام XcursorAnimationDestroy() عندما لم يعد مطلوبًا.






أنواع البيانات



  
XcursorAnimation

  
هيكل غير شفاف يمثل مؤشرًا متحركًا.

  
XcursorImage

  
هيكل يمثل صورة مؤشر فردية، والتي قد تحتوي على إطارات متعددة للرسوم المتحركة.








الوظائف



  
XcursorAnimateCreate

  
ينشئ كائن XcursorAnimation من XcursorImage.

  
XcursorAnimateDestroy

  
يدمر كائن XcursorAnimation.

  
XcursorAnimateNextFrame

  
يجلب الإطار التالي (كـ XcursorImage) من XcursorAnimation.

  
XcursorAnimationDestroy

  
يدمر XcursorImage تم الحصول عليه من XcursorAnimateNextFrame.








البيئة



  
Xcursor.theme_core

  
يمكّن السمات للمؤشرات الأساسية إذا كان متغير البيئة
      true.





  

  
إذا لم يتم توفير متغير البيئة، تحاول Xcursor المورد
      Xcursor.theme_core.

  

  
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام
    XcursorSetThemeCore.
