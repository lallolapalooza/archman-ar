تقوم هذه الوظائف بالبحث في مسار المكتبة، وتحميل أول ملف يتم العثور عليه بالحجم المطلوب، باستخدام دالة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا لم يكن theme هو NULL، فاستخدمه.
  • إذا كان theme هو NULL، أو إذا لم يكن هناك تطابق للسمة المطلوبة، فاستخدم "default" لاسم السمة.
  • إذا لم ينجح أي من البحثين، فإن هذه الوظائف تعيد NULL.
تختلف الدالتان عن عدد الصور المحملة:
  • XcursorLibraryLoadImage يستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages يستدعي XcursorFileLoadImages، و (في حالة النجاح) يستدعي XcursorImagesSetName لربط name بالنتيجة.

البيئة


يمكن استخدام متغيرات البيئة لتجاوز إعدادات الموارد، والتي بدورها تتجاوز القيم الافتراضية المضمنة.


بعض متغيرات البيئة التي يتعرف عليها Xcursor هي قيم منطقية، يتم تحديدها على النحو التالي:





  
صحيح لـ
    "t" أو "1" أو "y" أو
    "on"

  

  
خطأ لـ
    "f" أو "0" أو "n" أو
    "off"

  






يتجاهل Xcursor القيم الأخرى لهذه القيم المنطقية.



  
HOME

  
يفسر Xcursor "~" في قائمة البحث على أنها الدليل الرئيسي، باستخدام هذا المتغير بدلاً من قاعدة بيانات كلمات المرور.

  
XCURSOR_ANIM

  
إذا كان العرض يدعم طلب Render CreateCursor، وتم تمكين ميزة Render، فقم بتعطيل المؤشرات المتحركة إذا كان متغير البيئة خطأ.





  

  
إذا لم يتم تقديم متغير البيئة، يستخدم Xcursor المورد
      Xcursor.anim.





  
XCURSOR_CORE

  
إذا كان العرض يدعم طلب Render CreateCursor، فقم بتعطيل ميزة Render إذا كان متغير البيئة خطأ.





  

  
إذا لم يتم تقديم متغير البيئة، يستخدم Xcursor المورد
      Xcursor.core.





  
XCURSOR_DISCOVER

  
إذا تم تعيين المتغير، يقوم Xcursor بتشغيل ميزة تسجيل. يقوم بعرض قيمة التجزئة والصورة بحيث يمكن للمستخدمين رؤية اسم المؤشر المرتبط بكل صورة.





  

  
لا يوجد إعداد مورد مقابل.





  
XCURSOR_DITHER

  
يقوم هذا المتغير بتعيين التنقيط المطلوب.





  

  
إذا لم يتم تقديم متغير البيئة، يستخدم Xcursor المورد
      Xcursor.dither.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor
      "threshold" (الحد).

  

  
هذه هي القيم المعترف بها:







  
diffuse (منتشر)

  

  
median (متوسط)

  

  
ordered (مرتب)

  

  
threshold (حد)

  







  
XCURSOR_PATH

  
يقوم هذا المتغير بتعيين قائمة المسارات التي سيتم البحث فيها عن المؤشرات، بدلاً من القائمة الافتراضية المضمنة.





  

  
يتم فصل الدلائل في هذا المسار بنقطتين رأسيتين (:).





  
XCURSOR_RESIZED

  
يُمكّن تغيير حجم المؤشرات تلقائيًا لتحسين حجم عرضها إذا كان متغير البيئة صحيح.





  

  
إذا لم يتم تقديم متغير البيئة، يحاول Xcursor المورد
      Xcursor.resized.





  
XCURSOR_SIZE

  
يقوم هذا المتغير بتعيين حجم المؤشر المطلوب، بالبكسل.





  

  
إذا لم يتم تقديم متغير البيئة، يحاول Xcursor المورد
      Xcursor.size.

  

  
إذا لم يتم تقديم حجم، سواء عن طريق متغير البيئة أو إعداد المورد، يحاول Xcursor بعد ذلك إعداد المورد
      Xft.dpi لتخمين حجم مؤشر 16 نقطة.

  

  
أخيرًا، إذا لم يتم تعيين Xft.dpi، يستخدم Xcursor ارتفاع العرض، مقسومًا على 48 (بافتراض أن الارتفاع هو 768).





  
XCURSOR_THEME

  
يحدد هذا المتغير السمة المطلوبة.





  

  
إذا لم يتم تقديم متغير البيئة، يحاول Xcursor المورد
      Xcursor.theme.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor
      السمة الافتراضية.





  
XCURSOR_






XCURSORCORE


enable or disable core cursor themes






SYNOPSIS


XcursorCore






DESCRIPTION


The XcursorCore function is used to query
    the default theme to use for core cursors. This function is deprecated and
    is replaced by the XcursorGetTheme function.


This function is part of the Xcursor library, which provides
    functionality for loading and managing Xcursor cursor images.






ENVIRONMENT



  
XCURSOR_THEME

  
Specifies the default cursor theme to use.

  
XCURSOR_SIZE

  
Specifies the default cursor size to use.





  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.

XCURSORCORE


تمكين أو تعطيل سمات المؤشر الأساسي






الملخص


XcursorCore






الوصف


تُستخدم الدالة XcursorCore للاستعلام عن
    السمة الافتراضية لاستخدامها للمؤشرات الأساسية. تم إهمال هذه الدالة ويتم
    استبدالها بالدالة XcursorGetTheme.


هذه الدالة جزء من مكتبة Xcursor، التي توفر وظائف لتحميل
    وإدارة صور المؤشرات Xcursor.






البيئة



  
XCURSOR_THEME

  
يحدد سمة المؤشر الافتراضية المراد استخدامها.

  
XCURSOR_SIZE

  
يحدد حجم المؤشر الافتراضي المراد استخدامه.





  
Xcursor.theme_core

  
تمكين السمات للمؤشرات الأساسية إذا كانت متغير البيئة
      true.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor مورد
      Xcursor.theme_core.

  

  
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام
    XcursorSetThemeCore.








محاذير


Xcursor ستتغير جذرياً على الأرجح في المستقبل؛ ستُبذل محاولات
    ضعيفة للحفاظ على مستوى ما من التوافق في ملفات المصدر.
