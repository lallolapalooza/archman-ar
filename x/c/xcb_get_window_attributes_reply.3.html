xcb_get_window_attributes_reply(3)

الحزمة: libxcb

التراخيص: X11

NAME

xcb_get_window_attributes_reply - get the attributes of a window

SYNOPSIS

#include <xcb/xproto.h>

typedef struct xcb_get_window_attributes_cookie_t {
    unsigned int sequence;
} xcb_get_window_attributes_cookie_t;
xcb_get_window_attributes_cookie_t
xcb_get_window_attributes(xcb_connection_t *conn,
                          xcb_window_t window);
xcb_get_window_attributes_reply_t *
xcb_get_window_attributes_reply(xcb_get_window_attributes_cookie_t cookie,
                                xcb_connection_t *conn,
                                xcb_generic_error_t **e);
xcb_get_window_attributes_cookie_t
xcb_get_window_attributes_unchecked(xcb_connection_t *conn,
                                    xcb_window_t window);

REQUEST ARGUMENTS

conn
The xcb_connection_t to use.
window
The window to get attributes from.

REPLY FIELDS

XCB_MAP_STATE_UNMAPPED
TODO: لم يتم التوثيق بعد.
XCB_MAP_STATE_UNVIEWABLE
TODO: لم يتم التوثيق بعد.
XCB_MAP_STATE_VIEWABLE
TODO: لم يتم التوثيق بعد.
override_redirect
يجب على مديري النوافذ تجاهل هذه النافذة إذا كان override_redirect يساوي 1.
colormap
خريطة الألوان التي سيتم ربطها بالنافذة.
all_event_masks
مجموعة الأحداث التي يهتم بها جميع الأشخاص.
your_event_mask
قناعي الخاص بالأحداث.
do_not_propagate_mask
مجموعة الأحداث التي لا يجب أن تنتشر.

DESCRIPTION

يحصل على السمات الحالية للنافذة المحددة.

RETURN VALUE

تُرجع xcb_get_window_attributes_cookie_t. يجب التعامل مع الأخطاء عند استدعاء دالة الرد xcb_get_window_attributes_reply.

إذا كنت ترغب في التعامل مع الأخطاء في حلقة الأحداث بدلاً من ذلك، استخدم xcb_get_window_attributes_unchecked. انظر xcb-requests(3) للتفاصيل.
