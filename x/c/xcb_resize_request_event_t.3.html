حقول الحدث

response_type
نوع هذا الحدث، وفي هذه الحالة XCB_RESIZE_REQUEST. هذا الحقل موجود أيضًا في xcb_generic_event_t ويمكن استخدامه للتمييز بين الأحداث.
sequence
رقم تسلسل آخر طلب تمت معالجته بواسطة خادم X11.
window
لم يتم توثيقه بعد.
width
لم يتم توثيقه بعد.

لم يتم توثيقه بعد.
