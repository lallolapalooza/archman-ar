xcb_grab_keyboard - استحوذ على لوحة المفاتيح

اتصال XCB بـ X11.
owner_events
إذا كانت 1، ستظل النافذة grab_window تتلقى أحداث المؤشر. إذا كانت 0، لا يتم الإبلاغ عن الأحداث إلى النافذة grab_window.

تحدد النافذة التي يجب الاستحواذ على المؤشر فيها.

سيتم استبدال القيمة الخاصة XCB_CURRENT_TIME بالوقت الحالي للخادم.

pointer_mode

XCB_GRAB_MODE_ASYNC
تستمر معالجة أحداث لوحة المفاتيح بشكل طبيعي.

الوصف

يستحوذ بنشاط على التحكم في لوحة المفاتيح ويولد أحداث FocusIn و FocusOut. يتم الإبلاغ عن أحداث المفاتيح الأخرى فقط للعميل المستحوذ.

يتم تجاوز أي استحواذ نشط على لوحة المفاتيح بواسطة هذا العميل. إذا تم الاستحواذ بنشاط على لوحة المفاتيح بواسطة عميل آخر، يتم إرجاع AlreadyGrabbed. إذا لم تكن النافذة grab_window قابلة للعرض، يتم إرجاع GrabNotViewable. إذا كانت لوحة المفاتيح مجمدة بسبب استحواذ نشط من عميل آخر، يتم إرجاع GrabFrozen. إذا كان الطابع الزمني المحدد time أبكر من وقت آخر استحواذ على لوحة المفاتيح أو لاحقًا من وقت خادم X الحالي، يتم إرجاع GrabInvalidTime. بخلاف ذلك، يتم تعيين وقت آخر استحواذ على لوحة المفاتيح إلى الوقت المحدد.

القيمة المرتجعة

يعيد xcb_grab_keyboard_cookie_t. يجب معالجة الأخطاء عند استدعاء وظيفة الرد xcb_grab_keyboard_reply.

إذا كنت تريد معالجة الأخطاء في حلقة الأحداث بدلاً من ذلك، استخدم xcb_grab_keyboard_unchecked. انظر xcb-requests(3) للتفاصيل.

مثال

/*
 * يستحوذ على لوحة المفاتيح بنشاط
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen) {
    xcb_grab_keyboard_cookie_t cookie;
    xcb_grab_keyboard_reply_t *reply;
    cookie = xcb_grab_keyboard(
        conn,
        true,                /* الإبلاغ عن الأحداث */
        screen->root,        /* الاستحواذ على النافذة الجذر */
        XCB_CURRENT_TIME,
        XCB_GRAB_MODE_ASYNC, /* معالجة الأحداث كالمعتاد، لا تتطلب المزامنة */
        XCB_GRAB_MODE_ASYNC
    );
    if ((reply = xcb_grab_keyboard_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("تم الاستحواذ بنجاح على لوحة المفاتيح\n");
        free(reply);
    }
}
