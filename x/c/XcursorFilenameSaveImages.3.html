البيئة

يمكن استخدام متغيرات البيئة لتجاوز إعدادات الموارد، والتي بدورها تتجاوز القيم الافتراضية المضمنة.

بعض متغيرات البيئة التي يتعرف عليها Xcursor هي قيم منطقية، يتم تحديدها على النحو التالي:

صحيح لـ "t" أو "1" أو "y" أو "on"
خطأ لـ "f" أو "0" أو "n" أو "off"

يتجاهل Xcursor القيم الأخرى لهذه القيم المنطقية.

HOME
يفسر Xcursor "~" في قائمة البحث على أنه الدليل الرئيسي، باستخدام هذا المتغير بدلاً من قاعدة بيانات كلمات المرور.
XCURSOR_ANIM
إذا كان العرض يدعم طلب CreateCursor الخاص بـ Render، وتم تمكين ميزة Render، فقم بتعطيل المؤشرات المتحركة إذا كانت قيمة متغير البيئة خطأ.
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor مورد Xcursor.anim.
XCURSOR_CORE
إذا كان العرض يدعم طلب CreateCursor الخاص بـ Render، فقم بتعطيل ميزة Render إذا كانت قيمة متغير البيئة خطأ.
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor مورد Xcursor.core.
XCURSOR_DISCOVER
إذا تم تعيين المتغير، يقوم Xcursor بتشغيل ميزة تسجيل. يعرض قيمة التجزئة والصورة حتى يتمكن المستخدمون من رؤية اسم المؤشر المرتبط بكل صورة.
لا يوجد إعداد مورد مطابق.
XCURSOR_DITHER
يقوم هذا المتغير بتعيين التدرج المطلوب.
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor مورد Xcursor.dither.
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor "threshold".
هذه هي القيم المعترف بها:
diffuse
median
ordered
threshold
XCURSOR_PATH
يحدد هذا المتغير قائمة المسارات التي يتم البحث فيها عن المؤشرات، بدلاً من القائمة الافتراضية المضمنة.
يتم فصل الدلائل في هذا المسار بنقطتين رأسيتين (:).
XCURSOR_RESIZED
يمكّن تغيير حجم المؤشرات تلقائيًا لتحسين حجم عرضها إذا كانت قيمة متغير البيئة صحيح.
إذا لم يتم توفير متغير البيئة، يحاول Xcursor مورد Xcursor.resized.
XCURSOR_SIZE
يحدد هذا المتغير حجم المؤشر المطلوب، بالبكسل.
إذا لم يتم توفير متغير البيئة، يحاول Xcursor مورد Xcursor.size.
إذا لم يتم توفير حجم، سواء عن طريق متغير البيئة أو إعداد المورد، يحاول Xcursor بعد ذلك تعيين مورد Xft.dpi لتخمين حجم المؤشر ذي 16 نقطة.
أخيرًا، إذا لم يتم تعيين Xft.dpi، يستخدم Xcursor ارتفاع الشاشة، مع القسمة على 48 (بافتراض أن الارتفاع هو 768).
XCURSOR_THEME
يحدد هذا المتغير السمة المطلوبة.
إذا لم يتم توفير متغير البيئة، يحاول Xcursor مورد Xcursor.theme.
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor السمة الافتراضية.
XCURS

DESCRIPTION

The Xcursor library provides functions for loading and displaying cursor images, and for handling cursor themes.

It is designed to be used by X applications that need to display custom cursors, or to allow users to customize their cursors through themes.

FUNCTIONAL OVERVIEW

The library provides functions for:

  • Loading cursor images from files or memory.
  • Creating cursors from pixmaps, images, or fonts.
  • Saving cursors to files.
  • Handling cursor themes, including searching for theme files and applying themes.
  • Setting and getting the cursor theme.
  • Managing cursor resources.

DATATYPES

XcursorAnim
Structure to represent an animated cursor.
XcursorImage
Structure to represent a single cursor image, including its size, hotspot, and pixel data.
XcursorImages
Structure to represent a collection of cursor images, typically for an animated cursor.
XcursorChunk
Structure to represent a chunk of data within a cursor file.
XcursorFile
Structure representing an open cursor file.
XcursorTheme
Structure representing a cursor theme.

FUNCTIONS

The library provides a wide range of functions for cursor manipulation and theme handling. Some of the key functions include:

XcursorFilenameLoadImages
Loads cursor images from a file.
XcursorLoadImages
Loads cursor images from a memory buffer.
XcursorCreateCursor
Creates a cursor object from an XcursorImage.
XcursorSaveImages
Saves cursor images to a file.
XcursorInitTheme
Initializes the cursor theme system.
XcursorGetTheme
Gets the name of the current cursor theme.
XcursorSetTheme
Sets the current cursor theme.
XcursorGetDefaultTheme
Gets the name of the default cursor theme.
XcursorGetDefaultSize
Gets the default size of cursors.
XcursorSetDefaultSize
Sets the default size of cursors.
XcursorLibraryLoadCursor
Loads a cursor by name from the cursor theme.
XcursorLibraryLoadHotKeyCursor
Loads a cursor by name and hotspot from the cursor theme.
XcursorFilenameLoadCursor
Loads a cursor from a file.
XcursorCreatePixmapCursor
Creates a cursor from pixmaps.
XcursorCreateFontCursor
Creates a cursor from a font.

ENVIRONMENT

OR_THEME_CORE
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.

CAVEATS

Xcursor will probably change radically in the future; weak attempts will be made to retain some level of source-file compatibility.

الوصف

توفر مكتبة Xcursor وظائف لتحميل وعرض صور المؤشرات، والتعامل مع سمات المؤشرات.

تم تصميمها للاستخدام من قبل تطبيقات X التي تحتاج إلى عرض مؤشرات مخصصة، أو للسماح للمستخدمين بتخصيص مؤشراتهم عبر السمات.

نظرة عامة وظيفية

توفر المكتبة وظائف لـ:

  • تحميل صور المؤشرات من ملفات أو ذاكرة.
  • إنشاء مؤشرات من الخرائط النقطية (pixmaps) أو الصور أو الخطوط.
  • حفظ المؤشرات في ملفات.
  • التعامل مع سمات المؤشرات، بما في ذلك البحث عن ملفات السمات وتطبيق السمات.
  • تعيين واسترجاع سمة المؤشر الحالية.
  • إدارة موارد المؤشرات.

أنواع البيانات

XcursorAnim
هيكل لتمثيل مؤشر متحرك.
XcursorImage
هيكل لتمثيل صورة مؤشر واحدة، بما في ذلك حجمها، ونقطة التركيز (hotspot)، وبيانات البكسل.
XcursorImages
هيكل لتمثيل مجموعة من صور المؤشرات، عادةً لمؤشر متحرك.
XcursorChunk
هيكل لتمثيل جزء من البيانات داخل ملف مؤشر.
XcursorFile
هيكل يمثل ملف مؤشر مفتوح.
XcursorTheme
هيكل يمثل سمة مؤشر.

تُمكّن السمات للمؤشرات الأساسية إذا كانت متغير البيئة true.
