xcb_motion_notify_event_t(3)

الحزمة: libxcb

التراخيص: X11

xcb_motion_notify_event_t(3) أحداث XCB xcb_motion_notify_event_t(3)

الاسم

xcb_motion_notify_event_t - تم الضغط على مفتاح

الملخص

#include <xcb/xproto.h>

بنية بيانات الحدث

typedef struct xcb_motion_notify_event_t {
    uint8_t         response_type;
    uint8_t         detail;
    uint16_t        sequence;
    xcb_timestamp_t time;
    xcb_window_t    root;
    xcb_window_t    event;
    xcb_window_t    child;
    int16_t         root_x;
    int16_t         root_y;
    int16_t         event_x;
    int16_t         event_y;
    uint16_t        state;
    uint8_t         same_screen;
    uint8_t         pad0;
} xcb_motion_notify_event_t;

حقول الحدث

response_type
نوع هذا الحدث، وهو في هذه الحالة XCB_MOTION_NOTIFY. يوجد هذا الحقل أيضًا في xcb_generic_event_t ويمكن استخدامه للتمييز بين الأحداث.
sequence
رقم تسلسلي لآخر طلب تم معالجته بواسطة خادم X11.
detail
رمز المفتاح (رقم يمثل مفتاحًا فعليًا على لوحة المفاتيح) للمفتاح الذي تم الضغط عليه.
time
الوقت الذي تم فيه إنشاء الحدث (بالمللي ثانية).
root
النافذة الجذرية لـ child.
event
لم يتم توثيقه بعد.
child
لم يتم توثيقه بعد.
root_x
الإحداثي السيني للمؤشر بالنسبة للنافذة الجذرية root وقت وقوع الحدث.
root_y
الإحداثي الصادي للمؤشر بالنسبة للنافذة الجذرية root وقت وقوع الحدث.
event_x
إذا كانت same_screen صحيحة، فهذا هو الإحداثي السيني بالنسبة لأصل النافذة event. بخلاف ذلك، سيتم تعيين event_x إلى صفر.
event_y
إذا كانت same_screen صحيحة، فهذا هو الإحداثي الصادي بالنسبة لأصل النافذة event. بخلاف ذلك، سيتم تعيين event_y إلى صفر.
state
الحالة المنطقية لأزرار المؤشر ومفاتيح التعديل قبيل وقوع الحدث.
same_screen
ما إذا كانت النافذة event موجودة على نفس الشاشة مثل النافذة root.
