البيئة


يمكن استخدام متغيرات البيئة لتجاوز إعدادات الموارد، والتي بدورها تتجاوز القيم الافتراضية المضمنة.


بعض متغيرات البيئة التي تتعرف عليها Xcursor هي قيم منطقية، يتم تحديدها على النحو التالي:





  
true لـ
    "t" أو "1" أو "y" أو "on"

  

  
false لـ
    "f" أو "0" أو "n" أو "off"

  






يتجاهل Xcursor القيم الأخرى لهذه القيم المنطقية.



  
HOME

  
يفسر Xcursor "~" في قائمة البحث على أنها الدليل الرئيسي، باستخدام هذا المتغير بدلاً من قاعدة بيانات كلمات المرور.

  
XCURSOR_ANIM

  
إذا كان العرض يدعم طلب Render CreateCursor، وتم تمكين ميزة Render، فقم بتعطيل المؤشرات المتحركة إذا كان متغير البيئة false.





  

  
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor المورد Xcursor.anim.





  
XCURSOR_CORE

  
إذا كان العرض يدعم طلب Render CreateCursor، فقم بتعطيل ميزة Render إذا كان متغير البيئة false.





  

  
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor المورد Xcursor.core.





  
XCURSOR_DISCOVER

  
إذا تم تعيين المتغير، يقوم Xcursor بتشغيل ميزة تسجيل. يعرض قيمة التجزئة والصورة حتى يتمكن المستخدمون من رؤية اسم المؤشر المرتبط بكل صورة.





  

  
لا يوجد إعداد مورد مطابق.





  
XCURSOR_DITHER

  
يحدد هذا المتغير التنقيط المطلوب.





  

  
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor المورد Xcursor.dither.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor "threshold"

  

  
هذه هي القيم المعترف بها:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
يحدد هذا المتغير قائمة المسارات التي يجب البحث فيها عن المؤشرات، بدلاً من القائمة الافتراضية المضمنة.





  

  
يتم فصل الدلائل في هذا المسار بنقطتين (:).





  
XCURSOR_RESIZED

  
يُمكّن تغيير حجم المؤشرات تلقائيًا لتحسين حجمها المعروض إذا كان متغير البيئة true.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor المورد Xcursor.resized.





  
XCURSOR_SIZE

  
يحدد هذا المتغير حجم المؤشر المطلوب، بالبكسل.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor المورد Xcursor.size.

  

  
إذا لم يتم تحديد حجم، سواء عن طريق متغير البيئة أو إعداد المورد، فإن Xcursor يحاول بعد ذلك إعداد المورد Xft.dpi لتخمين حجم مؤشر بحجم 16 نقطة.

  

  
أخيرًا، إذا لم يتم تعيين Xft.dpi، يستخدم Xcursor ارتفاع العرض، مقسومًا على 48 (بافتراض أن الارتفاع هو 768).





  
XCURSOR_THEME

  
يختار هذا المتغير السمة المطلوبة.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor المورد Xcursor.theme.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor السمة الافتراضية.

NAME


XcursorFileLoadImages - Load cursor images from a file


SYNOPSIS




#include <Xcursor.h>



  

  
XcursorImages *XcursorFileLoadImages(const char *file);






DESCRIPTION




The function XcursorFileLoadImages reads a cursor image file named file.
    It returns a pointer to a structure of type XcursorImages containing all
    the images from the file.


The format of the cursor file is described in the XcursorFile(5)
    manual page.


If the file cannot be opened or read, or if it is not a valid
    cursor file, XcursorFileLoadImages returns NULL.


The memory for the returned structure and its contents is allocated
    by this function. It should be freed using XcursorFileFreeImages.




FUNCTIONAL OVERVIEW




This function provides a way to load multiple cursor images from a
    single file, typically a cursor theme directory, into memory.




DATATYPES




The function uses the XcursorImages structure, which
    contains an array of XcursorImage structures. Each XcursorImage
    structure represents a single cursor image and includes its dimensions,
    hotspot, and pixel data.




FUNCTIONS





  
XcursorFileLoadImages

  
Loads cursor images from a file.

  
XcursorFileFreeImages

  
Frees the memory allocated by XcursorFileLoadImages.






ENVIRONMENT





  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.






CAVEATS




Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.

XcursorFileLoadImages 3

الاسم




XcursorFileLoadImages - تحميل صور المؤشر من ملف




الملخص




#include <Xcursor.h>



  

  
XcursorImages *XcursorFileLoadImages(const char *file);






الوصف




تقوم الدالة XcursorFileLoadImages بقراءة ملف صور المؤشر المسمى file.
    وتعيد مؤشرًا إلى بنية من النوع XcursorImages تحتوي على جميع الصور من
    الملف.


تنسيق ملف المؤشر موصوف في صفحة الدليل XcursorFile(5).


إذا لم يكن من الممكن فتح الملف أو قراءته، أو إذا لم يكن ملف مؤشر
    صالحًا، تعيد الدالة XcursorFileLoadImages القيمة NULL.


يتم تخصيص الذاكرة للبنية المعادة ومحتوياتها بواسطة هذه الدالة.
    يجب تحريرها باستخدام XcursorFileFreeImages.




نظرة عامة وظيفية




توفر هذه الدالة طريقة لتحميل صور مؤشر متعددة من ملف واحد، عادةً
    دليل سمة المؤشر، إلى الذاكرة.




أنواع البيانات




تستخدم الدالة البنية XcursorImages، والتي تحتوي على مصفوفة من
    البنى XcursorImage. تمثل كل بنية XcursorImage صورة مؤشر
    واحدة وتتضمن أبعادها، ونقطة التركيز، وبيانات البكسل.




الدوال





  
XcursorFileLoadImages

  
تحميل صور المؤشر من ملف.

  
XcursorFileFreeImages

  
تحرير الذاكرة المخصصة بواسطة XcursorFileLoadImages.






البيئة





  
Xcursor.theme_core

  
تمكين السمات لمؤشرات النواة إذا كان متغير البيئة
      true.





  

  
إذا لم يتم إعطاء متغير البيئة، تحاول Xcursor المورد
      Xcursor.theme_core.

  

  
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام
    XcursorSetThemeCore.






تحذيرات




من المحتمل أن تتغير Xcursor جذريًا في المستقبل؛ سيتم بذل
    محاولات ضعيفة للحفاظ على مستوى معين من التوافق مع ملفات المصدر.
