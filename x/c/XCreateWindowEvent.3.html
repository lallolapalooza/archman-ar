XCreateWindowEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XCreateWindowEvent(3) دوال XLIB XCreateWindowEvent(3)

الاسم

XCreateWindowEvent - هيكل حدث CreateNotify

الهياكل

يحتوي هيكل أحداث CreateNotify على:

typedef struct {
        int type;       /* CreateNotify */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window parent;  /* parent of the window */
        Window window;  /* window id of window created */
        int x, y;       /* window location */
        int width, height;      /* size of window */
        int border_width;       /* border width */
        Bool override_redirect; /* creation should be overridden */
} XCreateWindowEvent;

عندما تتلقى هذا الحدث، يتم تعيين أعضاء الهيكل على النحو التالي.

يتم تعيين عضو النوع إلى اسم الثابت لنوع الحدث الذي يحدده بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose إلى تطبيق عميل، فإنه يرسل هيكل XGraphicsExposeEvent مع تعيين عضو النوع إلى GraphicsExpose. يتم تعيين عضو العرض إلى مؤشر إلى العرض الذي تمت قراءة الحدث منه. يتم تعيين عضو send_event إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو المسلسل من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من أقل 16 بت مهمة إلى قيمة كاملة 32 بت. يتم تعيين عضو النافذة إلى النافذة الأكثر فائدة لموزعي أدوات التحكم.

يتم تعيين عضو الوالدين إلى الوالد للنافذة التي تم إنشاؤها. يحدد عضو النافذة النافذة التي تم إنشاؤها. يتم تعيين الأعضاء x و y إلى إحداثيات النافذة التي تم إنشاؤها بالنسبة إلى أصل النافذة الوالدة ويشيران إلى موضع الزاوية الخارجية العلوية اليسرى للنافذة التي تم إنشاؤها. يتم تعيين الأعضاء width و height إلى الحجم الداخلي للنافذة التي تم إنشاؤها (لا تشمل الحدود) وهي دائمًا غير صفرية. يتم تعيين عضو border_width إلى عرض حدود النافذة التي تم إنشاؤها، بالبكسل. يتم تعيين عضو override_redirect إلى سمة override-redirect للنافذة. عادةً ما يجب على عملاء مدير النافذة تجاهل هذه النافذة إذا كان عضو override_redirect هو True.
