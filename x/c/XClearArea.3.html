XClearArea(3)

الحزمة: libx11

التراخيص: MIT AND X11

XClearArea(3) وظائف XLIB XClearArea(3)

الاسم

XClearArea, XClearWindow - مسح منطقة أو نافذة

الصيغة

int XClearArea(Display *display, Window w, int x, int y, unsigned width, unsigned height, Bool exposures);

int XClearWindow(Display *display, Window w);

المعاملات

display
يحدد الاتصال بخادم X.
exposures
يحدد قيمة منطقية تشير إلى ما إذا كان سيتم إنشاء أحداث Expose.
w
يحدد النافذة.
width

height
يحدد العرض والارتفاع، وهما أبعاد المستطيل.
x

y
يحدد إحداثيات x و y، وهي نسبية إلى أصل النافذة وتحدد الزاوية العلوية اليسرى للمستطيل.

الوصف

تقوم الدالة XClearArea بطلاء منطقة مستطيلة في النافذة المحددة وفقًا للأبعاد المحددة باستخدام بكسل الخلفية للنافذة أو pixmap. وضع النافذة الفرعية هو فعليًا ClipByChildren. إذا كان العرض صفرًا، يتم استبداله بالعرض الحالي للنافذة مطروحًا منه x. إذا كان الارتفاع صفرًا، يتم استبداله بالارتفاع الحالي للنافذة مطروحًا منه y. إذا كانت للنافذة خلفية بلاط محددة، يتم ملء المستطيل المقتطع بواسطة أي نوافذ فرعية بهذا البلاط. إذا كانت خلفية النافذة None، فلن يتم تغيير محتويات النافذة. في كلتا الحالتين، إذا كان exposures هو True، يتم إنشاء حدث أو أكثر من أحداث Expose للمناطق التي تكون مرئية أو يتم الاحتفاظ بها في مخزن خلفي. إذا قمت بتحديد نافذة فئتها InputOnly، فسينتج خطأ BadMatch.

يمكن لـ XClearArea إنشاء أخطاء BadMatch و BadValue و BadWindow.

تقوم الدالة XClearWindow بمسح المنطقة بأكملها في النافذة المحددة وهي مكافئة لـ XClearArea (display, w, 0, 0, 0, 0, False). إذا كانت للنافذة خلفية بلاط محددة، يتم تبليط المستطيل بقناع مستوى من جميع الواحدات ووظيفة GXcopy. إذا كانت خلفية النافذة None، فلن يتم تغيير محتويات النافذة. إذا قمت بتحديد نافذة فئتها InputOnly، فسينتج خطأ BadMatch.

يمكن لـ XClearWindow إنشاء أخطاء BadMatch و BadWindow.

التشخيصات

BadMatch
تم استخدام نافذة InputOnly كـ Drawable.
BadValue
تقع قيمة رقمية ما خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لمعامل، يتم قبول النطاق الكامل الذي تحدده نوع المعامل. يمكن لأي معامل محدد كمجموعة من البدائل إنشاء هذا الخطأ.
BadWindow
قيمة لمعامل Window لا تحدد نافذة معرفة.
