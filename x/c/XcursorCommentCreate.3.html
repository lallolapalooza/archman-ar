اسم

Xcursor - مكتبة إدارة المؤشرات

ملخص

#include <X11/Xcursor/Xcursor.h>

وصف

Xcursor هي مكتبة بسيطة مصممة للمساعدة في تحديد وتحميل المؤشرات. يمكن تحميل المؤشرات من الملفات أو الذاكرة. توجد مكتبة للمؤشرات الشائعة التي ترتبط بأسماء مؤشرات X القياسية. يمكن أن توجد المؤشرات بأحجام متعددة وتقوم المكتبة تلقائيًا باختيار أفضل حجم.

نظرة عامة وظيفية

تم بناء Xcursor في بضع طبقات؛ في الطبقة السفلية يوجد الكود الذي يمكنه تحميل صور المؤشرات من الملفات. فوق ذلك توجد طبقة تحدد مواقع ملفات المؤشرات بناءً على مسار المكتبة والموضوع. في الأعلى توجد طبقة تبني المؤشرات إما من صورة تم تحميلها من ملف أو أحد مؤشرات X القياسية. عند استخدام صور تم تحميلها من ملفات، تفضل Xcursor استخدام طلب إنشاء المؤشر الخاص بامتداد Render إذا كان الخادم X يدعمه. حيث لا يكون مدعومًا، تقوم Xcursor بربط صورة المؤشر بمؤشر X قياسي وتستخدم طلب إنشاء المؤشر الأساسي.

ملفات المؤشرات

تحدد Xcursor تنسيقًا جديدًا للمؤشرات على القرص. كل ملف يحتوي على صورة مؤشر واحدة أو أكثر. يتم تمييز كل صورة مؤشر بحجم اسمي بحيث يمكن اختيار أفضل حجم تلقائيًا. يمكن تحميل مؤشرات متعددة بنفس الحجم الاسمي معًا؛ من المتوقع أن تستخدمها التطبيقات كسلسلة رسوم متحركة.

يتم تخزين ملفات المؤشر كتذييل يحتوي على جدول محتويات متبوعًا بسلسلة من الأجزاء. يشير جدول المحتويات إلى نوع، نوع فرعي، وموقع في الملف لكل جزء. يبدو تذييل الملف كالتالي:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 بايت في هذا التذييل
version:	CARD32 رقم إصدار الملف
ntoc:	CARD32 عدد إدخالات جدول المحتويات
toc:	LISTofTOC جدول المحتويات

كل إدخال في جدول المحتويات يبدو كالتالي:


type:	CARD32 نوع الإدخال
subtype:	CARD32 تسمية خاصة بالنوع - حجم للصور
position:	CARD32 موقع البايت المطلق للجدول في الملف

كل جزء في الملف يحتوي على مجموعة من حقول التذييل الشائعة متبوعة بحقول إضافية خاصة بالنوع:


header:	CARD32 بايت في تذييل الجزء (بما في ذلك الحقول الخاصة بالنوع)
type:	CARD32 يجب أن يتطابق مع النوع في جدول المحتويات لهذا الجزء
subtype:	CARD32 يجب أن يتطابق مع النوع الفرعي في جدول المحتويات لهذا الجزء
version:	CARD32 رقم إصدار لهذا النوع من الأجزاء

يوجد حاليًا نوعان من الأجزاء محددين لملفات المؤشرات؛ التعليقات والصور. تبدو التعليقات كالتالي:


header:	20 تذييلات التعليقات بحجم 20 بايت
type:	0xfffe0001 نوع التعليق هو 0xfffe0001
subtype:	{ 1 (حقوق النشر)، 2 (ترخيص)، 3 (أخرى) }
version:	1
length:	CARD32 طول البايت للسلسلة UTF-8
string:	LISTofCARD8 سلسلة UTF-8

تبدو الصور كالتالي:


header:	36 تذييلات الصور بحجم 36 بايت
type:	0xfffd0002 نوع الصورة هو 0xfffd0002
subtype:	CARD32 النوع الفرعي للصورة هو الحجم الاسمي
version:	1
width:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
height:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
xhot:	CARD32 يجب أن يكون أقل من أو يساوي العرض
yhot:	CARD32 يجب أن يكون أقل من أو يساوي الارتفاع
delay:	CARD32 التأخير بين إطارات الرسوم المتحركة بالمللي ثانية
pixels:	LISTofCARD32 بكسلات بتنسيق ARGB مضغوط

المواضيع

تتبع Xcursor (في الغالب) مواصفات freedesktop.org لمواضيع الأيقونات. مسار البحث الافتراضي الذي تستخدمه هو

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

داخل كل من هذه الأدلة، تبحث عن دليل باستخدام اسم الموضوع:

•
داخل دليل الموضوع، تبحث عن ملفات المؤشرات في الدليل الفرعي "cursors".
تبحث Xcursor عن ملف محدد، والذي يجب أن يكون أحد أسماء شكل المؤشر، على سبيل المثال كما هو مستخدم في XcursorLibraryLoadImage أو XcursorLibraryShape.
•
إذا لم تجد ملف مؤشر مطابق في الدليل الفرعي "cursors"، تبحث Xcursor بعد ذلك عن ملف "index.theme" في كل دليل موضوع للبحث عن مواضيع موروثة. هذه عبارة عن أسطر بهذا التنسيق:
Inherits = اسم-الموضوع

تستخدم Xcursor أول اسم-موضوع موروث، متجاهلة الآخرين الذين قد يكونون موجودين في ملف "index.theme" معين. إذا وجدت موضوعًا موروثًا، فإن Xcursor تبحث على طول المسار لاستخدامه أيضًا. تتجاهل Xcursor مفاتيح أخرى في ملف "index.theme"، بما في ذلك "Name" (أي الاسم الذي قد يستخدمه تطبيق رسومي كـ اسم العرض).

يمكن إدراج أكثر من اسم-موضوع واحد في سطر Inherits=. تنص مواصفات freedesktop.org على أن عناصر القائمة مفصولة بفواصل. تقبل Xcursor أيضًا فاصلة منقوطة، لكنها تترجم كلاهما إلى نقطتين رأسيتين عند البحث في المسار. تتوقع Xcursor سطر Inherits= واحد فقط؛ مواصفات freedesktop.org غير واضحة ما إذا كانت مفاتيح متعددة مسموح بها.

إذا لم يتم تعيين موضوع، أو إذا لم يتم العثور على مؤشر للموضوع المحدد في أي مكان على طول المسار، تتحقق Xcursor من موضوع "default".

عندما تجد Xcursor ملف مؤشر، فإنها تتوقف عن البحث. تستخدم دائمًا ملف المؤشر الأول الذي تم العثور عليه أثناء البحث على طول المسار.

أنواع البيانات

XcursorImage
يحتوي على صورة مؤشر واحدة في الذاكرة. كل بكسل في المؤشر هو قيمة 32 بت تحتوي على ARGB مع A في البايت الأعلى. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* حجم اسمي للمطابقة */
    XcursorDim 	 width; 	/* العرض الفعلي */
    XcursorDim 	 height; 	/* الارتفاع الفعلي */
    XcursorDim 	 xhot; 	/* موقع نقطة الاتصال x (يجب أن يكون داخل الصورة) */
    XcursorDim 	 yhot; 	/* موقع نقطة الاتصال y (يجب أن يكون داخل الصورة) */
    XcursorPixel 	*pixels; 	/* مؤشر إلى البكسلات */
} XcursorImage;
XcursorImages
يحتوي على هياكل XcursorImage متعددة. يتم تحريرها جميعًا عند تحرير XcursorImages في XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* عدد الصور */
    XcursorImage 	**images; 	/* مصفوفة لمؤشرات XcursorImage */
} XcursorImages;
XcursorCursors
يحتوي على كائنات مؤشر متعددة. يتم تحريرها جميعًا عند تحرير XcursorCursors. هذه ذات عد مرجعي بحيث يمكن لهياكل XcursorAnimate متعددة استخدام نفس XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* شاشة تحتفظ بالمؤشرات */
    int 	 ref; 	/* عداد المرجع */
    int 	 ncursor; 	/* عدد المؤشرات */
    Cursor 	*cursors; 	/* مصفوفة من المؤشرات */
} XcursorCursors;
XcursorAnimate
يشير إلى مجموعة من المؤشرات وتسلسل داخل تلك المجموعة. قد تشير هياكل XcursorAnimate متعددة إلى نفس XcursorCursors؛ كل منها يحتفظ بمرجع يتم إزالته عند تحرير XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* قائمة المؤشرات المراد استخدامها */
    int 	 sequence; 	/* أي مؤشر هو التالي */
} XcursorAnimate;
XcursorFile
توفر Xcursor واجهة برمجة تطبيقات مجردة للوصول إلى بيانات الملف. توفر Xcursor تطبيق stdio لهذه الواجهة المجردة؛ التطبيقات حرة في إنشاء تطبيقات إضافية. هذه الوظائف توازي وظائف stdio.
nctions in return value and expected argument values; the read and write functions flip the arguments around to match the POSIX versions. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

تبحث هذه الوظائف في مسار المكتبة، وتقوم بتحميل أول ملف تم العثور عليه بالحجم المطلوب size، باستخدام وظيفة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا كان theme ليس NULL، استخدمه.
  • إذا كان theme NULL، أو إذا لم يتم العثور على تطابق للسمة المطلوبة، استخدم "default" لاسم السمة.
  • إذا فشلت كلا عمليتي البحث، فإن هذه الوظائف ترجع NULL.
تختلف الوظيفتان عن عدد الصور التي تم تحميلها:
  • XcursorLibraryLoadImage تستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages تستدعي XcursorFileLoadImages، وتقوم (عند النجاح) باستدعاء XcursorImagesSetName لربط name بالنتيجة.

        XcursorCommentCreate(3)
        
        
        
        
        
    
    
        

            
            

                
                



NAME


XcursorCommentCreate - create a comment entry






SYNOPSIS


#include <Xcursor.h>

XcursorComment *
XcursorCommentCreate(
    int type,
    int fmt,
    const char *data
);







DESCRIPTION


The function XcursorCommentCreate creates a
    new comment entry of the specified type and
    fmt, and initializes it with the given data.
    The comment entry is allocated with malloc and must
    be freed by the caller using XcursorCommentDestroy.






FUNCTIONAL OVERVIEW



  
XcursorCommentCreate

  
Creates and returns a pointer to a new XcursorComment
      structure. The structure is initialized with the provided type,
      fmt, and data. The caller is
      responsible for freeing the allocated memory using
      XcursorCommentDestroy.








DATATYPES



  
XcursorComment

  
Represents a comment entry within an Xcursor image. It typically contains
      fields for the comment type, format, and the comment data itself.

  
XcursorCommentType

  
An enumeration or integer type representing the category of the comment
      (e.g., description, author, license).

  
XcursorCommentFormat

  
An enumeration or integer type specifying the format of the comment
      data (e.g., plain text, URI).








FUNCTIONS



  
XcursorCommentCreate

  
Allocates and initializes a new XcursorComment
      structure.

  
XcursorCommentDestroy

  
Frees the memory allocated for an XcursorComment
      structure.

  
XcursorImageCreate

  
Creates a new Xcursor image structure.

  
XcursorImageDestroy

  
Frees the memory allocated for an Xcursor image structure.

  
XcursorFileLoadImage

  
Loads a single Xcursor image from a file.

  
XcursorFileLoadImages

  
Loads all Xcursor images from a file.

  
XcursorFilenameLoadImage

  
Loads a single Xcursor image from a file specified by filename.

  
XcursorFilenameLoadImages

  
Loads all Xcursor images from a file specified by filename.

  
XcursorSetThemeCore

  
Sets whether core themes are enabled.

  
XcursorGetThemeCore

  
Gets the current state of core theme enabling.








ENVIRONMENT



  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.
