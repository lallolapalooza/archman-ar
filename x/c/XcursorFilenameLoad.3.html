البيئة


يمكن استخدام متغيرات البيئة لتجاوز إعدادات الموارد، والتي بدورها تتجاوز القيم الافتراضية المدمجة.


بعض متغيرات البيئة التي يتعرف عليها Xcursor هي قيم منطقية، محددة على النحو التالي:





  
صحيح لـ
    «t»، «1»، «y» أو
    «on»

  

  
خطأ لـ
    «f»، «0»، «n» أو
    «off»

  






يتجاهل Xcursor القيم الأخرى لهذه القيم المنطقية.



  
HOME

  
يفسر Xcursor «~» في قائمة البحث على أنها الدليل الرئيسي، باستخدام هذا المتغير بدلاً من قاعدة بيانات كلمات المرور.

  
XCURSOR_ANIM

  
إذا كان العرض يدعم طلب Render CreateCursor، وتم تمكين ميزة Render، فقم بتعطيل المؤشرات المتحركة إذا كانت قيمة متغير البيئة false.





  

  
إذا لم يتم تقديم متغير البيئة، يستخدم Xcursor المورد
      Xcursor.anim.





  
XCURSOR_CORE

  
إذا كان العرض يدعم طلب Render CreateCursor، فقم بتعطيل ميزة Render إذا كانت قيمة متغير البيئة false.





  

  
إذا لم يتم تقديم متغير البيئة، يستخدم Xcursor المورد
      Xcursor.core.





  
XCURSOR_DISCOVER

  
إذا تم تعيين المتغير، يقوم Xcursor بتشغيل ميزة تسجيل. يعرض قيمة التجزئة والصورة حتى يتمكن المستخدمون من رؤية اسم المؤشر المرتبط بكل صورة.





  

  
لا يوجد إعداد مورد مطابق.





  
XCURSOR_DITHER

  
يضبط هذا المتغير التدرج المطلوب.





  

  
إذا لم يتم تقديم متغير البيئة، يستخدم Xcursor المورد
      Xcursor.dither.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor
      «threshold»

  

  
هذه هي القيم المعترف بها:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
يحدد هذا المتغير قائمة المسارات التي يتم فيها البحث عن المؤشرات، بدلاً من القائمة الافتراضية المدمجة.





  

  
يتم فصل الدلائل في هذا المسار بنقطتين رأسيتين (:).





  
XCURSOR_RESIZED

  
يمكّن تغيير حجم المؤشرات تلقائيًا لتحسين حجم عرضها إذا كان متغير البيئة true.





  

  
إذا لم يتم تقديم متغير البيئة، يحاول Xcursor استخدام مورد
      Xcursor.resized.





  
XCURSOR_SIZE

  
يحدد هذا المتغير حجم المؤشر المطلوب، بالبكسل.





  

  
إذا لم يتم تقديم متغير البيئة، يحاول Xcursor استخدام مورد
      Xcursor.size.

  

  
إذا لم يتم تحديد حجم، سواء عن طريق متغير البيئة أو إعداد المورد، فإن Xcursor يحاول بعد ذلك استخدام إعداد المورد
      Xft.dpi لتقدير حجم مؤشر بحجم 16 نقطة.

  

  
أخيرًا، إذا لم يتم تعيين Xft.dpi، يستخدم Xcursor ارتفاع العرض، مقسومًا على 48 (بافتراض أن الارتفاع هو 768).





  
XCURSOR_THEME

  
يحدد هذا المتغير السمة المطلوبة.





  

  
إذا لم يتم تقديم متغير البيئة، يحاول Xcursor استخدام مورد
      Xcursor.theme.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor
      السمة الافتراضية.

XcursorFilenameLoad(3)


الحزمة: libxcursor


التراخيص: HPND-sell-variant


        
        

            




NAME


XcursorFilenameLoad, XcursorFileLoad, XcursorFileLoadCursor, XcursorLibraryLoad, XcursorLibraryLoadCursor — load cursor images from files






SYNOPSIS


#include <Xcursor/Xcursor.h>


XcursorImage *
XcursorFilenameLoad(const char *filename);


XcursorImage *
XcursorFileLoad(FILE *file);


XcursorImage *
XcursorFileLoadCursor(FILE *file);


XcursorImage *
XcursorLibraryLoad(const char *filename);


XcursorImage *
XcursorLibraryLoadCursor(const char *filename);






DESCRIPTION


These functions load cursor images from the specified file.
    The file format is determined by the contents of the file. Currently supported
    formats are Xcursor (native binary format), and GIF. More formats may be added
    in the future. The data is read from the file into an
    XcursorImage structure, which is then returned.


The file is closed by
    XcursorFileLoad and
    XcursorFileLoadCursor, but not by
    XcursorFilenameLoad or
    XcursorLibraryLoad.


Functions starting with
    XcursorFile require a FILE* pointer.
    Functions starting with
    XcursorFilename take a filename. Functions starting with
    XcursorLibrary attempt to load the named file from the
    Xcursor library search path.
    The search path is determined by the
    XCURSOR_LIBRARY_PATH environment variable, or the
    default path if this variable is not set.


Functions ending with
    Cursor attempt to load the cursor from the file and
    set the default cursor for the root window. They return
    NULL on failure.


Functions not ending with
    Cursor return a pointer to the loaded
    XcursorImage on success, and
    NULL on failure. The caller is responsible for
    freeing the memory associated with the returned
    XcursorImage using
    XcursorImageDestroy.






FUNCTIONAL OVERVIEW



  
XcursorFilenameLoad

  
Loads a cursor image from the file specified by filename.

  
XcursorFileLoad

  
Loads a cursor image from the given FILE pointer. The
      file pointer is not closed after reading.

  
XcursorFileLoadCursor

  
Loads a cursor image from the given FILE pointer and
      sets it as the default cursor for the root window. The file pointer is
      closed after reading.

  
XcursorLibraryLoad

  
Loads a cursor image from the Xcursor library search path. The file name
      specifies the name of the cursor file to load.

  
XcursorLibraryLoadCursor

  
Loads a cursor image from the Xcursor library search path and sets it as the
      default cursor for the root window.








DATATYPES


XcursorImage is a structure containing information
    about a cursor image, including its dimensions, hotspot, and pixel data.






FUNCTIONS


The following functions are provided:



  
XcursorImageDestroy

  
Frees the memory associated with an XcursorImage.








ENVIRONMENT



  
XCURSOR_LIBRARY_PATH

  
Specifies a colon-separated list of directories to search for cursor
      libraries. If not set, a default path is used.

  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.
