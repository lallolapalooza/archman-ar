xcb_intern_atom(3) طلبات XCB xcb_intern_atom(3)

الاسم

xcb_intern_atom - الحصول على معرف الذرة بالاسم

ملخص

#include <xcb/xproto.h>

دالة الطلب

xcb_intern_atom_cookie_t xcb_intern_atom(xcb_connection_t *conn, uint8_t only_if_exists, uint16_t name_len, const char *name);

هيكل بيانات الرد

typedef struct xcb_intern_atom_reply_t {
    uint8_t    response_type;
    uint8_t    pad0;
    uint16_t   sequence;
    uint32_t   length;
    xcb_atom_t atom;
} xcb_intern_atom_reply_t;

دالة الرد

xcb_intern_atom_reply_t *xcb_intern_atom_reply(xcb_connection_t *conn, xcb_intern_atom_cookie_t cookie, xcb_generic_error_t **e);

وسائط الطلب

conn
اتصال XCB بـ X11.
only_if_exists
إرجاع معرف ذرة صالح فقط إذا كانت الذرة موجودة بالفعل.
name_len
طول name التالي.
name
اسم الذرة.

حقول الرد

response_type
نوع هذا الرد، في هذه الحالة XCB_INTERN_ATOM. هذا الحقل موجود أيضًا في xcb_generic_reply_t ويمكن استخدامه للتمييز بين الردود.
sequence
رقم تسلسل آخر طلب تم معالجته بواسطة خادم X11.
length
طول الرد، بالكلمات (الكلمة هي 4 بايت).
atom
TODO: لم يتم توثيقه بعد.

الوصف

يسترجع المعرف (xcb_atom_t TODO) للذرة بالاسم المحدد. تُستخدم الذرات في البروتوكولات مثل EWMH، على سبيل المثال لتخزين عناوين النوافذ (ذرة _NET_WM_NAME) كخاصية للنافذة.

إذا كان only_if_exists يساوي 0، فسيتم إنشاء الذرة إذا لم تكن موجودة بالفعل. إذا كان only_if_exists يساوي 1، فسيتم إرجاع XCB_ATOM_NONE إذا لم تكن الذرة موجودة بعد.

قيمة الإرجاع

ترجع xcb_intern_atom_cookie_t. يجب التعامل مع الأخطاء عند استدعاء دالة الرد xcb_intern_atom_reply.

إذا كنت ترغب في التعامل مع الأخطاء في حلقة الأحداث بدلاً من ذلك، استخدم xcb_intern_atom_unchecked. انظر xcb-requests(3) للتفاصيل.

مثال

/*
 * يحلل ذرة _NET_WM_NAME.
 *
 */
void my_example(xcb_connection_t *c) {
    xcb_intern_atom_cookie_t cookie;
    xcb_intern_atom_reply_t *reply;
    cookie = xcb_intern_atom(c, 0, strlen("_NET_WM_NAME"), "_NET_WM_NAME");
    /* ... قم بعمل آخر هنا إن أمكن ... */
    if ((reply = xcb_intern_atom_reply(c, cookie, NULL))) {
        printf("معرف ذرة _NET_WM_NAME هو %u0, reply->atom);
        free(reply);
    }
}
