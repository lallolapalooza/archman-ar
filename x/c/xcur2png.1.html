xcur2png(1)

الحزمة: xcur2png

التراخيص: GPL

XCUR2PNG(1) دليل الأوامر العامة XCUR2PNG(1)

الاسم

xcur2png - أخذ صور PNG من Xcursor وإنشاء ملف تكوين xcursorgen

الملخص

xcur2png [ -V ] [ --version ]

xcur2png [ -h ] [ --help ]

xcur2png [ -c مسار-التكوين ] [ --conf=مسار-التكوين ] [ -d مسار-الدليل ] [ --directory=مسار-الدليل ] [ -i لاحقة ] [ --initial-suffix=لاحقة ] [ -q ] [ --quiet ] [ -n ] [ --dry-run ] ملف-Xcursor

الوصف

يقوم xcur2png بأخذ صور PNG من ملف-Xcursor، وإنشاء ملف تكوين يمكن استخدامه بواسطة xcursorgen(1). ببساطة، إنه محول من مؤشر X إلى صورة PNG.

ملف-Xcursor هو مسار لملف Xcursor موجود. لا يتم دعم ملف-Xcursor المتعدد. يتم حفظ صور PNG التي تم إنشاؤها في الدليل الحالي.

خيارات

-V, --version
عرض رقم الإصدار والخروج بحالة 0.
-h, --help
عرض رسالة الاستخدام والخروج بحالة 0.
-c مسار-التكوين, --conf=مسار-التكوين
تعيين مسار الإخراج لملف التكوين. إذا تم تحديد "-"، يتم استخدام stdout(3). إذا لم يتم تحديده، يتم استخدام [اسم الملف لـ ملف-Xcursor].conf. إذا كان "مسار-التكوين" هو دليل، يتم حفظ ملف التكوين تحت الدليل المحدد كـ [اسم الملف لـ ملف-Xcursor].conf.
-d مسار-الدليل, --directory=مسار-الدليل
تعيين مسار الدليل الذي يتم فيه حفظ صور PNG. إذا لم يتم تحديده، يتم استخدام الدليل الحالي.
-i لاحقة, --initial-suffix=لاحقة
تعيين اللاحقة الأولية لصور PNG إلى لاحقة. يجب أن تكون لاحقة رقمًا صحيحًا موجبًا ولا يزيد عن 999. عندما تصل اللاحقة إلى 999، يخرج xcur2png بحالة سالبة.
-q, --quiet
كبت رسالة التقدم.
-n, --dry-run
لا تقم بإخراج صور PNG وبيانات التكوين إلى ملفات. يتم إرسال بيانات التكوين إلى stdout ويتم كبت رسالة التقدم.

حالة الخروج

يعيد xcur2png عدد صور PNG الناتجة إذا اكتمل التحويل بنجاح وتم إنشاء ملف-التكوين. في حالة حدوث خطأ، يعيد xcur2png قيمة سالبة.
