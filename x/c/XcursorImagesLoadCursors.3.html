XcursorImagesLoadCursors(3)

الحزمة: libxcursor

التراخيص: HPND-sell-variant

XCURSOR(3) الإصدار X 11 XCURSOR(3)

الاسم

Xcursor - مكتبة إدارة المؤشر

الملخص

#include <X11/Xcursor/Xcursor.h>

الوصف

Xcursor هي مكتبة بسيطة مصممة للمساعدة في تحديد مواقع تحميل المؤشرات. يمكن تحميل المؤشرات من الملفات أو الذاكرة. توجد مكتبة مؤشرات شائعة تربط بأسماء مؤشرات X القياسية. يمكن أن توجد المؤشرات بأحجام مختلفة وتقوم المكتبة تلقائيًا باختيار أفضل حجم.

نظرة عامة وظيفية

تم بناء Xcursor على طبقات قليلة؛ في الطبقة السفلية، يوجد كود يمكنه تحميل صور المؤشر من الملفات. فوق ذلك توجد طبقة تحدد مواقع ملفات المؤشر بناءً على مسار المكتبة والموضوع. في الأعلى توجد طبقة تبني المؤشرات إما من صورة تم تحميلها من ملف أو أحد مؤشرات X القياسية. عند استخدام الصور المحملة من الملفات، تفضل Xcursor استخدام طلب CreateCursor لامتداد Render إذا كان مدعومًا من خادم X. حيث لا يكون مدعومًا، تربط Xcursor صورة المؤشر بمؤشر X قياسي وتستخدم طلب CreateCursor الأساسي.

ملفات المؤشر

تحدد Xcursor تنسيقًا جديدًا للمؤشرات على القرص. كل ملف يحتوي على صورة مؤشر واحدة أو أكثر. كل صورة مؤشر موسومة بحجم اسمي بحيث يمكن اختيار أفضل حجم تلقائيًا. يمكن تحميل مؤشرات متعددة بنفس الحجم الاسمي معًا؛ من المتوقع أن تستخدمها التطبيقات كتسلسل متحرك.

يتم تخزين ملفات المؤشر كرأس يحتوي على جدول محتويات متبوعًا بسلسلة من المقاطع. يشير جدول المحتويات إلى النوع، النوع الفرعي، والموضع في الملف لكل مقطع. يبدو رأس الملف كالتالي:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 بايت في هذا الرأس
version:	CARD32 رقم إصدار الملف
ntoc:	CARD32 عدد إدخالات جدول المحتويات
toc:	LISTofTOC جدول المحتويات

كل إدخال في جدول المحتويات يبدو كالتالي:


type:	CARD32 نوع الإدخال
subtype:	CARD32 تسمية خاصة بالنوع - حجم للصور
position:	CARD32 موضع البايت المطلق للجدول في الملف

كل مقطع في الملف يحتوي على مجموعة من حقول الرأس الشائعة متبوعة بحقول إضافية خاصة بالنوع:


header:	CARD32 بايت في رأس المقطع (بما في ذلك الحقول الخاصة بالنوع)
type:	CARD32 يجب أن يتطابق مع النوع في TOC لهذا المقطع
subtype:	CARD32 يجب أن يتطابق مع النوع الفرعي في TOC لهذا المقطع
version:	CARD32 رقم إصدار لنوع هذا المقطع

يوجد حاليًا نوعان من المقاطع معرفان لملفات المؤشر؛ التعليقات والصور. تبدو التعليقات كالتالي:


header:	20 رؤوس التعليقات هي 20 بايت
type:	0xfffe0001 نوع التعليق هو 0xfffe0001
subtype:	{ 1 (حقوق النشر)، 2 (الترخيص)، 3 (أخرى) }
version:	1
length:	CARD32 طول البايت للسلسلة UTF-8
string:	LISTofCARD8 سلسلة UTF-8

تبدو الصور كالتالي:


header:	36 رؤوس الصور هي 36 بايت
type:	0xfffd0002 نوع الصورة هو 0xfffd0002
subtype:	CARD32 النوع الفرعي للصورة هو الحجم الاسمي
version:	1
width:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
height:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
xhot:	CARD32 يجب أن يكون أقل من أو يساوي العرض
yhot:	CARD32 يجب أن يكون أقل من أو يساوي الارتفاع
delay:	CARD32 التأخير بين إطارات الرسوم المتحركة بالمللي ثانية
pixels:	LISTofCARD32 وحدات البكسل بتنسيق ARGB المعبأ

المواضيع

تتبع Xcursor (في الغالب) مواصفات freedesktop.org لمواضيع الأيقونات. المسار الافتراضي للبحث الذي تستخدمه هو

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

داخل كل من هذه الدلائل، تبحث عن دليل باستخدام اسم الموضوع:

•
داخل دليل الموضوع، تبحث عن ملفات المؤشر في الدليل الفرعي "cursors".
تبحث Xcursor عن ملف معين، والذي يجب أن يكون أحد أسماء الأشكال للمؤشر، على سبيل المثال، كما هو مستخدم في XcursorLibraryLoadImage أو XcursorLibraryShape.
•
إذا لم تجد ملف مؤشر مطابق في الدليل الفرعي "cursors"، فإن Xcursor تبحث بعد ذلك عن ملف "index.theme" في كل دليل موضوع للبحث عن المواضيع الموروثة. هذه هي سطور بهذا التنسيق:
Inherits = theme-name

تستخدم Xcursor أول theme-name موروث، متجاهلة الآخرين الذين قد يكونون موجودين في ملف "index.theme" معين. إذا وجدت موضوعًا موروثًا، فإن Xcursor تبحث على طول المسار لاستخدامه أيضًا. تتجاهل Xcursor مفاتيح أخرى في ملف "index.theme"، بما في ذلك "Name" (أي، الاسم الذي قد يستخدمه التطبيق الرسومي كاسم عرض).

يمكن سرد أكثر من theme-name في سطر Inherits=. تنص مواصفات freedesktop.org على أن عناصر القائمة مفصولة بفواصل. تقبل Xcursor أيضًا فاصلة منقوطة، ولكنها تترجم كليهما إلى نقطتين عند البحث في المسار. تتوقع Xcursor سطرًا واحدًا فقط من Inherits=؛ مواصفات freedesktop.org غير واضحة ما إذا كان يمكن السماح بمفاتيح متعددة.

إذا لم يتم تعيين موضوع، أو إذا لم يتم العثور على مؤشر للموضوع المحدد في أي مكان على طول المسار، فإن Xcursor تتحقق من موضوع "default".

عندما تجد Xcursor ملف مؤشر، فإنها تتوقف عن البحث. تستخدم دائمًا أول ملف مؤشر يتم العثور عليه أثناء البحث على طول المسار.

أنواع البيانات

XcursorImage
يحتفظ بصورة مؤشر واحدة في الذاكرة. كل بكسل في المؤشر هو قيمة 32 بت تحتوي على ARGB مع A في البايت الأعلى. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* حجم اسمي للمطابقة */
    XcursorDim 	 width; 	/* العرض الفعلي */
    XcursorDim 	 height; 	/* الارتفاع الفعلي */
    XcursorDim 	 xhot; 	/* نقطة البداية x (يجب أن تكون داخل الصورة) */
    XcursorDim 	 yhot; 	/* نقطة البداية y (يجب أن تكون داخل الصورة) */
    XcursorPixel 	*pixels; 	/* مؤشر إلى وحدات البكسل */
} XcursorImage;
XcursorImages
يحتفظ بهياكل XcursorImage متعددة. يتم تحريرها جميعًا عند تحرير XcursorImages في XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* عدد الصور */
    XcursorImage 	**images; 	/* مصفوفة مؤشرات XcursorImage */
} XcursorImages;
XcursorCursors
يحتفظ بكائنات Cursor متعددة. يتم تحريرها جميعًا عند تحرير XcursorCursors. هذه مراجع محسوبة بحيث يمكن لهياكل XcursorAnimate متعددة استخدام نفس XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* شاشة تحتفظ بالمؤشرات */
    int 	 ref; 	/* عدد المراجع */
    int 	 ncursor; 	/* عدد المؤشرات */
    Cursor 	*cursors; 	/* مصفوفة المؤشرات */
} XcursorCursors;
XcursorAnimate
يشير إلى مجموعة من المؤشرات وتسلسل داخل تلك المجموعة. قد تشير هياكل XcursorAnimate متعددة إلى نفس XcursorCursors؛ كل منها يحتفظ بمرجع يتم إزالته عند تحرير XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* قائمة المؤشرات المراد استخدامها */
    int 	 sequence; 	/* أي مؤشر هو التالي */
} XcursorAnimate;
XcursorFile
توفر Xcursor واجهة برمجة تطبيقات مجردة للوصول إلى بيانات الملف. توفر Xcursor تطبيق stdio لهذه الواجهة المجردة؛ التطبيقات حرة في إنشاء تطبيقات إضافية. هذه الوظائف توازي وظائف stdio.

2004, Keith Packard

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

o functions in return value and expected argument values; the read and write functions flip the arguments around to match the POSIX versions. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

تبحث هذه الوظائف في مسار المكتبة، وتقوم بتحميل أول ملف يتم العثور عليه بالحجم المطلوب size، باستخدام وظيفة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا لم يكن theme فارغًا (NULL)، فاستخدمه.
  • إذا كان theme فارغًا (NULL)، أو إذا لم يكن هناك تطابق للسمة المطلوبة، فاستخدم "default" كاسم للسمة.
  • إذا فشل كلا البحثين، تعيد هذه الوظائف قيمة NULL.
تختلف الوظيفتان عن بعضهما البعض بأكثر من عدد الصور المحملة:
  • XcursorLibraryLoadImage تستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages تستدعي XcursorFileLoadImages، وتقوم (في حالة النجاح) باستدعاء XcursorImagesSetName لربط name بالنتيجة.

\n
ENVIRONMENT
\n
Environment variables can be used to override resource settings,\n    which in turn override compiled-in default values.
\n
Some of the environment variables recognized by Xcursor are\n    booleans, specified as follows:
\n
\n
\n  
true for\n    “t”, “1”, “y” or\n    “on”
\n  
\n  
false for\n    “f”, “0”, “n” or\n    “off”
\n  
\n
\n
\n
Xcursor ignores other values for these booleans.
\n
\n  
HOME
\n  
Xcursor interprets “~” in the search list as the home\n      directory, using this variable rather than the password database.
\n  
XCURSOR_ANIM
\n  
If the display supports the Render CreateCursor request, and the Render\n      feature is enabled, disable animated cursors if the environment\n      variable is false.
\n
\n
\n  
\n  
If the environment variable is not given, Xcursor uses the resource\n      Xcursor.anim.
\n
\n
\n  
XCURSOR_CORE
\n  
If the display supports the Render CreateCursor request disable the Render\n      feature if the environment variable is false.
\n
\n
\n  
\n  
If the environment variable is not given, Xcursor uses the resource\n      Xcursor.core.
\n
\n
\n  
XCURSOR_DISCOVER
\n  
If the variable is set, Xcursor turns on a logging feature. It displays\n      the hash value and the image so that users can see which cursor name is\n      associated with each image.
\n
\n
\n  
\n  
There is no corresponding resource setting.
\n
\n
\n  
XCURSOR_DITHER
\n  
This variable sets the desired dither.
\n
\n
\n  
\n  
If the environment variable is not given, Xcursor uses the resource\n      Xcursor.dither.
\n  
\n  
If neither environment variable or resource is found, Xcursor uses\n      “threshold”
\n  
\n  
These are the recognized values:
\n
\n
\n
\n  
diffuse
\n  
\n  
median
\n  
\n  
ordered
\n  
\n  
threshold
\n  
\n
\n
\n
\n  
XCURSOR_PATH
\n  
This variable sets the list of paths in which to search for cursors,\n      rather than the compiled-in default list.
\n
\n
\n  
\n  
Directories in this path are separated by colons (:).
\n
\n
\n  
XCURSOR_RESIZED
\n  
Enables automatic resizing of cursors to improve their displayed size if\n      the environment variable is true.
\n
\n
\n  
\n  
If the environment variable is not given, Xcursor tries the\n      Xcursor.resized resource.
\n
\n
\n  
XCURSOR_SIZE
\n  
This variable sets the desired cursor size, in pixels.
\n
\n
\n  
\n  
If the environment variable is not given, Xcursor tries the\n      Xcursor.size resource.
\n  
\n  
If no size is given, whether by environment variable or resource setting,\n      Xcursor next tries the Xft.dpi resource setting to guess the size\n      of a 16-point cursor.
\n  
\n  
Finally, if Xft.dpi is not set, Xcursor uses the display height,\n      dividing by 48 (assuming that the height is 768).
\n
\n
\n  
XCURSOR_THEME
\n  
This variable selects the desired theme.
\n
\n
\n  
\n  
If the environment variable is not given, Xcursor tries the\n      Xcursor.theme resource.
\n  
\n  
If neither environment variable or resource is found, Xcursor uses the\n      default theme.
\n
\n
