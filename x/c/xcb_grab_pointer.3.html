NAME

xcb_grab_pointer - grab the pointer

REQUEST ARGUMENTS

owner_events
If non-zero, the grab window receives pointer events. Otherwise, events are redirected to the grabbing client.
grab_window
The window to grab. Any pointer events generated by the pointer are reported to the grabbing client.
event_mask
Which pointer events to grab. PointerMotionMask, ButtonPressMask, ButtonReleaseMask, EnterWindowMask, LeaveWindowMask, PointerMotionHintMask, Button1MotionMask, Button2MotionMask, Button3MotionMask, Button4MotionMask, Button5MotionMask, ButtonMotionMask.
pointer_mode
Controls pointer events. XcbGrabModeSync or XcbGrabModeAsync.
keyboard_mode
Controls keyboard events. XcbGrabModeSync or XcbGrabModeAsync.
time
The time of the grab. Typically uses XCB_CURRENT_TIME.
cursor
The cursor to be displayed while the grab is active. None can be used to leave the cursor unchanged.

REPLY FIELDS

status
One of the following:
XcbGrabStatusSuccess
The grab was successful.
XcbGrabStatusAlreadyGrabbed
Another client has already grabbed the pointer.
XcbGrabStatusInvalidTime
The time specified was in the past.
XcbGrabStatusNotViewable
The grab window is not viewable.
XcbGrabStatusFrozen
The grab could not be performed because the pointer is frozen.

DESCRIPTION

Grabs the pointer. It requests that all pointer events be sent to the client, instead of going to the client that normally receives them. This is used for things like dragging.

The grab remains active until the pointer is ungrabbed, either by the client calling xcb_ungrab_pointer or implicitly when the grab window is destroyed.

If owner_events is true, the pointer events are sent to the grabbing client. If false, they are remapped to the grabbing client's window.

The grab_window is the window that will receive events. If it is not viewable, the grab fails.

The event_mask specifies which events the client is interested in.

The pointer_mode and keyboard_mode arguments control the behavior of the pointer and keyboard during the grab. XcbGrabModeAsync means that events continue to be processed normally. XcbGrabModeSync means that pointer and keyboard events are blocked until the grabbing client issues a xcb_allow_events call.

The time argument is used to prevent grabs of outdated state. If the server's current time is earlier than this value, the grab fails.

The cursor specifies the cursor to be displayed. Setting this to None leaves the cursor unchanged.

The xcb_grab_pointer_end function is used to release a grab previously made with xcb_grab_pointer.

RETURN VALUE

A cookie containing the grab status. This can be retrieved using xcb_grab_pointer_reply.

When using xcb_grab_pointer_checked, it returns the grab status directly, or throws an error.

ERRORS

This request can generate the following errors:

XcbGrabBrokenError
If the grab is broken.
XcbAccessError
If the grab window does not exist or is not viewable.
XcbMatchError
If the event mask is invalid.
XcbValueError
If pointer_mode or keyboard_mode is invalid.
XcbWindowError
If grab_window does not exist.

EXAMPLE

Grab the pointer and receive all events.

    uint8_t owner_events = 1;
    xcb_window_t grab_window = XCB_NONE; // Use root window
    uint16_t event_mask = XCB_EVENT_MASK_BUTTON_PRESS | XCB_EVENT_MASK_BUTTON_RELEASE | XCB_EVENT_MASK_POINTER_MOTION;
    uint8_t pointer_mode = XCB_GRAB_MODE_async;
    uint8_t keyboard_mode = XCB_GRAB_MODE_async;
    xcb_timestamp_t time = XCB_CURRENT_TIME;
    xcb_cursor_t cursor = XCB_NONE; // Use default cursor

    xcb_grab_status_t status = xcb_grab_pointer_checked (conn, owner_events, grab_window, event_mask, pointer_mode, keyboard_mode, time, cursor);

    if (status == XCB_GRAB_STATUS_success) {
        // Pointer grabbed successfully
        // ... process events ...
        xcb_ungrab_pointer (conn, XCB_CURRENT_TIME);
    } else {
        // Failed to grab pointer
    }
