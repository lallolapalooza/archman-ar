XConfigureWindow(3)

الحزمة: libx11

التراخيص: MIT AND X11

XConfigureWindow(3) وظائف XLIB XConfigureWindow(3)

الاسم

XConfigureWindow، XMoveWindow، XResizeWindow، XMoveResizeWindow، XSetWindowBorderWidth، XWindowChanges - تكوين النوافذ وهيكل تغييرات النافذة

الصيغة

int XConfigureWindow(Display *display, Window w, unsigned value_mask, XWindowChanges *changes);

int XMoveWindow(Display *display, Window w, int x, y);

int XResizeWindow(Display *display, Window w, unsigned width, unsigned height);

int XMoveResizeWindow(Display *display, Window w, int x, int y, unsigned width, unsigned height);

int XSetWindowBorderWidth(Display *display, Window w, unsigned width);

المعاملات

display
يحدد الاتصال بخادم X.
value_mask
يحدد القيم التي سيتم تعيينها باستخدام المعلومات الموجودة في هيكل القيم. هذا القناع هو OR الشامل للبتات لقيم النوافذ الصالحة للتكوين.
values
يحدد هيكل XWindowChanges.
w
يحدد النافذة المراد إعادة تكوينها أو نقلها أو تغيير حجمها.
width
يحدد عرض حدود النافذة.
width

height
تحديد العرض والارتفاع، وهما الأبعاد الداخلية للنافذة.
x

y
تحديد إحداثيات x و y، والتي تحدد الموقع الجديد للبكسل العلوي الأيسر لحدود النافذة أو النافذة نفسها إذا لم يكن لها حدود أو تحدد الموضع الجديد للنافذة نسبة إلى الأصل.

الوصف

تستخدم وظيفة XConfigureWindow القيم المحددة في هيكل XWindowChanges لإعادة تكوين حجم النافذة وموضعها وحدودها وترتيب تكدسها. القيم غير المحددة تؤخذ من الهندسة الحالية للنافذة.

إذا تم تحديد نافذة شقيقة بدون وضع تكدس أو إذا لم تكن النافذة شقيقة فعليًا، ينتج عن ذلك خطأ BadMatch. لاحظ أن الحسابات الخاصة بـ BottomIf و TopIf و Opposite تتم بالنسبة لهندسة النافذة النهائية (كما يتم التحكم فيها بواسطة الوسائط الأخرى التي تم تمريرها إلى XConfigureWindow)، وليس هندستها الأولية. يتم تجاهل أي محتويات مخزنة مؤقتًا للنافذة، أو الأصول التابعة لها، والنوافذ الأخرى المرئية حديثًا، أو تغييرها لتعكس محتويات الشاشة الحالية (اعتمادًا على التنفيذ).

يمكن لـ XConfigureWindow إنشاء أخطاء BadMatch و BadValue و BadWindow.

تقوم وظيفة XMoveWindow بنقل النافذة المحددة إلى إحداثيات x و y المحددة، ولكنها لا تغير حجم النافذة أو ترفع النافذة أو تغير حالة تعيين النافذة. قد يؤدي نقل نافذة معيّنة إلى فقدان محتوياتها أو عدم فقدانها اعتمادًا على ما إذا كانت النافذة محجوبة بواسطة نوافذ غير فرعية وما إذا كانت هناك ذاكرة تخزين مؤقت. إذا تم فقدان محتويات النافذة، فإن خادم X ينشئ أحداث Expose. نقل نافذة معيّنة ينشئ أحداث Expose على أي نوافذ كانت محجوبة سابقًا.

إذا كان علامة override-redirect للنافذة False وكان هناك عميل آخر قد حدد SubstructureRedirectMask على الأصل، فإن خادم X ينشئ حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. خلاف ذلك، يتم نقل النافذة.

يمكن لـ XMoveWindow إنشاء خطأ BadWindow.

تقوم وظيفة XResizeWindow بتغيير الأبعاد الداخلية للنافذة المحددة، لا تشمل حدودها. لا تغير هذه الوظيفة الإحداثي العلوي الأيسر للنافذة أو الأصل ولا تعيد تكديس النافذة. قد يؤدي تغيير حجم النافذة المعيّنة إلى فقدان محتوياتها وإنشاء أحداث Expose. إذا أصبحت نافذة معيّنة أصغر، فإن تغيير حجمها ينشئ أحداث Expose على النوافذ التي كانت النافذة المعيّنة تحجبها سابقًا.

إذا كانت علامة override-redirect للنافذة False وكان هناك عميل آخر قد حدد SubstructureRedirectMask على الأصل، فإن خادم X ينشئ حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. إذا كان العرض أو الارتفاع صفرًا، ينتج عن ذلك خطأ BadValue.

يمكن لـ XResizeWindow إنشاء أخطاء BadValue و BadWindow.

تقوم وظيفة XMoveResizeWindow بتغيير حجم وموقع النافذة المحددة دون رفعها. قد يؤدي نقل وتغيير حجم نافذة معيّنة إلى إنشاء حدث Expose على النافذة. اعتمادًا على معلمات الحجم والموقع الجديدة، قد يؤدي نقل وتغيير حجم النافذة إلى إنشاء أحداث Expose على النوافذ التي كانت النافذة تحجبها سابقًا.

إذا كانت علامة override-redirect للنافذة False وكان هناك عميل آخر قد حدد SubstructureRedirectMask على الأصل، فإن خادم X ينشئ حدث ConfigureRequest، ولا يتم إجراء أي معالجة إضافية. خلاف ذلك، يتم تغيير حجم النافذة وموقعها.

يمكن لـ XMoveResizeWindow إنشاء أخطاء BadValue و BadWindow.

تقوم وظيفة XSetWindowBorderWidth بتعيين عرض حدود النافذة المحددة إلى العرض المحدد.

يمكن لـ XSetWindowBorderWidth إنشاء خطأ BadWindow.

الهياكل

يحتوي هيكل XWindowChanges على:

/* أقنعة قيم تكوين النافذة */

#define CWX (1<<0)
#define CWY (1<<1)
#define CWWidth (1<<2)
#define CWHeight (1<<3)
#define CWBorderWidth (1<<4)
#define CWSibling (1<<5)
#define CWStackMode (1<<6) 
/* القيم */
typedef struct {
        int x, y;
        int width, height;
        int border_width;
        Window sibling;
        int stack_mode;
} XWindowChanges;

تستخدم الأعضاء x و y لتعيين إحداثيات x و y للنافذة، والتي تكون نسبة إلى أصل الأصل وتشير إلى موضع الزاوية الخارجية العلوية اليسرى للنافذة. تستخدم الأعضاء width و height لتعيين الحجم الداخلي للنافذة، لا يشمل الحدود، ويجب أن تكون غير صفرية، أو ينتج عن ذلك خطأ BadValue. محاولات تكوين نافذة الجذر ليس لها تأثير.

يستخدم العضو border_width لتعيين عرض الحدود بالبكسل. لاحظ أن تعيين عرض الحدود فقط يترك الزاوية الخارجية اليسرى للنافذة في موضع ثابت ولكنه يحرك الموضع المطلق لأصل النافذة. إذا حاولت تعيين سمة border-width لنافذة InputOnly بقيمة غير صفرية، ينتج عن ذلك خطأ BadMatch.

يستخدم العضو sibling لتعيين النافذة الشقيقة لعمليات التكديس. يستخدم العضو stack_mode لتعيين كيفية إعادة تكديس النافذة ويمكن تعيينه على Above أو Below أو TopIf أو BottomIf أو Opposite.

التشخيصات

BadMatch
يتم استخدام نافذة InputOnly كـ Drawable.
BadMatch
بعض المعاملات أو زوج من المعاملات لها النوع والنطاق الصحيحين ولكنها تفشل في المطابقة بطريقة أخرى تتطلبها الطلب.
BadValue
قيمة رقمية معينة تقع خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق محدد لمعامل، يتم قبول النطاق الكامل الذي تحدده نوع المعامل. يمكن لأي معامل محدد كمجموعة من البدائل إنشاء هذا الخطأ.
BadWindow

XConfigureWindow(3)

NAME

XConfigureWindow

configure a window

SYNTAX

Void XConfigureWindow ( Display *display , Window w , unsigned int value_mask , XWindowChanges *changes )

ARGUMENTS

display
Specifies the connection to the X server.
w
Specifies the window.
value_mask
Specifies which of the changes fields are valid. This mask is the bitwise OR of the following values:
CWX
The x member is valid.
CWY
The y member is valid.
CWWidth
The width member is valid.
CWHeight
The height member is valid.
CWBorderWidth
The border_width member is valid.
CWSibling
The sibling member is valid.
CWStackMode
The stack_mode member is valid.
changes
Specifies the new geometry attributes for the window.
x
Specifies the new x coordinate.
y
Specifies the new y coordinate.
width
Specifies the new width.
height
Specifies the new height.
border_width
Specifies the new border width.
sibling
Specifies the sibling window for stacking.
stack_mode
Specifies the stacking mode. Must be one of Above, Below, TopIf, or BottomIf.

DESCRIPTION

The XConfigureWindow function reconfigures the specified window. You can control which attributes are changed by setting the corresponding bits in the value_mask. Any bits that are not set in the value_mask are ignored. The changes structure is used to pass the new values.

If the CWX, CWY, CWWidth, or CWHeight attributes are set, the window's geometry is changed. If the CWBorderWidth attribute is set, the window's border width is changed.

If the CWSibling attribute is set, the sibling member must be a valid window or one of the special values Parent or Root. The window is then restacked according to the CWStackMode attribute.

The CWStackMode attribute controls how the window is restacked relative to the sibling window. Above raises the window above the sibling. Below lowers the window below the sibling. TopIf raises the window if it is not already the top window. BottomIf lowers the window if it is not already the bottom window.

If a window with a defined background pixmap or a defined background pixmap in a higher-level window is configured, the background of the window is not changed. If a window with a specified background and no border is configured, the background is not changed. If a window with a specified background or a pixmap in a higher-level window is configured, the background is not changed. If a window with a specified background and a border is configured, the background is not changed.

If the window is not viewable, XConfigureWindow does nothing.

STRUCTURES

The XWindowChanges structure contains the following members:

typedef struct {
    int x;
    int y;
    int width;
    int height;
    int border_width;
    Window sibling;
    int stack_mode;    /* Above, Below, TopIf, BottomIf, Opposite */
} XWindowChanges;

DIAGNOSTICS

BadWindow
A value for a Window argument does not name a defined Window.
