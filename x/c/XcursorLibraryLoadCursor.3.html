الحزمة: libxcursor

قراءة صور المكتبة

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

تبحث هذه الوظائف في مسار المكتبة، وتقوم بتحميل أول ملف تم العثور عليه بالحجم المطلوب، باستخدام دالة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا كان theme ليس NULL، فاستخدمه.
  • إذا كان theme NULL، أو إذا لم يكن هناك تطابق للسمة المطلوبة، فاستخدم "افتراضي" لاسم السمة.
  • إذا لم ينجح أي من البحثين، فترجع هذه الدوال NULL.
تختلف الدالتان بأكثر من عدد الصور المحملة:
  • XcursorLibraryLoadImage تستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages تستدعي XcursorFileLoadImages، وتقوم (عند النجاح) باستدعاء XcursorImagesSetName لربط name بالنتيجة.
