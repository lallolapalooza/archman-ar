XConfigureRequestEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XConfigureRequestEvent(3) وظائف XLIB XConfigureRequestEvent(3)

الاسم

XConfigureRequestEvent - بنية حدث ConfigureRequest

البنى

تحتوي بنية أحداث ConfigureRequest على:

typedef struct {
        int type;       /* ConfigureRequest */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window parent;
        Window window;
        int x, y;
        int width, height;
        int border_width;
        Window above;
        int detail;     /* Above, Below, TopIf, BottomIf, Opposite */
        unsigned long value_mask;
} XConfigureRequestEvent;

عندما تتلقى هذا الحدث، يتم تعيين أعضاء البنية على النحو التالي.

يتم تعيين عضو النوع (type) إلى اسم ثابت نوع الحدث الذي يميزه بشكل فريد. على سبيل المثال، عندما يقوم خادم X بالإبلاغ عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل بنية XGraphicsExposeEvent مع تعيين عضو النوع (type) إلى GraphicsExpose. يتم تعيين عضو العرض (display) إلى مؤشر للعرض الذي تم قراءة الحدث منه. يتم تعيين عضو إرسال_الحدث (send_event) إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو الرقم التسلسلي (serial) من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من أقل 16 بت ذات دلالة إلى قيمة كاملة 32 بت. يتم تعيين عضو النافذة (window) إلى النافذة الأكثر فائدة لقائمات توزيع الأدوات. النافذة الأصل (parent) يتم تعيينها إلى النافذة الأصل. يتم تعيين النافذة (window) إلى النافذة التي سيتم إعادة تكوين حجمها أو موضعها أو عرض حدودها أو ترتيبها. يشير قناع القيمة (value_mask) إلى المكونات التي تم تحديدها في طلب بروتوكول ConfigureWindow. يتم الإبلاغ عن القيم المقابلة كما هي معطاة في الطلب. يتم ملء القيم المتبقية من الهندسة الحالية للنافذة، باستثناء حالة "أعلاه" (above) (الشقيق) و "التفصيل" (detail) (وضع التكديس)، والتي يتم الإبلاغ عنها على أنها None و Above على التوالي، إذا لم يتم إعطاؤها في الطلب.
