xclipboard(1)

الحزمة: xorg-xclipboard

التراخيص: MIT-open-group

XCLIPBOARD(1) دليل الأوامر العامة XCLIPBOARD(1)

الاسم

xclipboard - عميل حافظة X

الاستخدام

xclipboard [ -toolkitoption ... ] [ -w ] [ -nw ]

الوصف

يُستخدم برنامج xclipboard لجمع وعرض اختيارات النص التي يتم إرسالها إلى CLIPBOARD بواسطة عملاء آخرين. يُستخدم عادةً لحفظ اختيارات CLIPBOARD لاستخدامها لاحقًا. يقوم بتخزين كل اختيار CLIPBOARD كسلسلة نصية منفصلة، يمكن تحديد كل منها. في كل مرة يتم فيها تأكيد CLIPBOARD بواسطة تطبيق آخر، يقوم xclipboard بنقل محتويات هذا الاختيار إلى مخزن مؤقت جديد وعرضها في نافذة النص. لا يتم حذف المخازن المؤقتة تلقائيًا أبدًا، لذا سترغب في استخدام زر الحذف للتخلص من العناصر غير المفيدة.

نظرًا لأن xclipboard يستخدم أداة النص لعرض محتويات حافظة النظام، فقد يتم إعادة تحديد النص المرسل إلى CLIPBOARD لاستخدامه في تطبيقات أخرى. يستجيب xclipboard أيضًا لطلبات اختيار CLIPBOARD من عملاء آخرين عن طريق إرسال المحتويات الكاملة للمخزن المؤقت المعروض حاليًا.

تحتوي نافذة xclipboard على الأزرار التالية عبر الأعلى:

خروج
عند الضغط على هذا الزر، يخرج xclipboard.
حذف
عند الضغط على هذا الزر، يتم حذف المخزن المؤقت الحالي وعرض المخزن التالي.
جديد
ينشئ مخزنًا مؤقتًا جديدًا بدون محتويات. مفيد في بناء اختيار CLIPBOARD جديد يدويًا.
حفظ
يعرض مربع حوار حفظ الملف. يؤدي الضغط على زر القبول إلى حفظ المخزن المؤقت المعروض حاليًا في الملف المحدد في حقل النص.
التالي
يعرض المخزن المؤقت التالي في القائمة.
السابق
يعرض المخزن المؤقت السابق.

خيارات

يقبل برنامج xclipboard جميع خيارات سطر أوامر X Toolkit القياسية بالإضافة إلى ما يلي:

-w
يشير هذا الخيار إلى أن الأسطر النصية الطويلة جدًا بحيث لا يمكن عرضها في سطر واحد في حافظة النظام يجب أن تلتف إلى الأسطر التالية.
-nw
يشير هذا الخيار إلى أن الأسطر النصية الطويلة يجب ألا تلتف. هذا هو السلوك الافتراضي.

الأدوات

لتحديد الموارد، من المفيد معرفة تسلسل الأدوات التي تشكل xclipboard. في الترميز أدناه، يشير المسافة البادئة إلى الهيكل الهرمي. يتم تقديم اسم فئة الأداة أولاً، متبوعًا باسم مثيل الأداة.

XClipboard  xclipboard
        Form  form
                Command  Quit
                Command  delete
                Command  new
                Command  Save
                Command  next
                Command  prev
                Label  index
                Text  text
        TransientShell  fileDialogShell
                Dialog  fileDialog
                        Label  label
                        Command  accept
                        Command  cancel
                        Text value
        TransientShell  failDialogShell
                Dialog  failDialog
                        Label  label
                        Command  continue

إرسال/استرجاع محتويات حافظة النظام

يتم نسخ النص إلى حافظة النظام كلما قام عميل بتأكيد ملكية اختيار CLIPBOARD. يتم نسخ النص من حافظة النظام كلما طلب عميل محتويات اختيار CLIPBOARD. أمثلة على ربط الأحداث الذي قد يرغب المستخدم في تضمينه في ملف تكوين الموارد لاستخدام حافظة النظام هي:

*VT100.Translations: #override \
        <Btn3Up>:       select-end(CLIPBOARD) \n\
        <Btn2Up>:       insert-selection(PRIMARY,CLIPBOARD) \n\
        <Btn2Down>:     ignore ()

انظر أيضًا

X(7), xcutsel(1), xterm(1), توثيق العميل الفردي لكيفية إجراء اختيار وإرساله إلى CLIPBOARD.

البيئة

DISPLAY

XENVIRONMENT
للحصول على اسم ملف موارد يتجاوز الموارد العامة المخزنة في خاصية RESOURCE_MANAGER.
