NAME


XcursorLibraryShape, XcursorSetThemeCore, XcursorGetThemeCore, XcursorLibrarySetTheme, XcursorLibraryGetTheme, XcursorLibraryShape - Xcursor library shape functions






SYNOPSIS


#include <Xcursor/Xcursor.h>

Bool
XcursorLibraryShape(void);

Bool
XcursorSetThemeCore(const char *theme_name);

const char *
XcursorGetThemeCore(void);

Bool
XcursorLibrarySetTheme(const char *theme_name);

const char *
XcursorLibraryGetTheme(void);







DESCRIPTION


The Xcursor library provides functions for loading and displaying
    cursor images. This man page describes functions related to the theme
    handling of core cursors.


XcursorLibraryShape is a dummy function. It is present for
    backward compatibility.


XcursorSetThemeCore sets the theme to be used for core
    cursors. A core cursor is a cursor that is part of the X server's default
    set, such as the standard arrow cursor.


XcursorGetThemeCore returns the name of the currently
    active theme for core cursors. The returned string is owned by the library
    and should not be freed.


XcursorLibrarySetTheme sets the default theme to be used
    by the Xcursor library for all cursor operations. If this function is called,
    it overrides any theme set via the Xcursor.theme resource or the
    XCURSOR_THEME environment variable.


XcursorLibraryGetTheme returns the name of the currently
    active theme for the Xcursor library. The returned string is owned by the
    library and should not be freed.






FUNCTIONAL OVERVIEW



  

  
The Xcursor library supports theming of cursors. This means that applications
      can use a consistent set of cursors across the system, defined by a theme.
      The theme can be specified using various methods, including environment
      variables, X resources, and programmatic calls.




Core cursors are a special set of cursors that are part of the
    X server's built-in cursor set. They are often used as fallbacks or for
    basic operations. Theming of core cursors can be controlled independently
    of other cursors.






DATATYPES


This section is intentionally left blank.






FUNCTIONS


XcursorLibraryShape() enables themes for core cursors if the
    environment variable is true.



  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








ENVIRONMENT



  
XCURSOR_THEME

  
Specifies the name of the cursor theme to use. If set, this overrides the
      Xcursor.theme X resource.

  
XCURSOR_SIZE

  
Specifies the size of the cursor theme to use. If set, this overrides the
      Xcursor.size X resource.




Additionally, the theme for core cursors can be controlled by the
    following X resource:



  
Xcursor.theme_core (class Xcursor)

  
Specifies the name of the cursor theme to use for core cursors. If not set,
      the theme specified by Xcursor.theme is used.

  
Xcursor.theme (class Xcursor)

  
Specifies the name of the cursor theme to use. This resource is consulted
      if the XCURSOR_THEME environment variable is not set.

  
Xcursor.size (class Xcursor)

  
Specifies the desired size of the cursor theme. This value is treated as a
      hint, and the actual size used may vary depending on the theme's
      supported sizes. This resource is consulted if the XCURSOR_SIZE
      environment variable is not set.




The theme for core cursors can be enabled or disabled via the
    following option:



  
Xcursor.theme_core

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.

XcursorLibraryShape(3) — libXcursor — X Version 11









الاسم


XcursorLibraryShape, XcursorSetThemeCore, XcursorGetThemeCore, XcursorLibrarySetTheme, XcursorLibraryGetTheme, XcursorLibraryShape - وظائف شكل مكتبة Xcursor






الملخص


#include <Xcursor/Xcursor.h>

Bool
XcursorLibraryShape(void);

Bool
XcursorSetThemeCore(const char *theme_name);

const char *
XcursorGetThemeCore(void);

Bool
XcursorLibrarySetTheme(const char *theme_name);

const char *
XcursorLibraryGetTheme(void);







الوصف


توفر مكتبة Xcursor وظائف لتحميل وعرض صور المؤشرات. تصف صفحة الدليل هذه الوظائف المتعلقة بمعالجة السمات للمؤشرات الأساسية.


XcursorLibraryShape هي وظيفة وهمية. إنها موجودة للتوافق مع الإصدارات السابقة.


XcursorSetThemeCore تحدد السمة التي سيتم استخدامها للمؤشرات الأساسية. المؤشر الأساسي هو مؤشر جزء من مجموعة المؤشرات الافتراضية لخادم X، مثل مؤشر السهم القياسي.


XcursorGetThemeCore ترجع اسم السمة النشطة حاليًا للمؤشرات الأساسية. السلسلة المرجعة مملوكة للمكتبة ويجب عدم تحريرها.


XcursorLibrarySetTheme تحدد السمة الافتراضية التي ستستخدمها مكتبة Xcursor لجميع عمليات المؤشر. إذا تم استدعاء هذه الوظيفة، فإنها تتجاوز أي سمة تم تعيينها عبر مورد Xcursor.theme أو متغير البيئة XCURSOR_THEME.


XcursorLibraryGetTheme ترجع اسم السمة النشطة حاليًا لمكتبة Xcursor. السلسلة المرجعة مملوكة للمكتبة ويجب عدم تحريرها.






نظرة عامة وظيفية



  

  
تدعم مكتبة Xcursor سمات المؤشرات. هذا يعني أنه يمكن للتطبيقات استخدام مجموعة متسقة من المؤشرات عبر النظام، والتي تحددها سمة. يمكن تحديد السمة باستخدام طرق مختلفة، بما في ذلك متغيرات البيئة وموارد X والمكالمات البرمجية.




المؤشرات الأساسية هي مجموعة خاصة من المؤشرات التي تعد جزءًا من مجموعة المؤشرات المضمنة لخادم X. غالبًا ما تستخدم كبدائل أو للعمليات الأساسية. يمكن التحكم في تحديد سمات المؤشرات الأساسية بشكل مستقل عن المؤشرات الأخرى.






أنواع البيانات


هذا القسم فارغ عمدًا.






الوظائف


XcursorLibraryShape() تمكن السمات للمؤشرات الأساسية إذا كان متغير البيئة هو true.



  

  
إذا لم يتم إعطاء متغير البيئة، فإن Xcursor يحاول مورد
      Xcursor.theme_core.

  

  
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام
    XcursorSetThemeCore.








البيئة



  
XCURSOR_THEME

  
يحدد اسم سمة المؤشر المراد استخدامها. إذا تم تعيينه، فإنه يتجاوز مورد X
      Xcursor.theme.

  
XCURSOR_SIZE

  
يحدد حجم سمة المؤشر المراد استخدامها. إذا تم تعيينه، فإنه يتجاوز مورد X
      Xcursor.size.




بالإضافة إلى ذلك، يمكن التحكم في سمة المؤشرات الأساسية من خلال مورد X التالي:



  
Xcursor.theme_core (فئة Xcursor)

  
يحدد اسم سمة المؤشر المراد استخدامها للمؤشرات الأساسية. إذا لم يتم تعيينها،
      يتم استخدام السمة المحددة بواسطة Xcursor.theme.

  
Xcursor.theme (فئة Xcursor)

  
يحدد اسم سمة المؤشر المراد استخدامها. يتم استشارة هذا المورد إذا لم يتم
      تعيين متغير البيئة XCURSOR_THEME.

  
Xcursor.size (فئة Xcursor)

  
يحدد الحجم المطلوب لسمة المؤشر. يتم التعامل مع هذه القيمة على أنها تلميح،
      وقد يختلف الحجم الفعلي المستخدم اعتمادًا على الأحجام المدعومة من قبل
      السمة. يتم استشارة هذا المورد إذا لم يتم تعيين متغير البيئة
      XCURSOR_SIZE.




يمكن تمكين أو تعطيل سمة المؤشرات الأساسية عبر الخيار التالي:



  
Xcursor.theme_core

  
تمكين السمات للمؤشرات الأساسية إذا كان متغير البيئة هو
      true.





  

  
إذا لم يتم إعطاء متغير البيئة، فإن Xcursor يحاول مورد
      Xcursor.theme_core.

  

  
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام
    XcursorSetThemeCore.

    محاولات ضعيفة للاحتفاظ ببعض مستوى التوافق مع ملفات المصدر.
