XChangeKeyboardMapping(3)

الحزمة: libx11

التراخيص: MIT AND X11

NAME

XChangeKeyboardMapping, XGetKeyboardMapping, XFree - change and query keyboard mapping, free keymap structure

SYNOPSIS

#include <X11/Xlib.h>

int
XChangeKeyboardMapping(Display *dpy,
    int first_keycode,
    int count,
    KeySym *keysyms_per_keycode_array,
    int keysyms_per_key);

KeySym *
XGetKeyboardMapping(Display *dpy,
    KeyCode first_keycode,
    int count,
    int *keysyms_per_key_return);

void
XFree(void *data);

ARGUMENTS

dpy
Specifies the connection to the X server.
first_keycode
Specifies the first keycode in the range of keycodes to be changed or retrieved. The server assigns keycodes. Keycode values are always greater than or equal to 8.
count
Specifies the number of keycodes in the range to be changed or retrieved. The count argument, plus the first_keycode argument, must not exceed the inclusive upper bound of the keycode range as returned by XDisplayKeycodes.
keysyms_per_keycode_array
Specifies a pointer to an array of KeySyms. The array contains the keysyms for the specified keycodes in the specified order.
keysyms_per_key
Specifies the number of KeySyms per keycode. For example, typically this is 2 (one for normal Shift, one for Shift).
keysyms_per_key_return
Returns the number of KeySyms per keycode.
data
Specifies the pointer to be freed. This is typically a pointer returned by Xlib.

DESCRIPTION

The XChangeKeyboardMapping function defines the key mapping for a range of keycodes. The mapping is specified by the keysyms_per_keycode_array and keysyms_per_key arguments. The server assigns keycodes. The valid range of keycodes is determined by the server's keyboard hardware. All keycodes outside the valid range are ignored. If a keycode is not valid, XChangeKeyboardMapping does not generate an error.

The keysyms_per_keycode_array argument points to an array of KeySyms that define the mapping for the keycodes in the range [first_keycode, first_keycode + count - 1]. The array should contain (keysyms_per_key * count) KeySyms. The KeySyms are ordered by keycode, then by index within the keycode. For a given keycode, the KeySyms correspond to the different shift levels.

The keysyms_per_key argument specifies the number of KeySyms per keycode in the keysyms_per_keycode_array. The maximum number of KeySyms per keycode is determined by the server's XDisplayKeycodes function.

The XChangeKeyboardMapping function can not change the mapping for the Shift, Lock, Control, Mod1, Mod2, Mod3, Mod4, or Mod5 modifier keys.

The XGetKeyboardMapping function returns the key mapping for the specified keycodes. It returns a pointer to an array of KeySyms. The array contains (keysyms_per_key_return * count) KeySyms. The KeySyms are ordered by keycode, then by index within the keycode. The caller must free the memory allocated for the returned array using XFree.

The keysyms_per_key_return argument returns the number of KeySyms per keycode.

The XFree function frees the specified XModifierKeymap structure.

STRUCTURES

The XModifierKeymap structure contains:

typedef struct {
        int max_keypermod;      /* This server's max number of keys per modifier */
        KeyCode *modifiermap;   /* An 8 by max_keypermod array of the modifiers */
} XModifierKeymap;

DIAGNOSTICS

BadAlloc
The server failed to allocate the requested resource or server memory.
BadValue
Some numeric value falls outside the range of values accepted by the request. Unless a specific range is specified for an argument, the full range defined by the argument's type is accepted. Any argument defined as a set of alternatives can generate this error.

الاسم

XChangeKeyboardMapping, XGetKeyboardMapping, XFree - تغيير والاستعلام عن تعيين لوحة المفاتيح، تحرير بنية تعيين المفاتيح

الملخص

#include <X11/Xlib.h>

int
XChangeKeyboardMapping(Display *dpy,
    int first_keycode,
    int count,
    KeySym *keysyms_per_keycode_array,
    int keysyms_per_key);

KeySym *
XGetKeyboardMapping(Display *dpy,
    KeyCode first_keycode,
    int count,
    int *keysyms_per_key_return);

void
XFree(void *data);

الوسائط

dpy
يحدد الاتصال بخادم X.
first_keycode
يحدد مفتاح الكود الأول في نطاق مفاتيح الكود المراد تغييرها أو استرجاعها. يقوم الخادم بتعيين مفاتيح الكود. قيم مفاتيح الكود دائما أكبر من أو تساوي 8.
count
يحدد عدد مفاتيح الكود في النطاق المراد تغييره أو استرجاعه. يجب ألا يتجاوز الوسيط count، بالإضافة إلى الوسيط first_keycode، الحد الأعلى الشامل لنطاق مفتاح الكود كما تم إرجاعه بواسطة XDisplayKeycodes.
keysyms_per_keycode_array
يحدد مؤشرًا إلى مصفوفة من KeySyms. تحتوي المصفوفة على رموز المفاتيح لمفاتيح الكود المحددة بالترتيب المحدد.
keysyms_per_key
يحدد عدد KeySyms لكل مفتاح كود. على سبيل المثال، عادة ما يكون هذا 2 (واحد للإزاحة العادية، واحد للإزاحة).
keysyms_per_key_return
يرجع عدد KeySyms لكل مفتاح كود.
data
يحدد المؤشر المراد تحريره. عادة ما يكون هذا مؤشرًا تم إرجاعه بواسطة Xlib.

الوصف

تقوم الدالة XChangeKeyboardMapping بتحديد تعيين المفاتيح لنطاق من مفاتيح الكود. يتم تحديد التعيين بواسطة الوسيطين keysyms_per_keycode_array و keysyms_per_key. يقوم الخادم بتعيين مفاتيح الكود. يتم تحديد النطاق الصالح لمفاتيح الكود بواسطة أجهزة لوحة المفاتيح الخاصة بالخادم. يتم تجاهل جميع مفاتيح الكود خارج النطاق الصالح. إذا لم يكن مفتاح الكود صالحًا، فإن XChangeKeyboardMapping لا تولد خطأ.

يشير الوسيط keysyms_per_keycode_array إلى مصفوفة من KeySyms تحدد تعيين مفاتيح الكود في النطاق [first_keycode, first_keycode + count - 1]. يجب أن تحتوي المصفوفة على (keysyms_per_key * count) KeySyms. يتم ترتيب KeySyms حسب مفتاح الكود، ثم حسب الفهرس داخل مفتاح الكود. بالنسبة لمفتاح كود معين، تتوافق KeySyms مع مستويات الإزاحة المختلفة.

يحدد الوسيط keysyms_per_key عدد KeySyms لكل مفتاح كود في keysyms_per_keycode_array. يتم تحديد الحد الأقصى لعدد KeySyms لكل مفتاح كود بواسطة الدالة XDisplayKeycodes الخاصة بالخادم.

لا يمكن للدالة XChangeKeyboardMapping تغيير تعيين مفاتيح Shift، Lock، Control، Mod1، Mod2، Mod3، Mod4، أو Mod5 المعدلة.

ترجع الدالة XGetKeyboardMapping تعيين المفاتيح لمفاتيح الكود المحددة. ترجع مؤشرًا إلى مصفوفة من KeySyms. تحتوي المصفوفة على (keysyms_per_key_return * count) KeySyms. يتم ترتيب KeySyms حسب مفتاح الكود، ثم حسب الفهرس داخل مفتاح الكود. يجب على المتصل تحرير الذاكرة المخصصة للمصفوفة المرجعة باستخدام XFree.

يرجع الوسيط keysyms_per_key_return عدد KeySyms لكل مفتاح كود.

تقوم الدالة XFree بتحرير بنية XModifierKeymap المحددة.

البنى

تحتوي بنية XModifierKeymap على:

typedef struct {
        int max_keypermod;      /* This server's max number of keys per modifier */
        KeyCode *modifiermap;   /* An 8 by max_keypermod array of the modifiers */
} XModifierKeymap;

التشخيصات

BadAlloc
فشل الخادم في تخصيص المورد المطلوب أو ذاكرة الخادم.
BadValue
تقع قيمة رقمية ما خارج نطاق القيم التي يقبلها الطلب. ما لم يتم تحديد نطاق معين لوسيط، يتم قبول النطاق الكامل الذي تحدده نوع الوسيط. يمكن لأي وسيط تم تعريفه كمجموعة من البدائل أن يولد هذا الخطأ.
