البيئة


يمكن استخدام متغيرات البيئة لتجاوز إعدادات الموارد، والتي بدورها تتجاوز القيم الافتراضية المضمنة.


بعض متغيرات البيئة التي يتعرف عليها Xcursor هي قيم منطقية، يتم تحديدها كما يلي:





  
صحيح لـ “t”، “1”، “y” أو “on”

  

  
خطأ لـ “f”، “0”، “n” أو “off”

  






يتجاهل Xcursor القيم الأخرى لهذه المتغيرات المنطقية.



  
HOME

  
يفسر Xcursor “~” في قائمة البحث على أنه الدليل الرئيسي، باستخدام هذا المتغير بدلاً من قاعدة بيانات كلمات المرور.

  
XCURSOR_ANIM

  
إذا كان العرض يدعم طلب Render CreateCursor، وتم تمكين ميزة Render، قم بتعطيل المؤشرات المتحركة إذا كان متغير البيئة false.





  

  
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor المورد Xcursor.anim.





  
XCURSOR_CORE

  
إذا كان العرض يدعم طلب Render CreateCursor، قم بتعطيل ميزة Render إذا كان متغير البيئة false.





  

  
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor المورد Xcursor.core.





  
XCURSOR_DISCOVER

  
إذا تم تعيين المتغير، يقوم Xcursor بتمكين ميزة تسجيل. يقوم بعرض قيمة التجزئة والصورة حتى يتمكن المستخدمون من رؤية اسم المؤشر المرتبط بكل صورة.





  

  
لا يوجد إعداد مورد مقابل.





  
XCURSOR_DITHER

  
يضبط هذا المتغير التنقيط المطلوب.





  

  
إذا لم يتم توفير متغير البيئة، يستخدم Xcursor المورد Xcursor.dither.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor “threshold”

  

  
هذه هي القيم المعترف بها:







  
diffuse

  

  
median

  

  
ordered

  

  
threshold

  







  
XCURSOR_PATH

  
يضبط هذا المتغير قائمة المسارات التي سيتم البحث فيها عن المؤشرات، بدلاً من القائمة الافتراضية المضمنة.





  

  
يتم فصل الدلائل في هذا المسار بنقطتين (:).





  
XCURSOR_RESIZED

  
يمكّن تغيير حجم المؤشرات تلقائيًا لتحسين حجمها المعروض إذا كان متغير البيئة true.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor المورد Xcursor.resized.





  
XCURSOR_SIZE

  
يضبط هذا المتغير حجم المؤشر المطلوب، بالبكسل.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor المورد Xcursor.size.

  

  
إذا لم يتم توفير حجم، سواء عن طريق متغير البيئة أو إعداد المورد، يحاول Xcursor بعد ذلك تعيين المورد Xft.dpi لتخمين حجم مؤشر بحجم 16 نقطة.

  

  
أخيرًا، إذا لم يتم تعيين Xft.dpi، يستخدم Xcursor ارتفاع العرض، مقسومًا على 48 (بافتراض أن الارتفاع هو 768).





  
XCURSOR_THEME

  
يحدد هذا المتغير السمة المطلوبة.





  

  
إذا لم يتم توفير متغير البيئة، يحاول Xcursor المورد Xcursor.theme.

  

  
إذا لم يتم العثور على متغير البيئة أو المورد، يستخدم Xcursor السمة الافتراضية.

الحزمة: libxcursor


التراخيص: HPND-sell-variant









NAME


XcursorGetTheme, XcursorGetThemeCore, XcursorSetTheme, XcursorSetThemeCore - get and set the cursor theme






SYNOPSIS


#include <Xcursor/Xcursor.h>
const char *
XcursorGetTheme(Display *display);
const char *
XcursorGetThemeCore(Display *display);
int
XcursorSetTheme(Display *display, const char *theme_name);
int
XcursorSetThemeCore(Display *display, const char *theme_name);







DESCRIPTION


The libXcursor library provides functions for
    loading and managing cursors. It is part of the Xorg server.


When X cursor themes are enabled, cursors are loaded from theme
    directories specified in the Xcursor theme specification. The default theme
    is named "default".


The functions XcursorGetTheme and
    XcursorSetTheme are used to query and set the cursor
    theme for a given display.


The functions XcursorGetThemeCore and
    XcursorSetThemeCore are used to query and set the
    cursor theme specifically for the core (standard X) cursors.






FUNCTIONAL OVERVIEW


The X cursor theme mechanism allows applications to use custom
    cursor themes. Cursors are identified by names, and the theme mechanism
    maps these names to actual cursor data based on the currently selected
    theme.


Themes are typically stored in directories like
    /usr/share/icons/<theme>/cursors/ and
    /usr/share/X11/xcursorgen/<theme>/.


The system administrator can set a default cursor theme by
    creating a file named
    ~/.XcursorTheme
    or
    ~/.icons/default/index.theme
    (for XDG compliance).


Applications can override the system default by calling
    XcursorSetTheme.


The core cursors (e.g., left_ptr, hand2, text, etc.) are also
    part of the theming mechanism. Applications can opt-in to theming core
    cursors using XcursorSetThemeCore.






DATATYPES


The return values of XcursorGetTheme and
    XcursorGetThemeCore are pointers to character arrays
    (strings) representing the theme names. These strings are managed by the
    libXcursor library and should not be freed by the
    caller.






FUNCTIONS



  
XcursorGetTheme

  
Returns the name of the currently active cursor theme for the given
      display. This includes themes set by applications using
      XcursorSetTheme.

  
XcursorGetThemeCore

  
Returns the name of the currently active theme for core cursors. If
      themeing for core cursors is disabled, it returns NULL.

  
XcursorSetTheme

  
Sets the cursor theme for the given display to
      theme_name. If
      theme_name is NULL,
      the theme reverts to the system default. Returns 0 on success, or a
      negative value on failure.

  
XcursorSetThemeCore

  
Sets the theme for core cursors to
      theme_name. If
      theme_name is NULL,
      core cursors revert to their default appearance. If the theme is not
      found or cannot be loaded, it attempts to use the default cursor theme.
      Returns 0 on success, or a negative value on failure.








ENVIRONMENT



  
XCURSOR_THEME

  
If this environment variable is set to a non-empty string, it is used as
      the default cursor theme name.

  
XCURSOR_THEME_CORE

  
Enables themes for core cursors if the environment variable is
      true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.








CAVEATS


Xcursor will probably change radically in the future; weak
    attempts will be made to retain some level of source-file compatibility.

XcursorGetTheme(3)










الاسم


XcursorGetTheme, XcursorGetThemeCore, XcursorSetTheme, XcursorSetThemeCore - الحصول على سمة المؤشر وتعيينها






الملخص


#include <Xcursor/Xcursor.h>
const char *
XcursorGetTheme(Display *display);
const char *
XcursorGetThemeCore(Display *display);
int
XcursorSetTheme(Display *display, const char *theme_name);
int
XcursorSetThemeCore(Display *display, const char *theme_name);







الوصف


libXcursor توفر مكتبة وظائف لتحميل وإدارة
    المؤشرات. وهي جزء من خادم Xorg.


عند تمكين سمات مؤشر X، يتم تحميل المؤشرات من مجلدات السمات
    المحددة في مواصفات سمات مؤشر X. السمة الافتراضية تسمى "default".


XcursorGetTheme و XcursorSetTheme
    تستخدم للاستعلام عن سمة المؤشر وتعيينها لشاشة عرض معينة.


XcursorGetThemeCore و XcursorSetThemeCore
    تستخدم للاستعلام عن سمة المؤشر وتعيينها خصيصًا لمؤشرات X الأساسية
    (القياسية) .






نظرة عامة وظيفية


تسمح آلية سمات مؤشر X للتطبيقات باستخدام سمات مؤشر مخصصة. يتم
    تحديد المؤشرات بالأسماء، وتقوم آلية السمات بربط هذه الأسماء ببيانات المؤشر
    الفعلية بناءً على السمة المحددة حاليًا.


تُخزن السمات عادةً في مجلدات مثل
    /usr/share/icons/<theme>/cursors/ و
    /usr/share/X11/xcursorgen/<theme>/.


يمكن لمسؤول النظام تعيين سمة مؤشر افتراضية عن طريق إنشاء ملف
    يسمى
    ~/.XcursorTheme
    أو
    ~/.icons/default/index.theme
    (للامتثال لـ XDG).


يمكن للتطبيقات تجاوز الافتراضي للنظام عن طريق استدعاء
    XcursorSetTheme.


تعد مؤشرات X الأساسية (مثل left_ptr، hand2، text، إلخ) جزءًا
    من آلية السمات أيضًا. يمكن للتطبيقات الاشتراك في سمات مؤشرات X الأساسية
    باستخدام
    XcursorSetThemeCore.






أنواع البيانات


قيم الإرجاع لـ
    XcursorGetTheme
    و
    XcursorGetThemeCore
    هي مؤشرات إلى مصفوفات أحرف (سلاسل نصية) تمثل أسماء السمات. تتم إدارة هذه
    السلاسل النصية بواسطة مكتبة
    libXcursor
    ولا ينبغي للمستدعي تحريرها.






الوظائف



  
XcursorGetTheme

  
تُرجع اسم سمة المؤشر النشطة حاليًا لشاشة العرض المحددة. يشمل ذلك السمات
      التي تم تعيينها بواسطة التطبيقات باستخدام
      XcursorSetTheme.

  
XcursorGetThemeCore

  
تُرجع اسم السمة النشطة حاليًا لمؤشرات X الأساسية. إذا تم تعطيل السمات
      لمؤشرات X الأساسية، فإنها تُرجع NULL.

  
XcursorSetTheme

  
تعين سمة المؤشر لشاشة العرض المحددة إلى
      theme_name. إذا كان
      theme_name هو NULL،
      فإن السمة تعود إلى الافتراضي للنظام. تُرجع 0 عند النجاح، أو قيمة
      سالبة عند الفشل.

  
XcursorSetThemeCore

  
تعين السمة لمؤشرات X الأساسية إلى
      theme_name. إذا كان
      theme_name هو NULL،
      فإن مؤشرات X الأساسية تعود إلى مظهرها الافتراضي. إذا لم يتم العثور على
      السمة أو تعذر تحميلها، فإنها تحاول استخدام سمة المؤشر الافتراضية.
      تُرجع 0 عند النجاح، أو قيمة سالبة عند الفشل.








البيئة



  
XCURSOR_THEME

  
إذا تم تعيين متغير البيئة هذا إلى سلسلة نصية غير فارغة، فسيتم استخدامه
      كاسم السمة الافتراضية للمؤشر.

  
XCURSOR_THEME_CORE

  
يمكّن السمات لمؤشرات X الأساسية إذا كان متغير البيئة
      true.





  

  
إذا لم يتم إعطاء متغير البيئة، فإن Xcursor يحاول المورد
      Xcursor.theme_core.

  

  
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام
    XcursorSetThemeCore.








تحذيرات


Xcursor سيشهد تغييرات جذرية على الأرجح في المستقبل؛
    ستبذل محاولات ضعيفة للحفاظ على مستوى معين من التوافق مع ملفات المصدر.
