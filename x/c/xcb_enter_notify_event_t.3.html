xcb_enter_notify_event_t(3)

الحزمة: libxcb

التراخيص: X11

xcb_enter_notify_event_t(3) أحداث XCB xcb_enter_notify_event_t(3)

الاسم

xcb_enter_notify_event_t - المؤشر في نافذة مختلفة

الملخص

#include <xcb/xproto.h>

بنية بيانات الحدث

typedef struct xcb_enter_notify_event_t {
    uint8_t         response_type;
    uint8_t         detail;
    uint16_t        sequence;
    xcb_timestamp_t time;
    xcb_window_t    root;
    xcb_window_t    event;
    xcb_window_t    child;
    int16_t         root_x;
    int16_t         root_y;
    int16_t         event_x;
    int16_t         event_y;
    uint16_t        state;
    uint8_t         mode;
    uint8_t         same_screen_focus;
} xcb_enter_notify_event_t;

حقول الحدث

response_type
نوع هذا الحدث، في هذه الحالة XCB_LEAVE_NOTIFY. هذا الحقل موجود أيضًا في xcb_generic_event_t ويمكن استخدامه للتمييز بين الأحداث.
sequence
رقم التسلسل لآخر طلب تم معالجته بواسطة خادم X11.
detail
لم يتم توثيقه بعد.
time
لم يتم توثيقه بعد.
root
النافذة الجذرية لموضع المؤشر النهائي.
event
النافذة التي تم إنشاء الحدث عليها.
child
إذا كانت نافذة event تحتوي على نوافذ فرعية وكان موضع المؤشر النهائي في إحداها، فسيتم تعيين child إلى تلك النافذة الفرعية، وإلا فسيتم تعيينها إلى XCB_WINDOW_NONE.
root_x
إحداثي X للمؤشر بالنسبة إلى أصل root في وقت الحدث.
root_y
إحداثي Y للمؤشر بالنسبة إلى أصل root في وقت الحدث.
event_x
إذا كانت event على نفس الشاشة مثل root، فهذا هو إحداثي X للمؤشر بالنسبة إلى أصل النافذة الحدث.
event_y
إذا كانت event على نفس الشاشة مثل root، فهذا هو إحداثي Y للمؤشر بالنسبة إلى أصل النافذة الحدث.
state
لم يتم توثيقه بعد.
mode
same_screen_focus
لم يتم توثيقه بعد.
