معاملات الطلب

conn
اتصال XCB بـ X11.
owner_events
إذا كانت 1، فإن `grab_window` ستتلقى أحداث المؤشر. إذا كانت 0، فلن يتم الإبلاغ عن الأحداث لـ `grab_window`.
grab_window
تحدد النافذة التي سيتم الاستيلاء على المؤشر فيها.
event_mask
تحدد أي أحداث مؤشر يتم الإبلاغ عنها للعميل.

cursor
تحدد المؤشر الذي يجب عرضه أو `XCB_NONE` لعدم تغيير المؤشر.
time
تسمح لك معلمة الوقت بتجنب بعض الظروف التي تنشأ إذا استغرقت التطبيقات وقتًا طويلاً للاستجابة أو إذا كانت هناك تأخيرات شبكة طويلة. ضع في اعتبارك سيناريو حيث لديك تطبيقان، وكلاهما يستولي عادةً على المؤشر عند النقر عليهما. إذا حدد كلا التطبيقين الطابع الزمني من الحدث، فقد يستيقظ التطبيق الثاني بشكل أسرع ويستولي بنجاح على المؤشر قبل التطبيق الأول. ثم يحصل التطبيق الأول على إشارة بأن التطبيق الآخر استحوذ على المؤشر قبل معالجة طلبه.

القيمة الخاصة `XCB_CURRENT_TIME` سيتم استبدالها بالوقت الحالي للخادم.

الوصف

يستولي بنشاط على التحكم في المؤشر. يتم الإبلاغ عن أحداث المؤشر اللاحقة فقط للعميل المستولي. يتجاوز أي استيلاء مؤشر نشط بواسطة هذا العميل.

قيمة الإرجاع

يعيد `xcb_grab_pointer_cookie_t`. يجب معالجة الأخطاء عند استدعاء وظيفة الرد `xcb_grab_pointer_reply`.

إذا كنت ترغب في معالجة الأخطاء في حلقة الأحداث بدلاً من ذلك، فاستخدم `xcb_grab_pointer_unchecked`. انظر xcb-requests(3) للتفاصيل.

مثال

/*
 * يستولي على المؤشر بنشاط
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen, xcb_cursor_t cursor) {
    xcb_grab_pointer_cookie_t cookie;
    xcb_grab_pointer_reply_t *reply;
    cookie = xcb_grab_pointer(
        conn,
        false,               /* الحصول على جميع أحداث المؤشر المحددة بواسطة القناع التالي */
        screen->root,        /* الاستيلاء على النافذة الجذر */
        XCB_NONE,            /* الأحداث التي سيتم تمريرها */
        XCB_GRAB_MODE_ASYNC, /* يجب أن تستمر أحداث المؤشر كالمعتاد */
        XCB_GRAB_MODE_ASYNC, /* وضع لوحة المفاتيح */
        XCB_NONE,            /* confine_to = في أي نافذة يجب أن يبقى المؤشر */
        cursor,              /* نقوم بتغيير المؤشر إلى ما أراده المستخدم */
        XCB_CURRENT_TIME
    );
    if ((reply = xcb_grab_pointer_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("تم الاستيلاء على المؤشر بنجاح\n");
        free(reply);
    }
}
