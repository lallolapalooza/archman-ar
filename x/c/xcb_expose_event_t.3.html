xcb_expose_event_t(3)

الحزمة: libxcb

التراخيص: X11

xcb_expose_event_t(3) أحداث XCB xcb_expose_event_t(3)

الاسم

xcb_expose_event_t - لم يتم توثيقه بعد

الملخص

#include <xcb/xproto.h>

هيكل بيانات الحدث

typedef struct xcb_expose_event_t {
    uint8_t      response_type;
    uint8_t      pad0;
    uint16_t     sequence;
    xcb_window_t window;
    uint16_t     x;
    uint16_t     y;
    uint16_t     width;
    uint16_t     height;
    uint16_t     count;
    uint8_t      pad1[2];
} xcb_expose_event_t;

حقول الحدث

response_type
نوع هذا الحدث، وفي هذه الحالة XCB_EXPOSE. هذا الحقل موجود أيضًا في xcb_generic_event_t ويمكن استخدامه للتمييز بين الأحداث.
sequence
رقم تسلسل آخر طلب تمت معالجته بواسطة خادم X11.
window
النافذة المكشوفة (التالفة).
x
الإحداثي X للزاوية العلوية اليسرى للمستطيل المكشوف، نسبة إلى أصل النافذة.
y
الإحداثي Y للزاوية العلوية اليسرى للمستطيل المكشوف، نسبة إلى أصل النافذة.
width
عرض المستطيل المكشوف.
height
ارتفاع المستطيل المكشوف.
count
عدد أحداث Expose التي تتبع هذا الحدث. التطبيقات البسيطة التي لا ترغب في تحسين إعادة العرض عن طريق التمييز بين المناطق الفرعية لنافذتها يمكنها ببساطة تجاهل جميع أحداث Expose ذات الأعداد غير الصفرية وإجراء إعادة عرض كاملة للأحداث ذات الأعداد الصفرية.
