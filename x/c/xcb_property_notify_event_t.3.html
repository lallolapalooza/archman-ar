xcb_property_notify_event_t(3)

الحزمة: libxcb

التراخيص: X11

xcb_property_notify_event_t(3) أحداث XCB xcb_property_notify_event_t(3)

الاسم

xcb_property_notify_event_t - تم تغيير خاصية نافذة

الملخص

#include <xcb/xproto.h>

هيكل بيانات الحدث

typedef struct xcb_property_notify_event_t {
    uint8_t         response_type;
    uint8_t         pad0;
    uint16_t        sequence;
    xcb_window_t    window;
    xcb_atom_t      atom;
    xcb_timestamp_t time;
    uint8_t         state;
    uint8_t         pad1[3];
} xcb_property_notify_event_t;

حقول الحدث

response_type
نوع هذا الحدث، وفي هذه الحالة XCB_PROPERTY_NOTIFY. هذا الحقل موجود أيضًا في xcb_generic_event_t ويمكن استخدامه للتمييز بين الأحداث.
sequence
رقم التسلسل لآخر طلب تم معالجته بواسطة خادم X11.
window
النافذة التي تم تغيير خاصيتها المرتبطة بها.
atom
الرمز (atom) الخاص بالخاصية، للإشارة إلى الخاصية التي تم تغييرها.
time
طابع زمني لوقت الخادم عندما تم تغيير الخاصية.
state
