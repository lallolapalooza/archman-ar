قراءة صور المكتبة

XcursorImage *XcursorLibraryLoadImage (
const char 	*name,
const char 	*theme,
int 	 size)
XcursorImages *XcursorLibraryLoadImages (
	const char 	*name,
	const char 	*theme,
	int 	 size)

تبحث هذه الوظائف في مسار المكتبة، وتحمل أول ملف يتم العثور عليه بالحجم المطلوب، باستخدام وظيفة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا كان theme ليس NULL، استخدمه.
  • إذا كان theme NULL، أو إذا لم يكن هناك تطابق للسمة المطلوبة، استخدم "default" لاسم السمة.
  • إذا فشل كلا البحثين، فإن هذه الوظائف تُرجع NULL.
تختلف الوظيفتان عن عدد الصور المحملة:
  • XcursorLibraryLoadImage تستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages تستدعي XcursorFileLoadImages، وتقوم (عند النجاح) باستدعاء XcursorImagesSetName لربط name بالنتيجة.
