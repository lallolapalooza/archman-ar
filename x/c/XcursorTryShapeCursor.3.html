XcursorTryShapeCursor(3)

NAME

XcursorTryShapeCursor, XcursorSetThemeCore, XcursorGetThemeCore - cursor theme functions

SYNOPSIS

#include <Xcursor/Xcursor.h>
int
XcursorTryShapeCursor(Display *dpy, Cursor cursor, XcursorShape shape,
    unsigned int left_x, unsigned int top_y, unsigned int width,
    unsigned int height);
const char *
XcursorGetThemeCore(void);
void
XcursorSetThemeCore(const char *theme);

DESCRIPTION

These functions are used to manage the theming of cursors.

XcursorTryShapeCursor attempts to find a cursor matching the given cursor and shape, within the rectangle defined by left_x, top_y, width, and height.

XcursorGetThemeCore returns the name of the core cursor theme, or NULL if no core theme is set.

XcursorSetThemeCore sets the name of the core cursor theme. This function is typically called by applications when they want to specify a particular cursor theme to be used for core cursors.

FUNCTIONAL OVERVIEW

The Xcursor library provides functions for working with Xcursor cursor themes. The library allows applications to load and use themed cursors, and to control various aspects of cursor display.

The core cursor theme is a special theme that is used for standard system cursors, such as the arrow pointer, the text caret, and the watch cursor. Applications can use the XcursorSetThemeCore function to set the core cursor theme to a specific theme, or they can rely on the default behavior of the Xcursor library, which is to use the system's default core cursor theme.

The XcursorTryShapeCursor function is useful for applications that need to display custom cursors for specific areas of the screen. For example, an application might use this function to display a resize cursor when the user is hovering over a window border.

DATATYPES

XcursorShape
An enumeration type that defines a set of standard X cursor shapes. These shapes are used to identify specific cursor roles, such as arrow, hand, text, etc.

FUNCTIONS

XcursorTryShapeCursor
Attempts to find a matching cursor within a specified region.
Arguments:
dpy: The display connection.
cursor: The cursor to match.
shape: The desired cursor shape.
left_x, top_y, width, height: The bounding box for the search.
XcursorSetThemeCore
Sets the core cursor theme.
Argument:
theme: The name of the cursor theme to set as the core theme.
XcursorGetThemeCore
Retrieves the name of the current core cursor theme.

ENVIRONMENT

Xcursor.theme_core
Resource for setting the core theme. If the environment variable Xcursor.theme_core is set, it overrides the resource.
HEME_CORE
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.
