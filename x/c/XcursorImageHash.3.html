الاسم

Xcursor - مكتبة إدارة المؤشرات

الملخص

#include <X11/Xcursor/Xcursor.h>

الوصف

Xcursor هي مكتبة بسيطة مصممة للمساعدة في تحديد موقع المؤشرات وتحميلها. يمكن تحميل المؤشرات من ملفات أو الذاكرة. توجد مكتبة من المؤشرات الشائعة التي تقابل أسماء مؤشرات X القياسية. يمكن أن توجد المؤشرات بأحجام متعددة وتقوم المكتبة تلقائيًا باختيار أفضل حجم.

نظرة عامة وظيفية

تم بناء Xcursor على عدة طبقات؛ في الطبقة السفلية يوجد الكود الذي يمكنه تحميل صور المؤشرات من الملفات. فوق ذلك توجد طبقة تحدد موقع ملفات المؤشرات بناءً على مسار المكتبة والموضوع. في الأعلى توجد طبقة تنشئ المؤشرات إما من صورة محملة من ملف أو من أحد مؤشرات X القياسية. عند استخدام الصور المحملة من الملفات، تفضل Xcursor استخدام طلب إنشاء المؤشر الخاص بامتداد Render إذا كان مدعومًا من خادم X. حيثما لا يكون مدعومًا، تقوم Xcursor بتعيين صورة المؤشر إلى مؤشر X قياسي وتستخدم طلب إنشاء المؤشر الأساسي.

ملفات المؤشرات

تحدد Xcursor تنسيقًا جديدًا للمؤشرات على القرص. كل ملف يحتوي على صورة مؤشر واحدة أو أكثر. كل صورة مؤشر موسومة بحجم اسمي بحيث يمكن اختيار أفضل حجم تلقائيًا. يمكن تحميل مؤشرات متعددة من نفس الحجم الاسمي معًا؛ من المتوقع أن تستخدمها التطبيقات كتسلسل متحرك.

يتم تخزين ملفات المؤشرات كرأس يحتوي على جدول محتويات يليه تسلسل من الأجزاء (chunks). يشير جدول المحتويات إلى النوع، النوع الفرعي، والموضع في الملف لكل جزء. رأس الملف يبدو كالتالي:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 بايتات في هذا الرأس
version:	CARD32 رقم إصدار الملف
ntoc:	CARD32 عدد إدخالات جدول المحتويات
toc:	LISTofTOC جدول المحتويات

كل إدخال في جدول المحتويات يبدو كالتالي:


type:	CARD32 نوع الإدخال
subtype:	CARD32 تسمية خاصة بالنوع - حجم للصور
position:	CARD32 الموضع المطلق بالبايت للجدول في الملف

كل جزء في الملف يحتوي على مجموعة من حقول الرأس المشتركة متبوعة بحقول إضافية خاصة بالنوع:


header:	CARD32 بايتات في رأس الجزء (بما في ذلك الحقول الخاصة بالنوع)
type:	CARD32 يجب أن يتطابق مع النوع في TOC لهذا الجزء
subtype:	CARD32 يجب أن يتطابق مع النوع الفرعي في TOC لهذا الجزء
version:	CARD32 رقم إصدار لهذا النوع من الأجزاء

يوجد حاليًا نوعان من الأجزاء المحددة لملفات المؤشرات؛ التعليقات والصور. تبدو التعليقات كالتالي:


header:	20 رؤوس التعليقات حجمها 20 بايت
type:	0xfffe0001 نوع التعليق هو 0xfffe0001
subtype:	{ 1 (حقوق النشر)، 2 (الترخيص)، 3 (أخرى) }
version:	1
length:	CARD32 طول البايت للسلسلة النصية UTF-8
string:	LISTofCARD8 سلسلة نصية UTF-8

تبدو الصور كالتالي:


header:	36 رؤوس الصور حجمها 36 بايت
type:	0xfffd0002 نوع الصورة هو 0xfffd0002
subtype:	CARD32 النوع الفرعي للصورة هو الحجم الاسمي
version:	1
width:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
height:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
xhot:	CARD32 يجب أن يكون أقل من أو يساوي العرض
yhot:	CARD32 يجب أن يكون أقل من أو يساوي الارتفاع
delay:	CARD32 التأخير بين إطارات الرسوم المتحركة بالمللي ثانية
pixels:	LISTofCARD32 بكسلات بتنسيق ARGB مضغوط

المواضيع (Themes)

تتبع Xcursor (في الغالب) مواصفات freedesktop.org لمواضيع الأيقونات. المسار البحث الافتراضي الذي تستخدمه هو

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

داخل كل من هذه الأدلة، تبحث عن دليل باستخدام اسم الموضوع:

•
داخل دليل الموضوع، تبحث عن ملفات المؤشرات في الدليل الفرعي “cursors”.
تبحث Xcursor عن ملف محدد، والذي يجب أن يكون أحد أسماء شكل المؤشر، على سبيل المثال، كما هو مستخدم في XcursorLibraryLoadImage أو XcursorLibraryShape.
•
إذا لم تجد ملف مؤشر مطابق في الدليل الفرعي “cursors”، تبحث Xcursor بعد ذلك عن ملف “index.theme” في كل دليل موضوع للبحث عن مواضيع موروثة. تلك هي الأسطر بهذا التنسيق:
Inherits = اسم-الموضوع

تستخدم Xcursor أول اسم-موضوع موروث، متجاهلة الأخرى التي قد تكون موجودة في ملف “index.theme” معين. إذا وجدت موضوعًا موروثًا، تبحث Xcursor على طول المسار لاستخدامه أيضًا. تتجاهل Xcursor مفاتيح أخرى في ملف “index.theme”، بما في ذلك “Name” (أي، الاسم الذي قد تستخدمه التطبيقات الرسومية كـ اسم عرض).

يمكن سرد أكثر من اسم-موضوع واحد في سطر Inherits=. تنص مواصفات freedesktop.org على أن عناصر القائمة مفصولة بفواصل. تقبل Xcursor أيضًا الفاصلة المنقوطة، ولكنها تحول كلاهما إلى نقطتين (colon) عند البحث في المسار. تتوقع Xcursor سطر Inherits= واحد فقط؛ مواصفات freedesktop.org غير واضحة ما إذا كانت مفاتيح متعددة مسموح بها.

إذا لم يتم تعيين موضوع، أو إذا لم يتم العثور على مؤشر للموضوع المحدد في أي مكان على طول المسار، تتحقق Xcursor من موضوع “default”.

عندما تجد Xcursor ملف مؤشر، تتوقف عن البحث. تستخدم دائمًا ملف المؤشر الأول الذي تم العثور عليه أثناء البحث على طول المسار.

أنواع البيانات

XcursorImage
يحتفظ بصورة مؤشر واحدة في الذاكرة. كل بكسل في المؤشر هو قيمة 32 بت تحتوي على ARGB مع A في البايت الأعلى. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* حجم اسمي للمطابقة */
    XcursorDim 	 width; 	/* العرض الفعلي */
    XcursorDim 	 height; 	/* الارتفاع الفعلي */
    XcursorDim 	 xhot; 	/* نقطة الاتصال x (يجب أن تكون داخل الصورة) */
    XcursorDim 	 yhot; 	/* نقطة الاتصال y (يجب أن تكون داخل الصورة) */
    XcursorPixel 	*pixels; 	/* مؤشر إلى البكسلات */
} XcursorImage;
XcursorImages
يحتفظ ببنى XcursorImage متعددة. يتم تحريرها جميعًا عند تحرير XcursorImages في XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* عدد الصور */
    XcursorImage 	**images; 	/* مصفوفة مؤشرات XcursorImage */
} XcursorImages;
XcursorCursors
يحتفظ بكائنات المؤشر المتعددة. يتم تحريرها جميعًا عند تحرير XcursorCursors. يتم حساب مرجع هذه الكائنات بحيث يمكن لهياكل XcursorAnimate متعددة استخدام نفس XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* الشاشة التي تحتوي على المؤشرات */
    int 	 ref; 	/* عداد المراجع */
    int 	 ncursor; 	/* عدد المؤشرات */
    Cursor 	*cursors; 	/* مصفوفة المؤشرات */
} XcursorCursors;
XcursorAnimate
يشير إلى مجموعة من المؤشرات وتسلسل ضمن تلك المجموعة. قد تشير هياكل XcursorAnimate متعددة إلى نفس XcursorCursors؛ كل منها يحتفظ بمرجع يتم إزالته عند تحرير XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* قائمة المؤشرات المراد استخدامها */
    int 	 sequence; 	/* المؤشر التالي */
} XcursorAnimate;
XcursorFile
توفر Xcursor واجهة برمجة تطبيقات مجردة للوصول إلى بيانات الملف. توفر Xcursor تنفيذًا قياسيًا لهذه الواجهة المجردة؛ التطبيقات حرة في إنشاء تطبيقات إضافية. هذه الدوال توازي الدوال القياسية لـ stdio.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

في القيمة المرجعة والقيم المتوقعة للمعلمات؛ تقوم وظائف القراءة والكتابة بتبديل الوسائط حولها لتتوافق مع إصدارات POSIX. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

تبحث هذه الوظائف في مسار المكتبة، وتحمل أول ملف تم العثور عليه بالحجم المطلوب، باستخدام وظيفة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا لم يكن theme فارغًا (NULL)، فاستخدمه.
  • إذا كان theme فارغًا (NULL)، أو إذا لم يكن هناك تطابق للسمة المطلوبة، فاستخدم "default" لاسم السمة.
  • إذا فشل كلا البحثين، فإن هذه الوظائف تُرجع فارغًا (NULL).
تختلف الوظيفتان بأكثر من عدد الصور المحملة:
  • XcursorLibraryLoadImage تستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages تستدعي XcursorFileLoadImages، وتقوم (عند النجاح) باستدعاء XcursorImagesSetName لربط name بالنتيجة.

- title: ENVIRONMENT
  content: |
    
Environment variables can be used to override resource settings,
        which in turn override compiled-in default values.

    
Some of the environment variables recognized by Xcursor are
        booleans, specified as follows:

    

      

        
true for
          “t”, “1”, “y” or
          “on”

        

        
false for
          “f”, “0”, “n” or
          “off”

        

      

    

    
Xcursor ignores other values for these booleans.

    

      
HOME

      
Xcursor interprets “~” in the search list as the home
          directory, using this variable rather than the password database.

      
XCURSOR_ANIM

      
If the display supports the Render CreateCursor request, and the Render
          feature is enabled, disable animated cursors if the environment
          variable is false.

    

    

      

      
If the environment variable is not given, Xcursor uses the resource
          Xcursor.anim.

    

    

      
XCURSOR_CORE

      
If the display supports the Render CreateCursor request disable the Render
          feature if the environment variable is false.

    

    

      

      
If the environment variable is not given, Xcursor uses the resource
          Xcursor.core.

    

    

      
XCURSOR_DISCOVER

      
If the variable is set, Xcursor turns on a logging feature. It displays
          the hash value and the image so that users can see which cursor name is
          associated with each image.

    

    

      

      
There is no corresponding resource setting.

    

    

      
XCURSOR_DITHER

      
This variable sets the desired dither.

    

    

      

      
If the environment variable is not given, Xcursor uses the resource
          Xcursor.dither.

      

      
If neither environment variable or resource is found, Xcursor uses
          “threshold”

      

      
These are the recognized values:

    

    

      

        
diffuse

        

        
median

        

        
ordered

        

        
threshold

        

      

    

    

      
XCURSOR_PATH

      
This variable sets the list of paths in which to search for cursors,
          rather than the compiled-in default list.

    

    

      

      
Directories in this path are separated by colons (:).

    

    

      
XCURSOR_RESIZED

      
Enables automatic resizing of cursors to improve their displayed size if
          the environment variable is true.

    

    

      

      
If the environment variable is not given, Xcursor tries the
          Xcursor.resized resource.

    

    

      
XCURSOR_SIZE

      
This variable sets the desired cursor size, in pixels.

    

    

      

      
If the environment variable is not given, Xcursor tries the
          Xcursor.size resource.

      

      
If no size is given, whether by environment variable or resource setting,
          Xcursor next tries the Xft.dpi resource setting to guess the size
          of a 16-point cursor.

      

      
Finally, if Xft.dpi is not set, Xcursor uses the display height,
          dividing by 48 (assuming that the height is 768).

    

    

      
XCURSOR_THEME

      
This variable selects the desired theme.

    

    

      

      
If the environment variable is not given, Xcursor tries the
          Xcursor.theme resource.

      

      
If neither environment variable or resource is found, Xcursor uses the
          default theme.

    

    

      
XCURSOR_THEME_CORE

      
If the display supports the Render CreateCursor request, and the Render
          feature is enabled, disable themes for core cursors if the
          environment variable is false.

    

    

      

      
If the environment variable is not given, Xcursor uses the resource
          Xcursor.theme_core.
