XcursorLibraryLoadCursors(3)

الحزمة: libxcursor

التراخيص: HPND-sell-variant

NAME

XcursorLibraryLoadCursors, XcursorLibraryLoadCursorByName, XcursorLibraryLoadIcon

load cursors and icons from disk

SYNOPSIS

#include <Xcursor/Xcursor.h>

XcursorCursors * XcursorLibraryLoadCursors( const char *filename );

XcursorCursor * XcursorLibraryLoadCursorByName( const char *name );

XcursorImage * XcursorLibraryLoadIcon( const char *name );

DESCRIPTION

XcursorLibraryLoadCursors loads a cursor theme from the specified filename. The name is searched for in standard locations according to the Icon Theme specification. The specification can be found at: https://specifications.freedesktop.org/icon-theme-spec/.

XcursorLibraryLoadCursorByName loads a single cursor named name. The name is searched for in standard locations, and may contain arbitrary characters.

XcursorLibraryLoadIcon loads an icon named name. The name is searched for in standard locations.

If the icon theme or icon is not found, these functions return NULL.

FUNCTIONAL OVERVIEW

The Xcursor library supports loading cursors and icons from disk.

It searches for cursors and icons in standard locations, based on the Icon Theme specification. These locations are typically defined by the environment variable XCURSOR_THEME_DIRS, or fall back to directories like /usr/share/icons.

The library provides functions to load:

  • Entire cursor themes (XcursorLibraryLoadCursors).
  • Specific cursors by name (XcursorLibraryLoadCursorByName).
  • Icons by name (XcursorLibraryLoadIcon).

These functions are useful for applications that need to use custom cursors or icons that are not part of the default system theme.

DATATYPES

XcursorCursors
A structure representing a collection of cursors, typically from a theme.
XcursorCursor
A structure representing a single cursor.
XcursorImage
A structure representing an image, which can be used for cursors or icons.

FUNCTIONS

XcursorLibraryLoadCursors
Loads a cursor theme from a file.
XcursorLibraryLoadCursorByName
Loads a specific cursor by its name.
XcursorLibraryLoadIcon
Loads an icon by its name.

ENVIRONMENT

OR_THEME_CORE
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.

CAVEATS

Xcursor will probably change radically in the future; weak attempts will be made to retain some level of source-file compatibility.

الاسم

XcursorLibraryLoadCursors, XcursorLibraryLoadCursorByName, XcursorLibraryLoadIcon

تحميل المؤشرات والأيقونات من القرص

الملخص

#include <Xcursor/Xcursor.h>

XcursorCursors * XcursorLibraryLoadCursors( const char *filename );

XcursorCursor * XcursorLibraryLoadCursorByName( const char *name );

XcursorImage * XcursorLibraryLoadIcon( const char *name );

الوصف

XcursorLibraryLoadCursors تقوم بتحميل سمة مؤشر من الملف المحدد. يتم البحث عن الاسم في مواقع قياسية وفقًا لمواصفات سمة الأيقونة. يمكن العثور على المواصفات على: https://specifications.freedesktop.org/icon-theme-spec/.

XcursorLibraryLoadCursorByName تقوم بتحميل مؤشر واحد بالاسم المحدد name. يتم البحث عن الاسم في مواقع قياسية، وقد يحتوي على أي أحرف.

XcursorLibraryLoadIcon تقوم بتحميل أيقونة بالاسم المحدد name. يتم البحث عن الاسم في مواقع قياسية.

إذا لم يتم العثور على سمة الأيقونة أو الأيقونة، فإن هذه الدوال تعيد NULL.

نظرة عامة وظيفية

تدعم مكتبة Xcursor تحميل المؤشرات والأيقونات من القرص.

تبحث عن المؤشرات والأيقونات في مواقع قياسية، بناءً على مواصفات سمة الأيقونة. عادةً ما يتم تعريف هذه المواقع بواسطة متغير البيئة XCURSOR_THEME_DIRS، أو يتم الرجوع إلى مجلدات مثل /usr/share/icons.

توفر المكتبة دوال لتحميل:

  • سمات مؤشرات كاملة (XcursorLibraryLoadCursors).
  • مؤشرات محددة بالاسم (XcursorLibraryLoadCursorByName).
  • أيقونات بالاسم (XcursorLibraryLoadIcon).

هذه الدوال مفيدة للتطبيقات التي تحتاج إلى استخدام مؤشرات أو أيقونات مخصصة ليست جزءًا من سمة النظام الافتراضية.

أنواع البيانات

XcursorCursors
بنية تمثل مجموعة من المؤشرات، عادةً من سمة.
XcursorCursor
بنية تمثل مؤشرًا واحدًا.
XcursorImage
بنية تمثل صورة، والتي يمكن استخدامها للمؤشرات أو الأيقونات.

الدوال

XcursorLibraryLoadCursors
تقوم بتحميل سمة مؤشر من ملف.
XcursorLibraryLoadCursorByName
تقوم بتحميل مؤشر محدد باسمه.
XcursorLibraryLoadIcon
تقوم بتحميل أيقونة باسمها.

البيئة

OR_THEME_CORE
تمكّن السمات للمؤشرات الأساسية إذا كان متغير البيئة true.
إذا لم يتم تقديم متغير البيئة، تحاول Xcursor المورد Xcursor.theme_core.
يمكن للتطبيق تمكين أو تعطيل السمات باستخدام XcursorSetThemeCore.

تحذيرات

من المحتمل أن تتغير Xcursor بشكل جذري في المستقبل؛ سيتم بذل محاولات ضعيفة للحفاظ على مستوى معين من توافق الملفات المصدر.
