NAME

xcb_get_window_attributes, xcb_get_window_attributes_unchecked, xcb_get_window_attributes_reply - get window attributes

DESCRIPTION

يحصل على السمات الحالية للنافذة المحددة window.

RETURN VALUE

يعيد xcb_get_window_attributes_cookie_t. يجب التعامل مع الأخطاء عند استدعاء وظيفة الرد xcb_get_window_attributes_reply.

إذا كنت ترغب في التعامل مع الأخطاء في حلقة الأحداث بدلاً من ذلك، استخدم xcb_get_window_attributes_unchecked. انظر xcb-requests(3) للتفاصيل.
