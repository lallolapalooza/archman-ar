XCirculateRequestEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XCirculateRequestEvent(3) دوال XLIB XCirculateRequestEvent(3)

الاسم

XCirculateRequestEvent - بنية حدث طلب التدوير

البنى

تحتوي بنية أحداث CirculateRequest على:

typedef struct {
        int type;       /* CirculateRequest */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window parent;
        Window window;
        int place;      /* PlaceOnTop, PlaceOnBottom */
} XCirculateRequestEvent;

عندما تتلقى هذا الحدث، يتم تعيين أعضاء البنية على النحو التالي.

يتم تعيين عضو النوع (type) إلى اسم ثابت نوع الحدث الذي يحدده بشكل فريد. على سبيل المثال، عندما يقوم خادم X بالإبلاغ عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل بنية XGraphicsExposeEvent مع تعيين عضو النوع (type) إلى GraphicsExpose. يتم تعيين عضو العرض (display) إلى مؤشر للعرض الذي تمت قراءة الحدث منه. يتم تعيين عضو إرسال الحدث (send_event) إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو الرقم التسلسلي (serial) من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من 16 بت الأقل أهمية إلى قيمة كاملة 32 بت. يتم تعيين عضو النافذة (window) إلى النافذة الأكثر فائدة لمعالجات التوزيع.

يتم تعيين عضو النافذة الأم (parent) إلى النافذة الأم. يتم تعيين عضو النافذة (window) إلى النافذة الفرعية المراد إعادة تكديسها. يتم تعيين عضو المكان (place) إلى الموضع الجديد في ترتيب التكديس ويجب أن يكون إما PlaceOnTop (وضع في الأعلى) أو PlaceOnBottom (وضع في الأسفل). إذا كان PlaceOnTop، يجب أن تكون النافذة الفرعية فوق جميع الأشقاء. إذا كان PlaceOnBottom، يجب أن تكون النافذة الفرعية أسفل جميع الأشقاء.
