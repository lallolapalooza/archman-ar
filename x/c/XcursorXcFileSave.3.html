NAME

XcursorConfig, XcursorConfigInit, XcursorConfigParse, XcursorConfigDestroy, XcursorGetDefaultResName, XcursorGetDefaultResClass, XcursorGetTheme, XcursorGetDefaultTheme, XcursorSetTheme, XcursorGetThemeCore, XcursorSetThemeCore - Configuration functions for Xcursor

SYNOPSIS

#include <Xcursor/Xcursor.h>
typedef struct _XcursorConfig *XcursorConfigPtr;
Bool XcursorConfigInit(
    XcursorConfigPtr config,
    const char *name);
Bool XcursorConfigParse(
    XcursorConfigPtr config,
    const char *filename);
void XcursorConfigDestroy(
    XcursorConfigPtr config);
const char *XcursorGetDefaultResName(
    void);
const char *XcursorGetDefaultResClass(
    void);
const char *XcursorGetTheme(
    Display * dpy);
const char *XcursorGetDefaultTheme(
    Display * dpy);
Bool XcursorSetTheme(
    Display * dpy,
    const char * theme_name);
Bool XcursorGetThemeCore(
    Display * dpy);
Bool XcursorSetThemeCore(
    Display * dpy,
    Bool enabled);

DESCRIPTION

The Xcursor library provides functions for loading and using Xcursor theme files. The theme files specify cursors to be used for different parts of the user interface. This document describes the configuration functions for Xcursor themes.

FUNCTIONAL OVERVIEW

XcursorConfigInit initializes an XcursorConfigPtr structure with the given name. This structure is used to manage the loaded theme configuration.

XcursorConfigParse parses a theme configuration file specified by filename and loads the theme settings into the provided XcursorConfigPtr structure.

XcursorConfigDestroy frees the resources associated with an XcursorConfigPtr structure.

XcursorGetDefaultResName returns the default resource name for Xcursor themes.

XcursorGetDefaultResClass returns the default resource class for Xcursor themes.

XcursorGetTheme retrieves the name of the currently active Xcursor theme for the given display.

XcursorGetDefaultTheme retrieves the name of the default Xcursor theme.

XcursorSetTheme sets the active Xcursor theme for the given display to the specified theme_name.

XcursorGetThemeCore checks if themes are enabled for core cursors.

XcursorSetThemeCore enables or disables themes for core cursors.

DATATYPES

typedef struct _XcursorConfig *XcursorConfigPtr;
A pointer to an opaque structure that holds Xcursor theme configuration data.

FUNCTIONS

XcursorConfigInit()
Initializes an Xcursor configuration structure. The name parameter is used to identify the theme resource.
XcursorConfigParse()
Parses the Xcursor theme configuration file specified by filename. The parsed information is stored in the config structure. Returns True on success, False on failure.
XcursorConfigDestroy()
Frees the memory allocated for the Xcursor configuration structure.
XcursorGetDefaultResName()
Returns the default X resource name used for Xcursor themes (e.g., "Xcursor.theme").
XcursorGetDefaultResClass()
Returns the default X resource class used for Xcursor themes (e.g., "Xcursor").
XcursorGetTheme()
Retrieves the name of the currently active Xcursor theme for the specified display dpy. Returns NULL if no theme is currently set or an error occurred.
XcursorGetDefaultTheme()
Retrieves the name of the default Xcursor theme. This is typically determined by system configuration or environment variables.
XcursorSetTheme()
Sets the Xcursor theme for the specified display dpy to the theme named theme_name. Returns True on success, False on failure.
XcursorGetThemeCore()
Checks if the Xcursor theme is currently enabled for core X cursors. Returns True if enabled, False otherwise.
XcursorSetThemeCore()
Enables or disables the use of Xcursor themes for core X cursors. If enabled is True, themes will be used for core cursors; otherwise, they will be disabled. Returns True on success, False on failure.

ENVIRONMENT

Xcursor.theme_core
Enables themes for core cursors if the environment variable is true.
If the environment variable is not given, Xcursor tries the Xcursor.theme_core resource.
An application can enable or disable themes using XcursorSetThemeCore.

CAVEATS
