الاسم

Xcursor - مكتبة إدارة المؤشرات

الملخص

#include <X11/Xcursor/Xcursor.h>

الوصف

Xcursor هي مكتبة بسيطة مصممة للمساعدة في تحديد وتحميل المؤشرات. يمكن تحميل المؤشرات من ملفات أو ذاكرة. توجد مكتبة للمؤشرات الشائعة التي تتوافق مع أسماء مؤشرات X القياسية. يمكن أن توجد المؤشرات بأحجام مختلفة والمكتبة تختار تلقائيًا أفضل حجم.

نظرة عامة وظيفية

تم بناء Xcursor على عدة طبقات؛ في الطبقة السفلية يوجد كود يمكنه تحميل صور المؤشرات من الملفات. فوق ذلك توجد طبقة تحدد مواقع ملفات المؤشرات بناءً على مسار المكتبة والموضوع. في الأعلى توجد طبقة تبني المؤشرات إما من صورة تم تحميلها من ملف أو أحد مؤشرات X القياسية. عند استخدام صور تم تحميلها من ملفات، تفضل Xcursor استخدام طلب إنشاء مؤشر امتداد Render إذا كان مدعومًا بواسطة خادم X. حيث لا يتم دعمه، تقوم Xcursor بتعيين صورة المؤشر إلى مؤشر X قياسي وتستخدم طلب إنشاء مؤشر أساسي.

ملفات المؤشرات

تحدد Xcursor تنسيقًا جديدًا للمؤشرات على القرص. يحتوي كل ملف على صورة مؤشر واحدة أو أكثر. يتم تمييز كل صورة مؤشر بحجم اسمي بحيث يمكن تحديد أفضل حجم تلقائيًا. يمكن تحميل مؤشرات متعددة بنفس الحجم الاسمي معًا؛ من المتوقع أن تستخدمها التطبيقات كتسلسل متحرك.

يتم تخزين ملفات المؤشرات كرأس يحتوي على جدول محتويات متبوعًا بسلسلة من الأجزاء. يشير جدول المحتويات إلى النوع، النوع الفرعي، والموقع في الملف لكل جزء. يبدو رأس الملف كما يلي:


magic:	CARD32 "Xcur" (0x58, 0x63, 0x75, 0x72)
header:	CARD32 بايت في هذا الرأس
version:	CARD32 رقم إصدار الملف
ntoc:	CARD32 عدد إدخالات جدول المحتويات
toc:	LISTofTOC جدول المحتويات

كل إدخال في جدول المحتويات يبدو كما يلي:


type:	CARD32 نوع الإدخال
subtype:	CARD32 تسمية خاصة بالنوع - الحجم للصور
position:	CARD32 موقع البايت المطلق للجدول في الملف

كل جزء في الملف يحتوي على مجموعة من رؤوس الحقول المشتركة متبوعة بحقول إضافية خاصة بالنوع:


header:	CARD32 بايت في رأس الجزء (بما في ذلك الحقول الخاصة بالنوع)
type:	CARD32 يجب أن يتطابق مع النوع في TOC لهذا الجزء
subtype:	CARD32 يجب أن يتطابق مع النوع الفرعي في TOC لهذا الجزء
version:	CARD32 رقم إصدار لهذا النوع من الأجزاء

يوجد حاليًا نوعان من الأجزاء معرفان لملفات المؤشرات؛ التعليقات والصور. التعليقات تبدو كما يلي:


header:	20 رؤوس التعليقات هي 20 بايت
type:	0xfffe0001 نوع التعليق هو 0xfffe0001
subtype:	{ 1 (حقوق النشر)، 2 (الترخيص)، 3 (أخرى) }
version:	1
length:	CARD32 طول البايت للسلسلة UTF-8
string:	LISTofCARD8 سلسلة UTF-8

الصور تبدو كما يلي:


header:	36 رؤوس الصور هي 36 بايت
type:	0xfffd0002 نوع الصورة هو 0xfffd0002
subtype:	CARD32 نوع الصورة الفرعي هو الحجم الاسمي
version:	1
width:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
height:	CARD32 يجب أن يكون أقل من أو يساوي 0x7fff
xhot:	CARD32 يجب أن يكون أقل من أو يساوي العرض
yhot:	CARD32 يجب أن يكون أقل من أو يساوي الارتفاع
delay:	CARD32 التأخير بين إطارات الرسوم المتحركة بالمللي ثانية
pixels:	LISTofCARD32 بكسلات بتنسيق ARGB مكدس

المواضيع

تتبع Xcursor (في الغالب) مواصفات freedesktop.org لترقين الأيقونات. مسار البحث الافتراضي الذي تستخدمه هو

~/.local/share/icons, ~/.icons, /usr/share/icons, /usr/share/pixmaps

داخل كل من هذه الدلائل، تبحث عن دليل باستخدام اسم الموضوع:

•
داخل دليل الموضوع، تبحث عن ملفات المؤشرات في الدليل الفرعي "cursors".
تبحث Xcursor عن ملف معين، يجب أن يكون أحد أسماء الأشكال للمؤشر، على سبيل المثال، كما هو مستخدم في XcursorLibraryLoadImage أو XcursorLibraryShape.
•
إذا لم تجد ملف مؤشر مطابق في الدليل الفرعي "cursors"، تبحث Xcursor بعد ذلك عن ملف "index.theme" في كل دليل موضوع للبحث عن مواضيع موروثة. هذه سطور بهذا التنسيق:
Inherits = اسم-الموضوع

تستخدم Xcursor أول اسم-موضوع موروث، متجاهلة الآخرين الذين قد يكونون موجودين في ملف "index.theme" معين. إذا وجدت موضوعًا موروثًا، تبحث Xcursor على طول المسار لاستخدامه أيضًا. تتجاهل Xcursor مفاتيح أخرى في ملف "index.theme"، بما في ذلك "Name" (أي، الاسم الذي قد تستخدمه التطبيقات الرسومية كـ اسم عرض).

يمكن سرد أكثر من اسم-موضوع واحد في سطر Inherits=. تنص مواصفات freedesktop.org على أن عناصر القائمة مفصولة بفواصل. تقبل Xcursor أيضًا الفاصلة المنقوطة، ولكنها تترجم كليهما إلى نقطتين عند البحث في المسار. تتوقع Xcursor سطرًا واحدًا فقط من Inherits=؛ مواصفات freedesktop.org غير واضحة ما إذا كانت المفاتيح المتعددة مسموح بها.

إذا لم يتم تعيين موضوع، أو إذا لم يتم العثور على مؤشر للموضوع المحدد في أي مكان على طول المسار، تتحقق Xcursor من موضوع "default".

عندما تجد Xcursor ملف مؤشر، تتوقف عن البحث. تستخدم دائمًا أول ملف مؤشر يتم العثور عليه أثناء البحث على طول المسار.

أنواع البيانات

XcursorImage
تحتوي على صورة مؤشر واحدة في الذاكرة. كل بكسل في المؤشر هو قيمة 32 بت تحتوي على ARGB مع A في البايت الأعلى. 


typedef struct _XcursorImage {
    XcursorDim 	 size; 	/* حجم اسمي للمطابقة */
    XcursorDim 	 width; 	/* عرض فعلي */
    XcursorDim 	 height; 	/* ارتفاع فعلي */
    XcursorDim 	 xhot; 	/* نقطة ساخنة x (يجب أن تكون داخل الصورة) */
    XcursorDim 	 yhot; 	/* نقطة ساخنة y (يجب أن تكون داخل الصورة) */
    XcursorPixel 	*pixels; 	/* مؤشر إلى البكسلات */
} XcursorImage;
XcursorImages
تحتوي على هياكل XcursorImage متعددة. يتم تحريرها جميعًا عند تحرير XcursorImages في XcursorImagesDestroy. 


typedef struct _XcursorImages {
    int 	 nimage; 	/* عدد الصور */
    XcursorImage 	**images; 	/* مصفوفة مؤشرات XcursorImage */
} XcursorImages;
XcursorCursors
تحتوي على كائنات مؤشر متعددة. يتم تحريرها جميعًا عند تحرير XcursorCursors. هذه محسوبة بالمرجع بحيث يمكن لهياكل XcursorAnimate متعددة استخدام نفس XcursorCursors. 


typedef struct _XcursorCursors {
    Display 	*dpy; 	/* شاشة عرض تحتوي على المؤشرات */
    int 	 ref; 	/* عداد المراجع */
    int 	 ncursor; 	/* عدد المؤشرات */
    Cursor 	*cursors; 	/* مصفوفة المؤشرات */
} XcursorCursors;
XcursorAnimate
تشير إلى مجموعة من المؤشرات وتسلسل ضمن تلك المجموعة. قد تشير هياكل XcursorAnimate متعددة إلى نفس XcursorCursors؛ كل منها يحمل مرجعًا يتم إزالته عند تحرير XcursorAnimate. 


typedef struct _XcursorAnimate {
    XcursorCursors 	*cursors; 	/* قائمة المؤشرات المراد استخدامها */
    int 	 sequence; 	/* أي مؤشر هو التالي */
} XcursorAnimate;
XcursorFile
توفر Xcursor واجهة برمجة تطبيقات مجردة للوصول إلى بيانات الملف. توفر Xcursor تطبيق stdio لهذه الواجهة المجردة؛ التطبيقات حرة في إنشاء تطبيقات إضافية. هذه الدوال موازية لدوال stdio.

هذا الموقع غير مرتبط بـ Arch Linux ولا تابع له بأي شكل من الأشكال. المحتوى هو ترجمة فقط لصفحات دليل Arch المنشورة على man.archlinux.org.

ns في القيمة المرجعة وقيم الوسيطات المتوقعة؛ تقوم وظائف القراءة والكتابة بتبديل الوسيطات حولها لتتناسب مع إصدارات POSIX. 


typedef struct _XcursorFile {
    void *closure;
    int (*read)  (XcursorFile *file, unsigned char *buf, int len);
    int (*write) (XcursorFile *file, unsigned char *buf, int len);
    int (*seek)  (XcursorFile *file, long offset, int whence);
};

	const char 	*name,

تقوم هذه الوظائف بالبحث في مسار المكتبة، وتحميل أول ملف يتم العثور عليه بالحجم المطلوب، باستخدام وظيفة خاصة (XcursorScanTheme) للعثور على السمة المناسبة:

  • إذا كان theme ليس NULL، فاستخدمه.
  • إذا كان theme NULL، أو إذا لم يكن هناك تطابق للسمة المطلوبة، فاستخدم "default" لاسم السمة.
  • إذا فشل كلا البحثين، فإن هذه الوظائف تعيد NULL.
تختلف الوظيفتان عن عدد الصور المحملة:
  • XcursorLibraryLoadImage تستدعي XcursorFileLoadImage ولكن
  • XcursorLibraryLoadImages تستدعي XcursorFileLoadImages، (عند النجاح) تستدعي XcursorImagesSetName لربط name بالنتيجة.

Environment variables can be used to override resource settings,
          which in turn override compiled-in default values.

      
Some of the environment variables recognized by Xcursor are
          booleans, specified as follows:

      

      

        
true for
          “t”, “1”, “y” or
          “on”

        

        
false for
          “f”, “0”, “n” or
          “off”

        

      

      

      
Xcursor ignores other values for these booleans.

      

        
HOME

        
Xcursor interprets “~” in the search list as the home
            directory, using this variable rather than the password database.

        
XCURSOR_ANIM

        
If the display supports the Render CreateCursor request, and the Render
            feature is enabled, disable animated cursors if the environment
            variable is false.

      

      

        

        
If the environment variable is not given, Xcursor uses the resource
            Xcursor.anim.

      

      

        
XCURSOR_CORE

        
If the display supports the Render CreateCursor request disable the Render
            feature if the environment variable is false.

      

      

        

        
If the environment variable is not given, Xcursor uses the resource
            Xcursor.core.

      

      

        
XCURSOR_DISCOVER

        
If the variable is set, Xcursor turns on a logging feature. It displays
            the hash value and the image so that users can see which cursor name is
            associated with each image.

      

      

        

        
There is no corresponding resource setting.

      

      

        
XCURSOR_DITHER

        
This variable sets the desired dither.

      

      

        

        
If the environment variable is not given, Xcursor uses the resource
            Xcursor.dither.

        

        
If neither environment variable or resource is found, Xcursor uses
            “threshold”

        

        
These are the recognized values:

      

      

      

        
diffuse

        

        
median

        

        
ordered

        

        
threshold

        

      

      

      

        
XCURSOR_PATH

        
This variable sets the list of paths in which to search for cursors,
            rather than the compiled-in default list.

      

      

        

        
Directories in this path are separated by colons (:).

      

      

        
XCURSOR_RESIZED

            the environment variable is true.

            Xcursor.resized resource.

NAME


XcursorSetTheme, XcursorGetTheme, XcursorSetThemeCore, XcursorGetThemeCore, XcursorSupportsTheme - set and get the cursor theme






SYNOPSIS


#include <Xcursor/Xcursor.h>
Bool
XcursorSetTheme(Display *display, const char *theme_name);
const char*
XcursorGetTheme(Display *display);
Bool
XcursorSetThemeCore(Display *display, const char *theme_name);
const char*
XcursorGetThemeCore(Display *display);
Bool
XcursorSupportsTheme(Display *display);







DESCRIPTION


The Xcursor library provides facilities for loading and displaying
    cursor themes.


XcursorSetTheme() sets the cursor theme to be used by the X server.
    If theme_name is NULL, the default theme is loaded.


XcursorGetTheme() returns the name of the currently active cursor
    theme.


XcursorSetThemeCore() sets the cursor theme to be used for core
    (standard) X cursors. This is useful if you want to use a specific cursor
    theme for all cursors, including the standard ones like arrow, hand, etc.


XcursorGetThemeCore() returns the name of the currently active core
    cursor theme.


XcursorSupportsTheme() checks if the X server supports cursor
    themes.






FUNCTIONAL OVERVIEW


Cursor themes are specified by a name, e.g. "Adwaita", "Breeze",
    "DMZ-White". A theme may contain cursors of different sizes and resolutions,
    and may include fallback cursors for core cursor shapes.


Cursor themes are searched for in standard locations, as defined
    by the Icon Theme Specification.


When an application calls XcursorSetTheme(), the library tries to
    load the specified theme. If it succeeds, the X server will use cursors from
    that theme for application-defined cursors.


If XcursorSetThemeCore() is called, the library tries to load the
    specified theme for core cursors as well. If the theme does not provide
    cursors for all core cursor shapes, the default core cursors will be used as
    a fallback.


If XcursorSupportsTheme() returns True,
    cursor themes are supported by the server. Otherwise, they are not.






DATATYPES


The Xcursor library uses its own data types, which are defined in
    <Xcursor/Xcursor.h>.






FUNCTIONS



  
XcursorSetTheme

  
Sets the cursor theme for the given display. If theme_name
      is NULL, the default theme is loaded. Returns
      True on success, False
      otherwise.

  
XcursorGetTheme

  
Returns the name of the currently active cursor theme. The returned string
      is allocated by the library and should be freed by the caller using
      Xfree().

  
XcursorSetThemeCore

  
Sets the cursor theme for core cursors. This function is similar to
      XcursorSetTheme(), but it only affects core cursors.
      Returns True on success, False
      otherwise.

  
XcursorGetThemeCore

  
Returns the name of the currently active core cursor theme. The returned
      string is allocated by the library and should be freed by the caller using
      Xfree().

  
XcursorSupportsTheme

  
Checks if the X server supports cursor themes. Returns True
      if supported, False otherwise.








ENVIRONMENT



  
XCURSOR_THEME

  
Specifies the cursor theme to be used. If this variable is set, it overrides
      any theme set by XcursorSetTheme().

  
XCURSOR_CORE_THEME

  
Specifies the cursor theme to be used for core cursors if the environment
      variable is true.





  

  
If the environment variable is not given, Xcursor tries the
      Xcursor.theme_core resource.

  

  
An application can enable or disable themes using
    XcursorSetThemeCore.
