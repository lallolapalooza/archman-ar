XClipBox(3)

الحزمة: libx11

التراخيص: MIT AND X11

XPolygonRegion(3) دوال XLIB XPolygonRegion(3)

الاسم

XPolygonRegion, XClipBox - توليد المناطق

الصيغة

Region XPolygonRegion(XPoint points[], int n, int fill_rule);

int XClipBox(Region r, XRectangle *rect_return);

المعاملات

fill_rule
يحدد قاعدة التعبئة التي تريد تعيينها لوحدة التحكم في الرسومات (GC) المحددة. يمكنك تمرير EvenOddRule أو WindingRule.
n
يحدد عدد النقاط في المضلع.
points
يحدد مصفوفة من النقاط.
r
يحدد المنطقة.
rect_return
يعيد أصغر مستطيل شامل.

الوصف

تقوم الدالة XPolygonRegion بإرجاع منطقة للمضلع المحدد بواسطة مصفوفة النقاط. لشرح fill_rule، راجع XCreateGC.

تقوم الدالة XClipBox بإرجاع أصغر مستطيل يحيط بالمنطقة المحددة.

انظر أيضًا

XCreateGC(3)، XDrawPoint(3)، XDrawRectangle(3)
