XColormapEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XColormapEvent(3) وظائف XLIB XColormapEvent(3)

الاسم

XColormapEvent - بنية حدث ColormapNotify

البنيات

تحتوي البنية الخاصة بأحداث ColormapNotify على:

typedef struct {
        int type;       /* ColormapNotify */
        unsigned long serial;   /* # of last request processed by server */
        Bool send_event;        /* true if this came from a SendEvent request */
        Display *display;       /* Display the event was read from */
        Window window;
        Colormap colormap;      /* colormap or None */
        Bool new;
        int state;      /* ColormapInstalled, ColormapUninstalled */
} XColormapEvent;

عند تلقي هذا الحدث، يتم تعيين أعضاء البنية على النحو التالي.

يتم تعيين عضو النوع (type) إلى ثابت اسم نوع الحدث الذي يميزه بشكل فريد. على سبيل المثال، عندما يبلغ خادم X عن حدث GraphicsExpose لتطبيق عميل، فإنه يرسل بنية XGraphicsExposeEvent مع تعيين عضو النوع إلى GraphicsExpose. يتم تعيين عضو العرض (display) إلى مؤشر إلى العرض الذي تم قراءة الحدث منه. يتم تعيين عضو إرسال_الحدث (send_event) إلى True إذا جاء الحدث من طلب بروتوكول SendEvent. يتم تعيين عضو الرقم التسلسلي (serial) من الرقم التسلسلي المبلغ عنه في البروتوكول ولكن تم توسيعه من أقل 16 بت أهمية إلى قيمة كاملة 32 بت. يتم تعيين عضو النافذة (window) إلى النافذة الأكثر فائدة لموزعات الأدوات.

يتم تعيين عضو النافذة (window) إلى النافذة التي تم تغيير خريطة الألوان المرتبطة بها، أو تثبيتها، أو إلغاء تثبيتها. بالنسبة لخريطة ألوان تم تغييرها، أو تثبيتها، أو إلغاء تثبيتها، يتم تعيين عضو خريطة الألوان (colormap) إلى خريطة الألوان المرتبطة بالنافذة. بالنسبة لخريطة ألوان تم تغييرها بواسطة استدعاء لـ XFreeColormap، يتم تعيين عضو خريطة الألوان إلى None. يتم تعيين عضو جديد (new) للإشارة إلى ما إذا كانت خريطة الألوان للنافذة المحددة قد تم تغييرها أو تثبيتها أو إلغاء تثبيتها، ويمكن أن تكون True أو False. إذا كانت True، فقد تم تغيير خريطة الألوان. إذا كانت False، فقد تم تثبيت خريطة الألوان أو إلغاء تثبيتها. يتم دائمًا تعيين عضو الحالة (state) للإشارة إلى ما إذا كانت خريطة الألوان مثبتة أو غير مثبتة ويمكن أن تكون ColormapInstalled أو ColormapUninstalled.
