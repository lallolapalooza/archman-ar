xcb_grab_keyboard - الاستيلاء على لوحة المفاتيح

وسائط الطلب

conn
اتصال XCB بـ X11.
owner_events
إذا كانت 1، فستظل النافذة grab_window تحصل على أحداث المؤشر. إذا كانت 0، فلن يتم الإبلاغ عن الأحداث إلى النافذة grab_window.
grab_window
يحدد النافذة التي سيتم الاستيلاء على المؤشر عليها.
time
طابع زمني لتجنب مشاكل السباق عند تشغيل X عبر الشبكة.

سيتم استبدال القيمة الخاصة XCB_CURRENT_TIME بالوقت الحالي للخادم.

pointer_mode
إحدى القيم التالية:
XCB_GRAB_MODE_SYNC
تبدو حالة لوحة المفاتيح مجمدة: لن يتم إنشاء المزيد من أحداث لوحة المفاتيح بواسطة الخادم حتى يصدر العميل الذي يستولي عليها طلب AllowEvents محررًا أو حتى يتم تحرير الاستيلاء على لوحة المفاتيح.
XCB_GRAB_MODE_ASYNC
تستمر معالجة أحداث لوحة المفاتيح بشكل طبيعي.
keyboard_mode
إحدى القيم التالية:

الوصف

يستولي بنشاط على التحكم في لوحة المفاتيح ويولد أحداث FocusIn و FocusOut. يتم الإبلاغ عن أحداث المفاتيح اللاحقة فقط للعميل الذي يستولي عليها.

سيتم تجاوز أي استيلاء نشط على لوحة المفاتيح بواسطة هذا العميل. إذا تم الاستيلاء على لوحة المفاتيح بنشاط بواسطة عميل آخر، يتم إرجاع AlreadyGrabbed. إذا لم تكن النافذة grab_window مرئية، يتم إرجاع GrabNotViewable. إذا كانت لوحة المفاتيح مجمدة بواسطة استيلاء نشط من عميل آخر، يتم إرجاع GrabFrozen. إذا كان الطابع الزمني المحدد سابقًا لوقت الاستيلاء الأخير على لوحة المفاتيح أو لاحقًا لوقت خادم X الحالي، يتم إرجاع GrabInvalidTime. بخلاف ذلك، يتم تعيين وقت الاستيلاء الأخير على لوحة المفاتيح إلى الطابع الزمني المحدد.

قيمة الإرجاع

يعيد xcb_grab_keyboard_cookie_t. يجب معالجة الأخطاء عند استدعاء دالة الرد xcb_grab_keyboard_reply.

إذا كنت ترغب في معالجة الأخطاء في حلقة الأحداث بدلاً من ذلك، فاستخدم xcb_grab_keyboard_unchecked. انظر xcb-requests(3) للحصول على التفاصيل.

مثال

/*
 * يستولي على لوحة المفاتيح بنشاط
 *
 */
void my_example(xcb_connection_t *conn, xcb_screen_t *screen) {
    xcb_grab_keyboard_cookie_t cookie;
    xcb_grab_keyboard_reply_t *reply;
    cookie = xcb_grab_keyboard(
        conn,
        true,                /* تقرير الأحداث */
        screen->root,        /* الاستيلاء على النافذة الجذر */
        XCB_CURRENT_TIME,
        XCB_GRAB_MODE_ASYNC, /* معالجة الأحداث كالمعتاد، لا تتطلب مزامنة */
        XCB_GRAB_MODE_ASYNC
    );
    if ((reply = xcb_grab_keyboard_reply(conn, cookie, NULL))) {
        if (reply->status == XCB_GRAB_STATUS_SUCCESS)
            printf("تم الاستيلاء بنجاح على لوحة المفاتيح\n");
        free(reply);
    }
}
