XkbKeyAction(3) وظائف Xkb XkbKeyAction(3)

الاسم

XkbKeyAction - ترجع إجراء المفتاح

الملخص

XkbAction XkbKeyAction (XkbDescPtr xkb, KeyCode keycode, int idx);

الوسائط

xkb
وصف Xkb محل الاهتمام
keycode
رمز المفتاح محل الاهتمام
idx
الفهرس للمجموعة والمستوى التحويلي

الوصف

يحدد إجراء المفتاح التأثير الذي تحدثه ضغطات المفاتيح وإطلاقاتها على الحالة الداخلية للخادم. على سبيل المثال، يكون إجراء المفتاح المتوقع المرتبط بضغط مفتاح Shift هو تعيين المعدل Shift. يوجد إجراء مفتاح واحد أو لا شيء مرتبط بكل رمز مفتاح (keysym) مرتبط بكل مفتاح.

تمامًا كما أن القائمة الكاملة لرموز المفاتيح لتعيين لوحة المفاتيح موجودة في الحقل syms لـ client map، فإن القائمة الكاملة لإجراءات المفاتيح لتعيين لوحة المفاتيح موجودة في المصفوفة acts لـ server map. يتم تحديد الحجم الكلي لـ acts بواسطة size_acts، ويتم تحديد عدد الإدخالات بواسطة num_acts.

تصف المصفوفة key_acts، مفهرسة بواسطة رمز المفتاح، الإجراءات المرتبطة بالمفتاح. تحتوي المصفوفة key_acts على min_key_code إدخالات غير مستخدمة في البداية للسماح بالفهرسة المباشرة باستخدام رمز المفتاح. إذا كان إدخال key_acts صفرًا، فهذا يعني أن المفتاح ليس لديه أي إجراءات مرتبطة به. إذا كان الإدخال غير صفري، فإن الإدخال يمثل فهرسًا في الحقل acts لـ server map، تمامًا كما أن الحقل offset لهيكل KeySymMapRec هو فهرس في الحقل syms لـ client map.

السبب في أن الحقل acts هو قائمة خطية من XkbActions هو لتقليل استهلاك الذاكرة المرتبط بخريطة المفاتيح. نظرًا لأن Xkb يسمح للمفاتيح الفردية بأن يكون لها مستويات تحويل متعددة وعدد مختلف من المجموعات لكل مفتاح، فإن مصفوفة ثنائية الأبعاد واحدة من KeySyms ستكون كبيرة جدًا وفارغة احتمالًا. بدلاً من ذلك، يوفر Xkb مصفوفة صغيرة ثنائية الأبعاد من XkbActions لكل مفتاح. لتخزين كل هذه المصفوفات الفردية، يقوم Xkb بدمج كل مصفوفة معًا في الحقل acts لـ server map.

تتكون هياكل إجراءات المفاتيح فقط من حقول من نوع char أو unsigned char. يتم ذلك لتحسين نقل البيانات عندما يرسل الخادم بايتات عبر الشبكة. إذا كانت الحقول بخلاف البايتات، فيجب على الخادم البحث في جميع الإجراءات وتبديل أي حقول غير بايت. نظرًا لأنها تتكون فقط من بايتات، يمكنه نسخها ببساطة.

XkbKeyAction ترجع إجراء المفتاح مفهرسًا بواسطة idx في المصفوفة ثنائية الأبعاد لإجراءات المفاتيح المرتبطة بالمفتاح المقابل لـ keycode. يمكن حساب idx من المجموعة والمستوى التحويلي محل الاهتمام كما يلي:

    idx = group_index * key_width + shift_level

الهياكل

يتم تعريف هيكل KeySymMapRec على النحو التالي:

    #define XkbNumKbdGroups             4
    #define XkbMaxKbdGroup              (XkbNumKbdGroups-1)
    typedef struct {                    /* map to keysyms for a single keycode */
        unsigned char       kt_index[XkbNumKbdGroups];  /* key type index for each group */
        unsigned char       group_info; /* # of groups and out of range group handling */
        unsigned char       width;      /* max # of shift levels for key */
        unsigned short      offset;     /* index to keysym table in syms array */
} XkbSymMapRec, *XkbSymMapPtr;
