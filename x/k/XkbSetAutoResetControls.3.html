XkbSetAutoResetControls(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbSetAutoResetControls(3) وظائف XKB XkbSetAutoResetControls(3)

الاسم

XkbSetAutoResetControls - يغير القيم الحالية لسمات التحكم في إعادة الضبط التلقائي

الملخص

Bool XkbSetAutoResetControls (Display *dpy, unsigned int changes, unsigned int *auto_ctrls, unsigned int *auto_values);

المعاملات

dpy
اتصال بخادم X
changes
عناصر تحكم لتغيير قيم إعادة الضبط التلقائي لها
auto_ctrls
عناصر تحكم من التغييرات التي يجب إعادة ضبطها تلقائيًا
auto_values
1 بت => إعادة الضبط التلقائي قيد التشغيل

الوصف

تقوم XkbSetAutoResetControls بتغيير حالة إعادة الضبط التلقائي وقيم إعادة الضبط التلقائي المرتبطة بها لعناصر التحكم المحددة بواسطة changes. لأي عنصر تحكم محدد بواسطة changes، إذا تم تعيين البت المقابل في auto_ctrls، يتم تكوين عنصر التحكم لإعادة الضبط تلقائيًا عند خروج العميل. إذا كان البت المقابل في auto_values قيد التشغيل، فسيتم تشغيل عنصر التحكم عند خروج العميل؛ إذا كان صفرًا، فسيتم إيقاف تشغيل عنصر التحكم عند خروج العميل. لأي عنصر تحكم محدد بواسطة changes، إذا لم يتم تعيين البت المقابل في auto_ctrls، يتم تكوين عنصر التحكم لعدم إعادة الضبط عند خروج العميل.

على سبيل المثال:

لترك عناصر التحكم في إعادة الضبط التلقائي للمفاتيح اللاصقة كما هي:
	ok = XkbSetAutoResetControls(dpy, 0, 0, 0);

لتغيير عناصر التحكم في إعادة الضبط التلقائي بحيث لا تتأثر المفاتيح اللاصقة عند خروج العميل:
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, 0, 0);

لتغيير عناصر التحكم في إعادة الضبط التلقائي بحيث يتم إيقاف تشغيل المفاتيح اللاصقة عند خروج العميل:
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, XkbStickyKeysMask, 0);

لتغيير عناصر التحكم في إعادة الضبط التلقائي بحيث يتم تشغيل المفاتيح اللاصقة عند خروج العميل:
	ok = XkbSetAutoResetControls(dpy, XkbStickyKeysMask, XkbStickyKeysMask, 
XkbStickyKeysMask);
تقوم XkbSetAutoResetControls بملء auto_ctrls و auto_values بعناصر التحكم في إعادة الضبط التلقائي لهذا العميل المحدد. لاحظ أن جميع البتات صالحة في القيم المرجعة، وليس فقط تلك المحددة في قناع changes.
