XkbBellEvent(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbBellEvent(3) وظائف XKB XkbBellEvent(3)

الاسم

XkbBellEvent - توفر دالة تبدأ حدث جرس للوحة المفاتيح دون إصدار صوت الجرس

الاستخدام

Bool XkbBellEvent (Display *display, Window window, int percent, Atom name);

الوسائط

display
الاتصال بخادم X
window
نافذة الحدث، أو None
percent
مستوى الصوت النسبي، والذي يمكن أن يتراوح من -100 إلى 100 شاملة
name
اسم جرس، أو NULL

الوصف

يسمح بروتوكول X الأساسي للتطبيقات فقط بإصدار صوت جرس النظام بشكل صريح بمدة ونغمة ومستوى صوت معين. Xkb يوسع هذه القدرة بالسماح للعملاء بربط أسماء رمزية بالأجراس، وتعطيل الأجراس المسموعة، وتلقي حدث كلما تم رنين جرس لوحة المفاتيح. لأغراض هذا المستند، يتم تعريف جرس المسموع على أنه جرس النظام، أو جرس لوحة المفاتيح الافتراضي، على عكس أي صوت مسموع آخر يتم توليده في مكان آخر في النظام. يمكنك طلب تلقي أحداث XkbBellNotify عند رنين أي عميل لأي من ما يلي:

  • الجرس الافتراضي
  • أي جرس على جهاز إدخال يمكن تحديده بواسطة زوج bell_class و bell_id
  • أي جرس يتم تحديده فقط باسم اعتباطي. (هذا، من وجهة نظر الخادم، مجرد اسم، ولا يرتبط بأي جهاز مادي يولد الصوت. يجب على بعض تطبيقات العملاء توليد الصوت، أو ردود الفعل المرئية، إن وجدت، المرتبطة بالاسم.)

    يمكنك أيضًا طلب تلقي أحداث XkbBellNotify عندما يرن الخادم الجرس الافتراضي أو إذا طلب أي عميل أحداث فقط (بدون إصدار صوت الجرس) لأي من أنواع الأجراس المذكورة سابقًا.

    يمكنك تعطيل الأجراس المسموعة على أساس عالمي. على سبيل المثال، قد يرغب العميل الذي يستبدل جرس لوحة المفاتيح بإشارة صوتية أخرى في إيقاف تشغيل التحكم AudibleBell لمنع الخادم من توليد صوت أيضًا وتجنب الضوضاء. إذا قمت بتعطيل الأجراس المسموعة وطلبت تلقي أحداث XkbBellNotify، يمكنك توليد ردود فعل مختلفة عن الجرس الافتراضي.

    ومع ذلك، يمكنك تجاوز التحكم AudibleBell عن طريق استدعاء إحدى الوظائف التي تجبر على رنين جرس بغض النظر عن إعداد التحكم AudibleBell - XkbForceDeviceBell أو XkbForceBell. في هذه الحالة، لا يولد الخادم حدث جرس.

    تمامًا كما يمكن لبعض لوحات المفاتيح إنتاج نقرات مفاتيح للإشارة عند الضغط على مفتاح أو تكراره، يمكن لـ Xkb توفير ردود فعل للضوابط باستخدام رموز تنبيه خاصة. يتم استخدام التحكم AccessXFeedback لتكوين الأنواع المحددة من العمليات التي تولد ردود فعل.

    أسماء الأجراس

    يمكنك ربط اسم بفعل رنين جرس عن طريق تحويل الاسم إلى Atom ثم استخدام هذا الاسم عند استدعاء الوظائف المدرجة في هذا الفصل. إذا تم توليد حدث كنتيجة، يتم تمرير الاسم بعد ذلك إلى جميع العملاء الآخرين المهتمين بتلقي أحداث XkbBellNotify. لاحظ أن هذه أسماء اعتباطية وأنه لا يوجد ارتباط بأي أصوات. يجب على أي أصوات أو تأثيرات أخرى (مثل الأجراس المرئية على الشاشة) أن يتم توليدها بواسطة تطبيق عميل عند استلام حدث الجرس الذي يحتوي على الاسم. لا يوجد اسم افتراضي لجرس لوحة المفاتيح الافتراضي. يولد الخادم بعض الأجراس المعرفة مسبقًا لضوابط AccessX. تظهر هذه الأجراس المسماة في الجدول 1؛ يتم تضمين الاسم في أي حدث جرس يتم إرساله إلى العملاء الذين طلبوا تلقي أحداث XkbBellNotify.

    الأجراس المسموعة

    باستخدام Xkb، يمكنك توليد أحداث جرس لا تصدر بالضرورة صوت جرس النظام. هذا مفيد إذا كنت بحاجة إلى استخدام خادم صوت بدلاً من صوت النظام. على سبيل المثال، عند بدء تشغيل عميل صوت، يمكنه تعطيل الجرس المسموع (جرس النظام)، ثم الاستماع إلى أحداث XkbBellNotify. عند استلام حدث XkbBellNotify، يمكن لعميل الصوت بعد ذلك إرسال طلب إلى خادم صوت لتشغيل صوت.

    يمكنك التحكم في ميزة الأجراس المسموعة عن طريق تمرير XkbAudibleBellMask إلى XkbChangeEnabledControls. إذا قمت بتعيين XkbAudibleBellMask على تشغيل، يرن الخادم جرس النظام عند حدوث حدث جرس. هذا هو الوضع الافتراضي. إذا قمت بتعيين XkbAudibleBellMask على إيقاف وحدث حدث جرس، فإن الخادم لا يرن جرس النظام ما لم تستدعي XkbForceDeviceBell أو XkbForceBell.

    الأجراس المسموعة هي أيضًا جزء من ضوابط إعادة الضبط التلقائي لكل عميل.

    وظائف الجرس

    استخدم الوظائف الموضحة في هذا القسم لرنين الأجراس وتوليد أحداث الجرس.

    يحتوي امتداد الإدخال على نوعين من ردود الفعل التي يمكن أن تولد الأجراس - ردود فعل الجرس وردود فعل لوحة المفاتيح. قد تحتوي بعض الوظائف في هذا القسم على معلمات bell_class و bell_id؛ قم بتعيينها على النحو التالي: قم بتعيين bell_class إلى BellFeedbackClass أو KbdFeedbackClass. يمكن أن يحتوي الجهاز على أكثر من رد فعل واحد من كل نوع؛ قم بتعيين bell_id إلى رد الفعل المحدد للجرس من نوع bell_class.

XkbBellEvent(3) - X11 Manual Pages

NAME

XkbBellEvent - raise a bell event

SYNOPSIS

    Bool XkbBellEvent(
        Display *display,
        Window window,
        int percent,
        Atom name
    );

ARGUMENTS

display
Specifies the connection to the X server.
window
Specifies the window associated with the event.
percent
Specifies the volume of the bell as a percentage of the maximum volume.
name
Specifies the name of the bell to be evoked.

DESCRIPTION

The XkbBellEvent function generates a bell event. This function first checks if a compatible keyboard extension is available in the X server. If not, XkbBellEvent immediately returns False. Otherwise, XkbBellEvent calls XkbDeviceBellEvent with the specified display, window, percent, and name, a device_spec of XkbUseCoreKbd, a bell_class of XkbDfltXIClass, and a bell_id of XkbDfltXIId, and returns what XkbDeviceBellEvent returns.

XkbBellEvent generates a XkbBellNotify event.

You can call XkbBellEvent without first initializing the keyboard extension.

RETURN VALUES

False
The XkbBellEvent immediately returns False, if a compatible keyboard extension isn't present in the X server.

STRUCTURES

Xkb generates XkbBellNotify events for all bells except for those resulting from calls to XkbForceDeviceBell and XkbForceBell. To receive XkbBellNotify events under all possible conditions, pass XkbBellNotifyMask in both the bits_to_change and values_for_bits parameters to XkbSelectEvents.

The XkbBellNotify event has no event details. It is either selected or it is not. However, you can call XkbSelectEventDetails using XkbBellNotify as the event_type and specifying XkbAllBellEventsMask in bits_to_change and values_for_bits. This has the same effect as a call to XkbSelectEvents.

The structure for the XkbBellNotify event type contains:

   typedef struct _XkbBellNotify {
       int            type;        /* Xkb extension base event code */
       unsigned long  serial;      /* X server serial number for event */
       Bool           send_event;  /* True => synthetically generated */
       Display *      display;     /* server connection where event generated */
       Time           time;        /* server time when event generated */
       int            xkb_type;    /* XkbBellNotify */
       unsigned int   device;      /* Xkb device ID, will not be XkbUseCoreKbd */
       int            percent;     /* requested volume as % of max */
       int            pitch;       /* requested pitch in Hz */
       int            duration;    /* requested duration in microseconds */
       unsigned int   bell_class;  /* X input extension feedback class */
       unsigned int   bell_id;     /* X input extension feedback ID */
       Atom           name;        /* "name" of requested bell */
       Window         window;      /* window associated with event */
       Bool           event_only;  /* False -> the server did not produce a beep */
   } XkbBellNotifyEvent;
If your application needs to generate visual bell feedback on the screen when it receives a bell event, use the window ID in the XkbBellNotifyEvent, if present.

XkbBellEvent - إثارة حدث جرس

الملخص

    Bool XkbBellEvent(
        Display *display,
        Window window,
        int percent,
        Atom name
    );

المعاملات

display
يحدد الاتصال بخادم X.
window
يحدد النافذة المرتبطة بالحدث.
percent
يحدد حجم الجرس كنسبة مئوية من الحد الأقصى للحجم.
name
يحدد اسم الجرس المطلوب إصداره.

الوصف

تقوم الدالة XkbBellEvent بإنشاء حدث جرس. تتحقق هذه الدالة أولاً مما إذا كان امتداد لوحة مفاتيح متوافق متاحًا في خادم X. إذا لم يكن كذلك، فإن XkbBellEvent تعيد القيمة False فورًا. بخلاف ذلك، تستدعي XkbBellEvent الدالة XkbDeviceBellEvent باستخدام المعاملات المحددة display, window, percent, و name, مع تحديد device_spec إلى XkbUseCoreKbd، و bell_class إلى XkbDfltXIClass، و bell_id إلى XkbDfltXIId، وتعيد ما تعيده XkbDeviceBellEvent.

تقوم XkbBellEvent بإنشاء حدث XkbBellNotify.

يمكنك استدعاء XkbBellEvent دون تهيئة امتداد لوحة المفاتيح أولاً.

قيم الإرجاع

False
تعيد الدالة XkbBellEvent القيمة False فورًا، إذا لم يكن امتداد لوحة مفاتيح متوافق موجودًا في خادم X.

الهياكل

ينشئ Xkb أحداث XkbBellNotify لجميع الأجراس باستثناء تلك الناتجة عن استدعاءات XkbForceDeviceBell و XkbForceBell. لاستقبال أحداث XkbBellNotify في جميع الظروف الممكنة، قم بتمرير XkbBellNotifyMask في كل من المعاملين bits_to_change و values_for_bits إلى XkbSelectEvents.

لا يحتوي حدث XkbBellNotify على تفاصيل حدث. إما أن يتم تحديده أو لا. ومع ذلك، يمكنك استدعاء XkbSelectEventDetails باستخدام XkbBellNotify كـ event_type وتحديد XkbAllBellEventsMask في bits_to_change و values_for_bits. وهذا له نفس تأثير استدعاء XkbSelectEvents.

يحتوي الهيكل الخاص بنوع حدث XkbBellNotify على:

   typedef struct _XkbBellNotify {
       int            type;        /* Xkb extension base event code */
       unsigned long  serial;      /* X server serial number for event */
       Bool           send_event;  /* True => synthetically generated */
       Display *      display;     /* server connection where event generated */
       Time           time;        /* server time when event generated */
       int            xkb_type;    /* XkbBellNotify */
       unsigned int   device;      /* Xkb device ID, will not be XkbUseCoreKbd */
       int            percent;     /* requested volume as % of max */
       int            pitch;       /* requested pitch in Hz */
       int            duration;    /* requested duration in microseconds */
       unsigned int   bell_class;  /* X input extension feedback class */
       unsigned int   bell_id;     /* X input extension feedback ID */
       Atom           name;        /* "name" of requested bell */
       Window         window;      /* window associated with event */
       Bool           event_only;  /* False -> the server did not produce a beep */
   } XkbBellNotifyEvent;
