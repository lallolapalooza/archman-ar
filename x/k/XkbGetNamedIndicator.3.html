XkbGetNamedIndicator(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbGetNamedIndicator(3) وظائف XKB XkbGetNamedIndicator(3)

الاسم

XkbGetNamedIndicator - البحث عن خريطة المؤشر ومعلومات أخرى لمؤشر بالاسم

الملخص

Bool XkbGetNamedDeviceIndicator (Display *dpy, unsigned int dev_spec, unsigned int led_class, unsigned int led_id, Atom name, int *ndx_rtrn, Bool *state_rtrn, XkbIndicatorMapPtr map_rtrn, Bool *real_rtrn);

Bool XkbGetNamedIndicator (Display *dpy, Atom name, int *ndx_rtrn, Bool *state_rtrn, XkbIndicatorMapPtr map_rtrn, Bool *real_rtrn);

الوسائط

dpy
اتصال بخادم X
dev_spec
معرف جهاز لوحة المفاتيح، أو XkbUseCoreKbd
led_class
فئة التغذية الراجعة، أو XkbDfltXIClass
led_id
معرف التغذية الراجعة، أو XkbDfltXIId
name
اسم المؤشر المطلوب استرداده
ndx_rtrn
يتم ملؤه بالمؤشر المسترد
state_rtrn
يتم ملؤه بالحالة الحالية للمؤشر المسترد
map_rtrn
يتم ملؤه بخريطة المؤشر المسترد
real_rtrn
يتم ملؤه بالقيمة True إذا كان المؤشر المسمى حقيقيًا (فعليًا)

الوصف

يسمح Xkb أيضًا للتطبيقات بالإشارة إلى المؤشرات بالاسم. استخدم XkbGetNames للحصول على أسماء المؤشرات. يؤدي استخدام الأسماء إلى التخلص من الحاجة إلى ترميز قيم الأقنعة الثنائية بشكل ثابت للوحات مفاتيح معينة. على سبيل المثال، بدلاً من استخدام ثوابت خاصة بالبائع مثل WSKBLed_ScrollLock على محطات عمل Digital أو XLED_SCROLL_LOCK على محطات عمل Sun، يمكنك بدلاً من ذلك استخدام XkbGetNamedDeviceIndicator للبحث عن معلومات حول المؤشر المسمى "Scroll Lock".

إذا كان الجهاز المحدد بواسطة device_spec يحتوي على مؤشر مسمى name، فستعيد XkbGetNamedDeviceIndicator القيمة True وتملأ بقية المعلمات بمعلومات حول المؤشر. خلاف ذلك، ستعيد XkbGetNamedDeviceIndicator القيمة False.

يُرجع حقل ndx_rtrn الفهرس المستند إلى الصفر للمؤشر المسمى. هذا الفهرس هو موضع البت لاستخدامه في أي استدعاء دالة يتطلب قناعًا لبتات المؤشر، وكذلك فهرس المؤشر في مصفوفة XkbIndicatorRec لخرائط المؤشرات. يُرجع state_rtrn الحالة الحالية للمؤشر المسمى (True = قيد التشغيل، False = متوقف). يُرجع map_rtrn خريطة المؤشر للمؤشر المسمى. بالإضافة إلى ذلك، إذا تم تعيين المؤشر إلى LED فعلي، فسيتم تعيين المعلمة real_rtrn إلى True.

كل من الوسائط " _rtrn " اختيارية؛ يمكنك تمرير NULL لأي وسائط " _rtrn " غير مطلوبة.

XkbGetNamedIndicator هي دالة مساعدة تستدعي XkbGetNamedDeviceIndicator باستخدام device_spec لـ XkbUseCoreKbd، و led_class لـ XkbDfltXIClass، و led_id لـ XkbDfltXIId. إنها تُرجع قيمة الإرجاع من XkbGetNamedDeviceIndicator.

قيم الإرجاع

True
تُرجع الدوال XkbGetNamedIndicator و XkbGetNamedDeviceIndicator القيمة True إذا كان الجهاز المحدد بواسطة device_spec يحتوي على مؤشر مسمى name.
False
تُرجع الدوال XkbGetNamedIndicator و XkbGetNamedDeviceIndicator القيمة False إذا كان الجهاز المحدد بواسطة device_spec لا يحتوي على مؤشر مسمى name.
