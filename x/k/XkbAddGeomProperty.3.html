XkbAddGeomProperty(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbAddGeomProperty(3) وظائف Xkb XkbAddGeomProperty(3)

الاسم

XkbAddGeomProperty - إضافة خاصية واحدة إلى وصف هندسة لوحة المفاتيح الموجودة

الملخص

XkbPropertyPtr XkbAddGeomProperty (XkbGeometryPtr geom، _Xconst char *name، _Xconst char *value);

الوسائط

geom
الهندسة التي سيتم تحديثها
name
اسم الخاصية الجديدة
value
قيمة الخاصية الجديدة

الوصف

يوفر Xkb وظائف لإضافة عنصر جديد واحد إلى هندسة لوحة المفاتيح العليا. في كل حالة، يتم زيادة حقول num_ * للهيكل المقابل بمقدار 1. لا تقوم هذه الوظائف بتغيير sz_* إلا إذا لم تعد هناك مساحة في المصفوفة. تملأ بعض هذه الوظائف قيم هيكل العنصر من الوسائط. بالنسبة للوظائف الأخرى، يجب عليك كتابة رمز صريح لملء عناصر الهيكل.

يحتوي وصف هندسة المستوى الأعلى على قائمة من خصائص الهندسة. تربط خاصية الهندسة سلسلة تعسفية باسم تعسفي بنفس القدر. يمكن للبرامج التي تعرض صورًا للوحات المفاتيح استخدام خصائص الهندسة كتلميحات، ولكن Xkb لا يفسرها. لا تشير هياكل الهندسة الأخرى إلى خصائص الهندسة.

XkbAddGeomProperty تضيف خاصية واحدة بالاسم name والقيمة value المحددتين إلى هندسة لوحة المفاتيح التي يحددها geom. XkbAddGeomProperty تعود بـ NULL إذا كان أي من الوسائط فارغًا أو إذا لم تتمكن من تخصيص مساحة للخاصية. لتخصيص مساحة لعدد تعسفي من الخصائص، استخدم وظيفة XkbAllocGeomProps.

الهياكل

    typedef struct _XkbProperty {
        char *         name;       /* اسم الخاصية */
        char *         value;      /* قيمة الخاصية */
    } XkbPropertyRec,*XkbPropertyPtr;
