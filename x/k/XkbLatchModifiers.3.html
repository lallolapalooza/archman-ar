XkbLatchModifiers(3)

الحزمة: libx11

التراخيص: MIT AND X11

XkbLatchModifiers(3) وظائف XKB XkbLatchModifiers(3)

الاسم

XkbLatchModifiers - تثبيت وإلغاء تثبيت أي من المعدلات الثمانية الحقيقية للوحة المفاتيح

الملخص

Bool XkbLatchModifiers (Display *display, unsigned int device_spec, unsigned int affect, unsigned int values);

الوسائط

display
الاتصال بخادم X
device_spec
معرف الجهاز، أو XkbUseCoreKbd
affect
قناع للمعدلات الحقيقية التي يجب تغيير حالة قفلها
values
1 => تثبيت، 0 => إلغاء تثبيت؛ فقط للمعدلات المحددة بواسطة affect

الوصف

XkbLatchModifiers يرسل طلبًا إلى الخادم لتثبيت المعدلات الحقيقية المحددة بواسطة كل من affect و values وإلغاء تثبيت المعدلات الحقيقية المحددة بواسطة affect ، ولكنها غير محددة بواسطة values.

XkbLatchModifiers لا ينتظر ردًا من الخادم. يعيد True إذا تم إرسال الطلب، و False إذا لم يكن كذلك.

الدوال في هذا القسم التي تغير استخدام المعدلات تستخدم قناعًا في الوسيط affect. إنه OR ثنائي شامل للقيم القانونية لأقنعة المعدلات:

الجدول 1 أقنعة المعدلات الحقيقية
قناع
ShiftMask
LockMask
ControlMask
Mod1Mask
Mod2Mask
Mod3Mask
Mod4Mask
Mod5Mask

قيم الإرجاع

True
تعيد الدالة XkbLatchModifiers True إذا تم إرسال طلب إلى الخادم لتثبيت المعدلات الحقيقية المحددة بواسطة كل من affect و values وإلغاء تثبيت المعدلات الحقيقية المحددة بواسطة affect ، ولكنها غير محددة بواسطة values.
False
تعيد الدالة XkbLatchModifiers False إذا لم يتم إرسال الطلب.
