XkbGetDeviceInfo(3)

XkbGetDeviceInfo(3) وظائف Xkb XkbGetDeviceInfo(3)

الاسم

XkbGetDeviceInfo - تحديد ما إذا كان خادم X يسمح بالوصول إلى Xkb لقدرات معينة لأجهزة الإدخال بخلاف لوحة المفاتيح الأساسية لـ X، أو لتحديد حالة خرائط المؤشرات، أسماء المؤشرات أو إجراءات الأزرار على جهاز ملحق غير فئة المفاتيح

الملخص

XkbDeviceInfoPtr XkbGetDeviceInfo (Display *dpy, unsigned int which, unsigned int device_spec, unsigned int ind_class, unsigned int ind_id);

المعاملات

dpy
الاتصال بخادم X
which
قناع يشير إلى المعلومات المراد إرجاعها
device_spec
معرف الجهاز، أو XkbUseCoreKbd
ind_class
فئة التغذية الراجعة لطلبات المؤشر
ind_id
معرف التغذية الراجعة لطلبات المؤشر

الوصف

لتحديد ما إذا كان خادم X يسمح بالوصول إلى Xkb لقدرات معينة لأجهزة الإدخال بخلاف لوحة المفاتيح الأساسية لـ X، أو لتحديد حالة خرائط المؤشرات، أسماء المؤشرات أو إجراءات الأزرار على جهاز ملحق غير فئة المفاتيح، استخدم XkbGetDeviceInfo.

XkbGetDeviceInfo ترجع معلومات حول جهاز الإدخال المحدد بواسطة device_spec. بخلاف المعامل device_spec لمعظم وظائف Xkb، لا يلزم أن يكون device_spec جهاز لوحة مفاتيح. ومع ذلك، يجب أن يشير إما إلى لوحة المفاتيح الأساسية أو جهاز ملحق إدخال X صالح.

المعامل which هو قناع يحدد المعلومات الاختيارية المراد إرجاعها. إنه OR شامل لواحدة أو أكثر من القيم من الجدول 1 ويسبب احتواء XkbDeviceInfoRec المرتجع على قيم للحقول المقابلة المحددة في الجدول.

XkbDeviceInfoRec التي ترجعها XkbGetDeviceInfo تحتوي دائمًا على قيم للحقول name (قد تكون سلسلة فارغة، "")، type, supported, unsupported, has_own_state, dflt_kbd_fd, و dflt_kbd_fb. يتم ملء الحقول الأخرى حسب ما يحدده which.

عند الإرجاع، سيتم تعيين الحقل supported إلى OR الشامل لصفر أو أكثر من البتات من الجدول 1؛ كل بت معين يشير إلى ميزة ملحق Xkb اختيارية مدعومة من قبل تنفيذ الخادم، وقد يقوم العميل بتعديل السلوك المرتبط بها.

إذا تم تعيين بت XkbButtonActionsMask في which، فإن XkbDeviceInfoRec المرتجع سيكون لديه إجراءات الأزرار (حقل btn_acts) مملوءة لجميع الأزرار.

إذا كان which يتضمن أحد البتات في XkbXI_IndicatorsMask، فيجب تحديد فئة التغذية الراجعة للمؤشرات في ind_class، ويجب تحديد معرف التغذية الراجعة للمؤشرات في ind_id. إذا لم يشمل الطلب أيًا من البتات في XkbXI_IndicatorsMask، يتم تجاهل معاملي ind_class و ind_id. يمكن الحصول على الفئة والمعرف عبر طلب امتداد جهاز الإدخال XListInputDevices.

إذا تم تعيين أي من بتات XkbXI_IndicatorsMask في which، فإن XkbDeviceInfoRec المرتجع سيكون قد ملأ الأجزاء من بنية leds المقابلة للتغذية الراجعة للمؤشر المحددة بواسطة ind_class و ind_id. سيتم تخصيص متجه leds لبنية XkbDeviceInfoRec إذا لزم الأمر وسيتم ملء sz_leds و num_leds. سيتم دائمًا ملء الحقول led_class, led_id و phys_indicators لإدخال leds المقابل لـ ind_class و ind_id. إذا كان which يحتوي على XkbXI_IndicatorNamesMask، فسيتم إرجاع الحقلين names_present و names لبنية leds المقابلين لـ ind_class و ind_id. إذا كان which يحتوي على XkbXI_IndicatorStateMask، فسيتم تحديث الحقل state المقابل. إذا كان which يحتوي على XkbXI_IndicatorMapsMask، فسيتم تحديث الحقلين maps_present و maps.

يوفر Xkb وظائف مساعدة لطلب مجموعات فرعية من المعلومات المتاحة عبر XkbGetDeviceInfo. تعكس هذه الوظائف المساعدة بعض أقنعة البتات. تأخذ جميع الوظائف مؤشر XkbDeviceInfoPtr كمعامل إدخال وتعمل على جهاز امتداد إدخال X المحدد بواسطة حقل device_spec للبنية. فقط الأجزاء من البنية المشار إليها في وصف الوظيفة يتم تحديثها. يمكن الحصول على بنية XkbDeviceInfoRec المستخدمة في استدعاء الوظيفة عن طريق استدعاء XkbGetDeviceInfo أو يمكن تخصيصها عن طريق استدعاء XkbAllocDeviceInfo.

البنى

يتم نقل المعلومات حول أجهزة امتداد إدخال X بين برنامج العميل وامتداد Xkb في بنية XkbDeviceInfoRec:

typedef struct {
    char *               name;          /* اسم الجهاز */
    Atom                 type;          /* اسم فئة الأجهزة */
    unsigned short       device_spec;   /* الجهاز المعني */
    Bool                 has_own_state; /* True=>هذا الجهاز لديه حالته الخاصة */
    unsigned short       supported;     /* بتات تشير إلى القدرات المدعومة */
    unsigned short       unsupported;   /* بتات تشير إلى القدرات غير المدعومة */
    unsigned short       num_btns;      /* عدد الإدخالات في btn_acts */
    XkbAction *          btn_acts;      /* إجراءات الأزرار */
    unsigned short       sz_leds;       /* العدد الإجمالي للإدخالات في متجه LEDs */
    unsigned short       num_leds;      /* عدد الإدخالات الصالحة في متجه LEDs */
    unsigned short       dflt_kbd_fb;   /* معرف امتداد الإدخال للمؤشر الافتراضي (لوحة المفاتيح الأساسية) */
    unsigned short       dflt_led_fb;   /* معرف امتداد الإدخال للتغذية الراجعة الافتراضية للمؤشر */
    XkbDeviceLedInfoPtr  leds;          /* أوصاف LEDs */
} XkbDeviceInfoRec, *XkbDeviceInfoPtr;
